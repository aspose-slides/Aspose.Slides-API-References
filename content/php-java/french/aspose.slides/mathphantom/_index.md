## MathPhantom classe

 Représente un objet mathématique fantôme (<m:phant>) qui affecte la mise en page de son élément enfant sans nécessairement l'afficher. Un fantôme peut masquer son expression de base tout en préservant sa largeur, sa hauteur ou sa profondeur afin d'aligner les formules ou de réserver de l'espace.  
 La visibilité et le comportement géométrique sont contrôlés par des propriétés telles que Show, ZeroWid, ZeroAsc, ZeroDesc et Transp.

**Paramètres :**

| Nom | Type | Description |
| --- | --- | --- |
| element | [MathLeftSubSuperscriptElement](../mathleftsubsuperscriptelement) | L'IMathElement de base dont la visibilité et la mise en page seront contrôlées par le fantôme. Cet élément définit le contenu qui peut être masqué ou affiché, tout en affectant l'alignement géométrique des mathématiques environnantes. L'élément fantôme est utilisé pour réserver ou supprimer l'espace visuel de son expression de base sans nécessairement l'afficher. Il correspond à l'élément OMML <m:phant>. |

### getShow {#getShow}

| Nom | Description |
| --- | --- |
| getShow () | Obtient ou définit une valeur indiquant si l'élément de base est affiché. Lorsque false, l'élément de base est masqué mais peut encore occuper de l'espace en fonction des autres paramètres du phantom. Correspond à l'attribut OMML m:show. |

**Renvoie :**
boolean

---

### getTransp {#getTransp}

| Nom | Description |
| --- | --- |
| getTransp () | Obtient ou définit une valeur indiquant si le phantom est transparent pour les règles d'espacement basées sur les classes. Lorsque true, les opérateurs et symboles à l'intérieur du phantom continuent d'influencer l'espacement mathématique autour du phantom (comme s'il était visible). Lorsque false, les règles d'espacement basées sur les classes sont ignorées. Correspond à l'attribut OMML m:transp. |

**Renvoie :**
boolean

---

### getZeroAsc {#getZeroAsc}

| Nom | Description |
| --- | --- |
| getZeroAsc () | Obtient ou définit une valeur indiquant si la portion ascendante (hauteur au-dessus de la ligne de base) de l'élément de base doit être considérée comme zéro. Lorsque true, le phantom ne soulève pas la ligne de base de la ligne de mathématiques environnante. Correspond à l'attribut OMML m:zeroAsc. |

**Renvoie :**
boolean
