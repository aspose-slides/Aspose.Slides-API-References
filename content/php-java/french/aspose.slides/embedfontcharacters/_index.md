## EmbedFontCharacters classe

Représente la règle à utiliser pour ajouter une nouvelle police d'incorporation dans IPresentation

## Constantes

| Nom | Valeur | Description |
| --- | --- | --- |
[OnlyUsed](#OnlyUsed) | 0 | Incorporer uniquement les caractères utilisés dans la présentation (idéal pour réduire la taille du fichier). |
[All](#All) | 1 | Incorporer tous les caractères (idéal pour l'édition par d'autres personnes). |

---

### OnlyUsed {#OnlyUsed}
Incorporer uniquement les caractères utilisés dans la présentation (idéal pour réduire la taille du fichier).

---

### All {#All}
Incorporer tous les caractères (idéal pour l'édition par d'autres personnes).
