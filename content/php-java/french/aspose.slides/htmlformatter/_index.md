### createDocumentFormatter {#createDocumentFormatter}

| Nom | Description |
| --- | --- |
| createDocumentFormatter (String, boolean) | Crée et renvoie un formateur HTML pour une vue de document simple constituée de séquences de diapositives affichées les unes sous les autres. |

 **Paramètres :**

| Nom | Type | Description |
| --- | --- | --- |
| css | String | Spécifie le CSS pour ce fichier. |
| showSlideTitle | boolean | Ajoute le titre de la diapositive s'il y en a un au-dessus de l'image de la diapositive. |

 **Renvoie :**
HtmlFormatter
