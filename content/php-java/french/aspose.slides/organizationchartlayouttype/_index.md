## OrganizationChartLayoutType classe

 Représente le type de mise en forme des nœuds enfants dans un organigramme
 

## Constantes

| Nom | Valeur | Description |
| --- | --- | --- |
[Initial](#Initial) | 0 | Type de disposition initial |
[Standart](#Standart) | 1 | Place les nœuds enfant horizontalement sous le nœud parent. |
[BothHanging](#BothHanging) | 2 | Place les nœuds enfant verticalement sous le nœud parent, à la fois du côté gauche et du côté droit. |
[LeftHanging](#LeftHanging) | 3 | Place les nœuds enfant verticalement sous le nœud parent du côté gauche. |
[RightHanging](#RightHanging) | 4 | Place les nœuds enfant verticalement sous le nœud parent du côté droit. |
