## classe VideoPlayModePreset

Constantes qui définissent comment une vidéo est lue.

## Constantes

| Nom | Valeur | Description |
| --- | --- | --- |
[Mixed](#Mixed) | -1 |  |
[Auto](#Auto) | 0 | Lecture automatique. |
[OnClick](#OnClick) | 1 | Lecture uniquement lorsque le cadre vidéo est cliqué. |
[AllSlides](#AllSlides) | 2 | Lecture sur toutes les diapositives. |
[InClickSequence](#InClickSequence) | 3 | Lecture automatique avec un clic. |
