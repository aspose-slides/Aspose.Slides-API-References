## SensitivityLabelAssignmentType classe

 Représente la méthode d'affectation pour l'étiquette de sensibilité.
 

## Constantes

| Name | Value | Description |
| --- | --- | --- |
[Standard](#Standard) | 0 | Utilisé pour toute étiquette de sensibilité qui n'a pas été appliquée directement par l'utilisateur. Cela inclut les étiquettes par défaut, les étiquettes appliquées automatiquement. |

---


### Standard {#Standard}
Utilisé pour toute étiquette de sensibilité qui n'a pas été appliquée directement par l'utilisateur. Cela inclut les étiquettes par défaut, les étiquettes appliquées automatiquement.

---

### Privilégié {#Privileged}
Utilisé pour toute étiquette de sensibilité qui a été appliquée directement par l'utilisateur. Cela inclut les étiquettes de sensibilité appliquées manuellement ainsi que l'étiquetage recommandé ou obligatoire ou toute fonctionnalité où l'utilisateur décide quelle étiquette de sensibilité appliquer.
