## TextSearchOptions classe

 Représente les options qui peuvent être utilisées pour rechercher du texte dans une Presentation, Slide ou TextFrame.
 
### TextSearchOptions {#TextSearchOptions}

| Nom | Description |
| --- | --- |
| TextSearchOptions() | Crée de nouvelles options de recherche de texte par défaut. |

 **Renvoie :**
TextSearchOptions

| Nom | Description |
| --- | --- |
| getCaseSensitive () | Définissez true pour utiliser une recherche sensible à la casse, false sinon. Booléen en lecture/écriture. |

boolean

### getIncludeNotes {#getIncludeNotes}

| Nom | Description |
| --- | --- |
| getIncludeNotes () | Définissez true pour inclure le texte contenu dans les notes de diapositive ( NotesSlide) lors d’une recherche, d’un remplacement ou d’opérations de mise en évidence. La valeur par défaut est false. |

 **Renvoie :**
boolean
