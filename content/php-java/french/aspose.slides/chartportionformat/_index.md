## ChartPortionFormat classe

 Cette classe contient les propriétés de formatage des portions de graphique utilisées dans les graphiques.
 Unlike IPortionFormatEffectiveData, toutes les propriétés de cette classe sont modifiables.
 
 Cette classe est utilisée pour retourner et manipuler les propriétés de formatage des portions de texte définies pour la portion particulière. Cela signifie qu'aucune héritage n'est appliquée lors de la récupération des valeurs, ainsi que, dans la majorité des cas, vous obtiendrez des valeurs signifiant « indéfini ».
 Afin d'obtenir les valeurs des paramètres de formatage effectif incluant les héritées, vous devez utiliser la méthode PortionFormat#getEffective qui renvoie une instance IPortionFormatEffectiveData.
