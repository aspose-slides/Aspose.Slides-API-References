## PdfTextCompression classe

 Constantes qui définissent le type de compression appliquée à tout le contenu du fichier PDF sauf les images.
 

## Constantes

| Nom | Valeur | Description |
| --- | --- | --- |
[None](#None) | 0 | Pas de compression. |
[Flate](#Flate) | 1 | Compression Flate (ZIP). |


---


### None {#None}
Pas de compression.

---

### Flate {#Flate}
Compression Flate (ZIP).
