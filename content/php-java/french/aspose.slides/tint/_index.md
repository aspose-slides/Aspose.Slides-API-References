## Tint classe

Représente un effet Tint.
Décale les valeurs de couleur de l'effet vers/loin de la teinte selon la quantité spécifiée.

### equals {#equals}

| Nom | Description |
| --- | --- |
| equals (Object) | Détermine si le Tint spécifié est égal au Tint actuel. |

**Paramètres :**

| Nom | Type | Description |
| --- | --- | --- |
| obj | Object | Le Tint à comparer. |

**Retour :**
boolean
