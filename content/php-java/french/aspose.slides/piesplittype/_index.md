## PieSplitType classe

Représente un type de points de division dans le deuxième camembert ou barre sur un graphique camembert-sur-camembert ou barre-sur-camembert.

## Constantes

| Nom | Valeur | Description |
| --- | --- | --- |
[Default](#Default) | 0 | Indique que les points de données doivent être divisés en utilisant le mécanisme par défaut pour ce type de graphique. |
[Custom](#Custom) | 1 | Indique que les points de données doivent être divisés entre le camembert et le deuxième graphique selon les valeurs Custom Split. |
[ByPercentage](#ByPercentage) | 2 | Indique que les points de données doivent être divisés entre le camembert et le deuxième graphique en plaçant les points dont le pourcentage est inférieur à Split Position percent dans le deuxième graphique. |
[ByPos](#ByPos) | 3 | Indique que les points de données doivent être divisés entre le camembert et le deuxième graphique en plaçant le dernier Split Position des points de données dans le deuxième graphique. |
[ByValue](#ByValue) | 4 | Indique que les points de données doivent être divisés entre le camembert et le deuxième graphique en plaçant les points de données dont la valeur est inférieure à Split Position dans le deuxième graphique. |

---

### Par défaut {#Default}
Indique que les points de données doivent être divisés en utilisant le mécanisme par défaut pour ce type de graphique.

---

### Personnalisé {#Custom}
Indique que les points de données doivent être divisés entre le camembert et le deuxième graphique selon les valeurs Custom Split.

---

### Par pourcentage {#ByPercentage}
Indique que les points de données doivent être divisés entre le camembert et le deuxième graphique en plaçant les points dont le pourcentage est inférieur à Split Position percent dans le deuxième graphique.

---

### Par position {#ByPos}
Indique que les points de données doivent être divisés entre le camembert et le deuxième graphique en plaçant le dernier Split Position des points de données dans le deuxième graphique.

---

### Par valeur {#ByValue}
Indique que les points de données doivent être divisés entre le camembert et le deuxième graphique en plaçant les points de données dont la valeur est inférieure à Split Position dans le deuxième graphique.
