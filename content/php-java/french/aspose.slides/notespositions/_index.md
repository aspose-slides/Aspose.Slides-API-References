## NotesPositions classe

 Représente la règle pour rendre les notes dans le document exporté
 

## Constantes

| Nom | Valeur | Description |
| --- | --- | --- |
[None](#None) | 0 | Spécifie que les notes ne doivent pas être affichées du tout. |
[BottomFull](#BottomFull) | 1 | Spécifie que les notes doivent être affichées pleinement en utilisant des pages supplémentaires selon les besoins. |
[BottomTruncated](#BottomTruncated) | 2 | Spécifie que les notes doivent être affichées sur une seule page. |


---


### None {#None}
Spécifie que les notes ne doivent pas être affichées du tout.

---

### BottomFull {#BottomFull}
Spécifie que les notes doivent être affichées pleinement en utilisant des pages supplémentaires selon les besoins.

---

### BottomTruncated {#BottomTruncated}
Spécifie que les notes doivent être affichées sur une seule page.
