## VideoPlayerHtmlController classe

 Cette classe permet l'exportation de fichiers vidéo et audio dans un HTML

### VideoPlayerHtmlController {#VideoPlayerHtmlController}

| Nom | Description |
| --- | --- |
| VideoPlayerHtmlController(String, String, String) | Crée une nouvelle instance du contrôleur |

 **Paramètres:**

| Nom | Type | Description |
| --- | --- | --- |
| path | String | Le chemin où les fichiers vidéo et audio seront générés |
| fileName | String | Le nom du fichier HTML |
| baseUri | String | L'URI de base qui sera utilisé pour la génération des liens |

 **Retour:**
VideoPlayerHtmlController
