## BaseHandoutNotesSlideHeaderFooterManager classe

 Représente le gestionnaire qui définit le comportement des espaces réservés, y compris l’espace réservé d’en-tête pour tous les types de diapos de livret et de notes.

### isHeaderVisible {#isHeaderVisible}

| Nom | Description |
| --- | --- |
| isHeaderVisible () | Obtient la valeur indiquant qu’un espace réservé d’en-tête est présent. Lecture booléenne. |

 **Retour:**  
boolean
