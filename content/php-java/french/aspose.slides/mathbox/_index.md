## MathBox classe

Spécifie l'encapsulation logique (emballage) d'un élément mathématique.  
Par exemple, un objet encapsulé peut servir d'émulateur d'opérateur avec ou sans point d'alignement, servir de point de rupture de ligne, ou être groupé de manière à ne pas autoriser les ruptures de ligne à l'intérieur.  
Par exemple, l'opérateur \"==\" doit être encapsulé pour éviter les ruptures de ligne.

### getExplicitBreak {#getExplicitBreak}

| Nom | Description |
| --- | --- |
| getExplicitBreak () | Rupture explicite indique s'il y a un saut de ligne au début de l'objet Box, de sorte que la ligne s'enroule au début de la boîte. Spécifie le numéro de l'opérateur sur la ligne précédente du texte mathématique qui doit être utilisé comme point d'alignement pour la ligne actuelle du texte mathématique. Valeurs possibles : 1..255 Valeur par défaut : 0 (pas de rupture explicite) |

**Renvoie:**
byte

---

### getNoBreak {#getNoBreak}

| Nom | Description |
| --- | --- |
| getNoBreak () | Pas de rupture : cette propriété indique que la boîte est « incassable ». Lorsque vrai, aucune rupture de ligne ne peut se produire à l'intérieur de la boîte. Cela peut être important pour les émulateurs d'opérateurs composés de plusieurs opérateurs binaires. Si cet élément n'est pas spécifié, des ruptures peuvent survenir à l'intérieur de la boîte. Valeur par défaut : true |

**Renvoie:**
boolean

---

### getOperatorEmulator {#getOperatorEmulator}

| Nom | Description |
| --- | --- |
| getOperatorEmulator () | Émulateur d'opérateur. Lorsque vrai, la boîte et son contenu se comportent comme un seul opérateur et héritent des propriétés d'un opérateur. Cela signifie, par exemple, que le caractère peut servir de point de rupture de ligne et peut être aligné avec d'autres opérateurs. Les émulateurs d'opérateur sont souvent utilisés lorsque un ou plusieurs glyphes se combinent pour former un opérateur, comme « == ». Valeur par défaut : false |

**Renvoie:**
boolean
