## PresentationHeaderFooterManager classe

 Représente le gestionnaire qui gère le comportement de tous les espaces réservés aux pieds de page, aux dates et heures ainsi qu'aux numéros de page de la présentation.
 
### setAllDateTimesText {#setAllDateTimesText}

| Nom | Description |
| --- | --- |
| setAllDateTimesText (String) | Définit le texte de tous les espaces réservés aux dates et heures, y compris les diapositives maîtres, les diapositives de disposition, les diapositives, le maître des notes, les diapositives de notes et le maître du document de remise. |

**Paramètres:**

| Nom | Type | Description |
| --- | --- | --- |
| text | String | Texte à définir. |

**Valeur de retour:**
void


---


### setAllDateTimesVisibility {#setAllDateTimesVisibility}

| Nom | Description |
| --- | --- |
| setAllDateTimesVisibility (boolean) | Modifie la visibilité de tous les espaces réservés aux dates et heures, y compris les diapositives maîtres, les diapositives de disposition, les diapositives, le maître des notes, les diapositives de notes et le maître du document de remise. |

**Paramètres:**

| Nom | Type | Description |
| --- | --- | --- |
| isVisible | boolean | true - rend les espaces réservés aux dates et heures visibles, sinon - les masque. |

**Valeur de retour:**
void
