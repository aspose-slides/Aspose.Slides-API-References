## classe Zip64Mode

 Indique quand utiliser les extensions de format ZIP64 pour un fichier OpenXML.
 
 Un fichier OpenXML est une archive ZIP qui a une limite de 4 Go (2^32 octets) sur la taille non compressée d’un fichier, la taille compressée d’un fichier et la taille totale de l’archive, ainsi qu’une limite de 65 535 (2^16-1) fichiers dans l’archive. Les extensions de format ZIP64 augmentent les limites à 2^64.
 

## Constantes

| Nom | Valeur | Description |
| --- | --- | --- |
[Never](#Never) | 0 | N'utilisez pas les extensions de format ZIP64. |
[IfNecessary](#IfNecessary) | 1 | Utilisez les extensions de format ZIP64 si nécessaire. |
[Always](#Always) | 2 | Utilisez toujours les extensions de format ZIP64. |


---


### Never {#Never}
N'utilisez pas les extensions de format ZIP64.

---

### IfNecessary {#IfNecessary}
Utilisez les extensions de format ZIP64 si nécessaire.

---

### Always {#Always}
Utilisez toujours les extensions de format ZIP64.
