## NormalViewRestoredProperties classe

 Spécifie la dimension de la région de diapositive ((largeur lorsqu'un enfant de restoredTop, hauteur lorsqu'un enfant de restoredLeft) de la vue normale, lorsque la région a une taille restaurée variable (ni réduite ni maximisée).

### getAutoAdjust {#getAutoAdjust}

| Name | Description |
| --- | --- |
| getAutoAdjust () | Spécifie si la taille de la région de contenu latéral doit compenser la nouvelle taille lors du redimensionnement de la fenêtre contenant la vue dans l'application Lecture/écriture booléen. |

 **Renvoie :**
boolean


---


### getDimensionSize {#getDimensionSize}

| Name | Description |
| --- | --- |
| getDimensionSize () | Spécifie la taille de la région de diapositive (largeur lorsqu'elle est un enfant de RestoredTop, hauteur lorsqu'elle est un enfant de RestoredLeft). Lecture/écriture float. |

 **Renvoie :**
float

 **Exception**

| Erreur | Condition |
| --- | --- |
| ArgumentOutOfRangeException | Lance une exception lorsque la valeur est inférieure à 0 ou supérieure à 100. |
