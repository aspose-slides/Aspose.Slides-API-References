## classe AlphaFloor

 Représente un effet de plancher Alpha.  
 Les valeurs Alpha (opacité) inférieures à 100 % sont modifiées à zéro.  
 En d’autres termes, tout ce qui est partiellement transparent devient totalement transparent.
