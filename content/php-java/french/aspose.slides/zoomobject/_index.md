## ZoomObject classe

Représente un objet Zoom dans une diapositive.

### getImageType {#getImageType}

| Nom | Description |
| --- | --- |
| getImageType () | Obtient ou définit le type d'image d'un objet zoom. Read/write ZoomImageType. Valeur par défaut : Preview Spécifie si l'objet Zoom utilise l'aperçu de la diapositive ou une image de couverture. |

**Renvoie :**
int


---


### getReturnToParent {#getReturnToParent}

| Nom | Description |
| --- | --- |
| getReturnToParent () | Obtient ou définit le comportement de navigation dans le diaporama. Read/write boolean. Valeur par défaut : false La valeur vraie de la propriété indique le comportement de retour au parent dans le diaporama. |

**Renvoie :**
boolean


---


### getShowBackground {#getShowBackground}

| Nom | Description |
| --- | --- |
| getShowBackground () | Obtient ou définit la valeur qui indique si le Zoom utilisera l'arrière-plan de la diapositive de destination. Read/write boolean. Valeur par défaut : true |

**Renvoie :**
boolean


---


### getTransitionDuration {#getTransitionDuration}

| Nom | Description |
| --- | --- |
| getTransitionDuration () | Obtient ou définit la durée de la transition entre le Zoom et la diapositive. Read/write float. Valeur par défaut : 1.0f Si non spécifié (TransitionDur = 0), il utilisera la transition de la diapositive de destination ainsi que les timings associés à cette transition. |

**Renvoie :**
float
