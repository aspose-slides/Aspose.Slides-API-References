## HeadingPair classe

 Représente une propriété 'Heading pair' du document. 
 Elle indique le nom du groupe des parties du document et le nombre de parties dans le groupe.
 
### getCount {#getCount}

| Nom | Description |
| --- | --- |
| getCount () | Renvoie le nombre de parties dans le groupe. Lecture seule int. |

 **Renvoie :**
int


---


### getName {#getName}

| Nom | Description |
| --- | --- |
| getName () | Renvoie le nom du groupe des parties du document. Lecture seule String. |

 **Renvoie :**
String
