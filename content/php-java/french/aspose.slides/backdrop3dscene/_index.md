## classe Backdrop3DScene

 Définit un plan dans lequel des effets, tels que la lueur et l'ombre, sont appliqués par rapport à la forme à laquelle ils sont appliqués.
 
### getAnchorPoint {#getAnchorPoint}

| Nom | Description |
| --- | --- |
| getAnchorPoint () | Renvoie ou définit un point dans l'espace 3D. Ce point est le point dans l'espace qui ancre le plan de fond. Point 3D représenté par un tableau de 3 valeurs float qui définissent les coordonnées X, Y et Z. Lecture/écriture float[]. |

 **Retour :**
float


---


### getNormalVector {#getNormalVector}

| Nom | Description |
| --- | --- |
| getNormalVector () | Renvoie ou définit un vecteur normal. Plus précisément, cet attribut définit un vecteur perpendiculaire à la face du plan de fond. Vecteur représenté par un tableau de 3 valeurs float qui définissent les coordonnées X, Y et Z. Lecture/écriture float[]. |

 **Retour :**
float
