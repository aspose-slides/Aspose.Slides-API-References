## PortionFormat classe

 Cette classe contient les propriétés de formatage des portions de texte. Contrairement à IPortionFormatEffectiveData, toutes les propriétés de cette classe sont modifiables.
 Cette classe est utilisée pour renvoyer et manipuler les propriétés de formatage des portions de texte définies pour la portion particulière. Cela signifie que
 aucune héritage n’est appliquée lors de la récupération des valeurs, ainsi dans la plupart des cas vous obtiendrez des valeurs signifiant "undefined".
 Afin d’obtenir les valeurs des paramètres de formatage effectif incluant l’héritage, vous devez utiliser la méthode PortionFormat#getEffective 
 qui renvoie une instance de IPortionFormatEffectiveData.
