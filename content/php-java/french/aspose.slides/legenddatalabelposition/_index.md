## LegendDataLabelPosition classe

Détermine la position des étiquettes de données.

## Constantes

| Nom | Valeur | Description |
| --- | --- | --- |
[NotDefined](#NotDefined) | -1 | La position n'est pas définie. |
[Bottom](#Bottom) | 0 | Spécifie que les étiquettes de données doivent être affichées sous le marqueur de données. |
[BestFit](#BestFit) | 1 | Spécifie que les étiquettes de données doivent être affichées à la meilleure position. |
[Center](#Center) | 2 | Spécifie que les étiquettes de données doivent être affichées centrées sur le marqueur de données. |
[InsideBase](#InsideBase) | 3 | Spécifie que les étiquettes de données doivent être affichées à l'intérieur de la base du marqueur de données. |
[InsideEnd](#InsideEnd) | 4 | Spécifie que les étiquettes de données doivent être affichées à l'intérieur de l'extrémité du marqueur de données. |
[Left](#Left) | 5 | Spécifie que les étiquettes de données doivent être affichées à gauche du marqueur de données. |
[OutsideEnd](#OutsideEnd) | 6 | Spécifie que les étiquettes de données doivent être affichées à l'extérieur de l'extrémité du marqueur de données. |
[Right](#Right) | 7 | Spécifie que les étiquettes de données doivent être affichées à droite du marqueur de données. |
[Top](#Top) | 8 | Spécifie que les étiquettes de données doivent être affichées au-dessus du marqueur de données. |
