## TextInheritanceLimit classe

 Contrôle la profondeur de l'héritage des propriétés de texte.
 

## Constantes

| Nom | Valeur | Description |
| --- | --- | --- |
[All](#All) | 0 | Hériter de toutes les propriétés de texte. |
[TextBox](#TextBox) | 1 | Hériter uniquement du style de TextFrame. |
[ParagraphOnly](#ParagraphOnly) | 2 | Utiliser uniquement les propriétés définies pour le paragraphe. |


---


### All {#All}
Hériter de toutes les propriétés de texte.

---

### TextBox {#TextBox}
Hériter uniquement du style de TextFrame.

---

### ParagraphOnly {#ParagraphOnly}
Utiliser uniquement les propriétés définies pour le paragraphe.
