## LayoutPlaceholderManager classe

 Représente le gestionnaire qui permet d’ajouter des espaces réservés à la diapositive de mise en page.
 
### addChartPlaceholder {#addChartPlaceholder}

| Nom | Description |
| --- | --- |
| addChartPlaceholder (float, float, float, float) | Ajoute une nouvelle forme d'espace réservé à la diapositive de mise en page pour contenir un graphique. |

 **Paramètres:**

| Nom | Type | Description |
| --- | --- | --- |
| x | float | La coordonnée X de la nouvelle forme d'espace réservé. |
| y | float | La coordonnée Y de la nouvelle forme d'espace réservé. |
| width | float | La largeur de la nouvelle forme d'espace réservé. |
| height | float | La hauteur de la nouvelle forme d'espace réservé. |

 **Retour:**
[AutoShape](../autoshape)
