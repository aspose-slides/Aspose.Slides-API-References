## TagCollection classe

 Représente la collection d'étiquettes (paires de chaînes définies par l'utilisateur)

### add {#add}

| Nom | Description |
| --- | --- |
| add (String, String) | Ajoute une nouvelle étiquette à la collection. |

 **Paramètres :**

| Nom | Type | Description |
| --- | --- | --- |
| name | String | Le nom de l'étiquette. |
| value | String | La valeur de l'étiquette. |

int
