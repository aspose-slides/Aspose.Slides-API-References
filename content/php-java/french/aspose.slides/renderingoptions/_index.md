## RenderingOptions classe

### getDisableFontLigatures {#getDisableFontLigatures}

| Nom | Description |
| --- | --- |
| getDisableFontLigatures () | Obtient ou définit une valeur indiquant si le texte est rendu sans utiliser de ligatures. Lorsqu'elle est définie sur true, les ligatures seront désactivées dans la sortie rendue. Par défaut, cette propriété est définie sur false. |

**Renvoie :**
boolean
