## Classe Input

 Représente une collection d'éléments d'entrée (templates).
 
### addTemplate {#addTemplate}

| Nom | Description |
| --- | --- |
| addTemplate (String, String) | Ajoute un modèle à la collection. |

 **Paramètres:**

| Nom | Type | Description |
| --- | --- | --- |
| key | String | Clé du modèle dans la collection. |
| path | String | Chemin vers le fichier de modèle. |

 **Retour:**
void
