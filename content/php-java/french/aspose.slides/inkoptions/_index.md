## InkOptions classe

 Fournit des options qui contrôlent l'apparence des objets Ink dans le document exporté.

### getHideInk {#getHideInk}

| Nom | Description |
| --- | --- |
| getHideInk () | Affiche ou masque les éléments Ink dans le document exporté. La valeur par défaut est false. |

 **Renvoie:**
boolean

---


### getInterpretMaskOpAsOpacity {#getInterpretMaskOpAsOpacity}

| Nom | Description |
| --- | --- |
| getInterpretMaskOpAsOpacity () | Utilise l'opération ROP ou l'Opacité pour le rendu du pinceau. La valeur par défaut est true. |

 **Renvoie:**
boolean
