### copyTo {#copyTo}

| Name | Description |
| --- | --- |
| copyTo (com.aspose.slides.IBehavior[], int) | Copie les éléments de l'IGenericCollection dans un Array, en commençant à un index d'Array particulier. |

 **Paramètres:**

| Name | Type | Description |
| --- | --- | --- |
| array | com.aspose.slides.IBehavior[] | Le tableau unidimensionnel qui est la destination des éléments copiés depuis l'IGenericCollection. Le tableau doit avoir un index basé sur zéro. |
| arrayIndex | int | L'index basé sur zéro dans le tableau à partir duquel la copie commence. |

 **Renvoie:**
void

 **Exception**

| Erreur | Condition |
| --- | --- |
 | com.aspose.ms.System.ArgumentException | Le nombre d'éléments dans la source IGenericCollection est supérieur à l'espace disponible depuis arrayIndex jusqu'à la fin du tableau de destination. |
