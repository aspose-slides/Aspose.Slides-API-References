## AlphaReplace classe

 Représente un effet Alpha Replace.  
 Les valeurs d'alpha (opacité) de l'effet sont remplacées par un alpha fixe.

| Nom | Description |

| equals (Object) | Détermine si l'AlphaReplace spécifié est égal à l'AlphaReplace actuel. |

 **Paramètres:**

| Nom | Type | Description |
| --- | --- | --- |
| obj | Object | L'AlphaReplace à comparer. |

 **Retour:**
boolean
