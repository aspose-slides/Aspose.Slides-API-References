## classe PptxOptions

 Représente les options pour l'enregistrement des présentations OpenXml (PPTX, PPSX, POTX, PPTM, PPSM, POTM).
 
### PptxOptions {#PptxOptions}

| Nom | Description |
| --- | --- |
| PptxOptions() | Crée une nouvelle instance de PptxOptions |

 **Retour :**
PptxOptions


---


### getCompressionLevel {#getCompressionLevel}

| Nom | Description |
| --- | --- |
| getCompressionLevel () | Spécifie le niveau de compression utilisé lors de l'enregistrement du document de présentation. La valeur par défaut est CompressionLevel#Level6. Des niveaux de compression plus élevés produisent des fichiers plus petits mais nécessitent plus de temps de traitement. Le taux de compression réel dépend du contenu de la présentation. |

 **Retour :**
int


---


### getConformance {#getConformance}

| Nom | Description |
| --- | --- |
| getConformance () | Spécifie la classe de conformité à laquelle le document Presentation se conforme. La valeur par défaut est Conformance#Ecma376_2006 |

 **Retour :**
int


---


### getRefreshThumbnail {#getRefreshThumbnail}

| Nom | Description |
| --- | --- |
| getRefreshThumbnail () | Spécifie si la vignette de la présentation sera actualisée. Booléen lecture/écriture. Valeur par défaut est true. Lorsque la valeur de l'option est true, la nouvelle vignette sera générée. Lorsque la valeur de l'option est false, la vignette actuelle sera enregistrée telle quelle. |

 **Retour :**
boolean


---

| --- | --- |

 **Retour :**
int
