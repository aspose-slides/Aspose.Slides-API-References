## SlideShowType classe

  Paramètres de base du diaporama. Les ancêtres représentent les types du diaporama:
   PresentedBySpeaker Présenté par un présentateur (plein écran)
   BrowsedByIndividual Parcouru par un individu (fenêtre)
   BrowsedAtKiosk Parcouru sur un kiosque (plein écran)
