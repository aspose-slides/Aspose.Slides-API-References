## TextExtractionArrangingMode classe

 Représente le mode à utiliser lors de l'extraction de texte
 

## Constantes

| Nom | Valeur | Description |
| --- | --- | --- |
[Unarranged](#Unarranged) | 0 | Le texte brut sans tenir compte de la position sur la diapositive |
[Arranged](#Arranged) | 1 | Le texte est positionné dans le même ordre que sur la diapositive |


---


### Unarranged {#Unarranged}
Le texte brut sans tenir compte de la position sur la diapositive

---

### Arranged {#Arranged}
Le texte est positionné dans le même ordre que sur la diapositive
