## DisplayBlanksAsType classe

 Détermine comment les données manquantes seront affichées.
 

## Constantes

| Nom | Valeur | Description |
| --- | --- | --- |
[Gap](#Gap) | 0 | Spécifie que les valeurs vides seront laissées comme un espace. |
[Span](#Span) | 1 | Spécifie que les valeurs vides seront étirées avec une ligne. |
[Zero](#Zero) | 2 | Spécifie que les valeurs vides seront traitées comme zéro. |
