## AxisAggregationType classe

 Représente le type d'agrégation de l'axe des catégories. Utilisé uniquement avec les séries Histogram ou HistogramPareto.
 

## Constantes

| Nom | Valeur | Description |
| --- | --- | --- |
[ByCategory](#ByCategory) | 0 | Agrège par catégories |
[Automatic](#Automatic) | 1 | Agrège les catégories automatiquement. |
[ByBinWidth](#ByBinWidth) | 2 | Agrège les catégories par largeur de bin. La propriété IAxis.BinWidth doit être définie. |
[ByNumberOfBins](#ByNumberOfBins) | 3 | Agrège les catégories par nombre de bins. La propriété IAxis.NumberOfBins doit être définie. |
