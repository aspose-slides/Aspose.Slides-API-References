## ErrorBarsCustomValues classe

 Spécifie les valeurs des barres d'erreur. Elle doit être utilisée uniquement lorsque le type de valeur des barres d'erreur est Custom.

### getXMinus {#getXMinus}

| Nom | Description |
| --- | --- |
| getXMinus () | Spécifie la valeur de la barre d'erreur dans la direction négative. Disponible si le type de valeur des barres d'erreur est Custom et que ErrorBarsXFormat est autorisé. Dans tout autre cas, cette propriété renvoie null. Lecture seule IDoubleChartValue. |

 **Renvoie:**
[DoubleChartValue](../doublechartvalue)
