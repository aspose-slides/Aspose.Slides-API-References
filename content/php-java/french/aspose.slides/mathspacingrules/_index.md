## MathSpacingRules classe

 Types d'écart (espacement horizontal) entre les colonnes d'une matrice
 

## Constantes

| Nom | Valeur | Description |
| --- | --- | --- |
[SingleSpacingGap](#SingleSpacingGap) | 0 | Simple (1 em pour les colonnes ou 1 ligne pour les lignes) |
[OneAndHalfSpacingGap](#OneAndHalfSpacingGap) | 1 | Un et demi (1,5 em pour les colonnes ou 1,5 lignes pour les lignes) |
[DoubleSpacingGap](#DoubleSpacingGap) | 2 | Espacement double (2 em pour les colonnes ou 2 lignes pour les lignes) |
[Exactly](#Exactly) | 3 | Valeur exacte Pour les colonnes, se base sur la valeur de ColumnGap, mesurée en twips Pour les lignes, se base sur la valeur de RowGap, mesurée en twips |
[Multiple](#Multiple) | 4 | Multiple Pour les colonnes, se base sur la valeur de ColumnGap, mesurée par incréments de 0,5 em Pour les lignes, se base sur la valeur de RowGap, mesurée en lignes |


---


### SingleSpacingGap {#SingleSpacingGap}
Simple (1 em pour les colonnes ou 1 ligne pour les lignes)

---

### OneAndHalfSpacingGap {#OneAndHalfSpacingGap}
Un et demi (1,5 em pour les colonnes ou 1,5 lignes pour les lignes)

---

### DoubleSpacingGap {#DoubleSpacingGap}
Espacement double (2 em pour les colonnes ou 2 lignes pour les lignes)

---

### Exactly {#Exactly}
Valeur exacte Pour les colonnes, se base sur la valeur de ColumnGap, mesurée en twips Pour les lignes, se base sur la valeur de RowGap, mesurée en twips

---

### Multiple {#Multiple}
Multiple Pour les colonies, se base sur la valeur de ColumnGap, mesurée par incréments de 0,5 em Pour les lignes, se base sur la valeur de RowGap, mesurée en lignes
