### getRootDirectoryClsid {#getRootDirectoryClsid}

| Nom | Description |
| --- | --- |
| getRootDirectoryClsid () | Représente le GUID (CLSID) de la classe d'objet qui est stocké dans l'entrée du répertoire racine. Peut être utilisé pour l'activation COM de l'application du document. La valeur par défaut est '64818D11-4F9B-11CF-86EA-00AA00B929E8' qui correspond à 'Microsoft Powerpoint.Slide.8'. |
