## classe FillType

Spécifie le type de remplissage intérieur de divers objets visuels.

## Constantes

| Nom | Valeur | Description |
| --- | --- | --- |
[NotDefined](#NotDefined) | -1 | Le type de remplissage n'est pas défini. |
[NoFill](#NoFill) | 0 | Aucun remplissage appliqué. |
[Solid](#Solid) | 1 | Rempli avec une couleur unie. |
[Gradient](#Gradient) | 2 | Le remplissage est un dégradé. |
[Pattern](#Pattern) | 3 | Un motif répété est utilisé pour remplir l'objet. |
[Picture](#Picture) | 4 | Une image unique est utilisée pour remplir l'objet. |
[Group](#Group) | 5 | L'objet visuel hérite des propriétés de remplissage du groupe. |
