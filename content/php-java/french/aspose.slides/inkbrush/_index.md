### getInkEffect {#getInkEffect}

| Nom | Description |
| --- | --- |
| getInkEffect () | Obtient le type d'effet d'encre (par ex., Galaxy, Gold, Silver) qui définit le style visuel du trait d'encre. La valeur est analysée à partir de la propriété du pinceau "inkEffects". Si aucun effet reconnu n'est spécifié, InkEffectType#NotDefined est renvoyé. |

**Renvoie:**
int
