## HandoutLayoutingOptions classe

 Représente le mode de mise en page de la présentation du document de support pour l'exportation.

| Nom | Description |
| --- | --- |
| HandoutLayoutingOptions() | Initialise les valeurs par défaut. |

 **Retourne:**
HandoutLayoutingOptions

| Nom | Description |
