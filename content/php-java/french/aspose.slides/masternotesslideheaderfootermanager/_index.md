## MasterNotesSlideHeaderFooterManager classe

Représente le gestionnaire qui contient le comportement du pied de page de la diapositive maîtresse des notes, des espaces réservés de date-heure, de numéro de page et de tous les espaces réservés enfants.  
Les espaces réservés enfants désignent des espaces réservés contenus sur les diapositives de notes dépendantes.  
Les diapositives de notes dépendantes utilisent et dépendent de la diapositive maîtresse des notes.

### setDateTimeAndChildDateTimesText {#setDateTimeAndChildDateTimesText}

| Nom | Description |
| --- | --- |
| setDateTimeAndChildDateTimesText (String) | Définit le texte du espace réservé de date-heure de la diapositive maîtresse et de tous les espaces réservés de date-heure enfants. Les espaces réservés enfants désignent des espaces réservés contenus sur les diapositives de notes dépendantes. Les diapositives de notes dépendantes utilisent et dépendent de la diapositive maîtresse des notes. |

**Paramètres:**

| Nom | Type | Description |
| --- | --- | --- |
| text | String | Texte à définir. |

**Retour:**
void
