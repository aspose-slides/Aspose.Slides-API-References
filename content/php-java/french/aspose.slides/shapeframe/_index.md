## ShapeFrame classe

Représente les propriétés du cadre de forme.

### ShapeFrame {#ShapeFrame}

| Nom | Description |
| --- | --- |
| ShapeFrame(float, float, float, float, byte, byte, float) | Crée les propriétés d'un nouveau cadre de forme. |

**Paramètres:**

| Nom | Type | Description |
| --- | --- | --- |
| x | float | Coordonnée X d'un cadre. |
| y | float | Coordonnée Y d'un cadre. |
| width | float | Largeur d'un cadre. |
| height | float | Hauteur d'un cadre. |
| flipH | byte | Vrai si un cadre est retourné horizontalement. |
| flipV | byte | Vrai si un cadre est retourné verticalement. |
| rotationAngle | float | Nombre de degrés de rotation du cadre. |

**Renvoie:**
ShapeFrame
