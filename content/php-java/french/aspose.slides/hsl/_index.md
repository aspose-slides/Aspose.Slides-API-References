## HSL classe

 Représente un effet de Teinte/Saturation/Luminosité.
 La teinte, la saturation et la luminosité peuvent chacune être ajustées par rapport à leur valeur actuelle.
 
### equals {#equals}

| Nom | Description |
| --- | --- |
| equals (Object) | Détermine si le HSL spécifié est égal au HSL actuel. |

 **Paramètres :**

| Nom | Type | Description |
| --- | --- | --- |
| obj | Object | Le HSL à comparer. |

 **Retour :**
boolean
