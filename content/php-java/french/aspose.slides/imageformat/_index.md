## ImageFormat classe

 Représente le format du fichier image.
 

## Constantes

| Nom | Valeur | Description |
| --- | --- | --- |
[MemoryBmp](#MemoryBmp) | 0 | Représente le format d'un bitmap en mémoire. |
[Bmp](#Bmp) | 1 | Représente le format d'image bitmap (BMP). |
[Emf](#Emf) | 2 | Représente le format d'image métafile amélioré (EMF). |
[Wmf](#Wmf) | 3 | Représente le format d'image métafile Windows (WMF). |
[Gif](#Gif) | 4 | Représente le format d'image Graphics Interchange Format (GIF). |
[Jpeg](#Jpeg) | 5 | Représente le format d'image Joint Photographic Experts Group (JPEG). |
[Png](#Png) | 6 | Représente le format d'image W3C Portable Network Graphics (PNG). |
[Tiff](#Tiff) | 7 | Représente le format d'image Tagged Image File Format (TIFF). |
[Exif](#Exif) | 8 | Représente le format Exchangeable Image File (Exif). |
[Icon](#Icon) | 9 | Représente le format d'image icône Windows. |
