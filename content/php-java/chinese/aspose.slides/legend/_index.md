## Legend 类

表示 chart 的图例属性。

### getActualHeight {#getActualHeight}

| Name | Description |
| --- | --- |
| getActualHeight () | 指定 chart 元素的实际高度。调用方法 IChart.validateChartLayout() 以获取实际值。读取 float。 |

**返回:**  
float
