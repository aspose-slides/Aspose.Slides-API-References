## MathPhantom 类

 表示一个幻影数学对象 (&lt;m:phant&gt;)，它会影响其子元素的布局，但不一定显示它。幻影可以隐藏其基表达式，同时保留宽度、高度或深度，以对齐公式或保留空间。可见性和几何行为由属性如 Show、ZeroWid、ZeroAsc、ZeroDesc 和 Transp 控制。

### getShow {#getShow}

| 名称 | 描述 |
| --- | --- |
| getShow () | 获取或设置一个值，指示是否显示基础元素。当为 false 时，基础元素被隐藏但仍可能占用空间，取决于其他 phantom 设置。对应 OMML 属性 m:show。 |

**返回值:**
boolean


---

### getTransp {#getTransp}

| 名称 | 描述 |
| --- | --- |
| getTransp () | 获取或设置一个值，指示 phantom 对基于类的间距规则是否透明。当为 true 时，phantom 内的运算符和符号仍会影响其周围的数学间距（如同可见）。当为 false 时，基于类的间距被忽略。对应 OMML 属性 m:transp。 |

**返回值:**
boolean


---

### getZeroAsc {#getZeroAsc}

| 名称 | 描述 |
| --- | --- |
| getZeroAsc () | 获取或设置一个值，指示是否将基础元素的上升高度（基线以上的高度）视为零。当为 true 时，phantom 不会提升周围数学行的基线。对应 OMML 属性 m:zeroAsc。 |

**返回值:**
boolean


---

### getZeroDesc {#getZeroDesc}

| 名称 | 描述 |
| --- | --- |
| getZeroDesc () | 获取或设置一个值，指示是否将基础元素的下降深度（基线以下的深度）视为零。当为 true 时，phantom 不会降低周围数学行的基线。对应 OMML 属性 m:zeroDesc。 |

**返回值:**
boolean


---

### getZeroWidth {#getZeroWidth}
