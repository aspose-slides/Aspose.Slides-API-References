## NotesSlide 类

| 名称 | 描述 |
| --- | --- |
| getHeaderFooterManager () | 返回备注幻灯片的 HeaderFooter 管理器。只读 INotesSlideHeaderFooterManager。 |

**返回：**
[NotesSlideHeaderFooterManager](../notesslideheaderfootermanager)

[TextFrame](../textframe)
