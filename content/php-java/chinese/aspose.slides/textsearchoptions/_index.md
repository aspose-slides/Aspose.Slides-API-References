## TextSearchOptions 类

 表示可用于在 Presentation、Slide 或 TextFrame 中搜索文本的选项。
 
### TextSearchOptions {#TextSearchOptions}

| 名称 | 描述 |
| --- | --- |
| TextSearchOptions() | 创建新的默认文本搜索选项。 |

 **返回：**
TextSearchOptions


---


### getCaseSensitive {#getCaseSensitive}

| 名称 | 描述 |
| --- | --- |
| getCaseSensitive () | 将 true 设置为使用区分大小写的搜索，false 则相反。可读写布尔值。 |

 **返回：**
boolean


---


### getIncludeNotes {#getIncludeNotes}

| 名称 | 描述 |
| --- | --- |
| getIncludeNotes () | 将 true 设置为在执行文本搜索、替换或高亮操作时包含幻灯片备注 ( NotesSlide) 中的文本。默认值为 false。 |

 **返回：**
boolean


---

 **返回：**
boolean
