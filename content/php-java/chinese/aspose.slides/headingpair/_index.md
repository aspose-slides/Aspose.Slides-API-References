## HeadingPair 类

 表示文档的 “Heading pair” 属性。 
 它指示文档部件的组名以及组中部件的数量。
 
### getCount {#getCount}

| 名称 | 描述 |
| --- | --- |
| getCount () | 返回组中部件的数量。只读 int。 |

 **返回：**
int


---


### getName {#getName}

| 名称 | 描述 |
| --- | --- |
| getName () | 返回文档部件的组名。只读 String。 |

 **返回：**
String
