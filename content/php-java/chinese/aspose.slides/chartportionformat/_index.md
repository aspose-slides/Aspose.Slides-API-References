## ChartPortionFormat 类

此类包含用于图表的图表部分格式属性。不同于 IPortionFormatEffectiveData，此类的所有属性都是可写的。

此类用于返回和操作为特定部分定义的文本部分格式属性。这意味着在获取值时不应用继承，因此在大多数情况下您将得到表示“未定义”的值。为了获取包括继承在内的有效格式参数值，需要使用 PortionFormat#getEffective 方法，该方法返回一个 IPortionFormatEffectiveData 实例。
