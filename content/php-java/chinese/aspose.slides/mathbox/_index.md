## MathBox 类

指定数学元素的逻辑盒装（包装）。
例如，盒装对象可以作为带对齐点或不带对齐点的运算符仿真器，充当换行点，或被分组以防止其内部出现换行。
例如，"==" 运算符应被盒装以防止换行。
