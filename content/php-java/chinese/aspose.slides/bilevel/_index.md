## BiLevel 类

 表示一种 Bi-Level（黑/白）效果。  
 输入颜色的亮度低于指定阈值时会被更改为黑色。  
 输入颜色的亮度大于或等于指定阈值时会被设置为白色。  
 该效果不会影响 alpha 效果值。
