## LayoutSlideHeaderFooterManager 类

 表示管理器，负责布局幻灯片的页脚、日期时间、页码占位符以及所有子占位符的行为。子占位符指的是包含在依赖幻灯片上的占位符。依赖幻灯片使用并依赖于布局幻灯片。

### setDateTimeAndChildDateTimesText {#setDateTimeAndChildDateTimesText}

| 名称 | 描述 |
| --- | --- |
| setDateTimeAndChildDateTimesText (String) | 将文本设置到布局幻灯片的日期时间占位符以及所有子日期时间占位符。子占位符指的是包含在依赖幻灯片上的占位符。依赖幻灯片使用并依赖于布局幻灯片。 |

 **参数:**

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| text | String | 要设置的文本。 |

 **返回值:**
void
