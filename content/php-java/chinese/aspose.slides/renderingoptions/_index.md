## RenderingOptions class

 提供用于控制演示文稿/幻灯片渲染方式的选项。

| 名称 | 描述 |
| --- | --- |
| RenderingOptions() | 默认函数。 |

 **返回值:**
RenderingOptions

### getDisableFontLigatures {#getDisableFontLigatures}

| 名称 | 描述 |
| --- | --- |
| getDisableFontLigatures () | 获取或设置一个值，指示文本是否在渲染时不使用连字。设置为 true 时，渲染输出中将禁用连字。默认情况下，此属性设置为 false。 |

 **返回值:**
boolean
