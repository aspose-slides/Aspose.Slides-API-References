## Backdrop3DScene 类

 定义一个平面，在该平面上相对于被应用的形状施加诸如辉光和阴影等效果。

### getAnchorPoint {#getAnchorPoint}

| 名称 | 描述 |
| --- | --- |
| getAnchorPoint () | 返回或设置 3D 空间中的一点。该点是锚定背景平面的空间点。3D 点由包含 X、Y 和 Z 坐标的 3 个 float 值的数组表示。读/写 float[]. |

 **返回值:**
float


---


### getNormalVector {#getNormalVector}

| 名称 | 描述 |
| --- | --- |
| getNormalVector () | 返回或设置法向量。更确切地说，该属性定义了与背景平面面相垂直的向量。向量由包含 X、Y 和 Z 坐标的 3 个 float 值的数组表示。读/写 float[]. |

 **返回值:**
float


---

float
