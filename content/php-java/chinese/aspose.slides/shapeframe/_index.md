## ShapeFrame 类

 表示形状框架的属性。
 
### ShapeFrame {#ShapeFrame}

| 名称 | 描述 |
| --- | --- |
| ShapeFrame(float, float, float, float, byte, byte, float) | 创建新的形状框架属性。 |

 **参数:**

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| x | float | 框架的 X 坐标。 |
| y | float | 框架的 Y 坐标。 |
| width | float | 框架的宽度。 |
| height | float | 框架的高度。 |
| flipH | byte | 如果框架水平翻转则为 True。 |
| flipV | byte | 如果框架垂直翻转则为 True。 |
| rotationAngle | float | 框架旋转的度数。 |

 **返回:**
ShapeFrame
