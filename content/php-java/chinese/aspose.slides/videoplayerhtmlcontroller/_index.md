## VideoPlayerHtmlController 类

此类允许将视频和音频文件导出为 HTML

### VideoPlayerHtmlController {#VideoPlayerHtmlController}

| 名称 | 描述 |
| --- | --- |
| VideoPlayerHtmlController(String, String, String) | Creates a new instance of controller |

**参数：**

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| path | String | 生成视频和音频文件的路径 |
| fileName | String | HTML 文件的名称 |
| baseUri | String | 用于生成链接的基础 URI |

**返回值：**
VideoPlayerHtmlController
