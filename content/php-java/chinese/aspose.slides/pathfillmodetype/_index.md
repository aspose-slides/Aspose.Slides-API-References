## PathFillModeType 类

指定路径的填充方式

## 常量

| 名称 | 值 | 描述 |
| --- | --- | --- |
| [None](#None) | 0 | 无路径填充，这表示对应的路径不应填充。 |
| [Normal](#Normal) | 1 | 普通路径填充，这表示对应的路径的填充应使用正常阴影颜色。 |
| [Lighten](#Lighten) | 2 | 浅色路径填充，这表示对应的路径的填充应使用浅阴影颜色。 |
| [LightenLess](#LightenLess) | 3 | 浅色路径填充（较少）这表示对应的路径的填充应使用稍微浅一些的阴影颜色。 |
| [Darken](#Darken) | 4 | 深色路径填充，这表示对应的路径的填充应使用更深的阴影颜色。 |
| [DarkenLess](#DarkenLess) | 5 | 深色路径填充（较少）这表示对应的路径的填充应使用稍微深一些的阴影颜色。 |
