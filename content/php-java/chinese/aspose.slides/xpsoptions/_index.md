## XpsOptions 类

 Provides options that control how a presentation is saved in XPS format.

| 名称 | 描述 |
| --- | --- |
| XpsOptions() | 默认函数。 |

 **返回值:**
XpsOptions

### getDrawSlidesFrame {#getDrawSlidesFrame}

| 名称 | 描述 |
| --- | --- |
| getDrawSlidesFrame () | 设置为 True 以在每个幻灯片周围绘制黑色框。可读写 boolean。默认值为 false。 |

 **返回值:**
boolean
