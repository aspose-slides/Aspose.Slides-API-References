## Rotation3D 类

 表示图表的 3D 旋转。

### getDepthPercents {#getDepthPercents}

| 名称 | 描述 |
| --- | --- |
| getDepthPercents () | 返回或设置 3D 图表的深度，作为图表宽度的百分比（介于 20% 到 2000% 之间）。读取/写入 int。 |

 **返回：**
int


---


### getHeightPercents {#getHeightPercents}

| 名称 | 描述 |
| --- | --- |
| getHeightPercents () | 指定 3-D 图表的高度，作为图表宽度的百分比（介于 5% 到 500% 之间）。读取/写入 int。 |

 **返回：**
int


---


### getPerspective {#getPerspective}

| 名称 | 描述 |
| --- | --- |
| getPerspective () | 返回或设置 3D 图表的透视值（视野角度）（介于 0 到 240 之间）。如果 RightAngleAxes 属性值为 true，则忽略。读取/写入 byte。 |

 **返回：**
byte


---


### getRightAngleAxes {#getRightAngleAxes}

| 名称 | 描述 |
| --- | --- |
| getRightAngleAxes () | 确定图表坐标轴是否呈直角，而非以透视方式绘制。换句话说，它确定坐标轴的角度是否独立于图表的旋转或倾斜。读取/写入 boolean。 |

 **返回：**
boolean


---


### getRotationX {#getRotationX}

| 名称 | 描述 |
| --- | --- |
| getRotationX () | 返回或设置绕 X-axis 轴的旋转角度，即 3D 图表的 Y 方向（介于 -90 到 90 度之间）。该属性对应 ECMA-376 中的 21.2.2.157 rotX（X Rotation）项以及 PowerPoint 2007+ 中的 “Y Rotation” 选项。读取/写入 byte。 |

 **返回：**
byte


---


### getRotationY {#getRotationY}

| 名称 | 描述 |
| --- | --- |
| getRotationY () | 返回或设置绕 Y-axis 轴的旋转角度，即 3D 图表的 X 方向（介于 0 到 360 度之间）。该属性对应 ECMA-376 中的 21.2.158 rotY（Y Rotation）项以及 PowerPoint 2007+ 中的 “X Rotation” 选项。读取/写入 int。 |

 **返回：**
int
