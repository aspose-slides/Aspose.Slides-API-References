## MasterNotesSlideHeaderFooterManager 类

 表示管理器，用于维护主备注幻灯片页脚、日期时间、页码占位符以及所有子占位符的行为。  
 子占位符表示这些占位符位于依赖的备注幻灯片上。  
 依赖的备注幻灯片使用并依赖于主备注幻灯片。

### setDateTimeAndChildDateTimesText {#setDateTimeAndChildDateTimesText}

| 名称 | 描述 |
| --- | --- |
| setDateTimeAndChildDateTimesText (String) | 将文本设置到主幻灯片日期时间占位符和所有子日期时间占位符。子占位符表示这些占位符位于依赖的备注幻灯片上。依赖的备注幻灯片使用并依赖于主备注幻灯片。 |

 **参数:**

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| text | String | 要设置的文本。 |

 **返回值:**
void
