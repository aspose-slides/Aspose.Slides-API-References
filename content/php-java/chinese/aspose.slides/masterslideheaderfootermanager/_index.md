## MasterSlideHeaderFooterManager 类

 表示管理器，负责处理母版幻灯片页脚、日期时间、页码占位符以及所有子占位符的行为。子占位符指的是包含在依赖布局幻灯片和依赖幻灯片中的占位符。依赖布局幻灯片和幻灯片使用并依赖于母版幻灯片。

### setDateTimeAndChildDateTimesText {#setDateTimeAndChildDateTimesText}

| Name | Description |
| --- | --- |
| setDateTimeAndChildDateTimesText (String) | 将文本设置到母版幻灯片日期时间占位符以及所有子日期时间占位符。子占位符指的是包含在依赖布局幻灯片和依赖幻灯片中的占位符。依赖布局幻灯片和幻灯片使用并依赖于母版幻灯片。 |

**参数:**

| Name | Type | Description |
| --- | --- | --- |
| text | String | 要设置的文本。 |

**返回:**
void
