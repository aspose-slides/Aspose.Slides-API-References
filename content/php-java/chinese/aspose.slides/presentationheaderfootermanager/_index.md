## PresentationHeaderFooterManager 类

 Represents manager which holds behavior of all footer, date-time and page number placeholders of presentation.
 
### setAllDateTimesText {#setAllDateTimesText}

| 名称 | 描述 |
| --- | --- |
| setAllDateTimesText (String) | 为所有日期时间占位符设置文本，包括母版幻灯片、布局幻灯片、普通幻灯片、备注母版、备注幻灯片和讲义母版。 |

 **参数:**

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| text | String | 要设置的文本。 |

 **返回值:**
void
