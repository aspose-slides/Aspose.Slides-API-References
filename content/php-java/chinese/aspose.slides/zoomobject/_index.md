## ZoomObject 类

 表示幻灯片中的 Zoom 对象。
 
### getImageType {#getImageType}

| Name | Description |
| --- | --- |
| getImageType () | 获取或设置缩放对象的图像类型。读/写 ZoomImageType。默认值：Preview 指定 Zoom 对象是使用幻灯片预览还是封面图像。 |

 **返回:**  
int


---


### getReturnToParent {#getReturnToParent}

| Name | Description |
| --- | --- |
| getReturnToParent () | 获取或设置幻灯片放映中的导航行为。读/写 boolean。默认值：false 布尔属性为 true 时表示在幻灯片放映中返回父级的导航行为。 |

 **返回:**  
boolean


---


### getShowBackground {#getShowBackground}

| Name | Description |
| --- | --- |
| getShowBackground () | 获取或设置指定 Zoom 是否使用目标幻灯片背景的值。读/写 boolean。默认值：true |

 **返回:**  
boolean


---


### getTransitionDuration {#getTransitionDuration}

| Name | Description |
| --- | --- |
| getTransitionDuration () | 获取或设置 Zoom 与幻灯片之间转换的持续时间。读/写 float。默认值：1.0f 如果未指定 (TransitionDur = 0)，将使用目标幻灯片的转换以及该转换关联的时间。 |

 **返回:**  
float


---
