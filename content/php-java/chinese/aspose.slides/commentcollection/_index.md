## CommentCollection 类

 表示单个作者的评论集合。
 
### addComment {#addComment}

| 名称 | 描述 |
| --- | --- |
| addComment (String, [Slide](../slide), Point2D.Float, Date) | 在集合末尾添加新评论。 |

 **参数：**

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| text | String | 新评论的纯文本。 |
| slide | [Slide](../slide) | 要在其上添加新评论的演示文稿幻灯片。 |
| position | Point2D.Float | 在幻灯片上添加新评论的位置。 |
| creationTime | Date | 评论创建的时间。 |

 **返回：**
[Comment](../comment), [ModernComment](../moderncomment)
