## HyperlinkQueries 类

提供对包含的超链接的简易访问。

### getAnyHyperlinks {#getAnyHyperlinks}

| Name | Description |
| --- | --- |
| getAnyHyperlinks () | 获取所有包含非空 HyperlinkMouseOver 的 IHyperlinkContainer 子对象。使用给定的 IHyperlinkContainer 对象可以管理其超链接（读取、更新或删除）。参见 IHyperlinkContainer 接口。 |

**返回:**
[BehaviorPropertyCollection](../behaviorpropertycollection), KeyedCollection, Collection, ReadOnlyCollection, List


---

### removeAllHyperlinks {#removeAllHyperlinks}

| Name | Description |
| --- | --- |
| removeAllHyperlinks () | 移除所有包含的 HyperlinkClick 和 HyperlinkMouseOver 超链接（在所有 IHyperlinkContainer 子对象中）。 |

**返回:**
void
