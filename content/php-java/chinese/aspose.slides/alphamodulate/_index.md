## AlphaModulate 类

 表示一个 Alpha Modulate 效果。  
 Effect alpha (opacity) values are multiplied by a fixed percentage. => 效果的 alpha（不透明度）值会乘以固定的百分比。  
 The effect container specifies an effect containing alpha values to modulate. => 效果容器指定一个包含要调制的 alpha 值的效果。
