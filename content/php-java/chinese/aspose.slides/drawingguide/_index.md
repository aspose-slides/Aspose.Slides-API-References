### getPosition {#getPosition}

| 名称 | 描述 |
| --- | --- |
| getPosition () | 返回或设置绘图参考线的位置（以点为单位），相对于幻灯片左上角的距离。读取/写入 float。典型的取值范围是从零到幻灯片高度（水平参考线）或从零到幻灯片宽度（垂直参考线）。 |
