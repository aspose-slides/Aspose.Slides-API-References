## Merger 类

 表示一组用于将相同格式的 PowerPoint 演示文稿合并为一个文件的方法。

### process {#process}

| 名称 | 描述 |
| --- | --- |
| process (java.lang.String[], String) | 将多个相同格式的 PowerPoint 演示文稿合并为单个演示文稿文件。 |

**参数:**

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| inputFileNames | java.lang.String[] | 输入演示文稿文件名的数组。 |
| outputFileName | String | 合并后生成的演示文稿文件的输出文件名。 |

**返回值:**
void

**异常**

| 错误 | 条件 |
| --- | --- |
| ArgumentException | 当输入文件名无效或格式不匹配时抛出。 |
