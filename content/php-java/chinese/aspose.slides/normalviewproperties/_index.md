## NormalViewProperties 类

 表示普通视图属性。普通视图由三个内容区域组成：幻灯片本身、侧边内容区域和底部内容区域。
 
### getHorizontalBarState {#getHorizontalBarState}

| 名称 | 描述 |
| --- | --- |
| getHorizontalBarState () | 指定水平分割条应显示的状态。水平分割条将幻灯片与幻灯片下方的内容区域分隔开。 |

 **返回值：**
int


---


### getPreferSingleView {#getPreferSingleView}

| 名称 | 描述 |
| --- | --- |
| getPreferSingleView () | 指定用户是否倾向于在普通视图的三内容区域标准布局上，看到全窗口的单一内容区域。如果启用，应用程序可能会选择在整个窗口中显示其中一个内容区域。读写 boolean。 |

 **返回值：**
boolean


---


### getRestoredLeft {#getRestoredLeft}

| 名称 | 描述 |
| --- | --- |
| getRestoredLeft () | 当侧边内容区域处于可变的恢复大小（既不是最小化也不是最大化）时，此元素指定普通视图侧边内容区域的大小。只读 INormalViewRestoredProperties。 |

 **返回值：**
[NormalViewRestoredProperties](../normalviewrestoredproperties)
