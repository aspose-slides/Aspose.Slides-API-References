## ErrorBarsCustomValues 类

 指定误差条的值。仅在 Error bars 值类型为 Custom 时使用。

### getXMinus {#getXMinus}

| 名称 | 描述 |
| --- | --- |
| getXMinus () | 指定误差条在负方向的值。仅当 error bars 值类型为 Custom 且允许 ErrorBarsXFormat 时可用。否则此属性返回 null。只读 IDoubleChartValue。 |

 **返回：**
[DoubleChartValue](../doublechartvalue)
