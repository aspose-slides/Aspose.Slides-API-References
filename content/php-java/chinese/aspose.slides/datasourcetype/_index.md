## DataSourceType class

 数据源类型。
 

## 常量

| 名称 | 值 | 描述 |
| --- | --- | --- |
[Worksheet](#Worksheet) | 0 | 使用 CellXls 对象在工作表中存储数据点的 XValue、YValue、Value 或 BubbleSize。 |
[StringLiterals](#StringLiterals) | 1 | 使用快速访问的 string 变量存储数据点的 XValue、YValue、Value 或 BubbleSize。Worksheet 不用于存储值。 |
[DoubleLiterals](#DoubleLiterals) | 2 | 使用快速访问的 double 变量存储数据点的 XValue、YValue、Value 或 BubbleSize。Worksheet 不用于存储值。 |
