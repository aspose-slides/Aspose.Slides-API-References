## ErrorBarValueType 类

 Represents type of error bar value
 

## 常量

| 名称 | 值 | 描述 |
| --- | --- | --- |
[Custom](#Custom) | 0 | 指定误差线的长度应由 Plus 和 Minus 元素确定。 |
[Fixed](#Fixed) | 1 | 指定误差线的长度应为由 Error Bar Value 确定的固定值。 |
[Percentage](#Percentage) | 2 | 指定误差线的长度应为数据的 Error Bar Value 百分比。 |
[StandardDeviation](#StandardDeviation) | 3 | 指定误差线的长度应为数据的 Error Bar Value 标准差。 |
[StandardError](#StandardError) | 4 | 指定误差线的长度应为数据的 Error Bar Value 标准误差。 |
