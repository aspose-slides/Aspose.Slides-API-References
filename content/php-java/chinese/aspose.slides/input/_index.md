### addTemplate {#addTemplate}

| 名称 | 描述 |
| --- | --- |
| addTemplate (String, String) | 将模板添加到集合中。 |

 **参数：**

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| key | String | 集合中模板的键。 |
| path | String | 模板文件的路径。 |

void
