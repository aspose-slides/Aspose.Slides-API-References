## HeadingPair κλάση

Αναπαριστά μια ιδιότητα 'Heading pair' του εγγράφου. 
Υποδεικνύει το όνομα της ομάδας των τμημάτων του εγγράφου και τον αριθμό των μερών στην ομάδα.
 
### getCount {#getCount}

| Όνομα | Περιγραφή |
| --- | --- |
| getCount () | Επιστρέφει τον αριθμό των μερών στην ομάδα. Μόνο για ανάγνωση int. |

 **Επιστρέφει:**
int


---


### getName {#getName}

| Όνομα | Περιγραφή |
| --- | --- |
| getName () | Επιστρέφει το όνομα της ομάδας των τμημάτων του εγγράφου. Μόνο για ανάγνωση String. |

 **Επιστρέφει:**
String
