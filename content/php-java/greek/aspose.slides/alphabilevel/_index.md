## AlphaBiLevel κλάση

Αντιπροσωπεύει ένα εφέ Alpha Bi-Level. Οι τιμές Alpha (Opacity) μικρότερες από το όριο μετατρέπονται σε 0 (πλήρως διαφανείς) και οι τιμές alpha μεγαλύτερες ή ίσες με το όριο μετατρέπονται σε 100 % (πλήρως αδιαφανείς).
