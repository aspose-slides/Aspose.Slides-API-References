## SummaryZoomFrame κλάση

Αντιπροσωπεύει ένα αντικείμενο Summary Zoom σε μια διαφάνεια.

### getLayout {#getLayout}

| Όνομα | Περιγραφή |
| --- | --- |
| getLayout () | Αποκτά τη διάταξη των τμημάτων Summary Zoom στο πλαίσιο. Η προεπιλεγμένη τιμή είναι GridLayout. |

**Επιστρέφει:**  
int
