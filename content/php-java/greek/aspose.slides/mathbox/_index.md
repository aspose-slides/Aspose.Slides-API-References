## MathBox κλάση

Καθορίζει τη λογική συσκευασία (συσκευασία) του μαθηματικού στοιχείου.  
Για παράδειγμα, ένα αντικείμενο σε κουτί μπορεί να λειτουργεί ως προσομιλητής τελεστή με ή χωρίς σημείο ευθυγράμμισης, να λειτουργεί ως σημείο αλλαγής γραμμής ή να ομαδοποιείται ώστε να μην επιτρέπεται αλλαγή γραμμής εντός του.  
Για παράδειγμα, ο τελεστής "==" πρέπει να τοποθετείται σε κουτί ώστε να αποτραπούν οι αλλαγές γραμμής.

### getExplicitBreak {#getExplicitBreak}

| Όνομα | Περιγραφή |

| getExplicitBreak () | Explicit break καθορίζει αν υπάρχει αλλαγή γραμμής στην αρχή του αντικειμένου Box, ώστε η γραμμή να τυλίγεται στην αρχή του κουτιού. ### getNoBreak {#getNoBreak}

| Όνομα | Περιγραφή |
| --- | --- |
| getNoBreak () | No break Αυτή η ιδιότητα προσδιορίζει την ιδιότητα “unbreakable” του κουτιού αντικειμένου. Όταν είναι true, δεν μπορούν να συμβούν αλλαγές γραμμής μέσα στο κουτί. Αυτό μπορεί να είναι σημαντικό για προσομιλητές τελεστή που αποτελούνται από περισσότερους από έναν δυαδικό τελεστή. Όταν αυτό το στοιχείο δεν καθορίζεται, μπορούν να συμβούν αλλαγές μέσα στο κουτί. Προεπιλογή: true |

**Επιστρέφει:**
boolean

### getOperatorEmulator {#getOperatorEmulator}

| Όνομα | Περιγραφή |
| --- | --- |
| getOperatorEmulator () | Operator Emulator. Όταν είναι true, το κουτί και τα περιεχόμενά του συμπεριφέρονται ως ένας ενιαίος τελεστής και κληρονομούν τις ιδιότητες ενός τελεστή. Αυτό σημαίνει, για παράδειγμα, ότι ο χαρακτήρας μπορεί να λειτουργεί ως σημείο αλλαγής γραμμής και να ευθυγραμμίζεται με άλλους τελεστές. Τα Operator Emulators χρησιμοποιούνται συχνά όταν ένας ή περισσότεροι γλύφοι συνδυάζονται για να σχηματίσουν έναν τελεστή, όπως το '=='. Προεπιλογή: false |

**Επιστρέφει:**
boolean
