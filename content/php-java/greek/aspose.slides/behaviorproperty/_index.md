## BehaviorProperty κλάση

Αναπαριστά τύπους ιδιοτήτων για τη συμπεριφορά κίνησης.
Follows the list of properties from https://msdn.microsoft.com/en-us/library/dd949052(v=office.15).aspx
and https://msdn.microsoft.com/en-us/library/documentformat.openxml.presentation.attributename(v=office.15).aspx

### equals {#equals}

| Όνομα | Περιγραφή |
| --- | --- |
| equals (Object) | Ελέγχει εάν αυτό το αντικείμενο είναι ίσο με άλλο. |

**Παράμετροι:**

| Όνομα | Τύπος | Περιγραφή |
| --- | --- | --- |
| obj | Object | Αντικείμενο προς σύγκριση. |

**Επιστρέφει:**
boolean
