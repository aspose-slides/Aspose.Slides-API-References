## ExcelDataCell κλάση

 Αντιπροσωπεύει ένα μοναδικό κελί σε ένα βιβλίο εργασίας Excel.
 
### getColumn {#getColumn}

| Όνομα | Περιγραφή |
| --- | --- |
| getColumn () | Επιστρέφει τον δείκτη βάσει μηδέν της στήλης στο φύλλο εργασίας όπου βρίσκεται το κελί. Μόνο προς ανάγνωση int. |

 **Επιστρέφει:**
int


---


### getName {#getName}

| Όνομα | Περιγραφή |
| --- | --- |
| getName () | Επιστρέφει το όνομα του κελιού δεδομένων του διαγράμματος. |

 **Επιστρέφει:**
String


---


### getRow {#getRow}

| Όνομα | Περιγραφή |
| --- | --- |
| getRow () | Επιστρέφει τον δείκτη βάσει μηδέν της γραμμής στο φύλλο εργασίας όπου βρίσκεται το κελί. Μόνο προς ανάγνωση int. |

 **Επιστρέφει:**
int


---


### getValue {#getValue}

| Όνομα | Περιγραφή |
| --- | --- |
| getValue () | Επιστρέφει την τιμή που περιέχεται στο κελί του Excel. |

 **Επιστρέφει:**
Object
