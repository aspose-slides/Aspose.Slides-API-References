## StringOrDoubleChartValue κλάση

Αναπαριστά τιμή συμβολοσειράς ή αριθμού double που μπορεί να αποθηκευτεί σε έγγραφο παρουσίασης pptx με δύο τρόπους:
1) σε κελί/κελιά του φύλλου εργασίας που σχετίζεται με το διάγραμμα;
2) ως κυριολεκτική τιμή.
