## PresentationHeaderFooterManager κλάση

 Αντιπροσωπεύει τον διαχειριστή που διατηρεί τη συμπεριφορά όλων των στοιχείων κράτησης θέσης υποσέλιδου, ημερομηνίας-ώρας και αριθμού σελίδας της παρουσίασης.
 
### setAllDateTimesText {#setAllDateTimesText}

| Όνομα | Περιγραφή |
| --- | --- |
| setAllDateTimesText (String) | Ορίζει κείμενο σε όλα τα στοιχεία κράτησης θέσης ημερομηνίας-ώρας, συμπεριλαμβανομένων των κύριων διαφανειών, διαφανειών διάταξης, διαφανειών, notes master, notes slides και handout master. |

 **Παράμετροι:**

| Όνομα | Τύπος | Περιγραφή |
| --- | --- | --- |
| text | String | Κείμενο προς ορισμό. |

 **Επιστρέφει:**
void
