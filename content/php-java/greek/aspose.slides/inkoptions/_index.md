## InkOptions κλάση

 Παρέχει επιλογές που ελέγχουν την εμφάνιση των Ink αντικειμένων στο εξαγόμενο έγγραφο.

### getHideInk {#getHideInk}

| Όνομα | Περιγραφή |
| --- | --- |
| getHideInk () | Εμφανίζει ή κρύβει τα στοιχεία Ink στο εξαγόμενο έγγραφο. Η προεπιλεγμένη τιμή είναι false. |

 **Επιστρέφει:**
boolean


---


### getInterpretMaskOpAsOpacity {#getInterpretMaskOpAsOpacity}

| Όνομα | Περιγραφή |
| --- | --- |
| getInterpretMaskOpAsOpacity () | Χρησιμοποιεί λειτουργία ROP ή Διαφάνεια για την απόδοση της βούρτσας. Η προεπιλεγμένη τιμή είναι true. |

 **Επιστρέφει:**
boolean


---

 **Επιστρέφει:**
void
