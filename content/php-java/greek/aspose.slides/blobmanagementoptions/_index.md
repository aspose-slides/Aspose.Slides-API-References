## BlobManagementOptions κλάση

Αντιπροσωπεύει επιλογές που μπορούν να χρησιμοποιηθούν για τη διαχείριση των κανόνων χειρισμού BLOB και άλλων ρυθμίσεων BLOB.

### BlobManagementOptions {#BlobManagementOptions}

| Όνομα | Περιγραφή |
| --- | --- |
| BlobManagementOptions() | Δημιουργεί νέες προεπιλεγμένες επιλογές διαχείρισης blob. |

 **Επιστρέφει:**
BlobManagementOptions

---

### getMaxBlobsBytesInMemory {#getMaxBlobsBytesInMemory}

| Όνομα | Περιγραφή |
| --- | --- |
| getMaxBlobsBytesInMemory () | Ορίζει το μέγιστο συνολικό μέγεθος ( σε bytes ) που μπορούν να καταλαμβάνουν όλα τα BLOB στη μνήμη. Από προεπιλογή, όλα τα BLOB φορτώνονται στη μνήμη· μόνο όταν αυτό το όριο επιτευχθεί χρησιμοποιούνται εναλλακτικοί μηχανισμοί ( όπως προσωρινά αρχεία ). Η διατήρηση των BLOB στη μνήμη μεγιστοποιεί την απόδοση αλλά μπορεί να προκαλέσει υψηλή χρήση μνήμης. Χρησιμοποιήστε αυτήν την ιδιότητα για προσαρμογή της συμπεριφοράς στο περιβάλλον ή τις απαιτήσεις σας. Η ιδιότητα αυτή αγνοείται εάν #isTemporaryFilesAllowed/ #setTemporaryFilesAllowed(boolean) έχει οριστεί σε ψευδές, καθώς η μνήμη είναι τότε η μοναδική διαθεσιμότητα αποθήκευσης και ο περιορισμός της χρήσης BLOB στη μνήμη δεν έχει αποτέλεσμα. Η προεπιλεγμένη τιμή είναι 629 145 600 bytes (600 MB). Μπορείτε να ορίσετε αυτήν την ιδιότητα στο μηδέν, αλλά ένα μικρό ελάχιστο ποσό μνήμης θα παραμείνει δεσμευμένο. |

 **Επιστρέφει:**
long

---

### getPresentationLockingBehavior {#getPresentationLockingBehavior}

| Όνομα | Περιγραφή |
| --- | --- |
| getPresentationLockingBehavior () | Αυτή η ιδιότητα ορίζει εάν μια παρουσία της Presentation κλάση μπορεί να είναι κάτοχος της πηγής – αρχείου ή ροής κατά τη διάρκεια της ζωής της παρουσίασης. Εάν η παρουσία είναι κάτοχος, κλειδώνει την πηγή. Αυτό βοηθά στη βελτίωση της κατανάλωσης μνήμης και της απόδοσης κατά την εργασία με BLOB, αλλά η πηγή (ροή ή αρχείο) δεν μπορεί να αλλάξει κατά τη διάρκεια της Presentation. |

 **Επιστρέφει:**
int

---

### getTempFilesRootPath {#getTempFilesRootPath}

| Όνομα | Περιγραφή |
| --- | --- |
| getTempFilesRootPath () | Η βασική διαδρομή όπου θα δημιουργηθούν προσωρινά αρχεία. Ο προεπιλεγμένος κατάλογος προσωρινών αρχείων του συστήματος θα χρησιμοποιηθεί. Η διαδικασία φιλοξενίας πρέπει να έχει δικαιώματα δημιουργίας αρχείων και φακέλων εκεί. |

 **Επιστρέφει:**
String

---

### isTemporaryFilesAllowed {#isTemporaryFilesAllowed}

| Όνομα | Περιγραφή |
| --- | --- |
| isTemporaryFilesAllowed () | Αυτή η ιδιότητα ορίζει εάν μπορούν να δημιουργηθούν προσωρινά αρχεία κατά την εργασία με BLOB, γεγονός που μειώνει σημαντικά τη χρήση μνήμης αλλά απαιτεί δικαιώματα δημιουργίας αρχείων. Όλα τα αρχεία θα διαγραφούν μετά το τέλος της εργασίας με την παρουσίαση. |

 **Επιστρέφει:**
boolean
