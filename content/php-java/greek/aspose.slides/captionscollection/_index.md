## CaptionsCollection κλάση

Αναπαριστά μια συλλογή των κλειστών υποτίτλων.

### add {#add}

| Όνομα | Περιγραφή |
| --- | --- |
| add (String, String) | Προσθέτει κλειστούς υπότιτλους WebVTT στο τέλος της συλλογής. |

**Παράμετροι:**

| Όνομα | Τύπος | Περιγραφή |
| --- | --- | --- |
| label | String | Η ετικέτα των κλειστών υποτίτλων. |
| filePath | String | Η διαδρομή του αρχείου WebVTT. |

**Επιστρέφει:**
[Captions](../captions)

**Εξαίρεση**

| Σφάλμα | Κατάσταση |
| --- | --- |
| ArgumentException | Εκτοπίζεται εάν το filePath είναι κενό. |
