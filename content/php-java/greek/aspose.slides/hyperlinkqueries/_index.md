## HyperlinkQueries class

Παρέχει εύκολη πρόσβαση στους περιέχοντες υπερσυνδέσμους.

### getAnyHyperlinks {#getAnyHyperlinks}

| Name | Description |
| --- | --- |
| getAnyHyperlinks () | Αποκτά όλα τα υποαντικείμενα IHyperlinkContainer που περιέχουν μη μηδενική HyperlinkMouseOver. Με το δοσμένο αντικείμενο IHyperlinkContainer μπορείτε να διαχειριστείτε τον υπερσύνδεσμό του (ανάγνωση, ενημέρωση ή αφαίρεση). Δείτε τη διεπαφή IHyperlinkContainer. |

**Επιστρέφει:**
[BehaviorPropertyCollection](../behaviorpropertycollection), KeyedCollection, Collection, ReadOnlyCollection, List
