### Worksheet {#Worksheet}
Χρησιμοποιήστε αντικείμενα CellXls για την αποθήκευση των XValue, YValue, Value ή BubbleSize του σημείου δεδομένων σε φύλλο εργασίας.

### StringLiterals {#StringLiterals}
