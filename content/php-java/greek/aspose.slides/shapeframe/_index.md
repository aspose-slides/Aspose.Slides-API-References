## ShapeFrame κλάση

Αναπαριστά τις ιδιότητες του πλαισίου σχήματος.
 
### ShapeFrame {#ShapeFrame}

| Όνομα | Περιγραφή |
| --- | --- |
| ShapeFrame(float, float, float, float, byte, byte, float) | Δημιουργεί νέες ιδιότητες πλαισίου σχήματος. |

 **Παράμετροι:**

| Όνομα | Τύπος | Περιγραφή |
| --- | --- | --- |
| x | float | Συντεταγμένη X ενός πλαισίου. |
| y | float | Συντεταγμένη Y ενός πλαισίου. |
| width | float | Πλάτος ενός πλαισίου. |
| height | float | Ύψος ενός πλαισίου. |
| flipH | byte | True εάν ένα πλαίσιο είναι αντισπασμένο οριζόντια. |
| flipV | byte | True εάν ένα πλαίσιο είναι αντισπασμένο κάθετα. |
| rotationAngle | float | Αριθμός μοιρών κατά τις οποίες περιστρέφεται ένα πλαίσιο. |

 **Επιστρέφει:**
ShapeFrame
