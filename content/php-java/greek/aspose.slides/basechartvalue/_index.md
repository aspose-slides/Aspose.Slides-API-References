### getDataSourceType {#getDataSourceType}

| Όνομα | Περιγραφή |
| --- | --- |
| getDataSourceType () | Καθορίζει εάν η ιδιότητα AsCell, AsCells, AsLiteralString ή AsLiteralDouble είναι ενεργή στα απογόνους. Με άλλα λόγια, καθορίζει τον τύπο της τιμής της ιδιότητας Data. Ανάγνωση/εγγραφή DataSourceType. Για σημεία στο ChartDataPointCollection αυτή η ιδιότητα είναι μόνο για ανάγνωση. Σε αυτή τη περίπτωση, για να αλλάξετε την τιμή αυτής της ιδιότητας, μπορείτε να χρησιμοποιήσετε μία από τις ιδιότητες ChartDataPointCollection.DataSourceTypeFor<...>. |

 **Επιστρέφει:**
int
