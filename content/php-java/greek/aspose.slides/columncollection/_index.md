## ColumnCollection κλάση

Αντιπροσωπεύει μια συλλογή στηλών σε έναν πίνακα.

### addClone {#addClone}

| Όνομα | Περιγραφή |
| --- | --- |
| addClone ([Column](../column), boolean) | Δημιουργεί ένα αντίγραφο της συγκεκριμένης γραμμής προτύπου και το εισάγει στο κάτω μέρος ενός πίνακα. |

**Παράμετροι:**

| Όνομα | Τύπος | Περιγραφή |
| --- | --- | --- |
| templ | [Column](../column) | Στήλη που χρησιμοποιείται ως πρότυπο. |
| withAttachedColumns | boolean | True για την αντιγραφή επίσης όλων των στηλών που είναι συνδεδεμένες με τη γραμμή προτύπου. |

**Επιστρέφει:**
[Column](../column)
