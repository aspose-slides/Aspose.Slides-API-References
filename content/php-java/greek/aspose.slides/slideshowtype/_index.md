## SlideShowType κλάση

  Βασικές ρυθμίσεις παρουσίασης διαφανειών. Οι πρόγονοι αντιπροσωπεύουν τύπους της παρουσίασης διαφανειών:
   PresentedBySpeaker Παρουσιάζεται από ομιλητή (πλήρης οθόνη)
   BrowsedByIndividual Περιηγείται από άτομο (παράθυρο)
   BrowsedAtKiosk Περιηγείται σε περίπτερο (πλήρης οθόνη)
