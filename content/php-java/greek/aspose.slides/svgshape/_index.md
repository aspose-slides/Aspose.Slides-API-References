### setEventHandler {#setEventHandler}

| Όνομα | Περιγραφή |
| --- | --- |
| setEventHandler (int, String) | Ορίζει το χειριστή συμβάντος για το σχήμα |

 **Παράμετροι:**

| Όνομα | Τύπος | Περιγραφή |
| --- | --- | --- |
| eventType | int | Τύπος του συμβάντος. |
| handler | String | Συνάρτηση Javascript για το χειρισμό του συμβάντος. Η τιμή Null αφαιρεί το χειριστή. |

 **Επιστρέφει:**
void
