## BaseSlideHeaderFooterManager κλάση

Αντιπροσωπεύει τον διαχειριστή που διατηρεί τη συμπεριφορά των δεικτών υποσέλιδου, ημερομηνίας-ώρας και αριθμού σελίδας για όλους τους τύπους διαφανειών.

### isDateTimeVisible {#isDateTimeVisible}

| Όνομα | Περιγραφή |
| --- | --- |
| isDateTimeVisible () | Λαμβάνει τιμή που υποδεικνύει ότι υπάρχει ένας δείκτης ημερομηνίας-ώρας. Διαβάζει boolean. |

**Επιστρέφει:**
boolean
