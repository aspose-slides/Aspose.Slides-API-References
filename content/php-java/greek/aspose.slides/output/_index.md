## Output κλάση

Αντιπροσωπεύει μια συλλογή στοιχείων εξόδου για IWebDocument.

### add {#add}

| Όνομα | Περιγραφή |
| --- | --- |
| add (String, String, TContextObject) | Προσθέτει ένα στοιχείο εξόδου για το αντικείμενο περιβάλλοντος. |

**Παράμετροι:**

| Όνομα | Τύπος | Περιγραφή |
| --- | --- | --- |
| path | String | Διαδρομή εξόδου. |
| templateKey | String | Το κλειδί του προτύπου που χρησιμοποιείται για τη μετατροπή του αντικειμένου περιβάλλοντος πριν την έξοδο. |
| contextObject | TContextObject | Αντικείμενο περιβάλλοντος. |

**Επιστροφή:**
[OutputFile](../outputfile)
