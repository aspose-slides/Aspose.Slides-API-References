## TextSearchOptions κλάση

Απεικονίζει επιλογές που μπορούν να χρησιμοποιηθούν για την αναζήτηση κειμένου σε μια Presentation, Slide ή TextFrame.

### TextSearchOptions {#TextSearchOptions}

| Όνομα | Περιγραφή |
| --- | --- |
| TextSearchOptions() | Δημιουργεί νέες προεπιλεγμένες επιλογές αναζήτησης κειμένου. |

**Επιστρέφει:**
TextSearchOptions


---


### getCaseSensitive {#getCaseSensitive}

| Όνομα | Περιγραφή |
| --- | --- |
| getCaseSensitive () | Ορίστε true για χρήση αναζήτησης με διαχωρισμό πεζών-κεφαλαίων, false – διαφορετικά. Αναγνώσιμο/εγγράψιμο boolean. |

**Επιστρέφει:**
boolean


---


### getIncludeNotes {#getIncludeNotes}

| Όνομα | Περιγραφή |
| --- | --- |
| getIncludeNotes () | Ορίστε true για να συμπεριληφθεί το κείμενο που περιέχεται σε σημειώσεις διαφάνειας ( NotesSlide) κατά την εκτέλεση αναζήτησης κειμένου, αντικατάστασης ή επισήμανσης. Η προεπιλεγμένη τιμή είναι false. |

**Επιστρέφει:**
boolean


---


### getWholeWordsOnly {#getWholeWordsOnly}

| Όνομα | Περιγραφή |
| --- | --- |
| getWholeWordsOnly () | Ορίστε true για να ταιριάζουν μόνο ολόκληρες λέξεις, false – διαφορετικά. Αναγνώσιμο/εγγράψιμο boolean. |

**Επιστρέφει:**
boolean
