## InkEffectType κλάση

 Προσδιορίζει ένα σύνολο προκαθορισμένων οπτικών εφέ για την απόδοση μελάνης.
 Κάθε εφέ αντιστοιχεί σε μια υφή ή εικόνα που προσομοιώνει μια στιλιζαρισμένη εμφάνιση μελάνης.
 Αυτές οι τιμές μπορούν να χρησιμοποιηθούν για την προσαρμογή του οπτικού στυλ των ψηφιακών πινελιών μελάνης κατά την απόδοση.
