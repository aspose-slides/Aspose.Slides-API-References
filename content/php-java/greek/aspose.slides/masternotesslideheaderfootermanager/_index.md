## MasterNotesSlideHeaderFooterManager κλάση

Αντιπροσωπεύει το διαχειριστή που διατηρεί τη συμπεριφορά του υποσέλιδου της κύριας διαφάνειας σημειώσεων, των θέσεων κράτησης ημερομηνίας-ώρα, αριθμού σελίδας και όλων των παιδικών placeholders. Τα παιδικά placeholders σημαίνουν ότι τα placeholders περιέχονται σε εξαρτημένες διαφάνειες σημειώσεων. Οι εξαρτημένες διαφάνειες σημειώσεων χρησιμοποιούν και εξαρτώνται από την κύρια διαφάνεια σημειώσεων.

### setDateTimeAndChildDateTimesText {#setDateTimeAndChildDateTimesText}

| Όνομα | Περιγραφή |
| --- | --- |
| setDateTimeAndChildDateTimesText (String) | Ορίζει κείμενο στην θέση κράτησης ημερομηνίας-ώρα της κύριας διαφάνειας και σε όλες τις θέσεις κράτησης ημερομηνίας-ώρα των παιδικών placeholders. Τα παιδικά placeholders σημαίνουν ότι τα placeholders περιέχονται σε εξαρτημένες διαφάνειες σημειώσεων. Οι εξαρτημένες διαφάνειες σημειώσεων χρησιμοποιούν και εξαρτώνται από την κύρια διαφάνεια σημειώσεων. |

| text | String | Το κείμενο προς ορισμό. |

**Επιστρέφει:**
