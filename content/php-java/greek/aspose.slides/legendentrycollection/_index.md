## LegendEntryCollection κλάση

Αντιπροσωπεύει τη συλλογή υπομνήσεων.

### getCount {#getCount}

| Όνομα | Περιγραφή |
| --- | --- |
| getCount () | Επιστρέφει τον αριθμό των καταχωρήσεων υπομνήματος. Μόνο για ανάγνωση int. |

**Επιστρέφει:**  
int

---

### get_Item {#get_Item}

| Όνομα | Περιγραφή |
| --- | --- |
| get_Item (int) | Λαμβάνει τις ιδιότητες της καταχώρησης υπομνήματος που αντιστοιχεί στο Chart.ChartData.Series[0].DataPoints[index] σε περίπτωση τύπου διαγράμματος από αυτή τη λίστα: ChartType.BarOfPie, ChartType.ExplodedPie, ChartType.ExplodedPie3D, ChartType.Pie, ChartType.Pie3D, ChartType.PieOfPie; ή που αντιστοιχεί στο Chart.ChartData.Series[index] για άλλους τύπους διαγράμματος. |

**Επιστρέφει:**  
[LegendEntryProperties](../legendentryproperties)
