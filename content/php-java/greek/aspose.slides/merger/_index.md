## Merger class

Αντιπροσωπεύει μια ομάδα μεθόδων για τη συγχώνευση παρουσιάσεων PowerPoint του ίδιου φορμάτ σε ένα αρχείο.

### process {#process}

| Όνομα | Περιγραφή |
| --- | --- |
| process (java.lang.String[], String) | Συγχωνεύει πολλαπλές παρουσιάσεις PowerPoint του ίδιου φορμάτ σε ένα ενιαίο αρχείο παρουσίασης. |

**Παράμετροι:**

| Όνομα | Τύπος | Περιγραφή |
| --- | --- | --- |
| inputFileNames | java.lang.String[] | Πίνακας με τα ονόματα των αρχείων εισόδου της παρουσίασης. |
| outputFileName | String | Το όνομα του αρχείου εξόδου της προκύπτουσας συγχωνευμένης παρουσίασης. |

**Τιμή επιστροφής:**
void

**Εξαίρεση**

| Σφάλμα | Συνθήκη |
| --- | --- |
| ArgumentException | Έγινε ρίψη όταν τα ονόματα των αρχείων εισόδου είναι άκυρα ή τα φορμάτ δεν ταιριάζουν. |
