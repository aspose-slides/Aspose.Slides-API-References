## Tab κλάση

| Όνομα | Περιγραφή |
| --- | --- |
| Tab(double, int) | Creates new Tab |

 **Παράμετροι:**

| Όνομα | Τύπος | Περιγραφή |
| --- | --- | --- |
| position | double | Tab position. |
| align | int | Align. |
