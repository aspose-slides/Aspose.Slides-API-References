## IImage κλάση

Αντιπροσωπεύει μια ραστερική ή διανυσματική εικόνα.

Αυτή η διεπαφή παρέχει μια κοινή αφαίρεση για τη διαχείριση τόσο ραστερικών όσο και διανυσματικών εικόνων.  
Οι υλοποιήσεις μπορεί να διαφέρουν ανάλογα με τον υποκείμενο τύπο εικόνας.
