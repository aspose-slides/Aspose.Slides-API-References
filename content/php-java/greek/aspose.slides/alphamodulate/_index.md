## AlphaModulate κλάση

 Αναπαριστά ένα εφέ Alpha Modulate.  
 Οι τιμές του alpha (αδιαφάνειας) του εφέ πολλαπλασιάζονται με ένα σταθερό ποσοστό.  
 Το δοχείο εφέ καθορίζει ένα εφέ που περιέχει τιμές alpha για τη διαμόρφωση.
