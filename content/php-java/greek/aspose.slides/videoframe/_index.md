## VideoFrame κλάση

Αντιπροσωπεύει ένα βίντεο σε μια διαφάνεια.

### getCaptionTracks {#getCaptionTracks}

| Όνομα | Περιγραφή |
| --- | --- |
| getCaptionTracks () | Λαμβάνει τη συλλογή των κλειστών υποτίτλων που σχετίζονται με το πλαίσιο βίντεο. Αυτή η ιδιότητα είναι μόνο για ανάγνωση και επιστρέφει ένα ICaptionsCollection που περιέχει όλα τα κομμάτια υπότιτλων. |

**Επιστρέφει:**
[CaptionsCollection](../captionscollection)
