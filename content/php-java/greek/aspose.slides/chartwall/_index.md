| Όνομα | Περιγραφή |
| --- | --- |
| getFormat () | Επιστρέφει τη γέμιση του τοίχου, τη γραμμή, το εφέ, τα 3δ στυλ. Μόνο για ανάγνωση IFormat. |

[Format](../format)
