## CommentAuthorCollection κλάση

Αναπαριστά μια συλλογή από συγγραφείς σχολίων.

### addAuthor {#addAuthor}

| Όνομα | Περιγραφή |
| --- | --- |
| addAuthor (String, String) | Προσθέτει νέο συγγραφέα στο τέλος μιας συλλογής. |

**Παράμετροι:**

| Όνομα | Τύπος | Περιγραφή |
| --- | --- | --- |
| name | String | Όνομα ενός νέου συγγραφέα. |
| initials | String | Αρχικά ενός νέου συγγραφέα. |

**Επιστρέφει:**
[CommentAuthor](../commentauthor)

**Εξαίρεση**

| Σφάλμα | Συνθήκη |
| --- | --- |
| PptxEditException | Εκτοπώθηκε εάν ο συγγραφέας με το ίδιο όνομα και αρχικά έχει ήδη προστεθεί. |
