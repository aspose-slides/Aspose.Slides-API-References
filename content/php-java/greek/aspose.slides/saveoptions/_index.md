### getSkipJavaScriptLinks {#getSkipJavaScriptLinks}

| Όνομα | Περιγραφή |
| --- | --- |
| getSkipJavaScriptLinks () | Καθορίζει αν θα παραλείπονται υπερσυνδέσμοι με κλήσεις JavaScript κατά την αποθήκευση της παρουσίασης. Ανάγνωση/εγγραφή boolean. Η προεπιλεγμένη τιμή είναι false. Όταν αυτή η ιδιότητα οριστεί σε true, οι υπερσυνδέσμοι με κλήσεις JavaScript θα αγνοηθούν κατά την αποθήκευση. Όταν αυτή η ιδιότητα οριστεί σε false, όλοι οι υπερσυνδέσμοι θα αποθηκευτούν. |

boolean
