## ControlCollection κλάση

 Μια συλλογή από ελέγχους ActiveX.
 
### addControl {#addControl}

| Όνομα | Περιγραφή |
| --- | --- |
| addControl (int, float, float, float, float) | Δημιουργεί και προσθέτει έναν νέο έλεγχο στη συλλογή. |

 **Παράμετροι:**

| Όνομα | Τύπος | Περιγραφή |
| --- | --- | --- |
| controlType | int | Τύπος του ελέγχου που θα προστεθεί. |
| x | float | Η συντεταγμένη X για την αριστερή πλευρά του πλαισίου του σχήματος. |
| y | float | Η συντεταγμένη Y για την άνω πλευρά του πλαισίου του σχήματος. |
| width | float | Το πλάτος του πλαισίου του σχήματος. |
| height | float | Το ύψος του πλαισίου του σχήματος. |

 **Επιστρέφει:**
[Control](../control)
