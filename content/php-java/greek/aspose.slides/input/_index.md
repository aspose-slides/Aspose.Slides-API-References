## Input κλάση

 Αναπαριστά μια συλλογή από στοιχεία εισόδου (πρότυπα).
 
### addTemplate {#addTemplate}

| Όνομα | Περιγραφή |
| --- | --- |
| addTemplate (String, String) | Προσθέτει ένα πρότυπο στη συλλογή. |

 **Παράμετροι:**

| Όνομα | Τύπος | Περιγραφή |
| --- | --- | --- |
| key | String | Κλειδί για το πρότυπο στη συλλογή. |
| path | String | Διαδρομή προς το αρχείο προτύπου. |

 **Επιστρέφει:**
void
