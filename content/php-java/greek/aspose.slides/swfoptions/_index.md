## SwfOptions κλάση

 Παρέχει επιλογές που ελέγχουν πώς αποθηκεύεται μια παρουσίαση σε μορφή Swf.

| --- | --- |
| SwfOptions() | Προεπιλεγμένη συνάρτηση. |

SwfOptions

boolean

### getLogoImageBytes {#getLogoImageBytes}

| Όνομα | Περιγραφή |
| --- | --- |
| getLogoImageBytes () | Εικόνα που θα εμφανίζεται ως λογότυπο στην επάνω δεξιά γωνία του προβολέα. Η εικόνα πρέπει να είναι PNG 32x64 pixels, διαφορετικά το λογότυπο μπορεί να εμφανιστεί λανθασμένα. |

 **Επιστρέφει:**
byte
