## OverrideTheme κλάση

Αναπαριστά ένα θέμα αντικατάστασης.

### clear {#clear}

| Όνομα | Περιγραφή |
| --- | --- |
| clear () | Ορίστε το ColorScheme, FontScheme, FormatScheme σε null για να απενεργοποιήσετε οποιαδήποτε αντικατάσταση με αυτό το αντικείμενο θέματος. |

**Επιστρέφει:**
void
