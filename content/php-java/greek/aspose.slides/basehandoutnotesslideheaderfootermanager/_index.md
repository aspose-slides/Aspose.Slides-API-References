## BaseHandoutNotesSlideHeaderFooterManager κλάση

 Αναπαριστά διαχειριστή που διατηρεί τη συμπεριφορά των placeholders, συμπεριλαμβανομένου του placeholder κεφαλίδας για όλα τα είδη handout και notes διαφανειών.

### isHeaderVisible {#isHeaderVisible}

| Όνομα | Περιγραφή |
| --- | --- |
| isHeaderVisible () | Λαμβάνει τιμή που υποδεικνύει ότι υπάρχει ένα placeholder κεφαλίδας. Ανάγνωση boolean. |

 **Επιστρέφει:**
boolean


---


### setHeaderText {#setHeaderText}

| Όνομα | Περιγραφή |
| --- | --- |
| setHeaderText (String) | Ορίζει κείμενο στο placeholder κεφαλίδας της διαφάνειας. |

 **Παράμετροι:**

| Όνομα | Τύπος | Περιγραφή |
| --- | --- | --- |
| text | String | Κείμενο προς ορισμό. |

 **Επιστρέφει:**
void


---


### setHeaderVisibility {#setHeaderVisibility}

| Όνομα | Περιγραφή |
| --- | --- |
| setHeaderVisibility (boolean) | Αλλάζει την ορατότητα του placeholder κεφαλίδας της διαφάνειας. |

 **Παράμετροι:**

| Όνομα | Τύπος | Περιγραφή |
| --- | --- | --- |
| isVisible | boolean | true - καθιστά το placeholder κεφαλίδας ορατό, διαφορετικά - το κρύβει. |

 **Επιστρέφει:**
void
