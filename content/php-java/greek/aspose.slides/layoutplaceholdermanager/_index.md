## LayoutPlaceholderManager κλάση

Αντιπροσωπεύει έναν διαχειριστή που επιτρέπει την προσθήκη συμβόλων κράτησης στη διαφάνεια διάταξης.

### addChartPlaceholder {#addChartPlaceholder}

| Όνομα | Περιγραφή |
| --- | --- |
| addChartPlaceholder (float, float, float, float) | Προσθέτει ένα νέο σχήμα σύμβολου κράτησης στη διαφάνεια διάταξης για να κρατήσει ένα διάγραμμα. |

**Παράμετροι:**

| Όνομα | Τύπος | Περιγραφή |
| --- | --- | --- |
| x | float | Η συντεταγμένη X της νέας μορφής σύμβολου κράτησης. |
| y | float | Η συντεταγμένη Y της νέας μορφής σύμβολου κράτησης. |
| width | float | Το πλάτος της νέας μορφής σύμβολου κράτησης. |
| height | float | Το ύψος της νέας μορφής σύμβολου κράτησης. |

**Επιστρέφει:**
[AutoShape](../autoshape)
