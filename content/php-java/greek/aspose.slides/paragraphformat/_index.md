## ParagraphFormat κλάση

Αυτή η κλάση περιέχει τις ιδιότητες μορφοποίησης παραγράφου. Σε αντίθεση με IParagraphFormatEffectiveData, όλες οι ιδιότητες αυτής της κλάσης είναι εγγράψιμες.  
Η κλάση αυτή χρησιμοποιείται για την επιστροφή και την τροποποίηση των ιδιοτήτων μορφοποίησης παραγράφου που ορίζονται για τη συγκεκριμένη παράγραφο. Αυτό σημαίνει ότι  
δεν εφαρμόζεται κληρονομικότητα κατά την ανάκτηση τιμών, έτσι στις περισσότερες περιπτώσεις θα λάβετε τιμές που σημαίνουν «απροσδιόριστο».  
Για την λήψη των αποτελεσματικών τιμών παραμέτρων μορφοποίησης, συμπεριλαμβανομένων των κληρονομημένων, πρέπει να χρησιμοποιήσετε τη μέθοδο ParagraphFormat#getEffective  
η οποία επιστρέφει ένα αντικείμενο IParagraphFormatEffectiveData.
