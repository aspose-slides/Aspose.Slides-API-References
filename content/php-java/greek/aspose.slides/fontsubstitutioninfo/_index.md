## FontSubstitutionInfo κλάση

 Αυτή η δομή αντιπροσωπεύει τις πληροφορίες σχετικά με την αντικατάσταση γραμματοσειράς όταν θα αποδοθεί.
 
### FontSubstitutionInfo {#FontSubstitutionInfo}

| Όνομα | Περιγραφή |
| --- | --- |
| FontSubstitutionInfo(String, String) | Δημιουργεί μια παρουσία της κλάσης FontSubstitutionInfo. |

**Παράμετροι:**

| Όνομα | Τύπος | Περιγραφή |
| --- | --- | --- |
| originFontName | String | Όνομα γραμματοσειράς προέλευσης στην παρουσίαση String |
| substFontName | String | Όνομα αντικαταστάσεως γραμματοσειράς για την αρχική γραμματοσειρά String |

**Επιστρέφει:**
FontSubstitutionInfo
