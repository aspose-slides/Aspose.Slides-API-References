### AccentProcess {#AccentProcess}
```
public static final int AccentProcess
```

Используется для отображения прогрессии, временной шкалы или последовательных шагов в задаче, процессе или рабочем потоке. Хорошо подходит для иллюстрации как текста Уровня 1, так и текста Уровня 2.

### AccentedPicture {#AccentedPicture}
```
public static final int AccentedPicture
```
