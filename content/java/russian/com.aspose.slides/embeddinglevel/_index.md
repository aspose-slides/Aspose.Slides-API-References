Представляет права лицензирования для встраивания шрифта.
## Поля

| Поле | Описание |
| --- | --- |

### Устанавливаемый {#Installable}
```
public static final int Installable
```

Шрифты с этой настройкой указывают, что они могут быть встроены и постоянно установлены на удалённой системе приложением. Пользователь удалённой системы получает те же права, обязательства и лицензии на этот шрифт, что и оригинальный покупатель шрифта, и подпадает под те же условия конечного лицензионного соглашения, авторские права, патент на дизайн и/или товарный знак, что и оригинальный покупатель.

### Ограниченный {#Restricted}
```
public static final int Restricted
```

Шрифты, у которых установлен только этот бит, не должны изменяться, встраиваться или обмениваться каким-либо способом без предварительного получения разрешения у законного владельца.

### ПредпросмотрПечать {#PreviewPrint}
```
public static final int PreviewPrint
```

Когда этот бит установлен, шрифт может быть встроен и временно загружен на удалённую систему. Документы, содержащие шрифты Preview & Print, должны открываться только в режиме "только для чтения"; редактирование документа запрещено.

### Редактируемый {#Editable}
```
public static final int Editable
```

Когда этот бит установлен, шрифт может быть встроен, но должен быть установлен только временно на других системах. В отличие от шрифтов Preview & Print, документы, содержащие шрифты Editable, могут открываться для чтения, редактирование разрешено, и изменения могут быть сохранены.

### БезСубсеттинга {#NoSubsetting}
```
public static final int NoSubsetting
```

Когда этот бит установлен, шрифт не может быть субсетирован перед встраиванием. Другие ограничения встраивания, указанные в битах 0-3 и 9, также применяются.

### ТолькоРастры {#BitmapOnly}
```
public static final int BitmapOnly
```

Когда этот бит установлен, могут быть встроены только растровые изображения, содержащиеся в шрифте. Контурные данные не могут быть встроены. Если в шрифте нет доступных растровых изображений, то шрифт считается не встраиваемым, и услуги по встраиванию завершатся с ошибкой.
