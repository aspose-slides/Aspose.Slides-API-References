Определяет набор предустановленных визуальных эффектов для отрисовки чернил. Каждый эффект соответствует текстуре или изображению, имитирующему стилизованный вид чернил. Эти значения можно использовать для настройки визуального стиля цифровых штрихов чернила во время отрисовки.
