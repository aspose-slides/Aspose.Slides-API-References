```
public interface ITextSearchOptions
```

Представляет параметры, которые могут быть использованы для поиска текста в Презентации, Слайде или TextFrame.

| [setCaseSensitive(boolean value)](#setCaseSensitive-boolean-) | Установите true, чтобы использовать поиск с учётом регистра, иначе false. |
| [getWholeWordsOnly()](#getWholeWordsOnly--) | Установите true, чтобы сопоставлять только целые слова, иначе false. |
| [setWholeWordsOnly(boolean value)](#setWholeWordsOnly-boolean-) | Установите true, чтобы сопоставлять только целые слова, иначе false. |
| [getIncludeNotes()](#getIncludeNotes--) | Установите true, чтобы включать текст из заметок слайда при выполнении поиска, замены или подсветки текста. |
| [setIncludeNotes(boolean value)](#setIncludeNotes-boolean-) | Установите true, чтобы включать текст из заметок слайда при выполнении поиска, замены или подсветки текста. |
