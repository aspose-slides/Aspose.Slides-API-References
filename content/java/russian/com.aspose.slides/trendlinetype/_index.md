| [Linear](#Linear) | Указывает, что линия тренда должна быть линией в заданной форме. |
| [Logarithmic](#Logarithmic) | Указывает, что линия тренда должна быть логарифмической кривой в заданной форме, где log — натуральный логарифм. |
| [MovingAverage](#MovingAverage) | Указывает, что линия тренда должна быть скользящей средней с периодом Period. |
| [Polynomial](#Polynomial) | Указывает, что линия тренда должна быть полиномиальной кривой порядка Order в заданной форме. |
| [Power](#Power) | Указывает, что линия тренда должна быть степенной кривой в заданной форме. |
