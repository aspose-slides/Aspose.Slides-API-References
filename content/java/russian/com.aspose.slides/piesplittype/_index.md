Представляет тип точек разбиения во второй части круговой или столбчатой диаграммы в диаграмме «круг-в-круге» или «столбец-в-круге».

| Поле | Описание |
| --- | --- |
| [Default](#Default) | Указывает, что точки данных должны быть разбиты с использованием механизма по умолчанию для этого типа диаграммы. |
| [Custom](#Custom) | Указывает, что точки данных должны быть разбиты между кругом и второй диаграммой в соответствии со значениями пользовательского разбиения. |
| [ByPercentage](#ByPercentage) | Указывает, что точки данных должны быть разбиты между кругом и второй диаграммой, помещая точки с процентом меньше значения Split Position в вторую диаграмму. |
| [ByPos](#ByPos) | Указывает, что точки данных должны быть разбиты между кругом и второй диаграммой, помещая последние точки позиции Split Position во вторую диаграмму. |
| [ByValue](#ByValue) | Указывает, что точки данных должны быть разбиты между кругом и второй диаграммой, помещая точки со значением меньше Split Position во вторую диаграмму. |
