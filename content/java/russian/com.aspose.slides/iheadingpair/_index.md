public interface IHeadingPair
```

Представляет свойство «Heading pair» документа. Указывает имя группы частей документа и количество частей в группе.
## Методы

| Method | Description |
| --- | --- |
| [getName()](#getName--) | Возвращает имя группы частей документа. |
| [getCount()](#getCount--) | Возвращает количество частей в группе. |
### getName() {#getName--}
```
public abstract String getName()
```

Возвращает имя группы частей документа. Только для чтения String.

**Возвращаемое значение:**
java.lang.String
### getCount() {#getCount--}
```
public abstract int getCount()
```

Возвращает количество частей в группе. Только для чтения int.

**Возвращаемое значение:**
int
