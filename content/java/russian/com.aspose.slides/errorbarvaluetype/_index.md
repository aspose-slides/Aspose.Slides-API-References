## Поля

| Поле | Описание |
| --- | --- |
| [Custom](#Custom) | Указывает, что длина линий ошибок должна определяться элементами Plus и Minus. |
| [Fixed](#Fixed) | Указывает, что длина линий ошибок должна быть фиксированным значением, определяемым Error Bar Value. |
| [Percentage](#Percentage) | Указывает, что длина линий ошибок должна быть Error Bar Value процентом от данных. |
| [StandardDeviation](#StandardDeviation) | Указывает, что длина линий ошибок должна быть Error Bar Value стандартными отклонениями данных. |
| [StandardError](#StandardError) | Указывает, что длина линий ошибок должна быть Error Bar Value стандартными ошибками данных. |
