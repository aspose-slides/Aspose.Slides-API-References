Указывает состояние, в котором должна отображаться полоса разделения. Полоса разделения разделяет первичную и вторичную область в пределах области просмотра.
## Поля

| Поле | Описание |
| --- | --- |
| [Minimized](#Minimized) | Первичная область занимает наименьшее количество области просмотра, разрешённое приложением. |
| [Restored](#Restored) | Первичная область имеет конкретный промежуточный размер. |
| [Maximized](#Maximized) | Первичная область занимает наибольшее количество области просмотра, разрешённое приложением. |
