Указывает выравнивание математического абзаца (последовательности смежных экземпляров математического текста в пределах одного абзаца)

| --- | --- |
| [LeftJustified](#LeftJustified) | Выравнивает математический текст по левому краю |
| [RightJustified](#RightJustified) | Выравнивает математический текст по правому краю |
| [Centered](#Centered) | Выравнивает математический текст по центру |

### CenteredAsGroup {#CenteredAsGroup}
```

```


Центрирует на странице всю группу блоков с математическим содержимым как единое целое. Это означает, что экземпляры математического текста могут выравниваться относительно друг друга, но вся группа математического текста центрируется как целое.
