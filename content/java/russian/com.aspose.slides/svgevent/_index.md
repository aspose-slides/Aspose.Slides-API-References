Представляет параметры для SVG-формы.  
## Поля

| Поле | Описание |
| --- | --- |
| [OnFocusIn](#OnFocusIn) | Происходит, когда элемент получает фокус, например, когда текст выделяется. |
| [OnFocusOut](#OnFocusOut) | Происходит, когда элемент теряет фокус, например, когда текст перестаёт быть выделенным. |
| [OnActivate](#OnActivate) | Происходит, когда элемент активируется, например, через щелчок мыши или нажатие клавиши. |
| [OnClick](#OnClick) | Происходит, когда кнопка указывающего устройства нажата над элементом. |
| [OnMouseDown](#OnMouseDown) | Происходит, когда кнопка указывающего устройства нажата и удерживается над элементом. |
| [OnMouseUp](#OnMouseUp) | Происходит, когда кнопка указывающего устройства отпущена над элементом. |
| [OnMouseOver](#OnMouseOver) | Происходит, когда указывающее устройство перемещается к элементу. |
| [OnMouseMove](#OnMouseMove) | Происходит, когда указывающее устройство перемещается, находясь над элементом. |
| [OnMouseOut](#OnMouseOut) | Происходит, когда указывающее устройство перемещается прочь от элемента. |
| [OnLoad](#OnLoad) | Происходит, когда пользовательский агент полностью проанализировал элемент и его потомков, а также все связанные ресурсы, необходимые для его отображения. |
| [OnUnload](#OnUnload) | Происходит, когда реализация DOM удаляет документ из окна или фрейма. |
| [OnAbort](#OnAbort) | Происходит, когда загрузка страницы останавливается до того, как элемент полностью загрузился. |
| [OnError](#OnError) | Происходит, когда элемент не загружается корректно или возникает ошибка во время выполнения скрипта. |
| [OnResize](#OnResize) | Происходит, когда представление документа изменяется по размеру. |
| [OnScroll](#OnScroll) | Происходит, когда представление документа сдвигается вдоль оси X, Y или обеих осей. |
| [OnZoom](#OnZoom) | Происходит, когда уровень масштабирования представления документа изменяется. |
| [OnBegin](#OnBegin) | Происходит, когда элемент анимации начинается. |
| [OnEnd](#OnEnd) | Происходит, когда элемент анимации заканчивается. |
| [OnRepeat](#OnRepeat) | Происходит, когда элемент анимации повторяется. |
