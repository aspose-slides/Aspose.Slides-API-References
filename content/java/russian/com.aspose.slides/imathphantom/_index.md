Представляет математический объект-призрак (<m:phant>), который влияет на расположение дочернего элемента, не обязательно отображая его. Призрак может скрывать базовое выражение, сохраняя его ширину, высоту или глубину для выравнивания формул или резервирования пространства. Видимость и геометрическое поведение управляются свойствами, такими как Show, ZeroWid, ZeroAsc, ZeroDesc и Transp.

--------------------

> ```
> Example:
>  
>  IMathPhantom phantom = new MathPhantom(new MathematicalText("1/2"));
>  phantom.setShow(false);          // Скрыть содержимое
>  phantom.setZeroWidth(false);     // Сохранить ширину
>  ```

### getTransp() {#getTransp--}
```
public abstract boolean getTransp()
```

Получает или задает значение, указывающее, является ли призрак прозрачным для правил межэлементного интервала, основанных на классах.

--------------------

Когда значение true, операторы и символы внутри призрака всё равно влияют на математический интервал вокруг него (как если бы они были видимыми). Когда значение false, правила межэлементного интервала, основанные на классах, игнорируются. Соответствует атрибуту OMML m:transp.

**Возвращаемое значение:**
boolean
