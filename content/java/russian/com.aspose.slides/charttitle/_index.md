### getTextFrameForOverriding() {#getTextFrameForOverriding--}
```
public final ITextFrame getTextFrameForOverriding()
```

Может содержать текст с богатыми форматами. Если это свойство не равно null, то значение форматированного текста переопределяет автоматически генерируемый текст. Автогенерируемый текст является неявным свойством подписи данных, подписи единиц измерения значения оси, заголовка оси, заголовка диаграммы, подписи линии тренда. Автогенерируемый текст форматируется свойством IFormattedTextContainer.TextFormat. Только чтение [ITextFrame](../../com.aspose.slides/itextframe).

**Возвращает:**
[ITextFrame](../../com.aspose.slides/itextframe)
