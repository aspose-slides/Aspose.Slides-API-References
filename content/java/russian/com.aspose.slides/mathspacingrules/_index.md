Типы промежутков (горизонтальное расстояние) между столбцами матрицы
## Поля

| Поле | Описание |
| --- | --- |
| [SingleSpacingGap](#SingleSpacingGap) | Одинарный (1 em для столбцов или 1 строка для строк) |
| [OneAndHalfSpacingGap](#OneAndHalfSpacingGap) | Полуторный (1,5 em для столбцов или 1,5 строки для строк) |
| [DoubleSpacingGap](#DoubleSpacingGap) | Двойной интервал (2 em для столбцов или 2 строки для строк) |
| [Exactly](#Exactly) | Точное значение. Для столбцов используется значение ColumnGap, измеряемое в twips. Для строк используется значение RowGap, измеряемое в twips. |
| [Multiple](#Multiple) | Множественное. Для столбцов используется значение ColumnGap, измеряемое с шагом 0.5 em. Для строк используется значение RowGap, измеряемое в строках. |
