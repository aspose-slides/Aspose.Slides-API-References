### getRotationAngle() {#getRotationAngle--}
```
public abstract float getRotationAngle()
```

बाउंडिंग बॉक्स के भीतर टेक्स्ट पर लागू कस्टम रोटेशन निर्दिष्ट करता है। यदि निर्दिष्ट नहीं है, तो साथ वाले आकार की रोटेशन उपयोग होती है। यदि निर्दिष्ट है, तो यह आकार से स्वतंत्र रूप से लागू होता है। अर्थात आकार पर रोटेशन हो सकता है और साथ ही टेक्स्ट पर भी रोटेशन लागू हो सकता है। इस प्रॉपर्टी और TextVerticalType प्रॉपर्टी में पूर्वनिर्धारित वर्टिकल प्रकार से प्राप्त दृश्य टेक्स्ट रोटेशन का सम्मिलित मान। पढ़ें/लिखें float.

--------------------

> ```
> ऐसे मामले पर विचार करें जहाँ कोई आकार 90 डिग्री घड़ी की सुई की दिशा में घुमाव लागू किया गया हो। 
>  इसके अतिरिक्त, टेक्स्ट बॉडी स्वयं -90 डिग्री का घुमाव रखती है। 
>  विपरीत दिशा में लागू किया गया है। फिर परिणामी आकार ऐसा दिखाई देगा कि
>  घुमाया गया हो, लेकिन उसके भीतर का टेक्स्ट ऐसा दिखाई देगा जैसे इसे बिल्कुल भी घुमाया नहीं गया हो।
> ```


**रिटर्न:**  
float
