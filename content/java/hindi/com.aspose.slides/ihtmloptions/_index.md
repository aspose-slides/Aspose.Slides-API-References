### getJpegQuality() {#getJpegQuality--}
```
public abstract byte getJpegQuality()
```

PDF दस्तावेज़ के भीतर JPEG छवियों की गुणवत्ता निर्धारित करने वाला मान प्राप्त करता है या सेट करता है। पढ़ें/लिखें byte।

--------------------

केवल तब प्रभावी जब दस्तावेज़ में JPEG छवियां हों।

इस प्रॉपर्टी का उपयोग PDF प्रारूप में सहेजते समय दस्तावेज़ के भीतर छवियों की गुणवत्ता प्राप्त या सेट करने के लिए किया जाता है। मान 0 से 100 तक हो सकता है जहाँ 0 का मतलब सबसे खराब गुणवत्ता लेकिन अधिकतम संपीड़न और 100 का मतलब सबसे अच्छी गुणवत्ता लेकिन न्यूनतम संपीड़न है।

डिफ़ॉल्ट मान **95** है।

**वापसी:**

```

टेक्स्ट को लिगेचर के बिना रेंडर किया जाए यह दर्शाने वाला मान प्राप्त करता है या सेट करता है। जब true पर सेट किया जाता है, लिगेचर रेंडर किए गए आउटपुट में निष्क्रिय हो जाएंगे। डिफ़ॉल्ट रूप से, यह प्रॉपर्टी false पर सेट होती है।

--------------------

> ```
> Example:
>  
>  Presentation pres = new Presentation("pres.pptx");
>  try {
>      HtmlOptions options = new HtmlOptions();
>      options.setDisableFontLigatures(true);
>      pres.save("presentation.html", SaveFormat.Html, options);
>  } finally {
>      if (pres != null) pres.dispose();
>  }
> ```

**वापसी:**
