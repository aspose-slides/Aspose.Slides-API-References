Reprezentuje opcje, które można użyć do wyszukiwania tekstu w Presentation, Slide lub TextFrame.

| [getWholeWordsOnly()](#getWholeWordsOnly--) | Ustaw true, aby dopasować tylko całe słowa, false - w przeciwnym razie. |

| [getIncludeNotes()](#getIncludeNotes--) | Ustaw true, aby uwzględnić tekst zawarty w notatkach slajdu podczas wykonywania wyszukiwania tekstu, zamiany lub operacji podświetlania. |
| [setIncludeNotes(boolean value)](#setIncludeNotes-boolean-) | Ustaw true, aby uwzględnić tekst zawarty w notatkach slajdu podczas wykonywania wyszukiwania tekstu, zamiany lub operacji podświetlania. |
