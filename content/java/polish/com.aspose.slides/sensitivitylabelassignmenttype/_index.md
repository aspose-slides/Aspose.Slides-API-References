Reprezentuje metodę przypisania etykiety poufności.
## Pola

| Pole | Opis |
| --- | --- |
| [Standard](#Standard) | Użyj dla dowolnej etykiety poufności, która nie została bezpośrednio zastosowana przez użytkownika. |
| [Privileged](#Privileged) | Użyj dla dowolnej etykiety poufności, która została bezpośrednio zastosowana przez użytkownika. |
### Standardowy {#Standard}
```
public static final int Standard
```


Użyj dla dowolnej etykiety poufności, która nie została bezpośrednio zastosowana przez użytkownika. Obejmuje to wszystkie domyślne etykiety, automatycznie zastosowane etykiety.

### Uprawniony {#Privileged}
```
public static final int Privileged
```


Użyj dla dowolnej etykiety poufności, która została bezpośrednio zastosowana przez użytkownika. Obejmuje to ręcznie zastosowane etykiety poufności, a także rekomendowane lub obowiązkowe etykietowanie lub każdą funkcję, w której użytkownik decyduje, którą etykietę poufności zastosować.
