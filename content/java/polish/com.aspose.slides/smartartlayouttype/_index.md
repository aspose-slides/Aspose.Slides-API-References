### AccentProcess {#AccentProcess}
```
public static final int AccentProcess
```

Użyj do przedstawienia postępu, osi czasu lub kolejnych kroków w zadaniu, procesie lub przepływie pracy. Dobrze sprawdza się przy ilustrowaniu zarówno tekstu Poziomu 1, jak i Poziomu 2.

### AccentedPicture {#AccentedPicture}
```
public static final int AccentedPicture
```

Użyj do przedstawienia centralnej, fotograficznej idei z powiązanymi pomysłami po bokach. Górny tekst Poziomu 1 pojawia się nad centralnym obrazem. Odpowiedni tekst dla pozostałych kształtów Poziomu 1 pojawia się obok małych okrągłych obrazków. Ten układ dobrze działa także bez tekstu.

### AlternatingFlow {#AlternatingFlow}
```
public static final int AlternatingFlow
```

Użyj do przedstawienia grup informacji lub kolejnych kroków w zadaniu, procesie lub przepływie pracy. Podkreśla interakcję lub relacje między grupami informacji.

### AlternatingHexagons {#AlternatingHexagons}
```
public static final int AlternatingHexagons
```

Użyj do reprezentacji serii połączonych idei. Tekst Poziomu 1 pojawia się wewnątrz heksagonów. Tekst Poziomu 2 pojawia się na zewnątrz kształtów.

### AlternatingPictureBlocks {#AlternatingPictureBlocks}
```
public static final int AlternatingPictureBlocks
```

Użyj do wyświetlenia serii zdjęć od góry do dołu. Tekst pojawia się naprzemiennie po prawej lub po lewej stronie obrazu.

### AlternatingPictureCircles {#AlternatingPictureCircles}
```
public static final int AlternatingPictureCircles
```

Użyj do pokazania zestawu zdjęć z tekstem. Odpowiedni tekst pojawia się w centralnych okręgach, a obrazy zmieniają się od lewej do prawej.

### ArrowRibbon {#ArrowRibbon}
```
public static final int ArrowRibbon
```

Użyj do przedstawienia powiązanych lub kontrastujących koncepcji z pewnym połączeniem, np. przeciwstawnych sił. Dwa pierwsze wiersze tekstu Poziomu 1 służą jako tekst w strzałkach. Nieużywany tekst nie jest wyświetlany, ale pozostaje dostępny po zmianie układu.

### AscendingPictureAccentProcess {#AscendingPictureAccentProcess}
```
public static final int AscendingPictureAccentProcess
```

Użyj do pokazania rosnącej serii zdjęć z opisowym tekstem. Działa najlepiej przy niewielkiej ilości tekstu.

### Balance {#Balance}
```
public static final int Balance
```
