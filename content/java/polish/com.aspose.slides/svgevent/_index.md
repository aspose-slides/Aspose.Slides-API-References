| [OnZoom](#OnZoom) | Występuje, gdy poziom powiększenia widoku dokumentu zostaje zmieniony. |
| [OnBegin](#OnBegin) | Występuje, gdy element animacji rozpoczyna się. |
| [OnEnd](#OnEnd) | Występuje, gdy element animacji kończy się. |
