Określa zestaw predefiniowanych efektów wizualnych dla renderowania atramentu. Każdy efekt odpowiada fakturze lub obrazowi, który symuluje stylizowany wygląd atramentu. Wartości te mogą być użyte do dostosowania stylu wizualnego cyfrowych pociągnięć atramentu podczas renderowania.
