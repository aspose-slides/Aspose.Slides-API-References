| Pole | Opis |

### NotDefined {#NotDefined}
```
public static final int NotDefined
```

Identyfikator trwałości nie został określony.

### PersistPropertyBag {#PersistPropertyBag}
```
public static final int PersistPropertyBag
```

Określa, że kontrolka ActiveX jest utrwalana przy użyciu trwałości opartej na worku właściwości. Trwałość oparta na worku właściwości przechowuje kontrolkę ActiveX za pomocą kolekcji par nazw i wartości, które określają dane utrwalane przez kontrolkę ActiveX.

### PersistStream {#PersistStream}
```
public static final int PersistStream
```

Określa, że kontrolka ActiveX jest utrwalana przy użyciu trwałości opartej na strumieniu, która nie obsługuje inicjalizacji kontrolki ActiveX do stanu domyślnego.

### PersistStreamInit {#PersistStreamInit}
```
public static final int PersistStreamInit
```

Określa, że kontrolka ActiveX jest utrwalana przy użyciu trwałości opartej na strumieniu, która obsługuje inicjalizację kontrolki ActiveX do stanu domyślnego.

### PersistStorage {#PersistStorage}
```
public static final int PersistStorage
```

Określa, że kontrolka ActiveX jest utrwalana przy użyciu trwałości opartej na pamięci masowej.
