### Installable {#Installable}
```
public static final int Installable
```

แบบอักษรที่มีการตั้งค่านี้แสดงว่ามันสามารถฝังและติดตั้งอย่างถาวรบนระบบระยะไกลโดยแอปพลิเคชัน ผู้ใช้ของระบบระยะไกลจะได้รับสิทธิ์ หน้าที่และใบอนุญาตเดียวกันสำหรับแบบอักษรนั้นเช่นเดียวกับผู้ซื้อแบบอักษรเดิม และต้องยอมรับข้อตกลงผู้ใช้สุดท้าย, ลิขสิทธิ์, สิทธิบัตรการออกแบบ, และ/หรือเครื่องหมายการค้าที่เหมือนกับผู้ซื้อเดิม

### Restricted {#Restricted}
```
public static final int Restricted
```

แบบอักษรที่มีเพียงบิตนี้เท่านั้นต้องไม่ถูกแก้ไข, ฝัง หรือแลกเปลี่ยนในลักษณะใด ๆ หากไม่ได้รับอนุญาตจากเจ้าของกฎหมายก่อน

### PreviewPrint {#PreviewPrint}
```
public static final int PreviewPrint
```

เมื่อบิตนี้ถูกตั้งค่า, แบบอักษรสามารถฝังและโหลดชั่วคราวบนระบบระยะไกลได้ เอกสารที่มีแบบอักษร Preview & Print ต้องเปิดในโหมด "read-only;" ไม่สามารถแก้ไขเอกสารได้

### Editable {#Editable}
```
public static final int Editable
```

เมื่อบิตนี้ถูกตั้งค่า, แบบอักษรสามารถฝังได้แต่ต้องติดตั้งชั่วคราวบนระบบอื่นเท่านั้น ในทางตรงข้ามกับแบบอักษร Preview & Print, เอกสารที่มีแบบอักษร Editable สามารถเปิดเพื่ออ่านได้ การแก้ไขได้รับอนุญาตและการเปลี่ยนแปลงสามารถบันทึกได้

### NoSubsetting {#NoSubsetting}
```
public static final int NoSubsetting
```

เมื่อบิตนี้ถูกตั้งค่า, แบบอักษรจะไม่สามารถทำ subset ก่อนการฝังได้ การจำกัดการฝังอื่น ๆ ที่ระบุในบิต 0-3 และบิต 9 ก็จะนำมาใช้เช่นกัน

### BitmapOnly {#BitmapOnly}
```
public static final int BitmapOnly
```

เมื่อบิตนี้ถูกตั้งค่า, จะสามารถฝังได้เฉพาะบิตแมพที่อยู่ในแบบอักษรเท่านั้น ไม่สามารถฝังข้อมูลเส้นรอบรูปได้ หากแบบอักษรไม่มีบิตแมพใด ๆ ให้ถือว่าไม่สามารถฝังได้และบริการฝังจะล้มเหลว
