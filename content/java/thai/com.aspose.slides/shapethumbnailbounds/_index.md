### Slide {#Slide}
```
public static final int Slide
```

ภาพย่อของรูปร่างจะมีขนาดเท่ากับขนาดสไลด์. ตำแหน่งของรูปร่างจะถูกบันทึก.

### Shape {#Shape}
```
public static final int Shape
```

ภาพย่อของรูปร่างจะมีขนาดเท่ากับสี่เหลี่ยมขอบเขตของรูปร่างโดยพิจารณาการตั้งค่าขอบรูปร่าง.

### Appearance {#Appearance}
```
public static final int Appearance
```

ภาพย่อของรูปร่างจะมีขนาดเท่ากับการแสดงผลของรูปร่าง (อยู่ภายในขอบของสไลด์). มีกรณีที่การแสดงผลของรูปร่างไม่พอดีกับขอบเขตของรูปร่าง. เช่น การหมุน, การเชื่อมต่อมิตเตอร์ของมุมฉากเฉียบ, เอฟเฟกต์ 3 มิติ, เป็นต้น.
