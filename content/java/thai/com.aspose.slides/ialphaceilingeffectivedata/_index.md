[com.aspose.slides.IEffectEffectiveData](../../com.aspose.slides/ieffecteffectivedata)

```
public interface IAlphaCeilingEffectiveData extends IEffectEffectiveData
```

อ็อบเจ็กต์ที่ไม่เปลี่ยนแปลงซึ่งเป็นตัวแทนของเอฟเฟกต์ Alpha Ceiling. ค่า Alpha (ความทึบ) ที่มากกว่าศูนย์จะถูกเปลี่ยนเป็น 100%. อีกนัยหนึ่ง สิ่งใดที่มีความทึบบางส่วนจะกลายเป็นทึบเต็มที่.
