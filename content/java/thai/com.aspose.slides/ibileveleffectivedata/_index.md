อ็อบเจกต์ที่ไม่เปลี่ยนแปลงซึ่งแทนค่าเอฟเฟกต์ระดับสอง (black/white) สีอินพุตที่มีความสว่างน้อยกว่าค่าขีดจำกัดที่ระบุจะถูกเปลี่ยนเป็นสีดำ สีอินพุตที่มีความสว่างมากกว่าหรือเท่ากับค่าที่ระบุจะถูกตั้งเป็นสีขาว ค่าเอฟเฟกต์อัลฟ่าไม่ได้รับผลกระทบจากเอฟเฟกต์นี้.
