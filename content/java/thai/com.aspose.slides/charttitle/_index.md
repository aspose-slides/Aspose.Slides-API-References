### getTextFrameForOverriding() {#getTextFrameForOverriding--}
```
public final ITextFrame getTextFrameForOverriding()
```

สามารถประกอบด้วยข้อความที่จัดรูปแบบอย่างละเอียด หากค่าคุณสมบัตินี้ไม่เป็น null ข้อความที่จัดรูปแบบนี้จะทับข้อความที่สร้างอัตโนมัติ ข้อความที่สร้างอัตโนมัติเป็นคุณสมบัติแฝงของป้ายข้อมูล, ป้ายหน่วยแสดงของแกนค่า, ชื่อแกน, ชื่อแผนภูมิ, ป้ายของเส้นเทรนด์ ข้อความที่สร้างอัตโนมัติจัดรูปแบบด้วยคุณสมบัติ IFormattedTextContainer.TextFormat อ่านอย่างเดียว [ITextFrame](../../com.aspose.slides/itextframe).

**Returns:**  
[ITextFrame](../../com.aspose.slides/itextframe)
