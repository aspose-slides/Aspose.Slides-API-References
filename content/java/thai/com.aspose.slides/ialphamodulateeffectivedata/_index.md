```
public interface IAlphaModulateEffectiveData extends IEffectEffectiveData
```

อ็อบเจ็กต์ที่ไม่เปลี่ยนแปลงซึ่งเป็นตัวแทนของเอฟเฟกต์ Alpha Modulate. ค่า alpha (ความทึบ) ของเอฟเฟ็กต์จะถูกคูณด้วยเปอร์เซ็นต์คงที่. ตัวคอนเทนเนอร์ของเอฟเฟ็กต์ระบุเอฟเฟ็กต์ที่มีค่า alpha เพื่อทำการปรับเปลี่ยน.
