### AccentProcess {#AccentProcess}
```
public static final int AccentProcess
```

Utilisez pour afficher une progression, une frise chronologique ou des étapes séquentielles dans une tâche, un processus ou un flux de travail. Fonctionne bien pour illustrer à la fois le texte de niveau 1 et le texte de niveau 2.

### AccentedPicture {#AccentedPicture}
```
public static final int AccentedPicture
```

Utilisez pour afficher une idée photographique centrale avec des idées associées sur le côté. Le texte de niveau 1 supérieur apparaît au-dessus de l’image centrale. Le texte correspondant aux autres formes de niveau 1 apparaît à côté des petites images circulaires. Cette disposition fonctionne également bien sans texte.

### AlternatingFlow {#AlternatingFlow}
```
public static final int AlternatingFlow
```

Utilisez pour afficher des groupes d’informations ou des étapes séquentielles dans une tâche, un processus ou un flux de travail. Met en évidence l’interaction ou les relations entre les groupes d’informations.

### AlternatingHexagons {#AlternatingHexagons}
```
public static final int AlternatingHexagons
```

Utilisez pour représenter une série d’idées interconnectées. Le texte de niveau 1 apparaît à l’intérieur des hexagones. Le texte de niveau 2 apparaît à l’extérieur des formes.

### AlternatingPictureBlocks {#AlternatingPictureBlocks}

public static final int AlternatingPictureBlocks

```
public static final int ArrowRibbon

### AscendingPictureAccentProcess {#AscendingPictureAccentProcess}

public static final int AscendingPictureAccentProcess

### Balance {#Balance}
```
public static final int Balance
```

Utilisez pour comparer ou montrer la relation entre deux idées. Chacune des deux premières lignes du texte de niveau 1 correspond au texte en haut d’un côté du point central. Met l’accent sur le texte de niveau 2, limité à quatre formes de chaque côté du point central. L’équilibre penche du côté contenant le plus de formes avec du texte de niveau 2. Le texte inutilisé n’apparaît pas, mais reste disponible si vous changez de disposition.

### BasicPie {#BasicPie}
```
public static final int BasicPie

La forme du texte de niveau 1 supérieur apparaît à l’extérieur du reste du secteur pour le mettre en évidence. Le texte inutilisé n’apparaît pas, mais reste disponible si vous changez de disposition.

### BasicTarget {#BasicTarget}

public static final int BasicTarget
```

public static final int BasicTimeline

### BasicVenn {#BasicVenn}
```
public static final int BasicVenn
```

Utilisez pour afficher des relations qui se chevauchent ou s’interconnectent. Les sept premières lignes du texte de niveau 1 correspondent à un cercle. S’il y a quatre lignes ou moins de texte de niveau 1, le texte se trouve à l’intérieur des cercles. S’il y a plus de quatre lignes de texte de niveau 1, le texte se trouve à l’extérieur des cercles. Le texte inutilisé n’apparaît pas, mais reste disponible si vous changez de disposition.
