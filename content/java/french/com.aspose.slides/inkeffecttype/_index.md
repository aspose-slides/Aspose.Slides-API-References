```
public final class InkEffectType extends System.Enum
```

Spécifie un ensemble d'effets visuels prédéfinis pour le rendu d'encre. Chaque effet correspond à une texture ou à une image qui simule une apparence d'encre stylisée. Ces valeurs peuvent être utilisées pour personnaliser le style visuel des traits d'encre numériques lors du rendu.
## Champs

| Champ | Description |
| --- | --- |
| [NotDefined](#NotDefined) | L'effet n'est pas défini ou est inconnu. |
| [Bronze](#Bronze) | Une texture métallique chaude et brunâtre ressemblant à de l'encre bronze. |
| [Galaxy](#Galaxy) | Une texture colorée et scintillante rappelant une galaxie, avec des tons cosmiques. |
| [Gold](#Gold) | Une texture métallique dorée brillante qui donne aux traits d'encre une apparence luxueuse. |
| [Lava](#Lava) | Une texture flamboyante rappelant de la lave en fusion, avec des teintes rouges et oranges. |
| [Ocean](#Ocean) | Une texture bleu profond, fluide, qui imite les vagues de l'océan ou l'encre à base d'eau. |
| [RainbowGlitter](#RainbowGlitter) | Un effet de paillettes arc-en-ciel coloré et scintillant utilisé pour des traits d'encre festifs ou vibrants. |
| [RoseGold](#RoseGold) | Un mélange doux de rose et d’or, similaire à l’or rose, pour des traits d’encre élégants. |
| [Silver](#Silver) | Une texture métallique argentée froide qui simule l’encre argent classique. |
