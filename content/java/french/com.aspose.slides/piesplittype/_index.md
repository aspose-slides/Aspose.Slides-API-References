Représente un type de points de division dans le deuxième secteur ou barre d’un graphique secteur-dans-secteur ou barre-dans-secteur.

## Champs

| Champ | Description |
| --- | --- |
| [Default](#Default) | Spécifie que les points de données doivent être divisés en utilisant le mécanisme par défaut pour ce type de graphique. |
| [Custom](#Custom) | Spécifie que les points de données doivent être divisés entre le secteur et le deuxième graphique selon les valeurs de division personnalisées. |
| [ByPercentage](#ByPercentage) | Spécifie que les points de données doivent être divisés entre le secteur et le deuxième graphique en plaçant les points dont le pourcentage est inférieur à Split Position percent dans le deuxième graphique. |
| [ByPos](#ByPos) | Spécifie que les points de données doivent être divisés entre le secteur et le deuxième graphique en plaçant la dernière Split Position des points de données dans le deuxième graphique. |
| [ByValue](#ByValue) | Spécifie que les points de données doivent être divisés entre le secteur et le deuxième graphique en plaçant les points de données dont la valeur est inférieure à Split Position dans le deuxième graphique. |
