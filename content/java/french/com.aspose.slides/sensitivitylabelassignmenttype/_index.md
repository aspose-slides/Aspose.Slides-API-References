Représente la méthode d'affectation du libellé de sensibilité.
## Champs

| Champ | Description |
| --- | --- |
| [Standard](#Standard) | À utiliser pour tout libellé de sensibilité qui n’a pas été appliqué directement par l’utilisateur. |
| [Privileged](#Privileged) | À utiliser pour tout libellé de sensibilité qui a été appliqué directement par l’utilisateur. |
### Standard {#Standard}
```
public static final int Standard
```

À utiliser pour tout libellé de sensibilité qui n’a pas été appliqué directement par l’utilisateur. Cela inclut tous les libellés par défaut, les libellés appliqués automatiquement.

### Privileged {#Privileged}
```
public static final int Privileged
```

À utiliser pour tout libellé de sensibilité qui a été appliqué directement par l’utilisateur. Cette catégorie comprend tous les libellés de sensibilité appliqués manuellement ainsi que le marquage recommandé ou obligatoire ou toute fonctionnalité où l'utilisateur décide du libellé de sensibilité à appliquer.
