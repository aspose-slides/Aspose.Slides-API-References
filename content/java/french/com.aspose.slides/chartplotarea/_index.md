### getLayoutTargetType() {#getLayoutTargetType--}
```
public final int getLayoutTargetType()
```

Si la mise en page de la zone de tracé est définie manuellement, cette propriété indique si la mise en page doit être effectuée à l’intérieur (sans les axes et les libellés d’axes) ou à l’extérieur (avec les axes et les libellés d’axes). Lecture/écriture [LayoutTargetType](../../com.aspose.slides/layouttargettype)(\#getLayoutTargetType.getLayoutTargetType/\#setLayoutTargetType(int).setLayoutTargetType(int)).

--------------------

> Presentation presentation = new Presentation();
>   try
>   {
>       ISlide slide = presentation.getSlides().get_Item(0);
>       IChart chart = slide.getShapes().addChart(ChartType.ClusteredColumn, 20, 100, 600, 400);
>       chart.getPlotArea().setX(0.2f);
>       chart.getPlotArea().setY(0.2f);
>       chart.getPlotArea().setWidth(0.7f);
>       chart.getPlotArea().setHeight(0.7f);
