Spécifie l'état dans lequel la barre de séparation doit être affichée. La barre de séparation sépare une région principale et une région secondaire dans une zone d'affichage.
## Champs

| Champ | Description |
| --- | --- |
| [Minimized](#Minimized) | La région principale occupe la plus petite partie de l'espace d'affichage autorisée par l'application. |
| [Restored](#Restored) | La région principale a une taille intermédiaire spécifique. |
| [Maximized](#Maximized) | La région principale occupe la plus grande partie de l'espace d'affichage autorisée par l'application. |
