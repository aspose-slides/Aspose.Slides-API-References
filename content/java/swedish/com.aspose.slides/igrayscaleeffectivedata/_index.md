```
public interface IGrayScaleEffectiveData extends IEffectEffectiveData
```

Oföränderligt objekt som representerar en Gray Scale effect. Konverterar alla effektfärgvärden till en nyans av gray, motsvarande deras luminance. Effekt alpha (opacity) värden påverkas inte.
