### getTextFrameForOverriding() {#getTextFrameForOverriding--}
```
public final ITextFrame getTextFrameForOverriding()
```

Kan innehålla en rikformatterad text. Om detta egenskap inte är null åsidosätter det formaterade textvärdet den automatiskt genererade texten. Den automatiskt genererade texten är en underförstådd egenskap för dataetiketten, displayenheten för värdeaxeln, axelrubriken, diagramrubriken, trendlänks etikett. Den automatiskt genererade texten formateras med IFormattedTextContainer.TextFormat-egenskapen. Läs-endast [ITextFrame](../../com.aspose.slides/itextframe).

**Returnerar:**
[ITextFrame](../../com.aspose.slides/itextframe)
