public interface IHeadingPair
```

Representerar en 'rubrikpar'-egenskap i dokumentet. Det anger gruppnamnet för dokumentdelar och antalet delar i gruppen.
## Metoder

| Metod | Beskrivning |
| --- | --- |
| [getName()](#getName--) | Returnerar gruppnamnet för dokumentdelar. |
| [getCount()](#getCount--) | Returnerar antalet delar i gruppen. |
### getName() {#getName--}
```
public abstract String getName()
```

**Returnerar:**
java.lang.String
### getCount() {#getCount--}
```
public abstract int getCount()
```
