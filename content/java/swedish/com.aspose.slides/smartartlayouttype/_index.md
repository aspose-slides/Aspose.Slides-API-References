### AccentProcess {#AccentProcess}
```
public static final int AccentProcess
```

Använd för att visa en progression, en tidslinje eller sekventiella steg i en uppgift, process eller arbetsflöde. Fungerar bra för att illustrera både Level 1 och Level 2 text.

### AccentedPicture {#AccentedPicture}
```
public static final int AccentedPicture
```

Använd för att visa en central, fotografisk idé med relaterade idéer i sidan. Den översta Level 1-texten visas över den centrala bilden. Motsvarande text för andra Level 1-former visas bredvid de små cirkulära bilderna. Denna layout fungerar också bra utan text.

### AlternatingFlow {#AlternatingFlow}
```
public static final int AlternatingFlow
```

Använd för att visa grupper av information eller sekventiella steg i en uppgift, process eller arbetsflöde. Betonar interaktionen eller relationerna mellan informationsgrupperna.

### AlternatingHexagons {#AlternatingHexagons}
```
public static final int AlternatingHexagons
```

Använd för att representera en serie av sammankopplade idéer. Level 1-text visas inuti hexagonerna. Level 2-text visas utanför formerna.

### AlternatingPictureBlocks {#AlternatingPictureBlocks}
```
public static final int AlternatingPictureBlocks
```

Använd för att visa en serie bilder från toppen till botten. Text visas växelvis till höger eller vänster om bilden.

### AlternatingPictureCircles {#AlternatingPictureCircles}
```
public static final int AlternatingPictureCircles
```

Använd för att visa ett set av bilder med text. Motsvarande text visas i de centrala cirklarna med bilderna som alternerar från vänster till höger.

### ArrowRibbon {#ArrowRibbon}
```
public static final int ArrowRibbon
```

Använd för att visa antingen relaterade eller kontrasterande koncept med någon förbindelse, till exempel motsatta krafter. De två första raderna av Level 1-text används för text i pilarna. Oanvänd text visas inte, men förblir tillgänglig om du byter layout.

### AscendingPictureAccentProcess {#AscendingPictureAccentProcess}
```
public static final int AscendingPictureAccentProcess
```

Använd för att visa en stigande serie av bilder med beskrivande text. Fungerar bäst med en liten mängd text.

### Balance {#Balance}
```
public static final int Balance
```

Använd för att jämföra eller visa relationen mellan två idéer. Varje av de två första raderna av Level 1-text motsvarar text högst upp på en sida av mittpunkten. Betonar Level 2-text, som är begränsad till fyra former på varje sida av mittpunkten. Balansen tippar åt den sida som har flest former med Level 2-text. Oanvänd text visas inte, men förblir tillgänglig om du byter layout.

### BasicBendingProcess {#BasicBendingProcess}
```
public static final int BasicBendingProcess
```

Använd för att visa en progression eller sekventiella steg i en uppgift, process eller arbetsflöde. Maximerar både horisontellt och vertikalt utrymme för former.

### BasicBlockList {#BasicBlockList}

```
public static final int BasicBlockList
```

### BasicChevronProcess {#BasicChevronProcess}
```
public static final int BasicChevronProcess
```

Använd för att visa en progression; en tidslinje; sekventiella steg i en uppgift, process eller arbetsflöde; eller för att betona rörelse eller riktning. Level 1-text visas inuti en pilform medan Level 2-text visas under pilformerna.

### BasicCycle {#BasicCycle}
```
public static final int BasicCycle
```

### BasicMatrix {#BasicMatrix}
```
public static final int BasicMatrix
```

Använd för att visa komponenternas förhållande till en helhet i kvadranter. De fyra första raderna av Level 1-text visas i kvadranterna. Oanvänd text visas inte, men förblir tillgänglig om du byter layout.

### BasicPie {#BasicPie}
```
public static final int BasicPie
```

Använd för att visa hur enskilda delar bildar en helhet. De sju första raderna av Level 1-text motsvarar de jämnt fördelade kil- eller pajformerna. Den översta Level 1-textformen visas utanför resten av pajen för betoning. Oanvänd text visas inte, men förblir tillgänglig om du byter layout.

### BasicProcess {#BasicProcess}

### BasicPyramid {#BasicPyramid}

```
public static final int BasicPyramid
```

### BasicRadial {#BasicRadial}
```
public static final int BasicRadial
```

Använd för att visa relationen till en central idé i en cykel. Den första raden av Level 1-text motsvarar den centrala formen, och dess Level 2-text motsvarar de omgivande cirkulära formerna. Oanvänd text visas inte, men förblir tillgänglig om du byter layout.

### BasicTarget {#BasicTarget}
```
public static final int BasicTarget
```

### BasicTimeline {#BasicTimeline}
```
public static final int BasicTimeline
```

### BasicVenn {#BasicVenn}
```
public static final int BasicVenn
```

Använd för att visa överlappande eller sammankopplade relationer. De sju första raderna av Level 1-text motsvarar en cirkel. Om det finns fyra eller färre rader av Level 1-text är texten inuti cirklarna. Om det finns fler än fyra rader är texten utanför cirklarna. Oanvänd text visas inte, men förblir tillgänglig om du byter layout.
