```
public interface IGrayScaleEffectiveData extends IEffectEffectiveData
```

不変オブジェクトで、グレースケール効果を表します。効果のカラー値すべてを、その輝度に対応するグレーの色調に変換します。効果のアルファ（不透明度）値は影響を受けません。
