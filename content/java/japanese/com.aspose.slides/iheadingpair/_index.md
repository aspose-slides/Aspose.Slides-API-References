public interface IHeadingPair
```

ドキュメントの『Heading pair』プロパティを表します。これは、ドキュメント パーツのグループ名とグループ内のパーツ数を示します。
## メソッド

| メソッド | 説明 |
| --- | --- |
| [getName()](#getName--) | ドキュメント パーツのグループ名を返します。 |
| [getCount()](#getCount--) | グループ内のパーツ数を返します。 |
### getName() {#getName--}
```
public abstract String getName()
```


ドキュメント パーツのグループ名を返します。読み取り専用 String。

**戻り値:**
java.lang.String
### getCount() {#getCount--}
```
public abstract int getCount()
```


グループ内のパーツ数を返します。読み取り専用 int。

**戻り値:**
int
