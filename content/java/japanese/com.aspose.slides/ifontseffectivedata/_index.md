public interface IFontsEffectiveData
```

有効フォントセットを含む不変オブジェクトです。

--------------------

このインターフェイスは [IBasePortionFormatEffectiveData](../../com.aspose.slides/ibaseportionformateffectivedata) と [IFontSchemeEffectiveData](../../com.aspose.slides/ifontschemeeffectivedata) インターフェイスの一部として使用されます。
## メソッド

| メソッド | 説明 |
| --- | --- |
| [getLatinFont()](#getLatinFont--) | Latin フォントを返します。 |
| [getEastAsianFont()](#getEastAsianFont--) | East Asian フォントを返します。 |
| [getComplexScriptFont()](#getComplexScriptFont--) | 複合スクリプトフォントを返します。 |
### getLatinFont() {#getLatinFont--}
```
public abstract IFontData getLatinFont()
```
