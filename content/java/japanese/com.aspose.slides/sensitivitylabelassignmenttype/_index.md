感度ラベルの割り当て方法を表します。
## フィールド

| フィールド | 説明 |
| --- | --- |
| [Standard](#Standard) | ユーザーが直接適用しなかったすべての感度ラベルに使用します。 |
| [Privileged](#Privileged) | ユーザーが直接適用したすべての感度ラベルに使用します。 |
### 標準 {#Standard}
```
public static final int Standard
```

ユーザーが直接適用しなかったすべての感度ラベルに使用します。これには、デフォルトラベルや自動的に適用されるラベルが含まれます。

### 特権 {#Privileged}
```
public static final int Privileged
```

ユーザーが直接適用したすべての感度ラベルに使用します。これには、手動で適用された感度ラベルの他、推奨または必須のラベリング、またはユーザーが適用する感度ラベルを決定する機能が含まれます。
