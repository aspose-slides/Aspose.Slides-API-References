インク描画のための事前定義されたビジュアルエフェクトのセットを指定します。各エフェクトは、スタイライズされたインクの外観をシミュレートするテクスチャまたは画像に対応しています。これらの値は、描画時にデジタルインクストロークのビジュアルスタイルをカスタマイズするために使用できます。

## フィールド

| フィールド | 説明 |
| --- | --- |
| [NotDefined](#NotDefined) | エフェクトは定義されていないか、未知です。 |
| [Bronze](#Bronze) | 青銅インクに似た、暖かく茶みがかった金属テクスチャです。 |
| [Galaxy](#Galaxy) | 銀河に似た、カラフルで煌めくテクスチャ、宇宙的な色調です。 |
| [Gold](#Gold) | 鮮やかで金属的な金色のテクスチャで、インクストロークに豪華な外観を与えます。 |
| [Lava](#Lava) | 溶岩のような燃えるテクスチャで、赤とオレンジの色合いがあります。 |
| [Ocean](#Ocean) | 深い青色の流体のようなテクスチャで、海の波や水性インクを模倣します。 |
| [RainbowGlitter](#RainbowGlitter) | 祭りや鮮やかなインクストロークに使用される、カラフルできらめく虹色のグリッターエフェクトです。 |
| [RoseGold](#RoseGold) | ローズゴールドに似た、柔らかなピンクとゴールドのブレンドで、エレガントなインクストロークに適しています。 |
| [Silver](#Silver) | クラシックなシルバーインクをシミュレートする、クールな金属シルバーのテクスチャです。 |
