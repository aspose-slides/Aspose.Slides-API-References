public interface IAlphaModulateEffectiveData extends IEffectEffectiveData

Alpha Modulate エフェクトを表す不変オブジェクトです。エフェクトの alpha (不透明度) 値は固定パーセンテージで乗算されます。エフェクトコンテナは、調整する alpha 値を含むエフェクトを指定します。
