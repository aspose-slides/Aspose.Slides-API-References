形状に割り当てられたスケッチタイプまたはエフェクトを表します。
## フィールド

| フィールド | 説明 |
| --- | --- |
| [NotDefined](#NotDefined) | 形状のスケッチエフェクトが未定義であることを指定します。 |
| [None](#None) | 形状にスケッチエフェクトがないことを指定します。 |
| [Curved](#Curved) | 形状が Curved エフェクトを持つことを指定します。このエフェクトは形状の各エッジを大きな滑らかな曲線に変えます。 |
| [Freehand](#Freehand) | 形状が Freehand エフェクトを持つことを指定します。このエフェクトは不完全に描かれた線に最も近い形です。 |
| [Scribble](#Scribble) | 形状が Scribble エフェクトを持つことを指定します。このエフェクトは意図的に乱れたように描かれた、誇張された振動を伴います。 |
