パイ・オブ・パイまたはバー・オブ・バー グラフの第2の円または棒における分割ポイントのタイプを表します。

## フィールド

| フィールド | 説明 |
| --- | --- |
| [Default](#Default) | このチャートタイプのデフォルトのメカニズムを使用してデータポイントを分割することを指定します。 |
| [Custom](#Custom) | カスタム分割値に従って、パイと第2のチャート間でデータポイントを分割することを指定します。 |
| [ByPercentage](#ByPercentage) | Split Position パーセンテージ未満のポイントを第2のチャートに配置することで、パイと第2のチャート間でデータポイントを分割することを指定します。 |
| [ByPos](#ByPos) | データポイントの最後の Split Position を第2のチャートに配置することで、パイと第2のチャート間でデータポイントを分割することを指定します。 |
| [ByValue](#ByValue) | Split Position 未満の値を持つデータポイントを第2のチャートに配置することで、パイと第2のチャート間でデータポイントを分割することを指定します。 |
