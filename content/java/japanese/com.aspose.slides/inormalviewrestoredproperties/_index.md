public interface INormalViewRestoredProperties
```

スライド領域のサイズ（幅が restoredTop の子、height が restoredLeft の子）を、通常ビューで、領域が可変の復元サイズ（最小化でも最大化でもない）である場合に指定します。

## メソッド

| メソッド | 説明 |
| --- | --- |
| [getDimensionSize()](#getDimensionSize--) | スライド領域のサイズ（幅が RestoredTop の子、height が RestoredLeft の子）を指定します。 |
| [setDimensionSize(float value)](#setDimensionSize-float-) | スライド領域のサイズ（幅が RestoredTop の子、height が RestoredLeft の子）を指定します。 |
| [getAutoAdjust()](#getAutoAdjust--) | ウィンドウ内のビューを含むアプリケーションでウィンドウサイズを変更する際に、サイドコンテンツ領域のサイズが新しいサイズを補正すべきかどうかを指定します。Read/write boolean. |
| [setAutoAdjust(boolean value)](#setAutoAdjust-boolean-) | ウィンドウ内のビューを含むアプリケーションでウィンドウサイズを変更する際に、サイドコンテンツ領域のサイズが新しいサイズを補正すべきかどうかを指定します。Read/write boolean. |
