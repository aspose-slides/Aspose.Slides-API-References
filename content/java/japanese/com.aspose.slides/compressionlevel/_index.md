OpenXML ファイルの ZIP 圧縮レベルを指定します。レベルが高いほど、圧縮率は向上しますが、処理速度が遅くなります。
## フィールド

| フィールド | 説明 |
| --- | --- |
| [None](#None) | 圧縮は適用されません。 |
| [Level1](#Level1) | 最も低い圧縮率で最速の圧縮です。 |
| [Level2](#Level2) | [Level1](../../com.aspose.slides/compressionlevel\#Level1) よりわずかに高い圧縮率で、より速い圧縮です。 |
| [Level3](#Level3) | [Level2](../../com.aspose.slides/compressionlevel\#Level2) より良い圧縮率を提供しますが、パフォーマンスへの影響は中程度です。 |
| [Level4](#Level4) | [Level3](../../com.aspose.slides/compressionlevel\#Level3) より良い圧縮率を提供します。 |
| [Level5](#Level5) | [Level4](../../com.aspose.slides/compressionlevel\#Level4) より改善された圧縮率を提供しますが、処理時間が増加します。 |
| [Level6](#Level6) | 標準的な圧縮で、圧縮速度とファイルサイズのバランスが適切です。 |
| [Level7](#Level7) | [Level6](../../com.aspose.slides/compressionlevel\#Level6) より高い圧縮率を提供しますが、処理は遅くなります。 |
| [Level8](#Level8) | [Level7](../../com.aspose.slides/compressionlevel\#Level7) より高い圧縮率を提供します。 |
| [Level9](#Level9) | 最大の圧縮率です。 |
