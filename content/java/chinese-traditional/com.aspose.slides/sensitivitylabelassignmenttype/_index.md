表示敏感度標籤的指派方式。
## 欄位

| 欄位 | 說明 |
| --- | --- |
| [Standard](#Standard) | 用於任何未由使用者直接套用的敏感度標籤。 |
| [Privileged](#Privileged) | 用於任何由使用者直接套用的敏感度標籤。 |
### 標準 {#Standard}
```
public static final int Standard
```

用於任何未由使用者直接套用的敏感度標籤。這包括任何預設標籤、以及自動套用的標籤。

### 特權 {#Privileged}
```
public static final int Privileged
```

用於任何由使用者直接套用的敏感度標籤。這包括任何手動套用的敏感度標籤，以及建議或強制標記，或任何讓使用者決定套用哪個敏感度標籤的功能。
