指定數學段落的對齊方式（同一段落內相鄰的數學文字實例的系列）

## 欄位

| 欄位 | 說明 |
| --- | --- |
| [LeftJustified](#LeftJustified) | 將數學文字對齊到左側 |
| [RightJustified](#RightJustified) | 將數學文字對齊到右側 |
| [Centered](#Centered) | 將數學文字對齊到中間 |
| [CenteredAsGroup](#CenteredAsGroup) | 將整個數學區塊組在頁面上置中，作為一個單位。 |

### CenteredAsGroup {#CenteredAsGroup}
```

```

將整個數學區塊組在頁面上置中，作為一個單位。這表示數學文字的實例可以相互對齊，但整個數學文字組會整體置中。
