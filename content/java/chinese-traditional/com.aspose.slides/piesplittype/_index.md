表示在餅圖中之餅圖或條形圖的第二個餅圖或條形圖的分割點類型。
## 欄位

| 欄位 | 說明 |
| --- | --- |
| [Default](#Default) | 指定資料點應使用此圖表類型的預設機制進行分割。 |
| [Custom](#Custom) | 指定資料點應根據自訂分割值在餅圖與第二張圖表之間進行分割。 |
| [ByPercentage](#ByPercentage) | 指定資料點應透過將百分比低於 Split Position 百分比的點放入第二張圖表，從而在餅圖與第二張圖表之間進行分割。 |
| [ByPos](#ByPos) | 指定資料點應將最後的 Split Position 放入第二張圖表，從而在餅圖與第二張圖表之間進行分割。 |
| [ByValue](#ByValue) | 指定資料點應將值低於 Split Position 的資料點放入第二張圖表，從而在餅圖與第二張圖表之間進行分割。 |
