矩陣欄位之間的間隙（水平間距）類型
## 欄位

| 欄位 | 說明 |
| --- | --- |
| [SingleSpacingGap](#SingleSpacingGap) | 單一（欄位 1 em 或 列 1 行） |
| [OneAndHalfSpacingGap](#OneAndHalfSpacingGap) | 一個半（欄位 1.5 em 或 列 1.5 行） |
| [DoubleSpacingGap](#DoubleSpacingGap) | 雙倍間距（欄位 2 em 或 列 2 行） |
| [Exactly](#Exactly) | 確切值；對於欄位，依賴 ColumnGap 的值，以 twips 為單位；對於列，依賴 RowGap 的值，以 twips 為單位 |
| [Multiple](#Multiple) | 多重；對於欄位，依賴 ColumnGap 的值，以 0.5 em 為增量；對於列，依賴 RowGap 的值，以行為單位 |
