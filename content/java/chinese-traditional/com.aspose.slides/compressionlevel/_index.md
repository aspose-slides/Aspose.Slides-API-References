指定 OpenXML 檔案的 ZIP 壓縮等級。較高的等級可提供更佳的壓縮效果，但會以較慢的處理速度為代價。

## 欄位

| 欄位 | 描述 |
| --- | --- |
| [None](#None) | 未套用壓縮。 |
| [Level1](#Level1) | 最快的壓縮，壓縮比最低。 |
| [Level2](#Level2) | 較 [Level1](../../com.aspose.slides/compressionlevel\#Level1) 稍佳的壓縮比，壓縮速度較快。 |
| [Level3](#Level3) | 在適度的效能影響下，提供比 [Level2](../../com.aspose.slides/compressionlevel\#Level2) 更好的壓縮。 |
| [Level4](#Level4) | 提供比 [Level3](../../com.aspose.slides/compressionlevel\#Level3) 更好的壓縮。 |
| [Level5](#Level5) | 相比 [Level4](../../com.aspose.slides/compressionlevel\#Level4)，在額外的處理時間下提供改進的壓縮。 |
| [Level6](#Level6) | 標準壓縮，提供壓縮速度與檔案大小之間的良好平衡。 |
| [Level7](#Level7) | 在較慢的處理下，提供比 [Level6](../../com.aspose.slides/compressionlevel\#Level6) 更高的壓縮。 |
| [Level8](#Level8) | 提供比 [Level7](../../com.aspose.slides/compressionlevel\#Level7) 更高的壓縮。 |
| [Level9](#Level9) | 最高壓縮。 |
