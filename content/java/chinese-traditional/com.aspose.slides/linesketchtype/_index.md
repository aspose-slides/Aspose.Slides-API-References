表示已指派給形狀的素描類型或效果。
## 欄位

| 欄位 | 描述 |
| --- | --- |
| [NotDefined](#NotDefined) | 指定形狀的素描效果為未定義。 |
| [None](#None) | 指定形狀沒有素描效果。 |
| [Curved](#Curved) | 指定形狀具有彎曲效果，該效果會將形狀的每條邊緣轉變為一條大的柔和曲線。 |
| [Freehand](#Freehand) | 指定形狀具有手繪效果，最接近於不完美的手繪線條。 |
| [Scribble](#Scribble) | 指定形狀具有塗鴉效果，呈現誇張的振盪，彷彿刻意隨意地繪製。 |
