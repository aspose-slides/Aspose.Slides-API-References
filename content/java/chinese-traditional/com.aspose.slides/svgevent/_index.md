## 欄位

| 欄位 | 說明 |

| [OnFocusIn](#OnFocusIn) | 當元素獲得焦點時發生，例如文字被選取時。 |

| [OnError](#OnError) | 當元素未正確載入或腳本執行期間發生錯誤時發生。 |

| [OnScroll](#OnScroll) | 當文件檢視在 X 軸、Y 軸或兩者同時平移時發生。 |
| [OnZoom](#OnZoom) | 當文件檢視的縮放比例變更時發生。 |
| [OnBegin](#OnBegin) | 當動畫元素開始時發生。 |
| [OnEnd](#OnEnd) | 當動畫元素結束時發生。 |
| [OnRepeat](#OnRepeat) | 當動畫元素重複時發生。 |
