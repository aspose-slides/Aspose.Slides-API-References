指定一組預先定義的墨跡渲染視覺效果。每種效果對應於模擬風格化墨跡外觀的紋理或圖像。這些值可用於在渲染過程中自訂數位墨跡筆畫的視覺樣式。

## 欄位

| 欄位 | 說明 |
| --- | --- |
| [NotDefined](#NotDefined) | 此效果未定義或未知。 |
| [Bronze](#Bronze) | 類似青銅墨水的暖色棕色金屬紋理。 |
| [Galaxy](#Galaxy) | 類似銀河的多彩閃爍紋理，帶有宇宙色調。 |
| [Gold](#Gold) | 明亮的金屬金紋理，使墨跡呈現奢華外觀。 |
| [Lava](#Lava) | 類似熔岩的炙熱紋理，具有紅色和橙色的色調。 |
| [Ocean](#Ocean) | 深藍色、類液態的紋理，模仿海浪或水性墨水。 |
| [RainbowGlitter](#RainbowGlitter) | 多彩、閃亮的彩虹亮粉效果，用於節慶或充滿活力的墨跡。 |
| [RoseGold](#RoseGold) | 柔和的粉金色混合，類似玫瑰金，適用於優雅的墨跡。 |
| [Silver](#Silver) | 冷色調的金屬銀紋理，模擬經典的銀色墨水。 |
