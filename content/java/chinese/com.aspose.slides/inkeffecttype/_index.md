指定一组预定义的可视化效果用于墨迹渲染。每种效果对应一种纹理或图像，用以模拟风格化的墨水外观。这些值可用于在渲染过程中自定义数字墨迹笔画的视觉样式。
## 字段

| 字段 | 描述 |
| --- | --- |
| [NotDefined](#NotDefined) | 效果未定义或未知。 |
| [Bronze](#Bronze) | 温暖的棕色金属纹理，类似青铜墨水。 |
| [Galaxy](#Galaxy) | 多彩的闪耀纹理，类似星系，带有宇宙色调。 |
| [Gold](#Gold) | 明亮的金属金色纹理，使墨迹笔画呈现奢华外观。 |
| [Lava](#Lava) | 炽热的纹理，类似熔岩，带有红色和橙色色调。 |
| [Ocean](#Ocean) | 深蓝色的流体纹理，模拟海浪或水基墨水。 |
| [RainbowGlitter](#RainbowGlitter) | 多彩的闪耀彩虹亮粉效果，用于节日或鲜艳的墨迹笔画。 |
| [RoseGold](#RoseGold) | 柔和的粉金色混合，类似玫瑰金，适用于优雅的墨迹笔画。 |
| [Silver](#Silver) | 冷峻的金属银色纹理，模拟经典银色墨水。 |
