```
public interface IAlphaCeilingEffectiveData extends IEffectEffectiveData
```

不可变对象，表示 Alpha Ceiling 效果。Alpha（不透明度）值大于零时会被更改为 100%。换句话说，任何部分不透明的内容都会变为完全不透明。
