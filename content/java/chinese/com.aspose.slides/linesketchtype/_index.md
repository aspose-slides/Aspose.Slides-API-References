表示已为形状分配的草图类型或效果。

## 字段

| 字段 | 描述 |
| --- | --- |
| [NotDefined](#NotDefined) | 指定形状的 Sketch 效果未定义。 |
| [None](#None) | 指定形状没有 Sketch 效果。 |
| [Curved](#Curved) | 指定形状具有 Curved 效果，可将形状的每条边转换为一个大的柔和曲线。 |
| [Freehand](#Freehand) | 指定形状具有 Freehand 效果，最接近手绘的非完美线条。 |
| [Scribble](#Scribble) | 指定形状具有 Scribble 效果，表现出夸张的摆动，好像故意画得凌乱。 |
