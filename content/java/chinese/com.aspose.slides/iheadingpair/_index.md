public interface IHeadingPair
```

表示文档的“Heading pair”属性。它指示文档部件的组名以及组中部件的数量。

## 方法

| 方法 | 描述 |
| --- | --- |
| [getName()](#getName--) | 返回文档部件的组名。 |
| [getCount()](#getCount--) | 返回组中部件的数量。 |

### getName() {#getName--}
```
public abstract String getName()
```

返回文档部件的组名。只读 String.

**返回：**
java.lang.String

### getCount() {#getCount--}
```
public abstract int getCount()
```

返回组中部件的数量。只读 int.

**返回：**
int
