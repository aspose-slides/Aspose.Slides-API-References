代表灵敏度标签的分配方法。
## 字段

| 字段 | 描述 |
| --- | --- |
| [Standard](#Standard) | 用于任何未被用户直接应用的灵敏度标签。 |
| [Privileged](#Privileged) | 用于任何被用户直接应用的灵敏度标签。 |
### 标准 {#Standard}
```
public static final int Standard
```

用于任何未被用户直接应用的灵敏度标签。这包括所有默认标签和自动应用的标签。

### 特权 {#Privileged}
```
public static final int Privileged
```

用于任何被用户直接应用的灵敏度标签。这包括所有手动应用的灵敏度标签以及推荐或强制的标记，或任何由用户决定使用哪个灵敏度标签的功能。
