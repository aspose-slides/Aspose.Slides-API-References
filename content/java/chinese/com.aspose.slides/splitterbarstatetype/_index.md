指定分割条应显示的状态。分割条在查看区域内将主区域和次要区域分开。

## 字段

| 字段 | 描述 |
| --- | --- |
| [Minimized](#Minimized) | 主区域占据应用允许的最小查看区域。 |
| [Restored](#Restored) | 主区域具有特定的中等大小。 |
| [Maximized](#Maximized) | 主区域占据应用允许的最大查看区域。 |
