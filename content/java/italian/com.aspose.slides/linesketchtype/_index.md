Rappresenta il tipo di schizzo o l'effetto assegnato a una forma.
## Campi

| Campo | Descrizione |
| --- | --- |
| [NotDefined](#NotDefined) | Specifica che l'effetto Sketch di una forma è indefinito. |
| [None](#None) | Specifica che una forma non ha alcun effetto Sketch. |
| [Curved](#Curved) | Specifica che una forma ha l'effetto Curved, che trasforma ogni bordo della forma in una grande curva dolce. |
| [Freehand](#Freehand) | Specifica che una forma ha l'effetto Freehand, che assomiglia più da vicino a una linea disegnata in modo imperfetto. |
| [Scribble](#Scribble) | Specifica che una forma ha l'effetto Scribble, che presenta un'oscillazione esagerata come se fosse disegnata intenzionalmente in modo confuso. |
### NotDefined {#NotDefined}
