Se il layout dell'area del grafico è definito manualmente, questa proprietà specifica se il layout dell'area del grafico deve avvenire al suo interno (escludendo gli assi e le etichette degli assi) o all'esterno (includendo gli assi e le etichette degli assi).
## Campi

| Field | Description |
| --- | --- |
| [Inner](#Inner) | Specifica che le dimensioni dell'area del grafico determinano le dimensioni dell'area del grafico, escludendo i segni di spunta e le etichette degli assi. |
| [Outer](#Outer) | Specifica che le dimensioni dell'area del grafico determinano le dimensioni dell'area del grafico, i segni di spunta e le etichette degli assi. |
### Inner {#Inner}
```
public static final int Inner
```

Specifică che le dimensioni dell'area del grafico determinano le dimensioni dell'area del grafico, escludendo i segni di spunta e le etichette degli assi.

### Outer {#Outer}
```
public static final int Outer
```

Specifică che le dimensioni dell'area del grafico determinano le dimensioni dell'area del grafico, i segni di spunta e le etichette degli assi.
