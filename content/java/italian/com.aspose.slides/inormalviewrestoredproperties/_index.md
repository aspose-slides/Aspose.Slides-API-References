public interface INormalViewRestoredProperties
```

Specifica le dimensioni della regione della diapositiva ((larghezza quando è un figlio di restoredTop, altezza quando è un figlio di restoredLeft) della visualizzazione normale, quando la regione è di una dimensione ripristinata variabile (né minimizzata né massimizzata).
## Metodi

| Metodo | Descrizione |
| --- | --- |
| [getDimensionSize()](#getDimensionSize--) | Specifica le dimensioni della regione della diapositiva (larghezza quando è un figlio di RestoredTop, altezza quando è un figlio di RestoredLeft). |
| [setDimensionSize(float value)](#setDimensionSize-float-) | Specifica le dimensioni della regione della diapositiva (larghezza quando è un figlio di RestoredTop, altezza quando è un figlio di RestoredLeft). |
| [getAutoAdjust()](#getAutoAdjust--) | Specifica se le dimensioni della regione di contenuto laterale devono compensare la nuova dimensione durante il ridimensionamento della finestra contenente la visualizzazione nell'applicazione Lettura/Scrittura boolean. |
| [setAutoAdjust(boolean value)](#setAutoAdjust-boolean-) | Specifica se le dimensioni della regione di contenuto laterale devono compensare la nuova dimensione durante il ridimensionamento della finestra contenente la visualizzazione nell'applicazione Lettura/Scrittura boolean. |
