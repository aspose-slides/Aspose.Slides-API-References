```
public interface IAlphaFloor extends IImageTransformOperation, IAccessiblePVIObject<IAlphaFloorEffectiveData>
```

Rappresenta un effetto Alpha Floor. I valori di Alpha (opacità) inferiori al 100% vengono impostati a zero. In altre parole, tutto ciò che è parzialmente trasparente diventa completamente trasparente.
