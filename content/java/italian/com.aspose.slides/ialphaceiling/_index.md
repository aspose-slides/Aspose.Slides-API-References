public interface IAlphaCeiling extends IImageTransformOperation, IAccessiblePVIObject<IAlphaCeilingEffectiveData>

Rappresenta un effetto Alpha Ceiling. I valori Alpha (opacità) maggiori di zero vengono modificati al 100%. In altre parole, tutto ciò che è parzialmente opaco diventa completamente opaco.
