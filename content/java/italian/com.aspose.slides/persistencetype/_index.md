Specifica il metodo usato per memorizzare le proprietà del controllo ActiveX.
## Campi

| Campo | Descrizione |
| --- | --- |
| [NotDefined](#NotDefined) | ID di persistenza non specificato. |
| [PersistPropertyBag](#PersistPropertyBag) | Specifica che il controllo ActiveX è persa mediante persistenza basata su property-bag. |
| [PersistStream](#PersistStream) | Specifica che il controllo ActiveX è persa mediante persistenza basata su stream che non supporta l’inizializzazione del controllo ActiveX in uno stato predefinito. |
| [PersistStreamInit](#PersistStreamInit) | Specifica che il controllo ActiveX è persa mediante persistenza basata su stream che supporta l’inizializzazione del controllo ActiveX in uno stato predefinito. |
| [PersistStorage](#PersistStorage) | Specifica che il controllo ActiveX è persa mediante persistenza basata su storage. |
### NotDefined {#NotDefined}
```
public static final int NotDefined
```

ID di persistenza non specificato.

### PersistPropertyBag {#PersistPropertyBag}
```
public static final int PersistPropertyBag
```

Specifica che il controllo ActiveX è persa mediante persistenza basata su property-bag. La persistenza basata su property-bag memorizza un controllo ActiveX mediante una collezione di coppie nome-valore che specificano i dati persi dal controllo ActiveX.

### PersistStream {#PersistStream}
```
public static final int PersistStream
```

Specifica che il controllo ActiveX è persa mediante persistenza basata su stream che non supporta l’inizializzazione del controllo ActiveX in uno stato predefinito.

### PersistStreamInit {#PersistStreamInit}
```
public static final int PersistStreamInit
```

Specifica che il controllo ActiveX è persa mediante persistenza basata su stream che supporta l’inizializzazione del controllo ActiveX in uno stato predefinito.

### PersistStorage {#PersistStorage}
```
public static final int PersistStorage
```

Specifica che il controllo ActiveX è persa mediante persistenza basata su storage.
