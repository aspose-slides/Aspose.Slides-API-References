Tipi di intervallo (spaziatura orizzontale) tra le colonne di una matrice
## Campi

| Campo | Descrizione |
| --- | --- |
| [SingleSpacingGap](#SingleSpacingGap) | Singolo (1 em per colonne o 1 linea per righe) |
| [OneAndHalfSpacingGap](#OneAndHalfSpacingGap) | Una e mezza (1.5 em per colonne o 1.5 linee per righe) |
| [DoubleSpacingGap](#DoubleSpacingGap) | Doppia spaziatura (2 em per colonne o 2 linee per righe) |
| [Exactly](#Exactly) | Valore esatto Per le colonne, fare affidamento sul valore di ColumnGap, misurato in twips Per le righe, fare affidamento sul valore di RowGap, misurato in twips |
| [Multiple](#Multiple) | Multiplo Per le colonne, fare affidamento sul valore di ColumnGap, misurato in incrementi di 0.5 em Per le righe, fare affidamento sul valore di RowGap, misurato in linee |
