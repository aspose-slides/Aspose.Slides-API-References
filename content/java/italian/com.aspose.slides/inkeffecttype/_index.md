```
public final class InkEffectType extends System.Enum
```

Specifica un insieme di effetti visivi predefiniti per il rendering dell'inchiostro. Ogni effetto corrisponde a una trama o immagine che simula un aspetto stilizzato dell'inchiostro. Questi valori possono essere utilizzati per personalizzare lo stile visivo delle pennellate di inchiostro digitale durante il rendering.
## Campi

| Field | Description |
| --- | --- |
| [NotDefined](#NotDefined) | L'effetto non è definito o è sconosciuto. |
| [Bronze](#Bronze) | Una trama metallica calda, di colore brunastro, simile all'inchiostro di bronzo. |
| [Galaxy](#Galaxy) | Una trama colorata e scintillante, simile a una galassia, con tonalità cosmiche. |
| [Gold](#Gold) | Una trama metallica dorata brillante che conferisce alle pennellate di inchiostro un aspetto lussuoso. |
| [Lava](#Lava) | Una trama infuocata, simile alla lava fusa, con tonalità rosse e arancioni. |
| [Ocean](#Ocean) | Una trama blu profonda, simile a un fluido, che imita le onde dell'oceano o l'inchiostro a base d'acqua. |
| [RainbowGlitter](#RainbowGlitter) | Un effetto glitter arcobaleno colorato e scintillante, usato per pennellate di inchiostro festive o vivaci. |
| [RoseGold](#RoseGold) | Una miscela morbida di rosa e oro, simile al rose gold, per pennellate di inchiostro eleganti. |
| [Silver](#Silver) | Una trama metallica argentata fresca che simula l'inchiostro d'argento classico. |
