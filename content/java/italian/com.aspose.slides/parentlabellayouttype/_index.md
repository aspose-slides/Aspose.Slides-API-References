Rappresenta il layout delle etichette dei dati di categoria. Utilizzato solo con le serie Treemap.
## Campi

| Campo | Descrizione |
| --- | --- |
| [Banner](#Banner) | Specifica che le etichette della categoria padre sono visualizzate come banner |
| [None](#None) | Specifica che le etichette della categoria padre non vengono disegnate |
| [Overlapping](#Overlapping) | Specifica che le etichette della categoria padre sono visualizzate come sovrapposte |
