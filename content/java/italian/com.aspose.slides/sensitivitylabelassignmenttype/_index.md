Rappresenta il metodo di assegnazione per l'etichetta di sensibilità.
## Campi

| Campo | Descrizione |
| --- | --- |
| [Standard](#Standard) | Utilizzare per qualsiasi etichetta di sensibilità che non è stata applicata direttamente dall'utente. |
| [Privileged](#Privileged) | Utilizzare per qualsiasi etichetta di sensibilità che è stata applicata direttamente dall'utente. |
### Standard {#Standard}
```
public static final int Standard
```

Utilizzare per qualsiasi etichetta di sensibilità che non è stata applicata direttamente dall'utente. Questo include tutte le etichette predefinite, le etichette applicate automaticamente.

### Privilegiato {#Privileged}
```
public static final int Privileged
```

Utilizzare per qualsiasi etichetta di sensibilità che è stata applicata direttamente dall'utente. Questo include tutte le etichette di sensibilità applicate manualmente così come le etichette consigliate o obbligatorie o qualsiasi funzione in cui l'utente decide quale etichetta di sensibilità applicare.
