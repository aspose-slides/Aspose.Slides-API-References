Specifica la giustificazione del paragrafo matematico (una serie di istanze adiacenti di testo matematico all'interno dello stesso paragrafo)

## Campi

| Campo | Descrizione |
| --- | --- |
| [LeftJustified](#LeftJustified) | Allinea il testo matematico a sinistra |
| [RightJustified](#RightJustified) | Allinea il testo matematico a destra |
| [Centered](#Centered) | Allinea il testo matematico al centro |
| [CenteredAsGroup](#CenteredAsGroup) | Centra sulla pagina l'intero gruppo di blocchi matematici come un'unica unità. |

### Centered {#Centered}
```
public static final int Centered
```

Allinea il testo matematico al centro

### CenteredAsGroup {#CenteredAsGroup}
```
public static final int CenteredAsGroup
```

Centra sulla pagina l'intero gruppo di blocchi matematici come un'unica unità. Questo significa che le istanze di testo matematico possono essere allineate tra loro, ma l'intero gruppo di testo matematico è centrato nel suo complesso.
