### AccentProcess {#AccentProcess}
```
public static final int AccentProcess
```

Usa per mostrare una progressione, una timeline o passaggi sequenziali in un’attività, processo o flusso di lavoro. Funziona bene per illustrare sia il testo di livello 1 sia quello di livello 2.

### AccentedPicture {#AccentedPicture}
```
public static final int AccentedPicture
```


Usa per mostrare un'idea fotografica centrale con idee correlate ai lati. Il testo di livello 1 superiore appare sopra l'immagine centrale. Il testo corrispondente per le altre forme di livello 1 appare accanto alle piccole immagini circolari. Questo layout funziona bene anche senza testo.

### AlternatingFlow {#AlternatingFlow}
```
public static final int AlternatingFlow
```


Usa per mostrare gruppi di informazioni o passaggi sequenziali in un’attività, processo o flusso di lavoro. Evidenzia l'interazione o le relazioni tra i gruppi di informazioni.

### AlternatingHexagons {#AlternatingHexagons}
```
public static final int AlternatingHexagons
```


Usa per rappresentare una serie di idee interconnesse. Il testo di livello 1 appare all'interno degli esagoni. Il testo di livello 2 appare all'esterno delle forme.

### AlternatingPictureBlocks {#AlternatingPictureBlocks}
```
public static final int AlternatingPictureBlocks
```


Usa per mostrare una serie di immagini dall'alto verso il basso. Il testo appare alternativamente a destra o a sinistra dell'immagine.

### AlternatingPictureCircles {#AlternatingPictureCircles}
```
public static final int AlternatingPictureCircles
```


Usa per mostrare un insieme di immagini con testo. Il testo corrispondente appare nei cerchi centrali con le immagini alternate da sinistra a destra.

### ArrowRibbon {#ArrowRibbon}
```
public static final int ArrowRibbon
```


Usa per mostrare concetti correlati o contrastanti con qualche connessione, come forze opposte. Le prime due righe del testo di livello 1 sono usate per il testo nelle frecce. Il testo non utilizzato non appare, ma rimane disponibile se cambi layout.

### AscendingPictureAccentProcess {#AscendingPictureAccentProcess}
```
public static final int AscendingPictureAccentProcess
```


Usa per mostrare una serie ascendente di immagini con testo descrittivo. Funziona al meglio con una piccola quantità di testo.

### Balance {#Balance}
```
public static final int Balance
```


Usa per confrontare o mostrare la relazione tra due idee. Ciascuna delle prime due righe del testo di livello 1 corrisponde al testo in alto su un lato del punto centrale. Evidenzia il testo di livello 2, che è limitato a quattro forme per ogni lato del punto centrale. L'equilibrio si inclina verso il lato con il maggior numero di forme contenenti testo di livello 2. Il testo non utilizzato non appare, ma rimane disponibile se cambi layout.

### BasicBendingProcess {#BasicBendingProcess}
```
public static final int BasicBendingProcess
```


Usa per mostrare una progressione o passaggi sequenziali in un’attività, processo o flusso di lavoro. Massimizza sia lo spazio orizzontale che quello verticale per le forme.

### BasicBlockList {#BasicBlockList}
```
public static final int BasicBlockList
```


Usa per mostrare blocchi di informazioni non sequenziali o raggruppati. Massimizza sia lo spazio orizzontale che quello verticale per le forme.

### BasicChevronProcess {#BasicChevronProcess}
```
public static final int BasicChevronProcess
```


Usa per mostrare una progressione; una timeline; passaggi sequenziali in un’attività, processo o flusso di lavoro; o per enfatizzare movimento o direzione. Il testo di livello 1 appare all'interno di una forma a freccia mentre il testo di livello 2 appare sotto le forme a freccia.

### BasicCycle {#BasicCycle}
```
public static final int BasicCycle
```


Usa per rappresentare una sequenza continua di fasi, compiti o eventi in un flusso circolare. Evidenzia le fasi o i passaggi piuttosto che le frecce o il flusso di collegamento. Funziona al meglio solo con testo di livello 1.

### BasicMatrix {#BasicMatrix}
```
public static final int BasicMatrix
```


Usa per mostrare la relazione dei componenti con un tutto in quadranti. Le prime quattro righe del testo di livello 1 appaiono nei quadranti. Il testo non utilizzato non appare, ma rimane disponibile se cambi layout.

### BasicPie {#BasicPie}
```
public static final int BasicPie
```


Usa per mostrare come le singole parti formano un insieme. Le prime sette righe del testo di livello 1 corrispondono alle fette o forme di torta distribuite uniformemente. La forma del testo di livello 1 superiore appare all'esterno del resto della torta per enfatizzare. Il testo non utilizzato non appare, ma rimane disponibile se cambi layout.

### BasicProcess {#BasicProcess}

public static final int BasicProcess

public static final int BasicPyramid

### BasicRadial {#BasicRadial}
```
public static final int BasicRadial
```


Usa per mostrare la relazione con un'idea centrale in un ciclo. La prima riga del testo di livello 1 corrisponde alla forma centrale, e il suo testo di livello 2 corrisponde alle forme circolari circostanti. Il testo non utilizzato non appare, ma rimane disponibile se cambi layout.

### BasicTarget {#BasicTarget}
```
public static final int BasicTarget
```


Usa per mostrare contenimento, gradazioni o relazioni gerarchiche. Le prime cinque righe del testo di livello 1 sono associate a un cerchio. Il testo non utilizzato non appare, ma rimane disponibile se cambi layout.

### BasicTimeline {#BasicTimeline}
```
public static final int BasicTimeline
```


Usa per mostrare passaggi sequenziali in un’attività, processo o flusso di lavoro, o per mostrare informazioni temporali. Funziona bene sia con testo di livello 1 sia con testo di livello 2.

### BasicVenn {#BasicVenn}
```
public static final int BasicVenn
```


Usa per mostrare relazioni sovrapposte o interconnesse. Le prime sette righe del testo di livello 1 corrispondono a un cerchio. Se ci sono quattro o meno righe di testo di livello 1, il testo è all'interno dei cerchi. Se ci sono più di quattro righe di testo di livello 1, il testo è all'esterno dei cerchi. Il testo non utilizzato non appare, ma rimane disponibile se cambi layout.
