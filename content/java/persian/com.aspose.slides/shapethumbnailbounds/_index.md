## فیلدها

| فیلد | توضیح |
| --- | --- |

### اسلاید {#Slide}
```
public static final int Slide
```

تصویر کوچک شکل اندازه‌ای برابر با اندازه اسلاید خواهد داشت. موقعیت شکل ذخیره می‌شود.

### شکل {#Shape}
```
public static final int Shape
```

تصویر کوچک شکل اندازه‌ای برابر با مستطیل مرزهای شکل خواهد داشت به‌همراه در نظر گرفتن تنظیمات خط‌مرز شکل.

### ظاهر {#Appearance}
```
public static final int Appearance
```

تصویر کوچک شکل اندازه‌ای برابر با ظاهر شکل (در محدوده اسلاید) خواهد داشت. ممکن است مواردی وجود داشته باشد که ظاهر شکل در مرزهای شکل جفت نشود. برای مثال چرخش، بخیه‌ذوزنق زاویهٔ تیز، افکت‌های سه‌بعدی و غیره.
