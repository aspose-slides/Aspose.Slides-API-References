مجموعه‌ای از جلوه‌های بصری پیش تعریف‌شده برای رندر جوهر را مشخص می‌کند. هر جلوه به بافت یا تصویری که ظاهر جوهر استیلیزه‌شده‌ای را شبیه‌سازی می‌کند، مربوط می‌شود. این مقادیر می‌توانند برای سفارشی‌سازی سبک بصری خطوط جوهر دیجیتال هنگام رندر استفاده شوند.
