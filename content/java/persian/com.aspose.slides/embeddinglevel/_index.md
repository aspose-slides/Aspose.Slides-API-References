### قابل نصب {#Installable}
```
public static final int Installable
```

فونت‌هایی که این تنظیم را دارند نشان می‌دهند که می‌توانند توسط یک برنامه در سیستم راه دور جاسازی شده و به‌صورت دائمی نصب شوند. کاربر سیستم راه دور همان حقوق، تعهدات و مجوزهای همانند خریدار اصلی فونت را به دست می‌آورد و مشمول همان توافق‌نامه مجوز کاربر نهایی، حق‌نویس، پتنت طراحی و/یا علامت تجاری است که خریدار اصلی نیز تحت آن بود.

### محدود {#Restricted}
```
public static final int Restricted
```

فونت‌هایی که تنها این بیت تنظیم شده است نباید به هیچ‌وجه تغییر یابند، جاسازی یا تبادل شوند مگر اینکه ابتدا اجازه مالک قانونی را دریافت کنند.

### پیش‌نمایش چاپ {#PreviewPrint}
```
public static final int PreviewPrint
```

زمانی که این بیت تنظیم شود، می‌توان فونت را جاسازی کرد و به‌صورت موقت بر روی سیستم راه دور بارگذاری کرد. اسناد حاوی فونت‌های پیش‌نمایش و چاپ باید به صورت «فقط-خواندنی» باز شوند؛ هیچ تغییری در سند اعمال نمی‌شود.

### قابل ویرایش {#Editable}
```
public static final int Editable
```

زمانی که این بیت تنظیم شود، می‌توان فونت را جاسازی کرد اما باید فقط به‌صورت موقت بر روی سایر سیستم‌ها نصب شود. بر خلاف فونت‌های پیش‌نمایش و چاپ، اسناد حاوی فونت‌های قابل ویرایش می‌توانند برای خواندن باز شوند، ویرایش مجاز است و تغییرات می‌توانند ذخیره شوند.

### بدون زیرمجموعه‌سازی {#NoSubsetting}
```
public static final int NoSubsetting
```

زمانی که این بیت تنظیم شود، قبل از جاسازی نمی‌توان فونت را زیرمجموعه کرد. سایر محدودیت‌های جاسازی مشخص شده در بیت‌های ۰-۳ و ۹ نیز اعمال می‌شوند.

### فقط بیت‌مپ {#BitmapOnly}
```
public static final int BitmapOnly
```

زمانی که این بیت تنظیم شود، فقط نقشه‌های بیت (bitmap) موجود در فونت می‌توانند جاسازی شوند. داده‌های خطوط (outline) قابل جاسازی نیستند. اگر در فونت هیچ bitmapی موجود نباشد، آن فونت به‌عنوان غیرقابل جاسازی در نظر گرفته می‌شود و سرویس‌های جاسازی شکست می‌خورند.
