این کلاس حاوی ویژگی‌های قالب‌بندی بخش نمودار استفاده‌شده در نمودارها است. برخلاف [IPortionFormatEffectiveData](../../com.aspose.slides/iportionformateffectivedata)، تمام ویژگی‌های این کلاس قابلیت نوشتن دارند.

--------------------

این کلاس برای برگرداندن و دستکاری ویژگی‌های قالب‌بندی بخش متن تعریف‌شده برای بخش خاص استفاده می‌شود. این به معنای این است که هنگام دریافت مقادیر هیچ ارث‌بری اعمال نمی‌شود، بنابراین در اکثر موارد مقادیر "undefined" دریافت خواهید کرد.

برای دریافت مقادیر مؤثر پارامترهای قالب‌بندی شامل ارث‌بری، باید از متد [PortionFormat.getEffective](../../com.aspose.slides/portionformat\#getEffective) استفاده کنید که یک نمونهٔ [IPortionFormatEffectiveData](../../com.aspose.slides/iportionformateffectivedata) را برمی‌گرداند.
