### استاندارد {#Standard}
```
public static final int Standard
```

برای هر برچسب حساسیتی که به‌صورت مستقیم توسط کاربر اعمال نشده است استفاده می‌شود. این شامل هر برچسب پیش‌فرض و برچسب‌های به‌صورت خودکار اعمال‌شده می‌شود.

### ویژه {#Privileged}
```
public static final int Privileged
```

برای هر برچسب حساسیتی که به‌صورت مستقیم توسط کاربر اعمال شده است استفاده می‌شود. این شامل برچسب‌های حساسیتی که به‌صورت دستی اعمال می‌شوند، همچنین برچسب‌گذاری پیشنهادی یا اجباری یا هر ویژگی‌ای که کاربر تصمیم می‌گیرد کدام برچسب حساسیتی را اعمال کند، می‌شود.
