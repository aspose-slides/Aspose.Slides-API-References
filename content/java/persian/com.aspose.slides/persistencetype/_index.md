### NotDefined {#NotDefined}
```
public static final int NotDefined
```

### PersistPropertyBag {#PersistPropertyBag}
```
public static final int PersistPropertyBag
```

مشخص می‌کند که کنترل ActiveX با استفاده از persistence مبتنی بر property-bag حفظ می‌شود. persistence مبتنی بر property-bag کنترل ActiveX را با استفاده از مجموعه‌ای از جفت‌های نام و مقدار که داده‌های حفظ‌شده توسط کنترل ActiveX را مشخص می‌کنند، ذخیره می‌کند.
