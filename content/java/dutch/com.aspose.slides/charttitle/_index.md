### getTextFrameForOverriding() {#getTextFrameForOverriding--}
```
public final ITextFrame getTextFrameForOverriding()
```

Kan een rijk opgemaakte tekst bevatten. Als deze eigenschap niet null is, dan overschrijft deze opgemaakte tekstwaarde automatisch gegenereerde tekst. Automatisch gegenereerde tekst is een impliciete eigenschap van het gegevenslabel, het weergave-eenheidslabel van de waardenas, de as-titel, de grafiektitel, het label van de trendlijn. Automatisch gegenereerde tekst wordt opgemaakt met de IFormattedTextContainer.TextFormat-eigenschap. Alleen-lezen [ITextFrame](../../com.aspose.slides/itextframe).

**Retour:**  
[ITextFrame](../../com.aspose.slides/itextframe)
