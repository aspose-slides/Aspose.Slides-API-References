```
public final class InkEffectType extends System.Enum
```

Specificeert een set vooraf gedefinieerde visuele effecten voor het renderen van inkt. Elk effect correspondeert met een textuur of afbeelding die een gestileerde inktuiterlijk simuleert. Deze waarden kunnen worden gebruikt om de visuele stijl van digitale inktstreken tijdens het renderen aan te passen.
## Velden

| Veld | Beschrijving |
| --- | --- |
| [NotDefined](#NotDefined) | Het effect is niet gedefinieerd of onbekend. |
| [Bronze](#Bronze) | Een warme, bruingleurige metalen textuur die lijkt op bronsink. |
| [Galaxy](#Galaxy) | Een kleurrijke, glinsterende textuur die lijkt op een sterrenstelsel, met kosmische tinten. |
| [Gold](#Gold) | Een heldere, metalen gouden textuur die inktstreken een luxueus uiterlijk geeft. |
| [Lava](#Lava) | Een vurig textuur die lijkt op gesmolten lava, met rode en oranje tinten. |
| [Ocean](#Ocean) | Een diepblauwe, vloeistofachtige textuur die oceaangolven of watergebaseerde inkt nabootst. |
| [RainbowGlitter](#RainbowGlitter) | Een kleurrijk, sprankelend regenboogglittereffect gebruikt voor feestelijke of levendige inktstreken. |
| [RoseGold](#RoseGold) | Een zacht roze-goud mengsel, vergelijkbaar met roségoud, voor elegante inktstreken. |
| [Silver](#Silver) | Een koele, metalen zilveren textuur die klassieke zilveren inkt simuleert. |
