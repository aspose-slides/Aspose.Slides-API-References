### AccentProcess {#AccentProcess}
```
public static final int AccentProcess
```

Gebruik om een voortgang, een tijdlijn of opeenvolgende stappen in een taak, proces of workflow te tonen. Werkt goed voor het illustreren van zowel Niveau 1- als Niveau 2-tekst.

### AccentedPicture {#AccentedPicture}
```
public static final int AccentedPicture
```

Gebruik om een centraal, fotografisch idee met gerelateerde ideeën aan de zijkant te tonen. De bovenste Niveau 1-tekst verschijnt boven de centrale afbeelding. De overeenkomstige tekst voor andere Niveau 1-vormen verschijnt naast de kleine ronde afbeeldingen. Deze lay-out werkt ook goed zonder tekst.

```
public static final int AlternatingFlow
```

```
public static final int AlternatingHexagons
```

### ArrowRibbon {#ArrowRibbon}
```
public static final int ArrowRibbon
```

### AscendingPictureAccentProcess {#AscendingPictureAccentProcess}
```
public static final int AscendingPictureAccentProcess
```

### Balance {#Balance}
```
public static final int Balance
```

Gebruik om de relatie tussen twee ideeën te vergelijken of te tonen. Elke van de eerste twee regels Niveau 1-tekst correspondeert met tekst boven aan één kant van het middelpunt. Benadrukt Niveau 2-tekst, die beperkt is tot vier vormen aan elke kant van het middelpunt. Het evenwicht kantelt naar de kant met de meeste vormen met Niveau 2-tekst. Ongebruikte tekst verschijnt niet, maar blijft beschikbaar als u van lay-out wisselt.
