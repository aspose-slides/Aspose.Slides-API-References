Specificeert de status waarin de splitterbalk moet worden weergegeven. De splitterbalk scheidt een primaire en een secundaire regio binnen een weergavegebied.
## Velden

| Veld | Beschrijving |
| --- | --- |
| [Minimized](#Minimized) | De primaire regio neemt het minste deel van het weergavegebied in dat door de applicatie is toegestaan. |
| [Restored](#Restored) | De primaire regio heeft een specifieke tussenliggende grootte. |
| [Maximized](#Maximized) | De primaire regio neemt het grootste deel van het weergavegebied in dat door de applicatie is toegestaan. |
