### getRepeatUntilEndSlide() {#getRepeatUntilEndSlide--}
```
public final boolean getRepeatUntilEndSlide()
```

Dit attribuut geeft aan of het effect wordt herhaald tot het einde van de dia. Alleen-lezen boolean.

--------------------

> ```
> Presentation presentation = new Presentation("demo.pptx");
>  try {
>      // Verkrijg de effectensequentie voor de eerste dia
>      ISequence effectsSequence = presentation.getSlides().get_Item(0).getTimeline().getMainSequence();
>      // Verkrijg het eerste effect van de hoofdsequente.
>      IEffect effect = effectsSequence.get_Item(0);
>      // Wijzig de Timing/Herhaling van het effect naar "Tot het einde van de dia"
>      effect.getTiming().setRepeatUntilEndSlide(true);
>  } finally {
>      if (presentation != null) presentation.dispose();
>  }
> ```


**Retourwaarde:**
boolean
