### NotDefined {#NotDefined}
```
public static final int NotDefined
```

Persistentie-id niet opgegeven.

### PersistPropertyBag {#PersistPropertyBag}
```
public static final int PersistPropertyBag
```

Geeft aan dat het ActiveX-besturingselement wordt bewaard met behulp van property-bag-gebaseerde persistentie. Property-bag-gebaseerde persistentie slaat een ActiveX-besturingselement op door middel van een verzameling naam-en-waarde-paren die de door het ActiveX-besturingselement gepersisteerde gegevens specificeren.

### PersistStream {#PersistStream}
```
public static final int PersistStream
```

Geeft aan dat het ActiveX-besturingselement wordt bewaard met behulp van een stream-gebaseerde persistentie die geen initialisatie van het ActiveX-besturingselement naar een standaardtoestand ondersteunt.

### PersistStreamInit {#PersistStreamInit}
```
public static final int PersistStreamInit
```

Geeft aan dat het ActiveX-besturingselement wordt bewaard met behulp van een stream-gebaseerde persistentie die initialisatie van het ActiveX-besturingselement naar een standaardtoestand ondersteunt.

### PersistStorage {#PersistStorage}
```
public static final int PersistStorage
```

Geeft aan dat het ActiveX-besturingselement wordt bewaard met behulp van storage-gebaseerde persistentie.
