public interface IErrorBarsCustomValues
```

Specificeert de waarden van de foutenbalken. Het mag alleen worden gebruikt wanneer het Error bars value type Custom is.

| [getXPlus()](#getXPlus--) | Specificeert de foutbalkwaarde in de positieve richting. |
| [getYPlus()](#getYPlus--) | Specificeert de foutbalkwaarde in de positieve richting. |
### getXMinus() {#getXMinus--}
```
public abstract IDoubleChartValue getXMinus()
```

Specificeert de foutbalkwaarde in de negatieve richting. Beschikbaar als het Error bars value type Custom is en ErrorBarsXFormat is toegestaan. In alle andere gevallen retourneert deze eigenschap null. Alleen-lezen [IDoubleChartValue](../../com.aspose.slides/idoublechartvalue).
