public interface IAlphaCeiling extends IImageTransformOperation, IAccessiblePVIObject<IAlphaCeilingEffectiveData>

Vertegenwoordigt een Alpha Ceiling effect. Alpha (opaciteit) waarden groter dan nul worden gewijzigd naar 100%. Met andere woorden, alles wat gedeeltelijk ondoorzichtig is, wordt volledig ondoorzichtig.
