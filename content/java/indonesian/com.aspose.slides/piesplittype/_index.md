Mewakili jenis titik pemisahan pada pai atau batang kedua pada diagram pai-dalam-pai atau batang-dalam-pai.

## Bidang

| Bidang | Deskripsi |
| --- | --- |
| [Default](#Default) | Menentukan bahwa titik data akan dibagi menggunakan mekanisme default untuk tipe diagram ini. |
| [Custom](#Custom) | Menentukan bahwa titik data akan dibagi antara pai dan diagram kedua sesuai nilai Custom Split. |
| [ByPercentage](#ByPercentage) | Menentukan bahwa titik data akan dibagi antara pai dan diagram kedua dengan menempatkan titik dengan persentase kurang dari Split Position persen di diagram kedua. |
| [ByPos](#ByPos) | Menentukan bahwa titik data akan dibagi antara pai dan diagram kedua dengan menempatkan posisi Split Position terakhir dari titik data di diagram kedua. |
| [ByValue](#ByValue) | Menentukan bahwa titik data akan dibagi antara pai dan diagram kedua dengan menempatkan titik data dengan nilai kurang dari Split Position di diagram kedua. |
