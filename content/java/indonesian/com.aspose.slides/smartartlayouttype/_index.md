### AccentProcess {#AccentProcess}
```
public static final int AccentProcess
```

Gunakan untuk menampilkan kemajuan, linimasa, atau langkah berurutan dalam sebuah tugas, proses, atau alur kerja. Bekerja dengan baik untuk menggambarkan teks Level 1 dan Level 2.

### AccentedPicture {#AccentedPicture}
```
public static final int AccentedPicture
```

Gunakan untuk menampilkan ide fotografis pusat dengan ide terkait di sampingnya. Teks Level 1 yang berada di atas muncul di atas gambar pusat. Teks yang sesuai untuk bentuk Level 1 lainnya muncul di sebelah gambar lingkaran kecil. Tata letak ini juga bekerja dengan baik tanpa teks.

### AlternatingFlow {#AlternatingFlow}
```
public static final int AlternatingFlow
```

Gunakan untuk menampilkan grup informasi atau langkah berurutan dalam sebuah tugas, proses, atau alur kerja. Menekankan interaksi atau hubungan antar grup informasi.

### AlternatingHexagons {#AlternatingHexagons}
```
public static final int AlternatingHexagons
```

Gunakan untuk merepresentasikan serangkaian ide yang saling terhubung. Teks Level 1 muncul di dalam heksagon. Teks Level 2 muncul di luar bentuk.

### AlternatingPictureBlocks {#AlternatingPictureBlocks}
```
public static final int AlternatingPictureBlocks
```

Gunakan untuk menampilkan serangkaian gambar dari atas ke bawah. Teks muncul secara bergantian di kanan atau kiri gambar.

### AlternatingPictureCircles {#AlternatingPictureCircles}
```
public static final int AlternatingPictureCircles
```

Gunakan untuk menampilkan sekumpulan gambar dengan teks. Teks yang sesuai muncul di dalam lingkaran pusat dengan gambar yang bergantian dari kiri ke kanan.

### ArrowRibbon {#ArrowRibbon}
```
public static final int ArrowRibbon
```

Gunakan untuk menampilkan konsep terkait atau kontras dengan beberapa hubungan, seperti gaya yang berlawanan. Dua baris pertama teks Level 1 digunakan untuk teks di panah. Teks yang tidak digunakan tidak muncul, tetapi tetap tersedia jika Anda mengganti tata letak.

### AscendingPictureAccentProcess {#AscendingPictureAccentProcess}
```
public static final int AscendingPictureAccentProcess
```

Gunakan untuk menampilkan serangkaian gambar naik dengan teks deskriptif. Bekerja paling baik dengan teks sedikit.

### Balance {#Balance}
```
public static final int Balance
```

Gunakan untuk membandingkan atau menunjukkan hubungan antara dua ide. Setiap dua baris pertama teks Level 1 sesuai dengan teks di bagian atas satu sisi titik pusat. Menekankan teks Level 2, yang dibatasi pada empat bentuk di setiap sisi titik pusat. Keseimbangan condong ke sisi dengan paling banyak bentuk yang berisi teks Level 2. Teks yang tidak digunakan tidak muncul, tetapi tetap tersedia jika Anda mengganti tata letak.
