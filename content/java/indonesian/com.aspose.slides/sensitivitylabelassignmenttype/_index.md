Mewakili metode penugasan untuk label sensitivitas.
## Bidang

| Bidang | Deskripsi |
| --- | --- |
| [Standard](#Standard) | Gunakan untuk label sensitivitas apa pun yang tidak diterapkan secara langsung oleh pengguna. |
| [Privileged](#Privileged) | Gunakan untuk label sensitivitas apa pun yang diterapkan secara langsung oleh pengguna. |
### Standar {#Standard}
```
public static final int Standard
```

Gunakan untuk label sensitivitas apa pun yang tidak diterapkan secara langsung oleh pengguna. Ini mencakup semua label default, label yang diterapkan secara otomatis.

### Istimewa {#Privileged}
```
public static final int Privileged
```

Gunakan untuk label sensitivitas apa pun yang diterapkan secara langsung oleh pengguna. Ini mencakup semua label sensitivitas yang diterapkan secara manual serta pelabelan yang direkomendasikan atau wajib, atau fitur apa pun di mana pengguna memutuskan label sensitivitas mana yang akan diterapkan.
