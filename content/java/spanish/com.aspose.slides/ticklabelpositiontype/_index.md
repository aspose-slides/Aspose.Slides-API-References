Representa el tipo de posición de las etiquetas de marcas de graduación en el eje especificado.
## Campos

| Campo | Descripción |
| --- | --- |
| [High](#High) | Especifica que las etiquetas del eje deben estar en el extremo alto del eje perpendicular. |
| [Low](#Low) | Especifica que las etiquetas del eje deben estar en el extremo bajo del eje perpendicular. |
| [NextTo](#NextTo) | Especifica que las etiquetas del eje deben estar junto al eje. |
| [None](#None) | Especifica que las etiquetas del eje no se dibujan. |
