### setVisibilityOnAllTitleSlides(boolean isVisible) {#setVisibilityOnAllTitleSlides-boolean-}
```
public final void setVisibilityOnAllTitleSlides(boolean isVisible)
```

Cambia la visibilidad de los marcadores de pie de página, fecha y número de página para todas las diapositivas de título y para la primera diapositiva de diseño. Las diapositivas de título \\u2013 diapositivas basadas en la primera diapositiva de diseño (independientemente del tipo de este primer diseño).

**Parámetros:**
| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| isVisible | boolean | true - hace visibles los marcadores, de lo contrario los oculta. |
