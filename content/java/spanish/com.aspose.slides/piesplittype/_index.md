Representa un tipo de puntos de división en el segundo sector o barra de un gráfico de pastel-sobre-pastel o barra-sobre-pastel.
## Campos

| Campo | Descripción |
| --- | --- |
| [Default](#Default) | Especifica que los puntos de datos se dividirán usando el mecanismo predeterminado para este tipo de gráfico. |
| [Custom](#Custom) | Especifica que los puntos de datos se dividirán entre el pastel y el segundo gráfico de acuerdo con los valores de Custom Split. |
| [ByPercentage](#ByPercentage) | Especifica que los puntos de datos se dividirán entre el pastel y el segundo gráfico colocando los puntos con un porcentaje menor que Split Position percent en el segundo gráfico. |
| [ByPos](#ByPos) | Especifica que los puntos de datos se dividirán entre el pastel y el segundo gráfico colocando la última Split Position de los puntos de datos en el segundo gráfico. |
| [ByValue](#ByValue) | Especifica que los puntos de datos se dividirán entre el pastel y el segundo gráfico colocando los puntos de datos con un valor menor que Split Position en el segundo gráfico. |
