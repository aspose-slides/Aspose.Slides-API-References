Proporciona opciones que controlan cómo se convertirán las imágenes de las diapositivas a imágenes bitonales.
## Campos

| Campo | Descripción |

| [Default](#Default) | No especifica un algoritmo de conversión. |
| [Dithering](#Dithering) | Especifica el algoritmo de dithering (Floyd-Steinberg). |
| [DitheringFloydSteinberg](#DitheringFloydSteinberg) | Especifica el algoritmo de dithering Floyd-Steinberg. |
| [Auto](#Auto) | Especifica el algoritmo de umbral calculado automáticamente (Otsu). |
| [AutoOtsu](#AutoOtsu) | Especifica el algoritmo de umbral Otsu calculado automáticamente. |
| [Threshold25](#Threshold25) | Especifica el algoritmo de umbral estático (25%). |
| [Threshold50](#Threshold50) | Especifica el algoritmo de umbral estático (50%). |
| [Threshold75](#Threshold75) | Especifica el algoritmo de umbral estático (75%). |
