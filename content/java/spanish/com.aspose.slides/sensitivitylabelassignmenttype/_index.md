Representa el método de asignación para la etiqueta de sensibilidad.
## Campos

| Campo | Descripción |
| --- | --- |
| [Standard](#Standard) | Úsese para cualquier etiqueta de sensibilidad que no haya sido aplicada directamente por el usuario. |
| [Privileged](#Privileged) | Úsese para cualquier etiqueta de sensibilidad que haya sido aplicada directamente por el usuario. |
### Estándar {#Standard}
```
public static final int Standard
```

Úsese para cualquier etiqueta de sensibilidad que no haya sido aplicada directamente por el usuario. Esto incluye cualquier etiqueta predeterminada, etiquetas aplicadas automáticamente.

### Privilegiado {#Privileged}
```
public static final int Privileged
```

Úsese para cualquier etiqueta de sensibilidad que haya sido aplicada directamente por el usuario. Esto incluye cualquier etiqueta de sensibilidad aplicada manualmente, así como etiquetado recomendado o obligatorio o cualquier característica donde el usuario decide qué etiqueta de sensibilidad aplicar.
