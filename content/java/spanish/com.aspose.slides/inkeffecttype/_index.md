Especifica un conjunto de efectos visuales predefinidos para la renderización de tinta. Cada efecto corresponde a una textura o imagen que simula una apariencia de tinta estilizada. Estos valores pueden usarse para personalizar el estilo visual de los trazos de tinta digital durante la renderización.
## Campos

| Campo | Descripción |
| --- | --- |
| [NotDefined](#NotDefined) | El efecto no está definido o es desconocido. |
| [Bronze](#Bronze) | Una textura metálica cálida, ligeramente parduzca, que se asemeja a la tinta de bronce. |
| [Galaxy](#Galaxy) | Una textura colorida y brillante que se asemeja a una galaxia, con tonos cósmicos. |
| [Gold](#Gold) | Una textura metálica dorada brillante que brinda a los trazos de tinta una apariencia lujosa. |
| [Lava](#Lava) | Una textura ígnea que se asemeja a lava fundida, con tonos rojos y naranjas. |
| [Ocean](#Ocean) | Una textura azul profunda, similar a un fluido, que imita las olas del océano o la tinta a base de agua. |
| [RainbowGlitter](#RainbowGlitter) | Un efecto brillante y colorido de glitter arcoíris utilizado para trazos de tinta festivos o vibrantes. |
| [RoseGold](#RoseGold) | Una mezcla suave de rosa y oro, similar al oro rosado, para trazos de tinta elegantes. |
| [Silver](#Silver) | Una textura metálica plateada fresca que simula la tinta plateada clásica. |
