## Campos

| Campo | Descripción |
| --- | --- |

| [OneAndHalfSpacingGap](#OneAndHalfSpacingGap) | Una y media (1.5 ems para columnas o 1.5 líneas para filas) |
| [DoubleSpacingGap](#DoubleSpacingGap) | Doble espaciado (2 ems para columnas o 2 líneas para filas) |
| [Exactly](#Exactly) | Valor exacto. Para columnas, depende del valor de ColumnGap, medido en twips. Para filas, depende del valor de RowGap, medido en twips. |
| [Multiple](#Multiple) | Múltiple. Para columnas, depende del valor de ColumnGap, medido en incrementos de 0.5 em. Para filas, depende del valor de RowGap, medido en líneas. |
