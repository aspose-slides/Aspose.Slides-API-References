### applyDefaultParagraphIndentsShifts() {#applyDefaultParagraphIndentsShifts--}
```
public final void applyDefaultParagraphIndentsShifts()
```


Beállítja az alapértelmezett nem nulla eltolásokat a hatékony bekezdés Behúzásához (Indent) és bal margójához (MarginLeft), amikor a listaelemek engedélyezve vannak (akárcsak a PowerPoint, ha engedélyezi a bekezdés listaelemeket/számozást). Ha a listaelemek le vannak tiltva, akkor csak visszaállítja a bekezdés Behúzását és bal margóját (akárcsak a PowerPoint, ha letiltja a bekezdés listaelemeket/számozást). Az eltolások a jelenlegi listaelem kontextusra vonatkozóan kerülnek alkalmazásra – IBulletFormat.Type, .NumberedBulletStyle és az első rész betűmagassága. A nem nulla eltolások a jelenlegi bekezdés hatékony Behúzására (Indent) és bal margójára (MarginLeft) kerülnek alkalmazásra (az eredmény értékek helyi értékekké válnak).

### getEffective() {#getEffective--}
```
public final IBulletFormatEffectiveData getEffective()
```


Lekéri a hatékony listaelem formázási adatokat az alkalmazott öröklődéssel.

--------------------

> ```
> This example demonstrates getting some effective bullet format properties.
>  
>  Presentation pres = new Presentation("MyPresentation.pptx");
>  try {
>      IAutoShape shape = (IAutoShape)pres.getSlides().get_Item(0).getShapes().get_Item(0);
>      IBulletFormatEffectiveData effectiveBulletFormat = shape.getTextFrame().getParagraphs().get_Item(0).getParagraphFormat().getBullet().getEffective();
>      System.out.println("Bullet type: " + effectiveBulletFormat.getType());
>      if (effectiveBulletFormat.getType() == BulletType.Numbered)
>      {
>          System.out.println("Numbered style: " + effectiveBulletFormat.getNumberedBulletStyle());
>          System.out.println("Starting number: " + effectiveBulletFormat.getNumberedBulletStartWith());
>      }
>  } finally {
>      if (pres != null) pres.dispose();
>  }
> ```

**Visszatér:**
[IBulletFormatEffectiveData](../../com.aspose.slides/ibulletformateffectivedata) - A [IBulletFormatEffectiveData](../../com.aspose.slides/ibulletformateffectivedata).
