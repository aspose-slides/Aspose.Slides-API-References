### AccentProcess {#AccentProcess}
```
public static final int AccentProcess
```

Használja a haladás, az ütemterv vagy egy feladat, folyamat vagy munkafolyamat sorozatos lépéseinek megjelenítésére. Jól működik az 1. és 2. szintű szöveg ábrázolásához.

### AccentedPicture {#AccentedPicture}
```
public static final int AccentedPicture
```

Használja központi, fotográfiai ötlet megjelenítésére, mellette kapcsolódó ötletekkel. A felső 1. szintű szöveg a központi képen jelenik meg. A többi 1. szintű alakhoz tartozó szöveg a kis kör alakú képek mellett jelenik meg. Ez a elrendezés szöveg nélkül is jól működik.

### AlternatingFlow {#AlternatingFlow}
```
public static final int AlternatingFlow
```

Használja információcsoportok vagy sorozatos lépések megjelenítésére egy feladat, folyamat vagy munkafolyamat során. Kiemeli a csoportok közötti interakciót vagy kapcsolatot.

### AlternatingHexagons {#AlternatingHexagons}
```
public static final int AlternatingHexagons
```

Használja egymással összekapcsolt ötletek ábrázolására. Az 1. szintű szöveg a hatszögeken belül jelenik meg. A 2. szintű szöveg a formák kívül található.

### AlternatingPictureBlocks {#AlternatingPictureBlocks}
```
public static final int AlternatingPictureBlocks
```

Használja a képek felső-alsó sorrendben történő megjelenítésére. A szöveg váltakozva a kép jobb vagy bal oldalán jelenik meg.

### AlternatingPictureCircles {#AlternatingPictureCircles}
```
public static final int AlternatingPictureCircles
```

Használja a képek és szöveg egy csoportjának megjelenítésére. A megfelelő szöveg a központi körökben jelenik meg, a képek pedig balról jobbra váltakoznak.

### ArrowRibbon {#ArrowRibbon}
