public final class InkEffectType extends System.Enum

Előre meghatározott vizuális effektusok halmazát határozza meg a tinta rendereléséhez. Minden effektus egy textúrához vagy képhez kapcsolódik, amely egy stilizált tintamegjelenést szimulál. Ezek az értékek a digitális tintaszakaszok megjelenési stílusának testreszabására használhatók a renderelés során.
