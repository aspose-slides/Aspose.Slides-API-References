**Öröklés:**

```
public final class SplitterBarStateType extends System.Enum
```

Megadja, hogy milyen állapotban jelenjen meg a splitter bar. A splitter bar elválaszt egy elsődleges és egy másodlagos régiót a nézetterületen.
## Mezők

| Mező | Leírás |
| --- | --- |
| [Minimized](#Minimized) | Az elsődleges régió elfoglalja a nézetterület legkisebb, az alkalmazás által engedélyezett mennyiségét. |
| [Restored](#Restored) | Az elsődleges régió egy meghatározott közbenső mérettel rendelkezik. |
| [Maximized](#Maximized) | Az elsődleges régió elfoglalja a nézetterület legnagyobb, az alkalmazás által engedélyezett mennyiségét. |
### Minimalizált {#Minimized}

### Maximalizált {#Maximized}
