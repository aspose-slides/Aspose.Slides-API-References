Módosíthatatlan objektum, amely egy Alpha Modulate effektust képvisel. A hatás alfa (átlátszóság) értékeit egy rögzített százalékkal szorozzák. A hatás tároló egy olyan hatást határoz meg, amely alfa értékeket tartalmaz modulálásra.
