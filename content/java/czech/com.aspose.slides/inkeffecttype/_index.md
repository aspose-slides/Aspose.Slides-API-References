java.lang.Object, com.aspose.ms.System.ValueType, com.aspose.ms.System.Enum
```
public final class InkEffectType extends System.Enum
```

Specifikuje sadu předdefinovaných vizuálních efektů pro vykreslování inkoustu. Každý efekt odpovídá textuře nebo obrázku, který simuluje stylizovaný vzhled inkoustu. Tyto hodnoty lze použít k přizpůsobení vizuálního stylu digitálních tahů inkoustu během vykreslování.
## Pole

| Pole | Popis |
| --- | --- |
| [NotDefined](#NotDefined) | Efekt není definován nebo je neznámý. |
| [Bronze](#Bronze) | Teplá, hnědavá kovová textura připomínající bronzový inkoust. |
| [Galaxy](#Galaxy) | Barevná, třpytivá textura připomínající galaxii s kosmickými odstíny. |
| [Gold](#Gold) | Zářivá, kovová zlatá textura, která dodává tahům inkoustu luxusní vzhled. |
| [Lava](#Lava) | Ohnivá textura připomínající roztavenou lávu s červenými a oranžovými odstíny. |
| [Ocean](#Ocean) | Hluboká modrá, tekutá textura napodobující vlny oceánu nebo vodní inkoust. |
| [RainbowGlitter](#RainbowGlitter) | Barevný, třpytivý duhový glitter efekt používaný pro slavnostní nebo živé tahy inkoustu. |
| [RoseGold](#RoseGold) | Jemná růžovo-zlatá kombinace, podobná rose gold, pro elegantní tahy inkoustu. |
| [Silver](#Silver) | Chladná, kovová stříbrná textura, která simuluje klasický stříbrný inkoust. |
