```

| [getWholeWordsOnly()](#getWholeWordsOnly--) | Nastavte true pro shodu pouze celých slov, false - jinak. |
| [setWholeWordsOnly(boolean value)](#setWholeWordsOnly-boolean-) | Nastavte true pro shodu pouze celých slov, false - jinak. |
| [getIncludeNotes()](#getIncludeNotes--) | Nastavte true pro zahrnutí textu obsaženého v poznámkách snímku při provádění vyhledávání textu, nahrazování nebo zvýrazňovacích operací. |
| [setIncludeNotes(boolean value)](#setIncludeNotes-boolean-) | Nastavte true pro zahrnutí textu obsaženého v poznámkách snímku při provádění vyhledávání textu, nahrazování nebo zvýrazňovacích operací. |
