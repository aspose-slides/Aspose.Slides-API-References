public interface IErrorBarsCustomValues
```

Určuje hodnoty chybových úseček. Má být použito pouze tehdy, když je typ hodnoty chybových úseček Custom.

### getXMinus() {#getXMinus--}
```
public abstract IDoubleChartValue getXMinus()
```

Určuje hodnotu chybové úsečky v záporném směru. K dispozici, pokud je typ hodnoty chybových úseček Custom a je povolen ErrorBarsXFormat. V každém jiném případě tato vlastnost vrátí null. Pouze pro čtení [IDoubleChartValue](../../com.aspose.slides/idoublechartvalue).
