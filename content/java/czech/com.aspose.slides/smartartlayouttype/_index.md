### AccentProcess {#AccentProcess}
```
public static final int AccentProcess
```

Použijte k zobrazení postupu, časové osy nebo sekvenčních kroků v úkolu, procesu nebo pracovním postupu. Dobře funguje při ilustrování textu Level 1 i Level 2 textu.

### AccentedPicture {#AccentedPicture}
```
public static final int AccentedPicture
```

Použijte k zobrazení centrální, fotografické myšlenky s souvisejícími nápady po straně. Horní Level 1 text se zobrazuje nad centrálním obrázkem. Odpovídající text pro ostatní tvary Level 1 se zobrazuje vedle malých kulatých obrázků. Toto rozvržení také dobře funguje bez textu.

### AlternatingFlow {#AlternatingFlow}
```
public static final int AlternatingFlow
```

Použijte k zobrazení skupin informací nebo sekvenčních kroků v úkolu, procesu nebo pracovním postupu. Zdůrazňuje interakci nebo vztahy mezi skupinami informací.

### AlternatingHexagons {#AlternatingHexagons}
```
public static final int AlternatingHexagons
```

Použijte k představování řady propojených myšlenek. Level 1 text se zobrazuje uvnitř šestiúhelníků. Level 2 text se zobrazuje mimo tvary.

### AlternatingPictureBlocks {#AlternatingPictureBlocks}
```
public static final int AlternatingPictureBlocks
```

Použijte k zobrazení série obrázků shora dolů. Text se střídavě objevuje vpravo nebo vlevo od obrázku.

### AlternatingPictureCircles {#AlternatingPictureCircles}
```
public static final int AlternatingPictureCircles
```

Použijte k zobrazení sady obrázků s textem. Odpovídající text se zobrazí ve středových kruzích, přičemž obrázky se střídají zleva doprava.

### ArrowRibbon {#ArrowRibbon}
```
public static final int ArrowRibbon
```

Použijte k zobrazení souvisejících nebo kontrastních konceptů s nějakým spojením, například protichůdných sil. První dvě řádky Level 1 textu jsou použity pro text v šípkách. Nepoužitý text se nezobrazuje, ale zůstává k dispozici při změně rozvržení.

### AscendingPictureAccentProcess {#AscendingPictureAccentProcess}
```
public static final int AscendingPictureAccentProcess
```

Použijte k zobrazení rostoucí řady obrázků s popisným textem. Nejlépe funguje s malým množstvím textu.

### Balance {#Balance}
```
public static final int Balance
```

Použijte k porovnání nebo zobrazení vztahu mezi dvěma myšlenkami. Každý z prvních dvou řádků Level 1 textu odpovídá textu na vrcholu jedné strany středu. Zdůrazňuje Level 2 text, který je omezen na čtyři tvary na každé straně středu. Vyvážení se nakloní ke straně s nejvíce tvary obsahujícími Level 2 text. Nepoužitý text se nezobrazuje, ale zůstává k dispozici při změně rozvržení.

### BasicBendingProcess {#BasicBendingProcess}
