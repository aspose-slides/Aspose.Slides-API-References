Αμετάβλητο αντικείμενο που αντιπροσωπεύει ένα εφέ Alpha Bi-Level. Οι τιμές Alpha (Αδιαφάνεια) μικρότερες από το όριο μετατρέπονται σε 0 (πλήρως διαφανές) και οι τιμές alpha ίσες ή μεγαλύτερες από το όριο μετατρέπονται σε 100 % (πλήρως αδιαφανές).
