public interface IMathPhantom extends IMathElement

Αντιστοιχεί σε ένα φανταστικό μαθηματικό αντικείμενο (<m:phant>) που επηρεάζει τη διάταξη του στοιχείου-παιδιού του χωρίς απαραίτητα να το εμφανίζει. Ένα φαντάσμα μπορεί να κρύψει την βασική έκφραση διατηρώντας το πλάτος, το ύψος ή το βάθος του για να ευθυγραμμίσει τύπους ή να κρατήσει χώρο. Η ορατότητα και η γεωμετρική συμπεριφορά ελέγχονται από ιδιότητες όπως Show, ZeroWid, ZeroAsc, ZeroDesc, και Transp.

--------------------

> ```
> Example:
>  
>  IMathPhantom phantom = new MathPhantom(new MathematicalText("1/2"));
>  phantom.setShow(false);          // Απόκρυψη του περιεχομένου
>  phantom.setZeroWidth(false);     // Διατήρηση του πλάτους
```

### getTransp() {#getTransp--}
```
public abstract boolean getTransp()
```

Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν το φάντασμα είναι διαφανές για τους κανόνες απόστασης με βάση την κατηγορία.

--------------------

Όταν είναι true, οι τελεστές και τα σύμβολα εντός του φαντάσματος επηρεάζουν ακόμη τη μαθηματική απόσταση γύρω από το φάντασμα (σαν να είναι ορατό). Όταν είναι false, οι κανόνες απόστασης με βάση την κατηγορία αγνοούνται. Συμφωνεί με το χαρακτηριστικό OMML m:transp.
