### getRotationAngle() {#getRotationAngle--}
```
public abstract float getRotationAngle()
```

Καθορίζει την προσαρμοσμένη περιστροφή που εφαρμόζεται στο κείμενο εντός του περιοριστικού πλαισίου. Εάν δεν καθοριστεί, χρησιμοποιείται η περιστροφή του συνοδευτικού σχήματος. Εάν καθοριστεί, αυτή εφαρμόζεται ανεξάρτητα από το σχήμα. Δηλαδή το σχήμα μπορεί να έχει μια περιστροφή επιπλέον της περιστροφής που εφαρμόζεται στο κείμενο. Η προκύπτουσα τιμή της οπτικής περιστροφής του κειμένου συνοψίζεται από αυτήν την ιδιότητα και τον προσαρμοσμένο κάθετο τύπο στην ιδιότητα TextVerticalType. Ανάγνωση/εγγραφή float.

--------------------

> ```
> Σκεφτείτε την περίπτωση όπου ένα σχήμα έχει μια περιστροφή 90 μοιρών δεξιόστροφα εφαρμοσμένη σε αυτό. 
>  Επιπλέον, το ίδιο το σώμα κειμένου έχει μια περιστροφή -90 μοιρών αριστερόστροφα εφαρμοσμένη σε αυτό. Στη συνέχεια το προκύπτον σχήμα θα φαίνεται να
>  γυρίζει, αλλά το κείμενο μέσα σε αυτό θα φαίνεται σαν να μην έχει περιστραφεί καθόλου.
> ```

**Επιστρέφει:**
