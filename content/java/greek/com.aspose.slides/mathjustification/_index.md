### CenteredAsGroup {#CenteredAsGroup}



Κεντράρισμα στη σελίδα ολόκληρης της ομάδας μαθηματικών μπλοκ ως ενιαία μονάδα. Αυτό σημαίνει ότι οι εμφανίσεις του μαθηματικού κειμένου μπορούν να στοιχιστούν μεταξύ τους, αλλά η ολόκληρη ομάδα του μαθηματικού κειμένου κεντράρίζεται ως σύνολο.
