public interface IErrorBarsCustomValues
```

Καθορίζει τις τιμές των μπαρών σφάλματος. Θα πρέπει να χρησιμοποιείται μόνο όταν ο τύπος τιμής των μπαρών σφάλματος είναι Custom.

### getXMinus() {#getXMinus--}
```
public abstract IDoubleChartValue getXMinus()
```


Καθορίζει την τιμή της μπάρας σφάλματος στη αρνητική κατεύθυνση. Διαθέσιμο εάν ο τύπος τιμής των μπαρών σφάλματος είναι Custom και η ErrorBarsXFormat είναι επιτρεπτή. Σε οποιαδήποτε άλλη περίπτωση αυτή η ιδιότητα επιστρέφει null. Μόνο για ανάγνωση [IDoubleChartValue](../../com.aspose.slides/idoublechartvalue).
