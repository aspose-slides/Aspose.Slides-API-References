## Πεδία

| Πεδίο | Περιγραφή |
| --- | --- |
| [SingleSpacingGap](#SingleSpacingGap) | Μοναδικό (1 em για στήλες ή 1 γραμμή για γραμμές) |
| [OneAndHalfSpacingGap](#OneAndHalfSpacingGap) | Μία και μισή (1,5 em για στήλες ή 1,5 γραμμές για γραμμές) |
| [DoubleSpacingGap](#DoubleSpacingGap) | Διπλή απόσταση (2 em για στήλες ή 2 γραμμές για γραμμές) |
| [Exactly](#Exactly) | Ακριβής τιμή. Για στήλες, βασίζεται στην τιμή του ColumnGap, μετρημένη σε twips. Για γραμμές, βασίζεται στην τιμή του RowGap, μετρημένη σε twips. |
| [Multiple](#Multiple) | Πολλαπλό. Για στήλες, βασίζεται στην τιμή του ColumnGap, μετρημένη σε βήματα 0,5 em. Για γραμμές, βασίζεται στην τιμή του RowGap, μετρημένη σε γραμμές. |
