```
public interface IGrayScaleEffectiveData extends IEffectEffectiveData
```

Αμετάβλητο αντικείμενο που αντιπροσωπεύει μια Gray Scale επίδραση. Μετατρέπει όλες τις τιμές χρώματος της επίδρασης σε μια απόχρωση του γκρι, που αντιστοιχεί στη φωτεινότητά τους. Οι τιμές alpha (opacity) της επίδρασης δεν επηρεάζονται.
