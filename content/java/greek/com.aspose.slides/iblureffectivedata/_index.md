Αμετάβλητο αντικείμενο που αντιπροσωπεύει ένα εφέ Θολώματος που εφαρμόζεται σε ολόκληρο το σχήμα, συμπεριλαμβανομένου του γεμίσματος. Όλα τα χρωματικά κανάλια, συμπεριλαμβανομένου του άλφα, επηρεάζονται.

### getGrow() {#getGrow--}
```
public abstract boolean getGrow()
```

Καθορίζει εάν τα όρια του αντικειμένου πρέπει να αυξηθούν ως αποτέλεσμα του θολώματος. Η τιμή true υποδεικνύει ότι τα όρια αυξάνονται, ενώ false ότι δεν γίνεται. Μόνο για ανάγνωση boolean.

**Επιστρέφει:**
boolean
