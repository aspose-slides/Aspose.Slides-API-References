Αμετάβλητο αντικείμενο που αντιπροσωπεύει ένα εφέ Alpha Floor. Οι τιμές Alpha (opacity) μικρότερες από 100% αλλάζουν σε μηδέν. Με άλλα λόγια, οτιδήποτε είναι μερικώς διαφανές γίνεται πλήρως διαφανές.
