Καθορίζει την κατάσταση στην οποία πρέπει να εμφανίζεται η γραμμή διαχωριστή. Η γραμμή διαχωριστή χωρίζει μια κύρια και μια δευτερεύουσα περιοχή εντός μιας περιοχής προβολής.
## Πεδία

| Πεδίο | Περιγραφή |
| --- | --- |
| [Minimized](#Minimized) | Η κύρια περιοχή καταλαμβάνει την ελάχιστη ποσότητα της περιοχής προβολής που επιτρέπεται από την εφαρμογή. |
| [Restored](#Restored) | Η κύρια περιοχή έχει ένα συγκεκριμένο ενδιάμεσο μέγεθος. |
| [Maximized](#Maximized) | Η κύρια περιοχή καταλαμβάνει τη μεγαλύτερη ποσότητα της περιοχής προβολής που επιτρέπεται από την εφαρμογή. |
