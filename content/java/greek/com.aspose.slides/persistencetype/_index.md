### NotDefined {#NotDefined}



Το αναγνωριστικό διατήρησης δεν έχει καθοριστεί.

### PersistPropertyBag {#PersistPropertyBag}
```
public static final int PersistPropertyBag
```


Καθορίζει ότι ο έλεγχος ActiveX διατηρείται χρησιμοποιώντας διατήρηση που βασίζεται σε property-bag. Η διατήρηση βασισμένη σε property-bag αποθηκεύει έναν έλεγχο ActiveX μέσω μιας συλλογής ζευγών ονομασίας και τιμής που καθορίζουν τα δεδομένα που διατηρούνται από τον έλεγχο ActiveX.
