### Installable {#Installable}
```
public static final int Installable
```

Οι γραμματοσειρές με αυτή τη ρύθμιση υποδεικνύουν ότι μπορούν να ενσωματωθούν και να εγκατασταθούν μόνιμα στο απομακρυσμένο σύστημα από μια εφαρμογή. Ο χρήστης του απομακρυσμένου συστήματος αποκτά τα ίδια δικαιώματα, υποχρεώσεις και άδειες για εκείνη τη γραμματοσειρά όπως ο αρχικός αγοραστής, και υπόκειται στην ίδια συμφωνία άδειας τελικού χρήστη, πνευματικά δικαιώματα, πατέντα σχεδίου και/ή εμπορικό σήμα όπως ο αρχικός αγοραστής.

### Restricted {#Restricted}
```
public static final int Restricted
```

Οι γραμματοσειρές που έχουν μόνο αυτό το bit ενεργό δεν πρέπει να τροποποιηθούν, να ενσωματωθούν ή να ανταλλαχθούν με κανέναν τρόπο χωρίς πρώτα να ληφθεί άδεια από τον νόμιμο κάτοχο.

### PreviewPrint {#PreviewPrint}
```
public static final int PreviewPrint
```

Όταν αυτό το bit είναι ενεργό, η γραμματοσειρά μπορεί να ενσωματωθεί και να φορτωθεί προσωρινά στο απομακρυσμένο σύστημα. Τα έγγραφα που περιέχουν γραμματοσειρές Preview & Print πρέπει να ανοίγουν σε «μόνο-ανάγνωση»· δεν μπορούν να γίνει επεξεργασίες στο έγγραφο.

### Editable {#Editable}
```
public static final int Editable
```

Όταν αυτό το bit είναι ενεργό, η γραμματοσειρά μπορεί να ενσωματωθεί αλλά πρέπει να εγκατασταθεί μόνο προσωρινά σε άλλα συστήματα. Σε αντίθεση με τις γραμματοσειρές Preview & Print, τα έγγραφα που περιέχουν γραμματοσειρές Editable μπορούν να ανοίγουν για ανάγνωση, η επεξεργασία επιτρέπεται και οι αλλαγές μπορούν να αποθηκευτούν.

### NoSubsetting {#NoSubsetting}
```
public static final int NoSubsetting
```

Όταν αυτό το bit είναι ενεργό, δεν επιτρέπεται η υποσυνολοποίηση της γραμματοσειράς πριν την ενσωμάτωση. Επίσης ισχύουν άλλοι περιορισμοί ενσωμάτωσης που καθορίζονται στα bits 0-3 και 9.

### BitmapOnly {#BitmapOnly}
```
public static final int BitmapOnly
```

Όταν αυτό το bit είναι ενεργό, μόνο τα bitmap που περιέχονται στη γραμματοσειρά μπορούν να ενσωματωθούν. Δεν μπορούν να ενσωματωθούν δεδομένα περιγράμματος. Εάν δεν υπάρχουν διαθέσιμα bitmap στη γραμματοσειρά, τότε η γραμματοσειρά θεωρείται μη ενσωματώσιμη και οι υπηρεσίες ενσωμάτωσης θα αποτύχουν.
