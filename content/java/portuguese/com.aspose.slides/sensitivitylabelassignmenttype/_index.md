Representa o método de atribuição para o rótulo de sensibilidade.
## Campos

| Campo | Descrição |
| --- | --- |
| [Standard](#Standard) | Use para qualquer rótulo de sensibilidade que não foi aplicado diretamente pelo usuário. |
| [Privileged](#Privileged) | Use para qualquer rótulo de sensibilidade que foi aplicado diretamente pelo usuário. |
### Padrão {#Standard}
```
public static final int Standard
```

Use para qualquer rótulo de sensibilidade que não foi aplicado diretamente pelo usuário. Isso inclui rótulos padrão e rótulos aplicados automaticamente.

### Privilegiado {#Privileged}
```
public static final int Privileged
```

Use para qualquer rótulo de sensibilidade que foi aplicado diretamente pelo usuário. Isso inclui rótulos de sensibilidade aplicados manualmente, bem como rotulagem recomendada ou obrigatória ou qualquer recurso onde o usuário decide qual rótulo de sensibilidade aplicar.
