Representa o tipo de posição dos rótulos de marca de escala no eixo especificado.
## Campos

| Campo | Descrição |
| --- | --- |
| [High](#High) | Especifica que os rótulos do eixo devem estar no extremo superior do eixo perpendicular. |
| [Low](#Low) | Especifica que os rótulos do eixo devem estar no extremo inferior do eixo perpendicular. |
| [NextTo](#NextTo) | Especifica que os rótulos do eixo devem estar ao lado do eixo. |
| [None](#None) | Especifica que os rótulos do eixo não são desenhados. |
