```
public final class InkEffectType extends System.Enum
```

Especifica um conjunto de efeitos visuais predefinidos para a renderização de tinta. Cada efeito corresponde a uma textura ou imagem que simula uma aparência de tinta estilizada. Esses valores podem ser usados para personalizar o estilo visual dos traços de tinta digital durante a renderização.
## Campos

| Campo | Descrição |
| --- | --- |
| [NotDefined](#NotDefined) | O efeito não está definido ou é desconhecido. |
| [Bronze](#Bronze) | Uma textura metálica quente, marrom, semelhante à tinta de bronze. |
| [Galaxy](#Galaxy) | Uma textura colorida e cintilante que se assemelha a uma galáxia, com tons cósmicos. |
| [Gold](#Gold) | Uma textura metálica dourada brilhante que confere aos traços de tinta uma aparência luxuosa. |
| [Lava](#Lava) | Uma textura flamejante que se assemelha a lava fundida, com tons vermelhos e laranja. |
| [Ocean](#Ocean) | Uma textura azul profunda, semelhante a um fluido, que imita ondas oceânicas ou tinta à base de água. |
| [RainbowGlitter](#RainbowGlitter) | Um efeito cintilante e colorido de glitter arco-íris usado para traços de tinta festivos ou vibrantes. |
| [RoseGold](#RoseGold) | Uma mistura suave de rosa e dourado, semelhante ao rose gold, para traços de tinta elegantes. |
| [Silver](#Silver) | Uma textura metálica prata fria que simula tinta prata clássica. |
