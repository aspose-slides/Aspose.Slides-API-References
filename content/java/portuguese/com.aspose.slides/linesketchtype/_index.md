Representa qual tipo de esboço ou efeito foi atribuído a uma forma.
## Campos

| Campo | Descrição |
| --- | --- |
| [NotDefined](#NotDefined) | Especifica que o efeito Sketch de uma forma está indefinido. |
| [None](#None) | Especifica que uma forma não tem efeito Sketch. |
| [Curved](#Curved) | Especifica que uma forma tem o efeito Curved, que transforma cada borda da forma em uma grande curva suave. |
| [Freehand](#Freehand) | Especifica que uma forma tem o efeito Freehand, que se assemelha mais a uma linha desenhada imperfeitamente. |
| [Scribble](#Scribble) | Especifica que uma forma tem o efeito Scribble, que possui oscilações exageradas como se fosse desenhado propositalmente bagunçado. |
