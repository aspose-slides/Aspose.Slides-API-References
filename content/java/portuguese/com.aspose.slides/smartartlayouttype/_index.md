### AccentProcess {#AccentProcess}
```
public static final int AccentProcess
```

Use para mostrar uma progressão, uma linha do tempo ou etapas sequenciais em uma tarefa, processo ou fluxo de trabalho. Funciona bem para ilustrar tanto o texto de Level 1 quanto o de Level 2.

### AccentedPicture {#AccentedPicture}
```
public static final int AccentedPicture
```


Use para mostrar uma ideia fotográfica central com ideias relacionadas ao lado. O texto de Level 1 superior aparece sobre a imagem central. O texto correspondente para outras formas de Level 1 aparece ao lado das pequenas imagens circulares. Esse layout também funciona bem sem texto.

### AlternatingFlow {#AlternatingFlow}
```
public static final int AlternatingFlow
```


Use para mostrar grupos de informação ou etapas sequenciais em uma tarefa, processo ou fluxo de trabalho. Enfatiza a interação ou os relacionamentos entre os grupos de informação.

### AlternatingHexagons {#AlternatingHexagons}
```
public static final int AlternatingHexagons
```


Use para representar uma série de ideias interconectadas. O texto de Level 1 aparece dentro dos hexágonos. O texto de Level 2 aparece fora das formas.

### AlternatingPictureBlocks {#AlternatingPictureBlocks}
```
public static final int AlternatingPictureBlocks
```


Use para mostrar uma série de imagens de cima para baixo. O texto aparece alternadamente à direita ou à esquerda da imagem.

### AlternatingPictureCircles {#AlternatingPictureCircles}
```
public static final int AlternatingPictureCircles
```


Use para mostrar um conjunto de imagens com texto. O texto correspondente aparece nos círculos centrais, com as imagens alternando da esquerda para a direita.

### ArrowRibbon {#ArrowRibbon}
```
public static final int ArrowRibbon
```


Use para mostrar conceitos relacionados ou contrastantes com alguma conexão, como forças opostas. As duas primeiras linhas de texto de Level 1 são usadas para o texto nas setas. O texto não utilizado não aparece, mas permanece disponível se você mudar o layout.

### AscendingPictureAccentProcess {#AscendingPictureAccentProcess}
```
public static final int AscendingPictureAccentProcess
```


Use para mostrar uma série ascendente de imagens com texto descritivo. Funciona melhor com uma pequena quantidade de texto.

### Balance {#Balance}
```
public static final int Balance
```


Use para comparar ou mostrar a relação entre duas ideias. Cada uma das duas primeiras linhas de texto de Level 1 corresponde ao texto na parte superior de um lado do ponto central. Enfatiza o texto de Level 2, que fica limitado a quatro formas em cada lado do ponto central. O equilíbrio inclina-se para o lado que possui mais formas contendo texto de Level 2. O texto não utilizado não aparece, mas permanece disponível se você mudar o layout.

### BasicBendingProcess {#BasicBendingProcess}
```
public static final int BasicBendingProcess

### BasicChevronProcess {#BasicChevronProcess}
```
public static final int BasicChevronProcess

Use para mostrar uma progressão; uma linha do tempo; etapas sequenciais em uma tarefa, processo ou fluxo de trabalho; ou para enfatizar movimento ou direção. O texto de Level 1 aparece dentro de uma forma de seta, enquanto o texto de Level 2 aparece abaixo das formas de seta.

public static final int BasicCycle

### BasicMatrix {#BasicMatrix}
```
public static final int BasicMatrix
```


Use para mostrar a relação dos componentes com um todo em quadrantes. As quatro primeiras linhas de texto de Level 1 aparecem nos quadrantes. O texto não utilizado não aparece, mas permanece disponível se você mudar o layout.

### BasicPie {#BasicPie}
```
public static final int BasicPie
```


Use para mostrar como partes individuais formam um todo. As sete primeiras linhas de texto de Level 1 correspondem às formas de fatia ou pizza distribuídas uniformemente. A forma de texto de Level 1 superior aparece fora do restante da pizza para ênfase. O texto não utilizado não aparece, mas permanece disponível se você mudar o layout.

### BasicRadial {#BasicRadial}

public static final int BasicRadial

### BasicVenn {#BasicVenn}
```
public static final int BasicVenn
```


Use para mostrar relações sobrepostas ou interconectadas. As sete primeiras linhas de texto de Level 1 correspondem a um círculo. Se houver quatro linhas ou menos de texto de Level 1, o texto fica dentro dos círculos. Se houver mais de quatro linhas de texto de Level 1, o texto fica fora dos círculos. O texto não utilizado não aparece, mas permanece disponível se você mudar o layout.
