## Campos

| Campo | Descrição |

| [OnFocusIn](#OnFocusIn) | Ocorre quando um elemento recebe foco, como quando um texto é selecionado. |

| [OnActivate](#OnActivate) | Ocorre quando um elemento é ativado, por exemplo, através de um clique do mouse ou de um pressionamento de tecla. |
| [OnClick](#OnClick) | Ocorre quando o botão do dispositivo apontador é clicado sobre um elemento. |
| [OnMouseDown](#OnMouseDown) | Ocorre quando o botão do dispositivo apontador é pressionado sobre um elemento. |
| [OnMouseUp](#OnMouseUp) | Ocorre quando o botão do dispositivo apontador é liberado sobre um elemento. |
| [OnMouseOver](#OnMouseOver) | Ocorre quando o dispositivo apontador é movido sobre um elemento. |
| [OnMouseMove](#OnMouseMove) | Ocorre quando o dispositivo pontador é movido enquanto está sobre um elemento. |
| [OnMouseOut](#OnMouseOut) | Ocorre quando o dispositivo apontador se afasta de um elemento. |
| [OnLoad](#OnLoad) | Ocorre quando o agente de usuário analisou completamente o elemento e seus descendentes e todos os recursos referenciados, necessários para renderizá-lo. |
| [OnUnload](#OnUnload) | Ocorre quando a implementação do DOM remove um documento de uma janela ou quadro. |
| [OnAbort](#OnAbort) | Ocorre quando o carregamento da página é interrompido antes que um elemento tenha sido totalmente carregado. |
| [OnError](#OnError) | Ocorre quando um elemento não carrega corretamente ou quando ocorre um erro durante a execução de script. |
| [OnResize](#OnResize) | Ocorre quando a visualização do documento está sendo redimensionada. |
| [OnScroll](#OnScroll) | Ocorre quando a visualização do documento está sendo deslocada ao longo do eixo X ou Y ou ambos. |
| [OnZoom](#OnZoom) | Ocorre quando o nível de zoom da visualização do documento está sendo alterado. |
| [OnBegin](#OnBegin) | Ocorre quando um elemento de animação começa. |
| [OnEnd](#OnEnd) | Ocorre quando um elemento de animação termina. |
| [OnRepeat](#OnRepeat) | Ocorre quando um elemento de animação se repete. |
