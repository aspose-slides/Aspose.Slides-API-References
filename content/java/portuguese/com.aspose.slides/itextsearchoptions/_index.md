public interface ITextSearchOptions
```

Representa opções que podem ser usadas para pesquisar texto em uma Apresentação, Slide ou TextFrame.
## Métodos

| Método | Descrição |
| --- | --- |
| [getCaseSensitive()](#getCaseSensitive--) | Defina true para usar pesquisa sensível a maiúsculas e minúsculas, false - caso contrário. |
| [setCaseSensitive(boolean value)](#setCaseSensitive-boolean-) | Defina true para usar pesquisa sensível a maiúsculas e minúsculas, false - caso contrário. |
| [getWholeWordsOnly()](#getWholeWordsOnly--) | Defina true para corresponder apenas palavras inteiras, false - caso contrário. |
| [setWholeWordsOnly(boolean value)](#setWholeWordsOnly-boolean-) | Defina true para corresponder apenas palavras inteiras, false - caso contrário. |
| [getIncludeNotes()](#getIncludeNotes--) | Defina true para incluir texto contido em notas de slide ao realizar pesquisas de texto, substituição ou operações de realce. |
| [setIncludeNotes(boolean value)](#setIncludeNotes-boolean-) | Defina true para incluir texto contido em notas de slide ao realizar pesquisas de texto, substituição ou operações de realce. |
