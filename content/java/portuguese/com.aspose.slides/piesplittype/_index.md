Representa um tipo de pontos de divisão no segundo conjunto de pizza ou barra em um gráfico de pizza-de-pizza ou barra-de-pizza.
## Campos

| Campo | Descrição |
| --- | --- |
| [Default](#Default) | Especifica que os pontos de dados devem ser divididos usando o mecanismo padrão para este tipo de gráfico. |
| [Custom](#Custom) | Especifica que os pontos de dados devem ser divididos entre a pizza e o segundo gráfico de acordo com os valores Custom Split. |
| [ByPercentage](#ByPercentage) | Especifica que os pontos de dados devem ser divididos entre a pizza e o segundo gráfico colocando os pontos com porcentagem inferior a Split Position por cento no segundo gráfico. |
| [ByPos](#ByPos) | Especifica que os pontos de dados devem ser divididos entre a pizza e o segundo gráfico colocando a última Split Position dos pontos de dados no segundo gráfico. |
| [ByValue](#ByValue) | Especifica que os pontos de dados devem ser divididos entre a pizza e o segundo gráfico colocando os pontos de dados com valor inferior a Split Position no segundo gráfico. |
