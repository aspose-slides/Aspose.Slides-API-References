### قابل للتثبيت {#Installable}
```
public static final int Installable
```

تشير الخطوط بهذه الإعداد إلى إمكانية تضمينها وتثبيتها بشكل دائم على النظام البعيد بواسطة تطبيق. يحصل مستخدم النظام البعيد على نفس الحقوق والالتزامات والتراخيص لهذا الخط كما يحصل المشتري الأصلي للخط، وهو خاضع لنفس اتفاقية ترخيص المستخدم النهائي وحقوق النشر وبراءة التصميم و/أو العلامة التجارية كما كان المشتري الأصلي.

### مقيد {#Restricted}
```
public static final int Restricted
```

يجب عدم تعديل الخطوط التي تم تعيين هذا البت فقط فيها أو تضمينها أو تبادلها بأي طريقة دون الحصول أولاً على إذن من المالك القانوني.

### معاينة وطباعة {#PreviewPrint}
```
public static final int PreviewPrint
```

عند تعيين هذا البت، يمكن تضمين الخط وتحميله مؤقتًا على النظام البعيد. يجب فتح المستندات التي تحتوي على خطوط المعاينة والطباعة في وضع "قراءة فقط"؛ لا يمكن إجراء أي تعديلات على المستند.

### قابل للتحرير {#Editable}
```
public static final int Editable
```

عند تعيين هذا البت، يمكن تضمين الخط ولكن يجب تثبيته مؤقتًا فقط على الأنظمة الأخرى. على عكس خطوط المعاينة والطباعة، يمكن فتح المستندات التي تحتوي على خطوط قابلة للتحرير للقراءة، ويسمح بالتحرير، ويمكن حفظ التغييرات.

### بدون تقليل {#NoSubsetting}
```
public static final int NoSubsetting
```

عند تعيين هذا البت، لا يجوز تقليل الخط إلى مجموعة فرعية قبل التضمين. كما تنطبق قيود التضمين الأخرى المحددة في البتات 0-3 و9.

### صور نقطية فقط {#BitmapOnly}
```
public static final int BitmapOnly
```

عند تعيين هذا البت، يمكن تضمين الصور النقطية المتوفرة فقط في الخط. لا يمكن تضمين بيانات التخطيط. إذا لم تتوفر صور نقطية في الخط، يُعتبر الخط غير قابل للتضمين وستفشل خدمات التضمين.
