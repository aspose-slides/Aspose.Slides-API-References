Stellt einen Manager dar, der das Verhalten der Fußzeilen-, Datums-/Uhrzeit- und Seitenzahl-Platzhalter der Master-Notizfolie sowie aller untergeordneten Platzhalter verwaltet. Untergeordnete Platzhalter bedeuten, dass Platzhalter auf abhängigen Notizfolien enthalten sind. Abhängige Notizfolien verwenden und basieren auf der Master-Notizfolie.
