Gibt an, in welchem Zustand die Trennleiste angezeigt werden soll. Die Trennleiste trennt einen primären und einen sekundären Bereich innerhalb eines Anzeigebereichs.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [Minimized](#Minimized) | Der primäre Bereich nimmt den geringsten vom Programm zulässigen Anteil des Anzeigebereichs ein. |
| [Restored](#Restored) | Der primäre Bereich hat eine spezifische mittlere Größe. |
| [Maximized](#Maximized) | Der primäre Bereich nimmt den größten vom Programm zulässigen Anteil des Anzeigebereichs ein. |
