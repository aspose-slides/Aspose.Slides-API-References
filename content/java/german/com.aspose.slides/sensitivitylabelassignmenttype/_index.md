Stellt die Zuweisungsmethode für das Sensitivitätslabel dar.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [Standard](#Standard) | Verwenden Sie für jedes Sensitivitätslabel, das nicht direkt vom Benutzer angewendet wurde. |
| [Privileged](#Privileged) | Verwenden Sie für jedes Sensitivitätslabel, das direkt vom Benutzer angewendet wurde. |
### Standard {#Standard}
```
public static final int Standard
```

Verwenden Sie für jedes Sensitivitätslabel, das nicht direkt vom Benutzer angewendet wurde. Dies schließt alle Standard-Labels und automatisch angewendete Labels ein.

### Privilegiert {#Privileged}
```
public static final int Privileged
```

Verwenden Sie für jedes Sensitivitätslabel, das direkt vom Benutzer angewendet wurde. Dies schließt alle manuell angewendeten Sensitivitätslabels sowie empfohlene oder verpflichtende Kennzeichnungen oder jede Funktion, bei der der Benutzer entscheidet, welches Sensitivitätslabel angewendet werden soll, ein.
