Unveränderliches Objekt, das einen Alpha-Ceiling-Effekt darstellt. Alpha (Deckkraft)-Werte, die größer als null sind, werden auf 100% geändert. Mit anderen Worten, alles teilweise undurchsichtig wird vollständig undurchsichtig.
