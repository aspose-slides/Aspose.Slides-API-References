Stellt einen Alpha Modulate-Effekt dar. Effekt-Alpha (Deckkraft)-Werte werden mit einem festen Prozentsatz multipliziert. Der Effekt-Container gibt einen Effekt an, der Alpha-Werte zur Modulation enthält.
