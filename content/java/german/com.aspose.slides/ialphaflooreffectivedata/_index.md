Unveränderliches Objekt, das einen Alpha-Floor-Effekt darstellt. Alpha (opacity)-Werte, die kleiner als 100 % sind, werden auf Null gesetzt. Mit anderen Worten: Alles, das teilweise transparent ist, wird vollständig transparent.
