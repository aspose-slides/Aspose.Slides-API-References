Stellt einen Typ von Aufteilungspunkten im zweiten Kuchen oder Balken eines Kuchen-aus-Kuchen- oder Balken-aus-Kuchen-Diagramms dar.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [Default](#Default) | Gibt an, dass die Datenpunkte mit dem Standard-Mechanismus für diesen Diagrammtyp aufgeteilt werden sollen. |
| [Custom](#Custom) | Gibt an, dass die Datenpunkte zwischen dem Kuchen und dem zweiten Diagramm gemäß den benutzerdefinierten Aufteilungswerten aufgeteilt werden sollen. |
| [ByPercentage](#ByPercentage) | Gibt an, dass die Datenpunkte zwischen dem Kuchen und dem zweiten Diagramm aufgeteilt werden, indem Punkte mit einem Prozentsatz kleiner als Split Position Prozent im zweiten Diagramm platziert werden. |
| [ByPos](#ByPos) | Gibt an, dass die Datenpunkte zwischen dem Kuchen und dem zweiten Diagramm aufgeteilt werden, indem die letzte Split Position der Datenpunkte im zweiten Diagramm platziert wird. |
| [ByValue](#ByValue) | Gibt an, dass die Datenpunkte zwischen dem Kuchen und dem zweiten Diagramm aufgeteilt werden, indem Datenpunkte mit einem Wert kleiner als Split Position im zweiten Diagramm platziert werden. |
