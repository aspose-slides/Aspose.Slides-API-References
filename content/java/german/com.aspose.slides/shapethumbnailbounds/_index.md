### Slide {#Slide}
```
public static final int Slide
```


Das Form-Miniatur hat die Größe der Folie. Die Position der Form wird gespeichert.

### Shape {#Shape}
```
public static final int Shape
```


Das Form-Miniatur hat die Größe des Begrenzungsrechtecks der Form, wobei die Kontureinstellungen der Form berücksichtigt werden.

### Appearance {#Appearance}
```
public static final int Appearance
```


Das Form-Miniatur hat die Größe des Erscheinungsbildes der Form (innerhalb der Folienbegrenzungen). Es kann Fälle geben, in denen das Erscheinungsbild der Form nicht in die Formbegrenzungen passt. Z. B. Drehung, Gehrungsschnitt eines spitzen Winkels, 3D-Effekte usw.
