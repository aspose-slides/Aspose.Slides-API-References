Gibt an, welchen Skizzen-Typ oder Effekt eine Form zugewiesen wurde.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [NotDefined](#NotDefined) | Gibt an, dass ein Sketch-Effekt einer Form nicht definiert ist. |
| [None](#None) | Gibt an, dass eine Form keinen Sketch-Effekt hat. |
| [Curved](#Curved) | Gibt an, dass eine Form den Curved-Effekt hat, der jede Kante der Form in eine große, sanfte Kurve verwandelt. |
| [Freehand](#Freehand) | Gibt an, dass eine Form den Freehand-Effekt hat, der einer unperfekt gezeichneten Linie am nächsten kommt. |
| [Scribble](#Scribble) | Gibt an, dass eine Form den Scribble-Effekt hat, der übertriebene Schwankungen aufweist, als wäre er absichtlich unordentlich gezeichnet. |
