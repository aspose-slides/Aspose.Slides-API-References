**Vererbung:**
java.lang.Object, com.aspose.ms.System.ValueType, com.aspose.ms.System.Enum
```
public final class InkEffectType extends System.Enum
```

Gibt einen Satz vordefinierter visueller Effekte für die Tintenwiedergabe an. Jeder Effekt entspricht einer Textur oder einem Bild, das ein stilisiertes Tinten-Aussehen simuliert. Diese Werte können verwendet werden, um den visuellen Stil digitaler Tintenstriche während der Wiedergabe anzupassen.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [NotDefined](#NotDefined) | Der Effekt ist nicht definiert oder unbekannt. |
| [Bronze](#Bronze) | Eine warme, bräunlich metallische Textur, die an bronzene Tinte erinnert. |
| [Galaxy](#Galaxy) | Eine farbenfrohe, schimmernde Textur, die einer Galaxie ähnelt, mit kosmischen Tönen. |
| [Gold](#Gold) | Eine helle, metallische Goldtextur, die Tintenstrichen ein luxuriöses Aussehen verleiht. |
| [Lava](#Lava) | Eine feurige Textur, die geschmolzener Lava ähnelt, mit roten und orangefarbenen Nuancen. |
| [Ocean](#Ocean) | Eine tiefblaue, flüssige Textur, die Ozeanwellen oder wasserbasierte Tinte nachahmt. |
| [RainbowGlitter](#RainbowGlitter) | Ein bunter, funkelnder Regenbogen-Glitzereffekt, der für festliche oder lebendige Tintenstriche verwendet wird. |
| [RoseGold](#RoseGold) | Eine sanfte pink-goldene Mischung, ähnlich zu Roségold, für elegante Tintenstriche. |
| [Silver](#Silver) | Eine kühle, metallische Silbertextur, die klassische Silber-Tinte simuliert. |
