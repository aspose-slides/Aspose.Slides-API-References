### getRotationAngle() {#getRotationAngle--}
```
public abstract float getRotationAngle()
```

Gibt die benutzerdefinierte Drehung an, die auf den Text innerhalb des Begrenzungsrahmens angewendet wird. Wenn nicht angegeben, wird die Drehung der zugehörigen Form verwendet. Wenn angegeben, wird sie unabhängig von der Form angewendet. Das bedeutet, die Form kann zusätzlich gedreht sein, während der Text selbst ebenfalls eine Drehung erhält. Der resultierende Wert der visuellen Textdrehung ergibt sich aus dieser Eigenschaft und dem vordefinierten vertikalen Typ in TextVerticalType. Lese/Schreib float.

--------------------

> ```
> Betrachten Sie den Fall, dass eine Form um 90 Grad im Uhrzeigersinn rotiert wurde. 
>  Zusätzlich dazu hat der Textkörper selbst eine Rotation von -90 Grad 
>  gegen den Uhrzeigersinn. Dann würde die resultierende Form scheinen zu
>  rotiert sein, aber der Text darin würde aussehen, als wäre er überhaupt nicht rotiert worden.
> ```


**Rückgabe:**
float
