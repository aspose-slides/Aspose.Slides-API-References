### ArrowRibbon {#ArrowRibbon}
```
public static final int ArrowRibbon
```

Verwenden Sie, um verwandte oder gegensätzliche Konzepte mit einer gewissen Verbindung, z.B.B. entgegenwirkenden Kräften, darzustellen. Die ersten beiden Zeilen des Level 1-Textes werden für den Text in den Pfeilen verwendet. Nicht genutzter Text wird nicht angezeigt, bleibt jedoch verfügbar, wenn Sie das Layout wechseln.

public static final int AscendingPictureAccentProcess

### Balance {#Balance}
```
public static final int Balance
```

Verwenden Sie, um zwei Ideen zu vergleichen oder deren Beziehung darzustellen. Jede der ersten beiden Zeilen des Level 1-Textes entspricht dem Text oben an einer Seite des Mittelpunktes. Betont Level 2-Text, der auf jeder Seite des Mittelpunktes auf vier Formen begrenzt ist. Das Gleichgewicht kippt zur Seite mit den meisten Formen, die Level 2-Text enthalten. Nicht genutzter Text wird nicht angezeigt, bleibt jedoch verfügbar, wenn Sie das Layout wechseln.

### BasicPie {#BasicPie}

public static final int BasicPie

Die oberste Level 1-Textform erscheint außen am restlichen Kreis zur Hervorhebung. Nicht genutzter Text wird nicht angezeigt, bleibt jedoch verfügbar, wenn Sie das Layout wechseln.

### BasicRadial {#BasicRadial}
```
public static final int BasicRadial
```
