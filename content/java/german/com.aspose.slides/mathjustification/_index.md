Gibt die Ausrichtung des mathematischen Absatzes an (eine Reihe benachbarter Instanzen von mathematischem Text innerhalb desselben Absatzes)
## Felder

| Feld | Beschreibung |
| --- | --- |
| [LeftJustified](#LeftJustified) | Mathematischen Text nach links ausrichten |
| [RightJustified](#RightJustified) | Mathematischen Text nach rechts ausrichten |
| [Centered](#Centered) | Mathematischen Text zentrieren |
| [CenteredAsGroup](#CenteredAsGroup) | Die gesamte Gruppe von Mathematikblöcken als Einheit auf der Seite zentrieren. |

### LeftJustified {#LeftJustified}
```
public static final int LeftJustified
```

Richtet den mathematischen Text linksbündig aus

### RightJustified {#RightJustified}
```
public static final int RightJustified
```

Richtet den mathematischen Text rechtsbündig aus

### Centered {#Centered}
```
public static final int Centered
```

Richtet den mathematischen Text zentriert aus

### CenteredAsGroup {#CenteredAsGroup}
```
public static final int CenteredAsGroup
```

Zentriert die gesamte Gruppe von Mathematikblöcken auf der Seite als eine einzelne Einheit. Das bedeutet, dass die Instanzen von mathematischem Text zueinander ausgerichtet werden können, aber die gesamte Gruppe von mathematischem Text als Ganzes zentriert ist.
