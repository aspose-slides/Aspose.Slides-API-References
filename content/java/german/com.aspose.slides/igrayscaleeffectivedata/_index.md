Unveränderliches Objekt, das einen Graustufen-Effekt darstellt. Konvertiert alle Effektfarbwerte in einen Grauton, der ihrer Luminanz entspricht. Effekt-Alpha-(Opazitäts-)Werte bleiben unverändert.
