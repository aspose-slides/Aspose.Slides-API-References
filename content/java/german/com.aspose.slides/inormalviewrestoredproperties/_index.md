public interface INormalViewRestoredProperties
```

Gibt die Größe des Folienbereichs an ((Breite, wenn ein Kind von restoredTop, Höhe, wenn ein Kind von restoredLeft) der Normalansicht, wenn die Region eine variable wiederhergestellte Größe hat (weder minimiert noch maximiert)).
