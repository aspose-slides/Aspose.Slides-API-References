Bevat klassen en methoden om complexe algemene bewerkingen op een low code manier af te handelen.
## Klassen

| Klasse | Beschrijving |
| :- | :- |
| [`Collect`](/slides/python-net/nl/aspose.slides.lowcode/collect/) | Stelt een groep methoden voor die bedoeld zijn om modelobjecten van verschillende typen te verzamelen van [`Presentation`](/slides/python-net/nl/aspose.slides/presentation). |
| [`Compress`](/slides/python-net/nl/aspose.slides.lowcode/compress/) | Stelt een groep methoden voor die bedoeld zijn om [`Presentation`](/slides/python-net/nl/aspose.slides/presentation) te comprimeren. |
| [`Convert`](/slides/python-net/nl/aspose.slides.lowcode/convert/) | Stelt een groep methoden voor die bedoeld zijn om [`Presentation`](/slides/python-net/nl/aspose.slides/presentation) te converteren. |
| [`ForEach`](/slides/python-net/nl/aspose.slides.lowcode/foreach/) | Stelt een groep methoden voor die bedoeld zijn om over verschillende [`Presentation`](/slides/python-net/nl/aspose.slides/presentation) modelobjecten te itereren.<br/>            Deze methoden kunnen nuttig zijn als je over sommige Presentation-elementen moet itereren en de opmaak of inhoud moet wijzigen,<br/>             bijv. de opmaak van elk gedeelte wijzigen. |
| [`Merger`](/slides/python-net/nl/aspose.slides.lowcode/merger/) | Stelt een groep methoden voor voor het samenvoegen van PowerPoint-presentaties van hetzelfde formaat tot één bestand. |
