## ParentLabelLayoutType enumeratie

Stelt de lay-out van categorielabels voor. Alleen gebruikt met Treemap-series.

Het type ParentLabelLayoutType biedt de volgende leden:

## Velden

| Field | Beschrijving |
| :- | :- |
| BANNER | Geeft aan dat oudercategorie-labels als banner worden weergegeven |
| NONE | Geeft aan dat oudercategorie-labels niet worden getekend |
| OVERLAPPING | Geeft aan dat oudercategorie-labels overlappend worden weergegeven |
