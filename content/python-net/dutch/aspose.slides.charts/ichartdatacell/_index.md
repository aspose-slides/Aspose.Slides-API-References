## IChartDataCell klasse

Stelt een cel voor diagramgegevens.

Het type IChartDataCell bevat de volgende leden:

## Eigenschappen

| Property | Description |
| :- | :- |
| [`row`](/slides/python-net/nl/aspose.slides.charts/ichartdatacell/row/) | Geeft de index van de rij van het werkblad waarin de cel zich bevindt terug.<br/>            Alleen-lezen **int**. |
| [`column`](/slides/python-net/nl/aspose.slides.charts/ichartdatacell/column/) | Geeft de index van de kolom van het werkblad waarin de cel zich bevindt terug.<br/>            Alleen-lezen **int**. |
| [`value`](/slides/python-net/nl/aspose.slides.charts/ichartdatacell/value/) | Haalt de waarde van een cel op of stelt deze in.<br/>            Lezen/schrijven **any**. |
| [`formula`](/slides/python-net/nl/aspose.slides.charts/ichartdatacell/formula/) | Haalt de formule in A1-stijl op of stelt deze in. |
| [`r1c1_formula`](/slides/python-net/nl/aspose.slides.charts/ichartdatacell/r1c1_formula/) | Haalt de formule in R1C1-stijl op of stelt deze in. |
| [`chart_data_worksheet`](/slides/python-net/nl/aspose.slides.charts/ichartdatacell/chart_data_worksheet/) | Haalt het werkblad op.<br/>            Alleen-lezen [`IChartDataWorksheet`](/slides/python-net/nl/aspose.slides.charts/ichartdataworksheet). |
| [`is_hidden`](/slides/python-net/nl/aspose.slides.charts/ichartdatacell/is_hidden/) | Bepaalt of de cel verborgen is.<br/>            Alleen-lezen **bool**. |
| [`custom_number_format`](/slides/python-net/nl/aspose.slides.charts/ichartdatacell/custom_number_format/) | Haalt het aangepaste weergaveformaat van nummers en datums op of stelt deze in.<br/>            Als de waarde leeg is, wordt de PresetNumberFormat-waarde gebruikt.<br/>            Lezen/schrijven **str**. |
| [`preset_number_format`](/slides/python-net/nl/aspose.slides.charts/ichartdatacell/preset_number_format/) | Haalt het ingebouwde weergaveformaat van nummers en datums op of stelt deze in. Het vooraf ingestelde nummer moet in [0..22] of [37..49] liggen.<br/>            Lezen/schrijven **int**. |
