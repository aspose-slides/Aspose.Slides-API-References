## is_chart_type_pie(chart_type) {#charttype}
Retourneer true als chartType een van de Pie-subtypen is.
            De set subtypen komt overeen met de overeenkomstige set in PowerPoint (zie dialoogvenster "Change Chart Type" in PowerPoint):
            [`ChartType.BAR_OF_PIE`](/slides/python-net/nl/aspose.slides.charts/charttype/BAR_OF_PIE),
            [`ChartType.EXPLODED_PIE`](/slides/python-net/nl/aspose.slides.charts/charttype/EXPLODED_PIE),
            [`ChartType.EXPLODED_PIE_3D`](/slides/python-net/nl/aspose.slides.charts/charttype/EXPLODED_PIE_3D),
            [`ChartType.PIE`](/slides/python-net/nl/aspose.slides.charts/charttype/PIE),
            [`ChartType.PIE_3D`](/slides/python-net/nl/aspose.slides.charts/charttype/PIE_3D),
            [`ChartType.PIE_OF_PIE`](/slides/python-net/nl/aspose.slides.charts/charttype/PIE_OF_PIE).
