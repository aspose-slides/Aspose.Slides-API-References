## is_chart_type_area(chart_type) {#charttype}
Retourneert true als chartType een van de Area-subtypen is.
            De set subtypen komt overeen met de juiste set in PowerPoint (zie het dialoogvenster "Change Chart Type" in PowerPoint):
            [`ChartType.AREA`](/slides/python-net/nl/aspose.slides.charts/charttype/AREA),
            [`ChartType.PERCENTS_STACKED_AREA`](/slides/python-net/nl/aspose.slides.charts/charttype/PERCENTS_STACKED_AREA),
            [`ChartType.PERCENTS_STACKED_AREA_3D`](/slides/python-net/nl/aspose.slides.charts/charttype/PERCENTS_STACKED_AREA_3D),
            [`ChartType.STACKED_AREA`](/slides/python-net/nl/aspose.slides.charts/charttype/STACKED_AREA),
            [`ChartType.STACKED_AREA_3D`](/slides/python-net/nl/aspose.slides.charts/charttype/STACKED_AREA_3D),
