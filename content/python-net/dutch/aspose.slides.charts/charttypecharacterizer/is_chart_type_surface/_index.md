## is_chart_type_surface(chart_type) {#charttype}
Retourneert true als chartType een van de Surface-subtypes is.
            Subtypes set corresponds to the appropriate set in PowerPoint (see "Change Chart Type" dialog in PowerPoint):
            [`ChartType.SURFACE_3D`](/slides/python-net/nl/aspose.slides.charts/charttype/SURFACE_3D),
            [`ChartType.WIREFRAME_SURFACE_3D`](/slides/python-net/nl/aspose.slides.charts/charttype/WIREFRAME_SURFACE_3D),
