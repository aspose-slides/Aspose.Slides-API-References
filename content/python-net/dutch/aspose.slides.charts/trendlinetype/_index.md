## TrendlineType enumeratie

Beschrijft het type trendlijn

Het type TrendlineType bevat de volgende leden:

## Velden

| Field | Description |
| :- | :- |
| EXPONENTIAL | Geeft aan dat de trendlijn een exponentiële curve in de vorm moet zijn. |
| LINEAR | Duidt aan dat de trendlijn een rechte lijn in de vorm moet zijn. |
| LOGARITHMIC | Geeft aan dat de trendlijn een logaritmische curve in de vorm is, waarbij log de natuurlijke logaritme is. |
| MOVING_AVERAGE | Geeft aan dat de trendlijn een voortschrijdend gemiddelde is van periode Period. |
| POLYNOMIAL | Geeft aan dat de trendlijn een polynomiale curve van orde Order in de vorm is. |
| POWER | Geeft aan dat de trendlijn een machtscurve in de vorm is. |
