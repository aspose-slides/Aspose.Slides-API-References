## hide(self) {#}
Maak het gegevenslabel verborgen door alle Show*-flags (ShowValue, ...) op false status te zetten.
IsVisible zal daarna false zijn.

```python
def hide(self):
    ...
```

### Opmerkingen
Als het gegevenslabel niet zichtbaar is (IsVisible is false) kun je het gegevenslabel zichtbaar maken door de Show*-flags (ShowValue, ...) op true status te zetten.
