## use_secondary_categories eigenschap
Als false dan [`ChartData.secondary_categories`](/slides/python-net/nl/aspose.slides.charts/chartdata/secondary_categories) eigenschap retourneert None en data 
            in [`ChartData.categories`](/slides/python-net/nl/aspose.slides.charts/chartdata/categories) eigenschap wordt zowel voor primaire als secundaire reeksen gebruikt.
            Als true dan data in [`ChartData.secondary_categories`](/slides/python-net/nl/aspose.slides.charts/chartdata/secondary_categories) eigenschap wordt gebruikt voor secundaire reeksen en data 
            in [`ChartData.categories`](/slides/python-net/nl/aspose.slides.charts/chartdata/categories) eigenschap wordt gebruikt voor primaire reeksen.
            Lezen/schrijven **bool**.
