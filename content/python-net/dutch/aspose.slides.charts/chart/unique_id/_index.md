## unique_id eigenschap
Retourneert een interne, presentatie-specifieke identificatie bedoeld voor gebruik door invoegtoepassingen of andere code.
            Omdat deze waarde door de gebruiker of programmatisch kan worden hertoegewezen, mag deze niet worden beschouwd als een blijvende unieke sleutel.
            Alleen-lezen **int**.
