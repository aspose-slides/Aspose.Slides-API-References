## LegendDataLabelPosition enumeratie

Bepaalt de positie van gegevenslabels.

Het type LegendDataLabelPosition biedt de volgende leden:

## Velden

| Field | Beschrijving |
| :- | :- |
| NOT_DEFINED | Positie is niet gedefinieerd. |
| BOTTOM | Specificeert dat gegevenslabels onder de gegevensmarkering worden weergegeven. |
| BEST_FIT | Specificeert dat gegevenslabels in de beste positie worden weergegeven. |
| CENTER | Specificeert dat gegevenslabels gecentreerd op de gegevensmarkering worden weergegeven. |
| INSIDE_BASE | Specificeert dat gegevenslabels binnen de basis van de gegevensmarkering worden weergegeven. |
| INSIDE_END | Specificeert dat gegevenslabels binnen het einde van de gegevensmarkering worden weergegeven. |
| LEFT | Specificeert dat gegevenslabels links van de gegevensmarkering worden weergegeven. |
| OUTSIDE_END | Specificeert dat gegevenslabels buiten het einde van de gegevensmarkering worden weergegeven. |
| RIGHT | Specificeert dat gegevenslabels rechts van de gegevensmarkering worden weergegeven. |
| TOP | Specificeert dat gegevenslabels boven de gegevensmarkering worden weergegeven. |
