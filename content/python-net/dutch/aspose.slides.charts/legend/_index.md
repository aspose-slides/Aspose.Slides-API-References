## Legend klasse

Stelt de eigenschappen van de legende van de grafiek voor.

Het type Legend bevat de volgende leden:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`x`](/slides/python-net/nl/aspose.slides.charts/legend/x/) | Geeft de x-coördinaat van een legende terug of stelt deze in als een fractie van de breedte van de grafiek.<br/>            Read/write **float**. |
| [`y`](/slides/python-net/nl/aspose.slides.charts/legend/y/) | Geeft de y-coördinaat van een legende terug of stelt deze in als een fractie van de hoogte van de grafiek.<br/>            Read/write **float**. |
| [`width`](/slides/python-net/nl/aspose.slides.charts/legend/width/) | Geeft de breedte van een legende terug of stelt deze in als een fractie van de breedte van de grafiek.<br/>            Read/write **float**. |
| [`height`](/slides/python-net/nl/aspose.slides.charts/legend/height/) | Geeft de hoogte van een legende terug of stelt deze in als een fractie van de hoogte van de grafiek.<br/>            Read/write **float**. |
| [`right`](/slides/python-net/nl/aspose.slides.charts/legend/right/) | Rechts.<br/>            Read-only **float**. |
| [`bottom`](/slides/python-net/nl/aspose.slides.charts/legend/bottom/) | Onder.<br/>            Read-only **float**. |
| [`overlay`](/slides/python-net/nl/aspose.slides.charts/legend/overlay/) | Bepaalt of andere grafiekelementen de legende mogen overlappen.<br/>            Read/write **bool**. |
| [`text_format`](/slides/python-net/nl/aspose.slides.charts/legend/text_format/) | Tekstopmaak.<br/>            Read-only [`IChartTextFormat`](/slides/python-net/nl/aspose.slides.charts/icharttextformat). |
| [`position`](/slides/python-net/nl/aspose.slides.charts/legend/position/) | Specificeert de positie van de legende op een grafiek.<br/>            Niet-NaN-waarden van X, Y, Width, Heigt eigenschappen overschrijven het effect van deze eigenschap.<br/>            Read/write [`LegendPositionType`](/slides/python-net/nl/aspose.slides.charts/legendpositiontype). |
| [`format`](/slides/python-net/nl/aspose.slides.charts/legend/format/) | Geeft het formaat van een legende terug.<br/>            Read-only [`IFormat`](/slides/python-net/nl/aspose.slides.charts/iformat). |
| [`chart`](/slides/python-net/nl/aspose.slides.charts/legend/chart/) | Geeft de grafiek terug.<br/>            Read-only [`IChart`](/slides/python-net/nl/aspose.slides.charts/ichart). |
| [`entries`](/slides/python-net/nl/aspose.slides.charts/legend/entries/) | Haalt legende-items op.<br/>            Read-only [`ILegendEntryCollection`](/slides/python-net/nl/aspose.slides.charts/ilegendentrycollection). |
| [`actual_x`](/slides/python-net/nl/aspose.slides.charts/legend/actual_x/) | Specificeert de daadwerkelijke x-locatie (links) van het grafiekelement ten opzichte van de linkerbovenhoek van de grafiek.<br/>            Roep de methode IChart.ValidateChartLayout() aan voordat u de werkelijke waarden opvraagt. <br/>            Read **float**. |
| [`actual_y`](/slides/python-net/nl/aspose.slides.charts/legend/actual_y/) | Specificeert de daadwerkelijke bovenkant van het grafiekelement ten opzichte van de linkerbovenhoek van de grafiek.<br/>            Roep de methode IChart.ValidateChartLayout() aan voordat u de werkelijke waarden opvraagt. <br/>            Read **float**. |
| [`actual_width`](/slides/python-net/nl/aspose.slides.charts/legend/actual_width/) | Specificeert de daadwerkelijke breedte van het grafiekelement. Roep de methode IChart.ValidateChartLayout() aan voordat u de werkelijke waarden opvraagt. <br/>            Read **float**. |
| [`actual_height`](/slides/python-net/nl/aspose.slides.charts/legend/actual_height/) | Specificeert de daadwerkelijke hoogte van het grafiekelement. Roep de methode IChart.ValidateChartLayout() aan voordat u de werkelijke waarden opvraagt. <br/>            Read **float**. |
