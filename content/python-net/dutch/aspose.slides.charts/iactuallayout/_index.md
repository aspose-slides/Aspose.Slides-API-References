## IActualLayout klasse

Specificeert de werkelijke positie van een grafiekelement.

Het IActualLayout type biedt de volgende leden:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`actual_x`](/slides/python-net/nl/aspose.slides.charts/iactuallayout/actual_x/) | Specificeert de werkelijke x-locatie (links) van het grafiekelement ten opzichte van de linkerbovenhoek van de grafiek.<br/>            Roep methode IChart.ValidateChartLayout() aan voordat je de werkelijke waarden krijgt. <br/>            Lees **float**. |
| [`actual_y`](/slides/python-net/nl/aspose.slides.charts/iactuallayout/actual_y/) | Specificeert de werkelijke bovenkant van het grafiekelement ten opzichte van de linkerbovenhoek van de grafiek.<br/>            Roep methode IChart.ValidateChartLayout() aan voordat je de werkelijke waarden krijgt. <br/>            Lees **float**. |
| [`actual_width`](/slides/python-net/nl/aspose.slides.charts/iactuallayout/actual_width/) | Specificeert de werkelijke breedte van het grafiekelement. Roep methode IChart.ValidateChartLayout() aan voordat je de werkelijke waarden krijgt. <br/>            Lees **float**. |
| [`actual_height`](/slides/python-net/nl/aspose.slides.charts/iactuallayout/actual_height/) | Specificeert de werkelijke hoogte van het grafiekelement. Roep methode IChart.ValidateChartLayout() aan voordat je de werkelijke waarden krijgt. <br/>            Lees **float**. |
