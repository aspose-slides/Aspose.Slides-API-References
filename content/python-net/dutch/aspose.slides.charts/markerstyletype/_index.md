## MarkerStyleType enumeratie

Bepaalt de vorm van de marker op het gegevenspunt van de grafiek.

Het type MarkerStyleType bevat de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| NOT_DEFINED |  |
| CIRCLE | Specificeert dat er op elk gegevenspunt een cirkel moet worden getekend. |
| DASH | Specificeert dat er op elk gegevenspunt een streep moet worden getekend. |
| DIAMOND | Specificeert dat er op elk gegevenspunt een diamant moet worden getekend. |
| DOT | Specificeert dat er op elk gegevenspunt een punt moet worden getekend. |
| NONE | Specificeert dat er niets moet worden getekend op elk gegevenspunt. |
| PICTURE | Specificeert dat er op elk gegevenspunt een afbeelding moet worden getekend. |
| PLUS | Specificeert dat er op elk gegevenspunt een plus moet worden getekend. |
| SQUARE | Specificeert dat er op elk gegevenspunt een vierkant moet worden getekend. |
| STAR | Specificeert dat er op elk gegevenspunt een ster moet worden getekend. |
| TRIANGLE | Specificeert dat er op elk gegevenspunt een driehoek moet worden getekend. |
| X | Specificeert dat er op elk gegevenspunt een X moet worden getekend. |
