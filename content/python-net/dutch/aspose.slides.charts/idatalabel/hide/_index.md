## hide(self) {#}
Maak het gegevenslabel verborgen door alle Show*-flags (ShowValue, ...) op de false status te zetten.
            IsVisible zal false zijn na deze actie.


```python
def hide(self):
    ...
```


### Opmerkingen

Als het gegevenslabel niet zichtbaar is (IsVisible is false) kun je het gegevenslabel zichtbaar maken door Show*-flags (ShowValue, ...) op true te zetten.
