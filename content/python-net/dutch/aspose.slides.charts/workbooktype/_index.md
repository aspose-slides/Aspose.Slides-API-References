## WorkbookType enumeratie

Specificeert het type Open XML-werkboekbestand.

Het type WorkbookType bevat de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| NOT_DEFINED | Het werkboektype is niet gedefinieerd. |
| WORKBOOK | Excel-werkboek (*.xlsx). |
| WORKBOOK_MACRO | Excel-werkboek met macro (*.xlsm). |
| TEMPLATE | Excel-sjabloon (*.xltx). |
| TEMPLATE_MACRO | Excel-sjabloon met macro (*.xltm). |
| WORKBOOK_BINARY_MACRO | Excel-binair werkboek met macro (*.xlsb). |
