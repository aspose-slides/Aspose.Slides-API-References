## DataLabelCollection klasse

Stelt een reeks labels voor.

Het type DataLabelCollection geeft de volgende leden weer:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`chart`](/slides/python-net/nl/aspose.slides.charts/datalabelcollection/chart/) | Retourneert de bovenliggende grafiek.<br/>            Alleen-lezen [`IChart`](/slides/python-net/nl/aspose.slides.charts/ichart). |
| [`is_visible`](/slides/python-net/nl/aspose.slides.charts/datalabelcollection/is_visible/) | False betekent dat het gegevenslabel standaard niet zichtbaar is (en dus zijn alle <br/>            Show*-vlaggen (ShowValue, ...) van de eigenschap DefaultDataLabelFormat false).<br/>            Alleen-lezen **bool**. |
| [`count_of_visible_data_labels`](/slides/python-net/nl/aspose.slides.charts/datalabelcollection/count_of_visible_data_labels/) | Haalt het aantal zichtbare gegevenslabels op in de collectie.<br/>            Alleen-lezen **int**. |
| [`count`](/slides/python-net/nl/aspose.slides.charts/datalabelcollection/count/) | Haalt het totale aantal gegevenslabels op in de collectie.<br/>            Alleen-lezen **int**. |
| [`default_data_label_format`](/slides/python-net/nl/aspose.slides.charts/datalabelcollection/default_data_label_format/) | Haalt de standaard gegevenslabelopmaak op.<br/>            Alleen-lezen [`IDataLabelFormat`](/slides/python-net/nl/aspose.slides.charts/idatalabelformat). |
| [`leader_lines_format`](/slides/python-net/nl/aspose.slides.charts/datalabelcollection/leader_lines_format/) | Stelt het formaat van de leader-lijnen van gegevenslabels voor.<br/>             Alleen-lezen [`IChartLinesFormat`](/slides/python-net/nl/aspose.slides.charts/ichartlinesformat). |
| [`parent_series`](/slides/python-net/nl/aspose.slides.charts/datalabelcollection/parent_series/) | Retourneert de bovenliggende reeks.<br/>            Alleen-lezen [`IChartSeries`](/slides/python-net/nl/aspose.slides.charts/ichartseries). |
| [`slide`](/slides/python-net/nl/aspose.slides.charts/datalabelcollection/slide/) |  |
| [`presentation`](/slides/python-net/nl/aspose.slides.charts/datalabelcollection/presentation/) |  |
