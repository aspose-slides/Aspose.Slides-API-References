## hide(self) {#}
Make data label hidden by default by setting all Show*-flags (ShowValue, ...) of the 
            DefaultDataLabelFormat eigenschap to false state.
            IsVisible will be false after this.


```python
def hide(self):
    ...
```


### Opmerkingen

If data label is not visible by default (IsVisible is false) you can make data label "standaard zichtbaar" 
            by setting Show*-flags (ShowValue, ...) of the DefaultDataLabelFormat eigenschap
            to true state.
