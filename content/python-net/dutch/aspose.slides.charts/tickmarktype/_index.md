## TickMarkType enumeratie

Geeft het type tikmarkering weer voor de opgegeven as.

Het type TickMarkType bevat de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| CROSS | Geeft aan dat de tikmarkeringen de as kruisen. |
| INSIDE | Geeft aan dat de tikmarkeringen zich binnen het plotgebied bevinden. |
| NONE | Geeft aan dat er geen tikmarkeringen zijn. |
| OUTSIDE | Geeft aan dat de tikmarkeringen zich buiten het plotgebied bevinden. |
