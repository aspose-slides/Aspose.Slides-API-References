## DataSourceType enumeratie

Gegevensbron types.

Het type DataSourceType heeft de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| WORKSHEET | Gebruik CellXls-objecten om XValue, YValue, Value of BubbleSize van een gegevenspunt op te slaan in een werkblad. |
| STRING_LITERALS | Gebruik een snel-toegankelijke stringvariabele om XValue, YValue, Value of BubbleSize van <br/>            gegevenspunt op te slaan. Werkblad wordt NIET gebruikt voor het opslaan van waarden. |
| DOUBLE_LITERALS | Gebruik een snel-toegankelijke double-variabele om XValue, YValue, Value of BubbleSize van <br/>            gegevenspunt op te slaan. Werkblad wordt NIET gebruikt voor het opslaan van waarden. |
