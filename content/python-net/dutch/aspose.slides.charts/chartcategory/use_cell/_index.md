## use_cell eigenschap
If true then AsCell eigenschap is actual. In other words, worksheet is used for 
            storing category (this case supports a multi-level category).
            If false then AsLiteral eigenschap is actual. In other words, worksheet is NOT used 
            for storing category (and this case doesn't support a multi-level categories).
            Alleen-lezen **bool**.


### Opmerkingen

For change value of this eigenschap (for all categories in collection) set new 
            value to ChartCategoryCollection.UseCells eigenschap.
