## IChartTextBlockFormat klasse

Stelt opmaak-eigenschappen voor tekstelementen van grafieken voor.

Het type IChartTextBlockFormat geeft de volgende leden weer:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`anchoring_type`](/slides/python-net/nl/aspose.slides.charts/icharttextblockformat/anchoring_type/) | Geeft de verticale ankertekst terug of stelt deze in een TextFrame.<br/>            Lezen/schrijven [`TextAnchorType`](/slides/python-net/nl/aspose.slides/textanchortype). |
| [`center_text`](/slides/python-net/nl/aspose.slides.charts/icharttextblockformat/center_text/) | Als NullableBool.True dan moet de tekst horizontaal gecentreerd worden in het vak.<br/>            Lezen/schrijven [`NullableBool`](/slides/python-net/nl/aspose.slides/nullablebool). |
| [`text_vertical_type`](/slides/python-net/nl/aspose.slides.charts/icharttextblockformat/text_vertical_type/) | Bepaalt de tekstoriëntatie.<br/>            De resulterende waarde van visuele tekstrichting, samengevat uit deze eigenschap en aangepaste hoek<br/>            in eigenschap RotationAngle.<br/>            Lezen/schrijven [`TextVerticalType`](/slides/python-net/nl/aspose.slides/textverticaltype). |
| [`margin_left`](/slides/python-net/nl/aspose.slides.charts/icharttextblockformat/margin_left/) | Geeft de linkermarge (punten) terug of stelt deze in een TextFrame.<br/>            Het wijzigen van deze eigenschap kan alleen invloed hebben op deze grafiekonderdelen: <br/>            DataLabel en DataLabelFormat (volledige ondersteuning in PowerPoint 2013; in PowerPoint 2007 heeft dit geen effect op weergave).<br/>            Lezen/schrijven **float**. |
| [`margin_right`](/slides/python-net/nl/aspose.slides.charts/icharttextblockformat/margin_right/) | Geeft de rechtermarge (punten) terug of stelt deze in een TextFrame.<br/>            Het wijzigen van deze eigenschap kan alleen invloed hebben op deze grafiekonderdelen: <br/>            DataLabel en DataLabelFormat (volledige ondersteuning in PowerPoint 2013; in PowerPoint 2007 heeft dit geen effect op weergave).<br/>            Lezen/schrijven **float**. |
| [`margin_top`](/slides/python-net/nl/aspose.slides.charts/icharttextblockformat/margin_top/) | Geeft de bovenmarge (punten) terug of stelt deze in een TextFrame.<br/>            Het wijzigen van deze eigenschap kan alleen invloed hebben op deze grafiekonderdelen: <br/>            DataLabel en DataLabelFormat (volledige ondersteuning in PowerPoint 2013; in PowerPoint 2007 heeft dit geen effect op weergave).<br/>            Lezen/schrijven **float**. |
| [`margin_bottom`](/slides/python-net/nl/aspose.slides.charts/icharttextblockformat/margin_bottom/) | Geeft de ondermarge (punten) terug of stelt deze in een TextFrame.<br/>            Het wijzigen van deze eigenschap kan alleen invloed hebben op deze grafiekonderdelen: <br/>            DataLabel en DataLabelFormat (volledige ondersteuning in PowerPoint 2013; in PowerPoint 2007 heeft dit geen effect op weergave).<br/>            Lezen/schrijven **float**. |
| [`wrap_text`](/slides/python-net/nl/aspose.slides.charts/icharttextblockformat/wrap_text/) | **True**  als tekst wordt afgebroken bij de marges van de TextFrame.<br/>            Het wijzigen van deze eigenschap kan alleen invloed hebben op deze grafiekonderdelen: <br/>            DataLabel en DataLabelFormat (volledige ondersteuning in PowerPoint 2007/2013).<br/>            Lezen/schrijven [`NullableBool`](/slides/python-net/nl/aspose.slides/nullablebool). |
| [`autofit_type`](/slides/python-net/nl/aspose.slides.charts/icharttextblockformat/autofit_type/) | Geeft de autofit-modus van de tekst terug of stelt deze in.<br/>            Het wijzigen van deze eigenschap kan alleen invloed hebben op deze grafiekonderdelen: <br/>            DataLabel en DataLabelFormat (volledige ondersteuning in PowerPoint 2013; in PowerPoint 2007 heeft dit geen effect op weergave).<br/>            Lezen/schrijven [`TextAutofitType`](/slides/python-net/nl/aspose.slides/textautofittype). |
| [`rotation_angle`](/slides/python-net/nl/aspose.slides.charts/icharttextblockformat/rotation_angle/) | Specificeert de aangepaste rotatie die wordt toegepast op de tekst binnen het omvattende vak. Als deze niet<br/>            is opgegeven, wordt de rotatie van de bijbehorende vorm gebruikt. Als deze wel is opgegeven, dan wordt dit<br/>            onafhankelijk van de vorm toegepast. Dat wil zeggen dat de vorm een rotatie kan hebben naast de rotatie<br/>            die op de tekst zelf wordt toegepast.<br/>            De resulterende waarde van visuele tekstrichting, samengevat uit deze eigenschap en vooraf gedefinieerde<br/>            verticale type in eigenschap TextVerticalType.<br/>            Lezen/schrijven **float**. |
