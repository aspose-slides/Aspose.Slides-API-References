## DisplayUnitType-enumeratie

Bepaalt de multipliciteit van de weergegeven gegevens.

Het DisplayUnitType-type geeft de volgende leden weer:

## Velden

| Veld | Beschrijving |
| :- | :- |
| NONE | Waarden worden weergegeven zoals ze zijn. |
| HUNDREDS | Specificeert dat de waarden op de grafiek gedeeld moeten worden door 100. |
| THOUSANDS | Specificeert dat de waarden op de grafiek gedeeld moeten worden door 1,000. |
| TEN_THOUSANDS | Specificeert dat de waarden op de grafiek gedeeld moeten worden door 10,000. |
| HUNDRED_THOUSANDS | Specificeert dat de waarden op de grafiek gedeeld moeten worden door 100,000. |
| MILLIONS | Specificeert dat de waarden op de grafiek gedeeld moeten worden door 1,000,000. |
| TEN_MILLIONS | Specificeert dat de waarden op de grafiek gedeeld moeten worden door 10,000,000. |
| HUNDRED_MILLIONS | Specificeert dat de waarden op de grafiek gedeeld moeten worden door 100,000,000. |
| BILLIONS | Specificeert dat de waarden op de grafiek gedeeld moeten worden door 1,000,000,000. |
| TRILLIONS | Specificeert dat de waarden op de grafiek gedeeld moeten worden door 1,000,000,000,000. |
| CUSTOM_VALUE | Specificeert dat de waarden op de grafiek gedeeld moeten worden door een aangepaste waarde. |
