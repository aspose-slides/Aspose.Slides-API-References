## hide(self) {#}
Maak het gegevenslabel standaard verborgen door alle Show*-vlaggen (ShowValue, ...) van de 
            DefaultDataLabelFormat-eigenschap op een valse toestand in te stellen.
            IsVisible zal na dit false zijn.

```python
def hide(self):
    ...
```

### Opmerkingen
Als het gegevenslabel standaard niet zichtbaar is (IsVisible is false) kun je het gegevenslabel "zichtbaar 
            standaard" maken door Show*-vlaggen (ShowValue, ...) van de DefaultDataLabelFormat-eigenschap
            op ware toestand.
