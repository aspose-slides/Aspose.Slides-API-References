## use_cells eigenschap
Als true dan wordt worksheet gebruikt voor het opslaan van categorieën (dit geval ondersteunt een meerlagige categorieën).
            Als false dan wordt worksheet NIET gebruikt voor het opslaan van waarden (en dit geval ondersteunt geen 
            meerlagige categorieën).
            Lezen/schrijven **bool**.
