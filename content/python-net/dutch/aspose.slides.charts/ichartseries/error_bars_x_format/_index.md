## error_bars_x_format eigenschap
Stelt ErrorBars van reeksen met richting X voor.
            
            ErrorBars met X-richting zijn beschikbaar voor reeksen van type area, bar, scatter en bubble.
            Voor alle andere soorten grafieken geeft deze eigenschap None terug (inclusief 3D-grafieken).
            In geval van aangepaste waarden gebruik de DataPoints-collectie om de waarde op te geven (met [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/nl/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) eigenschap).
            
            Alleen-lezen [`IErrorBarsFormat`](/slides/python-net/nl/aspose.slides.charts/ierrorbarsformat).
