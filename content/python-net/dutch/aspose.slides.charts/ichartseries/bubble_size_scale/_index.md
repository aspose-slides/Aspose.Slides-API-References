## bubble_size_scale eigenschap
Specifies the scale factor for the bubble chart (can be 
            between 0 and 300 percents of the default size).
            This is the eigenschap not only of this series but of all series of parent series 
            group - this is projection of appropriate group eigenschap. And so this eigenschap 
            is alleen-lezen.
            Use ParentSeriesGroup eigenschap for access to parent series group.
            Use ParentSeriesGroup.BubbleSizeScale lezen/schrijven eigenschap for change value.

### Opmerkingen

This is the projection of the eigenschap ParentSeriesGroup.BubbleSizeScale.
