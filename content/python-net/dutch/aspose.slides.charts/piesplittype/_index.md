## PieSplitType enumeratie

Stelt een type splitsingspunten voor in de tweede taart of balk op een taart-in-taart of balk-in-taart diagram.

Het type PieSplitType biedt de volgende leden:

## Velden

| Veld | Omschrijving |
| :- | :- |
| DEFAULT | Specificeert dat de gegevenspunten worden gesplitst met behulp van het standaard <br/> mechanisme voor dit diagramtype. |
| CUSTOM | Specificeert dat de gegevenspunten worden gesplitst tussen de <br/> taart en het tweede diagram volgens de aangepaste splitsingswaarden. |
| BY_PERCENTAGE | Specificeert dat de gegevenspunten worden gesplitst tussen de taart en de <br/> tweede diagram door de punten met een percentage lager dan <br/> Split Position procent in het tweede diagram te plaatsen. |
| BY_POS | Specificeert dat de gegevenspunten worden gesplitst tussen de taart en de <br/> tweede diagram door de laatste Split Position van de gegevenspunten <br/> in het tweede diagram te plaatsen. |
| BY_VALUE | Specificeert dat de gegevenspunten worden gesplitst tussen de taart en de <br/> tweede diagram door de gegevenspunten met een waarde lager dan <br/> Split Position in het tweede diagram te plaatsen. |
