## TimeUnitType enumeratie

Stelt de basiseenheid voor de categorische as

Het TimeUnitType type maakt de volgende leden beschikbaar:

## Velden

| Veld | Beschrijving |
| :- | :- |
| NONE | Waarden worden weergegeven zoals ze zijn. |
| DAYS | Geeft aan dat de diagramgegevens in dagen worden weergegeven. |
| MONTHS | Geeft aan dat de diagramgegevens in maanden worden weergegeven. |
| YEARS | Geeft aan dat de diagramgegevens in jaren worden weergegeven. |
