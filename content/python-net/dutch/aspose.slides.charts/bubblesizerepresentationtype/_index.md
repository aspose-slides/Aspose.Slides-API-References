## BubbleSizeRepresentationType enumeratie

Specificeert de mogelijke manieren om gegevens als bubbelfiguurgrootte weer te geven.

Het type BubbleSizeRepresentationType bevat de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| AREA | Specificeert dat de oppervlakte van de bubbels evenredig is aan de waarde van de bubbelgrootte. |
| WIDTH | Specificeert dat de straal van de bubbels evenredig is aan de waarde van de bubbelgrootte. |
