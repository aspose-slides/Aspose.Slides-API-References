## use_secondary_categories eigenschap
Als false dan [`IChartData.secondary_categories`](/slides/python-net/nl/aspose.slides.charts/ichartdata/secondary_categories) eigenschap return None en data 
            in [`IChartData.categories`](/slides/python-net/nl/aspose.slides.charts/ichartdata/categories) eigenschap wordt zowel voor primaire als secundaire series gebruikt.
            Als true dan data in [`IChartData.secondary_categories`](/slides/python-net/nl/aspose.slides.charts/ichartdata/secondary_categories) eigenschap wordt gebruikt voor secundaire series en data 
            in [`IChartData.categories`](/slides/python-net/nl/aspose.slides.charts/ichartdata/categories) eigenschap wordt gebruikt voor primaire series.
            Lezen/Schrijven **bool**.
