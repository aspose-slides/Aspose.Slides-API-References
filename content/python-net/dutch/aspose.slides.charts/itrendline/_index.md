## ITrendline klasse

Klasse representeert de trendlijn van een grafiekserie

Het ITrendline-type geeft de volgende leden weer:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`trendline_name`](/slides/python-net/nl/aspose.slides.charts/itrendline/trendline_name/) | Haalt of stelt de naam van de trendlijn in.<br/>            Read/write **str**. |
| [`trendline_type`](/slides/python-net/nl/aspose.slides.charts/itrendline/trendline_type/) | Haalt of stelt het type van de trendlijn in. <br/>            Read/write [`ITrendline.trendline_type`](/slides/python-net/nl/aspose.slides.charts/itrendline/trendline_type). |
| [`format`](/slides/python-net/nl/aspose.slides.charts/itrendline/format/) | Geeft het formaat van de trendlijn weer.<br/>            Read/write [`IFormat`](/slides/python-net/nl/aspose.slides.charts/iformat). |
| [`backward`](/slides/python-net/nl/aspose.slides.charts/itrendline/backward/) | Specificeert het aantal categorieën (of eenheden op een spreidingsdiagram) waartoe de trendlijn zich uitstrekt vóór<br/>            de gegevens voor de serie die wordt getrende. Op spreidings- en niet-spreidingsdiagrammen moet de waarde een niet-negatieve<br/>            waarde zijn.<br/>            Read/write **float**. |
| [`forward`](/slides/python-net/nl/aspose.slides.charts/itrendline/forward/) | Specificeert het aantal categorieën (of eenheden op een spreidingsdiagram) waartoe de trendlijn zich uitstrekt na<br/>            de gegevens voor de serie die wordt getrende. Op spreidings- en niet-spreidingsdiagrammen moet de waarde een niet-negatieve<br/>            waarde zijn.<br/>            Read/write **float**. |
| [`intercept`](/slides/python-net/nl/aspose.slides.charts/itrendline/intercept/) | Specificeert de waarde waarop de trendlijn de y-as kruist. Deze eigenschap wordt alleen ondersteund<br/>            wanneer het trendlijntype exp, linear of poly is.<br/>            Read/write **float**. |
| [`display_equation`](/slides/python-net/nl/aspose.slides.charts/itrendline/display_equation/) | Specificeert dat de vergelijking voor de trendlijn wordt weergegeven op het diagram (in hetzelfde label als de Rsquaredvalue).<br/>            Read/write **bool**. |
| [`order`](/slides/python-net/nl/aspose.slides.charts/itrendline/order/) | Specificeert de orde van de polynomiale trendlijn. Deze wordt genegeerd voor andere trendlijntypen. Waarde moet tussen 2 en 6 liggen.<br/>            Read/write **int**. |
| [`period`](/slides/python-net/nl/aspose.slides.charts/itrendline/period/) | Specificeert de periode van de trendlijn voor een voortschrijdend gemiddelde trendlijn. Deze wordt genegeerd voor andere trendlijnvarianten. Waarde moet tussen 2 en 255 liggen.<br/>            Read/write **int**. |
| [`display_r_squared_value`](/slides/python-net/nl/aspose.slides.charts/itrendline/display_r_squared_value/) | Specificeert dat de R-squared-waarde van de trendlijn wordt weergegeven op het diagram (in hetzelfde label als de vergelijking).<br/>            Read/write **bool**. |
| [`related_legend_entry`](/slides/python-net/nl/aspose.slides.charts/itrendline/related_legend_entry/) | Geeft de legenda-vermelding weer die verband houdt met deze trendlijn<br/>            Read-only [`ILegendEntryProperties`](/slides/python-net/nl/aspose.slides.charts/ilegendentryproperties). |
