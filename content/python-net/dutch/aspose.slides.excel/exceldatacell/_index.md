## ExcelDataCell klasse

Stelt een enkele cel in een Excel-werkmap voor.

Het ExcelDataCell-type geeft de volgende leden weer:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`value`](/slides/python-net/nl/aspose.slides.excel/exceldatacell/value/) | Haalt de waarde op die in de Excel-cel staat. |
| [`name`](/slides/python-net/nl/aspose.slides.excel/exceldatacell/name/) | Haalt de naam op van de grafiekgegevenscel. |
| [`row`](/slides/python-net/nl/aspose.slides.excel/exceldatacell/row/) | Haalt de nulgebaseerde index van de rij op in het werkblad waar de cel zich bevindt.<br/>            Alleen-lezen **int**. |
| [`column`](/slides/python-net/nl/aspose.slides.excel/exceldatacell/column/) | Haalt de nulgebaseerde index van de kolom op in het werkblad waar de cel zich bevindt.<br/>            Alleen-lezen **int**. |
