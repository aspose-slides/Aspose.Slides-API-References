## IExcelDataCell klasse

Stelt een enkele cel in een Excel-werkmap voor.

Het IExcelDataCell-type geeft de volgende leden weer:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`value`](/slides/python-net/nl/aspose.slides.excel/iexceldatacell/value/) | Haalt de waarde op die in de Excel-cel zit.<br/>            Alleen-lezen **any**. |
| [`name`](/slides/python-net/nl/aspose.slides.excel/iexceldatacell/name/) | Haalt de naam op van de grafiekdatacel.<br/>            Alleen-lezen **str**. |
| [`row`](/slides/python-net/nl/aspose.slides.excel/iexceldatacell/row/) | Haalt de nulgebaseerde index op van de rij in het werkblad waar de cel zich bevindt.<br/>            Alleen-lezen **int**. |
| [`column`](/slides/python-net/nl/aspose.slides.excel/iexceldatacell/column/) | Haalt de nulgebaseerde index op van de kolom in het werkblad waar de cel zich bevindt.<br/>            Alleen-lezen **int**. |
