## get_cells(self, formula, skip_hidden_cells) {#str-bool}
Haalt een verzameling cellen op uit de werkmap die overeenkomen met de opgegeven formule.

### Retourneert

Een alleen-lezen lijst van cellen die overeenkomen met de opgegeven formule.



```python
def get_cells(self, formula, skip_hidden_cells):
    ...
```


| Parameter | Type | Beschrijving |
| :- | :- | :- |
| formula | **str** | Een formule- of bereikexpressie (bijv. "Sheet1!A1:B3") die wordt gebruikt om doelcellen te identificeren. |
| skip_hidden_cells | **bool** | Als `true`, worden verborgen cellen (bijv. in verborgen rijen of kolommen) uitgesloten van het resultaat. |
