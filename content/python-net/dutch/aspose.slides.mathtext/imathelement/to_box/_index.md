## to_box(self) {#}
Plaatst dit element in een niet-visuele box (logische groepering) die wordt gebruikt om componenten van een vergelijking of een ander exemplaar van wiskundige tekst te groeperen.
Een ingesloten object kan (bijvoorbeeld) dienen als een operator-emulator met of zonder een uitlijningspunt, functioneren als een regeleinde-punt, of zo worden gegroepeerd dat regelbreuken binnenin niet worden toegestaan.

### Returns

Logische box met dit element erin geplaatst
