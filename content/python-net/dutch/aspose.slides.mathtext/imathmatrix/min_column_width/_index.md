## min_column_width eigenschap
Minimum kolombreedte in twips (1/20e van een punt)
            De tussenruimte (ook wel “Column Gap” of “Gap Width” genoemd) wordt opgeteld bij 
            de MinColumnWidth om de totale Matrix Column Spacing te bepalen
            (afstand tussen dezelfde randen van verschillende kolommen).
            Standaard: 0.
