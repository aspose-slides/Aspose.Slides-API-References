## IMathGroupingCharacter klasse

Bepaalt een groepsymbool boven of onder een expressie, meestal om de relatie tussen elementen te benadrukken.

Het type IMathGroupingCharacter bevat de volgende leden:

## Eigenschappen

| Property | Description |
| :- | :- |
| [`base`](/slides/python-net/nl/aspose.slides.mathtext/imathgroupingcharacter/base/) | Basisargument |
| [`character`](/slides/python-net/nl/aspose.slides.mathtext/imathgroupingcharacter/character/) | Groeperingskarakter<br/>            Standaardwaarde: U+23DF (BOTTOM CURLY BRACKET) |
| [`position`](/slides/python-net/nl/aspose.slides.mathtext/imathgroupingcharacter/position/) | Positie van het groeperingskarakter.<br/>            Standaard: Bottom |
| [`vertical_justification`](/slides/python-net/nl/aspose.slides.mathtext/imathgroupingcharacter/vertical_justification/) | Verticale uitlijning van groepskarakter.<br/>            Specificeert de uitlijning van het object ten opzichte van de basislijn.<br/>            Bij voorbeeld, wanneer het groepskarakter zich boven het object bevindt,<br/>            VerticalJustification van Top betekent dat de bovenkant van het object op de basislijn valt;<br/>            wanneer VerticalJustification is ingesteld op Bottom, bevindt de onderkant van het object zich op de basislijn<br/>            Standaard: Bottom voor Position=Top, en Top voor Position=Bottom |
