## to_box(self) {#}
Plaats dit element in een niet-visuele box (logische groepering) die wordt gebruikt om componenten van een vergelijking of een ander voorbeeld van wiskundige tekst te groeperen. Een ingekapseld object kan (bijvoorbeeld) dienen als een operator-emulator met of zonder een uitlijningspunt, dienen als een regeleinde-punt, of gegroepeerd worden zodat er geen regeleinden binnen worden toegestaan.

Logische box met dit element erin geplaatst
