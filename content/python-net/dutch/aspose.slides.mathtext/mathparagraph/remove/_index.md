## remove(self, math_block) {#imathblock}
Verwijdert de eerste verschijning van een specifiek object uit de verzameling/>

### Retourwaarde

true als `math_block` succesvol uit de verzameling is verwijderd; anders false. 
            Deze methode geeft ook false terug als `math_block` niet in de oorspronkelijke verzameling wordt gevonden/>.
