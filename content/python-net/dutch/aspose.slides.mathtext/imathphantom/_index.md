## IMathPhantom klasse

Vertegenwoordigt een phantom wiskundig object (<m:phant>) dat de lay-out van zijn kindelement beïnvloedt
            zonder het noodzakelijkerwijs weer te geven. Een phantom kan zijn basisexpressie verbergen terwijl het
            zijn breedte, hoogte of diepte behoudt om formules uit te lijnen of ruimte te reserveren. 
            Zichtbaarheid en geometrisch gedrag worden gecontroleerd door eigenschappen zoals Show, ZeroWid, ZeroAsc, 
            ZeroDesc en Transp.

Het IMathPhantom-type geeft de volgende leden weer:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`base`](/slides/python-net/nl/aspose.slides.mathtext/imathphantom/base/) | Base argument |
| [`show`](/slides/python-net/nl/aspose.slides.mathtext/imathphantom/show/) | Gets or sets a value indicating whether the base element is displayed. |
| [`zero_width`](/slides/python-net/nl/aspose.slides.mathtext/imathphantom/zero_width/) | Gets or sets a value indicating whether the width of the base element <br/>            should be treated as zero. |
| [`zero_asc`](/slides/python-net/nl/aspose.slides.mathtext/imathphantom/zero_asc/) | Gets or sets a value indicating whether the ascent (height above baseline) <br/>            of the base element should be treated as zero. |
| [`zero_desc`](/slides/python-net/nl/aspose.slides.mathtext/imathphantom/zero_desc/) | Gets or sets a value indicating whether the descent (depth below baseline)<br/>            of the base element should be treated as zero. |
| [`transp`](/slides/python-net/nl/aspose.slides.mathtext/imathphantom/transp/) | Gets or sets a value indicating whether the phantom is transparent <br/>            for class-based spacing rules. |
