## zero_width eigenschap
Gets or sets a value indicating whether the width of the base element 
            should be treated as zero.

### Opmerkingen

When `true`, the phantom does not reserve horizontal space 
            for its base. Corresponds to the OMML attribute `m:zeroWid`.
