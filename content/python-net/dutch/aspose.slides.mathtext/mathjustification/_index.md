## MathJustification enumeratie

Specificeert de uitlijning van de wiskundige alinea (een reeks aangrenzende instanties van wiskundige tekst binnen dezelfde alinea)

Het type MathJustification bevat de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| LEFT_JUSTIFIED | Lijn wiskundige tekst uit naar links |
| RIGHT_JUSTIFIED | Lijn wiskundige tekst uit naar rechts |
| CENTERED | Lijn wiskundige tekst uit naar het midden |
| CENTERED_AS_GROUP | Centreer op de pagina de volledige groep wiskundeblokken als één eenheid.<br/>            Dit betekent dat de instanties van wiskundige tekst ten opzichte van elkaar uitgelijnd kunnen worden, <br/>            maar dat de volledige groep wiskundige tekst als geheel gecentreerd is. |
