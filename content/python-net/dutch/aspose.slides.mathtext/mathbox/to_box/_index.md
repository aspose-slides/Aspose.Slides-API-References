## to_box(self) {#}
Plaatst dit element in een niet-visuele box (logische groepering) 
            die wordt gebruikt om componenten van een vergelijking of een andere instantie van wiskundige tekst te groeperen.
            Een ingesloten object kan (bijvoorbeeld) dienen als een operator-emulator met of zonder een uitlijningspunt, 
            dienen als een regelbreekpunt, of gegroepeerd worden zodat er geen regelbreuken binnen worden toegestaan.

### Retour

Logische box met dit element erin geplaatst
