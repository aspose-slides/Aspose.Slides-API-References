## MathRowSpacingRule enumeratie

Het type verticale spatiëring tussen kolommen in een matrix of array

Het MathRowSpacingRule-type geeft de volgende leden weer:

## Velden

| Veld | Beschrijving |
| :- | :- |
| SINGLE_LINE_GAP | enkele regelafstand |
| ONE_AND_A_HALF_LINE_GAP | anderhalve regelafstand |
| TWO_LINE_GAP | twee regelafstand |
| EXACTLY | Exact (gebaseerd op de waarde van de RowSpacing-eigenschap, gemeten in punten) |
| MULTIPLE | Meervoudig (gebaseerd op de waarde van de RowSpacing-eigenschap, gemeten in regels) |
