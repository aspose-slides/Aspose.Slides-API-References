## remove(self, item) {#imathelement}
Verwijdert de eerste voorkoming van een specifiek object uit de collectie.

### Retourwaarde
true als `item` succesvol is verwijderd uit de collectie; anders false. Deze methode geeft ook false terug als `item` niet wordt gevonden in de oorspronkelijke collectie.
