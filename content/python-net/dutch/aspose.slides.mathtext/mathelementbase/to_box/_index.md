## to_box(self) {#}
Plaatst dit element in een niet-visuele box (logische groepering) die wordt gebruikt om componenten van een vergelijking of een andere instantie van wiskundige tekst te groeperen. Een verpakte object kan (bijvoorbeeld) dienen als een operator-emulator met of zonder een uitlijningspunt, dienen als een regeleinde-punt, of zo worden gegroepeerd dat regelonderbrekingen binnen niet zijn toegestaan.

### Retour
Logische box met dit element erin geplaatst
