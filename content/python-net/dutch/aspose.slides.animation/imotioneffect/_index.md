## IMotionEffect klasse

Geeft het gedrag van een motion effect weer.

Het IMotionEffect-type exposeert de volgende leden:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`from_address`](/slides/python-net/nl/aspose.slides.animation/imotioneffect/from_address/) | Specificeert een x/y-coördinaat om de animatie vanaf te starten (in procenten).<br/>Lezen/schrijven **aspose.slides.PointF**. |
| [`to`](/slides/python-net/nl/aspose.slides.animation/imotioneffect/to/) | Specificeert de doel-locatie voor een animatie-motion effect (in procenten).<br/>Lezen/schrijven **aspose.slides.PointF**. |
| [`by`](/slides/python-net/nl/aspose.slides.animation/imotioneffect/by/) | Beschrijft de relatieve offsetwaarde voor de animatie (in procenten).<br/>Lezen/schrijven **aspose.slides.PointF**. |
| [`rotation_center`](/slides/python-net/nl/aspose.slides.animation/imotioneffect/rotation_center/) | Beschrijft het middelpunt van de rotatie die wordt gebruikt om een motion-pad te roteren met X-hoek.<br/>Lezen/schrijven **aspose.slides.PointF**. |
| [`origin`](/slides/python-net/nl/aspose.slides.animation/imotioneffect/origin/) | Specificeert wat de oorsprong van het motion-pad is ten opzichte van bijvoorbeeld de lay-out van de dia,<br/>of de bovenliggende.<br/>Lezen/schrijven [`MotionOriginType`](/slides/python-net/nl/aspose.slides.animation/motionorigintype). |
| [`path`](/slides/python-net/nl/aspose.slides.animation/imotioneffect/path/) | Specificeert het pad-primitief gevolgd door coördinaten voor de animatie-motion.<br/>Lezen/schrijven [`IMotionPath`](/slides/python-net/nl/aspose.slides.animation/imotionpath). |
| [`path_edit_mode`](/slides/python-net/nl/aspose.slides.animation/imotioneffect/path_edit_mode/) | Specificeert hoe het motion-pad beweegt wanneer de vorm wordt verplaatst.<br/>Lezen/schrijven [`MotionPathEditMode`](/slides/python-net/nl/aspose.slides.animation/motionpatheditmode). |
| [`angle`](/slides/python-net/nl/aspose.slides.animation/imotioneffect/angle/) | Beschrijft de relatieve hoek van het motion-pad.<br/>Lezen/schrijven **float**. |
