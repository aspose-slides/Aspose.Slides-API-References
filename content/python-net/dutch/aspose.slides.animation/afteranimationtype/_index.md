## AfterAnimationType enumeratie

Stelt het type na animatie van een animatie-effect voor.

Het AfterAnimationType type bevat de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| DO_NOT_DIM | Niet dimmen na animatietype. |
| COLOR | Kleur na animatietype. |
| HIDE_AFTER_ANIMATION | Verberg na animatie type |
| HIDE_ON_NEXT_MOUSE_CLICK | Verberg bij de volgende muisklik na animatietype. |
