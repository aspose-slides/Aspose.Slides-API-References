## BuildType enumeratie

Bepaalt hoe tekst wordt weergegeven op een shape tijdens animatie.

Het BuildType type exposeert de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| AS_ONE_OBJECT | Met de omvattende shape. |
| ALL_PARAGRAPHS_AT_ONCE | Alle alinea. |
| BY_LEVEL_PARAGRAPHS1 | Per groepen alinea's van diepte 1. |
| BY_LEVEL_PARAGRAPHS2 | Per groepen alinea's van diepte 2. |
| BY_LEVEL_PARAGRAPHS3 | Per groepen alinea's van diepte 3. |
| BY_LEVEL_PARAGRAPHS4 | Per groepen alinea's van diepte 4. |
| BY_LEVEL_PARAGRAPHS5 | Per groepen alinea's van diepte 5. |
