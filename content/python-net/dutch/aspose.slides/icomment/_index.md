## IComment klasse

Stelt een reactie op een dia voor.

Het type IComment geeft de volgende leden weer:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`text`](/slides/python-net/nl/aspose.slides/icomment/text/) | Geeft de platte tekst van een diareactie terug of stelt deze in.<br/>            Lezen/Schrijven **str**. |
| [`created_time`](/slides/python-net/nl/aspose.slides/icomment/created_time/) | Geeft de tijd van het aanmaken van een reactie terug of stelt deze in.<br/>            Het instellen van deze eigenschap op **System.DateTime** betekent dat er geen reactietijd is ingesteld.<br/>            Lezen/Schrijven **System.DateTime**. |
| [`slide`](/slides/python-net/nl/aspose.slides/icomment/slide/) | Geeft de bovenliggende dia van een reactie terug of stelt deze in.<br/>            Alleen-lezen [`ISlide`](/slides/python-net/nl/aspose.slides/islide). |
| [`author`](/slides/python-net/nl/aspose.slides/icomment/author/) | Geeft de auteur van een reactie terug.<br/>            Alleen-lezen [`ICommentAuthor`](/slides/python-net/nl/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/nl/aspose.slides/icomment/position/) | Geeft de positie van een reactie op een dia terug of stelt deze in.<br/>            Lezen/Schrijven **aspose.slides.PointF**. |
| [`parent_comment`](/slides/python-net/nl/aspose.slides/icomment/parent_comment/) | Geeft de bovenliggende reactie terug of stelt deze in.<br/>            Lezen/Schrijven [`IComment`](/slides/python-net/nl/aspose.slides/icomment). |
