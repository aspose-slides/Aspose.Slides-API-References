## IBackdrop3DScene klasse

Definieert een vlak waarin effecten, zoals gloed en schaduw, worden toegepast in relatie tot de vorm waarop ze worden toegepast.

Het type IBackdrop3DScene exposeert de volgende leden:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`normal_vector`](/slides/python-net/nl/aspose.slides/ibackdrop3dscene/normal_vector/) | Geeft een normale vector terug of stelt deze in. Om preciezer te zijn, definieert dit attribuut een vector<br/>            normaal ten opzichte van de voorkant van het backdrop-vlak. Vector wordt weergegeven door een array van 3 float-waarden<br/>            die X-, Y- en Z-coördinaten definiëren.<br/>            Lezen/schrijven **float**[]. |
| [`anchor_point`](/slides/python-net/nl/aspose.slides/ibackdrop3dscene/anchor_point/) | Geeft een punt in 3D-ruimte terug of stelt dit in. Dit punt is het punt in de ruimte dat het backdrop-vlak verankert.<br/>            3D-punt wordt weergegeven door een array van 3 float-waarden die X-, Y- en Z-coördinaten definiëren.<br/>            Lezen/schrijven **float**[]. |
| [`up_vector`](/slides/python-net/nl/aspose.slides/ibackdrop3dscene/up_vector/) | Geeft een vector die omhoog wijst terug of stelt deze in. Vector wordt weergegeven door een array<br/>            van 3 float-waarden die X-, Y- en Z-coördinaten definiëren.<br/>            Lezen/schrijven **float**[]. |
