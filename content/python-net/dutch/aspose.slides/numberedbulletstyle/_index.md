## NumberedBulletStyle enumeratie

Stelt de stijl van de genummerde opsommingstekens voor.

Het NumberedBulletStyle-type geeft de volgende leden weer:

## Velden

| Veld | Beschrijving |
| :- | :- |
| NOT_DEFINED | Niet gedefinieerd. |
| BULLET_ALPHA_LC_PERIOD | Kleine letters alfabetische tekens met een punt. Voorbeeld: a., b., c., ... |
| BULLET_ALPHA_UC_PERIOD | Hoofletters alfabetische tekens met een punt. Voorbeeld: A., B., C., ... |
| BULLET_ARABIC_PAREN_RIGHT | Arabische cijfers met sluitende haak. Voorbeeld: 1), 2), 3), ... |
| BULLET_ARABIC_PERIOD | Arabische cijfers met een punt. Voorbeeld: 1., 2., 3., ... |
| BULLET_ROMAN_LC_PAREN_BOTH | Kleine Romeinse cijfers met beide haakjes. Voorbeeld: (i), (ii), (iii), ... |
| BULLET_ROMAN_LC_PAREN_RIGHT | Kleine Romeinse cijfers met sluitende haak. Voorbeeld: i), ii), iii), ... |
| BULLET_ROMAN_LC_PERIOD | Kleine Romeinse cijfers met punt. Voorbeeld: i., ii., iii., ... |
| BULLET_ROMAN_UC_PERIOD | Hoofletters Romeinse cijfers met punt. Voorbeeld: I., II., III., ... |
| BULLET_ALPHA_LC_PAREN_BOTH | Kleine letters alfabetische tekens met beide haakjes. Voorbeeld: (a), (b), (c), ... |
| BULLET_ALPHA_LC_PAREN_RIGHT | Kleine letters alfabetische tekens met sluitende haak. Voorbeeld: a), b), c), ... |
| BULLET_ALPHA_UC_PAREN_BOTH | Hoofletters alfabetische tekens met beide haakjes. Voorbeeld: (A), (B), (C), ... |
| BULLET_ALPHA_UC_PAREN_RIGHT | Hoofletters alfabetische tekens met sluitende haak. Voorbeeld: A), B), C), ... |
| BULLET_ARABIC_PAREN_BOTH | Arabische cijfers met beide haakjes. Voorbeeld: (1), (2), (3), ... |
| BULLET_ARABIC_PLAIN | Arabische cijfers. Voorbeeld: 1, 2, 3, ... |
| BULLET_ROMAN_UC_PAREN_BOTH | Hoofletters Romeinse cijfers met beide haakjes. Voorbeeld: (I), (II), (III), ... |
| BULLET_ROMAN_UC_PAREN_RIGHT | Hoofletters Romeinse cijfers met sluitende haak. Voorbeeld: I), II), III), ... |
| BULLET_SIMP_CHIN_PLAIN | Vereenvoudigd Chinees zonder punt. |
| BULLET_SIMP_CHIN_PERIOD | Vereenvoudigd Chinees met punt. |
| BULLET_CIRCLE_NUM_DB_PLAIN | Dubbelbyte ingesloten getal voor waarden tot 10, vanaf 11 – Arabische cijfers. |
| BULLET_CIRCLE_NUM_WD_WHITE_PLAIN | Tekstkleurig getal met dezelfde kleur cirkel eromheen (Wingdings witte cirkelnummers). Van  11 - Arabische cijfers. |
| BULLET_CIRCLE_NUM_WD_BLACK_PLAIN | Schaduwkleurig getal met cirkelvormige achtergrond van normale tekstkleur (Wingdings zwarte cirkelnummers). |
| BULLET_TRAD_CHIN_PLAIN | Traditioneel Chinees zonder punt. |
| BULLET_TRAD_CHIN_PERIOD | Traditioneel Chinees met punt. |
| BULLET_ARABIC_ALPHA_DASH | Arabische alfabetische tekens met een streepje. |
| BULLET_ARABIC_ABJAD_DASH | Arabische Abjad-alfabetten met een streepje. |
| BULLET_HEBREW_ALPHA_DASH | Hebreeuwse alfabetische tekens met een streepje. |
| BULLET_KANJI_KOREAN_PLAIN | Japanse/Koreaanse cijfers zonder punt. |
| BULLET_KANJI_KOREAN_PERIOD | Japanse/Koreaanse cijfers met punt. |
| BULLET_ARABIC_DB_PLAIN | Dubbelbyte Arabisch nummeringssysteem (geen interpunctie). |
| BULLET_ARABIC_DB_PERIOD | Dubbelbyte Arabisch nummeringssysteem met dubbelbyte punt. |
| BULLET_THAI_ALPHA_PERIOD | Thais alfabet met punt. |
| BULLET_THAI_ALPHA_PAREN_RIGHT | Thais alfabet haakjes - rechts. |
| BULLET_THAI_ALPHA_PAREN_BOTH | Thais alfabet haakjes - beide. |
| BULLET_THAI_NUM_PERIOD | Thai cijferperiode. |
| BULLET_THAI_NUM_PAREN_RIGHT | Thai cijfer haakjes - rechts. |
| BULLET_THAI_NUM_PAREN_BOTH | Thai cijfer haakjes - beide. |
| BULLET_HINDI_ALPHA_PERIOD | Hindi alfabet periode - klinkers. |
| BULLET_HINDI_NUM_PERIOD | Hindi cijferperiode. |
| BULLET_KANJI_SIMP_CHIN_DB_PERIOD | Kanji Simpeler Chinees DB-periode. |
| BULLET_HINDI_NUM_PAREN_RIGHT | Hindi cijfer haakjes - rechts. |
| BULLET_HINDI_ALPHA_1_PERIOD | Hindi alfabet periode - medeklinkers. |
