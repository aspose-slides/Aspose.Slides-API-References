## get_script_font(self, script) {#str}
Haalt de naam van het lettertype op dat gekoppeld is aan een specifiek script-tag uit het presentatiethema.

### Retourneert

De naam van het lettertype dat wordt gebruikt voor het opgegeven script, of `None` als het script niet is gedefinieerd.



```python
def get_script_font(self, script):
    ...
```


| Parameter | Type | Beschrijving |
| :- | :- | :- |
| script | **str** | De BCP-47 scriptcode (bijv. "Latn", "Cyrl", "Jpan") die wordt gebruikt om een schrijfsysteem te identificeren. |
