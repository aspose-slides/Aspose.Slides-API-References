## IFonts klasse

Vertegenwoordigt een collectie lettertypen.

Het IFonts-type geeft de volgende leden weer:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`latin_font`](/slides/python-net/nl/aspose.slides/ifonts/latin_font/) | Geeft of stelt het Latijnse lettertype in.<br/>            Lezen/schrijven [`IFontData`](/slides/python-net/nl/aspose.slides/ifontdata). |
| [`east_asian_font`](/slides/python-net/nl/aspose.slides/ifonts/east_asian_font/) | Geeft of stelt het Oost-Aziatische lettertype in.<br/>            Lezen/schrijven [`IFontData`](/slides/python-net/nl/aspose.slides/ifontdata). |
| [`complex_script_font`](/slides/python-net/nl/aspose.slides/ifonts/complex_script_font/) | Geeft of stelt het complexe scriptlettertype in.<br/>            Lezen/schrijven [`IFontData`](/slides/python-net/nl/aspose.slides/ifontdata). |

## Methoden

| Methode | Beschrijving |
| :- | :- |
| [`get_script_font_map(self)`](/slides/python-net/nl/aspose.slides/ifonts/get_script_font_map/#) | Geeft een lijst terug van alle string-string paren met scriptlettertype-definities in de presentatie. |
