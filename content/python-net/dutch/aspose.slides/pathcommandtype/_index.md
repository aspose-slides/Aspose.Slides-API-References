## PathCommandType enumeratie

Representeert grafische padopdrachten

Het type PathCommandType bevat de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| CLOSE | Sluit geometrisch pad |
| MOVE_TO | Stelt de positie van het volgende punt van het geometrische pad in |
| LINE_TO | Voegt een lijn toe aan het geometrische pad |
| ARC_TO | Voegt de opgegeven boog toe aan het geometrische pad. |
| QUAD_BEZIER_TO | Voegt een kwadratische Bezier-curve toe aan het geometrische pad |
| CUBIC_BEZIER_TO | Voegt een kubieke Bezier-curve toe aan het geometrische pad |
