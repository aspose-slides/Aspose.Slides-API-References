## ColorType enumeratie

Representeert verschillende kleurmodi.

Het type ColorType bevat de volgende leden:

## Velden

| Field | Beschrijving |
| :- | :- |
| NOT_DEFINED | Kleur is helemaal niet gedefinieerd. |
| RGB | Standaard 24-bit RGB-kleur. |
| RGB_PERCENTAGE | RGB-kleur met hoge definitie. |
| HSL | HSL-kleur met hoge definitie. |
| SCHEME | Schema-kleur. |
| SYSTEM | Systeemkleur. |
| PRESET | Vooraf ingestelde kleur. |
