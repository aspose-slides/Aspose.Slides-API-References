## IImage klasse

Stelt een raster- of vectorafbeelding voor.

Het IImage-type biedt de volgende leden weer:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`size`](/slides/python-net/nl/aspose.slides/iimage/size/) | Haalt de grootte van de afbeelding op. |
| [`width`](/slides/python-net/nl/aspose.slides/iimage/width/) | Haalt de breedte van de afbeelding in pixels op. |
| [`height`](/slides/python-net/nl/aspose.slides/iimage/height/) | Haalt de hoogte van de afbeelding in pixels op. |

## Methoden

| Methode | Beschrijving |
| :- | :- |
| [`save(self, filename)`](/slides/python-net/nl/aspose.slides/iimage/save/#str) | Slaat de afbeelding op in een bestand. |
| [`save(self, filename, format)`](/slides/python-net/nl/aspose.slides/iimage/save/#str-imageformat) | Slaat de afbeelding op in een bestand in het opgegeven formaat. |
| [`save(self, stream, format)`](/slides/python-net/nl/aspose.slides/iimage/save/#iorawiobase-imageformat) | Slaat de afbeelding op in een stroom in het opgegeven formaat. |
| [`save(self, filename, format, quality)`](/slides/python-net/nl/aspose.slides/iimage/save/#str-imageformat-int) | Slaat de afbeelding op in een bestand in het opgegeven formaat en kwaliteit. |
| [`save(self, stream, format, quality)`](/slides/python-net/nl/aspose.slides/iimage/save/#iorawiobase-imageformat-int) | Slaat de afbeelding op in een stroom in het opgegeven formaat en kwaliteit. |


### Opmerkingen

Deze interface biedt een algemene abstractie voor het verwerken van zowel raster- als vectorafbeeldingen.  
Implementaties kunnen variëren afhankelijk van het onderliggende afbeeldingstype.
