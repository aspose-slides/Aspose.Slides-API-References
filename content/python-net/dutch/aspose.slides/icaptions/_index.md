## ICaptions klasse

Vertegenwoordigt de WebVTT gesloten bijschriften.

Het ICaptions-type stelt de volgende leden beschikbaar:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`caption_id`](/slides/python-net/nl/aspose.slides/icaptions/caption_id/) | Retourneert de wereldwijd unieke identifier (GUID) van de gesloten bijschriften.<br/>            Alleen-lezen **System.Guid**. |
| [`label`](/slides/python-net/nl/aspose.slides/icaptions/label/) | Retourneert of stelt het label van de gesloten bijschriften in.<br/>            Lezen/Schrijven **str**. |
| [`binary_data`](/slides/python-net/nl/aspose.slides/icaptions/binary_data/) | Retourneert de binaire gegevens van de gesloten bijschriften.<br/>            Alleen-lezen **int**[]. |
| [`data_as_string`](/slides/python-net/nl/aspose.slides/icaptions/data_as_string/) | Retourneert de gegevens van de gesloten bijschriften als UTF-8 gecodeerde string<br/>            Alleen-lezen **str**. |
