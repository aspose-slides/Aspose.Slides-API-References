## ShapesAlignmentType enumeratie

Definieert een manier om de plaatsing van geselecteerde vormen op de dia te wijzigen.

Het type ShapesAlignmentType geeft de volgende leden weer:

## Velden

| Veld | Beschrijving |
| :- | :- |
| ALIGN_LEFT | Uitlijnen links |
| ALIGN_RIGHT | Uitlijnen rechts |
| ALIGN_CENTER | Uitlijnen gecentreerd |
| ALIGN_TOP | Uitlijnen boven |
| ALIGN_MIDDLE | Uitlijnen midden |
| ALIGN_BOTTOM | Uitlijnen onder |
| DISTRIBUTE_HORIZONTALLY | Horizontaal verdelen |
| DISTRIBUTE_VERTICALLY | Verticaal verdelen |
