## SensitivityLabelContentType enumeratie

Stelt de soorten contentmarkering voor die op een document moeten worden toegepast.

Het type SensitivityLabelContentType geeft de volgende leden weer:

## Velden

| Veld | Beschrijving |
| :- | :- |
| NONE | Betekent dat het label standaard of automatisch wordt toegepast. |
| HEADER | Betekent dat het label handmatig is toegepast.<br/>            Gebruik voor elk gevoeligheidslabel dat direct door de gebruiker is toegepast. |
| FOOTER | Betekent dat het label handmatig is toegepast.<br/>            Gebruik voor elk gevoeligheidslabel dat direct door de gebruiker is toegepast. |
| WATERMARK | Betekent dat het label handmatig is toegepast.<br/>            Gebruik voor elk gevoeligheidslabel dat direct door de gebruiker is toegepast. |
| ENCRYPTION | Betekent dat het label handmatig is toegepast.<br/>            Gebruik voor elk gevoeligheidslabel dat direct door de gebruiker is toegepast. |
