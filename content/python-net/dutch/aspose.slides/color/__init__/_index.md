## __init__(self, r=0, g=0, b=0, a=255) {#int-int-int-int}
Maakt een kleur aan op basis van de opgegeven rood-, groen-, blauw- en alfacomponentwaarden.


```python
def __init__(self, r=0, g=0, b=0, a=255):
    ...
```


| Parameter | Type | Beschrijving |
| :- | :- | :- |
| r | **int** | De roodcomponentwaarde. Geldige waarden zijn 0 tot en met 255. |
| g | **int** | De groencomponentwaarde. Geldige waarden zijn 0 tot en met 255. |
| b | **int** | De blauwcomponentwaarde. Geldige waarden zijn 0 tot en met 255. |
| a | **int** | De alfacomponentwaarde. Geldige waarden zijn 0 tot en met 255. |

### Uitzonderingen

| Uitzondering | Beschrijving |
| :- | :- |
| **ValueError** | Een componentwaarde is kleiner dan 0 of groter dan 255. |
| **TypeError** | Een componentwaarde is geen getal. |
