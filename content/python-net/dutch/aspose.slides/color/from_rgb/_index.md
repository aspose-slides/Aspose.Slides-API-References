## from_rgb(r, g, b) {#int-int-int}
Maakt een ondoorzichtige kleur (alpha is 255) van de opgegeven rode, groene en blauwe waarden.

### Retour

De kleur die is gemaakt van de opgegeven waarden.



```python
@staticmethod
def from_rgb(r, g, b):
    ...
```


| Parameter | Type | Beschrijving |
| :- | :- | :- |
| r | **int** | De rode componentwaarde. Geldige waarden zijn 0 tot en met 255. |
| g | **int** | De groene componentwaarde. Geldige waarden zijn 0 tot en met 255. |
| b | **int** | De blauwe componentwaarde. Geldige waarden zijn 0 tot en met 255. |

### Uitzonderingen

| Uitzondering | Beschrijving |
| :- | :- |
| **ValueError** | Een componentwaarde is kleiner dan 0 of groter dan 255. |
