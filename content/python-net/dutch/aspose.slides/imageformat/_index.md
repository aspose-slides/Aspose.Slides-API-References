## ImageFormat enumeratie

Stelt het bestandsformaat van de afbeelding voor.

Het ImageFormat-type geeft de volgende leden weer:

## Velden

| Veld | Beschrijving |
| :- | :- |
| MEMORY_BMP | Stelt het formaat van een bitmap in het geheugen voor. |
| BMP | Stelt het bitmap (BMP)-afbeeldingsformaat voor. |
| EMF | Stelt het verbeterde metafile (EMF)-afbeeldingsformaat voor. |
| WMF | Stelt het Windows-metafile (WMF)-afbeeldingsformaat voor. |
| GIF | Stelt het Graphics Interchange Format (GIF)-afbeeldingsformaat voor. |
| JPEG | Stelt het Joint Photographic Experts Group (JPEG)-afbeeldingsformaat voor. |
| PNG | Stelt het W3C Portable Network Graphics (PNG)-afbeeldingsformaat voor. |
| TIFF | Stelt het Tagged Image File Format (TIFF)-afbeeldingsformaat voor. |
| EXIF | Stelt het Exchangeable Image File (Exif)-formaat voor. |
| ICON | Stelt het Windows-pictogram-afbeeldingsformaat voor. |
