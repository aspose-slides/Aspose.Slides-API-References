## remove(self, item) {#iportion}
Verwijdert de eerste keer dat een specifiek object voorkomt uit de **System.Collections.Generic.ICollection`1**.

### Retourneert

true als `item` met succes is verwijderd uit de **System.Collections.Generic.ICollection`1**; anders false. Deze methode geeft ook false terug als `item` niet wordt gevonden in de oorspronkelijke **System.Collections.Generic.ICollection`1**.



```python
def remove(self, item):
    ...
```


| Parameter | Type | Beschrijving |
| :- | :- | :- |
| item | [`IPortion`](/slides/python-net/nl/aspose.slides/iportion) | Het object dat moet worden verwijderd uit de **System.Collections.Generic.ICollection`1**. |

### Uitzonderingen

| Uitzondering | Beschrijving |
| :- | :- |
| **RuntimeError(Proxy error(NotSupportedException))** | De **System.Collections.Generic.ICollection`1** is alleen-lezen. |
