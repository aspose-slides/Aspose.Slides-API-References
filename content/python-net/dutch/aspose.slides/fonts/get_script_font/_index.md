## get_script_font(self, script) {#str}
Haalt de lettertype-naam op die is gekoppeld aan een specifiek script-tag uit het presentatiethema.

### Retour
De naam van het lettertype dat wordt gebruikt voor het opgegeven script, of `None` als het script niet is gedefinieerd.



```python
def get_script_font(self, script):
    ...
```


| Parameter | Type | Beschrijving |
| :- | :- | :- |
| script | **str** | De BCP-47 scriptcode (bijv. "Latn", "Cyrl", "Jpan") die wordt gebruikt om een schrift te identificeren. |
