## set_date_time_and_child_date_times_visibility(self, is_visible) {#bool}
Wijzigt de zichtbaarheid van de datum-tijd-placeholder op de lay-out slide en van alle onderliggende datum-tijd-placeholders.
Child placeholders betekenen dat placeholders zich bevinden op afhankelijke slides.
Afhankelijke slides gebruiken en zijn afhankelijk van de lay-out slide.

```python
def set_date_time_and_child_date_times_visibility(self, is_visible):
    ...
```

| Parameter | Type | Beschrijving |
| :- | :- | :- |
| is_visible | **bool** | true - maakt een datum-tijd-placeholder zichtbaar, anders - verbergt ze. |
