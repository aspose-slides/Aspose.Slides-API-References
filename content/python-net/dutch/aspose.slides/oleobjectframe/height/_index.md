## height eigenschap
Gets or sets the height of the shape, measured in points.
            Lezen/Schrijven **float**.


### Opmerkingen

The value returned is always defined and never **float**.
            The value assigned must also be defined; assign **float** only to eigenschappen of a `RawFrame` instantie.
