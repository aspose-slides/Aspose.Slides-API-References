## rotatie eigenschap
Returns or sets the number of degrees the specified shape is rotated around
            the z-axis. A positive value indicates clockwise rotation; a negative value
            indicates counterclockwise rotation.
            Lezen/schrijven **float**.


### Opmerkingen

De geretourneerde waarde is altijd gedefinieerd (is geen float.NaN).
            Toegewezen waarde moet gedefinieerd zijn (geen float.NaN). U kunt ongedefinieerde waarden instellen voor RawFrame instance-eigenschappen.
