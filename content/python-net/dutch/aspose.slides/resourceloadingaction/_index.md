## ResourceLoadingAction enumeratie

Specificeert de modus van het laden van externe bronnen.

Het type ResourceLoadingAction biedt de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| DEFAULT | Aspose.Slides zal externe bronnen op de gebruikelijke manier laden. |
| SKIP | Aspose.Slides zal het laden van externe bronnen overslaan. Alleen een link zonder gegevens wordt opgeslagen voor een afbeelding. |
| USER_PROVIDED | Aspose.Slides zal de door de gebruiker geleverde byte-array gebruiken in **Aspose.Slides.IResourceLoadingArgs.SetData(Syste** als afbeeldingsgegevens. |
