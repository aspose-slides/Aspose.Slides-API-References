## AdjustValue klasse

Stelt de aanpassingswaarde van een geometrische vorm voor.
            Deze waarden beïnvloeden de vorm van de shape.

Het AdjustValue type biedt de volgende leden weer:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`raw_value`](/slides/python-net/nl/aspose.slides/adjustvalue/raw_value/) | Retourneert of stelt de aanpassingswaarde "as is" in.<br/>            Read/write **int**. |
| [`angle_value`](/slides/python-net/nl/aspose.slides/adjustvalue/angle_value/) | Retourneert of stelt de waarde in, geïnterpreteerd als een hoek in graden.<br/>            Read/write **float**. |
| [`name`](/slides/python-net/nl/aspose.slides/adjustvalue/name/) | Retourneert een naam van deze aanpassingswaarde.<br/>            Read-only **str**. |
| [`type`](/slides/python-net/nl/aspose.slides/adjustvalue/type/) | Retourneert het type van de vormaanpassing.<br/>            Read-only [`ShapeAdjustmentType`](/slides/python-net/nl/aspose.slides/shapeadjustmenttype). |
