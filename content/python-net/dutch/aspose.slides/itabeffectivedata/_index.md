## ITabEffectiveData class

Onveranderlijk object dat de tabulatiestop-eigenschappen van effectieve tekst bevat.

Het type ITabEffectiveData bevat de volgende leden:

## Eigenschappen

| Property | Beschrijving |
| :- | :- |
| [`position`](/slides/python-net/nl/aspose.slides/itabeffectivedata/position/) | Geeft de positie van een tab terug.<br/>            Het toewijzen van deze eigenschap kan de index van de tab in de collectie wijzigen en de enumerator ongeldig maken.<br/>            Alleen-lezen **float**. |
| [`alignment`](/slides/python-net/nl/aspose.slides/itabeffectivedata/alignment/) | Geeft de uitlijningsstijl van een tab terug.<br/>            Alleen-lezen [`TabAlignment`](/slides/python-net/nl/aspose.slides/tabalignment). |


### Opmerkingen

Deze interface wordt gebruikt als onderdeel van [`IParagraphFormatEffectiveData`](/slides/python-net/nl/aspose.slides/iparagraphformateffectivedata).
