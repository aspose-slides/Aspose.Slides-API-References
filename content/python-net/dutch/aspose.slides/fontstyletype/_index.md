## FontStyleType enumeratie

Definieert opmaakstijlen die op tekst kunnen worden toegepast.

Het FontStyleType-type bevat de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| REGULAR | Standaardtekst. |
| BOLD | Vette tekst. |
| ITALIC | Cursieve tekst. |
| UNDERLINE | Onderstreepte tekst. |
| STRIKEOUT | Tekst doorgestreept met een horizontale lijn. |
