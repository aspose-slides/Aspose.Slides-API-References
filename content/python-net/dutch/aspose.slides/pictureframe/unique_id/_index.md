## unique_id eigenschap
Retourneert een interne, presentatie-gebonden identifier die bedoeld is voor gebruik door invoegtoepassingen of andere code.
            Omdat deze waarde door de gebruiker of programmatisch kan worden toegewezen, mag deze niet worden beschouwd als een permanente unieke sleutel.
            Alleen-lezen **int**.
