## PlaceholderType enumeratie

Stelt het type van een plaatsaanduiding voor.

Het PlaceholderType-type maakt de volgende leden beschikbaar:

## Velden

| Veld | Omschrijving |
| :- | :- |
| TITLE | Titel. |
| BODY | Inhoud. |
| CENTERED_TITLE | Gecentreerde Titel. |
| SUBTITLE | Subtitel. |
| DATE_AND_TIME | Datum en Tijd. |
| SLIDE_NUMBER | Dia Nummer. |
| FOOTER | Voettekst. |
| HEADER | Koptekst. |
| OBJECT | Object. |
| CHART | Grafiek. |
| TABLE | Tabel. |
| CLIP_ART | ClipArt. |
| DIAGRAM | Diagram. |
| MEDIA | Media. |
| SLIDE_IMAGE | Dia-afbeelding. |
| PICTURE | Afbeelding. |
