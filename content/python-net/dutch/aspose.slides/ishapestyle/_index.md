## IShapeStyle klasse

Vertegenwoordigt de stijlreferentie van een vorm.

Het IShapeStyle-type biedt de volgende leden weer:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`line_color`](/slides/python-net/nl/aspose.slides/ishapestyle/line_color/) | Geeft de omtrekkleur van een vorm terug.<br/>            Alleen-lezen [`IColorFormat`](/slides/python-net/nl/aspose.slides/icolorformat). |
| [`line_style_index`](/slides/python-net/nl/aspose.slides/ishapestyle/line_style_index/) | Geeft de kolomindex van een lijn in een stijlmatrix terug of stelt deze in.<br/>            Lezen/schrijven **int**. |
| [`fill_color`](/slides/python-net/nl/aspose.slides/ishapestyle/fill_color/) | Geeft de opvulkleur van een vorm terug.<br/>            Alleen-lezen [`IColorFormat`](/slides/python-net/nl/aspose.slides/icolorformat). |

| [`font_color`](/slides/python-net/nl/aspose.slides/ishapestyle/font_color/) | Geeft de lettertypekleur van een vorm terug.<br/>            Alleen-lezen [`IColorFormat`](/slides/python-net/nl/aspose.slides/icolorformat). |
