## encrypt_document_properties eigenschap
This property makes sense, if presentation is password protected.
            Als true dan worden documenteigenschappen versleuteld in het presentatiebestand.
            Als false dan zijn documenteigenschappen openbaar terwijl de presentatie versleuteld is.
            Lezen/Schrijven **bool**.
