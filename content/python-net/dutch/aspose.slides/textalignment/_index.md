## TextAlignment enumeratie

Stelt verschillende tekstuitlijningsstijlen voor.

Het TextAlignment type exposeert de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| NOT_DEFINED | Standaard uitlijning. |
| LEFT | Linker uitlijning. |
| CENTER | Centrale uitlijning. |
| RIGHT | Rechter uitlijning. |
| JUSTIFY | Uitvullen uitlijning. |
| JUSTIFY_LOW | Kashida lage uitvulling. |
| DISTRIBUTED | Gedistribueerde uitlijning. |
