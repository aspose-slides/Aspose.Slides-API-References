## split_text_by_columns(self) {#}
Splits de tekstinhoud van de [`ITextFrame`](/slides/python-net/nl/aspose.slides/itextframe) in een array van strings,  
            waarbij elk element overeenkomt met een aparte tekstkolom binnen het frame.

### Retourwaarde

Een array van strings, waarbij elke string de tekstinhoud van een specifieke kolom in de [`ITextFrame`](/slides/python-net/nl/aspose.slides/itextframe) weergeeft.



```python
def split_text_by_columns(self):
    ...
```


### Opmerkingen

Als het tekstframe geen meerdere kolommen bevat, zal de geretourneerde array één element hebben dat de volledige tekst bevat.  
            Lege kolommen worden in de array weergegeven als lege strings.
