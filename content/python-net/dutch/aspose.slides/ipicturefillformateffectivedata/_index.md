## IPictureFillFormatEffectiveData klasse

Onveranderlijk object dat de eigenschappen van een afbeeldingvulling bevat.

Het type IPictureFillFormatEffectiveData biedt de volgende leden weer:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`dpi`](/slides/python-net/nl/aspose.slides/ipicturefillformateffectivedata/dpi/) | Retourneert de dpi die wordt gebruikt om een afbeelding te vullen.<br/>            Alleen-lezen **int**. |
| [`picture_fill_mode`](/slides/python-net/nl/aspose.slides/ipicturefillformateffectivedata/picture_fill_mode/) | Retourneert de vullingsmodus van de afbeelding.<br/>            Alleen-lezen [`PictureFillMode`](/slides/python-net/nl/aspose.slides/picturefillmode). |
| [`picture`](/slides/python-net/nl/aspose.slides/ipicturefillformateffectivedata/picture/) | Retourneert de afbeelding.<br/>            Alleen-lezen [`IPictureEffectiveData`](/slides/python-net/nl/aspose.slides/ipictureeffectivedata). |
| [`crop_left`](/slides/python-net/nl/aspose.slides/ipicturefillformateffectivedata/crop_left/) | Retourneert het aantal procenten van de werkelijke afbeeldingsbreedte dat wordt weggesneden<br/>            aan de linkerkant van de afbeelding. <br/>            Alleen-lezen **float**. |

| [`crop_right`](/slides/python-net/nl/aspose.slides/ipicturefillformateffectivedata/crop_right/) | Retourneert het aantal procenten van de werkelijke afbeeldingsbreedte dat wordt weggesneden<br/>            aan de rechterkant van de afbeelding. <br/>            Alleen-lezen **float**. |
