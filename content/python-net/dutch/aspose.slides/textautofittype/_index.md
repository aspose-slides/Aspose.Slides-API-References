## TextAutofitType enumeratie

Stelt de tekst-autofit-modus voor.

Het TextAutofitType-type heeft de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| NOT_DEFINED | Niet gedefinieerd. |
| NONE | Geen autofit. |
| NORMAL | Normale autofit. Lettergrootte en regelafstand worden verkleind om in de vorm te passen. |
| SHAPE | Vorm-autofit. Vormgrootte wordt aangepast om de tekst te laten passen. |
