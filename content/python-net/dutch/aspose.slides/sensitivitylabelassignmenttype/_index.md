## SensitivityLabelAssignmentType enumeratie

Geeft de toewijzingsmethode voor het gevoeligheidslabel weer.

Het type SensitivityLabelAssignmentType bevat de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| STANDARD | Gebruik voor elk gevoeligheidslabel dat niet direct door de gebruiker is toegepast. <br/>            Dit omvat alle standaardlabels, automatisch toegepaste labels. |
| PRIVILEGED | Gebruik voor elk gevoeligheidslabel dat direct door de gebruiker is toegepast. <br/>            Dit omvat alle handmatig toegepaste gevoeligheidslabels, evenals aanbevolen<br/>            of verplichte labeling, of elke functie waarbij de gebruiker beslist welk gevoeligheidslabel moet worden toegepast. |
