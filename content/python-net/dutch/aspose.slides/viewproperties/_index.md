## ViewProperties klasse

Presentatiebrede weergave-eigenschappen.

Het type ViewProperties stelt de volgende leden beschikbaar:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`last_view`](/slides/python-net/nl/aspose.slides/viewproperties/last_view/) | Specificeert de weergavemodus die werd gebruikt toen het presentatiedocument voor het laatst werd opgeslagen.<br/>            Lezen/schrijven [`ViewType`](/slides/python-net/nl/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/nl/aspose.slides/viewproperties/show_comments/) | Specificeert of de dia-opmerkingen moeten worden getoond.<br/>            Lezen/schrijven [`NullableBool`](/slides/python-net/nl/aspose.slides/nullablebool). |
| [`normal_view_properties`](/slides/python-net/nl/aspose.slides/viewproperties/normal_view_properties/) | Vertegenwoordigt normale weergave-eigenschappen. De normale weergave bestaat uit<br/>            drie inhoudsgebieden: de dia zelf, een zij-inhoudsgebied en een onder-inhoudsgebied.<br/>            Alleen-lezen [`INormalViewProperties`](/slides/python-net/nl/aspose.slides/inormalviewproperties). |
| [`slide_view_properties`](/slides/python-net/nl/aspose.slides/viewproperties/slide_view_properties/) | Specificeert algemene weergave-eigenschappen die geassocieerd zijn met de dia-weergavemodus.<br/>            Alleen-lezen [`ICommonSlideViewProperties`](/slides/python-net/nl/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/nl/aspose.slides/viewproperties/notes_view_properties/) | Specificeert algemene weergave-eigenschappen die geassocieerd zijn met de notitie-weergavemodus.<br/>            Alleen-lezen [`ICommonSlideViewProperties`](/slides/python-net/nl/aspose.slides/icommonslideviewproperties). |
| [`grid_spacing`](/slides/python-net/nl/aspose.slides/viewproperties/grid_spacing/) | Geeft de rasterafstand terug of stelt deze in die gebruikt moet worden voor het raster onderliggend aan het presentatiedocument, in punten. <br/>            Lezen/schrijven **float**. |
