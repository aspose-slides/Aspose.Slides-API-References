## AudioPlayModePreset enumeratie

Constanten die bepalen hoe een geluid wordt afgespeeld.

Het type AudioPlayModePreset bevat de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| MIXED |  |
| AUTO | Automatisch afspelen. |
| ON_CLICK | Alleen afspelen wanneer op het pictogram wordt geklikt. |
