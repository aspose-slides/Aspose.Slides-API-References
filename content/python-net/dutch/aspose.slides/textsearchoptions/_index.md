## TextSearchOptions klasse

Vertegenwoordigt opties die kunnen worden gebruikt om te zoeken naar tekst in een Presentation, Slide of TextFrame.

Het TextSearchOptions-type biedt de volgende leden:

## Constructors

| Constructor | Beschrijving |
| :- | :- |
| [`__init__(self)`](/slides/python-net/nl/aspose.slides/textsearchoptions/__init__/#) | Maakt nieuwe standaardtekstzoekopties aan. |

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`case_sensitive`](/slides/python-net/nl/aspose.slides/textsearchoptions/case_sensitive/) | Stel true in om hoofdlettergevoelige zoekopdracht te gebruiken, false - anders.<br/>            Lezen/Schrijven **bool**. |
| [`whole_words_only`](/slides/python-net/nl/aspose.slides/textsearchoptions/whole_words_only/) | Stel true in om alleen hele woorden te matchen, false - anders.<br/>            Lezen/Schrijven **bool**. |
| [`include_notes`](/slides/python-net/nl/aspose.slides/textsearchoptions/include_notes/) | Stel `true` in om tekst die in slide-notities staat op te nemen ([`NotesSlide`](/slides/python-net/nl/aspose.slides/notesslide)) <br/>            bij het uitvoeren van tekstzoek-, vervangings- of markeerbewerkingen.<br/>            De standaardwaarde is `false`. |
