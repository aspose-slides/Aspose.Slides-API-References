## IParagraphFormatEffectiveData klasse

Onveranderlijk object dat effectieve alinea-opmaak eigenschappen bevat.

### Opmerkingen

Deze interface wordt samen met de [`IParagraphFormat`](/slides/python-net/nl/aspose.slides/iparagraphformat) interface gebruikt om effectieve opmaakwaarden met toegepaste overerving te retourneren.
