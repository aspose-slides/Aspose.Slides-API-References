## SlideShowSettings klasse

Geeft de slide-showinstellingen voor de presentatie weer.

Het type SlideShowSettings bevat de volgende leden:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`slide_show_type`](/slides/python-net/nl/aspose.slides/slideshowsettings/slide_show_type/) | Haalt het slide-showtype op of stelt het in. Wordt vertegenwoordigd door de volgende [`SlideShowSettings.slide_show_type`](/slides/python-net/nl/aspose.slides/slideshowsettings/slide_show_type) voorouders: [`BrowsedAtKiosk`](/slides/python-net/nl/aspose.slides/browsedatkiosk), [`PresentedBySpeaker`](/slides/python-net/nl/aspose.slides/presentedbyspeaker) en [`BrowsedByIndividual`](/slides/python-net/nl/aspose.slides/browsedbyindividual) |
| [`loop`](/slides/python-net/nl/aspose.slides/slideshowsettings/loop/) | Loop diavoorstelling |
| [`show_narration`](/slides/python-net/nl/aspose.slides/slideshowsettings/show_narration/) | Toon vertelling in diavoorstelling |
| [`show_animation`](/slides/python-net/nl/aspose.slides/slideshowsettings/show_animation/) | Toon animatie in diavoorstelling |
| [`pen_color`](/slides/python-net/nl/aspose.slides/slideshowsettings/pen_color/) | Penkleur voor diavoorstelling |
| [`slides`](/slides/python-net/nl/aspose.slides/slideshowsettings/slides/) | Bereik van dia's |
| [`use_timings`](/nl/slides/python-net/aspose.slides/slideshowsettings/use_timings/) | Gebruik timing in diavoorstelling |
| [`show_media_controls`](/slides/python-net/nl/aspose.slides/slideshowsettings/show_media_controls/) | Toon mediabediening |
