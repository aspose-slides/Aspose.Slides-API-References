## Comment klasse

Stelt een Comment voor op een dia.

Het Comment-type exposeert de volgende leden:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`text`](/slides/python-net/nl/aspose.slides/comment/text/) | Geeft de platte tekst van een dia-commentaar terug of stelt deze in.<br/>            Lezen/schrijven **str**. |
| [`created_time`](/slides/python-net/nl/aspose.slides/comment/created_time/) | Geeft de tijd van een commentaarcreatie terug of stelt deze in.<br/>            Als deze eigenschap wordt ingesteld op **System.DateTime**, betekent dit dat er geen commentaartijd is ingesteld.<br/>            Lezen/schrijven **System.DateTime**. |
| [`slide`](/slides/python-net/nl/aspose.slides/comment/slide/) | Geeft de bovenliggende dia van een commentaar terug of stelt deze in.<br/>            Alleen-lezen [`ISlide`](/slides/python-net/nl/aspose.slides/islide). |
| [`author`](/slides/python-net/nl/aspose.slides/comment/author/) | Geeft de auteur van een commentaar terug.<br/>            Alleen-lezen [`ICommentAuthor`](/slides/python-net/nl/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/nl/aspose.slides/comment/position/) | Geeft de positie van een commentaar op een dia terug of stelt deze in.<br/>            Lezen/schrijven **aspose.slides.PointF**. |
| [`parent_comment`](/slides/python-net/nl/aspose.slides/comment/parent_comment/) | Haalt de bovenliggende commentaar op of stelt deze in.<br/>            Lezen/schrijven [`IComment`](/slides/python-net/nl/aspose.slides/icomment). |

## Methoden

| :- | :- |
