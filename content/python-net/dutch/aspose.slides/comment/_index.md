## Comment klasse

Stelt een opmerking op een dia voor.

Het Comment type bevat de volgende leden:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`text`](/slides/python-net/nl/aspose.slides/comment/text/) | Geeft de platte tekst van een dia-opmerking terug of stelt deze in.<br/>Lezen/Schrijven **str**. |
| [`created_time`](/slides/python-net/nl/aspose.slides/comment/created_time/) | Geeft de tijd van het aanmaken van een opmerking terug of stelt deze in.<br/>Het instellen van deze eigenschap op **System.DateTime** betekent dat er geen opmerkingstijd is ingesteld.<br/>Lezen/Schrijven **System.DateTime**. |
| [`slide`](/slides/python-net/nl/aspose.slides/comment/slide/) | Geeft de bovenliggende dia van een opmerking terug of stelt deze in.<br/>Alleen-lezen [`ISlide`](/slides/python-net/nl/aspose.slides/islide). |
| [`author`](/slides/python-net/nl/aspose.slides/comment/author/) | Geeft de auteur van een opmerking terug.<br/>Alleen-lezen [`ICommentAuthor`](/slides/python-net/nl/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/nl/aspose.slides/comment/position/) | Geeft de positie van een opmerking op een dia terug of stelt deze in.<br/>Lezen/Schrijven [`PointF`](/slides/python-net/nl/aspose.slides/pointf). |
| [`parent_comment`](/slides/python-net/nl/aspose.slides/comment/parent_comment/) | Geeft de bovenliggende opmerking terug of stelt deze in.<br/>Lezen/Schrijven [`IComment`](/slides/python-net/nl/aspose.slides/icomment). |

## Methoden

| Methode | Beschrijving |
| :- | :- |
| [`remove(self)`](/slides/python-net/nl/aspose.slides/comment/remove/#) | Verwijdert de opmerking en al haar antwoorden uit de bovenliggende collectie. |
