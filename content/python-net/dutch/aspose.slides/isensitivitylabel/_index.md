## ISensitivityLabel klasse

Stelt het gevoeligheidslabel van Microsoft Purview Information Protection voor.

Het type ISensitivityLabel exposeert de volgende leden:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`id`](/slides/python-net/nl/aspose.slides/isensitivitylabel/id/) | Geeft de id van het gevoeligheidslabel terug of stelt deze in.<br/>            Lezen/schrijven **str**. |
| [`site_id`](/slides/python-net/nl/aspose.slides/isensitivitylabel/site_id/) | Geeft de Azure Active Directory (Azure AD) site-identifier terug of stelt deze in <br/>            die overeenkomt met het gevoeligheidslabel-beleid dat het gevoeligheidslabel beschrijft.<br/>            Lezen/schrijven **System.Guid**. |
| [`is_enabled`](/slides/python-net/nl/aspose.slides/isensitivitylabel/is_enabled/) | Geeft aan of het gevoeligheidslabel is ingeschakeld. |
| [`is_removed`](/slides/python-net/nl/aspose.slides/isensitivitylabel/is_removed/) | Geeft aan of het gevoeligheidslabel is verwijderd. |
| [`assignment_method_type`](/slides/python-net/nl/aspose.slides/isensitivitylabel/assignment_method_type/) | Geeft de toewijzingsmethode voor het gevoeligheidslabel terug of stelt deze in.<br/>            Lezen/schrijven [`SensitivityLabelAssignmentType`](/slides/python-net/nl/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/nl/aspose.slides/isensitivitylabel/content_mark_types/) | Geeft de lijst met typen content-markering die op een bestand toegepast moeten worden terug. |
