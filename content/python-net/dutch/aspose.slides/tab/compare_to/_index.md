## compare_to(self, obj) {#any}
Vergelijkt de huidige instantie met een ander object van hetzelfde type.

### Retour
Een 32-bit geheel getal dat de relatieve volgorde van de te vergelijken elementen aangeeft.
De retourwaarde heeft de volgende betekenissen:

* < 0 - Deze instantie is kleiner dan obj. = 0 - Deze instantie is gelijk aan obj. > 0 - Deze instantie is groter dan obj.
