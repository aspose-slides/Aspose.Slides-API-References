## Size klasse

Slaat een geordend paar gehele getallen op, die een breedte en een hoogte specificeren. Compatibel met .NET `System.Drawing.Size`.

Het type Size geeft de volgende leden weer:

## Constructoren

| Constructor | Beschrijving |
| :- | :- |
| [`__init__(self, width=0, height=0)`](/slides/python-net/nl/aspose.slides/size/__init__/#int-int) | Maakt een grootte met de opgegeven breedte en hoogte. Float-waarden worden afgekapt tot gehele getallen. |

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`width`](/slides/python-net/nl/aspose.slides/size/width/) | Haalt het horizontale component van deze grootte op.<br/>            Alleen-lezen **int**. |
| [`height`](/slides/python-net/nl/aspose.slides/size/height/) | Haalt het verticale component van deze grootte op.<br/>            Alleen-lezen **int**. |


### Opmerkingen

Grootten worden met hun componenten vergeleken met `==` en kunnen worden gebruikt als woordenboek-sleutels of set-leden.
