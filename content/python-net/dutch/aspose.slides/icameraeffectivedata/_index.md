## ICameraEffectiveData klasse

Onveranderlijk object dat effectieve cameravelden bevat.

Het ICameraEffectiveData-type maakt de volgende leden beschikbaar:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`camera_type`](/slides/python-net/nl/aspose.slides/icameraeffectivedata/camera_type/) | Cameratype.<br/>            Alleen-lezen [`CameraPresetType`](/slides/python-net/nl/aspose.slides/camerapresettype). |
| [`field_of_view_angle`](/slides/python-net/nl/aspose.slides/icameraeffectivedata/field_of_view_angle/) | Camera FOV (0-180 deg, gezichtsveld).<br/>            Alleen-lezen **float**. |
| [`zoom`](/slides/python-net/nl/aspose.slides/icameraeffectivedata/zoom/) | Camerazoom (positieve waarde in procent).<br/>            Alleen-lezen **float**. |

## Methoden

| Methode | Beschrijving |

| [`get_rotation(self)`](/slides/python-net/nl/aspose.slides/icameraeffectivedata/get_rotation/#) | Een rotatie wordt gedefinieerd door het gebruik van een breedtegraad<br/>            coördinaat, een lengtegraad coördinaat en een rotatie rond de as <br/>            als de breedtegraad- en lengtegraadcoördinaten.<br/>            eerste element in teruggegeven array - breedtegraad, tweede - lengtegraad, derde - rotatie.<br/>            Retourneert None als er geen rotatie is gedefinieerd. |
