## get_rotation(self) {#}
Een rotatie wordt gedefinieerd door het gebruik van een breedtegraadcoördinaat, een lengtegraadcoördinaat en een revolutie rond de as, zoals bij de breedtegraad- en lengtegraadcoördinaten. Eerste element in het teruggegeven array - breedtegraad, tweede - lengtegraad, derde - revolutie. Retourneert None als er geen rotatie is gedefinieerd.

### Retour
Array van rotatiewaarden als **float**[].
