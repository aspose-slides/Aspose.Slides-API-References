## ModernComment klasse

Representeert een commentaar op een dia.

**Erfenis:**[`ModernComment`](/slides/python-net/nl/aspose.slides/moderncomment) → [`Comment`](/slides/python-net/nl/aspose.slides/comment)

Het type ModernComment biedt de volgende leden:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`text`](/slides/python-net/nl/aspose.slides/moderncomment/text/) | Geeft de platte tekst van een dia-commentaar terug of stelt deze in.<br/>            Lezen/Schrijven **str**. |
| [`created_time`](/slides/python-net/nl/aspose.slides/moderncomment/created_time/) | Geeft de tijd van het aanmaken van een commentaar terug of stelt deze in.<br/>            Het instellen van deze eigenschap op **System.DateTime** betekent dat er geen commentaartijd is ingesteld.<br/>            Lezen/Schrijven **System.DateTime**. |
| [`slide`](/slides/python-net/nl/aspose.slides/moderncomment/slide/) | Geeft de bovenliggende dia van een commentaar terug of stelt deze in.<br/>            Alleen-lezen [`ISlide`](/slides/python-net/nl/aspose.slides/islide). |
| [`author`](/slides/python-net/nl/aspose.slides/moderncomment/author/) | Geeft de auteur van een commentaar terug.<br/>            Alleen-lezen [`ICommentAuthor`](/slides/python-net/nl/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/nl/aspose.slides/moderncomment/position/) | Geeft de positie van een commentaar op een dia terug of stelt deze in.<br/>            Lezen/Schrijven **aspose.slides.PointF**. |
| [`parent_comment`](/slides/python-net/nl/aspose.slides/moderncomment/parent_comment/) | Geeft de bovenliggende commentaar terug of stelt deze in.<br/>            Lezen/Schrijven [`IComment`](/slides/python-net/nl/aspose.slides/icomment). |
| [`shape`](/slides/python-net/nl/aspose.slides/moderncomment/shape/) | Geeft een vorm die aan het commentaar is gekoppeld terug.<br/>            Alleen-lezen [`IShape`](/slides/python-net/nl/aspose.slides/ishape). |
| [`text_selection_start`](/slides/python-net/nl/aspose.slides/moderncomment/text_selection_start/) | Geeft de startpositie van tekstselectie in het tekstframe terug of stelt deze in als het commentaar is gekoppeld aan een AutoShape.<br/>            Lezen/Schrijven **int**. |
| [`text_selection_length`](/slides/python-net/nl/aspose.slides/moderncomment/text_selection_length/) | Geeft de lengte van de tekstselectie in het tekstframe terug of stelt deze in als het commentaar is gekoppeld aan een AutoShape.<br/>            Lezen/Schrijven **int**. |
| [`status`](/slides/python-net/nl/aspose.slides/moderncomment/status/) | Geeft de status van het commentaar terug of stelt deze in.<br/>            Lezen/Schrijven [`ModernCommentStatus`](/slides/python-net/nl/aspose.slides/moderncommentstatus). |
