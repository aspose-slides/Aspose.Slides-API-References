## ModernComment klasse

Stelt een opmerking op een dia voor.

**Erfenis:**[`ModernComment`](/slides/python-net/nl/aspose.slides/moderncomment) → [`Comment`](/slides/python-net/nl/aspose.slides/comment)

Het ModernComment-type maakt de volgende leden beschikbaar:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`text`](/slides/python-net/nl/aspose.slides/moderncomment/text/) | Geeft de platte tekst van een dia-opmerking terug of stelt deze in.<br/>            Lezen/Schrijven **str**. |
| [`created_time`](/slides/python-net/nl/aspose.slides/moderncomment/created_time/) | Geeft de tijd van het maken van een opmerking terug of stelt deze in.<br/>            Als deze eigenschap wordt ingesteld op **System.DateTime**, betekent dit dat er geen opmerkingstijd is ingesteld.<br/>            Lezen/Schrijven **System.DateTime**. |
| [`slide`](/slides/python-net/nl/aspose.slides/moderncomment/slide/) | Geeft de bovenliggende dia van een opmerking terug of stelt deze in.<br/>            Alleen-lezen [`ISlide`](/slides/python-net/nl/aspose.slides/islide). |
| [`author`](/slides/python-net/nl/aspose.slides/moderncomment/author/) | Geeft de auteur van een opmerking terug.<br/>            Alleen-lezen [`ICommentAuthor`](/slides/python-net/nl/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/nl/aspose.slides/moderncomment/position/) | Geeft de positie van een opmerking op een dia terug of stelt deze in.<br/>            Lezen/Schrijven [`PointF`](/slides/python-net/nl/aspose.slides/pointf). |
| [`parent_comment`](/slides/python-net/nl/aspose.slides/moderncomment/parent_comment/) | Geeft de bovenliggende opmerking terug of stelt deze in.<br/>            Lezen/Schrijven [`IComment`](/slides/python-net/nl/aspose.slides/icomment). |
| [`shape`](/slides/python-net/nl/aspose.slides/moderncomment/shape/) | Geeft een vorm terug die aan de opmerking is gekoppeld.<br/>            Alleen-lezen [`IShape`](/slides/python-net/nl/aspose.slides/ishape). |
| [`text_selection_start`](/slides/python-net/nl/aspose.slides/moderncomment/text_selection_start/) | Geeft de startpositie van de tekstselectie in het tekstvak terug of stelt deze in als de opmerking is gekoppeld aan een AutoShape.<br/>            Lezen/Schrijven **int**. |
| [`text_selection_length`](/slides/python-net/nl/aspose.slides/moderncomment/text_selection_length/) | Geeft de lengte van de tekstselectie in het tekstvak terug of stelt deze in als de opmerking is gekoppeld aan een AutoShape.<br/>            Lezen/Schrijven **int**. |
| [`status`](/slides/python-net/nl/aspose.slides/moderncomment/status/) | Geeft de status van de opmerking terug of stelt deze in.<br/>            Lezen/Schrijven [`ModernCommentStatus`](/slides/python-net/nl/aspose.slides/moderncommentstatus). |
