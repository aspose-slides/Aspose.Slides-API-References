## FontsLoader klasse

Klasse voor het laden van aangepaste lettertypen gedefinieerd door de gebruiker.  
Moet worden gebruikt voordat er presentatie-objecten worden gemaakt.

Het FontsLoader-type exposeert de volgende leden:

| Methode | Beschrijving |
| :- | :- |
| [`load_external_fonts(directories)`](/slides/python-net/nl/aspose.slides/fontsloader/load_external_fonts/#liststr) | Voegt extra mappen toe om lettertypen te zoeken. |
| [`load_external_font(data)`](/slides/python-net/nl/aspose.slides/fontsloader/load_external_font/#bytes) | Voegt een lettertype toe vanuit de binaire gegevens |
| [`get_font_folders()`](/slides/python-net/nl/aspose.slides/fontsloader/get_font_folders/#) | Haalt lettertype-mappen op. Retourneert mappen die zijn toegevoegd met de LoadExternalFonts-methode, evenals systeembrede lettertype-mappen |
| [`clear_cache()`](/slides/python-net/nl/aspose.slides/fontsloader/clear_cache/#) | Verwijdert alle aangepaste lettertypen die door de gebruiker zijn gedefinieerd |
