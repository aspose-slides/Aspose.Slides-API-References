## IPictureEffectiveData klasse

Onveranderlijk object dat effectieve afbeeldingseigenschappen bevat.

Het type IPPictureEffectiveData exposeert de volgende leden:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`image`](/slides/python-net/nl/aspose.slides/ipictureeffectivedata/image/) | Retourneert de ingebedde afbeelding.<br/>            Alleen-lezen [`IPPImage`](/slides/python-net/nl/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/nl/aspose.slides/ipictureeffectivedata/link_path_long/) | Retourneert de URL van de gekoppelde afbeelding.<br/>            Alleen-lezen **str**. |
| [`image_transform`](/slides/python-net/nl/aspose.slides/ipictureeffectivedata/image_transform/) | Retourneert de collectie van beeldtransformatie-effecten.<br/>            Alleen-lezen [`IImageTransformOCollectionEffectiveData`](/slides/python-net/nl/aspose.slides.effects/iimagetransformocollectioneffectivedata). |


### Opmerkingen

Deze interface wordt gebruikt als onderdeel van [`IPictureFillFormatEffectiveData`](/slides/python-net/nl/aspose.slides/ipicturefillformateffectivedata) en [`IBulletFormatEffectiveData`](/slides/python-net/nl/aspose.slides/ibulletformateffectivedata).
