## IShapeFrame klasse

Stelt de eigenschappen van een vormframe voor.

Het IShapeFrame-type biedt de volgende leden weer:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`x`](/slides/python-net/nl/aspose.slides/ishapeframe/x/) | Geeft de X-coördinaat van de linkerbovenhoek van een frame terug.<br/>            Alleen-lezen **float**. |
| [`y`](/slides/python-net/nl/aspose.slides/ishapeframe/y/) | Geeft de Y-coördinaat van de linkerbovenhoek van een frame terug.<br/>            Alleen-lezen **float**. |
| [`width`](/slides/python-net/nl/aspose.slides/ishapeframe/width/) | Geeft de breedte van een frame terug.<br/>            Alleen-lezen **float**. |
| [`height`](/slides/python-net/nl/aspose.slides/ishapeframe/height/) | Geeft de hoogte van een frame terug.<br/>            Alleen-lezen **float**. |
| [`rotation`](/slides/python-net/nl/aspose.slides/ishapeframe/rotation/) | Geeft het aantal graden waarmee een frame rond de z-as is geroteerd.<br/>            Een positieve waarde duidt rotatie met de klok mee aan; een negatieve waarde<br/>            duidt rotatie tegen de klok in aan.<br/>            Alleen-lezen **float**. |
| [`center_x`](/slides/python-net/nl/aspose.slides/ishapeframe/center_x/) | Geeft de X-coördinaat van het midden van een frame terug.<br/>            Alleen-lezen **float**. |
| [`center_y`](/slides/python-net/nl/aspose.slides/ishapeframe/center_y/) | Geeft de Y-coördinaat van het midden van een frame terug.<br/>            Alleen-lezen **float**. |
| [`flip_h`](/slides/python-net/nl/aspose.slides/ishapeframe/flip_h/) | Bepaalt of een frame horizontaal is gespiegeld.<br/>            Alleen-lezen [`NullableBool`](/slides/python-net/nl/aspose.slides/nullablebool). |
| [`flip_v`](/slides/python-net/nl/aspose.slides/ishapeframe/flip_v/) | Bepaalt of een frame verticaal is gespiegeld.<br/>            Alleen-lezen [`NullableBool`](/slides/python-net/nl/aspose.slides/nullablebool). |
| [`rectangle`](/slides/python-net/nl/aspose.slides/ishapeframe/rectangle/) | Geeft de coördinaten van een frame terug.<br/>            Alleen-lezen **aspose.slides.RectangleF**. |
