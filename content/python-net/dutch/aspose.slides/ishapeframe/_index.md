## IShapeFrame klasse

Representeert de eigenschappen van een shape frame.

Het IShapeFrame-type geeft de volgende leden weer:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`x`](/slides/python-net/nl/aspose.slides/ishapeframe/x/) | Geeft de X-coördinaat van de linkerbovenhoek van een frame.<br/>            Alleen-lezen **float**. |
| [`y`](/slides/python-net/nl/aspose.slides/ishapeframe/y/) | Geeft de Y-coördinaat van de linkerbovenhoek van een frame.<br/>            Alleen-lezen **float**. |
| [`width`](/slides/python-net/nl/aspose.slides/ishapeframe/width/) | Geeft de breedte van een frame.<br/>            Alleen-lezen **float**. |
| [`height`](/slides/python-net/nl/aspose.slides/ishapeframe/height/) | Geeft de hoogte van een frame.<br/>            Alleen-lezen **float**. |
| [`rotation`](/slides/python-net/nl/aspose.slides/ishapeframe/rotation/) | Geeft het aantal graden dat een frame rond de z-as is gedraaid.<br/>            Een positieve waarde duidt op een rotatie met de klok mee; een negatieve waarde<br/>            duidt op een rotatie tegen de klok in.<br/>            Alleen-lezen **float**. |
| [`center_x`](/slides/python-net/nl/aspose.slides/ishapeframe/center_x/) | Geeft de X-coördinaat van het midden van een frame.<br/>            Alleen-lezen **float**. |
| [`center_y`](/slides/python-net/nl/aspose.slides/ishapeframe/center_y/) | Geeft de Y-coördinaat van het midden van een frame.<br/>            Alleen-lezen **float**. |
| [`flip_h`](/slides/python-net/nl/aspose.slides/ishapeframe/flip_h/) | Bepaalt of een frame horizontaal wordt gespiegeld.<br/>            Alleen-lezen [`NullableBool`](/slides/python-net/nl/aspose.slides/nullablebool). |
| [`flip_v`](/slides/python-net/nl/aspose.slides/ishapeframe/flip_v/) | Bepaalt of een frame verticaal wordt gespiegeld.<br/>            Alleen-lezen [`NullableBool`](/slides/python-net/nl/aspose.slides/nullablebool). |
| [`rectangle`](/slides/python-net/nl/aspose.slides/ishapeframe/rectangle/) | Geeft de coördinaten van een frame.<br/>            Alleen-lezen [`RectangleF`](/slides/python-net/nl/aspose.slides/rectanglef). |
