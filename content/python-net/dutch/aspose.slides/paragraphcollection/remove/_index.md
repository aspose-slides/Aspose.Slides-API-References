## remove(self, item) {#iparagraph}
Verwijdert de eerste instantie van een specifiek object uit de **System.Collections.Generic.ICollection`1**.

### Retourneert
true als `item` succesvol is verwijderd uit de **System.Collections.Generic.ICollection`1**; anders false. Deze methode retourneert ook false als `item` niet wordt gevonden in de oorspronkelijke **System.Collections.Generic.ICollection`1**.



```python
def remove(self, item):
    ...
```


| Parameter | Type | Beschrijving |
| :- | :- | :- |
| item | [`IParagraph`](/slides/python-net/nl/aspose.slides/iparagraph) | Het object dat moet worden verwijderd uit de **System.Collections.Generic.ICollection`1**. |

### Uitzonderingen

| Uitzondering | Beschrijving |
| :- | :- |
| **RuntimeError(Proxy error(NotSupportedException))** | De **System.Collections.Generic.ICollection`1** is alleen-lezen. |
