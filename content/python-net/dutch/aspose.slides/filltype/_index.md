## FillType enumeratie

Specificeert het binnenvultype van verschillende visuele objecten.

Het FillType type geeft de volgende leden weer:

## Velden

| Veld | Beschrijving |
| :- | :- |
| NOT_DEFINED | Het vultype is niet gedefinieerd. |
| NO_FILL | Geen vulling toegepast. |
| SOLID | Gevuld met een effen kleur. |
| GRADIENT | De vulling is een verloop. |
| PATTERN | Een herhalend patroon wordt gebruikt om het object te vullen. |
| PICTURE | Een enkele afbeelding wordt gebruikt om het object te vullen. |
| GROUP | Het visuele object erft de vul-eigenschappen van de groep. |
