## LineSketchType enumeration

Geeft aan welk schetstype of effect aan een vorm is toegewezen.

Het type LineSketchType exposeert de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| NOT_DEFINED | Geeft aan dat een Sketch-effect van een vorm niet is gedefinieerd. |
| NONE | Geeft aan dat een vorm geen Sketch-effect heeft. Dit is gelijk aan een lege eigenschap. |
| CURVED | Geeft aan dat een vorm het Curved-effect heeft, dat elke rand van de vorm verandert in één grote zachte boog. |
| FREEHAND | Geeft aan dat een vorm het Freehand-effect heeft, dat het meest lijkt op een onvolkomen getekende lijn. |
| SCRIBBLE | Geeft aan dat een vorm het Scribble-effect heeft, dat een overdreven oscillatie vertoont alsof het opzettelijk rommelig is getekend. |
