## PPImageFormat enumeratie

Afbeeldingsformaten. Deze enum is een vervanging voor de `System.Drawing.Imaging.ImageFormat`-klasse. Het is nodig voor COM-compatibiliteit.

Het PPImageFormat-type bevat de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| BMP | Haalt het bitmap (BMP) afbeeldingsformaat op. |
| EMF | Haalt het verbeterde metafile (EMF) afbeeldingsformaat op. |
| EXIF | Haalt het uitwisselbare afbeeldingsbestand (Exif)-formaat op. |
| GIF | Haalt het Graphics Interchange Format (GIF) afbeeldingsformaat op. |
| ICON | Haalt het Windows-pictogram afbeeldingsformaat op. |
| JPEG | Haalt het Joint Photographic Experts Group (JPEG) afbeeldingsformaat op. |
| MEMORY_BMP | Haalt het formaat van een bitmap in het geheugen op. |
| PNG | Haalt het W3C Portable Network Graphics (PNG) afbeeldingsformaat op. |
| TIFF | Haalt het Tagged Image File Format (TIFF) afbeeldingsformaat op. |
| WMF | Haalt het Windows-metafile (WMF) afbeeldingsformaat op. |
