## IMasterLayoutSlideCollection klasse

Stelt een verzameling van alle layout slides van een gedefinieerde master slide voor.
Breidt de ILayoutSlideCollection interface uit met methoden voor het toevoegen/invoegen/verwijderen/kloon van layout slides in de context van de individuele verzamelingen van de master’s layout slides.
