## NormalViewProperties klasse

Stelt normale weergave-eigenschappen voor. De normale weergave bestaat uit drie inhoudsgebieden: de dia zelf, een zij-inhoudsgebied en een onder-inhoudsgebied.

Het NormalViewProperties-type maakt de volgende leden beschikbaar:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`show_outline_icons`](/slides/python-net/nl/aspose.slides/normalviewproperties/show_outline_icons/) | Specificeert of de applicatie pictogrammen moet weergeven als de outline-inhoud wordt weergegeven in een van de inhoudsgebieden van de normale weergavemodus.<br/>            Lezen/schrijven **bool**. |
| [`snap_vertical_splitter`](/slides/python-net/nl/aspose.slides/normalviewproperties/snap_vertical_splitter/) | Specificeert of de verticale splitter naar een geminimaliseerde toestand moet springen wanneer het zijgebied voldoende klein is.<br/>            Lezen/schrijven **bool**. |
| [`vertical_bar_state`](/slides/python-net/nl/aspose.slides/normalviewproperties/vertical_bar_state/) | Specificeert de toestand waarin de verticale splitbalk moet worden weergegeven. <br/>            Een verticale splitbalk scheidt de dia van het zij-inhoudsgebied. |
| [`horizontal_bar_state`](/slides/python-net/nl/aspose.slides/normalviewproperties/horizontal_bar_state/) | Specificeert de toestand waarin de horizontale splitbalk moet worden weergegeven.<br/>            Een horizontale splitbalk scheidt de dia van het inhoudsgebied onder de dia. |
| [`prefer_single_view`](/slides/python-net/nl/aspose.slides/normalviewproperties/prefer_single_view/) | Specificeert of de gebruiker de voorkeur geeft aan een volledig-venster enkel-inhoudsgebied boven de standaard normale weergave met drie inhoudsgebieden. Indien ingeschakeld kan de applicatie ervoor kiezen een van de inhoudsgebieden in het volledige venster weer te geven.<br/>            Lezen/schrijven **bool**. |
| [`restored_left`](/slides/python-net/nl/aspose.slides/normalviewproperties/restored_left/) | Dit element geeft de grootte van het zij-inhoudsgebied van de normale weergave aan, wanneer het gebied een variabele herstelde grootte heeft (noch geminimaliseerd noch gemaximaliseerd).<br/>            Alleen lezen [`INormalViewRestoredProperties`](/slides/python-net/nl/aspose.slides/inormalviewrestoredproperties). |
| [`restored_top`](/slides/python-net/nl/aspose.slides/normalviewproperties/restored_top/) | Dit element geeft de grootte van het bovenste dia-gebied van de normale weergave aan, wanneer het gebied een variabele herstelde grootte heeft (noch geminimaliseerd noch gemaximaliseerd).<br/>            Alleen lezen [`INormalViewRestoredProperties`](/slides/python-net/nl/aspose.slides/inormalviewrestoredproperties). |
