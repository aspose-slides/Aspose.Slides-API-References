## BlackWhiteMode enumeratie

Bepaalt hoe een gekleurde vorm moet worden omgezet naar zwart-wit.

Het type BlackWhiteMode bevat de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| NOT_DEFINED | De eigenschap is niet ingesteld |
| COLOR | Het object wordt gerenderd met normale kleuring |
| AUTOMATIC | Het object wordt gerenderd met automatische kleuring |
| GRAY | Het object wordt gerenderd met grijze kleuring |
| LIGHT_GRAY | Het object wordt gerenderd met lichtgrijze kleuring |
| INVERSE_GRAY | Het object wordt gerenderd met omgekeerde grijze kleuring |
| GRAY_WHITE | Het object wordt gerenderd met grijze en witte kleuring |
| BLACK_GRAY | Het object wordt gerenderd met zwarte en grijze kleuring |
| BLACK_WHITE | Het object wordt gerenderd met zwarte en witte kleuring |
| BLACK | Het object wordt alleen met zwarte kleuring gerenderd |
| WHITE | Het object wordt gerenderd met witte kleuring |
| HIDDEN | Het object wordt niet gerenderd |
