## ITextSearchOptions klasse

Stelt opties voor die kunnen worden gebruikt om te zoeken naar tekst in een Presentation, Slide of TextFrame.

Het type ITextSearchOptions geeft de volgende leden weer:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`case_sensitive`](/slides/python-net/nl/aspose.slides/itextsearchoptions/case_sensitive/) | Stel true in om hoofdlettergevoelige zoekopdrachten te gebruiken, anders false.<br/>            Lezen/Schrijven **bool**. |
| [`whole_words_only`](/slides/python-net/nl/aspose.slides/itextsearchoptions/whole_words_only/) | Stel true in om alleen volledige woorden te matchen, anders false.<br/>            Lezen/Schrijven **bool**. |
| [`include_notes`](/slides/python-net/nl/aspose.slides/itextsearchoptions/include_notes/) | Stel `true` in om tekst die zich in slide-notities bevindt op te nemen <br/>            bij het uitvoeren van tekstzoek-, vervangings- of markeerbewerkingen.<br/>            De standaardwaarde is `false`. |
