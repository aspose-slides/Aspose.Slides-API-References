## ShapeAdjustmentType enumeratie

Specificeert verschillende typen vormaanpassingswaarden.

Het ShapeAdjustmentType-type geeft de volgende leden weer:

## Velden

| Veld | Beschrijving |
| :- | :- |
| CUSTOM | Aangepast type (onbekende aanpassing) |
| CORNER_SIZE | Regelt de grootte van de hoeken. |
| LEFT_UP_CORNER | Regelt de linkerbovenhoek. |
| RIGHT_UP_CORNER | Regelt de rechterbovenhoek. |
| UP_CORNERS | Regelt de bovenste hoeken. |
| DOWN_CORNERS | Regelt de onderste hoeken. |
| THICKNESS | Regelt de dikte van de figuur. |
| ARROW_TAIL_THICKNESS | Regelt de dikte van de pijlstaart. |
| ARROWHEAD_LENGTH | Regelt de lengte van de pijlpunt. |
| ARROWHEAD_WIDTH | Regelt de breedte van de pijlpunt. |
| RADIUS | Regelt de grootte van de radius van de vorm of een onderdeel daarvan. |
| DEPTH | Regelt de diepte van de tandwieltanden of het afschuinings-effect. |
| SHAPE_PART_OFFSET | Regelt de offset van een deel van de figuur ten opzichte van een ander. |
| ANGLE | Regelt de hoek voor de figuur of een deel ervan. |
| START_ANGLE | Beginhoek voor taart- en boogvormen. |
| END_ANGLE | Eindhoek voor taart- en boogvormen. |
| START_POINT_X | Regelt de X-positie van het startpunt van de callout. |
| START_POINT_Y | Regelt de Y-positie van het startpunt van de callout. |
| CONNECTOR_POINT_1X | Regelt de horizontale positie van het hoekaanpassingspunt van de callout. |
| CONNECTOR_POINT_1Y | Regelt de verticale positie van het hoekaanpassingspunt van de callout. |
| CONNECTOR_POINT_2X | Regelt de horizontale positie van het hoekaanpassingspunt van de callout. |
| CONNECTOR_POINT_2Y | Regelt de verticale positie van het hoekaanpassingspunt van de callout. |
| CONNECTOR_BEND_POSITION_X | Regelt de horizontale positie van de buiging in de connector. |
| CONNECTOR_BEND_POSITION_Y | Regelt de verticale positie van de buiging in de connector. |
| ATTACH_Y | Regelt het verticale bevestigingspunt van de figuur. |
| ATTACH_X | Regelt het horizontale bevestigingspunt van de figuur. |
| CALLOUT_HEIGHT | Regelt de verticale maat van de callout. |
| CALLOUT_WIDTH | Regelt de horizontale maat van de callout. |
| CALLOUT_SIZE | Regelt de grootte van de callout. |
| CURVATURE | Kromming van een gebogen, beugel, gebogen pijl of vorm. |
| HORIZONTAL_THICKNESS | Regelt de horizontale dikte van de hoekvorm. |
| VERTICAL_THICKNESS | Regelt de verticale dikte van de hoekvorm. |
| VERTICAL_SIZE | Regelt de verticale maat van de vorm. |
| HORIZONTAL_SIZE | Regelt de horizontale maat van de vorm. |
| TOP | Regelt de bovenkant van een vorm. |
