## split_text_by_columns(self) {#}
Splits de tekstinhoud van de [`ITextFrame`](/slides/python-net/nl/aspose.slides/itextframe) in een array van strings,  
            waarbij elk element overeenkomt met een aparte tekstkolom binnen het frame.

### Retour

Een array van strings, waarbij elke string de tekstinhoud van een specifieke kolom weergeeft  
            in de [`ITextFrame`](/slides/python-net/nl/aspose.slides/itextframe).



```python
def split_text_by_columns(self):
    ...
```


### Opmerkingen

Als het tekstframe geen meerdere kolommen bevat, zal de geretourneerde array één enkel element hebben  
            dat de volledige tekst bevat.  
            Lege kolommen worden weergegeven als lege strings in de array.
