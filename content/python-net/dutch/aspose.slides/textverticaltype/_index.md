## TextVerticalType enumeratie

Bepaalt de verticale schrijfrichting voor een tekst.

Het type TextVerticalType biedt de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| NOT_DEFINED | Niet gedefinieerd. |
| HORIZONTAL | Horizontale tekst. |
| VERTICAL | Verticale tekst. |
| VERTICAL270 | Verticale tekst van 270 graden. |
| WORD_ART_VERTICAL | WordArt verticale tekst. |
| EAST_ASIAN_VERTICAL | Oost-Aziatische verticale tekst. |
| MONGOLIAN_VERTICAL | Mongolische verticale tekst. |
| WORD_ART_VERTICAL_RIGHT_TO_LEFT | WordArt verticale tekst van rechts naar links. |
