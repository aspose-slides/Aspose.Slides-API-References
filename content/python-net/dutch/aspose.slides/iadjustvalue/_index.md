## IAdjustValue klasse

Stelt een aanpassingswaarde van een geometrische vorm voor.  
Deze waarden beïnvloeden de vorm van de geometrie.

Het type IAdjustValue biedt de volgende leden:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`raw_value`](/slides/python-net/nl/aspose.slides/iadjustvalue/raw_value/) | Retourneert of stelt de aanpassingswaarde "as is" in.<br/>            Lezen/Schrijven **int**. |
| [`angle_value`](/slides/python-net/nl/aspose.slides/iadjustvalue/angle_value/) | Retourneert of stelt de waarde in, waarbij deze wordt geïnterpreteerd als een hoek in graden.<br/>            Lezen/Schrijven **float**. |
| [`name`](/slides/python-net/nl/aspose.slides/iadjustvalue/name/) | Retourneert een naam van deze aanpassingswaarde.<br/>            Alleen-lezen **str**. |
| [`type`](/slides/python-net/nl/aspose.slides/iadjustvalue/type/) | Retourneert het type van de vormaanpassing.<br/>            Alleen-lezen [`ShapeAdjustmentType`](/slides/python-net/nl/aspose.slides/shapeadjustmenttype). |
