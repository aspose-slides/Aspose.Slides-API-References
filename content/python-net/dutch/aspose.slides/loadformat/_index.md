## LoadFormat enumeratie

Geeft het formaat van het document aan dat geladen moet worden.

Het LoadFormat-type bevat de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| AUTO | Instrueert Aspose.Slides om het formaat automatisch te herkennen. |
| PPT | Microsoft PowerPoint 97-2003-presentatie. |
| PPS | Microsoft PowerPoint 97-2003-diavoorstelling. |
| PPTX | Microsoft Office Open XML PresentationML-document. |
| PPSX | Microsoft Office Open XML PresentationML-diavoorstelling. |
| ODP | OpenOffice ODF-presentatie. |
| POTX | Microsoft Office Open XML PresentationML-sjabloon. |
| PPTM | Microsoft Office Open XML PresentationML-macro-ondersteund document. |
| PPSM | Microsoft Office Open XML PresentationML-macro-ondersteunde diavoorstelling. |
| POTM | Microsoft Office Open XML PresentationML-macro-ondersteunde sjabloon. |
| OTP | OpenOffice OTP-presentatiesjabloon. |
| PPT95 | Microsoft PowerPoint 95-presentatie. |
| POT | Microsoft PowerPoint 97-2003-presentatiesjabloon. |
| FODP | Platte XML ODF-presentatie. |
| UNKNOWN | Onbekend bestandsformaat |
