## INormalViewRestoredProperties klasse

Specificeert de grootte van het dia-gebied ((breedte wanneer een kind van restoredTop, hoogte wanneer een
            kind van restoredLeft) van de normale weergave, wanneer het gebied een variabele herstelde grootte heeft (niet geminimaliseerd noch gemaximaliseerd).

The INormalViewRestoredProperties type exposes the following members:

## Eigenschappen

| Property | Description |
| :- | :- |
| [`dimension_size`](/slides/python-net/nl/aspose.slides/inormalviewrestoredproperties/dimension_size/) | Specificeert de grootte van het dia-gebied (breedte wanneer een kind van RestoredTop, hoogte wanneer een kind van RestoredLeft).<br/>            Lezen/Schrijven **float**.<br/>            Werpt een uitzondering wanneer de waarde kleiner is dan 0 of groter dan 100. |
| [`auto_adjust`](/slides/python-net/nl/aspose.slides/inormalviewrestoredproperties/auto_adjust/) | Specificeert of de grootte van het zij-inhoudsgebied moet compenseren voor de nieuwe grootte<br/>            bij het wijzigen van de grootte van het venster dat de weergave binnen de applicatie bevat<br/>            Lezen/Schrijven **bool**. |
