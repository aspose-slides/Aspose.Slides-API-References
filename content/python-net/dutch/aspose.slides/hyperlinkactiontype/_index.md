## HyperlinkActionType enumeratie

Stelt een type hyperlinkactie voor.

Het type HyperlinkActionType biedt de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| UNKNOWN | Onbekend actietype. |
| NO_ACTION | Geen actie. |
| HYPERLINK | Gewone hyperlink. |
| JUMP_FIRST_SLIDE | Spring naar de eerste dia van de presentatie. |
| JUMP_PREVIOUS_SLIDE | Spring naar de vorige dia. |
| JUMP_NEXT_SLIDE | Spring naar de volgende dia. |
| JUMP_LAST_SLIDE | Spring naar de laatste dia van de presentatie. |
| JUMP_END_SHOW | Spring naar het einde van de diavoorstelling. |
| JUMP_LAST_VIEWED_SLIDE | Spring naar de laatst bekeken dia. |
| JUMP_SPECIFIC_SLIDE | Spring naar de specifieke dia, aangeduid door de eigenschap [`IHyperlink.target_slide`](/slides/python-net/nl/aspose.slides/ihyperlink/target_slide). |
| START_CUSTOM_SLIDE_SHOW | Start aangepaste diavoorstelling. |
| OPEN_FILE | Open het verwijzende bestand. |
| OPEN_PRESENTATION | Open de verwijzende presentatie. |
| START_STOP_MEDIA | Start/stop afspelen van mediabestand. |
| START_MACRO | Start uitvoeren van macro-script. |
| START_PROGRAM | Start programma. |
