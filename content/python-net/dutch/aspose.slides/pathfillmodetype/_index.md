## PathFillModeType enumeratie

Specificeert de manier waarop een pad moet worden gevuld

The PathFillModeType type exposes the following members:

## Velden

| Veld | Beschrijving |
| :- | :- |
| NONE | Geen padvulling<br/>            Dit specificeert dat het overeenkomstige pad geen vulling mag hebben. |
| NORMAL | Normale padvulling<br/>            Dit specificeert dat het overeenkomstige pad een normaal geschaduwde kleur op de vulling moet toepassen. |
| LIGHTEN | Verlichte padvulling<br/>            Dit specificeert dat het overeenkomstige pad een licht geschaduwde kleur op de vulling moet toepassen. |
| LIGHTEN_LESS | Minder verlichte padvulling<br/>            Dit specificeert dat het overeenkomstige pad een iets lichter geschaduwd kleur op de vulling moet toepassen. |
| DARKEN | Donkere padvulling<br/>            Dit specificeert dat het overeenkomstige pad een donkerder geschaduwd kleur op de vulling moet toepassen. |
| DARKEN_LESS | Minder donkere padvulling<br/>            Dit specificeert dat het overeenkomstige pad een iets donkerder geschaduwd kleur op de vulling moet toepassen. |
