## ShapeElementFillSource enumeratie

Geeft aan hoe een shape-element moet worden gevuld.

Het type ShapeElementFillSource bevat de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| NO_FILL | Vul primitive niet. |
| SHAPE | Gebruik de vulling van de vorm. |
| LIGHTEN | Gebruik de verlichte vulling van de vorm. |
| LIGHTEN_LESS | Gebruik een minder verlichte vulling van de vorm. |
| DARKEN | Gebruik de verduisterde vulling van de vorm. |
| DARKEN_LESS | Gebruik een minder verduisterde vulling van de vorm. |
