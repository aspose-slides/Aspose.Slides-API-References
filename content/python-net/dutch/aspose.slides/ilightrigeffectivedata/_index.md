## ILightRigEffectiveData klasse

Onveranderlijk object dat effectieve lichtrig-eigenschappen bevat.

Het ILightRigEffectiveData-type geeft de volgende leden weer:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`direction`](/slides/python-net/nl/aspose.slides/ilightrigeffectivedata/direction/) | Lichtrichting.<br/>            Alleen-lezen [`LightingDirection`](/slides/python-net/nl/aspose.slides/lightingdirection). |
| [`light_type`](/slides/python-net/nl/aspose.slides/ilightrigeffectivedata/light_type/) | Stelt een vooraf ingestelde lichtinstelling voor die op een vorm kan worden toegepast. <br/>            Het lichtrig vertegenwoordigt een groep lichten die op een specifieke manier ten opzichte van een 3D-scene zijn georiënteerd.<br/>            Alleen-lezen [`LightRigPresetType`](/slides/python-net/nl/aspose.slides/lightrigpresettype). |

## Methoden

| Methode | Beschrijving |
| :- | :- |
| [`get_rotation(self)`](/slides/python-net/nl/aspose.slides/ilightrigeffectivedata/get_rotation/#) | Een rotatie wordt gedefinieerd door het gebruik van een breedtegraadcoördinaat, een lengtegraadcoördinaat en een revolutie rond de as zoals de breedte- en lengtegraadcoördinaten.<br/>            Eerste element in teruggegeven array – breedtegraad, tweede – lengtegraad, derde – revolutie. |


### Opmerkingen

Deze interface wordt gebruikt als onderdeel van [`IThreeDFormatEffectiveData`](/slides/python-net/nl/aspose.slides/ithreedformateffectivedata).
