Bevat klassen die verschillende soorten waarschuwingen vertegenwoordigen
## Klassen

| Klasse | Beschrijving |
| :- | :- |
| [`IKnownIssueWarningInfo`](/slides/python-net/nl/aspose.slides.warnings/iknownissuewarninginfo/) | Stelt een waarschuwing voor over een bekend probleem dat niet in de nabije toekomst zal worden opgelost. |
| [`INotImplementedWarningInfo`](/slides/python-net/nl/aspose.slides.warnings/inotimplementedwarninginfo/) | Stelt een waarschuwing voor over een bekend niet-ingevoerd kenmerk dat niet in de nabije toekomst zal worden geïmplementeerd. |
| [`IObsoletePresLockingBehaviorWarningInfo`](/slides/python-net/nl/aspose.slides.warnings/iobsoletepreslockingbehaviorwarninginfo/) | Deze waarschuwing geeft aan dat een verouderd vergrendelingsgedrag van de presentatie wordt gebruikt. |
| [`IPresentationSignedWarningInfo`](/slides/python-net/nl/aspose.slides.warnings/ipresentationsignedwarninginfo/) | Deze waarschuwing geeft aan dat de gelezen presentatie de handtekening <br/>            heeft en dat deze handtekening tijdens de verwerking zal worden verwijderd. |
| [`IWarningCallback`](/slides/python-net/nl/aspose.slides.warnings/iwarningcallback/) | Interface voor klassen die een waarschuwing ontvangen |
| [`IWarningInfo`](/slides/python-net/nl/aspose.slides.warnings/iwarninginfo/) | Stelt een basisinterface voor voor alle waarschuwingen. |
