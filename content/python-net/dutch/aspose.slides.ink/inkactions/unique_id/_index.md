## unique_id eigenschap
Geeft een interne, presentatie-gebonden identifier terug die bedoeld is voor gebruik door add-ins of andere code.
            Omdat deze waarde door de gebruiker of programmatisch kan worden opnieuw toegewezen, mag deze niet worden beschouwd als een persistente unieke sleutel.
            Alleen-lezen **int**.
            Zie ook [`Shape.office_interop_shape_id`](/slides/python-net/nl/aspose.slides/shape/office_interop_shape_id).
