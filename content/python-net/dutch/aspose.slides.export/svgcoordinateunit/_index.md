## SvgCoordinateUnit enumeratie

Stelt CSS2-coördineerneenheden voor die worden gebruikt om SVG-coördinaten te definiëren.

Het type SvgCoordinateUnit biedt de volgende leden:

## Velden

| Field | Description |
| :- | :- |
| INCH | Inch |
| CENTIMETER | Centimeter |
| MILLIMETER | Millimeter |
| POINT | Punt (1/72 van een inch) |
| PICA | Pica (1/6 van een inch) |
| EM | Em-grootte van een lettertype van het omvattende element |
| EX | Ex-grootte (grootte van de kleine letter, meestal "x") van het lettertype van het omvattende element |
| PIXEL | Pixelgrootte |
| PERCENT | Procent |
