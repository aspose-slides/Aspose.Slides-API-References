## ISwfOptions klasse

Biedt opties die bepalen hoe een presentatie wordt opgeslagen in SWF-formaat.

Het type ISwfOptions bevat de volgende leden:

## Eigenschappen

| Property | Description |
| :- | :- |
| [`compressed`](/slides/python-net/nl/aspose.slides.export/iswfoptions/compressed/) | Specificeert of het gegenereerde SWF-document al dan niet gecomprimeerd moet worden.<br/>            Standaard is `true`. |
| [`viewer_included`](/slides/python-net/nl/aspose.slides.export/iswfoptions/viewer_included/) | Specificeert of het gegenereerde SWF-document al dan niet de geïntegreerde documentviewer moet bevatten.<br/>            Standaard is `true`. |
| [`show_page_border`](/slides/python-net/nl/aspose.slides.export/iswfoptions/show_page_border/) | Specificeert of de rand rond pagina's moet worden weergegeven. Standaard is true. |
| [`show_hidden_slides`](/slides/python-net/nl/aspose.slides.export/iswfoptions/show_hidden_slides/) | Specificeert of het gegenereerde document al dan niet verborgen dia's moet bevatten.<br/>            Standaard is `false`. |
| [`show_full_screen`](/slides/python-net/nl/aspose.slides.export/iswfoptions/show_full_screen/) | Toon/verberg de volledig-schermknop. Kan worden overschreven in flashvars. Standaard is true. |
| [`show_page_stepper`](/slides/python-net/nl/aspose.slides.export/iswfoptions/show_page_stepper/) | Toon/verberg de paginestappen. Kan worden overschreven in flashvars. Standaard is true. |
| [`show_search`](/slides/python-net/nl/aspose.slides.export/iswfoptions/show_search/) | Toon/verberg de zoeksectie. Kan worden overschreven in flashvars. Standaard is true. |
| [`show_top_pane`](/slides/python-net/nl/aspose.slides.export/iswfoptions/show_top_pane/) | Toon/verberg het volledige bovenpaneel. Kan worden overschreven in flashvars. Standaard is true. |
| [`show_bottom_pane`](/slides/python-net/nl/aspose.slides.export/iswfoptions/show_bottom_pane/) | Toon/verberg het onderste paneel. Kan worden overschreven in flashvars. Standaard is true. |
| [`show_left_pane`](/slides/python-net/nl/aspose.slides.export/iswfoptions/show_left_pane/) | Toon/verberg het linker paneel. Kan worden overschreven in flashvars. Standaard is true. |
| [`start_open_left_pane`](/slides/python-net/nl/aspose.slides.export/iswfoptions/start_open_left_pane/) | Start met geopend linker paneel. Kan worden overschreven in flashvars. Standaard is false. |
| [`enable_context_menu`](/slides/python-net/nl/aspose.slides.export/iswfoptions/enable_context_menu/) | Inschakelen/uitschakelen van contextmenu. Standaard is true. |
| [`logo_image_bytes`](/slides/python-net/nl/aspose.slides.export/iswfoptions/logo_image_bytes/) | Afbeelding die als logo wordt weergegeven in de rechterbovenhoek van de viewer.<br/>            De afbeelding moet een PNG-afbeelding van 32x64 pixels zijn, anders kan het logo onjuist worden weergegeven. |
| [`logo_link`](/slides/python-net/nl/aspose.slides.export/iswfoptions/logo_link/) | Haalt de volledige hyperlink-adresse op of stelt deze in voor een logo.<br/>            Heeft alleen effect als een [`ISwfOptions.logo_image_bytes`](/slides/python-net/nl/aspose.slides.export/iswfoptions/logo_image_bytes) is gespecificeerd. |
| [`jpeg_quality`](/slides/python-net/nl/aspose.slides.export/iswfoptions/jpeg_quality/) | Specificeert de kwaliteit van JPEG-afbeeldingen.<br/>            Standaard is 95. |
| [`slides_layout_options`](/slides/python-net/nl/aspose.slides.export/iswfoptions/slides_layout_options/) | Haalt op of stelt de modus in waarin dia's op de pagina worden geplaatst bij het exporteren van een presentatie [`ISlidesLayoutOptions`](/slides/python-net/nl/aspose.slides.export/islideslayoutoptions).<br/>            Deze eigenschap ondersteunt het toewijzen van objecten van type `Aspose.Slides.Export.HandoutLayoutingOptions` niet. |
