## skip_java_script_links eigenschap
Specifies whether to skip hyperlinks with JavaScript calls when saving the presentation. 
            Lezen/schrijven **bool**. De standaardwaarde is **false** .

### Opmerkingen

Wanneer deze eigenschap is ingesteld op **true**, worden hyperlinks met JavaScript-aanroepen bij het opslaan genegeerd.

Wanneer deze eigenschap is ingesteld op **false**, worden alle hyperlinks opgeslagen.
