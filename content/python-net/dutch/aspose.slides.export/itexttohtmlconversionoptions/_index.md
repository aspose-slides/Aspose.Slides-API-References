## ITextToHtmlConversionOptions class

Opties voor het extraheren van HTML uit de Pptx-tekst.

Het ITextToHtmlConversionOptions-type geeft de volgende leden weer:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`add_clipboard_fragment_header`](/slides/python-net/nl/aspose.slides.export/itexttohtmlconversionoptions/add_clipboard_fragment_header/) | Geeft een waarde terug of stelt deze in, waarmee wordt aangegeven of klembordkoppen moeten worden toegevoegd.<br/>            Lezen/schrijven **bool**. |
| [`text_inheritance_limit`](/slides/python-net/nl/aspose.slides.export/itexttohtmlconversionoptions/text_inheritance_limit/) | Geeft een onderliggende diepte terug of stelt deze in voor texteigenschappen.<br/>            Lezen/schrijven [`ITextToHtmlConversionOptions.text_inheritance_limit`](/slides/python-net/nl/aspose.slides.export/itexttohtmlconversionoptions/text_inheritance_limit). |
