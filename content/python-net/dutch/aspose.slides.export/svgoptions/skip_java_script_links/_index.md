## skip_java_script_links eigenschap
Specificeert of hyperlinks met JavaScript-aanroepen moeten worden overgeslagen bij het opslaan van de presentatie. 
            Lezen/schrijven **bool**. The default value is **false** .


### Opmerkingen

When this eigenschap is set to **true** , hyperlinks met JavaScript calls will be ignored while saving.


When this eigenschap is set to **false** , all hyperlinks will be saved.
