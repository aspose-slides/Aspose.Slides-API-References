## CompressionLevel enumeratie

Specificeert ZIP-compressieniveaus voor een OpenXML-bestand.
            Hogere niveaus bieden betere compressie ten koste van tragere verwerking.

Het type CompressionLevel bevat de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| NONE | Er wordt geen compressie toegepast. Bestanden worden ongewijzigd opgeslagen. |
| LEVEL1 | Snelste compressie met de laagste compressieverhouding. |
| LEVEL2 | Snellere compressie met een iets betere compressieverhouding dan [`CompressionLevel.LEVEL1`](/slides/python-net/nl/aspose.slides.export/compressionlevel/LEVEL1). |
| LEVEL3 | Biedt betere compressie dan [`CompressionLevel.LEVEL2`](/slides/python-net/nl/aspose.slides.export/compressionlevel/LEVEL2) met een matige impact op de prestaties. |
| LEVEL4 | Biedt betere compressie dan [`CompressionLevel.LEVEL3`](/slides/python-net/nl/aspose.slides.export/compressionlevel/LEVEL3). |
| LEVEL5 | Biedt verbeterde compressie ten opzichte van [`CompressionLevel.LEVEL4`](/slides/python-net/nl/aspose.slides.export/compressionlevel/LEVEL4) met extra verwerkingstijd. |
| LEVEL6 | Standaardcompressie, die een goede balans biedt tussen compressiesnelheid en bestandsgrootte.<br/>            Het standaardcompressieniveau. |
| LEVEL7 | Biedt hogere compressie dan [`CompressionLevel.LEVEL6`](/slides/python-net/nl/aspose.slides.export/compressionlevel/LEVEL6) met langzamere verwerking. |
| LEVEL8 | Biedt hogere compressie dan [`CompressionLevel.LEVEL7`](/slides/python-net/nl/aspose.slides.export/compressionlevel/LEVEL7). |
| LEVEL9 | Maximale compressie. Produceert de kleinste bestandsgrootte met de langzaamste verwerkingssnelheid. |
