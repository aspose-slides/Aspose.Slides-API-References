## TextInheritanceLimit enumeratie

Bepaalt de diepte van de overerving van tekst-eigenschappen.

Het type TextInheritanceLimit bevat de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| ALL | Erft alle texteigenschappen. |
| TEXT_BOX | Erft alleen van de stijl van TextFrame. |
| PARAGRAPH_ONLY | Gebruikt alleen eigenschappen gedefinieerd voor alinea. |
