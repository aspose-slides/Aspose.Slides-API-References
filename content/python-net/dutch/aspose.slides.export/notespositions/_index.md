## NotesPositions enumeratie

Stelt de regel voor om notities weer te geven in het geëxporteerde document

Het NotesPositions type bevat de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| NONE | Specificeert dat notities helemaal niet weergegeven moeten worden. |
| BOTTOM_FULL | Specificeert dat notities volledig weergegeven moeten worden met extra pagina's indien nodig. |
| BOTTOM_TRUNCATED | Specificeert dat notities op slechts één pagina weergegeven moeten worden. |
