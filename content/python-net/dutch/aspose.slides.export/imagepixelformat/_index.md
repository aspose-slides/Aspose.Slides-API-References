## ImagePixelFormat enumeratie

Specificeert het pixelformaat voor de gegenereerde afbeeldingen.

Het type ImagePixelFormat geeft de volgende leden weer:

## Velden

| Veld | Beschrijving |
| :- | :- |
| FORMAT_1BPP_INDEXED | 1 bit per pixel, geïndexeerd. |
| FORMAT_4BPP_INDEXED | 4 bits per pixel, geïndexeerd. |
| FORMAT_8BPP_INDEXED | 8 bits per pixel, geïndexeerd. |
| FORMAT_24BPP_RGB | 24 bits per pixel, RGB. |
| FORMAT_32BPP_ARGB | 32 bits per pixel, ARGB. |
