## HandoutType enumeratie

Specificeert hoeveel dia's en in welke volgorde op de pagina worden geplaatst.

De HandoutType type geeft de volgende leden weer:

## Velden

| Veld | Beschrijving |
| :- | :- |
| HANDOUTS1 | Eén dia per pagina. |
| HANDOUTS2 | Twee dia's per pagina. |
| HANDOUTS3 | Drie dia's per pagina. |
| HANDOUTS_4_HORIZONTAL | Vier dia's per pagina in een horizontale volgorde. |
| HANDOUTS_4_VERTICAL | Vier dia's per pagina in een verticale volgorde. |
| HANDOUTS_6_HORIZONTAL | Zes dia's per pagina in een horizontale volgorde. |
| HANDOUTS_6_VERTICAL | Zes dia's per pagina in een verticale volgorde. |
| HANDOUTS_9_HORIZONTAL | Negen dia's per pagina in een horizontale volgorde. |
| HANDOUTS_9_VERTICAL | Negen dia's per pagina in een verticale volgorde. |
