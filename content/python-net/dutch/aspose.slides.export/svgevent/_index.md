## SvgEvent enumeratie

Vertegenwoordigt opties voor SVG shape.

Het type SvgEvent exposeert de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| ON_FOCUS_IN | Komt voor wanneer een element focus krijgt, bijvoorbeeld wanneer een tekst wordt geselecteerd. |
| ON_FOCUS_OUT | Komt voor wanneer een element de focus verliest, bijvoorbeeld wanneer een tekst wordt gedeselecteerd. |
| ON_ACTIVATE | Komt voor wanneer een element geactiveerd wordt, bijvoorbeeld via een muisklik of een toetsaanslag. |
| ON_CLICK | Komt voor wanneer de knop van het aanwijzende apparaat wordt geklikt op een element. |
| ON_MOUSE_DOWN | Komt voor wanneer de knop van het aanwijzende apparaat wordt ingedrukt op een element. |
| ON_MOUSE_UP | Komt voor wanneer de knop van het aanwijzende apparaat wordt losgelaten op een element. |
| ON_MOUSE_OVER | Komt voor wanneer het aanwijzende apparaat naar een element wordt bewogen. |
| ON_MOUSE_MOVE | Komt voor wanneer het aanwijzende apparaat beweegt terwijl het zich boven een element bevindt. |
| ON_MOUSE_OUT | Komt voor wanneer het aanwijzende apparaat van een element wordt weggehaald. |
| ON_LOAD | Komt voor wanneer de user agent het element en zijn afstammelingen en alle verwezen bronnen volledig heeft geparseerd, die nodig zijn om het weer te geven. |
| ON_UNLOAD | Komt voor wanneer de DOM-implementatie een document uit een venster of frame verwijdert. Alleen van toepassing op buitenste svg-elementen. |
| ON_ABORT | Komt voor wanneer het laden van de pagina wordt gestopt voordat een element volledig geladen mag worden. |
| ON_ERROR | Komt voor wanneer een element niet correct wordt geladen of wanneer er een fout optreedt tijdens de uitvoering van een script. |
| ON_RESIZE | Komt voor wanneer een documentweergave wordt aangepast in grootte. Alleen van toepassing op buitenste svg-elementen. |
| ON_SCROLL | Komt voor wanneer een documentweergave verschuift langs de X- of Y-as of beide. Alleen van toepassing op buitenste svg-elementen. |
| ON_ZOOM | Komt voor wanneer het zoomniveau van een documentweergave wordt gewijzigd. Alleen van toepassing op buitenste svg-elementen. |
| ON_BEGIN | Komt voor wanneer een animatie-element begint. |
| ON_END | Komt voor wanneer een animatie-element eindigt. |
| ON_REPEAT | Komt voor wanneer een animatie-element wordt herhaald. |
