## root_directory_clsid eigenschap
Stelt de objectklasse GUID (CLSID) voor die is opgeslagen in de root directory-vermelding. Kan worden gebruikt voor COM activatie van de toepassing van het document. De standaardwaarde is '64818D11-4F9B-11CF-86EA-00AA00B929E8' die overeenkomt met 'Microsoft Powerpoint.Slide.8'.
