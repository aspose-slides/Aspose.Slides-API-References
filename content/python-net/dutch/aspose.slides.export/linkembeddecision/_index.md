## LinkEmbedDecision enumeratie

Bepaalt hoe het object wordt verwerkt tijdens het opslaan.

Het type LinkEmbedDecision bevat de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| LINK | Object wordt extern opgeslagen, verwezen via URL |
| EMBED | Object moet, indien mogelijk, worden ingebed in een gegenereerd bestand. Als inbedding onmogelijk is, wordt GetUrl aangeroepen en wordt het object, afhankelijk van het resultaat, via URL verwezen of genegeerd. |
| IGNORE | Object wordt genegeerd. |
