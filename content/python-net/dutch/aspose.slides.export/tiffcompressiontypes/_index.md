## TiffCompressionTypes enumeratie

Biedt opties die bepalen hoe een presentatie in TIFF-formaat wordt gecomprimeerd.

Het type TiffCompressionTypes bevat de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| DEFAULT | Geeft het standaard compressieschema aan (LZW). |
| NONE | Geeft aan dat er geen compressie wordt toegepast. |
| CCITT3 | Geeft het CCITT3-compressieschema aan. |
| CCITT4 | Geeft het CCITT4-compressieschema aan. |
| LZW | Geeft het LZW-compressieschema aan (Standaard). |
| RLE | Geeft het RLE-compressieschema aan. |
