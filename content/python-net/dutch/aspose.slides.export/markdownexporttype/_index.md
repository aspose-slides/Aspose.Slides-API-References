## MarkdownExportType enumeratie

Type van het renderen van een document.

Het type MarkdownExportType geeft de volgende leden weer:

## Velden

| Veld | Beschrijving |
| :- | :- |
| SEQUENTIAL | Render alle items afzonderlijk. Eén voor één. |
| TEXT_ONLY | Render alleen tekst. |
| VISUAL | Render alle items, items die gegroepeerd zijn - render samen. |
