## skip_java_script_links eigenschap
Specificeert of hyperkoppelingen met JavaScript-oproepen overgeslagen moeten worden bij het opslaan van de presentatie. 
            Lezen/schrijven **bool**. De standaardwaarde is **false** .


### Opmerkingen

Wanneer deze eigenschap is ingesteld op **true**, worden hyperkoppelingen met JavaScript-oproepen genegeerd bij het opslaan.


Wanneer deze eigenschap is ingesteld op **false**, worden alle hyperkoppelingen opgeslagen.
