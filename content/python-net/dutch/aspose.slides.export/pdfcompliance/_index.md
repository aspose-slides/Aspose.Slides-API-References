## PdfCompliance enumeratie

Constanten die het PDF-standaarden-nalevingsniveau definiëren.

Het PdfCompliance type bevat de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| PDF15 | Het uitvoerbestand voldoet aan de PDF 1.5-standaard. |
| PDF16 | Het uitvoerbestand voldoet aan de PDF 1.6-standaard. |
| PDF17 | Het uitvoerbestand voldoet aan de PDF 1.7-standaard. |
| PDF_A1B | Het uitvoerbestand voldoet aan de PDF/A-1b-standaard. |
| PDF_A1A | Het uitvoerbestand voldoet aan de PDF/A-1a-standaard. |
| PDF_A2B | Het uitvoerbestand voldoet aan de PDF/A-2b-standaard. |
| PDF_A2A | Het uitvoerbestand voldoet aan de PDF/A-2a-standaard. |
| PDF_A3B | Het uitvoerbestand voldoet aan de PDF/A-3b-standaard. |
| PDF_A3A | Het uitvoerbestand voldoet aan de PDF/A-3a-standaard. |
| PDF_UA | Het uitvoerbestand voldoet aan de PDF/UA-standaard. |
| PDF_A2U | Het uitvoerbestand voldoet aan de PDF/A-2u-standaard. |
