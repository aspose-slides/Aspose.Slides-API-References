## root_directory_clsid eigenschap
Geeft de objectklasse GUID (CLSID) weer die is opgeslagen in de root directory entry. Kan worden gebruikt voor COM-activatie van de applicatie van het document. De standaardwaarde is '64818D11-4F9B-11CF-86EA-00AA00B929E8' die overeenkomt met 'Microsoft Powerpoint.Slide.8'.
