## SaveFormat enumeratie

Constanten die het formaat van een opgeslagen presentatie definiëren.

Het SaveFormat-type bevat de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| PPT | Presentatie opslaan in PPT-formaat. |
| PDF | Presentatie opslaan in PDF-formaat. |
| XPS | Presentatie opslaan in XPS-formaat. |
| PPTX | Presentatie opslaan in PPTX-formaat. |
| PPSX | Presentatie opslaan in PPSX (diavoorstelling)-formaat. |
| TIFF | Presentatie opslaan als meerpagina's TIFF-afbeelding. |
| ODP | Presentatie opslaan in ODP-formaat. |
| PPTM | Presentatie opslaan in PPTM (macro-ingeschakelde presentatie)-formaat. |
| PPSM | Presentatie opslaan in PPSM (macro-ingeschakelde diavoorstelling)-formaat. |
| POTX | Presentatie opslaan in POTX (sjabloon)-formaat. |
| POTM | Presentatie opslaan in POTM (macro-ingeschakelde sjabloon)-formaat. |
| HTML | Presentatie opslaan in HTML-formaat. |
| SWF | Presentatie opslaan in SWF-formaat. |
| OTP | Presentatie opslaan in OTP (presentatiesjabloon)-formaat. |
| PPS | Presentatie opslaan in PPS-formaat. |
| POT | Presentatie opslaan in POT-formaat. |
| FODP | Presentatie opslaan in FODP-formaat. |
| GIF | Presentatie opslaan in GIF-formaat. |
| HTML5 | Presentatie opslaan in HTML-formaat met behulp van het nieuwe HTML5-sjablonsysteem. |
| MD | Presentatie opslaan in Markdown-formaat |
| XML | Presentatie opslaan in PowerPoint XML-presentatieformaat. |
