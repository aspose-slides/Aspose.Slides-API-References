## CommentsPositions enumeratie

Geeft de regel weer om opmerkingen in het geëxporteerde document weer te geven

Het type CommentsPositions exposeert de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| NONE | Specificeert dat opmerkingen niet getoond moeten worden. |
| BOTTOM | Specificeert dat opmerkingen onderaan de pagina moeten worden weergegeven. |
| RIGHT | Specificeert dat opmerkingen rechts van de pagina moeten worden weergegeven. |
