## Conformance enumeratie

Specificeert de conformiteitsklasse waaraan het PresentationML-document voldoet.

Het Conformance type geeft de volgende leden weer:

## Velden

| Veld | Beschrijving |
| :- | :- |
| ECMA_376_2006 | Specificeert dat het document voldoet aan ECMA376:2006. |
| ISO_29500_2008_TRANSITIONAL | Specificeert dat het document voldoet aan de ISO/IEC 29500:2008 Transitional-conformiteitsklasse. |
| ISO_29500_2008_STRICT | Specificeert dat het document voldoet aan de ISO/IEC 29500:2008 Strict-conformiteitsklasse. |
