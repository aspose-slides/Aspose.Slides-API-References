## SvgExternalFontsHandling enumeratie

Stelt een manier voor om externe lettertypen te gebruiken voor het tekenen van tekst.

Het type SvgExternalFontsHandling bevat de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| ADD_LINKS_TO_FONT_FILES | Voeg links toe naar afzonderlijke lettertypebestanden in de stijlsectie van het SVG-bestand. |
| EMBED | Sla lettertypegegevens direct op in het SVG-bestand. Controleer alstublieft alle licentieovereenkomsten voor externe lettertypen voordat u deze optie gebruikt. |
| VECTORIZE | Sla alle tekst die externe lettertypen gebruikt op als grafische weergave. |
