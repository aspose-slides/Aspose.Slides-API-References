## BlackWhiteConversionMode enumeratie

Biedt opties die bepalen hoe afbeeldingen van dia's worden geconverteerd naar bitonaal afbeeldingen.

Het type BlackWhiteConversionMode bevat de volgende leden:

## Velden

| Veld | Beschrijving |
| :- | :- |
| DEFAULT | Specificeert geen conversie-algoritme. Het algoritme geïmplementeerd in de TIFF-codec wordt gebruikt. (Standaard) |
| DITHERING | Specificeert het dithering-algoritme (Floyd-Steinberg). |
| DITHERING_FLOYD_STEINBERG | Specificeert het Floyd-Steinberg dithering-algoritme. |
| AUTO | Specificeert het automatisch berekende drempelalgoritme (Otsu). |
| AUTO_OTSU | Specificeert het automatisch berekende Otsu-drempelalgoritme. |
| THRESHOLD25 | Specificeert het statische drempelalgoritme (25%). |
| THRESHOLD50 | Specificeert het statische drempelalgoritme (50%). |
| THRESHOLD75 | Specificeert het statische drempelalgoritme (75%). |
