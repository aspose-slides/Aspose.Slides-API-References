## ISmartArtNode klasse

Stelt een knoop van een SmartArt-diagram voor.

Het type ISmartArtNode bevat de volgende leden:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`child_nodes`](/slides/python-net/nl/aspose.slides.smartart/ismartartnode/child_nodes/) | Retourneert collecties van alle kindknopen van de huidige knoop.<br/>            Alleen-lezen [`ISmartArtNodeCollection`](/slides/python-net/nl/aspose.slides.smartart/ismartartnodecollection). |
| [`shapes`](/slides/python-net/nl/aspose.slides.smartart/ismartartnode/shapes/) | Retourneert collecties van alle vormen die aan de knoop zijn gekoppeld.<br/>            Alleen-lezen [`ISmartArtShapeCollection`](/slides/python-net/nl/aspose.slides.smartart/ismartartshapecollection). |
| [`text_frame`](/slides/python-net/nl/aspose.slides.smartart/ismartartnode/text_frame/) | Retourneert of stelt de tekst van de knoop in.<br/>            Alleen-lezen [`ITextFrame`](/slides/python-net/nl/aspose.slides/itextframe). |
| [`is_assistant`](/slides/python-net/nl/aspose.slides.smartart/ismartartnode/is_assistant/) | Retourneert of stelt de knoop in als assistent.<br/>            Lezen/Schrijven **bool**. |
| [`level`](/slides/python-net/nl/aspose.slides.smartart/ismartartnode/level/) | Retourneert het nestingsniveau van de knoop.<br/>            Alleen-lezen **int**. |
| [`bullet_fill_format`](/slides/python-net/nl/aspose.slides.smartart/ismartartnode/bullet_fill_format/) | Retourneert het FillFormat-object dat opvullingsopmaak eigenschappen voor een knoop-opsommingsteken bevat.<br/>            Opmerking: kan None retourneren voor bepaalde types van SmartArt-indelingen die geen opsommingstekens voor knopen bieden.<br/>            Alleen-lezen [`IFillFormat`](/slides/python-net/nl/aspose.slides/ifillformat). |
| [`position`](/slides/python-net/nl/aspose.slides.smartart/ismartartnode/position/) | Retourneert of stelt de nulgebaseerde positie van de knoop onder broers-zusterknopen in.<br/>            Lezen/Schrijven **int**. |
| [`is_hidden`](/slides/python-net/nl/aspose.slides.smartart/ismartartnode/is_hidden/) | Retourneert true als deze knoop een verborgen knoop in het datamodel is.<br/>            Alleen-lezen **bool**. |
| [`organization_chart_layout`](/slides/python-net/nl/aspose.slides.smartart/ismartartnode/organization_chart_layout/) | Retourneert of stelt het lay-outtype van het organigram dat aan de huidige knoop is gekoppeld in.<br/>            Lezen/Schrijven [`OrganizationChartLayoutType`](/slides/python-net/nl/aspose.slides.smartart/organizationchartlayouttype). |
