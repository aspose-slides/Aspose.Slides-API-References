## IVbaProject klasse

Stelt een VBA-project voor met presentatiemacro's.

Het type IVbaProject geeft de volgende leden weer:

## Eigenschappen

| Property | Description |
| :- | :- |
| [`name`](/slides/python-net/nl/aspose.slides.vba/ivbaproject/name/) | Geeft de naam van het VBA-project terug.<br/>            Alleen-lezen **str**. |
| [`modules`](/slides/python-net/nl/aspose.slides.vba/ivbaproject/modules/) | Geeft de lijst met alle modules die zich in het VBA-project bevinden.<br/>            Alleen-lezen [`IVbaModuleCollection`](/slides/python-net/nl/aspose.slides.vba/ivbamodulecollection). |
| [`references`](/slides/python-net/nl/aspose.slides.vba/ivbaproject/references/) | Geeft de lijst met alle referenties die zich in het VBA-project bevinden.<br/>            Alleen-lezen [`IVbaReferenceCollection`](/slides/python-net/nl/aspose.slides.vba/ivbareferencecollection). |
| [`is_password_protected`](/slides/python-net/nl/aspose.slides.vba/ivbaproject/is_password_protected/) | Geeft aan of het VBAProject beschermd is met een wachtwoord om projecteigenschappen te bekijken.<br/>            Alleen-lezen **bool**. |
