## Reflection klasse

Representeert een Reflection-effect.

Het Reflection-type maakt de volgende leden beschikbaar:

## Eigenschappen

| Eigenschap | Beschrijving |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/nl/aspose.slides.effects/reflection/start_pos_alpha/) | Specificeert de startpositie (langs de alfa-kleurverloophelling) van de start-alphawaarde (percentages).<br/>            Lezen/Schrijven **float**. |
| [`end_pos_alpha`](/slides/python-net/nl/aspose.slides.effects/reflection/end_pos_alpha/) | Specificeert de eindpositie (langs de alfa-kleurverloophelling) van de eind-alphawaarde (percentages).<br/>            Lezen/Schrijven **float**. |
| [`fade_direction`](/slides/python-net/nl/aspose.slides.effects/reflection/fade_direction/) | Specificeert de richting om de reflectie te verschuiven. (hoek).<br/>            Lezen/Schrijven **float**. |
| [`start_reflection_opacity`](/slides/python-net/nl/aspose.slides.effects/reflection/start_reflection_opacity/) | Beginnende reflectie-opaciteit. (percentages).<br/>            Lezen/Schrijven **float**. |
| [`end_reflection_opacity`](/slides/python-net/nl/aspose.slides.effects/reflection/end_reflection_opacity/) | Eindreflectie-opaciteit. (percentages).<br/>            Lezen/Schrijven **float**. |
| [`blur_radius`](/slides/python-net/nl/aspose.slides.effects/reflection/blur_radius/) | Vervagingsstraal.<br/>            Lezen/Schrijven **float**. |

| [`rectangle_align`](/slides/python-net/nl/aspose.slides.effects/reflection/rectangle_align/) | Rechthoekuitlijning.<br/>            Lezen/Schrijven [`RectangleAlignment`](/slides/python-net/nl/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/nl/aspose.slides.effects/reflection/skew_horizontal/) | Specificeert de horizontale scheefhoek.<br/>            Lezen/Schrijven **float**. |

| [`scale_vertical`](/slides/python-net/nl/aspose.slides.effects/reflection/scale_vertical/) | Specificeert de verticale schaalfactor, negatieve schaal veroorzaakt een omkering. (percentages)<br/>            Lezen/Schrijven **float**. |
