## OrganizationChartLayoutType 열거형

조직도에서 자식 노드의 형식 유형을 나타냅니다

OrganizationChartLayoutType 타입은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| INITIAL | 초기 레이아웃 유형 |
| STANDART | 부모 노드 아래에 자식 노드를 가로로 배치합니다. |
| BOTH_HANGING | 부모 노드 아래에 자식 노드를 왼쪽과 오른쪽 양쪽에 수직으로 배치합니다. |
| LEFT_HANGING | 부모 노드 아래에 자식 노드를 왼쪽에 수직으로 배치합니다. |
| RIGHT_HANGING | 부모 노드 아래에 자식 노드를 오른쪽에 수직으로 배치합니다. |
