## width 속성
형상의 너비를 가져오거나 설정합니다. 단위는 포인트입니다.
            읽기/쓰기 **float**.

### 비고

반환된 값은 항상 정의되어 있으며 **float**가 아닙니다.
            할당된 값도 정의되어 있어야 합니다; `RawFrame` 인스턴스의 속성에만 **float**를 할당하십시오.
