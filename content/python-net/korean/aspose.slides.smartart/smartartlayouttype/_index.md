## SmartArtLayoutType 열거형

SmartArt 다이어그램의 레이아웃 유형을 나타냅니다.

SmartArtLayoutType 유형은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| ACCENT_PROCESS | 작업, 프로세스 또는 워크플로에서 진행, 타임라인 또는 순차적인 단계를 표시하는 데 사용합니다. Level 1 및 Level 2 텍스트를 모두 나타내는 데 적합합니다. |
| ACCENTED_PICTURE | 중앙의 사진 아이디어와 측면의 관련 아이디어를 표시하는 데 사용합니다. 상위 Level 1 텍스트는 중앙 사진 위에 표시됩니다. 다른 Level 1 도형에 대한 텍스트는 작은 원형 사진 옆에 표시됩니다. 이 레이아웃은 텍스트가 없어도 잘 작동합니다. |
| ALTERNATING_FLOW | 정보 그룹 또는 작업, 프로세스, 워크플로의 순차적인 단계를 표시하는 데 사용합니다. 정보 그룹 간의 상호 작용이나 관계를 강조합니다. |
| ALTERNATING_HEXAGONS | 상호 연결된 아이디어 시리즈를 나타내는 데 사용합니다. Level 1 텍스트는 육각형 내부에 표시되고, Level 2 텍스트는 도형 외부에 표시됩니다. |
| ALTERNATING_PICTURE_BLOCKS | 위에서 아래로 일련의 사진을 표시하는 데 사용합니다. 텍스트는 사진 오른쪽 또는 왼쪽에 번갈아가며 표시됩니다. |
| ALTERNATING_PICTURE_CIRCLES | 텍스트가 포함된 사진 세트를 표시하는 데 사용합니다. 해당 텍스트는 중앙 원 안에 표시되며 이미지가 왼쪽에서 오른쪽으로 교대로 배치됩니다. |
| ARROW_RIBBON | 연결된 개념이나 대비되는 개념을 표시하는 데 사용합니다(예: 반대되는 힘). Level 1 텍스트의 처음 두 줄이 화살표 텍스트로 사용됩니다. 사용되지 않은 텍스트는 표시되지 않지만 레이아웃을 변경하면 사용할 수 있습니다. |
| ASCENDING_PICTURE_ACCENT_PROCESS | 설명 텍스트와 함께 상승하는 사진 시리즈를 표시하는 데 사용합니다. 텍스트가 적을 때 가장 잘 작동합니다. |
| BALANCE | 두 아이디어를 비교하거나 관계를 표시하는 데 사용합니다. Level 1 텍스트의 처음 두 줄은 중심점 양쪽 상단 텍스트에 해당합니다. Level 2 텍스트는 각 측면에 네 개의 도형으로 제한되어 강조됩니다. Level 2 텍스트가 포함된 도형이 더 많은 쪽으로 균형이 기울어집니다. 사용되지 않은 텍스트는 표시되지 않지만 레이아웃을 전환 시 사용할 수 있습니다. |
| BASIC_BENDING_PROCESS | 작업, 프로세스 또는 워크플로에서 진행 또는 순차적인 단계를 표시하는 데 사용합니다. 도형의 가로 및 세로 표시 공간을 최대화합니다. |
| BASIC_BLOCK_LIST | 비순차적이거나 그룹화된 정보 블록을 표시하는 데 사용합니다. 도형의 가로 및 세로 표시 공간을 최대화합니다. |
| BASIC_CHEVRON_PROCESS | 진행, 타임라인, 작업·프로세스·워크플로의 순차 단계 또는 움직임·방향을 강조하는 데 사용합니다. Level 1 텍스트는 화살표 도형 내부에, Level 2 텍스트는 화살표 도형 아래에 표시됩니다. |
| BASIC_CYCLE | 원형 흐름에서 단계, 작업 또는 이벤트가 지속적으로 이어지는 시퀀스를 나타내는 데 사용합니다. 연결 화살표나 흐름보다 단계 자체를 강조합니다. Level 1 텍스트만 사용할 때 가장 적합합니다. |
| BASIC_MATRIX | 구역으로 구성된 전체와 구성 요소 간의 관계를 표시하는 데 사용합니다. Level 1 텍스트의 처음 네 줄이 각 구역에 표시됩니다. 사용되지 않은 텍스트는 표시되지 않지만 레이아웃을 전환하면 사용할 수 있습니다. |
| BASIC_PIE | 개별 부분이 전체를 이루는 방식을 표시하는 데 사용합니다. Level 1 텍스트의 처음 일곱 줄이 고르게 배분된 부채꼴이나 원형 도형에 해당합니다. 상단 Level 1 텍스트 도형은 강조를 위해 원형 외부에 표시됩니다. 사용되지 않은 텍스트는 표시되지 않지만 레이아웃을 전환하면 사용할 수 있습니다. |
| BASIC_PROCESS | 작업, 프로세스 또는 워크플로에서 진행 또는 순차적인 단계를 표시하는 데 사용합니다. |
| BASIC_PYRAMID | 가장 큰 요소가 하단에 있고 위쪽으로 좁아지는 비례적, 상호 연결된 또는 계층적 관계를 표시하는 데 사용합니다. Level 1 텍스트는 피라미드 구간에, Level 2 텍스트는 각 구간 옆의 도형에 표시됩니다. |
| BASIC_RADIAL | 순환 구조에서 중앙 아이디어와의 관계를 표시하는 데 사용합니다. Level 1 텍스트의 첫 줄은 중앙 도형에, 해당 Level 2 텍스트는 주변 원형 도형에 대응합니다. 사용되지 않은 텍스트는 표시되지 않지만 레이아웃을 전환 시 사용할 수 있습니다. |
| BASIC_TARGET | 포함, 단계적 변화 또는 계층적 관계를 표시하는 데 사용합니다. Level 1 텍스트의 처음 다섯 줄이 원과 연결됩니다. 사용되지 않은 텍스트는 표시되지 않지만 레이아웃을 바꾸면 사용할 수 있습니다. |
| BASIC_TIMELINE | 작업, 프로세스 또는 워크플로의 순차 단계 또는 타임라인 정보를 표시하는 데 사용합니다. Level 1 및 Level 2 텍스트 모두에 잘 작동합니다. |
| BASIC_VENN | 중첩되거나 상호 연결된 관계를 표시하는 데 사용합니다. Level 1 텍스트의 처음 일곱 줄이 원과 대응합니다. Level 1 텍스트가 네 줄 이하이면 원 안에, 네 줄 초과이면 원 밖에 표시됩니다. 사용되지 않은 텍스트는 표시되지 않지만 레이아웃을 바꾸면 사용할 수 있습니다. |
| BENDING_PICTURE_ACCENT_LIST | 비순차적이거나 그룹화된 정보 블록을 표시하는 데 사용합니다. 작은 원형 도형은 사진을 포함하도록 설계되었습니다. Level 1 및 Level 2 텍스트를 모두 설명하는 데 적합합니다. 도형의 가로·세로 표시 공간을 최대화합니다. |
| BENDING_PICTURE_BLOCKS | 사진 시리즈를 표시하는 데 사용합니다. 하단 코너를 덮는 상자는 소량의 텍스트를 포함할 수 있습니다. |
| BENDING_PICTURE_CAPTION | 순차적인 사진 시리즈를 표시하는 데 사용합니다. 하단 코너를 덮는 상자는 소량의 텍스트를 포함할 수 있습니다. |
| BENDING_PICTURE_CAPTION_LIST | 사진 시리즈를 표시하는 데 사용합니다. 제목과 설명은 각 사진 아래의 호출 도형에 표시됩니다. |
| BENDING_PICTURE_SEMI_TRANSPARENT_TEXT | 사진 시리즈를 표시하는 데 사용합니다. 반투명 상자가 사진 하단을 덮고 모든 수준의 텍스트를 포함합니다. |
| BLOCK_CYCLE | 원형 흐름에서 단계, 작업 또는 이벤트가 지속적으로 이어지는 시퀀스를 나타내는 데 사용합니다. 연결 화살표나 흐름보다 단계 자체를 강조합니다. |
| BUBBLE_PICTURE_LIST | 사진 시리즈를 표시하는 데 사용합니다. 최대 8개의 Level 1 사진을 포함할 수 있습니다. 사용되지 않은 텍스트와 사진은 표시되지 않지만 레이아웃 전환 시 사용할 수 있습니다. 텍스트가 적을 때 가장 적합합니다. |
| CAPTIONED_PICTURES | 다중 수준 텍스트가 포함된 사진을 표시하는 데 사용합니다. Level 1 텍스트가 적고 Level 2 텍스트가 중간 정도일 때 가장 적합합니다. |
| CHEVRON_LIST | 전체 워크플로를 구성하는 여러 프로세스를 통해 진행을 보여주는 데 사용합니다. 대비되는 프로세스를 설명하는 데에도 사용할 수 있습니다. Level 1 텍스트는 왼쪽 첫 번째 화살표 도형에, Level 2 텍스트는 Level 1 텍스트가 포함된 각 도형에 대한 가로 부단계에 대응합니다. |
| CIRCLE_ACCENT_TIMELINE | 이벤트 시리즈 또는 타임라인 정보를 표시하는 데 사용합니다. Level 1 텍스트는 큰 원형 도형 옆에, Level 2 텍스트는 작은 원형 도형 옆에 표시됩니다. |
| CIRCLE_ARROW_PROCESS | 각 항목에 대한 보조 텍스트와 함께 순차 항목을 표시하는 데 사용합니다. Level 1 텍스트가 적을 때 가장 적합합니다. |
| CIRCLE_PICTURE_HIERARCHY | 조직의 계층 정보 또는 보고 관계를 표시하는 데 사용합니다. 사진은 원 안에 표시되고 해당 텍스트는 사진 옆에 표시됩니다. |
| CIRCLE_RELATIONSHIP | 중심 아이디어와의 관계를 표시하는 데 사용합니다. Level 2 텍스트는 비순차적으로 추가되며 최대 다섯 개 항목으로 제한됩니다. Level 1 항목은 하나만 가능합니다. |
| CIRCULAR_BENDING_PROCESS | 작업, 프로세스 또는 워크플로에서 길거나 비선형적인 순서나 단계를 표시하는 데 사용합니다. Level 1 텍스트만 사용할 때 가장 적합합니다. 도형의 가로·세로 표시 공간을 최대화합니다. |
| CIRCULAR_PICTURE_CALLOUT | 중심 아이디어와 하위 아이디어 또는 관련 항목을 표시하는 데 사용합니다. 첫 번째 사진의 텍스트는 사진 하단을 차지합니다. 다른 Level 1 도형에 대한 텍스트는 작은 원형 사진 옆에 표시됩니다. 텍스트가 없어도 이 다이어그램은 잘 작동합니다. |
| CLOSED_CHEVRON_PROCESS | 진행, 타임라인 또는 작업·프로세스·워크플로의 순차 단계를 표시하거나 움직임·방향을 강조하는 데 사용합니다. 시작 도형의 정보를 강조하는 데 활용할 수 있습니다. Level 1 텍스트만 사용할 때 가장 적합합니다. |
| CONTINUOUS_ARROW_PROCESS | 타임라인이나 작업·프로세스·워크플로의 순차 단계를 표시하는 데 사용합니다. 각 Level 1 텍스트 줄이 화살표 도형 내부에 표시되므로 Level 1 텍스트만 사용할 때 가장 적합합니다. Level 2 텍스트는 화살표 도형 외부에 표시됩니다. |
| CONTINUOUS_BLOCK_PROCESS | 작업, 프로세스 또는 워크플로에서 진행 또는 순차 단계를 표시하는 데 사용합니다. Level 1 및 Level 2 텍스트가 최소일 때 가장 적합합니다. |
| CONTINUOUS_CYCLE | 원형 흐름에서 단계, 작업 또는 이벤트가 지속적으로 이어지는 시퀀스를 나타내는 데 사용합니다. 모든 구성 요소 간의 연결을 강조합니다. Level 1 텍스트만 사용할 때 가장 적합합니다. |
| CONTINUOUS_PICTURE_LIST | 상호 연결된 정보 그룹을 표시하는 데 사용합니다. 원형 도형은 사진을 포함하도록 설계되었습니다. |
| CONVERGING_ARROWS | 아이디어나 개념이 중앙 지점으로 수렴하는 모습을 표시하는 데 사용합니다. Level 1 텍스트만 사용할 때 가장 적합합니다. |
| CONVERGING_RADIAL | 사이클에서 개념이나 구성 요소가 중심 아이디어와 갖는 관계를 표시하는 데 사용합니다. Level 1 텍스트의 첫 줄은 중앙 원형 도형에, Level 2 텍스트 줄은 주변 사각형 도형에 대응합니다. 사용되지 않은 텍스트는 표시되지 않지만 레이아웃을 바꾸면 사용할 수 있습니다. |
| COUNTERBALANCE_ARROWS | 두 개의 반대 아이디어나 개념을 표시하는 데 사용합니다. Level 1 텍스트의 처음 두 줄이 각각 화살표에 대응하며 Level 2 텍스트와도 잘 어울립니다. 사용되지 않은 텍스트는 표시되지 않지만 레이아웃 전환 시 사용할 수 있습니다. |
| CYCLE_MATRIX | 순환 진행에서 중심 아이디어와의 관계를 표시하는 데 사용합니다. Level 1 텍스트의 첫 네 줄이 부채꼴 또는 원형 도형에 대응하고, Level 2 텍스트는 해당 부채꼴 또는 원형 도형 옆의 사각형 도형에 표시됩니다. 사용되지 않은 텍스트는 표시되지 않지만 레이아웃 전환 시 사용할 수 있습니다. |
| DESCENDING_BLOCK_LIST | 관련 아이디어 그룹 또는 정보 목록을 표시하는 데 사용합니다. 텍스트 도형이 순차적으로 높이가 감소하고 Level 1 텍스트가 수직으로 표시됩니다. |
| DESCENDING_PROCESS | 하강하는 이벤트 시리즈를 표시하는 데 사용합니다. 첫 번째 Level 1 텍스트가 화살표 상단에, 마지막 Level 1 텍스트가 화살표 하단에 표시됩니다. 처음 일곱 개의 Level 1 항목만 표시됩니다. 텍스트가 소량에서 중량일 때 가장 적합합니다. |
| DETAILED_PROCESS | 많은 Level 2 텍스트와 함께 단계별 진행을 표시하는 데 사용합니다. |
| DIVERGING_ARROWS | 아이디어나 개념이 중앙 소스로부터 외부로 진행하는 모습을 표시하는 데 사용합니다. Level 1 텍스트만 사용할 때 가장 적합합니다. |
