## IBehavior 클래스

효과의 기본 클래스 동작을 나타냅니다.

IBehavior 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`accumulate`](/slides/python-net/ko/aspose.slides.animation/ibehavior/accumulate/) | 애니메이션 동작이 누적되는지 여부를 나타냅니다.<br/>읽기/쓰기 [`NullableBool`](/slides/python-net/ko/aspose.slides/nullablebool). |
| [`additive`](/slides/python-net/ko/aspose.slides.animation/ibehavior/additive/) | 현재 애니메이션 동작이 다른 실행 중인 애니메이션과 결합되는지 여부를 나타냅니다.<br/>읽기/쓰기 [`BehaviorAdditiveType`](/slides/python-net/ko/aspose.slides.animation/behavioradditivetype). |
| [`properties`](/slides/python-net/ko/aspose.slides.animation/ibehavior/properties/) | 동작의 속성을 나타냅니다.<br/>읽기 전용 [`IBehaviorPropertyCollection`](/slides/python-net/ko/aspose.slides.animation/ibehaviorpropertycollection). |
| [`timing`](/slides/python-net/ko/aspose.slides.animation/ibehavior/timing/) | 효과 동작에 대한 타이밍 속성을 나타냅니다.<br/>읽기/쓰기 [`ITiming`](/slides/python-net/ko/aspose.slides.animation/itiming). |
