## Timing 클래스

애니메이션 타이밍을 나타냅니다.

Timing 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`accelerate`](/slides/python-net/ko/aspose.slides.animation/timing/accelerate/) | 가속 동작 효과의 지속 시간 백분율을 설명합니다.<br/>            읽기/쓰기 **float**. |
| [`decelerate`](/slides/python-net/ko/aspose.slides.animation/timing/decelerate/) | 감속 동작 효과의 지속 시간 백분율을 설명합니다.<br/>            읽기/쓰기 **float**. |
| [`auto_reverse`](/slides/python-net/ko/aspose.slides.animation/timing/auto_reverse/) | 전방으로 재생한 후 애니메이션을 자동으로 역방향으로 재생할지 여부를 설명합니다.<br/>            읽기/쓰기 **bool**. |
| [`duration`](/slides/python-net/ko/aspose.slides.animation/timing/duration/) | 애니메이션 효과의 지속 시간을 설명합니다.<br/>            읽기/쓰기 **float**. |
| [`repeat_count`](/slides/python-net/ko/aspose.slides.animation/timing/repeat_count/) | 효과가 반복되어야 할 횟수를 설명합니다.<br/>            읽기/쓰기 **float**. |
| [`repeat_until_end_slide`](/slides/python-net/ko/aspose.slides.animation/timing/repeat_until_end_slide/) | 이 속성은 효과가 슬라이드 끝까지 반복될지 여부를 지정합니다.<br/>            읽기/쓰기 **bool**. |
| [`repeat_until_next_click`](/slides/python-net/ko/aspose.slides.animation/timing/repeat_until_next_click/) | 이 속성은 효과가 다음 클릭까지 반복될지 여부를 지정합니다.<br/>            읽기/쓰기 **bool**. |
| [`repeat_duration`](/slides/python-net/ko/aspose.slides.animation/timing/repeat_duration/) | 효과가 반복되어야 할 횟수를 설명합니다.<br/>            읽기/쓰기 **float**. |
| [`restart`](/slides/python-net/ko/aspose.slides.animation/timing/restart/) | 효과가 완료된 후 재시작될지 여부를 지정합니다.<br/>            읽기/쓰기 [`EffectRestartType`](/slides/python-net/ko/aspose.slides.animation/effectrestarttype). |
| [`rewind`](/slides/python-net/ko/aspose.slides.animation/timing/rewind/) | 이 속성은 재생이 완료될 때 효과를 되감을지 여부를 지정합니다.<br/>            읽기/쓰기 **bool**. |
| [`speed`](/slides/python-net/ko/aspose.slides.animation/timing/speed/) | 타이밍을 가속(또는 감속)할 백분율을 지정합니다.<br/>            읽기/쓰기 **float**. |
| [`trigger_delay_time`](/slides/python-net/ko/aspose.slides.animation/timing/trigger_delay_time/) | 트리거 후 지연 시간을 설명합니다.<br/>            읽기/쓰기 **float**. |
| [`trigger_type`](/slides/python-net/ko/aspose.slides.animation/timing/trigger_type/) | 트리거 유형을 설명합니다.<br/>            읽기/쓰기 [`EffectTriggerType`](/slides/python-net/ko/aspose.slides.animation/effecttriggertype). |
