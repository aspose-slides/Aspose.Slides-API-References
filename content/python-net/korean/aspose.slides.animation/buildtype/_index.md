## BuildType 열거형

텍스트가 애니메이션 중에 도형에 표시되는 방식을 결정합니다.

BuildType 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| AS_ONE_OBJECT | 포함하는 도형과 함께. |
| ALL_PARAGRAPHS_AT_ONCE | 모든 단락. |
| BY_LEVEL_PARAGRAPHS1 | 깊이 1인 단락 그룹별. |
| BY_LEVEL_PARAGRAPHS2 | 깊이 2인 단락 그룹별. |
| BY_LEVEL_PARAGRAPHS3 | 깊이 3인 단락 그룹별. |
| BY_LEVEL_PARAGRAPHS4 | 깊이 4인 단락 그룹별. |
| BY_LEVEL_PARAGRAPHS5 | 깊이 5인 단락 그룹별. |
