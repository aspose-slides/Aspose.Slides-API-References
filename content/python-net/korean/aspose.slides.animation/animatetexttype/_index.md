## AnimateTextType 열거형

애니메이션 효과의 텍스트 애니메이션 유형을 나타냅니다.

AnimateTextType 유형은 다음 멤버를 제공합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| ALL_AT_ONCE | 모든 텍스트를 한 번에 애니메이션합니다. |
| BY_WORD | 단어 단위로 텍스트를 애니메이션합니다. |
| BY_LETTER | 문자 단위로 텍스트를 애니메이션합니다. |
