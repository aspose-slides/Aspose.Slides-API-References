## ITextAnimation 클래스

텍스트 애니메이션을 나타냅니다.

ITextAnimation 유형은 다음 멤버를 제공합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`build_type`](/slides/python-net/ko/aspose.slides.animation/itextanimation/build_type/) | 텍스트 애니메이션의 빌드 유형 목록(예: Paragraph 1,2,3, All at Once).<br/>            읽기/쓰기 [`ITextAnimation.build_type`](/slides/python-net/ko/aspose.slides.animation/itextanimation/build_type). |
| [`effect_animate_background_shape`](/slides/python-net/ko/aspose.slides.animation/itextanimation/effect_animate_background_shape/) | 그룹 여부에 따른 연결된 도형 효과(또는 없음)<br/>            읽기/쓰기 [`IEffect`](/slides/python-net/ko/aspose.slides.animation/ieffect). |

## 메서드

| 메서드 | 설명 |
| :- | :- |
| [`add_effect(self, effect_type, subtype, trigger_type)`](/slides/python-net/ko/aspose.slides.animation/itextanimation/add_effect/#effecttype-effectsubtype-effecttriggertype) | 그룹 텍스트 애니메이션의 현재 시퀀스 끝에 새 효과를 추가합니다.<br/>            이 그룹의 효과 개수보다 텍스트 단락 수가 같거나 많을 때만 유효합니다! |
