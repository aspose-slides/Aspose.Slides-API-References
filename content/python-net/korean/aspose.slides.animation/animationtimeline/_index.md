## AnimationTimeLine 클래스

애니메이션 타임라인을 나타냅니다.

AnimationTimeLine 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`interactive_sequences`](/slides/python-net/ko/aspose.slides.animation/animationtimeline/interactive_sequences/) | 인터랙티브 시퀀스 컬렉션을 반환합니다.<br/>            이 시퀀스는 지정된 대상 모양을 클릭하여 발생하는 효과만 포함할 수 있습니다.<br/>            읽기 전용 [`ISequenceCollection`](/slides/python-net/ko/aspose.slides.animation/isequencecollection). |
| [`main_sequence`](/slides/python-net/ko/aspose.slides.animation/animationtimeline/main_sequence/) | 주 효과 컬렉션만 포함할 수 있는 메인 시퀀스를 반환합니다.<br/>            읽기 전용 [`ISequence`](/slides/python-net/ko/aspose.slides.animation/isequence). |
| [`text_animation_collection`](/slides/python-net/ko/aspose.slides.animation/animationtimeline/text_animation_collection/) | 텍스트 애니메이션 컬렉션을 반환합니다.<br/>            읽기 전용 [`ITextAnimationCollection`](/slides/python-net/ko/aspose.slides.animation/itextanimationcollection). |
