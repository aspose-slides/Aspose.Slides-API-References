## AfterAnimationType 열거형

애니메이션 효과의 사후 애니메이션 유형을 나타냅니다.

AfterAnimationType 유형은 다음 멤버를 제공합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| DO_NOT_DIM | 애니메이션 후 어두워지지 않음. |
| COLOR | 애니메이션 후 색상. |
| HIDE_AFTER_ANIMATION | 애니메이션 후 숨기기. |
| HIDE_ON_NEXT_MOUSE_CLICK | 다음 마우스 클릭 시 애니메이션 후 숨기기. |
