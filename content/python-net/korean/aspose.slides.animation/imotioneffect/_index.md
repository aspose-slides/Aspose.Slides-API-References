## IMotionEffect 클래스

효과의 움직임 동작을 나타냅니다.

IMotionEffect 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`from_address`](/slides/python-net/ko/aspose.slides.animation/imotioneffect/from_address/) | 애니메이션 시작 위치를 x/y 좌표(퍼센트)로 지정합니다.<br/>읽기/쓰기 **aspose.slides.PointF**. |
| [`to`](/slides/python-net/ko/aspose.slides.animation/imotioneffect/to/) | 애니메이션 움직임 효과의 대상 위치를 퍼센트로 지정합니다.<br/>읽기/쓰기 **aspose.slides.PointF**. |
| [`by`](/slides/python-net/ko/aspose.slides.animation/imotioneffect/by/) | 애니메이션의 상대적 오프셋 값을 퍼센트로 설명합니다.<br/>읽기/쓰기 **aspose.slides.PointF**. |
| [`rotation_center`](/slides/python-net/ko/aspose.slides.animation/imotioneffect/rotation_center/) | X 각도로 회전 경로를 회전시키는 데 사용되는 회전 중심을 설명합니다.<br/>읽기/쓰기 **aspose.slides.PointF**. |
| [`origin`](/slides/python-net/ko/aspose.slides.animation/imotioneffect/origin/) | 슬라이드 레이아웃이나 상위 요소와 같이 움직임 경로의 기준이 되는 원점을 지정합니다.<br/>읽기/쓰기 [`MotionOriginType`](/slides/python-net/ko/aspose.slides.animation/motionorigintype). |
| [`path`](/slides/python-net/ko/aspose.slides.animation/imotioneffect/path/) | 애니메이션 움직임을 위해 좌표와 함께 따라가는 경로 기본 형식을 지정합니다.<br/>읽기/쓰기 [`IMotionPath`](/slides/python-net/ko/aspose.slides.animation/imotionpath). |
| [`path_edit_mode`](/slides/python-net/ko/aspose.slides.animation/imotioneffect/path_edit_mode/) | 모양이 이동할 때 움직임 경로가 어떻게 이동하는지를 지정합니다.<br/>읽기/쓰기 [`MotionPathEditMode`](/slides/python-net/ko/aspose.slides.animation/motionpatheditmode). |
| [`angle`](/slides/python-net/ko/aspose.slides.animation/imotioneffect/angle/) | 움직임 경로의 상대 각도를 설명합니다.<br/>읽기/쓰기 **float**. |
