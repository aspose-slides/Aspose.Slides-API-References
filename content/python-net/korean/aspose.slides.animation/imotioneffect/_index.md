## IMotionEffect 클래스

효과의 움직임 효과 동작을 나타냅니다.

IMotionEffect 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`from_address`](/slides/python-net/ko/aspose.slides.animation/imotioneffect/from_address/) | 애니메이션을 시작할 x/y 좌표를 지정합니다(백분율 단위). <br/>            읽기/쓰기 [`PointF`](/slides/python-net/ko/aspose.slides/pointf). |
| [`to`](/slides/python-net/ko/aspose.slides.animation/imotioneffect/to/) | 애니메이션 동작 효과의 목표 위치를 지정합니다(백분율 단위).<br/>            읽기/쓰기 [`PointF`](/slides/python-net/ko/aspose.slides/pointf). |
| [`by`](/slides/python-net/ko/aspose.slides.animation/imotioneffect/by/) | 애니메이션의 상대적 오프셋 값을 설명합니다(백분율 단위).<br/>            읽기/쓰기 [`PointF`](/slides/python-net/ko/aspose.slides/pointf). |
| [`rotation_center`](/slides/python-net/ko/aspose.slides.animation/imotioneffect/rotation_center/) | X 각도로 움직임 경로를 회전시키는 데 사용되는 회전 중심을 설명합니다.<br/>            읽기/쓰기 [`PointF`](/slides/python-net/ko/aspose.slides/pointf). |
| [`origin`](/slides/python-net/ko/aspose.slides.animation/imotioneffect/origin/) | 슬라이드 레이아웃 또는 상위 요소와 같이 움직임 경로의 기준점이 무엇인지 지정합니다.<br/>            읽기/쓰기 [`MotionOriginType`](/slides/python-net/ko/aspose.slides.animation/motionorigintype). |
| [`path`](/slides/python-net/ko/aspose.slides.animation/imotioneffect/path/) | 애니메이션 움직임을 위한 좌표가 따라가는 경로 기본형식을 지정합니다.<br/>            읽기/쓰기 [`IMotionPath`](/slides/python-net/ko/aspose.slides.animation/imotionpath). |
| [`path_edit_mode`](/slides/python-net/ko/aspose.slides.animation/imotioneffect/path_edit_mode/) | 도형이 이동될 때 움직임 경로가 어떻게 이동하는지 지정합니다.<br/>            읽기/쓰기 [`MotionPathEditMode`](/slides/python-net/ko/aspose.slides.animation/motionpatheditmode). |
| [`angle`](/slides/python-net/ko/aspose.slides.animation/imotioneffect/angle/) | 움직임 경로의 상대 각도를 설명합니다.<br/>            읽기/쓰기 **float**. |
