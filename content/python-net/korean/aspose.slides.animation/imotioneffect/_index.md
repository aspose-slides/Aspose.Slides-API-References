## IMotionEffect 클래스

효과의 모션 효과 동작을 나타냅니다.

IMotionEffect 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`from_`](/slides/python-net/ko/aspose.slides.animation/imotioneffect/from_/) | 애니메이션을 시작할 x/y 좌표를 지정합니다 (퍼센트 단위). <br/>            읽기/쓰기 [`PointF`](/slides/python-net/ko/aspose.slides/pointf). |
| [`to`](/slides/python-net/ko/aspose.slides.animation/imotioneffect/to/) | 애니메이션 모션 효과의 대상 위치를 지정합니다 (퍼센트 단위).<br/>            읽기/쓰기 [`PointF`](/slides/python-net/ko/aspose.slides/pointf). |
| [`by`](/slides/python-net/ko/aspose.slides.animation/imotioneffect/by/) | 애니메이션에 대한 상대 오프셋 값을 설명합니다 (퍼센트 단위).<br/>            읽기/쓰기 [`PointF`](/slides/python-net/ko/aspose.slides/pointf). |
| [`rotation_center`](/slides/python-net/ko/aspose.slides.animation/imotioneffect/rotation_center/) | X 각도만큼 모션 경로를 회전시키는 데 사용되는 회전 중심을 설명합니다.<br/>            읽기/쓰기 [`PointF`](/slides/python-net/ko/aspose.slides/pointf). |
| [`origin`](/slides/python-net/ko/aspose.slides.animation/imotioneffect/origin/) | 모션 경로의 기준이 되는 원본이 슬라이드 레이아웃이나 부모와 같은 무엇에 상대적인지 지정합니다,<br/>            또는 부모.<br/>            읽기/쓰기 [`MotionOriginType`](/slides/python-net/ko/aspose.slides.animation/motionorigintype). |
| [`path`](/slides/python-net/ko/aspose.slides.animation/imotioneffect/path/) | 애니메이션 모션을 위한 좌표와 함께 따라가는 경로 기본 요소를 지정합니다.<br/>            읽기/쓰기 [`IMotionPath`](/slides/python-net/ko/aspose.slides.animation/imotionpath). |
| [`path_edit_mode`](/slides/python-net/ko/aspose.slides.animation/imotioneffect/path_edit_mode/) | 도형이 이동할 때 모션 경로가 어떻게 움직이는지 지정합니다.<br/>            읽기/쓰기 [`MotionPathEditMode`](/slides/python-net/ko/aspose.slides.animation/motionpatheditmode). |
| [`angle`](/slides/python-net/ko/aspose.slides.animation/imotioneffect/angle/) | 모션 경로의 상대 각도를 설명합니다.<br/>            읽기/쓰기 **float**. |
