## Behavior 클래스

효과의 기본 클래스 동작을 나타냅니다.

Behavior 타입은 다음 멤버를 제공합니다:

## 속성

| Property | Description |
| :- | :- |
| [`accumulate`](/slides/python-net/ko/aspose.slides.animation/behavior/accumulate/) | 애니메이션 동작이 누적되는지 여부를 나타냅니다.<br/>            읽기/쓰기 [`NullableBool`](/slides/python-net/ko/aspose.slides/nullablebool). |
| [`additive`](/slides/python-net/ko/aspose.slides.animation/behavior/additive/) | 현재 애니메이션 동작이 다른 실행 중인 애니메이션과 결합되는지 여부를 나타냅니다.<br/>            읽기/쓰기 [`BehaviorAdditiveType`](/slides/python-net/ko/aspose.slides.animation/behavioradditivetype). |
| [`properties`](/slides/python-net/ko/aspose.slides.animation/behavior/properties/) | 동작의 속성을 나타냅니다.<br/>            읽기 전용 [`IBehaviorPropertyCollection`](/slides/python-net/ko/aspose.slides.animation/ibehaviorpropertycollection). |
| [`timing`](/slides/python-net/ko/aspose.slides.animation/behavior/timing/) | 효과 동작에 대한 타이밍 속성을 나타냅니다.<br/>            읽기/쓰기 [`ITiming`](/slides/python-net/ko/aspose.slides.animation/itiming). |
