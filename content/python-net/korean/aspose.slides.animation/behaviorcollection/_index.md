## BehaviorCollection 클래스

동작 효과의 컬렉션을 나타냅니다.

BehaviorCollection 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`count`](/slides/python-net/ko/aspose.slides.animation/behaviorcollection/count/) | 컬렉션에 있는 동작의 수를 반환합니다.<br/>            읽기 전용 **int**. |
| [`is_read_only`](/slides/python-net/ko/aspose.slides.animation/behaviorcollection/is_read_only/) | **System.Collections.Generic.ICollection`1**이 읽기 전용인지 여부를 나타내는 값을 가져옵니다.<br/>            읽기 전용 **bool**. |

지정된 인덱스에서 동작을 반환합니다.

| 이름 | 설명 |
| :- | :- |
| [`[index]`](/slides/python-net/ko/aspose.slides.animation/behaviorcollection/__getitem__/) | 반환할 동작의 인덱스. |
