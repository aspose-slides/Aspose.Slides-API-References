## IColorEffect 클래스

IColorEffect 형식은 다음 구성원을 노출합니다:

| 속성 | 설명 |
| :- | :- |
| [`from_address`](/slides/python-net/ko/aspose.slides.animation/icoloreffect/from_address/) | 이 값은 동작의 시작 색상을 지정하는 데 사용됩니다.<br/>            읽기/쓰기 [`IColorFormat`](/slides/python-net/ko/aspose.slides/icolorformat). |
| [`to`](/slides/python-net/ko/aspose.slides.animation/icoloreffect/to/) | 애니메이션 색상 변경에 대한 결과 색상을 설명합니다.<br/>            읽기/쓰기 [`IColorFormat`](/slides/python-net/ko/aspose.slides/icolorformat). |
| [`by`](/slides/python-net/ko/aspose.slides.animation/icoloreffect/by/) | 색상 애니메이션에 대한 상대적인 오프셋 값을 설명합니다.<br/>            읽기/쓰기 [`IColorOffset`](/slides/python-net/ko/aspose.slides.animation/icoloroffset). |
