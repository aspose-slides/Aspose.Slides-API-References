## PropertyEffect 클래스

속성 효과 동작을 나타냅니다.

**상속:**[`PropertyEffect`](/slides/python-net/ko/aspose.slides.animation/propertyeffect) → [`Behavior`](/slides/python-net/ko/aspose.slides.animation/behavior)

PropertyEffect 형식은 다음 멤버를 노출합니다:

## 생성자

| 생성자 | 설명 |
| :- | :- |
| [`__init__(self)`](/slides/python-net/ko/aspose.slides.animation/propertyeffect/__init__/#) | 새 인스턴스를 생성합니다. |

## 속성

| 속성 | 설명 |
| :- | :- |
| [`accumulate`](/slides/python-net/ko/aspose.slides.animation/propertyeffect/accumulate/) | 애니메이션 동작이 누적되는지를 나타냅니다.<br/>            읽기/쓰기 [`NullableBool`](/slides/python-net/ko/aspose.slides/nullablebool). |
| [`additive`](/slides/python-net/ko/aspose.slides.animation/propertyeffect/additive/) | 현재 애니메이션 동작이 다른 실행 중인 애니메이션과 결합되는지를 나타냅니다.<br/>            읽기/쓰기 [`BehaviorAdditiveType`](/slides/python-net/ko/aspose.slides.animation/behavioradditivetype). |
| [`properties`](/slides/python-net/ko/aspose.slides.animation/propertyeffect/properties/) | 동작의 속성을 나타냅니다.<br/>            읽기 전용 [`IBehaviorPropertyCollection`](/slides/python-net/ko/aspose.slides.animation/ibehaviorpropertycollection). |
| [`timing`](/slides/python-net/ko/aspose.slides.animation/propertyeffect/timing/) | 효과 동작의 타이밍 속성을 나타냅니다.<br/>            읽기/쓰기 [`ITiming`](/slides/python-net/ko/aspose.slides.animation/itiming). |
| [`from_address`](/slides/python-net/ko/aspose.slides.animation/propertyeffect/from_address/) | 애니메이션의 시작 값을 지정합니다.<br/>            읽기/쓰기 **str**. |
| [`to`](/slides/python-net/ko/aspose.slides.animation/propertyeffect/to/) | 애니메이션의 끝 값을 지정합니다.<br/>            읽기/쓰기 **str**. |
| [`by`](/slides/python-net/ko/aspose.slides.animation/propertyeffect/by/) | 애니메이션에 대한 상대 오프셋 값을 지정합니다.<br/>            애니메이션 시작 전 위치를 기준으로 합니다.<br/>            읽기/쓰기 **str**. |
| [`value_type`](/slides/python-net/ko/aspose.slides.animation/propertyeffect/value_type/) | 속성 값의 유형을 지정합니다.<br/>            읽기/쓰기 [`PropertyValueType`](/slides/python-net/ko/aspose.slides.animation/propertyvaluetype). |
| [`calc_mode`](/slides/python-net/ko/aspose.slides.animation/propertyeffect/calc_mode/) | 애니메이션의 보간 모드를 지정합니다<br/>            읽기/쓰기 [`PropertyCalcModeType`](/slides/python-net/ko/aspose.slides.animation/propertycalcmodetype). |
| [`points`](/slides/python-net/ko/aspose.slides.animation/propertyeffect/points/) | 애니메이션의 포인트를 지정합니다.<br/>            읽기/쓰기 [`IPointCollection`](/slides/python-net/ko/aspose.slides.animation/ipointcollection). |
