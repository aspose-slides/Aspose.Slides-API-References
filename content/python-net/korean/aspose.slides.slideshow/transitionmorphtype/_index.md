## TransitionMorphType 열거형

Morph 전환 유형을 나타냅니다.

TransitionMorphType 타입은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| BY_OBJECT | Morph 전환은 도형을 분할할 수 없는 객체로 간주하여 수행됩니다. |
| BY_WORD | Morph 전환은 가능한 경우 텍스트를 단어 단위로 전송하여 수행됩니다. |
| BY_CHAR | Morph 전환은 가능한 경우 텍스트를 문자 단위로 전송하여 수행됩니다. |
