## AsposeAIWebClient 클래스

Aspose 고유의 LLM에 연결되는 내장 [`IAIWebClient`](/slides/python-net/ko/aspose.slides.ai/iaiwebclient) 구현입니다. 매개변수 없는 **SlidesAIAgent.#ctor** 생성자에서 사용되는 기본 클라이언트입니다.

AsposeAIWebClient 유형은 다음 멤버를 노출합니다:

## 생성자

| Constructor | Description |
| :- | :- |
| [`__init__(self)`](/slides/python-net/ko/aspose.slides.ai/asposeaiwebclient/__init__/#) | Aspose AI 웹 클라이언트의 인스턴스를 생성하며, 기본 Aspose LLM 엔드포인트에 연결합니다.<br/>            이 클라이언트는 매개변수 없는 **SlidesAIAgent.#ctor** 생성자에서 사용되므로, 클라이언트를 **Aspose.Slides.AI.SlidesAIAgent.#ctor(Aspose.Slides.A**<br/>            생성자에 직접 전달할 때만 명시적으로 생성할 필요가 있습니다. |
| [`__init__(self, url)`](/slides/python-net/ko/aspose.slides.ai/asposeaiwebclient/__init__/#str) | 사용자 지정 엔드포인트 URL에 연결되는 Aspose AI 웹 클라이언트 인스턴스를 생성합니다. Aspose.Slides 팀에서 제공한 URL이 있는 경우 이<br/>            오버로드를 사용하고, 그렇지 않으면 기본 URL을 사용하는 **AsposeAIWebClient.#ctor** 오버로드를 사용하십시오. |
