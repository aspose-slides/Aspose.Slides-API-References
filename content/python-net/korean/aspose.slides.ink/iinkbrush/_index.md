## IInkBrush 클래스

추적 브러시를 나타냅니다.

IInkBrush 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`color`](/slides/python-net/ko/aspose.slides.ink/iinkbrush/color/) | 선에 대한 브러시 색상을 가져오거나 설정합니다. |
| [`size`](/slides/python-net/ko/aspose.slides.ink/iinkbrush/size/) | 선의 크기를 포인트 단위로 가져오거나 설정합니다. |
| [`ink_effect`](/slides/python-net/ko/aspose.slides.ink/iinkbrush/ink_effect/) | 잉크 스트로크의 시각적 스타일을 정의하는 잉크 효과 유형을 가져옵니다 (예: Galaxy, Gold, Silver).<br/>            값은 브러시 속성 \"inkEffects\"에서 구문 분석됩니다. 인식된 효과가 지정되지 않으면,<br/>            [`InkEffectType.NOT_DEFINED`](/slides/python-net/ko/aspose.slides.ink/inkeffecttype/NOT_DEFINED)가 반환됩니다. |
