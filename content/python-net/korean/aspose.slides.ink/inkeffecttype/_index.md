## InkEffectType 열거형

지정된 시각 효과 집합을 정의합니다.
각 효과는 스타일화된 잉크 외관을 시뮬레이션하는 텍스처 또는 이미지에 해당합니다.
이러한 값은 렌더링 중 디지털 잉크 스트로크의 시각 스타일을 사용자 정의하는 데 사용할 수 있습니다.

InkEffectType 유형은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| NOT_DEFINED | 효과가 정의되지 않았거나 알 수 없습니다. 이 값은 기본값이나 대체값으로 사용할 수 있습니다. |
| BRONZE | 청동 잉크와 유사한 따뜻한 갈색 금속 텍스처입니다. |
| GALAXY | 은하를 연상시키는 다채롭고 반짝이는 텍스처이며, 우주 색조를 가지고 있습니다. |
| GOLD | 잉크 스트로크에 고급스러운 외관을 부여하는 밝은 금속 금 텍스처입니다. |
| LAVA | 빨강과 주황색 색조를 가진 용암이 녹은 듯한 불꽃 텍스처입니다. |
| OCEAN | 바다 파도나 물 기반 잉크를 모방한 깊은 파란색의 유동적인 텍스처입니다. |
| RAINBOW_GLITTER | 축제적이거나 활기찬 잉크 스트로크에 사용되는 다채롭고 반짝이는 무지개 글리터 효과입니다. |
| ROSE_GOLD | 장미 금과 유사한 부드러운 핑크-골드 혼합으로, 우아한 잉크 스트로크에 적합합니다. |
| SILVER | 고전적인 은잉크를 시뮬레이션하는 차가운 금속 실버 텍스처입니다. |
