## 프레임 속성
도형 프레임의 속성을 반환하거나 설정합니다.
읽기/쓰기 [`IShapeFrame`](/slides/python-net/ko/aspose.slides/ishapeframe).

### 비고

반환된 IShapeFrame 인스턴스의 각 속성값은 undefined가 아닙니다 (NaN 또는 NotDefined가 아님).
할당된 IShapeFrame 인스턴스의 각 속성값은 undefined가 아니어야 합니다 (NaN 또는 NotDefined가 아니어야 합니다).
RawFrame 인스턴스 속성에 undefined 값을 설정할 수 있습니다.

### 정의:
```python
@property
def frame(self):
    ...

@frame.setter
def frame(self, value):
    ...
```
