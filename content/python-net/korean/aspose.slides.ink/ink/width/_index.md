## width 속성
모양의 width를 포인트 단위로 가져오거나 설정합니다.
            읽기/쓰기 **float**.


### 비고

반환된 값은 항상 정의되어 있으며 **float**가 아닙니다.
            할당된 값도 정의되어 있어야 합니다; **float**는 `RawFrame` 인스턴스의 속성에만 할당하십시오.

def width(self):
    ...

    ...
