## SplitterBarStateType 열거형

분할 바가 표시되어야 하는 상태를 지정합니다. 분할 바는 보기 영역 내에서 기본 영역과 보조 영역을 분리합니다.

SplitterBarStateType 유형은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| MINIMIZED | 기본 영역이 애플리케이션이 허용하는 보기 영역의 최소량을 차지합니다. |
| RESTORED | 기본 영역이 특정 중간 크기를 가집니다. |
| MAXIMIZED | 기본 영역이 애플리케이션이 허용하는 보기 영역의 최대량을 차지합니다. |
