## FontStyleType 열거형

텍스트에 적용할 수 있는 서식 스타일을 정의합니다.

FontStyleType 유형은 다음 멤버를 제공합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| REGULAR | 표준 텍스트. |
| BOLD | 굵은 텍스트. |
| ITALIC | 이탤릭 텍스트. |
| UNDERLINE | 밑줄이 있는 텍스트. |
| STRIKEOUT | 가로선으로 취소된 텍스트. |
