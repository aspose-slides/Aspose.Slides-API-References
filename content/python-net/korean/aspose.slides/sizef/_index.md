## SizeF 클래스

부동 소수점 숫자 쌍을 순서대로 저장하며, 일반적으로 사각형의 너비와 높이를 나타냅니다. .NET `System.Drawing.SizeF`와 호환됩니다.

SizeF 형식은 다음 멤버를 제공합니다:

## 생성자

| 생성자 | 설명 |
| :- | :- |
| [`__init__(self, width=0.0, height=0.0)`](/slides/python-net/ko/aspose.slides/sizef/__init__/#float-float) | 지정된 너비와 높이로 크기를 생성합니다. |

## 속성

| 속성 | 설명 |
| :- | :- |
| [`width`](/slides/python-net/ko/aspose.slides/sizef/width/) | 이 크기의 가로 구성 요소를 가져옵니다.<br/>            읽기 전용 **float**. |
| [`height`](/slides/python-net/ko/aspose.slides/sizef/height/) | 이 크기의 세로 구성 요소를 가져옵니다.<br/>            읽기 전용 **float**. |


### 비고

크기는 `==` 연산자로 구성 요소를 비교하며 사전 키나 집합 멤버로 사용할 수 있습니다.
