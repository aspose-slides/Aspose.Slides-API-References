## SlideSizeType 열거형

슬라이드 크기 사전 설정을 나타냅니다.

SlideSizeType 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| ON_SCREEN | 화면 4x3 |
| LETTER_PAPER | 레터 |
| A4_PAPER | A4 |
| SLIDE_35MM | 슬라이드 35mm |
| OVERHEAD | 오버헤드 |
| BANNER | 배너 |
| CUSTOM | 맞춤 크기 |
| LEDGER | 레저 |
| A3_PAPER | A3 |
| B4_ISO_PAPER | B4 ISO |
| B5_ISO_PAPER | B5 ISO |
| B4_JIS_PAPER | B4 JIS |
| B5_JIS_PAPER | B5 JIS |
| HAGAKI_CARD | 하가키 카드 |
| ON_SCREEN_16X9 | 화면 16x9 |
| ON_SCREEN_16X10 | 화면 16x10 |
| WIDESCREEN | 와이드스크린 |
