## CustomXmlPart 클래스

맞춤 XML 파트를 나타냅니다.

CustomXmlPart 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`xml_data`](/slides/python-net/ko/aspose.slides/customxmlpart/xml_data/) | XML 데이터를 반환하거나 설정합니다.<br/>            읽기/쓰기 **int**[].<br/>            값은 `None`입니다.값이 비어 있거나 xml-데이터가 잘못되었습니다. |
| [`xml_as_string`](/slides/python-net/ko/aspose.slides/customxmlpart/xml_as_string/) | XML 데이터를 UTF-8 문자열로 반환하거나 설정합니다.<br/>            읽기/쓰기 **str**.<br/>            값은 `None`입니다.값이 비어 있거나 xml-데이터가 잘못되었습니다. |
| [`item_id`](/slides/python-net/ko/aspose.slides/customxmlpart/item_id/) | Office Open XML 문서 내에서 단일 맞춤 XML 파트를 고유하게 식별하는 전역 고유 식별자(GUID)를 지정합니다.<br/>            읽기 전용 **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/ko/aspose.slides/customxmlpart/namespace_schemas/) | 맞춤 XML 파트와 연결된 컬렉션 XML 스키마를 반환합니다.<br/>            읽기 전용 **str**[]. |
