## external_url_original 속성
Represents a hyperlink that is set for this portion without regard to the actual content of the portion.

            PowerPoint는 부분 내의 링크와 해당 텍스트에 대해 특별히 동작합니다. 유효한 URL 형태의 텍스트를 링크의 실제 주소와 다르게 생성할 수 있습니다. 이 경우 편집 창에서 링크를 볼 때 텍스트 부분에 맞게 변경됩니다. 이 속성은 하이퍼링크의 원래 값을 나타냅니다.
