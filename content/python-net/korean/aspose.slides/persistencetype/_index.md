## PersistenceType 열거형

ActiveX 컨트롤의 속성을 저장하는 데 사용되는 방법을 지정합니다.

PersistenceType 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| NOT_DEFINED | 지속성 ID가 지정되지 않았습니다. |
| PERSIST_PROPERTY_BAG | ActiveX 컨트롤이 속성-백 기반 지속성을 사용하여 저장됨을 지정합니다. <br/>             속성-백 기반 지속성은 이름과 값 쌍의 컬렉션을 통해 ActiveX 컨트롤이 저장하는 데이터를 지정하여 ActiveX 컨트롤을 저장합니다. |
| PERSIST_STREAM | ActiveX 컨트롤이 스트림 기반 지속성을 사용하여 저장됨을 지정합니다. <br/>             이 지속성은 ActiveX 컨트롤을 기본 상태로 초기화하는 것을 지원하지 않습니다. |
| PERSIST_STREAM_INIT | ActiveX 컨트롤이 스트림 기반 지속성을 사용하여 저장됨을 지정합니다. <br/>             이 지속성은 ActiveX 컨트롤을 기본 상태로 초기화하는 것을 지원합니다. |
| PERSIST_STORAGE | ActiveX 컨트롤이 스토리지 기반 지속성을 사용하여 저장됨을 지정합니다. |
