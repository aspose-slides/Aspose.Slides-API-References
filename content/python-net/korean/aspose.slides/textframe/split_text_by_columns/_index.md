## split_text_by_columns(self) {#}
[`ITextFrame`](/slides/python-net/ko/aspose.slides/itextframe)의 텍스트 내용을 문자열 배열로 분할합니다,  
            각 요소는 프레임 내 별도의 텍스트 열에 해당합니다.

### 반환값

문자열 배열이며,  
            각 문자열은 [`ITextFrame`](/slides/python-net/ko/aspose.slides/itextframe)의 특정 열에 대한 텍스트 내용을 나타냅니다.



```python
def split_text_by_columns(self):
    ...
```


### 비고

텍스트 프레임에 여러 열이 포함되지 않으면, 반환된 배열은 전체 텍스트를 포함하는 단일 요소를 가집니다.  
            빈 열은 배열에서 빈 문자열로 표시됩니다.
