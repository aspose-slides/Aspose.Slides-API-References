## Backdrop3DScene 클래스

광원 및 그림자와 같은 효과가 적용되는 평면을 정의하며, 이 평면은 효과가 적용되는 모양과 관련이 있습니다.

**상속:**[`Backdrop3DScene`](/slides/python-net/ko/aspose.slides/backdrop3dscene) → [`PVIObject`](/slides/python-net/ko/aspose.slides/pviobject)

Backdrop3DScene 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`normal_vector`](/slides/python-net/ko/aspose.slides/backdrop3dscene/normal_vector/) | 정규 벡터를 반환하거나 설정합니다. 보다 정확하게 말하면, 이 속성은 백드롭 평면의 면에 수직인 벡터를 정의합니다.<br/>            벡터는 X, Y, Z 좌표를 정의하는 3개의 float 값 배열로 표현됩니다.<br/>            읽기/쓰기 **float**[]. |
| [`anchor_point`](/slides/python-net/ko/aspose.slides/backdrop3dscene/anchor_point/) | 3D 공간의 점을 반환하거나 설정합니다. 이 점은 백드롭 평면을 고정하는 공간상의 점입니다.<br/>            3D 점은 X, Y, Z 좌표를 정의하는 3개의 float 값 배열로 표현됩니다.<br/>            읽기/쓰기 **float**[]. |
| [`up_vector`](/slides/python-net/ko/aspose.slides/backdrop3dscene/up_vector/) | 위쪽을 나타내는 벡터를 반환하거나 설정합니다. 보다 정확하게 말하면, 이 속성은 백드롭 평면의 면에 대한 위쪽을 나타내는 벡터를 정의합니다.<br/>            벡터는 X, Y, Z 좌표를 정의하는 3개의 float 값 배열로 표현됩니다.<br/>            읽기/쓰기 **float**[]. |
