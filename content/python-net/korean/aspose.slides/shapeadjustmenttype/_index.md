## ShapeAdjustmentType 열거형

다양한 종류의 도형 조정 값을 지정합니다.

ShapeAdjustmentType 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| CUSTOM | 사용자 지정 유형(알 수 없는 조정) |
| CORNER_SIZE | 코너의 크기를 제어합니다. |
| LEFT_UP_CORNER | 왼쪽 위 코너를 제어합니다. |
| RIGHT_UP_CORNER | 오른쪽 위 코너를 제어합니다. |
| UP_CORNERS | 상단 코너를 제어합니다. |
| DOWN_CORNERS | 하단 코너를 제어합니다. |
| THICKNESS | 도형의 두께를 제어합니다. |
| ARROW_TAIL_THICKNESS | 화살표 꼬리의 두께를 제어합니다. |
| ARROWHEAD_LENGTH | 화살촉의 길이를 제어합니다. |
| ARROWHEAD_WIDTH | 화살촉의 너비를 제어합니다. |
| RADIUS | 도형 또는 그 부분의 반지름 크기를 제어합니다. |
| DEPTH | 기어 이빨 또는 베벨 효과의 깊이를 제어합니다. |
| SHAPE_PART_OFFSET | 도형의 한 부분을 다른 부분에 대해 오프셋을 제어합니다. |
| ANGLE | 도형 또는 그 부분의 각도를 제어합니다. |
| START_ANGLE | 파이 및 호형 도형의 시작 각도입니다. |
| END_ANGLE | 파이 및 호형 도형의 종료 각도입니다. |
| START_POINT_X | 콜아웃 시작점 X 위치를 제어합니다. |
| START_POINT_Y | 콜아웃 시작점 Y 위치를 제어합니다. |
| CONNECTOR_POINT_1X | 콜아웃 각도 조정점의 수평 위치를 제어합니다. |
| CONNECTOR_POINT_1Y | 콜아웃 각도 조정점의 수직 위치를 제어합니다. |
| CONNECTOR_POINT_2X | 콜아웃 각도 조정점의 수평 위치를 제어합니다. |
| CONNECTOR_POINT_2Y | 콜아웃 각도 조정점의 수직 위치를 제어합니다. |
| CONNECTOR_BEND_POSITION_X | 커넥터 굽힘의 수평 위치를 제어합니다. |
| CONNECTOR_BEND_POSITION_Y | 커넥터 굽힘의 수직 위치를 제어합니다. |
| ATTACH_Y | 도형의 수직 부착점을 제어합니다. |
| ATTACH_X | 도형의 수평 부착점을 제어합니다. |
| CALLOUT_HEIGHT | 콜아웃의 수직 크기를 제어합니다. |
| CALLOUT_WIDTH | 콜아웃의 수평 크기를 제어합니다. |
| CALLOUT_SIZE | 콜아웃의 크기를 제어합니다. |
| CURVATURE | 굽은 형태, 괄호, 곡선 화살표 또는 도형의 곡률입니다. |
| HORIZONTAL_THICKNESS | 코너 형태의 수평 두께를 제어합니다. |
| VERTICAL_THICKNESS | 코너 형태의 수직 두께를 제어합니다. |
| VERTICAL_SIZE | 도형의 수직 크기를 제어합니다. |
| HORIZONTAL_SIZE | 도형의 수평 크기를 제어합니다. |
| TOP | 도형의 상단을 제어합니다. |
