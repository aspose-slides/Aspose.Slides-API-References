## IRow 클래스

테이블의 행을 나타냅니다.

IRow 타입은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`height`](/slides/python-net/ko/aspose.slides/irow/height/) | 행의 높이를 반환합니다.<br/>            읽기 전용 **float**. |
| [`minimal_height`](/slides/python-net/ko/aspose.slides/irow/minimal_height/) | 행의 최소 가능한 높이를 반환하거나 설정합니다.<br/>            읽기/쓰기 **float**. |
| [`row_format`](/slides/python-net/ko/aspose.slides/irow/row_format/) | 이 행에 대한 서식 속성을 포함하는 RowFormat 객체를 반환합니다.<br/>            읽기 전용 [`IRowFormat`](/slides/python-net/ko/aspose.slides/irowformat). |
| [`slide`](/slides/python-net/ko/aspose.slides/irow/slide/) |  |
