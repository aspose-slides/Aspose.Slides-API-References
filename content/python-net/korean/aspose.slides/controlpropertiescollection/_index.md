## ControlPropertiesCollection 클래스

AcitveX 속성의 컬렉션입니다.

ControlPropertiesCollection 타입은 다음 멤버를 공개합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`names_of_properties`](/slides/python-net/ko/aspose.slides/controlpropertiescollection/names_of_properties/) | 속성 이름 컬렉션을 반환합니다.<br/>            읽기 전용 **list**. |
| [`count`](/slides/python-net/ko/aspose.slides/controlpropertiescollection/count/) | 컬렉션의 속성 수를 반환합니다.<br/>            읽기 전용 **int**. |

## 메서드

| 메서드 | 설명 |
| :- | :- |
| [`add(self, name, value)`](/slides/python-net/ko/aspose.slides/controlpropertiescollection/add/#str-str) | 컬렉션에 속성을 추가합니다. |
| [`remove(self, name)`](/slides/python-net/ko/aspose.slides/controlpropertiescollection/remove/#str) | 지정된 이름의 속성을 제거합니다. |
| [`clear(self)`](/slides/python-net/ko/aspose.slides/controlpropertiescollection/clear/#) | 모든 속성을 제거합니다. |
