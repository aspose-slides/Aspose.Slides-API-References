## NumberedBulletStyle 열거형

숫자 글머리표의 스타일을 나타냅니다.

NumberedBulletStyle 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| NOT_DEFINED | 정의되지 않음. |
| BULLET_ALPHA_LC_PERIOD | 마침표가 있는 소문자 알파벳 문자. Sample: a., b., c., ... |
| BULLET_ALPHA_UC_PERIOD | 마침표가 있는 대문자 알파벳 문자. Sample: A., B., C., ... |
| BULLET_ARABIC_PAREN_RIGHT | 닫는 괄호가 있는 아라비아 숫자. Sample: 1), 2), 3), ... |
| BULLET_ARABIC_PERIOD | 마침표가 있는 아라비아 숫자. Sample: 1., 2., 3., ... |
| BULLET_ROMAN_LC_PAREN_BOTH | 양쪽 괄호가 있는 소문자 로마 숫자. Sample: (i), (ii), (iii), ... |
| BULLET_ROMAN_LC_PAREN_RIGHT | 닫는 괄호가 있는 소문자 로마 숫자. Sample: i), ii), iii), ... |
| BULLET_ROMAN_LC_PERIOD | 마침표가 있는 소문자 로마 숫자. Sample: i., ii., iii., ... |
| BULLET_ROMAN_UC_PERIOD | 마침표가 있는 대문자 로마 숫자. Sample: I., II., III., ... |
| BULLET_ALPHA_LC_PAREN_BOTH | 양쪽 괄호가 있는 소문자 알파벳 문자. Sample: (a), (b), (c), ... |
| BULLET_ALPHA_LC_PAREN_RIGHT | 닫는 괄호가 있는 소문자 알파벳 문자. Sample: a), b), c), ... |
| BULLET_ALPHA_UC_PAREN_BOTH | 양쪽 괄호가 있는 대문자 알파벳 문자. Sample: (A), (B), (C), ... |
| BULLET_ALPHA_UC_PAREN_RIGHT | 닫는 괄호가 있는 대문자 알파벳 문자. Sample: A), B), C), ... |
| BULLET_ARABIC_PAREN_BOTH | 양쪽 괄호가 있는 아라비아 숫자. Sample: (1), (2), (3), ... |
| BULLET_ARABIC_PLAIN | 아라비아 숫자. Sample: 1, 2, 3, ... |
| BULLET_ROMAN_UC_PAREN_BOTH | 양쪽 괄호가 있는 대문자 로마 숫자. Sample: (I), (II), (III), ... |
| BULLET_ROMAN_UC_PAREN_RIGHT | 닫는 괄호가 있는 대문자 로마 숫자. Sample: I), II), III), ... |
| BULLET_SIMP_CHIN_PLAIN | 마침표 없는 간체 중국어. |
| BULLET_SIMP_CHIN_PERIOD | 마침표가 있는 간체 중국어. |
| BULLET_CIRCLE_NUM_DB_PLAIN | 10까지의 값을 위한 더블바이트 원형 번호이며, 11부터는 아라비아 숫자입니다. |
| BULLET_CIRCLE_NUM_WD_WHITE_PLAIN | 텍스트 색상과 동일한 색상의 원이 둘러진 숫자 (Wingdings 흰색 원 번호). 11부터는 아라비아 숫자. |
| BULLET_CIRCLE_NUM_WD_BLACK_PLAIN | 일반 텍스트 색상의 원형 배경이 있는 그림자 색상 숫자 (Wingdings 검은 원 번호). |
| BULLET_TRAD_CHIN_PLAIN | 마침표 없는 전통 중국어. |
| BULLET_TRAD_CHIN_PERIOD | 마침표가 있는 전통 중국어. |
| BULLET_ARABIC_ALPHA_DASH | 대시가 있는 아랍어 알파벳 문자. |
| BULLET_ARABIC_ABJAD_DASH | 대시가 있는 아랍어 아브자드 알파벳. |
| BULLET_HEBREW_ALPHA_DASH | 대시가 있는 히브리어 알파벳 문자. |
| BULLET_KANJI_KOREAN_PLAIN | 마침표 없는 일본어/한국어 숫자. |
| BULLET_KANJI_KOREAN_PERIOD | 마침표가 있는 일본어/한국어 숫자. |
| BULLET_ARABIC_DB_PLAIN | 구두점 없는 더블바이트 아라비아 번호 체계. |
| BULLET_ARABIC_DB_PERIOD | 더블바이트 마침표가 있는 더블바이트 아라비아 번호 체계. |
| BULLET_THAI_ALPHA_PERIOD | 태국어 알파벳 마침표. |
| BULLET_THAI_ALPHA_PAREN_RIGHT | 태국어 알파벳 닫는 괄호. |
| BULLET_THAI_ALPHA_PAREN_BOTH | 태국어 알파벳 양쪽 괄호. |
| BULLET_THAI_NUM_PERIOD | 태국어 숫자 마침표. |
| BULLET_THAI_NUM_PAREN_RIGHT | 태국어 숫자 닫는 괄호. |
| BULLET_THAI_NUM_PAREN_BOTH | 태국어 숫자 양쪽 괄호. |
| BULLET_HINDI_ALPHA_PERIOD | 힌디어 모음에 대한 알파벳 마침표. |
| BULLET_HINDI_NUM_PERIOD | 힌디어 숫자 마침표. |
| BULLET_KANJI_SIMP_CHIN_DB_PERIOD | Kanji 간체 중국어 DBPeriod. |
| BULLET_HINDI_NUM_PAREN_RIGHT | 힌디어 숫자 닫는 괄호. |
| BULLET_HINDI_ALPHA_1_PERIOD | 힌디어 자음에 대한 알파벳 마침표. |
