## IInterruptionToken 클래스

이 클래스는 장기 실행 작업에 중단 요청이 있었는지 신호를 보내는 토큰을 나타냅니다.

IInterruptionToken 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`is_interruption_requested`](/slides/python-net/ko/aspose.slides/iinterruptiontoken/is_interruption_requested/) | 중단이 요청된 경우 **bool**.true 를 반환합니다. |

## 메서드

| 메서드 | 설명 |
| :- | :- |
