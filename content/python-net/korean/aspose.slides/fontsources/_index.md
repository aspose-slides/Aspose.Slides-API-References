## FontSources 클래스

외부 글꼴에 대한 파일 및 메모리 소스를 제공합니다.

FontSources 형식은 다음 멤버를 노출합니다:

## 생성자

| 생성자 | 설명 |
| :- | :- |
| [`__init__(self)`](/slides/python-net/ko/aspose.slides/fontsources/__init__/#) | 새 기본 글꼴 옵션을 생성합니다. |

## 속성

| 속성 | 설명 |
| :- | :- |
| [`font_folders`](/slides/python-net/ko/aspose.slides/fontsources/font_folders/) | 글꼴 파일이 들어있는 폴더.<br/>            이 폴더에 위치한 모든 글꼴 파일이 컬렉션에 포함됩니다. 재귀적으로 검색되는 폴더입니다. |
| [`memory_fonts`](/slides/python-net/ko/aspose.slides/fontsources/memory_fonts/) | 바이트 배열로 표현된 글꼴 컬렉션입니다. |
