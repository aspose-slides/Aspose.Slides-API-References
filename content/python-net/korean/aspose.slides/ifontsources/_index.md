## IFontSources 클래스

외부 글꼴에 대한 파일 및 메모리 소스를 제공합니다.

IFontSources 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`font_folders`](/slides/python-net/ko/aspose.slides/ifontsources/font_folders/) | 글꼴 파일이 포함된 폴더.<br/>이 폴더에 위치한 모든 글꼴 파일이 컬렉션에 포함됩니다. 재귀적으로 검색되는 폴더. |
| [`memory_fonts`](/slides/python-net/ko/aspose.slides/ifontsources/memory_fonts/) | 바이트 배열로 표현된 글꼴 컬렉션. |
