## ResourceLoadingAction 열거형

외부 리소스 로드 모드를 지정합니다.

ResourceLoadingAction 유형은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| DEFAULT | Aspose.Slides는 외부 리소스를 정상적으로 로드합니다. |
| SKIP | Aspose.Slides는 외부 리소스 로드를 건너뜁니다. 데이터가 없는 링크만 이미지에 대해 저장됩니다. |
| USER_PROVIDED | Aspose.Slides는 사용자에 의해 제공된 바이트 배열을 이미지 데이터로 **Aspose.Slides.IResourceLoadingArgs.SetData(Syste** 에서 사용합니다. |
