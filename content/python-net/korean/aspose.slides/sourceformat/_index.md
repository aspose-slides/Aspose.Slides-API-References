## SourceFormat 열거형

소스 파일 형식을 나타냅니다.

SourceFormat 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| PPT | Microsoft PowerPoint 97-2003 프레젠테이션 (*.ppt). |
| PPTX | Microsoft Office Open XML 프레젠테이션 (*.pptx). |
| ODP | OpenDocument 프레젠테이션 (*.odp). |
| PPTM | Microsoft Office Open XML 매크로 사용 프레젠테이션 (*.pptm). |
| PPSX | Microsoft Office Open XML 슬라이드쇼 (*.ppsx). |
| PPSM | Microsoft Office Open XML 매크로 사용 슬라이드쇼 (*.ppsm). |
| POTX | Microsoft Office Open XML 템플릿 (*.potx). |
| POTM | Microsoft Office Open XML 매크로 사용 템플릿 (*.potm). |
| PPS | Microsoft PowerPoint 97-2003 슬라이드쇼 (*.pps). |
| POT | Microsoft PowerPoint 97-2003 템플릿 (*.pot). |
| OTP | OpenDocument 프레젠테이션 템플릿 (*.otp). |
| FODP | Flat XML ODF 프레젠테이션 (*.fodp). |
| XML | PowerPoint XML 프레젠테이션 (*.xml). |
