## ILineFillFormatEffectiveData 클래스

유효한 선 채우기 속성을 포함하는 불변 객체입니다.

ILineFillFormatEffectiveData 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`fill_type`](/slides/python-net/ko/aspose.slides/ilinefillformateffectivedata/fill_type/) | 채우기 유형을 반환합니다.<br/>            읽기 전용 [`FillType`](/slides/python-net/ko/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/ko/aspose.slides/ilinefillformateffectivedata/solid_fill_color/) | 단색 채우기의 색상을 반환합니다.<br/>            읽기 전용 [`Color`](/slides/python-net/ko/aspose.slides/color). |
| [`gradient_format`](/slides/python-net/ko/aspose.slides/ilinefillformateffectivedata/gradient_format/) | 그라디언트 채우기 형식을 반환합니다.<br/>            읽기 전용 [`IGradientFormatEffectiveData`](/slides/python-net/ko/aspose.slides/igradientformateffectivedata). |
| [`pattern_format`](/slides/python-net/ko/aspose.slides/ilinefillformateffectivedata/pattern_format/) | 패턴 채우기 형식을 반환합니다.<br/>            읽기 전용 [`IPatternFormatEffectiveData`](/slides/python-net/ko/aspose.slides/ipatternformateffectivedata). |
| [`rotate_with_shape`](/slides/python-net/ko/aspose.slides/ilinefillformateffectivedata/rotate_with_shape/) | 채우기가 도형과 함께 회전해야 하는지 여부를 결정합니다.<br/>            읽기 전용 **bool**. |
