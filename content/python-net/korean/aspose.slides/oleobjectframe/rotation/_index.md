## 회전 속성
지정된 도형이 z축을 중심으로 회전하는 각도의 수를 반환하거나 설정합니다. 양수 값은 시계 방향 회전을 나타내고, 음수 값은 반시계 방향 회전을 나타냅니다. 읽기/쓰기 **float**.

### 비고

반환값은 항상 정의됩니다 (float.NaN이 아님). 할당값은 정의되어야 합니다 (float.NaN이 아님). RawFrame 인스턴스 속성에 대해 정의되지 않은 값을 설정할 수 있습니다.

@property
def rotation(self):
    ...

    ...
