## 프레임 속성
모양 프레임의 속성을 반환하거나 설정합니다.
            읽기/쓰기 [`IShapeFrame`](/slides/python-net/ko/aspose.slides/ishapeframe).


### 비고

반환된 IShapeFrame 인스턴스의 각 속성 값은 
            undefined가 아닙니다 (is not NaN or NotDefined).
            할당된 IShapeFrame 인스턴스의 각 속성 값은 
            undefined가 아니어야 합니다 (must be not NaN or NotDefined).
            RawFrame 인스턴스 속성에 undefined 값을 설정할 수 있습니다.

### 정의:
```python
@property
def frame(self):
    ...

@frame.setter
def frame(self, value):
    ...
```
