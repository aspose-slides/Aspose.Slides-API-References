## ILightRigEffectiveData 클래스

효과적인 라이트 릭 속성을 포함하는 불변 객체입니다.

ILightRigEffectiveData 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`direction`](/slides/python-net/ko/aspose.slides/ilightrigeffectivedata/direction/) | 광선 방향.<br/>            읽기 전용 [`LightingDirection`](/slides/python-net/ko/aspose.slides/lightingdirection). |
| [`light_type`](/slides/python-net/ko/aspose.slides/ilightrigeffectivedata/light_type/) | 형태에 적용할 수 있는 사전 설정 라이트 오른쪽을 나타냅니다.<br/>            라이트 릭은 3D 씬에 대해 특정 방식으로 배치된 조명 그룹을 나타냅니다.<br/>            읽기 전용 [`LightRigPresetType`](/slides/python-net/ko/aspose.slides/lightrigpresettype). |

## 메서드

| 메서드 | 설명 |
| :- | :- |
| [`get_rotation(self)`](/slides/python-net/ko/aspose.slides/ilightrigeffectivedata/get_rotation/#) | 위도 좌표, 경도 좌표 및 위도와 경도 좌표로 축을 중심으로 하는 회전을 사용하여 회전을 정의합니다.<br/>            반환 배열의 첫 번째 요소 - 위도, 두 번째 - 경도, 세 번째 - 회전. |

### 비고
