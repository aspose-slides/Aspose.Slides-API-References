## Row 클래스

테이블의 행을 나타냅니다.

**상속:**[`Row`](/slides/python-net/ko/aspose.slides/row) → [`CellCollection`](/slides/python-net/ko/aspose.slides/cellcollection)

Row 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`slide`](/slides/python-net/ko/aspose.slides/row/slide/) | CellCollection의 상위 슬라이드를 반환합니다.<br/>            읽기 전용 [`IBaseSlide`](/slides/python-net/ko/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/ko/aspose.slides/row/presentation/) | CellCollection의 상위 프레젠테이션을 반환합니다.<br/>            읽기 전용 [`IPresentation`](/slides/python-net/ko/aspose.slides/ipresentation). |
| [`height`](/slides/python-net/ko/aspose.slides/row/height/) | 행의 높이를 반환합니다.<br/>            읽기 전용 **float**. |
| [`minimal_height`](/slides/python-net/ko/aspose.slides/row/minimal_height/) | 행의 최소 가능한 높이를 반환하거나 설정합니다.<br/>            읽기/쓰기 **float**. |
| [`row_format`](/slides/python-net/ko/aspose.slides/row/row_format/) | 이 행에 대한 서식 속성을 포함하는 RowFormat 객체를 반환합니다.<br/>            읽기 전용 [`IRowFormat`](/slides/python-net/ko/aspose.slides/irowformat). |
