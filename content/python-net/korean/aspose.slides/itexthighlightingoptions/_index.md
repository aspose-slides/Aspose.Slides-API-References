## ITextHighlightingOptions 클래스

텍스트 프레임에서 텍스트를 강조 표시하는 데 사용할 수 있는 옵션을 나타냅니다.

ITextHighlightingOptions 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`case_sensitive`](/slides/python-net/ko/aspose.slides/itexthighlightingoptions/case_sensitive/) | 대소문자를 구분하는 검색을 사용하려면 true를 설정하고, 그렇지 않으면 false를 설정합니다.<br/>            읽기/쓰기 **bool**. |
| [`whole_words_only`](/slides/python-net/ko/aspose.slides/itexthighlightingoptions/whole_words_only/) | 전체 단어만 일치시키려면 true를 설정하고, 그렇지 않으면 false를 설정합니다.<br/>            읽기/쓰기 **bool**. |
