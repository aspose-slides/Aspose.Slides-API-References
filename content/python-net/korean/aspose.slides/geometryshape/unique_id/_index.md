## unique_id 속성
내부의 프레젠테이션 범위 식별자를 반환하며, 이는 추가 기능이나 다른 코드에서 사용하도록 설계되었습니다.
            이 값은 사용자에 의해 또는 프로그래밍 방식으로 재할당될 수 있으므로 지속적인 고유 키로 간주해서는 안 됩니다.
            읽기 전용 **int**.
