## IAdjustValue 클래스

형상(geometry shape)의 조정 값을 나타냅니다.
            이러한 값은 형상의 형태에 영향을 줍니다.

IAdjustValue 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`raw_value`](/slides/python-net/ko/aspose.slides/iadjustvalue/raw_value/) | 조정 값을 있는 그대로 반환하거나 설정합니다.<br/>            읽기/쓰기 **int**. |
| [`angle_value`](/slides/python-net/ko/aspose.slides/iadjustvalue/angle_value/) | 값을 반환하거나 설정하고, 각도를 도 단위로 해석합니다.<br/>            읽기/쓰기 **float**. |
| [`name`](/slides/python-net/ko/aspose.slides/iadjustvalue/name/) | 이 조정 값의 이름을 반환합니다.<br/>            읽기 전용 **str**. |
| [`type`](/slides/python-net/ko/aspose.slides/iadjustvalue/type/) | 형상 조정의 유형을 반환합니다.<br/>            읽기 전용 [`ShapeAdjustmentType`](/slides/python-net/ko/aspose.slides/shapeadjustmenttype). |
