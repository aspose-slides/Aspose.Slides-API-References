## PlaceholderType 열거형

플레이스홀더의 유형을 나타냅니다.

PlaceholderType 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| TITLE | 제목. |
| BODY | 본문. |
| CENTERED_TITLE | 가운데 정렬된 제목. |
| SUBTITLE | 부제목. |
| DATE_AND_TIME | 날짜 및 시간. |
| SLIDE_NUMBER | 슬라이드 번호. |
| FOOTER | 바닥글. |
| HEADER | 머리글. |
| OBJECT | 개체. |
| CHART | 차트. |
| TABLE | 표. |
| CLIP_ART | 클립 아트. |
| DIAGRAM | 다이어그램. |
| MEDIA | 미디어. |
| SLIDE_IMAGE | 슬라이드 이미지. |
| PICTURE | 그림. |
