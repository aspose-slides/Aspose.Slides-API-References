## HyperlinkQueries 클래스

포함된 하이퍼링크에 대한 쉬운 액세스를 제공합니다.

HyperlinkQueries 형식은 다음 멤버를 노출합니다:

## 메서드

| 메서드 | 설명 |
| :- | :- |
| [`get_hyperlink_clicks(self)`](/slides/python-net/ko/aspose.slides/hyperlinkqueries/get_hyperlink_clicks/#) | 모든 IHyperlinkContainer 하위 객체 중 HyperlinkClick이 None이 아닌 것을 가져옵니다.<br/> 주어진 IHyperlinkContainer 객체를 사용하여 해당 하이퍼링크를 관리할 수 있습니다 (읽기, 업데이트 또는 삭제). IHyperlinkContainer 인터페이스를 참조하십시오. |
| [`get_hyperlink_mouse_overs(self)`](/slides/python-net/ko/aspose.slides/hyperlinkqueries/get_hyperlink_mouse_overs/#) | 모든 IHyperlinkContainer 하위 객체 중 HyperlinkMouseOver가 None이 아닌 것을 가져옵니다.<br/> 주어진 IHyperlinkContainer 객체를 사용하여 해당 하이퍼링크를 관리할 수 있습니다 (읽기, 업데이트 또는 삭제). IHyperlinkContainer 인터페이스를 참조하십시오. |
| [`get_any_hyperlinks(self)`](/slides/python-net/ko/aspose.slides/hyperlinkqueries/get_any_hyperlinks/#) | 모든 IHyperlinkContainer 하위 객체 중 HyperlinkMouseOver가 None이 아닌 것을 가져옵니다.<br/> 주어진 IHyperlinkContainer 객체를 사용하여 해당 하이퍼링크를 관리할 수 있습니다 (읽기, 업데이트 또는 삭제). IHyperlinkContainer 인터페이스를 참조하십시오. |
| [`remove_all_hyperlinks(self)`](/slides/python-net/ko/aspose.slides/hyperlinkqueries/remove_all_hyperlinks/#) | 모든 포함된 HyperlinkClick 및 HyperlinkMouseOver 하이퍼링크를 제거합니다 (모든 IHyperlinkContainer 하위 객체에서). |
