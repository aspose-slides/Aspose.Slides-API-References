## __init__(self, r=0, g=0, b=0, a=255) {#int-int-int-int}
지정된 빨강, 초록, 파랑 및 알파 구성 요소 값을 사용하여 색상을 생성합니다.

```python
def __init__(self, r=0, g=0, b=0, a=255):
    ...
```


| 매개변수 | 유형 | 설명 |
| :- | :- | :- |
| r | **int** | 빨간색 구성 요소 값. 유효한 값은 0부터 255까지입니다. |
| g | **int** | 초록색 구성 요소 값. 유효한 값은 0부터 255까지입니다. |
| b | **int** | 파란색 구성 요소 값. 유효한 값은 0부터 255까지입니다. |
| a | **int** | 알파 구성 요소 값. 유효한 값은 0부터 255까지입니다. |

### 예외

| 예외 | 설명 |
| :- | :- |
| **ValueError** | 구성 요소 값이 0보다 작거나 255보다 큽니다. |
| **TypeError** | 구성 요소 값이 숫자가 아닙니다. |
