## is_system_color 속성
이 색상이 시스템 색상인지 지정합니다: Windows 표시 요소에 사용되는 색상으로, `Control` 또는 `ActiveBorder`와 같은 색상입니다.<br/>            시스템 색상은 `Color` 속성으로 노출되지 않으며 [`from_known_color`](/slides/python-net/ko/aspose.slides/color/from_known_color/) 로만 가져오거나 라이브러리에서 반환될 수 있습니다.
            읽기 전용 **bool**.
