## 프레임 속성

            읽기/쓰기 [`IShapeFrame`](/slides/python-net/ko/aspose.slides/ishapeframe).

### 비고
반환된 IShapeFrame 인스턴스의 각 속성 값은 
            undefined가 아닙니다 (NaN 또는 NotDefined가 아님).
할당된 IShapeFrame 인스턴스의 각 속성 값은 
            undefined가 아니어야 합니다 (NaN 또는 NotDefined가 아니어야 합니다).
RawFrame 인스턴스 속성에 대해 undefined 값을 설정할 수 있습니다.
