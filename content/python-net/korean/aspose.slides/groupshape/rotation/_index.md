## rotation 속성
지정된 도형이 z축을 중심으로 회전하는 각도(도)를 반환하거나 설정합니다. 양수 값은 시계 방향 회전을 나타내며, 음수 값은 반시계 방향 회전을 나타냅니다.
읽기/쓰기 **float**.

### 비고
반환값은 항상 정의되어 있습니다 (float.NaN이 아닙니다). 할당된 값은 정의되어 있어야 합니다 (float.NaN이 아닙니다). RawFrame 인스턴스 속성에 대해 정의되지 않은 값을 설정할 수 있습니다.

### 정의:
```python
@property
def rotation(self):
    ...

@rotation.setter
def rotation(self, value):
    ...
```
