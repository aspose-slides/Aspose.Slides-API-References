## IOleEmbeddedDataInfo 클래스

임베디드 OLE 객체에 대한 데이터 정보를 나타냅니다.

IOleEmbeddedDataInfo 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`embedded_file_data`](/slides/python-net/ko/aspose.slides/ioleembeddeddatainfo/embedded_file_data/) | 임베디드 OLE 객체의 파일 데이터를 반환합니다<br/>            읽기 전용 **int**[]. |
| [`embedded_file_extension`](/slides/python-net/ko/aspose.slides/ioleembeddeddatainfo/embedded_file_extension/) | 현재 임베디드 OLE 객체의 파일 확장자를 반환합니다<br/>            읽기 전용 **str**. |
