## ViewProperties 클래스

프레젠테이션 전체 보기 속성.

ViewProperties 타입은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`last_view`](/slides/python-net/ko/aspose.slides/viewproperties/last_view/) | 프레젠테이션 문서를 마지막으로 저장할 때 사용된 보기 모드를 지정합니다.<br/>            읽기/쓰기 [`ViewType`](/slides/python-net/ko/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/ko/aspose.slides/viewproperties/show_comments/) | 슬라이드 주석을 표시할지 여부를 지정합니다.<br/>            읽기/쓰기 [`NullableBool`](/slides/python-net/ko/aspose.slides/nullablebool). |
| [`normal_view_properties`](/slides/python-net/ko/aspose.slides/viewproperties/normal_view_properties/) | 일반 보기 속성을 나타냅니다. 일반 보기는<br/>            세 개의 콘텐츠 영역으로 구성됩니다: 슬라이드 자체, 측면 콘텐츠 영역, 및 하단 콘텐츠 영역.<br/>            읽기 전용 [`INormalViewProperties`](/slides/python-net/ko/aspose.slides/inormalviewproperties). |
| [`slide_view_properties`](/slides/python-net/ko/aspose.slides/viewproperties/slide_view_properties/) | 슬라이드 보기 모드와 연관된 공통 보기 속성을 지정합니다.<br/>            읽기 전용 [`ICommonSlideViewProperties`](/slides/python-net/ko/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/ko/aspose.slides/viewproperties/notes_view_properties/) | 노트 보기 모드와 연관된 공통 보기 속성을 지정합니다.<br/>            읽기 전용 [`ICommonSlideViewProperties`](/slides/python-net/ko/aspose.slides/icommonslideviewproperties). |
| [`grid_spacing`](/slides/python-net/ko/aspose.slides/viewproperties/grid_spacing/) | 프레젠테이션 문서 하단에 있는 그리드에 사용될 그리드 간격을 포인트 단위로 반환하거나 설정합니다. <br/>            읽기/쓰기 **float**. |
