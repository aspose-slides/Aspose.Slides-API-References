## Point 클래스

2차원 평면에서 점을 정의하는 정수 x좌표와 y좌표의 순서쌍을 나타냅니다. .NET `System.Drawing.Point`와 호환됩니다.

Point 타입은 다음 멤버를 제공합니다:

## 생성자

| 생성자 | 설명 |
| :- | :- |
| [`__init__(self, x=0, y=0)`](/slides/python-net/ko/aspose.slides/point/__init__/#int-int) | 지정된 좌표로 점을 생성합니다. 부동 소수점 값은 정수로 잘립니다. |

## 속성

| 속성 | 설명 |
| :- | :- |
| [`x`](/slides/python-net/ko/aspose.slides/point/x/) | 이 점의 x좌표를 가져오거나 설정합니다.<br/>            읽기/쓰기 **int**. |
| [`y`](/slides/python-net/ko/aspose.slides/point/y/) | 이 점의 y좌표를 가져오거나 설정합니다.<br/>            읽기/쓰기 **int**. |


### 비고

점은 좌표를 `==` 연산자로 비교하며, 사전 키 또는 집합 멤버로 사용할 수 있습니다.
