## ILayoutPlaceholderManager 클래스

레이아웃 슬라이드에 자리 표시자를 추가할 수 있게 하는 관리자를 나타냅니다.

ILayoutPlaceholderManager 형식은 다음 멤버를 노출합니다:

## 메서드

| 메서드 | 설명 |
| :- | :- |
| [`add_content_placeholder(self, x, y, width, height)`](/slides/python-net/ko/aspose.slides/ilayoutplaceholdermanager/add_content_placeholder/#float-float-float-float) | 레이아웃 슬라이드에 그림, 표, 미디어 또는 텍스트와 같은 콘텐츠를 보관할 새 자리 표시자 모양을 추가합니다. |
| [`add_vertical_content_placeholder(self, x, y, width, height)`](/slides/python-net/ko/aspose.slides/ilayoutplaceholdermanager/add_vertical_content_placeholder/#float-float-float-float) | 레이아웃 슬라이드에 그림, 표, 미디어 <br/>            또는 세로 방향의 텍스트와 같은 콘텐츠를 보관할 새 자리 표시자 모양을 추가합니다. |
| [`add_text_placeholder(self, x, y, width, height)`](/slides/python-net/ko/aspose.slides/ilayoutplaceholdermanager/add_text_placeholder/#float-float-float-float) | 레이아웃 슬라이드에 텍스트 콘텐츠를 보관할 새 자리 표시자 모양을 추가합니다. |
