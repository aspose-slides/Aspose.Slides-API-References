## x 속성
도형의 왼쪽 위 모서리의 x 좌표를 가져오거나 설정합니다. 단위는 포인트입니다.
            읽기/쓰기 **float**.


### 비고

반환된 값은 항상 정의되어 있으며 절대 **float**가 아닙니다.
            할당된 값도 정의되어야 합니다; `RawFrame` 인스턴스의 속성에만 **float**을 할당하십시오.

### 정의:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
