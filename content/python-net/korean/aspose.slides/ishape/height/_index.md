## height 속성
shape의 height을 가져오거나 설정합니다. 포인트 단위로 측정됩니다.
            읽기/쓰기 **float**.


### 비고

반환된 값은 항상 정의되어 있으며 절대 **float**가 아닙니다.
            할당되는 값도 정의되어 있어야 합니다; `RawFrame` 인스턴스의 속성에만 **float**를 할당하십시오.
