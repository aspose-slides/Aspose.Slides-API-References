## remove(self, item) {#iparagraph}
특정 개체를 **System.Collections.Generic.ICollection`1**에서 첫 번째로 발생하는 것을 제거합니다.

### 반환값

`item`이 **System.Collections.Generic.ICollection`1**에서 성공적으로 제거되면 true; 그렇지 않으면 false. 이 메서드는 원래 **System.Collections.Generic.ICollection`1**에 `item`이 없을 경우에도 false를 반환합니다.

```python
def remove(self, item):
    ...
```
