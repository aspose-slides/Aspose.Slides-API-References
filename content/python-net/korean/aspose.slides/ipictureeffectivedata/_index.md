## IPictureEffectiveData 클래스

효과적인 그림 속성을 포함하는 불변 객체입니다.

IPictureEffectiveData 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`image`](/slides/python-net/ko/aspose.slides/ipictureeffectivedata/image/) | 임베드된 이미지를 반환합니다.<br/>            읽기 전용 [`IPPImage`](/slides/python-net/ko/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/ko/aspose.slides/ipictureeffectivedata/link_path_long/) | 링크된 이미지의 URL을 반환합니다.<br/>            읽기 전용 **str**. |
| [`image_transform`](/slides/python-net/ko/aspose.slides/ipictureeffectivedata/image_transform/) | 이미지 변환 효과 컬렉션을 반환합니다.<br/>            읽기 전용 [`IImageTransformOCollectionEffectiveData`](/slides/python-net/ko/aspose.slides.effects/iimagetransformocollectioneffectivedata). |


### 주석

이 인터페이스는 [`IPictureFillFormatEffectiveData`](/slides/python-net/ko/aspose.slides/ipicturefillformateffectivedata) 및 [`IBulletFormatEffectiveData`](/slides/python-net/ko/aspose.slides/ibulletformateffectivedata)의 일부로 사용됩니다.
