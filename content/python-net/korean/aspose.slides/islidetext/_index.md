## ISlideText 클래스

슬라이드에서 추출한 텍스트를 나타냅니다.

ISlideText 타입은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`text`](/slides/python-net/ko/aspose.slides/islidetext/text/) | 슬라이드의 도형에 있는 텍스트 |
| [`master_text`](/slides/python-net/ko/aspose.slides/islidetext/master_text/) | 이 슬라이드에 대한 마스터 페이지 도형의 텍스트 |
| [`layout_text`](/slides/python-net/ko/aspose.slides/islidetext/layout_text/) | 이 슬라이드에 대한 레이아웃 페이지 도형의 텍스트 |
| [`notes_text`](/slides/python-net/ko/aspose.slides/islidetext/notes_text/) | 이 슬라이드에 대한 노트 페이지 도형의 텍스트 |
| [`comments_text`](/slides/python-net/ko/aspose.slides/islidetext/comments_text/) | 슬라이드 주석의 텍스트 |
