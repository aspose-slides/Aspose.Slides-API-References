## IGradientStop 클래스

그라디언트 형식을 나타냅니다.

IGradientStop 타입은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`position`](/slides/python-net/ko/aspose.slides/igradientstop/position/) | 그라디언트 정지점의 위치(0..1)를 반환하거나 설정합니다.<br/>            읽기/쓰기 **float**. |
| [`color`](/slides/python-net/ko/aspose.slides/igradientstop/color/) | 그라디언트 정지점의 색을 반환합니다.<br/>            읽기 전용 [`IColorFormat`](/slides/python-net/ko/aspose.slides/icolorformat). |
