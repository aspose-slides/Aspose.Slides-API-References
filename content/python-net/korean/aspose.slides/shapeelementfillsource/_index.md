## ShapeElementFillSource 열거형

Shape 요소를 어떻게 채워야 하는지를 나타냅니다.

ShapeElementFillSource 유형은 다음 멤버를 제공합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| NO_FILL | 프리미티브를 채우지 않음. |
| SHAPE | 도형의 채우기를 사용합니다. |
| LIGHTEN | 도형의 채우기를 밝게 합니다. |
| LIGHTEN_LESS | 도형의 채우기를 덜 밝게 합니다. |
| DARKEN | 도형의 채우기를 어둡게 합니다. |
| DARKEN_LESS | 도형의 채우기를 덜 어둡게 합니다. |
