## HyperlinkActionType 열거형

Represents a type of hyperlink action.

The HyperlinkActionType type exposes the following members:

## 필드

| 필드 | 설명 |
| :- | :- |
| UNKNOWN | 인식되지 않은 동작 유형. |
| NO_ACTION | 동작 없음. |
| HYPERLINK | 일반 하이퍼링크. |
| JUMP_FIRST_SLIDE | 프레젠테이션의 첫 번째 슬라이드로 이동합니다. |
| JUMP_PREVIOUS_SLIDE | 이전 슬라이드로 이동합니다. |
| JUMP_NEXT_SLIDE | 다음 슬라이드로 이동합니다. |
| JUMP_LAST_SLIDE | 프레젠테이션의 마지막 슬라이드로 이동합니다. |
| JUMP_END_SHOW | 슬라이드쇼의 끝으로 이동합니다. |
| JUMP_LAST_VIEWED_SLIDE | 마지막으로 본 슬라이드로 이동합니다. |
| JUMP_SPECIFIC_SLIDE | 특정 슬라이드로 이동합니다, [`IHyperlink.target_slide`](/slides/python-net/ko/aspose.slides/ihyperlink/target_slide) 속성에 의해 지정됩니다. |
| START_CUSTOM_SLIDE_SHOW | 사용자 지정 슬라이드쇼를 시작합니다. |
| OPEN_FILE | 참조된 파일을 엽니다. |
| OPEN_PRESENTATION | 참조된 프레젠테이션을 엽니다. |
| START_STOP_MEDIA | 미디어 파일 재생을 시작/중지합니다. |
| START_MACRO | 매크로 스크립트 실행을 시작합니다. |
| START_PROGRAM | 프로그램을 시작합니다. |
