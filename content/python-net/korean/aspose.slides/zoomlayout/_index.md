## ZoomLayout 열거형

요약 줌 레이아웃을 지정합니다.

ZoomLayout 유형은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| GRID_LAYOUT | 객체 목록에 대한 그리드 레이아웃으로 레이아웃을 지정합니다. |
| FIXED_LAYOUT | 사용자 정의 Zoom 위치 지정으로 레이아웃을 지정합니다. |
