## IPPImage 클래스

프레젠테이션에서 이미지를 나타냅니다.

IPPImage 타입은 다음 멤버를 제공합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`binary_data`](/slides/python-net/ko/aspose.slides/ippimage/binary_data/) | 이미지 데이터의 복사본을 반환합니다.<br/>            읽기 전용 **int**[]. |
| [`image`](/slides/python-net/ko/aspose.slides/ippimage/image/) | 이미지의 복사본을 반환합니다.<br/>            읽기 전용 [`IPPImage.image`](/slides/python-net/ko/aspose.slides/ippimage/image). |
| [`svg_image`](/slides/python-net/ko/aspose.slides/ippimage/svg_image/) | ISvgImage 객체 [`ISvgImage`](/slides/python-net/ko/aspose.slides/isvgimage)를 반환하거나 설정합니다 |
| [`content_type`](/slides/python-net/ko/aspose.slides/ippimage/content_type/) | 이미지의 MIME 유형을 [`IPPImage.binary_data`](/slides/python-net/ko/aspose.slides/ippimage/binary_data)로 인코딩하여 반환합니다.<br/>            읽기 전용 **str**. |
| [`width`](/slides/python-net/ko/aspose.slides/ippimage/width/) | 이미지의 너비를 반환합니다.<br/>            읽기 전용 **int**. |
| [`height`](/slides/python-net/ko/aspose.slides/ippimage/height/) | 이미지의 높이를 반환합니다.<br/>            읽기 전용 **int**. |
| [`x`](/slides/python-net/ko/aspose.slides/ippimage/x/) | 이미지의 X 오프셋을 반환합니다.<br/>            읽기 전용 **int**. |
| [`y`](/slides/python-net/ko/aspose.slides/ippimage/y/) | 이미지의 Y 오프셋을 반환합니다.<br/>            읽기 전용 **int**. |
