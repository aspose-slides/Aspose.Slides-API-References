## ITab 클래스

텍스트에 대한 탭을 나타냅니다.

ITab 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`position`](/slides/python-net/ko/aspose.slides/itab/position/) | 탭의 위치를 반환하거나 설정합니다.<br/>            이 속성을 할당하면 컬렉션에서 탭의 인덱스가 변경되고 Enumerator가 무효화될 수 있습니다.<br/>            읽기/쓰기 **float**. |
| [`alignment`](/slides/python-net/ko/aspose.slides/itab/alignment/) | 탭의 정렬 스타일을 반환하거나 설정합니다.<br/>            읽기/쓰기 [`TabAlignment`](/slides/python-net/ko/aspose.slides/tabalignment). |
