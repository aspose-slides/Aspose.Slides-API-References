## PathCommandType 열거형

그래픽 경로 명령을 나타냅니다

PathCommandType 유형은 다음 멤버를 제공합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| CLOSE | 지오메트리 경로를 닫습니다 |
| MOVE_TO | 지오메트리 경로의 다음 점 위치를 설정합니다 |
| LINE_TO | 지오메트리 경로에 선을 추가합니다 |
| ARC_TO | 지정된 호를 지오메트리 경로에 추가합니다. |
| QUAD_BEZIER_TO | 지오메트리 경로에 2차 베지어 곡선을 추가합니다 |
| CUBIC_BEZIER_TO | 지오메트리 경로에 3차 베지어 곡선을 추가합니다 |
