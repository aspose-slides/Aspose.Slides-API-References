## BuildVersionInfo 클래스

Aspose.Slides 버전에 대한 정보를 포함합니다.

BuildVersionInfo 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`ASSEMBLY_VERSION`](/slides/python-net/ko/aspose.slides/buildversioninfo/assembly_version/) | Aspose.Slides 어셈블리의 버전. |
| [`FILE_VERSION`](/slides/python-net/ko/aspose.slides/buildversioninfo/file_version/) | 어셈블리 파일의 버전. |
| [`PRODUCT`](/slides/python-net/ko/aspose.slides/buildversioninfo/product/) | Aspose.Slides의 제품 이름 |
| [`PRODUCT_MAJOR`](/slides/python-net/ko/aspose.slides/buildversioninfo/product_major/) | 주 버전 번호. |
| [`PRODUCT_MINOR`](/slides/python-net/ko/aspose.slides/buildversioninfo/product_minor/) | 부 버전 번호. |
| [`RELEASE_DATE`](/slides/python-net/ko/aspose.slides/buildversioninfo/release_date/) | 어셈블리의 릴리스 날짜. |
