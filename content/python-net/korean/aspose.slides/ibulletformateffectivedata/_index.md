## IBulletFormatEffectiveData 클래스

효과적인 단락 글머리 기호 서식 속성을 포함하는 불변 객체.

IBulletFormatEffectiveData 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`type`](/slides/python-net/ko/aspose.slides/ibulletformateffectivedata/type/) | 단락의 글머리 기호 유형을 반환합니다.<br/>            읽기 전용 [`BulletType`](/slides/python-net/ko/aspose.slides/bullettype). |
| [`char`](/slides/python-net/ko/aspose.slides/ibulletformateffectivedata/char/) | 단락의 글머리 기호 문자를 반환합니다.<br/>            읽기 전용 **System.Char**. |
| [`actual_bullet_value`](/slides/python-net/ko/aspose.slides/ibulletformateffectivedata/actual_bullet_value/) | 부모 단락에 대한 실제 글머리 기호 값을 반환합니다.<br/>            읽기 전용 **str**. |
| [`font`](/slides/python-net/ko/aspose.slides/ibulletformateffectivedata/font/) | 단락의 글머리 기호 폰트를 반환합니다.<br/>            읽기 전용 [`IFontData`](/slides/python-net/ko/aspose.slides/ifontdata). |
| [`height`](/slides/python-net/ko/aspose.slides/ibulletformateffectivedata/height/) | 단락의 글머리 기호 높이를 반환합니다.<br/>            읽기 전용 **float**. |
| [`numbered_bullet_start_with`](/slides/python-net/ko/aspose.slides/ibulletformateffectivedata/numbered_bullet_start_with/) | 번호 매기기 글머리 기호 그룹에 사용되는 첫 번째 번호를 반환합니다.<br/>            읽기 전용 **int**. |
| [`numbered_bullet_style`](/slides/python-net/ko/aspose.slides/ibulletformateffectivedata/numbered_bullet_style/) | 번호 매기기 글머리 기호의 스타일을 반환합니다.<br/>            읽기 전용 [`NumberedBulletStyle`](/slides/python-net/ko/aspose.slides/numberedbulletstyle). |
| [`is_bullet_hard_color`](/slides/python-net/ko/aspose.slides/ibulletformateffectivedata/is_bullet_hard_color/) | 글머리 기호가 자체 색상을 가지고 있는지 또는 단락의 첫 번째 부분에서 색상을 상속받는지 판단합니다.<br/>            글머리 기호가 자체 색상을 가지고 있으면 **true**, 단락의 첫 번째 부분에서 색상을 상속받으면 **false** 를 반환합니다.<br/>            읽기 전용 **bool**. |
| [`is_bullet_hard_font`](/slides/python-net/ko/aspose.slides/ibulletformateffectivedata/is_bullet_hard_font/) | 글머리 기호가 자체 폰트를 가지고 있는지 또는 단락의 첫 번째 부분에서 폰트를 상속받는지 판단합니다.<br/>            글머리 기호가 자체 폰트를 가지고 있으면 **true**, 단락의 첫 번째 부분에서 폰트를 상속받으면 **true** 를 반환합니다.<br/>            읽기 전용 **bool**. |
| [`picture`](/slides/python-net/ko/aspose.slides/ibulletformateffectivedata/picture/) | 단락에서 글머리 기호로 사용되는 그림을 반환합니다.<br/>            읽기 전용 [`IPictureEffectiveData`](/slides/python-net/ko/aspose.slides/ipictureeffectivedata). |
| [`fill_format`](/slides/python-net/ko/aspose.slides/ibulletformateffectivedata/fill_format/) | 단락의 글머리 기호 채우기 형식을 반환합니다.<br/>            읽기 전용 [`IFillFormatEffectiveData`](/slides/python-net/ko/aspose.slides/ifillformateffectivedata). |
