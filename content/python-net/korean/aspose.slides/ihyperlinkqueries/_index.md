## IHyperlinkQueries 클래스

포함된 하이퍼링크에 쉽게 접근할 수 있습니다.

IHyperlinkQueries 타입은 다음 멤버를 노출합니다:

## 메서드

| 메서드 | 설명 |
| :- | :- |
| [`get_hyperlink_clicks(self)`](/slides/python-net/ko/aspose.slides/ihyperlinkqueries/get_hyperlink_clicks/#) | IHyperlinkContainer 하위 객체 중 HyperlinkClick이 None이 아닌 모든 객체를 가져옵니다.<br/>            지정된 IHyperlinkContainer 객체를 사용하여 해당 하이퍼링크를 관리할 수 있습니다(읽기, 업데이트 또는 제거). IHyperlinkContainer 인터페이스를 참조하세요. |

IHyperlinkContainer 인터페이스를 참조하세요. |

IHyperlinkContainer 인터페이스를 참조하세요. |
