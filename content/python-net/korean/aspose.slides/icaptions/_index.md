## ICaptions 클래스

WebVTT 폐쇄 캡션을 나타냅니다.

ICaptions 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`caption_id`](/slides/python-net/ko/aspose.slides/icaptions/caption_id/) | 폐쇄 캡션의 전역 고유 식별자(GUID)를 반환합니다.<br/>            읽기 전용 **System.Guid**. |
| [`label`](/slides/python-net/ko/aspose.slides/icaptions/label/) | 폐쇄 캡션의 레이블을 반환하거나 설정합니다.<br/>            읽기/쓰기 **str**. |
| [`binary_data`](/slides/python-net/ko/aspose.slides/icaptions/binary_data/) | 폐쇄 캡션의 바이너리 데이터를 반환합니다.<br/>            읽기 전용 **int**[]. |
| [`data_as_string`](/slides/python-net/ko/aspose.slides/icaptions/data_as_string/) | 폐쇄 캡션 데이터를 UTF-8 인코딩 문자열로 반환합니다.<br/>            읽기 전용 **str**. |
