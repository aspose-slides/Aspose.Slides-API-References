## ILightRig 클래스

LightRig을 나타냅니다.

ILightRig 유형은 다음 구성원을 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`direction`](/slides/python-net/ko/aspose.slides/ilightrig/direction/) | 빛 방향.<br/>            읽기/쓰기 [`LightingDirection`](/slides/python-net/ko/aspose.slides/lightingdirection). |
| [`light_type`](/slides/python-net/ko/aspose.slides/ilightrig/light_type/) | 도형에 적용할 수 있는 사전 설정 라이트 라이트를 나타냅니다. <br/>            LightRig은 3D 장면에 상대적으로 특정 방식으로 배치된 조명 그룹을 나타냅니다.<br/>            읽기/쓰기 [`LightRigPresetType`](/slides/python-net/ko/aspose.slides/lightrigpresettype). |
