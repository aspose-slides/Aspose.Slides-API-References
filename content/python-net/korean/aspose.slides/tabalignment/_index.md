## TabAlignment 열거형

탭 정렬을 나타냅니다.

## 필드

| 필드 | 설명 |
| :- | :- |
| LEFT | 왼쪽 정렬 |
| CENTER | 가운데 정렬 |
| RIGHT | 오른쪽 정렬 |
| DECIMAL | 소수점 정렬 |
