## PointF 클래스

부동 소수점 x 및 y 좌표의 순서쌍을 나타내며, 2차원 평면에서 점을 정의합니다. .NET `System.Drawing.PointF`와 호환됩니다.

**상속:**[`PointF`](/slides/python-net/ko/aspose.slides/pointf) → [`Point`](/slides/python-net/ko/aspose.slides/point)

PointF 형식은 다음 멤버를 제공합니다:

## 생성자

| 생성자 | 설명 |
| :- | :- |
| [`__init__(self, x=0.0, y=0.0)`](/slides/python-net/ko/aspose.slides/pointf/__init__/#float-float) | 지정된 좌표로 점을 생성합니다. |

## 속성

| 속성 | 설명 |
| :- | :- |
| [`x`](/slides/python-net/ko/aspose.slides/pointf/x/) | 이 점의 x 좌표를 가져오거나 설정합니다.<br/>            읽기/쓰기 **float**. |
| [`y`](/slides/python-net/ko/aspose.slides/pointf/y/) | 이 점의 y 좌표를 가져오거나 설정합니다.<br/>            읽기/쓰기 **float**. |


### 비고

점은 `==` 연산자로 좌표를 비교하며, 사전 키 또는 집합 멤버로 사용할 수 있습니다.
