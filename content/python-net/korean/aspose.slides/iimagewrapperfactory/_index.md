## IImageWrapperFactory 클래스

이 인터페이스는 IBitmapWrapper를 초기화할 수 있습니다.

IImageWrapperFactory 형식은 다음 멤버를 노출합니다:

## 메서드

| 메서드 | 설명 |
| :- | :- |
| [`create_image_wrapper(self, image)`](/slides/python-net/ko/aspose.slides/iimagewrapperfactory/create_image_wrapper/#iimage) | 지정된 기존 이미지에서 ImageWrapper 클래스의 새 인스턴스를 초기화합니다. |
| [`create_image_wrapper(self, stream)`](/slides/python-net/ko/aspose.slides/iimagewrapperfactory/create_image_wrapper/#iorawiobase) | 지정된 데이터 스트림에서 ImageWrapper 클래스의 새 인스턴스를 초기화합니다. |
| [`create_image_wrapper(self, file_name)`](/slides/python-net/ko/aspose.slides/iimagewrapperfactory/create_image_wrapper/#str) | 지정된 파일에서 ImageWrapper 클래스의 새 인스턴스를 초기화합니다. |
