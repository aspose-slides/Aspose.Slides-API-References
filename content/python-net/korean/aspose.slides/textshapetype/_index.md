## TextShapeType 열거형

텍스트 래핑 모양을 나타냅니다.

TextShapeType 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| NOT_DEFINED | 정의되지 않음 |
| NONE | 모양 없음 |
| PLAIN | 단순 |
| STOP | 정지 표지 |
| TRIANGLE | 삼각형 |
| TRIANGLE_INVERTED | 역삼각형 |
| CHEVRON | 쉐브론 |
| CHEVRON_INVERTED | 역쉐브론 |
| RING_INSIDE | 내부 링 |
| RING_OUTSIDE | 외부 링 |
| ARCH_UP | 위쪽 아치 |
| ARCH_DOWN | 아래쪽 아치 |
| CIRCLE | 원 |
| BUTTON | 버튼 |
| ARCH_UP_POUR | 위쪽 퍼 아치 |
| ARCH_DOWN_POUR | 아래쪽 퍼 아치 |
| CIRCLE_POUR | 원 퍼 |
| BUTTON_POUR | 버튼 퍼 |
| CURVE_UP | 위쪽 곡선 |
| CURVE_DOWN | 아래쪽 곡선 |
| CAN_UP | 위쪽 캔 |
| CAN_DOWN | 아래쪽 캔 |
| WAVE1 | 파형 1 |
| WAVE2 | 파형 2 |
| DOUBLE_WAVE1 | 이중 파형 1 |
| WAVE4 | 파형 4 |
| INFLATE | 팽창 |
| DEFLATE | 수축 |
| INFLATE_BOTTOM | 하단 팽창 |
| DEFLATE_BOTTOM | 하단 수축 |
| INFLATE_TOP | 상단 팽창 |
| DEFLATE_TOP | 상단 수축 |
| DEFLATE_INFLATE | 수축-팽창 |
| DEFLATE_INFLATE_DEFLATE | 수축-팽창-수축 |
| FADE_RIGHT | 오른쪽 페이드 |
| FADE_LEFT | 왼쪽 페이드 |
| FADE_UP | 위쪽 페이드 |
| FADE_DOWN | 아래쪽 페이드 |
| SLANT_UP | 위쪽 기울기 |
| SLANT_DOWN | 아래쪽 기울기 |
| CASCADE_UP | 위쪽 캐스케이드 |
| CASCADE_DOWN | 아래쪽 캐스케이드 |
| CUSTOM | 사용자 정의 |
