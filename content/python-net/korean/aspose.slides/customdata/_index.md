## CustomData 클래스

Custom data에 대한 컨테이너를 나타냅니다.

CustomData 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`tags`](/slides/python-net/ko/aspose.slides/customdata/tags/) | Customer Data Tags 컬렉션을 반환합니다.<br/>읽기 전용 [`ITagCollection`](/slides/python-net/ko/aspose.slides/itagcollection). |
| [`custom_xml_parts`](/slides/python-net/ko/aspose.slides/customdata/custom_xml_parts/) | custom xml parts 컬렉션을 반환합니다.<br/>읽기 전용 [`ICustomXmlPartCollection`](/slides/python-net/ko/aspose.slides/icustomxmlpartcollection). |
