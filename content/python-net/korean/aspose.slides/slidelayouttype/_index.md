## SlideLayoutType 열거형

슬라이드 레이아웃 유형을 나타냅니다.

SlideLayoutType 형식은 다음 멤버를 노출합니다:

## 필드

| Field | Description |
| :- | :- |
| CUSTOM | 사용자 정의 |
| TITLE | 제목 |
| TEXT | 텍스트 |
| TWO_COLUMN_TEXT | 두 열 텍스트 |
| TABLE | 표 |
| TEXT_AND_CHART | 텍스트와 차트 |
| CHART_AND_TEXT | 차트와 텍스트 |
| DIAGRAM | 다이어그램 |
| CHART | 차트 |
| TEXT_AND_CLIP_ART | 텍스트와 클립 아트 |
| CLIP_ART_AND_TEXT | 클립 아트와 텍스트 |
| TITLE_ONLY | 제목만 |
| BLANK | 빈 |
| TEXT_AND_OBJECT | 텍스트와 개체 |
| OBJECT_AND_TEXT | 개체와 텍스트 |
| OBJECT | 개체 |
| TITLE_AND_OBJECT | 제목과 개체 |
| TEXT_AND_MEDIA | 텍스트와 미디어 |
| MEDIA_AND_TEXT | 미디어와 텍스트 |
| OBJECT_OVER_TEXT | 텍스트 위의 개체 |
| TEXT_OVER_OBJECT | 개체 위의 텍스트 |
| TEXT_AND_TWO_OBJECTS | 텍스트와 두 개체 |
| TWO_OBJECTS_AND_TEXT | 두 개체와 텍스트 |
| TWO_OBJECTS_OVER_TEXT | 텍스트 위의 두 개체 |
| FOUR_OBJECTS | 네 개체 |
| VERTICAL_TEXT | 수직 텍스트 |
| CLIP_ART_AND_VERTICAL_TEXT | 클립 아트와 수직 텍스트 |
| VERTICAL_TITLE_AND_TEXT | 수직 제목과 텍스트 |
| VERTICAL_TITLE_AND_TEXT_OVER_CHART | 차트 위의 수직 제목과 텍스트 |
| TWO_OBJECTS | 두 개체 |
| OBJECT_AND_TWO_OBJECT | 개체와 두 개체 |
| TWO_OBJECTS_AND_OBJECT | 두 개체와 개체 |
| SECTION_HEADER | 섹션 헤더 |
| TWO_TEXT_AND_TWO_OBJECTS | 두 텍스트와 두 개체 |
| TITLE_OBJECT_AND_CAPTION | 제목, 개체 및 캡션 |
| PICTURE_AND_CAPTION | 그림과 캡션 |
