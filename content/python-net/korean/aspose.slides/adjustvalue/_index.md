## AdjustValue 클래스

지오메트리 도형의 조정 값을 나타냅니다. 이러한 값은 도형의 형태에 영향을 줍니다.

AdjustValue 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`raw_value`](/slides/python-net/ko/aspose.slides/adjustvalue/raw_value/) | 조정 값 "as is"를 반환하거나 설정합니다.<br/>            읽기/쓰기 **int**. |
| [`angle_value`](/slides/python-net/ko/aspose.slides/adjustvalue/angle_value/) | 값을 반환하거나 설정합니다. 값을 도 단위의 각도로 해석합니다.<br/>            읽기/쓰기 **float**. |
| [`name`](/slides/python-net/ko/aspose.slides/adjustvalue/name/) | 이 조정 값의 이름을 반환합니다.<br/>            읽기 전용 **str**. |
| [`type`](/slides/python-net/ko/aspose.slides/adjustvalue/type/) | 도형 조정의 유형을 반환합니다.<br/>            읽기 전용 [`ShapeAdjustmentType`](/slides/python-net/ko/aspose.slides/shapeadjustmenttype). |
