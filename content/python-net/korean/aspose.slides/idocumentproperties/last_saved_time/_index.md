## last_saved_time 속성
프레젠테이션이 마지막으로 수정된 날짜를 반환합니다.
            값은 UTC.P 형식입니다.
            Presentation.DocumentProperties의 경우 읽기 전용입니다 (IPresentation 객체 저장 과정 중 내부에서 업데이트되기 때문). 
            [`IPresentationInfo.read_document_properties`](/slides/python-net/ko/aspose.slides/ipresentationinfo/read_document_properties) 메서드가 반환하는 DocumentProperties 인스턴스를 통해 변경할 수 있습니다.
            **Aspose.Slides.IPresentationInfo.UpdateDocumentProperties(Aspose.Slide** 메서드 요약에서 예제를 참고하십시오.
