## IImage 클래스

래스터 또는 벡터 이미지를 나타냅니다.

IImage 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`size`](/slides/python-net/ko/aspose.slides/iimage/size/) | 이미지의 크기를 가져옵니다. |
| [`width`](/slides/python-net/ko/aspose.slides/iimage/width/) | 이미지의 너비(픽셀)를 가져옵니다. |
| [`height`](/slides/python-net/ko/aspose.slides/iimage/height/) | 이미지의 높이(픽셀)를 가져옵니다. |

## 메서드

| 메서드 | 설명 |
| :- | :- |
| [`save(self, filename)`](/slides/python-net/ko/aspose.slides/iimage/save/#str) | 이미지를 파일에 저장합니다. |
| [`save(self, filename, format)`](/slides/python-net/ko/aspose.slides/iimage/save/#str-imageformat) | 이미지를 지정된 형식으로 파일에 저장합니다. |
| [`save(self, stream, format)`](/slides/python-net/ko/aspose.slides/iimage/save/#iorawiobase-imageformat) | 이미지를 지정된 형식으로 스트림에 저장합니다. |
| [`save(self, filename, format, quality)`](/slides/python-net/ko/aspose.slides/iimage/save/#str-imageformat-int) | 이미지를 지정된 형식 및 품질로 파일에 저장합니다. |
| [`save(self, stream, format, quality)`](/slides/python-net/ko/aspose.slides/iimage/save/#iorawiobase-imageformat-int) | 이미지를 지정된 형식 및 품질로 스트림에 저장합니다. |

### 비고

이 인터페이스는 래스터와 벡터 이미지를 모두 처리하기 위한 공통 추상화를 제공합니다.  
구현은 기본 이미지 유형에 따라 달라질 수 있습니다.
