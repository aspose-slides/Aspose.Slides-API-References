## ITabEffectiveData 클래스

실제 텍스트의 탭 정지 속성을 포함하는 불변 객체.

ITabEffectiveData 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`position`](/slides/python-net/ko/aspose.slides/itabeffectivedata/position/) | 탭의 위치를 반환합니다.<br/>            이 속성을 할당하면 컬렉션에서 탭의 인덱스를 변경하고 Enumerator를 무효화할 수 있습니다.<br/>            읽기 전용 **float**. |
| [`alignment`](/slides/python-net/ko/aspose.slides/itabeffectivedata/alignment/) | 탭의 정렬 스타일을 반환합니다.<br/>            읽기 전용 [`TabAlignment`](/slides/python-net/ko/aspose.slides/tabalignment). |


### 비고

이 인터페이스는 [`IParagraphFormatEffectiveData`](/slides/python-net/ko/aspose.slides/iparagraphformateffectivedata)의 일부로 사용됩니다.
