## IControlPropertiesCollection 클래스

ActiveX 컨트롤의 컬렉션입니다.

IControlPropertiesCollection 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`count`](/slides/python-net/ko/aspose.slides/icontrolpropertiescollection/count/) | 컬렉션에 있는 속성의 개수를 반환합니다.<br/>            읽기 전용 **int**. |
| [`names_of_properties`](/slides/python-net/ko/aspose.slides/icontrolpropertiescollection/names_of_properties/) | 컬렉션에 있는 속성의 개수를 반환합니다.<br/>            읽기 전용 **list**. |

## 메서드

| 메서드 | 설명 |
| :- | :- |
| [`add(self, name, value)`](/slides/python-net/ko/aspose.slides/icontrolpropertiescollection/add/#str-str) | 컬렉션에 속성을 추가합니다. |
| [`remove(self, name)`](/slides/python-net/ko/aspose.slides/icontrolpropertiescollection/remove/#str) | 지정된 이름을 가진 속성을 제거합니다. |
| [`clear(self)`](/slides/python-net/ko/aspose.slides/icontrolpropertiescollection/clear/#) | 모든 속성을 제거합니다. |
