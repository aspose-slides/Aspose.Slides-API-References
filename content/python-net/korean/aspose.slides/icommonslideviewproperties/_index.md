## ICommonSlideViewProperties 클래스

공통 슬라이드 보기 속성을 나타냅니다.

ICommonSlideViewProperties 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`scale`](/slides/python-net/ko/aspose.slides/icommonslideviewproperties/scale/) | 뷰 스케일 비율을 백분율로 지정합니다.<br/>            읽기/쓰기 **int**. |
| [`variable_scale`](/slides/python-net/ko/aspose.slides/icommonslideviewproperties/variable_scale/) | 뷰 콘텐츠가 현재 창 크기에 맞게 자동으로 최적 스케일링되도록 지정합니다.<br/>            읽기/쓰기 **bool**. |
| [`drawing_guides`](/slides/python-net/ko/aspose.slides/icommonslideviewproperties/drawing_guides/) | 그림 가이드 컬렉션을 반환합니다.<br/>            읽기 전용 [`IDrawingGuidesCollection`](/slides/python-net/ko/aspose.slides/idrawingguidescollection) |
