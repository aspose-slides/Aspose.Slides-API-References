## ColorType 열거형

다양한 색상 모드를 나타냅니다.

ColorType 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| NOT_DEFINED | 색상이 전혀 정의되지 않았습니다. |
| RGB | 표준 24비트 RGB 색상. |
| RGB_PERCENTAGE | 고해상도 RGB 색상. |
| HSL | 고해상도 HSL 색상. |
| SCHEME | 스키마 색상. |
| SYSTEM | 시스템 색상. |
| PRESET | 프리셋 색상. |
