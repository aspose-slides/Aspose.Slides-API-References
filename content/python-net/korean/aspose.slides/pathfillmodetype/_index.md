## PathFillModeType 열거형

경로를 채우는 방식을 지정합니다

PathFillModeType 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| NONE | No Path Fill<br/>            이는 해당 경로에 채우기가 없어야 함을 지정합니다. |
| NORMAL | Normal Path Fill<br/>            이는 해당 경로에 일반적인 음영 색상이 적용된 채우기가 있어야 함을 지정합니다. |
| LIGHTEN | Lighten Path Fill<br/>            이는 해당 경로에 약간 밝은 음영 색상이 적용된 채우기가 있어야 함을 지정합니다. |
| LIGHTEN_LESS | Lighten Path Fill Less<br/>            이는 해당 경로에 약간 더 밝은 음영 색상이 적용된 채우기가 있어야 함을 지정합니다. |
| DARKEN | Darken Path Fill<br/>            이는 해당 경로에 더 어두운 음영 색상이 적용된 채우기가 있어야 함을 지정합니다. |
| DARKEN_LESS | Darken Path Fill Less<br/>            이는 해당 경로에 약간 더 어두운 음영 색상이 적용된 채우기가 있어야 함을 지정합니다. |
