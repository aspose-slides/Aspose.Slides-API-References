## ITextSearchOptions 클래스

프레젠테이션, 슬라이드 또는 텍스트 프레임에서 텍스트를 검색하는 데 사용할 수 있는 옵션을 나타냅니다.

ITextSearchOptions 타입은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`case_sensitive`](/slides/python-net/ko/aspose.slides/itextsearchoptions/case_sensitive/) | 대소문자를 구분하는 검색을 사용하려면 true를 설정하고, 그렇지 않으면 false를 설정합니다.<br/>            읽기/쓰기 **bool**. |
| [`whole_words_only`](/slides/python-net/ko/aspose.slides/itextsearchoptions/whole_words_only/) | 전체 단어만 일치시키려면 true를 설정하고, 그렇지 않으면 false를 설정합니다.<br/>            읽기/쓰기 **bool**. |
| [`include_notes`](/slides/python-net/ko/aspose.slides/itextsearchoptions/include_notes/) | `true`를 설정하면 슬라이드 노트에 포함된 텍스트를 텍스트 검색, 교체 또는 하이라이트 작업을 수행할 때 포함합니다.<br/>            기본값은 `false`입니다. |
