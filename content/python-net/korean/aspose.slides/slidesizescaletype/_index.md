## SlideSizeScaleType 열거형

슬라이드 콘텐츠의 크기 유형을 나타냅니다.

SlideSizeScaleType 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| DO_NOT_SCALE | 크기를 조정하지 않음. |
| ENSURE_FIT | 맞춤을 보장하도록 크기를 조정합니다. |
| MAXIMIZE | 콘텐츠 크기를 최대화합니다. |
