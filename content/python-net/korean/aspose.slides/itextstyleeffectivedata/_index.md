## ITextStyleEffectiveData 클래스

ITextStyleEffectiveData 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`default_paragraph_format`](/slides/python-net/ko/aspose.slides/itextstyleeffectivedata/default_paragraph_format/) | 효과적인 기본 단락 속성을 반환합니다.<br/> 읽기 전용 [`IParagraphFormatEffectiveData`](/slides/python-net/ko/aspose.slides/iparagraphformateffectivedata). |
