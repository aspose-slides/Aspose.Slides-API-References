## ShapeStyle 클래스

도형의 스타일 참조를 나타냅니다.

ShapeStyle 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`line_color`](/slides/python-net/ko/aspose.slides/shapestyle/line_color/) | 도형의 윤곽선 색을 반환합니다.<br/>            읽기 전용 [`IColorFormat`](/slides/python-net/ko/aspose.slides/icolorformat). |
| [`line_style_index`](/slides/python-net/ko/aspose.slides/shapestyle/line_style_index/) | 라인의 스타일 매트릭스에서 열 인덱스를 반환하거나 설정합니다.<br/>            읽기/쓰기 **int**. |
| [`fill_color`](/slides/python-net/ko/aspose.slides/shapestyle/fill_color/) | 도형의 채우기 색을 반환합니다.<br/>            읽기 전용 [`IColorFormat`](/slides/python-net/ko/aspose.slides/icolorformat). |
| [`fill_style_index`](/slides/python-net/ko/aspose.slides/shapestyle/fill_style_index/) | 스타일 매트릭스에서 도형의 채우기 열 인덱스를 반환하거나 설정합니다.<br/>            0은 채우기 없음을 의미합니다,<br/>            양수 값 – 테마의 채우기 스타일 인덱스,<br/>            음수 값 – 테마의 배경 스타일 인덱스.<br/>            읽기/쓰기 **int**. |
| [`effect_color`](/slides/python-net/ko/aspose.slides/shapestyle/effect_color/) | 도형의 효과 색을 반환합니다.<br/>            읽기 전용 [`IColorFormat`](/slides/python-net/ko/aspose.slides/icolorformat). |
| [`effect_style_index`](/slides/python-net/ko/aspose.slides/shapestyle/effect_style_index/) | 스타일 매트릭스에서 도형의 효과 열 인덱스를 반환하거나 설정합니다.<br/>            읽기/쓰기 **int**. |
| [`font_color`](/slides/python-net/ko/aspose.slides/shapestyle/font_color/) | 도형의 글꼴 색을 반환합니다.<br/>            읽기 전용 [`IColorFormat`](/slides/python-net/ko/aspose.slides/icolorformat). |
| [`font_collection_index`](/slides/python-net/ko/aspose.slides/shapestyle/font_collection_index/) | 글꼴 컬렉션에서 도형의 글꼴 인덱스를 반환하거나 설정합니다.<br/>            읽기/쓰기 [`FontCollectionIndex`](/slides/python-net/ko/aspose.slides/fontcollectionindex). |
