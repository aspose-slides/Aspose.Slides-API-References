## INotesSlideManager 클래스

노트 슬라이드 관리자.

INotesSlideManager 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`notes_slide`](/slides/python-net/ko/aspose.slides/inotesslidemanager/notes_slide/) | 현재 슬라이드에 대한 노트 슬라이드를 반환합니다. 슬라이드에 노트 슬라이드가 없으면 None을 반환합니다.<br/>읽기 전용 [`INotesSlide`](/slides/python-net/ko/aspose.slides/inotesslide). |

## 메서드

| 메서드 | 설명 |
| :- | :- |
| [`add_notes_slide(self)`](/slides/python-net/ko/aspose.slides/inotesslidemanager/add_notes_slide/#) | 현재 슬라이드에 대한 노트 슬라이드를 반환하며, 없을 경우 새로 생성합니다. |
| [`remove_notes_slide(self)`](/slides/python-net/ko/aspose.slides/inotesslidemanager/remove_notes_slide/#) | 현재 슬라이드의 노트 슬라이드를 제거합니다. |
