## IShapeStyle 클래스

도형 스타일 참조를 나타냅니다.

IShapeStyle 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`line_color`](/slides/python-net/ko/aspose.slides/ishapestyle/line_color/) | 도형의 외곽선 색상을 반환합니다.<br/>            읽기 전용 [`IColorFormat`](/slides/python-net/ko/aspose.slides/icolorformat). |
| [`line_style_index`](/slides/python-net/ko/aspose.slides/ishapestyle/line_style_index/) | 스타일 매트릭스에서 선의 열 인덱스를 반환하거나 설정합니다.<br/>            읽기/쓰기 **int**. |
| [`fill_color`](/slides/python-net/ko/aspose.slides/ishapestyle/fill_color/) | 도형의 채우기 색상을 반환합니다.<br/>            읽기 전용 [`IColorFormat`](/slides/python-net/ko/aspose.slides/icolorformat). |
| [`fill_style_index`](/slides/python-net/ko/aspose.slides/ishapestyle/fill_style_index/) | 스타일 매트릭스에서 도형의 채우기 열 인덱스를 반환하거나 설정합니다.<br/>            0은 채우기 없음,<br/>            양수 값 - 테마의 채우기 스타일 인덱스,<br/>            음수 값 - 테마의 배경 스타일 인덱스.<br/>            읽기/쓰기 **int**. |
| [`effect_color`](/slides/python-net/ko/aspose.slides/ishapestyle/effect_color/) | 도형의 효과 색상을 반환합니다.<br/>            읽기 전용 [`IColorFormat`](/slides/python-net/ko/aspose.slides/icolorformat). |
| [`effect_style_index`](/slides/python-net/ko/aspose.slides/ishapestyle/effect_style_index/) | 스타일 매트릭스에서 도형의 효과 열 인덱스를 반환하거나 설정합니다.<br/>            읽기/쓰기 **int**. |
| [`font_color`](/slides/python-net/ko/aspose.slides/ishapestyle/font_color/) | 도형의 글꼴 색상을 반환합니다.<br/>            읽기 전용 [`IColorFormat`](/slides/python-net/ko/aspose.slides/icolorformat). |
| [`font_collection_index`](/slides/python-net/ko/aspose.slides/ishapestyle/font_collection_index/) | 글꼴 컬렉션에서 도형의 글꼴 인덱스를 반환하거나 설정합니다.<br/>            읽기/쓰기 [`FontCollectionIndex`](/slides/python-net/ko/aspose.slides/fontcollectionindex). |
