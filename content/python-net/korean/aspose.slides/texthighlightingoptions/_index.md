## TextHighlightingOptions 클래스

텍스트 프레임에서 텍스트를 강조 표시하는 데 사용할 수 있는 옵션을 나타냅니다.

TextHighlightingOptions 유형은 다음 멤버를 노출합니다:

## 생성자

| 생성자 | 설명 |
| :- | :- |
| [`__init__(self)`](/slides/python-net/ko/aspose.slides/texthighlightingoptions/__init__/#) | 새 기본 텍스트 강조 옵션을 생성합니다. |

## 속성

| 속성 | 설명 |
| :- | :- |
| [`case_sensitive`](/slides/python-net/ko/aspose.slides/texthighlightingoptions/case_sensitive/) | 대소문자를 구분하는 검색을 사용하려면 true, 그렇지 않으면 false로 설정합니다.<br/>읽기/쓰기 **bool**. |
| [`whole_words_only`](/slides/python-net/ko/aspose.slides/texthighlightingoptions/whole_words_only/) | 전체 단어만 일치시키려면 true, 그렇지 않으면 false로 설정합니다.<br/>읽기/쓰기 **bool**. |
