## ICustomData 클래스

사용자 지정 데이터에 대한 컨테이너를 나타냅니다.

ICustomData 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`tags`](/slides/python-net/ko/aspose.slides/icustomdata/tags/) | Customer Data Tags 컬렉션을 반환합니다.<br/>            읽기 전용 [`ITagCollection`](/slides/python-net/ko/aspose.slides/itagcollection). |
| [`custom_xml_parts`](/slides/python-net/ko/aspose.slides/icustomdata/custom_xml_parts/) | 사용자 지정 xml 파트 컬렉션을 반환합니다.<br/>            읽기 전용 [`ICustomXmlPartCollection`](/slides/python-net/ko/aspose.slides/icustomxmlpartcollection). |
