## TagCollection 클래스

태그(사용자 정의 문자열 쌍)의 컬렉션을 나타냅니다.

TagCollection 형식은 다음 멤버를 노출합니다:

## 메서드

| 메서드 | 설명 |
| :- | :- |
| [`add(self, name, value)`](/slides/python-net/ko/aspose.slides/tagcollection/add/#str-str) | 컬렉션에 새 태그를 추가합니다. |
| [`remove(self, name)`](/slides/python-net/ko/aspose.slides/tagcollection/remove/#str) | 컬렉션에서 지정된 이름을 가진 태그를 제거합니다. |
| [`index_of_name(self, name)`](/slides/python-net/ko/aspose.slides/tagcollection/index_of_name/#str) | 컬렉션에서 지정된 키의 0부터 시작하는 인덱스를 반환합니다. |
| [`remove_at(self, index)`](/slides/python-net/ko/aspose.slides/tagcollection/remove_at/#int) | 지정된 인덱스에 있는 태그를 제거합니다. |
| [`clear(self)`](/slides/python-net/ko/aspose.slides/tagcollection/clear/#) | 컬렉션의 모든 태그를 제거합니다. |
| [`get_value_by_index(self, index)`](/slides/python-net/ko/aspose.slides/tagcollection/get_value_by_index/#int) | 지정된 인덱스에 있는 태그의 값을 반환합니다. |
| [`get_name_by_index(self, index)`](/slides/python-net/ko/aspose.slides/tagcollection/get_name_by_index/#int) | 지정된 인덱스에 있는 태그의 키를 반환합니다. |
| [`get_names_of_tags(self)`](/slides/python-net/ko/aspose.slides/tagcollection/get_names_of_tags/#) | 태그 이름을 반환합니다. |
