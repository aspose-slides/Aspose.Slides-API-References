## TextVerticalType 열거형

텍스트에 대한 수직 쓰기 모드를 결정합니다.

TextVerticalType 타입은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| NOT_DEFINED | 정의되지 않음. |
| HORIZONTAL | 수평 텍스트. |
| VERTICAL | 수직 텍스트. |
| VERTICAL270 | 수직 270도 텍스트. |
| WORD_ART_VERTICAL | WordArt 수직 텍스트. |
| EAST_ASIAN_VERTICAL | 동아시아 수직 텍스트. |
| MONGOLIAN_VERTICAL | 몽골 수직 텍스트. |
| WORD_ART_VERTICAL_RIGHT_TO_LEFT | WordArt 수직 오른쪽에서 왼쪽 텍스트. |
