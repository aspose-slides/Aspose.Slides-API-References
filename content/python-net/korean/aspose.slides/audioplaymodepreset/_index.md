## AudioPlayModePreset 열거형

소리가 재생되는 방식을 정의하는 상수들입니다.

AudioPlayModePreset 유형은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| MIXED |  |
| AUTO | 자동 재생합니다. |
| ON_CLICK | 아이콘을 클릭했을 때만 재생합니다. |
| ALL_SLIDES | 모든 슬라이드에서 재생합니다. <br/>            대신 [`IAudioFrame.play_across_slides`](/slides/python-net/ko/aspose.slides/iaudioframe/play_across_slides) 속성을 사용하십시오.<br/>            이 요소는 PowerPoint 2013 이후로 오래되었습니다. |
| IN_CLICK_SEQUENCE | 클릭과 함께 자동으로 재생합니다. |
