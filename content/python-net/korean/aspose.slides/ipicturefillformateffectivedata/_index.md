## IPictureFillFormatEffectiveData 클래스

IPictureFillFormatEffectiveData 형식은 다음 멤버를 노출합니다:

## 속성

| Property | Description |
| :- | :- |
| [`dpi`](/slides/python-net/ko/aspose.slides/ipicturefillformateffectivedata/dpi/) | 그림을 채우는 데 사용되는 dpi를 반환합니다.<br/>            읽기 전용 **int**. |

| [`crop_bottom`](/slides/python-net/ko/aspose.slides/ipicturefillformateffectivedata/crop_bottom/) | 그림의 아래쪽에서 잘려 나간 실제 이미지 높이의 백분율을 반환합니다.<br/>            읽기 전용 **float**. |
