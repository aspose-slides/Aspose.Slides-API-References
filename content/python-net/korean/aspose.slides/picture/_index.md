## Picture 클래스

프레젠테이션에서 그림을 나타냅니다.

Picture 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`image`](/slides/python-net/ko/aspose.slides/picture/image/) | 임베디드 이미지를 반환하거나 설정합니다.<br/>읽기/쓰기 [`IPPImage`](/slides/python-net/ko/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/ko/aspose.slides/picture/link_path_long/) | 링크된 이미지 URL을 반환하거나 설정합니다.<br/>읽기/쓰기 **str**. |
| [`image_transform`](/slides/python-net/ko/aspose.slides/picture/image_transform/) | 이미지 변환 효과 컬렉션을 반환합니다.<br/>읽기 전용 [`IImageTransformOperationCollection`](/slides/python-net/ko/aspose.slides.effects/iimagetransformoperationcollection). |
| [`presentation`](/slides/python-net/ko/aspose.slides/picture/presentation/) | 프레젠테이션을 반환합니다.<br/>읽기 전용 [`IPresentation`](/slides/python-net/ko/aspose.slides/ipresentation). |
| [`slide`](/slides/python-net/ko/aspose.slides/picture/slide/) | 그림의 부모 슬라이드를 반환합니다.<br/>읽기 전용 [`IBaseSlide`](/slides/python-net/ko/aspose.slides/ibaseslide). |
