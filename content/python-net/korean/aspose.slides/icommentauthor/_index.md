## ICommentAuthor 클래스

주석의 작성자를 나타냅니다.

ICommentAuthor 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`name`](/slides/python-net/ko/aspose.slides/icommentauthor/name/) | 작성자의 이름을 반환하거나 설정합니다.<br/>            읽기/쓰기 **str**. |
| [`initials`](/slides/python-net/ko/aspose.slides/icommentauthor/initials/) | 작성자의 이니셜을 반환하거나 설정합니다.<br/>            읽기/쓰기 **str**. |
| [`comments`](/slides/python-net/ko/aspose.slides/icommentauthor/comments/) | 이 작성자가 만든 댓글 컬렉션을 반환합니다.<br/>            읽기 전용 [`ICommentCollection`](/slides/python-net/ko/aspose.slides/icommentcollection). |

## 메서드

| 메서드 | 설명 |
| :- | :- |
| [`remove(self)`](/slides/python-net/ko/aspose.slides/icommentauthor/remove/#) | 작성자를 상위 컬렉션에서 제거합니다. |
