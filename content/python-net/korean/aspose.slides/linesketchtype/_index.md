## LineSketchType 열거형

형태에 할당된 스케치 유형 또는 효과를 나타냅니다.

The LineSketchType type exposes the following members:

## 필드

| Field | Description |
| :- | :- |
| NOT_DEFINED | 형태에 Sketch 효과가 정의되지 않았음을 지정합니다. |
| NONE | 형태에 Sketch 효과가 없음을 지정합니다. 이는 해당 속성이 비어 있음과 동일합니다. |
| CURVED | 형태에 Curved 효과가 있음을 지정합니다. 이 효과는 형태의 각 가장자리를 하나의 부드러운 큰 곡선으로 변환합니다. |
| FREEHAND | 형태에 Freehand 효과가 있음을 지정합니다. 이는 불완전하게 그린 선과 가장 유사합니다. |
| SCRIBBLE | 형태에 Scribble 효과가 있음을 지정합니다. 이는 의도적으로 난잡하게 그린 것처럼 과장된 진동을 가집니다. |
