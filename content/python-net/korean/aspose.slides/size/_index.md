## Size 클래스

정수 쌍을 저장하며, 너비와 높이를 지정합니다. .NET `System.Drawing.Size`와 호환됩니다.

Size 타입은 다음 멤버를 노출합니다:

## 생성자

| 생성자 | 설명 |
| :- | :- |
| [`__init__(self, width=0, height=0)`](/slides/python-net/ko/aspose.slides/size/__init__/#int-int) | 지정된 너비와 높이로 크기를 생성합니다. 부동 소수점 값은 정수로 잘립니다. |

## 속성

| 속성 | 설명 |
| :- | :- |
| [`width`](/slides/python-net/ko/aspose.slides/size/width/) | 이 크기의 수평 구성 요소를 가져옵니다.<br/>            읽기 전용 **int**. |
| [`height`](/slides/python-net/ko/aspose.slides/size/height/) | 이 크기의 수직 구성 요소를 가져옵니다.<br/>            읽기 전용 **int**. |

### 비고

크기는 `==` 연산자로 구성 요소를 비교하며 사전 키나 집합 멤버로 사용할 수 있습니다.
