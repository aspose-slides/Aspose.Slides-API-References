## LoadFormat 열거형

LoadFormat 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| AUTO | Aspose.Slides에 형식을 자동으로 인식하도록 지시합니다. |
| PPT | Microsoft PowerPoint 97-2003 프레젠테이션. |
| PPS | Microsoft PowerPoint 97-2003 슬라이드쇼. |
| PPTX | Microsoft Office Open XML PresentationML 문서. |
| PPSX | Microsoft Office Open XML PresentationML 슬라이드쇼. |
| ODP | OpenOffice ODF 프레젠테이션. |
| POTX | Microsoft Office Open XML PresentationML 템플릿. |
| PPTM | Microsoft Office Open XML PresentationML 매크로 사용 문서. |
| PPSM | Microsoft Office Open XML PresentationML 매크로 사용 슬라이드쇼. |
| POTM | Microsoft Office Open XML PresentationML 매크로 사용 템플릿. |
| OTP | OpenOffice OTP 프레젠테이션 템플릿. |
| PPT95 | Microsoft PowerPoint 95 프레젠테이션. |
| POT | Microsoft PowerPoint 97-2003 프레젠테이션 템플릿. |
| FODP | Flat XML ODF 프레젠테이션. |
| UNKNOWN | 알 수 없는 파일 형식 |
