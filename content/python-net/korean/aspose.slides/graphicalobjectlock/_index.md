## GraphicalObjectLock 클래스

부모 GraphicalObject에서 비활성화된 작업을 결정합니다.

**상속:**[`GraphicalObjectLock`](/slides/python-net/ko/aspose.slides/graphicalobjectlock) → [`BaseShapeLock`](/slides/python-net/ko/aspose.slides/baseshapelock)

GraphicalObjectLock 유형은 다음 멤버를 공개합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`no_locks`](/slides/python-net/ko/aspose.slides/graphicalobjectlock/no_locks/) | 모든 lock-flags가 비활성화된 경우 true를 반환합니다.<br/>            읽기 전용 **bool**. |
| [`grouping_locked`](/slides/python-net/ko/aspose.slides/graphicalobjectlock/grouping_locked/) | 이 도형을 그룹에 추가하는 것이 금지되는지 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`drilldown_locked`](/slides/python-net/ko/aspose.slides/graphicalobjectlock/drilldown_locked/) | 이 객체의 하위 도형을 선택하는 것이 금지되는지 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`select_locked`](/slides/python-net/ko/aspose.slides/graphicalobjectlock/select_locked/) | 이 도형을 선택하는 것이 금지되는지 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/ko/aspose.slides/graphicalobjectlock/aspect_ratio_locked/) | 도형을 크기 조정할 때 가로세로 비율을 유지해야 하는지 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`position_locked`](/slides/python-net/ko/aspose.slides/graphicalobjectlock/position_locked/) | 이 도형을 이동하는 것이 금지되는지 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`size_locked`](/slides/python-net/ko/aspose.slides/graphicalobjectlock/size_locked/) | 이 도형의 크기 조정을 금지하는지 결정합니다.<br/>            읽기/쓰기 **bool**. |
