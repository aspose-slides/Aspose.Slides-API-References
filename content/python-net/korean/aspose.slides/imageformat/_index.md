## ImageFormat 열거형

이미지의 파일 형식을 나타냅니다.

ImageFormat 타입은 다음 멤버를 제공합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| MEMORY_BMP | 메모리 내 비트맵 형식을 나타냅니다. |
| BMP | 비트맵 (BMP) 이미지 형식을 나타냅니다. |
| EMF | 향상된 메타파일 (EMF) 이미지 형식을 나타냅니다. |
| WMF | Windows 메타파일 (WMF) 이미지 형식을 나타냅니다. |
| GIF | Graphics Interchange Format (GIF) 이미지 형식을 나타냅니다. |
| JPEG | Joint Photographic Experts Group (JPEG) 이미지 형식을 나타냅니다. |
| PNG | W3C Portable Network Graphics (PNG) 이미지 형식을 나타냅니다. |
| TIFF | Tagged Image File Format (TIFF) 이미지 형식을 나타냅니다. |
| EXIF | Exchangeable Image File (Exif) 형식을 나타냅니다. |
| ICON | Windows 아이콘 이미지 형식을 나타냅니다. |
