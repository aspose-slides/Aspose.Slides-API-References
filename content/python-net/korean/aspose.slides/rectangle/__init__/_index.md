## __init__(self, x=0, y=0, width=0, height=0) {#int-int-int-int}

```python
def __init__(self, x=0, y=0, width=0, height=0):
    ...
```

| 매개변수 | 형식 | 설명 |
| :- | :- | :- |
| x | **int** | 사각형의 왼쪽 위 모서리의 x 좌표입니다. |
| y | **int** | 사각형의 왼쪽 위 모서리의 y 좌표입니다. |
| width | **int** | 사각형의 너비입니다. |
| height | **int** | 사각형의 높이입니다. |
