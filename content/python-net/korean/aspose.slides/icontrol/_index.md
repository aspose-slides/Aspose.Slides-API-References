## IControl 클래스

ActiveX 컨트롤을 나타냅니다.

IControl 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`name`](/slides/python-net/ko/aspose.slides/icontrol/name/) | 이 컨트롤의 이름을 반환합니다.<br/>            읽기/쓰기 **str**. |
| [`class_id`](/slides/python-net/ko/aspose.slides/icontrol/class_id/) | 이 컨트롤의 클래스 ID를 가져옵니다.<br/>            읽기 전용 **System.Guid**. |
| [`substitute_picture_format`](/slides/python-net/ko/aspose.slides/icontrol/substitute_picture_format/) | ControlEx 이미지 채우기 속성 개체를 반환합니다.<br/>            읽기 전용 [`IPictureFillFormat`](/slides/python-net/ko/aspose.slides/ipicturefillformat). |
| [`frame`](/slides/python-net/ko/aspose.slides/icontrol/frame/) | 컨트롤의 프레임을 반환하거나 설정합니다.<br/>            읽기/쓰기 [`IShapeFrame`](/slides/python-net/ko/aspose.slides/ishapeframe). |
| [`properties`](/slides/python-net/ko/aspose.slides/icontrol/properties/) | ActiveX 속성의 컬렉션을 반환합니다.<br/>            읽기 전용 [`IControlPropertiesCollection`](/slides/python-net/ko/aspose.slides/icontrolpropertiescollection). |
| [`persistence`](/slides/python-net/ko/aspose.slides/icontrol/persistence/) | ActiveX 컨트롤의 속성을 저장하는 방법을 가져옵니다.<br/>            읽기 전용 [`PersistenceType`](/slides/python-net/ko/aspose.slides/persistencetype). |
| [`active_x_control_binary`](/slides/python-net/ko/aspose.slides/icontrol/active_x_control_binary/) | PersistStream, PersistStreamInit 또는 PersistStorage 중 하나를 지속 방법으로 사용할 때 ActiveX 컨트롤의 지속성을 지정합니다. |
| [`slide`](/slides/python-net/ko/aspose.slides/icontrol/slide/) |  |
| [`presentation`](/slides/python-net/ko/aspose.slides/icontrol/presentation/) |  |
