## AutoShapeLock 클래스

부모 AutoshapeEx에서 비활성화된 작업이 어떤 것인지 결정합니다.

**상속:**[`AutoShapeLock`](/slides/python-net/ko/aspose.slides/autoshapelock) → [`BaseShapeLock`](/slides/python-net/ko/aspose.slides/baseshapelock)

AutoShapeLock 타입은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`no_locks`](/slides/python-net/ko/aspose.slides/autoshapelock/no_locks/) | 모든 lock-flags가 비활성화된 경우 true를 반환합니다.<br/>            읽기 전용 **bool**. |
| [`grouping_locked`](/slides/python-net/ko/aspose.slides/autoshapelock/grouping_locked/) | 이 모양을 그룹에 추가하는 것이 금지되는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`select_locked`](/slides/python-net/ko/aspose.slides/autoshapelock/select_locked/) | 이 모양을 선택하는 것이 금지되는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`rotate_locked`](/slides/python-net/ko/aspose.slides/autoshapelock/rotate_locked/) | 이 모양의 회전 각도를 변경하는 것이 금지되는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/ko/aspose.slides/autoshapelock/aspect_ratio_locked/) | 크기 조정 시 모양이 종횡비를 유지해야 하는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`position_locked`](/slides/python-net/ko/aspose.slides/autoshapelock/position_locked/) | 이 모양을 이동하는 것이 금지되는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`size_locked`](/slides/python-net/ko/aspose.slides/autoshapelock/size_locked/) | 이 모양의 크기 조정이 금지되는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`edit_points_locked`](/slides/python-net/ko/aspose.slides/autoshapelock/edit_points_locked/) | 이 모양의 윤곽을 직접 변경하는 것이 금지되는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`adjust_handles_locked`](/slides/python-net/ko/aspose.slides/autoshapelock/adjust_handles_locked/) | 조정값을 변경하는 것이 금지되는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`arrowheads_locked`](/slides/python-net/ko/aspose.slides/autoshapelock/arrowheads_locked/) | 화살촉을 변경하는 것이 금지되는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`shape_type_locked`](/slides/python-net/ko/aspose.slides/autoshapelock/shape_type_locked/) | 모양 유형을 변경하는 것이 금지되는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`text_locked`](/slides/python-net/ko/aspose.slides/autoshapelock/text_locked/) | 텍스트 편집이 금지되는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
