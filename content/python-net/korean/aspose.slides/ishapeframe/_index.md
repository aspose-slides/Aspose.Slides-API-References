## IShapeFrame 클래스

shape frame의 속성을 나타냅니다.

IShapeFrame 유형은 다음 멤버를 노출합니다.

## 속성

| 속성 | 설명 |
| :- | :- |
| [`x`](/slides/python-net/ko/aspose.slides/ishapeframe/x/) | 프레임의 왼쪽 위 모서리 X 좌표를 반환합니다.<br/>            읽기 전용 **float**. |
| [`y`](/slides/python-net/ko/aspose.slides/ishapeframe/y/) | 프레임의 왼쪽 위 모서리 Y 좌표를 반환합니다.<br/>            읽기 전용 **float**. |
| [`width`](/slides/python-net/ko/aspose.slides/ishapeframe/width/) | 프레임의 너비를 반환합니다.<br/>            읽기 전용 **float**. |
| [`height`](/slides/python-net/ko/aspose.slides/ishapeframe/height/) | 프레임의 높이를 반환합니다.<br/>            읽기 전용 **float**. |
| [`rotation`](/slides/python-net/ko/aspose.slides/ishapeframe/rotation/) | 프레임이 z축을 중심으로 회전된 각도를 반환합니다.<br/>            양수 값은 시계 방향 회전을 나타내며, 음수 값은<br/>            반시계 방향 회전을 나타냅니다.<br/>            읽기 전용 **float**. |
| [`center_x`](/slides/python-net/ko/aspose.slides/ishapeframe/center_x/) | 프레임 중심의 X 좌표를 반환합니다.<br/>            읽기 전용 **float**. |
| [`center_y`](/slides/python-net/ko/aspose.slides/ishapeframe/center_y/) | 프레임 중심의 Y 좌표를 반환합니다.<br/>            읽기 전용 **float**. |
| [`flip_h`](/slides/python-net/ko/aspose.slides/ishapeframe/flip_h/) | 프레임이 수평으로 뒤집혔는지 여부를 결정합니다.<br/>            읽기 전용 [`NullableBool`](/slides/python-net/ko/aspose.slides/nullablebool). |
| [`flip_v`](/slides/python-net/ko/aspose.slides/ishapeframe/flip_v/) | 프레임이 수직으로 뒤집혔는지 여부를 결정합니다.<br/>            읽기 전용 [`NullableBool`](/slides/python-net/ko/aspose.slides/nullablebool). |
| [`rectangle`](/slides/python-net/ko/aspose.slides/ishapeframe/rectangle/) | 프레임의 좌표를 반환합니다.<br/>            읽기 전용 **aspose.slides.RectangleF**. |
