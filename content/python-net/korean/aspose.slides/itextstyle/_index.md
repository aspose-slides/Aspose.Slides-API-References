## ITextStyle 클래스

텍스트 스타일 서식 속성.

ITextStyle 형식은 다음 멤버를 제공합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`default_paragraph_format`](/slides/python-net/ko/aspose.slides/itextstyle/default_paragraph_format/) | 기본 단락 속성.<br/>읽기 전용 [`IParagraphFormat`](/slides/python-net/ko/aspose.slides/iparagraphformat). |

## 메서드

| 메서드 | 설명 |
| :- | :- |
| [`get_level(self, index)`](/slides/python-net/ko/aspose.slides/itextstyle/get_level/#int) | 스타일 레벨이 존재하면 반환하고, 그렇지 않으면 None을 반환합니다. |
| [`get_effective(self)`](/slides/python-net/ko/aspose.slides/itextstyle/get_effective/#) | 상속이 적용된 효과적인 텍스트 스타일 서식 데이터를 가져옵니다. |
