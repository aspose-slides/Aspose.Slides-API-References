## ICustomXmlPart 클래스

커스텀 XML 파트를 나타냅니다.

ICustomXmlPart 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`xml_as_string`](/slides/python-net/ko/aspose.slides/icustomxmlpart/xml_as_string/) | XML 데이터를 UTF-8 문자열로 반환하거나 설정합니다.<br/>            읽기/쓰기 **str**.<br/>            값은 `None`입니다.값이 비어 있거나 XML 데이터가 유효하지 않습니다. |
| [`xml_data`](/slides/python-net/ko/aspose.slides/icustomxmlpart/xml_data/) | XML 데이터를 반환하거나 설정합니다.<br/>            읽기/쓰기 **int**[].<br/>            값은 `None`입니다.값이 비어 있거나 XML 데이터가 유효하지 않습니다. |
| [`item_id`](/slides/python-net/ko/aspose.slides/icustomxmlpart/item_id/) | Office Open XML 문서 내에서 단일 커스텀 XML <br/>            파트를 고유하게 식별하는 전역 고유 식별자(GUID)를 지정합니다.<br/>            읽기 전용 **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/ko/aspose.slides/icustomxmlpart/namespace_schemas/) | 커스텀 XML 파트와 연결된 컬렉션 XML 스키마를 반환합니다.<br/>            읽기 전용 **str**[]. |

## 메서드

| 메서드 | 설명 |
| :- | :- |
