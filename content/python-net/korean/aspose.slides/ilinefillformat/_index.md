## ILineFillFormat 클래스

선 채우기 속성을 나타냅니다.

ILineFillFormat 형식은 다음 멤버를 제공합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`fill_type`](/slides/python-net/ko/aspose.slides/ilinefillformat/fill_type/) | 채우기 유형을 가져오거나 설정합니다.<br/>            읽기/쓰기 [`FillType`](/slides/python-net/ko/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/ko/aspose.slides/ilinefillformat/solid_fill_color/) | 단색 채우기의 색상을 반환합니다.<br/>            읽기 전용 [`IColorFormat`](/slides/python-net/ko/aspose.slides/icolorformat). |
| [`gradient_format`](/slides/python-net/ko/aspose.slides/ilinefillformat/gradient_format/) | 그라디언트 채우기 형식을 반환합니다.<br/>            읽기 전용 [`IGradientFormat`](/slides/python-net/ko/aspose.slides/igradientformat). |
| [`pattern_format`](/slides/python-net/ko/aspose.slides/ilinefillformat/pattern_format/) | 패턴 채우기 형식을 반환합니다.<br/>            읽기 전용 [`IPatternFormat`](/slides/python-net/ko/aspose.slides/ipatternformat). |
| [`rotate_with_shape`](/slides/python-net/ko/aspose.slides/ilinefillformat/rotate_with_shape/) | 채우기가 도형과 함께 회전해야 하는지 여부를 결정합니다.<br/>            읽기/쓰기 [`NullableBool`](/slides/python-net/ko/aspose.slides/nullablebool). |
