## IThreeDFormatEffectiveData 클래스

불변 객체이며 효과적인 3-D 서식 속성을 나타냅니다.

IThreeDFormatEffectiveData 형식은 다음 멤버를 노출합니다:

## 속성

| Property | Description |
| :- | :- |
| [`contour_width`](/slides/python-net/ko/aspose.slides/ithreedformateffectivedata/contour_width/) | 3D 윤곽선의 너비를 반환합니다.<br/>            읽기 전용 **float**. |
| [`extrusion_height`](/slides/python-net/ko/aspose.slides/ithreedformateffectivedata/extrusion_height/) | 돌출 효과의 높이를 반환합니다.<br/>            읽기 전용 **float**. |
| [`depth`](/slides/python-net/ko/aspose.slides/ithreedformateffectivedata/depth/) | 3D 도형의 깊이를 반환합니다.<br/>            읽기 전용 **float**. |
| [`bevel_top`](/slides/python-net/ko/aspose.slides/ithreedformateffectivedata/bevel_top/) | 상단 3D 베벨의 유형을 반환합니다.<br/>            읽기 전용 [`IShapeBevelEffectiveData`](/slides/python-net/ko/aspose.slides/ishapebeveleffectivedata). |
| [`bevel_bottom`](/slides/python-net/ko/aspose.slides/ithreedformateffectivedata/bevel_bottom/) | 하단 3D 베벨의 유형을 반환합니다.<br/>            읽기 전용 [`IShapeBevelEffectiveData`](/slides/python-net/ko/aspose.slides/ishapebeveleffectivedata). |
| [`contour_color`](/slides/python-net/ko/aspose.slides/ithreedformateffectivedata/contour_color/) | 윤곽선의 색상을 반환합니다.<br/>            읽기 전용 [`Color`](/slides/python-net/ko/aspose.slides/color). |
| [`extrusion_color`](/slides/python-net/ko/aspose.slides/ithreedformateffectivedata/extrusion_color/) | 돌출의 색상을 반환합니다.<br/>            읽기 전용 [`Color`](/slides/python-net/ko/aspose.slides/color). |
| [`camera`](/slides/python-net/ko/aspose.slides/ithreedformateffectivedata/camera/) | 카메라 설정을 반환합니다.<br/>            읽기 전용 [`ICameraEffectiveData`](/slides/python-net/ko/aspose.slides/icameraeffectivedata). |
| [`light_rig`](/slides/python-net/ko/aspose.slides/ithreedformateffectivedata/light_rig/) | 조명의 유형을 반환합니다.<br/>            읽기 전용 [`ILightRigEffectiveData`](/slides/python-net/ko/aspose.slides/ilightrigeffectivedata). |
| [`material`](/slides/python-net/ko/aspose.slides/ithreedformateffectivedata/material/) | 재료의 유형을 반환합니다.<br/>            읽기 전용 [`MaterialPresetType`](/slides/python-net/ko/aspose.slides/materialpresettype). |
