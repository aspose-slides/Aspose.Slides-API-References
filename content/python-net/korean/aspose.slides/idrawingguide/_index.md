## IDrawingGuide 클래스

조정 가능한 그리기 가이드를 나타냅니다.

IDrawingGuide 유형은 다음 멤버를 제공합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`orientation`](/slides/python-net/ko/aspose.slides/idrawingguide/orientation/) | 그리기 가이드의 방향을 반환하거나 설정합니다.<br/>            읽기/쓰기 [`Orientation`](/slides/python-net/ko/aspose.slides/orientation). |
| [`position`](/slides/python-net/ko/aspose.slides/idrawingguide/position/) | 그리기 가이드의 위치를 슬라이드의 왼쪽 위 모서리에서 포인트 단위로 반환하거나 설정합니다.<br/>            읽기/쓰기 **float**. |
| [`color`](/slides/python-net/ko/aspose.slides/idrawingguide/color/) | 그리기 가이드의 색상을 반환하거나 설정합니다.<br/>            읽기/쓰기 [`Color`](/slides/python-net/ko/aspose.slides/color). |
