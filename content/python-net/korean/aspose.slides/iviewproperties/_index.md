## IViewProperties class

프레젠테이션 전체 뷰 속성.

IViewProperties 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`last_view`](/slides/python-net/ko/aspose.slides/iviewproperties/last_view/) | 프레젠테이션 문서가 마지막으로 저장될 때 사용된 보기 모드를 지정합니다.<br/>            읽기/쓰기 [`ViewType`](/slides/python-net/ko/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/ko/aspose.slides/iviewproperties/show_comments/) | 슬라이드 주석을 표시할지 여부를 지정합니다.<br/>            읽기/쓰기 [`NullableBool`](/slides/python-net/ko/aspose.slides/nullablebool). |
| [`slide_view_properties`](/slides/python-net/ko/aspose.slides/iviewproperties/slide_view_properties/) | 슬라이드 보기 모드와 관련된 공통 뷰 속성을 지정합니다.<br/>            읽기 전용 [`ICommonSlideViewProperties`](/slides/python-net/ko/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/ko/aspose.slides/iviewproperties/notes_view_properties/) | 노트 보기 모드와 관련된 공통 뷰 속성을 지정합니다.<br/>            읽기 전용 [`ICommonSlideViewProperties`](/slides/python-net/ko/aspose.slides/icommonslideviewproperties). |
| [`normal_view_properties`](/slides/python-net/ko/aspose.slides/iviewproperties/normal_view_properties/) | 일반 뷰 속성을 나타냅니다. 일반 뷰는<br/>            세 개의 콘텐츠 영역으로 구성됩니다: 슬라이드 자체, 측면 콘텐츠 영역, 그리고 하단 콘텐츠 영역.<br/>            읽기 전용 [`INormalViewProperties`](/slides/python-net/ko/aspose.slides/inormalviewproperties). |
| [`grid_spacing`](/slides/python-net/ko/aspose.slides/iviewproperties/grid_spacing/) | 프레젠테이션 문서의 기본 그리드에 사용될 그리드 간격을 포인트 단위로 반환하거나 설정합니다. <br/>            읽기/쓰기 **float**. |
