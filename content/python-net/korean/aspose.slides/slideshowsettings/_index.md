## SlideShowSettings 클래스

프레젠테이션의 슬라이드 쇼 설정을 나타냅니다.

SlideShowSettings 형식은 다음 구성원을 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`slide_show_type`](/slides/python-net/ko/aspose.slides/slideshowsettings/slide_show_type/) | 슬라이드 쇼 유형을 가져오거나 설정합니다. 다음 [`SlideShowSettings.slide_show_type`](/slides/python-net/ko/aspose.slides/slideshowsettings/slide_show_type) 조상으로 표시됩니다: [`BrowsedAtKiosk`](/slides/python-net/ko/aspose.slides/browsedatkiosk), [`PresentedBySpeaker`](/slides/python-net/ko/aspose.slides/presentedbyspeaker) 및 [`BrowsedByIndividual`](/slides/python-net/ko/aspose.slides/browsedbyindividual) |
| [`loop`](/slides/python-net/ko/aspose.slides/slideshowsettings/loop/) | 슬라이드 쇼 루프 |
| [`show_narration`](/slides/python-net/ko/aspose.slides/slideshowsettings/show_narration/) | 슬라이드 쇼에서 내레이션 표시 |
| [`show_animation`](/slides/python-net/ko/aspose.slides/slideshowsettings/show_animation/) | 슬라이드 쇼에서 애니메이션 표시 |
| [`pen_color`](/slides/python-net/ko/aspose.slides/slideshowsettings/pen_color/) | 슬라이드 쇼용 펜 색상 |
| [`slides`](/slides/python-net/ko/aspose.slides/slideshowsettings/slides/) | 슬라이드 범위 |
| [`use_timings`](/ko/slides/python-net/aspose.slides/slideshowsettings/use_timings/) | 슬라이드 쇼에서 타이밍 사용 |
| [`show_media_controls`](/slides/python-net/ko/aspose.slides/slideshowsettings/show_media_controls/) | 미디어 컨트롤 표시 |
