## TextAlignment 열거형

다양한 텍스트 정렬 스타일을 나타냅니다.

TextAlignment 유형은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| NOT_DEFINED | 기본 정렬. |
| LEFT | 왼쪽 정렬. |
| CENTER | 가운데 정렬. |
| RIGHT | 오른쪽 정렬. |
| JUSTIFY | 두쪽 정렬. |
| JUSTIFY_LOW | Kashida 낮은 맞춤. |
| DISTRIBUTED | 분산 정렬. |
