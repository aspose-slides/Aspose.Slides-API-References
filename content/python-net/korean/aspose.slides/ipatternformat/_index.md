## IPatternFormat 클래스

IPatternFormat 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`pattern_style`](/slides/python-net/ko/aspose.slides/ipatternformat/pattern_style/) | 패턴 스타일을 반환하거나 설정합니다.<br/>            읽기/쓰기 [`PatternStyle`](/slides/python-net/ko/aspose.slides/patternstyle). |
| [`fore_color`](/slides/python-net/ko/aspose.slides/ipatternformat/fore_color/) | 전경 패턴 색상을 반환합니다.<br/>            읽기 전용 [`IColorFormat`](/slides/python-net/ko/aspose.slides/icolorformat). |
| [`back_color`](/slides/python-net/ko/aspose.slides/ipatternformat/back_color/) | 배경 패턴 색상을 반환합니다.<br/>            읽기 전용 [`IColorFormat`](/slides/python-net/ko/aspose.slides/icolorformat). |
