## NormalViewProperties 클래스

일반 보기 속성을 나타냅니다. 일반 보기에는 슬라이드 자체, 측면 콘텐츠 영역, 하단 콘텐츠 영역의 세 가지 콘텐츠 영역이 포함됩니다.

NormalViewProperties 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`show_outline_icons`](/slides/python-net/ko/aspose.slides/normalviewproperties/show_outline_icons/) | 일반 보기 모드의 콘텐츠 영역 중 어느 하나에서 개요 콘텐츠를 표시할 경우 아이콘을 표시해야 하는지 지정합니다.<br/>            읽기/쓰기 **bool**. |
| [`snap_vertical_splitter`](/slides/python-net/ko/aspose.slides/normalviewproperties/snap_vertical_splitter/) | 측면 영역이 충분히 작을 때 수직 분할기가 최소화된 상태로 스냅해야 하는지 지정합니다.<br/>            읽기/쓰기 **bool**. |
| [`vertical_bar_state`](/slides/python-net/ko/aspose.slides/normalviewproperties/vertical_bar_state/) | 수직 분할 막대가 표시되어야 할 상태를 지정합니다.<br/>            수직 분할 막대는 슬라이드와 측면 콘텐츠 영역을 구분합니다. |
| [`horizontal_bar_state`](/slides/python-net/ko/aspose.slides/normalviewproperties/horizontal_bar_state/) | 수평 분할 막대가 표시되어야 할 상태를 지정합니다.<br/>            수평 분할 막대는 슬라이드와 슬라이드 아래 콘텐츠 영역을 구분합니다. |
| [`prefer_single_view`](/slides/python-net/ko/aspose.slides/normalviewproperties/prefer_single_view/) | 사용자가 세 개의 콘텐츠 영역이 있는 표준 일반 보기 대신 전체 창 단일 콘텐츠 영역을 보기를 선호하는지 여부를 지정합니다. 활성화된 경우 응용 프로그램은 전체 창에 콘텐츠 영역 중 하나를 표시하도록 선택할 수 있습니다.<br/>            읽기/쓰기 **bool**. |
| [`restored_left`](/slides/python-net/ko/aspose.slides/normalviewproperties/restored_left/) | 이 요소는 영역이 가변 복원 크기(최소화되지도 않고 최대화되지도 않음)일 때 일반 보기의 측면 콘텐츠 영역 크기를 지정합니다.<br/>            읽기 전용 [`INormalViewRestoredProperties`](/slides/python-net/ko/aspose.slides/inormalviewrestoredproperties). |
| [`restored_top`](/slides/python-net/ko/aspose.slides/normalviewproperties/restored_top/) | 이 요소는 영역이 가변 복원 크기(최소화되지도 않고 최대화되지도 않음)일 때 일반 보기의 상단 슬라이드 영역 크기를 지정합니다.<br/>            읽기 전용 [`INormalViewRestoredProperties`](/slides/python-net/ko/aspose.slides/inormalviewrestoredproperties). |
