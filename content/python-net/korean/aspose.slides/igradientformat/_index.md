## IGradientFormat 클래스

그라디언트 형식을 나타냅니다.

IGradientFormat 유형은 다음 멤버를 제공합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`tile_flip`](/slides/python-net/ko/aspose.slides/igradientformat/tile_flip/) | 그라디언트의 뒤집기 모드를 반환하거나 설정합니다.<br/> 읽기/쓰기 [`TileFlip`](/slides/python-net/ko/aspose.slides/tileflip). |
| [`gradient_direction`](/slides/python-net/ko/aspose.slides/igradientformat/gradient_direction/) | 그라디언트 스타일을 반환하거나 설정합니다.<br/> 읽기/쓰기 [`GradientDirection`](/slides/python-net/ko/aspose.slides/gradientdirection). |
| [`linear_gradient_angle`](/slides/python-net/ko/aspose.slides/igradientformat/linear_gradient_angle/) | 그라디언트의 각도를 반환하거나 설정합니다.<br/> 읽기/쓰기 **float**. |
| [`linear_gradient_scaled`](/slides/python-net/ko/aspose.slides/igradientformat/linear_gradient_scaled/) | 그라디언트가 스케일링되는지 여부를 결정합니다.<br/> 읽기/쓰기 [`NullableBool`](/slides/python-net/ko/aspose.slides/nullablebool). |
| [`gradient_shape`](/slides/python-net/ko/aspose.slides/igradientformat/gradient_shape/) | 그라디언트의 모양을 반환하거나 설정합니다.<br/> 읽기/쓰기 [`GradientShape`](/slides/python-net/ko/aspose.slides/gradientshape). |
| [`gradient_stops`](/slides/python-net/ko/aspose.slides/igradientformat/gradient_stops/) | 그라디언트 정지점 컬렉션을 반환합니다.<br/> 읽기 전용 [`IGradientStopCollection`](/slides/python-net/ko/aspose.slides/igradientstopcollection). |
