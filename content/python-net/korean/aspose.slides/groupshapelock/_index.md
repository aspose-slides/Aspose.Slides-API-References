## GroupShapeLock 클래스

부모 GroupShape에서 비활성화된 작업을 결정합니다.

**상속:**[`GroupShapeLock`](/slides/python-net/ko/aspose.slides/groupshapelock) → [`BaseShapeLock`](/slides/python-net/ko/aspose.slides/baseshapelock)

GroupShapeLock 형식은 다음 구성원을 노출합니다.

## 속성

| 속성 | 설명 |
| :- | :- |
| [`no_locks`](/slides/python-net/ko/aspose.slides/groupshapelock/no_locks/) | 모든 lock-flags가 비활성화된 경우 true를 반환합니다.<br/>            읽기 전용 **bool**. |
| [`grouping_locked`](/slides/python-net/ko/aspose.slides/groupshapelock/grouping_locked/) | 이 형태를 그룹에 추가하는 것이 금지되는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`ungrouping_locked`](/slides/python-net/ko/aspose.slides/groupshapelock/ungrouping_locked/) | 이 groupshape를 분할하는 것이 금지되는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`select_locked`](/slides/python-net/ko/aspose.slides/groupshapelock/select_locked/) | 이 형태를 선택하는 것이 금지되는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`rotation_locked`](/slides/python-net/ko/aspose.slides/groupshapelock/rotation_locked/) | 이 형태의 회전 각도를 변경하는 것이 금지되는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/ko/aspose.slides/groupshapelock/aspect_ratio_locked/) | 크기 조정 시 형태가 종횡비를 유지해야 하는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`position_locked`](/slides/python-net/ko/aspose.slides/groupshapelock/position_locked/) | 이 형태를 이동하는 것이 금지되는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`size_locked`](/slides/python-net/ko/aspose.slides/groupshapelock/size_locked/) | 이 형태의 크기 조정을 금지하는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
