## parent_group 속성
shape가 그룹화된 경우 parent GroupShape 객체를 반환합니다. 그렇지 않으면 None을 반환합니다.
            읽기 전용 [`IGroupShape`](/slides/python-net/ko/aspose.slides/igroupshape).
