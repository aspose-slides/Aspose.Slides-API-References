## external_url_original 속성
이 구간에 대해 실제 내용과 무관하게 설정된 하이퍼링크를 나타냅니다.
            
            PowerPoint는 구간 내 링크와 해당 텍스트에 대해 특별히 동작합니다. 하이퍼링크 텍스트를 유효한 URL 형식으로 생성하도록 허용합니다, 실제 주소와는 다르게.
            이 경우, 편집 창에서 링크를 볼 때 텍스트 구간에 맞게 변경됩니다.
            원래 하이퍼링크 값을 나타냅니다.
