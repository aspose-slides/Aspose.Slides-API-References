## TextSearchOptions 클래스

Presentation, Slide 또는 TextFrame에서 텍스트를 검색하는 데 사용할 수 있는 옵션을 나타냅니다.

TextSearchOptions 유형은 다음 멤버를 노출합니다:

## 생성자

| 생성자 | 설명 |
| :- | :- |
| [`__init__(self)`](/slides/python-net/ko/aspose.slides/textsearchoptions/__init__/#) | 새 기본 텍스트 검색 옵션을 생성합니다. |

## 속성

| 속성 | 설명 |
| :- | :- |
| [`case_sensitive`](/slides/python-net/ko/aspose.slides/textsearchoptions/case_sensitive/) | true 로 설정하면 대소문자 구분 검색을 사용하고, false 로 설정하면 그렇지 않습니다.<br/>            읽기/쓰기 **bool**. |
| [`whole_words_only`](/slides/python-net/ko/aspose.slides/textsearchoptions/whole_words_only/) | true 로 설정하면 전체 단어만 일치하고, false 로 설정하면 그렇지 않습니다.<br/>            읽기/쓰기 **bool**. |
| [`include_notes`](/slides/python-net/ko/aspose.slides/textsearchoptions/include_notes/) | `true` 로 설정하면 슬라이드 노트([`NotesSlide`](/slides/python-net/ko/aspose.slides/notesslide))에 포함된 텍스트를 텍스트 검색, 교체 또는 강조 작업 시 포함합니다.<br/>            기본값은 `false` 입니다. |
