## IFillFormatEffectiveData 클래스

유효한 채우기 서식 속성을 포함하는 불변 객체입니다.

IFillFormatEffectiveData 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`fill_type`](/slides/python-net/ko/aspose.slides/ifillformateffectivedata/fill_type/) | 채우기 유형을 반환합니다.<br/>            읽기 전용 [`FillType`](/slides/python-net/ko/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/ko/aspose.slides/ifillformateffectivedata/solid_fill_color/) | 채우기 색상을 반환합니다.<br/>            읽기 전용 **aspose.slides.Color**. |
| [`solid_fill_scheme_color`](/slides/python-net/ko/aspose.slides/ifillformateffectivedata/solid_fill_scheme_color/) | 색 구성표에 의해 정의된 채우기 색상을 가져옵니다.<br/>            [`SchemeColor.NOT_DEFINED`](/slides/python-net/ko/aspose.slides/schemecolor/NOT_DEFINED) 값은 [`IFillFormatEffectiveData.solid_fill_color`](/slides/python-net/ko/aspose.slides/ifillformateffectivedata/solid_fill_color) <br/>            색 구성표 색상이 아님을 나타냅니다.<br/>            읽기 전용 [`SchemeColor`](/slides/python-net/ko/aspose.slides/schemecolor). |
| [`gradient_format`](/slides/python-net/ko/aspose.slides/ifillformateffectivedata/gradient_format/) | 그라데이션 채우기 형식을 반환합니다.<br/>            읽기 전용 [`IGradientFormatEffectiveData`](/slides/python-net/ko/aspose.slides/igradientformateffectivedata). |
| [`pattern_format`](/slides/python-net/ko/aspose.slides/ifillformateffectivedata/pattern_format/) | 패턴 채우기 형식을 반환합니다.<br/>            읽기 전용 [`IPatternFormatEffectiveData`](/slides/python-net/ko/aspose.slides/ipatternformateffectivedata). |
| [`picture_fill_format`](/slides/python-net/ko/aspose.slides/ifillformateffectivedata/picture_fill_format/) | 그림 채우기 형식을 반환합니다.<br/>            읽기 전용 [`IPictureFillFormatEffectiveData`](/slides/python-net/ko/aspose.slides/ipicturefillformateffectivedata). |
| [`rotate_with_shape`](/slides/python-net/ko/aspose.slides/ifillformateffectivedata/rotate_with_shape/) | 채우기가 형태와 함께 회전되어야 하는지 여부를 결정합니다.<br/>            읽기 전용 **bool**. |


### 비고

이 인터페이스는 [`IFillFormat`](/slides/python-net/ko/aspose.slides/ifillformat) 인터페이스와 함께 사용되어 상속이 적용된 유효한 서식 값을 반환합니다.
