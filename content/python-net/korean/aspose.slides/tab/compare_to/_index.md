## compare_to(self, obj) {#any}
현재 인스턴스를 동일 유형의 다른 객체와 비교합니다.

### 반환값

비교 대상들의 상대 순서를 나타내는 32비트 정수입니다.
            반환값은 다음과 같은 의미를 가집니다:
            
*  < 0 - 이 인스턴스는 obj보다 작습니다. = 0 - 이 인스턴스는 obj와 같습니다. > 0 - 이 인스턴스는 obj보다 큽니다.

*  < 0 - 이 인스턴스는 obj보다 작습니다. = 0 - 이 인스턴스는 obj와 같습니다. > 0 - 이 인스턴스는 obj보다 큽니다.

*  < 0 - 이 인스턴스는 obj보다 작습니다. = 0 - 이 인스턴스는 obj와 같습니다. > 0 - 이 인스턴스는 obj보다 큽니다.
