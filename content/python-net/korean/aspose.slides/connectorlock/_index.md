## ConnectorLock class

부모 Connector에서 비활성화된 작업을 결정합니다.

**Inheritance:**[`ConnectorLock`](/slides/python-net/ko/aspose.slides/connectorlock) → [`BaseShapeLock`](/slides/python-net/ko/aspose.slides/baseshapelock)

ConnectorLock 유형은 다음 멤버를 제공합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`no_locks`](/slides/python-net/ko/aspose.slides/connectorlock/no_locks/) | 모든 lock-flags가 비활성화된 경우 true를 반환합니다.<br/>            읽기 전용 **bool**. |
| [`grouping_locked`](/slides/python-net/ko/aspose.slides/connectorlock/grouping_locked/) | 이 도형을 그룹에 추가하는 것이 금지되는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`select_locked`](/slides/python-net/ko/aspose.slides/connectorlock/select_locked/) | 이 도형을 선택하는 것이 금지되는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`rotate_locked`](/slides/python-net/ko/aspose.slides/connectorlock/rotate_locked/) | 이 도형의 회전 각도를 변경하는 것이 금지되는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/ko/aspose.slides/connectorlock/aspect_ratio_locked/) | 크기 조정 시 도형이 가로세로 비율을 유지해야 하는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`position_move`](/slides/python-net/ko/aspose.slides/connectorlock/position_move/) | 이 도형을 이동하는 것이 금지되는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`size_locked`](/slides/python-net/ko/aspose.slides/connectorlock/size_locked/) | 이 도형을 크기 조정하는 것이 금지되는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`edit_points_locked`](/slides/python-net/ko/aspose.slides/connectorlock/edit_points_locked/) | 이 도형의 윤곽을 직접 변경하는 것이 금지되는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`adjust_handles_locked`](/slides/python-net/ko/aspose.slides/connectorlock/adjust_handles_locked/) | 조정 값을 변경하는 것이 금지되는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`arrowheads_locked`](/slides/python-net/ko/aspose.slides/connectorlock/arrowheads_locked/) | 화살촉을 변경하는 것이 금지되는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`shape_type_locked`](/slides/python-net/ko/aspose.slides/connectorlock/shape_type_locked/) | 도형 유형을 변경하는 것이 금지되는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
