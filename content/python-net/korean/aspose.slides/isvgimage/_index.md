## ISvgImage 클래스

SVG 이미지를 나타냅니다.

ISvgImage 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`svg_content`](/slides/python-net/ko/aspose.slides/isvgimage/svg_content/) | SVG 콘텐츠를 반환합니다.<br/>            읽기 전용 **str**. |
| [`svg_data`](/slides/python-net/ko/aspose.slides/isvgimage/svg_data/) | SVG 데이터를 반환합니다.<br/>            읽기 전용 **int**[]. |
| [`external_resource_resolver`](/slides/python-net/ko/aspose.slides/isvgimage/external_resource_resolver/) | SVG 문서 가져오기 중 외부 리소스를 해결하는 데 사용되는 콜백 인터페이스를 반환합니다.<br/>            읽기 전용 **IExternalResourceResolver**. |
| [`base_uri`](/slides/python-net/ko/aspose.slides/isvgimage/base_uri/) | 지정된 SVG의 기본 URI를 반환합니다. 상대 링크를 해결하는 데 사용됩니다.<br/>            읽기 전용 **str**. |
