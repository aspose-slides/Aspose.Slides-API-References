## IFontsEffectiveData 클래스

효과적인 글꼴 집합을 포함하는 불변 객체입니다.

IFontsEffectiveData 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`latin_font`](/slides/python-net/ko/aspose.slides/ifontseffectivedata/latin_font/) | 라틴 글꼴을 반환합니다.<br/>            읽기 전용 [`IFontData`](/slides/python-net/ko/aspose.slides/ifontdata). |
| [`east_asian_font`](/slides/python-net/ko/aspose.slides/ifontseffectivedata/east_asian_font/) | 동아시아 글꼴을 반환합니다.<br/>            읽기 전용 [`IFontData`](/slides/python-net/ko/aspose.slides/ifontdata). |
| [`complex_script_font`](/slides/python-net/ko/aspose.slides/ifontseffectivedata/complex_script_font/) | 복합 스크립트 글꼴을 반환합니다.<br/>            읽기 전용 [`IFontData`](/slides/python-net/ko/aspose.slides/ifontdata). |
