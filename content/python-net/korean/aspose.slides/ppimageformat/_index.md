## PPImageFormat 열거형

이미지 형식. 이 열거형은 `System.Drawing.Imaging.ImageFormat` 클래스를 대체합니다. COM 호환성을 위해 필요합니다.

PPImageFormat 유형은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| BMP | 비트맵 (BMP) 이미지 형식을 가져옵니다. |
| EMF | 향상된 메타파일 (EMF) 이미지 형식을 가져옵니다. |
| EXIF | 교환 가능한 이미지 파일 (Exif) 형식을 가져옵니다. |
| GIF | 그래픽 교환 형식 (GIF) 이미지 형식을 가져옵니다. |
| ICON | Windows 아이콘 이미지 형식을 가져옵니다. |
| JPEG | Joint Photographic Experts Group (JPEG) 이미지 형식을 가져옵니다. |
| MEMORY_BMP | 메모리 내 비트맵 형식을 가져옵니다. |
| PNG | W3C 포터블 네트워크 그래픽스 (PNG) 이미지 형식을 가져옵니다. |
| TIFF | Tagged Image File Format (TIFF) 이미지 형식을 가져옵니다. |
| WMF | Windows 메타파일 (WMF) 이미지 형식을 가져옵니다. |
