## VideoPlayModePreset 열거형

비디오가 재생되는 방식을 정의하는 상수입니다.

VideoPlayModePreset 타입은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| MIXED |  |
| AUTO | 자동으로 재생합니다. |
| ON_CLICK | 비디오 프레임을 클릭했을 때만 재생합니다. |
| ALL_SLIDES | 모든 슬라이드에서 재생합니다. |
| IN_CLICK_SEQUENCE | 클릭과 함께 자동으로 재생합니다. |
