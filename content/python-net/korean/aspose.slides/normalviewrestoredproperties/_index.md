## NormalViewRestoredProperties 클래스

정상 보기에서 슬라이드 영역의 크기((복원된 상단의 자식일 때 너비, 복원된 왼쪽의 자식일 때 높이)를 지정하며, 영역이 가변 복원 크기(축소되지도 최대화되지도 않음)일 때 적용됩니다.

NormalViewRestoredProperties 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`dimension_size`](/slides/python-net/ko/aspose.slides/normalviewrestoredproperties/dimension_size/) | 슬라이드 영역의 크기를 지정합니다 (RestoredTop의 자식일 때 너비, RestoredLeft의 자식일 때 높이).<br/>            읽기/쓰기 **float**. |
| [`auto_adjust`](/slides/python-net/ko/aspose.slides/normalviewrestoredproperties/auto_adjust/) | 창 크기를 조정하면서 뷰를 포함하는 창의 새 크기에 맞게 측면 콘텐츠 영역의 크기가 보상되어야 하는지 여부를 지정합니다.<br/>            읽기/쓰기 **bool**. |
