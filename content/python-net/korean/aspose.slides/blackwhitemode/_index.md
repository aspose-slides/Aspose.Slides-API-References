## BlackWhiteMode 열거형

색상이 있는 도형을 흑백으로 변환하는 방식을 결정합니다.

BlackWhiteMode 타입은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| NOT_DEFINED | 속성이 설정되지 않았습니다 |
| COLOR | 객체가 일반 색상으로 렌더링됩니다 |
| AUTOMATIC | 객체가 자동 색상으로 렌더링됩니다 |
| GRAY | 객체가 회색 색상으로 렌더링됩니다 |
| LIGHT_GRAY | 객체가 밝은 회색 색상으로 렌더링됩니다 |
| INVERSE_GRAY | 객체가 역 회색 색상으로 렌더링됩니다 |
| GRAY_WHITE | 객체가 회색 및 흰색 색상으로 렌더링됩니다 |
| BLACK_GRAY | 객체가 검정 및 회색 색상으로 렌더링됩니다 |
| BLACK_WHITE | 객체가 검정 및 흰색 색상으로 렌더링됩니다 |
| BLACK | 객체가 오직 검정 색상으로만 렌더링됩니다 |
| WHITE | 객체가 흰색 색상으로 렌더링됩니다 |
| HIDDEN | 객체가 렌더링되지 않습니다 |
