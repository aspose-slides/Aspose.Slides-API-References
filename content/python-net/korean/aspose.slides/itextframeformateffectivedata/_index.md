## ITextFrameFormatEffectiveData 클래스

유효한 텍스트 프레임 서식 속성을 포함하는 불변 객체입니다.

ITextFrameFormatEffectiveData 형식은 다음 멤버를 공개합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`text_style`](/slides/python-net/ko/aspose.slides/itextframeformateffectivedata/text_style/) | 유효한 텍스트의 스타일을 반환합니다.<br/>            읽기 전용 [`ITextStyleEffectiveData`](/slides/python-net/ko/aspose.slides/itextstyleeffectivedata). |
| [`margin_left`](/slides/python-net/ko/aspose.slides/itextframeformateffectivedata/margin_left/) | 텍스트 프레임에서 왼쪽 여백(포인트)을 반환합니다.<br/>            읽기 전용 **float**. |
| [`margin_right`](/slides/python-net/ko/aspose.slides/itextframeformateffectivedata/margin_right/) | 텍스트 프레임에서 오른쪽 여백(포인트)을 반환합니다.<br/>            읽기 전용 **float**. |
| [`margin_top`](/slides/python-net/ko/aspose.slides/itextframeformateffectivedata/margin_top/) | 텍스트 프레임에서 상단 여백(포인트)을 반환합니다.<br/>            읽기 전용 **float**. |
| [`margin_bottom`](/slides/python-net/ko/aspose.slides/itextframeformateffectivedata/margin_bottom/) | 텍스트 프레임에서 하단 여백(포인트)을 반환합니다.<br/>            읽기 전용 **float**. |
| [`wrap_text`](/slides/python-net/ko/aspose.slides/itextframeformateffectivedata/wrap_text/) | 텍스트가 텍스트 프레임의 여백에서 줄바꿈되는지 여부를 반환합니다.<br/>            읽기 전용 **bool**. |
| [`anchoring_type`](/slides/python-net/ko/aspose.slides/itextframeformateffectivedata/anchoring_type/) | 텍스트 프레임에서 수직 앵커 텍스트를 반환합니다.<br/>            읽기 전용 [`TextAnchorType`](/slides/python-net/ko/aspose.slides/textanchortype). |
| [`center_text`](/slides/python-net/ko/aspose.slides/itextframeformateffectivedata/center_text/) | 텍스트가 박스 안에서 가로로 가운데 정렬되어야 하는지 여부를 반환합니다.<br/>            읽기 전용 **bool**. |
| [`text_vertical_type`](/slides/python-net/ko/aspose.slides/itextframeformateffectivedata/text_vertical_type/) | 텍스트 방향을 반환합니다.<br/>            읽기 전용 [`TextVerticalType`](/slides/python-net/ko/aspose.slides/textverticaltype). |
| [`autofit_type`](/slides/python-net/ko/aspose.slides/itextframeformateffectivedata/autofit_type/) | 텍스트 자동 맞춤 모드를 반환합니다.<br/>            읽기 전용 [`TextAutofitType`](/slides/python-net/ko/aspose.slides/textautofittype). |
| [`column_count`](/slides/python-net/ko/aspose.slides/itextframeformateffectivedata/column_count/) | 경계 사각형 안에서 텍스트 열 수를 지정합니다.<br/>            읽기 전용 **int**. |
| [`column_spacing`](/slides/python-net/ko/aspose.slides/itextframeformateffectivedata/column_spacing/) | 텍스트 영역에서 텍스트 열 사이의 간격(포인트)을 지정합니다.<br/>            읽기 전용 **float**. |


### 비고

이 인터페이스는 [`ITextFrameFormat`](/slides/python-net/ko/aspose.slides/itextframeformat) 인터페이스와 함께 사용되어 상속이 적용된 유효한 서식 값을 반환합니다.
