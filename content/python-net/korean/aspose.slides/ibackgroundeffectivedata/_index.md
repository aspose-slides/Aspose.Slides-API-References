## IBackgroundEffectiveData 클래스

유효한 배경 속성을 포함하는 불변 객체입니다.

IBackgroundEffectiveData 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`fill_format`](/slides/python-net/ko/aspose.slides/ibackgroundeffectivedata/fill_format/) | 유효한 채우기 형식을 반환합니다.<br/>            읽기 전용 [`IFillFormatEffectiveData`](/slides/python-net/ko/aspose.slides/ifillformateffectivedata). |
| [`effect_format`](/slides/python-net/ko/aspose.slides/ibackgroundeffectivedata/effect_format/) | 유효한 효과 형식을 반환합니다.<br/>            읽기 전용 [`IEffectFormatEffectiveData`](/slides/python-net/ko/aspose.slides/ieffectformateffectivedata). |


### 비고

이 인터페이스는 [`IBackground`](/slides/python-net/ko/aspose.slides/ibackground) 인터페이스와 함께 사용되어 상속이 적용된 유효한 서식 값을 반환합니다.
