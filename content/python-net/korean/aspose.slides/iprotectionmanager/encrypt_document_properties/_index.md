## encrypt_document_properties 속성
This property makes sense, if presentation is password protected.
            프레젠테이션이 암호로 보호된 경우 이 속성은 의미가 있습니다.
            true이면 프레젠테이션 파일에서 문서 속성이 암호화됩니다.
            false이면 프레젠테이션이 암호화된 동안 문서 속성은 공개됩니다.
            읽기/쓰기 **bool**.
