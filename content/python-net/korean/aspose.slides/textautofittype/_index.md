## TextAutofitType 열거형

텍스트 자동 맞춤 모드를 나타냅니다.

TextAutofitType 유형은 다음 멤버를 제공합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| NOT_DEFINED | 정의되지 않음. |
| NONE | 자동 맞춤 없음. |
| NORMAL | 일반 자동 맞춤. 글꼴 크기와 줄 간격이 도형에 맞게 축소됩니다. |
| SHAPE | 도형 자동 맞춤. 도형 크기가 텍스트에 맞게 변경됩니다. |
