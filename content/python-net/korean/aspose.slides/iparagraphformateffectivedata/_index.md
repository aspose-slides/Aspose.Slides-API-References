## IParagraphFormatEffectiveData 클래스

효과적인 단락 서식 속성을 포함하는 불변 객체입니다.

IParagraphFormatEffectiveData 형식은 다음 멤버를 노출합니다:

## 속성

| Property | Description |
| :- | :- |
| [`bullet`](/slides/python-net/ko/aspose.slides/iparagraphformateffectivedata/bullet/) | 단락의 글머리표 형식을 반환합니다.<br/>            읽기 전용 [`IBulletFormatEffectiveData`](/slides/python-net/ko/aspose.slides/ibulletformateffectivedata). |
| [`depth`](/slides/python-net/ko/aspose.slides/iparagraphformateffectivedata/depth/) | 단락의 깊이를 반환합니다.<br/>            읽기 전용 **int**. |
| [`alignment`](/slides/python-net/ko/aspose.slides/iparagraphformateffectivedata/alignment/) | 단락의 텍스트 정렬을 반환합니다.<br/>            읽기 전용 [`TextAlignment`](/slides/python-net/ko/aspose.slides/textalignment). |
| [`space_within`](/slides/python-net/ko/aspose.slides/iparagraphformateffectivedata/space_within/) | 단락의 기준선 사이의 간격을 반환합니다.<br/>            읽기 전용 **float**. |
| [`space_before`](/slides/python-net/ko/aspose.slides/iparagraphformateffectivedata/space_before/) | 단락의 첫 번째 줄 전에 있는 공간의 양을 반환합니다.<br/>            읽기 전용 **float**. |
| [`space_after`](/slides/python-net/ko/aspose.slides/iparagraphformateffectivedata/space_after/) | 단락의 마지막 줄 후의 공간 양을 반환합니다.<br/>            읽기 전용 **float**. |
| [`east_asian_line_break`](/slides/python-net/ko/aspose.slides/iparagraphformateffectivedata/east_asian_line_break/) | 단락에서 동아시아 줄 바꿈이 사용되는지 여부를 결정합니다.<br/>            읽기 전용 **bool**. |
| [`right_to_left`](/slides/python-net/ko/aspose.slides/iparagraphformateffectivedata/right_to_left/) | 단락에서 오른쪽에서 왼쪽으로 쓰기가 사용되는지 여부를 결정합니다.<br/>            읽기 전용 **bool**. |
| [`latin_line_break`](/slides/python-net/ko/aspose.slides/iparagraphformateffectivedata/latin_line_break/) | 단락에서 라틴 줄 바꿈이 사용되는지 여부를 결정합니다.<br/>            읽기 전용 **bool**. |
| [`hanging_punctuation`](/slides/python-net/ko/aspose.slides/iparagraphformateffectivedata/hanging_punctuation/) | 단락에서 행잉 구두점이 사용되는지 여부를 결정합니다.<br/>            읽기 전용 **bool**. |
| [`margin_left`](/slides/python-net/ko/aspose.slides/iparagraphformateffectivedata/margin_left/) | 단락의 왼쪽 여백을 반환합니다.<br/>            읽기 전용 **float**. |
| [`margin_right`](/slides/python-net/ko/aspose.slides/iparagraphformateffectivedata/margin_right/) | 단락의 오른쪽 여백을 반환합니다.<br/>            읽기 전용 **float**. |
| [`indent`](/slides/python-net/ko/aspose.slides/iparagraphformateffectivedata/indent/) | 단락의 첫 번째 줄 들여쓰기/행잉 들여쓰기를 반환합니다. 행잉 들여쓰기는 음수 값으로 정의될 수 있습니다.<br/>            읽기 전용 **float**. |
| [`default_tab_size`](/slides/python-net/ko/aspose.slides/iparagraphformateffectivedata/default_tab_size/) | 기본 탭 크기를 반환합니다.<br/>            읽기 전용 **float**. |
| [`tabs`](/slides/python-net/ko/aspose.slides/iparagraphformateffectivedata/tabs/) | 단락의 탭을 반환합니다.<br/>            읽기 전용 [`ITabEffectiveData`](/slides/python-net/ko/aspose.slides/itabeffectivedata)[]. |
| [`font_alignment`](/slides/python-net/ko/aspose.slides/iparagraphformateffectivedata/font_alignment/) | 단락의 글꼴 정렬을 반환합니다.<br/>            읽기 전용 [`FontAlignment`](/slides/python-net/ko/aspose.slides/fontalignment). |
