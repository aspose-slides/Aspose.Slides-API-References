## IPictureFillFormat 클래스

IPictureFillFormat 형식은 다음 멤버를 노출합니다:

| :- | :- |

| [`picture_fill_mode`](/slides/python-net/ko/aspose.slides/ipicturefillformat/picture_fill_mode/) | 그림 채우기 모드를 반환하거나 설정합니다.<br/>            읽기/쓰기 [`PictureFillMode`](/slides/python-net/ko/aspose.slides/picturefillmode). |
| [`picture`](/slides/python-net/ko/aspose.slides/ipicturefillformat/picture/) | 그림을 반환합니다.<br/>            읽기 전용 [`ISlidesPicture`](/slides/python-net/ko/aspose.slides/islidespicture). |

| [`tile_alignment`](/slides/python-net/ko/aspose.slides/ipicturefillformat/tile_alignment/) | 텍스처가 도형 내에서 정렬되는 방식을 반환하거나 설정합니다. 이 설정은 텍스처 패턴의 시작점과 도형 전체에 걸쳐 반복되는 방식을 제어합니다.<br/>            읽기/쓰기 [`RectangleAlignment`](/slides/python-net/ko/aspose.slides/rectanglealignment). |
