## ISensitivityLabel 클래스

Microsoft Purview Information Protection의 감도 레이블을 나타냅니다.

ISensitivityLabel 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`id`](/slides/python-net/ko/aspose.slides/isensitivitylabel/id/) | 감도 레이블 ID를 반환하거나 설정합니다.<br/>            읽기/쓰기 **str**. |
| [`site_id`](/slides/python-net/ko/aspose.slides/isensitivitylabel/site_id/) | 감도 레이블을 설명하는 감도 레이블 정책에 해당하는 Azure Active Directory (Azure AD) 사이트 식별자를 반환하거나 설정합니다.<br/>            읽기/쓰기 **System.Guid**. |
| [`is_enabled`](/slides/python-net/ko/aspose.slides/isensitivitylabel/is_enabled/) | 감도 레이블이 활성화되어 있는지 나타냅니다. |
| [`is_removed`](/slides/python-net/ko/aspose.slides/isensitivitylabel/is_removed/) | 감도 레이블이 제거되었는지 나타냅니다. |
| [`assignment_method_type`](/slides/python-net/ko/aspose.slides/isensitivitylabel/assignment_method_type/) | 감도 레이블의 할당 방법을 반환하거나 설정합니다.<br/>            읽기/쓰기 [`SensitivityLabelAssignmentType`](/slides/python-net/ko/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/ko/aspose.slides/isensitivitylabel/content_mark_types/) | 파일에 적용되어야 하는 콘텐츠 표시 유형 목록을 반환합니다. |
