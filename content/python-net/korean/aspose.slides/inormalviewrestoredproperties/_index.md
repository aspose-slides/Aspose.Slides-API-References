## INormalViewRestoredProperties 클래스

정규 보기에서 슬라이드 영역의 크기를 지정합니다((restoredTop의 자식일 경우 너비, restoredLeft의 자식일 경우 높이)이며, 영역이 가변 복원 크기(축소되지도 않고 최대화되지도 않음)인 경우에 해당합니다.

INormalViewRestoredProperties 유형은 다음 멤버를 노출합니다:

## 속성

| Property | Description |
| :- | :- |
| [`dimension_size`](/slides/python-net/ko/aspose.slides/inormalviewrestoredproperties/dimension_size/) | 슬라이드 영역의 크기를 지정합니다 (RestoredTop의 자식일 경우 너비, RestoredLeft의 자식일 경우 높이).<br/>            읽기/쓰기 **float**.<br/>            값이 0보다 작거나 100보다 큰 경우 예외가 발생합니다. |
| [`auto_adjust`](/slides/python-net/ko/aspose.slides/inormalviewrestoredproperties/auto_adjust/) | 뷰를 포함하는 윈도우의 크기를 조정할 때, 사이드 콘텐츠 영역의 크기가 새로운 크기를 보정해야 하는지 여부를 지정합니다.<br/>            읽기/쓰기 **bool**. |
