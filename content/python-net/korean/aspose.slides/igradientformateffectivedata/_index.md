## IGradientFormatEffectiveData class

유효 그라데이션 채우기 속성을 포함하는 불변 객체.

IGradientFormatEffectiveData 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`tile_flip`](/slides/python-net/ko/aspose.slides/igradientformateffectivedata/tile_flip/) | 그라데이션의 뒤집기 모드를 반환합니다.<br/>            읽기 전용 [`TileFlip`](/slides/python-net/ko/aspose.slides/tileflip). |
| [`gradient_direction`](/slides/python-net/ko/aspose.slides/igradientformateffectivedata/gradient_direction/) | 그라데이션의 스타일을 반환합니다.<br/>            읽기 전용 [`GradientDirection`](/slides/python-net/ko/aspose.slides/gradientdirection). |
| [`linear_gradient_angle`](/slides/python-net/ko/aspose.slides/igradientformateffectivedata/linear_gradient_angle/) | 그라데이션의 각도를 반환합니다.<br/>            읽기 전용 **float**. |
| [`linear_gradient_scaled`](/slides/python-net/ko/aspose.slides/igradientformateffectivedata/linear_gradient_scaled/) | 그라데이션이 스케일되는지 여부를 결정합니다.<br/>            읽기 전용 **bool**. |
| [`gradient_shape`](/slides/python-net/ko/aspose.slides/igradientformateffectivedata/gradient_shape/) | 그라데이션의 모양을 반환합니다.<br/>            읽기 전용 [`GradientShape`](/slides/python-net/ko/aspose.slides/gradientshape). |
| [`gradient_stops`](/slides/python-net/ko/aspose.slides/igradientformateffectivedata/gradient_stops/) | 그라데이션 정지점들의 컬렉션을 반환합니다.<br/>            읽기 전용 [`IGradientStopCollectionEffectiveData`](/slides/python-net/ko/aspose.slides/igradientstopcollectioneffectivedata). |


### 비고

이 인터페이스는 [`IFillFormatEffectiveData`](/slides/python-net/ko/aspose.slides/ifillformateffectivedata) 및 [`ILineFillFormatEffectiveData`](/slides/python-net/ko/aspose.slides/ilinefillformateffectivedata)의 일부로 사용됩니다.
