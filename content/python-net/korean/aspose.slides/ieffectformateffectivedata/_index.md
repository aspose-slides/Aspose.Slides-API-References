## IEffectFormatEffectiveData 클래스

효과 서식 속성을 포함하는 불변 객체입니다.

IEffectFormatEffectiveData 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`is_no_effects`](/slides/python-net/ko/aspose.slides/ieffectformateffectivedata/is_no_effects/) | 모든 효과가 비활성화된 경우(방금 생성된 기본 EffectFormat 개체) true를 반환합니다.<br/>            읽기 전용 **bool**. |
| [`blur_effect`](/slides/python-net/ko/aspose.slides/ieffectformateffectivedata/blur_effect/) | 블러 효과.<br/>            읽기 전용 [`IBlurEffectiveData`](/slides/python-net/ko/aspose.slides.effects/iblureffectivedata). |
| [`fill_overlay_effect`](/slides/python-net/ko/aspose.slides/ieffectformateffectivedata/fill_overlay_effect/) | 채우기 오버레이 효과.<br/>            읽기 전용 [`IFillOverlayEffectiveData`](/slides/python-net/ko/aspose.slides.effects/ifilloverlayeffectivedata). |
| [`glow_effect`](/slides/python-net/ko/aspose.slides/ieffectformateffectivedata/glow_effect/) | 글로우 효과.<br/>            읽기 전용 [`IGlowEffectiveData`](/slides/python-net/ko/aspose.slides.effects/igloweffectivedata). |
| [`inner_shadow_effect`](/slides/python-net/ko/aspose.slides/ieffectformateffectivedata/inner_shadow_effect/) | 내부 그림자.<br/>            읽기 전용 [`IInnerShadowEffectiveData`](/slides/python-net/ko/aspose.slides.effects/iinnershadoweffectivedata). |
| [`outer_shadow_effect`](/slides/python-net/ko/aspose.slides/ieffectformateffectivedata/outer_shadow_effect/) | 외부 그림자.<br/>            읽기 전용 [`IOuterShadowEffectiveData`](/slides/python-net/ko/aspose.slides.effects/ioutershadoweffectivedata). |
| [`preset_shadow_effect`](/slides/python-net/ko/aspose.slides/ieffectformateffectivedata/preset_shadow_effect/) | 프리셋 그림자.<br/>            읽기 전용 [`IPresetShadowEffectiveData`](/slides/python-net/ko/aspose.slides.effects/ipresetshadoweffectivedata). |
| [`reflection_effect`](/slides/python-net/ko/aspose.slides/ieffectformateffectivedata/reflection_effect/) | 반사.<br/>            읽기 전용 [`IReflectionEffectiveData`](/slides/python-net/ko/aspose.slides.effects/ireflectioneffectivedata). |
| [`soft_edge_effect`](/slides/python-net/ko/aspose.slides/ieffectformateffectivedata/soft_edge_effect/) | 소프트 엣지.<br/>            읽기 전용 [`ISoftEdgeEffectiveData`](/slides/python-net/ko/aspose.slides.effects/isoftedgeeffectivedata). |


### 비고

이 인터페이스는 [`IEffectFormat`](/slides/python-net/ko/aspose.slides/ieffectformat) 인터페이스와 함께 사용되어 상속이 적용된 효과적인 서식 값을 반환합니다.
