## SlideSize 클래스

슬라이드의 크기와 방향을 나타냅니다.

SlideSize 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`size`](/slides/python-net/ko/aspose.slides/slidesize/size/) | 슬라이드 차원을 포인트 단위로 가져옵니다. |
| [`type`](/slides/python-net/ko/aspose.slides/slidesize/type/) | 슬라이드 크기 유형을 가져옵니다. |
| [`orientation`](/slides/python-net/ko/aspose.slides/slidesize/orientation/) | 슬라이드 방향을 가져오거나 설정합니다. |

## 메서드

| 메서드 | 설명 |
| :- | :- |
| [`set_size(self, type, scale_type)`](/slides/python-net/ko/aspose.slides/slidesize/set_size/#slidesizetype-slidesizescaletype) | 유형으로 슬라이드 크기를 설정하고 기존 콘텐츠를 스케일합니다. |
| [`set_size(self, width, height, scale_type)`](/slides/python-net/ko/aspose.slides/slidesize/set_size/#float-float-slidesizescaletype) | 슬라이드 차원을 명시적으로 설정하고 기존 콘텐츠를 스케일합니다. |
