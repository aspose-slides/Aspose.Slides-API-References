## ColorSchemeIndex 열거형

색 구성표에서 인덱스를 나타냅니다.

ColorSchemeIndex 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| DARK1 | 다크 1. |
| LIGHT1 | 라이트 1. |
| DARK2 | 다크 2. |
| LIGHT2 | 라이트 2. |
| ACCENT1 | 강조 1. |
| ACCENT2 | 강조 2. |
| ACCENT3 | 강조 3. |
| ACCENT4 | 강조 4. |
| ACCENT5 | 강조 5. |
| ACCENT6 | 강조 6. |
| HYPERLINK | 하이퍼링크. |
| FOLLOWED_HYPERLINK | 방문한 하이퍼링크. |
