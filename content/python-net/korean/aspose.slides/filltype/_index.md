## FillType 열거형

다양한 시각 객체의 내부 채우기 유형을 지정합니다.

FillType 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| NOT_DEFINED | 채우기 유형이 정의되지 않았습니다. |
| NO_FILL | 채우기가 적용되지 않았습니다. |
| SOLID | 단색으로 채워집니다. |
| GRADIENT | 채우기가 그라디언트입니다. |
| PATTERN | 반복 패턴이 객체를 채우는 데 사용됩니다. |
| PICTURE | 단일 이미지가 객체를 채우는 데 사용됩니다. |
| GROUP | 시각적 객체가 그룹으로부터 채우기 속성을 상속합니다. |
