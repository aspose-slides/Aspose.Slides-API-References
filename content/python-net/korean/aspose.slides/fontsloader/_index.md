## FontsLoader 클래스

사용자가 정의한 커스텀 폰트를 로드하기 위한 클래스입니다.
프레젠테이션 객체를 만들기 전에 사용해야 합니다.

FontsLoader 타입은 다음 멤버를 제공합니다:

## 메서드

| 메서드 | 설명 |
| :- | :- |
| [`load_external_fonts(directories)`](/slides/python-net/ko/aspose.slides/fontsloader/load_external_fonts/#liststr) | 폰트를 찾기 위한 추가 폴더를 추가합니다. |
| [`load_external_font(data)`](/slides/python-net/ko/aspose.slides/fontsloader/load_external_font/#bytes) | 이진 데이터에서 폰트를 추가합니다. |
| [`get_font_folders()`](/slides/python-net/ko/aspose.slides/fontsloader/get_font_folders/#) | 폰트 폴더를 가져옵니다. LoadExternalFonts 메서드로 추가된 폴더와 시스템 폰트 폴더를 반환합니다. |
| [`clear_cache()`](/slides/python-net/ko/aspose.slides/fontsloader/clear_cache/#) | 사용자가 정의한 모든 커스텀 폰트를 해제합니다. |
