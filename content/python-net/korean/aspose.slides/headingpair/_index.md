## HeadingPair 클래스

문서의 'Heading pair' 속성을 나타냅니다.  
그룹 이름과 그룹 내 파트 수를 나타냅니다.

HeadingPair 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`name`](/slides/python-net/ko/aspose.slides/headingpair/name/) | 문서 파트의 그룹 이름을 반환합니다.<br/> 읽기 전용 **str**. |
| [`count`](/slides/python-net/ko/aspose.slides/headingpair/count/) | 그룹 내 파트 수를 반환합니다.<br/> 읽기 전용 **int**. |
