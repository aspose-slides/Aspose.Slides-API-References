## Paragraph 클래스

텍스트 단락을 나타냅니다.

Paragraph 유형은 다음 멤버를 노출합니다:

## 생성자

| 생성자 | 설명 |
| :- | :- |
| [`__init__`](/slides/python-net/ko/aspose.slides/paragraph/__init__/#) | 기본 속성으로 Paragraph 클래스를 새 인스턴스화합니다. |
| [`__init__`](/slides/python-net/ko/aspose.slides/paragraph/__init__/#paragraph) | 새 Paragraph 클래스 인스턴스를 초기화하는 복사 생성자. |

## 속성

| 속성 | 설명 |
| :- | :- |
| [`portions`](/slides/python-net/ko/aspose.slides/paragraph/portions/) | 텍스트 부분의 컬렉션을 반환합니다.<br/>            읽기 전용 [`IPortionCollection`](/slides/python-net/ko/aspose.slides/iportioncollection). |
| [`paragraph_format`](/slides/python-net/ko/aspose.slides/paragraph/paragraph_format/) | 이 단락에 대한 형식 개체를 반환합니다.<br/>            읽기 전용 [`IParagraphFormat`](/slides/python-net/ko/aspose.slides/iparagraphformat). |
| [`text`](/slides/python-net/ko/aspose.slides/paragraph/text/) | 단락의 일반 텍스트를 가져오거나 설정합니다.<br/>            읽기/쓰기 **str**. |
| [`end_paragraph_portion_format`](/slides/python-net/ko/aspose.slides/paragraph/end_paragraph_portion_format/) | 다른 부분이 마지막 부분 뒤에 삽입될 경우 사용될 부분 속성을 지정합니다.<br/>            마지막 부분 뒤에. |
