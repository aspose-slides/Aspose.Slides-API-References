## SensitivityLabelAssignmentType 열거형

민감도 레이블에 대한 할당 방법을 나타냅니다.

SensitivityLabelAssignmentType 형식은 다음 멤버를 노출합니다:

## 필드

| Field | Description |
| :- | :- |
| STANDARD | 사용자가 직접 적용하지 않은 모든 민감도 레이블에 사용됩니다. <br/>            여기에는 기본 레이블 및 자동으로 적용된 레이블이 포함됩니다. |
| PRIVILEGED | 사용자가 직접 적용한 모든 민감도 레이블에 사용됩니다. <br/>            여기에는 수동으로 적용된 민감도 레이블뿐만 아니라 권장되거나 필수적인 레이블링, 또는 사용자가 적용할 민감도 레이블을 선택하는 모든 기능이 포함됩니다. |
