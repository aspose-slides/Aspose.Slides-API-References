## IExcelDataCell 클래스

Excel 통합 문서의 단일 셀을 나타냅니다.

IExcelDataCell 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`value`](/slides/python-net/ko/aspose.slides.excel/iexceldatacell/value/) | Excel 셀에 포함된 값을 가져옵니다.<br/>            읽기 전용 **any**. |
| [`name`](/slides/python-net/ko/aspose.slides.excel/iexceldatacell/name/) | 차트 데이터 셀의 이름을 가져옵니다.<br/>            읽기 전용 **str**. |
| [`row`](/slides/python-net/ko/aspose.slides.excel/iexceldatacell/row/) | 셀이 위치한 워크시트에서 행의 0부터 시작하는 인덱스를 가져옵니다.<br/>            읽기 전용 **int**. |
| [`column`](/slides/python-net/ko/aspose.slides.excel/iexceldatacell/column/) | 셀이 위치한 워크시트에서 열의 0부터 시작하는 인덱스를 가져옵니다.<br/>            읽기 전용 **int**. |
