## HtmlFormatter 클래스

HTML 파일 템플릿을 나타냅니다.

HtmlFormatter 타입은 다음 멤버를 노출합니다:

## 메서드

| 메서드 | 설명 |
| :- | :- |
| [`create_document_formatter(css, show_slide_title)`](/slides/python-net/ko/aspose.slides.export/htmlformatter/create_document_formatter/#str-bool) | 슬라이드가 위아래로 순차적으로 배열된 단순 문서 보기용 HTML 포맷터를 생성하고 반환합니다. |
| [`create_slide_show_formatter(css, show_slide_title)`](/slides/python-net/ko/aspose.slides.export/htmlformatter/create_slide_show_formatter/#str-bool) | 슬라이드가 차례대로 표시되는 단순 슬라이드 쇼 HTML을 위한 HTML 포맷터를 생성하고 반환합니다. |
| [`create_custom_formatter(formatting_controller)`](/slides/python-net/ko/aspose.slides.export/htmlformatter/create_custom_formatter/#ihtmlformattingcontroller) | 사용자 정의 콜백 기반 HTML 생성을 위한 HTML 포맷터를 생성하고 반환합니다. |
