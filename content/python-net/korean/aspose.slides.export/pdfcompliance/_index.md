## PdfCompliance 열거형

PDF 표준 준수 수준을 정의하는 상수입니다.

PdfCompliance 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| PDF15 | 출력 파일은 PDF 1.5 표준을 준수합니다. |
| PDF16 | 출력 파일은 PDF 1.6 표준을 준수합니다. |
| PDF17 | 출력 파일은 PDF 1.7 표준을 준수합니다. |
| PDF_A1B | 출력 파일은 PDF/A-1b 표준을 준수합니다. |
| PDF_A1A | 출력 파일은 PDF/A-1a 표준을 준수합니다. |
| PDF_A2B | 출력 파일은 PDF/A-2b 표준을 준수합니다. |
| PDF_A2A | 출력 파일은 PDF/A-2a 표준을 준수합니다. |
| PDF_A3B | 출력 파일은 PDF/A-3b 표준을 준수합니다. |
| PDF_A3A | 출력 파일은 PDF/A-3a 표준을 준수합니다. |
| PDF_UA | 출력 파일은 PDF/UA 표준을 준수합니다. |
| PDF_A2U | 출력 파일은 PDF/A-2u 표준을 준수합니다. |
