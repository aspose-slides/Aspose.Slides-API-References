## image_size 속성
Specifies size of a generated TIFF image.
            기본값은 0x0이며, 이는 생성된 이미지 크기가 프레젠테이션 슬라이드 크기 값을 기반으로 계산된다는 의미입니다.
            읽기/쓰기 **aspose.slides.Size**.
