## ImagePixelFormat 열거형

생성된 이미지의 픽셀 형식을 지정합니다.

ImagePixelFormat 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| FORMAT_1BPP_INDEXED | 픽셀당 1비트, 인덱스형. |
| FORMAT_4BPP_INDEXED | 픽셀당 4비트, 인덱스형. |
| FORMAT_8BPP_INDEXED | 픽셀당 8비트, 인덱스형. |
| FORMAT_24BPP_RGB | 픽셀당 24비트, RGB. |
| FORMAT_32BPP_ARGB | 픽셀당 32비트, ARGB. |
