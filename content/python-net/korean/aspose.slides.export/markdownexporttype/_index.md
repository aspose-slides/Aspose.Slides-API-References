## MarkdownExportType 열거형

문서를 렌더링하는 유형.

MarkdownExportType 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| SEQUENTIAL | 모든 항목을 별도로 렌더링합니다. 하나씩. |
| TEXT_ONLY | 텍스트만 렌더링합니다. |
| VISUAL | 모든 항목을 렌더링합니다. 그룹화된 항목은 함께 렌더링합니다. |
