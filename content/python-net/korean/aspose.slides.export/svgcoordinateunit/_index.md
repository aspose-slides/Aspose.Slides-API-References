## SvgCoordinateUnit 열거형

CSS2 좌표 단위를 나타내며, SVG 좌표를 정의하는 데 사용됩니다.

SvgCoordinateUnit 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| INCH | 인치 |
| CENTIMETER | 센티미터. |
| MILLIMETER | 밀리미터. |
| POINT | 포인트 (1/72 인치), |
| PICA | 파이카 (1/6 인치). |
| EM | 포함 요소의 글꼴 EM 크기. |
| EX | 포함 요소의 글꼴 EX 크기 (소문자 크기, 일반적으로 "x"). |
| PIXEL | 픽셀 크기. |
| PERCENT | 백분율. |
