## TiffCompressionTypes 열거형

프레젠테이션을 TIFF 형식으로 압축하는 방식을 제어하는 옵션을 제공합니다.

TiffCompressionTypes 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| DEFAULT | 기본 압축 방식(LZW)을 지정합니다. |
| NONE | 압축을 사용하지 않음을 지정합니다. |
| CCITT3 | CCITT3 압축 방식을 지정합니다. |
| CCITT4 | CCITT4 압축 방식을 지정합니다. |
| LZW | LZW 압축 방식(기본)을 지정합니다. |
| RLE | RLE 압축 방식을 지정합니다. |
