## LinkEmbedDecision 열거형

객체가 저장되는 동안 어떻게 처리될지 결정합니다.

LinkEmbedDecision 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| LINK | 객체가 외부에 저장되며, URL로 참조됩니다 |
| EMBED | 가능하면 객체를 생성된 파일에 포함시켜야 합니다. 포함이 불가능한 경우 GetUrl이 호출되며, 결과에 따라 객체가 URL로 참조되거나 무시됩니다. |
| IGNORE | 객체가 무시됩니다. |
