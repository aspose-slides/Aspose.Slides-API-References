## SvgEvent 열거형

SvgEvent 형식은 다음 멤버를 노출합니다.

## 필드

| 필드 | 설명 |
| :- | :- |
| ON_FOCUS_IN | 요소가 포커스를 받았을 때 발생합니다. 예를 들어 텍스트가 선택될 때. |
| ON_FOCUS_OUT | 요소가 포커스를 잃었을 때 발생합니다. 예를 들어 텍스트 선택이 해제될 때. |
| ON_ACTIVATE | 요소가 활성화될 때 발생합니다. 예를 들어 마우스 클릭이나 키 입력 시. |
| ON_CLICK | 포인팅 장치 버튼을 요소 위에서 클릭했을 때 발생합니다. |
| ON_MOUSE_DOWN | 포인팅 장치 버튼을 요소 위에서 눌렀을 때 발생합니다. |
| ON_MOUSE_UP | 포인팅 장치 버튼을 요소 위에서 놓았을 때 발생합니다. |
| ON_MOUSE_OVER | 포인팅 장치가 요소 위로 이동했을 때 발생합니다. |
| ON_MOUSE_MOVE | 포인팅 장치가 요소 위에 있는 동안 이동했을 때 발생합니다. |
| ON_MOUSE_OUT | 포인팅 장치가 요소에서 멀어질 때 발생합니다. |
| ON_LOAD | 사용자 에이전트가 요소와 그 하위 요소 및 렌더링에 필요한 모든 참조 리소스를 완전히 구문 분석했을 때 발생합니다. |
| ON_UNLOAD | DOM 구현이 문서를 창이나 프레임에서 제거할 때 발생합니다. 최상위 svg 요소에만 적용됩니다. |
| ON_ABORT | 요소가 완전히 로드되기 전에 페이지 로딩이 중단될 때 발생합니다. |
| ON_ERROR | 요소가 제대로 로드되지 않거나 스크립트 실행 중 오류가 발생할 때 발생합니다. |
| ON_RESIZE | 문서 뷰가 크기 조정될 때 발생합니다. 최상위 svg 요소에만 적용됩니다. |
| ON_SCROLL | 문서 뷰가 X축, Y축 또는 두 축을 따라 이동될 때 발생합니다. 최상위 svg 요소에만 적용됩니다. |
| ON_ZOOM | 문서 뷰의 확대/축소 수준이 변경될 때 발생합니다. 최상위 svg 요소에만 적용됩니다. |
| ON_BEGIN | 애니메이션 요소가 시작될 때 발생합니다. |
| ON_END | 애니메이션 요소가 끝날 때 발생합니다. |
| ON_REPEAT | 애니메이션 요소가 반복될 때 발생합니다. |
