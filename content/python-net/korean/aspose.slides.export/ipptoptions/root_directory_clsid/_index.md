## root_directory_clsid 속성
루트 디렉터리 항목에 저장된 객체 클래스 GUID (CLSID)를 나타냅니다. COM
            활성화는 문서 응용 프로그램에 사용할 수 있습니다.
            기본값은 '64818D11-4F9B-11CF-86EA-00AA00B929E8'이며, 이는 'Microsoft Powerpoint.Slide.8'에 해당합니다.
