## ISwfOptions 클래스

프레젠테이션을 SWF 형식으로 저장하는 방식을 제어하는 옵션을 제공합니다.

ISwfOptions 형식은 다음 멤버를 노출합니다:

## 속성

| Property | Description |
| :- | :- |
| [`compressed`](/slides/python-net/ko/aspose.slides.export/iswfoptions/compressed/) | 생성된 SWF 문서를 압축할지 여부를 지정합니다.<br/>            기본값은 `true`입니다. |
| [`viewer_included`](/slides/python-net/ko/aspose.slides.export/iswfoptions/viewer_included/) | 생성된 SWF 문서에 통합 문서 뷰어를 포함할지 여부를 지정합니다.<br/>            기본값은 `true`입니다. |
| [`show_page_border`](/slides/python-net/ko/aspose.slides.export/iswfoptions/show_page_border/) | 페이지 주변의 테두리를 표시할지 여부를 지정합니다. 기본값은 true입니다. |
| [`show_hidden_slides`](/slides/python-net/ko/aspose.slides.export/iswfoptions/show_hidden_slides/) | 생성된 문서에 숨겨진 슬라이드를 포함할지 여부를 지정합니다.<br/>            기본값은 `false`입니다. |
| [`show_full_screen`](/slides/python-net/ko/aspose.slides.export/iswfoptions/show_full_screen/) | 전체 화면 버튼을 보이거나 숨깁니다. flashvars에서 재정의할 수 있습니다. 기본값은 true입니다. |
| [`show_page_stepper`](/slides/python-net/ko/aspose.slides.export/iswfoptions/show_page_stepper/) | 페이지 스테퍼를 보이거나 숨깁니다. flashvars에서 재정의할 수 있습니다. 기본값은 true입니다. |
| [`show_search`](/slides/python-net/ko/aspose.slides.export/iswfoptions/show_search/) | 검색 섹션을 보이거나 숨깁니다. flashvars에서 재정의할 수 있습니다. 기본값은 true입니다. |
| [`show_top_pane`](/slides/python-net/ko/aspose.slides.export/iswfoptions/show_top_pane/) | 전체 상단 창을 보이거나 숨깁니다. flashvars에서 재정의할 수 있습니다. 기본값은 true입니다. |
| [`show_bottom_pane`](/slides/python-net/ko/aspose.slides.export/iswfoptions/show_bottom_pane/) | 하단 창을 보이거나 숨깁니다. flashvars에서 재정의할 수 있습니다. 기본값은 true입니다. |
| [`show_left_pane`](/slides/python-net/ko/aspose.slides.export/iswfoptions/show_left_pane/) | 왼쪽 창을 보이거나 숨깁니다. flashvars에서 재정의할 수 있습니다. 기본값은 true입니다. |
| [`start_open_left_pane`](/slides/python-net/ko/aspose.slides.export/iswfoptions/start_open_left_pane/) | 왼쪽 창을 열린 상태로 시작합니다. flashvars에서 재정의할 수 있습니다. 기본값은 false입니다. |
| [`enable_context_menu`](/slides/python-net/ko/aspose.slides.export/iswfoptions/enable_context_menu/) | 컨텍스트 메뉴를 활성화하거나 비활성화합니다. 기본값은 true입니다. |
| [`logo_image_bytes`](/slides/python-net/ko/aspose.slides.export/iswfoptions/logo_image_bytes/) | 뷰어 오른쪽 상단에 로고로 표시될 이미지입니다.             <br/>            이미지는 32x64 픽셀 PNG 이미지여야 하며, 그렇지 않으면 로고가 제대로 표시되지 않을 수 있습니다. |
| [`logo_link`](/slides/python-net/ko/aspose.slides.export/iswfoptions/logo_link/) | 로고의 전체 하이퍼링크 주소를 가져오거나 설정합니다.<br/>            [`ISwfOptions.logo_image_bytes`](/slides/python-net/ko/aspose.slides.export/iswfoptions/logo_image_bytes)가 지정된 경우에만 영향을 미칩니다. |
| [`jpeg_quality`](/slides/python-net/ko/aspose.slides.export/iswfoptions/jpeg_quality/) | JPEG 이미지의 품질을 지정합니다.             <br/>            기본값은 95입니다. |
| [`slides_layout_options`](/slides/python-net/ko/aspose.slides.export/iswfoptions/slides_layout_options/) | 프레젠테이션 [`ISlidesLayoutOptions`](/slides/python-net/ko/aspose.slides.export/islideslayoutoptions)을(를) 내보낼 때 슬라이드가 페이지에 배치되는 방식을 가져오거나 설정합니다.<br/>            이 속성은 `Aspose.Slides.Export.HandoutLayoutingOptions` 유형의 객체 할당을 지원하지 않습니다. |
| [`warning_callback`](/slides/python-net/ko/aspose.slides.export/iswfoptions/warning_callback/) |  |
