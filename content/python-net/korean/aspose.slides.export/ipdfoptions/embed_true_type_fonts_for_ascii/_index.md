## embed_true_type_fonts_for_ascii 속성
ASCII 문자 32-127에 대해 True 타입 글꼴을 포함하도록 true로 설정합니다.
127보다 큰 문자 코드에 대한 글꼴은 항상 포함됩니다.
읽기/쓰기 **bool**.

### 비고
기본값은 **true** 입니다.
