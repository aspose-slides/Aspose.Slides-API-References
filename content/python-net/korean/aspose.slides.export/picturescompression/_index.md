## PicturesCompression 열거형

그림 압축 수준을 나타냅니다

PicturesCompression 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| DPI330 | 고해상도(HD) 디스플레이에 대한 좋은 품질 |
| DPI220 | 대부분의 프린터와 화면에서 뛰어난 품질 |
| DPI150 | 웹 페이지와 프로젝터에 적합 |
| DPI96 | 공유를 위해 문서 크기를 최소화 |
| DPI72 | 기본 압축 수준 |
| DOCUMENT_RESOLUTION | 문서 해상도 사용 - 사진이 압축되지 않고 그대로 문서에 사용됩니다 |
