## TextInheritanceLimit 열거형

텍스트 속성 상속의 깊이를 제어합니다.

TextInheritanceLimit 형식은 다음 멤버를 노출합니다:

## 필드

| Field | 설명 |
| :- | :- |
| ALL | 모든 텍스트 속성을 상속합니다. |
| TEXT_BOX | TextFrame의 스타일만 상속합니다. |
| PARAGRAPH_ONLY | 단락에 정의된 속성만 사용합니다. |
