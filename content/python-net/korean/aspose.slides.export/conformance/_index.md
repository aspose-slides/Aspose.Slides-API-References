## 적합성 열거형

Conformance 타입은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| ECMA_376_2006 | 문서가 ECMA376:2006에 적합함을 지정합니다. |
| ISO_29500_2008_TRANSITIONAL | 문서가 ISO/IEC 29500:2008 Transitional 적합성 클래스에 적합함을 지정합니다. |
| ISO_29500_2008_STRICT | 문서가 ISO/IEC 29500:2008 Strict 적합성 클래스에 적합함을 지정합니다. |
