## CompressionLevel 열거형

OpenXML 파일에 대한 ZIP 압축 수준을 지정합니다.  
높은 수준일수록 압축 효율은 향상되지만 처리 속도가 느려집니다.

CompressionLevel 타입은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| NONE | 압축이 적용되지 않습니다. 파일은 그대로 저장됩니다. |
| LEVEL1 | 가장 낮은 압축 비율로 가장 빠른 압축을 제공합니다. |
| LEVEL2 | [`CompressionLevel.LEVEL1`](/slides/python-net/ko/aspose.slides.export/compressionlevel/LEVEL1)보다 약간 나은 압축 비율로 더 빠른 압축을 제공합니다. |
| LEVEL3 | [`CompressionLevel.LEVEL2`](/slides/python-net/ko/aspose.slides.export/compressionlevel/LEVEL2)보다 더 나은 압축을 제공하지만 성능에 중간 정도의 영향을 미칩니다. |
| LEVEL4 | [`CompressionLevel.LEVEL3`](/slides/python-net/ko/aspose.slides.export/compressionlevel/LEVEL3)보다 더 나은 압축을 제공합니다. |
| LEVEL5 | [`CompressionLevel.LEVEL4`](/slides/python-net/ko/aspose.slides.export/compressionlevel/LEVEL4)보다 향상된 압축을 제공하지만 추가 처리 시간이 필요합니다. |
| LEVEL6 | 표준 압축으로, 압축 속도와 파일 크기 사이에 좋은 균형을 제공합니다.<br/>            기본 압축 수준입니다. |
| LEVEL7 | [`CompressionLevel.LEVEL6`](/slides/python-net/ko/aspose.slides.export/compressionlevel/LEVEL6)보다 높은 압축을 제공하지만 처리 속도가 느립니다. |
| LEVEL8 | [`CompressionLevel.LEVEL7`](/slides/python-net/ko/aspose.slides.export/compressionlevel/LEVEL7)보다 높은 압축을 제공합니다. |
| LEVEL9 | 최대 압축. 가장 작은 파일 크기를 생성하며 처리 속도가 가장 느립니다. |
