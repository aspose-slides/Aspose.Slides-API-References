## disable_font_ligatures 속성
텍스트가 합자를 사용하지 않고 렌더링되는지 여부를 나타내는 값을 가져오거나 설정합니다.
`true` 로 설정하면 렌더링된 출력에서 합자가 비활성화됩니다. 기본적으로 이 속성은 `false` 로 설정됩니다.

@property

    ...
