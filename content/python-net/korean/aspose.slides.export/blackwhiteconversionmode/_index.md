## BlackWhiteConversionMode 열거형

슬라이드 이미지가 이진 이미지로 변환되는 방식을 제어하는 옵션을 제공합니다.

BlackWhiteConversionMode 타입은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| DEFAULT | 변환 알고리즘을 사용하지 않음을 지정합니다. TIFF 코덱에 구현된 알고리즘이 사용됩니다. (Default) |
| DITHERING | 디더링 알고리즘(Floyd-Steinberg)을 지정합니다. |
| DITHERING_FLOYD_STEINBERG | Floyd-Steinberg 디더링 알고리즘을 지정합니다. |
| AUTO | 자동으로 계산된 임계값 알고리즘(Otsu)을 지정합니다. |
| AUTO_OTSU | 자동으로 계산된 Otsu의 임계값 알고리즘을 지정합니다. |
| THRESHOLD25 | 정적 임계값 알고리즘(25%)을 지정합니다. |
| THRESHOLD50 | 정적 임계값 알고리즘(50%)을 지정합니다. |
| THRESHOLD75 | 정적 임계값 알고리즘(75%)을 지정합니다. |
