## IHtmlOptions 클래스

HTML 내보내기 옵션을 나타냅니다.

IHtmlOptions 형식은 다음 멤버를 노출합니다:

## 속성

| Property | Description |
| :- | :- |
| [`html_formatter`](/slides/python-net/ko/aspose.slides.export/ihtmloptions/html_formatter/) | HTML 템플릿을 반환하거나 설정합니다.<br/>            읽기/쓰기 [`IHtmlFormatter`](/slides/python-net/ko/aspose.slides.export/ihtmlformatter). |

| [`jpeg_quality`](/slides/python-net/ko/aspose.slides.export/ihtmloptions/jpeg_quality/) | PDF 문서 내 JPEG 이미지 품질을 결정하는 값을 반환하거나 설정합니다.<br/>            읽기/쓰기 **int**. |

| [`slides_layout_options`](/slides/python-net/ko/aspose.slides.export/ihtmloptions/slides_layout_options/) | 프레젠테이션을 내보낼 때 슬라이드가 페이지에 배치되는 모드를 반환하거나 설정합니다 [`ISlidesLayoutOptions`](/slides/python-net/ko/aspose.slides.export/islideslayoutoptions). |
