## CommentsPositions 열거형

내보낸 문서에 주석을 렌더링하는 규칙을 나타냅니다.

CommentsPositions 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| NONE | 주석을 전혀 표시하지 않도록 지정합니다. |
| BOTTOM | 주석을 페이지 하단에 표시하도록 지정합니다. |
| RIGHT | 주석을 페이지 오른쪽에 표시하도록 지정합니다. |
