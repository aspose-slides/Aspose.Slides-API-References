## SaveFormat 열거형

저장된 프레젠테이션의 형식을 정의하는 상수들.

SaveFormat 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| PPT | PPT 형식으로 프레젠테이션을 저장합니다. |
| PDF | PDF 형식으로 프레젠테이션을 저장합니다. |
| XPS | XPS 형식으로 프레젠테이션을 저장합니다. |
| PPTX | PPTX 형식으로 프레젠테이션을 저장합니다. |
| PPSX | PPSX (슬라이드쇼) 형식으로 프레젠테이션을 저장합니다. |
| TIFF | 다중 페이지 TIFF 이미지 형식으로 프레젠테이션을 저장합니다. |
| ODP | ODP 형식으로 프레젠테이션을 저장합니다. |
| PPTM | PPTM (매크로 사용 프레젠테이션) 형식으로 프레젠테이션을 저장합니다. |
| PPSM | PPSM (매크로 사용 슬라이드쇼) 형식으로 프레젠테이션을 저장합니다. |
| POTX | POTX (템플릿) 형식으로 프레젠테이션을 저장합니다. |
| POTM | POTM (매크로 사용 템플릿) 형식으로 프레젠테이션을 저장합니다. |
| HTML | HTML 형식으로 프레젠테이션을 저장합니다. |
| SWF | SWF 형식으로 프레젠테이션을 저장합니다. |
| OTP | OTP (프레젠테이션 템플릿) 형식으로 프레젠테이션을 저장합니다. |
| PPS | PPS 형식으로 프레젠테이션을 저장합니다. |
| POT | POT 형식으로 프레젠테이션을 저장합니다. |
| FODP | FODP 형식으로 프레젠테이션을 저장합니다. |
| GIF | GIF 형식으로 프레젠테이션을 저장합니다. |
| HTML5 | 새 HTML5 템플릿 시스템을 사용하여 HTML 형식으로 프레젠테이션을 저장합니다. |
| MD | Markdown 형식으로 프레젠테이션을 저장합니다 |
| XML | PowerPoint XML Presentation 형식으로 프레젠테이션을 저장합니다. |
