## ITextToHtmlConversionOptions 클래스

Pptx 텍스트에서 HTML을 추출하기 위한 옵션입니다.

ITextToHtmlConversionOptions 유형은 다음 구성원을 노출합니다:

## 속성

| Property | Description |
| :- | :- |
| [`add_clipboard_fragment_header`](/slides/python-net/ko/aspose.slides.export/itexttohtmlconversionoptions/add_clipboard_fragment_header/) | Clipboard 헤더를 추가할지 여부를 나타내는 값을 반환하거나 설정합니다.<br/>            읽기/쓰기 **bool**. |
| [`text_inheritance_limit`](/slides/python-net/ko/aspose.slides.export/itexttohtmlconversionoptions/text_inheritance_limit/) | 텍스트 속성에 대한 상속 깊이를 반환하거나 설정합니다.<br/>            읽기/쓰기 [`ITextToHtmlConversionOptions.text_inheritance_limit`](/slides/python-net/ko/aspose.slides.export/itexttohtmlconversionoptions/text_inheritance_limit). |
| [`link_embed_controller`](/slides/python-net/ko/aspose.slides.export/itexttohtmlconversionoptions/link_embed_controller/) | 외부 객체가 저장되는 방식을 제어하는 콜백 객체를 반환하거나 설정합니다.<br/>            읽기/쓰기 [`ILinkEmbedController`](/slides/python-net/ko/aspose.slides.export/ilinkembedcontroller). |
| [`encoding_name`](/slides/python-net/ko/aspose.slides.export/itexttohtmlconversionoptions/encoding_name/) | HTML 인코딩 이름을 반환하거나 설정합니다.<br/>            이 값은 생성된 HTML 파일에 저장되지만, 파일이 해당 인코딩으로 저장되도록 보장하는 것은 호출자에게 달려 있습니다.<br/>            읽기/쓰기 **str**. |
