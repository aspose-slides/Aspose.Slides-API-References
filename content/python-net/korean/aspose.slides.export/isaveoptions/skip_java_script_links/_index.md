## skip_java_script_links 속성
프레젠테이션을 저장할 때 JavaScript 호출이 있는 하이퍼링크를 건너뛸지 여부를 지정합니다. 
            읽기/쓰기 **bool**. 기본값은 **false** 입니다 .


### 비고

이 속성이 **true** , JavaScript 호출이 있는 하이퍼링크는 저장하는 동안 무시됩니다.


이 속성이 **false** , 모든 하이퍼링크가 저장됩니다.

```python
@property
def skip_java_script_links(self):
    ...

@skip_java_script_links.setter
def skip_java_script_links(self, value):
    ...
```
