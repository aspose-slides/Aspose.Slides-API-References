## HandoutType 열거형

페이지에 몇 개의 슬라이드를 어떤 순서로 배치할지 지정합니다.

HandoutType 유형은 다음 멤버를 제공합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| HANDOUTS1 | 페이지당 하나의 슬라이드. |
| HANDOUTS2 | 페이지당 두 개의 슬라이드. |
| HANDOUTS3 | 페이지당 세 개의 슬라이드. |
| HANDOUTS_4_HORIZONTAL | 가로 순서로 페이지당 네 개의 슬라이드. |
| HANDOUTS_4_VERTICAL | 세로 순서로 페이지당 네 개의 슬라이드. |
| HANDOUTS_6_HORIZONTAL | 가로 순서로 페이지당 여섯 개의 슬라이드. |
| HANDOUTS_6_VERTICAL | 세로 순서로 페이지당 여섯 개의 슬라이드. |
| HANDOUTS_9_HORIZONTAL | 가로 순서로 페이지당 아홉 개의 슬라이드. |
| HANDOUTS_9_VERTICAL | 세로 순서로 페이지당 아홉 개의 슬라이드. |
