## hide(self) {#}
데이터 레이블을 기본적으로 숨기려면 모든 Show*-플래그(ShowValue 등)를
            DefaultDataLabelFormat 속성을 false 상태로 설정하십시오.
            IsVisible는 이후 false가 됩니다.

```python
def hide(self):
    ...
```

### 참고

데이터 레이블이 기본적으로 보이지 않는 경우(IsVisible가 false) 데이터 레이블을 "보이게"
            기본적으로 Show*-플래그(ShowValue 등)를 설정하고 DefaultDataLabelFormat 속성을
            true 상태로 만들 수 있습니다.
