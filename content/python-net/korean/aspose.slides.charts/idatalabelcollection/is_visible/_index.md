## is_visible 속성
False는 데이터 레이블이 기본적으로 표시되지 않음을 의미합니다(따라서 DefaultDataLabelFormat 속성의 모든 Show*-플래그(ShowValue, ...)가 false입니다).
            읽기 전용 **bool**.


### 비고

데이터 레이블이 기본적으로 표시되는 경우 Hide() 메서드로 기본적으로 숨길 수 있습니다.
            하지만 데이터 레이블이 기본적으로 표시되지 않는 경우 (IsVisible가 false) DefaultDataLabelFormat 속성의 Show*-플래그(ShowValue, ...)를 true 상태로 설정하여 데이터 레이블을 "기본적으로 표시"하도록 만들 수 있습니다.
