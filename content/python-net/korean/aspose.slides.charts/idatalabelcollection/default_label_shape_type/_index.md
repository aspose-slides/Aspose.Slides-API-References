## default_label_shape_type 속성
데이터 레이블의 기본 도형 유형을 가져오거나 설정합니다.
             [`ShapeType.NOT_DEFINED`](/slides/python-net/ko/aspose.slides/shapetype/NOT_DEFINED)를 반환합니다. 도형이 정의되지 않은 경우.

### 비고
이 속성을 설정하면 [`IDataLabel.label_shape_type`](/slides/python-net/ko/aspose.slides.charts/idatalabel/label_shape_type) 속성도
             컬렉션의 모든 데이터 레이블에 대해 동일한 값으로 설정됩니다.

def default_label_shape_type(self):
    ...
