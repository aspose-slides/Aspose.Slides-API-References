## ILayoutable 클래스

차트 요소의 정확한 위치를 지정합니다.

ILayoutable 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`x`](/slides/python-net/ko/aspose.slides.charts/ilayoutable/x/) | 차트 요소의 x 위치(왼쪽)를 차트 너비의 비율로 지정합니다.<br/>            읽기/쓰기 **float**. |
| [`y`](/slides/python-net/ko/aspose.slides.charts/ilayoutable/y/) | 차트 요소의 위쪽을 차트 높이의 비율로 지정합니다.<br/>            읽기/쓰기 **float**. |
| [`width`](/slides/python-net/ko/aspose.slides.charts/ilayoutable/width/) | 차트 요소의 너비를 차트 너비의 비율로 지정합니다.<br/>            읽기/쓰기 **float**. |
| [`height`](/slides/python-net/ko/aspose.slides.charts/ilayoutable/height/) | 차트 요소의 높이를 차트 높이의 비율로 지정합니다.<br/>            읽기/쓰기 **float**. |
| [`right`](/slides/python-net/ko/aspose.slides.charts/ilayoutable/right/) | 차트 요소의 오른쪽을 차트 너비의 비율로 가져옵니다.<br/>            읽기 전용 **float**. |
| [`bottom`](/slides/python-net/ko/aspose.slides.charts/ilayoutable/bottom/) | 차트 요소의 위쪽을 차트 높이의 비율로 가져옵니다.<br/>            읽기 전용 **float**. |
