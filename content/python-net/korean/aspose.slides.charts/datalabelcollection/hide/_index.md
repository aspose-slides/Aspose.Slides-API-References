## hide(self) {#}
모든 Show*-flags(ShowValue, ...)를 false 상태로 설정하여 기본적으로 데이터 레이블을 숨깁니다.  
IsVisible는 이 후 false가 됩니다.


```python
def hide(self):
    ...
```


### 비고

데이터 레이블이 기본적으로 표시되지 않는 경우(IsVisible가 false) DefaultDataLabelFormat 속성의 Show*-flags(ShowValue, ...)를 true 상태로 설정하여 데이터 레이블을 "기본적으로 표시"하도록 만들 수 있습니다.
