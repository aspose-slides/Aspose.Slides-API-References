## default_label_shape_type 속성
데이터 레이블에 대한 기본 도형 유형을 가져오거나 설정합니다.
             정의된 도형이 없으면 [`ShapeType.NOT_DEFINED`](/slides/python-net/ko/aspose.slides/shapetype/NOT_DEFINED)을(를) 반환합니다.

### Remarks
이 속성을 설정하면 컬렉션에 있는 모든 데이터 레이블의 [`IDataLabel.label_shape_type`](/slides/python-net/ko/aspose.slides.charts/idatalabel/label_shape_type) 속성도 동일한 값으로 설정됩니다.
