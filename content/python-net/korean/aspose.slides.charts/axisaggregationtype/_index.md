## AxisAggregationType 열거형

카테고리 축의 집계 유형을 나타냅니다. Histogram 또는 HistogramPareto 시리즈와 함께 사용할 때만 사용됩니다.

AxisAggregationType 유형은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| BY_CATEGORY | 카테고리별 집계 |
| AUTOMATIC | 카테고리를 자동으로 집계합니다. |
| BY_BIN_WIDTH | 빈 너비별로 카테고리를 집계합니다. 속성 IAxis.BinWidth는 설정되어야 합니다. |
| BY_NUMBER_OF_BINS | 빈 개수별로 카테고리를 집계합니다. 속성 IAxis.NumberOfBins는 설정되어야 합니다. |
