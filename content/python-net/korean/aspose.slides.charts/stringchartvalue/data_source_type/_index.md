## data_source_type 속성
Descendants에 실제로 AsCell, AsCells, AsLiteralString 또는 AsLiteralDouble 속성이 있는지를 지정합니다.  
다시 말해 Data 속성 값의 유형을 지정합니다.  
읽기/쓰기 [`DataSourceType`](/slides/python-net/ko/aspose.slides.charts/datasourcetype).

### 비고

ChartDataPointCollection의 포인트에 대해서는 이 속성이 읽기 전용입니다.  
이 경우 이 속성의 값을 변경하려면 ChartDataPointCollection.DataSourceTypeFor<...> 속성 중 하나를 사용할 수 있습니다.
