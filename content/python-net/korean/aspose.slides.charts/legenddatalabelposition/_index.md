## LegendDataLabelPosition 열거형

데이터 레이블의 위치를 결정합니다.

LegendDataLabelPosition 유형은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| NOT_DEFINED | 위치가 정의되지 않았습니다. |
| BOTTOM | 데이터 마커 아래에 데이터 레이블이 표시됩니다. |
| BEST_FIT | 데이터 레이블이 최적의 위치에 표시됩니다. |
| CENTER | 데이터 레이블이 데이터 마커 중앙에 표시됩니다. |
| INSIDE_BASE | 데이터 레이블이 데이터 마커 기반 내부에 표시됩니다. |
| INSIDE_END | 데이터 레이블이 데이터 마커 끝 내부에 표시됩니다. |
| LEFT | 데이터 레이블이 데이터 마커 왼쪽에 표시됩니다. |
| OUTSIDE_END | 데이터 레이블이 데이터 마커 끝 외부에 표시됩니다. |
| RIGHT | 데이터 레이블이 데이터 마커 오른쪽에 표시됩니다. |
| TOP | 데이터 레이블이 데이터 마커 위에 표시됩니다. |
