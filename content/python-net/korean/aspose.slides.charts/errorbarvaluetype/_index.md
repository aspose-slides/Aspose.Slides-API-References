## ErrorBarValueType 열거형

오류 막대값의 유형을 나타냅니다

ErrorBarValueType 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| CUSTOM | 오류 막대의 길이가 Plus 및 Minus 요소에 의해 결정됨을 지정합니다. |
| FIXED | 오류 막대의 길이가 Error Bar Value에 의해 결정된 고정값임을 지정합니다. |
| PERCENTAGE | 오류 막대의 길이가 데이터의 Error Bar Value 퍼센트임을 지정합니다. |
| STANDARD_DEVIATION | 오류 막대의 길이가 데이터의 Error Bar Value 표준 편차임을 지정합니다. |
| STANDARD_ERROR | 오류 막대의 길이가 데이터의 Error Bar Value 표준 오차임을 지정합니다. |
