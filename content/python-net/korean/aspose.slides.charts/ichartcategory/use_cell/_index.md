## use_cell 속성
true이면 AsCell 속성이 실제입니다. 다시 말해, 워크시트가 저장하는 데 사용됩니다 
            범주를 저장합니다 (이 경우 다중 레벨 범주를 지원합니다).
            false이면 AsLiteral 속성이 실제입니다. 다시 말해, 워크시트는 사용되지 않으며 
            범주를 저장하는 데 사용되지 않습니다 (이 경우 다중 레벨 범주를 지원하지 않습니다).
            읽기 전용 **bool**.

### 비고

이 속성의 값을 변경하려면(컬렉션의 모든 범주에 대해) 새 
            값을 ChartCategoryCollection.UseCells 속성에 설정합니다.
