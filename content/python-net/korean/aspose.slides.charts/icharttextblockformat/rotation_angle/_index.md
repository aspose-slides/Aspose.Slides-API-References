## rotation_angle 속성
경계 상자 내부의 텍스트에 적용되는 사용자 지정 회전을 지정합니다. 지정되지
            않은 경우, 해당 모양의 회전이 사용됩니다. 지정된 경우,
            이는 모양과 독립적으로 적용됩니다. 즉, 모양은
            회전이 적용될 수 있으며 텍스트 자체에도 회전이 적용될 수 있습니다.
            이 속성과 속성 TextVerticalType에 정의된 사전 정의 수직 유형에서 요약된
            시각적 텍스트 회전 값이 결과로 반환됩니다.
            읽기/쓰기 **float**.
