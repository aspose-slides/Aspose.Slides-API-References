## DisplayUnitType 열거형

표시된 데이터의 배수를 결정합니다.

DisplayUnitType 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| NONE | 값이 있는 그대로 표시됩니다. |
| HUNDREDS | 차트의 값이 100으로 나누어지도록 지정합니다. |
| THOUSANDS | 차트의 값이 1,000으로 나누어지도록 지정합니다. |
| TEN_THOUSANDS | 차트의 값이 10,000으로 나누어지도록 지정합니다. |
| HUNDRED_THOUSANDS | 차트의 값이 100,000으로 나누어지도록 지정합니다. |
| MILLIONS | 차트의 값이 1,000,000으로 나누어지도록 지정합니다. |
| TEN_MILLIONS | 차트의 값이 10,000,000으로 나누어지도록 지정합니다. |
| HUNDRED_MILLIONS | 차트의 값이 100,000,000으로 나누어지도록 지정합니다. |
| BILLIONS | 차트의 값이 1,000,000,000으로 나누어지도록 지정합니다. |
| TRILLIONS | 차트의 값이 1,000,000,000,000으로 나누어지도록 지정합니다. |
| CUSTOM_VALUE | 차트의 값이 사용자 지정 값으로 나누어지도록 지정합니다. |
