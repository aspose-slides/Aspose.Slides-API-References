## DataTable 클래스

데이터 테이블 속성을 나타냅니다.

DataTable 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`format`](/slides/python-net/ko/aspose.slides.charts/datatable/format/) | 객체의 선, 채우기 및 효과 스타일을 반환합니다.<br/>            읽기 전용 [`IFormat`](/slides/python-net/ko/aspose.slides.charts/iformat). |
| [`has_border_horizontal`](/slides/python-net/ko/aspose.slides.charts/datatable/has_border_horizontal/) | 차트 데이터 테이블에 가로 셀 테두리가 있으면 True.<br/>            읽기/쓰기 **bool**. |
| [`has_border_outline`](/slides/python-net/ko/aspose.slides.charts/datatable/has_border_outline/) | 차트 데이터 테이블에 외곽 테두리가 있으면 True.<br/>            읽기/쓰기 **bool**. |
| [`has_border_vertical`](/slides/python-net/ko/aspose.slides.charts/datatable/has_border_vertical/) | 차트 데이터 테이블에 세로 셀 테두리가 있으면 True.<br/>            읽기/쓰기 **bool**. |
| [`show_legend_key`](/slides/python-net/ko/aspose.slides.charts/datatable/show_legend_key/) | 데이터 레이블 범례 키가 보이면 True.<br/>            읽기/쓰기 **bool**. |
| [`chart`](/slides/python-net/ko/aspose.slides.charts/datatable/chart/) | 차트를 반환합니다.<br/>            읽기 전용 [`IChart`](/slides/python-net/ko/aspose.slides.charts/ichart). |
| [`text_format`](/slides/python-net/ko/aspose.slides.charts/datatable/text_format/) | 텍스트 형식을 반환합니다.<br/>            읽기 전용 [`IChartTextFormat`](/slides/python-net/ko/aspose.slides.charts/icharttextformat). |
| [`slide`](/slides/python-net/ko/aspose.slides.charts/datatable/slide/) |  |
| [`presentation`](/slides/python-net/ko/aspose.slides.charts/datatable/presentation/) |  |
