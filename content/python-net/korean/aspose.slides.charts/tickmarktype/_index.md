## TickMarkType 열거형

지정된 축에 대한 눈금 표시 유형을 나타냅니다.

TickMarkType 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| CROSS | 눈금이 축을 가로지르도록 지정됩니다. |
| INSIDE | 눈금이 플롯 영역 내부에 있도록 지정됩니다. |
| NONE | 눈금이 없도록 지정됩니다. |
| OUTSIDE | 눈금이 플롯 영역 외부에 있도록 지정됩니다. |
