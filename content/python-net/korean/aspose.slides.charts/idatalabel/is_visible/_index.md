## is_visible 속성
False는 데이터 레이블이 보이지 않음을 의미합니다(그리고 모든 Show*-flags (ShowValue, ...)도 false입니다).
읽기 전용 **bool**.


### 비고

데이터 레이블이 보이는 경우 Hide() 메서드로 숨길 수 있습니다.
하지만 데이터 레이블이 보이지 않으면(IsVisible가 false) Show*-flags (ShowValue, ...)를 true 상태로 설정하여 데이터 레이블을 다시 보이게 할 수 있습니다.
