## LegendPositionType 열거형

차트에서 범례의 위치를 결정합니다.

LegendPositionType 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| BOTTOM | 범례가 차트 하단에 그려짐을 지정합니다. |
| LEFT | 범례가 차트 왼쪽에 그려짐을 지정합니다. |
| RIGHT | 범례가 차트 오른쪽에 그려짐을 지정합니다. |
| TOP | 범례가 차트 상단에 그려짐을 지정합니다. |
| TOP_RIGHT | 범례가 차트 오른쪽 상단에 그려짐을 지정합니다. |
