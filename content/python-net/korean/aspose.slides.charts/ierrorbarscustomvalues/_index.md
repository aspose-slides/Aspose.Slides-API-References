## IErrorBarsCustomValues 클래스

오류 막대 값을 지정합니다. 오류 막대 값 유형이 Custom인 경우에만 사용해야 합니다.

IErrorBarsCustomValues 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`x_minus`](/slides/python-net/ko/aspose.slides.charts/ierrorbarscustomvalues/x_minus/) | 음수 방향의 오류 막대 값을 지정합니다. <br/>            오류 막대 값 유형이 Custom이고 ErrorBarsXFormat이 허용되는 경우에만 사용할 수 있습니다.<br/>            다른 경우에는 이 속성이 None을 반환합니다.  <br/>            읽기 전용 [`IDoubleChartValue`](/slides/python-net/ko/aspose.slides.charts/idoublechartvalue). |
