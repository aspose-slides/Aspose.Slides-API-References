## PictureType 열거형

막대 그림 채우기 모드를 결정합니다.

PictureType 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| NOT_DEFINED | 정의되지 않음. |
| STACK | 그림은 가장 긴 누적 막대에서 최대 15번 반복하도록 크기가 조정됩니다. |
| STACK_SCALE | 그림은 지정된 단위 수에 맞게 크기가 조정되고 막대 길이만큼 반복됩니다. |
| STRETCH | 그림은 누적 막대 전체 길이로 늘어납니다. |
