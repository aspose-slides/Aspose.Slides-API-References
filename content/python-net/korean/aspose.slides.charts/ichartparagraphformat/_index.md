## IChartParagraphFormat 클래스

차트의 단락 서식 속성을 나타냅니다.

IChartParagraphFormat 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`alignment`](/slides/python-net/ko/aspose.slides.charts/ichartparagraphformat/alignment/) | 단락에서 텍스트 정렬을 반환하거나 설정합니다.<br/>            읽기/쓰기 [`TextAlignment`](/slides/python-net/ko/aspose.slides/textalignment). |
| [`space_within`](/slides/python-net/ko/aspose.slides.charts/ichartparagraphformat/space_within/) | 단락에서 기준선 사이의 간격을 반환하거나 설정합니다.<br/>            읽기/쓰기 **float**. |
| [`space_before`](/slides/python-net/ko/aspose.slides.charts/ichartparagraphformat/space_before/) | 단락에서 첫 번째 줄 전에 있는 여백을 반환하거나 설정합니다.<br/>            읽기/쓰기 **float**. |
| [`space_after`](/slides/python-net/ko/aspose.slides.charts/ichartparagraphformat/space_after/) | 단락에서 마지막 줄 뒤의 여백을 반환하거나 설정합니다.<br/>            읽기/쓰기 **float**. |
| [`east_asian_line_break`](/slides/python-net/ko/aspose.slides.charts/ichartparagraphformat/east_asian_line_break/) | 단락에서 동아시아 줄 바꿈이 사용되는지를 결정합니다.<br/>            읽기/쓰기 [`NullableBool`](/slides/python-net/ko/aspose.slides/nullablebool). |
| [`right_to_left`](/slides/python-net/ko/aspose.slides.charts/ichartparagraphformat/right_to_left/) | 단락에서 오른쪽에서 왼쪽으로 쓰기가 사용되는지를 결정합니다.<br/>            읽기/쓰기 [`NullableBool`](/slides/python-net/ko/aspose.slides/nullablebool). |
| [`latin_line_break`](/slides/python-net/ko/aspose.slides.charts/ichartparagraphformat/latin_line_break/) | 단락에서 라틴 줄 바꿈이 사용되는지를 결정합니다.<br/>            읽기/쓰기 [`NullableBool`](/slides/python-net/ko/aspose.slides/nullablebool). |
| [`hanging_punctuation`](/slides/python-net/ko/aspose.slides.charts/ichartparagraphformat/hanging_punctuation/) | 단락에서 매달림 구두점이 사용되는지를 결정합니다.<br/>            읽기/쓰기 [`NullableBool`](/slides/python-net/ko/aspose.slides/nullablebool). |
| [`margin_left`](/slides/python-net/ko/aspose.slides.charts/ichartparagraphformat/margin_left/) | 단락에서 왼쪽 여백을 반환하거나 설정합니다.<br/>            읽기/쓰기 **float**. |
| [`margin_right`](/slides/python-net/ko/aspose.slides.charts/ichartparagraphformat/margin_right/) | 단락에서 오른쪽 여백을 반환하거나 설정합니다.<br/>            읽기/쓰기 **float**. |
| [`indent`](/slides/python-net/ko/aspose.slides.charts/ichartparagraphformat/indent/) | 단락의 첫 줄 들여쓰기/매달림 들여쓰기를 반환하거나 설정합니다. 매달림 들여쓰기는 음수 값으로 정의될 수 있습니다.<br/>            읽기/쓰기 **float**. |
| [`default_tab_size`](/slides/python-net/ko/aspose.slides.charts/ichartparagraphformat/default_tab_size/) | 기본 탭 크기를 반환하거나 설정합니다.<br/>            읽기/쓰기 **float**. |
| [`tabs`](/slides/python-net/ko/aspose.slides.charts/ichartparagraphformat/tabs/) | 단락의 탭을 반환합니다.<br/>            읽기 전용 [`ITabCollection`](/slides/python-net/ko/aspose.slides/itabcollection). |
| [`font_alignment`](/slides/python-net/ko/aspose.slides.charts/ichartparagraphformat/font_alignment/) | 단락에서 글꼴 정렬을 반환하거나 설정합니다.<br/>            읽기/쓰기 [`FontAlignment`](/slides/python-net/ko/aspose.slides/fontalignment). |
