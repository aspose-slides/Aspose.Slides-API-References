## CrossesType 열거형

축이 교차할 위치를 결정합니다.

CrossesType 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| AXIS_CROSSES_AT_ZERO | 범주 축이 값 축의 0 지점(가능한 경우)에서 교차하거나, 최소값(최소값이 0보다 큰 경우) 또는 최대값(최대값이 0보다 작은 경우)에서 교차합니다. |
| MAXIMUM | 축이 최대값에서 교차합니다. |
| CUSTOM | 속성 CrossAt에서 지정한 사용자 값 |
