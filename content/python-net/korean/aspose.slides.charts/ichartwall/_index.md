## IChartWall 클래스

3d 차트의 벽을 나타냅니다.

IChartWall 유형은 다음 멤버를 제공합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`thickness`](/slides/python-net/ko/aspose.slides.charts/ichartwall/thickness/) | 플롯 볼륨의 가장 큰 차원에 대한 백분율로 벽 두께를 반환하거나 설정합니다.<br/>            읽기/쓰기 **int**. |
| [`format`](/slides/python-net/ko/aspose.slides.charts/ichartwall/format/) | 벽 채우기, 선, 효과, 3d 스타일을 반환합니다.<br/>            읽기 전용 [`IFormat`](/slides/python-net/ko/aspose.slides.charts/iformat). |
| [`picture_type`](/slides/python-net/ko/aspose.slides.charts/ichartwall/picture_type/) | 그림 유형을 반환하거나 설정합니다.<br/>            읽기/쓰기 [`IChartWall.picture_type`](/slides/python-net/ko/aspose.slides.charts/ichartwall/picture_type). |
