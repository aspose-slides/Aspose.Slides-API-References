## ParentLabelLayoutType 열거형

카테고리 데이터 레이블의 레이아웃을 나타냅니다. Treemap 시리즈와 함께만 사용됩니다.

ParentLabelLayoutType 타입은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| BANNER | 부모 카테고리 레이블이 배너 형태로 표시됩니다 |
| NONE | 부모 카테고리 레이블이 그려지지 않음을 지정합니다 |
| OVERLAPPING | 부모 카테고리 레이블이 겹쳐서 표시됩니다 |
