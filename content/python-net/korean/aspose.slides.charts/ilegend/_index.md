## ILegend 클래스

차트의 범례 속성을 나타냅니다.

ILegend 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`overlay`](/slides/python-net/ko/aspose.slides.charts/ilegend/overlay/) | 다른 차트 요소가 범례와 겹치도록 허용할지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`position`](/slides/python-net/ko/aspose.slides.charts/ilegend/position/) | 차트에서 범례의 위치를 지정합니다.<br/>            X, Y, Width, Heigt 속성의 Non-NaN 값은 이 속성의 효과를 무시합니다.<br/>            읽기/쓰기 [`LegendPositionType`](/slides/python-net/ko/aspose.slides.charts/legendpositiontype). |
| [`format`](/slides/python-net/ko/aspose.slides.charts/ilegend/format/) | 범례의 형식을 반환합니다.<br/>            읽기 전용 [`IFormat`](/slides/python-net/ko/aspose.slides.charts/iformat). |
