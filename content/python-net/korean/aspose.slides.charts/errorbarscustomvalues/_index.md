## ErrorBarsCustomValues 클래스

오류 막대 값을 지정합니다. 오류 막대 값 유형이 Custom인 경우에만 사용해야 합니다.

ErrorBarsCustomValues 유형은 다음 멤버를 제공합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`x_minus`](/slides/python-net/ko/aspose.slides.charts/errorbarscustomvalues/x_minus/) | 음수 방향의 오류 막대 값을 지정합니다. <br/>            오류 막대 값 유형이 Custom이고 ErrorBarsXFormat이 허용되는 경우에만 사용할 수 있습니다.<br/>            그 외의 경우 이 속성은 None을 반환합니다.<br/>            읽기 전용 [`IDoubleChartValue`](/slides/python-net/ko/aspose.slides.charts/idoublechartvalue). |
| [`y_minus`](/slides/python-net/ko/aspose.slides.charts/errorbarscustomvalues/y_minus/) | 음수 방향의 오류 막대 값을 지정합니다. <br/>            오류 막대 값 유형이 Custom이고 ErrorBarsYFormat이 허용되는 경우에만 사용할 수 있습니다.<br/>            그 외의 경우 이 속성은 None을 반환합니다.<br/>            읽기 전용 [`IDoubleChartValue`](/slides/python-net/ko/aspose.slides.charts/idoublechartvalue). |
