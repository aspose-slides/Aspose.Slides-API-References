## IDataLabelFormat class

| [`show_percentage`](/slides/python-net/ko/aspose.slides.charts/idatalabelformat/show_percentage/) | 지정된 차트의 데이터 레이블 백분율 값 표시 동작을 나타냅니다. <br/>            True는 백분율 값을 표시합니다. False는 숨깁니다.<br/>            읽기/쓰기 **bool**. |
