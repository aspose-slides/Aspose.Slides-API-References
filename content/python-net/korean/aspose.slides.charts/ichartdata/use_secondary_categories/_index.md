## use_secondary_categories 속성
false인 경우 [`IChartData.secondary_categories`](/slides/python-net/ko/aspose.slides.charts/ichartdata/secondary_categories) 속성은 None을 반환하고 데이터 
            [`IChartData.categories`](/slides/python-net/ko/aspose.slides.charts/ichartdata/categories) 속성의 데이터는 기본 및 보조 시리즈 모두에 사용됩니다.
            true인 경우 [`IChartData.secondary_categories`](/slides/python-net/ko/aspose.slides.charts/ichartdata/secondary_categories) 속성의 데이터는 보조 시리즈에 사용되고 데이터 
            [`IChartData.categories`](/slides/python-net/ko/aspose.slides.charts/ichartdata/categories) 속성의 데이터는 기본 시리즈에 사용됩니다.
            읽기/쓰기 **bool**.
