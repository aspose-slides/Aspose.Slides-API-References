## use_secondary_categories 속성
If false then [`IChartData.secondary_categories`](/slides/python-net/ko/aspose.slides.charts/ichartdata/secondary_categories) 속성 return None and data 
            in [`IChartData.categories`](/slides/python-net/ko/aspose.slides.charts/ichartdata/categories) 속성 is used both for primary and secondary series.
            If true then data in [`IChartData.secondary_categories`](/slides/python-net/ko/aspose.slides.charts/ichartdata/secondary_categories) 속성 is used for secondary series and data 
            in [`IChartData.categories`](/slides/python-net/ko/aspose.slides.charts/ichartdata/categories) 속성 is used for primary series.
            Read/write **bool**.
