## height 속성
shape의 height를 가져오거나 설정합니다, 측정 단위는 포인트입니다.
            읽기/쓰기 **float**.

            할당된 값도 정의되어 있어야 합니다; `RawFrame` 인스턴스의 속성에만 **float**를 할당하십시오.
