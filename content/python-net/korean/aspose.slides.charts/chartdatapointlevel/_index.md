## ChartDataPointLevel 클래스

데이터 포인트 레벨을 나타냅니다. Treemap 및 Sunburst 차트에 적용됩니다.

ChartDataPointLevel 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`format`](/slides/python-net/ko/aspose.slides.charts/chartdatapointlevel/format/) | 데이터 포인트 레벨의 서식 속성을 나타냅니다.<br/>            읽기/쓰기 [`IFormat`](/slides/python-net/ko/aspose.slides.charts/iformat). |
| [`label`](/slides/python-net/ko/aspose.slides.charts/chartdatapointlevel/label/) | 데이터 포인트 레벨의 데이터 레이블을 나타냅니다. Treemap 및 Sunburst 시리즈 유형에 적용됩니다.<br/>             읽기 전용 [`IDataLabel`](/slides/python-net/ko/aspose.slides.charts/idatalabel). |
