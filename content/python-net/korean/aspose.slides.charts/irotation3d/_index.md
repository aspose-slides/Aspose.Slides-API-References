## IRotation3D 클래스

3D 차트의 회전을 나타냅니다.

IRotation3D 형식은 다음 멤버를 노출합니다:

## 속성

| Property | Description |
| :- | :- |
| [`rotation_x`](/slides/python-net/ko/aspose.slides.charts/irotation3d/rotation_x/) | 회전 각도를 X축을 중심으로 설정하거나 반환합니다(3D 차트에서는 Y 방향). -90도에서 90도 사이의 값입니다.<br/>            이 속성은 ECMA-376의 21.2.2.157 rotX (X Rotation) 항목 및 PowerPoint 2007+의 "Y Rotation" 옵션과 일치합니다.<br/>            읽기/쓰기 **int**. |
| [`rotation_y`](/slides/python-net/ko/aspose.slides.charts/irotation3d/rotation_y/) | 회전 각도를 Y축을 중심으로 설정하거나 반환합니다(3D 차트에서는 X 방향). 0도에서 360도 사이의 값입니다.<br/>            이 속성은 ECMA-376의 21.2.2.158 rotY (Y Rotation) 항목 및 PowerPoint 2007+의 "X Rotation" 옵션과 일치합니다.<br/>            읽기/쓰기 **int**. |
| [`perspective`](/slides/python-net/ko/aspose.slides.charts/irotation3d/perspective/) | 3D 차트의 원근값(시야각)을 설정하거나 반환합니다(0에서 100 사이).<br/>            RightAngleAxes 속성 값이 true인 경우 무시됩니다.<br/>            읽기/쓰기 **int**. |
| [`right_angle_axes`](/slides/python-net/ko/aspose.slides.charts/irotation3d/right_angle_axes/) | 차트 축이 원근이 아닌 직각으로 그려지는지 여부를 결정합니다.<br/>            다시 말해 차트 축의 각도가 차트 회전 또는 고도와 독립적인지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`depth_percents`](/slides/python-net/ko/aspose.slides.charts/irotation3d/depth_percents/) | 3D 차트의 깊이를 차트 너비의 백분율로 설정하거나 반환합니다(20%에서 2000% 사이).<br/>            읽기/쓰기 **int**. |
| [`height_percents`](/slides/python-net/ko/aspose.slides.charts/irotation3d/height_percents/) | 3D 차트의 높이를 차트 너비의 백분율로 지정하거나 반환합니다(5%에서 500% 사이).<br/>            읽기/쓰기 **int**. |
