## AxesManager 클래스

차트 축에 대한 액세스를 제공합니다.

AxesManager 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`horizontal_axis`](/slides/python-net/ko/aspose.slides.charts/axesmanager/horizontal_axis/) | 차트의 수평 축을 가져옵니다.<br/>             읽기 전용 [`IAxis`](/slides/python-net/ko/aspose.slides.charts/iaxis). |
| [`secondary_horizontal_axis`](/slides/python-net/ko/aspose.slides.charts/axesmanager/secondary_horizontal_axis/) | 차트의 보조 수평 축을 가져옵니다.<br/>             읽기 전용 [`IAxis`](/slides/python-net/ko/aspose.slides.charts/iaxis). |
| [`vertical_axis`](/slides/python-net/ko/aspose.slides.charts/axesmanager/vertical_axis/) | 차트의 수직 축을 가져옵니다.<br/>             읽기 전용 [`IAxis`](/slides/python-net/ko/aspose.slides.charts/iaxis). |
| [`secondary_vertical_axis`](/slides/python-net/ko/aspose.slides.charts/axesmanager/secondary_vertical_axis/) | 차트의 보조 수직 축을 가져옵니다.<br/>             읽기 전용 [`IAxis`](/slides/python-net/ko/aspose.slides.charts/iaxis). |
| [`series_axis`](/slides/python-net/ko/aspose.slides.charts/axesmanager/series_axis/) | 차트의 시리즈 축을 가져옵니다.<br/>             읽기 전용 [`IAxis`](/slides/python-net/ko/aspose.slides.charts/iaxis). |
