## TimeUnitType 열거형

카테고리 축의 기본 단위를 나타냅니다.

TimeUnitType 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| NONE | 값은 그대로 표시됩니다. |
| DAYS | 차트 데이터가 일 단위로 표시되도록 지정합니다. |
| MONTHS | 차트 데이터가 월 단위로 표시되도록 지정합니다. |
| YEARS | 차트 데이터가 연 단위로 표시되도록 지정합니다. |
