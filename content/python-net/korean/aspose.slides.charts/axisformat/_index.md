## AxisFormat 클래스

차트 형식 속성을 나타냅니다.

AxisFormat 형식은 다음 멤버를 노출합니다.

## 속성

| 속성 | 설명 |
| :- | :- |
| [`fill`](/slides/python-net/ko/aspose.slides.charts/axisformat/fill/) | 축의 채우기 스타일 속성을 반환합니다.<br/>            읽기 전용 [`IFillFormat`](/slides/python-net/ko/aspose.slides/ifillformat). |
| [`line`](/slides/python-net/ko/aspose.slides.charts/axisformat/line/) | 축의 선 스타일 속성을 반환합니다.<br/>            읽기 전용 [`ILineFormat`](/slides/python-net/ko/aspose.slides/ilineformat). |
| [`effect`](/slides/python-net/ko/aspose.slides.charts/axisformat/effect/) | 축에 사용되는 효과를 반환합니다.<br/>            읽기 전용 [`IEffectFormat`](/slides/python-net/ko/aspose.slides/ieffectformat). |
