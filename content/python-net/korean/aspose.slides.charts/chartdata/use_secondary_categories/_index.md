## use_secondary_categories 속성
If false then [`ChartData.secondary_categories`](/slides/python-net/ko/aspose.slides.charts/chartdata/secondary_categories) 속성 return None and data 
            [`ChartData.categories`](/slides/python-net/ko/aspose.slides.charts/chartdata/categories) 속성의 데이터는 기본 및 보조 시리즈 모두에 사용됩니다.
            If true then data in [`ChartData.secondary_categories`](/slides/python-net/ko/aspose.slides.charts/chartdata/secondary_categories) 속성은 보조 시리즈에 사용되고 데이터 
            [`ChartData.categories`](/slides/python-net/ko/aspose.slides.charts/chartdata/categories) 속성의 데이터는 기본 시리즈에 사용됩니다.
            Read/write **bool**.
