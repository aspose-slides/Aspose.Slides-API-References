## ChartDataPointCollection 클래스

시리즈 데이터 포인트의 컬렉션을 나타냅니다.

ChartDataPointCollection 유형은 다음 멤버를 노출합니다:

## 속성

| Property | Description |
| :- | :- |
| [`data_source_type_for_x_values`](/slides/python-net/ko/aspose.slides.charts/chartdatapointcollection/data_source_type_for_x_values/) | AsCell 또는 AsLiteralString 또는 AsLiteralDouble 속성이 데이터 포인트 XValue 속성 객체에 실제로 사용되는지를 지정합니다.<br/>            다시 말해 ChartDataPoint.XValue.Data 속성의 값 유형을 지정합니다.<br/>            읽기/쓰기 [`DataSourceType`](/slides/python-net/ko/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_y_values`](/slides/python-net/ko/aspose.slides.charts/chartdatapointcollection/data_source_type_for_y_values/) | AsCell 또는 AsLiteralString 또는 AsLiteralDouble 속성이 데이터 포인트 YValue 속성 객체에 실제로 사용되는지를 지정합니다.<br/>            다시 말해 ChartDataPoint.YValue.Data 속성의 값 유형을 지정합니다.<br/>            읽기/쓰기 [`DataSourceType`](/slides/python-net/ko/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_bubble_sizes`](/slides/python-net/ko/aspose.slides.charts/chartdatapointcollection/data_source_type_for_bubble_sizes/) | AsCell 또는 AsLiteralString 또는 AsLiteralDouble 속성이 데이터 포인트 BubbleSize 속성 객체에 실제로 사용되는지를 지정합니다.<br/>            다시 말해 ChartDataPoint.BubbleSize.Data 속성의 값 유형을 지정합니다.<br/>            읽기/쓰기 [`DataSourceType`](/slides/python-net/ko/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_values`](/slides/python-net/ko/aspose.slides.charts/chartdatapointcollection/data_source_type_for_values/) | AsCell 또는 AsLiteralString 또는 AsLiteralDouble 속성이 데이터 포인트 Value 속성 객체에 실제로 사용되는지를 지정합니다.<br/>            다시 말해 ChartDataPoint.Value.Data 속성의 값 유형을 지정합니다.<br/>            읽기/쓰기 [`DataSourceType`](/slides/python-net/ko/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_error_bars_custom_values`](/slides/python-net/ko/aspose.slides.charts/chartdatapointcollection/data_source_type_for_error_bars_custom_values/) | ChartDataPoint.ErrorBarsCustomValues 속성 목록에 있는 값 유형을 지정합니다.<br/>            읽기 전용 [`IDataSourceTypeForErrorBarsCustomValues`](/slides/python-net/ko/aspose.slides.charts/idatasourcetypeforerrorbarscustomvalues). |

컬렉션에서 인덱스(해당 컬렉션 내 일련 번호)로 시리즈 데이터 포인트를 반환합니다.
