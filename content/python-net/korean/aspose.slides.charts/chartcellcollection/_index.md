## ChartCellCollection 클래스

데이터가 있는 셀들의 컬렉션을 나타냅니다.

ChartCellCollection 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`count`](/slides/python-net/ko/aspose.slides.charts/chartcellcollection/count/) | 컬렉션의 셀 수를 가져옵니다.<br/>            읽기 전용 **int**. |

인덱스로 셀 (IChartDataCell)을 반환합니다.

## 인덱서

| 이름 | 설명 |
| :- | :- |
| [`[index]`](/slides/python-net/ko/aspose.slides.charts/chartcellcollection/__getitem__/) | 셀의 인덱스. |
