## TrendlineType 열거형

추세선 유형을 나타냅니다.

TrendlineType 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| EXPONENTIAL | 추세선이 형태의 지수 곡선이어야 함을 지정합니다. |
| LINEAR | 추세선이 형태의 직선이어야 함을 지정합니다. |
| LOGARITHMIC | 추세선이 형태의 로그 곡선이어야 함을 지정하며, 여기서 log는 자연 로그입니다. |
| MOVING_AVERAGE | 추세선이 기간 Period의 이동 평균이어야 함을 지정합니다. |
| POLYNOMIAL | 추세선이 형태의 차수 Order인 다항 곡선이어야 함을 지정합니다. |
| POWER | 추세선이 형태의 거듭제곱 곡선이어야 함을 지정합니다. |
