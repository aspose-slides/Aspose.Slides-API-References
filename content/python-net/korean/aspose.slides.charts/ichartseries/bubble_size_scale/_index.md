## bubble_size_scale 속성
버블 차트의 배율 요소를 지정합니다 (가능한 값은 
            기본 크기의 0%에서 300% 사이입니다).
            이 속성은 이 시리즈뿐만 아니라 상위 시리즈 그룹의 모든 시리즈에 적용됩니다 
            그룹 - 이는 해당 그룹 속성의 투영입니다. 따라서 이 속성은 
            읽기 전용입니다.
            ParentSeriesGroup 속성을 사용하여 상위 시리즈 그룹에 접근합니다.
            ParentSeriesGroup.BubbleSizeScale 읽기/쓰기 속성을 사용하여 값을 변경합니다.


### 비고

이는 속성 ParentSeriesGroup.BubbleSizeScale의 투영입니다.
