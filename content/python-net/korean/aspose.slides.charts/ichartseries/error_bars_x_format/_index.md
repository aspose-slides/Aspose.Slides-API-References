## error_bars_x_format 속성
시리즈의 X 방향 ErrorBars를 나타냅니다.
            
            ErrorBars는 X 방향에 대해 area, bar, scatter 및 bubble 유형의 시리즈에 사용할 수 있습니다. 
            다른 모든 차트 유형에 대해서는 이 속성이 None을 반환합니다 (3D 차트 포함).
            사용자 정의 값의 경우 DataPoints 컬렉션을 사용하여 값을 지정합니다
            ([`IChartDataPoint.error_bars_custom_values`](/slides/python-net/ko/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) 속성을 사용하여).
            
            읽기 전용 [`IErrorBarsFormat`](/slides/python-net/ko/aspose.slides.charts/ierrorbarsformat).
