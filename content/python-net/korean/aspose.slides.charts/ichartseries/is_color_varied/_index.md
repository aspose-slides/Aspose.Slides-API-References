## is_color_varied 속성
Specifies that each data marker in the series has a different color.
            이 속성은 이 시리즈뿐만 아니라 상위 시리즈 그룹의 모든 시리즈에도 적용되는 속성이며 
            그룹 - 해당 그룹 속성의 투영입니다. 따라서 이 속성 
            은 읽기 전용입니다.
            ParentSeriesGroup 속성을 사용하여 상위 시리즈 그룹에 액세스합니다.
            ParentSeriesGroup.IsColorVaried 읽기/쓰기 속성을 사용하여 값을 변경합니다.
            읽기 전용 **bool**.


### 비고

이는 속성 ParentSeriesGroup.IsColorVaried의 투영입니다.
