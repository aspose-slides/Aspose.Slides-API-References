## ChartPlotArea 클래스

차트가 그려져야 하는 사각형을 나타냅니다.

ChartPlotArea 유형은 다음 멤버를 노출합니다:

## 속성

| Property | Description |
| :- | :- |
| [`format`](/slides/python-net/ko/aspose.slides.charts/chartplotarea/format/) | 플롯 영역의 형식을 반환합니다.<br/>            읽기 전용 [`IFormat`](/slides/python-net/ko/aspose.slides.charts/iformat). |
| [`x`](/slides/python-net/ko/aspose.slides.charts/chartplotarea/x/) | 플롯 영역 경계 상자의 왼쪽 위 모서리의 x 좌표를 차트 너비의 비율(0~1)로 반환하거나 설정합니다.<br/>            읽기/쓰기 **float**. |
| [`y`](/slides/python-net/ko/aspose.slides.charts/chartplotarea/y/) | 플롯 영역 경계 상자의 왼쪽 위 모서리의 y 좌표를 차트 높이의 비율(0~1)로 반환하거나 설정합니다.<br/>            읽기/쓰기 **float**. |
| [`width`](/slides/python-net/ko/aspose.slides.charts/chartplotarea/width/) | 플롯 영역 경계 상자의 너비를 차트 너비의 비율(0~1)로 반환하거나 설정합니다.<br/>            읽기/쓰기 **float**. |
| [`height`](/slides/python-net/ko/aspose.slides.charts/chartplotarea/height/) | 플롯 영역 경계 상자의 높이를 차트 높이의 비율(0~1)로 반환하거나 설정합니다.<br/>            읽기/쓰기 **float**. |
| [`right`](/slides/python-net/ko/aspose.slides.charts/chartplotarea/right/) | 오른쪽.<br/>            읽기 전용 **float**. |
| [`bottom`](/slides/python-net/ko/aspose.slides.charts/chartplotarea/bottom/) | 아래.<br/>            읽기 전용 **float**. |
| [`chart`](/slides/python-net/ko/aspose.slides.charts/chartplotarea/chart/) | 차트.<br/>            읽기 전용 [`IChart`](/slides/python-net/ko/aspose.slides.charts/ichart). |
| [`is_location_autocalculated`](/slides/python-net/ko/aspose.slides.charts/chartplotarea/is_location_autocalculated/) | 위치 계산 방법을 정의합니다: true – 자동으로 계산됨; X, Y, Width, Height 속성에 의해 정의됩니다.<br/>            읽기 전용 **bool**. |
| [`layout_target_type`](/slides/python-net/ko/aspose.slides.charts/chartplotarea/layout_target_type/) | 플롯 영역 레이아웃이 수동으로 정의된 경우 이 속성은 내부(축 및 축 레이블 제외) 또는 외부(축 및 축 레이블 포함) 중 어디에 레이아웃을 할지 지정합니다.<br/>            읽기/쓰기 [`ChartPlotArea.layout_target_type`](/slides/python-net/ko/aspose.slides.charts/chartplotarea/layout_target_type). |
| [`actual_x`](/slides/python-net/ko/aspose.slides.charts/chartplotarea/actual_x/) | 차트 요소의 실제 x 위치(왼쪽)를 차트의 왼쪽 상단 모서리와 상대적으로 지정합니다.<br/>            IChart.ValidateChartLayout() 메서드를 호출하여 실제 값을 가져오세요. <br/>            읽기 **float**. |
| [`actual_y`](/slides/python-net/ko/aspose.slides.charts/chartplotarea/actual_y/) | 차트 요소의 실제 상단을 차트의 왼쪽 상단 모서리와 상대적으로 지정합니다.<br/>            IChart.ValidateChartLayout() 메서드를 호출하여 실제 값을 가져오세요. <br/>            읽기 **float**. |
| [`actual_width`](/slides/python-net/ko/aspose.slides.charts/chartplotarea/actual_width/) | 차트 요소의 실제 너비를 지정합니다. IChart.ValidateChartLayout() 메서드를 호출하여 실제 값을 가져오세요. <br/>            읽기 **float**. |
| [`actual_height`](/slides/python-net/ko/aspose.slides.charts/chartplotarea/actual_height/) | 차트 요소의 실제 높이를 지정합니다. IChart.ValidateChartLayout() 메서드를 호출하여 실제 값을 가져오세요. <br/>            읽기 **float**. |
