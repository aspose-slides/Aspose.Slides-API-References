## ChartShapeType 열거형

차트의 모양을 나타냅니다.

ChartShapeType 타입은 다음 멤버를 노출합니다:

## 필드

| Field | Description |
| :- | :- |
| NOT_DEFINED | 차트 모양이 정의되지 않았습니다. |
| BOX | 차트가 박스 형태로 그려짐을 지정합니다. |
| CONE | 차트가 원뿔 형태로 그려짐을 지정합니다. 원뿔의 바닥은 바닥에 놓이고 원뿔의 꼭짓점은 데이터 마커의 상단에 위치합니다. |
| CONE_TO_MAX | 차트가 잘린 원뿔 형태로 그려짐을 지정합니다. 원뿔의 꼭짓점이 최대 데이터 값이 되도록 합니다. |
| CYLINDER | 차트가 원통 형태로 그려짐을 지정합니다. |
| PYRAMID | 차트가 직사각형 피라미드 형태로 그려짐을 지정합니다. 피라미드의 바닥은 바닥에 놓이고 피라미드의 꼭짓점은 데이터 마커의 상단에 위치합니다. |
| PYRAMID_TO_MAXIMUM | 차트가 잘린 원뿔 형태로 그려짐을 지정합니다. 원뿔의 꼭짓점이 최대 데이터 값이 되도록 합니다. |
