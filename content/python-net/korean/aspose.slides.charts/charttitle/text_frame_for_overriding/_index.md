## text_frame_for_overriding 속성
리치 형식 텍스트를 포함할 수 있습니다. 이 속성이 None이 아니면 이 형식화된 텍스트 값이 자동 생성된 텍스트를 대체합니다.
            자동 생성된 텍스트는 데이터 레이블, 값 축의 표시 단위 레이블, 축 제목, 차트 제목, 추세선 레이블의 암시적 속성입니다.
            자동 생성된 텍스트는 IFormattedTextContainer.TextFormat 속성을 사용해 형식이 지정됩니다.
            읽기 전용 [`ITextFrame`](/slides/python-net/ko/aspose.slides/itextframe).
