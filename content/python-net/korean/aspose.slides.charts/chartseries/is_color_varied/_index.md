## is_color_varied 속성
Specifies that each data marker in the series has a different color.
            이 속성은 이 시리즈에만 국한되지 않고 상위 시리즈 그룹의 모든 시리즈에 적용됩니다 - 해당 그룹 속성의 투영입니다. 따라서 이 속성은 읽기 전용입니다.
            상위 시리즈 그룹에 접근하려면 ParentSeriesGroup 속성을 사용하십시오.
            값을 변경하려면 ParentSeriesGroup.IsColorVaried 읽기/쓰기 속성을 사용하십시오.
            읽기 전용 **bool**.


### 비고

이는 속성 ParentSeriesGroup.IsColorVaried의 투영입니다.
