## pie_split_position 속성
파이-오브-파이 또는 바-오브-파이 차트에서 두 번째 파이 또는 바에 포함되는 데이터 포인트를 결정하는 데 사용되는 값을 지정합니다. 
            두 번째 파이 또는 바에 포함됩니다. 
            PieSplitBy 속성과 함께 사용됩니다. 
            이 속성은 이 시리즈뿐만 아니라 상위 시리즈 그룹의 모든 시리즈에 적용됩니다. 
            이는 해당 그룹 속성의 투영이며, 따라서 이 속성은 
            읽기 전용입니다. 
            ParentSeriesGroup 속성을 사용하여 상위 시리즈 그룹에 접근합니다. 
            값을 변경하려면 ParentSeriesGroup.PieSplitPosition 읽기/쓰기 속성을 사용합니다. 
            읽기 전용 **float**.

### 비고

이것은 속성 ParentSeriesGroup.PieSplitPosition의 투영입니다.
