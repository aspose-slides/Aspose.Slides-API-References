## gap_width 속성
막대 또는 열 클러스터 사이의 공간을 막대 또는 열 너비의 백분율로 지정합니다.
            이 속성은 이 시리즈에만 국한되는 것이 아니라 상위 시리즈 그룹의 모든 시리즈에 적용됩니다 - 이는 해당 그룹 속성의 투영입니다. 따라서 이 속성은 읽기 전용입니다.
            상위 시리즈 그룹에 접근하려면 ParentSeriesGroup 속성을 사용하십시오.
            값을 변경하려면 ParentSeriesGroup.GapWidth 읽기/쓰기 속성을 사용하십시오.
            읽기 전용 **int**.


### 비고

이는 속성 ParentSeriesGroup.GapWidth의 투영입니다.
