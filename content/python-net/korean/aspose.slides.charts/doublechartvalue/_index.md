## DoubleChartValue 클래스

pptx 프레젠테이션 문서에 두 가지 방식으로 저장될 수 있는 double 값을 나타냅니다:
1) 차트와 관련된 워크북의 cell/cells;
2) 리터럴 값.

**상속:**[`DoubleChartValue`](/slides/python-net/ko/aspose.slides.charts/doublechartvalue) → [`BaseChartValue`](/slides/python-net/ko/aspose.slides.charts/basechartvalue)

DoubleChartValue 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`data_source_type`](/slides/python-net/ko/aspose.slides.charts/doublechartvalue/data_source_type/) | AsCell, AsCells, AsLiteralString 또는 AsLiteralDouble <br/>            property가 하위 클래스에서 실제로 사용되는지 지정합니다. 즉 Data property의 값 유형을 지정합니다.<br/>            **읽기/쓰기** [`DataSourceType`](/slides/python-net/ko/aspose.slides.charts/datasourcetype). |
| [`data`](/slides/python-net/ko/aspose.slides.charts/doublechartvalue/data/) | Data 객체를 반환하거나 설정합니다.<br/>            **읽기/쓰기** **any**. |
| [`as_cell`](/slides/python-net/ko/aspose.slides.charts/doublechartvalue/as_cell/) | 차트 데이터 셀을 반환하거나 설정합니다.<br/>            **읽기/쓰기** [`IChartDataCell`](/slides/python-net/ko/aspose.slides.charts/ichartdatacell). |
| [`as_literal_double`](/slides/python-net/ko/aspose.slides.charts/doublechartvalue/as_literal_double/) | 값을 리터럴 double로 반환하거나 설정합니다.<br/>            **읽기/쓰기** **float**. |
