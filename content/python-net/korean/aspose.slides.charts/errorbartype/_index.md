## ErrorBarType 열거형

오류 표시줄의 유형을 나타냅니다

ErrorBarType 유형은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| BOTH | 양의 방향과 음의 방향 모두에 오류 표시줄이 표시됩니다. |
| MINUS | 음의 방향에만 오류 표시줄이 표시됩니다. |
| PLUS | 양의 방향에만 오류 표시줄이 표시됩니다. |
