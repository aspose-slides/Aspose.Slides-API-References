## WorkbookType 열거형

Open XML 워크북 파일의 유형을 지정합니다.

WorkbookType 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| NOT_DEFINED | 워크북 유형이 정의되지 않았습니다. |
| WORKBOOK | Excel 워크북(*.xlsx). |
| WORKBOOK_MACRO | Excel 매크로 사용 워크북(*.xlsm). |
| TEMPLATE | Excel 템플릿(*.xltx). |
| TEMPLATE_MACRO | Excel 매크로 사용 템플릿(*.xltm). |
| WORKBOOK_BINARY_MACRO | Excel 바이너리 매크로 사용 워크북(*.xlsb). |
