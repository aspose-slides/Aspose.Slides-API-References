## MarkerStyleType 열거형

차트의 데이터 포인트에 표시되는 마커의 형태를 결정합니다.

MarkerStyleType 유형은 다음 멤버를 제공합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| NOT_DEFINED |  |
| CIRCLE | 각 데이터 포인트에 원이 그려집니다. |
| DASH | 각 데이터 포인트에 대시가 그려집니다. |
| DIAMOND | 각 데이터 포인트에 다이아몬드가 그려집니다. |
| DOT | 각 데이터 포인트에 점이 그려집니다. |
| NONE | 각 데이터 포인트에 아무것도 그리지 않습니다. |
| PICTURE | 각 데이터 포인트에 그림이 그려집니다. |
| PLUS | 각 데이터 포인트에 플러스가 그려집니다. |
| SQUARE | 각 데이터 포인트에 사각형이 그려집니다. |
| STAR | 각 데이터 포인트에 별이 그려집니다. |
| TRIANGLE | 각 데이터 포인트에 삼각형이 그려집니다. |
| X | 각 데이터 포인트에 X가 그려집니다. |
