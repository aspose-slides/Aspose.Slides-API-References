## backward 속성
추세선이 확장되는 범주(또는 산점도 차트의 단위) 수를 지정합니다.
            해당 시리즈의 데이터 이전까지 적용됩니다. 산점도 및 비산점도 차트에서는 값이 0 이상인 모든 값을 허용합니다.
            읽기/쓰기 **float**.
