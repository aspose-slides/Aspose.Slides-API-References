## LegendEntryCollection 클래스

범례 컬렉션을 나타냅니다.

LegendEntryCollection 타입은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`count`](/slides/python-net/ko/aspose.slides.charts/legendentrycollection/count/) | 범례 항목 수를 가져옵니다.<br/>            읽기 전용 **int**. |

Chart.ChartData.Series[0].DataPoints[index]에 해당하는 범례 항목의 속성을 가져옵니다.
            차트 유형이 다음 목록 중 하나인 경우:
              ChartType.BarOfPie,
              ChartType.ExplodedPie,
              ChartType.ExplodedPie3D,
              ChartType.Pie,
              ChartType.Pie3D,
              ChartType.PieOfPie;
            또는 다른 차트 유형에 대해서는 Chart.ChartData.Series[index]에 해당합니다.
