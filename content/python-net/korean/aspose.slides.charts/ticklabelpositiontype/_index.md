## TickLabelPositionType 열거형

지정된 축에서 눈금 레이블의 위치 유형을 나타냅니다.

TickLabelPositionType 유형은 다음 멤버를 노출합니다:

## 필드

| Field | Description |
| :- | :- |
| HIGH | 축 레이블이 수직 축의 높은 쪽에 있어야 함을 지정합니다. |
| LOW | 축 레이블이 수직 축의 낮은 쪽에 있어야 함을 지정합니다. |
| NEXT_TO | 축 레이블이 축 옆에 있어야 함을 지정합니다. |
| NONE | 축 레이블이 그려지지 않음을 지정합니다. |
