## text_frame_for_overriding 속성
풍부하게 서식이 지정된 텍스트를 포함할 수 있습니다. 만약 이 속성이 None이 아닌 경우, 이 서식이 지정된 텍스트 값은 데이터 레이블의 자동 생성 텍스트를 대체합니다. 데이터 레이블의 자동 생성 텍스트는 ShowSeriesName, ShowValue, ... 속성에 의해 관리되고 TextFormatManager.TextFormat 속성으로 서식이 지정됩니다. 읽기 전용 [`ITextFrame`](/slides/python-net/ko/aspose.slides/itextframe).
