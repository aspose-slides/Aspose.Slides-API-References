## IChartCellCollection 클래스

데이터가 있는 셀들의 컬렉션을 나타냅니다.

IChartCellCollection 형식은 다음 멤버를 노출합니다:

## 속성

| Property | Description |
| :- | :- |
| [`count`](/slides/python-net/ko/aspose.slides.charts/ichartcellcollection/count/) | 컬렉션에 있는 셀 수를 가져옵니다.<br/>            읽기 전용 **int**. |

인덱스를 사용하여 셀 (IChartDataCell)을 반환합니다.

## 인덱서

| Name | Description |
| :- | :- |
| [`[index]`](/slides/python-net/ko/aspose.slides.charts/ichartcellcollection/__getitem__/) | 셀의 인덱스. |
