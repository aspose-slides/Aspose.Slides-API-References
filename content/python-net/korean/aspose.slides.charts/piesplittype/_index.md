## PieSplitType 열거형

이 차트 유형의 두 번째 파이 또는 바에 대한 분할 포인트 유형을 나타냅니다.

PieSplitType 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| DEFAULT | 데이터 포인트는 이 차트 유형에 대한 기본 <br/>            메커니즘을 사용하여 분할됩니다. |
| CUSTOM | 데이터 포인트는 <br/>            사용자 정의 분할 값에 따라 파이와 두 번째 차트 사이에 분할됩니다. |
| BY_PERCENTAGE | 데이터 포인트는 <br/>            퍼센트가 Split Position 퍼센트보다 작은 포인트를 두 번째 차트에 배치함으로써 파이와 두 번째 차트 사이에 분할됩니다. |
| BY_POS | 데이터 포인트는 <br/>            데이터 포인트의 마지막 Split Position을 두 번째 차트에 배치함으로써 파이와 두 번째 차트 사이에 분할됩니다. |
| BY_VALUE | 데이터 포인트는 <br/>            값이 Split Position보다 작은 포인트를 두 번째 차트에 배치함으로써 파이와 두 번째 차트 사이에 분할됩니다. |
