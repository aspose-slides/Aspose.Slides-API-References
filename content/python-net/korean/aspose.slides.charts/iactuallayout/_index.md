## IActualLayout class

차트 요소의 실제 위치를 지정합니다.

IActualLayout 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`actual_x`](/slides/python-net/ko/aspose.slides.charts/iactuallayout/actual_x/) | 차트 요소의 왼쪽 상단 모서리를 기준으로 실제 x 위치(왼쪽)를 지정합니다.<br/>            실제 값을 얻으려면 IChart.ValidateChartLayout() 메서드를 먼저 호출하십시오. <br/>            읽기 **float**. |
| [`actual_y`](/slides/python-net/ko/aspose.slides.charts/iactuallayout/actual_y/) | 차트 요소의 왼쪽 상단 모서리를 기준으로 실제 상단 위치를 지정합니다.<br/>            실제 값을 얻으려면 IChart.ValidateChartLayout() 메서드를 먼저 호출하십시오. <br/>            읽기 **float**. |
| [`actual_width`](/slides/python-net/ko/aspose.slides.charts/iactuallayout/actual_width/) | 차트 요소의 실제 너비를 지정합니다. 실제 값을 얻으려면 IChart.ValidateChartLayout() 메서드를 먼저 호출하십시오. <br/>            읽기 **float**. |
| [`actual_height`](/slides/python-net/ko/aspose.slides.charts/iactuallayout/actual_height/) | 차트 요소의 실제 높이를 지정합니다. 실제 값을 얻으려면 IChart.ValidateChartLayout() 메서드를 먼저 호출하십시오. <br/>            읽기 **float**. |
