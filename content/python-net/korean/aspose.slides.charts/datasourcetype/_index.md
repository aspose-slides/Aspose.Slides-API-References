## DataSourceType 열거형

데이터 소스 유형입니다.

DataSourceType 유형은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| WORKSHEET | 워크시트에서 데이터 포인트의 XValue, YValue, Value 또는 BubbleSize를 저장하기 위해 CellXls 객체를 사용합니다. |
| STRING_LITERALS | 빠른 액세스 문자열 변수를 사용하여 데이터 포인트의 XValue, YValue, Value 또는 BubbleSize를 저장합니다.<br/>            워크시트는 값을 저장하는 데 사용되지 않습니다. |
| DOUBLE_LITERALS | 빠른 액세스 double 변수를 사용하여 데이터 포인트의 XValue, YValue, Value 또는 BubbleSize를 저장합니다.<br/>            워크시트는 값을 저장하는 데 사용되지 않습니다. |
