## Legend 클래스

차트의 레전드 속성을 나타냅니다.

Legend 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`x`](/slides/python-net/ko/aspose.slides.charts/legend/x/) | 레전드의 x 좌표를 차트 너비에 대한 비율로 반환하거나 설정합니다.<br/>            읽기/쓰기 **float**. |
| [`y`](/slides/python-net/ko/aspose.slides.charts/legend/y/) | 레전드의 y 좌표를 차트 높이에 대한 비율로 반환하거나 설정합니다.<br/>            읽기/쓰기 **float**. |
| [`width`](/slides/python-net/ko/aspose.slides.charts/legend/width/) | 레전드의 너비를 차트 너비에 대한 비율로 반환하거나 설정합니다.<br/>            읽기/쓰기 **float**. |
| [`height`](/slides/python-net/ko/aspose.slides.charts/legend/height/) | 레전드의 높이를 차트 높이에 대한 비율로 반환하거나 설정합니다.<br/>            읽기/쓰기 **float**. |
| [`right`](/slides/python-net/ko/aspose.slides.charts/legend/right/) | 오른쪽.<br/>            읽기 전용 **float**. |
| [`bottom`](/slides/python-net/ko/aspose.slides.charts/legend/bottom/) | 아래쪽.<br/>            읽기 전용 **float**. |
| [`overlay`](/slides/python-net/ko/aspose.slides.charts/legend/overlay/) | 다른 차트 요소가 레전드와 겹치도록 허용할지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |
| [`text_format`](/slides/python-net/ko/aspose.slides.charts/legend/text_format/) | 텍스트 형식.<br/>            읽기 전용 [`IChartTextFormat`](/slides/python-net/ko/aspose.slides.charts/icharttextformat). |
| [`position`](/slides/python-net/ko/aspose.slides.charts/legend/position/) | 차트에서 레전드의 위치를 지정합니다.<br/>            X, Y, Width, Heigt 속성의 Non-NaN 값은 이 속성의 효과를 재정의합니다.<br/>            읽기/쓰기 [`LegendPositionType`](/slides/python-net/ko/aspose.slides.charts/legendpositiontype). |
| [`format`](/slides/python-net/ko/aspose.slides.charts/legend/format/) | 레전드의 형식을 반환합니다.<br/>            읽기 전용 [`IFormat`](/slides/python-net/ko/aspose.slides.charts/iformat). |
| [`chart`](/slides/python-net/ko/aspose.slides.charts/legend/chart/) | 차트를 반환합니다.<br/>            읽기 전용 [`IChart`](/slides/python-net/ko/aspose.slides.charts/ichart). |
| [`entries`](/slides/python-net/ko/aspose.slides.charts/legend/entries/) | 레전드 항목을 가져옵니다.<br/>            읽기 전용 [`ILegendEntryCollection`](/slides/python-net/ko/aspose.slides.charts/ilegendentrycollection). |
| [`actual_x`](/slides/python-net/ko/aspose.slides.charts/legend/actual_x/) | 차트 요소의 실제 x 위치(왼쪽)를 차트 왼쪽 상단 모서리를 기준으로 지정합니다.<br/>            실제 값을 얻기 위해 IChart.ValidateChartLayout() 메서드를 먼저 호출하십시오. <br/>            읽기 **float**. |
| [`actual_y`](/slides/python-net/ko/aspose.slides.charts/legend/actual_y/) | 차트 요소의 실제 상단을 차트 왼쪽 상단 모서리를 기준으로 지정합니다.<br/>            실제 값을 얻기 위해 IChart.ValidateChartLayout() 메서드를 먼저 호출하십시오. <br/>            읽기 **float**. |
| [`actual_width`](/slides/python-net/ko/aspose.slides.charts/legend/actual_width/) | 차트 요소의 실제 너비를 지정합니다. 실제 값을 얻기 위해 IChart.ValidateChartLayout() 메서드를 먼저 호출하십시오. <br/>            읽기 **float**. |
| [`actual_height`](/slides/python-net/ko/aspose.slides.charts/legend/actual_height/) | 차트 요소의 실제 높이를 지정합니다. 실제 값을 얻기 위해 IChart.ValidateChartLayout() 메서드를 먼저 호출하십시오. <br/>            읽기 **float**. |
| [`slide`](/slides/python-net/ko/aspose.slides.charts/legend/slide/) |  |
| [`presentation`](/slides/python-net/ko/aspose.slides.charts/legend/presentation/) |  |
