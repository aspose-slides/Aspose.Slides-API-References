## use_cell 속성
true이면 AsCell 속성이 실제입니다. 다시 말해, 워크시트가 카테고리를 저장하는 데 사용됩니다 (이 경우 다단계 카테고리를 지원합니다).
false이면 AsLiteral 속성이 실제입니다. 다시 말해, 워크시트가 카테고리를 저장하는 데 사용되지 않습니다 (이 경우 다단계 카테고리를 지원하지 않습니다).
읽기 전용 **bool**.

### 비고

이 속성의 값을 변경하려면 (컬렉션의 모든 카테고리) ChartCategoryCollection.UseCells 속성에 새 값을 설정하십시오.
