## IDataTable 클래스

데이터 테이블 속성을 나타냅니다.

IDataTable 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`format`](/slides/python-net/ko/aspose.slides.charts/idatatable/format/) | 객체의 선, 채우기 및 효과 스타일을 반환합니다.<br/>            읽기 전용 [`IFormat`](/slides/python-net/ko/aspose.slides.charts/iformat). |
| [`has_border_horizontal`](/slides/python-net/ko/aspose.slides.charts/idatatable/has_border_horizontal/) | 차트 데이터 테이블에 가로 셀 테두리가 있는 경우 True.<br/>            읽기/쓰기 **bool**. |
| [`has_border_outline`](/slides/python-net/ko/aspose.slides.charts/idatatable/has_border_outline/) | 차트 데이터 테이블에 외곽선 테두리가 있는 경우 True.<br/>            읽기/쓰기 **bool**. |
| [`has_border_vertical`](/slides/python-net/ko/aspose.slides.charts/idatatable/has_border_vertical/) | 차트 데이터 테이블에 세로 셀 테두리가 있는 경우 True.<br/>            읽기/쓰기 **bool**. |
| [`show_legend_key`](/slides/python-net/ko/aspose.slides.charts/idatatable/show_legend_key/) | 데이터 레이블 범례 키가 표시되는 경우 True.<br/>            읽기/쓰기 **bool**. |
