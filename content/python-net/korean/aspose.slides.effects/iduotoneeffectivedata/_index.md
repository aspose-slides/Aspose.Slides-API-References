## IDuotoneEffectiveData 클래스

듀오톤 효과를 나타내는 불변 객체입니다.
각 픽셀에 대해 clr1과 clr2를 선형 보간을 통해 결합하여 해당 픽셀의 새 색상을 결정합니다.

IDuotoneEffectiveData 형식은 다음 멤버를 노출합니다:

## 속성

| :- | :- |
| [`color1`](/slides/python-net/ko/aspose.slides.effects/iduotoneeffectivedata/color1/) | 다크 픽셀에 대한 대상 색상 형식을 반환합니다.<br/>            읽기 전용 **aspose.slides.Color**. |
| [`color2`](/slides/python-net/ko/aspose.slides.effects/iduotoneeffectivedata/color2/) | 라이트 픽셀에 대한 대상 색상 형식을 반환합니다.<br/>            읽기 전용 **aspose.slides.Color**. |
