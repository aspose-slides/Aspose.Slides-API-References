## IBlurEffectiveData 클래스

전체 도형에 적용되는 블러 효과를 나타내는 불변 객체이며, 채우기 영역도 포함합니다.<br/>알파 채널을 포함한 모든 색상 채널이 영향을 받습니다.

IBlurEffectiveData 유형은 다음 멤버를 노출합니다:

## 속성

| Property | Description |
| :- | :- |
| [`radius`](/slides/python-net/ko/aspose.slides.effects/iblureffectivedata/radius/) | 블러 반경을 반환하거나 설정합니다.<br/>            읽기 전용 **float**. |
| [`grow`](/slides/python-net/ko/aspose.slides.effects/iblureffectivedata/grow/) | 블러링 결과 객체의 경계가 확대되어야 하는지 여부를 결정합니다.<br/>            True는 경계가 확대됨을 의미하고 false는 그렇지 않음을 의미합니다.<br/>            읽기 전용 **bool**. |
