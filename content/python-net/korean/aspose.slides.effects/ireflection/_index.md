## IReflection 클래스

반사 효과를 나타냅니다.

IReflection 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/ko/aspose.slides.effects/ireflection/start_pos_alpha/) | 시작 알파 값(백분율)의 알파 그라디언트 램프를 따라 시작 위치를 지정합니다.<br/>            읽기/쓰기 **float**. |
| [`end_pos_alpha`](/slides/python-net/ko/aspose.slides.effects/ireflection/end_pos_alpha/) | 끝 알파 값(백분율)의 알파 그라디언트 램프를 따라 끝 위치를 지정합니다.<br/>            읽기/쓰기 **float**. |
| [`fade_direction`](/slides/python-net/ko/aspose.slides.effects/ireflection/fade_direction/) | 반사를 오프셋할 방향을 지정합니다(각도).<br/>            읽기/쓰기 **float**. |
| [`start_reflection_opacity`](/slides/python-net/ko/aspose.slides.effects/ireflection/start_reflection_opacity/) | 시작 반사 불투명도(백분율)를 지정합니다.<br/>            읽기/쓰기 **float**. |
| [`end_reflection_opacity`](/slides/python-net/ko/aspose.slides.effects/ireflection/end_reflection_opacity/) | 끝 반사 불투명도(백분율)를 지정합니다.<br/>            읽기/쓰기 **float**. |
| [`blur_radius`](/slides/python-net/ko/aspose.slides.effects/ireflection/blur_radius/) | 블러 반경을 지정합니다.<br/>            읽기/쓰기 **float**. |
| [`direction`](/slides/python-net/ko/aspose.slides.effects/ireflection/direction/) | 반사의 방향을 지정합니다.<br/>            읽기/쓰기 **float**. |
| [`distance`](/slides/python-net/ko/aspose.slides.effects/ireflection/distance/) | 반사의 거리를 지정합니다.<br/>            읽기/쓰기 **float**. |
| [`rectangle_align`](/slides/python-net/ko/aspose.slides.effects/ireflection/rectangle_align/) | 사각형 정렬을 지정합니다.<br/>            읽기/쓰기 [`RectangleAlignment`](/slides/python-net/ko/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/ko/aspose.slides.effects/ireflection/skew_horizontal/) | 수평 왜곡 각도를 지정합니다.<br/>            읽기/쓰기 **float**. |
| [`skew_vertical`](/slides/python-net/ko/aspose.slides.effects/ireflection/skew_vertical/) | 수직 왜곡 각도를 지정합니다.<br/>            읽기/쓰기 **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/ko/aspose.slides.effects/ireflection/rotate_shadow_with_shape/) | 모양이 회전된 경우 반사도 모양과 함께 회전해야 하는지 여부를 지정합니다.<br/>            읽기/쓰기 **bool**. |
| [`scale_horizontal`](/slides/python-net/ko/aspose.slides.effects/ireflection/scale_horizontal/) | 수평 스케일링 계수를 지정합니다. 음수 스케일링은 플립을 일으킵니다(백분율).<br/>            읽기/쓰기 **float**. |
| [`scale_vertical`](/slides/python-net/ko/aspose.slides.effects/ireflection/scale_vertical/) | 수직 스케일링 계수를 지정합니다. 음수 스케일링은 플립을 일으킵니다(백분율).<br/>            읽기/쓰기 **float**. |
