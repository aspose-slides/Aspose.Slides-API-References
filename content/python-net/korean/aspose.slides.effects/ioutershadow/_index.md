## IOuterShadow 클래스

외부 그림자 효과를 나타냅니다.

IOuterShadow 형식은 다음 멤버를 노출합니다:

## 속성

| Property | Description |
| :- | :- |
| [`blur_radius`](/slides/python-net/ko/aspose.slides.effects/ioutershadow/blur_radius/) | 포인트 단위 흐림 반경.<br/>            기본값 – 0 pt.<br/>            읽기/쓰기 **float**. |
| [`direction`](/slides/python-net/ko/aspose.slides.effects/ioutershadow/direction/) | 그림자 방향, 도 단위.<br/>            기본값 – 0 ° (왼쪽에서 오른쪽).<br/>            읽기/쓰기 **float**. |
| [`distance`](/slides/python-net/ko/aspose.slides.effects/ioutershadow/distance/) | 그림자가 객체에서 떨어진 거리, 포인트 단위.<br/>            기본값 – 0 pt.<br/>            읽기/쓰기 **float**. |
| [`shadow_color`](/slides/python-net/ko/aspose.slides.effects/ioutershadow/shadow_color/) | 그림자 색상.<br/>            기본값 – 자동 검정(테마 의존).<br/>            읽기 전용 [`IColorFormat`](/slides/python-net/ko/aspose.slides/icolorformat). |
| [`rectangle_align`](/slides/python-net/ko/aspose.slides.effects/ioutershadow/rectangle_align/) | 사각형 정렬.<br/>            기본값 – [`RectangleAlignment.BOTTOM`](/slides/python-net/ko/aspose.slides/rectanglealignment/BOTTOM). <br/>            읽기/쓰기 [`RectangleAlignment`](/slides/python-net/ko/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/ko/aspose.slides.effects/ioutershadow/skew_horizontal/) | 수평 기울기 각도, 도 단위.<br/>            기본값 – 0 °.<br/>            읽기/쓰기 **float**. |
| [`skew_vertical`](/slides/python-net/ko/aspose.slides.effects/ioutershadow/skew_vertical/) | 수직 기울기 각도, 도 단위.<br/>            기본값 – 0 °.<br/>            읽기/쓰기 **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/ko/aspose.slides.effects/ioutershadow/rotate_shadow_with_shape/) | 그림자와 형태가 함께 회전하는지 여부를 나타냅니다.<br/>            기본값 – true.<br/>            읽기/쓰기 **bool**. |
| [`scale_horizontal`](/slides/python-net/ko/aspose.slides.effects/ioutershadow/scale_horizontal/) | 원래 크기의 백분율로 표시되는 수평 스케일링 요인.<br/>            음수 스케일링은 뒤집기를 일으킵니다.<br/>            기본값 – 100 %.<br/>            읽기/쓰기 **float**. |
| [`scale_vertical`](/slides/python-net/ko/aspose.slides.effects/ioutershadow/scale_vertical/) | 원래 크기의 백분율로 표시되는 수직 스케일링 요인.<br/>            음수 스케일링은 뒤집기를 일으킵니다.<br/>            기본값 – 100 %.<br/>            읽기/쓰기 **float**. |
