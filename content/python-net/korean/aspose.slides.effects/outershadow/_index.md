## OuterShadow 클래스

외부 그림자 효과를 나타냅니다.

OuterShadow 타입은 다음 멤버를 제공합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`blur_radius`](/slides/python-net/ko/aspose.slides.effects/outershadow/blur_radius/) | Blur radius, in points.<br/>            Default value – 0 pt.<br/>            Read/write **float**. |
| [`direction`](/slides/python-net/ko/aspose.slides.effects/outershadow/direction/) | Direction of the shadow, in degrees.<br/>            Default value – 0 ° (left-to-right).<br/>            Read/write **float**. |
| [`distance`](/slides/python-net/ko/aspose.slides.effects/outershadow/distance/) | Distance of the shadow from the object, in points.<br/>            Default value – 0 pt.<br/>            Read/write **float**. |
| [`shadow_color`](/slides/python-net/ko/aspose.slides.effects/outershadow/shadow_color/) | Color of the shadow.<br/>            Default value – automatic black (theme-dependent).<br/>            Read-only [`IColorFormat`](/slides/python-net/ko/aspose.slides/icolorformat). |
| [`rectangle_align`](/slides/python-net/ko/aspose.slides.effects/outershadow/rectangle_align/) | Rectangle alignment.<br/>            Default value – [`RectangleAlignment.BOTTOM`](/slides/python-net/ko/aspose.slides/rectanglealignment/BOTTOM). <br/>            Read/write [`RectangleAlignment`](/slides/python-net/ko/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/ko/aspose.slides.effects/outershadow/skew_horizontal/) | Horizontal skew angle, in degrees.<br/>            Default value – 0 °.<br/>            Read/write **float**. |
| [`skew_vertical`](/slides/python-net/ko/aspose.slides.effects/outershadow/skew_vertical/) | Vertical skew angle, in degrees.<br/>            Default value – 0 °.<br/>            Read/write **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/ko/aspose.slides.effects/outershadow/rotate_shadow_with_shape/) | Indicates whether the shadow rotates together with the shape.<br/>            Default value – true.<br/>            Read/write **bool**. |
| [`scale_horizontal`](/slides/python-net/ko/aspose.slides.effects/outershadow/scale_horizontal/) | Horizontal scaling factor, in percent of the original size.<br/>            Negative scaling causes a flip.<br/>            Default value – 100 %.<br/>            Read/write **float**. |
| [`scale_vertical`](/slides/python-net/ko/aspose.slides.effects/outershadow/scale_vertical/) | Vertical scaling factor, in percent of the original size.<br/>            Negative scaling causes a flip.<br/>            Default value – 100 %.<br/>            Read/write **float**. |
