## IBlur 클래스

전체 모양에 적용되는 블러 효과를 나타내며, 채우기 영역도 포함합니다.  
알파를 포함한 모든 색상 채널이 영향을 받습니다.

IBlur 형식은 다음 멤버를 제공합니다:

## 속성

| Property | Description |
| :- | :- |
| [`radius`](/slides/python-net/ko/aspose.slides.effects/iblur/radius/) | 블러 반경을 반환하거나 설정합니다.<br/>읽기/쓰기 **float**. |
| [`grow`](/slides/python-net/ko/aspose.slides.effects/iblur/grow/) | 블러 처리 결과 객체의 경계가 확대되어야 하는지 여부를 결정합니다.<br/>True는 경계가 확대됨을, false는 확대되지 않음을 나타냅니다.<br/>읽기/쓰기 **bool**. |
