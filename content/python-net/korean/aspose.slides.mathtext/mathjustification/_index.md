## MathJustification 열거형

수학 단락(같은 단락 내에서 인접한 수학 텍스트 인스턴스들의 연속)의 정렬 방식을 지정합니다.

MathJustification 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| LEFT_JUSTIFIED | 수학 텍스트를 왼쪽에 정렬 |
| RIGHT_JUSTIFIED | 수학 텍스트를 오른쪽에 정렬 |
| CENTERED | 수학 텍스트를 가운데에 정렬 |
| CENTERED_AS_GROUP | 수학 블록 전체 그룹을 단일 단위로 페이지 중앙에 배치합니다.<br/>            이는 수학 텍스트 인스턴스들이 서로에 대해 정렬될 수 있지만, 전체 수학 텍스트 그룹은 전체적으로 중앙에 배치된다는 것을 의미합니다. |
