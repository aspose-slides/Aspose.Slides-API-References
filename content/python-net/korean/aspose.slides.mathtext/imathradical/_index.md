## IMathRadical 클래스

기본값과 선택적 차수를 포함하는 루트 함수(근호)를 지정합니다.  
루트 객체의 예는 √𝑥 입니다.

IMathRadical 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`base`](/slides/python-net/ko/aspose.slides.mathtext/imathradical/base/) | Base argument |
| [`degree`](/slides/python-net/ko/aspose.slides.mathtext/imathradical/degree/) | Degree argument |
| [`hide_degree`](/slides/python-net/ko/aspose.slides.mathtext/imathradical/hide_degree/) | Hide degree<br/>            When is true, the degree is not shown, as in √𝑥 |
