## MathSpacingRules 열거형

행렬 열 사이의 간격(수평 간격) 유형

The MathSpacingRules type exposes the following members:

## 필드

| 필드 | 설명 |
| :- | :- |
| SINGLE_SPACING_GAP | 단일 (열에 대해 1 em, 행에 대해 1 라인) |
| ONE_AND_HALF_SPACING_GAP | 1.5배 (열에 대해 1.5 em, 행에 대해 1.5 라인) |
| DOUBLE_SPACING_GAP | 두 배 간격 (열에 대해 2 em, 행에 대해 2 라인) |
| EXACTLY | 정확한 값<br/>            열의 경우 ColumnGap 값을 사용하며, 단위는 twips<br/>            행의 경우 RowGap 값을 사용하며, 단위는 twips |
| MULTIPLE | 다중<br/>            열의 경우 ColumnGap 값을 사용하며, 0.5 em 단위로 측정<br/>            행의 경우 RowGap 값을 사용하며, 라인 단위로 측정 |
