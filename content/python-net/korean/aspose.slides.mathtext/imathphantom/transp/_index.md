## transp 속성
팬텀의 투명 여부를 나타내는 값을 가져오거나 설정합니다. 이 값은 클래스 기반 간격 규칙에 적용됩니다.

### 비고
`true`인 경우, 팬텀 내부의 연산자와 기호는 팬텀 주위의 수학적 간격에 여전히 영향을 미칩니다(가시적인 것처럼). `false`인 경우, 클래스 기반 간격이 무시됩니다. OMML 속성 `m:transp`에 해당합니다.

### 정의:
```python
@property
def transp(self):
    ...

@transp.setter
def transp(self, value):
    ...
```
