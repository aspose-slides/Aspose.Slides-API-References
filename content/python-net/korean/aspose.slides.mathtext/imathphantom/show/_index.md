## show 속성
기본 요소가 표시되는지 여부를 나타내는 값을 가져오거나 설정합니다.


### 비고

`false`일 경우, 기본 요소가 숨겨지지만 다른 phantom 설정에 따라 여전히 공간을 차지할 수 있습니다.
            OMML 속성 `m:show`에 해당합니다.

### 정의:
```python
@property
def show(self):
    ...

@show.setter
def show(self, value):
    ...
```
