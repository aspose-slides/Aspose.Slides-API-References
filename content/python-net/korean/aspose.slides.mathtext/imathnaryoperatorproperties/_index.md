## IMathNaryOperatorProperties 클래스

IMathNaryOperator의 속성을 지정합니다

IMathNaryOperatorProperties 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`operator`](/slides/python-net/ko/aspose.slides.mathtext/imathnaryoperatorproperties/operator/) | 다항 연산자 문자<br/>            예: '∑', '∫' |
| [`limit_location`](/slides/python-net/ko/aspose.slides.mathtext/imathnaryoperatorproperties/limit_location/) | 제한(아래첨자 및 위첨자)의 위치 |
| [`grow_to_match_operand_height`](/slides/python-net/ko/aspose.slides.mathtext/imathnaryoperatorproperties/grow_to_match_operand_height/) | 연산자 문자가 피연산자 높이에 맞게 수직으로 확대됩니다 |
| [`hide_subscript`](/slides/python-net/ko/aspose.slides.mathtext/imathnaryoperatorproperties/hide_subscript/) | 아래첨자 숨기기 |
| [`hide_superscript`](/slides/python-net/ko/aspose.slides.mathtext/imathnaryoperatorproperties/hide_superscript/) | 위첨자 숨기기 |
