## MathRowSpacingRule 열거형

행렬 또는 배열에서 열 사이의 수직 간격 유형

MathRowSpacingRule 형식은 다음 멤버를 노출합니다:

## 필드

| 필드 | 설명 |
| :- | :- |
| SINGLE_LINE_GAP | 단일 라인 간격 |
| ONE_AND_A_HALF_LINE_GAP | 한 줄 반 간격 |
| TWO_LINE_GAP | 두 줄 간격 |
| EXACTLY | 정확히 (RowSpacing 속성의 값을 사용, 포인트 단위) |
| MULTIPLE | 여러 개 (RowSpacing 속성의 값을 사용, 라인 단위) |
