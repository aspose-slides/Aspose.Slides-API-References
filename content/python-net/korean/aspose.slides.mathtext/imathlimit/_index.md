## IMathLimit 클래스

기준선에 있는 텍스트와 그 바로 위 또는 아래에 위치한 축소된 크기의 텍스트로 구성된 Limit 객체를 지정합니다.

IMathLimit 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`base`](/slides/python-net/ko/aspose.slides.mathtext/imathlimit/base/) | 기본 인수 |
| [`limit`](/slides/python-net/ko/aspose.slides.mathtext/imathlimit/limit/) | 제한 인수 |
| [`upper_limit`](/slides/python-net/ko/aspose.slides.mathtext/imathlimit/upper_limit/) | 상한 또는 하한을 지정합니다 |
