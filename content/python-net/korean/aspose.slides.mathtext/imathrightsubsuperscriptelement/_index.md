## IMathRightSubSuperscriptElement 클래스

하위-위첨자 객체를 지정합니다. 이 객체는 기본 요소와 기본 요소의 오른쪽에 배치된 아래첨자와 위첨자로 구성됩니다.

IMathRightSubSuperscriptElement 형식은 다음 멤버를 공개합니다:

## 속성

| Property | Description |
| :- | :- |
| [`base`](/slides/python-net/ko/aspose.slides.mathtext/imathrightsubsuperscriptelement/base/) | 기본 인수 |
| [`subscript`](/slides/python-net/ko/aspose.slides.mathtext/imathrightsubsuperscriptelement/subscript/) | 아래첨자 인수 |
| [`superscript`](/slides/python-net/ko/aspose.slides.mathtext/imathrightsubsuperscriptelement/superscript/) | 위첨자 인수 |
| [`align_scripts`](/slides/python-net/ko/aspose.slides.mathtext/imathrightsubsuperscriptelement/align_scripts/) | 아래첨자/위첨자의 정렬을 지정합니다. <br/>            true인 경우, 아래첨자와 위첨자는 서로 수평으로 정렬됩니다.<br/>            false인 경우, 기본 요소의 형태에 맞게 커닝됩니다.<br/>            기본값은 false입니다. |
