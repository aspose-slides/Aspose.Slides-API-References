## zero_width 속성
기본 요소의 너비를 0으로 취급할지 여부를 나타내는 값을 가져오거나 설정합니다.

### 비고

`true`일 때, 팬텀은 기본 요소에 대해 수평 공간을 예약하지 않습니다. OMML 속성 `m:zeroWid`에 해당합니다.
