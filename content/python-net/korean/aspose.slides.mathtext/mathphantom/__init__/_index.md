지정된 기본 수학 요소를 사용하여 [`MathPhantom`](/slides/python-net/ko/aspose.slides.mathtext/mathphantom) 클래스의 새 인스턴스를 초기화합니다.

```python
def __init__(self, element):
    ...
```

| 매개변수 | 형식 | 설명 |
| :- | :- | :- |
| element | [`IMathElement`](/slides/python-net/ko/aspose.slides.mathtext/imathelement) | 가시성과 레이아웃이 팬텀에 의해 제어되는 기본 [`IMathElement`](/slides/python-net/ko/aspose.slides.mathtext/imathelement)입니다.<br/><br/>            이 요소는 숨겨지거나 표시될 수 있는 콘텐츠를 정의하지만,<br/><br/>            주변 수학의 기하학적 정렬에 여전히 영향을 줍니다. |

### 비고

팬텀 요소는 기본 식의 시각적 공간을 표시하지 않고도 예약하거나 억제하는 데 사용됩니다. 이는 OMML 요소 `<m:phant>`에 해당합니다.
