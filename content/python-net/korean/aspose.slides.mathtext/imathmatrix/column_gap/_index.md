## column_gap 속성
행렬의 열 사이의 수평 간격 값;
            If the ColumnGapRule is set to 3 ("Exactly"), then the unit is interpreted as twips (1/20th of a point)
            If the ColumnGapRule is set to 4 ("Multiple"), then the unit is interpreted as number of 0.5 em increments.
            다른 경우는 무시됩니다.
            기본값: 0
