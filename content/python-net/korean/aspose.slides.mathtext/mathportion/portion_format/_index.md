## portion_format 속성
포맷팅 객체를 반환합니다. 이 객체는 상속이 적용되지 않은 텍스트 부분에 명시적으로 설정된 서식 속성을 포함합니다.
읽기 전용 [`IPortionFormat`](/slides/python-net/ko/aspose.slides/iportionformat).

### 비고

포맷팅 객체는 현재 부분에 대해 정의된 서식 매개변수만 포함하며, 상속된 데이터는 적용되지 않습니다.

상속된 값을 포함한 실제 값을 얻으려면 [`PortionFormat.get_effective`](/slides/python-net/ko/aspose.slides/portionformat/get_effective) 메서드를 사용하십시오.
