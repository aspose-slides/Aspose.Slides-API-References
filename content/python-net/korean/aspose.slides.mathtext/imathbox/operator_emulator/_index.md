## operator_emulator 속성
연산자 에뮬레이터.
            true일 경우, 상자와 그 내용물은 단일 연산자로 동작하며 연산자의 속성을 상속합니다. 
            즉, 예를 들어 해당 문자를 줄 바꿈 지점으로 사용할 수 있고 다른 연산자에 맞출 수 있다는 뜻입니다.
            연산자 에뮬레이터는 '=='와 같이 하나 이상의 글리프가 결합하여 연산자를 형성할 때 자주 사용됩니다.
            기본값: false
