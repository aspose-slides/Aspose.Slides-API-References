## explicit_break 속성
명시적 구분은 Box 객체 시작 부분에 줄 바꿈이 있는지를 지정하며, 줄이 Box 객체 시작 부분에서 감싸지도록 합니다.
            수학 텍스트의 이전 행에 있는 연산자 수를 지정하며, 이는 현재 행의 정렬 기준점으로 사용됩니다.
            가능한 값: 1..255
            기본값: 0 (명시적 구분 없음)
