## ChartThemeManager 클래스

차트 테마를 재정의하는 데 대한 액세스를 제공합니다.

**상속:**[`ChartThemeManager`](/slides/python-net/ko/aspose.slides.theme/chartthememanager) → [`BaseOverrideThemeManager`](/slides/python-net/ko/aspose.slides.theme/baseoverridethememanager) → [`BaseThemeManager`](/slides/python-net/ko/aspose.slides.theme/basethememanager)

ChartThemeManager 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`override_theme`](/slides/python-net/ko/aspose.slides.theme/chartthememanager/override_theme/) | 재정의된 테마 객체를 반환합니다.<br/>            읽기/쓰기 [`IOverrideTheme`](/slides/python-net/ko/aspose.slides.theme/ioverridetheme). |
| [`is_override_theme_enabled`](/slides/python-net/ko/aspose.slides.theme/chartthememanager/is_override_theme_enabled/) | OverrideTheme가 상속된 유효 테마를 재정의하는지 여부를 결정합니다.<br/>            OverrideTheme를 재정의하도록 활성화하려면 OverrideTheme.Init*() 메서드를 사용하십시오.<br/>            OverrideTheme의 재정을 비활성화하려면 OverrideTheme.Clear() 메서드를 사용하십시오.<br/>            읽기 전용 **bool**. |
