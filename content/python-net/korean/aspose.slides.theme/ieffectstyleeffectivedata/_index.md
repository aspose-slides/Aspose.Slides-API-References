## IEffectStyleEffectiveData 클래스

효과적인 효과 스타일 속성을 포함하는 불변 객체.

IEffectStyleEffectiveData 형식은 다음 멤버를 제공합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`effect_format`](/slides/python-net/ko/aspose.slides.theme/ieffectstyleeffectivedata/effect_format/) | 효과 형식을 반환합니다.<br/>            읽기 전용 [`IEffectFormatEffectiveData`](/slides/python-net/ko/aspose.slides/ieffectformateffectivedata). |
| [`three_d_format`](/slides/python-net/ko/aspose.slides.theme/ieffectstyleeffectivedata/three_d_format/) | 3D 형식을 반환합니다.<br/>            읽기 전용 [`IThreeDFormatEffectiveData`](/slides/python-net/ko/aspose.slides/ithreedformateffectivedata). |


### 비고

이 인터페이스는 [`IEffectStyleCollectionEffectiveData`](/slides/python-net/ko/aspose.slides.theme/ieffectstylecollectioneffectivedata)의 일부로 사용됩니다.
