## LayoutSlideThemeManager 클래스

레아웃 슬라이드 테마를 오버라이드하는 액세스를 제공합니다.

**Inheritance:**[`LayoutSlideThemeManager`](/slides/python-net/ko/aspose.slides.theme/layoutslidethememanager) → [`BaseOverrideThemeManager`](/slides/python-net/ko/aspose.slides.theme/baseoverridethememanager) → [`BaseThemeManager`](/slides/python-net/ko/aspose.slides.theme/basethememanager)

LayoutSlideThemeManager 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`override_theme`](/slides/python-net/ko/aspose.slides.theme/layoutslidethememanager/override_theme/) | 오버라이드된 테마 개체를 반환합니다.<br/>            읽기/쓰기 [`IOverrideTheme`](/slides/python-net/ko/aspose.slides.theme/ioverridetheme). |
| [`is_override_theme_enabled`](/slides/python-net/ko/aspose.slides.theme/layoutslidethememanager/is_override_theme_enabled/) | OverrideTheme가 상속된 유효 테마를 오버라이드하는지 여부를 결정합니다.<br/>            오버라이드를 위해 OverrideTheme를 활성화하려면 OverrideTheme.Init*() 메서드를 사용하십시오.<br/>            OverrideTheme가 오버라이드하지 않도록 비활성화하려면 OverrideTheme.Clear() 메서드를 사용하십시오.<br/>            읽기 전용 **bool**. |
