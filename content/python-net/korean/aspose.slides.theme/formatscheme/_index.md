## FormatScheme 클래스

도형에 대한 테마 정의 형식을 저장합니다.

FormatScheme 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`fill_styles`](/slides/python-net/ko/aspose.slides.theme/formatscheme/fill_styles/) | 테마 정의 채우기 스타일의 컬렉션을 반환합니다.<br/>            읽기 전용 [`IFillFormatCollection`](/slides/python-net/ko/aspose.slides.theme/ifillformatcollection). |
| [`line_styles`](/slides/python-net/ko/aspose.slides.theme/formatscheme/line_styles/) | 테마 정의 선 스타일의 컬렉션을 반환합니다.<br/>            읽기 전용 [`ILineFormatCollection`](/slides/python-net/ko/aspose.slides.theme/ilineformatcollection). |
| [`effect_styles`](/slides/python-net/ko/aspose.slides.theme/formatscheme/effect_styles/) | 테마 정의 효과 스타일의 컬렉션을 반환합니다.<br/>            읽기 전용 [`IEffectStyleCollection`](/slides/python-net/ko/aspose.slides.theme/ieffectstylecollection). |
| [`background_fill_styles`](/slides/python-net/ko/aspose.slides.theme/formatscheme/background_fill_styles/) | 테마 정의 배경 채우기 스타일의 컬렉션을 반환합니다.<br/>            읽기 전용 [`IFillFormatCollection`](/slides/python-net/ko/aspose.slides.theme/ifillformatcollection). |
| [`slide`](/slides/python-net/ko/aspose.slides.theme/formatscheme/slide/) | 부모 슬라이드를 반환합니다.<br/>            읽기 전용 [`IBaseSlide`](/slides/python-net/ko/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/ko/aspose.slides.theme/formatscheme/presentation/) | 부모 프레젠테이션을 반환합니다.<br/>            읽기 전용 [`IPresentation`](/slides/python-net/ko/aspose.slides/ipresentation). |
