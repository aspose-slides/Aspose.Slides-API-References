## FontScheme 클래스

테마에서 정의된 글꼴을 저장합니다.

FontScheme 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`minor`](/slides/python-net/ko/aspose.slides.theme/fontscheme/minor/) | 슬라이드의 "body" 부분에 대한 글꼴 컬렉션을 반환합니다.<br/>            읽기 전용 [`IFonts`](/slides/python-net/ko/aspose.slides/ifonts). |
| [`major`](/slides/python-net/ko/aspose.slides.theme/fontscheme/major/) | 슬라이드의 "heading" 부분에 대한 글꼴 컬렉션을 반환합니다.<br/>            읽기 전용 [`IFonts`](/slides/python-net/ko/aspose.slides/ifonts). |
| [`name`](/slides/python-net/ko/aspose.slides.theme/fontscheme/name/) | 글꼴 스키마 이름을 반환합니다.<br/>            읽기/쓰기 **str**. |
