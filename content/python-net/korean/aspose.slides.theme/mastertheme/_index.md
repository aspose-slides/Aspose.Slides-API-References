## MasterTheme 클래스

마스터 테마를 나타냅니다.

**상속:**[`MasterTheme`](/slides/python-net/ko/aspose.slides.theme/mastertheme) → [`Theme`](/slides/python-net/ko/aspose.slides.theme/theme)

MasterTheme 유형은 다음 멤버를 제공합니다:

## 속성

| Property | Description |
| :- | :- |
| [`color_scheme`](/slides/python-net/ko/aspose.slides.theme/mastertheme/color_scheme/) | 색 구성표를 반환합니다.<br/>            읽기 전용 [`IColorScheme`](/slides/python-net/ko/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/ko/aspose.slides.theme/mastertheme/font_scheme/) | 글꼴 구성표를 반환합니다.<br/>            읽기 전용 [`IFontScheme`](/slides/python-net/ko/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/ko/aspose.slides.theme/mastertheme/format_scheme/) | 도형 서식 구성표를 반환합니다.<br/>            읽기 전용 [`IFormatScheme`](/slides/python-net/ko/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/ko/aspose.slides.theme/mastertheme/presentation/) | 부모 프레젠테이션을 반환합니다.<br/>            읽기 전용 [`IPresentation`](/slides/python-net/ko/aspose.slides/ipresentation). |
| [`extra_color_schemes`](/slides/python-net/ko/aspose.slides.theme/mastertheme/extra_color_schemes/) | 추가 색 구성표 컬렉션을 반환합니다.<br/>            이 구성표는 프레젠테이션의 모양에 영향을 주지 않으며, 슬라이드의 기본 색 구성표로 선택될 수 있습니다.<br/>            읽기 전용 [`IExtraColorSchemeCollection`](/slides/python-net/ko/aspose.slides.theme/iextracolorschemecollection). |
| [`name`](/slides/python-net/ko/aspose.slides.theme/mastertheme/name/) | 테마의 이름을 반환합니다.<br/>            읽기/쓰기 **str**. |
