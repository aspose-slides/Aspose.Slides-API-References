## OverrideTheme 클래스

재정의 테마를 나타냅니다.

**Inheritance:**[`OverrideTheme`](/slides/python-net/ko/aspose.slides.theme/overridetheme) → [`Theme`](/slides/python-net/ko/aspose.slides.theme/theme)

OverrideTheme 유형은 다음 멤버를 노출합니다:

## 속성

| Property | Description |
| :- | :- |
| [`color_scheme`](/slides/python-net/ko/aspose.slides.theme/overridetheme/color_scheme/) | 색 구성표를 반환합니다.<br/>            읽기 전용 [`IColorScheme`](/slides/python-net/ko/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/ko/aspose.slides.theme/overridetheme/font_scheme/) | 글꼴 구성표를 반환합니다.<br/>            읽기 전용 [`IFontScheme`](/slides/python-net/ko/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/ko/aspose.slides.theme/overridetheme/format_scheme/) | 도형 형식 구성표를 반환합니다.<br/>            읽기 전용 [`IFormatScheme`](/slides/python-net/ko/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/ko/aspose.slides.theme/overridetheme/presentation/) | 상위 프레젠테이션을 반환합니다.<br/>            읽기 전용 [`IPresentation`](/slides/python-net/ko/aspose.slides/ipresentation). |
| [`is_empty`](/slides/python-net/ko/aspose.slides.theme/overridetheme/is_empty/) | True 값은 ColorScheme, FontScheme, FormatScheme이 None이며 이 테마 객체에 대한 모든 재정의가 비활성화됨을 의미합니다.<br/>            읽기 전용 **bool**. |
