## IOverrideThemeManager 클래스

다양한 유형의 재정의된 테마에 대한 접근을 제공합니다.

IOverrideThemeManager 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`is_override_theme_enabled`](/slides/python-net/ko/aspose.slides.theme/ioverridethememanager/is_override_theme_enabled/) | OverrideTheme가 상속된 유효 테마를 재정의하는지 여부를 결정합니다.<br/>            OverrideTheme를 재정의에 사용하려면 OverrideTheme.Init*() 메서드를 사용하십시오.<br/>            OverrideTheme가 재정의를 중단하도록 하려면 OverrideTheme.Clear() 메서드를 사용하십시오.<br/>            읽기 전용 **bool**. |
| [`override_theme`](/slides/python-net/ko/aspose.slides.theme/ioverridethememanager/override_theme/) | 재정의된 테마 객체를 반환합니다.<br/>            읽기/쓰기 [`IOverrideTheme`](/slides/python-net/ko/aspose.slides.theme/ioverridetheme). |
