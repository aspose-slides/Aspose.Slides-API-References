## MasterThemeManager 클래스

프레젠테이션 마스터 테마에 대한 액세스를 제공합니다.

**Inheritance:**[`MasterThemeManager`](/slides/python-net/ko/aspose.slides.theme/masterthememanager) → [`BaseThemeManager`](/slides/python-net/ko/aspose.slides.theme/basethememanager)

MasterThemeManager 형식은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`override_theme`](/slides/python-net/ko/aspose.slides.theme/masterthememanager/override_theme/) | 재정의 테마 개체를 반환합니다.<br/>            읽기/쓰기 [`IMasterTheme`](/slides/python-net/ko/aspose.slides.theme/imastertheme). |
| [`is_override_theme_enabled`](/slides/python-net/ko/aspose.slides.theme/masterthememanager/is_override_theme_enabled/) | OverrideTheme가 상속된 유효 테마 (Presentation.MasterTheme)를 재정의하는지 여부를 결정합니다.<br/>            읽기/쓰기 **bool**. |

## 메서드

| 메서드 | 설명 |
| :- | :- |
| [`create_theme_effective(self)`](/slides/python-net/ko/aspose.slides.theme/masterthememanager/create_theme_effective/#) | 테마 개체를 반환합니다. |
| [`apply_color_scheme(self, scheme)`](/slides/python-net/ko/aspose.slides.theme/masterthememanager/apply_color_scheme/#iextracolorscheme) | 슬라이드에 추가 색 구성표를 적용합니다. |
