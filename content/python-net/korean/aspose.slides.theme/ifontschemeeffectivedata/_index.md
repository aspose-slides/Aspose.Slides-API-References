## IFontSchemeEffectiveData 클래스

슬라이드에 적용된 글꼴 스키마 속성을 포함하는 불변 객체.

IFontSchemeEffectiveData 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`minor`](/slides/python-net/ko/aspose.slides.theme/ifontschemeeffectivedata/minor/) | 슬라이드의 "body" 부분에 대한 글꼴 컬렉션을 반환합니다.<br/>            읽기 전용 [`IFontsEffectiveData`](/slides/python-net/ko/aspose.slides/ifontseffectivedata). |
| [`major`](/slides/python-net/ko/aspose.slides.theme/ifontschemeeffectivedata/major/) | 슬라이드의 "heading" 부분에 대한 글꼴 컬렉션을 반환합니다.<br/>            읽기 전용 [`IFontsEffectiveData`](/slides/python-net/ko/aspose.slides/ifontseffectivedata). |
| [`name`](/slides/python-net/ko/aspose.slides.theme/ifontschemeeffectivedata/name/) | 글꼴 스키마 이름을 반환합니다.<br/>            읽기 전용 **str**. |


### 비고

이 인터페이스는 [`IThemeEffectiveData`](/slides/python-net/ko/aspose.slides.theme/ithemeeffectivedata)의 일부로 사용됩니다.
