## SlideThemeManager 클래스

슬라이드 테마를 재정의하는 기능에 접근할 수 있습니다.

**Inheritance:**[`SlideThemeManager`](/slides/python-net/ko/aspose.slides.theme/slidethememanager) → [`BaseOverrideThemeManager`](/slides/python-net/ko/aspose.slides.theme/baseoverridethememanager) → [`BaseThemeManager`](/slides/python-net/ko/aspose.slides.theme/basethememanager)

## 속성

| 속성 | 설명 |
| :- | :- |
| [`override_theme`](/slides/python-net/ko/aspose.slides.theme/slidethememanager/override_theme/) | 재정의된 테마 객체를 반환합니다.<br/>            읽기/쓰기 [`IOverrideTheme`](/slides/python-net/ko/aspose.slides.theme/ioverridetheme). |
| [`is_override_theme_enabled`](/slides/python-net/ko/aspose.slides.theme/slidethememanager/is_override_theme_enabled/) | OverrideTheme가 상속된 유효 테마를 재정의하는지 여부를 결정합니다.<br/>            OverrideTheme를 재정의하도록 활성화하려면 OverrideTheme.Init*() 메서드를 사용하십시오.<br/>            OverrideTheme가 재정을 하지 않도록 비활성화하려면 OverrideTheme.Clear() 메서드를 사용하십시오.<br/>            읽기 전용 **bool**. |
