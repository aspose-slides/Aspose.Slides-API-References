## Theme 클래스

테마를 나타냅니다.

Theme 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`color_scheme`](/slides/python-net/ko/aspose.slides.theme/theme/color_scheme/) | 색 구성표를 반환합니다.<br/>읽기 전용 [`IColorScheme`](/slides/python-net/ko/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/ko/aspose.slides.theme/theme/font_scheme/) | 글꼴 구성표를 반환합니다.<br/>읽기 전용 [`IFontScheme`](/slides/python-net/ko/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/ko/aspose.slides.theme/theme/format_scheme/) | 모양 형식 구성표를 반환합니다.<br/>읽기 전용 [`IFormatScheme`](/slides/python-net/ko/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/ko/aspose.slides.theme/theme/presentation/) | 상위 프레젠테이션을 반환합니다.<br/>읽기 전용 [`IPresentation`](/slides/python-net/ko/aspose.slides/ipresentation). |
