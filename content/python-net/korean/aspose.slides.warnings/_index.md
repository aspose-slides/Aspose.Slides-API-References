다양한 종류의 경고를 나타내는 클래스를 포함합니다.
## 클래스

| 클래스 | 설명 |
| :- | :- |
| [`IKnownIssueWarningInfo`](/slides/python-net/ko/aspose.slides.warnings/iknownissuewarninginfo/) | 알려진 이슈에 대한 경고이며, 가까운 시일 내에 해결되지 않을 것입니다. |
| [`INotImplementedWarningInfo`](/slides/python-net/ko/aspose.slides.warnings/inotimplementedwarninginfo/) | 알려진 구현되지 않은 기능에 대한 경고이며, 가까운 시일 내에 구현되지 않을 것입니다. |
| [`IObsoletePresLockingBehaviorWarningInfo`](/slides/python-net/ko/aspose.slides.warnings/iobsoletepreslockingbehaviorwarninginfo/) | 이 경고는 사용된 프레젠테이션 잠금 동작이 구식임을 나타냅니다. |
| [`IPresentationSignedWarningInfo`](/slides/python-net/ko/aspose.slides.warnings/ipresentationsignedwarninginfo/) | 이 경고는 읽어들인 프레젠테이션에 서명이 포함되어 있음을 나타냅니다 <br/>            그리고 이 서명은 처리 중에 제거될 것입니다. |
| [`IWarningCallback`](/slides/python-net/ko/aspose.slides.warnings/iwarningcallback/) | 경고를 받는 클래스용 인터페이스 |
| [`IWarningInfo`](/slides/python-net/ko/aspose.slides.warnings/iwarninginfo/) | 모든 경고를 위한 기본 인터페이스를 나타냅니다. |

## 열거형

| 열거형 | 설명 |
| :- | :- |

| [`WarningType`](/slides/python-net/ko/aspose.slides.warnings/warningtype/) | 경고 유형을 나타냅니다. |
