## IWarningInfo 클래스

모든 경고에 대한 기본 인터페이스를 나타냅니다.

IWarningInfo 유형은 다음 멤버를 노출합니다:

## 속성

| 속성 | 설명 |
| :- | :- |
| [`warning_type`](/slides/python-net/ko/aspose.slides.warnings/iwarninginfo/warning_type/) | 경고 유형을 반환합니다.<br/>읽기 전용 [`IWarningInfo.warning_type`](/slides/python-net/ko/aspose.slides.warnings/iwarninginfo/warning_type). |
| [`description`](/slides/python-net/ko/aspose.slides.warnings/iwarninginfo/description/) | 이 경고에 대한 사람 친화적인 설명을 반환합니다.<br/>읽기 전용 **str**. |

## 메서드

| 메서드 | 설명 |
| :- | :- |
| [`send_warning(self, receiver)`](/slides/python-net/ko/aspose.slides.warnings/iwarninginfo/send_warning/#iwarningcallback) | receiver가 None이 아니면 지정된 수신자에게 경고를 종료하고, 수신자가 작업을 중단하기로 결정하면 AbortRequestedException을 발생시킵니다. |
