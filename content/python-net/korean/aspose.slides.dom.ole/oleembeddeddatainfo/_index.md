## OleEmbeddedDataInfo 클래스

OLE 객체에 대한 임베디드 데이터 정보를 나타냅니다.

OleEmbeddedDataInfo 형식은 다음 멤버를 노출합니다:

## 생성자

| 생성자 | 설명 |
| :- | :- |
| [`__init__(self)`](/slides/python-net/ko/aspose.slides.dom.ole/oleembeddeddatainfo/__init__/#) | OLE 객체에 대한 새 임베디드 데이터 정보를 생성합니다. |
| [`__init__(self, embedded_file_data, embedded_file_extension)`](/slides/python-net/ko/aspose.slides.dom.ole/oleembeddeddatainfo/__init__/#bytes-str) | OLE 객체에 대한 임베디드 데이터 정보의 새 인스턴스를 생성합니다.<br/>            임베디드 OLE 객체의 파일 데이터 **int**[]. 현재 임베디드 OLE 객체의 파일 확장자 **str**. |
