## default_label_shape_type property
Gets or sets the default shape type for data labels.
             Returns [`ShapeType.NOT_DEFINED`](/slides/python-net/aspose.slides/shapetype/NOT_DEFINED) if no shape is defined.


### Remarks

Setting this property also sets the [`IDataLabel.label_shape_type`](/slides/python-net/aspose.slides.charts/idatalabel/label_shape_type) property
             for all data labels in the collection to the same value.
