## Size class

Stores an ordered pair of integers, which specify a width and a height. Compatible with .NET `System.Drawing.Size`.

The Size type exposes the following members:

## Constructors

| Constructor | Description |
| :- | :- |
| [`__init__(self, width=0, height=0)`](/slides/python-net/aspose.slides/size/__init__/#int-int) | Creates a size with the specified width and height. Float values are truncated to integers. |

## Properties

| Property | Description |
| :- | :- |
| [`width`](/slides/python-net/aspose.slides/size/width/) | Gets the horizontal component of this size.<br/>            Read-only **int**. |
| [`height`](/slides/python-net/aspose.slides/size/height/) | Gets the vertical component of this size.<br/>            Read-only **int**. |


### Remarks

Sizes are compared by their components with `==` and can be used as dictionary keys or set members.
