## is_system_color property
Specifies whether this color is a system color: a color used for a Windows display element, such as `Control` or `ActiveBorder`.<br/>            System colors are not exposed as `Color` attributes and can only be obtained with [`from_known_color`](/slides/python-net/aspose.slides/color/from_known_color/) or returned from the library.
            Read-only **bool**.
