## to_argb(self) {#}
Gets the 32-bit ARGB value of this color.

### Returns

The 32-bit ARGB value of this color as a signed integer, matching .NET `Color.ToArgb()`. For example, opaque red returns `-65536` (`0xFFFF0000` as a signed 32-bit integer).
