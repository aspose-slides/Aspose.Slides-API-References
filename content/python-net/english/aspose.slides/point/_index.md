## Point class

Represents an ordered pair of integer x- and y-coordinates that defines a point in a two-dimensional plane. Compatible with .NET `System.Drawing.Point`.

The Point type exposes the following members:

## Constructors

| Constructor | Description |
| :- | :- |
| [`__init__(self, x=0, y=0)`](/slides/python-net/aspose.slides/point/__init__/#int-int) | Creates a point with the specified coordinates. Float values are truncated to integers. |

## Properties

| Property | Description |
| :- | :- |
| [`x`](/slides/python-net/aspose.slides/point/x/) | Gets or sets the x-coordinate of this point.<br/>            Read/write **int**. |
| [`y`](/slides/python-net/aspose.slides/point/y/) | Gets or sets the y-coordinate of this point.<br/>            Read/write **int**. |


### Remarks

Points are compared by their coordinates with `==` and can be used as dictionary keys or set members.
