## volume_value property
Returns or sets the exact video volume as a percentage.
             The value is expressed as a percentage from 0 to 100. Use this property
             to read or set volume values that are more precise than the predefined
             levels available through the [`IVideoFrame.volume`](/slides/python-net/aspose.slides/ivideoframe/volume) property.
             Read/write **float**.
