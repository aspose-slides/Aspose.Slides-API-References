## IExcelDataCell třída

Reprezentuje jednu buňku v sešitu Excel.

Typ IExcelDataCell zpřístupňuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`value`](/slides/python-net/cs/aspose.slides.excel/iexceldatacell/value/) | Získá hodnotu obsaženou v buňce Excel.<br/>            Pouze pro čtení **any**. |
| [`name`](/slides/python-net/cs/aspose.slides.excel/iexceldatacell/name/) | Získá název datové buňky grafu.<br/>            Pouze pro čtení **str**. |
| [`row`](/slides/python-net/cs/aspose.slides.excel/iexceldatacell/row/) | Získá nulový index řádku v listu, kde je buňka umístěna.<br/>            Pouze pro čtení **int**. |
| [`column`](/slides/python-net/cs/aspose.slides.excel/iexceldatacell/column/) | Získá nulový index sloupce v listu, kde je buňka umístěna.<br/>            Pouze pro čtení **int**. |
