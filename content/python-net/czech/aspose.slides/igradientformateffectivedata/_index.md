## IGradientFormatEffectiveData třída

Neměnný objekt, který obsahuje účinné vlastnosti výplně gradientu.

Typ IGradientFormatEffectiveData vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`tile_flip`](/slides/python-net/cs/aspose.slides/igradientformateffectivedata/tile_flip/) | Returns the flipping mode for a gradient.<br/>            Pouze pro čtení [`TileFlip`](/slides/python-net/cs/aspose.slides/tileflip). |
| [`gradient_direction`](/slides/python-net/cs/aspose.slides/igradientformateffectivedata/gradient_direction/) | Returns the style of a gradient.<br/>            Pouze pro čtení [`GradientDirection`](/slides/python-net/cs/aspose.slides/gradientdirection). |
| [`linear_gradient_angle`](/slides/python-net/cs/aspose.slides/igradientformateffectivedata/linear_gradient_angle/) | Returns the angle of a gradient.<br/>            Pouze pro čtení **float**. |
| [`linear_gradient_scaled`](/slides/python-net/cs/aspose.slides/igradientformateffectivedata/linear_gradient_scaled/) | Determines whether a gradient is scaled.<br/>            Pouze pro čtení **bool**. |
| [`gradient_shape`](/slides/python-net/cs/aspose.slides/igradientformateffectivedata/gradient_shape/) | Returns the shape of a gradient.<br/>            Pouze pro čtení [`GradientShape`](/slides/python-net/cs/aspose.slides/gradientshape). |
| [`gradient_stops`](/slides/python-net/cs/aspose.slides/igradientformateffectivedata/gradient_stops/) | Returns the collection of gradient stops.<br/>            Pouze pro čtení [`IGradientStopCollectionEffectiveData`](/slides/python-net/cs/aspose.slides/igradientstopcollectioneffectivedata). |


### Poznámky

Toto rozhraní se používá jako součást [`IFillFormatEffectiveData`](/slides/python-net/cs/aspose.slides/ifillformateffectivedata) a [`ILineFillFormatEffectiveData`](/slides/python-net/cs/aspose.slides/ilinefillformateffectivedata).
