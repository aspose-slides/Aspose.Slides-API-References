## ICaptions třída

Reprezentuje uzavřené titulky ve formátu WebVTT.

Typ ICaptions vystavuje následující členy:

## Vlastnosti

| Property | Description |
| :- | :- |
| [`caption_id`](/slides/python-net/cs/aspose.slides/icaptions/caption_id/) | Vrací globálně jedinečný identifikátor (GUID) uzavřených titulků.<br/>            Pouze ke čtení **System.Guid**. |
| [`label`](/slides/python-net/cs/aspose.slides/icaptions/label/) | Vrací nebo nastavuje popisek uzavřených titulků.<br/>            Čtení/Zápis **str**. |
| [`binary_data`](/slides/python-net/cs/aspose.slides/icaptions/binary_data/) | Vrací binární data uzavřených titulků.<br/>            Pouze ke čtení **int**[]. |
| [`data_as_string`](/slides/python-net/cs/aspose.slides/icaptions/data_as_string/) | Vrací data uzavřených titulků jako řetězec kódovaný v UTF-8<br/>            Pouze ke čtení **str**. |
