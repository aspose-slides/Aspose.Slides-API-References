## HyperlinkActionType enumeration

Representuje typ akce hypertextového odkazu.

Typ HyperlinkActionType obsahuje následující členy:

## Pole

| Field | Description |
| :- | :- |
| UNKNOWN | Nerozpoznaný typ akce. |
| NO_ACTION | Žádná akce. |
| HYPERLINK | Běžný hypertextový odkaz. |
| JUMP_FIRST_SLIDE | Přeskočit na první snímek prezentace. |
| JUMP_PREVIOUS_SLIDE | Přeskočit na předchozí snímek. |
| JUMP_NEXT_SLIDE | Přeskočit na další snímek. |
| JUMP_LAST_SLIDE | Přeskočit na poslední snímek prezentace. |
| JUMP_END_SHOW | Přeskočit na konec prezentace. |
| JUMP_LAST_VIEWED_SLIDE | Přeskočit na naposledy zobrazený snímek. |
| JUMP_SPECIFIC_SLIDE | Přeskočit na konkrétní snímek, určený vlastností [`IHyperlink.target_slide`](/slides/python-net/cs/aspose.slides/ihyperlink/target_slide). |
| START_CUSTOM_SLIDE_SHOW | Spustit vlastní prezentaci. |
| OPEN_FILE | Otevřít odkazovaný soubor. |
| OPEN_PRESENTATION | Otevřít odkazovanou prezentaci. |
| START_STOP_MEDIA | Spustit/zastavit přehrávání mediálního souboru. |
| START_MACRO | Spustit provádění makra. |
| START_PROGRAM | Spustit program. |
