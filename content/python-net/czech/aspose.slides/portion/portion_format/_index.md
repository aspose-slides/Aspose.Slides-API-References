## portion_format vlastnost
Vrací formátovací objekt, který obsahuje explicitně nastavené formátovací vlastnosti textové části bez aplikace dědičnosti.
            Pouze ke čtení [`IPortionFormat`](/slides/python-net/cs/aspose.slides/iportionformat).


### Poznámky

Formátovací objekt obsahuje formátovací parametry definované pouze pro aktuální část, děděná data nejsou aplikována.


Pro získání účinných hodnot včetně zděděných použijte metodu [`PortionFormat.get_effective`](/slides/python-net/cs/aspose.slides/portionformat/get_effective).
