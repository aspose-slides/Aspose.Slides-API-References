## ShapeStyle třída

Reprezentuje odkaz na styl tvaru.

Typ ShapeStyle obsahuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`line_color`](/slides/python-net/cs/aspose.slides/shapestyle/line_color/) | Vrací barvu obrysu tvaru.<br/> Jen pro čtení [`IColorFormat`](/slides/python-net/cs/aspose.slides/icolorformat). |
| [`line_style_index`](/slides/python-net/cs/aspose.slides/shapestyle/line_style_index/) | Vrací nebo nastavuje index sloupce čáry v matici stylu.<br/> Čtení/zápis **int**. |
| [`fill_color`](/slides/python-net/cs/aspose.slides/shapestyle/fill_color/) | Vrací barvu výplně tvaru.<br/> Jen pro čtení [`IColorFormat`](/slides/python-net/cs/aspose.slides/icolorformat). |
| [`fill_style_index`](/slides/python-net/cs/aspose.slides/shapestyle/fill_style_index/) | Vrací nebo nastavuje index sloupce výplně tvaru v maticích stylů.<br/> 0 znamená žádnou výplň,<br/> kladná hodnota – index ve výplních motivu,<br/> záporná hodnota – index v pozadích motivu.<br/> Čtení/zápis **int**. |
| [`effect_color`](/slides/python-net/cs/aspose.slides/shapestyle/effect_color/) | Vrací barvu efektu tvaru.<br/> Jen pro čtení [`IColorFormat`](/slides/python-net/cs/aspose.slides/icolorformat). |
| [`effect_style_index`](/slides/python-net/cs/aspose.slides/shapestyle/effect_style_index/) | Vrací nebo nastavuje index sloupce efektu tvaru v matici stylu.<br/> Čtení/zápis **int**. |
| [`font_color`](/slides/python-net/cs/aspose.slides/shapestyle/font_color/) | Vrací barvu písma tvaru.<br/> Jen pro čtení [`IColorFormat`](/slides/python-net/cs/aspose.slides/icolorformat). |
| [`font_collection_index`](/slides/python-net/cs/aspose.slides/shapestyle/font_collection_index/) | Vrací nebo nastavuje index písma tvaru ve sbírce písem.<br/> Čtení/zápis [`FontCollectionIndex`](/slides/python-net/cs/aspose.slides/fontcollectionindex). |
