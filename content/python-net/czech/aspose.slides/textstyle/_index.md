## TextStyle třída

Tato třída obsahuje vlastnosti formátování textového stylu.

**Dědičnost:**[`TextStyle`](/slides/python-net/cs/aspose.slides/textstyle) → [`PVIObject`](/slides/python-net/cs/aspose.slides/pviobject)

Typ TextStyle zpřístupňuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`default_paragraph_format`](/slides/python-net/cs/aspose.slides/textstyle/default_paragraph_format/) | Výchozí vlastnosti odstavce.<br/>            Pouze pro čtení [`IParagraphFormat`](/slides/python-net/cs/aspose.slides/iparagraphformat). |
| [`slide`](/slides/python-net/cs/aspose.slides/textstyle/slide/) |  |
| [`presentation`](/slides/python-net/cs/aspose.slides/textstyle/presentation/) |  |

| Metoda | Popis |
| :- | :- |
| [`get_level(self, index)`](/slides/python-net/cs/aspose.slides/textstyle/get_level/#int) | Pokud úroveň stylu existuje, vrátí ji, jinak vrátí None. |
