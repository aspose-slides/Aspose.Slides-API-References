## ITextStyleEffectiveData třída

Neměnný objekt, který obsahuje účinné vlastnosti stylu textu.

Typ ITextStyleEffectiveData vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`default_paragraph_format`](/slides/python-net/cs/aspose.slides/itextstyleeffectivedata/default_paragraph_format/) | Vrací účinné výchozí vlastnosti odstavce.<br/>            Pouze ke čtení [`IParagraphFormatEffectiveData`](/slides/python-net/cs/aspose.slides/iparagraphformateffectivedata). |

## Metody

| Metoda | Popis |
| :- | :- |
| [`get_level(self, index)`](/slides/python-net/cs/aspose.slides/itextstyleeffectivedata/get_level/#int) | Vrací úroveň účinného stylu. |

### Poznámky

Toto rozhraní se používá spolu s rozhraním [`ITextStyle`](/slides/python-net/cs/aspose.slides/itextstyle) k vrácení účinných hodnot formátování s aplikovanou dědičností.
