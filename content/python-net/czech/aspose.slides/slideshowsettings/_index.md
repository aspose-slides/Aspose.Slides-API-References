## SlideShowSettings třída

Reprezentuje nastavení slideshow pro prezentaci.

Typ SlideShowSettings vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`slide_show_type`](/slides/python-net/cs/aspose.slides/slideshowsettings/slide_show_type/) | Získává nebo nastavuje typ slideshow. Reprezentováno následujícími [`SlideShowSettings.slide_show_type`](/slides/python-net/cs/aspose.slides/slideshowsettings/slide_show_type) předky: [`BrowsedAtKiosk`](/slides/python-net/cs/aspose.slides/browsedatkiosk), [`PresentedBySpeaker`](/slides/python-net/cs/aspose.slides/presentedbyspeaker) a [`BrowsedByIndividual`](/slides/python-net/cs/aspose.slides/browsedbyindividual) |
| [`loop`](/slides/python-net/cs/aspose.slides/slideshowsettings/loop/) | Opakovat slideshow |
| [`show_narration`](/slides/python-net/cs/aspose.slides/slideshowsettings/show_narration/) | Zobrazit vyprávění v slideshow |
| [`show_animation`](/slides/python-net/cs/aspose.slides/slideshowsettings/show_animation/) | Zobrazit animaci v slideshow |
| [`pen_color`](/slides/python-net/cs/aspose.slides/slideshowsettings/pen_color/) | Barva pera pro slideshow |
| [`slides`](/slides/python-net/cs/aspose.slides/slideshowsettings/slides/) | Rozsah snímků |
| [`use_timings`](/cs/slides/python-net/aspose.slides/slideshowsettings/use_timings/) | Použít časování v slideshow |
| [`show_media_controls`](/slides/python-net/cs/aspose.slides/slideshowsettings/show_media_controls/) | Zobrazit ovládací prvky médií |
