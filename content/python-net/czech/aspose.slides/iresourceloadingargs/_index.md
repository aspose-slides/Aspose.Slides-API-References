## IResourceLoadingArgs třída

Rozhraní pro argumenty načítání externích zdrojů.

Typ IResourceLoadingArgs poskytuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`original_uri`](/slides/python-net/cs/aspose.slides/iresourceloadingargs/original_uri/) | Původní URI zdroje, jak je uvedeno v importované prezentaci. |
| [`uri`](/slides/python-net/cs/aspose.slides/iresourceloadingargs/uri/) | URI zdroje, který se používá pro stahování, pokud **Aspose.Slides.IResourceLoadingCallback.ResourceLoading(Aspose.Slide** <br/>            vrátí [`ResourceLoadingAction.DEFAULT`](/slides/python-net/cs/aspose.slides/resourceloadingaction/DEFAULT). <br/>            Na začátku je nastaven na původní URI zdroje, ale může být předefinováno na libovolnou hodnotu. |

## Metody

| Metoda | Popis |
| :- | :- |
| [`set_data(self, data)`](/slides/python-net/cs/aspose.slides/iresourceloadingargs/set_data/#bytes) | Nastaví uživatelem poskytnutá data zdroje, která jsou použita, pokud **Aspose.Slides.IResourceLoadingCallback.ResourceLoading(Aspose.Slide** <br/>            vrátí [`ResourceLoadingAction.USER_PROVIDED`](/slides/python-net/cs/aspose.slides/resourceloadingaction/USER_PROVIDED). |
