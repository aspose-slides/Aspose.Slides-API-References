## IDigitalSignature třída

Digitální podpis v podepsaném souboru.

Typ IDigitalSignature poskytuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`certificate`](/slides/python-net/cs/aspose.slides/idigitalsignature/certificate/) | Objekt certifikátu, který byl použit k podepsání dokumentu.<br/>            Read-only **System.Security.Cryptography.X509Certificates.X509Certificate2**. |
| [`is_valid`](/slides/python-net/cs/aspose.slides/idigitalsignature/is_valid/) | Pokud je tento digitální podpis platný a dokument nebyl poškozen, bude tato hodnota true.<br/>            Read-only **bool**. |
| [`sign_time`](/slides/python-net/cs/aspose.slides/idigitalsignature/sign_time/) | Čas, kdy byl dokument podepsán.<br/>            Read-only **System.DateTime**. |
| [`comments`](/slides/python-net/cs/aspose.slides/idigitalsignature/comments/) | Účel podpisu.<br/>            Read/write **str**. |
