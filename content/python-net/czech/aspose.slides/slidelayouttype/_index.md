## SlideLayoutType enumerace

Reprezentuje typ rozložení snímku.

Typ SlideLayoutType obsahuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| CUSTOM | Vlastní |
| TITLE | Nadpis |
| TEXT | Text |
| TWO_COLUMN_TEXT | Text se dvěma sloupci |
| TABLE | Tabulka |
| TEXT_AND_CHART | Text a graf |
| CHART_AND_TEXT | Graf a text |
| DIAGRAM | Diagram |
| CHART | Graf |
| TEXT_AND_CLIP_ART | Text a Clip Art |
| CLIP_ART_AND_TEXT | Clip Art a text |
| TITLE_ONLY | Pouze nadpis |
| BLANK | Prázdný |
| TEXT_AND_OBJECT | Text a objekt |
| OBJECT_AND_TEXT | Objekt a text |
| OBJECT | Objekt |
| TITLE_AND_OBJECT | Nadpis a objekt |
| TEXT_AND_MEDIA | Text a média |
| MEDIA_AND_TEXT | Média a text |
| OBJECT_OVER_TEXT | Objekt nad textem |
| TEXT_OVER_OBJECT | Text nad objektem |
| TEXT_AND_TWO_OBJECTS | Text a dva objekty |
| TWO_OBJECTS_AND_TEXT | Dva objekty a text |
| TWO_OBJECTS_OVER_TEXT | Dva objekty nad textem |
| FOUR_OBJECTS | Čtyři objekty |
| VERTICAL_TEXT | Vertikální text |
| CLIP_ART_AND_VERTICAL_TEXT | Clip Art a vertikální text |
| VERTICAL_TITLE_AND_TEXT | Vertikální nadpis a text |
| VERTICAL_TITLE_AND_TEXT_OVER_CHART | Vertikální nadpis a text nad grafem |
| TWO_OBJECTS | Dva objekty |
| OBJECT_AND_TWO_OBJECT | Objekt a dva objekty |
| TWO_OBJECTS_AND_OBJECT | Dva objekty a objekt |
| SECTION_HEADER | Záhlaví sekce |
| TWO_TEXT_AND_TWO_OBJECTS | Dva texty a dva objekty |
| TITLE_OBJECT_AND_CAPTION | Nadpis, objekt a popisek |
| PICTURE_AND_CAPTION | Obrázek a popisek |
