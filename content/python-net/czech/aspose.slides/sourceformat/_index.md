## SourceFormat enumerace

Reprezentuje formát zdrojového souboru.

Typ SourceFormat obsahuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| PPT | Microsoft PowerPoint 97-2003 prezentace (*.ppt). |
| PPTX | Microsoft Office Open XML prezentace (*.pptx). |
| ODP | OpenDocument prezentace (*.odp). |
| PPTM | Microsoft Office Open XML prezentace s makry (*.pptm). |
| PPSX | Microsoft Office Open XML prezentace (*.ppsx). |
| PPSM | Microsoft Office Open XML prezentace s makry (*.ppsm). |
| POTX | Microsoft Office Open XML šablona (*.potx). |
| POTM | Microsoft Office Open XML šablona s makry (*.potm). |
| PPS | Microsoft PowerPoint 97-2003 prezentace (*.pps). |
| POT | Microsoft PowerPoint 97-2003 šablona (*.pot). |
| OTP | OpenDocument šablona prezentace (*.otp). |
| FODP | Flat XML ODF prezentace (*.fodp). |
| XML | PowerPoint XML prezentace (*.xml). |
