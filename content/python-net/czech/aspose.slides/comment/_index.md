## Třída Comment

Reprezentuje komentář na snímku.

Typ Comment obsahuje následující členy:

## Vlastnosti

| Property | Description |
| :- | :- |
| [`text`](/slides/python-net/cs/aspose.slides/comment/text/) | Vrací nebo nastavuje prostý text komentáře ke snímku.<br/>            Čtení/zápis **str**. |
| [`created_time`](/slides/python-net/cs/aspose.slides/comment/created_time/) | Vrací nebo nastavuje čas vytvoření komentáře.<br/>            Nastavení této vlastnosti na **System.DateTime** znamená, že čas komentáře není nastaven.<br/>            Čtení/zápis **System.DateTime**. |
| [`slide`](/slides/python-net/cs/aspose.slides/comment/slide/) | Vrací nebo nastavuje nadřazený snímek komentáře.<br/>            Pouze ke čtení [`ISlide`](/slides/python-net/cs/aspose.slides/islide). |
| [`author`](/slides/python-net/cs/aspose.slides/comment/author/) | Vrací autora komentáře.<br/>            Pouze ke čtení [`ICommentAuthor`](/slides/python-net/cs/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/cs/aspose.slides/comment/position/) | Vrací nebo nastavuje pozici komentáře na snímku.<br/>            Čtení/zápis **aspose.slides.PointF**. |
| [`parent_comment`](/slides/python-net/cs/aspose.slides/comment/parent_comment/) | Vrací nebo nastavuje nadřazený komentář.<br/>            Čtení/zápis [`IComment`](/slides/python-net/cs/aspose.slides/icomment). |

## Metody

| Method | Description |
| :- | :- |
| [`remove(self)`](/slides/python-net/cs/aspose.slides/comment/remove/#) | Odstraní komentář a všechny jeho odpovědi z nadřazené kolekce. |
