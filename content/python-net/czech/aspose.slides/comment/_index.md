## Comment třída

Reprezentuje komentář na snímku.

Typ Comment poskytuje následující členy:

## Vlastnosti

| Property | Popis |
| :- | :- |
| [`text`](/slides/python-net/cs/aspose.slides/comment/text/) | Vrací nebo nastavuje prostý text komentáře na snímku.<br/>            Čtení/Zápis **str**. |
| [`created_time`](/slides/python-net/cs/aspose.slides/comment/created_time/) | Vrací nebo nastavuje čas vytvoření komentáře.<br/>            Nastavením této vlastnosti na **System.DateTime** znamená, že není nastaven čas komentáře.<br/>            Čtení/Zápis **System.DateTime**. |
| [`slide`](/slides/python-net/cs/aspose.slides/comment/slide/) | Vrací nebo nastavuje nadřazený snímek komentáře.<br/>            Pouze ke čtení [`ISlide`](/slides/python-net/cs/aspose.slides/islide). |
| [`author`](/slides/python-net/cs/aspose.slides/comment/author/) | Vrací autora komentáře.<br/>            Pouze ke čtení [`ICommentAuthor`](/slides/python-net/cs/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/cs/aspose.slides/comment/position/) | Vrací nebo nastavuje pozici komentáře na snímku.<br/>            Čtení/Zápis [`PointF`](/slides/python-net/cs/aspose.slides/pointf). |
| [`parent_comment`](/slides/python-net/cs/aspose.slides/comment/parent_comment/) | Získá nebo nastaví nadřazený komentář.<br/>            Čtení/Zápis [`IComment`](/slides/python-net/cs/aspose.slides/icomment). |

## Metody

| Method | Popis |
| :- | :- |
| [`remove(self)`](/slides/python-net/cs/aspose.slides/comment/remove/#) | Odstraní komentář a všechny jeho odpovědi z nadřazené kolekce. |
