## vlastnost width
Získá nebo nastaví width tvaru, měřeno v bodech.
            Čtení/zápis **float**.


### Poznámky

Vrácená hodnota je vždy definovaná a nikdy není **float**.
            Přiřazená hodnota musí být také definovaná; přiřaďte **float** pouze k vlastnostem instance `RawFrame`.
