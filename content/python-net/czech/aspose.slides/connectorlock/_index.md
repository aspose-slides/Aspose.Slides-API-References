## ConnectorLock třída

Určuje, které operace jsou na nadřazeném Connectoru zakázány.

**Dědičnost:**[`ConnectorLock`](/slides/python-net/cs/aspose.slides/connectorlock) → [`BaseShapeLock`](/slides/python-net/cs/aspose.slides/baseshapelock)

Typ ConnectorLock obsahuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`no_locks`](/slides/python-net/cs/aspose.slides/connectorlock/no_locks/) | Vrátí true, pokud jsou všechna lock-flags zakázána.<br/>            Pouze pro čtení **bool**. |
| [`grouping_locked`](/slides/python-net/cs/aspose.slides/connectorlock/grouping_locked/) | Určuje, zda je přidání tohoto tvaru do skupiny zakázáno.<br/>            Čtení/zápis **bool**. |
| [`select_locked`](/slides/python-net/cs/aspose.slides/connectorlock/select_locked/) | Určuje, zda je výběr tohoto tvaru zakázán.<br/>            Čtení/zápis **bool**. |
| [`rotate_locked`](/slides/python-net/cs/aspose.slides/connectorlock/rotate_locked/) | Určuje, zda je změna úhlu otáčení tohoto tvaru zakázána.<br/>            Čtení/zápis **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/cs/aspose.slides/connectorlock/aspect_ratio_locked/) | Určuje, zda má tvar při změně velikosti zachovat poměr stran.<br/>            Čtení/zápis **bool**. |
| [`position_move`](/slides/python-net/cs/aspose.slides/connectorlock/position_move/) | Určuje, zda je přesunutí tohoto tvaru zakázáno.<br/>            Čtení/zápis **bool**. |
| [`size_locked`](/slides/python-net/cs/aspose.slides/connectorlock/size_locked/) | Určuje, zda je změna velikosti tohoto tvaru zakázána.<br/>            Čtení/zápis **bool**. |
| [`edit_points_locked`](/slides/python-net/cs/aspose.slides/connectorlock/edit_points_locked/) | Určuje, zda je přímá změna obrysu tohoto tvaru zakázána.<br/>            Čtení/zápis **bool**. |
| [`adjust_handles_locked`](/slides/python-net/cs/aspose.slides/connectorlock/adjust_handles_locked/) | Určuje, zda je změna adjust values zakázána.<br/>            Čtení/zápis **bool**. |
| [`arrowheads_locked`](/slides/python-net/cs/aspose.slides/connectorlock/arrowheads_locked/) | Určuje, zda je změna arrowheads zakázána.<br/>            Čtení/zápis **bool**. |
| [`shape_type_locked`](/slides/python-net/cs/aspose.slides/connectorlock/shape_type_locked/) | Určuje, zda je změna typu tvaru zakázána.<br/>            Čtení/zápis **bool**. |
