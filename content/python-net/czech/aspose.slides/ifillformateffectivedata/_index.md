## IFillFormatEffectiveData class

Neměnný objekt, který obsahuje účinné vlastnosti výplně.

Typ IFillFormatEffectiveData poskytuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`fill_type`](/slides/python-net/cs/aspose.slides/ifillformateffectivedata/fill_type/) | Vrací typ výplně.<br/>            Pouze pro čtení [`FillType`](/slides/python-net/cs/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/cs/aspose.slides/ifillformateffectivedata/solid_fill_color/) | Vrací barvu výplně.<br/>            Pouze pro čtení **aspose.slides.Color**. |
| [`solid_fill_scheme_color`](/slides/python-net/cs/aspose.slides/ifillformateffectivedata/solid_fill_scheme_color/) | Získá barvu výplně definovanou barevným schématem.<br/>            Hodnota [`SchemeColor.NOT_DEFINED`](/slides/python-net/cs/aspose.slides/schemecolor/NOT_DEFINED) naznačuje, že [`IFillFormatEffectiveData.solid_fill_color`](/slides/python-net/cs/aspose.slides/ifillformateffectivedata/solid_fill_color) <br/>            není barvou ze schématu.<br/>            Pouze pro čtení [`SchemeColor`](/slides/python-net/cs/aspose.slides/schemecolor). |
| [`gradient_format`](/slides/python-net/cs/aspose.slides/ifillformateffectivedata/gradient_format/) | Vrací formát gradientové výplně.<br/>            Pouze pro čtení [`IGradientFormatEffectiveData`](/slides/python-net/cs/aspose.slides/igradientformateffectivedata). |
| [`pattern_format`](/slides/python-net/cs/aspose.slides/ifillformateffectivedata/pattern_format/) | Vrací formát vzorové výplně.<br/>            Pouze pro čtení [`IPatternFormatEffectiveData`](/slides/python-net/cs/aspose.slides/ipatternformateffectivedata). |
| [`picture_fill_format`](/slides/python-net/cs/aspose.slides/ifillformateffectivedata/picture_fill_format/) | Vrací formát obrazové výplně.<br/>            Pouze pro čtení [`IPictureFillFormatEffectiveData`](/slides/python-net/cs/aspose.slides/ipicturefillformateffectivedata). |
| [`rotate_with_shape`](/slides/python-net/cs/aspose.slides/ifillformateffectivedata/rotate_with_shape/) | Určuje, zda má být výplň otáčena spolu s tvarem.<br/>            Pouze pro čtení **bool**. |
