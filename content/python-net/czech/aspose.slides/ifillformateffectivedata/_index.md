## IFillFormatEffectiveData třída

Neměnný objekt, který obsahuje efektivní vlastnosti formátování výplně.

Typ IFillFormatEffectiveData poskytuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`fill_type`](/slides/python-net/cs/aspose.slides/ifillformateffectivedata/fill_type/) | Vrací typ výplně.<br/>            Pouze pro čtení [`FillType`](/slides/python-net/cs/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/cs/aspose.slides/ifillformateffectivedata/solid_fill_color/) | Vrací barvu výplně.<br/>            Pouze pro čtení [`Color`](/slides/python-net/cs/aspose.slides/color). |
| [`solid_fill_scheme_color`](/slides/python-net/cs/aspose.slides/ifillformateffectivedata/solid_fill_scheme_color/) | Získá barvu výplně definovanou barevným schématem.<br/>            Hodnota [`SchemeColor.NOT_DEFINED`](/slides/python-net/cs/aspose.slides/schemecolor/NOT_DEFINED) indikuje, že [`IFillFormatEffectiveData.solid_fill_color`](/slides/python-net/cs/aspose.slides/ifillformateffectivedata/solid_fill_color) <br/>            není barva schématu.<br/>            Pouze pro čtení [`SchemeColor`](/slides/python-net/cs/aspose.slides/schemecolor). |
| [`gradient_format`](/slides/python-net/cs/aspose.slides/ifillformateffectivedata/gradient_format/) | Vrací formát přechodové výplně.<br/>            Pouze pro čtení [`IGradientFormatEffectiveData`](/slides/python-net/cs/aspose.slides/igradientformateffectivedata). |
| [`pattern_format`](/slides/python-net/cs/aspose.slides/ifillformateffectivedata/pattern_format/) | Vrací formát vzorové výplně.<br/>            Pouze pro čtení [`IPatternFormatEffectiveData`](/slides/python-net/cs/aspose.slides/ipatternformateffectivedata). |
| [`picture_fill_format`](/slides/python-net/cs/aspose.slides/ifillformateffectivedata/picture_fill_format/) | Vrací formát obrázkové výplně.<br/>            Pouze pro čtení [`IPictureFillFormatEffectiveData`](/slides/python-net/cs/aspose.slides/ipicturefillformateffectivedata). |
| [`rotate_with_shape`](/slides/python-net/cs/aspose.slides/ifillformateffectivedata/rotate_with_shape/) | Určuje, zda má být výplň otočena spolu se tvarem.<br/>            Pouze pro čtení **bool**. |


### Poznámky

Toto rozhraní se používá spolu s rozhraním [`IFillFormat`](/slides/python-net/cs/aspose.slides/ifillformat) k vrácení efektivních hodnot formátování s aplikovaným děděním.
