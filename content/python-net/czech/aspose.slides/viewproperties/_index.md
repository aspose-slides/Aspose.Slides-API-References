## ViewProperties třída

Vlastnosti zobrazení pro celou prezentaci.

Typ ViewProperties poskytuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`last_view`](/slides/python-net/cs/aspose.slides/viewproperties/last_view/) | Určuje režim zobrazení, který byl použit při posledním uložení dokumentu prezentace.<br/>            Číst/Zapisovat [`ViewType`](/slides/python-net/cs/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/cs/aspose.slides/viewproperties/show_comments/) | Určuje, zda se mají zobrazovat komentáře snímků.<br/>            Číst/Zapisovat [`NullableBool`](/slides/python-net/cs/aspose.slides/nullablebool). |
| [`normal_view_properties`](/slides/python-net/cs/aspose.slides/viewproperties/normal_view_properties/) | Reprezentuje vlastnosti normálního zobrazení. Normální zobrazení se skládá z<br/>            tří oblastí obsahu: samotného snímku, postranní oblasti obsahu a spodní oblasti obsahu.<br/>            Jen ke čtení [`INormalViewProperties`](/slides/python-net/cs/aspose.slides/inormalviewproperties). |
| [`slide_view_properties`](/slides/python-net/cs/aspose.slides/viewproperties/slide_view_properties/) | Určuje společné vlastnosti zobrazení související s režimem zobrazení snímku.<br/>            Jen ke čtení [`ICommonSlideViewProperties`](/slides/python-net/cs/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/cs/aspose.slides/viewproperties/notes_view_properties/) | Určuje společné vlastnosti zobrazení související s režimem zobrazení poznámek.<br/>            Jen ke čtení [`ICommonSlideViewProperties`](/slides/python-net/cs/aspose.slides/icommonslideviewproperties). |
| [`grid_spacing`](/slides/python-net/cs/aspose.slides/viewproperties/grid_spacing/) | Vrací nebo nastavuje rozestupy mřížky, která by měla být použita pro mřížku podkladu dokumentu prezentace, v bodech. <br/>            Číst/Zapisovat **float**. |
