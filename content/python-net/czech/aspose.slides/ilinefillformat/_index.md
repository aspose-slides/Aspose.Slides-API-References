## ILineFillFormat třída

Reprezentuje vlastnosti pro výplň čar.

Typ ILineFillFormat poskytuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`fill_type`](/slides/python-net/cs/aspose.slides/ilinefillformat/fill_type/) | Vrací nebo nastavuje typ výplně.<br/>            Čtení/zápis [`FillType`](/slides/python-net/cs/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/cs/aspose.slides/ilinefillformat/solid_fill_color/) | Vrací barvu plné výplně.<br/>            Pouze ke čtení [`IColorFormat`](/slides/python-net/cs/aspose.slides/icolorformat). |
| [`gradient_format`](/slides/python-net/cs/aspose.slides/ilinefillformat/gradient_format/) | Vrací formát přechodové výplně.<br/>            Pouze ke čtení [`IGradientFormat`](/slides/python-net/cs/aspose.slides/igradientformat). |
| [`pattern_format`](/slides/python-net/cs/aspose.slides/ilinefillformat/pattern_format/) | Vrací formát vzorové výplně.<br/>            Pouze ke čtení [`IPatternFormat`](/slides/python-net/cs/aspose.slides/ipatternformat). |
| [`rotate_with_shape`](/slides/python-net/cs/aspose.slides/ilinefillformat/rotate_with_shape/) | Určuje, zda by měla být výplň otáčena spolu s tvarem.<br/>            Čtení/zápis [`NullableBool`](/slides/python-net/cs/aspose.slides/nullablebool). |
