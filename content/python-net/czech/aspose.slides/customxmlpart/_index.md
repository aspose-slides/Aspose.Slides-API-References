## CustomXmlPart třída

Representuje vlastní část XML.

Typ CustomXmlPart vystavuje následující členy:

## Vlastnosti

| Property | Description |
| :- | :- |
| [`xml_data`](/slides/python-net/cs/aspose.slides/customxmlpart/xml_data/) | Vrací nebo nastavuje data XML.<br/>            Čtení/zápis **int**[].<br/>            hodnota je `None`. hodnota je prázdná nebo data XML jsou neplatná. |
| [`xml_as_string`](/slides/python-net/cs/aspose.slides/customxmlpart/xml_as_string/) | Vrací nebo nastavuje data XML jako řetězec UTF-8.<br/>            Čtení/zápis **str**.<br/>            hodnota je `None`. hodnota je prázdná nebo data XML jsou neplatná. |
| [`item_id`](/slides/python-net/cs/aspose.slides/customxmlpart/item_id/) | Určuje globálně jedinečný identifikátor (GUID), který jednoznačně identifikuje jednu vlastní část XML <br/>            v dokumentu Office Open XML.<br/>            Pouze pro čtení **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/cs/aspose.slides/customxmlpart/namespace_schemas/) | Vrací kolekci schémat XML, která jsou spojena s vlastní částí XML.<br/>            Pouze pro čtení **str**[]. |

## Metody

| Method | Description |
| :- | :- |
| [`remove(self)`](/slides/python-net/cs/aspose.slides/customxmlpart/remove/#) | Odebere vlastní část XML z prezentace. |
