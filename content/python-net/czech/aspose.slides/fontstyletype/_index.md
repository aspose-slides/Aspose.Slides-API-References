## FontStyleType výčet

Definuje formátovací styly, které lze použít na text.

Typ FontStyleType obsahuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| REGULAR | Standardní text. |
| BOLD | Tučný text. |
| ITALIC | Kurzivní text. |
| UNDERLINE | Podtržený text. |
| STRIKEOUT | Text přeškrtnutý vodorovnou čarou. |
