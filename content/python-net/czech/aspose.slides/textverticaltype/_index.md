## TextVerticalType enumerace

Určuje vertikální režim psaní pro text.

Typ TextVerticalType obsahuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| NOT_DEFINED | Není definováno. |
| HORIZONTAL | Horizontální text. |
| VERTICAL | Vertikální text. |
| VERTICAL270 | Vertikální text o 270 stupňů. |
| WORD_ART_VERTICAL | Vertikální text WordArt. |
| EAST_ASIAN_VERTICAL | Východoasijský vertikální text. |
| MONGOLIAN_VERTICAL | Mongolský vertikální text. |
| WORD_ART_VERTICAL_RIGHT_TO_LEFT | Vertikální text WordArt zprava doleva. |
