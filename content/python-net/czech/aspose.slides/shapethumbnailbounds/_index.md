## ShapeThumbnailBounds výčet

Výčet typů ohraničení miniatury tvaru.

Typ ShapeThumbnailBounds poskytuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| SLIDE | Miniatura tvaru bude mít velikost rovnající se velikosti snímku.<br/>            Pozice tvaru bude uložena. |
| SHAPE | Miniatura tvaru bude mít velikost rovnající se obdélníku ohraničení tvaru<br/>            s ohledem na nastavení obrysu tvaru. |
| APPEARANCE | Miniatura tvaru bude mít velikost rovnající se vzhledu tvaru (v ohraničení snímku). <br/>            Může nastat případ, že vzhled tvaru se nevejde do ohraničení tvaru. Např.<br/>            rotace, šikmé spojení ostrého úhlu, 3D efekty, atd. |
