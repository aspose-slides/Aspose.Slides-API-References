## ICustomXmlPart třída

Zastupuje vlastní xml část.

Typ ICustomXmlPart poskytuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`xml_as_string`](/slides/python-net/cs/aspose.slides/icustomxmlpart/xml_as_string/) | Vrací nebo nastavuje data xml jako řetězec UTF-8.<br/>            Čtení/zápis **str**.<br/>            hodnota je `None`.hodnota je prázdná nebo xml-data je neplatná. |
| [`xml_data`](/slides/python-net/cs/aspose.slides/icustomxmlpart/xml_data/) | Vrací nebo nastavuje data xml.<br/>            Čtení/zápis **int**[].<br/>            hodnota je `None`.hodnota je prázdná nebo xml-data je neplatná. |
| [`item_id`](/slides/python-net/cs/aspose.slides/icustomxmlpart/item_id/) | Určuje globálně jedinečný identifikátor (GUID), který jednoznačně identifikuje jedinou vlastní XML <br/>            část v dokumentu Office Open XML.<br/>            Pouze pro čtení **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/cs/aspose.slides/icustomxmlpart/namespace_schemas/) | Vrací kolekci schémat XML, která jsou spojena s vlastní částí XML.<br/>            Pouze pro čtení **str**[]. |

## Metody

| Metoda | Popis |
| :- | :- |
| [`remove(self)`](/slides/python-net/cs/aspose.slides/icustomxmlpart/remove/#) | Odstraňuje vlastní xml část z prezentace. |
