## vlastnost rotation
Vrací nebo nastavuje počet stupňů, o které je zadaný tvar otočen kolem
            osy z. Kladná hodnota indikuje otáčení po směru hodinových ručiček; záporná hodnota
            indikuje otáčení proti směru hodinových ručiček.
            Read/write **float**.

### Poznámky

Vrácená hodnota je vždy definována (není float.NaN). Přiřazená hodnota musí být definována (není float.NaN). Můžete nastavit nedefinované hodnoty pro vlastnosti instance RawFrame.
