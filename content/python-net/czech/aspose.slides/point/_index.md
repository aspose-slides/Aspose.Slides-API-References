## třída Point

Typ Point představuje uspořádanou dvojici celých čísel x a y, která určuje bod ve dvourozměrné rovině. Kompatibilní s .NET `System.Drawing.Point`.

Typ Point obsahuje následující členy:

## Konstruktory

| Konstruktor | Popis |
| :- | :- |
| [`__init__(self, x=0, y=0)`](/slides/python-net/cs/aspose.slides/point/__init__/#int-int) | Vytvoří bod se zadanými souřadnicemi. Hodnoty typu float jsou zkráceny na celá čísla. |

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`x`](/slides/python-net/cs/aspose.slides/point/x/) | Získá nebo nastaví x-souřadnici tohoto bodu.<br/>            Čtení/zápis **int**. |
| [`y`](/slides/python-net/cs/aspose.slides/point/y/) | Získá nebo nastaví y-souřadnici tohoto bodu.<br/>            Čtení/zápis **int**. |


### Poznámky

Body se porovnávají podle svých souřadnic pomocí `==` a mohou být použity jako klíče slovníků nebo položky množin.
