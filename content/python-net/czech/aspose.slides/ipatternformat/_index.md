## IPatternFormat třída

Representuje vzor pro vyplnění tvaru.

Typ IPatternFormat poskytuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`pattern_style`](/slides/python-net/cs/aspose.slides/ipatternformat/pattern_style/) | Vrací nebo nastavuje styl vzoru.<br/>Čtení/zápis [`PatternStyle`](/slides/python-net/cs/aspose.slides/patternstyle). |
| [`fore_color`](/slides/python-net/cs/aspose.slides/ipatternformat/fore_color/) | Vrací barvu popředí vzoru.<br/>Pouze pro čtení [`IColorFormat`](/slides/python-net/cs/aspose.slides/icolorformat). |
| [`back_color`](/slides/python-net/cs/aspose.slides/ipatternformat/back_color/) | Vrací barvu pozadí vzoru.<br/>Pouze pro čtení [`IColorFormat`](/slides/python-net/cs/aspose.slides/icolorformat). |
