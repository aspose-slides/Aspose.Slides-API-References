## ITextHighlightingOptions třída

Reprezentuje možnosti, které lze použít k zvýraznění textu v textovém rámečku.

Typ ITextHighlightingOptions obsahuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`case_sensitive`](/slides/python-net/cs/aspose.slides/itexthighlightingoptions/case_sensitive/) | Nastavte true pro použití vyhledávání rozlišujícího velikost písmen, false - jinak.<br/>            Číst/zapisovat **bool**. |
| [`whole_words_only`](/slides/python-net/cs/aspose.slides/itexthighlightingoptions/whole_words_only/) | Nastavte true pro shodu pouze s celými slovy, false - jinak.<br/>            Číst/zapisovat **bool**. |
