## IPictureFillFormatEffectiveData třída

Neměnný objekt, který obsahuje vlastnosti vyplnění obrázkem.

Typ IPictureFillFormatEffectiveData vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`dpi`](/slides/python-net/cs/aspose.slides/ipicturefillformateffectivedata/dpi/) | Vrací dpi, které se používá k vyplnění obrázku.<br/>            Pouze pro čtení **int**. |
| [`picture_fill_mode`](/slides/python-net/cs/aspose.slides/ipicturefillformateffectivedata/picture_fill_mode/) | Vrací režim vyplnění obrázku.<br/>            Pouze pro čtení [`PictureFillMode`](/slides/python-net/cs/aspose.slides/picturefillmode). |
| [`picture`](/slides/python-net/cs/aspose.slides/ipicturefillformateffectivedata/picture/) | Vrací obrázek.<br/>            Pouze pro čtení [`IPictureEffectiveData`](/slides/python-net/cs/aspose.slides/ipictureeffectivedata). |
| [`crop_left`](/slides/python-net/cs/aspose.slides/ipicturefillformateffectivedata/crop_left/) | Vrací počet procent skutečné šířky obrázku, která je oříznuta<br/>            zleva od obrázku. <br/>            Pouze pro čtení **float**. |
| [`crop_top`](/slides/python-net/cs/aspose.slides/ipicturefillformateffectivedata/crop_top/) | Vrací počet procent skutečné výšky obrázku, která je oříznuta<br/>            z vršku obrázku. <br/>            Pouze pro čtení **float**. |
| [`crop_right`](/slides/python-net/cs/aspose.slides/ipicturefillformateffectivedata/crop_right/) | Vrací počet procent skutečné šířky obrázku, která je oříznuta<br/>            zprava od obrázku. <br/>            Pouze pro čtení **float**. |
| [`crop_bottom`](/slides/python-net/cs/aspose.slides/ipicturefillformateffectivedata/crop_bottom/) | Vrací počet procent skutečné výšky obrázku, která je oříznuta<br/>            ze spodu obrázku. <br/>            Pouze pro čtení **float**. |


### Poznámky
