## width vlastnost
Získá nebo nastaví width tvaru, měřenou v bodech.
            Čtení/Zápis **float**.


### Poznámky

Vrácená hodnota je vždy definována a nikdy není **float**.
            Přiřazená hodnota musí být také definována; **float** přiřazujte jen vlastnostem instance `RawFrame`.
