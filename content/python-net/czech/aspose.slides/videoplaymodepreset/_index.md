## Výčet VideoPlayModePreset

Konstanty, které definují, jak je video přehráváno.

Typ VideoPlayModePreset obsahuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| MIXED |  |
| AUTO | Přehraje se automaticky. |
| ON_CLICK | Přehraje se pouze po kliknutí na video rámeček. |
| ALL_SLIDES | Přehraje se na všech snímcích. |
| IN_CLICK_SEQUENCE | Přehraje se automaticky po kliknutí. |
