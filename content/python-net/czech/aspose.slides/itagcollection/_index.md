## ITagCollection třída

Představuje kolekci štítků (uživatelem definované páry řetězců)

Typ ITagCollection obsahuje následující členy:

## Metody

| Metoda | Popis |
| :- | :- |
| [`add(self, name, value)`](/slides/python-net/cs/aspose.slides/itagcollection/add/#str-str) | Přidá nový štítek do kolekce. |
| [`remove(self, name)`](/slides/python-net/cs/aspose.slides/itagcollection/remove/#str) | Odstraní štítek se zadaným názvem z kolekce. |
| [`index_of_name(self, name)`](/slides/python-net/cs/aspose.slides/itagcollection/index_of_name/#str) | Vrací nulový index zadaného klíče v kolekci. |
| [`remove_at(self, index)`](/slides/python-net/cs/aspose.slides/itagcollection/remove_at/#int) | Odstraní štítek na zadaném indexu. |
| [`clear(self)`](/slides/python-net/cs/aspose.slides/itagcollection/clear/#) | Odstraní všechny štítky z kolekce. |
| [`get_value_by_index(self, index)`](/slides/python-net/cs/aspose.slides/itagcollection/get_value_by_index/#int) | Vrací hodnotu štítku na zadaném indexu. |
| [`get_name_by_index(self, index)`](/slides/python-net/cs/aspose.slides/itagcollection/get_name_by_index/#int) | Vrací klíč štítku na zadaném indexu. |
