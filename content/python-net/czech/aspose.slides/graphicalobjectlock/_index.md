## GraphicalObjectLock třída

Určuje, které operace jsou zakázány na nadřazeném GraphicalObject.

**Dědičnost:**[`GraphicalObjectLock`](/slides/python-net/cs/aspose.slides/graphicalobjectlock) → [`BaseShapeLock`](/slides/python-net/cs/aspose.slides/baseshapelock)

Typ GraphicalObjectLock vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`no_locks`](/slides/python-net/cs/aspose.slides/graphicalobjectlock/no_locks/) | Vrátí true, pokud jsou všechny příznaky zamčení zakázány.<br/>            Pouze pro čtení **bool**. |
| [`grouping_locked`](/slides/python-net/cs/aspose.slides/graphicalobjectlock/grouping_locked/) | Určuje, zda je přidání tohoto tvaru do skupiny zakázáno.<br/>            Čtení/zápis **bool**. |
| [`drilldown_locked`](/slides/python-net/cs/aspose.slides/graphicalobjectlock/drilldown_locked/) | Určuje, zda je výběr podtvarů tohoto objektu zakázán.<br/>            Čtení/zápis **bool**. |
| [`select_locked`](/slides/python-net/cs/aspose.slides/graphicalobjectlock/select_locked/) | Určuje, zda je výběr tohoto tvaru zakázán.<br/>            Čtení/zápis **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/cs/aspose.slides/graphicalobjectlock/aspect_ratio_locked/) | Určuje, zda musí tvar zachovat poměr stran při změně velikosti.<br/>            Čtení/zápis **bool**. |
| [`position_locked`](/slides/python-net/cs/aspose.slides/graphicalobjectlock/position_locked/) | Určuje, zda je přesun tohoto tvaru zakázán.<br/>            Čtení/zápis **bool**. |
| [`size_locked`](/slides/python-net/cs/aspose.slides/graphicalobjectlock/size_locked/) | Určuje, zda je změna velikosti tohoto tvaru zakázána.<br/>            Čtení/zápis **bool**. |
