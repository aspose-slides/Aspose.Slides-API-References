## LoadFormat enumerace

Indikuje formát dokumentu, který má být načten.

Typ LoadFormat poskytuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| AUTO | Instrukce pro Aspose.Slides, aby automaticky rozpoznal formát. |
| PPT | Prezentace Microsoft PowerPoint 97-2003. |
| PPS | Microsoft PowerPoint 97-2003 SlideShow. |
| PPTX | Dokument Microsoft Office Open XML PresentationML. |
| PPSX | Microsoft Office Open XML PresentationML SlideShow. |
| ODP | Prezentace OpenOffice ODF. |
| POTX | Šablona Microsoft Office Open XML PresentationML. |
| PPTM | Makro-povolený dokument Microsoft Office Open XML PresentationML. |
| PPSM | Makro-povolený SlideShow Microsoft Office Open XML PresentationML. |
| POTM | Makro-povolená šablona Microsoft Office Open XML PresentationML. |
| OTP | Šablona prezentace OpenOffice OTP. |
| PPT95 | Prezentace Microsoft PowerPoint 95. |
| POT | Šablona prezentace Microsoft PowerPoint 97-2003. |
| FODP | Prezentace Flat XML ODF. |
| UNKNOWN | Neznámý formát souboru |
