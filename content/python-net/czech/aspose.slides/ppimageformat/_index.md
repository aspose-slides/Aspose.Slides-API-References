## PPImageFormat výčtový typ

Formáty obrázků. Tento výčet nahrazuje třídu `System.Drawing.Imaging.ImageFormat`. Je potřeba pro kompatibilitu s COM.

Typ PPImageFormat poskytuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| BMP | Vrací formát bitmapy (BMP). |
| EMF | Vrací formát rozšířeného metafile (EMF). |
| EXIF | Vrací formát výměnného souboru obrázku (Exif). |
| GIF | Vrací formát Graphics Interchange Format (GIF). |
| ICON | Vrací formát ikony Windows. |
| JPEG | Vrací formát Joint Photographic Experts Group (JPEG). |
| MEMORY_BMP | Vrací formát bitmapy v paměti. |
| PNG | Vrací formát W3C Portable Network Graphics (PNG). |
| TIFF | Vrací formát Tagged Image File Format (TIFF). |
| WMF | Vrací formát metafile Windows (WMF). |
