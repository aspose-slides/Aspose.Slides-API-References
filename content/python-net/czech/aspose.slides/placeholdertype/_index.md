## PlaceholderType výčet

Představuje typ zástupného prvku.

Typ PlaceholderType obsahuje následující členy:

| Pole | Popis |
| :- | :- |

| BODY | Tělo. |
| CENTERED_TITLE | Centrovaný název. |
| SUBTITLE | Podtitul. |
| DATE_AND_TIME | Datum a čas. |
| SLIDE_NUMBER | Číslo snímku. |
| FOOTER | Patička. |
| HEADER | Záhlaví. |
| OBJECT | Objekt. |
| CHART | Graf. |

| PICTURE | Obrázek. |
