## Výčet ResourceLoadingAction

Určuje režim načítání externích zdrojů.

Typ ResourceLoadingAction obsahuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| DEFAULT | Aspose.Slides bude načítat externí zdroj obvyklým způsobem. |
| SKIP | Aspose.Slides přeskočí načítání externího zdroje. Pro obrázek bude uloženo pouze odkaz bez dat. |
| USER_PROVIDED | Aspose.Slides použije pole bytů poskytnuté uživatelem v **Aspose.Slides.IResourceLoadingArgs.SetData(Syste** jako data obrázku. |
