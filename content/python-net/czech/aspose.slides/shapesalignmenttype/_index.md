## ShapesAlignmentType enumerace

Definuje způsob, jak změnit umístění vybraných tvarů na snímku.

Typ ShapesAlignmentType vystavuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| ALIGN_LEFT | Zarovnat vlevo |
| ALIGN_RIGHT | Zarovnat vpravo |
| ALIGN_CENTER | Zarovnat na střed |
| ALIGN_TOP | Zarovnat nahoru |
| ALIGN_MIDDLE | Zarovnat doprostřed |
| ALIGN_BOTTOM | Zarovnat dolů |
| DISTRIBUTE_HORIZONTALLY | Rozložit horizontálně |
| DISTRIBUTE_VERTICALLY | Rozložit vertikálně |
