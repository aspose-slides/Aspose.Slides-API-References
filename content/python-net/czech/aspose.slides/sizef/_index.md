## třída SizeF

Ukládá uspořádaný pár čísel s plovoucí řádovou čárkou, typicky šířku a výšku obdélníku. Kompatibilní s .NET `System.Drawing.SizeF`.

Typ SizeF obsahuje následující členy:

## Konstruktory

| Konstruktor | Popis |
| :- | :- |
| [`__init__(self, width=0.0, height=0.0)`](/slides/python-net/cs/aspose.slides/sizef/__init__/#float-float) | Vytvoří velikost se zadanou šířkou a výškou. |

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`width`](/slides/python-net/cs/aspose.slides/sizef/width/) | Vrací vodorovnou složku této velikosti.<br/>            Pouze pro čtení **float**. |
| [`height`](/slides/python-net/cs/aspose.slides/sizef/height/) | Vrací svislou složku této velikosti.<br/>            Pouze pro čtení **float**. |


### Poznámky

Velikosti se porovnávají podle svých složek pomocí `==` a lze je použít jako klíče slovníků nebo jako položky množin.
