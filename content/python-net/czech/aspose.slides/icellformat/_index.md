## ICellFormat třída

Reprezentuje formát buňky tabulky.

Typ ICellFormat vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`fill_format`](/slides/python-net/cs/aspose.slides/icellformat/fill_format/) | Vrací objekt vlastností výplně buňky.<br/>            Pouze pro čtení [`IFillFormat`](/slides/python-net/cs/aspose.slides/ifillformat). |
| [`border_left`](/slides/python-net/cs/aspose.slides/icellformat/border_left/) | Vrací objekt vlastností levého okraje.<br/>            Pouze pro čtení [`ILineFormat`](/slides/python-net/cs/aspose.slides/ilineformat). |
| [`border_top`](/slides/python-net/cs/aspose.slides/icellformat/border_top/) | Vrací objekt vlastností horního okraje.<br/>            Pouze pro čtení [`ILineFormat`](/slides/python-net/cs/aspose.slides/ilineformat). |
| [`border_right`](/slides/python-net/cs/aspose.slides/icellformat/border_right/) | Vrací objekt vlastností pravého okraje.<br/>            Pouze pro čtení [`ILineFormat`](/slides/python-net/cs/aspose.slides/ilineformat). |
| [`border_bottom`](/slides/python-net/cs/aspose.slides/icellformat/border_bottom/) | Vrací objekt vlastností spodního okraje.<br/>            Pouze pro čtení [`ILineFormat`](/slides/python-net/cs/aspose.slides/ilineformat). |
| [`border_diagonal_down`](/slides/python-net/cs/aspose.slides/icellformat/border_diagonal_down/) | Vrací objekt vlastností úhlopříčky z levého horního do pravého dolního rohu.<br/>            Pouze pro čtení [`ILineFormat`](/slides/python-net/cs/aspose.slides/ilineformat). |
| [`border_diagonal_up`](/slides/python-net/cs/aspose.slides/icellformat/border_diagonal_up/) | Vrací objekt vlastností úhlopříčky ze spodního levého do horního pravého rohu.<br/>            Pouze pro čtení [`ILineFormat`](/slides/python-net/cs/aspose.slides/ilineformat). |
| [`transparency`](/slides/python-net/cs/aspose.slides/icellformat/transparency/) | Získává nebo nastavuje průhlednost barvy výplně.<br/>            Čtení/zápis **float**. |
