## IColorFormat třída

Představuje barvu použitou v prezentaci.

Typ IColorFormat obsahuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`color_type`](/slides/python-net/cs/aspose.slides/icolorformat/color_type/) | Vrací nebo nastavuje metodu definice barvy.<br/>            Čtení/zápis [`ColorType`](/slides/python-net/cs/aspose.slides/colortype). |
| [`color`](/slides/python-net/cs/aspose.slides/icolorformat/color/) | Vrací výslednou barvu (s aplikovanými všemi transformacemi barvy).<br/>            Nastaví RGB barvy a smaže všechny transformace barvy.<br/>            Čtení/zápis [`Color`](/slides/python-net/cs/aspose.slides/color). |
| [`preset_color`](/slides/python-net/cs/aspose.slides/icolorformat/preset_color/) | Vrací nebo nastavuje předvolbu barvy.<br/>            Čtení/zápis [`PresetColor`](/slides/python-net/cs/aspose.slides/presetcolor). |
| [`system_color`](/slides/python-net/cs/aspose.slides/icolorformat/system_color/) | Vrací nebo nastavuje barvu určenou systémovou tabulkou barev.<br/>            Čtení/zápis [`SystemColor`](/slides/python-net/cs/aspose.slides/systemcolor). |
| [`scheme_color`](/slides/python-net/cs/aspose.slides/icolorformat/scheme_color/) | Vrací nebo nastavuje barvu určenou schématem barev.<br/>            Čtení/zápis [`SchemeColor`](/slides/python-net/cs/aspose.slides/schemecolor). |
| [`r`](/slides/python-net/cs/aspose.slides/icolorformat/r/) | Vrací nebo nastavuje červenou složku barvy. Všechny transformace barvy jsou ignorovány.<br/>            Čtení/zápis **int**. |
| [`g`](/slides/python-net/cs/aspose.slides/icolorformat/g/) | Vrací nebo nastavuje zelenou složku barvy. Všechny transformace barvy jsou ignorovány.<br/>            Čtení/zápis **int**. |
| [`b`](/slides/python-net/cs/aspose.slides/icolorformat/b/) | Vrací nebo nastavuje modrou složku barvy. Všechny transformace barvy jsou ignorovány.<br/>            Čtení/zápis **int**. |
| [`float_r`](/slides/python-net/cs/aspose.slides/icolorformat/float_r/) | Vrací nebo nastavuje červenou složku barvy. Všechny transformace barvy jsou ignorovány.<br/>            Čtení/zápis **float**. |
| [`float_g`](/slides/python-net/cs/aspose.slides/icolorformat/float_g/) | Vrací nebo nastavuje zelenou složku barvy. Všechny transformace barvy jsou ignorovány.<br/>            Čtení/zápis **float**. |
| [`float_b`](/slides/python-net/cs/aspose.slides/icolorformat/float_b/) | Vrací nebo nastavuje modrou složku barvy. Všechny transformace barvy jsou ignorovány.<br/>            Čtení/zápis **float**. |
| [`hue`](/slides/python-net/cs/aspose.slides/icolorformat/hue/) | Vrací nebo nastavuje složku odstínu barvy v HSL reprezentaci.<br/>            Všechny transformace barvy jsou ignorovány.<br/>            Čtení/zápis **float**. |
| [`saturation`](/slides/python-net/cs/aspose.slides/icolorformat/saturation/) | Vrací nebo nastavuje složku sytosti barvy v HSL reprezentaci.<br/>            Všechny transformace barvy jsou ignorovány.<br/>            Čtení/zápis **float**. |
| [`luminance`](/slides/python-net/cs/aspose.slides/icolorformat/luminance/) | Vrací nebo nastavuje složku jasu barvy v HSL reprezentaci.<br/>            Všechny transformace barvy jsou ignorovány.<br/>            Čtení/zápis **float**. |
| [`color_transform`](/slides/python-net/cs/aspose.slides/icolorformat/color_transform/) | Vrací kolekci transformací barvy aplikovaných na barvu.<br/>            Pouze pro čtení [`IColorOperationCollection`](/slides/python-net/cs/aspose.slides/icoloroperationcollection). |
