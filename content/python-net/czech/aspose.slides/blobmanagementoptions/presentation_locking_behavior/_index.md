## presentation_locking_behavior vlastnost
Tato vlastnost určuje, zda může být instance třídy Presentation vlastníkem zdroje – souboru nebo proudu během životnosti instance. Pokud je instance vlastníkem, uzamkne zdroj. To pomáhá zlepšit spotřebu paměti a výkon při práci s BLOBy, ale zdroj (proud nebo soubor) nelze během životnosti instance Presentation měnit.
