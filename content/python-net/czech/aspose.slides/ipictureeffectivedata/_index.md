## IPictureEffectiveData třída

Neměnný objekt, který obsahuje efektivní vlastnosti obrázku.

Typ IPictureEffectiveData poskytuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`image`](/slides/python-net/cs/aspose.slides/ipictureeffectivedata/image/) | Vrací vložený obrázek.<br/>            Pouze pro čtení [`IPPImage`](/slides/python-net/cs/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/cs/aspose.slides/ipictureeffectivedata/link_path_long/) | Vrací URL propojeného obrázku.<br/>            Pouze pro čtení **str**. |
| [`image_transform`](/slides/python-net/cs/aspose.slides/ipictureeffectivedata/image_transform/) | Vrací kolekci efektů transformace obrázku.<br/>            Pouze pro čtení [`IImageTransformOCollectionEffectiveData`](/slides/python-net/cs/aspose.slides.effects/iimagetransformocollectioneffectivedata). |


### Poznámky

Toto rozhraní se používá jako součást [`IPictureFillFormatEffectiveData`](/slides/python-net/cs/aspose.slides/ipicturefillformateffectivedata) a [`IBulletFormatEffectiveData`](/slides/python-net/cs/aspose.slides/ibulletformateffectivedata).
