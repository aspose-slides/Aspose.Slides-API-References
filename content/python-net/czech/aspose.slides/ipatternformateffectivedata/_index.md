## IPatternFormatEffectiveData třída

Neměnný objekt, který obsahuje efektivní vlastnosti výplně vzoru.

Typ IPatternFormatEffectiveData obsahuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`pattern_style`](/slides/python-net/cs/aspose.slides/ipatternformateffectivedata/pattern_style/) | Vrací styl vzoru.<br/>            Pouze pro čtení [`PatternStyle`](/slides/python-net/cs/aspose.slides/patternstyle). |
| [`fore_color`](/slides/python-net/cs/aspose.slides/ipatternformateffectivedata/fore_color/) | Vrací barvu popředí vzoru.<br/>            Pouze pro čtení [`Color`](/slides/python-net/cs/aspose.slides/color). |
| [`back_color`](/slides/python-net/cs/aspose.slides/ipatternformateffectivedata/back_color/) | Vrací barvu pozadí vzoru.<br/>            Pouze pro čtení [`Color`](/slides/python-net/cs/aspose.slides/color). |

## Metody

| Metoda | Popis |
| :- | :- |
| [`get_tile_i_image(self, background, foreground)`](/slides/python-net/cs/aspose.slides/ipatternformateffectivedata/get_tile_i_image/#asposeslidescolor-asposeslidescolor) | Vytvoří obraz dlaždice pro výplň vzoru se specifikovanými barvami. |
