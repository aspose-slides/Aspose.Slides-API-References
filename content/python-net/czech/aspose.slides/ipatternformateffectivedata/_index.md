## IPatternFormatEffectiveData třída

Neměnný objekt, který obsahuje efektivní vlastnosti vyplnění vzoru.

Typ IPatternFormatEffectiveData vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`pattern_style`](/slides/python-net/cs/aspose.slides/ipatternformateffectivedata/pattern_style/) | Vrací styl vzoru.<br/>            Pouze ke čtení [`PatternStyle`](/slides/python-net/cs/aspose.slides/patternstyle). |
| [`fore_color`](/slides/python-net/cs/aspose.slides/ipatternformateffectivedata/fore_color/) | Vrací barvu popředí vzoru.<br/>            Pouze ke čtení **aspose.slides.Color**. |
| [`back_color`](/slides/python-net/cs/aspose.slides/ipatternformateffectivedata/back_color/) | Vrací barvu pozadí vzoru.<br/>            Pouze ke čtení **aspose.slides.Color**. |

## Metody

| Metoda | Popis |
| :- | :- |
| [`get_tile_i_image(self, background, foreground)`](/slides/python-net/cs/aspose.slides/ipatternformateffectivedata/get_tile_i_image/#asposepydrawingcolor-asposepydrawingcolor) | Vytvoří dlaždicový obrázek pro vyplnění vzoru se zadanými barvami. |
