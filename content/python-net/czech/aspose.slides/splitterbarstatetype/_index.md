## SplitterBarStateType výčtový typ

Specifikuje stav, ve kterém by měl být zobrazen splitter bar. Splitter bar odděluje primární a
            sekundární oblast v rámci zobrazovací plochy.

Typ SplitterBarStateType vystavuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| MINIMIZED | Primární oblast zabírá nejmenší část zobrazovací oblasti povolenou aplikací. |
| RESTORED | Primární oblast má konkrétní mezilehlou velikost. |
| MAXIMIZED | Primární oblast zabírá největší část zobrazovací oblasti povolenou aplikací. |
