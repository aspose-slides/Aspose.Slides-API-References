## TextAutofitType výčet

Reprezentuje režim automatického přizpůsobení textu.

Typ TextAutofitType obsahuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| NOT_DEFINED | Není definováno. |
| NONE | Žádné automatické přizpůsobení. |
| NORMAL | Normální automatické přizpůsobení. Velikost písma a řádkování budou zmenšeny, aby se vešly do tvaru. |
| SHAPE | Automatické přizpůsobení tvaru. Velikost tvaru bude změněna, aby se vešel text. |
