## IParagraph třída

Představuje odstavec textu.

Typ IParagraph obsahuje následující členy:

## Vlastnosti

| Property | Description |
| :- | :- |
| [`portions`](/slides/python-net/cs/aspose.slides/iparagraph/portions/) | Vrací kolekci částí textu.<br/>            Pouze pro čtení [`IPortionCollection`](/slides/python-net/cs/aspose.slides/iportioncollection). |
| [`paragraph_format`](/slides/python-net/cs/aspose.slides/iparagraph/paragraph_format/) | Vrací objekt formátování pro tento odstavec.<br/>            Pouze pro čtení [`IParagraphFormat`](/slides/python-net/cs/aspose.slides/iparagraphformat). |
| [`text`](/slides/python-net/cs/aspose.slides/iparagraph/text/) | Získává nebo nastavuje prostý text odstavce.<br/>            Čtení a zápis **str**. |
| [`end_paragraph_portion_format`](/slides/python-net/cs/aspose.slides/iparagraph/end_paragraph_portion_format/) | Určuje vlastnosti části, které mají být použity, pokud je po poslední <br/>            vložena další část. |
| [`slide`](/slides/python-net/cs/aspose.slides/iparagraph/slide/) |  |
| [`presentation`](/slides/python-net/cs/aspose.slides/iparagraph/presentation/) |  |
