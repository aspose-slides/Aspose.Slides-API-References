## IParagraph třída

Reprezentuje odstavec textu.

Typ IParagraph poskytuje následující členy:

## Vlastnosti

| Property | Description |
| :- | :- |
| [`portions`](/slides/python-net/cs/aspose.slides/iparagraph/portions/) | Vrací kolekci částí textu.<br/>            Jen pro čtení [`IPortionCollection`](/slides/python-net/cs/aspose.slides/iportioncollection). |
| [`paragraph_format`](/slides/python-net/cs/aspose.slides/iparagraph/paragraph_format/) | Vrací objekt formátování pro tento odstavec.<br/>            Jen pro čtení [`IParagraphFormat`](/slides/python-net/cs/aspose.slides/iparagraphformat). |
| [`text`](/slides/python-net/cs/aspose.slides/iparagraph/text/) | Získá nebo nastaví prostý text odstavce.<br/>            Čtení/zápis **str**. |
| [`end_paragraph_portion_format`](/slides/python-net/cs/aspose.slides/iparagraph/end_paragraph_portion_format/) | Určuje vlastnosti částí, které se mají použít, pokud je po poslední vložena další část. |
| [`slide`](/slides/python-net/cs/aspose.slides/iparagraph/slide/) |  |
| [`presentation`](/slides/python-net/cs/aspose.slides/iparagraph/presentation/) |  |
