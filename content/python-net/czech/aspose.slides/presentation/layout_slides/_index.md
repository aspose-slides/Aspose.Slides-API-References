## layout_slides vlastnost
Vrací seznam všech rozložení snímků, které jsou v prezentaci definovány.
Pouze ke čtení [`IGlobalLayoutSlideCollection`](/slides/python-net/cs/aspose.slides/igloballayoutslidecollection).


### Poznámky

K alternativnímu API pro přidávání/vkládání/odstraňování/klonování rozložení snímků můžete přistupovat pomocí vlastnosti IMasterSlide.LayoutSlides.
