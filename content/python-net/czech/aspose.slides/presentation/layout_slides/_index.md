## layout_slides vlastnost
Vrací seznam všech rozložení snímků, které jsou definovány v prezentaci.
            Pouze ke čtení [`IGlobalLayoutSlideCollection`](/slides/python-net/cs/aspose.slides/igloballayoutslidecollection).

### Poznámky

Můžete získat přístup k alternativnímu API pro přidávání/vkládání/odstraňování/klonování rozložení snímků 
            pomocí IMasterSlide.LayoutSlides vlastnost.
