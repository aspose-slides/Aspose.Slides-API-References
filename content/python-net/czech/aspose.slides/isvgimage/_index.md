## ISvgImage třída

Reprezentuje obrázek SVG.

Typ ISvgImage poskytuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`svg_content`](/slides/python-net/cs/aspose.slides/isvgimage/svg_content/) | Vrací obsah SVG.<br/>            Pouze pro čtení **str**. |
| [`svg_data`](/slides/python-net/cs/aspose.slides/isvgimage/svg_data/) | Vrací data SVG.<br/>            Pouze pro čtení **int**[]. |
| [`external_resource_resolver`](/slides/python-net/cs/aspose.slides/isvgimage/external_resource_resolver/) | Vrací rozhraní zpětného volání používané k řešení externích zdrojů během importu dokumentů SVG.<br/>            Pouze pro čtení **IExternalResourceResolver**. |
| [`base_uri`](/slides/python-net/cs/aspose.slides/isvgimage/base_uri/) | Vrací základní URI zadaného SVG. Používá se k řešení relativních odkazů.<br/>            Pouze pro čtení **str**. |

## Metody

| Metoda | Popis |
| :- | :- |
| [`write_as_emf(self, stream)`](/slides/python-net/cs/aspose.slides/isvgimage/write_as_emf/#iorawiobase) | Uloží obrázek SVG jako soubor EMF. |
