## frame property
Vrací nebo nastavuje vlastnosti rámce tvaru.
            Čtení/Zápis [`IShapeFrame`](/slides/python-net/cs/aspose.slides/ishapeframe).

### Poznámky

Hodnota každé vlastnosti vrácené instance IShapeFrame není 
            undefined (není NaN ani NotDefined).
            Hodnota každé vlastnosti přiřazené instance IShapeFrame nesmí být 
            undefined (nesmí být NaN ani NotDefined).
            Můžete nastavit undefined hodnoty pro vlastnosti instance RawFrame.
