## třída Control

Představuje ActiveX ovládací prvek.

Typ Control poskytuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`persistence`](/slides/python-net/cs/aspose.slides/control/persistence/) | Získá metodu používanou k uložení vlastností ActiveX ovládacího prvku.<br/>            Pouze ke čtení [`PersistenceType`](/slides/python-net/cs/aspose.slides/persistencetype). |
| [`name`](/slides/python-net/cs/aspose.slides/control/name/) | Získá nebo nastaví název tohoto ovládacího prvku.<br/>            Čtení/zápis **str**. |
| [`class_id`](/slides/python-net/cs/aspose.slides/control/class_id/) | Získá ID třídy tohoto ovládacího prvku.<br/>            Pouze ke čtení **System.Guid**. |
| [`substitute_picture_format`](/slides/python-net/cs/aspose.slides/control/substitute_picture_format/) | Vrátí objekt vlastností výplně obrazu ovládacího prvku Control.<br/>            Pouze ke čtení [`IPictureFillFormat`](/slides/python-net/cs/aspose.slides/ipicturefillformat). |
| [`frame`](/slides/python-net/cs/aspose.slides/control/frame/) | Získá nebo nastaví rámec ovládacího prvku.<br/>            Čtení/zápis [`IShapeFrame`](/slides/python-net/cs/aspose.slides/ishapeframe). |
| [`properties`](/slides/python-net/cs/aspose.slides/control/properties/) | Vrátí kolekci vlastností ActiveX.<br/>            Poznámka: Aspose.Slides podporuje pouze XML-založené vlastnosti ActiveX. Pokud jsou vlastnosti uloženy v binárním formátu, tato vlastnost vrátí None.<br/>            Pouze ke čtení [`IControlPropertiesCollection`](/slides/python-net/cs/aspose.slides/icontrolpropertiescollection). |
| [`active_x_control_binary`](/slides/python-net/cs/aspose.slides/control/active_x_control_binary/) | Určuje perzistenci ActiveX ovládacího prvku, když je metoda perzistence buď PersistStream, PersistStreamInit nebo PersistStorage. |
