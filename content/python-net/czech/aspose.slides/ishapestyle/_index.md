## IShapeStyle třída

Reprezentuje odkaz na styl tvaru.

Typ IShapeStyle obsahuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`line_color`](/slides/python-net/cs/aspose.slides/ishapestyle/line_color/) | Vrací barvu obrysu tvaru.<br/>            Pouze pro čtení [`IColorFormat`](/slides/python-net/cs/aspose.slides/icolorformat). |
| [`line_style_index`](/slides/python-net/cs/aspose.slides/ishapestyle/line_style_index/) | Vrací nebo nastavuje index sloupce čáry ve stylové matici.<br/>            Čtení/Zápis **int**. |
| [`fill_color`](/slides/python-net/cs/aspose.slides/ishapestyle/fill_color/) | Vrací barvu výplně tvaru.<br/>            Pouze pro čtení [`IColorFormat`](/slides/python-net/cs/aspose.slides/icolorformat). |
| [`fill_style_index`](/slides/python-net/cs/aspose.slides/ishapestyle/fill_style_index/) | Vrací nebo nastavuje index sloupce výplně tvaru ve stylových maticích.<br/>            0 znamená žádná výplň,<br/>            kladná hodnota – index ve výplňových stylech motivu,<br/>            záporná hodnota – index ve stylech pozadí motivu.<br/>            Čtení/Zápis **int**. |
| [`effect_color`](/slides/python-net/cs/aspose.slides/ishapestyle/effect_color/) | Vrací barvu efektu tvaru.<br/>            Pouze pro čtení [`IColorFormat`](/slides/python-net/cs/aspose.slides/icolorformat). |
| [`effect_style_index`](/slides/python-net/cs/aspose.slides/ishapestyle/effect_style_index/) | Vrací nebo nastavuje index sloupce efektu tvaru ve stylové matici.<br/>            Čtení/Zápis **int**. |
| [`font_color`](/slides/python-net/cs/aspose.slides/ishapestyle/font_color/) | Vrací barvu písma tvaru.<br/>            Pouze pro čtení [`IColorFormat`](/slides/python-net/cs/aspose.slides/icolorformat). |
| [`font_collection_index`](/slides/python-net/cs/aspose.slides/ishapestyle/font_collection_index/) | Vrací nebo nastavuje index písma tvaru ve sbírce písem.<br/>            Čtení/Zápis [`FontCollectionIndex`](/slides/python-net/cs/aspose.slides/fontcollectionindex). |
