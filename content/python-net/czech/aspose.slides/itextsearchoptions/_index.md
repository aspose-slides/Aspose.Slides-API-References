## ITextSearchOptions třída

Represents options that can be used to search for text in a Presentation, Slide or TextFrame.

The ITextSearchOptions type exposes the following members:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`case_sensitive`](/slides/python-net/cs/aspose.slides/itextsearchoptions/case_sensitive/) | Nastavte true pro citlivé vyhledávání na rozlišení velkých a malých písmen, false - jinak.<br/>            Číst/zapisovat **bool**. |
| [`whole_words_only`](/slides/python-net/cs/aspose.slides/itextsearchoptions/whole_words_only/) | Nastavte true pro shodu pouze celých slov, false - jinak.<br/>            Číst/zapisovat **bool**. |
| [`include_notes`](/slides/python-net/cs/aspose.slides/itextsearchoptions/include_notes/) | Nastavte `true` pro zahrnutí textu obsaženého v poznámkách snímku <br/>            při provádění operací vyhledávání textu, nahrazování nebo zvýrazňování.<br/>            Výchozí hodnota je `false`. |
