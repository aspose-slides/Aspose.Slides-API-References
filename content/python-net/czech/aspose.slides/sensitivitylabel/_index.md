## SensitivityLabel třída

Represents the sensitivity label from Microsoft Purview Information Protection.

The SensitivityLabel type exposes the following members:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`id`](/slides/python-net/cs/aspose.slides/sensitivitylabel/id/) | Vrací nebo nastavuje identifikátor citlivostní štítku.<br/>            Read/write **str**. |
