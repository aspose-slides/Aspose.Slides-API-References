## IGradientFormat třída

Reprezentuje formát gradientu.

Typ IGradientFormat exponuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`tile_flip`](/slides/python-net/cs/aspose.slides/igradientformat/tile_flip/) | Vrací nebo nastavuje režim převrácení pro gradient.<br/>            Čtení/Zápis [`TileFlip`](/slides/python-net/cs/aspose.slides/tileflip). |
| [`gradient_direction`](/slides/python-net/cs/aspose.slides/igradientformat/gradient_direction/) | Vrací nebo nastavuje styl gradientu.<br/>            Čtení/Zápis [`GradientDirection`](/slides/python-net/cs/aspose.slides/gradientdirection). |
| [`linear_gradient_angle`](/slides/python-net/cs/aspose.slides/igradientformat/linear_gradient_angle/) | Vrací nebo nastavuje úhel gradientu.<br/>            Čtení/Zápis **float**. |
| [`linear_gradient_scaled`](/slides/python-net/cs/aspose.slides/igradientformat/linear_gradient_scaled/) | Určuje, zda je gradient škálován.<br/>            Čtení/Zápis [`NullableBool`](/slides/python-net/cs/aspose.slides/nullablebool). |
| [`gradient_shape`](/slides/python-net/cs/aspose.slides/igradientformat/gradient_shape/) | Vrací nebo nastavuje tvar gradientu.<br/>            Čtení/Zápis [`GradientShape`](/slides/python-net/cs/aspose.slides/gradientshape). |
| [`gradient_stops`](/slides/python-net/cs/aspose.slides/igradientformat/gradient_stops/) | Vrací kolekci zastavení gradientu.<br/>            Pouze pro čtení [`IGradientStopCollection`](/slides/python-net/cs/aspose.slides/igradientstopcollection). |
