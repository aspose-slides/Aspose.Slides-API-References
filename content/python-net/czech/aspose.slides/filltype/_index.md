## FillType výčet

Určuje typ vnitřní výplně různých vizuálních objektů.

Typ FillType poskytuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| NOT_DEFINED | Typ výplně není definován. |
| NO_FILL | Žádná výplň není použita. |
| SOLID | Vyplněno plnou barvou. |
| GRADIENT | Výplň je gradientní. |
| PATTERN | K vyplnění objektu se používá opakující se vzor. |
| PICTURE | K vyplnění objektu se používá jeden obrázek. |
| GROUP | Vizuální objekt dědí vlastnosti výplně ze skupiny. |
