## TextHighlightingOptions třída

Reprezentuje možnosti, které lze použít k zvýraznění textu v textovém rámečku.

Typ TextHighlightingOptions poskytuje následující členy:

## Konstruktory

| Konstruktor | Popis |
| :- | :- |
| [`__init__(self)`](/slides/python-net/cs/aspose.slides/texthighlightingoptions/__init__/#) | Vytvoří nové výchozí možnosti zvýraznění textu. |

| Vlastnost | Popis |
| :- | :- |
| [`case_sensitive`](/slides/python-net/cs/aspose.slides/texthighlightingoptions/case_sensitive/) | Nastavte na true pro použití vyhledávání rozlišujícího velká a malá písmena, false jinak.<br/>            Čtení/zápis **bool**. |
