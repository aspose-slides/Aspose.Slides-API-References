## SlideSizeType enumerace

Reprezentuje předdefinovanou velikost snímku.

Typ SlideSizeType vystavuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| ON_SCREEN | Na obrazovce 4x3 |
| LETTER_PAPER | Letter |
| A4_PAPER | A4 |
| SLIDE_35MM | Snímek 35mm |
| OVERHEAD | Overhead |
| BANNER | Banner |
| CUSTOM | Vlastní velikost |
| LEDGER | Ledger |
| A3_PAPER | A3 |
| B4_ISO_PAPER | B4 ISO |
| B5_ISO_PAPER | B5 ISO |
| B4_JIS_PAPER | B4 JIS |
| B5_JIS_PAPER | B5 JIS |
| HAGAKI_CARD | Hagaki karta |
| ON_SCREEN_16X9 | Na obrazovce 16x9 |
| ON_SCREEN_16X10 | Na obrazovce 16x10 |
| WIDESCREEN | Širokoúhlý |
