## NumberedBulletStyle enumerace

Reprezentuje styl číslovaných odrážek.

Typ NumberedBulletStyle vystavuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| NOT_DEFINED | Není definováno. |
| BULLET_ALPHA_LC_PERIOD | Malá písmena abecedy s tečkou. Příklad: a., b., c., ... |
| BULLET_ALPHA_UC_PERIOD | Velká písmena abecedy s tečkou. Příklad: A., B., C., ... |
| BULLET_ARABIC_PAREN_RIGHT | Arabské číslice s pravou závorkou. Příklad: 1), 2), 3), ... |
| BULLET_ARABIC_PERIOD | Arabské číslice s tečkou. Příklad: 1., 2., 3., ... |
| BULLET_ROMAN_LC_PAREN_BOTH | Malá římská čísla s oběma závorkami. Příklad: (i), (ii), (iii), ... |
| BULLET_ROMAN_LC_PAREN_RIGHT | Malá římská čísla s pravou závorkou. Příklad: i), ii), iii), ... |
| BULLET_ROMAN_LC_PERIOD | Malá římská čísla s tečkou. Příklad: i., ii., iii., ... |
| BULLET_ROMAN_UC_PERIOD | Velká římská čísla s tečkou. Příklad: I., II., III., ... |
| BULLET_ALPHA_LC_PAREN_BOTH | Malá písmena abecedy s oběma závorkami. Příklad: (a), (b), (c), ... |
| BULLET_ALPHA_LC_PAREN_RIGHT | Malá písmena abecedy s pravou závorkou. Příklad: a), b), c), ... |
| BULLET_ALPHA_UC_PAREN_BOTH | Velká písmena abecedy s oběma závorkami. Příklad: (A), (B), (C), ... |
| BULLET_ALPHA_UC_PAREN_RIGHT | Velká písmena abecedy s pravou závorkou. Příklad: A), B), C), ... |
| BULLET_ARABIC_PAREN_BOTH | Arabské číslice s oběma závorkami. Příklad: (1), (2), (3), ... |
| BULLET_ARABIC_PLAIN | Arabské číslice. Příklad: 1, 2, 3, ... |
| BULLET_ROMAN_UC_PAREN_BOTH | Velká římská čísla s oběma závorkami. Příklad: (I), (II), (III), ... |
| BULLET_ROMAN_UC_PAREN_RIGHT | Velká římská čísla s pravou závorkou. Příklad: I), II), III), ... |
| BULLET_SIMP_CHIN_PLAIN | Zjednodušená čínština bez tečky. |
| BULLET_SIMP_CHIN_PERIOD | Zjednodušená čínština s tečkou. |
| BULLET_CIRCLE_NUM_DB_PLAIN | Dvoubytové číslo v kroužku pro hodnoty až do 10, od 11 – arabské číslice. |
| BULLET_CIRCLE_NUM_WD_WHITE_PLAIN | Číslo barevného textu se stejným barevným kruhem kolem něj (Wingdings bílá čísla v kruhu). Od 11 – arabské číslice. |
| BULLET_CIRCLE_NUM_WD_BLACK_PLAIN | Číslo se stínovanou barvou a kulatým pozadím normální barvy textu (Wingdings černá čísla v kruhu). |
| BULLET_TRAD_CHIN_PLAIN | Tradiční čínština bez tečky. |
| BULLET_TRAD_CHIN_PERIOD | Tradiční čínština s tečkou. |
| BULLET_ARABIC_ALPHA_DASH | Arabská písmena s pomlčkou. |
| BULLET_ARABIC_ABJAD_DASH | Arabské abjadové abecedy s pomlčkou. |
| BULLET_HEBREW_ALPHA_DASH | Hebrejská písmena s pomlčkou. |
| BULLET_KANJI_KOREAN_PLAIN | Japonské/korejské číslice bez tečky. |
| BULLET_KANJI_KOREAN_PERIOD | Japonské/korejské číslice s tečkou. |
| BULLET_ARABIC_DB_PLAIN | Dvoubytové arabské číslování (bez interpunkce). |
| BULLET_ARABIC_DB_PERIOD | Dvoubytové arabské číslování s dvojbytovou tečkou. |
| BULLET_THAI_ALPHA_PERIOD | Thajská abeceda s tečkou. |
| BULLET_THAI_ALPHA_PAREN_RIGHT | Thajská abeceda s pravou závorkou. |
| BULLET_THAI_ALPHA_PAREN_BOTH | Thajská abeceda se dvěma závorkami. |
| BULLET_THAI_NUM_PERIOD | Thajské číselné označení s tečkou. |
| BULLET_THAI_NUM_PAREN_RIGHT | Thajské číslice s pravou závorkou. |
| BULLET_THAI_NUM_PAREN_BOTH | Thajské číslice se dvěma závorkami. |
| BULLET_HINDI_ALPHA_PERIOD | Hindská abeceda s tečkou – samohlásky. |
| BULLET_HINDI_NUM_PERIOD | Hindské číselné označení s tečkou. |
| BULLET_KANJI_SIMP_CHIN_DB_PERIOD | Kanji jednoduchá čínština DBPeriod. |
| BULLET_HINDI_NUM_PAREN_RIGHT | Hindské číslice s pravou závorkou. |
| BULLET_HINDI_ALPHA_1_PERIOD | Hindská abeceda s tečkou – souhlásky. |
