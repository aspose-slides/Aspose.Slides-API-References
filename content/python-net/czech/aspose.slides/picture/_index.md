## Třída Picture

Představuje obrázek v prezentaci.

Typ Picture poskytuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`image`](/slides/python-net/cs/aspose.slides/picture/image/) | Vrací nebo nastavuje vložený obrázek.<br/>            Čtení/zápis [`IPPImage`](/slides/python-net/cs/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/cs/aspose.slides/picture/link_path_long/) | Vrací nebo nastavuje URL propojeného obrázku.<br/>            Čtení/zápis **str**. |
| [`image_transform`](/slides/python-net/cs/aspose.slides/picture/image_transform/) | Vrací kolekci transformací obrázku.<br/>            Pouze pro čtení [`IImageTransformOperationCollection`](/slides/python-net/cs/aspose.slides.effects/iimagetransformoperationcollection). |
| [`presentation`](/slides/python-net/cs/aspose.slides/picture/presentation/) | Vrací prezentaci. <br/>            Pouze pro čtení [`IPresentation`](/slides/python-net/cs/aspose.slides/ipresentation). |
| [`slide`](/slides/python-net/cs/aspose.slides/picture/slide/) | Vrací nadřazený snímek obrázku.<br/>            Pouze pro čtení [`IBaseSlide`](/slides/python-net/cs/aspose.slides/ibaseslide). |
