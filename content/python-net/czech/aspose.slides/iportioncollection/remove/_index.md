## remove(self, item) {#iportion}
Odstraňuje první výskyt konkrétního objektu ze **System.Collections.Generic.ICollection`1**.

### Návratová hodnota
true, pokud byl `item` úspěšně odstraněn ze **System.Collections.Generic.ICollection`1**; jinak false. Tato metoda také vrací false, pokud `item` není v původní **System.Collections.Generic.ICollection`1** nalezen.



```python
def remove(self, item):
    ...
```


| Parametr | Typ | Popis |
| :- | :- | :- |
| item | [`IPortion`](/slides/python-net/cs/aspose.slides/iportion) | Objekt, který má být odstraněn ze **System.Collections.Generic.ICollection`1**. |
