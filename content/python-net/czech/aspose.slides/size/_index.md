## Size třída

Ukládá uspořádaný pár celých čísel, který určuje šířku a výšku. Kompatibilní s .NET `System.Drawing.Size`.

Typ Size obsahuje následující členy:

## Konstruktory

| Konstruktor | Popis |
| :- | :- |
| [`__init__(self, width=0, height=0)`](/slides/python-net/cs/aspose.slides/size/__init__/#int-int) | Vytvoří velikost se zadanou šířkou a výškou. Hodnoty typu float jsou oříznuty na celá čísla. |

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`width`](/slides/python-net/cs/aspose.slides/size/width/) | Vrací horizontální komponentu této velikosti.<br/>            Pouze pro čtení **int**. |
| [`height`](/slides/python-net/cs/aspose.slides/size/height/) | Vrací vertikální komponentu této velikosti.<br/>            Pouze pro čtení **int**. |


### Poznámky

Velikosti se porovnávají podle jejich komponent pomocí `==` a mohou být použity jako klíče slovníků nebo jako členové množin.
