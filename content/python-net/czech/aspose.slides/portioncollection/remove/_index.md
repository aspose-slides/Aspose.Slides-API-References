## remove(self, item) {#iportion}
Odstraní první výskyt konkrétního objektu ze **System.Collections.Generic.ICollection`1**.

### Návratová hodnota

true pokud byl `item` úspěšně odstraněn ze **System.Collections.Generic.ICollection`1**; jinak false. Tato metoda také vrací false, pokud `item` není nalezen v původní **System.Collections.Generic.ICollection`1**.

```python
def remove(self, item):
    ...
```

| :- | :- | :- |
| item | [`IPortion`](/slides/python-net/cs/aspose.slides/iportion) | Objekt, který má být odstraněn ze **System.Collections.Generic.ICollection`1**. |
