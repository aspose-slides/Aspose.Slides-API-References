## TextAlignment enumerace

Representuje různé styly zarovnání textu.

Typ TextAlignment obsahuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| NOT_DEFINED | Výchozí zarovnání. |
| LEFT | Zarovnání vlevo. |
| CENTER | Zarovnání na střed. |
| RIGHT | Zarovnání vpravo. |
| JUSTIFY | Zarovnání do bloku. |
| JUSTIFY_LOW | Nízké Kashida zarovnání. |
| DISTRIBUTED | Rozptýlené zarovnání. |
