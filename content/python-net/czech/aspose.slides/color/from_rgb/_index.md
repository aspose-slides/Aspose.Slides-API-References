## from_rgb(r, g, b) {#int-int-int}
Vytvoří neprůhlednou barvu (alfa je 255) ze zadaných hodnot červené, zelené a modré.

### Vrací

Barva vytvořená ze zadaných hodnot.



```python
@staticmethod
def from_rgb(r, g, b):
    ...
```


| Parametr | Typ | Popis |
| :- | :- | :- |
| r | **int** | Hodnota červené složky. Platné hodnoty jsou od 0 do 255. |
| g | **int** | Hodnota zelené složky. Platné hodnoty jsou od 0 do 255. |
| b | **int** | Hodnota modré složky. Platné hodnoty jsou od 0 do 255. |

### Výjimky

| Výjimka | Popis |
| :- | :- |
