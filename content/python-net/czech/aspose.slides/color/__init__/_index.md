```python
    ...
```


| Parametr | Typ | Popis |
| :- | :- | :- |
| r | **int** | Hodnota červené komponenty. Platné hodnoty jsou 0 až 255. |
| g | **int** | Hodnota zelené komponenty. Platné hodnoty jsou 0 až 255. |
