## CommentAuthor třída

Představuje autora komentářů.

Typ CommentAuthor obsahuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`name`](/slides/python-net/cs/aspose.slides/commentauthor/name/) | Vrací nebo nastavuje jméno autora.<br/>            Čtení/zápis **str**. |
| [`initials`](/slides/python-net/cs/aspose.slides/commentauthor/initials/) | Vrací nebo nastavuje iniciály autora.<br/>            Čtení/zápis **str**. |
| [`comments`](/slides/python-net/cs/aspose.slides/commentauthor/comments/) | Vrací kolekci komentářů vytvořených tímto autorem.<br/>            Pouze pro čtení [`ICommentCollection`](/slides/python-net/cs/aspose.slides/icommentcollection). |

## Metody

| Metoda | Popis |
| :- | :- |
| [`remove(self)`](/slides/python-net/cs/aspose.slides/commentauthor/remove/#) | Odstraňuje autora z nadřazené kolekce. |
