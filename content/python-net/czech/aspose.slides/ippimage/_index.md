## IPPImage třída

Representuje obrázek v prezentaci.

Typ IPPImage vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`binary_data`](/slides/python-net/cs/aspose.slides/ippimage/binary_data/) | Vrací kopii dat obrázku.<br/>            Pouze pro čtení **int**[]. |
| [`image`](/slides/python-net/cs/aspose.slides/ippimage/image/) | Vrací kopii obrázku.<br/>            Pouze pro čtení [`IPPImage.image`](/slides/python-net/cs/aspose.slides/ippimage/image). |
| [`svg_image`](/slides/python-net/cs/aspose.slides/ippimage/svg_image/) | Vrací nebo nastavuje objekt ISvgImage [`ISvgImage`](/slides/python-net/cs/aspose.slides/isvgimage) |
| [`content_type`](/slides/python-net/cs/aspose.slides/ippimage/content_type/) | Vrací MIME typ obrázku, zakódovaný v [`IPPImage.binary_data`](/slides/python-net/cs/aspose.slides/ippimage/binary_data).<br/>            Pouze pro čtení **str**. |
| [`width`](/slides/python-net/cs/aspose.slides/ippimage/width/) | Vrací šířku obrázku.<br/>            Pouze pro čtení **int**. |
| [`height`](/slides/python-net/cs/aspose.slides/ippimage/height/) | Vrací výšku obrázku.<br/>            Pouze pro čtení **int**. |
| [`x`](/slides/python-net/cs/aspose.slides/ippimage/x/) | Vrací X-odchylku obrázku.<br/>            Pouze pro čtení **int**. |
| [`y`](/slides/python-net/cs/aspose.slides/ippimage/y/) | Vrací Y-odchylku obrázku.<br/>            Pouze pro čtení **int**. |
