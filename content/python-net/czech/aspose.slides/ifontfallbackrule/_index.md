## Třída IFontFallBackRule

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`range_start_index`](/slides/python-net/cs/aspose.slides/ifontfallbackrule/range_start_index/) | Získá první index kontinuálního unicode rozsahu. |
| [`range_end_index`](/slides/python-net/cs/aspose.slides/ifontfallbackrule/range_end_index/) | Získá poslední index kontinuálního unicode rozsahu. |
| [`count`](/slides/python-net/cs/aspose.slides/ifontfallbackrule/count/) | Získá počet písem skutečně definovaných pro rozsah. |
