## IShapeFrame třída

Reprezentuje vlastnosti rámce tvaru.

Typ IShapeFrame obsahuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`x`](/slides/python-net/cs/aspose.slides/ishapeframe/x/) | Vrací souřadnici X levého horního rohu rámce.<br/>            Pouze pro čtení **float**. |
| [`y`](/slides/python-net/cs/aspose.slides/ishapeframe/y/) | Vrací souřadnici Y levého horního rohu rámce.<br/>            Pouze pro čtení **float**. |
| [`width`](/slides/python-net/cs/aspose.slides/ishapeframe/width/) | Vrací šířku rámce.<br/>            Pouze pro čtení **float**. |
| [`height`](/slides/python-net/cs/aspose.slides/ishapeframe/height/) | Vrací výšku rámce.<br/>            Pouze pro čtení **float**. |
| [`rotation`](/slides/python-net/cs/aspose.slides/ishapeframe/rotation/) | Vrací počet stupňů, o které je rámec natočen kolem osy z.<br/>            Kladná hodnota značí otáčení po směru hodinových ručiček; záporná hodnota<br/>            značí otáčení proti směru hodinových ručiček.<br/>            Pouze pro čtení **float**. |
| [`center_x`](/slides/python-net/cs/aspose.slides/ishapeframe/center_x/) | Vrací souřadnici X středu rámce.<br/>            Pouze pro čtení **float**. |
| [`center_y`](/slides/python-net/cs/aspose.slides/ishapeframe/center_y/) | Vrací souřadnici Y středu rámce.<br/>            Pouze pro čtení **float**. |
| [`flip_h`](/slides/python-net/cs/aspose.slides/ishapeframe/flip_h/) | Určuje, zda je rámec přeložen vodorovně.<br/>            Pouze pro čtení [`NullableBool`](/slides/python-net/cs/aspose.slides/nullablebool). |
| [`flip_v`](/slides/python-net/cs/aspose.slides/ishapeframe/flip_v/) | Určuje, zda je rámec přeložen svisle.<br/>            Pouze pro čtení [`NullableBool`](/slides/python-net/cs/aspose.slides/nullablebool). |
| [`rectangle`](/slides/python-net/cs/aspose.slides/ishapeframe/rectangle/) | Vrací souřadnice rámce.<br/>            Pouze pro čtení [`RectangleF`](/slides/python-net/cs/aspose.slides/rectanglef). |
