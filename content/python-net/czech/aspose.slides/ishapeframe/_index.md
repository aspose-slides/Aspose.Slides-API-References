## IShapeFrame třída

Představuje vlastnosti rámce tvaru.

Typ IShapeFrame vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`x`](/slides/python-net/cs/aspose.slides/ishapeframe/x/) | Vrací X-souřadnici levého horního rohu rámce.<br/>            Pouze ke čtení **float**. |
| [`y`](/slides/python-net/cs/aspose.slides/ishapeframe/y/) | Vrací Y-souřadnici levého horního rohu rámce.<br/>            Pouze ke čtení **float**. |
| [`width`](/slides/python-net/cs/aspose.slides/ishapeframe/width/) | Vrací šířku rámce.<br/>            Pouze ke čtení **float**. |
| [`height`](/slides/python-net/cs/aspose.slides/ishapeframe/height/) | Vrací výšku rámce.<br/>            Pouze ke čtení **float**. |
| [`rotation`](/slides/python-net/cs/aspose.slides/ishapeframe/rotation/) | Vrací počet stupňů, o které je rámec natočen kolem osy z.<br/>            Kladná hodnota značí otočení po směru hodinových ručiček; záporná hodnota<br/>            značí otočení proti směru hodinových ručiček.<br/>            Pouze ke čtení **float**. |
| [`center_x`](/slides/python-net/cs/aspose.slides/ishapeframe/center_x/) | Vrací X-souřadnici středu rámce.<br/>            Pouze ke čtení **float**. |
| [`center_y`](/slides/python-net/cs/aspose.slides/ishapeframe/center_y/) | Vrací Y-souřadnici středu rámce.<br/>            Pouze ke čtení **float**. |
| [`flip_h`](/slides/python-net/cs/aspose.slides/ishapeframe/flip_h/) | Určuje, zda je rámec horizontálně převrácen.<br/>            Pouze ke čtení [`NullableBool`](/slides/python-net/cs/aspose.slides/nullablebool). |
| [`flip_v`](/slides/python-net/cs/aspose.slides/ishapeframe/flip_v/) | Určuje, zda je rámec vertikálně převrácen.<br/>            Pouze ke čtení [`NullableBool`](/slides/python-net/cs/aspose.slides/nullablebool). |
| [`rectangle`](/slides/python-net/cs/aspose.slides/ishapeframe/rectangle/) | Vrací souřadnice rámce.<br/>            Pouze ke čtení **aspose.slides.RectangleF**. |
