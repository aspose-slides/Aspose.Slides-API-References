## ImageFormat výčet

Představuje formát souboru obrázku.

Typ ImageFormat poskytuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| MEMORY_BMP | Reprezentuje formát bitmapy v paměti. |
| BMP | Reprezentuje formát obrázku bitmap (BMP). |
| EMF | Reprezentuje formát vylepšeného metafile (EMF) obrázku. |
| WMF | Reprezentuje formát Windows metafile (WMF) obrázku. |
| GIF | Reprezentuje formát Graphics Interchange Format (GIF) obrázku. |
| JPEG | Reprezentuje formát Joint Photographic Experts Group (JPEG) obrázku. |
| PNG | Reprezentuje formát W3C Portable Network Graphics (PNG) obrázku. |
| TIFF | Reprezentuje formát Tagged Image File Format (TIFF) obrázku. |
| EXIF | Reprezentuje formát Exchangeable Image File (Exif). |
| ICON | Reprezentuje formát ikony Windows. |
