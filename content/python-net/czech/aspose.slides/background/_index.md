## Background třída

Představuje pozadí snímku.

**Dědičnost:**[`Background`](/slides/python-net/cs/aspose.slides/background) → [`PVIObject`](/slides/python-net/cs/aspose.slides/pviobject)

Typ Background poskytuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`type`](/slides/python-net/cs/aspose.slides/background/type/) | Vrací typ výplně pozadí.<br/>            Čtení/zápis [`BackgroundType`](/slides/python-net/cs/aspose.slides/backgroundtype). |
| [`fill_format`](/slides/python-net/cs/aspose.slides/background/fill_format/) | Vrací FillFormat pro výplň BackgroundType.OwnBackground.<br/>            Pouze pro čtení [`IFillFormat`](/slides/python-net/cs/aspose.slides/ifillformat). |
| [`effect_format`](/slides/python-net/cs/aspose.slides/background/effect_format/) | Vrací EffectFormat pro výplň BackgroundType.OwnBackground.<br/>            Pouze pro čtení [`IEffectFormat`](/slides/python-net/cs/aspose.slides/ieffectformat). |
| [`style_color`](/slides/python-net/cs/aspose.slides/background/style_color/) | Vrací ColorFormat pro výplň BackgroundType.Themed.<br/>            Pouze pro čtení [`IColorFormat`](/slides/python-net/cs/aspose.slides/icolorformat). |
| [`style_index`](/slides/python-net/cs/aspose.slides/background/style_index/) | Vrací index výplně BackgroundType.Themed v kolekci motivů pozadí.<br/>            0 znamená žádnou výplň.<br/>            1..999 - index.<br/>            Čtení/zápis **int**. |
| [`slide`](/slides/python-net/cs/aspose.slides/background/slide/) | Vrací rodičovský snímek tvaru.<br/>            Pouze pro čtení [`IBaseSlide`](/slides/python-net/cs/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/cs/aspose.slides/background/presentation/) | Vrací rodičovskou prezentaci snímku.<br/>            Pouze pro čtení [`IPresentation`](/slides/python-net/cs/aspose.slides/ipresentation). |
