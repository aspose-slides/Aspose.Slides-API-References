## ShapeElementFillSource enumeration

Reprezentuje, jak by měl být tvarový prvek vyplněn.

Typ ShapeElementFillSource poskytuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| NO_FILL | Nevyplňovat primitivum. |
| SHAPE | Použít výplň tvaru. |
| LIGHTEN | Použít zesvětlenou výplň tvaru. |
| LIGHTEN_LESS | Použít méně zesvětlenou výplň tvaru. |
| DARKEN | Použít ztmavenou výplň tvaru. |
| DARKEN_LESS | Použít méně ztmavenou výplň tvaru. |
