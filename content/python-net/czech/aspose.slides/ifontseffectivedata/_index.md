## IFontsEffectiveData třída

Neměnný objekt, který obsahuje efektivně nastavená písma.

Typ IFontsEffectiveData poskytuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`latin_font`](/slides/python-net/cs/aspose.slides/ifontseffectivedata/latin_font/) | Vrací latinské písmo.<br/>            Pouze pro čtení [`IFontData`](/slides/python-net/cs/aspose.slides/ifontdata). |
| [`east_asian_font`](/slides/python-net/cs/aspose.slides/ifontseffectivedata/east_asian_font/) | Vrací východoasijské písmo.<br/>            Pouze pro čtení [`IFontData`](/slides/python-net/cs/aspose.slides/ifontdata). |
| [`complex_script_font`](/slides/python-net/cs/aspose.slides/ifontseffectivedata/complex_script_font/) | Vrací písmo pro složité skripty.<br/>            Pouze pro čtení [`IFontData`](/slides/python-net/cs/aspose.slides/ifontdata). |
