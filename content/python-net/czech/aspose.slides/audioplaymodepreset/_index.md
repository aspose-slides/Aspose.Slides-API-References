## AudioPlayModePreset výčet

Konstanty, které určují, jak se zvuk přehrává.

Typ AudioPlayModePreset vystavuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| MIXED |  |
| AUTO | Přehraje se automaticky. |
| ON_CLICK | Přehraje se pouze po kliknutí na ikonu. |
| ALL_SLIDES | Přehraje se na všech snímcích. <br/>            Použijte místo toho vlastnost [`IAudioFrame.play_across_slides`](/slides/python-net/cs/aspose.slides/iaudioframe/play_across_slides).<br/>            Tento prvek je zastaralý od PowerPoint 2013. |
| IN_CLICK_SEQUENCE | Přehraje se automaticky po kliknutí. |
