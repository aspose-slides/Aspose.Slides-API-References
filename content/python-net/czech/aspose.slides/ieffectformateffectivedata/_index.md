## IEffectFormatEffectiveData třída

Neměnný objekt, který obsahuje účinné vlastnosti formátování efektů.

Typ IEffectFormatEffectiveData obsahuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`is_no_effects`](/slides/python-net/cs/aspose.slides/ieffectformateffectivedata/is_no_effects/) | Vrací true, pokud jsou všechny efekty zakázány (jako právě vytvořený výchozí objekt EffectFormat).<br/>            Pouze ke čtení **bool**. |
| [`blur_effect`](/slides/python-net/cs/aspose.slides/ieffectformateffectivedata/blur_effect/) | Efekt rozostření.<br/>            Pouze ke čtení [`IBlurEffectiveData`](/slides/python-net/cs/aspose.slides.effects/iblureffectivedata). |
| [`fill_overlay_effect`](/slides/python-net/cs/aspose.slides/ieffectformateffectivedata/fill_overlay_effect/) | Efekt překrytí výplní.<br/>            Pouze ke čtení [`IFillOverlayEffectiveData`](/slides/python-net/cs/aspose.slides.effects/ifilloverlayeffectivedata). |
| [`glow_effect`](/slides/python-net/cs/aspose.slides/ieffectformateffectivedata/glow_effect/) | Efekt záře.<br/>            Pouze ke čtení [`IGlowEffectiveData`](/slides/python-net/cs/aspose.slides.effects/igloweffectivedata). |
| [`inner_shadow_effect`](/slides/python-net/cs/aspose.slides/ieffectformateffectivedata/inner_shadow_effect/) | Vnitřní stín.<br/>            Pouze ke čtení [`IInnerShadowEffectiveData`](/slides/python-net/cs/aspose.slides.effects/iinnershadoweffectivedata). |
| [`outer_shadow_effect`](/slides/python-net/cs/aspose.slides/ieffectformateffectivedata/outer_shadow_effect/) | Vnější stín.<br/>            Pouze ke čtení [`IOuterShadowEffectiveData`](/slides/python-net/cs/aspose.slides.effects/ioutershadoweffectivedata). |
| [`preset_shadow_effect`](/slides/python-net/cs/aspose.slides/ieffectformateffectivedata/preset_shadow_effect/) | Přednastavený stín.<br/>            Pouze ke čtení [`IPresetShadowEffectiveData`](/slides/python-net/cs/aspose.slides.effects/ipresetshadoweffectivedata). |
| [`reflection_effect`](/slides/python-net/cs/aspose.slides/ieffectformateffectivedata/reflection_effect/) | Reflexe. <br/>            Pouze ke čtení [`IReflectionEffectiveData`](/slides/python-net/cs/aspose.slides.effects/ireflectioneffectivedata). |
| [`soft_edge_effect`](/slides/python-net/cs/aspose.slides/ieffectformateffectivedata/soft_edge_effect/) | Měkký okraj.<br/>            Pouze ke čtení [`ISoftEdgeEffectiveData`](/slides/python-net/cs/aspose.slides.effects/isoftedgeeffectivedata). |

Toto rozhraní se používá spolu s rozhraním [`IEffectFormat`](/slides/python-net/cs/aspose.slides/ieffectformat) k vrácení účinných hodnot formátování s aplikovaným děděním.
