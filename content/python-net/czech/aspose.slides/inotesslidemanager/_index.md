## INotesSlideManager třída

Správce snímků poznámek.

Typ INotesSlideManager vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`notes_slide`](/slides/python-net/cs/aspose.slides/inotesslidemanager/notes_slide/) | Vrací snímek poznámek pro aktuální snímek. Vrací None, pokud snímek nemá snímek poznámek.<br/>            Pouze pro čtení [`INotesSlide`](/slides/python-net/cs/aspose.slides/inotesslide). |

## Metody

| Metoda | Popis |
| :- | :- |
| [`add_notes_slide(self)`](/slides/python-net/cs/aspose.slides/inotesslidemanager/add_notes_slide/#) | Vrací snímek poznámek pro aktuální snímek, vytvoří jej, pokud neexistuje. |
| [`remove_notes_slide(self)`](/slides/python-net/cs/aspose.slides/inotesslidemanager/remove_notes_slide/#) | Odstraní snímek poznámek aktuálního snímku. |
