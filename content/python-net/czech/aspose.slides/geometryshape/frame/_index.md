## vlastnost rámce
Vrací nebo nastavuje vlastnosti rámce tvaru.
            Čtení/zápis [`IShapeFrame`](/slides/python-net/cs/aspose.slides/ishapeframe).


### Poznámky

Hodnota každé vlastnosti vráceného IShapeFrame instance není 
            undefined (není NaN nebo NotDefined).
            Hodnota každé vlastnosti přiřazeného IShapeFrame instance musí být 
            undefined (nesmí být NaN nebo NotDefined).
            Můžete nastavit undefined hodnoty pro vlastnosti RawFrame instance.
