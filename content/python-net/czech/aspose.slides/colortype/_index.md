## Výčet ColorType

Representuje různé barevné režimy.

Typ ColorType obsahuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| NOT_DEFINED | Barva není vůbec definována. |
| RGB | Standardní 24bitová RGB barva. |
| RGB_PERCENTAGE | Vysoce definovaná RGB barva. |
| HSL | Vysoce definovaná HSL barva. |
| SCHEME | Barevné schéma. |
| SYSTEM | Systémová barva. |
| PRESET | Přednastavená barva. |
