## TextSearchOptions třída

Reprezentuje možnosti, které lze použít k vyhledávání textu v objektu Presentation, Slide nebo TextFrame.

Typ TextSearchOptions poskytuje následující členy:

## Konstruktory

| Konstruktor | Popis |
| :- | :- |
| [`__init__(self)`](/slides/python-net/cs/aspose.slides/textsearchoptions/__init__/#) | Creates new default text search options. |

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`case_sensitive`](/slides/python-net/cs/aspose.slides/textsearchoptions/case_sensitive/) | Nastavte true pro použití vyhledávání rozlišujícího velikost písmen, false – jinak.<br/>            Čtení/zápis **bool**. |
| [`whole_words_only`](/slides/python-net/cs/aspose.slides/textsearchoptions/whole_words_only/) | Nastavte true pro shodu pouze s celými slovy, false – jinak.<br/>            Čtení/zápis **bool**. |
| [`include_notes`](/slides/python-net/cs/aspose.slides/textsearchoptions/include_notes/) | Nastavte `true` pro zahrnutí textu obsaženého v poznámkách snímku ([`NotesSlide`](/slides/python-net/cs/aspose.slides/notesslide)) <br/>            při provádění operací vyhledávání textu, nahrazování nebo zvýrazňování.<br/>            Výchozí hodnota je `false`. |
