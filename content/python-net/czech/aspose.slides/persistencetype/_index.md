## Enumerace PersistenceType

Určuje metodu používanou k ukládání vlastností ActiveX ovládacího prvku.

Typ PersistenceType obsahuje následující členy:

## Pole

| Field | Description |
| :- | :- |
| NOT_DEFINED | Identifikátor persistance není specifikován. |
| PERSIST_PROPERTY_BAG | Určuje, že ActiveX ovládací prvek je perzistován pomocí perzistence založené na property-bag.<br/>             Perzistence založená na property-bag ukládá ActiveX ovládací prvek pomocí kolekce párů název a hodnota, které určují data perzistovaná ActiveX ovládacím prvkem. |
| PERSIST_STREAM | Určuje, že ActiveX ovládací prvek je perzistován pomocí perzistence založené na proudu<br/>             která nepodporuje inicializaci ActiveX ovládacího prvku do výchozího stavu. |
| PERSIST_STREAM_INIT | Určuje, že ActiveX ovládací prvek je perzistován pomocí perzistence založené na proudu<br/>             která podporuje inicializaci ActiveX ovládacího prvku do výchozího stavu. |
| PERSIST_STORAGE | Určuje, že ActiveX ovládací prvek je perzistován pomocí perzistence založené na úložišti. |
