## get_script_font(self, script) {#str}
Získá název písma přiřazeného konkrétní značce skriptu v motivu prezentace.

### Návratová hodnota

Název písma použitého pro zadaný skript, nebo `None`, pokud skript není definován.



```python
def get_script_font(self, script):
    ...
```


| Parametr | Typ | Popis |
| :- | :- | :- |
| script | **str** | Kód skriptu podle BCP-47 (např. "Latn", "Cyrl", "Jpan") používaný k identifikaci psacího systému. |
