## IFonts třída

Representuje kolekci písem.

Typ IFonts vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`latin_font`](/slides/python-net/cs/aspose.slides/ifonts/latin_font/) | Vrací nebo nastavuje latinské písmo.<br/>Číst/zapisovat [`IFontData`](/slides/python-net/cs/aspose.slides/ifontdata). |
| [`east_asian_font`](/slides/python-net/cs/aspose.slides/ifonts/east_asian_font/) | Vrací nebo nastavuje východoasijské písmo.<br/>Číst/zapisovat [`IFontData`](/slides/python-net/cs/aspose.slides/ifontdata). |
| [`complex_script_font`](/slides/python-net/cs/aspose.slides/ifonts/complex_script_font/) | Vrací nebo nastavuje písmo komplexního skriptu.<br/>Číst/zapisovat [`IFontData`](/slides/python-net/cs/aspose.slides/ifontdata). |

## Metody

| Metoda | Popis |
| :- | :- |
| [`get_script_font_map(self)`](/slides/python-net/cs/aspose.slides/ifonts/get_script_font_map/#) | Vrací seznam všech definic písma skriptu jako páry řetězec-řetězec v prezentaci. |
| [`get_script_font(self, script)`](/slides/python-net/cs/aspose.slides/ifonts/get_script_font/#str) | Získá název písma spojený s konkrétním štítkem skriptu z motivu prezentace. |
| [`set_script_font(self, script, font_name)`](/slides/python-net/cs/aspose.slides/ifonts/set_script_font/#str-str) | Přiřadí název písma konkrétnímu štítku skriptu, který určuje, jak bude text toho skriptu vykreslen v prezentaci. |
| [`remove_script_font(self, script)`](/slides/python-net/cs/aspose.slides/ifonts/remove_script_font/#str) | Odstraní nastavení písma spojené s konkrétním štítkem skriptu z kolekce písem motivu. |
