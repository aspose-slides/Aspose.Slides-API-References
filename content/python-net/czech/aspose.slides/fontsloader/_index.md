## FontsLoader třída

Třída pro načítání vlastních fontů definovaných uživatelem.
            Měla by být použita před vytvořením jakýchkoli objektů prezentace.

Typ FontsLoader vystavuje následující členy:

## Metody

| Metoda | Popis |
| :- | :- |
| [`load_external_fonts(directories)`](/slides/python-net/cs/aspose.slides/fontsloader/load_external_fonts/#liststr) | Přidá další složky pro vyhledávání fontů. |
| [`load_external_font(data)`](/slides/python-net/cs/aspose.slides/fontsloader/load_external_font/#bytes) | Přidá font z binárních dat |
| [`get_font_folders()`](/slides/python-net/cs/aspose.slides/fontsloader/get_font_folders/#) | Získá složky fontů. Vrací složky, které byly přidány pomocí metody LoadExternalFonts, stejně jako systémové složky fontů |
| [`clear_cache()`](/slides/python-net/cs/aspose.slides/fontsloader/clear_cache/#) | Uvolní všechny uživatelem definované vlastní fonty |
