## IAnimationTimeLine třída

Reprezentuje časovou osu animace.

Typ IAnimationTimeLine vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`interactive_sequences`](/slides/python-net/cs/aspose.slides/ianimationtimeline/interactive_sequences/) | Vrací kolekci interaktivních sekvencí.<br/>            Tyto sekvence mohou obsahovat jen efekty pomocí "kliknutí na tvar" s určeným cílovým tvarem.<br/>            Pouze pro čtení [`ISequenceCollection`](/slides/python-net/cs/aspose.slides.animation/isequencecollection). |
| [`main_sequence`](/slides/python-net/cs/aspose.slides/ianimationtimeline/main_sequence/) | Vrací hlavní sekvenci, která může obsahovat jen hlavní kolekci efektů.<br/>            Pouze pro čtení [`ISequence`](/slides/python-net/cs/aspose.slides.animation/isequence). |
| [`text_animation_collection`](/slides/python-net/cs/aspose.slides/ianimationtimeline/text_animation_collection/) | Vrací kolekci textových animací.<br/>            Pouze pro čtení [`ITextAnimationCollection`](/slides/python-net/cs/aspose.slides.animation/itextanimationcollection). |
