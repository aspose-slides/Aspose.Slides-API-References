## PictureFrameLock třída

Určuje, které operace jsou zakázány na nadřazeném PictureFrame.

**Dědičnost:**[`PictureFrameLock`](/slides/python-net/cs/aspose.slides/pictureframelock) → [`BaseShapeLock`](/slides/python-net/cs/aspose.slides/baseshapelock)

Typ PictureFrameLock obsahuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`no_locks`](/slides/python-net/cs/aspose.slides/pictureframelock/no_locks/) | Vrátí true, pokud jsou všechny příznaky zamčení zakázány.<br/>            Pouze pro čtení **bool**. |
| [`grouping_locked`](/slides/python-net/cs/aspose.slides/pictureframelock/grouping_locked/) | Určuje, zda je zakázáno přidávat tento tvar do skupiny.<br/>            Čtení/zápis **bool**. |
| [`select_locked`](/slides/python-net/cs/aspose.slides/pictureframelock/select_locked/) | Určuje, zda je zakázáno vybírat tento tvar.<br/>            Čtení/zápis **bool**. |
| [`rotation_locked`](/slides/python-net/cs/aspose.slides/pictureframelock/rotation_locked/) | Určuje, zda je zakázáno měnit úhel otáčení tohoto tvaru.<br/>            Čtení/zápis **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/cs/aspose.slides/pictureframelock/aspect_ratio_locked/) | Určuje, zda má tvar při změně velikosti zachovat poměr stran.<br/>            Čtení/zápis **bool**. |
| [`position_locked`](/slides/python-net/cs/aspose.slides/pictureframelock/position_locked/) | Určuje, zda je zakázáno přesouvat tento tvar.<br/>            Čtení/zápis **bool**. |
| [`size_locked`](/slides/python-net/cs/aspose.slides/pictureframelock/size_locked/) | Určuje, zda je zakázáno měnit velikost tohoto tvaru.<br/>            Čtení/zápis **bool**. |
| [`edit_points_locked`](/slides/python-net/cs/aspose.slides/pictureframelock/edit_points_locked/) | Určuje, zda je zakázáno přímo měnit obrys tohoto tvaru.<br/>            Čtení/zápis **bool**. |
| [`adjust_handles_locked`](/slides/python-net/cs/aspose.slides/pictureframelock/adjust_handles_locked/) | Určuje, zda je zakázáno měnit hodnoty úprav.<br/>            Čtení/zápis **bool**. |
| [`arrowheads_locked`](/slides/python-net/cs/aspose.slides/pictureframelock/arrowheads_locked/) | Určuje, zda je zakázáno měnit šipky.<br/>            Čtení/zápis **bool**. |
| [`shape_type_locked`](/slides/python-net/cs/aspose.slides/pictureframelock/shape_type_locked/) | Určuje, zda je zakázáno měnit typ tvaru.<br/>            Čtení/zápis **bool**. |
| [`crop_locked`](/slides/python-net/cs/aspose.slides/pictureframelock/crop_locked/) | Určuje, zda je zakázáno ořezávat obrázek.<br/>            Čtení/zápis **bool**. |
