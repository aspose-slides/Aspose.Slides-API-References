## Výčet ShapeAdjustmentType

Určuje různé typy hodnot úprav tvaru.

Typ ShapeAdjustmentType obsahuje následující členy:

## Pole

| Field | Description |
| :- | :- |
| CUSTOM | Vlastní typ (neznámé nastavení) |
| CORNER_SIZE | Řídí velikost rohů. |
| LEFT_UP_CORNER | Řídí levý horní roh. |
| RIGHT_UP_CORNER | Řídí pravý horní roh. |
| UP_CORNERS | Řídí horní rohy. |
| DOWN_CORNERS | Řídí dolní rohy. |
| THICKNESS | Řídí tloušťku objektu. |
| ARROW_TAIL_THICKNESS | Řídí tloušťku konce šipky. |
| ARROWHEAD_LENGTH | Řídí délku špičky šipky. |
| ARROWHEAD_WIDTH | Řídí šířku špičky šipky. |
| RADIUS | Řídí velikost poloměru tvaru nebo jeho části. |
| DEPTH | Řídí hloubku zubů ozubeného kola nebo zkosení. |
| SHAPE_PART_OFFSET | Řídí posunutí jedné části objektu vůči druhé. |
| ANGLE | Řídí úhel objektu nebo jeho části. |
| START_ANGLE | Úvodní úhel pro výsečové a obloukové tvary. |
| END_ANGLE | Koncový úhel pro výsečové a obloukové tvary. |
| START_POINT_X | Řídí vodorovnou (X) pozici počátečního bodu popisku. |
| START_POINT_Y | Řídí svislou (Y) pozici počátečního bodu popisku. |
| CONNECTOR_POINT_1X | Řídí vodorovnou pozici bodu úpravy úhlu popisku. |
| CONNECTOR_POINT_1Y | Řídí svislou pozici bodu úpravy úhlu popisku. |
| CONNECTOR_POINT_2X | Řídí vodorovnou pozici bodu úpravy úhlu popisku. |
| CONNECTOR_POINT_2Y | Řídí svislou pozici bodu úpravy úhlu popisku. |
| CONNECTOR_BEND_POSITION_X | Řídí vodorovnou pozici ohybu v konektoru. |
| CONNECTOR_BEND_POSITION_Y | Řídí svislou pozici ohybu v konektoru. |
| ATTACH_Y | Řídí svislý bod přichycení objektu. |
| ATTACH_X | Řídí vodorovný bod přichycení objektu. |
| CALLOUT_HEIGHT | Řídí výšku popisku. |
| CALLOUT_WIDTH | Řídí šířku popisku. |
| CALLOUT_SIZE | Řídí velikost popisku. |
| CURVATURE | Zakřivení ohnutého, závěsu, zakřivené šipky nebo tvaru. |
| HORIZONTAL_THICKNESS | Řídí vodorovnou tloušťku rohového tvaru. |
| VERTICAL_THICKNESS | Řídí svislou tloušťku rohového tvaru. |
| VERTICAL_SIZE | Řídí svislou velikost tvaru. |
| HORIZONTAL_SIZE | Řídí vodorovnou velikost tvaru. |
| TOP | Řídí horní stranu tvaru. |
