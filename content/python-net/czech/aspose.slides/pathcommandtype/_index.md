## PathCommandType výčet

Reprezentuje grafické příkazy cesty

Typ PathCommandType uvádí následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| CLOSE | Uzavře geometrickou cestu |
| MOVE_TO | Nastaví pozici dalšího bodu geometrické cesty |
| LINE_TO | Přidá čáru do geometrické cesty |
| ARC_TO | Přidá určený oblouk do geometrické cesty. |
| QUAD_BEZIER_TO | Přidá kvadratickou Bézierovu křivku do geometrické cesty |
| CUBIC_BEZIER_TO | Přidá kubickou Bézierovu křivku do geometrické cesty |
