## IViewProperties třída

Vlastnosti zobrazení na úrovni celé prezentace.

Typ IViewProperties vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`last_view`](/slides/python-net/cs/aspose.slides/iviewproperties/last_view/) | Určuje režim zobrazení, který byl použit při posledním uložení dokumentu prezentace.<br/>            Čtení/zápis [`ViewType`](/slides/python-net/cs/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/cs/aspose.slides/iviewproperties/show_comments/) | Určuje, zda se mají zobrazit komentáře k snímku.<br/>            Čtení/zápis [`NullableBool`](/slides/python-net/cs/aspose.slides/nullablebool). |
| [`slide_view_properties`](/slides/python-net/cs/aspose.slides/iviewproperties/slide_view_properties/) | Určuje společné vlastnosti zobrazení související s režimem zobrazení snímku.<br/>            Pouze ke čtení [`ICommonSlideViewProperties`](/slides/python-net/cs/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/cs/aspose.slides/iviewproperties/notes_view_properties/) | Určuje společné vlastnosti zobrazení související s režimem zobrazení poznámek.<br/>            Pouze ke čtení [`ICommonSlideViewProperties`](/slides/python-net/cs/aspose.slides/icommonslideviewproperties). |
| [`normal_view_properties`](/slides/python-net/cs/aspose.slides/iviewproperties/normal_view_properties/) | Představuje vlastnosti normálního zobrazení. Normální zobrazení se skládá z<br/>            tří oblastí obsahu: samotného snímku, boční oblasti obsahu a spodní oblasti obsahu.<br/>            Pouze ke čtení [`INormalViewProperties`](/slides/python-net/cs/aspose.slides/inormalviewproperties). |
| [`grid_spacing`](/slides/python-net/cs/aspose.slides/iviewproperties/grid_spacing/) | Vrací nebo nastavuje rozestup mřížky, který by měl být použit pro mřížku podkládající dokument prezentace, v bodech. <br/>            Čtení/zápis **float**. |
