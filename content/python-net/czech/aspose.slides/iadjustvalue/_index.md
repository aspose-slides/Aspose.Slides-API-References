## IAdjustValue třída

Representuje hodnotu úpravy geometrického tvaru.  
Tyto hodnoty ovlivňují tvar objektu.

Typ IAdjustValue poskytuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`raw_value`](/slides/python-net/cs/aspose.slides/iadjustvalue/raw_value/) | Vrací nebo nastavuje hodnotu úpravy „as is“.<br/>            Pouze pro čtení **int**. |
| [`angle_value`](/slides/python-net/cs/aspose.slides/iadjustvalue/angle_value/) | Vrací nebo nastavuje hodnotu, interpretuje ji jako úhel ve stupních.<br/>            Pouze pro čtení **float**. |
| [`name`](/slides/python-net/cs/aspose.slides/iadjustvalue/name/) | Vrací název této hodnoty úpravy.<br/>            Pouze pro čtení **str**. |
| [`type`](/slides/python-net/cs/aspose.slides/iadjustvalue/type/) | Vrací typ úpravy tvaru.<br/>            Pouze pro čtení [`ShapeAdjustmentType`](/slides/python-net/cs/aspose.slides/shapeadjustmenttype). |
