## compare_to(self, obj) {#any}
Porovnává aktuální instanci s jiným objektem stejného typu.

### Návratová hodnota

32-bitové celé číslo, které udává relativní pořadí srovnávaných objektů. Návratová hodnota má tyto významy:
            
*  < 0 - Tato instance je menší než obj. = 0 - Tato instance je rovna obj. > 0 - Tato instance je větší než obj.

*  < 0 - Tato instance je menší než obj. = 0 - Tato instance je rovna obj. > 0 - Tato instance je větší než obj.

*  < 0 - Tato instance je menší než obj. = 0 - Tato instance je rovna obj. > 0 - Tato instance je větší než obj.
