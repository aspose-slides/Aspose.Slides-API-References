## portion_format vlastnost
Vrací objekt formátování, který obsahuje výslovně nastavené vlastnosti formátování textové části bez použití dědičnosti.
            Pouze ke čtení [`IPortionFormat`](/slides/python-net/cs/aspose.slides/iportionformat).


### Poznámky

Objekt formátování obsahuje parametry formátování definované pouze pro aktuální část, zděděná data nejsou použita.


Chcete-li získat účinné hodnoty včetně zděděných, použijte [`IPortionFormat.get_effective`](/slides/python-net/cs/aspose.slides/iportionformat/get_effective) metodu.
