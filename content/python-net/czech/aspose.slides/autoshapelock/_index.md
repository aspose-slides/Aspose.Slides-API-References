## AutoShapeLock třída

Určuje, které operace jsou na nadřazeném AutoshapeEx zakázány.

**Dědičnost:**[`AutoShapeLock`](/slides/python-net/cs/aspose.slides/autoshapelock) → [`BaseShapeLock`](/slides/python-net/cs/aspose.slides/baseshapelock)

Typ AutoShapeLock vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`no_locks`](/slides/python-net/cs/aspose.slides/autoshapelock/no_locks/) | Vrátí true, pokud jsou všechny zamykací příznaky zakázány.<br/>            Pouze pro čtení **bool**. |
| [`grouping_locked`](/slides/python-net/cs/aspose.slides/autoshapelock/grouping_locked/) | Určuje, zda je přidání tohoto tvaru do skupiny zakázáno.<br/>            Čtení/zápis **bool**. |
| [`select_locked`](/slides/python-net/cs/aspose.slides/autoshapelock/select_locked/) | Určuje, zda je výběr tohoto tvaru zakázán.<br/>            Čtení/zápis **bool**. |
| [`rotate_locked`](/slides/python-net/cs/aspose.slides/autoshapelock/rotate_locked/) | Určuje, zda je změna úhlu otáčení tohoto tvaru zakázána.<br/>            Čtení/zápis **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/cs/aspose.slides/autoshapelock/aspect_ratio_locked/) | Určuje, zda má tvar zachovávat poměr stran při změně velikosti.<br/>            Čtení/zápis **bool**. |
| [`position_locked`](/slides/python-net/cs/aspose.slides/autoshapelock/position_locked/) | Určuje, zda je přesunutí tohoto tvaru zakázáno.<br/>            Čtení/zápis **bool**. |
| [`size_locked`](/slides/python-net/cs/aspose.slides/autoshapelock/size_locked/) | Určuje, zda je změna velikosti tohoto tvaru zakázána.<br/>            Čtení/zápis **bool**. |
| [`edit_points_locked`](/slides/python-net/cs/aspose.slides/autoshapelock/edit_points_locked/) | Určuje, zda je přímá změna obrysu tohoto tvaru zakázána.<br/>            Čtení/zápis **bool**. |
| [`adjust_handles_locked`](/slides/python-net/cs/aspose.slides/autoshapelock/adjust_handles_locked/) | Určuje, zda je změna hodnot úprav zakázána.<br/>            Čtení/zápis **bool**. |
| [`arrowheads_locked`](/slides/python-net/cs/aspose.slides/autoshapelock/arrowheads_locked/) | Určuje, zda je změna šípových konců zakázána.<br/>            Čtení/zápis **bool**. |
| [`shape_type_locked`](/slides/python-net/cs/aspose.slides/autoshapelock/shape_type_locked/) | Určuje, zda je změna typu tvaru zakázána.<br/>            Čtení/zápis **bool**. |
| [`text_locked`](/slides/python-net/cs/aspose.slides/autoshapelock/text_locked/) | Určuje, zda je úprava textu zakázána.<br/>            Čtení/zápis **bool**. |
