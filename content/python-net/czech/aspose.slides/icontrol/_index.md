## IControl třída

Representuje ActiveX ovládací prvek.

Typ IControl poskytuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`name`](/slides/python-net/cs/aspose.slides/icontrol/name/) | Vrací název tohoto ovládacího prvku.<br/>            Read/write **str**. |
| [`class_id`](/slides/python-net/cs/aspose.slides/icontrol/class_id/) | Získává identifikátor třídy tohoto ovládacího prvku.<br/>            Read-only **System.Guid**. |
| [`substitute_picture_format`](/slides/python-net/cs/aspose.slides/icontrol/substitute_picture_format/) | Vrací objekt vlastností výplně obrázku ControlEx.<br/>            Read-only [`IPictureFillFormat`](/slides/python-net/cs/aspose.slides/ipicturefillformat). |
| [`frame`](/slides/python-net/cs/aspose.slides/icontrol/frame/) | Vrací nebo nastavuje rámeček ovládacího prvku.<br/>            Read/write [`IShapeFrame`](/slides/python-net/cs/aspose.slides/ishapeframe). |
| [`properties`](/slides/python-net/cs/aspose.slides/icontrol/properties/) | Vrací kolekci vlastností ActiveX.<br/>            Read-only [`IControlPropertiesCollection`](/slides/python-net/cs/aspose.slides/icontrolpropertiescollection). |
| [`persistence`](/slides/python-net/cs/aspose.slides/icontrol/persistence/) | Získává metodu používanou pro uložení vlastností ActiveX ovládacího prvku.<br/>            Read only [`PersistenceType`](/slides/python-net/cs/aspose.slides/persistencetype). |
| [`active_x_control_binary`](/slides/python-net/cs/aspose.slides/icontrol/active_x_control_binary/) | Určuje trvalost ActiveX ovládacího prvku, když je metoda použitá pro uchování buď PersistStream, PersistStreamInit nebo PersistStorage. |
| [`slide`](/slides/python-net/cs/aspose.slides/icontrol/slide/) |  |
| [`presentation`](/slides/python-net/cs/aspose.slides/icontrol/presentation/) |  |
