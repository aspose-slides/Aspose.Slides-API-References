## ITextStyle třída

Vlastnosti formátování stylu textu.

Typ ITextStyle poskytuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`default_paragraph_format`](/slides/python-net/cs/aspose.slides/itextstyle/default_paragraph_format/) | Výchozí vlastnosti odstavce.<br/>            Pouze pro čtení [`IParagraphFormat`](/slides/python-net/cs/aspose.slides/iparagraphformat). |

## Metody

| Metoda | Popis |
| :- | :- |
| [`get_level(self, index)`](/slides/python-net/cs/aspose.slides/itextstyle/get_level/#int) | Pokud úroveň stylu existuje, vrátí ji, jinak vrátí None. |
| [`get_effective(self)`](/slides/python-net/cs/aspose.slides/itextstyle/get_effective/#) | Získá efektivní data formátování stylu textu s aplikovaným děděním. |
