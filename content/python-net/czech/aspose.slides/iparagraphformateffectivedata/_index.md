## IParagraphFormatEffectiveData třída

Neměnný objekt, který obsahuje účinné vlastnosti formátování odstavců.

Typ IParagraphFormatEffectiveData vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`bullet`](/slides/python-net/cs/aspose.slides/iparagraphformateffectivedata/bullet/) | Vrací formát odrážky odstavce.<br/>            Pouze pro čtení [`IBulletFormatEffectiveData`](/slides/python-net/cs/aspose.slides/ibulletformateffectivedata). |
| [`depth`](/slides/python-net/cs/aspose.slides/iparagraphformateffectivedata/depth/) | Vrací hloubku odstavce.<br/>            Pouze pro čtení **int**. |
| [`alignment`](/slides/python-net/cs/aspose.slides/iparagraphformateffectivedata/alignment/) | Vrací zarovnání textu v odstavci.<br/>            Pouze pro čtení [`TextAlignment`](/slides/python-net/cs/aspose.slides/textalignment). |
| [`space_within`](/slides/python-net/cs/aspose.slides/iparagraphformateffectivedata/space_within/) | Vrací množství prostoru mezi základními řádky v odstavci.<br/>            Pouze pro čtení **float**. |
| [`space_before`](/slides/python-net/cs/aspose.slides/iparagraphformateffectivedata/space_before/) | Vrací množství prostoru před prvním řádkem v odstavci.<br/>            Pouze pro čtení **float**. |
| [`space_after`](/slides/python-net/cs/aspose.slides/iparagraphformateffectivedata/space_after/) | Vrací množství prostoru po posledním řádku v odstavci.<br/>            Pouze pro čtení **float**. |
| [`east_asian_line_break`](/slides/python-net/cs/aspose.slides/iparagraphformateffectivedata/east_asian_line_break/) | Určuje, zda se v odstavci používá asijský zalomení řádku.<br/>            Pouze pro čtení **bool**. |
| [`right_to_left`](/slides/python-net/cs/aspose.slides/iparagraphformateffectivedata/right_to_left/) | Určuje, zda se v odstavci používá zápis zprava doleva.<br/>            Pouze pro čtení **bool**. |
| [`latin_line_break`](/slides/python-net/cs/aspose.slides/iparagraphformateffectivedata/latin_line_break/) | Určuje, zda se v odstavci používá latinské zalomení řádku.<br/>            Pouze pro čtení **bool**. |
| [`hanging_punctuation`](/slides/python-net/cs/aspose.slides/iparagraphformateffectivedata/hanging_punctuation/) | Určuje, zda se v odstavci používá závěsná interpunkce.<br/>            Pouze pro čtení **bool**. |
| [`margin_left`](/slides/python-net/cs/aspose.slides/iparagraphformateffectivedata/margin_left/) | Vrací levý okraj v odstavci.<br/>            Pouze pro čtení **float**. |
| [`margin_right`](/slides/python-net/cs/aspose.slides/iparagraphformateffectivedata/margin_right/) | Vrací pravý okraj v odstavci.<br/>            Pouze pro čtení **float**. |
| [`indent`](/slides/python-net/cs/aspose.slides/iparagraphformateffectivedata/indent/) | Vrací první řádek odsazení / závěsné odsazení odstavce. Závěsné odsazení může být definováno zápornými hodnotami.<br/>            Pouze pro čtení **float**. |
| [`default_tab_size`](/slides/python-net/cs/aspose.slides/iparagraphformateffectivedata/default_tab_size/) | Vrací výchozí velikost tabulátoru.<br/>            Pouze pro čtení **float**. |
| [`tabs`](/slides/python-net/cs/aspose.slides/iparagraphformateffectivedata/tabs/) | Vrací tabulátory odstavce.<br/>            Pouze pro čtení [`ITabEffectiveData`](/slides/python-net/cs/aspose.slides/itabeffectivedata)[]. |
| [`font_alignment`](/slides/python-net/cs/aspose.slides/iparagraphformateffectivedata/font_alignment/) | Vrací zarovnání písma v odstavci.<br/>            Pouze pro čtení [`FontAlignment`](/slides/python-net/cs/aspose.slides/fontalignment). |
| [`default_portion_format`](/slides/python-net/cs/aspose.slides/iparagraphformateffectivedata/default_portion_format/) | Vrací výchozí formát podílu odstavce.<br/>            Pouze pro čtení [`IPortionFormatEffectiveData`](/slides/python-net/cs/aspose.slides/iportionformateffectivedata). |

### Poznámky

Toto rozhraní se používá spolu s rozhraním [`IParagraphFormat`](/slides/python-net/cs/aspose.slides/iparagraphformat) k vrácení účinných hodnot formátování s uplatněnou dědičností.
