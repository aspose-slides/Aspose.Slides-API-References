## GroupShapeLock třída

Určuje, které operace jsou vypnuté na nadřazeném GroupShape.

**Dědičnost:**[`GroupShapeLock`](/slides/python-net/cs/aspose.slides/groupshapelock) → [`BaseShapeLock`](/slides/python-net/cs/aspose.slides/baseshapelock)

Typ GroupShapeLock obsahuje následující členy:

## Vlastnosti

| Property | Description |
| :- | :- |
| [`no_locks`](/slides/python-net/cs/aspose.slides/groupshapelock/no_locks/) | Vrací true, pokud jsou všechny příznaky zamykání zakázány.<br/>            Pouze ke čtení **bool**. |
| [`grouping_locked`](/slides/python-net/cs/aspose.slides/groupshapelock/grouping_locked/) | Určuje, zda je přidání tohoto tvaru do skupiny zakázáno.<br/>            Čtení/Zápis **bool**. |
| [`ungrouping_locked`](/slides/python-net/cs/aspose.slides/groupshapelock/ungrouping_locked/) | Určuje, zda je rozdělení této skupiny tvarů zakázáno.<br/>            Čtení/Zápis **bool**. |
| [`select_locked`](/slides/python-net/cs/aspose.slides/groupshapelock/select_locked/) | Určuje, zda je výběr tohoto tvaru zakázán.<br/>            Čtení/Zápis **bool**. |
| [`rotation_locked`](/slides/python-net/cs/aspose.slides/groupshapelock/rotation_locked/) | Určuje, zda je změna úhlu otočení tohoto tvaru zakázána.<br/>            Čtení/Zápis **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/cs/aspose.slides/groupshapelock/aspect_ratio_locked/) | Určuje, zda má tvar při změně velikosti zachovat poměr stran.<br/>            Čtení/Zápis **bool**. |
| [`position_locked`](/slides/python-net/cs/aspose.slides/groupshapelock/position_locked/) | Určuje, zda je přesunutí tohoto tvaru zakázáno.<br/>            Čtení/Zápis **bool**. |
| [`size_locked`](/slides/python-net/cs/aspose.slides/groupshapelock/size_locked/) | Určuje, zda je změna velikosti tohoto tvaru zakázána.<br/>            Čtení/Zápis **bool**. |
