## IThreeDFormatEffectiveData třída

Neměnný objekt, který představuje efektivní vlastnosti 3-D formátování.

Typ IThreeDFormatEffectiveData vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`contour_width`](/slides/python-net/cs/aspose.slides/ithreedformateffectivedata/contour_width/) | Vrací šířku 3D kontury.<br/>            Pouze ke čtení **float**. |
| [`extrusion_height`](/slides/python-net/cs/aspose.slides/ithreedformateffectivedata/extrusion_height/) | Vrací výšku efektu extruze.<br/>            Pouze ke čtení **float**. |
| [`depth`](/slides/python-net/cs/aspose.slides/ithreedformateffectivedata/depth/) | Vrací hloubku 3D tvaru.<br/>            Pouze ke čtení **float**. |
| [`bevel_top`](/slides/python-net/cs/aspose.slides/ithreedformateffectivedata/bevel_top/) | Vrací typ horního 3D zkosení.<br/>            Pouze ke čtení [`IShapeBevelEffectiveData`](/slides/python-net/cs/aspose.slides/ishapebeveleffectivedata). |
| [`bevel_bottom`](/slides/python-net/cs/aspose.slides/ithreedformateffectivedata/bevel_bottom/) | Vrací typ spodního 3D zkosení.<br/>            Pouze ke čtení [`IShapeBevelEffectiveData`](/slides/python-net/cs/aspose.slides/ishapebeveleffectivedata). |
| [`contour_color`](/slides/python-net/cs/aspose.slides/ithreedformateffectivedata/contour_color/) | Vrací barvu kontury.<br/>            Pouze ke čtení **aspose.slides.Color**. |
| [`extrusion_color`](/slides/python-net/cs/aspose.slides/ithreedformateffectivedata/extrusion_color/) | Vrací barvu extruze.<br/>            Pouze ke čtení **aspose.slides.Color**. |
| [`camera`](/slides/python-net/cs/aspose.slides/ithreedformateffectivedata/camera/) | Vrací nastavení kamery.<br/>            Pouze ke čtení [`ICameraEffectiveData`](/slides/python-net/cs/aspose.slides/icameraeffectivedata). |
| [`light_rig`](/slides/python-net/cs/aspose.slides/ithreedformateffectivedata/light_rig/) | Vrací typ světla.<br/>            Pouze ke čtení [`ILightRigEffectiveData`](/slides/python-net/cs/aspose.slides/ilightrigeffectivedata). |
| [`material`](/slides/python-net/cs/aspose.slides/ithreedformateffectivedata/material/) | Vrací typ materiálu.<br/>            Pouze ke čtení [`MaterialPresetType`](/slides/python-net/cs/aspose.slides/materialpresettype). |


### Poznámky

Toto rozhraní se používá spolu s rozhraním [`IThreeDFormat`](/slides/python-net/cs/aspose.slides/ithreedformat) k vrácení efektivních hodnot formátování s aplikovaným děděním.
