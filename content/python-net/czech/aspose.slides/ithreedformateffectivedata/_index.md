## IThreeDFormatEffectiveData třída

Neměnný objekt, který představuje efektivní vlastnosti 3-D formátování.

Typ IThreeDFormatEffectiveData vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`contour_width`](/slides/python-net/cs/aspose.slides/ithreedformateffectivedata/contour_width/) | Returns the width of a 3D contour.<br/>            Pouze pro čtení **float**. |
| [`extrusion_height`](/slides/python-net/cs/aspose.slides/ithreedformateffectivedata/extrusion_height/) | Returns the height of an extrusion effect.<br/>            Pouze pro čtení **float**. |
| [`depth`](/slides/python-net/cs/aspose.slides/ithreedformateffectivedata/depth/) | Returns the depth of a 3D shape.<br/>            Pouze pro čtení **float**. |
| [`bevel_top`](/slides/python-net/cs/aspose.slides/ithreedformateffectivedata/bevel_top/) | Returns the type of a top 3D bevel.<br/>            Pouze pro čtení [`IShapeBevelEffectiveData`](/slides/python-net/cs/aspose.slides/ishapebeveleffectivedata). |
| [`bevel_bottom`](/slides/python-net/cs/aspose.slides/ithreedformateffectivedata/bevel_bottom/) | Returns the type of a bottom 3D bevel.<br/>            Pouze pro čtení [`IShapeBevelEffectiveData`](/slides/python-net/cs/aspose.slides/ishapebeveleffectivedata). |
| [`contour_color`](/slides/python-net/cs/aspose.slides/ithreedformateffectivedata/contour_color/) | Returns the color of a contour.<br/>            Pouze pro čtení [`Color`](/slides/python-net/cs/aspose.slides/color). |
| [`extrusion_color`](/slides/python-net/cs/aspose.slides/ithreedformateffectivedata/extrusion_color/) | Returns the color of an extrusion.<br/>            Pouze pro čtení [`Color`](/slides/python-net/cs/aspose.slides/color). |
| [`camera`](/slides/python-net/cs/aspose.slides/ithreedformateffectivedata/camera/) | Returns the settings of a camera.<br/>            Pouze pro čtení [`ICameraEffectiveData`](/slides/python-net/cs/aspose.slides/icameraeffectivedata). |
| [`light_rig`](/slides/python-net/cs/aspose.slides/ithreedformateffectivedata/light_rig/) | Returns the type of a light.<br/>            Pouze pro čtení [`ILightRigEffectiveData`](/slides/python-net/cs/aspose.slides/ilightrigeffectivedata). |
| [`material`](/slides/python-net/cs/aspose.slides/ithreedformateffectivedata/material/) | Returns the type of a material.<br/>            Pouze pro čtení [`MaterialPresetType`](/slides/python-net/cs/aspose.slides/materialpresettype). |
