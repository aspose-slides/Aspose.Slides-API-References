## Fonts třída

Fonts kolekce.

Typ Fonts obsahuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`latin_font`](/slides/python-net/cs/aspose.slides/fonts/latin_font/) | Vrací nebo nastavuje latinský font.<br/>            Číst/zapisovat [`IFontData`](/slides/python-net/cs/aspose.slides/ifontdata). |
| [`east_asian_font`](/slides/python-net/cs/aspose.slides/fonts/east_asian_font/) | Vrací nebo nastavuje východoasijský font.<br/>            Číst/zapisovat [`IFontData`](/slides/python-net/cs/aspose.slides/ifontdata). |
| [`complex_script_font`](/slides/python-net/cs/aspose.slides/fonts/complex_script_font/) | Vrací nebo nastavuje komplexní skriptový font.<br/>            Číst/zapisovat [`IFontData`](/slides/python-net/cs/aspose.slides/ifontdata). |

## Metody

| Metoda | Popis |
| :- | :- |
| [`get_script_font_map(self)`](/slides/python-net/cs/aspose.slides/fonts/get_script_font_map/#) | Vrací seznam všech dvojic string-string definic fontů skriptu v prezentaci. |
| [`get_script_font(self, script)`](/slides/python-net/cs/aspose.slides/fonts/get_script_font/#str) | Získává název fontu přiřazený ke konkrétní značce skriptu z motivu prezentace. |

| [`remove_script_font(self, script)`](/slides/python-net/cs/aspose.slides/fonts/remove_script_font/#str) | Odstraňuje nastavení fontu přiřazené ke konkrétní značce skriptu z kolekce fontů motivu. |
