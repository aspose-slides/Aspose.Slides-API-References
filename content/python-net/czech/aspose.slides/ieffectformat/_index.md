## IEffectFormat třída

Reprezentuje vlastnosti efektu tvaru.

Typ IEffectFormat vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`is_no_effects`](/slides/python-net/cs/aspose.slides/ieffectformat/is_no_effects/) | Vrací true, pokud jsou všechny efekty zakázány (při právě vytvořeném výchozím objektu EffectFormat).<br/>            Pouze pro čtení **bool**. |
| [`blur_effect`](/slides/python-net/cs/aspose.slides/ieffectformat/blur_effect/) | Efekt rozostření.<br/>            Čtení/Zápis [`IBlur`](/slides/python-net/cs/aspose.slides.effects/iblur). |
| [`fill_overlay_effect`](/slides/python-net/cs/aspose.slides/ieffectformat/fill_overlay_effect/) | Efekt překrytí výplní.<br/>            Čtení/Zápis [`IFillOverlay`](/slides/python-net/cs/aspose.slides.effects/ifilloverlay). |
| [`glow_effect`](/slides/python-net/cs/aspose.slides/ieffectformat/glow_effect/) | Efekt záře.<br/>            Čtení/Zápis [`IGlow`](/slides/python-net/cs/aspose.slides.effects/iglow). |
| [`inner_shadow_effect`](/slides/python-net/cs/aspose.slides/ieffectformat/inner_shadow_effect/) | Vnitřní stín.<br/>            Čtení/Zápis [`IInnerShadow`](/slides/python-net/cs/aspose.slides.effects/iinnershadow). |
| [`outer_shadow_effect`](/slides/python-net/cs/aspose.slides/ieffectformat/outer_shadow_effect/) | Vnější stín.<br/>            Čtení/Zápis [`IOuterShadow`](/slides/python-net/cs/aspose.slides.effects/ioutershadow). |
| [`preset_shadow_effect`](/slides/python-net/cs/aspose.slides/ieffectformat/preset_shadow_effect/) | Předdefinovaný stín.<br/>            Čtení/Zápis [`IPresetShadow`](/slides/python-net/cs/aspose.slides.effects/ipresetshadow). |
| [`reflection_effect`](/slides/python-net/cs/aspose.slides/ieffectformat/reflection_effect/) | Odraz.<br/>            Čtení/Zápis [`IReflection`](/slides/python-net/cs/aspose.slides.effects/ireflection). |
| [`soft_edge_effect`](/slides/python-net/cs/aspose.slides/ieffectformat/soft_edge_effect/) | Měkký okraj.<br/>            Čtení/Zápis [`ISoftEdge`](/slides/python-net/cs/aspose.slides.effects/isoftedge). |
