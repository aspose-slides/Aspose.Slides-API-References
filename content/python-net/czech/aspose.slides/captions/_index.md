## třída Captions

Representuje uzavřené titulky ve formátu WebVTT.

Typ Captions obsahuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`caption_id`](/slides/python-net/cs/aspose.slides/captions/caption_id/) | Vrátí globálně jedinečný identifikátor (GUID) uzavřených titulků.<br/>            Pouze pro čtení **System.Guid**. |
| [`label`](/slides/python-net/cs/aspose.slides/captions/label/) | Vrátí nebo nastaví popisek uzavřených titulků.<br/>            Čtení/zápis **str**. |
| [`binary_data`](/slides/python-net/cs/aspose.slides/captions/binary_data/) | Vrátí binární data uzavřených titulků.<br/>            Pouze pro čtení **int**[]. |
| [`data_as_string`](/slides/python-net/cs/aspose.slides/captions/data_as_string/) | Vrátí data uzavřených titulků jako řetězec kódovaný UTF-8<br/>            Pouze pro čtení **str**. |
