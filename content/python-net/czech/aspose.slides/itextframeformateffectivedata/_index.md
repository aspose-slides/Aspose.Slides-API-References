## ITextFrameFormatEffectiveData třída

Neměnný objekt, který obsahuje efektivní vlastnosti formátování textového rámečku.

Typ ITextFrameFormatEffectiveData vystavuje následující členy:

## Properties

| Property | Description |
| :- | :- |
| [`text_style`](/slides/python-net/cs/aspose.slides/itextframeformateffectivedata/text_style/) | Vrací efektivní styl textu.<br/>            Pouze pro čtení [`ITextStyleEffectiveData`](/slides/python-net/cs/aspose.slides/itextstyleeffectivedata). |
| [`margin_left`](/slides/python-net/cs/aspose.slides/itextframeformateffectivedata/margin_left/) | Vrací levý okraj (body) v TextFrame.<br/>            Pouze pro čtení **float**. |
| [`margin_right`](/slides/python-net/cs/aspose.slides/itextframeformateffectivedata/margin_right/) | Vrací pravý okraj (body) v TextFrame.<br/>            Pouze pro čtení **float**. |
| [`margin_top`](/slides/python-net/cs/aspose.slides/itextframeformateffectivedata/margin_top/) | Vrací horní okraj (body) v TextFrame.<br/>            Pouze pro čtení **float**. |
| [`margin_bottom`](/slides/python-net/cs/aspose.slides/itextframeformateffectivedata/margin_bottom/) | Vrací dolní okraj (body) v TextFrame.<br/>            Pouze pro čtení **float**. |
| [`wrap_text`](/slides/python-net/cs/aspose.slides/itextframeformateffectivedata/wrap_text/) | Vrací, zda je text zalamován na okrajích TextFrame.<br/>            Pouze pro čtení **bool**. |
