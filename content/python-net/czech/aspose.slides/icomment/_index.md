## IComment třída

Reprezentuje komentář na snímku.

Typ IComment obsahuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`text`](/slides/python-net/cs/aspose.slides/icomment/text/) | Vrací nebo nastavuje prostý text komentáře na snímku.<br/>            Číst/zapisovat **str**. |
| [`created_time`](/slides/python-net/cs/aspose.slides/icomment/created_time/) | Vrací nebo nastavuje čas vytvoření komentáře.<br/>            Nastavení této vlastnosti na **System.DateTime** znamená, že čas komentáře není nastaven.<br/>            Číst/zapisovat **System.DateTime**. |
| [`slide`](/slides/python-net/cs/aspose.slides/icomment/slide/) | Vrací nebo nastavuje nadřazený snímek komentáře.<br/>            Pouze ke čtení [`ISlide`](/slides/python-net/cs/aspose.slides/islide). |
| [`author`](/slides/python-net/cs/aspose.slides/icomment/author/) | Vrací autora komentáře.<br/>            Pouze ke čtení [`ICommentAuthor`](/slides/python-net/cs/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/cs/aspose.slides/icomment/position/) | Vrací nebo nastavuje pozici komentáře na snímku.<br/>            Číst/zapisovat **aspose.slides.PointF**. |
| [`parent_comment`](/slides/python-net/cs/aspose.slides/icomment/parent_comment/) | Vrací nebo nastavuje nadřazený komentář.<br/>            Číst/zapisovat [`IComment`](/slides/python-net/cs/aspose.slides/icomment). |

## Metody

| Metoda | Popis |
| :- | :- |
| [`remove(self)`](/slides/python-net/cs/aspose.slides/icomment/remove/#) | Odstraňuje komentář a všechny jeho odpovědi z nadřazené kolekce. |
