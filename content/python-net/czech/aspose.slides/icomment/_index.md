## IComment třída

Reprezentuje komentář na snímku.

Typ IComment poskytuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`text`](/slides/python-net/cs/aspose.slides/icomment/text/) | Vrací nebo nastavuje jednoduchý text komentáře na snímku.<br/>            Čtení/zápis **str**. |
| [`created_time`](/slides/python-net/cs/aspose.slides/icomment/created_time/) | Vrací nebo nastavuje čas vytvoření komentáře.<br/>            Nastavení této vlastnosti na **System.DateTime** znamená, že čas komentáře není nastaven.<br/>            Čtení/zápis **System.DateTime**. |
| [`slide`](/slides/python-net/cs/aspose.slides/icomment/slide/) | Vrací nebo nastavuje nadřazený snímek komentáře.<br/>            Pouze pro čtení [`ISlide`](/slides/python-net/cs/aspose.slides/islide). |
| [`author`](/slides/python-net/cs/aspose.slides/icomment/author/) | Vrací autora komentáře.<br/>            Pouze pro čtení [`ICommentAuthor`](/slides/python-net/cs/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/cs/aspose.slides/icomment/position/) | Vrací nebo nastavuje pozici komentáře na snímku.<br/>            Čtení/zápis [`PointF`](/slides/python-net/cs/aspose.slides/pointf). |
| [`parent_comment`](/slides/python-net/cs/aspose.slides/icomment/parent_comment/) | Vrací nebo nastavuje nadřazený komentář.<br/>            Čtení/zápis [`IComment`](/slides/python-net/cs/aspose.slides/icomment). |

## Metody

| Metoda | Popis |
| :- | :- |
| [`remove(self)`](/slides/python-net/cs/aspose.slides/icomment/remove/#) | Odstraní komentář a všechny jeho odpovědi z nadřazené kolekce. |
