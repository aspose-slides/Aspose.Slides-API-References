## BlackWhiteMode enumerace

Určuje, jak má být barevný tvar převeden na černobílý.

Typ BlackWhiteMode poskytuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| NOT_DEFINED | Vlastnost není nastavena |
| COLOR | Objekt je vykreslen s normálním barvením |
| AUTOMATIC | Objekt je vykreslen s automatickým barvením |
| GRAY | Objekt je vykreslen se šedým zbarvením |
| LIGHT_GRAY | Objekt je vykreslen se světle šedým zbarvením |
| INVERSE_GRAY | Objekt je vykreslen s inverzním šedým zbarvením |
| GRAY_WHITE | Objekt je vykreslen se šedým a bílým zbarvením |
| BLACK_GRAY | Objekt je vykreslen s černým a šedým zbarvením |
| BLACK_WHITE | Objekt je vykreslen s černým a bílým zbarvením |
| BLACK | Objekt je vykreslen pouze s černým zbarvením |
| WHITE | Objekt je vykreslen s bílým zbarvením |
| HIDDEN | Objekt není vykreslen |
