Obsahuje třídy, které představují různé typy varování
## Třídy

| Třída | Popis |
| :- | :- |
| [`IKnownIssueWarningInfo`](/slides/python-net/cs/aspose.slides.warnings/iknownissuewarninginfo/) | Představuje varování o známém problému, který v blízké budoucnosti nebude opraven. |
| [`INotImplementedWarningInfo`](/slides/python-net/cs/aspose.slides.warnings/inotimplementedwarninginfo/) | Představuje varování o známé neimplementované funkci, která nebude v blízké budoucnosti implementována. |
| [`IObsoletePresLockingBehaviorWarningInfo`](/slides/python-net/cs/aspose.slides.warnings/iobsoletepreslockingbehaviorwarninginfo/) | Toto varování naznačuje, že je použito zastaralé chování zamykání prezentace. |
| [`IPresentationSignedWarningInfo`](/slides/python-net/cs/aspose.slides.warnings/ipresentationsignedwarninginfo/) | Toto varování naznačuje, že načítaná prezentace má podpis <br/>            a tento podpis bude během zpracování odstraněn. |
| [`IWarningCallback`](/slides/python-net/cs/aspose.slides.warnings/iwarningcallback/) | Rozhraní pro třídy, které přijímají varování |
| [`IWarningInfo`](/slides/python-net/cs/aspose.slides.warnings/iwarninginfo/) | Představuje základní rozhraní pro všechna varování. |
