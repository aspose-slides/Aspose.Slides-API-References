## SmartArtNode třída

Reprezentuje uzel objektu SmartArt

Typ SmartArtNode vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`child_nodes`](/slides/python-net/cs/aspose.slides.smartart/smartartnode/child_nodes/) | Vrací kolekci všech podřízených uzlů aktuálního uzlu.<br/>            Pouze pro čtení [`ISmartArtNodeCollection`](/slides/python-net/cs/aspose.slides.smartart/ismartartnodecollection). |
| [`shapes`](/slides/python-net/cs/aspose.slides.smartart/smartartnode/shapes/) | Vrací kolekci všech tvarů spojených s uzlem.<br/>            Pouze pro čtení [`ISmartArtShapeCollection`](/slides/python-net/cs/aspose.slides.smartart/ismartartshapecollection). |
| [`text_frame`](/slides/python-net/cs/aspose.slides.smartart/smartartnode/text_frame/) | Vrací textový rámec uzlu.<br/>            Pouze pro čtení [`ITextFrame`](/slides/python-net/cs/aspose.slides/itextframe). |
| [`is_assistant`](/slides/python-net/cs/aspose.slides.smartart/smartartnode/is_assistant/) | Vrací nebo nastavuje uzel jako asistenta.<br/>            Čtení/Zápis **bool**. |
| [`level`](/slides/python-net/cs/aspose.slides.smartart/smartartnode/level/) | Vrací úroveň vnoření uzlu.<br/>            Pouze pro čtení **int**. |
| [`bullet_fill_format`](/slides/python-net/cs/aspose.slides.smartart/smartartnode/bullet_fill_format/) | Vrací objekt FillFormat, který obsahuje vlastnosti formátování výplně pro odrážku uzlu.<br/>            Poznámka: může vrátit None pro některé typy rozvržení SmartArt, které neposkytují odrážky pro uzly.<br/>            Pouze pro čtení [`IFillFormat`](/slides/python-net/cs/aspose.slides/ifillformat). |
| [`position`](/slides/python-net/cs/aspose.slides.smartart/smartartnode/position/) | Vrací nebo nastavuje nulovou pozici uzlu mezi sourozeneckými uzly.<br/>            Čtení/Zápis **int**. |
| [`is_hidden`](/slides/python-net/cs/aspose.slides.smartart/smartartnode/is_hidden/) | Vrací true, pokud je tento uzel skrytý uzel v datovém modelu.<br/>            Pouze pro čtení **bool**. |
| [`organization_chart_layout`](/slides/python-net/cs/aspose.slides.smartart/smartartnode/organization_chart_layout/) | Vrací nebo nastavuje typ rozvržení organizačního grafu spojený s aktuálním uzlem.<br/>            Čtení/Zápis [`OrganizationChartLayoutType`](/slides/python-net/cs/aspose.slides.smartart/organizationchartlayouttype). |
