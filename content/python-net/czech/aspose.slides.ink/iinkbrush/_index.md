## IInkBrush třída

Reprezentuje stopový štětec.

Typ IInkBrush obsahuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`color`](/slides/python-net/cs/aspose.slides.ink/iinkbrush/color/) | Získá nebo nastaví barvu štětce pro čáru. |
| [`size`](/slides/python-net/cs/aspose.slides.ink/iinkbrush/size/) | Získá nebo nastaví velikost štětce pro čáru v bodech. |
| [`ink_effect`](/slides/python-net/cs/aspose.slides.ink/iinkbrush/ink_effect/) | Získá typ efektu inkoustu (např. Galaxy, Gold, Silver), který definuje vizuální styl tahů inkoustu.<br/>            Hodnota je parsována z vlastnosti štětce \"inkEffects\". Pokud není zadán žádný rozpoznaný efekt,<br/>            [`InkEffectType.NOT_DEFINED`](/slides/python-net/cs/aspose.slides.ink/inkeffecttype/NOT_DEFINED) je vrácena. |
