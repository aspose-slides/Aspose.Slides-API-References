## InkEffectType výčet

Specifikuje sadu předdefinovaných vizuálních efektů pro vykreslování inkoustu.
Každý efekt odpovídá textuře nebo obrázku, který simuluje stylizovaný vzhled inkoustu.
Tyto hodnoty lze použít k přizpůsobení vizuálního stylu digitálních tahů inkoustu během vykreslování.

The InkEffectType type exposes the following members:

## Pole

| Pole | Popis |
| :- | :- |
| NOT_DEFINED | Efekt není definován nebo je neznámý. Tuto hodnotu lze použít jako výchozí nebo náhradní. |
| BRONZE | Teplá, hnědavá kovová textura připomínající bronzový inkoust. |
| GALAXY | Barevná, třpytivá textura připomínající galaxii s kosmickými tóny. |
| GOLD | Jasná, kovová zlatá textura, která dodává tahům inkoustu luxusní vzhled. |
| LAVA | Ohnivá textura připomínající roztavenou lávu s červenými a oranžovými odstíny. |
| OCEAN | Hloubavě modrá, tekutá textura napodobující oceánské vlny nebo vodní inkoust. |
| RAINBOW_GLITTER | Barevný, jiskřivý efekt duhového třpytu použitý pro slavnostní nebo živé tahy inkoustu. |
| ROSE_GOLD | Jemná růžovo-zlatá kombinace podobná růžovému zlatu, pro elegantní tahy inkoustu. |
| SILVER | Chladná, kovová stříbrná textura, která simuluje klasický stříbrný inkoust. |
