## IVbaProject třída

Zastupuje projekt VBA s makry prezentace.

Typ IVbaProject poskytuje následující členy:

## Vlastnosti

| Property | Description |
| :- | :- |
| [`name`](/slides/python-net/cs/aspose.slides.vba/ivbaproject/name/) | Vrací název VBA projektu.<br/>            Pouze ke čtení **str**. |
| [`modules`](/slides/python-net/cs/aspose.slides.vba/ivbaproject/modules/) | Vrací seznam všech modulů, které jsou obsaženy v projektu VBA.<br/>            Pouze ke čtení [`IVbaModuleCollection`](/slides/python-net/cs/aspose.slides.vba/ivbamodulecollection). |
| [`references`](/slides/python-net/cs/aspose.slides.vba/ivbaproject/references/) | Vrací seznam všech odkazů, které jsou obsaženy v projektu VBA.<br/>            Pouze ke čtení [`IVbaReferenceCollection`](/slides/python-net/cs/aspose.slides.vba/ivbareferencecollection). |
| [`is_password_protected`](/slides/python-net/cs/aspose.slides.vba/ivbaproject/is_password_protected/) | Určuje, zda je VBAProject chráněn heslem pro zobrazení vlastností projektu.<br/>            Pouze ke čtení **bool**. |
