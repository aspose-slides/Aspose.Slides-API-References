## IMathGroupingCharacter třída

Specifikuje skupinový znak nad nebo pod výrazem, obvykle k zvýraznění vztahu mezi prvky

Typ IMathGroupingCharacter obsahuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`base`](/slides/python-net/cs/aspose.slides.mathtext/imathgroupingcharacter/base/) | Základní argument |
| [`character`](/slides/python-net/cs/aspose.slides.mathtext/imathgroupingcharacter/character/) | Skupinový znak<br/>            Výchozí hodnota: U+23DF (BOTTOM CURLY BRACKET) |
| [`position`](/slides/python-net/cs/aspose.slides.mathtext/imathgroupingcharacter/position/) | Pozice skupinového znaku.<br/>            Výchozí: Bottom |
| [`vertical_justification`](/slides/python-net/cs/aspose.slides.mathtext/imathgroupingcharacter/vertical_justification/) | Vertikální zarovnání skupinového znaku.<br/>            Určuje zarovnání objektu vzhledem k základní čáře.<br/>            Například když je skupinový znak nad objektem, <br/>            VerticalJustification hodnoty Top znamená, že horní část objektu leží na základní čáře;<br/>            když je VerticalJustification nastavena na Bottom, spodní část objektu leží na základní čáře<br/>            Výchozí: Bottom pro Position=Top a Top pro Position=Bottom |
