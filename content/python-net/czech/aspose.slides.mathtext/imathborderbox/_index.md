## IMathBorderBox třída

Vykresluje obdélníkový nebo jiný okraj kolem IMathElement.

Typ IMathBorderBox poskytuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`base`](/slides/python-net/cs/aspose.slides.mathtext/imathborderbox/base/) | Základní argument |
| [`hide_top`](/slides/python-net/cs/aspose.slides.mathtext/imathborderbox/hide_top/) | Skrýt horní okraj (výchozí je false) – určuje skrytý nebo zobrazený stav horního okraje border boxu. |
| [`hide_bottom`](/slides/python-net/cs/aspose.slides.mathtext/imathborderbox/hide_bottom/) | Skrýt spodní okraj (výchozí je false) – určuje skrytý nebo zobrazený stav spodního okraje border boxu. |
| [`hide_left`](/slides/python-net/cs/aspose.slides.mathtext/imathborderbox/hide_left/) | Skrýt levý okraj (výchozí je false) – určuje skrytý nebo zobrazený stav levého okraje border boxu. |
| [`hide_right`](/slides/python-net/cs/aspose.slides.mathtext/imathborderbox/hide_right/) | Skrýt pravý okraj (výchozí je false) – určuje skrytý nebo zobrazený stav pravého okraje border boxu. |
| [`strikethrough_horizontal`](/slides/python-net/cs/aspose.slides.mathtext/imathborderbox/strikethrough_horizontal/) | Přeškrtnutí horizontální (výchozí je false) – určuje skrytý nebo zobrazený stav horizontální přeškrtnuté čáry. |
| [`strikethrough_vertical`](/slides/python-net/cs/aspose.slides.mathtext/imathborderbox/strikethrough_vertical/) | Přeškrtnutí vertikální (výchozí je false) – určuje skrytý nebo zobrazený stav vertikální přeškrtnuté čáry. |
| [`strikethrough_bottom_left_to_top_right`](/slides/python-net/cs/aspose.slides.mathtext/imathborderbox/strikethrough_bottom_left_to_top_right/) | Přeškrtnutí z dolního levého do pravého horního (výchozí je false).<br/>            Určuje skrytý nebo zobrazený stav přeškrtnuté úhlopříčky od dolního levého rohu k pravému hornímu rohu border boxu. |
| [`strikethrough_top_left_to_bottom_right`](/slides/python-net/cs/aspose.slides.mathtext/imathborderbox/strikethrough_top_left_to_bottom_right/) | Přeškrtnutí z levého horního do pravého dolního (výchozí je false).<br/>            Určuje skrytý nebo zobrazený stav přeškrtnuté úhlopříčky od levého horního rohu k pravému dolnímu rohu border boxu. |
