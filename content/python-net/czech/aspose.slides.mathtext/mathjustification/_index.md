## MathJustification výčet

Specifikuje zarovnání matematického odstavce (série sousedních výskytů matematického textu ve stejném odstavci)

Typ MathJustification obsahuje následující členy:

## Pole

| Field | Description |
| :- | :- |
| LEFT_JUSTIFIED | Zarovnat matematický text doleva |
| RIGHT_JUSTIFIED | Zarovnat matematický text doprava |
| CENTERED | Zarovnat matematický text na střed |
| CENTERED_AS_GROUP | Centrovat na stránce celou skupinu matematických bloků jako jednotku.<br/>            To znamená, že výskyty matematického textu mohou být zarovnány vůči sobě navzájem, <br/>            ale celá skupina matematického textu je centrována jako celek. |
