## to_box(self) {#}
Places this element in a non-visual box (logické seskupení) 
            which is used to group components of an equation or other instance of mathematical text.
            A boxed object can (například) serve as an operator emulator with or without an alignment point, 
            serve as a line break point, or be grouped such as not to allow line breaks within.
