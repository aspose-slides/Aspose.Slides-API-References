## MathLimitLocations enumerace

Umístění limit (dolní index/horní index) v n-ární operátorech.

Typ MathLimitLocations obsahuje následující členy:

## Pole

| Field | Description |
| :- | :- |
| NOT_DEFINED | Není definováno |
| UNDER_OVER | Meze jsou vykresleny nahoře a dole pod symbolem operátoru |
| SUBSCRIPT_SUPERSCRIPT | Meze jsou vykresleny jako dolní a horní index |
