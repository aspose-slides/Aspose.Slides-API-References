## align_scripts vlastnost
Určuje zarovnání dolního indexu/ horního indexu. 
            Když je true, dolní index a horní index jsou vodorovně zarovnány k sobě navzájem.
            Když je false, jsou podříznuty do tvaru základu.
            Výchozí hodnota je false.
