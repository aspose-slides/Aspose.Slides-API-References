## IOuterShadow třída

Reprezentuje efekt vnějšího stínu.

Typ IOuterShadow poskytuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`blur_radius`](/slides/python-net/cs/aspose.slides.effects/ioutershadow/blur_radius/) | Poloměr rozostření, v bodech.<br/>            Výchozí hodnota – 0 pt.<br/>            Čtení/zápis **float**. |
| [`direction`](/slides/python-net/cs/aspose.slides.effects/ioutershadow/direction/) | Směr stínu, ve stupních.<br/>            Výchozí hodnota – 0 ° (zleva doprava).<br/>            Čtení/zápis **float**. |
| [`distance`](/slides/python-net/cs/aspose.slides.effects/ioutershadow/distance/) | Vzdálenost stínu od objektu, v bodech.<br/>            Výchozí hodnota – 0 pt.<br/>            Čtení/zápis **float**. |
| [`shadow_color`](/slides/python-net/cs/aspose.slides.effects/ioutershadow/shadow_color/) | Barva stínu.<br/>            Výchozí hodnota – automatická černá (závislá na motivu).<br/>            Pouze ke čtení [`IColorFormat`](/slides/python-net/cs/aspose.slides/icolorformat). |
| [`rectangle_align`](/slides/python-net/cs/aspose.slides.effects/ioutershadow/rectangle_align/) | Zarovnání obdélníku.<br/>            Výchozí hodnota – [`RectangleAlignment.BOTTOM`](/slides/python-net/cs/aspose.slides/rectanglealignment/BOTTOM). <br/>            Čtení/zápis [`RectangleAlignment`](/slides/python-net/cs/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/cs/aspose.slides.effects/ioutershadow/skew_horizontal/) | Úhel horizontálního skosu, ve stupních.<br/>            Výchozí hodnota – 0 °.<br/>            Čtení/zápis **float**. |
| [`skew_vertical`](/slides/python-net/cs/aspose.slides.effects/ioutershadow/skew_vertical/) | Úhel vertikálního skosu, ve stupních.<br/>            Výchozí hodnota – 0 °.<br/>            Čtení/zápis **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/cs/aspose.slides.effects/ioutershadow/rotate_shadow_with_shape/) | Určuje, zda se stín otáčí spolu s tvarem.<br/>            Výchozí hodnota – true.<br/>            Čtení/zápis **bool**. |
| [`scale_horizontal`](/slides/python-net/cs/aspose.slides.effects/ioutershadow/scale_horizontal/) | Faktor horizontálního škálování, v procentech původní velikosti.<br/>            Negativní škálování způsobí převrácení.<br/>            Výchozí hodnota – 100 %.<br/>            Čtení/zápis **float**. |
| [`scale_vertical`](/slides/python-net/cs/aspose.slides.effects/ioutershadow/scale_vertical/) | Faktor vertikálního škálování, v procentech původní velikosti.<br/>            Negativní škálování způsobí převrácení.<br/>            Výchozí hodnota – 100 %.<br/>            Čtení/zápis **float**. |
