## IReflectionEffectiveData třída

Neměnný objekt, který představuje efekt odrazu.

Typ IReflectionEffectiveData exponuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/cs/aspose.slides.effects/ireflectioneffectivedata/start_pos_alpha/) | Určuje počáteční pozici (podél alfa gradientové rampy) počáteční hodnoty alfa (procenta).<br/>            Pouze ke čtení **float**. |
| [`end_pos_alpha`](/slides/python-net/cs/aspose.slides.effects/ireflectioneffectivedata/end_pos_alpha/) | Určuje koncovou pozici (podél alfa gradientové rampy) koncové hodnoty alfa (procenta).<br/>            Pouze ke čtení **float**. |
| [`fade_direction`](/slides/python-net/cs/aspose.slides.effects/ireflectioneffectivedata/fade_direction/) | Určuje směr posunu odrazu. (úhel).<br/>            Pouze ke čtení **float**. |
| [`start_reflection_opacity`](/slides/python-net/cs/aspose.slides.effects/ireflectioneffectivedata/start_reflection_opacity/) | Počáteční neprůhlednost odrazu. (procenta).<br/>            Pouze ke čtení **float**. |
| [`end_reflection_opacity`](/slides/python-net/cs/aspose.slides.effects/ireflectioneffectivedata/end_reflection_opacity/) | Koncová neprůhlednost odrazu. (procenta).<br/>            Pouze ke čtení **float**. |
| [`blur_radius`](/slides/python-net/cs/aspose.slides.effects/ireflectioneffectivedata/blur_radius/) | Poloměr rozostření.<br/>            Pouze ke čtení **float**. |
| [`direction`](/slides/python-net/cs/aspose.slides.effects/ireflectioneffectivedata/direction/) | Směr odrazu.<br/>            Pouze ke čtení **float**. |
| [`distance`](/slides/python-net/cs/aspose.slides.effects/ireflectioneffectivedata/distance/) | Vzdálenost odrazu.<br/>            Pouze ke čtení **float**. |
| [`rectangle_align`](/slides/python-net/cs/aspose.slides.effects/ireflectioneffectivedata/rectangle_align/) | Zarovnání obdélníku.<br/>            Pouze ke čtení [`RectangleAlignment`](/slides/python-net/cs/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/cs/aspose.slides.effects/ireflectioneffectivedata/skew_horizontal/) | Určuje horizontální úhel šikmosti.<br/>            Pouze ke čtení **float**. |
| [`skew_vertical`](/slides/python-net/cs/aspose.slides.effects/ireflectioneffectivedata/skew_vertical/) | Určuje vertikální úhel šikmosti.<br/>            Pouze ke čtení **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/cs/aspose.slides.effects/ireflectioneffectivedata/rotate_shadow_with_shape/) | Určuje, zda se odraz má otáčet spolu s tvarem, pokud je tvar otočen.<br/>            Pouze ke čtení **bool**. |
| [`scale_horizontal`](/slides/python-net/cs/aspose.slides.effects/ireflectioneffectivedata/scale_horizontal/) | Určuje horizontální faktor měřítka, záporné měřítko způsobuje převrácení. (procenta)<br/>            Pouze ke čtení **float**. |
| [`scale_vertical`](/slides/python-net/cs/aspose.slides.effects/ireflectioneffectivedata/scale_vertical/) | Určuje vertikální faktor měřítka, záporné měřítko způsobuje převrácení. (procenta)<br/>            Pouze ke čtení **float**. |
