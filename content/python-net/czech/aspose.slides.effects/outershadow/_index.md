## OuterShadow třída

Představuje efekt vnějšího stínu.

Typ OuterShadow obsahuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`blur_radius`](/slides/python-net/cs/aspose.slides.effects/outershadow/blur_radius/) | Blur radius, in points.<br/>            Default value – 0 pt.<br/>            Čtení/zápis **float**. |
| [`direction`](/slides/python-net/cs/aspose.slides.effects/outershadow/direction/) | Direction of the shadow, in degrees.<br/>            Default value – 0 ° (left-to-right).<br/>            Čtení/zápis **float**. |
| [`distance`](/slides/python-net/cs/aspose.slides.effects/outershadow/distance/) | Distance of the shadow from the object, in points.<br/>            Default value – 0 pt.<br/>            Čtení/zápis **float**. |
| [`shadow_color`](/slides/python-net/cs/aspose.slides.effects/outershadow/shadow_color/) | Color of the shadow.<br/>            Default value – automatic black (theme-dependent).<br/>            Pouze pro čtení [`IColorFormat`](/slides/python-net/cs/aspose.slides/icolorformat). |
| [`rectangle_align`](/slides/python-net/cs/aspose.slides.effects/outershadow/rectangle_align/) | Rectangle alignment.<br/>            Default value – [`RectangleAlignment.BOTTOM`](/slides/python-net/cs/aspose.slides/rectanglealignment/BOTTOM). <br/>            Čtení/zápis [`RectangleAlignment`](/slides/python-net/cs/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/cs/aspose.slides.effects/outershadow/skew_horizontal/) | Horizontal skew angle, in degrees.<br/>            Default value – 0 °.<br/>            Čtení/zápis **float**. |
| [`skew_vertical`](/slides/python-net/cs/aspose.slides.effects/outershadow/skew_vertical/) | Vertical skew angle, in degrees.<br/>            Default value – 0 °.<br/>            Čtení/zápis **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/cs/aspose.slides.effects/outershadow/rotate_shadow_with_shape/) | Indicates whether the shadow rotates together with the shape.<br/>            Default value – true.<br/>            Čtení/zápis **bool**. |
| [`scale_horizontal`](/slides/python-net/cs/aspose.slides.effects/outershadow/scale_horizontal/) | Horizontal scaling factor, in percent of the original size.<br/>            Negative scaling causes a flip.<br/>            Default value – 100 %.<br/>            Čtení/zápis **float**. |
| [`scale_vertical`](/slides/python-net/cs/aspose.slides.effects/outershadow/scale_vertical/) | Vertical scaling factor, in percent of the original size.<br/>            Negative scaling causes a flip.<br/>            Default value – 100 %.<br/>            Čtení/zápis **float**. |
