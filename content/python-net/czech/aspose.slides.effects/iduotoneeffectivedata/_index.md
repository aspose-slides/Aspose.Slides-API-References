## IDuotoneEffectiveData třída

Neměnný objekt, který představuje efekt Duotone.
Pro každý pixel kombinuje clr1 a clr2 pomocí lineární interpolace, aby určil novou barvu pro tento pixel.

Typ IDuotoneEffectiveData zpřístupňuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`color1`](/slides/python-net/cs/aspose.slides.effects/iduotoneeffectivedata/color1/) | Vrací cílový formát barvy pro tmavé pixely.<br/>            Pouze pro čtení [`Color`](/slides/python-net/cs/aspose.slides/color). |
| [`color2`](/slides/python-net/cs/aspose.slides.effects/iduotoneeffectivedata/color2/) | Vrací cílový formát barvy pro světlé pixely.<br/>            Pouze pro čtení [`Color`](/slides/python-net/cs/aspose.slides/color). |
