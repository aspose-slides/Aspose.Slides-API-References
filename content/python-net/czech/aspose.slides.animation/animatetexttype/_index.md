## Výčet AnimateTextType

Reprezentuje typ animovaného textu animačního efektu.

Typ AnimateTextType obsahuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| ALL_AT_ONCE | Animovat celý text najednou. |
| BY_WORD | Animovat text po slovech. |
| BY_LETTER | Animovat text po znacích. |
