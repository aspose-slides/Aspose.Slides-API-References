## AnimationTimeLine třída

Representuje časovou osu animace.

Typ AnimationTimeLine poskytuje následující členy:

## Vlastnosti

| Property | Description |
| :- | :- |
| [`interactive_sequences`](/slides/python-net/cs/aspose.slides.animation/animationtimeline/interactive_sequences/) | Vrací kolekci interaktivních sekvencí.<br/>            Tyto sekvence mohou obsahovat pouze efekty pomocí "click on shape" s určeným cílovým tvarem.<br/>            Pouze pro čtení [`ISequenceCollection`](/slides/python-net/cs/aspose.slides.animation/isequencecollection). |
| [`main_sequence`](/slides/python-net/cs/aspose.slides.animation/animationtimeline/main_sequence/) | Vrací hlavní sekvenci, která může obsahovat pouze kolekci hlavních efektů.<br/>            Pouze pro čtení [`ISequence`](/slides/python-net/cs/aspose.slides.animation/isequence). |
| [`text_animation_collection`](/slides/python-net/cs/aspose.slides.animation/animationtimeline/text_animation_collection/) | Vrací kolekci textových animací.<br/>            Pouze pro čtení [`ITextAnimationCollection`](/slides/python-net/cs/aspose.slides.animation/itextanimationcollection). |
