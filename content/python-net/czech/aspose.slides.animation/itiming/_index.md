## třída ITiming

Reprezentuje časování animace.

Typ ITiming obsahuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`accelerate`](/slides/python-net/cs/aspose.slides.animation/itiming/accelerate/) | Popisuje procento trvání efektu zrychlení.<br/>            Read/write **float**. |
| [`decelerate`](/slides/python-net/cs/aspose.slides.animation/itiming/decelerate/) | Popisuje procento trvání efektu zpomalení.<br/>            Read/write **float**. |
| [`auto_reverse`](/slides/python-net/cs/aspose.slides.animation/itiming/auto_reverse/) | Popisuje, zda se má animace po přehrání dopředu automaticky přehrát pozpátku.<br/>            Read/write **bool**. |
| [`duration`](/slides/python-net/cs/aspose.slides.animation/itiming/duration/) | Popisuje trvání efektu animace.<br/>            Read/write **float**. |
| [`repeat_count`](/slides/python-net/cs/aspose.slides.animation/itiming/repeat_count/) | Popisuje, kolikrát se má efekt opakovat.<br/>            Read/write **float**. |
| [`repeat_until_end_slide`](/slides/python-net/cs/aspose.slides.animation/itiming/repeat_until_end_slide/) | Tento atribut určuje, zda se efekt bude opakovat až do konce snímku.<br/>             Read/write **bool**. |
| [`repeat_until_next_click`](/slides/python-net/cs/aspose.slides.animation/itiming/repeat_until_next_click/) | Tento atribut určuje, zda se efekt bude opakovat až do dalšího kliknutí.<br/>             Read/write **bool**. |
| [`repeat_duration`](/slides/python-net/cs/aspose.slides.animation/itiming/repeat_duration/) | Popisuje, kolikrát se má efekt opakovat.<br/>            Read/write **float**. |
| [`restart`](/slides/python-net/cs/aspose.slides.animation/itiming/restart/) | Určuje, zda se má efekt po dokončení restartovat.<br/>            Read/write [`EffectRestartType`](/slides/python-net/cs/aspose.slides.animation/effectrestarttype). |
| [`speed`](/slides/python-net/cs/aspose.slides.animation/itiming/speed/) | Určuje procento, o které se má časování zrychlit (nebo zpomalit).<br/>            Read/write **float**. |
| [`trigger_delay_time`](/slides/python-net/cs/aspose.slides.animation/itiming/trigger_delay_time/) | Popisuje dobu zpoždění po spuštění.<br/>            Read/write **float**. |
| [`trigger_type`](/slides/python-net/cs/aspose.slides.animation/itiming/trigger_type/) | Popisuje typ spouštění.<br/>            Read/write [`EffectTriggerType`](/slides/python-net/cs/aspose.slides.animation/effecttriggertype). |
| [`rewind`](/slides/python-net/cs/aspose.slides.animation/itiming/rewind/) | Tento atribut určuje, zda se po přehrání efekt přetáčí zpět.<br/>             Read/write **bool**. |
