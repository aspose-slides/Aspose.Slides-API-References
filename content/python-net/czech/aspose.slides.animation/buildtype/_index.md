## BuildType výčet

Určuje, jak se text objeví na tvaru během animace.

Typ BuildType vystavuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| AS_ONE_OBJECT | S obsahujícím tvarem. |
| ALL_PARAGRAPHS_AT_ONCE | Všechny odstavce. |
| BY_LEVEL_PARAGRAPHS1 | Podle skupin odstavců hloubky 1. |
| BY_LEVEL_PARAGRAPHS2 | Podle skupin odstavců hloubky 2. |
| BY_LEVEL_PARAGRAPHS3 | Podle skupin odstavců hloubky 3. |
| BY_LEVEL_PARAGRAPHS4 | Podle skupin odstavců hloubky 4. |
| BY_LEVEL_PARAGRAPHS5 | Podle skupin odstavců hloubky 5. |
