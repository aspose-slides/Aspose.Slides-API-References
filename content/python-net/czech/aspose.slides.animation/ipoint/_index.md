## IPoint třída

Reprezentuje animační bod.

Typ IPoint vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`time`](/slides/python-net/cs/aspose.slides.animation/ipoint/time/) | Representuje časovou hodnotu.<br/>            Čtení/Zápis **float**. |
| [`value`](/slides/python-net/cs/aspose.slides.animation/ipoint/value/) | Representuje hodnotu bodu.<br/>            Pouze: bool, ColorFormat, float, int, string.<br/>            Čtení/Zápis **any**. |
| [`formula`](/slides/python-net/cs/aspose.slides.animation/ipoint/formula/) | Vzorce v hodnotách, from, to, by atributech mohou být tvořeny těmito:<br/>            Standardní aritmetické operátory: ‘+’, ‘-‘, ‘*’, ‘/’, ‘^’, ‘%’ (mod)<br/>            Konstanty: ‘pi’ ‘e’<br/>            Podmíněné operátory: ‘abs’, ‘min’, ‘max’, ‘?’ (if)<br/>            Porovnávací operátory: '==', '>=', '', '!=', '!'<br/>            Trigonometrické operátory: ‘sin()’, ‘cos()’, ‘tan()’, ‘asin()’, ‘acos()’, ‘atan()’<br/>            Přirozený logarithmus ‘ln()’<br/>            Odkazy na vlastnosti (host podporované vlastnosti)<br/>            <br/>            například: "#ppt_x+(cos(-2*pi*(1-$))*-#ppt_x-sin(-2*pi*(1-$))*(1-#ppt_y))*(1-$)"<br/>            Čtení/Zápis **str**. |
