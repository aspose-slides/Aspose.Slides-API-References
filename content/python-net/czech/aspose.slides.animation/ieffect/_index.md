## třída IEffect

Reprezentuje animační efekt.

Typ IEffect vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`sequence`](/slides/python-net/cs/aspose.slides.animation/ieffect/sequence/) | Vrací sekvenci pro efekt.<br/>            Jen ke čtení [`ISequence`](/slides/python-net/cs/aspose.slides.animation/isequence). |
| [`text_animation`](/slides/python-net/cs/aspose.slides.animation/ieffect/text_animation/) | Vrací textovou animaci.<br/>            Jen ke čtení [`ITextAnimation`](/slides/python-net/cs/aspose.slides.animation/itextanimation). |
| [`preset_class_type`](/slides/python-net/cs/aspose.slides.animation/ieffect/preset_class_type/) | Definuje třídu efektu.<br/>            Čtení/zápis [`EffectPresetClassType`](/slides/python-net/cs/aspose.slides.animation/effectpresetclasstype). |
| [`type`](/slides/python-net/cs/aspose.slides.animation/ieffect/type/) | Definuje typ efektu.<br/>            Čtení/zápis [`EffectType`](/slides/python-net/cs/aspose.slides.animation/effecttype). |
| [`subtype`](/slides/python-net/cs/aspose.slides.animation/ieffect/subtype/) | Definuje podtyp efektu.<br/>            Čtení/zápis [`EffectSubtype`](/slides/python-net/cs/aspose.slides.animation/effectsubtype). |
| [`behaviors`](/slides/python-net/cs/aspose.slides.animation/ieffect/behaviors/) | Vrací kolekci chování pro efekt.<br/>            Čtení/zápis [`IBehaviorCollection`](/slides/python-net/cs/aspose.slides.animation/ibehaviorcollection). |
| [`timing`](/slides/python-net/cs/aspose.slides.animation/ieffect/timing/) | Definuje časovou hodnotu pro efekt.<br/>            Čtení/zápis [`ITiming`](/slides/python-net/cs/aspose.slides.animation/itiming). |
| [`target_shape`](/slides/python-net/cs/aspose.slides.animation/ieffect/target_shape/) | Vrací cílový tvar pro efekt.<br/>            Jen ke čtení [`IShape`](/slides/python-net/cs/aspose.slides/ishape). |
| [`sound`](/slides/python-net/cs/aspose.slides.animation/ieffect/sound/) | Definuje vložený zvuk pro efekt.<br/>            Čtení/zápis [`IAudio`](/slides/python-net/cs/aspose.slides/iaudio). |
| [`stop_previous_sound`](/slides/python-net/cs/aspose.slides.animation/ieffect/stop_previous_sound/) | Tento atribut specifikuje, zda animační efekt zastaví předchozí zvuk.<br/>            Čtení/zápis **bool**. |
| [`after_animation_type`](/slides/python-net/cs/aspose.slides.animation/ieffect/after_animation_type/) | Definuje typ následné animace pro efekt.<br/>            Čtení/zápis [`IEffect.after_animation_type`](/slides/python-net/cs/aspose.slides.animation/ieffect/after_animation_type). |
| [`after_animation_color`](/slides/python-net/cs/aspose.slides.animation/ieffect/after_animation_color/) | Definuje barvu následné animace pro efekt.<br/>            Čtení/zápis [`IColorFormat`](/slides/python-net/cs/aspose.slides/icolorformat). |
| [`animate_text_type`](/slides/python-net/cs/aspose.slides.animation/ieffect/animate_text_type/) | Definuje typ animovaného textu pro efekt.<br/>            Text tvaru může být animován po písmenu, po slově nebo najednou.<br/>            Čtení/zápis [`IEffect.animate_text_type`](/slides/python-net/cs/aspose.slides.animation/ieffect/animate_text_type). |
| [`delay_between_text_parts`](/slides/python-net/cs/aspose.slides.animation/ieffect/delay_between_text_parts/) | Definuje zpoždění mezi částmi animovaného textu (slovy nebo písmeny).<br/>            Kladná hodnota určuje procento trvání efektu.<br/>            Záporná hodnota určuje zpoždění v sekundách.<br/>            Čtení/zápis **float**. |
