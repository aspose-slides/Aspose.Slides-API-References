## AfterAnimationType výčet

Reprezentuje typ po animaci animačního efektu.

Typ AfterAnimationType poskytuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| DO_NOT_DIM | Neztlumovat po typu animace. |
| COLOR | Barva po typu animace. |
| HIDE_AFTER_ANIMATION | Skrýt po typu animace |
| HIDE_ON_NEXT_MOUSE_CLICK | Skrýt při dalším kliknutí myši po typu animace. |
