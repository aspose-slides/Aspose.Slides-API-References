## třída Timing

Představuje časování animace.

Typ Timing vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`accelerate`](/slides/python-net/cs/aspose.slides.animation/timing/accelerate/) | Popisuje procento trvání efektu zrychlení chování.<br/>            Číst/zapisovat **float**. |
| [`decelerate`](/slides/python-net/cs/aspose.slides.animation/timing/decelerate/) | Popisuje procento trvání efektu zpomalení chování.<br/>            Číst/zapisovat **float**. |
| [`auto_reverse`](/slides/python-net/cs/aspose.slides.animation/timing/auto_reverse/) | Popisuje, zda se má animace po přehrání dopředu automaticky přehrát pozpátku.<br/>            Číst/zapisovat **bool**. |
| [`duration`](/slides/python-net/cs/aspose.slides.animation/timing/duration/) | Popisuje dobu trvání efektu animace.<br/>            Číst/zapisovat **float**. |
| [`repeat_count`](/slides/python-net/cs/aspose.slides.animation/timing/repeat_count/) | Popisuje počet opakování efektu.<br/>            Číst/zapisovat **float**. |
| [`repeat_until_end_slide`](/slides/python-net/cs/aspose.slides.animation/timing/repeat_until_end_slide/) | Tento atribut určuje, zda se efekt bude opakovat až do konce snímku.<br/>             Číst/zapisovat **bool**. |
| [`repeat_until_next_click`](/slides/python-net/cs/aspose.slides.animation/timing/repeat_until_next_click/) | Tento atribut určuje, zda se efekt bude opakovat až do dalšího kliknutí.<br/>             Číst/zapisovat **bool**. |
| [`repeat_duration`](/slides/python-net/cs/aspose.slides.animation/timing/repeat_duration/) | Popisuje počet opakování efektu.<br/>            Číst/zapisovat **float**. |
| [`restart`](/slides/python-net/cs/aspose.slides.animation/timing/restart/) | Určuje, zda se má efekt po dokončení restartovat.<br/>            Číst/zapisovat [`EffectRestartType`](/slides/python-net/cs/aspose.slides.animation/effectrestarttype). |
| [`rewind`](/slides/python-net/cs/aspose.slides.animation/timing/rewind/) | Tento atribut určuje, zda se efekt po přehrání přetočí zpět.<br/>             Číst/zapisovat **bool**. |
| [`speed`](/slides/python-net/cs/aspose.slides.animation/timing/speed/) | Určuje procento, o které se má časování zrychlit (nebo zpomalit).<br/>            Číst/zapisovat **float**. |
| [`trigger_delay_time`](/slides/python-net/cs/aspose.slides.animation/timing/trigger_delay_time/) | Popisuje čas zpoždění po spouštěči.<br/>            Číst/zapisovat **float**. |
| [`trigger_type`](/slides/python-net/cs/aspose.slides.animation/timing/trigger_type/) | Popisuje typ spouštěče.<br/>            Číst/zapisovat [`EffectTriggerType`](/slides/python-net/cs/aspose.slides.animation/effecttriggertype). |
