## IFontSchemeEffectiveData class

Neměnný objekt, který obsahuje efektivní vlastnosti schématu písem.

Typ IFontSchemeEffectiveData vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`minor`](/slides/python-net/cs/aspose.slides.theme/ifontschemeeffectivedata/minor/) | Vrací kolekci písem pro část "body" snímku.<br/>            Pouze pro čtení [`IFontsEffectiveData`](/slides/python-net/cs/aspose.slides/ifontseffectivedata). |
| [`major`](/slides/python-net/cs/aspose.slides.theme/ifontschemeeffectivedata/major/) | Vrací kolekci písem pro část "heading" snímku.<br/>            Pouze pro čtení [`IFontsEffectiveData`](/slides/python-net/cs/aspose.slides/ifontseffectivedata). |
| [`name`](/slides/python-net/cs/aspose.slides.theme/ifontschemeeffectivedata/name/) | Vrací název schématu písem.<br/>            Pouze pro čtení **str**. |
