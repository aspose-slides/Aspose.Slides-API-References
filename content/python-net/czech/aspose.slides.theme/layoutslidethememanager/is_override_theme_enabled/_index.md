## is_override_theme_enabled vlastnost
Určuje, zda OverrideTheme přepisuje zděděné efektivní téma, nebo ne.
            Pro povolení přepisování pomocí OverrideTheme použijte metody OverrideTheme.Init*().
            Pro zakázání přepisování OverrideTheme použijte metodu OverrideTheme.Clear().
            Pouze pro čtení **bool**.
