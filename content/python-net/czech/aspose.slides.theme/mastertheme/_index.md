## třída MasterTheme

Reprezentuje hlavní motiv.

**Dědičnost:**[`MasterTheme`](/slides/python-net/cs/aspose.slides.theme/mastertheme) → [`Theme`](/slides/python-net/cs/aspose.slides.theme/theme)

Typ MasterTheme obsahuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`color_scheme`](/slides/python-net/cs/aspose.slides.theme/mastertheme/color_scheme/) | Vrací barevné schéma.<br/>            Pouze pro čtení [`IColorScheme`](/slides/python-net/cs/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/cs/aspose.slides.theme/mastertheme/font_scheme/) | Vrací schéma písma.<br/>            Pouze pro čtení [`IFontScheme`](/slides/python-net/cs/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/cs/aspose.slides.theme/mastertheme/format_scheme/) | Vrací schéma formátu tvaru.<br/>            Pouze pro čtení [`IFormatScheme`](/slides/python-net/cs/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/cs/aspose.slides.theme/mastertheme/presentation/) | Vrací nadřazenou prezentaci.<br/>            Pouze pro čtení [`IPresentation`](/slides/python-net/cs/aspose.slides/ipresentation). |
| [`extra_color_schemes`](/slides/python-net/cs/aspose.slides.theme/mastertheme/extra_color_schemes/) | Vrací kolekci dalších barevných schémat.<br/>            Tato schémata nemají vliv na vzhled prezentace, mohou být vybrána jako hlavní barevné schéma pro snímek.<br/>            Pouze pro čtení [`IExtraColorSchemeCollection`](/slides/python-net/cs/aspose.slides.theme/iextracolorschemecollection). |
| [`name`](/slides/python-net/cs/aspose.slides.theme/mastertheme/name/) | Vrací název motivu.<br/>            Čtení/Zápis **str**. |
