## FontScheme třída

Ukládá písma definovaná motivem.

Typ FontScheme vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`minor`](/slides/python-net/cs/aspose.slides.theme/fontscheme/minor/) | Vrací kolekci písem pro část "body" snímku.<br/>            Jen pro čtení [`IFonts`](/slides/python-net/cs/aspose.slides/ifonts). |
| [`major`](/slides/python-net/cs/aspose.slides.theme/fontscheme/major/) | Vrací kolekci písem pro část "heading" snímku.<br/>            Jen pro čtení [`IFonts`](/slides/python-net/cs/aspose.slides/ifonts). |
| [`name`](/slides/python-net/cs/aspose.slides.theme/fontscheme/name/) | Vrací název schématu písma.<br/>            Čtení/zápis **str**. |
