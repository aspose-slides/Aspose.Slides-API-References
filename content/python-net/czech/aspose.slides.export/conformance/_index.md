## Výčtový typ shody

Určuje třídu shody, ke které dokument PresentationML odpovídá.

Typ Conformance poskytuje následující členy:

## Pole

| Field | Description |
| :- | :- |
| ECMA_376_2006 | Určuje, že dokument odpovídá standardu ECMA376:2006. |
| ISO_29500_2008_TRANSITIONAL | Určuje, že dokument odpovídá přechodné třídě shody ISO/IEC 29500:2008. |
| ISO_29500_2008_STRICT | Určuje, že dokument odpovídá přísné třídě shody ISO/IEC 29500:2008. |
