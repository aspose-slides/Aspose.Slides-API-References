## SaveFormat výčet

Konstanty, které definují formát uložené prezentace.

Typ SaveFormat exponuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| PPT | Uložit prezentaci ve formátu PPT. |
| PDF | Uložit prezentaci ve formátu PDF. |
| XPS | Uložit prezentaci ve formátu XPS. |
| PPTX | Uložit prezentaci ve formátu PPTX. |
| PPSX | Uložit prezentaci ve formátu PPSX (prezentace). |
| TIFF | Uložit prezentaci jako vícestránkový obrázek TIFF. |
| ODP | Uložit prezentaci ve formátu ODP. |
| PPTM | Uložit prezentaci ve formátu PPTM (prezentace s makry). |
| PPSM | Uložit prezentaci ve formátu PPSM (prezentace s makry). |
| POTX | Uložit prezentaci ve formátu POTX (šablona). |
| POTM | Uložit prezentaci ve formátu POTM (šablona s makry). |
| HTML | Uložit prezentaci ve formátu HTML. |
| SWF | Uložit prezentaci ve formátu SWF. |
| OTP | Uložit prezentaci ve formátu OTP (šablona prezentace). |
| PPS | Uložit prezentaci ve formátu PPS. |
| POT | Uložit prezentaci ve formátu POT. |
| FODP | Uložit prezentaci ve formátu FODP. |
| GIF | Uložit prezentaci ve formátu GIF. |
| HTML5 | Uložit prezentaci ve formátu HTML pomocí nového systému šablon HTML5. |
| MD | Uložit prezentaci ve formátu Markdown |
| XML | Uložit prezentaci ve formátu PowerPoint XML Presentation |
