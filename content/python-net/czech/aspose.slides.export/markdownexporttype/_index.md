## MarkdownExportType enumerace

Typ vykreslování dokumentu.

Typ MarkdownExportType obsahuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| SEQUENTIAL | Vykreslit všechny položky samostatně. Jednu po druhé. |
| TEXT_ONLY | Vykreslit pouze text. |
| VISUAL | Vykreslit všechny položky, položky, které jsou seskupeny - vykreslit společně. |
