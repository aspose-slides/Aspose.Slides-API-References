## IGifOptions třída

Představuje možnosti exportu GIF.

Typ IGifOptions poskytuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`frame_size`](/slides/python-net/cs/aspose.slides.export/igifoptions/frame_size/) | Získá nebo nastaví velikost snímku. |
| [`export_hidden_slides`](/slides/python-net/cs/aspose.slides.export/igifoptions/export_hidden_slides/) | Určuje, zda budou skryté snímky exportovány.<br/>            Výchozí hodnota je false. |
| [`transition_fps`](/slides/python-net/cs/aspose.slides.export/igifoptions/transition_fps/) | Získá nebo nastaví FPS přechodu [frames/sec]<br/>            Výchozí hodnota je 25. |
| [`default_delay`](/slides/python-net/cs/aspose.slides.export/igifoptions/default_delay/) | Získá nebo nastaví výchozí prodlevu [ms].
