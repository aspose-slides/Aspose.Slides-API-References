## CommentsPositions enumerace

Reprezentuje pravidlo pro vykreslení komentářů v exportovaném dokumentu

Typ CommentsPositions vystavuje následující členy:

## Pole

| Field | Description |
| :- | :- |
| NONE | Určuje, že komentáře se vůbec nezobrazí. |
| BOTTOM | Určuje, že komentáře se zobrazí v dolní části stránky. |
| RIGHT | Určuje, že komentáře se zobrazí vpravo od stránky. |
