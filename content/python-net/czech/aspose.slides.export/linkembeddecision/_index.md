## LinkEmbedDecision enumerace

Určuje, jak bude objekt zpracován během ukládání.

Typ LinkEmbedDecision vystavuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| LINK | Objekt bude uložen externě, odkazován pomocí URL |
| EMBED | Objekt by měl být vložen do vygenerovaného souboru, pokud je to možné. Pokud vložení není možné, bude zavolána metoda GetUrl a v závislosti na výsledku bude objekt odkazován pomocí URL nebo bude ignorován. |
| IGNORE | Objekt bude ignorován. |
