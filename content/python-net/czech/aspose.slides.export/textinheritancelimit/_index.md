## TextInheritanceLimit enumeration

Řídí hloubku dědičnosti textových vlastností.

Typ TextInheritanceLimit exponuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| ALL | Všechny textové vlastnosti. |
| TEXT_BOX | Dědit pouze ze stylu TextFrame. |
| PARAGRAPH_ONLY | Použít pouze vlastnosti definované pro odstavec. |
