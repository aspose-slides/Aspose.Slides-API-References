## root_directory_clsid vlastnost
Reprezentuje GUID třídy objektu (CLSID), který je uložen v záznamu kořenového adresáře. Lze použít pro COM
aktivaci aplikace dokumentu.
Výchozí hodnota je '64818D11-4F9B-11CF-86EA-00AA00B929E8', která odpovídá 'Microsoft Powerpoint.Slide.8'.
