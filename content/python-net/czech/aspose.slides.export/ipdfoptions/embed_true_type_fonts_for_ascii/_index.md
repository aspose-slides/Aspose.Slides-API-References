## embed_true_type_fonts_for_ascii vlastnost
True pro vložení TrueType fontů pro ASCII znaky 32-127.
            Fonty pro kódy znaků větší než 127 jsou vždy vloženy.
            Číst/zapisovat **bool**.

### Poznámky

Výchozí hodnota je **true** .
