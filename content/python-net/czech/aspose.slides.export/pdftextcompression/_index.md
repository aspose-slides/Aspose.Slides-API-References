## PdfTextCompression výčet

Konstanty, které určují typ komprese použité na celý obsah PDF souboru kromě obrázků.

Typ PdfTextCompression poskytuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| NONE | Žádná komprese. |
| FLATE | Flate (ZIP) komprese. |
