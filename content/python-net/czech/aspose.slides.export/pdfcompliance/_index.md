# PdfCompliance enumerace

Konstanty, které definují úroveň souladu se standardy PDF.

Typ PdfCompliance obsahuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| PDF15 | Výstupní soubor bude vyhovovat standardu PDF 1.5. |
| PDF16 | Výstupní soubor bude vyhovovat standardu PDF 1.6. |
| PDF17 | Výstupní soubor bude vyhovovat standardu PDF 1.7. |
| PDF_A1B | Výstupní soubor bude vyhovovat standardu PDF/A-1b. |
| PDF_A1A | Výstupní soubor bude vyhovovat standardu PDF/A-1a. |
| PDF_A2B | Výstupní soubor bude vyhovovat standardu PDF/A-2b. |
| PDF_A2A | Výstupní soubor bude vyhovovat standardu PDF/A-2a. |
| PDF_A3B | Výstupní soubor bude vyhovovat standardu PDF/A-3b. |
| PDF_A3A | Výstupní soubor bude vyhovovat standardu PDF/A-3a. |
| PDF_UA | Výstupní soubor bude vyhovovat standardu PDF/UA. |
| PDF_A2U | Výstupní soubor bude vyhovovat standardu PDF/A-2u. |
