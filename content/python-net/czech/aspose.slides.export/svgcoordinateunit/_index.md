## SvgCoordinateUnit enumerace

Representuje jednotky souřadnic CSS2 používané k definování souřadnic SVG.

Typ SvgCoordinateUnit obsahuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| INCH | palec |
| CENTIMETER | centimetr. |
| MILLIMETER | milimetr. |
| POINT | Bod (1/72 palce), |
| PICA | Pica (1/6 palce). |
| EM | Velikost em písma obsahujícího prvku. |
| EX | Velikost ex (velikost malého písmena, obvykle "x") písma obsahujícího prvku. |
| PIXEL | Velikost pixelu. |
| PERCENT | Procento. |
