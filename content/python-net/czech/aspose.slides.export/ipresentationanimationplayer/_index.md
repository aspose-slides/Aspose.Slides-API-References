## IPresentationAnimationPlayer třída

Reprezentuje přehrávač animace.
            
            Animace generované [`PresentationAnimationsGenerator`](/slides/python-net/cs/aspose.slides.export/presentationanimationsgenerator) prostřednictvím její události **NewAnimation**.

Typ IPresentationAnimationPlayer vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`duration`](/slides/python-net/cs/aspose.slides.export/ipresentationanimationplayer/duration/) | Získat dobu trvání animace [ms] |

## Metody

| Metoda | Popis |
| :- | :- |
| [`set_time_position(self, time)`](/slides/python-net/cs/aspose.slides.export/ipresentationanimationplayer/set_time_position/#float) | Nastavit časovou pozici animace v rámci [`IPresentationAnimationPlayer.duration`](/slides/python-net/cs/aspose.slides.export/ipresentationanimationplayer/duration). |
| [`get_frame(self)`](/slides/python-net/cs/aspose.slides.export/ipresentationanimationplayer/get_frame/#) | Získat snímek pro aktuální časovou pozici dříve nastavenou pomocí metody **Aspose.Slides.Export.IPresentationAnimationPlayer.SetTimePosition(Syste**. |
