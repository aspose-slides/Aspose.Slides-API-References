## TiffCompressionTypes enumerace

Poskytuje možnosti, které řídí, jak je prezentace komprimována ve formátu TIFF.

Typ TiffCompressionTypes vystavuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| DEFAULT | Určuje výchozí kompresní schéma (LZW). |
| NONE | Určuje žádnou kompresi. |
| CCITT3 | Určuje kompresní schéma CCITT3. |
| CCITT4 | Určuje kompresní schéma CCITT4. |
| LZW | Určuje kompresní schéma LZW (výchozí). |
| RLE | Určuje kompresní schéma RLE. |
