## enumerace SvgEvent

Představuje možnosti pro tvar SVG.

Typ SvgEvent poskytuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| ON_FOCUS_IN | Vyskytne se, když prvek získá zaměření, například když je text vybrán. |
| ON_FOCUS_OUT | Vyskytne se, když prvek ztratí zaměření, například když je text odznačen. |
| ON_ACTIVATE | Vyskytne se, když je prvek aktivován, například kliknutím myši nebo stisknutím klávesy. |
| ON_CLICK | Vyskytne se, když je tlačítko ukazovacího zařízení kliknuto nad prvkem. |
| ON_MOUSE_DOWN | Vyskytne se, když je tlačítko ukazovacího zařízení stisknuto nad prvkem. |
| ON_MOUSE_UP | Vyskytne se, když je tlačítko ukazovacího zařízení uvolněno nad prvkem. |
| ON_MOUSE_OVER | Vyskytne se, když je ukazovací zařízení přesunuto na prvek. |
| ON_MOUSE_MOVE | Vyskytne se, když je ukazovací zařízení přesunuto, zatímco je nad prvkem. |
| ON_MOUSE_OUT | Vyskytne se, když je ukazovací zařízení přesunuto pryč od prvku. |
| ON_LOAD | Vyskytne se, když uživatelský agent plně zpracuje prvek a jeho potomky a všechny odkazované zdroje potřebné k jeho vykreslení. |
| ON_UNLOAD | Vyskytne se, když implementace DOM odebere dokument z okna nebo rámce. Platí pouze pro vnější SVG prvky. |
| ON_ABORT | Vyskytne se, když je načítání stránky zastaveno, dříve než byl prvek povolen načíst se úplně. |
| ON_ERROR | Vyskytne se, když se prvek nenačte správně nebo když během vykonávání skriptu nastane chyba. |
| ON_RESIZE | Vyskytne se, když dochází ke změně velikosti pohledu dokumentu. Platí pouze pro vnější SVG prvky. |
| ON_SCROLL | Vyskytne se, když je pohled dokumentu posunut podél osy X, Y nebo obou. Platí pouze pro vnější SVG prvky. |
| ON_ZOOM | Vyskytne se, když se mění úroveň přiblížení pohledu dokumentu. Platí pouze pro vnější SVG prvky. |
| ON_BEGIN | Vyskytne se, když animovaný prvek začne. |
| ON_END | Vyskytne se, když animovaný prvek skončí. |
| ON_REPEAT | Vyskytne se, když se animovaný prvek opakuje. |
