## Výčtový typ CompressionLevel

Určuje úrovně komprese ZIP pro soubor OpenXML.  
Vyšší úrovně poskytují lepší kompresi za cenu pomalejšího zpracování.

Typ CompressionLevel obsahuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| NONE | Nenastavuje se žádná komprese. Soubory jsou uloženy tak, jak jsou. |
| LEVEL1 | Nejrychlejší komprese s nejnižším poměrem komprese. |
| LEVEL2 | Rychlejší komprese s mírně lepším poměrem komprese než [`CompressionLevel.LEVEL1`](/slides/python-net/cs/aspose.slides.export/compressionlevel/LEVEL1). |
| LEVEL3 | Poskytuje lepší kompresi než [`CompressionLevel.LEVEL2`](/slides/python-net/cs/aspose.slides.export/compressionlevel/LEVEL2) při středním dopadu na výkon. |
| LEVEL4 | Poskytuje lepší kompresi než [`CompressionLevel.LEVEL3`](/slides/python-net/cs/aspose.slides.export/compressionlevel/LEVEL3). |
| LEVEL5 | Poskytuje vylepšenou kompresi oproti [`CompressionLevel.LEVEL4`](/slides/python-net/cs/aspose.slides.export/compressionlevel/LEVEL4) s dodatečným časem zpracování. |
| LEVEL6 | Standardní komprese, nabízející dobrý poměr mezi rychlostí komprese a velikostí souboru.<br/>            Výchozí úroveň komprese. |
| LEVEL7 | Poskytuje vyšší kompresi než [`CompressionLevel.LEVEL6`](/slides/python-net/cs/aspose.slides.export/compressionlevel/LEVEL6) při pomalejším zpracování. |
| LEVEL8 | Poskytuje vyšší kompresi než [`CompressionLevel.LEVEL7`](/slides/python-net/cs/aspose.slides.export/compressionlevel/LEVEL7). |
| LEVEL9 | Maximální komprese. Vytváří nejmenší velikost souboru při nejpomalejší rychlosti zpracování. |
