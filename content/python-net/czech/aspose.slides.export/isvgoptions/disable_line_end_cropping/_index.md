## disable_line_end_cropping vlastnost
SVG 1.1 postrádá možnost definovat odsazení pro značky.
            Aspose.Slides SVG writing engine má pro tento problém řešení:
            ořízne konec čáry s šipkou, takže čára nepřekrývá značky.
            Tato volba vypíná takové chování.
            Čtení/zápis **bool**.
