## skip_java_script_links vlastnost
Určuje, zda při ukládání prezentace přeskočit hypertextové odkazy s voláním JavaScriptu. 
            Číst/zapisovat **bool**. Výchozí hodnota je **false** .


### Poznámky

Když je tato vlastnost nastavena na **true**, hypertextové odkazy s voláním JavaScriptu budou při ukládání ignorovány.

Když je tato vlastnost nastavena na **false**, budou uloženy všechny hypertextové odkazy.
