## BlackWhiteConversionMode enumerace

Poskytuje možnosti, které řídí, jak budou obrázky snímků převedeny na bitové obrazy.

Typ BlackWhiteConversionMode obsahuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| DEFAULT | Určuje žádný převodní algoritmus. Použije se algoritmus implementovaný v kodeku TIFF. (Výchozí) |
| DITHERING | Určuje algoritmus rozptýlení (Floyd-Steinberg). |
| DITHERING_FLOYD_STEINBERG | Určuje algoritmus Floyd-Steinberg rozptýlení. |
| AUTO | Určuje automaticky vypočítaný prahový algoritmus (Otsu). |
| AUTO_OTSU | Určuje automaticky vypočítaný Otsuův prahový algoritmus. |
| THRESHOLD25 | Určuje statický prahový algoritmus (25%). |
| THRESHOLD50 | Určuje statický prahový algoritmus (50%). |
| THRESHOLD75 | Určuje statický prahový algoritmus (75%). |
