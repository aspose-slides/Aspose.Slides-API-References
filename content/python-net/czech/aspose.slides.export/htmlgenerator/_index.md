## HtmlGenerator třída

Generátor HTML.

Typ HtmlGenerator obsahuje následující členy:

## Vlastnosti

| Property | Popis |
| :- | :- |
| [`slide_image_size`](/slides/python-net/cs/aspose.slides.export/htmlgenerator/slide_image_size/) | Vrací velikost snímku.<br/>            Pouze pro čtení [`SizeF`](/slides/python-net/cs/aspose.slides/sizef). |
| [`slide_image_size_unit`](/slides/python-net/cs/aspose.slides.export/htmlgenerator/slide_image_size_unit/) | Vrací jednotku, ve které je velikost snímku určena.<br/>            Pouze pro čtení [`SvgCoordinateUnit`](/slides/python-net/cs/aspose.slides.export/svgcoordinateunit). |
| [`slide_image_size_unit_code`](/slides/python-net/cs/aspose.slides.export/htmlgenerator/slide_image_size_unit_code/) | Vrací CSS kód jednotky, ve které je velikost snímku určena.<br/>            Pouze pro čtení **str**. |
| [`previous_slide_index`](/slides/python-net/cs/aspose.slides.export/htmlgenerator/previous_slide_index/) | Vrací index předchozího vykresleného snímku nebo -1, pokud se vykresluje první snímek.<br/>            Pouze pro čtení **int**. |
| [`slide_index`](/slides/python-net/cs/aspose.slides.export/htmlgenerator/slide_index/) | Vrací index aktuálně vykreslovaného snímku.<br/>            Pouze pro čtení **int**. |
| [`next_slide_index`](/slides/python-net/cs/aspose.slides.export/htmlgenerator/next_slide_index/) | Vrací index snímku, který bude vykreslen po aktuálním snímku, nebo -1, pokud je právě vykreslován poslední snímek.<br/>            Pouze pro čtení **int**. |
