## EmbedFontCharacters výčet

Reprezentuje pravidlo pro přidání nového fontu pro vložení do [`IPresentation`](/slides/python-net/cs/aspose.slides/ipresentation)

Typ EmbedFontCharacters poskytuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| ONLY_USED | Vložit pouze znaky použité v prezentaci (nejlepší pro snížení velikosti souboru). |
| ALL | Vložit všechny znaky (nejlepší pro úpravy ostatními lidmi). |
