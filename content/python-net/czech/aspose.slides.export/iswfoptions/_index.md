## ISwfOptions třída

Provides options that control how a presentation is saved in SWF format.

The ISwfOptions type exposes the following members:

| [`compressed`](/slides/python-net/cs/aspose.slides.export/iswfoptions/compressed/) | Určuje, zda má být generovaný SWF dokument komprimován nebo ne.<br/>            Výchozí hodnota je `true`. |
