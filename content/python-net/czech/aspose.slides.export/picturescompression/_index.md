## PicturesCompression enumerace

Reprezentuje úroveň komprese obrázků

Typ PicturesCompression obsahuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| DPI330 | Dobrá kvalita pro displeje vysokého rozlišení (HD) |
| DPI220 | Vynikající kvalita na většině tiskáren a obrazovek |
| DPI150 | Dobré pro webové stránky a projektory |
| DPI96 | Minimalizuje velikost dokumentu pro sdílení |
| DPI72 | Výchozí úroveň komprese |
| DOCUMENT_RESOLUTION | Použít rozlišení dokumentu – obrázek nebude komprimován a bude použit v dokumentu tak, jak je |
