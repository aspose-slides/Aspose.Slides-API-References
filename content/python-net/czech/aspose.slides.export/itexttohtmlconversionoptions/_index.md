## ITextToHtmlConversionOptions třída

Možnosti pro extrahování HTML z textu Pptx.

Typ ITextToHtmlConversionOptions poskytuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`add_clipboard_fragment_header`](/slides/python-net/cs/aspose.slides.export/itexttohtmlconversionoptions/add_clipboard_fragment_header/) | Vrací nebo nastavuje hodnotu, která určuje, zda mají být přidány hlavičky schránky.<br/>            Read/write **bool**. |
| [`text_inheritance_limit`](/slides/python-net/cs/aspose.slides.export/itexttohtmlconversionoptions/text_inheritance_limit/) | Vrací nebo nastavuje vloženou hloubku pro textové vlastnosti.<br/>            Read/write [`ITextToHtmlConversionOptions.text_inheritance_limit`](/slides/python-net/cs/aspose.slides.export/itexttohtmlconversionoptions/text_inheritance_limit). |
| [`link_embed_controller`](/slides/python-net/cs/aspose.slides.export/itexttohtmlconversionoptions/link_embed_controller/) | Vrací nebo nastavuje objekt zpětného volání, který řídí, jak bude externí objekt uložen.<br/>            Read/write [`ILinkEmbedController`](/slides/python-net/cs/aspose.slides.export/ilinkembedcontroller). |
| [`encoding_name`](/slides/python-net/cs/aspose.slides.export/itexttohtmlconversionoptions/encoding_name/) | Vrací nebo nastavuje název kódování html.<br/>            Tato hodnota bude uložena do vygenerovaného souboru HTML, ale je na volajícím, aby zajistil, že soubor bude uložen v tomto kódování.<br/>            Read/write **str**. |
