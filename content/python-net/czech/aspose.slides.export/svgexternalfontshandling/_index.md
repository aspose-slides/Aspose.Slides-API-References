## SvgExternalFontsHandling enumerace

Representuje způsob, jak zacházet s externími fonty používanými pro kreslení textu.

Typ SvgExternalFontsHandling obsahuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| ADD_LINKS_TO_FONT_FILES | Přidat odkazy na samostatné soubory fontů do sekce style v souboru SVG. |
| EMBED | Uložit data fontů přímo do souboru SVG. Před použitím této možnosti zkontrolujte licenční smlouvy všech externích fontů. |
| VECTORIZE | Uložit celý text s externími fonty jako grafiku. |
