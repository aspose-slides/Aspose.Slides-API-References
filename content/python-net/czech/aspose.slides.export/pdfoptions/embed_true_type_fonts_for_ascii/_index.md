## embed_true_type_fonts_for_ascii vlastnost
Určuje, zda Aspose.Slides vloží běžná písma pro text v rozmezí kódů ASCII (33..127).
Písma pro znakové kódy vyšší než 127 jsou vždy vložena.
Seznam běžných písem zahrnuje základních 14 písem PDF a další uživatelem specifikovaná písma.
Čtení/zápis **bool**.

### Poznámky

Výchozí hodnota je **true**.
