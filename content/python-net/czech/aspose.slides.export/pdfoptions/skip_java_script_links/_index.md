## skip_java_script_links vlastnost
Určuje, zda při ukládání prezentace přeskakovat hypertextové odkazy s voláním JavaScriptu. 
            Číst/zapisovat **bool**. Výchozí hodnota je **false** .


### Poznámky

Když je tato vlastnost nastavena na **true**, budou při ukládání hypertextové odkazy s voláním JavaScriptu ignorovány.


Když je tato vlastnost nastavena na **false**, budou všechny hypertextové odkazy uloženy.
