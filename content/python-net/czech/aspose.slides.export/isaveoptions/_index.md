## ISaveOptions třída

Možnosti, které řídí, jak je prezentace uložena.

Typ ISaveOptions poskytuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`warning_callback`](/slides/python-net/cs/aspose.slides.export/isaveoptions/warning_callback/) | Vrací nebo nastavuje objekt, který přijímá varování a rozhoduje, zda bude proces načítání pokračovat nebo bude přerušen.<br/>            Čtení/Zápis [`IWarningCallback`](/slides/python-net/cs/aspose.slides.warnings/iwarningcallback). |
| [`progress_callback`](/slides/python-net/cs/aspose.slides.export/isaveoptions/progress_callback/) | Reprezentuje objekt zpětného volání pro aktualizace postupu ukládání v procentech. <br/>            Viz [`IProgressCallback`](/slides/python-net/cs/aspose.slides/iprogresscallback). |
| [`default_regular_font`](/slides/python-net/cs/aspose.slides.export/isaveoptions/default_regular_font/) | Vrací nebo nastavuje písmo použité v případě, že výchozí písmo není nalezeno.<br/>            Čtení/Zápis **str**. |
| [`gradient_style`](/slides/python-net/cs/aspose.slides.export/isaveoptions/gradient_style/) | Vrací nebo nastavuje vizuální styl gradientu.<br/>            Čtení/Zápis [`GradientStyle`](/slides/python-net/cs/aspose.slides/gradientstyle). |
| [`skip_java_script_links`](/slides/python-net/cs/aspose.slides.export/isaveoptions/skip_java_script_links/) | Určuje, zda při ukládání prezentace přeskočit hypertextové odkazy s voláním JavaScriptu. <br/>            Čtení/Zápis **bool**. Výchozí hodnota je **false** . |
