## skip_java_script_links vlastnost
Specifies whether to skip hyperlinks with JavaScript calls when saving the presentation. 
            Čtení/Zápis **bool**. Výchozí hodnota je **false** .


### Poznámky

Když je tato vlastnost nastavena na **true**, budou hypertextové odkazy s voláním JavaScriptu při ukládání ignorovány.


Když je tato vlastnost nastavena na **false**, všechny hypertextové odkazy budou uloženy.
