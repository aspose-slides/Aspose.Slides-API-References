## IHtmlOptions třída

Představuje možnosti exportu HTML.

Typ IHtmlOptions obsahuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`html_formatter`](/slides/python-net/cs/aspose.slides.export/ihtmloptions/html_formatter/) | Vrací nebo nastavuje šablonu HTML.<br/>            Číst/zapisovat [`IHtmlFormatter`](/slides/python-net/cs/aspose.slides.export/ihtmlformatter). |
| [`slide_image_format`](/slides/python-net/cs/aspose.slides.export/ihtmloptions/slide_image_format/) | Vrací nebo nastavuje možnosti formátu obrázku snímku.<br/>            Číst/zapisovat [`ISlideImageFormat`](/slides/python-net/cs/aspose.slides.export/islideimageformat). |
| [`show_hidden_slides`](/slides/python-net/cs/aspose.slides.export/ihtmloptions/show_hidden_slides/) | Určuje, zda má vygenerovaný dokument zahrnovat skryté snímky nebo ne.<br/>            Výchozí hodnota je `false`. |
| [`jpeg_quality`](/slides/python-net/cs/aspose.slides.export/ihtmloptions/jpeg_quality/) | Vrací nebo nastavuje hodnotu určující kvalitu JPEG obrázků v PDF dokumentu.<br/>            Číst/zapisovat **int**. |
| [`pictures_compression`](/slides/python-net/cs/aspose.slides.export/ihtmloptions/pictures_compression/) | Representuje úroveň komprese obrázků<br/>            Číst/zapisovat [`IHtmlOptions.pictures_compression`](/slides/python-net/cs/aspose.slides.export/ihtmloptions/pictures_compression). |

Pokud je true, oříznuté <br/>            části budou odstraněny, pokud je false, budou v dokumentu serializovány (což může potenciálně vést k <br/>            většímu souboru)<br/>            Číst/zapisovat **bool**. |

| [`disable_font_ligatures`](/slides/python-net/cs/aspose.slides.export/ihtmloptions/disable_font_ligatures/) | Získá nebo nastaví hodnotu určující, zda je text vykreslen bez použití ligatur.<br/>            Když je nastavena na `true`, ligatury budou v renderovaném výstupu zakázány. Ve výchozím nastavení je tato vlastnost nastavena na `false`. |

| [`ink_options`](/slides/python-net/cs/aspose.slides.export/ihtmloptions/ink_options/) | Poskytuje možnosti, které řídí vzhled Ink objektů v exportovaném dokumentu.<br/>            Pouze pro čtení [`IInkOptions`](/slides/python-net/cs/aspose.slides.export/iinkoptions) |
