## value_type vlastnost
Representuje možné způsoby, jak určit délku chybových úseček. 
            V případě vlastního typu hodnoty použijte vlastnost [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/cs/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) konkrétního datového bodu ve sbírce DataPoints řady.
            V případě typu hodnoty Fixed, Percentage nebo StandardDeviation použijte vlastnost Value k určení hodnoty.  
            Číst/zapisovat [`ErrorBarValueType`](/slides/python-net/cs/aspose.slides.charts/errorbarvaluetype).
