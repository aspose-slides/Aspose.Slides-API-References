## LegendDataLabelPosition enumerace

Určuje umístění popisků dat.

Typ LegendDataLabelPosition poskytuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| NOT_DEFINED | Pozice není definována. |
| BOTTOM | Určuje, že popisky dat se zobrazí pod datovým ukazatelem. |
| BEST_FIT | Určuje, že popisky dat se zobrazí v nejvhodnější pozici. |
| CENTER | Určuje, že popisky dat se zobrazí vycentrovaně na datovém ukazateli. |
| INSIDE_BASE | Určuje, že popisky dat se zobrazí uvnitř základny datového ukazatele. |
| INSIDE_END | Určuje, že popisky dat se zobrazí uvnitř konce datového ukazatele. |
| LEFT | Určuje, že popisky dat se zobrazí vlevo od datového ukazatele. |
| OUTSIDE_END | Určuje, že popisky dat se zobrazí vně konce datového ukazatele. |
| RIGHT | Určuje, že popisky dat se zobrazí vpravo od datového ukazatele. |
| TOP | Určuje, že popisky dat se zobrazí nad datovým ukazatelem. |
