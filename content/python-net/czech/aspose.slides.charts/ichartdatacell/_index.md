## IChartDataCell třída

Představuje buňku pro data grafu.

Typ IChartDataCell obsahuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`row`](/slides/python-net/cs/aspose.slides.charts/ichartdatacell/row/) | Vrací index řádku listu, ve kterém se buňka nachází.<br/>            Pouze pro čtení **int**. |
| [`column`](/slides/python-net/cs/aspose.slides.charts/ichartdatacell/column/) | Vrací index sloupce listu, ve kterém se buňka nachází.<br/>            Pouze pro čtení **int**. |
| [`value`](/slides/python-net/cs/aspose.slides.charts/ichartdatacell/value/) | Získá nebo nastaví hodnotu buňky.<br/>            Čtení/zápis **any**. |
| [`formula`](/slides/python-net/cs/aspose.slides.charts/ichartdatacell/formula/) | Získá nebo nastaví vzorec ve stylu A1. |
| [`r1c1_formula`](/slides/python-net/cs/aspose.slides.charts/ichartdatacell/r1c1_formula/) | Získá nebo nastaví vzorec ve stylu R1C1. |
| [`chart_data_worksheet`](/slides/python-net/cs/aspose.slides.charts/ichartdatacell/chart_data_worksheet/) | Získá list.<br/>            Pouze pro čtení [`IChartDataWorksheet`](/slides/python-net/cs/aspose.slides.charts/ichartdataworksheet). |
| [`is_hidden`](/slides/python-net/cs/aspose.slides.charts/ichartdatacell/is_hidden/) | Určuje, zda je buňka skrytá.<br/>            Pouze pro čtení **bool**. |
| [`custom_number_format`](/slides/python-net/cs/aspose.slides.charts/ichartdatacell/custom_number_format/) | Získá nebo nastaví vlastní formát zobrazení čísel a dat.<br/>            Pokud je hodnota prázdná, bude použita hodnota PresetNumberFormat.<br/>            Čtení/zápis **str**. |
| [`preset_number_format`](/slides/python-net/cs/aspose.slides.charts/ichartdatacell/preset_number_format/) | Získá nebo nastaví vestavěný formát zobrazení čísel a dat. Přednastavené číslo musí být v rozmezí [0..22] nebo [37..49].<br/>            Čtení/zápis **int**. |

## Metody

| Metoda | Popis |
| :- | :- |
| [`calculate(self, update_values)`](/slides/python-net/cs/aspose.slides.charts/ichartdatacell/calculate/#bool) | Pokud buňka obsahuje vzorec, hodnota bude aktualizována na základě tohoto vzorce. |
