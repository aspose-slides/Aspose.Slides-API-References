## TickMarkType enumerace

Reprezentuje typ značky osy pro danou osu.

Typ TickMarkType obsahuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| CROSS | Určuje, že značky budou protínat osu. |
| INSIDE | Určuje, že značky budou uvnitř vykreslovací oblasti. |
| NONE | Určuje, že žádné značky nebudou. |
| OUTSIDE | Určuje, že značky budou mimo vykreslovací oblast. |
