## text_frame_for_overriding vlastnost
Může obsahovat bohatě formátovaný text. Pokud tato vlastnost není None, pak tato 
            formátovaná hodnota textu přepíše automaticky generovaný text.
            Automaticky generovaný text je implicitní vlastnost datového popisku, zobrazovací 
            jednotkový popisek osy hodnot, název osy, název grafu, popisek trendové čáry.
            Automaticky generovaný text je formátován pomocí IFormattedTextContainer.TextFormat vlastnost.
            Pouze ke čtení [`ITextFrame`](/slides/python-net/cs/aspose.slides/itextframe).
