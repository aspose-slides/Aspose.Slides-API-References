## ChartShapeType enumerace

Represents a shape of chart.

The ChartShapeType type exposes the following members:

## Pole

| Pole | Popis |
| :- | :- |
| NOT_DEFINED | Tvar grafu není definován. |
| BOX | Určuje, že graf bude vykreslen v podobě krabice. |
| CONE | Určuje, že graf bude vykreslen jako kužel, přičemž základna kužele je na podlaze a špička kužele na vrcholu datového markeru. |
| CONE_TO_MAX | Určuje, že graf bude vykreslen zkrácenými kužely tak, že špička kužele bude odpovídat maximální datové hodnotě. |
| CYLINDER | Určuje, že graf bude vykreslen jako válec. |
| PYRAMID | Určuje, že graf bude vykreslen jako pravoúhlá pyramida, přičemž základna pyramidy je na podlaze a špička pyramidy na vrcholu datového markeru. |
| PYRAMID_TO_MAXIMUM | Určuje, že graf bude vykreslen zkrácenými kužely tak, že špička kužele bude odpovídat maximální datové hodnotě. |
