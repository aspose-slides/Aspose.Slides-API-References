## Enumerace PictureType

Určuje režim vyplňování obrázků sloupcových grafů.

Typ PictureType obsahuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| NOT_DEFINED | Není definováno. |
| STACK | Obrázek je nastaven tak, aby se v nejdelším sloupcovém grafu opakoval maximálně 15krát. |
| STACK_SCALE | Obrázek je nastaven na určený počet jednotek a opakuje se po celé délce sloupce. |
| STRETCH | Obrázek je roztáhnut po celé délce sloupcového grafu. |
