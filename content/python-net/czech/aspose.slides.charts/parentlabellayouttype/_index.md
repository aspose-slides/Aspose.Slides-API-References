## ParentLabelLayoutType enumerace

Reprezentuje rozvržení popisků kategorií dat. Používá se pouze se sérií Treemap.

Typ ParentLabelLayoutType obsahuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| BANNER | Určuje, že popisky nadřazených kategorií jsou zobrazeny jako páska |
| NONE | Určuje, že popisky nadřazených kategorií nejsou vykresleny |
| OVERLAPPING | Určuje, že popisky nadřazených kategorií jsou zobrazeny překrývající se |
