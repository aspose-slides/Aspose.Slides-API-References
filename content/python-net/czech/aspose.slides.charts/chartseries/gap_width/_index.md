## gap_width vlastnost
Určuje prostor mezi shluky pruhů nebo sloupců jako procento šířky pruhu nebo sloupce.
            Jedná se o vlastnost nejen tohoto pořadí, ale o všech pořadích nadřazené skupiny pořadí – jedná se o projekci odpovídající skupinové vlastnosti. Tato vlastnost je tedy pouze pro čtení.
            Použijte vlastnost ParentSeriesGroup pro přístup k nadřazené skupině pořadí.
            Použijte vlastnost ParentSeriesGroup.GapWidth čtení/zápis pro změnu hodnoty.
            Pouze pro čtení **int**.


### Poznámky

Jedná se o projekci vlastnosti ParentSeriesGroup.GapWidth.
