## bubble_size_scale vlastnost
Určuje měřítkový faktor pro bublinový graf (může být mezi 0 a 300 procenty výchozí velikosti).
Tato vlastnost není pouze této sérii, ale všech sérií nadřazené skupiny sérií – jedná se o projekci odpovídající vlastnosti skupiny. Tato vlastnost je tedy jen pro čtení.
Použijte vlastnost ParentSeriesGroup pro přístup k nadřazené skupině sérií.
Použijte vlastnost ParentSeriesGroup.BubbleSizeScale pro čtení/zápis k změně hodnoty.

### Poznámky

Jedná se o projekci vlastnosti ParentSeriesGroup.BubbleSizeScale.
