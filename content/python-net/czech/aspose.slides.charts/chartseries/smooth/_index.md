## smooth vlastnost
Představuje vyhlazování křivky. True pokud je vyhlazování křivky zapnuto pro čárový graf nebo rozptylový graf.
            Platí pouze pro čárové a rozptylové grafy spojené čarami.
            Čtení/zápis **bool**.
