## x_plus vlastnost
Určuje hodnotu chybové úsečky v kladném směru. 
Available if error bars value type is Custom and ErrorBarsXFormat is allowed. 
V ostatních případech tato vlastnost vrací None. 
Pouze pro čtení [`IDoubleChartValue`](/slides/python-net/cs/aspose.slides.charts/idoublechartvalue).
