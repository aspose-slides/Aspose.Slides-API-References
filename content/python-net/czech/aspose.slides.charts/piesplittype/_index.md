## PieSplitType enumerace

Představuje typ dělicích bodů ve druhém výsečí nebo pruhu na grafu typu výseč-ve-výseči nebo pruh-ve-výseči.

Typ PieSplitType obsahuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| DEFAULT | Určuje, že datové body mají být rozděleny pomocí výchozího <br/>            mechanismu pro tento typ grafu. |
| CUSTOM | Určuje, že datové body mají být rozděleny mezi <br/>            výseč a druhý graf podle hodnot Vlastního rozdělení. |
| BY_PERCENTAGE | Určuje, že datové body mají být rozděleny mezi výseč a <br/>            druhý graf tak, že body s procentem menším než <br/>            Split Position procent ve druhém grafu. |
| BY_POS | Určuje, že datové body mají být rozděleny mezi výseč a <br/>            druhý graf tak, že poslední Split Position datových bodů <br/>            bude umístěna ve druhém grafu. |
| BY_VALUE | Určuje, že datové body mají být rozděleny mezi výseč a <br/>            druhý graf tak, že datové body s hodnotou menší než <br/>            Split Position budou umístěny ve druhém grafu. |
