## IActualLayout třída

Určuje skutečnou polohu prvku grafu.

Typ IActualLayout obsahuje následující členy:

## Vlastnosti

| Property | Description |
| :- | :- |
| [`actual_x`](/slides/python-net/cs/aspose.slides.charts/iactuallayout/actual_x/) | Určuje skutečnou x polohu (levý) prvku grafu vzhledem k levému hornímu rohu grafu.<br/>            Zavolejte metodu IChart.ValidateChartLayout() před tím, abyste získali skutečné hodnoty. <br/>            Číst **float**. |
| [`actual_y`](/slides/python-net/cs/aspose.slides.charts/iactuallayout/actual_y/) | Určuje skutečný horní okraj prvku grafu vzhledem k levému hornímu rohu grafu.<br/>            Zavolejte metodu IChart.ValidateChartLayout() před tím, abyste získali skutečné hodnoty. <br/>            Číst **float**. |
| [`actual_width`](/slides/python-net/cs/aspose.slides.charts/iactuallayout/actual_width/) | Určuje skutečnou šířku prvku grafu. Zavolejte metodu IChart.ValidateChartLayout() před tím, abyste získali skutečné hodnoty. <br/>            Číst **float**. |
| [`actual_height`](/slides/python-net/cs/aspose.slides.charts/iactuallayout/actual_height/) | Určuje skutečnou výšku prvku grafu. Zavolejte metodu IChart.ValidateChartLayout() před tím, abyste získali skutečné hodnoty. <br/>            Číst **float**. |
