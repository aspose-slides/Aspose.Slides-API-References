## IUpDownBarsManager třída

Poskytuje přístup k sloupcům nahoru/dolů u čárového nebo akciového grafu.

Typ IUpDownBarsManager exponuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`up_bars_format`](/slides/python-net/cs/aspose.slides.charts/iupdownbarsmanager/up_bars_format/) | Vrací formát horních sloupců.<br/>            Pouze ke čtení [`IFormat`](/slides/python-net/cs/aspose.slides.charts/iformat). |
| [`down_bars_format`](/slides/python-net/cs/aspose.slides.charts/iupdownbarsmanager/down_bars_format/) | Vrací formát dolních sloupců.<br/>            Pouze ke čtení [`IFormat`](/slides/python-net/cs/aspose.slides.charts/iformat). |
| [`has_up_down_bars`](/slides/python-net/cs/aspose.slides.charts/iupdownbarsmanager/has_up_down_bars/) | Určuje, zda graf má sloupce nahoru/dolů.<br/>            Čtení/zápis **bool**. |
| [`gap_width`](/slides/python-net/cs/aspose.slides.charts/iupdownbarsmanager/gap_width/) | Vrací nebo nastavuje šířku mezery.<br/>            Čtení/zápis **int**. |
