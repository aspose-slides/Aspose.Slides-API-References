## ChartPlotArea třída

Reprezentuje obdélník, ve kterém by měl být graf vykreslen.

Typ ChartPlotArea vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`format`](/slides/python-net/cs/aspose.slides.charts/chartplotarea/format/) | Vrací formát oblasti grafu.<br/>            Pouze pro čtení [`IFormat`](/slides/python-net/cs/aspose.slides.charts/iformat). |
| [`x`](/slides/python-net/cs/aspose.slides.charts/chartplotarea/x/) | Vrací nebo nastavuje souřadnici x levého horního rohu ohraničujícího rámečku oblasti grafu jako zlomek šířky grafu (od 0 do 1).<br/>            Čtení/zápis **float**. |
| [`y`](/slides/python-net/cs/aspose.slides.charts/chartplotarea/y/) | Vrací nebo nastavuje souřadnici y levého horního rohu ohraničujícího rámečku oblasti grafu jako zlomek výšky grafu (od 0 do 1).<br/>            Čtení/zápis **float**. |
| [`width`](/slides/python-net/cs/aspose.slides.charts/chartplotarea/width/) | Vrací nebo nastavuje šířku ohraničujícího rámečku oblasti grafu jako zlomek šířky grafu (od 0 do 1).<br/>            Čtení/zápis **float**. |
| [`height`](/slides/python-net/cs/aspose.slides.charts/chartplotarea/height/) | Vrací nebo nastavuje výšku ohraničujícího rámečku oblasti grafu jako zlomek výšky grafu (od 0 do 1).<br/>            Čtení/zápis **float**. |
| [`right`](/slides/python-net/cs/aspose.slides.charts/chartplotarea/right/) | Vpravo.<br/>            Pouze pro čtení **float**. |
| [`bottom`](/slides/python-net/cs/aspose.slides.charts/chartplotarea/bottom/) | Dole.<br/>            Pouze pro čtení **float**. |
| [`chart`](/slides/python-net/cs/aspose.slides.charts/chartplotarea/chart/) | Graf.<br/>            Pouze pro čtení [`IChart`](/slides/python-net/cs/aspose.slides.charts/ichart). |
| [`is_location_autocalculated`](/slides/python-net/cs/aspose.slides.charts/chartplotarea/is_location_autocalculated/) | Definuje, jak má být umístění vypočítáno: true – vypočítáno automaticky; definováno vlastnostmi X, Y, Width, Height.<br/>            Pouze pro čtení **bool**. |
| [`layout_target_type`](/slides/python-net/cs/aspose.slides.charts/chartplotarea/layout_target_type/) | Pokud je rozvržení oblasti grafu definováno ručně, tato vlastnost určuje, zda <br/>             rozvrhnout oblast grafu podle jejího vnitřku (bez os a popisků os) nebo vnějšího<br/>             (s osami a popisky os).<br/>             Čtení/zápis [`ChartPlotArea.layout_target_type`](/slides/python-net/cs/aspose.slides.charts/chartplotarea/layout_target_type). |
| [`actual_x`](/slides/python-net/cs/aspose.slides.charts/chartplotarea/actual_x/) | Určuje skutečnou x polohu (levý) prvku grafu relativně k levému hornímu rohu grafu.<br/>            Zavolejte metodu IChart.ValidateChartLayout() předtím, abyste získali skutečné hodnoty. <br/>            Čtení **float**. |
| [`actual_y`](/slides/python-net/cs/aspose.slides.charts/chartplotarea/actual_y/) | Určuje skutečné horní umístění prvku grafu relativně k levému hornímu rohu grafu.<br/>            Zavolejte metodu IChart.ValidateChartLayout() předtím, abyste získali skutečné hodnoty. <br/>            Čtení **float**. |
| [`actual_width`](/slides/python-net/cs/aspose.slides.charts/chartplotarea/actual_width/) | Určuje skutečnou šířku prvku grafu. Zavolejte metodu IChart.ValidateChartLayout() předtím, abyste získali skutečné hodnoty. <br/>            Čtení **float**. |
| [`actual_height`](/slides/python-net/cs/aspose.slides.charts/chartplotarea/actual_height/) | Určuje skutečnou výšku prvku grafu. Zavolejte metodu IChart.ValidateChartLayout() předtím, abyste získali skutečné hodnoty. <br/>            Čtení **float**. |
