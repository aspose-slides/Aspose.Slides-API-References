## ChartType výčet

Reprezentuje typ grafu.

Typ ChartType obsahuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| CLUSTERED_COLUMN | Reprezentuje seskupený sloupcový graf. |
| STACKED_COLUMN | Reprezentuje skládaný sloupcový graf. |
| PERCENTS_STACKED_COLUMN | Reprezentuje 100% skládaný sloupcový graf. |
| CLUSTERED_COLUMN_3D | Reprezentuje 3D seskupený sloupcový graf. |
| STACKED_COLUMN_3D | Reprezentuje 3D skládaný sloupcový graf. |
| PERCENTS_STACKED_COLUMN_3D | Reprezentuje 3D 100% skládaný sloupcový graf. |
| COLUMN_3D | Reprezentuje 3D sloupcový graf. |
| CLUSTERED_CYLINDER | Reprezentuje válecový graf. |
| STACKED_CYLINDER | Reprezentuje skládaný válecový graf. |
| PERCENTS_STACKED_CYLINDER | Reprezentuje 100% skládaný válecový graf. |
| CYLINDER_3D | Reprezentuje 3D válecový sloupcový graf. |
| CLUSTERED_CONE | Reprezentuje kónový graf. |
| STACKED_CONE | Reprezentuje skládaný kónový graf. |
| PERCENTS_STACKED_CONE | Reprezentuje 100% skládaný kónový graf. |
| CONE_3D | Reprezentuje 3D kónový sloupcový graf. |
| CLUSTERED_PYRAMID | Reprezentuje pyramidový graf. |

| PERCENTS_STACKED_LINE | Reprezentuje 100% skládaný čárový graf. |
| LINE_WITH_MARKERS | Reprezentuje čárový graf s datovými značkami. |
| STACKED_LINE_WITH_MARKERS | Reprezentuje skládaný čárový graf s datovými značkami. |
| PERCENTS_STACKED_LINE_WITH_MARKERS | Reprezentuje 100% skládaný čárový graf s datovými značkami. |

| BAR_OF_PIE | Reprezentuje graf pruh v koláči. |
| PERCENTS_STACKED_BAR | Reprezentuje 100% skládaný pruhový graf. |
| CLUSTERED_BAR_3D | Reprezentuje 3D seskupený pruhový graf. |
| CLUSTERED_BAR | Reprezentuje seskupený pruhový graf. |
| STACKED_BAR | Reprezentuje skládaný pruhový graf. |

| VOLUME_OPEN_HIGH_LOW_CLOSE | Reprezentuje graf akcií Volume-Open-High-Low-Close. |
| SURFACE_3D | Reprezentuje 3D povrchový graf. |
| WIREFRAME_SURFACE_3D | Reprezentuje drátový 3D povrchový graf. |
