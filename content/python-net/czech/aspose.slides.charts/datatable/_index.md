## DataTable třída

Reprezentuje vlastnosti datové tabulky.

Typ DataTable vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`format`](/slides/python-net/cs/aspose.slides.charts/datatable/format/) | Vrací styly čar, výplní a efektů objektu.<br/>            Read-only [`IFormat`](/slides/python-net/cs/aspose.slides.charts/iformat). |
| [`has_border_horizontal`](/slides/python-net/cs/aspose.slides.charts/datatable/has_border_horizontal/) | True pokud má datová tabulka grafu vodorovné okraje buněk.<br/>            Read/write **bool**. |
| [`has_border_outline`](/slides/python-net/cs/aspose.slides.charts/datatable/has_border_outline/) | True pokud má datová tabulka grafu obrysové okraje.<br/>            Read/write **bool**. |
| [`has_border_vertical`](/slides/python-net/cs/aspose.slides.charts/datatable/has_border_vertical/) | True pokud má datová tabulka grafu svislé okraje buněk.<br/>            Read/write **bool**. |
| [`show_legend_key`](/slides/python-net/cs/aspose.slides.charts/datatable/show_legend_key/) | True pokud je legendový klíč popisku dat viditelný.<br/>            Read/write **bool**. |
| [`chart`](/slides/python-net/cs/aspose.slides.charts/datatable/chart/) | Vrací graf.<br/>            Read-only [`IChart`](/slides/python-net/cs/aspose.slides.charts/ichart). |
| [`text_format`](/slides/python-net/cs/aspose.slides.charts/datatable/text_format/) | Vrací formát textu.<br/>            Read-only [`IChartTextFormat`](/slides/python-net/cs/aspose.slides.charts/icharttextformat). |
