## default_label_shape_type vlastnost
Získá nebo nastaví výchozí typ tvaru pro datové popisky.
             Vrátí [`ShapeType.NOT_DEFINED`](/slides/python-net/cs/aspose.slides/shapetype/NOT_DEFINED), pokud není definován žádný tvar.


### Poznámky

Setting this property also sets the [`IDataLabel.label_shape_type`](/slides/python-net/cs/aspose.slides.charts/idatalabel/label_shape_type) property
             for all data labels in the collection to the same value.
