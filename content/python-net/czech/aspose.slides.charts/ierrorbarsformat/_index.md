## IErrorBarsFormat třída

Reprezentuje chybové úsečky řady grafu. Vlastní hodnoty ErrorBars jsou v IChartDataPointCollection
            (v [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/cs/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) vlastnosti).

Typ IErrorBarsFormat vystavuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`type`](/slides/python-net/cs/aspose.slides.charts/ierrorbarsformat/type/) | Získá nebo nastaví typ chybových úseček. <br/>            Čtení/Zápis [`ErrorBarType`](/slides/python-net/cs/aspose.slides.charts/errorbartype). |
| [`value_type`](/slides/python-net/cs/aspose.slides.charts/ierrorbarsformat/value_type/) | Reprezentuje možné způsoby určení délky chybových úseček. <br/>            V případě typu vlastní hodnoty pro zadání hodnoty použijte [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/cs/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) vlastnost konkrétního datového bodu ve sbírce DataPoints řady.  <br/>            Čtení/Zápis [`ErrorBarValueType`](/slides/python-net/cs/aspose.slides.charts/errorbarvaluetype). |
| [`has_end_cap`](/slides/python-net/cs/aspose.slides.charts/ierrorbarsformat/has_end_cap/) | Určuje, že na konci chybových úseček není kreslená kapka.<br/>            Čtení/Zápis **bool**. |
| [`value`](/slides/python-net/cs/aspose.slides.charts/ierrorbarsformat/value/) | Získá nebo nastaví hodnotu, která se používá s typy Fixed, Percentage a StandardDeviation k určení délky chybových úseček. <br/>            Čtení/Zápis **float**. |
| [`format`](/slides/python-net/cs/aspose.slides.charts/ierrorbarsformat/format/) | Reprezentuje formát chybových úseček.<br/>            Čtení/Zápis [`IFormat`](/slides/python-net/cs/aspose.slides.charts/iformat). |
| [`is_visible`](/slides/python-net/cs/aspose.slides.charts/ierrorbarsformat/is_visible/) | Získá nebo nastaví viditelnost chybových úseček.<br/>            Čtení/Zápis **bool**. |
