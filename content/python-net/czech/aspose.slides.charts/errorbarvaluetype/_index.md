## ErrorBarValueType enumeration

Reprezentuje typ hodnoty chybového pruhu

Typ ErrorBarValueType obsahuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| CUSTOM | Určuje, že délka chybových pruhů bude určena prvky Plus a Minus. |
| FIXED | Určuje, že délka chybových pruhů bude pevná hodnota určená pomocí Error Bar Value. |
| PERCENTAGE | Určuje, že délka chybových pruhů bude procento Error Bar Value z dat. |
| STANDARD_DEVIATION | Určuje, že délka chybových pruhů bude standardních odchylek Error Bar Value z dat. |
| STANDARD_ERROR | Určuje, že délka chybových pruhů bude standardních chyb Error Bar Value z dat. |
