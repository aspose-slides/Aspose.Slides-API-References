## TickLabelPositionType výčet

Representuje typ umístění popisků dělových značek na zadané ose.

Typ TickLabelPositionType vystavuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| HIGH | Určuje, že popisky osy budou na vysokém konci kolmých os. |
| LOW | Určuje, že popisky osy budou na nízkém konci kolmých os. |
| NEXT_TO | Určuje, že popisky osy budou umístěny vedle osy. |
| NONE | Určuje, že popisky osy nejsou vykresleny. |
