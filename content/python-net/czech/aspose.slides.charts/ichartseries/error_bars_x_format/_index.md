## error_bars_x_format vlastnost
Reprezentuje ErrorBars řady se směrem X.

            ErrorBars with X direction are avalible for series of type area, bar, scatter and bubble. 
            For any other types of chart this property returns None (including 3D charts).
            In case of custom values use DataPoints collection to specify value
            (with [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/cs/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) property).
            
            Read-only [`IErrorBarsFormat`](/slides/python-net/cs/aspose.slides.charts/ierrorbarsformat).
