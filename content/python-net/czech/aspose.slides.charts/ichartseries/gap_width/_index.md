## gap_width vlastnost
Určuje prostor mezi shluky pruhů nebo sloupců jako procento šířky pruhu nebo sloupce.
            Tato vlastnost není pouze této řadě, ale všem řadám skupiny nadřazených řad – jedná se o projekci příslušné vlastnosti skupiny. Tato vlastnost je tedy jen pro čtení.
            Pro přístup ke skupině nadřazených řad použijte vlastnost ParentSeriesGroup.
            Pro změnu hodnoty použijte vlastnost ParentSeriesGroup.GapWidth čtení/zápis.
            Pouze pro čtení **int**.

### Poznámky

Jedná se o projekci vlastnosti ParentSeriesGroup.GapWidth.
