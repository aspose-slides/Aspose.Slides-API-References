## TimeUnitType enumerace

Reprezentuje základní jednotku pro kategorickou osu

Typ TimeUnitType poskytuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| NONE | Hodnoty budou zobrazeny tak, jak jsou. |
| DAYS | Určuje, že data grafu budou zobrazena ve dnech. |
| MONTHS | Určuje, že data grafu budou zobrazena v měsících. |
| YEARS | Určuje, že data grafu budou zobrazena v letech. |
