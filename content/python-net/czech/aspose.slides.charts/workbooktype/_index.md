## WorkbookType enumerace

Určuje typ souboru sešitu Open XML.

Typ WorkbookType obsahuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| NOT_DEFINED | Typ sešitu není definován. |
| WORKBOOK | Excel sešit (*.xlsx). |
| WORKBOOK_MACRO | Excel sešit s povolenými makry (*.xlsm). |
| TEMPLATE | Excel šablona (*.xltx). |
| TEMPLATE_MACRO | Excel šablona s povolenými makry (*.xltm). |
| WORKBOOK_BINARY_MACRO | Excel binární sešit s povolenými makry (*.xlsb). |
