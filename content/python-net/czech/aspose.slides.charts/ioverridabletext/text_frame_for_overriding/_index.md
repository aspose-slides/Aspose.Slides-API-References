## text_frame_for_overriding vlastnost
Can contain a rich formatted text. If this vlastnost is not None then this 
            formatted text value overrides auto-generated text.
            Auto-generated text is an implicit vlastnost of the data label, the display 
            unit label of the value axis, the axis title, the chart title, the label of the trendline.
            Auto-generated text is formatted with the IFormattedTextContainer.TextFormat vlastnost.
            Pouze pro čtení [`ITextFrame`](/slides/python-net/cs/aspose.slides/itextframe).
