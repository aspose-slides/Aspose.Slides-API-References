## Rotation3D třída

Představuje 3D otáčení grafu.

Typ Rotation3D obsahuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`rotation_x`](/slides/python-net/cs/aspose.slides.charts/rotation3d/rotation_x/) | Vrací nebo nastavuje úhel rotace kolem osy X, tj. ve směru osy Y pro 3D grafy (mezi -90 a 90 stupni).<br/>            Vlastnost odpovídá položce 21.2.2.157 rotX (X Rotation) v ECMA-376 a možnosti „Y Rotation“ v PowerPoint 2007+.<br/>            Čtení/zápis **int**. |
| [`rotation_y`](/slides/python-net/cs/aspose.slides.charts/rotation3d/rotation_y/) | Vrací nebo nastavuje úhel rotace kolem osy Y, tj. ve směru osy X pro 3D grafy (mezi 0 a 360 stupni).<br/>            Vlastnost odpovídá položce 21.2.2.158 rotY (Y Rotation) v ECMA-376 a možnosti „X Rotation“ v PowerPoint 2007+.<br/>            Čtení/zápis **int**. |
| [`perspective`](/slides/python-net/cs/aspose.slides.charts/rotation3d/perspective/) | Vrací nebo nastavuje perspektivní hodnotu (úhel zorného pole) pro 3D grafy (mezi 0 a 240).<br/>            Ignorováno, pokud je hodnota vlastnosti RightAngleAxes true.<br/>            Čtení/zápis **int**. |
| [`right_angle_axes`](/slides/python-net/cs/aspose.slides.charts/rotation3d/right_angle_axes/) | Určuje, zda jsou osy grafu v pravých úhlech, místo aby byly vykresleny v perspektivě.<br/>            Jinými slovy určuje, zda jsou úhly os grafu nezávislé na otáčení nebo nadvihnutí grafu <br/>            rotaci.<br/>            Čtení/zápis **bool**. |
| [`depth_percents`](/slides/python-net/cs/aspose.slides.charts/rotation3d/depth_percents/) | Vrací nebo nastavuje hloubku 3D grafu jako procento šířky grafu (mezi 20 a 2000 procent).<br/>            Čtení/zápis **int**. |
| [`height_percents`](/slides/python-net/cs/aspose.slides.charts/rotation3d/height_percents/) | Určuje výšku 3-D grafu jako procento šířky grafu (mezi 5 a 500 procent).<br/>            Čtení/zápis **int**. |
