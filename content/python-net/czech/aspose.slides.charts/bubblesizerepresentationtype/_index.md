## BubbleSizeRepresentationType enumeration

Určuje možné způsoby, jak reprezentovat data jako velikosti bublinového grafu.

Typ BubbleSizeRepresentationType obsahuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| AREA | Určuje, že plocha bublin má být úměrná hodnotě velikosti bubliny. |
| WIDTH | Určuje, že poloměr bublin má být úměrný hodnotě velikosti bubliny. |
