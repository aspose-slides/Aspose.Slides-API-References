## height vlastnost
Získá nebo nastaví výšku shape, měřenou v bodech.
            Čtení/zápis **float**.


### Poznámky

The value returned is always defined and never **float**.
            The value assigned must also be defined; assign **float** only to properties of a `RawFrame` instance.
