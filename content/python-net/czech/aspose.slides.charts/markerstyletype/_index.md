## MarkerStyleType enumerace

Určuje tvar značky u datového bodu grafu.

Typ MarkerStyleType obsahuje následující členy:

## Pole

| Field | Description |
| :- | :- |
| NOT_DEFINED |  |
| CIRCLE | Určuje, že kruh bude nakreslen u každého datového bodu. |
| DASH | Určuje, že pomlčka bude nakreslena u každého datového bodu. |
| DIAMOND | Určuje, že diamant bude nakreslen u každého datového bodu. |
| DOT | Určuje, že tečka bude nakreslena u každého datového bodu. |
| NONE | Určuje, že nic nebude nakresleno u každého datového bodu. |
| PICTURE | Určuje, že obrázek bude nakreslen u každého datového bodu. |
| PLUS | Určuje, že plus bude nakreslen u každého datového bodu. |
| SQUARE | Určuje, že čtverec bude nakreslen u každého datového bodu. |
| STAR | Určuje, že hvězda bude nakreslena u každého datového bodu. |
| TRIANGLE | Určuje, že trojúhelník bude nakreslen u každého datového bodu. |
| X | Určuje, že X bude nakresleno u každého datového bodu. |
