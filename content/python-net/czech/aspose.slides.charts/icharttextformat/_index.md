## IChartTextFormat třída

Chart operuje s omezenou sadou vlastností formátování textu.  
            IChartTextFormat, IChartTextBlockFormat, IChartParagraphFormat, IChartPortionFormat  
            rozhraní popisují tuto omezenou sadu.

Typ IChartTextFormat poskytuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`text_block_format`](/slides/python-net/cs/aspose.slides.charts/icharttextformat/text_block_format/) | Vrací formát pro textové prvky diagramu.<br/>            Pouze pro čtení [`IChartTextBlockFormat`](/slides/python-net/cs/aspose.slides.charts/icharttextblockformat). |
| [`paragraph_format`](/slides/python-net/cs/aspose.slides.charts/icharttextformat/paragraph_format/) | Vrací formát odstavce.<br/>            Pouze pro čtení [`IChartParagraphFormat`](/slides/python-net/cs/aspose.slides.charts/ichartparagraphformat). |
| [`portion_format`](/slides/python-net/cs/aspose.slides.charts/icharttextformat/portion_format/) | Vrací formát úseku.<br/>            Pouze pro čtení [`IChartPortionFormat`](/slides/python-net/cs/aspose.slides.charts/ichartportionformat). |
