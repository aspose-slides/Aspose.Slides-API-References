## AxisAggregationType výčet

Představuje typ agregace pro kategorickou osu. Používá se pouze se sériemi Histogram nebo HistogramPareto.

Typ AxisAggregationType obsahuje následující členy:

## Pole

| Field | Description |
| :- | :- |
| BY_CATEGORY | Agregovat podle kategorií |
| AUTOMATIC | Automaticky agregovat kategorie. |
| BY_BIN_WIDTH | Agregovat kategorie podle šířky koše. Property IAxis.BinWidth must be setted. |
| BY_NUMBER_OF_BINS | Agregovat kategorie podle počtu košů. Property IAxis.NumberOfBins must be setted. |
