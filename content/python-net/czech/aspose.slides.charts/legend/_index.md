## Legend třída

Představuje vlastnosti legendy grafu.

Typ Legend poskytuje následující členy:

## Vlastnosti

| Property | Description |
| :- | :- |
| [`x`](/slides/python-net/cs/aspose.slides.charts/legend/x/) | Vrací nebo nastavuje souřadnici x legendy jako zlomek šířky grafu.<br/>            Čtení/zápis **float**. |
| [`y`](/slides/python-net/cs/aspose.slides.charts/legend/y/) | Vrací nebo nastavuje souřadnici y legendy jako zlomek výšky grafu.<br/>            Čtení/zápis **float**. |
| [`width`](/slides/python-net/cs/aspose.slides.charts/legend/width/) | Vrací nebo nastavuje šířku legendy jako zlomek šířky grafu.<br/>            Čtení/zápis **float**. |
| [`height`](/slides/python-net/cs/aspose.slides.charts/legend/height/) | Vrací nebo nastavuje výšku legendy jako zlomek výšky grafu.<br/>            Čtení/zápis **float**. |
| [`right`](/slides/python-net/cs/aspose.slides.charts/legend/right/) | Vpravo.<br/>            Pouze pro čtení **float**. |
| [`bottom`](/slides/python-net/cs/aspose.slides.charts/legend/bottom/) | Dole.<br/>            Pouze pro čtení **float**. |
| [`overlay`](/slides/python-net/cs/aspose.slides.charts/legend/overlay/) | Určuje, zda ostatní prvky grafu mohou překrývat legendu.<br/>            Čtení/zápis **bool**. |
| [`text_format`](/slides/python-net/cs/aspose.slides.charts/legend/text_format/) | Formát textu.<br/>            Pouze pro čtení [`IChartTextFormat`](/slides/python-net/cs/aspose.slides.charts/icharttextformat). |
| [`position`](/slides/python-net/cs/aspose.slides.charts/legend/position/) | Určuje pozici legendy v grafu.<br/>            Hodnoty X, Y, Width, Heigt, které nejsou NaN, přebijí účinek této vlastnosti.<br/>            Čtení/zápis [`LegendPositionType`](/slides/python-net/cs/aspose.slides.charts/legendpositiontype). |
| [`format`](/slides/python-net/cs/aspose.slides.charts/legend/format/) | Vrací formát legendy.<br/>            Pouze pro čtení [`IFormat`](/slides/python-net/cs/aspose.slides.charts/iformat). |
| [`chart`](/slides/python-net/cs/aspose.slides.charts/legend/chart/) | Vrací graf.<br/>            Pouze pro čtení [`IChart`](/slides/python-net/cs/aspose.slides.charts/ichart). |
| [`entries`](/slides/python-net/cs/aspose.slides.charts/legend/entries/) | Získává položky legendy.<br/>            Pouze pro čtení [`ILegendEntryCollection`](/slides/python-net/cs/aspose.slides.charts/ilegendentrycollection). |
| [`actual_x`](/slides/python-net/cs/aspose.slides.charts/legend/actual_x/) | Určuje skutečnou polohu x (levý) prvku grafu vůči levému hornímu rohu grafu.<br/>            Před získáním skutečných hodnot zavolejte metodu IChart.ValidateChartLayout(). <br/>            Čtení **float**. |
| [`actual_y`](/slides/python-net/cs/aspose.slides.charts/legend/actual_y/) | Určuje skutečnou horní polohu prvku grafu vůči levému hornímu rohu grafu.<br/>            Před získáním skutečných hodnot zavolejte metodu IChart.ValidateChartLayout(). <br/>            Čtení **float**. |
| [`actual_width`](/slides/python-net/cs/aspose.slides.charts/legend/actual_width/) | Určuje skutečnou šířku prvku grafu. Před získáním skutečných hodnot zavolejte metodu IChart.ValidateChartLayout(). <br/>            Čtení **float**. |
| [`actual_height`](/slides/python-net/cs/aspose.slides.charts/legend/actual_height/) | Určuje skutečnou výšku prvku grafu. Před získáním skutečných hodnot zavolejte metodu IChart.ValidateChartLayout(). <br/>            Čtení **float**. |
