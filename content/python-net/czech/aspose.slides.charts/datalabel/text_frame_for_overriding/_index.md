## text_frame_for_overriding vlastnost
Může obsahovat bohatě formátovaný text. Pokud tato vlastnost není None, pak tato 
            hodnota formátovaného textu přepíše automaticky generovaný text popisku dat.
            Automaticky generovaný text popisku dat znamená text, který je řízen vlastnostmi ShowSeriesName, 
            ShowValue, ... a je formátován pomocí vlastnosti TextFormatManager.TextFormat.
            Pouze pro čtení [`ITextFrame`](/slides/python-net/cs/aspose.slides/itextframe).
