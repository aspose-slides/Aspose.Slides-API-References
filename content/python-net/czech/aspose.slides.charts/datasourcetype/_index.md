## Výčtový typ DataSourceType

Typy zdrojů dat.

Typ DataSourceType poskytuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| WORKSHEET | Použijte objekty CellXls pro ukládání XValue, YValue, Value nebo BubbleSize datového bodu v listu. |
| STRING_LITERALS | Použijte rychle přístupnou řetězcovou proměnnou pro ukládání XValue, YValue, Value nebo BubbleSize <br/>            datového bodu. List NENÍ používán pro ukládání hodnot. |
| DOUBLE_LITERALS | Použijte rychle přístupnou proměnnou typu double pro ukládání XValue, YValue, Value nebo BubbleSize <br/>            datového bodu. List NENÍ používán pro ukládání hodnot. |
