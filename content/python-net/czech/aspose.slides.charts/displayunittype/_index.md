## Výčet DisplayUnitType

Určuje násobnost zobrazovaných dat.

Typ DisplayUnitType poskytuje následující členy:

## Pole

| Pole | Popis |
| :- | :- |
| NONE | Hodnoty budou zobrazeny tak, jak jsou. |
| HUNDREDS | Určuje, že hodnoty v grafu budou děleny 100. |
| THOUSANDS | Určuje, že hodnoty v grafu budou děleny 1,000. |
| TEN_THOUSANDS | Určuje, že hodnoty v grafu budou děleny 10,000. |
| HUNDRED_THOUSANDS | Určuje, že hodnoty v grafu budou děleny 100,000. |
| MILLIONS | Určuje, že hodnoty v grafu budou děleny 1,000,000. |
| TEN_MILLIONS | Určuje, že hodnoty v grafu budou děleny 10,000,000. |
| HUNDRED_MILLIONS | Určuje, že hodnoty v grafu budou děleny 100,000,000. |
| BILLIONS | Určuje, že hodnoty v grafu budou děleny 1,000,000,000. |
| TRILLIONS | Určuje, že hodnoty v grafu budou děleny 1,000,000,000,000. |
| CUSTOM_VALUE | Určuje, že hodnoty v grafu budou děleny vlastní hodnotou. |
