## ITrendline třída

Třída představuje čáru trendu řady grafu

Typ ITrendline exponuje následující členy:

## Vlastnosti

| Vlastnost | Popis |
| :- | :- |
| [`trendline_name`](/slides/python-net/cs/aspose.slides.charts/itrendline/trendline_name/) | Získá nebo nastaví název čáry trendu.<br/>            Číst/zapisovat **str**. |
| [`trendline_type`](/slides/python-net/cs/aspose.slides.charts/itrendline/trendline_type/) | Získá nebo nastaví typ čáry trendu.<br/>            Číst/zapisovat [`ITrendline.trendline_type`](/slides/python-net/cs/aspose.slides.charts/itrendline/trendline_type). |
| [`format`](/slides/python-net/cs/aspose.slides.charts/itrendline/format/) | Representuje formát čáry trendu.<br/>            Číst/zapisovat [`IFormat`](/slides/python-net/cs/aspose.slides.charts/iformat). |
| [`backward`](/slides/python-net/cs/aspose.slides.charts/itrendline/backward/) | Určuje počet kategorií (nebo jednotek v bodovém grafu), o které čára trendu zasahuje před<br/>            data řady, která je trendována. V bodových i nebodových grafech musí být hodnota libovolná nezáporná<br/>            hodnota.<br/>            Číst/zapisovat **float**. |
| [`forward`](/slides/python-net/cs/aspose.slides.charts/itrendline/forward/) | Určuje počet kategorií (nebo jednotek v bodovém grafu), o které čára trendu zasahuje za<br/>            data řady, která je trendována. V bodových i nebodových grafech musí být hodnota libovolná nezáporná<br/>            hodnota.<br/>            Číst/zapisovat **float**. |
| [`intercept`](/slides/python-net/cs/aspose.slides.charts/itrendline/intercept/) | Určuje hodnotu, kde má čára trendu protínat osu y. Tato vlastnost je podporována pouze<br/>            když je typ čáry trendu exp, linear nebo poly.<br/>            Číst/zapisovat **float**. |
| [`display_equation`](/slides/python-net/cs/aspose.slides.charts/itrendline/display_equation/) | Určuje, že rovnice čáry trendu je zobrazena v grafu (ve stejném popisku jako hodnota R^2).<br/>            Číst/zapisovat **bool**. |
| [`order`](/slides/python-net/cs/aspose.slides.charts/itrendline/order/) | Určuje řád polynomické čáry trendu. Ignorováno u jiných typů čáry trendu. Hodnota musí být mezi 2 a 6.<br/>            Číst/zapisovat **int**. |
| [`period`](/slides/python-net/cs/aspose.slides.charts/itrendline/period/) | Určuje periodu čáry trendu pro čáru klouzavého průměru. Ignorováno u jiných variant čáry trendu.<br/>            Hodnota musí být mezi 2 a 255.<br/>            Číst/zapisovat **int**. |
| [`display_r_squared_value`](/slides/python-net/cs/aspose.slides.charts/itrendline/display_r_squared_value/) | Určuje, že hodnota R-čtverce čáry trendu je zobrazena v grafu (ve stejném popisku jako rovnice).<br/>            Číst/zapisovat **bool**. |
| [`related_legend_entry`](/slides/python-net/cs/aspose.slides.charts/itrendline/related_legend_entry/) | Representuje položku legendy související s touto čárou trendu<br/>            Pouze pro čtení [`ILegendEntryProperties`](/slides/python-net/cs/aspose.slides.charts/ilegendentryproperties). |
| [`text_frame_for_overriding`](/slides/python-net/cs/aspose.slides.charts/itrendline/text_frame_for_overriding/) |  |
| [`text_format`](/slides/python-net/cs/aspose.slides.charts/itrendline/text_format/) |  |
