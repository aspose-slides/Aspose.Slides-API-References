Obsahuje třídy a metody pro zpracování složitých obecných operací nízkokódovým způsobem.
## Třídy

| Třída | Popis |
| :- | :- |
| [`Collect`](/slides/python-net/cs/aspose.slides.lowcode/collect/) | Zastupuje skupinu metod určených ke sběru modelových objektů různých typů z [`Presentation`](/slides/python-net/cs/aspose.slides/presentation). |
| [`Compress`](/slides/python-net/cs/aspose.slides.lowcode/compress/) | Zastupuje skupinu metod určených ke kompresi [`Presentation`](/slides/python-net/cs/aspose.slides/presentation). |
| [`Convert`](/slides/python-net/cs/aspose.slides.lowcode/convert/) | Zastupuje skupinu metod určených ke konverzi [`Presentation`](/slides/python-net/cs/aspose.slides/presentation). |
| [`ForEach`](/slides/python-net/cs/aspose.slides.lowcode/foreach/) | Zastupuje skupinu metod určených k iteraci přes různé modelové objekty [`Presentation`](/slides/python-net/cs/aspose.slides/presentation).<br/> Tyto metody mohou být užitečné, pokud potřebujete iterovat a měnit formátování nebo obsah některých prvků Presentation,<br/> např. změnit formátování každé části. |
| [`Merger`](/slides/python-net/cs/aspose.slides.lowcode/merger/) | Zastupuje skupinu metod pro sloučení PowerPoint prezentací stejného formátu do jednoho souboru. |
