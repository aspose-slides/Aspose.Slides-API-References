## SlideShowTransition क्लास

स्लाइड शो ट्रांज़िशन का प्रतिनिधित्व करता है।

SlideShowTransition टाइप निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`sound`](/slides/python-net/hi/aspose.slides.slideshow/slideshowtransition/sound/) | एम्बेडेड ऑडियो डेटा को लौटाता या सेट करता है।<br/>            पढ़ें/लिखें [`IAudio`](/slides/python-net/hi/aspose.slides/iaudio). |
| [`sound_mode`](/slides/python-net/hi/aspose.slides.slideshow/slideshowtransition/sound_mode/) | स्लाइड ट्रांज़िशन के लिए साउंड मोड को सेट या लौटाता है।<br/>            पढ़ें/लिखें [`TransitionSoundMode`](/slides/python-net/hi/aspose.slides.slideshow/transitionsoundmode). |
| [`sound_loop`](/slides/python-net/hi/aspose.slides.slideshow/slideshowtransition/sound_loop/) | यह गुण निर्धारित करता है कि ध्वनि अगले साउंड इवेंट तक लूप होगी या नहीं।<br/>            पढ़ें/लिखें **bool**. |
| [`advance_on_click`](/slides/python-net/hi/aspose.slides.slideshow/slideshowtransition/advance_on_click/) | निर्धारित करता है कि माउस क्लिक स्लाइड को आगे बढ़ाएगा या नहीं। यदि यह गुण निर्दिष्ट नहीं है तो true मान माना जाता है।<br/>            पढ़ें/लिखें **bool**. |
| [`advance_after`](/slides/python-net/hi/aspose.slides.slideshow/slideshowtransition/advance_after/) | यह गुण निर्धारित करता है कि स्लाइड शो निश्चित समय के बाद अगले स्लाइड पर जाएगा या नहीं।<br/>            पढ़ें/लिखें **bool**. |
| [`advance_after_time`](/slides/python-net/hi/aspose.slides.slideshow/slideshowtransition/advance_after_time/) | वह समय (मिलीसेकंड में) निर्दिष्ट करता है जिसके बाद ट्रांज़िशन शुरू होना चाहिए। यह सेटिंग advClick गुण के साथ उपयोग की जा सकती है। यदि यह गुण निर्दिष्ट नहीं है तो यह माना जाता है कि कोई ऑटो-एडवांस नहीं होगा।<br/>            पढ़ें/लिखें **int**. |
| [`speed`](/slides/python-net/hi/aspose.slides.slideshow/slideshowtransition/speed/) | वर्तमान स्लाइड से अगले स्लाइड पर ट्रांज़िशन के दौरान उपयोग होने वाली गति को निर्दिष्ट करता है।<br/>            पढ़ें/लिखें [`TransitionSpeed`](/slides/python-net/hi/aspose.slides.slideshow/transitionspeed). |
| [`value`](/slides/python-net/hi/aspose.slides.slideshow/slideshowtransition/value/) | स्लाइड शो ट्रांज़िशन मान।<br/>            केवल पढ़ने योग्य [`ITransitionValueBase`](/slides/python-net/hi/aspose.slides.slideshow/itransitionvaluebase). |
| [`type`](/slides/python-net/hi/aspose.slides.slideshow/slideshowtransition/type/) | ट्रांज़िशन का प्रकार।<br/>            पढ़ें/लिखें [`TransitionType`](/slides/python-net/hi/aspose.slides.slideshow/transitiontype). |
| [`sound_is_built_in`](/slides/python-net/hi/aspose.slides.slideshow/slideshowtransition/sound_is_built_in/) | यह निर्धारित करता है कि यह ध्वनि बिल्ट-इन ध्वनि है या नहीं। यदि यह गुण true पर सेट है तो उत्पन्न करने वाले एप्लिकेशन को इस ध्वनि के लिए निर्दिष्ट name गुण की जांच करने के लिए अभिसूचित किया जाता है और आवश्यकतानुसार कस्टम नाम या UI प्रस्तुत किया जा सकता है।<br/>            पढ़ें/लिखें **bool**. |
| [`sound_name`](/slides/python-net/hi/aspose.slides.slideshow/slideshowtransition/sound_name/) | ट्रांज़िशन की ध्वनि के लिए एक मानव पठनीय नाम निर्दिष्ट करता है। ध्वनि नाम प्राप्त या सेट करने के लिए [`SlideShowTransition.sound`](/slides/python-net/hi/aspose.slides.slideshow/slideshowtransition/sound) गुण को असाइन करना आवश्यक है।<br/>            पढ़ें/लिखें **str**. |
| [`duration`](/slides/python-net/hi/aspose.slides.slideshow/slideshowtransition/duration/) | स्लाइड ट्रांज़िशन प्रभाव की अवधि को मिलीसेकंड में प्राप्त या सेट करता है।<br/>            पढ़ें/लिखें **int**. |
