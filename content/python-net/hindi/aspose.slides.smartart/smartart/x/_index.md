## x प्रॉपर्टी
शेप के ऊपर-बाएँ कोने के x-निर्देशांक को प्राप्त या सेट करता है, जिसे पॉइंट्स में मापा जाता है.
            पढ़ें/लिखें **float**.

### टिप्पणी

वापसी मान हमेशा निर्धारित होता है और कभी **float** नहीं होता।
            असाइन किया गया मान भी निर्धारित होना चाहिए; **float** केवल `RawFrame` इंस्टैंस के गुणों को असाइन करें।

### परिभाषा:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
