## x प्रॉपर्टी
आकार के ऊपर-बाएँ कोने के x-निर्देशांक को सेट या प्राप्त करता है, जिसे पॉइंट में मापा जाता है.
            पढ़ें/लिखें **float**.


### टिप्पणियाँ

वापस किया गया मान हमेशा परिभाषित होता है और कभी **float** नहीं होता.
            असाइन किया गया मान भी परिभाषित होना चाहिए; केवल `RawFrame` इंस्टेंस की प्रॉपर्टीज़ को **float** असाइन करें.

### परिभाषा:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
