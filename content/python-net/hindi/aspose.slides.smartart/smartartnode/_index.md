## SmartArtNode क्लास

SmartArt ऑब्जेक्ट का नोड दर्शाता है

SmartArtNode प्रकार निम्नलिखित सदस्य प्रस्तुत करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`child_nodes`](/slides/python-net/hi/aspose.slides.smartart/smartartnode/child_nodes/) | वर्तमान नोड के सभी चाइल्ड नोड्स का संग्रह लौटाता है।<br/>            केवल पढ़ने योग्य [`ISmartArtNodeCollection`](/slides/python-net/hi/aspose.slides.smartart/ismartartnodecollection). |
| [`shapes`](/slides/python-net/hi/aspose.slides.smartart/smartartnode/shapes/) | नोड से जुड़े सभी शैप्स का संग्रह लौटाता है।<br/>            केवल पढ़ने योग्य [`ISmartArtShapeCollection`](/slides/python-net/hi/aspose.slides.smartart/ismartartshapecollection). |
| [`text_frame`](/slides/python-net/hi/aspose.slides.smartart/smartartnode/text_frame/) | नोड का टेक्स्ट फ्रेम लौटाता है।<br/>            केवल पढ़ने योग्य [`ITextFrame`](/slides/python-net/hi/aspose.slides/itextframe). |
| [`is_assistant`](/slides/python-net/hi/aspose.slides.smartart/smartartnode/is_assistant/) | नोड को सहायक के रूप में लौटाता या सेट करता है।<br/>            पढ़ने/लिखने योग्य **bool**. |
| [`level`](/slides/python-net/hi/aspose.slides.smartart/smartartnode/level/) | नोड के नेस्टिंग स्तर को लौटाता है।<br/>            केवल पढ़ने योग्य **int**. |
| [`bullet_fill_format`](/slides/python-net/hi/aspose.slides.smartart/smartartnode/bullet_fill_format/) | नोड बुल्लेट के लिए भराव फॉर्मेटिंग प्रॉपर्टीज़ वाला FillFormat ऑब्जेक्ट लौटाता है।<br/>            नोट: कुछ प्रकार के SmartArt लेआउट के लिए None लौट सकता है जो नोड्स के लिए बुल्लेट प्रदान नहीं करता।<br/>            केवल पढ़ने योग्य [`IFillFormat`](/slides/python-net/hi/aspose.slides/ifillformat). |
| [`position`](/slides/python-net/hi/aspose.slides.smartart/smartartnode/position/) | सहायक नोड्स के बीच शून्य-आधारित स्थिति लौटाता या सेट करता है।<br/>            पढ़ने/लिखने योग्य **int**. |
| [`is_hidden`](/slides/python-net/hi/aspose.slides.smartart/smartartnode/is_hidden/) | यदि यह नोड डेटा मॉडल में छिपा हुआ है तो true लौटाता है।<br/>            केवल पढ़ने योग्य **bool**. |
| [`organization_chart_layout`](/slides/python-net/hi/aspose.slides.smartart/smartartnode/organization_chart_layout/) | वर्तमान नोड से जुड़े संगठन चार्ट लेआउट प्रकार को लौटाता या सेट करता है।<br/>            पढ़ने/लिखने योग्य [`OrganizationChartLayoutType`](/slides/python-net/hi/aspose.slides.smartart/organizationchartlayouttype). |
