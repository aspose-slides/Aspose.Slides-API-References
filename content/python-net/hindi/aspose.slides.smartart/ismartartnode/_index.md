## ISmartArtNode क्लास

SmartArt आरेख का नोड दर्शाता है।

ISmartArtNode प्रकार निम्नलिखित सदस्य प्रदर्शित करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`child_nodes`](/slides/python-net/hi/aspose.slides.smartart/ismartartnode/child_nodes/) | वर्तमान नोड के सभी चाइल्ड नोड्स का संग्रह लौटाता है।<br/>            केवल-पढ़ने योग्य [`ISmartArtNodeCollection`](/slides/python-net/hi/aspose.slides.smartart/ismartartnodecollection)। |
| [`shapes`](/slides/python-net/hi/aspose.slides.smartart/ismartartnode/shapes/) | नोड से संबंधित सभी शैप्स का संग्रह लौटाता है।<br/>            केवल-पढ़ने योग्य [`ISmartArtShapeCollection`](/slides/python-net/hi/aspose.slides.smartart/ismartartshapecollection)। |
| [`text_frame`](/slides/python-net/hi/aspose.slides.smartart/ismartartnode/text_frame/) | नोड का पाठ लौटाता या सेट करता है।<br/>            केवल-पढ़ने योग्य [`ITextFrame`](/slides/python-net/hi/aspose.slides/itextframe)। |
| [`is_assistant`](/slides/python-net/hi/aspose.slides.smartart/ismartartnode/is_assistant/) | नोड को सहायक के रूप में लौटाता या सेट करता है।<br/>            पढ़ने/लिखने योग्य **bool**। |
| [`level`](/slides/python-net/hi/aspose.slides.smartart/ismartartnode/level/) | नोड का नेस्टिंग स्तर लौटाता है।<br/>            केवल-पढ़ने योग्य **int**। |
| [`bullet_fill_format`](/slides/python-net/hi/aspose.slides.smartart/ismartartnode/bullet_fill_format/) | नोड बुलेट के लिए फ़िल फ़ॉर्मेट गुणों को सम्मिलित करने वाले FillFormat ऑब्जेक्ट को लौटाता है।<br/>            ध्यान दें: कुछ प्रकार के SmartArt लेआउट के लिए जो नोड्स के लिए बुलेट प्रदान नहीं करता, None वापस कर सकता है।<br/>            केवल-पढ़ने योग्य [`IFillFormat`](/slides/python-net/hi/aspose.slides/ifillformat)। |
| [`position`](/slides/python-net/hi/aspose.slides.smartart/ismartartnode/position/) | भाई-बंद नोड्स में नोड की शून्य-आधारित स्थिति लौटाता या सेट करता है।<br/>            पढ़ने/लिखने योग्य **int**। |
| [`is_hidden`](/slides/python-net/hi/aspose.slides.smartart/ismartartnode/is_hidden/) | यदि यह नोड डेटा मॉडल में छिपा नोड है तो true लौटाता है।<br/>            केवल-पढ़ने योग्य **bool**। |
| [`organization_chart_layout`](/slides/python-net/hi/aspose.slides.smartart/ismartartnode/organization_chart_layout/) | वर्तमान नोड से जुड़े संगठन चार्ट लेआउट प्रकार को लौटाता या सेट करता है।<br/>            पढ़ने/लिखने योग्य [`OrganizationChartLayoutType`](/slides/python-net/hi/aspose.slides.smartart/organizationchartlayouttype)। |
