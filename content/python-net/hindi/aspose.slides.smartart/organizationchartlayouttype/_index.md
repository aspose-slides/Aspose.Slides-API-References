## OrganizationChartLayoutType एनीमरेशन

प्रतिनिधित्व करता है फ़ॉर्मेटिंग प्रकार चाइल्ड नोड्स का एक संगठन चार्ट में

OrganizationChartLayoutType प्रकार निम्न सदस्य प्रदान करता है:

## फ़ील्ड

| फ़ील्ड | विवरण |
| :- | :- |
| INITIAL | प्रारंभिक लेआउट प्रकार |
| STANDART | चाइल्ड नोड्स को क्षैतिज रूप से पेरेंट नोड के नीचे रखता है। |
| BOTH_HANGING | चाइल्ड नोड्स को वर्टिकल रूप से पेरेंट नोड के दोनों बाएँ और दाएँ पक्ष में नीचे रखता है। |
| LEFT_HANGING | चाइल्ड नोड्स को वर्टिकल रूप से पेरेंट नोड के बाएँ पक्ष में नीचे रखता है। |
| RIGHT_HANGING | चाइल्ड नोड्स को वर्टिकल रूप से पेरेंट नोड के दाएँ पक्ष में नीचे रखता है। |
