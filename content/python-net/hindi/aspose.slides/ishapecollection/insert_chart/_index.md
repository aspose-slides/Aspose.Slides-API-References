## insert_chart(self, type, x, y, width, height, index) {#asposeslideschartscharttype-float-float-float-float-int}
एक नया चार्ट बनाता है, इसे नमूना श्रृंखला डेटा और सेटिंग्स से प्रारंभ करता है, और निर्दिष्ट इंडेक्स पर shape collection में सम्मिलित करता है।

| Parameter | Type | Description |
| :- | :- | :- |
| type | [`ChartType`](/slides/python-net/hi/aspose.slides.charts/charttype) | बनाये जाने वाले चार्ट का प्रकार। |
| x | **float** | नए चार्ट का x-निर्देशांक, पॉइंट में। |
| y | **float** | नए चार्ट का y-निर्देशांक, पॉइंट में। |
| width | **float** | नए चार्ट की चौड़ाई, पॉइंट में। |
| height | **float** | नए चार्ट की ऊँचाई, पॉइंट में। |
| index | **int** | shape collection में नए चार्ट को सम्मिलित करने के लिए शून्य-आधारित इंडेक्स। |
