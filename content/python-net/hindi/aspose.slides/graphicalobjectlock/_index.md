## GraphicalObjectLock क्लास

निरधारित करता है कि पैरेंट GraphicalObject पर कौन-से संचालन निष्क्रिय हैं।

**विरासत:**[`GraphicalObjectLock`](/slides/python-net/hi/aspose.slides/graphicalobjectlock) → [`BaseShapeLock`](/slides/python-net/hi/aspose.slides/baseshapelock)

GraphicalObjectLock प्रकार नीचे दिए गए सदस्यों को उजागर करता है:

## गुण

| Property | Description |
| :- | :- |
| [`no_locks`](/slides/python-net/hi/aspose.slides/graphicalobjectlock/no_locks/) | यदि सभी lock-flags निष्क्रिय हों तो true लौटाता है।<br/>            केवल-पढ़ने योग्य **bool**. |
| [`grouping_locked`](/slides/python-net/hi/aspose.slides/graphicalobjectlock/grouping_locked/) | निर्धारित करता है कि इस shape को समूह में जोड़ना प्रतिबंधित है या नहीं।<br/>            पढ़ना/लिखना **bool**. |
| [`drilldown_locked`](/slides/python-net/hi/aspose.slides/graphicalobjectlock/drilldown_locked/) | निर्धारित करता है कि इस ऑब्जेक्ट के subshapes का चयन प्रतिबंधित है या नहीं।<br/>            पढ़ना/लिखना **bool**. |
| [`select_locked`](/slides/python-net/hi/aspose.slides/graphicalobjectlock/select_locked/) | निर्धारित करता है कि इस shape का चयन प्रतिबंधित है या नहीं।<br/>            पढ़ना/लिखना **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/hi/aspose.slides/graphicalobjectlock/aspect_ratio_locked/) | निर्धारित करता है कि shape को आकार बदलते समय aspect ratio बनाए रखना चाहिए या नहीं।<br/>            पढ़ना/लिखना **bool**. |
| [`position_locked`](/slides/python-net/hi/aspose.slides/graphicalobjectlock/position_locked/) | निर्धारित करता है कि इस shape को ले जाना प्रतिबंधित है या नहीं।<br/>            पढ़ना/लिखना **bool**. |
| [`size_locked`](/slides/python-net/hi/aspose.slides/graphicalobjectlock/size_locked/) | निर्धारित करता है कि इस shape का आकार बदलना प्रतिबंधित है या नहीं।<br/>            पढ़ना/लिखना **bool**. |
