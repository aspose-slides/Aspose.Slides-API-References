## ShapeStyle वर्ग

शेप की शैली संदर्भ को दर्शाता है।

ShapeStyle प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`line_color`](/slides/python-net/hi/aspose.slides/shapestyle/line_color/) | शेप की रूपरेखा रंग को लौटाता है।<br/>            केवल-पढ़ने योग्य [`IColorFormat`](/slides/python-net/hi/aspose.slides/icolorformat). |
| [`line_style_index`](/slides/python-net/hi/aspose.slides/shapestyle/line_style_index/) | स्टाइल मैट्रिक्स में लाइन के कॉलम अनुक्रमांक को लौटाता है या सेट करता है।<br/>            पढ़ने/लिखने **int**. |
| [`fill_color`](/slides/python-net/hi/aspose.slides/shapestyle/fill_color/) | शेप के फ़िल रंग को लौटाता है।<br/>            केवल-पढ़ने योग्य [`IColorFormat`](/slides/python-net/hi/aspose.slides/icolorformat). |
| [`fill_style_index`](/slides/python-net/hi/aspose.slides/shapestyle/fill_style_index/) | स्टाइल मैट्रिक्स में शेप के फ़िल कॉलम अनुक्रमांक को लौटाता है या सेट करता है।<br/>            0 का अर्थ कोई फ़िल नहीं,<br/>            सकारात्मक मान - थीम के फ़िल शैलियों में अनुक्रमांक,<br/>            नकारात्मक मान - थीम के पृष्ठभूमि शैलियों में अनुक्रमांक।<br/>            पढ़ने/लिखने **int**. |
| [`effect_color`](/slides/python-net/hi/aspose.slides/shapestyle/effect_color/) | शेप के प्रभाव रंग को लौटाता है।<br/>            केवल-पढ़ने योग्य [`IColorFormat`](/slides/python-net/hi/aspose.slides/icolorformat). |
| [`effect_style_index`](/slides/python-net/hi/aspose.slides/shapestyle/effect_style_index/) | स्टाइल मैट्रिक्स में शेप के प्रभाव कॉलम अनुक्रमांक को लौटाता है या सेट करता है।<br/>            पढ़ने/लिखने **int**. |
| [`font_color`](/slides/python-net/hi/aspose.slides/shapestyle/font_color/) | शेप के फ़ॉन्ट रंग को लौटाता है।<br/>            केवल-पढ़ने योग्य [`IColorFormat`](/slides/python-net/hi/aspose.slides/icolorformat). |
| [`font_collection_index`](/slides/python-net/hi/aspose.slides/shapestyle/font_collection_index/) | फ़ॉन्ट संग्रह में शेप के फ़ॉन्ट अनुक्रमांक को लौटाता है या सेट करता है।<br/>            पढ़ने/लिखने [`FontCollectionIndex`](/slides/python-net/hi/aspose.slides/fontcollectionindex). |
