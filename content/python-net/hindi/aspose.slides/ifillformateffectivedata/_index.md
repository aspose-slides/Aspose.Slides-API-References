## IFillFormatEffectiveData क्लास

एक अपरिवर्तनीय वस्तु जो प्रभावी भराव स्वरूपण गुणों को सम्मिलित करती है।

IFillFormatEffectiveData प्रकार निम्न सदस्य प्रदर्शित करता है:

## गुण

| Property | Description |
| :- | :- |
| [`fill_type`](/slides/python-net/hi/aspose.slides/ifillformateffectivedata/fill_type/) | भरण का प्रकार लौटाता है।<br/>            केवल-पढ़ने योग्य [`FillType`](/slides/python-net/hi/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/hi/aspose.slides/ifillformateffectivedata/solid_fill_color/) | भरण रंग लौटाता है।<br/>            केवल-पढ़ने योग्य [`Color`](/slides/python-net/hi/aspose.slides/color). |
| [`solid_fill_scheme_color`](/slides/python-net/hi/aspose.slides/ifillformateffectivedata/solid_fill_scheme_color/) | रंग योजना द्वारा परिभाषित भरण रंग प्राप्त करता है।<br/>            [`SchemeColor.NOT_DEFINED`](/slides/python-net/hi/aspose.slides/schemecolor/NOT_DEFINED) मान इंगित करता है कि [`IFillFormatEffectiveData.solid_fill_color`](/slides/python-net/hi/aspose.slides/ifillformateffectivedata/solid_fill_color) <br/>            कोई योजना रंग नहीं है।<br/>            केवल-पढ़ने योग्य [`SchemeColor`](/slides/python-net/hi/aspose.slides/schemecolor). |
| [`gradient_format`](/slides/python-net/hi/aspose.slides/ifillformateffectivedata/gradient_format/) | ग्रेडिएंट भरण स्वरूप लौटाता है।<br/>            केवल-पढ़ने योग्य [`IGradientFormatEffectiveData`](/slides/python-net/hi/aspose.slides/igradientformateffectivedata). |
| [`pattern_format`](/slides/python-net/hi/aspose.slides/ifillformateffectivedata/pattern_format/) | पैटर्न भरण स्वरूप लौटाता है।<br/>            केवल-पढ़ने योग्य [`IPatternFormatEffectiveData`](/slides/python-net/hi/aspose.slides/ipatternformateffectivedata). |
| [`picture_fill_format`](/slides/python-net/hi/aspose.slides/ifillformateffectivedata/picture_fill_format/) | चित्र भरण स्वरूप लौटाता है।<br/>            केवल-पढ़ने योग्य [`IPictureFillFormatEffectiveData`](/slides/python-net/hi/aspose.slides/ipicturefillformateffectivedata). |
| [`rotate_with_shape`](/slides/python-net/hi/aspose.slides/ifillformateffectivedata/rotate_with_shape/) | निर्धारित करता है कि क्या भरण को आकृति के साथ घुमा दिया जाना चाहिए।<br/>            केवल-पढ़ने योग्य **bool**. |


### टिप्पणियाँ

यह इंटरफ़ेस [`IFillFormat`](/slides/python-net/hi/aspose.slides/ifillformat) इंटरफ़ेस के साथ मिलकर उपयोग किया जाता है ताकि विरासत लागू होने के साथ प्रभावी स्वरूपण मान लौटाए जा सकें।
