## IFillFormatEffectiveData क्लास

एक अपरिवर्तनीय ऑब्जेक्ट जिसमें प्रभावी भराव स्वरूपण गुण होते हैं.

IFillFormatEffectiveData प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| प्रॉपर्टी | विवरण |
| :- | :- |
| [`fill_type`](/slides/python-net/hi/aspose.slides/ifillformateffectivedata/fill_type/) | भराव के प्रकार को वापस करता है.<br/>            केवल-पढ़ने योग्य [`FillType`](/slides/python-net/hi/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/hi/aspose.slides/ifillformateffectivedata/solid_fill_color/) | भराव का रंग वापस करता है.<br/>            केवल-पढ़ने योग्य **aspose.slides.Color**. |
| [`solid_fill_scheme_color`](/slides/python-net/hi/aspose.slides/ifillformateffectivedata/solid_fill_scheme_color/) | रंग योजना द्वारा परिभाषित भराव रंग प्राप्त करता है.<br/>            [`SchemeColor.NOT_DEFINED`](/slides/python-net/hi/aspose.slides/schemecolor/NOT_DEFINED) मान इंगित करता है कि [`IFillFormatEffectiveData.solid_fill_color`](/slides/python-net/hi/aspose.slides/ifillformateffectivedata/solid_fill_color) <br/>            एक योजना रंग नहीं है.<br/>            केवल-पढ़ने योग्य [`SchemeColor`](/slides/python-net/hi/aspose.slides/schemecolor). |
| [`gradient_format`](/slides/python-net/hi/aspose.slides/ifillformateffectivedata/gradient_format/) | ग्रेडिएंट भराव स्वरूप को वापस करता है.<br/>            केवल-पढ़ने योग्य [`IGradientFormatEffectiveData`](/slides/python-net/hi/aspose.slides/igradientformateffectivedata). |
| [`pattern_format`](/slides/python-net/hi/aspose.slides/ifillformateffectivedata/pattern_format/) | पैटर्न भराव स्वरूप को वापस करता है.<br/>            केवल-पढ़ने योग्य [`IPatternFormatEffectiveData`](/slides/python-net/hi/aspose.slides/ipatternformateffectivedata). |
| [`picture_fill_format`](/slides/python-net/hi/aspose.slides/ifillformateffectivedata/picture_fill_format/) | चित्र भराव स्वरूप को वापस करता है.<br/>            केवल-पढ़ने योग्य [`IPictureFillFormatEffectiveData`](/slides/python-net/hi/aspose.slides/ipicturefillformateffectivedata). |
| [`rotate_with_shape`](/slides/python-net/hi/aspose.slides/ifillformateffectivedata/rotate_with_shape/) | निर्धारित करता है कि भराव को आकार के साथ घुमाया जाना चाहिए या नहीं.<br/>            केवल-पढ़ने योग्य **bool**. |


### टिप्पणी

यह इंटरफ़ेस [`IFillFormat`](/slides/python-net/hi/aspose.slides/ifillformat) इंटरफ़ेस के साथ मिलकर उपयोग किया जाता है ताकि विरासत लागू होने के साथ प्रभावी स्वरूपण मान लौटाए जा सकें.
