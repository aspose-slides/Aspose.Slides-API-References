## x प्रॉपर्टी
शेप के ऊपरी-बाएँ कोने के x-निर्देशांक को प्राप्त करता है या सेट करता है, जिसे पॉइंट्स में मापा जाता है।
            पढ़ें/लिखें **float**.


### टिप्पणियाँ

वापसी मान हमेशा परिभाषित होता है और कभी **float** नहीं होता।
            निर्धारित मान भी परिभाषित होना चाहिए; **float** को केवल `RawFrame` इंस्टेंस की प्रॉपर्टीज़ को ही असाइन करें।

### परिभाषा:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
