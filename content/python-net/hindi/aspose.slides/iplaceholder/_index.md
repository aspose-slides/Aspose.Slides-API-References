## IPlaceholder क्लास

एक स्लाइड पर Placeholder का प्रतिनिधित्व करता है।

IPlaceholder प्रकार निम्नलिखित सदस्य प्रदान करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`orientation`](/slides/python-net/hi/aspose.slides/iplaceholder/orientation/) | Placeholder की अभिविन्यास प्राप्त करता है।<br/>            केवल-पढ़ने योग्य [`Orientation`](/slides/python-net/hi/aspose.slides/orientation). |
| [`size`](/slides/python-net/hi/aspose.slides/iplaceholder/size/) | Placeholder का आकार प्राप्त करता है।<br/>            केवल-पढ़ने योग्य [`PlaceholderSize`](/slides/python-net/hi/aspose.slides/placeholdersize). |
| [`type`](/slides/python-net/hi/aspose.slides/iplaceholder/type/) | Placeholder का प्रकार प्राप्त करता है।<br/>            केवल-पढ़ने योग्य [`PlaceholderType`](/slides/python-net/hi/aspose.slides/placeholdertype). |
| [`index`](/slides/python-net/hi/aspose.slides/iplaceholder/index/) | Placeholder का सूचकांक प्राप्त करता है।<br/>            केवल-पढ़ने योग्य **int**. |
