## IPatternFormat क्लास

एक आकार को भरने के लिए पैटर्न का प्रतिनिधित्व करता है।

IPatternFormat प्रकार निम्न सदस्य प्रदान करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`pattern_style`](/slides/python-net/hi/aspose.slides/ipatternformat/pattern_style/) | पैटर्न शैली को वापस देता है या सेट करता है.<br/> पढ़ें/लिखें [`PatternStyle`](/slides/python-net/hi/aspose.slides/patternstyle). |
| [`fore_color`](/slides/python-net/hi/aspose.slides/ipatternformat/fore_color/) | फ़ोरग्राउंड पैटर्न रंग को वापस देता है.<br/> केवल पढ़ने योग्य [`IColorFormat`](/slides/python-net/hi/aspose.slides/icolorformat). |
| [`back_color`](/slides/python-net/hi/aspose.slides/ipatternformat/back_color/) | बैकग्राउंड पैटर्न रंग को वापस देता है.<br/> केवल पढ़ने योग्य [`IColorFormat`](/slides/python-net/hi/aspose.slides/icolorformat). |
