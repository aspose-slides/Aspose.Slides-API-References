## TextSearchOptions क्लास

प्रस्तुति, Slide या TextFrame में टेक्स्ट खोजने के लिए उपयोग किए जा सकने वाले विकल्पों का प्रतिनिधित्व करता है।

TextSearchOptions प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## निर्माताओं

| निर्माता | विवरण |
| :- | :- |
| [`__init__(self)`](/slides/python-net/hi/aspose.slides/textsearchoptions/__init__/#) | नई डिफ़ॉल्ट टेक्स्ट खोज विकल्प बनाता है। |

## गुण

| गुण | विवरण |
| :- | :- |
| [`case_sensitive`](/slides/python-net/hi/aspose.slides/textsearchoptions/case_sensitive/) | true सेट करें ताकि केस-सेंसिटिव खोज उपयोग हो, false - अन्यथा।<br/>            पढ़ना/लिखना **bool**. |
| [`whole_words_only`](/slides/python-net/hi/aspose.slides/textsearchoptions/whole_words_only/) | true सेट करें ताकि केवल पूरे शब्द मेल हों, false - अन्यथा।<br/>            पढ़ना/लिखना **bool**. |
| [`include_notes`](/slides/python-net/hi/aspose.slides/textsearchoptions/include_notes/) | `true` सेट करें ताकि स्लाइड नोट्स ([`NotesSlide`](/slides/python-net/hi/aspose.slides/notesslide)) में मौजूद पाठ शामिल हो <br/>            जब टेक्स्ट खोज, प्रतिस्थापन, या हाइलाइटिंग ऑपरेशन किया जा रहा हो।<br/>            डिफ़ॉल्ट मान `false` है। |
