## ILineFillFormat वर्ग

रेखाओं के भराव के लिए गुणों का प्रतिनिधित्व करता है।

ILineFillFormat प्रकार निम्नलिखित सदस्य प्रदर्शित करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`fill_type`](/slides/python-net/hi/aspose.slides/ilinefillformat/fill_type/) | भरण प्रकार को लौटाता है या सेट करता है।<br/>            पढ़ें/लिखें [`FillType`](/slides/python-net/hi/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/hi/aspose.slides/ilinefillformat/solid_fill_color/) | सॉलिड भराव का रंग लौटाता है।<br/>            केवल-पढ़ने योग्य [`IColorFormat`](/slides/python-net/hi/aspose.slides/icolorformat). |
| [`gradient_format`](/slides/python-net/hi/aspose.slides/ilinefillformat/gradient_format/) | ग्रेडिएंट भराव प्रारूप लौटाता है।<br/>            केवल-पढ़ने योग्य [`IGradientFormat`](/slides/python-net/hi/aspose.slides/igradientformat). |
| [`pattern_format`](/slides/python-net/hi/aspose.slides/ilinefillformat/pattern_format/) | पैटर्न भराव प्रारूप लौटाता है।<br/>            केवल-पढ़ने योग्य [`IPatternFormat`](/slides/python-net/hi/aspose.slides/ipatternformat). |
| [`rotate_with_shape`](/slides/python-net/hi/aspose.slides/ilinefillformat/rotate_with_shape/) | निर्धारित करता है कि भराव को आकार के साथ घुमाया जाना चाहिए या नहीं।<br/>            पढ़ें/लिखें [`NullableBool`](/slides/python-net/hi/aspose.slides/nullablebool). |
