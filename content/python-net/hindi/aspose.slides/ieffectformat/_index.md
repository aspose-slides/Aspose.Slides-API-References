## IEffectFormat क्लास

आकृति की प्रभाव गुणों का प्रतिनिधित्व करता है।

IEffectFormat प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`is_no_effects`](/slides/python-net/hi/aspose.slides/ieffectformat/is_no_effects/) | यदि सभी प्रभाव निष्क्रिय हैं तो true लौटाता है (जैसे अभी बनाया गया, डिफॉल्ट EffectFormat ऑब्जेक्ट)।<br/>            केवल-पढ़ने-योग्य **bool**. |
| [`blur_effect`](/slides/python-net/hi/aspose.slides/ieffectformat/blur_effect/) | ब्लर प्रभाव।<br/>            पढ़ें/लिखें [`IBlur`](/slides/python-net/hi/aspose.slides.effects/iblur). |
| [`fill_overlay_effect`](/slides/python-net/hi/aspose.slides/ieffectformat/fill_overlay_effect/) | फ़िल ओवरले प्रभाव।<br/>            पढ़ें/लिखें [`IFillOverlay`](/slides/python-net/hi/aspose.slides.effects/ifilloverlay). |
| [`glow_effect`](/slides/python-net/hi/aspose.slides/ieffectformat/glow_effect/) | ग्लो प्रभाव।<br/>            पढ़ें/लिखें [`IGlow`](/slides/python-net/hi/aspose.slides.effects/iglow). |
| [`inner_shadow_effect`](/slides/python-net/hi/aspose.slides/ieffectformat/inner_shadow_effect/) | आंतरिक छाया।<br/>            पढ़ें/लिखें [`IInnerShadow`](/slides/python-net/hi/aspose.slides.effects/iinnershadow). |
| [`outer_shadow_effect`](/slides/python-net/hi/aspose.slides/ieffectformat/outer_shadow_effect/) | बाहरी छाया।<br/>            पढ़ें/लिखें [`IOuterShadow`](/slides/python-net/hi/aspose.slides.effects/ioutershadow). |
| [`preset_shadow_effect`](/slides/python-net/hi/aspose.slides/ieffectformat/preset_shadow_effect/) | पूर्वनिर्धारित छाया।<br/>            पढ़ें/लिखें [`IPresetShadow`](/slides/python-net/hi/aspose.slides.effects/ipresetshadow). |
| [`reflection_effect`](/slides/python-net/hi/aspose.slides/ieffectformat/reflection_effect/) | प्रतिबिंब। <br/>            पढ़ें/लिखें [`IReflection`](/slides/python-net/hi/aspose.slides.effects/ireflection). |
| [`soft_edge_effect`](/slides/python-net/hi/aspose.slides/ieffectformat/soft_edge_effect/) | नरम किनारा।<br/>            पढ़ें/लिखें [`ISoftEdge`](/slides/python-net/hi/aspose.slides.effects/isoftedge). |
