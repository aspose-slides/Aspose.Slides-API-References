## ShapesAlignmentType enumeration

स्लाइड पर चयनित आकृतियों की स्थिती बदलने का एक तरीका परिभाषित करता है।

ShapesAlignmentType प्रकार निम्नलिखित सदस्यों को प्रकट करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| ALIGN_LEFT | बाएँ संरेखित |
| ALIGN_RIGHT | दाएँ संरेखित |
| ALIGN_CENTER | केंद्रीय संरेखित |
| ALIGN_TOP | ऊपर संरेखित |
| ALIGN_MIDDLE | मध्य में संरेखित |
| ALIGN_BOTTOM | नीचे संरेखित |
| DISTRIBUTE_HORIZONTALLY | क्षितिजीय रूप से वितरित |
| DISTRIBUTE_VERTICALLY | ऊर्ध्वाधर रूप से वितरित |
