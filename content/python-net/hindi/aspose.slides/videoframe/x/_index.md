## x प्रॉपर्टी
आकार के ऊपर-बाएँ कोने के x-निर्देशांक को प्राप्त करता है या सेट करता है, जिसे बिंदुओं में मापा जाता है।
            पढ़ें/लिखें **float**.


### टिप्पणी

वापस किया गया मान हमेशा परिभाषित रहता है और कभी **float** नहीं होता है।
            असाइन किया गया मान भी परिभाषित होना चाहिए; केवल `RawFrame` इंस्टेंस की प्रॉपर्टीज़ को **float** असाइन करें।

### परिभाषा:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
