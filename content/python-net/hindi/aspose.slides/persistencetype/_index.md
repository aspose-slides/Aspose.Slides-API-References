## PersistenceType एन्युमरेशन

ActiveX नियंत्रण की गुणों को संग्रहीत करने के लिए प्रयुक्त विधि को निर्दिष्ट करता है।

The PersistenceType type exposes the following members:

## फ़ील्ड

| फ़ील्ड | विवरण |
| :- | :- |
| NOT_DEFINED | स्थायित्व id निर्दिष्ट नहीं है। |
| PERSIST_PROPERTY_BAG | यह निर्दिष्ट करता है कि ActiveX नियंत्रण को property-bag-आधारित persistence का उपयोग करके स्थायी किया जाता है। <br/>             Property-bag-आधारित persistence नाम और मान जोड़ों के संग्रह द्वारा एक ActiveX नियंत्रण को संग्रहीत करता है जो ActiveX नियंत्रण द्वारा स्थायी किए गए डेटा को निर्दिष्ट करते हैं। |
| PERSIST_STREAM | यह निर्दिष्ट करता है कि ActiveX नियंत्रण को stream-आधारित persistence का उपयोग करके स्थायी किया जाता है <br/>             जो ActiveX नियंत्रण को डिफ़ॉल्ट स्थिति में प्रारंभ करने का समर्थन नहीं करता। |
| PERSIST_STREAM_INIT | यह निर्दिष्ट करता है कि ActiveX नियंत्रण को stream-आधारित persistence का उपयोग करके स्थायी किया जाता है <br/>             जो ActiveX नियंत्रण को डिफ़ॉल्ट स्थिति में प्रारंभ करने का समर्थन करता है। |
| PERSIST_STORAGE | यह निर्दिष्ट करता है कि ActiveX नियंत्रण को storage-आधारित persistence का उपयोग करके स्थायी किया जाता है। |
