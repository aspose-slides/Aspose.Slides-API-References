## IColorFormat वर्ग

एक प्रस्तुति में उपयोग किए गए रंग का प्रतिनिधित्व करता है।

IColorFormat प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`color_type`](/slides/python-net/hi/aspose.slides/icolorformat/color_type/) | रंग परिभाषा विधि को प्राप्त करता है या सेट करता है।<br/>            पढ़ें/लिखें [`ColorType`](/slides/python-net/hi/aspose.slides/colortype). |
| [`color`](/slides/python-net/hi/aspose.slides/icolorformat/color/) | परिणामी रंग को लौटाता है (सभी रंग रूपान्तरण लागू करके)।<br/>            RGB रंग सेट करता है और सभी रंग रूपान्तरण साफ करता है।<br/>            पढ़ें/लिखें **aspose.slides.Color**. |
| [`preset_color`](/slides/python-net/hi/aspose.slides/icolorformat/preset_color/) | रंग प्रीसेट को प्राप्त करता है या सेट करता है।<br/>            पढ़ें/लिखें [`PresetColor`](/slides/python-net/hi/aspose.slides/presetcolor). |
| [`system_color`](/slides/python-net/hi/aspose.slides/icolorformat/system_color/) | सिस्टम रंग तालिका द्वारा पहचाने गए रंग को प्राप्त करता है या सेट करता है।<br/>            पढ़ें/लिखें [`SystemColor`](/slides/python-net/hi/aspose.slides/systemcolor). |
| [`scheme_color`](/slides/python-net/hi/aspose.slides/icolorformat/scheme_color/) | रंग योजना द्वारा पहचाने गए रंग को प्राप्त करता है या सेट करता है।<br/>            पढ़ें/लिखें [`SchemeColor`](/slides/python-net/hi/aspose.slides/schemecolor). |
| [`r`](/slides/python-net/hi/aspose.slides/icolorformat/r/) | रंग के लाल घटक को प्राप्त करता है या सेट करता है। सभी रंग रूपान्तरण को अनदेखा किया जाता है।<br/>            पढ़ें/लिखें **int**. |
| [`g`](/slides/python-net/hi/aspose.slides/icolorformat/g/) | रंग के हरे घटक को प्राप्त करता है या सेट करता है। सभी रंग रूपान्तरण को अनदेखा किया जाता है।<br/>            पढ़ें/लिखें **int**. |
| [`b`](/slides/python-net/hi/aspose.slides/icolorformat/b/) | रंग के नीले घटक को प्राप्त करता है या सेट करता है। सभी रंग रूपान्तरण को अनदेखा किया जाता है।<br/>            पढ़ें/लिखें **int**. |
| [`float_r`](/slides/python-net/hi/aspose.slides/icolorformat/float_r/) | रंग के लाल घटक को प्राप्त करता है या सेट करता है। सभी रंग रूपान्तरण को अनदेखा किया जाता है।<br/>            पढ़ें/लिखें **float**. |
| [`float_g`](/slides/python-net/hi/aspose.slides/icolorformat/float_g/) | रंग के हरे घटक को प्राप्त करता है या सेट करता है। सभी रंग रूपान्तरण को अनदेखा किया जाता है।<br/>            पढ़ें/लिखें **float**. |
| [`float_b`](/slides/python-net/hi/aspose.slides/icolorformat/float_b/) | रंग के नीले घटक को प्राप्त करता है या सेट करता है। सभी रंग रूपान्तरण को अनदेखा किया जाता है।<br/>            पढ़ें/लिखें **float**. |
| [`hue`](/slides/python-net/hi/aspose.slides/icolorformat/hue/) | HSL प्रतिनिधित्व में रंग के ह्यू घटक को प्राप्त करता है या सेट करता है।<br/>            सभी रंग रूपान्तरण को अनदेखा किया जाता है।<br/>            पढ़ें/लिखें **float**. |
| [`saturation`](/slides/python-net/hi/aspose.slides/icolorformat/saturation/) | HSL प्रतिनिधित्व में रंग के संतृप्ति घटक को प्राप्त करता है या सेट करता है।<br/>            सभी रंग रूपान्तरण को अनदेखा किया जाता है।<br/>            पढ़ें/लिखें **float**. |
| [`luminance`](/slides/python-net/hi/aspose.slides/icolorformat/luminance/) | HSL प्रतिनिधित्व में रंग के चमक घटक को प्राप्त करता है या सेट करता है।<br/>            सभी रंग रूपान्तरण को अनदेखा किया जाता है।<br/>            पढ़ें/लिखें **float**. |
| [`color_transform`](/slides/python-net/hi/aspose.slides/icolorformat/color_transform/) | रंग पर लागू किए गए रंग रूपान्तरणों का संग्रह लौटाता है।<br/>            केवल पढ़ने योग्य [`IColorOperationCollection`](/slides/python-net/hi/aspose.slides/icoloroperationcollection). |
