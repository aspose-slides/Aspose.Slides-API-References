## IViewProperties वर्ग

प्रस्तुति-व्यापी दृश्य गुण।

IViewProperties प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`last_view`](/slides/python-net/hi/aspose.slides/iviewproperties/last_view/) | उस दृश्य मोड को निर्दिष्ट करता है जो प्रस्तुति दस्तावेज़ को अंतिम बार सहेजते समय उपयोग किया गया था।<br/>            पढ़ें/लिखें [`ViewType`](/slides/python-net/hi/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/hi/aspose.slides/iviewproperties/show_comments/) | निर्दिष्ट करता है कि स्लाइड टिप्पणी दिखाई जानी चाहिए या नहीं।<br/>            पढ़ें/लिखें [`NullableBool`](/slides/python-net/hi/aspose.slides/nullablebool). |
| [`slide_view_properties`](/slides/python-net/hi/aspose.slides/iviewproperties/slide_view_properties/) | स्लाइड दृश्य मोड से संबंधित सामान्य दृश्य गुण निर्दिष्ट करता है।<br/>            केवल पढ़ने योग्य [`ICommonSlideViewProperties`](/slides/python-net/hi/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/hi/aspose.slides/iviewproperties/notes_view_properties/) | नोट्स दृश्य मोड से संबंधित सामान्य दृश्य गुण निर्दिष्ट करता है।<br/>            केवल पढ़ने योग्य [`ICommonSlideViewProperties`](/slides/python-net/hi/aspose.slides/icommonslideviewproperties). |
| [`normal_view_properties`](/slides/python-net/hi/aspose.slides/iviewproperties/normal_view_properties/) | सामान्य दृश्य गुणों का प्रतिनिधित्व करता है। सामान्य दृश्य में शामिल है<br/>            तीन सामग्री क्षेत्रों: स्वयं स्लाइड, एक साइड सामग्री क्षेत्र, और एक निचला सामग्री क्षेत्र।<br/>            केवल पढ़ने योग्य [`INormalViewProperties`](/slides/python-net/hi/aspose.slides/inormalviewproperties). |
| [`grid_spacing`](/slides/python-net/hi/aspose.slides/iviewproperties/grid_spacing/) | ग्रिड स्पेसिंग जो प्रस्तुति दस्तावेज़ के नीचे मौजूद ग्रिड के लिए बिंदुओं में उपयोग की जानी चाहिए, उसे लौटाता है या सेट करता है। <br/>            पढ़ें/लिखें **float**. |
