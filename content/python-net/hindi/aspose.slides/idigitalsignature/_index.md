## IDigitalSignature क्लास

हस्ताक्षरित फ़ाइल में डिजिटल हस्ताक्षर।

IDigitalSignature प्रकार निम्न सदस्यों को उजागर करता है:

## गुण

| प्रॉपर्टी | विवरण |
| :- | :- |
| [`certificate`](/slides/python-net/hi/aspose.slides/idigitalsignature/certificate/) | दस्तावेज़ पर हस्ताक्षर करने के लिए उपयोग किया गया प्रमाणपत्र ऑब्जेक्ट।<br/>            केवल-पढ़ने योग्य **System.Security.Cryptography.X509Certificates.X509Certificate2**. |
| [`is_valid`](/slides/python-net/hi/aspose.slides/idigitalsignature/is_valid/) | यदि यह डिजिटल सिग्नेचर वैध है और दस्तावेज़ में कोई छेड़छाड़ नहीं की गई है, तो यह मान सत्य होगा।<br/>            केवल-पढ़ने योग्य **bool**. |
| [`sign_time`](/slides/python-net/hi/aspose.slides/idigitalsignature/sign_time/) | दस्तावेज़ पर हस्ताक्षर किए जाने का समय।<br/>            केवल-पढ़ने योग्य **System.DateTime**. |
| [`comments`](/slides/python-net/hi/aspose.slides/idigitalsignature/comments/) | हस्ताक्षर का उद्देश्य।<br/>            पढ़ने-लिखने योग्य **str**. |
