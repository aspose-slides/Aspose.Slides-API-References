## ModernComment कक्षा

स्लाइड पर एक टिप्पणी का प्रतिनिधित्व करता है।

**विरासत:**[`ModernComment`](/slides/python-net/hi/aspose.slides/moderncomment) → [`Comment`](/slides/python-net/hi/aspose.slides/comment)

ModernComment प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`text`](/slides/python-net/hi/aspose.slides/moderncomment/text/) | स्लाइड टिप्पणी का साधारण पाठ वापस करता है या सेट करता है.<br/>            पढ़ें/लिखें **str**. |
| [`created_time`](/slides/python-net/hi/aspose.slides/moderncomment/created_time/) | टिप्पणी निर्माण का समय वापस करता है या सेट करता है.<br/>            इस गुण को **System.DateTime** पर सेट करने का मतलब है कि टिप्पणी समय सेट नहीं किया गया है.<br/>            पढ़ें/लिखें **System.DateTime**. |
| [`slide`](/slides/python-net/hi/aspose.slides/moderncomment/slide/) | टिप्पणी की मूल स्लाइड को वापस करता है या सेट करता है.<br/>            केवल-पढ़ने योग्य [`ISlide`](/slides/python-net/hi/aspose.slides/islide). |
| [`author`](/slides/python-net/hi/aspose.slides/moderncomment/author/) | टिप्पणी के लेखक को वापस करता है.<br/>            केवल-पढ़ने योग्य [`ICommentAuthor`](/slides/python-net/hi/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/hi/aspose.slides/moderncomment/position/) | स्लाइड पर टिप्पणी की स्थिति को वापस करता है या सेट करता है.<br/>            पढ़ें/लिखें **aspose.slides.PointF**. |
| [`parent_comment`](/slides/python-net/hi/aspose.slides/moderncomment/parent_comment/) | मूल टिप्पणी को प्राप्त करता है या सेट करता है.<br/>            पढ़ें/लिखें [`IComment`](/slides/python-net/hi/aspose.slides/icomment). |
| [`shape`](/slides/python-net/hi/aspose.slides/moderncomment/shape/) | टिप्पणी से जुड़ा आकार वापस करता है.<br/>            केवल-पढ़ने योग्य [`IShape`](/slides/python-net/hi/aspose.slides/ishape). |
| [`text_selection_start`](/slides/python-net/hi/aspose.slides/moderncomment/text_selection_start/) | यदि टिप्पणी AutoShape से जुड़ी हो तो टेक्स्ट फ्रेम में टेक्स्ट चयन की प्रारंभिक स्थिति को प्राप्त करता है या सेट करता है.<br/>            पढ़ें/लिखें **int**. |
| [`text_selection_length`](/slides/python-net/hi/aspose.slides/moderncomment/text_selection_length/) | यदि टिप्पणी AutoShape से जुड़ी हो तो टेक्स्ट फ्रेम में टेक्स्ट चयन की लंबाई को प्राप्त करता है या सेट करता है.<br/>            पढ़ें/लिखें **int**. |
| [`status`](/slides/python-net/hi/aspose.slides/moderncomment/status/) | टिप्पणी की स्थिति को प्राप्त करता है या सेट करता है.<br/>            पढ़ें/लिखें [`ModernCommentStatus`](/slides/python-net/hi/aspose.slides/moderncommentstatus). |
