## INormalViewProperties क्लास

नॉर्मल व्यू प्रॉपर्टीज़ का प्रतिनिधित्व करता है। नॉर्मल व्यू में तीन सामग्री क्षेत्र होते हैं: स्लाइड स्वयं, एक साइड सामग्री क्षेत्र, और एक बॉटम सामग्री क्षेत्र।

INormalViewProperties प्रकार निम्नलिखित सदस्य उजागर करता है:

## प्रॉपर्टीज़

| Property | Description |
| :- | :- |
| [`show_outline_icons`](/slides/python-net/hi/aspose.slides/inormalviewproperties/show_outline_icons/) | निर्दिष्ट करता है कि क्या एप्लिकेशन को किसी भी सामग्री क्षेत्र में रूपरेखा सामग्री प्रदर्शित करते समय आइकन दिखाने चाहिए।<br/>            Read/write **bool**. |
| [`snap_vertical_splitter`](/slides/python-net/hi/aspose.slides/inormalviewproperties/snap_vertical_splitter/) | निर्दिष्ट करता है कि जब साइड क्षेत्र पर्याप्त छोटा हो तो वर्टिकल स्प्लिटर को न्यूनतम अवस्था में स्नैप करना चाहिए या नहीं।<br/>            Read/write **bool**. |
| [`vertical_bar_state`](/slides/python-net/hi/aspose.slides/inormalviewproperties/vertical_bar_state/) | निर्दिष्ट करता है कि वर्टिकल स्प्लिटर बार किस अवस्था में दिखाया जाना चाहिए। <br/>            एक वर्टिकल स्प्लिटर बार स्लाइड को साइड सामग्री क्षेत्र से अलग करता है। |
| [`horizontal_bar_state`](/slides/python-net/hi/aspose.slides/inormalviewproperties/horizontal_bar_state/) | निर्दिष्ट करता है कि हॉरिज़ॉन्टल स्प्लिटर बार किस अवस्था में दिखाया जाना चाहिए।<br/>            एक हॉरिज़ॉन्टल स्प्लिटर बार स्लाइड को स्लाइड के नीचे की सामग्री क्षेत्र से अलग करता है। |
| [`prefer_single_view`](/slides/python-net/hi/aspose.slides/inormalviewproperties/prefer_single_view/) | निर्दिष्ट करता है कि उपयोगकर्ता मानक नॉर्मल व्यू के तीन सामग्री क्षेत्रों के बजाए पूर्ण-विंडो एकल-समग्री क्षेत्र देखना चाहता है या नहीं। यदि सक्षम है, तो एप्लिकेशन पूरे विंडो में किसी एक सामग्री क्षेत्र को प्रदर्शित करने का चयन कर सकता है।<br/>            Read/write **bool**. |
| [`restored_left`](/slides/python-net/hi/aspose.slides/inormalviewproperties/restored_left/) | यह तत्व नॉर्मल व्यू के साइड सामग्री क्षेत्र के आकार को निर्दिष्ट करता है, जब यह रेस्टोर्ड आकार (न्यूनतम या अधिकतम नहीं) में हो।<br/>            केवल पढ़ने योग्य [`INormalViewRestoredProperties`](/slides/python-net/hi/aspose.slides/inormalviewrestoredproperties). |
| [`restored_top`](/slides/python-net/hi/aspose.slides/inormalviewproperties/restored_top/) | यह तत्व नॉर्मल व्यू के टॉप स्लाइड क्षेत्र के आकार को निर्दिष्ट करता है, जब यह रेस्टोर्ड आकार (न्यूनतम या अधिकतम नहीं) में हो।<br/>            केवल पढ़ने योग्य [`INormalViewRestoredProperties`](/slides/python-net/hi/aspose.slides/inormalviewrestoredproperties). |
