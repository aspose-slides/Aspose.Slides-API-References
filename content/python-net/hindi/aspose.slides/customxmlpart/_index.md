## CustomXmlPart क्लास

कस्टम XML भाग का प्रतिनिधित्व करता है।

CustomXmlPart प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| संपत्ति | विवरण |
| :- | :- |
| [`xml_data`](/slides/python-net/hi/aspose.slides/customxmlpart/xml_data/) | XML डेटा को प्राप्त करता है या सेट करता है।<br/>            पढ़ें/लिखें **int**[].<br/>            मान `None` है। मान खाली है या XML-डेटा अमान्य है। |
| [`xml_as_string`](/slides/python-net/hi/aspose.slides/customxmlpart/xml_as_string/) | XML डेटा को UTF-8 स्ट्रिंग के रूप में प्राप्त करता है या सेट करता है।<br/>            पढ़ें/लिखें **str**।<br/>            मान `None` है। मान खाली है या XML-डेटा अमान्य है। |
| [`item_id`](/slides/python-net/hi/aspose.slides/customxmlpart/item_id/) | एक वैश्विक रूप से अद्वितीय पहचानकर्ता (GUID) निर्दिष्ट करता है जो Office Open XML दस्तावेज़ के भीतर एक एकल कस्टम XML <br/>            भाग को विशिष्ट रूप से पहचानता है।<br/>            केवल-पढ़ने योग्य **System.Guid**। |
| [`namespace_schemas`](/slides/python-net/hi/aspose.slides/customxmlpart/namespace_schemas/) | कस्टम XML भाग के साथ जुड़े संग्रह XML स्कीमा को प्राप्त करता है।<br/>            केवल-पढ़ने योग्य **str**[]. |
