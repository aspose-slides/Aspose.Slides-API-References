## FillType एन्यूमरेशन

विभिन्न दृश्य वस्तुओं के आंतरिक भराव प्रकार को निर्दिष्ट करता है।

FillType प्रकार निम्नलिखित सदस्य प्रकट करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| NOT_DEFINED | भरण प्रकार परिभाषित नहीं है। |
| NO_FILL | कोई भराव लागू नहीं किया गया। |
| SOLID | एक ठोस रंग से भरा हुआ। |
| GRADIENT | भरण ग्रेडिएंट है। |
| PATTERN | वस्तु को भरने के लिए दोहराया गया पैटर्न प्रयोग किया जाता है। |
| PICTURE | वस्तु को भरने के लिए एक चित्र प्रयोग किया जाता है। |
| GROUP | विज़ुअल ऑब्जेक्ट समूह से भरण गुणों को विरासत में लेता है। |
