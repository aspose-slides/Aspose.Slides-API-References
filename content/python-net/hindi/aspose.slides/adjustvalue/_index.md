## AdjustValue क्लास

एक ज्यामिति आकार के समायोजन मान का प्रतिनिधित्व करता है.  
            ये मान आकार के रूप को प्रभावित करते हैं.

AdjustValue प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## Properties

| Property | Description |
| :- | :- |
| [`raw_value`](/slides/python-net/hi/aspose.slides/adjustvalue/raw_value/) | समायोजन मान को जैसा है वैसा लौटाता है या सेट करता है.<br/>            पढ़ें/लिखें **int**. |
| [`angle_value`](/slides/python-net/hi/aspose.slides/adjustvalue/angle_value/) | मान को लौटाता है या सेट करता है, जिसे डिग्री में कोण के रूप में व्याख्यायित किया जाता है.<br/>            पढ़ें/लिखें **float**. |
| [`name`](/slides/python-net/hi/aspose.slides/adjustvalue/name/) | इस समायोजन मान का नाम लौटाता है.<br/>            केवल- पढ़ें **str**. |
| [`type`](/slides/python-net/hi/aspose.slides/adjustvalue/type/) | आकार समायोजन का प्रकार लौटाता है.<br/>            केवल- पढ़ें [`ShapeAdjustmentType`](/slides/python-net/hi/aspose.slides/shapeadjustmenttype). |
