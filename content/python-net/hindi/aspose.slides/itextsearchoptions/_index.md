## ITextSearchOptions क्लास

प्रस्तुति, स्लाइड या टेक्स्टफ़्रेम में टेक्स्ट खोजने के लिए उपयोग किए जा सकने वाले विकल्पों का प्रतिनिधित्व करता है।

ITextSearchOptions प्रकार निम्नलिखित सदस्य उजागर करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`case_sensitive`](/slides/python-net/hi/aspose.slides/itextsearchoptions/case_sensitive/) | केस-सेंसिटिव खोज के लिए true सेट करें, अन्यथा false।<br/>            पढ़ने/लिखने योग्य **bool**. |
| [`whole_words_only`](/slides/python-net/hi/aspose.slides/itextsearchoptions/whole_words_only/) | केवल पूर्ण शब्दों से मेल खाने के लिए true सेट करें, अन्यथा false।<br/>            पढ़ने/लिखने योग्य **bool**. |
| [`include_notes`](/slides/python-net/hi/aspose.slides/itextsearchoptions/include_notes/) | स्लाइड नोट्स में मौजूद टेक्स्ट को शामिल करने के लिए `true` सेट करें <br/>            जब टेक्स्ट खोज, प्रतिस्थापन, या हाइलाइटिंग ऑपरेशन किया जा रहा हो।<br/>            डिफ़ॉल्ट मान `false` है। |
