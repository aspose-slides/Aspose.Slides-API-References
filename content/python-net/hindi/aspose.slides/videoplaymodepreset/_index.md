## VideoPlayModePreset एन्यूमरेशन

वीडियो कैसे चलाया जाता है, इसे परिभाषित करने वाले स्थिरांक।

VideoPlayModePreset प्रकार निम्नलिखित सदस्य उजागर करता है:

## फ़ील्ड

| Field | विवरण |
| :- | :- |
| MIXED |  |
| AUTO | स्वचालित रूप से चलाएँ। |
| ON_CLICK | केवल तब चलाएँ जब वीडियो फ्रेम पर क्लिक किया जाए। |
| ALL_SLIDES | सभी स्लाइड्स पर चलाएँ। |
| IN_CLICK_SEQUENCE | क्लिक के साथ स्वचालित रूप से चलाएँ। |
