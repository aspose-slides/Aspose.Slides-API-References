## x प्रॉपर्टी
आकृति के ऊपरी बाएँ कोने के x-निर्देशांक को प्राप्त करता है या सेट करता है, जिसे पॉइंट्स में मापा गया है।
            पढ़ने/लिखने योग्य **float**.


### टिप्पणियाँ

वापसी मान हमेशा परिभाषित रहता है और कभी **float** नहीं होता।
            आबंटित किया गया मान भी परिभाषित होना चाहिए; केवल `RawFrame` इकाई की प्रॉपर्टीज़ को ही **float** असाइन करें।

### परिभाषा:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
