## unique_id गुण
Returns an internal, presentation-scoped identifier intended for use by add-ins or other code.
            क्योंकि इस मान को उपयोगकर्ता या प्रोग्राम द्वारा पुनः असाइन किया जा सकता है, इसे स्थायी अद्वितीय कुंजी के रूप में नहीं माना जाना चाहिए।
            पढ़ने-केवल **int**।
            इसे भी देखें [`Shape.office_interop_shape_id`](/slides/python-net/hi/aspose.slides/shape/office_interop_shape_id).
