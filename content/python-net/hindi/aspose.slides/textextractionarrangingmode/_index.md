## TextExtractionArrangingMode एन्यूमरेशन

टेक्स्ट निष्कर्षण के दौरान उपयोग करने के मोड का प्रतिनिधित्व करता है

TextExtractionArrangingMode प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| UNARRANGED | स्लाइड पर स्थिति की परवाह किए बिना कच्चा टेक्स्ट |
| ARRANGED | टेक्स्ट स्लाइड पर जैसे क्रम में है, उसी क्रम में स्थित है |
