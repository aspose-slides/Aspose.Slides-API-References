## TextAlignment एन्यूमरेशन

विभिन्न टेक्स्ट एलाइनमेंट शैलियों का प्रतिनिधित्व करता है।

The TextAlignment type निम्नलिखित सदस्यों को प्रकट करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| NOT_DEFINED | डिफ़ॉल्ट संरेखण। |
| LEFT | बाएँ संरेखण। |
| CENTER | केंद्र संरेखण। |
| RIGHT | दाएँ संरेखण। |
| JUSTIFY | जस्टिफ़ाइ संरेखण। |
| JUSTIFY_LOW | कशीदा जस्टिफ़ाइ लो। |
| DISTRIBUTED | वितरित संरेखण। |
