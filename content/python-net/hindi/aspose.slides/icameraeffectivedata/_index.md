## ICameraEffectiveData वर्ग

एक अपरिवर्तनीय वस्तु जो प्रभावी कैमरा गुणों को समाहित करती है।

ICameraEffectiveData प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| Property | Description |
| :- | :- |
| [`camera_type`](/slides/python-net/hi/aspose.slides/icameraeffectivedata/camera_type/) | कैमरा प्रकार।<br/>            केवल पढ़ने योग्य [`CameraPresetType`](/slides/python-net/hi/aspose.slides/camerapresettype). |
| [`field_of_view_angle`](/slides/python-net/hi/aspose.slides/icameraeffectivedata/field_of_view_angle/) | कैमरा FOV (0-180 डिग्री, दृश्य क्षेत्र)।<br/>            केवल पढ़ने योग्य **float**. |
| [`zoom`](/slides/python-net/hi/aspose.slides/icameraeffectivedata/zoom/) | कैमरा ज़ूम (प्रतिशत में सकारात्मक मान)।<br/>            केवल पढ़ने योग्य **float**. |

## विधियाँ

| Method | Description |
| :- | :- |
| [`get_rotation(self)`](/slides/python-net/hi/aspose.slides/icameraeffectivedata/get_rotation/#) | एक घूर्णन को अक्षांश समन्वय, देशांतर समन्वय, और अक्ष के चारों ओर एक क्रांति के उपयोग से परिभाषित किया जाता है, जैसा कि अक्षांश और देशांतर समन्वय हैं।<br/>            पहले तत्व में लौटाए गए array में - अक्षांश, दूसरा - देशांतर, तीसरा - क्रांति।<br/>            यदि कोई घूर्णन परिभाषित नहीं है तो None लौटाता है. |
