## IShapeFrame क्लास

Shape frame की गुणधर्मों का प्रतिनिधित्व करता है।

IShapeFrame प्रकार निम्न सदस्य उजागर करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`x`](/slides/python-net/hi/aspose.slides/ishapeframe/x/) | फ़्रेम के ऊपरी-बाएँ कोने का X निर्देशांक लौटाता है।<br/>            केवल-पढ़ने-योग्य **float**. |
| [`y`](/slides/python-net/hi/aspose.slides/ishapeframe/y/) | फ़्रेम के ऊपरी-बाएँ कोने का Y निर्देशांक लौटाता है।<br/>            केवल-पढ़ने-योग्य **float**. |
| [`width`](/slides/python-net/hi/aspose.slides/ishapeframe/width/) | फ़्रेम की चौड़ाई लौटाता है।<br/>            केवल-पढ़ने-योग्य **float**. |
| [`height`](/slides/python-net/hi/aspose.slides/ishapeframe/height/) | फ़्रेम की ऊँचाई लौटाता है।<br/>            केवल-पढ़ने-योग्य **float**. |
| [`rotation`](/slides/python-net/hi/aspose.slides/ishapeframe/rotation/) | फ़्रेम के z-अक्ष के चारों ओर घुमाए गए डिग्री की संख्या लौटाता है।<br/>            सकारात्मक मान घड़ी की दिशा में घूर्णन दर्शाता है; नकारात्मक मान<br/>            विपरीत दिशा में घूर्णन दर्शाता है।<br/>            केवल-पढ़ने-योग्य **float**. |
| [`center_x`](/slides/python-net/hi/aspose.slides/ishapeframe/center_x/) | फ़्रेम के केंद्र का X निर्देशांक लौटाता है।<br/>            केवल-पढ़ने-योग्य **float**. |
| [`center_y`](/slides/python-net/hi/aspose.slides/ishapeframe/center_y/) | फ़्रेम के केंद्र का Y निर्देशांक लौटाता है।<br/>            केवल-पढ़ने-योग्य **float**. |
| [`flip_h`](/slides/python-net/hi/aspose.slides/ishapeframe/flip_h/) | निर्धारित करता है कि क्या फ़्रेम क्षैतिज रूप से फ़्लिप किया गया है।<br/>            केवल-पढ़ने-योग्य [`NullableBool`](/slides/python-net/hi/aspose.slides/nullablebool). |
| [`flip_v`](/slides/python-net/hi/aspose.slides/ishapeframe/flip_v/) | निर्धारित करता है कि क्या फ़्रेम लंबवत रूप से फ़्लिप किया गया है।<br/>            केवल-पढ़ने-योग्य [`NullableBool`](/slides/python-net/hi/aspose.slides/nullablebool). |
| [`rectangle`](/slides/python-net/hi/aspose.slides/ishapeframe/rectangle/) | फ़्रेम के निर्देशांक लौटाता है।<br/>            केवल-पढ़ने-योग्य **aspose.slides.RectangleF**. |
