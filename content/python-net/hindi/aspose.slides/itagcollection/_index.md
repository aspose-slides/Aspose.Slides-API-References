## ITagCollection क्लास

संग्रहित टैग (उपयोगकर्ता द्वारा परिभाषित स्ट्रिंग युग्म) का प्रतिनिधित्व करता है

ITagCollection प्रकार निम्नलिखित सदस्य प्रदर्शित करता है:

## विधियाँ

| विधि | विवरण |
| :- | :- |
| [`add(self, name, value)`](/slides/python-net/hi/aspose.slides/itagcollection/add/#str-str) | एक नया टैग संग्रह में जोड़ता है। |
| [`remove(self, name)`](/slides/python-net/hi/aspose.slides/itagcollection/remove/#str) | निर्दिष्ट नाम वाले टैग को संग्रह से हटाता है। |
| [`index_of_name(self, name)`](/slides/python-net/hi/aspose.slides/itagcollection/index_of_name/#str) | संग्रह में निर्दिष्ट कुंजी का शून्य-आधारित सूचकांक लौटाता है। |
| [`remove_at(self, index)`](/slides/python-net/hi/aspose.slides/itagcollection/remove_at/#int) | निर्दिष्ट सूचकांक पर टैग हटाता है। |
| [`clear(self)`](/slides/python-net/hi/aspose.slides/itagcollection/clear/#) | सभी टैग्स को संग्रह से हटाता है। |

| [`get_name_by_index(self, index)`](/slides/python-net/hi/aspose.slides/itagcollection/get_name_by_index/#int) | निर्दिष्ट सूचकांक पर टैग की कुंजी लौटाता है। |
| [`get_names_of_tags(self)`](/slides/python-net/hi/aspose.slides/itagcollection/get_names_of_tags/#) | टैग के नाम लौटाता है। |
