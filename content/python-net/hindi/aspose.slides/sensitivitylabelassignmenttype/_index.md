## SensitivityLabelAssignmentType एन्यूमरेशन

सेंसिटिविटी लेबल के लिए असाइनमेंट विधि को दर्शाता है।

SensitivityLabelAssignmentType प्रकार निम्नलिखित सदस्य प्रस्तुत करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| STANDARD | उपयोगकर्ता द्वारा सीधे लागू नहीं किए गए किसी भी सेंसिटिविटी लेबल के लिए उपयोग करें। <br/>            इसमें सभी डिफ़ॉल्ट लेबल, स्वत: लागू हुए लेबल शामिल हैं। |
| PRIVILEGED | उपयोगकर्ता द्वारा सीधे लागू किए गए किसी भी सेंसिटिविटी लेबल के लिए उपयोग करें। <br/>            इसमें मैन्युअल रूप से लागू किए गए सेंसिटिविटी लेबल, साथ ही अनुशंसित<br/>            या अनिवार्य लेबलिंग, या कोई भी फीचर शामिल है जहाँ उपयोगकर्ता यह तय करता है कि कौन सा सेंसिटिविटी लेबल लागू किया जाए। |
