## ImageFormat एन्यूमरेशन

इमेज के फ़ाइल फ़ॉर्मेट को दर्शाता है।

ImageFormat टाइप निम्न सदस्य दिखाता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| MEMORY_BMP | मेमोरी में बिटमैप के फ़ॉर्मेट को दर्शाता है। |
| BMP | बिटमैप (BMP) इमेज फ़ॉर्मेट को दर्शाता है। |
| EMF | एन्हैंस्ड मेटाफाइल (EMF) इमेज फ़ॉर्मेट को दर्शाता है। |
| WMF | विंडोज़ मेटाफाइल (WMF) इमेज फ़ॉर्मेट को दर्शाता है। |
| GIF | ग्राफ़िक्स इंटरचेंज फ़ॉर्मेट (GIF) इमेज फ़ॉर्मेट को दर्शाता है। |
| JPEG | जॉइंट फ़ोटोग्राफिक एक्सपर्ट्स ग्रुप (JPEG) इमेज फ़ॉर्मेट को दर्शाता है। |
| PNG | W3C पोर्टेबल नेटवर्क ग्राफ़िक्स (PNG) इमेज फ़ॉर्मेट को दर्शाता है। |
| TIFF | टैग्ड इमेज फ़ाइल फ़ॉर्मेट (TIFF) इमेज फ़ॉर्मेट को दर्शाता है। |
| EXIF | एक्सचेंजेबल इमेज फ़ाइल (Exif) फ़ॉर्मेट को दर्शाता है। |
| ICON | विंडोज़ आइकन इमेज फ़ॉर्मेट को दर्शाता है। |
