## ConnectorLock क्लास

निर्धारित करता है कि कौन-सी ऑपरेशन्स मूल Connector पर निष्क्रिय हैं।

**विरासत:**[`ConnectorLock`](/slides/python-net/hi/aspose.slides/connectorlock) → [`BaseShapeLock`](/slides/python-net/hi/aspose.slides/baseshapelock)

ConnectorLock प्रकार निम्न सदस्य प्रकट करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`no_locks`](/slides/python-net/hi/aspose.slides/connectorlock/no_locks/) | Return true if all lock-flags are disabled.<br/>            Read-only **bool**. |
| [`grouping_locked`](/slides/python-net/hi/aspose.slides/connectorlock/grouping_locked/) | यह निर्धारित करता है कि इस shape को समूह में जोड़ना प्रतिबंधित है या नहीं।<br/>            Read/write **bool**. |
| [`select_locked`](/slides/python-net/hi/aspose.slides/connectorlock/select_locked/) | यह निर्धारित करता है कि इस shape को चुनना प्रतिबंधित है या नहीं।<br/>            Read/write **bool**. |
| [`rotate_locked`](/slides/python-net/hi/aspose.slides/connectorlock/rotate_locked/) | यह निर्धारित करता है कि इस shape का घूर्णन कोण बदलना प्रतिबंधित है या नहीं।<br/>            Read/write **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/hi/aspose.slides/connectorlock/aspect_ratio_locked/) | यह निर्धारित करता है कि shape को री-साइज़ पर अनुपात बनाए रखना आवश्यक है या नहीं।<br/>            Read/write **bool**. |
| [`position_move`](/slides/python-net/hi/aspose.slides/connectorlock/position_move/) | यह निर्धारित करता है कि इस shape को ले जाना प्रतिबंधित है या नहीं.<br/>            Read/write **bool**. |
| [`size_locked`](/slides/python-net/hi/aspose.slides/connectorlock/size_locked/) | यह निर्धारित करता है कि इस shape को री-साइज़ करना प्रतिबंधित है या नहीं.<br/>            Read/write **bool**. |
| [`edit_points_locked`](/slides/python-net/hi/aspose.slides/connectorlock/edit_points_locked/) | यह निर्धारित करता है कि इस shape की कंटूर को सीधे बदलना प्रतिबंधित है या नहीं.<br/>            Read/write **bool**. |
| [`adjust_handles_locked`](/slides/python-net/hi/aspose.slides/connectorlock/adjust_handles_locked/) | यह निर्धारित करता है कि समायोजन मान बदलना प्रतिबंधित है या नहीं.<br/>            Read/write **bool**. |
| [`arrowheads_locked`](/slides/python-net/hi/aspose.slides/connectorlock/arrowheads_locked/) | यह निर्धारित करता है कि एरोहेड बदलना प्रतिबंधित है या नहीं.<br/>            Read/write **bool**. |
| [`shape_type_locked`](/slides/python-net/hi/aspose.slides/connectorlock/shape_type_locked/) | यह निर्धारित करता है कि shape प्रकार बदलना प्रतिबंधित है या नहीं.<br/>            Read/write **bool**. |
