## IParagraph क्लास

एक पाठ के अनुच्छेद को दर्शाता है।

IParagraph प्रकार निम्न सदस्य प्रदान करता है:

## गुण

| Property | Description |
| :- | :- |
| [`portions`](/slides/python-net/hi/aspose.slides/iparagraph/portions/) | टेक्स्ट हिस्सों का संग्रह लौटाता है।<br/>केवल-पढ़ने योग्य [`IPortionCollection`](/slides/python-net/hi/aspose.slides/iportioncollection)। |
| [`paragraph_format`](/slides/python-net/hi/aspose.slides/iparagraph/paragraph_format/) | इस अनुच्छेद के लिए फॉर्मेटिंग ऑब्जेक्ट लौटाता है।<br/>केवल-पढ़ने योग्य [`IParagraphFormat`](/slides/python-net/hi/aspose.slides/iparagraphformat)। |
| [`text`](/slides/python-net/hi/aspose.slides/iparagraph/text/) | एक अनुच्छेद के साधारण पाठ को प्राप्त करता है या सेट करता है।<br/>पढ़ें/लिखें **str**। |
| [`end_paragraph_portion_format`](/slides/python-net/hi/aspose.slides/iparagraph/end_paragraph_portion_format/) | यदि कोई अन्य भाग अंतिम भाग के बाद डाला जाता है तो उपयोग किए जाने वाले भाग गुणों को निर्दिष्ट करता है।<br/>अंतिम भाग के बाद। |
| [`slide`](/slides/python-net/hi/aspose.slides/iparagraph/slide/) |  |
| [`presentation`](/slides/python-net/hi/aspose.slides/iparagraph/presentation/) |  |
