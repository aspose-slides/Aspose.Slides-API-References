## IControl वर्ग

एक ActiveX नियंत्रण का प्रतिनिधित्व करता है।

IControl प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`name`](/slides/python-net/hi/aspose.slides/icontrol/name/) | इस नियंत्रण का नाम लौटाता है।<br/>            पढ़ें/लिखें **str**. |
| [`class_id`](/slides/python-net/hi/aspose.slides/icontrol/class_id/) | इस नियंत्रण की class id प्राप्त करता है।<br/>            केवल पढ़ने योग्य **System.Guid**. |
| [`substitute_picture_format`](/slides/python-net/hi/aspose.slides/icontrol/substitute_picture_format/) | ControlEx इमेज फ़िल प्रॉपर्टीज़ ऑब्जेक्ट लौटाता है।<br/>            केवल पढ़ने योग्य [`IPictureFillFormat`](/slides/python-net/hi/aspose.slides/ipicturefillformat). |
| [`frame`](/slides/python-net/hi/aspose.slides/icontrol/frame/) | नियंत्रण का फ्रेम लौटाता है या सेट करता है।<br/>            पढ़ें/लिखें [`IShapeFrame`](/slides/python-net/hi/aspose.slides/ishapeframe). |
| [`properties`](/slides/python-net/hi/aspose.slides/icontrol/properties/) | ActiveX गुणों का संग्रह लौटाता है।<br/>            केवल पढ़ने योग्य [`IControlPropertiesCollection`](/slides/python-net/hi/aspose.slides/icontrolpropertiescollection). |
| [`persistence`](/slides/python-net/hi/aspose.slides/icontrol/persistence/) | ActiveX नियंत्रण की प्रॉपर्टीज़ को संग्रहीत करने के लिए उपयोग की जाने वाली विधि प्राप्त करता है।<br/>            केवल पढ़ने योग्य [`PersistenceType`](/slides/python-net/hi/aspose.slides/persistencetype). |
| [`active_x_control_binary`](/slides/python-net/hi/aspose.slides/icontrol/active_x_control_binary/) | जब स्थायित्व के लिये उपयोग की गई विधि PersistStream, PersistStreamInit या PersistStorage हो, तब ActiveX नियंत्रण की स्थायित्व को निर्दिष्ट करता है। |
