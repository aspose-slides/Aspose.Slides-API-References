## portion_format गुण
Returns formatting object which contains explicitly set formatting properties of the text portion with no inheritance applied.
            केवल-पढ़ने योग्य [`IPortionFormat`](/slides/python-net/hi/aspose.slides/iportionformat).

### टिप्पणियाँ

फ़ॉर्मैटिंग ऑब्जेक्ट केवल वर्तमान भाग के लिए परिभाषित फ़ॉर्मैटिंग पैरामीटरों को सम्मिलित करता है, विरासत में मिला डेटा लागू नहीं किया जाता है।

विरासत में मिलने वाले मानों को शामिल करके प्रभावी मान प्राप्त करने के लिए [`IPortionFormat.get_effective`](/slides/python-net/hi/aspose.slides/iportionformat/get_effective) मेथड का उपयोग करें।
