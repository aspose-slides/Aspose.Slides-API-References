## y प्रॉपर्टी
शेप के ऊपर-बायें कोने के y-निर्देशांक को प्राप्त करता है या सेट करता है, जो पॉइंट्स में मापा जाता है।
पढ़ें/लिखें **float**.


### टिप्पणी

वापसी मान हमेशा परिभाषित होता है और कभी **float** नहीं होता।
निर्धारित मान असाइन भी परिभाषित होना चाहिए; **float** को केवल `RawFrame` इंस्टेंस की प्रॉपर्टीज़ को असाइन करें।

### परिभाषा:
```python
@property
def y(self):
    ...

@y.setter
def y(self, value):
    ...
```
