## x प्रॉपर्टी
आकार के बाएँ-ऊपरी कोने के x-निर्देशांक को प्राप्त करता है या सेट करता है, जिसे पॉइंट में मापा जाता है।
            पढ़ें/लिखें **float**.

### टिप्पणियाँ

वापस किया गया मान हमेशा परिभाषित होता है और कभी भी **float** नहीं होता।
            असाइन किया गया मान भी परिभाषित होना चाहिए; केवल `RawFrame` उदाहरण की प्रॉपर्टी को **float** असाइन करें।

### परिभाषा:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
