## IThreeDFormatEffectiveData वर्ग

अपरिवर्तनीय वस्तु जो प्रभावी 3-D फ़ॉर्मेटिंग गुणों को दर्शाती है।

IThreeDFormatEffectiveData प्रकार निम्न सदस्य प्रदान करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`contour_width`](/slides/python-net/hi/aspose.slides/ithreedformateffectivedata/contour_width/) | 3D आकृति की सीमा की चौड़ाई लौटाता है।<br/>            केवल-पढ़ने-योग्य **float**. |
| [`extrusion_height`](/slides/python-net/hi/aspose.slides/ithreedformateffectivedata/extrusion_height/) | एक्सट्रूज़न प्रभाव की ऊँचाई लौटाता है।<br/>            केवल-पढ़ने-योग्य **float**. |
| [`depth`](/slides/python-net/hi/aspose.slides/ithreedformateffectivedata/depth/) | 3D आकार की गहराई लौटाता है।<br/>            केवल-पढ़ने-योग्य **float**. |
| [`bevel_top`](/slides/python-net/hi/aspose.slides/ithreedformateffectivedata/bevel_top/) | शीर्ष 3D बवेल का प्रकार लौटाता है।<br/>            केवल-पढ़ने-योग्य [`IShapeBevelEffectiveData`](/slides/python-net/hi/aspose.slides/ishapebeveleffectivedata). |

| [`contour_color`](/slides/python-net/hi/aspose.slides/ithreedformateffectivedata/contour_color/) | सीमा का रंग लौटाता है।<br/>            केवल-पढ़ने-योग्य [`Color`](/slides/python-net/hi/aspose.slides/color). |
| [`extrusion_color`](/slides/python-net/hi/aspose.slides/ithreedformateffectivedata/extrusion_color/) | एक्सट्रूज़न का रंग लौटाता है।<br/>            केवल-पढ़ने-योग्य [`Color`](/slides/python-net/hi/aspose.slides/color). |
| [`camera`](/slides/python-net/hi/aspose.slides/ithreedformateffectivedata/camera/) | कैमरे की सेटिंग्स लौटाता है।<br/>            केवल-पढ़ने-योग्य [`ICameraEffectiveData`](/slides/python-net/hi/aspose.slides/icameraeffectivedata). |
| [`light_rig`](/slides/python-net/hi/aspose.slides/ithreedformateffectivedata/light_rig/) | प्रकाश का प्रकार लौटाता है।<br/>            केवल-पढ़ने-योग्य [`ILightRigEffectiveData`](/slides/python-net/hi/aspose.slides/ilightrigeffectivedata). |
