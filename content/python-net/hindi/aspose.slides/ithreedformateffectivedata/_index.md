## IThreeDFormatEffectiveData क्लास

एक अपरिवर्तनीय ऑब्जेक्ट जो प्रभावी 3-D फ़ॉर्मेटिंग गुणों का प्रतिनिधित्व करता है।

IThreeDFormatEffectiveData प्रकार निम्न सदस्य प्रकट करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`contour_width`](/slides/python-net/hi/aspose.slides/ithreedformateffectivedata/contour_width/) | Returns the width of a 3D contour.<br/>            केवल पढ़ने योग्य **float**. |
| [`extrusion_height`](/slides/python-net/hi/aspose.slides/ithreedformateffectivedata/extrusion_height/) | Returns the height of an extrusion effect.<br/>            केवल पढ़ने योग्य **float**. |
| [`depth`](/slides/python-net/hi/aspose.slides/ithreedformateffectivedata/depth/) | Returns the depth of a 3D shape.<br/>            केवल पढ़ने योग्य **float**. |
| [`bevel_top`](/slides/python-net/hi/aspose.slides/ithreedformateffectivedata/bevel_top/) | Returns the type of a top 3D bevel.<br/>            केवल पढ़ने योग्य [`IShapeBevelEffectiveData`](/slides/python-net/hi/aspose.slides/ishapebeveleffectivedata). |
| [`bevel_bottom`](/slides/python-net/hi/aspose.slides/ithreedformateffectivedata/bevel_bottom/) | Returns the type of a bottom 3D bevel.<br/>            केवल पढ़ने योग्य [`IShapeBevelEffectiveData`](/slides/python-net/hi/aspose.slides/ishapebeveleffectivedata). |
| [`contour_color`](/slides/python-net/hi/aspose.slides/ithreedformateffectivedata/contour_color/) | Returns the color of a contour.<br/>            केवल पढ़ने योग्य **aspose.slides.Color**. |
| [`extrusion_color`](/slides/python-net/hi/aspose.slides/ithreedformateffectivedata/extrusion_color/) | Returns the color of an extrusion.<br/>            केवल पढ़ने योग्य **aspose.slides.Color**. |
