## TextVerticalType एन्यूमरेशन

किसी पाठ के लिए ऊर्ध्वाधर लेखन मोड निर्धारित करता है।

TextVerticalType प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## फ़ील्ड

| फ़ील्ड | विवरण |
| :- | :- |
| NOT_DEFINED | परिभाषित नहीं। |
| HORIZONTAL | क्षैतिज पाठ। |
| VERTICAL | ऊर्ध्वाधर पाठ। |
| VERTICAL270 | 270 डिग्री ऊर्ध्वाधर पाठ। |
| WORD_ART_VERTICAL | WordArt ऊर्ध्वाधर पाठ। |
| EAST_ASIAN_VERTICAL | पूर्वी एशियाई ऊर्ध्वाधर पाठ। |
| MONGOLIAN_VERTICAL | मंगोलियन ऊर्ध्वाधर पाठ। |
| WORD_ART_VERTICAL_RIGHT_TO_LEFT | WordArt ऊर्ध्वाधर दाएँ से बाएँ पाठ। |
