## TextHighlightingOptions क्लास

टेक्स्ट फ्रेम में टेक्स्ट को हाइलाइट करने के लिए उपयोग किए जा सकने वाले विकल्पों का प्रतिनिधित्व करता है।

TextHighlightingOptions प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## कंस्ट्रक्टर्स

| कंस्ट्रक्टर | विवरण |
| :- | :- |
| [`__init__(self)`](/slides/python-net/hi/aspose.slides/texthighlightingoptions/__init__/#) | नए डिफ़ॉल्ट टेक्स्ट हाइलाइटिंग विकल्प बनाता है। |

## गुण

| गुण | विवरण |
| :- | :- |
| [`case_sensitive`](/slides/python-net/hi/aspose.slides/texthighlightingoptions/case_sensitive/) | सही सेट करें ताकि केस-सेन्सिटिव खोज का उपयोग हो, अन्यथा गलत।<br/>            पढ़ें/लिखें **bool**. |
| [`whole_words_only`](/slides/python-net/hi/aspose.slides/texthighlightingoptions/whole_words_only/) | सही सेट करें ताकि केवल पूर्ण शब्द मिलें, अन्यथा गलत.<br/>            पढ़ें/लिखें **bool**. |
