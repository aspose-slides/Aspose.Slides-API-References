## y प्रॉपर्टी
आकार के ऊपरी-बाएँ कोने के y-निर्देशांक को प्राप्त करता है या सेट करता है, जो पॉइंट्स में मापा गया है।
            पढ़ें/लिखें **float**.

### टिप्पणियाँ

वापस किया गया मान हमेशा परिभाषित होता है और कभी **float** नहीं होता।
            असाइन किया गया मान भी परिभाषित होना चाहिए; **float** को केवल `RawFrame` इंस्टेंस की प्रॉपर्टीज़ को ही असाइन करें।

### परिभाषा:
```python
@property
def y(self):
    ...

@y.setter
def y(self, value):
    ...
```
