## x गुण
आकार के ऊपरी-बाएँ कोने के x-निर्देशांक को प्राप्त या सेट करता है, जो पॉइंट्स में मापा जाता है.
            पढ़ें/लिखें **float**.

### टिप्पणियाँ

वापसी मान हमेशा परिभाषित रहता है और कभी भी **float** नहीं होता.
            सौंपा गया मान भी परिभाषित होना चाहिए; **float** केवल `RawFrame` उदाहरण की गुणों को ही सौंपें।

### परिभाषा:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
