## AudioPlayModePreset एन्यूमरेशन

ध्वनि को कैसे चलाया जाता है, इसे परिभाषित करने वाले स्थिरांक।

AudioPlayModePreset प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## फ़ील्ड्स

| Field | Description |
| :- | :- |
| MIXED |  |
| AUTO | स्वचालित रूप से चलाएँ। |
| ON_CLICK | केवल तब चलाएँ जब आइकन पर क्लिक किया जाए। |
| ALL_SLIDES | सभी स्लाइडों पर चलाएँ। <br/>            Please use [`IAudioFrame.play_across_slides`](/slides/python-net/hi/aspose.slides/iaudioframe/play_across_slides) property instead.<br/>            This element is out of date since PowerPoint 2013. |
| IN_CLICK_SEQUENCE | क्लिक के साथ स्वचालित रूप से चलाएँ। |
