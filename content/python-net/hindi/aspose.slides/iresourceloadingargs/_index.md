## IResourceLoadingArgs क्लास

बाहरी संसाधन लोडिंग तर्कों के लिए इंटरफ़ेस।

IResourceLoadingArgs प्रकार निम्नलिखित सदस्यों को प्रकट करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`original_uri`](/slides/python-net/hi/aspose.slides/iresourceloadingargs/original_uri/) | आयातित प्रस्तुति में निर्दिष्ट संसाधन का मूल URI। |
| [`uri`](/slides/python-net/hi/aspose.slides/iresourceloadingargs/uri/) | संसाधन का URI जो डाउनलोड करने के लिए उपयोग किया जाता है यदि **Aspose.Slides.IResourceLoadingCallback.ResourceLoading(Aspose.Slide** <br/>            returns [`ResourceLoadingAction.DEFAULT`](/slides/python-net/hi/aspose.slides/resourceloadingaction/DEFAULT). <br/>            प्रारंभ में इसे संसाधन के मूल URI पर सेट किया जाता है, लेकिन इसे किसी भी मान में पुनः निर्धारित किया जा सकता है। |

## विधियां

| विधि | विवरण |
| :- | :- |
| [`set_data(self, data)`](/slides/python-net/hi/aspose.slides/iresourceloadingargs/set_data/#bytes) | संसाधन का उपयोगकर्ता द्वारा प्रदान किया गया डेटा सेट करता है यदि **Aspose.Slides.IResourceLoadingCallback.ResourceLoading(Aspose.Slide** <br/>            returns [`ResourceLoadingAction.USER_PROVIDED`](/slides/python-net/hi/aspose.slides/resourceloadingaction/USER_PROVIDED). |
