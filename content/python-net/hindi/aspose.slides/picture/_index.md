## Picture वर्ग

प्रेज़ेंटेशन में एक चित्र को दर्शाता है।

Picture प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| संपत्ति | विवरण |
| :- | :- |
| [`image`](/slides/python-net/hi/aspose.slides/picture/image/) | एम्बेडेड छवि को लौटाता है या सेट करता है।<br/>            पढ़ें/लिखें [`IPPImage`](/slides/python-net/hi/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/hi/aspose.slides/picture/link_path_long/) | लिंक्ड छवि की URL को लौटाता है या सेट करता है।<br/>            पढ़ें/लिखें **str**. |
| [`image_transform`](/slides/python-net/hi/aspose.slides/picture/image_transform/) | छवि ट्रांसफ़ॉर्म इफ़ेक्ट्स के संग्रह को लौटाता है।<br/>            केवल-पढ़न [`IImageTransformOperationCollection`](/slides/python-net/hi/aspose.slides.effects/iimagetransformoperationcollection). |
| [`presentation`](/slides/python-net/hi/aspose.slides/picture/presentation/) | प्रेज़ेंटेशन लौटाता है। <br/>            केवल-पढ़न [`IPresentation`](/slides/python-net/hi/aspose.slides/ipresentation). |
| [`slide`](/slides/python-net/hi/aspose.slides/picture/slide/) | चित्र की पेरेंट स्लाइड को लौटाता है।<br/>            केवल-पढ़न [`IBaseSlide`](/slides/python-net/hi/aspose.slides/ibaseslide). |
