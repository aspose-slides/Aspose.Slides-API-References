## ITextFrameFormatEffectiveData क्लास

अपरिवर्तनीय वस्तु जिसमें प्रभावी टेक्स्ट फ्रेम फ़ॉर्मेटिंग गुण होते हैं।

ITextFrameFormatEffectiveData प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`text_style`](/slides/python-net/hi/aspose.slides/itextframeformateffectivedata/text_style/) | प्रभावी टेक्स्ट की शैली लौटाता है।<br/>            Read-only [`ITextStyleEffectiveData`](/slides/python-net/hi/aspose.slides/itextstyleeffectivedata). |
| [`margin_left`](/slides/python-net/hi/aspose.slides/itextframeformateffectivedata/margin_left/) | TextFrame में बाएँ मार্জिन (पॉइंट) लौटाता है।<br/>            Read-only **float**. |
| [`margin_right`](/slides/python-net/hi/aspose.slides/itextframeformateffectivedata/margin_right/) | TextFrame में दाएँ मार्जिन (पॉइंट) लौटाता है।<br/>            Read-only **float**. |
| [`margin_top`](/slides/python-net/hi/aspose.slides/itextframeformateffectivedata/margin_top/) | TextFrame में शीर्ष मार्जिन (पॉइंट) लौटाता है।<br/>            Read-only **float**. |
| [`margin_bottom`](/slides/python-net/hi/aspose.slides/itextframeformateffectivedata/margin_bottom/) | TextFrame में नीचे मार्जिन (पॉइंट) लौटाता है।<br/>            Read-only **float**. |
| [`wrap_text`](/slides/python-net/hi/aspose.slides/itextframeformateffectivedata/wrap_text/) | यदि टेक्स्ट TextFrame के मार्जिन पर रैप किया गया है तो लौटाता है।<br/>            Read-only **bool**. |
| [`anchoring_type`](/slides/python-net/hi/aspose.slides/itextframeformateffectivedata/anchoring_type/) | TextFrame में ऊर्ध्वाधर एंकर टेक्स्ट लौटाता है।<br/>            Read-only [`TextAnchorType`](/slides/python-net/hi/aspose.slides/textanchortype). |
| [`center_text`](/slides/python-net/hi/aspose.slides/itextframeformateffectivedata/center_text/) | यदि टेक्स्ट बॉक्स में क्षैतिज रूप से केंद्रित होना चाहिए तो लौटाता है।<br/>            Read-only **bool**. |
| [`text_vertical_type`](/slides/python-net/hi/aspose.slides/itextframeformateffectivedata/text_vertical_type/) | टेक्स्ट अभिविन्यास लौटाता है।<br/>            Read-only [`TextVerticalType`](/slides/python-net/hi/aspose.slides/textverticaltype). |
| [`autofit_type`](/slides/python-net/hi/aspose.slides/itextframeformateffectivedata/autofit_type/) | टेक्स्ट ऑटोफ़िट मोड लौटाता है।<br/>            Read-only [`TextAutofitType`](/slides/python-net/hi/aspose.slides/textautofittype). |
| [`column_count`](/slides/python-net/hi/aspose.slides/itextframeformateffectivedata/column_count/) | बाउंडिंग आयत में टेक्स्ट के कॉलमों की संख्या निर्दिष्ट करता है।<br/>            Read-only **int**. |
| [`column_spacing`](/slides/python-net/hi/aspose.slides/itextframeformateffectivedata/column_spacing/) | टेक्स्ट क्षेत्र में टेक्स्ट कॉलमों के बीच का अंतर (पॉइंट में) निर्दिष्ट करता है।<br/>            Read-only **float**. |

### टिप्पणी

यह इंटरफ़ेस [`ITextFrameFormat`](/slides/python-net/hi/aspose.slides/itextframeformat) इंटरफ़ेस के साथ मिलकर उत्तराधिकार लागू किए गए प्रभावी फ़ॉर्मेटिंग मान लौटाने के लिए उपयोग किया जाता है।
