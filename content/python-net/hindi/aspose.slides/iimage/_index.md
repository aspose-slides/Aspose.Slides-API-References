## IImage वर्ग

रैस्टर या वेक्टर छवि का प्रतिनिधित्व करता है।

IImage प्रकार निम्न सदस्य प्रस्तुत करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`size`](/slides/python-net/hi/aspose.slides/iimage/size/) | छवि का आकार प्राप्त करता है। |
| [`width`](/slides/python-net/hi/aspose.slides/iimage/width/) | छवि की चौड़ाई पिक्सेल में प्राप्त करता है। |
| [`height`](/slides/python-net/hi/aspose.slides/iimage/height/) | छवि की ऊँचाई पिक्सेल में प्राप्त करता है। |

## विधियाँ

| विधि | विवरण |
| :- | :- |
| [`save(self, filename)`](/slides/python-net/hi/aspose.slides/iimage/save/#str) | छवि को फ़ाइल में सहेजता है। |
| [`save(self, filename, format)`](/slides/python-net/hi/aspose.slides/iimage/save/#str-imageformat) | छवि को निर्दिष्ट फ़ॉर्मेट में फ़ाइल में सहेजता है। |
| [`save(self, stream, format)`](/slides/python-net/hi/aspose.slides/iimage/save/#iorawiobase-imageformat) | छवि को निर्दिष्ट फ़ॉर्मेट में स्ट्रीम में सहेजता है। |
| [`save(self, filename, format, quality)`](/slides/python-net/hi/aspose.slides/iimage/save/#str-imageformat-int) | छवि को निर्दिष्ट फ़ॉर्मेट और गुणवत्ता में फ़ाइल में सहेजता है। |
| [`save(self, stream, format, quality)`](/slides/python-net/hi/aspose.slides/iimage/save/#iorawiobase-imageformat-int) | छवि को निर्दिष्ट फ़ॉर्मेट और गुणवत्ता में स्ट्रीम में सहेजता है। |

### टिप्पणियाँ

यह इंटरफ़ेस रैस्टर और वेक्टर दोनों छवियों को संभालने के लिए एक सामान्य अभ्यावेदन प्रदान करता है।  
इम्प्लीमेंटेशन अंतर्निहित इमेज प्रकार पर निर्भर हो सकते हैं।
