## BlackWhiteMode एन्यूमरेशन

निर्धारित करता है कि रंगीन आकार को कैसे काली और सफ़ेद में परिवर्तित किया जाना चाहिए।

BlackWhiteMode टाइप निम्नलिखित सदस्य प्रदर्शित करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| NOT_DEFINED | प्रॉपर्टी सेट नहीं है |
| COLOR | ऑब्जेक्ट सामान्य रंगावली के साथ रेंडर किया जाता है |
| AUTOMATIC | ऑब्जेक्ट स्वचालित रंगावली के साथ रेंडर किया जाता है |
| GRAY | ऑब्जेक्ट ग्रे रंगावली के साथ रेंडर किया जाता है |
| LIGHT_GRAY | ऑब्जेक्ट हल्की ग्रे रंगावली के साथ रेंडर किया जाता है |
| INVERSE_GRAY | ऑब्जेक्ट उल्टी ग्रे रंगावली के साथ रेंडर किया जाता है |
| GRAY_WHITE | ऑब्जेक्ट ग्रे और सफ़ेद रंगावली के साथ रेंडर किया जाता है |
| BLACK_GRAY | ऑब्जेक्ट काली और ग्रे रंगावली के साथ रेंडर किया जाता है |
| BLACK_WHITE | ऑब्जेक्ट काली और सफ़ेद रंगावली के साथ रेंडर किया जाता है |
| BLACK | ऑब्जेक्ट केवल काली रंगावली के साथ रेंडर किया जाता है |
| WHITE | ऑब्जेक्ट सफ़ेद रंगावली के साथ रेंडर किया जाता है |
| HIDDEN | ऑब्जेक्ट रेंडर नहीं किया जाता है |
