## IEffectFormatEffectiveData वर्ग

अपरिवर्तनीय ऑब्जेक्ट जो प्रभावी इफ़ेक्ट फ़ॉर्मेटिंग गुणों को रखता है।

IEffectFormatEffectiveData प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`is_no_effects`](/slides/python-net/hi/aspose.slides/ieffectformateffectivedata/is_no_effects/) | सभी इफ़ेक्ट बंद होने पर true लौटाता है (जैसे अभी बनाए गए, डिफ़ॉल्ट EffectFormat ऑब्जेक्ट)।<br/>            केवल- पढ़ने योग्य **bool**. |
| [`blur_effect`](/slides/python-net/hi/aspose.slides/ieffectformateffectivedata/blur_effect/) | धुंध प्रभाव।<br/>            केवल- पढ़ने योग्य [`IBlurEffectiveData`](/slides/python-net/hi/aspose.slides.effects/iblureffectivedata). |
| [`fill_overlay_effect`](/slides/python-net/hi/aspose.slides/ieffectformateffectivedata/fill_overlay_effect/) | भरण ओवरले प्रभाव।<br/>            केवल- पढ़ने योग्य [`IFillOverlayEffectiveData`](/slides/python-net/hi/aspose.slides.effects/ifilloverlayeffectivedata). |
| [`glow_effect`](/slides/python-net/hi/aspose.slides/ieffectformateffectivedata/glow_effect/) | ग्लो प्रभाव।<br/>            केवल- पढ़ने योग्य [`IGlowEffectiveData`](/slides/python-net/hi/aspose.slides.effects/igloweffectivedata). |
| [`inner_shadow_effect`](/slides/python-net/hi/aspose.slides/ieffectformateffectivedata/inner_shadow_effect/) | आंतरिक छाया।<br/>            केवल- पढ़ने योग्य [`IInnerShadowEffectiveData`](/slides/python-net/hi/aspose.slides.effects/iinnershadoweffectivedata). |
| [`outer_shadow_effect`](/slides/python-net/hi/aspose.slides/ieffectformateffectivedata/outer_shadow_effect/) | बाहरी छाया।<br/>            केवल- पढ़ने योग्य [`IOuterShadowEffectiveData`](/slides/python-net/hi/aspose.slides.effects/ioutershadoweffectivedata). |
| [`preset_shadow_effect`](/slides/python-net/hi/aspose.slides/ieffectformateffectivedata/preset_shadow_effect/) | पूर्वनिर्धारित छाया।<br/>            केवल- पढ़ने योग्य [`IPresetShadowEffectiveData`](/slides/python-net/hi/aspose.slides.effects/ipresetshadoweffectivedata). |
| [`reflection_effect`](/slides/python-net/hi/aspose.slides/ieffectformateffectivedata/reflection_effect/) | प्रतिबिंब। <br/>            केवल- पढ़ने योग्य [`IReflectionEffectiveData`](/slides/python-net/hi/aspose.slides.effects/ireflectioneffectivedata). |
| [`soft_edge_effect`](/slides/python-net/hi/aspose.slides/ieffectformateffectivedata/soft_edge_effect/) | सॉफ्ट एज।<br/>            केवल- पढ़ने योग्य [`ISoftEdgeEffectiveData`](/slides/python-net/hi/aspose.slides.effects/isoftedgeeffectivedata). |
