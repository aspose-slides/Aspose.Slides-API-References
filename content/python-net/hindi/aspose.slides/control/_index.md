## Control क्लास

एक ActiveX कंट्रोल का प्रतिनिधित्व करता है।

Control प्रकार निम्न सदस्य उजागर करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`persistence`](/slides/python-net/hi/aspose.slides/control/persistence/) | ActiveX कंट्रोल की गुणों को संग्रहीत करने के लिए उपयोग किए जाने वाले विधि को प्राप्त करता है।<br/>            केवल पढ़ने योग्य [`PersistenceType`](/slides/python-net/hi/aspose.slides/persistencetype). |
| [`name`](/slides/python-net/hi/aspose.slides/control/name/) | इस कंट्रोल का नाम प्राप्त करता है या सेट करता है।<br/>            पढ़ने/लिखने योग्य **str**. |
| [`class_id`](/slides/python-net/hi/aspose.slides/control/class_id/) | इस कंट्रोल का क्लास id प्राप्त करता है।<br/>            केवल पढ़ने योग्य **System.Guid**. |
| [`substitute_picture_format`](/slides/python-net/hi/aspose.slides/control/substitute_picture_format/) | Control छवि भराव गुण वस्तु लौटाता है।<br/>            केवल पढ़ने योग्य [`IPictureFillFormat`](/slides/python-net/hi/aspose.slides/ipicturefillformat). |
| [`frame`](/slides/python-net/hi/aspose.slides/control/frame/) | control के frame को प्राप्त करता है या सेट करता है।<br/>            पढ़ने/लिखने योग्य [`IShapeFrame`](/slides/python-net/hi/aspose.slides/ishapeframe). |
| [`properties`](/slides/python-net/hi/aspose.slides/control/properties/) | ActiveX गुणों का एक संग्रह लौटाता है।<br/>            Note: Aspose.Slides केवल XML आधारित ActiveX गुणों को समर्थन देता है। यदि गुण बाइनरी स्वरूप में संग्रहीत हैं, तो यह गुण None लौटाएगा।<br/>            केवल पढ़ने योग्य [`IControlPropertiesCollection`](/slides/python-net/hi/aspose.slides/icontrolpropertiescollection). |
| [`active_x_control_binary`](/slides/python-net/hi/aspose.slides/control/active_x_control_binary/) | जब स्थायित्व के लिए प्रयुक्त विधि PersistStream, PersistStreamInit या PersistStorage में से कोई एक हो, तब ActiveX कंट्रोल की स्थायीता को निर्दिष्ट करता है। |
| [`slide`](/slides/python-net/hi/aspose.slides/control/slide/) |  |
| [`presentation`](/slides/python-net/hi/aspose.slides/control/presentation/) |  |
