## unique_id गुण
Returns an internal, presentation-scoped identifier intended for use by add-ins or other code.
            क्योंकि इस मान को उपयोगकर्ता द्वारा या प्रोग्रामेटिक रूप से पुनः असाइन किया जा सकता है, इसे
            एक स्थायी अद्वितीय कुंजी के रूप में नहीं माना जाना चाहिए।
            केवल-पढ़ने योग्य **int**.
            देखें भी [`Shape.office_interop_shape_id`](/slides/python-net/hi/aspose.slides/shape/office_interop_shape_id).
