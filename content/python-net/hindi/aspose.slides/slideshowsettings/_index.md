## SlideShowSettings क्लास

प्रेजेंटेशन के लिए स्लाइड शो सेटिंग्स को दर्शाता है।

SlideShowSettings प्रकार निम्नलिखित सदस्य उजागर करता है:

## गुण

| संपत्ति | विवरण |
| :- | :- |
| [`slide_show_type`](/slides/python-net/hi/aspose.slides/slideshowsettings/slide_show_type/) | स्लाइड शो प्रकार को प्राप्त करता है या सेट करता है। निम्नलिखित [`SlideShowSettings.slide_show_type`](/slides/python-net/hi/aspose.slides/slideshowsettings/slide_show_type) पूर्वजों द्वारा प्रतिनिधित्व किया गया: [`BrowsedAtKiosk`](/slides/python-net/hi/aspose.slides/browsedatkiosk), [`PresentedBySpeaker`](/slides/python-net/hi/aspose.slides/presentedbyspeaker) और [`BrowsedByIndividual`](/slides/python-net/hi/aspose.slides/browsedbyindividual) |
| [`loop`](/slides/python-net/hi/aspose.slides/slideshowsettings/loop/) | स्लाइड शो लूप |
| [`show_narration`](/slides/python-net/hi/aspose.slides/slideshowsettings/show_narration/) | स्लाइड शो में नैरेशन दिखाएँ |
| [`show_animation`](/slides/python-net/hi/aspose.slides/slideshowsettings/show_animation/) | स्लाइड शो में एनीमेशन दिखाएँ |
| [`pen_color`](/slides/python-net/hi/aspose.slides/slideshowsettings/pen_color/) | स्लाइड शो के लिए पेन रंग |
| [`slides`](/slides/python-net/hi/aspose.slides/slideshowsettings/slides/) | स्लाइड्स की सीमा |
| [`use_timings`](/hi/slides/python-net/aspose.slides/slideshowsettings/use_timings/) | स्लाइड शो में टाइमिंग्स का उपयोग करें |
| [`show_media_controls`](/slides/python-net/hi/aspose.slides/slideshowsettings/show_media_controls/) | मीडिया नियंत्रण दिखाएँ |
