## Comment क्लास

एक स्लाइड पर Comment का प्रतिनिधित्व करता है।

Comment प्रकार निम्नलिखित सदस्य दिखाता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`text`](/slides/python-net/hi/aspose.slides/comment/text/) | एक स्लाइड टिप्पणी का साधारण पाठ लौटाता है या सेट करता है।<br/>            पढ़ें/लिखें **str**. |
| [`created_time`](/slides/python-net/hi/aspose.slides/comment/created_time/) | एक टिप्पणी निर्माण का समय लौटाता है या सेट करता है।<br/>            इस गुण को **System.DateTime** पर सेट करने का अर्थ है कि टिप्पणी समय सेट नहीं है।<br/>            पढ़ें/लिखें **System.DateTime**. |
| [`slide`](/slides/python-net/hi/aspose.slides/comment/slide/) | एक टिप्पणी की पैरेंट स्लाइड लौटाता है या सेट करता है।<br/>            केवल-पढ़ने योग्य [`ISlide`](/slides/python-net/hi/aspose.slides/islide). |
| [`author`](/slides/python-net/hi/aspose.slides/comment/author/) | एक टिप्पणी के लेखक को लौटाता है।<br/>            केवल-पढ़ने योग्य [`ICommentAuthor`](/slides/python-net/hi/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/hi/aspose.slides/comment/position/) | एक स्लाइड पर टिप्पणी की स्थिति लौटाता है या सेट करता है।<br/>            पढ़ें/लिखें [`PointF`](/slides/python-net/hi/aspose.slides/pointf). |
| [`parent_comment`](/slides/python-net/hi/aspose.slides/comment/parent_comment/) | पैरेंट टिप्पणी को प्राप्त करता है या सेट करता है।<br/>            पढ़ें/लिखें [`IComment`](/slides/python-net/hi/aspose.slides/icomment). |
