## ISensitivityLabel वर्ग

Microsoft Purview Information Protection से संवेदनशीलता लेबल को दर्शाता है।

ISensitivityLabel प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| Property | Description |
| :- | :- |
| [`id`](/slides/python-net/hi/aspose.slides/isensitivitylabel/id/) | संवेदनशीलता लेबल का id लौटता है या सेट करता है।<br/>            पढ़ें/लिखें **str**. |
| [`site_id`](/slides/python-net/hi/aspose.slides/isensitivitylabel/site_id/) | संवेदनशीलता लेबल नीति से सम्बंधित Azure Active Directory (Azure AD) साइट पहचानकर्ता को लौटता है या सेट करता है जो संवेदनशीलता लेबल का वर्णन करता है।<br/>            पढ़ें/लिखें **System.Guid**. |
| [`is_enabled`](/slides/python-net/hi/aspose.slides/isensitivitylabel/is_enabled/) | दर्शाता है कि संवेदनशीलता लेबल सक्षम है या नहीं। |
| [`is_removed`](/slides/python-net/hi/aspose.slides/isensitivitylabel/is_removed/) | दर्शाता है कि संवेदनशीलता लेबल हटाया गया था या नहीं। |
| [`assignment_method_type`](/slides/python-net/hi/aspose.slides/isensitivitylabel/assignment_method_type/) | संवेदनशीलता लेबल के लिए असाइनमेंट विधि को लौटता है या सेट करता है।<br/>            पढ़ें/लिखें [`SensitivityLabelAssignmentType`](/slides/python-net/hi/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/hi/aspose.slides/isensitivitylabel/content_mark_types/) | फ़ाइल पर लागू किए जाने वाले सामग्री मार्किंग प्रकारों की सूची लौटता है। |
