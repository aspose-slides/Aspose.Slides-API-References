## ImageWrapper वर्ग

## गुण

| Property | Description |
| :- | :- |
| [`image_source`](/slides/python-net/hi/aspose.slides/imagewrapper/image_source/) | छवि प्राप्त करता है.<br/>            केवल पढ़ने योग्य [`IImage`](/slides/python-net/hi/aspose.slides/iimage). |
| [`size`](/slides/python-net/hi/aspose.slides/imagewrapper/size/) | छवि की चौड़ाई और ऊँचाई, पिक्सेल में, प्राप्त करता है।<br/>            केवल पढ़ने योग्य [`ImageWrapper.size`](/slides/python-net/hi/aspose.slides/imagewrapper/size). |
