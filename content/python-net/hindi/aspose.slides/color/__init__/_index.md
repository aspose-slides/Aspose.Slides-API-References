निर्दिष्ट लाल, हरे, नीले और अल्फा घटक मानों से एक रंग बनाता है।


```python
def __init__(self, r=0, g=0, b=0, a=255):
    ...
```


| पैरामीटर | प्रकार | विवरण |
| :- | :- | :- |
| r | **int** | लाल घटक का मान। मान्य मान 0 से 255 तक हैं। |
| g | **int** | हरे घटक का मान। मान्य मान 0 से 255 तक हैं। |
| b | **int** | नीले घटक का मान। मान्य मान 0 से 255 तक हैं। |
| a | **int** | अल्फा घटक का मान। मान्य मान 0 से 255 तक हैं। |

### अपवाद

| अपवाद | विवरण |
