## from_rgb(r, g, b) {#int-int-int}
निर्दिष्ट लाल, हरा और नीले मानों से एक अपारदर्शी रंग बनाता है (alpha 255 है)।

### वापसी

निर्दिष्ट मानों से निर्मित रंग।



```python
@staticmethod
def from_rgb(r, g, b):
    ...
```


| पैरामीटर | प्रकार | विवरण |
| :- | :- | :- |
| r | **int** | लाल घटक का मान। मान्य मान 0 से 255 तक हैं। |
| g | **int** | हरा घटक का मान। मान्य मान 0 से 255 तक हैं। |
| b | **int** | नीला घटक का मान। मान्य मान 0 से 255 तक हैं। |

### अपवाद

| अपवाद | विवरण |
| :- | :- |
| **ValueError** | कोई घटक मान 0 से कम या 255 से अधिक है। |
