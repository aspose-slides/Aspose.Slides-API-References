## ShapeAdjustmentType एन्यूमरेशन

आकृति समायोजन मूल्यों के विभिन्न प्रकार निर्दिष्ट करता है।

ShapeAdjustmentType प्रकार निम्नलिखित सदस्यों को प्रदर्शित करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| CUSTOM | कस्टम प्रकार (अज्ञात समायोजन) |
| CORNER_SIZE | कोनों के आकार को नियंत्रित करता है। |
| LEFT_UP_CORNER | ऊपर बाएँ कोने को नियंत्रित करता है। |
| RIGHT_UP_CORNER | ऊपर दाएँ कोने को नियंत्रित करता है। |
| UP_CORNERS | ऊपरी कोनों को नियंत्रित करता है। |
| DOWN_CORNERS | नीचे के कोनों को नियंत्रित करता है। |
| THICKNESS | आकृति की मोटाई को नियंत्रित करता है। |
| ARROW_TAIL_THICKNESS | तीर के पूंछ की मोटाई को नियंत्रित करता है। |
| ARROWHEAD_LENGTH | तीर के सिर के लंबाई को नियंत्रित करता है। |
| ARROWHEAD_WIDTH | तीर के सिर की चौड़ाई को नियंत्रित करता है। |
| RADIUS | आकृति या उसके भाग के त्रिज्या के आकार को नियंत्रित करता है। |
| DEPTH | गियर के दाँतों या बिवेल प्रभाव की गहराई को नियंत्रित करता है। |
| SHAPE_PART_OFFSET | आकृति के एक भाग को दूसरे के सापेक्ष ऑफ़सेट को नियंत्रित करता है। |
| ANGLE | आकृति या उसके भाग के कोण को नियंत्रित करता है। |
| START_ANGLE | पाई और चाप आकृतियों के लिए प्रारम्भिक कोण। |
| END_ANGLE | पाई और चाप आकृतियों के लिए अंतिम कोण। |
| START_POINT_X | कॉलआउट प्रारम्भ बिंदु X स्थिति को नियंत्रित करता है। |
| START_POINT_Y | कॉलआउट प्रारम्भ बिंदु Y स्थिति को नियंत्रित करता है। |
| CONNECTOR_POINT_1X | कॉलआउट कोण समायोजन बिंदु की क्षैतिज स्थिति को नियंत्रित करता है। |
| CONNECTOR_POINT_1Y | कॉलआउट कोण समायोजन बिंदु की लंबवत स्थिति को नियंत्रित करता है। |
| CONNECTOR_POINT_2X | कॉलआउट कोण समायोजन बिंदु की क्षैतिज स्थिति को नियंत्रित करता है। |
| CONNECTOR_POINT_2Y | कॉलआउट कोण समायोजन बिंदु की लंबवत स्थिति को नियंत्रित करता है। |
| CONNECTOR_BEND_POSITION_X | कनेक्टर में मोड़ की क्षैतिज स्थिति को नियंत्रित करता है। |
| CONNECTOR_BEND_POSITION_Y | कनेक्टर में मोड़ की लंबवत स्थिति को नियंत्रित करता है। |
| ATTACH_Y | आकृति के लंबवत संलग्न बिंदु को नियंत्रित करता है। |
| ATTACH_X | आकृति के क्षैतिज संलग्न बिंदु को नियंत्रित करता है। |
| CALLOUT_HEIGHT | कॉलआउट की लंबवत आकार को नियंत्रित करता है। |
| CALLOUT_WIDTH | कॉलआउट की क्षैतिज आकार को नियंत्रित करता है। |
| CALLOUT_SIZE | कॉलआउट के आकार को नियंत्रित करता है। |
| CURVATURE | मोड़े, ब्रेस, वक्र तीर या आकृति की वक्रता। |
| HORIZONTAL_THICKNESS | कोने की आकृति की क्षैतिज मोटाई को नियंत्रित करता है। |
| VERTICAL_THICKNESS | कोने की आकृति की लंबवत मोटाई को नियंत्रित करता है। |
| VERTICAL_SIZE | आकृति के लंबवत आकार को नियंत्रित करता है। |
| HORIZONTAL_SIZE | आकृति के क्षैतिज आकार को नियंत्रित करता है। |
| TOP | आकृति के शीर्ष पक्ष को नियंत्रित करता है। |
