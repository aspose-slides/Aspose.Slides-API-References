## Point क्लास

एक दो-आयामी तल में बिंदु को परिभाषित करने वाले पूर्णांक x- और y-निर्देशांक की क्रमबद्ध जोड़ी को दर्शाता है। .NET `System.Drawing.Point` के साथ संगत है।

Point प्रकार निम्न सदस्य प्रदान करता है:

## कंस्ट्रक्टर

| Constructor | Description |
| :- | :- |
| [`__init__(self, x=0, y=0)`](/slides/python-net/hi/aspose.slides/point/__init__/#int-int) | निर्दिष्ट निर्देशांक के साथ एक बिंदु बनाता है। फ़्लोट मान को पूर्णांक में ट्रंकेट किया जाता है। |

## प्रॉपर्टी

| Property | Description |
| :- | :- |
| [`x`](/slides/python-net/hi/aspose.slides/point/x/) | इस बिंदु के x-निर्देशांक को प्राप्त करता है या सेट करता है।<br/>            पढ़ें/लिखें **int**. |
| [`y`](/slides/python-net/hi/aspose.slides/point/y/) | इस बिंदु के y-निर्देशांक को प्राप्त करता है या सेट करता है।<br/>            पढ़ें/लिखें **int**. |


### टिप्पणी

`==` का उपयोग करके बिंदुओं की उनके निर्देशांक से तुलना की जाती है और उन्हें शब्दकोश कुंजियों या सेट सदस्यों के रूप में उपयोग किया जा सकता है।
