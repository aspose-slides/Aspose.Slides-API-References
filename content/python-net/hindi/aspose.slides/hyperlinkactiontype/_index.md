## HyperlinkActionType एन्युमरेशन

Represents a type of hyperlink action.

The HyperlinkActionType type exposes the following members:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| UNKNOWN | अमान्य कार्रवाई प्रकार। |
| NO_ACTION | कोई कार्रवाई नहीं। |
| HYPERLINK | सामान्य हाइपरलिंक। |
| JUMP_FIRST_SLIDE | प्रस्तुति की पहली स्लाइड पर जाएँ। |
| JUMP_PREVIOUS_SLIDE | पिछली स्लाइड पर जाएँ। |
| JUMP_NEXT_SLIDE | अगली स्लाइड पर जाएँ। |
| JUMP_LAST_SLIDE | प्रस्तुति की अंतिम स्लाइड पर जाएँ। |
| JUMP_END_SHOW | स्लाइडशो के अंत पर जाएँ। |
| JUMP_LAST_VIEWED_SLIDE | आखिरी देखी गई स्लाइड पर जाएँ। |
| JUMP_SPECIFIC_SLIDE | विशिष्ट स्लाइड पर जाएँ, जिसे [`IHyperlink.target_slide`](/slides/python-net/hi/aspose.slides/ihyperlink/target_slide) प्रॉपर्टी द्वारा संकेतित किया गया है। |
| START_CUSTOM_SLIDE_SHOW | कस्टम स्लाइडशो शुरू करें। |
| OPEN_FILE | संदर्भित फ़ाइल खोलें। |
| OPEN_PRESENTATION | संदर्भित प्रस्तुति खोलें। |
| START_STOP_MEDIA | मीडिया फ़ाइल चलाना शुरू/रोकें। |
| START_MACRO | मैक्रो स्क्रिप्ट चलाना शुरू करें। |
| START_PROGRAM | प्रोग्राम शुरू करें। |
