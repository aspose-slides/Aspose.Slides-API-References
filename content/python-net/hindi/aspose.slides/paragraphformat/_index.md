## विधियाँ

| Method | Description |
| :- | :- |
| [`get_effective(self)`](/slides/python-net/hi/aspose.slides/paragraphformat/get_effective/#) | विरासत लागू होने पर प्रभावी पैराग्राफ फ़ॉर्मैटिंग डेटा प्राप्त करता है। |

### टिप्पणियाँ

इस क्लास का उपयोग विशेष पैराग्राफ के लिए परिभाषित पैराग्राफ फ़ॉर्मैटिंग गुणों को लौटाने और बदलने के लिए किया जाता है। इसका अर्थ है कि मान प्राप्त करते समय कोई विरासत लागू नहीं होती, इसलिए अधिकांश मामलों में आपको "अपरिभाषित" मान प्राप्त होंगे।

विरासत सहित प्रभावी फ़ॉर्मैटिंग पैरामीटर मान प्राप्त करने के लिए आपको [`ParagraphFormat.get_effective`](/slides/python-net/hi/aspose.slides/paragraphformat/get_effective) विधि का उपयोग करना होगा जो एक [`IParagraphFormatEffectiveData`](/slides/python-net/hi/aspose.slides/iparagraphformateffectivedata) इंस्टेंस लौटाता है।
