## add_auto_shape(self, shape_type, x, y, width, height, create_from_template) {#shapetype-float-float-float-float-bool}

            इसे डिफ़ॉल्ट टेम्पलेट फ़ॉर्मेटिंग के साथ इनिशियलाइज़ करता है।

### रिटर्न

नया बनाया गया [`IAutoShape`](/slides/python-net/hi/aspose.slides/iautoshape).



```python
def add_auto_shape(self, shape_type, x, y, width, height, create_from_template):
    ...
```


| पैरामीटर | प्रकार | विवरण |
| :- | :- | :- |
| shape_type | [`ShapeType`](/slides/python-net/hi/aspose.slides/shapetype) | जोड़ने के लिए ऑटो शेप का [`ShapeType`](/slides/python-net/hi/aspose.slides/shapetype)। |
| x | **float** | shape के फ्रेम का x-निर्देशांक, पॉइंट्स में। |
| y | **float** | shape के फ्रेम का y-निर्देशांक, पॉइंट्स में। |
| width | **float** | shape के फ्रेम की चौड़ाई, पॉइंट्स में। |
| height | **float** | shape के फ्रेम की ऊँचाई, पॉइंट्स में। |
| create_from_template | **bool** | True डिफ़ॉल्ट टेम्पलेट स्टाइल (सादा स्टाइल, केंद्रित टेक्स्ट, और गैर-खाली नाम) नए शेप पर लागू करने के लिए;<br/><br/>            false सभी गुणों को डिफ़ॉल्ट मानों पर सेट करके शेप बनाने के लिए। |
