## IComment क्लास

स्लाइड पर टिप्पणी का प्रतिनिधित्व करता है।

IComment प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## प्रॉपर्टीज़

| गुण | विवरण |
| :- | :- |
| [`text`](/slides/python-net/hi/aspose.slides/icomment/text/) | स्लाइड टिप्पणी का साधारण पाठ लौटाता है या सेट करता है।<br/> पढ़ें/लिखें **str**. |
| [`created_time`](/slides/python-net/hi/aspose.slides/icomment/created_time/) | टिप्पणी निर्माण का समय लौटाता है या सेट करता है।<br/> इस प्रॉपर्टी को **System.DateTime** पर सेट करने का अर्थ है कोई टिप्पणी समय सेट नहीं है।<br/> पढ़ें/लिखें **System.DateTime**. |
| [`slide`](/slides/python-net/hi/aspose.slides/icomment/slide/) | टिप्पणी का मूल स्लाइड लौटाता है या सेट करता है।<br/> केवल-पढ़ने योग्य [`ISlide`](/slides/python-net/hi/aspose.slides/islide). |
| [`author`](/slides/python-net/hi/aspose.slides/icomment/author/) | टिप्पणी के लेखक को लौटाता है।<br/> केवल-पढ़ने योग्य [`ICommentAuthor`](/slides/python-net/hi/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/hi/aspose.slides/icomment/position/) | स्लाइड पर टिप्पणी की स्थिति लौटाता है या सेट करता है।<br/> पढ़ें/लिखें **aspose.slides.PointF**. |
| [`parent_comment`](/slides/python-net/hi/aspose.slides/icomment/parent_comment/) | मूल टिप्पणी को प्राप्त करता है या सेट करता है।<br/> पढ़ें/लिखें [`IComment`](/slides/python-net/hi/aspose.slides/icomment). |
