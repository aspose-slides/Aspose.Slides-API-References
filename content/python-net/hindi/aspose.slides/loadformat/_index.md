## LoadFormat एन्यूमरेशन

दस्तावेज़ के लोड किए जाने वाले फ़ॉर्मेट को दर्शाता है।

| PPT | Microsoft PowerPoint 97-2003 प्रस्तुति। |

| PPSX | Microsoft Office Open XML PresentationML स्लाइडशो। |
| ODP | OpenOffice ODF प्रस्तुति। |
| POTX | Microsoft Office Open XML PresentationML टेम्पलेट। |
| PPTM | Microsoft Office Open XML PresentationML मैक्रो-सक्षम दस्तावेज़। |
| PPSM | Microsoft Office Open XML PresentationML मैक्रो-सक्षम स्लाइडशो। |
