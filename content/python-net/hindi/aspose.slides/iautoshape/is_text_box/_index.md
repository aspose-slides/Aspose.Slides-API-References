## is_text_box गुण
निर्देशित करता है कि आकार टेक्स्ट बॉक्स है या नहीं।

### टिप्पणी

यदि आकार को टेक्स्ट बॉक्स के रूप में निर्दिष्ट नहीं किया गया है, तो इसका मतलब यह नहीं है कि उसमें टेक्स्ट संलग्न नहीं हो सकता। एक टेक्स्ट बॉक्स केवल विशिष्ट गुणों वाला एक विशेष आकार होता है।
