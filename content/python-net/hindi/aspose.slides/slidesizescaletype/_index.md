## SlideSizeScaleType एन्यूमेरेशन

स्लाइड सामग्री के स्केल प्रकार का प्रतिनिधित्व करता है।

SlideSizeScaleType टाइप निम्नलिखित सदस्य उजागर करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| DO_NOT_SCALE | स्केल न करें। |
| ENSURE_FIT | फ़िट सुनिश्चित करने के लिए स्केल करें। |
| MAXIMIZE | सामग्री का आकार अधिकतम करें। |
