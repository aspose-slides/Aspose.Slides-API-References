## ColorType एन्यूमरेशन

विभिन्न रंग मोड्स को दर्शाता है।

ColorType प्रकार निम्नलिखित सदस्य प्रदर्शित करता है:

## फ़ील्ड

| फ़ील्ड | विवरण |
| :- | :- |
| NOT_DEFINED | रंग बिल्कुल भी परिभाषित नहीं है। |
| RGB | मानक 24 बिट RGB रंग। |
| RGB_PERCENTAGE | उच्च परिभाषा RGB रंग। |
| HSL | उच्च परिभाषा HSL रंग। |
| SCHEME | स्कीम रंग। |
| SYSTEM | सिस्टम रंग। |
| PRESET | प्रीसेट रंग। |
