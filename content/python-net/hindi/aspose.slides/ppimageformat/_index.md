## PPImageFormat एन्यूमेरेशन

इमेज फ़ॉर्मेट्स। यह एनीम `System.Drawing.Imaging.ImageFormat` क्लास का प्रतिस्थापन है। यह COM संगतता के लिए आवश्यक है।

PPImageFormat प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## फ़ील्ड

| फ़ील्ड | विवरण |
| :- | :- |
| BMP | बिटमैप (BMP) इमेज फ़ॉर्मेट प्राप्त करता है। |
| EMF | बढ़ी हुई मेटा फ़ाइल (EMF) इमेज फ़ॉर्मेट प्राप्त करता है। |
| EXIF | एक्सचेंजेबल इमेज फ़ाइल (Exif) फ़ॉर्मेट प्राप्त करता है। |
| GIF | ग्राफ़िक्स इंटरचेंज फ़ॉर्मेट (GIF) इमेज फ़ॉर्मेट प्राप्त करता है। |
| ICON | विंडोज़ आइकन इमेज फ़ॉर्मेट प्राप्त करता है। |
| JPEG | जॉइंट फ़ोटो ग्राफ़िक एक्सपर्ट्स ग्रुप (JPEG) इमेज फ़ॉर्मेट प्राप्त करता है। |
| MEMORY_BMP | मेमोरी में बिटमैप का फ़ॉर्मेट प्राप्त करता है। |
| PNG | W3C पोर्टेबल नेटवर्क ग्राफ़िक्स (PNG) इमेज फ़ॉर्मेट प्राप्त करता है। |
| TIFF | टैग्ड इमेज फ़ाइल फ़ॉर्मेट (TIFF) इमेज फ़ॉर्मेट प्राप्त करता है। |
| WMF | विंडोज़ मेटा फ़ाइल (WMF) इमेज फ़ॉर्मेट प्राप्त करता है। |
