## IFonts वर्ग

फ़ॉन्ट संग्रह का प्रतिनिधित्व करता है।

IFonts प्रकार निम्नलिखित सदस्य उजागर करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`latin_font`](/slides/python-net/hi/aspose.slides/ifonts/latin_font/) | Latin फ़ॉन्ट को लौटाता है या सेट करता है।<br/>            पढ़ें/लिखें [`IFontData`](/slides/python-net/hi/aspose.slides/ifontdata)। |
| [`east_asian_font`](/slides/python-net/hi/aspose.slides/ifonts/east_asian_font/) | East Asian फ़ॉन्ट को लौटाता है या सेट करता है।<br/>            पढ़ें/लिखें [`IFontData`](/slides/python-net/hi/aspose.slides/ifontdata)। |
| [`complex_script_font`](/slides/python-net/hi/aspose.slides/ifonts/complex_script_font/) | complex script फ़ॉन्ट को लौटाता है या सेट करता है।<br/>            पढ़ें/लिखें [`IFontData`](/slides/python-net/hi/aspose.slides/ifontdata)। |
