## SourceFormat एन्यूमरेशन

स्रोत फ़ाइल प्रारूप का प्रतिनिधित्व करता है।

SourceFormat टाइप निम्नलिखित सदस्यों को उजागर करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| PPT | Microsoft PowerPoint 97-2003 प्रस्तुति (*.ppt)। |
| PPTX | Microsoft Office Open XML प्रस्तुति (*.pptx)। |
| ODP | OpenDocument प्रस्तुति (*.odp)। |
| PPTM | Microsoft Office Open XML मैक्रो-सक्षम प्रस्तुति (*.pptm)। |
| PPSX | Microsoft Office Open XML स्लाइडशो (*.ppsx)। |
| PPSM | Microsoft Office Open XML मैक्रो-सक्षम स्लाइडशो (*.ppsm)। |
| POTX | Microsoft Office Open XML टेम्पलेट (*.potx)। |
| POTM | Microsoft Office Open XML मैक्रो-सक्षम टेम्पलेट (*.potm)। |
| PPS | Microsoft PowerPoint 97-2003 स्लाइडशो (*.pps)। |
| POT | Microsoft PowerPoint 97-2003 टेम्पलेट (*.pot)। |
| OTP | OpenDocument प्रस्तुति टेम्पलेट (*.otp)। |
| FODP | Flat XML ODF प्रस्तुति (*.fodp)। |
| XML | PowerPoint XML प्रस्तुति (*.xml)। |
