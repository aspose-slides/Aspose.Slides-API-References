## SensitivityLabel क्लास

Microsoft Purview Information Protection से संवेदनशीलता लेबल का प्रतिनिधित्व करता है।

SensitivityLabel प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`id`](/slides/python-net/hi/aspose.slides/sensitivitylabel/id/) | संवेदनशीलता लेबल की आईडी को वापस करता है या सेट करता है।<br/>            पढ़ें/लिखें **str**. |
| [`site_id`](/slides/python-net/hi/aspose.slides/sensitivitylabel/site_id/) | संवेदनशीलता लेबल नीति से संबंधित Azure Active Directory (Azure AD) साइट पहचानकर्ता को वापस करता है या सेट करता है जो संवेदनशीलता लेबल का वर्णन करता है।<br/>            पढ़ें/लिखें **System.Guid**. |
| [`is_enabled`](/slides/python-net/hi/aspose.slides/sensitivitylabel/is_enabled/) | इंगित करता है कि संवेदनशीलता लेबल सक्षम है या नहीं। |
| [`is_removed`](/slides/python-net/hi/aspose.slides/sensitivitylabel/is_removed/) | इंगित करता है कि संवेदनशीलता लेबल हटा दिया गया है या नहीं। |
| [`assignment_method_type`](/slides/python-net/hi/aspose.slides/sensitivitylabel/assignment_method_type/) | संवेदनशीलता लेबल के असाइनमेंट विधि को वापस करता है या सेट करता है।<br/>            पढ़ें/लिखें [`SensitivityLabelAssignmentType`](/slides/python-net/hi/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/hi/aspose.slides/sensitivitylabel/content_mark_types/) | फ़ाइल पर लागू की जाने वाली सामग्री चिह्नित करने के प्रकारों की सूची को वापस करता है। |
