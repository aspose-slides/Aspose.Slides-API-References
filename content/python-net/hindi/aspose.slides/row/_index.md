## Row क्लास

| गुण | विवरण |
| :- | :- |
| [`slide`](/slides/python-net/hi/aspose.slides/row/slide/) | CellCollection की मूल स्लाइड लौटाता है.<br/>            केवल पढ़ने योग्य [`IBaseSlide`](/slides/python-net/hi/aspose.slides/ibaseslide). |

| [`height`](/slides/python-net/hi/aspose.slides/row/height/) | पंक्ति की ऊँचाई लौटाता है.<br/>            केवल पढ़ने योग्य **float**. |

| [`row_format`](/slides/python-net/hi/aspose.slides/row/row_format/) | RowFormat ऑब्जेक्ट लौटाता है जिसमें इस पंक्ति के लिए स्वरूपण गुण होते हैं.<br/>            केवल पढ़ने योग्य [`IRowFormat`](/slides/python-net/hi/aspose.slides/irowformat). |
