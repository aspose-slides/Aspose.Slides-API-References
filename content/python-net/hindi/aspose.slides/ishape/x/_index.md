## x प्रॉपर्टी
आकार के ऊपरी-बाएँ कोने के x-निर्देशांक को प्राप्त करता है या सेट करता है, जिसे पॉइंट्स में मापा जाता है.
            पढ़ें/लिखें **float**.

### टिप्पणियाँ

वापसी मान हमेशा परिभाषित होता है और कभी भी **float** नहीं होता।
            निर्धारित मान भी परिभाषित होना चाहिए; **float** केवल `RawFrame` उदाहरण की प्रॉपर्टियों को ही सौंपें।

### परिभाषा:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
