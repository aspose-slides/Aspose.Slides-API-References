## रोटेशन प्रॉपर्टी
Returns or sets the number of degrees the specified shape is rotated around
the z-axis. A positive value indicates clockwise rotation; a negative value
indicates counterclockwise rotation.
पढ़ने/लिखने योग्य **float**.

### टिप्पणी

वापसी मान हमेशा परिभाषित रहता है (float.NaN नहीं है). आवंटित मान परिभाषित होना चाहिए (float.NaN नहीं). आप RawFrame इंस्टेंस गुणों के लिए अपरिभाषित मान सेट कर सकते हैं।
