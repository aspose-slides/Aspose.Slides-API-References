## ResourceLoadingAction एन्यूमरेशन

बाहरी संसाधन लोडिंग के मोड को निर्दिष्ट करता है।

ResourceLoadingAction प्रकार निम्नलिखित सदस्य उजागर करता है:

## फ़ील्ड

| फ़ील्ड | विवरण |
| :- | :- |
| DEFAULT | Aspose.Slides सामान्य रूप से बाहरी संसाधन लोड करेगा। |
| SKIP | Aspose.Slides बाहरी संसाधन के लोडिंग को छोड़ देगा। केवल लिंक बिना डेटा के एक छवि के लिए संग्रहित किया जाएगा। |
| USER_PROVIDED | Aspose.Slides उपयोगकर्ता द्वारा प्रदान किए गए बाइट एरे का उपयोग **Aspose.Slides.IResourceLoadingArgs.SetData(Syste** को छवि डेटा के रूप में करेगा। |
