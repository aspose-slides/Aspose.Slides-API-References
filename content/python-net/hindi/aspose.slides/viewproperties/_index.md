## ViewProperties क्लास

प्रेजेंटेशन-व्यापी दृश्य गुण।

ViewProperties टाइप निम्न सदस्य प्रदान करता है:

## प्रॉपर्टीज़

| प्रॉपर्टी | विवरण |
| :- | :- |
| [`last_view`](/slides/python-net/hi/aspose.slides/viewproperties/last_view/) | निर्दिष्ट करता है वह दृश्य मोड जो प्रस्तुति दस्तावेज़ को अंतिम बार सहेजा गया था।<br/>            पढ़ें/लिखें [`ViewType`](/slides/python-net/hi/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/hi/aspose.slides/viewproperties/show_comments/) | निर्दिष्ट करता है कि स्लाइड टिप्पणी दिखाने चाहिए या नहीं।<br/>            पढ़ें/लिखें [`NullableBool`](/slides/python-net/hi/aspose.slides/nullablebool). |
| [`normal_view_properties`](/slides/python-net/hi/aspose.slides/viewproperties/normal_view_properties/) | सामान्य दृश्य गुणों का प्रतिनिधित्व करता है। सामान्य दृश्य में तीन सामग्री क्षेत्र होते हैं:<br/>            स्लाइड स्वयं, एक साइड सामग्री क्षेत्र, और एक बॉटम सामग्री क्षेत्र।<br/>            केवल पढ़ने योग्य [`INormalViewProperties`](/slides/python-net/hi/aspose.slides/inormalviewproperties). |
| [`slide_view_properties`](/slides/python-net/hi/aspose.slides/viewproperties/slide_view_properties/) | स्लाइड दृश्य मोड से जुड़े सामान्य दृश्य गुणों को निर्दिष्ट करता है।<br/>            केवल पढ़ने योग्य [`ICommonSlideViewProperties`](/slides/python-net/hi/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/hi/aspose.slides/viewproperties/notes_view_properties/) | नोट्स दृश्य मोड से जुड़े सामान्य दृश्य गुणों को निर्दिष्ट करता है।<br/>            केवल पढ़ने योग्य [`ICommonSlideViewProperties`](/slides/python-net/hi/aspose.slides/icommonslideviewproperties). |
| [`grid_spacing`](/slides/python-net/hi/aspose.slides/viewproperties/grid_spacing/) | प्रेजेंटेशन दस्तावेज़ के नीचे ग्रिड के लिए उपयोग किए जाने वाले ग्रिड स्पेसिंग को बिंदुओं में लौटाता या सेट करता है।<br/>            पढ़ें/लिखें **float**. |
