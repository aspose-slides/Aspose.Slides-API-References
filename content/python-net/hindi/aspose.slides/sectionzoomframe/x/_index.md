## x गुण
आकृति के ऊपरी-बाएं कोने के x-कोऑर्डिनेट को प्राप्त करता है या सेट करता है, जो बिंदुओं में मापा जाता है।
पढ़ें/लिखें **float**.


### टिप्पणी

वापसी मान हमेशा परिभाषित रहता है और कभी भी **float** नहीं होता।
आवंटित मान भी परिभाषित होना चाहिए; केवल `RawFrame` उदाहरण की गुणों को ही **float** आवंटित करें।

### परिभाषा:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
