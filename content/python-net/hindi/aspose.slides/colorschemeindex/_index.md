## ColorSchemeIndex एन्यूमरेशन

एक रंग योजना में इंडेक्स को दर्शाता है।

ColorSchemeIndex टाइप निम्नलिखित सदस्यों को प्रकट करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| DARK1 | गहरा 1. |
| LIGHT1 | प्रकाश 1. |
| DARK2 | गहरा 2. |
| LIGHT2 | प्रकाश 2. |
| ACCENT1 | एक्सेंट 1. |
| ACCENT2 | एक्सेंट 2. |
| ACCENT3 | एक्सेंट 3. |
| ACCENT4 | एक्सेंट 4. |
| ACCENT5 | एक्सेंट 5. |
| ACCENT6 | एक्सेंट 6. |
| HYPERLINK | हाइपरलिंक. |
| FOLLOWED_HYPERLINK | अनुसरित हाइपरलिंक. |
