## ISvgImage वर्ग

एक SVG छवि का प्रतिनिधित्व करता है।

ISvgImage प्रकार निम्नलिखित सदस्य प्रदान करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`svg_content`](/slides/python-net/hi/aspose.slides/isvgimage/svg_content/) | SVG सामग्री लौटाता है.<br/>            केवल-पढ़ने योग्य **str**. |
| [`svg_data`](/slides/python-net/hi/aspose.slides/isvgimage/svg_data/) | SVG डेटा लौटाता है.<br/>            केवल-पढ़ने योग्य **int**[]. |
| [`external_resource_resolver`](/slides/python-net/hi/aspose.slides/isvgimage/external_resource_resolver/) | SVG दस्तावेज़ आयात के दौरान बाहरी संसाधनों को हल करने के लिए उपयोग किया जाने वाला कॉलबैक इंटरफ़ेस लौटाता है.<br/>            केवल-पढ़ने योग्य **IExternalResourceResolver**. |
| [`base_uri`](/slides/python-net/hi/aspose.slides/isvgimage/base_uri/) | निर्दिष्ट SVG की आधार URI लौटाता है। सापेक्ष लिंक हल करने के लिए उपयोग किया जाता है.<br/>            केवल-पढ़ने योग्य **str**. |
