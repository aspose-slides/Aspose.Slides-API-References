## IGradientFormat क्लास

एक ग्रेडिएंट फ़ॉर्मेट का प्रतिनिधित्व करता है।

IGradientFormat प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| प्रॉपर्टी | विवरण |
| :- | :- |
| [`tile_flip`](/slides/python-net/hi/aspose.slides/igradientformat/tile_flip/) | एक ग्रेडिएंट के लिए फ्लिपिंग मोड को वापस देता है या सेट करता है।<br/>            पढ़ें/लिखें [`TileFlip`](/slides/python-net/hi/aspose.slides/tileflip). |
| [`gradient_direction`](/slides/python-net/hi/aspose.slides/igradientformat/gradient_direction/) | ग्रेडिएंट की शैली को वापस देता है या सेट करता है।<br/>            पढ़ें/लिखें [`GradientDirection`](/slides/python-net/hi/aspose.slides/gradientdirection). |
| [`linear_gradient_angle`](/slides/python-net/hi/aspose.slides/igradientformat/linear_gradient_angle/) | ग्रेडिएंट का कोन वापस देता है या सेट करता है।<br/>            पढ़ें/लिखें **float**. |
| [`linear_gradient_scaled`](/slides/python-net/hi/aspose.slides/igradientformat/linear_gradient_scaled/) | निर्धारित करता है कि ग्रेडिएंट स्केल किया गया है या नहीं।<br/>            पढ़ें/लिखें [`NullableBool`](/slides/python-net/hi/aspose.slides/nullablebool). |
| [`gradient_shape`](/slides/python-net/hi/aspose.slides/igradientformat/gradient_shape/) | ग्रेडिएंट के आकार को वापस देता है या सेट करता है।<br/>            पढ़ें/लिखें [`GradientShape`](/slides/python-net/hi/aspose.slides/gradientshape). |
| [`gradient_stops`](/slides/python-net/hi/aspose.slides/igradientformat/gradient_stops/) | ग्रेडिएंट स्टॉप्स का संग्रह वापस देता है।<br/>            केवल-पढ़ें [`IGradientStopCollection`](/slides/python-net/hi/aspose.slides/igradientstopcollection). |
