## x प्रॉपर्टी
आकार के ऊपरी-बाएँ कोने के x-coordinate को प्राप्त करता है या सेट करता है, जो बिंदुओं में मापा जाता है.
            पढ़ें/लिखें **float**.


### टिप्पणियाँ

वापसी में प्राप्त मान हमेशा परिभाषित रहता है और कभी **float** नहीं होता।
            नियुक्त किया गया मान भी परिभाषित होना चाहिए; केवल `RawFrame` इंस्टेंस की प्रॉपर्टीज़ को **float** असाइन करें।

### परिभाषा:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
