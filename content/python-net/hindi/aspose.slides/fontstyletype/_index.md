## FontStyleType एन्यूमरेशन

टेक्स्ट पर लागू किए जा सकने वाले फॉर्मैटिंग शैलियों को परिभाषित करता है।

FontStyleType प्रकार निम्नलिखित सदस्य प्रस्तुत करता है:

## फ़ील्ड

| फ़ील्ड | विवरण |
| :- | :- |
| REGULAR | मानक टेक्स्ट। |
| BOLD | बोल्ड टेक्स्ट। |
| ITALIC | इटैलिक टेक्स्ट। |
| UNDERLINE | अंडरलाइन किया गया टेक्स्ट। |
| STRIKEOUT | टेक्स्ट जो क्षैतिज रेखा के साथ काटा गया है। |
