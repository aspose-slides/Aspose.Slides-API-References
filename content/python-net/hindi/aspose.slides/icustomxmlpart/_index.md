## ICustomXmlPart क्लास

कस्टम XML भाग का प्रतिनिधित्व करता है।

ICustomXmlPart प्रकार निम्नलिखित सदस्यों को प्रदर्शित करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`xml_as_string`](/slides/python-net/hi/aspose.slides/icustomxmlpart/xml_as_string/) | XML डेटा को UTF-8 स्ट्रिंग के रूप में प्राप्त करता है या सेट करता है।<br/>            पढ़ें/लिखें **str**.<br/>            मान `None` है। मान खाली है या XML-डेटा अमान्य है। |
| [`xml_data`](/slides/python-net/hi/aspose.slides/icustomxmlpart/xml_data/) | XML डेटा को प्राप्त करता है या सेट करता है।<br/>            पढ़ें/लिखें **int**[].<br/>            मान `None` है। मान खाली है या XML-डेटा अमान्य है। |
| [`item_id`](/slides/python-net/hi/aspose.slides/icustomxmlpart/item_id/) | एक वैश्विक अनन्य पहचानकर्ता (GUID) निर्दिष्ट करता है जो Office Open XML दस्तावेज़ में एकल कस्टम XML <br/>            भाग को अनन्य रूप से पहचानता है।<br/>            केवल-पढ़ने योग्य **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/hi/aspose.slides/icustomxmlpart/namespace_schemas/) | कस्टम XML भाग से जुड़े XML स्कीमा संग्रह को प्राप्त करता है।<br/>            केवल-पढ़ने योग्य **str**[]. |
