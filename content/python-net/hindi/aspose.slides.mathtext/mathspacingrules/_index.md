## MathSpacingRules एन्यूमरेशन

मैट्रिक्स की कॉलमों के बीच गैप (क्षैतिज स्पेसिंग) के प्रकार

MathSpacingRules प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## फ़ील्ड

| फ़ील्ड | विवरण |
| :- | :- |
| SINGLE_SPACING_GAP | एकल (कॉलम के लिए 1 em या पंक्तियों के लिए 1 लाइन) |
| ONE_AND_HALF_SPACING_GAP | एक और आधा (कॉलम के लिए 1.5 ems या पंक्तियों के लिए 1.5 लाइन) |
| DOUBLE_SPACING_GAP | डबल स्पेसिंग (कॉलम के लिए 2 ems या पंक्तियों के लिए 2 लाइन) |
| EXACTLY | सटीक मान<br/>            For columns, rely on value of ColumnGap, measured in twips<br/>            For rows, rely on value of RowGap, measured in twips |
| MULTIPLE | एकाधिक<br/>            For columns, rely on value of ColumnGap, measured in 0.5 em increments<br/>            For rows, rely on value of RowGap, measured in lines |
