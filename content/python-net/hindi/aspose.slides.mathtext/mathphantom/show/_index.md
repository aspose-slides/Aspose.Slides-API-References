## show प्रॉपर्टी
Gets or sets a value indicating whether the base element is displayed.

### टिप्पणियाँ

`false` होने पर, बेस एलिमेंट छिपा रहता है लेकिन अन्य phantom सेटिंग्स के आधार पर अभी भी स्थान ले सकता है। यह OMML विशेषता `m:show` के अनुरूप है।

### परिभाषा:
```python
@property
def show(self):
    ...

@show.setter
def show(self, value):
    ...
```
