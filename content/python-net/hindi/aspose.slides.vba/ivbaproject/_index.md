## IVbaProject क्लास

प्रेजेंटेशन मैक्रो के साथ VBA प्रोजेक्ट को दर्शाता है।

IVbaProject प्रकार निम्नलिखित सदस्य प्रदर्शित करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`name`](/slides/python-net/hi/aspose.slides.vba/ivbaproject/name/) | VBA प्रोजेक्ट का नाम लौटाता है।<br/>            केवल-पढ़ने योग्य **str**. |
| [`modules`](/slides/python-net/hi/aspose.slides.vba/ivbaproject/modules/) | VBA प्रोजेक्ट में शामिल सभी मॉड्यूलों की सूची लौटाता है।<br/>            केवल-पढ़ने योग्य [`IVbaModuleCollection`](/slides/python-net/hi/aspose.slides.vba/ivbamodulecollection). |
| [`references`](/slides/python-net/hi/aspose.slides.vba/ivbaproject/references/) | VBA प्रोजेक्ट में शामिल सभी रेफ़रेंसेज़ की सूची लौटाता है।<br/>            केवल-पढ़ने योग्य [`IVbaReferenceCollection`](/slides/python-net/hi/aspose.slides.vba/ivbareferencecollection). |
| [`is_password_protected`](/slides/python-net/hi/aspose.slides.vba/ivbaproject/is_password_protected/) | संकल्पित करता है कि क्या VBAProject पासवर्ड द्वारा संरक्षित है ताकि प्रोजेक्ट प्रॉपर्टीज़ देखी जाएँ।<br/>            केवल-पढ़ने योग्य **bool**. |

## विधियाँ

| विधि | विवरण |
| :- | :- |
| [`to_binary(self)`](/slides/python-net/hi/aspose.slides.vba/ivbaproject/to_binary/#) | VBA प्रोजेक्ट का बाइनरी प्रतिनिधित्व OLE कंटेनर के रूप में लौटाता है।<br/>            केवल-पढ़ने योग्य **int**[]. |
