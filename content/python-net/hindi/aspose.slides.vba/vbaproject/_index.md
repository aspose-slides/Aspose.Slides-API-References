## VbaProject क्लास

VBA प्रोजेक्ट का प्रतिनिधित्व करता है जिसमें प्रेजेंटेशन मैक्रोज़ होते हैं।

VbaProject प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## कंस्ट्रक्टर

| कंस्ट्रक्टर्स | विवरण |
| :- | :- |
| [`__init__(self)`](/slides/python-net/hi/aspose.slides.vba/vbaproject/__init__/#) | यह कंस्ट्रक्टर नई VBA प्रोजेक्ट को शुरू से बनाता है।<br/>            प्रोजेक्ट 1252 Windows Latin 1 (ANSI) कोडपेज में बनाया जाएगा |
| [`__init__(self, data)`](/slides/python-net/hi/aspose.slides.vba/vbaproject/__init__/#bytes) | यह कंस्ट्रक्टर OLE कंटेनर की बाइनरी प्रतिनिधित्व से VBA प्रोजेक्ट को लोड करता है। |

## प्रॉपर्टी

| गुण | विवरण |
| :- | :- |
| [`name`](/slides/python-net/hi/aspose.slides.vba/vbaproject/name/) | VBA प्रोजेक्ट का नाम लौटाता है।<br/>            केवल-पढ़ने योग्य **str**। |
| [`modules`](/slides/python-net/hi/aspose.slides.vba/vbaproject/modules/) | VBA प्रोजेक्ट में सम्मिलित सभी मॉड्यूल की सूची लौटाता है।<br/>            केवल-पढ़ने योग्य [`IVbaModuleCollection`](/slides/python-net/hi/aspose.slides.vba/ivbamodulecollection)। |
| [`references`](/slides/python-net/hi/aspose.slides.vba/vbaproject/references/) | VBA प्रोजेक्ट में सम्मिलित सभी रेफ़रेंसेस की सूची लौटाता है।<br/>            केवल-पढ़ने योग्य [`IVbaReferenceCollection`](/slides/python-net/hi/aspose.slides.vba/ivbareferencecollection)। |
| [`is_password_protected`](/slides/python-net/hi/aspose.slides.vba/vbaproject/is_password_protected/) | यह दर्शाता है कि VBAProject को प्रोजेक्ट प्रॉपर्टीज़ देखने के लिए पासवर्ड द्वारा संरक्षित किया गया है या नहीं।<br/>            केवल-पढ़ने योग्य **bool**। |
