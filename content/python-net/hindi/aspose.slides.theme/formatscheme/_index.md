## FormatScheme वर्ग

शेप्स के लिए थीम-परिभाषित फ़ॉर्मैट संग्रहीत करता है।

FormatScheme प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`fill_styles`](/slides/python-net/hi/aspose.slides.theme/formatscheme/fill_styles/) | थीम द्वारा परिभाषित फ़िल स्टाइल्स का संग्रह लौटाता है।<br/>            केवल-पढ़ने योग्य [`IFillFormatCollection`](/slides/python-net/hi/aspose.slides.theme/ifillformatcollection)। |
| [`line_styles`](/slides/python-net/hi/aspose.slides.theme/formatscheme/line_styles/) | थीम द्वारा परिभाषित लाइन स्टाइल्स का संग्रह लौटाता है।<br/>            केवल-पढ़ने योग्य [`ILineFormatCollection`](/slides/python-net/hi/aspose.slides.theme/ilineformatcollection)। |
| [`effect_styles`](/slides/python-net/hi/aspose.slides.theme/formatscheme/effect_styles/) | थीम द्वारा परिभाषित इफ़ेक्ट स्टाइल्स का संग्रह लौटाता है।<br/>            केवल-पढ़ने योग्य [`IEffectStyleCollection`](/slides/python-net/hi/aspose.slides.theme/ieffectstylecollection)। |
| [`background_fill_styles`](/slides/python-net/hi/aspose.slides.theme/formatscheme/background_fill_styles/) | थीम द्वारा परिभाषित बैकग्राउंड फ़िल स्टाइल्स का संग्रह लौटाता है।<br/>            केवल-पढ़ने योग्य [`IFillFormatCollection`](/slides/python-net/hi/aspose.slides.theme/ifillformatcollection)। |
| [`slide`](/slides/python-net/hi/aspose.slides.theme/formatscheme/slide/) | पैरेंट स्लाइड लौटाता है।<br/>            केवल-पढ़ने योग्य [`IBaseSlide`](/slides/python-net/hi/aspose.slides/ibaseslide)। |
| [`presentation`](/slides/python-net/hi/aspose.slides.theme/formatscheme/presentation/) | पैरेंट प्रेज़ेंटेशन लौटाता है।<br/>            केवल-पढ़ने योग्य [`IPresentation`](/slides/python-net/hi/aspose.slides/ipresentation)। |
