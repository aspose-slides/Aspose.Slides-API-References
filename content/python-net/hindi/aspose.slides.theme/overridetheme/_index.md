## OverrideTheme क्लास

एक ओवरराइडिंग थीम का प्रतिनिधित्व करता है।

**विरासत:**[`OverrideTheme`](/slides/python-net/hi/aspose.slides.theme/overridetheme) → [`Theme`](/slides/python-net/hi/aspose.slides.theme/theme)

OverrideTheme प्रकार निम्न सदस्य प्रदर्शित करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`color_scheme`](/slides/python-net/hi/aspose.slides.theme/overridetheme/color_scheme/) | रंग योजना लौटाता है।<br/>केवल पढ़ने योग्य [`IColorScheme`](/slides/python-net/hi/aspose.slides.theme/icolorscheme)। |
| [`font_scheme`](/slides/python-net/hi/aspose.slides.theme/overridetheme/font_scheme/) | फ़ॉन्ट योजना लौटाता है।<br/>केवल पढ़ने योग्य [`IFontScheme`](/slides/python-net/hi/aspose.slides.theme/ifontscheme)। |
| [`format_scheme`](/slides/python-net/hi/aspose.slides.theme/overridetheme/format_scheme/) | आकृति स्वरूप योजना लौटाता है।<br/>केवल पढ़ने योग्य [`IFormatScheme`](/slides/python-net/hi/aspose.slides.theme/iformatscheme)। |
| [`presentation`](/slides/python-net/hi/aspose.slides.theme/overridetheme/presentation/) | पैरेंट प्रस्तुति लौटाता है।<br/>केवल पढ़ने योग्य [`IPresentation`](/slides/python-net/hi/aspose.slides/ipresentation)। |
| [`is_empty`](/slides/python-net/hi/aspose.slides.theme/overridetheme/is_empty/) | सही मान का अर्थ है कि ColorScheme, FontScheme, FormatScheme None है और इस थीम ऑब्जेक्ट के साथ कोई भी ओवरराइडिंग अक्षम है।<br/>केवल पढ़ने योग्य **bool**। |
