## FontScheme क्लास

थीम-परिभाषित फ़ॉन्ट्स को संग्रहीत करता है।

FontScheme प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## प्रॉपर्टी

| Property | Description |
| :- | :- |
| [`minor`](/slides/python-net/hi/aspose.slides.theme/fontscheme/minor/) | स्लाइड के "body" भाग के लिए फ़ॉन्ट्स संग्रह लौटाता है।<br/>            केवल-रीड [`IFonts`](/slides/python-net/hi/aspose.slides/ifonts). |
| [`major`](/slides/python-net/hi/aspose.slides.theme/fontscheme/major/) | स्लाइड के "heading" भाग के लिए फ़ॉन्ट्स संग्रह लौटाता है।<br/>            केवल-रीड [`IFonts`](/slides/python-net/hi/aspose.slides/ifonts). |
| [`name`](/slides/python-net/hi/aspose.slides.theme/fontscheme/name/) | फ़ॉन्ट स्कीम का नाम लौटाता है।<br/>            पढ़ें/लिखें **str**. |
