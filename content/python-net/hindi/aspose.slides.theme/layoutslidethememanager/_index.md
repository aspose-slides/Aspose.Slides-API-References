## LayoutSlideThemeManager क्लास

लेआउट स्लाइड थीम को ओवरराइड करने का एक्सेस प्रदान करता है।

**विरासत:**[`LayoutSlideThemeManager`](/slides/python-net/hi/aspose.slides.theme/layoutslidethememanager) → [`BaseOverrideThemeManager`](/slides/python-net/hi/aspose.slides.theme/baseoverridethememanager) → [`BaseThemeManager`](/slides/python-net/hi/aspose.slides.theme/basethememanager)

LayoutSlideThemeManager टाइप निम्नलिखित सदस्य उजागर करता है:

## प्रॉपर्टी

| Property | Description |
| :- | :- |
| [`override_theme`](/slides/python-net/hi/aspose.slides.theme/layoutslidethememanager/override_theme/) | ओवरराइडिंग थीम ऑब्जेक्ट को रिटर्न करता है।<br/>            पढ़ें/लिखें [`IOverrideTheme`](/slides/python-net/hi/aspose.slides.theme/ioverridetheme). |
| [`is_override_theme_enabled`](/slides/python-net/hi/aspose.slides.theme/layoutslidethememanager/is_override_theme_enabled/) | निर्धारित करता है कि OverrideTheme विरासत में मिली प्रभावी थीम को ओवरराइड करता है या नहीं।<br/>            OverrideTheme को ओवरराइड करने के लिए सक्षम करने हेतु OverrideTheme.Init*() मेथड्स का उपयोग करें।<br/>            OverrideTheme को ओवरराइड करने से रोकने के लिए OverrideTheme.Clear() मेथड का उपयोग करें।<br/>            केवल-पढ़ने योग्य **bool**. |
