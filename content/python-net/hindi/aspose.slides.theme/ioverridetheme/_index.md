## IOverrideTheme क्लास

IOverrideTheme प्रकार निम्नलिखित सदस्यों को उजागर करता है:

| [`is_empty`](/slides/python-net/hi/aspose.slides.theme/ioverridetheme/is_empty/) | True मान का अर्थ है कि ColorScheme, FontScheme, FormatScheme None है और इस थीम ऑब्जेक्ट के साथ कोई भी ओवरराइडिंग अक्षम है.<br/>            केवल-पढ़ने योग्य **bool**. |
| [`color_scheme`](/slides/python-net/hi/aspose.slides.theme/ioverridetheme/color_scheme/) |  |
