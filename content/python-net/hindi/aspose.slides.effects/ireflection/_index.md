## IReflection क्लास

एक परावर्तन प्रभाव का प्रतिनिधित्व करता है।

IReflection प्रकार निम्न सदस्य प्रदर्शित करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/hi/aspose.slides.effects/ireflection/start_pos_alpha/) | प्रारंभिक अल्फा मान (प्रतिशत) के शुरुआती स्थिति (अल्फा ग्रेडिएंट रैंप के साथ) को निर्दिष्ट करता है।<br/>            पढ़ें/लिखें **float**. |
| [`end_pos_alpha`](/slides/python-net/hi/aspose.slides.effects/ireflection/end_pos_alpha/) | समाप्त अल्फा मान (प्रतिशत) के समाप्ति स्थिति (अल्फा ग्रेडिएंट रैंप के साथ) को निर्दिष्ट करता है।<br/>            पढ़ें/लिखें **float**. |
| [`fade_direction`](/slides/python-net/hi/aspose.slides.effects/ireflection/fade_direction/) | परावर्तन को ऑफ़सेट करने की दिशा (कोण) को निर्दिष्ट करता है।<br/>            पढ़ें/लिखें **float**. |
| [`start_reflection_opacity`](/slides/python-net/hi/aspose.slides.effects/ireflection/start_reflection_opacity/) | परावर्तन की प्रारंभिक अपारदर्शिता (प्रतिशत)।<br/>            पढ़ें/लिखें **float**. |
| [`end_reflection_opacity`](/slides/python-net/hi/aspose.slides.effects/ireflection/end_reflection_opacity/) | परावर्तन की समाप्ति अपारदर्शिता (प्रतिशत)।<br/>            पढ़ें/लिखें **float**. |
| [`blur_radius`](/slides/python-net/hi/aspose.slides.effects/ireflection/blur_radius/) | धुंधलापन त्रिज्या।<br/>            पढ़ें/लिखें **float**. |
| [`direction`](/slides/python-net/hi/aspose.slides.effects/ireflection/direction/) | परावर्तन की दिशा।<br/>            पढ़ें/लिखें **float**. |
| [`distance`](/slides/python-net/hi/aspose.slides.effects/ireflection/distance/) | परावर्तन की दूरी।<br/>            पढ़ें/लिखें **float**. |
| [`rectangle_align`](/slides/python-net/hi/aspose.slides.effects/ireflection/rectangle_align/) | आयत संरेखण।<br/>            पढ़ें/लिखें [`RectangleAlignment`](/slides/python-net/hi/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/hi/aspose.slides.effects/ireflection/skew_horizontal/) | क्षैतिज विकृति कोण को निर्दिष्ट करता है।<br/>            पढ़ें/लिखें **float**. |
| [`skew_vertical`](/slides/python-net/hi/aspose.slides.effects/ireflection/skew_vertical/) | ऊर्ध्वाधर विकृति कोण को निर्दिष्ट करता है।<br/>            पढ़ें/लिखें **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/hi/aspose.slides.effects/ireflection/rotate_shadow_with_shape/) | यदि आकार घुमाया गया है तो परावर्तन को आकार के साथ घुमाना चाहिए या नहीं, यह निर्दिष्ट करता है।<br/>            पढ़ें/लिखें **bool**. |
| [`scale_horizontal`](/slides/python-net/hi/aspose.slides.effects/ireflection/scale_horizontal/) | क्षैतिज स्केलिंग फ़ैक्टर को निर्दिष्ट करता है, नकारात्मक स्केलिंग उलट देता है। (प्रतिशत)<br/>            पढ़ें/लिखें **float**. |
| [`scale_vertical`](/slides/python-net/hi/aspose.slides.effects/ireflection/scale_vertical/) | ऊर्ध्वाधर स्केलिंग फ़ैक्टर को निर्दिष्ट करता है, नकारात्मक स्केलिंग उलट देता है। (प्रतिशत)<br/>            पढ़ें/लिखें **float**. |
