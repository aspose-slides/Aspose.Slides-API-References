## Reflection क्लास

एक Reflection इफ़ेक्ट का प्रतिनिधित्व करता है।

Reflection प्रकार निम्नलिखित सदस्य प्रदान करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/hi/aspose.slides.effects/reflection/start_pos_alpha/) | प्रारंभ अल्फा मान (प्रतिशत) की प्रारम्भ स्थिती (along the alpha gradient ramp) निर्दिष्ट करता है। पढ़ें/लिखें **float**. |
| [`end_pos_alpha`](/slides/python-net/hi/aspose.slides.effects/reflection/end_pos_alpha/) | समाप्त अल्फा मान (प्रतिशत) की अंत स्थिती (along the alpha gradient ramp) निर्दिष्ट करता है। पढ़ें/लिखें **float**. |
| [`fade_direction`](/slides/python-net/hi/aspose.slides.effects/reflection/fade_direction/) | Reflection को ऑफसेट करने की दिशा निर्दिष्ट करता है। (angle) पढ़ें/लिखें **float**. |
| [`start_reflection_opacity`](/slides/python-net/hi/aspose.slides.effects/reflection/start_reflection_opacity/) | Reflection की प्रारम्भिक अपारदर्शिता। (percents) पढ़ें/लिखें **float**. |
| [`end_reflection_opacity`](/slides/python-net/hi/aspose.slides.effects/reflection/end_reflection_opacity/) | Reflection की समाप्ति अपारदर्शिता। (percents) पढ़ें/लिखें **float**. |
| [`blur_radius`](/slides/python-net/hi/aspose.slides.effects/reflection/blur_radius/) | ब्लर त्रिज्या। पढ़ें/लिखें **float**. |
| [`direction`](/slides/python-net/hi/aspose.slides.effects/reflection/direction/) | Reflection की दिशा। पढ़ें/लिखें **float**. |
| [`distance`](/slides/python-net/hi/aspose.slides.effects/reflection/distance/) | Reflection की दूरी। पढ़ें/लिखें **float**. |
| [`rectangle_align`](/slides/python-net/hi/aspose.slides.effects/reflection/rectangle_align/) | आयत संरेखण। पढ़ें/लिखें [`RectangleAlignment`](/slides/python-net/hi/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/hi/aspose.slides.effects/reflection/skew_horizontal/) | क्षैतिज स्क्यू कोण निर्दिष्ट करता है। पढ़ें/लिखें **float**. |
| [`skew_vertical`](/slides/python-net/hi/aspose.slides.effects/reflection/skew_vertical/) | लंबवत स्क्यू कोण निर्दिष्ट करता है। पढ़ें/लिखें **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/hi/aspose.slides.effects/reflection/rotate_shadow_with_shape/) | यदि आकार घुमाया गया है तो reflection को आकार के साथ घुमाना चाहिए या नहीं निर्दिष्ट करता है। पढ़ें/लिखें **bool**. |
| [`scale_horizontal`](/slides/python-net/hi/aspose.slides.effects/reflection/scale_horizontal/) | क्षैतिज स्केलिंग गुणांक निर्दिष्ट करता है, नकारात्मक स्केलिंग से फ़्लिप होता है। (percents) पढ़ें/लिखें **float**. |
| [`scale_vertical`](/slides/python-net/hi/aspose.slides.effects/reflection/scale_vertical/) | लंबवत स्केलिंग गुणांक निर्दिष्ट करता है, नकारात्मक स्केलिंग से फ़्लिप होता है। (percents) पढ़ें/लिखें **float**. |
