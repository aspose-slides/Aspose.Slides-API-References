PowerPoint प्रस्तुतियों का विश्लेषण और प्रसंस्करण करने के लिए AI-आधारित सुविधाएँ प्रदान करने वाली क्लासेस शामिल हैं।

## क्लासेस

| क्लास | विवरण |
| :- | :- |
| [`AsposeAIWebClient`](/slides/python-net/hi/aspose.slides.ai/asposeaiwebclient/) | Aspose के अपने LLM से जुड़ने वाला एक अंतर्निर्मित [`IAIWebClient`](/slides/python-net/hi/aspose.slides.ai/iaiwebclient) कार्यान्वयन।<br/>            यह डिफ़ॉल्ट क्लाइंट है जिसे पैरामीटर-रहित **SlidesAIAgent.#ctor** कन्स्ट्रक्टर द्वारा उपयोग किया जाता है। |
| [`IAIConversation`](/slides/python-net/hi/aspose.slides.ai/iaiconversation/) | एक वार्तालाप इंस्टेंस का प्रतिनिधित्व करता है। सामान्य AI कॉल्स के विपरीत, वार्तालाप पूरे संदर्भ को बनाए रखता है। |
| [`IAIWebClient`](/slides/python-net/hi/aspose.slides.ai/iaiwebclient/) | AI वेब क्लाइंट इंटरफ़ेस। यह इंटरफ़ेस विभिन्न AI भाषा मॉडलों को बदलने में सक्षम बनाता है।<br/>            इस इंटरफ़ेस को लागू करने वाली क्लासेस को `SlidesAIAgent` के साथ उपयोग किया जाना चाहिए। |
| [`OpenAICompatibleWebClient`](/slides/python-net/hi/aspose.slides.ai/openaicompatiblewebclient/) | एक अंतर्निर्मित [`IAIWebClient`](/slides/python-net/hi/aspose.slides.ai/iaiwebclient) कार्यान्वयन जो OpenAI-अनुकूल LLM प्रदाता से जुड़ता है<br/>            निर्दिष्ट बेस URL पर। |
| [`OpenAIWebClient`](/slides/python-net/hi/aspose.slides.ai/openaiwebclient/) | एक अंतर्निर्मित [`IAIWebClient`](/slides/python-net/hi/aspose.slides.ai/iaiwebclient) कार्यान्वयन जो OpenAI API से जुड़ता है। |
| [`SlidesAIAgent`](/slides/python-net/hi/aspose.slides.ai/slidesaiagent/) | प्रस्तुतियों के प्रसंस्करण के लिए AI-संचालित सुविधाएँ प्रदान करता है। |
| [`SlidesAIAgentException`](/slides/python-net/hi/aspose.slides.ai/slidesaiagentexception/) | Slides AI Agent से संबंधित अपवादों का प्रतिनिधित्व करता है। |
