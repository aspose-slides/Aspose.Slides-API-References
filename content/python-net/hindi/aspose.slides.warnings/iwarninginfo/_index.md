## IWarningInfo वर्ग

सभी चेतावनियों के लिए एक बुनियादी इंटरफ़ेस का प्रतिनिधित्व करता है।

IWarningInfo प्रकार निम्न सदस्य उजागर करता है:

## गुण

| Property | Description |
| :- | :- |
| [`warning_type`](/slides/python-net/hi/aspose.slides.warnings/iwarninginfo/warning_type/) | चेतावनी का प्रकार लौटाता है।<br/>            केवल-पढ़ने योग्य [`IWarningInfo.warning_type`](/slides/python-net/hi/aspose.slides.warnings/iwarninginfo/warning_type). |
| [`description`](/slides/python-net/hi/aspose.slides.warnings/iwarninginfo/description/) | इस चेतावनी का मानव-पठनीय विवरण लौटाता है।<br/>            केवल-पढ़ने योग्य **str**. |

## विधियाँ

| Method | Description |
| :- | :- |
| [`send_warning(self, receiver)`](/slides/python-net/hi/aspose.slides.warnings/iwarninginfo/send_warning/#iwarningcallback) | यदि receiver None नहीं है तो निर्दिष्ट receiver को चेतावनी समाप्त करता है और <br/>            AbortRequestedException को throw करता है यदि receiver ने संचालन को रोकने का निर्णय लिया. |
