## WarningType एन्उमरेशन

Represents a type of warning.

The WarningType type exposes the following members:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| SOURCE_FILE_CORRUPTION | स्रोत दस्तावेज़ में एक समस्या का पता चला है जिससे यह बहुत संभावित है कि यदि इसे मूल स्वरूप में सहेजा जाए तो दस्तावेज़ खोल नहीं पाएगा। |
| DATA_LOSS | पाठ/चार्ट/छवि या अन्य डेटा लोड के बाद दस्तावेज़ वृक्ष से या सहेजने के बाद निर्मित दस्तावेज़ से पूरी तरह गायब हो जाएगा। |
| MAJOR_FORMATTING_LOSS | मुख्य स्वरूपण हानि। |
| MINOR_FORMATTING_LOSS | सामान्य स्वरूपण हानि। |
| COMPATIBILITY_ISSUE | यह ज्ञात समस्या है जो कुछ उपयोगकर्ता एजेंटों या उपयोगकर्ता एजेंटों के पिछले संस्करणों द्वारा दस्तावेज़ खोलने से रोकेगी। |
| UNEXPECTED_CONTENT | स्रोत दस्तावेज़ में कुछ सामग्री को पहचाना नहीं जा सका (अर्थात असमर्थित है), यह समस्याएं पैदा कर सकता है या नहीं भी, और डेटा/स्वरूपण हानि का परिणाम हो सकता है। |
