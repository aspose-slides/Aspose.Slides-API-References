## TickMarkType एन्यूमरेशन

निर्दिष्ट अक्ष के लिए टिक मार्क प्रकार को दर्शाता है।

TickMarkType प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| CROSS | निर्दिष्ट करता है कि टिक मार्क अक्ष को पार करेंगे। |
| INSIDE | निर्दिष्ट करता है कि टिक मार्क प्लॉट क्षेत्र के भीतर होंगे। |
| NONE | निर्दिष्ट करता है कि कोई टिक मार्क नहीं होगा। |
| OUTSIDE | निर्दिष्ट करता है कि टिक मार्क प्लॉट क्षेत्र के बाहर होंगे। |
