## IChartTextBlockFormat क्लास

चार्ट टेक्स्ट तत्वों के लिए फ़ॉर्मेटिंग प्रॉपर्टीज़ का प्रतिनिधित्व करता है।

IChartTextBlockFormat प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## Properties

| Property | Description |
| :- | :- |
| [`anchoring_type`](/slides/python-net/hi/aspose.slides.charts/icharttextblockformat/anchoring_type/) | TextFrame में वर्टिकल एंकर टेक्स्ट को लौटाता है या सेट करता है।<br/>            पढ़ें/लिखें [`TextAnchorType`](/slides/python-net/hi/aspose.slides/textanchortype). |
| [`center_text`](/slides/python-net/hi/aspose.slides.charts/icharttextblockformat/center_text/) | यदि NullableBool.True है तो टेक्स्ट को बॉक्स में क्षैतिज रूप से केंद्रित होना चाहिए।<br/>            पढ़ें/लिखें [`NullableBool`](/slides/python-net/hi/aspose.slides/nullablebool). |
| [`text_vertical_type`](/slides/python-net/hi/aspose.slides.charts/icharttextblockformat/text_vertical_type/) | टेक्स्ट अभिविन्यास निर्धारित करता है।<br/>            विजुअल टेक्स्ट रोटेशन का परिणामस्वरूप मान इस प्रॉपर्टी और कस्टम एंगल <br/>            प्रॉपर्टी RotationAngle से संक्षिप्त किया गया है।<br/>            पढ़ें/लिखें [`TextVerticalType`](/slides/python-net/hi/aspose.slides/textverticaltype). |
| [`margin_left`](/slides/python-net/hi/aspose.slides.charts/icharttextblockformat/margin_left/) | TextFrame में बाएँ मार्जिन (points) को लौटाता है या सेट करता है।<br/>            इस प्रॉपर्टी को बदलने से केवल इन चार्ट भागों पर कुछ प्रभाव पड़ सकता है: <br/>            DataLabel और DataLabelFormat (PowerPoint 2013 में पूर्ण समर्थन; PowerPoint 2007 में रेंडरिंग पर कोई प्रभाव नहीं)।<br/>            पढ़ें/लिखें **float**. |
| [`margin_right`](/slides/python-net/hi/aspose.slides.charts/icharttextblockformat/margin_right/) | TextFrame में दाएँ मार्जिन (points) को लौटाता है या सेट करता है।<br/>            इस प्रॉपर्टी को बदलने से केवल इन चार्ट भागों पर कुछ प्रभाव पड़ सकता है: <br/>            DataLabel और DataLabelFormat (PowerPoint 2013 में पूर्ण समर्थन; PowerPoint 2007 में रेंडरिंग पर कोई प्रभाव नहीं)।<br/>            पढ़ें/लिखें **float**. |
| [`margin_top`](/slides/python-net/hi/aspose.slides.charts/icharttextblockformat/margin_top/) | TextFrame में शीर्ष मार्जिन (points) को लौटाता है या सेट करता है।<br/>            इस प्रॉपर्टी को बदलने से केवल इन चार्ट भागों पर कुछ प्रभाव पड़ सकता है: <br/>            DataLabel और DataLabelFormat (PowerPoint 2013 में पूर्ण समर्थन; PowerPoint 2007 में रेंडरिंग पर कोई प्रभाव नहीं)।<br/>            पढ़ें/लिखें **float**. |
| [`margin_bottom`](/slides/python-net/hi/aspose.slides.charts/icharttextblockformat/margin_bottom/) | TextFrame में निचला मार्जिन (points) को लौटाता है या सेट करता है।<br/>            इस प्रॉपर्टी को बदलने से केवल इन चार्ट भागों पर कुछ प्रभाव पड़ सकता है: <br/>            DataLabel और DataLabelFormat (PowerPoint 2013 में पूर्ण समर्थन; PowerPoint 2007 में रेंडरिंग पर कोई प्रभाव नहीं)।<br/>            पढ़ें/लिखें **float**. |
| [`wrap_text`](/slides/python-net/hi/aspose.slides.charts/icharttextblockformat/wrap_text/) | **True** यदि टेक्स्ट TextFrame के मार्जिन पर रैप किया गया है।<br/>            इस प्रॉपर्टी को बदलने से केवल इन चार्ट भागों पर कुछ प्रभाव पड़ सकता है: <br/>            DataLabel और DataLabelFormat (PowerPoint 2007/2013 में पूर्ण समर्थन)।<br/>            पढ़ें/लिखें [`NullableBool`](/slides/python-net/hi/aspose.slides/nullablebool). |
| [`autofit_type`](/slides/python-net/hi/aspose.slides.charts/icharttextblockformat/autofit_type/) | टेक्स्ट के ऑटोफ़िट मोड को लौटाता है या सेट करता है।<br/>            इस प्रॉपर्टी को बदलने से केवल इन चार्ट भागों पर कुछ प्रभाव पड़ सकता है: <br/>            DataLabel और DataLabelFormat (PowerPoint 2013 में पूर्ण समर्थन; PowerPoint 2007 में रेंडरिंग पर कोई प्रभाव नहीं)।<br/>            पढ़ें/लिखें [`TextAutofitType`](/slides/python-net/hi/aspose.slides/textautofittype). |
| [`rotation_angle`](/slides/python-net/hi/aspose.slides.charts/icharttextblockformat/rotation_angle/) | बाउंडिंग बॉक्स में टेक्स्ट पर लागू किए जाने वाले कस्टम रोटेशन को निर्दिष्ट करता है। यदि यह निर्दिष्ट नहीं है, तो साथ वाले आकार का रोटेशन उपयोग किया जाता है। यदि यह निर्दिष्ट है, तो यह आकार से स्वतंत्र रूप से लागू होता है। अर्थात आकार में अतिरिक्त रोटेशन लागू हो सकता है जबकि टेक्स्ट को स्वयं का रोटेशन लागू किया गया है।<br/>            विजुअल टेक्स्ट रोटेशन का परिणामस्वरूप मान इस प्रॉपर्टी और पूर्वनिर्धारित वर्टिकल टाइप प्रॉपर्टी TextVerticalType से संक्षिप्त किया गया है।<br/>            पढ़ें/लिखें **float**. |
