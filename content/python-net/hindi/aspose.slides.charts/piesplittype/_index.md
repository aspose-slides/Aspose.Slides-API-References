## PieSplitType एन्यूमरेशन

डेटा बिंदुओं के विभाजन बिंदुओं के प्रकार का प्रतिनिधित्व करता है, जो पाई-ऑफ़-पाई या बार-ऑफ़-पाई चार्ट में दूसरे पाई या बार पर लागू होते हैं।

PieSplitType प्रकार निम्नलिखित सदस्यों को प्रकट करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| DEFAULT | निर्दिष्ट करता है कि डेटा बिंदुओं को इस चार्ट प्रकार के डिफ़ॉल्ट <br/>            तंत्र का उपयोग करके विभाजित किया जाएगा। |
| CUSTOM | निर्दिष्ट करता है कि डेटा बिंदुओं को कस्टम स्प्लिट मानों के अनुसार <br/>            पाई और दूसरे चार्ट के बीच विभाजित किया जाएगा। |
| BY_PERCENTAGE | निर्दिष्ट करता है कि डेटा बिंदुओं को पाई और दूसरे चार्ट के बीच विभाजित किया जाएगा, <br/>            इस प्रकार कि प्रतिशत <br/>            Split Position प्रतिशत से कम वाले बिंदुओं को दूसरे चार्ट में रखा जाएगा। |
| BY_POS | निर्दिष्ट करता है कि डेटा बिंदुओं को पाई और दूसरे चार्ट के बीच विभाजित किया जाएगा, <br/>            डेटा बिंदुओं की अंतिम Split Position को दूसरे चार्ट में रखकर। |
| BY_VALUE | निर्दिष्ट करता है कि डेटा बिंदुओं को पाई और दूसरे चार्ट के बीच विभाजित किया जाएगा, <br/>            डेटा बिंदुओं को उन मानों के साथ रखकर जिनका मान Split Position से कम है। |
