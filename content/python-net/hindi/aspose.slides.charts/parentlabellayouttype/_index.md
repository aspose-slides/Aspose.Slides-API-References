## ParentLabelLayoutType एनीमरेशन

श्रेणी डेटा लेबल्स का लेआउट दर्शाता है। केवल Treemap श्रृंखला के साथ ही उपयोग किया जाता है।

ParentLabelLayoutType प्रकार निम्न सदस्यों को उजागर करता है:

## फ़ील्ड

| फ़ील्ड | विवरण |
| :- | :- |
| BANNER | निर्दिष्ट करता है कि पैरेंट कैटेगरी लेबल्स को बैनर के रूप में दिखाया जाता है |
| NONE | निर्दिष्ट करता है कि पैरेंट कैटेगरी लेबल्स नहीं दिखाए जाते |
| OVERLAPPING | निर्दिष्ट करता है कि पैरेंट कैटेगरी लेबल्स को ओवरलैपिंग के रूप में दिखाया जाता है |
