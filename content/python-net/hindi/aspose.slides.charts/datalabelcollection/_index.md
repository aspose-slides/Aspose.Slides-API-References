## DataLabelCollection क्लास

एक श्रृंखला के लेबल का प्रतिनिधित्व करता है।

DataLabelCollection प्रकार निम्न सदस्य उजागर करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`chart`](/slides/python-net/hi/aspose.slides.charts/datalabelcollection/chart/) | पैरेंट चार्ट लौटाता है।<br/>            केवल पढ़ने योग्य [`IChart`](/slides/python-net/hi/aspose.slides.charts/ichart). |
| [`is_visible`](/slides/python-net/hi/aspose.slides.charts/datalabelcollection/is_visible/) | False का अर्थ है कि डेटा लेबल डिफ़ॉल्ट रूप से दृश्य नहीं है (और इसलिए DefaultDataLabelFormat प्रॉपर्टी के सभी Show*-flags (ShowValue, ...) गलत हैं)।<br/>            केवल पढ़ने योग्य **bool**. |
| [`count_of_visible_data_labels`](/slides/python-net/hi/aspose.slides.charts/datalabelcollection/count_of_visible_data_labels/) | संग्रह में दृश्यमान डेटा लेबल की संख्या प्राप्त करता है।<br/>            केवल पढ़ने योग्य **int**. |
| [`count`](/slides/python-net/hi/aspose.slides.charts/datalabelcollection/count/) | संग्रह में सभी डेटा लेबल की संख्या प्राप्त करता है।<br/>            केवल पढ़ने योग्य **int**. |
| [`default_data_label_format`](/slides/python-net/hi/aspose.slides.charts/datalabelcollection/default_data_label_format/) | डिफ़ॉल्ट डेटा लेबल फ़ॉर्मेट प्राप्त करता है।<br/>            केवल पढ़ने योग्य [`IDataLabelFormat`](/slides/python-net/hi/aspose.slides.charts/idatalabelformat). |
| [`leader_lines_format`](/slides/python-net/hi/aspose.slides.charts/datalabelcollection/leader_lines_format/) | डेटा लेबल लीडर लाइन्स फ़ॉर्मेट का प्रतिनिधित्व करता है।<br/>             केवल पढ़ने योग्य [`IChartLinesFormat`](/slides/python-net/hi/aspose.slides.charts/ichartlinesformat). |
| [`parent_series`](/slides/python-net/hi/aspose.slides.charts/datalabelcollection/parent_series/) | पैरेंट श्रृंखला प्राप्त करता है।<br/>            केवल पढ़ने योग्य [`IChartSeries`](/slides/python-net/hi/aspose.slides.charts/ichartseries). |
| [`slide`](/slides/python-net/hi/aspose.slides.charts/datalabelcollection/slide/) |  |
| [`presentation`](/slides/python-net/hi/aspose.slides.charts/datalabelcollection/presentation/) |  |

निर्दिष्ट इंडेक्स वाले डेटा पॉइंट के लिए डेटा लेबल प्राप्त करता है।
