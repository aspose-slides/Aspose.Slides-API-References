## AxisAggregationType एन्यूमरेशन

श्रेणी अक्ष का एग्रीगेशन प्रकार दर्शाता है। केवल Histogram या HistogramPareto सीरीज़ के साथ उपयोग किया जाता है।

AxisAggregationType प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## फ़ील्ड
| फ़ील्ड | विवरण |
| :- | :- |
| BY_CATEGORY | श्रेणियों द्वारा समेकित करें |
| AUTOMATIC | श्रेणियों को स्वतः समेकित करें। |
| BY_BIN_WIDTH | बिन चौड़ाई के द्वारा श्रेणियों को समेकित करें। IAxis.BinWidth प्रॉपर्टी को सेट किया जाना चाहिए। |
| BY_NUMBER_OF_BINS | बिन की संख्या के द्वारा श्रेणियों को समेकित करें। IAxis.NumberOfBins प्रॉपर्टी को सेट किया जाना चाहिए। |
