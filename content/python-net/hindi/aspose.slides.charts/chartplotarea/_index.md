## ChartPlotArea क्लास

वह आयत प्रस्तुत करता है जहाँ चार्ट प्लॉट किया जाना चाहिए।

ChartPlotArea प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुणधर्म

| Property | Description |
| :- | :- |
| [`format`](/slides/python-net/hi/aspose.slides.charts/chartplotarea/format/) | प्लॉट क्षेत्र का स्वरूप लौटाता है।<br/>            केवल-पढ़ने-योग्य [`IFormat`](/slides/python-net/hi/aspose.slides.charts/iformat). |
| [`x`](/slides/python-net/hi/aspose.slides.charts/chartplotarea/x/) | प्लॉट क्षेत्र बाउंडिंग बॉक्स के ऊपरी बाएँ कोने के x निर्देशांक को चार्ट की चौड़ाई के अनुपात (0 से 1) के रूप में लौटाता है या सेट करता है।<br/>            पढ़ें/लिखें **float**. |
| [`y`](/slides/python-net/hi/aspose.slides.charts/chartplotarea/y/) | प्लॉट क्षेत्र बाउंडिंग बॉक्स के ऊपरी बाएँ कोने के y निर्देशांक को चार्ट की ऊँचाई के अनुपात (0 से 1) के रूप में लौटाता है या सेट करता है।<br/>            पढ़ें/लिखें **float**. |
| [`width`](/slides/python-net/hi/aspose.slides.charts/chartplotarea/width/) | प्लॉट क्षेत्र बाउंडिंग बॉक्स की चौड़ाई को चार्ट की चौड़ाई के अनुपात (0 से 1) के रूप में लौटाता है या सेट करता है।<br/>            पढ़ें/लिखें **float**. |
| [`height`](/slides/python-net/hi/aspose.slides.charts/chartplotarea/height/) | प्लॉट क्षेत्र बाउंडिंग बॉक्स की ऊँचाई को चार्ट की ऊँचाई के अनुपात (0 से 1) के रूप में लौटाता है या सेट करता है।<br/>            पढ़ें/लिखें **float**. |
| [`right`](/slides/python-net/hi/aspose.slides.charts/chartplotarea/right/) | दायाँ।<br/>            केवल-पढ़ने-योग्य **float**. |
| [`bottom`](/slides/python-net/hi/aspose.slides.charts/chartplotarea/bottom/) | नीचे।<br/>            केवल-पढ़ने-योग्य **float**. |
| [`chart`](/slides/python-net/hi/aspose.slides.charts/chartplotarea/chart/) | चार्ट।<br/>            केवल-पढ़ने-योग्य [`IChart`](/slides/python-net/hi/aspose.slides.charts/ichart). |
| [`is_location_autocalculated`](/slides/python-net/hi/aspose.slides.charts/chartplotarea/is_location_autocalculated/) | यह निर्धारित करता है कि स्थान की गणना कैसे की जानी चाहिए: true – स्वचालित रूप से गणना किया गया; X, Y, Width, Height गुणों द्वारा परिभाषित।<br/>            केवल-पढ़ने-योग्य **bool**. |
| [`layout_target_type`](/slides/python-net/hi/aspose.slides.charts/chartplotarea/layout_target_type/) | यदि प्लॉट क्षेत्र की लेआउट मैन्युअल रूप से परिभाषित है तो यह गुण यह निर्दिष्ट करता है कि <br/>             प्लॉट क्षेत्र को उसके अंदर (अक्ष और अक्ष लेबल को छोड़कर) या बाहर (अक्ष और अक्ष लेबल सहित) लेआउट किया जाए।<br/>             पढ़ें/लिखें [`ChartPlotArea.layout_target_type`](/slides/python-net/hi/aspose.slides.charts/chartplotarea/layout_target_type). |
| [`actual_x`](/slides/python-net/hi/aspose.slides.charts/chartplotarea/actual_x/) | चार्ट तत्व का वास्तविक x स्थान (बाएँ) जो चार्ट के ऊपरी बाएँ कोने के सापेक्ष है, निर्दिष्ट करता है।<br/>            वास्तविक मान प्राप्त करने के लिए IChart.ValidateChartLayout() विधि को पहले कॉल करें। <br/>            केवल-पढ़ने-योग्य **float**. |
| [`actual_y`](/slides/python-net/hi/aspose.slides.charts/chartplotarea/actual_y/) | चार्ट तत्व का वास्तविक शीर्ष जो चार्ट के ऊपरी बाएँ कोने के सापेक्ष है, निर्दिष्ट करता है।<br/>            वास्तविक मान प्राप्त करने के लिए IChart.ValidateChartLayout() विधि को पहले कॉल करें। <br/>            केवल-पढ़ने-योग्य **float**. |
| [`actual_width`](/slides/python-net/hi/aspose.slides.charts/chartplotarea/actual_width/) | चार्ट तत्व की वास्तविक चौड़ाई निर्दिष्ट करता है। IChart.ValidateChartLayout() विधि को पहले कॉल करें। <br/>            केवल-पढ़ने-योग्य **float**. |
| [`actual_height`](/slides/python-net/hi/aspose.slides.charts/chartplotarea/actual_height/) | चार्ट तत्व की वास्तविक ऊँचाई निर्दिष्ट करता है। IChart.ValidateChartLayout() विधि को पहले कॉल करें। <br/>            केवल-पढ़ने-योग्य **float**. |
