## hide(self) {#}
डिफ़ॉल्ट रूप से डेटा लेबल को छिपा हुआ बनाने के लिए सभी Show*-flags (ShowValue, ...) को DefaultDataLabelFormat प्रॉपर्टी के तहत false स्थिति में सेट करें।
IsVisible false रहेगा।


```python
def hide(self):
    ...
```


### टिप्पणियाँ

यदि डेटा लेबल डिफ़ॉल्ट रूप से दिखाई नहीं देता है (IsVisible false है) तो आप Show*-flags (ShowValue, ...) को DefaultDataLabelFormat प्रॉपर्टी के तहत true स्थिति में सेट करके डेटा लेबल को "डिफ़ॉल्ट रूप से दिखाई देने योग्य" बना सकते हैं।
