## IDataLabelCollection वर्ग

एक श्रृंखला लेबल का प्रतिनिधित्व करता है।

IDataLabelCollection प्रकार निम्नलिखित सदस्य उजागर करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`default_data_label_format`](/slides/python-net/hi/aspose.slides.charts/idatalabelcollection/default_data_label_format/) | संग्रह में सभी डेटा लेबल्स का डिफ़ॉल्ट स्वरूप लौटाता है।<br/>            केवल-पढ़ने योग्य [`IDataLabelFormat`](/slides/python-net/hi/aspose.slides.charts/idatalabelformat). |
| [`leader_lines_format`](/slides/python-net/hi/aspose.slides.charts/idatalabelcollection/leader_lines_format/) | डेटा लेबल्स लीडर लाइनों का स्वरूप दर्शाता है।<br/>            केवल-पढ़ने योग्य [`IChartLinesFormat`](/slides/python-net/hi/aspose.slides.charts/ichartlinesformat). |
| [`is_visible`](/slides/python-net/hi/aspose.slides.charts/idatalabelcollection/is_visible/) | False का अर्थ है कि डेटा लेबल डिफ़ॉल्ट रूप से दृश्यमान नहीं है (और इसलिए सभी Show*-फ़्लैग (ShowValue, ...) DefaultDataLabelFormat गुण के गलत होते हैं)।<br/>            केवल-pढ़ने योग्य **bool**. |
| [`count_of_visible_data_labels`](/slides/python-net/hi/aspose.slides.charts/idatalabelcollection/count_of_visible_data_labels/) | संग्रह में दृश्यमान डेटा लेबल्स की संख्या प्राप्त करता है।<br/>            केवल-pढ़ने योग्य **int**. |
| [`count`](/slides/python-net/hi/aspose.slides.charts/idatalabelcollection/count/) | संग्रह में सभी डेटा लेबल्स की संख्या प्राप्त करता है।<br/>            केवल-pढ़ने योग्य **int**. |
| [`parent_series`](/slides/python-net/hi/aspose.slides.charts/idatalabelcollection/parent_series/) | पैरेंट चार्ट सीरीज़ लौटाता है।<br/>            केवल-pढ़ने योग्य [`IChartSeries`](/slides/python-net/hi/aspose.slides.charts/ichartseries). |
| [`chart`](/slides/python-net/hi/aspose.slides.charts/idatalabelcollection/chart/) |  |
| [`slide`](/slides/python-net/hi/aspose.slides.charts/idatalabelcollection/slide/) |  |
| [`presentation`](/slides/python-net/hi/aspose.slides.charts/idatalabelcollection/presentation/) |  |
