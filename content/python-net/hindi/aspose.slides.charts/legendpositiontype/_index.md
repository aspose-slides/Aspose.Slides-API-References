## LegendPositionType एन्यूमरेशन

एक चार्ट पर लेजेंड की स्थिति निर्धारित करता है।

LegendPositionType प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| BOTTOM | निर्दिष्ट करता है कि लेजेंड चार्ट के नीचे बनाया जाएगा। |
| LEFT | निर्दिष्ट करता है कि लेजेंड चार्ट के बाएँ बनाए जाएगा। |
| RIGHT | निर्दिष्ट करता है कि लेजेंड चार्ट के दाएँ बनाए जाएगा। |
| TOP | निर्दिष्ट करता है कि लेजेंड चार्ट के ऊपर बनाया जाएगा। |
| TOP_RIGHT | निर्दिष्ट करता है कि लेजेंड चार्ट के ऊपर दाएँ बनाया जाएगा। |
