## IChartDataCell क्लास

Represents cell for chart data.

The IChartDataCell type exposes the following members:

| [`column`](/slides/python-net/hi/aspose.slides.charts/ichartdatacell/column/) | सेल जिस कार्यपत्र में स्थित है, उसकी स्तंभ का सूचकांक लौटाता है.<br/>            केवल-पढ़ने योग्य **int**. |

| [`preset_number_format`](/slides/python-net/hi/aspose.slides.charts/ichartdatacell/preset_number_format/) | संख्याओं और तिथियों के लिए निर्मित प्रदर्शन प्रारूप प्राप्त करता है या सेट करता है. Preset number को [0..22] या [37..49] में होना चाहिए.<br/>            पढ़ें/लिखें **int**. |
