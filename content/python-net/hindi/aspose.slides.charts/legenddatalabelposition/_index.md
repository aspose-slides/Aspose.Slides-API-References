## LegendDataLabelPosition enumeration

डेटा लेबल की स्थिति निर्धारित करता है।

LegendDataLabelPosition प्रकार निम्नलिखित सदस्यों को प्रस्तुत करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| NOT_DEFINED | स्थिति निर्धारित नहीं है। |
| BOTTOM | यह निर्दिष्ट करता है कि डेटा लेबल डेटा मार्कर के नीचे प्रदर्शित किए जाएंगे। |
| BEST_FIT | यह निर्दिष्ट करता है कि डेटा लेबल सर्वोत्तम स्थिति में प्रदर्शित किए जाएंगे। |
| CENTER | यह निर्दिष्ट करता है कि डेटा लेबल डेटा मार्कर के केंद्र में प्रदर्शित किए जाएंगे। |
| INSIDE_BASE | यह निर्दिष्ट करता है कि डेटा लेबल डेटा मार्कर के बेस के अंदर प्रदर्शित किए जाएंगे। |
| INSIDE_END | यह निर्दिष्ट करता है कि डेटा लेबल डेटा मार्कर के अंत में अंदर प्रदर्शित किए जाएंगे। |
| LEFT | यह निर्दिष्ट करता है कि डेटा लेबल डेटा मार्कर के बाएँ तरफ प्रदर्शित किए जाएंगे। |
| OUTSIDE_END | यह निर्दिष्ट करता है कि डेटा लेबल डेटा मार्कर के अंत के बाहर प्रदर्शित किए जाएंगे। |
| RIGHT | यह निर्दिष्ट करता है कि डेटा लेबल डेटा मार्कर के दाएँ तरफ प्रदर्शित किए जाएंगे। |
| TOP | यह निर्दिष्ट करता है कि डेटा लेबल डेटा मार्कर के ऊपर प्रदर्शित किए जाएंगे। |
