## ChartCategory क्लास

चार्ट वर्गों का प्रतिनिधित्व करता है।

ChartCategory प्रकार निम्न सदस्य प्रकट करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`use_cell`](/slides/python-net/hi/aspose.slides.charts/chartcategory/use_cell/) | यदि true हो तो AsCell प्रॉपर्टी वास्तविक है। दूसरे शब्दों में, वर्कशीट का उपयोग वर्ग को संग्रहीत करने के लिए किया जाता है <br/>            (यह केस मल्टी-लेवल वर्ग का समर्थन करता है)।<br/>            यदि false हो तो AsLiteral प्रॉपर्टी वास्तविक है। दूसरे शब्दों में, वर्कशीट का उपयोग वर्ग संग्रहीत करने के लिए नहीं किया जाता <br/>            (और यह केस मल्टी-लेवल वर्गों को समर्थन नहीं करता)।<br/>            केवल-पढ़ने योग्य **bool**. |
| [`as_cell`](/slides/python-net/hi/aspose.slides.charts/chartcategory/as_cell/) | IChartDataCell ऑब्जेक्ट को लौटाता या सेट करता है।<br/>            यदि वर्ग बहु-स्तरीय है तो स्तर "0" के लिए IChartDataCell ऑब्जेक्ट उपयोग किया जाता है।<br/>            पढ़ने/लिखने योग्य [`IChartDataCell`](/slides/python-net/hi/aspose.slides.charts/ichartdatacell). |
| [`as_literal`](/slides/python-net/hi/aspose.slides.charts/chartcategory/as_literal/) | AsLiteral ऑब्जेक्ट को लौटाता या सेट करता है।<br/>            पढ़ने/लिखने योग्य **any**. |
| [`value`](/slides/python-net/hi/aspose.slides.charts/chartcategory/value/) | यदि UseCell true है तो यह प्रॉपर्टी AsCell.Value प्रॉपर्टी को दर्शाती है।<br/>            यदि UseCell false है तो यह प्रॉपर्टी AsLiteral प्रॉपर्टी को दर्शाती है।<br/>            पढ़ने/लिखने योग्य **any**. |
| [`grouping_levels`](/slides/python-net/hi/aspose.slides.charts/chartcategory/grouping_levels/) | चार्ट वर्ग समूह स्तरों के मानों का प्रबंधित कंटेनर।<br/>            मल्टी-लेवल वर्ग में एक से अधिक समूह स्तर होते हैं।<br/>            समूह स्तरों की अनुक्रमण शून्य-आधारित है।<br/>            केवल-पढ़ने योग्य [`IChartCategoryLevelsManager`](/slides/python-net/hi/aspose.slides.charts/ichartcategorylevelsmanager). |
