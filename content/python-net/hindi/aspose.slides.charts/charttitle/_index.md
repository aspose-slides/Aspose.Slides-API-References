## ChartTitle क्लास

चार्ट शीर्षक गुणों का प्रतिनिधित्व करता है।

ChartTitle प्रकार निम्न सदस्यों को उजागर करता है:

## गुण

| प्रॉपर्टी | विवरण |
| :- | :- |
| [`x`](/slides/python-net/hi/aspose.slides.charts/charttitle/x/) | शीर्षक के x निर्देशांक को चार्ट की चौड़ाई के भाग के रूप में लौटाता है या सेट करता है।<br/>            पढ़ें/लिखें **float**. |
| [`y`](/slides/python-net/hi/aspose.slides.charts/charttitle/y/) | शीर्षक के y निर्देशांक को चार्ट की ऊँचाई के भाग के रूप में लौटाता है या सेट करता है।<br/>            पढ़ें/लिखें **float**. |
| [`width`](/slides/python-net/hi/aspose.slides.charts/charttitle/width/) | शीर्षक की चौड़ाई को चार्ट की चौड़ाई के भाग के रूप में लौटाता है या सेट करता है।<br/>            पढ़ें/लिखें **float**. |
| [`height`](/slides/python-net/hi/aspose.slides.charts/charttitle/height/) | शीर्षक की ऊँचाई को चार्ट की ऊँचाई के भाग के रूप में लौटाता है या सेट करता है।<br/>            पढ़ें/लिखें **float**. |
| [`right`](/slides/python-net/hi/aspose.slides.charts/charttitle/right/) | दाएँ।<br/>            केवल पढ़ने योग्य **float**. |
| [`bottom`](/slides/python-net/hi/aspose.slides.charts/charttitle/bottom/) | नीचे।<br/>            केवल पढ़ने योग्य **float**. |
| [`overlay`](/slides/python-net/hi/aspose.slides.charts/charttitle/overlay/) | निर्धारित करता है कि क्या अन्य चार्ट तत्वों को शीर्षक के ऊपर ओवरलैप करने की अनुमति है।<br/>            पढ़ें/लिखें **bool**. |
| [`format`](/slides/python-net/hi/aspose.slides.charts/charttitle/format/) | शीर्षक की भराव, रेखा, प्रभाव शैलियों को लौटाता है।<br/>            केवल पढ़ने योग्य [`IFormat`](/slides/python-net/hi/aspose.slides.charts/iformat). |
| [`text_frame_for_overriding`](/slides/python-net/hi/aspose.slides.charts/charttitle/text_frame_for_overriding/) | रिच फॉर्मेटेड टेक्स्ट रख सकता है। यदि यह प्रॉपर्टी None नहीं है तो यह <br/>            फॉर्मेटेड टेक्स्ट वैल्यू ऑटो-जनरेटेड टेक्स्ट को ओवरराइड करती है।<br/>            ऑटो-जनरेटेड टेक्स्ट डेटा लेबल, वैल्यू एक्सिस की डिस्प्ले <br/>            यूनिट लेबल, एक्सिस शीर्षक, चार्ट शीर्षक, ट्रेंडलाइन लेबल की एक अंतर्निहित प्रॉपर्टी है।<br/>            ऑटो-जनरेटेड टेक्स्ट IFormattedTextContainer.TextFormat प्रॉपर्टी के साथ फॉर्मेट किया जाता है।<br/>            केवल पढ़ने योग्य [`ITextFrame`](/slides/python-net/hi/aspose.slides/itextframe). |
| [`text_format`](/slides/python-net/hi/aspose.slides.charts/charttitle/text_format/) | टेक्स्ट फॉर्मेट लौटाता है।<br/>            केवल पढ़ने योग्य [`IChartTextFormat`](/slides/python-net/hi/aspose.slides.charts/icharttextformat). |
| [`actual_x`](/slides/python-net/hi/aspose.slides.charts/charttitle/actual_x/) | चार्ट तत्व के वास्तविक x स्थान (बाएँ) को चार्ट के बाएँ शीर्ष कोने के सापेक्ष निर्दिष्ट करता है।<br/>            वास्तविक मान प्राप्त करने के लिए पहले IChart.ValidateChartLayout() मेथड को कॉल करें। <br/>            पढ़ें **float**. |
| [`actual_y`](/slides/python-net/hi/aspose.slides.charts/charttitle/actual_y/) | चार्ट तत्व के वास्तविक शीर्ष को चार्ट के बाएँ शीर्ष कोने के सापेक्ष निर्दिष्ट करता है।<br/>            वास्तविक मान प्राप्त करने के लिए पहले IChart.ValidateChartLayout() मेथड को कॉल करें। <br/>            पढ़ें **float**. |
| [`actual_width`](/slides/python-net/hi/aspose.slides.charts/charttitle/actual_width/) | चार्ट तत्व की वास्तविक चौड़ाई निर्दिष्ट करता है। वास्तविक मान प्राप्त करने के लिए पहले IChart.ValidateChartLayout() मेथड को कॉल करें। <br/>            पढ़ें **float**. |
| [`actual_height`](/slides/python-net/hi/aspose.slides.charts/charttitle/actual_height/) | चार्ट तत्व की वास्तविक ऊँचाई निर्दिष्ट करता है। वास्तविक मान प्राप्त करने के लिए पहले IChart.ValidateChartLayout() मेथड को कॉल करें। <br/>            पढ़ें **float**. |
| [`chart`](/slides/python-net/hi/aspose.slides.charts/charttitle/chart/) | पैरेंट चार्ट लौटाता है।<br/>            केवल पढ़ने योग्य [`IChart`](/slides/python-net/hi/aspose.slides.charts/ichart). |
| [`slide`](/slides/python-net/hi/aspose.slides.charts/charttitle/slide/) |  |
