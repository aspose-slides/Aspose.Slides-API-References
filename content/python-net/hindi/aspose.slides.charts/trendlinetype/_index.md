## TrendlineType एन्हुमरेशन

ट्रेंड लाइन का प्रकार दर्शाता है

TrendlineType प्रकार निम्नलिखित सदस्यों को प्रकट करता है:

## फ़ील्ड

| फ़ील्ड | विवरण |
| :- | :- |
| EXPONENTIAL | निर्देश देता है कि ट्रेंडलाइन फॉर्म में एक घातीय वक्र होगी। |
| LINEAR | निर्देश देता है कि ट्रेंडलाइन फॉर्म में एक रेखा होगी। |
| LOGARITHMIC | निर्देश देता है कि ट्रेंडलाइन फॉर्म में एक लघुगणकीय वक्र होगी, जहाँ log प्राकृतिक लघुगणक है। |
| MOVING_AVERAGE | निर्देश देता है कि ट्रेंडलाइन अवधि Period की चल औसत होगी। |
| POLYNOMIAL | निर्देश देता है कि ट्रेंडलाइन फॉर्म में क्रम Order की एक बहुपद वक्र होगी। |
| POWER | निर्देश देता है कि ट्रेंडलाइन फॉर्म में एक शक्ति वक्र होगी। |
