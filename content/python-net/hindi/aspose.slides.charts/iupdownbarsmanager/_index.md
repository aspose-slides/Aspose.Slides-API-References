## IUpDownBarsManager वर्ग

Line- या Stock-चार्ट के अप/डाउन बार तक पहुँच प्रदान करता है।

IUpDownBarsManager प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| संपत्ति | विवरण |
| :- | :- |
| [`up_bars_format`](/slides/python-net/hi/aspose.slides.charts/iupdownbarsmanager/up_bars_format/) | अप बार का स्वरूप लौटाता है।<br/>            केवल-पढ़ने योग्य [`IFormat`](/slides/python-net/hi/aspose.slides.charts/iformat). |
| [`down_bars_format`](/slides/python-net/hi/aspose.slides.charts/iupdownbarsmanager/down_bars_format/) | डाउन बार का स्वरूप लौटाता है।<br/>            केवल-पढ़ने योग्य [`IFormat`](/slides/python-net/hi/aspose.slides.charts/iformat). |
| [`has_up_down_bars`](/slides/python-net/hi/aspose.slides.charts/iupdownbarsmanager/has_up_down_bars/) | निर्धारित करता है कि चार्ट में अप/डाउन बार हैं या नहीं।<br/>            पढ़ें/लिखें **bool**. |
| [`gap_width`](/slides/python-net/hi/aspose.slides.charts/iupdownbarsmanager/gap_width/) | गैप की चौड़ाई लौटाता है या सेट करता है।<br/>            पढ़ें/लिखें **int**. |
