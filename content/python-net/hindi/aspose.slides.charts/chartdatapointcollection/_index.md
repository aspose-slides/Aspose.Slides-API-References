## ChartDataPointCollection क्लास

एक श्रृंखला डेटा पॉइंट का संग्रह दर्शाता है।

ChartDataPointCollection प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| Property | Description |
| :- | :- |
| [`data_source_type_for_x_values`](/slides/python-net/hi/aspose.slides.charts/chartdatapointcollection/data_source_type_for_x_values/) | निर्दिष्ट करता है कि AsCell या AsLiteralString या AsLiteralDouble प्रॉपर्टी डेटा पॉइंट्स XValue प्रॉपर्टी ऑब्जेक्ट में वास्तविक है या नहीं। <br/>            दूसरे शब्दों में यह निर्दिष्ट करता है ChartDataPoint.XValue.Data प्रॉपर्टी के मान के प्रकार को।<br/>            Read/write [`DataSourceType`](/slides/python-net/hi/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_y_values`](/slides/python-net/hi/aspose.slides.charts/chartdatapointcollection/data_source_type_for_y_values/) | निर्दिष्ट करता है कि AsCell या AsLiteralString या AsLiteralDouble प्रॉपर्टी डेटा पॉइंट्स YValue प्रॉपर्टी ऑब्जेक्ट में वास्तविक है या नहीं। <br/>            दूसरे शब्दों में यह निर्दिष्ट करता है ChartDataPoint.YValue.Data प्रॉपर्टी के मान के प्रकार को।<br/>            Read/write [`DataSourceType`](/slides/python-net/hi/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_bubble_sizes`](/slides/python-net/hi/aspose.slides.charts/chartdatapointcollection/data_source_type_for_bubble_sizes/) | निर्दिष्ट करता है कि AsCell या AsLiteralString या AsLiteralDouble प्रॉपर्टी डेटा पॉइंट्स BubbleSize प्रॉपर्टी ऑब्जेक्ट में वास्तविक है या नहीं। <br/>            दूसरे शब्दों में यह निर्दिष्ट करता है ChartDataPoint.BubbleSize.Data प्रॉपर्टी के मान के प्रकार को।<br/>            Read/write [`DataSourceType`](/slides/python-net/hi/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_values`](/slides/python-net/hi/aspose.slides.charts/chartdatapointcollection/data_source_type_for_values/) | निर्दिष्ट करता है कि AsCell या AsLiteralString या AsLiteralDouble प्रॉपर्टी डेटा पॉइंट्स Value प्रॉपर्टी ऑब्जेक्ट में वास्तविक है या नहीं। <br/>            दूसरे शब्दों में यह निर्दिष्ट करता है ChartDataPoint.Value.Data प्रॉपर्टी के मान के प्रकार को।<br/>            Read/write [`DataSourceType`](/slides/python-net/hi/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_error_bars_custom_values`](/slides/python-net/hi/aspose.slides.charts/chartdatapointcollection/data_source_type_for_error_bars_custom_values/) | ChartDataPoint.ErrorBarsCustomValues प्रॉपर्टीज़ सूची में मानों के प्रकार को निर्दिष्ट करता है।<br/>            Read-only [`IDataSourceTypeForErrorBarsCustomValues`](/slides/python-net/hi/aspose.slides.charts/idatasourcetypeforerrorbarscustomvalues). |

इंडेक्स के आधार पर (इस संग्रह में इसकी क्रम संख्या) श्रृंखला डेटा पॉइंट लौटाता है।
