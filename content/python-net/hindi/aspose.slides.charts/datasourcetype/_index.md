## DataSourceType एन्यूमरेशन

डेटा स्रोत प्रकार।

DataSourceType प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| WORKSHEET | डेटा पॉइंट के XValue, YValue, Value या BubbleSize को वर्कशीट में संग्रहीत करने के लिए CellXls ऑब्जेक्ट्स का उपयोग करें। |
| STRING_LITERALS | डेटा पॉइंट के XValue, YValue, Value या BubbleSize को संग्रहीत करने के लिए तेज़-एक्सेस स्ट्रिंग वेरिएबल का उपयोग करें।<br/>            डेटा पॉइंट। Worksheet मानों को संग्रहीत करने के लिए उपयोग नहीं किया जाता है। |
| DOUBLE_LITERALS | डेटा पॉइंट के XValue, YValue, Value या BubbleSize को संग्रहीत करने के लिए तेज़-एक्सेस डबल वेरिएबल का उपयोग करें।<br/>            डेटा पॉइंट। Worksheet मानों को संग्रहीत करने के लिए उपयोग नहीं किया जाता है। |
