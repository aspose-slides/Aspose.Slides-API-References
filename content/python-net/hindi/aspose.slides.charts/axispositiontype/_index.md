## AxisPositionType एन्यूमरेशन

एक अक्ष की स्थिति निर्धारित करता है।

AxisPositionType प्रकार निम्नलिखित सदस्यों को प्रदर्शित करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| BOTTOM | निर्देश देता है कि अक्ष को प्लॉट क्षेत्र के नीचे प्रदर्शित किया जाएगा। |
| LEFT | निर्देश देता है कि अक्ष को प्लॉट क्षेत्र के बाएँ प्रदर्शित किया जाएगा। |
| RIGHT | निर्देश देता है कि अक्ष को प्लॉट क्षेत्र के दाएँ प्रदर्शित किया जाएगा। |
| TOP | निर्देश देता है कि अक्ष को प्लॉट क्षेत्र के शीर्ष पर प्रदर्शित किया जाएगा। |
