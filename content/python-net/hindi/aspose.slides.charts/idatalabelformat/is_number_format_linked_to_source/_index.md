## is_number_format_linked_to_source गुण
पढ़ें/लिखें **bool**.

### टिप्पणियाँ
If parent of this DataLabelFormat object is a DataLabelCollection collection of data labels then this गुण gets or sets the default value of the IsNumberFormatLinkedToSource गुण for the new data 
labels in the DataLabelCollection collection.
Set this गुण with value also sets this value to the IsNumberFormatLinkedToSource गुण 
for all data labels in the DataLabelCollection collection
(i.e. "DataLabels.DefaultDataLabelFormat.IsNumberFormatLinkedToSource = val;" cause to 
all DataLabels[i].IsNumberFormatLinkedToSource is equal to val).
