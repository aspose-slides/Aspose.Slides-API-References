## use_cells प्रॉपर्टी
If true then worksheet is used for storing categories (this case supports a multi-level categories).
            यदि false हो तो worksheet का उपयोग मानों को संग्रहीत करने के लिए नहीं किया जाता (और इस मामले में बहु-स्तरीय श्रेणियों का समर्थन नहीं करता)।
            पढ़ें/लिखें **bool**.
