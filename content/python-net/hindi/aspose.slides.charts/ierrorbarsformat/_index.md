## IErrorBarsFormat क्लास

चार्ट श्रृंखला के त्रुटि बार को दर्शाता है। ErrorBars कस्टम मान IChartDataPointCollection में होते हैं ([`IChartDataPoint.error_bars_custom_values`](/slides/python-net/hi/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) प्रॉपर्टी में)।

IErrorBarsFormat प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| प्रॉपर्टी | विवरण |
| :- | :- |
| [`type`](/slides/python-net/hi/aspose.slides.charts/ierrorbarsformat/type/) | त्रुटि बार के प्रकार को प्राप्त करता है या सेट करता है। <br/>            पढ़ें/लिखें [`ErrorBarType`](/slides/python-net/hi/aspose.slides.charts/errorbartype). |
| [`value_type`](/slides/python-net/hi/aspose.slides.charts/ierrorbarsformat/value_type/) | त्रुटि बार की लंबाई निर्धारित करने के संभावित तरीकों को दर्शाता है। <br/>            कस्टम वैल्यू प्रकार के मामले में मान निर्दिष्ट करने के लिए सीरीज़ के DataPoints संग्रह में विशिष्ट डेटा पॉइंट की [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/hi/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) प्रॉपर्टी का उपयोग करें।  <br/>            पढ़ें/लिखें [`ErrorBarValueType`](/slides/python-net/hi/aspose.slides.charts/errorbarvaluetype). |
| [`has_end_cap`](/slides/python-net/hi/aspose.slides.charts/ierrorbarsformat/has_end_cap/) | निर्दिष्ट करता है कि त्रुटि बार पर अंत कैप नहीं बनाया जाएगा।<br/>            पढ़ें/लिखें **bool**. |
| [`value`](/slides/python-net/hi/aspose.slides.charts/ierrorbarsformat/value/) | त्रुटि बार की लंबाई निर्धारित करने के लिए Fixed, Percentage और StandardDeviation मान प्रकारों के साथ उपयोग किया जाने वाला मान प्राप्त करता है या सेट करता है। <br/>            पढ़ें/लिखें **float**. |
| [`format`](/slides/python-net/hi/aspose.slides.charts/ierrorbarsformat/format/) | त्रुटि बार का स्वरूप दर्शाता है।<br/>            पढ़ें/लिखें [`IFormat`](/slides/python-net/hi/aspose.slides.charts/iformat). |
| [`is_visible`](/slides/python-net/hi/aspose.slides.charts/ierrorbarsformat/is_visible/) | त्रुटि बार की दृश्यमानता प्राप्त करता है या सेट करता है।<br/>            पढ़ें/लिखें **bool**. |
