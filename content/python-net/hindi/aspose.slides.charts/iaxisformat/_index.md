## IAxisFormat क्लास

चार्ट फ़ॉर्मेट गुणों का प्रतिनिधित्व करता है।

IAxisFormat टाइप निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`fill`](/slides/python-net/hi/aspose.slides.charts/iaxisformat/fill/) | एक अक्ष की भराव शैली गुणों को लौटाता है।<br/>            केवल-पढ़ने योग्य [`IFillFormat`](/slides/python-net/hi/aspose.slides/ifillformat). |
| [`line`](/slides/python-net/hi/aspose.slides.charts/iaxisformat/line/) | एक अक्ष की रेखा शैली गुणों को लौटाता है।<br/>            केवल-पढ़ने योग्य [`ILineFormat`](/slides/python-net/hi/aspose.slides/ilineformat). |
| [`effect`](/slides/python-net/hi/aspose.slides.charts/iaxisformat/effect/) | एक अक्ष के लिए उपयोग किए गए प्रभावों को लौटाता है।<br/>            केवल-पढ़ने योग्य [`IEffectFormat`](/slides/python-net/hi/aspose.slides/ieffectformat). |
