## IFormat क्लास

चार्ट फार्मेट गुणधर्म दर्शाता है।

IFormat प्रकार निम्न सदस्य प्रदान करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`fill`](/slides/python-net/hi/aspose.slides.charts/iformat/fill/) | एक चार्ट की भराव शैली गुण लौटाता है।<br/>            केवल पढ़ने योग्य [`IFillFormat`](/slides/python-net/hi/aspose.slides/ifillformat). |
| [`line`](/slides/python-net/hi/aspose.slides.charts/iformat/line/) | एक चार्ट की रेखा शैली गुण लौटाता है।<br/>            केवल पढ़ने योग्य [`ILineFormat`](/slides/python-net/hi/aspose.slides/ilineformat). |
| [`effect`](/slides/python-net/hi/aspose.slides.charts/iformat/effect/) | एक चार्ट के लिए उपयोग किए गए प्रभाव लौटाता है।<br/>            केवल पढ़ने योग्य [`IEffectFormat`](/slides/python-net/hi/aspose.slides/ieffectformat). |
| [`effect_3d`](/slides/python-net/hi/aspose.slides.charts/iformat/effect_3d/) | एक चार्ट का 3D स्वरूप लौटाता है।<br/>            केवल पढ़ने योग्य [`IThreeDFormat`](/slides/python-net/hi/aspose.slides/ithreedformat). |
