## is_visible प्रॉपर्टी
False का अर्थ है कि डेटा लेबल दिखाई नहीं देता (और इसलिए सभी Show*-flags (ShowValue, ...) false होते हैं)।
Read-only **bool**।

### टिप्पणी

यदि डेटा लेबल दिखाई देता है तो आप इसे Hide() मेथड से छिपा सकते हैं।  
लेकिन यदि डेटा लेबल दिखाई नहीं देता (IsVisible false है) तो आप Show*-flags (ShowValue, ...) को true स्थिति में सेट करके डेटा लेबल को दिखाई दे सकता है।
