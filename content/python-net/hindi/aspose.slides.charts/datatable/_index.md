## DataTable क्लास

डेटा टेबल गुणधर्मों का प्रतिनिधित्व करता है।

DataTable प्रकार निम्नलिखित सदस्य उजागर करता है:

## प्रॉपर्टी

| प्रॉपर्टी | विवरण |
| :- | :- |
| [`format`](/slides/python-net/hi/aspose.slides.charts/datatable/format/) | ऑब्जेक्ट की लाइन, फिल, और इफ़ेक्ट शैलियों को लौटाता है।<br/>केवल-पढ़ने योग्य [`IFormat`](/slides/python-net/hi/aspose.slides.charts/iformat). |
| [`has_border_horizontal`](/slides/python-net/hi/aspose.slides.charts/datatable/has_border_horizontal/) | यदि चार्ट डेटा टेबल में क्षैतिज सेल बॉर्डर हैं तो सत्य।<br/>पढ़ें/लिखें **bool**. |
| [`has_border_outline`](/slides/python-net/hi/aspose.slides.charts/datatable/has_border_outline/) | यदि चार्ट डेटा टेबल में आउटलाइन बॉर्डर हैं तो सत्य।<br/>पढ़ें/लिखें **bool**. |
| [`has_border_vertical`](/slides/python-net/hi/aspose.slides.charts/datatable/has_border_vertical/) | यदि चार्ट डेटा टेबल में लंबवत सेल बॉर्डर हैं तो सत्य।<br/>पढ़ें/लिखें **bool**. |
| [`show_legend_key`](/slides/python-net/hi/aspose.slides.charts/datatable/show_legend_key/) | यदि डेटा लेबल लेजेंड कुंजी दिखाई देती है तो सत्य।<br/>पढ़ें/लिखें **bool**. |
| [`chart`](/slides/python-net/hi/aspose.slides.charts/datatable/chart/) | चार्ट लौटाता है।<br/>केवल-पढ़ने योग्य [`IChart`](/slides/python-net/hi/aspose.slides.charts/ichart). |
| [`text_format`](/slides/python-net/hi/aspose.slides.charts/datatable/text_format/) | टेक्स्ट फ़ॉर्मेट लौटाता है।<br/>केवल-पढ़ने योग्य [`IChartTextFormat`](/slides/python-net/hi/aspose.slides.charts/icharttextformat). |
