## error_bars_x_format प्रॉपर्टी

त्रुटि बार (ErrorBars) को X दिशा वाली श्रृंखला का प्रतिनिधित्व करता है।

            ErrorBars X दिशा के साथ area, bar, scatter और bubble प्रकार की श्रृंखलाओं के लिए उपलब्ध हैं। 
            अन्य सभी प्रकार के चार्ट के लिए यह प्रॉपर्टी None लौटाती है (3D चार्ट सहित)। 
            कस्टम मानों के लिए DataPoints संग्रह का उपयोग करके मान निर्दिष्ट करें ([`IChartDataPoint.error_bars_custom_values`](/slides/python-net/hi/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) प्रॉपर्टी के साथ)। 
            
            केवल-पढ़ने योग्य [`IErrorBarsFormat`](/slides/python-net/hi/aspose.slides.charts/ierrorbarsformat)।
