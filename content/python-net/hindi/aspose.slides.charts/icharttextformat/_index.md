## IChartTextFormat क्लास

चार्ट सीमित सेट के टेक्स्ट फ़ॉर्मेट प्रॉपर्टीज़ के साथ काम करता है।
IChartTextFormat, IChartTextBlockFormat, IChartParagraphFormat, IChartPortionFormat इंटरफ़ेस इस सीमित सेट का वर्णन करते हैं।

IChartTextFormat प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## प्रॉपर्टीज़

| प्रॉपर्टी | विवरण |
| :- | :- |
| [`text_block_format`](/slides/python-net/hi/aspose.slides.charts/icharttextformat/text_block_format/) | चार्ट टेक्स्ट तत्वों के लिए फ़ॉर्मेट लौटाता है.<br/> केवल-पढ़ने-योग्य [`IChartTextBlockFormat`](/slides/python-net/hi/aspose.slides.charts/icharttextblockformat). |
| [`paragraph_format`](/slides/python-net/hi/aspose.slides.charts/icharttextformat/paragraph_format/) | पैराग्राफ फ़ॉर्मेट लौटाता है.<br/> केवल-पढ़ने-योग्य [`IChartParagraphFormat`](/slides/python-net/hi/aspose.slides.charts/ichartparagraphformat). |
| [`portion_format`](/slides/python-net/hi/aspose.slides.charts/icharttextformat/portion_format/) | भाग फ़ॉर्मेट लौटाता है.<br/> केवल-पढ़ने-योग्य [`IChartPortionFormat`](/slides/python-net/hi/aspose.slides.charts/ichartportionformat). |
