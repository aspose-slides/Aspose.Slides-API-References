## hide(self) {#}
सभी Show*-flags (ShowValue, ...) को false स्थिति में सेट करके डेटा लेबल को छुपा दें।  
IsVisible will be false after this.

```python
def hide(self):
    ...
```

### टिप्पणियाँ

यदि डेटा लेबल दृश्य नहीं है (IsVisible false है) तो आप Show*-flags (ShowValue, ...) को true स्थिति में सेट करके डेटा लेबल को दृश्य बना सकते हैं।
