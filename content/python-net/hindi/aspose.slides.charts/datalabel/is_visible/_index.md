## is_visible प्रॉपर्टी
False का मतलब है कि डेटा लेबल दिखाई नहीं देता (और इसलिए सभी Show*-flags (ShowValue, ...) false होते हैं)।
केवल-पढ़ने योग्य **bool**।

### टिप्पणियाँ

यदि डेटा लेबल दिखाई दे रहा है तो आप इसे Hide() मेथड से छिपा सकते हैं।
लेकिन यदि डेटा लेबल दिखाई नहीं दे रहा है (IsVisible false है) तो आप Show*-flags (ShowValue, ...) को true स्थिति में सेट करके डेटा लेबल को दिखाई दे सकता है।
