## text_frame_for_overriding गुण
Can contain a rich formatted text. If this गुण is not None then this 
            formatted text value overrides auto-generated text of data label.
            Auto-generated text of data label means text that is managed by ShowSeriesName, 
            ShowValue, ... गुण and is formatted with the TextFormatManager.TextFormat गुण.
            केवल-पढ़ने योग्य [`ITextFrame`](/slides/python-net/hi/aspose.slides/itextframe).
