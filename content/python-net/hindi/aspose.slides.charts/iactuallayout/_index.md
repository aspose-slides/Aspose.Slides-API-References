## IActualLayout क्लास

चार्ट तत्व की वास्तविक स्थिति निर्दिष्ट करता है।

IActualLayout प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुणधर्म

| Property | Description |
| :- | :- |
| [`actual_x`](/slides/python-net/hi/aspose.slides.charts/iactuallayout/actual_x/) | चार्ट तत्व के बाएँ शीर्ष कोने के सापेक्ष वास्तविक x स्थिति (बाएँ) निर्दिष्ट करता है।<br/>            वास्तविक मान प्राप्त करने के लिए IChart.ValidateChartLayout() मेथड को पहले कॉल करें। <br/>            पढ़ें **float**. |
| [`actual_y`](/slides/python-net/hi/aspose.slides.charts/iactuallayout/actual_y/) | चार्ट तत्व के बाएँ शीर्ष कोने के सापेक्ष वास्तविक शीर्ष निर्दिष्ट करता है।<br/>            वास्तविक मान प्राप्त करने के लिए IChart.ValidateChartLayout() मेथड को पहले कॉल करें। <br/>            पढ़ें **float**. |
| [`actual_width`](/slides/python-net/hi/aspose.slides.charts/iactuallayout/actual_width/) | चार्ट तत्व की वास्तविक चौड़ाई निर्दिष्ट करता है। वास्तविक मान प्राप्त करने के लिए IChart.ValidateChartLayout() मेथड को पहले कॉल करें। <br/>            पढ़ें **float**. |
| [`actual_height`](/slides/python-net/hi/aspose.slides.charts/iactuallayout/actual_height/) | चार्ट तत्व की वास्तविक ऊँचाई निर्दिष्ट करता है। वास्तविक मान प्राप्त करने के लिए IChart.ValidateChartLayout() मेथड को पहले कॉल करें। <br/>            पढ़ें **float**. |
