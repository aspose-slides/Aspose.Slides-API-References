## Legend क्लास

चार्ट की लेजेंड गुणों का प्रतिनिधित्व करता है।

Legend प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`x`](/slides/python-net/hi/aspose.slides.charts/legend/x/) | लेजेंड के x निर्देशांक को चार्ट की चौड़ाई के अनुपात में लौटाता है या सेट करता है।<br/>            केवल-पढ़ने योग्य **float**. |
| [`y`](/slides/python-net/hi/aspose.slides.charts/legend/y/) | लेजेंड के y निर्देशांक को चार्ट की ऊँचाई के अनुपात में लौटाता है या सेट करता है।<br/>            केवल-पढ़ने योग्य **float**. |
| [`width`](/slides/python-net/hi/aspose.slides.charts/legend/width/) | लेजेंड की चौड़ाई को चार्ट की चौड़ाई के अनुपात में लौटाता है या सेट करता है।<br/>            केवल-पढ़ने योग्य **float**. |
| [`height`](/slides/python-net/hi/aspose.slides.charts/legend/height/) | लेजेंड की ऊँचाई को चार्ट की ऊँचाई के अनुपात में लौटाता है या सेट करता है।<br/>            केवल-पढ़ने योग्य **float**. |
| [`right`](/slides/python-net/hi/aspose.slides.charts/legend/right/) | दायाँ।<br/>            केवल-पढ़ने योग्य **float**. |
| [`bottom`](/slides/python-net/hi/aspose.slides.charts/legend/bottom/) | नीचे।<br/>            केवल-पढ़ने योग्य **float**. |
| [`overlay`](/slides/python-net/hi/aspose.slides.charts/legend/overlay/) | निर्धारित करता है कि अन्य चार्ट तत्वों को लेजेंड के ऊपर ओवरलैप करने की अनुमति होनी चाहिए या नहीं।<br/>            पढ़ें/लिखें **bool**. |
| [`text_format`](/slides/python-net/hi/aspose.slides.charts/legend/text_format/) | टेक्स्ट फ़ॉर्मेट।<br/>            केवल-पढ़ने योग्य [`IChartTextFormat`](/slides/python-net/hi/aspose.slides.charts/icharttextformat). |
| [`position`](/slides/python-net/hi/aspose.slides.charts/legend/position/) | चार्ट पर लेजेंड की स्थिति को निर्दिष्ट करता है।<br/>            X, Y, Width, Heigt गुणों के Non-NaN मान इस गुण के प्रभाव को ओवरराइड करते हैं।<br/>            पढ़ें/लिखें [`LegendPositionType`](/slides/python-net/hi/aspose.slides.charts/legendpositiontype). |
| [`format`](/slides/python-net/hi/aspose.slides.charts/legend/format/) | लेजेंड का फ़ॉर्मेट लौटाता है।<br/>            केवल-पढ़ने योग्य [`IFormat`](/slides/python-net/hi/aspose.slides.charts/iformat). |
| [`chart`](/slides/python-net/hi/aspose.slides.charts/legend/chart/) | चार्ट लौटाता है।<br/>            केवल-पढ़ने योग्य [`IChart`](/slides/python-net/hi/aspose.slides.charts/ichart). |
| [`entries`](/slides/python-net/hi/aspose.slides.charts/legend/entries/) | लेजेंड एंट्रीज़ प्राप्त करता है।<br/>            केवल-पढ़ने योग्य [`ILegendEntryCollection`](/slides/python-net/hi/aspose.slides.charts/ilegendentrycollection). |
| [`actual_x`](/slides/python-net/hi/aspose.slides.charts/legend/actual_x/) | चार्ट तत्व का वास्तविक x स्थान (बाएँ) चार्ट के बाएँ ऊपरी कोने के सापेक्ष निर्दिष्ट करता है।<br/>            वास्तविक मान प्राप्त करने के लिए पहले IChart.ValidateChartLayout() विधि को कॉल करें।<br/>            पढ़ें **float**. |
| [`actual_y`](/slides/python-net/hi/aspose.slides.charts/legend/actual_y/) | चार्ट तत्व के वास्तविक शीर्ष को चार्ट के बाएँ ऊपरी कोने के सापेक्ष निर्दिष्ट करता है।<br/>            वास्तविक मान प्राप्त करने के लिए पहले IChart.ValidateChartLayout() विधि को कॉल करें।<br/>            पढ़ें **float**. |
| [`actual_width`](/slides/python-net/hi/aspose.slides.charts/legend/actual_width/) | चार्ट तत्व की वास्तविक चौड़ाई को निर्दिष्ट करता है। वास्तविक मान प्राप्त करने के लिए पहले IChart.ValidateChartLayout() विधि को कॉल करें।<br/>            पढ़ें **float**. |
| [`actual_height`](/slides/python-net/hi/aspose.slides.charts/legend/actual_height/) | चार्ट तत्व की वास्तविक ऊँचाई को निर्दिष्ट करता है। वास्तविक मान प्राप्त करने के लिए पहले IChart.ValidateChartLayout() विधि को कॉल करें।<br/>            पढ़ें **float**. |
