## x_minus प्रॉपर्टी
Specifies the error bar value in the negative direction. 
            Available if error bars value type is Custom and ErrorBarsXFormat is allowed.
            In any other case this property returns None.
            केवल- पढ़ने योग्य [`IDoubleChartValue`](/slides/python-net/hi/aspose.slides.charts/idoublechartvalue).
