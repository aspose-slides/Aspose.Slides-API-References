## ChartDataPoint क्लास

सिरीज़ डेटा पॉइंट का प्रतिनिधित्व करता है।

ChartDataPoint प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`x_value`](/slides/python-net/hi/aspose.slides.charts/chartdatapoint/x_value/) | XValue.<br/>            केवल-पढ़ने योग्य [`IStringOrDoubleChartValue`](/slides/python-net/hi/aspose.slides.charts/istringordoublechartvalue). |
| [`y_value`](/slides/python-net/hi/aspose.slides.charts/chartdatapoint/y_value/) | YValue.<br/>            केवल-पढ़ने योग्य [`IDoubleChartValue`](/slides/python-net/hi/aspose.slides.charts/idoublechartvalue). |
| [`bubble_size`](/slides/python-net/hi/aspose.slides.charts/chartdatapoint/bubble_size/) | BubbleSize.<br/>            केवल-पढ़ने योग्य [`IDoubleChartValue`](/slides/python-net/hi/aspose.slides.charts/idoublechartvalue). |
| [`value`](/slides/python-net/hi/aspose.slides.charts/chartdatapoint/value/) | Value.<br/>            केवल-पढ़ने योग्य [`IDoubleChartValue`](/slides/python-net/hi/aspose.slides.charts/idoublechartvalue). |

| [`color_value`](/slides/python-net/hi/aspose.slides.charts/chartdatapoint/color_value/) | चार्ट डेटा पॉइंट का रंग मान लौटाता है।<br/>            Map चार्ट के साथ उपयोग किया जाता है। <br/>            केवल-पढ़ने योग्य [`IDoubleChartValue`](/slides/python-net/hi/aspose.slides.charts/idoublechartvalue). |

| [`label`](/slides/python-net/hi/aspose.slides.charts/chartdatapoint/label/) | Label.<br/>            केवल-पढ़ने योग्य [`IDataLabel`](/slides/python-net/hi/aspose.slides.charts/idatalabel). |
| [`is_bubble_3d`](/slides/python-net/hi/aspose.slides.charts/chartdatapoint/is_bubble_3d/) | निर्दिष्ट करता है कि बुलबुले पर 3-D प्रभाव लागू किया गया है।<br/>            पढ़ें/लिखें **bool**. |
| [`explosion`](/slides/python-net/hi/aspose.slides.charts/chartdatapoint/explosion/) | निर्दिष्ट करता है कि डेटा पॉइंट को पाई के केन्द्र से कितना हटाया जाए।<br/>            पढ़ें/लिखें **int**. |

| [`related_legend_entry`](/slides/python-net/hi/aspose.slides.charts/chartdatapoint/related_legend_entry/) | निम्नलिखित चार्ट प्रकारों के लिए सुलेख प्रविष्टि के संबंधित गुणधर्म:<br/>            ChartType.BarOfPie,<br/>            ChartType.ExplodedPie,<br/>            ChartType.ExplodedPie3D,<br/>            ChartType.Pie,<br/>            ChartType.Pie3D,<br/>            ChartType.PieOfPie.<br/>            केवल-पढ़ने योग्य [`ILegendEntryProperties`](/slides/python-net/hi/aspose.slides.charts/ilegendentryproperties). |
| [`data_point_levels`](/slides/python-net/hi/aspose.slides.charts/chartdatapoint/data_point_levels/) | डेटा पॉइंट स्तरों का कंटेनर लौटाता है। केवल Treeamp और Sunburst सीरीज़ के लिए लागू।<br/>            डेटा पॉइंट स्तरों की इंडेक्सिंग शून्य-आधारित है। |
| [`index`](/slides/python-net/hi/aspose.slides.charts/chartdatapoint/index/) |  |

| [`actual_x`](/slides/python-net/hi/aspose.slides.charts/chartdatapoint/actual_x/) | चार्ट तत्व का वास्तविक x स्थान (बायाँ) चार्ट के बाएँ-ऊपर कोने की तुलना में निर्दिष्ट करता है।<br/>            वास्तविक मान पाने से पहले IChart.ValidateChartLayout() मेथड कॉल करें। <br/>            पढ़ें **float**. |
