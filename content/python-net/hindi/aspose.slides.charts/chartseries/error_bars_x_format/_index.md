## error_bars_x_format प्रॉपर्टी
Represents ErrorBars of series with derection X. 
            
            X दिशा वाले ErrorBars series of type area, bar, scatter और bubble के लिए उपलब्ध हैं। 
            किसी भी अन्य प्रकार के chart के लिए यह प्रॉपर्टी None लौटाती है (जिसमें 3D charts शामिल हैं)।
            कस्टम मानों के मामले में value निर्दिष्ट करने के लिए DataPoints collection का उपयोग करें
            ([`IChartDataPoint.error_bars_custom_values`](/slides/python-net/hi/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) प्रॉपर्टी के साथ)।
            
            केवल-पढ़ने योग्य [`IErrorBarsFormat`](/slides/python-net/hi/aspose.slides.charts/ierrorbarsformat)।
