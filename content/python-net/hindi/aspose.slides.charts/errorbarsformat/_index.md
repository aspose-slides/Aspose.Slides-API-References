## ErrorBarsFormat क्लास

चार्ट श्रृंखला के त्रुटि बार का प्रतिनिधित्व करता है। ErrorBars कस्टम मान IChartDataPointCollection में होते हैं ([`IChartDataPoint.error_bars_custom_values`](/slides/python-net/hi/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) प्रॉपर्टी में)।

ErrorBarsFormat टाइप निम्नलिखित सदस्य प्रदान करता है:

## गुण

| Property | Description |
| :- | :- |
| [`type`](/slides/python-net/hi/aspose.slides.charts/errorbarsformat/type/) | त्रुटि बार के प्रकार को प्राप्त करता है या सेट करता है। <br/>            पढ़ें/लिखें [`ErrorBarType`](/slides/python-net/hi/aspose.slides.charts/errorbartype). |
| [`value_type`](/slides/python-net/hi/aspose.slides.charts/errorbarsformat/value_type/) | त्रुटि बार की लंबाई निर्धारित करने के संभावित तरीकों को दर्शाता है। <br/>            कस्टम वैल्यू टाइप के मामले में मान निर्दिष्ट करने के लिए सीरीज़ के DataPoints कलेक्शन में विशिष्ट डेटा पॉइंट की [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/hi/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) प्रॉपर्टी का उपयोग करें।<br/>            Fixed, Percentage या StandardDeviation वैल्यू टाइप के मामले में मान निर्दिष्ट करने के लिए Value प्रॉपर्टी का उपयोग करें।  <br/>            पढ़ें/लिखें [`ErrorBarValueType`](/slides/python-net/hi/aspose.slides.charts/errorbarvaluetype). |
| [`has_end_cap`](/slides/python-net/hi/aspose.slides.charts/errorbarsformat/has_end_cap/) | निर्दिष्ट करता है कि त्रुटि बार पर अंत कैप नहीं बनाया जाता है।<br/>            पढ़ें/लिखें **bool**. |
| [`value`](/slides/python-net/hi/aspose.slides.charts/errorbarsformat/value/) | त्रुटि बार की लंबाई निर्धारित करने के लिए Fixed, Percentage और StandardDeviation वैल्यू टाइप के साथ उपयोग किए जाने वाले मान को प्राप्त करता है या सेट करता है। <br/>            किसी अन्य मामले में NaN लौटाएगा।<br/>            पढ़ें/लिखें **float**. |
| [`format`](/slides/python-net/hi/aspose.slides.charts/errorbarsformat/format/) | त्रुटि बार के फॉर्मेट को दर्शाता है।<br/>            पढ़ें/लिखें [`IFormat`](/slides/python-net/hi/aspose.slides.charts/iformat). |
| [`chart`](/slides/python-net/hi/aspose.slides.charts/errorbarsformat/chart/) | पैरेंट चार्ट को लौटाता है।<br/>            केवल पढ़ने योग्य [`IChart`](/slides/python-net/hi/aspose.slides.charts/ichart). |
| [`is_visible`](/slides/python-net/hi/aspose.slides.charts/errorbarsformat/is_visible/) | त्रुटि बार की दृश्यमानता को प्राप्त करता है या सेट करता है।<br/>            पढ़ें/लिखें **bool**. |
