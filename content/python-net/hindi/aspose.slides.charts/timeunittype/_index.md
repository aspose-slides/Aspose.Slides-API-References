## TimeUnitType एन्यूमरेशन

श्रेणी अक्ष के लिए आधार इकाई का प्रतिनिधित्व करता है

TimeUnitType प्रकार निम्नलिखित सदस्य प्रदान करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| NONE | मान जैसा है वैसा ही प्रदर्शित किए जाएंगे। |
| DAYS | निर्दिष्ट करता है कि चार्ट डेटा दिनों में दिखाया जाएगा। |
| MONTHS | निर्दिष्ट करता है कि चार्ट डेटा महीनों में दिखाया जाएगा। |
| YEARS | निर्दिष्ट करता है कि चार्ट डेटा वर्षों में दिखाया जाएगा। |
