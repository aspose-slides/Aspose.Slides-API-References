## IChartDataPointLevel क्लास

डेटा पॉइंट स्तर का प्रतिनिधित्व करता है। Treemap और Sunburst चार्ट के लिए लागू होता है।

IChartDataPointLevel प्रकार निम्नलिखित सदस्य प्रदान करता है:

## गुण

| Property | Description |
| :- | :- |
| [`format`](/slides/python-net/hi/aspose.slides.charts/ichartdatapointlevel/format/) | डेटा पॉइंट स्तर की फ़ॉर्मेटिंग प्रॉपर्टीज़ का प्रतिनिधित्व करता है।<br/>            Read/write [`IFormat`](/slides/python-net/hi/aspose.slides.charts/iformat). |
| [`label`](/slides/python-net/hi/aspose.slides.charts/ichartdatapointlevel/label/) | डेटा पॉइंट स्तर का डेटा लेबल दर्शाता है। Treemap और Sunburst सीरीज़ प्रकार के लिए लागू।<br/>             Read-only [`IDataLabel`](/slides/python-net/hi/aspose.slides.charts/idatalabel). |
