## DisplayUnitType एन्यूमेरेशन

प्रदर्शित डेटा की बहुलता निर्धारित करता है।

DisplayUnitType टाइप निम्नलिखित सदस्यों को प्रकट करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| NONE | मान जैसा है वैसा ही प्रदर्शित होंगे। |
| HUNDREDS | निर्देश देता है कि चार्ट पर मान को 100 से विभाजित किया जाएगा। |
| THOUSANDS | निर्देश देता है कि चार्ट पर मान को 1,000 से विभाजित किया जाएगा। |
| TEN_THOUSANDS | निर्देश देता है कि चार्ट पर मान को 10,000 से विभाजित किया जाएगा। |
| HUNDRED_THOUSANDS | निर्देश देता है कि चार्ट पर मान को 100,000 से विभाजित किया जाएगा। |
| MILLIONS | निर्देश देता है कि चार्ट पर मान को 1,000,000 से विभाजित किया जाएगा। |
| TEN_MILLIONS | निर्देश देता है कि चार्ट पर मान को 10,000,000 से विभाजित किया जाएगा। |
| HUNDRED_MILLIONS | निर्देश देता है कि चार्ट पर मान को 100,000,000 से विभाजित किया जाएगा। |
| BILLIONS | निर्देश देता है कि चार्ट पर मान को 1,000,000,000 से विभाजित किया जाएगा। |
| TRILLIONS | निर्देश देता है कि चार्ट पर मान को 1,000,000,000,000 से विभाजित किया जाएगा। |
| CUSTOM_VALUE | निर्देश देता है कि चार्ट पर मान को एक कस्टम मान से विभाजित किया जाएगा। |
