## IOverridableText वर्ग

एक चार्ट के लिए ओवरराइड करने योग्य टेक्स्ट का प्रतिनिधित्व करता है।

IOverridableText प्रकार निम्नलिखित सदस्य उजागर करता है:

## गुण

| प्रॉपर्टी | विवरण |
| :- | :- |
| [`text_frame_for_overriding`](/slides/python-net/hi/aspose.slides.charts/ioverridabletext/text_frame_for_overriding/) | रिच फॉर्मेटेड टेक्स्ट रख सकता है। यदि यह प्रॉपर्टी None नहीं है तो यह <br/> फॉर्मेटेड टेक्स्ट मान ऑटो-जनरेटेड टेक्स्ट को ओवरराइड करता है।<br/> ऑटो-जनरेटेड टेक्स्ट डेटा लेबल, वैल्यू एक्सिस का डिस्प्ले <br/> यूनिट लेबल, एक्सिस टाइटल, चार्ट टाइटल, ट्रेंडलाइन का लेबल का एक इम्प्लिसिट प्रॉपर्टी है।<br/> ऑटो-जनरेटेड टेक्स्ट IFormattedTextContainer.TextFormat प्रॉपर्टी के साथ फ़ॉर्मेट किया जाता है।<br/> केवल-पढ़ने योग्य [`ITextFrame`](/slides/python-net/hi/aspose.slides/itextframe)। |
