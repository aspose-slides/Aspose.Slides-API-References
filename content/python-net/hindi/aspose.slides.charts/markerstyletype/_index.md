## MarkerStyleType क्रमांकन

डेटा पॉइंट पर मार्कर के रूप को निर्धारित करता है।

MarkerStyleType प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| NOT_DEFINED |  |
| CIRCLE | प्रत्येक डेटा पॉइंट पर एक वृत्त खींचा जाएगा। |
| DASH | प्रत्येक डेटा पॉइंट पर एक डैश खींचा जाएगा। |
| DIAMOND | प्रत्येक डेटा पॉइंट पर एक हीरा खींचा जाएगा। |
| DOT | प्रत्येक डेटा पॉइंट पर एक बिंदु खींचा जाएगा। |
| NONE | प्रत्येक डेटा पॉइंट पर कुछ भी नहीं खींचा जाएगा। |
| PICTURE | प्रत्येक डेटा पॉइंट पर एक चित्र खींचा जाएगा। |
| PLUS | प्रत्येक डेटा पॉइंट पर एक प्लस खींचा जाएगा। |
| SQUARE | प्रत्येक डेटा पॉइंट पर एक वर्ग खींचा जाएगा। |
| STAR | प्रत्येक डेटा पॉइंट पर एक तारा खींचा जाएगा। |
| TRIANGLE | प्रत्येक डेटा पॉइंट पर एक त्रिकोण खींचा जाएगा। |
| X | प्रत्येक डेटा पॉइंट पर एक X खींचा जाएगा। |
