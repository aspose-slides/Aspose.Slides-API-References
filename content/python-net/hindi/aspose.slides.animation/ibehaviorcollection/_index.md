## IBehaviorCollection क्लास

व्यवहार प्रभावों का संग्रह दर्शाता है।

IBehaviorCollection प्रकार निम्न सदस्यों को उजागर करता है:

## गुण

| Property | Description |
| :- | :- |
| [`count`](/slides/python-net/hi/aspose.slides.animation/ibehaviorcollection/count/) | कलेक्शन में व्यवहारों की संख्या लौटाता है।<br/>            केवल-पढ़ने योग्य **int**. |

निर्दिष्ट अनुक्रमांक पर एक व्यवहार लौटाता है।

## इंडेक्सर
