## ITextAnimation क्लास

पाठ एनिमेशन को दर्शाता है।

ITextAnimation प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| Property | Description |
| :- | :- |
| [`build_type`](/slides/python-net/hi/aspose.slides.animation/itextanimation/build_type/) | पाठ एनिमेशन के निर्माण प्रकार की सूची (उदाहरण के लिए पैराग्राफ 1,2,3, सभी एक साथ)।<br/>            पढ़ें/लिखें [`ITextAnimation.build_type`](/slides/python-net/hi/aspose.slides.animation/itextanimation/build_type). |
| [`effect_animate_background_shape`](/slides/python-net/hi/aspose.slides.animation/itextanimation/effect_animate_background_shape/) | समूह के साथ या बिना जुड़ा शेप इफ़ेक्ट (कोई नहीं)<br/>            पढ़ें/लिखें [`IEffect`](/slides/python-net/hi/aspose.slides.animation/ieffect). |
