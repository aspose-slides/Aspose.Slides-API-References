## BehaviorCollection क्लास

व्यवहार प्रभावों का संग्रह दर्शाता है।

BehaviorCollection प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`count`](/slides/python-net/hi/aspose.slides.animation/behaviorcollection/count/) | संग्रह में व्यवहारों की संख्या लौटाता है।<br/>            केवल-पढ़ने योग्य **int**. |
| [`is_read_only`](/slides/python-net/hi/aspose.slides.animation/behaviorcollection/is_read_only/) | एक मान प्राप्त करता है जो संकेत देता है कि **System.Collections.Generic.ICollection`1** केवल-पढ़ने योग्य है।<br/>            केवल-पढ़ने योग्य **bool**. |

निर्दिष्ट सूचकांक पर एक व्यवहार लौटाता है।

## इंडेक्सर

| नाम | विवरण |
| :- | :- |
| [`[index]`](/slides/python-net/hi/aspose.slides.animation/behaviorcollection/__getitem__/) | वापस करने के लिए व्यवहार का सूचकांक। |

## विधियां

| विधि | विवरण |
| :- | :- |
| [`add(self, item)`](/slides/python-net/hi/aspose.slides.animation/behaviorcollection/add/#ibehavior) | संग्रह में नया व्यवहार जोड़ता है। |
| [`index_of(self, item)`](/slides/python-net/hi/aspose.slides.animation/behaviorcollection/index_of/#ibehavior) | निर्दिष्ट आइटम का सूचकांक **System.Collections.Generic.IList`1** में निर्धारित करता है। |
| [`insert(self, index, item)`](/slides/python-net/hi/aspose.slides.animation/behaviorcollection/insert/#int-ibehavior) | निर्दिष्ट सूचकांक पर संग्रह में नया व्यवहार सम्मिलित करता है। |
| [`copy_to(self, array, array_index)`](/slides/python-net/hi/aspose.slides.animation/behaviorcollection/copy_to/#listibehavior-int) | **System.Collections.Generic.ICollection`1** के तत्वों को एक **System.Array** में कॉपी करता है, जो एक विशेष **System.Array** सूचकांक से शुरू होता है। |
| [`remove(self, item)`](/slides/python-net/hi/aspose.slides.animation/behaviorcollection/remove/#ibehavior) | संग्रह से निर्दिष्ट व्यवहार को हटाता है। |
| [`remove_at(self, index)`](/slides/python-net/hi/aspose.slides.animation/behaviorcollection/remove_at/#int) | निर्दिष्ट सूचकांक पर संग्रह से व्यवहार को हटाता है। |
| [`clear(self)`](/slides/python-net/hi/aspose.slides.animation/behaviorcollection/clear/#) | संग्रह से सभी व्यवहारों को हटाता है। |
| [`contains(self, item)`](/slides/python-net/hi/aspose.slides.animation/behaviorcollection/contains/#ibehavior) | निर्धारित करता है कि **System.Collections.Generic.ICollection`1** में कोई विशिष्ट मान मौजूद है या नहीं। |
