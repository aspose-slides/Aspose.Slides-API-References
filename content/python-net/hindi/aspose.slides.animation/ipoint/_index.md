## IPoint क्लास

एनीमेशन पॉइंट को दर्शाता है।

IPoint प्रकार निम्न सदस्य को उजागर करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`time`](/slides/python-net/hi/aspose.slides.animation/ipoint/time/) | समय मान को दर्शाता है।<br/>            पढ़ें/लिखें **float**. |
| [`value`](/slides/python-net/hi/aspose.slides.animation/ipoint/value/) | बिंदु मान को दर्शाता है।<br/>            केवल: bool, ColorFormat, float, int, string.<br/>            पढ़ें/लिखें **any**. |
| [`formula`](/slides/python-net/hi/aspose.slides.animation/ipoint/formula/) | मानों, from, to, by गुणों के भीतर के सूत्र इनमें से बनाए जा सकते हैं:<br/>            मानक अंकगणितीय ऑपरेटर: ‘+’, ‘-‘, ‘*’, ‘/’, ‘^’, ‘%’ (mod)<br/>            स्थिरांक: ‘pi’ ‘e’<br/>            सशर्त ऑपरेटर: ‘abs’, ‘min’, ‘max’, ‘?’ (if)<br/>            तुलना ऑपरेटर: '==', '>=', '', '!=', '!'<br/>            त्रिकोणमितीय ऑपरेटर: ‘sin()’, ‘cos()’, ‘tan()’, ‘asin()’, ‘acos()’, ‘atan()’<br/>            प्राकृतिक लघुगणक ‘ln()’<br/>            प्रॉपर्टी रेफ़रेंसेज़ (होस्ट समर्थित प्रॉपर्टी)<br/>            <br/>            उदाहरण के लिए: "#ppt_x+(cos(-2*pi*(1-$))*-#ppt_x-sin(-2*pi*(1-$))*(1-#ppt_y))*(1-$)"<br/>            पढ़ें/लिखें **str**. |
