## AfterAnimationType enumeration

एक एनीमेशन प्रभाव के बाद एनीमेशन प्रकार का प्रतिनिधित्व करता है।

AfterAnimationType प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| DO_NOT_DIM | एनिमेशन के बाद डिम न करें। |
| COLOR | एनिमेशन के बाद रंग। |
| HIDE_AFTER_ANIMATION | एनिमेशन के बाद छिपाएँ। |
| HIDE_ON_NEXT_MOUSE_CLICK | एनिमेशन के बाद अगले माउस क्लिक पर छिपाएँ। |
