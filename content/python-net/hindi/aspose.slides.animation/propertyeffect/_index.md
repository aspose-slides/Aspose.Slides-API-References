## PropertyEffect क्लास

प्रॉपर्टी इफ़ेक्ट व्यवहार को दर्शाता है।

**विरासत:**[`PropertyEffect`](/slides/python-net/hi/aspose.slides.animation/propertyeffect) → [`Behavior`](/slides/python-net/hi/aspose.slides.animation/behavior)

PropertyEffect प्रकार निम्नलिखित सदस्यों को उजागर करता है।

## निर्माता

| निर्माता | विवरण |
| :- | :- |
| [`__init__(self)`](/slides/python-net/hi/aspose.slides.animation/propertyeffect/__init__/#) | एक नया उदाहरण बनाता है। |

## गुण

| गुण | विवरण |
| :- | :- |
| [`accumulate`](/slides/python-net/hi/aspose.slides.animation/propertyeffect/accumulate/) | निर्धारित करता है कि क्या एनीमेशन व्यवहार संचित होते हैं।<br/>            पढ़ें/लिखें [`NullableBool`](/slides/python-net/hi/aspose.slides/nullablebool). |
| [`additive`](/slides/python-net/hi/aspose.slides.animation/propertyeffect/additive/) | निर्धारित करता है कि क्या वर्तमान एनीमेशन व्यवहार को अन्य चल रहे एनीमेशन के साथ संयोजित किया जाता है।<br/>            पढ़ें/लिखें [`BehaviorAdditiveType`](/slides/python-net/hi/aspose.slides.animation/behavioradditivetype). |
| [`properties`](/slides/python-net/hi/aspose.slides.animation/propertyeffect/properties/) | व्यवहार की गुणधर्मों को दर्शाता है।<br/>            केवल-पढ़ने योग्य [`IBehaviorPropertyCollection`](/slides/python-net/hi/aspose.slides.animation/ibehaviorpropertycollection). |
| [`timing`](/slides/python-net/hi/aspose.slides.animation/propertyeffect/timing/) | इफ़ेक्ट व्यवहार के लिए समय निर्धारण गुणधर्मों को दर्शाता है।<br/>            पढ़ें/लिखें [`ITiming`](/slides/python-net/hi/aspose.slides.animation/itiming). |
| [`from_`](/slides/python-net/hi/aspose.slides.animation/propertyeffect/from_/) | एनीमेशन का प्रारंभिक मान निर्दिष्ट करता है।<br/>            पढ़ें/लिखें **str**. |
| [`to`](/slides/python-net/hi/aspose.slides.animation/propertyeffect/to/) | एनीमेशन के अंत मान को निर्दिष्ट करता है।<br/>            पढ़ें/लिखें **str**. |
| [`by`](/slides/python-net/hi/aspose.slides.animation/propertyeffect/by/) | एनीमेशन के लिए सापेक्ष ऑफ़सेट मान निर्दिष्ट करता है।<br/>            एनीमेशन के प्रारंभ होने से पहले उसकी स्थिति के सापेक्ष।<br/>            पढ़ें/लिखें **str**. |
| [`value_type`](/slides/python-net/hi/aspose.slides.animation/propertyeffect/value_type/) | एक गुण मान के प्रकार को निर्दिष्ट करता है।<br/>            पढ़ें/लिखें [`PropertyValueType`](/slides/python-net/hi/aspose.slides.animation/propertyvaluetype). |
| [`calc_mode`](/slides/python-net/hi/aspose.slides.animation/propertyeffect/calc_mode/) | एनीमेशन के लिए इंटरपोलेशन मोड को निर्दिष्ट करता है।<br/>            पढ़ें/लिखें [`PropertyCalcModeType`](/slides/python-net/hi/aspose.slides.animation/propertycalcmodetype). |
| [`points`](/slides/python-net/hi/aspose.slides.animation/propertyeffect/points/) | एनीमेशन के बिंदुओं को निर्दिष्ट करता है।<br/>            पढ़ें/लिखें [`IPointCollection`](/slides/python-net/hi/aspose.slides.animation/ipointcollection). |
