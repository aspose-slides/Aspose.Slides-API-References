## IBehavior क्लास

इफ़ेक्ट के बेस क्लास व्यवहार को दर्शाता है।

IBehavior प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`accumulate`](/slides/python-net/hi/aspose.slides.animation/ibehavior/accumulate/) | दर्शाता है कि एनीमेशन व्यवहार संचयी हैं या नहीं।<br/>            पढ़ें/लिखें [`NullableBool`](/slides/python-net/hi/aspose.slides/nullablebool). |
| [`additive`](/slides/python-net/hi/aspose.slides.animation/ibehavior/additive/) | दर्शाता है कि वर्तमान एनीमेशन व्यवहार अन्य चल रहे एनीमेशन के साथ मिलाया गया है या नहीं।<br/>            पढ़ें/लिखें [`BehaviorAdditiveType`](/slides/python-net/hi/aspose.slides.animation/behavioradditivetype). |
| [`properties`](/slides/python-net/hi/aspose.slides.animation/ibehavior/properties/) | व्यवहार की प्रॉपर्टी को दर्शाता है।<br/>            केवल पढ़ें [`IBehaviorPropertyCollection`](/slides/python-net/hi/aspose.slides.animation/ibehaviorpropertycollection). |
| [`timing`](/slides/python-net/hi/aspose.slides.animation/ibehavior/timing/) | इफ़ेक्ट व्यवहार के लिए टाइमिंग गुणों को दर्शाता है।<br/>            पढ़ें/लिखें [`ITiming`](/slides/python-net/hi/aspose.slides.animation/itiming). |
