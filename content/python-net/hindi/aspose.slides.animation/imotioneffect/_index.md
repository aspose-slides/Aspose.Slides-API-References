## IMotionEffect क्लास

इफ़ेक्ट के मोशन इफ़ेक्ट व्यवहार का प्रतिनिधित्व करता है।

IMotionEffect प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| Property | Description |
| :- | :- |
| [`from_address`](/slides/python-net/hi/aspose.slides.animation/imotioneffect/from_address/) | एनिमेशन को शुरू करने के लिए एक x/y निर्देशांक निर्दिष्ट करता है (प्रतिशत में)।<br/>पढ़ें/लिखें [`PointF`](/slides/python-net/hi/aspose.slides/pointf)। |
| [`to`](/slides/python-net/hi/aspose.slides.animation/imotioneffect/to/) | एनिमेशन मोशन इफ़ेक्ट के लिए लक्ष्य स्थान निर्दिष्ट करता है (प्रतिशत में)।<br/>पढ़ें/लिखें [`PointF`](/slides/python-net/hi/aspose.slides/pointf)। |
| [`by`](/slides/python-net/hi/aspose.slides.animation/imotioneffect/by/) | एनिमेशन के लिए सापेक्ष ऑफ़सेट मान का वर्णन करता है (प्रतिशत में)।<br/>पढ़ें/लिखें [`PointF`](/slides/python-net/hi/aspose.slides/pointf)। |
| [`rotation_center`](/slides/python-net/hi/aspose.slides.animation/imotioneffect/rotation_center/) | एक मोशन पाथ को X कोण से घुमा करने के लिए उपयोग किए जाने वाले घूर्णन के केंद्र का वर्णन करता है।<br/>पढ़ें/लिखें [`PointF`](/slides/python-net/hi/aspose.slides/pointf)। |
| [`origin`](/slides/python-net/hi/aspose.slides.animation/imotioneffect/origin/) | निर्दिष्ट करता है कि मोशन पाथ की उत्पत्ति किसके सापेक्ष है, जैसे स्लाइड का लेआउट, या पैरेंट।<br/>पढ़ें/लिखें [`MotionOriginType`](/slides/python-net/hi/aspose.slides.animation/motionorigintype)। |
| [`path`](/slides/python-net/hi/aspose.slides.animation/imotioneffect/path/) | एनिमेशन मोशन के लिए निर्देशांक द्वारा अनुसरण किए जाने वाले पाथ प्रिमिटिव को निर्दिष्ट करता है।<br/>पढ़ें/लिखें [`IMotionPath`](/slides/python-net/hi/aspose.slides.animation/imotionpath)। |
| [`path_edit_mode`](/slides/python-net/hi/aspose.slides.animation/imotioneffect/path_edit_mode/) | आकार को स्थानांतरित करने पर मोशन पाथ कैसे चलता है, यह निर्दिष्ट करता है।<br/>पढ़ें/लिखें [`MotionPathEditMode`](/slides/python-net/hi/aspose.slides.animation/motionpatheditmode)। |
| [`angle`](/slides/python-net/hi/aspose.slides.animation/imotioneffect/angle/) | मोशन पाथ के सापेक्ष कोण का वर्णन करता है।<br/>पढ़ें/लिखें **float**। |
