## IMotionEffect क्लास

इफ़ेक्ट के मोशन इफ़ेक्ट व्यवहार का प्रतिनिधित्व करता है।

IMotionEffect प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`from_address`](/slides/python-net/hi/aspose.slides.animation/imotioneffect/from_address/) | एनिमेशन शुरू करने के लिए x/y निर्देशांक निर्दिष्ट करता है (प्रतिशत में)। <br/>            पढ़ें/लिखें **aspose.slides.PointF**. |
| [`to`](/slides/python-net/hi/aspose.slides.animation/imotioneffect/to/) | एनिमेशन मोशन इफ़ेक्ट के लिए लक्ष्य स्थान निर्दिष्ट करता है (प्रतिशत में)।<br/>            पढ़ें/लिखें **aspose.slides.PointF**. |
| [`by`](/slides/python-net/hi/aspose.slides.animation/imotioneffect/by/) | एनिमेशन के लिए सापेक्ष ऑफसेट मान का वर्णन करता है (प्रतिशत में)।<br/>            पढ़ें/लिखें **aspose.slides.PointF**. |
| [`rotation_center`](/slides/python-net/hi/aspose.slides.animation/imotioneffect/rotation_center/) | एक मोशन पाथ को X कोण द्वारा घुमाने के लिए उपयोग किए जाने वाले रोटेशन के केंद्र का वर्णन करता है।<br/>            पढ़ें/लिखें **aspose.slides.PointF**. |
| [`origin`](/slides/python-net/hi/aspose.slides.animation/imotioneffect/origin/) | स्लाइड के लेआउट या पैरेंट जैसी वस्तु के सापेक्ष मोशन पाथ का मूल क्या है, यह निर्दिष्ट करता है।<br/>            पढ़ें/लिखें [`MotionOriginType`](/slides/python-net/hi/aspose.slides.animation/motionorigintype). |
| [`path`](/slides/python-net/hi/aspose.slides.animation/imotioneffect/path/) | एनिमेशन मोशन के लिए निर्देशांक द्वारा अनुसरण किए जाने वाले पाथ प्रिमिटिव को निर्दिष्ट करता है।<br/>            पढ़ें/लिखें [`IMotionPath`](/slides/python-net/hi/aspose.slides.animation/imotionpath). |
| [`path_edit_mode`](/slides/python-net/hi/aspose.slides.animation/imotioneffect/path_edit_mode/) | शेप के स्थानांतरित होने पर मोशन पाथ कैसे चलता है, यह निर्दिष्ट करता है।<br/>            पढ़ें/लिखें [`MotionPathEditMode`](/slides/python-net/hi/aspose.slides.animation/motionpatheditmode). |
| [`angle`](/slides/python-net/hi/aspose.slides.animation/imotioneffect/angle/) | मोशन पाथ का सापेक्ष कोण का वर्णन करता है।<br/>            पढ़ें/लिखें **float**. |
