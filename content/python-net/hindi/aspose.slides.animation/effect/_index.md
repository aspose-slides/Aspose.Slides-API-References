## Effect क्लास

एनिमेशन इफ़ेक्ट को दर्शाता है।

Effect प्रकार निम्नलिखित सदस्यों को प्रकट करता है:

## गुण

| Property | Description |
| :- | :- |
| [`sequence`](/slides/python-net/hi/aspose.slides.animation/effect/sequence/) | इफ़ेक्ट के लिए एक अनुक्रम पुनः देता है।<br/>            केवल पढ़ने योग्य [`ISequence`](/slides/python-net/hi/aspose.slides.animation/isequence). |
| [`text_animation`](/slides/python-net/hi/aspose.slides.animation/effect/text_animation/) | TextAnimation<br/>            केवल पढ़ने योग्य [`ITextAnimation`](/slides/python-net/hi/aspose.slides.animation/itextanimation). |
| [`preset_class_type`](/slides/python-net/hi/aspose.slides.animation/effect/preset_class_type/) | इफ़ेक्ट का वर्ग परिभाषित करता है।<br/>            पढ़ने/लिखने योग्य [`EffectPresetClassType`](/slides/python-net/hi/aspose.slides.animation/effectpresetclasstype). |
| [`type`](/slides/python-net/hi/aspose.slides.animation/effect/type/) | इफ़ेक्ट का प्रकार परिभाषित करता है।<br/>            पढ़ने/लिखने योग्य [`EffectType`](/slides/python-net/hi/aspose.slides.animation/effecttype). |
| [`subtype`](/slides/python-net/hi/aspose.slides.animation/effect/subtype/) | इफ़ेक्ट का उपप्रकार परिभाषित करता है।<br/>            पढ़ने/लिखने योग्य [`EffectSubtype`](/slides/python-net/hi/aspose.slides.animation/effectsubtype). |
| [`behaviors`](/slides/python-net/hi/aspose.slides.animation/effect/behaviors/) | इफ़ेक्ट के लिए व्यवहार का संग्रह पुनः देता है।<br/>            पढ़ने/लिखने योग्य [`IBehaviorCollection`](/slides/python-net/hi/aspose.slides.animation/ibehaviorcollection). |
| [`timing`](/slides/python-net/hi/aspose.slides.animation/effect/timing/) | इफ़ेक्ट के लिये समय मान परिभाषित करता है।<br/>            पढ़ने/लिखने योग्य [`ITiming`](/slides/python-net/hi/aspose.slides.animation/itiming). |
| [`target_shape`](/slides/python-net/hi/aspose.slides.animation/effect/target_shape/) | इफ़ेक्ट के लिये लक्ष्य आकार पुनः देता है।<br/>            केवल पढ़ने योग्य [`IShape`](/slides/python-net/hi/aspose.slides/ishape). |
| [`sound`](/slides/python-net/hi/aspose.slides.animation/effect/sound/) | इफ़ेक्ट के लिये अंतर्निहित ध्वनि परिभाषित करता है।<br/>            पढ़ने/लिखने योग्य [`IAudio`](/slides/python-net/hi/aspose.slides/iaudio). |
| [`stop_previous_sound`](/slides/python-net/hi/aspose.slides.animation/effect/stop_previous_sound/) | यह गुण निर्धारित करता है कि एनीमेशन इफ़ेक्ट पहले की ध्वनि को रोकता है या नहीं।<br/>            पढ़ने/लिखने योग्य **bool**. |
| [`after_animation_type`](/slides/python-net/hi/aspose.slides.animation/effect/after_animation_type/) | इफ़ेक्ट के लिये बाद की एनीमेशन प्रकार परिभाषित करता है।<br/>            पढ़ने/लिखने योग्य [`Effect.after_animation_type`](/slides/python-net/hi/aspose.slides.animation/effect/after_animation_type). |
| [`after_animation_color`](/slides/python-net/hi/aspose.slides.animation/effect/after_animation_color/) | इफ़ेक्ट के लिये बाद की एनीमेशन रंग परिभाषित करता है।<br/>            पढ़ने/लिखने योग्य [`IColorFormat`](/slides/python-net/hi/aspose.slides/icolorformat). |
| [`animate_text_type`](/slides/python-net/hi/aspose.slides.animation/effect/animate_text_type/) | इफ़ेक्ट के लिये एनीमेट टेक्स्ट प्रकार परिभाषित करता है। <br/>            आकार का टेक्स्ट अक्षर द्वारा, शब्द द्वारा या सभी एक साथ एनीमेट किया जा सकता है।<br/>            पढ़ने/लिखने योग्य [`Effect.animate_text_type`](/slides/python-net/hi/aspose.slides.animation/effect/animate_text_type). |
| [`delay_between_text_parts`](/slides/python-net/hi/aspose.slides.animation/effect/delay_between_text_parts/) | एनीमेटेड टेक्स्ट भागों (शब्द या अक्षर) के बीच देरी परिभाषित करता है।<br/>            एक सकारात्मक मान इफ़ेक्ट अवधि के प्रतिशत को निर्दिष्ट करता है।<br/>            एक नकारात्मक मान सेकंड में देरी को निर्दिष्ट करता है।<br/>            पढ़ने/लिखने योग्य **float**. |
