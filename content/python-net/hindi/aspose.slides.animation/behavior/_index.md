## Behavior वर्ग

इफ़ेक्ट के बेस वर्ग व्यवहार को दर्शाता है।

Behavior प्रकार निम्नलिखित सदस्य प्रदर्शित करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`accumulate`](/slides/python-net/hi/aspose.slides.animation/behavior/accumulate/) | यह दर्शाता है कि एनीमेशन व्यवहार संचित हैं या नहीं।<br/>            पढ़ें/लिखें [`NullableBool`](/slides/python-net/hi/aspose.slides/nullablebool). |
| [`additive`](/slides/python-net/hi/aspose.slides.animation/behavior/additive/) | यह दर्शाता है कि वर्तमान एनीमेशन व्यवहार अन्य चल रहे एनीमेशन के साथ संयुक्त है या नहीं।<br/>            पढ़ें/लिखें [`BehaviorAdditiveType`](/slides/python-net/hi/aspose.slides.animation/behavioradditivetype). |
| [`properties`](/slides/python-net/hi/aspose.slides.animation/behavior/properties/) | यह व्यवहार की गुणधर्मों को दर्शाता है।<br/>            केवल-पढ़ें [`IBehaviorPropertyCollection`](/slides/python-net/hi/aspose.slides.animation/ibehaviorpropertycollection). |
| [`timing`](/slides/python-net/hi/aspose.slides.animation/behavior/timing/) | यह इफ़ेक्ट व्यवहार के समय संबंधी गुणधर्मों को दर्शाता है।<br/>            पढ़ें/लिखें [`ITiming`](/slides/python-net/hi/aspose.slides.animation/itiming). |
