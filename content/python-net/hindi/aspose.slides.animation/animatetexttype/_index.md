## AnimateTextType एनीमरेशन

एनीमेशन प्रभाव के एनीमेट टेक्स्ट टाइप का प्रतिनिधित्व करता है।

AnimateTextType प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| ALL_AT_ONCE | एक बार में सभी टेक्स्ट को एनीमेट करें। |
| BY_WORD | शब्द द्वारा टेक्स्ट को एनीमेट करें। |
| BY_LETTER | अक्षर द्वारा टेक्स्ट को एनीमेट करें। |
