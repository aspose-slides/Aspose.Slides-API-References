## x प्रॉपर्टी
आकृति के ऊपरी बाएँ कोने के x-निर्देशांक को प्राप्त करता है या सेट करता है, जो पॉइंट्स में मापा जाता है.
            पढ़ें/लिखें **float**.


### टिप्पणियाँ

वापस किया गया मान हमेशा परिभाषित होता है और कभी भी **float** नहीं होता.
            आवंटित किया गया मान भी परिभाषित होना चाहिए; केवल `RawFrame` इंस्टेंस के गुणों को **float** आवंटित करें.

### परिभाषा:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
