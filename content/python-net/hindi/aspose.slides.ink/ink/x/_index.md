## x गुण
आकार के ऊपर-बाएँ कोने के x-निर्देशांक को प्राप्त करता है या सेट करता है, जिसे पॉइंट में मापा जाता है.
            पढ़ें/लिखें **float**.


### टिप्पणियाँ

वापस किया गया मान हमेशा परिभाषित होता है और कभी भी **float** नहीं होता।
            नियुक्त मान भी परिभाषित होना चाहिए; **float** को केवल `RawFrame` इंस्टेंस की गुणों को ही असाइन करें।

### परिभाषा:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
