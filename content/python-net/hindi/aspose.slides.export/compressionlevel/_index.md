## CompressionLevel enumeration

OpenXML फ़ाइल के लिए ZIP संपीड़न स्तर निर्दिष्ट करता है।  
उच्च स्तर बेहतर संपीड़न प्रदान करते हैं लेकिन धीमी प्रोसेसिंग की कीमत पर।

CompressionLevel प्रकार निम्नलिखित सदस्य उजागर करता है:

## Fields

| फ़ील्ड | विवरण |
| :- | :- |
| NONE | कोई संपीड़न लागू नहीं होता। फ़ाइलें जैसा है वैसा ही संग्रहीत की जाती हैं। |
| LEVEL1 | न्यूनतम संपीड़न अनुपात के साथ सबसे तेज़ संपीड़न। |
| LEVEL2 | [`CompressionLevel.LEVEL1`](/slides/python-net/hi/aspose.slides.export/compressionlevel/LEVEL1) की तुलना में थोड़ा बेहतर संपीड़न अनुपात के साथ तेज़ संपीड़न। |
| LEVEL3 | [`CompressionLevel.LEVEL2`](/slides/python-net/hi/aspose.slides.export/compressionlevel/LEVEL2) की तुलना में बेहतर संपीड़न प्रदान करता है, मध्यम प्रदर्शन असर के साथ। |
| LEVEL4 | [`CompressionLevel.LEVEL3`](/slides/python-net/hi/aspose.slides.export/compressionlevel/LEVEL3) की तुलना में बेहतर संपीड़न प्रदान करता है। |
| LEVEL5 | [`CompressionLevel.LEVEL4`](/slides/python-net/hi/aspose.slides.export/compressionlevel/LEVEL4) की तुलना में अतिरिक्त प्रोसेसिंग समय के साथ सुधरता संपीड़न प्रदान करता है। |
| LEVEL6 | मानक संपीड़न, जो संपीड़न गति और फ़ाइल आकार के बीच अच्छा संतुलन प्रदान करता है।<br/>डिफ़ॉल्ट संपीड़न स्तर। |
| LEVEL7 | [`CompressionLevel.LEVEL6`](/slides/python-net/hi/aspose.slides.export/compressionlevel/LEVEL6) की तुलना में उच्च संपीड़न प्रदान करता है, लेकिन धीमी प्रोसेसिंग के साथ। |
| LEVEL8 | [`CompressionLevel.LEVEL7`](/slides/python-net/hi/aspose.slides.export/compressionlevel/LEVEL7) की तुलना में उच्च संपीड़न प्रदान करता है। |
| LEVEL9 | अधिकतम संपीड़न। सबसे छोटे फ़ाइल आकार को सबसे धीमी प्रोसेसिंग गति के साथ उत्पन्न करता है। |
