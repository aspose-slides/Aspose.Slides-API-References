## SvgEvent एन्यूमरेशन

SVG आकृति के विकल्प का प्रतिनिधित्व करता है।

SvgEvent प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| ON_FOCUS_IN | जब कोई तत्व फ़ोकस प्राप्त करता है, जैसे कि जब कोई पाठ चयनित हो जाता है, तब यह घटित होता है। |
| ON_FOCUS_OUT | जब कोई तत्व फ़ोकस खो देता है, जैसे कि जब कोई पाठ चयन से मुक्त हो जाता है, तब यह घटित होता है। |
| ON_ACTIVATE | जब कोई तत्व सक्रिय किया जाता है, उदाहरण के लिए माउस क्लिक या कुंजी दबाव के माध्यम से, तब यह घटित होता है। |
| ON_CLICK | जब पॉइंटिंग डिवाइस बटन को किसी तत्व पर क्लिक किया जाता है, तब यह घटित होता है। |
| ON_MOUSE_DOWN | जब पॉइंटिंग डिवाइस बटन को किसी तत्व पर दबाया जाता है, तब यह घटित होता है। |
| ON_MOUSE_UP | जब पॉइंटिंग डिवाइस बटन को किसी तत्व पर रिलीज़ किया जाता है, तब यह घटित होता है। |
| ON_MOUSE_OVER | जब पॉइंटिंग डिवाइस को किसी तत्व पर ले जाया जाता है, तब यह घटित होता है। |
| ON_MOUSE_MOVE | जब पॉइंटिंग डिवाइस को किसी तत्व के ऊपर होते हुए ले जाया जाता है, तब यह घटित होता है। |
| ON_MOUSE_OUT | जब पॉइंटिंग डिवाइस को किसी तत्व से दूर ले जाया जाता है, तब यह घटित होता है। |
| ON_LOAD | जब उपयोगकर्ता एजेंट ने तत्व और उसके उत्तराधिकारी तथा सभी संदर्भित संसाधनों को पूरी तरह पार्स कर लिया हो, जो इसे रेंडर करने के लिए आवश्यक हैं, तब यह घटित होता है। |
| ON_UNLOAD | जब DOM कार्यान्वयन किसी दस्तावेज़ को विंडो या फ्रेम से हटाता है, तब यह घटित होता है। केवल सबसे बाहरी svg तत्वों पर लागू है। |
| ON_ABORT | जब पृष्ठ लोडिंग को तब रोक दिया जाता है जब कोई तत्व पूरी तरह लोड होने की अनुमति नहीं पाता, तब यह घटित होता है। |
| ON_ERROR | जब कोई तत्व सही तरीके से लोड नहीं होता या स्क्रिप्ट निष्पादन के दौरान कोई त्रुटि होती है, तब यह घटित होता है। |
| ON_RESIZE | जब दस्तावेज़ दृश्य का आकार बदल रहा हो, तब यह घटित होता है। केवल सबसे बाहरी svg तत्वों पर लागू है। |
| ON_SCROLL | जब दस्तावेज़ दृश्य को X या Y या दोनों अक्षों के साथ स्थानांतरित किया जा रहा हो, तब यह घटित होता है। केवल सबसे बाहरी svg तत्वों पर लागू है। |
| ON_ZOOM | जब दस्तावेज़ दृश्य का ज़ूम स्तर बदला जा रहा हो, तब यह घटित होता है। केवल सबसे बाहरी svg तत्वों पर लागू है। |
| ON_BEGIN | जब एनीमेशन तत्व शुरू होता है, तब यह घटित होता है। |
| ON_END | जब एनीमेशन तत्व समाप्त होता है, तब यह घटित होता है। |
| ON_REPEAT | जब एनीमेशन तत्व दोहराता है, तब यह घटित होता है। |
