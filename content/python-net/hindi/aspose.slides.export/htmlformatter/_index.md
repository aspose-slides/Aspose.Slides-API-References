## HtmlFormatter क्लास

HTML फ़ाइल टेम्पलेट का प्रतिनिधित्व करता है।

HtmlFormatter प्रकार निम्नलिखित सदस्य प्रकट करता है:

## मेथड्स

| मेथड | विवरण |
| :- | :- |
| [`create_document_formatter(css, show_slide_title)`](/slides/python-net/hi/aspose.slides.export/htmlformatter/create_document_formatter/#str-bool) | एक सरल दस्तावेज़ दृश्य के लिए HTML फ़ॉर्मेटर बनाता और लौटाता है, जो स्लाइड्स की क्रमशः नीचे नीचे रखी हुई श्रृंखलाओं से बनता है। |
| [`create_slide_show_formatter(css, show_slide_title)`](/slides/python-net/hi/aspose.slides.export/htmlformatter/create_slide_show_formatter/#str-bool) | एक सरल स्लाइड शो HTML के लिए HTML फ़ॉर्मेटर बनाता और लौटाता है, जो स्लाइड्स को एक के बाद एक दिखाता है। |
| [`create_custom_formatter(formatting_controller)`](/slides/python-net/hi/aspose.slides.export/htmlformatter/create_custom_formatter/#ihtmlformattingcontroller) | कस्टम कॉलबैक-चालित HTML जनरेशन के लिए HTML फ़ॉर्मेटर बनाता और लौटाता है। |
