## IPptxOptions क्लास

प्रस्तुति (OpenXml) फ़ाइलों को सहेजने के विकल्प का प्रतिनिधित्व करता है (PPTX, PPSX, POTX, PPTM, PPSM, POTM)।

IPptxOptions प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| Property | Description |
| :- | :- |
| [`conformance`](/slides/python-net/hi/aspose.slides.export/ipptxoptions/conformance/) | निर्दिष्ट करता है कि प्रस्तुति दस्तावेज़ किस अनुरूपता वर्ग के अनुरूप है।<br/>            डिफ़ॉल्ट मान है [`Conformance.ECMA_376_2006`](/slides/python-net/hi/aspose.slides.export/conformance/ECMA_376_2006) |
| [`zip_64_mode`](/slides/python-net/hi/aspose.slides.export/ipptxoptions/zip_64_mode/) | निर्दिष्ट करता है कि प्रस्तुति दस्तावेज़ के लिए ZIP64 प्रारूप उपयोग किया गया है या नहीं।<br/>            डिफ़ॉल्ट मान है [`Zip64Mode.IF_NECESSARY`](/slides/python-net/hi/aspose.slides.export/zip64mode/IF_NECESSARY) |
| [`refresh_thumbnail`](/slides/python-net/hi/aspose.slides.export/ipptxoptions/refresh_thumbnail/) | निर्दिष्ट करता है कि प्रस्तुति थंबनेल को रीफ़्रेश किया जाएगा या नहीं।<br/>            पढ़ने/लिखने योग्य **bool**।<br/>            डिफ़ॉल्ट मान **true** है। |
| [`compression_level`](/slides/python-net/hi/aspose.slides.export/ipptxoptions/compression_level/) | निर्दिष्ट करता है कि प्रस्तुति दस्तावेज़ को सहेजते समय किस संपीड़न स्तर का उपयोग किया जाता है।<br/>            डिफ़ॉल्ट मान है [`CompressionLevel.LEVEL6`](/slides/python-net/hi/aspose.slides.export/compressionlevel/LEVEL6)। |
