## ImagePixelFormat एन्यूमरेशन

जेनरेट की गई छवियों के लिए पिक्सेल फ़ॉर्मेट निर्दिष्ट करता है।

ImagePixelFormat टाइप निम्नलिखित सदस्यों को उजागर करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| FORMAT_1BPP_INDEXED | 1 बिट प्रति पिक्सेल, इंडेक्स्ड। |
| FORMAT_4BPP_INDEXED | 4 बिट प्रति पिक्सेल, इंडेक्स्ड। |
| FORMAT_8BPP_INDEXED | 8 बिट प्रति पिक्सेल, इंडेक्स्ड। |
| FORMAT_24BPP_RGB | 24 बिट प्रति पिक्सेल, RGB। |
| FORMAT_32BPP_ARGB | 32 बिट प्रति पिक्सेल, ARGB। |
