## HandoutType एन्यूमरेशन

निर्देश देता है कि किसी पृष्ठ पर कितनी स्लाइडें और किस क्रम में रखी जाएँगी।

HandoutType टाइप निम्नलिखित सदस्यों को उजागर करता है:

## फ़ील्ड्स

| Field | विवरण |
| :- | :- |
| HANDOUTS1 | प्रति पृष्ठ एक स्लाइड। |
| HANDOUTS2 | प्रति पृष्ठ दो स्लाइडें। |
| HANDOUTS3 | प्रति पृष्ठ तीन स्लाइडें। |
| HANDOUTS_4_HORIZONTAL | प्रति पृष्ठ चार स्लाइडें, क्षैतिज क्रम में। |
| HANDOUTS_4_VERTICAL | प्रति पृष्ठ चार स्लाइडें, लंबवत क्रम में। |
| HANDOUTS_6_HORIZONTAL | प्रति पृष्ठ छह स्लाइडें, क्षैतिज क्रम में। |
| HANDOUTS_6_VERTICAL | प्रति पृष्ठ छह स्लाइडें, लंबवत क्रम में। |
| HANDOUTS_9_HORIZONTAL | प्रति पृष्ठ नौ स्लाइडें, क्षैतिज क्रम में। |
| HANDOUTS_9_VERTICAL | प्रति पृष्ठ नौ स्लाइडें, लंबवत क्रम में। |
