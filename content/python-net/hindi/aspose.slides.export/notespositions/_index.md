## NotesPositions एन्यूमरेशन

नोट्स को निर्यातित दस्तावेज़ में रेंडर करने के नियम का प्रतिनिधित्व करता है

NotesPositions प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| NONE | निर्दिष्ट करता है कि नोट्स बिल्कुल भी प्रदर्शित नहीं होने चाहिए। |
| BOTTOM_FULL | निर्दिष्ट करता है कि नोट्स को अतिरिक्त पृष्ठों का उपयोग करके पूरी तरह से प्रदर्शित किया जाना चाहिए जब आवश्यक हो। |
| BOTTOM_TRUNCATED | निर्दिष्ट करता है कि नोट्स केवल एक पृष्ठ में प्रदर्शित किए जाने चाहिए। |
