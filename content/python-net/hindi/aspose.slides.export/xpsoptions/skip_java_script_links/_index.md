## skip_java_script_links प्रॉपर्टी
प्रस्तुति को सहेजते समय जावास्क्रिप्ट कॉल वाले हाइपरलिंक को छोड़ना है या नहीं, यह निर्धारित करता है। 
            पढ़ने/लिखने योग्य **bool**. डिफ़ॉल्ट मान **false** है।


### टिप्पणियाँ

जब इस प्रॉपर्टी को **true** पर सेट किया जाता है, जावास्क्रिप्ट कॉल वाले हाइपरलिंक को सहेजते समय अनदेखा किया जाएगा।


जब इस प्रॉपर्टी को **false** पर सेट किया जाता है, सभी हाइपरलिंक सहेजे जाएंगे।
