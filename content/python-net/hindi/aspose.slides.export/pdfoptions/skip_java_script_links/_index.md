## skip_java_script_links गुण
Specifies whether to skip hyperlinks with JavaScript calls when saving the presentation. 
पढ़ें/लिखें **bool**. डिफ़ॉल्ट मान **false** है .

### टिप्पणियाँ

जब यह गुण **true** , हाइपरलिंक JavaScript कॉल वाले को सहेजते समय अनदेखा किया जाएगा।

जब यह गुण **false** , सभी हाइपरलिंक सहेजे जाएंगे।
