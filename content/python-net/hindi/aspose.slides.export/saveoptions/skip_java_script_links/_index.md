## skip_java_script_links प्रॉपर्टी
प्रस्तुति को सहेजते समय JavaScript कॉल्स वाले हाइपरलिंक्स को छोड़ना है या नहीं, यह निर्धारित करता है। 
            पढ़ें/लिखें **bool**। डिफ़ॉल्ट मान **false** है। 


### टिप्पणी

जब इस प्रॉपर्टी का मान **true** सेट किया जाता है, तो सहेजते समय JavaScript कॉल्स वाले हाइपरलिंक्स को अनदेखा किया जाएगा।


जब इस प्रॉपर्टी का मान **false** सेट किया जाता है, तो सभी हाइपरलिंक्स सहेजे जाएंगे।
