## SaveOptions क्लास

एब्स्ट्रैक्ट क्लास जिसमें विकल्प होते हैं जो नियंत्रित करते हैं कि एक प्रस्तुति कैसे सहेजी जाती है।

SaveOptions प्रकार निम्नलिखित सदस्यों को प्रदान करता है:

## गुण

| Property | Description |
| :- | :- |
| [`warning_callback`](/slides/python-net/hi/aspose.slides.export/saveoptions/warning_callback/) | एक ऑब्जेक्ट को लौटाता है या सेट करता है जो चेतावनियों को प्राप्त करता है और निर्धारित करता है कि लोडिंग प्रक्रिया जारी रहेगी या रद्द कर दी जाएगी।<br/>            पढ़ें/लिखें [`IWarningCallback`](/slides/python-net/hi/aspose.slides.warnings/iwarningcallback). |
| [`progress_callback`](/slides/python-net/hi/aspose.slides.export/saveoptions/progress_callback/) | सहेजने की प्रगति अपडेट को प्रतिशत में दर्शाने वाले कॉलबैक ऑब्जेक्ट को दर्शाता है।<br/>            देखें [`IProgressCallback`](/slides/python-net/hi/aspose.slides/iprogresscallback). |
| [`default_regular_font`](/slides/python-net/hi/aspose.slides.export/saveoptions/default_regular_font/) | स्रोत फ़ॉन्ट नहीं मिलने पर उपयोग किए जाने वाले फ़ॉन्ट को लौटाता है या सेट करता है।<br/>            पढ़ें-लिखें **str**. |
| [`gradient_style`](/slides/python-net/hi/aspose.slides.export/saveoptions/gradient_style/) | ग्रेडिएंट की दृश्य शैली को लौटाता है या सेट करता है।<br/>            पढ़ें/लिखें [`GradientStyle`](/slides/python-net/hi/aspose.slides/gradientstyle). |
| [`skip_java_script_links`](/slides/python-net/hi/aspose.slides.export/saveoptions/skip_java_script_links/) | प्रस्तुति सहेजते समय JavaScript कॉल वाले हाइपरलिंक को छोड़ने चाहिए या नहीं, यह निर्दिष्ट करता है। <br/>            पढ़ें/लिखें **bool**. डिफ़ॉल्ट मान **false** है। |
