## IGifOptions क्लास

GIF निर्यात विकल्पों का प्रतिनिधित्व करता है।

IGifOptions टाइप निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`frame_size`](/slides/python-net/hi/aspose.slides.export/igifoptions/frame_size/) | फ़्रेम आकार प्राप्त करता है या सेट करता है। |
| [`export_hidden_slides`](/slides/python-net/hi/aspose.slides.export/igifoptions/export_hidden_slides/) | निर्धारित करता है कि छिपी हुई स्लाइड्स निर्यात की जाएँगी या नहीं।<br/>            डिफ़ॉल्ट मान false है। |
| [`transition_fps`](/slides/python-net/hi/aspose.slides.export/igifoptions/transition_fps/) | ट्रांज़िशन FPS [फ़्रेम/सेकंड] प्राप्त करता है या सेट करता है।<br/>            डिफ़ॉल्ट मान 25 है। |
| [`default_delay`](/slides/python-net/hi/aspose.slides.export/igifoptions/default_delay/) | डिफ़ॉल्ट देरी समय [ms] प्राप्त करता है या सेट करता है। यदि [`ISlideShowTransition.advance_after_time`](/slides/python-net/hi/aspose.slides/islideshowtransition/advance_after_time) सेट नहीं है तो यह मान उपयोग किया जाएगा।<br/>            डिफ़ॉल्ट मान 1000 है। |
| [`warning_callback`](/slides/python-net/hi/aspose.slides.export/igifoptions/warning_callback/) |  |
