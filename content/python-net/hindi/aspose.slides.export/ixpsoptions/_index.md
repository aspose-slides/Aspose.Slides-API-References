## IXpsOptions क्लास

XPS स्वरूप में प्रस्तुति को सहेजने के तरीके को नियंत्रित करने वाले विकल्प प्रदान करता है।

IXpsOptions प्रकार निम्नलिखित सदस्यों को प्रकट करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`save_metafiles_as_png`](/slides/python-net/hi/aspose.slides.export/ixpsoptions/save_metafiles_as_png/) | True, प्रस्तुति में उपयोग किए गए सभी मेटाफाइलों को PNG छवियों में बदलने के लिए।<br/>            Read/write **bool**. |
| [`draw_slides_frame`](/slides/python-net/hi/aspose.slides.export/ixpsoptions/draw_slides_frame/) | True, प्रत्येक स्लाइड के चारों ओर काली सीमा खींचने के लिए।<br/>             Read/write **bool**. |
| [`show_hidden_slides`](/slides/python-net/hi/aspose.slides.export/ixpsoptions/show_hidden_slides/) | उत्पन्न दस्तावेज़ को छिपी स्लाइडें शामिल करनी हैं या नहीं, यह निर्दिष्ट करता है।<br/>            Default is `false`. |
