## ITextToHtmlConversionOptions क्लास

Pptx टेक्स्ट से HTML निकालने के विकल्प।

ITextToHtmlConversionOptions टाइप निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| प्रॉपर्टी | विवरण |
| :- | :- |
| [`add_clipboard_fragment_header`](/slides/python-net/hi/aspose.slides.export/itexttohtmlconversionoptions/add_clipboard_fragment_header/) | मूल्य को वापस देता है या सेट करता है, यह दर्शाता है कि क्या क्लिपबोर्ड हेडर जोड़े जाने चाहिए।<br/>            पढ़ें/लिखें **bool**. |
| [`text_inheritance_limit`](/slides/python-net/hi/aspose.slides.export/itexttohtmlconversionoptions/text_inheritance_limit/) | इनहेरेंट गहराई को वापस देता है या सेट करता है, टेक्स्ट प्रॉपर्टीज़ के लिए।<br/>            पढ़ें/लिखें [`ITextToHtmlConversionOptions.text_inheritance_limit`](/slides/python-net/hi/aspose.slides.export/itexttohtmlconversionoptions/text_inheritance_limit). |
| [`link_embed_controller`](/slides/python-net/hi/aspose.slides.export/itexttohtmlconversionoptions/link_embed_controller/) | बाहरी ऑब्जेक्ट को कैसे संग्रहीत किया जाएगा, इसे नियंत्रित करने वाला कॉलबैक ऑब्जेक्ट को वापस देता है या सेट करता है।<br/>            पढ़ें/लिखें [`ILinkEmbedController`](/slides/python-net/hi/aspose.slides.export/ilinkembedcontroller). |
| [`encoding_name`](/slides/python-net/hi/aspose.slides.export/itexttohtmlconversionoptions/encoding_name/) | HTML एन्कोडिंग नाम को वापस देता है या सेट करता है।<br/>            यह मान जेनरेटेड HTML फ़ाइल में सहेजा जाएगा, लेकिन यह कॉलर पर निर्भर है कि फ़ाइल इस एन्कोडिंग में सहेजी जाए।<br/>            पढ़ें/लिखें **str**. |
