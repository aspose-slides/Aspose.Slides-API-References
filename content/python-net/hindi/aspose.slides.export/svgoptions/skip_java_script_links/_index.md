## skip_java_script_links प्रॉपर्टी
Specifies whether to skip hyperlinks with JavaScript calls when saving the presentation. 
            पढ़ें/लिखें **bool**. डिफ़ॉल्ट मान **false** है। 


### टिप्पणियाँ

जब इस प्रॉपर्टी को **true** , हाइपरलिंक्स के साथ JavaScript कॉल को सहेजते समय अनदेखा किया जाएगा।


जब इस प्रॉपर्टी को **false** , सभी हाइपरलिंक्स सहेजे जाएंगे।
