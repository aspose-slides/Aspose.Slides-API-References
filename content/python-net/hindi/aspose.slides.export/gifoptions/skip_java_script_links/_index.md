## skip_java_script_links प्रॉपर्टी
निर्दिष्ट करता है कि प्रस्तुति सहेजते समय JavaScript कॉल वाले हाइपरलिंक को छोड़ दिया जाए या नहीं। 
            पढ़ें/लिखें **bool**. डिफ़ॉल्ट मान **false** . 


### टिप्पणी

जब इस प्रॉपर्टी को **true** पर सेट किया जाता है, तो JavaScript कॉल वाले हाइपरलिंक को सहेजते समय अनदेखा किया जाएगा।


जब इस प्रॉपर्टी को **false** पर सेट किया जाता है, तो सभी हाइपरलिंक सहेजे जाएंगे।
