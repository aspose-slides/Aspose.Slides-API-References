## skip_java_script_links प्रॉपर्टी
प्रेजेंटेशन को सहेजते समय JavaScript कॉल वाले हाइपरलिंक को छोड़ना है या नहीं, यह निर्धारित करता है। 
            पढ़ें/लिखें **bool**. डिफॉल्ट मान **false** है।

### टिप्पणी

जब इस प्रॉपर्टी को **true** , हाइपरलिंक JavaScript कॉल वाले सहेजते समय अनदेखा कर दिया जाएगा।

जब इस प्रॉपर्टी को **false** , सभी हाइपरलिंक सहेजे जाएंगे।
