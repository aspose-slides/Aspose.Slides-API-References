## SvgExternalFontsHandling एन्यूमरेशन

टेक्स्ट ड्रॉइंग के लिए उपयोग किए जाने वाले बाहरी फ़ॉन्ट को संभालने का एक तरीका दर्शाता है।

SvgExternalFontsHandling प्रकार निम्नलिखित सदस्यों को प्रदर्शित करता है:

## फ़ील्ड

| फ़ील्ड | विवरण |
| :- | :- |
| ADD_LINKS_TO_FONT_FILES | SVG फ़ाइल के स्टाइल सेक्शन में अलग-अलग फ़ॉन्ट फ़ाइलों के लिंक जोड़ें। |
| EMBED | फ़ॉन्ट डेटा को सीधे SVG फ़ाइल में सहेजें। इस विकल्प को उपयोग करने से पहले सभी बाहरी फ़ॉन्ट लाइसेंस समझौतों की जाँच करें। |
| VECTORIZE | बाहरी फ़ॉन्ट का उपयोग करके सभी टेक्स्ट को ग्राफिक्स के रूप में सहेजें। |
