## HtmlGenerator वर्ग

Html जनरेटर।

HtmlGenerator प्रकार निम्नलिखित सदस्य प्रकट करता है:

## गुण

| प्रॉपर्टी | विवरण |
| :- | :- |
| [`slide_image_size`](/slides/python-net/hi/aspose.slides.export/htmlgenerator/slide_image_size/) | स्लाइड छवि आकार लौटाता है.<br/>            केवल-पढ़ने योग्य **aspose.slides.SizeF**. |
| [`slide_image_size_unit`](/slides/python-net/hi/aspose.slides.export/htmlgenerator/slide_image_size_unit/) | स्लाइड छवि आकार निर्दिष्ट करने वाली इकाई लौटाता है.<br/>            केवल-पढ़ने योग्य [`SvgCoordinateUnit`](/slides/python-net/hi/aspose.slides.export/svgcoordinateunit). |
| [`slide_image_size_unit_code`](/slides/python-net/hi/aspose.slides.export/htmlgenerator/slide_image_size_unit_code/) | स्लाइड छवि आकार निर्दिष्ट करने वाली इकाई की css कोड लौटाता है.<br/>            केवल-पढ़ने योग्य **str**. |
| [`previous_slide_index`](/slides/python-net/hi/aspose.slides.export/htmlgenerator/previous_slide_index/) | पहले रेंडर की गई स्लाइड का इंडेक्स लौटाता है या यदि पहले स्लाइड को रेंडर किया जा रहा है तो -1.<br/>            केवल-पढ़ने योग्य **int**. |
| [`slide_index`](/slides/python-net/hi/aspose.slides.export/htmlgenerator/slide_index/) | वर्तमान में रेंडर हो रही स्लाइड का इंडेक्स लौटाता है.<br/>            केवल-पढ़ने योग्य **int**. |
| [`next_slide_index`](/slides/python-net/hi/aspose.slides.export/htmlgenerator/next_slide_index/) | वह स्लाइड इंडेक्स लौटाता है, जिसे वर्तमान स्लाइड के बाद रेंडर किया जाएगा या यदि वर्तमान में अंतिम स्लाइड रेंडर हो रही है तो -1.<br/>            केवल-पढ़ने योग्य **int**. |
