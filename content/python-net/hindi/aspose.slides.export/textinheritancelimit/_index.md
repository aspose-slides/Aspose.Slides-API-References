## TextInheritanceLimit एन्युमरेशन

पाठ गुणों के उत्तराधिकार की गहराई को नियंत्रित करता है।

TextInheritanceLimit प्रकार निम्नलिखित सदस्यों को प्रदर्शित करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| ALL | सभी पाठ गुणों को उत्तराधिकार में लें। |
| TEXT_BOX | केवल TextFrame की शैली से उत्तराधिकार लें। |
| PARAGRAPH_ONLY | केवल पैराग्राफ के लिए परिभाषित गुणों का उपयोग करें। |
