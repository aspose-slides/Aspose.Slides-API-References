## skip_java_script_links प्रॉपर्टी
प्रेजेंटेशन को सहेजते समय जावास्क्रिप्ट कॉल वाले हाइपरलिंक को छोड़ना है या नहीं, यह निर्दिष्ट करता है। 
Read/write **bool**. डिफ़ॉल्ट मान **false** है।


### टिप्पणियां

जब इस प्रॉपर्टी को **true** पर सेट किया जाता है, तो जावास्क्रिप्ट कॉल वाले हाइपरलिंक को सहेजते समय नहीं माना जाएगा।


जब इस प्रॉपर्टी को **false** पर सेट किया जाता है, तो सभी हाइपरलिंक सहेजे जाएँगे।
