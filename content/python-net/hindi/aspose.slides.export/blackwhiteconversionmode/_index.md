## BlackWhiteConversionMode एन्यूमरेशन

स्लाइड्स की छवियों को बिटोनल छवियों में रूपांतरित करने के तरीके को नियंत्रित करने वाले विकल्प प्रदान करता है।

BlackWhiteConversionMode प्रकार निम्नलिखित सदस्य प्रकट करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| DEFAULT | कोई रूपांतरण एल्गोरिदम निर्दिष्ट नहीं करता है। TIFF कोडेक में लागू किया गया एल्गोरिदम उपयोग किया जाएगा। (डिफ़ॉल्ट) |
| DITHERING | डिथरिंग एल्गोरिदम निर्दिष्ट करता है (Floyd-Steinberg)। |
| DITHERING_FLOYD_STEINBERG | Floyd-Steinberg डिथरिंग एल्गोरिदम निर्दिष्ट करता है। |
| AUTO | स्वचालित रूप से गणना किए गए थ्रेशोल्ड एल्गोरिदम (Otsu) को निर्दिष्ट करता है। |
| AUTO_OTSU | स्वचालित रूप से गणना किए गए Otsu के थ्रेशोल्ड एल्गोरिदम को निर्दिष्ट करता है। |
| THRESHOLD25 | स्थैतिक थ्रेशोल्ड एल्गोरिदम (25%) को निर्दिष्ट करता है। |
| THRESHOLD50 | स्थैतिक थ्रेशोल्ड एल्गोरिदम (50%) को निर्दिष्ट करता है। |
| THRESHOLD75 | स्थैतिक थ्रेशोल्ड एल्गोरिदम (75%) को निर्दिष्ट करता है। |
