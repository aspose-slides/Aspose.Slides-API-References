## अनुपालन सूची

वह अनुपालन वर्ग निर्दिष्ट करता है जिससे PresentationML दस्तावेज़ अनुरूप है।

Conformance प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## फ़ील्ड

| फ़ील्ड | विवरण |
| :- | :- |
| ECMA_376_2006 | निर्दिष्ट करता है कि दस्तावेज़ ECMA376:2006 के अनुरूप है। |
| ISO_29500_2008_TRANSITIONAL | निर्दिष्ट करता है कि दस्तावेज़ ISO/IEC 29500:2008 Transitional अनुपालन वर्ग के अनुरूप है। |
| ISO_29500_2008_STRICT | निर्दिष्ट करता है कि दस्तावेज़ ISO/IEC 29500:2008 Strict अनुपालन वर्ग के अनुरूप है। |
