## skip_java_script_links गुणधर्म
प्रस्तुति को सहेजते समय JavaScript कॉल वाले हाइपरलिंक को छोड़ना है या नहीं, दर्शाता है। 
            पढ़ें/लिखें **bool**. डिफ़ॉल्ट मान **false** है। 


### टिप्पणी

जब इस गुणधर्म को **true** , हाइपरलिंक JavaScript कॉल के साथ सहेजते समय अनदेखा कर दिया जाएगा।


जब इस गुणधर्म को **false** , सभी हाइपरलिंक सहेजे जाएंगे।
