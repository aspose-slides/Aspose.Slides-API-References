## Html5Options क्लास

HTML5 निर्यात विकल्पों का प्रतिनिधित्व करता है।

**विरासत:**[`Html5Options`](/slides/python-net/hi/aspose.slides.export/html5options) → [`SaveOptions`](/slides/python-net/hi/aspose.slides.export/saveoptions)

## गुण

| गुण | विवरण |
| :- | :- |
| [`warning_callback`](/slides/python-net/hi/aspose.slides.export/html5options/warning_callback/) | एक ऑब्जेक्ट को लौटाता है या सेट करता है जो चेतावनियों को प्राप्त करता है और तय करता है कि लोडिंग प्रक्रिया जारी रहेगी या समाप्त हो जाएगी।<br/>            पढ़ें/लिखें [`IWarningCallback`](/slides/python-net/hi/aspose.slides.warnings/iwarningcallback). |
| [`progress_callback`](/slides/python-net/hi/aspose.slides.export/html5options/progress_callback/) | एक कॉलबैक ऑब्जेक्ट का प्रतिनिधित्व करता है जो प्रतिशत में सहेजने की प्रगति अपडेट करता है।<br/>            देखें [`IProgressCallback`](/slides/python-net/hi/aspose.slides/iprogresscallback). |
| [`default_regular_font`](/slides/python-net/hi/aspose.slides.export/html5options/default_regular_font/) | एक फ़ॉन्ट लौटाता है या सेट करता है जिसका उपयोग तब किया जाता है जब स्रोत फ़ॉन्ट नहीं मिला।<br/>            पढ़ें-लिखें **str**. |
| [`gradient_style`](/slides/python-net/hi/aspose.slides.export/html5options/gradient_style/) | ग्रेडिएंट की दृश्य शैली को लौटाता है या सेट करता है।<br/>            पढ़ें/लिखें [`GradientStyle`](/slides/python-net/hi/aspose.slides/gradientstyle). |
| [`skip_java_script_links`](/slides/python-net/hi/aspose.slides.export/html5options/skip_java_script_links/) | प्रस्तुति को सहेजते समय JavaScript कॉल वाले हाइपरलिंक को छोड़ने के बारे में निर्दिष्ट करता है। <br/>            पढ़ें/लिखें **bool**. डिफ़ॉल्ट मान **false** है। |
| [`animate_transitions`](/slides/python-net/hi/aspose.slides.export/html5options/animate_transitions/) | ट्रांज़िशन एनीमेशन विकल्प को लौटाता है या सेट करता है।<br/>            पढ़ें/लिखें **bool**. |
| [`animate_shapes`](/slides/python-net/hi/aspose.slides.export/html5options/animate_shapes/) | शेप्स एनीमेशन विकल्प को लौटाता है या सेट करता है।<br/>            पढ़ें/लिखें **bool**. |
| [`embed_images`](/slides/python-net/hi/aspose.slides.export/html5options/embed_images/) | छवियों को एम्बेड करने का विकल्प लौटाता है या सेट करता है। <br/>            पढ़ें/लिखें **bool**. |
| [`output_path`](/slides/python-net/hi/aspose.slides.export/html5options/output_path/) | निर्धारित करता है कि बाहरी संसाधन कहाँ संग्रहीत किए जाने चाहिए। <br/>            पढ़ें/लिखें **str**. |
| [`pictures_compression`](/slides/python-net/hi/aspose.slides.export/html5options/pictures_compression/) | छवियों के संपीड़न स्तर का प्रतिनिधित्व करता है |
| [`disable_font_ligatures`](/slides/python-net/hi/aspose.slides.export/html5options/disable_font_ligatures/) | एक मान प्राप्त करता है या सेट करता है जो यह दर्शाता है कि टेक्स्ट लिगेचर का उपयोग किए बिना रेंडर किया गया है या नहीं।<br/>            जब `true` पर सेट किया जाता है, तो रेंडर आउटपुट में लिगेचर अक्षम हो जाएंगे। डिफ़ॉल्ट रूप से, यह प्रॉपर्टी `false` पर सेट है। |
| [`slides_layout_options`](/slides/python-net/hi/aspose.slides.export/html5options/slides_layout_options/) | जब प्रस्तुति निर्यात की जाती है तो स्लाइड्स को पृष्ठ पर रखने के मोड को प्राप्त करता है या सेट करता है [`ISlidesLayoutOptions`](/slides/python-net/hi/aspose.slides.export/islideslayoutoptions). |
