## skip_java_script_links प्रॉपर्टी
प्रेजेंटेशन को सहेजते समय JavaScript कॉल वाले हाइपरलिंक को छोड़ने के बारे में निर्दिष्ट करता है। 
पढ़ें/लिखें **bool**. डिफ़ॉल्ट मान **false** है।


### टिप्पणी

जब यह प्रॉपर्टी **true** पर सेट की जाती है, तो सहेजते समय JavaScript कॉल वाले हाइपरलिंक को नजरअंदाज किया जाएगा।

जब यह प्रॉपर्टी **false** पर सेट की जाती है, तो सभी हाइपरलिंक सहेजे जाएंगे।
