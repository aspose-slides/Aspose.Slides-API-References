## IHtmlFormattingController क्लास

html फ़ाइल जनरेशन को नियंत्रित करता है।

IHtmlFormattingController प्रकार निम्नलिखित सदस्यों को प्रकट करता है:

## विधियाँ

| मेथड | विवरण |
| :- | :- |
| [`write_document_start(self, generator, presentation)`](/slides/python-net/hi/aspose.slides.export/ihtmlformattingcontroller/write_document_start/#ihtmlgenerator-ipresentation) | html दस्तावेज़ हेडर लिखने के लिए बुलाया जाता है। प्रस्तुति रूपांतरण पर एक बार बुलाया जाता है। |
| [`write_document_end(self, generator, presentation)`](/slides/python-net/hi/aspose.slides.export/ihtmlformattingcontroller/write_document_end/#ihtmlgenerator-ipresentation) | html दस्तावेज़ फुटर लिखने के लिए बुलाया जाता है। प्रस्तुति रूपांतरण पर एक बार बुलाया जाता है। |
| [`write_slide_start(self, generator, slide)`](/slides/python-net/hi/aspose.slides.export/ihtmlformattingcontroller/write_slide_start/#ihtmlgenerator-islide) | html स्लाइड हेडर लिखने के लिए बुलाया जाता है। प्रत्येक स्लाइड पर एक बार बुलाया जाता है। |
| [`write_slide_end(self, generator, slide)`](/slides/python-net/hi/aspose.slides.export/ihtmlformattingcontroller/write_slide_end/#ihtmlgenerator-islide) | html स्लाइड फुटर लिखने के लिए बुलाया जाता है। प्रत्येक स्लाइड पर एक बार बुलाया जाता है। |
| [`write_shape_start(self, generator, shape)`](/slides/python-net/hi/aspose.slides.export/ihtmlformattingcontroller/write_shape_start/#ihtmlgenerator-ishape) | shape की रेंडरिंग से पहले बुलाया जाता है। प्रत्येक shape पर एक बार बुलाया जाता है। यदि यह फ़ंक्शन जेनरेटर को कुछ भी लिखता है, तो वर्तमान स्लाइड छवि निर्माण समाप्त हो जाएगा, जोड़ा गया html फ्रैगमेंट सम्मिलित होगा और नया चित्र पिछले के ऊपर शुरू होगा। |
| [`write_shape_end(self, generator, shape)`](/slides/python-net/hi/aspose.slides.export/ihtmlformattingcontroller/write_shape_end/#ihtmlgenerator-ishape) | shape की रेंडरिंग से पहले बुलाया जाता है। प्रत्येक shape पर एक बार बुलाया जाता है। यदि यह फ़ंक्शन जेनरेटर को कुछ भी लिखता है, तो वर्तमान स्लाइड छवि निर्माण समाप्त हो जाएगा, जोड़ा गया html फ्रैगमेंट सम्मिलित होगा और नया चित्र पिछले के ऊपर शुरू होगा। |
