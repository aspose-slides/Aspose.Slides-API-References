## skip_java_script_links प्रॉपर्टी
प्रस्तुति को सहेजते समय जावास्क्रिप्ट कॉल्स वाले हाइपरलिंक को छोड़ना है या नहीं, यह निर्धारित करता है। 
            पढ़ने/लिखने **bool**. डिफ़ॉल्ट मान **false** है।


### टिप्पणी

जब यह प्रॉपर्टी **true** पर सेट की जाती है, सहेजते समय जावास्क्रिप्ट कॉल्स वाले हाइपरलिंक्स को अनदेखा किया जाएगा।


जब यह प्रॉपर्टी **false** पर सेट की जाती है, सभी हाइपरलिंक्स सहेजे जाएंगे।
