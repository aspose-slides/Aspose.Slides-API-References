## SvgCoordinateUnit एन्यूमेरेशन

SVG निर्देशांक निर्धारित करने के लिए उपयोग किए जाने वाले CSS2 कॉर्डिनेट इकाइयों का प्रतिनिधित्व करता है।

SvgCoordinateUnit प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## फ़ील्ड

| फ़ील्ड | विवरण |
| :- | :- |
| INCH | इंच |
| CENTIMETER | सेंटीमीटर। |
| MILLIMETER | मिलिमीटर। |
| POINT | पॉइंट (इंच का 1/72), |
| PICA | पिका (इंच का 1/6)। |
| EM | संकलित तत्व के फ़ॉन्ट का एम आकार। |
| EX | संकलित तत्व के फ़ॉन्ट का एक्स आकार (निचले अक्षर का आकार, सामान्यतः "x")। |
| PIXEL | पिक्सेल आकार। |
| PERCENT | प्रतिशत। |
