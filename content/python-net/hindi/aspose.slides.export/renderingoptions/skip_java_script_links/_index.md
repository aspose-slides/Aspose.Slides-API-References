## skip_java_script_links प्रॉपर्टी
यह दर्शाता है कि प्रस्तुति को सहेजते समय जावास्क्रिप्ट कॉल वाले हाइपरलिंक को छोड़ना है या नहीं। 
            पढ़ें/लिखें **bool**. डिफ़ॉल्ट मान **false** है।


### टिप्पणी

When this property is set to **true** , hyperlinks with JavaScript calls will be ignored while saving.


When this property is set to **false** , all hyperlinks will be saved.
