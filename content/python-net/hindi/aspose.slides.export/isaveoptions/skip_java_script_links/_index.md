## skip_java_script_links प्रॉपर्टी
निर्दिष्ट करता है कि प्रस्तुति को सहेजते समय JavaScript कॉल वाले हाइपरलिंक को छोड़ना है या नहीं। 
            पढ़ने/लिखने योग्य **bool**। डिफ़ॉल्ट मान **false** है।


### टिप्पणियाँ

जब यह प्रॉपर्टी **true** पर सेट की जाती है, तो JavaScript कॉल वाले हाइपरलिंक को सहेजते समय अनदेखा किया जाएगा।


जब यह प्रॉपर्टी **false** पर सेट की जाती है, तो सभी हाइपरलिंक सहेजे जाएंगे।
