## ISaveOptions क्लास

प्रेजेंटेशन को सहेजने के तरीके को नियंत्रित करने वाले विकल्प।

ISaveOptions प्रकार निम्न सदस्य प्रदान करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`warning_callback`](/slides/python-net/hi/aspose.slides.export/isaveoptions/warning_callback/) | त्रुटियों को प्राप्त करने और यह निर्धारित करने वाला ऑब्जेक्ट लौटाता है या सेट करता है कि लोडिंग प्रक्रिया जारी रखी जाएगी या निरस्त की जाएगी।<br/>            पढ़ें/लिखें [`IWarningCallback`](/slides/python-net/hi/aspose.slides.warnings/iwarningcallback). |
| [`progress_callback`](/slides/python-net/hi/aspose.slides.export/isaveoptions/progress_callback/) | प्रतिशत में सहेजने की प्रगति अपडेट के लिए एक कॉलबैक ऑब्जेक्ट का प्रतिनिधित्व करता है। <br/>            देखें [`IProgressCallback`](/slides/python-net/hi/aspose.slides/iprogresscallback). |
| [`default_regular_font`](/slides/python-net/hi/aspose.slides.export/isaveoptions/default_regular_font/) | यदि स्रोत फ़ॉन्ट नहीं मिला तो उपयोग किया जाने वाला फ़ॉन्ट लौटाता है या सेट करता है।<br/>            पढ़ें-लिखें **str**. |
| [`gradient_style`](/slides/python-net/hi/aspose.slides.export/isaveoptions/gradient_style/) | ग्रेडिएंट की विज़ुअल शैली लौटाता है या सेट करता है।<br/>            पढ़ें/लिखें [`GradientStyle`](/slides/python-net/hi/aspose.slides/gradientstyle). |
| [`skip_java_script_links`](/slides/python-net/hi/aspose.slides.export/isaveoptions/skip_java_script_links/) | प्रेजेंटेशन सहेजते समय जावास्क्रिप्ट कॉल वाले हाइपरलिंक को छोड़ना है या नहीं, यह निर्दिष्ट करता है। <br/>            पढ़ें/लिखें **bool**. डिफ़ॉल्ट मान **false** है। |
