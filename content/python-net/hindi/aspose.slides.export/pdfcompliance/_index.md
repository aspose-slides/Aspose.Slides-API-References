## PdfCompliance enumeration

PDF मानकों के अनुपालन स्तर को परिभाषित करने वाले स्थिरांक।

PdfCompliance प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## फ़ील्ड

| फ़ील्ड | विवरण |
| :- | :- |
| PDF15 | आउटपुट फ़ाइल PDF 1.5 मानक के अनुरूप होगी। |
| PDF16 | आउटपुट फ़ाइल PDF 1.6 मानक के अनुरूप होगी। |
| PDF17 | आउटपुट फ़ाइल PDF 1.7 मानक के अनुरूप होगी। |
| PDF_A1B | आउटपुट फ़ाइल PDF/A-1b मानक के अनुरूप होगी। |
| PDF_A1A | आउटपुट फ़ाइल PDF/A-1a मानक के अनुरूप होगी। |
| PDF_A2B | आउटपुट फ़ाइल PDF/A-2b मानक के अनुरूप होगी। |
| PDF_A2A | आउटपुट फ़ाइल PDF/A-2a मानक के अनुरूप होगी। |
| PDF_A3B | आउटपुट फ़ाइल PDF/A-3b मानक के अनुरूप होगी। |
