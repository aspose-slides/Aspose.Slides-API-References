## IHtml5Options क्लास

HTML5 निर्यात विकल्प का प्रतिनिधित्व करता है।

IHtml5Options प्रकार निम्नलिखित सदस्यों को उजागर करता है:

## गुण

| गुण | विवरण |
| :- | :- |
| [`animate_transitions`](/slides/python-net/hi/aspose.slides.export/ihtml5options/animate_transitions/) | ट्रांज़िशन एनीमेशन विकल्प को प्राप्त या सेट करता है।<br/>            पढ़ें/लिखें **bool**. |
| [`animate_shapes`](/slides/python-net/hi/aspose.slides.export/ihtml5options/animate_shapes/) | आकृति एनीमेशन विकल्प को प्राप्त या सेट करता है।<br/>            पढ़ें/लिखें **bool**. |
| [`embed_images`](/slides/python-net/hi/aspose.slides.export/ihtml5options/embed_images/) | छवि एम्बेडिंग विकल्प को प्राप्त या सेट करता है।<br/>            पढ़ें/लिखें **bool**. |
| [`output_path`](/slides/python-net/hi/aspose.slides.export/ihtml5options/output_path/) | निर्धारित करता है कि बाहरी संसाधन कहाँ संग्रहीत किए जाने चाहिए।<br/>            पढ़ें/लिखें **str**. |
| [`pictures_compression`](/slides/python-net/hi/aspose.slides.export/ihtml5options/pictures_compression/) | चित्रों संपीड़न स्तर को दर्शाता है<br/>            पढ़ें/लिखें [`IHtml5Options.pictures_compression`](/slides/python-net/hi/aspose.slides.export/ihtml5options/pictures_compression). |
| [`disable_font_ligatures`](/slides/python-net/hi/aspose.slides.export/ihtml5options/disable_font_ligatures/) | प्राप्त या सेट करता है एक मान जो दर्शाता है कि क्या टेक्स्ट लिगेचर का उपयोग किए बिना रेंडर किया जाता है।<br/>            जब `true` पर सेट किया जाता है, तो रेंडर किए गए आउटपुट में लिगेचर निष्क्रिय हो जाएंगे। डिफ़ॉल्ट रूप से, यह प्रॉपर्टी `false` पर सेट है। |
| [`slides_layout_options`](/slides/python-net/hi/aspose.slides.export/ihtml5options/slides_layout_options/) | एक प्रस्तुति [`ISlidesLayoutOptions`](/slides/python-net/hi/aspose.slides.export/islideslayoutoptions) निर्यात करते समय स्लाइड्स को पृष्ठ पर रखने के मोड को प्राप्त या सेट करता है। |
