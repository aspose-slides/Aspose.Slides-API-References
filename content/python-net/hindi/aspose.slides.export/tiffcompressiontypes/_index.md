## TiffCompressionTypes एन्यूमरेशन

विकल्प प्रदान करता है जो नियंत्रित करते हैं कि प्रस्तुति TIFF स्वरूप में कैसे संकुचित की जाती है।

TiffCompressionTypes प्रकार निम्न सदस्य प्रदान करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| DEFAULT | डिफ़ॉल्ट संपीड़न योजना (LZW) निर्दिष्ट करता है। |
| NONE | कोई संपीड़न नहीं निर्दिष्ट करता है। |
| CCITT3 | CCITT3 संपीड़न योजना निर्दिष्ट करता है। |
| CCITT4 | CCITT4 संपीड़न योजना निर्दिष्ट करता है। |
| LZW | LZW संपीड़न योजना (डिफ़ॉल्ट) निर्दिष्ट करता है। |
| RLE | RLE संपीड़न योजना निर्दिष्ट करता है। |
