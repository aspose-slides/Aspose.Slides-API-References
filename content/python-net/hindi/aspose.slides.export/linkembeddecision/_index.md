## LinkEmbedDecision एन्यूमरेशन

निर्धारित करता है कि सहेजते समय वस्तु को कैसे प्रोसेस किया जाएगा।

LinkEmbedDecision प्रकार निम्नलिखित सदस्य उजागर करता है:

## फ़ील्ड्स

| फ़ील्ड | विवरण |
| :- | :- |
| LINK | ऑब्जेक्ट को बाहरी रूप से संग्रहीत किया जाएगा, URL द्वारा संदर्भित। |
| EMBED | ऑब्जेक्ट को संभव हो तो उत्पन्न फाइल में एम्बेड किया जाना चाहिए। यदि एम्बेड करना असंभव है, तो GetUrl को कॉल किया जाएगा और परिणाम के आधार पर, ऑब्जेक्ट को URL द्वारा संदर्भित या अनदेखा किया जाएगा। |
| IGNORE | ऑब्जेक्ट को अनदेखा किया जाएगा। |
