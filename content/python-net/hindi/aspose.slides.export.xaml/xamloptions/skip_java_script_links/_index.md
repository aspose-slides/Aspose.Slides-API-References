## skip_java_script_links प्रॉपर्टी
प्रेजेंटेशन को सहेजते समय JavaScript कॉल वाले हाइपरलिंक को छोड़ना है या नहीं, यह निर्दिष्ट करता है। 
            पढ़ें/लिखें **bool**. डिफ़ॉल्ट मान **false** है। 


### टिप्पणी

जब इस प्रॉपर्टी को **true** सेट किया जाता है, तो JavaScript कॉल वाले हाइपरलिंक सहेजते समय अनदेखे कर दिए जाएंगे।


जब इस प्रॉपर्टी को **false** सेट किया जाता है, तो सभी हाइपरलिंक सहेजे जाएंगे।
