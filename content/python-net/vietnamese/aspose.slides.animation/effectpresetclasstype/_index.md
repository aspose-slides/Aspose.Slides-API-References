## EffectPresetClassType liệt kê

Biểu diễn các loại lớp hiệu ứng.

Kiểu EffectPresetClassType cung cấp các thành viên sau:

## Trường

| Trường | Mô tả |
| :- | :- |
| ENTRANCE | Lớp hiệu ứng vào.<br/><br/><br/>Các loại hình dạng mục tiêu: All |
| EXIT | Lớp hiệu ứng ra.<br/><br/><br/>Các loại hình dạng mục tiêu: All |
| EMPHASIS | Lớp hiệu ứng nhấn mạnh.<br/><br/><br/>Các loại hình dạng mục tiêu: All |
| PATH | Lớp đường chuyển động.<br/><br/><br/>Các loại hình dạng mục tiêu: All |
| MEDIA_CALL | Lớp hiệu ứng phương tiện.<br/><br/><br/>Các loại hình dạng mục tiêu: [`IVideoFrame`](/slides/python-net/vi/aspose.slides/ivideoframe), [`IAudioFrame`](/slides/python-net/vi/aspose.slides/iaudioframe) |
| OLE_ACTION_VERBS | Lớp OLE Action Verbs.<br/><br/><br/>Các loại hình dạng mục tiêu: [`IOleObjectFrame`](/slides/python-net/vi/aspose.slides/ioleobjectframe) |
