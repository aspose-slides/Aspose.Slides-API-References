## IEffect lớp

Đại diện cho hiệu ứng hoạt ảnh.

Kiểu IEffect cung cấp các thành viên sau:

## Thuộc tính

| Thuộc tính | Mô tả |
| :- | :- |
| [`sequence`](/slides/python-net/vi/aspose.slides.animation/ieffect/sequence/) | Trả về một dãy cho một hiệu ứng.<br/>            Chỉ đọc [`ISequence`](/slides/python-net/vi/aspose.slides.animation/isequence). |
| [`text_animation`](/slides/python-net/vi/aspose.slides.animation/ieffect/text_animation/) | Trả về hoạt ảnh văn bản.<br/>            Chỉ đọc [`ITextAnimation`](/slides/python-net/vi/aspose.slides.animation/itextanimation). |
| [`preset_class_type`](/slides/python-net/vi/aspose.slides.animation/ieffect/preset_class_type/) | Xác định lớp của hiệu ứng.<br/>            Đọc/ghi [`EffectPresetClassType`](/slides/python-net/vi/aspose.slides.animation/effectpresetclasstype). |
| [`type`](/slides/python-net/vi/aspose.slides.animation/ieffect/type/) | Xác định loại hiệu ứng.<br/>            Đọc/ghi [`EffectType`](/slides/python-net/vi/aspose.slides.animation/effecttype). |
| [`subtype`](/slides/python-net/vi/aspose.slides.animation/ieffect/subtype/) | Xác định kiểu con của hiệu ứng.<br/>            Đọc/ghi [`EffectSubtype`](/slides/python-net/vi/aspose.slides.animation/effectsubtype). |
| [`behaviors`](/slides/python-net/vi/aspose.slides.animation/ieffect/behaviors/) | Trả về tập hợp hành vi cho hiệu ứng.<br/>            Đọc/ghi [`IBehaviorCollection`](/slides/python-net/vi/aspose.slides.animation/ibehaviorcollection). |
| [`timing`](/slides/python-net/vi/aspose.slides.animation/ieffect/timing/) | Xác định giá trị thời gian cho hiệu ứng.<br/>            Đọc/ghi [`ITiming`](/slides/python-net/vi/aspose.slides.animation/itiming). |
| [`target_shape`](/slides/python-net/vi/aspose.slides.animation/ieffect/target_shape/) | Trả về hình dạng mục tiêu cho hiệu ứng.<br/>            Chỉ đọc [`IShape`](/slides/python-net/vi/aspose.slides/ishape). |
| [`sound`](/slides/python-net/vi/aspose.slides.animation/ieffect/sound/) | Định nghĩa âm thanh nhúng cho hiệu ứng.<br/>            Đọc/ghi [`IAudio`](/slides/python-net/vi/aspose.slides/iaudio). |
| [`stop_previous_sound`](/slides/python-net/vi/aspose.slides.animation/ieffect/stop_previous_sound/) | Thuộc tính này chỉ định liệu hiệu ứng hoạt ảnh có dừng âm thanh trước đó không.<br/>            Đọc/ghi **bool**. |
| [`after_animation_type`](/slides/python-net/vi/aspose.slides.animation/ieffect/after_animation_type/) | Định nghĩa kiểu hoạt ảnh sau cho hiệu ứng.<br/>            Đọc/ghi [`IEffect.after_animation_type`](/slides/python-net/vi/aspose.slides.animation/ieffect/after_animation_type). |
| [`after_animation_color`](/slides/python-net/vi/aspose.slides.animation/ieffect/after_animation_color/) | Định nghĩa màu sau hoạt ảnh cho hiệu ứng.<br/>            Đọc/ghi [`IColorFormat`](/slides/python-net/vi/aspose.slides/icolorformat). |
| [`animate_text_type`](/slides/python-net/vi/aspose.slides.animation/ieffect/animate_text_type/) | Xác định kiểu văn bản hoạt ảnh cho hiệu ứng.<br/>            Văn bản hình dạng có thể được hoạt ảnh theo chữ, theo từ hoặc toàn bộ cùng lúc.<br/>            Đọc/ghi [`IEffect.animate_text_type`](/slides/python-net/vi/aspose.slides.animation/ieffect/animate_text_type). |
| [`delay_between_text_parts`](/slides/python-net/vi/aspose.slides.animation/ieffect/delay_between_text_parts/) | Xác định độ trễ giữa các phần văn bản hoạt ảnh (từ hoặc chữ).<br/>            Giá trị dương chỉ tỷ lệ phần trăm thời lượng hiệu ứng.<br/>            Giá trị âm chỉ độ trễ tính bằng giây.<br/>            Đọc/ghi **float**. |
