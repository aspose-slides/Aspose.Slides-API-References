Biểu diễn hành vi lớp cơ sở của hiệu ứng.

Kiểu Behavior cung cấp các thành viên sau:

## Thuộc tính

| Property | Description |
| :- | :- |
| [`accumulate`](/slides/python-net/vi/aspose.slides.animation/behavior/accumulate/) | Mô tả liệu các hành vi hoạt ảnh có được tích lũy hay không.<br/>            Đọc/ghi [`NullableBool`](/slides/python-net/vi/aspose.slides/nullablebool). |
