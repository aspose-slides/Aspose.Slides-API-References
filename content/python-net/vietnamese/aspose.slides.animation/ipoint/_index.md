## IPoint lớp

Biểu diễn điểm hoạt hình.

Kiểu IPoint cung cấp các thành viên sau:

## Thuộc tính

| Property | Description |
| :- | :- |
| [`time`](/slides/python-net/vi/aspose.slides.animation/ipoint/time/) | Biểu diễn giá trị thời gian.<br/>Đọc/Ghi **float**. |
| [`value`](/slides/python-net/vi/aspose.slides.animation/ipoint/value/) | Biểu diễn giá trị điểm.<br/>Chỉ: bool, ColorFormat, float, int, string.<br/>Đọc/Ghi **any**. |
| [`formula`](/slides/python-net/vi/aspose.slides.animation/ipoint/formula/) | Công thức trong các giá trị, thuộc tính from, to, by có thể bao gồm các thành phần sau:<br/>            Toán tử số học tiêu chuẩn: ‘+’, ‘-‘, ‘*’, ‘/’, ‘^’, ‘%’ (mod)<br/>            Hằng số: ‘pi’ ‘e’<br/>            Toán tử điều kiện: ‘abs’, ‘min’, ‘max’, ‘?’ (if)<br/>            Toán tử so sánh: '==', '>=', '', '!=', '!'<br/>            Toán tử lượng giác: ‘sin()’, ‘cos()’, ‘tan()’, ‘asin()’, ‘acos()’, ‘atan()’<br/>            Logarit tự nhiên ‘ln()’<br/>            Tham chiếu thuộc tính (host supported properties)<br/>            <br/>            ví dụ: "#ppt_x+(cos(-2*pi*(1-$))*-#ppt_x-sin(-2*pi*(1-$))*(1-#ppt_y))*(1-$)"<br/>            Đọc/Ghi **str**. |
