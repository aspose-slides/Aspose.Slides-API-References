## Thuộc tính

| Property | Description |
| :- | :- |
| [`accumulate`](/slides/python-net/vi/aspose.slides.animation/propertyeffect/accumulate/) | Biểu thị việc các hành vi hoạt ảnh có được tích lũy hay không.<br/>            Đọc/ghi [`NullableBool`](/slides/python-net/vi/aspose.slides/nullablebool). |
| [`additive`](/slides/python-net/vi/aspose.slides.animation/propertyeffect/additive/) | Biểu thị việc hành vi hoạt ảnh hiện tại được kết hợp với các hoạt ảnh đang chạy khác hay không.<br/>            Đọc/ghi [`BehaviorAdditiveType`](/slides/python-net/vi/aspose.slides.animation/behavioradditivetype). |
| [`properties`](/slides/python-net/vi/aspose.slides.animation/propertyeffect/properties/) | Đại diện cho các thuộc tính của hành vi.<br/>            Chỉ đọc [`IBehaviorPropertyCollection`](/slides/python-net/vi/aspose.slides.animation/ibehaviorpropertycollection). |
| [`timing`](/slides/python-net/vi/aspose.slides.animation/propertyeffect/timing/) | Đại diện cho các thuộc tính thời gian cho hành vi hiệu ứng.<br/>            Đọc/ghi [`ITiming`](/slides/python-net/vi/aspose.slides.animation/itiming). |
| [`from_address`](/slides/python-net/vi/aspose.slides.animation/propertyeffect/from_address/) | Xác định giá trị khởi đầu của hoạt ảnh.<br/>            Đọc/ghi **str**. |
| [`to`](/slides/python-net/vi/aspose.slides.animation/propertyeffect/to/) | Xác định giá trị kết thúc cho hoạt ảnh.<br/>            Đọc/ghi **str**. |
| [`by`](/slides/python-net/vi/aspose.slides.animation/propertyeffect/by/) | Xác định giá trị độ lệch tương đối cho hoạt ảnh so với<br/>            vị trí của nó trước khi hoạt ảnh bắt đầu.<br/>            Đọc/ghi **str**. |
| [`value_type`](/slides/python-net/vi/aspose.slides.animation/propertyeffect/value_type/) | Xác định loại giá trị thuộc tính.<br/>            Đọc/ghi [`PropertyValueType`](/slides/python-net/vi/aspose.slides.animation/propertyvaluetype). |
| [`calc_mode`](/slides/python-net/vi/aspose.slides.animation/propertyeffect/calc_mode/) | Xác định chế độ nội suy cho hoạt ảnh<br/>            Đọc/ghi [`PropertyCalcModeType`](/slides/python-net/vi/aspose.slides.animation/propertycalcmodetype). |
| [`points`](/slides/python-net/vi/aspose.slides.animation/propertyeffect/points/) | Xác định các điểm của hoạt ảnh.<br/>            Đọc/ghi [`IPointCollection`](/slides/python-net/vi/aspose.slides.animation/ipointcollection). |
