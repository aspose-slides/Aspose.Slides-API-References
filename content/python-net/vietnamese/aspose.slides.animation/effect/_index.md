## Lớp Effect

Biểu diễn hiệu ứng hoạt họa.

Kiểu Effect cung cấp các thành viên sau:

## Thuộc tính

| Thuộc tính | Mô tả |
| :- | :- |
| [`sequence`](/slides/python-net/vi/aspose.slides.animation/effect/sequence/) | Trả về một chuỗi cho hiệu ứng.<br/>            Chỉ-đọc [`ISequence`](/slides/python-net/vi/aspose.slides.animation/isequence). |
| [`text_animation`](/slides/python-net/vi/aspose.slides.animation/effect/text_animation/) | TextAnimation<br/>            Chỉ-đọc [`ITextAnimation`](/slides/python-net/vi/aspose.slides.animation/itextanimation). |
| [`preset_class_type`](/slides/python-net/vi/aspose.slides.animation/effect/preset_class_type/) | Xác định lớp của hiệu ứng.<br/>            Đọc/ghi [`EffectPresetClassType`](/slides/python-net/vi/aspose.slides.animation/effectpresetclasstype). |
| [`type`](/slides/python-net/vi/aspose.slides.animation/effect/type/) | Xác định kiểu của hiệu ứng.<br/>            Đọc/ghi [`EffectType`](/slides/python-net/vi/aspose.slides.animation/effecttype). |
| [`subtype`](/slides/python-net/vi/aspose.slides.animation/effect/subtype/) | Xác định loại phụ của hiệu ứng.<br/>            Đọc/ghi [`EffectSubtype`](/slides/python-net/vi/aspose.slides.animation/effectsubtype). |
| [`behaviors`](/slides/python-net/vi/aspose.slides.animation/effect/behaviors/) | Trả về tập hợp hành vi cho hiệu ứng.<br/>            Đọc/ghi [`IBehaviorCollection`](/slides/python-net/vi/aspose.slides.animation/ibehaviorcollection). |
| [`timing`](/slides/python-net/vi/aspose.slides.animation/effect/timing/) | Xác định giá trị thời gian cho hiệu ứng.<br/>            Đọc/ghi [`ITiming`](/slides/python-net/vi/aspose.slides.animation/itiming). |
| [`target_shape`](/slides/python-net/vi/aspose.slides.animation/effect/target_shape/) | Trả về hình dạng mục tiêu cho hiệu ứng.<br/>            Chỉ-đọc [`IShape`](/slides/python-net/vi/aspose.slides/ishape). |
| [`sound`](/slides/python-net/vi/aspose.slides.animation/effect/sound/) | Định nghĩa âm thanh nhúng cho hiệu ứng.<br/>            Đọc/ghi [`IAudio`](/slides/python-net/vi/aspose.slides/iaudio). |
| [`stop_previous_sound`](/slides/python-net/vi/aspose.slides.animation/effect/stop_previous_sound/) | Thuộc tính này chỉ định liệu hiệu ứng hoạt họa có dừng âm thanh trước đó hay không.<br/>            Đọc/ghi **bool**. |
| [`after_animation_type`](/slides/python-net/vi/aspose.slides.animation/effect/after_animation_type/) | Xác định kiểu hoạt họa sau cho hiệu ứng.<br/>            Đọc/ghi [`Effect.after_animation_type`](/slides/python-net/vi/aspose.slides.animation/effect/after_animation_type). |
| [`after_animation_color`](/slides/python-net/vi/aspose.slides.animation/effect/after_animation_color/) | Xác định màu hoạt họa sau cho hiệu ứng.<br/>            Đọc/ghi [`IColorFormat`](/slides/python-net/vi/aspose.slides/icolorformat). |
| [`animate_text_type`](/slides/python-net/vi/aspose.slides.animation/effect/animate_text_type/) | Xác định kiểu văn bản hoạt họa cho hiệu ứng. <br/>            Văn bản hình dạng có thể được hoạt họa theo ký tự, theo từ hoặc toàn bộ một lúc.<br/>            Đọc/ghi [`Effect.animate_text_type`](/slides/python-net/vi/aspose.slides.animation/effect/animate_text_type). |
| [`delay_between_text_parts`](/slides/python-net/vi/aspose.slides.animation/effect/delay_between_text_parts/) | Xác định độ trễ giữa các phần văn bản được hoạt họa (từ hoặc ký tự).<br/>            Giá trị dương chỉ định phần trăm thời lượng của hiệu ứng.<br/>            Giá trị âm chỉ định độ trễ tính bằng giây.<br/>            Đọc/ghi **float**. |
