## ITiming lớp

Đại diện cho thời gian hoạt ảnh.

Kiểu ITiming cung cấp các thành viên sau:

## Thuộc tính

| Property | Description |
| :- | :- |
| [`accelerate`](/slides/python-net/vi/aspose.slides.animation/itiming/accelerate/) | Mô tả phần trăm thời lượng của hiệu ứng hành vi tăng tốc.<br/>            Đọc/ghi **float**. |
| [`decelerate`](/slides/python-net/vi/aspose.slides.animation/itiming/decelerate/) | Mô tả phần trăm thời lượng của hiệu ứng hành vi giảm tốc.<br/>            Đọc/ghi **float**. |
| [`auto_reverse`](/slides/python-net/vi/aspose.slides.animation/itiming/auto_reverse/) | Mô tả việc có tự động phát hoạt ảnh ngược lại sau khi<br/>            phát nó theo hướng tiến.<br/>            Đọc/ghi **bool**. |
| [`duration`](/slides/python-net/vi/aspose.slides.animation/itiming/duration/) | Mô tả thời lượng của hiệu ứng hoạt ảnh.<br/>            Đọc/ghi **float**. |
| [`repeat_count`](/slides/python-net/vi/aspose.slides.animation/itiming/repeat_count/) | Mô tả số lần hiệu ứng nên lặp lại.<br/>            Đọc/ghi **float**. |
| [`repeat_until_end_slide`](/slides/python-net/vi/aspose.slides.animation/itiming/repeat_until_end_slide/) | Thuộc tính này chỉ định liệu hiệu ứng sẽ lặp lại cho đến khi kết thúc slide.<br/>             Đọc/ghi **bool**. |
| [`repeat_until_next_click`](/slides/python-net/vi/aspose.slides.animation/itiming/repeat_until_next_click/) | Thuộc tính này chỉ định liệu hiệu ứng sẽ lặp lại cho đến lần nhấn tiếp theo.<br/>             Đọc/ghi **bool**. |
| [`repeat_duration`](/slides/python-net/vi/aspose.slides.animation/itiming/repeat_duration/) | Mô tả số lần hiệu ứng nên lặp lại.<br/>            Đọc/ghi **float**. |
| [`restart`](/slides/python-net/vi/aspose.slides.animation/itiming/restart/) | Chỉ định liệu một hiệu ứng sẽ được khởi động lại sau khi hoàn thành.<br/>            Đọc/ghi [`EffectRestartType`](/slides/python-net/vi/aspose.slides.animation/effectrestarttype). |
| [`speed`](/slides/python-net/vi/aspose.slides.animation/itiming/speed/) | Chỉ định phần trăm mà thời gian sẽ được tăng tốc (hoặc giảm tốc).<br/>            Đọc/ghi **float**. |
| [`trigger_delay_time`](/slides/python-net/vi/aspose.slides.animation/itiming/trigger_delay_time/) | Mô tả thời gian độ trễ sau khi kích hoạt.<br/>            Đọc/ghi **float**. |
| [`trigger_type`](/slides/python-net/vi/aspose.slides.animation/itiming/trigger_type/) | Mô tả loại kích hoạt.<br/>            Đọc/ghi [`EffectTriggerType`](/slides/python-net/vi/aspose.slides.animation/effecttriggertype). |
| [`rewind`](/slides/python-net/vi/aspose.slides.animation/itiming/rewind/) | Thuộc tính này chỉ định liệu hiệu ứng sẽ tua lại khi phát xong.<br/>             Đọc/ghi **bool**. |
