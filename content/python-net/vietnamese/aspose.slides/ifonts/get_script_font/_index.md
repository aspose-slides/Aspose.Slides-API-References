## get_script_font(self, script) {#str}
Lấy tên phông chữ được liên kết với một thẻ script cụ thể từ chủ đề của bản trình chiếu.

### Trả về

Tên phông chữ được sử dụng cho script đã chỉ định, hoặc `None` nếu script không được định nghĩa.



```python
def get_script_font(self, script):
    ...
```


| Tham số | Kiểu | Mô tả |
| :- | :- | :- |
| script | **str** | Mã script BCP-47 (ví dụ: "Latn", "Cyrl", "Jpan") được sử dụng để xác định một hệ thống viết. |
