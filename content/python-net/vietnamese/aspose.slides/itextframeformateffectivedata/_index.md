## Lớp ITextFrameFormatEffectiveData

Đối tượng bất biến chứa các thuộc tính định dạng khung văn bản hiệu quả.

Kiểu ITextFrameFormatEffectiveData cung cấp các thành viên sau:

## Thuộc tính

| Thuộc tính | Mô tả |
| :- | :- |
| [`text_style`](/slides/python-net/vi/aspose.slides/itextframeformateffectivedata/text_style/) | Trả về kiểu văn bản hiệu quả.<br/>            Chỉ đọc [`ITextStyleEffectiveData`](/slides/python-net/vi/aspose.slides/itextstyleeffectivedata). |
| [`margin_left`](/slides/python-net/vi/aspose.slides/itextframeformateffectivedata/margin_left/) | Trả về lề trái (điểm) trong TextFrame.<br/>            Chỉ đọc **float**. |
| [`margin_right`](/slides/python-net/vi/aspose.slides/itextframeformateffectivedata/margin_right/) | Trả về lề phải (điểm) trong TextFrame.<br/>            Chỉ đọc **float**. |
| [`margin_top`](/slides/python-net/vi/aspose.slides/itextframeformateffectivedata/margin_top/) | Trả về lề trên (điểm) trong TextFrame.<br/>            Chỉ đọc **float**. |
| [`margin_bottom`](/slides/python-net/vi/aspose.slides/itextframeformateffectivedata/margin_bottom/) | Trả về lề dưới (điểm) trong TextFrame.<br/>            Chỉ đọc **float**. |
| [`wrap_text`](/slides/python-net/vi/aspose.slides/itextframeformateffectivedata/wrap_text/) | Trả về liệu văn bản có được cuộn lại ở các lề của TextFrame hay không.<br/>            Chỉ đọc **bool**. |
| [`anchoring_type`](/slides/python-net/vi/aspose.slides/itextframeformateffectivedata/anchoring_type/) | Trả về văn bản neo dọc trong TextFrame.<br/>            Chỉ đọc [`TextAnchorType`](/slides/python-net/vi/aspose.slides/textanchortype). |
| [`center_text`](/slides/python-net/vi/aspose.slides/itextframeformateffectivedata/center_text/) | Trả về liệu văn bản có nên được căn giữa theo chiều ngang trong hộp hay không.<br/>            Chỉ đọc **bool**. |
| [`text_vertical_type`](/slides/python-net/vi/aspose.slides/itextframeformateffectivedata/text_vertical_type/) | Trả về hướng văn bản.<br/>            Chỉ đọc [`TextVerticalType`](/slides/python-net/vi/aspose.slides/textverticaltype). |
| [`autofit_type`](/slides/python-net/vi/aspose.slides/itextframeformateffectivedata/autofit_type/) | Trả về chế độ tự động vừa văn bản.<br/>            Chỉ đọc [`TextAutofitType`](/slides/python-net/vi/aspose.slides/textautofittype). |
| [`column_count`](/slides/python-net/vi/aspose.slides/itextframeformateffectivedata/column_count/) | Xác định số cột văn bản trong hình chữ nhật bao quanh.<br/>            Chỉ đọc **int**. |
| [`column_spacing`](/slides/python-net/vi/aspose.slides/itextframeformateffectivedata/column_spacing/) | Xác định khoảng cách giữa các cột văn bản trong vùng văn bản (đơn vị điểm).<br/>            Chỉ đọc **float**. |

### Ghi chú

Giao diện này được sử dụng cùng với giao diện [`ITextFrameFormat`](/slides/python-net/vi/aspose.slides/itextframeformat) để trả về các giá trị định dạng hiệu quả với tính kế thừa được áp dụng.
