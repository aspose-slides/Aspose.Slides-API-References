## TextVerticalType liệt kê

Xác định chế độ viết dọc cho một đoạn văn bản.

Kiểu TextVerticalType cung cấp các thành viên sau:

## Trường

| Trường | Mô tả |
| :- | :- |
| NOT_DEFINED | Chưa được định nghĩa. |
| HORIZONTAL | Văn bản ngang. |
| VERTICAL | Văn bản dọc. |
| VERTICAL270 | Văn bản dọc 270 độ. |
| WORD_ART_VERTICAL | Văn bản dọc WordArt. |
| EAST_ASIAN_VERTICAL | Văn bản dọc Đông Á. |
| MONGOLIAN_VERTICAL | Văn bản dọc Mông Cổ. |
| WORD_ART_VERTICAL_RIGHT_TO_LEFT | Văn bản dọc WordArt từ phải sang trái. |
