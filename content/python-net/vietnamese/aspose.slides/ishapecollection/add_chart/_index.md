Tạo một biểu đồ mới, khởi tạo nó với dữ liệu và cài đặt mẫu, và thêm nó vào cuối bộ sưu tập shape.

```python
def add_chart(self, type, x, y, width, height, init_with_sample):
    ...
```

| Tham số | Kiểu | Mô tả |
| :- | :- | :- |
| type | [`ChartType`](/slides/python-net/vi/aspose.slides.charts/charttype) | Kiểu biểu đồ cần thêm. |
| x | **float** | Tọa độ x của biểu đồ mới, tính bằng điểm. |
