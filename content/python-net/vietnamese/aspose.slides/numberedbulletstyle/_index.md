## Liệt kê NumberedBulletStyle

Đại diện cho kiểu dáng của các dấu đầu dòng có số.

Kiểu NumberedBulletStyle cung cấp các thành viên sau:

## Trường

| Trường | Mô tả |
| :- | :- |
| NOT_DEFINED | Chưa định nghĩa. |
| BULLET_ALPHA_LC_PERIOD | Các ký tự chữ cái thường kèm dấu chấm. Sample: a., b., c., ... |
| BULLET_ALPHA_UC_PERIOD | Các ký tự chữ cái hoa kèm dấu chấm. Sample: A., B., C., ... |
| BULLET_ARABIC_PAREN_RIGHT | Số Ả Rập kèm dấu ngoặc đóng. Sample: 1), 2), 3), ... |
| BULLET_ARABIC_PERIOD | Số Ả Rập kèm dấu chấm. Sample: 1., 2., 3., ... |
| BULLET_ROMAN_LC_PAREN_BOTH | Số La Mã thường kèm cả hai dấu ngoặc. Sample: (i), (ii), (iii), ... |
| BULLET_ROMAN_LC_PAREN_RIGHT | Số La Mã thường kèm dấu ngoặc đóng. Sample: i), ii), iii), ... |
| BULLET_ROMAN_LC_PERIOD | Số La Mã thường kèm dấu chấm. Sample: i., ii., iii., ... |
| BULLET_ROMAN_UC_PERIOD | Số La Mã hoa kèm dấu chấm. Sample: I., II., III., ... |
| BULLET_ALPHA_LC_PAREN_BOTH | Các ký tự chữ cái thường kèm cả hai dấu ngoặc. Sample: (a), (b), (c), ... |
| BULLET_ALPHA_LC_PAREN_RIGHT | Các ký tự chữ cái thường kèm dấu ngoặc đóng. Sample: a), b), c), ... |
| BULLET_ALPHA_UC_PAREN_BOTH | Các ký tự chữ cái hoa kèm cả hai dấu ngoặc. Sample: (A), (B), (C), ... |
| BULLET_ALPHA_UC_PAREN_RIGHT | Các ký tự chữ cái hoa kèm dấu ngoặc đóng. Sample: A), B), C), ... |
| BULLET_ARABIC_PAREN_BOTH | Số Ả Rập kèm cả hai dấu ngoặc. Sample: (1), (2), (3), ... |
| BULLET_ARABIC_PLAIN | Số Ả Rập. Sample: 1, 2, 3, ... |
| BULLET_ROMAN_UC_PAREN_BOTH | Số La Mã hoa kèm cả hai dấu ngoặc. Sample: (I), (II), (III), ... |
| BULLET_ROMAN_UC_PAREN_RIGHT | Số La Mã hoa kèm dấu ngoặc đóng. Sample: I), II), III), ... |
| BULLET_SIMP_CHIN_PLAIN | Tiếng Trung giản thể không có dấu chấm. |
| BULLET_SIMP_CHIN_PERIOD | Tiếng Trung giản thể có dấu chấm. |
| BULLET_CIRCLE_NUM_DB_PLAIN | Số trong vòng tròn double-byte cho các giá trị tới 10, từ 11 - số Ả Rập. |
| BULLET_CIRCLE_NUM_WD_WHITE_PLAIN | Số màu văn bản với vòng tròn cùng màu quanh nó (số vòng tròn trắng Wingdings). Từ 11 - số Ả Rập. |
| BULLET_CIRCLE_NUM_WD_BLACK_PLAIN | Số màu bóng với nền vòng tròn màu văn bản thường (số vòng tròn đen Wingdings). |
| BULLET_TRAD_CHIN_PLAIN | Tiếng Trung truyền thống không có dấu chấm. |
| BULLET_TRAD_CHIN_PERIOD | Tiếng Trung truyền thống có dấu chấm. |
| BULLET_ARABIC_ALPHA_DASH | Các ký tự chữ cái tiếng Ả Rập kèm dấu gạch nối. |
| BULLET_ARABIC_ABJAD_DASH | Bảng chữ cái Abjad tiếng Ả Rập kèm dấu gạch nối. |
| BULLET_HEBREW_ALPHA_DASH | Các ký tự chữ cái tiếng Hebrew kèm dấu gạch nối. |
| BULLET_KANJI_KOREAN_PLAIN | Số tiếng Nhật/Hàn không có dấu chấm. |
| BULLET_KANJI_KOREAN_PERIOD | Số tiếng Nhật/Hàn có dấu chấm. |
| BULLET_ARABIC_DB_PLAIN | Hệ thống đánh số Arabic double-byte (không có dấu câu). |
| BULLET_ARABIC_DB_PERIOD | Hệ thống đánh số Arabic double-byte có dấu chấm double-byte. |
| BULLET_THAI_ALPHA_PERIOD | Chữ Thai có dấu chấm. |
| BULLET_THAI_ALPHA_PAREN_RIGHT | Chữ Thai với dấu ngoặc đơn - phải. |
| BULLET_THAI_ALPHA_PAREN_BOTH | Chữ Thai với cả hai dấu ngoặc đơn. |
| BULLET_THAI_NUM_PERIOD | Số Thai có dấu chấm. |
| BULLET_THAI_NUM_PAREN_RIGHT | Số Thai với dấu ngoặc đơn - phải. |
| BULLET_THAI_NUM_PAREN_BOTH | Số Thai với cả hai dấu ngoặc đơn. |
| BULLET_HINDI_ALPHA_PERIOD | Chữ Hindi có dấu chấm - nguyên âm. |
| BULLET_HINDI_NUM_PERIOD | Số Hindi có dấu chấm. |
| BULLET_KANJI_SIMP_CHIN_DB_PERIOD | Kanji Chinese đơn giản DBPeriod. |
| BULLET_HINDI_NUM_PAREN_RIGHT | Số Hindi với dấu ngoặc đơn - phải. |
| BULLET_HINDI_ALPHA_1_PERIOD | Chữ Hindi có dấu chấm - phụ âm. |
