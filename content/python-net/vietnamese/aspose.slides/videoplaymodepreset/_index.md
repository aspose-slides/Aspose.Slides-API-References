## VideoPlayModePreset liệt kê

Các hằng số xác định cách một video được phát.

Kiểu VideoPlayModePreset cung cấp các thành viên sau:

## Trường

| Trường | Mô tả |
| :- | :- |
| MIXED |  |
| AUTO | Phát tự động. |
| ON_CLICK | Chỉ phát khi người dùng nhấp vào khung video. |
| ALL_SLIDES | Phát trên tất cả các slide. |
| IN_CLICK_SEQUENCE | Phát tự động với một cú nhấp. |
