## ILineFillFormat lớp

Đại diện cho các thuộc tính của việc tô nền cho đường.

Kiểu ILineFillFormat mở ra các thành viên sau:

## Thuộc tính

| Property | Description |
| :- | :- |
| [`fill_type`](/slides/python-net/vi/aspose.slides/ilinefillformat/fill_type/) | Trả về hoặc đặt loại tô nền.<br/>            Đọc/ghi [`FillType`](/slides/python-net/vi/aspose.slides/filltype). |

| [`gradient_format`](/slides/python-net/vi/aspose.slides/ilinefillformat/gradient_format/) | Trả về định dạng tô nền gradient.<br/>            Chỉ đọc [`IGradientFormat`](/slides/python-net/vi/aspose.slides/igradientformat). |
