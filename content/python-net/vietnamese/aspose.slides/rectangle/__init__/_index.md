## __init__(self, x=0, y=0, width=0, height=0) {#int-int-int-int}
Tạo một hình chữ nhật với vị trí và kích thước được chỉ định. Các giá trị float sẽ được cắt giảm thành số nguyên.

```python
def __init__(self, x=0, y=0, width=0, height=0):
    ...
```

| Tham số | Kiểu | Mô tả |
| :- | :- | :- |
| x | **int** | Tọa độ x của góc trên-trái của hình chữ nhật. |
| y | **int** | Tọa độ y của góc trên-trái của hình chữ nhật. |
| width | **int** | Chiều rộng của hình chữ nhật. |
| height | **int** | Chiều cao của hình chữ nhật. |

### Ngoại lệ

| Ngoại lệ | Mô tả |
| :- | :- |
