## IEffectFormat class

Đại diện cho các thuộc tính hiệu ứng của hình.

Kiểu IEffectFormat cung cấp các thành viên sau:

## Thuộc tính

| Property | Mô tả |
| :- | :- |
| [`is_no_effects`](/slides/python-net/vi/aspose.slides/ieffectformat/is_no_effects/) | Trả về true nếu tất cả các hiệu ứng bị tắt (khi vừa tạo, đối tượng EffectFormat mặc định).<br/>            Chỉ đọc **bool**. |
| [`blur_effect`](/slides/python-net/vi/aspose.slides/ieffectformat/blur_effect/) | Hiệu ứng làm mờ.<br/>            Đọc/ghi [`IBlur`](/slides/python-net/vi/aspose.slides.effects/iblur). |
| [`fill_overlay_effect`](/slides/python-net/vi/aspose.slides/ieffectformat/fill_overlay_effect/) | Hiệu ứng phủ màu nền.<br/>            Đọc/ghi [`IFillOverlay`](/slides/python-net/vi/aspose.slides.effects/ifilloverlay). |
| [`glow_effect`](/slides/python-net/vi/aspose.slides/ieffectformat/glow_effect/) | Hiệu ứng phát sáng.<br/>            Đọc/ghi [`IGlow`](/slides/python-net/vi/aspose.slides.effects/iglow). |
| [`inner_shadow_effect`](/slides/python-net/vi/aspose.slides/ieffectformat/inner_shadow_effect/) | Bóng nội.<br/>            Đọc/ghi [`IInnerShadow`](/slides/python-net/vi/aspose.slides.effects/iinnershadow). |
| [`outer_shadow_effect`](/slides/python-net/vi/aspose.slides/ieffectformat/outer_shadow_effect/) | Bóng ngoại.<br/>            Đọc/ghi [`IOuterShadow`](/slides/python-net/vi/aspose.slides.effects/ioutershadow). |
| [`preset_shadow_effect`](/slides/python-net/vi/aspose.slides/ieffectformat/preset_shadow_effect/) | Bóng đặt sẵn.<br/>            Đọc/ghi [`IPresetShadow`](/slides/python-net/vi/aspose.slides.effects/ipresetshadow). |
| [`reflection_effect`](/slides/python-net/vi/aspose.slides/ieffectformat/reflection_effect/) | Phản chiếu.<br/>            Đọc/ghi [`IReflection`](/slides/python-net/vi/aspose.slides.effects/ireflection). |
| [`soft_edge_effect`](/slides/python-net/vi/aspose.slides/ieffectformat/soft_edge_effect/) | Đường viền mềm.<br/>            Đọc/ghi [`ISoftEdge`](/slides/python-net/vi/aspose.slides.effects/isoftedge). |
