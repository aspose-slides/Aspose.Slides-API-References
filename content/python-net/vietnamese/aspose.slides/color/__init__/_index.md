## __init__(self, r=0, g=0, b=0, a=255) {#int-int-int-int}
Tạo một màu từ các giá trị thành phần đỏ, xanh lá, xanh dương và alpha được chỉ định.

```python
def __init__(self, r=0, g=0, b=0, a=255):
    ...
```

| Tham số | Kiểu | Mô tả |
| :- | :- | :- |
| r | **int** | Giá trị thành phần đỏ. Giá trị hợp lệ từ 0 đến 255. |
| g | **int** | Giá trị thành phần xanh lá. Giá trị hợp lệ từ 0 đến 255. |
| b | **int** | Giá trị thành phần xanh dương. Giá trị hợp lệ từ 0 đến 255. |
| a | **int** | Giá trị thành phần alpha. Giá trị hợp lệ từ 0 đến 255. |

### Ngoại lệ

| Ngoại lệ | Mô tả |
| :- | :- |
| **ValueError** | Giá trị một thành phần nhỏ hơn 0 hoặc lớn hơn 255. |
| **TypeError** | Giá trị một thành phần không phải là số. |
