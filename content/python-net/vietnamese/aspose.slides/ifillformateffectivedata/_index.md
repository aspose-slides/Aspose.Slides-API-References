## IFillFormatEffectiveData lớp

Đối tượng bất biến chứa các thuộc tính định dạng tô đầy hiệu quả.

Kiểu IFillFormatEffectiveData cung cấp các thành viên sau:

## Thuộc tính

| Thuộc tính | Mô tả |
| :- | :- |
| [`fill_type`](/slides/python-net/vi/aspose.slides/ifillformateffectivedata/fill_type/) | Trả về kiểu tô.<br/>            Chỉ đọc [`FillType`](/slides/python-net/vi/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/vi/aspose.slides/ifillformateffectivedata/solid_fill_color/) | Trả về màu tô.<br/>            Chỉ đọc **aspose.slides.Color**. |
| [`solid_fill_scheme_color`](/slides/python-net/vi/aspose.slides/ifillformateffectivedata/solid_fill_scheme_color/) | Lấy màu tô được định nghĩa bởi một bảng màu.<br/>            Giá trị [`SchemeColor.NOT_DEFINED`](/slides/python-net/vi/aspose.slides/schemecolor/NOT_DEFINED) cho biết [`IFillFormatEffectiveData.solid_fill_color`](/slides/python-net/vi/aspose.slides/ifillformateffectivedata/solid_fill_color) <br/>            không phải là màu trong bảng màu.<br/>            Chỉ đọc [`SchemeColor`](/slides/python-net/vi/aspose.slides/schemecolor). |
| [`gradient_format`](/slides/python-net/vi/aspose.slides/ifillformateffectivedata/gradient_format/) | Trả về định dạng tô gradient.<br/>            Chỉ đọc [`IGradientFormatEffectiveData`](/slides/python-net/vi/aspose.slides/igradientformateffectivedata). |
| [`pattern_format`](/slides/python-net/vi/aspose.slides/ifillformateffectivedata/pattern_format/) | Trả về định dạng tô mẫu.<br/>            Chỉ đọc [`IPatternFormatEffectiveData`](/slides/python-net/vi/aspose.slides/ipatternformateffectivedata). |
| [`picture_fill_format`](/slides/python-net/vi/aspose.slides/ifillformateffectivedata/picture_fill_format/) | Trả về định dạng tô ảnh.<br/>            Chỉ đọc [`IPictureFillFormatEffectiveData`](/slides/python-net/vi/aspose.slides/ipicturefillformateffectivedata). |
| [`rotate_with_shape`](/slides/python-net/vi/aspose.slides/ifillformateffectivedata/rotate_with_shape/) | Xác định liệu màu tô có nên xoay cùng hình dạng hay không.<br/>            Chỉ đọc **bool**. |


### Ghi chú

Giao diện này được sử dụng cùng với giao diện [`IFillFormat`](/slides/python-net/vi/aspose.slides/ifillformat) để trả về các giá trị định dạng hiệu quả với kế thừa được áp dụng.
