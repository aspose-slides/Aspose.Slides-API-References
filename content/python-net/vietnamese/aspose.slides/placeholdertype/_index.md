## PlaceholderType liệt kê

Biểu thị loại của một placeholder.

Kiểu PlaceholderType cung cấp các thành viên sau:

## Trường

| Trường | Mô tả |
| :- | :- |
| TITLE | Tiêu đề. |
| BODY | Thân bài. |
| CENTERED_TITLE | Tiêu đề căn giữa. |
| SUBTITLE | Phụ đề. |
| DATE_AND_TIME | Ngày và Giờ. |
| SLIDE_NUMBER | Số slide. |
| FOOTER | Chân trang. |
| HEADER | Đầu trang. |
| OBJECT | Đối tượng. |
| CHART | Biểu đồ. |
| TABLE | Bảng. |
| CLIP_ART | Clip Art. |
| DIAGRAM | Sơ đồ. |
| MEDIA | Phương tiện. |
| SLIDE_IMAGE | Hình ảnh slide. |
| PICTURE | Hình ảnh. |
