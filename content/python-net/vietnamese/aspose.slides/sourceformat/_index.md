## Liệt kê SourceFormat

Biểu thị định dạng tệp nguồn.

Kiểu SourceFormat cung cấp các thành viên sau:

## Các trường

| Trường | Mô tả |
| :- | :- |
| PPT | Bản trình bày Microsoft PowerPoint 97-2003 (*.ppt). |
| PPTX | Bản trình bày Microsoft Office Open XML (*.pptx). |
| ODP | Bản trình bày OpenDocument (*.odp). |
| PPTM | Bản trình bày Microsoft Office Open XML có hỗ trợ macro (*.pptm). |
| PPSX | Trình chiếu Microsoft Office Open XML (*.ppsx). |
| PPSM | Trình chiếu Microsoft Office Open XML có hỗ trợ macro (*.ppsm). |
| POTX | Mẫu Microsoft Office Open XML (*.potx). |
| POTM | Mẫu Microsoft Office Open XML có hỗ trợ macro (*.potm). |
| PPS | Trình chiếu Microsoft PowerPoint 97-2003 (*.pps). |
| POT | Mẫu Microsoft PowerPoint 97-2003 (*.pot). |
| OTP | Mẫu bản trình bày OpenDocument (*.otp). |
| FODP | Bản trình bày Flat XML ODF (*.fodp). |
| XML | Bản trình bày PowerPoint XML (*.xml). |
