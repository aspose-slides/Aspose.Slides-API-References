## __init__(self, width=0, height=0) {#int-int}
Tạo một kích thước với chiều rộng và chiều cao đã chỉ định. Các giá trị float sẽ được làm tròn xuống thành số nguyên.


```python
def __init__(self, width=0, height=0):
    ...
```


| Tham số | Kiểu | Mô tả |
| :- | :- | :- |
| width | **int** | Thành phần chiều rộng của kích thước mới. |
| height | **int** | Thành phần chiều cao của kích thước mới. |

### Ngoại lệ

| Ngoại lệ | Mô tả |
| :- | :- |
