## IImage lớp

Biểu diễn một hình ảnh raster hoặc vector.

Kiểu IImage cung cấp các thành viên sau:

## Thuộc tính

| Property | Mô tả |
| :- | :- |
| [`size`](/slides/python-net/vi/aspose.slides/iimage/size/) | Lấy kích thước của hình ảnh. |
| [`width`](/slides/python-net/vi/aspose.slides/iimage/width/) | Lấy chiều rộng của hình ảnh tính bằng pixel. |
| [`height`](/slides/python-net/vi/aspose.slides/iimage/height/) | Lấy chiều cao của hình ảnh tính bằng pixel. |

### Ghi chú

Giao diện này cung cấp một mô hình trừu tượng chung để xử lý cả hình ảnh raster và vector.  
            Các triển khai có thể khác nhau tùy thuộc vào loại hình ảnh nền.
