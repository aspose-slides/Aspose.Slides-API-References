## layout_slides thuộc tính
Trả về danh sách tất cả các slide bố cục được định nghĩa trong bản trình diễn.
            Chỉ đọc [`IGlobalLayoutSlideCollection`](/slides/python-net/vi/aspose.slides/igloballayoutslidecollection).


### Ghi chú

Bạn có thể truy cập API thay thế để thêm/chèn/xóa/nhân bản các slide bố cục 
            bằng cách sử dụng IMasterSlide.LayoutSlides thuộc tính.
