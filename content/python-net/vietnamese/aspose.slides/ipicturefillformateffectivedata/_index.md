## IPictureFillFormatEffectiveData lớp

Đối tượng bất biến chứa các thuộc tính của việc tô nền bằng hình ảnh.

Kiểu IPictureFillFormatEffectiveData cung cấp các thành viên sau:

## Thuộc tính

| Thuộc tính | Mô tả |
| :- | :- |
| [`dpi`](/slides/python-net/vi/aspose.slides/ipicturefillformateffectivedata/dpi/) | Trả về dpi được sử dụng để tô nền hình ảnh.<br/>            Chỉ đọc **int**. |
| [`picture_fill_mode`](/slides/python-net/vi/aspose.slides/ipicturefillformateffectivedata/picture_fill_mode/) | Trả về chế độ tô nền hình ảnh.<br/>            Chỉ đọc [`PictureFillMode`](/slides/python-net/vi/aspose.slides/picturefillmode). |
| [`picture`](/slides/python-net/vi/aspose.slides/ipicturefillformateffectivedata/picture/) | Trả về hình ảnh.<br/>            Chỉ đọc [`IPictureEffectiveData`](/slides/python-net/vi/aspose.slides/ipictureeffectivedata). |
| [`crop_left`](/slides/python-net/vi/aspose.slides/ipicturefillformateffectivedata/crop_left/) | Trả về tỷ lệ phần trăm chiều rộng thực của hình ảnh bị cắt bỏ<br/>            phía bên trái của hình.<br/>            Chỉ đọc **float**. |

| [`crop_right`](/slides/python-net/vi/aspose.slides/ipicturefillformateffectivedata/crop_right/) | Trả về tỷ lệ phần trăm chiều rộng thực của hình ảnh bị cắt bỏ<br/>            phía bên phải của hình.<br/>            Chỉ đọc **float**. |
| [`crop_bottom`](/slides/python-net/vi/aspose.slides/ipicturefillformateffectivedata/crop_bottom/) | Trả về tỷ lệ phần trăm chiều cao thực của hình ảnh bị cắt bỏ<br/>            phía dưới của hình.<br/>            Chỉ đọc **float**. |
