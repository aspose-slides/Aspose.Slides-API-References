## BulletType liệt kê

Đại diện cho loại các dấu đầu dòng mở rộng.

Kiểu BulletType cung cấp các thành viên sau:

## Trường

| Trường | Mô tả |
| :- | :- |
| NOT_DEFINED |  |
| NONE |  |
| SYMBOL | Các ký tự đầu dòng dạng biểu tượng. |
| NUMBERED | Các ký tự đầu dòng dạng số. |
| PICTURE | Các ký tự đầu dòng dạng hình ảnh. |
