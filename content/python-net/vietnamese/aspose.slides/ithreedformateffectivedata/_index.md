## IThreeDFormatEffectiveData class

Đối tượng bất biến đại diện cho các thuộc tính định dạng 3-D hiệu quả.

Kiểu IThreeDFormatEffectiveData cung cấp các thành viên sau:

## Thuộc tính

| Thuộc tính | Mô tả |
| :- | :- |
| [`contour_width`](/slides/python-net/vi/aspose.slides/ithreedformateffectivedata/contour_width/) | Trả về chiều rộng của một đường viền 3D.<br/>            Chỉ đọc **float**. |
| [`extrusion_height`](/slides/python-net/vi/aspose.slides/ithreedformateffectivedata/extrusion_height/) | Trả về chiều cao của hiệu ứng đùn ra.<br/>            Chỉ đọc **float**. |
| [`depth`](/slides/python-net/vi/aspose.slides/ithreedformateffectivedata/depth/) | Trả về độ sâu của một hình dạng 3D.<br/>            Chỉ đọc **float**. |
| [`bevel_top`](/slides/python-net/vi/aspose.slides/ithreedformateffectivedata/bevel_top/) | Trả về kiểu của viền 3D trên.<br/>            Chỉ đọc [`IShapeBevelEffectiveData`](/slides/python-net/vi/aspose.slides/ishapebeveleffectivedata). |
| [`bevel_bottom`](/slides/python-net/vi/aspose.slides/ithreedformateffectivedata/bevel_bottom/) | Trả về kiểu của viền 3D dưới.<br/>            Chỉ đọc [`IShapeBevelEffectiveData`](/slides/python-net/vi/aspose.slides/ishapebeveleffectivedata). |
| [`contour_color`](/slides/python-net/vi/aspose.slides/ithreedformateffectivedata/contour_color/) | Trả về màu của đường viền.<br/>            Chỉ đọc **aspose.slides.Color**. |
| [`extrusion_color`](/slides/python-net/vi/aspose.slides/ithreedformateffectivedata/extrusion_color/) | Trả về màu của phần đùn.<br/>            Chỉ đọc **aspose.slides.Color**. |
| [`camera`](/slides/python-net/vi/aspose.slides/ithreedformateffectivedata/camera/) | Trả về cài đặt của máy ảnh.<br/>            Chỉ đọc [`ICameraEffectiveData`](/slides/python-net/vi/aspose.slides/icameraeffectivedata). |
| [`light_rig`](/slides/python-net/vi/aspose.slides/ithreedformateffectivedata/light_rig/) | Trả về kiểu của ánh sáng.<br/>            Chỉ đọc [`ILightRigEffectiveData`](/slides/python-net/vi/aspose.slides/ilightrigeffectivedata). |
| [`material`](/slides/python-net/vi/aspose.slides/ithreedformateffectivedata/material/) | Trả về kiểu của vật liệu.<br/>            Chỉ đọc [`MaterialPresetType`](/slides/python-net/vi/aspose.slides/materialpresettype). |
