## Lớp CustomXmlPart

Đại diện cho phần xml tùy chỉnh.

Kiểu CustomXmlPart cung cấp các thành viên sau:

## Thuộc tính

| Thuộc tính | Mô tả |
| :- | :- |
| [`xml_data`](/slides/python-net/vi/aspose.slides/customxmlpart/xml_data/) | Trả về hoặc thiết lập dữ liệu xml.<br/>            Đọc/ghi **int**[].<br/>            giá trị là `None`.giá trị trống hoặc dữ liệu xml không hợp lệ. |
| [`xml_as_string`](/slides/python-net/vi/aspose.slides/customxmlpart/xml_as_string/) | Trả về hoặc thiết lập dữ liệu xml dưới dạng chuỗi UTF-8.<br/>            Đọc/ghi **str**.<br/>            giá trị là `None`.giá trị trống hoặc dữ liệu xml không hợp lệ. |
| [`item_id`](/slides/python-net/vi/aspose.slides/customxmlpart/item_id/) | Xác định một định danh toàn cục duy nhất (GUID) mà duy nhất nhận dạng một phần XML tùy chỉnh <br/>            trong tài liệu Office Open XML.<br/>            Chỉ đọc **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/vi/aspose.slides/customxmlpart/namespace_schemas/) | Trả về bộ sưu tập các lược đồ XML được liên kết với phần XML tùy chỉnh.<br/>            Chỉ đọc **str**[]. |
