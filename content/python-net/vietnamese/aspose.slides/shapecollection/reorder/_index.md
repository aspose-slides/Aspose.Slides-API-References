```python
def reorder(self, index, shape):
    ...
```

| Tham số | Kiểu | Mô tả |
| :- | :- | :- |
| index | **int** | Chỉ mục đích dựa trên số 0, nơi hình dạng sẽ được đặt. |
| shape | [`IShape`](/slides/python-net/vi/aspose.slides/ishape) | [`IShape`](/slides/python-net/vi/aspose.slides/ishape) cần di chuyển trong bộ sưu tập. |

```python
def reorder(self, index, shapes):
    ...
```

| Tham số | Kiểu | Mô tả |
| :- | :- | :- |
| index | **int** | Chỉ mục đích dựa trên số 0, nơi hình dạng đã chỉ định đầu tiên sẽ được đặt; <br/><br/>            các hình dạng tiếp theo sẽ theo thứ tự đã cung cấp. |
