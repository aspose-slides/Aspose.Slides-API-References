```python
def add_chart(self, type, x, y, width, height, init_with_sample):
    ...
```


| Tham số | Kiểu | Mô tả |
| :- | :- | :- |
| type | [`ChartType`](/slides/python-net/vi/aspose.slides.charts/charttype) | Loại biểu đồ cần thêm. |
| x | **float** | Tọa độ x của biểu đồ mới, tính bằng point. |
| y | **float** | Tọa độ y của biểu đồ mới, tính bằng point. |
