## PathFillModeType liệt kê

Xác định cách mà một đường cần được tô

Kiểu PathFillModeType cung cấp các thành viên sau:

## Trường

| Trường | Mô tả |
| :- | :- |
| NONE | No Path Fill<br/>            Điều này chỉ định rằng đường tương ứng không có nền. |
| NORMAL | Normal Path Fill<br/>            Điều này chỉ định rằng đường tương ứng nên có màu được tô bóng một cách bình thường. |
| LIGHTEN | Lighten Path Fill<br/>            Điều này chỉ định rằng đường tương ứng nên có màu được tô bóng nhẹ. |
| LIGHTEN_LESS | Lighten Path Fill Less<br/>            Điều này chỉ định rằng đường tương ứng nên có màu được tô bóng nhẹ hơn một chút. |
| DARKEN | Darken Path Fill<br/>            Điều này chỉ định rằng đường tương ứng nên có màu được tô bóng tối hơn. |
| DARKEN_LESS | Darken Path Fill Less<br/>            Điều này chỉ định rằng đường tương ứng nên có màu được tô bóng tối hơn một chút. |
