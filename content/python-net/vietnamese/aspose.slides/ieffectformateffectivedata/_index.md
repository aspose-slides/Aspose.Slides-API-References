## IEffectFormatEffectiveData lớp

Đối tượng bất biến chứa các thuộc tính định dạng hiệu ứng thực tế.

Kiểu IEffectFormatEffectiveData công bố các thành viên sau:

## Thuộc tính

| Thuộc tính | Mô tả |
| :- | :- |
| [`is_no_effects`](/slides/python-net/vi/aspose.slides/ieffectformateffectivedata/is_no_effects/) | Trả về true nếu tất cả các hiệu ứng bị tắt (như vừa mới tạo, đối tượng EffectFormat mặc định).<br/>Chỉ đọc **bool**. |
| [`blur_effect`](/slides/python-net/vi/aspose.slides/ieffectformateffectivedata/blur_effect/) | Hiệu ứng làm mờ.<br/>Chỉ đọc [`IBlurEffectiveData`](/slides/python-net/vi/aspose.slides.effects/iblureffectivedata). |
| [`fill_overlay_effect`](/slides/python-net/vi/aspose.slides/ieffectformateffectivedata/fill_overlay_effect/) | Hiệu ứng phủ nền.<br/>Chỉ đọc [`IFillOverlayEffectiveData`](/slides/python-net/vi/aspose.slides.effects/ifilloverlayeffectivedata). |
| [`glow_effect`](/slides/python-net/vi/aspose.slides/ieffectformateffectivedata/glow_effect/) | Hiệu ứng phát sáng.<br/>Chỉ đọc [`IGlowEffectiveData`](/slides/python-net/vi/aspose.slides.effects/igloweffectivedata). |
| [`inner_shadow_effect`](/slides/python-net/vi/aspose.slides/ieffectformateffectivedata/inner_shadow_effect/) | Bóng nội.<br/>Chỉ đọc [`IInnerShadowEffectiveData`](/slides/python-net/vi/aspose.slides.effects/iinnershadoweffectivedata). |
| [`outer_shadow_effect`](/slides/python-net/vi/aspose.slides/ieffectformateffectivedata/outer_shadow_effect/) | Bóng ngoại.<br/>Chỉ đọc [`IOuterShadowEffectiveData`](/slides/python-net/vi/aspose.slides.effects/ioutershadoweffectivedata). |
| [`preset_shadow_effect`](/slides/python-net/vi/aspose.slides/ieffectformateffectivedata/preset_shadow_effect/) | Bóng chuẩn.<br/>Chỉ đọc [`IPresetShadowEffectiveData`](/slides/python-net/vi/aspose.slides.effects/ipresetshadoweffectivedata). |
| [`reflection_effect`](/slides/python-net/vi/aspose.slides/ieffectformateffectivedata/reflection_effect/) | Phản chiếu.<br/>Chỉ đọc [`IReflectionEffectiveData`](/slides/python-net/vi/aspose.slides.effects/ireflectioneffectivedata). |
| [`soft_edge_effect`](/slides/python-net/vi/aspose.slides/ieffectformateffectivedata/soft_edge_effect/) | Cạnh mềm.<br/>Chỉ đọc [`ISoftEdgeEffectiveData`](/slides/python-net/vi/aspose.slides.effects/isoftedgeeffectivedata). |

### Ghi chú

Giao diện này được sử dụng cùng với giao diện [`IEffectFormat`](/slides/python-net/vi/aspose.slides/ieffectformat) để trả về các giá trị định dạng hiệu lực đã áp dụng kế thừa.
