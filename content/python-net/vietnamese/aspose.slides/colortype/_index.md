## ColorType liệt kê

Biểu thị các chế độ màu khác nhau.

Kiểu ColorType cung cấp các thành viên sau:

## Trường

| Trường | Mô tả |
| :- | :- |
| NOT_DEFINED | Màu không được định nghĩa gì cả. |
| RGB | Màu RGB chuẩn 24bit. |
| RGB_PERCENTAGE | Màu RGB độ phân giải cao. |
| HSL | Màu HSL độ phân giải cao. |
| SCHEME | Màu Scheme. |
| SYSTEM | Màu hệ thống. |
| PRESET | Màu được đặt trước. |
