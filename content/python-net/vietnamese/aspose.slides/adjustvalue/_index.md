## AdjustValue lớp

Đại diện cho giá trị điều chỉnh của hình dạng hình học. Các giá trị này ảnh hưởng tới hình dạng của hình.

Kiểu AdjustValue cung cấp các thành viên sau:

## Thuộc tính

| Thuộc tính | Mô tả |
| :- | :- |
| [`raw_value`](/slides/python-net/vi/aspose.slides/adjustvalue/raw_value/) | Trả về hoặc đặt giá trị điều chỉnh "as is".<br/>            Đọc/ghi **int**. |
| [`angle_value`](/slides/python-net/vi/aspose.slides/adjustvalue/angle_value/) | Trả về hoặc đặt giá trị, diễn giải nó như góc tính bằng độ.<br/>            Đọc/ghi **float**. |
| [`name`](/slides/python-net/vi/aspose.slides/adjustvalue/name/) | Trả về tên của giá trị điều chỉnh này.<br/>            Chỉ đọc **str**. |
| [`type`](/slides/python-net/vi/aspose.slides/adjustvalue/type/) | Trả về kiểu của điều chỉnh hình dạng.<br/>            Chỉ đọc [`ShapeAdjustmentType`](/slides/python-net/vi/aspose.slides/shapeadjustmenttype). |
