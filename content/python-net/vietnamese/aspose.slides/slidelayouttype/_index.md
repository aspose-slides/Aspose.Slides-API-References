## SlideLayoutType liệt kê

Đại diện cho kiểu bố cục slide.

Kiểu SlideLayoutType cung cấp các thành viên sau:

## Trường

| Field | Mô tả |
| :- | :- |
| CUSTOM | Tùy chỉnh |
| TITLE | Tiêu đề |
| TEXT | Văn bản |
| TWO_COLUMN_TEXT | Văn bản hai cột |
| TABLE | Bảng |
| TEXT_AND_CHART | Văn bản và Biểu đồ |
| CHART_AND_TEXT | Biểu đồ và Văn bản |
| DIAGRAM | Sơ đồ |
| CHART | Biểu đồ |
| TEXT_AND_CLIP_ART | Văn bản và Ảnh minh hoạ |
| CLIP_ART_AND_TEXT | Ảnh minh hoạ và Văn bản |
| TITLE_ONLY | Chỉ tiêu đề |
| BLANK | Trống |
| TEXT_AND_OBJECT | Văn bản và Đối tượng |
| OBJECT_AND_TEXT | Đối tượng và Văn bản |
| OBJECT | Đối tượng |
| TITLE_AND_OBJECT | Tiêu đề và Đối tượng |
| TEXT_AND_MEDIA | Văn bản và Phương tiện |
| MEDIA_AND_TEXT | Phương tiện và Văn bản |
| OBJECT_OVER_TEXT | Đối tượng trên Văn bản |
| TEXT_OVER_OBJECT | Văn bản trên Đối tượng |
| TEXT_AND_TWO_OBJECTS | Văn bản và Hai Đối tượng |
| TWO_OBJECTS_AND_TEXT | Hai Đối tượng và Văn bản |
| TWO_OBJECTS_OVER_TEXT | Hai Đối tượng trên Văn bản |
| FOUR_OBJECTS | Bốn Đối tượng |
| VERTICAL_TEXT | Văn bản dọc |
| CLIP_ART_AND_VERTICAL_TEXT | Ảnh minh hoạ và Văn bản dọc |
| VERTICAL_TITLE_AND_TEXT | Tiêu đề dọc và Văn bản |
| VERTICAL_TITLE_AND_TEXT_OVER_CHART | Tiêu đề dọc và Văn bản trên Biểu đồ |
| TWO_OBJECTS | Hai Đối tượng |
| OBJECT_AND_TWO_OBJECT | Đối tượng và Hai Đối tượng |
| TWO_OBJECTS_AND_OBJECT | Hai Đối tượng và Đối tượng |
| SECTION_HEADER | Tiêu đề phần |
| TWO_TEXT_AND_TWO_OBJECTS | Hai Văn bản và Hai Đối tượng |
| TITLE_OBJECT_AND_CAPTION | Tiêu đề, Đối tượng, và Chú thích |
| PICTURE_AND_CAPTION | Hình ảnh và Chú thích |
