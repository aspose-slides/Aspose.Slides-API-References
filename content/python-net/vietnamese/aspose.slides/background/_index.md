## Lớp Background

Biểu diễn nền của một slide.

**Kế thừa:**[`Background`](/slides/python-net/vi/aspose.slides/background) → [`PVIObject`](/slides/python-net/vi/aspose.slides/pviobject)

Kiểu Background hiển thị các thành viên sau:

## Thuộc tính

| Property | Description |
| :- | :- |
| [`type`](/slides/python-net/vi/aspose.slides/background/type/) | Trả về một kiểu nền tô màu.<br/>            Đọc/ghi [`BackgroundType`](/slides/python-net/vi/aspose.slides/backgroundtype). |
| [`fill_format`](/slides/python-net/vi/aspose.slides/background/fill_format/) | Trả về một FillFormat cho nền tô kiểu BackgroundType.OwnBackground.<br/>            Chỉ đọc [`IFillFormat`](/slides/python-net/vi/aspose.slides/ifillformat). |
| [`effect_format`](/slides/python-net/vi/aspose.slides/background/effect_format/) | Trả về một EffectFormat cho nền tô kiểu BackgroundType.OwnBackground.<br/>            Chỉ đọc [`IEffectFormat`](/slides/python-net/vi/aspose.slides/ieffectformat). |
| [`style_color`](/slides/python-net/vi/aspose.slides/background/style_color/) | Trả về một ColorFormat cho nền tô kiểu BackgroundType.Themed.<br/>            Chỉ đọc [`IColorFormat`](/slides/python-net/vi/aspose.slides/icolorformat). |
| [`style_index`](/slides/python-net/vi/aspose.slides/background/style_index/) | Trả về chỉ mục của nền tô kiểu BackgroundType.Themed trong bộ sưu tập chủ đề nền.<br/>            0 có nghĩa là không có nền.<br/>            1..999 - chỉ mục.<br/>            Đọc/ghi **int**. |
| [`slide`](/slides/python-net/vi/aspose.slides/background/slide/) | Trả về slide cha của một shape.<br/>            Chỉ đọc [`IBaseSlide`](/slides/python-net/vi/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/vi/aspose.slides/background/presentation/) | Trả về bản trình bày cha của một slide.<br/>            Chỉ đọc [`IPresentation`](/slides/python-net/vi/aspose.slides/ipresentation). |
