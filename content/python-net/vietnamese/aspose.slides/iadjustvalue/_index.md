## IAdjustValue lớp

Biểu diễn giá trị điều chỉnh của hình dạng hình học.
            Các giá trị này ảnh hưởng đến hình dạng của hình.

Kiểu IAdjustValue cung cấp các thành viên sau:

## Thuộc tính

| Thuộc tính | Mô tả |
| :- | :- |
| [`raw_value`](/slides/python-net/vi/aspose.slides/iadjustvalue/raw_value/) | Trả về hoặc đặt giá trị điều chỉnh "nguyên trạng".<br/>            Đọc/ghi **int**. |
| [`angle_value`](/slides/python-net/vi/aspose.slides/iadjustvalue/angle_value/) | Trả về hoặc đặt giá trị, giải thích nó là góc theo độ.<br/>            Đọc/ghi **float**. |
| [`name`](/slides/python-net/vi/aspose.slides/iadjustvalue/name/) | Trả về tên của giá trị điều chỉnh này.<br/>            Chỉ đọc **str**. |
| [`type`](/slides/python-net/vi/aspose.slides/iadjustvalue/type/) | Trả về kiểu của việc điều chỉnh hình dạng.<br/>            Chỉ đọc [`ShapeAdjustmentType`](/slides/python-net/vi/aspose.slides/shapeadjustmenttype). |
