## Kiểu liệt kê ImageFormat

Biểu thị định dạng tệp của hình ảnh.

Kiểu ImageFormat cung cấp các thành viên sau:

## Trường

| Trường | Mô tả |
| :- | :- |
| MEMORY_BMP | Biểu thị định dạng bitmap trong bộ nhớ. |
| BMP | Biểu thị định dạng ảnh bitmap (BMP). |
| EMF | Biểu thị định dạng ảnh enhanced metafile (EMF). |
| WMF | Biểu thị định dạng ảnh Windows metafile (WMF). |
| GIF | Biểu thị định dạng ảnh Graphics Interchange Format (GIF). |
| JPEG | Biểu thị định dạng ảnh Joint Photographic Experts Group (JPEG). |
| PNG | Biểu thị định dạng ảnh W3C Portable Network Graphics (PNG). |
| TIFF | Biểu thị định dạng ảnh Tagged Image File Format (TIFF). |
| EXIF | Biểu thị định dạng Exchangeable Image File (Exif). |
| ICON | Biểu thị định dạng ảnh biểu tượng Windows. |
