## ShapeAdjustmentType liệt kê

Xác định các loại giá trị điều chỉnh hình khác nhau.

Kiểu ShapeAdjustmentType cung cấp các thành viên sau:

## Trường

| Trường | Mô tả |
| :- | :- |
| CUSTOM | Loại tùy chỉnh (điều chỉnh không xác định) |
| CORNER_SIZE | Điều khiển kích thước các góc. |
| LEFT_UP_CORNER | Điều khiển góc trên bên trái. |
| RIGHT_UP_CORNER | Điều khiển góc trên bên phải. |
| UP_CORNERS | Điều khiển các góc trên. |
| DOWN_CORNERS | Điều khiển các góc dưới. |
| THICKNESS | Điều khiển độ dày của hình. |
| ARROW_TAIL_THICKNESS | Điều khiển độ dày của đuôi mũi tên. |
| ARROWHEAD_LENGTH | Điều khiển chiều dài của đầu mũi tên. |
| ARROWHEAD_WIDTH | Điều khiển chiều rộng của đầu mũi tên. |
| RADIUS | Điều khiển kích thước bán kính của hình hoặc phần của nó. |
| DEPTH | Điều khiển độ sâu của răng bánh răng hoặc hiệu ứng chùm. |
| SHAPE_PART_OFFSET | Điều khiển độ lệch của một phần của hình so với phần khác. |
| ANGLE | Điều khiển góc cho hình hoặc phần của nó. |
| START_ANGLE | Góc bắt đầu cho các hình tròn và cung. |
| END_ANGLE | Góc kết thúc cho các hình tròn và cung. |
| START_POINT_X | Điều khiển vị trí X của điểm bắt đầu callout. |
| START_POINT_Y | Điều khiển vị trí Y của điểm bắt đầu callout. |
| CONNECTOR_POINT_1X | Điều khiển vị trí ngang của điểm điều chỉnh góc callout. |
| CONNECTOR_POINT_1Y | Điều khiển vị trí dọc của điểm điều chỉnh góc callout. |
| CONNECTOR_POINT_2X | Điều khiển vị trí ngang của điểm điều chỉnh góc callout. |
| CONNECTOR_POINT_2Y | Điều khiển vị trí dọc của điểm điều chỉnh góc callout. |
| CONNECTOR_BEND_POSITION_X | Điều khiển vị trí ngang của độ cong trong connector. |
| CONNECTOR_BEND_POSITION_Y | Điều khiển vị trí dọc của độ cong trong connector. |
| ATTACH_Y | Điều khiển điểm gắn dọc của hình. |
| ATTACH_X | Điều khiển điểm gắn ngang của hình. |
| CALLOUT_HEIGHT | Điều khiển kích thước dọc của callout. |
| CALLOUT_WIDTH | Điều khiển kích thước ngang của callout. |
| CALLOUT_SIZE | Điều khiển kích thước của callout. |
| CURVATURE | Độ cong của một đoạn uốn, móc, mũi tên cong hoặc hình dạng. |
| HORIZONTAL_THICKNESS | Điều khiển độ dày ngang của hình góc. |
| VERTICAL_THICKNESS | Điều khiển độ dày dọc của hình góc. |
| VERTICAL_SIZE | Điều khiển kích thước dọc của hình. |
| HORIZONTAL_SIZE | Điều khiển kích thước ngang của hình. |
| TOP | Điều khiển phía trên của một hình. |
