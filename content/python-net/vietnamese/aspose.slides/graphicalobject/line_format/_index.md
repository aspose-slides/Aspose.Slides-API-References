## line_format thuộc tính
Returns the LineFormat object that contains line formatting properties for a shape.
            Lưu ý: can return None for certain types of shapes which don't have line properties.
            Chỉ đọc [`ILineFormat`](/slides/python-net/vi/aspose.slides/ilineformat).
