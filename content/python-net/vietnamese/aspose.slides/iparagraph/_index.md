## IParagraph lớp

Đại diện cho một đoạn văn bản.

Kiểu IParagraph cung cấp các thành phần sau:

## Thuộc tính

| Property | Description |
| :- | :- |
| [`portions`](/slides/python-net/vi/aspose.slides/iparagraph/portions/) | Trả về tập hợp các phần văn bản.<br/>            Chỉ-đọc [`IPortionCollection`](/slides/python-net/vi/aspose.slides/iportioncollection). |
| [`paragraph_format`](/slides/python-net/vi/aspose.slides/iparagraph/paragraph_format/) | Trả về đối tượng định dạng cho đoạn văn này.<br/>            Chỉ-đọc [`IParagraphFormat`](/slides/python-net/vi/aspose.slides/iparagraphformat). |
| [`text`](/slides/python-net/vi/aspose.slides/iparagraph/text/) | Lấy hoặc đặt văn bản thuần của một đoạn văn.<br/>            Đọc/ghi **str**. |
| [`end_paragraph_portion_format`](/slides/python-net/vi/aspose.slides/iparagraph/end_paragraph_portion_format/) | Xác định các thuộc tính phần sẽ được sử dụng nếu một phần khác được chèn sau phần cuối cùng. |
| [`slide`](/slides/python-net/vi/aspose.slides/iparagraph/slide/) |  |
| [`presentation`](/slides/python-net/vi/aspose.slides/iparagraph/presentation/) |  |

## Phương thức

| [`join_portions_with_same_formatting`](/slides/python-net/vi/aspose.slides/iparagraph/join_portions_with_same_formatting/#) | Ghép các đoạn chạy có cùng định dạng. |
