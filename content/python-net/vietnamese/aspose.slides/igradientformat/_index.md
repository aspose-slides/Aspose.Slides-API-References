## IGradientFormat lớp

Đại diện cho một định dạng gradient.

Kiểu IGradientFormat cung cấp các thành viên sau:

## Thuộc tính

| Thuộc tính | Mô tả |
| :- | :- |
| [`tile_flip`](/slides/python-net/vi/aspose.slides/igradientformat/tile_flip/) | Trả về hoặc đặt chế độ lật cho gradient.<br/>            Đọc/ghi [`TileFlip`](/slides/python-net/vi/aspose.slides/tileflip). |
| [`gradient_direction`](/slides/python-net/vi/aspose.slides/igradientformat/gradient_direction/) | Trả về hoặc đặt kiểu cho gradient.<br/>            Đọc/ghi [`GradientDirection`](/slides/python-net/vi/aspose.slides/gradientdirection). |
| [`linear_gradient_angle`](/slides/python-net/vi/aspose.slides/igradientformat/linear_gradient_angle/) | Trả về hoặc đặt góc của gradient.<br/>            Đọc/ghi **float**. |
| [`linear_gradient_scaled`](/slides/python-net/vi/aspose.slides/igradientformat/linear_gradient_scaled/) | Xác định liệu gradient có được tỷ lệ hay không.<br/>            Đọc/ghi [`NullableBool`](/slides/python-net/vi/aspose.slides/nullablebool). |
| [`gradient_shape`](/slides/python-net/vi/aspose.slides/igradientformat/gradient_shape/) | Trả về hoặc đặt hình dạng của gradient.<br/>            Đọc/ghi [`GradientShape`](/slides/python-net/vi/aspose.slides/gradientshape). |
| [`gradient_stops`](/slides/python-net/vi/aspose.slides/igradientformat/gradient_stops/) | Trả về bộ sưu tập các dừng gradient.<br/>            Chỉ đọc [`IGradientStopCollection`](/slides/python-net/vi/aspose.slides/igradientstopcollection). |
