## IControl lớp

Đại diện cho một điều khiển ActiveX.

Kiểu IControl cung cấp các thành viên sau:

## Thuộc tính

| Property | Description |
| :- | :- |
| [`name`](/slides/python-net/vi/aspose.slides/icontrol/name/) | Trả về tên của điều khiển này.<br/>            Đọc/ghi **str**. |
| [`class_id`](/slides/python-net/vi/aspose.slides/icontrol/class_id/) | Lấy class id của điều khiển này.<br/>            Chỉ đọc **System.Guid**. |
| [`substitute_picture_format`](/slides/python-net/vi/aspose.slides/icontrol/substitute_picture_format/) | Trả về đối tượng thuộc tính tô ảnh ControlEx.<br/>            Chỉ đọc [`IPictureFillFormat`](/slides/python-net/vi/aspose.slides/ipicturefillformat). |
| [`frame`](/slides/python-net/vi/aspose.slides/icontrol/frame/) | Trả về hoặc đặt khung của điều khiển.<br/>            Đọc/ghi [`IShapeFrame`](/slides/python-net/vi/aspose.slides/ishapeframe). |
| [`properties`](/slides/python-net/vi/aspose.slides/icontrol/properties/) | Trả về một tập hợp các thuộc tính ActiveX.<br/>            Chỉ đọc [`IControlPropertiesCollection`](/slides/python-net/vi/aspose.slides/icontrolpropertiescollection). |
| [`persistence`](/slides/python-net/vi/aspose.slides/icontrol/persistence/) | Lấy phương pháp được sử dụng để lưu trữ các thuộc tính của điều khiển ActiveX.<br/>            Chỉ đọc [`PersistenceType`](/slides/python-net/vi/aspose.slides/persistencetype). |
| [`active_x_control_binary`](/slides/python-net/vi/aspose.slides/icontrol/active_x_control_binary/) | Xác định tính bền vững của một điều khiển ActiveX khi phương pháp được sử dụng để duy trì là PersistStream, PersistStreamInit hoặc PersistStorage. |
