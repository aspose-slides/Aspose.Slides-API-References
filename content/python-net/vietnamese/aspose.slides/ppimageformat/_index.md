## Liệt kê PPImageFormat

Các định dạng hình ảnh. Enum này là sự thay thế cho lớp `System.Drawing.Imaging.ImageFormat`. Nó cần thiết cho khả năng tương thích COM.

Kiểu PPImageFormat cung cấp các thành viên sau:

## Trường

| Trường | Mô tả |
| :- | :- |
| BMP | Lấy định dạng ảnh bitmap (BMP). |
| EMF | Lấy định dạng ảnh enhanced metafile (EMF). |
| EXIF | Lấy định dạng Exchangeable Image File (Exif). |
| GIF | Lấy định dạng Graphics Interchange Format (GIF). |
| ICON | Lấy định dạng ảnh biểu tượng Windows. |
| JPEG | Lấy định dạng Joint Photographic Experts Group (JPEG). |
| MEMORY_BMP | Lấy định dạng bitmap trong bộ nhớ. |
| PNG | Lấy định dạng W3C Portable Network Graphics (PNG). |
| TIFF | Lấy định dạng Tagged Image File Format (TIFF). |
| WMF | Lấy định dạng Windows metafile (WMF). |
