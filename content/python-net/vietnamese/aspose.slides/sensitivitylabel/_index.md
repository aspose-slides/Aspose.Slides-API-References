## SensitivityLabel lớp

Biểu diễn nhãn độ nhạy từ Microsoft Purview Information Protection.

Kiểu SensitivityLabel hiển thị các thành viên sau:

## Thuộc tính

| Thuộc tính | Mô tả |
| :- | :- |
| [`id`](/slides/python-net/vi/aspose.slides/sensitivitylabel/id/) | Trả về hoặc đặt id của nhãn độ nhạy.<br/>            Đọc/ghi **str**. |
| [`site_id`](/slides/python-net/vi/aspose.slides/sensitivitylabel/site_id/) | Trả về hoặc đặt định danh site Azure Active Directory (Azure AD) <br/>            tương ứng với chính sách nhãn độ nhạy mô tả nhãn độ nhạy.<br/>            Đọc/ghi **System.Guid**. |
| [`is_enabled`](/slides/python-net/vi/aspose.slides/sensitivitylabel/is_enabled/) | Cho biết nhãn độ nhạy có được bật hay không. |
| [`is_removed`](/slides/python-net/vi/aspose.slides/sensitivitylabel/is_removed/) | Cho biết nhãn độ nhạy đã bị xóa hay chưa. |
| [`assignment_method_type`](/slides/python-net/vi/aspose.slides/sensitivitylabel/assignment_method_type/) | Trả về hoặc đặt phương pháp gán cho nhãn độ nhạy.<br/>            Đọc/ghi [`SensitivityLabelAssignmentType`](/slides/python-net/vi/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/vi/aspose.slides/sensitivitylabel/content_mark_types/) | Trả về danh sách các loại đánh dấu nội dung cần áp dụng cho tệp. |
