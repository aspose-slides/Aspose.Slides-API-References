## ColorSchemeIndex liệt kê

Đại diện cho một chỉ mục trong một bảng màu.

Kiểu ColorSchemeIndex cung cấp các thành viên sau:

## Trường

| Trường | Mô tả |
| :- | :- |
| DARK1 | Màu tối 1. |
| LIGHT1 | Màu sáng 1. |
| DARK2 | Màu tối 2. |
| LIGHT2 | Màu sáng 2. |
| ACCENT1 | Màu nhấn 1. |
| ACCENT2 | Màu nhấn 2. |
| ACCENT3 | Màu nhấn 3. |
| ACCENT4 | Màu nhấn 4. |
| ACCENT5 | Màu nhấn 5. |
| ACCENT6 | Màu nhấn 6. |
| HYPERLINK | Liên kết siêu văn bản. |
| FOLLOWED_HYPERLINK | Liên kết đã theo dõi. |
