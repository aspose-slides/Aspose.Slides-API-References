## ISlideSize lớp

Kiểu ISlideSize cung cấp các thành viên sau:

## Thuộc tính

| Property | Description |
| :- | :- |
| [`size`](/slides/python-net/vi/aspose.slides/islidesize/size/) | Lấy kích thước slide tính bằng points. |
| [`type`](/slides/python-net/vi/aspose.slides/islidesize/type/) | Lấy loại kích thước slide. |
| [`orientation`](/slides/python-net/vi/aspose.slides/islidesize/orientation/) | Lấy hoặc đặt định hướng slide. |
