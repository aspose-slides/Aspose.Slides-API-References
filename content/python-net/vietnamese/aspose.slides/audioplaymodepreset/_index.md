## AudioPlayModePreset liệt kê

Các hằng số xác định cách âm thanh được phát.

Kiểu AudioPlayModePreset cung cấp các thành viên sau:

## Trường

| Trường | Mô tả |
| :- | :- |
| MIXED |  |
| AUTO | Phát tự động. |
| ON_CLICK | Chỉ phát khi biểu tượng được nhấp. |
| ALL_SLIDES | Phát trên tất cả các slide.<br/>            Vui lòng sử dụng thuộc tính [`IAudioFrame.play_across_slides`](/slides/python-net/vi/aspose.slides/iaudioframe/play_across_slides) thay thế.<br/>            Phần tử này đã lỗi thời kể từ PowerPoint 2013. |
| IN_CLICK_SEQUENCE | Phát tự động khi nhấp. |
