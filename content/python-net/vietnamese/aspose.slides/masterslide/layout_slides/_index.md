## layout_slides thuộc tính
Returns the collection of child layout slides for this master slide.
            Chỉ đọc [`IMasterLayoutSlideCollection`](/slides/python-net/vi/aspose.slides/imasterlayoutslidecollection).


### Ghi chú

You can access to alternative API for adding/inserting/removing/cloning layout slides 
            by using [`IPresentation.layout_slides`](/slides/python-net/vi/aspose.slides/ipresentation/layout_slides) thuộc tính.
