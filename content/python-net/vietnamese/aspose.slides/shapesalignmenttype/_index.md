## ShapesAlignmentType kiểu liệt kê

Xác định cách thay đổi vị trí của các hình dạng đã chọn trên slide.

Kiểu ShapesAlignmentType cung cấp các thành viên sau:

## Trường

| Trường | Mô tả |
| :- | :- |
| ALIGN_LEFT | Căn trái |
| ALIGN_RIGHT | Căn phải |
| ALIGN_CENTER | Căn giữa |
| ALIGN_TOP | Căn trên |
| ALIGN_MIDDLE | Căn giữa |
| ALIGN_BOTTOM | Căn dưới |
| DISTRIBUTE_HORIZONTALLY | Phân bố theo chiều ngang |
| DISTRIBUTE_VERTICALLY | Phân bố theo chiều dọc |
