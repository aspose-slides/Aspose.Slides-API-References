## ISensitivityLabel lớp

Biểu diễn nhãn độ nhạy cảm từ Microsoft Purview Information Protection.

Kiểu ISensitivityLabel cung cấp các thành viên sau:

## Thuộc tính

| Thuộc tính | Mô tả |
| :- | :- |
| [`id`](/slides/python-net/vi/aspose.slides/isensitivitylabel/id/) | Trả về hoặc thiết lập id của nhãn độ nhạy cảm.<br/>            Đọc/ghi **str**. |
| [`site_id`](/slides/python-net/vi/aspose.slides/isensitivitylabel/site_id/) | Trả về hoặc thiết lập định danh site Azure Active Directory (Azure AD) tương ứng với chính sách nhãn độ nhạy cảm mô tả nhãn độ nhạy cảm.<br/>            Đọc/ghi **System.Guid**. |
| [`is_enabled`](/slides/python-net/vi/aspose.slides/isensitivitylabel/is_enabled/) | Cho biết nhãn độ nhạy cảm có được bật hay không. |
| [`is_removed`](/slides/python-net/vi/aspose.slides/isensitivitylabel/is_removed/) | Cho biết nhãn độ nhạy cảm đã bị xóa hay chưa. |
| [`assignment_method_type`](/slides/python-net/vi/aspose.slides/isensitivitylabel/assignment_method_type/) | Trả về hoặc thiết lập phương pháp gán cho nhãn độ nhạy cảm.<br/>            Đọc/ghi [`SensitivityLabelAssignmentType`](/slides/python-net/vi/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/vi/aspose.slides/isensitivitylabel/content_mark_types/) | Trả về danh sách các loại đánh dấu nội dung nên được áp dụng cho tệp. |
