## SlideShowSettings lớp

Đại diện cho các cài đặt trình chiếu của bản trình bày.

Kiểu SlideShowSettings cung cấp các thành viên sau:

## Thuộc tính

| Thuộc tính | Mô tả |
| :- | :- |
| [`slide_show_type`](/slides/python-net/vi/aspose.slides/slideshowsettings/slide_show_type/) | Lấy hoặc đặt loại trình chiếu. Được đại diện bởi các tổ tiên [`SlideShowSettings.slide_show_type`](/slides/python-net/vi/aspose.slides/slideshowsettings/slide_show_type) sau: [`BrowsedAtKiosk`](/slides/python-net/vi/aspose.slides/browsedatkiosk), [`PresentedBySpeaker`](/slides/python-net/vi/aspose.slides/presentedbyspeaker) và [`BrowsedByIndividual`](/slides/python-net/vi/aspose.slides/browsedbyindividual) |
| [`loop`](/slides/python-net/vi/aspose.slides/slideshowsettings/loop/) | Lặp lại trình chiếu |
| [`show_narration`](/slides/python-net/vi/aspose.slides/slideshowsettings/show_narration/) | Hiển thị lời thuyết minh trong trình chiếu |
| [`show_animation`](/slides/python-net/vi/aspose.slides/slideshowsettings/show_animation/) | Hiển thị hoạt ảnh trong trình chiếu |
| [`pen_color`](/slides/python-net/vi/aspose.slides/slideshowsettings/pen_color/) | Màu bút cho trình chiếu |
| [`slides`](/slides/python-net/vi/aspose.slides/slideshowsettings/slides/) | Phạm vi slide |
| [`use_timings`](/vi/slides/python-net/aspose.slides/slideshowsettings/use_timings/) | Sử dụng thời gian trong trình chiếu |
| [`show_media_controls`](/slides/python-net/vi/aspose.slides/slideshowsettings/show_media_controls/) | Hiển thị điều khiển phương tiện |
