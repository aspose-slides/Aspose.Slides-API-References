## TextSearchOptions lớp

Biểu diễn các tùy chọn có thể được sử dụng để tìm kiếm văn bản trong một Presentation, Slide hoặc TextFrame.

Kiểu TextSearchOptions cung cấp các thành viên sau:

## Hàm khởi tạo

| Constructor | Description |
| :- | :- |
| [`__init__(self)`](/slides/python-net/vi/aspose.slides/textsearchoptions/__init__/#) | Tạo các tùy chọn tìm kiếm văn bản mặc định mới. |

## Thuộc tính

| Property | Description |
| :- | :- |
| [`case_sensitive`](/slides/python-net/vi/aspose.slides/textsearchoptions/case_sensitive/) | Đặt true để sử dụng tìm kiếm phân biệt chữ hoa/thường, false - ngược lại.<br/>            Read/write **bool**. |
| [`whole_words_only`](/slides/python-net/vi/aspose.slides/textsearchoptions/whole_words_only/) | Đặt true để chỉ khớp toàn bộ từ, false - ngược lại.<br/>            Read/write **bool**. |
| [`include_notes`](/slides/python-net/vi/aspose.slides/textsearchoptions/include_notes/) | Đặt `true` để bao gồm văn bản trong ghi chú slide ([`NotesSlide`](/slides/python-net/vi/aspose.slides/notesslide)) <br/>            khi thực hiện các thao tác tìm kiếm văn bản, thay thế hoặc làm nổi bật.<br/>            Giá trị mặc định là `false`. |
