## PathCommandType liệt kê

Mô tả các lệnh đường đồ họa

Kiểu PathCommandType cung cấp các thành viên sau:

## Trường

| Trường | Mô tả |
| :- | :- |
| CLOSE | Đóng đường hình học |
| MOVE_TO | Đặt vị trí điểm tiếp theo của đường hình học |
| LINE_TO | Thêm đường thẳng vào đường hình học |
| ARC_TO | Thêm cung chỉ định vào đường hình học. |
| QUAD_BEZIER_TO | Thêm đường cong Bezier bậc hai vào đường hình học |
| CUBIC_BEZIER_TO | Thêm đường cong Bezier bậc ba vào đường hình học |
