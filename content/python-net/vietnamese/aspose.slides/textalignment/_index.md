## TextAlignment liệt kê

Đại diện cho các kiểu căn chỉnh văn bản khác nhau.

Kiểu TextAlignment cung cấp các thành viên sau:

## Trường

| Trường | Mô tả |
| :- | :- |
| NOT_DEFINED | Căn chỉnh mặc định. |
| LEFT | Căn trái. |
| CENTER | Căn giữa. |
| RIGHT | Căn phải. |
| JUSTIFY | Căn đều. |
| JUSTIFY_LOW | Căn đều Kashida thấp. |
| DISTRIBUTED | Căn phân phối. |
