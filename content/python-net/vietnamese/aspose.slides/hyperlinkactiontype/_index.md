## HyperlinkActionType enumeration

Biểu diễn một loại hành động siêu liên kết.

Kiểu HyperlinkActionType cung cấp các thành viên sau:

## Trường

| Trường | Mô tả |
| :- | :- |
| UNKNOWN | Kiểu hành động không xác định. |
| NO_ACTION | Không hành động. |
| HYPERLINK | Siêu liên kết thông thường. |
| JUMP_FIRST_SLIDE | Nhảy đến slide đầu tiên của bản trình chiếu. |
| JUMP_PREVIOUS_SLIDE | Nhảy đến slide trước đó. |
| JUMP_NEXT_SLIDE | Nhảy đến slide tiếp theo. |
| JUMP_LAST_SLIDE | Nhảy đến slide cuối cùng của bản trình chiếu. |
| JUMP_END_SHOW | Nhảy đến cuối buổi trình chiếu. |
| JUMP_LAST_VIEWED_SLIDE | Nhảy đến slide đã xem lần cuối. |
| JUMP_SPECIFIC_SLIDE | Nhảy đến slide cụ thể, được tham chiếu bởi thuộc tính [`IHyperlink.target_slide`](/slides/python-net/vi/aspose.slides/ihyperlink/target_slide). |
| START_CUSTOM_SLIDE_SHOW | Bắt đầu buổi trình chiếu tùy chỉnh. |
| OPEN_FILE | Mở tệp được tham chiếu. |
| OPEN_PRESENTATION | Mở bản trình chiếu được tham chiếu. |
| START_STOP_MEDIA | Bắt đầu/dừng phát tệp media. |
| START_MACRO | Bắt đầu thực thi macro script. |
| START_PROGRAM | Bắt đầu chương trình. |
