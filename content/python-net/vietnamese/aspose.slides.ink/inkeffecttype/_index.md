## InkEffectType liệt kê

Specifies a set of predefined visual effects for ink rendering.
            Mỗi hiệu ứng tương ứng với một kết cấu hoặc hình ảnh mô phỏng hình dạng mực được tạo kiểu.
            Các giá trị này có thể được sử dụng để tùy chỉnh phong cách hình ảnh của các nét mực kỹ thuật số trong quá trình hiển thị.

## Trường

| Trường | Mô tả |
| :- | :- |
| NOT_DEFINED | Hiệu ứng không được xác định hoặc không biết. Giá trị này có thể được sử dụng làm mặc định hoặc dự phòng. |
| BRONZE | Kết cấu kim loại ấm, màu nâu giống mực đồng thau. |
| GALAXY | Kết cấu rực rỡ, lấp lánh giống như một dải ngân hà, với tông màu vũ trụ. |
| GOLD | Kết cấu vàng kim loại sáng bóng, tạo cho nét mực vẻ sang trọng. |
| LAVA | Kết cấu lửa giống dung nham chảy, với sắc đỏ và cam. |
| OCEAN | Kết cấu màu xanh sâu, như chất lỏng, mô phỏng sóng biển hoặc mực dựa trên nước. |
| RAINBOW_GLITTER | Hiệu ứng lấp lánh màu cầu vồng đầy màu sắc, dùng cho các nét mực lễ hội hoặc sống động. |
| ROSE_GOLD | Sự pha trộn màu hồng vàng mềm mại, giống như vàng hồng, cho các nét mực thanh lịch. |
| SILVER | Kết cấu bạc kim loại mát lạnh, mô phỏng mực bạc cổ điển. |
