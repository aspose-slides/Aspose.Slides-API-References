## parent_group thuộc tính
Returns parent GroupShape object if shape is grouped. Otherwise returns None.
            Chỉ đọc [`IGroupShape`](/slides/python-net/vi/aspose.slides/igroupshape).

### Ghi chú

Thuộc tính [`Shape.is_grouped`](/slides/python-net/vi/aspose.slides/shape/is_grouped) determines whether the shape is grouped.
