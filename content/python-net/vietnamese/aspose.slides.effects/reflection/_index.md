## Lớp Reflection

Biểu thị một hiệu ứng Reflection.

Kiểu Reflection cung cấp các thành viên sau:

## Thuộc tính

| Thuộc tính | Mô tả |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/vi/aspose.slides.effects/reflection/start_pos_alpha/) | Xác định vị trí bắt đầu (trên dốc gradient alpha) của giá trị alpha bắt đầu (phần trăm).<br/>            Đọc/ghi **float**. |
| [`end_pos_alpha`](/slides/python-net/vi/aspose.slides.effects/reflection/end_pos_alpha/) | Xác định vị trí kết thúc (trên dốc gradient alpha) của giá trị alpha kết thúc (phần trăm).<br/>            Đọc/ghi **float**. |
| [`fade_direction`](/slides/python-net/vi/aspose.slides.effects/reflection/fade_direction/) | Xác định hướng lệch phản chiếu. (góc).<br/>            Đọc/ghi **float**. |
| [`start_reflection_opacity`](/slides/python-net/vi/aspose.slides.effects/reflection/start_reflection_opacity/) | Độ mờ phản chiếu ban đầu. (phần trăm).<br/>            Đọc/ghi **float**. |
| [`end_reflection_opacity`](/slides/python-net/vi/aspose.slides.effects/reflection/end_reflection_opacity/) | Độ mờ phản chiếu cuối cùng. (phần trăm).<br/>            Đọc/ghi **float**. |
| [`blur_radius`](/slides/python-net/vi/aspose.slides.effects/reflection/blur_radius/) | Bán kính làm mờ.<br/>            Đọc/ghi **float**. |
| [`direction`](/slides/python-net/vi/aspose.slides.effects/reflection/direction/) | Hướng của phản chiếu.<br/>            Đọc/ghi **float**. |
| [`distance`](/slides/python-net/vi/aspose.slides.effects/reflection/distance/) | Khoảng cách của phản chiếu.<br/>            Đọc/ghi **float**. |
| [`rectangle_align`](/slides/python-net/vi/aspose.slides.effects/reflection/rectangle_align/) | Căn hình chữ nhật.<br/>            Đọc/ghi [`RectangleAlignment`](/slides/python-net/vi/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/vi/aspose.slides.effects/reflection/skew_horizontal/) | Xác định góc nghiêng ngang.<br/>            Đọc/ghi **float**. |
| [`skew_vertical`](/slides/python-net/vi/aspose.slides.effects/reflection/skew_vertical/) | Xác định góc nghiêng dọc.<br/>            Đọc/ghi **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/vi/aspose.slides.effects/reflection/rotate_shadow_with_shape/) | Xác định xem phản chiếu có nên quay cùng hình dạng nếu hình dạng được quay hay không.<br/>            Đọc/ghi **bool**. |
| [`scale_horizontal`](/slides/python-net/vi/aspose.slides.effects/reflection/scale_horizontal/) | Xác định hệ số co dọc chiều ngang, co âm gây lật. (phần trăm)<br/>            Đọc/ghi **float**. |
| [`scale_vertical`](/slides/python-net/vi/aspose.slides.effects/reflection/scale_vertical/) | Xác định hệ số co dọc chiều dọc, co âm gây lật. (phần trăm)<br/>            Đọc/ghi **float**. |
