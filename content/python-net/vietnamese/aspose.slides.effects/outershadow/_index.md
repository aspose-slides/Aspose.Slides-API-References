## OuterShadow lớp

Biểu diễn một hiệu ứng Outer Shadow.

Kiểu OuterShadow cung cấp các thành viên sau:

## Thuộc tính

| Thuộc tính | Mô tả |
| :- | :- |
| [`blur_radius`](/slides/python-net/vi/aspose.slides.effects/outershadow/blur_radius/) | Blur radius, in points.<br/>            Giá trị mặc định – 0 pt.<br/>            Đọc/ghi **float**. |
| [`direction`](/slides/python-net/vi/aspose.slides.effects/outershadow/direction/) | Direction of the shadow, in degrees.<br/>            Giá trị mặc định – 0 ° (trái sang phải).<br/>            Đọc/ghi **float**. |
| [`distance`](/slides/python-net/vi/aspose.slides.effects/outershadow/distance/) | Distance of the shadow from the object, in points.<br/>            Giá trị mặc định – 0 pt.<br/>            Đọc/ghi **float**. |
| [`shadow_color`](/slides/python-net/vi/aspose.slides.effects/outershadow/shadow_color/) | Color of the shadow.<br/>            Giá trị mặc định – automatic black (theme-dependent).<br/>            Chỉ đọc [`IColorFormat`](/slides/python-net/vi/aspose.slides/icolorformat). |
| [`rectangle_align`](/slides/python-net/vi/aspose.slides.effects/outershadow/rectangle_align/) | Rectangle alignment.<br/>            Giá trị mặc định – [`RectangleAlignment.BOTTOM`](/slides/python-net/vi/aspose.slides/rectanglealignment/BOTTOM). <br/>            Đọc/ghi [`RectangleAlignment`](/slides/python-net/vi/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/vi/aspose.slides.effects/outershadow/skew_horizontal/) | Horizontal skew angle, in degrees.<br/>            Giá trị mặc định – 0 °.<br/>            Đọc/ghi **float**. |
| [`skew_vertical`](/slides/python-net/vi/aspose.slides.effects/outershadow/skew_vertical/) | Vertical skew angle, in degrees.<br/>            Giá trị mặc định – 0 °.<br/>            Đọc/ghi **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/vi/aspose.slides.effects/outershadow/rotate_shadow_with_shape/) | Indicates whether the shadow rotates together with the shape.<br/>            Giá trị mặc định – true.<br/>            Đọc/ghi **bool**. |
| [`scale_horizontal`](/slides/python-net/vi/aspose.slides.effects/outershadow/scale_horizontal/) | Horizontal scaling factor, in percent of the original size.<br/>            Việc co dãn âm sẽ làm lật.<br/>            Giá trị mặc định – 100 %.<br/>            Đọc/ghi **float**. |
| [`scale_vertical`](/slides/python-net/vi/aspose.slides.effects/outershadow/scale_vertical/) | Vertical scaling factor, in percent of the original size.<br/>            Việc co dãn âm sẽ làm lật.<br/>            Giá trị mặc định – 100 %.<br/>            Đọc/ghi **float**. |
