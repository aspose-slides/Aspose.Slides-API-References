## IReflection lớp

Đại diện cho hiệu ứng phản chiếu.

Kiểu IReflection cung cấp các thành viên sau:

## Thuộc tính

| Thuộc tính | Mô tả |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/vi/aspose.slides.effects/ireflection/start_pos_alpha/) | Xác định vị trí bắt đầu (trên dốc gradient alpha) của giá trị alpha bắt đầu (phần trăm).<br/>            Đọc/ghi **float**. |
| [`end_pos_alpha`](/slides/python-net/vi/aspose.slides.effects/ireflection/end_pos_alpha/) | Xác định vị trí kết thúc (trên dốc gradient alpha) của giá trị alpha kết thúc (phần trăm).<br/>            Đọc/ghi **float**. |
| [`fade_direction`](/slides/python-net/vi/aspose.slides.effects/ireflection/fade_direction/) | Xác định hướng để dịch phản chiếu. (góc).<br/>            Đọc/ghi **float**. |
| [`start_reflection_opacity`](/slides/python-net/vi/aspose.slides.effects/ireflection/start_reflection_opacity/) | Độ mờ phản chiếu bắt đầu. (phần trăm).<br/>            Đọc/ghi **float**. |
| [`end_reflection_opacity`](/slides/python-net/vi/aspose.slides.effects/ireflection/end_reflection_opacity/) | Độ mờ phản chiếu kết thúc. (phần trăm).<br/>            Đọc/ghi **float**. |
| [`blur_radius`](/slides/python-net/vi/aspose.slides.effects/ireflection/blur_radius/) | Bán kính làm mờ.<br/>            Đọc/ghi **float**. |
| [`direction`](/slides/python-net/vi/aspose.slides.effects/ireflection/direction/) | Hướng của phản chiếu.<br/>            Đọc/ghi **float**. |
| [`distance`](/slides/python-net/vi/aspose.slides.effects/ireflection/distance/) | Khoảng cách phản chiếu.<br/>            Đọc/ghi **float**. |
| [`rectangle_align`](/slides/python-net/vi/aspose.slides.effects/ireflection/rectangle_align/) | Căn chữ nhật.<br/>            Đọc/ghi [`RectangleAlignment`](/slides/python-net/vi/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/vi/aspose.slides.effects/ireflection/skew_horizontal/) | Xác định góc lệch ngang.<br/>            Đọc/ghi **float**. |
| [`skew_vertical`](/slides/python-net/vi/aspose.slides.effects/ireflection/skew_vertical/) | Xác định góc lệch dọc.<br/>            Đọc/ghi **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/vi/aspose.slides.effects/ireflection/rotate_shadow_with_shape/) | Xác định liệu phản chiếu có nên xoay theo hình dạng nếu hình dạng được xoay hay không.<br/>            Đọc/ghi **bool**. |
| [`scale_horizontal`](/slides/python-net/vi/aspose.slides.effects/ireflection/scale_horizontal/) | Xác định hệ số tỉ lệ ngang, tỉ lệ âm gây lật. (phần trăm)<br/>            Đọc/ghi **float**. |
| [`scale_vertical`](/slides/python-net/vi/aspose.slides.effects/ireflection/scale_vertical/) | Xác định hệ số tỉ lệ dọc, tỉ lệ âm gây lật. (phần trăm)<br/>            Đọc/ghi **float**. |
