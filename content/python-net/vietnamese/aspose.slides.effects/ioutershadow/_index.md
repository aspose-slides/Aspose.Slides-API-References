## IOuterShadow lớp

Biểu diễn hiệu ứng Đổ bóng bên ngoài.

Kiểu IOuterShadow cung cấp các thành viên sau:

## Thuộc tính

| Thuộc tính | Mô tả |
| :- | :- |
| [`blur_radius`](/slides/python-net/vi/aspose.slides.effects/ioutershadow/blur_radius/) | Bán kính mờ, tính bằng điểm.<br/>            Giá trị mặc định – 0 pt.<br/>            Đọc/ghi **float**. |
| [`direction`](/slides/python-net/vi/aspose.slides.effects/ioutershadow/direction/) | Hướng của bóng, tính bằng độ.<br/>            Giá trị mặc định – 0 ° (từ trái sang phải).<br/>            Đọc/ghi **float**. |
| [`distance`](/slides/python-net/vi/aspose.slides.effects/ioutershadow/distance/) | Khoảng cách của bóng tới đối tượng, tính bằng điểm.<br/>            Giá trị mặc định – 0 pt.<br/>            Đọc/ghi **float**. |
| [`shadow_color`](/slides/python-net/vi/aspose.slides.effects/ioutershadow/shadow_color/) | Màu của bóng.<br/>            Giá trị mặc định – màu đen tự động (phụ thuộc vào giao diện).<br/>            Chỉ đọc [`IColorFormat`](/slides/python-net/vi/aspose.slides/icolorformat). |
| [`rectangle_align`](/slides/python-net/vi/aspose.slides.effects/ioutershadow/rectangle_align/) | Căn hình chữ nhật.<br/>            Giá trị mặc định – [`RectangleAlignment.BOTTOM`](/slides/python-net/vi/aspose.slides/rectanglealignment/BOTTOM). <br/>            Đọc/ghi [`RectangleAlignment`](/slides/python-net/vi/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/vi/aspose.slides.effects/ioutershadow/skew_horizontal/) | Góc nghiêng ngang, tính bằng độ.<br/>            Giá trị mặc định – 0 °.<br/>            Đọc/ghi **float**. |
| [`skew_vertical`](/slides/python-net/vi/aspose.slides.effects/ioutershadow/skew_vertical/) | Góc nghiêng dọc, tính bằng độ.<br/>            Giá trị mặc định – 0 °.<br/>            Đọc/ghi **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/vi/aspose.slides.effects/ioutershadow/rotate_shadow_with_shape/) | Cho biết liệu bóng có quay cùng với hình dạng hay không.<br/>            Giá trị mặc định – true.<br/>            Đọc/ghi **bool**. |
| [`scale_horizontal`](/slides/python-net/vi/aspose.slides.effects/ioutershadow/scale_horizontal/) | Hệ số co chiều ngang, tính bằng phần trăm của kích thước gốc.<br/>            Việc co âm gây lật.<br/>            Giá trị mặc định – 100 %.<br/>            Đọc/ghi **float**. |
| [`scale_vertical`](/slides/python-net/vi/aspose.slides.effects/ioutershadow/scale_vertical/) | Hệ số co chiều dọc, tính bằng phần trăm của kích thước gốc.<br/>            Việc co âm gây lật.<br/>            Giá trị mặc định – 100 %.<br/>            Đọc/ghi **float**. |
