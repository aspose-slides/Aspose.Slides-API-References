## lớp IReflectionEffectiveData

Đối tượng bất biến đại diện cho hiệu ứng Reflection.

Kiểu IReflectionEffectiveData cung cấp các thành viên sau:

## Thuộc tính

| Thuộc tính | Mô tả |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/vi/aspose.slides.effects/ireflectioneffectivedata/start_pos_alpha/) | Xác định vị trí bắt đầu (trên dốc gradient alpha) của giá trị alpha bắt đầu (phần trăm).<br/>            Chỉ đọc **float**. |
| [`end_pos_alpha`](/slides/python-net/vi/aspose.slides.effects/ireflectioneffectivedata/end_pos_alpha/) | Xác định vị trí kết thúc (trên dốc gradient alpha) của giá trị alpha kết thúc (phần trăm).<br/>            Chỉ đọc **float**. |
| [`fade_direction`](/slides/python-net/vi/aspose.slides.effects/ireflectioneffectivedata/fade_direction/) | Xác định hướng để dịch chuyển phản chiếu. (góc).<br/>            Chỉ đọc **float**. |
| [`start_reflection_opacity`](/slides/python-net/vi/aspose.slides.effects/ireflectioneffectivedata/start_reflection_opacity/) | Độ mờ bắt đầu của phản chiếu. (phần trăm).<br/>            Chỉ đọc **float**. |
| [`end_reflection_opacity`](/slides/python-net/vi/aspose.slides.effects/ireflectioneffectivedata/end_reflection_opacity/) | Độ mờ cuối của phản chiếu. (phần trăm).<br/>            Chỉ đọc **float**. |
| [`blur_radius`](/slides/python-net/vi/aspose.slides.effects/ireflectioneffectivedata/blur_radius/) | Bán kính làm mờ.<br/>            Chỉ đọc **float**. |
| [`direction`](/slides/python-net/vi/aspose.slides.effects/ireflectioneffectivedata/direction/) | Hướng của phản chiếu.<br/>            Chỉ đọc **float**. |
| [`distance`](/slides/python-net/vi/aspose.slides.effects/ireflectioneffectivedata/distance/) | Khoảng cách của phản chiếu.<br/>            Chỉ đọc **float**. |
| [`rectangle_align`](/slides/python-net/vi/aspose.slides.effects/ireflectioneffectivedata/rectangle_align/) | Căn hình chữ nhật.<br/>            Chỉ đọc [`RectangleAlignment`](/slides/python-net/vi/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/vi/aspose.slides.effects/ireflectioneffectivedata/skew_horizontal/) | Xác định góc nghiêng theo chiều ngang.<br/>            Chỉ đọc **float**. |
| [`skew_vertical`](/slides/python-net/vi/aspose.slides.effects/ireflectioneffectivedata/skew_vertical/) | Xác định góc nghiêng theo chiều dọc.<br/>            Chỉ đọc **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/vi/aspose.slides.effects/ireflectioneffectivedata/rotate_shadow_with_shape/) | Xác định có nên phản chiếu quay cùng hình dạng khi hình dạng bị quay hay không.<br/>            Chỉ đọc **bool**. |
| [`scale_horizontal`](/slides/python-net/vi/aspose.slides.effects/ireflectioneffectivedata/scale_horizontal/) | Xác định hệ số tỷ lệ theo chiều ngang, tỷ lệ âm gây lật. (phần trăm)<br/>            Chỉ đọc **float**. |
| [`scale_vertical`](/slides/python-net/vi/aspose.slides.effects/ireflectioneffectivedata/scale_vertical/) | Xác định hệ số tỷ lệ theo chiều dọc, tỷ lệ âm gây lật. (phần trăm)<br/>            Chỉ đọc **float**. |
