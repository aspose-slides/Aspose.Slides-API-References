## default_delay thuộc tính
Gets or sets default delay time [ms]. This value will be used if [`ISlideShowTransition.advance_after_time`](/slides/python-net/vi/aspose.slides/islideshowtransition/advance_after_time) is not set.
            Giá trị mặc định là 1000.
