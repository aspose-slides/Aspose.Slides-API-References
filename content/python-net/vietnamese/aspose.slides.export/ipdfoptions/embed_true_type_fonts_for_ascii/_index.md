## embed_true_type_fonts_for_ascii thuộc tính
True để nhúng phông chữ true type cho các ký tự ASCII 32-127.
            Phông chữ cho các mã ký tự lớn hơn 127 luôn được nhúng.
            Đọc/ghi **bool**.

### Ghi chú
