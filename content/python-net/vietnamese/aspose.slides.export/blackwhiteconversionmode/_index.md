## BlackWhiteConversionMode liệt kê

Cung cấp các tùy chọn kiểm soát cách hình ảnh của slide sẽ được chuyển đổi thành hình ảnh nhị phân.

Kiểu BlackWhiteConversionMode cung cấp các thành viên sau:

## Trường

| Trường | Mô tả |
| :- | :- |
| DEFAULT | Chỉ định không có thuật toán chuyển đổi. Thuật toán được triển khai trong bộ mã hoá TIFF sẽ được sử dụng. (Mặc định) |
| DITHERING | Chỉ định thuật toán dithering (Floyd-Steinberg). |
| DITHERING_FLOYD_STEINBERG | Chỉ định thuật toán dithering Floyd-Steinberg. |
| AUTO | Chỉ định thuật toán ngưỡng được tính toán tự động (Otsu). |
| AUTO_OTSU | Chỉ định thuật toán ngưỡng Otsu được tính toán tự động. |
| THRESHOLD25 | Chỉ định thuật toán ngưỡng tĩnh (25%). |
| THRESHOLD50 | Chỉ định thuật toán ngưỡng tĩnh (50%). |
| THRESHOLD75 | Chỉ định thuật toán ngưỡng tĩnh (75%). |
