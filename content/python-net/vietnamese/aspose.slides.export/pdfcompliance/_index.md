## PdfCompliance liệt kê

Các hằng số định nghĩa mức độ tuân thủ tiêu chuẩn PDF.

Kiểu PdfCompliance cung cấp các thành viên sau:

## Trường

| Trường | Mô tả |
| :- | :- |
| PDF15 | Tệp đầu ra sẽ tuân thủ chuẩn PDF 1.5. |
| PDF16 | Tệp đầu ra sẽ tuân thủ chuẩn PDF 1.6. |
| PDF17 | Tệp đầu ra sẽ tuân thủ chuẩn PDF 1.7. |
| PDF_A1B | Tệp đầu ra sẽ tuân thủ chuẩn PDF/A-1b. |
| PDF_A1A | Tệp đầu ra sẽ tuân thủ chuẩn PDF/A-1a. |
| PDF_A2B | Tệp đầu ra sẽ tuân thủ chuẩn PDF/A-2b. |
| PDF_A2A | Tệp đầu ra sẽ tuân thủ chuẩn PDF/A-2a. |
| PDF_A3B | Tệp đầu ra sẽ tuân thủ chuẩn PDF/A-3b. |
| PDF_A3A | Tệp đầu ra sẽ tuân thủ chuẩn PDF/A-3a. |
| PDF_UA | Tệp đầu ra sẽ tuân thủ chuẩn PDF/UA. |
| PDF_A2U | Tệp đầu ra sẽ tuân thủ chuẩn PDF/A-2u. |
