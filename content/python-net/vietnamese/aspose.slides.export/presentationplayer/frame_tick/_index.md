## frame_tick sự kiện
Sự kiện frame_tick.

Occurs when each frame of the animation created by [`PresentationAnimationsGenerator`](/slides/python-net/vi/aspose.slides.export/presentationanimationsgenerator) is generated by the player.

### Định nghĩa:
```python
def on_frame_tick(sender, args):
    ...

obj.frame_tick += on_frame_tick
```
