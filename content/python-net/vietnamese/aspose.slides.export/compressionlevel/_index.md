## CompressionLevel liệt kê

Xác định các mức nén ZIP cho tệp OpenXML. Các mức cao hơn cung cấp khả năng nén tốt hơn nhưng sẽ làm chậm quá trình xử lý.

Kiểu CompressionLevel cung cấp các thành viên sau:

## Trường

| Trường | Mô tả |
| :- | :- |
| NONE | Không áp dụng nén. Các tệp được lưu giữ nguyên. |
| LEVEL1 | Nén nhanh nhất với tỉ lệ nén thấp nhất. |
| LEVEL2 | Nén nhanh hơn với tỉ lệ nén hơi tốt hơn so với [`CompressionLevel.LEVEL1`](/slides/python-net/vi/aspose.slides.export/compressionlevel/LEVEL1). |
| LEVEL3 | Cung cấp mức nén tốt hơn so với [`CompressionLevel.LEVEL2`](/slides/python-net/vi/aspose.slides.export/compressionlevel/LEVEL2) với ảnh hưởng hiệu năng vừa phải. |
| LEVEL4 | Cung cấp mức nén tốt hơn so với [`CompressionLevel.LEVEL3`](/slides/python-net/vi/aspose.slides.export/compressionlevel/LEVEL3). |
| LEVEL5 | Cung cấp mức nén cải thiện hơn so với [`CompressionLevel.LEVEL4`](/slides/python-net/vi/aspose.slides.export/compressionlevel/LEVEL4) với thời gian xử lý bổ sung. |
| LEVEL6 | Nén tiêu chuẩn, cung cấp cân bằng tốt giữa tốc độ nén và kích thước tệp.<br/>            Mức nén mặc định. |
| LEVEL7 | Cung cấp mức nén cao hơn so với [`CompressionLevel.LEVEL6`](/slides/python-net/vi/aspose.slides.export/compressionlevel/LEVEL6) với xử lý chậm hơn. |
| LEVEL8 | Cung cấp mức nén cao hơn so với [`CompressionLevel.LEVEL7`](/slides/python-net/vi/aspose.slides.export/compressionlevel/LEVEL7). |
| LEVEL9 | Mức nén tối đa. Tạo kích thước tệp nhỏ nhất với tốc độ xử lý chậm nhất. |
