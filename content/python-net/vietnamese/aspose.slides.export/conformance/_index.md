## Liệt kê mức độ tương thích

Chỉ định lớp tương thích mà tài liệu PresentationML tuân theo.

Kiểu Conformance hiển thị các thành viên sau:

## Trường

| Trường | Mô tả |
| :- | :- |
| ECMA_376_2006 | Chỉ định rằng tài liệu tuân thủ ECMA376:2006. |
| ISO_29500_2008_TRANSITIONAL | Chỉ định rằng tài liệu tuân thủ lớp tương thích Transitional của ISO/IEC 29500:2008. |
| ISO_29500_2008_STRICT | Chỉ định rằng tài liệu tuân thủ lớp tương thích Strict của ISO/IEC 29500:2008. |
