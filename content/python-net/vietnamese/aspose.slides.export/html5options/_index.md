Đại diện cho các tùy chọn xuất HTML5.

**Kế thừa:**[`Html5Options`](/slides/python-net/vi/aspose.slides.export/html5options) → [`SaveOptions`](/slides/python-net/vi/aspose.slides.export/saveoptions)

## Thuộc tính

| Thuộc tính | Mô tả |
| :- | :- |
| [`warning_callback`](/slides/python-net/vi/aspose.slides.export/html5options/warning_callback/) | Trả về hoặc đặt một đối tượng nhận cảnh báo và quyết định liệu quá trình tải sẽ tiếp tục hay sẽ bị hủy.<br/>            Đọc/ghi [`IWarningCallback`](/slides/python-net/vi/aspose.slides.warnings/iwarningcallback). |
| [`progress_callback`](/slides/python-net/vi/aspose.slides.export/html5options/progress_callback/) | Đại diện cho một đối tượng callback để cập nhật tiến độ lưu dưới dạng phần trăm.<br/>            Xem [`IProgressCallback`](/slides/python-net/vi/aspose.slides/iprogresscallback). |
| [`default_regular_font`](/slides/python-net/vi/aspose.slides.export/html5options/default_regular_font/) | Trả về hoặc đặt phông chữ được sử dụng khi không tìm thấy phông nguồn.<br/>            Đọc/ghi **str**. |
| [`gradient_style`](/slides/python-net/vi/aspose.slides.export/html5options/gradient_style/) | Trả về hoặc đặt kiểu hiển thị của gradient.<br/>            Đọc/ghi [`GradientStyle`](/slides/python-net/vi/aspose.slides/gradientstyle). |
| [`skip_java_script_links`](/slides/python-net/vi/aspose.slides.export/html5options/skip_java_script_links/) | Xác định có bỏ qua siêu liên kết có lời gọi JavaScript khi lưu bản trình chiếu hay không.<br/>            Đọc/ghi **bool**. Giá trị mặc định là **false**. |
| [`animate_transitions`](/slides/python-net/vi/aspose.slides.export/html5options/animate_transitions/) | Trả về hoặc đặt tùy chọn hoạt ảnh chuyển tiếp.<br/>            Đọc/ghi **bool**. |
| [`animate_shapes`](/slides/python-net/vi/aspose.slides.export/html5options/animate_shapes/) | Trả về hoặc đặt tùy chọn hoạt ảnh hình dạng.<br/>            Đọc/ghi **bool**. |
| [`embed_images`](/slides/python-net/vi/aspose.slides.export/html5options/embed_images/) | Trả về hoặc đặt tùy chọn nhúng hình ảnh.<br/>            Đọc/ghi **bool**. |
| [`output_path`](/slides/python-net/vi/aspose.slides.export/html5options/output_path/) | Xác định nơi lưu các tài nguyên bên ngoài.<br/>            Đọc/ghi **str**. |
| [`pictures_compression`](/slides/python-net/vi/aspose.slides.export/html5options/pictures_compression/) | Đại diện cho mức nén hình ảnh |
| [`disable_font_ligatures`](/slides/python-net/vi/aspose.slides.export/html5options/disable_font_ligatures/) | Lấy hoặc đặt giá trị cho biết văn bản có được hiển thị mà không sử dụng ligature hay không.<br/>            Khi được đặt là `true`, ligature sẽ bị tắt trong đầu ra đã render. Mặc định, thuộc tính này được đặt là `false`. |
| [`slides_layout_options`](/slides/python-net/vi/aspose.slides.export/html5options/slides_layout_options/) | Lấy hoặc đặt chế độ sắp xếp các slide trên trang khi xuất bản trình chiếu [`ISlidesLayoutOptions`](/slides/python-net/vi/aspose.slides.export/islideslayoutoptions). |
