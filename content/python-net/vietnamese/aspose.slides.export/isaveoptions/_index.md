## ISaveOptions lớp

Các tùy chọn kiểm soát cách một bản trình chiếu được lưu.

Kiểu ISaveOptions cung cấp các thành viên sau:

## Thuộc tính

| Property | Description |
| :- | :- |
| [`warning_callback`](/slides/python-net/vi/aspose.slides.export/isaveoptions/warning_callback/) | Trả về hoặc đặt một đối tượng nhận cảnh báo và quyết định quá trình tải sẽ tiếp tục hay bị hủy.<br/>            Đọc/ghi [`IWarningCallback`](/slides/python-net/vi/aspose.slides.warnings/iwarningcallback). |
| [`progress_callback`](/slides/python-net/vi/aspose.slides.export/isaveoptions/progress_callback/) | Đại diện cho một đối tượng callback để cập nhật tiến trình lưu dưới dạng phần trăm. <br/>            Xem [`IProgressCallback`](/slides/python-net/vi/aspose.slides/iprogresscallback). |
| [`default_regular_font`](/slides/python-net/vi/aspose.slides.export/isaveoptions/default_regular_font/) | Trả về hoặc đặt phông chữ được sử dụng trong trường hợp không tìm thấy phông chữ nguồn.<br/>            Đọc/ghi **str**. |
| [`gradient_style`](/slides/python-net/vi/aspose.slides.export/isaveoptions/gradient_style/) | Trả về hoặc đặt kiểu hiển thị của gradient.<br/>            Đọc/ghi [`GradientStyle`](/slides/python-net/vi/aspose.slides/gradientstyle). |
| [`skip_java_script_links`](/slides/python-net/vi/aspose.slides.export/isaveoptions/skip_java_script_links/) | Chỉ định có bỏ qua các siêu liên kết có lời gọi JavaScript khi lưu bản trình chiếu hay không. <br/>            Đọc/ghi **bool**. Giá trị mặc định là **false**. |
