## Liệt kê Flavor

Tất cả các đặc tả markdown được sử dụng trong chương trình.

Kiểu Flavor cung cấp các thành viên sau:

## Trường

| Trường | Mô tả |
| :- | :- |
| GITHUB | Phiên bản Github. |
| GRUBER | Phiên bản Gruber. |
| MULTI_MARKDOWN | Phiên bản Multi markdown. |
| COMMON_MARK | Phiên bản Common mark. |
| MARKDOWN_EXTRA | Phiên bản Markdown extra. |
| PANDOC | Phiên bản Pandoc. |
| KRAMDOWN | Phiên bản Kramdown. |
| MARKUA | Phiên bản Markua. |
| MARUKU | Phiên bản Maruku. |
| MARKDOWN2 | Phiên bản Markdown2. |
| REMARKABLE | Phiên bản Remarkable. |
| SHOWDOWN | Phiên bản Showdown. |
| GHOST | Phiên bản Ghost. |
| GIT_LAB | Phiên bản Gitlab. |
| HAROOPAD | Phiên bản Haroopad. |
| IA_WRITER | Phiên bản IAWriter. |
| REDCARPET | Phiên bản Redcarpet. |
| SCHOLARLY_MARKDOWN | Phiên bản Scholarly markdown. |
| TAIGA | Phiên bản Taiga. |
| TRELLO | Phiên bản Trello. |
| S9E_TEXT_FORMATTER | Phiên bản S9E text formatter. |
| X_WIKI | Phiên bản XWiki. |

| DEFAULT | Phiên bản markdown mặc định. |
