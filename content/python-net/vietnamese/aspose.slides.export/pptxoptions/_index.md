## PptxOptions lớp

Biểu thị các tùy chọn cho việc lưu các bản trình chiếu OpenXml (PPTX, PPSX, POTX, PPTM, PPSM, POTM).

**Kế thừa:**[`PptxOptions`](/slides/python-net/vi/aspose.slides.export/pptxoptions) → [`SaveOptions`](/slides/python-net/vi/aspose.slides.export/saveoptions)

Kiểu PptxOptions cung cấp các thành viên sau:

## Thuộc tính

| Thuộc tính | Mô tả |
| :- | :- |
| [`warning_callback`](/slides/python-net/vi/aspose.slides.export/pptxoptions/warning_callback/) | Trả về hoặc đặt một đối tượng nhận cảnh báo và quyết định liệu quá trình tải sẽ tiếp tục hay bị hủy.<br/>            Đọc/ghi [`IWarningCallback`](/slides/python-net/vi/aspose.slides.warnings/iwarningcallback). |
| [`progress_callback`](/slides/python-net/vi/aspose.slides.export/pptxoptions/progress_callback/) | Biểu diễn một đối tượng callback để cập nhật tiến độ lưu dưới dạng phần trăm.<br/>            Xem [`IProgressCallback`](/slides/python-net/vi/aspose.slides/iprogresscallback). |
| [`default_regular_font`](/slides/python-net/vi/aspose.slides.export/pptxoptions/default_regular_font/) | Trả về hoặc đặt phông chữ được sử dụng khi không tìm thấy phông nguồn.<br/>            Đọc-ghi **str**. |
| [`gradient_style`](/slides/python-net/vi/aspose.slides.export/pptxoptions/gradient_style/) | Trả về hoặc đặt kiểu hiển thị của gradient.<br/>            Đọc/ghi [`GradientStyle`](/slides/python-net/vi/aspose.slides/gradientstyle). |
| [`skip_java_script_links`](/slides/python-net/vi/aspose.slides.export/pptxoptions/skip_java_script_links/) | Xác định có bỏ qua các siêu liên kết có lời gọi JavaScript khi lưu bản trình chiếu hay không.<br/>            Đọc/ghi **bool**. Giá trị mặc định là **false**. |
| [`conformance`](/slides/python-net/vi/aspose.slides.export/pptxoptions/conformance/) | Xác định lớp tuân thủ mà tài liệu Presentation tuân theo.<br/>            Giá trị mặc định là [`Conformance.ECMA_376_2006`](/slides/python-net/vi/aspose.slides.export/conformance/ECMA_376_2006) |
| [`zip_64_mode`](/slides/python-net/vi/aspose.slides.export/pptxoptions/zip_64_mode/) | Xác định có sử dụng định dạng ZIP64 cho tài liệu Presentation hay không.<br/>            Giá trị mặc định là [`Zip64Mode.IF_NECESSARY`](/slides/python-net/vi/aspose.slides.export/zip64mode/IF_NECESSARY) |
| [`refresh_thumbnail`](/slides/python-net/vi/aspose.slides.export/pptxoptions/refresh_thumbnail/) | Xác định có làm mới hình thu nhỏ của bản trình chiếu hay không.<br/>            Đọc/ghi **bool**.<br/>            Giá trị mặc định là **true**. |
| [`compression_level`](/slides/python-net/vi/aspose.slides.export/pptxoptions/compression_level/) | Xác định mức độ nén được sử dụng khi lưu tài liệu bản trình chiếu.<br/>            Giá trị mặc định là [`CompressionLevel.LEVEL6`](/slides/python-net/vi/aspose.slides.export/compressionlevel/LEVEL6). |
