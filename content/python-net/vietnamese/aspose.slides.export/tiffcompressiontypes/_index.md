## TiffCompressionTypes liệt kê

Cung cấp các tùy chọn kiểm soát cách một bản trình bày được nén ở định dạng TIFF.

Kiểu TiffCompressionTypes cung cấp các thành viên sau:

## Trường

| Trường | Mô tả |
| :- | :- |
| DEFAULT | Xác định sơ đồ nén mặc định (LZW). |
| NONE | Xác định không nén. |
| CCITT3 | Xác định sơ đồ nén CCITT3. |
| CCITT4 | Xác định sơ đồ nén CCITT4. |
| LZW | Xác định sơ đồ nén LZW (Mặc định). |
| RLE | Xác định sơ đồ nén RLE. |
