## Lớp OverrideTheme

| Thuộc tính | Mô tả |
| :- | :- |

| [`presentation`](/slides/python-net/vi/aspose.slides.theme/overridetheme/presentation/) | Trả về bản trình chiếu cha.<br/>            Chỉ đọc [`IPresentation`](/slides/python-net/vi/aspose.slides/ipresentation). |
