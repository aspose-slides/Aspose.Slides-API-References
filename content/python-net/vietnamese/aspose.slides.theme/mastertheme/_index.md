## MasterTheme lớp

Biểu diễn một chủ đề gốc.

**Kế thừa:**[`MasterTheme`](/slides/python-net/vi/aspose.slides.theme/mastertheme) → [`Theme`](/slides/python-net/vi/aspose.slides.theme/theme)

Kiểu MasterTheme cung cấp các thành viên sau:

## Thuộc tính

| Thuộc tính | Mô tả |
| :- | :- |
| [`color_scheme`](/slides/python-net/vi/aspose.slides.theme/mastertheme/color_scheme/) | Trả về bảng màu.<br/>            Chỉ đọc [`IColorScheme`](/slides/python-net/vi/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/vi/aspose.slides.theme/mastertheme/font_scheme/) | Trả về bảng phông chữ.<br/>            Chỉ đọc [`IFontScheme`](/slides/python-net/vi/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/vi/aspose.slides.theme/mastertheme/format_scheme/) | Trả về bảng định dạng hình dạng.<br/>            Chỉ đọc [`IFormatScheme`](/slides/python-net/vi/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/vi/aspose.slides.theme/mastertheme/presentation/) | Trả về bản trình chiếu cha.<br/>            Chỉ đọc [`IPresentation`](/slides/python-net/vi/aspose.slides/ipresentation). |
| [`extra_color_schemes`](/slides/python-net/vi/aspose.slides.theme/mastertheme/extra_color_schemes/) | Trả về bộ sưu tập các bảng màu bổ sung.<br/>            Các bảng màu này không ảnh hưởng đến giao diện của bản trình chiếu, chúng có thể được chọn làm bảng màu chính cho một slide.<br/>            Chỉ đọc [`IExtraColorSchemeCollection`](/slides/python-net/vi/aspose.slides.theme/iextracolorschemecollection). |
| [`name`](/slides/python-net/vi/aspose.slides.theme/mastertheme/name/) | Trả về tên của một chủ đề.<br/>            Đọc/ghi **str**. |
