## hide(self) {#}
Đặt nhãn dữ liệu ẩn mặc định bằng cách đặt tất cả các cờ Show*-flags (ShowValue, ...) của thuộc tính DefaultDataLabelFormat thành trạng thái false. IsVisible sẽ là false sau khi thực hiện.

```python
def hide(self):
    ...
```

### Ghi chú

Nếu nhãn dữ liệu không hiển thị mặc định (IsVisible là false) bạn có thể làm nhãn dữ liệu “được hiển thị mặc định” bằng cách đặt các cờ Show*-flags (ShowValue, ...) của thuộc tính DefaultDataLabelFormat thành trạng thái true.
