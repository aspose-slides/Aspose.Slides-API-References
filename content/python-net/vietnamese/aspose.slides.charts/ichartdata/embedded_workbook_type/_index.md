## embedded_workbook_type thuộc tính
Gets the type of the embedded workbook.
            Returns [`WorkbookType.NOT_DEFINED`](/slides/python-net/vi/aspose.slides.charts/workbooktype/NOT_DEFINED) if [`IChartData.data_source_type`](/slides/python-net/vi/aspose.slides.charts/ichartdata/data_source_type) is 
            [`ChartDataSourceType.EXTERNAL_WORKBOOK`](/slides/python-net/vi/aspose.slides.charts/chartdatasourcetype/EXTERNAL_WORKBOOK).
            Chỉ đọc [`WorkbookType`](/slides/python-net/vi/aspose.slides.charts/workbooktype).
