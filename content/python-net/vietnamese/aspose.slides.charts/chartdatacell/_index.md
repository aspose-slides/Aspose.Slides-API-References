## Lớp ChartDataCell

Biểu diễn ô cho dữ liệu biểu đồ.

Kiểu ChartDataCell cung cấp các thành viên sau:

## Thuộc tính

| Thuộc tính | Mô tả |
| :- | :- |
| [`row`](/slides/python-net/vi/aspose.slides.charts/chartdatacell/row/) | Trả về chỉ số của hàng trong bảng tính mà ô nằm trong.<br/>            Chỉ đọc **int**. |
| [`column`](/slides/python-net/vi/aspose.slides.charts/chartdatacell/column/) | Trả về chỉ số của cột trong bảng tính mà ô nằm trong.<br/>            Chỉ đọc **int**. |
| [`value`](/slides/python-net/vi/aspose.slides.charts/chartdatacell/value/) | Lấy hoặc đặt giá trị của ô.<br/>            Đọc/ghi **any**. |
| [`formula`](/slides/python-net/vi/aspose.slides.charts/chartdatacell/formula/) | Lấy hoặc đặt công thức theo kiểu A1. |
| [`r1c1_formula`](/slides/python-net/vi/aspose.slides.charts/chartdatacell/r1c1_formula/) | Lấy hoặc đặt công thức theo kiểu R1C1. |
| [`chart_data_worksheet`](/slides/python-net/vi/aspose.slides.charts/chartdatacell/chart_data_worksheet/) | Lấy bảng tính.<br/>            Chỉ đọc [`IChartDataWorksheet`](/slides/python-net/vi/aspose.slides.charts/ichartdataworksheet). |
| [`is_hidden`](/slides/python-net/vi/aspose.slides.charts/chartdatacell/is_hidden/) | Xác định xem ô có bị ẩn hay không.<br/>            Chỉ đọc **bool**. |
| [`custom_number_format`](/slides/python-net/vi/aspose.slides.charts/chartdatacell/custom_number_format/) | Lấy hoặc đặt định dạng hiển thị tùy chỉnh cho số và ngày.<br/>            Nếu giá trị rỗng sẽ sử dụng giá trị PresetNumberFormat.<br/>            Đọc/ghi **str**. |
| [`preset_number_format`](/slides/python-net/vi/aspose.slides.charts/chartdatacell/preset_number_format/) | Lấy hoặc đặt định dạng hiển thị tích hợp cho số và ngày. Số preset phải nằm trong [0..22] hoặc [37..49].<br/>            Đọc/ghi **int**. |
