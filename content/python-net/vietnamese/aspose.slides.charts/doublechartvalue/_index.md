## Lớp DoubleChartValue

Biểu diễn giá trị double có thể được lưu trong tài liệu trình chiếu pptx theo hai cách:
            1) trong ô/ô của workbook liên quan tới biểu đồ;
            2) dưới dạng giá trị nguyên thủy.

**Kế thừa:**[`DoubleChartValue`](/slides/python-net/vi/aspose.slides.charts/doublechartvalue) → [`BaseChartValue`](/slides/python-net/vi/aspose.slides.charts/basechartvalue)

Kiểu DoubleChartValue cung cấp các thành viên sau:

## Thuộc tính

| Thuộc tính | Mô tả |
| :- | :- |
| [`data_source_type`](/slides/python-net/vi/aspose.slides.charts/doublechartvalue/data_source_type/) | Xác định xem thuộc tính AsCell, AsCells, AsLiteralString hay AsLiteralDouble <br/>            là thực tế trong các lớp con. Nói cách khác, nó xác định loại <br/>            của giá trị thuộc tính Data.<br/>            Đọc/ghi [`DataSourceType`](/slides/python-net/vi/aspose.slides.charts/datasourcetype). |
| [`data`](/slides/python-net/vi/aspose.slides.charts/doublechartvalue/data/) | Trả về hoặc đặt đối tượng Data.<br/>            Đọc/ghi **any**. |
| [`as_cell`](/slides/python-net/vi/aspose.slides.charts/doublechartvalue/as_cell/) | Trả về hoặc đặt ô dữ liệu biểu đồ.<br/>            Đọc/ghi [`IChartDataCell`](/slides/python-net/vi/aspose.slides.charts/ichartdatacell). |
| [`as_literal_double`](/slides/python-net/vi/aspose.slides.charts/doublechartvalue/as_literal_double/) | Trả về hoặc đặt giá trị dưới dạng double nguyên thủy.<br/>            Đọc/ghi **float**. |
