## hide(self) {#}
Ẩn nhãn dữ liệu bằng cách đặt tất cả các cờ Show*-flags (ShowValue, ...) thành trạng thái false.
            IsVisible sẽ là false sau hành động này.

```python
def hide(self):
    ...
```

### Ghi chú

Nếu nhãn dữ liệu không hiển thị (IsVisible là false) bạn có thể làm cho nhãn dữ liệu hiển thị bằng cách 
            đặt các cờ Show*-flags (ShowValue, ...) thành trạng thái true.
