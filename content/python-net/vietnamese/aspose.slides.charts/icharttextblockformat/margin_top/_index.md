## margin_top thuộc tính
Returns or sets the top margin (điểm) in a TextFrame.
            Changing of this property can produce a certain influence only for these chart parts: 
            DataLabel và DataLabelFormat (full support in PowerPoint 2013; in PowerPoint 2007 there is no effect for rendering).
            Đọc/ghi **float**.
