## is_visible thuộc tính
False means that data label is not visible (and so all Show*-flags (ShowValue, ...) are false).
            Chỉ đọc **bool**.

### Ghi chú

If data label is visible you can make it hidden with Hide() method.
            Nhưng nếu nhãn dữ liệu không hiển thị (IsVisible is false) bạn có thể làm cho nhãn dữ liệu hiển thị bằng cách đặt các cờ Show*-flags (ShowValue, ...) ở trạng thái true.
