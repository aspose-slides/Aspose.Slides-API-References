## WorkbookType liệt kê

Xác định loại tệp workbook Open XML.

Kiểu WorkbookType cung cấp các thành viên sau:

## Trường

| Trường | Mô tả |
| :- | :- |
| NOT_DEFINED | Loại workbook không được xác định. |
| WORKBOOK | Workbook Excel (*.xlsx). |
| WORKBOOK_MACRO | Workbook Excel có macro (*.xlsm). |
| TEMPLATE | Mẫu Excel (*.xltx). |
| TEMPLATE_MACRO | Mẫu Excel có macro (*.xltm). |
| WORKBOOK_BINARY_MACRO | Workbook Excel nhị phân có macro (*.xlsb). |
