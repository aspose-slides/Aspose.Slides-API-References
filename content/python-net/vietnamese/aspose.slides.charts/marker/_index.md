## Lớp Marker

Biểu diễn đánh dấu của một biểu đồ.

Kiểu Marker cung cấp các thành viên sau:

## Thuộc tính

| Thuộc tính | Mô tả |
| :- | :- |
| [`symbol`](/slides/python-net/vi/aspose.slides.charts/marker/symbol/) | Biểu diễn kiểu đánh dấu trong biểu đồ đường, biểu đồ phân tán, hoặc biểu đồ radar.<br/>            Đọc/ghi [`MarkerStyleType`](/slides/python-net/vi/aspose.slides.charts/markerstyletype). |
| [`format`](/slides/python-net/vi/aspose.slides.charts/marker/format/) | Lấy hoặc đặt màu nền của đánh dấu.<br/>            Chỉ-đọc [`IFormat`](/slides/python-net/vi/aspose.slides.charts/iformat). |
| [`size`](/slides/python-net/vi/aspose.slides.charts/marker/size/) | Biểu diễn kích thước đánh dấu trong biểu đồ đường, biểu đồ phân tán, hoặc biểu đồ radar.<br/>            Đọc/ghi **int**. |
