## DataSourceType liệt kê

Các loại nguồn dữ liệu.

Kiểu DataSourceType cung cấp các thành viên sau:

## Trường

| Trường | Mô tả |
| :- | :- |
| WORKSHEET | Sử dụng các đối tượng CellXls để lưu XValue, YValue, Value hoặc BubbleSize của điểm dữ liệu trong worksheet. |
| STRING_LITERALS | Sử dụng biến chuỗi truy cập nhanh để lưu XValue, YValue, Value hoặc BubbleSize của <br/>            điểm dữ liệu. Worksheet KHÔNG được sử dụng để lưu các giá trị. |
| DOUBLE_LITERALS | Sử dụng biến double truy cập nhanh để lưu XValue, YValue, Value hoặc BubbleSize của <br/>            điểm dữ liệu. Worksheet KHÔNG được sử dụng để lưu các giá trị. |
