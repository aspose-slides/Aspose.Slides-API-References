## value thuộc tính
Nếu UseCell là true thì thuộc tính này đại diện cho thuộc tính AsCell.Value.
            Nếu UseCell là false thì thuộc tính này đại diện cho thuộc tính AsLiteral.
            Đọc/ghi **bất kỳ**.

### Định nghĩa:
```python
@property
def value(self):
    ...

@value.setter
def value(self, value):
    ...
```
