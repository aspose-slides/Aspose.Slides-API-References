## show_legend_key thuộc tính
Đại diện cho hành vi hiển thị chìa khóa chú thích dữ liệu của biểu đồ được chỉ định. 
True nếu chìa khóa chú thích dữ liệu hiển thị.
Đọc/ghi **bool**.


### Ghi chú

If parent of this DataLabelFormat object is a DataLabelCollection collection of data labels then this
            thuộc tính này lấy hoặc đặt giá trị mặc định của thuộc tính ShowLegendKey cho các nhãn dữ liệu mới trong bộ sưu tập DataLabelCollection.
            Đặt thuộc tính này với giá trị cũng sẽ đặt giá trị này cho thuộc tính ShowLegendKey của tất cả các nhãn dữ liệu trong bộ sưu tập DataLabelCollection
            (ví dụ "DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;" khiến tất cả DataLabels[i].ShowLegendKey bằng val).
