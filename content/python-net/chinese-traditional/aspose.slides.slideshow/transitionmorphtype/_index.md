## TransitionMorphType 列舉

表示一種類型的形態過渡。

TransitionMorphType 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| BY_OBJECT | 形態過渡將在將形狀視為不可分割的物件時執行。 |
| BY_WORD | 形態過渡將在可能的情況下以單字為單位傳送文字執行。 |
| BY_CHAR | 形態過渡將在可能的情況下以字元為單位傳送文字執行。 |
