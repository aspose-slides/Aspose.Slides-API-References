## NotesPositions 列舉

表示將註釋渲染到匯出文件的規則

NotesPositions 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| NONE | 指定不應顯示任何註釋。 |
| BOTTOM_FULL | 指定註釋應使用額外頁面完整顯示。 |
| BOTTOM_TRUNCATED | 指定註釋僅顯示於單一頁面。 |
