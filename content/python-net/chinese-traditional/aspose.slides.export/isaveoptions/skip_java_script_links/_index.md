## skip_java_script_links 屬性
指定在儲存簡報時是否跳過包含 JavaScript 呼叫的超連結。 
            讀/寫 **bool**. 預設值為 **false** .


### 備註

當此屬性設定為 **true** , 超連結包含 JavaScript 呼叫將在儲存時被忽略。

當此屬性設定為 **false** , 所有超連結將會被儲存。
