## SvgExternalFontsHandling 列舉

表示處理用於文字繪製的外部字型的方式。

SvgExternalFontsHandling 型別公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| ADD_LINKS_TO_FONT_FILES | 在 SVG 檔案的樣式區段加入指向獨立字型檔案的連結。 |
| EMBED | 將字型資料直接儲存至 SVG 檔案。使用此選項前，請檢查所有外部字型的授權協議。 |
| VECTORIZE | 將所有使用外部字型的文字儲存為圖形。 |
