## TiffCompressionTypes 列舉

提供控制演示文稿以 TIFF 格式壓縮方式的選項。

TiffCompressionTypes 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| DEFAULT | 指定預設的壓縮方案 (LZW)。 |
| NONE | 指定不進行壓縮。 |
| CCITT3 | 指定 CCITT3 壓縮方案。 |
| CCITT4 | 指定 CCITT4 壓縮方案。 |
| LZW | 指定 LZW 壓縮方案（預設）。 |
| RLE | 指定 RLE 壓縮方案。 |
