## skip_java_script_links 屬性
指定在保存簡報時是否跳過帶有 JavaScript 呼叫的超連結。 
            讀寫 **bool**。 預設值為 **false** .


### 備註

當此屬性設為 **true** 時，保存時將忽略帶有 JavaScript 呼叫的超連結。


當此屬性設為 **false** 時，所有超連結將被保存。
