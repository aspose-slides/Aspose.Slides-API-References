## IPptxOptions 類別

表示用於儲存 OpenXml 簡報的選項 (PPTX, PPSX, POTX, PPTM, PPSM, POTM)。

IPptxOptions 類型公開以下成員：

## 屬性

| Property | Description |
| :- | :- |
| [`conformance`](/slides/python-net/zh-hant/aspose.slides.export/ipptxoptions/conformance/) | 指定演示文件符合的相容性類別。<br/>            預設值為 [`Conformance.ECMA_376_2006`](/slides/python-net/zh-hant/aspose.slides.export/conformance/ECMA_376_2006) |
| [`zip_64_mode`](/slides/python-net/zh-hant/aspose.slides.export/ipptxoptions/zip_64_mode/) | 指定是否對演示文件使用 ZIP64 格式。 <br/>            預設值為 [`Zip64Mode.IF_NECESSARY`](/slides/python-net/zh-hant/aspose.slides.export/zip64mode/IF_NECESSARY) |
| [`refresh_thumbnail`](/slides/python-net/zh-hant/aspose.slides.export/ipptxoptions/refresh_thumbnail/) | 指定是否重新整理演示縮圖。 <br/>            讀寫 **bool**。<br/>            預設值為 **true** 。 |
| [`compression_level`](/slides/python-net/zh-hant/aspose.slides.export/ipptxoptions/compression_level/) | 指定儲存演示文件時使用的壓縮等級。<br/>            預設值為 [`CompressionLevel.LEVEL6`](/slides/python-net/zh-hant/aspose.slides.export/compressionlevel/LEVEL6)。 |
