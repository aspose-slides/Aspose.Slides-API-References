## TextInheritanceLimit 列舉

控制文字屬性繼承的深度。

TextInheritanceLimit 型別公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| ALL | 繼承所有文字屬性。 |
| TEXT_BOX | 僅繼承自 TextFrame 的樣式。 |
| PARAGRAPH_ONLY | 僅使用為段落定義的屬性。 |
