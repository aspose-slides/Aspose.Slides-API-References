## SvgEvent 枚舉

代表 SVG 形狀的選項。

SvgEvent 類型公開以下成員：

## 欄位

| 欄位 | 描述 |
| :- | :- |
| ON_FOCUS_IN | 當元素獲得焦點時發生，例如文字被選取時。 |
| ON_FOCUS_OUT | 當元素失去焦點時發生，例如文字被取消選取時。 |
| ON_ACTIVATE | 當元素被激活時發生，例如透過滑鼠點擊或按鍵。 |
| ON_CLICK | 當指向裝置的按鈕在元素上被點擊時發生。 |
| ON_MOUSE_DOWN | 當指向裝置的按鈕在元素上被按下時發生。 |
| ON_MOUSE_UP | 當指向裝置的按鈕在元素上被釋放時發生。 |
| ON_MOUSE_OVER | 當指向裝置移到元素上時發生。 |
| ON_MOUSE_MOVE | 當指向裝置在元素上移動時發生。 |
| ON_MOUSE_OUT | 當指向裝置移離元素時發生。 |
| ON_LOAD | 當使用者代理已完整解析該元素及其子元素和所有參考資源，並需要渲染它時發生。 |
| ON_UNLOAD | 當 DOM 實作從視窗或框架中移除文件時發生。僅適用於最外層的 svg 元素。 |
| ON_ABORT | 當頁面載入在元素完全載入之前被停止時發生。 |
| ON_ERROR | 當元素未正確載入或腳本執行期間發生錯誤時發生。 |
| ON_RESIZE | 當文件檢視被調整大小時發生。僅適用於最外層的 svg 元素。 |
| ON_SCROLL | 當文件檢視沿 X、Y 或兩個軸平移時發生。僅適用於最外層的 svg 元素。 |
| ON_ZOOM | 當文件檢視的縮放級別被變更時發生。僅適用於最外層的 svg 元素。 |
| ON_BEGIN | 當動畫元素開始時發生。 |
| ON_END | 當動畫元素結束時發生。 |
| ON_REPEAT | 當動畫元素重複時發生。 |
