## HandoutType 列舉

指定在頁面上放置多少張投影片以及其順序。

HandoutType 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| HANDOUTS1 | 每頁一張投影片。 |
| HANDOUTS2 | 每頁兩張投影片。 |
| HANDOUTS3 | 每頁三張投影片。 |
| HANDOUTS_4_HORIZONTAL | 每頁四張投影片，以水平順序排列。 |
| HANDOUTS_4_VERTICAL | 每頁四張投影片，以垂直順序排列。 |
| HANDOUTS_6_HORIZONTAL | 每頁六張投影片，以水平順序排列。 |
| HANDOUTS_6_VERTICAL | 每頁六張投影片，以垂直順序排列。 |
| HANDOUTS_9_HORIZONTAL | 每頁九張投影片，以水平順序排列。 |
| HANDOUTS_9_VERTICAL | 每頁九張投影片，以垂直順序排列。 |
