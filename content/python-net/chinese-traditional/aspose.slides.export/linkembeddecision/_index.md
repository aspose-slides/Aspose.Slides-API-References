## LinkEmbedDecision 列舉

決定物件在儲存期間的處理方式。

LinkEmbedDecision 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| LINK | 物件將會以 URL 方式外部儲存，並以 URL 參照 |
| EMBED | 如果可能，應將物件嵌入產生的檔案中。如果嵌入不可行，將會呼叫 GetUrl，根據結果，物件將以 URL 參照或被忽略。 |
| IGNORE | 物件將被忽略。 |
