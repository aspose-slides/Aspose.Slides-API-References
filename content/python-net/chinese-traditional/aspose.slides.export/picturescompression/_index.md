## PicturesCompression 列舉

表示圖片壓縮等級

PicturesCompression 類型會公開下列成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| DPI330 | 適合高畫質 (HD) 顯示器的良好品質 |
| DPI220 | 在大多數印表機和螢幕上提供卓越品質 |
| DPI150 | 適用於網頁和投影機的良好品質 |
| DPI96 | 減少文件大小以便分享 |
| DPI72 | 預設壓縮等級 |
| DOCUMENT_RESOLUTION | 使用文件解析度 - 圖片不會被壓縮，並會以原始狀態插入文件中 |
