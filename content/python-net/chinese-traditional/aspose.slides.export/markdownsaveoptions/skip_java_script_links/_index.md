## skip_java_script_links 屬性
指定在儲存簡報時是否要跳過含有 JavaScript 呼叫的超連結。  
讀寫 **bool**。預設值為 **false** 。

### 備註

當此屬性設定為 **true** 時，超連結（含 JavaScript 呼叫）在儲存時將被忽略。

當此屬性設定為 **false** 時，所有超連結都會被儲存。
