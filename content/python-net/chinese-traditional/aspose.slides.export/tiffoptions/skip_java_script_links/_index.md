## skip_java_script_links 屬性
指定在保存簡報時是否跳過帶有 JavaScript 呼叫的超連結。 
            可讀寫 **bool**。預設值為 **false** .


### 備註

當此屬性設為 **true** , 帶有 JavaScript 呼叫的超連結在保存時將被忽略。


當此屬性設為 **false** , 所有超連結都將被保存。
