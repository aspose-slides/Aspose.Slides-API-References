## CompressionLevel 列舉

指定 ZIP 壓縮等級用於 OpenXML 檔案。較高的等級可提供更好的壓縮，但會犧牲較慢的處理速度。

CompressionLevel 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| NONE | 未套用壓縮。檔案會原樣儲存。 |
| LEVEL1 | 最快的壓縮，壓縮比最低。 |
| LEVEL2 | 較快的壓縮，壓縮比略佳於 [`CompressionLevel.LEVEL1`](/slides/python-net/zh-hant/aspose.slides.export/compressionlevel/LEVEL1)。 |
| LEVEL3 | 提供比 [`CompressionLevel.LEVEL2`](/slides/python-net/zh-hant/aspose.slides.export/compressionlevel/LEVEL2) 更佳的壓縮，對效能的影響為中等。 |
| LEVEL4 | 提供比 [`CompressionLevel.LEVEL3`](/slides/python-net/zh-hant/aspose.slides.export/compressionlevel/LEVEL3) 更佳的壓縮。 |
| LEVEL5 | 提供比 [`CompressionLevel.LEVEL4`](/slides/python-net/zh-hant/aspose.slides.export/compressionlevel/LEVEL4) 更佳的壓縮，需額外的處理時間。 |
| LEVEL6 | 標準壓縮，於壓縮速度與檔案大小之間提供良好平衡。<br/>預設的壓縮等級。 |
| LEVEL7 | 提供比 [`CompressionLevel.LEVEL6`](/slides/python-net/zh-hant/aspose.slides.export/compressionlevel/LEVEL6) 更高的壓縮，但處理速度較慢。 |
| LEVEL8 | 提供比 [`CompressionLevel.LEVEL7`](/slides/python-net/zh-hant/aspose.slides.export/compressionlevel/LEVEL7) 更高的壓縮。 |
| LEVEL9 | 最大壓縮。產生最小的檔案大小，但處理速度最慢。 |
