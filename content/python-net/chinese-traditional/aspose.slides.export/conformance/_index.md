## 相容性列舉

指定 PresentationML 文件符合的相容性類別。

Conformance 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| ECMA_376_2006 | 指定文件符合 ECMA376:2006。 |
| ISO_29500_2008_TRANSITIONAL | 指定文件符合 ISO/IEC 29500:2008 Transitional 相容性等級。 |
| ISO_29500_2008_STRICT | 指定文件符合 ISO/IEC 29500:2008 Strict 相容性等級。 |
