## PdfCompliance enumeration

定義 PDF 標準相容等級的常數。

PdfCompliance 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| PDF15 | 輸出檔案將符合 PDF 1.5 標準。 |
| PDF16 | 輸出檔案將符合 PDF 1.6 標準。 |
| PDF17 | 輸出檔案將符合 PDF 1.7 標準。 |
| PDF_A1B | 輸出檔案將符合 PDF/A-1b 標準。 |
| PDF_A1A | 輸出檔案將符合 PDF/A-1a 標準。 |
| PDF_A2B | 輸出檔案將符合 PDF/A-2b 標準。 |
| PDF_A2A | 輸出檔案將符合 PDF/A-2a 標準。 |
| PDF_A3B | 輸出檔案將符合 PDF/A-3b 標準。 |
| PDF_A3A | 輸出檔案將符合 PDF/A-3a 標準。 |
| PDF_UA | 輸出檔案將符合 PDF/UA 標準。 |
| PDF_A2U | 輸出檔案將符合 PDF/A-2u 標準。 |
