## SaveFormat 列舉

定義已儲存簡報格式的常數。

SaveFormat 型別公開以下成員：

## 欄位

| Field | Description |
| :- | :- |
| PPT | 將簡報儲存為 PPT 格式。 |
| PDF | 將簡報儲存為 PDF 格式。 |
| XPS | 將簡報儲存為 XPS 格式。 |
| PPTX | 將簡報儲存為 PPTX 格式。 |
| PPSX | 將簡報儲存為 PPSX（投影片）格式。 |
| TIFF | 將簡報儲存為多頁 TIFF 影像。 |
| ODP | 將簡報儲存為 ODP 格式。 |
| PPTM | 將簡報儲存為 PPTM（具備巨集的簡報）格式。 |
| PPSM | 將簡報儲存為 PPSM（具備巨集的投影片）格式。 |
| POTX | 將簡報儲存為 POTX（範本）格式。 |
| POTM | 將簡報儲存為 POTM（具備巨集的範本）格式。 |
| HTML | 將簡報儲存為 HTML 格式。 |
| SWF | 將簡報儲存為 SWF 格式。 |
| OTP | 將簡報儲存為 OTP（簡報範本）格式。 |
| PPS | 將簡報儲存為 PPS 格式。 |
| POT | 將簡報儲存為 POT 格式。 |
| FODP | 將簡報儲存為 FODP 格式。 |
| GIF | 將簡報儲存為 GIF 格式。 |
| HTML5 | 將簡報儲存為 HTML 格式，使用新的 HTML5 模板系統。 |
| MD | 將簡報儲存為 Markdown 格式。 |
| XML | 將簡報儲存為 PowerPoint XML 簡報格式。 |
