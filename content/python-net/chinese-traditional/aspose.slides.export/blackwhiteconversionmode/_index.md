## BlackWhiteConversionMode 列舉

提供控制投影片圖像如何轉換為雙色影像的選項。

BlackWhiteConversionMode 類型會公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| DEFAULT | 指定不使用轉換演算法。將使用 TIFF 編解碼器實作的演算法。(預設) |
| DITHERING | 指定抖動演算法 (Floyd-Steinberg)。 |
| DITHERING_FLOYD_STEINBERG | 指定 Floyd-Steinberg 抖動演算法。 |
| AUTO | 指定自動計算的閾值演算法 (Otsu)。 |
| AUTO_OTSU | 指定自動計算的 Otsu 閾值演算法。 |
| THRESHOLD25 | 指定靜態閾值演算法 (25%)。 |
| THRESHOLD50 | 指定靜態閾值演算法 (50%)。 |
| THRESHOLD75 | 指定靜態閾值演算法 (75%)。 |
