## ISwfOptions 類別

提供控制如何將簡報儲存為 SWF 格式的選項。

ISwfOptions 類型公開以下成員：

## 屬性

| 屬性 | 描述 |
| :- | :- |
| [`compressed`](/slides/python-net/zh-hant/aspose.slides.export/iswfoptions/compressed/) | 指定產生的 SWF 文件是否應該壓縮。<br/>            預設為 `true`。 |
| [`viewer_included`](/slides/python-net/zh-hant/aspose.slides.export/iswfoptions/viewer_included/) | 指定產生的 SWF 文件是否應包含整合的文件檢視器。<br/>            預設為 `true`。 |
| [`show_page_border`](/slides/python-net/zh-hant/aspose.slides.export/iswfoptions/show_page_border/) | 指定是否顯示頁面周圍的邊框。預設為 true。 |
| [`show_hidden_slides`](/slides/python-net/zh-hant/aspose.slides.export/iswfoptions/show_hidden_slides/) | 指定產生的文件是否應包含隱藏投影片。<br/>            預設為 `false`。 |
| [`show_full_screen`](/slides/python-net/zh-hant/aspose.slides.export/iswfoptions/show_full_screen/) | 顯示/隱藏全螢幕按鈕。可在 flashvars 中覆寫。預設為 true。 |
| [`show_page_stepper`](/slides/python-net/zh-hant/aspose.slides.export/iswfoptions/show_page_stepper/) | 顯示/隱藏頁面步進器。可在 flashvars 中覆寫。預設為 true。 |
| [`show_search`](/slides/python-net/zh-hant/aspose.slides.export/iswfoptions/show_search/) | 顯示/隱藏搜尋區段。可在 flashvars 中覆寫。預設為 true。 |
| [`show_top_pane`](/slides/python-net/zh-hant/aspose.slides.export/iswfoptions/show_top_pane/) | 顯示/隱藏整個上方面板。可在 flashvars 中覆寫。預設為 true。 |
| [`show_bottom_pane`](/slides/python-net/zh-hant/aspose.slides.export/iswfoptions/show_bottom_pane/) | 顯示/隱藏下方面板。可在 flashvars 中覆寫。預設為 true。 |
| [`show_left_pane`](/slides/python-net/zh-hant/aspose.slides.export/iswfoptions/show_left_pane/) | 顯示/隱藏左側面板。可在 flashvars 中覆寫。預設為 true。 |
| [`start_open_left_pane`](/slides/python-net/zh-hant/aspose.slides.export/iswfoptions/start_open_left_pane/) | 以已開啟的左側面板開始。可在 flashvars 中覆寫。預設為 false。 |
| [`enable_context_menu`](/slides/python-net/zh-hant/aspose.slides.export/iswfoptions/enable_context_menu/) | 啟用/停用右鍵功能表。預設為 true。 |
| [`logo_image_bytes`](/slides/python-net/zh-hant/aspose.slides.export/iswfoptions/logo_image_bytes/) | 在檢視器右上角顯示為標誌的圖像。<br/>            圖像應為 32x64 像素的 PNG 圖片，否則標誌可能無法正確顯示。 |
| [`logo_link`](/slides/python-net/zh-hant/aspose.slides.export/iswfoptions/logo_link/) | 取得或設定標誌的完整超連結位址。<br/>            僅在指定了 [`ISwfOptions.logo_image_bytes`](/slides/python-net/zh-hant/aspose.slides.export/iswfoptions/logo_image_bytes) 時才會生效。 |
| [`jpeg_quality`](/slides/python-net/zh-hant/aspose.slides.export/iswfoptions/jpeg_quality/) | 指定 JPEG 圖像的品質。<br/>            預設為 95。 |
| [`slides_layout_options`](/slides/python-net/zh-hant/aspose.slides.export/iswfoptions/slides_layout_options/) | 取得或設定匯出簡報 [`ISlidesLayoutOptions`](/slides/python-net/zh-hant/aspose.slides.export/islideslayoutoptions) 時投影片在頁面上的排列模式。<br/>            此屬性不支援指定 `Aspose.Slides.Export.HandoutLayoutingOptions` 型別的物件。 |
| [`warning_callback`](/slides/python-net/zh-hant/aspose.slides.export/iswfoptions/warning_callback/) |  |
| [`progress_callback`](/slides/python-net/zh-hant/aspose.slides.export/iswfoptions/progress_callback/) |  |
