## skip_java_script_links 屬性
指定在儲存簡報時是否跳過包含 JavaScript 呼叫的超連結。 
            可讀寫 **bool**。 預設值為 **false** .


### 備註

當此屬性設為 **true** 時，保存時將忽略 JavaScript 呼叫的超連結。


當此屬性設為 **false** 時，所有超連結都將被保存。
