## 類別

| 類別 | 說明 |
| :- | :- |
| [`ExcelWorkbookImporter`](/slides/python-net/zh-hant/aspose.slides.importing/excelworkbookimporter/) | 提供將 Excel 活頁簿的內容匯入簡報的功能。 |
| [`ExternalResourceResolver`](/slides/python-net/zh-hant/aspose.slides.importing/externalresourceresolver/) | 回呼類別，用於在 Html、Svg 文件匯入期間解析外部資源。<br/>            使用此解析器可能在客戶端提供的 HTML 或 SVG 檔案使伺服器軟體取得本機或網路檔案時產生安全漏洞。請小心使用。建議完全不要指定 ExternalResourceResolver（僅會讀取嵌入的物件），或建立子類別以檢查指定的 uri 是否有效。 |
| [`HtmlExternalResolver`](/slides/python-net/zh-hant/aspose.slides.importing/htmlexternalresolver/) | 回呼物件，由 HTML 匯入例程使用，以取得如影像等參考的物件。<br/>            使用此解析器可能在客戶端提供的 HTML 檔案使伺服器軟體取得本機或網路檔案時產生安全漏洞。請小心使用。建議完全不要指定 HtmlExternalResolver（僅會讀取嵌入的物件），或建立子類別以檢查指定的 uri 是否有效。 |
| [`IExternalResourceResolver`](/slides/python-net/zh-hant/aspose.slides.importing/iexternalresourceresolver/) | 回呼介面，用於在 Html、Svg 文件匯入期間解析外部資源。 |
| [`IHtmlExternalResolver`](/slides/python-net/zh-hant/aspose.slides.importing/ihtmlexternalresolver/) | 回呼介面，由 HTML 匯入例程使用，以取得如影像等參考的物件。 |
| [`PdfImportOptions`](/slides/python-net/zh-hant/aspose.slides.importing/pdfimportoptions/) | 表示 PDF 匯入選項 |
