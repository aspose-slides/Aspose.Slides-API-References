## IWarningInfo 類別

代表所有警告的基礎介面。

IWarningInfo 類型公開下列成員：

## 屬性

| Property | 說明 |
| :- | :- |
| [`warning_type`](/slides/python-net/zh-hant/aspose.slides.warnings/iwarninginfo/warning_type/) | 傳回警告的類型。<br/>            唯讀 [`IWarningInfo.warning_type`](/slides/python-net/zh-hant/aspose.slides.warnings/iwarninginfo/warning_type). |
| [`description`](/slides/python-net/zh-hant/aspose.slides.warnings/iwarninginfo/description/) | 傳回此警告的人類可讀說明。<br/>            唯讀 **str**. |

## 方法

| Method | 說明 |
| :- | :- |
| [`send_warning(self, receiver)`](/slides/python-net/zh-hant/aspose.slides.warnings/iwarninginfo/send_warning/#iwarningcallback) | 如果 receiver 不是 None，則將警告傳送給指定的 receiver，並在 receiver 決定中止操作時拋出 <br/>            AbortRequestedException。 |
