## WarningType 列舉

表示一種警告類型。

WarningType 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| SOURCE_FILE_CORRUPTION | 已在原始文件中偵測到問題，若以原始格式儲存，文件很可能無法開啟。 |
| DATA_LOSS | 文字、圖表、影像或其他資料在載入後的文件樹，或是儲存後產生的文件中，將會完全缺失。 |
| MAJOR_FORMATTING_LOSS | 重大格式遺失。 |
| MINOR_FORMATTING_LOSS | 小幅格式遺失。 |
| COMPATIBILITY_ISSUE | 這是一個已知問題，會導致某些使用者代理或舊版使用者代理無法開啟文件。 |
| UNEXPECTED_CONTENT | 原始文件中的某些內容無法被辨識（即不受支援），這可能會導致問題或造成資料/格式遺失，也可能不會。 |
