## OverrideTheme 類別

代表一個覆寫主題。

**繼承:**[`OverrideTheme`](/slides/python-net/zh-hant/aspose.slides.theme/overridetheme) → [`Theme`](/slides/python-net/zh-hant/aspose.slides.theme/theme)

OverrideTheme 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`color_scheme`](/slides/python-net/zh-hant/aspose.slides.theme/overridetheme/color_scheme/) | 返回顏色方案。<br/>            唯讀 [`IColorScheme`](/slides/python-net/zh-hant/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/zh-hant/aspose.slides.theme/overridetheme/font_scheme/) | 返回字型方案。<br/>            唯讀 [`IFontScheme`](/slides/python-net/zh-hant/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/zh-hant/aspose.slides.theme/overridetheme/format_scheme/) | 返回形狀格式方案。<br/>            唯讀 [`IFormatScheme`](/slides/python-net/zh-hant/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/zh-hant/aspose.slides.theme/overridetheme/presentation/) | 返回父簡報。<br/>            唯讀 [`IPresentation`](/slides/python-net/zh-hant/aspose.slides/ipresentation). |
| [`is_empty`](/slides/python-net/zh-hant/aspose.slides.theme/overridetheme/is_empty/) | True 值表示 ColorScheme、FontScheme、FormatScheme 為 None，且此主題物件的任何覆寫皆已停用。<br/>            唯讀 **bool**. |
