## MasterTheme class

代表一個母版主題。

**繼承：**[`MasterTheme`](/slides/python-net/zh-hant/aspose.slides.theme/mastertheme) → [`Theme`](/slides/python-net/zh-hant/aspose.slides.theme/theme)

MasterTheme 類型公開以下成員：

## 屬性

| 屬性 | 描述 |
| :- | :- |
| [`color_scheme`](/slides/python-net/zh-hant/aspose.slides.theme/mastertheme/color_scheme/) | 返回顏色方案。<br/>            唯讀 [`IColorScheme`](/slides/python-net/zh-hant/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/zh-hant/aspose.slides.theme/mastertheme/font_scheme/) | 返回字型方案。<br/>            唯讀 [`IFontScheme`](/slides/python-net/zh-hant/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/zh-hant/aspose.slides.theme/mastertheme/format_scheme/) | 返回形狀格式方案。<br/>            唯讀 [`IFormatScheme`](/slides/python-net/zh-hant/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/zh-hant/aspose.slides.theme/mastertheme/presentation/) | 返回父簡報。<br/>            唯讀 [`IPresentation`](/slides/python-net/zh-hant/aspose.slides/ipresentation). |
| [`extra_color_schemes`](/slides/python-net/zh-hant/aspose.slides.theme/mastertheme/extra_color_schemes/) | 返回額外顏色方案的集合。<br/>            這些方案不會影響簡報的外觀，可被選為投影片的主要顏色方案。<br/>            唯讀 [`IExtraColorSchemeCollection`](/slides/python-net/zh-hant/aspose.slides.theme/iextracolorschemecollection). |
| [`name`](/slides/python-net/zh-hant/aspose.slides.theme/mastertheme/name/) | 返回主題名稱。<br/>            讀/寫 **str**. |
