## Theme 類別

表示一個主題。

Theme 類型會公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`color_scheme`](/slides/python-net/zh-hant/aspose.slides.theme/theme/color_scheme/) | 傳回顏色配色方案。<br/>            只讀 [`IColorScheme`](/slides/python-net/zh-hant/aspose.slides.theme/icolorscheme)。 |
| [`font_scheme`](/slides/python-net/zh-hant/aspose.slides.theme/theme/font_scheme/) | 傳回字型配色方案。<br/>            只讀 [`IFontScheme`](/slides/python-net/zh-hant/aspose.slides.theme/ifontscheme)。 |
| [`format_scheme`](/slides/python-net/zh-hant/aspose.slides.theme/theme/format_scheme/) | 傳回圖形格式配色方案。<br/>            只讀 [`IFormatScheme`](/slides/python-net/zh-hant/aspose.slides.theme/iformatscheme)。 |
| [`presentation`](/slides/python-net/zh-hant/aspose.slides.theme/theme/presentation/) | 傳回父簡報。<br/>            只讀 [`IPresentation`](/slides/python-net/zh-hant/aspose.slides/ipresentation)。 |
