## SlideThemeManager 類別

提供對投影片佈景主題覆寫的存取。

**繼承:**[`SlideThemeManager`](/slides/python-net/zh-hant/aspose.slides.theme/slidethememanager) → [`BaseOverrideThemeManager`](/slides/python-net/zh-hant/aspose.slides.theme/baseoverridethememanager) → [`BaseThemeManager`](/slides/python-net/zh-hant/aspose.slides.theme/basethememanager)

## 屬性

| Property | Description |
| :- | :- |
| [`override_theme`](/slides/python-net/zh-hant/aspose.slides.theme/slidethememanager/override_theme/) | 傳回覆寫的佈景主題物件。<br/>            可讀寫 [`IOverrideTheme`](/slides/python-net/zh-hant/aspose.slides.theme/ioverridetheme). |
| [`is_override_theme_enabled`](/slides/python-net/zh-hant/aspose.slides.theme/slidethememanager/is_override_theme_enabled/) | 決定 OverrideTheme 是否覆寫繼承的有效佈景主題。<br/>            若要啟用 OverrideTheme 進行覆寫，請使用 OverrideTheme.Init*() 方法。<br/>            若要停用 OverrideTheme 的覆寫，請使用 OverrideTheme.Clear() 方法。<br/>            唯讀 **bool**. |
