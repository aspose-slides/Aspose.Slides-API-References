## IExcelDataCell 類別

表示Excel活頁簿中的單一儲存格。

IExcelDataCell 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`value`](/slides/python-net/zh-hant/aspose.slides.excel/iexceldatacell/value/) | 取得Excel儲存格中包含的值。<br/>            唯讀 **any**. |
| [`name`](/slides/python-net/zh-hant/aspose.slides.excel/iexceldatacell/name/) | 取得圖表資料儲存格的名稱。<br/>            唯讀 **str**. |
| [`row`](/slides/python-net/zh-hant/aspose.slides.excel/iexceldatacell/row/) | 取得儲存格所在工作表中列的零基索引。<br/>            唯讀 **int**. |
| [`column`](/slides/python-net/zh-hant/aspose.slides.excel/iexceldatacell/column/) | 取得儲存格所在工作表中欄的零基索引。<br/>            唯讀 **int**. |
