## ExcelDataCell 類別

表示 Excel 活頁簿中的單一儲存格。

ExcelDataCell 類型公開以下成員：

## 屬性

| 屬性 | 描述 |
| :- | :- |
| [`value`](/slides/python-net/zh-hant/aspose.slides.excel/exceldatacell/value/) | 取得 Excel 儲存格中包含的值。 |
| [`name`](/slides/python-net/zh-hant/aspose.slides.excel/exceldatacell/name/) | 取得圖表資料儲存格的名稱。 |
| [`row`](/slides/python-net/zh-hant/aspose.slides.excel/exceldatacell/row/) | 取得儲存格所在工作表中列的零基索引。<br/>            Read-only **int**. |
| [`column`](/slides/python-net/zh-hant/aspose.slides.excel/exceldatacell/column/) | 取得儲存格所在工作表中欄的零基索引。<br/>            Read-only **int**. |
