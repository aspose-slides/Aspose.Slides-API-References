## show 屬性
取得或設定一個值，用來指示基礎元素是否顯示。

### 備註

當 `false` 時，基礎元素會被隱藏，但仍可能根據其他幻影設定佔用空間。對應 OMML 屬性 `m:show`。

### 定義:
```python
@property
def show(self):
    ...

@show.setter
def show(self, value):
    ...
```
