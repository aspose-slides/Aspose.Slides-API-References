## MathJustification 列舉

指定數學段落的對齊方式（同一段落中相鄰的數學文字實例的系列）

MathJustification 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| LEFT_JUSTIFIED | 將數學文字向左對齊 |
| RIGHT_JUSTIFIED | 將數學文字向右對齊 |
| CENTERED | 將數學文字置中 |
| CENTERED_AS_GROUP | 在頁面上將整個數學區塊組作為單一單位置中。<br/>            這表示數學文字的實例可以彼此對齊，<br/>            但整個數學文字組會作為整體置中。 |
