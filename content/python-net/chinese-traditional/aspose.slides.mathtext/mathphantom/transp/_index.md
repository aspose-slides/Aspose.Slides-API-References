## transp 屬性
取得或設定一個值，指示 phantom 是否對基於類別的間距規則為透明


### 備註

當 `true` 時，phantom 內部的運算子和符號仍會影響 phantom 周圍的數學間距（如同可見）。當 `false` 時，基於類別的間距會被忽略。對應 OMML 屬性 `m:transp`。

### 定義：
```python
@property
def transp(self):
    ...

@transp.setter
def transp(self, value):
    ...
```
