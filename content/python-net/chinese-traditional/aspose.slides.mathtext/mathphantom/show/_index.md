## show 屬性
取得或設定指示基礎元素是否顯示的值。


### 備註

當 `false` 時，基礎元素會被隱藏，但根據其他 phantom 設定，它仍可能佔用空間。對應於 OMML 屬性 `m:show`。

### 定義:
```python
@property
def show(self):
    ...

@show.setter
def show(self, value):
    ...
```
