## IMathRightSubSuperscriptElement 類別

指定 Sub-Superscript 物件，該物件由基底
            以及放置於基底右側的下標和上標組成。

IMathRightSubSuperscriptElement 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`base`](/slides/python-net/zh-hant/aspose.slides.mathtext/imathrightsubsuperscriptelement/base/) | 基底參數 |
| [`subscript`](/slides/python-net/zh-hant/aspose.slides.mathtext/imathrightsubsuperscriptelement/subscript/) | 下標參數 |
| [`superscript`](/slides/python-net/zh-hant/aspose.slides.mathtext/imathrightsubsuperscriptelement/superscript/) | 上標參數 |
| [`align_scripts`](/slides/python-net/zh-hant/aspose.slides.mathtext/imathrightsubsuperscriptelement/align_scripts/) | 指定下標/上標的對齊方式。<br/>            為 true 時，下標與上標水平對齊。<br/>            為 false 時，根據基底的形狀進行字距調整。<br/>            預設值為 false。 |
