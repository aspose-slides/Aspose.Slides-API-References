## MathSpacingRules 列舉

矩陣欄之間的間隙類型（水平間距）

MathSpacingRules 型別公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| SINGLE_SPACING_GAP | 單一 (欄為 1 em 或 列為 1 行) |
| ONE_AND_HALF_SPACING_GAP | 一個半 (欄為 1.5 em 或 列為 1.5 行) |
| DOUBLE_SPACING_GAP | 雙倍間距 (欄為 2 em 或 列為 2 行) |
| EXACTLY | 精確值<br/>            對於欄，依賴 ColumnGap 的值，單位為 twips<br/>            對於列，依賴 RowGap 的值，單位為 twips |
| MULTIPLE | 多重<br/>            對於欄，依賴 ColumnGap 的值，以 0.5 em 為增量<br/>            對於列，依賴 RowGap 的值，以 行 為單位 |
