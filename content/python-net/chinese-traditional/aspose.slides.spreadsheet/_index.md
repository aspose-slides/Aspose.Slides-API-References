包含用於在 Microsoft PowerPoint 簡報中處理試算表物件的類別。

## 類別

| 類別 | 說明 |
| :- | :- |
| [`CellCircularReferenceException`](/slides/python-net/zh-hant/aspose.slides.spreadsheet/cellcircularreferenceexception/) | 當偵測到一個或多個循環參照時所拋出的例外，該情況下公式直接或間接參照到其<br/>            自身儲存格。 |
| [`CellInvalidFormulaException`](/slides/python-net/zh-hant/aspose.slides.spreadsheet/cellinvalidformulaexception/) | 當計算出的公式不正確或未被解析時所拋出的例外。 |
| [`CellInvalidReferenceException`](/slides/python-net/zh-hant/aspose.slides.spreadsheet/cellinvalidreferenceexception/) | 當遇到無效的儲存格參照時所拋出的例外。 |
| [`CellUnsupportedDataException`](/slides/python-net/zh-hant/aspose.slides.spreadsheet/cellunsupporteddataexception/) | 當在試算表儲存格中遇到不支援的資料時所拋出的例外。 |
