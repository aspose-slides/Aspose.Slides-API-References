## GraphicalObjectLock 類別

確定在父 GraphicalObject 上哪些操作被停用。

**繼承:**[`GraphicalObjectLock`](/slides/python-net/zh-hant/aspose.slides/graphicalobjectlock) → [`BaseShapeLock`](/slides/python-net/zh-hant/aspose.slides/baseshapelock)

## 屬性

| Property | Description |
| :- | :- |
| [`no_locks`](/slides/python-net/zh-hant/aspose.slides/graphicalobjectlock/no_locks/) | 如果所有 lock-flags 都被停用，返回 true。<br/>            只讀 **bool**. |
| [`grouping_locked`](/slides/python-net/zh-hant/aspose.slides/graphicalobjectlock/grouping_locked/) | 判斷是否禁止將此形狀加入群組。<br/>            讀寫 **bool**. |
| [`drilldown_locked`](/slides/python-net/zh-hant/aspose.slides/graphicalobjectlock/drilldown_locked/) | 判斷是否禁止選取此物件的子形狀。<br/>            讀寫 **bool**. |
| [`select_locked`](/slides/python-net/zh-hant/aspose.slides/graphicalobjectlock/select_locked/) | 判斷是否禁止選取此形狀。<br/>            讀寫 **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/zh-hant/aspose.slides/graphicalobjectlock/aspect_ratio_locked/) | 判斷形狀在調整大小時是否必須保留長寬比。<br/>            讀寫 **bool**. |
| [`position_locked`](/slides/python-net/zh-hant/aspose.slides/graphicalobjectlock/position_locked/) | 判斷是否禁止移動此形狀。<br/>            讀寫 **bool**. |
| [`size_locked`](/slides/python-net/zh-hant/aspose.slides/graphicalobjectlock/size_locked/) | 判斷是否禁止調整此形狀的大小。<br/>            讀寫 **bool**. |
