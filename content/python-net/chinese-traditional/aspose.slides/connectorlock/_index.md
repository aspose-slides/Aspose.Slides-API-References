## ConnectorLock 類別

確定在父 Connector 上哪些操作被停用。

## Properties

| 屬性 | 描述 |
| :- | :- |
| [`no_locks`](/slides/python-net/zh-hant/aspose.slides/connectorlock/no_locks/) | 如果所有 lock-flags 都已停用，則返回 true。<br/>            唯讀 **bool**. |
| [`grouping_locked`](/slides/python-net/zh-hant/aspose.slides/connectorlock/grouping_locked/) | 確定是否禁止將此形狀新增至群組。<br/>            讀寫 **bool**. |
| [`select_locked`](/slides/python-net/zh-hant/aspose.slides/connectorlock/select_locked/) | 確定是否禁止選取此形狀。<br/>            讀寫 **bool**. |
| [`rotate_locked`](/slides/python-net/zh-hant/aspose.slides/connectorlock/rotate_locked/) | 確定是否禁止變更此形狀的旋轉角度。<br/>            讀寫 **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/zh-hant/aspose.slides/connectorlock/aspect_ratio_locked/) | 確定在調整大小時是否必須保持形狀的長寬比。<br/>            讀寫 **bool**. |
| [`position_move`](/slides/python-net/zh-hant/aspose.slides/connectorlock/position_move/) | 確定是否禁止移動此形狀。<br/>            讀寫 **bool**. |
| [`size_locked`](/slides/python-net/zh-hant/aspose.slides/connectorlock/size_locked/) | 確定是否禁止調整此形狀的大小。<br/>            讀寫 **bool**. |
| [`edit_points_locked`](/slides/python-net/zh-hant/aspose.slides/connectorlock/edit_points_locked/) | 確定是否禁止直接變更此形狀的輪廓。<br/>            讀寫 **bool**. |
| [`adjust_handles_locked`](/slides/python-net/zh-hant/aspose.slides/connectorlock/adjust_handles_locked/) | 確定是否禁止變更調整值。<br/>            讀寫 **bool**. |
| [`arrowheads_locked`](/slides/python-net/zh-hant/aspose.slides/connectorlock/arrowheads_locked/) | 確定是否禁止變更箭頭端點。<br/>            讀寫 **bool**. |
| [`shape_type_locked`](/slides/python-net/zh-hant/aspose.slides/connectorlock/shape_type_locked/) | 確定是否禁止變更形狀類型。<br/>            讀寫 **bool**. |
