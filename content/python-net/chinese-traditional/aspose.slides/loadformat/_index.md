## LoadFormat 列舉

指示要載入的文件格式。

LoadFormat 類型提供以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| AUTO | 指示 Aspose.Slides 自動識別格式。 |
| PPT | Microsoft PowerPoint 97-2003 簡報。 |
| PPS | Microsoft PowerPoint 97-2003 投影片放映。 |
| PPTX | Microsoft Office Open XML PresentationML 文件。 |
| PPSX | Microsoft Office Open XML PresentationML 投影片放映。 |
| ODP | OpenOffice ODF 簡報。 |
| POTX | Microsoft Office Open XML PresentationML 範本。 |
| PPTM | Microsoft Office Open XML PresentationML 巨集啟用文件。 |
| PPSM | Microsoft Office Open XML PresentationML 巨集啟用投影片放映。 |
| POTM | Microsoft Office Open XML PresentationML 巨集啟用範本。 |
| OTP | OpenOffice OTP 簡報範本。 |
| PPT95 | Microsoft PowerPoint 95 簡報。 |
| POT | Microsoft PowerPoint 97-2003 簡報範本。 |
| FODP | Flat XML ODF 簡報。 |
| UNKNOWN | 未知檔案格式 |
