## ISlideText 類別

表示從投影片中擷取的文字

ISlideText 類型會公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`text`](/slides/python-net/zh-hant/aspose.slides/islidetext/text/) | 投影片形狀上的文字 |
| [`master_text`](/slides/python-net/zh-hant/aspose.slides/islidetext/master_text/) | 此投影片的母版頁面形狀上的文字 |
| [`layout_text`](/slides/python-net/zh-hant/aspose.slides/islidetext/layout_text/) | 此投影片的版面配置頁面形狀上的文字 |
| [`notes_text`](/slides/python-net/zh-hant/aspose.slides/islidetext/notes_text/) | 此投影片的備註頁面形狀上的文字 |
| [`comments_text`](/slides/python-net/zh-hant/aspose.slides/islidetext/comments_text/) | 投影片註解的文字 |
