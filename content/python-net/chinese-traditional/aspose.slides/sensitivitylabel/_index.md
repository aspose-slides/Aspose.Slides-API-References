## SensitivityLabel 類別

表示 Microsoft Purview Information Protection 中的敏感度標籤。

SensitivityLabel 類型會公開下列成員：

## 屬性

| Property | Description |
| :- | :- |
| [`id`](/slides/python-net/zh-hant/aspose.slides/sensitivitylabel/id/) | 返回或設定敏感度標籤的 id。<br/>            讀/寫 **str**. |
| [`site_id`](/slides/python-net/zh-hant/aspose.slides/sensitivitylabel/site_id/) | 返回或設定 Azure Active Directory (Azure AD) 站點識別碼，<br/>            其對應描述此敏感度標籤的標籤原則。<br/>            讀/寫 **System.Guid**. |
| [`is_enabled`](/slides/python-net/zh-hant/aspose.slides/sensitivitylabel/is_enabled/) | 表示此敏感度標籤是否已啟用。 |
| [`is_removed`](/slides/python-net/zh-hant/aspose.slides/sensitivitylabel/is_removed/) | 表示此敏感度標籤是否已被移除。 |
| [`assignment_method_type`](/slides/python-net/zh-hant/aspose.slides/sensitivitylabel/assignment_method_type/) | 返回或設定敏感度標籤的指派方式。<br/>            讀/寫 [`SensitivityLabelAssignmentType`](/slides/python-net/zh-hant/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/zh-hant/aspose.slides/sensitivitylabel/content_mark_types/) | 返回應套用於檔案之內容標記類型的清單。 |
