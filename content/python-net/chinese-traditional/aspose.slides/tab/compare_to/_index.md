## compare_to(self, obj) {#any}
比較目前實例與相同類型的另一個物件。

### 回傳值

一個 32 位元整數，用於指示比較對象的相對順序。回傳值具有以下含義：

* < 0 - 此實例小於 obj. = 0 - 此實例等於 obj. > 0 - 此實例大於 obj.
* < 0 - 此實例小於 obj. = 0 - 此實例等於 obj. > 0 - 此實例大於 obj.
* < 0 - 此實例小於 obj. = 0 - 此實例等於 obj. > 0 - 此實例大於 obj.
