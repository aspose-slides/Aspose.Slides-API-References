## ShapeAdjustmentType 列舉

指定形狀調整值的不同類型。

ShapeAdjustmentType 類型公開以下成員：

## 欄位

| Field | 說明 |
| :- | :- |
| CUSTOM | 自訂類型（未知調整） |
| CORNER_SIZE | 控制角落的大小。 |
| LEFT_UP_CORNER | 控制左上角。 |
| RIGHT_UP_CORNER | 控制右上角。 |
| UP_CORNERS | 控制上方的角落。 |
| DOWN_CORNERS | 控制下方的角落。 |
| THICKNESS | 控制圖形的厚度。 |
| ARROW_TAIL_THICKNESS | 控制箭頭尾部的厚度。 |
| ARROWHEAD_LENGTH | 控制箭頭的長度。 |
| ARROWHEAD_WIDTH | 控制箭頭的寬度。 |
| RADIUS | 控制形狀或其部分半徑的大小。 |
| DEPTH | 控制齒輪齒的深度或斜角效果。 |
| SHAPE_PART_OFFSET | 控制圖形的一部分相對於另一部分的偏移。 |
| ANGLE | 控制圖形或其部分的角度。 |
| START_ANGLE | 餅圖和弧形的起始角度。 |
| END_ANGLE | 餅圖和弧形的結束角度。 |
| START_POINT_X | 控制標註起點的 X 位置。 |
| START_POINT_Y | 控制標註起點的 Y 位置。 |
| CONNECTOR_POINT_1X | 控制標註角度調整點的水平位置。 |
| CONNECTOR_POINT_1Y | 控制標註角度調整點的垂直位置。 |
| CONNECTOR_POINT_2X | 控制標註角度調整點的水平位置。 |
| CONNECTOR_POINT_2Y | 控制標註角度調整點的垂直位置。 |
| CONNECTOR_BEND_POSITION_X | 控制連接線彎曲處的水平位置。 |
| CONNECTOR_BEND_POSITION_Y | 控制連接線彎曲處的垂直位置。 |
| ATTACH_Y | 控制圖形的垂直附加點。 |
| ATTACH_X | 控制圖形的水平附加點。 |
| CALLOUT_HEIGHT | 控制標註的垂直尺寸。 |
| CALLOUT_WIDTH | 控制標註的水平尺寸。 |
| CALLOUT_SIZE | 控制標註的大小。 |
| CURVATURE | 彎曲、支撐、彎曲箭頭或形狀的曲率。 |
| HORIZONTAL_THICKNESS | 控制角落形狀的水平厚度。 |
| VERTICAL_THICKNESS | 控制角落形狀的垂直厚度。 |
| VERTICAL_SIZE | 控制形狀的垂直尺寸。 |
| HORIZONTAL_SIZE | 控制形狀的水平尺寸。 |
| TOP | 控制形狀的上側。 |
