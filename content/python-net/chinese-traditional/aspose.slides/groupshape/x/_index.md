## x 屬性
取得或設定形狀左上角的 x 坐標，以點為單位。
            Read/write **float**.


### 備註

返回的值始終已定義，且永不為 **float**。
            必須分配已定義的值；僅將 **float** 指派給 `RawFrame` 實例的屬性。

### 定義：
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
