## Comment 類別

表示投影片上的註解。

Comment 類型公開以下成員：

## 屬性

| Property | Description |
| :- | :- |
| [`text`](/slides/python-net/zh-hant/aspose.slides/comment/text/) | 取得或設定投影片註解的純文字。<br/>            可讀寫 **str**. |
| [`created_time`](/slides/python-net/zh-hant/aspose.slides/comment/created_time/) | 取得或設定註解建立的時間。<br/>            將此屬性設為 **System.DateTime** 表示未設定註解時間。<br/>            可讀寫 **System.DateTime**. |
| [`slide`](/slides/python-net/zh-hant/aspose.slides/comment/slide/) | 取得或設定註解的父投影片。<br/>            唯讀 [`ISlide`](/slides/python-net/zh-hant/aspose.slides/islide). |
| [`author`](/slides/python-net/zh-hant/aspose.slides/comment/author/) | 取得註解的作者。<br/>            唯讀 [`ICommentAuthor`](/slides/python-net/zh-hant/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/zh-hant/aspose.slides/comment/position/) | 取得或設定註解在投影片上的位置。<br/>            可讀寫 [`PointF`](/slides/python-net/zh-hant/aspose.slides/pointf). |
| [`parent_comment`](/slides/python-net/zh-hant/aspose.slides/comment/parent_comment/) | 取得或設定父註解。<br/>            可讀寫 [`IComment`](/slides/python-net/zh-hant/aspose.slides/icomment). |

## 方法

| Method | Description |
| :- | :- |
| [`remove(self)`](/slides/python-net/zh-hant/aspose.slides/comment/remove/#) | 從父集合中移除註解及其所有回覆。 |
