## Comment 類別

表示投影片上的 Comment。  
Comment 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`text`](/slides/python-net/zh-hant/aspose.slides/comment/text/) | 取得或設定投影片評論的純文字。<br/>            可讀寫 **str**. |
| [`created_time`](/slides/python-net/zh-hant/aspose.slides/comment/created_time/) | 取得或設定評論建立的時間。<br/>            將此屬性設定為 **System.DateTime** 表示未設定評論時間。<br/>            可讀寫 **System.DateTime**. |
| [`slide`](/slides/python-net/zh-hant/aspose.slides/comment/slide/) | 取得或設定評論的父投影片。<br/>            唯讀 [`ISlide`](/slides/python-net/zh-hant/aspose.slides/islide). |
| [`author`](/slides/python-net/zh-hant/aspose.slides/comment/author/) | 取得評論的作者。<br/>            唯讀 [`ICommentAuthor`](/slides/python-net/zh-hant/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/zh-hant/aspose.slides/comment/position/) | 取得或設定評論在投影片上的位置。<br/>            可讀寫 **aspose.slides.PointF**. |
| [`parent_comment`](/slides/python-net/zh-hant/aspose.slides/comment/parent_comment/) | 取得或設定父評論。<br/>            可讀寫 [`IComment`](/slides/python-net/zh-hant/aspose.slides/icomment). |

## 方法

| 方法 | 說明 |
| :- | :- |
| [`remove(self)`](/slides/python-net/zh-hant/aspose.slides/comment/remove/#) | 從父集合中移除評論及其所有回覆。 |
