## remove(self, item) {#iparagraph}
從 **System.Collections.Generic.ICollection`1** 中移除第一個出現的特定物件。

### 回傳值

如果成功從 **System.Collections.Generic.ICollection`1** 中移除 `item`，則返回 true；否則返回 false。如果在原始 **System.Collections.Generic.ICollection`1** 中找不到 `item`，此方法也會返回 false。

```python
def remove(self, item):
    ...
```

| 參數 | 類型 | 說明 |
| :- | :- | :- |
| item | [`IParagraph`](/slides/python-net/zh-hant/aspose.slides/iparagraph) | 要從 **System.Collections.Generic.ICollection`1** 中移除的物件。 |

### 例外

| 例外 | 說明 |
| :- | :- |
| **RuntimeError(Proxy error(NotSupportedException))** | **System.Collections.Generic.ICollection`1** 為唯讀。 |
