## ILineFormat 類別

表示線的格式。

ILineFormat 類型公開以下成員：

## 屬性

| Property | Description |
| :- | :- |
| [`is_format_not_defined`](/slides/python-net/zh-hant/aspose.slides/ilineformat/is_format_not_defined/) | 若線格式未定義（剛建立時的預設），則傳回 true。<br/>唯讀 **bool**. |
| [`fill_format`](/slides/python-net/zh-hant/aspose.slides/ilineformat/fill_format/) | 傳回線的填充格式。<br/>唯讀 [`ILineFillFormat`](/slides/python-net/zh-hant/aspose.slides/ilinefillformat). |
| [`sketch_format`](/slides/python-net/zh-hant/aspose.slides/ilineformat/sketch_format/) | 傳回線的草圖格式。<br/>唯讀 [`ISketchFormat`](/slides/python-net/zh-hant/aspose.slides/isketchformat). |
| [`width`](/slides/python-net/zh-hant/aspose.slides/ilineformat/width/) | 傳回或設定線的寬度。<br/>可讀寫 **float**. |
| [`dash_style`](/slides/python-net/zh-hant/aspose.slides/ilineformat/dash_style/) | 傳回或設定線的虛線樣式。<br/>可讀寫 [`LineDashStyle`](/slides/python-net/zh-hant/aspose.slides/linedashstyle). |
| [`custom_dash_pattern`](/slides/python-net/zh-hant/aspose.slides/ilineformat/custom_dash_pattern/) | 傳回或設定自訂虛線模式。<br/>可讀寫 **float**[]. |
| [`cap_style`](/slides/python-net/zh-hant/aspose.slides/ilineformat/cap_style/) | 傳回或設定線端點樣式。<br/>可讀寫 [`LineCapStyle`](/slides/python-net/zh-hant/aspose.slides/linecapstyle). |
| [`style`](/slides/python-net/zh-hant/aspose.slides/ilineformat/style/) | 傳回或設定線樣式。<br/>可讀寫 [`LineStyle`](/slides/python-net/zh-hant/aspose.slides/linestyle). |
| [`alignment`](/slides/python-net/zh-hant/aspose.slides/ilineformat/alignment/) | 傳回或設定線對齊方式。<br/>可讀寫 [`LineAlignment`](/slides/python-net/zh-hant/aspose.slides/linealignment). |
| [`join_style`](/slides/python-net/zh-hant/aspose.slides/ilineformat/join_style/) | 傳回或設定線的接合樣式。<br/>可讀寫 [`LineJoinStyle`](/slides/python-net/zh-hant/aspose.slides/linejoinstyle). |
| [`miter_limit`](/slides/python-net/zh-hant/aspose.slides/ilineformat/miter_limit/) | 傳回或設定線的斜接限制。<br/>可讀寫 **float**. |
| [`begin_arrowhead_style`](/slides/python-net/zh-hant/aspose.slides/ilineformat/begin_arrowhead_style/) | 傳回或設定線起點的箭頭樣式。<br/>可讀寫 [`LineArrowheadStyle`](/slides/python-net/zh-hant/aspose.slides/linearrowheadstyle). |
| [`end_arrowhead_style`](/slides/python-net/zh-hant/aspose.slides/ilineformat/end_arrowhead_style/) | 傳回或設定線終點的箭頭樣式。<br/>可讀寫 [`LineArrowheadStyle`](/slides/python-net/zh-hant/aspose.slides/linearrowheadstyle). |
| [`begin_arrowhead_width`](/slides/python-net/zh-hant/aspose.slides/ilineformat/begin_arrowhead_width/) | 傳回或設定線起點的箭頭寬度。<br/>可讀寫 [`LineArrowheadWidth`](/slides/python-net/zh-hant/aspose.slides/linearrowheadwidth). |
| [`end_arrowhead_width`](/slides/python-net/zh-hant/aspose.slides/ilineformat/end_arrowhead_width/) | 傳回或設定線終點的箭頭寬度。<br/>可讀寫 [`LineArrowheadWidth`](/slides/python-net/zh-hant/aspose.slides/linearrowheadwidth). |
| [`begin_arrowhead_length`](/slides/python-net/zh-hant/aspose.slides/ilineformat/begin_arrowhead_length/) | 傳回或設定線起點的箭頭長度。<br/>可讀寫 [`LineArrowheadLength`](/slides/python-net/zh-hant/aspose.slides/linearrowheadlength). |
| [`end_arrowhead_length`](/slides/python-net/zh-hant/aspose.slides/ilineformat/end_arrowhead_length/) | 傳回或設定線終點的箭頭長度。<br/>可讀寫 [`LineArrowheadLength`](/slides/python-net/zh-hant/aspose.slides/linearrowheadlength). |
