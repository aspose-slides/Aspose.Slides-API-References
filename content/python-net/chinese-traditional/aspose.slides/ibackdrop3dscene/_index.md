## IBackdrop3DScene 類別

定義一個平面，於該平面上會根據所套用的形狀應用發光與陰影等特效。

IBackdrop3DScene 類型公開以下成員：

## 屬性

| Property | Description |
| :- | :- |
| [`normal_vector`](/slides/python-net/zh-hant/aspose.slides/ibackdrop3dscene/normal_vector/) | 返回或設定法向量。更確切地說，此屬性定義一個垂直於背景平面面的向量。向量以包含 3 個 float 值的陣列表示，這些值定義 X、Y 與 Z 座標。<br/>            Read/write **float**[]. |
| [`anchor_point`](/slides/python-net/zh-hant/aspose.slides/ibackdrop3dscene/anchor_point/) | 返回或設定 3D 空間中的一個點。此點是錨定背景平面的空間點。<br/>            3D 點以包含 3 個 float 值的陣列表示，這些值定義 X、Y 與 Z 座標。<br/>            Read/write **float**[]. |
| [`up_vector`](/slides/python-net/zh-hant/aspose.slides/ibackdrop3dscene/up_vector/) | 返回或設定表示向上的向量。更確切地說，此屬性定義一個相對於背景平面面的向上向量。向量以包含 3 個 float 值的陣列表示，這些值定義 X、Y 與 Z 座標。<br/>            Read/write **float**[]. |
