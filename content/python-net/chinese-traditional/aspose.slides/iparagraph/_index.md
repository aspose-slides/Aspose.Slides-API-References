## IParagraph 類別

表示文字段落。

IParagraph 類型公開以下成員：

## 屬性

| Property | Description |
| :- | :- |
| [`portions`](/slides/python-net/zh-hant/aspose.slides/iparagraph/portions/) | 傳回文字片段的集合。<br/>            只讀 [`IPortionCollection`](/slides/python-net/zh-hant/aspose.slides/iportioncollection)。 |
| [`paragraph_format`](/slides/python-net/zh-hant/aspose.slides/iparagraph/paragraph_format/) | 傳回此段落的格式化物件。<br/>            只讀 [`IParagraphFormat`](/slides/python-net/zh-hant/aspose.slides/iparagraphformat)。 |
| [`text`](/slides/python-net/zh-hant/aspose.slides/iparagraph/text/) | 取得或設定段落的純文字。<br/>            可讀寫 **str**。 |
| [`end_paragraph_portion_format`](/slides/python-net/zh-hant/aspose.slides/iparagraph/end_paragraph_portion_format/) | 指定如果在最後一個之後插入另一個片段時要使用的片段屬性。 |
| [`slide`](/slides/python-net/zh-hant/aspose.slides/iparagraph/slide/) |  |
| [`presentation`](/slides/python-net/zh-hant/aspose.slides/iparagraph/presentation/) |  |

## 方法

| Method | Description |
| :- | :- |
| [`get_image`](/slides/python-net/zh-hant/aspose.slides/iparagraph/get_image/#) | 傳回段落的影像。 |
| [`get_image`](/slides/python-net/zh-hant/aspose.slides/iparagraph/get_image/#float-float) | 傳回具有指定比例的段落影像。 |
| [`join_portions_with_same_formatting`](/slides/python-net/zh-hant/aspose.slides/iparagraph/join_portions_with_same_formatting/#) | 合併具有相同格式的執行序列。 |
| [`get_rect`](/slides/python-net/zh-hant/aspose.slides/iparagraph/get_rect/#) | 取得限定段落的矩形座標。該矩形包含段落中所有的文字行，<br/>            包括空行。 |
| [`get_lines_count`](/slides/python-net/zh-hant/aspose.slides/iparagraph/get_lines_count/#) | 取得段落中的行數。 |
