## prefer_single_view 屬性
指定使用者是否偏好在完整視窗中顯示單一內容區域，而非具備三個內容區域的標準常規檢視。若啟用，應用程式可能會選擇將其中一個內容區域顯示於整個視窗。讀/寫 **bool**.

```python
@property
def prefer_single_view(self):
    ...

@prefer_single_view.setter
def prefer_single_view(self, value):
    ...
```
