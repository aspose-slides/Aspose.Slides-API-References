## INormalViewProperties 類別

表示常規檢視屬性。常規檢視包含三個內容區域：投影片本身、側邊內容區域，以及底部內容區域。

INormalViewProperties 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`show_outline_icons`](/slides/python-net/zh-hant/aspose.slides/inormalviewproperties/show_outline_icons/) | 指定應用程式在任何常規檢視模式的內容區域中顯示大綱內容時，是否顯示圖示。<br/>            可讀寫 **bool**. |
| [`snap_vertical_splitter`](/slides/python-net/zh-hant/aspose.slides/inormalviewproperties/snap_vertical_splitter/) | 指定當側邊區域足夠小時，垂直分隔條是否應自動縮至最小化狀態。<br/>            可讀寫 **bool**. |
| [`vertical_bar_state`](/slides/python-net/zh-hant/aspose.slides/inormalviewproperties/vertical_bar_state/) | 指定垂直分隔條應顯示的狀態。 <br/>            垂直分隔條將投影片與側邊內容區域分開. |
| [`horizontal_bar_state`](/slides/python-net/zh-hant/aspose.slides/inormalviewproperties/horizontal_bar_state/) | 指定水平分隔條應顯示的狀態。<br/>            水平分隔條將投影片與投影片下方的內容區域分開. |
| [`prefer_single_view`](/slides/python-net/zh-hant/aspose.slides/inormalviewproperties/prefer_single_view/) | 指定使用者是否偏好在全視窗的單一內容區域中顯示，而非具有三個內容區域的標準常規檢視。如果啟用，應用程式可能會選擇在整個視窗中顯示其中一個內容區域。<br/>            可讀寫 **bool**. |
| [`restored_left`](/slides/python-net/zh-hant/aspose.slides/inormalviewproperties/restored_left/) | 此元素指定常規檢視中側邊內容區域的大小，當該區域為可變的還原大小（既非最小化也非最大化）時。<br/>            唯讀 [`INormalViewRestoredProperties`](/slides/python-net/zh-hant/aspose.slides/inormalviewrestoredproperties). |
| [`restored_top`](/slides/python-net/zh-hant/aspose.slides/inormalviewproperties/restored_top/) | 此元素指定常規檢視中上方投影片區域的大小，當該區域為可變的還原大小（既非最小化也非最大化）時。<br/>            唯讀 [`INormalViewRestoredProperties`](/slides/python-net/zh-hant/aspose.slides/inormalviewrestoredproperties). |
