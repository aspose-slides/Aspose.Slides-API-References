## BuildVersionInfo 類別

包含有關 Aspose.Slides 版本的資訊。

BuildVersionInfo 類型會公開以下成員：

## 屬性

| Property | 說明 |
| :- | :- |
| [`ASSEMBLY_VERSION`](/slides/python-net/zh-hant/aspose.slides/buildversioninfo/assembly_version/) | Aspose.Slides 程式集的版本。 |
| [`FILE_VERSION`](/slides/python-net/zh-hant/aspose.slides/buildversioninfo/file_version/) | 程式集檔案的版本。 |
| [`PRODUCT`](/slides/python-net/zh-hant/aspose.slides/buildversioninfo/product/) | Aspose.Slides 的產品名稱。 |
| [`PRODUCT_MAJOR`](/slides/python-net/zh-hant/aspose.slides/buildversioninfo/product_major/) | 主要版本號碼。 |
| [`PRODUCT_MINOR`](/slides/python-net/zh-hant/aspose.slides/buildversioninfo/product_minor/) | 次要版本號碼。 |
| [`RELEASE_DATE`](/slides/python-net/zh-hant/aspose.slides/buildversioninfo/release_date/) | 程式集的發佈日期。 |
