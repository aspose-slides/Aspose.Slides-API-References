## FillType 列舉

指定各種視覺物件的內部填充類型。

FillType 類型公開以下成員：

## 欄位

| 欄位 | 描述 |
| :- | :- |
| NOT_DEFINED | 填充類型未定義。 |
| NO_FILL | 未套用填充。 |
| SOLID | 以純色填充。 |
| GRADIENT | 填充為漸層。 |
| PATTERN | 使用重複圖案填充物件。 |
| PICTURE | 使用單一圖片填充物件。 |
| GROUP | 視覺物件從群組繼承填充屬性。 |
