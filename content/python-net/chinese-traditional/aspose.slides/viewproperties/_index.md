## ViewProperties 類別

Presentation 全域檢視屬性。

ViewProperties 類型會公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`last_view`](/slides/python-net/zh-hant/aspose.slides/viewproperties/last_view/) | 指定最後一次儲存簡報文件時使用的檢視模式。<br/>            讀/寫 [`ViewType`](/slides/python-net/zh-hant/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/zh-hant/aspose.slides/viewproperties/show_comments/) | 指定是否應顯示投影片註解。<br/>            讀/寫 [`NullableBool`](/slides/python-net/zh-hant/aspose.slides/nullablebool). |
| [`normal_view_properties`](/slides/python-net/zh-hant/aspose.slides/viewproperties/normal_view_properties/) | 代表一般檢視屬性。一般檢視包含三個內容區域：投影片本身、一個側邊內容區域，以及一個底部內容區域。<br/>            唯讀 [`INormalViewProperties`](/slides/python-net/zh-hant/aspose.slides/inormalviewproperties). |
| [`slide_view_properties`](/slides/python-net/zh-hant/aspose.slides/viewproperties/slide_view_properties/) | 指定與投影片檢視模式相關的共用檢視屬性。<br/>            唯讀 [`ICommonSlideViewProperties`](/slides/python-net/zh-hant/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/zh-hant/aspose.slides/viewproperties/notes_view_properties/) | 指定與備註檢視模式相關的共用檢視屬性。<br/>            唯讀 [`ICommonSlideViewProperties`](/slides/python-net/zh-hant/aspose.slides/icommonslideviewproperties). |
| [`grid_spacing`](/slides/python-net/zh-hant/aspose.slides/viewproperties/grid_spacing/) | 取得或設定用於簡報文件底層格線的間距（以點為單位）。<br/>            讀/寫 **float**. |
