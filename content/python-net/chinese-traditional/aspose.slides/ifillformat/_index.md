## IFillFormat 類別

表示填充格式選項。

IFillFormat 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`fill_type`](/slides/python-net/zh-hant/aspose.slides/ifillformat/fill_type/) | 取得或設定填充類型。<br/>            可讀寫 [`FillType`](/slides/python-net/zh-hant/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/zh-hant/aspose.slides/ifillformat/solid_fill_color/) | 取得填充顏色。<br/>            只讀 [`IColorFormat`](/slides/python-net/zh-hant/aspose.slides/icolorformat). |
| [`gradient_format`](/slides/python-net/zh-hant/aspose.slides/ifillformat/gradient_format/) | 取得漸層填充格式。<br/>            只讀 [`IGradientFormat`](/slides/python-net/zh-hant/aspose.slides/igradientformat). |
| [`pattern_format`](/slides/python-net/zh-hant/aspose.slides/ifillformat/pattern_format/) | 取得圖案填充格式。<br/>            只讀 [`IPatternFormat`](/slides/python-net/zh-hant/aspose.slides/ipatternformat). |
| [`picture_fill_format`](/slides/python-net/zh-hant/aspose.slides/ifillformat/picture_fill_format/) | 取得圖片填充格式。<br/>            只讀 [`IPictureFillFormat`](/slides/python-net/zh-hant/aspose.slides/ipicturefillformat). |
| [`rotate_with_shape`](/slides/python-net/zh-hant/aspose.slides/ifillformat/rotate_with_shape/) | 判斷填充是否隨形狀旋轉。<br/>            可讀寫 [`NullableBool`](/slides/python-net/zh-hant/aspose.slides/nullablebool). |
