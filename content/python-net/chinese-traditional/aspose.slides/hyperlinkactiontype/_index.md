## HyperlinkActionType 列舉

表示一種超連結動作類型。

HyperlinkActionType 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| UNKNOWN | 未辨識的動作類型。 |
| NO_ACTION | 無動作。 |
| HYPERLINK | 一般超連結。 |
| JUMP_FIRST_SLIDE | 跳至簡報的第一張投影片。 |
| JUMP_PREVIOUS_SLIDE | 跳至上一張投影片。 |
| JUMP_NEXT_SLIDE | 跳至下一張投影片。 |
| JUMP_LAST_SLIDE | 跳至簡報的最後一張投影片。 |
| JUMP_END_SHOW | 跳至投影片放映的結尾。 |
| JUMP_LAST_VIEWED_SLIDE | 跳至最後檢視的投影片。 |
| JUMP_SPECIFIC_SLIDE | 跳至由 [`IHyperlink.target_slide`](/slides/python-net/zh-hant/aspose.slides/ihyperlink/target_slide) 屬性參照的特定投影片。 |
| START_CUSTOM_SLIDE_SHOW | 開始自訂投影片放映。 |
| OPEN_FILE | 開啟參照的檔案。 |
| OPEN_PRESENTATION | 開啟參照的簡報。 |
| START_STOP_MEDIA | 開始/停止播放媒體檔案。 |
| START_MACRO | 開始執行巨集腳本。 |
| START_PROGRAM | 啟動程式。 |
