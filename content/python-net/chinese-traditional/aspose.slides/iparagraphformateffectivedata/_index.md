## IParagraphFormatEffectiveData 類別

不可變的物件，包含有效的段落格式屬性。

IParagraphFormatEffectiveData 類型公開以下成員：

## 屬性

| Property | Description |
| :- | :- |
| [`bullet`](/slides/python-net/zh-hant/aspose.slides/iparagraphformateffectivedata/bullet/) | 傳回段落的項目符號格式。<br/>            唯讀 [`IBulletFormatEffectiveData`](/slides/python-net/zh-hant/aspose.slides/ibulletformateffectivedata)。 |
| [`depth`](/slides/python-net/zh-hant/aspose.slides/iparagraphformateffectivedata/depth/) | 傳回段落的深度。<br/>            唯讀 **int**。 |
| [`alignment`](/slides/python-net/zh-hant/aspose.slides/iparagraphformateffectivedata/alignment/) | 傳回段落中的文字對齊方式。<br/>            唯讀 [`TextAlignment`](/slides/python-net/zh-hant/aspose.slides/textalignment)。 |
| [`space_within`](/slides/python-net/zh-hant/aspose.slides/iparagraphformateffectivedata/space_within/) | 傳回段落中基線之間的間距。<br/>            唯讀 **float**。 |
| [`space_before`](/slides/python-net/zh-hant/aspose.slides/iparagraphformateffectivedata/space_before/) | 傳回段落第一行之前的間距。<br/>            唯讀 **float**。 |
| [`space_after`](/slides/python-net/zh-hant/aspose.slides/iparagraphformateffectivedata/space_after/) | 傳回段落最後一行之後的間距。<br/>            唯讀 **float**。 |
| [`east_asian_line_break`](/slides/python-net/zh-hant/aspose.slides/iparagraphformateffectivedata/east_asian_line_break/) | 判斷段落是否使用東亞斷行。<br/>            唯讀 **bool**。 |
| [`right_to_left`](/slides/python-net/zh-hant/aspose.slides/iparagraphformateffectivedata/right_to_left/) | 判斷段落是否使用從右至左書寫。<br/>            唯讀 **bool**。 |
| [`latin_line_break`](/slides/python-net/zh-hant/aspose.slides/iparagraphformateffectivedata/latin_line_break/) | 判斷段落是否使用拉丁斷行。<br/>            唯讀 **bool**。 |
| [`hanging_punctuation`](/slides/python-net/zh-hant/aspose.slides/iparagraphformateffectivedata/hanging_punctuation/) | 判斷段落是否使用懸掛標點。<br/>            唯讀 **bool**。 |
| [`margin_left`](/slides/python-net/zh-hant/aspose.slides/iparagraphformateffectivedata/margin_left/) | 傳回段落的左邊距。<br/>            唯讀 **float**。 |
| [`margin_right`](/slides/python-net/zh-hant/aspose.slides/iparagraphformateffectivedata/margin_right/) | 傳回段落的右邊距。<br/>            唯讀 **float**。 |
| [`indent`](/slides/python-net/zh-hant/aspose.slides/iparagraphformateffectivedata/indent/) | 傳回段落的首行縮排/懸掛縮排。懸掛縮排可使用負值定義。<br/>            唯讀 **float**。 |
| [`default_tab_size`](/slides/python-net/zh-hant/aspose.slides/iparagraphformateffectivedata/default_tab_size/) | 傳回預設的定位大小。<br/>            唯讀 **float**。 |
| [`tabs`](/slides/python-net/zh-hant/aspose.slides/iparagraphformateffectivedata/tabs/) | 傳回段落的定位。<br/>            唯讀 [`ITabEffectiveData`](/slides/python-net/zh-hant/aspose.slides/itabeffectivedata)[]。 |
| [`font_alignment`](/slides/python-net/zh-hant/aspose.slides/iparagraphformateffectivedata/font_alignment/) | 傳回段落的字型對齊方式。<br/>            唯讀 [`FontAlignment`](/slides/python-net/zh-hant/aspose.slides/fontalignment)。 |
| [`default_portion_format`](/slides/python-net/zh-hant/aspose.slides/iparagraphformateffectivedata/default_portion_format/) | 傳回段落的預設部份格式。<br/>            唯讀 [`IPortionFormatEffectiveData`](/slides/python-net/zh-hant/aspose.slides/iportionformateffectivedata)。 |

此介面與 [`IParagraphFormat`](/slides/python-net/zh-hant/aspose.slides/iparagraphformat) 介面一起使用，以回傳套用繼承後的有效格式值。
