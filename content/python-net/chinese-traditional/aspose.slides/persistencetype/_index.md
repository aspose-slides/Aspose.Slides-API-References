## PersistenceType 列舉

指定用於儲存 ActiveX 控制項屬性的方法。

PersistenceType 類型公開以下成員：

## 欄位

| 欄位 | 描述 |
| :- | :- |
| NOT_DEFINED | 未指定持久性 ID。 |
| PERSIST_PROPERTY_BAG | 指定使用 property-bag-based 持久性來保存 ActiveX 控制項。<br/>             property-bag-based 持久性透過名稱<br/>             與值配對的集合來儲存 ActiveX 控制項的資料。 |
| PERSIST_STREAM | 指定使用 stream-based 持久性來保存 ActiveX 控制項<br/>             此方式不支援將 ActiveX 控制項初始化為預設狀態。 |
| PERSIST_STREAM_INIT | 指定使用 stream-based 持久性來保存 ActiveX 控制項<br/>             此方式支援將 ActiveX 控制項初始化為預設狀態。 |
| PERSIST_STORAGE | 指定使用 storage-based 持久性來保存 ActiveX 控制項。 |
