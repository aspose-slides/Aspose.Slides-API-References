## BlackWhiteMode 列舉

決定彩色形狀應如何轉換為黑白。

BlackWhiteMode 類型會公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| NOT_DEFINED | 此屬性尚未設定 |
| COLOR | 物件以正常著色方式呈現 |
| AUTOMATIC | 物件以自動著色方式呈現 |
| GRAY | 物件以灰色著色方式呈現 |
| LIGHT_GRAY | 物件以淡灰色著色方式呈現 |
| INVERSE_GRAY | 物件以反轉灰色著色方式呈現 |
| GRAY_WHITE | 物件以灰白色著色方式呈現 |
| BLACK_GRAY | 物件以黑灰色著色方式呈現 |
| BLACK_WHITE | 物件以黑白色著色方式呈現 |
| BLACK | 物件僅以黑色著色呈現 |
| WHITE | 物件以白色著色方式呈現 |
| HIDDEN | 物件不會呈現 |
