## ICaptions 類別

表示 WebVTT 閉合字幕。

ICaptions 類型公開以下成員：

## 屬性

| Property | Description |
| :- | :- |
| [`caption_id`](/slides/python-net/zh-hant/aspose.slides/icaptions/caption_id/) | 返回閉合字幕的全域唯一識別碼 (GUID)。<br/>            只讀 **System.Guid**. |
| [`label`](/slides/python-net/zh-hant/aspose.slides/icaptions/label/) | 返回或設定閉合字幕的標籤。<br/>            可讀寫 **str**. |
| [`binary_data`](/slides/python-net/zh-hant/aspose.slides/icaptions/binary_data/) | 返回閉合字幕的二進位資料。<br/>            只讀 **int**[]. |
| [`data_as_string`](/slides/python-net/zh-hant/aspose.slides/icaptions/data_as_string/) | 返回以 UTF-8 編碼的閉合字幕字串<br/>            只讀 **str**. |
