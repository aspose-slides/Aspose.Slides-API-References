## Point 類別

表示一組有序的整數 x 與 y 座標，用於定義二維平面上的點。相容於 .NET `System.Drawing.Point`。

Point 類別公開以下成員：

## 建構式

| 建構式 | 說明 |
| :- | :- |
| [`__init__(self, x=0, y=0)`](/slides/python-net/zh-hant/aspose.slides/point/__init__/#int-int) | 建立具有指定座標的點。浮點值會被截斷為整數。 |

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`x`](/slides/python-net/zh-hant/aspose.slides/point/x/) | 取得或設定此點的 x 座標。<br/>            讀寫 **int**。 |
| [`y`](/slides/python-net/zh-hant/aspose.slides/point/y/) | 取得或設定此點的 y 座標。<br/>            讀寫 **int**。 |


### 備註

點可使用 `==` 依座標比較，且可作為字典鍵或集合成員使用。
