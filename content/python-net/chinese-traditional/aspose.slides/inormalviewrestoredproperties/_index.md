## INormalViewRestoredProperties 類別

指定普通檢視中投影片區域的大小（（寬度在 restoredTop 為子項時， 高度在
            restoredLeft 為子項時）位於普通檢視中，當區域具有可變的還原大小（既未最小化也未最大化））。

INormalViewRestoredProperties 類型公開以下成員：

## 屬性
| Property | Description |
| :- | :- |
| [`dimension_size`](/slides/python-net/zh-hant/aspose.slides/inormalviewrestoredproperties/dimension_size/) | 指定投影片區域的大小（當為 RestoredTop 的子項時為寬度，當為 RestoredLeft 的子項時為高度）。<br/>            讀寫 **float**。<br/>            當值小於 0 或大於 100 時拋出例外。 |
| [`auto_adjust`](/slides/python-net/zh-hant/aspose.slides/inormalviewrestoredproperties/auto_adjust/) | 指定在調整包含視圖的應用程式視窗大小時，側邊內容區域的大小是否應該補償新的尺寸。<br/>            讀寫 **bool**。 |
