## 框架屬性
返回或設定形狀框架的屬性。
            讀/寫 [`IShapeFrame`](/slides/python-net/zh-hant/aspose.slides/ishapeframe).

### 備註

返回的 IShapeFrame 實例的每個屬性值均不是 
            未定義（不是 NaN 或 NotDefined）。
            指定的 IShapeFrame 實例的每個屬性值必須不是 
            未定義（必須不是 NaN 或 NotDefined）。
            您可以為 RawFrame 實例的屬性設定未定義值。

@property
def frame(self):
    ...

@frame.setter
def frame(self, value):
    ...
