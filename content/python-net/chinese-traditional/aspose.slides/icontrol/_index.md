## IControl 類別

表示一個 ActiveX 控制項。

IControl 類型公開以下成員：

## 屬性

| Property | Description |
| :- | :- |
| [`name`](/slides/python-net/zh-hant/aspose.slides/icontrol/name/) | 傳回此控制項的名稱。<br/>            讀寫 **str**。 |
| [`class_id`](/slides/python-net/zh-hant/aspose.slides/icontrol/class_id/) | 取得此控制項的 class id。<br/>            唯讀 **System.Guid**。 |
| [`substitute_picture_format`](/slides/python-net/zh-hant/aspose.slides/icontrol/substitute_picture_format/) | 傳回 ControlEx 影像填充屬性物件。<br/>            唯讀 [`IPictureFillFormat`](/slides/python-net/zh-hant/aspose.slides/ipicturefillformat)。 |
| [`frame`](/slides/python-net/zh-hant/aspose.slides/icontrol/frame/) | 傳回或設定控制項的框架。<br/>            讀寫 [`IShapeFrame`](/slides/python-net/zh-hant/aspose.slides/ishapeframe)。 |
| [`properties`](/slides/python-net/zh-hant/aspose.slides/icontrol/properties/) | 傳回 ActiveX 屬性集合。<br/>            唯讀 [`IControlPropertiesCollection`](/slides/python-net/zh-hant/aspose.slides/icontrolpropertiescollection)。 |
| [`persistence`](/slides/python-net/zh-hant/aspose.slides/icontrol/persistence/) | 取得用於儲存 ActiveX 控制項屬性的方式。<br/>            唯讀 [`PersistenceType`](/slides/python-net/zh-hant/aspose.slides/persistencetype)。 |
| [`active_x_control_binary`](/slides/python-net/zh-hant/aspose.slides/icontrol/active_x_control_binary/) | 指定當持續化方法為 PersistStream、PersistStreamInit 或 PersistStorage 時，ActiveX 控制項的持續性。 |
