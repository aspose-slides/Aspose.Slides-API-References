## SlideSizeType 列舉

| :- | :- |
| ON_SCREEN | 螢幕 4x3 |
| LETTER_PAPER | 信紙 |
| A4_PAPER | A4 |
| SLIDE_35MM | 投影片 35mm |
| OVERHEAD | 投影 |
| BANNER | 橫幅 |
| CUSTOM | 自訂大小 |
| LEDGER | Ledger 紙 |
| A3_PAPER | A3 |
| B4_ISO_PAPER | B4 ISO |
| B5_ISO_PAPER | B5 ISO |
| B4_JIS_PAPER | B4 JIS |
| B5_JIS_PAPER | B5 JIS |
| HAGAKI_CARD | 明信片 |
| ON_SCREEN_16X9 | 螢幕 16x9 |
| ON_SCREEN_16X10 | 螢幕 16x10 |
| WIDESCREEN | 寬螢幕 |
