## set_date_time_and_child_date_times_visibility(self, is_visible) {#bool}
變更主投影片日期時間佔位符以及所有子日期時間佔位符的可見性。  
子佔位符表示佔位符位於相依的版面配置投影片以及相依的投影片上。  
相依的版面配置投影片和投影片使用且依賴於主投影片。

```python
def set_date_time_and_child_date_times_visibility(self, is_visible):
    ...
```

| Parameter | Type | Description |
| :- | :- | :- |
| is_visible | **bool** | true - 使日期時間佔位符可見，否則 - 隱藏它們。 |
