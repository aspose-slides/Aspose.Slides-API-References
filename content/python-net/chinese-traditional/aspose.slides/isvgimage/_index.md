| 屬性 | 說明 |
| :- | :- |
| [`svg_content`](/slides/python-net/zh-hant/aspose.slides/isvgimage/svg_content/) | 返回 SVG 內容。<br/>            唯讀 **str**。 |
| [`svg_data`](/slides/python-net/zh-hant/aspose.slides/isvgimage/svg_data/) | 返回 SVG 資料。<br/>            唯讀 **int**[]。 |
