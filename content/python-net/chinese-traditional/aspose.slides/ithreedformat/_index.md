## IThreeDFormat 類別

表示 3-D 屬性。

IThreeDFormat 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`contour_width`](/slides/python-net/zh-hant/aspose.slides/ithreedformat/contour_width/) | 傳回或設定 3D 輪廓的寬度。<br/>            讀/寫 **float**. |
| [`extrusion_height`](/slides/python-net/zh-hant/aspose.slides/ithreedformat/extrusion_height/) | 傳回或設定 擠壓效果的高度。<br/>            讀/寫 **float**. |
| [`depth`](/slides/python-net/zh-hant/aspose.slides/ithreedformat/depth/) | 傳回或設定 3D 形狀的深度。<br/>            讀/寫 **float**. |
| [`bevel_top`](/slides/python-net/zh-hant/aspose.slides/ithreedformat/bevel_top/) | 傳回或設定 頂部 3D 斜角的類型。<br/>            唯讀 [`IShapeBevel`](/slides/python-net/zh-hant/aspose.slides/ishapebevel). |
| [`bevel_bottom`](/slides/python-net/zh-hant/aspose.slides/ithreedformat/bevel_bottom/) | 傳回或設定 底部 3D 斜角的類型。<br/>            唯讀 [`IShapeBevel`](/slides/python-net/zh-hant/aspose.slides/ishapebevel). |
| [`contour_color`](/slides/python-net/zh-hant/aspose.slides/ithreedformat/contour_color/) | 傳回或設定 輪廓的顏色。<br/>            唯讀 [`IColorFormat`](/slides/python-net/zh-hant/aspose.slides/icolorformat). |
| [`extrusion_color`](/slides/python-net/zh-hant/aspose.slides/ithreedformat/extrusion_color/) | 傳回或設定 擠壓的顏色。<br/>            唯讀 [`IColorFormat`](/slides/python-net/zh-hant/aspose.slides/icolorformat). |
| [`camera`](/slides/python-net/zh-hant/aspose.slides/ithreedformat/camera/) | 傳回或設定 相機的設定。<br/>            唯讀 [`ICamera`](/slides/python-net/zh-hant/aspose.slides/icamera). |
| [`light_rig`](/slides/python-net/zh-hant/aspose.slides/ithreedformat/light_rig/) | 傳回或設定 光源的類型。<br/>            唯讀 [`ILightRig`](/slides/python-net/zh-hant/aspose.slides/ilightrig). |
| [`material`](/slides/python-net/zh-hant/aspose.slides/ithreedformat/material/) | 傳回或設定 材料的類型。<br/>            讀/寫 [`MaterialPresetType`](/slides/python-net/zh-hant/aspose.slides/materialpresettype). |
