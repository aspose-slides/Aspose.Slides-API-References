## IGradientFormatEffectiveData 類別

不可變物件，包含實際的漸層填充屬性。

IGradientFormatEffectiveData 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`tile_flip`](/slides/python-net/zh-hant/aspose.slides/igradientformateffectivedata/tile_flip/) | 傳回漸層的翻轉模式。<br/>唯讀 [`TileFlip`](/slides/python-net/zh-hant/aspose.slides/tileflip)。 |
| [`gradient_direction`](/slides/python-net/zh-hant/aspose.slides/igradientformateffectivedata/gradient_direction/) | 傳回漸層的樣式。<br/>唯讀 [`GradientDirection`](/slides/python-net/zh-hant/aspose.slides/gradientdirection)。 |
| [`linear_gradient_angle`](/slides/python-net/zh-hant/aspose.slides/igradientformateffectivedata/linear_gradient_angle/) | 傳回漸層的角度。<br/>唯讀 **float**。 |
| [`linear_gradient_scaled`](/slides/python-net/zh-hant/aspose.slides/igradientformateffectivedata/linear_gradient_scaled/) | 判斷漸層是否已縮放。<br/>唯讀 **bool**。 |
| [`gradient_shape`](/slides/python-net/zh-hant/aspose.slides/igradientformateffectivedata/gradient_shape/) | 傳回漸層的形狀。<br/>唯讀 [`GradientShape`](/slides/python-net/zh-hant/aspose.slides/gradientshape)。 |
| [`gradient_stops`](/slides/python-net/zh-hant/aspose.slides/igradientformateffectivedata/gradient_stops/) | 傳回漸層停止點的集合。<br/>唯讀 [`IGradientStopCollectionEffectiveData`](/slides/python-net/zh-hant/aspose.slides/igradientstopcollectioneffectivedata)。 |


### 備註

此介面作為 [`IFillFormatEffectiveData`](/slides/python-net/zh-hant/aspose.slides/ifillformateffectivedata) 和 [`ILineFillFormatEffectiveData`](/slides/python-net/zh-hant/aspose.slides/ilinefillformateffectivedata) 的一部分使用。
