## SlideShowSettings 類別

表示簡報的投影片播放設定。

SlideShowSettings 類型公開以下成員：

## 屬性

| Property | Description |
| :- | :- |
| [`slide_show_type`](/slides/python-net/zh-hant/aspose.slides/slideshowsettings/slide_show_type/) | 取得或設定投影片播放類型。由以下 [`SlideShowSettings.slide_show_type`](/slides/python-net/zh-hant/aspose.slides/slideshowsettings/slide_show_type) 祖先表示：[`BrowsedAtKiosk`](/slides/python-net/zh-hant/aspose.slides/browsedatkiosk)、[`PresentedBySpeaker`](/slides/python-net/zh-hant/aspose.slides/presentedbyspeaker) 和 [`BrowsedByIndividual`](/slides/python-net/zh-hant/aspose.slides/browsedbyindividual) |
| [`loop`](/slides/python-net/zh-hant/aspose.slides/slideshowsettings/loop/) | 迴圈投影片播放 |
| [`show_narration`](/slides/python-net/zh-hant/aspose.slides/slideshowsettings/show_narration/) | 在投影片播放中顯示旁白 |
| [`show_animation`](/slides/python-net/zh-hant/aspose.slides/slideshowsettings/show_animation/) | 在投影片播放中顯示動畫 |
| [`pen_color`](/slides/python-net/zh-hant/aspose.slides/slideshowsettings/pen_color/) | 投影片播放的筆跡顏色 |
| [`slides`](/slides/python-net/zh-hant/aspose.slides/slideshowsettings/slides/) | 投影片範圍 |
| [`use_timings`](/zh-hant/slides/python-net/aspose.slides/slideshowsettings/use_timings/) | 在投影片播放中使用計時 |
| [`show_media_controls`](/slides/python-net/zh-hant/aspose.slides/slideshowsettings/show_media_controls/) | 顯示媒體控制項 |
