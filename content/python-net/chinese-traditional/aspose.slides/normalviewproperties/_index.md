## NormalViewProperties 類別

代表普通檢視屬性。普通檢視包含三個內容區域：投影片本身、一個側邊內容區域，以及底部內容區域。

NormalViewProperties 類型公開以下成員：

## 屬性

| Property | Description |
| :- | :- |
| [`show_outline_icons`](/slides/python-net/zh-hant/aspose.slides/normalviewproperties/show_outline_icons/) | 指定應用程式在普通檢視模式的任何<br/>            內容區域顯示大綱內容時是否顯示圖示。<br/>            讀/寫 **bool**. |
| [`snap_vertical_splitter`](/slides/python-net/zh-hant/aspose.slides/normalviewproperties/snap_vertical_splitter/) | 指定垂直分割器在側邊<br/>            區域足夠小時是否應該卡住至最小化狀態。<br/>            讀/寫 **bool**. |
| [`vertical_bar_state`](/slides/python-net/zh-hant/aspose.slides/normalviewproperties/vertical_bar_state/) | 指定垂直分割條顯示的狀態。 <br/>            垂直分割條將投影片與側邊內容區域分開. |
| [`horizontal_bar_state`](/slides/python-net/zh-hant/aspose.slides/normalviewproperties/horizontal_bar_state/) | 指定水平分割條顯示的狀態。<br/>            水平分割條將投影片與投影片下方的內容區域分開. |
| [`prefer_single_view`](/slides/python-net/zh-hant/aspose.slides/normalviewproperties/prefer_single_view/) | 指定使用者是否偏好在完整視窗中僅顯示單一內容區域，而非在<br/>            具有三個內容區域的標準普通檢視。若啟用，應用程式可能會選擇<br/>            讀/寫 **bool**. |
| [`restored_left`](/slides/python-net/zh-hant/aspose.slides/normalviewproperties/restored_left/) | 此元素指定普通檢視的側邊內容區域的尺寸，當該區域為可變的<br/>            還原大小（既未最小化也未最大化）。<br/>            唯讀 [`INormalViewRestoredProperties`](/slides/python-net/zh-hant/aspose.slides/inormalviewrestoredproperties). |
| [`restored_top`](/slides/python-net/zh-hant/aspose.slides/normalviewproperties/restored_top/) | 此元素指定普通檢視的上部投影片區域的尺寸，當該區域為可變的<br/>            還原大小（既未最小化也未最大化）。<br/>            唯讀 [`INormalViewRestoredProperties`](/slides/python-net/zh-hant/aspose.slides/inormalviewrestoredproperties). |
