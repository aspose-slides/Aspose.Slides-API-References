## ShapeStyle 類別

表示形狀的樣式參考。

ShapeStyle 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`line_color`](/slides/python-net/zh-hant/aspose.slides/shapestyle/line_color/) | 回傳形狀的輪廓顏色。<br/>            唯讀 [`IColorFormat`](/slides/python-net/zh-hant/aspose.slides/icolorformat)。 |
| [`line_style_index`](/slides/python-net/zh-hant/aspose.slides/shapestyle/line_style_index/) | 回傳或設定線條在樣式矩陣中的欄索引。<br/>            讀寫 **int**。 |
| [`fill_color`](/slides/python-net/zh-hant/aspose.slides/shapestyle/fill_color/) | 回傳形狀的填充顏色。<br/>            唯讀 [`IColorFormat`](/slides/python-net/zh-hant/aspose.slides/icolorformat)。 |
| [`fill_style_index`](/slides/python-net/zh-hant/aspose.slides/shapestyle/fill_style_index/) | 回傳或設定形狀在樣式矩陣中的填充欄索引。<br/>            0 表示無填充，<br/>            正值 - 主題填充樣式的索引，<br/>            負值 - 主題背景樣式的索引。<br/>            讀寫 **int**。 |
| [`effect_color`](/slides/python-net/zh-hant/aspose.slides/shapestyle/effect_color/) | 回傳形狀的效果顏色。<br/>            唯讀 [`IColorFormat`](/slides/python-net/zh-hant/aspose.slides/icolorformat)。 |
| [`effect_style_index`](/slides/python-net/zh-hant/aspose.slides/shapestyle/effect_style_index/) | 回傳或設定形狀在樣式矩陣中的效果欄索引。<br/>            讀寫 **int**。 |
| [`font_color`](/slides/python-net/zh-hant/aspose.slides/shapestyle/font_color/) | 回傳形狀的字型顏色。<br/>            唯讀 [`IColorFormat`](/slides/python-net/zh-hant/aspose.slides/icolorformat)。 |
| [`font_collection_index`](/slides/python-net/zh-hant/aspose.slides/shapestyle/font_collection_index/) | 回傳或設定形狀在字型集合中的字型索引。<br/>            讀寫 [`FontCollectionIndex`](/slides/python-net/zh-hant/aspose.slides/fontcollectionindex)。 |
