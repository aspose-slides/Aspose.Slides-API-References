## Row 類別

代表表格中的一列。

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`slide`](/slides/python-net/zh-hant/aspose.slides/row/slide/) | 傳回 CellCollection 的父投影片。<br/>            只讀 [`IBaseSlide`](/slides/python-net/zh-hant/aspose.slides/ibaseslide)。 |
| [`presentation`](/slides/python-net/zh-hant/aspose.slides/row/presentation/) | 傳回 CellCollection 的父簡報。<br/>            只讀 [`IPresentation`](/slides/python-net/zh-hant/aspose.slides/ipresentation)。 |
| [`height`](/slides/python-net/zh-hant/aspose.slides/row/height/) | 傳回列的高度。<br/>            只讀 **float**。 |
| [`minimal_height`](/slides/python-net/zh-hant/aspose.slides/row/minimal_height/) | 傳回或設定列的最小可能高度。<br/>            可讀寫 **float**。 |
| [`row_format`](/slides/python-net/zh-hant/aspose.slides/row/row_format/) | 傳回包含此列格式屬性的 RowFormat 物件。<br/>            只讀 [`IRowFormat`](/slides/python-net/zh-hant/aspose.slides/irowformat)。 |
