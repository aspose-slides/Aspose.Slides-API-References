## TextAlignment 列舉

表示不同的文字對齊樣式。

TextAlignment 類型公開以下成員：

## 欄位

| Field | 描述 |
| :- | :- |
| NOT_DEFINED | 預設對齊。 |
| LEFT | 左對齊。 |
| CENTER | 置中對齊。 |
| RIGHT | 右對齊。 |
| JUSTIFY | 兩端對齊。 |
| JUSTIFY_LOW | Kashida 低對齊。 |
| DISTRIBUTED | 分散對齊。 |
