## PPImageFormat 列舉

圖像格式。此列舉是 `System.Drawing.Imaging.ImageFormat` 類別的替代品。需要它以符合 COM 相容性。

PPImageFormat 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| BMP | 取得 bitmap (BMP) 圖像格式。 |
| EMF | 取得增強型中繼檔 (EMF) 圖像格式。 |
| EXIF | 取得可交換影像檔 (Exif) 格式。 |
| GIF | 取得圖形交換格式 (GIF) 圖像格式。 |
| ICON | 取得 Windows 圖示圖像格式。 |
| JPEG | 取得 Joint Photographic Experts Group (JPEG) 圖像格式。 |
| MEMORY_BMP | 取得記憶體中 bitmap 的格式。 |
| PNG | 取得 W3C 可攜式網路圖形 (PNG) 圖像格式。 |
| TIFF | 取得 Tagged Image File Format (TIFF) 圖像格式。 |
| WMF | 取得 Windows 中繼檔 (WMF) 圖像格式。 |
