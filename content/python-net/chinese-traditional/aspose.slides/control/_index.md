## Control 類別

表示一個 ActiveX 控制項。

Control 類型公開以下成員：

## 屬性

| Property | Description |
| :- | :- |
| [`persistence`](/slides/python-net/zh-hant/aspose.slides/control/persistence/) | 取得用於儲存 ActiveX 控制項屬性的方式。<br/>            只讀 [`PersistenceType`](/slides/python-net/zh-hant/aspose.slides/persistencetype). |
| [`name`](/slides/python-net/zh-hant/aspose.slides/control/name/) | 取得或設定此控制項的名稱。<br/>            可讀寫 **str**. |
| [`class_id`](/slides/python-net/zh-hant/aspose.slides/control/class_id/) | 取得此控制項的類別識別碼。<br/>            只讀 **System.Guid**. |
| [`substitute_picture_format`](/slides/python-net/zh-hant/aspose.slides/control/substitute_picture_format/) | 傳回 Control 圖像填充屬性物件。<br/>            只讀 [`IPictureFillFormat`](/slides/python-net/zh-hant/aspose.slides/ipicturefillformat). |
| [`frame`](/slides/python-net/zh-hant/aspose.slides/control/frame/) | 取得或設定控制項的框架。<br/>            可讀寫 [`IShapeFrame`](/slides/python-net/zh-hant/aspose.slides/ishapeframe). |
| [`properties`](/slides/python-net/zh-hant/aspose.slides/control/properties/) | 傳回 ActiveX 屬性的集合。<br/>            註記：Aspose.Slides 只支援基於 XML 的 ActiveX 屬性。如果屬性以二進位格式儲存，此屬性將傳回 None。<br/>            只讀 [`IControlPropertiesCollection`](/slides/python-net/zh-hant/aspose.slides/icontrolpropertiescollection). |
| [`active_x_control_binary`](/slides/python-net/zh-hant/aspose.slides/control/active_x_control_binary/) | 指定 ActiveX 控制項的持久性，當使用的持久化方法為 PersistStream、PersistStreamInit 或 PersistStorage 時。 |
| [`slide`](/slides/python-net/zh-hant/aspose.slides/control/slide/) |  |
| [`presentation`](/slides/python-net/zh-hant/aspose.slides/control/presentation/) |  |
