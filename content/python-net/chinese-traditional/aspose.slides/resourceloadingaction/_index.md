## ResourceLoadingAction 列舉

指定外部資源載入的模式。

ResourceLoadingAction 類型公開以下成員：

## 欄位

| 欄位 | 描述 |
| :- | :- |
| DEFAULT | Aspose.Slides 將如常載入外部資源。 |
| SKIP | Aspose.Slides 將跳過外部資源的載入。僅會為影像存儲沒有資料的連結。 |
| USER_PROVIDED | Aspose.Slides 將使用使用者提供的位元組陣列作為影像資料，透過 **Aspose.Slides.IResourceLoadingArgs.SetData(Syste**。 |
