## NumberedBulletStyle 列舉

表示編號項目的樣式。

NumberedBulletStyle 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| NOT_DEFINED | 未定義。 |
| BULLET_ALPHA_LC_PERIOD | 小寫字母加句點。範例：a., b., c., ... |
| BULLET_ALPHA_UC_PERIOD | 大寫字母加句點。範例：A., B., C., ... |
| BULLET_ARABIC_PAREN_RIGHT | 阿拉伯數字加右括號。範例：1), 2), 3), ... |
| BULLET_ARABIC_PERIOD | 阿拉伯數字加句點。範例：1., 2., 3., ... |
| BULLET_ROMAN_LC_PAREN_BOTH | 小寫羅馬數字加雙括號。範例：(i), (ii), (iii), ... |
| BULLET_ROMAN_LC_PAREN_RIGHT | 小寫羅馬數字加右括號。範例：i), ii), iii), ... |
| BULLET_ROMAN_LC_PERIOD | 小寫羅馬數字加句點。範例：i., ii., iii., ... |
| BULLET_ROMAN_UC_PERIOD | 大寫羅馬數字加句點。範例：I., II., III., ... |
| BULLET_ALPHA_LC_PAREN_BOTH | 小寫字母加雙括號。範例：(a), (b), (c), ... |
| BULLET_ALPHA_LC_PAREN_RIGHT | 小寫字母加右括號。範例：a), b), c), ... |
| BULLET_ALPHA_UC_PAREN_BOTH | 大寫字母加雙括號。範例：(A), (B), (C), ... |
| BULLET_ALPHA_UC_PAREN_RIGHT | 大寫字母加右括號。範例：A), B), C), ... |
| BULLET_ARABIC_PAREN_BOTH | 阿拉伯數字加雙括號。範例：(1), (2), (3), ... |
| BULLET_ARABIC_PLAIN | 阿拉伯數字。範例：1, 2, 3, ... |
| BULLET_ROMAN_UC_PAREN_BOTH | 大寫羅馬數字加雙括號。範例：(I), (II), (III), ... |
| BULLET_ROMAN_UC_PAREN_RIGHT | 大寫羅馬數字加右括號。範例：I), II), III), ... |
| BULLET_SIMP_CHIN_PLAIN | 簡體中文（無句點）。 |
| BULLET_SIMP_CHIN_PERIOD | 簡體中文（有句點）。 |
| BULLET_CIRCLE_NUM_DB_PLAIN | 雙位元組圓圈數字，適用於 0 到 10，11 起使用阿拉伯數字。 |
| BULLET_CIRCLE_NUM_WD_WHITE_PLAIN | 文字顏色數字，且以相同顏色的圓圈環繞（Wingdings 白色圓圈數字）。從 11 起使用阿拉伯數字。 |
| BULLET_CIRCLE_NUM_WD_BLACK_PLAIN | 陰影顏色數字，圓形背景使用普通文字顏色（Wingdings 黑色圓圈數字）。 |
| BULLET_TRAD_CHIN_PLAIN | 繁體中文（無句點）。 |
| BULLET_TRAD_CHIN_PERIOD | 繁體中文（有句點）。 |
| BULLET_ARABIC_ALPHA_DASH | 阿拉伯語字母加破折號。 |
| BULLET_ARABIC_ABJAD_DASH | 阿拉伯字母表（Abjad）加破折號。 |
| BULLET_HEBREW_ALPHA_DASH | 希伯來語字母加破折號。 |
| BULLET_KANJI_KOREAN_PLAIN | 日文/韓文數字（無句點）。 |
| BULLET_KANJI_KOREAN_PERIOD | 日文/韓文數字（有句點）。 |
| BULLET_ARABIC_DB_PLAIN | 雙位元組阿拉伯編號系統（無標點）。 |
| BULLET_ARABIC_DB_PERIOD | 雙位元組阿拉伯編號系統加雙位元組句點。 |
| BULLET_THAI_ALPHA_PERIOD | 泰文字母加句點。 |
| BULLET_THAI_ALPHA_PAREN_RIGHT | 泰文字母右括號。 |
| BULLET_THAI_ALPHA_PAREN_BOTH | 泰文字母雙括號。 |
| BULLET_THAI_NUM_PERIOD | 泰文數字加句點。 |
| BULLET_THAI_NUM_PAREN_RIGHT | 泰文數字右括號。 |
| BULLET_THAI_NUM_PAREN_BOTH | 泰文數字雙括號。 |
| BULLET_HINDI_ALPHA_PERIOD | 印地語字母（元音）加句點。 |
| BULLET_HINDI_NUM_PERIOD | 印地語數字加句點。 |
| BULLET_KANJI_SIMP_CHIN_DB_PERIOD | 漢字簡體中文雙位元組句點。 |
| BULLET_HINDI_NUM_PAREN_RIGHT | 印地語數字右括號。 |
| BULLET_HINDI_ALPHA_1_PERIOD | 印地語字母（輔音）加句點。 |
