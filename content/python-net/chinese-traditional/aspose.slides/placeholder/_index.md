## Placeholder 類別

表示投影片上的佔位符。

Placeholder 型別公開以下成員：

## 屬性

| 屬性 | 描述 |
| :- | :- |
| [`orientation`](/slides/python-net/zh-hant/aspose.slides/placeholder/orientation/) | 取得或設定佔位符的方向。<br/>            唯讀 [`Orientation`](/slides/python-net/zh-hant/aspose.slides/orientation). |
| [`size`](/slides/python-net/zh-hant/aspose.slides/placeholder/size/) | 取得或設定佔位符的大小。<br/>            唯讀 [`PlaceholderSize`](/slides/python-net/zh-hant/aspose.slides/placeholdersize). |
| [`type`](/slides/python-net/zh-hant/aspose.slides/placeholder/type/) | 取得或設定佔位符的類型。<br/>            唯讀 [`PlaceholderType`](/slides/python-net/zh-hant/aspose.slides/placeholdertype). |
| [`index`](/slides/python-net/zh-hant/aspose.slides/placeholder/index/) | 取得或設定佔位符的索引。<br/>            唯讀 **int**. |
