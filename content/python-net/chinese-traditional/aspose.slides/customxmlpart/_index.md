## CustomXmlPart 類別

表示自訂 xml 部分。

CustomXmlPart 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`xml_data`](/slides/python-net/zh-hant/aspose.slides/customxmlpart/xml_data/) | 取得或設定 xml 資料。<br/>            讀寫 **int**[]。<br/>            值為 `None`。值為空或 xml-data 無效。 |
| [`xml_as_string`](/slides/python-net/zh-hant/aspose.slides/customxmlpart/xml_as_string/) | 取得或設定 xml 資料為 UTF-8 字串。<br/>            讀寫 **str**。<br/>            值為 `None`。值為空或 xml-data 無效。 |
| [`item_id`](/slides/python-net/zh-hant/aspose.slides/customxmlpart/item_id/) | 指定全域唯一識別碼 (GUID)，用於唯一識別 Office Open XML 文件中的單一自訂 XML 部分。<br/>            唯讀 **System.Guid**。 |
| [`namespace_schemas`](/slides/python-net/zh-hant/aspose.slides/customxmlpart/namespace_schemas/) | 取得與自訂 XML 部分關聯的 XML 架構集合。<br/>            唯讀 **str**[]。 |

| :- | :- |
| [`remove(self)`](/slides/python-net/zh-hant/aspose.slides/customxmlpart/remove/#) | 從簡報中移除自訂 xml 部分。 |
