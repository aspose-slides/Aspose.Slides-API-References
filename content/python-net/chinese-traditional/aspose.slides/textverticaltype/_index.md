## TextVerticalType 列舉

## 欄位

| 欄位 | 描述 |
| :- | :- |
| NOT_DEFINED | 未定義。 |
| HORIZONTAL | 水平文字。 |
| VERTICAL | 垂直文字。 |
| VERTICAL270 | 垂直 270 度文字。 |
| WORD_ART_VERTICAL | WordArt 垂直文字。 |

| MONGOLIAN_VERTICAL | 蒙古垂直文字。 |
