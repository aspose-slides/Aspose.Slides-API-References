## IDigitalSignature 類別

已簽署檔案中的數位簽章。

IDigitalSignature 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`certificate`](/slides/python-net/zh-hant/aspose.slides/idigitalsignature/certificate/) | 用於簽署文件的憑證物件。<br/>            唯讀 **System.Security.Cryptography.X509Certificates.X509Certificate2**。 |
| [`is_valid`](/slides/python-net/zh-hant/aspose.slides/idigitalsignature/is_valid/) | 如果此數位簽章有效且文件未被竄改，則此值為 true。<br/>            唯讀 **bool**。 |
| [`sign_time`](/slides/python-net/zh-hant/aspose.slides/idigitalsignature/sign_time/) | 文件簽署的時間。<br/>            唯讀 **System.DateTime**。 |
| [`comments`](/slides/python-net/zh-hant/aspose.slides/idigitalsignature/comments/) | 簽章的目的。<br/>            可讀寫 **str**。 |
