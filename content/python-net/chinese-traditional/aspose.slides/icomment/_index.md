## IComment 類別

表示投影片上的註解。

IComment 類型公開以下成員：

## 屬性

| Property | Description |
| :- | :- |
| [`text`](/slides/python-net/zh-hant/aspose.slides/icomment/text/) | 取得或設定投影片註解的純文字。<br/>            可讀寫 **str**. |
| [`created_time`](/slides/python-net/zh-hant/aspose.slides/icomment/created_time/) | 取得或設定註解建立的時間。<br/>            設定此屬性為 **System.DateTime** 代表未設定註解時間。<br/>            可讀寫 **System.DateTime**. |
| [`slide`](/slides/python-net/zh-hant/aspose.slides/icomment/slide/) | 取得或設定註解的父投影片。<br/>            唯讀 [`ISlide`](/slides/python-net/zh-hant/aspose.slides/islide). |
| [`author`](/slides/python-net/zh-hant/aspose.slides/icomment/author/) | 取得註解的作者。<br/>            唯讀 [`ICommentAuthor`](/slides/python-net/zh-hant/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/zh-hant/aspose.slides/icomment/position/) | 取得或設定註解在投影片上的位置。<br/>            可讀寫 **aspose.slides.PointF**. |
| [`parent_comment`](/slides/python-net/zh-hant/aspose.slides/icomment/parent_comment/) | 取得或設定父註解。<br/>            可讀寫 [`IComment`](/slides/python-net/zh-hant/aspose.slides/icomment). |

## 方法

| Method | Description |
| :- | :- |
| [`remove(self)`](/slides/python-net/zh-hant/aspose.slides/icomment/remove/#) | 從父集合中移除註解及其所有回覆. |
