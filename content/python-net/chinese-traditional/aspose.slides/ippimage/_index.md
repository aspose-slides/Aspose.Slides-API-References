## IPPImage 類別

代表簡報中的影像。

IPPImage 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`binary_data`](/slides/python-net/zh-hant/aspose.slides/ippimage/binary_data/) | 傳回影像資料的副本。<br/>            唯讀 **int**[]. |
| [`image`](/slides/python-net/zh-hant/aspose.slides/ippimage/image/) | 傳回影像的副本。<br/>            唯讀 [`IPPImage.image`](/slides/python-net/zh-hant/aspose.slides/ippimage/image). |
| [`svg_image`](/slides/python-net/zh-hant/aspose.slides/ippimage/svg_image/) | 傳回或設定 ISvgImage 物件 [`ISvgImage`](/slides/python-net/zh-hant/aspose.slides/isvgimage) |
| [`content_type`](/slides/python-net/zh-hant/aspose.slides/ippimage/content_type/) | 傳回影像的 MIME 類型，使用 [`IPPImage.binary_data`](/slides/python-net/zh-hant/aspose.slides/ippimage/binary_data) 編碼。<br/>            唯讀 **str**. |
| [`width`](/slides/python-net/zh-hant/aspose.slides/ippimage/width/) | 傳回影像的寬度。<br/>            唯讀 **int**. |
| [`height`](/slides/python-net/zh-hant/aspose.slides/ippimage/height/) | 傳回影像的高度。<br/>            唯讀 **int**. |
| [`x`](/slides/python-net/zh-hant/aspose.slides/ippimage/x/) | 傳回影像的 X 偏移量。<br/>            唯讀 **int**. |
| [`y`](/slides/python-net/zh-hant/aspose.slides/ippimage/y/) | 傳回影像的 Y 偏移量。<br/>            唯讀 **int**. |
