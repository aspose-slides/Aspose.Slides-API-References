## PathFillModeType 列舉

指定路徑的填充方式

PathFillModeType 類型公開以下成員：

## 欄位

| Field | Description |
| :- | :- |
| NONE | 無路徑填充<br/>            此說明相應的路徑不應有填充。 |
| NORMAL | 正常路徑填充<br/>            此說明相應的路徑的填充應套用正常陰影的顏色。 |
| LIGHTEN | 變亮路徑填充<br/>            此說明相應的路徑的填充應套用淡色陰影的顏色。 |
| LIGHTEN_LESS | 稍微變亮路徑填充<br/>            此說明相應的路徑的填充應套用略微較亮的陰影顏色。 |
| DARKEN | 變暗路徑填充<br/>            此說明相應的路徑的填充應套用較暗的陰影顏色。 |
| DARKEN_LESS | 稍微變暗路徑填充<br/>            此說明相應的路徑的填充應套用稍暗的陰影顏色。 |
