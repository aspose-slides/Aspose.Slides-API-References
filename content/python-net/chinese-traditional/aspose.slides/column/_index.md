## Column 類別

表示表格中的欄位。

**繼承:**[`Column`](/slides/python-net/zh-hant/aspose.slides/column) → [`CellCollection`](/slides/python-net/zh-hant/aspose.slides/cellcollection)

Column 類型會公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`slide`](/slides/python-net/zh-hant/aspose.slides/column/slide/) | 傳回 CellCollection 的父投影片。<br/>            只讀 [`IBaseSlide`](/slides/python-net/zh-hant/aspose.slides/ibaseslide)。 |
| [`presentation`](/slides/python-net/zh-hant/aspose.slides/column/presentation/) | 傳回 CellCollection 的父簡報。<br/>            只讀 [`IPresentation`](/slides/python-net/zh-hant/aspose.slides/ipresentation)。 |
| [`width`](/slides/python-net/zh-hant/aspose.slides/column/width/) | 傳回或設定欄位的寬度。<br/>            可讀寫 **float**。 |
| [`column_format`](/slides/python-net/zh-hant/aspose.slides/column/column_format/) | 傳回包含此欄位格式屬性的 ColumnFormat 物件。<br/>            只讀 [`IColumnFormat`](/slides/python-net/zh-hant/aspose.slides/icolumnformat)。 |
