## IBulletFormatEffectiveData 類別

不可變的物件，包含有效段落項目符號格式屬性。

IBulletFormatEffectiveData 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`type`](/slides/python-net/zh-hant/aspose.slides/ibulletformateffectivedata/type/) | 傳回段落的項目符號類型。<br/>            唯讀 [`BulletType`](/slides/python-net/zh-hant/aspose.slides/bullettype)。 |
| [`char`](/slides/python-net/zh-hant/aspose.slides/ibulletformateffectivedata/char/) | 傳回段落的項目符號字元。<br/>            唯讀 **System.Char**。 |
| [`actual_bullet_value`](/slides/python-net/zh-hant/aspose.slides/ibulletformateffectivedata/actual_bullet_value/) | 傳回父段落的實際項目符號值。<br/>            唯讀 **str**。 |
| [`font`](/slides/python-net/zh-hant/aspose.slides/ibulletformateffectivedata/font/) | 傳回段落的項目符號字型。<br/>            唯讀 [`IFontData`](/slides/python-net/zh-hant/aspose.slides/ifontdata)。 |
| [`height`](/slides/python-net/zh-hant/aspose.slides/ibulletformateffectivedata/height/) | 傳回段落的項目符號高度。<br/>            唯讀 **float**。 |
| [`numbered_bullet_start_with`](/slides/python-net/zh-hant/aspose.slides/ibulletformateffectivedata/numbered_bullet_start_with/) | 傳回用於編號項目符號組的第一個數字。<br/>            唯讀 **int**。 |
| [`numbered_bullet_style`](/slides/python-net/zh-hant/aspose.slides/ibulletformateffectivedata/numbered_bullet_style/) | 傳回編號項目符號的樣式。<br/>            唯讀 [`NumberedBulletStyle`](/slides/python-net/zh-hant/aspose.slides/numberedbulletstyle)。 |
| [`is_bullet_hard_color`](/slides/python-net/zh-hant/aspose.slides/ibulletformateffectivedata/is_bullet_hard_color/) | 判斷項目符號是否擁有自己的顏色，或從段落的第一個部份繼承顏色。<br/>            若項目符號擁有自己的顏色則傳回 **true**，若從段落的第一個部份繼承顏色則傳回 **false**。<br/>            唯讀 **bool**。 |
| [`is_bullet_hard_font`](/slides/python-net/zh-hant/aspose.slides/ibulletformateffectivedata/is_bullet_hard_font/) | 判斷項目符號是否擁有自己的字型，或從段落的第一個部份繼承字型。<br/>            若項目符號擁有自己的字型則傳回 **true**，若從段落的第一個部份繼承字型則傳回 **true**。<br/>            唯讀 **bool**。 |
| [`picture`](/slides/python-net/zh-hant/aspose.slides/ibulletformateffectivedata/picture/) | 傳回段落中用作項目符號的圖片。<br/>            唯讀 [`IPictureEffectiveData`](/slides/python-net/zh-hant/aspose.slides/ipictureeffectivedata)。 |
| [`fill_format`](/slides/python-net/zh-hant/aspose.slides/ibulletformateffectivedata/fill_format/) | 傳回段落的項目符號填充格式。<br/>            唯讀 [`IFillFormatEffectiveData`](/slides/python-net/zh-hant/aspose.slides/ifillformateffectivedata)。 |
