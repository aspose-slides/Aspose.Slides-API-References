## SlideLayoutType 列舉

表示投影片佈局類型。

SlideLayoutType 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| CUSTOM | 自訂 |
| TITLE | 標題 |
| TEXT | 文字 |
| TWO_COLUMN_TEXT | 雙欄文字 |
| TABLE | 表格 |
| TEXT_AND_CHART | 文字與圖表 |
| CHART_AND_TEXT | 圖表與文字 |
| DIAGRAM | 圖解 |
| CHART | 圖表 |
| TEXT_AND_CLIP_ART | 文字與剪貼畫 |
| CLIP_ART_AND_TEXT | 剪貼畫與文字 |
| TITLE_ONLY | 僅標題 |
| BLANK | 空白 |
| TEXT_AND_OBJECT | 文字與物件 |
| OBJECT_AND_TEXT | 物件與文字 |
| OBJECT | 物件 |
| TITLE_AND_OBJECT | 標題與物件 |
| TEXT_AND_MEDIA | 文字與媒體 |
| MEDIA_AND_TEXT | 媒體與文字 |
| OBJECT_OVER_TEXT | 物件在文字上方 |
| TEXT_OVER_OBJECT | 文字在物件上方 |
| TEXT_AND_TWO_OBJECTS | 文字與兩個物件 |
| TWO_OBJECTS_AND_TEXT | 兩個物件與文字 |
| TWO_OBJECTS_OVER_TEXT | 兩個物件在文字上方 |
| FOUR_OBJECTS | 四個物件 |
| VERTICAL_TEXT | 垂直文字 |
| CLIP_ART_AND_VERTICAL_TEXT | 剪貼畫與垂直文字 |
| VERTICAL_TITLE_AND_TEXT | 垂直標題與文字 |
| VERTICAL_TITLE_AND_TEXT_OVER_CHART | 垂直標題與文字在圖表上方 |
| TWO_OBJECTS | 兩個物件 |
| OBJECT_AND_TWO_OBJECT | 物件與兩個物件 |
| TWO_OBJECTS_AND_OBJECT | 兩個物件與物件 |
| SECTION_HEADER | 章節標題 |
| TWO_TEXT_AND_TWO_OBJECTS | 兩段文字與兩個物件 |
| TITLE_OBJECT_AND_CAPTION | 標題、物件與說明文字 |
| PICTURE_AND_CAPTION | 圖片與說明文字 |
