## IPlaceholder 類別

表示投影片上的占位項。

IPlaceholder 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`orientation`](/slides/python-net/zh-hant/aspose.slides/iplaceholder/orientation/) | 取得占位項的方向。<br/>            唯讀 [`Orientation`](/slides/python-net/zh-hant/aspose.slides/orientation). |
| [`size`](/slides/python-net/zh-hant/aspose.slides/iplaceholder/size/) | 取得占位項的大小。<br/>            唯讀 [`PlaceholderSize`](/slides/python-net/zh-hant/aspose.slides/placeholdersize). |
| [`type`](/slides/python-net/zh-hant/aspose.slides/iplaceholder/type/) | 取得占位項的類型。<br/>            唯讀 [`PlaceholderType`](/slides/python-net/zh-hant/aspose.slides/placeholdertype). |
| [`index`](/slides/python-net/zh-hant/aspose.slides/iplaceholder/index/) | 取得占位項的索引。<br/>            唯讀 **int**. |
