## IHeadingPair 類別

表示文件的「Heading pair」屬性。 
            它指示文件部分的群組名稱以及群組中的部分數量。

IHeadingPair 型別公開以下成員：

## 屬性

| Property | Description |
| :- | :- |
| [`name`](/slides/python-net/zh-hant/aspose.slides/iheadingpair/name/) | 返回文件部分的群組名稱。<br/>            唯讀 **str**. |
| [`count`](/slides/python-net/zh-hant/aspose.slides/iheadingpair/count/) | 返回群組中部分的數量。<br/>            唯讀 **int**. |
