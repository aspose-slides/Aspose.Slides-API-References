## IDrawingGuide 類別

表示一個可調整的繪圖參考線。

IDrawingGuide 類型公開以下成員：

## 屬性

| 屬性 | 描述 |
| :- | :- |
| [`orientation`](/slides/python-net/zh-hant/aspose.slides/idrawingguide/orientation/) | Returns or sets orientation of the drawing guide.<br/>            可讀寫 [`Orientation`](/slides/python-net/zh-hant/aspose.slides/orientation). |
| [`position`](/slides/python-net/zh-hant/aspose.slides/idrawingguide/position/) | Returns or sets position of the drawing guide in points from the top, left corner of the slide.<br/>            可讀寫 **float**. |
| [`color`](/slides/python-net/zh-hant/aspose.slides/idrawingguide/color/) | Returns or sets color of the drawing guide.<br/>            可讀寫 **aspose.slides.Color**. |
