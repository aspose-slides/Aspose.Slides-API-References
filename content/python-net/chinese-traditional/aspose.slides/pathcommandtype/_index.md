## PathCommandType 列舉

表示圖形路徑指令

PathCommandType 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| CLOSE | 關閉幾何路徑 |
| MOVE_TO | 設定幾何路徑的下一個點位置 |
| LINE_TO | 將線段附加至幾何路徑 |
| ARC_TO | 將指定的弧線附加至幾何路徑。 |
| QUAD_BEZIER_TO | 將二次貝茲曲線附加至幾何路徑 |
| CUBIC_BEZIER_TO | 將三次貝茲曲線附加至幾何路徑 |
