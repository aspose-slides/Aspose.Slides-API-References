## EffectFormat 類別

表示形狀的效果屬性。

**繼承:**[`EffectFormat`](/slides/python-net/zh-hant/aspose.slides/effectformat) → [`PVIObject`](/slides/python-net/zh-hant/aspose.slides/pviobject)

EffectFormat 類型公開以下成員：

## 屬性

| Property | 說明 |
| :- | :- |
| [`is_no_effects`](/slides/python-net/zh-hant/aspose.slides/effectformat/is_no_effects/) | 如果所有效果均已停用，則傳回 true（剛建立時，預設的 EffectFormat 物件）。<br/>            唯讀 **bool**。 |
| [`blur_effect`](/slides/python-net/zh-hant/aspose.slides/effectformat/blur_effect/) | 模糊效果。<br/>            可讀寫 [`IBlur`](/slides/python-net/zh-hant/aspose.slides.effects/iblur)。 |
| [`fill_overlay_effect`](/slides/python-net/zh-hant/aspose.slides/effectformat/fill_overlay_effect/) | 填充覆蓋效果。<br/>            可讀寫 [`IFillOverlay`](/slides/python-net/zh-hant/aspose.slides.effects/ifilloverlay)。 |
| [`glow_effect`](/slides/python-net/zh-hant/aspose.slides/effectformat/glow_effect/) | 發光效果。<br/>            可讀寫 [`IGlow`](/slides/python-net/zh-hant/aspose.slides.effects/iglow)。 |
| [`inner_shadow_effect`](/slides/python-net/zh-hant/aspose.slides/effectformat/inner_shadow_effect/) | 內部陰影。<br/>            可讀寫 [`IInnerShadow`](/slides/python-net/zh-hant/aspose.slides.effects/iinnershadow)。 |
| [`outer_shadow_effect`](/slides/python-net/zh-hant/aspose.slides/effectformat/outer_shadow_effect/) | 外部陰影。<br/>            可讀寫 [`IOuterShadow`](/slides/python-net/zh-hant/aspose.slides.effects/ioutershadow)。 |
| [`preset_shadow_effect`](/slides/python-net/zh-hant/aspose.slides/effectformat/preset_shadow_effect/) | 預設陰影。<br/>            可讀寫 [`IPresetShadow`](/slides/python-net/zh-hant/aspose.slides.effects/ipresetshadow)。 |
| [`reflection_effect`](/slides/python-net/zh-hant/aspose.slides/effectformat/reflection_effect/) | 反射。 <br/>            可讀寫 [`IReflection`](/slides/python-net/zh-hant/aspose.slides.effects/ireflection)。 |
| [`soft_edge_effect`](/slides/python-net/zh-hant/aspose.slides/effectformat/soft_edge_effect/) | 柔和邊緣。<br/>            可讀寫 [`ISoftEdge`](/slides/python-net/zh-hant/aspose.slides.effects/isoftedge)。 |
| [`slide`](/slides/python-net/zh-hant/aspose.slides/effectformat/slide/) |  |
