## IShapeFrame 類別

表示形狀框架的屬性。

IShapeFrame 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`x`](/slides/python-net/zh-hant/aspose.slides/ishapeframe/x/) | 返回框架左上角的 X 坐標。<br/>            唯讀 **float**. |
| [`y`](/slides/python-net/zh-hant/aspose.slides/ishapeframe/y/) | 返回框架左上角的 Y 坐標。<br/>            唯讀 **float**. |
| [`width`](/slides/python-net/zh-hant/aspose.slides/ishapeframe/width/) | 返回框架的寬度。<br/>            唯讀 **float**. |
| [`height`](/slides/python-net/zh-hant/aspose.slides/ishapeframe/height/) | 返回框架的高度。<br/>            唯讀 **float**. |
| [`rotation`](/slides/python-net/zh-hant/aspose.slides/ishapeframe/rotation/) | 返回框架繞 Z 軸旋轉的角度（度）。<br/>            正值表示順時針旋轉；負值表示逆時針旋轉。<br/>            唯讀 **float**. |
| [`center_x`](/slides/python-net/zh-hant/aspose.slides/ishapeframe/center_x/) | 返回框架中心的 X 坐標。<br/>            唯讀 **float**. |
| [`center_y`](/slides/python-net/zh-hant/aspose.slides/ishapeframe/center_y/) | 返回框架中心的 Y 坐標。<br/>            唯讀 **float**. |
| [`flip_h`](/slides/python-net/zh-hant/aspose.slides/ishapeframe/flip_h/) | 判斷框架是否水平翻轉。<br/>            唯讀 [`NullableBool`](/slides/python-net/zh-hant/aspose.slides/nullablebool). |
| [`flip_v`](/slides/python-net/zh-hant/aspose.slides/ishapeframe/flip_v/) | 判斷框架是否垂直翻轉。<br/>            唯讀 [`NullableBool`](/slides/python-net/zh-hant/aspose.slides/nullablebool). |
| [`rectangle`](/slides/python-net/zh-hant/aspose.slides/ishapeframe/rectangle/) | 返回框架的座標。<br/>            唯讀 [`RectangleF`](/slides/python-net/zh-hant/aspose.slides/rectanglef). |
