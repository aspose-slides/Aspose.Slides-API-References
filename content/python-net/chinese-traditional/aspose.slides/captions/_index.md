## Captions 類別

表示 WebVTT 閉合字幕。

Captions 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`caption_id`](/slides/python-net/zh-hant/aspose.slides/captions/caption_id/) | 返回閉合字幕的全域唯一辨識碼 (GUID)。<br/>            唯讀 **System.Guid**. |
| [`label`](/slides/python-net/zh-hant/aspose.slides/captions/label/) | 返回或設定閉合字幕的標籤。<br/>            讀寫 **str**. |
| [`binary_data`](/slides/python-net/zh-hant/aspose.slides/captions/binary_data/) | 返回閉合字幕的二進位資料。<br/>            唯讀 **int**[]. |
| [`data_as_string`](/slides/python-net/zh-hant/aspose.slides/captions/data_as_string/) | 返回閉合字幕資料的 UTF-8 編碼字串<br/>            唯讀 **str**. |
