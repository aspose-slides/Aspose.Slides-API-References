## IGradientFormat 類別

表示漸層格式。

IGradientFormat 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`tile_flip`](/slides/python-net/zh-hant/aspose.slides/igradientformat/tile_flip/) | 返回或設定漸層的翻轉模式。<br/>            讀/寫 [`TileFlip`](/slides/python-net/zh-hant/aspose.slides/tileflip). |
| [`gradient_direction`](/slides/python-net/zh-hant/aspose.slides/igradientformat/gradient_direction/) | 返回或設定漸層的樣式。<br/>            讀/寫 [`GradientDirection`](/slides/python-net/zh-hant/aspose.slides/gradientdirection). |
| [`linear_gradient_angle`](/slides/python-net/zh-hant/aspose.slides/igradientformat/linear_gradient_angle/) | 返回或設定漸層的角度。<br/>            讀/寫 **float**. |
| [`linear_gradient_scaled`](/slides/python-net/zh-hant/aspose.slides/igradientformat/linear_gradient_scaled/) | 確定漸層是否已縮放。<br/>            讀/寫 [`NullableBool`](/slides/python-net/zh-hant/aspose.slides/nullablebool). |
| [`gradient_shape`](/slides/python-net/zh-hant/aspose.slides/igradientformat/gradient_shape/) | 返回或設定漸層的形狀。<br/>            讀/寫 [`GradientShape`](/slides/python-net/zh-hant/aspose.slides/gradientshape). |
| [`gradient_stops`](/slides/python-net/zh-hant/aspose.slides/igradientformat/gradient_stops/) | 返回漸層停止點的集合。<br/>            只讀 [`IGradientStopCollection`](/slides/python-net/zh-hant/aspose.slides/igradientstopcollection). |
