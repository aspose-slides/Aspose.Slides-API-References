## PictureFrameLock 類別

判斷在父 PictureFrame 上哪些操作被停用。

**繼承:**[`PictureFrameLock`](/slides/python-net/zh-hant/aspose.slides/pictureframelock) → [`BaseShapeLock`](/slides/python-net/zh-hant/aspose.slides/baseshapelock)

PictureFrameLock 類別公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`no_locks`](/slides/python-net/zh-hant/aspose.slides/pictureframelock/no_locks/) | 如果所有鎖定旗標均已停用，則傳回 true。<br/>            唯讀 **bool**。 |
| [`grouping_locked`](/slides/python-net/zh-hant/aspose.slides/pictureframelock/grouping_locked/) | 判斷是否禁止將此形狀加入群組。<br/>            可讀寫 **bool**。 |
| [`select_locked`](/slides/python-net/zh-hant/aspose.slides/pictureframelock/select_locked/) | 判斷是否禁止選取此形狀。<br/>            可讀寫 **bool**。 |
| [`rotation_locked`](/slides/python-net/zh-hant/aspose.slides/pictureframelock/rotation_locked/) | 判斷是否禁止更改此形狀的旋轉角度。<br/>            可讀寫 **bool**。 |
| [`aspect_ratio_locked`](/slides/python-net/zh-hant/aspose.slides/pictureframelock/aspect_ratio_locked/) | 判斷在調整大小時是否必須保持形狀的長寬比。<br/>            可讀寫 **bool**。 |
| [`position_locked`](/slides/python-net/zh-hant/aspose.slides/pictureframelock/position_locked/) | 判斷是否禁止移動此形狀。<br/>            可讀寫 **bool**。 |
| [`size_locked`](/slides/python-net/zh-hant/aspose.slides/pictureframelock/size_locked/) | 判斷是否禁止調整此形狀的大小。<br/>            可讀寫 **bool**。 |
| [`edit_points_locked`](/slides/python-net/zh-hant/aspose.slides/pictureframelock/edit_points_locked/) | 判斷是否禁止直接更改此形狀的輪廓。<br/>            可讀寫 **bool**。 |
| [`adjust_handles_locked`](/slides/python-net/zh-hant/aspose.slides/pictureframelock/adjust_handles_locked/) | 判斷是否禁止更改調整值。<br/>            可讀寫 **bool**。 |
| [`arrowheads_locked`](/slides/python-net/zh-hant/aspose.slides/pictureframelock/arrowheads_locked/) | 判斷是否禁止更改箭頭。<br/>            可讀寫 **bool**。 |
| [`shape_type_locked`](/slides/python-net/zh-hant/aspose.slides/pictureframelock/shape_type_locked/) | 判斷是否禁止更改形狀類型。<br/>            可讀寫 **bool**。 |
| [`crop_locked`](/slides/python-net/zh-hant/aspose.slides/pictureframelock/crop_locked/) | 判斷是否禁止影像裁剪。<br/>            可讀寫 **bool**。 |
