## DrawingGuide 類別

表示一個可調整的繪圖參考線。

| Property | Description |
| :- | :- |
| [`orientation`](/slides/python-net/zh-hant/aspose.slides/drawingguide/orientation/) | 返回或設定繪圖參考線的方向。<br/> 讀/寫 [`Orientation`](/slides/python-net/zh-hant/aspose.slides/orientation). |

| [`color`](/slides/python-net/zh-hant/aspose.slides/drawingguide/color/) | 返回或設定繪圖參考線的顏色。<br/> 讀/寫 [`Color`](/slides/python-net/zh-hant/aspose.slides/color). |
