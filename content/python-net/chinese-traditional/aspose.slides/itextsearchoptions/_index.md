## ITextSearchOptions 類別

表示可用於在 Presentation、Slide 或 TextFrame 中搜尋文字的選項。

ITextSearchOptions 類型公開以下成員：

## 屬性

| Property | Description |
| :- | :- |
| [`case_sensitive`](/slides/python-net/zh-hant/aspose.slides/itextsearchoptions/case_sensitive/) | 設定為 true 以使用區分大小寫的搜尋，否則設定為 false。<br/>            讀/寫 **bool**。 |
| [`whole_words_only`](/slides/python-net/zh-hant/aspose.slides/itextsearchoptions/whole_words_only/) | 設定為 true 僅匹配完整單字，否則設定為 false。<br/>            讀/寫 **bool**。 |
| [`include_notes`](/slides/python-net/zh-hant/aspose.slides/itextsearchoptions/include_notes/) | 設定 `true` 以在執行文字搜尋、取代或突顯操作時，包含投影片備註中的文字。<br/>            預設值為 `false`。 |
