## IShapeStyle class

表示形狀樣式的參考。

IShapeStyle 類型會公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`line_color`](/slides/python-net/zh-hant/aspose.slides/ishapestyle/line_color/) | 傳回形狀的輪廓顏色。<br/>            唯讀 [`IColorFormat`](/slides/python-net/zh-hant/aspose.slides/icolorformat)。 |
| [`line_style_index`](/slides/python-net/zh-hant/aspose.slides/ishapestyle/line_style_index/) | 傳回或設定樣式矩陣中線條的欄位索引。<br/>            讀寫 **int**。 |
| [`fill_color`](/slides/python-net/zh-hant/aspose.slides/ishapestyle/fill_color/) | 傳回形狀的填充顏色。<br/>            唯讀 [`IColorFormat`](/slides/python-net/zh-hant/aspose.slides/icolorformat)。 |
| [`fill_style_index`](/slides/python-net/zh-hant/aspose.slides/ishapestyle/fill_style_index/) | 傳回或設定樣式矩陣中形狀的填充欄位索引。<br/>            0 代表無填充，<br/>            正值 - 主題填充樣式的索引，<br/>            負值 - 主題背景樣式的索引。<br/>            讀寫 **int**。 |
| [`effect_color`](/slides/python-net/zh-hant/aspose.slides/ishapestyle/effect_color/) | 傳回形狀的特效顏色。<br/>            唯讀 [`IColorFormat`](/slides/python-net/zh-hant/aspose.slides/icolorformat)。 |
| [`effect_style_index`](/slides/python-net/zh-hant/aspose.slides/ishapestyle/effect_style_index/) | 傳回或設定樣式矩陣中形狀的特效欄位索引。<br/>            讀寫 **int**。 |
| [`font_color`](/slides/python-net/zh-hant/aspose.slides/ishapestyle/font_color/) | 傳回形狀的字型顏色。<br/>            唯讀 [`IColorFormat`](/slides/python-net/zh-hant/aspose.slides/icolorformat)。 |
| [`font_collection_index`](/slides/python-net/zh-hant/aspose.slides/ishapestyle/font_collection_index/) | 傳回或設定字型集合中形狀的字型索引。<br/>            讀寫 [`FontCollectionIndex`](/slides/python-net/zh-hant/aspose.slides/fontcollectionindex)。 |
