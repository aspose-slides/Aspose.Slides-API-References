## AutoShapeLock 類別

決定在父 AutoshapeEx 上哪些操作被停用。

**繼承:**[`AutoShapeLock`](/slides/python-net/zh-hant/aspose.slides/autoshapelock) → [`BaseShapeLock`](/slides/python-net/zh-hant/aspose.slides/baseshapelock)

AutoShapeLock 類型會公開以下成員：

## 屬性

| Property | Description |
| :- | :- |
| [`no_locks`](/slides/python-net/zh-hant/aspose.slides/autoshapelock/no_locks/) | 如果所有鎖定旗標皆已停用，則回傳 true。<br/>            唯讀 **bool**. |
| [`grouping_locked`](/slides/python-net/zh-hant/aspose.slides/autoshapelock/grouping_locked/) | 判斷是否禁止將此圖形加入群組。<br/>            讀寫 **bool**. |
| [`select_locked`](/slides/python-net/zh-hant/aspose.slides/autoshapelock/select_locked/) | 判斷是否禁止選取此圖形。<br/>            讀寫 **bool**. |
| [`rotate_locked`](/slides/python-net/zh-hant/aspose.slides/autoshapelock/rotate_locked/) | 判斷是否禁止變更此圖形的旋轉角度。<br/>            讀寫 **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/zh-hant/aspose.slides/autoshapelock/aspect_ratio_locked/) | 判斷在調整大小時是否必須保持長寬比例。<br/>            讀寫 **bool**. |
| [`position_locked`](/slides/python-net/zh-hant/aspose.slides/autoshapelock/position_locked/) | 判斷是否禁止移動此圖形。<br/>            讀寫 **bool**. |
| [`size_locked`](/slides/python-net/zh-hant/aspose.slides/autoshapelock/size_locked/) | 判斷是否禁止調整此圖形的大小。<br/>            讀寫 **bool**. |
| [`edit_points_locked`](/slides/python-net/zh-hant/aspose.slides/autoshapelock/edit_points_locked/) | 判斷是否禁止直接變更此圖形的輪廓。<br/>            讀寫 **bool**. |
| [`adjust_handles_locked`](/slides/python-net/zh-hant/aspose.slides/autoshapelock/adjust_handles_locked/) | 判斷是否禁止變更調整值。<br/>            讀寫 **bool**. |
| [`arrowheads_locked`](/slides/python-net/zh-hant/aspose.slides/autoshapelock/arrowheads_locked/) | 判斷是否禁止變更箭頭樣式。<br/>            讀寫 **bool**. |
| [`shape_type_locked`](/slides/python-net/zh-hant/aspose.slides/autoshapelock/shape_type_locked/) | 判斷是否禁止變更圖形類型。<br/>            讀寫 **bool**. |
| [`text_locked`](/slides/python-net/zh-hant/aspose.slides/autoshapelock/text_locked/) | 判斷是否禁止編輯文字。<br/>            讀寫 **bool**. |
