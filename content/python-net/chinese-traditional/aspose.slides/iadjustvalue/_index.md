## IAdjustValue 類別

表示幾何形狀的調整值。這些值會影響形狀的外形。

IAdjustValue 類型公開以下成員：

## 屬性

| Property | 說明 |
| :- | :- |
| [`raw_value`](/slides/python-net/zh-hant/aspose.slides/iadjustvalue/raw_value/) | 返回或設定調整值「原樣」。<br/>            可讀寫 **int**. |
| [`angle_value`](/slides/python-net/zh-hant/aspose.slides/iadjustvalue/angle_value/) | 返回或設定值，並將其解讀為角度（單位：度）。<br/>            可讀寫 **float**. |
| [`name`](/slides/python-net/zh-hant/aspose.slides/iadjustvalue/name/) | 返回此調整值的名稱。<br/>            唯讀 **str**. |
| [`type`](/slides/python-net/zh-hant/aspose.slides/iadjustvalue/type/) | 返回形狀調整的類型。<br/>            唯讀 [`ShapeAdjustmentType`](/slides/python-net/zh-hant/aspose.slides/shapeadjustmenttype). |
