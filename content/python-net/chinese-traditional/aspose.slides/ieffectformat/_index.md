## IEffectFormat 類別

表示形狀的效果屬性。

IEffectFormat 類型公開以下成員：

## 屬性

| Property | Description |
| :- | :- |
| [`is_no_effects`](/slides/python-net/zh-hant/aspose.slides/ieffectformat/is_no_effects/) | 如果所有效果皆被停用則傳回 true（剛建立時的預設 EffectFormat 物件）。<br/>            唯讀 **bool**. |
| [`blur_effect`](/slides/python-net/zh-hant/aspose.slides/ieffectformat/blur_effect/) | 模糊效果。<br/>            讀寫 [`IBlur`](/slides/python-net/zh-hant/aspose.slides.effects/iblur). |
| [`fill_overlay_effect`](/slides/python-net/zh-hant/aspose.slides/ieffectformat/fill_overlay_effect/) | 填充覆蓋效果。<br/>            讀寫 [`IFillOverlay`](/slides/python-net/zh-hant/aspose.slides.effects/ifilloverlay). |
| [`glow_effect`](/slides/python-net/zh-hant/aspose.slides/ieffectformat/glow_effect/) | 發光效果。<br/>            讀寫 [`IGlow`](/slides/python-net/zh-hant/aspose.slides.effects/iglow). |
| [`inner_shadow_effect`](/slides/python-net/zh-hant/aspose.slides/ieffectformat/inner_shadow_effect/) | 內部陰影。<br/>            讀寫 [`IInnerShadow`](/slides/python-net/zh-hant/aspose.slides.effects/iinnershadow). |
| [`outer_shadow_effect`](/slides/python-net/zh-hant/aspose.slides/ieffectformat/outer_shadow_effect/) | 外部陰影。<br/>            讀寫 [`IOuterShadow`](/slides/python-net/zh-hant/aspose.slides.effects/ioutershadow). |
| [`preset_shadow_effect`](/slides/python-net/zh-hant/aspose.slides/ieffectformat/preset_shadow_effect/) | 預設陰影。<br/>            讀寫 [`IPresetShadow`](/slides/python-net/zh-hant/aspose.slides.effects/ipresetshadow). |
| [`reflection_effect`](/slides/python-net/zh-hant/aspose.slides/ieffectformat/reflection_effect/) | 反射。 <br/>            讀寫 [`IReflection`](/slides/python-net/zh-hant/aspose.slides.effects/ireflection). |
| [`soft_edge_effect`](/slides/python-net/zh-hant/aspose.slides/ieffectformat/soft_edge_effect/) | 柔化邊緣。<br/>            讀寫 [`ISoftEdge`](/slides/python-net/zh-hant/aspose.slides.effects/isoftedge). |
