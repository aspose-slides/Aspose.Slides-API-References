## LineSketchType 列舉

表示已指派給形狀的素描類型或效果。

LineSketchType 類型會公開以下成員：

## 欄位

| 欄位 | 描述 |
| :- | :- |
| NOT_DEFINED | 指定形狀的 Sketch 效果未定義。 |
| NONE | 指定形狀沒有 Sketch 效果。這相當於此屬性為空。 |
| CURVED | 指定形狀具有 Curved 效果，會將形狀的每條邊緣變成一個大而平緩的曲線。 |
| FREEHAND | 指定形狀具有 Freehand 效果，最接近手繪的不完美線條。 |
| SCRIBBLE | 指定形狀具有 Scribble 效果，呈現誇張的振盪，好像故意畫得凌亂。 |
