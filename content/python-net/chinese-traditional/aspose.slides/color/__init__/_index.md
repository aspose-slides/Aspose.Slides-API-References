## __init__(self, r=0, g=0, b=0, a=255) {#int-int-int-int}
根據指定的紅色、綠色、藍色和 Alpha 元件值建立顏色。


```python
def __init__(self, r=0, g=0, b=0, a=255):
    ...
```


| 參數 | 類型 | 描述 |
| :- | :- | :- |
| r | **int** | 紅色元件值。有效值範圍為 0 到 255。 |
| g | **int** | 綠色元件值。有效值範圍為 0 到 255。 |
| b | **int** | 藍色元件值。有效值範圍為 0 到 255。 |
| a | **int** | Alpha 元件值。有效值範圍為 0 到 255。 |

### 例外情況

| 例外 | 描述 |
| :- | :- |
| **ValueError** | 元件值小於 0 或大於 255。 |
| **TypeError** | 元件值不是數字。 |
