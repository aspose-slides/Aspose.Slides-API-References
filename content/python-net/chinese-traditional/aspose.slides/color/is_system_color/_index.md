## is_system_color 屬性
指定此顏色是否為系統顏色：用於 Windows 顯示元素的顏色，例如 `Control` 或 `ActiveBorder`。<br/> 系統顏色不會以 `Color` 屬性形式公開，且只能透過 [`from_known_color`](/slides/python-net/zh-hant/aspose.slides/color/from_known_color/) 取得或由函式庫返回。
            唯讀 **bool**.
