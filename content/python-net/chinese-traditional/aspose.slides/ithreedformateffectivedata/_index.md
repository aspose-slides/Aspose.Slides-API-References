## IThreeDFormatEffectiveData 類別

不可變的物件，表示有效的 3-D 格式屬性。

IThreeDFormatEffectiveData 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`contour_width`](/slides/python-net/zh-hant/aspose.slides/ithreedformateffectivedata/contour_width/) | 傳回 3D 輪廓的寬度。<br/>            只讀 **float**。 |
| [`extrusion_height`](/slides/python-net/zh-hant/aspose.slides/ithreedformateffectivedata/extrusion_height/) | 傳回拉伸效果的高度。<br/>            只讀 **float**。 |
| [`depth`](/slides/python-net/zh-hant/aspose.slides/ithreedformateffectivedata/depth/) | 傳回 3D 形狀的深度。<br/>            只讀 **float**。 |
| [`bevel_top`](/slides/python-net/zh-hant/aspose.slides/ithreedformateffectivedata/bevel_top/) | 傳回頂部 3D 斜角的類型。<br/>            只讀 [`IShapeBevelEffectiveData`](/slides/python-net/zh-hant/aspose.slides/ishapebeveleffectivedata)。 |
| [`bevel_bottom`](/slides/python-net/zh-hant/aspose.slides/ithreedformateffectivedata/bevel_bottom/) | 傳回底部 3D 斜角的類型。<br/>            只讀 [`IShapeBevelEffectiveData`](/slides/python-net/zh-hant/aspose.slides/ishapebeveleffectivedata)。 |
| [`contour_color`](/slides/python-net/zh-hant/aspose.slides/ithreedformateffectivedata/contour_color/) | 傳回輪廓的顏色。<br/>            只讀 [`Color`](/slides/python-net/zh-hant/aspose.slides/color)。 |
| [`extrusion_color`](/slides/python-net/zh-hant/aspose.slides/ithreedformateffectivedata/extrusion_color/) | 傳回拉伸的顏色。<br/>            只讀 [`Color`](/slides/python-net/zh-hant/aspose.slides/color)。 |
| [`camera`](/slides/python-net/zh-hant/aspose.slides/ithreedformateffectivedata/camera/) | 傳回相機的設定。<br/>            只讀 [`ICameraEffectiveData`](/slides/python-net/zh-hant/aspose.slides/icameraeffectivedata)。 |
| [`light_rig`](/slides/python-net/zh-hant/aspose.slides/ithreedformateffectivedata/light_rig/) | 傳回光源的類型。<br/>            只讀 [`ILightRigEffectiveData`](/slides/python-net/zh-hant/aspose.slides/ilightrigeffectivedata)。 |
| [`material`](/slides/python-net/zh-hant/aspose.slides/ithreedformateffectivedata/material/) | 傳回材質的類型。<br/>            只讀 [`MaterialPresetType`](/slides/python-net/zh-hant/aspose.slides/materialpresettype)。 |

### 備註

此介面與 [`IThreeDFormat`](/slides/python-net/zh-hant/aspose.slides/ithreedformat) 介面一起使用，以傳回套用繼承後的有效格式值。
