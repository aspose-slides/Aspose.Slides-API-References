## IImage 類別

表示光柵或向量圖像。

IImage 類型公開以下成員：

## 屬性

| Property | Description |
| :- | :- |
| [`size`](/slides/python-net/zh-hant/aspose.slides/iimage/size/) | Gets the size of the image. |
| [`width`](/slides/python-net/zh-hant/aspose.slides/iimage/width/) | Gets the width of the image in pixels. |
| [`height`](/slides/python-net/zh-hant/aspose.slides/iimage/height/) | Gets the height of the image in pixels. |

## 方法

| Method | Description |
| :- | :- |
| [`save(self, filename)`](/slides/python-net/zh-hant/aspose.slides/iimage/save/#str) | Saves the image to a file. |
| [`save(self, filename, format)`](/slides/python-net/zh-hant/aspose.slides/iimage/save/#str-imageformat) | Saves the image to a file in the specified format. |
| [`save(self, stream, format)`](/slides/python-net/zh-hant/aspose.slides/iimage/save/#iorawiobase-imageformat) | Saves the image to a stream in the specified format. |
| [`save(self, filename, format, quality)`](/slides/python-net/zh-hant/aspose.slides/iimage/save/#str-imageformat-int) | Saves the image to a file in the specified format and quality. |
| [`save(self, stream, format, quality)`](/slides/python-net/zh-hant/aspose.slides/iimage/save/#iorawiobase-imageformat-int) | Saves the image to a stream in the specified format and quality. |


### 備註

此介面提供了一個通用抽象，用於處理光柵和向量圖像。  
Implementations may vary depending on the underlying image type.
