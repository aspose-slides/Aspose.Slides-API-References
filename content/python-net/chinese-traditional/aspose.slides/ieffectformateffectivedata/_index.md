## IEffectFormatEffectiveData 類別

不可變的物件，包含有效的效果格式屬性。

IEffectFormatEffectiveData 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`is_no_effects`](/slides/python-net/zh-hant/aspose.slides/ieffectformateffectivedata/is_no_effects/) | 如果所有效果皆已停用則回傳 true（如剛建立的預設 EffectFormat 物件）。<br/>            唯讀 **bool**. |
| [`blur_effect`](/slides/python-net/zh-hant/aspose.slides/ieffectformateffectivedata/blur_effect/) | 模糊效果。<br/>            唯讀 [`IBlurEffectiveData`](/slides/python-net/zh-hant/aspose.slides.effects/iblureffectivedata). |
| [`fill_overlay_effect`](/slides/python-net/zh-hant/aspose.slides/ieffectformateffectivedata/fill_overlay_effect/) | 填充覆蓋效果。<br/>            唯讀 [`IFillOverlayEffectiveData`](/slides/python-net/zh-hant/aspose.slides.effects/ifilloverlayeffectivedata). |
| [`glow_effect`](/slides/python-net/zh-hant/aspose.slides/ieffectformateffectivedata/glow_effect/) | 發光效果。<br/>            唯讀 [`IGlowEffectiveData`](/slides/python-net/zh-hant/aspose.slides.effects/igloweffectivedata). |
| [`inner_shadow_effect`](/slides/python-net/zh-hant/aspose.slides/ieffectformateffectivedata/inner_shadow_effect/) | 內部陰影。<br/>            唯讀 [`IInnerShadowEffectiveData`](/slides/python-net/zh-hant/aspose.slides.effects/iinnershadoweffectivedata). |
| [`outer_shadow_effect`](/slides/python-net/zh-hant/aspose.slides/ieffectformateffectivedata/outer_shadow_effect/) | 外部陰影。<br/>            唯讀 [`IOuterShadowEffectiveData`](/slides/python-net/zh-hant/aspose.slides.effects/ioutershadoweffectivedata). |
| [`preset_shadow_effect`](/slides/python-net/zh-hant/aspose.slides/ieffectformateffectivedata/preset_shadow_effect/) | 預設陰影。<br/>            唯讀 [`IPresetShadowEffectiveData`](/slides/python-net/zh-hant/aspose.slides.effects/ipresetshadoweffectivedata). |
| [`reflection_effect`](/slides/python-net/zh-hant/aspose.slides/ieffectformateffectivedata/reflection_effect/) | 反射。 <br/>            唯讀 [`IReflectionEffectiveData`](/slides/python-net/zh-hant/aspose.slides.effects/ireflectioneffectivedata). |
| [`soft_edge_effect`](/slides/python-net/zh-hant/aspose.slides/ieffectformateffectivedata/soft_edge_effect/) | 柔和邊緣。<br/>            唯讀 [`ISoftEdgeEffectiveData`](/slides/python-net/zh-hant/aspose.slides.effects/isoftedgeeffectivedata). |


### 備註

此介面與 [`IEffectFormat`](/slides/python-net/zh-hant/aspose.slides/ieffectformat) 介面一起使用，以回傳套用繼承的有效格式值。
