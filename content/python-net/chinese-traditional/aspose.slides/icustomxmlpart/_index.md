## ICustomXmlPart 類別

代表自訂 XML 部分。

ICustomXmlPart 類型會公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`xml_as_string`](/slides/python-net/zh-hant/aspose.slides/icustomxmlpart/xml_as_string/) | 取得或設定 XML 資料作為 UTF-8 字串。<br/>            讀寫 **str**。<br/>            值為 `None`。值為空或 XML 資料無效。 |
| [`xml_data`](/slides/python-net/zh-hant/aspose.slides/icustomxmlpart/xml_data/) | 取得或設定 XML 資料。<br/>            讀寫 **int**[]。<br/>            值為 `None`。值為空或 XML 資料無效。 |
| [`item_id`](/slides/python-net/zh-hant/aspose.slides/icustomxmlpart/item_id/) | 指定全域唯一識別碼 (GUID)，用以唯一識別 Office Open XML 文件中單一的自訂 XML <br/>            部分。<br/>            唯讀 **System.Guid**。 |
| [`namespace_schemas`](/slides/python-net/zh-hant/aspose.slides/icustomxmlpart/namespace_schemas/) | 取得與自訂 XML 部分相關聯的 XML 架構集合。<br/>            唯讀 **str**[]。 |

## 方法

| 方法 | 說明 |
| :- | :- |
| [`remove(self)`](/slides/python-net/zh-hant/aspose.slides/icustomxmlpart/remove/#) | 從簡報中移除自訂 XML 部分。 |
