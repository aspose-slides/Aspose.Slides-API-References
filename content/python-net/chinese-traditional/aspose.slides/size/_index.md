## Size 類別

儲存一個有序的整數對，指定寬度和高度。相容於 .NET `System.Drawing.Size`。

Size 類型公開以下成員：

## 建構子

| 建構子 | 說明 |
| :- | :- |
| [`__init__(self, width=0, height=0)`](/slides/python-net/zh-hant/aspose.slides/size/__init__/#int-int) | 建立一個具有指定寬度與高度的 size。浮點數值會被截斷為整數。 |

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`width`](/slides/python-net/zh-hant/aspose.slides/size/width/) | 取得此 size 的水平分量。<br/>            唯讀 **int**. |
| [`height`](/slides/python-net/zh-hant/aspose.slides/size/height/) | 取得此 size 的垂直分量。<br/>            唯讀 **int**. |


### 備註

Size 會以其組件使用 `==` 進行比較，且可作為字典鍵或集合成員使用。
