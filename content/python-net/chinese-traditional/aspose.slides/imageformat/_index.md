## ImageFormat 列舉

表示圖像的檔案格式。

ImageFormat 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| MEMORY_BMP | 表示記憶體中位圖的格式。 |
| BMP | 表示位圖（BMP）影像格式。 |
| EMF | 表示增強型中繼檔（EMF）影像格式。 |
| WMF | 表示 Windows 中繼檔（WMF）影像格式。 |
| GIF | 表示圖形交換格式（GIF）影像格式。 |
| JPEG | 表示聯合圖像專家組（JPEG）影像格式。 |
| PNG | 表示 W3C 可攜式網路圖形（PNG）影像格式。 |
| TIFF | 表示標記影像檔案格式（TIFF）影像格式。 |
| EXIF | 表示可交換影像檔（Exif）格式。 |
| ICON | 表示 Windows 圖示影像格式。 |
