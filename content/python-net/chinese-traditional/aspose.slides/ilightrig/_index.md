## ILightRig 類別

表示 LightRig.

ILightRig 類型公開以下成員：

## 屬性

| Property | Description |
| :- | :- |
| [`direction`](/slides/python-net/zh-hant/aspose.slides/ilightrig/direction/) | 光線方向。<br/>            讀/寫 [`LightingDirection`](/slides/python-net/zh-hant/aspose.slides/lightingdirection). |
| [`light_type`](/slides/python-net/zh-hant/aspose.slides/ilightrig/light_type/) | 表示可以套用於形狀的預設光線。<br/>            light rig 代表相對於 3D 場景以特定方式定位的一組光線。<br/>            讀/寫 [`LightRigPresetType`](/slides/python-net/zh-hant/aspose.slides/lightrigpresettype). |

## 方法

| Method | Description |
