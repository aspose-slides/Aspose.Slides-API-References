## IConnectorLock 類別

判斷父級 Connector 上哪些操作被停用。

IConnectorLock 型別公開以下成員：

## 屬性

| 屬性 | 描述 |
| :- | :- |
| [`grouping_locked`](/slides/python-net/zh-hant/aspose.slides/iconnectorlock/grouping_locked/) | 判斷是否禁止將此形狀加入群組。<br/>            讀寫 **bool**. |
| [`select_locked`](/slides/python-net/zh-hant/aspose.slides/iconnectorlock/select_locked/) | 判斷是否禁止選取此形狀。<br/>            讀寫 **bool**. |
| [`rotate_locked`](/slides/python-net/zh-hant/aspose.slides/iconnectorlock/rotate_locked/) | 判斷是否禁止變更此形狀的旋轉角度。<br/>            讀寫 **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/zh-hant/aspose.slides/iconnectorlock/aspect_ratio_locked/) | 判斷在調整大小時是否必須保留形狀的長寬比。<br/>            讀寫 **bool**. |
| [`position_move`](/slides/python-net/zh-hant/aspose.slides/iconnectorlock/position_move/) | 判斷是否禁止移動此形狀。<br/>            讀寫 **bool**. |
| [`size_locked`](/slides/python-net/zh-hant/aspose.slides/iconnectorlock/size_locked/) | 判斷是否禁止調整此形狀的大小。<br/>            讀寫 **bool**. |
| [`edit_points_locked`](/slides/python-net/zh-hant/aspose.slides/iconnectorlock/edit_points_locked/) | 判斷是否禁止直接變更此形狀的輪廓。<br/>            讀寫 **bool**. |
| [`adjust_handles_locked`](/slides/python-net/zh-hant/aspose.slides/iconnectorlock/adjust_handles_locked/) | 判斷是否禁止變更調整值。<br/>            讀寫 **bool**. |
| [`arrowheads_locked`](/slides/python-net/zh-hant/aspose.slides/iconnectorlock/arrowheads_locked/) | 判斷是否禁止變更箭頭。<br/>            讀寫 **bool**. |
