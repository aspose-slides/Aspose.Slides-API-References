## IColorFormat 類別

表示在簡報中使用的顏色。

IColorFormat 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`color_type`](/slides/python-net/zh-hant/aspose.slides/icolorformat/color_type/) | 傳回或設定顏色定義方法。<br/>            讀寫 [`ColorType`](/slides/python-net/zh-hant/aspose.slides/colortype). |
| [`color`](/slides/python-net/zh-hant/aspose.slides/icolorformat/color/) | 傳回結果顏色（已套用所有顏色轉換）。<br/>            設定 RGB 顏色並清除所有顏色轉換。<br/>            讀寫 [`Color`](/slides/python-net/zh-hant/aspose.slides/color). |
| [`preset_color`](/slides/python-net/zh-hant/aspose.slides/icolorformat/preset_color/) | 傳回或設定顏色預設值。<br/>            讀寫 [`PresetColor`](/slides/python-net/zh-hant/aspose.slides/presetcolor). |
| [`system_color`](/slides/python-net/zh-hant/aspose.slides/icolorformat/system_color/) | 傳回或設定由系統顏色表識別的顏色。<br/>            讀寫 [`SystemColor`](/slides/python-net/zh-hant/aspose.slides/systemcolor). |
| [`scheme_color`](/slides/python-net/zh-hant/aspose.slides/icolorformat/scheme_color/) | 傳回或設定由色彩方案識別的顏色。<br/>            讀寫 [`SchemeColor`](/slides/python-net/zh-hant/aspose.slides/schemecolor). |
| [`r`](/slides/python-net/zh-hant/aspose.slides/icolorformat/r/) | 傳回或設定顏色的紅色分量。所有顏色轉換皆被忽略。<br/>            讀寫 **int**. |
| [`g`](/slides/python-net/zh-hant/aspose.slides/icolorformat/g/) | 傳回或設定顏色的綠色分量。所有顏色轉換皆被忽略。<br/>            讀寫 **int**. |
| [`b`](/slides/python-net/zh-hant/aspose.slides/icolorformat/b/) | 傳回或設定顏色的藍色分量。所有顏色轉換皆被忽略。<br/>            讀寫 **int**. |
| [`float_r`](/slides/python-net/zh-hant/aspose.slides/icolorformat/float_r/) | 傳回或設定顏色的紅色分量。所有顏色轉換皆被忽略。<br/>            讀寫 **float**. |
| [`float_g`](/slides/python-net/zh-hant/aspose.slides/icolorformat/float_g/) | 傳回或設定顏色的綠色分量。所有顏色轉換皆被忽略。<br/>            讀寫 **float**. |
| [`float_b`](/slides/python-net/zh-hant/aspose.slides/icolorformat/float_b/) | 傳回或設定顏色的藍色分量。所有顏色轉換皆被忽略。<br/>            讀寫 **float**. |
| [`hue`](/slides/python-net/zh-hant/aspose.slides/icolorformat/hue/) | 傳回或設定顏色在 HSL 表示法中的色相分量。<br/>            所有顏色轉換皆被忽略。<br/>            讀寫 **float**. |
| [`saturation`](/slides/python-net/zh-hant/aspose.slides/icolorformat/saturation/) | 傳回或設定顏色在 HSL 表示法中的飽和度分量。<br/>            所有顏色轉換皆被忽略。<br/>            讀寫 **float**. |
| [`luminance`](/slides/python-net/zh-hant/aspose.slides/icolorformat/luminance/) | 傳回或設定顏色在 HSL 表示法中的亮度分量。<br/>            所有顏色轉換皆被忽略。<br/>            讀寫 **float**. |
| [`color_transform`](/slides/python-net/zh-hant/aspose.slides/icolorformat/color_transform/) | 傳回套用於顏色的顏色轉換集合。<br/>            唯讀 [`IColorOperationCollection`](/slides/python-net/zh-hant/aspose.slides/icoloroperationcollection). |
