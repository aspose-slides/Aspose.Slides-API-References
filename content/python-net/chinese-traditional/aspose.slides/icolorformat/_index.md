## IColorFormat 類

表示簡報中使用的顏色。

IColorFormat 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`color_type`](/slides/python-net/zh-hant/aspose.slides/icolorformat/color_type/) | 取得或設定顏色定義方式。<br/>            讀/寫 [`ColorType`](/slides/python-net/zh-hant/aspose.slides/colortype)。 |
| [`color`](/slides/python-net/zh-hant/aspose.slides/icolorformat/color/) | 取得結果顏色（套用所有顏色轉換後）。<br/>            設定 RGB 顏色並清除所有顏色轉換。<br/>            讀/寫 **aspose.slides.Color**。 |
| [`preset_color`](/slides/python-net/zh-hant/aspose.slides/icolorformat/preset_color/) | 取得或設定顏色預設值。<br/>            讀/寫 [`PresetColor`](/slides/python-net/zh-hant/aspose.slides/presetcolor)。 |
| [`system_color`](/slides/python-net/zh-hant/aspose.slides/icolorformat/system_color/) | 取得或設定由系統顏色表識別的顏色。<br/>            讀/寫 [`SystemColor`](/slides/python-net/zh-hant/aspose.slides/systemcolor)。 |
| [`scheme_color`](/slides/python-net/zh-hant/aspose.slides/icolorformat/scheme_color/) | 取得或設定由配色方案識別的顏色。<br/>            讀/寫 [`SchemeColor`](/slides/python-net/zh-hant/aspose.slides/schemecolor)。 |
| [`r`](/slides/python-net/zh-hant/aspose.slides/icolorformat/r/) | 取得或設定顏色的紅色成分。所有顏色轉換皆被忽略。<br/>            讀/寫 **int**。 |
| [`g`](/slides/python-net/zh-hant/aspose.slides/icolorformat/g/) | 取得或設定顏色的綠色成分。所有顏色轉換皆被忽略。<br/>            讀/寫 **int**。 |
| [`b`](/slides/python-net/zh-hant/aspose.slides/icolorformat/b/) | 取得或設定顏色的藍色成分。所有顏色轉換皆被忽略。<br/>            讀/寫 **int**。 |
| [`float_r`](/slides/python-net/zh-hant/aspose.slides/icolorformat/float_r/) | 取得或設定顏色的紅色成分。所有顏色轉換皆被忽略。<br/>            讀/寫 **float**。 |
| [`float_g`](/slides/python-net/zh-hant/aspose.slides/icolorformat/float_g/) | 取得或設定顏色的綠色成分。所有顏色轉換皆被忽略。<br/>            讀/寫 **float**。 |
| [`float_b`](/slides/python-net/zh-hant/aspose.slides/icolorformat/float_b/) | 取得或設定顏色的藍色成分。所有顏色轉換皆被忽略。<br/>            讀/寫 **float**。 |
| [`hue`](/slides/python-net/zh-hant/aspose.slides/icolorformat/hue/) | 取得或設定 HSL 表示法中顏色的色相成分。<br/>            所有顏色轉換皆被忽略。<br/>            讀/寫 **float**。 |
| [`saturation`](/slides/python-net/zh-hant/aspose.slides/icolorformat/saturation/) | 取得或設定 HSL 表示法中顏色的飽和度成分。<br/>            所有顏色轉換皆被忽略。<br/>            讀/寫 **float**。 |
| [`luminance`](/slides/python-net/zh-hant/aspose.slides/icolorformat/luminance/) | 取得或設定 HSL 表示法中顏色的亮度成分。<br/>            所有顏色轉換皆被忽略。<br/>            讀/寫 **float**。 |
| [`color_transform`](/slides/python-net/zh-hant/aspose.slides/icolorformat/color_transform/) | 取得套用於顏色的顏色轉換集合。<br/>            唯讀 [`IColorOperationCollection`](/slides/python-net/zh-hant/aspose.slides/icoloroperationcollection)。 |
