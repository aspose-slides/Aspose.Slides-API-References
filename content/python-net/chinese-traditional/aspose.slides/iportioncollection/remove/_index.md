## remove(self, item) {#iportion}
從 **System.Collections.Generic.ICollection`1** 中移除特定物件的第一次出現。

### 傳回值

`item` 成功從 **System.Collections.Generic.ICollection`1** 中移除時傳回 true；否則傳回 false。若在原始 **System.Collections.Generic.ICollection`1** 中找不到 `item`，此方法也會傳回 false。  


```python
def remove(self, item):
    ...
```


| 參數 | 類型 | 說明 |
| :- | :- | :- |
| item | [`IPortion`](/slides/python-net/zh-hant/aspose.slides/iportion) | 要從 **System.Collections.Generic.ICollection`1** 中移除的物件。 |

### 例外狀況

| 例外 | 說明 |
| :- | :- |
| **RuntimeError(Proxy error(NotSupportedException))** | **System.Collections.Generic.ICollection`1** 為唯讀。 |
