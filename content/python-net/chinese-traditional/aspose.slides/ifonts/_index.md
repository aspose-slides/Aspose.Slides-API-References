## IFonts 類別

代表字型集合。

IFonts 型別公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`latin_font`](/slides/python-net/zh-hant/aspose.slides/ifonts/latin_font/) | 傳回或設定拉丁字型。<br/>            讀寫 [`IFontData`](/slides/python-net/zh-hant/aspose.slides/ifontdata). |
| [`east_asian_font`](/slides/python-net/zh-hant/aspose.slides/ifonts/east_asian_font/) | 傳回或設定東亞字型。<br/>            讀寫 [`IFontData`](/slides/python-net/zh-hant/aspose.slides/ifontdata). |
| [`complex_script_font`](/slides/python-net/zh-hant/aspose.slides/ifonts/complex_script_font/) | 傳回或設定複雜文字字型。<br/>            讀寫 [`IFontData`](/slides/python-net/zh-hant/aspose.slides/ifontdata). |

## 方法

| 方法 | 說明 |
| :- | :- |
| [`get_script_font_map(self)`](/slides/python-net/zh-hant/aspose.slides/ifonts/get_script_font_map/#) | 傳回簡報中所有字串-字串配對的腳本字型定義清單。 |
| [`get_script_font(self, script)`](/slides/python-net/zh-hant/aspose.slides/ifonts/get_script_font/#str) | 取得與簡報主題中特定腳本標籤相關聯的字型名稱。 |
| [`set_script_font(self, script, font_name)`](/slides/python-net/zh-hant/aspose.slides/ifonts/set_script_font/#str-str) | 指定字型名稱給特定腳本標籤，以定義簡報中該腳本文字的呈現方式。 |
| [`remove_script_font(self, script)`](/slides/python-net/zh-hant/aspose.slides/ifonts/remove_script_font/#str) | 從主題的字型集合中移除與特定腳本標籤相關的字型設定。 |
