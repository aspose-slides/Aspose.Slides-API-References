## ColorFormat 類別

表示簡報中使用的色彩。

**Inheritance:**[`ColorFormat`](/slides/python-net/zh-hant/aspose.slides/colorformat) → [`PVIObject`](/slides/python-net/zh-hant/aspose.slides/pviobject)

ColorFormat 類別公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`color_type`](/slides/python-net/zh-hant/aspose.slides/colorformat/color_type/) | 取得或設定色彩定義方法。<br/>            讀寫 [`ColorType`](/slides/python-net/zh-hant/aspose.slides/colortype)。 |
| [`color`](/slides/python-net/zh-hant/aspose.slides/colorformat/color/) | 取得結果色彩（已套用所有色彩變換）。<br/>            設定 RGB 色彩並清除所有色彩變換。<br/>            讀寫 **aspose.slides.Color**。 |
| [`preset_color`](/slides/python-net/zh-hant/aspose.slides/colorformat/preset_color/) | 取得或設定色彩預設值。<br/>            讀寫 [`PresetColor`](/slides/python-net/zh-hant/aspose.slides/presetcolor)。 |
| [`system_color`](/slides/python-net/zh-hant/aspose.slides/colorformat/system_color/) | 取得或設定由系統色彩表辨識的色彩。<br/>            讀寫 [`SystemColor`](/slides/python-net/zh-hant/aspose.slides/systemcolor)。 |
| [`scheme_color`](/slides/python-net/zh-hant/aspose.slides/colorformat/scheme_color/) | 取得或設定由配色方案辨識的色彩。<br/>            讀寫 [`SchemeColor`](/slides/python-net/zh-hant/aspose.slides/schemecolor)。 |
| [`r`](/slides/python-net/zh-hant/aspose.slides/colorformat/r/) | 取得或設定色彩的紅色成分。忽略所有色彩變換。<br/>            讀寫 **int**。 |
| [`g`](/slides/python-net/zh-hant/aspose.slides/colorformat/g/) | 取得或設定色彩的綠色成分。忽略所有色彩變換。 |
| [`b`](/slides/python-net/zh-hant/aspose.slides/colorformat/b/) | 取得或設定色彩的藍色成分。忽略所有色彩變換。<br/>            讀寫 **int**。 |
| [`float_r`](/slides/python-net/zh-hant/aspose.slides/colorformat/float_r/) | 取得或設定色彩的紅色成分。忽略所有色彩變換。<br/>            讀寫 **float**。 |
| [`float_g`](/slides/python-net/zh-hant/aspose.slides/colorformat/float_g/) | 取得或設定色彩的綠色成分。忽略所有色彩變換。<br/>            讀寫 **float**。 |
| [`float_b`](/slides/python-net/zh-hant/aspose.slides/colorformat/float_b/) | 取得或設定色彩的藍色成分。忽略所有色彩變換。<br/>            讀寫 **float**。 |
| [`hue`](/slides/python-net/zh-hant/aspose.slides/colorformat/hue/) | 取得或設定色彩在 HSL 表示法中的色相成分。<br/>            忽略所有色彩變換。<br/>            讀寫 **float**。 |
| [`saturation`](/slides/python-net/zh-hant/aspose.slides/colorformat/saturation/) | 取得或設定色彩在 HSL 表示法中的飽和度成分。<br/>            忽略所有色彩變換。<br/>            讀寫 **float**。 |
| [`luminance`](/slides/python-net/zh-hant/aspose.slides/colorformat/luminance/) | 取得或設定色彩在 HSL 表示法中的亮度成分。<br/>            忽略所有色彩變換。<br/>            讀寫 **float**。 |
| [`color_transform`](/slides/python-net/zh-hant/aspose.slides/colorformat/color_transform/) | 取得套用於色彩的色彩變換集合。<br/>            唯讀 [`IColorOperationCollection`](/slides/python-net/zh-hant/aspose.slides/icoloroperationcollection)。 |
