## TextSearchOptions 類別

表示可用於在 Presentation、Slide 或 TextFrame 中搜尋文字的選項。

TextSearchOptions 類別暴露以下成員：

## 建構函式

| 建構函式 | 說明 |
| :- | :- |
| [`__init__(self)`](/slides/python-net/zh-hant/aspose.slides/textsearchoptions/__init__/#) | 建立新的預設文字搜尋選項。 |

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`case_sensitive`](/slides/python-net/zh-hant/aspose.slides/textsearchoptions/case_sensitive/) | 設定 true 以使用區分大小寫的搜尋，否則為 false。<br/>            可讀寫 **bool**。 |
| [`whole_words_only`](/slides/python-net/zh-hant/aspose.slides/textsearchoptions/whole_words_only/) | 設定 true 以僅匹配完整單詞，否則為 false。<br/>            可讀寫 **bool**。 |
| [`include_notes`](/slides/python-net/zh-hant/aspose.slides/textsearchoptions/include_notes/) | 設定 `true` 以在執行文字搜尋、取代或標記操作時，包含投影片備註 ([`NotesSlide`](/slides/python-net/zh-hant/aspose.slides/notesslide)) 中的文字。<br/>            預設值為 `false`。 |
