## ISensitivityLabel 類別

表示來自 Microsoft Purview Information Protection 的敏感度標籤。

ISensitivityLabel 類型公開以下成員：

## 屬性

| Property | Description |
| :- | :- |
| [`id`](/slides/python-net/zh-hant/aspose.slides/isensitivitylabel/id/) | 傳回或設定敏感度標籤的 id。<br/>            讀寫 **str**。 |
| [`site_id`](/slides/python-net/zh-hant/aspose.slides/isensitivitylabel/site_id/) | 傳回或設定 Azure Active Directory (Azure AD) 站台識別碼<br/>            與描述該敏感度標籤之敏感度標籤原則相對應。<br/>            讀寫 **System.Guid**。 |
| [`is_enabled`](/slides/python-net/zh-hant/aspose.slides/isensitivitylabel/is_enabled/) | 表示是否已啟用敏感度標籤。 |
| [`is_removed`](/slides/python-net/zh-hant/aspose.slides/isensitivitylabel/is_removed/) | 表示是否已移除敏感度標籤。 |
| [`assignment_method_type`](/slides/python-net/zh-hant/aspose.slides/isensitivitylabel/assignment_method_type/) | 傳回或設定敏感度標籤的指派方法。<br/>            讀寫 [`SensitivityLabelAssignmentType`](/slides/python-net/zh-hant/aspose.slides/sensitivitylabelassignmenttype)。 |
| [`content_mark_types`](/slides/python-net/zh-hant/aspose.slides/isensitivitylabel/content_mark_types/) | 傳回應套用於檔案的內容標記類型清單。 |
