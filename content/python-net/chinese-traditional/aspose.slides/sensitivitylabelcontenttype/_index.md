## SensitivityLabelContentType 列舉

表示應套用於文件的內容標記類型。

SensitivityLabelContentType 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| NONE | 表示該標籤是預設或自動套用的。 |
| HEADER | 表示該標籤是手動套用的。<br/>            用於任何直接由使用者套用的機密標籤。 |
| FOOTER | 表示該標籤是手動套用的。<br/>            用於任何直接由使用者套用的機密標籤。 |
| WATERMARK | 表示該標籤是手動套用的。<br/>            用於任何直接由使用者套用的機密標籤。 |
| ENCRYPTION | 表示該標籤是手動套用的。<br/>            用於任何直接由使用者套用的機密標籤。 |
