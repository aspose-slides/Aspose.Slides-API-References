## x 屬性
取得或設定形狀左上角的 x 座標，以點為單位。
            Read/write **float**.


### 備註

返回的值始終已定義，且絕不為 **float**。
            指定的值也必須已定義；僅對 `RawFrame` 實例的屬性指派 **float**。

### 定義：
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
