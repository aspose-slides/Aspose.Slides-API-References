## ColorType 列舉

表示不同的顏色模式。

ColorType 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| NOT_DEFINED | 顏色根本未定義。 |
| RGB | 標準 24 位元 RGB 顏色。 |
| RGB_PERCENTAGE | 高解析度 RGB 顏色。 |
| HSL | 高解析度 HSL 顏色。 |
| SCHEME | 方案顏色。 |
| SYSTEM | 系統顏色。 |
| PRESET | 預設顏色。 |
