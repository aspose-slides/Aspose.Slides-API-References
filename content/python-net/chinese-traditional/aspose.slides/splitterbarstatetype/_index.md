## SplitterBarStateType 列舉

指定分割條應顯示的狀態。分割條在檢視區域內將主要區域與次要區域分開。

SplitterBarStateType 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| MINIMIZED | 主要區域佔用應用程式允許的檢視區域中最少的空間。 |
| RESTORED | 主要區域具有特定的中間大小。 |
| MAXIMIZED | 主要區域佔用應用程式允許的檢視區域中最大的空間。 |
