## SizeF 類別

儲存一組有序的浮點數，通常為矩形的寬度與高度。相容於 .NET `System.Drawing.SizeF`。

SizeF 類別提供以下成員：

## 建構式

| 建構式 | 說明 |
| :- | :- |
| [`__init__(self, width=0.0, height=0.0)`](/slides/python-net/zh-hant/aspose.slides/sizef/__init__/#float-float) | 建立具有指定寬度與高度的尺寸。 |

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`width`](/slides/python-net/zh-hant/aspose.slides/sizef/width/) | 取得此尺寸的水平分量。<br/>            唯讀 **float**. |
| [`height`](/slides/python-net/zh-hant/aspose.slides/sizef/height/) | 取得此尺寸的垂直分量。<br/>            唯讀 **float**. |


### 備註

尺寸可使用 `==` 依其分量進行比較，且可作為字典鍵或集合成員使用。
