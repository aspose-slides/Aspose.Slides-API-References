## IViewProperties 類別

整個簡報的檢視屬性。

IViewProperties 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`last_view`](/slides/python-net/zh-hant/aspose.slides/iviewproperties/last_view/) | 指定在最後一次儲存簡報文件時所使用的檢視模式。<br/>            讀/寫 [`ViewType`](/slides/python-net/zh-hant/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/zh-hant/aspose.slides/iviewproperties/show_comments/) | 指定是否應顯示投影片註解。<br/>            讀/寫 [`NullableBool`](/slides/python-net/zh-hant/aspose.slides/nullablebool). |
| [`slide_view_properties`](/slides/python-net/zh-hant/aspose.slides/iviewproperties/slide_view_properties/) | 指定與投影片檢視模式相關的共同檢視屬性。<br/>            唯讀 [`ICommonSlideViewProperties`](/slides/python-net/zh-hant/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/zh-hant/aspose.slides/iviewproperties/notes_view_properties/) | 指定與備註檢視模式相關的共同檢視屬性。<br/>            唯讀 [`ICommonSlideViewProperties`](/slides/python-net/zh-hant/aspose.slides/icommonslideviewproperties). |
| [`normal_view_properties`](/slides/python-net/zh-hant/aspose.slides/iviewproperties/normal_view_properties/) | 代表一般檢視屬性。一般檢視由三個內容區域組成：投影片本身、側邊內容區域以及底部內容區域。<br/>            唯讀 [`INormalViewProperties`](/slides/python-net/zh-hant/aspose.slides/inormalviewproperties). |
| [`grid_spacing`](/slides/python-net/zh-hant/aspose.slides/iviewproperties/grid_spacing/) | 取得或設定用於簡報文件底層格線的間距（單位為點）。<br/>            讀/寫 **float**. |
