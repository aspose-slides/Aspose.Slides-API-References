## Reflection 類別

表示 Reflection 效果。

Reflection 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/zh-hant/aspose.slides.effects/reflection/start_pos_alpha/) | 指定起始 alpha 值（百分比）在 alpha 漸層坡道上的起始位置。<br/>            讀寫 **float**。 |
| [`end_pos_alpha`](/slides/python-net/zh-hant/aspose.slides.effects/reflection/end_pos_alpha/) | 指定結束 alpha 值（百分比）在 alpha 漸層坡道上的結束位置。<br/>            讀寫 **float**。 |
| [`fade_direction`](/slides/python-net/zh-hant/aspose.slides.effects/reflection/fade_direction/) | 指定反射的偏移方向。（角度）。<br/>            讀寫 **float**。 |
| [`start_reflection_opacity`](/slides/python-net/zh-hant/aspose.slides.effects/reflection/start_reflection_opacity/) | 起始反射不透明度。（百分比）。<br/>            讀寫 **float**。 |
| [`end_reflection_opacity`](/slides/python-net/zh-hant/aspose.slides.effects/reflection/end_reflection_opacity/) | 結束反射不透明度。（百分比）。<br/>            讀寫 **float**。 |
| [`blur_radius`](/slides/python-net/zh-hant/aspose.slides.effects/reflection/blur_radius/) | 模糊半徑。<br/>            讀寫 **float**。 |
| [`direction`](/slides/python-net/zh-hant/aspose.slides.effects/reflection/direction/) | 反射方向。<br/>            讀寫 **float**。 |
| [`distance`](/slides/python-net/zh-hant/aspose.slides.effects/reflection/distance/) | 反射距離。<br/>            讀寫 **float**。 |
| [`rectangle_align`](/slides/python-net/zh-hant/aspose.slides.effects/reflection/rectangle_align/) | 矩形對齊。<br/>            讀寫 [`RectangleAlignment`](/slides/python-net/zh-hant/aspose.slides/rectanglealignment)。 |
| [`skew_horizontal`](/slides/python-net/zh-hant/aspose.slides.effects/reflection/skew_horizontal/) | 指定水平斜角。<br/>            讀寫 **float**。 |
| [`skew_vertical`](/slides/python-net/zh-hant/aspose.slides.effects/reflection/skew_vertical/) | 指定垂直斜角。<br/>            讀寫 **float**。 |
| [`rotate_shadow_with_shape`](/slides/python-net/zh-hant/aspose.slides.effects/reflection/rotate_shadow_with_shape/) | 指定當形狀旋轉時，反射是否隨形狀一起旋轉。<br/>            讀寫 **bool**。 |
| [`scale_horizontal`](/slides/python-net/zh-hant/aspose.slides.effects/reflection/scale_horizontal/) | 指定水平縮放係數，負值縮放會導致翻轉。（百分比）<br/>            讀寫 **float**。 |
| [`scale_vertical`](/slides/python-net/zh-hant/aspose.slides.effects/reflection/scale_vertical/) | 指定垂直縮放係數，負值縮放會導致翻轉。（百分比）<br/>            讀寫 **float**。 |
