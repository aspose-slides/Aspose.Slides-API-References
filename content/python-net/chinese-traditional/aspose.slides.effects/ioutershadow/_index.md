## IOuterShadow 類別

表示外部陰影效果。

IOuterShadow 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`blur_radius`](/slides/python-net/zh-hant/aspose.slides.effects/ioutershadow/blur_radius/) | 模糊半徑（以點為單位）。<br/>            預設值 – 0 pt.<br/>            讀寫 **float**. |
| [`direction`](/slides/python-net/zh-hant/aspose.slides.effects/ioutershadow/direction/) | 陰影方向，單位為度。<br/>            預設值 – 0 °（由左至右）。<br/>            讀寫 **float**. |
| [`distance`](/slides/python-net/zh-hant/aspose.slides.effects/ioutershadow/distance/) | 陰影與物件的距離，單位為點。<br/>            預設值 – 0 pt.<br/>            讀寫 **float**. |
| [`shadow_color`](/slides/python-net/zh-hant/aspose.slides.effects/ioutershadow/shadow_color/) | 陰影顏色。<br/>            預設值 – 自動黑色（依主題而定）。<br/>            唯讀 [`IColorFormat`](/slides/python-net/zh-hant/aspose.slides/icolorformat). |
| [`rectangle_align`](/slides/python-net/zh-hant/aspose.slides.effects/ioutershadow/rectangle_align/) | 矩形對齊方式。<br/>            預設值 – [`RectangleAlignment.BOTTOM`](/slides/python-net/zh-hant/aspose.slides/rectanglealignment/BOTTOM). <br/>            讀寫 [`RectangleAlignment`](/slides/python-net/zh-hant/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/zh-hant/aspose.slides.effects/ioutershadow/skew_horizontal/) | 水平斜切角度，單位為度。<br/>            預設值 – 0 °.<br/>            讀寫 **float**. |
| [`skew_vertical`](/slides/python-net/zh-hant/aspose.slides.effects/ioutershadow/skew_vertical/) | 垂直斜切角度，單位為度。<br/>            預設值 – 0 °.<br/>            讀寫 **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/zh-hant/aspose.slides.effects/ioutershadow/rotate_shadow_with_shape/) | 指示陰影是否隨形狀一起旋轉。<br/>            預設值 – true。<br/>            讀寫 **bool**. |
| [`scale_horizontal`](/slides/python-net/zh-hant/aspose.slides.effects/ioutershadow/scale_horizontal/) | 水平縮放比例，原始大小的百分比。<br/>            負向縮放會導致翻轉。<br/>            預設值 – 100 %。<br/>            讀寫 **float**. |
| [`scale_vertical`](/slides/python-net/zh-hant/aspose.slides.effects/ioutershadow/scale_vertical/) | 垂直縮放比例，原始大小的百分比。<br/>            負向縮放會導致翻轉。<br/>            預設值 – 100 %。<br/>            讀寫 **float**. |
