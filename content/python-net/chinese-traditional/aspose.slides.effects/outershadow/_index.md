## OuterShadow 類別

表示外部陰影效果。

OuterShadow 類型公開以下成員：

## 屬性

| Property | Description |
| :- | :- |
| [`blur_radius`](/slides/python-net/zh-hant/aspose.slides.effects/outershadow/blur_radius/) | 模糊半徑，以點為單位。<br/>            預設值 – 0 pt。<br/>            可讀寫 **float**. |
| [`direction`](/slides/python-net/zh-hant/aspose.slides.effects/outershadow/direction/) | 陰影方向，以度為單位。<br/>            預設值 – 0 °（從左到右）。<br/>            可讀寫 **float**. |
| [`distance`](/slides/python-net/zh-hant/aspose.slides.effects/outershadow/distance/) | 陰影與物件的距離，以點為單位。<br/>            預設值 – 0 pt。<br/>            可讀寫 **float**. |
| [`shadow_color`](/slides/python-net/zh-hant/aspose.slides.effects/outershadow/shadow_color/) | 陰影的顏色。<br/>            預設值 – 自動黑色（依佈景主題）。<br/>            只讀 [`IColorFormat`](/slides/python-net/zh-hant/aspose.slides/icolorformat). |
| [`rectangle_align`](/slides/python-net/zh-hant/aspose.slides.effects/outershadow/rectangle_align/) | 矩形對齊方式。<br/>            預設值 – [`RectangleAlignment.BOTTOM`](/slides/python-net/zh-hant/aspose.slides/rectanglealignment/BOTTOM)。 <br/>            可讀寫 [`RectangleAlignment`](/slides/python-net/zh-hant/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/zh-hant/aspose.slides.effects/outershadow/skew_horizontal/) | 水平傾斜角度，以度為單位。<br/>            預設值 – 0 °。<br/>            可讀寫 **float**. |
| [`skew_vertical`](/slides/python-net/zh-hant/aspose.slides.effects/outershadow/skew_vertical/) | 垂直傾斜角度，以度為單位。<br/>            預設值 – 0 °。<br/>            可讀寫 **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/zh-hant/aspose.slides.effects/outershadow/rotate_shadow_with_shape/) | 指示陰影是否隨形狀一起旋轉。<br/>            預設值 – true。<br/>            可讀寫 **bool**. |
| [`scale_horizontal`](/slides/python-net/zh-hant/aspose.slides.effects/outershadow/scale_horizontal/) | 水平縮放係數，以原始大小的百分比表示。<br/>            負值縮放會導致翻轉。<br/>            預設值 – 100%。<br/>            可讀寫 **float**. |
| [`scale_vertical`](/slides/python-net/zh-hant/aspose.slides.effects/outershadow/scale_vertical/) | 垂直縮放係數，以原始大小的百分比表示。<br/>            負值縮放會導致翻轉。<br/>            預設值 – 100%。<br/>            可讀寫 **float**. |
