## LegendDataLabelPosition 列舉

決定資料標籤的位置。

LegendDataLabelPosition 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| NOT_DEFINED | 位置未定義。 |
| BOTTOM | 指定資料標籤應顯示在資料標記的下方。 |
| BEST_FIT | 指定資料標籤應顯示在最佳位置。 |
| CENTER | 指定資料標籤應顯示在資料標記的中心。 |
| INSIDE_BASE | 指定資料標籤應顯示在資料標記的底部內部。 |
| INSIDE_END | 指定資料標籤應顯示在資料標記的末端內部。 |
| LEFT | 指定資料標籤應顯示在資料標記的左側。 |
| OUTSIDE_END | 指定資料標籤應顯示在資料標記的末端外側。 |
| RIGHT | 指定資料標籤應顯示在資料標記的右側。 |
| TOP | 指定資料標籤應顯示在資料標記的上方。 |
