## AxisAggregationType 列舉

表示類別軸的聚合類型。僅適用於 Histogram 或 HistogramPareto 系列。

AxisAggregationType 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| BY_CATEGORY | 依類別聚合 |
| AUTOMATIC | 自動聚合類別。 |
| BY_BIN_WIDTH | 依等寬聚合類別。必須設定屬性 IAxis.BinWidth。 |
| BY_NUMBER_OF_BINS | 依箱數聚合類別。必須設定屬性 IAxis.NumberOfBins。 |
