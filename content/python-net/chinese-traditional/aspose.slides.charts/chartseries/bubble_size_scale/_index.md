## bubble_size_scale 屬性
指定氣泡圖的比例因子（可以是預設大小的 0 到 300 百分比之間）。  
此屬性不僅屬於本序列，亦屬於父序列群組的所有序列——這是相應群組屬性的投射。因此此屬性為唯讀。  
使用 ParentSeriesGroup 屬性以存取父序列群組。  
使用 ParentSeriesGroup.BubbleSizeScale 可讀寫屬性來變更值。
