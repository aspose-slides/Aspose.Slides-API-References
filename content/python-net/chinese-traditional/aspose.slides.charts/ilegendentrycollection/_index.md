## ILegendEntryCollection 類別

表示圖例集合。

ILegendEntryCollection 型別公開下列成員：

## 屬性

| Property | Description |
| :- | :- |
| [`count`](/slides/python-net/zh-hant/aspose.slides.charts/ilegendentrycollection/count/) | 取得集合實際包含的元素數量。<br/>            唯讀 **int**. |

取得圖例項目的屬性，該項目對應於 Chart.ChartData.Series[0].DataPoints[index]，當圖表類型屬於下列清單時：
              ChartType.BarOfPie,
              ChartType.ExplodedPie,
              ChartType.ExplodedPie3D,
              ChartType.Pie,
              ChartType.Pie3D,
              ChartType.PieOfPie;
            或對於其他圖表類型，對應於 Chart.ChartData.Series[index]。
