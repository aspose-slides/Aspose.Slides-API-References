## TimeUnitType 列舉

表示類別軸的基礎單位

TimeUnitType 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| NONE | 值將照原樣顯示。 |
| DAYS | 指定圖表資料以天為單位顯示。 |
| MONTHS | 指定圖表資料以月為單位顯示。 |
| YEARS | 指定圖表資料以年為單位顯示。 |
