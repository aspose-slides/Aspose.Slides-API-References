## PictureType 列舉

確定條形圖圖片填充模式。

PictureType 類型提供以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| NOT_DEFINED | 未定義。 |
| STACK | 圖片大小會在最長的堆疊條形圖中重複最多 15 次。 |
| STACK_SCALE | 圖片大小設定為指定的單位數，並在條形圖的長度上重複。 |
| STRETCH | 圖片會被拉伸至堆疊條形圖的完整長度。 |
