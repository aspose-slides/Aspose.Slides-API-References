## IDataLabelFormat 類別

代表 DataLabel 的格式化選項。

IDataLabelFormat 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`is_number_format_linked_to_source`](/slides/python-net/zh-hant/aspose.slides.charts/idatalabelformat/is_number_format_linked_to_source/) | 可讀寫 **bool**. |
| [`number_format`](/slides/python-net/zh-hant/aspose.slides.charts/idatalabelformat/number_format/) | 代表 DataLabels 物件的格式字串。<br/>            可讀寫 **str**. |
| [`format`](/slides/python-net/zh-hant/aspose.slides.charts/idatalabelformat/format/) | 代表資料標籤的格式。<br/>            唯讀 [`IFormat`](/slides/python-net/zh-hant/aspose.slides.charts/iformat). |
| [`position`](/slides/python-net/zh-hant/aspose.slides.charts/idatalabelformat/position/) | 代表資料標籤的位置。<br/>            可讀寫 [`LegendDataLabelPosition`](/slides/python-net/zh-hant/aspose.slides.charts/legenddatalabelposition). |
| [`show_legend_key`](/slides/python-net/zh-hant/aspose.slides.charts/idatalabelformat/show_legend_key/) | 代表特定圖表的資料標籤圖例鍵顯示行為。 <br/>            如果資料標籤圖例鍵可見則為 True。<br/>            可讀寫 **bool**. |
| [`show_value`](/slides/python-net/zh-hant/aspose.slides.charts/idatalabelformat/show_value/) | 代表特定圖表的資料標籤百分比值顯示行為。 <br/>            True 顯示百分比值。False 隱藏。<br/>            可讀寫 **bool**. |
| [`show_category_name`](/slides/python-net/zh-hant/aspose.slides.charts/idatalabelformat/show_category_name/) | 代表特定圖表的資料標籤類別名稱顯示行為。<br/>            True 顯示類別名稱。False 隱藏。<br/>            可讀寫 **bool**. |
| [`show_series_name`](/slides/python-net/zh-hant/aspose.slides.charts/idatalabelformat/show_series_name/) | 返回或設定布林值，以指示圖表上資料標籤的系列名稱顯示行為。 <br/>            True 顯示系列名稱。False 隱藏。<br/>            可讀寫 **bool**. |
| [`show_percentage`](/slides/python-net/zh-hant/aspose.slides.charts/idatalabelformat/show_percentage/) | 代表特定圖表的資料標籤百分比值顯示行為。 <br/>            True 顯示百分比值。False 隱藏。<br/>            可讀寫 **bool**. |
| [`show_bubble_size`](/slides/python-net/zh-hant/aspose.slides.charts/idatalabelformat/show_bubble_size/) | 代表特定圖表的資料標籤氣泡大小值顯示行為。 <br/>            True 顯示氣泡大小值。False 隱藏。<br/>            可讀寫 **bool**. |
| [`show_leader_lines`](/slides/python-net/zh-hant/aspose.slides.charts/idatalabelformat/show_leader_lines/) | 代表特定圖表的資料標籤引導線顯示行為。 <br/>            True 顯示引導線。False 隱藏。<br/>            可讀寫 **bool**. |
| [`show_label_as_data_callout`](/slides/python-net/zh-hant/aspose.slides.charts/idatalabelformat/show_label_as_data_callout/) | 決定特定圖表的資料標籤將以資料註解或資料標籤方式顯示。<br/>            <br/>            如果此 DataLabelFormat 物件的父項是 DataLabelCollection（資料標籤集合），則此<br/>            屬性取得或設定 ShowLabelAsDataCallout 屬性的預設值，適用於 DataLabelCollection<br/>            中的新資料標籤。<br/>            設定此屬性值時，同時會將此值設定給 ShowLabelAsDataCallout 屬性<br/>            以套用於 DataLabelCollection 中的所有資料標籤<br/>            （例如 "DataLabels.DefaultDataLabelFormat.ShowLabelAsDataCallout = val;" 會使<br/>            所有 DataLabels[i].ShowLabelAsDataCallout 等於 val）。 |
| [`show_label_value_from_cell`](/slides/python-net/zh-hant/aspose.slides.charts/idatalabelformat/show_label_value_from_cell/) | 代表特定圖表的資料標籤儲存格值顯示行為。 <br/>            True 顯示儲存格值。False 隱藏。<br/>            可讀寫 **bool**. |
| [`separator`](/slides/python-net/zh-hant/aspose.slides.charts/idatalabelformat/separator/) | 設定或返回一個 Variant，代表圖表上資料標籤使用的分隔符號。<br/>            可讀寫 **str**. |
