## Legend 類別

代表圖表的圖例屬性。

Legend 類型揭露以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`x`](/slides/python-net/zh-hant/aspose.slides.charts/legend/x/) | 返回或設定圖例的 x 坐標，作為圖表寬度的比例。<br/>            讀寫 **float**. |
| [`y`](/slides/python-net/zh-hant/aspose.slides.charts/legend/y/) | 返回或設定圖例的 y 坐標，作為圖表高度的比例。<br/>            讀寫 **float**. |
| [`width`](/slides/python-net/zh-hant/aspose.slides.charts/legend/width/) | 返回或設定圖例的寬度，作為圖表寬度的比例。<br/>            讀寫 **float**. |
| [`height`](/slides/python-net/zh-hant/aspose.slides.charts/legend/height/) | 返回或設定圖例的高度，作為圖表高度的比例。<br/>            讀寫 **float**. |
| [`right`](/slides/python-net/zh-hant/aspose.slides.charts/legend/right/) | 右側。<br/>            唯讀 **float**. |
| [`bottom`](/slides/python-net/zh-hant/aspose.slides.charts/legend/bottom/) | 底部。<br/>            唯讀 **float**. |
| [`overlay`](/slides/python-net/zh-hant/aspose.slides.charts/legend/overlay/) | 決定是否允許其他圖表元素覆蓋圖例。<br/>            讀寫 **bool**. |
| [`text_format`](/slides/python-net/zh-hant/aspose.slides.charts/legend/text_format/) | 文字格式。<br/>            唯讀 [`IChartTextFormat`](/slides/python-net/zh-hant/aspose.slides.charts/icharttextformat). |
| [`position`](/slides/python-net/zh-hant/aspose.slides.charts/legend/position/) | 指定圖例在圖表上的位置。<br/>            非 NaN 的 X、Y、Width、Heigt 屬性值會覆蓋此屬性的效果。<br/>            讀寫 [`LegendPositionType`](/slides/python-net/zh-hant/aspose.slides.charts/legendpositiontype). |
| [`format`](/slides/python-net/zh-hant/aspose.slides.charts/legend/format/) | 返回圖例的格式。<br/>            唯讀 [`IFormat`](/slides/python-net/zh-hant/aspose.slides.charts/iformat). |
| [`chart`](/slides/python-net/zh-hant/aspose.slides.charts/legend/chart/) | 返回圖表。<br/>            唯讀 [`IChart`](/slides/python-net/zh-hant/aspose.slides.charts/ichart). |
| [`entries`](/slides/python-net/zh-hant/aspose.slides.charts/legend/entries/) | 取得圖例項目。<br/>            唯讀 [`ILegendEntryCollection`](/slides/python-net/zh-hant/aspose.slides.charts/ilegendentrycollection). |
| [`actual_x`](/slides/python-net/zh-hant/aspose.slides.charts/legend/actual_x/) | 指定圖表元素相對於圖表左上角的實際 x 位置（左）。<br/>            在取得實際值之前請先呼叫方法 IChart.ValidateChartLayout()。<br/>            讀 **float**. |
| [`actual_y`](/slides/python-net/zh-hant/aspose.slides.charts/legend/actual_y/) | 指定圖表元素相對於圖表左上角的實際上緣。<br/>            在取得實際值之前請先呼叫方法 IChart.ValidateChartLayout()。<br/>            讀 **float**. |
| [`actual_width`](/slides/python-net/zh-hant/aspose.slides.charts/legend/actual_width/) | 指定圖表元素的實際寬度。請先呼叫方法 IChart.ValidateChartLayout() 以取得實際值。<br/>            讀 **float**. |
| [`actual_height`](/slides/python-net/zh-hant/aspose.slides.charts/legend/actual_height/) | 指定圖表元素的實際高度。請先呼叫方法 IChart.ValidateChartLayout() 以取得實際值。<br/>            讀 **float**. |
