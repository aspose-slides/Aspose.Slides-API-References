## hide(self) {#}
將資料標籤預設設為隱藏，方法是將 DefaultDataLabelFormat 屬性的所有 Show*-旗標 (ShowValue, ...) 設為 false 狀態。IsVisible 於此之後會是 false。

```python
def hide(self):
    ...
```

### 備註

如果資料標籤預設不可見 (IsVisible 為 false)，可透過將 DefaultDataLabelFormat 屬性的 Show*-旗標 (ShowValue, ...) 設為 true 狀態，將資料標籤設為「預設可見」。
