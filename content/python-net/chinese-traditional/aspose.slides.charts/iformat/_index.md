## IFormat 類別

表示圖表格式屬性。

IFormat 類別公開以下成員：

## 屬性

| Property | 說明 |
| :- | :- |
| [`fill`](/slides/python-net/zh-hant/aspose.slides.charts/iformat/fill/) | 傳回圖表的填充樣式屬性。<br/>            只讀 [`IFillFormat`](/slides/python-net/zh-hant/aspose.slides/ifillformat)。 |
| [`line`](/slides/python-net/zh-hant/aspose.slides.charts/iformat/line/) | 傳回圖表的線條樣式屬性。<br/>            只讀 [`ILineFormat`](/slides/python-net/zh-hant/aspose.slides/ilineformat)。 |
| [`effect`](/slides/python-net/zh-hant/aspose.slides.charts/iformat/effect/) | 傳回圖表使用的效果。<br/>            只讀 [`IEffectFormat`](/slides/python-net/zh-hant/aspose.slides/ieffectformat)。 |
| [`effect_3d`](/slides/python-net/zh-hant/aspose.slides.charts/iformat/effect_3d/) | 傳回圖表的 3D 格式。<br/>            只讀 [`IThreeDFormat`](/slides/python-net/zh-hant/aspose.slides/ithreedformat)。 |
