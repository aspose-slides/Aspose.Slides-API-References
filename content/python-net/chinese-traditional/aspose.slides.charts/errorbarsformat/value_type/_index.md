## value_type 屬性
表示確定誤差棒長度的可能方式。  
若使用自訂值類型來指定值，請使用系列中 DataPoints 集合之特定資料點的 [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/zh-hant/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) 屬性。  
若使用 Fixed、Percentage 或 StandardDeviation 值類型，請使用 Value 屬性來指定值。  
讀寫 [`ErrorBarValueType`](/slides/python-net/zh-hant/aspose.slides.charts/errorbarvaluetype)。
