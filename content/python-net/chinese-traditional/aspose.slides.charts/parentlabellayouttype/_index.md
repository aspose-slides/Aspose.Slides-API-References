## ParentLabelLayoutType 列舉

表示類別資料標籤的版面配置。僅適用於 Treemap 系列。

ParentLabelLayoutType 類型公開以下成員：

## 欄位

| 欄位 | 描述 |
| :- | :- |
| BANNER | 指定父類別標籤以橫幅形式顯示 |
| NONE | 指定父類別標籤不會被繪製 |
| OVERLAPPING | 指定父類別標籤以重疊方式顯示 |
