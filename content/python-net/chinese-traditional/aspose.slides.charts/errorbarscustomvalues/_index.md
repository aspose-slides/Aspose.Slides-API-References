## ErrorBarsCustomValues 類別

指定誤差棒的值。僅當誤差棒值類型為 Custom 時才會使用。

ErrorBarsCustomValues 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`x_minus`](/slides/python-net/zh-hant/aspose.slides.charts/errorbarscustomvalues/x_minus/) | 指定負方向的誤差棒值。<br/>            若誤差棒值類型為 Custom 且允許 ErrorBarsXFormat，則可用。<br/>            在其他任何情況下，此屬性返回 None。<br/>            只讀 [`IDoubleChartValue`](/slides/python-net/zh-hant/aspose.slides.charts/idoublechartvalue). |
| [`y_minus`](/slides/python-net/zh-hant/aspose.slides.charts/errorbarscustomvalues/y_minus/) | 指定負方向的誤差棒值。<br/>            若誤差棒值類型為 Custom 且允許 ErrorBarsYFormat，則可用。<br/>            在其他任何情況下，此屬性返回 None。<br/>            只讀 [`IDoubleChartValue`](/slides/python-net/zh-hant/aspose.slides.charts/idoublechartvalue). |
| [`x_plus`](/slides/python-net/zh-hant/aspose.slides.charts/errorbarscustomvalues/x_plus/) | 指定正方向的誤差棒值。<br/>            若誤差棒值類型為 Custom 且允許 ErrorBarsXFormat，則可用。<br/>            在其他任何情況下，此屬性返回 None。<br/>            只讀 [`IDoubleChartValue`](/slides/python-net/zh-hant/aspose.slides.charts/idoublechartvalue). |
| [`y_plus`](/slides/python-net/zh-hant/aspose.slides.charts/errorbarscustomvalues/y_plus/) | 指定正方向的誤差棒值。<br/>            若誤差棒值類型為 Custom 且允許 ErrorBarsYFormat，則可用。<br/>            在其他任何情況下，此屬性返回 None。<br/>            只讀 [`IDoubleChartValue`](/slides/python-net/zh-hant/aspose.slides.charts/idoublechartvalue). |
