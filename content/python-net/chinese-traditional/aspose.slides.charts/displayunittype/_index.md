## DisplayUnitType 列舉

決定顯示資料的倍數。

DisplayUnitType 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| NONE | 值將原樣顯示。 |
| HUNDREDS | 指定圖表上的數值除以 100。 |
| THOUSANDS | 指定圖表上的數值除以 1,000。 |
| TEN_THOUSANDS | 指定圖表上的數值除以 10,000。 |
| HUNDRED_THOUSANDS | 指定圖表上的數值除以 100,000。 |
| MILLIONS | 指定圖表上的數值除以 1,000,000。 |
| TEN_MILLIONS | 指定圖表上的數值除以 10,000,000。 |
| HUNDRED_MILLIONS | 指定圖表上的數值除以 100,000,000。 |
| BILLIONS | 指定圖表上的數值除以 1,000,000,000。 |
| TRILLIONS | 指定圖表上的數值除以 1,000,000,000,000。 |
| CUSTOM_VALUE | 指定圖表上的數值除以自訂值。 |
