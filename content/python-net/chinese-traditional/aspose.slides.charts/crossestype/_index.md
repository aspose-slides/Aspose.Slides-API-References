## CrossesType 列舉

決定軸線將在何處交叉。

CrossesType 類型公開以下成員：

## 欄位

| Field | Description |
| :- | :- |
| AXIS_CROSSES_AT_ZERO | 類別軸在值軸的零點交叉（如果可能），或在最小值處交叉（如果最小值大於零），或在最大值處交叉（如果最大值小於零）。 |
| MAXIMUM | 軸在最大值處交叉。 |
| CUSTOM | 自訂來自屬性 CrossAt 的值 |
