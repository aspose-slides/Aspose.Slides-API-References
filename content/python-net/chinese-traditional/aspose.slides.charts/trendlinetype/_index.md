## TrendlineType 列舉

表示趨勢線的類型

TrendlineType 類型公開以下成員：

## 欄位

| 欄位 | 描述 |
| :- | :- |
| EXPONENTIAL | 指定趨勢線應為指數曲線的形式。 |
| LINEAR | 指定趨勢線應為直線的形式。 |
| LOGARITHMIC | 指定趨勢線應為對數曲線的形式，log 為自然對數。 |
| MOVING_AVERAGE | 指定趨勢線應為期間 Period 的移動平均。 |
| POLYNOMIAL | 指定趨勢線應為階數 Order 的多項式曲線的形式。 |
| POWER | 指定趨勢線應為冪曲線的形式。 |
