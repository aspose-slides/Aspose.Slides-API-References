## hide(self) {#}
將資料標籤隱藏，方法是將所有 Show*-flags (ShowValue, ...) 設為 false 狀態。
            IsVisible 會在之後為 false。


```python
def hide(self):
    ...
```


### 備註

如果資料標籤不可見 (IsVisible 為 false)，您可以透過將 Show*-flags (ShowValue, ...) 設為 true 狀態，使資料標籤可見。
