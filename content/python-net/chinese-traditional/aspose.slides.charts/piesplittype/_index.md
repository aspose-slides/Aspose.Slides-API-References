## PieSplitType 列舉

表示在餅圖或條形圖的子圖（餅圖中的餅圖或條形圖中的條形圖）中的第二個餅圖或條形圖的分割點類型。

PieSplitType 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| DEFAULT | 指定資料點將使用此圖表類型的預設<br/>            機制進行分割。 |
| CUSTOM | 指定資料點將根據自訂分割值在<br/>            餅圖和第二圖表之間分割。 |
| BY_PERCENTAGE | 指定資料點將透過將百分比小於<br/>            Split Position 百分比的點放入第二圖表，從而在餅圖和<br/>            第二圖表之間分割。 |
| BY_POS | 指定資料點將透過將資料點的最後<br/>            Split Position 放入第二圖表，從而在餅圖和<br/>            第二圖表之間分割。 |
| BY_VALUE | 指定資料點將透過將數值小於<br/>            Split Position 的資料點放入第二圖表，從而在餅圖和<br/>            第二圖表之間分割。 |
