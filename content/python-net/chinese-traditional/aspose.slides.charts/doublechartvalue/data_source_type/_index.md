## data_source_type 屬性
指定在衍生類別中實際使用 AsCell、AsCells、AsLiteralString 或 AsLiteralDouble 屬性。換句話說，它指定 Data 屬性的值類型。讀/寫 [`DataSourceType`](/slides/python-net/zh-hant/aspose.slides.charts/datasourcetype)。

### 備註

對於 ChartDataPointCollection 中的點，此屬性為唯讀。在此情況下，要變更此屬性的值，您可以使用 ChartDataPointCollection.DataSourceTypeFor<...> 屬性之一。
