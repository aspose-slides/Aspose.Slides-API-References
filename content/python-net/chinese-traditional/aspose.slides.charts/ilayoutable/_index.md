## ILayoutable 類別

指定圖表元件的確切位置。

ILayoutable 型別公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`x`](/slides/python-net/zh-hant/aspose.slides.charts/ilayoutable/x/) | 指定圖表元件的 x 位置（左側），以圖表寬度的比例表示。<br/>            可讀寫 **float**。 |
| [`y`](/slides/python-net/zh-hant/aspose.slides.charts/ilayoutable/y/) | 指定圖表元件的頂部位置，以圖表高度的比例表示。<br/>            可讀寫 **float**。 |
| [`width`](/slides/python-net/zh-hant/aspose.slides.charts/ilayoutable/width/) | 指定圖表元件的寬度，以圖表寬度的比例表示。<br/>            可讀寫 **float**。 |
| [`height`](/slides/python-net/zh-hant/aspose.slides.charts/ilayoutable/height/) | 指定圖表元件的高度，以圖表高度的比例表示。<br/>            可讀寫 **float**。 |
| [`right`](/slides/python-net/zh-hant/aspose.slides.charts/ilayoutable/right/) | 取得圖表元件的右側位置，以圖表寬度的比例表示。<br/>            唯讀 **float**。 |
| [`bottom`](/slides/python-net/zh-hant/aspose.slides.charts/ilayoutable/bottom/) | 取得圖表元件的頂部位置，以圖表高度的比例表示。<br/>            唯讀 **float**。 |
