## ITrendline 類別

類別表示圖表系列的趨勢線

ITrendline 類型公開以下成員：

## 屬性

| Property | Description |
| :- | :- |
| [`trendline_name`](/slides/python-net/zh-hant/aspose.slides.charts/itrendline/trendline_name/) | 取得或設定 趨勢線的名稱。<br/>            可讀寫 **str**. |
| [`trendline_type`](/slides/python-net/zh-hant/aspose.slides.charts/itrendline/trendline_type/) | 取得或設定 趨勢線的類型。<br/>            可讀寫 [`ITrendline.trendline_type`](/slides/python-net/zh-hant/aspose.slides.charts/itrendline/trendline_type). |
| [`format`](/slides/python-net/zh-hant/aspose.slides.charts/itrendline/format/) | 代表趨勢線的格式。<br/>            可讀寫 [`IFormat`](/slides/python-net/zh-hant/aspose.slides.charts/iformat). |
| [`backward`](/slides/python-net/zh-hant/aspose.slides.charts/itrendline/backward/) | 指定趨勢線在被趨勢化系列的資料之前延伸的類別（或散點圖上的單位）。<br/>            在散點圖與非散點圖上，該值必須為任何非負值。<br/>            可讀寫 **float**. |
| [`forward`](/slides/python-net/zh-hant/aspose.slides.charts/itrendline/forward/) | 指定趨勢線在被趨勢化系列的資料之後延伸的類別（或散點圖上的單位）。<br/>            在散點圖與非散點圖上，該值必須為任何非負值。<br/>            可讀寫 **float**. |
| [`intercept`](/slides/python-net/zh-hant/aspose.slides.charts/itrendline/intercept/) | 指定趨勢線交叉 y 軸的值。此屬性僅在趨勢線類型為 exp、linear 或 poly 時受支援。<br/>            可讀寫 **float**. |
| [`display_equation`](/slides/python-net/zh-hant/aspose.slides.charts/itrendline/display_equation/) | 指定在圖表上顯示趨勢線的方程式（與 Rsquaredvalue 同一標籤）。<br/>            可讀寫 **bool**. |
| [`order`](/slides/python-net/zh-hant/aspose.slides.charts/itrendline/order/) | 指定多項式趨勢線的階次。對其他趨勢線類型會被忽略。值必須在 2 到 6 之間。<br/>            可讀寫 **int**. |
| [`period`](/slides/python-net/zh-hant/aspose.slides.charts/itrendline/period/) | 指定移動平均趨勢線的期間。對其他趨勢線變體會被忽略。值必須在 2 到 255 之間。<br/>            可讀寫 **int**. |
| [`display_r_squared_value`](/slides/python-net/zh-hant/aspose.slides.charts/itrendline/display_r_squared_value/) | 指定在圖表上顯示趨勢線的 R-squared 值（與方程式同一標籤）。<br/>            可讀寫 **bool**. |
| [`related_legend_entry`](/slides/python-net/zh-hant/aspose.slides.charts/itrendline/related_legend_entry/) | 代表與此趨勢線相關聯的圖例項目<br/>            唯讀 [`ILegendEntryProperties`](/slides/python-net/zh-hant/aspose.slides.charts/ilegendentryproperties). |
| [`text_frame_for_overriding`](/slides/python-net/zh-hant/aspose.slides.charts/itrendline/text_frame_for_overriding/) |  |
| [`text_format`](/slides/python-net/zh-hant/aspose.slides.charts/itrendline/text_format/) |  |
