## DataSourceType 列舉

資料來源類型。

DataSourceType 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| WORKSHEET | 使用 CellXls 物件來儲存 XValue、YValue、Value 或 BubbleSize 的資料點至工作表。 |
| STRING_LITERALS | 使用快速存取的字串變數來儲存 XValue、YValue、Value 或 BubbleSize 的<br/>            資料點。工作表不會用於儲存值。 |
| DOUBLE_LITERALS | 使用快速存取的 double 變數來儲存 XValue、YValue、Value 或 BubbleSize 的<br/>            資料點。工作表不會用於儲存值。 |
