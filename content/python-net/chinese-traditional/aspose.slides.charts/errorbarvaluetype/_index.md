## ErrorBarValueType 列舉

表示誤差棒值的類型

ErrorBarValueType 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| CUSTOM | 指定誤差棒的長度應由 Plus 和 Minus 元素決定。 |
| FIXED | 指定誤差棒的長度應為由 Error Bar Value 所決定的固定值。 |
| PERCENTAGE | 指定誤差棒的長度應為資料的 Error Bar Value 百分比。 |
| STANDARD_DEVIATION | 指定誤差棒的長度應為資料的 Error Bar Value 標準差倍數。 |
| STANDARD_ERROR | 指定誤差棒的長度應為資料的 Error Bar Value 標準誤差。 |
