## IChartParagraphFormat 類別

表示圖表的段落格式屬性。

IChartParagraphFormat 類型提供以下成員：

## 屬性

| Property | Description |
| :- | :- |
| [`alignment`](/slides/python-net/zh-hant/aspose.slides.charts/ichartparagraphformat/alignment/) | 返回或設定段落中的文字對齊方式。<br/>            可讀寫 [`TextAlignment`](/slides/python-net/zh-hant/aspose.slides/textalignment). |
| [`space_within`](/slides/python-net/zh-hant/aspose.slides.charts/ichartparagraphformat/space_within/) | 返回或設定段落中基線之間的間距。<br/>            可讀寫 **float**. |
| [`space_before`](/slides/python-net/zh-hant/aspose.slides.charts/ichartparagraphformat/space_before/) | 返回或設定段落中第一行之前的間距。<br/>            可讀寫 **float**. |
| [`space_after`](/slides/python-net/zh-hant/aspose.slides.charts/ichartparagraphformat/space_after/) | 返回或設定段落中最後一行之後的間距。<br/>            可讀寫 **float**. |
| [`east_asian_line_break`](/slides/python-net/zh-hant/aspose.slides.charts/ichartparagraphformat/east_asian_line_break/) | 判斷段落是否使用東亞換行。<br/>            可讀寫 [`NullableBool`](/slides/python-net/zh-hant/aspose.slides/nullablebool). |
| [`right_to_left`](/slides/python-net/zh-hant/aspose.slides.charts/ichartparagraphformat/right_to_left/) | 判斷段落是否使用由右至左書寫。<br/>            可讀寫 [`NullableBool`](/slides/python-net/zh-hant/aspose.slides/nullablebool). |
| [`latin_line_break`](/slides/python-net/zh-hant/aspose.slides.charts/ichartparagraphformat/latin_line_break/) | 判斷段落是否使用拉丁換行。<br/>            可讀寫 [`NullableBool`](/slides/python-net/zh-hant/aspose.slides/nullablebool). |
| [`hanging_punctuation`](/slides/python-net/zh-hant/aspose.slides.charts/ichartparagraphformat/hanging_punctuation/) | 判斷段落是否使用懸掛標點。<br/>            可讀寫 [`NullableBool`](/slides/python-net/zh-hant/aspose.slides/nullablebool). |
| [`margin_left`](/slides/python-net/zh-hant/aspose.slides.charts/ichartparagraphformat/margin_left/) | 返回或設定段落的左邊距。<br/>            可讀寫 **float**. |
| [`margin_right`](/slides/python-net/zh-hant/aspose.slides.charts/ichartparagraphformat/margin_right/) | 返回或設定段落的右邊距。<br/>            可讀寫 **float**. |
| [`indent`](/slides/python-net/zh-hant/aspose.slides.charts/ichartparagraphformat/indent/) | 返回或設定段落的首行縮排/懸掛縮排。懸掛縮排可使用負值。<br/>            可讀寫 **float**. |
| [`default_tab_size`](/slides/python-net/zh-hant/aspose.slides.charts/ichartparagraphformat/default_tab_size/) | 返回或設定預設定位點大小。<br/>            可讀寫 **float**. |
| [`tabs`](/slides/python-net/zh-hant/aspose.slides.charts/ichartparagraphformat/tabs/) | 返回段落的定位點。<br/>            唯讀 [`ITabCollection`](/slides/python-net/zh-hant/aspose.slides/itabcollection). |
| [`font_alignment`](/slides/python-net/zh-hant/aspose.slides.charts/ichartparagraphformat/font_alignment/) | 返回或設定段落中的字型對齊方式。<br/>            可讀寫 [`FontAlignment`](/slides/python-net/zh-hant/aspose.slides/fontalignment). |
