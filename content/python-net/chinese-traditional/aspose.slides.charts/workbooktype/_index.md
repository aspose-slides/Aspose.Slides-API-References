## WorkbookType 列舉

指定 Open XML 工作簿檔案的類型。

WorkbookType 類型會公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| NOT_DEFINED | 未定義工作簿類型。 |
| WORKBOOK | Excel 工作簿 (*.xlsx)。 |
| WORKBOOK_MACRO | 支援巨集的 Excel 工作簿 (*.xlsm)。 |
| TEMPLATE | Excel 範本 (*.xltx)。 |
| TEMPLATE_MACRO | 支援巨集的 Excel 範本 (*.xltm)。 |
| WORKBOOK_BINARY_MACRO | 支援巨集的二進位 Excel 工作簿 (*.xlsb)。 |
