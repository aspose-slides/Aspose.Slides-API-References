## TickLabelPositionType 列舉

表示指定軸上刻度標籤的位置類型。

TickLabelPositionType 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| HIGH | 指定軸標籤應位於垂直軸的高端。 |
| LOW | 指定軸標籤應位於垂直軸的低端。 |
| NEXT_TO | 指定軸標籤應位於軸的旁邊。 |
| NONE | 指定軸標籤不會被繪製。 |
