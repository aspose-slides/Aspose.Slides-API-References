## IActualLayout 類別

指定圖表元素的實際位置。

IActualLayout 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`actual_x`](/slides/python-net/zh-hant/aspose.slides.charts/iactuallayout/actual_x/) | 指定圖表元素相對於圖表左上角的實際 x 位置（左側）。<br/>            呼叫方法 IChart.ValidateChartLayout() 以取得實際值。 <br/>            讀取 **float**。 |
| [`actual_y`](/slides/python-net/zh-hant/aspose.slides.charts/iactuallayout/actual_y/) | 指定圖表元素相對於圖表左上角的實際上方位置。<br/>            呼叫方法 IChart.ValidateChartLayout() 以取得實際值。 <br/>            讀取 **float**。 |
| [`actual_width`](/slides/python-net/zh-hant/aspose.slides.charts/iactuallayout/actual_width/) | 指定圖表元素的實際寬度。呼叫方法 IChart.ValidateChartLayout() 以取得實際值。 <br/>            讀取 **float**。 |
| [`actual_height`](/slides/python-net/zh-hant/aspose.slides.charts/iactuallayout/actual_height/) | 指定圖表元素的實際高度。呼叫方法 IChart.ValidateChartLayout() 以取得實際值。 <br/>            讀取 **float**。 |
