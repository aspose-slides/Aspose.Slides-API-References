## hide(self) {#}
預設將資料標籤設為隱藏，方法是將 DefaultDataLabelFormat 屬性的所有 Show*-旗標（如 ShowValue 等）設為 false 狀態。  
IsVisible 將為 false。

```python
def hide(self):
    ...
```

### 備註
如果資料標籤預設不可見（IsVisible 為 false），您可以透過將 DefaultDataLabelFormat 屬性的 Show*-旗標（如 ShowValue 等）設為 true，將資料標籤設為「預設可見」。
