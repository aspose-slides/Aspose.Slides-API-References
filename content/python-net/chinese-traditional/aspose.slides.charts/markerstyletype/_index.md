## MarkerStyleType 列舉

決定圖表資料點上標記的形狀。

MarkerStyleType 型別會公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| NOT_DEFINED |  |
| CIRCLE | 指定在每個資料點上繪製一個圓形。 |
| DASH | 指定在每個資料點上繪製一條虛線。 |
| DIAMOND | 指定在每個資料點上繪製一個菱形。 |
| DOT | 指定在每個資料點上繪製一個點。 |
| NONE | 指定在每個資料點上不繪製任何東西。 |
| PICTURE | 指定在每個資料點上繪製一張圖片。 |
| PLUS | 指定在每個資料點上繪製一個加號。 |
| SQUARE | 指定在每個資料點上繪製一個方形。 |
| STAR | 指定在每個資料點上繪製一個星形。 |
| TRIANGLE | 指定在每個資料點上繪製一個三角形。 |
| X | 指定在每個資料點上繪製一個 X 符號。 |
