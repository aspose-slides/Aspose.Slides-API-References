## IChartTextBlockFormat 類別

表示圖表文字元素的格式屬性。

IChartTextBlockFormat 類型公開以下成員：

## 屬性

| 屬性 | 描述 |
| :- | :- |
| [`anchoring_type`](/slides/python-net/zh-hant/aspose.slides.charts/icharttextblockformat/anchoring_type/) | 取得或設定 TextFrame 中的垂直錨點文字。<br/>            讀寫 [`TextAnchorType`](/slides/python-net/zh-hant/aspose.slides/textanchortype)。 |
| [`center_text`](/slides/python-net/zh-hant/aspose.slides.charts/icharttextblockformat/center_text/) | 如果 NullableBool.True，則文字應水平置中於方框內。<br/>            讀寫 [`NullableBool`](/slides/python-net/zh-hant/aspose.slides/nullablebool)。 |
| [`text_vertical_type`](/slides/python-net/zh-hant/aspose.slides.charts/icharttextblockformat/text_vertical_type/) | 決定文字方向。<br/>            此屬性與屬性 RotationAngle 中的自訂角度彙總的視覺文字旋轉的最終值。<br/>            讀寫 [`TextVerticalType`](/slides/python-net/zh-hant/aspose.slides/textverticaltype)。 |
| [`margin_left`](/slides/python-net/zh-hant/aspose.slides.charts/icharttextblockformat/margin_left/) | 取得或設定 TextFrame 中的左邊距（points）。<br/>            變更此屬性僅會對以下圖表部分產生特定影響： <br/>            DataLabel 與 DataLabelFormat（在 PowerPoint 2013 中提供完整支援；在 PowerPoint 2007 中對呈現無效）。<br/>            讀寫 **float**。 |
| [`margin_right`](/slides/python-net/zh-hant/aspose.slides.charts/icharttextblockformat/margin_right/) | 取得或設定 TextFrame 中的右邊距（points）。<br/>            變更此屬性僅會對以下圖表部分產生特定影響： <br/>            DataLabel 與 DataLabelFormat（在 PowerPoint 2013 中提供完整支援；在 PowerPoint 2007 中對呈現無效）。<br/>            讀寫 **float**。 |
| [`margin_top`](/slides/python-net/zh-hant/aspose.slides.charts/icharttextblockformat/margin_top/) | 取得或設定 TextFrame 中的上邊距（points）。<br/>            變更此屬性僅會對以下圖表部分產生特定影響： <br/>            DataLabel 與 DataLabelFormat（在 PowerPoint 2013 中提供完整支援；在 PowerPoint 2007 中對呈現無效）。<br/>            讀寫 **float**。 |
| [`margin_bottom`](/slides/python-net/zh-hant/aspose.slides.charts/icharttextblockformat/margin_bottom/) | 取得或設定 TextFrame 中的下邊距（points）。<br/>            變更此屬性僅會對以下圖表部分產生特定影響： <br/>            DataLabel 與 DataLabelFormat（在 PowerPoint 2013 中提供完整支援；在 PowerPoint 2007 中對呈現無效）。<br/>            讀寫 **float**。 |
| [`wrap_text`](/slides/python-net/zh-hant/aspose.slides.charts/icharttextblockformat/wrap_text/) | **True** 如果文字在 TextFrame 的邊緣自動換行。<br/>            變更此屬性僅會對以下圖表部分產生特定影響： <br/>            DataLabel 與 DataLabelFormat（在 PowerPoint 2007/2013 中提供完整支援）。<br/>            讀寫 [`NullableBool`](/slides/python-net/zh-hant/aspose.slides/nullablebool)。 |
| [`autofit_type`](/slides/python-net/zh-hant/aspose.slides.charts/icharttextblockformat/autofit_type/) | 取得或設定 文字的自動適應模式。<br/>            變更此屬性僅會對以下圖表部分產生特定影響： <br/>            DataLabel 與 DataLabelFormat（在 PowerPoint 2013 中提供完整支援；在 PowerPoint 2007 中對呈現無效）。<br/>            讀寫 [`TextAutofitType`](/slides/python-net/zh-hant/aspose.slides/textautofittype)。 |
| [`rotation_angle`](/slides/python-net/zh-hant/aspose.slides.charts/icharttextblockformat/rotation_angle/) | 指定套用於文字於邊界框內的自訂旋轉。若未指定<br/>            伴隨圖形的旋轉將被使用。若已指定，則此旋轉<br/>            獨立於圖形。也就是說，圖形可以有旋轉，同時文字本身也會有旋轉。<br/>            從此屬性與屬性 TextVerticalType 中的預定義垂直類型彙總的視覺文字旋轉的最終值。<br/>            讀寫 **float**。 |
