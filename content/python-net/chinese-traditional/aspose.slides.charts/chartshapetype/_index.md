## ChartShapeType 列舉

表示圖表的形狀。

ChartShapeType 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| NOT_DEFINED | 圖表形狀未定義。 |
| BOX | 指定圖表應以方框形狀繪製。 |
| CONE | 指定圖表應繪製為圓錐形，圓錐的底部位於底部，圓錐的尖端位於資料標記的上方。 |
| CONE_TO_MAX | 指定圖表應繪製為截斷圓錐，使圓錐的尖端為最大資料值。 |
| CYLINDER | 指定圖表應以圓柱體繪製。 |
| PYRAMID | 指定圖表應繪製為矩形金字塔，金字塔的底部位於底部，金字塔的尖端位於資料標記的上方。 |
| PYRAMID_TO_MAXIMUM | 指定圖表應繪製為截斷的金字塔，使金字塔的尖端為最大資料值。 |
