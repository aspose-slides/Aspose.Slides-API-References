## TickMarkType 列舉

代表指定軸的刻度線類型。

TickMarkType 類型公開以下成員：

## 欄位

| 欄位 | 描述 |
| :- | :- |
| CROSS | 指定刻度線應該交叉軸。 |
| INSIDE | 指定刻度線應該位於繪圖區內部。 |
| NONE | 指定不應有刻度線。 |
| OUTSIDE | 指定刻度線應該位於繪圖區外部。 |
