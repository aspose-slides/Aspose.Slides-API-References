| 屬性 | 描述 |
| :- | :- |
| [`accumulate`](/slides/python-net/zh-hant/aspose.slides.animation/filtereffect/accumulate/) | 表示是否累積動畫行為。<br/>            可讀寫 [`NullableBool`](/slides/python-net/zh-hant/aspose.slides/nullablebool)。 |

| [`reveal`](/slides/python-net/zh-hant/aspose.slides.animation/filtereffect/reveal/) | 表示帶有行為的效果必須顯示（進入/退出）。<br/>            可讀寫 [`FilterEffectRevealType`](/slides/python-net/zh-hant/aspose.slides.animation/filtereffectrevealtype)。 |
| [`type`](/slides/python-net/zh-hant/aspose.slides.animation/filtereffect/type/) | 表示濾鏡效果的類型。<br/>            可讀寫 [`FilterEffectType`](/slides/python-net/zh-hant/aspose.slides.animation/filtereffecttype)。 |
| [`subtype`](/slides/python-net/zh-hant/aspose.slides.animation/filtereffect/subtype/) | 表示濾鏡效果的子類型。<br/>            可讀寫 [`FilterEffectSubtype`](/slides/python-net/zh-hant/aspose.slides.animation/filtereffectsubtype)。 |
