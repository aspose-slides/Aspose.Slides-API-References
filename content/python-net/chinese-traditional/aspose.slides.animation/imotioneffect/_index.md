## IMotionEffect 類別

代表效果的動作效果行為。

IMotionEffect 類型公開以下成員：

## 屬性

| Property | Description |
| :- | :- |
| [`from_address`](/slides/python-net/zh-hant/aspose.slides.animation/imotioneffect/from_address/) | 指定動畫起始的 x/y 坐標（以百分比表示）。<br/>            可讀寫 **aspose.slides.PointF**。 |
| [`to`](/slides/python-net/zh-hant/aspose.slides.animation/imotioneffect/to/) | 指定動畫動作效果的目標位置（以百分比表示）。<br/>            可讀寫 **aspose.slides.PointF**。 |
| [`by`](/slides/python-net/zh-hant/aspose.slides.animation/imotioneffect/by/) | 描述動畫的相對偏移值（以百分比表示）。<br/>            可讀寫 **aspose.slides.PointF**。 |
| [`rotation_center`](/slides/python-net/zh-hant/aspose.slides.animation/imotioneffect/rotation_center/) | 描述用於將運動路徑繞 X 角度旋轉的中心點。<br/>            可讀寫 **aspose.slides.PointF**。 |
| [`origin`](/slides/python-net/zh-hant/aspose.slides.animation/imotioneffect/origin/) | 指定運動路徑的原點相對於什麼，例如投影片的版面配置，<br/>            或父項。<br/>            可讀寫 [`MotionOriginType`](/slides/python-net/zh-hant/aspose.slides.animation/motionorigintype)。 |
| [`path`](/slides/python-net/zh-hant/aspose.slides.animation/imotioneffect/path/) | 指定動畫動作的路徑原語及其座標。<br/>            可讀寫 [`IMotionPath`](/slides/python-net/zh-hant/aspose.slides.animation/imotionpath)。 |
| [`path_edit_mode`](/slides/python-net/zh-hant/aspose.slides.animation/imotioneffect/path_edit_mode/) | 指定形狀移動時運動路徑的移動方式。<br/>            可讀寫 [`MotionPathEditMode`](/slides/python-net/zh-hant/aspose.slides.animation/motionpatheditmode)。 |
| [`angle`](/slides/python-net/zh-hant/aspose.slides.animation/imotioneffect/angle/) | 描述運動路徑的相對角度。<br/>            可讀寫 **float**。 |
