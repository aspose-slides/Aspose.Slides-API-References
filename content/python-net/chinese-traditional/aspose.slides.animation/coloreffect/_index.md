## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`accumulate`](/slides/python-net/zh-hant/aspose.slides.animation/coloreffect/accumulate/) | 表示是否累積動畫行為。<br/>            讀寫 [`NullableBool`](/slides/python-net/zh-hant/aspose.slides/nullablebool). |
| [`additive`](/slides/python-net/zh-hant/aspose.slides.animation/coloreffect/additive/) | 表示目前的動畫行為是否與其他執行中的動畫結合。<br/>            讀寫 [`BehaviorAdditiveType`](/slides/python-net/zh-hant/aspose.slides.animation/behavioradditivetype). |
| [`properties`](/slides/python-net/zh-hant/aspose.slides.animation/coloreffect/properties/) | 表示行為的屬性。<br/>            唯讀 [`IBehaviorPropertyCollection`](/slides/python-net/zh-hant/aspose.slides.animation/ibehaviorpropertycollection). |
| [`timing`](/slides/python-net/zh-hant/aspose.slides.animation/coloreffect/timing/) | 表示效果行為的時間屬性。<br/>            讀寫 [`ITiming`](/slides/python-net/zh-hant/aspose.slides.animation/itiming). |
| [`from_address`](/slides/python-net/zh-hant/aspose.slides.animation/coloreffect/from_address/) | 此值用於指定行為的起始顏色。<br/>            讀寫 [`IColorFormat`](/slides/python-net/zh-hant/aspose.slides/icolorformat). |
| [`to`](/slides/python-net/zh-hant/aspose.slides.animation/coloreffect/to/) | 描述動畫顏色變化的結果顏色。<br/>            讀寫 [`IColorFormat`](/slides/python-net/zh-hant/aspose.slides/icolorformat). |
| [`by`](/slides/python-net/zh-hant/aspose.slides.animation/coloreffect/by/) | 描述顏色動畫的相對偏移值。<br/>            讀寫 [`IColorOffset`](/slides/python-net/zh-hant/aspose.slides.animation/icoloroffset). |
| [`color_space`](/slides/python-net/zh-hant/aspose.slides.animation/coloreffect/color_space/) | 表示行為的色彩空間。<br/>            讀寫 [`ColorSpace`](/slides/python-net/zh-hant/aspose.slides.animation/colorspace). |
| [`direction`](/slides/python-net/zh-hant/aspose.slides.animation/coloreffect/direction/) | 指定在色相環上循環色相的方向。<br/>            讀寫 [`ColorDirection`](/slides/python-net/zh-hant/aspose.slides.animation/colordirection). |
