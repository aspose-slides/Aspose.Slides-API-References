## IEffect class

表示動畫效果。

IEffect 類型公開以下成員：

## 屬性

| 屬性 | 描述 |
| :- | :- |
| [`sequence`](/slides/python-net/zh-hant/aspose.slides.animation/ieffect/sequence/) | 傳回效果的序列。<br/>            唯讀 [`ISequence`](/slides/python-net/zh-hant/aspose.slides.animation/isequence). |
| [`text_animation`](/slides/python-net/zh-hant/aspose.slides.animation/ieffect/text_animation/) | 傳回文字動畫。<br/>            唯讀 [`ITextAnimation`](/slides/python-net/zh-hant/aspose.slides.animation/itextanimation). |
| [`preset_class_type`](/slides/python-net/zh-hant/aspose.slides.animation/ieffect/preset_class_type/) | 定義效果的類別。<br/>            可讀寫 [`EffectPresetClassType`](/slides/python-net/zh-hant/aspose.slides.animation/effectpresetclasstype). |
| [`type`](/slides/python-net/zh-hant/aspose.slides.animation/ieffect/type/) | 定義效果的類型。<br/>            可讀寫 [`EffectType`](/slides/python-net/zh-hant/aspose.slides.animation/effecttype). |
| [`subtype`](/slides/python-net/zh-hant/aspose.slides.animation/ieffect/subtype/) | 定義效果的子類型。<br/>            可讀寫 [`EffectSubtype`](/slides/python-net/zh-hant/aspose.slides.animation/effectsubtype). |
| [`behaviors`](/slides/python-net/zh-hant/aspose.slides.animation/ieffect/behaviors/) | 傳回效果的行為集合。<br/>            可讀寫 [`IBehaviorCollection`](/slides/python-net/zh-hant/aspose.slides.animation/ibehaviorcollection). |
| [`timing`](/slides/python-net/zh-hant/aspose.slides.animation/ieffect/timing/) | 定義效果的時間值。<br/>            可讀寫 [`ITiming`](/slides/python-net/zh-hant/aspose.slides.animation/itiming). |
| [`target_shape`](/slides/python-net/zh-hant/aspose.slides.animation/ieffect/target_shape/) | 傳回效果的目標形狀。<br/>            唯讀 [`IShape`](/slides/python-net/zh-hant/aspose.slides/ishape). |
| [`sound`](/slides/python-net/zh-hant/aspose.slides.animation/ieffect/sound/) | 定義效果的內嵌聲音。<br/>            可讀寫 [`IAudio`](/slides/python-net/zh-hant/aspose.slides/iaudio). |
| [`stop_previous_sound`](/slides/python-net/zh-hant/aspose.slides.animation/ieffect/stop_previous_sound/) | 此屬性指定動畫效果是否停止先前的聲音。<br/>            可讀寫 **bool**. |
| [`after_animation_type`](/slides/python-net/zh-hant/aspose.slides.animation/ieffect/after_animation_type/) | 定義效果的後置動畫類型。<br/>            可讀寫 [`IEffect.after_animation_type`](/slides/python-net/zh-hant/aspose.slides.animation/ieffect/after_animation_type). |
| [`after_animation_color`](/slides/python-net/zh-hant/aspose.slides.animation/ieffect/after_animation_color/) | 定義效果的後置動畫顏色。<br/>            可讀寫 [`IColorFormat`](/slides/python-net/zh-hant/aspose.slides/icolorformat). |
| [`animate_text_type`](/slides/python-net/zh-hant/aspose.slides.animation/ieffect/animate_text_type/) | 定義效果的文字動畫類型。<br/>            形狀文字可以逐字、逐詞或一次全部動畫。<br/>            可讀寫 [`IEffect.animate_text_type`](/slides/python-net/zh-hant/aspose.slides.animation/ieffect/animate_text_type). |
| [`delay_between_text_parts`](/slides/python-net/zh-hant/aspose.slides.animation/ieffect/delay_between_text_parts/) | 定義動畫文字部份（字或詞）之間的延遲。<br/>            正值指定效果持續時間的百分比。<br/>            負值指定以秒為單位的延遲。<br/>            可讀寫 **float**. |
