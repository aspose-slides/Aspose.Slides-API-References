## 屬性

| 屬性 | 描述 |
| :- | :- |
| [`accumulate`](/slides/python-net/zh-hant/aspose.slides.animation/scaleeffect/accumulate/) | 表示是否累積動畫行為。<br/>            讀/寫 [`NullableBool`](/slides/python-net/zh-hant/aspose.slides/nullablebool). |
| [`additive`](/slides/python-net/zh-hant/aspose.slides.animation/scaleeffect/additive/) | 表示目前的動畫行為是否與其他執行中的動畫結合。<br/>            讀/寫 [`BehaviorAdditiveType`](/slides/python-net/zh-hant/aspose.slides.animation/behavioradditivetype). |
| [`properties`](/slides/python-net/zh-hant/aspose.slides.animation/scaleeffect/properties/) | 表示行為的屬性。<br/>            唯讀 [`IBehaviorPropertyCollection`](/slides/python-net/zh-hant/aspose.slides.animation/ibehaviorpropertycollection). |
| [`timing`](/slides/python-net/zh-hant/aspose.slides.animation/scaleeffect/timing/) | 表示效果行為的時間屬性。<br/>            讀/寫 [`ITiming`](/slides/python-net/zh-hant/aspose.slides.animation/itiming). |
| [`zoom_content`](/slides/python-net/zh-hant/aspose.slides.animation/scaleeffect/zoom_content/) | 決定內容是否應該縮放。<br/>            讀/寫 [`NullableBool`](/slides/python-net/zh-hant/aspose.slides/nullablebool). |
| [`from_address`](/slides/python-net/zh-hant/aspose.slides.animation/scaleeffect/from_address/) | 指定動畫起始的 x/y 座標（以百分比表示）。<br/>            讀/寫 [`PointF`](/slides/python-net/zh-hant/aspose.slides/pointf). |
| [`to`](/slides/python-net/zh-hant/aspose.slides.animation/scaleeffect/to/) | 指定動畫縮放效果的目標位置（以百分比表示）。<br/>            讀/寫 [`PointF`](/slides/python-net/zh-hant/aspose.slides/pointf). |
| [`by`](/slides/python-net/zh-hant/aspose.slides.animation/scaleeffect/by/) | 描述動畫的相對偏移值（以百分比表示）。<br/>            讀/寫 [`PointF`](/slides/python-net/zh-hant/aspose.slides/pointf). |
