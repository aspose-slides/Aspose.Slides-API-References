## BuildType 列舉

## 欄位

| 欄位 | 說明 |
| :- | :- |
| AS_ONE_OBJECT | 與包含的形狀一起。 |
| ALL_PARAGRAPHS_AT_ONCE | 所有段落。 |
| BY_LEVEL_PARAGRAPHS1 | 依深度 1 的段落群組。 |
| BY_LEVEL_PARAGRAPHS2 | 依深度 2 的段落群組。 |
| BY_LEVEL_PARAGRAPHS3 | 依深度 3 的段落群組。 |
