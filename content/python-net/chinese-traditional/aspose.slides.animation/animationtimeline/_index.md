## AnimationTimeLine 類別

代表動畫的時間線。

AnimationTimeLine 類型會公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`interactive_sequences`](/slides/python-net/zh-hant/aspose.slides.animation/animationtimeline/interactive_sequences/) | 傳回互動序列的集合。<br/>            此序列可能僅包含透過「click on shape」且指定目標形狀的效果。<br/>            唯讀 [`ISequenceCollection`](/slides/python-net/zh-hant/aspose.slides.animation/isequencecollection)。 |
| [`main_sequence`](/slides/python-net/zh-hant/aspose.slides.animation/animationtimeline/main_sequence/) | 傳回主序列，該序列可能僅包含主要效果集合。<br/>            唯讀 [`ISequence`](/slides/python-net/zh-hant/aspose.slides.animation/isequence)。 |
| [`text_animation_collection`](/slides/python-net/zh-hant/aspose.slides.animation/animationtimeline/text_animation_collection/) | 傳回文字動畫的集合。<br/>            唯讀 [`ITextAnimationCollection`](/slides/python-net/zh-hant/aspose.slides.animation/itextanimationcollection)。 |
