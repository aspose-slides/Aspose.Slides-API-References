## AfterAnimationType 列舉

表示動畫效果的後置動畫類型。

AfterAnimationType 類型提供以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| DO_NOT_DIM | 動畫完成後不變暗。 |
| COLOR | 動畫完成後的顏色。 |
| HIDE_AFTER_ANIMATION | 動畫完成後隱藏。 |
| HIDE_ON_NEXT_MOUSE_CLICK | 在下一次滑鼠點擊時隱藏。 |
