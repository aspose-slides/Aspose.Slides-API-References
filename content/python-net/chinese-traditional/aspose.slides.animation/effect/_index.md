## Effect 類別

表示動畫效果。

Effect 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`sequence`](/slides/python-net/zh-hant/aspose.slides.animation/effect/sequence/) | 傳回效果的序列。<br/>            唯讀 [`ISequence`](/slides/python-net/zh-hant/aspose.slides.animation/isequence). |
| [`text_animation`](/slides/python-net/zh-hant/aspose.slides.animation/effect/text_animation/) | TextAnimation<br/>            唯讀 [`ITextAnimation`](/slides/python-net/zh-hant/aspose.slides.animation/itextanimation). |
| [`preset_class_type`](/slides/python-net/zh-hant/aspose.slides.animation/effect/preset_class_type/) | 定義效果的類別。<br/>            讀寫 [`EffectPresetClassType`](/slides/python-net/zh-hant/aspose.slides.animation/effectpresetclasstype). |
| [`type`](/slides/python-net/zh-hant/aspose.slides.animation/effect/type/) | 定義效果的類型。<br/>            讀寫 [`EffectType`](/slides/python-net/zh-hant/aspose.slides.animation/effecttype). |
| [`subtype`](/slides/python-net/zh-hant/aspose.slides.animation/effect/subtype/) | 定義效果的子類型。<br/>            讀寫 [`EffectSubtype`](/slides/python-net/zh-hant/aspose.slides.animation/effectsubtype). |
| [`behaviors`](/slides/python-net/zh-hant/aspose.slides.animation/effect/behaviors/) | 傳回效果的行為集合。<br/>            讀寫 [`IBehaviorCollection`](/slides/python-net/zh-hant/aspose.slides.animation/ibehaviorcollection). |
| [`timing`](/slides/python-net/zh-hant/aspose.slides.animation/effect/timing/) | 定義效果的時間值。<br/>            讀寫 [`ITiming`](/slides/python-net/zh-hant/aspose.slides.animation/itiming). |
| [`target_shape`](/slides/python-net/zh-hant/aspose.slides.animation/effect/target_shape/) | 傳回效果的目標圖形。<br/>            唯讀 [`IShape`](/slides/python-net/zh-hant/aspose.slides/ishape). |
| [`sound`](/slides/python-net/zh-hant/aspose.slides.animation/effect/sound/) | 定義嵌入式音效於效果。<br/>            讀寫 [`IAudio`](/slides/python-net/zh-hant/aspose.slides/iaudio). |
| [`stop_previous_sound`](/slides/python-net/zh-hant/aspose.slides.animation/effect/stop_previous_sound/) | 此屬性指定動畫效果是否停止先前的音效。<br/>            讀寫 **bool**. |
| [`after_animation_type`](/slides/python-net/zh-hant/aspose.slides.animation/effect/after_animation_type/) | 定義效果的後續動畫類型。<br/>            讀寫 [`Effect.after_animation_type`](/slides/python-net/zh-hant/aspose.slides.animation/effect/after_animation_type). |
| [`after_animation_color`](/slides/python-net/zh-hant/aspose.slides.animation/effect/after_animation_color/) | 定義效果的後續動畫顏色。<br/>            讀寫 [`IColorFormat`](/slides/python-net/zh-hant/aspose.slides/icolorformat). |
| [`animate_text_type`](/slides/python-net/zh-hant/aspose.slides.animation/effect/animate_text_type/) | 定義效果的文字動畫類型。<br/>            形狀文字可按字母、單詞或一次全部動畫化。<br/>            讀寫 [`Effect.animate_text_type`](/slides/python-net/zh-hant/aspose.slides.animation/effect/animate_text_type). |
| [`delay_between_text_parts`](/slides/python-net/zh-hant/aspose.slides.animation/effect/delay_between_text_parts/) | 定義動畫文字部分（單詞或字母）之間的延遲。<br/>            正值指定效果持續時間的百分比。<br/>            負值指定以秒為單位的延遲。<br/>            讀寫 **float**. |
