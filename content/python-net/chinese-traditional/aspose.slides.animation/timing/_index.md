## Timing 類別

表示動畫計時。

Timing 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`accelerate`](/slides/python-net/zh-hant/aspose.slides.animation/timing/accelerate/) | 描述持續時間加速行為效果的百分比。<br/>            Read/write **float**. |
| [`decelerate`](/slides/python-net/zh-hant/aspose.slides.animation/timing/decelerate/) | 描述持續時間減速行為效果的百分比。<br/>            Read/write **float**. |
| [`auto_reverse`](/slides/python-net/zh-hant/aspose.slides.animation/timing/auto_reverse/) | 描述在正向播放後，是否自動以相反方向播放動畫。<br/>            在正向方向播放時。<br/>            Read/write **bool**. |
| [`duration`](/slides/python-net/zh-hant/aspose.slides.animation/timing/duration/) | 描述動畫效果的持續時間。<br/>            Read/write **float**. |
| [`repeat_count`](/slides/python-net/zh-hant/aspose.slides.animation/timing/repeat_count/) | 描述效果應重複的次數。<br/>            Read/write **float**. |
| [`repeat_until_end_slide`](/slides/python-net/zh-hant/aspose.slides.animation/timing/repeat_until_end_slide/) | 此屬性指定效果是否會持續重複至投影片結束。<br/>             Read/write **bool**. |
| [`repeat_until_next_click`](/slides/python-net/zh-hant/aspose.slides.animation/timing/repeat_until_next_click/) | 此屬性指定效果是否會持續重複至下一次點擊。<br/>             Read/write **bool**. |
| [`repeat_duration`](/slides/python-net/zh-hant/aspose.slides.animation/timing/repeat_duration/) | 描述效果應重複的次數。<br/>            Read/write **float**. |
| [`restart`](/slides/python-net/zh-hant/aspose.slides.animation/timing/restart/) | 指定效果在完成後是否重新開始。<br/>            Read/write [`EffectRestartType`](/slides/python-net/zh-hant/aspose.slides.animation/effectrestarttype). |
| [`rewind`](/slides/python-net/zh-hant/aspose.slides.animation/timing/rewind/) | 此屬性指定當播放完成時是否會倒帶效果。<br/>             Read/write **bool**. |
| [`speed`](/slides/python-net/zh-hant/aspose.slides.animation/timing/speed/) | 指定加速（或減速）計時的百分比。<br/>            Read/write **float**. |
| [`trigger_delay_time`](/slides/python-net/zh-hant/aspose.slides.animation/timing/trigger_delay_time/) | 描述觸發後的延遲時間。<br/>            Read/write **float**. |
| [`trigger_type`](/slides/python-net/zh-hant/aspose.slides.animation/timing/trigger_type/) | 描述觸發類型。<br/>            Read/write [`EffectTriggerType`](/slides/python-net/zh-hant/aspose.slides.animation/effecttriggertype). |
