## ITiming 類別

表示動畫計時。

ITiming 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`accelerate`](/slides/python-net/zh-hant/aspose.slides.animation/itiming/accelerate/) | 描述持續時間加速行為效果的百分比。<br/>            讀/寫 **float**. |
| [`decelerate`](/slides/python-net/zh-hant/aspose.slides.animation/itiming/decelerate/) | 描述持續時間減速行為效果的百分比。<br/>            讀/寫 **float**. |
| [`auto_reverse`](/slides/python-net/zh-hant/aspose.slides.animation/itiming/auto_reverse/) | 描述是否在正向播放後自動以相反方向播放動畫。<br/>            讀/寫 **bool**. |
| [`duration`](/slides/python-net/zh-hant/aspose.slides.animation/itiming/duration/) | 描述動畫效果的持續時間。<br/>            讀/寫 **float**. |
| [`repeat_count`](/slides/python-net/zh-hant/aspose.slides.animation/itiming/repeat_count/) | 描述效果應重複的次數。<br/>            讀/寫 **float**. |
| [`repeat_until_end_slide`](/slides/python-net/zh-hant/aspose.slides.animation/itiming/repeat_until_end_slide/) | 此屬性指定效果是否會持續重複至投影片結束。<br/>            讀/寫 **bool**. |
| [`repeat_until_next_click`](/slides/python-net/zh-hant/aspose.slides.animation/itiming/repeat_until_next_click/) | 此屬性指定效果是否會持續重複至下一次點擊。<br/>            讀/寫 **bool**. |
| [`repeat_duration`](/slides/python-net/zh-hant/aspose.slides.animation/itiming/repeat_duration/) | 描述效果應重複的次數。<br/>            讀/寫 **float**. |
| [`restart`](/slides/python-net/zh-hant/aspose.slides.animation/itiming/restart/) | 指定效果是否在完成後重新啟動。<br/>            讀/寫 [`EffectRestartType`](/slides/python-net/zh-hant/aspose.slides.animation/effectrestarttype). |
| [`speed`](/slides/python-net/zh-hant/aspose.slides.animation/itiming/speed/) | 指定計時加速（或減速）的百分比。<br/>            讀/寫 **float**. |
| [`trigger_delay_time`](/slides/python-net/zh-hant/aspose.slides.animation/itiming/trigger_delay_time/) | 描述觸發後的延遲時間。<br/>            讀/寫 **float**. |
| [`trigger_type`](/slides/python-net/zh-hant/aspose.slides.animation/itiming/trigger_type/) | 描述觸發類型。<br/>            讀/寫 [`EffectTriggerType`](/slides/python-net/zh-hant/aspose.slides.animation/effecttriggertype). |
| [`rewind`](/slides/python-net/zh-hant/aspose.slides.animation/itiming/rewind/) | 此屬性指定在播放完成後是否會倒帶效果。<br/>            讀/寫 **bool**. |
