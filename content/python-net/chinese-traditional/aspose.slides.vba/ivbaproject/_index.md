## IVbaProject 類別

代表具備簡報巨集的 VBA 專案。

IVbaProject 型別公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`name`](/slides/python-net/zh-hant/aspose.slides.vba/ivbaproject/name/) | 傳回 VBA 專案的名稱。<br/>            唯讀 **str**. |
| [`modules`](/slides/python-net/zh-hant/aspose.slides.vba/ivbaproject/modules/) | 傳回 VBA 專案中包含的所有模組清單。<br/>            唯讀 [`IVbaModuleCollection`](/slides/python-net/zh-hant/aspose.slides.vba/ivbamodulecollection). |
| [`references`](/slides/python-net/zh-hant/aspose.slides.vba/ivbaproject/references/) | 傳回 VBA 專案中包含的所有參考清單。<br/>            唯讀 [`IVbaReferenceCollection`](/slides/python-net/zh-hant/aspose.slides.vba/ivbareferencecollection). |
| [`is_password_protected`](/slides/python-net/zh-hant/aspose.slides.vba/ivbaproject/is_password_protected/) | 指示 VBAProject 是否受密碼保護，以檢視專案屬性。<br/>            唯讀 **bool**. |

## 方法

| 方法 | 說明 |
| :- | :- |
| [`to_binary(self)`](/slides/python-net/zh-hant/aspose.slides.vba/ivbaproject/to_binary/#) | 傳回 VBA 專案作為 OLE 容器的二進位表示。<br/>            唯讀 **int**[]. |
