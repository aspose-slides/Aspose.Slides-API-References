## skip_java_script_links 屬性
指定在儲存簡報時是否跳過帶有 JavaScript 呼叫的超連結。 
            讀/寫 **bool**。預設值為 **false** 。

### 備註

當此屬性設為 **true** 時，帶有 JavaScript 呼叫的超連結在儲存時會被忽略。

當此屬性設為 **false** 時，所有超連結皆會被儲存。
