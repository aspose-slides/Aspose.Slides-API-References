## x 屬性
取得或設定形狀左上角的 x 座標，以點為單位。
            Read/write **float**.


### 備註

返回的值始終是已定義的，且永不為 **float**。
            指定的值也必須是已定義的；僅將 **float** 指派給 `RawFrame` 實例的屬性。

### 定義：
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
