## InkEffectType 列舉

指定一組預先定義的墨水渲染視覺效果。  
每個效果對應一種紋理或圖像，用於模擬風格化的墨水外觀。  
這些值可用於在渲染過程中自訂數位墨水筆畫的視覺樣式。

InkEffectType 型別公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| NOT_DEFINED | 此效果未定義或未知。此值可作為預設或備援使用。 |
| BRONZE | 類似青銅墨水的溫暖、棕色金屬紋理。 |
| GALAXY | 類似星系的多彩、閃爍紋理，帶有宇宙色調。 |
| GOLD | 明亮的金屬金色紋理，賦予墨水筆畫奢華外觀。 |
| LAVA | 類似熔融岩漿的炙熱紋理，帶有紅色與橙色色調。 |
| OCEAN | 深藍色、類似液體的紋理，模仿海浪或水性墨水。 |
| RAINBOW_GLITTER | 用於節慶或鮮明墨水筆畫的多彩、閃亮彩虹亮粉效果。 |
| ROSE_GOLD | 柔和的粉金混合色，類似玫瑰金，用於優雅的墨水筆畫。 |
| SILVER | 冷色調的金屬銀色紋理，模擬經典銀墨。 |
