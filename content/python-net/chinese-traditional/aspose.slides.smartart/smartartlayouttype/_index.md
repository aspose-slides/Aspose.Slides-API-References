## SmartArtLayoutType 列舉

表示 SmartArt 圖表的版面類型。

SmartArtLayoutType 類型公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| ACCENT_PROCESS | 用於展示任務、流程或工作流中的進度、時間軸或連續步驟。適合說明第 1 級與第 2 級文字。 |
| ACCENTED_PICTURE | 用於在中心展示影像概念，旁邊配合相關概念。第 1 級文字顯示於中心圖片上方。其他第 1 級形狀的文字出現在小圓形圖片旁。此版面亦適用於無文字情況。 |
| ALTERNATING_FLOW | 用於展示任務、流程或工作流中的資訊群組或連續步驟。強調資訊群組之間的互動或關係。 |
| ALTERNATING_HEXAGONS | 用於表示一系列相互連結的概念。第 1 級文字位於六邊形內。第 2 級文字位於形狀外。 |
| ALTERNATING_PICTURE_BLOCKS | 用於從上至下展示一系列圖片。文字交替出現在圖片的右側或左側。 |
| ALTERNATING_PICTURE_CIRCLES | 用於展示一組帶文字的圖片。相應文字顯示於中心圓形內，圖片則交替排列於左至右。 |
| ARROW_RIBBON | 用於展示相關或對立概念以及其連結，例如相對的力量。第 1 級文字的前兩行用於箭頭內的文字。未使用的文字不會顯示，但在切換版面時仍可使用。 |
| ASCENDING_PICTURE_ACCENT_PROCESS | 用於展示一系列向上排列的圖片與說明文字。適合文字量較少的情況。 |
| BALANCE | 用於比較或顯示兩個概念之間的關係。第 1 級文字的前兩行分別對應於中心點左右兩側的上方文字。強調第 2 級文字，且每側最多四個形狀。平衡會傾向於第 2 級文字形狀較多的一側。未使用的文字不會顯示，但在切換版面時仍可使用。 |
| BASIC_BENDING_PROCESS | 用於展示任務、流程或工作流中的進度或連續步驟。最大化形狀的水平與垂直顯示空間。 |
| BASIC_BLOCK_LIST | 用於展示非連續或分組的資訊塊。最大化形狀的水平與垂直顯示空間。 |
| BASIC_CHEVRON_PROCESS | 用於展示進度、時間軸、任務、流程或工作流中的連續步驟，或強調移動或方向。第 1 級文字位於箭頭形狀內，第 2 級文字位於箭頭形狀下方。 |
| BASIC_CYCLE | 用於以環狀流程表示持續的階段、任務或事件序列。強調階段或步驟而非連接的箭頭或流程。最佳效果僅使用第 1 級文字。 |
| BASIC_MATRIX | 用於在四象限中顯示組件與整體的關係。第 1 級文字的前四行出現在各象限內。未使用的文字不會顯示，但在切換版面時仍可使用。 |
| BASIC_PIE | 用於展示各個部份如何組成整體。第 1 級文字的前七行對應於平均分佈的扇形或圓餅形狀。最上方的第 1 級文字形狀位於圓餅其餘部分之外以示強調。未使用的文字不會顯示，但在切換版面時仍可使用。 |
| BASIC_PROCESS | 用於展示任務、流程或工作流中的進度或連續步驟。 |
| BASIC_PYRAMID | 用於展示比例、相互關聯或分層關係，底部為最大組件，向上逐漸收窄。第 1 級文字位於金字塔各段落內，第 2 級文字位於每段旁側的形狀內。 |
| BASIC_RADIAL | 用於展示相對於中心概念的關係。第 1 級文字的第一行對應中心形狀，其第 2 級文字對應周圍的圓形。未使用的文字不會顯示，但在切換版面時仍可使用。 |
| BASIC_TARGET | 用於展示包含、分層或階層關係。第 1 級文字的前五行與一個圓形相關。未使用的文字不會顯示，但在切換版面時仍可使用。 |
| BASIC_TIMELINE | 用於展示任務、流程或工作流中的連續步驟，或呈現時間軸資訊。適合同時使用第 1 級與第 2 級文字。 |
| BASIC_VENN | 用於展示重疊或相互連結的關係。第 1 級文字的前七行對應一個圓形。若第 1 級文字行數 ≤4，文字位於圓形內；若 >4，文字位於圓形外。未使用的文字不會顯示，但在切換版面時仍可使用。 |
| BENDING_PICTURE_ACCENT_LIST | 用於展示非連續或分組的資訊塊。小圓形設計用於容納圖片，適合說明第 1 級與第 2 級文字，同時最大化形狀的水平與垂直顯示空間。 |
| BENDING_PICTURE_BLOCKS | 用於展示一系列圖片。底角的方框可容納少量文字。 |
| BENDING_PICTURE_CAPTION | 用於展示連續的圖片系列。底角的方框可容納少量文字。 |
| BENDING_PICTURE_CAPTION_LIST | 用於展示一系列圖片。標題與說明出現在每張圖片下方的標註形狀內。 |
| BENDING_PICTURE_SEMI_TRANSPARENT_TEXT | 用於展示一系列圖片。半透明方框覆蓋圖片下部，容納所有層級的文字。 |
| BLOCK_CYCLE | 用於以環狀流程表示持續的階段、任務或事件序列。強調階段或步驟而非連接的箭頭或流程。 |
| BUBBLE_PICTURE_LIST | 用於展示一系列圖片。可容納最多八張第 1 級圖片。未使用的文字與圖片不會顯示，但在切換版面時仍可使用。最佳效果為少量文字。 |
| CAPTIONED_PICTURES | 用於展示具有多層文字的圖片。最佳效果為少量第 1 級文字與中等量第 2 級文字。 |
| CHEVRON_LIST | 用於展示組成整體工作流程的多個流程的進度，也可用於說明對立的流程。第 1 級文字對應左側的第一個箭頭形狀，第 2 級文字對應每個含第 1 級文字形狀的水平子步驟。 |
| CIRCLE_ACCENT_TIMELINE | 用於展示一系列事件或時間軸資訊。第 1 級文字顯示於較大圓形旁， 第 2 級文字顯示於較小圓形旁。 |
| CIRCLE_ARROW_PROCESS | 用於展示帶有各項說明文字的連續項目。此圖表最適合少量第 1 級文字。 |
| CIRCLE_PICTURE_HIERARCHY | 用於展示組織內的階層資訊或匯報關係。圖片置於圓形中，對應文字顯示於圖片旁。 |
| CIRCLE_RELATIONSHIP | 用於展示與中心概念的關係。第 2 級文字以非連續方式加入，最多五項。僅能有一項第 1 級文字。 |
| CIRCULAR_BENDING_PROCESS | 用於展示任務、流程或工作流中較長或非線性的序列或步驟。最佳效果僅使用第 1 級文字。最大化形狀的水平與垂直顯示空間。 |
| CIRCULAR_PICTURE_CALLOUT | 用於展示中心概念及其子概念或相關項目。第一張圖片的文字覆蓋圖片下部。其他第 1 級形狀的對應文字顯示於小圓形圖片旁。此圖表亦適用於無文字情況。 |
| CLOSED_CHEVRON_PROCESS | 用於展示任務、流程或工作流中的進度、時間軸或連續步驟，或強調移動或方向。可用於強調起始形狀的資訊。最佳效果僅使用第 1 級文字。 |
| CONTINUOUS_ARROW_PROCESS | 用於展示時間軸或任務、流程或工作流中的連續步驟。最佳效果為第 1 級文字，因每行第 1 級文字都位於箭頭形狀內。第 2 級文字位於箭頭形狀外。 |
| CONTINUOUS_BLOCK_PROCESS | 用於展示任務、流程或工作流中的進度或連續步驟。最佳效果為最少量的第 1 級與第 2 級文字。 |
| CONTINUOUS_CYCLE | 用於以環狀流程表示持續的階段、任務或事件序列。強調所有元件之間的連接。最佳效果僅使用第 1 級文字。 |
| CONTINUOUS_PICTURE_LIST | 用於展示相互連結資訊的群組。圓形設計用於容納圖片。 |
| CONVERGING_ARROWS | 用於展示收斂至中心點的概念或想法。最佳效果僅使用第 1 級文字。 |
| CONVERGING_RADIAL | 用於展示概念或元件相對於中心概念的關係。第 1 級文字的第一行對應中心圓形， 第 2 級文字的各行對應周圍的矩形形狀。未使用的文字不會顯示，但在切換版面時仍可使用。 |
| COUNTERBALANCE_ARROWS | 用於展示兩個相對的概念或想法。第 1 級文字的前兩行分別對應於兩個箭頭，並與第 2 級文字良好搭配。未使用的文字不會顯示，但在切換版面時仍可使用。 |
| CYCLE_MATRIX | 用於展示中心概念在循環進程中的關係。第 1 級文字的前四行對應於扇形或圓餅形狀，第 2 級文字則出現在扇形或圓餅形狀側面的矩形內。未使用的文字不會顯示，但在切換版面時仍可使用。 |
| DESCENDING_BLOCK_LIST | 用於展示相關概念或資訊清單的群組。文字形狀依序下降高度，第 1 級文字垂直排列。 |
| DESCENDING_PROCESS | 用於展示事件的下降序列。第 1 級文字的第一項位於箭頭頂端，最後一項位於箭頭底端。僅顯示前七項第 1 級項目。最佳效果為少至中等量文字。 |
| DETAILED_PROCESS | 搭配大量第 2 級文字以展示階段性的進度。 |
| DIVERGING_ARROWS | 用於展示從中心來源向外延伸的概念或想法。最佳效果僅使用第 1 級文字。 |
| DIVERGING_RADIAL | 用於展示相對於中心概念的關係。第 1 級文字的第一行對應中心圓形。強調周圍的圓形而非中心概念。未使用的文字不會顯示，但在切換版面時仍可使用。 |
| EQUATION | 用於展示描繪計畫或結果的連續步驟或任務。最後一行第 1 級文字出現在等號 (=) 之後。最佳效果僅使用第 1 級文字。 |
| FRAMED_TEXT_PICTURE | 用於展示圖片，且相應的第 1 級文字以框線方式呈現。 |
| FUNNEL | 用於展示資訊的篩選或部件合併成整體的過程。強調最終結果。可容納最多四行第 1 級文字；最後一行出現在漏斗下方，其餘行對應圓形。未使用的文字不會顯示，但在切換版面時仍可使用。 |
| GEAR | 用於展示相互銜接的概念。第 1 級文字的前三行分別對應齒輪形狀，其相應的第 2 級文字出現在齒輪旁的矩形內。未使用的文字不會顯示，但在切換版面時仍可使用。
| GRID_MATRIX | 用於顯示概念在兩個軸上的排列。強調個別組件而非整體。第一層文字的前四行顯示在象限中。未使用的文字不會顯示，但在切換版面時仍可用。 |
| GROUPED_LIST | 用於顯示資訊的組別與子組別，或任務、流程、工作流程中的步驟與子步驟。第1層文字對應於頂層水平形狀，第2層文字對應於每個相關頂層形狀下的垂直子步驟。適合強調子組別或子步驟、層次資訊或多個資訊清單。 |
| HALF_CIRCLE_ORGANIZATION_CHART | 用於顯示組織中的層級資訊或匯報關係。此版面提供助理形狀和組織圖懸掛版面。 |
| HEXAGON_CLUSTER | 用於顯示帶有說明文字的圖片。小六角形表示圖片和文字配對。最適合少量文字。 |
| HIERARCHY | 用於顯示自上而下的層級關係。 |
| HIERARCHY_LIST | 用於顯示跨組的層級關係。也可用於分組或列出資訊。 |
| HORIZONTAL_BULLET_LIST | 用於顯示非順序或分組的資訊清單。適合大量文字。所有文字具有相同的強調程度，且不暗示方向。 |
| HORIZONTAL_HIERARCHY | 用於顯示水平延伸的層級關係。適合決策樹。 |
| HORIZONTAL_LABELED_HIERARCHY | 用於顯示水平且層級分組的層級關係。強調標題或第1層文字。第1層文字的第一行出現在層級起始的形狀中，其餘第1層文字行出現在高長方形的頂部。 |
| HORIZONTAL_MULTI_LEVEL_HIERARCHY | 用於顯示大量水平延伸的層級資訊。層級的頂部以垂直方式顯示。此版面支援層級中的多個層次。 |
| HORIZONTAL_ORGANIZATION_CHART | 用於顯示水平的層級資訊或組織中的匯報關係。此版面提供助理形狀和組織圖懸掛版面。 |
| HORIZONTAL_PICTURE_LIST | 用於顯示非順序或分組資訊，且強調相關圖片。頂部形狀設計用於放置圖片。 |
| INCREASING_ARROWS_PROCESS | 用於顯示流程中的順序和重疊步驟。限於五個第1層項目。第2層可包含大量文字。 |
| INCREASING_CIRCLE_PROCESS | 用於顯示一系列步驟，圓形內部隨每一步增大。限於七個第1層步驟，且第2層項目不限。適合大量第2層文字。 |
| INVERTED_PYRAMID | 用於顯示比例、相互關聯或層級關係，最大組件在頂部，向下收縮。第1層文字出現在金字塔區段中，第2層文字出現在每個區段旁的形狀中。 |
| LABELED_HIERARCHY | 用於顯示自上而下且層級分組的層級關係。強調標題或第1層文字。第1層文字的第一行出現在層級起始的形狀中，所有後續第1層文字行出現在長矩形的左側。 |
| LINEAR_VENN | 用於顯示序列中的重疊關係。最適合僅使用第1層文字。 |

| NESTED_TARGET | 用於顯示包含關係。第1層文字的前三行對應於形狀左上方的文字，第2層文字對應於較小的形狀。最適合最少的第2層文字行。未使用的文字不會顯示，但在切換版面時仍可用。 |
| NONDIRECTIONAL_CYCLE | 用於表示持續的階段、任務或事件的循環流。每個形狀具有相同重要程度。適合不需要指示方向的情況。 |
| OPPOSING_ARROWS | 用於顯示兩個相對的想法，或從中心點分岔的想法。第1層文字的前兩行分別對應於一個箭頭。未使用的文字不會顯示，但在切換版面時仍可用。 |
| OPPOSING_IDEAS | 用於顯示兩個相對或對比的想法。可有一或兩個第1層項目。每個第1層文字可包含多個子層級。適合大量文字。 |
| ORGANIZATION_CHART | 用於顯示組織中的層級資訊或匯報關係。此版面提供助理形狀和組織圖懸掛版面。 |
| PHASED_PROCESS | 用於顯示流程的三個階段。限於三個第1層項目。前兩個第1層項目各可包含四個第2層項目，第三個第1層項目可包含無限數量的第2層項目。最適合少量文字。 |
| PICTURE_ACCENT_BLOCKS | 用於從角落開始，以區塊形式顯示一組圖片。相應的文字垂直顯示。適合作為標題或副標題投影片的重點，或文件的章節分隔。 |
| PICTURE_ACCENT_LIST | 用於顯示分組或相關資訊。上角的小形狀設計用於放置圖片。強調第2層文字於第1層文字之上，適合大量第2層文字。 |
| PICTURE_ACCENT_PROCESS | 用於顯示任務、流程或工作流程中的順序步驟。背景中的矩形形狀設計用於放置圖片。 |
| PICTURE_CAPTION_LIST | 用於顯示非順序或分組的資訊區塊。頂部形狀設計用於放置圖片，且圖片相較文字更受強調。適合帶有短文字說明的圖片。 |
