## x 屬性
取得或設定形狀左上角的 x 座標，單位為點。
            Read/write **float**.


### 備註

回傳的值始終已定義，且永不為 **float**。
            指派的值也必須已定義；僅將 **float** 指派給 `RawFrame` 實例的屬性。

```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
