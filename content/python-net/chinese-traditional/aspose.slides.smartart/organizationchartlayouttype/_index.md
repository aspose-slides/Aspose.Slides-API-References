## OrganizationChartLayoutType 列舉

表示組織圖中子節點的格式類型

OrganizationChartLayoutType 類型會公開以下成員：

## 欄位

| 欄位 | 說明 |
| :- | :- |
| INITIAL | 初始佈局類型 |
| STANDART | 將子節點水平放置在父節點下方。 |
| BOTH_HANGING | 將子節點垂直放置在父節點下方的左側和右側。 |
| LEFT_HANGING | 將子節點垂直放置在父節點下方的左側。 |
| RIGHT_HANGING | 將子節點垂直放置在父節點下方的右側。 |
