## SmartArtNode 類別

表示 SmartArt 物件的節點

SmartArtNode 類型公開以下成員：

## 屬性

| 屬性 | 說明 |
| :- | :- |
| [`child_nodes`](/slides/python-net/zh-hant/aspose.slides.smartart/smartartnode/child_nodes/) | 傳回目前節點所有子節點的集合。<br/>            唯讀 [`ISmartArtNodeCollection`](/slides/python-net/zh-hant/aspose.slides.smartart/ismartartnodecollection)。 |
| [`shapes`](/slides/python-net/zh-hant/aspose.slides.smartart/smartartnode/shapes/) | 傳回與該節點相關聯的所有圖形的集合。<br/>            唯讀 [`ISmartArtShapeCollection`](/slides/python-net/zh-hant/aspose.slides.smartart/ismartartshapecollection)。 |
| [`text_frame`](/slides/python-net/zh-hant/aspose.slides.smartart/smartartnode/text_frame/) | 傳回節點的文字框。<br/>            唯讀 [`ITextFrame`](/slides/python-net/zh-hant/aspose.slides/itextframe)。 |
| [`is_assistant`](/slides/python-net/zh-hant/aspose.slides.smartart/smartartnode/is_assistant/) | 傳回或設定節點為助理。<br/>            可讀寫 **bool**。 |
| [`level`](/slides/python-net/zh-hant/aspose.slides.smartart/smartartnode/level/) | 傳回節點的巢狀層級。<br/>            唯讀 **int**。 |
| [`bullet_fill_format`](/slides/python-net/zh-hant/aspose.slides.smartart/smartartnode/bullet_fill_format/) | 傳回包含節點項目符號填充格式屬性的 FillFormat 物件。<br/>            註：對於某些不提供節點項目符號的 SmartArt 版面配置，可能傳回 None。<br/>            唯讀 [`IFillFormat`](/slides/python-net/zh-hant/aspose.slides/ifillformat)。 |
| [`position`](/slides/python-net/zh-hant/aspose.slides.smartart/smartartnode/position/) | 傳回或設定節點在同級節點中的零基位置。<br/>            可讀寫 **int**。 |
| [`is_hidden`](/slides/python-net/zh-hant/aspose.slides.smartart/smartartnode/is_hidden/) | 如果此節點在資料模型中是隱藏節點，則傳回 true。<br/>            唯讀 **bool**。 |
| [`organization_chart_layout`](/slides/python-net/zh-hant/aspose.slides.smartart/smartartnode/organization_chart_layout/) | 傳回或設定與目前節點相關聯的組織圖版面配置類型。<br/>            可讀寫 [`OrganizationChartLayoutType`](/slides/python-net/zh-hant/aspose.slides.smartart/organizationchartlayouttype)。 |
