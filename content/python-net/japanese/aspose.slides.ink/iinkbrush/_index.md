## IInkBrush クラス

トレースブラシを表します。

IInkBrush タイプは次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`color`](/slides/python-net/ja/aspose.slides.ink/iinkbrush/color/) | ラインのブラシ色を取得または設定します。 |
| [`size`](/slides/python-net/ja/aspose.slides.ink/iinkbrush/size/) | ラインのポイント単位のブラシサイズを取得または設定します。 |
| [`ink_effect`](/slides/python-net/ja/aspose.slides.ink/iinkbrush/ink_effect/) | インクエフェクトタイプ（例: Galaxy、Gold、Silver）を取得し、インクストロークの視覚的スタイルを定義します。<br/>            この値はブラシプロパティ "inkEffects" から解析されます。もし認識されたエフェクトが指定されていない場合、<br/>            [`InkEffectType.NOT_DEFINED`](/slides/python-net/ja/aspose.slides.ink/inkeffecttype/NOT_DEFINED) が返されます。 |
