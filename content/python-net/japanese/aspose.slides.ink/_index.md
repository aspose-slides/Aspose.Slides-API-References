Ink の操作に使用するクラスを含みます。

## クラス

| クラス | 説明 |
| :- | :- |
| [`IInk`](/slides/python-net/ja/aspose.slides.ink/iink/) | スライド上の ink オブジェクトを表します。 |
| [`IInkActions`](/slides/python-net/ja/aspose.slides.ink/iinkactions/) | スライド上の ink オブジェクトを表します。 |
| [`IInkBrush`](/slides/python-net/ja/aspose.slides.ink/iinkbrush/) | trace ブラシを表します。 |
| [`IInkTrace`](/slides/python-net/ja/aspose.slides.ink/iinktrace/) | Ink オブジェクト内の手書きラインを表します。 |
| [`Ink`](/slides/python-net/ja/aspose.slides.ink/ink/) | スライド上の ink オブジェクトを表します。 |
| [`InkActions`](/slides/python-net/ja/aspose.slides.ink/inkactions/) | ink アクションのルートを表します。 |
| [`InkBrush`](/slides/python-net/ja/aspose.slides.ink/inkbrush/) | inkBrush オブジェクトを表します。 |
| [`InkTrace`](/slides/python-net/ja/aspose.slides.ink/inktrace/) | Trace オブジェクトを表します。<br/>            Trace 要素はデジタライザで取得されたデータを記録するために使用されます。<br/>            InkTraceFormat オブジェクトで指定された仕様に従ってエンコードされたポイントのシーケンスを含みます。 |

## 列挙型

| 列挙型 | 説明 |
| :- | :- |
| [`InkEffectType`](/slides/python-net/ja/aspose.slides.ink/inkeffecttype/) | ink のレンダリング用に事前定義されたビジュアルエフェクトのセットを指定します。<br/>            各エフェクトは、スタイライズされた ink の外観をシミュレートするテクスチャまたは画像に対応します。<br/>            これらの値は、レンダリング中にデジタル ink ストロークのビジュアルスタイルをカスタマイズするために使用できます。 |
