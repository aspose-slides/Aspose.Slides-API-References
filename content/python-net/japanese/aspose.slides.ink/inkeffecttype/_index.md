## InkEffectType 列挙型

インクレンダリング用の事前定義された視覚効果のセットを指定します。  
各効果は、様式化されたインク外観をシミュレートするテクスチャまたは画像に対応しています。  
これらの値は、レンダリング中にデジタルインクストロークの視覚スタイルをカスタマイズするために使用できます。

InkEffectType 型は以下のメンバーを公開します:

## フィールド

| フィールド | 説明 |
| :- | :- |
| NOT_DEFINED | 効果が定義されていないか不明です。この値はデフォルトまたはフォールバックとして使用できます。 |
| BRONZE | 銅インクに似た、暖かみのある茶色系の金属テクスチャです。 |
| GALAXY | 銀河に似た、カラフルできらめくテクスチャで、宇宙的な色合いがあります。 |
| GOLD | インクストロークに豪華な外観を与える、明るく金属的な金色テクスチャです。 |
| LAVA | 溶岩のような燃えるテクスチャで、赤とオレンジの色調があります。 |
| OCEAN | 海の波や水系インクを模した、深い青色の液体のようなテクスチャです。 |
| RAINBOW_GLITTER | 祝祭的または鮮やかなインクストロークに使用される、カラフルできらびやかな虹のグリッター効果です。 |
| ROSE_GOLD | エレガントなインクストロークのための、ローズゴールドに似た柔らかなピンクゴールドのブレンドです。 |
| SILVER | クラシックなシルバーインクをシミュレートする、クールな金属シルバーテクスチャです。 |
