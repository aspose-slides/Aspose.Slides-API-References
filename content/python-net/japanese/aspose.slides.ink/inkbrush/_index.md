## InkBrush クラス

inkBrush オブジェクトを表します。

InkBrush 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`color`](/slides/python-net/ja/aspose.slides.ink/inkbrush/color/) | ラインのブラシ色を取得または設定します。 |
| [`size`](/slides/python-net/ja/aspose.slides.ink/inkbrush/size/) | ラインのブラシサイズをポイント単位で取得または設定します。 |
| [`ink_effect`](/slides/python-net/ja/aspose.slides.ink/inkbrush/ink_effect/) | インク効果タイプを取得します（例: Galaxy、Gold、Silver）。このタイプはインクストロークの視覚スタイルを定義します。<br/>            値はブラシプロパティ "inkEffects" から解析されます。認識された効果が指定されていない場合、<br/>            [`InkEffectType.NOT_DEFINED`](/slides/python-net/ja/aspose.slides.ink/inkeffecttype/NOT_DEFINED) が返されます。 |
