Microsoft PowerPoint プレゼンテーション内のスプレッドシートオブジェクトを操作するためのクラスが含まれています。

## クラス

| クラス | 説明 |
| :- | :- |
| [`CellCircularReferenceException`](/slides/python-net/ja/aspose.slides.spreadsheet/cellcircularreferenceexception/) | 式が自身のセルを直接または間接的に参照している場合に、<br/>1つ以上の循環参照が検出されたときにスローされる例外です。 |
| [`CellInvalidFormulaException`](/slides/python-net/ja/aspose.slides.spreadsheet/cellinvalidformulaexception/) | 計算された式が正しくない、または解析できなかった場合にスローされる例外です。 |
| [`CellInvalidReferenceException`](/slides/python-net/ja/aspose.slides.spreadsheet/cellinvalidreferenceexception/) | 無効なセル参照が発生したときにスローされる例外です。 |
| [`CellUnsupportedDataException`](/slides/python-net/ja/aspose.slides.spreadsheet/cellunsupporteddataexception/) | スプレッドシートのセルでサポートされていないデータが検出されたときにスローされる例外です。 |
