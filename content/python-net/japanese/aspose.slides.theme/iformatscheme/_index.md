## IFormatScheme クラス

シェイプのテーマで定義されたフォーマットを格納します。

IFormatScheme 型は以下のメンバーを提供します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`fill_styles`](/slides/python-net/ja/aspose.slides.theme/iformatscheme/fill_styles/) | テーマで定義された塗りつぶしスタイルのコレクションを返します。<br/>            読み取り専用 [`IFillFormatCollection`](/slides/python-net/ja/aspose.slides.theme/ifillformatcollection)。 |
| [`line_styles`](/slides/python-net/ja/aspose.slides.theme/iformatscheme/line_styles/) | テーマで定義された線スタイルのコレクションを返します。<br/>            読み取り専用 [`ILineFormatCollection`](/slides/python-net/ja/aspose.slides.theme/ilineformatcollection)。 |
| [`effect_styles`](/slides/python-net/ja/aspose.slides.theme/iformatscheme/effect_styles/) | テーマで定義されたエフェクトスタイルのコレクションを返します。<br/>            読み取り専用 [`IEffectStyleCollection`](/slides/python-net/ja/aspose.slides.theme/ieffectstylecollection)。 |
| [`background_fill_styles`](/slides/python-net/ja/aspose.slides.theme/iformatscheme/background_fill_styles/) | テーマで定義された背景塗りつぶしスタイルのコレクションを返します。<br/>            読み取り専用 [`IFillFormatCollection`](/slides/python-net/ja/aspose.slides.theme/ifillformatcollection)。 |
| [`slide`](/slides/python-net/ja/aspose.slides.theme/iformatscheme/slide/) |  |
