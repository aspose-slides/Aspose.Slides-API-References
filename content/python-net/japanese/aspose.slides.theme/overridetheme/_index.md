## OverrideTheme クラス

オーバーライドテーマを表します。

**Inheritance:**[`OverrideTheme`](/slides/python-net/ja/aspose.slides.theme/overridetheme) → [`Theme`](/slides/python-net/ja/aspose.slides.theme/theme)

The OverrideTheme type exposes the following members:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`color_scheme`](/slides/python-net/ja/aspose.slides.theme/overridetheme/color_scheme/) | カラースキームを返します。<br/>            読み取り専用 [`IColorScheme`](/slides/python-net/ja/aspose.slides.theme/icolorscheme)。 |
| [`font_scheme`](/slides/python-net/ja/aspose.slides.theme/overridetheme/font_scheme/) | フォントスキームを返します。<br/>            読み取り専用 [`IFontScheme`](/slides/python-net/ja/aspose.slides.theme/ifontscheme)。 |
| [`format_scheme`](/slides/python-net/ja/aspose.slides.theme/overridetheme/format_scheme/) | シェイプの書式スキームを返します。<br/>            読み取り専用 [`IFormatScheme`](/slides/python-net/ja/aspose.slides.theme/iformatscheme)。 |
| [`presentation`](/slides/python-net/ja/aspose.slides.theme/overridetheme/presentation/) | 親プレゼンテーションを返します。<br/>            読み取り専用 [`IPresentation`](/slides/python-net/ja/aspose.slides/ipresentation)。 |
| [`is_empty`](/slides/python-net/ja/aspose.slides.theme/overridetheme/is_empty/) | True の値は、ColorScheme、FontScheme、FormatScheme が None であり、このテーマオブジェクトによるすべてのオーバーライドが無効になっていることを意味します。<br/>            読み取り専用 **bool**。 |
