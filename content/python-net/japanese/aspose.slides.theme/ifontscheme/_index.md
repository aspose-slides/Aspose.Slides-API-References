## IFontScheme クラス

テーマで定義されたフォントを格納します。

IFontScheme 型は以下のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`minor`](/slides/python-net/ja/aspose.slides.theme/ifontscheme/minor/) | スライドの「body」部分のフォントコレクションを返します。<br/>            読み取り専用 [`IFonts`](/slides/python-net/ja/aspose.slides/ifonts)。 |
| [`major`](/slides/python-net/ja/aspose.slides.theme/ifontscheme/major/) | スライドの「heading」部分のフォントコレクションを返します。<br/>            読み取り専用 [`IFonts`](/slides/python-net/ja/aspose.slides/ifonts)。 |
| [`name`](/slides/python-net/ja/aspose.slides.theme/ifontscheme/name/) | フォントスキームの名前を返します。<br/>            読み書き可能 **str**。 |
