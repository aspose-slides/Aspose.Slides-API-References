## IOverrideThemeManager クラス

オーバーライドされたテーマのさまざまなタイプへのアクセスを提供します。

IOverrideThemeManager 型は以下のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`is_override_theme_enabled`](/slides/python-net/ja/aspose.slides.theme/ioverridethememanager/is_override_theme_enabled/) | OverrideTheme が継承された有効なテーマを上書きするかどうかを決定します。<br/>            OverrideTheme の上書きを有効にするには、OverrideTheme.Init*() メソッドを使用します。<br/>            OverrideTheme の上書きを無効にするには、OverrideTheme.Clear() メソッドを使用します。<br/>            読み取り専用 **bool**. |
| [`override_theme`](/slides/python-net/ja/aspose.slides.theme/ioverridethememanager/override_theme/) | 上書きされたテーマオブジェクトを返します。<br/>            読み書き可能 [`IOverrideTheme`](/slides/python-net/ja/aspose.slides.theme/ioverridetheme). |
