## FontScheme クラス

テーマで定義されたフォントを格納します。

FontScheme 型は以下のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`minor`](/slides/python-net/ja/aspose.slides.theme/fontscheme/minor/) | スライドの「body」部分のフォント コレクションを返します。<br/>            読み取り専用 [`IFonts`](/slides/python-net/ja/aspose.slides/ifonts). |
| [`major`](/slides/python-net/ja/aspose.slides.theme/fontscheme/major/) | スライドの「heading」部分のフォント コレクションを返します。<br/>            読み取り専用 [`IFonts`](/slides/python-net/ja/aspose.slides/ifonts). |
| [`name`](/slides/python-net/ja/aspose.slides.theme/fontscheme/name/) | フォント スキーム名を返します。<br/>            読み書き可能 **str**. |
