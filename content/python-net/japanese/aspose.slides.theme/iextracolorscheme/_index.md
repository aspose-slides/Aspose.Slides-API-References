## IExtraColorScheme クラス

スライドに割り当て可能な追加のカラースキームを表します。

IExtraColorScheme 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`name`](/slides/python-net/ja/aspose.slides.theme/iextracolorscheme/name/) | このスキームの名前を返します。<br/>            読み取り専用 **str**. |
| [`color_scheme`](/slides/python-net/ja/aspose.slides.theme/iextracolorscheme/color_scheme/) | カラースキームを返します。<br/>            読み取り専用 [`IColorScheme`](/slides/python-net/ja/aspose.slides.theme/icolorscheme). |
