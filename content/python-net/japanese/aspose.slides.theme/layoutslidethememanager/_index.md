## LayoutSlideThemeManager クラス

レイアウトスライドのテーマのオーバーライドへのアクセスを提供します。

**継承:**[`LayoutSlideThemeManager`](/slides/python-net/ja/aspose.slides.theme/layoutslidethememanager) → [`BaseOverrideThemeManager`](/slides/python-net/ja/aspose.slides.theme/baseoverridethememanager) → [`BaseThemeManager`](/slides/python-net/ja/aspose.slides.theme/basethememanager)

LayoutSlideThemeManager 型は以下のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`override_theme`](/slides/python-net/ja/aspose.slides.theme/layoutslidethememanager/override_theme/) | オーバーライドされたテーマオブジェクトを返します。<br/>            読み取り/書き込み [`IOverrideTheme`](/slides/python-net/ja/aspose.slides.theme/ioverridetheme)。 |
| [`is_override_theme_enabled`](/slides/python-net/ja/aspose.slides.theme/layoutslidethememanager/is_override_theme_enabled/) | OverrideTheme が継承された有効テーマを上書きするかどうかを決定します。<br/>            OverrideTheme を上書きするには OverrideTheme.Init*() メソッドを使用します。<br/>            OverrideTheme の上書きを無効にするには OverrideTheme.Clear() メソッドを使用します。<br/>            読み取り専用 **bool**。 |
