## IEffectStyle クラス

エフェクトスタイルを表します。

IEffectStyle 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`effect_format`](/slides/python-net/ja/aspose.slides.theme/ieffectstyle/effect_format/) | エフェクト形式を返します。<br/>            読み取り専用 [`IEffectFormat`](/slides/python-net/ja/aspose.slides/ieffectformat). |
| [`three_d_format`](/slides/python-net/ja/aspose.slides.theme/ieffectstyle/three_d_format/) | 3D 形式を返します。<br/>            読み取り専用 [`IThreeDFormat`](/slides/python-net/ja/aspose.slides/ithreedformat). |
