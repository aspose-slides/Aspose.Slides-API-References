## FormatScheme クラス

シェイプのテーマ定義フォーマットを格納します。

FormatScheme 型は以下のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`fill_styles`](/slides/python-net/ja/aspose.slides.theme/formatscheme/fill_styles/) | テーマで定義された塗りつぶしスタイルのコレクションを返します。<br/>            読み取り専用 [`IFillFormatCollection`](/slides/python-net/ja/aspose.slides.theme/ifillformatcollection). |
| [`line_styles`](/slides/python-net/ja/aspose.slides.theme/formatscheme/line_styles/) | テーマで定義された線スタイルのコレクションを返します。<br/>            読み取り専用 [`ILineFormatCollection`](/slides/python-net/ja/aspose.slides.theme/ilineformatcollection). |
| [`effect_styles`](/slides/python-net/ja/aspose.slides.theme/formatscheme/effect_styles/) | テーマで定義された効果スタイルのコレクションを返します。<br/>            読み取り専用 [`IEffectStyleCollection`](/slides/python-net/ja/aspose.slides.theme/ieffectstylecollection). |
| [`background_fill_styles`](/slides/python-net/ja/aspose.slides.theme/formatscheme/background_fill_styles/) | テーマで定義された背景塗りつぶしスタイルのコレクションを返します。<br/>            読み取り専用 [`IFillFormatCollection`](/slides/python-net/ja/aspose.slides.theme/ifillformatcollection). |
| [`slide`](/slides/python-net/ja/aspose.slides.theme/formatscheme/slide/) | 親スライドを返します。<br/>            読み取り専用 [`IBaseSlide`](/slides/python-net/ja/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/ja/aspose.slides.theme/formatscheme/presentation/) | 親プレゼンテーションを返します。<br/>            読み取り専用 [`IPresentation`](/slides/python-net/ja/aspose.slides/ipresentation). |
