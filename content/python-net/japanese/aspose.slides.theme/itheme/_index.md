## ITheme クラス

テーマを表します。

ITheme 型は以下のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`color_scheme`](/slides/python-net/ja/aspose.slides.theme/itheme/color_scheme/) | カラースキームを返します。<br/>            読み取り専用 [`IColorScheme`](/slides/python-net/ja/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/ja/aspose.slides.theme/itheme/font_scheme/) | フォントスキームを返します。<br/>            読み取り専用 [`IFontScheme`](/slides/python-net/ja/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/ja/aspose.slides.theme/itheme/format_scheme/) | シェイプ形式スキームを返します。<br/>            読み取り専用 [`IFormatScheme`](/slides/python-net/ja/aspose.slides.theme/iformatscheme). |
