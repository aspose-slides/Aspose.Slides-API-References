## ColorScheme クラス

テーマで定義された色を格納します。

ColorScheme 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`dark1`](/slides/python-net/ja/aspose.slides.theme/colorscheme/dark1/) | スキーム内の最初の暗い色です。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat). |
| [`light1`](/slides/python-net/ja/aspose.slides.theme/colorscheme/light1/) | スキーム内の最初の明るい色です。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat). |
| [`dark2`](/slides/python-net/ja/aspose.slides.theme/colorscheme/dark2/) | スキーム内の2番目の暗い色です。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat). |
| [`light2`](/slides/python-net/ja/aspose.slides.theme/colorscheme/light2/) | スキーム内の2番目の明るい色です。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat). |
| [`accent1`](/slides/python-net/ja/aspose.slides.theme/colorscheme/accent1/) | スキーム内の最初のアクセント色です。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat). |
| [`accent2`](/slides/python-net/ja/aspose.slides.theme/colorscheme/accent2/) | スキーム内の2番目のアクセント色です。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat). |
| [`accent3`](/slides/python-net/ja/aspose.slides.theme/colorscheme/accent3/) | スキーム内の3番目のアクセント色です。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat). |
| [`accent4`](/slides/python-net/ja/aspose.slides.theme/colorscheme/accent4/) | スキーム内の4番目のアクセント色です。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat). |
