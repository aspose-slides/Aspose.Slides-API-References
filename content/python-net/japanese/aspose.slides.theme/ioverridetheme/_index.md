## IOverrideTheme クラス

オーバーライドテーマを表します。

IOverrideTheme 型は次のメンバーを公開します。

## プロパティ

| Property | Description |
| :- | :- |
| [`is_empty`](/slides/python-net/ja/aspose.slides.theme/ioverridetheme/is_empty/) | True の値は、ColorScheme、FontScheme、FormatScheme が None であり、このテーマオブジェクトによるオーバーライドが無効になることを意味します。<br/>            読み取り専用 **bool**。 |
| [`color_scheme`](/slides/python-net/ja/aspose.slides.theme/ioverridetheme/color_scheme/) |  |
| [`font_scheme`](/slides/python-net/ja/aspose.slides.theme/ioverridetheme/font_scheme/) |  |
