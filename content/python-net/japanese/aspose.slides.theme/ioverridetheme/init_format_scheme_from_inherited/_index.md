## init_format_scheme_from_inherited(self) {#}
InheritedTheme の FormatScheme をオーバーライドするために、新しいオブジェクトで FormatScheme を初期化します。また、この新しいオブジェクトのデータを InheritedTheme の FormatScheme のデータで初期化します。

```python
def init_format_scheme_from_inherited(self):
    ...
```

### 例外

| 例外 | 説明 |
| :- | :- |
| **RuntimeError(Proxy error(InvalidOperationException))** | FormatScheme がすでに初期化されている場合にスローされます (None ではない)。 |
