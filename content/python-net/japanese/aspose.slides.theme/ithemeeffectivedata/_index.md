## IThemeEffectiveData クラス

有効なテーマプロパティを含む不変オブジェクトです。

IThemeEffectiveData型は以下のメンバーを公開します。

## プロパティ

| Property | Description |
| :- | :- |
| [`font_scheme`](/slides/python-net/ja/aspose.slides.theme/ithemeeffectivedata/font_scheme/) | フォントスキームを返します。<br/>            読み取り専用 [`IFontSchemeEffectiveData`](/slides/python-net/ja/aspose.slides.theme/ifontschemeeffectivedata). |
| [`format_scheme`](/slides/python-net/ja/aspose.slides.theme/ithemeeffectivedata/format_scheme/) | シェイプフォーマットスキームを返します。<br/>            読み取り専用 [`IFormatSchemeEffectiveData`](/slides/python-net/ja/aspose.slides.theme/iformatschemeeffectivedata). |

## メソッド

| Method | Description |
| :- | :- |
| [`get_color_scheme(self, style_color)`](/slides/python-net/ja/aspose.slides.theme/ithemeeffectivedata/get_color_scheme/#asposeslidescolor) | カラースキームを返します。 |

### 備考

このインターフェイスは[`ITheme`](/slides/python-net/ja/aspose.slides.theme/itheme)インターフェイスと組み合わせて、継承が適用された有効な書式設定値を返すために使用されます。
