## IThemeEffectiveData クラス

有効なテーマプロパティを含む不変オブジェクトです。

IThemeEffectiveData 型は以下のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`font_scheme`](/slides/python-net/ja/aspose.slides.theme/ithemeeffectivedata/font_scheme/) | フォントスキームを返します。<br/>            読み取り専用 [`IFontSchemeEffectiveData`](/slides/python-net/ja/aspose.slides.theme/ifontschemeeffectivedata). |
| [`format_scheme`](/slides/python-net/ja/aspose.slides.theme/ithemeeffectivedata/format_scheme/) | シェイプ形式スキームを返します。<br/>            読み取り専用 [`IFormatSchemeEffectiveData`](/slides/python-net/ja/aspose.slides.theme/iformatschemeeffectivedata). |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`get_color_scheme(self, style_color)`](/slides/python-net/ja/aspose.slides.theme/ithemeeffectivedata/get_color_scheme/#asposepydrawingcolor) | カラースキームを返します。 |

### 備考

このインターフェイスは [`ITheme`](/slides/python-net/ja/aspose.slides.theme/itheme) インターフェイスと共に使用され、継承が適用された有効な書式設定値を返すためです。
