## MasterTheme クラス

マスターテーマを表します。

**継承:**[`MasterTheme`](/slides/python-net/ja/aspose.slides.theme/mastertheme) → [`Theme`](/slides/python-net/ja/aspose.slides.theme/theme)

MasterTheme 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`color_scheme`](/slides/python-net/ja/aspose.slides.theme/mastertheme/color_scheme/) | カラースキームを返します。<br/>            読み取り専用 [`IColorScheme`](/slides/python-net/ja/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/ja/aspose.slides.theme/mastertheme/font_scheme/) | フォントスキームを返します。<br/>            読み取り専用 [`IFontScheme`](/slides/python-net/ja/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/ja/aspose.slides.theme/mastertheme/format_scheme/) | シェイプ形式スキームを返します。<br/>            読み取り専用 [`IFormatScheme`](/slides/python-net/ja/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/ja/aspose.slides.theme/mastertheme/presentation/) | 親プレゼンテーションを返します。<br/>            読み取り専用 [`IPresentation`](/slides/python-net/ja/aspose.slides/ipresentation). |
| [`extra_color_schemes`](/slides/python-net/ja/aspose.slides.theme/mastertheme/extra_color_schemes/) | 追加のカラースキームコレクションを返します。<br/>            これらのスキームはプレゼンテーションの外観に影響せず、スライドのメインカラースキームとして選択できます。<br/>            読み取り専用 [`IExtraColorSchemeCollection`](/slides/python-net/ja/aspose.slides.theme/iextracolorschemecollection). |
| [`name`](/slides/python-net/ja/aspose.slides.theme/mastertheme/name/) | テーマの名前を返します。<br/>            読み書き **str**. |
