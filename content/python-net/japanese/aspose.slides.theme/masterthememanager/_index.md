## MasterThemeManager クラス

プレゼンテーションのマスターテーマへのアクセスを提供します。

**継承:**[`MasterThemeManager`](/slides/python-net/ja/aspose.slides.theme/masterthememanager) → [`BaseThemeManager`](/slides/python-net/ja/aspose.slides.theme/basethememanager)

MasterThemeManager 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`override_theme`](/slides/python-net/ja/aspose.slides.theme/masterthememanager/override_theme/) | オーバーライドされたテーマオブジェクトを返します。<br/>            読み取り/書き込み [`IMasterTheme`](/slides/python-net/ja/aspose.slides.theme/imastertheme). |
| [`is_override_theme_enabled`](/slides/python-net/ja/aspose.slides.theme/masterthememanager/is_override_theme_enabled/) | OverrideTheme が継承された有効テーマ (Presentation.MasterTheme) を上書きするかどうかを決定します。<br/>            読み取り/書き込み **bool**. |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`create_theme_effective(self)`](/slides/python-net/ja/aspose.slides.theme/masterthememanager/create_theme_effective/#) | テーマオブジェクトを返します。 |
| [`apply_color_scheme(self, scheme)`](/slides/python-net/ja/aspose.slides.theme/masterthememanager/apply_color_scheme/#iextracolorscheme) | スライドに追加のカラースキームを適用します。 |
