## IEffectStyleEffectiveData クラス

有効なエフェクトスタイルプロパティを含む不変オブジェクトです。

IEffectStyleEffectiveData型は以下のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`effect_format`](/slides/python-net/ja/aspose.slides.theme/ieffectstyleeffectivedata/effect_format/) | 効果フォーマットを返します。<br/>            読み取り専用 [`IEffectFormatEffectiveData`](/slides/python-net/ja/aspose.slides/ieffectformateffectivedata). |
| [`three_d_format`](/slides/python-net/ja/aspose.slides.theme/ieffectstyleeffectivedata/three_d_format/) | 3Dフォーマットを返します。<br/>            読み取り専用 [`IThreeDFormatEffectiveData`](/slides/python-net/ja/aspose.slides/ithreedformateffectivedata). |


### 備考

このインターフェイスは [`IEffectStyleCollectionEffectiveData`](/slides/python-net/ja/aspose.slides.theme/ieffectstylecollectioneffectivedata) の一部として使用されます。
