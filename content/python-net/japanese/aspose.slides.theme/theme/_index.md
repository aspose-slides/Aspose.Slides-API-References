## Theme クラス

Theme タイプは以下のメンバーを公開します。

## プロパティ

| Property | 説明 |
| :- | :- |
| [`color_scheme`](/slides/python-net/ja/aspose.slides.theme/theme/color_scheme/) | カラースキームを返します。<br/>            読み取り専用 [`IColorScheme`](/slides/python-net/ja/aspose.slides.theme/icolorscheme)。 |
| [`font_scheme`](/slides/python-net/ja/aspose.slides.theme/theme/font_scheme/) | フォントスキームを返します。<br/>            読み取り専用 [`IFontScheme`](/slides/python-net/ja/aspose.slides.theme/ifontscheme)。 |
| [`format_scheme`](/slides/python-net/ja/aspose.slides.theme/theme/format_scheme/) | シェイプフォーマットスキームを返します。<br/>            読み取り専用 [`IFormatScheme`](/slides/python-net/ja/aspose.slides.theme/iformatscheme)。 |
| [`presentation`](/slides/python-net/ja/aspose.slides.theme/theme/presentation/) | 親プレゼンテーションを返します。<br/>            読み取り専用 [`IPresentation`](/slides/python-net/ja/aspose.slides/ipresentation)。 |
