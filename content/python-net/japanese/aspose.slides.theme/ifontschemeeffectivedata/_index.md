## IFontSchemeEffectiveData クラス

有効なフォント スキーム プロパティを含む不変オブジェクトです。

IFontSchemeEffectiveData 型は次のメンバーを公開します。

## プロパティ

| Property | Description |
| :- | :- |
| [`minor`](/slides/python-net/ja/aspose.slides.theme/ifontschemeeffectivedata/minor/) | スライドの "body" 部分のフォント コレクションを返します。<br/> 読み取り専用 [`IFontsEffectiveData`](/slides/python-net/ja/aspose.slides/ifontseffectivedata). |
| [`major`](/slides/python-net/ja/aspose.slides.theme/ifontschemeeffectivedata/major/) | スライドの "heading" 部分のフォント コレクションを返します。<br/> 読み取り専用 [`IFontsEffectiveData`](/slides/python-net/ja/aspose.slides/ifontseffectivedata). |
| [`name`](/slides/python-net/ja/aspose.slides.theme/ifontschemeeffectivedata/name/) | フォント スキーム名を返します。<br/> 読み取り専用 **str**. |

### 備考

このインターフェイスは [`IThemeEffectiveData`](/slides/python-net/ja/aspose.slides.theme/ithemeeffectivedata) の一部として使用されます。
