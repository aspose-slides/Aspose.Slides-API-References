## ICachedChartValue クラス

キャッシュされたチャート値を表します（例: X、Y、バブルサイズ、または主値）。

ICachedChartValue 型は次のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`data`](/slides/python-net/ja/aspose.slides.charts/icachedchartvalue/data/) | キャッシュされたデータ オブジェクトを取得します。<br/>            読み取り専用 **any**. |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`to_double(self)`](/slides/python-net/ja/aspose.slides.charts/icachedchartvalue/to_double/#) | キャッシュされた値を **float** に変換します。 |
