## IChartTextBlockFormat クラス

チャートテキスト要素の書式設定プロパティを表します。

IChartTextBlockFormat 型は以下のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`anchoring_type`](/slides/python-net/ja/aspose.slides.charts/icharttextblockformat/anchoring_type/) | TextFrame の垂直アンカー テキストを取得または設定します。<br/>            読み取り/書き込み [`TextAnchorType`](/slides/python-net/ja/aspose.slides/textanchortype). |
| [`center_text`](/slides/python-net/ja/aspose.slides.charts/icharttextblockformat/center_text/) | NullableBool.True の場合、テキストは水平方向にボックスの中央に配置されます。<br/>            読み取り/書き込み [`NullableBool`](/slides/python-net/ja/aspose.slides/nullablebool). |
| [`text_vertical_type`](/slides/python-net/ja/aspose.slides.charts/icharttextblockformat/text_vertical_type/) | テキストの向きを決定します。<br/>            このプロパティとプロパティ RotationAngle のカスタム角度から要約された視覚的テキスト回転の結果値です。<br/>            読み取り/書き込み [`TextVerticalType`](/slides/python-net/ja/aspose.slides/textverticaltype). |
| [`margin_left`](/slides/python-net/ja/aspose.slides.charts/icharttextblockformat/margin_left/) | TextFrame の左余白（ポイント）を取得または設定します。<br/>            このプロパティの変更は、次のチャート部分にのみ影響を与える可能性があります： <br/>            DataLabel と DataLabelFormat（PowerPoint 2013 で完全にサポート; PowerPoint 2007 ではレンダリングに効果なし）。<br/>            読み取り/書き込み **float**. |
| [`margin_right`](/slides/python-net/ja/aspose.slides.charts/icharttextblockformat/margin_right/) | TextFrame の右余白（ポイント）を取得または設定します。<br/>            このプロパティの変更は、次のチャート部分にのみ影響を与える可能性があります： <br/>            DataLabel と DataLabelFormat（PowerPoint 2013 で完全にサポート; PowerPoint 2007 ではレンダリングに効果なし）。<br/>            読み取り/書き込み **float**. |
| [`margin_top`](/slides/python-net/ja/aspose.slides.charts/icharttextblockformat/margin_top/) | TextFrame の上余白（ポイント）を取得または設定します。<br/>            このプロパティの変更は、次のチャート部分にのみ影響を与える可能性があります： <br/>            DataLabel と DataLabelFormat（PowerPoint 2013 で完全にサポート; PowerPoint 2007 ではレンダリングに効果なし）。<br/>            読み取り/書き込み **float**. |
| [`margin_bottom`](/slides/python-net/ja/aspose.slides.charts/icharttextblockformat/margin_bottom/) | TextFrame の下余白（ポイント）を取得または設定します。<br/>            このプロパティの変更は、次のチャート部分にのみ影響を与える可能性があります： <br/>            DataLabel と DataLabelFormat（PowerPoint 2013 で完全にサポート; PowerPoint 2007 ではレンダリングに効果なし）。<br/>            読み取り/書き込み **float**. |
| [`wrap_text`](/slides/python-net/ja/aspose.slides.charts/icharttextblockformat/wrap_text/) | **True**  テキストが TextFrame の余白で折り返される場合。<br/>            このプロパティの変更は、次のチャート部分にのみ影響を与える可能性があります： <br/>            DataLabel と DataLabelFormat（PowerPoint 2007/2013 で完全にサポート）。<br/>            読み取り/書き込み [`NullableBool`](/slides/python-net/ja/aspose.slides/nullablebool). |
| [`autofit_type`](/slides/python-net/ja/aspose.slides.charts/icharttextblockformat/autofit_type/) | テキストの自動調整モードを取得または設定します。<br/>            このプロパティの変更は、次のチャート部分にのみ影響を与える可能性があります： <br/>            DataLabel と DataLabelFormat（PowerPoint 2013 で完全にサポート; PowerPoint 2007 ではレンダリングに効果なし）。<br/>            読み取り/書き込み [`TextAutofitType`](/slides/python-net/ja/aspose.slides/textautofittype). |
| [`rotation_angle`](/slides/python-net/ja/aspose.slides.charts/icharttextblockformat/rotation_angle/) | バウンディングボックス内のテキストに適用されるカスタム回転を指定します。指定されていない場合、付随するシェイプの回転が使用されます。指定された場合、シェイプとは独立して適用されます。つまり、シェイプに回転が適用されると同時に、テキスト自体にも回転が適用されます。<br/>            このプロパティとプロパティ TextVerticalType の事前定義された垂直タイプから要約された視覚的テキスト回転の結果値です。<br/>            読み取り/書き込み **float**. |
