## margin_right プロパティ
TextFrame の右余白（ポイント）を取得または設定します。
Changing of this property can produce a certain influence only for these chart parts:
DataLabel と DataLabelFormat（PowerPoint 2013 で完全にサポート; PowerPoint 2007 ではレンダリングに影響なし）。
Read/write **float**。
