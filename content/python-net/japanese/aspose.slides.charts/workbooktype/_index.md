## WorkbookType 列挙型

Open XML ワークブック ファイルのタイプを指定します。

WorkbookType 型は次のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| NOT_DEFINED | ワークブックのタイプが定義されていません。 |
| WORKBOOK | Excel ワークブック (*.xlsx)。 |
| WORKBOOK_MACRO | Excel マクロ有効ワークブック (*.xlsm)。 |
| TEMPLATE | Excel テンプレート (*.xltx)。 |
| TEMPLATE_MACRO | Excel マクロ有効テンプレート (*.xltm)。 |
| WORKBOOK_BINARY_MACRO | Excel バイナリマクロ有効ワークブック (*.xlsb)。 |
