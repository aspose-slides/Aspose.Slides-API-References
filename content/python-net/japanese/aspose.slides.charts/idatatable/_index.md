## IDataTable クラス

データテーブルのプロパティを表します。

IDataTable 型は次のメンバーを公開しています:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`format`](/slides/python-net/ja/aspose.slides.charts/idatatable/format/) | オブジェクトの線、塗りつぶし、およびエフェクトスタイルを返します。<br/>            読み取り専用 [`IFormat`](/slides/python-net/ja/aspose.slides.charts/iformat). |
| [`has_border_horizontal`](/slides/python-net/ja/aspose.slides.charts/idatatable/has_border_horizontal/) | チャートのデータテーブルが水平セル罫線を持つ場合は true です。<br/>            読み書き可能 **bool**. |
| [`has_border_outline`](/slides/python-net/ja/aspose.slides.charts/idatatable/has_border_outline/) | チャートのデータテーブルが外枠罫線を持つ場合は true です。<br/>            読み書き可能 **bool**. |
| [`has_border_vertical`](/slides/python-net/ja/aspose.slides.charts/idatatable/has_border_vertical/) | チャートのデータテーブルが垂直セル罫線を持つ場合は true です。<br/>            読み書き可能 **bool**. |
| [`show_legend_key`](/slides/python-net/ja/aspose.slides.charts/idatatable/show_legend_key/) | データ ラベルの凡例キーが表示されている場合は true です。<br/>            読み書き可能 **bool**. |
