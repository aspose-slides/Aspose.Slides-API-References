## ChartLinesFormat クラス

グリッドラインの書式プロパティを表します。

ChartLinesFormat 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`line`](/slides/python-net/ja/aspose.slides.charts/chartlinesformat/line/) | チャートラインの線スタイルプロパティを返します。<br/>            読み取り専用 [`ILineFormat`](/slides/python-net/ja/aspose.slides/ilineformat). |
| [`effect`](/slides/python-net/ja/aspose.slides.charts/chartlinesformat/effect/) | チャートラインで使用されるエフェクトを返します。<br/>            読み取り専用 [`IEffectFormat`](/slides/python-net/ja/aspose.slides/ieffectformat). |
