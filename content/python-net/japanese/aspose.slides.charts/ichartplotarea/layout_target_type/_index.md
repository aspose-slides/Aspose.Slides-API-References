## layout_target_type プロパティ
プロット領域のレイアウトが手動で定義されている場合、このプロパティは、
             プロット領域を内部（軸と軸ラベルを含まない）でレイアウトするか、外部
             （軸と軸ラベルを含む）を指定します。
             読み取り/書き込み [`IChartPlotArea.layout_target_type`](/slides/python-net/ja/aspose.slides.charts/ichartplotarea/layout_target_type).
