## IChartWall クラス

3D チャート上の壁を表します。

IChartWall 型は次のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`thickness`](/slides/python-net/ja/aspose.slides.charts/ichartwall/thickness/) | 壁の厚さをプロット ボリュームの最大寸法のパーセンテージとして取得または設定します。<br/>            読み書き **int**. |
| [`format`](/slides/python-net/ja/aspose.slides.charts/ichartwall/format/) | 壁の塗りつぶし、線、効果、3D スタイルを取得します。<br/>            読み取り専用 [`IFormat`](/slides/python-net/ja/aspose.slides.charts/iformat). |
| [`picture_type`](/slides/python-net/ja/aspose.slides.charts/ichartwall/picture_type/) | 画像のタイプを取得または設定します。<br/>            読み書き [`IChartWall.picture_type`](/slides/python-net/ja/aspose.slides.charts/ichartwall/picture_type). |
