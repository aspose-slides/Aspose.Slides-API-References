## ChartPlotArea クラス

Chart が描画されるべき矩形を表します。

ChartPlotArea 型は以下のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`format`](/slides/python-net/ja/aspose.slides.charts/chartplotarea/format/) | プロット領域の書式を返します。<br/>            読み取り専用 [`IFormat`](/slides/python-net/ja/aspose.slides.charts/iformat). |
| [`x`](/slides/python-net/ja/aspose.slides.charts/chartplotarea/x/) | プロット領域バウンディングボックスの左上隅の x 座標を、チャートの幅の比率（0 から 1）で返すまたは設定します。<br/>            読み書き可能 **float**. |
| [`y`](/slides/python-net/ja/aspose.slides.charts/chartplotarea/y/) | プロット領域バウンディングボックスの左上隅の y 座標を、チャートの高さの比率（0 から 1）で返すまたは設定します。<br/>            読み書き可能 **float**. |
| [`width`](/slides/python-net/ja/aspose.slides.charts/chartplotarea/width/) | プロット領域バウンディングボックスの幅を、チャートの幅の比率（0 から 1）で返すまたは設定します。<br/>            読み書き可能 **float**. |
| [`height`](/slides/python-net/ja/aspose.slides.charts/chartplotarea/height/) | プロット領域バウンディングボックスの高さを、チャートの高さの比率（0 から 1）で返すまたは設定します。<br/>            読み書き可能 **float**. |
| [`right`](/slides/python-net/ja/aspose.slides.charts/chartplotarea/right/) | 右。<br/>            読み取り専用 **float**. |
| [`bottom`](/slides/python-net/ja/aspose.slides.charts/chartplotarea/bottom/) | 下。<br/>            読み取り専用 **float**. |
| [`chart`](/slides/python-net/ja/aspose.slides.charts/chartplotarea/chart/) | チャート。<br/>            読み取り専用 [`IChart`](/slides/python-net/ja/aspose.slides.charts/ichart). |
| [`is_location_autocalculated`](/slides/python-net/ja/aspose.slides.charts/chartplotarea/is_location_autocalculated/) | 位置の計算方法を定義します: true – 自動計算; X、Y、Width、Height プロパティで定義。<br/>            読み取り専用 **bool**. |
| [`layout_target_type`](/slides/python-net/ja/aspose.slides.charts/chartplotarea/layout_target_type/) | プロット領域のレイアウトが手動で定義されている場合、このプロパティは領域を内部（軸と軸ラベルを除く）または外部（軸と軸ラベルを含む）でレイアウトするかを指定します。<br/>            読み書き可能 [`ChartPlotArea.layout_target_type`](/slides/python-net/ja/aspose.slides.charts/chartplotarea/layout_target_type). |
| [`actual_x`](/slides/python-net/ja/aspose.slides.charts/chartplotarea/actual_x/) | チャート要素の実際の x 位置（左）を、チャートの左上隅に対する相対位置で指定します。<br/>            実際の値を取得するには事前に IChart.ValidateChartLayout() メソッドを呼び出してください。<br/>            読み取り **float**. |
| [`actual_y`](/slides/python-net/ja/aspose.slides.charts/chartplotarea/actual_y/) | チャート要素の実際の上位置を、チャートの左上隅に対する相対位置で指定します。<br/>            実際の値を取得するには事前に IChart.ValidateChartLayout() メソッドを呼び出してください。<br/>            読み取り **float**. |
| [`actual_width`](/slides/python-net/ja/aspose.slides.charts/chartplotarea/actual_width/) | チャート要素の実際の幅を指定します。実際の値を取得するには事前に IChart.ValidateChartLayout() メソッドを呼び出してください。<br/>            読み取り **float**. |
| [`actual_height`](/slides/python-net/ja/aspose.slides.charts/chartplotarea/actual_height/) | チャート要素の実際の高さを指定します。実際の値を取得するには事前に IChart.ValidateChartLayout() メソッドを呼び出してください。<br/>            読み取り **float**. |
| [`slide`](/slides/python-net/ja/aspose.slides.charts/chartplotarea/slide/) |  |
