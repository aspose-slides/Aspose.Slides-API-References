## data_source_type プロパティ
子孫で実際に使用されている AsCell、AsCells、AsLiteralString、または AsLiteralDouble プロパティかどうかを指定します。つまり、Data プロパティの値の型を指定します。読み書き [`DataSourceType`](/slides/python-net/ja/aspose.slides.charts/datasourcetype)。


### 備考

ChartDataPointCollection のポイントの場合、このプロパティは読み取り専用です。この場合、このプロパティの値を変更するには、ChartDataPointCollection.DataSourceTypeFor<...> プロパティのいずれかを使用できます。
