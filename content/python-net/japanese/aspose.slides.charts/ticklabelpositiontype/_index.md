## TickLabelPositionType 列挙型

指定された軸上の目盛りラベルの位置タイプを表します。

TickLabelPositionType 型は次のメンバーを公開します:

## フィールド

| フィールド | 説明 |
| :- | :- |
| HIGH | 軸ラベルは垂直軸の上端に配置されます。 |
| LOW | 軸ラベルは垂直軸の下端に配置されます。 |
| NEXT_TO | 軸ラベルは軸の隣に配置されます。 |
| NONE | 軸ラベルは描画されません。 |
