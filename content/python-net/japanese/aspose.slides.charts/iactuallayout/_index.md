## IActualLayout クラス

チャート要素の実際の位置を指定します。

IActualLayout 型は以下のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`actual_x`](/slides/python-net/ja/aspose.slides.charts/iactuallayout/actual_x/) | チャート要素の左上隅に対する実際の x 位置（左）を指定します。<br/>            IChart.ValidateChartLayout() メソッドを呼び出して実際の値を取得してください。 <br/>            **float** を読み取ります。 |
| [`actual_y`](/slides/python-net/ja/aspose.slides.charts/iactuallayout/actual_y/) | チャート要素の左上隅に対する実際の上位置を指定します。<br/>            IChart.ValidateChartLayout() メソッドを呼び出して実際の値を取得してください。 <br/>            **float** を読み取ります。 |
| [`actual_width`](/slides/python-net/ja/aspose.slides.charts/iactuallayout/actual_width/) | チャート要素の実際の幅を指定します。 IChart.ValidateChartLayout() メソッドを呼び出して実際の値を取得してください。 <br/>            **float** を読み取ります。 |
| [`actual_height`](/slides/python-net/ja/aspose.slides.charts/iactuallayout/actual_height/) | チャート要素の実際の高さを指定します。 IChart.ValidateChartLayout() メソッドを呼び出して実際の値を取得してください。 <br/>            **float** を読み取ります。 |
