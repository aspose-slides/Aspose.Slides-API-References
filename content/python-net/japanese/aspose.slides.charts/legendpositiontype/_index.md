## LegendPositionType 列挙

チャート上の凡例の位置を決定します。

LegendPositionType 型は次のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| BOTTOM | 凡例がチャートの下部に描画されることを指定します。 |
| LEFT | 凡例がチャートの左側に描画されることを指定します。 |
| RIGHT | 凡例がチャートの右側に描画されることを指定します。 |
| TOP | 凡例がチャートの上部に描画されることを指定します。 |
| TOP_RIGHT | 凡例がチャートの右上に描画されることを指定します。 |
