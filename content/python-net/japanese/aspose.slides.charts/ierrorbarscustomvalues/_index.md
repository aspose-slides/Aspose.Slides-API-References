## IErrorBarsCustomValues クラス

エラーバーの値を指定します。Error bars value type が Custom の場合にのみ使用する必要があります。

IErrorBarsCustomValues 型は次のメンバーを公開します。

## プロパティ

| Property | Description |
| :- | :- |
| [`x_minus`](/slides/python-net/ja/aspose.slides.charts/ierrorbarscustomvalues/x_minus/) | エラーバーの値を負方向に指定します。<br/>            エラーバーの値タイプが Custom であり、ErrorBarsXFormat が許可されている場合に利用可能です。<br/>            それ以外の場合、このプロパティは None を返します。<br/>            読み取り専用 [`IDoubleChartValue`](/slides/python-net/ja/aspose.slides.charts/idoublechartvalue). |
| [`y_minus`](/slides/python-net/ja/aspose.slides.charts/ierrorbarscustomvalues/y_minus/) | エラーバーの値を負方向に指定します。<br/>            エラーバーの値タイプが Custom であり、ErrorBarsYFormat が許可されている場合に利用可能です。<br/>            それ以外の場合、このプロパティは None を返します。<br/>            読み取り専用 [`IDoubleChartValue`](/slides/python-net/ja/aspose.slides.charts/idoublechartvalue). |
| [`x_plus`](/slides/python-net/ja/aspose.slides.charts/ierrorbarscustomvalues/x_plus/) | エラーバーの値を正方向に指定します。<br/>            エラーバーの値タイプが Custom であり、ErrorBarsXFormat が許可されている場合に利用可能です。<br/>            それ以外の場合、このプロパティは None を返します。<br/>            読み取り専用 [`IDoubleChartValue`](/slides/python-net/ja/aspose.slides.charts/idoublechartvalue). |
| [`y_plus`](/slides/python-net/ja/aspose.slides.charts/ierrorbarscustomvalues/y_plus/) | エラーバーの値を正方向に指定します。<br/>            エラーバーの値タイプが Custom であり、ErrorBarsYFormat が許可されている場合に利用可能です。<br/>            それ以外の場合、このプロパティは None を返します。<br/>            読み取り専用 [`IDoubleChartValue`](/slides/python-net/ja/aspose.slides.charts/idoublechartvalue). |
