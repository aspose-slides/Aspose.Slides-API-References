## IFormat クラス

チャートの書式プロパティを表します。

IFormat 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`fill`](/slides/python-net/ja/aspose.slides.charts/iformat/fill/) | チャートの塗りつぶしスタイル プロパティを返します。<br/>            読み取り専用 [`IFillFormat`](/slides/python-net/ja/aspose.slides/ifillformat). |
| [`line`](/slides/python-net/ja/aspose.slides.charts/iformat/line/) | チャートの線スタイル プロパティを返します。<br/>            読み取り専用 [`ILineFormat`](/slides/python-net/ja/aspose.slides/ilineformat). |
| [`effect`](/slides/python-net/ja/aspose.slides.charts/iformat/effect/) | チャートで使用されるエフェクトを返します。<br/>            読み取り専用 [`IEffectFormat`](/slides/python-net/ja/aspose.slides/ieffectformat). |
| [`effect_3d`](/slides/python-net/ja/aspose.slides.charts/iformat/effect_3d/) | チャートの 3D 書式を返します。<br/>            読み取り専用 [`IThreeDFormat`](/slides/python-net/ja/aspose.slides/ithreedformat). |
