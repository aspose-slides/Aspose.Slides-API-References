## ChartTextFormat クラス

チャート テキスト要素のデフォルトのテキスト書式を指定します。

ChartTextFormat 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`text_block_format`](/slides/python-net/ja/aspose.slides.charts/charttextformat/text_block_format/) | TextBlockFormat.<br/>            読み取り専用 [`IChartTextBlockFormat`](/slides/python-net/ja/aspose.slides.charts/icharttextblockformat). |
| [`paragraph_format`](/slides/python-net/ja/aspose.slides.charts/charttextformat/paragraph_format/) | ParagraphFormat.<br/>            読み取り専用 [`IChartParagraphFormat`](/slides/python-net/ja/aspose.slides.charts/ichartparagraphformat). |
| [`portion_format`](/slides/python-net/ja/aspose.slides.charts/charttextformat/portion_format/) | PortionFormat.<br/>            読み取り専用 [`IChartPortionFormat`](/slides/python-net/ja/aspose.slides.charts/ichartportionformat). |

## メソッド

| メソッド | 説明 |
| :- | :- |
