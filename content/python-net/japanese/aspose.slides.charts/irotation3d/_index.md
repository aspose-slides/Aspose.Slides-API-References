## IRotation3D クラス

チャートの 3D 回転を表します。

IRotation3D 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`rotation_x`](/slides/python-net/ja/aspose.slides.charts/irotation3d/rotation_x/) | X 軸周りの回転角度（3D グラフの場合は Y 方向）を取得または設定します（-90 から 90 度の範囲）。<br/>            このプロパティは ECMA-376 の 21.2.2.157 rotX（X Rotation）項目および PowerPoint 2007 以降の "Y Rotation" オプションに対応しています。<br/>            読み取り/書き込み **int**. |
| [`rotation_y`](/slides/python-net/ja/aspose.slides.charts/irotation3d/rotation_y/) | Y 軸周りの回転角度（3D グラフの場合は X 方向）を取得または設定します（0 から 360 度の範囲）。<br/>            このプロパティは ECMA-376 の 21.2.2.158 rotY（Y Rotation）項目および PowerPoint 2007 以降の "X Rotation" オプションに対応しています。<br/>            読み取り/書き込み **int**. |
| [`perspective`](/slides/python-net/ja/aspose.slides.charts/irotation3d/perspective/) | 3D グラフの視点値（視野角）を取得または設定します（0 から 100 の範囲）。<br/>            RightAngleAxes プロパティの値が true の場合は無視されます。<br/>            読み取り/書き込み **int**. |
| [`right_angle_axes`](/slides/python-net/ja/aspose.slides.charts/irotation3d/right_angle_axes/) | チャートの軸が透視図法ではなく直角であるかどうかを決定します。<br/>            言い換えれば、軸の角度がチャートの<br/>            回転や傾斜とは独立しているかどうかを判定します。<br/>            読み取り/書き込み **bool**. |
| [`depth_percents`](/slides/python-net/ja/aspose.slides.charts/irotation3d/depth_percents/) | 3D グラフの深さをチャート幅のパーセンテージで取得または設定します（20% から 2000% の範囲）。<br/>            読み取り/書き込み **int**. |
| [`height_percents`](/slides/python-net/ja/aspose.slides.charts/irotation3d/height_percents/) | 3D グラフの高さをチャート幅のパーセンテージで指定します（5% から 500% の範囲）。<br/>            読み取り/書き込み **int**. |
