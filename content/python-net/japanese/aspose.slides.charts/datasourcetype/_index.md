## DataSourceType 列挙型

データ ソース タイプ。

DataSourceType 型は次のメンバーを公開します:

## フィールド

| フィールド | 説明 |
| :- | :- |
| WORKSHEET | データ ポイントの XValue、YValue、Value、または BubbleSize を保存するために CellXls オブジェクトを使用します（ワークシート内）。 |
| STRING_LITERALS | 高速アクセス文字列変数を使用して XValue、YValue、Value、または <br/>            データ ポイントを保存します。Worksheet は値の保存に使用されません。 |
| DOUBLE_LITERALS | 高速アクセス double 変数を使用して XValue、YValue、Value、または <br/>            データ ポイントを保存します。Worksheet は値の保存に使用されません。 |
