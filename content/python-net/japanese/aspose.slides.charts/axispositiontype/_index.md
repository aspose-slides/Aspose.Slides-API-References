## AxisPositionType 列挙体

軸の位置を決定します。

AxisPositionType 型は次のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| BOTTOM | プロット領域の下部に軸が表示されることを指定します。 |
| LEFT | プロット領域の左側に軸が表示されることを指定します。 |
| RIGHT | プロット領域の右側に軸が表示されることを指定します。 |
| TOP | プロット領域の上部に軸が表示されることを指定します。 |
