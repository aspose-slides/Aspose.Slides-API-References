## ErrorBarType 列挙型

エラーバーのタイプを表します

ErrorBarType 型は次のメンバーを公開します:

## フィールド

| フィールド | 説明 |
| :- | :- |
| BOTH | エラーバーが正方向および負方向の両方に表示されることを指定します。 |
| MINUS | エラーバーが負方向のみに表示されることを指定します。 |
| PLUS | エラーバーが正方向のみに表示されることを指定します。 |
