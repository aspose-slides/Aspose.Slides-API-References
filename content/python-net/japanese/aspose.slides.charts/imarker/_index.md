## IMarker クラス

IMarker はチャートのマーカーを表します。

IMarker 型は次のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`symbol`](/slides/python-net/ja/aspose.slides.charts/imarker/symbol/) | ラインチャート、散布図、またはレーダーチャートにおけるマーカースタイルを表します。<br/>            読み取り/書き込み [`MarkerStyleType`](/slides/python-net/ja/aspose.slides.charts/markerstyletype). |
| [`format`](/slides/python-net/ja/aspose.slides.charts/imarker/format/) | マーカーの塗りつぶしを取得します。<br/>            読み取り専用 [`IFormat`](/slides/python-net/ja/aspose.slides.charts/iformat). |
| [`size`](/slides/python-net/ja/aspose.slides.charts/imarker/size/) | ラインチャート、散布図、またはレーダーチャートにおけるマーカーサイズを表します。<br/>            読み取り/書き込み **int**. |
