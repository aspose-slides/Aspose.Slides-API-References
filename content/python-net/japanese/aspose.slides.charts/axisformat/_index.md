## AxisFormat クラス

チャートの書式プロパティを表します。

AxisFormat タイプは次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`fill`](/slides/python-net/ja/aspose.slides.charts/axisformat/fill/) | 軸の塗りつぶしスタイルプロパティを返します。<br/>            読み取り専用 [`IFillFormat`](/slides/python-net/ja/aspose.slides/ifillformat). |
| [`line`](/slides/python-net/ja/aspose.slides.charts/axisformat/line/) | 軸の線スタイルプロパティを返します。<br/>            読み取り専用 [`ILineFormat`](/slides/python-net/ja/aspose.slides/ilineformat). |
| [`effect`](/slides/python-net/ja/aspose.slides.charts/axisformat/effect/) | 軸に使用されるエフェクトを返します。<br/>            読み取り専用 [`IEffectFormat`](/slides/python-net/ja/aspose.slides/ieffectformat). |
