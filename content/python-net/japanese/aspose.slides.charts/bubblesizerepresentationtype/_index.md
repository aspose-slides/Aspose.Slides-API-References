## BubbleSizeRepresentationType 列挙体

バブルチャートのサイズとしてデータを表現する可能な方法を指定します。

BubbleSizeRepresentationType 型は次のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| AREA | バブルの面積がバブルサイズの値に比例するように指定します。 |
| WIDTH | バブルの半径がバブルサイズの値に比例するように指定します。 |
