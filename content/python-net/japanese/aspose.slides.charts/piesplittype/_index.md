## PieSplitType 列挙体

この型は、pie-of-pie または bar-of-pie チャートにおける第2の円または棒の分割点の種類を表します。

PieSplitType 型は次のメンバーを公開します:

## フィールド

| フィールド | 説明 |
| :- | :- |
| DEFAULT | デフォルトの <br/> メカニズムを使用してこのチャートタイプのデータポイントを分割することを指定します。 |
| CUSTOM | カスタム分割値に従って、円と第2のチャート間でデータポイントを分割することを指定します。 |
| BY_PERCENTAGE | パーセンテージが Split Position のパーセント未満のポイントを第2のチャートに配置し、円と第2のチャート間でデータポイントを分割することを指定します。 |
| BY_POS | データポイントの最後の Split Position を第2のチャートに配置し、円と第2のチャート間でデータポイントを分割することを指定します。 |
| BY_VALUE | Split Position 未満の値を持つデータポイントを第2のチャートに配置し、円と第2のチャート間でデータポイントを分割することを指定します。 |
