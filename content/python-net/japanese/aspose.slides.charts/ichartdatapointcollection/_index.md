## IChartDataPointCollection クラス

シリーズ データポイントのコレクションを表します。

IChartDataPointCollection 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`data_source_type_for_x_values`](/slides/python-net/ja/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_x_values/) | AsCell または AsLiteralString または AsLiteralDouble プロパティがデータポイントの XValue プロパティオブジェクトで実際に使用されているかを指定します。<br/>            他の言い方をすれば、ChartDataPointEx.XValue.Data プロパティの値の型を指定します。<br/>            読み取り/書き込み [`DataSourceType`](/slides/python-net/ja/aspose.slides.charts/datasourcetype)。 |
| [`data_source_type_for_y_values`](/slides/python-net/ja/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_y_values/) | AsCell または AsLiteralString または AsLiteralDouble プロパティがデータポイントの YValue プロパティオブジェクトで実際に使用されているかを指定します。<br/>            他の言い方をすれば、ChartDataPointEx.YValue.Data プロパティの値の型を指定します。<br/>            読み取り/書き込み [`DataSourceType`](/slides/python-net/ja/aspose.slides.charts/datasourcetype)。 |
| [`data_source_type_for_bubble_sizes`](/slides/python-net/ja/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_bubble_sizes/) | AsCell または AsLiteralString または AsLiteralDouble プロパティがデータポイントの BubbleSize プロパティオブジェクトで実際に使用されているかを指定します。<br/>            他の言い方をすれば、ChartDataPointEx.BubbleSize.Data プロパティの値の型を指定します。<br/>            読み取り/書き込み [`DataSourceType`](/slides/python-net/ja/aspose.slides.charts/datasourcetype)。 |
| [`data_source_type_for_values`](/slides/python-net/ja/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_values/) | AsCell または AsLiteralString または AsLiteralDouble プロパティがデータポイントの Value プロパティオブジェクトで実際に使用されているかを指定します。<br/>            他の言い方をすれば、ChartDataPoint.Value.Data プロパティの値の型を指定します。<br/>            読み取り/書き込み [`DataSourceType`](/slides/python-net/ja/aspose.slides.charts/datasourcetype)。 |
| [`data_source_type_for_error_bars_custom_values`](/slides/python-net/ja/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_error_bars_custom_values/) | ChartDataPoint.ErrorBarsCustomValues プロパティ リスト内の値の型を指定します。<br/>            読み取り専用 [`IDataSourceTypeForErrorBarsCustomValues`](/slides/python-net/ja/aspose.slides.charts/idatasourcetypeforerrorbarscustomvalues)。 |

コレクション内のインデックス（シリアル番号）でシリーズ データポイントを返します。
