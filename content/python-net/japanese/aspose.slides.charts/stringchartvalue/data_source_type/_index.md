## data_source_type プロパティ
Specifies whether AsCell, AsCells, AsLiteralString or AsLiteralDouble プロパティが子孫で実際に使用されるかを指定します。  
言い換えれば、Data プロパティの値のタイプを指定します。  
読み取り/書き込み [`DataSourceType`](/slides/python-net/ja/aspose.slides.charts/datasourcetype)。

### 備考
ChartDataPointCollection のポイントについてはこのプロパティは読み取り専用です。  
この場合、このプロパティの値を変更するには、ChartDataPointCollection.DataSourceTypeFor<...> プロパティのいずれかを使用できます。
