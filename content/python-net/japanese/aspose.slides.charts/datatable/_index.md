## DataTable クラス

データテーブルのプロパティを表します。

DataTable 型は以下のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`format`](/slides/python-net/ja/aspose.slides.charts/datatable/format/) | オブジェクトの線、塗り、エフェクトスタイルを返します。<br/>            読み取り専用 [`IFormat`](/slides/python-net/ja/aspose.slides.charts/iformat)。 |
| [`has_border_horizontal`](/slides/python-net/ja/aspose.slides.charts/datatable/has_border_horizontal/) | チャートのデータテーブルに水平セル枠線がある場合は True。<br/>            読み書き **bool**。 |
| [`has_border_outline`](/slides/python-net/ja/aspose.slides.charts/datatable/has_border_outline/) | チャートのデータテーブルにアウトライン枠線がある場合は True。<br/>            読み書き **bool**。 |
| [`has_border_vertical`](/slides/python-net/ja/aspose.slides.charts/datatable/has_border_vertical/) | チャートのデータテーブルに垂直セル枠線がある場合は True。<br/>            読み書き **bool**。 |
| [`show_legend_key`](/slides/python-net/ja/aspose.slides.charts/datatable/show_legend_key/) | データラベルの凡例キーが表示されている場合は True。<br/>            読み書き **bool**。 |
| [`chart`](/slides/python-net/ja/aspose.slides.charts/datatable/chart/) | チャートを返します。<br/>            読み取り専用 [`IChart`](/slides/python-net/ja/aspose.slides.charts/ichart)。 |
| [`text_format`](/slides/python-net/ja/aspose.slides.charts/datatable/text_format/) | テキスト形式を返します。<br/>            読み取り専用 [`IChartTextFormat`](/slides/python-net/ja/aspose.slides.charts/icharttextformat)。 |
| [`slide`](/slides/python-net/ja/aspose.slides.charts/datatable/slide/) |  |
| [`presentation`](/slides/python-net/ja/aspose.slides.charts/datatable/presentation/) |  |
