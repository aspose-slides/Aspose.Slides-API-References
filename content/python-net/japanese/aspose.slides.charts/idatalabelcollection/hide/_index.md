## hide(self) {#}
すべての Show*-フラグ (ShowValue, ...) をデフォルトで false に設定することで、データ ラベルをデフォルトで非表示にします。
            DefaultDataLabelFormat プロパティを false の状態にします。
            この後、IsVisible は false になります。

```python
def hide(self):
    ...
```

### 備考
デフォルトでデータ ラベルが表示されていない場合 (IsVisible は false)、データ ラベルを「表示」 
            デフォルトで\" と設定することで、Show*-フラグ (ShowValue, ...) を DefaultDataLabelFormat プロパティで 
            true の状態に設定できます。
