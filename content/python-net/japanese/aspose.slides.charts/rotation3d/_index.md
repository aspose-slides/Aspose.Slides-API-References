## Rotation3D クラス

チャートの 3D 回転を表します。

Rotation3D 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`rotation_x`](/slides/python-net/ja/aspose.slides.charts/rotation3d/rotation_x/) | X 軸周りの回転角度を取得または設定します。つまり 3D チャートでは Y 方向です (-90 から 90 度の間)。<br/>            このプロパティは ECMA-376 の 21.2.2.157 rotX (X Rotation) 項目および PowerPoint 2007 以降の「Y Rotation」オプションに対応しています。<br/>            読み取り/書き込み **int**。 |
| [`rotation_y`](/slides/python-net/ja/aspose.slides.charts/rotation3d/rotation_y/) | Y 軸周りの回転角度を取得または設定します。つまり 3D チャートでは X 方向です (0 から 360 度の間)。<br/>            このプロパティは ECMA-376 の 21.2.2.158 rotY (Y Rotation) 項目および PowerPoint 2007 以降の「X Rotation」オプションに対応しています。<br/>            読み取り/書き込み **int**。 |
| [`perspective`](/slides/python-net/ja/aspose.slides.charts/rotation3d/perspective/) | 3D チャートの遠近感の値 (視野角) を取得または設定します (0 から 240 の間)。<br/>            RightAngleAxes プロパティが true の場合は無視されます。<br/>            読み取り/書き込み **int**。 |
| [`right_angle_axes`](/slides/python-net/ja/aspose.slides.charts/rotation3d/right_angle_axes/) | チャートの軸が遠近投影ではなく直角であるかどうかを決定します。<br/>            言い換えると、軸の角度がチャートの回転や標高から独立しているかどうかを決定します。<br/>            読み取り/書き込み **bool**。 |
| [`depth_percents`](/slides/python-net/ja/aspose.slides.charts/rotation3d/depth_percents/) | 3D チャートの深さをチャート幅のパーセンテージで取得または設定します (20% から 2000% の間)。<br/>            読み取り/書き込み **int**。 |
| [`height_percents`](/slides/python-net/ja/aspose.slides.charts/rotation3d/height_percents/) | 3D チャートの高さをチャート幅のパーセンテージで指定します (5% から 500% の間)。<br/>            読み取り/書き込み **int**。 |
