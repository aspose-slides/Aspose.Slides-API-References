## CrossesType 列挙型

軸がどこで交差するかを決定します。

CrossesType 型は次のメンバーを公開します。

## Fields

| Field | Description |
| :- | :- |
| AXIS_CROSSES_AT_ZERO | カテゴリ軸は、値軸のゼロ点で交差します（可能な場合）、それが不可能な場合は最小値（最小がゼロより大きい場合）または最大値（最大がゼロ未満の場合）で交差します。 |
| MAXIMUM | 軸は最大値で交差します。 |
| CUSTOM | プロパティ CrossAt のカスタム値。 |
