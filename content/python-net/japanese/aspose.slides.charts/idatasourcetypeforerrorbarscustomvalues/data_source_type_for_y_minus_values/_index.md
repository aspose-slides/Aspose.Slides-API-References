## data_source_type_for_y_minus_values プロパティ
Specifies whether AsCell or AsLiteralString or AsLiteralDouble プロパティ 
            がエラーバー カスタム値 用のデータポイント YMinus プロパティ オブジェクトで実際に使用されるかを指定します。別の言い方をすれば、ChartDataPointEx.ErrorBarsCustomValues.YMinus.Data プロパティ の値のタイプを指定します。
            読み取り/書き込み [`DataSourceType`](/slides/python-net/ja/aspose.slides.charts/datasourcetype).
