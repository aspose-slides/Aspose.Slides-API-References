## ChartShapeType 列挙型

チャートの形状を表します。

ChartShapeType 型は次のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| NOT_DEFINED | チャートの形状が定義されていません。 |
| BOX | チャートはボックス形状で描画されることを指定します。 |
| CONE | チャートは円錐として描画されることを指定します。円錐の底部は床にあり、円錐の先端はデータ マーカーの上部にあります。 |
| CONE_TO_MAX | チャートは切頭円錐で描画され、円錐の先端が最大データ値になるように指定します。 |
| CYLINDER | チャートはシリンダーとして描画されることを指定します。 |
| PYRAMID | チャートは長方形のピラミッドとして描画されることを指定します。ピラミッドの底部は床にあり、ピラミッドの先端はデータ マーカーの上部にあります。 |
| PYRAMID_TO_MAXIMUM | チャートは切頭ピラミッドで描画され、ピラミッドの先端が最大データ値になるように指定します。 |
