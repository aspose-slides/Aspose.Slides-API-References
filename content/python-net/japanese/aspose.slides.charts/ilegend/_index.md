## ILegend クラス

チャートの凡例プロパティを表します。

ILegend 型は次のメンバーを公開します。

## プロパティ

| Property | Description |
| :- | :- |
| [`overlay`](/slides/python-net/ja/aspose.slides.charts/ilegend/overlay/) | 他のチャート要素が凡例と重なることを許可するかどうかを決定します。<br/>            読み取り/書き込み **bool**。 |
| [`position`](/slides/python-net/ja/aspose.slides.charts/ilegend/position/) | チャート上の凡例の位置を指定します。<br/>            X、Y、Width、Heigt プロパティの NaN でない値はこのプロパティの効果を上書きします。<br/>            読み取り/書き込み [`LegendPositionType`](/slides/python-net/ja/aspose.slides.charts/legendpositiontype)。 |
| [`format`](/slides/python-net/ja/aspose.slides.charts/ilegend/format/) | 凡例の書式を返します。<br/>            読み取り専用 [`IFormat`](/slides/python-net/ja/aspose.slides.charts/iformat)。 |
