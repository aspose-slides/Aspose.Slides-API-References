## ChartDataPointCollection クラス

シリーズのデータポイントのコレクションを表します。

ChartDataPointCollection 型は以下のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`data_source_type_for_x_values`](/slides/python-net/ja/aspose.slides.charts/chartdatapointcollection/data_source_type_for_x_values/) | AsCell または AsLiteralString または AsLiteralDouble プロパティが<br/>            データポイントの XValue プロパティオブジェクトで実際に使用されているかを指定します。言い換えれば、<br/>            ChartDataPoint.XValue.Data プロパティの値の型を指定します。<br/>            読み取り/書き込み [`DataSourceType`](/slides/python-net/ja/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_y_values`](/slides/python-net/ja/aspose.slides.charts/chartdatapointcollection/data_source_type_for_y_values/) | AsCell または AsLiteralString または AsLiteralDouble プロパティが<br/>            データポイントの YValue プロパティオブジェクトで実際に使用されているかを指定します。言い換えれば、<br/>            ChartDataPoint.YValue.Data プロパティの値の型を指定します。<br/>            読み取り/書き込み [`DataSourceType`](/slides/python-net/ja/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_bubble_sizes`](/slides/python-net/ja/aspose.slides.charts/chartdatapointcollection/data_source_type_for_bubble_sizes/) | AsCell または AsLiteralString または AsLiteralDouble プロパティが<br/>            データポイントの BubbleSize プロパティオブジェクトで実際に使用されているかを指定します。言い換えれば、<br/>            ChartDataPoint.BubbleSize.Data プロパティの値の型を指定します。<br/>            読み取り/書き込み [`DataSourceType`](/slides/python-net/ja/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_values`](/slides/python-net/ja/aspose.slides.charts/chartdatapointcollection/data_source_type_for_values/) | AsCell または AsLiteralString または AsLiteralDouble プロパティが<br/>            データポイントの Value プロパティオブジェクトで実際に使用されているかを指定します。言い換えれば、<br/>            ChartDataPoint.Value.Data プロパティの値の型を指定します。<br/>            読み取り/書き込み [`DataSourceType`](/slides/python-net/ja/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_error_bars_custom_values`](/slides/python-net/ja/aspose.slides.charts/chartdatapointcollection/data_source_type_for_error_bars_custom_values/) | ChartDataPoint.ErrorBarsCustomValues プロパティリスト内の値の型を指定します。<br/>            読み取り専用 [`IDataSourceTypeForErrorBarsCustomValues`](/slides/python-net/ja/aspose.slides.charts/idatasourcetypeforerrorbarscustomvalues). |

インデックス (このコレクション内のシリアル番号) によってシリーズのデータポイントを返します。
