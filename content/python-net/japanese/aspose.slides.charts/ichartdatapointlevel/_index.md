## IChartDataPointLevel クラス

データ ポイント レベルを表します。Treemap と Sunburst チャートに適用されます。

IChartDataPointLevel 型は以下のメンバーを公開します：

## プロパティ

| Property | Description |
| :- | :- |
| [`format`](/slides/python-net/ja/aspose.slides.charts/ichartdatapointlevel/format/) | データ ポイント レベルの書式設定プロパティを表します。<br/>            読み取り/書き込み [`IFormat`](/slides/python-net/ja/aspose.slides.charts/iformat). |
| [`label`](/slides/python-net/ja/aspose.slides.charts/ichartdatapointlevel/label/) | データ ポイント レベルのデータ ラベルを表します。Treemap と Sunburst シリーズ タイプに適用されます。<br/>            読み取り専用 [`IDataLabel`](/slides/python-net/ja/aspose.slides.charts/idatalabel). |
