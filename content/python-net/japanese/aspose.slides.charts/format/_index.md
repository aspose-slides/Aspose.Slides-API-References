## Format クラス

チャートのフォーマットプロパティを表します。

**継承:**[`Format`](/slides/python-net/ja/aspose.slides.charts/format) → [`PVIObject`](/slides/python-net/ja/aspose.slides/pviobject)

Format 型は以下のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`fill`](/slides/python-net/ja/aspose.slides.charts/format/fill/) | チャートの塗りつぶしスタイルプロパティを返します。<br/>            読み取り専用 [`IFillFormat`](/slides/python-net/ja/aspose.slides/ifillformat). |
| [`line`](/slides/python-net/ja/aspose.slides.charts/format/line/) | チャートの線スタイルプロパティを返します。<br/>            読み取り専用 [`ILineFormat`](/slides/python-net/ja/aspose.slides/ilineformat). |
| [`effect`](/slides/python-net/ja/aspose.slides.charts/format/effect/) | チャートで使用されるエフェクトを返します。<br/>            読み取り専用 [`IEffectFormat`](/slides/python-net/ja/aspose.slides/ieffectformat). |
| [`effect_3d`](/slides/python-net/ja/aspose.slides.charts/format/effect_3d/) | チャートの3D形式を返します。<br/>            読み取り専用 [`IThreeDFormat`](/slides/python-net/ja/aspose.slides/ithreedformat). |
| [`slide`](/slides/python-net/ja/aspose.slides.charts/format/slide/) |  |
