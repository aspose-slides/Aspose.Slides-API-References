## IChartParagraphFormat クラス

チャートの段落書式設定プロパティを表します。

IChartParagraphFormat 型は次のメンバーを公開します。

## プロパティ

| Property | Description |
| :- | :- |
| [`alignment`](/slides/python-net/ja/aspose.slides.charts/ichartparagraphformat/alignment/) | 段落のテキスト配置を取得または設定します。<br/>            読み書き [`TextAlignment`](/slides/python-net/ja/aspose.slides/textalignment)。 |
| [`space_within`](/slides/python-net/ja/aspose.slides.charts/ichartparagraphformat/space_within/) | 段落のベースライン間のスペース量を取得または設定します。<br/>            読み書き **float**。 |
| [`space_before`](/slides/python-net/ja/aspose.slides.charts/ichartparagraphformat/space_before/) | 段落の最初の行の前のスペース量を取得または設定します。<br/>            読み書き **float**。 |
| [`space_after`](/slides/python-net/ja/aspose.slides.charts/ichartparagraphformat/space_after/) | 段落の最後の行の後のスペース量を取得または設定します。<br/>            読み書き **float**。 |
| [`east_asian_line_break`](/slides/python-net/ja/aspose.slides.charts/ichartparagraphformat/east_asian_line_break/) | 段落で東アジアの改行が使用されているかどうかを判定します。<br/>            読み書き [`NullableBool`](/slides/python-net/ja/aspose.slides/nullablebool)。 |
| [`right_to_left`](/slides/python-net/ja/aspose.slides.charts/ichartparagraphformat/right_to_left/) | 段落で右から左への書き込みが使用されているかどうかを判定します。<br/>            読み書き [`NullableBool`](/slides/python-net/ja/aspose.slides/nullablebool)。 |
| [`latin_line_break`](/slides/python-net/ja/aspose.slides.charts/ichartparagraphformat/latin_line_break/) | 段落でラテン文字の改行が使用されているかどうかを判定します。<br/>            読み書き [`NullableBool`](/slides/python-net/ja/aspose.slides/nullablebool)。 |
| [`hanging_punctuation`](/slides/python-net/ja/aspose.slides.charts/ichartparagraphformat/hanging_punctuation/) | 段落でハンギング句読点が使用されているかどうかを判定します。<br/>            読み書き [`NullableBool`](/slides/python-net/ja/aspose.slides/nullablebool)。 |
| [`margin_left`](/slides/python-net/ja/aspose.slides.charts/ichartparagraphformat/margin_left/) | 段落の左余白を取得または設定します。<br/>            読み書き **float**。 |
| [`margin_right`](/slides/python-net/ja/aspose.slides.charts/ichartparagraphformat/margin_right/) | 段落の右余白を取得または設定します。<br/>            読み書き **float**。 |
| [`indent`](/slides/python-net/ja/aspose.slides.charts/ichartparagraphformat/indent/) | 段落の最初の行インデント/ハンギングインデントを取得または設定します。ハンギングインデントは負の値で定義できます。<br/>            読み書き **float**。 |
| [`default_tab_size`](/slides/python-net/ja/aspose.slides.charts/ichartparagraphformat/default_tab_size/) | デフォルトのタブ幅を取得または設定します。<br/>            読み書き **float**。 |
| [`tabs`](/slides/python-net/ja/aspose.slides.charts/ichartparagraphformat/tabs/) | 段落のタブ設定を取得します。<br/>            読み取り専用 [`ITabCollection`](/slides/python-net/ja/aspose.slides/itabcollection)。 |
| [`font_alignment`](/slides/python-net/ja/aspose.slides.charts/ichartparagraphformat/font_alignment/) | 段落のフォント配置を取得または設定します。<br/>            読み書き [`FontAlignment`](/slides/python-net/ja/aspose.slides/fontalignment)。 |
