## BaseChartValue クラス

チャートの値を表します。

BaseChartValue 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`data_source_type`](/slides/python-net/ja/aspose.slides.charts/basechartvalue/data_source_type/) | 派生クラスで AsCell、AsCells、AsLiteralString、または AsLiteralDouble プロパティが実際に存在するかどうかを指定します。<br/>言い換えれば、Data プロパティの値の型を指定します。<br/>読み取り/書き込み [`DataSourceType`](/slides/python-net/ja/aspose.slides.charts/datasourcetype). |
| [`data`](/slides/python-net/ja/aspose.slides.charts/basechartvalue/data/) | Data。<br/>読み取り/書き込み **任意**. |
