## IUpDownBarsManager クラス

Line または Stock-チャートの上/下バーへのアクセスを提供します。

IUpDownBarsManager 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`up_bars_format`](/slides/python-net/ja/aspose.slides.charts/iupdownbarsmanager/up_bars_format/) | 上バーの形式を返します。<br/>            読み取り専用 [`IFormat`](/slides/python-net/ja/aspose.slides.charts/iformat). |
| [`down_bars_format`](/slides/python-net/ja/aspose.slides.charts/iupdownbarsmanager/down_bars_format/) | 下バーの形式を返します。<br/>            読み取り専用 [`IFormat`](/slides/python-net/ja/aspose.slides.charts/iformat). |
| [`has_up_down_bars`](/slides/python-net/ja/aspose.slides.charts/iupdownbarsmanager/has_up_down_bars/) | チャートに上/下バーがあるかどうかを判定します。<br/>            読み取り/書き込み **bool**. |
| [`gap_width`](/slides/python-net/ja/aspose.slides.charts/iupdownbarsmanager/gap_width/) | ギャップ幅を取得または設定します。<br/>            読み取り/書き込み **int**. |
