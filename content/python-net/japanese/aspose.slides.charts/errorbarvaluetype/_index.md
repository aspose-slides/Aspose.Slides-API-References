## ErrorBarValueType 列挙型

エラーバー値の種類を表します。

ErrorBarValueType 型は次のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| CUSTOM | エラーバーの長さが Plus と Minus の要素によって決定されることを指定します。 |
| FIXED | エラーバーの長さが Error Bar Value によって決定された固定値であることを指定します。 |
| PERCENTAGE | エラーバーの長さがデータの Error Bar Value パーセントであることを指定します。 |
| STANDARD_DEVIATION | エラーバーの長さがデータの Error Bar Value 標準偏差であることを指定します。 |
| STANDARD_ERROR | エラーバーの長さがデータの Error Bar Value 標準誤差であることを指定します。 |
