## LegendEntryProperties クラス

チャートの凡例プロパティを表します。

LegendEntryProperties 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`text_format`](/slides/python-net/ja/aspose.slides.charts/legendentryproperties/text_format/) | テキスト形式を返します。<br/>            読み取り専用 [`IChartTextFormat`](/slides/python-net/ja/aspose.slides.charts/icharttextformat)。 |
| [`hide`](/slides/python-net/ja/aspose.slides.charts/legendentryproperties/hide/) | 凡例エントリが非表示かどうかを決定します。<br/>            読み取り/書き込み **bool**。 |
| [`chart`](/slides/python-net/ja/aspose.slides.charts/legendentryproperties/chart/) | 親チャートを返します。<br/>            読み取り専用 [`IChart`](/slides/python-net/ja/aspose.slides.charts/ichart)。 |
