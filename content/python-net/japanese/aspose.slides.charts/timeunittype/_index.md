## TimeUnitType 列挙型

カテゴリ軸の基本単位を表します

TimeUnitType 型は次のメンバーを公開します:

## フィールド

| フィールド | 説明 |
| :- | :- |
| NONE | 値はそのまま表示されます。 |
| DAYS | チャート データを日単位で表示します。 |
| MONTHS | チャート データを月単位で表示します。 |
| YEARS | チャート データを年単位で表示します。 |
