## IAxesManager クラス

チャート軸へのアクセスを提供します。

IAxesManager 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`horizontal_axis`](/slides/python-net/ja/aspose.slides.charts/iaxesmanager/horizontal_axis/) | チャートの水平軸を取得します。<br/>             読み取り専用 [`IAxis`](/slides/python-net/ja/aspose.slides.charts/iaxis). |
| [`secondary_horizontal_axis`](/slides/python-net/ja/aspose.slides.charts/iaxesmanager/secondary_horizontal_axis/) | チャートの二次水平軸を取得します。<br/>             読み取り専用 [`IAxis`](/slides/python-net/ja/aspose.slides.charts/iaxis). |
| [`vertical_axis`](/slides/python-net/ja/aspose.slides.charts/iaxesmanager/vertical_axis/) | チャートの垂直軸を取得します。<br/>             読み取り専用 [`IAxis`](/slides/python-net/ja/aspose.slides.charts/iaxis). |
| [`secondary_vertical_axis`](/slides/python-net/ja/aspose.slides.charts/iaxesmanager/secondary_vertical_axis/) | チャートの二次垂直軸を取得します。<br/>             読み取り専用 [`IAxis`](/slides/python-net/ja/aspose.slides.charts/iaxis). |
| [`series_axis`](/slides/python-net/ja/aspose.slides.charts/iaxesmanager/series_axis/) | チャートの系列軸を取得します。<br/>             読み取り専用 [`IAxis`](/slides/python-net/ja/aspose.slides.charts/iaxis). |
