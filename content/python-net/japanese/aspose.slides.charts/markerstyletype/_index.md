## MarkerStyleType 列挙

チャートのデータポイントにおけるマーカーの形状を決定します。

MarkerStyleType 型は以下のメンバーを公開します：

## フィールド

| フィールド | 説明 |
| :- | :- |
| NOT_DEFINED |  |
| CIRCLE | 各データポイントに円が描画されます。 |
| DASH | 各データポイントに破線が描画されます。 |
| DIAMOND | 各データポイントに菱形が描画されます。 |
| DOT | 各データポイントに点が描画されます。 |
| NONE | 各データポイントに何も描画されません。 |
| PICTURE | 各データポイントに画像が描画されます。 |
| PLUS | 各データポイントにプラス記号が描画されます。 |
| SQUARE | 各データポイントに正方形が描画されます。 |
| STAR | 各データポイントに星形が描画されます。 |
| TRIANGLE | 各データポイントに三角形が描画されます。 |
| X | 各データポイントに X が描画されます。 |
