## value_type プロパティ
エラーバーの長さを決定する可能な方法を表します。 
            カスタムの value type の場合、値を指定するには、シリーズの DataPoints コレクション内の特定のデータポイントの [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/ja/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) プロパティを使用します。 
            Fixed、Percentage、または StandardDeviation の value type の場合、値を指定するには Value プロパティを使用します。  
            読み書き [`ErrorBarValueType`](/slides/python-net/ja/aspose.slides.charts/errorbarvaluetype)。
