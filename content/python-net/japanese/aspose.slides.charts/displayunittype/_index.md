## DisplayUnitType 列挙型

表示データの倍率を決定します。

DisplayUnitType 型は次のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| NONE | 値はそのまま表示されます。 |
| HUNDREDS | チャート上の値を 100 で除算することを指定します。 |
| THOUSANDS | チャート上の値を 1,000 で除算することを指定します。 |
| TEN_THOUSANDS | チャート上の値を 10,000 で除算することを指定します。 |
| HUNDRED_THOUSANDS | チャート上の値を 100,000 で除算することを指定します。 |
| MILLIONS | チャート上の値を 1,000,000 で除算することを指定します。 |
| TEN_MILLIONS | チャート上の値を 10,000,000 で除算することを指定します。 |
| HUNDRED_MILLIONS | チャート上の値を 100,000,000 で除算することを指定します。 |
| BILLIONS | チャート上の値を 1,000,000,000 で除算することを指定します。 |
| TRILLIONS | チャート上の値を 1,000,000,000,000 で除算することを指定します。 |
| CUSTOM_VALUE | チャート上の値をカスタム値で除算することを指定します。 |
