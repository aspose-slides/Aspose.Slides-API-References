## is_chart_type_area(chart_type) {#charttype}
chartType が Area のサブタイプのいずれかである場合に true を返します。
            Subtypes set corresponds to the appropriate set in PowerPoint (see "Change Chart Type" dialog in PowerPoint):
            [`ChartType.AREA`](/slides/python-net/ja/aspose.slides.charts/charttype/AREA),
            [`ChartType.PERCENTS_STACKED_AREA`](/slides/python-net/ja/aspose.slides.charts/charttype/PERCENTS_STACKED_AREA),
            [`ChartType.PERCENTS_STACKED_AREA_3D`](/slides/python-net/ja/aspose.slides.charts/charttype/PERCENTS_STACKED_AREA_3D),
            [`ChartType.STACKED_AREA`](/slides/python-net/ja/aspose.slides.charts/charttype/STACKED_AREA),
            [`ChartType.STACKED_AREA_3D`](/slides/python-net/ja/aspose.slides.charts/charttype/STACKED_AREA_3D),
            [`ChartType.AREA_3D`](/slides/python-net/ja/aspose.slides.charts/charttype/AREA_3D).
