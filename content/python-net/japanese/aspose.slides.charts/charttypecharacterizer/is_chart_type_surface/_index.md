## is_chart_type_surface(chart_type) {#charttype}

            Subtypes set corresponds to the appropriate set in PowerPoint (see "Change Chart Type" dialog in PowerPoint):
            [`ChartType.SURFACE_3D`](/slides/python-net/ja/aspose.slides.charts/charttype/SURFACE_3D),
            [`ChartType.WIREFRAME_SURFACE_3D`](/slides/python-net/ja/aspose.slides.charts/charttype/WIREFRAME_SURFACE_3D),
            [`ChartType.CONTOUR`](/slides/python-net/ja/aspose.slides.charts/charttype/CONTOUR),
