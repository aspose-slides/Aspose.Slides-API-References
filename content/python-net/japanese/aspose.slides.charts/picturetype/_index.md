## PictureType 列挙

棒グラフの画像塗りつぶしモードを決定します。

PictureType 型は次のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| NOT_DEFINED | 定義されていません。 |
| STACK | 画像は、最長の積み上げ棒グラフで最大15回繰り返すようにサイズが設定されます。 |
| STACK_SCALE | 画像は指定された単位数にサイズが設定され、棒の長さに沿って繰り返されます。 |
| STRETCH | 画像は積み上げ棒の全長に伸ばされます。 |
