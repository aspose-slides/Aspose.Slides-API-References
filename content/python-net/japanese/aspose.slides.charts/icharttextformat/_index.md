## IChartTextFormat クラス

チャートは制限されたテキスト書式プロパティのセットで操作されます。  
IChartTextFormat、IChartTextBlockFormat、IChartParagraphFormat、IChartPortionFormat インターフェイスは、この制限されたセットを説明します。

IChartTextFormat 型は以下のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`text_block_format`](/slides/python-net/ja/aspose.slides.charts/icharttextformat/text_block_format/) | チャートテキスト要素の書式を返します。<br/>            読み取り専用 [`IChartTextBlockFormat`](/slides/python-net/ja/aspose.slides.charts/icharttextblockformat). |
| [`paragraph_format`](/slides/python-net/ja/aspose.slides.charts/icharttextformat/paragraph_format/) | 段落書式を返します。<br/>            読み取り専用 [`IChartParagraphFormat`](/slides/python-net/ja/aspose.slides.charts/ichartparagraphformat). |
| [`portion_format`](/slides/python-net/ja/aspose.slides.charts/icharttextformat/portion_format/) | 部分書式を返します。<br/>            読み取り専用 [`IChartPortionFormat`](/slides/python-net/ja/aspose.slides.charts/ichartportionformat). |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`copy_to(self, dest_text_frame)`](/slides/python-net/ja/aspose.slides.charts/icharttextformat/copy_to/#itextframe) | 指定されたテキストフレームにテキスト書式をコピーします。 |
| [`copy_from(self, source_text_frame)`](/slides/python-net/ja/aspose.slides.charts/icharttextformat/copy_from/#itextframe) | 指定されたテキストフレームからテキスト書式をコピーします。 |
