## is_visible プロパティ
False はデータ ラベルが表示されないことを意味します (そしてすべての Show*-フラグ (ShowValue, ...) は false です)。
読み取り専用 **bool**。

### 備考

データ ラベルが表示されている場合は、Hide() メソッドで非表示にできます。
しかし、データ ラベルが表示されていない場合 (IsVisible が false) は、Show*-フラグ (ShowValue, ...) を true に設定することでデータ ラベルを表示できます。
