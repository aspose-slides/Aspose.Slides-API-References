## hide(self) {#}
すべての Show*-flags (ShowValue, ...) を false の状態に設定することで、データ ラベルを非表示にします。
            IsVisible はこの後 false になります。


```python
def hide(self):
    ...
```


### 備考

データ ラベルが表示されていない (IsVisible が false) 場合、データ ラベルを表示できるように
            Show*-flags (ShowValue, ...) を true の状態に設定します。
