## ILegendEntryCollection クラス

凡例コレクションを表します。

ILegendEntryCollection 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`count`](/slides/python-net/ja/aspose.slides.charts/ilegendentrycollection/count/) | コレクションに実際に含まれる要素数を取得します。<br/>            読み取り専用 **int**. |

Chart.ChartData.Series[0].DataPoints[index] に対応する凡例エントリのプロパティを取得します（次のチャートタイプの場合: ChartType.BarOfPie, ChartType.ExplodedPie, ChartType.ExplodedPie3D, ChartType.Pie, ChartType.Pie3D, ChartType.PieOfPie;）。他のチャートタイプの場合は Chart.ChartData.Series[index] に対応します。
