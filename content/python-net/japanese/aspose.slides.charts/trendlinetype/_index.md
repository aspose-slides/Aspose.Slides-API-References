## TrendlineType 列挙型

トレンドラインのタイプを表します

TrendlineType 型は次のメンバーを公開します：

## Fields

| フィールド | 説明 |
| :- | :- |
| EXPONENTIAL | トレンドラインが指数曲線になることを指定します。 |
| LINEAR | トレンドラインが直線になることを指定します。 |
| LOGARITHMIC | トレンドラインが対数曲線になることを指定します（log は自然対数です）。 |
| MOVING_AVERAGE | トレンドラインが期間 Period の移動平均になることを指定します。 |
| POLYNOMIAL | トレンドラインが次数 Order の多項式曲線になることを指定します。 |
| POWER | トレンドラインがべき曲線になることを指定します。 |
