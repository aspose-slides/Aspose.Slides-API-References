## text_frame_for_overriding プロパティ
Can contain a rich formatted text. If this プロパティ is not None then this 
            formatted text value overrides auto-generated text.
            Auto-generated text is an implicit プロパティ of the data label, the display 
            unit label of the value axis, the axis title, the chart title, the label of the trendline.
            Auto-generated text is formatted with the IFormattedTextContainer.TextFormat プロパティ.
            読み取り専用 [`ITextFrame`](/slides/python-net/ja/aspose.slides/itextframe).
