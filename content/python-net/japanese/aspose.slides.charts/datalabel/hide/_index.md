## hide(self) {#}
すべての Show*-フラグ (ShowValue, ...) を false の状態に設定することで、データ ラベルを非表示にします。
この操作の後、IsVisible は false になります。


```python
def hide(self):
    ...
```


### 備考

データ ラベルが非表示 (IsVisible が false) の場合、Show*-フラグ (ShowValue, ...) を true の状態に設定することで、データ ラベルを表示できます。
