## is_visible プロパティ
False はデータ ラベルが表示されないことを意味します (したがってすべての Show*-フラグ (ShowValue, ...) は false です)。
            読み取り専用 **bool**。


### 備考

データ ラベルが表示されている場合は、Hide() メソッドで非表示にできます。
            ただし、データ ラベルが表示されていない (IsVisible が false) 場合は、Show*-フラグ (ShowValue, ...) を true に設定することでデータ ラベルを表示できます。
