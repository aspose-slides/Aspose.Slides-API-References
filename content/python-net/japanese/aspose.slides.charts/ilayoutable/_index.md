## ILayoutable クラス

チャート要素の正確な位置を指定します。

ILayoutable タイプは次のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`x`](/slides/python-net/ja/aspose.slides.charts/ilayoutable/x/) | チャート要素の幅に対する割合として、チャート要素の x 位置（左）を指定します。<br/>            読み取り/書き込み **float**。 |
| [`y`](/slides/python-net/ja/aspose.slides.charts/ilayoutable/y/) | チャート要素の高さに対する割合として、チャート要素の上部を指定します。<br/>            読み取り/書き込み **float**。 |
| [`width`](/slides/python-net/ja/aspose.slides.charts/ilayoutable/width/) | チャート要素の幅に対する割合として、チャート要素の幅を指定します。<br/>            読み取り/書き込み **float**。 |
| [`height`](/slides/python-net/ja/aspose.slides.charts/ilayoutable/height/) | チャート要素の高さに対する割合として、チャート要素の高さを指定します。<br/>            読み取り/書き込み **float**。 |
| [`right`](/slides/python-net/ja/aspose.slides.charts/ilayoutable/right/) | チャート要素の幅に対する割合として、チャート要素の右端を取得します。<br/>            読み取り専用 **float**。 |
| [`bottom`](/slides/python-net/ja/aspose.slides.charts/ilayoutable/bottom/) | チャート要素の高さに対する割合として、チャート要素の上部を取得します。<br/>            読み取り専用 **float**。 |
