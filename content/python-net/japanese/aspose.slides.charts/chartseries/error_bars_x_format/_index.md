## error_bars_x_format プロパティ
Represents ErrorBars of series with derection X.

            X 方向の ErrorBars は、area、bar、scatter、bubble タイプの系列で利用できます。
            他の型のチャートでは、このプロパティは None を返します（3D チャートを含む）。
            カスタム値の場合は、DataPoints コレクションを使用して値を指定します（[`IChartDataPoint.error_bars_custom_values`](/slides/python-net/ja/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) プロパティを使用）。

            読み取り専用 [`IErrorBarsFormat`](/slides/python-net/ja/aspose.slides.charts/ierrorbarsformat).
