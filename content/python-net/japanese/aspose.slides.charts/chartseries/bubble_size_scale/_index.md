## bubble_size_scale プロパティ
バブルチャートのスケール係数を指定します（できる範囲は 
            デフォルトサイズの 0% から 300% の間です）。
            このプロパティはこの系列だけでなく、親系列グループのすべての系列にも適用されます 
            グループ - これは適切なグループプロパティの投影です。そしてこのプロパティ 
            は読み取り専用です。
            親系列グループにアクセスするには ParentSeriesGroup プロパティを使用します。
            値を変更するには ParentSeriesGroup.BubbleSizeScale 読み書き可能プロパティを使用します。


### 備考

このプロパティは ParentSeriesGroup.BubbleSizeScale の投影です。
