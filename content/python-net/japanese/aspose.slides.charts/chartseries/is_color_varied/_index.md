## is_color_varied プロパティ
Specifies that each data marker in the series has a different color.
            このプロパティは、このシリーズだけでなく、親シリーズのすべてのシリーズに適用されるプロパティの投影です。
            したがってこのプロパティ
            は読み取り専用です。
            ParentSeriesGroup プロパティを使用して、親シリーズ グループにアクセスします。
            ParentSeriesGroup.IsColorVaried 読み取り/書き込み プロパティを使用して値を変更します。
            読み取り専用 **bool**。

### 備考
これはプロパティ ParentSeriesGroup.IsColorVaried の投影です。
