## ChartType 列挙体

チャートのタイプを表します。

ChartType 型は次のメンバーを公開します：

## フィールド

| フィールド | 説明 |
| :- | :- |
| CLUSTERED_COLUMN | Clustered Column Chart を表します。 |
| STACKED_COLUMN | Stacked Column Chart を表します。 |
| PERCENTS_STACKED_COLUMN | 100% Stacked Column Chart を表します。 |
| CLUSTERED_COLUMN_3D | 3D Colustered Column Chart を表します。 |
| STACKED_COLUMN_3D | 3D Stacked Column Chart を表します。 |
| PERCENTS_STACKED_COLUMN_3D | 3D 100% Stacked Column Chart を表します。 |
| COLUMN_3D | 3D Column Chart を表します。 |
| CLUSTERED_CYLINDER | Cylinder Chart を表します。 |
| STACKED_CYLINDER | Stacked Cylinder Chart を表します。 |
| PERCENTS_STACKED_CYLINDER | 100% Stacked Cylinder Chart を表します。 |
| CYLINDER_3D | 3D Cylindrical Column Chart を表します。 |
| CLUSTERED_CONE | Cone Chart を表します。 |
| STACKED_CONE | Stacked Cone Chart を表します。 |
| PERCENTS_STACKED_CONE | 100% Stacked Cone Chart を表します。 |
| CONE_3D | 3D Conical Column Chart を表します。 |
| CLUSTERED_PYRAMID | Pyramid Chart を表します。 |
| STACKED_PYRAMID | Stacked Pyramid Chart を表します。 |
| PERCENTS_STACKED_PYRAMID | 100% Stacked Pyramid Chart を表します。 |
| PYRAMID_3D | 3D Pyramid Column Chart を表します。 |
| LINE | Line Chart を表します。 |
| STACKED_LINE | Stacked Line Chart を表します。 |
| PERCENTS_STACKED_LINE | 100% Stacked Line Chart を表します。 |
| LINE_WITH_MARKERS | データ マーカー付き Line Chart を表します。 |
| STACKED_LINE_WITH_MARKERS | データ マーカー付き Stacked Line Chart を表します。 |
| PERCENTS_STACKED_LINE_WITH_MARKERS | データ マーカー付き 100% Stacked Line Chart を表します。 |
| LINE_3D | 3D Line Chart を表します。 |
| PIE | Pie Chart を表します。 |
| PIE_3D | 3D Pie Chart を表します。 |
| PIE_OF_PIE | Pie of Pie Chart を表します。 |

| CLUSTERED_HORIZONTAL_CONE | Conical Bar Chart を表します。 |
| STACKED_HORIZONTAL_CONE | Stacked Conical Bar Chart を表します。 |
| PERCENTS_STACKED_HORIZONTAL_CONE | 100% Stacked Conical Bar Chart を表します。 |

| AREA_3D | 3D Area Chart を表します。 |
| STACKED_AREA_3D | 3D Stacked Area Chart を表します。 |
| PERCENTS_STACKED_AREA_3D | 3D 100% Stacked Area Chart を表します。 |
| SCATTER_WITH_MARKERS | Scatter Chart を表します。 |

| SERIES_OF_MIXED_TYPES | この値は ChartEx.Type プロパティでのみ取得できます。<br/>            このチャートは混合タイプの系列を持つことを意味します。 |
| TREEMAP | Treemap chart を表します。 |
| SUNBURST | Sunburst chart を表します。 |
| HISTOGRAM | Histogram chart を表します。 |
| PARETO_LINE | Pareto line series type (Histogram Pareto chart) を表します。 |
