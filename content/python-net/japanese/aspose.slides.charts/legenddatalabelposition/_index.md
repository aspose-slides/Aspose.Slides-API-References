## LegendDataLabelPosition 列挙体

データ ラベルの位置を決定します。

LegendDataLabelPosition 型は次のメンバーを公開します：

## フィールド

| フィールド | 説明 |
| :- | :- |
| NOT_DEFINED | 位置は定義されていません。 |
| BOTTOM | データ ラベルがデータ マーカーの下に表示されるように指定します。 |
| BEST_FIT | データ ラベルが最適な位置に表示されるように指定します。 |
| CENTER | データ ラベルがデータ マーカーの中心に表示されるように指定します。 |
| INSIDE_BASE | データ ラベルがデータ マーカーの基部内部に表示されるように指定します。 |
| INSIDE_END | データ ラベルがデータ マーカーの端部内部に表示されるように指定します。 |
| LEFT | データ ラベルがデータ マーカーの左側に表示されるように指定します。 |
| OUTSIDE_END | データ ラベルがデータ マーカーの端部の外側に表示されるように指定します。 |
| RIGHT | データ ラベルがデータ マーカーの右側に表示されるように指定します。 |
| TOP | データ ラベルがデータ マーカーの上に表示されるように指定します。 |
