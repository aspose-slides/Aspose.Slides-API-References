## bubble_size_representation プロパティ
Specifies how the bubble size values are represented on the bubble chart.
            このプロパティはこのシリーズだけでなく、親シリーズのすべてのシリーズにも適用されます 
            グループ - これは適切なグループプロパティの投影です。そしてこのプロパティ 
            は読み取り専用です。
            親シリーズグループへのアクセスには ParentSeriesGroup プロパティを使用します。
            値を変更するには ParentSeriesGroup.BubbleSizeRepresentation の読み書き可能プロパティを使用します。
