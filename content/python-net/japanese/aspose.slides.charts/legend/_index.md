## Legend クラス

チャートの凡例プロパティを表します。

Legend 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`x`](/slides/python-net/ja/aspose.slides.charts/legend/x/) | 凡例の x 座標を、チャートの幅の比率として取得または設定します。<br/>            読み書き可能 **float**. |
| [`y`](/slides/python-net/ja/aspose.slides.charts/legend/y/) | 凡例の y 座標を、チャートの高さの比率として取得または設定します。<br/>            読み書き可能 **float**. |
| [`width`](/slides/python-net/ja/aspose.slides.charts/legend/width/) | 凡例の幅を、チャートの幅の比率として取得または設定します。<br/>            読み書き可能 **float**. |
| [`height`](/slides/python-net/ja/aspose.slides.charts/legend/height/) | 凡例の高さを、チャートの高さの比率として取得または設定します。<br/>            読み書き可能 **float**. |
| [`right`](/slides/python-net/ja/aspose.slides.charts/legend/right/) | 右。<br/>            読み取り専用 **float**. |
| [`bottom`](/slides/python-net/ja/aspose.slides.charts/legend/bottom/) | 下。<br/>            読み取り専用 **float**. |
| [`overlay`](/slides/python-net/ja/aspose.slides.charts/legend/overlay/) | 他のチャート要素が凡例と重なることを許可するかどうかを決定します。<br/>            読み書き可能 **bool**. |
| [`text_format`](/slides/python-net/ja/aspose.slides.charts/legend/text_format/) | テキスト形式。<br/>            読み取り専用 [`IChartTextFormat`](/slides/python-net/ja/aspose.slides.charts/icharttextformat). |
| [`position`](/slides/python-net/ja/aspose.slides.charts/legend/position/) | チャート上の凡例の位置を指定します。<br/>            X、Y、Width、Heigt プロパティの NaN でない値はこのプロパティの効果を上書きします。<br/>            読み書き可能 [`LegendPositionType`](/slides/python-net/ja/aspose.slides.charts/legendpositiontype). |
| [`format`](/slides/python-net/ja/aspose.slides.charts/legend/format/) | 凡例の形式を取得します。<br/>            読み取り専用 [`IFormat`](/slides/python-net/ja/aspose.slides.charts/iformat). |
| [`chart`](/slides/python-net/ja/aspose.slides.charts/legend/chart/) | チャートを取得します。<br/>            読み取り専用 [`IChart`](/slides/python-net/ja/aspose.slides.charts/ichart). |
| [`entries`](/slides/python-net/ja/aspose.slides.charts/legend/entries/) | 凡例エントリを取得します。<br/>            読み取り専用 [`ILegendEntryCollection`](/slides/python-net/ja/aspose.slides.charts/ilegendentrycollection). |
| [`actual_x`](/slides/python-net/ja/aspose.slides.charts/legend/actual_x/) | チャート要素の実際の x 位置（左）を、チャートの左上隅に対して指定します。<br/>            実際の値を取得するには、先に IChart.ValidateChartLayout() メソッドを呼び出してください。 <br/>            読み取り **float**. |
| [`actual_y`](/slides/python-net/ja/aspose.slides.charts/legend/actual_y/) | チャート要素の実際の上位置（上）を、チャートの左上隅に対して指定します。<br/>            実際の値を取得するには、先に IChart.ValidateChartLayout() メソッドを呼び出してください。 <br/>            読み取り **float**. |
| [`actual_width`](/slides/python-net/ja/aspose.slides.charts/legend/actual_width/) | チャート要素の実際の幅を指定します。実際の値を取得するには、先に IChart.ValidateChartLayout() メソッドを呼び出してください。<br/>            読み取り **float**. |
| [`actual_height`](/slides/python-net/ja/aspose.slides.charts/legend/actual_height/) | チャート要素の実際の高さを指定します。実際の値を取得するには、先に IChart.ValidateChartLayout() メソッドを呼び出してください。<br/>            読み取り **float**. |
| [`slide`](/slides/python-net/ja/aspose.slides.charts/legend/slide/) |  |
| [`presentation`](/slides/python-net/ja/aspose.slides.charts/legend/presentation/) |  |
