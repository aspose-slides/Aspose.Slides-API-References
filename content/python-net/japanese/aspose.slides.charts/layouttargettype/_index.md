## LayoutTargetType 列挙型

レイアウトが手動で定義された場合、このプロパティはプロット領域を内部（軸と軸ラベルを除く）でレイアウトするか、外部（軸と軸ラベルを含む）でレイアウトするかを指定します。

LayoutTargetType 型は以下のメンバーを公開します:

## フィールド

| フィールド | 説明 |
| :- | :- |
| INNER | プロット領域のサイズが決定されることを指定します<br/>            目盛りと軸ラベルを除くプロット領域のサイズです<br/>            。 |
| OUTER | プロット領域のサイズが決定され、<br/>            プロット領域、目盛り、および軸<br/>            ラベルのサイズを決定することを指定します。 |
