## ChartWall クラス

3d チャート上の壁を表します。

ChartWall 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`thickness`](/slides/python-net/ja/aspose.slides.charts/chartwall/thickness/) | 壁の厚さをプロット領域の最大次元のパーセンテージとして取得または設定します。<br/>            読み書き可能 **int**. |
| [`format`](/slides/python-net/ja/aspose.slides.charts/chartwall/format/) | 壁の塗りつぶし、線、効果、3d スタイルを取得します。<br/>            読み取り専用 [`IFormat`](/slides/python-net/ja/aspose.slides.charts/iformat). |
| [`picture_type`](/slides/python-net/ja/aspose.slides.charts/chartwall/picture_type/) | 画像のタイプを取得または設定します。<br/>            読み書き可能 [`PictureType`](/slides/python-net/ja/aspose.slides.charts/picturetype). |
