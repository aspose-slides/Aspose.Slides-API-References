## TickMarkType 列挙型

指定された軸の目盛りタイプを表します。

TickMarkType 型は次のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| CROSS | 目盛りが軸を横切ることを指定します。 |
| INSIDE | 目盛りがプロット領域の内部にあることを指定します。 |
| NONE | 目盛りが存在しないことを指定します。 |
| OUTSIDE | 目盛りがプロット領域の外部にあることを指定します。 |
