## default_label_shape_type プロパティ
データラベルのデフォルト シェイプ タイプを取得または設定します。
             シェイプが定義されていない場合、[`ShapeType.NOT_DEFINED`](/slides/python-net/ja/aspose.slides/shapetype/NOT_DEFINED) を返します。


### 備考

このプロパティを設定すると、コレクション内のすべてのデータラベルの [`IDataLabel.label_shape_type`](/slides/python-net/ja/aspose.slides.charts/idatalabel/label_shape_type) プロパティ
             同じ値に設定されます。
