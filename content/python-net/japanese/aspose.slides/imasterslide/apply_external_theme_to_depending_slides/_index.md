## apply_external_theme_to_depending_slides(self, fname) {#str}
現在のスライドをベースに新しいマスタースライドを作成し、外部テーマを適用して、作成したマスタースライドをすべての依存スライドに適用します。

### 戻り値

新しいテーマが適用された MasterSlide.

```python
def apply_external_theme_to_depending_slides(self, fname):
    ...
```


| パラメータ | 型 | 説明 |
| :- | :- | :- |
| fname | **str** | 外部テーマファイル(.thmx)へのパス。 |
