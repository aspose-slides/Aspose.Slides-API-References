## ITextSearchOptions クラス

Presentation、Slide、または TextFrame 内のテキストを検索するために使用できるオプションを表します。

ITextSearchOptions 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`case_sensitive`](/slides/python-net/ja/aspose.slides/itextsearchoptions/case_sensitive/) | true を設定すると大文字と小文字を区別した検索を使用し、false を設定すると区別しません。<br/>            読み取り/書き込み **bool**. |
| [`whole_words_only`](/slides/python-net/ja/aspose.slides/itextsearchoptions/whole_words_only/) | true を設定すると単語全体にのみ一致させ、false を設定するとそうでなくなります。<br/>            読み取り/書き込み **bool**. |
| [`include_notes`](/slides/python-net/ja/aspose.slides/itextsearchoptions/include_notes/) | `true` を設定すると、テキスト検索、置換、またはハイライト操作を行う際にスライドノートに含まれるテキストを含めます。<br/>            デフォルト値は `false` です。 |
