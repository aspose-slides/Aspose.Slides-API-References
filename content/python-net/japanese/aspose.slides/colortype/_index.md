## ColorType 列挙

さまざまなカラーモードを表します。

ColorType 型は以下のメンバーを公開します：

## フィールド

| Field | Description |
| :- | :- |
| NOT_DEFINED | 色が全く定義されていません。 |
| RGB | 標準の 24bit RGB カラー。 |
| RGB_PERCENTAGE | 高精細 RGB カラー。 |
| HSL | 高精細 HSL カラー。 |
| SCHEME | スキーム カラー。 |
| SYSTEM | システム カラー。 |
| PRESET | プリセット カラー。 |
