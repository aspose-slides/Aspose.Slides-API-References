## Captions クラス

WebVTT のクローズド キャプションを表します。

Captions タイプは次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`caption_id`](/slides/python-net/ja/aspose.slides/captions/caption_id/) | 閉じたキャプションのグローバルに一意な識別子 (GUID) を返します。<br/>            読み取り専用 **System.Guid**. |
| [`label`](/slides/python-net/ja/aspose.slides/captions/label/) | 閉じたキャプションのラベルを返しますまたは設定します。<br/>            読み取り/書き込み **str**. |
| [`binary_data`](/slides/python-net/ja/aspose.slides/captions/binary_data/) | 閉じたキャプションのバイナリ データを返します。<br/>            読み取り専用 **int**[]. |
| [`data_as_string`](/slides/python-net/ja/aspose.slides/captions/data_as_string/) | 閉じたキャプションのデータを UTF-8 エンコードされた文字列として返します。<br/>            読み取り専用 **str**. |
