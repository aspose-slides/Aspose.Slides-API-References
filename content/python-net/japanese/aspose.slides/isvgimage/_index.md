## ISvgImage クラス

SVG 画像を表します。

ISvgImage 型は以下のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`svg_content`](/slides/python-net/ja/aspose.slides/isvgimage/svg_content/) | SVG コンテンツを返します。<br/>            読み取り専用 **str**。 |
| [`svg_data`](/slides/python-net/ja/aspose.slides/isvgimage/svg_data/) | SVG データを返します。<br/>            読み取り専用 **int**[]. |
| [`external_resource_resolver`](/slides/python-net/ja/aspose.slides/isvgimage/external_resource_resolver/) | SVG ドキュメントのインポート中に外部リソースを解決するために使用されるコールバック インターフェイスを返します。<br/>            読み取り専用 **IExternalResourceResolver**。 |
| [`base_uri`](/slides/python-net/ja/aspose.slides/isvgimage/base_uri/) | 指定された SVG のベース URI を返します。相対リンクの解決に使用されます。<br/>            読み取り専用 **str**。 |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`write_as_emf(self, stream)`](/slides/python-net/ja/aspose.slides/isvgimage/write_as_emf/#iorawiobase) | SVG 画像を EMF ファイルとして保存します。 |
