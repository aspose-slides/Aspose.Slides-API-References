## GradientStyle 列挙型

利用可能なグラデーションスタイルを表します。

GradientStyle 型は次のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| DEFAULT | デフォルトのグラデーションスタイルです。 |
| POWER_POINT_UI | PowerPoint ユーザー インターフェイスに表示されるグラデーションスタイルです。 |
