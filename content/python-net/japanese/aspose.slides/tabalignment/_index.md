## TabAlignment 列挙体

TabAlignment はタブ揃えを表します。

TabAlignment 型は次のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| LEFT | 左揃え |
| CENTER | 中央揃え |
| RIGHT | 右揃え |
| DECIMAL | 小数点揃え |
