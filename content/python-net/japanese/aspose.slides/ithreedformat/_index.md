## IThreeDFormat クラス

3-D プロパティを表します。

IThreeDFormat 型は以下のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`contour_width`](/slides/python-net/ja/aspose.slides/ithreedformat/contour_width/) | 3D輪郭の幅を取得または設定します。<br/>            読み取り/書き込み **float**. |
| [`extrusion_height`](/slides/python-net/ja/aspose.slides/ithreedformat/extrusion_height/) | 押し出し効果の高さを取得または設定します。<br/>            読み取り/書き込み **float**. |
| [`depth`](/slides/python-net/ja/aspose.slides/ithreedformat/depth/) | 3D形状の奥行きを取得または設定します。<br/>            読み取り/書き込み **float**. |
| [`bevel_top`](/slides/python-net/ja/aspose.slides/ithreedformat/bevel_top/) | 上部3Dベベルのタイプを取得または設定します。<br/>            読み取り専用 [`IShapeBevel`](/slides/python-net/ja/aspose.slides/ishapebevel). |
| [`bevel_bottom`](/slides/python-net/ja/aspose.slides/ithreedformat/bevel_bottom/) | 下部3Dベベルのタイプを取得または設定します。<br/>            読み取り専用 [`IShapeBevel`](/slides/python-net/ja/aspose.slides/ishapebevel). |
| [`contour_color`](/slides/python-net/ja/aspose.slides/ithreedformat/contour_color/) | 輪郭の色を取得または設定します。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat). |
| [`extrusion_color`](/slides/python-net/ja/aspose.slides/ithreedformat/extrusion_color/) | 押し出しの色を取得または設定します。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat). |
| [`camera`](/slides/python-net/ja/aspose.slides/ithreedformat/camera/) | カメラ設定を取得または設定します。<br/>            読み取り専用 [`ICamera`](/slides/python-net/ja/aspose.slides/icamera). |
| [`light_rig`](/slides/python-net/ja/aspose.slides/ithreedformat/light_rig/) | 光源のタイプを取得または設定します。<br/>            読み取り専用 [`ILightRig`](/slides/python-net/ja/aspose.slides/ilightrig). |
| [`material`](/slides/python-net/ja/aspose.slides/ithreedformat/material/) | マテリアルのタイプを取得または設定します。<br/>            読み取り/書き込み [`MaterialPresetType`](/slides/python-net/ja/aspose.slides/materialpresettype). |
