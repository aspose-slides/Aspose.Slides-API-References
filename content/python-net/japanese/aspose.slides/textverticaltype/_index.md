## TextVerticalType 列挙型

テキストの縦書きモードを決定します。

TextVerticalType 型は次のメンバーを公開します：

## フィールド

| フィールド | 説明 |
| :- | :- |
| NOT_DEFINED | 定義されていません。 |
| HORIZONTAL | 横向きテキスト。 |
| VERTICAL | 縦向きテキスト。 |
| VERTICAL270 | 270 度の縦向きテキスト。 |
| WORD_ART_VERTICAL | WordArt 縦書きテキスト。 |
| EAST_ASIAN_VERTICAL | 東アジア縦書きテキスト。 |
| MONGOLIAN_VERTICAL | モンゴル語縦書きテキスト。 |
| WORD_ART_VERTICAL_RIGHT_TO_LEFT | WordArt 縦書き右から左のテキスト。 |
