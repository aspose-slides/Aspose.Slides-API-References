## ICaptionsCollection クラス

閉じたキャプションのコレクションを表します。

ICaptionsCollection 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`count`](/slides/python-net/ja/aspose.slides/icaptionscollection/count/) | コレクション内の要素数を返します。<br/>            読み取り専用 **int**. |

指定されたインデックスの閉じたキャプションを返します。
            読み取り専用 [`ICaptions`](/slides/python-net/ja/aspose.slides/icaptions).
