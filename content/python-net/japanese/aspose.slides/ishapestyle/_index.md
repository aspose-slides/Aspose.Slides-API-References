## IShapeStyle クラス

シェイプのスタイル参照を表します。

IShapeStyle 型は次のメンバーを公開します。

## プロパティ

| Property | Description |
| :- | :- |
| [`line_color`](/slides/python-net/ja/aspose.slides/ishapestyle/line_color/) | シェイプの輪郭色を返します。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat)。 |
| [`line_style_index`](/slides/python-net/ja/aspose.slides/ishapestyle/line_style_index/) | スタイルマトリックス内の線の列インデックスを取得または設定します。<br/>            読み書き **int**。 |
| [`fill_color`](/slides/python-net/ja/aspose.slides/ishapestyle/fill_color/) | シェイプの塗りつぶし色を返します。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat)。 |
| [`fill_style_index`](/slides/python-net/ja/aspose.slides/ishapestyle/fill_style_index/) | スタイルマトリックス内のシェイプの塗りつぶし列インデックスを取得または設定します。<br/>            0 は塗りつぶしなしを意味し、<br/>            正の値 - テーマの塗りつぶしスタイルのインデックス、<br/>            負の値 - テーマの背景スタイルのインデックス。<br/>            読み書き **int**。 |
| [`effect_color`](/slides/python-net/ja/aspose.slides/ishapestyle/effect_color/) | シェイプのエフェクト色を返します。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat)。 |
| [`effect_style_index`](/slides/python-net/ja/aspose.slides/ishapestyle/effect_style_index/) | スタイルマトリックス内のシェイプのエフェクト列インデックスを取得または設定します。<br/>            読み書き **int**。 |
| [`font_color`](/slides/python-net/ja/aspose.slides/ishapestyle/font_color/) | シェイプのフォント色を返します。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat)。 |
| [`font_collection_index`](/slides/python-net/ja/aspose.slides/ishapestyle/font_collection_index/) | フォントコレクション内のシェイプのフォントインデックスを取得または設定します。<br/>            読み書き [`FontCollectionIndex`](/slides/python-net/ja/aspose.slides/fontcollectionindex)。 |
