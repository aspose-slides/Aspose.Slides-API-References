## fill_style_index プロパティ
shape のスタイル マトリックスにおける塗りつぶし列インデックスを取得または設定します。
            0 は塗りつぶしなしを意味します,
            正の値 - theme の塗りつぶしスタイルのインデックス,
            負の値 - theme の背景スタイルのインデックスです.
            読み取り/書き込み **int**.
