## IFontSources class

外部フォント用のファイルおよびメモリ ソースを提供します。

IFontSources 型は以下のメンバーを公開します。

## Properties

| プロパティ | 説明 |
| :- | :- |
| [`font_folders`](/slides/python-net/ja/aspose.slides/ifontsources/font_folders/) | フォント ファイルが含まれるフォルダー。<br/>            これらのフォルダーにあるすべてのフォント ファイルがコレクションに含まれます。再帰的に検索されるフォルダー。 |
| [`memory_fonts`](/slides/python-net/ja/aspose.slides/ifontsources/memory_fonts/) | バイト配列として表現されたフォントのコレクションです。 |
