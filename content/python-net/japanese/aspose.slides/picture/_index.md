## Picture クラス

プレゼンテーション内の画像を表します。

Picture 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`image`](/slides/python-net/ja/aspose.slides/picture/image/) | 埋め込み画像を取得または設定します。<br/>            読み取り/書き込み [`IPPImage`](/slides/python-net/ja/aspose.slides/ippimage)。 |
| [`link_path_long`](/slides/python-net/ja/aspose.slides/picture/link_path_long/) | リンクされた画像の URL を取得または設定します。<br/>            読み取り/書き込み **str**。 |
| [`image_transform`](/slides/python-net/ja/aspose.slides/picture/image_transform/) | 画像変換効果のコレクションを取得します。<br/>            読み取り専用 [`IImageTransformOperationCollection`](/slides/python-net/ja/aspose.slides.effects/iimagetransformoperationcollection)。 |
| [`presentation`](/slides/python-net/ja/aspose.slides/picture/presentation/) | プレゼンテーションを取得します。 <br/>            読み取り専用 [`IPresentation`](/slides/python-net/ja/aspose.slides/ipresentation)。 |
| [`slide`](/slides/python-net/ja/aspose.slides/picture/slide/) | 画像の親スライドを取得します。<br/>            読み取り専用 [`IBaseSlide`](/slides/python-net/ja/aspose.slides/ibaseslide)。 |
