## set_date_time_and_child_date_times_visibility(self, is_visible) {#bool}
マスター スライドの日時プレースホルダーとすべての子日時プレースホルダーの表示状態を変更します。
子プレースホルダーは、依存レイアウト スライドおよび依存スライドに含まれるプレースホルダーを意味します。
依存レイアウト スライドとスライドはマスター スライドを使用し、依存します。

```python
def set_date_time_and_child_date_times_visibility(self, is_visible):
    ...
```

| パラメータ | 型 | 説明 |
| :- | :- | :- |
| is_visible | **bool** | true - 日時プレースホルダーを表示し、そうでない場合は非表示にします。 |
