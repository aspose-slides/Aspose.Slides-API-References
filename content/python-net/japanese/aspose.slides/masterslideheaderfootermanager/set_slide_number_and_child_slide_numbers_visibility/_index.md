## set_slide_number_and_child_slide_numbers_visibility(self, is_visible) {#bool}
マスタースライドのページ番号プレースホルダーとすべての子ページ番号プレースホルダーの表示状態を変更します。
子プレースホルダーは、依存するレイアウトスライドおよびそれらのスライドに含まれるプレースホルダーを指します。
依存するレイアウトスライドとスライドは、マスタースライドを使用し、マスタースライドに依存します。

```python
def set_slide_number_and_child_slide_numbers_visibility(self, is_visible):
    ...
```


| パラメータ | 型 | 説明 |
| :- | :- | :- |
