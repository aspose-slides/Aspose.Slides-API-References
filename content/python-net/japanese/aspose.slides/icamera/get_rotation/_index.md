## get_rotation(self) {#}
A rotation is defined through the use of a latitude
            緯度座標、経度座標、および緯度と経度座標に沿った軸の回転によって定義されます。
            返却配列の最初の要素は緯度、2 番目は経度、3 番目は回転です。
            Returns None if no rotation defined.
