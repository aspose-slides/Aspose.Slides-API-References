## IPatternFormat クラス

シェイプを塗りつぶすためのパターンを表します。

IPatternFormat 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`pattern_style`](/slides/python-net/ja/aspose.slides/ipatternformat/pattern_style/) | パターンスタイルを取得または設定します。<br/>            読み書き [`PatternStyle`](/slides/python-net/ja/aspose.slides/patternstyle). |
| [`fore_color`](/slides/python-net/ja/aspose.slides/ipatternformat/fore_color/) | 前景パターンの色を返します。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat). |
| [`back_color`](/slides/python-net/ja/aspose.slides/ipatternformat/back_color/) | 背景パターンの色を返します。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat). |
