## IPatternFormat クラス

シェイプを塗りつぶすパターンを表します。

IPatternFormat 型は以下のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`pattern_style`](/slides/python-net/ja/aspose.slides/ipatternformat/pattern_style/) | パターンスタイルを取得または設定します。<br/>            読み取り/書き込み [`PatternStyle`](/slides/python-net/ja/aspose.slides/patternstyle). |
| [`fore_color`](/slides/python-net/ja/aspose.slides/ipatternformat/fore_color/) | 前景パターンカラーを取得します。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat). |
| [`back_color`](/slides/python-net/ja/aspose.slides/ipatternformat/back_color/) | 背景パターンカラーを取得します。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat). |

## メソッド

| メソッド | 説明 |
| :- | :- |
