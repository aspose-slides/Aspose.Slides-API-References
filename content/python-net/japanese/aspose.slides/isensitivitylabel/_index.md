## ISensitivityLabel クラス

Microsoft Purview Information Protection の感度ラベルを表します。

ISensitivityLabel 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`id`](/slides/python-net/ja/aspose.slides/isensitivitylabel/id/) | 感度ラベルの ID を取得または設定します。<br/>            読み書き **str**. |
| [`site_id`](/slides/python-net/ja/aspose.slides/isensitivitylabel/site_id/) | Azure Active Directory (Azure AD) サイト識別子を取得または設定します。<br/>            これは感度ラベルを記述する感度ラベル ポリシーに対応します。<br/>            読み書き **System.Guid**. |
| [`is_enabled`](/slides/python-net/ja/aspose.slides/isensitivitylabel/is_enabled/) | 感度ラベルが有効かどうかを示します。 |
| [`is_removed`](/slides/python-net/ja/aspose.slides/isensitivitylabel/is_removed/) | 感度ラベルが削除されたかどうかを示します。 |
| [`assignment_method_type`](/slides/python-net/ja/aspose.slides/isensitivitylabel/assignment_method_type/) | 感度ラベルの割り当て方法を取得または設定します。<br/>            読み書き [`SensitivityLabelAssignmentType`](/slides/python-net/ja/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/ja/aspose.slides/isensitivitylabel/content_mark_types/) | ファイルに適用すべきコンテンツマーキングのタイプのリストを取得します。 |
