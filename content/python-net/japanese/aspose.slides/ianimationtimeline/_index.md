## IAnimationTimeLine クラス

アニメーションのタイムラインを表します。

IAnimationTimeLine 型は以下のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`interactive_sequences`](/slides/python-net/ja/aspose.slides/ianimationtimeline/interactive_sequences/) | インタラクティブ シーケンスのコレクションを返します。<br/>            このシーケンスは、指定された対象シェイプをクリックすることによるエフェクトのみを含む可能性があります。<br/>            読み取り専用 [`ISequenceCollection`](/slides/python-net/ja/aspose.slides.animation/isequencecollection)。 |
| [`main_sequence`](/slides/python-net/ja/aspose.slides/ianimationtimeline/main_sequence/) | メインエフェクト コレクションのみを含む可能性があるメインシーケンスを返します。<br/>            読み取り専用 [`ISequence`](/slides/python-net/ja/aspose.slides.animation/isequence)。 |
| [`text_animation_collection`](/slides/python-net/ja/aspose.slides/ianimationtimeline/text_animation_collection/) | テキスト アニメーションのコレクションを返します。<br/>            読み取り専用 [`ITextAnimationCollection`](/slides/python-net/ja/aspose.slides.animation/itextanimationcollection)。 |
