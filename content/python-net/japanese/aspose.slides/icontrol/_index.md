## IControl クラス

ActiveX コントロールを表します。

IControl 型は次のメンバーを公開します。

## プロパティ

| Property | Description |
| :- | :- |
| [`name`](/slides/python-net/ja/aspose.slides/icontrol/name/) | このコントロールの名前を返します。<br/>            読み取り/書き込み **str**. |
| [`class_id`](/slides/python-net/ja/aspose.slides/icontrol/class_id/) | このコントロールのクラス ID を取得します。<br/>            読み取り専用 **System.Guid**. |
| [`substitute_picture_format`](/slides/python-net/ja/aspose.slides/icontrol/substitute_picture_format/) | ControlEx 画像塗りつぶしプロパティオブジェクトを返します。<br/>            読み取り専用 [`IPictureFillFormat`](/slides/python-net/ja/aspose.slides/ipicturefillformat). |
| [`frame`](/slides/python-net/ja/aspose.slides/icontrol/frame/) | コントロールのフレームを取得または設定します。<br/>            読み取り/書き込み [`IShapeFrame`](/slides/python-net/ja/aspose.slides/ishapeframe). |
| [`properties`](/slides/python-net/ja/aspose.slides/icontrol/properties/) | ActiveX プロパティのコレクションを返します。<br/>            読み取り専用 [`IControlPropertiesCollection`](/slides/python-net/ja/aspose.slides/icontrolpropertiescollection). |
| [`persistence`](/slides/python-net/ja/aspose.slides/icontrol/persistence/) | ActiveX コントロールのプロパティを保存するために使用されるメソッドを取得します。<br/>            読み取り専用 [`PersistenceType`](/slides/python-net/ja/aspose.slides/persistencetype). |
| [`active_x_control_binary`](/slides/python-net/ja/aspose.slides/icontrol/active_x_control_binary/) | 永続化方法が PersistStream、PersistStreamInit、または PersistStorage のいずれかである場合の ActiveX コントロールの永続性を指定します。 |
| [`slide`](/slides/python-net/ja/aspose.slides/icontrol/slide/) |  |
| [`presentation`](/slides/python-net/ja/aspose.slides/icontrol/presentation/) |  |
