## TextAlignment 列挙型

さまざまなテキスト配置スタイルを表します。

TextAlignment 型は次のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| NOT_DEFINED | デフォルトの配置。 |
| LEFT | 左揃え。 |
| CENTER | 中央揃え。 |
| RIGHT | 右揃え。 |
| JUSTIFY | 両端揃え。 |
| JUSTIFY_LOW | 低いKashida 両端揃え。 |
| DISTRIBUTED | 分散配置。 |
