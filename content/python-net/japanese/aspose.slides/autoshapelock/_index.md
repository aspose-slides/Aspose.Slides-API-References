## AutoShapeLock クラス

親 AutoshapeEx で無効になっている操作を決定します。

**継承:**[`AutoShapeLock`](/slides/python-net/ja/aspose.slides/autoshapelock) → [`BaseShapeLock`](/slides/python-net/ja/aspose.slides/baseshapelock)

AutoShapeLock タイプは以下のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`no_locks`](/slides/python-net/ja/aspose.slides/autoshapelock/no_locks/) | すべてのロックフラグが無効な場合に true を返します。<br/>            読み取り専用 **bool**. |
| [`grouping_locked`](/slides/python-net/ja/aspose.slides/autoshapelock/grouping_locked/) | この形状をグループに追加することが禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`select_locked`](/slides/python-net/ja/aspose.slides/autoshapelock/select_locked/) | この形状を選択することが禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`rotate_locked`](/slides/python-net/ja/aspose.slides/autoshapelock/rotate_locked/) | この形状の回転角を変更することが禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/ja/aspose.slides/autoshapelock/aspect_ratio_locked/) | リサイズ時に形状がアスペクト比を保持しなければならないかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`position_locked`](/slides/python-net/ja/aspose.slides/autoshapelock/position_locked/) | この形状を移動することが禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`size_locked`](/slides/python-net/ja/aspose.slides/autoshapelock/size_locked/) | この形状のサイズ変更が禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`edit_points_locked`](/slides/python-net/ja/aspose.slides/autoshapelock/edit_points_locked/) | この形状の輪郭を直接変更することが禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`adjust_handles_locked`](/slides/python-net/ja/aspose.slides/autoshapelock/adjust_handles_locked/) | 調整値の変更が禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`arrowheads_locked`](/slides/python-net/ja/aspose.slides/autoshapelock/arrowheads_locked/) | 矢じりの変更が禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`shape_type_locked`](/slides/python-net/ja/aspose.slides/autoshapelock/shape_type_locked/) | 形状タイプの変更が禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`text_locked`](/slides/python-net/ja/aspose.slides/autoshapelock/text_locked/) | テキストの編集が禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
