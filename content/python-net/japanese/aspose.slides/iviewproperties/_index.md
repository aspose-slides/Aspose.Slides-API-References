## IViewProperties クラス

プレゼンテーション全体のビュー プロパティ。

IViewProperties 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`last_view`](/slides/python-net/ja/aspose.slides/iviewproperties/last_view/) | プレゼンテーション ドキュメントが最後に保存されたときに使用されたビュー モードを指定します。<br/>            読み書き [`ViewType`](/slides/python-net/ja/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/ja/aspose.slides/iviewproperties/show_comments/) | スライド コメントを表示するかどうかを指定します。<br/>            読み書き [`NullableBool`](/slides/python-net/ja/aspose.slides/nullablebool). |
| [`slide_view_properties`](/slides/python-net/ja/aspose.slides/iviewproperties/slide_view_properties/) | スライド ビュー モードに関連付けられた共通ビュー プロパティを指定します。<br/>            読み取り専用 [`ICommonSlideViewProperties`](/slides/python-net/ja/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/ja/aspose.slides/iviewproperties/notes_view_properties/) | ノート ビュー モードに関連付けられた共通ビュー プロパティを指定します。<br/>            読み取り専用 [`ICommonSlideViewProperties`](/slides/python-net/ja/aspose.slides/icommonslideviewproperties). |
| [`normal_view_properties`](/slides/python-net/ja/aspose.slides/iviewproperties/normal_view_properties/) | 通常ビューのプロパティを表します。通常ビューは<br/>            スライド自体、サイド コンテンツ領域、およびボトム コンテンツ領域の 3 つのコンテンツ領域で構成されます。<br/>            読み取り専用 [`INormalViewProperties`](/slides/python-net/ja/aspose.slides/inormalviewproperties). |
| [`grid_spacing`](/slides/python-net/ja/aspose.slides/iviewproperties/grid_spacing/) | プレゼンテーション ドキュメントの基になるグリッドに使用すべきグリッド間隔（ポイント単位）を取得または設定します。 <br/>            読み書き **float**. |
