## GroupShapeLock クラス

親の GroupShape で無効になっている操作を決定します。

**継承:**[`GroupShapeLock`](/slides/python-net/ja/aspose.slides/groupshapelock) → [`BaseShapeLock`](/slides/python-net/ja/aspose.slides/baseshapelock)

GroupShapeLock タイプは以下のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`no_locks`](/slides/python-net/ja/aspose.slides/groupshapelock/no_locks/) | すべての lock-flags が無効な場合に true を返します。<br/>            読み取り専用 **bool**. |
| [`grouping_locked`](/slides/python-net/ja/aspose.slides/groupshapelock/grouping_locked/) | このシェイプをグループに追加することが禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`ungrouping_locked`](/slides/python-net/ja/aspose.slides/groupshapelock/ungrouping_locked/) | この groupshape を分割することが禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`select_locked`](/slides/python-net/ja/aspose.slides/groupshapelock/select_locked/) | このシェイプの選択が禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`rotation_locked`](/slides/python-net/ja/aspose.slides/groupshapelock/rotation_locked/) | このシェイプの回転角度の変更が禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/ja/aspose.slides/groupshapelock/aspect_ratio_locked/) | リサイズ時にシェイプが aspect ratio を保持しなければならないかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`position_locked`](/slides/python-net/ja/aspose.slides/groupshapelock/position_locked/) | このシェイプの移動が禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`size_locked`](/slides/python-net/ja/aspose.slides/groupshapelock/size_locked/) | このシェイプのサイズ変更が禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
