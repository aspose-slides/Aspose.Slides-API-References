## NormalViewProperties クラス

Represents normal view properties. The normal view consists of
            three content regions: the slide itself, a side content region, and a bottom content region.

The NormalViewProperties type exposes the following members:

## プロパティ

| Property | Description |
| :- | :- |
| [`show_outline_icons`](/slides/python-net/ja/aspose.slides/normalviewproperties/show_outline_icons/) | アプリケーションが、通常ビュー モードのコンテンツ領域のいずれかにアウトライン コンテンツを表示する場合にアイコンを表示すべきかどうかを指定します。<br/>            読み書き可能 **bool**. |
| [`snap_vertical_splitter`](/slides/python-net/ja/aspose.slides/normalviewproperties/snap_vertical_splitter/) | サイド領域が十分に小さい場合に、垂直スプリッタが最小化状態にスナップすべきかどうかを指定します。<br/>            読み書き可能 **bool**. |
| [`vertical_bar_state`](/slides/python-net/ja/aspose.slides/normalviewproperties/vertical_bar_state/) | 垂直スプリッタ バーが表示される状態を指定します。<br/>            垂直スプリッタ バーはスライドとサイド コンテンツ領域を分割します。 |
| [`horizontal_bar_state`](/slides/python-net/ja/aspose.slides/normalviewproperties/horizontal_bar_state/) | 水平スプリッタ バーが表示される状態を指定します。<br/>            水平スプリッタ バーはスライドとスライド下のコンテンツ領域を分割します。 |
| [`prefer_single_view`](/slides/python-net/ja/aspose.slides/normalviewproperties/prefer_single_view/) | ユーザーが、3 つのコンテンツ領域を持つ標準の通常ビューではなく、ウィンドウ全体で単一のコンテンツ領域を表示することを好むかどうかを指定します。有効にすると、アプリケーションはコンテンツ領域のいずれかをウィンドウ全体に表示することを選択できる場合があります。<br/>            読み書き可能 **bool**. |
| [`restored_left`](/slides/python-net/ja/aspose.slides/normalviewproperties/restored_left/) | この要素は、領域が可変の復元サイズ（最小化でも最大化でもない）である場合の、通常ビューのサイド コンテンツ領域のサイズ指定を行います。<br/>            読み取り専用 [`INormalViewRestoredProperties`](/slides/python-net/ja/aspose.slides/inormalviewrestoredproperties). |
| [`restored_top`](/slides/python-net/ja/aspose.slides/normalviewproperties/restored_top/) | この要素は、領域が可変の復元サイズ（最小化でも最大化でもない）である場合の、通常ビューの上部スライド領域のサイズ指定を行います。<br/>            読み取り専用 [`INormalViewRestoredProperties`](/slides/python-net/ja/aspose.slides/inormalviewrestoredproperties). |
