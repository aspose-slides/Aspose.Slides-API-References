## 背景クラス

スライドの背景を表します。

**継承:**[`Background`](/slides/python-net/ja/aspose.slides/background) → [`PVIObject`](/slides/python-net/ja/aspose.slides/pviobject)

Background 型は次のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`type`](/slides/python-net/ja/aspose.slides/background/type/) | 背景塗りつぶしのタイプを返します。<br/>            読み書き [`BackgroundType`](/slides/python-net/ja/aspose.slides/backgroundtype)。 |
| [`fill_format`](/slides/python-net/ja/aspose.slides/background/fill_format/) | BackgroundType.OwnBackground 塗りつぶしの FillFormat を返します。<br/>            読み取り専用 [`IFillFormat`](/slides/python-net/ja/aspose.slides/ifillformat)。 |
| [`effect_format`](/slides/python-net/ja/aspose.slides/background/effect_format/) | BackgroundType.OwnBackground 塗りつぶしの EffectFormat を返します。<br/>            読み取り専用 [`IEffectFormat`](/slides/python-net/ja/aspose.slides/ieffectformat)。 |
| [`style_color`](/slides/python-net/ja/aspose.slides/background/style_color/) | BackgroundType.Themed 塗りつぶしの ColorFormat を返します。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat)。 |
| [`style_index`](/slides/python-net/ja/aspose.slides/background/style_index/) | BackgroundType.Themed 塗りつぶしのインデックスを背景テーマコレクションから返します。<br/>            0 は塗りつぶしなしを意味します。<br/>            1..999 - インデックス。<br/>            読み書き **int**。 |
| [`slide`](/slides/python-net/ja/aspose.slides/background/slide/) | シェイプの親スライドを返します。<br/>            読み取り専用 [`IBaseSlide`](/slides/python-net/ja/aspose.slides/ibaseslide)。 |
| [`presentation`](/slides/python-net/ja/aspose.slides/background/presentation/) | スライドの親プレゼンテーションを返します。<br/>            読み取り専用 [`IPresentation`](/slides/python-net/ja/aspose.slides/ipresentation)。 |
