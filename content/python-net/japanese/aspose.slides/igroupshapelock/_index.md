## IGroupShapeLock クラス

親の GroupShape で無効になっている操作を決定します。

IGroupShapeLock 型は以下のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`grouping_locked`](/slides/python-net/ja/aspose.slides/igroupshapelock/grouping_locked/) | このシェイプをグループに追加することが禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`ungrouping_locked`](/slides/python-net/ja/aspose.slides/igroupshapelock/ungrouping_locked/) | この groupshape を分割することが禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`select_locked`](/slides/python-net/ja/aspose.slides/igroupshapelock/select_locked/) | このシェイプの選択が禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`rotation_locked`](/slides/python-net/ja/aspose.slides/igroupshapelock/rotation_locked/) | このシェイプの回転角度を変更することが禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/ja/aspose.slides/igroupshapelock/aspect_ratio_locked/) | リサイズ時にシェイプがアスペクト比を保持しなければならないかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`position_locked`](/slides/python-net/ja/aspose.slides/igroupshapelock/position_locked/) | このシェイプの移動が禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`size_locked`](/slides/python-net/ja/aspose.slides/igroupshapelock/size_locked/) | このシェイプのサイズ変更が禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
