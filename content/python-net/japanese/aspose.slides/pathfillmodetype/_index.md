## PathFillModeType 列挙型

パスをどのように塗りつぶすかを指定します

PathFillModeType 型は次のメンバーを公開します：

## フィールド

| Field | Description |
| :- | :- |
| NONE | No Path Fill<br/>            これは、対応するパスに塗りつぶしがないことを指定します。 |
| NORMAL | Normal Path Fill<br/>            これは、対応するパスに通常の陰影が付いた色が塗りつぶしに適用されることを指定します。 |
| LIGHTEN | Lighten Path Fill<br/>            これは、対応するパスに軽く陰影が付いた色が塗りつぶしに適用されることを指定します。 |
| LIGHTEN_LESS | Lighten Path Fill Less<br/>            これは、対応するパスにやや明るい陰影の色が塗りつぶしに適用されることを指定します。 |
| DARKEN | Darken Path Fill<br/>            これは、対応するパスにより暗い陰影の色が塗りつぶしに適用されることを指定します。 |
| DARKEN_LESS | Darken Path Fill Less<br/>            これは、対応するパスにやや暗い陰影の色が塗りつぶしに適用されることを指定します。 |
