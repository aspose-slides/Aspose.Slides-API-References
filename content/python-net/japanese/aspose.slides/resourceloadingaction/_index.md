## ResourceLoadingAction 列挙体

外部リソースのロードモードを指定します。

ResourceLoadingAction 型は以下のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| DEFAULT | Aspose.Slides は外部リソースを通常どおりロードします。 |
| SKIP | Aspose.Slides は外部リソースのロードをスキップします。データのないリンクだけが画像として保存されます。 |
| USER_PROVIDED | Aspose.Slides はユーザーが提供したバイト配列を **Aspose.Slides.IResourceLoadingArgs.SetData(Syste** を画像データとして使用します。 |
