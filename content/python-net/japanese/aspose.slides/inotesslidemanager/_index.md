## INotesSlideManager クラス

ノートスライドマネージャー。

INotesSlideManager 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`notes_slide`](/slides/python-net/ja/aspose.slides/inotesslidemanager/notes_slide/) | 現在のスライドのノートスライドを返します。スライドにノートスライドがない場合は None を返します。<br/> 読み取り専用 [`INotesSlide`](/slides/python-net/ja/aspose.slides/inotesslide). |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`add_notes_slide(self)`](/slides/python-net/ja/aspose.slides/inotesslidemanager/add_notes_slide/#) | 現在のスライドのノートスライドを返し、存在しない場合は作成します。 |
| [`remove_notes_slide(self)`](/slides/python-net/ja/aspose.slides/inotesslidemanager/remove_notes_slide/#) | 現在のスライドのノートスライドを削除します。 |
