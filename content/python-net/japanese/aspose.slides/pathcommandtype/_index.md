## PathCommandType 列挙体

グラフィック パス コマンドを表します

PathCommandType 型は次のメンバーを公開します:

## フィールド

| フィールド | 説明 |
| :- | :- |
| CLOSE | ジオメトリパスを閉じます |
| MOVE_TO | ジオメトリパスの次の点の位置を設定します |
| LINE_TO | ジオメトリパスに直線を追加します |
| ARC_TO | ジオメトリパスに指定された円弧を追加します。 |
| QUAD_BEZIER_TO | ジオメトリパスに二次ベジェ曲線を追加します |
| CUBIC_BEZIER_TO | ジオメトリパスに三次ベジェ曲線を追加します |
