## IEffectFormat クラス

シェイプのエフェクトプロパティを表します。

IEffectFormat 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`is_no_effects`](/slides/python-net/ja/aspose.slides/ieffectformat/is_no_effects/) | すべてのエフェクトが無効になっている場合に true を返します（作成直後のデフォルト EffectFormat オブジェクトとして）。<br/> 読み取り専用 **bool**. |
| [`blur_effect`](/slides/python-net/ja/aspose.slides/ieffectformat/blur_effect/) | ぼかしエフェクト。<br/> 読み書き [`IBlur`](/slides/python-net/ja/aspose.slides.effects/iblur). |
| [`fill_overlay_effect`](/slides/python-net/ja/aspose.slides/ieffectformat/fill_overlay_effect/) | 塗りつぶしオーバーレイ エフェクト。<br/> 読み書き [`IFillOverlay`](/slides/python-net/ja/aspose.slides.effects/ifilloverlay). |
| [`glow_effect`](/slides/python-net/ja/aspose.slides/ieffectformat/glow_effect/) | グロー エフェクト。<br/> 読み書き [`IGlow`](/slides/python-net/ja/aspose.slides.effects/iglow). |
| [`inner_shadow_effect`](/slides/python-net/ja/aspose.slides/ieffectformat/inner_shadow_effect/) | インナー シャドウ。<br/> 読み書き [`IInnerShadow`](/slides/python-net/ja/aspose.slides.effects/iinnershadow). |
| [`outer_shadow_effect`](/slides/python-net/ja/aspose.slides/ieffectformat/outer_shadow_effect/) | アウトサイド シャドウ。<br/> 読み書き [`IOuterShadow`](/slides/python-net/ja/aspose.slides.effects/ioutershadow). |
| [`preset_shadow_effect`](/slides/python-net/ja/aspose.slides/ieffectformat/preset_shadow_effect/) | プリセット シャドウ。<br/> 読み書き [`IPresetShadow`](/slides/python-net/ja/aspose.slides.effects/ipresetshadow). |
| [`reflection_effect`](/slides/python-net/ja/aspose.slides/ieffectformat/reflection_effect/) | リフレクション。<br/> 読み書き [`IReflection`](/slides/python-net/ja/aspose.slides.effects/ireflection). |
| [`soft_edge_effect`](/slides/python-net/ja/aspose.slides/ieffectformat/soft_edge_effect/) | ソフト エッジ。<br/> 読み書き [`ISoftEdge`](/slides/python-net/ja/aspose.slides.effects/isoftedge). |
