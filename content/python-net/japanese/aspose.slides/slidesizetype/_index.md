## SlideSizeType 列挙体

スライドサイズのプリセットを表します。

SlideSizeType 型は次のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| ON_SCREEN | 画面上 4x3 |
| LETTER_PAPER | レター |
| A4_PAPER | A4 |
| SLIDE_35MM | スライド 35mm |
| OVERHEAD | オーバーヘッド |
| BANNER | バナー |
| CUSTOM | カスタムサイズ |
| LEDGER | 帳簿 |
| A3_PAPER | A3 |
| B4_ISO_PAPER | B4 ISO |
| B5_ISO_PAPER | B5 ISO |
| B4_JIS_PAPER | B4 JIS |
| B5_JIS_PAPER | B5 JIS |
| HAGAKI_CARD | はがきカード |
| ON_SCREEN_16X9 | 画面上 16x9 |
| ON_SCREEN_16X10 | 画面上 16x10 |
| WIDESCREEN | ワイドスクリーン |
