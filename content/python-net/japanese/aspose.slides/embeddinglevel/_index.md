## EmbeddingLevel 列挙体

フォントの埋め込みに関するライセンス権を表します。

EmbeddingLevel 型は次のメンバーを公開します。

## フィールド

| Field | Description |
| :- | :- |
| INSTALLABLE | この設定が付いたフォントは、アプリケーションによってリモートシステムに埋め込まれ、永続的にインストールできることを示します。<br/>            リモートシステムのユーザーは、そのフォントの元の購入者と同じ権利、義務、ライセンスを取得し、<br/>            元の購入者と同様のエンドユーザー使用許諾契約、著作権、意匠特許、または商標の対象となります。 |
| RESTRICTED | このビットのみが設定されたフォントは、法的所有者の許可を事前に取得せずに、いかなる方法でも変更、埋め込み、または交換してはなりません。 |
| PREVIEW_PRINT | このビットが設定されている場合、フォントは埋め込むことができ、リモートシステムに一時的にロードされます。Preview &<br/>            Print フォントを含むドキュメントは「読み取り専用」で開く必要があり、ドキュメントへの編集は許可されません。 |
| EDITABLE | このビットが設定されている場合、フォントは埋め込むことができますが、他のシステムには一時的にのみインストールされなければなりません。Preview &<br/>            Print フォントとは対照的に、Editable フォントを含むドキュメントは読み取り用に開くことができ、編集が許可され、変更を保存できます。 |
| NO_SUBSETTING | このビットが設定されている場合、フォントは埋め込む前にサブセット化することはできません。ビット 0-3 および 9 で指定されたその他の埋め込み制限も適用されます。 |
| BITMAP_ONLY | このビットが設定されている場合、フォントに含まれるビットマップのみが埋め込むことができます。アウトラインデータは埋め込むことができません。フォントにビットマップが全く存在しない場合は、<br/>            そのフォントは埋め込み不可とみなされ、埋め込みサービスは失敗します。 |
