## IDrawingGuide クラス

調整可能な描画ガイドを表します。

IDrawingGuide 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`orientation`](/slides/python-net/ja/aspose.slides/idrawingguide/orientation/) | 描画ガイドの向きを取得または設定します。<br/>            読み取り/書き込み [`Orientation`](/slides/python-net/ja/aspose.slides/orientation). |
| [`position`](/slides/python-net/ja/aspose.slides/idrawingguide/position/) | スライドの左上隅からのポイント単位で描画ガイドの位置を取得または設定します。<br/>            読み取り/書き込み **float**. |
| [`color`](/slides/python-net/ja/aspose.slides/idrawingguide/color/) | 描画ガイドの色を取得または設定します。<br/>            読み取り/書き込み [`Color`](/slides/python-net/ja/aspose.slides/color). |
