## ITab クラス

テキストのタブ化を表します。

ITab タイプは次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`position`](/slides/python-net/ja/aspose.slides/itab/position/) | タブの位置を取得または設定します。<br/>プロパティを設定すると、コレクション内のタブのインデックスが変更され、Enumerator が無効になることがあります。<br/>読み書き可能 **float**. |
| [`alignment`](/slides/python-net/ja/aspose.slides/itab/alignment/) | タブの配置スタイルを取得または設定します。<br/>読み書き可能 [`TabAlignment`](/slides/python-net/ja/aspose.slides/tabalignment). |
