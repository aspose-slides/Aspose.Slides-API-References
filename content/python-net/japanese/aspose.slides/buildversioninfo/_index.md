## BuildVersionInfo クラス

Aspose.Slides のバージョンに関する情報を含みます。

BuildVersionInfo 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`ASSEMBLY_VERSION`](/slides/python-net/ja/aspose.slides/buildversioninfo/assembly_version/) | Aspose.Slides アセンブリのバージョン。 |
| [`FILE_VERSION`](/slides/python-net/ja/aspose.slides/buildversioninfo/file_version/) | アセンブリ ファイルのバージョン。 |
| [`PRODUCT`](/slides/python-net/ja/aspose.slides/buildversioninfo/product/) | Aspose.Slides の製品名 |
| [`PRODUCT_MAJOR`](/slides/python-net/ja/aspose.slides/buildversioninfo/product_major/) | メジャーバージョン番号。 |
| [`PRODUCT_MINOR`](/slides/python-net/ja/aspose.slides/buildversioninfo/product_minor/) | マイナーバージョン番号。 |
| [`RELEASE_DATE`](/slides/python-net/ja/aspose.slides/buildversioninfo/release_date/) | アセンブリのリリース日。 |
