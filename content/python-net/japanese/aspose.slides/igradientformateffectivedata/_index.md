## IGradientFormatEffectiveData クラス

有効なグラデーション塗りつぶしプロパティを含む不変オブジェクトです。

IGradientFormatEffectiveData 型は次のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`tile_flip`](/slides/python-net/ja/aspose.slides/igradientformateffectivedata/tile_flip/) | グラデーションの反転モードを返します。<br/>            読み取り専用 [`TileFlip`](/slides/python-net/ja/aspose.slides/tileflip)。 |
| [`gradient_direction`](/slides/python-net/ja/aspose.slides/igradientformateffectivedata/gradient_direction/) | グラデーションのスタイルを返します。<br/>            読み取り専用 [`GradientDirection`](/slides/python-net/ja/aspose.slides/gradientdirection)。 |
| [`linear_gradient_angle`](/slides/python-net/ja/aspose.slides/igradientformateffectivedata/linear_gradient_angle/) | グラデーションの角度を返します。<br/>            読み取り専用 **float**。 |
| [`linear_gradient_scaled`](/slides/python-net/ja/aspose.slides/igradientformateffectivedata/linear_gradient_scaled/) | グラデーションがスケーリングされているかどうかを判断します。<br/>            読み取り専用 **bool**。 |
| [`gradient_shape`](/slides/python-net/ja/aspose.slides/igradientformateffectivedata/gradient_shape/) | グラデーションの形状を返します。<br/>            読み取り専用 [`GradientShape`](/slides/python-net/ja/aspose.slides/gradientshape)。 |
| [`gradient_stops`](/slides/python-net/ja/aspose.slides/igradientformateffectivedata/gradient_stops/) | グラデーションストップのコレクションを返します。<br/>            読み取り専用 [`IGradientStopCollectionEffectiveData`](/slides/python-net/ja/aspose.slides/igradientstopcollectioneffectivedata)。 |


### 備考

このインターフェイスは [`IFillFormatEffectiveData`](/slides/python-net/ja/aspose.slides/ifillformateffectivedata) と [`ILineFillFormatEffectiveData`](/slides/python-net/ja/aspose.slides/ilinefillformateffectivedata) の一部として使用されます。
