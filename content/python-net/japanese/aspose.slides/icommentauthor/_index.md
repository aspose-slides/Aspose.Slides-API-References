## ICommentAuthor クラス

コメントの作者を表します。

ICommentAuthor 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`name`](/slides/python-net/ja/aspose.slides/icommentauthor/name/) | 作者の名前を取得または設定します。<br/>            読み取り/書き込み **str**. |
| [`initials`](/slides/python-net/ja/aspose.slides/icommentauthor/initials/) | 作者のイニシャルを取得または設定します。<br/>            読み取り/書き込み **str**. |
| [`comments`](/slides/python-net/ja/aspose.slides/icommentauthor/comments/) | この作者が作成したコメントのコレクションを取得します。<br/>            読み取り専用 [`ICommentCollection`](/slides/python-net/ja/aspose.slides/icommentcollection). |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`remove(self)`](/slides/python-net/ja/aspose.slides/icommentauthor/remove/#) | 親コレクションから作者を削除します。 |
