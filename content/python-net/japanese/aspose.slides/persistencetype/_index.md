## PersistenceType 列挙

ActiveX コントロールのプロパティを格納する方法を指定します。

PersistenceType 型は、次のメンバーを公開します:

## フィールド

| フィールド | 説明 |
| :- | :- |
| NOT_DEFINED | 永続 ID が指定されていません。 |
| PERSIST_PROPERTY_BAG | ActiveX コントロールがプロパティ バッグ ベースの永続性を使用して永続化されることを指定します。 <br/>             プロパティ バッグ ベースの永続性は、名前と値のペアのコレクションによって ActiveX コントロールを永続化し、ActiveX コントロールによって永続化されるデータを指定します。 |
| PERSIST_STREAM | ActiveX コントロールがストリームベースの永続性を使用して永続化されることを指定します。 <br/>             これは、ActiveX コントロールをデフォルト状態に初期化することをサポートしません。 |
| PERSIST_STREAM_INIT | ActiveX コントロールがストリームベースの永続性を使用して永続化されることを指定します。 <br/>             これは、ActiveX コントロールをデフォルト状態に初期化することをサポートします。 |
| PERSIST_STORAGE | ActiveX コントロールがストレージベースの永続性を使用して永続化されることを指定します。 |
