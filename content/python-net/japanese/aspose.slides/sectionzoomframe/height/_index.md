## height プロパティ
形状の height を取得または設定します。単位はポイントです。
            読み書き **float**.

### 備考

返される値は常に定義済みで、**float** ではありません。
            割り当てられる値も定義済みである必要があります。`RawFrame` インスタンスのプロパティにのみ **float** を割り当ててください。
