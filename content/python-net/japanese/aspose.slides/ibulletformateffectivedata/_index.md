## IBulletFormatEffectiveData クラス

有効な段落の箇条書き書式プロパティを含む不変オブジェクトです。

IBulletFormatEffectiveData 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`type`](/slides/python-net/ja/aspose.slides/ibulletformateffectivedata/type/) | 段落の箇条書きタイプを取得します。<br/>            読み取り専用 [`BulletType`](/slides/python-net/ja/aspose.slides/bullettype)。 |
| [`char`](/slides/python-net/ja/aspose.slides/ibulletformateffectivedata/char/) | 段落の箇条書き文字を取得します。<br/>            読み取り専用 **System.Char**。 |
| [`actual_bullet_value`](/slides/python-net/ja/aspose.slides/ibulletformateffectivedata/actual_bullet_value/) | 親段落の実際の箇条書き値を取得します。<br/>            読み取り専用 **str**。 |
| [`font`](/slides/python-net/ja/aspose.slides/ibulletformateffectivedata/font/) | 段落の箇条書きフォントを取得します。<br/>            読み取り専用 [`IFontData`](/slides/python-net/ja/aspose.slides/ifontdata)。 |
| [`height`](/slides/python-net/ja/aspose.slides/ibulletformateffectivedata/height/) | 段落の箇条書きの高さを取得します。<br/>            読み取り専用 **float**。 |
| [`numbered_bullet_start_with`](/slides/python-net/ja/aspose.slides/ibulletformateffectivedata/numbered_bullet_start_with/) | 番号付き箇条書きのグループで使用される最初の番号を取得します。<br/>            読み取り専用 **int**。 |
| [`numbered_bullet_style`](/slides/python-net/ja/aspose.slides/ibulletformateffectivedata/numbered_bullet_style/) | 番号付き箇条書きのスタイルを取得します。<br/>            読み取り専用 [`NumberedBulletStyle`](/slides/python-net/ja/aspose.slides/numberedbulletstyle)。 |
| [`is_bullet_hard_color`](/slides/python-net/ja/aspose.slides/ibulletformateffectivedata/is_bullet_hard_color/) | 箇条書きが独自の色を持つか、段落の最初の部分から継承するかを判定します。<br/>            箇条書きが独自の色を持つ場合は **true**、段落の最初の部分から色を継承する場合は **false** を返します。<br/>            読み取り専用 **bool**。 |
| [`is_bullet_hard_font`](/slides/python-net/ja/aspose.slides/ibulletformateffectivedata/is_bullet_hard_font/) | 箇条書きが独自のフォントを持つか、段落の最初の部分から継承するかを判定します。<br/>            箇条書きが独自のフォントを持つ場合は **true**、段落の最初の部分からフォントを継承する場合は **true** を返します。<br/>            読み取り専用 **bool**。 |
| [`picture`](/slides/python-net/ja/aspose.slides/ibulletformateffectivedata/picture/) | 段落で箇条書きとして使用される画像を取得します。<br/>            読み取り専用 [`IPictureEffectiveData`](/slides/python-net/ja/aspose.slides/ipictureeffectivedata)。 |
| [`fill_format`](/slides/python-net/ja/aspose.slides/ibulletformateffectivedata/fill_format/) | 段落の箇条書き塗りつぶし形式を取得します。<br/>            読み取り専用 [`IFillFormatEffectiveData`](/slides/python-net/ja/aspose.slides/ifillformateffectivedata)。 |

### 備考

このインターフェイスは [`IParagraphFormatEffectiveData`](/slides/python-net/ja/aspose.slides/iparagraphformateffectivedata) の一部として使用されます。
