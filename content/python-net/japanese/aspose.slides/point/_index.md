## Point クラス

整数の x および y 座標の順序付きペアを表し、2 次元平面上の点を定義します。.NET `System.Drawing.Point` と互換性があります。

Point 型は次のメンバーを公開します:

## コンストラクタ

| コンストラクタ | 説明 |
| :- | :- |
| [`__init__(self, x=0, y=0)`](/slides/python-net/ja/aspose.slides/point/__init__/#int-int) | 指定された座標でポイントを作成します。浮動小数点値は整数に切り捨てられます。 |

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`x`](/slides/python-net/ja/aspose.slides/point/x/) | このポイントの x 座標を取得または設定します。<br/>            読み取り/書き込み **int**. |
| [`y`](/slides/python-net/ja/aspose.slides/point/y/) | このポイントの y 座標を取得または設定します。<br/>            読み取り/書き込み **int**. |


### 備考

ポイントは `==` 演算子で座標を比較され、辞書のキーや集合のメンバーとして使用できます。
