## IImage クラス

ラスター画像またはベクトル画像を表します。

IImage 型は以下のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`size`](/slides/python-net/ja/aspose.slides/iimage/size/) | 画像のサイズを取得します。 |
| [`width`](/slides/python-net/ja/aspose.slides/iimage/width/) | 画像の幅（ピクセル）を取得します。 |
| [`height`](/slides/python-net/ja/aspose.slides/iimage/height/) | 画像の高さ（ピクセル）を取得します。 |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`save(self, filename)`](/slides/python-net/ja/aspose.slides/iimage/save/#str) | 画像をファイルに保存します。 |
| [`save(self, filename, format)`](/slides/python-net/ja/aspose.slides/iimage/save/#str-imageformat) | 画像を指定された形式でファイルに保存します。 |
| [`save(self, stream, format)`](/slides/python-net/ja/aspose.slides/iimage/save/#iorawiobase-imageformat) | 画像を指定された形式でストリームに保存します。 |
| [`save(self, filename, format, quality)`](/slides/python-net/ja/aspose.slides/iimage/save/#str-imageformat-int) | 画像を指定された形式と品質でファイルに保存します。 |
| [`save(self, stream, format, quality)`](/slides/python-net/ja/aspose.slides/iimage/save/#iorawiobase-imageformat-int) | 画像を指定された形式と品質でストリームに保存します。 |


### 備考

このインターフェイスは、ラスター画像とベクトル画像の両方を処理するための共通抽象を提供します。  
実装は基になる画像タイプに応じて異なる場合があります。
