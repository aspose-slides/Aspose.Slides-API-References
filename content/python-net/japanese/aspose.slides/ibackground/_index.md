## IBackground クラス

スライドの背景を表します。

IBackground 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`type`](/slides/python-net/ja/aspose.slides/ibackground/type/) | 背景塗りつぶしのタイプを返します。<br/>            読み取り/書き込み [`BackgroundType`](/slides/python-net/ja/aspose.slides/backgroundtype). |
| [`fill_format`](/slides/python-net/ja/aspose.slides/ibackground/fill_format/) | BackgroundType.OwnBackground 塗りつぶしの FillFormat を返します。<br/>            読み取り専用 [`IFillFormat`](/slides/python-net/ja/aspose.slides/ifillformat). |
| [`effect_format`](/slides/python-net/ja/aspose.slides/ibackground/effect_format/) | BackgroundType.OwnBackground 塗りつぶしの EffectFormat を返します。<br/>            読み取り専用 [`IEffectFormat`](/slides/python-net/ja/aspose.slides/ieffectformat). |
| [`style_color`](/slides/python-net/ja/aspose.slides/ibackground/style_color/) | BackgroundType.Themed 塗りつぶしの ColorFormat を返します。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat). |
| [`style_index`](/slides/python-net/ja/aspose.slides/ibackground/style_index/) | BackgroundType.Themed 塗りつぶしの背景テーマコレクション内のインデックスを返します。<br/>            0 は塗りつぶしなしを意味します。<br/>            1..999 - インデックス。<br/>            読み取り/書き込み **int**. |
| [`slide`](/slides/python-net/ja/aspose.slides/ibackground/slide/) |  |
| [`presentation`](/slides/python-net/ja/aspose.slides/ibackground/presentation/) |  |
