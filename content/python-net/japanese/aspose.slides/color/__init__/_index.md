## __init__(self, r=0, g=0, b=0, a=255) {#int-int-int-int}
指定された赤、緑、青、およびアルファ成分の値から色を作成します。

```python
def __init__(self, r=0, g=0, b=0, a=255):
    ...
```

| パラメータ | 型 | 説明 |
| :- | :- | :- |
| r | **int** | 赤成分の値です。有効な値は 0 から 255 です。 |
| g | **int** | 緑成分の値です。有効な値は 0 から 255 です。 |
| b | **int** | 青成分の値です。有効な値は 0 から 255 です。 |
| a | **int** | アルファ成分の値です。有効な値は 0 から 255 です。 |

### 例外

| 例外 | 説明 |
| :- | :- |
| **ValueError** | 成分の値が 0 未満または 255 超えです。 |
| **TypeError** | 成分の値が数値ではありません。 |
