## is_system_color プロパティ
このカラーがシステムカラーかどうかを指定します。システムカラーは、`Control` や `ActiveBorder` などの Windows の表示要素に使用される色です。<br/>            システムカラーは `Color` 属性として公開されておらず、[`from_known_color`](/slides/python-net/ja/aspose.slides/color/from_known_color/) で取得するか、ライブラリから返されるのみです。
            読み取り専用 **bool**.
