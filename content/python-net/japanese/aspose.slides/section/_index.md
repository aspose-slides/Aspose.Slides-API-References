## Section クラス

スライドのセクションを表します。

Section 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`name`](/slides/python-net/ja/aspose.slides/section/name/) | セクションの名前。 |
| [`section_id`](/slides/python-net/ja/aspose.slides/section/section_id/) | セクション ID。 |
| [`started_from_slide`](/slides/python-net/ja/aspose.slides/section/started_from_slide/) | セクションの最初のスライドを返します。 |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`get_slides_list_of_section(self)`](/slides/python-net/ja/aspose.slides/section/get_slides_list_of_section/#) | セクション内のスライドの一覧を返します。 |
