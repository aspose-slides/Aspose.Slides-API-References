## IGraphicalObjectLock クラス

親の GraphicalObjectEx で無効になる操作を決定します。

IGraphicalObjectLock 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`grouping_locked`](/slides/python-net/ja/aspose.slides/igraphicalobjectlock/grouping_locked/) | このシェイプをグループに追加することが禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`drilldown_locked`](/slides/python-net/ja/aspose.slides/igraphicalobjectlock/drilldown_locked/) | このオブジェクトのサブシェイプを選択することが禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`select_locked`](/slides/python-net/ja/aspose.slides/igraphicalobjectlock/select_locked/) | このシェイプを選択することが禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/ja/aspose.slides/igraphicalobjectlock/aspect_ratio_locked/) | リサイズ時にシェイプがアスペクト比を保持しなければならないかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`position_locked`](/slides/python-net/ja/aspose.slides/igraphicalobjectlock/position_locked/) | このシェイプを移動することが禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`size_locked`](/slides/python-net/ja/aspose.slides/igraphicalobjectlock/size_locked/) | このシェイプをリサイズすることが禁止されているかどうかを決定します。<br/>            読み取り/書き込み **bool**. |
| [`no_locks`](/slides/python-net/ja/aspose.slides/igraphicalobjectlock/no_locks/) |  |
