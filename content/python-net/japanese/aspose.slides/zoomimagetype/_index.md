## ZoomImageType 列挙型

Zoom オブジェクトがスライドプレビューを使用するかカバー画像を使用するかを定義します。

ZoomImageType 型は次のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| PREVIEW | スライドまたはセクションの画像を使用します。 |
| COVER | カスタム画像を使用します。 |
