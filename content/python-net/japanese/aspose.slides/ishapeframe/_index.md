## IShapeFrame クラス

シェイプフレームのプロパティを表します。

IShapeFrame 型は以下のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`x`](/slides/python-net/ja/aspose.slides/ishapeframe/x/) | フレームの左上隅の X 座標を返します。<br/>            読み取り専用 **float**. |
| [`y`](/slides/python-net/ja/aspose.slides/ishapeframe/y/) | フレームの左上隅の Y 座標を返します。<br/>            読み取り専用 **float**. |
| [`width`](/slides/python-net/ja/aspose.slides/ishapeframe/width/) | フレームの幅を返します。<br/>            読み取り専用 **float**. |
| [`height`](/slides/python-net/ja/aspose.slides/ishapeframe/height/) | フレームの高さを返します。<br/>            読み取り専用 **float**. |
| [`rotation`](/slides/python-net/ja/aspose.slides/ishapeframe/rotation/) | フレームが Z 軸を中心に回転する角度（度）を返します。<br/>            正の値は時計回りの回転を示し、負の値は反時計回りの回転を示します。<br/>            読み取り専用 **float**. |
| [`center_x`](/slides/python-net/ja/aspose.slides/ishapeframe/center_x/) | フレームの中心の X 座標を返します。<br/>            読み取り専用 **float**. |
| [`center_y`](/slides/python-net/ja/aspose.slides/ishapeframe/center_y/) | フレームの中心の Y 座標を返します。<br/>            読み取り専用 **float**. |
| [`flip_h`](/slides/python-net/ja/aspose.slides/ishapeframe/flip_h/) | フレームが水平に反転しているかどうかを判断します。<br/>            読み取り専用 [`NullableBool`](/slides/python-net/ja/aspose.slides/nullablebool). |
| [`flip_v`](/slides/python-net/ja/aspose.slides/ishapeframe/flip_v/) | フレームが垂直に反転しているかどうかを判断します。<br/>            読み取り専用 [`NullableBool`](/slides/python-net/ja/aspose.slides/nullablebool). |
| [`rectangle`](/slides/python-net/ja/aspose.slides/ishapeframe/rectangle/) | フレームの座標を返します。<br/>            読み取り専用 **aspose.slides.RectangleF**. |
