## IControlPropertiesCollection クラス

ActiveX コントロールのコレクションです。

IControlPropertiesCollection 型は以下のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`count`](/slides/python-net/ja/aspose.slides/icontrolpropertiescollection/count/) | コレクション内のプロパティの数を返します。<br/>            読み取り専用 **int**. |
| [`names_of_properties`](/slides/python-net/ja/aspose.slides/icontrolpropertiescollection/names_of_properties/) | コレクション内のプロパティの数を返します。<br/>            読み取り専用 **list**. |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`add(self, name, value)`](/slides/python-net/ja/aspose.slides/icontrolpropertiescollection/add/#str-str) | コレクションにプロパティを追加します。 |
| [`remove(self, name)`](/slides/python-net/ja/aspose.slides/icontrolpropertiescollection/remove/#str) | 指定された名前のプロパティを削除します。 |
| [`clear(self)`](/slides/python-net/ja/aspose.slides/icontrolpropertiescollection/clear/#) | すべてのプロパティを削除します。 |
