## ICommonSlideViewProperties クラス

共通スライドビュー プロパティを表します。

ICommonSlideViewProperties 型は次のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`scale`](/slides/python-net/ja/aspose.slides/icommonslideviewproperties/scale/) | ビューのスケーリング比率をパーセンテージで指定します。<br/>            読み書き **int**. |
| [`variable_scale`](/slides/python-net/ja/aspose.slides/icommonslideviewproperties/variable_scale/) | ビュー コンテンツが現在のウィンドウサイズに最適に合わせて自動的にスケールするように指定します。<br/>            読み書き **bool**. |
| [`drawing_guides`](/slides/python-net/ja/aspose.slides/icommonslideviewproperties/drawing_guides/) | 描画ガイドのコレクションを返します。<br/>            読み取り専用 [`IDrawingGuidesCollection`](/slides/python-net/ja/aspose.slides/idrawingguidescollection) |
