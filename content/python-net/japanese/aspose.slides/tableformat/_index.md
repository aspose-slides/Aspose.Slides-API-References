## TableFormat クラス

テーブルの書式を表します。

TableFormat 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`fill_format`](/slides/python-net/ja/aspose.slides/tableformat/fill_format/) | テーブルの塗りつぶしプロパティ オブジェクトを返します。<br/>            読み取り専用 [`IFillFormat`](/slides/python-net/ja/aspose.slides/ifillformat). |
| [`transparency`](/slides/python-net/ja/aspose.slides/tableformat/transparency/) | 塗りつぶし色の透明度を取得または設定します。<br/>            読み取り/書き込み **float**. |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`get_effective(self)`](/slides/python-net/ja/aspose.slides/tableformat/get_effective/#) | 継承とテーブル スタイルが適用された有効なテーブル書式プロパティを取得します。 |
