## IBaseSlideHeaderFooterManager クラス

すべてのスライドタイプのフッタ、日時、ページ番号プレースホルダーの動作を保持するマネージャーを表します。

IBaseSlideHeaderFooterManager 型は次のメンバーを公開します:

| プロパティ | 説明 |

| [`is_footer_visible`](/slides/python-net/ja/aspose.slides/ibaseslideheaderfootermanager/is_footer_visible/) | フッタプレースホルダーが存在することを示す値を取得します。<br/>            Read **bool**. |
| [`is_slide_number_visible`](/slides/python-net/ja/aspose.slides/ibaseslideheaderfootermanager/is_slide_number_visible/) | ページ番号プレースホルダーが存在することを示す値を取得します。<br/>            Read**bool**. |
| [`is_date_time_visible`](/slides/python-net/ja/aspose.slides/ibaseslideheaderfootermanager/is_date_time_visible/) | 日時プレースホルダーが存在することを示す値を取得します。<br/>            Read**bool**. |
