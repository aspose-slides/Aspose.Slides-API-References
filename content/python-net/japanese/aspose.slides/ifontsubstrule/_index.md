## IFontSubstRule クラス

フォント置換情報を表します

IFontSubstRule 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`source_font`](/slides/python-net/ja/aspose.slides/ifontsubstrule/source_font/) | 置換対象のFont<br/>            読み取り専用 [`IFontData`](/slides/python-net/ja/aspose.slides/ifontdata). |
| [`dest_font`](/slides/python-net/ja/aspose.slides/ifontsubstrule/dest_font/) | 置換に使用するFont<br/>            読み取り専用 [`IFontData`](/slides/python-net/ja/aspose.slides/ifontdata). |
| [`replace_font_condition`](/slides/python-net/ja/aspose.slides/ifontsubstrule/replace_font_condition/) | 置換に適用するRule<br/>            読み取り専用 [`FontSubstCondition`](/slides/python-net/ja/aspose.slides/fontsubstcondition). |
