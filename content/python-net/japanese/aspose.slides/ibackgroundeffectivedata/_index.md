## IBackgroundEffectiveData クラス

効果的な背景プロパティを含む不変オブジェクトです。

IBackgroundEffectiveData 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`fill_format`](/slides/python-net/ja/aspose.slides/ibackgroundeffectivedata/fill_format/) | 有効な塗りつぶし形式を返します。<br/>            読み取り専用 [`IFillFormatEffectiveData`](/slides/python-net/ja/aspose.slides/ifillformateffectivedata)。 |
| [`effect_format`](/slides/python-net/ja/aspose.slides/ibackgroundeffectivedata/effect_format/) | 有効な効果形式を返します。<br/>            読み取り専用 [`IEffectFormatEffectiveData`](/slides/python-net/ja/aspose.slides/ieffectformateffectivedata)。 |


### 備考

このインターフェイスは [`IBackground`](/slides/python-net/ja/aspose.slides/ibackground) インターフェイスと組み合わせて、継承が適用された有効な書式設定値を返すために使用されます。
