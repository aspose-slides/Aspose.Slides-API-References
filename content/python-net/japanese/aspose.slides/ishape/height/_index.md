## height プロパティ
ポイント単位で測定された shape の height を取得または設定します。
            読み取り/書き込み **float**。


### Remarks

返される値は常に定義済みであり、**float** ではありません。
            割り当てられる値も定義済みである必要があります。`RawFrame` インスタンスのプロパティに対してのみ **float** を割り当ててください。
