## Row クラス

テーブル内の行を表します。

**継承:**[`Row`](/slides/python-net/ja/aspose.slides/row) → [`CellCollection`](/slides/python-net/ja/aspose.slides/cellcollection)

Row タイプは以下のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`slide`](/slides/python-net/ja/aspose.slides/row/slide/) | CellCollection の親スライドを返します。<br/>            読み取り専用 [`IBaseSlide`](/slides/python-net/ja/aspose.slides/ibaseslide)。 |
| [`presentation`](/slides/python-net/ja/aspose.slides/row/presentation/) | CellCollection の親プレゼンテーションを返します。<br/>            読み取り専用 [`IPresentation`](/slides/python-net/ja/aspose.slides/ipresentation)。 |
| [`height`](/slides/python-net/ja/aspose.slides/row/height/) | 行の高さを返します。<br/>            読み取り専用 **float**。 |
| [`minimal_height`](/slides/python-net/ja/aspose.slides/row/minimal_height/) | 行の最小可能高さを取得または設定します。<br/>            読み取り/書き込み **float**。 |
| [`row_format`](/slides/python-net/ja/aspose.slides/row/row_format/) | この行の書式設定プロパティを含む RowFormat オブジェクトを返します。<br/>            読み取り専用 [`IRowFormat`](/slides/python-net/ja/aspose.slides/irowformat)。 |
