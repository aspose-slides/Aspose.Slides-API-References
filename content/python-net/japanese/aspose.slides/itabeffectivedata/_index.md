## ITabEffectiveData クラス

有効なテキストのタブ停止プロパティを含む不変オブジェクトです。

ITabEffectiveData 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`position`](/slides/python-net/ja/aspose.slides/itabeffectivedata/position/) | タブの位置を返します。<br/>            このプロパティを設定すると、コレクション内のタブのインデックスが変更され、Enumerator が無効になる可能性があります。<br/>            読み取り専用 **float**. |
| [`alignment`](/slides/python-net/ja/aspose.slides/itabeffectivedata/alignment/) | タブの配置スタイルを返します。<br/>            読み取り専用 [`TabAlignment`](/slides/python-net/ja/aspose.slides/tabalignment). |


### 備考

このインターフェイスは [`IParagraphFormatEffectiveData`](/slides/python-net/ja/aspose.slides/iparagraphformateffectivedata) の一部として使用されます。
