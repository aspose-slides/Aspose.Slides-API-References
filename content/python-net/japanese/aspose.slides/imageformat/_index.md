## ImageFormat 列挙体

画像のファイル形式を表します。

ImageFormat 型は次のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| MEMORY_BMP | メモリ内のビットマップの形式を表します。 |
| BMP | ビットマップ (BMP) 画像形式を表します。 |
| EMF | 拡張メタファイル (EMF) 画像形式を表します。 |
| WMF | Windows メタファイル (WMF) 画像形式を表します。 |
| GIF | Graphics Interchange Format (GIF) 画像形式を表します。 |
| JPEG | Joint Photographic Experts Group (JPEG) 画像形式を表します。 |
| PNG | W3C Portable Network Graphics (PNG) 画像形式を表します。 |
| TIFF | Tagged Image File Format (TIFF) 画像形式を表します。 |
| EXIF | Exchangeable Image File (Exif) 形式を表します。 |
| ICON | Windows アイコン画像形式を表します。 |
