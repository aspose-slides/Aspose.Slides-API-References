## BlackWhiteMode 列挙型

カラーシェイプが白黒に変換される方法を決定します。

BlackWhiteMode 型は次のメンバーを公開します：

## フィールド

| フィールド | 説明 |
| :- | :- |
| NOT_DEFINED | プロパティが設定されていません |
| COLOR | オブジェクトは通常の色付けで描画されます |
| AUTOMATIC | オブジェクトは自動色付けで描画されます |
| GRAY | オブジェクトはグレーで描画されます |
| LIGHT_GRAY | オブジェクトは薄いグレーで描画されます |
| INVERSE_GRAY | オブジェクトは反転グレーで描画されます |
| GRAY_WHITE | オブジェクトはグレーと白で描画されます |
| BLACK_GRAY | オブジェクトは黒とグレーで描画されます |
| BLACK_WHITE | オブジェクトは黒と白で描画されます |
| BLACK | オブジェクトは黒だけで描画されます |
| WHITE | オブジェクトは白で描画されます |
| HIDDEN | オブジェクトは描画されません |
