## FontStyleType 列挙型

テキストに適用できる書式スタイルを定義します。

FontStyleType 型は以下のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| REGULAR | 標準テキスト。 |
| BOLD | 太字テキスト。 |
| ITALIC | 斜体テキスト。 |
| UNDERLINE | 下線付きテキスト。 |
| STRIKEOUT | 横線で取り消し線が引かれたテキスト。 |
