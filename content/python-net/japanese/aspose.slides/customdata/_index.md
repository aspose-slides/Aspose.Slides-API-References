## CustomData クラス

カスタム データのコンテナを表します。

CustomData 型は次のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`tags`](/slides/python-net/ja/aspose.slides/customdata/tags/) | Customer Data Tags コレクションを返します。<br/>            読み取り専用 [`ITagCollection`](/slides/python-net/ja/aspose.slides/itagcollection)。 |
| [`custom_xml_parts`](/slides/python-net/ja/aspose.slides/customdata/custom_xml_parts/) | カスタム XML パーツ コレクションを返します。<br/>            読み取り専用 [`ICustomXmlPartCollection`](/slides/python-net/ja/aspose.slides/icustomxmlpartcollection)。 |
