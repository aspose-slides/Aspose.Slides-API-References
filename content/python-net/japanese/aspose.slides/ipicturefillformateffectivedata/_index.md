## IPictureFillFormatEffectiveData クラス

画像塗りつぶしのプロパティを含む不変オブジェクトです。

IPictureFillFormatEffectiveData 型は次のメンバーを公開します。

## Properties

| プロパティ | 説明 |
| :- | :- |
| [`dpi`](/slides/python-net/ja/aspose.slides/ipicturefillformateffectivedata/dpi/) | 画像を塗りつぶす際に使用される DPI を返します。<br/>            読み取り専用 **int**. |
| [`picture_fill_mode`](/slides/python-net/ja/aspose.slides/ipicturefillformateffectivedata/picture_fill_mode/) | 画像塗りつぶしモードを返します。<br/>            読み取り専用 [`PictureFillMode`](/slides/python-net/ja/aspose.slides/picturefillmode). |
| [`picture`](/slides/python-net/ja/aspose.slides/ipicturefillformateffectivedata/picture/) | 画像を返します。<br/>            読み取り専用 [`IPictureEffectiveData`](/slides/python-net/ja/aspose.slides/ipictureeffectivedata). |
| [`crop_left`](/slides/python-net/ja/aspose.slides/ipicturefillformateffectivedata/crop_left/) | 画像の左側で切り取られる実際の画像幅のパーセンテージを返します。<br/>            読み取り専用 **float**. |
