## ICameraEffectiveData クラス

効果的なカメラプロパティを含む不変オブジェクトです。

ICameraEffectiveData 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`camera_type`](/slides/python-net/ja/aspose.slides/icameraeffectivedata/camera_type/) | カメラタイプ。<br/>            読み取り専用 [`CameraPresetType`](/slides/python-net/ja/aspose.slides/camerapresettype)。 |
| [`field_of_view_angle`](/slides/python-net/ja/aspose.slides/icameraeffectivedata/field_of_view_angle/) | カメラFOV（0-180度、視野角）。<br/>            読み取り専用 **float**。 |
| [`zoom`](/slides/python-net/ja/aspose.slides/icameraeffectivedata/zoom/) | カメラズーム（パーセンテージでの正の値）。<br/>            読み取り専用 **float**。 |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`get_rotation(self)`](/slides/python-net/ja/aspose.slides/icameraeffectivedata/get_rotation/#) | 緯度<br/>            座標、経度座標、および軸周りの回転を使用して回転が定義されます<br/>            緯度と経度座標として。<br/>            戻り配列の最初の要素は緯度、2番目は経度、3番目は回転です。<br/>            回転が定義されていない場合は None を返します。 |

### 備考

このインターフェイスは [`IThreeDFormatEffectiveData`](/slides/python-net/ja/aspose.slides/ithreedformateffectivedata) の一部として使用されます。
