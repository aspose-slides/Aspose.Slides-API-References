## ITableFormat クラス

テーブルの書式を表します。

ITableFormat 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`fill_format`](/slides/python-net/ja/aspose.slides/itableformat/fill_format/) | テーブルの塗りつぶしプロパティ オブジェクトを返します。<br/>            読み取り専用 [`IFillFormat`](/slides/python-net/ja/aspose.slides/ifillformat). |
| [`transparency`](/slides/python-net/ja/aspose.slides/itableformat/transparency/) | 塗りつぶし色の透明度を取得または設定します。<br/>            読み書き可能 **float**. |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`get_effective(self)`](/slides/python-net/ja/aspose.slides/itableformat/get_effective/#) | 継承およびテーブル スタイルが適用された有効なテーブル書式プロパティを取得します。 |
