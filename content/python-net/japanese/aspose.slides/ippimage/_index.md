## IPPImage クラス

プレゼンテーション内の画像を表します。

IPPImage 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`binary_data`](/slides/python-net/ja/aspose.slides/ippimage/binary_data/) | 画像データのコピーを返します。<br/>            読み取り専用 **int**[]. |
| [`image`](/slides/python-net/ja/aspose.slides/ippimage/image/) | 画像のコピーを返します。<br/>            読み取り専用 [`IPPImage.image`](/slides/python-net/ja/aspose.slides/ippimage/image). |
| [`svg_image`](/slides/python-net/ja/aspose.slides/ippimage/svg_image/) | 取得または設定します ISvgImage オブジェクト [`ISvgImage`](/slides/python-net/ja/aspose.slides/isvgimage) |
| [`content_type`](/slides/python-net/ja/aspose.slides/ippimage/content_type/) | 画像の MIME タイプ（[`IPPImage.binary_data`](/slides/python-net/ja/aspose.slides/ippimage/binary_data) にエンコード）を返します。<br/>            読み取り専用 **str**. |
| [`width`](/slides/python-net/ja/aspose.slides/ippimage/width/) | 画像の幅を返します。<br/>            読み取り専用 **int**. |
| [`height`](/slides/python-net/ja/aspose.slides/ippimage/height/) | 画像の高さを返します。<br/>            読み取り専用 **int**. |
| [`x`](/slides/python-net/ja/aspose.slides/ippimage/x/) | 画像の X オフセットを返します。<br/>            読み取り専用 **int**. |
| [`y`](/slides/python-net/ja/aspose.slides/ippimage/y/) | 画像の Y オフセットを返します。<br/>            読み取り専用 **int**. |
