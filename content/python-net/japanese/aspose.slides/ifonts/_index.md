## IFonts クラス

フォント コレクションを表します。

IFonts 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`latin_font`](/slides/python-net/ja/aspose.slides/ifonts/latin_font/) | Latin フォントを取得または設定します。<br/>            読み書き [`IFontData`](/slides/python-net/ja/aspose.slides/ifontdata). |
| [`east_asian_font`](/slides/python-net/ja/aspose.slides/ifonts/east_asian_font/) | East Asian フォントを取得または設定します。<br/>            読み書き [`IFontData`](/slides/python-net/ja/aspose.slides/ifontdata). |
| [`complex_script_font`](/slides/python-net/ja/aspose.slides/ifonts/complex_script_font/) | 複合スクリプト フォントを取得または設定します。<br/>            読み書き [`IFontData`](/slides/python-net/ja/aspose.slides/ifontdata). |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`get_script_font_map(self)`](/slides/python-net/ja/aspose.slides/ifonts/get_script_font_map/#) | プレゼンテーション内のすべての文字列-文字列ペア スクリプト フォント定義のリストを返します。 |
| [`get_script_font(self, script)`](/slides/python-net/ja/aspose.slides/ifonts/get_script_font/#str) | プレゼンテーション テーマから特定のスクリプト タグに関連付けられたフォント名を取得します。 |
| [`set_script_font(self, script, font_name)`](/slides/python-net/ja/aspose.slides/ifonts/set_script_font/#str-str) | 特定のスクリプト タグにフォント名を割り当てます。これにより、そのスクリプトのテキストがプレゼンテーションでどのように表示されるかが定義されます。 |
| [`remove_script_font(self, script)`](/slides/python-net/ja/aspose.slides/ifonts/remove_script_font/#str) | テーマのフォント コレクションから特定のスクリプト タグに関連付けられたフォント設定を削除します。 |
