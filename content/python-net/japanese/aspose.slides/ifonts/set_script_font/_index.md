## set_script_font(self, script, font_name) {#str-str}
特定のスクリプトタグにフォント名を割り当てます。このタグはプレゼンテーション内でそのスクリプトのテキストがどのようにレンダリングされるかを定義します。

```python
def set_script_font(self, script, font_name):
    ...
```

| パラメータ | タイプ | 説明 |
| :- | :- | :- |
| script | **str** | BCP-47 スクリプトコード（例: "Arab", "Hebr", "Hans"）で、文字体系を識別します。 |
| font_name | **str** | 指定されたスクリプトに割り当てるフォントの名前。 |
