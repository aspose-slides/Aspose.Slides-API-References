## TextSearchOptions クラス

プレゼンテーション、スライド、または TextFrame 内のテキストを検索するために使用できるオプションを表します。

TextSearchOptions 型は次のメンバーを公開します。

## コンストラクタ

| コンストラクタ | 説明 |
| :- | :- |
| [`__init__(self)`](/slides/python-net/ja/aspose.slides/textsearchoptions/__init__/#) | 新しいデフォルトのテキスト検索オプションを作成します。 |

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`case_sensitive`](/slides/python-net/ja/aspose.slides/textsearchoptions/case_sensitive/) | true に設定すると大文字小文字を区別した検索を使用し、false に設定すると区別しません。<br/>            読み書き可能 **bool**. |
| [`whole_words_only`](/slides/python-net/ja/aspose.slides/textsearchoptions/whole_words_only/) | true に設定すると単語全体のみを一致させ、false の場合はそれ以外です。<br/>            読み書き可能 **bool**. |
| [`include_notes`](/slides/python-net/ja/aspose.slides/textsearchoptions/include_notes/) | `true` に設定すると、スライドノート ([`NotesSlide`](/slides/python-net/ja/aspose.slides/notesslide)) に含まれるテキストをテキスト検索、置換、またはハイライト操作を行う際に含めます。<br/>            デフォルト値は `false`です。 |
