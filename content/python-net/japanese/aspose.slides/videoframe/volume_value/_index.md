## volume_value プロパティ
正確なビデオ音量をパーセンテージとして返すまたは設定します。
             この値は 0 から 100 のパーセンテージで表されます。[`VideoFrame.volume`](/slides/python-net/ja/aspose.slides/videoframe/volume) プロパティを通じて利用できる事前定義レベルよりも、より正確な音量値を読み取ったり設定したりするためにこのプロパティを使用します。
             読み取り/書き込み **float**.
