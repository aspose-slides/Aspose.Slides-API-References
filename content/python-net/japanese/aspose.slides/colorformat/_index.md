## ColorFormat クラス

プレゼンテーションで使用される色を表します。

**継承:**[`ColorFormat`](/slides/python-net/ja/aspose.slides/colorformat) → [`PVIObject`](/slides/python-net/ja/aspose.slides/pviobject)

ColorFormat 型は以下のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`color_type`](/slides/python-net/ja/aspose.slides/colorformat/color_type/) | 色定義方法を取得または設定します。<br/>            読み書き [`ColorType`](/slides/python-net/ja/aspose.slides/colortype)。 |
| [`color`](/slides/python-net/ja/aspose.slides/colorformat/color/) | すべての色変換が適用された結果の色を取得します。<br/>            RGB 色を設定し、すべての色変換をクリアします。<br/>            読み書き [`Color`](/slides/python-net/ja/aspose.slides/color)。 |
| [`preset_color`](/slides/python-net/ja/aspose.slides/colorformat/preset_color/) | 色のプリセットを取得または設定します。<br/>            読み書き [`PresetColor`](/slides/python-net/ja/aspose.slides/presetcolor)。 |
| [`system_color`](/slides/python-net/ja/aspose.slides/colorformat/system_color/) | システム カラーテーブルで識別される色を取得または設定します。<br/>            読み書き [`SystemColor`](/slides/python-net/ja/aspose.slides/systemcolor)。 |
| [`scheme_color`](/slides/python-net/ja/aspose.slides/colorformat/scheme_color/) | カラースキームで識別される色を取得または設定します。<br/>            読み書き [`SchemeColor`](/slides/python-net/ja/aspose.slides/schemecolor)。 |
| [`r`](/slides/python-net/ja/aspose.slides/colorformat/r/) | 色の赤成分を取得または設定します。すべての色変換は無視されます。<br/>            読み書き **int**。 |
| [`g`](/slides/python-net/ja/aspose.slides/colorformat/g/) | 色の緑成分を取得または設定します。すべての色変換は無視されます。 |
| [`b`](/slides/python-net/ja/aspose.slides/colorformat/b/) | 色の青成分を取得または設定します。すべての色変換は無視されます。<br/>            読み書き **int**。 |
| [`float_r`](/slides/python-net/ja/aspose.slides/colorformat/float_r/) | 色の赤成分を取得または設定します。すべての色変換は無視されます。<br/>            読み書き **float**。 |
| [`float_g`](/slides/python-net/ja/aspose.slides/colorformat/float_g/) | 色の緑成分を取得または設定します。すべての色変換は無視されます。<br/>            読み書き **float**。 |
| [`float_b`](/slides/python-net/ja/aspose.slides/colorformat/float_b/) | 色の青成分を取得または設定します。すべての色変換は無視されます。<br/>            読み書き **float**。 |
| [`hue`](/slides/python-net/ja/aspose.slides/colorformat/hue/) | HSL 表現の色相成分を取得または設定します。すべての色変換は無視されます。<br/>            読み書き **float**。 |
| [`saturation`](/slides/python-net/ja/aspose.slides/colorformat/saturation/) | HSL 表現の彩度成分を取得または設定します。すべての色変換は無視されます。<br/>            読み書き **float**。 |
| [`luminance`](/slides/python-net/ja/aspose.slides/colorformat/luminance/) | HSL 表現の輝度成分を取得または設定します。すべての色変換は無視されます。<br/>            読み書き **float**。 |
| [`color_transform`](/slides/python-net/ja/aspose.slides/colorformat/color_transform/) | 色に適用された色変換のコレクションを取得します。<br/>            読み取り専用 [`IColorOperationCollection`](/slides/python-net/ja/aspose.slides/icoloroperationcollection)。 |
| [`slide`](/slides/python-net/ja/aspose.slides/colorformat/slide/) |  |
| [`presentation`](/slides/python-net/ja/aspose.slides/colorformat/presentation/) |  |
