## SlideSize クラス

スライドのサイズと向きを表します。

SlideSize 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`size`](/slides/python-net/ja/aspose.slides/slidesize/size/) | スライドの寸法をポイント単位で取得します。 |
| [`type`](/slides/python-net/ja/aspose.slides/slidesize/type/) | スライド サイズの種類を取得します。 |
| [`orientation`](/slides/python-net/ja/aspose.slides/slidesize/orientation/) | スライドの向きを取得または設定します。 |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`set_size(self, type, scale_type)`](/slides/python-net/ja/aspose.slides/slidesize/set_size/#slidesizetype-slidesizescaletype) | 種類でスライドサイズを設定し、既存のコンテンツをスケーリングします。 |
| [`set_size(self, width, height, scale_type)`](/slides/python-net/ja/aspose.slides/slidesize/set_size/#float-float-slidesizescaletype) | スライドの寸法を明示的に設定し、既存のコンテンツをスケーリングします。 |
