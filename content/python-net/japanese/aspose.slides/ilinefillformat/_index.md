## ILineFillFormat クラス

線の塗りつぶしプロパティを表します。

ILineFillFormat 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`fill_type`](/slides/python-net/ja/aspose.slides/ilinefillformat/fill_type/) | 塗りタイプを取得または設定します。<br/>            読み書き [`FillType`](/slides/python-net/ja/aspose.slides/filltype)。 |
| [`solid_fill_color`](/slides/python-net/ja/aspose.slides/ilinefillformat/solid_fill_color/) | 単色の塗りつぶしの色を取得します。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat)。 |
| [`gradient_format`](/slides/python-net/ja/aspose.slides/ilinefillformat/gradient_format/) | グラデーション塗りつぶしフォーマットを取得します。<br/>            読み取り専用 [`IGradientFormat`](/slides/python-net/ja/aspose.slides/igradientformat)。 |
| [`pattern_format`](/slides/python-net/ja/aspose.slides/ilinefillformat/pattern_format/) | パターン塗りつぶしフォーマットを取得します。<br/>            読み取り専用 [`IPatternFormat`](/slides/python-net/ja/aspose.slides/ipatternformat)。 |
| [`rotate_with_shape`](/slides/python-net/ja/aspose.slides/ilinefillformat/rotate_with_shape/) | 塗りがシェイプとともに回転すべきかどうかを決定します。<br/>            読み書き [`NullableBool`](/slides/python-net/ja/aspose.slides/nullablebool)。 |
