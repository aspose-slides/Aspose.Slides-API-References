## IFillFormatEffectiveData クラス

有効な塗りつぶし書式プロパティを含むイミュータブルオブジェクトです。

IFillFormatEffectiveData 型は次のメンバーを公開します。

## プロパティ

| Property | Description |
| :- | :- |
| [`fill_type`](/slides/python-net/ja/aspose.slides/ifillformateffectivedata/fill_type/) | 塗りつぶしのタイプを返します。<br/>            読み取り専用 [`FillType`](/slides/python-net/ja/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/ja/aspose.slides/ifillformateffectivedata/solid_fill_color/) | 塗りつぶしのカラーを返します。<br/>            読み取り専用 **aspose.slides.Color**. |
| [`solid_fill_scheme_color`](/slides/python-net/ja/aspose.slides/ifillformateffectivedata/solid_fill_scheme_color/) | カラースキームで定義された塗りつぶしカラーを取得します。<br/>            [`SchemeColor.NOT_DEFINED`](/slides/python-net/ja/aspose.slides/schemecolor/NOT_DEFINED) の値は、[`IFillFormatEffectiveData.solid_fill_color`](/slides/python-net/ja/aspose.slides/ifillformateffectivedata/solid_fill_color) <br/> がスキームカラーではないことを示します。<br/>            読み取り専用 [`SchemeColor`](/slides/python-net/ja/aspose.slides/schemecolor). |
| [`gradient_format`](/slides/python-net/ja/aspose.slides/ifillformateffectivedata/gradient_format/) | グラデーション塗りつぶし形式を返します。<br/>            読み取り専用 [`IGradientFormatEffectiveData`](/slides/python-net/ja/aspose.slides/igradientformateffectivedata). |
| [`pattern_format`](/slides/python-net/ja/aspose.slides/ifillformateffectivedata/pattern_format/) | パターン塗りつぶし形式を返します。<br/>            読み取り専用 [`IPatternFormatEffectiveData`](/slides/python-net/ja/aspose.slides/ipatternformateffectivedata). |
| [`picture_fill_format`](/slides/python-net/ja/aspose.slides/ifillformateffectivedata/picture_fill_format/) | 画像塗りつぶし形式を返します。<br/>            読み取り専用 [`IPictureFillFormatEffectiveData`](/slides/python-net/ja/aspose.slides/ipicturefillformateffectivedata). |
| [`rotate_with_shape`](/slides/python-net/ja/aspose.slides/ifillformateffectivedata/rotate_with_shape/) | 塗りつぶしがシェイプとともに回転すべきかどうかを決定します。<br/>            読み取り専用 **bool**. |


### 備考

[`IFillFormat`](/slides/python-net/ja/aspose.slides/ifillformat) インターフェイスと共に使用され、継承が適用された有効な書式値を返します。
