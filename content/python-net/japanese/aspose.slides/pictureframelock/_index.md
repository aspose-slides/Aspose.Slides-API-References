## PictureFrameLock クラス

親 PictureFrame で無効になる操作を決定します。

**継承:**[`PictureFrameLock`](/slides/python-net/ja/aspose.slides/pictureframelock) → [`BaseShapeLock`](/slides/python-net/ja/aspose.slides/baseshapelock)

PictureFrameLock 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`no_locks`](/slides/python-net/ja/aspose.slides/pictureframelock/no_locks/) | すべてのロックフラグが無効な場合に true を返します。<br/>            読み取り専用 **bool**. |
| [`grouping_locked`](/slides/python-net/ja/aspose.slides/pictureframelock/grouping_locked/) | このシェイプをグループに追加することが禁止されているかどうかを決定します。<br/>            読み書き **bool**. |
| [`select_locked`](/slides/python-net/ja/aspose.slides/pictureframelock/select_locked/) | このシェイプの選択が禁止されているかどうかを決定します。<br/>            読み書き **bool**. |
| [`rotation_locked`](/slides/python-net/ja/aspose.slides/pictureframelock/rotation_locked/) | このシェイプの回転角度の変更が禁止されているかどうかを決定します。<br/>            読み書き **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/ja/aspose.slides/pictureframelock/aspect_ratio_locked/) | リサイズ時にシェイプがアスペクト比を保持する必要があるかどうかを決定します。<br/>            読み書き **bool**. |
| [`position_locked`](/slides/python-net/ja/aspose.slides/pictureframelock/position_locked/) | このシェイプの移動が禁止されているかどうかを決定します。<br/>            読み書き **bool**. |
| [`size_locked`](/slides/python-net/ja/aspose.slides/pictureframelock/size_locked/) | このシェイプのサイズ変更が禁止されているかどうかを決定します。<br/>            読み書き **bool**. |
| [`edit_points_locked`](/slides/python-net/ja/aspose.slides/pictureframelock/edit_points_locked/) | このシェイプの輪郭の直接変更が禁止されているかどうかを決定します。<br/>            読み書き **bool**. |
| [`adjust_handles_locked`](/slides/python-net/ja/aspose.slides/pictureframelock/adjust_handles_locked/) | 調整値の変更が禁止されているかどうかを決定します。<br/>            読み書き **bool**. |
| [`arrowheads_locked`](/slides/python-net/ja/aspose.slides/pictureframelock/arrowheads_locked/) | 矢印ヘッドの変更が禁止されているかどうかを決定します。<br/>            読み書き **bool**. |
| [`shape_type_locked`](/slides/python-net/ja/aspose.slides/pictureframelock/shape_type_locked/) | シェイプタイプの変更が禁止されているかどうかを決定します。<br/>            読み書き **bool**. |
| [`crop_locked`](/slides/python-net/ja/aspose.slides/pictureframelock/crop_locked/) | 画像のトリミングが禁止されているかどうかを決定します。<br/>            読み書き **bool**. |
