## IGradientFormat クラス

グラデーション フォーマットを表します。

IGradientFormat 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`tile_flip`](/slides/python-net/ja/aspose.slides/igradientformat/tile_flip/) | グラデーションのフリップモードを取得または設定します。<br/>            読み書き [`TileFlip`](/slides/python-net/ja/aspose.slides/tileflip). |
| [`gradient_direction`](/slides/python-net/ja/aspose.slides/igradientformat/gradient_direction/) | グラデーションのスタイルを取得または設定します。<br/>            読み書き [`GradientDirection`](/slides/python-net/ja/aspose.slides/gradientdirection). |
| [`linear_gradient_angle`](/slides/python-net/ja/aspose.slides/igradientformat/linear_gradient_angle/) | グラデーションの角度を取得または設定します。<br/>            読み書き **float**. |
| [`linear_gradient_scaled`](/slides/python-net/ja/aspose.slides/igradientformat/linear_gradient_scaled/) | グラデーションがスケールされるかどうかを判断します。<br/>            読み書き [`NullableBool`](/slides/python-net/ja/aspose.slides/nullablebool). |
| [`gradient_shape`](/slides/python-net/ja/aspose.slides/igradientformat/gradient_shape/) | グラデーションの形状を取得または設定します。<br/>            読み書き [`GradientShape`](/slides/python-net/ja/aspose.slides/gradientshape). |
| [`gradient_stops`](/slides/python-net/ja/aspose.slides/igradientformat/gradient_stops/) | グラデーション ストップのコレクションを取得します。<br/>            読み取り専用 [`IGradientStopCollection`](/slides/python-net/ja/aspose.slides/igradientstopcollection). |
