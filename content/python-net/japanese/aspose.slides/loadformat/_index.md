## LoadFormat 列挙

ロードされるドキュメントの形式を示します。

LoadFormat 型は以下のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| AUTO | Aspose.Slides に対し、形式を自動的に認識するよう指示します。 |
| PPT | Microsoft PowerPoint 97-2003 プレゼンテーション。 |
| PPS | Microsoft PowerPoint 97-2003 スライドショー。 |
| PPTX | Microsoft Office Open XML PresentationML ドキュメント。 |
| PPSX | Microsoft Office Open XML PresentationML スライドショー。 |
| ODP | OpenOffice ODF プレゼンテーション。 |
| POTX | Microsoft Office Open XML PresentationML テンプレート。 |
| PPTM | Microsoft Office Open XML PresentationML マクロ有効ドキュメント。 |
| PPSM | Microsoft Office Open XML PresentationML マクロ有効スライドショー。 |
| POTM | Microsoft Office Open XML PresentationML マクロ有効テンプレート。 |
| OTP | OpenOffice OTP プレゼンテーションテンプレート。 |
| PPT95 | Microsoft PowerPoint 95 プレゼンテーション。 |
| POT | Microsoft PowerPoint 97-2003 プレゼンテーションテンプレート。 |
| FODP | Flat XML ODF プレゼンテーション。 |
| UNKNOWN | 不明なファイル形式 |
