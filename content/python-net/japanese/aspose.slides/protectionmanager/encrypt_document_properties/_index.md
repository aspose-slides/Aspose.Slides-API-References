## encrypt_document_properties プロパティ
このプロパティは、プレゼンテーションがパスワードで保護されている場合に意味があります。
            true の場合、ドキュメントのプロパティはプレゼンテーションファイル内で暗号化されます。
            false の場合、ドキュメントのプロパティは公開されますが、プレゼンテーションは暗号化されます。
            読み取り/書き込み **bool**。
