## AdjustValue クラス

ジオメトリ形状の調整値を表します。  
これらの値は形状の形状に影響します。

AdjustValue 型は次のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`raw_value`](/slides/python-net/ja/aspose.slides/adjustvalue/raw_value/) | 読み取り/書き込み可能な調整値を「そのまま」返すか設定します。<br/>            Read/write **int**. |
| [`angle_value`](/slides/python-net/ja/aspose.slides/adjustvalue/angle_value/) | 角度（度）として解釈し、値を返すまたは設定します。<br/>            Read/write **float**. |
| [`name`](/slides/python-net/ja/aspose.slides/adjustvalue/name/) | この調整値の名前を返します。<br/>            Read-only **str**. |
| [`type`](/slides/python-net/ja/aspose.slides/adjustvalue/type/) | 形状調整のタイプを返します。<br/>            Read-only [`ShapeAdjustmentType`](/slides/python-net/ja/aspose.slides/shapeadjustmenttype). |
