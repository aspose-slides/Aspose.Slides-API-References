## NumberedBulletStyle 列挙型

番号付き箇条書きのスタイルを表します。

NumberedBulletStyle 型は次のメンバーを公開します。

## フィールド

| Field | Description |
| :- | :- |
| NOT_DEFINED | 未定義です。 |
| BULLET_ALPHA_LC_PERIOD | 句点付きの小文字アルファベット文字。Sample: a., b., c., ... |
| BULLET_ALPHA_UC_PERIOD | 句点付きの大文字アルファベット文字。Sample: A., B., C., ... |
| BULLET_ARABIC_PAREN_RIGHT | 閉じ括弧付きのアラビア数字。Sample: 1), 2), 3), ... |
| BULLET_ARABIC_PERIOD | 句点付きのアラビア数字。Sample: 1., 2., 3., ... |
| BULLET_ROMAN_LC_PAREN_BOTH | 両側括弧付きの小文字ローマ数字。Sample: (i), (ii), (iii), ... |
| BULLET_ROMAN_LC_PAREN_RIGHT | 閉じ括弧付きの小文字ローマ数字。Sample: i), ii), iii), ... |
| BULLET_ROMAN_LC_PERIOD | 句点付きの小文字ローマ数字。Sample: i., ii., iii., ... |
| BULLET_ROMAN_UC_PERIOD | 句点付きの大文字ローマ数字。Sample: I., II., III., ... |
| BULLET_ALPHA_LC_PAREN_BOTH | 両側括弧付きの小文字アルファベット文字。Sample: (a), (b), (c), ... |
| BULLET_ALPHA_LC_PAREN_RIGHT | 閉じ括弧付きの小文字アルファベット文字。Sample: a), b), c), ... |
| BULLET_ALPHA_UC_PAREN_BOTH | 両側括弧付きの大文字アルファベット文字。Sample: (A), (B), (C), ... |
| BULLET_ALPHA_UC_PAREN_RIGHT | 閉じ括弧付きの大文字アルファベット文字。Sample: A), B), C), ... |
| BULLET_ARABIC_PAREN_BOTH | 両側括弧付きのアラビア数字。Sample: (1), (2), (3), ... |
| BULLET_ARABIC_PLAIN | アラビア数字。Sample: 1, 2, 3, ... |
| BULLET_ROMAN_UC_PAREN_BOTH | 両側括弧付きの大文字ローマ数字。Sample: (I), (II), (III), ... |
| BULLET_ROMAN_UC_PAREN_RIGHT | 閉じ括弧付きの大文字ローマ数字。Sample: I), II), III), ... |
| BULLET_SIMP_CHIN_PLAIN | 句点なしの簡体字中国語。 |
| BULLET_SIMP_CHIN_PERIOD | 句点付きの簡体字中国語。 |
| BULLET_CIRCLE_NUM_DB_PLAIN | 10までの二重バイト円形数字、11以降はアラビア数字。 |
| BULLET_CIRCLE_NUM_WD_WHITE_PLAIN | 文字色と同じ色の円で囲んだ番号（Wingdings白円番号）。11以降はアラビア数字。 |
| BULLET_CIRCLE_NUM_WD_BLACK_PLAIN | 通常の文字色の円形背景を持つ影色番号（Wingdings黒円番号）。 |
| BULLET_TRAD_CHIN_PLAIN | 句点なしの繁体字中国語。 |
| BULLET_TRAD_CHIN_PERIOD | 句点付きの繁体字中国語。 |
| BULLET_ARABIC_ALPHA_DASH | ハイフン付きのアラビア語アルファベット文字。 |
| BULLET_ARABIC_ABJAD_DASH | ハイフン付きのアラビア語アブジャド文字。 |
| BULLET_HEBREW_ALPHA_DASH | ハイフン付きのヘブライ語アルファベット文字。 |
| BULLET_KANJI_KOREAN_PLAIN | 句点なしの日本語/韓国語数字。 |
| BULLET_KANJI_KOREAN_PERIOD | 句点付きの日本語/韓国語数字。 |
| BULLET_ARABIC_DB_PLAIN | 句読点なしの二重バイトアラビア数字方式。 |
| BULLET_ARABIC_DB_PERIOD | 二重バイト句点付きの二重バイトアラビア数字方式。 |
| BULLET_THAI_ALPHA_PERIOD | タイ文字の句点。 |
| BULLET_THAI_ALPHA_PAREN_RIGHT | タイ文字の右側括弧。 |
| BULLET_THAI_ALPHA_PAREN_BOTH | タイ文字の両側括弧。 |
| BULLET_THAI_NUM_PERIOD | タイ数字の句点。 |
| BULLET_THAI_NUM_PAREN_RIGHT | タイ数字の右側括弧。 |
| BULLET_THAI_NUM_PAREN_BOTH | タイ数字の両側括弧。 |
| BULLET_HINDI_ALPHA_PERIOD | ヒンディー語の母音の句点。 |
| BULLET_HINDI_NUM_PERIOD | ヒンディー語数字の句点。 |
| BULLET_KANJI_SIMP_CHIN_DB_PERIOD | 漢字簡体字の二重バイト句点。 |
| BULLET_HINDI_NUM_PAREN_RIGHT | ヒンディー語数字の右側括弧。 |
| BULLET_HINDI_ALPHA_1_PERIOD | ヒンディー語の子音の句点。 |
