## IPlaceholder クラス

プレースホルダーを表します。

IPlaceholder 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`orientation`](/slides/python-net/ja/aspose.slides/iplaceholder/orientation/) | プレースホルダーの向きを取得します。<br/>            読み取り専用 [`Orientation`](/slides/python-net/ja/aspose.slides/orientation). |
| [`size`](/slides/python-net/ja/aspose.slides/iplaceholder/size/) | プレースホルダーのサイズを取得します。<br/>            読み取り専用 [`PlaceholderSize`](/slides/python-net/ja/aspose.slides/placeholdersize). |
| [`type`](/slides/python-net/ja/aspose.slides/iplaceholder/type/) | プレースホルダーの種類を取得します。<br/>            読み取り専用 [`PlaceholderType`](/slides/python-net/ja/aspose.slides/placeholdertype). |
| [`index`](/slides/python-net/ja/aspose.slides/iplaceholder/index/) | プレースホルダーのインデックスを取得します。<br/>            読み取り専用 **int**. |
