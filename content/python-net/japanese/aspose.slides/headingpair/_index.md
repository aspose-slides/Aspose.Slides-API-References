## HeadingPair クラス

文書の 'Heading pair' プロパティを表します。  
文書部分のグループ名とグループ内の部分数を示します。

HeadingPair 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`name`](/slides/python-net/ja/aspose.slides/headingpair/name/) | 文書部分のグループ名を返します。<br/> 読み取り専用 **str**. |
| [`count`](/slides/python-net/ja/aspose.slides/headingpair/count/) | グループ内の部分数を返します。<br/> 読み取り専用 **int**. |
