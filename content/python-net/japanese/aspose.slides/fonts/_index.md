## Fonts クラス

Fonts コレクション。

Fonts タイプは次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`latin_font`](/slides/python-net/ja/aspose.slides/fonts/latin_font/) | Latin フォントを取得または設定します。<br/>            読み取り/書き込み [`IFontData`](/slides/python-net/ja/aspose.slides/ifontdata). |
| [`east_asian_font`](/slides/python-net/ja/aspose.slides/fonts/east_asian_font/) | East Asian フォントを取得または設定します。<br/>            読み取り/書き込み [`IFontData`](/slides/python-net/ja/aspose.slides/ifontdata). |
| [`complex_script_font`](/slides/python-net/ja/aspose.slides/fonts/complex_script_font/) | complex script フォントを取得または設定します。<br/>            読み取り/書き込み [`IFontData`](/slides/python-net/ja/aspose.slides/ifontdata). |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`get_script_font_map(self)`](/slides/python-net/ja/aspose.slides/fonts/get_script_font_map/#) | プレゼンテーション内のすべての文字列-文字列ペアのスクリプトフォント定義のリストを返します。 |
| [`get_script_font(self, script)`](/slides/python-net/ja/aspose.slides/fonts/get_script_font/#str) | プレゼンテーションテーマから特定のスクリプトタグに関連付けられたフォント名を取得します。 |
| [`set_script_font(self, script, font_name)`](/slides/python-net/ja/aspose.slides/fonts/set_script_font/#str-str) | 特定のスクリプトタグにフォント名を割り当てます。これにより、そのスクリプトのテキストがプレゼンテーションでどのようにレンダリングされるかが決まります。 |
| [`remove_script_font(self, script)`](/slides/python-net/ja/aspose.slides/fonts/remove_script_font/#str) | テーマのフォントコレクションから特定のスクリプトタグに関連付けられたフォント設定を削除します。 |
