## SplitterBarStateType 列挙体

スプリッターバーが表示される状態を指定します。スプリッターバーは、表示領域内のプライマリ領域とセカンダリ領域を分割します。

SplitterBarStateType 型は次のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| MINIMIZED | プライマリ領域は、アプリケーションが許可する表示領域の最小量を占めます。 |
| RESTORED | プライマリ領域は、特定の中間サイズを持ちます。 |
| MAXIMIZED | プライマリ領域は、アプリケーションが許可する表示領域の最大量を占めます。 |
