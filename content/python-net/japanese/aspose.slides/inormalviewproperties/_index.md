## INormalViewProperties クラス

通常ビューのプロパティを表します。通常ビューは、スライド自体、サイドコンテンツ領域、下部コンテンツ領域の 3つのコンテンツ領域で構成されます。

INormalViewProperties 型は以下のメンバーを公開します：

## プロパティ

| Property | Description |
| :- | :- |
| [`show_outline_icons`](/slides/python-net/ja/aspose.slides/inormalviewproperties/show_outline_icons/) | アプリケーションが通常ビュー モードのコンテンツ領域のいずれかでアウトライン コンテンツを表示する場合に、アイコンを表示するかどうかを指定します。<br/>            読み取り/書き込み **bool**。 |
| [`snap_vertical_splitter`](/slides/python-net/ja/aspose.slides/inormalviewproperties/snap_vertical_splitter/) | サイド領域が十分に小さい場合に、垂直スプリッタが最小化状態にスナップするかどうかを指定します。<br/>            読み取り/書き込み **bool**。 |
| [`vertical_bar_state`](/slides/python-net/ja/aspose.slides/inormalviewproperties/vertical_bar_state/) | 垂直スプリッタ バーが表示される状態を指定します。<br/>            垂直スプリッタ バーは、スライドとサイド コンテンツ領域を分割します。 |
| [`horizontal_bar_state`](/slides/python-net/ja/aspose.slides/inormalviewproperties/horizontal_bar_state/) | 水平スプリッタ バーが表示される状態を指定します。<br/>            水平スプリッタ バーは、スライドとスライド下のコンテンツ領域を分割します。 |
| [`prefer_single_view`](/slides/python-net/ja/aspose.slides/inormalviewproperties/prefer_single_view/) | ユーザーが、3つのコンテンツ領域を持つ標準の通常ビューではなく、全ウィンドウ単一コンテンツ領域を表示することを好むかどうかを指定します。有効にすると、アプリケーションはコンテンツ領域のいずれかをウィンドウ全体に表示することを選択できる場合があります。<br/>            読み取り/書き込み **bool**。 |
| [`restored_left`](/slides/python-net/ja/aspose.slides/inormalviewproperties/restored_left/) | この要素は、領域が可変の復元サイズ（最小化も最大化もされていない）である場合の、通常ビューのサイド コンテンツ領域のサイズ設定を指定します。<br/>            読み取り専用 [`INormalViewRestoredProperties`](/slides/python-net/ja/aspose.slides/inormalviewrestoredproperties)。 |
| [`restored_top`](/slides/python-net/ja/aspose.slides/inormalviewproperties/restored_top/) | この要素は、領域が可変の復元サイズ（最小化も最大化もされていない）である場合の、通常ビューのトップ スライド領域のサイズ設定を指定します。<br/>            読み取り専用 [`INormalViewRestoredProperties`](/slides/python-net/ja/aspose.slides/inormalviewrestoredproperties)。 |
