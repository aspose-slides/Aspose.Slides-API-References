## remove(self, item) {#iportion}
特定のオブジェクトの最初の出現を **System.Collections.Generic.ICollection`1** から削除します。

### 戻り値

`item` が **System.Collections.Generic.ICollection`1** から正常に削除された場合は true、そうでなければ false を返します。また、元の **System.Collections.Generic.ICollection`1** に `item` が見つからない場合も false を返します。



```python
def remove(self, item):
    ...
```


| パラメーター | 型 | 説明 |
| :- | :- | :- |
| item | [`IPortion`](/slides/python-net/ja/aspose.slides/iportion) | **System.Collections.Generic.ICollection`1** から削除するオブジェクトです。 |

### 例外

| 例外 | 説明 |
| :- | :- |
| **RuntimeError(Proxy error(NotSupportedException))** | **System.Collections.Generic.ICollection`1** は読み取り専用です。 |
