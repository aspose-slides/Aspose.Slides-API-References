## FontsLoader クラス

ユーザーが定義したカスタムフォントをロードするためのクラスです。  
プレゼンテーションオブジェクトを作成する前に使用する必要があります。

FontsLoader 型は次のメンバーを公開します。

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`load_external_fonts(directories)`](/slides/python-net/ja/aspose.slides/fontsloader/load_external_fonts/#liststr) | フォントを検索するための追加フォルダーを追加します。 |
| [`load_external_font(data)`](/slides/python-net/ja/aspose.slides/fontsloader/load_external_font/#bytes) | バイナリデータからフォントを追加します。 |
| [`get_font_folders()`](/slides/python-net/ja/aspose.slides/fontsloader/get_font_folders/#) | フォントフォルダーを取得します。LoadExternalFonts メソッドで追加されたフォルダーとシステムフォントフォルダーを返します。 |
| [`clear_cache()`](/slides/python-net/ja/aspose.slides/fontsloader/clear_cache/#) | ユーザーが定義したすべてのカスタムフォントを解放します。 |
