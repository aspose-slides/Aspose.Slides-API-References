## ViewProperties クラス

プレゼンテーション全体のビュー プロパティ。

ViewProperties 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`last_view`](/slides/python-net/ja/aspose.slides/viewproperties/last_view/) | プレゼンテーション ドキュメントが最後に保存されたときに使用されたビュー モードを指定します。<br/>            読み書き可能 [`ViewType`](/slides/python-net/ja/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/ja/aspose.slides/viewproperties/show_comments/) | スライド コメントを表示するかどうかを指定します。<br/>            読み書き可能 [`NullableBool`](/slides/python-net/ja/aspose.slides/nullablebool). |
| [`normal_view_properties`](/slides/python-net/ja/aspose.slides/viewproperties/normal_view_properties/) | 通常ビューのプロパティを表します。通常ビューは<br/>            3 つのコンテンツ領域で構成されます：スライド自体、サイド コンテンツ領域、そして下部コンテンツ領域。<br/>            読み取り専用 [`INormalViewProperties`](/slides/python-net/ja/aspose.slides/inormalviewproperties). |
| [`slide_view_properties`](/slides/python-net/ja/aspose.slides/viewproperties/slide_view_properties/) | スライド ビュー モードに関連付けられた共通ビュー プロパティを指定します。<br/>            読み取り専用 [`ICommonSlideViewProperties`](/slides/python-net/ja/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/ja/aspose.slides/viewproperties/notes_view_properties/) | ノート ビュー モードに関連付けられた共通ビュー プロパティを指定します。<br/>            読み取り専用 [`ICommonSlideViewProperties`](/slides/python-net/ja/aspose.slides/icommonslideviewproperties). |
| [`grid_spacing`](/slides/python-net/ja/aspose.slides/viewproperties/grid_spacing/) | プレゼンテーション ドキュメントの基礎となるグリッドの間隔をポイント単位で取得または設定します。 <br/>            読み書き可能 **float**. |
