## IColorOperation クラス

カラー変換に使用されるさまざまなカラー操作を表します。

IColorOperation 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`operation_type`](/slides/python-net/ja/aspose.slides/icoloroperation/operation_type/) | 操作のタイプを取得または設定します。<br/>            読み取り専用 [`ColorTransformOperation`](/slides/python-net/ja/aspose.slides/colortransformoperation)。 |
| [`parameter`](/slides/python-net/ja/aspose.slides/icoloroperation/parameter/) | 操作のパラメータを取得します。<br/>            読み取り専用 **float**。 |
