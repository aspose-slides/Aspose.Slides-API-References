## ILightRigEffectiveData クラス

有効なライトリグプロパティを含む不変オブジェクトです。

ILightRigEffectiveData 型は以下のメンバーを公開します：

## プロパティ

| Property | Description |
| :- | :- |
| [`direction`](/slides/python-net/ja/aspose.slides/ilightrigeffectivedata/direction/) | 光の方向。<br/>            読み取り専用 [`LightingDirection`](/slides/python-net/ja/aspose.slides/lightingdirection). |
| [`light_type`](/slides/python-net/ja/aspose.slides/ilightrigeffectivedata/light_type/) | シェイプに適用できるプリセット光源を表します。 <br/>            ライトリグは、3Dシーンに対して特定の方向に配置されたライトのグループを表します。<br/>            読み取り専用 [`LightRigPresetType`](/slides/python-net/ja/aspose.slides/lightrigpresettype). |

## メソッド

| Method | Description |
| :- | :- |
| [`get_rotation(self)`](/slides/python-net/ja/aspose.slides/ilightrigeffectivedata/get_rotation/#) | 緯度座標、経度座標、および軸周りの回転を使用して回転が定義されます。<br/>            返却配列の最初の要素は緯度、2番目は経度、3番目は回転です。 |

### 備考

このインターフェイスは [`IThreeDFormatEffectiveData`](/slides/python-net/ja/aspose.slides/ithreedformateffectivedata) の一部として使用されます。
