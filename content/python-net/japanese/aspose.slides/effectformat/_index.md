## EffectFormat クラス

シェイプの効果プロパティを表します。

**継承:**[`EffectFormat`](/slides/python-net/ja/aspose.slides/effectformat) → [`PVIObject`](/slides/python-net/ja/aspose.slides/pviobject)

EffectFormat 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`is_no_effects`](/slides/python-net/ja/aspose.slides/effectformat/is_no_effects/) | すべてのエフェクトが無効になっている場合に true を返します（作成直後のデフォルト EffectFormat オブジェクトとして）。<br/>読み取り専用 **bool**。 |
| [`blur_effect`](/slides/python-net/ja/aspose.slides/effectformat/blur_effect/) | ぼかしエフェクト。<br/>読み取り/書き込み [`IBlur`](/slides/python-net/ja/aspose.slides.effects/iblur)。 |
| [`fill_overlay_effect`](/slides/python-net/ja/aspose.slides/effectformat/fill_overlay_effect/) | 塗りつぶしオーバーレイエフェクト。<br/>読み取り/書き込み [`IFillOverlay`](/slides/python-net/ja/aspose.slides.effects/ifilloverlay)。 |
| [`glow_effect`](/slides/python-net/ja/aspose.slides/effectformat/glow_effect/) | グロウエフェクト。<br/>読み取り/書き込み [`IGlow`](/slides/python-net/ja/aspose.slides.effects/iglow)。 |
| [`inner_shadow_effect`](/slides/python-net/ja/aspose.slides/effectformat/inner_shadow_effect/) | インナーシャドウ。<br/>読み取り/書き込み [`IInnerShadow`](/slides/python-net/ja/aspose.slides.effects/iinnershadow)。 |
| [`outer_shadow_effect`](/slides/python-net/ja/aspose.slides/effectformat/outer_shadow_effect/) | 外部シャドウ。<br/>読み取り/書き込み [`IOuterShadow`](/slides/python-net/ja/aspose.slides.effects/ioutershadow)。 |
| [`preset_shadow_effect`](/slides/python-net/ja/aspose.slides/effectformat/preset_shadow_effect/) | プリセットシャドウ。<br/>読み取り/書き込み [`IPresetShadow`](/slides/python-net/ja/aspose.slides.effects/ipresetshadow)。 |
| [`reflection_effect`](/slides/python-net/ja/aspose.slides/effectformat/reflection_effect/) | リフレクション。 <br/>読み取り/書き込み [`IReflection`](/slides/python-net/ja/aspose.slides.effects/ireflection)。 |
| [`soft_edge_effect`](/slides/python-net/ja/aspose.slides/effectformat/soft_edge_effect/) | ソフトエッジ。<br/>読み取り/書き込み [`ISoftEdge`](/slides/python-net/ja/aspose.slides.effects/isoftedge)。 |
| [`slide`](/slides/python-net/ja/aspose.slides/effectformat/slide/) |  |
| [`presentation`](/slides/python-net/ja/aspose.slides/effectformat/presentation/) |  |
