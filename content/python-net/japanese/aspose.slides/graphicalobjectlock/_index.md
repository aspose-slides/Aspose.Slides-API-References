## GraphicalObjectLock クラス

親 GraphicalObject で無効化されている操作を決定します。

**継承:**[`GraphicalObjectLock`](/slides/python-net/ja/aspose.slides/graphicalobjectlock) → [`BaseShapeLock`](/slides/python-net/ja/aspose.slides/baseshapelock)

GraphicalObjectLock 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`no_locks`](/slides/python-net/ja/aspose.slides/graphicalobjectlock/no_locks/) | すべてのロックフラグが無効な場合に true を返します。<br/>            読み取り専用 **bool**. |
| [`grouping_locked`](/slides/python-net/ja/aspose.slides/graphicalobjectlock/grouping_locked/) | このシェイプをグループに追加することが禁止されているかどうかを決定します。<br/>            読み書き **bool**. |
| [`drilldown_locked`](/slides/python-net/ja/aspose.slides/graphicalobjectlock/drilldown_locked/) | このオブジェクトのサブシェイプの選択が禁止されているかどうかを決定します。<br/>            読み書き **bool**. |
| [`select_locked`](/slides/python-net/ja/aspose.slides/graphicalobjectlock/select_locked/) | このシェイプの選択が禁止されているかどうかを決定します。<br/>            読み書き **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/ja/aspose.slides/graphicalobjectlock/aspect_ratio_locked/) | リサイズ時にシェイプがアスペクト比を維持しなければならないかどうかを決定します。<br/>            読み書き **bool**. |
| [`position_locked`](/slides/python-net/ja/aspose.slides/graphicalobjectlock/position_locked/) | このシェイプの移動が禁止されているかどうかを決定します。<br/>            読み書き **bool**. |
| [`size_locked`](/slides/python-net/ja/aspose.slides/graphicalobjectlock/size_locked/) | このシェイプのリサイズが禁止されているかどうかを決定します。<br/>            読み書き **bool**. |
