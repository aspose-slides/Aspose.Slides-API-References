## TextAutofitType 列挙型

テキストの自動調整モードを表します。

TextAutofitType 型は次のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| NOT_DEFINED | 定義されていません。 |
| NONE | 自動調整なし。 |
| NORMAL | 標準の自動調整。フォントサイズと行間が形状に合わせて縮小されます。 |
| SHAPE | 形状の自動調整。テキストに合わせて形状のサイズが変更されます。 |
