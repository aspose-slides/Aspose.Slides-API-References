## CommonSlideViewProperties クラス

共通スライドビュー プロパティを表します。

CommonSlideViewProperties 型は以下のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`scale`](/slides/python-net/ja/aspose.slides/commonslideviewproperties/scale/) | ビューの拡大縮小率をパーセンテージで指定します。<br/>            読み取り/書き込み **int**. |
| [`variable_scale`](/slides/python-net/ja/aspose.slides/commonslideviewproperties/variable_scale/) | ビュー コンテンツが現在のウィンドウサイズに最適に合わせて自動的に拡大縮小されるように指定します。<br/>            読み取り/書き込み **bool**. |
| [`drawing_guides`](/slides/python-net/ja/aspose.slides/commonslideviewproperties/drawing_guides/) | 描画ガイドのコレクションを返します。<br/>            読み取り専用 [`IDrawingGuidesCollection`](/slides/python-net/ja/aspose.slides/idrawingguidescollection) |
