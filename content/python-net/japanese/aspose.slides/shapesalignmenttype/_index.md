## ShapesAlignmentType 列挙型

選択されたシェイプのスライド上での配置を変更する方法を定義します。

ShapesAlignmentType 型は次のメンバーを公開します：

## フィールド

| フィールド | 説明 |
| :- | :- |
| ALIGN_LEFT | 左揃え |
| ALIGN_RIGHT | 右揃え |
| ALIGN_CENTER | 中央揃え |
| ALIGN_TOP | 上揃え |
| ALIGN_MIDDLE | 中央揃え |
| ALIGN_BOTTOM | 下揃え |
| DISTRIBUTE_HORIZONTALLY | 水平に分布 |
| DISTRIBUTE_VERTICALLY | 垂直に分布 |
