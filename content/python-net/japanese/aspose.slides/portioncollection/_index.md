## PortionCollection クラス

コレクションの部分を表します。

PortionCollection 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`count`](/slides/python-net/ja/aspose.slides/portioncollection/count/) | コレクションに実際に含まれる要素の数を取得します。<br/>            読み取り専用 **int**. |
| [`is_read_only`](/slides/python-net/ja/aspose.slides/portioncollection/is_read_only/) | **System.Collections.Generic.ICollection`1** が読み取り専用かどうかを示す値を取得します。<br/>            読み取り専用 **bool**. |

指定されたインデックスの要素を取得します。
