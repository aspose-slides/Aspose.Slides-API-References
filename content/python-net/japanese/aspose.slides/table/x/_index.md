## x プロパティ
シェイプの左上隅の x 座標を取得または設定します（ポイント単位）。
            読み取り/書き込み **float**。


### 備考

返される値は常に定義されており、**float** ではありません。
            割り当てられる値も定義されている必要があります。**float** は `RawFrame` インスタンスのプロパティにのみ割り当ててください。
