## parent_group プロパティ
シェイプがグループ化されている場合、親 GroupShape オブジェクトを返します。グループ化されていない場合は None を返します。
            読み取り専用 [`IGroupShape`](/slides/python-net/ja/aspose.slides/igroupshape).
