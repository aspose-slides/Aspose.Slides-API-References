## SizeF クラス

順序付けられたペアの浮動小数点数を格納し、通常は矩形の幅と高さを表します。 .NET `System.Drawing.SizeF` と互換性があります。

## プロパティ

| Property | Description |
| :- | :- |
| [`width`](/slides/python-net/ja/aspose.slides/sizef/width/) | このサイズの水平成分を取得します。<br/>            読み取り専用 **float**. |
| [`height`](/slides/python-net/ja/aspose.slides/sizef/height/) | このサイズの垂直成分を取得します。<br/>            読み取り専用 **float**. |
