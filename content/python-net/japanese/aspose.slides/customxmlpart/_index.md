## CustomXmlPart クラス

カスタム XML パーツを表します。

CustomXmlPart タイプは次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`xml_data`](/slides/python-net/ja/aspose.slides/customxmlpart/xml_data/) | XML データを取得または設定します。<br/>            読み書き **int**[].<br/>            値は `None` です。値が空の場合または XML データが無効です。 |
| [`xml_as_string`](/slides/python-net/ja/aspose.slides/customxmlpart/xml_as_string/) | XML データを UTF-8 文字列として取得または設定します。<br/>            読み書き **str**。<br/>            値は `None` です。値が空の場合または XML データが無効です。 |
| [`item_id`](/slides/python-net/ja/aspose.slides/customxmlpart/item_id/) | Office Open XML 文書内の単一のカスタム XML <br/>            パーツを一意に識別するグローバル一意識別子 (GUID) を指定します。<br/>            読み取り専用 **System.Guid**。 |
| [`namespace_schemas`](/slides/python-net/ja/aspose.slides/customxmlpart/namespace_schemas/) | カスタム XML パーツに関連付けられたコレクション XML スキーマを取得します。<br/>            読み取り専用 **str**[]. |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`remove(self)`](/slides/python-net/ja/aspose.slides/customxmlpart/remove/#) | プレゼンテーションからカスタム XML パーツを削除します。 |
