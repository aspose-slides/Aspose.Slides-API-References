## ConnectorLock クラス

親 Connector に対してどの操作が無効化されているかを決定します。

**継承:**[`ConnectorLock`](/slides/python-net/ja/aspose.slides/connectorlock) → [`BaseShapeLock`](/slides/python-net/ja/aspose.slides/baseshapelock)

ConnectorLock 型は以下のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`no_locks`](/slides/python-net/ja/aspose.slides/connectorlock/no_locks/) | すべてのロックフラグが無効な場合は true を返します。<br/>            読み取り専用 **bool**. |
| [`grouping_locked`](/slides/python-net/ja/aspose.slides/connectorlock/grouping_locked/) | このシェイプをグループに追加することが禁止されているかどうかを決定します。<br/>            読み書き可能 **bool**. |
| [`select_locked`](/slides/python-net/ja/aspose.slides/connectorlock/select_locked/) | このシェイプを選択することが禁止されているかどうかを決定します。<br/>            読み書き可能 **bool**. |
| [`rotate_locked`](/slides/python-net/ja/aspose.slides/connectorlock/rotate_locked/) | このシェイプの回転角度を変更することが禁止されているかどうかを決定します。<br/>            読み書き可能 **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/ja/aspose.slides/connectorlock/aspect_ratio_locked/) | リサイズ時にシェイプがアスペクト比を保持しなければならないかどうかを決定します。<br/>            読み書き可能 **bool**. |
| [`position_move`](/slides/python-net/ja/aspose.slides/connectorlock/position_move/) | このシェイプを移動することが禁止されているかどうかを決定します。<br/>            読み書き可能 **bool**. |
| [`size_locked`](/slides/python-net/ja/aspose.slides/connectorlock/size_locked/) | このシェイプをリサイズすることが禁止されているかどうかを決定します。<br/>            読み書き可能 **bool**. |
| [`edit_points_locked`](/slides/python-net/ja/aspose.slides/connectorlock/edit_points_locked/) | このシェイプの輪郭を直接変更することが禁止されているかどうかを決定します。<br/>            読み書き可能 **bool**. |
| [`adjust_handles_locked`](/slides/python-net/ja/aspose.slides/connectorlock/adjust_handles_locked/) | 調整値を変更することが禁止されているかどうかを決定します。<br/>            読み書き可能 **bool**. |
| [`arrowheads_locked`](/slides/python-net/ja/aspose.slides/connectorlock/arrowheads_locked/) | 矢じりを変更することが禁止されているかどうかを決定します。<br/>            読み書き可能 **bool**. |
| [`shape_type_locked`](/slides/python-net/ja/aspose.slides/connectorlock/shape_type_locked/) | シェイプの種類を変更することが禁止されているかどうかを決定します。<br/>            読み書き可能 **bool**. |
