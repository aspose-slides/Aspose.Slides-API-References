## IHyperlinkQueries クラス

含まれるハイパーリンクへの簡単なアクセスを提供します。

IHyperlinkQueries 型は次のメンバーを公開します：

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`get_hyperlink_clicks(self)`](/slides/python-net/ja/aspose.slides/ihyperlinkqueries/get_hyperlink_clicks/#) | None でない HyperlinkClick を含むすべての IHyperlinkContainer サブオブジェクトを取得します。<br/> 指定された IHyperlinkContainer オブジェクトでハイパーリンクを管理できます（読み取り、更新、または削除）。IHyperlinkContainer インターフェイスを参照してください。 |
| [`get_hyperlink_mouse_overs(self)`](/slides/python-net/ja/aspose.slides/ihyperlinkqueries/get_hyperlink_mouse_overs/#) | None でない HyperlinkMouseOver を含むすべての IHyperlinkContainer サブオブジェクトを取得します。<br/> 指定された IHyperlinkContainer オブジェクトでハイパーリンクを管理できます（読み取り、更新、または削除）。IHyperlinkContainer インターフェイスを参照してください。 |
| [`get_any_hyperlinks(self)`](/slides/python-net/ja/aspose.slides/ihyperlinkqueries/get_any_hyperlinks/#) | None でない HyperlinkMouseOver を含むすべての IHyperlinkContainer サブオブジェクトを取得します。<br/> 指定された IHyperlinkContainer オブジェクトでハイパーリンクを管理できます（読み取り、更新、または削除）。IHyperlinkContainer インターフェイスを参照してください。 |
| [`remove_all_hyperlinks(self)`](/slides/python-net/ja/aspose.slides/ihyperlinkqueries/remove_all_hyperlinks/#) | すべての含まれる HyperlinkClick と HyperlinkMouseOver のハイパーリンクを削除します（すべての IHyperlinkContainer サブオブジェクト内）。 |
