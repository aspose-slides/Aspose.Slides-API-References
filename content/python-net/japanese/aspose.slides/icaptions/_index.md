## ICaptions クラス

WebVTT のクローズドキャプションを表します。

ICaptions 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`caption_id`](/slides/python-net/ja/aspose.slides/icaptions/caption_id/) | クローズドキャプションのグローバルに一意な識別子 (GUID) を返します。<br/>            読み取り専用 **System.Guid**. |
| [`label`](/slides/python-net/ja/aspose.slides/icaptions/label/) | クローズドキャプションのラベルを取得または設定します。<br/>            読み書き可能 **str**. |
| [`binary_data`](/slides/python-net/ja/aspose.slides/icaptions/binary_data/) | クローズドキャプションのバイナリ データを返します。<br/>            読み取り専用 **int**[]. |
| [`data_as_string`](/slides/python-net/ja/aspose.slides/icaptions/data_as_string/) | クローズドキャプションのデータを UTF-8 エンコードされた文字列として返します。<br/>            読み取り専用 **str**. |
