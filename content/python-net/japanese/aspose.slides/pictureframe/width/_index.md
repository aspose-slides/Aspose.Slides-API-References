## width プロパティ
形状の width を取得または設定します。単位はポイントです。
            読み取り/書き込み **float**。


### 備考

返される値は常に定義されており、**float** になることはありません。
            代入される値も定義されている必要があります。`RawFrame` インスタンスのプロパティに対してのみ **float** を代入してください。
