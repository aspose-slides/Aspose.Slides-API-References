## IEffectFormatEffectiveData クラス

有効なエフェクトの書式設定プロパティを含む不変オブジェクトです。

IEffectFormatEffectiveData 型は次のメンバーを公開します。

## Properties

| プロパティ | 説明 |
| :- | :- |
| [`is_no_effects`](/slides/python-net/ja/aspose.slides/ieffectformateffectivedata/is_no_effects/) | すべてのエフェクトが無効になっている場合に true を返します（作成直後のデフォルト EffectFormat オブジェクトのように）。<br/>            読み取り専用 **bool**。 |
| [`blur_effect`](/slides/python-net/ja/aspose.slides/ieffectformateffectivedata/blur_effect/) | ぼかし効果。<br/>            読み取り専用 [`IBlurEffectiveData`](/slides/python-net/ja/aspose.slides.effects/iblureffectivedata)。 |
| [`fill_overlay_effect`](/slides/python-net/ja/aspose.slides/ieffectformateffectivedata/fill_overlay_effect/) | 塗りつぶしオーバーレイ効果。<br/>            読み取り専用 [`IFillOverlayEffectiveData`](/slides/python-net/ja/aspose.slides.effects/ifilloverlayeffectivedata)。 |
| [`glow_effect`](/slides/python-net/ja/aspose.slides/ieffectformateffectivedata/glow_effect/) | グロー効果。<br/>            読み取り専用 [`IGlowEffectiveData`](/slides/python-net/ja/aspose.slides.effects/igloweffectivedata)。 |
| [`inner_shadow_effect`](/slides/python-net/ja/aspose.slides/ieffectformateffectivedata/inner_shadow_effect/) | 内部シャドウ。<br/>            読み取り専用 [`IInnerShadowEffectiveData`](/slides/python-net/ja/aspose.slides.effects/iinnershadoweffectivedata)。 |
| [`outer_shadow_effect`](/slides/python-net/ja/aspose.slides/ieffectformateffectivedata/outer_shadow_effect/) | 外部シャドウ。<br/>            読み取り専用 [`IOuterShadowEffectiveData`](/slides/python-net/ja/aspose.slides.effects/ioutershadoweffectivedata)。 |
| [`preset_shadow_effect`](/slides/python-net/ja/aspose.slides/ieffectformateffectivedata/preset_shadow_effect/) | プリセットシャドウ。<br/>            読み取り専用 [`IPresetShadowEffectiveData`](/slides/python-net/ja/aspose.slides.effects/ipresetshadoweffectivedata)。 |
| [`reflection_effect`](/slides/python-net/ja/aspose.slides/ieffectformateffectivedata/reflection_effect/) | 反射。<br/>            読み取り専用 [`IReflectionEffectiveData`](/slides/python-net/ja/aspose.slides.effects/ireflectioneffectivedata)。 |
| [`soft_edge_effect`](/slides/python-net/ja/aspose.slides/ieffectformateffectivedata/soft_edge_effect/) | ソフトエッジ。<br/>            読み取り専用 [`ISoftEdgeEffectiveData`](/slides/python-net/ja/aspose.slides.effects/isoftedgeeffectivedata)。 |


### 備考

このインターフェイスは [`IEffectFormat`](/slides/python-net/ja/aspose.slides/ieffectformat) インターフェイスと共に使用され、継承が適用された有効な書式設定値を返します。
