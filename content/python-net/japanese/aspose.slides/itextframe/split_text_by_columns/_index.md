## split_text_by_columns(self) {#}
[`ITextFrame`](/slides/python-net/ja/aspose.slides/itextframe) のテキスト コンテンツを文字列の配列に分割し、各要素はフレーム内の個別のテキスト 列に対応します。

### 戻り値
文字列の配列で、各文字列は [`ITextFrame`](/slides/python-net/ja/aspose.slides/itextframe) の特定の列のテキスト コンテンツを表します。

```python
def split_text_by_columns(self):
    ...
```

### 備考
テキスト フレームに複数列が含まれていない場合、返される配列は全文テキストを含む単一の要素になります。空の列は配列内で空文字列として表されます。
