            各要素はフレーム内の個別のテキスト列に対応します。

### Returns
文字列の配列で、各文字列は特定の列のテキストコンテンツを表します  
            [`ITextFrame`](/slides/python-net/ja/aspose.slides/itextframe) 内の。

```python
def split_text_by_columns(self):
    ...
```

### Remarks
テキストフレームに複数列が含まれていない場合、返される配列は単一の要素となります  
            完全なテキストを含む。  
            空の列は配列内で空文字列として表されます。
