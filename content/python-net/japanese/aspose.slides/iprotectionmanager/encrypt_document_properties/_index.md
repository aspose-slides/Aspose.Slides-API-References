## encrypt_document_properties プロパティ
This property makes sense, if presentation is password protected.
            true の場合、ドキュメント プロパティはプレゼンテーション ファイル内で暗号化されます。
            false の場合、ドキュメント プロパティは公開され、プレゼンテーションは暗号化されます。
            読み取り/書き込み **bool**.
