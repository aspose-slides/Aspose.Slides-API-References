## remove(self, item) {#icustomxmlpart}
コレクションから特定のオブジェクトの最初の出現を削除します。

### 戻り値

`true` がアイテムを正常に削除した場合; それ以外の場合は `false`。

```python
def remove(self, item):
    ...
```

| :- | :- | :- |
| item | [`ICustomXmlPart`](/slides/python-net/ja/aspose.slides/icustomxmlpart) | 削除するカスタム XML パート。 |

| 例外 | 説明 |
