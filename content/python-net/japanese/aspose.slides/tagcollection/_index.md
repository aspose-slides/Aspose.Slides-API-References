## TagCollection クラス

タグ（ユーザー定義の文字列ペア）のコレクションを表します

TagCollection 型は次のメンバーを公開します:

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`add(self, name, value)`](/slides/python-net/ja/aspose.slides/tagcollection/add/#str-str) | コレクションに新しいタグを追加します。 |
| [`remove(self, name)`](/slides/python-net/ja/aspose.slides/tagcollection/remove/#str) | 指定された名前のタグをコレクションから削除します。 |
| [`index_of_name(self, name)`](/slides/python-net/ja/aspose.slides/tagcollection/index_of_name/#str) | コレクション内の指定されたキーのゼロベースインデックスを返します。 |
| [`remove_at(self, index)`](/slides/python-net/ja/aspose.slides/tagcollection/remove_at/#int) | 指定されたインデックスのタグを削除します。 |
| [`clear(self)`](/slides/python-net/ja/aspose.slides/tagcollection/clear/#) | コレクションからすべてのタグを削除します。 |
| [`get_value_by_index(self, index)`](/slides/python-net/ja/aspose.slides/tagcollection/get_value_by_index/#int) | 指定されたインデックスのタグの値を返します。 |
| [`get_name_by_index(self, index)`](/slides/python-net/ja/aspose.slides/tagcollection/get_name_by_index/#int) | 指定されたインデックスのタグのキーを返します。 |
| [`get_names_of_tags(self)`](/slides/python-net/ja/aspose.slides/tagcollection/get_names_of_tags/#) | タグの名前を返します。 |
