## HyperlinkActionType 列挙型

ハイパーリンクアクションのタイプを表します。

HyperlinkActionType 型は次のメンバーを公開します:

## フィールド

| フィールド | 説明 |
| :- | :- |
| UNKNOWN | 認識できないアクションタイプ。 |
| NO_ACTION | アクションなし。 |
| HYPERLINK | 通常のハイパーリンク。 |
| JUMP_FIRST_SLIDE | プレゼンテーションの最初のスライドへジャンプ。 |
| JUMP_PREVIOUS_SLIDE | 前のスライドへジャンプ。 |
| JUMP_NEXT_SLIDE | 次のスライドへジャンプ。 |
| JUMP_LAST_SLIDE | プレゼンテーションの最後のスライドへジャンプ。 |
| JUMP_END_SHOW | スライドショーの最後へジャンプ。 |
| JUMP_LAST_VIEWED_SLIDE | 最後に表示されたスライドへジャンプ。 |
| JUMP_SPECIFIC_SLIDE | [`IHyperlink.target_slide`](/slides/python-net/ja/aspose.slides/ihyperlink/target_slide) プロパティで参照される特定のスライドへジャンプ。 |
| START_CUSTOM_SLIDE_SHOW | カスタムスライドショーを開始。 |
| OPEN_FILE | 参照されたファイルを開く。 |
| OPEN_PRESENTATION | 参照されたプレゼンテーションを開く。 |
| START_STOP_MEDIA | メディアファイルの再生を開始/停止。 |
| START_MACRO | マクロスクリプトの実行を開始。 |
| START_PROGRAM | プログラムを開始。 |
