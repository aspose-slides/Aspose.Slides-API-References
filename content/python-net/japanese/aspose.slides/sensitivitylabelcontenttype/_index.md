## SensitivityLabelContentType 列挙

ドキュメントに適用すべきコンテンツマーキングのタイプを表します。

SensitivityLabelContentType 型は次のメンバーを公開します。

## フィールド

| Field | Description |
| :- | :- |
| NONE | ラベルがデフォルトまたは自動的に適用されることを意味します。 |
| HEADER | ラベルが手動で適用されたことを意味します。<br/>            ユーザーが直接適用したすべての感度ラベルに使用します。 |
| FOOTER | ラベルが手動で適用されたことを意味します。<br/>            ユーザーが直接適用したすべての感度ラベルに使用します。 |
| WATERMARK | ラベルが手動で適用されたことを意味します。<br/>            ユーザーが直接適用したすべての感度ラベルに使用します。 |
| ENCRYPTION | ラベルが手動で適用されたことを意味します。<br/>            ユーザーが直接適用したすべての感度ラベルに使用します。 |
