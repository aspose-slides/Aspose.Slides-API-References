## IShapeBevelEffectiveData クラス

有効なシェイプの表面リリーフプロパティを含む不変オブジェクトです。

IShapeBevelEffectiveData 型は以下のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`width`](/slides/python-net/ja/aspose.slides/ishapebeveleffectivedata/width/) | ベベル幅。<br/>            読み取り専用 **float**. |
| [`height`](/slides/python-net/ja/aspose.slides/ishapebeveleffectivedata/height/) | ベベル高さ。<br/>            読み取り専用 **float**. |
| [`bevel_type`](/slides/python-net/ja/aspose.slides/ishapebeveleffectivedata/bevel_type/) | ベベルタイプ。<br/>            読み取り専用 [`BevelPresetType`](/slides/python-net/ja/aspose.slides/bevelpresettype). |
