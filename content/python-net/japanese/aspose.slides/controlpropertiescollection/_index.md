## ControlPropertiesCollection クラス

ActiveX プロパティのコレクションです。

ControlPropertiesCollection 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`names_of_properties`](/slides/python-net/ja/aspose.slides/controlpropertiescollection/names_of_properties/) | プロパティ名のコレクションを返します。<br/>            読み取り専用 **list**. |
| [`count`](/slides/python-net/ja/aspose.slides/controlpropertiescollection/count/) | コレクション内のプロパティ数を返します。<br/>            読み取り専用 **int**. |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`add(self, name, value)`](/slides/python-net/ja/aspose.slides/controlpropertiescollection/add/#str-str) | コレクションにプロパティを追加します。 |
| [`remove(self, name)`](/slides/python-net/ja/aspose.slides/controlpropertiescollection/remove/#str) | 指定された名前のプロパティを削除します。 |
| [`clear(self)`](/slides/python-net/ja/aspose.slides/controlpropertiescollection/clear/#) | すべてのプロパティを削除します。 |
