## ISection クラス

スライドのセクションを表します。

ISection 型は以下のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`name`](/slides/python-net/ja/aspose.slides/isection/name/) | セクションの名前。 |
| [`section_id`](/slides/python-net/ja/aspose.slides/isection/section_id/) | セクション ID。 |
| [`started_from_slide`](/slides/python-net/ja/aspose.slides/isection/started_from_slide/) | セクションの最初のスライドを返します。 |

## メソッド
