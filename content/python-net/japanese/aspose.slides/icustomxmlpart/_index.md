## ICustomXmlPart class

カスタム XML パートを表します。

ICustomXmlPart 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`xml_as_string`](/slides/python-net/ja/aspose.slides/icustomxmlpart/xml_as_string/) | XML データを UTF-8 文字列として取得または設定します。<br/>            読み書き **str**。<br/>            値は `None` です。値が空であるか XML データが無効です。 |
| [`xml_data`](/slides/python-net/ja/aspose.slides/icustomxmlpart/xml_data/) | XML データを取得または設定します。<br/>            読み書き **int**[]。<br/>            値は `None` です。値が空であるか XML データが無効です。 |
| [`item_id`](/slides/python-net/ja/aspose.slides/icustomxmlpart/item_id/) | Office Open XML ドキュメント内の単一のカスタム XML パートを一意に識別する、グローバルに一意な識別子 (GUID) を指定します。<br/>            読み取り専用 **System.Guid**。 |
| [`namespace_schemas`](/slides/python-net/ja/aspose.slides/icustomxmlpart/namespace_schemas/) | カスタム XML パートに関連付けられた XML スキーマ コレクションを取得します。<br/>            読み取り専用 **str**[]。 |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`remove(self)`](/slides/python-net/ja/aspose.slides/icustomxmlpart/remove/#) | プレゼンテーションからカスタム XML パートを削除します。 |
