## SensitivityLabel クラス

Microsoft Purview Information Protection からの感度ラベルを表します。

SensitivityLabel 型は次のメンバーを公開します。

## プロパティ

| Property | Description |
| :- | :- |
| [`id`](/slides/python-net/ja/aspose.slides/sensitivitylabel/id/) | 感度ラベルの ID を取得または設定します。<br/>            読み取り/書き込み **str**. |
| [`site_id`](/slides/python-net/ja/aspose.slides/sensitivitylabel/site_id/) | Azure Active Directory (Azure AD) サイト識別子を取得または設定します。<br/>            感度ラベルを記述する感度ラベル ポリシーに対応する。<br/>            読み取り/書き込み **System.Guid**. |
| [`is_enabled`](/slides/python-net/ja/aspose.slides/sensitivitylabel/is_enabled/) | 感度ラベルが有効かどうかを示します。 |
| [`is_removed`](/slides/python-net/ja/aspose.slides/sensitivitylabel/is_removed/) | 感度ラベルが削除されたかどうかを示します。 |
| [`assignment_method_type`](/slides/python-net/ja/aspose.slides/sensitivitylabel/assignment_method_type/) | 感度ラベルの割り当て方法を取得または設定します。<br/>            読み取り/書き込み [`SensitivityLabelAssignmentType`](/slides/python-net/ja/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/ja/aspose.slides/sensitivitylabel/content_mark_types/) | ファイルに適用すべきコンテンツ マーキングのタイプの一覧を取得します。 |
