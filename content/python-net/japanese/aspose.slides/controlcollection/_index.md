## ControlCollection クラス

ActiveX コントロールのコレクションです。

ControlCollection タイプは次のメンバーを公開します。

指定された位置にあるコントロールを返します。

## インデクサ

| 名前 | 説明 |
| :- | :- |
| [`[index]`](/slides/python-net/ja/aspose.slides/controlcollection/__getitem__/) | コントロールのインデックスです。 |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`add_control(self, control_type, x, y, width, height)`](/slides/python-net/ja/aspose.slides/controlcollection/add_control/#controltype-float-float-float-float) | 新しいコントロールを作成し、コレクションに追加します。 |
| [`remove(self, item)`](/slides/python-net/ja/aspose.slides/controlcollection/remove/#icontrol) | コレクションから ActiveX コントロールを削除します。 |
| [`remove_at(self, index)`](/slides/python-net/ja/aspose.slides/controlcollection/remove_at/#int) | 指定された位置にある ActiveX コントロールをコレクションから削除します。 |
| [`clear(self)`](/slides/python-net/ja/aspose.slides/controlcollection/clear/#) | コレクションからすべてのコントロールを削除します。 |
