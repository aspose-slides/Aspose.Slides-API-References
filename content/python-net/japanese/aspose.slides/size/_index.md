## Size クラス

幅と高さを指定する整数の順序付きペアを格納します。.NET `System.Drawing.Size` と互換性があります。

Size 型は次のメンバーを公開します：

## コンストラクタ

| コンストラクタ | 説明 |
| :- | :- |
| [`__init__(self, width=0, height=0)`](/slides/python-net/ja/aspose.slides/size/__init__/#int-int) | 指定された幅と高さでサイズを作成します。浮動小数点値は整数に切り捨てられます。 |

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`width`](/slides/python-net/ja/aspose.slides/size/width/) | このサイズの水平成分を取得します。<br/>            読み取り専用 **int**。 |
| [`height`](/slides/python-net/ja/aspose.slides/size/height/) | このサイズの垂直成分を取得します。<br/>            読み取り専用 **int**。 |


### 備考

サイズは `==` を使用して各成分で比較でき、辞書のキーやセットのメンバーとして使用できます。
