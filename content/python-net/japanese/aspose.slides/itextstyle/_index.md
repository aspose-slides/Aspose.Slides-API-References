## ITextStyle クラス

テキストスタイルの書式設定プロパティです。

ITextStyle 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`default_paragraph_format`](/slides/python-net/ja/aspose.slides/itextstyle/default_paragraph_format/) | デフォルトの段落プロパティです。<br/>            読み取り専用 [`IParagraphFormat`](/slides/python-net/ja/aspose.slides/iparagraphformat). |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`get_level(self, index)`](/slides/python-net/ja/aspose.slides/itextstyle/get_level/#int) | スタイルのレベルが存在すればそれを返し、存在しない場合は None を返します。 |
| [`get_effective(self)`](/slides/python-net/ja/aspose.slides/itextstyle/get_effective/#) | 継承が適用された有効なテキストスタイル書式設定データを取得します。 |
