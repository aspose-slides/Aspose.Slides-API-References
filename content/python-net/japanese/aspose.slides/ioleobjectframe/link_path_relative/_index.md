## link_path_relative プロパティ
リンクされたファイルが存在する場合は、その相対パスを返し、存在しない場合は空文字列を返します。
             読み取り専用 **str**.

### 備考

Ppt プレゼンテーションでは、いくつかの Ole オブジェクトリンクが相対表現になる場合があります。
