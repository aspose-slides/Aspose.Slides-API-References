## blob_management_options プロパティ
Represents the options which can be used to manage Binary Large Objects (BLOBs) handling behavior,
            例えば、一時ファイルの使用やメモリ内の最大 BLOB バイト数などです。これらのオプションは設定されることを意図しています
            特定の環境や要件に対して、最高のパフォーマンス/メモリ使用率の比率を実現することを目的としています。
            Binary Large Object (BLOB) は単一のエンティティとして保存されるバイナリデータであり、すなわち BLOB は 
            オーディオ、ビデオ、またはプレゼンテーションそのものになることができます。
