## ISlideSize クラス

スライドのサイズと向きを表します。

ISlideSize 型は以下のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`size`](/slides/python-net/ja/aspose.slides/islidesize/size/) | スライドの寸法（ポイント）を取得します。 |
| [`type`](/slides/python-net/ja/aspose.slides/islidesize/type/) | スライドのサイズタイプを取得します。 |
| [`orientation`](/slides/python-net/ja/aspose.slides/islidesize/orientation/) | スライドの向きを取得または設定します。 |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`set_size(self, type, scale_type)`](/slides/python-net/ja/aspose.slides/islidesize/set_size/#slidesizetype-slidesizescaletype) | スライドサイズをタイプで設定し、既存のコンテンツをスケーリングします。 |
| [`set_size(self, width, height, scale_type)`](/slides/python-net/ja/aspose.slides/islidesize/set_size/#float-float-slidesizescaletype) | スライド寸法を明示的に設定し、既存のコンテンツをスケーリングします。 |
