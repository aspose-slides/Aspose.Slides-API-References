## IParagraphFormatEffectiveData クラス

有効な段落書式プロパティを含む不変オブジェクトです。

IParagraphFormatEffectiveData 型は次のメンバーを公開します。

## プロパティ

| Property | Description |
| :- | :- |
| [`bullet`](/slides/python-net/ja/aspose.slides/iparagraphformateffectivedata/bullet/) | 段落の箇条書き形式を返します。<br/>            読み取り専用 [`IBulletFormatEffectiveData`](/slides/python-net/ja/aspose.slides/ibulletformateffectivedata)。 |
| [`depth`](/slides/python-net/ja/aspose.slides/iparagraphformateffectivedata/depth/) | 段落の深さを返します。<br/>            読み取り専用 **int**。 |
| [`alignment`](/slides/python-net/ja/aspose.slides/iparagraphformateffectivedata/alignment/) | 段落のテキスト配置を返します。<br/>            読み取り専用 [`TextAlignment`](/slides/python-net/ja/aspose.slides/textalignment)。 |
| [`space_within`](/slides/python-net/ja/aspose.slides/iparagraphformateffectivedata/space_within/) | 段落のベースライン間のスペース量を返します。<br/>            読み取り専用 **float**。 |
| [`space_before`](/slides/python-net/ja/aspose.slides/iparagraphformateffectivedata/space_before/) | 段落の最初の行の前のスペース量を返します。<br/>            読み取り専用 **float**。 |
| [`space_after`](/slides/python-net/ja/aspose.slides/iparagraphformateffectivedata/space_after/) | 段落の最後の行の後のスペース量を返します。<br/>            読み取り専用 **float**。 |
| [`east_asian_line_break`](/slides/python-net/ja/aspose.slides/iparagraphformateffectivedata/east_asian_line_break/) | 段落で東アジアの改行が使用されているかどうかを判定します。<br/>            読み取り専用 **bool**。 |
| [`right_to_left`](/slides/python-net/ja/aspose.slides/iparagraphformateffectivedata/right_to_left/) | 段落で右から左への書字が使用されているかどうかを判定します。<br/>            読み取り専用 **bool**。 |
| [`latin_line_break`](/slides/python-net/ja/aspose.slides/iparagraphformateffectivedata/latin_line_break/) | 段落でラテン文字の改行が使用されているかどうかを判定します。<br/>            読み取り専用 **bool**。 |
| [`hanging_punctuation`](/slides/python-net/ja/aspose.slides/iparagraphformateffectivedata/hanging_punctuation/) | 段落でハンギング句読点が使用されているかどうかを判定します。<br/>            読み取り専用 **bool**。 |
| [`margin_left`](/slides/python-net/ja/aspose.slides/iparagraphformateffectivedata/margin_left/) | 段落の左余白を返します。<br/>            読み取り専用 **float**。 |
| [`margin_right`](/slides/python-net/ja/aspose.slides/iparagraphformateffectivedata/margin_right/) | 段落の右余白を返します。<br/>            読み取り専用 **float**。 |
| [`indent`](/slides/python-net/ja/aspose.slides/iparagraphformateffectivedata/indent/) | 段落の最初の行インデント/ハンギングインデントを返します。ハンギングインデントは負の値で定義できます。<br/>            読み取り専用 **float**。 |
| [`default_tab_size`](/slides/python-net/ja/aspose.slides/iparagraphformateffectivedata/default_tab_size/) | デフォルトのタブ幅を返します。<br/>            読み取り専用 **float**。 |
| [`tabs`](/slides/python-net/ja/aspose.slides/iparagraphformateffectivedata/tabs/) | 段落のタブ設定を返します。<br/>            読み取り専用 [`ITabEffectiveData`](/slides/python-net/ja/aspose.slides/itabeffectivedata)[]。 |
| [`font_alignment`](/slides/python-net/ja/aspose.slides/iparagraphformateffectivedata/font_alignment/) | 段落のフォント配置を返します。<br/>            読み取り専用 [`FontAlignment`](/slides/python-net/ja/aspose.slides/fontalignment)。 |
| [`default_portion_format`](/slides/python-net/ja/aspose.slides/iparagraphformateffectivedata/default_portion_format/) | 段落のデフォルト部分書式を返します。<br/>            読み取り専用 [`IPortionFormatEffectiveData`](/slides/python-net/ja/aspose.slides/iportionformateffectivedata)。 |

### 備考

このインターフェイスは [`IParagraphFormat`](/slides/python-net/ja/aspose.slides/iparagraphformat) インターフェイスと共に使用され、継承が適用された有効な書式値を返します。
