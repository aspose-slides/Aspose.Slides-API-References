## AudioPlayModePreset 列挙体

サウンドの再生方法を定義する定数です。

AudioPlayModePreset 型は次のメンバーを公開します:

## フィールド

| フィールド | 説明 |
| :- | :- |
| MIXED |  |
| AUTO | 自動的に再生します。 |
| ON_CLICK | アイコンがクリックされたときにのみ再生します。 |
| ALL_SLIDES | すべてのスライドで再生します。 <br/>            代わりに [`IAudioFrame.play_across_slides`](/slides/python-net/ja/aspose.slides/iaudioframe/play_across_slides) プロパティを使用してください。<br/>            この要素は PowerPoint 2013 以降、廃止されています。 |
| IN_CLICK_SEQUENCE | クリックとともに自動的に再生します。 |
