## TextHighlightingOptions クラス

テキストフレーム内のテキストをハイライトするために使用できるオプションを表します。

TextHighlightingOptions 型は次のメンバーを公開します：

## コンストラクタ

| コンストラクタ | 説明 |
| :- | :- |
| [`__init__(self)`](/slides/python-net/ja/aspose.slides/texthighlightingoptions/__init__/#) | 新しいデフォルトのテキストハイライトオプションを作成します。 |

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`case_sensitive`](/slides/python-net/ja/aspose.slides/texthighlightingoptions/case_sensitive/) | true を設定すると大文字小文字を区別した検索を使用し、false の場合はそれ以外です。<br/>            読み書き **bool**. |
| [`whole_words_only`](/slides/python-net/ja/aspose.slides/texthighlightingoptions/whole_words_only/) | true を設定すると単語全体に一致させ、false の場合はそれ以外です。<br/>            読み書き **bool**. |
