## remove(self, item) {#iparagraph}
**System.Collections.Generic.ICollection`1** から特定のオブジェクトの最初の出現を削除します。

### 戻り値

`item` が **System.Collections.Generic.ICollection`1** から正常に削除された場合は true、そうでない場合は false。元の **System.Collections.Generic.ICollection`1** に `item` が見つからなかった場合も false を返します。



```python
def remove(self, item):
    ...
```


| パラメータ | 型 | 説明 |
| :- | :- | :- |
| item | [`IParagraph`](/slides/python-net/ja/aspose.slides/iparagraph) | **System.Collections.Generic.ICollection`1** から削除するオブジェクトです。 |

### 例外

| 例外 | 説明 |
| :- | :- |
| **RuntimeError(Proxy error(NotSupportedException))** | **System.Collections.Generic.ICollection`1** は読み取り専用です。 |
