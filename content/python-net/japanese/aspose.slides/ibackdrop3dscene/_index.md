## IBackdrop3DScene クラス

効果（例えば、グローやシャドウ）が適用される形状との関係で適用される平面を定義します。

IBackdrop3DScene 型は以下のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`normal_vector`](/slides/python-net/ja/aspose.slides/ibackdrop3dscene/normal_vector/) | 正規ベクトルを取得または設定します。より正確には、この属性はベクトル<br/>            バックドロップ平面の面に対して法線となります。ベクトルは 3 つの float 値の配列で表され、<br/>            X、Y、Z 座標を定義します。<br/>            読み取り/書き込み **float**[]. |
| [`anchor_point`](/slides/python-net/ja/aspose.slides/ibackdrop3dscene/anchor_point/) | 3D 空間の点を取得または設定します。この点はバックドロップ平面を固定する空間上の点です。<br/>            3D 点は 3 つの float 値の配列で表され、X、Y、Z 座標を定義します。<br/>            読み取り/書き込み **float**[]. |
| [`up_vector`](/slides/python-net/ja/aspose.slides/ibackdrop3dscene/up_vector/) | 上方向を表すベクトルを取得または設定します。より正確には、この属性はベクトル<br/>            バックドロップ平面の面に対して上方向となります。ベクトルは 3 つの float 値の配列で表され、<br/>            X、Y、Z 座標を定義します。<br/>            読み取り/書き込み **float**[]. |
