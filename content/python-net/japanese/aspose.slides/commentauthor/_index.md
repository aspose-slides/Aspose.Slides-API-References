## CommentAuthor クラス

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`name`](/slides/python-net/ja/aspose.slides/commentauthor/name/) | 著者の名前を取得または設定します。<br/>            読み書き **str**. |
| [`initials`](/slides/python-net/ja/aspose.slides/commentauthor/initials/) | 著者のイニシャルを取得または設定します。<br/>            読み書き **str**. |
| [`comments`](/slides/python-net/ja/aspose.slides/commentauthor/comments/) | この著者が作成したコメントのコレクションを取得します。<br/>            読み取り専用 [`ICommentCollection`](/slides/python-net/ja/aspose.slides/icommentcollection). |
