## INormalViewRestoredProperties クラス

スライド領域のサイズを指定します（restoredTop の子の場合は幅、restoredLeft の子の場合は高さ）通常ビューの領域が可変の復元サイズ（最小化でも最大化でもない）である場合。

INormalViewRestoredProperties 型は次のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`dimension_size`](/slides/python-net/ja/aspose.slides/inormalviewrestoredproperties/dimension_size/) | スライド領域のサイズを指定します（RestoredTop の子の場合は幅、RestoredLeft の子の場合は高さ）。<br/>            読み書き **float**。<br/>            値が 0 未満または 100 を超える場合にスローします。 |
| [`auto_adjust`](/slides/python-net/ja/aspose.slides/inormalviewrestoredproperties/auto_adjust/) | ウィンドウをリサイズしたときに、ビューを含むアプリケーション内のサイドコンテンツ領域のサイズが新しいサイズを補償すべきかどうかを指定します。<br/>            読み書き **bool**。 |
