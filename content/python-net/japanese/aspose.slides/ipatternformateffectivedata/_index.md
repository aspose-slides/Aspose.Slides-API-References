## IPatternFormatEffectiveData クラス

効果的なパターン塗りつぶしプロパティを含む不変オブジェクトです。

IPatternFormatEffectiveData 型は以下のメンバーを公開します。

## プロパティ

| Property | Description |
| :- | :- |
| [`pattern_style`](/slides/python-net/ja/aspose.slides/ipatternformateffectivedata/pattern_style/) | パターンスタイルを返します。<br/>            読み取り専用 [`PatternStyle`](/slides/python-net/ja/aspose.slides/patternstyle). |
| [`fore_color`](/slides/python-net/ja/aspose.slides/ipatternformateffectivedata/fore_color/) | 前景パターンの色を返します。<br/>            読み取り専用 **aspose.slides.Color**. |
| [`back_color`](/slides/python-net/ja/aspose.slides/ipatternformateffectivedata/back_color/) | 背景パターンの色を返します。<br/>            読み取り専用 **aspose.slides.Color**. |
