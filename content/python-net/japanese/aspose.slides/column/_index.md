## Column クラス

テーブル内の列を表します。

**継承:**[`Column`](/slides/python-net/ja/aspose.slides/column) → [`CellCollection`](/slides/python-net/ja/aspose.slides/cellcollection)

Column 型は次のメンバーを公開します。

## プロパティ

| Property | Description |
| :- | :- |
| [`slide`](/slides/python-net/ja/aspose.slides/column/slide/) | CellCollection の親スライドを返します。<br/>            読み取り専用 [`IBaseSlide`](/slides/python-net/ja/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/ja/aspose.slides/column/presentation/) | CellCollection の親プレゼンテーションを返します。<br/>            読み取り専用 [`IPresentation`](/slides/python-net/ja/aspose.slides/ipresentation). |
| [`width`](/slides/python-net/ja/aspose.slides/column/width/) | 列の幅を取得または設定します。<br/>            読み書き **float**. |
| [`column_format`](/slides/python-net/ja/aspose.slides/column/column_format/) | この列の書式設定プロパティを含む ColumnFormat オブジェクトを返します。<br/>            読み取り専用 [`IColumnFormat`](/slides/python-net/ja/aspose.slides/icolumnformat). |
