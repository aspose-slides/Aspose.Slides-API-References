## ICellFormat クラス

テーブルセルの書式を表します。

ICellFormat 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`fill_format`](/slides/python-net/ja/aspose.slides/icellformat/fill_format/) | セルの塗りつぶしプロパティ オブジェクトを返します。<br/>            読み取り専用 [`IFillFormat`](/slides/python-net/ja/aspose.slides/ifillformat). |
| [`border_left`](/slides/python-net/ja/aspose.slides/icellformat/border_left/) | 左側の罫線プロパティ オブジェクトを返します。<br/>            読み取り専用 [`ILineFormat`](/slides/python-net/ja/aspose.slides/ilineformat). |
| [`border_top`](/slides/python-net/ja/aspose.slides/icellformat/border_top/) | 上側の罫線プロパティ オブジェクトを返します。<br/>            読み取り専用 [`ILineFormat`](/slides/python-net/ja/aspose.slides/ilineformat). |
| [`border_right`](/slides/python-net/ja/aspose.slides/icellformat/border_right/) | 右側の罫線プロパティ オブジェクトを返します。<br/>            読み取り専用 [`ILineFormat`](/slides/python-net/ja/aspose.slides/ilineformat). |
| [`border_bottom`](/slides/python-net/ja/aspose.slides/icellformat/border_bottom/) | 下側の罫線プロパティ オブジェクトを返します。<br/>            読み取り専用 [`ILineFormat`](/slides/python-net/ja/aspose.slides/ilineformat). |
| [`border_diagonal_down`](/slides/python-net/ja/aspose.slides/icellformat/border_diagonal_down/) | 左上から右下への対角線プロパティ オブジェクトを返します。<br/>            読み取り専用 [`ILineFormat`](/slides/python-net/ja/aspose.slides/ilineformat). |
| [`border_diagonal_up`](/slides/python-net/ja/aspose.slides/icellformat/border_diagonal_up/) | 左下から右上への対角線プロパティ オブジェクトを返します。<br/>            読み取り専用 [`ILineFormat`](/slides/python-net/ja/aspose.slides/ilineformat). |
| [`transparency`](/slides/python-net/ja/aspose.slides/icellformat/transparency/) | 塗りつぶしカラーの透明度を取得または設定します。<br/>            読み書き **float**. |
