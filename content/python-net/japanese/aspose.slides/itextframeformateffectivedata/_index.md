## ITextFrameFormatEffectiveData クラス

効果的なテキストフレーム書式設定プロパティを含む不変オブジェクトです。

ITextFrameFormatEffectiveData 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`text_style`](/slides/python-net/ja/aspose.slides/itextframeformateffectivedata/text_style/) | 有効なテキストのスタイルを返します。<br/>            読み取り専用 [`ITextStyleEffectiveData`](/slides/python-net/ja/aspose.slides/itextstyleeffectivedata). |
| [`margin_left`](/slides/python-net/ja/aspose.slides/itextframeformateffectivedata/margin_left/) | TextFrame の左余白（ポイント）を返します。<br/>            読み取り専用 **float**. |
| [`margin_right`](/slides/python-net/ja/aspose.slides/itextframeformateffectivedata/margin_right/) | TextFrame の右余白（ポイント）を返します。<br/>            読み取り専用 **float**. |
| [`margin_top`](/slides/python-net/ja/aspose.slides/itextframeformateffectivedata/margin_top/) | TextFrame の上余白（ポイント）を返します。<br/>            読み取り専用 **float**. |
| [`margin_bottom`](/slides/python-net/ja/aspose.slides/itextframeformateffectivedata/margin_bottom/) | TextFrame の下余白（ポイント）を返します。<br/>            読み取り専用 **float**. |
| [`wrap_text`](/slides/python-net/ja/aspose.slides/itextframeformateffectivedata/wrap_text/) | TextFrame の余白でテキストが折り返されるかどうかを返します。<br/>            読み取り専用 **bool**. |
| [`anchoring_type`](/slides/python-net/ja/aspose.slides/itextframeformateffectivedata/anchoring_type/) | TextFrame の垂直アンカー テキストを返します。<br/>            読み取り専用 [`TextAnchorType`](/slides/python-net/ja/aspose.slides/textanchortype). |
| [`center_text`](/slides/python-net/ja/aspose.slides/itextframeformateffectivedata/center_text/) | テキストを水平にボックスの中央に配置すべきかどうかを返します。<br/>            読み取り専用 **bool**. |
| [`text_vertical_type`](/slides/python-net/ja/aspose.slides/itextframeformateffectivedata/text_vertical_type/) | テキストの向きを返します。<br/>            読み取り専用 [`TextVerticalType`](/slides/python-net/ja/aspose.slides/textverticaltype). |
| [`autofit_type`](/slides/python-net/ja/aspose.slides/itextframeformateffectivedata/autofit_type/) | テキストの自動フィットモードを返します。<br/>            読み取り専用 [`TextAutofitType`](/slides/python-net/ja/aspose.slides/textautofittype). |
| [`column_count`](/slides/python-net/ja/aspose.slides/itextframeformateffectivedata/column_count/) | バウンディング矩形内のテキスト列数を指定します。<br/>            読み取り専用 **int**. |
| [`column_spacing`](/slides/python-net/ja/aspose.slides/itextframeformateffectivedata/column_spacing/) | テキスト領域内のテキスト列間のスペース（ポイント）を指定します。<br/>            読み取り専用 **float**. |

### 備考

このインターフェイスは [`ITextFrameFormat`](/slides/python-net/ja/aspose.slides/itextframeformat) インターフェイスと併用して、継承が適用された効果的な書式設定値を返すために使用されます。
