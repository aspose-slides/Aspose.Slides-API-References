## IInterruptionTokenSource クラス

[`IInterruptionToken`](/slides/python-net/ja/aspose.slides/iinterruptiontoken) のソースを表します。

IInterruptionTokenSource 型は次のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`token`](/slides/python-net/ja/aspose.slides/iinterruptiontokensource/token/) | この [`IInterruptionTokenSource`](/slides/python-net/ja/aspose.slides/iinterruptiontokensource) にバインドされた新しいトークンを返します。 |
| [`is_interruption_requested`](/slides/python-net/ja/aspose.slides/iinterruptiontokensource/is_interruption_requested/) | 割り込みが要求された場合は true を、そうでない場合は false を返します。 |
