## PlaceholderType 列挙型

プレースホルダーの種類を表します。

PlaceholderType 型は次のメンバーを公開します：

## フィールド

| フィールド | 説明 |
| :- | :- |
| TITLE | タイトル。 |
| BODY | 本文。 |
| CENTERED_TITLE | 中央揃えタイトル。 |
| SUBTITLE | サブタイトル。 |
| DATE_AND_TIME | 日付と時刻。 |
| SLIDE_NUMBER | スライド番号。 |
| FOOTER | フッター。 |
| HEADER | ヘッダー。 |
| OBJECT | オブジェクト。 |
| CHART | チャート。 |
| TABLE | テーブル。 |
| CLIP_ART | クリップアート。 |
| DIAGRAM | 図。 |
| MEDIA | メディア。 |
| SLIDE_IMAGE | スライド画像。 |
| PICTURE | 画像。 |
