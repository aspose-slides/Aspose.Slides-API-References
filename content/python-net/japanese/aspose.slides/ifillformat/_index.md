## IFillFormat クラス

塗りつぶしの書式設定オプションを表します。

IFillFormat 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`fill_type`](/slides/python-net/ja/aspose.slides/ifillformat/fill_type/) | 塗りつぶしのタイプを取得または設定します。<br/>            読み取り/書き込み [`FillType`](/slides/python-net/ja/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/ja/aspose.slides/ifillformat/solid_fill_color/) | 塗りつぶしの色を取得します。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat). |
| [`gradient_format`](/slides/python-net/ja/aspose.slides/ifillformat/gradient_format/) | グラデーション塗りつぶし形式を取得します。<br/>            読み取り専用 [`IGradientFormat`](/slides/python-net/ja/aspose.slides/igradientformat). |
| [`pattern_format`](/slides/python-net/ja/aspose.slides/ifillformat/pattern_format/) | パターン塗りつぶし形式を取得します。<br/>            読み取り専用 [`IPatternFormat`](/slides/python-net/ja/aspose.slides/ipatternformat). |
| [`picture_fill_format`](/slides/python-net/ja/aspose.slides/ifillformat/picture_fill_format/) | 画像塗りつぶし形式を取得します。<br/>            読み取り専用 [`IPictureFillFormat`](/slides/python-net/ja/aspose.slides/ipicturefillformat). |
| [`rotate_with_shape`](/slides/python-net/ja/aspose.slides/ifillformat/rotate_with_shape/) | 塗りつぶしをシェイプと共に回転させるかどうかを決定します。<br/>            読み取り/書き込み [`NullableBool`](/slides/python-net/ja/aspose.slides/nullablebool). |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`get_effective(self)`](/slides/python-net/ja/aspose.slides/ifillformat/get_effective/#) | 継承が適用された有効な塗りつぶし書式設定データを取得します。 |
