## ShapeStyle クラス

シェイプのスタイル参照を表します。

ShapeStyle 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`line_color`](/slides/python-net/ja/aspose.slides/shapestyle/line_color/) | シェイプの輪郭色を返します。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat)。 |
| [`line_style_index`](/slides/python-net/ja/aspose.slides/shapestyle/line_style_index/) | スタイル マトリックス内の線の列インデックスを取得または設定します。<br/>            読み書き **int**。 |
| [`fill_color`](/slides/python-net/ja/aspose.slides/shapestyle/fill_color/) | シェイプの塗りつぶし色を返します。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat)。 |
| [`fill_style_index`](/slides/python-net/ja/aspose.slides/shapestyle/fill_style_index/) | スタイル マトリックスにおけるシェイプの塗りつぶし列インデックスを取得または設定します。<br/>            0 は塗りつぶしなし、<br/>            正の値 - テーマの塗りつぶしスタイルのインデックス、<br/>            負の値 - テーマの背景スタイルのインデックス。<br/>            読み書き **int**。 |
| [`effect_color`](/slides/python-net/ja/aspose.slides/shapestyle/effect_color/) | シェイプのエフェクト色を返します。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat)。 |
| [`effect_style_index`](/slides/python-net/ja/aspose.slides/shapestyle/effect_style_index/) | スタイル マトリックスにおけるシェイプのエフェクト列インデックスを取得または設定します。<br/>            読み書き **int**。 |
| [`font_color`](/slides/python-net/ja/aspose.slides/shapestyle/font_color/) | シェイプのフォント色を返します。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat)。 |
| [`font_collection_index`](/slides/python-net/ja/aspose.slides/shapestyle/font_collection_index/) | フォント コレクション内のシェイプのフォントインデックスを取得または設定します。<br/>            読み書き [`FontCollectionIndex`](/slides/python-net/ja/aspose.slides/fontcollectionindex)。 |
