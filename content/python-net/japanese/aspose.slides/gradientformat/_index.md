## GradientFormat クラス

グラデーション形式を表します。

**継承:**[`GradientFormat`](/slides/python-net/ja/aspose.slides/gradientformat) → [`PVIObject`](/slides/python-net/ja/aspose.slides/pviobject)

GradientFormat 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`tile_flip`](/slides/python-net/ja/aspose.slides/gradientformat/tile_flip/) | グラデーションのフリッピングモードを取得または設定します。<br/>            読み取り/書き込み [`TileFlip`](/slides/python-net/ja/aspose.slides/tileflip)。 |
| [`gradient_direction`](/slides/python-net/ja/aspose.slides/gradientformat/gradient_direction/) | グラデーションのスタイルを取得または設定します。<br/>            読み取り/書き込み [`GradientDirection`](/slides/python-net/ja/aspose.slides/gradientdirection)。 |
| [`linear_gradient_angle`](/slides/python-net/ja/aspose.slides/gradientformat/linear_gradient_angle/) | グラデーションの角度を取得または設定します。<br/>            読み取り/書き込み **float**. |
| [`linear_gradient_scaled`](/slides/python-net/ja/aspose.slides/gradientformat/linear_gradient_scaled/) | グラデーションがスケーリングされるかどうかを決定します。<br/>            読み取り/書き込み [`NullableBool`](/slides/python-net/ja/aspose.slides/nullablebool). |
| [`gradient_shape`](/slides/python-net/ja/aspose.slides/gradientformat/gradient_shape/) | グラデーションの形状を取得または設定します。<br/>            読み取り/書き込み [`GradientShape`](/slides/python-net/ja/aspose.slides/gradientshape). |
| [`gradient_stops`](/slides/python-net/ja/aspose.slides/gradientformat/gradient_stops/) | グラデーションストップのコレクションを取得します。<br/>            読み取り専用 [`IGradientStopCollection`](/slides/python-net/ja/aspose.slides/igradientstopcollection). |
