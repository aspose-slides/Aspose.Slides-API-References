## IThreeDFormatEffectiveData クラス

効果的な 3-D 書式設定プロパティを表す不変オブジェクトです。

IThreeDFormatEffectiveData 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`contour_width`](/slides/python-net/ja/aspose.slides/ithreedformateffectivedata/contour_width/) | 3D 輪郭の幅を取得します。<br/>            読み取り専用 **float**. |
| [`extrusion_height`](/slides/python-net/ja/aspose.slides/ithreedformateffectivedata/extrusion_height/) | 押し出し効果の高さを取得します。<br/>            読み取り専用 **float**. |
| [`depth`](/slides/python-net/ja/aspose.slides/ithreedformateffectivedata/depth/) | 3D 形状の奥行きを取得します。<br/>            読み取り専用 **float**. |
| [`bevel_top`](/slides/python-net/ja/aspose.slides/ithreedformateffectivedata/bevel_top/) | 上部 3D ベベルのタイプを取得します。<br/>            読み取り専用 [`IShapeBevelEffectiveData`](/slides/python-net/ja/aspose.slides/ishapebeveleffectivedata). |
| [`bevel_bottom`](/slides/python-net/ja/aspose.slides/ithreedformateffectivedata/bevel_bottom/) | 下部 3D ベベルのタイプを取得します。<br/>            読み取り専用 [`IShapeBevelEffectiveData`](/slides/python-net/ja/aspose.slides/ishapebeveleffectivedata). |
| [`contour_color`](/slides/python-net/ja/aspose.slides/ithreedformateffectivedata/contour_color/) | 輪郭の色を取得します。<br/>            読み取り専用 **aspose.slides.Color**. |
| [`extrusion_color`](/slides/python-net/ja/aspose.slides/ithreedformateffectivedata/extrusion_color/) | 押し出しの色を取得します。<br/>            読み取り専用 **aspose.slides.Color**. |
| [`camera`](/slides/python-net/ja/aspose.slides/ithreedformateffectivedata/camera/) | カメラの設定を取得します。<br/>            読み取り専用 [`ICameraEffectiveData`](/slides/python-net/ja/aspose.slides/icameraeffectivedata). |
| [`light_rig`](/slides/python-net/ja/aspose.slides/ithreedformateffectivedata/light_rig/) | ライトのタイプを取得します。<br/>            読み取り専用 [`ILightRigEffectiveData`](/slides/python-net/ja/aspose.slides/ilightrigeffectivedata). |
| [`material`](/slides/python-net/ja/aspose.slides/ithreedformateffectivedata/material/) | マテリアルのタイプを取得します。<br/>            読み取り専用 [`MaterialPresetType`](/slides/python-net/ja/aspose.slides/materialpresettype). |

### 備考

このインターフェイスは [`IThreeDFormat`](/slides/python-net/ja/aspose.slides/ithreedformat) インターフェイスと組み合わせて使用し、継承が適用された効果的な書式設定値を返します。
