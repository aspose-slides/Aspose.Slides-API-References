## IThreeDFormatEffectiveData クラス

有効な3-D書式プロパティを表す不変オブジェクトです。

IThreeDFormatEffectiveData 型は以下のメンバーを公開します。

## プロパティ

| Property | Description |
| :- | :- |
| [`contour_width`](/slides/python-net/ja/aspose.slides/ithreedformateffectivedata/contour_width/) | 3D輪郭の幅を返します。<br/>            読み取り専用 **float**. |
| [`extrusion_height`](/slides/python-net/ja/aspose.slides/ithreedformateffectivedata/extrusion_height/) | 押し出し効果の高さを返します。<br/>            読み取り専用 **float**. |
| [`depth`](/slides/python-net/ja/aspose.slides/ithreedformateffectivedata/depth/) | 3D形状の深さを返します。<br/>            読み取り専用 **float**. |
| [`bevel_top`](/slides/python-net/ja/aspose.slides/ithreedformateffectivedata/bevel_top/) | 上部3Dベベルの種類を返します。<br/>            読み取り専用 [`IShapeBevelEffectiveData`](/slides/python-net/ja/aspose.slides/ishapebeveleffectivedata). |
| [`bevel_bottom`](/slides/python-net/ja/aspose.slides/ithreedformateffectivedata/bevel_bottom/) | 下部3Dベベルの種類を返します。<br/>            読み取り専用 [`IShapeBevelEffectiveData`](/slides/python-net/ja/aspose.slides/ishapebeveleffectivedata). |
| [`contour_color`](/slides/python-net/ja/aspose.slides/ithreedformateffectivedata/contour_color/) | 輪郭の色を返します。<br/>            読み取り専用 [`Color`](/slides/python-net/ja/aspose.slides/color). |
| [`extrusion_color`](/slides/python-net/ja/aspose.slides/ithreedformateffectivedata/extrusion_color/) | 押し出しの色を返します。<br/>            読み取り専用 [`Color`](/slides/python-net/ja/aspose.slides/color). |
| [`camera`](/slides/python-net/ja/aspose.slides/ithreedformateffectivedata/camera/) | カメラの設定を返します。<br/>            読み取り専用 [`ICameraEffectiveData`](/slides/python-net/ja/aspose.slides/icameraeffectivedata). |
| [`light_rig`](/slides/python-net/ja/aspose.slides/ithreedformateffectivedata/light_rig/) | 光源の種類を返します。<br/>            読み取り専用 [`ILightRigEffectiveData`](/slides/python-net/ja/aspose.slides/ilightrigeffectivedata). |
| [`material`](/slides/python-net/ja/aspose.slides/ithreedformateffectivedata/material/) | 材料の種類を返します。<br/>            読み取り専用 [`MaterialPresetType`](/slides/python-net/ja/aspose.slides/materialpresettype). |

### 備考

このインターフェイスは [`IThreeDFormat`](/slides/python-net/ja/aspose.slides/ithreedformat) インターフェイスと組み合わせて使用され、継承が適用された有効な書式設定値を返します。
