## IAdjustValue クラス

ジオメトリ形状の調整値を表します。
これらの値は形状の形状に影響します。

IAdjustValue 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`raw_value`](/slides/python-net/ja/aspose.slides/iadjustvalue/raw_value/) | 調整値をそのまま取得または設定します。<br/>Read/write **int**. |
| [`angle_value`](/slides/python-net/ja/aspose.slides/iadjustvalue/angle_value/) | 値を取得または設定します（角度（度）として解釈）。<br/>Read/write **float**. |
| [`name`](/slides/python-net/ja/aspose.slides/iadjustvalue/name/) | この調整値の名前を取得します。<br/>Read-only **str**. |
| [`type`](/slides/python-net/ja/aspose.slides/iadjustvalue/type/) | 形状の調整のタイプを取得します。<br/>Read-only [`ShapeAdjustmentType`](/slides/python-net/ja/aspose.slides/shapeadjustmenttype). |
