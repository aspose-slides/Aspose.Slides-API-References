## SlideLayoutType 列挙型

スライドレイアウトの種類を表します。

SlideLayoutType 型は次のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| CUSTOM | カスタム |
| TITLE | タイトル |
| TEXT | テキスト |
| TWO_COLUMN_TEXT | 2 列テキスト |
| TABLE | テーブル |
| TEXT_AND_CHART | テキストとチャート |
| CHART_AND_TEXT | チャートとテキスト |
| DIAGRAM | 図 |
| CHART | チャート |
| TEXT_AND_CLIP_ART | テキストとクリップアート |
| CLIP_ART_AND_TEXT | クリップアートとテキスト |
| TITLE_ONLY | タイトルのみ |
| BLANK | 空白 |
| TEXT_AND_OBJECT | テキストとオブジェクト |
| OBJECT_AND_TEXT | オブジェクトとテキスト |
| OBJECT | オブジェクト |
| TITLE_AND_OBJECT | タイトルとオブジェクト |
| TEXT_AND_MEDIA | テキストとメディア |
| MEDIA_AND_TEXT | メディアとテキスト |
| OBJECT_OVER_TEXT | テキスト上のオブジェクト |
| TEXT_OVER_OBJECT | オブジェクト上のテキスト |
| TEXT_AND_TWO_OBJECTS | テキストと2 オブジェクト |
| TWO_OBJECTS_AND_TEXT | 2 オブジェクトとテキスト |
| TWO_OBJECTS_OVER_TEXT | テキスト上の2 オブジェクト |
| FOUR_OBJECTS | 4 オブジェクト |
| VERTICAL_TEXT | 縦書きテキスト |
| CLIP_ART_AND_VERTICAL_TEXT | クリップアートと縦書きテキスト |
| VERTICAL_TITLE_AND_TEXT | 縦書きタイトルとテキスト |
| VERTICAL_TITLE_AND_TEXT_OVER_CHART | 縦書きタイトルとテキスト（チャート上） |
| TWO_OBJECTS | 2 オブジェクト |
| OBJECT_AND_TWO_OBJECT | オブジェクトと2 オブジェクト |
| TWO_OBJECTS_AND_OBJECT | 2 オブジェクトとオブジェクト |
| SECTION_HEADER | セクションヘッダー |
| TWO_TEXT_AND_TWO_OBJECTS | 2 テキストと2 オブジェクト |
| TITLE_OBJECT_AND_CAPTION | タイトル、オブジェクト、キャプション |
| PICTURE_AND_CAPTION | 画像とキャプション |
