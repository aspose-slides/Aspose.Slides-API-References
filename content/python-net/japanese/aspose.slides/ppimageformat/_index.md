## PPImageFormat 列挙体

画像フォーマット。この列挙体は `System.Drawing.Imaging.ImageFormat` クラスの置き換えです。COM 互換性のために必要です。

PPImageFormat 型は次のメンバーを公開します:

## フィールド

| フィールド | 説明 |
| :- | :- |
| BMP | ビットマップ（BMP）画像形式を取得します。 |
| EMF | 拡張メタファイル（EMF）画像形式を取得します。 |
| EXIF | 交換可能画像ファイル（Exif）形式を取得します。 |
| GIF | グラフィック交換形式（GIF）画像形式を取得します。 |
| ICON | Windows アイコン画像形式を取得します。 |
| JPEG | Joint Photographic Experts Group（JPEG）画像形式を取得します。 |
| MEMORY_BMP | メモリ内のビットマップ形式を取得します。 |
| PNG | W3C ポータブルネットワークグラフィックス（PNG）画像形式を取得します。 |
| TIFF | タグ付け画像ファイル形式（TIFF）画像形式を取得します。 |
| WMF | Windows メタファイル（WMF）画像形式を取得します。 |
