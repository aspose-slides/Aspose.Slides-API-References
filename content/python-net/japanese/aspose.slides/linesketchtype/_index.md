## LineSketchType 列挙型

シェイプに割り当てられたスケッチタイプまたは効果を表します。

LineSketchType 型は次のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| NOT_DEFINED | シェイプの Sketch 効果が未定義であることを指定します。 |
| NONE | シェイプに Sketch 効果がないことを指定します。これはこのプロパティが空であるのと同等です。 |
| CURVED | シェイプに CURVED 効果があることを指定します。この効果はシェイプの各エッジを大きくて緩やかな曲線に変換します。 |
| FREEHAND | シェイプに FREEHAND 効果があることを指定します。この効果は不完全に描かれた線に最も近い外観です。 |
| SCRIBBLE | シェイプに SCRIBBLE 効果があることを指定します。この効果は意図的に乱雑に描かれたかのように、誇張された揺れを持ちます。 |
