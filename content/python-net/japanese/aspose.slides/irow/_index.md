## IRow クラス

テーブル内の行を表します。

IRow 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`height`](/slides/python-net/ja/aspose.slides/irow/height/) | 行の高さを返します。<br/>            読み取り専用 **float**. |
| [`minimal_height`](/slides/python-net/ja/aspose.slides/irow/minimal_height/) | 行の最小可能高さを取得または設定します。<br/>            読み書き可能 **float**. |
| [`row_format`](/slides/python-net/ja/aspose.slides/irow/row_format/) | この行の書式設定プロパティを含む RowFormat オブジェクトを返します。<br/>            読み取り専用 [`IRowFormat`](/slides/python-net/ja/aspose.slides/irowformat). |
