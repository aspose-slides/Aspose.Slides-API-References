## SlideShowSettings クラス

プレゼンテーションのスライドショー設定を表します。

SlideShowSettings 型は次のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`slide_show_type`](/slides/python-net/ja/aspose.slides/slideshowsettings/slide_show_type/) | スライドショーのタイプを取得または設定します。次の [`SlideShowSettings.slide_show_type`](/slides/python-net/ja/aspose.slides/slideshowsettings/slide_show_type) 祖先で表されます: [`BrowsedAtKiosk`](/slides/python-net/ja/aspose.slides/browsedatkiosk), [`PresentedBySpeaker`](/slides/python-net/ja/aspose.slides/presentedbyspeaker) および [`BrowsedByIndividual`](/slides/python-net/ja/aspose.slides/browsedbyindividual) |
| [`loop`](/slides/python-net/ja/aspose.slides/slideshowsettings/loop/) | スライドショーをループ |
| [`show_narration`](/slides/python-net/ja/aspose.slides/slideshowsettings/show_narration/) | スライドショーでナレーションを表示 |
| [`show_animation`](/slides/python-net/ja/aspose.slides/slideshowsettings/show_animation/) | スライドショーでアニメーションを表示 |
| [`pen_color`](/slides/python-net/ja/aspose.slides/slideshowsettings/pen_color/) | スライドショーのペンの色 |
| [`slides`](/slides/python-net/ja/aspose.slides/slideshowsettings/slides/) | スライドの範囲 |
| [`use_timings`](/ja/slides/python-net/aspose.slides/slideshowsettings/use_timings/) | スライドショーでタイミングを使用 |
| [`show_media_controls`](/slides/python-net/ja/aspose.slides/slideshowsettings/show_media_controls/) | メディアコントロールを表示 |
