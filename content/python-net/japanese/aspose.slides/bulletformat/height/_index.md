## height プロパティ
継承されていない段落の箇条書きの height を取得または設定します。
            値 float.NaN は、箇条書きが段落の最初の部分から height を継承することを示します。
            読み書き **float**。


### 備考

負の height 値は、height がポイントで指定されていることを意味し、正の値は周囲のテキストに対するパーセンテージであることを意味します。
