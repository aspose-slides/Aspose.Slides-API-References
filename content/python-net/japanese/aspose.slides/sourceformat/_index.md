## SourceFormat 列挙体

ソースファイル形式を表します。

SourceFormat 型は次のメンバーを公開します:

## フィールド

| フィールド | 説明 |
| :- | :- |
| PPT | Microsoft PowerPoint 97-2003 プレゼンテーション (*.ppt). |
| PPTX | Microsoft Office Open XML プレゼンテーション (*.pptx). |
| ODP | OpenDocument プレゼンテーション (*.odp). |
| PPTM | Microsoft Office Open XML マクロ有効プレゼンテーション (*.pptm). |
| PPSX | Microsoft Office Open XML スライドショー (*.ppsx). |
| PPSM | Microsoft Office Open XML マクロ有効スライドショー (*.ppsm). |
| POTX | Microsoft Office Open XML テンプレート (*.potx). |
| POTM | Microsoft Office Open XML マクロ有効テンプレート (*.potm). |
| PPS | Microsoft PowerPoint 97-2003 スライドショー (*.pps). |
| POT | Microsoft PowerPoint 97-2003 テンプレート (*.pot). |
| OTP | OpenDocument プレゼンテーションテンプレート (*.otp). |
| FODP | Flat XML ODF プレゼンテーション (*.fodp). |
| XML | PowerPoint XML プレゼンテーション (*.xml). |
