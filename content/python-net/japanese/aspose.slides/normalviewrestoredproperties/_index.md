## NormalViewRestoredProperties クラス

スライド領域のサイズ指定を行います（通常ビューの (restoredTop の子の場合は幅、restoredLeft の子の場合は高さ) が可変の復元サイズ（最小化でも最大化でもない）である場合）。

NormalViewRestoredProperties 型は以下のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`dimension_size`](/slides/python-net/ja/aspose.slides/normalviewrestoredproperties/dimension_size/) | スライド領域のサイズを指定します（RestoredTop の子の場合は幅、RestoredLeft の子の場合は高さ）。<br/>            Read/write **float**. |
| [`auto_adjust`](/slides/python-net/ja/aspose.slides/normalviewrestoredproperties/auto_adjust/) | サイドコンテンツ領域のサイズが、新しいサイズを補正すべきかどうかを指定します<br/>            ウィンドウ内でビューを含むアプリケーションのウィンドウをリサイズする際に<br/>            Read/write **bool**. |
