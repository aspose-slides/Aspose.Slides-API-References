## CellCollection クラス

CellCollection のコレクションを表します。

CellCollection 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`slide`](/slides/python-net/ja/aspose.slides/cellcollection/slide/) | CellCollection の親スライドを返します。<br/>            読み取り専用 [`IBaseSlide`](/slides/python-net/ja/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/ja/aspose.slides/cellcollection/presentation/) | CellCollection の親プレゼンテーションを返します。<br/>            読み取り専用 [`IPresentation`](/slides/python-net/ja/aspose.slides/ipresentation). |

Cell をその位置で返します。
            読み取り専用 [`Cell`](/slides/python-net/ja/aspose.slides/cell).
