## ImageWrapper クラス

COM インターフェイス用の System.Drawing.Image ラッパーです。

ImageWrapper 型は以下のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`image_source`](/slides/python-net/ja/aspose.slides/imagewrapper/image_source/) | Image を取得します。<br/>            読み取り専用 [`IImage`](/slides/python-net/ja/aspose.slides/iimage). |
| [`size`](/slides/python-net/ja/aspose.slides/imagewrapper/size/) | Image の幅と高さ（ピクセル単位）を取得します。<br/>            読み取り専用 [`ImageWrapper.size`](/slides/python-net/ja/aspose.slides/imagewrapper/size). |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`save(self, file_name)`](/slides/python-net/ja/aspose.slides/imagewrapper/save/#str) | 指定されたファイルに Image を保存します |
| [`save(self, stream, image_format)`](/slides/python-net/ja/aspose.slides/imagewrapper/save/#iorawiobase-ppimageformat) | 指定された形式で、指定されたストリームに Image を保存します。 |
| [`save(self, file_name, image_format)`](/slides/python-net/ja/aspose.slides/imagewrapper/save/#str-ppimageformat) | 指定された形式で、指定されたファイルに Image を保存します。 |
