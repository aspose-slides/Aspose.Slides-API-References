## IHeadingPair クラス

ドキュメントの 'Heading pair' プロパティを表します。  
ドキュメント パーツのグループ名と、グループ内のパーツ数を示します。

IHeadingPair 型は以下のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`name`](/slides/python-net/ja/aspose.slides/iheadingpair/name/) | ドキュメント パーツのグループ名を返します。<br/>            読み取り専用 **str**. |
| [`count`](/slides/python-net/ja/aspose.slides/iheadingpair/count/) | グループ内のパーツ数を返します。<br/>            読み取り専用 **int**. |
