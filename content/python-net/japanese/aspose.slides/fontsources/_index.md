## FontSources クラス

外部フォントのファイルおよびメモリ ソースを提供します。

FontSources 型は次のメンバーを公開します。

## コンストラクタ

| コンストラクタ | 説明 |
| :- | :- |
| [`__init__(self)`](/slides/python-net/ja/aspose.slides/fontsources/__init__/#) | 新しいデフォルト フォント オプションを作成します。 |

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`font_folders`](/slides/python-net/ja/aspose.slides/fontsources/font_folders/) | フォント ファイルを含むフォルダー。<br/>            これらのフォルダーにあるすべてのフォント ファイルがコレクションに含まれます。再帰的に検索されるフォルダー。 |
| [`memory_fonts`](/slides/python-net/ja/aspose.slides/fontsources/memory_fonts/) | バイト配列として表現されたフォントのコレクション。 |
