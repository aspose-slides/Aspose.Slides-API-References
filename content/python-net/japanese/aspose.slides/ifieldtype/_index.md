## IFieldType クラス

フィールドのタイプを表します。 
            この値は、フィールド部分が更新される際に設定されるテキストを決定します。

IFieldType タイプは以下のメンバーを公開します。

## プロパティ

| Property | Description |
| :- | :- |
| [`internal_string`](/slides/python-net/ja/aspose.slides/ifieldtype/internal_string/) | この FieldTypeEx オブジェクトの内部名を返します。<br/>            読み書き **str**. |
