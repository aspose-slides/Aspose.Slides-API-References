## Placeholder クラス

スライド上のプレースホルダーを表します。

Placeholder 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`orientation`](/slides/python-net/ja/aspose.slides/placeholder/orientation/) | プレースホルダーの向きを取得または設定します。<br/>            読み取り専用 [`Orientation`](/slides/python-net/ja/aspose.slides/orientation). |
| [`size`](/slides/python-net/ja/aspose.slides/placeholder/size/) | プレースホルダーのサイズを取得または設定します。<br/>            読み取り専用 [`PlaceholderSize`](/slides/python-net/ja/aspose.slides/placeholdersize). |
| [`type`](/slides/python-net/ja/aspose.slides/placeholder/type/) | プレースホルダーのタイプを取得または設定します。<br/>            読み取り専用 [`PlaceholderType`](/slides/python-net/ja/aspose.slides/placeholdertype). |
| [`index`](/slides/python-net/ja/aspose.slides/placeholder/index/) | プレースホルダーのインデックスを取得または設定します。<br/>            読み取り専用 **int**. |
