## ColorSchemeIndex 列挙

カラースキーム内のインデックスを表します。

ColorSchemeIndex 型は次のメンバーを公開します：

## フィールド

| フィールド | 説明 |
| :- | :- |
| DARK1 | 暗い 1。 |
| LIGHT1 | 明るい 1。 |
| DARK2 | 暗い 2。 |
| LIGHT2 | 明るい 2。 |
| ACCENT1 | アクセント 1。 |
| ACCENT2 | アクセント 2。 |
| ACCENT3 | アクセント 3。 |
| ACCENT4 | アクセント 4。 |
| ACCENT5 | アクセント 5。 |
| ACCENT6 | アクセント 6。 |
| HYPERLINK | ハイパーリンク。 |
| FOLLOWED_HYPERLINK | 訪問済みハイパーリンク。 |
