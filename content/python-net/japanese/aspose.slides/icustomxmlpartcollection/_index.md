## ICustomXmlPartCollection クラス

カスタム XML パートのコレクションを表します。

ICustomXmlPartCollection 型は次のメンバーを公開します。

指定されたインデックスの要素を返します。

## インデクサ

| 名前 | 説明 |
| :- | :- |
| [`[index]`](/slides/python-net/ja/aspose.slides/icustomxmlpartcollection/__getitem__/) | 取得する要素のゼロベースインデックスです。 |

| メソッド | 説明 |
| :- | :- |
| [`add(self, xml_data)`](/slides/python-net/ja/aspose.slides/icustomxmlpartcollection/add/#bytes) | 新しいカスタム XML パートを追加します。 |
| [`add(self, xml_string)`](/slides/python-net/ja/aspose.slides/icustomxmlpartcollection/add/#str) | 新しいカスタム XML パートを追加します。 |
| [`add(self, input_stream)`](/slides/python-net/ja/aspose.slides/icustomxmlpartcollection/add/#iorawiobase) | 新しいカスタム XML パートを追加します。 |
