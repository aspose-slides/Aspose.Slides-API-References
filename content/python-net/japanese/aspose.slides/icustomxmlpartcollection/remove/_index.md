## remove(self, item) {#icustomxmlpart}
コレクションから特定のオブジェクトの最初の出現を削除します。

### 戻り値

item が正常に削除された場合は `true`、それ以外の場合は `false` が返されます。



```python
def remove(self, item):
    ...
```


| パラメーター | 型 | 説明 |
| :- | :- | :- |
| item | [`ICustomXmlPart`](/slides/python-net/ja/aspose.slides/icustomxmlpart) | 削除するカスタム XML パートです。 |

### 例外

| 例外 | 説明 |
| :- | :- |
| **RuntimeError(Proxy error(ArgumentNullException))** | item は `None` です。 |
