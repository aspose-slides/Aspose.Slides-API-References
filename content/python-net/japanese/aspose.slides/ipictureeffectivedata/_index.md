## IPictureEffectiveData クラス

有効な画像プロパティを含む不変オブジェクトです。

IPictureEffectiveData 型は次のメンバーを公開します:

## プロパティ

| Property | Description |
| :- | :- |
| [`image`](/slides/python-net/ja/aspose.slides/ipictureeffectivedata/image/) | 埋め込まれた画像を返します。<br/>            読み取り専用 [`IPPImage`](/slides/python-net/ja/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/ja/aspose.slides/ipictureeffectivedata/link_path_long/) | リンクされた画像の URL を返します。<br/>            読み取り専用 **str**. |
| [`image_transform`](/slides/python-net/ja/aspose.slides/ipictureeffectivedata/image_transform/) | 画像変換エフェクトのコレクションを返します。<br/>            読み取り専用 [`IImageTransformOCollectionEffectiveData`](/slides/python-net/ja/aspose.slides.effects/iimagetransformocollectioneffectivedata). |


### 備考

このインターフェイスは [`IPictureFillFormatEffectiveData`](/slides/python-net/ja/aspose.slides/ipicturefillformateffectivedata) と [`IBulletFormatEffectiveData`](/slides/python-net/ja/aspose.slides/ibulletformateffectivedata) の一部として使用されます。
