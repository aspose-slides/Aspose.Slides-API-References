## ShapeFrame クラス

シェイプフレームのプロパティを表します。

ShapeFrame 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`x`](/slides/python-net/ja/aspose.slides/shapeframe/x/) | フレームの左上隅の X 座標を返します。<br/>            読み取り専用 **float**. |
| [`y`](/slides/python-net/ja/aspose.slides/shapeframe/y/) | フレームの左上隅の Y 座標を返します。<br/>            読み取り専用 **float**. |
| [`width`](/slides/python-net/ja/aspose.slides/shapeframe/width/) | フレームの幅を返します。<br/>            読み取り専用 **float**. |
| [`height`](/slides/python-net/ja/aspose.slides/shapeframe/height/) | フレームの高さを返します。<br/>            読み取り専用 **float**. |
| [`rotation`](/slides/python-net/ja/aspose.slides/shapeframe/rotation/) | フレームが z 軸周りに回転した角度（度）を返します。<br/>            正の値は時計回りの回転を示し、負の値<br/>            は反時計回りの回転を示します。<br/>            読み取り専用 **float**. |
| [`center_x`](/slides/python-net/ja/aspose.slides/shapeframe/center_x/) | フレームの中心の X 座標を返します。<br/>            読み取り専用 **float**. |
| [`center_y`](/slides/python-net/ja/aspose.slides/shapeframe/center_y/) | フレームの中心の Y 座標を返します。<br/>            読み取り専用 **float**. |
| [`flip_h`](/slides/python-net/ja/aspose.slides/shapeframe/flip_h/) | フレームが水平に反転されているかどうかを判断します。<br/>            読み取り専用 [`NullableBool`](/slides/python-net/ja/aspose.slides/nullablebool). |
| [`flip_v`](/slides/python-net/ja/aspose.slides/shapeframe/flip_v/) | フレームが垂直に反転されているかどうかを判断します。<br/>            読み取り専用 [`NullableBool`](/slides/python-net/ja/aspose.slides/nullablebool). |
| [`rectangle`](/slides/python-net/ja/aspose.slides/shapeframe/rectangle/) | フレームの座標を返します。<br/>            読み取り専用 [`RectangleF`](/slides/python-net/ja/aspose.slides/rectanglef). |
