## ShapeAdjustmentType 列挙型

シェイプの調整値のさまざまなタイプを指定します。

ShapeAdjustmentType 型は以下のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| CUSTOM | カスタムタイプ（不明な調整） |
| CORNER_SIZE | コーナーのサイズを制御します。 |
| LEFT_UP_CORNER | 左上コーナーを制御します。 |
| RIGHT_UP_CORNER | 右上コーナーを制御します。 |
| UP_CORNERS | 上部のコーナーを制御します。 |
| DOWN_CORNERS | 下部のコーナーを制御します。 |
| THICKNESS | 図形の厚さを制御します。 |
| ARROW_TAIL_THICKNESS | 矢じりの太さを制御します。 |
| ARROWHEAD_LENGTH | 矢じりの長さを制御します。 |
| ARROWHEAD_WIDTH | 矢じりの幅を制御します。 |
| RADIUS | シェイプまたはその部分の半径のサイズを制御します。 |
| DEPTH | 歯車の歯の深さまたはベベル効果を制御します。 |
| SHAPE_PART_OFFSET | 図形のある部分と別の部分とのオフセットを制御します。 |
| ANGLE | 図形またはその部分の角度を制御します。 |
| START_ANGLE | 円グラフや円弧形状の開始角度。 |
| END_ANGLE | 円グラフや円弧形状の終了角度。 |
| START_POINT_X | コールアウトの開始点 X 位置を制御します。 |
| START_POINT_Y | コールアウトの開始点 Y 位置を制御します。 |
| CONNECTOR_POINT_1X | コールアウト角度調整ポイントの水平位置を制御します。 |
| CONNECTOR_POINT_1Y | コールアウト角度調整ポイントの垂直位置を制御します。 |
| CONNECTOR_POINT_2X | コールアウト角度調整ポイントの水平位置を制御します。 |
| CONNECTOR_POINT_2Y | コールアウト角度調整ポイントの垂直位置を制御します。 |
| CONNECTOR_BEND_POSITION_X | コネクタの曲がりの水平位置を制御します。 |
| CONNECTOR_BEND_POSITION_Y | コネクタの曲がりの垂直位置を制御します。 |
| ATTACH_Y | 図形の垂直方向の接続点を制御します。 |
| ATTACH_X | 図形の水平方向の接続点を制御します。 |
| CALLOUT_HEIGHT | コールアウトの垂直サイズを制御します。 |
| CALLOUT_WIDTH | コールアウトの水平サイズを制御します。 |
| CALLOUT_SIZE | コールアウトのサイズを制御します。 |
| CURVATURE | 曲がった線、ブレース、曲線矢印またはシェイプの曲率。 |
| HORIZONTAL_THICKNESS | コーナーシェイプの水平厚さを制御します。 |
| VERTICAL_THICKNESS | コーナーシェイプの垂直厚さを制御します。 |
| VERTICAL_SIZE | シェイプの垂直サイズを制御します。 |
| HORIZONTAL_SIZE | シェイプの水平サイズを制御します。 |
| TOP | シェイプの上側を制御します。 |
