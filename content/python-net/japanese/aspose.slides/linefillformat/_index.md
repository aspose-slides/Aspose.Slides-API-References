## LineFillFormat クラス

**継承:**[`LineFillFormat`](/slides/python-net/ja/aspose.slides/linefillformat) → [`PVIObject`](/slides/python-net/ja/aspose.slides/pviobject)

LineFillFormat 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`fill_type`](/slides/python-net/ja/aspose.slides/linefillformat/fill_type/) | 塗りつぶしのタイプを取得または設定します。<br/>            読み書き可能 [`FillType`](/slides/python-net/ja/aspose.slides/filltype). |
| [`rotate_with_shape`](/slides/python-net/ja/aspose.slides/linefillformat/rotate_with_shape/) | 塗りつぶしをシェイプと一緒に回転させるかどうかを決定します。<br/>            読み書き可能 [`NullableBool`](/slides/python-net/ja/aspose.slides/nullablebool). |
