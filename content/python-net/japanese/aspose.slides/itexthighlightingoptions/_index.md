## ITextHighlightingOptions クラス

テキスト フレーム内のテキストをハイライトするために使用できるオプションを表します。

ITextHighlightingOptions 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`case_sensitive`](/slides/python-net/ja/aspose.slides/itexthighlightingoptions/case_sensitive/) | true を設定すると大文字と小文字を区別した検索を使用し、false を設定すると区別しません。<br/>            読み書き **bool**. |
| [`whole_words_only`](/slides/python-net/ja/aspose.slides/itexthighlightingoptions/whole_words_only/) | true を設定すると完全一致のみを検索し、false を設定すると部分一致も検索します。<br/>            読み書き **bool**. |
