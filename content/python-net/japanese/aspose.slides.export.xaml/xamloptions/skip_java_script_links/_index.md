## skip_java_script_links プロパティ
プレゼンテーションを保存するときに、JavaScript 呼び出しを含むハイパーリンクをスキップするかどうかを指定します。 
            読み書き **bool**. デフォルト値は **false** .


### 備考

このプロパティが **true** , JavaScript 呼び出しを含むハイパーリンクは保存時に無視されます。


このプロパティが **false** , すべてのハイパーリンクが保存されます。
