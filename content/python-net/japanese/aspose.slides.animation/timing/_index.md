## Timing クラス

アニメーションのタイミングを表します。

Timing 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`accelerate`](/slides/python-net/ja/aspose.slides.animation/timing/accelerate/) | 加速動作効果の継続時間のパーセンテージを示します。<br/>            読み書き **float**. |
| [`decelerate`](/slides/python-net/ja/aspose.slides.animation/timing/decelerate/) | 減速動作効果の継続時間のパーセンテージを示します。<br/>            読み書き **float**. |
| [`auto_reverse`](/slides/python-net/ja/aspose.slides.animation/timing/auto_reverse/) | 正方向に再生した後、アニメーションを自動的に逆方向で再生するかどうかを示します。<br/>            読み書き **bool**. |
| [`duration`](/slides/python-net/ja/aspose.slides.animation/timing/duration/) | アニメーション効果の継続時間を示します。<br/>            読み書き **float**. |
| [`repeat_count`](/slides/python-net/ja/aspose.slides.animation/timing/repeat_count/) | 効果を繰り返す回数を示します。<br/>            読み書き **float**. |
| [`repeat_until_end_slide`](/slides/python-net/ja/aspose.slides.animation/timing/repeat_until_end_slide/) | この属性は、効果がスライドの最後まで繰り返されるかどうかを指定します。<br/>            読み書き **bool**. |
| [`repeat_until_next_click`](/slides/python-net/ja/aspose.slides.animation/timing/repeat_until_next_click/) | この属性は、効果が次のクリックまで繰り返されるかどうかを指定します。<br/>            読み書き **bool**. |
| [`repeat_duration`](/slides/python-net/ja/aspose.slides.animation/timing/repeat_duration/) | 効果を繰り返す回数を示します。<br/>            読み書き **float**. |
| [`restart`](/slides/python-net/ja/aspose.slides.animation/timing/restart/) | 効果が完了した後に再開するかどうかを指定します。<br/>            読み書き [`EffectRestartType`](/slides/python-net/ja/aspose.slides.animation/effectrestarttype). |
| [`rewind`](/slides/python-net/ja/aspose.slides.animation/timing/rewind/) | この属性は、再生が完了したときに効果を巻き戻すかどうかを指定します。<br/>            読み書き **bool**. |
| [`speed`](/slides/python-net/ja/aspose.slides.animation/timing/speed/) | タイミングを速める（または遅くする）割合のパーセンテージを指定します。<br/>            読み書き **float**. |
| [`trigger_delay_time`](/slides/python-net/ja/aspose.slides.animation/timing/trigger_delay_time/) | トリガー後の遅延時間を示します。<br/>            読み書き **float**. |
| [`trigger_type`](/slides/python-net/ja/aspose.slides.animation/timing/trigger_type/) | トリガーの種類を示します。<br/>            読み書き [`EffectTriggerType`](/slides/python-net/ja/aspose.slides.animation/effecttriggertype). |
