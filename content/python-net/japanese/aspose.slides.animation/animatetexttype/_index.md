## AnimateTextType 列挙型

アニメーション効果のアニメートテキストタイプを表します。

AnimateTextType 型は次のメンバーを公開します。

## Fields

| フィールド | 説明 |
| :- | :- |
| ALL_AT_ONCE | テキストをすべて一度にアニメーションさせます。 |
| BY_WORD | テキストを単語単位でアニメーションさせます。 |
| BY_LETTER | テキストを文字単位でアニメーションさせます。 |
