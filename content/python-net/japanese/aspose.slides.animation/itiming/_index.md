## ITiming クラス

Represents animation timing.

The ITiming type exposes the following members:

## プロパティ

| Property | Description |
| :- | :- |
| [`accelerate`](/slides/python-net/ja/aspose.slides.animation/itiming/accelerate/) | 加速動作効果の期間のパーセンテージを記述します。<br/>            読み書き **float**. |
| [`decelerate`](/slides/python-net/ja/aspose.slides.animation/itiming/decelerate/) | 減速動作効果の期間のパーセンテージを記述します。<br/>            読み書き **float**. |
| [`auto_reverse`](/slides/python-net/ja/aspose.slides.animation/itiming/auto_reverse/) | 前方に再生した後、アニメーションを自動的に逆方向で再生するかどうかを記述します。<br/>            読み書き **bool**. |
| [`duration`](/slides/python-net/ja/aspose.slides.animation/itiming/duration/) | アニメーション効果の期間を記述します。<br/>            読み書き **float**. |
| [`repeat_count`](/slides/python-net/ja/aspose.slides.animation/itiming/repeat_count/) | エフェクトを繰り返す回数を記述します。<br/>            読み書き **float**. |
| [`repeat_until_end_slide`](/slides/python-net/ja/aspose.slides.animation/itiming/repeat_until_end_slide/) | この属性はエフェクトがスライドの最後まで繰り返されるかどうかを指定します。<br/>             読み書き **bool**. |

| [`restart`](/slides/python-net/ja/aspose.slides.animation/itiming/restart/) | 効果が完了した後に再開するかどうかを指定します。<br/>            読み書き [`EffectRestartType`](/slides/python-net/ja/aspose.slides.animation/effectrestarttype). |

| [`rewind`](/slides/python-net/ja/aspose.slides.animation/itiming/rewind/) | この属性はエフェクトの再生が完了したときに巻き戻すかどうかを指定します。<br/>             読み書き **bool**. |
