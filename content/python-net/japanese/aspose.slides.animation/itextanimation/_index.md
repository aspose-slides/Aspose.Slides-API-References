## ITextAnimation クラス

テキストアニメーションを表します。

ITextAnimation 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`build_type`](/slides/python-net/ja/aspose.slides.animation/itextanimation/build_type/) | テキストアニメーションのビルドタイプのリスト（例: Paragraph 1,2,3, All at Once）。<br/>            読み取り/書き込み [`ITextAnimation.build_type`](/slides/python-net/ja/aspose.slides.animation/itextanimation/build_type)。 |
| [`effect_animate_background_shape`](/slides/python-net/ja/aspose.slides.animation/itextanimation/effect_animate_background_shape/) | グループの有無にかかわらずリンクされたシェイプ効果（None）<br/>            読み取り/書き込み [`IEffect`](/slides/python-net/ja/aspose.slides.animation/ieffect)。 |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`add_effect(self, effect_type, subtype, trigger_type)`](/slides/python-net/ja/aspose.slides.animation/itextanimation/add_effect/#effecttype-effectsubtype-effecttriggertype) | 現在のシーケンスの末尾に新しいエフェクトを追加し、グループテキストアニメーションの末尾にします。<br/>            このグループのエフェクト数と同等またはそれ以上のテキスト段落数の場合のみ有効です！ |
