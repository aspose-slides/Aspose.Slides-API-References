## IBehavior クラス

エフェクトの基本クラスの動作を表します。

IBehavior 型は次のメンバーを公開します。

## プロパティ

| Property | Description |
| :- | :- |
| [`accumulate`](/slides/python-net/ja/aspose.slides.animation/ibehavior/accumulate/) | アニメーション ビヘイビアが蓄積されるかどうかを表します。<br/>            読み取り/書き込み [`NullableBool`](/slides/python-net/ja/aspose.slides/nullablebool). |
| [`additive`](/slides/python-net/ja/aspose.slides.animation/ibehavior/additive/) | 現在のアニメーション ビヘイビアが他の実行中アニメーションと結合されるかどうかを表します。<br/>            読み取り/書き込み [`BehaviorAdditiveType`](/slides/python-net/ja/aspose.slides.animation/behavioradditivetype). |
| [`properties`](/slides/python-net/ja/aspose.slides.animation/ibehavior/properties/) | ビヘイビアのプロパティを表します。<br/>            読み取り専用 [`IBehaviorPropertyCollection`](/slides/python-net/ja/aspose.slides.animation/ibehaviorpropertycollection). |
| [`timing`](/slides/python-net/ja/aspose.slides.animation/ibehavior/timing/) | エフェクト ビヘイビアのタイミングプロパティを表します。<br/>            読み取り/書き込み [`ITiming`](/slides/python-net/ja/aspose.slides.animation/itiming). |
