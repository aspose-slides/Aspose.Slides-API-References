## IBehaviorCollection クラス

動作効果のコレクションを表します。

IBehaviorCollection 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`count`](/slides/python-net/ja/aspose.slides.animation/ibehaviorcollection/count/) | コレクション内の動作の数を返します。<br/>            読み取り専用 **int**. |

指定したインデックスの動作を返します。

## インデクサー

| 名前 | 説明 |
| :- | :- |
| [`[index]`]( /slides/python-net/ja/aspose.slides.animation/ibehaviorcollection/__getitem__/ ) | 返す動作のインデックス。 |
