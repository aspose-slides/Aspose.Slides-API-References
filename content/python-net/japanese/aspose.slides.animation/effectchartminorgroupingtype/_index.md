## EffectChartMinorGroupingType 列挙体

チャートのシリーズまたはカテゴリ内の要素に対するアニメーション効果のタイプを表します。

EffectChartMinorGroupingType 型は以下のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| BY_ELEMENT_IN_SERIES | シリーズ内の要素ごとにチャートをアニメーション化 |
| BY_ELEMENT_IN_CATEGORY | カテゴリ内の要素ごとにチャートをアニメーション化 |
