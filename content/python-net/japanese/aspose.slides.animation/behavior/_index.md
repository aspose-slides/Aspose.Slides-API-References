## Behavior クラス

エフェクトの基本クラスの動作を表します。

Behavior 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`accumulate`](/slides/python-net/ja/aspose.slides.animation/behavior/accumulate/) | アニメーション動作が蓄積されるかどうかを表します。<br/>            読み書き [`NullableBool`](/slides/python-net/ja/aspose.slides/nullablebool). |
| [`additive`](/slides/python-net/ja/aspose.slides.animation/behavior/additive/) | 現在のアニメーション動作が他の実行中のアニメーションと結合されるかどうかを表します。<br/>            読み書き [`BehaviorAdditiveType`](/slides/python-net/ja/aspose.slides.animation/behavioradditivetype). |
| [`properties`](/slides/python-net/ja/aspose.slides.animation/behavior/properties/) | 動作のプロパティを表します。<br/>            読み取り専用 [`IBehaviorPropertyCollection`](/slides/python-net/ja/aspose.slides.animation/ibehaviorpropertycollection). |
| [`timing`](/slides/python-net/ja/aspose.slides.animation/behavior/timing/) | エフェクト動作のタイミングプロパティを表します。<br/>            読み書き [`ITiming`](/slides/python-net/ja/aspose.slides.animation/itiming). |
