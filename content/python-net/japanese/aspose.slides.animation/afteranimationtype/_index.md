## AfterAnimationType 列挙型

アニメーション効果の後のアニメーションタイプを表します。

AfterAnimationType 型は次のメンバーを公開します：

## フィールド

| フィールド | 説明 |
| :- | :- |
| DO_NOT_DIM | アニメーション後に暗くしません。 |
| COLOR | アニメーション後の色タイプです。 |
| HIDE_AFTER_ANIMATION | アニメーション後に非表示にするタイプです。 |
| HIDE_ON_NEXT_MOUSE_CLICK | 次のマウスクリックでアニメーション後に非表示にするタイプです。 |
