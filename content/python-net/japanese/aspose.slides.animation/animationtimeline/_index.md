## AnimationTimeLine クラス

アニメーションのタイムラインを表します。

AnimationTimeLine 型は以下のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`interactive_sequences`](/slides/python-net/ja/aspose.slides.animation/animationtimeline/interactive_sequences/) | インタラクティブシーケンスのコレクションを返します。<br/>            このシーケンスは、指定された対象シェイプによる「シェイプのクリック」効果のみを含むことができます。<br/>            読み取り専用 [`ISequenceCollection`](/slides/python-net/ja/aspose.slides.animation/isequencecollection). |
| [`main_sequence`](/slides/python-net/ja/aspose.slides.animation/animationtimeline/main_sequence/) | メインエフェクトコレクションのみを含む可能性があるメインシーケンスを返します。<br/>            読み取り専用 [`ISequence`](/slides/python-net/ja/aspose.slides.animation/isequence). |
| [`text_animation_collection`](/slides/python-net/ja/aspose.slides.animation/animationtimeline/text_animation_collection/) | テキストアニメーションのコレクションを返します。<br/>            読み取り専用 [`ITextAnimationCollection`](/slides/python-net/ja/aspose.slides.animation/itextanimationcollection). |
