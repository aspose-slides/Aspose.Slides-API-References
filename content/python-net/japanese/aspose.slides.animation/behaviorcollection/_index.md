## BehaviorCollection クラス

振る舞いエフェクトのコレクションを表します。

BehaviorCollection 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`count`](/slides/python-net/ja/aspose.slides.animation/behaviorcollection/count/) | コレクション内の振る舞いの数を返します。<br/>            読み取り専用 **int**. |
| [`is_read_only`](/slides/python-net/ja/aspose.slides.animation/behaviorcollection/is_read_only/) | **System.Collections.Generic.ICollection`1** が読み取り専用かどうかを示す値を取得します。<br/>            読み取り専用 **bool**. |

指定されたインデックスの振る舞いを返します。

## インデクサ

| 名前 | 説明 |
| :- | :- |
| [`[index]`](/slides/python-net/ja/aspose.slides.animation/behaviorcollection/__getitem__/) | 返す振る舞いのインデックス。 |
