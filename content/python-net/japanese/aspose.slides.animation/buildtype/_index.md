## BuildType 列挙型

アニメーション中にテキストがシェイプ上でどのように表示されるかを決定します。

BuildType 型は以下のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| AS_ONE_OBJECT | 含むシェイプと共に。 |
| ALL_PARAGRAPHS_AT_ONCE | すべての段落。 |
| BY_LEVEL_PARAGRAPHS1 | 深さ 1 の段落のグループごとに。 |
| BY_LEVEL_PARAGRAPHS2 | 深さ 2 の段落のグループごとに。 |
| BY_LEVEL_PARAGRAPHS3 | 深さ 3 の段落のグループごとに。 |
| BY_LEVEL_PARAGRAPHS4 | 深さ 4 の段落のグループごとに。 |
| BY_LEVEL_PARAGRAPHS5 | 深さ 5 の段落のグループごとに。 |
