## IMotionEffect クラス

エフェクトのモーション効果の動作を表します。

IMotionEffect 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`from_address`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/from_address/) | アニメーションの開始座標（％）となる x/y 座標を指定します。<br/>            読み書き **aspose.slides.PointF**. |
| [`to`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/to/) | アニメーションモーション効果の対象位置（％）を指定します。<br/>            読み書き **aspose.slides.PointF**. |
| [`by`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/by/) | アニメーションの相対オフセット値（％）を記述します。<br/>            読み書き **aspose.slides.PointF**. |
| [`rotation_center`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/rotation_center/) | X 角度でモーション パスを回転させる際に使用される回転の中心を記述します。<br/>            読み書き **aspose.slides.PointF**. |
| [`origin`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/origin/) | モーション パスの起点がスライドのレイアウトや親など、何に対して相対的かを指定します。<br/>            または、親。<br/>            読み書き [`MotionOriginType`](/slides/python-net/ja/aspose.slides.animation/motionorigintype). |
| [`path`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/path/) | アニメーションモーションの座標に続くパスのプリミティブを指定します。<br/>            読み書き [`IMotionPath`](/slides/python-net/ja/aspose.slides.animation/imotionpath). |
| [`path_edit_mode`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/path_edit_mode/) | シェイプが移動したときのモーション パスの動き方を指定します。<br/>            読み書き [`MotionPathEditMode`](/slides/python-net/ja/aspose.slides.animation/motionpatheditmode). |
| [`angle`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/angle/) | モーション パスの相対角度を記述します。<br/>            読み書き **float**. |
| [`accumulate`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/accumulate/) |  |
