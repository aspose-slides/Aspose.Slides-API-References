## IMotionEffect クラス

エフェクトのモーション効果の動作を表します。

IMotionEffect 型は次のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`from_`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/from_/) | アニメーションの開始位置となる x/y 座標を指定します（パーセンテージ）。 <br/>            読み取り/書き込み [`PointF`](/slides/python-net/ja/aspose.slides/pointf)。 |
| [`to`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/to/) | アニメーションのモーション効果の対象位置を指定します（パーセンテージ）。<br/>            読み取り/書き込み [`PointF`](/slides/python-net/ja/aspose.slides/pointf)。 |
| [`by`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/by/) | アニメーションの相対オフセット値を記述します（パーセンテージ）。<br/>            読み取り/書き込み [`PointF`](/slides/python-net/ja/aspose.slides/pointf)。 |
| [`rotation_center`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/rotation_center/) | モーションパスを X 角度で回転させる際に使用される回転の中心を記述します。<br/>            読み取り/書き込み [`PointF`](/slides/python-net/ja/aspose.slides/pointf)。 |
| [`origin`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/origin/) | モーションパスの基点がスライドのレイアウトや親など、何に対して相対的であるかを指定します。<br/>            読み取り/書き込み [`MotionOriginType`](/slides/python-net/ja/aspose.slides.animation/motionorigintype)。 |
| [`path`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/path/) | アニメーションモーションの座標に続くパスプリミティブを指定します。<br/>            読み取り/書き込み [`IMotionPath`](/slides/python-net/ja/aspose.slides.animation/imotionpath)。 |
| [`path_edit_mode`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/path_edit_mode/) | シェイプが移動したときにモーションパスがどのように動くかを指定します。<br/>            読み取り/書き込み [`MotionPathEditMode`](/slides/python-net/ja/aspose.slides.animation/motionpatheditmode)。 |
| [`angle`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/angle/) | モーションパスの相対角度を記述します。<br/>            読み取り/書き込み **float**. |
| [`accumulate`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/accumulate/) |  |
