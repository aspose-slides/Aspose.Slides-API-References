## IMotionEffect クラス

エフェクトのモーションエフェクトの動作を表します。

IMotionEffect 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`from_address`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/from_address/) | アニメーションの開始座標となる x/y 座標をパーセンテージで指定します。<br/>            読み取り/書き込み [`PointF`](/slides/python-net/ja/aspose.slides/pointf)。 |
| [`to`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/to/) | アニメーションモーションエフェクトの対象位置をパーセンテージで指定します。<br/>            読み取り/書き込み [`PointF`](/slides/python-net/ja/aspose.slides/pointf)。 |
| [`by`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/by/) | アニメーションの相対オフセット値をパーセンテージで指定します。<br/>            読み取り/書き込み [`PointF`](/slides/python-net/ja/aspose.slides/pointf)。 |
| [`rotation_center`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/rotation_center/) | モーションパスを X 角度で回転させる際に使用される回転の中心を指定します。<br/>            読み取り/書き込み [`PointF`](/slides/python-net/ja/aspose.slides/pointf)。 |
| [`origin`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/origin/) | モーションパスの原点がスライドのレイアウトや親など、何に対して相対的かを指定します。<br/>            読み取り/書き込み [`MotionOriginType`](/slides/python-net/ja/aspose.slides.animation/motionorigintype)。 |
| [`path`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/path/) | アニメーションモーションの座標で構成されるパスプリミティブを指定します。<br/>            読み取り/書き込み [`IMotionPath`](/slides/python-net/ja/aspose.slides.animation/imotionpath)。 |
| [`path_edit_mode`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/path_edit_mode/) | シェイプが移動したときにモーションパスがどのように動くかを指定します。<br/>            読み取り/書き込み [`MotionPathEditMode`](/slides/python-net/ja/aspose.slides.animation/motionpatheditmode)。 |
| [`angle`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/angle/) | モーションパスの相対角度を指定します。<br/>            読み取り/書き込み **float**。 |
| [`accumulate`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/accumulate/) |  |
| [`additive`](/slides/python-net/ja/aspose.slides.animation/imotioneffect/additive/) |  |
