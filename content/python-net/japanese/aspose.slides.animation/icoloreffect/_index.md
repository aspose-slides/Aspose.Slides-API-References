## IColorEffect クラス

アニメーション動作のためのカラーエフェクトを表します。

IColorEffect 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`from_`](/slides/python-net/ja/aspose.slides.animation/icoloreffect/from_/) | この値は動作の開始色を指定するために使用されます。<br/>            読み書き [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat)。 |
| [`to`](/slides/python-net/ja/aspose.slides.animation/icoloreffect/to/) | アニメーションの色変更に対する結果の色を説明します。<br/>            読み書き [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat)。 |
| [`by`](/slides/python-net/ja/aspose.slides.animation/icoloreffect/by/) | カラーアニメーションの相対オフセット値を説明します。<br/>            読み書き [`IColorOffset`](/slides/python-net/ja/aspose.slides.animation/icoloroffset)。 |
| [`color_space`](/slides/python-net/ja/aspose.slides.animation/icoloreffect/color_space/) | 動作の色空間を表します。<br/>            読み書き [`IColorEffect.color_space`](/slides/python-net/ja/aspose.slides.animation/icoloreffect/color_space)。 |
| [`direction`](/slides/python-net/ja/aspose.slides.animation/icoloreffect/direction/) | 色相を色相環で循環させる方向を指定します。<br/>            読み書き [`ColorDirection`](/slides/python-net/ja/aspose.slides.animation/colordirection)。 |
| [`accumulate`](/slides/python-net/ja/aspose.slides.animation/icoloreffect/accumulate/) |  |
