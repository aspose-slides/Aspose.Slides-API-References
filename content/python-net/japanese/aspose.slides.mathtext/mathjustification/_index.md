## MathJustification 列挙型

数学段落の配置を指定します (同じ段落内の隣接する複数の数学テキスト)。

MathJustification 型は次のメンバーを公開します：

## フィールド

| フィールド | 説明 |
| :- | :- |
| LEFT_JUSTIFIED | 数学テキストを左揃えにする |
| RIGHT_JUSTIFIED | 数学テキストを右揃えにする |
| CENTERED | 数学テキストを中央揃えにする |
| CENTERED_AS_GROUP | ページ上で数式ブロック全体を単一ユニットとして中央に配置する。<br/>            これは、個々の数学テキストのインスタンスは互いに揃えることができるが、数学テキスト全体のグループは全体として中央に配置されることを意味します。 |
