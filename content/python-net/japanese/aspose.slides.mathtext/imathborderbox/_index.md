## IMathBorderBox クラス

IMathElement の周囲に長方形またはその他の罫線を描画します。

IMathBorderBox 型は次のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`base`](/slides/python-net/ja/aspose.slides.mathtext/imathborderbox/base/) | 基本引数 |
| [`hide_top`](/slides/python-net/ja/aspose.slides.mathtext/imathborderbox/hide_top/) | 上端を非表示にする (デフォルトは false) - 境界ボックスの上端の非表示または表示状態を指定します。 |
| [`hide_bottom`](/slides/python-net/ja/aspose.slides.mathtext/imathborderbox/hide_bottom/) | 下端を非表示にする (デフォルトは false) - 境界ボックスの下端の非表示または表示状態を指定します。 |
| [`hide_left`](/slides/python-net/ja/aspose.slides.mathtext/imathborderbox/hide_left/) | 左端を非表示にする (デフォルトは false) - 境界ボックスの左端の非表示または表示状態を指定します。 |
| [`hide_right`](/slides/python-net/ja/aspose.slides.mathtext/imathborderbox/hide_right/) | 右端を非表示にする (デフォルトは false) - 境界ボックスの右端の非表示または表示状態を指定します。 |
| [`strikethrough_horizontal`](/slides/python-net/ja/aspose.slides.mathtext/imathborderbox/strikethrough_horizontal/) | 水平の取り消し線 (デフォルトは false) - 水平の取り消し線の非表示または表示状態を指定します。 |
| [`strikethrough_vertical`](/slides/python-net/ja/aspose.slides.mathtext/imathborderbox/strikethrough_vertical/) | 垂直の取り消し線 (デフォルトは false) - 垂直の取り消し線の非表示または表示状態を指定します。 |
| [`strikethrough_bottom_left_to_top_right`](/slides/python-net/ja/aspose.slides.mathtext/imathborderbox/strikethrough_bottom_left_to_top_right/) | 左下から右上への取り消し線 (デフォルトは false).<br/>            境界ボックスの左下隅から右上隅へ伸びる対角線の取り消し線の非表示または表示状態を指定します。 |
| [`strikethrough_top_left_to_bottom_right`](/slides/python-net/ja/aspose.slides.mathtext/imathborderbox/strikethrough_top_left_to_bottom_right/) | 左上から右下への取り消し線 (デフォルトは false).<br/>            境界ボックスの左上隅から右下隅へ伸びる対角線の取り消し線の非表示または表示状態を指定します。 |
