## IMathElementCollection クラス

数学要素 (MathElement) のコレクションを表します。

IMathElementCollection 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`count`](/slides/python-net/ja/aspose.slides.mathtext/imathelementcollection/count/) | コレクションに実際に含まれる要素数を取得します。<br/>            読み取り専用 **int**. |

指定されたインデックスの要素を取得します。
            読み取り専用 [`IMathElement`](/slides/python-net/ja/aspose.slides.mathtext/imathelement).
