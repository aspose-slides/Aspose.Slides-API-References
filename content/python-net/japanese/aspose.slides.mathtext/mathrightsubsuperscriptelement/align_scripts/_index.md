## align_scripts プロパティ
下付き文字/上付き文字の配置を指定します。 
            true の場合、下付き文字と上付き文字は水平方向に揃えられます。
            false の場合、ベース文字の形状に合わせてカーニングされます。
            デフォルト値は false です。
