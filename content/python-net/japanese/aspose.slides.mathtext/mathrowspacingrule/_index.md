## MathRowSpacingRule 列挙型

マトリックスまたは配列における列間の垂直間隔のタイプ

MathRowSpacingRule 型は次のメンバーを公開しています:

## フィールド

| フィールド | 説明 |
| :- | :- |
| SINGLE_LINE_GAP | 単一行のギャップ |
| ONE_AND_A_HALF_LINE_GAP | 1.5 行のギャップ |
| TWO_LINE_GAP | 2 行のギャップ |
| EXACTLY | 正確に（RowSpacing プロパティの値に依存し、ポイント単位で測定） |
| MULTIPLE | 複数（RowSpacing プロパティの値に依存し、行単位で測定） |
