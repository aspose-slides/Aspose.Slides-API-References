## show プロパティ
ベース要素が表示されるかどうかを示す値を取得または設定します。


### 備考

`false` のとき、ベース要素は非表示になりますが、他の phantom 設定に応じてスペースを占有する場合があります。`m:show` 属性に対応します。

```python
@property
def show(self):
    ...

@show.setter

    ...
```
