## index_of(self, math_block) {#imathblock}

### 戻り値

コレクション内に `math_block` が見つかった場合はそのインデックスを返し、見つからない場合は -1 を返します。

```python
def index_of(self, math_block):
    ...
```

| math_block | [`IMathBlock`](/slides/python-net/ja/aspose.slides.mathtext/imathblock) | コレクション内で検索する項目です。 |
