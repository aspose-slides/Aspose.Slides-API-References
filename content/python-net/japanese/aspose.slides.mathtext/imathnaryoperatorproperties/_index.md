## IMathNaryOperatorProperties クラス

IMathNaryOperator のプロパティを指定します

IMathNaryOperatorProperties 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`operator`](/slides/python-net/ja/aspose.slides.mathtext/imathnaryoperatorproperties/operator/) | Nary Operator Character<br/>            例: '∑', '∫' |
| [`limit_location`](/slides/python-net/ja/aspose.slides.mathtext/imathnaryoperatorproperties/limit_location/) | リミット（下付きと上付き）の位置 |
| [`grow_to_match_operand_height`](/slides/python-net/ja/aspose.slides.mathtext/imathnaryoperatorproperties/grow_to_match_operand_height/) | Operator Character はオペランドの高さに合わせて垂直方向に伸びます |
| [`hide_subscript`](/slides/python-net/ja/aspose.slides.mathtext/imathnaryoperatorproperties/hide_subscript/) | 下付きを非表示 |
| [`hide_superscript`](/slides/python-net/ja/aspose.slides.mathtext/imathnaryoperatorproperties/hide_superscript/) | 上付きを非表示 |
