## MathSpacingRules 列挙体

行列の列の間の隙間（水平間隔）の種類

MathSpacingRules 型は次のメンバーを公開します:

## フィールド

| フィールド | 説明 |
| :- | :- |
| SINGLE_SPACING_GAP | 単一 (列は 1 em、行は 1 行) |
| ONE_AND_HALF_SPACING_GAP | 1.5 倍 (列は 1.5 em、行は 1.5 行) |
| DOUBLE_SPACING_GAP | 二重間隔 (列は 2 em、行は 2 行) |
| EXACTLY | 正確な値<br/>            列の場合は ColumnGap の値に依存し、単位は twips<br/>            行の場合は RowGap の値に依存し、単位は twips |
| MULTIPLE | 複数<br/>            列の場合は ColumnGap の値に依存し、0.5 em の増分で測定<br/>            行の場合は RowGap の値に依存し、行単位で測定 |
