## IFlyThroughTransition クラス

フライスルー スライド遷移効果。

IFlyThroughTransition タイプは次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`direction`](/slides/python-net/ja/aspose.slides.slideshow/iflythroughtransition/direction/) | 遷移の方向。<br/>            読み取り/書き込み [`TransitionInOutDirectionType`](/slides/python-net/ja/aspose.slides.slideshow/transitioninoutdirectiontype). |
| [`has_bounce`](/slides/python-net/ja/aspose.slides.slideshow/iflythroughtransition/has_bounce/) | 遷移中のプレゼンテーション スライドの動きにバウンスが含まれることを指定します。<br/>            読み取り/書き込み **bool**. |
