## TransitionMorphType 列挙

モーフ遷移のタイプを表します。

TransitionMorphType 型は以下のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| BY_OBJECT | モーフ遷移は、シェイプを不可分なオブジェクトとして扱って実行されます。 |
| BY_WORD | 可能な限り、テキストを単語単位で転送しながらモーフ遷移が実行されます。 |
| BY_CHAR | 可能な限り、テキストを文字単位で転送しながらモーフ遷移が実行されます。 |
