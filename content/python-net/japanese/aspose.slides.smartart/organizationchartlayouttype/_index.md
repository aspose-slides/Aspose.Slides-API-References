## OrganizationChartLayoutType 列挙体

組織図の子ノードの書式設定タイプを表します

OrganizationChartLayoutType 型は以下のメンバーを公開します:

## フィールド

| Field | 説明 |
| :- | :- |
| INITIAL | 初期レイアウトタイプ |
| STANDART | 子ノードを親ノードの下に水平方向に配置します。 |
| BOTH_HANGING | 子ノードを親ノードの左側と右側の両方に垂直方向に配置します。 |
| LEFT_HANGING | 子ノードを親ノードの左側に垂直方向に配置します。 |
| RIGHT_HANGING | 子ノードを親ノードの右側に垂直方向に配置します。 |
