## SmartArtLayoutType 列挙体

SmartArt ダイアグラムのレイアウトタイプを表します。

SmartArtLayoutType 型は次のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| ACCENT_PROCESS | 進行、タイムライン、またはタスク、プロセス、ワークフローの順次ステップを示すのに使用します。Level 1 と Level 2 のテキストの両方の図示に適しています。 |
| ACCENTED_PICTURE | 中央の写真的アイデアとそれに関連するサイドのアイデアを示すのに使用します。上部の Level 1 テキストは中央画像の上に表示されます。他の Level 1 形状の対応するテキストは小さな円形画像の横に表示されます。このレイアウトはテキストがない場合でもうまく機能します。 |
| ALTERNATING_FLOW | 情報のグループまたはタスク、プロセス、ワークフローの順次ステップを示すのに使用します。情報グループ間の相互作用や関係性を強調します。 |
| ALTERNATING_HEXAGONS | 相互に接続されたアイデアの連続を表すのに使用します。Level 1 テキストは六角形の内部に、Level 2 テキストは形状の外側に表示されます。 |
| ALTERNATING_PICTURE_BLOCKS | 上から下へ一連の画像を示すのに使用します。テキストは画像の右または左に交互に表示されます。 |
| ALTERNATING_PICTURE_CIRCLES | 画像とテキストのセットを示すのに使用します。対応するテキストは中央の円に表示され、画像は左から右へ交互に配置されます。 |
| ARROW_RIBBON | 関連または対照的な概念を何らかの接続で示すのに使用します（例：対立する力）。Level 1 テキストの最初の 2 行が矢印内のテキストとして使用されます。未使用のテキストは表示されませんが、レイアウトを切り替えると利用可能です。 |
| ASCENDING_PICTURE_ACCENT_PROCESS | 上昇する一連の画像と説明テキストを示すのに使用します。少量のテキストに最適です。 |
| BALANCE | 2 つのアイデアを比較または関係性を示すのに使用します。最初の 2 行の Level 1 テキストは中心点の両側上部に対応し、Level 2 テキストは各側の 4 つの形状に制限されます。バランスは Level 2 テキストを含む形状が多い側に傾きます。未使用のテキストは表示されませんが、レイアウトを切り替えると利用可能です。 |
| BASIC_BENDING_PROCESS | タスク、プロセス、ワークフローの進行または順次ステップを示すのに使用します。形状の水平・垂直表示領域を最大化します。 |
| BASIC_BLOCK_LIST | 順序のない情報ブロックまたはグループ化された情報を示すのに使用します。形状の水平・垂直表示領域を最大化します。 |
| BASIC_CHEVRON_PROCESS | 進行、タイムライン、タスク、プロセス、ワークフローの順次ステップ、または動きや方向を強調するのに使用します。Level 1 テキストは矢印形状の内部に、Level 2 テキストは矢印形状の下に表示されます。 |
| BASIC_CYCLE | 循環フローでステージ、タスク、イベントの連続を表すのに使用します。接続矢印やフローよりもステージやステップを強調します。Level 1 テキストのみでの使用が最適です。 |
| BASIC_MATRIX | 四分割で全体に対する構成要素の関係を示すのに使用します。最初の 4 行の Level 1 テキストが各象限に表示されます。未使用のテキストは表示されませんが、レイアウトを切り替えると利用可能です。 |
| BASIC_PIE | 個々の部分が全体を構成する様子を示すのに使用します。最初の 7 行の Level 1 テキストが均等に配置された円弧または円形に対応します。上部の Level 1 テキスト形状は円全体の外側に表示され、強調されます。未使用のテキストは表示されませんが、レイアウトを切り替えると利用可能です。 |
| BASIC_PROCESS | タスク、プロセス、ワークフローの進行または順次ステップを示すのに使用します。 |
| BASIC_PYRAMID | 底部が最大の構成要素となり上方に狭まる、比例的・相互接続・階層的関係を示すのに使用します。Level 1 テキストはピラミッドのセグメントに、Level 2 テキストは各セグメント横の形状に表示されます。 |
| BASIC_RADIAL | 中央アイデアとの関係を循環で示すのに使用します。最初の行の Level 1 テキストが中央形状に、対応する Level 2 テキストが周囲の円形に対応します。未使用のテキストは表示されませんが、レイアウトを切り替えると利用可能です。 |
| BASIC_TARGET | 包含、段階、または階層関係を示すのに使用します。最初の 5 行の Level 1 テキストが円に紐付けられます。未使用のテキストは表示されませんが、レイアウトを切り替えると利用可能です。 |
| BASIC_TIMELINE | タスク、プロセス、ワークフローの順次ステップ、またはタイムライン情報を示すのに使用します。Level 1 と Level 2 のテキストの両方に適しています。 |
| BASIC_VENN | 重なり合うまたは相互接続された関係を示すのに使用します。最初の 7 行の Level 1 テキストが円に対応します。Level 1 テキストが 4 行以下の場合は円の内部に、5 行以上の場合は円の外部に表示されます。未使用のテキストは表示されませんが、レイアウトを切り替えると利用可能です。 |
| BENDING_PICTURE_ACCENT_LIST | 順序のない情報ブロックまたはグループ化された情報を示すのに使用します。小さな円形は画像を含むように設計されています。Level 1 と Level 2 のテキストの両方の図示に適しています。形状の水平・垂直表示領域を最大化します。 |
| BENDING_PICTURE_BLOCKS | 画像の連続を示すのに使用します。下側のボックスに少量のテキストを入れることができます。 |
| BENDING_PICTURE_CAPTION | 連続した画像シリーズを示すのに使用します。下側のボックスに少量のテキストを入れることができます。 |
| BENDING_PICTURE_CAPTION_LIST | 画像の連続を示すのに使用します。タイトルと説明は各画像の下にある吹き出し形状に表示されます。 |
| BENDING_PICTURE_SEMI_TRANSPARENT_TEXT | 画像の連続を示すのに使用します。半透明のボックスが画像の下部を覆い、すべてのレベルのテキストを含みます。 |
| BLOCK_CYCLE | 循環フローでステージ、タスク、イベントの連続を表すのに使用します。接続矢印やフローよりもステージやステップを強調します。 |
| BUBBLE_PICTURE_LIST | 画像の連続を示すのに使用します。最大 8 枚の Level 1 画像を含むことができます。未使用のテキストと画像は表示されませんが、レイアウトを切り替えると利用可能です。少量のテキストに最適です。 |
| CAPTIONED_PICTURES | 複数レベルのテキストを伴う画像を示すのに使用します。少量の Level 1 テキストと中程度の Level 2 テキストに最適です。 |
| CHEVRON_LIST | 全体的なワークフローを構成する複数プロセスの進行を示すのに使用します。対照的なプロセスの図示にも適しています。Level 1 テキストは左側の最初の矢印形状に対応し、Level 2 テキストは各 Level 1 テキストを含む形状の横方向サブステップに対応します。 |
| CIRCLE_ACCENT_TIMELINE | イベントの連続またはタイムライン情報を示すのに使用します。Level 1 テキストは大きな円形の横に、Level 2 テキストは小さな円形の横に表示されます。 |
| CIRCLE_ARROW_PROCESS | 各項目にサポートテキストを伴う順次項目を示すのに使用します。この図は少量の Level 1 テキストに最適です。 |
| CIRCLE_PICTURE_HIERARCHY | 組織内の階層情報や報告関係を示すのに使用します。画像は円内に配置され、対応するテキストは画像の横に表示されます。 |
| CIRCLE_RELATIONSHIP | 中央アイデアとの関係を示すのに使用します。Level 2 テキストは非順序的に追加され、最大 5 項目に制限されます。Level 1 項目は 1 つだけです。 |
| CIRCULAR_BENDING_PROCESS | タスク、プロセス、ワークフローの長いまたは非線形のシーケンスやステップを示すのに使用します。Level 1 テキストのみでの使用が最適です。形状の水平・垂直表示領域を最大化します。 |
| CIRCULAR_PICTURE_CALLOUT | 中央アイデアとサブアイデアまたは関連項目を示すのに使用します。最初の画像のテキストは画像の下部を覆います。他の Level 1 形状の対応テキストは小さな円形画像の横に表示されます。この図はテキストがなくてもうまく機能します。 |

| CONTINUOUS_ARROW_PROCESS | タイムラインまたはタスク、プロセス、ワークフローの順次ステップを示すのに使用します。各 Level 1 テキスト行が矢印形状内に表示されるため、Level 1 テキストに最適です。Level 2 テキストは矢印形状の外側に表示されます。 |
| CONTINUOUS_BLOCK_PROCESS | タスク、プロセス、ワークフローの進行または順次ステップを示すのに使用します。最小限の Level 1 と Level 2 テキストに最適です。 |
| CONTINUOUS_CYCLE | 循環フローでステージ、タスク、イベントの連続を表すのに使用します。すべてのコンポーネント間の接続を強調します。Level 1 テキストのみでの使用が最適です。 |

| COUNTERBALANCE_ARROWS | 2 つの対立するアイデアや概念を示すのに使用します。最初の 2 行の Level 1 テキストがそれぞれ矢印に対応し、Level 2 テキストと組み合わせて使用できます。未使用のテキストは表示されませんが、レイアウトを切り替えると利用可能です。 |
| CYCLE_MATRIX | 循環的な進行で中心アイデアとの関係を示すのに使用します。最初の 4 行の Level 1 テキストが楔形または円形に対応し、Level 2 テキストは楔形または円形の横側にある矩形に表示されます。未使用のテキストは表示されませんが、レイアウトを切り替えると利用可能です。 |
| DESCENDING_BLOCK_LIST | 関連アイデアや情報リストのグループを示すのに使用します。テキスト形状は高さが順に減少し、Level 1 テキストは垂直に配置されます。 |
| DESCENDING_PROCESS | 降順のイベント系列を示すのに使用します。最初の Level 1 テキストは矢印の上部に、最後の Level 1 テキストは矢印の下部に表示されます。最初の 7 項目のみが表示されます。少量から中量のテキストに最適です。 |
| DETAILED_PROCESS | 大量の Level 2 テキストと共にステージを通じた進行を示すのに使用します。 |
| DIVERGING_ARROWS | 中央の起点から外側へ広がるアイデアや概念を示すのに使用します。Level 1 テキストのみでの使用が最適です。 |
