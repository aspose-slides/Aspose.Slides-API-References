## IHtml5Options クラス

HTML5 エクスポートオプションを表します。

IHtml5Options タイプは以下のメンバーを公開します。

## プロパティ

| Property | Description |
| :- | :- |
| [`animate_transitions`](/slides/python-net/ja/aspose.slides.export/ihtml5options/animate_transitions/) | 遷移アニメーションオプションを取得または設定します。<br/>            Read/write **bool**. |
| [`animate_shapes`](/slides/python-net/ja/aspose.slides.export/ihtml5options/animate_shapes/) | シェイプのアニメーションオプションを取得または設定します。<br/>            Read/write **bool**. |
| [`embed_images`](/slides/python-net/ja/aspose.slides.export/ihtml5options/embed_images/) | 画像の埋め込みオプションを取得または設定します。 <br/>            Read/write **bool**. |
| [`output_path`](/slides/python-net/ja/aspose.slides.export/ihtml5options/output_path/) | 外部リソースの保存場所を決定します。 <br/>            Read/write **str**. |
| [`pictures_compression`](/slides/python-net/ja/aspose.slides.export/ihtml5options/pictures_compression/) | 画像圧縮レベルを表します<br/>            Read/write [`IHtml5Options.pictures_compression`](/slides/python-net/ja/aspose.slides.export/ihtml5options/pictures_compression). |
| [`disable_font_ligatures`](/slides/python-net/ja/aspose.slides.export/ihtml5options/disable_font_ligatures/) | テキストが合字を使用せずにレンダリングされるかどうかを取得または設定します。<br/>            When set to `true`, ligatures will be disabled in the rendered output. By default, this property is set to `false`. |
