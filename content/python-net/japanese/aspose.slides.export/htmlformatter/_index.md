## HtmlFormatter クラス

HTML ファイルテンプレートを表します。

HtmlFormatter 型は次のメンバーを公開します:

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`create_document_formatter(css, show_slide_title)`](/slides/python-net/ja/aspose.slides.export/htmlformatter/create_document_formatter/#str-bool) | シンプルなドキュメントビュー用の HTML フォーマッタを作成し、返します。このビューはスライドが上下に連なるシーケンスで構成されます。 |
| [`create_slide_show_formatter(css, show_slide_title)`](/slides/python-net/ja/aspose.slides.export/htmlformatter/create_slide_show_formatter/#str-bool) | シンプルなスライドショー HTML 用の HTML フォーマッタを作成し、返します。このスライドショーはスライドを順番に表示します。 |
| [`create_custom_formatter(formatting_controller)`](/slides/python-net/ja/aspose.slides.export/htmlformatter/create_custom_formatter/#ihtmlformattingcontroller) | カスタムコールバック駆動の HTML 生成用の HTML フォーマッタを作成し、返します。 |
