## disable_line_end_cropping プロパティ
SVG 1.1 ではマーカーのインセットを定義する機能がありません。
            Aspose.Slides の SVG 書き込みエンジンはこの問題に対する回避策を持っています:
            矢印付きの線の末端を切り取るため、線がマーカーと重ならなくなります。
            このオプションはその動作をオフにします。
            読み取り/書き込み **bool**.
