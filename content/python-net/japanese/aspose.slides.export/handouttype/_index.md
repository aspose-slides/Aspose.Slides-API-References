## HandoutType 列挙体

ページに配置されるスライドの枚数と配置順序を指定します。

HandoutType 型は次のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| HANDOUTS1 | 1ページに1枚のスライド。 |
| HANDOUTS2 | 1ページに2枚のスライド。 |
| HANDOUTS3 | 1ページに3枚のスライド。 |
| HANDOUTS_4_HORIZONTAL | 横方向の順序で1ページに4枚のスライド。 |
| HANDOUTS_4_VERTICAL | 縦方向の順序で1ページに4枚のスライド。 |
| HANDOUTS_6_HORIZONTAL | 横方向の順序で1ページに6枚のスライド。 |
| HANDOUTS_6_VERTICAL | 縦方向の順序で1ページに6枚のスライド。 |
| HANDOUTS_9_HORIZONTAL | 横方向の順序で1ページに9枚のスライド。 |
| HANDOUTS_9_VERTICAL | 縦方向の順序で1ページに9枚のスライド。 |
