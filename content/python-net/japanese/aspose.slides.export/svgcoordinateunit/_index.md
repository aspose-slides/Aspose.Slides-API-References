## SvgCoordinateUnit 列挙体

CSS2 の座標単位を表し、SVG 座標の定義に使用されます。

SvgCoordinateUnit 型は次のメンバーを公開します。

## フィールド

| Field | Description |
| :- | :- |
| INCH | インチ |
| CENTIMETER | センチメートル。 |
| MILLIMETER | ミリメートル。 |
| POINT | ポイント (1/72 インチ)、 |
| PICA | パイカ (1/6 インチ)。 |
| EM | 含む要素のフォントの Em サイズ。 |
| EX | Ex サイズ (小文字のサイズ、通常は "x")、含む要素のフォントの。 |
| PIXEL | ピクセル サイズ。 |
| PERCENT | パーセント。 |
