## CommentsPositions 列挙型

エクスポートされたドキュメントにコメントを描画するルールを表します

CommentsPositions 型は以下のメンバーを公開します：

## フィールド

| フィールド | 説明 |
| :- | :- |
| NONE | コメントが全く表示されないことを指定します。 |
| BOTTOM | コメントがページの下部に表示されることを指定します。 |
| RIGHT | コメントがページの右側に表示されることを指定します。 |
