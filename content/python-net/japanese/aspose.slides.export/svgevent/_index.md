## SvgEvent 列挙型

SvgEvent 型は次のメンバーを公開します。

## フィールド

| Field | Description |
| :- | :- |
| ON_FOCUS_IN | 要素がフォーカスを受け取ったときに発生します（例: テキストが選択されたとき）。 |
| ON_FOCUS_OUT | 要素がフォーカスを失ったときに発生します（例: テキストの選択が解除されたとき）。 |
| ON_ACTIVATE | 要素がアクティブになったときに発生します。例としてマウスクリックやキー入力があります。 |
| ON_CLICK | 要素上でポインティングデバイスのボタンがクリックされたときに発生します。 |
| ON_MOUSE_DOWN | 要素上でポインティングデバイスのボタンが押されたときに発生します。 |
| ON_MOUSE_UP | 要素上でポインティングデバイスのボタンが離されたときに発生します。 |
| ON_MOUSE_OVER | ポインティングデバイスが要素上に移動したときに発生します。 |
| ON_MOUSE_MOVE | ポインティングデバイスが要素上で移動したときに発生します。 |
| ON_MOUSE_OUT | ポインティングデバイスが要素から離れたときに発生します。 |
| ON_LOAD | ユーザーエージェントが要素とその子要素、そして描画に必要なすべての参照リソースを完全に解析したときに発生します。 |
| ON_UNLOAD | DOM 実装がウィンドウまたはフレームからドキュメントを削除したときに発生します。最外層の svg 要素にのみ適用されます。 |
| ON_ABORT | 要素が完全にロードされる前にページの読み込みが中止されたときに発生します。 |
| ON_ERROR | 要素が正しくロードされない、またはスクリプト実行中にエラーが発生したときに発生します。 |
| ON_RESIZE | ドキュメントビューがリサイズされるときに発生します。最外層の svg 要素にのみ適用されます。 |
| ON_SCROLL | ドキュメントビューが X 軸、Y 軸、またはその両方に沿って移動するときに発生します。最外層の svg 要素にのみ適用されます。 |
| ON_ZOOM | ドキュメントビューのズームレベルが変更されるときに発生します。最外層の svg 要素にのみ適用されます。 |
| ON_BEGIN | アニメーション要素が開始したときに発生します。 |
| ON_END | アニメーション要素が終了したときに発生します。 |
| ON_REPEAT | アニメーション要素が繰り返されるときに発生します。 |
