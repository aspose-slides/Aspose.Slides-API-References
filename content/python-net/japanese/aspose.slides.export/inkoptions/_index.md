## InkOptions クラス

エクスポートされたドキュメントで Ink オブジェクトの外観を制御するオプションを提供します。

InkOptions 型は次のメンバーを提供します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`hide_ink`](/slides/python-net/ja/aspose.slides.export/inkoptions/hide_ink/) | エクスポートされたドキュメントで Ink 要素を表示または非表示にします。 |
| [`interpret_mask_op_as_opacity`](/slides/python-net/ja/aspose.slides.export/inkoptions/interpret_mask_op_as_opacity/) | レンダリングブラシに ROP 操作または不透明度を使用します。 |
