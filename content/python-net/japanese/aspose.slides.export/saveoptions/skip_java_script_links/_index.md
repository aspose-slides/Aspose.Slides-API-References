## skip_java_script_links プロパティ
プレゼンテーションを保存する際に、JavaScript 呼び出しを含むハイパーリンクをスキップするかどうかを指定します。 
            読み書き **bool**。デフォルト値は **false** です。


### 備考

このプロパティが **true** に設定されている場合、保存中に JavaScript 呼び出しを含むハイパーリンクは無視されます。


このプロパティが **false** に設定されている場合、すべてのハイパーリンクが保存されます。
