## NotesPositions 列挙型

エクスポートされたドキュメントにノートを描画するルールを表します。

NotesPositions 型は以下のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| NONE | ノートはまったく表示されないことを指定します。 |
| BOTTOM_FULL | ノートは必要に応じて追加ページを使用して全体が表示されることを指定します。 |
| BOTTOM_TRUNCATED | ノートは1ページにのみ表示されることを指定します。 |
