## BlackWhiteConversionMode 列挙型

スライドの画像を二値画像に変換する方法を制御するオプションを提供します。

BlackWhiteConversionMode 型は次のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| DEFAULT | 変換アルゴリズムを指定しません。TIFF コーデックで実装されたアルゴリズムが使用されます。(Default) |
| DITHERING | ディザリングアルゴリズム（Floyd-Steinberg）を指定します。 |
| DITHERING_FLOYD_STEINBERG | Floyd-Steinberg ディザリングアルゴリズムを指定します。 |
| AUTO | 自動的に計算された閾値アルゴリズム（Otsu）を指定します。 |
| AUTO_OTSU | 自動的に計算された Otsu の閾値アルゴリズムを指定します。 |
| THRESHOLD25 | 静的閾値アルゴリズム（25%）を指定します。 |
| THRESHOLD50 | 静的閾値アルゴリズム（50%）を指定します。 |
| THRESHOLD75 | 静的閾値アルゴリズム（75%）を指定します。 |
