## TiffCompressionTypes 列挙型

TIFF 形式でプレゼンテーションが圧縮される方法を制御するオプションを提供します。

TiffCompressionTypes 型は以下のメンバーを公開します。

## フィールド

| Field | Description |
| :- | :- |
| DEFAULT | デフォルトの圧縮方式 (LZW) を指定します。 |
| NONE | 圧縮なしを指定します。 |
| CCITT3 | CCITT3 圧縮方式を指定します。 |
| CCITT4 | CCITT4 圧縮方式を指定します。 |
| LZW | LZW 圧縮方式 (デフォルト) を指定します。 |
| RLE | RLE 圧縮方式を指定します。 |
