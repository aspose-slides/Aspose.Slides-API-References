## LinkEmbedDecision 列挙型

保存時にオブジェクトがどのように処理されるかを決定します。

LinkEmbedDecision 型は以下のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| LINK | オブジェクトは外部に保存され、URLで参照されます |
| EMBED | 可能であれば、オブジェクトは生成されたファイルに埋め込まれるべきです。埋め込みが不可能な場合、GetUrl が呼び出され、結果に応じてオブジェクトは URLで参照されるか、無視されます。 |
| IGNORE | オブジェクトは無視されます。 |
