## PdfCompliance 列挙体

PDF 標準のコンプライアンスレベルを定義する定数です。

PdfCompliance 型は以下のメンバーを公開します：

## フィールド

| フィールド | 説明 |
| :- | :- |
| PDF15 | 出力ファイルは PDF 1.5 標準に準拠します。 |
| PDF16 | 出力ファイルは PDF 1.6 標準に準拠します。 |
| PDF17 | 出力ファイルは PDF 1.7 標準に準拠します。 |
| PDF_A1B | 出力ファイルは PDF/A-1b 標準に準拠します。 |
| PDF_A1A | 出力ファイルは PDF/A-1a 標準に準拠します。 |
| PDF_A2B | 出力ファイルは PDF/A-2b 標準に準拠します。 |
| PDF_A2A | 出力ファイルは PDF/A-2a 標準に準拠します。 |
| PDF_A3B | 出力ファイルは PDF/A-3b 標準に準拠します。 |
| PDF_A3A | 出力ファイルは PDF/A-3a 標準に準拠します。 |
| PDF_UA | 出力ファイルは PDF/UA 標準に準拠します。 |
| PDF_A2U | 出力ファイルは PDF/A-2u 標準に準拠します。 |
