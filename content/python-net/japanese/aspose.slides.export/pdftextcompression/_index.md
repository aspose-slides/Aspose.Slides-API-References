## PdfTextCompression 列挙型

画像を除く PDF ファイル内のすべてのコンテンツに適用される圧縮の種類を定義する定数です。

PdfTextCompression 型は次のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| NONE | 圧縮なし。 |
| FLATE | Flate (ZIP) 圧縮。 |
