## IPptxOptions クラス

OpenXml プレゼンテーション (PPTX, PPSX, POTX, PPTM, PPSM, POTM) の保存オプションを表します。

IPptxOptions タイプは以下のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`conformance`](/slides/python-net/ja/aspose.slides.export/ipptxoptions/conformance/) | Presentation ドキュメントが準拠するコンフォーマンス クラスを指定します。<br/>            既定値は [`Conformance.ECMA_376_2006`](/slides/python-net/ja/aspose.slides.export/conformance/ECMA_376_2006) |
| [`zip_64_mode`](/slides/python-net/ja/aspose.slides.export/ipptxoptions/zip_64_mode/) | Presentation ドキュメントで ZIP64 形式が使用されるかどうかを指定します。<br/>            既定値は [`Zip64Mode.IF_NECESSARY`](/slides/python-net/ja/aspose.slides.export/zip64mode/IF_NECESSARY) |
| [`refresh_thumbnail`](/slides/python-net/ja/aspose.slides.export/ipptxoptions/refresh_thumbnail/) | プレゼンテーション サムネイルが更新されるかどうかを指定します。<br/>            読み取り/書き込み **bool**。<br/>            既定値は **true** . |
| [`compression_level`](/slides/python-net/ja/aspose.slides.export/ipptxoptions/compression_level/) | プレゼンテーション ドキュメントを保存する際に使用される圧縮レベルを指定します。<br/>            既定値は [`CompressionLevel.LEVEL6`](/slides/python-net/ja/aspose.slides.export/compressionlevel/LEVEL6). |
| [`warning_callback`](/slides/python-net/ja/aspose.slides.export/ipptxoptions/warning_callback/) |  |
| [`progress_callback`](/slides/python-net/ja/aspose.slides.export/ipptxoptions/progress_callback/) |  |
| [`default_regular_font`](/slides/python-net/ja/aspose.slides.export/ipptxoptions/default_regular_font/) |  |
| [`gradient_style`](/slides/python-net/ja/aspose.slides.export/ipptxoptions/gradient_style/) |  |
| [`skip_java_script_links`](/slides/python-net/ja/aspose.slides.export/ipptxoptions/skip_java_script_links/) |  |
