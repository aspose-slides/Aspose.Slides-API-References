## disable_line_end_cropping プロパティ
SVG 1.1 にはマーカーのインセットを定義する機能がありません。
            Aspose.Slides SVG 書き込みエンジンはこの問題に対する回避策を持っています:
            矢印付きのラインの端を切り取るので、ラインがマーカーと重なりません。
            このオプションはその動作を無効にします。
            読み取り/書き込み **bool**。
