## Conformance 列挙

PresentationML ドキュメントが準拠する適合クラスを指定します。

Conformance 型は以下のメンバーを公開します：

## フィールド

| フィールド | 説明 |
| :- | :- |
| ECMA_376_2006 | ドキュメントが ECMA376:2006 に準拠していることを指定します。 |
| ISO_29500_2008_TRANSITIONAL | ドキュメントが ISO/IEC 29500:2008 Transitional 適合クラスに準拠していることを指定します。 |
| ISO_29500_2008_STRICT | ドキュメントが ISO/IEC 29500:2008 Strict 適合クラスに準拠していることを指定します。 |
