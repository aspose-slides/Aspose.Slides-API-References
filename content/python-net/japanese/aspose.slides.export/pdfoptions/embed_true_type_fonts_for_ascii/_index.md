## embed_true_type_fonts_for_ascii プロパティ
Aspose.SlidesがASCII (33..127 code range) テキスト用に共通フォントを埋め込むかどうかを決定します。  
文字コードが127より大きいフォントは常に埋め込まれます。  
共通フォントリストにはPDFのベース14フォントと、追加のユーザー指定フォントが含まれます。  
読み取り/書き込み **bool**。

### 備考

デフォルトは **true** です。
