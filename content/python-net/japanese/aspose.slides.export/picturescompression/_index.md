## PicturesCompression 列挙体

画像圧縮レベルを表します

PicturesCompression 型は以下のメンバーを公開します：

## フィールド

| フィールド | 説明 |
| :- | :- |
| DPI330 | HD（高解像度）ディスプレイ向けの高品質 |
| DPI220 | ほとんどのプリンターおよび画面での優れた品質 |
| DPI150 | ウェブページやプロジェクター向けの適度な品質 |
| DPI96 | 共有用にドキュメントサイズを最小化 |
| DPI72 | デフォルトの圧縮レベル |
| DOCUMENT_RESOLUTION | ドキュメントの解像度を使用します - 画像は圧縮されず、そのままドキュメントに使用されます |
