## IPresentationAnimationPlayer クラス

アニメーションのプレーヤーを表します。

[`PresentationAnimationsGenerator`](/slides/python-net/ja/aspose.slides.export/presentationanimationsgenerator) によって **NewAnimation** イベントを通じて生成されたアニメーション。

IPresentationAnimationPlayer 型は以下のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`duration`](/slides/python-net/ja/aspose.slides.export/ipresentationanimationplayer/duration/) | アニメーションの期間を取得します [ms] |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`set_time_position(self, time)`](/slides/python-net/ja/aspose.slides.export/ipresentationanimationplayer/set_time_position/#float) | [`IPresentationAnimationPlayer.duration`](/slides/python-net/ja/aspose.slides.export/ipresentationanimationplayer/duration) 内のアニメーション時間位置を設定します。 |
| [`get_frame(self)`](/slides/python-net/ja/aspose.slides.export/ipresentationanimationplayer/get_frame/#) | 以前に **Aspose.Slides.Export.IPresentationAnimationPlayer.SetTimePosition(Syste** メソッドで設定された現在の時間位置のフレームを取得します。 |
