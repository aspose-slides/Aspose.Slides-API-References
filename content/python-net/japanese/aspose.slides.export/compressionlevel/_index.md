## CompressionLevel 列挙体

OpenXML ファイル用の ZIP 圧縮レベルを指定します。  
レベルが高くなるほど、処理速度が遅くなる代わりに圧縮率が向上します。

CompressionLevel 型は次のメンバーを公開します：

## フィールド

| Field | Description |
| :- | :- |
| NONE | 圧縮は適用されません。ファイルはそのまま保存されます。 |
| LEVEL1 | 最低の圧縮率で最速の圧縮を行います。 |
| LEVEL2 | [`CompressionLevel.LEVEL1`](/slides/python-net/ja/aspose.slides.export/compressionlevel/LEVEL1) よりわずかに圧縮率が向上し、圧縮が速くなります。 |
| LEVEL3 | [`CompressionLevel.LEVEL2`](/slides/python-net/ja/aspose.slides.export/compressionlevel/LEVEL2) より圧縮率が向上し、パフォーマンスへの影響は中程度です。 |
| LEVEL4 | [`CompressionLevel.LEVEL3`](/slides/python-net/ja/aspose.slides.export/compressionlevel/LEVEL3) より圧縮率が向上します。 |
| LEVEL5 | [`CompressionLevel.LEVEL4`](/slides/python-net/ja/aspose.slides.export/compressionlevel/LEVEL4) より圧縮率が改善され、処理時間が追加でかかります。 |
| LEVEL6 | 標準的な圧縮で、圧縮速度とファイルサイズのバランスが取れています。<br/>            デフォルトの圧縮レベルです。 |
| LEVEL7 | [`CompressionLevel.LEVEL6`](/slides/python-net/ja/aspose.slides.export/compressionlevel/LEVEL6) より高い圧縮率を提供しますが、処理は遅くなります。 |
| LEVEL8 | [`CompressionLevel.LEVEL7`](/slides/python-net/ja/aspose.slides.export/compressionlevel/LEVEL7) より高い圧縮率を提供します。 |
| LEVEL9 | 最大の圧縮率です。最も遅い処理速度で最小のファイルサイズを生成します。 |
