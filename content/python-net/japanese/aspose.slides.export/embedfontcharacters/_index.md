## EmbedFontCharacters 列挙

[`IPresentation`](/slides/python-net/ja/aspose.slides/ipresentation) に新しい埋め込みフォントを追加する際に使用するルールを表します

EmbedFontCharacters 型は以下のメンバーを公開します:

## フィールド

| フィールド | 説明 |
| :- | :- |
| ONLY_USED | プレゼンテーションで使用されている文字のみを埋め込む（ファイルサイズ削減に最適）。 |
| ALL | すべての文字を埋め込む（他の人が編集する場合に最適）。 |
