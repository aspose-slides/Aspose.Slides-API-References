## embed_true_type_fonts_for_ascii プロパティ
True を設定すると、ASCII 文字コード 32-127 の TrueType フォントが埋め込まれます。
文字コード 127 を超えるフォントは常に埋め込まれます。
読み書き可能 **bool**。

### 備考

デフォルトは **true** です。
