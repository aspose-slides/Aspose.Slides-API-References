## skip_java_script_links プロパティ
プレゼンテーションの保存時に、JavaScript 呼び出しを含むハイパーリンクをスキップするかどうかを指定します。 
読み取り/書き込み **bool**. デフォルト値は **false** .


### 備考

このプロパティが **true** , 保存時に JavaScript 呼び出しを含むハイパーリンクは無視されます。

このプロパティが **false** , すべてのハイパーリンクが保存されます。
