## TextInheritanceLimit 列挙体

テキストプロパティの継承の深さを制御します。

TextInheritanceLimit 型は次のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| ALL | すべてのテキストプロパティを継承します。 |
| TEXT_BOX | TextFrame のスタイルからのみ継承します。 |
| PARAGRAPH_ONLY | 段落に定義されたプロパティのみ使用します。 |
