## ITextToHtmlConversionOptions class

Pptx テキストから HTML を抽出するオプションです。

ITextToHtmlConversionOptions 型は次のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`add_clipboard_fragment_header`](/slides/python-net/ja/aspose.slides.export/itexttohtmlconversionoptions/add_clipboard_fragment_header/) | 値を取得または設定します。Clipboard ヘッダーを追加するかどうかを示します。<br/>            読み書き **bool**. |
| [`text_inheritance_limit`](/slides/python-net/ja/aspose.slides.export/itexttohtmlconversionoptions/text_inheritance_limit/) | テキスト プロパティの継承深さを取得または設定します。<br/>            読み書き [`ITextToHtmlConversionOptions.text_inheritance_limit`](/slides/python-net/ja/aspose.slides.export/itexttohtmlconversionoptions/text_inheritance_limit). |
| [`link_embed_controller`](/slides/python-net/ja/aspose.slides.export/itexttohtmlconversionoptions/link_embed_controller/) | 外部オブジェクトの保存方法を制御するコールバック オブジェクトを取得または設定します。<br/>            読み書き [`ILinkEmbedController`](/slides/python-net/ja/aspose.slides.export/ilinkembedcontroller). |
| [`encoding_name`](/slides/python-net/ja/aspose.slides.export/itexttohtmlconversionoptions/encoding_name/) | HTML エンコーディング名を取得または設定します。<br/>            この値は生成された HTML ファイルに保存されますが、ファイルがこのエンコーディングで保存されることを呼び出し側が保証する必要があります。<br/>            読み書き **str**. |
