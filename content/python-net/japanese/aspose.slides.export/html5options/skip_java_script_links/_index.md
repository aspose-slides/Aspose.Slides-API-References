## skip_java_script_links プロパティ
Specifies whether to skip hyperlinks with JavaScript calls when saving the presentation. 
            読み書き **bool**. デフォルト値は **false** .


### 備考

このプロパティが **true** に設定されている場合、保存時に JavaScript 呼び出しを含むハイパーリンクは無視されます。


このプロパティが **false** に設定されている場合、すべてのハイパーリンクが保存されます。
