## Html5Options クラス

HTML5 エクスポート オプションを表します。

**継承:**[`Html5Options`](/slides/python-net/ja/aspose.slides.export/html5options) → [`SaveOptions`](/slides/python-net/ja/aspose.slides.export/saveoptions)

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`warning_callback`](/slides/python-net/ja/aspose.slides.export/html5options/warning_callback/) | 警告を受け取り、ロードプロセスを続行するか中止するかを決定するオブジェクトを取得または設定します。<br/>            読み書き [`IWarningCallback`](/slides/python-net/ja/aspose.slides.warnings/iwarningcallback)。 |
| [`progress_callback`](/slides/python-net/ja/aspose.slides.export/html5options/progress_callback/) | パーセンテージで保存進捗の更新を行うコールバックオブジェクトを表します。<br/>            参照 [`IProgressCallback`](/slides/python-net/ja/aspose.slides/iprogresscallback)。 |
| [`default_regular_font`](/slides/python-net/ja/aspose.slides.export/html5options/default_regular_font/) | ソースフォントが見つからない場合に使用されるフォントを取得または設定します。<br/>            読み書き **str**。 |
| [`gradient_style`](/slides/python-net/ja/aspose.slides.export/html5options/gradient_style/) | グラデーションの視覚スタイルを取得または設定します。<br/>            読み書き [`GradientStyle`](/slides/python-net/ja/aspose.slides/gradientstyle)。 |
| [`skip_java_script_links`](/slides/python-net/ja/aspose.slides.export/html5options/skip_java_script_links/) | プレゼンテーションを保存する際に、JavaScript 呼び出しを含むハイパーリンクをスキップするかどうかを指定します。 <br/>            読み書き **bool**。 デフォルト値は **false** です。 |
| [`animate_transitions`](/slides/python-net/ja/aspose.slides.export/html5options/animate_transitions/) | トランジション アニメーションオプションを取得または設定します。<br/>            読み書き **bool**。 |
| [`animate_shapes`](/slides/python-net/ja/aspose.slides.export/html5options/animate_shapes/) | シェイプ アニメーションオプションを取得または設定します。<br/>            読み書き **bool**。 |
| [`embed_images`](/slides/python-net/ja/aspose.slides.export/html5options/embed_images/) | 画像埋め込みオプションを取得または設定します。 <br/>            読み書き **bool**。 |
| [`output_path`](/slides/python-net/ja/aspose.slides.export/html5options/output_path/) | 外部リソースの保存場所を決定します。 <br/>            読み書き **str**。 |
| [`pictures_compression`](/slides/python-net/ja/aspose.slides.export/html5options/pictures_compression/) | 画像圧縮レベルを表します |
| [`disable_font_ligatures`](/slides/python-net/ja/aspose.slides.export/html5options/disable_font_ligatures/) | リガチャを使用せずにテキストをレンダリングするかどうかを示す値を取得または設定します。<br/>            `true` に設定すると、レンダリング出力でリガチャが無効になります。デフォルトでは、このプロパティは `false` に設定されています。 |
| [`slides_layout_options`](/slides/python-net/ja/aspose.slides.export/html5options/slides_layout_options/) | プレゼンテーションをエクスポートする際に、スライドがページ上に配置されるモードを取得または設定します [`ISlidesLayoutOptions`](/slides/python-net/ja/aspose.slides.export/islideslayoutoptions)。 |
