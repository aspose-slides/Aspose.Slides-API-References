## IGifOptions クラス

GIF エクスポートオプションを表します。

IGifOptions 型は次のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`frame_size`](/slides/python-net/ja/aspose.slides.export/igifoptions/frame_size/) | フレームサイズを取得または設定します。 |
| [`export_hidden_slides`](/slides/python-net/ja/aspose.slides.export/igifoptions/export_hidden_slides/) | 非表示スライドがエクスポートされるかどうかを決定します。<br/>            既定値は false です。 |
| [`transition_fps`](/slides/python-net/ja/aspose.slides.export/igifoptions/transition_fps/) | 遷移 FPS [frames/sec] を取得または設定します<br/>            既定値は 25 です。 |
| [`default_delay`](/slides/python-net/ja/aspose.slides.export/igifoptions/default_delay/) | デフォルトの遅延時間 [ms] を取得または設定します。この値は [`ISlideShowTransition.advance_after_time`](/slides/python-net/ja/aspose.slides/islideshowtransition/advance_after_time) が設定されていない場合に使用されます。<br/>            既定値は 1000 です。 |
| [`warning_callback`](/slides/python-net/ja/aspose.slides.export/igifoptions/warning_callback/) |  |
| [`progress_callback`](/slides/python-net/ja/aspose.slides.export/igifoptions/progress_callback/) |  |
| [`default_regular_font`](/slides/python-net/ja/aspose.slides.export/igifoptions/default_regular_font/) |  |
| [`gradient_style`](/slides/python-net/ja/aspose.slides.export/igifoptions/gradient_style/) |  |
| [`skip_java_script_links`](/slides/python-net/ja/aspose.slides.export/igifoptions/skip_java_script_links/) |  |
