## SaveFormat 列挙型

保存されたプレゼンテーションの形式を定義する定数です。

SaveFormat 型は次のメンバーを公開します：

## フィールド

| フィールド | 説明 |
| :- | :- |
| PPT | PPT 形式でプレゼンテーションを保存します。 |
| PDF | PDF 形式でプレゼンテーションを保存します。 |
| XPS | XPS 形式でプレゼンテーションを保存します。 |
| PPTX | PPTX 形式でプレゼンテーションを保存します。 |
| PPSX | PPSX（スライドショー）形式でプレゼンテーションを保存します。 |
| TIFF | マルチページ TIFF 画像としてプレゼンテーションを保存します。 |
| ODP | ODP 形式でプレゼンテーションを保存します。 |
| PPTM | PPTM（マクロ対応プレゼンテーション）形式でプレゼンテーションを保存します。 |
| PPSM | PPSM（マクロ対応スライドショー）形式でプレゼンテーションを保存します。 |
| POTX | POTX（テンプレート）形式でプレゼンテーションを保存します。 |
| POTM | POTM（マクロ対応テンプレート）形式でプレゼンテーションを保存します。 |
| HTML | HTML 形式でプレゼンテーションを保存します。 |
| SWF | SWF 形式でプレゼンテーションを保存します。 |
| OTP | OTP（プレゼンテーションテンプレート）形式でプレゼンテーションを保存します。 |
| PPS | PPS 形式でプレゼンテーションを保存します。 |
| POT | POT 形式でプレゼンテーションを保存します。 |
| FODP | FODP 形式でプレゼンテーションを保存します。 |
| GIF | GIF 形式でプレゼンテーションを保存します。 |
| HTML5 | 新しい HTML5 テンプレートシステムを使用して HTML 形式でプレゼンテーションを保存します。 |
| MD | Markdown 形式でプレゼンテーションを保存します。 |
| XML | PowerPoint XML プレゼンテーション形式でプレゼンテーションを保存します。 |
