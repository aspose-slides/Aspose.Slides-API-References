## MarkdownExportType 列挙型

ドキュメントのレンダリングタイプ。

MarkdownExportType 型は次のメンバーを公開します。

## フィールド

| フィールド | 説明 |
| :- | :- |
| SEQUENTIAL | すべての項目を個別にレンダリングします。1つずつ。 |
| TEXT_ONLY | テキストのみをレンダリングします。 |
| VISUAL | すべての項目をレンダリングします。グループ化された項目はまとめてレンダリングします。 |
