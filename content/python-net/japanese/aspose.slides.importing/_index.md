## クラス

| クラス | 説明 |
| :- | :- |
| [`ExcelWorkbookImporter`](/slides/python-net/ja/aspose.slides.importing/excelworkbookimporter/) | プレゼンテーションへ Excel ワークブックからコンテンツをインポートする機能を提供します。 |
| [`ExternalResourceResolver`](/slides/python-net/ja/aspose.slides.importing/externalresourceresolver/) | 外部リソースを解決するために使用されるコールバッククラスです。Html、Svg ドキュメントのインポート中に使用します。<br/>            このリゾルバを使用すると、クライアントが提供した HTML または SVG ファイルがサーバーソフトウェアにローカルまたはネットワークファイルを取得させる脆弱性が発生する可能性があります。注意して使用してください。ExternalResourceResolver を全く指定しないこと（埋め込みオブジェクトのみが読み取られます）か、指定された uri が有効かどうかをチェックするサブクラスを作成することを推奨します。 |
| [`HtmlExternalResolver`](/slides/python-net/ja/aspose.slides.importing/htmlexternalresolver/) | HTML インポートルーチンが画像などの参照オブジェクトを取得するために使用するコールバックオブジェクトです。<br/>            このリゾルバを使用すると、クライアントが提供した HTML ファイルがサーバーソフトウェアにローカルまたはネットワークファイルを取得させる脆弱性が発生する可能性があります。注意して使用してください。HtmlExternalResolver を全く指定しないこと（埋め込みオブジェクトのみが読み取られます）か、指定された uri が有効かどうかをチェックするサブクラスを作成することを推奨します。 |
| [`IExternalResourceResolver`](/slides/python-net/ja/aspose.slides.importing/iexternalresourceresolver/) | Html、Svg ドキュメントのインポート中に外部リソースを解決するために使用されるコールバックインターフェースです。 |
| [`IHtmlExternalResolver`](/slides/python-net/ja/aspose.slides.importing/ihtmlexternalresolver/) | HTML インポートルーチンが画像などの参照オブジェクトを取得するために使用されるコールバックインターフェースです。 |
| [`PdfImportOptions`](/slides/python-net/ja/aspose.slides.importing/pdfimportoptions/) | PDF インポートオプションを表します。 |
