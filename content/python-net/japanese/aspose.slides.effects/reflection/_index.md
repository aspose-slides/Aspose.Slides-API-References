## Reflection クラス

Reflection エフェクトを表します。

Reflection タイプは以下のメンバーを公開します。

## プロパティ

| Property | Description |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/ja/aspose.slides.effects/reflection/start_pos_alpha/) | 開始アルファ値（パーセント）の開始位置（アルファ グラデーション ランプに沿って）を指定します。<br/>            Read/write **float**. |
| [`end_pos_alpha`](/slides/python-net/ja/aspose.slides.effects/reflection/end_pos_alpha/) | 終了アルファ値（パーセント）の終了位置（アルファ グラデーション ランプに沿って）を指定します。<br/>            Read/write **float**. |
| [`fade_direction`](/slides/python-net/ja/aspose.slides.effects/reflection/fade_direction/) | 反射のオフセット方向（角度）を指定します。<br/>            Read/write **float**. |
| [`start_reflection_opacity`](/slides/python-net/ja/aspose.slides.effects/reflection/start_reflection_opacity/) | 開始反射の不透明度（パーセント）。<br/>            Read/write **float**. |
| [`end_reflection_opacity`](/slides/python-net/ja/aspose.slides.effects/reflection/end_reflection_opacity/) | 終了反射の不透明度（パーセント）。<br/>            Read/write **float**. |
| [`blur_radius`](/slides/python-net/ja/aspose.slides.effects/reflection/blur_radius/) | ぼかし半径。<br/>            Read/write **float**. |
| [`direction`](/slides/python-net/ja/aspose.slides.effects/reflection/direction/) | 反射の方向。<br/>            Read/write **float**. |
| [`distance`](/slides/python-net/ja/aspose.slides.effects/reflection/distance/) | 反射の距離。<br/>            Read/write **float**. |
| [`rectangle_align`](/slides/python-net/ja/aspose.slides.effects/reflection/rectangle_align/) | 矩形の配置。<br/>            Read/write [`RectangleAlignment`](/slides/python-net/ja/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/ja/aspose.slides.effects/reflection/skew_horizontal/) | 水平せん断角度を指定します。<br/>            Read/write **float**. |
| [`skew_vertical`](/slides/python-net/ja/aspose.slides.effects/reflection/skew_vertical/) | 垂直せん断角度を指定します。<br/>            Read/write **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/ja/aspose.slides.effects/reflection/rotate_shadow_with_shape/) | 形状が回転した場合に、反射も形状と共に回転するかどうかを指定します。<br/>            Read/write **bool**. |
| [`scale_horizontal`](/slides/python-net/ja/aspose.slides.effects/reflection/scale_horizontal/) | 水平スケーリング係数を指定します。負のスケーリングは反転を引き起こします。（パーセント）<br/>            Read/write **float**. |
| [`scale_vertical`](/slides/python-net/ja/aspose.slides.effects/reflection/scale_vertical/) | 垂直スケーリング係数を指定します。負のスケーリングは反転を引き起こします。（パーセント）<br/>            Read/write **float**. |
