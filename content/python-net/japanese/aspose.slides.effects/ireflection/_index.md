## IReflection クラス

反射効果を表します。

IReflection 型は次のメンバーを公開します:

## プロパティ

| Property | Description |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/ja/aspose.slides.effects/ireflection/start_pos_alpha/) | アルファ グラデーション ランプに沿った開始アルファ値（パーセント）の開始位置を指定します。<br/>            読み取り/書き込み **float**. |
| [`end_pos_alpha`](/slides/python-net/ja/aspose.slides.effects/ireflection/end_pos_alpha/) | アルファ グラデーション ランプに沿った終了アルファ値（パーセント）の終了位置を指定します。<br/>            読み取り/書き込み **float**. |
| [`fade_direction`](/slides/python-net/ja/aspose.slides.effects/ireflection/fade_direction/) | 反射のオフセット方向を指定します。（角度）<br/>            読み取り/書き込み **float**. |
| [`start_reflection_opacity`](/slides/python-net/ja/aspose.slides.effects/ireflection/start_reflection_opacity/) | 反射の開始不透明度（パーセント）を指定します。<br/>            読み取り/書き込み **float**. |
| [`end_reflection_opacity`](/slides/python-net/ja/aspose.slides.effects/ireflection/end_reflection_opacity/) | 反射の終了不透明度（パーセント）を指定します。<br/>            読み取り/書き込み **float**. |
| [`blur_radius`](/slides/python-net/ja/aspose.slides.effects/ireflection/blur_radius/) | ぼかし半径を指定します。<br/>            読み取り/書き込み **float**. |
| [`direction`](/slides/python-net/ja/aspose.slides.effects/ireflection/direction/) | 反射の方向を指定します。<br/>            読み取り/書き込み **float**. |
| [`distance`](/slides/python-net/ja/aspose.slides.effects/ireflection/distance/) | 反射の距離を指定します。<br/>            読み取り/書き込み **float**. |
| [`rectangle_align`](/slides/python-net/ja/aspose.slides.effects/ireflection/rectangle_align/) | 矩形の配置。<br/>            読み取り/書き込み [`RectangleAlignment`](/slides/python-net/ja/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/ja/aspose.slides.effects/ireflection/skew_horizontal/) | 水平歪み角度を指定します。<br/>            読み取り/書き込み **float**. |
| [`skew_vertical`](/slides/python-net/ja/aspose.slides.effects/ireflection/skew_vertical/) | 垂直歪み角度を指定します。<br/>            読み取り/書き込み **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/ja/aspose.slides.effects/ireflection/rotate_shadow_with_shape/) | シェイプが回転した場合に、反射がシェイプと共に回転するかどうかを指定します。<br/>            読み取り/書き込み **bool**. |
| [`scale_horizontal`](/slides/python-net/ja/aspose.slides.effects/ireflection/scale_horizontal/) | 水平スケーリング係数を指定します。負のスケーリングは反転を引き起こします。（パーセント）<br/>            読み取り/書き込み **float**. |
| [`scale_vertical`](/slides/python-net/ja/aspose.slides.effects/ireflection/scale_vertical/) | 垂直スケーリング係数を指定します。負のスケーリングは反転を引き起こします。（パーセント）<br/>            読み取り/書き込み **float**. |
