## Glow クラス

Glow エフェクトを表します。このエフェクトでは、オブジェクトのエッジの外側に色のぼかしアウトラインが追加されます。

Glow タイプは次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`radius`](/slides/python-net/ja/aspose.slides.effects/glow/radius/) | 半径。<br/>            読み書き可能 **float**. |
| [`color`](/slides/python-net/ja/aspose.slides.effects/glow/color/) | カラー形式。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat). |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`get_effective(self)`](/slides/python-net/ja/aspose.slides.effects/glow/get_effective/#) | 継承が適用された効果的な Glow エフェクトデータを取得します。 |
