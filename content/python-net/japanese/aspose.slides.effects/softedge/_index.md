## SoftEdge クラス

ソフトエッジ効果を表します。 
            シェイプのエッジはぼかされますが、塗りは影響を受けません。

SoftEdge タイプは以下のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`radius`](/slides/python-net/ja/aspose.slides.effects/softedge/radius/) | エッジに適用するぼかしの半径を指定します。<br/>            読み書き可能 **float**. |

## メソッド

| メソッド | 説明 |
| :- | :- |
| [`get_effective(self)`](/slides/python-net/ja/aspose.slides.effects/softedge/get_effective/#) | 継承が適用された有効な Soft Edge エフェクト データを取得します。 |
