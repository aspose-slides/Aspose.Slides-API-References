## InnerShadow クラス

内部シャドウ効果を表します。

InnerShadow タイプは次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`blur_radius`](/slides/python-net/ja/aspose.slides.effects/innershadow/blur_radius/) | ぼかし半径。<br/>読み書き **float**. |
| [`direction`](/slides/python-net/ja/aspose.slides.effects/innershadow/direction/) | 影の方向。<br/>読み書き **float**. |
| [`distance`](/slides/python-net/ja/aspose.slides.effects/innershadow/distance/) | 影の距離。<br/>読み書き **float**. |
| [`shadow_color`](/slides/python-net/ja/aspose.slides.effects/innershadow/shadow_color/) | 影の色。<br/>読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat). |
