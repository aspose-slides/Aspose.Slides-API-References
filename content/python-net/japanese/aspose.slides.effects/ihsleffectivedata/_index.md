## IHSLEffectiveData クラス

Hue/Saturation/Luminanceエフェクトを表します。
            Hue、Saturation、Luminanceはそれぞれ現在の値に対して相対的に調整できます。

IHSLEffectiveData型は次のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`hue`](/slides/python-net/ja/aspose.slides.effects/ihsleffectivedata/hue/) | Hueのパーセンテージを返します。<br/>            読み取り専用 **float**. |
| [`saturation`](/slides/python-net/ja/aspose.slides.effects/ihsleffectivedata/saturation/) | Saturationのパーセンテージを返します。<br/>            読み取り専用 **float**. |
| [`luminance`](/slides/python-net/ja/aspose.slides.effects/ihsleffectivedata/luminance/) | Luminanceのパーセンテージを返します。<br/>            読み取り専用 **float**. |
