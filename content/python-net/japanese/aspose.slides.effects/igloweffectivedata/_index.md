## IGlowEffectiveData クラス

不変オブジェクトで、Glow 効果を表し、色のぼやけた輪郭がオブジェクトのエッジの外側に追加されます。

IGlowEffectiveData 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`radius`](/slides/python-net/ja/aspose.slides.effects/igloweffectivedata/radius/) | 半径。<br/>            読み取り専用 **float**. |
| [`color`](/slides/python-net/ja/aspose.slides.effects/igloweffectivedata/color/) | 色。<br/>            読み取り専用 [`Color`](/slides/python-net/ja/aspose.slides/color). |
