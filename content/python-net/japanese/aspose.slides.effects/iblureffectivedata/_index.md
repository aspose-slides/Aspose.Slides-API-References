## IBlurEffectiveData クラス

シェイプ全体に適用されるぼかし効果を表す不変オブジェクトで、塗りつぶしも対象となります。アルファを含むすべてのカラーチャンネルが影響を受けます。

IBlurEffectiveData 型は次のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`radius`](/slides/python-net/ja/aspose.slides.effects/iblureffectivedata/radius/) | ぼかし半径を取得または設定します。<br/>            読み取り専用 **float**。 |
| [`grow`](/slides/python-net/ja/aspose.slides.effects/iblureffectivedata/grow/) | ブラー処理の結果としてオブジェクトの境界を拡張するかどうかを決定します。<br/>            true は境界が拡張されることを示し、false は拡張されないことを示します。<br/>            読み取り専用 **bool**。 |
