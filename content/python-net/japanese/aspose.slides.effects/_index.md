Microsoft PowerPoint プレゼンテーションでさまざまな効果を扱うためのクラスを含みます。

## クラス

| クラス | 説明 |
| :- | :- |
| [`AlphaBiLevel`](/slides/python-net/ja/aspose.slides.effects/alphabilevel/) | Alpha Bi-Level 効果を表します。<br/>            Alpha (Opacity) 値が閾値未満の場合は 0 (完全に透明) に、閾値以上の場合は 100% (完全に不透明) に変更されます。 |
| [`AlphaCeiling`](/slides/python-net/ja/aspose.slides.effects/alphaceiling/) | Alpha Ceiling 効果を表します。<br/>            Alpha (opacity) の値が 0 より大きい場合は 100% に変更されます。<br/>            言い換えれば、部分的に不透明なものはすべて完全に不透明になります。 |
| [`AlphaFloor`](/slides/python-net/ja/aspose.slides.effects/alphafloor/) | Alpha Floor 効果を表します。<br/>            Alpha (opacity) の値が 100% 未満の場合は 0 に変更されます。<br/>            言い換えれば、部分的に透明なものはすべて完全に透明になります。 |
| [`AlphaInverse`](/slides/python-net/ja/aspose.slides.effects/alphainverse/) | Alpha Inverse 効果を表します。<br/>            Alpha (opacity) の値は 100% から減算することで反転します。 |
| [`AlphaModulate`](/slides/python-net/ja/aspose.slides.effects/alphamodulate/) | Alpha Modulate 効果を表します。<br/>            効果の alpha (opacity) 値は固定のパーセンテージで乗算されます。<br/>            効果コンテナは、アルファ値を変調する効果を指定します。 |
| [`AlphaModulateFixed`](/slides/python-net/ja/aspose.slides.effects/alphamodulatefixed/) | Alpha Modulate Fixed 効果を表します。<br/>            効果の alpha (opacity) 値は固定のパーセンテージで乗算されます。 |

| [`ColorReplace`](/slides/python-net/ja/aspose.slides.effects/colorreplace/) | Color Replacement 効果を表します。<br/>            すべての効果カラーが固定色に変更されます。<br/>            アルファ値は影響を受けません。 |
