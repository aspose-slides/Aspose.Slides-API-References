## FillOverlay クラス

Fill Overlay エフェクトを表します。 Fill overlay はオブジェクトに対して追加の塗りを指定し、2つの塗りをブレンドするために使用できます。

**継承:**[`FillOverlay`](/slides/python-net/ja/aspose.slides.effects/filloverlay) → [`ImageTransformOperation`](/slides/python-net/ja/aspose.slides.effects/imagetransformoperation) → [`PVIObject`](/slides/python-net/ja/aspose.slides/pviobject)

FillOverlay 型は以下のメンバーを公開します。

| プロパティ | 説明 |
| :- | :- |
| [`fill_format`](/slides/python-net/ja/aspose.slides.effects/filloverlay/fill_format/) | 塗りの形式。<br/>            読み取り専用 [`IFillFormat`](/slides/python-net/ja/aspose.slides/ifillformat)。 |
