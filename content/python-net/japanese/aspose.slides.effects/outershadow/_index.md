## OuterShadow クラス

外側の影効果を表します。

OuterShadow タイプは次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`blur_radius`](/slides/python-net/ja/aspose.slides.effects/outershadow/blur_radius/) | ポイント単位のぼかし半径。<br/>            デフォルト値 – 0 pt。<br/>            読み取り/書き込み **float**。 |
| [`direction`](/slides/python-net/ja/aspose.slides.effects/outershadow/direction/) | 影の方向（度単位）。<br/>            デフォルト値 – 0 °（左から右）。<br/>            読み取り/書き込み **float**。 |
| [`distance`](/slides/python-net/ja/aspose.slides.effects/outershadow/distance/) | オブジェクトから影までの距離（ポイント単位）。<br/>            デフォルト値 – 0 pt。<br/>            読み取り/書き込み **float**。 |
| [`shadow_color`](/slides/python-net/ja/aspose.slides.effects/outershadow/shadow_color/) | 影の色。<br/>            デフォルト値 – 自動的な黒（テーマ依存）。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat)。 |
| [`rectangle_align`](/slides/python-net/ja/aspose.slides.effects/outershadow/rectangle_align/) | 矩形の配置。<br/>            デフォルト値 – [`RectangleAlignment.BOTTOM`](/slides/python-net/ja/aspose.slides/rectanglealignment/BOTTOM)。 <br/>            読み取り/書き込み [`RectangleAlignment`](/slides/python-net/ja/aspose.slides/rectanglealignment)。 |
| [`skew_horizontal`](/slides/python-net/ja/aspose.slides.effects/outershadow/skew_horizontal/) | 水平方向のスキュー角度（度単位）。<br/>            デフォルト値 – 0 °。<br/>            読み取り/書き込み **float**。 |
| [`skew_vertical`](/slides/python-net/ja/aspose.slides.effects/outershadow/skew_vertical/) | 垂直方向のスキュー角度（度単位）。<br/>            デフォルト値 – 0 °。<br/>            読み取り/書き込み **float**。 |
| [`rotate_shadow_with_shape`](/slides/python-net/ja/aspose.slides.effects/outershadow/rotate_shadow_with_shape/) | 影が形状と共に回転するかどうかを示します。<br/>            デフォルト値 – true。<br/>            読み取り/書き込み **bool**。 |
| [`scale_horizontal`](/slides/python-net/ja/aspose.slides.effects/outershadow/scale_horizontal/) | 元のサイズに対する水平方向のスケーリング係数（パーセント）。<br/>            マイナスのスケーリングは反転を引き起こします。<br/>            デフォルト値 – 100 %。<br/>            読み取り/書き込み **float**。 |
| [`scale_vertical`](/slides/python-net/ja/aspose.slides.effects/outershadow/scale_vertical/) | 元のサイズに対する垂直方向のスケーリング係数（パーセント）。<br/>            マイナスのスケーリングは反転を引き起こします。<br/>            デフォルト値 – 100 %。<br/>            読み取り/書き込み **float**。 |
