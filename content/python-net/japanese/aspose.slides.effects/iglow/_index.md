## IGlow クラス

Glow効果を表し、オブジェクトのエッジの外側にカラーのぼかしアウトラインが追加されます。

IGlow型は以下のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`radius`](/slides/python-net/ja/aspose.slides.effects/iglow/radius/) | 半径。<br/>            読み取り/書き込み **float**. |
| [`color`](/slides/python-net/ja/aspose.slides.effects/iglow/color/) | カラー形式。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat). |
