## IDuotoneEffectiveData クラス

Duotone 効果を表す不変オブジェクトです。  
各ピクセルについて、線形補間を通じて clr1 と clr2 を組み合わせ、そのピクセルの新しい色を決定します。

IDuotoneEffectiveData 型は次のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`color1`](/slides/python-net/ja/aspose.slides.effects/iduotoneeffectivedata/color1/) | 暗いピクセル用のターゲット カラー形式を返します。<br/>            読み取り専用 [`Color`](/slides/python-net/ja/aspose.slides/color). |
| [`color2`](/slides/python-net/ja/aspose.slides.effects/iduotoneeffectivedata/color2/) | 明るいピクセル用のターゲット カラー形式を返します。<br/>            読み取り専用 [`Color`](/slides/python-net/ja/aspose.slides/color). |
