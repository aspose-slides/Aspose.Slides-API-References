## ILuminanceEffectiveData クラス

Luminance エフェクトを表します。
            明るさは、すべての色を白または黒に線形にシフトします。
            コントラストは、すべての色の間隔を拡大または縮小します。

ILuminanceEffectiveData 型は、次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`brightness`](/slides/python-net/ja/aspose.slides.effects/iluminanceeffectivedata/brightness/) | 明るさ。<br/>            読み取り専用 **float**. |
| [`contrast`](/slides/python-net/ja/aspose.slides.effects/iluminanceeffectivedata/contrast/) | コントラスト。<br/>            読み取り専用 **float**. |
