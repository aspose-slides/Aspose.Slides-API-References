## IBlur クラス

シェイプ全体（塗りつぶしを含む）に適用されるぼかし効果を表します。  
アルファを含むすべてのカラーチャンネルが影響を受けます。

IBlur 型は以下のメンバーを公開します。

## プロパティ

| Property | Description |
| :- | :- |
| [`radius`](/slides/python-net/ja/aspose.slides.effects/iblur/radius/) | ぼかし半径を取得または設定します。<br/>            読み取り/書き込み **float**. |
| [`grow`](/slides/python-net/ja/aspose.slides.effects/iblur/grow/) | ぼかしの結果としてオブジェクトの境界を拡張するかどうかを決定します。<br/>            True は境界が拡張されることを示し、false は拡張されないことを示します。<br/>            読み取り/書き込み **bool**. |
