## ITintEffectiveData クラス

Tint効果を表す不変オブジェクトです。  
指定された量だけ、色相に向かってまたは離れてエフェクトの色値をシフトします。

ITintEffectiveData型は以下のメンバーを公開します:

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`hue`](/slides/python-net/ja/aspose.slides.effects/itinteffectivedata/hue/) | 色相を返します。<br/>            読み取り専用 **float**. |
| [`amount`](/slides/python-net/ja/aspose.slides.effects/itinteffectivedata/amount/) | エフェクト量を返します。<br/>            読み取り専用 **float**. |
