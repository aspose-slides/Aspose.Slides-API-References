## IColorChange クラス

カラー変更エフェクトを表します。  
FromColor のインスタンスは ToColor のインスタンスに置き換えられます。

IColorChange 型は以下のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`from_color`](/slides/python-net/ja/aspose.slides.effects/icolorchange/from_color/) | 置き換えられる色。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat). |
| [`to_color`](/slides/python-net/ja/aspose.slides.effects/icolorchange/to_color/) | 置き換える色。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat). |
