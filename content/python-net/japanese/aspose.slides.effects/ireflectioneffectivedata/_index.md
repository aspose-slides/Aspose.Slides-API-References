## IReflectionEffectiveData クラス

リフレクション効果を表す不変オブジェクトです。

IReflectionEffectiveData 型は以下のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/ja/aspose.slides.effects/ireflectioneffectivedata/start_pos_alpha/) | 開始アルファ値（パーセント）の開始位置（アルファ勾配ランプに沿って）を指定します。<br/>            読み取り専用 **float**. |
| [`end_pos_alpha`](/slides/python-net/ja/aspose.slides.effects/ireflectioneffectivedata/end_pos_alpha/) | 終了アルファ値（パーセント）の終了位置（アルファ勾配ランプに沿って）を指定します。<br/>            読み取り専用 **float**. |
| [`fade_direction`](/slides/python-net/ja/aspose.slides.effects/ireflectioneffectivedata/fade_direction/) | 反射のオフセット方向を指定します。（角度）。<br/>            読み取り専用 **float**. |
| [`start_reflection_opacity`](/slides/python-net/ja/aspose.slides.effects/ireflectioneffectivedata/start_reflection_opacity/) | 開始時の反射不透明度。（パーセント）。<br/>            読み取り専用 **float**. |
| [`end_reflection_opacity`](/slides/python-net/ja/aspose.slides.effects/ireflectioneffectivedata/end_reflection_opacity/) | 終了時の反射不透明度。（パーセント）。<br/>            読み取り専用 **float**. |
| [`blur_radius`](/slides/python-net/ja/aspose.slides.effects/ireflectioneffectivedata/blur_radius/) | ぼかし半径。<br/>            読み取り専用 **float**. |
| [`direction`](/slides/python-net/ja/aspose.slides.effects/ireflectioneffectivedata/direction/) | 反射の方向。<br/>            読み取り専用 **float**. |
| [`distance`](/slides/python-net/ja/aspose.slides.effects/ireflectioneffectivedata/distance/) | 反射の距離。<br/>            読み取り専用 **float**. |
| [`rectangle_align`](/slides/python-net/ja/aspose.slides.effects/ireflectioneffectivedata/rectangle_align/) | 矩形の配置。<br/>            読み取り専用 [`RectangleAlignment`](/slides/python-net/ja/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/ja/aspose.slides.effects/ireflectioneffectivedata/skew_horizontal/) | 水平せん断角度を指定します。<br/>            読み取り専用 **float**. |
| [`skew_vertical`](/slides/python-net/ja/aspose.slides.effects/ireflectioneffectivedata/skew_vertical/) |垂直せん断角度を指定します。<br/>            読み取り専用 **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/ja/aspose.slides.effects/ireflectioneffectivedata/rotate_shadow_with_shape/) | シェイプが回転した場合に、反射がシェイプとともに回転するかどうかを指定します。<br/>            読み取り専用 **bool**. |
| [`scale_horizontal`](/slides/python-net/ja/aspose.slides.effects/ireflectioneffectivedata/scale_horizontal/) | 水平スケーリング係数を指定します。負のスケーリングは反転を引き起こします。（パーセント）<br/>            読み取り専用 **float**. |
| [`scale_vertical`](/slides/python-net/ja/aspose.slides.effects/ireflectioneffectivedata/scale_vertical/) | 垂直スケーリング係数を指定します。負のスケーリングは反転を引き起こします。（パーセント）<br/>            読み取り専用 **float**. |
