## IFillOverlayEffectiveData クラス

オブジェクトの Fill Overlay 効果を表す不変オブジェクトです。Fill Overlay は、オブジェクトに追加の塗りつぶしを指定し、2 つの塗りつぶしをブレンドするために使用できます。

IFillOverlayEffectiveData タイプは、次のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`blend`](/slides/python-net/ja/aspose.slides.effects/ifilloverlayeffectivedata/blend/) | FillBlendMode.<br/>            読み取り専用 [`FillBlendMode`](/slides/python-net/ja/aspose.slides/fillblendmode). |
| [`fill_format`](/slides/python-net/ja/aspose.slides.effects/ifilloverlayeffectivedata/fill_format/) | 塗りつぶし形式。<br/>            読み取り専用 [`IFillFormatEffectiveData`](/slides/python-net/ja/aspose.slides/ifillformateffectivedata). |
