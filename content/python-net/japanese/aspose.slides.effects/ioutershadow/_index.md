## IOuterShadow クラス

外部シャドウ効果を表します。

IOuterShadow型は次のメンバーを公開します。

## プロパティ

| Property | Description |
| :- | :- |
| [`blur_radius`](/slides/python-net/ja/aspose.slides.effects/ioutershadow/blur_radius/) | ポイント単位のぼかし半径。<br/>            デフォルト値 – 0 pt。<br/>            読み書き可能 **float**. |
| [`direction`](/slides/python-net/ja/aspose.slides.effects/ioutershadow/direction/) | 影の方向（度単位）。<br/>            デフォルト値 – 0 °（左から右）。<br/>            読み書き可能 **float**. |
| [`distance`](/slides/python-net/ja/aspose.slides.effects/ioutershadow/distance/) | オブジェクトから影までの距離（ポイント単位）。<br/>            デフォルト値 – 0 pt。<br/>            読み書き可能 **float**. |
| [`shadow_color`](/slides/python-net/ja/aspose.slides.effects/ioutershadow/shadow_color/) | 影の色。<br/>            デフォルト値 – 自動的な黒（テーマ依存）。<br/>            読み取り専用 [`IColorFormat`](/slides/python-net/ja/aspose.slides/icolorformat). |
| [`rectangle_align`](/slides/python-net/ja/aspose.slides.effects/ioutershadow/rectangle_align/) | 矩形の配置。<br/>            デフォルト値 – [`RectangleAlignment.BOTTOM`](/slides/python-net/ja/aspose.slides/rectanglealignment/BOTTOM)。 <br/>            読み書き可能 [`RectangleAlignment`](/slides/python-net/ja/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/ja/aspose.slides.effects/ioutershadow/skew_horizontal/) | 水平方向の斜め角度（度単位）。<br/>            デフォルト値 – 0 °。<br/>            読み書き可能 **float**. |
| [`skew_vertical`](/slides/python-net/ja/aspose.slides.effects/ioutershadow/skew_vertical/) | 垂直方向の斜め角度（度単位）。<br/>            デフォルト値 – 0 °。<br/>            読み書き可能 **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/ja/aspose.slides.effects/ioutershadow/rotate_shadow_with_shape/) | 影がシェイプと一緒に回転するかどうかを示します。<br/>            デフォルト値 – true。<br/>            読み書き可能 **bool**. |
| [`scale_horizontal`](/slides/python-net/ja/aspose.slides.effects/ioutershadow/scale_horizontal/) | 元のサイズに対する水平方向のスケーリング係数（パーセント）。<br/>            負のスケーリングは反転を引き起こします。<br/>            デフォルト値 – 100 %。<br/>            読み書き可能 **float**. |
| [`scale_vertical`](/slides/python-net/ja/aspose.slides.effects/ioutershadow/scale_vertical/) | 元のサイズに対する垂直方向のスケーリング係数（パーセント）。<br/>            負のスケーリングは反転を引き起こします。<br/>            デフォルト値 – 100 %。<br/>            読み書き可能 **float**. |
