## IOuterShadowEffectiveData クラス

外側の影効果を表す不変オブジェクトです。

IOuterShadowEffectiveData 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`blur_radius`](/slides/python-net/ja/aspose.slides.effects/ioutershadoweffectivedata/blur_radius/) | ぼかし半径。<br/>            読み取り専用 **float**. |
| [`direction`](/slides/python-net/ja/aspose.slides.effects/ioutershadoweffectivedata/direction/) | 影の方向。<br/>            読み取り専用 **float**. |
| [`distance`](/slides/python-net/ja/aspose.slides.effects/ioutershadoweffectivedata/distance/) | 影の距離。<br/>            読み取り専用 **float**. |
| [`shadow_color`](/slides/python-net/ja/aspose.slides.effects/ioutershadoweffectivedata/shadow_color/) | 影の色。<br/>            読み取り専用 [`Color`](/slides/python-net/ja/aspose.slides/color). |
| [`rectangle_align`](/slides/python-net/ja/aspose.slides.effects/ioutershadoweffectivedata/rectangle_align/) | 矩形の配置。<br/>            読み取り専用 [`RectangleAlignment`](/slides/python-net/ja/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/ja/aspose.slides.effects/ioutershadoweffectivedata/skew_horizontal/) | 水平スキュー角度（度単位）を指定します。<br/>            読み取り専用 **float**. |
| [`skew_vertical`](/slides/python-net/ja/aspose.slides.effects/ioutershadoweffectivedata/skew_vertical/) | 垂直スキュー角度（度単位）を指定します。<br/>            読み取り専用 **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/ja/aspose.slides.effects/ioutershadoweffectivedata/rotate_shadow_with_shape/) | シェイプが回転した場合に影もシェイプとともに回転するかどうかを指定します。<br/>            読み取り専用 **bool**. |
| [`scale_horizontal`](/slides/python-net/ja/aspose.slides.effects/ioutershadoweffectivedata/scale_horizontal/) | 水平スケーリング係数を指定します。負のスケーリングは反転を引き起こします。<br/>            読み取り専用 **float**. |
| [`scale_vertical`](/slides/python-net/ja/aspose.slides.effects/ioutershadoweffectivedata/scale_vertical/) | 垂直スケーリング係数を指定します。負のスケーリングは反転を引き起こします。<br/>            読み取り専用 **float**. |
