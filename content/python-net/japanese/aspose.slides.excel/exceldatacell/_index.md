## ExcelDataCell クラス

Excel ワークブック内の単一のセルを表します。

ExcelDataCell 型は次のメンバーを公開します。

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`value`](/slides/python-net/ja/aspose.slides.excel/exceldatacell/value/) | Excel のセルに含まれる値を取得します。 |
| [`name`](/slides/python-net/ja/aspose.slides.excel/exceldatacell/name/) | チャート データ セルの名前を取得します。 |
| [`row`](/slides/python-net/ja/aspose.slides.excel/exceldatacell/row/) | セルが配置されているワークシートの行のゼロベースインデックスを取得します。<br/>            読み取り専用 **int**。 |
| [`column`](/slides/python-net/ja/aspose.slides.excel/exceldatacell/column/) | セルが配置されているワークシートの列のゼロベースインデックスを取得します。<br/>            読み取り専用 **int**。 |
