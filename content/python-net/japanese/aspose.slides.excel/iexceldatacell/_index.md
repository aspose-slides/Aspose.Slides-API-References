## IExcelDataCell クラス

Excel ブック内の単一セルを表します。

IExcelDataCell 型は以下のメンバーを公開します：

## プロパティ

| プロパティ | 説明 |
| :- | :- |
| [`value`](/slides/python-net/ja/aspose.slides.excel/iexceldatacell/value/) | Excel セルに含まれる値を取得します。<br/>            読み取り専用 **any**. |
| [`name`](/slides/python-net/ja/aspose.slides.excel/iexceldatacell/name/) | チャート データ セルの名前を取得します。<br/>            読み取り専用 **str**. |
| [`row`](/slides/python-net/ja/aspose.slides.excel/iexceldatacell/row/) | セルが位置するワークシートの行のゼロベース インデックスを取得します。<br/>            読み取り専用 **int**. |
| [`column`](/slides/python-net/ja/aspose.slides.excel/iexceldatacell/column/) | セルが位置するワークシートの列のゼロベース インデックスを取得します。<br/>            読み取り専用 **int**. |
