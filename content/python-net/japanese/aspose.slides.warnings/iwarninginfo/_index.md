## IWarningInfo クラス

すべての警告の基底インターフェイスを表します。

IWarningInfo 型は以下のメンバーを公開します。

## プロパティ

| Property | 説明 |
| :- | :- |
| [`warning_type`](/slides/python-net/ja/aspose.slides.warnings/iwarninginfo/warning_type/) | 警告のタイプを返します。<br/>            読み取り専用 [`IWarningInfo.warning_type`](/slides/python-net/ja/aspose.slides.warnings/iwarninginfo/warning_type). |
| [`description`](/slides/python-net/ja/aspose.slides.warnings/iwarninginfo/description/) | この警告の人間が読みやすい説明を返します。<br/>            読み取り専用 **str**. |

## メソッド

| Method | 説明 |
| :- | :- |
| [`send_warning(self, receiver)`](/slides/python-net/ja/aspose.slides.warnings/iwarninginfo/send_warning/#iwarningcallback) | receiver が None でない場合、指定された受信者に警告を終了し、受信者が操作を中止することを決定した場合は <br/>            AbortRequestedException をスローします. |
