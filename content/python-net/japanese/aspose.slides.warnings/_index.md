さまざまな種類の警告を表すクラスを含みます
## クラス

| クラス | 説明 |
| :- | :- |
| [`IKnownIssueWarningInfo`](/slides/python-net/ja/aspose.slides.warnings/iknownissuewarninginfo/) | 近い将来に修正されない既知の問題に関する警告を表します。 |
| [`INotImplementedWarningInfo`](/slides/python-net/ja/aspose.slides.warnings/inotimplementedwarninginfo/) | 近い将来に実装されない既知の未実装機能に関する警告を表します。 |
| [`IObsoletePresLockingBehaviorWarningInfo`](/slides/python-net/ja/aspose.slides.warnings/iobsoletepreslockingbehaviorwarninginfo/) | この警告は、廃止されたプレゼンテーションのロック動作が使用されていることを示します。 |
| [`IPresentationSignedWarningInfo`](/slides/python-net/ja/aspose.slides.warnings/ipresentationsignedwarninginfo/) | この警告は、読み取られたプレゼンテーションが署名を持っていることを示します <br/>            そしてこの署名は処理中に削除されます。 |
| [`IWarningCallback`](/slides/python-net/ja/aspose.slides.warnings/iwarningcallback/) | 警告を受け取るクラスのインターフェイスです。 |
| [`IWarningInfo`](/slides/python-net/ja/aspose.slides.warnings/iwarninginfo/) | すべての警告の基本インターフェイスを表します。 |

## 列挙型

| 列挙型 | 説明 |
| :- | :- |
| [`ReturnAction`](/slides/python-net/ja/aspose.slides.warnings/returnaction/) | 警告コールバックの決定オプションを表します。 |
| [`WarningType`](/slides/python-net/ja/aspose.slides.warnings/warningtype/) | 警告の種類を表します。 |
