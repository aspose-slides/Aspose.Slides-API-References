## PresentationContentAmountType 列挙体

生成されたプレゼンテーションに含まれるコンテンツの量を指定し、スライド数とスライドごとの詳細度の両方に影響します。

PresentationContentAmountType 型は以下のメンバーを公開します：

## フィールド

| フィールド | 説明 |
| :- | :- |
| BRIEF | 短く基本的なコンテンツ。 |
| MEDIUM | 適度な量のコンテンツ。 |
| DETAILED | 広範なテキストを含む最も詳細なオプション。 |
