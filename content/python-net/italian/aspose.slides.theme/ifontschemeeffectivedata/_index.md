## classe IFontSchemeEffectiveData

Oggetto immutabile che contiene le proprietà effettive dello schema di caratteri.

Il tipo IFontSchemeEffectiveData espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`minor`](/slides/python-net/it/aspose.slides.theme/ifontschemeeffectivedata/minor/) | Restituisce la collezione di caratteri per una parte "body" della diapositiva.<br/>            Sola lettura [`IFontsEffectiveData`](/slides/python-net/it/aspose.slides/ifontseffectivedata). |
| [`major`](/slides/python-net/it/aspose.slides.theme/ifontschemeeffectivedata/major/) | Restituisce la collezione di caratteri per una parte "heading" della diapositiva.<br/>            Sola lettura [`IFontsEffectiveData`](/slides/python-net/it/aspose.slides/ifontseffectivedata). |
| [`name`](/slides/python-net/it/aspose.slides.theme/ifontschemeeffectivedata/name/) | Restituisce il nome dello schema di caratteri.<br/>            Sola lettura **str**. |


### Osservazioni

Questa interfaccia è utilizzata come parte di [`IThemeEffectiveData`](/slides/python-net/it/aspose.slides.theme/ithemeeffectivedata).
