## IOverrideThemeManager classe

Fornisce accesso a diversi tipi di temi sovrascritti.

Il tipo IOverrideThemeManager espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`is_override_theme_enabled`](/slides/python-net/it/aspose.slides.theme/ioverridethememanager/is_override_theme_enabled/) | Determina se OverrideTheme sovrascrive o meno il tema efficace ereditato.<br/>            Per abilitare OverrideTheme per la sovrascrittura usare i metodi OverrideTheme.Init*().<br/>            Per disabilitare OverrideTheme dalla sovrascrittura usare il metodo OverrideTheme.Clear().<br/>            Solo lettura **bool**. |
| [`override_theme`](/slides/python-net/it/aspose.slides.theme/ioverridethememanager/override_theme/) | Restituisce l'oggetto del tema sovrascritto.<br/>            Lettura/scrittura [`IOverrideTheme`](/slides/python-net/it/aspose.slides.theme/ioverridetheme). |
