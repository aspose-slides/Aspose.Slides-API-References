## MasterTheme classe

Rappresenta un tema master.

**Ereditarietà:**[`MasterTheme`](/slides/python-net/it/aspose.slides.theme/mastertheme) → [`Theme`](/slides/python-net/it/aspose.slides.theme/theme)

Il tipo MasterTheme espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`color_scheme`](/slides/python-net/it/aspose.slides.theme/mastertheme/color_scheme/) | Restituisce lo schema dei colori.<br/>            Solo lettura [`IColorScheme`](/slides/python-net/it/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/it/aspose.slides.theme/mastertheme/font_scheme/) | Restituisce lo schema dei caratteri.<br/>            Solo lettura [`IFontScheme`](/slides/python-net/it/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/it/aspose.slides.theme/mastertheme/format_scheme/) | Restituisce lo schema del formato della forma.<br/>            Solo lettura [`IFormatScheme`](/slides/python-net/it/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/it/aspose.slides.theme/mastertheme/presentation/) | Restituisce la presentazione genitore.<br/>            Solo lettura [`IPresentation`](/slides/python-net/it/aspose.slides/ipresentation). |
| [`extra_color_schemes`](/slides/python-net/it/aspose.slides.theme/mastertheme/extra_color_schemes/) | Restituisce la collezione di schemi di colore aggiuntivi.<br/>            Questi schemi non influenzano l'aspetto della presentazione, possono essere selezionati come schema di colore principale per una diapositiva.<br/>            Solo lettura [`IExtraColorSchemeCollection`](/slides/python-net/it/aspose.slides.theme/iextracolorschemecollection). |
| [`name`](/slides/python-net/it/aspose.slides.theme/mastertheme/name/) | Restituisce il nome di un tema.<br/>            Lettura/scrittura **str**. |

## Metodi
