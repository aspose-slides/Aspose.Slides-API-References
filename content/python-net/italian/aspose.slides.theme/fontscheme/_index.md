## FontScheme classe

Memorizza i font definiti dal tema.

Il tipo FontScheme espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`minor`](/slides/python-net/it/aspose.slides.theme/fontscheme/minor/) | Restituisce la collezione di font per la parte "body" della diapositiva.<br/>            Solo lettura [`IFonts`](/slides/python-net/it/aspose.slides/ifonts). |
| [`major`](/slides/python-net/it/aspose.slides.theme/fontscheme/major/) | Restituisce la collezione di font per la parte "heading" della diapositiva.<br/>            Solo lettura [`IFonts`](/slides/python-net/it/aspose.slides/ifonts). |
| [`name`](/slides/python-net/it/aspose.slides.theme/fontscheme/name/) | Restituisce il nome dello schema di font.<br/>            Lettura/scrittura **str**. |
