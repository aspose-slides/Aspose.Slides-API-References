## InkBrush classe

Rappresenta un oggetto inkBrush.

Il tipo InkBrush espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`color`](/slides/python-net/it/aspose.slides.ink/inkbrush/color/) | Ottiene o imposta il colore del pennello per una linea. |
| [`size`](/slides/python-net/it/aspose.slides.ink/inkbrush/size/) | Ottiene o imposta la dimensione del pennello per una linea in punti. |
| [`ink_effect`](/slides/python-net/it/aspose.slides.ink/inkbrush/ink_effect/) | Ottiene il tipo di effetto inchiostro (ad es., Galaxy, Gold, Silver) che definisce lo stile visivo del tratto di inchiostro.<br/>            Il valore è analizzato dalla proprietà del pennello "inkEffects". Se non è specificato alcun effetto riconosciuto,<br/>            [`InkEffectType.NOT_DEFINED`](/slides/python-net/it/aspose.slides.ink/inkeffecttype/NOT_DEFINED) viene restituito. |
