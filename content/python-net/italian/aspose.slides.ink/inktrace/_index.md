## InkTrace classe

Rappresenta un oggetto Trace.  
Un elemento Trace è usato per registrare i dati acquisiti dal digitalizzatore.  
Contiene una sequenza di punti codificati secondo le specifiche fornite dall'oggetto InkTraceFormat.

Il tipo InkTrace espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`brush`](/slides/python-net/it/aspose.slides.ink/inktrace/brush/) | Ottiene Brush per l'IInkLine [`IInkBrush`](/slides/python-net/it/aspose.slides.ink/iinkbrush)<br/>            Solo lettura. |
| [`points`](/slides/python-net/it/aspose.slides.ink/inktrace/points/) | Ottiene i punti per l'IInkLine [`PointF`](/slides/python-net/it/aspose.slides/pointf)<br/>            Solo lettura. |
