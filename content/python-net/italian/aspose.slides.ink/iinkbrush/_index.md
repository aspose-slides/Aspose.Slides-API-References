## IInkBrush class

Rappresenta il pennello di tracciatura.

Il tipo IInkBrush espone i seguenti membri:

## Proprietà

| Property | Description |
| :- | :- |
| [`color`](/slides/python-net/it/aspose.slides.ink/iinkbrush/color/) | Ottiene o imposta il colore del pennello per una linea. |
| [`size`](/slides/python-net/it/aspose.slides.ink/iinkbrush/size/) | Ottiene o imposta la dimensione del pennello per una linea in punti. |
| [`ink_effect`](/slides/python-net/it/aspose.slides.ink/iinkbrush/ink_effect/) | Ottiene il tipo di effetto inchiostro (ad esempio, Galaxy, Gold, Silver) che definisce lo stile visivo della traccia di inchiostro.<br/>            Il valore viene analizzato dalla proprietà brush "inkEffects". Se non è specificato alcun effetto riconosciuto,<br/>            [`InkEffectType.NOT_DEFINED`](/slides/python-net/it/aspose.slides.ink/inkeffecttype/NOT_DEFINED) viene restituito. |
