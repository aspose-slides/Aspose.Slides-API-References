## Enumerazione InkEffectType

Specifica un insieme di effetti visivi predefiniti per il rendering dell'inchiostro. Ogni effetto corrisponde a una texture o immagine che simula un aspetto stilizzato dell'inchiostro. Questi valori possono essere usati per personalizzare lo stile visivo dei tratti di inchiostro digitale durante il rendering.

Il tipo InkEffectType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| NOT_DEFINED | L'effetto non è definito o è sconosciuto. Questo valore può essere usato come predefinito o di riserva. |
| BRONZE | Una texture metallica calda, marrone, che ricorda l'inchiostro di bronzo. |
| GALAXY | Una texture colorata e scintillante che ricorda una galassia, con tonalità cosmiche. |
| GOLD | Una texture dorata brillante e metallica che conferisce ai tratti d'inchiostro un aspetto lussuoso. |
| LAVA | Una texture infuocata che ricorda lava fusa, con sfumature rosse e arancioni. |
| OCEAN | Una texture di un blu profondo, simile a un fluido, che imita le onde dell'oceano o l'inchiostro a base d'acqua. |
| RAINBOW_GLITTER | Un effetto glitter arcobaleno colorato e scintillante, usato per tratti d'inchiostro festosi o vivaci. |
| ROSE_GOLD | Una miscela morbida di rosa e oro, simile al rose gold, per tratti d'inchiostro eleganti. |
| SILVER | Una texture argentata fresca e metallica che simula l'inchiostro argentato classico. |
