## MathSpacingRules enumerazione

Tipi di spazio (spaziatura orizzontale) tra le colonne di una matrice

Il tipo MathSpacingRules espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| SINGLE_SPACING_GAP | Singolo (1 em per colonne o 1 linea per righe) |
| ONE_AND_HALF_SPACING_GAP | Uno e mezzo (1.5 em per colonne o 1.5 linee per righe) |
| DOUBLE_SPACING_GAP | Doppio spazio (2 em per colonne o 2 linee per righe) |
| EXACTLY | Valore esatto<br/>            Per le colonne, utilizza il valore di ColumnGap, misurato in twips<br/>            Per le righe, utilizza il valore di RowGap, misurato in twips |
| MULTIPLE | Multiplo<br/>            Per le colonne, utilizza il valore di ColumnGap, misurato in incrementi di 0.5 em<br/>            Per le righe, utilizza il valore di RowGap, misurato in linee |
