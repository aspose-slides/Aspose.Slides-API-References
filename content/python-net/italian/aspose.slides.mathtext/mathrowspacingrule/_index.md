## Enumerazione MathRowSpacingRule

Il tipo di spaziatura verticale tra le colonne in una matrice o array

Il tipo MathRowSpacingRule espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| SINGLE_LINE_GAP | spaziatura di una riga |
| ONE_AND_A_HALF_LINE_GAP | spaziatura di una riga e mezza |
| TWO_LINE_GAP | spaziatura di due righe |
| EXACTLY | Esattamente (si basa sul valore della proprietà RowSpacing, misurato in punti) |
| MULTIPLE | Multiplo (si basa sul valore della proprietà RowSpacing, misurato in linee) |
