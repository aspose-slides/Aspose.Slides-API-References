## zero_desc proprietà
Ottiene o imposta un valore che indica se la discesa (profondità sotto la linea di base)
            dell'elemento di base deve essere trattata come zero.

### Osservazioni
Quando `true`, il fantasma non abbassa la linea di base della riga matematica circostante 
            riga matematica. Corrisponde all'attributo OMML `m:zeroDesc`.
