## zero_asc property
Ottiene o imposta un valore che indica se l'ascesa (altezza sopra la linea di base) dell'elemento di base deve essere trattata come zero.


### Osservazioni

Quando `true`, il fantasma non solleva la linea di base della riga matemica circostante. Corrisponde all'attributo OMML `m:zeroAsc`.
