## row_spacing proprietà
Spaziatura tra le righe di un array
            È usato solo quando RowSpacingRule è impostato su 3 Exactly, nel qual caso l'unità di misura è punti
            o Multiple, nel qual caso l'unità di misura è mezze linee.
            Predefinito: 0
