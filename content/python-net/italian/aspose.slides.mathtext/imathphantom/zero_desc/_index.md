## zero_desc proprietà
Ottiene o imposta un valore che indica se la discesa (profondità sotto la linea di base) dell'elemento base deve essere considerata zero.

### Osservazioni

Quando `true`, il phantom non abbassa la linea di base della riga matematica circostante. Corrisponde all'attributo OMML `m:zeroDesc`.
