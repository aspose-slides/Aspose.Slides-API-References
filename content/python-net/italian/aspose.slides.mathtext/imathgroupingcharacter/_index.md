## IMathGroupingCharacter classe

Specifica un simbolo di raggruppamento sopra o sotto un'espressione, di solito per evidenziare la relazione tra gli elementi

Il tipo IMathGroupingCharacter espone i seguenti membri:

## Proprietà

| Property | Description |
| :- | :- |
| [`base`](/slides/python-net/it/aspose.slides.mathtext/imathgroupingcharacter/base/) | Argomento di base |
| [`character`](/slides/python-net/it/aspose.slides.mathtext/imathgroupingcharacter/character/) | Carattere di raggruppamento<br/>            Valore predefinito: U+23DF (BOTTOM CURLY BRACKET) |
| [`position`](/slides/python-net/it/aspose.slides.mathtext/imathgroupingcharacter/position/) | Posizione del carattere di raggruppamento.<br/>            Predefinito: Bottom |
| [`vertical_justification`](/slides/python-net/it/aspose.slides.mathtext/imathgroupingcharacter/vertical_justification/) | Giustificazione verticale del carattere di gruppo.<br/>            Specifica l'allineamento dell'oggetto rispetto alla linea di base.<br/>            Per esempio, quando il carattere di gruppo è sopra l'oggetto, <br/>            VerticalJustification di Top indica che la parte superiore dell'oggetto cade sulla linea di base;<br/>            quando VerticalJustification è impostato su Bottom, la parte inferiore dell'oggetto è sulla linea di base<br/>            Predefinito: Bottom per Position=Top, e Top per Position=Bottom |
