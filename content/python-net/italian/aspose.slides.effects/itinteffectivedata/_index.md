## ITintEffectiveData classe

Oggetto immutabile che rappresenta un effetto Tint.  
Sposta i valori di colore dell'effetto verso/lontano dalla tonalità di una quantità specificata.

Il tipo ITintEffectiveData espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`hue`](/slides/python-net/it/aspose.slides.effects/itinteffectivedata/hue/) | Restituisce la tonalità.<br/>            Solo lettura **float**. |
| [`amount`](/slides/python-net/it/aspose.slides.effects/itinteffectivedata/amount/) | Restituisce la quantità dell'effetto.<br/>            Solo lettura **float**. |
