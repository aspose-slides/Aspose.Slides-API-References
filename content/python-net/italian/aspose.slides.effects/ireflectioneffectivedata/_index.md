## IReflectionEffectiveData classe

Oggetto immutabile che rappresenta un effetto di riflessione.

Il tipo IReflectionEffectiveData espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/it/aspose.slides.effects/ireflectioneffectivedata/start_pos_alpha/) | Specifica la posizione iniziale (lungo la rampa del gradiente alfa) del valore alfa iniziale (percentuali).<br/>            Sola lettura **float**. |
| [`end_pos_alpha`](/slides/python-net/it/aspose.slides.effects/ireflectioneffectivedata/end_pos_alpha/) | Specifica la posizione finale (lungo la rampa del gradiente alfa) del valore alfa finale (percentuali).<br/>            Sola lettura **float**. |
| [`fade_direction`](/slides/python-net/it/aspose.slides.effects/ireflectioneffectivedata/fade_direction/) | Specifica la direzione per spostare la riflessione. (angolo).<br/>            Sola lettura **float**. |
| [`start_reflection_opacity`](/slides/python-net/it/aspose.slides.effects/ireflectioneffectivedata/start_reflection_opacity/) | Opacità iniziale della riflessione. (percentuali).<br/>            Sola lettura **float**. |
| [`end_reflection_opacity`](/slides/python-net/it/aspose.slides.effects/ireflectioneffectivedata/end_reflection_opacity/) | Opacità finale della riflessione. (percentuali).<br/>            Sola lettura **float**. |
| [`blur_radius`](/slides/python-net/it/aspose.slides.effects/ireflectioneffectivedata/blur_radius/) | Raggio della sfocatura.<br/>            Sola lettura **float**. |
