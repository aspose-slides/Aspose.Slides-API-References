## IOuterShadow classe

Rappresenta un effetto di ombra esterna.

Il tipo IOuterShadow espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`blur_radius`](/slides/python-net/it/aspose.slides.effects/ioutershadow/blur_radius/) | Raggio di sfocatura, in punti.<br/>            Valore predefinito – 0 pt.<br/>            Lettura/scrittura **float**. |
| [`direction`](/slides/python-net/it/aspose.slides.effects/ioutershadow/direction/) | Direzione dell'ombra, in gradi.<br/>            Valore predefinito – 0 ° (da sinistra a destra).<br/>            Lettura/scrittura **float**. |
| [`distance`](/slides/python-net/it/aspose.slides.effects/ioutershadow/distance/) | Distanza dell'ombra dall'oggetto, in punti.<br/>            Valore predefinito – 0 pt.<br/>            Lettura/scrittura **float**. |
| [`shadow_color`](/slides/python-net/it/aspose.slides.effects/ioutershadow/shadow_color/) | Colore dell'ombra.<br/>            Valore predefinito – nero automatico (dipendente dal tema).<br/>            Sola lettura [`IColorFormat`](/slides/python-net/it/aspose.slides/icolorformat). |
| [`rectangle_align`](/slides/python-net/it/aspose.slides.effects/ioutershadow/rectangle_align/) | Allineamento del rettangolo.<br/>            Valore predefinito – [`RectangleAlignment.BOTTOM`](/slides/python-net/it/aspose.slides/rectanglealignment/BOTTOM). <br/>            Lettura/scrittura [`RectangleAlignment`](/slides/python-net/it/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/it/aspose.slides.effects/ioutershadow/skew_horizontal/) | Angolo di inclinazione orizzontale, in gradi.<br/>            Valore predefinito – 0 °.<br/>            Lettura/scrittura **float**. |
| [`skew_vertical`](/slides/python-net/it/aspose.slides.effects/ioutershadow/skew_vertical/) | Angolo di inclinazione verticale, in gradi.<br/>            Valore predefinito – 0 °.<br/>            Lettura/scrittura **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/it/aspose.slides.effects/ioutershadow/rotate_shadow_with_shape/) | Indica se l'ombra ruota insieme alla forma.<br/>            Valore predefinito – true.<br/>            Lettura/scrittura **bool**. |
| [`scale_horizontal`](/slides/python-net/it/aspose.slides.effects/ioutershadow/scale_horizontal/) | Fattore di scala orizzontale, in percentuale della dimensione originale.<br/>            Una scala negativa provoca un capovolgimento.<br/>            Valore predefinito – 100 %.<br/>            Lettura/scrittura **float**. |
| [`scale_vertical`](/slides/python-net/it/aspose.slides.effects/ioutershadow/scale_vertical/) | Fattore di scala verticale, in percentuale della dimensione originale.<br/>            Una scala negativa provoca un capovolgimento.<br/>            Valore predefinito – 100 %.<br/>            Lettura/scrittura **float**. |
