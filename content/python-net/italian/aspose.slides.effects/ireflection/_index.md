## IReflection classe

Rappresenta un effetto di riflessione.

Il tipo IReflection espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/it/aspose.slides.effects/ireflection/start_pos_alpha/) | Specifica la posizione iniziale (lungo la rampa del gradiente alfa) del valore alfa iniziale (percentuali).<br/>            Lettura/scrittura **float**. |
| [`end_pos_alpha`](/slides/python-net/it/aspose.slides.effects/ireflection/end_pos_alpha/) | Specifica la posizione finale (lungo la rampa del gradiente alfa) del valore alfa finale (percentuali).<br/>            Lettura/scrittura **float**. |
| [`fade_direction`](/slides/python-net/it/aspose.slides.effects/ireflection/fade_direction/) | Specifica la direzione per spostare la riflessione. (angolo).<br/>            Lettura/scrittura **float**. |
| [`start_reflection_opacity`](/slides/python-net/it/aspose.slides.effects/ireflection/start_reflection_opacity/) | Opacità iniziale della riflessione. (percentuali).<br/>            Lettura/scrittura **float**. |
| [`end_reflection_opacity`](/slides/python-net/it/aspose.slides.effects/ireflection/end_reflection_opacity/) | Opacità finale della riflessione. (percentuali).<br/>            Lettura/scrittura **float**. |
| [`blur_radius`](/slides/python-net/it/aspose.slides.effects/ireflection/blur_radius/) | Raggio della sfocatura.<br/>            Lettura/scrittura **float**. |
| [`direction`](/slides/python-net/it/aspose.slides.effects/ireflection/direction/) | Direzione della riflessione.<br/>            Lettura/scrittura **float**. |
| [`distance`](/slides/python-net/it/aspose.slides.effects/ireflection/distance/) | Distanza della riflessione.<br/>            Lettura/scrittura **float**. |
| [`rectangle_align`](/slides/python-net/it/aspose.slides.effects/ireflection/rectangle_align/) | Allineamento del rettangolo.<br/>            Lettura/scrittura [`RectangleAlignment`](/slides/python-net/it/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/it/aspose.slides.effects/ireflection/skew_horizontal/) | Specifica l'angolo di inclinazione orizzontale.<br/>            Lettura/scrittura **float**. |
| [`skew_vertical`](/slides/python-net/it/aspose.slides.effects/ireflection/skew_vertical/) | Specifica l'angolo di inclinazione verticale.<br/>            Lettura/scrittura **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/it/aspose.slides.effects/ireflection/rotate_shadow_with_shape/) | Specifica se la riflessione deve ruotare con la forma quando la forma è ruotata.<br/>            Lettura/scrittura **bool**. |
| [`scale_horizontal`](/slides/python-net/it/aspose.slides.effects/ireflection/scale_horizontal/) | Specifica il fattore di scala orizzontale, una scala negativa provoca un'inversione. (percentuali)<br/>            Lettura/scrittura **float**. |
| [`scale_vertical`](/slides/python-net/it/aspose.slides.effects/ireflection/scale_vertical/) | Specifica il fattore di scala verticale, una scala negativa provoca un'inversione. (percentuali)<br/>            Lettura/scrittura **float**. |
