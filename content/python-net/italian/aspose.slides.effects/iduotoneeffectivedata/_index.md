## IDuotoneEffectiveData classe

Oggetto immutabile che rappresenta un effetto Duotone.  
Per ogni pixel, combina clr1 e clr2 tramite un'interpolazione lineare per determinare il nuovo colore per quel pixel.

Il tipo IDuotoneEffectiveData espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`color1`](/slides/python-net/it/aspose.slides.effects/iduotoneeffectivedata/color1/) | Restituisce il formato colore di destinazione per i pixel scuri.<br/>            Solo lettura **aspose.slides.Color**. |
| [`color2`](/slides/python-net/it/aspose.slides.effects/iduotoneeffectivedata/color2/) | Restituisce il formato colore di destinazione per i pixel chiari.<br/>            Solo lettura **aspose.slides.Color**. |
