## Glow classe

Rappresenta un effetto Glow, in cui un contorno sfocato di colore viene aggiunto al di fuori dei bordi dell'oggetto.

Il tipo Glow espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`radius`](/slides/python-net/it/aspose.slides.effects/glow/radius/) | Raggio.<br/>            Lettura/scrittura **float**. |
| [`color`](/slides/python-net/it/aspose.slides.effects/glow/color/) | Formato colore.<br/>            Sola lettura [`IColorFormat`](/slides/python-net/it/aspose.slides/icolorformat). |

## Metodi

| Metodo | Descrizione |
| :- | :- |
| [`get_effective(self)`](/slides/python-net/it/aspose.slides.effects/glow/get_effective/#) | Ottiene i dati dell'effetto Glow effettivo con l'ereditarietà applicata. |
