## OuterShadow classe

Rappresenta un effetto di ombra esterna.

Il tipo OuterShadow espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`blur_radius`](/slides/python-net/it/aspose.slides.effects/outershadow/blur_radius/) | Raggio di sfocatura, in punti.<br/>            Valore predefinito – 0 pt.<br/>            Lettura/scrittura **float**. |
| [`direction`](/slides/python-net/it/aspose.slides.effects/outershadow/direction/) | Direzione dell'ombra, in gradi.<br/>            Valore predefinito – 0 ° (da sinistra a destra).<br/>            Lettura/scrittura **float**. |
| [`distance`](/slides/python-net/it/aspose.slides.effects/outershadow/distance/) | Distanza dell'ombra dall'oggetto, in punti.<br/>            Valore predefinito – 0 pt.<br/>            Lettura/scrittura **float**. |
| [`shadow_color`](/slides/python-net/it/aspose.slides.effects/outershadow/shadow_color/) | Colore dell'ombra.<br/>            Valore predefinito – nero automatico (dipendente dal tema).<br/>            Sola lettura [`IColorFormat`](/slides/python-net/it/aspose.slides/icolorformat). |
| [`rectangle_align`](/slides/python-net/it/aspose.slides.effects/outershadow/rectangle_align/) | Allineamento del rettangolo.<br/>            Valore predefinito – [`RectangleAlignment.BOTTOM`](/slides/python-net/it/aspose.slides/rectanglealignment/BOTTOM). <br/>            Lettura/scrittura [`RectangleAlignment`](/slides/python-net/it/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/it/aspose.slides.effects/outershadow/skew_horizontal/) | Angolo di inclinazione orizzontale, in gradi.<br/>            Valore predefinito – 0 °.<br/>            Lettura/scrittura **float**. |
| [`skew_vertical`](/slides/python-net/it/aspose.slides.effects/outershadow/skew_vertical/) | Angolo di inclinazione verticale, in gradi.<br/>            Valore predefinito – 0 °.<br/>            Lettura/scrittura **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/it/aspose.slides.effects/outershadow/rotate_shadow_with_shape/) | Indica se l'ombra ruota insieme alla forma.<br/>            Valore predefinito – true.<br/>            Lettura/scrittura **bool**. |
| [`scale_horizontal`](/slides/python-net/it/aspose.slides.effects/outershadow/scale_horizontal/) | Fattore di scala orizzontale, in percentuale della dimensione originale.<br/>            Una scala negativa provoca un ribaltamento.<br/>            Valore predefinito – 100 %.<br/>            Lettura/scrittura **float**. |
| [`scale_vertical`](/slides/python-net/it/aspose.slides.effects/outershadow/scale_vertical/) | Fattore di scala verticale, in percentuale della dimensione originale.<br/>            Una scala negativa provoca un ribaltamento.<br/>            Valore predefinito – 100 %.<br/>            Lettura/scrittura **float**. |
