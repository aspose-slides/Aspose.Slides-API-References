## Reflection classe

Rappresenta un effetto Reflection.

Il tipo Reflection espone i seguenti membri:

## Proprietà

| Property | Description |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/it/aspose.slides.effects/reflection/start_pos_alpha/) | Specifica la posizione iniziale (lungo la rampa del gradiente alfa) del valore alfa iniziale (percentuali).<br/>            Read/write **float**. |
| [`end_pos_alpha`](/slides/python-net/it/aspose.slides.effects/reflection/end_pos_alpha/) | Specifica la posizione finale (lungo la rampa del gradiente alfa) del valore alfa finale (percentuali).<br/>            Read/write **float**. |
| [`fade_direction`](/slides/python-net/it/aspose.slides.effects/reflection/fade_direction/) | Specifica la direzione per spostare la riflessione. (angolo).<br/>            Read/write **float**. |
| [`start_reflection_opacity`](/slides/python-net/it/aspose.slides.effects/reflection/start_reflection_opacity/) | Opacità iniziale della riflessione. (percentuali).<br/>            Read/write **float**. |
| [`end_reflection_opacity`](/slides/python-net/it/aspose.slides.effects/reflection/end_reflection_opacity/) | Opacità finale della riflessione. (percentuali).<br/>            Read/write **float**. |
| [`blur_radius`](/slides/python-net/it/aspose.slides.effects/reflection/blur_radius/) | Raggio di sfocatura.<br/>            Read/write **float**. |
| [`direction`](/slides/python-net/it/aspose.slides.effects/reflection/direction/) | Direzione della riflessione.<br/>            Read/write **float**. |
| [`distance`](/slides/python-net/it/aspose.slides.effects/reflection/distance/) | Distanza della riflessione.<br/>            Read/write **float**. |
| [`rectangle_align`](/slides/python-net/it/aspose.slides.effects/reflection/rectangle_align/) | Allineamento del rettangolo.<br/>            Read/write [`RectangleAlignment`](/slides/python-net/it/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/it/aspose.slides.effects/reflection/skew_horizontal/) | Specifica l'angolo di inclinazione orizzontale.<br/>            Read/write **float**. |
| [`skew_vertical`](/slides/python-net/it/aspose.slides.effects/reflection/skew_vertical/) | Specifica l'angolo di inclinazione verticale.<br/>            Read/write **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/it/aspose.slides.effects/reflection/rotate_shadow_with_shape/) | Specifica se la riflessione deve ruotare con la forma se la forma viene ruotata.<br/>            Read/write **bool**. |
| [`scale_horizontal`](/slides/python-net/it/aspose.slides.effects/reflection/scale_horizontal/) | Specifica il fattore di scala orizzontale, una scala negativa provoca un'inversione. (percentuali)<br/>            Read/write **float**. |
| [`scale_vertical`](/slides/python-net/it/aspose.slides.effects/reflection/scale_vertical/) | Specifica il fattore di scala verticale, una scala negativa provoca un'inversione. (percentuali)<br/>            Read/write **float**. |
