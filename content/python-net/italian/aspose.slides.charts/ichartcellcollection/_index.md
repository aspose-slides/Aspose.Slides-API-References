## IChartCellCollection classe

Rappresenta una collezione di celle con dati.

Il tipo IChartCellCollection espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`count`](/slides/python-net/it/aspose.slides.charts/ichartcellcollection/count/) | Ottiene il conteggio delle celle nella collezione.<br/>            Solo lettura **int**. |

Restituisce una cella (IChartDataCell) per indice.

## Indicizzatore

| Nome | Descrizione |
| :- | :- |
| [`[index]`](/slides/python-net/it/aspose.slides.charts/ichartcellcollection/__getitem__/) | Indice di una cella. |
