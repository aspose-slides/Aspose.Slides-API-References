## use_cells proprietà
Se true allora worksheet è usato per memorizzare le categorie (questo caso supporta categorie a più livelli).
            Se false allora worksheet NON è usato per memorizzare i valori (e questo caso non supporta 
            categorie a più livelli).
            Lettura/scrittura **bool**.
