## Enumerazione MarkerStyleType

Determina la forma del marcatore sul punto dati del grafico.

Il tipo MarkerStyleType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| NOT_DEFINED |  |
| CIRCLE | Specifica che un cerchio deve essere disegnato in ciascun punto dati. |
| DASH | Specifica che una linea tratteggiata deve essere disegnata in ciascun punto dati. |
| DIAMOND | Specifica che un diamante deve essere disegnato in ciascun punto dati. |
| DOT | Specifica che un punto deve essere disegnato in ciascun punto dati. |
| NONE | Specifica che nulla deve essere disegnato in ciascun punto dati. |
| PICTURE | Specifica che un'immagine deve essere disegnata in ciascun punto dati. |
| PLUS | Specifica che un segno più deve essere disegnato in ciascun punto dati. |
| SQUARE | Specifica che un quadrato deve essere disegnato in ciascun punto dati. |
| STAR | Specifica che una stella deve essere disegnata in ciascun punto dati. |
| TRIANGLE | Specifica che un triangolo deve essere disegnato in ciascun punto dati. |
| X | Specifica che una X deve essere disegnata in ciascun punto dati. |
