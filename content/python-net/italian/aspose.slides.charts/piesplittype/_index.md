## PieSplitType enumerazione

Rappresenta un tipo di punti di divisione nel secondo grafico a torta o barra su un grafico pie-of-pie o bar-of-pie.

Il tipo PieSplitType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| DEFAULT | Specifica che i punti dati debbano essere suddivisi usando il meccanismo predefinito <br/>            per questo tipo di grafico. |
| CUSTOM | Specifica che i punti dati debbano essere suddivisi tra la <br/>            torta e il secondo grafico secondo i valori di suddivisione personalizzata. |
| BY_PERCENTAGE | Specifica che i punti dati debbano essere suddivisi tra la torta e il <br/>            secondo grafico posizionando i punti con percentuale inferiore a <br/>            la percentuale Split Position nel secondo grafico. |
| BY_POS | Specifica che i punti dati debbano essere suddivisi tra la torta e il <br/>            secondo grafico posizionando l'ultima posizione Split Position dei punti dati <br/>            nel secondo grafico. |
| BY_VALUE | Specifica che i punti dati debbano essere suddivisi tra la torta e il <br/>            secondo grafico posizionando i punti dati con valore inferiore a <br/>            Split Position nel secondo grafico. |
