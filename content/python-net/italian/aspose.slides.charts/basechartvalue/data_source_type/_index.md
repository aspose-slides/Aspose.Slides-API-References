## data_source_type proprietà
Specifica se AsCell, AsCells, AsLiteralString o AsLiteralDouble 
            property è attuale nei discendenti. In altre parole specifica il tipo 
            di valore della proprietà Data. Lettura/scrittura [`DataSourceType`](/slides/python-net/it/aspose.slides.charts/datasourcetype).

### Osservazioni

Per i punti in ChartDataPointCollection questa proprietà è di sola lettura. 
            In questo caso, per modificare il valore di questa proprietà è possibile utilizzare una delle 
            proprietà ChartDataPointCollection.DataSourceTypeFor<...>.
