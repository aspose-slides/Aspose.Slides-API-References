## use_secondary_categories property
Se false allora la proprietà [`ChartData.secondary_categories`](/slides/python-net/it/aspose.slides.charts/chartdata/secondary_categories) restituisce None e i dati 
            nella proprietà [`ChartData.categories`](/slides/python-net/it/aspose.slides.charts/chartdata/categories) sono usati sia per le serie primarie che secondarie.
            Se true allora i dati nella proprietà [`ChartData.secondary_categories`](/slides/python-net/it/aspose.slides.charts/chartdata/secondary_categories) sono usati per le serie secondarie e i dati 
            nella proprietà [`ChartData.categories`](/slides/python-net/it/aspose.slides.charts/chartdata/categories) sono usati per le serie primarie.
            Lettura/scrittura **bool**.
