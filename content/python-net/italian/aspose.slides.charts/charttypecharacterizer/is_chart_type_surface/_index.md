## is_chart_type_surface(chart_type) {#charttype}

            Il set di sottotipi corrisponde al set appropriato in PowerPoint (vedi la finestra di dialogo "Change Chart Type" in PowerPoint):

            [`ChartType.WIREFRAME_SURFACE_3D`](/slides/python-net/it/aspose.slides.charts/charttype/WIREFRAME_SURFACE_3D),
