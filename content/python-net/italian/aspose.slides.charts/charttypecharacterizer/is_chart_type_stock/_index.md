## is_chart_type_stock(chart_type) {#charttype}
Restituisce true se chartType è uno dei sottotipi Stock.
            Il set di sottotipi corrisponde al set appropriato in PowerPoint (vedi la finestra di dialogo "Change Chart Type" in PowerPoint):
            [`ChartType.HIGH_LOW_CLOSE`](/slides/python-net/it/aspose.slides.charts/charttype/HIGH_LOW_CLOSE),
            [`ChartType.OPEN_HIGH_LOW_CLOSE`](/slides/python-net/it/aspose.slides.charts/charttype/OPEN_HIGH_LOW_CLOSE),
            [`ChartType.VOLUME_HIGH_LOW_CLOSE`](/slides/python-net/it/aspose.slides.charts/charttype/VOLUME_HIGH_LOW_CLOSE),
