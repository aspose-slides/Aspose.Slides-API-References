## is_chart_type_area(chart_type) {#charttype}
Restituisce true se chartType è uno dei sottotipi Area.
            Il set di sottotipi corrisponde al set appropriato in PowerPoint (vedi la finestra di dialogo "Change Chart Type" in PowerPoint):
            [`ChartType.AREA`](/slides/python-net/it/aspose.slides.charts/charttype/AREA),
            [`ChartType.PERCENTS_STACKED_AREA`](/slides/python-net/it/aspose.slides.charts/charttype/PERCENTS_STACKED_AREA),
            [`ChartType.PERCENTS_STACKED_AREA_3D`](/slides/python-net/it/aspose.slides.charts/charttype/PERCENTS_STACKED_AREA_3D),
            [`ChartType.STACKED_AREA`](/slides/python-net/it/aspose.slides.charts/charttype/STACKED_AREA),
            [`ChartType.STACKED_AREA_3D`](/slides/python-net/it/aspose.slides.charts/charttype/STACKED_AREA_3D),
            [`ChartType.AREA_3D`](/slides/python-net/it/aspose.slides.charts/charttype/AREA_3D).
