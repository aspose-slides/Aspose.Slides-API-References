## IOverridableText classe

Rappresenta il testo sovrascrivibile per un grafico.

Il tipo IOverridableText espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`text_frame_for_overriding`](/slides/python-net/it/aspose.slides.charts/ioverridabletext/text_frame_for_overriding/) | Può contenere un testo formattato riccamente. Se questa proprietà non è None allora questo <br/>            valore di testo formattato sovrascrive il testo generato automaticamente.<br/>            Il testo generato automaticamente è una proprietà implicita dell'etichetta dati, dell'etichetta unità di visualizzazione dell'asse dei valori, del titolo dell'asse, del titolo del grafico, dell'etichetta della linea di tendenza.<br/>            Il testo generato automaticamente è formattato con la proprietà IFormattedTextContainer.TextFormat.<br/>            Solo lettura [`ITextFrame`](/slides/python-net/it/aspose.slides/itextframe). |
