## TrendlineType enumerazione

Rappresenta il tipo di linea di tendenza

Il tipo TrendlineType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| EXPONENTIAL | Specifica che la linea di tendenza deve essere una curva esponenziale nella forma. |
| LINEAR | Specifica che la linea di tendenza deve essere una linea nella forma. |
| LOGARITHMIC | Specifica che la linea di tendenza deve essere una curva logaritmica nella forma, dove log è il logaritmo naturale. |
| MOVING_AVERAGE | Specifica che la linea di tendenza deve essere una media mobile del periodo Period. |
| POLYNOMIAL | Specifica che la linea di tendenza deve essere una curva polinomiale di ordine Order nella forma. |
| POWER | Specifica che la linea di tendenza deve essere una curva di potenza nella forma. |
