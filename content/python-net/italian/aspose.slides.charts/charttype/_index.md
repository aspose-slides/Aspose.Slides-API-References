## ChartType enumerazione

Rappresenta un tipo di grafico.

Il tipo ChartType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| CLUSTERED_COLUMN | Rappresenta un grafico a colonne raggruppate. |
| STACKED_COLUMN | Rappresenta un grafico a colonne impilate. |
| PERCENTS_STACKED_COLUMN | Rappresenta un grafico a colonne impilate al 100%. |
| CLUSTERED_COLUMN_3D | Rappresenta un grafico a colonne raggruppate 3D. |
| STACKED_COLUMN_3D | Rappresenta un grafico a colonne impilate 3D. |
| PERCENTS_STACKED_COLUMN_3D | Rappresenta un grafico a colonne impilate al 100% 3D. |
| COLUMN_3D | Rappresenta un grafico a colonne 3D. |
| CLUSTERED_CYLINDER | Rappresenta un grafico a cilindro. |
| STACKED_CYLINDER | Rappresenta un grafico a cilindro impilato. |
| PERCENTS_STACKED_CYLINDER | Rappresenta un grafico a cilindro impilato al 100%. |
| CYLINDER_3D | Rappresenta un grafico a cilindro 3D. |
| CLUSTERED_CONE | Rappresenta un grafico a cono. |
| STACKED_CONE | Rappresenta un grafico a cono impilato. |
| PERCENTS_STACKED_CONE | Rappresenta un grafico a cono impilato al 100%. |
| CONE_3D | Rappresenta un grafico a cono 3D. |
| CLUSTERED_PYRAMID | Rappresenta un grafico a piramide. |

| STACKED_LINE | Rappresenta un grafico a linee impilate. |
| PERCENTS_STACKED_LINE | Rappresenta un grafico a linee impilate al 100%. |
| LINE_WITH_MARKERS | Rappresenta un grafico a linee con marcatori dei dati. |
| STACKED_LINE_WITH_MARKERS | Rappresenta un grafico a linee impilate con marcatori dei dati. |
| PERCENTS_STACKED_LINE_WITH_MARKERS | Rappresenta un grafico a linee impilate al 100% con marcatori dei dati. |

| PIE | Rappresenta un grafico a torta. |

| EXPLODED_PIE | Rappresenta un grafico a torta esploso. |
| EXPLODED_PIE_3D | Rappresenta un grafico a torta esploso 3D. |
| BAR_OF_PIE | Rappresenta un grafico a barre di torta. |
| PERCENTS_STACKED_BAR | Rappresenta un grafico a barre impilate al 100%. |
| CLUSTERED_BAR_3D | Rappresenta un grafico a barre raggruppate 3D. |
| CLUSTERED_BAR | Rappresenta un grafico a barre raggruppate. |
| STACKED_BAR | Rappresenta un grafico a barre impilate. |
| STACKED_BAR_3D | Rappresenta un grafico a barre impilate 3D. |

| CLUSTERED_HORIZONTAL_PYRAMID | Rappresenta un grafico a barre piramidali. |
| STACKED_HORIZONTAL_PYRAMID | Rappresenta un grafico a barre piramidali impilate. |
| PERCENTS_STACKED_HORIZONTAL_PYRAMID | Rappresenta un grafico a barre piramidali impilate al 100%. |
| AREA | Rappresenta un grafico ad area. |
