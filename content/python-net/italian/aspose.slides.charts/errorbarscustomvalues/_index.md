## ErrorBarsCustomValues classe

Specifica i valori delle barre di errore. Deve essere utilizzato solo quando il tipo di valore delle barre di errore è Custom.

Il tipo ErrorBarsCustomValues espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`x_minus`](/slides/python-net/it/aspose.slides.charts/errorbarscustomvalues/x_minus/) | Specifica il valore della barra di errore nella direzione negativa. <br/>            Disponibile se il tipo di valore delle barre di errore è Custom e ErrorBarsXFormat è consentito.<br/>            In qualsiasi altro caso questa proprietà restituisce None.<br/>            Solo lettura [`IDoubleChartValue`](/slides/python-net/it/aspose.slides.charts/idoublechartvalue). |
| [`y_minus`](/slides/python-net/it/aspose.slides.charts/errorbarscustomvalues/y_minus/) | Specifica il valore della barra di errore nella direzione negativa. <br/>            Disponibile se il tipo di valore delle barre di errore è Custom e ErrorBarsYFormat è consentito.<br/>            In qualsiasi altro caso questa proprietà restituisce None.<br/>            Solo lettura [`IDoubleChartValue`](/slides/python-net/it/aspose.slides.charts/idoublechartvalue). |
| [`x_plus`](/slides/python-net/it/aspose.slides.charts/errorbarscustomvalues/x_plus/) | Specifica il valore della barra di errore nella direzione positiva. <br/>            Disponibile se il tipo di valore delle barre di errore è Custom e ErrorBarsXFormat è consentito.<br/>            In qualsiasi altro caso questa proprietà restituisce None.<br/>            Solo lettura [`IDoubleChartValue`](/slides/python-net/it/aspose.slides.charts/idoublechartvalue). |
| [`y_plus`](/slides/python-net/it/aspose.slides.charts/errorbarscustomvalues/y_plus/) | Specifica il valore della barra di errore nella direzione positiva. <br/>            Disponibile se il tipo di valore delle barre di errore è Custom e ErrorBarsYFormat è consentito.<br/>            In qualsiasi altro caso questa proprietà restituisce None.<br/>            Solo lettura [`IDoubleChartValue`](/slides/python-net/it/aspose.slides.charts/idoublechartvalue). |
