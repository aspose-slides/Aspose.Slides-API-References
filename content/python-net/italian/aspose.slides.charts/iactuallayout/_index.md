## classe IActualLayout

Specifica la posizione reale di un elemento del grafico.

Il tipo IActualLayout espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`actual_x`](/slides/python-net/it/aspose.slides.charts/iactuallayout/actual_x/) | Specifica la posizione x reale (sinistra) dell'elemento del grafico rispetto all'angolo superiore sinistro del grafico.<br/>            Chiama il metodo IChart.ValidateChartLayout() prima per ottenere i valori reali. <br/>            Lettura **float**. |
| [`actual_y`](/slides/python-net/it/aspose.slides.charts/iactuallayout/actual_y/) | Specifica la parte superiore reale dell'elemento del grafico rispetto all'angolo superiore sinistro del grafico.<br/>            Chiama il metodo IChart.ValidateChartLayout() prima per ottenere i valori reali. <br/>            Lettura **float**. |
| [`actual_width`](/slides/python-net/it/aspose.slides.charts/iactuallayout/actual_width/) | Specifica la larghezza reale dell'elemento del grafico. Chiama il metodo IChart.ValidateChartLayout() prima per ottenere i valori reali. <br/>            Lettura **float**. |
| [`actual_height`](/slides/python-net/it/aspose.slides.charts/iactuallayout/actual_height/) | Specifica l'altezza reale dell'elemento del grafico. Chiama il metodo IChart.ValidateChartLayout() prima per ottenere i valori reali. <br/>            Lettura **float**. |
