## IMarker classe

Rappresenta il marcatore di un chert.

Il tipo IMarker espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`symbol`](/slides/python-net/it/aspose.slides.charts/imarker/symbol/) | Rappresenta lo stile del marcatore in un grafico a linee, grafico a dispersione o grafico radar.<br/>            Lettura/scrittura [`MarkerStyleType`](/slides/python-net/it/aspose.slides.charts/markerstyletype). |
| [`format`](/slides/python-net/it/aspose.slides.charts/imarker/format/) | Ottiene il riempimento del marcatore.<br/>            Solo lettura [`IFormat`](/slides/python-net/it/aspose.slides.charts/iformat). |
| [`size`](/slides/python-net/it/aspose.slides.charts/imarker/size/) | Rappresenta la dimensione del marcatore in un grafico a linee, grafico a dispersione o grafico radar.<br/>            Lettura/scrittura **int**. |
