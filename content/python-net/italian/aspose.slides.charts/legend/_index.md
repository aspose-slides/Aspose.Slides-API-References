## Legend classe

Rappresenta le proprietà della legenda del grafico.

Il tipo Legend espone i seguenti membri:

## Proprietà

| Property | Description |
| :- | :- |
| [`x`](/slides/python-net/it/aspose.slides.charts/legend/x/) | Restituisce o imposta la coordinata x di una legenda come frazione della larghezza del grafico.<br/>            Lettura/Scrittura **float**. |
| [`y`](/slides/python-net/it/aspose.slides.charts/legend/y/) | Restituisce o imposta la coordinata y di una legenda come frazione dell'altezza del grafico.<br/>            Lettura/Scrittura **float**. |
| [`width`](/slides/python-net/it/aspose.slides.charts/legend/width/) | Restituisce o imposta la larghezza di una legenda come frazione della larghezza del grafico.<br/>            Lettura/Scrittura **float**. |
| [`height`](/slides/python-net/it/aspose.slides.charts/legend/height/) | Restituisce o imposta l'altezza di una legenda come frazione dell'altezza del grafico.<br/>            Lettura/Scrittura **float**. |
| [`right`](/slides/python-net/it/aspose.slides.charts/legend/right/) | Destra.<br/>            Sola lettura **float**. |
| [`bottom`](/slides/python-net/it/aspose.slides.charts/legend/bottom/) | Inferiore.<br/>            Sola lettura **float**. |
| [`overlay`](/slides/python-net/it/aspose.slides.charts/legend/overlay/) | Determina se altri elementi del grafico possono sovrapporsi alla legenda.<br/>            Lettura/Scrittura **bool**. |
| [`text_format`](/slides/python-net/it/aspose.slides.charts/legend/text_format/) | Formato testuale.<br/>            Sola lettura [`IChartTextFormat`](/slides/python-net/it/aspose.slides.charts/icharttextformat). |
| [`position`](/slides/python-net/it/aspose.slides.charts/legend/position/) | Specifica la posizione della legenda su un grafico.<br/>            I valori non NaN delle proprietà X, Y, Width, Heigt sovrascrivono l'effetto di questa proprietà.<br/>            Lettura/Scrittura [`LegendPositionType`](/slides/python-net/it/aspose.slides.charts/legendpositiontype). |
| [`format`](/slides/python-net/it/aspose.slides.charts/legend/format/) | Restituisce il formato di una legenda.<br/>            Sola lettura [`IFormat`](/slides/python-net/it/aspose.slides.charts/iformat). |
| [`chart`](/slides/python-net/it/aspose.slides.charts/legend/chart/) | Restituisce il grafico.<br/>            Sola lettura [`IChart`](/slides/python-net/it/aspose.slides.charts/ichart). |
| [`entries`](/slides/python-net/it/aspose.slides.charts/legend/entries/) | Ottiene le voci della legenda.<br/>            Sola lettura [`ILegendEntryCollection`](/slides/python-net/it/aspose.slides.charts/ilegendentrycollection). |
| [`actual_x`](/slides/python-net/it/aspose.slides.charts/legend/actual_x/) | Specifica la posizione x effettiva (sinistra) dell'elemento del grafico rispetto all'angolo superiore sinistro del grafico.<br/>            Chiamare il metodo IChart.ValidateChartLayout() prima per ottenere i valori effettivi. <br/>            Lettura **float**. |
| [`actual_y`](/slides/python-net/it/aspose.slides.charts/legend/actual_y/) | Specifica la parte superiore effettiva dell'elemento del grafico rispetto all'angolo superiore sinistro del grafico.<br/>            Chiamare il metodo IChart.ValidateChartLayout() prima per ottenere i valori effettivi. <br/>            Lettura **float**. |
| [`actual_width`](/slides/python-net/it/aspose.slides.charts/legend/actual_width/) | Specifica la larghezza effettiva dell'elemento del grafico. Chiamare il metodo IChart.ValidateChartLayout() prima per ottenere i valori effettivi. <br/>            Lettura **float**. |
| [`actual_height`](/slides/python-net/it/aspose.slides.charts/legend/actual_height/) | Specifica l'altezza effettiva dell'elemento del grafico. Chiamare il metodo IChart.ValidateChartLayout() prima per ottenere i valori effettivi. <br/>            Lettura **float**. |
