## LegendDataLabelPosition enumerazione

Determina la posizione delle etichette dei dati.

Il tipo LegendDataLabelPosition espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| NOT_DEFINED | La posizione non è definita. |
| BOTTOM | Specifica che le etichette dei dati devono essere visualizzate sotto il marcatore dei dati. |
| BEST_FIT | Specifica che le etichette dei dati devono essere visualizzate nella posizione migliore. |
| CENTER | Specifica che le etichette dei dati devono essere visualizzate centrate sul marcatore dei dati. |
| INSIDE_BASE | Specifica che le etichette dei dati devono essere visualizzate all'interno della base del marcatore dei dati. |
| INSIDE_END | Specifica che le etichette dei dati devono essere visualizzate all'interno dell'estremità del marcatore dei dati. |
| LEFT | Specifica che le etichette dei dati devono essere visualizzate a sinistra del marcatore dei dati. |
| OUTSIDE_END | Specifica che le etichette dei dati devono essere visualizzate all'esterno dell'estremità del marcatore dei dati. |
| RIGHT | Specifica che le etichette dei dati devono essere visualizzate a destra del marcatore dei dati. |
| TOP | Specifica che le etichette dei dati devono essere visualizzate sopra il marcatore dei dati. |
