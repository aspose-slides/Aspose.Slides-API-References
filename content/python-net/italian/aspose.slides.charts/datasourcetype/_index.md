## DataSourceType enumerazione

Tipi di origine dati.

Il tipo DataSourceType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| WORKSHEET | Utilizzare oggetti CellXls per memorizzare XValue, YValue, Value o BubbleSize del punto dati nel worksheet. |
| STRING_LITERALS | Utilizzare variabile stringa ad accesso rapido per memorizzare XValue, YValue, Value o BubbleSize del <br/>            data point. Worksheet NON è usato per memorizzare i valori. |
| DOUBLE_LITERALS | Utilizzare variabile double ad accesso rapido per memorizzare XValue, YValue, Value o BubbleSize del <br/>            data point. Worksheet NON è usato per memorizzare i valori. |
