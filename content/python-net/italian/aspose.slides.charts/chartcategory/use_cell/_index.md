## use_cell proprietà
Se vero, la proprietà AsCell è effettiva. In altre parole, il foglio di lavoro è utilizzato per memorizzare la categoria (questo caso supporta una categoria a più livelli).
Se falso, la proprietà AsLiteral è effettiva. In altre parole, il foglio di lavoro NON è utilizzato per memorizzare la categoria (e questo caso non supporta categorie a più livelli).
Solo lettura **bool**.


### Osservazioni

Per modificare il valore di questa proprietà (per tutte le categorie nella raccolta) impostare il nuovo valore sulla proprietà ChartCategoryCollection.UseCells.
