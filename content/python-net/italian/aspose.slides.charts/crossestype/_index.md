## CrossesType enumerazione

Determina dove l'asse si interseca.

Il tipo CrossesType espone i seguenti membri:

## Campi

| Field | Description |
| :- | :- |
| AXIS_CROSSES_AT_ZERO | L'asse delle categorie si interseca al punto zero dell'asse dei valori (se possibile), oppure al valore minimo (se il minimo è maggiore di zero) o al massimo (se il massimo è minore di zero). |
| MAXIMUM | L'asse si interseca al valore massimo. |
| CUSTOM | Valore personalizzato dalla proprietà CrossAt |
