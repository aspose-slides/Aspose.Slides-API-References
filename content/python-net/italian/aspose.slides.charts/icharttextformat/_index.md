## IChartTextFormat classe

Il grafico opera con un insieme limitato di proprietà di formattazione del testo.
            IChartTextFormat, IChartTextBlockFormat, IChartParagraphFormat, IChartPortionFormat
            le interfacce descrivono questo insieme limitato.

Il tipo IChartTextFormat espone i seguenti membri:

## Proprietà

| Property | Description |
| :- | :- |
| [`text_block_format`](/slides/python-net/it/aspose.slides.charts/icharttextformat/text_block_format/) | Restituisce il formato per gli elementi di testo del grafico.<br/>            Solo lettura [`IChartTextBlockFormat`](/slides/python-net/it/aspose.slides.charts/icharttextblockformat). |
| [`paragraph_format`](/slides/python-net/it/aspose.slides.charts/icharttextformat/paragraph_format/) | Restituisce il formato del paragrafo.<br/>            Solo lettura [`IChartParagraphFormat`](/slides/python-net/it/aspose.slides.charts/ichartparagraphformat). |
| [`portion_format`](/slides/python-net/it/aspose.slides.charts/icharttextformat/portion_format/) | Restituisce il formato della porzione.<br/>            Solo lettura [`IChartPortionFormat`](/slides/python-net/it/aspose.slides.charts/ichartportionformat). |
