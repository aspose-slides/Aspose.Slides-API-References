## is_visible proprietà
False indica che l'etichetta dati non è visibile per impostazione predefinita (e quindi tutti i flag Show* (ShowValue, ...) della proprietà DefaultDataLabelFormat sono false). Solo lettura **bool**.

### Osservazioni

Se l'etichetta dati è visibile per impostazione predefinita, è possibile nasconderla per impostazione predefinita con il metodo Hide(). Tuttavia, se l'etichetta dati non è visibile per impostazione predefinita (IsVisible è false) è possibile renderla "visibile per impostazione predefinita" impostando i flag Show* (ShowValue, ...) della proprietà DefaultDataLabelFormat su true.
