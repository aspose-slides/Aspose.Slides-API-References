## enumerazione DisplayUnitType

Determina la molteplicità dei dati visualizzati.

Il tipo DisplayUnitType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| NONE | I valori saranno visualizzati così come sono. |
| HUNDREDS | Specifica che i valori nel grafico saranno divisi per 100. |
| THOUSANDS | Specifica che i valori nel grafico saranno divisi per 1.000. |
| TEN_THOUSANDS | Specifica che i valori nel grafico saranno divisi per 10.000. |
| HUNDRED_THOUSANDS | Specifica che i valori nel grafico saranno divisi per 100.000. |
| MILLIONS | Specifica che i valori nel grafico saranno divisi per 1.000.000. |
| TEN_MILLIONS | Specifica che i valori nel grafico saranno divisi per 10.000.000. |
| HUNDRED_MILLIONS | Specifica che i valori nel grafico saranno divisi per 100.000.000. |
| BILLIONS | Specifica che i valori nel grafico saranno divisi per 1.000.000.000. |
| TRILLIONS | Specifica che i valori nel grafico saranno divisi per 1.000.000.000.000. |
| CUSTOM_VALUE | Specifica che i valori nel grafico saranno divisi per un valore personalizzato. |
