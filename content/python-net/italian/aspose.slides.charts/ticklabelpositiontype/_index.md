## TickLabelPositionType enumerazione

Rappresenta il tipo di posizione delle etichette dei segni di graduazione sull'asse specificato.

Il tipo TickLabelPositionType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| HIGH | Specifica che le etichette dell'asse devono trovarsi all'estremità alta dell'asse perpendicolare. |
| LOW | Specifica che le etichette dell'asse devono trovarsi all'estremità bassa dell'asse perpendicolare. |
| NEXT_TO | Specifica che le etichette dell'asse devono trovarsi accanto all'asse. |
| NONE | Specifica che le etichette dell'asse non vengono disegnate. |
