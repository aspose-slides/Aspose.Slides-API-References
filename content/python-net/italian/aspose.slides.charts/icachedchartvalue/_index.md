## ICachedChartValue classe

Rappresenta un valore di chart memorizzato nella cache (ad es., X, Y, dimensione bubble o il valore principale).

Il tipo ICachedChartValue espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`data`](/slides/python-net/it/aspose.slides.charts/icachedchartvalue/data/) | Ottiene l'oggetto dati memorizzato nella cache.<br/>            Solo lettura **any**. |

## Metodi

| Metodo | Descrizione |
| :- | :- |
| [`to_double(self)`](/slides/python-net/it/aspose.slides.charts/icachedchartvalue/to_double/#) | Converte il valore memorizzato nella cache in un **float**. |
