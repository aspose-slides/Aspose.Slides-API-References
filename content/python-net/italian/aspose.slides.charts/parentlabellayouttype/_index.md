## ParentLabelLayoutType enumerazione

Rappresenta il layout delle etichette dei dati di categoria. Utilizzato solo con la serie Treemap.

Il tipo ParentLabelLayoutType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| BANNER | Specifica che le etichette di categoria principale sono visualizzate come banner |
| NONE | Specifica che le etichette di categoria principale non vengono disegnate |
| OVERLAPPING | Specifica che le etichette di categoria principale sono visualizzate come sovrapposte |
