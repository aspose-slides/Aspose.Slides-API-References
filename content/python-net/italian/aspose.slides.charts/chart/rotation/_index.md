## rotation proprietà
Returns or sets the number of degrees the specified shape is rotated around
            the z-axis. A positive value indicates clockwise rotation; a negative value
            indicates counterclockwise rotation.
            Lettura/scrittura **float**.


### Osservazioni

Il valore restituito è sempre definito (non è float.NaN).
            Il valore assegnato deve essere definito (non float.NaN). È possibile impostare valori non definiti per le proprietà dell'istanza RawFrame.
