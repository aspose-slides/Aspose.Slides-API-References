## is_number_format_linked_to_source proprietà
Lettura/scrittura **bool**.


### Note

Se il genitore di questo oggetto DataLabelFormat è una raccolta DataLabelCollection di etichette di dati, allora questa
            proprietà ottiene o imposta il valore predefinito della proprietà IsNumberFormatLinkedToSource per le nuove etichette di dati
            nella raccolta DataLabelCollection.
            Imposta questa proprietà con un valore imposta anche tale valore sulla proprietà IsNumberFormatLinkedToSource
            per tutte le etichette di dati nella raccolta DataLabelCollection
            (ad esempio "DataLabels.DefaultDataLabelFormat.IsNumberFormatLinkedToSource = val;" fa sì che
            tutti DataLabels[i].IsNumberFormatLinkedToSource siano uguali a val).
