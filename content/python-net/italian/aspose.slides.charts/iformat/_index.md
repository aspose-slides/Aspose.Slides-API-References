## IFormat classe

Rappresenta le proprietà del formato del grafico.

Il tipo IFormat espone i seguenti membri:

| Proprietà | Descrizione |
| :- | :- |
| [`fill`](/slides/python-net/it/aspose.slides.charts/iformat/fill/) | Restituisce le proprietà dello stile di riempimento di un grafico.<br/>            Sola lettura [`IFillFormat`](/slides/python-net/it/aspose.slides/ifillformat). |
| [`line`](/slides/python-net/it/aspose.slides.charts/iformat/line/) | Restituisce le proprietà dello stile di linea di un grafico.<br/>            Sola lettura [`ILineFormat`](/slides/python-net/it/aspose.slides/ilineformat). |
