## ChartPlotArea classe

Rappresenta il rettangolo in cui il grafico deve essere tracciato.

Il tipo ChartPlotArea espone i seguenti membri:

## Proprietà

| Property | Description |
| :- | :- |
| [`format`](/slides/python-net/it/aspose.slides.charts/chartplotarea/format/) | Restituisce il formato di un'area del grafico.<br/>            Solo lettura [`IFormat`](/slides/python-net/it/aspose.slides.charts/iformat). |
| [`x`](/slides/python-net/it/aspose.slides.charts/chartplotarea/x/) | Restituisce o imposta la coordinata x dell'angolo superiore sinistro del riquadro dell'area del grafico come frazione della larghezza del grafico (da 0 a 1).<br/>            Lettura/Scrittura **float**. |
| [`y`](/slides/python-net/it/aspose.slides.charts/chartplotarea/y/) | Restituisce o imposta la coordinata y dell'angolo superiore sinistro del riquadro dell'area del grafico come frazione dell'altezza del grafico (da 0 a 1).<br/>            Lettura/Scrittura **float**. |
| [`width`](/slides/python-net/it/aspose.slides.charts/chartplotarea/width/) | Restituisce o imposta la larghezza del riquadro dell'area del grafico come frazione della larghezza del grafico (da 0 a 1).<br/>            Lettura/Scrittura **float**. |
| [`height`](/slides/python-net/it/aspose.slides.charts/chartplotarea/height/) | Restituisce o imposta l'altezza del riquadro dell'area del grafico come frazione dell'altezza del grafico (da 0 a 1).<br/>            Lettura/Scrittura **float**. |
| [`right`](/slides/python-net/it/aspose.slides.charts/chartplotarea/right/) | Destra.<br/>            Solo lettura **float**. |
| [`bottom`](/slides/python-net/it/aspose.slides.charts/chartplotarea/bottom/) | Inferiore.<br/>            Solo lettura **float**. |
| [`chart`](/slides/python-net/it/aspose.slides.charts/chartplotarea/chart/) | Grafico.<br/>            Solo lettura [`IChart`](/slides/python-net/it/aspose.slides.charts/ichart). |
| [`is_location_autocalculated`](/slides/python-net/it/aspose.slides.charts/chartplotarea/is_location_autocalculated/) | Definisce come dovrebbe essere calcolata la posizione: true – calcolata automaticamente; definita dalle proprietà X, Y, Width, Height.<br/>            Solo lettura **bool**. |
| [`layout_target_type`](/slides/python-net/it/aspose.slides.charts/chartplotarea/layout_target_type/) | Se il layout dell'area del grafico è definito manualmente, questa proprietà specifica se <br/>             posizionare l'area del grafico per interno (escludendo assi ed etichette degli assi) o per esterno<br/>             (includendo assi ed etichette degli assi).<br/>             Lettura/Scrittura [`ChartPlotArea.layout_target_type`](/slides/python-net/it/aspose.slides.charts/chartplotarea/layout_target_type). |
| [`actual_x`](/slides/python-net/it/aspose.slides.charts/chartplotarea/actual_x/) | Specifica la posizione x reale (sinistra) dell'elemento del grafico relativa all'angolo in alto a sinistra del grafico.<br/>            Chiamare il metodo IChart.ValidateChartLayout() prima per ottenere i valori reali. <br/>            Lettura **float**. |
| [`actual_y`](/slides/python-net/it/aspose.slides.charts/chartplotarea/actual_y/) | Specifica la parte superiore reale dell'elemento del grafico relativa all'angolo in alto a sinistra del grafico.<br/>            Chiamare il metodo IChart.ValidateChartLayout() prima per ottenere i valori reali. <br/>            Lettura **float**. |
| [`actual_width`](/slides/python-net/it/aspose.slides.charts/chartplotarea/actual_width/) | Specifica la larghezza reale dell'elemento del grafico. Chiamare il metodo IChart.ValidateChartLayout() prima per ottenere i valori reali. <br/>            Lettura **float**. |
| [`actual_height`](/slides/python-net/it/aspose.slides.charts/chartplotarea/actual_height/) | Specifica l'altezza reale dell'elemento del grafico. Chiamare il metodo IChart.ValidateChartLayout() prima per ottenere i valori reali. <br/>            Lettura **float**. |
