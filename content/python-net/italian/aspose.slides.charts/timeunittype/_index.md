## TimeUnitType enumerazione

Rappresenta l'unità base per l'asse delle categorie

Il tipo TimeUnitType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| NONE | I valori verranno visualizzati così come sono. |
| DAYS | Specifica che i dati del grafico vengono mostrati in giorni. |
| MONTHS | Specifica che i dati del grafico vengono mostrati in mesi. |
| YEARS | Specifica che i dati del grafico vengono mostrati in anni. |
