## AxisAggregationType enumerazione

Rappresenta il tipo di aggregazione dell'asse delle categorie. Utilizzato solo con le serie Histogram o HistogramPareto.

Il tipo AxisAggregationType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| BY_CATEGORY | Aggrega per categorie |
| AUTOMATIC | Aggrega automaticamente le categorie. |
| BY_BIN_WIDTH | Aggrega le categorie per larghezza del contenitore. Property IAxis.BinWidth must be setted. |
| BY_NUMBER_OF_BINS | Aggrega le categorie per numero di contenitori. Property IAxis.NumberOfBins must be setted. |
