## PictureType enumerazione

Determina la modalità di riempimento dell'immagine della barra.

Il tipo PictureType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| NOT_DEFINED | Non definito. |
| STACK | L'immagine è dimensionata per ripetersi al massimo 15 volte nella barra impilata più lunga. |
| STACK_SCALE | L'immagine è dimensionata a un numero specificato di unità e si ripete lungo tutta la barra. |
| STRETCH | L'immagine è allungata per l'intera lunghezza della barra impilata. |
