## ChartWall classe

Rappresenta le pareti nei grafici 3d.

Il tipo ChartWall espone i seguenti membri:

## Proprietà

| Property | Description |
| :- | :- |
| [`thickness`](/slides/python-net/it/aspose.slides.charts/chartwall/thickness/) | Restituisce o imposta lo spessore delle pareti come percentuale della dimensione più grande <br/>            del volume del grafico.<br/>            Lettura/scrittura **int**. |
| [`format`](/slides/python-net/it/aspose.slides.charts/chartwall/format/) | Restituisce il riempimento della parete, la linea, l'effetto, gli stili 3d.<br/>            Sola lettura [`IFormat`](/slides/python-net/it/aspose.slides.charts/iformat). |
| [`picture_type`](/slides/python-net/it/aspose.slides.charts/chartwall/picture_type/) | Restituisce o imposta il tipo di immagine.<br/>            Lettura/scrittura [`PictureType`](/slides/python-net/it/aspose.slides.charts/picturetype). |
