## error_bars_x_format proprietà
Rappresenta ErrorBars di serie con direzione X.
            
            ErrorBars con direzione X sono disponibili per serie di tipo area, bar, scatter e bubble. 
            Per tutti gli altri tipi di grafico questa proprietà restituisce None (inclusi i grafici 3D). 
            Nel caso di valori personalizzati, usa la collezione DataPoints per specificare il valore 
            (con la proprietà [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/it/aspose.slides.charts/ichartdatapoint/error_bars_custom_values)). 
            
            Solo lettura [`IErrorBarsFormat`](/slides/python-net/it/aspose.slides.charts/ierrorbarsformat).
