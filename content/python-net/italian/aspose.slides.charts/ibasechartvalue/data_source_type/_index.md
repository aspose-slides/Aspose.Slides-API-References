## data_source_type proprietà
Specifica se la proprietà AsCell o AsLiteralString o AsLiteralDouble è attuale. In altre parole, specifica il tipo di valore della proprietà Data. Questa proprietà è sola lettura. Per modificare il valore di questa proprietà è possibile utilizzare una delle proprietà ChartDataPointCollection.DataSourceTypeFor<...>.
