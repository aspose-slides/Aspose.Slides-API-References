## IBaseChartValue classe

Rappresenta un valore di un grafico.

Il tipo IBaseChartValue espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`data_source_type`](/slides/python-net/it/aspose.slides.charts/ibasechartvalue/data_source_type/) | Specifica se la proprietà AsCell o AsLiteralString o AsLiteralDouble è effettiva. In altre parole, specifica il tipo di valore della proprietà Data. Questa proprietà è di sola lettura. Per modificare il valore di questa proprietà è possibile utilizzare una delle proprietà ChartDataPointCollection.DataSourceTypeFor<...>. Lettura/scrittura [`IBaseChartValue.data_source_type`](/slides/python-net/it/aspose.slides.charts/ibasechartvalue/data_source_type). |
| [`data`](/slides/python-net/it/aspose.slides.charts/ibasechartvalue/data/) | Lettura/scrittura **qualsiasi**. |
