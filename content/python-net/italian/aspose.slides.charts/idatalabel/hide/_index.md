## hide(self) {#}
Rendi l'etichetta dei dati nascosta impostando tutti i flag Show*-flags (ShowValue, ...) nello stato false.
IsVisible sarà false dopo questo.


```python
def hide(self):
    ...
```


### Osservazioni

Se l'etichetta dei dati non è visibile (IsVisible è false) è possibile rendere l'etichetta dei dati visibile con 
            impostando i flag Show*-flags (ShowValue, ...) nello stato true.
