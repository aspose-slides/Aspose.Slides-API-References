## Rotation3D classe

Rappresenta la rotazione 3D di un grafico.

Il tipo Rotation3D espone i seguenti membri:

## Proprietà

| Property | Description |
| :- | :- |
| [`rotation_x`](/slides/python-net/it/aspose.slides.charts/rotation3d/rotation_x/) | Restituisce o imposta il valore di rotazione attorno all'asse X, cioè nella direzione Y per i grafici 3D (tra -90 e 90 gradi).<br/>            La proprietà corrisponde all'elemento 21.2.2.157 rotX (Rotazione X) in ECMA-376 e all'opzione "Y Rotation" in PowerPoint 2007+.<br/>            Lettura/Scrittura **int**. |
| [`rotation_y`](/slides/python-net/it/aspose.slides.charts/rotation3d/rotation_y/) | Restituisce o imposta il valore di rotazione attorno all'asse Y, cioè nella direzione X per i grafici 3D (tra 0 e 360 gradi).<br/>            La proprietà corrisponde all'elemento 21.2.2.158 rotY (Rotazione Y) in ECMA-376 e all'opzione "X Rotation" in PowerPoint 2007+.<br/>            Lettura/Scrittura **int**. |
| [`perspective`](/slides/python-net/it/aspose.slides.charts/rotation3d/perspective/) | Restituisce o imposta il valore di prospettiva (angolo del campo visivo) per i grafici 3D (tra 0 e 240).<br/>            Ignorata se il valore della proprietà RightAngleAxes è true.<br/>            Lettura/Scrittura **int**. |
| [`right_angle_axes`](/slides/python-net/it/aspose.slides.charts/rotation3d/right_angle_axes/) | Determina se gli assi del grafico sono ad angolo retto, anziché disegnati in prospettiva.<br/>            In altre parole stabilisce se gli angoli degli assi del grafico sono indipendenti dalla rotazione o elevazione del grafico.<br/>            Lettura/Scrittura **bool**. |
| [`depth_percents`](/slides/python-net/it/aspose.slides.charts/rotation3d/depth_percents/) | Restituisce o imposta la profondità di un grafico 3D come percentuale della larghezza del grafico (tra 20 e 2000 percento).<br/>            Lettura/Scrittura **int**. |
| [`height_percents`](/slides/python-net/it/aspose.slides.charts/rotation3d/height_percents/) | Specifica l'altezza di un grafico 3-D come percentuale della larghezza del grafico (tra 5 e 500 percento).<br/>            Lettura/Scrittura **int**. |
