## ChartCellCollection classe

Rappresenta una collezione di celle con dati.

Il tipo ChartCellCollection espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`count`](/slides/python-net/it/aspose.slides.charts/chartcellcollection/count/) | Ottiene il conteggio delle celle nella collezione.<br/>            Sola lettura **int**. |

Restituisce una cella (IChartDataCell) per indice.

| Nome | Descrizione |
| :- | :- |
| [`[index]`](/slides/python-net/it/aspose.slides.charts/chartcellcollection/__getitem__/) | Indice di una cella. |
