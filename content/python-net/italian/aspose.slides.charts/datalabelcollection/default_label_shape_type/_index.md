## default_label_shape_type proprietà
Ottiene o imposta il tipo di forma predefinito per le etichette dati.
             Restituisce [`ShapeType.NOT_DEFINED`](/slides/python-net/it/aspose.slides/shapetype/NOT_DEFINED) se non è definita alcuna forma.


### Osservazioni

Impostare questa proprietà imposta anche la proprietà [`IDataLabel.label_shape_type`](/slides/python-net/it/aspose.slides.charts/idatalabel/label_shape_type) per tutte le etichette dati nella raccolta allo stesso valore.
