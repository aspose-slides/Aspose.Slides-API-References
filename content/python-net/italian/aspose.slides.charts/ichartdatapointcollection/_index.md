## IChartDataPointCollection classe

Rappresenta una collezione di un punto dati di serie.

Il tipo IChartDataPointCollection espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`data_source_type_for_x_values`](/slides/python-net/it/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_x_values/) | Specifica se la proprietà AsCell o AsLiteralString o AsLiteralDouble<br/>            è effettiva nell'oggetto proprietà XValue dei punti dati. In altre parole specifica<br/>            il tipo di valore della proprietà Data di ChartDataPointEx.XValue.<br/>            Lettura/scrittura [`DataSourceType`](/slides/python-net/it/aspose.slides.charts/datasourcetype). |

In altre parole specifica<br/>            il tipo di valore della proprietà Data di ChartDataPointEx.YValue.<br/>            Lettura/scrittura [`DataSourceType`](/slides/python-net/it/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_bubble_sizes`](/slides/python-net/it/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_bubble_sizes/) | Specifica se la proprietà AsCell o AsLiteralString o AsLiteralDouble<br/>            è effettiva nell'oggetto proprietà BubbleSize dei punti dati. In altre parole specifica<br/>            il tipo di valore della proprietà Data di ChartDataPointEx.BubbleSize.<br/>            Lettura/scrittura [`DataSourceType`](/slides/python-net/it/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_values`](/slides/python-net/it/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_values/) | Specifica se la proprietà AsCell o AsLiteralString o AsLiteralDouble<br/>            è effettiva nell'oggetto proprietà Value dei punti dati. In altre parole specifica<br/>            il tipo di valore della proprietà Data di ChartDataPoint.Value.<br/>            Lettura/scrittura [`DataSourceType`](/slides/python-net/it/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_error_bars_custom_values`](/slides/python-net/it/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_error_bars_custom_values/) | Specifica il tipo di valori nella lista di proprietà ChartDataPoint.ErrorBarsCustomValues.<br/>            Sola lettura [`IDataSourceTypeForErrorBarsCustomValues`](/slides/python-net/it/aspose.slides.charts/idatasourcetypeforerrorbarscustomvalues). |
