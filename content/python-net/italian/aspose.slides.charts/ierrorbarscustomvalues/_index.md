## IErrorBarsCustomValues classe

Specifica i valori delle barre di errore. Deve essere usato solo quando il tipo di valore delle barre di errore è Custom.

Il tipo IErrorBarsCustomValues espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`x_minus`](/slides/python-net/it/aspose.slides.charts/ierrorbarscustomvalues/x_minus/) | Specifica il valore della barra di errore nella direzione negativa. <br/>            Disponibile se il tipo di valore delle barre di errore è Custom e ErrorBarsXFormat è consentito.<br/>            In qualsiasi altro caso questa proprietà restituisce None.  <br/>            Solo lettura [`IDoubleChartValue`](/slides/python-net/it/aspose.slides.charts/idoublechartvalue). |
| [`y_minus`](/slides/python-net/it/aspose.slides.charts/ierrorbarscustomvalues/y_minus/) | Specifica il valore della barra di errore nella direzione negativa. <br/>            Disponibile se il tipo di valore delle barre di errore è Custom e ErrorBarsYFormat è consentito. <br/>            In qualsiasi altro caso questa proprietà restituisce None. <br/>            Solo lettura [`IDoubleChartValue`](/slides/python-net/it/aspose.slides.charts/idoublechartvalue). |
| [`x_plus`](/slides/python-net/it/aspose.slides.charts/ierrorbarscustomvalues/x_plus/) | Specifica il valore della barra di errore nella direzione positiva. <br/>            Disponibile se il tipo di valore delle barre di errore è Custom e ErrorBarsXFormat è consentito. <br/>            In qualsiasi altro caso questa proprietà restituisce None. <br/>            Solo lettura [`IDoubleChartValue`](/slides/python-net/it/aspose.slides.charts/idoublechartvalue). |
| [`y_plus`](/slides/python-net/it/aspose.slides.charts/ierrorbarscustomvalues/y_plus/) | Specifica il valore della barra di errore nella direzione positiva. <br/>            Disponibile se il tipo di valore delle barre di errore è Custom e ErrorBarsYFormat è consentito.<br/>            In qualsiasi altro caso questa proprietà restituisce None. <br/>            Solo lettura [`IDoubleChartValue`](/slides/python-net/it/aspose.slides.charts/idoublechartvalue). |
