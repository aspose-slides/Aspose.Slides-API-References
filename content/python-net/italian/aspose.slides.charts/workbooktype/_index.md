## WorkbookType enumerazione

Specifica il tipo di file cartella di lavoro Open XML.

Il tipo WorkbookType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| NOT_DEFINED | Il tipo di cartella di lavoro non è definito. |
| WORKBOOK | Cartella di lavoro Excel (*.xlsx). |
| WORKBOOK_MACRO | Cartella di lavoro Excel con macro (*.xlsm). |
| TEMPLATE | Modello Excel (*.xltx). |
| TEMPLATE_MACRO | Modello Excel con macro (*.xltm). |
| WORKBOOK_BINARY_MACRO | Cartella di lavoro Excel binaria con macro (*.xlsb). |
