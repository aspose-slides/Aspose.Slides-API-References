## enumerazione ErrorBarType

Rappresenta il tipo di barra di errore

Il tipo ErrorBarType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| BOTH | Specifica che le barre di errore devono essere mostrate nelle direzioni positiva e negativa. |
| MINUS | Specifica che le barre di errore devono essere mostrate solo nella direzione negativa. |
| PLUS | Specifica che le barre di errore devono essere mostrate solo nella direzione positiva. |
