## IChartParagraphFormat classe

Rappresenta le proprietà di formattazione di un paragrafo di un grafico.

Il tipo IChartParagraphFormat espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`alignment`](/slides/python-net/it/aspose.slides.charts/ichartparagraphformat/alignment/) | Restituisce o imposta l'allineamento del testo in un paragrafo.<br/>            Lettura/Scrittura [`TextAlignment`](/slides/python-net/it/aspose.slides/textalignment). |
| [`space_within`](/slides/python-net/it/aspose.slides.charts/ichartparagraphformat/space_within/) | Restituisce o imposta la quantità di spazio tra le linee di base in un paragrafo.<br/>            Lettura/Scrittura **float**. |
| [`space_before`](/slides/python-net/it/aspose.slides.charts/ichartparagraphformat/space_before/) | Restituisce o imposta la quantità di spazio prima della prima riga in un paragrafo.<br/>            Lettura/Scrittura **float**. |
| [`space_after`](/slides/python-net/it/aspose.slides.charts/ichartparagraphformat/space_after/) | Restituisce o imposta la quantità di spazio dopo l'ultima riga in un paragrafo.<br/>            Lettura/Scrittura **float**. |
| [`east_asian_line_break`](/slides/python-net/it/aspose.slides.charts/ichartparagraphformat/east_asian_line_break/) | Determina se l'interruzione di riga East Asian è usata in un paragrafo.<br/>            Lettura/Scrittura [`NullableBool`](/slides/python-net/it/aspose.slides/nullablebool). |
| [`right_to_left`](/slides/python-net/it/aspose.slides.charts/ichartparagraphformat/right_to_left/) | Determina se la scrittura da destra a sinistra è usata in un paragrafo.<br/>            Lettura/Scrittura [`NullableBool`](/slides/python-net/it/aspose.slides/nullablebool). |
| [`latin_line_break`](/slides/python-net/it/aspose.slides.charts/ichartparagraphformat/latin_line_break/) | Determina se l'interruzione di riga Latin è usata in un paragrafo.<br/>            Lettura/Scrittura [`NullableBool`](/slides/python-net/it/aspose.slides/nullablebool). |
| [`hanging_punctuation`](/slides/python-net/it/aspose.slides.charts/ichartparagraphformat/hanging_punctuation/) | Determina se la punteggiatura sospesa è usata in un paragrafo.<br/>            Lettura/Scrittura [`NullableBool`](/slides/python-net/it/aspose.slides/nullablebool). |
| [`margin_left`](/slides/python-net/it/aspose.slides.charts/ichartparagraphformat/margin_left/) | Restituisce o imposta il margine sinistro in un paragrafo.<br/>            Lettura/Scrittura **float**. |
| [`margin_right`](/slides/python-net/it/aspose.slides.charts/ichartparagraphformat/margin_right/) | Restituisce o imposta il margine destro in un paragrafo.<br/>            Lettura/Scrittura **float**. |
| [`indent`](/slides/python-net/it/aspose.slides.charts/ichartparagraphformat/indent/) | Restituisce o imposta il rientro della prima riga / rientro sospeso del paragrafo. Il rientro sospeso può essere definito con valori negativi.<br/>            Lettura/Scrittura **float**. |
| [`default_tab_size`](/slides/python-net/it/aspose.slides.charts/ichartparagraphformat/default_tab_size/) | Restituisce o imposta la dimensione predefinita della tabulazione.<br/>            Lettura/Scrittura **float**. |
| [`tabs`](/slides/python-net/it/aspose.slides.charts/ichartparagraphformat/tabs/) | Restituisce le tabulazioni di un paragrafo.<br/>            Solo lettura [`ITabCollection`](/slides/python-net/it/aspose.slides/itabcollection). |
| [`font_alignment`](/slides/python-net/it/aspose.slides.charts/ichartparagraphformat/font_alignment/) | Restituisce o imposta l'allineamento del font in un paragrafo.<br/>            Lettura/Scrittura [`FontAlignment`](/slides/python-net/it/aspose.slides/fontalignment). |
