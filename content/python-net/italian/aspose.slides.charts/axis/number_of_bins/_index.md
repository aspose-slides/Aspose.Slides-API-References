## number_of_bins proprietà
Specifica il numero di bins quando il valore della proprietà AggregationType è impostato su AxisAggregationType.ByNumberOfBins. 
            Applicato agli assi di categoria. Utilizzato solo con le serie Histogram o HistogramPareto.
