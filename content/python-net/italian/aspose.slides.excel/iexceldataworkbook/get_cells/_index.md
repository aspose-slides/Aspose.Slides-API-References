## get_cells(self, formula, skip_hidden_cells) {#str-bool}
Recupera una raccolta di celle dalla cartella di lavoro che corrispondono alla formula specificata.

### Restituisce

Un elenco di sola lettura di celle che corrispondono alla formula specificata.



```python
def get_cells(self, formula, skip_hidden_cells):
    ...
```


| Parametro | Tipo | Descrizione |
| :- | :- | :- |
| formula | **str** | Un'espressione di formula o intervallo (ad es., "Sheet1!A1:B3") usata per identificare le celle target. |
| skip_hidden_cells | **bool** | Se `true`, le celle nascoste (ad es., in righe o colonne nascoste) saranno escluse dal risultato. |
