## ExcelDataCell classe

Rappresenta una singola cella in una cartella di lavoro Excel.

Il tipo ExcelDataCell espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`value`](/slides/python-net/it/aspose.slides.excel/exceldatacell/value/) | Ottiene il valore contenuto nella cella Excel. |
| [`name`](/slides/python-net/it/aspose.slides.excel/exceldatacell/name/) | Ottiene il nome della cella dati del grafico. |
| [`row`](/slides/python-net/it/aspose.slides.excel/exceldatacell/row/) | Ottiene l'indice basato su zero della riga nel foglio di lavoro in cui si trova la cella.<br/>            Read-only **int**. |
| [`column`](/slides/python-net/it/aspose.slides.excel/exceldatacell/column/) | Ottiene l'indice basato su zero della colonna nel foglio di lavoro in cui si trova la cella.<br/>            Read-only **int**. |
