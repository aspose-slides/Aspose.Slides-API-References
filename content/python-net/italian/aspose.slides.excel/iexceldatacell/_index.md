## IExcelDataCell classe

Rappresenta una singola cella in una cartella di lavoro Excel.

Il tipo IExcelDataCell espone i seguenti membri:

## Proprietà

| Property | Description |
| :- | :- |
| [`value`](/slides/python-net/it/aspose.slides.excel/iexceldatacell/value/) | Restituisce il valore contenuto nella cella Excel.<br/>            Sola lettura **any**. |
| [`name`](/slides/python-net/it/aspose.slides.excel/iexceldatacell/name/) | Restituisce il nome della cella dati del grafico.<br/>            Sola lettura **str**. |
| [`row`](/slides/python-net/it/aspose.slides.excel/iexceldatacell/row/) | Restituisce l'indice basato su zero della riga nel foglio di lavoro in cui si trova la cella.<br/>            Sola lettura **int**. |
| [`column`](/slides/python-net/it/aspose.slides.excel/iexceldatacell/column/) | Restituisce l'indice basato su zero della colonna nel foglio di lavoro in cui si trova la cella.<br/>            Sola lettura **int**. |
