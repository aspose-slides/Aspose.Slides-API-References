## ITextFrameFormatEffectiveData classe

Oggetto immutabile che contiene le proprietà di formattazione effettive del riquadro di testo.

Il tipo ITextFrameFormatEffectiveData espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`text_style`](/slides/python-net/it/aspose.slides/itextframeformateffectivedata/text_style/) | Restituisce lo stile del testo effettivo.<br/>            Solo lettura [`ITextStyleEffectiveData`](/slides/python-net/it/aspose.slides/itextstyleeffectivedata). |
| [`margin_left`](/slides/python-net/it/aspose.slides/itextframeformateffectivedata/margin_left/) | Restituisce il margine sinistro (punti) in un TextFrame.<br/>            Solo lettura **float**. |
| [`margin_right`](/slides/python-net/it/aspose.slides/itextframeformateffectivedata/margin_right/) | Restituisce il margine destro (punti) in un TextFrame.<br/>            Solo lettura **float**. |
| [`margin_top`](/slides/python-net/it/aspose.slides/itextframeformateffectivedata/margin_top/) | Restituisce il margine superiore (punti) in un TextFrame.<br/>            Solo lettura **float**. |
| [`margin_bottom`](/slides/python-net/it/aspose.slides/itextframeformateffectivedata/margin_bottom/) | Restituisce il margine inferiore (punti) in un TextFrame.<br/>            Solo lettura **float**. |
| [`wrap_text`](/slides/python-net/it/aspose.slides/itextframeformateffectivedata/wrap_text/) | Restituisce se il testo è avvolto nei margini del TextFrame.<br/>            Solo lettura **bool**. |
| [`anchoring_type`](/slides/python-net/it/aspose.slides/itextframeformateffectivedata/anchoring_type/) | Restituisce il testo di ancoraggio verticale in un TextFrame.<br/>            Solo lettura [`TextAnchorType`](/slides/python-net/it/aspose.slides/textanchortype). |
| [`center_text`](/slides/python-net/it/aspose.slides/itextframeformateffectivedata/center_text/) | Restituisce se il testo deve essere centrato orizzontalmente nella casella.<br/>            Solo lettura **bool**. |
| [`text_vertical_type`](/slides/python-net/it/aspose.slides/itextframeformateffectivedata/text_vertical_type/) | Restituisce l'orientamento del testo.<br/>            Solo lettura [`TextVerticalType`](/slides/python-net/it/aspose.slides/textverticaltype). |
| [`autofit_type`](/slides/python-net/it/aspose.slides/itextframeformateffectivedata/autofit_type/) | Restituisce la modalità di adattamento automatico del testo.<br/>            Solo lettura [`TextAutofitType`](/slides/python-net/it/aspose.slides/textautofittype). |
| [`column_count`](/slides/python-net/it/aspose.slides/itextframeformateffectivedata/column_count/) | Specifica il numero di colonne di testo nel rettangolo di delimitazione.<br/>            Solo lettura **int**. |
| [`column_spacing`](/slides/python-net/it/aspose.slides/itextframeformateffectivedata/column_spacing/) | Specifica lo spazio tra le colonne di testo nell'area di testo (in punti).<br/>            Solo lettura **float**. |

### Osservazioni

Questa interfaccia è utilizzata insieme all'interfaccia [`ITextFrameFormat`](/slides/python-net/it/aspose.slides/itextframeformat) per restituire valori di formattazione effective con ereditarietà applicata.
