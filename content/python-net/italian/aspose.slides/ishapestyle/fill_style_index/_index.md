## fill_style_index proprietà
Restituisce o imposta l'indice della colonna di riempimento della forma nelle matrici di stile.
            0 indica nessun riempimento,
            valore positivo - indice negli stili di riempimento del tema,
            valore negativo - indice negli stili di sfondo del tema.
            Lettura/Scrittura **int**.
