## IShapeStyle classe

Rappresenta il riferimento allo stile della forma.

Il tipo IShapeStyle espone i seguenti membri:

## Proprietà

| Property | Description |
| :- | :- |
| [`line_color`](/slides/python-net/it/aspose.slides/ishapestyle/line_color/) | Restituisce il colore del contorno della forma.<br/>            Solo lettura [`IColorFormat`](/slides/python-net/it/aspose.slides/icolorformat). |
| [`line_style_index`](/slides/python-net/it/aspose.slides/ishapestyle/line_style_index/) | Restituisce o imposta l'indice di colonna della linea in una matrice di stile.<br/>            Lettura/scrittura **int**. |
| [`fill_color`](/slides/python-net/it/aspose.slides/ishapestyle/fill_color/) | Restituisce il colore di riempimento della forma.<br/>            Solo lettura [`IColorFormat`](/slides/python-net/it/aspose.slides/icolorformat). |
| [`fill_style_index`](/slides/python-net/it/aspose.slides/ishapestyle/fill_style_index/) | Restituisce o imposta l'indice di colonna di riempimento della forma nelle matrici di stile.<br/>            0 indica nessun riempimento,<br/>            valore positivo - indice negli stili di riempimento del tema,<br/>            valore negativo - indice negli stili di sfondo del tema.<br/>            Lettura/scrittura **int**. |
| [`effect_color`](/slides/python-net/it/aspose.slides/ishapestyle/effect_color/) | Restituisce il colore dell'effetto della forma.<br/>            Solo lettura [`IColorFormat`](/slides/python-net/it/aspose.slides/icolorformat). |
| [`effect_style_index`](/slides/python-net/it/aspose.slides/ishapestyle/effect_style_index/) | Restituisce o imposta l'indice di colonna dell'effetto della forma in una matrice di stile.<br/>            Lettura/scrittura **int**. |
| [`font_color`](/slides/python-net/it/aspose.slides/ishapestyle/font_color/) | Restituisce il colore del carattere della forma.<br/>            Solo lettura [`IColorFormat`](/slides/python-net/it/aspose.slides/icolorformat). |
| [`font_collection_index`](/slides/python-net/it/aspose.slides/ishapestyle/font_collection_index/) | Restituisce o imposta l'indice del carattere della forma in una collezione di caratteri.<br/>            Lettura/scrittura [`FontCollectionIndex`](/slides/python-net/it/aspose.slides/fontcollectionindex). |
