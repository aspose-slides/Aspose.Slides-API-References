## CommentAuthor classe

Rappresenta un autore di commenti.

Il tipo CommentAuthor espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`name`](/slides/python-net/it/aspose.slides/commentauthor/name/) | Restituisce o imposta il nome dell'autore.<br/>            Lettura/scrittura **str**. |
| [`initials`](/slides/python-net/it/aspose.slides/commentauthor/initials/) | Restituisce o imposta le iniziali dell'autore.<br/>            Lettura/scrittura **str**. |
| [`comments`](/slides/python-net/it/aspose.slides/commentauthor/comments/) | Restituisce la raccolta di commenti fatti da questo autore.<br/>            Sola lettura [`ICommentCollection`](/slides/python-net/it/aspose.slides/icommentcollection). |

## Metodi

| Metodo | Descrizione |
| :- | :- |
| [`remove(self)`](/slides/python-net/it/aspose.slides/commentauthor/remove/#) | Rimuove l'autore dalla raccolta padre. |
