## IColorFormat classe

Rappresenta un colore utilizzato in una presentazione.

Il tipo IColorFormat espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`color_type`](/slides/python-net/it/aspose.slides/icolorformat/color_type/) | Restituisce o imposta il metodo di definizione del colore.<br/>            Lettura/scrittura [`ColorType`](/slides/python-net/it/aspose.slides/colortype). |
| [`color`](/slides/python-net/it/aspose.slides/icolorformat/color/) | Restituisce il colore risultante (con tutte le trasformazioni colore applicate).<br/>            Imposta i colori RGB e cancella tutte le trasformazioni colore.<br/>            Lettura/scrittura **aspose.slides.Color**. |
| [`preset_color`](/slides/python-net/it/aspose.slides/icolorformat/preset_color/) | Restituisce o imposta il preset di colore.<br/>            Lettura/scrittura [`PresetColor`](/slides/python-net/it/aspose.slides/presetcolor). |
| [`system_color`](/slides/python-net/it/aspose.slides/icolorformat/system_color/) | Restituisce o imposta il colore identificato dalla tabella dei colori di sistema.<br/>            Lettura/scrittura [`SystemColor`](/slides/python-net/it/aspose.slides/systemcolor). |
| [`scheme_color`](/slides/python-net/it/aspose.slides/icolorformat/scheme_color/) | Restituisce o imposta il colore identificato da uno schema di colore.<br/>            Lettura/scrittura [`SchemeColor`](/slides/python-net/it/aspose.slides/schemecolor). |
| [`r`](/slides/python-net/it/aspose.slides/icolorformat/r/) | Restituisce o imposta il componente rosso di un colore. Tutte le trasformazioni colore sono ignorate.<br/>            Lettura/scrittura **int**. |
| [`g`](/slides/python-net/it/aspose.slides/icolorformat/g/) | Restituisce o imposta il componente verde di un colore. Tutte le trasformazioni colore sono ignorate.<br/>            Lettura/scrittura **int**. |
| [`b`](/slides/python-net/it/aspose.slides/icolorformat/b/) | Restituisce o imposta il componente blu di un colore. Tutte le trasformazioni colore sono ignorate.<br/>            Lettura/scrittura **int**. |
| [`float_r`](/slides/python-net/it/aspose.slides/icolorformat/float_r/) | Restituisce o imposta il componente rosso di un colore. Tutte le trasformazioni colore sono ignorate.<br/>            Lettura/scrittura **float**. |
| [`float_g`](/slides/python-net/it/aspose.slides/icolorformat/float_g/) | Restituisce o imposta il componente verde di un colore. Tutte le trasformazioni colore sono ignorate.<br/>            Lettura/scrittura **float**. |
| [`float_b`](/slides/python-net/it/aspose.slides/icolorformat/float_b/) | Restituisce o imposta il componente blu di un colore. Tutte le trasformazioni colore sono ignorate.<br/>            Lettura/scrittura **float**. |
| [`hue`](/slides/python-net/it/aspose.slides/icolorformat/hue/) | Restituisce o imposta il componente tonalità di un colore in rappresentazione HSL.<br/>            Tutte le trasformazioni colore sono ignorate.<br/>            Lettura/scrittura **float**. |
| [`saturation`](/slides/python-net/it/aspose.slides/icolorformat/saturation/) | Restituisce o imposta il componente saturazione di un colore in rappresentazione HSL.<br/>            Tutte le trasformazioni colore sono ignorate.<br/>            Lettura/scrittura **float**. |
| [`luminance`](/slides/python-net/it/aspose.slides/icolorformat/luminance/) | Restituisce o imposta il componente luminanza di un colore in rappresentazione HSL.<br/>            Tutte le trasformazioni colore sono ignorate.<br/>            Lettura/scrittura **float**. |
| [`color_transform`](/slides/python-net/it/aspose.slides/icolorformat/color_transform/) | Restituisce la raccolta di trasformazioni colore applicate a un colore.<br/>            Sola lettura [`IColorOperationCollection`](/slides/python-net/it/aspose.slides/icoloroperationcollection). |
