## IControl classe

Represents an ActiveX control.

The IControl type exposes the following members:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`name`](/slides/python-net/it/aspose.slides/icontrol/name/) | Restituisce il nome di questo controllo.<br/>            Lettura/scrittura **str**. |
| [`class_id`](/slides/python-net/it/aspose.slides/icontrol/class_id/) | Ottiene l'id della classe di questo controllo.<br/>            Sola lettura **System.Guid**. |
| [`substitute_picture_format`](/slides/python-net/it/aspose.slides/icontrol/substitute_picture_format/) | Restituisce l'oggetto delle proprietà di riempimento immagine di ControlEx.<br/>            Sola lettura [`IPictureFillFormat`](/slides/python-net/it/aspose.slides/ipicturefillformat). |
| [`frame`](/slides/python-net/it/aspose.slides/icontrol/frame/) | Restituisce o imposta il frame del controllo.<br/>            Lettura/scrittura [`IShapeFrame`](/slides/python-net/it/aspose.slides/ishapeframe). |
| [`properties`](/slides/python-net/it/aspose.slides/icontrol/properties/) | Restituisce una collezione di proprietà ActiveX.<br/>            Sola lettura [`IControlPropertiesCollection`](/slides/python-net/it/aspose.slides/icontrolpropertiescollection). |
| [`persistence`](/slides/python-net/it/aspose.slides/icontrol/persistence/) | Ottiene il metodo usato per memorizzare le proprietà del controllo ActiveX.<br/>            Solo lettura [`PersistenceType`](/slides/python-net/it/aspose.slides/persistencetype). |
| [`active_x_control_binary`](/slides/python-net/it/aspose.slides/icontrol/active_x_control_binary/) | Specifica la persistenza di un controllo ActiveX quando il metodo usato per la persistenza è PersistStream, PersistStreamInit o PersistStorage. |
