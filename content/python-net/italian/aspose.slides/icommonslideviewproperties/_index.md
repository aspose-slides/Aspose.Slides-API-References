## ICommonSlideViewProperties classe

Rappresenta le proprietà comuni della visualizzazione della diapositiva.

Il tipo ICommonSlideViewProperties espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`scale`](/slides/python-net/it/aspose.slides/icommonslideviewproperties/scale/) | Specifica il rapporto di scala della visualizzazione in percentuale.<br/>            Lettura/scrittura **int**. |
| [`variable_scale`](/slides/python-net/it/aspose.slides/icommonslideviewproperties/variable_scale/) | Specifica che il contenuto della visualizzazione dovrebbe ridimensionarsi automaticamente per adattarsi al meglio alle dimensioni della finestra corrente.<br/>            Lettura/scrittura **bool**. |
| [`drawing_guides`](/slides/python-net/it/aspose.slides/icommonslideviewproperties/drawing_guides/) | Restituisce la raccolta delle guide di disegno.<br/>            Sola lettura [`IDrawingGuidesCollection`](/slides/python-net/it/aspose.slides/idrawingguidescollection) |
