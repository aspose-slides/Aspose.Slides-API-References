## classe IPictureEffectiveData

Oggetto immutabile che contiene le proprietà effettive dell'immagine.

Il tipo IPictureEffectiveData espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`image`](/slides/python-net/it/aspose.slides/ipictureeffectivedata/image/) | Restituisce l'immagine incorporata.<br/>            Solo lettura [`IPPImage`](/slides/python-net/it/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/it/aspose.slides/ipictureeffectivedata/link_path_long/) | Restituisce l'URL dell'immagine collegata.<br/>            Solo lettura **str**. |
| [`image_transform`](/slides/python-net/it/aspose.slides/ipictureeffectivedata/image_transform/) | Restituisce la collezione degli effetti di trasformazione dell'immagine.<br/>            Solo lettura [`IImageTransformOCollectionEffectiveData`](/slides/python-net/it/aspose.slides.effects/iimagetransformocollectioneffectivedata). |


### Osservazioni

Questa interfaccia è usata come parte di [`IPictureFillFormatEffectiveData`](/slides/python-net/it/aspose.slides/ipicturefillformateffectivedata) e [`IBulletFormatEffectiveData`](/slides/python-net/it/aspose.slides/ibulletformateffectivedata).
