## IParagraphFormatEffectiveData classe

Oggetto immutabile che contiene le proprietà di formattazione effettiva del paragrafo.

Il tipo IParagraphFormatEffectiveData espone i seguenti membri:

## Proprietà

| Property | Description |
| :- | :- |
| [`bullet`](/slides/python-net/it/aspose.slides/iparagraphformateffectivedata/bullet/) | Restituisce un formato puntato di un paragrafo.<br/>            Solo lettura [`IBulletFormatEffectiveData`](/slides/python-net/it/aspose.slides/ibulletformateffectivedata). |
| [`depth`](/slides/python-net/it/aspose.slides/iparagraphformateffectivedata/depth/) | Restituisce la profondità di un paragrafo.<br/>            Solo lettura **int**. |

| [`space_before`](/slides/python-net/it/aspose.slides/iparagraphformateffectivedata/space_before/) | Restituisce la quantità di spazio prima della prima riga in un paragrafo.<br/>            Solo lettura **float**. |
| [`space_after`](/slides/python-net/it/aspose.slides/iparagraphformateffectivedata/space_after/) | Restituisce la quantità di spazio dopo l'ultima riga in un paragrafo.<br/>            Solo lettura **float**. |

### Osservazioni

Questa interfaccia è utilizzata insieme all'interfaccia [`IParagraphFormat`](/slides/python-net/it/aspose.slides/iparagraphformat) per restituire i valori di formattazione effettiva con ereditarietà applicata.
