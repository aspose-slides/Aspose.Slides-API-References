## GraphicalObjectLock classe

Determina quali operazioni sono disabilitate sull'oggetto GraphicalObject padre.

**Ereditarietà:**[`GraphicalObjectLock`](/slides/python-net/it/aspose.slides/graphicalobjectlock) → [`BaseShapeLock`](/slides/python-net/it/aspose.slides/baseshapelock)

Il tipo GraphicalObjectLock espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`no_locks`](/slides/python-net/it/aspose.slides/graphicalobjectlock/no_locks/) | Restituisce true se tutti i flag di blocco sono disabilitati.<br/>            Sola lettura **bool**. |
| [`grouping_locked`](/slides/python-net/it/aspose.slides/graphicalobjectlock/grouping_locked/) | Determina se l'aggiunta di questa forma a un gruppo è proibita.<br/>            Lettura/Scrittura **bool**. |
| [`drilldown_locked`](/slides/python-net/it/aspose.slides/graphicalobjectlock/drilldown_locked/) | Determina se la selezione di sottoforme di questo oggetto è proibita.<br/>            Lettura/Scrittura **bool**. |
| [`select_locked`](/slides/python-net/it/aspose.slides/graphicalobjectlock/select_locked/) | Determina se la selezione di questa forma è proibita.<br/>            Lettura/Scrittura **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/it/aspose.slides/graphicalobjectlock/aspect_ratio_locked/) | Determina se la forma deve mantenere le proporzioni durante il ridimensionamento.<br/>            Lettura/Scrittura **bool**. |
| [`position_locked`](/slides/python-net/it/aspose.slides/graphicalobjectlock/position_locked/) | Determina se lo spostamento di questa forma è proibito.<br/>            Lettura/Scrittura **bool**. |
| [`size_locked`](/slides/python-net/it/aspose.slides/graphicalobjectlock/size_locked/) | Determina se il ridimensionamento di questa forma è proibito.<br/>            Lettura/Scrittura **bool**. |
