## Enumerazione PPImageFormat

Formati immagine. Questa enumerazione è un sostituto della classe `System.Drawing.Imaging.ImageFormat`. È necessaria per la compatibilità COM.

Il tipo PPImageFormat espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| BMP | Restituisce il formato immagine bitmap (BMP). |
| EMF | Restituisce il formato immagine metafile avanzato (EMF). |
| EXIF | Restituisce il formato Exchangeable Image File (Exif). |
| GIF | Restituisce il formato immagine Graphics Interchange Format (GIF). |
| ICON | Restituisce il formato immagine icona Windows. |
| JPEG | Restituisce il formato immagine Joint Photographic Experts Group (JPEG). |
| MEMORY_BMP | Restituisce il formato di un bitmap in memoria. |
| PNG | Restituisce il formato immagine W3C Portable Network Graphics (PNG). |
| TIFF | Restituisce il formato immagine Tagged Image File Format (TIFF). |
| WMF | Restituisce il formato immagine metafile Windows (WMF). |
