## ModernComment classe

Rappresenta un commento su una diapositiva.

**Eredità:**[`ModernComment`](/slides/python-net/it/aspose.slides/moderncomment) → [`Comment`](/slides/python-net/it/aspose.slides/comment)

Il tipo ModernComment espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`text`](/slides/python-net/it/aspose.slides/moderncomment/text/) | Restituisce o imposta il testo semplice di un commento su una diapositiva.<br/>            Leggi/scrivi **str**. |
| [`created_time`](/slides/python-net/it/aspose.slides/moderncomment/created_time/) | Restituisce o imposta l'ora della creazione di un commento.<br/>            Impostare questa proprietà a **System.DateTime** indica che non è impostata l'ora del commento.<br/>            Leggi/scrivi **System.DateTime**. |
| [`slide`](/slides/python-net/it/aspose.slides/moderncomment/slide/) | Restituisce o imposta la diapositiva genitore di un commento.<br/>            Sola lettura [`ISlide`](/slides/python-net/it/aspose.slides/islide). |
| [`author`](/slides/python-net/it/aspose.slides/moderncomment/author/) | Restituisce l'autore di un commento.<br/>            Sola lettura [`ICommentAuthor`](/slides/python-net/it/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/it/aspose.slides/moderncomment/position/) | Restituisce o imposta la posizione di un commento su una diapositiva.<br/>            Leggi/scrivi [`PointF`](/slides/python-net/it/aspose.slides/pointf). |
| [`parent_comment`](/slides/python-net/it/aspose.slides/moderncomment/parent_comment/) | Restituisce o imposta il commento genitore.<br/>            Leggi/scrivi [`IComment`](/slides/python-net/it/aspose.slides/icomment). |
| [`shape`](/slides/python-net/it/aspose.slides/moderncomment/shape/) | Restituisce una forma associata al commento.<br/>            Sola lettura [`IShape`](/slides/python-net/it/aspose.slides/ishape). |
| [`text_selection_start`](/slides/python-net/it/aspose.slides/moderncomment/text_selection_start/) | Restituisce o imposta la posizione iniziale della selezione di testo nel frame di testo se il commento è associato a AutoShape.<br/>            Leggi/scrivi **int**. |
| [`text_selection_length`](/slides/python-net/it/aspose.slides/moderncomment/text_selection_length/) | Restituisce o imposta la lunghezza della selezione di testo nel frame di testo se il commento è associato a AutoShape.<br/>            Leggi/scrivi **int**. |
| [`status`](/slides/python-net/it/aspose.slides/moderncomment/status/) | Restituisce o imposta lo stato del commento.<br/>            Leggi/scrivi [`ModernCommentStatus`](/slides/python-net/it/aspose.slides/moderncommentstatus). |

## Metodi

| Metodo | Descrizione |
| :- | :- |
| [`remove(self)`](/slides/python-net/it/aspose.slides/moderncomment/remove/#) | Rimuove il commento e tutte le sue risposte dalla collezione genitore. |
