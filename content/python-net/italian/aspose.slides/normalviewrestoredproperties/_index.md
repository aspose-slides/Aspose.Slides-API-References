## NormalViewRestoredProperties classe

Specifica le dimensioni della regione della diapositiva ((width quando è figlio di restoredTop, height quando è
            figlio di restoredLeft) della vista normale, quando la regione è di una dimensione restaurata variabile (né minimizzata né massimizzata).

Il tipo NormalViewRestoredProperties espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`dimension_size`](/slides/python-net/it/aspose.slides/normalviewrestoredproperties/dimension_size/) | Specifica le dimensioni della regione della diapositiva (width quando è figlio di RestoredTop, height quando è<br/>            figlio di RestoredLeft).<br/>            Read/write **float**. |
| [`auto_adjust`](/slides/python-net/it/aspose.slides/normalviewrestoredproperties/auto_adjust/) | Specifica se le dimensioni della regione del contenuto laterale devono compensare la nuova dimensione<br/>            durante il ridimensionamento della finestra contenente la vista nell'applicazione<br/>            Read/write **bool**. |
