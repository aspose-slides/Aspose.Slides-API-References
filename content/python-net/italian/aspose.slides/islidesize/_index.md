## ISlideSize classe

Rappresenta le dimensioni e l'orientamento di una diapositiva.

Il tipo ISlideSize espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`size`](/slides/python-net/it/aspose.slides/islidesize/size/) | Ottiene le dimensioni della diapositiva in punti. |
| [`type`](/slides/python-net/it/aspose.slides/islidesize/type/) | Ottiene il tipo di dimensione della diapositiva. |
| [`orientation`](/slides/python-net/it/aspose.slides/islidesize/orientation/) | Ottiene o imposta l'orientamento della diapositiva. |

## Metodi

| Metodo | Descrizione |
| :- | :- |
| [`set_size(self, type, scale_type)`](/slides/python-net/it/aspose.slides/islidesize/set_size/#slidesizetype-slidesizescaletype) | Imposta la dimensione della diapositiva per tipo e ridimensiona il contenuto esistente. |
| [`set_size(self, width, height, scale_type)`](/slides/python-net/it/aspose.slides/islidesize/set_size/#float-float-slidesizescaletype) | Imposta esplicitamente le dimensioni della diapositiva e ridimensiona il contenuto esistente. |
