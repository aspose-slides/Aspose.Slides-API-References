## INormalViewRestoredProperties classe

Specifica le dimensioni dell'area della diapositiva ((larghezza quando è figlio di restoredTop, altezza quando è figlio di restoredLeft) della vista normale, quando l'area è di dimensione variabile ripristinata (né minimizzata né massimizzata).

Il tipo INormalViewRestoredProperties espone i seguenti membri:

## Proprietà

| Property | Description |
| :- | :- |
| [`dimension_size`](/slides/python-net/it/aspose.slides/inormalviewrestoredproperties/dimension_size/) | Specifica la dimensione dell'area della diapositiva (larghezza quando è figlio di RestoredTop, altezza quando è<br/>            figlio di RestoredLeft).<br/>            Lettura/scrittura **float**.<br/>            Genera un'eccezione quando il valore è minore di 0 o maggiore di 100. |
| [`auto_adjust`](/slides/python-net/it/aspose.slides/inormalviewrestoredproperties/auto_adjust/) | Specifica se la dimensione dell'area di contenuto laterale deve compensare la nuova dimensione<br/>            durante il ridimensionamento della finestra che contiene la vista nell'applicazione.<br/>            Lettura/scrittura **bool**. |
