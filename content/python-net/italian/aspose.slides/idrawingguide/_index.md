## IDrawingGuide classe

Rappresenta una guida di disegno regolabile.

Il tipo IDrawingGuide espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`orientation`](/slides/python-net/it/aspose.slides/idrawingguide/orientation/) | Restituisce o imposta l'orientamento della guida di disegno.<br/>            Lettura/scrittura [`Orientation`](/slides/python-net/it/aspose.slides/orientation). |
| [`position`](/slides/python-net/it/aspose.slides/idrawingguide/position/) | Restituisce o imposta la posizione della guida di disegno in punti dal bordo superiore, angolo sinistro della diapositiva.<br/>            Lettura/scrittura **float**. |
| [`color`](/slides/python-net/it/aspose.slides/idrawingguide/color/) | Restituisce o imposta il colore della guida di disegno.<br/>            Lettura/scrittura [`Color`](/slides/python-net/it/aspose.slides/color). |
