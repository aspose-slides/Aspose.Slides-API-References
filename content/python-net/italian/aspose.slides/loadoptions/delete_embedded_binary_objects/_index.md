## delete_embedded_binary_objects proprietà
Determina se Aspose.Slides eliminerà tutti gli oggetti binari incorporati durante il caricamento della presentazione.

I tipi degli oggetti binari incorporati:

* Progetto VBA [`IPresentation.vba_project`](/slides/python-net/it/aspose.slides/ipresentation/vba_project)
* Dati incorporati OLE Object [`IOleEmbeddedDataInfo.embedded_file_data`](/slides/python-net/it/aspose.slides/ioleembeddeddatainfo/embedded_file_data)
* Dati binari ActiveX Control [`IControl.active_x_control_binary`](/slides/python-net/it/aspose.slides/icontrol/active_x_control_binary)

Lettura/scrittura **bool**.

### Note

Il valore predefinito è **false** .
