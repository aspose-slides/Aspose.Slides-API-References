## TagCollection classe

Rappresenta la collezione di tag (coppie di stringhe definite dall'utente)

Il tipo TagCollection espone i seguenti membri:

## Metodi

| Metodo | Descrizione |
| :- | :- |
| [`add(self, name, value)`](/slides/python-net/it/aspose.slides/tagcollection/add/#str-str) | Aggiunge un nuovo tag alla collezione. |
| [`remove(self, name)`](/slides/python-net/it/aspose.slides/tagcollection/remove/#str) | Rimuove il tag con un nome specificato dalla collezione. |
| [`index_of_name(self, name)`](/slides/python-net/it/aspose.slides/tagcollection/index_of_name/#str) | Restituisce l'indice basato su zero della chiave specificata nella collezione. |
| [`remove_at(self, index)`](/slides/python-net/it/aspose.slides/tagcollection/remove_at/#int) | Rimuove il tag all'indice specificato. |
| [`clear(self)`](/slides/python-net/it/aspose.slides/tagcollection/clear/#) | Rimuove tutti i tag dalla collezione. |
| [`get_value_by_index(self, index)`](/slides/python-net/it/aspose.slides/tagcollection/get_value_by_index/#int) | Restituisce il valore di un tag all'indice specificato. |
| [`get_name_by_index(self, index)`](/slides/python-net/it/aspose.slides/tagcollection/get_name_by_index/#int) | Restituisce la chiave di un tag all'indice specificato. |
| [`get_names_of_tags(self)`](/slides/python-net/it/aspose.slides/tagcollection/get_names_of_tags/#) | Restituisce i nomi dei tag. |
