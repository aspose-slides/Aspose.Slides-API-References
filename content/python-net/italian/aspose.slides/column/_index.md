## Classe Column

Rappresenta una colonna in una tabella.

**Eredità:**[`Column`](/slides/python-net/it/aspose.slides/column) → [`CellCollection`](/slides/python-net/it/aspose.slides/cellcollection)

Il tipo Column espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`slide`](/slides/python-net/it/aspose.slides/column/slide/) | Restituisce lo slide padre di una CellCollection.<br/>            Sola lettura [`IBaseSlide`](/slides/python-net/it/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/it/aspose.slides/column/presentation/) | Restituisce la presentazione padre di una CellCollection.<br/>            Sola lettura [`IPresentation`](/slides/python-net/it/aspose.slides/ipresentation). |
| [`width`](/slides/python-net/it/aspose.slides/column/width/) | Restituisce o imposta la larghezza di una colonna.<br/>            Lettura/scrittura **float**. |
| [`column_format`](/slides/python-net/it/aspose.slides/column/column_format/) | Restituisce l'oggetto ColumnFormat che contiene le proprietà di formattazione per questa colonna.<br/>            Sola lettura [`IColumnFormat`](/slides/python-net/it/aspose.slides/icolumnformat). |
