## IEffectFormat classe

Rappresenta le proprietà dell'effetto della forma.

Il tipo IEffectFormat espone i seguenti membri:

## Proprietà

| Property | Description |
| :- | :- |
| [`is_no_effects`](/slides/python-net/it/aspose.slides/ieffectformat/is_no_effects/) | Restituisce true se tutti gli effetti sono disabilitati (come appena creato, oggetto EffectFormat predefinito).<br/>            Solo lettura **bool**. |
| [`blur_effect`](/slides/python-net/it/aspose.slides/ieffectformat/blur_effect/) | Effetto sfocatura.<br/>            Lettura/scrittura [`IBlur`](/slides/python-net/it/aspose.slides.effects/iblur). |
| [`fill_overlay_effect`](/slides/python-net/it/aspose.slides/ieffectformat/fill_overlay_effect/) | Effetto di sovrapposizione riempimento.<br/>            Lettura/scrittura [`IFillOverlay`](/slides/python-net/it/aspose.slides.effects/ifilloverlay). |
| [`glow_effect`](/slides/python-net/it/aspose.slides/ieffectformat/glow_effect/) | Effetto bagliore.<br/>            Lettura/scrittura [`IGlow`](/slides/python-net/it/aspose.slides.effects/iglow). |
| [`inner_shadow_effect`](/slides/python-net/it/aspose.slides/ieffectformat/inner_shadow_effect/) | Ombra interna.<br/>            Lettura/scrittura [`IInnerShadow`](/slides/python-net/it/aspose.slides.effects/iinnershadow). |
| [`outer_shadow_effect`](/slides/python-net/it/aspose.slides/ieffectformat/outer_shadow_effect/) | Ombra esterna.<br/>            Lettura/scrittura [`IOuterShadow`](/slides/python-net/it/aspose.slides.effects/ioutershadow). |
| [`preset_shadow_effect`](/slides/python-net/it/aspose.slides/ieffectformat/preset_shadow_effect/) | Ombra predefinita.<br/>            Lettura/scrittura [`IPresetShadow`](/slides/python-net/it/aspose.slides.effects/ipresetshadow). |
| [`reflection_effect`](/slides/python-net/it/aspose.slides/ieffectformat/reflection_effect/) | Riflessione.<br/>            Lettura/scrittura [`IReflection`](/slides/python-net/it/aspose.slides.effects/ireflection). |
| [`soft_edge_effect`](/slides/python-net/it/aspose.slides/ieffectformat/soft_edge_effect/) | Bordo morbido.<br/>            Lettura/scrittura [`ISoftEdge`](/slides/python-net/it/aspose.slides.effects/isoftedge). |
