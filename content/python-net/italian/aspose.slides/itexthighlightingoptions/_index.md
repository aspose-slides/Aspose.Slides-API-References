## ITextHighlightingOptions classe

Rappresenta le opzioni che possono essere utilizzate per evidenziare il testo in un text frame.

Il tipo ITextHighlightingOptions espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`case_sensitive`](/slides/python-net/it/aspose.slides/itexthighlightingoptions/case_sensitive/) | Imposta true per utilizzare una ricerca sensibile al maiuscolo/minuscolo, false - altrimenti.<br/>            Lettura/Scrittura **bool**. |
| [`whole_words_only`](/slides/python-net/it/aspose.slides/itexthighlightingoptions/whole_words_only/) | Imposta true per corrispondere solo a parole intere, false - altrimenti.<br/>            Lettura/Scrittura **bool**. |
