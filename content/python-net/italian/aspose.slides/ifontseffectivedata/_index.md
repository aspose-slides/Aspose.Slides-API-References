## IFontsEffectiveData classe

Oggetto immutabile che contiene l'insieme di font effettivi.

Il tipo IFontsEffectiveData espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`latin_font`](/slides/python-net/it/aspose.slides/ifontseffectivedata/latin_font/) | Restituisce il font latino.<br/>            Sola lettura [`IFontData`](/slides/python-net/it/aspose.slides/ifontdata). |
| [`east_asian_font`](/slides/python-net/it/aspose.slides/ifontseffectivedata/east_asian_font/) | Restituisce il font dell'Est asiatico.<br/>            Sola lettura [`IFontData`](/slides/python-net/it/aspose.slides/ifontdata). |
| [`complex_script_font`](/slides/python-net/it/aspose.slides/ifontseffectivedata/complex_script_font/) | Restituisce il font per script complessi.<br/>            Sola lettura [`IFontData`](/slides/python-net/it/aspose.slides/ifontdata). |


### Osservazioni

Questa interfaccia è usata come parte delle interfacce [`IBasePortionFormatEffectiveData`](/slides/python-net/it/aspose.slides/ibaseportionformateffectivedata) e [`IFontSchemeEffectiveData`](/slides/python-net/it/aspose.slides.theme/ifontschemeeffectivedata).
