## from_rgb(r, g, b) {#int-int-int}
Crea un colore opaco (alpha è 255) dai valori rosso, verde e blu specificati.

### Restituisce
Il colore creato dai valori specificati.

```python
@staticmethod
def from_rgb(r, g, b):
    ...
```

| Parametro | Tipo | Descrizione |
| :- | :- | :- |
| r | **int** | Il valore del componente rosso. I valori validi sono da 0 a 255. |
| g | **int** | Il valore del componente verde. I valori validi sono da 0 a 255. |
| b | **int** | Il valore del componente blu. I valori validi sono da 0 a 255. |

### Eccezioni
| Eccezione | Descrizione |
| :- | :- |
| **ValueError** | Un valore di componente è inferiore a 0 o superiore a 255. |
