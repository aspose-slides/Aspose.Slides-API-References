## __init__(self, r=0, g=0, b=0, a=255) {#int-int-int-int}
Crea un colore dai valori dei componenti rosso, verde, blu e alfa specificati.

```python
def __init__(self, r=0, g=0, b=0, a=255):
    ...
```

| Parametro | Tipo | Descrizione |
| :- | :- | :- |
| r | **int** | Il valore del componente rosso. I valori validi sono da 0 a 255. |
| g | **int** | Il valore del componente verde. I valori validi sono da 0 a 255. |
| b | **int** | Il valore del componente blu. I valori validi sono da 0 a 255. |
| a | **int** | Il valore del componente alfa. I valori validi sono da 0 a 255. |

### Eccezioni

| Eccezione | Descrizione |
| :- | :- |
| **ValueError** | Un valore del componente è minore di 0 o maggiore di 255. |
| **TypeError** | Un valore del componente non è un numero. |
