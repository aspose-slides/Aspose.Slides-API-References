## SlideShowSettings classe

Rappresenta le impostazioni della presentazione per lo slide show.

Il tipo SlideShowSettings espone i seguenti membri:

| Proprietà | Descrizione |
| :- | :- |
| [`slide_show_type`](/slides/python-net/it/aspose.slides/slideshowsettings/slide_show_type/) | Ottiene o imposta il tipo di slide show. | [`show_narration`](/slides/python-net/it/aspose.slides/slideshowsettings/show_narration/) | Show Narration in Slide Show |
| [`show_animation`](/slides/python-net/it/aspose.slides/slideshowsettings/show_animation/) | Show Animation in Slide Show |
| [`pen_color`](/slides/python-net/it/aspose.slides/slideshowsettings/pen_color/) | Pen Color for Slide Show |
| [`slides`](/slides/python-net/it/aspose.slides/slideshowsettings/slides/) | Slides range |
