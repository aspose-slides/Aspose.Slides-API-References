## LineSketchType enumerazione

Rappresenta il tipo di schizzo o effetto assegnato a una forma.

Il tipo LineSketchType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| NOT_DEFINED | Specifica che l'effetto Sketch di una forma non è definito. |
| NONE | Specifica che una forma non ha alcun effetto Sketch. Questo è equivalente al fatto che questa proprietà sia vuota. |
| CURVED | Specifica che una forma ha l'effetto Curved, che trasforma ogni bordo della forma in una grande e delicata curva. |
| FREEHAND | Specifica che una forma ha l'effetto Freehand, che più si avvicina a una linea disegnata in modo imperfetto. |
| SCRIBBLE | Specifica che una forma ha l'effetto Scribble, che presenta un'oscillazione esagerata come se fosse disegnata volutamente in modo disordinato. |
