## ITab classe

Rappresenta una tabulazione per un testo.

Il tipo ITab espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`position`](/slides/python-net/it/aspose.slides/itab/position/) | Restituisce o imposta la posizione di una tabulazione.<br/>            Assegnare questa proprietà può cambiare l'indice della tabulazione nella collezione e invalidare l'Enumeratore.<br/>            Lettura/Scrittura **float**. |
| [`alignment`](/slides/python-net/it/aspose.slides/itab/alignment/) | Restituisce o imposta lo stile di allineamento di una tabulazione.<br/>            Lettura/Scrittura [`TabAlignment`](/slides/python-net/it/aspose.slides/tabalignment). |
