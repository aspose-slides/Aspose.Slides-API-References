## enumerazione ZoomLayout

Specifica il layout di zoom riepilogativo.

Il tipo ZoomLayout espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| GRID_LAYOUT | Specifica il layout come layout a griglia per un elenco di oggetti. |
| FIXED_LAYOUT | Specifica il layout con posizionamento Zoom definito dall'utente. |
