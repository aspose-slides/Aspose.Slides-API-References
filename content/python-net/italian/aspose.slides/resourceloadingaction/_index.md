## ResourceLoadingAction enumerazione

Specifica la modalità di caricamento delle risorse esterne.

Il tipo ResourceLoadingAction espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| DEFAULT | Aspose.Slides caricherà le risorse esterne come di consueto. |
| SKIP | Aspose.Slides salterà il caricamento della risorsa esterna. Verrà memorizzato solo il collegamento senza dati per un'immagine. |
| USER_PROVIDED | Aspose.Slides utilizzerà l'array di byte fornito dall'utente in **Aspose.Slides.IResourceLoadingArgs.SetData(Syste** come dati dell'immagine. |
