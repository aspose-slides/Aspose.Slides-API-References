## portion_format proprietà
Returns formatting object which contains explicitly set formatting properties of the text portion with no inheritance applied.
            Solo lettura [`IPortionFormat`](/slides/python-net/it/aspose.slides/iportionformat).

### Osservazioni

L'oggetto di formattazione contiene i parametri di formattazione definiti solo per la porzione corrente, i dati ereditati non vengono applicati.

Per ottenere i valori effettivi, inclusi quelli ereditati, utilizzare il metodo [`IPortionFormat.get_effective`](/slides/python-net/it/aspose.slides/iportionformat/get_effective).
