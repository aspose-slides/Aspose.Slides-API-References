## is_text_box proprietà
Specifica se la forma è una casella di testo.


### Osservazioni

Se la forma non è specificata come casella di testo, non significa che non possa avere del testo allegato. Una casella di testo è semplicemente una forma specializzata con proprietà specifiche.
