## proprietà di rotazione
Restituisce o imposta il numero di gradi con cui la forma specificata è ruotata attorno
            l'asse z. Un valore positivo indica rotazione in senso orario; un valore negativo
            indica rotazione in senso antiorario.
            Lettura/scrittura **float**.


### Osservazioni

Il valore restituito è sempre definito (non è float.NaN).
            Il valore assegnato deve essere definito (non è float.NaN). È possibile impostare valori non definiti per le proprietà dell'istanza RawFrame.
