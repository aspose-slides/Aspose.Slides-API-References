## SlideSizeScaleType enumerazione

Rappresenta il tipo di scala del contenuto della diapositiva.

Il tipo SlideSizeScaleType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| DO_NOT_SCALE | Non scalare. |
| ENSURE_FIT | Scala per garantire l'adattamento. |
| MAXIMIZE | Massimizza la dimensione del contenuto. |
