## IBulletFormatEffectiveData classe

Oggetto immutabile che contiene le proprietà di formattazione effective dei bullet di un paragrafo.

Il tipo IBulletFormatEffectiveData espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`type`](/slides/python-net/it/aspose.slides/ibulletformateffectivedata/type/) | Restituisce il tipo di bullet di un paragrafo.<br/>            Solo lettura [`BulletType`](/slides/python-net/it/aspose.slides/bullettype). |
| [`char`](/slides/python-net/it/aspose.slides/ibulletformateffectivedata/char/) | Restituisce il carattere di bullet di un paragrafo.<br/>            Solo lettura **System.Char**. |
| [`actual_bullet_value`](/slides/python-net/it/aspose.slides/ibulletformateffectivedata/actual_bullet_value/) | Restituisce il valore effettivo del bullet per il paragrafo padre.<br/>            Solo lettura **str**. |
| [`font`](/slides/python-net/it/aspose.slides/ibulletformateffectivedata/font/) | Restituisce il font del bullet di un paragrafo.<br/>            Solo lettura [`IFontData`](/slides/python-net/it/aspose.slides/ifontdata). |
| [`height`](/slides/python-net/it/aspose.slides/ibulletformateffectivedata/height/) | Restituisce l'altezza del bullet di un paragrafo.<br/>            Solo lettura **float**. |
| [`numbered_bullet_start_with`](/slides/python-net/it/aspose.slides/ibulletformateffectivedata/numbered_bullet_start_with/) | Restituisce il primo numero utilizzato per il gruppo di bullet numerati.<br/>            Solo lettura **int**. |
| [`numbered_bullet_style`](/slides/python-net/it/aspose.slides/ibulletformateffectivedata/numbered_bullet_style/) | Restituisce lo stile di un bullet numerato.<br/>            Solo lettura [`NumberedBulletStyle`](/slides/python-net/it/aspose.slides/numberedbulletstyle). |
| [`is_bullet_hard_color`](/slides/python-net/it/aspose.slides/ibulletformateffectivedata/is_bullet_hard_color/) | Determina se il bullet ha un colore proprio o lo eredita dalla prima porzione del paragrafo.<br/>            Restituisce **true**  se il bullet ha un colore proprio e **false**  se il bullet eredita il colore dalla prima porzione del paragrafo.<br/>            Solo lettura **bool**. |
| [`is_bullet_hard_font`](/slides/python-net/it/aspose.slides/ibulletformateffectivedata/is_bullet_hard_font/) | Determina se il bullet ha un font proprio o lo eredita dalla prima porzione del paragrafo.<br/>            Restituisce **true**  se il bullet ha un font proprio e **true**  se il bullet eredita il font dalla prima porzione del paragrafo.<br/>            Solo lettura **bool**. |
| [`picture`](/slides/python-net/it/aspose.slides/ibulletformateffectivedata/picture/) | Restituisce l'immagine usata come bullet nel paragrafo.<br/>            Solo lettura [`IPictureEffectiveData`](/slides/python-net/it/aspose.slides/ipictureeffectivedata). |
| [`fill_format`](/slides/python-net/it/aspose.slides/ibulletformateffectivedata/fill_format/) | Restituisce il formato di riempimento del bullet di un paragrafo.<br/>            Solo lettura [`IFillFormatEffectiveData`](/slides/python-net/it/aspose.slides/ifillformateffectivedata). |

### Osservazioni

Questa interfaccia è utilizzata come parte di [`IParagraphFormatEffectiveData`](/slides/python-net/it/aspose.slides/iparagraphformateffectivedata).
