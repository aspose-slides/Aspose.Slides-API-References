## SlideLayoutType enumerazione

Rappresenta il tipo di layout della diapositiva.

Il tipo SlideLayoutType espone i seguenti membri:

## Campi

| Field | Description |
| :- | :- |
| CUSTOM | Personalizzato |
| TITLE | Titolo |
| TEXT | Testo |
| TWO_COLUMN_TEXT | Testo a due colonne |
| TABLE | Tabella |
| TEXT_AND_CHART | Testo e grafico |
| CHART_AND_TEXT | Grafico e testo |
| DIAGRAM | Diagramma |
| CHART | Grafico |
| TEXT_AND_CLIP_ART | Testo e clip art |
| CLIP_ART_AND_TEXT | Clip art e testo |
| TITLE_ONLY | Solo titolo |
| BLANK | Vuoto |
| TEXT_AND_OBJECT | Testo e oggetto |
| OBJECT_AND_TEXT | Oggetto e testo |
| OBJECT | Oggetto |
| TITLE_AND_OBJECT | Titolo e oggetto |
| TEXT_AND_MEDIA | Testo e media |
| MEDIA_AND_TEXT | Media e testo |
| OBJECT_OVER_TEXT | Oggetto sopra testo |
| TEXT_OVER_OBJECT | Testo sopra oggetto |
| TEXT_AND_TWO_OBJECTS | Testo e due oggetti |
| TWO_OBJECTS_AND_TEXT | Due oggetti e testo |
| TWO_OBJECTS_OVER_TEXT | Due oggetti sopra testo |
| FOUR_OBJECTS | Quattro oggetti |
| VERTICAL_TEXT | Testo verticale |
| CLIP_ART_AND_VERTICAL_TEXT | Clip art e testo verticale |
| VERTICAL_TITLE_AND_TEXT | Titolo verticale e testo |
| VERTICAL_TITLE_AND_TEXT_OVER_CHART | Titolo verticale e testo sopra grafico |
| TWO_OBJECTS | Due oggetti |
| OBJECT_AND_TWO_OBJECT | Oggetto e due oggetti |
| TWO_OBJECTS_AND_OBJECT | Due oggetti e oggetto |
| SECTION_HEADER | Intestazione sezione |
| TWO_TEXT_AND_TWO_OBJECTS | Due testi e due oggetti |
| TITLE_OBJECT_AND_CAPTION | Titolo, oggetto e didascalia |
| PICTURE_AND_CAPTION | Immagine e didascalia |
