## is_bullet_hard_color proprietà
Determina se il bullet ha un colore proprio o lo eredita dalla prima porzione del paragrafo.
            **NullableBool.True**  if bullet has own color and **NullableBool.False**  if bullet
            inherits color from the first portion in the paragraph.
            Lettura/Scrittura [`NullableBool`](/slides/python-net/it/aspose.slides/nullablebool).
