## IPictureFillFormatEffectiveData classe

Oggetto immutabile che contiene le proprietà del riempimento dell'immagine.

Il tipo IPictureFillFormatEffectiveData espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`dpi`](/slides/python-net/it/aspose.slides/ipicturefillformateffectivedata/dpi/) | Restituisce i dpi utilizzati per riempire un'immagine.<br/>            Sola lettura **int**. |
| [`picture_fill_mode`](/slides/python-net/it/aspose.slides/ipicturefillformateffectivedata/picture_fill_mode/) | Restituisce la modalità di riempimento immagine.<br/>            Sola lettura [`PictureFillMode`](/slides/python-net/it/aspose.slides/picturefillmode). |
| [`picture`](/slides/python-net/it/aspose.slides/ipicturefillformateffectivedata/picture/) | Restituisce l'immagine.<br/>            Sola lettura [`IPictureEffectiveData`](/slides/python-net/it/aspose.slides/ipictureeffectivedata). |
| [`crop_left`](/slides/python-net/it/aspose.slides/ipicturefillformateffectivedata/crop_left/) | Restituisce il numero di percentuali della larghezza reale dell'immagine che viene ritagliata a sinistra dell'immagine.<br/>            Sola lettura **float**. |
| [`crop_top`](/slides/python-net/it/aspose.slides/ipicturefillformateffectivedata/crop_top/) | Restituisce il numero di percentuali dell'altezza reale dell'immagine che viene ritagliata in alto dell'immagine.<br/>            Sola lettura **float**. |
| [`crop_right`](/slides/python-net/it/aspose.slides/ipicturefillformateffectivedata/crop_right/) | Restituisce il numero di percentuali della larghezza reale dell'immagine che viene ritagliata a destra dell'immagine.<br/>            Sola lettura **float**. |
| [`crop_bottom`](/slides/python-net/it/aspose.slides/ipicturefillformateffectivedata/crop_bottom/) | Restituisce il numero di percentuali dell'altezza reale dell'immagine che viene ritagliata in basso dell'immagine.<br/>            Sola lettura **float**. |
