## AdjustValue classe

Rappresenta il valore di aggiustamento di una forma geometrica.
            Questi valori influenzano la forma della shape.

Il tipo AdjustValue espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`raw_value`](/slides/python-net/it/aspose.slides/adjustvalue/raw_value/) | Restituisce o imposta il valore di aggiustamento "as is".<br/> Lettura/scrittura **int**. |
| [`angle_value`](/slides/python-net/it/aspose.slides/adjustvalue/angle_value/) | Restituisce o imposta il valore, interpretandolo come angolo in gradi.<br/> Lettura/scrittura **float**. |
| [`name`](/slides/python-net/it/aspose.slides/adjustvalue/name/) | Restituisce il nome di questo valore di aggiustamento.<br/> Solo lettura **str**. |
| [`type`](/slides/python-net/it/aspose.slides/adjustvalue/type/) | Restituisce il tipo di aggiustamento della shape.<br/> Solo lettura [`ShapeAdjustmentType`](/slides/python-net/it/aspose.slides/shapeadjustmenttype). |
