## IMasterLayoutSlideCollection classe

Rappresenta una collezione di tutte le diapositive di layout dello slide master definito.
Estende l'interfaccia ILayoutSlideCollection con metodi per aggiungere/inserire/rimuovere/clonare diapositive di layout nel contesto delle collezioni individuali delle diapositive di layout del master.
