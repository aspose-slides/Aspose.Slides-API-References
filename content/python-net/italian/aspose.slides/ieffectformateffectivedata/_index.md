## IEffectFormatEffectiveData classe

Oggetto immutabile che contiene le proprietà di formattazione degli effetti effettivi.

Il tipo IEffectFormatEffectiveData espone i seguenti membri:

## Proprietà

| Property | Description |
| :- | :- |
| [`is_no_effects`](/slides/python-net/it/aspose.slides/ieffectformateffectivedata/is_no_effects/) | Restituisce true se tutti gli effetti sono disabilitati (come appena creato, oggetto EffectFormat predefinito).<br/>            Solo lettura **bool**. |
| [`blur_effect`](/slides/python-net/it/aspose.slides/ieffectformateffectivedata/blur_effect/) | Effetto sfocatura.<br/>            Solo lettura [`IBlurEffectiveData`](/slides/python-net/it/aspose.slides.effects/iblureffectivedata). |
| [`fill_overlay_effect`](/slides/python-net/it/aspose.slides/ieffectformateffectivedata/fill_overlay_effect/) | Effetto di sovrapposizione riempimento.<br/>            Solo lettura [`IFillOverlayEffectiveData`](/slides/python-net/it/aspose.slides.effects/ifilloverlayeffectivedata). |
| [`glow_effect`](/slides/python-net/it/aspose.slides/ieffectformateffectivedata/glow_effect/) | Effetto bagliore.<br/>            Solo lettura [`IGlowEffectiveData`](/slides/python-net/it/aspose.slides.effects/igloweffectivedata). |
| [`inner_shadow_effect`](/slides/python-net/it/aspose.slides/ieffectformateffectivedata/inner_shadow_effect/) | Ombra interna.<br/>            Solo lettura [`IInnerShadowEffectiveData`](/slides/python-net/it/aspose.slides.effects/iinnershadoweffectivedata). |
| [`outer_shadow_effect`](/slides/python-net/it/aspose.slides/ieffectformateffectivedata/outer_shadow_effect/) | Ombra esterna.<br/>            Solo lettura [`IOuterShadowEffectiveData`](/slides/python-net/it/aspose.slides.effects/ioutershadoweffectivedata). |
| [`preset_shadow_effect`](/slides/python-net/it/aspose.slides/ieffectformateffectivedata/preset_shadow_effect/) | Ombra predefinita.<br/>            Solo lettura [`IPresetShadowEffectiveData`](/slides/python-net/it/aspose.slides.effects/ipresetshadoweffectivedata). |
| [`reflection_effect`](/slides/python-net/it/aspose.slides/ieffectformateffectivedata/reflection_effect/) | Riflesso. <br/>            Solo lettura [`IReflectionEffectiveData`](/slides/python-net/it/aspose.slides.effects/ireflectioneffectivedata). |
| [`soft_edge_effect`](/slides/python-net/it/aspose.slides/ieffectformateffectivedata/soft_edge_effect/) | Bordo morbido.<br/>            Solo lettura [`ISoftEdgeEffectiveData`](/slides/python-net/it/aspose.slides.effects/isoftedgeeffectivedata). |

### Note

Questa interfaccia è utilizzata insieme all'interfaccia [`IEffectFormat`](/slides/python-net/it/aspose.slides/ieffectformat) per restituire i valori di formattazione effettiva con l'ereditarietà applicata.
