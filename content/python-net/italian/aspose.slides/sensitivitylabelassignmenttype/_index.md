## SensitivityLabelAssignmentType enumerazione

Rappresenta il metodo di assegnazione per l'etichetta di sensibilità.

Il tipo SensitivityLabelAssignmentType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| STANDARD | Utilizzare per qualsiasi etichetta di sensibilità che non è stata applicata direttamente dall'utente. <br/>            Questo include tutte le etichette predefinite, le etichette applicate automaticamente. |
| PRIVILEGED | Utilizzare per qualsiasi etichetta di sensibilità che sia stata applicata direttamente dall'utente. <br/>            Questo include tutte le etichette di sensibilità applicate manualmente così come quelle raccomandate<br/>            o obbligatorie, oppure qualsiasi funzione in cui l'utente decide quale etichetta di sensibilità applicare. |
