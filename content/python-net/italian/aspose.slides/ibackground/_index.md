## IBackground classe

Rappresenta lo sfondo di una diapositiva.

Il tipo IBackground espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`type`](/slides/python-net/it/aspose.slides/ibackground/type/) | Restituisce un tipo di riempimento dello sfondo.<br/>            Lettura/scrittura [`BackgroundType`](/slides/python-net/it/aspose.slides/backgroundtype). |
| [`fill_format`](/slides/python-net/it/aspose.slides/ibackground/fill_format/) | Restituisce un FillFormat per il riempimento BackgroundType.OwnBackground.<br/>            Sola lettura [`IFillFormat`](/slides/python-net/it/aspose.slides/ifillformat). |
| [`effect_format`](/slides/python-net/it/aspose.slides/ibackground/effect_format/) | Restituisce un EffectFormat per il riempimento BackgroundType.OwnBackground.<br/>            Sola lettura [`IEffectFormat`](/slides/python-net/it/aspose.slides/ieffectformat). |
| [`style_color`](/slides/python-net/it/aspose.slides/ibackground/style_color/) | Restituisce un ColorFormat per un riempimento BackgroundType.Themed.<br/>            Sola lettura [`IColorFormat`](/slides/python-net/it/aspose.slides/icolorformat). |
| [`style_index`](/slides/python-net/it/aspose.slides/ibackground/style_index/) | Restituisce un indice del riempimento BackgroundType.Themed nella raccolta del tema di sfondo.<br/>            0 indica nessun riempimento.<br/>            1..999 - indice.<br/>            Lettura/scrittura **int**. |
