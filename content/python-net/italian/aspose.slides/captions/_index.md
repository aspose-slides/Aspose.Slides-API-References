## Captions classe

Rappresenta i sottotitoli chiusi WebVTT.

Il tipo Captions espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`caption_id`](/slides/python-net/it/aspose.slides/captions/caption_id/) | Restituisce l'identificatore globale univoco (GUID) dei sottotitoli chiusi.<br/>            Sola lettura **System.Guid**. |
| [`label`](/slides/python-net/it/aspose.slides/captions/label/) | Restituisce o imposta l'etichetta dei sottotitoli chiusi.<br/>            Lettura/scrittura **str**. |
| [`binary_data`](/slides/python-net/it/aspose.slides/captions/binary_data/) | Restituisce i dati binari dei sottotitoli chiusi.<br/>            Sola lettura **int**[]. |
| [`data_as_string`](/slides/python-net/it/aspose.slides/captions/data_as_string/) | Restituisce i dati dei sottotitoli chiusi come stringa codificata UTF-8<br/>            Sola lettura **str**. |
