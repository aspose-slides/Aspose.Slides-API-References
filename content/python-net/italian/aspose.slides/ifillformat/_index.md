## IFillFormat classe

Rappresenta le opzioni di formattazione di riempimento.

Il tipo IFillFormat espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`fill_type`](/slides/python-net/it/aspose.slides/ifillformat/fill_type/) | Restituisce o imposta il tipo di riempimento.<br/>            Lettura/Scrittura [`FillType`](/slides/python-net/it/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/it/aspose.slides/ifillformat/solid_fill_color/) | Restituisce il colore di riempimento.<br/>            Sola lettura [`IColorFormat`](/slides/python-net/it/aspose.slides/icolorformat). |
| [`gradient_format`](/slides/python-net/it/aspose.slides/ifillformat/gradient_format/) | Restituisce il formato di riempimento a gradiente.<br/>            Sola lettura [`IGradientFormat`](/slides/python-net/it/aspose.slides/igradientformat). |
| [`pattern_format`](/slides/python-net/it/aspose.slides/ifillformat/pattern_format/) | Restituisce il formato di riempimento a motivo.<br/>            Sola lettura [`IPatternFormat`](/slides/python-net/it/aspose.slides/ipatternformat). |
| [`picture_fill_format`](/slides/python-net/it/aspose.slides/ifillformat/picture_fill_format/) | Restituisce il formato di riempimento immagine.<br/>            Sola lettura [`IPictureFillFormat`](/slides/python-net/it/aspose.slides/ipicturefillformat). |
| [`rotate_with_shape`](/slides/python-net/it/aspose.slides/ifillformat/rotate_with_shape/) | Determina se il riempimento deve essere ruotato con la forma.<br/>            Lettura/Scrittura [`NullableBool`](/slides/python-net/it/aspose.slides/nullablebool). |
