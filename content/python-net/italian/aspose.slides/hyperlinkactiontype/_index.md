## HyperlinkActionType enumerazione

Rappresenta un tipo di azione di collegamento ipertestuale.

Il tipo HyperlinkActionType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| UNKNOWN | Tipo di azione non riconosciuto. |
| NO_ACTION | Nessuna azione. |
| HYPERLINK | Collegamento ipertestuale usuale. |
| JUMP_FIRST_SLIDE | Vai alla prima diapositiva della presentazione. |
| JUMP_PREVIOUS_SLIDE | Vai alla diapositiva precedente. |
| JUMP_NEXT_SLIDE | Vai alla diapositiva successiva. |
| JUMP_LAST_SLIDE | Vai all'ultima diapositiva della presentazione. |
| JUMP_END_SHOW | Vai alla fine della presentazione. |
| JUMP_LAST_VIEWED_SLIDE | Vai all'ultima diapositiva visualizzata. |
| JUMP_SPECIFIC_SLIDE | Vai alla diapositiva specifica, indicata dalla proprietà [`IHyperlink.target_slide`](/slides/python-net/it/aspose.slides/ihyperlink/target_slide). |
| START_CUSTOM_SLIDE_SHOW | Avvia presentazione personalizzata. |
| OPEN_FILE | Apri il file di riferimento. |
| OPEN_PRESENTATION | Apri la presentazione di riferimento. |
| START_STOP_MEDIA | Avvia/ferma la riproduzione del file multimediale. |
| START_MACRO | Avvia l'esecuzione dello script macro. |
| START_PROGRAM | Avvia il programma. |
