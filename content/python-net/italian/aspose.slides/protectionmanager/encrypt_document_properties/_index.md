## encrypt_document_properties proprietà
Questa proprietà ha senso, se la presentazione è protetta da password.
Se true, le proprietà del documento sono cifrate nel file della presentazione.
Se false, le proprietà del documento sono pubbliche mentre la presentazione è cifrata.
Lettura/Scrittura **bool**.
