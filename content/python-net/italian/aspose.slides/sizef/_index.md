## SizeF classe

Memorizza una coppia ordinata di numeri a virgola mobile, tipicamente la larghezza e l'altezza di un rettangolo. Compatibile con .NET `System.Drawing.SizeF`.

Il tipo SizeF espone i seguenti membri:

## Costruttori

| Costruttore | Descrizione |
| :- | :- |
| [`__init__(self, width=0.0, height=0.0)`](/slides/python-net/it/aspose.slides/sizef/__init__/#float-float) | Crea una dimensione con la larghezza e l'altezza specificate. |

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`width`](/slides/python-net/it/aspose.slides/sizef/width/) | Restituisce la componente orizzontale di questa dimensione.<br/>            Sola lettura **float**. |
| [`height`](/slides/python-net/it/aspose.slides/sizef/height/) | Restituisce la componente verticale di questa dimensione.<br/>            Sola lettura **float**. |


### Osservazioni

Le dimensioni vengono confrontate tramite le loro componenti con `==` e possono essere utilizzate come chiavi di dizionario o elementi di un set.
