## FontsLoader classe

Classe per caricare i caratteri personalizzati definiti dall'utente.
            Deve essere usata prima di creare qualsiasi oggetto di presentazione.

Il tipo FontsLoader espone i seguenti membri:

## Metodi

| Metodo | Descrizione |
| :- | :- |
| [`load_external_fonts(directories)`](/slides/python-net/it/aspose.slides/fontsloader/load_external_fonts/#liststr) | Aggiunge cartelle aggiuntive per cercare i caratteri. |
| [`load_external_font(data)`](/slides/python-net/it/aspose.slides/fontsloader/load_external_font/#bytes) | Aggiunge un carattere dai dati binari |
| [`get_font_folders()`](/slides/python-net/it/aspose.slides/fontsloader/get_font_folders/#) | Ottiene le cartelle dei caratteri. Restituisce le cartelle aggiunte con LoadExternalFonts method così come le cartelle dei caratteri di sistema |
| [`clear_cache()`](/slides/python-net/it/aspose.slides/fontsloader/clear_cache/#) | Rilascia tutti i caratteri personalizzati definiti dall'utente |
