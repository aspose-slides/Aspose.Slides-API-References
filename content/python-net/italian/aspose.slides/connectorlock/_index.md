## ConnectorLock classe

Determina quali operazioni sono disabilitate sul genitore Connector.

**Eredità:**[`ConnectorLock`](/slides/python-net/it/aspose.slides/connectorlock) → [`BaseShapeLock`](/slides/python-net/it/aspose.slides/baseshapelock)

Il tipo ConnectorLock espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`no_locks`](/slides/python-net/it/aspose.slides/connectorlock/no_locks/) | Restituisce true se tutti i lock-flags sono disabilitati.<br/>            Solo lettura **bool**. |
| [`grouping_locked`](/slides/python-net/it/aspose.slides/connectorlock/grouping_locked/) | Determina se l'aggiunta di questa forma a un gruppo è proibita.<br/>            Lettura/scrittura **bool**. |
| [`select_locked`](/slides/python-net/it/aspose.slides/connectorlock/select_locked/) | Determina se la selezione di questa forma è proibita.<br/>            Lettura/scrittura **bool**. |
| [`rotate_locked`](/slides/python-net/it/aspose.slides/connectorlock/rotate_locked/) | Determina se la modifica dell'angolo di rotazione di questa forma è proibita.<br/>            Lettura/scrittura **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/it/aspose.slides/connectorlock/aspect_ratio_locked/) | Determina se una forma deve mantenere le proporzioni durante il ridimensionamento.<br/>            Lettura/scrittura **bool**. |
| [`position_move`](/slides/python-net/it/aspose.slides/connectorlock/position_move/) | Determina se lo spostamento di questa forma è proibito.<br/>            Lettura/scrittura **bool**. |
| [`size_locked`](/slides/python-net/it/aspose.slides/connectorlock/size_locked/) | Determina se il ridimensionamento di questa forma è proibito.<br/>            Lettura/scrittura **bool**. |
| [`edit_points_locked`](/slides/python-net/it/aspose.slides/connectorlock/edit_points_locked/) | Determina se la modifica diretta del contorno di questa forma è proibita.<br/>            Lettura/scrittura **bool**. |
| [`adjust_handles_locked`](/slides/python-net/it/aspose.slides/connectorlock/adjust_handles_locked/) | Determina se la modifica dei valori di aggiustamento è proibita.<br/>            Lettura/scrittura **bool**. |
| [`arrowheads_locked`](/slides/python-net/it/aspose.slides/connectorlock/arrowheads_locked/) | Determina se la modifica delle punte delle frecce è proibita.<br/>            Lettura/scrittura **bool**. |
| [`shape_type_locked`](/slides/python-net/it/aspose.slides/connectorlock/shape_type_locked/) | Determina se la modifica del tipo di forma è proibita.<br/>            Lettura/scrittura **bool**. |
