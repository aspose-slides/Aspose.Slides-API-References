## NormalViewProperties classe

Rappresenta le proprietà della visualizzazione normale. La visualizzazione normale è composta da
            tre regioni di contenuto: la diapositiva stessa, una regione di contenuto laterale e una regione di contenuto inferiore.

Il tipo NormalViewProperties espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`show_outline_icons`](/slides/python-net/it/aspose.slides/normalviewproperties/show_outline_icons/) | Specifica se l'applicazione deve mostrare le icone quando visualizza contenuti di outline in qualsiasi<br/>            delle regioni di contenuto della modalità visualizzazione normale.<br/>            Lettura/scrittura **bool**. |
| [`snap_vertical_splitter`](/slides/python-net/it/aspose.slides/normalviewproperties/snap_vertical_splitter/) | Specifica se il divisore verticale deve scattare a uno stato minimizzato quando la regione laterale è sufficientemente piccola.<br/>            Lettura/scrittura **bool**. |
| [`vertical_bar_state`](/slides/python-net/it/aspose.slides/normalviewproperties/vertical_bar_state/) | Specifica lo stato in cui dovrebbe essere mostrata la barra di divisione verticale. <br/>            Una barra di divisione verticale separa la diapositiva dalla regione di contenuto laterale. |
| [`horizontal_bar_state`](/slides/python-net/it/aspose.slides/normalviewproperties/horizontal_bar_state/) | Specifica lo stato in cui dovrebbe essere mostrata la barra di divisione orizzontale.<br/>            Una barra di divisione orizzontale separa la diapositiva dalla regione di contenuto sotto la diapositiva. |
| [`prefer_single_view`](/slides/python-net/it/aspose.slides/normalviewproperties/prefer_single_view/) | Specifica se l'utente preferisce vedere una singola regione di contenuto a finestra intera rispetto alla<br/>            visualizzazione normale standard con tre regioni di contenuto. Se abilitato, l'applicazione può scegliere<br/>            di visualizzare una delle regioni di contenuto nell'intera finestra.<br/>            Lettura/scrittura **bool**. |
| [`restored_left`](/slides/python-net/it/aspose.slides/normalviewproperties/restored_left/) | Questo elemento specifica le dimensioni della regione di contenuto laterale della visualizzazione normale, quando la regione è di una dimensione ripristinata variabile (né minimizzata né massimizzata).<br/>            Sola lettura [`INormalViewRestoredProperties`](/slides/python-net/it/aspose.slides/inormalviewrestoredproperties). |
| [`restored_top`](/slides/python-net/it/aspose.slides/normalviewproperties/restored_top/) | Questo elemento specifica le dimensioni della regione superiore della diapositiva nella visualizzazione normale, quando la regione è di una dimensione ripristinata variabile (né minimizzata né massimizzata).<br/>            Sola lettura [`INormalViewRestoredProperties`](/slides/python-net/it/aspose.slides/inormalviewrestoredproperties). |
