## IFillFormatEffectiveData classe

Oggetto immutabile che contiene le proprietà di formattazione di riempimento effettive.

Il tipo IFillFormatEffectiveData espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`fill_type`](/slides/python-net/it/aspose.slides/ifillformateffectivedata/fill_type/) | Restituisce il tipo di riempimento.<br/>            Solo lettura [`FillType`](/slides/python-net/it/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/it/aspose.slides/ifillformateffectivedata/solid_fill_color/) | Restituisce il colore di riempimento.<br/>            Solo lettura [`Color`](/slides/python-net/it/aspose.slides/color). |
| [`solid_fill_scheme_color`](/slides/python-net/it/aspose.slides/ifillformateffectivedata/solid_fill_scheme_color/) | Ottiene il colore di riempimento definito da uno schema di colori.<br/>            Il valore [`SchemeColor.NOT_DEFINED`](/slides/python-net/it/aspose.slides/schemecolor/NOT_DEFINED) indica che il [`IFillFormatEffectiveData.solid_fill_color`](/slides/python-net/it/aspose.slides/ifillformateffectivedata/solid_fill_color) <br/>            non è un colore di schema.<br/>            Solo lettura [`SchemeColor`](/slides/python-net/it/aspose.slides/schemecolor). |
| [`gradient_format`](/slides/python-net/it/aspose.slides/ifillformateffectivedata/gradient_format/) | Restituisce il formato di riempimento a gradiente.<br/>            Solo lettura [`IGradientFormatEffectiveData`](/slides/python-net/it/aspose.slides/igradientformateffectivedata). |
| [`pattern_format`](/slides/python-net/it/aspose.slides/ifillformateffectivedata/pattern_format/) | Restituisce il formato di riempimento a pattern.<br/>            Solo lettura [`IPatternFormatEffectiveData`](/slides/python-net/it/aspose.slides/ipatternformateffectivedata). |
| [`picture_fill_format`](/slides/python-net/it/aspose.slides/ifillformateffectivedata/picture_fill_format/) | Restituisce il formato di riempimento immagine.<br/>            Solo lettura [`IPictureFillFormatEffectiveData`](/slides/python-net/it/aspose.slides/ipicturefillformateffectivedata). |
| [`rotate_with_shape`](/slides/python-net/it/aspose.slides/ifillformateffectivedata/rotate_with_shape/) | Determina se il riempimento debba essere ruotato con la forma.<br/>            Solo lettura **bool**. |

### Osservazioni

Questa interfaccia è utilizzata insieme all'interfaccia [`IFillFormat`](/slides/python-net/it/aspose.slides/ifillformat) per restituire i valori di formattazione effettivi con ereditarietà applicata.
