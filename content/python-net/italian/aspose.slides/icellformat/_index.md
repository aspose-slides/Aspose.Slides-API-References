## ICellFormat classe

Rappresenta il formato di una cella di tabella.

Il tipo ICellFormat espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`fill_format`](/slides/python-net/it/aspose.slides/icellformat/fill_format/) | Restituisce un oggetto delle proprietà di riempimento della cella.<br/>            Solo lettura [`IFillFormat`](/slides/python-net/it/aspose.slides/ifillformat). |
| [`border_left`](/slides/python-net/it/aspose.slides/icellformat/border_left/) | Restituisce un oggetto delle proprietà della linea del bordo sinistro.<br/>            Solo lettura [`ILineFormat`](/slides/python-net/it/aspose.slides/ilineformat). |
| [`border_top`](/slides/python-net/it/aspose.slides/icellformat/border_top/) | Restituisce un oggetto delle proprietà della linea del bordo superiore.<br/>            Solo lettura [`ILineFormat`](/slides/python-net/it/aspose.slides/ilineformat). |
| [`border_right`](/slides/python-net/it/aspose.slides/icellformat/border_right/) | Restituisce un oggetto delle proprietà della linea del bordo destro.<br/>            Solo lettura [`ILineFormat`](/slides/python-net/it/aspose.slides/ilineformat). |
| [`border_bottom`](/slides/python-net/it/aspose.slides/icellformat/border_bottom/) | Restituisce un oggetto delle proprietà della linea del bordo inferiore.<br/>            Solo lettura [`ILineFormat`](/slides/python-net/it/aspose.slides/ilineformat). |
| [`border_diagonal_down`](/slides/python-net/it/aspose.slides/icellformat/border_diagonal_down/) | Restituisce un oggetto delle proprietà della linea diagonale da alto sinistra a basso destra.<br/>            Solo lettura [`ILineFormat`](/slides/python-net/it/aspose.slides/ilineformat). |
| [`border_diagonal_up`](/slides/python-net/it/aspose.slides/icellformat/border_diagonal_up/) | Restituisce un oggetto delle proprietà della linea diagonale da basso sinistra a alto destra.<br/>            Solo lettura [`ILineFormat`](/slides/python-net/it/aspose.slides/ilineformat). |
| [`transparency`](/slides/python-net/it/aspose.slides/icellformat/transparency/) | Ottiene o imposta la trasparenza del colore di riempimento.<br/>            Lettura/scrittura **float**. |

## Metodi

| Metodo | Descrizione |
| :- | :- |
