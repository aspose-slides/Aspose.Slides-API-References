## IAnimationTimeLine classe

Rappresenta la timeline dell'animazione.

Il tipo IAnimationTimeLine espone i seguenti membri:

## Proprietà

| Property | Descrizione |
| :- | :- |
| [`interactive_sequences`](/slides/python-net/it/aspose.slides/ianimationtimeline/interactive_sequences/) | Restituisce la collezione di sequenze interattive.<br/>            Questa sequenza può contenere solo effetti di "clic sulla forma" con forma di destinazione specificata.<br/>            Solo lettura [`ISequenceCollection`](/slides/python-net/it/aspose.slides.animation/isequencecollection). |
| [`main_sequence`](/slides/python-net/it/aspose.slides/ianimationtimeline/main_sequence/) | Restituisce la sequenza principale che può contenere solo la collezione di effetti principali.<br/>            Solo lettura [`ISequence`](/slides/python-net/it/aspose.slides.animation/isequence). |
| [`text_animation_collection`](/slides/python-net/it/aspose.slides/ianimationtimeline/text_animation_collection/) | Restituisce la collezione di animazioni di testo.<br/>            Solo lettura [`ITextAnimationCollection`](/slides/python-net/it/aspose.slides.animation/itextanimationcollection). |
