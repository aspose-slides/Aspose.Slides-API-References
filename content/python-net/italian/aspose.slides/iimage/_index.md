## IImage classe

Rappresenta un'immagine raster o vettoriale.

Il tipo IImage espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`size`](/slides/python-net/it/aspose.slides/iimage/size/) | Restituisce la dimensione dell'immagine. |
| [`width`](/slides/python-net/it/aspose.slides/iimage/width/) | Restituisce la larghezza dell'immagine in pixel. |
| [`height`](/slides/python-net/it/aspose.slides/iimage/height/) | Restituisce l'altezza dell'immagine in pixel. |

## Metodi

| Metodo | Descrizione |
| :- | :- |
| [`save(self, filename)`](/slides/python-net/it/aspose.slides/iimage/save/#str) | Salva l'immagine su un file. |
| [`save(self, filename, format)`](/slides/python-net/it/aspose.slides/iimage/save/#str-imageformat) | Salva l'immagine su un file nel formato specificato. |
| [`save(self, stream, format)`](/slides/python-net/it/aspose.slides/iimage/save/#iorawiobase-imageformat) | Salva l'immagine su uno stream nel formato specificato. |
| [`save(self, filename, format, quality)`](/slides/python-net/it/aspose.slides/iimage/save/#str-imageformat-int) | Salva l'immagine su un file nel formato e nella qualità specificati. |
| [`save(self, stream, format, quality)`](/slides/python-net/it/aspose.slides/iimage/save/#iorawiobase-imageformat-int) | Salva l'immagine su uno stream nel formato e nella qualità specificati. |


### Osservazioni

Questa interfaccia fornisce un'astrazione comune per la gestione sia delle immagini raster che vettoriali.  
Implementazioni possono variare a seconda del tipo di immagine sottostante.
