## ITextStyleEffectiveData classe

Oggetto immutabile che contiene le proprietà effettive dello stile del testo.

Il tipo ITextStyleEffectiveData espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`default_paragraph_format`](/slides/python-net/it/aspose.slides/itextstyleeffectivedata/default_paragraph_format/) | Restituisce le proprietà del paragrafo predefinite effettive.<br/>            Sola lettura [`IParagraphFormatEffectiveData`](/slides/python-net/it/aspose.slides/iparagraphformateffectivedata). |

## Metodi

| Metodo | Descrizione |
| :- | :- |
| [`get_level(self, index)`](/slides/python-net/it/aspose.slides/itextstyleeffectivedata/get_level/#int) | Restituisce il livello dello stile effettivo. |


### Osservazioni

Questa interfaccia è usata insieme all'interfaccia [`ITextStyle`](/slides/python-net/it/aspose.slides/itextstyle) per restituire i valori di formattazione effettivi con ereditarietà applicata.
