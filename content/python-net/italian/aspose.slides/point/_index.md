## Classe Point

Rappresenta una coppia ordinata di coordinate intere x e y che definisce un punto in un piano bidimensionale. Compatibile con .NET `System.Drawing.Point`.

Il tipo Point espone i seguenti membri:

## Costruttori

| Costruttore | Descrizione |
| :- | :- |
| [`__init__(self, x=0, y=0)`](/slides/python-net/it/aspose.slides/point/__init__/#int-int) | Crea un punto con le coordinate specificate. I valori float vengono troncati a interi. |

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`x`](/slides/python-net/it/aspose.slides/point/x/) | Ottiene o imposta la coordinata x di questo punto.<br/>            Lettura/Scrittura **int**. |
| [`y`](/slides/python-net/it/aspose.slides/point/y/) | Ottiene o imposta la coordinata y di questo punto.<br/>            Lettura/Scrittura **int**. |

### Osservazioni

I punti vengono confrontati per le loro coordinate con `==` e possono essere usati come chiavi di dizionario o membri di set.
