## proprietà di rotazione
Restituisce o imposta il numero di gradi di rotazione della forma specificata attorno all'asse z. Un valore positivo indica rotazione in senso orario; un valore negativo indica rotazione in senso anti-orario. Lettura/scrittura **float**.

### Osservazioni

Il valore restituito è sempre definito (non è float.NaN). Il valore assegnato deve essere definito (non float.NaN). È possibile impostare valori indefiniti per le proprietà delle istanze di RawFrame.
