## Classe Control

Rappresenta un controllo ActiveX.

Il tipo Control espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`persistence`](/slides/python-net/it/aspose.slides/control/persistence/) | Ottiene il metodo usato per memorizzare le proprietà del controllo ActiveX.<br/>            Solo lettura [`PersistenceType`](/slides/python-net/it/aspose.slides/persistencetype). |
| [`name`](/slides/python-net/it/aspose.slides/control/name/) | Ottiene o imposta il nome di questo controllo.<br/>            Lettura/scrittura **str**. |
| [`class_id`](/slides/python-net/it/aspose.slides/control/class_id/) | Ottiene l'id di classe di questo controllo.<br/>            Solo lettura **System.Guid**. |
| [`substitute_picture_format`](/slides/python-net/it/aspose.slides/control/substitute_picture_format/) | Restituisce l'oggetto delle proprietà di riempimento immagine del Control.<br/>            Solo lettura [`IPictureFillFormat`](/slides/python-net/it/aspose.slides/ipicturefillformat). |
| [`frame`](/slides/python-net/it/aspose.slides/control/frame/) | Restituisce o imposta il frame del controllo.<br/>            Lettura/scrittura [`IShapeFrame`](/slides/python-net/it/aspose.slides/ishapeframe). |
| [`properties`](/slides/python-net/it/aspose.slides/control/properties/) | Restituisce una collezione di proprietà ActiveX.<br/>            Nota: Aspose.Slides supporta solo proprietà ActiveX basate su XML. Se le proprietà sono memorizzate in formato binario, questa proprietà restituisce None.<br/>            Solo lettura [`IControlPropertiesCollection`](/slides/python-net/it/aspose.slides/icontrolpropertiescollection). |
| [`active_x_control_binary`](/slides/python-net/it/aspose.slides/control/active_x_control_binary/) | Specifica la persistenza di un controllo ActiveX quando il metodo usato per persistere è PersistStream, PersistStreamInit o PersistStorage. |
