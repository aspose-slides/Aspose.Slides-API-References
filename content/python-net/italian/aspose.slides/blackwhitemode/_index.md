## BlackWhiteMode enumerazione

Determina come una forma colorata debba essere trasformata in bianco e nero.

Il tipo BlackWhiteMode espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| NOT_DEFINED | La proprietà non è impostata |
| COLOR | L'oggetto è renderizzato con colorazione normale |
| AUTOMATIC | L'oggetto è renderizzato con colorazione automatica |
| GRAY | L'oggetto è renderizzato con colorazione grigia |
| LIGHT_GRAY | L'oggetto è renderizzato con colorazione grigio chiaro |
| INVERSE_GRAY | L'oggetto è renderizzato con colorazione grigia inversa |
| GRAY_WHITE | L'oggetto è renderizzato con colorazione grigia e bianca |
| BLACK_GRAY | L'oggetto è renderizzato con colorazione nera e grigia |
| BLACK_WHITE | L'oggetto è renderizzato con colorazione nera e bianca |
| BLACK | L'oggetto è renderizzato solo con colorazione nera |
| WHITE | L'oggetto è renderizzato con colorazione bianca |
| HIDDEN | L'oggetto non è renderizzato |
