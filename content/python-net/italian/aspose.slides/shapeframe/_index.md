| Proprietà | Descrizione |
| :- | :- |
| [`x`](/slides/python-net/it/aspose.slides/shapeframe/x/) | Restituisce la coordinata X dell'angolo superiore sinistro di un frame.<br/>            Sola lettura **float**. |
| [`y`](/slides/python-net/it/aspose.slides/shapeframe/y/) | Restituisce la coordinata Y dell'angolo superiore sinistro di un frame.<br/>            Sola lettura **float**. |
| [`width`](/slides/python-net/it/aspose.slides/shapeframe/width/) | Restituisce la larghezza di un frame.<br/>            Sola lettura **float**. |

| [`rotation`](/slides/python-net/it/aspose.slides/shapeframe/rotation/) | Restituisce il numero di gradi di rotazione di un frame attorno all'asse z.<br/>            Un valore positivo indica rotazione in senso orario; un valore negativo<br/>            indica rotazione in senso antiorario.<br/>            Sola lettura **float**. |
| [`center_x`](/slides/python-net/it/aspose.slides/shapeframe/center_x/) | Restituisce la coordinata X del centro di un frame.<br/>            Sola lettura **float**. |
| [`center_y`](/slides/python-net/it/aspose.slides/shapeframe/center_y/) | Restituisce la coordinata Y del centro di un frame.<br/>            Sola lettura **float**. |
| [`flip_h`](/slides/python-net/it/aspose.slides/shapeframe/flip_h/) | Determina se un frame è capovolto orizzontalmente.<br/>            Sola lettura [`NullableBool`](/slides/python-net/it/aspose.slides/nullablebool). |
| [`flip_v`](/slides/python-net/it/aspose.slides/shapeframe/flip_v/) | Determina se un frame è capovolto verticalmente.<br/>            Sola lettura [`NullableBool`](/slides/python-net/it/aspose.slides/nullablebool). |
| [`rectangle`](/slides/python-net/it/aspose.slides/shapeframe/rectangle/) | Restituisce le coordinate di un frame.<br/>            Sola lettura **aspose.slides.RectangleF**. |
