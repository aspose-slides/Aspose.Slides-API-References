## get_custom_property_name(self, index) {#int}
Restituisce il nome di una proprietà personalizzata all'indice specificato.

### Restituisce

Nome della proprietà personalizzata all'indice specificato.



```python
def get_custom_property_name(self, index):
    ...
```


| Parametro | Tipo | Descrizione |
| :- | :- | :- |
| index | **int** | L'indice basato su zero di una proprietà personalizzata da ottenere. |

### Eccezioni

| Eccezione | Descrizione |
| :- | :- |
| **RuntimeError(Proxy error(ArgumentOutOfRangeException))** | L'indice è minore di zero. L'indice è uguale o maggiore di Count. |
