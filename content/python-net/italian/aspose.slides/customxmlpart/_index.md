## CustomXmlPart classe

Rappresenta la parte XML personalizzata.

Il tipo CustomXmlPart espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`xml_data`](/slides/python-net/it/aspose.slides/customxmlpart/xml_data/) | Restituisce o imposta i dati xml.<br/>            Lettura/scrittura **int**[].<br/>            il valore è `None`. il valore è vuoto o i dati xml non sono validi. |
| [`xml_as_string`](/slides/python-net/it/aspose.slides/customxmlpart/xml_as_string/) | Restituisce o imposta i dati xml come stringa UTF-8.<br/>            Lettura/scrittura **str**.<br/>            il valore è `None`. il valore è vuoto o i dati xml non sono validi. |
| [`item_id`](/slides/python-net/it/aspose.slides/customxmlpart/item_id/) | Specifica un identificatore univoco globale (GUID) che identifica in modo univoco una singola parte XML personalizzata <br/>            all'interno di un documento Office Open XML.<br/>            sola lettura **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/it/aspose.slides/customxmlpart/namespace_schemas/) | Restituisce la raccolta di schemi XML associati alla parte XML personalizzata.<br/>            sola lettura **str**[]. |

## Metodi

| Metodo | Descrizione |
| :- | :- |
| [`remove(self)`](/slides/python-net/it/aspose.slides/customxmlpart/remove/#) | Rimuove la parte XML personalizzata dalla presentazione. |
