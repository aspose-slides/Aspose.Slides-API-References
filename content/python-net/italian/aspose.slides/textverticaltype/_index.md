## TextVerticalType enumerazione

Determina la modalità di scrittura verticale per un testo.

Il tipo TextVerticalType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| NOT_DEFINED | Non definito. |
| HORIZONTAL | Testo orizzontale. |
| VERTICAL | Testo verticale. |
| VERTICAL270 | Testo verticale a 270 gradi. |
| WORD_ART_VERTICAL | Testo verticale WordArt. |
| EAST_ASIAN_VERTICAL | Testo verticale East asian. |
| MONGOLIAN_VERTICAL | Testo verticale Mongolian. |
| WORD_ART_VERTICAL_RIGHT_TO_LEFT | Testo verticale WordArt da destra a sinistra. |
