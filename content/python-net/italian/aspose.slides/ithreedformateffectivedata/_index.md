## IThreeDFormatEffectiveData classe

Oggetto immutabile che rappresenta le proprietà di formattazione 3-D effettive.

Il tipo IThreeDFormatEffectiveData espone i seguenti membri:

| Proprietà | Descrizione |
| :- | :- |

| [`extrusion_height`](/slides/python-net/it/aspose.slides/ithreedformateffectivedata/extrusion_height/) | Restituisce l'altezza di un effetto di estrusione.<br/>            Solo lettura **float**. |
| [`depth`](/slides/python-net/it/aspose.slides/ithreedformateffectivedata/depth/) | Restituisce la profondità di una forma 3D.<br/>            Solo lettura **float**. |
| [`bevel_top`](/slides/python-net/it/aspose.slides/ithreedformateffectivedata/bevel_top/) | Restituisce il tipo di un rebordo superiore 3D.<br/>            Solo lettura [`IShapeBevelEffectiveData`](/slides/python-net/it/aspose.slides/ishapebeveleffectivedata). |
| [`bevel_bottom`](/slides/python-net/it/aspose.slides/ithreedformateffectivedata/bevel_bottom/) | Restituisce il tipo di un rebordo inferiore 3D.<br/>            Solo lettura [`IShapeBevelEffectiveData`](/slides/python-net/it/aspose.slides/ishapebeveleffectivedata). |
