## IComment classe

Rappresenta un commento su una diapositiva.

Il tipo IComment espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`text`](/slides/python-net/it/aspose.slides/icomment/text/) | Restituisce o imposta il testo semplice di un commento su una diapositiva.<br/>            Lettura/scrittura **str**. |
| [`created_time`](/slides/python-net/it/aspose.slides/icomment/created_time/) | Restituisce o imposta l'ora di creazione di un commento.<br/>            Impostare questa proprietà su **System.DateTime** significa che non è impostata alcuna ora del commento.<br/>            Lettura/scrittura **System.DateTime**. |
| [`slide`](/slides/python-net/it/aspose.slides/icomment/slide/) | Restituisce o imposta la diapositiva principale di un commento.<br/>            Solo lettura [`ISlide`](/slides/python-net/it/aspose.slides/islide). |
| [`author`](/slides/python-net/it/aspose.slides/icomment/author/) | Restituisce l'autore di un commento.<br/>            Solo lettura [`ICommentAuthor`](/slides/python-net/it/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/it/aspose.slides/icomment/position/) | Restituisce o imposta la posizione di un commento su una diapositiva.<br/>            Lettura/scrittura [`PointF`](/slides/python-net/it/aspose.slides/pointf). |
| [`parent_comment`](/slides/python-net/it/aspose.slides/icomment/parent_comment/) | Restituisce o imposta il commento principale.<br/>            Lettura/scrittura [`IComment`](/slides/python-net/it/aspose.slides/icomment). |

## Metodi

| Metodo | Descrizione |
| :- | :- |
| [`remove(self)`](/slides/python-net/it/aspose.slides/icomment/remove/#) | Rimuove il commento e tutte le sue risposte dalla collezione principale. |
