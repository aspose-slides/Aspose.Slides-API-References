## enumerazione LoadFormat

Indica il formato del documento da caricare.

Il tipo LoadFormat espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| AUTO | Istruisce Aspose.Slides a riconoscere automaticamente il formato. |
| PPT | Presentazione Microsoft PowerPoint 97-2003. |
| PPS | SlideShow Microsoft PowerPoint 97-2003. |
| PPTX | Documento Microsoft Office Open XML PresentationML. |
| PPSX | SlideShow Microsoft Office Open XML PresentationML. |
| ODP | Presentazione OpenOffice ODF. |
| POTX | Modello Microsoft Office Open XML PresentationML. |
| PPTM | Documento Microsoft Office Open XML PresentationML con macro. |
| PPSM | SlideShow Microsoft Office Open XML PresentationML con macro. |
| POTM | Modello Microsoft Office Open XML PresentationML con macro. |
| OTP | Modello di presentazione OpenOffice OTP. |
| PPT95 | Presentazione Microsoft PowerPoint 95. |
| POT | Modello di presentazione Microsoft PowerPoint 97-2003. |
| FODP | Presentazione Flat XML ODF. |
| UNKNOWN | Formato file sconosciuto |
