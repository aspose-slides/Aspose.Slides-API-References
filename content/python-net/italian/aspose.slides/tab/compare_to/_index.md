## compare_to(self, obj) {#any}
Confronta l'istanza corrente con un altro oggetto dello stesso tipo.

### Restituisce

Un intero a 32 bit che indica l'ordine relativo dei comparandi.
Il valore restituito ha questi significati:
            
* < 0 - Questa istanza è minore di obj. = 0 - Questa istanza è uguale a obj. > 0 - Questa istanza è maggiore di obj.

* < 0 - Questa istanza è minore di obj. = 0 - Questa istanza è uguale a obj. > 0 - Questa istanza è maggiore di obj.

* < 0 - Questa istanza è minore di obj. = 0 - Questa istanza è uguale a obj. > 0 - Questa istanza è maggiore di obj.
