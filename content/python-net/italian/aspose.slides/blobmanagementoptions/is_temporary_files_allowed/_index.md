## is_temporary_files_allowed proprietà
Questa proprietà definisce se è possibile creare file temporanei durante il lavoro con i BLOB, ciò che riduce notevolmente 
            il consumo di memoria ma richiede permessi per creare i file.
            Tutti i file verranno eliminati al termine del lavoro con la presentazione.
