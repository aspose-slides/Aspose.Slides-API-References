## height proprietà
Ottiene o imposta il valore di height della forma, misurato in punti.
            Lettura/Scrittura **float**.


### Note

Il valore restituito è sempre definito e mai **float**.
            Il valore assegnato deve anch'esso essere definito; assegnare **float** solo alle proprietà di un'istanza `RawFrame`.
