## INormalViewProperties classe

Rappresenta le proprietà della vista normale. La vista normale è composta da tre regioni di contenuto: la diapositiva stessa, una regione di contenuto laterale e una regione di contenuto inferiore.

Il tipo INormalViewProperties espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`show_outline_icons`](/slides/python-net/it/aspose.slides/inormalviewproperties/show_outline_icons/) | Specifica se l'applicazione deve mostrare le icone quando visualizza contenuto di contorno in una qualsiasi<br/>            delle regioni di contenuto della modalità vista normale.<br/>            Lettura/scrittura **bool**. |
| [`snap_vertical_splitter`](/slides/python-net/it/aspose.slides/inormalviewproperties/snap_vertical_splitter/) | Specifica se il divisore verticale deve scattare a uno stato minimo quando la regione laterale è sufficientemente piccola.<br/>            Lettura/scrittura **bool**. |
| [`vertical_bar_state`](/slides/python-net/it/aspose.slides/inormalviewproperties/vertical_bar_state/) | Specifica lo stato in cui deve essere visualizzata la barra del divisore verticale. <br/>            Una barra del divisore verticale separa la diapositiva dalla regione di contenuto laterale. |
| [`horizontal_bar_state`](/slides/python-net/it/aspose.slides/inormalviewproperties/horizontal_bar_state/) | Specifica lo stato in cui deve essere visualizzata la barra del divisore orizzontale.<br/>            Una barra del divisore orizzontale separa la diapositiva dalla regione di contenuto sotto la diapositiva. |
| [`prefer_single_view`](/slides/python-net/it/aspose.slides/inormalviewproperties/prefer_single_view/) | Specifica se l'utente preferisce vedere una singola regione di contenuto a finestra intera rispetto alla<br/>            vista normale standard con tre regioni di contenuto. Se abilitato, l'applicazione può scegliere<br/>            di visualizzare una delle regioni di contenuto nell'intera finestra.<br/>            Lettura/scrittura **bool**. |
| [`restored_left`](/slides/python-net/it/aspose.slides/inormalviewproperties/restored_left/) | Questo elemento specifica le dimensioni della regione di contenuto laterale della vista normale, quando la regione è di dimensione variabile<br/>            ripristinata (né minimizzata né massimizzata).<br/>            Sola lettura [`INormalViewRestoredProperties`](/slides/python-net/it/aspose.slides/inormalviewrestoredproperties). |
| [`restored_top`](/slides/python-net/it/aspose.slides/inormalviewproperties/restored_top/) | Questo elemento specifica le dimensioni della regione superiore della diapositiva nella vista normale, quando la regione è di dimensione variabile<br/>            ripristinata (né minimizzata né massimizzata).<br/>            Sola lettura [`INormalViewRestoredProperties`](/slides/python-net/it/aspose.slides/inormalviewrestoredproperties). |
