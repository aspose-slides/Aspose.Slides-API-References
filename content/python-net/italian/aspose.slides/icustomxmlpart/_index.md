## ICustomXmlPart classe

Rappresenta una parte xml personalizzata.

Il tipo ICustomXmlPart espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`xml_as_string`](/slides/python-net/it/aspose.slides/icustomxmlpart/xml_as_string/) | Restituisce o imposta i dati xml come stringa UTF-8.<br/>            Read/write **str**.<br/>            Il valore è `None`. Il valore è vuoto o i dati xml non sono validi. |
| [`xml_data`](/slides/python-net/it/aspose.slides/icustomxmlpart/xml_data/) | Restituisce o imposta i dati xml.<br/>            Read/write **int**[].<br/>            Il valore è `None`. Il valore è vuoto o i dati xml non sono validi. |
| [`item_id`](/slides/python-net/it/aspose.slides/icustomxmlpart/item_id/) | Specifica un identificatore univoco globale (GUID) che identifica in modo univoco una singola parte XML personalizzata <br/>            all'interno di un documento Office Open XML.<br/>            Read-only **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/it/aspose.slides/icustomxmlpart/namespace_schemas/) | Restituisce gli schemi XML della raccolta associati alla parte XML personalizzata.<br/>            Read-only **str**[]. |

## Metodi

| Metodo | Descrizione |
| :- | :- |
| [`remove(self)`](/slides/python-net/it/aspose.slides/icustomxmlpart/remove/#) | Rimuove la parte xml personalizzata dalla presentazione. |
