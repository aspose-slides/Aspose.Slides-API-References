## CommonSlideViewProperties classe

Rappresenta le proprietà comuni della vista della diapositiva.

Il tipo CommonSlideViewProperties espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`scale`](/slides/python-net/it/aspose.slides/commonslideviewproperties/scale/) | Specifica il rapporto di ridimensionamento della vista in percentuale.<br/>            Lettura/scrittura **int**. |
| [`variable_scale`](/slides/python-net/it/aspose.slides/commonslideviewproperties/variable_scale/) | Specifica che il contenuto della vista deve essere scalato automaticamente per adattarsi al meglio alla dimensione corrente della finestra.<br/>            Lettura/scrittura **bool**. |
| [`drawing_guides`](/slides/python-net/it/aspose.slides/commonslideviewproperties/drawing_guides/) | Restituisce la collezione delle guide di disegno.<br/>            Solo lettura [`IDrawingGuidesCollection`](/slides/python-net/it/aspose.slides/idrawingguidescollection) |
