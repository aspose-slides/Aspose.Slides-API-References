## binary_data proprietà
Restituisce una copia dei dati di un audio. In caso di grandi quantità di dati considerare 
            utilizzo del metodo [`IAudio.get_stream`](/slides/python-net/it/aspose.slides/iaudio/get_stream) per evitare il caricamento non necessario  dei dati dell'audio
            dati in memoria o anche OutOfMemoryException.
            Sola lettura **int**[].
