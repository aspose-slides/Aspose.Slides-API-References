## SensitivityLabel classe

Rappresenta l'etichetta di sensibilità di Microsoft Purview Information Protection.

Il tipo SensitivityLabel espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`id`](/slides/python-net/it/aspose.slides/sensitivitylabel/id/) | Restituisce o imposta l'ID dell'etichetta di sensibilità.<br/>            Lettura/scrittura **str**. |
| [`site_id`](/slides/python-net/it/aspose.slides/sensitivitylabel/site_id/) | Restituisce o imposta l'identificatore del sito Azure Active Directory (Azure AD) <br/>            corrispondente alla policy dell'etichetta di sensibilità che descrive l'etichetta di sensibilità.<br/>            Lettura/scrittura **System.Guid**. |
| [`is_enabled`](/slides/python-net/it/aspose.slides/sensitivitylabel/is_enabled/) | Indica se l'etichetta di sensibilità è abilitata. |
| [`is_removed`](/slides/python-net/it/aspose.slides/sensitivitylabel/is_removed/) | Indica se l'etichetta di sensibilità è stata rimossa. |
| [`assignment_method_type`](/slides/python-net/it/aspose.slides/sensitivitylabel/assignment_method_type/) | Restituisce o imposta il metodo di assegnazione per l'etichetta di sensibilità.<br/>            Lettura/scrittura [`SensitivityLabelAssignmentType`](/slides/python-net/it/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/it/aspose.slides/sensitivitylabel/content_mark_types/) | Restituisce l'elenco dei tipi di marcatura del contenuto che dovrebbero essere applicati a un file. |
