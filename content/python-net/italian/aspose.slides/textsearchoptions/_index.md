## TextSearchOptions classe

Rappresenta le opzioni che possono essere usate per cercare testo in una Presentation, Slide o TextFrame.

Il tipo TextSearchOptions espone i seguenti membri:

## Costruttori

| Costruttore | Descrizione |
| :- | :- |
| [`__init__(self)`](/slides/python-net/it/aspose.slides/textsearchoptions/__init__/#) | Crea nuove opzioni di ricerca del testo predefinite. |

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`case_sensitive`](/slides/python-net/it/aspose.slides/textsearchoptions/case_sensitive/) | Imposta true per usare la ricerca sensibile al maiuscolo/minuscolo, false altrimenti.<br/>            Lettura/scrittura **bool**. |
| [`whole_words_only`](/slides/python-net/it/aspose.slides/textsearchoptions/whole_words_only/) | Imposta true per corrispondere solo parole intere, false altrimenti.<br/>            Lettura/scrittura **bool**. |
| [`include_notes`](/slides/python-net/it/aspose.slides/textsearchoptions/include_notes/) | Imposta `true` per includere il testo contenuto nelle note della diapositiva ([`NotesSlide`](/slides/python-net/it/aspose.slides/notesslide)) <br/>            durante l'esecuzione di operazioni di ricerca del testo, sostituzione o evidenziazione.<br/>            Il valore predefinito è `false`. |
