## width proprietà
Ottiene o imposta la width della forma, misurata in punti.
            Lettura/Scrittura **float**.


### Osservazioni

Il valore restituito è sempre definito e mai **float**.
            Il valore assegnato deve essere anch'esso definito; assegnare **float** solo alle proprietà di un'istanza di `RawFrame`.
