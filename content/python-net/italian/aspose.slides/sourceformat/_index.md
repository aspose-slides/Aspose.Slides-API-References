## SourceFormat enumerazione

Rappresenta il formato del file sorgente.

Il tipo SourceFormat espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| PPT | Microsoft PowerPoint 97-2003 Presentazione (*.ppt). |
| PPTX | Microsoft Office Open XML Presentazione (*.pptx). |
| ODP | OpenDocument Presentazione (*.odp). |
| PPTM | Microsoft Office Open XML Presentazione con macro (*.pptm). |
| PPSX | Microsoft Office Open XML Presentazione diapositive (*.ppsx). |
| PPSM | Microsoft Office Open XML Presentazione diapositive con macro (*.ppsm). |
| POTX | Microsoft Office Open XML Modello (*.potx). |
| POTM | Microsoft Office Open XML Modello con macro (*.potm). |
| PPS | Microsoft PowerPoint 97-2003 Presentazione diapositive (*.pps). |
| POT | Microsoft PowerPoint 97-2003 Modello (*.pot). |
| OTP | OpenDocument Modello di presentazione (*.otp). |
| FODP | Flat XML ODF Presentazione (*.fodp). |
| XML | PowerPoint XML Presentazione (*.xml). |
