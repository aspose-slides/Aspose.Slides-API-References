## SlideSize classe

Rappresenta la dimensione e l'orientamento di una diapositiva.

Il tipo SlideSize espone i seguenti membri:

## Proprietà

| Property | Description |
| :- | :- |
| [`size`](/slides/python-net/it/aspose.slides/slidesize/size/) | Ottiene le dimensioni della diapositiva in punti. |
| [`type`](/slides/python-net/it/aspose.slides/slidesize/type/) | Ottiene il tipo di dimensione della diapositiva. |
| [`orientation`](/slides/python-net/it/aspose.slides/slidesize/orientation/) | Ottiene o imposta l'orientamento della diapositiva. |

## Metodi

| Method | Description |
| :- | :- |
| [`set_size(self, type, scale_type)`](/slides/python-net/it/aspose.slides/slidesize/set_size/#slidesizetype-slidesizescaletype) | Imposta la dimensione della diapositiva per tipo e ridimensiona il contenuto esistente. |
| [`set_size(self, width, height, scale_type)`](/slides/python-net/it/aspose.slides/slidesize/set_size/#float-float-slidesizescaletype) | Imposta esplicitamente le dimensioni della diapositiva e ridimensiona il contenuto esistente. |
