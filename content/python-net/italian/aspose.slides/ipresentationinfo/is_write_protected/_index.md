## is_write_protected proprietà
Restituisce un valore che indica se una presentazione collegata è protetta in scrittura.

### Osservazioni

Se la presentazione è protetta da una password per l'apertura, il valore della proprietà è uguale a NotDefined.  
Vedi l'enumerazione [`NullableBool`](/slides/python-net/it/aspose.slides/nullablebool).
