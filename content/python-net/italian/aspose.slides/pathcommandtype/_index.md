## PathCommandType enumerazione

Rappresenta i comandi di percorso grafico

Il tipo PathCommandType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| CLOSE | Chiude il percorso geometrico |
| MOVE_TO | Imposta la posizione del punto successivo del percorso geometrico |
| LINE_TO | Aggiunge una linea al percorso geometrico |
| ARC_TO | Aggiunge l'arco specificato al percorso geometrico. |
| QUAD_BEZIER_TO | Aggiunge una curva Bézier quadratica al percorso geometrico |
| CUBIC_BEZIER_TO | Aggiunge una curva Bézier cubica al percorso geometrico |
