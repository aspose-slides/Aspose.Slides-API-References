## IPPImage classe

Rappresenta un'immagine in una presentazione.

Il tipo IPPImage espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`binary_data`](/slides/python-net/it/aspose.slides/ippimage/binary_data/) | Restituisce una copia dei dati di un'immagine.<br/>            Solo lettura **int**[] |
| [`image`](/slides/python-net/it/aspose.slides/ippimage/image/) | Restituisce una copia di un'immagine.<br/>            Solo lettura [`IPPImage.image`](/slides/python-net/it/aspose.slides/ippimage/image) |
| [`svg_image`](/slides/python-net/it/aspose.slides/ippimage/svg_image/) | Restituisce o imposta l'oggetto ISvgImage [`ISvgImage`](/slides/python-net/it/aspose.slides/isvgimage) |
| [`content_type`](/slides/python-net/it/aspose.slides/ippimage/content_type/) | Restituisce il tipo MIME di un'immagine, codificato in [`IPPImage.binary_data`](/slides/python-net/it/aspose.slides/ippimage/binary_data).<br/>            Solo lettura **str** |
| [`width`](/slides/python-net/it/aspose.slides/ippimage/width/) | Restituisce la larghezza di un'immagine.<br/>            Solo lettura **int** |
| [`height`](/slides/python-net/it/aspose.slides/ippimage/height/) | Restituisce l'altezza di un'immagine.<br/>            Solo lettura **int** |
| [`x`](/slides/python-net/it/aspose.slides/ippimage/x/) | Restituisce l'offset X di un'immagine.<br/>            Solo lettura **int** |
| [`y`](/slides/python-net/it/aspose.slides/ippimage/y/) | Restituisce l'offset Y di un'immagine.<br/>            Solo lettura **int** |
