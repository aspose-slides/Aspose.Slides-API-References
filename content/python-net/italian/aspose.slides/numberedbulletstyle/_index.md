## Enumerazione NumberedBulletStyle

Rappresenta lo stile dei punti numerati.

Il tipo NumberedBulletStyle espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| NOT_DEFINED | Non definito. |
| BULLET_ALPHA_LC_PERIOD | Caratteri alfabetici minuscoli con un punto. Sample: a., b., c., ... |
| BULLET_ALPHA_UC_PERIOD | Caratteri alfabetici maiuscoli con un punto. Sample: A., B., C., ... |
| BULLET_ARABIC_PAREN_RIGHT | Numeri arabi con parentesi chiusa. Sample: 1), 2), 3), ... |
| BULLET_ARABIC_PERIOD | Numeri arabi con un punto. Sample: 1., 2., 3., ... |
| BULLET_ROMAN_LC_PAREN_BOTH | Numeri romani minuscoli con entrambe le parentesi. Sample: (i), (ii), (iii), ... |
| BULLET_ROMAN_LC_PAREN_RIGHT | Numeri romani minuscoli con parentesi chiusa. Sample: i), ii), iii), ... |
| BULLET_ROMAN_LC_PERIOD | Numeri romani minuscoli con punto. Sample: i., ii., iii., ... |
| BULLET_ROMAN_UC_PERIOD | Numeri romani maiuscoli con punto. Sample: I., II., III., ... |
| BULLET_ALPHA_LC_PAREN_BOTH | Caratteri alfabetici minuscoli con entrambe le parentesi. Sample: (a), (b), (c), ... |
| BULLET_ALPHA_LC_PAREN_RIGHT | Caratteri alfabetici minuscoli con parentesi chiusa. Sample: a), b), c), ... |
| BULLET_ALPHA_UC_PAREN_BOTH | Caratteri alfabetici maiuscoli con entrambe le parentesi. Sample: (A), (B), (C), ... |
| BULLET_ALPHA_UC_PAREN_RIGHT | Caratteri alfabetici maiuscoli con parentesi chiusa. Sample: A), B), C), ... |
| BULLET_ARABIC_PAREN_BOTH | Numeri arabi con entrambe le parentesi. Sample: (1), (2), (3), ... |
| BULLET_ARABIC_PLAIN | Numeri arabi. Sample: 1, 2, 3, ... |
| BULLET_ROMAN_UC_PAREN_BOTH | Numeri romani maiuscoli con entrambe le parentesi. Sample: (I), (II), (III), ... |
| BULLET_ROMAN_UC_PAREN_RIGHT | Numeri romani maiuscoli con parentesi chiusa. Sample: I), II), III), ... |
| BULLET_SIMP_CHIN_PLAIN | Cinese semplificato senza punto. |
| BULLET_SIMP_CHIN_PERIOD | Cinese semplificato con punto. |
| BULLET_CIRCLE_NUM_DB_PLAIN | Numero circondato a doppio byte per valori fino a 10, da 11 - numeri arabi. |
| BULLET_CIRCLE_NUM_WD_WHITE_PLAIN | Numero colorato del testo con cerchio dello stesso colore disegnato attorno (Wingdings white circle numbers). From  11 - arabic numbers. |
| BULLET_CIRCLE_NUM_WD_BLACK_PLAIN | Numero di colore ombra con sfondo circolare del colore testo normale (Wingdings black circle numbers). |
| BULLET_TRAD_CHIN_PLAIN | Cinese tradizionale senza punto. |
| BULLET_TRAD_CHIN_PERIOD | Cinese tradizionale con punto. |
| BULLET_ARABIC_ALPHA_DASH | Caratteri alfabetici della lingua araba con trattino. |
| BULLET_ARABIC_ABJAD_DASH | Alfabeti Abjad arabi con trattino. |
| BULLET_HEBREW_ALPHA_DASH | Caratteri alfabetici della lingua ebraica con trattino. |
| BULLET_KANJI_KOREAN_PLAIN | Numeri giapponesi/coreani senza punto. |
| BULLET_KANJI_KOREAN_PERIOD | Numeri giapponesi/coreani con punto. |
| BULLET_ARABIC_DB_PLAIN | Schema di numerazione arabo a doppio byte (no punctuation). |
| BULLET_ARABIC_DB_PERIOD | Schema di numerazione arabo a doppio byte con double-byte period. |
| BULLET_THAI_ALPHA_PERIOD | Alfabeto tailandese con punto. |
| BULLET_THAI_ALPHA_PAREN_RIGHT | Parentesi dell'alfabeto tailandese - destra. |
| BULLET_THAI_ALPHA_PAREN_BOTH | Parentesi dell'alfabeto tailandese - entrambe. |
| BULLET_THAI_NUM_PERIOD | Periodo numerico tailandese. |
| BULLET_THAI_NUM_PAREN_RIGHT | Parentesi numeriche tailandesi - destra. |
| BULLET_THAI_NUM_PAREN_BOTH | Parentesi numeriche tailandesi - entrambe. |
| BULLET_HINDI_ALPHA_PERIOD | Alfabeto hindi con punto - vocali. |
| BULLET_HINDI_NUM_PERIOD | Periodo numerico hindi. |
| BULLET_KANJI_SIMP_CHIN_DB_PERIOD | Kanji Cinese semplice DBPeriod. |
| BULLET_HINDI_NUM_PAREN_RIGHT | Parentesi numeriche hindi - destra. |
| BULLET_HINDI_ALPHA_1_PERIOD | Alfabeto hindi con punto - consonanti. |
