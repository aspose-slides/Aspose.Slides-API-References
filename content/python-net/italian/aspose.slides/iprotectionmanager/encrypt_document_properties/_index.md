## encrypt_document_properties proprietà
Questa proprietà ha senso, se la presentazione è protetta da password.
            Se vero, le proprietà del documento sono crittografate nel file della presentazione.
            Se falso, le proprietà del documento sono pubbliche mentre la presentazione è crittografata.
Lettura/scrittura **bool**.
