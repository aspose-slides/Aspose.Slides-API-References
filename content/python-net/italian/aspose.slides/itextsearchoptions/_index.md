## ITextSearchOptions classe

Rappresenta le opzioni che possono essere usate per cercare testo in una Presentation, Slide o TextFrame.

Il tipo ITextSearchOptions espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`case_sensitive`](/slides/python-net/it/aspose.slides/itextsearchoptions/case_sensitive/) | Imposta true per utilizzare una ricerca sensibile al maiuscolo/minuscolo, false - altrimenti.<br/>            Lettura/scrittura **bool**. |
| [`whole_words_only`](/slides/python-net/it/aspose.slides/itextsearchoptions/whole_words_only/) | Imposta true per corrispondere solo parole intere, false - altrimenti.<br/>            Lettura/scrittura **bool**. |
| [`include_notes`](/slides/python-net/it/aspose.slides/itextsearchoptions/include_notes/) | Imposta `true` per includere il testo contenuto nelle note della slide <br/>            durante le operazioni di ricerca testo, sostituzione o evidenziazione.<br/>            Il valore predefinito è `false`. |
