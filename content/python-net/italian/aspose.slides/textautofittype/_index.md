## TextAutofitType enumerazione

Rappresenta la modalità di adattamento automatico del testo.

Il tipo TextAutofitType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| NOT_DEFINED | Non definito. |
| NONE | Nessun adattamento automatico. |
| NORMAL | Adattamento automatico normale. La dimensione del carattere e l'interlinea verranno ridotte per adattarsi alla forma. |
| SHAPE | Adattamento automatico forma. La dimensione della forma verrà modificata per adattarsi al testo. |
