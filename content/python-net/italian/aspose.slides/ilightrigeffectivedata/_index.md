## ILightRigEffectiveData classe

Oggetto immutabile che contiene le proprietà effective del light rig.

Il tipo ILightRigEffectiveData espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`direction`](/slides/python-net/it/aspose.slides/ilightrigeffectivedata/direction/) | Direzione della luce.<br/>            Solo lettura [`LightingDirection`](/slides/python-net/it/aspose.slides/lightingdirection). |
| [`light_type`](/slides/python-net/it/aspose.slides/ilightrigeffectivedata/light_type/) | Rappresenta una luce predefinita che può essere applicata a una forma. <br/>            Il light rig rappresenta un gruppo di luci orientate in modo specifico rispetto a una scena 3D.<br/>            Solo lettura [`LightRigPresetType`](/slides/python-net/it/aspose.slides/lightrigpresettype). |

## Metodi

| Metodo | Descrizione |
| :- | :- |
| [`get_rotation(self)`](/slides/python-net/it/aspose.slides/ilightrigeffectivedata/get_rotation/#) | Una rotazione è definita mediante l'uso di una coordinata di latitudine, una coordinata di longitudine e una rivoluzione attorno all'asse come le coordinate di latitudine e longitudine.<br/>            Primo elemento nell'array restituito - latitudine, secondo - longitudine, terzo - rivoluzione. |


### Osservazioni

Questa interfaccia è usata come parte di [`IThreeDFormatEffectiveData`](/slides/python-net/it/aspose.slides/ithreedformateffectivedata).
