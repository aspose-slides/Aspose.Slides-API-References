## Row classe

Rappresenta una riga in una tabella.

**Eredità:**[`Row`](/slides/python-net/it/aspose.slides/row) → [`CellCollection`](/slides/python-net/it/aspose.slides/cellcollection)

Il tipo Row espone i seguenti membri:

## Proprietà

| Property | Description |
| :- | :- |
| [`slide`](/slides/python-net/it/aspose.slides/row/slide/) | Restituisce la diapositiva padre di una CellCollection.<br/>            Sola lettura [`IBaseSlide`](/slides/python-net/it/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/it/aspose.slides/row/presentation/) | Restituisce la presentazione padre di una CellCollection.<br/>            Sola lettura [`IPresentation`](/slides/python-net/it/aspose.slides/ipresentation). |
| [`height`](/slides/python-net/it/aspose.slides/row/height/) | Restituisce l'altezza di una riga.<br/>            Sola lettura **float**. |
| [`minimal_height`](/slides/python-net/it/aspose.slides/row/minimal_height/) | Restituisce o imposta l'altezza minima possibile di una riga.<br/>            Lettura/scrittura **float**. |
| [`row_format`](/slides/python-net/it/aspose.slides/row/row_format/) | Restituisce l'oggetto RowFormat che contiene le proprietà di formattazione per questa riga.<br/>            Sola lettura [`IRowFormat`](/slides/python-net/it/aspose.slides/irowformat). |
