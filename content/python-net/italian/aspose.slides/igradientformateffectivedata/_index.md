## IGradientFormatEffectiveData classe

Oggetto immutabile che contiene le proprietà effettive di riempimento del gradiente.

Il tipo IGradientFormatEffectiveData espone i seguenti membri:

| Proprietà | Descrizione |

| [`tile_flip`](/slides/python-net/it/aspose.slides/igradientformateffectivedata/tile_flip/) | Restituisce la modalità di inversione per un gradiente.<br/>            Sola lettura [`TileFlip`](/slides/python-net/it/aspose.slides/tileflip). |
| [`gradient_direction`](/slides/python-net/it/aspose.slides/igradientformateffectivedata/gradient_direction/) | Restituisce lo stile di un gradiente.<br/>            Sola lettura [`GradientDirection`](/slides/python-net/it/aspose.slides/gradientdirection). |
| [`linear_gradient_angle`](/slides/python-net/it/aspose.slides/igradientformateffectivedata/linear_gradient_angle/) | Restituisce l'angolo di un gradiente.<br/>            Sola lettura **float**. |
| [`linear_gradient_scaled`](/slides/python-net/it/aspose.slides/igradientformateffectivedata/linear_gradient_scaled/) | Determina se un gradiente è scalato.<br/>            Sola lettura **bool**. |
| [`gradient_shape`](/slides/python-net/it/aspose.slides/igradientformateffectivedata/gradient_shape/) | Restituisce la forma di un gradiente.<br/>            Sola lettura [`GradientShape`](/slides/python-net/it/aspose.slides/gradientshape). |
