## IDigitalSignature classe

Firma digitale in un file firmato.

Il tipo IDigitalSignature espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`certificate`](/slides/python-net/it/aspose.slides/idigitalsignature/certificate/) | Oggetto certificato che è stato usato per firmare il documento.<br/>            Sola lettura **System.Security.Cryptography.X509Certificates.X509Certificate2**. |
| [`is_valid`](/slides/python-net/it/aspose.slides/idigitalsignature/is_valid/) | Se questa firma digitale è valida e il documento non è stato manomesso, questo valore sarà vero.<br/>            Sola lettura **bool**. |
| [`sign_time`](/slides/python-net/it/aspose.slides/idigitalsignature/sign_time/) | Il momento in cui il documento è stato firmato.<br/>            Sola lettura **System.DateTime**. |
| [`comments`](/slides/python-net/it/aspose.slides/idigitalsignature/comments/) | Lo scopo della firma.<br/>            Lettura/scrittura **str**. |
