## ColorType enumerazione

Rappresenta diverse modalità di colore.

Il tipo ColorType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| NOT_DEFINED | Il colore non è definito affatto. |
| RGB | Colore RGB standard a 24 bit. |
| RGB_PERCENTAGE | Colore RGB ad alta definizione. |
| HSL | Colore HSL ad alta definizione. |
| SCHEME | Colore di schema. |
| SYSTEM | Colore di sistema. |
| PRESET | Colore preimpostato. |
