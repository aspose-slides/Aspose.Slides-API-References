## ISensitivityLabel classe

Rappresenta l'etichetta di sensibilità di Microsoft Purview Information Protection.

Il tipo ISensitivityLabel espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`id`](/slides/python-net/it/aspose.slides/isensitivitylabel/id/) | Restituisce o imposta l'id dell'etichetta di sensibilità.<br/>            Read/write **str**. |
| [`site_id`](/slides/python-net/it/aspose.slides/isensitivitylabel/site_id/) | Restituisce o imposta l'identificatore del sito Azure Active Directory (Azure AD) <br/>            corrispondente alla policy dell'etichetta di sensibilità che descrive l'etichetta di sensibilità.<br/>            Read/write **System.Guid**. |
| [`is_enabled`](/slides/python-net/it/aspose.slides/isensitivitylabel/is_enabled/) | Indica se l'etichetta di sensibilità è attivata. |
| [`is_removed`](/slides/python-net/it/aspose.slides/isensitivitylabel/is_removed/) | Indica se l'etichetta di sensibilità è stata rimossa. |
| [`assignment_method_type`](/slides/python-net/it/aspose.slides/isensitivitylabel/assignment_method_type/) | Restituisce o imposta il metodo di assegnazione per l'etichetta di sensibilità.<br/>            Read/write [`SensitivityLabelAssignmentType`](/slides/python-net/it/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/it/aspose.slides/isensitivitylabel/content_mark_types/) | Restituisce l'elenco dei tipi di marcatura del contenuto che dovrebbero essere applicati a un file. |
