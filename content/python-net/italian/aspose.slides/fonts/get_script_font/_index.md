## get_script_font(self, script) {#str}
Restituisce il nome del font associato a un tag script specifico dal tema della presentazione.

### Returns
Il nome del font utilizzato per lo script specificato, o `None` se lo script non è definito.

```python
def get_script_font(self, script):
    ...
```

| Parametro | Tipo | Descrizione |
| :- | :- | :- |
| script | **str** | Il codice script BCP-47 (ad es., "Latn", "Cyrl", "Jpan") usato per identificare un sistema di scrittura. |
