## ICommentAuthor classe

Rappresenta un autore di commenti.

Il tipo ICommentAuthor espone i seguenti membri:

## Proprietà

| Property | Descrizione |
| :- | :- |
| [`name`](/slides/python-net/it/aspose.slides/icommentauthor/name/) | Restituisce o imposta il nome dell'autore.<br/>            Lettura/scrittura **str**. |
| [`initials`](/slides/python-net/it/aspose.slides/icommentauthor/initials/) | Restituisce o imposta le iniziali dell'autore.<br/>            Lettura/scrittura **str**. |
| [`comments`](/slides/python-net/it/aspose.slides/icommentauthor/comments/) | Restituisce la raccolta dei commenti effettuati da questo autore.<br/>            Sola lettura [`ICommentCollection`](/slides/python-net/it/aspose.slides/icommentcollection). |

## Metodi

| Method | Descrizione |
| :- | :- |
