## PresetShadowType enumerazione

Rappresenta una preimpostazione per un effetto ombra.

Il tipo PresetShadowType espone i seguenti membri:

| Campo | Descrizione |
| :- | :- |
| TOP_LEFT_DROP_SHADOW | Rappresenta l'ombreggiatura a caduta in alto a sinistra. |
| TOP_LEFT_LARGE_DROP_SHADOW | Rappresenta l'ombreggiatura a caduta grande in alto a sinistra. |
| BACK_LEFT_LONG_PERSPECTIVE_SHADOW | Rappresenta l'ombreggiatura prospettica lunga sul retro sinistro. |

| FRONT_RIGHT_LONG_PERSPECTIVE_SHADOW | Rappresenta l'ombreggiatura prospettica lunga sul fronte destro. |
| OUTER_BOX_SHADOW_3D | Rappresenta l'ombreggiatura a scatola esterna 3D. |
