## IShapeFrame classe

Rappresenta le proprietà del frame della forma.

Il tipo IShapeFrame espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`x`](/slides/python-net/it/aspose.slides/ishapeframe/x/) | Restituisce la coordinata X dell'angolo superiore sinistro di un frame.<br/>            Solo lettura **float**. |
| [`y`](/slides/python-net/it/aspose.slides/ishapeframe/y/) | Restituisce la coordinata Y dell'angolo superiore sinistro di un frame.<br/>            Solo lettura **float**. |
| [`width`](/slides/python-net/it/aspose.slides/ishapeframe/width/) | Restituisce la larghezza di un frame.<br/>            Solo lettura **float**. |
| [`height`](/slides/python-net/it/aspose.slides/ishapeframe/height/) | Restituisce l'altezza di un frame.<br/>            Solo lettura **float**. |
| [`rotation`](/slides/python-net/it/aspose.slides/ishapeframe/rotation/) | Restituisce il numero di gradi con cui un frame è ruotato attorno all'asse z.<br/>            Un valore positivo indica rotazione in senso orario; un valore negativo<br/>            indica rotazione in senso antiorario.<br/>            Solo lettura **float**. |
| [`center_x`](/slides/python-net/it/aspose.slides/ishapeframe/center_x/) | Restituisce la coordinata X del centro di un frame.<br/>            Solo lettura **float**. |
| [`center_y`](/slides/python-net/it/aspose.slides/ishapeframe/center_y/) | Restituisce la coordinata Y del centro di un frame.<br/>            Solo lettura **float**. |
| [`flip_h`](/slides/python-net/it/aspose.slides/ishapeframe/flip_h/) | Determina se un frame è capovolto orizzontalmente.<br/>            Solo lettura [`NullableBool`](/slides/python-net/it/aspose.slides/nullablebool). |
| [`flip_v`](/slides/python-net/it/aspose.slides/ishapeframe/flip_v/) | Determina se un frame è capovolto verticalmente.<br/>            Solo lettura [`NullableBool`](/slides/python-net/it/aspose.slides/nullablebool). |
| [`rectangle`](/slides/python-net/it/aspose.slides/ishapeframe/rectangle/) | Restituisce le coordinate di un frame.<br/>            Solo lettura **aspose.slides.RectangleF**. |
