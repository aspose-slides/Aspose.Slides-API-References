## IAdjustValue classe

Rappresenta il valore di aggiustamento di una forma geometrica.
            Questi valori influenzano la forma della forma.

Il tipo IAdjustValue espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`raw_value`](/slides/python-net/it/aspose.slides/iadjustvalue/raw_value/) | Restituisce o imposta il valore di aggiustamento "così com'è".<br/>            Lettura/scrittura **int**. |
| [`angle_value`](/slides/python-net/it/aspose.slides/iadjustvalue/angle_value/) | Restituisce o imposta il valore, interpretandolo come angolo in gradi.<br/>            Lettura/scrittura **float**. |
| [`name`](/slides/python-net/it/aspose.slides/iadjustvalue/name/) | Restituisce un nome di questo valore di aggiustamento.<br/>            Solo lettura **str**. |
| [`type`](/slides/python-net/it/aspose.slides/iadjustvalue/type/) | Restituisce il tipo di aggiustamento della forma.<br/>            Solo lettura [`ShapeAdjustmentType`](/slides/python-net/it/aspose.slides/shapeadjustmenttype). |
