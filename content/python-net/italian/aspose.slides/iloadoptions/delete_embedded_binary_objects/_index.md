## delete_embedded_binary_objects proprietà
Determina se Aspose.Slides eliminerà tutti gli oggetti binari incorporati durante il caricamento della presentazione.
            
I tipi degli oggetti binari incorporati:


* VBA Project [`IPresentation.vba_project`](/slides/python-net/it/aspose.slides/ipresentation/vba_project)
* OLE Object embedded data [`IOleEmbeddedDataInfo.embedded_file_data`](/slides/python-net/it/aspose.slides/ioleembeddeddatainfo/embedded_file_data)
* ActiveX Control binary data [`IControl.active_x_control_binary`](/slides/python-net/it/aspose.slides/icontrol/active_x_control_binary)


Lettura/Scrittura **bool**.

### Osservazioni

Il valore predefinito è **false** .
