## blob_management_options proprietà
Rappresenta le opzioni che possono essere usate per gestire il comportamento di gestione dei Binary Large Objects (BLOBs),
            come l'uso di file temporanei o il numero massimo di byte BLOB in memoria. Queste opzioni sono intese a impostare
            il miglior rapporto prestazioni/consumo di memoria per un ambiente o requisiti specifici.
            Un Binary Large Object (BLOB) è un dato binario memorizzato come un'entità singola - cioè BLOB può 
            essere un audio, un video o una presentazione stessa.
