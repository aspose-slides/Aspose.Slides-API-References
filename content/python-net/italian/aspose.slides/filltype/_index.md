## enumerazione FillType

Specifica il tipo di riempimento interno di vari oggetti visivi.

Il tipo FillType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| NOT_DEFINED | Il tipo di riempimento non è definito. |
| NO_FILL | Nessun riempimento applicato. |
| SOLID | Riempito con un colore solido. |
| GRADIENT | Il riempimento è gradiente. |
| PATTERN | Viene usato un motivo ripetuto per riempire l'oggetto. |
| PICTURE | Viene usata un'immagine singola per riempire l'oggetto. |
| GROUP | L'oggetto visivo eredita le proprietà di riempimento dal gruppo. |
