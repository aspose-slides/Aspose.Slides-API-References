## get_script_font(self, script) {#str}
Restituisce il nome del carattere associato a un tag script specifico dal tema della presentazione.

### Restituisce

Il nome del carattere utilizzato per lo script specificato, o `None` se lo script non è definito.

```python
def get_script_font(self, script):
    ...
```


| Parametro | Tipo | Descrizione |
| :- | :- | :- |
| script | **str** | Il codice script BCP-47 (ad es., "Latn", "Cyrl", "Jpan") utilizzato per identificare un sistema di scrittura. |
