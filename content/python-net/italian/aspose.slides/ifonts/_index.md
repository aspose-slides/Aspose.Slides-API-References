## IFonts classe

Rappresenta la raccolta di caratteri.

Il tipo IFonts espone i seguenti membri:

## Proprietà

| Property | Description |
| :- | :- |
| [`latin_font`](/slides/python-net/it/aspose.slides/ifonts/latin_font/) | Restituisce o imposta il carattere Latin.<br/> Lettura/scrittura [`IFontData`](/slides/python-net/it/aspose.slides/ifontdata). |
| [`east_asian_font`](/slides/python-net/it/aspose.slides/ifonts/east_asian_font/) | Restituisce o imposta il carattere East Asian.<br/> Lettura/scrittura [`IFontData`](/slides/python-net/it/aspose.slides/ifontdata). |
| [`complex_script_font`](/slides/python-net/it/aspose.slides/ifonts/complex_script_font/) | Restituisce o imposta il carattere per script complessi.<br/> Lettura/scrittura [`IFontData`](/slides/python-net/it/aspose.slides/ifontdata). |

## Metodi

| Method | Description |
| :- | :- |
| [`get_script_font_map(self)`](/slides/python-net/it/aspose.slides/ifonts/get_script_font_map/#) | Restituisce un elenco di tutte le coppie stringa-stringa delle definizioni di caratteri script nella presentazione. |
| [`get_script_font(self, script)`](/slides/python-net/it/aspose.slides/ifonts/get_script_font/#str) | Ottiene il nome del carattere associato a un tag script specifico dal tema della presentazione. |
| [`set_script_font(self, script, font_name)`](/slides/python-net/it/aspose.slides/ifonts/set_script_font/#str-str) | Assegna un nome di carattere a un tag script specifico, definendo come il testo di quello script sarà renderizzato nella presentazione. |
| [`remove_script_font(self, script)`](/slides/python-net/it/aspose.slides/ifonts/remove_script_font/#str) | Rimuove l'impostazione del carattere associata a un tag script specifico dalla raccolta di caratteri del tema. |
