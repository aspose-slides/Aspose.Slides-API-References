## SensitivityLabelContentType enumerazione

Rappresenta i tipi di marcatura del contenuto che dovrebbero essere applicati a un documento.

Il tipo SensitivityLabelContentType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| NONE | Implica che l'etichetta sia applicata per impostazione predefinita o automaticamente. |
| HEADER | Implica che l'etichetta sia stata applicata manualmente.<br/>            Utilizzare per qualsiasi etichetta di sensibilità che sia stata applicata direttamente dall'utente. |
| FOOTER | Implica che l'etichetta sia stata applicata manualmente.<br/>            Utilizzare per qualsiasi etichetta di sensibilità che sia stata applicata direttamente dall'utente. |
| WATERMARK | Implica che l'etichetta sia stata applicata manualmente.<br/>            Utilizzare per qualsiasi etichetta di sensibilità che sia stata applicata direttamente dall'utente. |
| ENCRYPTION | Implica che l'etichetta sia stata applicata manualmente.<br/>            Utilizzare per qualsiasi etichetta di sensibilità che sia stata applicata direttamente dall'utente. |
