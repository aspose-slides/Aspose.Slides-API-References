## IFontSources classe

Fornisce sorgenti di file e di memoria per i font esterni.

Il tipo IFontSources espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`font_folders`](/slides/python-net/it/aspose.slides/ifontsources/font_folders/) | Cartelle contenenti file di font.<br/>            Tutti i file di font presenti in queste cartelle sono inclusi nella raccolta. Cartelle ricorsivamente ricercate. |
| [`memory_fonts`](/slides/python-net/it/aspose.slides/ifontsources/memory_fonts/) | Una raccolta di font rappresentata come array di byte. |
