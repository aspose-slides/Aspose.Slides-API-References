## TextHighlightingOptions classe

Rappresenta le opzioni che possono essere utilizzate per evidenziare il testo in un frame di testo.

Il tipo TextHighlightingOptions espone i seguenti membri:

## Costruttori

| Costruttore | Descrizione |
| :- | :- |
| [`__init__(self)`](/slides/python-net/it/aspose.slides/texthighlightingoptions/__init__/#) | Crea nuove opzioni predefinite per l'evidenziazione del testo. |

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`case_sensitive`](/slides/python-net/it/aspose.slides/texthighlightingoptions/case_sensitive/) | Imposta true per utilizzare la ricerca sensibile al maiuscolo/minuscolo, false - altrimenti.<br/>            Lettura/Scrittura **bool**. |
| [`whole_words_only`](/slides/python-net/it/aspose.slides/texthighlightingoptions/whole_words_only/) | Imposta true per corrispondere solo parole intere, false - altrimenti.<br/>            Lettura/Scrittura **bool**. |
