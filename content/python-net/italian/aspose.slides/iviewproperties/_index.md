## IViewProperties classe

Proprietà di visualizzazione a livello di presentazione.

Il tipo IViewProperties espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`last_view`](/slides/python-net/it/aspose.slides/iviewproperties/last_view/) | Specifica la modalità di visualizzazione che è stata usata quando il documento della presentazione è stato salvato l'ultima volta.<br/>            Lettura/scrittura [`ViewType`](/slides/python-net/it/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/it/aspose.slides/iviewproperties/show_comments/) | Specifica se i commenti della diapositiva devono essere mostrati.<br/>            Lettura/scrittura [`NullableBool`](/slides/python-net/it/aspose.slides/nullablebool). |
| [`slide_view_properties`](/slides/python-net/it/aspose.slides/iviewproperties/slide_view_properties/) | Specifica le proprietà di visualizzazione comuni associate alla modalità di visualizzazione della diapositiva.<br/>            Sola lettura [`ICommonSlideViewProperties`](/slides/python-net/it/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/it/aspose.slides/iviewproperties/notes_view_properties/) | Specifica le proprietà di visualizzazione comuni associate alla modalità di visualizzazione delle note.<br/>            Sola lettura [`ICommonSlideViewProperties`](/slides/python-net/it/aspose.slides/icommonslideviewproperties). |
| [`normal_view_properties`](/slides/python-net/it/aspose.slides/iviewproperties/normal_view_properties/) | Rappresenta le proprietà di visualizzazione normali. La vista normale è composta da<br/>            tre regioni di contenuto: la diapositiva stessa, una regione di contenuto laterale e una regione di contenuto inferiore.<br/>            Sola lettura [`INormalViewProperties`](/slides/python-net/it/aspose.slides/inormalviewproperties). |
| [`grid_spacing`](/slides/python-net/it/aspose.slides/iviewproperties/grid_spacing/) | Restituisce o imposta la spaziatura della griglia da utilizzare per la griglia sottostante al documento della presentazione, in punti. <br/>            Lettura/scrittura **float**. |
