## get_font_bytes(self, font_data, font_style) {#ifontdata-fontstyletype}
Recupera l'array di byte che rappresenta i dati del font per uno stile di font specificato e per i dati del font.

### Restituisce

Un array di byte contenente i dati del font per lo stile di font specificato. Se i dati del font o lo stile non vengono trovati, restituisce None.
