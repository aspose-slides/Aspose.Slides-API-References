## TableFormat classe

Rappresenta il formato di una tabella.

Il tipo TableFormat espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`fill_format`](/slides/python-net/it/aspose.slides/tableformat/fill_format/) | Restituisce un oggetto di proprietà di riempimento della tabella.<br/>            Solo lettura [`IFillFormat`](/slides/python-net/it/aspose.slides/ifillformat). |
| [`transparency`](/slides/python-net/it/aspose.slides/tableformat/transparency/) | Ottiene o imposta la trasparenza del colore di riempimento.<br/>            Lettura/scrittura **float**. |

## Metodi

| Metodo | Descrizione |
| :- | :- |
| [`get_effective(self)`](/slides/python-net/it/aspose.slides/tableformat/get_effective/#) | Ottiene le proprietà di formattazione della tabella effettive con ereditarietà e stili di tabella applicati. |
