## IParagraph classe

Rappresenta un paragrafo di testo.

Il tipo IParagraph espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`portions`](/slides/python-net/it/aspose.slides/iparagraph/portions/) | Restituisce la raccolta di porzioni di testo.<br/>            Sola lettura [`IPortionCollection`](/slides/python-net/it/aspose.slides/iportioncollection). |
| [`paragraph_format`](/slides/python-net/it/aspose.slides/iparagraph/paragraph_format/) | Restituisce l'oggetto di formattazione per questo paragrafo.<br/>            Sola lettura [`IParagraphFormat`](/slides/python-net/it/aspose.slides/iparagraphformat). |
| [`text`](/slides/python-net/it/aspose.slides/iparagraph/text/) | Ottiene o imposta il testo semplice di un paragrafo.<br/>            Lettura/scrittura **str**. |
| [`end_paragraph_portion_format`](/slides/python-net/it/aspose.slides/iparagraph/end_paragraph_portion_format/) | Specifica le proprietà della porzione da utilizzare se un'altra porzione viene inserita dopo <br/>            l'ultima. |
| [`slide`](/slides/python-net/it/aspose.slides/iparagraph/slide/) |  |
| [`presentation`](/slides/python-net/it/aspose.slides/iparagraph/presentation/) |  |

## Metodi

| Metodo | Descrizione |
| :- | :- |
| [`get_image`](/slides/python-net/it/aspose.slides/iparagraph/get_image/#) | Restituisce un'immagine del paragrafo. |
| [`get_image`](/slides/python-net/it/aspose.slides/iparagraph/get_image/#float-float) | Restituisce un'immagine del paragrafo con la scala specificata. |
| [`join_portions_with_same_formatting`](/slides/python-net/it/aspose.slides/iparagraph/join_portions_with_same_formatting/#) | Unisce le sequenze con la stessa formattazione. |
| [`get_rect`](/slides/python-net/it/aspose.slides/iparagraph/get_rect/#) | Ottiene le coordinate del rettangolo che delimita il paragrafo. Il rettangolo include tutte le linee di<br/>            testo nel paragrafo, incluse quelle vuote. |
| [`get_lines_count`](/slides/python-net/it/aspose.slides/iparagraph/get_lines_count/#) | Ottiene il numero di linee in un paragrafo. |
