## ShapeAdjustmentType enumerazione

Specifica diversi tipi di valori di regolazione della forma.

Il tipo ShapeAdjustmentType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| CUSTOM | Tipo personalizzato (regolazione sconosciuta) |
| CORNER_SIZE | Controlla la dimensione degli angoli. |
| LEFT_UP_CORNER | Controlla l'angolo in alto a sinistra. |
| RIGHT_UP_CORNER | Controlla l'angolo in alto a destra. |
| UP_CORNERS | Controlla gli angoli superiori. |
| DOWN_CORNERS | Controlla gli angoli inferiori. |
| THICKNESS | Controlla lo spessore della figura. |
| ARROW_TAIL_THICKNESS | Controlla lo spessore della coda della freccia. |
| ARROWHEAD_LENGTH | Controlla la lunghezza della punta della freccia. |
| ARROWHEAD_WIDTH | Controlla la larghezza della punta della freccia. |
| RADIUS | Controlla la dimensione del raggio della forma o della sua parte. |
| DEPTH | Controlla la profondità dei denti dell'ingranaggio o l'effetto smusso. |
| SHAPE_PART_OFFSET | Controlla lo spostamento di una parte della figura rispetto a un'altra. |
| ANGLE | Controlla l'angolo per la figura o la sua parte. |
| START_ANGLE | Angolo di partenza per le forme a torta e ad arco. |
| END_ANGLE | Angolo finale per le forme a torta e ad arco. |
| START_POINT_X | Controlla la posizione X del punto di inizio del richiamo. |
| START_POINT_Y | Controlla la posizione Y del punto di inizio del richiamo. |
| CONNECTOR_POINT_1X | Controlla la posizione orizzontale del punto di regolazione dell'angolo del richiamo. |
| CONNECTOR_POINT_1Y | Controlla la posizione verticale del punto di regolazione dell'angolo del richiamo. |
| CONNECTOR_POINT_2X | Controlla la posizione orizzontale del punto di regolazione dell'angolo del richiamo. |
| CONNECTOR_POINT_2Y | Controlla la posizione verticale del punto di regolazione dell'angolo del richiamo. |
| CONNECTOR_BEND_POSITION_X | Controlla la posizione orizzontale della piega nel connettore. |
| CONNECTOR_BEND_POSITION_Y | Controlla la posizione verticale della piega nel connettore. |
| ATTACH_Y | Controlla il punto di attacco verticale della figura. |
| ATTACH_X | Controlla il punto di attacco orizzontale della figura. |
| CALLOUT_HEIGHT | Controlla la dimensione verticale del richiamo. |
| CALLOUT_WIDTH | Controlla la dimensione orizzontale del richiamo. |
| CALLOUT_SIZE | Controlla la dimensione del richiamo. |
| CURVATURE | Curvatura di una piega, parentesi graffa, freccia curva o forma. |
| HORIZONTAL_THICKNESS | Controlla lo spessore orizzontale della forma d'angolo. |
| VERTICAL_THICKNESS | Controlla lo spessore verticale della forma d'angolo. |
| VERTICAL_SIZE | Controlla la dimensione verticale della forma. |
| HORIZONTAL_SIZE | Controlla la dimensione orizzontale della forma. |
| TOP | Controlla il lato superiore di una forma. |
