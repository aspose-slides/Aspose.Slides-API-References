## remove(self, item) {#iparagraph}
Rimuove la prima occorrenza di un oggetto specifico dalla **System.Collections.Generic.ICollection`1**.

### Restituisce

true se `item` è stato rimosso con successo dalla **System.Collections.Generic.ICollection`1**; altrimenti, false. Questo metodo restituisce anche false se `item` non è stato trovato nella **System.Collections.Generic.ICollection`1** originale.



```python
def remove(self, item):
    ...
```


| Parametro | Tipo | Descrizione |
| :- | :- | :- |
| item | [`IParagraph`](/slides/python-net/it/aspose.slides/iparagraph) | L'oggetto da rimuovere dalla **System.Collections.Generic.ICollection`1**. |

### Eccezioni

| Eccezione | Descrizione |
| :- | :- |
| **RuntimeError(Proxy error(NotSupportedException))** | La **System.Collections.Generic.ICollection`1** è di sola lettura. |
