## ViewProperties classe

Il tipo ViewProperties espone i seguenti membri:

## Proprietà

| Property | Description |
| :- | :- |
| [`last_view`](/slides/python-net/it/aspose.slides/viewproperties/last_view/) | Specifica la modalità di visualizzazione utilizzata quando il documento della presentazione è stato salvato l'ultima volta.<br/>            Lettura/scrittura [`ViewType`](/slides/python-net/it/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/it/aspose.slides/viewproperties/show_comments/) | Specifica se i commenti della diapositiva devono essere mostrati.<br/>            Lettura/scrittura [`NullableBool`](/slides/python-net/it/aspose.slides/nullablebool). |
| [`normal_view_properties`](/slides/python-net/it/aspose.slides/viewproperties/normal_view_properties/) | Rappresenta le proprietà della visualizzazione normale. La visualizzazione normale è composta da<br/>            tre regioni di contenuto: la diapositiva stessa, una regione di contenuto laterale e una regione di contenuto inferiore.<br/>            Solo lettura [`INormalViewProperties`](/slides/python-net/it/aspose.slides/inormalviewproperties). |
| [`slide_view_properties`](/slides/python-net/it/aspose.slides/viewproperties/slide_view_properties/) | Specifica le proprietà di visualizzazione comuni associate alla modalità di visualizzazione della diapositiva.<br/>            Solo lettura [`ICommonSlideViewProperties`](/slides/python-net/it/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/it/aspose.slides/viewproperties/notes_view_properties/) | Specifica le proprietà di visualizzazione comuni associate alla modalità di visualizzazione delle note.<br/>            Solo lettura [`ICommonSlideViewProperties`](/slides/python-net/it/aspose.slides/icommonslideviewproperties). |
| [`grid_spacing`](/slides/python-net/it/aspose.slides/viewproperties/grid_spacing/) | Restituisce o imposta la spaziatura della griglia da utilizzare per la griglia sottostante al documento della presentazione, in punti. <br/>            Lettura/scrittura **float**. |
