## split_text_by_columns(self) {#}
Divide il contenuto testuale del [`ITextFrame`](/slides/python-net/it/aspose.slides/itextframe) in un array di stringhe,  
            dove ogni elemento corrisponde a una colonna di testo separata all'interno del riquadro.

### Restituisce

Un array di stringhe, dove ogni stringa rappresenta il contenuto testuale di una colonna specifica nel [`ITextFrame`](/slides/python-net/it/aspose.slides/itextframe).


```python
def split_text_by_columns(self):
    ...
```


### Osservazioni

Se il riquadro di testo non contiene più colonne, l'array restituito avrà un unico elemento  
            contenente l'intero testo.  
            Le colonne vuote saranno rappresentate come stringhe vuote nell'array.
