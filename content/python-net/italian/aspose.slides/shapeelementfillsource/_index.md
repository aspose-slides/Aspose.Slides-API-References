## ShapeElementFillSource enumerazione

Rappresenta come l'elemento shape dovrebbe essere riempito.

Il tipo ShapeElementFillSource espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| NO_FILL | Non riempire il primitivo. |
| SHAPE | Usa il riempimento dello shape. |
| LIGHTEN | Usa il riempimento del shape schiarito. |
| LIGHTEN_LESS | Usa il riempimento del shape meno schiarito. |
| DARKEN | Usa il riempimento del shape scurito. |
| DARKEN_LESS | Usa il riempimento del shape meno scurito. |
