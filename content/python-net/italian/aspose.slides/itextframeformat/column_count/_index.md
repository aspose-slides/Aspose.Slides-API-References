## column_count proprietà
Restituisce o imposta il numero di colonne nell'area di testo.
            Questo valore deve essere un numero positivo. Altrimenti, il valore verrà impostato a zero. 
            Il valore 0 indica un valore non definito.
            Lettura/scrittura **int**.
