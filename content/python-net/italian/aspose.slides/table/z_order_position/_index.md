## z_order_position proprietà
Restituisce la posizione di una forma nell'ordine z.
            Shapes[0] restituisce la forma sul retro dell'ordine z,
            e Shapes[Shapes.Count - 1] restituisce la forma sul davanti dell'ordine z.
            Sola lettura **int**.
