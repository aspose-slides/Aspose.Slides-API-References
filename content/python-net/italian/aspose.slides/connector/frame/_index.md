## proprietà del frame
Restituisce o imposta le proprietà del frame della forma.
            Lettura/scrittura [`IShapeFrame`](/slides/python-net/it/aspose.slides/ishapeframe).

### Osservazioni

Il valore di ciascuna proprietà dell'istanza IShapeFrame restituita non è 
            non definito (non è NaN o NotDefined).
            Il valore di ciascuna proprietà dell'istanza IShapeFrame assegnata deve non essere 
            non definito (deve non essere NaN o NotDefined).
            È possibile impostare valori non definiti per le proprietà dell'istanza RawFrame.
