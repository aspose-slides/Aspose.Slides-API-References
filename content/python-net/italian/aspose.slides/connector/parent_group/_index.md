## parent_group proprietà
Restituisce l'oggetto GroupShape padre se la forma è raggruppata. Altrimenti restituisce None.
            Solo lettura [`IGroupShape`](/slides/python-net/it/aspose.slides/igroupshape).


### Note

Proprietà [`Shape.is_grouped`](/slides/python-net/it/aspose.slides/shape/is_grouped) determina se la forma è raggruppata.
