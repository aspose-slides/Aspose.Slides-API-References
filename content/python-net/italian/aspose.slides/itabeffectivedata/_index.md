## ITabEffectiveData classe

Oggetto immutabile che contiene le proprietà di arresto di tabulazione del testo effettivo.

Il tipo ITabEffectiveData espone i seguenti membri:

## Proprietà

| Property | Description |
| :- | :- |
| [`position`](/slides/python-net/it/aspose.slides/itabeffectivedata/position/) | Returns position of a tab.<br/>            Assigning this property can change tab's index in collection and invalidate Enumerator.<br/>            Read-only **float**. |
| [`alignment`](/slides/python-net/it/aspose.slides/itabeffectivedata/alignment/) | Returns align style of a tab.<br/>            Read-only [`TabAlignment`](/slides/python-net/it/aspose.slides/tabalignment). |

### Osservazioni

This interface is used as a part of [`IParagraphFormatEffectiveData`](/slides/python-net/it/aspose.slides/iparagraphformateffectivedata).
