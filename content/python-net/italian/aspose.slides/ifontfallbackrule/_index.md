## IFontFallBackRule classe

Rappresenta la regola di fallback dei caratteri

Il tipo IFontFallBackRule espone i seguenti membri:

## Proprietà

| Property | Description |
| :- | :- |
| [`range_start_index`](/slides/python-net/it/aspose.slides/ifontfallbackrule/range_start_index/) | Ottiene il primo indice dell'intervallo Unicode continuo. |
| [`range_end_index`](/slides/python-net/it/aspose.slides/ifontfallbackrule/range_end_index/) | Ottiene l'ultimo indice dell'intervallo Unicode continuo. |
| [`count`](/slides/python-net/it/aspose.slides/ifontfallbackrule/count/) | Ottiene il numero di caratteri effettivamente definiti per l'intervallo. |

Ottiene il nome del carattere all'indice specificato.
