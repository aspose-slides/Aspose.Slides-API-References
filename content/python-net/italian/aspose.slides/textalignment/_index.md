## enumerazione TextAlignment

Rappresenta diversi stili di allineamento del testo.

Il tipo TextAlignment espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| NOT_DEFINED | Allineamento predefinito. |
| LEFT | Allineamento a sinistra. |
| CENTER | Allineamento al centro. |
| RIGHT | Allineamento a destra. |
| JUSTIFY | Allineamento giustificato. |
| JUSTIFY_LOW | Giustificazione Kashida bassa. |
| DISTRIBUTED | Allineamento distribuito. |
