## enumerazione ShapesAlignmentType

Definisce un modo per modificare la posizione delle forme selezionate nella diapositiva.

Il tipo ShapesAlignmentType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| ALIGN_LEFT | Allinea a sinistra |
| ALIGN_RIGHT | Allinea a destra |
| ALIGN_CENTER | Allinea al centro |
| ALIGN_TOP | Allinea in alto |
| ALIGN_MIDDLE | Allinea al centro verticale |
| ALIGN_BOTTOM | Allinea in basso |
| DISTRIBUTE_HORIZONTALLY | Distribuisci orizzontalmente |
| DISTRIBUTE_VERTICALLY | Distribuisci verticalmente |
