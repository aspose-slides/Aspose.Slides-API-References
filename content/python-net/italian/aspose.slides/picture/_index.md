## Picture classe

Rappresenta un'immagine in una presentazione.

Il tipo Picture espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`image`](/slides/python-net/it/aspose.slides/picture/image/) | Restituisce o imposta l'immagine incorporata.<br/>            Lettura/Scrittura [`IPPImage`](/slides/python-net/it/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/it/aspose.slides/picture/link_path_long/) | Restituisce o imposta l'URL dell'immagine collegata.<br/>            Lettura/Scrittura **str**. |
| [`image_transform`](/slides/python-net/it/aspose.slides/picture/image_transform/) | Restituisce la collezione di effetti di trasformazione dell'immagine.<br/>            Sola lettura [`IImageTransformOperationCollection`](/slides/python-net/it/aspose.slides.effects/iimagetransformoperationcollection). |
| [`presentation`](/slides/python-net/it/aspose.slides/picture/presentation/) | Restituisce la presentazione.<br/>            Sola lettura [`IPresentation`](/slides/python-net/it/aspose.slides/ipresentation). |
| [`slide`](/slides/python-net/it/aspose.slides/picture/slide/) | Restituisce la diapositiva genitore di un'immagine.<br/>            Sola lettura [`IBaseSlide`](/slides/python-net/it/aspose.slides/ibaseslide). |
