## get_rotation(self) {#}
Una rotazione è definita mediante l'uso di una coordinata di latitudine,
una coordinata di longitudine e una rivoluzione attorno all'asse come le coordinate di latitudine e longitudine.
primo elemento nell'array restituito - latitudine, secondo - longitudine, terzo - rivoluzione.
Restituisce None se nessuna rotazione è definita.

### Restituisce

Array di valori di rotazione come **float**[].
