## IInterruptionToken classe

Questa classe rappresenta il token da utilizzare per segnalare a operazioni di lunga durata se è stata richiesta l'interruzione.

Il tipo IInterruptionToken espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`is_interruption_requested`](/slides/python-net/it/aspose.slides/iinterruptiontoken/is_interruption_requested/) | Restituisce **bool**.true se l'interruzione è stata richiesta. |

## Metodi

| Metodo | Descrizione |
| :- | :- |
| [`throw_if_interruption_requested(self)`](/slides/python-net/it/aspose.slides/iinterruptiontoken/throw_if_interruption_requested/#) | Lancia un OperationCanceledException se<br/>            l'interruzione è stata richiesta.<br/>            Lanciato quando l'interruzione è stata richiesta. |
