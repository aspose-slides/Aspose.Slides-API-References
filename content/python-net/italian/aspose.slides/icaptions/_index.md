## ICaptions classe

Rappresenta i sottotitoli chiusi WebVTT.

Il tipo ICaptions espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`caption_id`](/slides/python-net/it/aspose.slides/icaptions/caption_id/) | Restituisce l'identificatore univoco globale (GUID) dei sottotitoli chiusi.<br/>            Solo lettura **System.Guid**. |
| [`label`](/slides/python-net/it/aspose.slides/icaptions/label/) | Restituisce o imposta l'etichetta dei sottotitoli chiusi.<br/>            Lettura/scrittura **str**. |
| [`binary_data`](/slides/python-net/it/aspose.slides/icaptions/binary_data/) | Restituisce i dati binari dei sottotitoli chiusi.<br/>            Solo lettura **int**[]. |
| [`data_as_string`](/slides/python-net/it/aspose.slides/icaptions/data_as_string/) | Restituisce i dati dei sottotitoli chiusi come stringa codificata UTF-8<br/>            Solo lettura **str**. |
