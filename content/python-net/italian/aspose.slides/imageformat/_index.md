## enumerazione ImageFormat

Rappresenta il formato file dell'immagine.

Il tipo ImageFormat espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| MEMORY_BMP | Rappresenta il formato di un bitmap in memoria. |
| BMP | Rappresenta il formato immagine bitmap (BMP). |
| EMF | Rappresenta il formato immagine metafile migliorato (EMF). |
| WMF | Rappresenta il formato immagine metafile Windows (WMF). |
| GIF | Rappresenta il formato immagine Graphics Interchange Format (GIF). |
| JPEG | Rappresenta il formato immagine Joint Photographic Experts Group (JPEG). |
| PNG | Rappresenta il formato immagine W3C Portable Network Graphics (PNG). |
| TIFF | Rappresenta il formato immagine Tagged Image File Format (TIFF). |
| EXIF | Rappresenta il formato Exchangeable Image File (Exif). |
| ICON | Rappresenta il formato immagine icona Windows. |
