## ITextStyle classe

Proprietà di formattazione dello stile del testo.

Il tipo ITextStyle espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`default_paragraph_format`](/slides/python-net/it/aspose.slides/itextstyle/default_paragraph_format/) | Proprietà predefinite del paragrafo.<br/>            Solo lettura [`IParagraphFormat`](/slides/python-net/it/aspose.slides/iparagraphformat). |

## Metodi

| Metodo | Descrizione |
| :- | :- |
| [`get_level(self, index)`](/slides/python-net/it/aspose.slides/itextstyle/get_level/#int) | Se il livello di stile esiste lo restituisce, altrimenti restituisce None. |
| [`get_effective(self)`](/slides/python-net/it/aspose.slides/itextstyle/get_effective/#) | Ottiene i dati di formattazione effettiva dello stile del testo con l'ereditarietà applicata. |
