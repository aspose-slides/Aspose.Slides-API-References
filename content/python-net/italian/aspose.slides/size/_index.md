## Size classe

Memorizza una coppia ordinata di interi, che specificano una larghezza e un'altezza. Compatibile con .NET `System.Drawing.Size`.

Il tipo Size espone i seguenti membri:

## Costruttori

| Costruttore | Descrizione |
| :- | :- |
| [`__init__(self, width=0, height=0)`](/slides/python-net/it/aspose.slides/size/__init__/#int-int) | Crea una size con la larghezza e l'altezza specificate. I valori float sono troncati a interi. |

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`width`](/slides/python-net/it/aspose.slides/size/width/) | Restituisce la componente orizzontale di questa size.<br/>            Solo lettura **int**. |
| [`height`](/slides/python-net/it/aspose.slides/size/height/) | Restituisce la componente verticale di questa size.<br/>            Solo lettura **int**. |

### Osservazioni

Le size sono confrontate per le loro componenti con `==` e possono essere usate come chiavi di dizionario o membri di set.
