## ISvgImage classe

Rappresenta un'immagine SVG.

Il tipo ISvgImage espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`svg_content`](/slides/python-net/it/aspose.slides/isvgimage/svg_content/) | Restituisce il contenuto SVG.<br/>            Sola lettura **str**. |
| [`svg_data`](/slides/python-net/it/aspose.slides/isvgimage/svg_data/) | Restituisce i dati SVG.<br/>            Sola lettura **int**[]. |
| [`external_resource_resolver`](/slides/python-net/it/aspose.slides/isvgimage/external_resource_resolver/) | Restituisce l'interfaccia di callback utilizzata per risolvere le risorse esterne durante l'importazione di documenti SVG.<br/>            Sola lettura **IExternalResourceResolver**. |
| [`base_uri`](/slides/python-net/it/aspose.slides/isvgimage/base_uri/) | Restituisce l'URI di base dell'SVG specificato. Usato per risolvere collegamenti relativi.<br/>            Sola lettura **str**. |

## Metodi

| Metodo | Descrizione |
| :- | :- |
| [`write_as_emf(self, stream)`](/slides/python-net/it/aspose.slides/isvgimage/write_as_emf/#iorawiobase) | Salva l'immagine SVG come file EMF. |
