## Enumerazione PersistenceType

Specifica il metodo utilizzato per memorizzare le proprietà del controllo ActiveX.

Il tipo PersistenceType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| NOT_DEFINED | ID di persistenza non specificato. |
| PERSIST_PROPERTY_BAG | Specifica che il controllo ActiveX è persistito usando persistenza basata su property-bag. <br/> La persistenza basata su property-bag memorizza un controllo ActiveX mediante una raccolta di coppie nome e valore che specificano i dati persistiti dal controllo ActiveX. |
| PERSIST_STREAM | Specifica che il controllo ActiveX è persistito usando una persistenza basata su stream che non supporta l'inizializzazione del controllo ActiveX in uno stato predefinito. |
| PERSIST_STREAM_INIT | Specifica che il controllo ActiveX è persistito usando una persistenza basata su stream che supporta l'inizializzazione del controllo ActiveX in uno stato predefinito. |
| PERSIST_STORAGE | Specifica che il controllo ActiveX è persistito usando una persistenza basata su storage. |
