## IWarningInfo classe

Rappresenta un'interfaccia di base per tutti gli avvisi.

Il tipo IWarningInfo espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`warning_type`](/slides/python-net/it/aspose.slides.warnings/iwarninginfo/warning_type/) | Restituisce un tipo di avviso.<br/>            Solo lettura [`IWarningInfo.warning_type`](/slides/python-net/it/aspose.slides.warnings/iwarninginfo/warning_type). |
| [`description`](/slides/python-net/it/aspose.slides.warnings/iwarninginfo/description/) | Restituisce una descrizione leggibile da un umano di questo avviso.<br/>            Solo lettura **str**. |

## Metodi

| Metodo | Descrizione |
| :- | :- |
| [`send_warning(self, receiver)`](/slides/python-net/it/aspose.slides.warnings/iwarninginfo/send_warning/#iwarningcallback) | Se il ricevitore non è None termina l'avviso a un ricevitore specificato e lancia l<br/>            AbortRequestedException se il ricevitore decide di abortire un'operazione. |
