## Classi

| Class | Descrizione |
| :- | :- |
| [`IKnownIssueWarningInfo`](/slides/python-net/it/aspose.slides.warnings/iknownissuewarninginfo/) | Rappresenta un avviso relativo a un problema noto che non verrà risolto nel prossimo futuro. |
| [`INotImplementedWarningInfo`](/slides/python-net/it/aspose.slides.warnings/inotimplementedwarninginfo/) | Rappresenta un avviso relativo a una funzionalità nota non implementata che non sarà implementata nel prossimo futuro. |
| [`IObsoletePresLockingBehaviorWarningInfo`](/slides/python-net/it/aspose.slides.warnings/iobsoletepreslockingbehaviorwarninginfo/) | Questo avviso indica che viene utilizzato un comportamento di blocco della presentazione obsoleto. |
| [`IPresentationSignedWarningInfo`](/slides/python-net/it/aspose.slides.warnings/ipresentationsignedwarninginfo/) | Questo avviso indica che la presentazione letta ha la firma <br/>            e questa firma verrà rimossa durante l'elaborazione. |
| [`IWarningCallback`](/slides/python-net/it/aspose.slides.warnings/iwarningcallback/) | Interfaccia per le classi che ricevono avvisi |
| [`IWarningInfo`](/slides/python-net/it/aspose.slides.warnings/iwarninginfo/) | Rappresenta un'interfaccia base per tutti gli avvisi. |
