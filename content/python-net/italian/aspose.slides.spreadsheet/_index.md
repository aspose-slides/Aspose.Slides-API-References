Contiene classi per lavorare con oggetti foglio di calcolo nelle presentazioni Microsoft PowerPoint.
## Classi

| Classe | Descrizione |
| :- | :- |
| [`CellCircularReferenceException`](/slides/python-net/it/aspose.slides.spreadsheet/cellcircularreferenceexception/) | L'eccezione che viene sollevata quando uno o più riferimenti circolari vengono rilevati dove una formula si riferisce alla sua<br/>            propria cella direttamente o indirettamente. |
| [`CellInvalidFormulaException`](/slides/python-net/it/aspose.slides.spreadsheet/cellinvalidformulaexception/) | L'eccezione che viene sollevata quando una formula calcolata non è corretta o non è stata analizzata. |
| [`CellInvalidReferenceException`](/slides/python-net/it/aspose.slides.spreadsheet/cellinvalidreferenceexception/) | L'eccezione che viene sollevata quando viene incontrato un riferimento di cella non valido. |
| [`CellUnsupportedDataException`](/slides/python-net/it/aspose.slides.spreadsheet/cellunsupporteddataexception/) | L'eccezione che viene sollevata quando vengono incontrati dati non supportati in una cella di foglio di calcolo. |
