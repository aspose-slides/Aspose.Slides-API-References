## proprietà del frame
Restituisce o imposta le proprietà del frame della forma.
            Lettura/Scrittura [`IShapeFrame`](/slides/python-net/it/aspose.slides/ishapeframe).

### Osservazioni

Il valore di ogni proprietà dell'istanza IShapeFrame restituita non è 
            undefined (non è NaN o NotDefined).
            Il valore di ogni proprietà dell'istanza IShapeFrame assegnata deve non 
            essere undefined (deve non essere NaN o NotDefined).
            È possibile impostare valori undefined per le proprietà dell'istanza RawFrame.
