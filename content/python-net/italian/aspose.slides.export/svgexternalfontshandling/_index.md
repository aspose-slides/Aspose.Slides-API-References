## SvgExternalFontsHandling enumeration

Rappresenta un modo per gestire i font esterni utilizzati per il disegno del testo.

Il tipo SvgExternalFontsHandling espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| ADD_LINKS_TO_FONT_FILES | Aggiunge collegamenti a file di font separati nella sezione style del file SVG. |
| EMBED | Salva i dati dei font direttamente nel file SVG. Verificare tutti gli accordi di licenza dei font esterni prima di utilizzare questa opzione. |
| VECTORIZE | Salva tutto il testo che utilizza font esterni come grafica. |
