## enumerazione CompressionLevel

Specifica i livelli di compressione ZIP per il file OpenXML.
            Livelli più alti forniscono una compressione migliore a scapito di un'elaborazione più lenta.

Il tipo CompressionLevel espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| NONE | Nessuna compressione viene applicata. I file vengono memorizzati così come sono. |
| LEVEL1 | Compressione più veloce con il rapporto di compressione più basso. |
| LEVEL2 | Compressione più veloce con un rapporto di compressione leggermente migliore rispetto a [`CompressionLevel.LEVEL1`](/slides/python-net/it/aspose.slides.export/compressionlevel/LEVEL1). |
| LEVEL3 | Fornisce una compressione migliore rispetto a [`CompressionLevel.LEVEL2`](/slides/python-net/it/aspose.slides.export/compressionlevel/LEVEL2) con un impatto sulle prestazioni moderato. |
| LEVEL4 | Fornisce una compressione migliore rispetto a [`CompressionLevel.LEVEL3`](/slides/python-net/it/aspose.slides.export/compressionlevel/LEVEL3). |
| LEVEL5 | Fornisce una compressione migliorata rispetto a [`CompressionLevel.LEVEL4`](/slides/python-net/it/aspose.slides.export/compressionlevel/LEVEL4) con tempo di elaborazione aggiuntivo. |
| LEVEL6 | Compressione standard, offrendo un buon equilibrio tra velocità di compressione e dimensione del file.<br/>            Il livello di compressione predefinito. |
| LEVEL7 | Fornisce una compressione più alta rispetto a [`CompressionLevel.LEVEL6`](/slides/python-net/it/aspose.slides.export/compressionlevel/LEVEL6) con un'elaborazione più lenta. |
| LEVEL8 | Fornisce una compressione più alta rispetto a [`CompressionLevel.LEVEL7`](/slides/python-net/it/aspose.slides.export/compressionlevel/LEVEL7). |
| LEVEL9 | Compressione massima. Produce la dimensione di file più piccola con la velocità di elaborazione più lenta. |
