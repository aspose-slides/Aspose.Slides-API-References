## Enumerazione NotesPositions

Rappresenta la regola per visualizzare le note nel documento esportato

Il tipo NotesPositions espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| NONE | Specifica che le note non devono essere visualizzate affatto. |
| BOTTOM_FULL | Specifica che le note devono essere visualizzate per intero utilizzando pagine aggiuntive se necessario. |
| BOTTOM_TRUNCATED | Specifica che le note devono essere visualizzate in una sola pagina. |
