## SvgEvent enumerazione

Rappresenta le opzioni per la forma SVG.

Il tipo SvgEvent espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| ON_FOCUS_IN | Si verifica quando un elemento riceve il focus, ad esempio quando un testo viene selezionato. |
| ON_FOCUS_OUT | Si verifica quando un elemento perde il focus, ad esempio quando un testo non è più selezionato. |
| ON_ACTIVATE | Si verifica quando un elemento viene attivato, ad esempio mediante un clic del mouse o una pressione di un tasto. |
| ON_CLICK | Si verifica quando il pulsante del dispositivo di puntamento viene cliccato su un elemento. |
| ON_MOUSE_DOWN | Si verifica quando il pulsante del dispositivo di puntamento viene premuto su un elemento. |
| ON_MOUSE_UP | Si verifica quando il pulsante del dispositivo di puntamento viene rilasciato su un elemento. |
| ON_MOUSE_OVER | Si verifica quando il dispositivo di puntamento viene spostato su un elemento. |
| ON_MOUSE_MOVE | Si verifica quando il dispositivo di puntamento viene spostato mentre è sopra un elemento. |
| ON_MOUSE_OUT | Si verifica quando il dispositivo di puntamento si sposta lontano da un elemento. |
| ON_LOAD | Si verifica quando l'agente utente ha analizzato completamente l'elemento e i suoi discendenti e tutte le risorse referenziate necessarie per renderizzarlo. |
| ON_UNLOAD | Si verifica quando l'implementazione DOM rimuove un documento da una finestra o da un frame. Valido solo per gli elementi svg più esterni. |
| ON_ABORT | Si verifica quando il caricamento della pagina viene interrotto prima che un elemento abbia potuto caricarsi completamente. |
| ON_ERROR | Si verifica quando un elemento non viene caricato correttamente o quando si verifica un errore durante l'esecuzione di uno script. |
| ON_RESIZE | Si verifica quando la vista del documento viene ridimensionata. Valido solo per gli elementi svg più esterni. |
| ON_SCROLL | Si verifica quando la vista del documento viene spostata lungo l'asse X o Y o entrambi. Valido solo per gli elementi svg più esterni. |
| ON_ZOOM | Si verifica quando il livello di zoom della vista del documento viene modificato. Valido solo per gli elementi svg più esterni. |
| ON_BEGIN | Si verifica quando un elemento di animazione inizia. |
| ON_END | Si verifica quando un elemento di animazione termina. |
| ON_REPEAT | Si verifica quando un elemento di animazione si ripete. |
