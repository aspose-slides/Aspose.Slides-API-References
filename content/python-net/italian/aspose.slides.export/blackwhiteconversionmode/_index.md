## BlackWhiteConversionMode enumerazione

Fornisce opzioni che controllano come le immagini delle diapositive verranno convertite in immagini bitonali.

Il tipo BlackWhiteConversionMode espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| DEFAULT | Specifica nessun algoritmo di conversione. Verrà utilizzato l'algoritmo implementato nel codec TIFF. (Predefinito) |
| DITHERING | Specifica l'algoritmo di dithering (Floyd-Steinberg). |
| DITHERING_FLOYD_STEINBERG | Specifica l'algoritmo di dithering Floyd-Steinberg. |
| AUTO | Specifica l'algoritmo di soglia calcolato automaticamente (Otsu). |
| AUTO_OTSU | Specifica l'algoritmo di soglia Otsu calcolato automaticamente. |
| THRESHOLD25 | Specifica l'algoritmo di soglia statico (25%). |
| THRESHOLD50 | Specifica l'algoritmo di soglia statico (50%). |
| THRESHOLD75 | Specifica l'algoritmo di soglia statico (75%). |
