## PdfCompliance enumerazione

Costanti che definiscono il livello di conformità agli standard PDF.

Il tipo PdfCompliance espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| PDF15 | Il file di output sarà conforme allo standard PDF 1.5. |
| PDF16 | Il file di output sarà conforme allo standard PDF 1.6. |
| PDF17 | Il file di output sarà conforme allo standard PDF 1.7. |
| PDF_A1B | Il file di output sarà conforme allo standard PDF/A-1b. |
| PDF_A1A | Il file di output sarà conforme allo standard PDF/A-1a. |
| PDF_A2B | Il file di output sarà conforme allo standard PDF/A-2b. |
| PDF_A2A | Il file di output sarà conforme allo standard PDF/A-2a. |
| PDF_A3B | Il file di output sarà conforme allo standard PDF/A-3b. |
| PDF_A3A | Il file di output sarà conforme allo standard PDF/A-3a. |
| PDF_UA | Il file di output sarà conforme allo standard PDF/UA. |
| PDF_A2U | Il file di output sarà conforme allo standard PDF/A-2u. |
