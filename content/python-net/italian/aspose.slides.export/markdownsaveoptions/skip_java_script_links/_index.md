## skip_java_script_links proprietà
Specifica se saltare i collegamenti ipertestuali con chiamate JavaScript durante il salvataggio della presentazione. 
            Lettura/scrittura **bool**. Il valore predefinito è **false** .


### Osservazioni

When this property is set to **true** , hyperlinks with JavaScript calls will be ignored while saving.


When this property is set to **false** , all hyperlinks will be saved.
