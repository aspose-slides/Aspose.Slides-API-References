## TextInheritanceLimit enumerazione

Controlla la profondità dell'ereditarietà delle proprietà del testo.

Il tipo TextInheritanceLimit espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| ALL | Eredita tutte le proprietà del testo. |
| TEXT_BOX | Eredita solo dallo stile di TextFrame. |
| PARAGRAPH_ONLY | Usa solo le proprietà definite per il paragrafo. |
