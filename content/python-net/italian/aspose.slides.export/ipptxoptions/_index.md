## IPptxOptions classe

Rappresenta le opzioni per salvare presentazioni OpenXml (PPTX, PPSX, POTX, PPTM, PPSM, POTM).

Il tipo IPptxOptions espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`conformance`](/slides/python-net/it/aspose.slides.export/ipptxoptions/conformance/) | Specifica la classe di conformità a cui il documento Presentation è conforme.<br/>            Il valore predefinito è [`Conformance.ECMA_376_2006`](/slides/python-net/it/aspose.slides.export/conformance/ECMA_376_2006) |
| [`zip_64_mode`](/slides/python-net/it/aspose.slides.export/ipptxoptions/zip_64_mode/) | Specifica se il formato ZIP64 è usato per il documento Presentation.<br/>            Il valore predefinito è [`Zip64Mode.IF_NECESSARY`](/slides/python-net/it/aspose.slides.export/zip64mode/IF_NECESSARY) |
| [`refresh_thumbnail`](/slides/python-net/it/aspose.slides.export/ipptxoptions/refresh_thumbnail/) | Specifica se la miniatura della presentazione sarà aggiornata.<br/>            Lettura/scrittura **bool**.<br/>            Il valore predefinito è **true**. |
| [`compression_level`](/slides/python-net/it/aspose.slides.export/ipptxoptions/compression_level/) | Specifica il livello di compressione utilizzato durante il salvataggio del documento della presentazione.<br/>            Il valore predefinito è [`CompressionLevel.LEVEL6`](/slides/python-net/it/aspose.slides.export/compressionlevel/LEVEL6). |
| [`warning_callback`](/slides/python-net/it/aspose.slides.export/ipptxoptions/warning_callback/) |  |
