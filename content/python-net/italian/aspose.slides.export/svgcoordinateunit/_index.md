## SvgCoordinateUnit enumerazione

Rappresenta le unità di coordinate CSS2 utilizzate per definire le coordinate SVG.

Il tipo SvgCoordinateUnit espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| INCH | Pollice |
| CENTIMETER | Centimetro. |
| MILLIMETER | Millimetro. |
| POINT | Punto (1/72 di pollice), |
| PICA | Pica (1/6 di pollice). |
| EM | Dimensione em di un font dell'elemento contenente. |
| EX | Dimensione ex (dimensione della lettera minuscola, di solito "x") del font dell'elemento contenente. |
| PIXEL | Dimensione pixel. |
| PERCENT | Percentuale. |
