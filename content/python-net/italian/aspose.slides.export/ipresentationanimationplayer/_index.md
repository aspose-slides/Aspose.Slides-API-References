## IPresentationAnimationPlayer classe

Rappresenta un lettore dell'animazione.
            
            Animazioni generate da [`PresentationAnimationsGenerator`](/slides/python-net/it/aspose.slides.export/presentationanimationsgenerator) tramite il suo evento **NewAnimation**.

Il tipo IPresentationAnimationPlayer espone i seguenti membri:

## Proprietà

| Property | Description |
| :- | :- |
| [`duration`](/slides/python-net/it/aspose.slides.export/ipresentationanimationplayer/duration/) | Ottiene la durata dell'animazione [ms] |

## Metodi

| Method | Description |
| :- | :- |
| [`set_time_position(self, time)`](/slides/python-net/it/aspose.slides.export/ipresentationanimationplayer/set_time_position/#float) | Imposta la posizione temporale dell'animazione all'interno del [`IPresentationAnimationPlayer.duration`](/slides/python-net/it/aspose.slides.export/ipresentationanimationplayer/duration). |
| [`get_frame(self)`](/slides/python-net/it/aspose.slides.export/ipresentationanimationplayer/get_frame/#) | Ottiene il frame per la posizione temporale corrente precedentemente impostata con il metodo **Aspose.Slides.Export.IPresentationAnimationPlayer.SetTimePosition(Syste**. |
