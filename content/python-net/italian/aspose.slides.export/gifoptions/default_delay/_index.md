## default_delay proprietà
Ottiene o imposta il tempo di ritardo predefinito [ms]. Questo valore verrà utilizzato se [`ISlideShowTransition.advance_after_time`](/slides/python-net/it/aspose.slides/islideshowtransition/advance_after_time) non è impostato.
            Il valore predefinito è 1000.
