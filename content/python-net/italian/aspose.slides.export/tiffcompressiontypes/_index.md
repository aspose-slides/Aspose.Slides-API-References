## TiffCompressionTypes enumerazione

Fornisce opzioni che controllano come una presentazione viene compressa nel formato TIFF.

Il tipo TiffCompressionTypes espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| DEFAULT | Specifica lo schema di compressione predefinito (LZW). |
| NONE | Specifica nessuna compressione. |
| CCITT3 | Specifica lo schema di compressione CCITT3. |
| CCITT4 | Specifica lo schema di compressione CCITT4. |
| LZW | Specifica lo schema di compressione LZW (Predefinito). |
| RLE | Specifica lo schema di compressione RLE. |
