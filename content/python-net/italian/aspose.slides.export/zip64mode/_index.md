## Zip64Mode enumerazione

Specifica quando usare le estensioni del formato ZIP64 per il file OpenXML.

Il tipo Zip64Mode espone i seguenti membri:

## Campi

| Field | Description |
| :- | :- |
| NEVER | Non utilizzare le estensioni del formato ZIP64. |
| IF_NECESSARY | Utilizzare le estensioni del formato ZIP64 se necessario. |
| ALWAYS | Utilizzare sempre le estensioni del formato ZIP64. |


### Osservazioni

Il file OpenXML è un archivio ZIP che ha un limite di 4 GB (2^32 byte) sulla dimensione non compressa di un file, sulla dimensione compressa di un file e sulla dimensione totale dell'archivio, così come un limite di 65.535 (2^16-1) file nell'archivio. Le estensioni del formato ZIP64 aumentano i limiti a 2^64.
