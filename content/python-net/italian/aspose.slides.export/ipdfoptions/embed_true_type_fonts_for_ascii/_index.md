## embed_true_type_fonts_for_ascii proprietà
True per incorporare i font TrueType per i caratteri ASCII 32-127.
            I font per i codici di carattere superiori a 127 sono sempre incorporati.
            Lettura/scrittura **bool**.


### Osservazioni

Il valore predefinito è **true** .
