## PicturesCompression enumerazione

Rappresenta il livello di compressione delle immagini

Il tipo PicturesCompression espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| DPI330 | Buona qualità per display ad alta definizione (HD) |
| DPI220 | Qualità eccellente sulla maggior parte di stampanti e schermi |
| DPI150 | Buono per pagine web e proiettori |
| DPI96 | Minimizza le dimensioni del documento per la condivisione |
| DPI72 | Livello di compressione predefinito |
| DOCUMENT_RESOLUTION | Usa la risoluzione del documento - l'immagine non verrà compressa e sarà usata nel documento così com'è |
