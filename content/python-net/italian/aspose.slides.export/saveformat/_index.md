## Enumerazione SaveFormat

Costanti che definiscono il formato di una presentazione salvata.

Il tipo SaveFormat espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| PPT | Salva la presentazione in formato PPT. |
| PDF | Salva la presentazione in formato PDF. |
| XPS | Salva la presentazione in formato XPS. |
| PPTX | Salva la presentazione in formato PPTX. |
| PPSX | Salva la presentazione in formato PPSX (presentazione). |
| TIFF | Salva la presentazione come immagine TIFF multi-pagina. |
| ODP | Salva la presentazione in formato ODP. |
| PPTM | Salva la presentazione in formato PPTM (presentazione con macro). |
| PPSM | Salva la presentazione in formato PPSM (presentazione con macro). |
| POTX | Salva la presentazione in formato POTX (modello). |
| POTM | Salva la presentazione in formato POTM (modello con macro). |
| HTML | Salva la presentazione in formato HTML. |
| SWF | Salva la presentazione in formato SWF. |
| OTP | Salva la presentazione in formato OTP (modello di presentazione). |
| PPS | Salva la presentazione in formato PPS. |
| POT | Salva la presentazione in formato POT. |
| FODP | Salva la presentazione in formato FODP. |
| GIF | Salva la presentazione in formato GIF. |
| HTML5 | Salva la presentazione in formato HTML usando il nuovo sistema di templating HTML5. |
| MD | Salva la presentazione in formato Markdown |
| XML | Salva la presentazione in formato PowerPoint XML Presentation. |
