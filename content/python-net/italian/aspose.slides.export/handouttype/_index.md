## HandoutType enumerazione

Specifica quante diapositive e in quale sequenza saranno posizionate nella pagina.

Il tipo HandoutType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| HANDOUTS1 | Una diapositiva per pagina. |
| HANDOUTS2 | Due diapositive per pagina. |
| HANDOUTS3 | Tre diapositive per pagina. |
| HANDOUTS_4_HORIZONTAL | Quattro diapositive per pagina in una sequenza orizzontale. |
| HANDOUTS_4_VERTICAL | Quattro diapositive per pagina in una sequenza verticale. |
| HANDOUTS_6_HORIZONTAL | Sei diapositive per pagina in una sequenza orizzontale. |
| HANDOUTS_6_VERTICAL | Sei diapositive per pagina in una sequenza verticale. |
| HANDOUTS_9_HORIZONTAL | Nove diapositive per pagina in una sequenza orizzontale. |
| HANDOUTS_9_VERTICAL | Nove diapositive per pagina in una sequenza verticale. |
