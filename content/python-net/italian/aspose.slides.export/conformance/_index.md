## Conformance enumerazione

Specifica la classe di conformità a cui il documento PresentationML è conforme.

Il tipo Conformance espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| ECMA_376_2006 | Specifica che il documento è conforme a ECMA376:2006. |
| ISO_29500_2008_TRANSITIONAL | Specifica che il documento è conforme alla classe di conformità ISO/IEC 29500:2008 Transitional. |
| ISO_29500_2008_STRICT | Specifica che il documento è conforme alla classe di conformità ISO/IEC 29500:2008 Strict. |
