## BehaviorCollection classe

Rappresenta una raccolta di effetti di comportamento.

Il tipo BehaviorCollection espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`count`](/slides/python-net/it/aspose.slides.animation/behaviorcollection/count/) | Restituisce il numero di comportamenti in una raccolta.<br/>            Sola lettura **int**. |
| [`is_read_only`](/slides/python-net/it/aspose.slides.animation/behaviorcollection/is_read_only/) | Ottiene un valore che indica se il **System.Collections.Generic.ICollection`1** è di sola lettura.<br/>            Sola lettura **bool**. |

Restituisce un comportamento all'indice specificato.

## Indicizzatore

| Nome | Descrizione |
| :- | :- |
| [`[index]`](/slides/python-net/it/aspose.slides.animation/behaviorcollection/__getitem__/) | Indice di un comportamento da restituire. |
