## ITiming classe

Rappresenta la temporizzazione dell'animazione.

Il tipo ITTiming espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`accelerate`](/slides/python-net/it/aspose.slides.animation/itiming/accelerate/) | Descrive la percentuale dell'effetto di accelerazione della durata.<br/>            Lettura/scrittura **float**. |
| [`decelerate`](/slides/python-net/it/aspose.slides.animation/itiming/decelerate/) | Descrive la percentuale dell'effetto di decelerazione della durata.<br/>            Lettura/scrittura **float**. |
| [`auto_reverse`](/slides/python-net/it/aspose.slides.animation/itiming/auto_reverse/) | Descrive se riprodurre automaticamente l'animazione al contrario dopo<br/>            averla riprodotta nella direzione avanti.<br/>            Lettura/scrittura **bool**. |
| [`duration`](/slides/python-net/it/aspose.slides.animation/itiming/duration/) | Descrive la durata dell'effetto di animazione.<br/>            Lettura/scrittura **float**. |
| [`repeat_count`](/slides/python-net/it/aspose.slides.animation/itiming/repeat_count/) | Descrive il numero di volte in cui l'effetto deve ripetersi.<br/>            Lettura/scrittura **float**. |
| [`repeat_until_end_slide`](/slides/python-net/it/aspose.slides.animation/itiming/repeat_until_end_slide/) | Questo attributo specifica se l'effetto si ripeterà fino alla fine della diapositiva.<br/>             Lettura/scrittura **bool**. |
| [`repeat_until_next_click`](/slides/python-net/it/aspose.slides.animation/itiming/repeat_until_next_click/) | Questo attributo specifica se l'effetto si ripeterà fino al prossimo clic.<br/>             Lettura/scrittura **bool**. |
| [`repeat_duration`](/slides/python-net/it/aspose.slides.animation/itiming/repeat_duration/) | Descrive il numero di volte in cui l'effetto deve ripetersi.<br/>            Lettura/scrittura **float**. |
| [`restart`](/slides/python-net/it/aspose.slides.animation/itiming/restart/) | Specifica se un effetto deve ricominciare dopo il completamento.<br/>            Lettura/scrittura [`EffectRestartType`](/slides/python-net/it/aspose.slides.animation/effectrestarttype). |
| [`speed`](/slides/python-net/it/aspose.slides.animation/itiming/speed/) | Specifica la percentuale di accelerazione (o rallentamento) della temporizzazione.<br/>            Lettura/scrittura **float**. |
| [`trigger_delay_time`](/slides/python-net/it/aspose.slides.animation/itiming/trigger_delay_time/) | Descrive il tempo di ritardo dopo il trigger.<br/>            Lettura/scrittura **float**. |
| [`trigger_type`](/slides/python-net/it/aspose.slides.animation/itiming/trigger_type/) | Descrive il tipo di trigger.<br/>            Lettura/scrittura [`EffectTriggerType`](/slides/python-net/it/aspose.slides.animation/effecttriggertype). |
| [`rewind`](/slides/python-net/it/aspose.slides.animation/itiming/rewind/) | Questo attributo specifica se l'effetto verrà riavvolto una volta terminata la riproduzione.<br/>             Lettura/scrittura **bool**. |
