## Enumerazione AnimateTextType

Rappresenta il tipo di testo animato di un effetto di animazione.

Il tipo AnimateTextType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| ALL_AT_ONCE | Anima tutto il testo in una volta. |
| BY_WORD | Anima il testo parola per parola. |
| BY_LETTER | Anima il testo lettera per lettera. |
