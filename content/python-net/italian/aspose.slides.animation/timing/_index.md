## classe Timing

Rappresenta la temporizzazione dell'animazione.

Il tipo Timing espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`accelerate`](/slides/python-net/it/aspose.slides.animation/timing/accelerate/) | Descrive la percentuale della durata dell'effetto di accelerazione del comportamento.<br/>Lettura/scrittura **float**. |
| [`decelerate`](/slides/python-net/it/aspose.slides.animation/timing/decelerate/) | Descrive la percentuale della durata dell'effetto di decelerazione del comportamento.<br/>Lettura/scrittura **float**. |
| [`auto_reverse`](/slides/python-net/it/aspose.slides.animation/timing/auto_reverse/) | Descrive se riprodurre automaticamente l'animazione al contrario dopo averla riprodotta in avanti.<br/>Lettura/scrittura **bool**. |
| [`duration`](/slides/python-net/it/aspose.slides.animation/timing/duration/) | Descrive la durata dell'effetto di animazione.<br/>Lettura/scrittura **float**. |
| [`repeat_count`](/slides/python-net/it/aspose.slides.animation/timing/repeat_count/) | Descrive il numero di volte in cui l'effetto deve ripetersi.<br/>Lettura/scrittura **float**. |
| [`repeat_until_end_slide`](/slides/python-net/it/aspose.slides.animation/timing/repeat_until_end_slide/) | Questo attributo specifica se l'effetto verrà ripetuto fino alla fine della diapositiva.<br/>Lettura/scrittura **bool**. |
| [`repeat_until_next_click`](/slides/python-net/it/aspose.slides.animation/timing/repeat_until_next_click/) | Questo attributo specifica se l'effetto verrà ripetuto fino al prossimo clic.<br/>Lettura/scrittura **bool**. |
| [`repeat_duration`](/slides/python-net/it/aspose.slides.animation/timing/repeat_duration/) | Descrive il numero di volte in cui l'effetto deve ripetersi.<br/>Lettura/scrittura **float**. |
| [`restart`](/slides/python-net/it/aspose.slides.animation/timing/restart/) | Specifica se un effetto deve ricominciare dopo il completamento.<br/>Lettura/scrittura [`EffectRestartType`](/slides/python-net/it/aspose.slides.animation/effectrestarttype). |
| [`rewind`](/slides/python-net/it/aspose.slides.animation/timing/rewind/) | Questo attributo specifica se l'effetto verrà riavvolto al termine della riproduzione.<br/>Lettura/scrittura **bool**. |
| [`speed`](/slides/python-net/it/aspose.slides.animation/timing/speed/) | Specifica la percentuale con cui accelerare (o rallentare) la temporizzazione.<br/>Lettura/scrittura **float**. |
| [`trigger_delay_time`](/slides/python-net/it/aspose.slides.animation/timing/trigger_delay_time/) | Descrive il tempo di ritardo dopo il trigger.<br/>Lettura/scrittura **float**. |
| [`trigger_type`](/slides/python-net/it/aspose.slides.animation/timing/trigger_type/) | Descrive il tipo di trigger.<br/>Lettura/scrittura [`EffectTriggerType`](/slides/python-net/it/aspose.slides.animation/effecttriggertype). |
