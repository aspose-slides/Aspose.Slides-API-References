## AnimationTimeLine classe

Rappresenta la timeline dell'animazione.

Il tipo AnimationTimeLine espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`interactive_sequences`](/slides/python-net/it/aspose.slides.animation/animationtimeline/interactive_sequences/) | Restituisce la collezione di sequenze interattive.<br/>            Questa sequenze possono contenere solo effetti mediante "click on shape" con la forma target specificata.<br/>            Solo lettura [`ISequenceCollection`](/slides/python-net/it/aspose.slides.animation/isequencecollection). |
| [`main_sequence`](/slides/python-net/it/aspose.slides.animation/animationtimeline/main_sequence/) | Restituisce la sequenza principale che può contenere solo la collezione di effetti principali.<br/>            Solo lettura [`ISequence`](/slides/python-net/it/aspose.slides.animation/isequence). |
| [`text_animation_collection`](/slides/python-net/it/aspose.slides.animation/animationtimeline/text_animation_collection/) | Restituisce la collezione di animazioni di testo.<br/>            Solo lettura [`ITextAnimationCollection`](/slides/python-net/it/aspose.slides.animation/itextanimationcollection). |
