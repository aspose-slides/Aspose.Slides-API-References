## IMotionEffect classe

Rappresenta il comportamento dell'effetto di movimento.

Il tipo IMotionEffect espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`from_address`](/slides/python-net/it/aspose.slides.animation/imotioneffect/from_address/) | Specifica una coordinata x/y da cui avviare l'animazione (in percentuale). <br/> Lettura/scrittura **aspose.slides.PointF**. |
| [`to`](/slides/python-net/it/aspose.slides.animation/imotioneffect/to/) | Specifica la posizione target per un effetto di movimento dell'animazione (in percentuale).<br/> Lettura/scrittura **aspose.slides.PointF**. |
| [`by`](/slides/python-net/it/aspose.slides.animation/imotioneffect/by/) | Descrive il valore di offset relativo per l'animazione (in percentuale).<br/> Lettura/scrittura **aspose.slides.PointF**. |
| [`rotation_center`](/slides/python-net/it/aspose.slides.animation/imotioneffect/rotation_center/) | Descrive il centro della rotazione usato per ruotare un percorso di movimento di un angolo X.<br/> Lettura/scrittura **aspose.slides.PointF**. |
| [`origin`](/slides/python-net/it/aspose.slides.animation/imotioneffect/origin/) | Specifica a cosa è relativo l'origine del percorso di movimento, ad esempio al layout della diapositiva,<br/> o al genitore.<br/> Lettura/scrittura [`MotionOriginType`](/slides/python-net/it/aspose.slides.animation/motionorigintype). |
| [`path`](/slides/python-net/it/aspose.slides.animation/imotioneffect/path/) | Specifica il primitivo del percorso seguito da coordinate per il movimento dell'animazione.<br/> Lettura/scrittura [`IMotionPath`](/slides/python-net/it/aspose.slides.animation/imotionpath). |
| [`path_edit_mode`](/slides/python-net/it/aspose.slides.animation/imotioneffect/path_edit_mode/) | Specifica come si muove il percorso di movimento quando la forma viene spostata.<br/> Lettura/scrittura [`MotionPathEditMode`](/slides/python-net/it/aspose.slides.animation/motionpatheditmode). |
| [`angle`](/slides/python-net/it/aspose.slides.animation/imotioneffect/angle/) | Descrive l'angolo relativo del percorso di movimento.<br/> Lettura/scrittura **float**. |
