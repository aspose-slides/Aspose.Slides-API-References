## IMotionEffect classe

Rappresenta il comportamento dell'effetto di movimento.

Il tipo IMotionEffect espone i seguenti membri:

## Proprietà

| Proprietà | Descrizione |
| :- | :- |
| [`from_`](/slides/python-net/it/aspose.slides.animation/imotioneffect/from_/) | Specifica una coordinata x/y da cui avviare l'animazione (in percentuale). <br/>            Lettura/Scrittura [`PointF`](/slides/python-net/it/aspose.slides/pointf). |
| [`to`](/slides/python-net/it/aspose.slides.animation/imotioneffect/to/) | Specifica la posizione target per un effetto di movimento dell'animazione (in percentuale).<br/>            Lettura/Scrittura [`PointF`](/slides/python-net/it/aspose.slides/pointf). |
| [`by`](/slides/python-net/it/aspose.slides.animation/imotioneffect/by/) | Descrive il valore di offset relativo per l'animazione (in percentuale).<br/>            Lettura/Scrittura [`PointF`](/slides/python-net/it/aspose.slides/pointf). |
| [`rotation_center`](/slides/python-net/it/aspose.slides.animation/imotioneffect/rotation_center/) | Descrive il centro della rotazione utilizzato per ruotare un percorso di movimento di X gradi.<br/>            Lettura/Scrittura [`PointF`](/slides/python-net/it/aspose.slides/pointf). |
| [`origin`](/slides/python-net/it/aspose.slides.animation/imotioneffect/origin/) | Specifica a cosa è relativo l'origine del percorso di movimento, ad esempio al layout della diapositiva,<br/>            o al genitore.<br/>            Lettura/Scrittura [`MotionOriginType`](/slides/python-net/it/aspose.slides.animation/motionorigintype). |
| [`path`](/slides/python-net/it/aspose.slides.animation/imotioneffect/path/) | Specifica la primitiva del percorso seguita dalle coordinate per il movimento dell'animazione.<br/>            Lettura/Scrittura [`IMotionPath`](/slides/python-net/it/aspose.slides.animation/imotionpath). |
| [`path_edit_mode`](/slides/python-net/it/aspose.slides.animation/imotioneffect/path_edit_mode/) | Specifica come si muove il percorso di movimento quando la forma viene spostata.<br/>            Lettura/Scrittura [`MotionPathEditMode`](/slides/python-net/it/aspose.slides.animation/motionpatheditmode). |
| [`angle`](/slides/python-net/it/aspose.slides.animation/imotioneffect/angle/) | Descrive l'angolo relativo del percorso di movimento.<br/>            Lettura/Scrittura **float**. |
