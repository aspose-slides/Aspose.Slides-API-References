## BuildType enumerazione

Determina come il testo apparirà su una forma durante l'animazione.

Il tipo BuildType espone i seguenti membri:

## Campi

| Campo | Descrizione |
| :- | :- |
| AS_ONE_OBJECT | Con la forma contenente. |
| ALL_PARAGRAPHS_AT_ONCE | Tutti i paragrafi. |
| BY_LEVEL_PARAGRAPHS1 | Per gruppi di paragrafi di profondità 1. |
| BY_LEVEL_PARAGRAPHS2 | Per gruppi di paragrafi di profondità 2. |
| BY_LEVEL_PARAGRAPHS3 | Per gruppi di paragrafi di profondità 3. |
| BY_LEVEL_PARAGRAPHS4 | Per gruppi di paragrafi di profondità 4. |
| BY_LEVEL_PARAGRAPHS5 | Per gruppi di paragrafi di profondità 5. |
