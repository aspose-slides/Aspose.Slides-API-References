## bullet_fill_format свойство
Возвращает объект FillFormat, который содержит свойства форматирования заливки для маркера узла.
            Примечание: может вернуть None для некоторых типов макета SmartArt, которые не предоставляют маркеры для узлов.
            Только для чтения [`IFillFormat`](/slides/python-net/ru/aspose.slides/ifillformat).
