## width свойство
Получает или задает width фигуры, измеренную в пунктах.
            Чтение/запись **float**.


### Примечания

Возвращаемое значение всегда определено и никогда не **float**.
            Значение, присваиваемое также должно быть определено; присваивайте **float** только свойствам экземпляра `RawFrame`.
