## x свойство
Получает или задает координату x верхнего левого угла фигуры, измеренную в пунктах.
            Чтение/запись **float**.

### Примечания

Возвращаемое значение всегда определено и никогда не **float**.
            Назначаемое значение также должно быть определено; назначайте **float** только свойствам экземпляра `RawFrame`.

### Определение:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
