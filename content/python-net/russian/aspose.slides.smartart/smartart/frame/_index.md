## Свойство frame
Возвращает или задаёт свойства рамки фигуры.
Чтение/запись [`IShapeFrame`](/slides/python-net/ru/aspose.slides/ishapeframe).


### Примечания

Значение каждого свойства возвращённого экземпляра IShapeFrame не является undefined (это не NaN и не NotDefined).
Значение каждого свойства назначенного экземпляра IShapeFrame должно быть не undefined (должно быть не NaN и не NotDefined).
Вы можете устанавливать значения undefined для свойств экземпляра RawFrame.

### Определение:
```python
@property
def frame(self):
    ...

@frame.setter
def frame(self, value):
    ...
```
