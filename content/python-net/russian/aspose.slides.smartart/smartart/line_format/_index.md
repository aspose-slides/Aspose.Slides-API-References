## line_format свойство
Returns the LineFormat object that contains line formatting properties for a shape.
            Примечание: может возвращать None для некоторых типов фигур, у которых нет свойств линии.
            Только для чтения [`ILineFormat`](/slides/python-net/ru/aspose.slides/ilineformat).
