## SmartArtLayoutType перечисление

Представляет тип макета диаграммы SmartArt.

Тип SmartArtLayoutType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| ACCENT_PROCESS | Используется для отображения прогрессии, временной шкалы или последовательных шагов в задаче, процессе или рабочем потоке. Хорошо подходит для иллюстрации текста уровней 1 и 2. |
| ACCENTED_PICTURE | Используется для отображения центральной фотографической идеи с связанными идеями по бокам. Текст верхнего уровня 1 появляется над центральным изображением. Соответствующий текст для остальных фигур уровня 1 располагается рядом с малыми круговыми изображениями. Этот макет также хорошо работает без текста. |
| ALTERNATING_FLOW | Используется для отображения групп информации или последовательных шагов в задаче, процессе или рабочем потоке. Подчеркивает взаимодействие или взаимосвязи между группами информации. |
| ALTERNATING_HEXAGONS | Используется для представления серии взаимосвязанных идей. Текст уровня 1 отображается внутри шестиугольников. Текст уровня 2 — снаружи фигур. |
| ALTERNATING_PICTURE_BLOCKS | Используется для отображения серии изображений сверху вниз. Текст чередуется справа и слева от изображения. |
| ALTERNATING_PICTURE_CIRCLES | Используется для отображения набора изображений с текстом. Соответствующий текст появляется в центральных кругах, при этом изображения чередуются слева направо. |
| ARROW_RIBBON | Используется для отображения связанных или контрастных концепций с некоторой связью, например противоположных сил. Первые две строки текста уровня 1 используются в стрелках. Неиспользуемый текст не отображается, но остаётся доступным при переключении макетов. |
| ASCENDING_PICTURE_ACCENT_PROCESS | Используется для отображения восходящей серии изображений с описательным текстом. Лучше всего подходит для небольшого объёма текста. |
| BALANCE | Используется для сравнения или отображения взаимосвязи между двумя идеями. Каждая из первых двух строк текста уровня 1 соответствует тексту в верхней части одной из сторон центральной точки. Подчеркивает текст уровня 2, ограниченный четырьмя фигурами с каждой стороны центральной точки. Баланс наклоняется в сторону, где больше фигур с текстом уровня 2. Неиспользуемый текст не отображается, но остаётся доступным при переключении макетов. |
| BASIC_BENDING_PROCESS | Используется для отображения прогрессии или последовательных шагов в задаче, процессе или рабочем потоке. Максимизирует как горизонтальное, так и вертикальное пространство для фигур. |
| BASIC_BLOCK_LIST | Используется для отображения непоследовательных или сгруппированных блоков информации. Максимизирует как горизонтальное, так и вертикальное пространство для фигур. |
| BASIC_CHEVRON_PROCESS | Используется для отображения прогрессии, временной шкалы, последовательных шагов в задаче, процессе или рабочем потоке, а также для подчёркивания движения или направления. Текст уровня 1 отображается внутри фигуры-стрелки, текст уровня 2 — под стрелками. |
| BASIC_CYCLE | Используется для представления непрерывной последовательности стадий, задач или событий в круговом потоке. Подчеркивает стадии или шаги, а не соединительные стрелки. Лучше всего подходит только для текста уровня 1. |
| BASIC_MATRIX | Используется для отображения взаимосвязи компонентов с целым в квадрантах. Первые четыре строки текста уровня 1 помещаются в квадранты. Неиспользуемый текст не отображается, но остаётся доступным при переключении макетов. |
| BASIC_PIE | Используется для отображения того, как отдельные части образуют целое. Первые семь строк текста уровня 1 соответствуют равномерно распределённым секторам или кусочкам диаграммы. Верхняя фигура текста уровня 1 располагается за пределами остальной части диаграммы для акцента. Неиспользуемый текст не отображается, но остаётся доступным при переключении макетов. |
| BASIC_PROCESS | Используется для отображения прогрессии или последовательных шагов в задаче, процессе или рабочем потоке. |
| BASIC_PYRAMID | Используется для отображения пропорциональных, взаимосвязанных или иерархических отношений с крупнейшим компонентом внизу и сужающимся вверх. Текст уровня 1 отображается в сегментах пирамиды, текст уровня 2 — в фигурах рядом с каждым сегментом. |
| BASIC_RADIAL | Используется для отображения отношения к центральной идее в цикле. Первая строка текста уровня 1 соответствует центральной фигуре, а её текст уровня 2 — окружающим круговым фигурам. Неиспользуемый текст не отображается, но остаётся доступным при переключении макетов. |
| BASIC_TARGET | Используется для отображения вложения, градаций или иерархических отношений. Первые пять строк текста уровня 1 связаны с кругом. Неиспользуемый текст не отображается, но остаётся доступным при переключении макетов. |
| BASIC_TIMELINE | Используется для отображения последовательных шагов в задаче, процессе или рабочем потоке, а также для показа информации по временной шкале. Хорошо подходит для текста уровней 1 и 2. |
| BASIC_VENN | Используется для отображения перекрывающихся или взаимосвязанных отношений. Первые семь строк текста уровня 1 соответствуют кругу. Если строк уровня 1 четыре или меньше, текст размещён внутри кругов; если их больше четырёх — снаружи кругов. Неиспользуемый текст не отображается, но остаётся доступным при переключении макетов. |
| BENDING_PICTURE_ACCENT_LIST | Используется для отображения непоследовательных или сгруппированных блоков информации. Маленькие круговые фигуры предназначены для размещения изображений. Хорошо подходит для иллюстрации как текста уровня 1, так и уровня 2. Максимизирует как горизонтальное, так и вертикальное пространство для фигур. |
| BENDING_PICTURE_BLOCKS | Используется для отображения серии изображений. Нижний угол-коробка может содержать небольшие объёмы текста. |
| BENDING_PICTURE_CAPTION | Используется для отображения последовательной серии изображений. Нижний угол-коробка может содержать небольшие объёмы текста. |
| BENDING_PICTURE_CAPTION_LIST | Используется для отображения серии изображений. Заголовок и описание появляются в фигурe-вызове под каждым изображением. |
| BENDING_PICTURE_SEMI_TRANSPARENT_TEXT | Используется для отображения серии изображений. Полупрозрачный блок покрывает нижнюю часть изображения и содержит все уровни текста. |
| BLOCK_CYCLE | Используется для представления непрерывной последовательности стадий, задач или событий в круговом потоке. Подчеркивает стадии или шаги, а не соединительные стрелки. |
| BUBBLE_PICTURE_LIST | Используется для отображения серии изображений. Может содержать до восьми изображений уровня 1. Неиспользуемый текст и изображения не отображаются, но остаются доступными при переключении макетов. Лучше всего подходит для небольшого объёма текста. |
| CAPTIONED_PICTURES | Используется для отображения изображений с несколькими уровнями текста. Лучше всего подходит для небольшого количества текста уровня 1 и среднего объёма текста уровня 2. |
| CHEVRON_LIST | Используется для отображения прогрессии через несколько процессов, составляющих общий рабочий поток. Также подходит для иллюстрации контрастных процессов. Текст уровня 1 соответствует первой фигуре-стрелке слева, а текст уровня 2 — горизонтальным подшагам для каждой фигуры, содержащей текст уровня 1. |
| CIRCLE_ACCENT_TIMELINE | Используется для отображения серии событий или информации по временной шкале. Текст уровня 1 располагается рядом с большими круговыми фигурами. Текст уровня 2 — рядом с малыми круговыми фигурами. |
| CIRCLE_ARROW_PROCESS | Используется для отображения последовательных элементов с поддерживающим текстом для каждого элемента. Эта диаграмма лучше всего подходит для небольших объёмов текста уровня 1. |
| CIRCLE_PICTURE_HIERARCHY | Используется для отображения иерархической информации или отношений отчётности в организации. Изображения помещаются в круги, соответствующий текст — рядом с изображениями. |
| CIRCLE_RELATIONSHIP | Используется для отображения отношения к центральной идее или от неё. Текст уровня 2 добавляется непоследовательно и ограничен пятью элементами. Может быть только один элемент уровня 1. |
| CIRCULAR_BENDING_PROCESS | Используется для отображения длинной или нелинейной последовательности шагов в задаче, процессе или рабочем потоке. Лучше всего подходит только для текста уровня 1. Максимизирует как горизонтальное, так и вертикальное пространство для фигур. |
| CIRCULAR_PICTURE_CALLOUT | Используется для отображения центральной идеи и подидей или связанных элементов. Текст для первого изображения покрывает нижнюю часть изображения. Соответствующий текст для других фигур уровня 1 появляется рядом с малыми круговыми изображениями. Эта диаграмма также хорошо работает без текста. |
| CLOSED_CHEVRON_PROCESS | Используется для отображения прогрессии, временной шкалы или последовательных шагов в задаче, процессе или рабочем потоке, а также для подчёркивания движения или направления. Может использоваться для акцентирования информации в начальной фигуре. Лучше всего подходит только для текста уровня 1. |
| CONTINUOUS_ARROW_PROCESS | Используется для отображения временной шкалы или последовательных шагов в задаче, процессе или рабочем потоке. Лучше всего подходит для текста уровня 1, так как каждая строка текста уровня 1 помещается внутри фигуры-стрелки. Текст уровня 2 располагается снаружи фигуры-стрелки. |
| CONTINUOUS_BLOCK_PROCESS | Используется для отображения прогрессии или последовательных шагов в задаче, процессе или рабочем потоке. Лучше всего подходит для минимального объёма текста уровней 1 и 2. |
| CONTINUOUS_CYCLE | Используется для представления непрерывной последовательности стадий, задач или событий в круговом потоке. Подчеркивает связь между всеми компонентами. Лучше всего подходит только для текста уровня 1. |
| CONTINUOUS_PICTURE_LIST | Используется для отображения групп взаимосвязанной информации. Круговые фигуры предназначены для размещения изображений. |
| CONVERGING_ARROWS | Используется для отображения идей или концепций, сходящихся к центральной точке. Лучше всего подходит только для текста уровня 1. |
| CONVERGING_RADIAL | Используется для отображения взаимосвязей концепций или компонентов с центральной идеей в цикле. Первая строка текста уровня 1 соответствует центральной круговой фигуре, а строки текста уровня 2 — окружающим прямоугольным фигурам. Неиспользуемый текст не отображается, но остаётся доступным при переключении макетов. |
| COUNTERBALANCE_ARROWS | Используется для отображения двух противоположных идей или концепций. Каждая из первых двух строк текста уровня 1 соответствует стрелке и хорошо сочетается с текстом уровня 2. Неиспользуемый текст не отображается, но остаётся доступным при переключении макетов. |
| CYCLE_MATRIX | Используется для отображения отношения к центральной идее в циклической прогрессии. Каждая из первых четырёх строк текста уровня 1 соответствует сектору или кусочку диаграммы, а текст уровня 2 располагается в прямоугольной фигуре рядом с сектором. Неиспользуемый текст не отображается, но остаётся доступным при переключении макетов. |
| DESCENDING_BLOCK_LIST | Используется для отображения групп связанных идей или списков информации. Фигуры текста последовательно уменьшаются в высоте, а текст уровня 1 отображается вертикально. |
| DESCENDING_PROCESS | Используется для отображения нисходящей серии событий. Первый текст уровня 1 находится в верхней части стрелки, а последний текст уровня 1 — в нижней части стрелки. Появляются только первые семь элементов уровня 1. Лучше всего подходит для небольшого-среднего объёма текста. |

Подчеркивает окружающие круги, а не центральную идею. Неиспользуемый текст не отображается, но остаётся доступным при переключении макетов. |

Может содержать до четырёх строк текста уровня 1; последняя из этих четырёх строк находится под воронкой, остальные — соответствуют круговой фигуре. Неиспользуемый текст не отображается, но остаётся доступным при переключении макетов. |

Неиспользуемый текст не отображается, но остаётся доступным при переключении макетов. |

Текст уровня 1 соответствует верхним уровневым горизонтальным фигурам, а текст уровня 2 — вертикальным подпунктам под каждой соответствующей верхней фигурой. | CUSTOM | Представляет диаграмму SmartArt с пользовательским шаблоном раскладки |
| PICTURE_ORGANIZATION_CHART | Используется для отображения иерархической информации или отношений подчинения в организации с соответствующими изображениями. Фигуры помощника и висячие раскладки организационной диаграммы доступны с этой раскладкой. |
