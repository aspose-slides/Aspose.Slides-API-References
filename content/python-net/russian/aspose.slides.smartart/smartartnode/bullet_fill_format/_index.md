## bullet_fill_format свойство
Возвращает объект FillFormat, который содержит свойства форматирования заполнения для маркера узла.
            Примечание: может возвращать None для некоторых типов компоновки SmartArt, которые не предоставляют маркеры для узлов.
            Только для чтения [`IFillFormat`](/slides/python-net/ru/aspose.slides/ifillformat).
