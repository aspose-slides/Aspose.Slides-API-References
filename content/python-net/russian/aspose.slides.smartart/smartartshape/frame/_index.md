## свойство frame
Возвращает или задает свойства рамки фигуры.
            Чтение/запись [`IShapeFrame`](/slides/python-net/ru/aspose.slides/ishapeframe).


### Замечания

Значение каждого свойства возвращённого экземпляра IShapeFrame не 
            неопределённым (не NaN или NotDefined).
            Значение каждого свойства назначенного экземпляра IShapeFrame должно быть не 
            неопределённым (должно быть не NaN или NotDefined).
            Вы можете задавать неопределённые значения свойствам экземпляра RawFrame.
