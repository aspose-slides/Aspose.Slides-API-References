## fill_format свойство
Возвращает объект FillFormat, который содержит свойства заливки для фигуры.
            Примечание: может вернуть None для определенных типов фигур, у которых нет свойств заливки.
            Только чтение [`IFillFormat`](/slides/python-net/ru/aspose.slides/ifillformat).
