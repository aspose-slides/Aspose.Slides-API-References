## width свойство
Получает или задает width формы, измеряемую в пунктах.
Чтение/запись **float**.


### Примечания

Возвращаемое значение всегда определено и никогда не **float**.
Присваиваемое значение также должно быть определено; присваивайте **float** только свойствам экземпляра `RawFrame`.
