## rotation свойство
Возвращает или задаёт количество градусов, на которое указанная фигура повернута вокруг оси z. Положительное значение означает вращение по часовой стрелке; отрицательное значение — вращение против часовой стрелки.
            Чтение/запись **float**.

### Примечания

Возвращаемое значение всегда определено (не является float.NaN).
            Присваиваемое значение должно быть определено (не float.NaN). Вы можете установить неопределённые значения для свойств экземпляра RawFrame.
