## ExcelDataCell класс

Представляет отдельную ячейку в книге Excel.

Тип ExcelDataCell открывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`value`](/slides/python-net/ru/aspose.slides.excel/exceldatacell/value/) | Возвращает значение, содержащееся в ячейке Excel. |
| [`name`](/slides/python-net/ru/aspose.slides.excel/exceldatacell/name/) | Возвращает имя ячейки данных диаграммы. |
| [`row`](/slides/python-net/ru/aspose.slides.excel/exceldatacell/row/) | Возвращает нулевой индекс строки в листе, где расположена ячейка.<br/>            Только для чтения **int**. |
| [`column`](/slides/python-net/ru/aspose.slides.excel/exceldatacell/column/) | Возвращает нулевой индекс столбца в листе, где расположена ячейка.<br/>            Только для чтения **int**. |
