## get_cells(self, formula, skip_hidden_cells) {#str-bool}
Получает коллекцию ячеек из рабочей книги, соответствующих указанной формуле.

### Возвращаемое значение
Только для чтения список ячеек, соответствующих указанной формуле.

```python
def get_cells(self, formula, skip_hidden_cells):
    ...
```

| Параметр | Тип | Описание |
| :- | :- | :- |
| formula | **str** | Формула или выражение диапазона (например, "Sheet1!A1:B3"), используемое для идентификации целевых ячеек. |
| skip_hidden_cells | **bool** | Если `true`, скрытые ячейки (например, в скрытых строках или столбцах) будут исключены из результата. |
