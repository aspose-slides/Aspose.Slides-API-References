## IExcelDataCell класс

Представляет отдельную ячейку в рабочей книге Excel.

Тип IExcelDataCell раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`value`](/slides/python-net/ru/aspose.slides.excel/iexceldatacell/value/) | Возвращает значение, содержащееся в ячейке Excel.<br/>            Только для чтения **any**. |
| [`name`](/slides/python-net/ru/aspose.slides.excel/iexceldatacell/name/) | Возвращает имя ячейки данных диаграммы.<br/>            Только для чтения **str**. |
| [`row`](/slides/python-net/ru/aspose.slides.excel/iexceldatacell/row/) | Возвращает нулевой индекс строки в листе, где расположена ячейка.<br/>            Только для чтения **int**. |
| [`column`](/slides/python-net/ru/aspose.slides.excel/iexceldatacell/column/) | Возвращает нулевой индекс столбца в листе, где расположена ячейка.<br/>            Только для чтения **int**. |
