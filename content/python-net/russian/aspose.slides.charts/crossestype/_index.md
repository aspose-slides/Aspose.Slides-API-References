## CrossesType перечисление

Определяет, где ось будет пересекаться.

Тип CrossesType предоставляет следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| AXIS_CROSSES_AT_ZERO | Ось категорий пересекает ось значений в точке нуля (если возможно), либо минимальное значение (если минимум больше нуля), либо максимум (если максимум меньше нуля). |
| MAXIMUM | Ось пересекает максимальное значение. |
| CUSTOM | Пользовательское значение из свойства CrossAt |
