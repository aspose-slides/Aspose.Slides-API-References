## IAxisFormat класс

Представляет свойства формата диаграммы.

Тип IAxisFormat раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`fill`](/slides/python-net/ru/aspose.slides.charts/iaxisformat/fill/) | Возвращает свойства стиля заливки оси.<br/>            Только для чтения [`IFillFormat`](/slides/python-net/ru/aspose.slides/ifillformat). |
| [`line`](/slides/python-net/ru/aspose.slides.charts/iaxisformat/line/) | Возвращает свойства стиля линии оси.<br/>            Только для чтения [`ILineFormat`](/slides/python-net/ru/aspose.slides/ilineformat). |
| [`effect`](/slides/python-net/ru/aspose.slides.charts/iaxisformat/effect/) | Возвращает эффекты, используемые для оси.<br/>            Только для чтения [`IEffectFormat`](/slides/python-net/ru/aspose.slides/ieffectformat). |
