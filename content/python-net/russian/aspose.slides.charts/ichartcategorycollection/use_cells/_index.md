## use_cells свойство
Если true, то рабочий лист используется для хранения категорий (этот случай поддерживает многоуровневые категории).
            Если false, то рабочий лист НЕ используется для хранения значений (и этот случай не поддерживает 
            многоуровневые категории).
            Чтение/запись **bool**.
