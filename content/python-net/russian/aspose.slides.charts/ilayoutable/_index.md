## ILayoutable класс

Определяет точное положение элемента диаграммы.

Тип ILayoutable раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`x`](/slides/python-net/ru/aspose.slides.charts/ilayoutable/x/) | Определяет положение по оси x (слева) элемента диаграммы как долю от ширины диаграммы.<br/>            Чтение/запись **float**. |
| [`y`](/slides/python-net/ru/aspose.slides.charts/ilayoutable/y/) | Определяет верхнюю позицию элемента диаграммы как долю от высоты диаграммы.<br/>            Чтение/запись **float**. |
| [`width`](/slides/python-net/ru/aspose.slides.charts/ilayoutable/width/) | Определяет ширину элемента диаграммы как долю от ширины диаграммы.<br/>            Чтение/запись **float**. |
| [`height`](/slides/python-net/ru/aspose.slides.charts/ilayoutable/height/) | Определяет высоту элемента диаграммы как долю от высоты диаграммы.<br/>            Чтение/запись **float**. |
| [`right`](/slides/python-net/ru/aspose.slides.charts/ilayoutable/right/) | Возвращает правую позицию элемента диаграммы как долю от ширины диаграммы.<br/>            Только чтение **float**. |
