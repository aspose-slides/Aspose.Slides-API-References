## ErrorBarsCustomValues класс

Указывает значения линий ошибок. Должен использоваться только когда тип значения линий ошибок — Custom.

Тип ErrorBarsCustomValues предоставляет следующие члены:

## Свойства

| :- | :- |
| [`x_minus`](/slides/python-net/ru/aspose.slides.charts/errorbarscustomvalues/x_minus/) | Указывает значение линии ошибок в отрицательном направлении.<br/>            Доступно, если тип значения линии ошибок — Custom и разрешён ErrorBarsXFormat.<br/>            В остальных случаях это свойство возвращает None.<br/>            Только для чтения [`IDoubleChartValue`](/slides/python-net/ru/aspose.slides.charts/idoublechartvalue). |
