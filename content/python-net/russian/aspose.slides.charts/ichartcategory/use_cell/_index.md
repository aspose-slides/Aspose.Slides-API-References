## use_cell свойство
Если значение true, то свойство AsCell действительно. Другими словами, worksheet используется для хранения категории (в этом случае поддерживается многоуровневая категория). Если значение false, то свойство AsLiteral действительно. Другими словами, worksheet НЕ используется для хранения категории (и этот случай не поддерживает многоуровневые категории). Только для чтения **bool**.

### Примечания

Чтобы изменить значение этого свойства (для всех категорий в коллекции), задайте новое значение свойству ChartCategoryCollection.UseCells.
