## fill_format свойство
Возвращает объект FillFormat, содержащий свойства заливки для фигуры.
            Примечание: может возвращать None для некоторых типов фигур, у которых нет свойств заливки.
            Только для чтения [`IFillFormat`](/slides/python-net/ru/aspose.slides/ifillformat).
