## rotation property
Возвращает или задаёт количество градусов, на которое указанная фигура повернута вокруг оси z. Положительное значение указывает на вращение по часовой стрелке; отрицательное значение указывает на вращение против часовой стрелки.
Чтение/запись **float**.


### Примечания

Возвращаемое значение всегда определено (не является float.NaN). Присвоенное значение должно быть определено (не является float.NaN). Вы можете задать неопределённые значения для свойств экземпляра RawFrame.
