## AxesManager класс

Обеспечивает доступ к осям диаграммы.

Тип AxesManager предоставляет следующие члены:

## Свойства

| Property | Описание |
| :- | :- |
| [`horizontal_axis`](/slides/python-net/ru/aspose.slides.charts/axesmanager/horizontal_axis/) | Получает горизонтальную ось диаграммы.<br/>             Только для чтения [`IAxis`](/slides/python-net/ru/aspose.slides.charts/iaxis). |
| [`secondary_horizontal_axis`](/slides/python-net/ru/aspose.slides.charts/axesmanager/secondary_horizontal_axis/) | Получает вторичную горизонтальную ось диаграммы.<br/>             Только для чтения [`IAxis`](/slides/python-net/ru/aspose.slides.charts/iaxis). |
| [`vertical_axis`](/slides/python-net/ru/aspose.slides.charts/axesmanager/vertical_axis/) | Получает вертикальную ось диаграммы.<br/>             Только для чтения [`IAxis`](/slides/python-net/ru/aspose.slides.charts/iaxis). |
| [`secondary_vertical_axis`](/slides/python-net/ru/aspose.slides.charts/axesmanager/secondary_vertical_axis/) | Получает вторичную вертикальную ось диаграммы.<br/>             Только для чтения [`IAxis`](/slides/python-net/ru/aspose.slides.charts/iaxis). |
| [`series_axis`](/slides/python-net/ru/aspose.slides.charts/axesmanager/series_axis/) | Получает ось серии диаграммы.<br/>             Только для чтения [`IAxis`](/slides/python-net/ru/aspose.slides.charts/iaxis). |
