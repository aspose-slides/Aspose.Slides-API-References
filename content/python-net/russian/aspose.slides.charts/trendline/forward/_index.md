## forward свойство
Указывает количество категорий (или единиц на диаграмме разброса), на которое трендовая линия продолжается после данных для серии, которая отображается. На диаграммах разброса и неразброса значение должно быть любым неотрицательным значением.
Чтение/запись **float**.

```python
@property
def forward(self):
    ...

@forward.setter
def forward(self, value):
    ...
```
