## text_frame_for_overriding свойство
Может содержать богато отформатированный текст. Если это свойство не None, то этот 
            значение отформатированного текста переопределяет автоматически сгенерированный текст подписи данных.
            Автогенерируемый текст подписи данных означает текст, который управляется свойствами ShowSeriesName, 
            ShowValue, ... свойствами и отформатирован с помощью свойства TextFormatManager.TextFormat.
            Только для чтения [`ITextFrame`](/slides/python-net/ru/aspose.slides/itextframe).
