## backward свойство
Указывает количество категорий (или единиц на точечной диаграмме), на которые линия тренда расширяется до
            данных для серии, для которой строится тренд. На точечных и неточечных диаграммах значение должно быть любым неотрицательным.
            Чтение/запись **float**.

    ...

    ...
