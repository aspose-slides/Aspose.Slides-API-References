## DisplayUnitType перечисление

Определяет кратность отображаемых данных.

Тип DisplayUnitType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| NONE | Значения будут отображаться как есть. |
| HUNDREDS | Указывает, что значения на диаграмме следует разделить на 100. |
| THOUSANDS | Указывает, что значения на диаграмме следует разделить на 1,000. |
| TEN_THOUSANDS | Указывает, что значения на диаграмме следует разделить на 10,000. |
| HUNDRED_THOUSANDS | Указывает, что значения на диаграмме следует разделить на 100,000. |
| MILLIONS | Указывает, что значения на диаграмме следует разделить на 1,000,000. |
| TEN_MILLIONS | Указывает, что значения на диаграмме следует разделить на 10,000,000. |
| HUNDRED_MILLIONS | Указывает, что значения на диаграмме следует разделить на 100,000,000. |
| BILLIONS | Указывает, что значения на диаграмме следует разделить на 1,000,000,000. |
| TRILLIONS | Указывает, что значения на диаграмме следует разделить на 1,000,000,000,000. |
| CUSTOM_VALUE | Указывает, что значения на диаграмме следует разделить на пользовательское значение. |
