## spell_check свойство
Получает или задает значение, указывающее, включена ли проверка орфографии для текстовой части.
            Когда это свойство установлено в false, проверки орфографии для текстовых элементов подавляются.
            Когда установлено в true, проверка орфографии разрешена.
            Значение по умолчанию — `false`.
