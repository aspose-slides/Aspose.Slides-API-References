## TickMarkType перечисление

Представляет тип делений для указанной оси.

Тип TickMarkType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| CROSS | Указывает, что деления должны пересекать ось. |
| INSIDE | Указывает, что деления должны находиться внутри области построения. |
| NONE | Указывает, что деления отсутствуют. |
| OUTSIDE | Указывает, что деления должны быть за пределами области построения. |
