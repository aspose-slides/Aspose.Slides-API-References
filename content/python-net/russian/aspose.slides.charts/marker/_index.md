## Marker класс

Представляет маркер диаграммы.

Тип Marker раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`symbol`](/slides/python-net/ru/aspose.slides.charts/marker/symbol/) | Представляет стиль маркера в линейной диаграмме, точечной диаграмме или радиальной диаграмме.<br/>            Чтение/запись [`MarkerStyleType`](/slides/python-net/ru/aspose.slides.charts/markerstyletype). |
| [`format`](/slides/python-net/ru/aspose.slides.charts/marker/format/) | Получает или задает заливку маркера.<br/>            Только для чтения [`IFormat`](/slides/python-net/ru/aspose.slides.charts/iformat). |
| [`size`](/slides/python-net/ru/aspose.slides.charts/marker/size/) | Представляет размер маркера в линейной диаграмме, точечной диаграмме или радиальной диаграмме.<br/>            Чтение/запись **int**. |
