## hide(self) {#}
Сделайте подпись данных скрытой по умолчанию, установив все флаги Show*- (ShowValue, ...) свойства DefaultDataLabelFormat в состояние false. IsVisible будет false после этого.

```python
def hide(self):
    ...
```

### Примечания

Если подпись данных не видима по умолчанию (IsVisible равно false), вы можете сделать подпись данных «видимой по умолчанию», установив флаги Show*- (ShowValue, ...) свойства DefaultDataLabelFormat в состояние true.
