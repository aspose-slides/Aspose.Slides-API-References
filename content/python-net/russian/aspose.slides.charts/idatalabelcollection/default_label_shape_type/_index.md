## default_label_shape_type свойство
Получает или задает тип формы по умолчанию для подписей данных.
             Возвращает [`ShapeType.NOT_DEFINED`](/slides/python-net/ru/aspose.slides/shapetype/NOT_DEFINED) если форма не определена.

### Примечания

Установка этого свойства также задает свойство [`IDataLabel.label_shape_type`](/slides/python-net/ru/aspose.slides.charts/idatalabel/label_shape_type)
             для всех подписей данных в коллекции со тем же значением.
