## bubble_size_representation свойство
Указывает, как значения размеров пузырей отображаются на пузырчатой диаграмме.
            Это свойство относится не только к этой серии, но и ко всем сериям группы родительских серий — это проекция соответствующего свойства группы. Поэтому это свойство только для чтения.
            Используйте свойство ParentSeriesGroup для доступа к группе родительских серий.
            Используйте свойство ParentSeriesGroup.BubbleSizeRepresentation с чтением/записью для изменения значения.

### Примечания

Это проекция свойства ParentSeriesGroup.BubbleSizeRepresentation.
