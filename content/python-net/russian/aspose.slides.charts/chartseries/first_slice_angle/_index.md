## first_slice_angle свойство
Указывает угол первой дольки круговой или пончиковой диаграммы в градусах (по часовой стрелке от верха, от 0 до 360 градусов). Это свойство относится не только к этой серии, но ко всем сериям группы родительской серии — это проекция соответствующего свойства группы. Таким образом, это свойство только для чтения. Используйте свойство ParentSeriesGroup для доступа к группе родительской серии. Используйте свойство ParentSeriesGroup.FirstSliceAngle свойства чтения/записи для изменения значения. Только для чтения **int**.

### Примечания

Это проекция свойства ParentSeriesGroup.FirstSliceAngle.
