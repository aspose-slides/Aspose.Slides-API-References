## doughnut_hole_size свойство
Указывает размер отверстия в кольцевой диаграмме (может быть от 10 до 90 процентов размера области построения).
Это свойство относится не только к этой серии, но и ко всем сериям группы родительской серии — это проекция соответствующего свойства группы. Поэтому это свойство только для чтения.
Используйте свойство ParentSeriesGroup для доступа к группе родительской серии.
Используйте свойство ParentSeriesGroup.DoughnutHoleSize чтения/записи для изменения значения.
Только для чтения **int**.

### Примечания

Это проекция свойства ParentSeriesGroup.DoughnutHoleSize.
