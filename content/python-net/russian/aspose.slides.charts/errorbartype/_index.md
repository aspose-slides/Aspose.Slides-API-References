## ErrorBarType перечисление

Представляет тип полосы ошибок

Тип ErrorBarType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| BOTH | Указывает, что полосы ошибок должны отображаться в положительном и отрицательном направлениях. |
| MINUS | Указывает, что полосы ошибок должны отображаться только в отрицательном направлении. |
| PLUS | Указывает, что полосы ошибок должны отображаться только в положительном направлении. |
