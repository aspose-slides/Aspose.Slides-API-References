## ChartCellCollection класс

Представляет коллекцию ячеек с данными.

Тип ChartCellCollection раскрывает следующие члены:

## Свойства

| Property | Description |
| :- | :- |
| [`count`](/slides/python-net/ru/aspose.slides.charts/chartcellcollection/count/) | Возвращает количество ячеек в коллекции.<br/>            Только для чтения **int**. |

Возвращает ячейку (IChartDataCell) по индексу.

## Индексатор

| Name | Description |
| :- | :- |
| [`[index]`](/slides/python-net/ru/aspose.slides.charts/chartcellcollection/__getitem__/) | Индекс ячейки. |

## Методы

| Method | Description |
| :- | :- |
| [`add(self, cell)`](/slides/python-net/ru/aspose.slides.charts/chartcellcollection/add/#ichartdatacell) | Добавляет новую ячейку в коллекцию. |
| [`add(self, value)`](/slides/python-net/ru/aspose.slides.charts/chartcellcollection/add/#any) | Создаёт [`ChartDataCell`](/slides/python-net/ru/aspose.slides.charts/chartdatacell) из указанного значения и добавляет её в коллекцию. |
| [`get_cells_address(self)`](/slides/python-net/ru/aspose.slides.charts/chartcellcollection/get_cells_address/#) | Возвращает адрес набора ячеек в рабочей книге. |

| [`remove_at(self, index)`](/slides/python-net/ru/aspose.slides.charts/chartcellcollection/remove_at/#int) | Удаляет ячейку из коллекции по индексу. |
