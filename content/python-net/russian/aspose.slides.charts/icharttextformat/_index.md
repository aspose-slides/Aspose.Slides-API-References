## IChartTextFormat класс

Диаграмма оперирует ограниченным набором свойств формата текста.
            IChartTextFormat, IChartTextBlockFormat, IChartParagraphFormat, IChartPortionFormat
            интерфейсы описывают этот ограниченный набор.

Тип IChartTextFormat содержит следующие члены:

## Свойства

| Property | Description |
| :- | :- |
| [`text_block_format`](/slides/python-net/ru/aspose.slides.charts/icharttextformat/text_block_format/) | Возвращает формат для элементов текста диаграммы.<br/>            Только для чтения [`IChartTextBlockFormat`](/slides/python-net/ru/aspose.slides.charts/icharttextblockformat). |
| [`paragraph_format`](/slides/python-net/ru/aspose.slides.charts/icharttextformat/paragraph_format/) | Возвращает формат абзаца.<br/>            Только для чтения [`IChartParagraphFormat`](/slides/python-net/ru/aspose.slides.charts/ichartparagraphformat). |
| [`portion_format`](/slides/python-net/ru/aspose.slides.charts/icharttextformat/portion_format/) | Возвращает формат части.<br/>            Только для чтения [`IChartPortionFormat`](/slides/python-net/ru/aspose.slides.charts/ichartportionformat). |
