## ErrorBarValueType перечисление

Представляет тип значения линии погрешности

Тип ErrorBarValueType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| CUSTOM | Указывает, что длина линий погрешности определяется элементами Plus и Minus. |
| FIXED | Указывает, что длина линий погрешности будет фиксированным значением, определённым параметром Error Bar Value. |
| PERCENTAGE | Указывает, что длина линий погрешности будет процентом Error Bar Value от данных. |
| STANDARD_DEVIATION | Указывает, что длина линий погрешности будет равна стандартным отклонениям Error Bar Value от данных. |
| STANDARD_ERROR | Указывает, что длина линий погрешности будет равна стандартным ошибкам Error Bar Value от данных. |
