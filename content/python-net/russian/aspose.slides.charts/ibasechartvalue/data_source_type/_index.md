## data_source_type свойство
Указывает, является ли фактически свойство AsCell или AsLiteralString или AsLiteralDouble. Другими словами, указывает тип значения свойства Data. Это свойство только для чтения. Для изменения значения этого свойства можно использовать одно из свойств ChartDataPointCollection.DataSourceTypeFor<...>.
