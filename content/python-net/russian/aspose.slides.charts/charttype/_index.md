## ChartType перечисление

Представляет тип диаграммы.

Тип ChartType предоставляет следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| CLUSTERED_COLUMN | Представляет гистограмму с группированными столбцами. |
| STACKED_COLUMN | Представляет гистограмму с накопленными столбцами. |
| PERCENTS_STACKED_COLUMN | Представляет гистограмму с 100 % накопленными столбцами. |
| CLUSTERED_COLUMN_3D | Представляет 3D гистограмму с группированными столбцами. |
| STACKED_COLUMN_3D | Представляет 3D гистограмму с накопленными столбцами. |
| PERCENTS_STACKED_COLUMN_3D | Представляет 3D гистограмму с 100 % накопленными столбцами. |
| COLUMN_3D | Представляет 3D гистограмму. |
| CLUSTERED_CYLINDER | Представляет цилиндрическую диаграмму. |
| STACKED_CYLINDER | Представляет цилиндрическую диаграмму с накопленными данными. |
| PERCENTS_STACKED_CYLINDER | Представляет 100 % накопленную цилиндрическую диаграмму. |
| CYLINDER_3D | Представляет 3D цилиндрическую диаграмму. |
| CLUSTERED_CONE | Представляет коническую диаграмму. |
| STACKED_CONE | Представляет коническую диаграмму с накопленными данными. |
| PERCENTS_STACKED_CONE | Представляет 100 % накопленную коническую диаграмму. |
| CONE_3D | Представляет 3D коническую диаграмму. |
| CLUSTERED_PYRAMID | Представляет пирамидальную диаграмму. |
| STACKED_PYRAMID | Представляет пирамидальную диаграмму с накопленными данными. |
| PERCENTS_STACKED_PYRAMID | Представляет 100 % накопленную пирамидальную диаграмму. |
| PYRAMID_3D | Представляет 3D пирамидальную диаграмму. |
| LINE | Представляет линейную диаграмму. |
| STACKED_LINE | Представляет линейную диаграмму с накопленными данными. |
| PERCENTS_STACKED_LINE | Представляет 100 % накопленную линейную диаграмму. |
| LINE_WITH_MARKERS | Представляет линейную диаграмму с маркерами данных. |
| STACKED_LINE_WITH_MARKERS | Представляет линейную диаграмму с накопленными данными и маркерами. |
| PERCENTS_STACKED_LINE_WITH_MARKERS | Представляет 100 % накопленную линейную диаграмму с маркерами данных. |
| LINE_3D | Представляет 3D линейную диаграмму. |
| PIE | Представляет круговую диаграмму. |
| PIE_3D | Представляет 3D круговую диаграмму. |
| PIE_OF_PIE | Представляет диаграмму «круг внутри круга». |
| EXPLODED_PIE | Представляет разорванную круговую диаграмму. |
| EXPLODED_PIE_3D | Представляет 3D разорванную круговую диаграмму. |
| BAR_OF_PIE | Представляет диаграмму «полоса внутри круга». |
| PERCENTS_STACKED_BAR | Представляет 100 % накопленную гистограмму. |
| CLUSTERED_BAR_3D | Представляет 3D гистограмму с группированными столбцами. |
| CLUSTERED_BAR | Представляет гистограмму с группированными столбцами. |
| STACKED_BAR | Представляет гистограмму с накопленными столбцами. |
| STACKED_BAR_3D | Представляет 3D гистограмму с накопленными столбцами. |
| PERCENTS_STACKED_BAR_3D | Представляет 3D гистограмму с 100 % накопленными столбцами. |
| CLUSTERED_HORIZONTAL_CYLINDER | Представляет цилиндрическую гистограмму. |
| STACKED_HORIZONTAL_CYLINDER | Представляет накопленную цилиндрическую гистограмму. |
| PERCENTS_STACKED_HORIZONTAL_CYLINDER | Представляет 100 % накопленную цилиндрическую гистограмму. |
| CLUSTERED_HORIZONTAL_CONE | Представляет коническую гистограмму. |
| STACKED_HORIZONTAL_CONE | Представляет накопленную коническую гистограмму. |
| PERCENTS_STACKED_HORIZONTAL_CONE | Представляет 100 % накопленную коническую гистограмму. |
| CLUSTERED_HORIZONTAL_PYRAMID | Представляет пирамидальную гистограмму. |
| STACKED_HORIZONTAL_PYRAMID | Представляет накопленную пирамидальную гистограмму. |
| PERCENTS_STACKED_HORIZONTAL_PYRAMID | Представляет 100 % накопленную пирамидальную гистограмму. |
| AREA | Представляет площадную диаграмму. |
| STACKED_AREA | Представляет накопленную площадную диаграмму. |
| PERCENTS_STACKED_AREA | Представляет 100 % накопленную площадную диаграмму. |
| AREA_3D | Представляет 3D площадную диаграмму. |
| STACKED_AREA_3D | Представляет 3D накопленную площадную диаграмму. |
| PERCENTS_STACKED_AREA_3D | Представляет 3D 100 % накопленную площадную диаграмму. |
| SCATTER_WITH_MARKERS | Представляет точечную диаграмму. |
| SCATTER_WITH_SMOOTH_LINES_AND_MARKERS | Представляет точечную диаграмму, соединённую кривыми, с маркерами данных. |
| SCATTER_WITH_SMOOTH_LINES | Представляет точечную диаграмму, соединённую кривыми, без маркеров данных. |
| SCATTER_WITH_STRAIGHT_LINES_AND_MARKERS | Представляет точечную диаграмму, соединённую линиями, с маркерами данных. |
| SCATTER_WITH_STRAIGHT_LINES | Представляет точечную диаграмму, соединённую линиями, без маркеров данных. |
| HIGH_LOW_CLOSE | Представляет биржевую диаграмму «high-low-close». |
| OPEN_HIGH_LOW_CLOSE | Представляет биржевую диаграмму «open-high-low-close». |
| VOLUME_HIGH_LOW_CLOSE | Представляет биржевую диаграмму «volume-high-low-close». |
| VOLUME_OPEN_HIGH_LOW_CLOSE | Представляет биржевую диаграмму «volume-open-high-low-close». |
| SURFACE_3D | Представляет 3D поверхностную диаграмму. |
| WIREFRAME_SURFACE_3D | Представляет 3D каркасную поверхностную диаграмму. |
| CONTOUR | Представляет контурную диаграмму. |
| WIREFRAME_CONTOUR | Представляет каркасную контурную диаграмму. |
| DOUGHNUT | Представляет кольцевую диаграмму. |
| EXPLODED_DOUGHNUT | Представляет разорванную кольцевую диаграмму. |
| BUBBLE | Представляет пузырьковую диаграмму. |
| BUBBLE_WITH_3D | Представляет 3D пузырьковую диаграмму. |
| RADAR | Представляет радиальную диаграмму. |
| RADAR_WITH_MARKERS | Представляет радиальную диаграмму с маркерами данных. |
| FILLED_RADAR | Представляет заполненную радиальную диаграмму. |
| SERIES_OF_MIXED_TYPES | Это значение может быть возвращено только свойством ChartEx.Type. <br/>            Это означает, что диаграмма имеет серии смешанных типов. |
| TREEMAP | Представляет диаграмму treemap. |
| SUNBURST | Представляет диаграмму sunburst. |
| HISTOGRAM | Представляет гистограмму. |
| PARETO_LINE | Представляет тип серии «Pareto line» (гистограмма Pareto). |
| BOX_AND_WHISKER | Представляет диаграмму BoxAndWhisker. |
| WATERFALL | Представляет диаграмму waterfall. |
| FUNNEL | Представляет диаграмму funnel. |
| MAP | Представляет карта. |
