## IAxesManager класс

Предоставляет доступ к осям диаграммы.

Тип IAxesManager раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`horizontal_axis`](/slides/python-net/ru/aspose.slides.charts/iaxesmanager/horizontal_axis/) | Получает горизонтальную ось диаграммы.<br/>             Только для чтения [`IAxis`](/slides/python-net/ru/aspose.slides.charts/iaxis). |
| [`secondary_horizontal_axis`](/slides/python-net/ru/aspose.slides.charts/iaxesmanager/secondary_horizontal_axis/) | Получает вторичную горизонтальную ось диаграммы.<br/>             Только для чтения [`IAxis`](/slides/python-net/ru/aspose.slides.charts/iaxis). |
| [`vertical_axis`](/slides/python-net/ru/aspose.slides.charts/iaxesmanager/vertical_axis/) | Получает вертикальную ось диаграммы.<br/>             Только для чтения [`IAxis`](/slides/python-net/ru/aspose.slides.charts/iaxis). |
| [`secondary_vertical_axis`](/slides/python-net/ru/aspose.slides.charts/iaxesmanager/secondary_vertical_axis/) | Получает вторичную вертикальную ось диаграммы.<br/>             Только для чтения [`IAxis`](/slides/python-net/ru/aspose.slides.charts/iaxis). |
| [`series_axis`](/slides/python-net/ru/aspose.slides.charts/iaxesmanager/series_axis/) | Получает ось серии диаграммы.<br/>             Только для чтения [`IAxis`](/slides/python-net/ru/aspose.slides.charts/iaxis). |
