## intercept свойство
Указывает значение, где трендовая линия пересекает ось y. Это свойство поддерживается только тогда, когда тип трендовой линии — exp, linear или poly. Чтение/запись **float**.

### Определение:
```python
@property
def intercept(self):
    ...

@intercept.setter

    ...
```
