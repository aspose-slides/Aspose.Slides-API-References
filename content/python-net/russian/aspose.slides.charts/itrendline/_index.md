## ITrendline класс

Класс представляет трендовую линию серии диаграммы

Тип ITrendline раскрывает следующие члены:

## Свойства

| Property | Description |
| :- | :- |
| [`trendline_name`](/slides/python-net/ru/aspose.slides.charts/itrendline/trendline_name/) | Получает или задает  название трендовой линии.<br/>            Read/write **str**. |
| [`trendline_type`](/slides/python-net/ru/aspose.slides.charts/itrendline/trendline_type/) | Получает или задает тип трендовой линии. <br/>            Read/write [`ITrendline.trendline_type`](/slides/python-net/ru/aspose.slides.charts/itrendline/trendline_type). |
| [`format`](/slides/python-net/ru/aspose.slides.charts/itrendline/format/) | Представляет формат трендовой линии.<br/>            Read/write [`IFormat`](/slides/python-net/ru/aspose.slides.charts/iformat). |
| [`backward`](/slides/python-net/ru/aspose.slides.charts/itrendline/backward/) | Указывает количество категорий (или единиц на точечной диаграмме), на которое трендовая линия расширяется до<br/>            данных серии, для которой построен тренд. На точечных и не точечных диаграммах значение должно быть любым неотрицательным<br/>            значением.<br/>            Read/write **float**. |
| [`forward`](/slides/python-net/ru/aspose.slides.charts/itrendline/forward/) | Указывает количество категорий (или единиц на точечной диаграмме), на которое трендовая линия расширяется после<br/>            данных серии, для которой построен тренд. На точечных и не точечных диаграммах значение должно быть любым неотрицательным<br/>            значением.<br/>            Read/write **float**. |
| [`intercept`](/slides/python-net/ru/aspose.slides.charts/itrendline/intercept/) | Указывает значение, где трендовая линия пересекает ось y. Это свойство поддерживается только<br/>            когда тип трендовой линии – exp, linear или poly.<br/>            Read/write **float**. |
| [`display_equation`](/slides/python-net/ru/aspose.slides.charts/itrendline/display_equation/) | Указывает, что уравнение трендовой линии отображается на диаграмме (в той же метке, что и значение Rsquaredvalue).<br/>            Read/write **bool**. |
| [`order`](/slides/python-net/ru/aspose.slides.charts/itrendline/order/) | Указывает порядок полиномиальной трендовой линии. Игнорируется для других типов трендовых линий. Значение должно быть от 2 до 6.<br/>            Read/write **int**. |
| [`period`](/slides/python-net/ru/aspose.slides.charts/itrendline/period/) | Указывает период трендовой линии для скользящего среднего. Игнорируется для других вариантов<br/>            трендовой линии. Значение должно быть от 2 до 255.<br/>            Read/write **int**. |
| [`display_r_squared_value`](/slides/python-net/ru/aspose.slides.charts/itrendline/display_r_squared_value/) | Указывает, что значение R-squared трендовой линии отображается на диаграмме (в той же метке, что и уравнение).<br/>            Read/write **bool**. |
| [`related_legend_entry`](/slides/python-net/ru/aspose.slides.charts/itrendline/related_legend_entry/) | Представляет запись легенды, связанную с этой трендовой линией<br/>            Read-only [`ILegendEntryProperties`](/slides/python-net/ru/aspose.slides.charts/ilegendentryproperties). |
| [`text_frame_for_overriding`](/slides/python-net/ru/aspose.slides.charts/itrendline/text_frame_for_overriding/) |  |
