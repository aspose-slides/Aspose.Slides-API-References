## forward property
Указывает количество категорий (или единиц на диаграмме разброса), на которое трендовая линия продолжается после
            данных для серии, к которой применяется тренд. На диаграммах разброса и неразбросных диаграммах значение должно быть любым неотрицательным
            значением.
            Чтение/запись **float**.

@property
def forward(self):
    ...

    ...
