## MarkerStyleType перечисление

Определяет форму маркера у точки данных диаграммы.

Тип MarkerStyleType предоставляет следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| NOT_DEFINED |  |
| CIRCLE | Указывает, что в каждой точке данных будет нарисован круг. |
| DASH | Указывает, что в каждой точке данных будет нарисован штрих. |
| DIAMOND | Указывает, что в каждой точке данных будет нарисован ромб. |
| DOT | Указывает, что в каждой точке данных будет нарисована точка. |
| NONE | Указывает, что в каждой точке данных ничего не будет нарисовано. |
| PICTURE | Указывает, что в каждой точке данных будет нарисовано изображение. |
| PLUS | Указывает, что в каждой точке данных будет нарисован плюс. |
| SQUARE | Указывает, что в каждой точке данных будет нарисован квадрат. |
| STAR | Указывает, что в каждой точке данных будет нарисована звезда. |
| TRIANGLE | Указывает, что в каждой точке данных будет нарисован треугольник. |
| X | Указывает, что в каждой точке данных будет нарисована буква X. |
