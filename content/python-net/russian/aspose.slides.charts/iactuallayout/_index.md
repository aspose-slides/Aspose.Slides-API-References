## IActualLayout класс

Указывает фактическое положение элемента диаграммы.

Тип IActualLayout раскрывает следующие члены:

## Свойства

| Property | Description |
| :- | :- |
| [`actual_x`](/slides/python-net/ru/aspose.slides.charts/iactuallayout/actual_x/) | Указывает фактическое положение по оси x (слева) элемента диаграммы относительно левого верхнего угла диаграммы.<br/>Вызовите метод IChart.ValidateChartLayout() перед этим, чтобы получить фактические значения.<br/>Чтение **float**. |
| [`actual_y`](/slides/python-net/ru/aspose.slides.charts/iactuallayout/actual_y/) | Указывает фактическую верхнюю позицию элемента диаграммы относительно левого верхнего угла диаграммы.<br/>Вызовите метод IChart.ValidateChartLayout() перед этим, чтобы получить фактические значения.<br/>Чтение **float**. |
| [`actual_width`](/slides/python-net/ru/aspose.slides.charts/iactuallayout/actual_width/) | Указывает фактическую ширину элемента диаграммы. Вызовите метод IChart.ValidateChartLayout() перед этим, чтобы получить фактические значения.<br/>Чтение **float**. |
