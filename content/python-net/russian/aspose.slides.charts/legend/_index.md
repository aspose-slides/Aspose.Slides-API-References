## Класс Legend

Представляет свойства легенды диаграммы.

Тип Legend раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`x`](/slides/python-net/ru/aspose.slides.charts/legend/x/) | Возвращает или задает координату x легенды как долю от ширины диаграммы.<br/>            Чтение/запись **float**. |
| [`y`](/slides/python-net/ru/aspose.slides.charts/legend/y/) | Возвращает или задает координату y легенды как долю от высоты диаграммы.<br/>            Чтение/запись **float**. |
| [`width`](/slides/python-net/ru/aspose.slides.charts/legend/width/) | Возвращает или задает ширину легенды как долю от ширины диаграммы.<br/>            Чтение/запись **float**. |
| [`height`](/slides/python-net/ru/aspose.slides.charts/legend/height/) | Возвращает или задает высоту легенды как долю от высоты диаграммы.<br/>            Чтение/запись **float**. |
| [`right`](/slides/python-net/ru/aspose.slides.charts/legend/right/) | Справа.<br/>            Только для чтения **float**. |
| [`bottom`](/slides/python-net/ru/aspose.slides.charts/legend/bottom/) | Снизу.<br/>            Только для чтения **float**. |
| [`overlay`](/slides/python-net/ru/aspose.slides.charts/legend/overlay/) | Определяет, разрешено ли другим элементам диаграммы перекрывать легенду.<br/>            Чтение/запись **bool**. |
| [`text_format`](/slides/python-net/ru/aspose.slides.charts/legend/text_format/) | Формат текста.<br/>            Только для чтения [`IChartTextFormat`](/slides/python-net/ru/aspose.slides.charts/icharttextformat). |
| [`position`](/slides/python-net/ru/aspose.slides.charts/legend/position/) | Указывает положение легенды на диаграмме.<br/>            Значения, не являющиеся NaN, свойств X, Y, Width, Heigt переопределяют действие этого свойства.<br/>            Чтение/запись [`LegendPositionType`](/slides/python-net/ru/aspose.slides.charts/legendpositiontype). |
| [`format`](/slides/python-net/ru/aspose.slides.charts/legend/format/) | Возвращает формат легенды.<br/>            Только для чтения [`IFormat`](/slides/python-net/ru/aspose.slides.charts/iformat). |
| [`chart`](/slides/python-net/ru/aspose.slides.charts/legend/chart/) | Возвращает диаграмму.<br/>            Только для чтения [`IChart`](/slides/python-net/ru/aspose.slides.charts/ichart). |
| [`entries`](/slides/python-net/ru/aspose.slides.charts/legend/entries/) | Получает элементы легенды.<br/>            Только для чтения [`ILegendEntryCollection`](/slides/python-net/ru/aspose.slides.charts/ilegendentrycollection). |
| [`actual_x`](/slides/python-net/ru/aspose.slides.charts/legend/actual_x/) | Указывает фактическое расположение по оси x (слева) элемента диаграммы относительно левого верхнего угла диаграммы.<br/>            Вызовите метод IChart.ValidateChartLayout() перед получением фактических значений.<br/>            Чтение **float**. |
| [`actual_y`](/slides/python-net/ru/aspose.slides.charts/legend/actual_y/) | Указывает фактическую верхнюю границу элемента диаграммы относительно левого верхнего угла диаграммы.<br/>            Вызовите метод IChart.ValidateChartLayout() перед получением фактических значений.<br/>            Чтение **float**. |
| [`actual_width`](/slides/python-net/ru/aspose.slides.charts/legend/actual_width/) | Указывает фактическую ширину элемента диаграммы. Вызовите метод IChart.ValidateChartLayout() перед получением фактических значений.<br/>            Чтение **float**. |
| [`actual_height`](/slides/python-net/ru/aspose.slides.charts/legend/actual_height/) | Указывает фактическую высоту элемента диаграммы. Вызовите метод IChart.ValidateChartLayout() перед получением фактических значений.<br/>            Чтение **float**. |
