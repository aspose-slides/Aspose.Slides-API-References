## use_secondary_categories свойство
Если false, то [`ChartData.secondary_categories`](/slides/python-net/ru/aspose.slides.charts/chartdata/secondary_categories) свойство возвращает None, а данные 
            в [`ChartData.categories`](/slides/python-net/ru/aspose.slides.charts/chartdata/categories) свойстве используются как для основной, так и для вторичной серии.
            Если true, то данные в [`ChartData.secondary_categories`](/slides/python-net/ru/aspose.slides.charts/chartdata/secondary_categories) свойстве используют для вторичной серии, а данные 
            в [`ChartData.categories`](/slides/python-net/ru/aspose.slides.charts/chartdata/categories) свойстве используют для основной серии.
            Чтение/запись **bool**.
