## use_secondary_categories свойство
Если false, то [`ChartData.secondary_categories`](/slides/python-net/ru/aspose.slides.charts/chartdata/secondary_categories) свойство возвращает None и данные 
            в [`ChartData.categories`](/slides/python-net/ru/aspose.slides.charts/chartdata/categories) свойство используется как для первичных, так и для вторичных рядов.
            Если true, то данные в [`ChartData.secondary_categories`](/slides/python-net/ru/aspose.slides.charts/chartdata/secondary_categories) свойство используется для вторичных рядов и данные 
            в [`ChartData.categories`](/slides/python-net/ru/aspose.slides.charts/chartdata/categories) свойство используется для первичных рядов.
            Чтение/запись **bool**.
