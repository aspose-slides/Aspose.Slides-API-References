## default_label_shape_type свойство
Gets or sets the default shape type for data labels.
             Возвращает [`ShapeType.NOT_DEFINED`](/slides/python-net/ru/aspose.slides/shapetype/NOT_DEFINED), если форма не определена.


### Примечания

Установка этого свойства также задаёт свойство [`IDataLabel.label_shape_type`](/slides/python-net/ru/aspose.slides.charts/idatalabel/label_shape_type)
             для всех подписей данных в коллекции тем же значением.
