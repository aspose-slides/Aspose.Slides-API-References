## IDataTable класс

Представляет свойства таблицы данных.

Тип IDataTable открывает следующие члены:

## Свойства

| :- | :- |
| [`format`](/slides/python-net/ru/aspose.slides.charts/idatatable/format/) | Возвращает стили линии, заливки и эффектов объекта.<br/>            Только чтение [`IFormat`](/slides/python-net/ru/aspose.slides.charts/iformat). |
| [`has_border_horizontal`](/slides/python-net/ru/aspose.slides.charts/idatatable/has_border_horizontal/) | Истина, если у таблицы данных диаграммы есть горизонтальные границы ячеек.<br/>            Чтение/запись **bool**. |
