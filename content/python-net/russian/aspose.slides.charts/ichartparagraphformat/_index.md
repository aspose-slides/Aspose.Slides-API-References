## IChartParagraphFormat класс

Представляет свойства форматирования абзаца диаграммы.

Тип IChartParagraphFormat предоставляет следующие члены:

## Свойства

| Property | Description |
| :- | :- |
| [`alignment`](/slides/python-net/ru/aspose.slides.charts/ichartparagraphformat/alignment/) | Возвращает или задает выравнивание текста в абзаце.<br/>            Чтение/запись [`TextAlignment`](/slides/python-net/ru/aspose.slides/textalignment). |
| [`space_within`](/slides/python-net/ru/aspose.slides.charts/ichartparagraphformat/space_within/) | Возвращает или задает величину пространства между базовыми линиями в абзаце.<br/>            Чтение/запись **float**. |
| [`space_before`](/slides/python-net/ru/aspose.slides.charts/ichartparagraphformat/space_before/) | Возвращает или задает величину пространства перед первой строкой в абзаце.<br/>            Чтение/запись **float**. |
| [`space_after`](/slides/python-net/ru/aspose.slides.charts/ichartparagraphformat/space_after/) | Возвращает или задает величину пространства после последней строки в абзаце.<br/>            Чтение/запись **float**. |
| [`east_asian_line_break`](/slides/python-net/ru/aspose.slides.charts/ichartparagraphformat/east_asian_line_break/) | Определяет, используется ли разрыв строки восточноазиатского типа в абзаце.<br/>            Чтение/запись [`NullableBool`](/slides/python-net/ru/aspose.slides/nullablebool). |
| [`right_to_left`](/slides/python-net/ru/aspose.slides.charts/ichartparagraphformat/right_to_left/) | Определяет, используется ли запись справа налево в абзаце.<br/>            Чтение/запись [`NullableBool`](/slides/python-net/ru/aspose.slides/nullablebool). |
| [`latin_line_break`](/slides/python-net/ru/aspose.slides.charts/ichartparagraphformat/latin_line_break/) | Определяет, используется ли разрыв строки латинского типа в абзаце.<br/>            Чтение/запись [`NullableBool`](/slides/python-net/ru/aspose.slides/nullablebool). |
| [`hanging_punctuation`](/slides/python-net/ru/aspose.slides.charts/ichartparagraphformat/hanging_punctuation/) | Определяет, используется ли висячая пунктуация в абзаце.<br/>            Чтение/запись [`NullableBool`](/slides/python-net/ru/aspose.slides/nullablebool). |
| [`margin_left`](/slides/python-net/ru/aspose.slides.charts/ichartparagraphformat/margin_left/) | Возвращает или задает левый отступ в абзаце.<br/>            Чтение/запись **float**. |
| [`margin_right`](/slides/python-net/ru/aspose.slides.charts/ichartparagraphformat/margin_right/) | Возвращает или задает правый отступ в абзаце.<br/>            Чтение/запись **float**. |
| [`indent`](/slides/python-net/ru/aspose.slides.charts/ichartparagraphformat/indent/) | Возвращает или задает первый отступ/висячий отступ абзаца. Висячий отступ может быть задан отрицательными значениями.<br/>            Чтение/запись **float**. |
| [`default_tab_size`](/slides/python-net/ru/aspose.slides.charts/ichartparagraphformat/default_tab_size/) | Возвращает или задает размер табуляции по умолчанию.<br/>            Чтение/запись **float**. |
| [`tabs`](/slides/python-net/ru/aspose.slides.charts/ichartparagraphformat/tabs/) | Возвращает табуляции абзаца.<br/>            Только чтение [`ITabCollection`](/slides/python-net/ru/aspose.slides/itabcollection). |
| [`font_alignment`](/slides/python-net/ru/aspose.slides.charts/ichartparagraphformat/font_alignment/) | Возвращает или задает выравнивание шрифта в абзаце.<br/>            Чтение/запись [`FontAlignment`](/slides/python-net/ru/aspose.slides/fontalignment). |
