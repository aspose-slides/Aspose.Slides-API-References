## ILegendEntryCollection класс

Представляет коллекцию легенд.

Тип ILegendEntryCollection предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`count`](/slides/python-net/ru/aspose.slides.charts/ilegendentrycollection/count/) | Возвращает количество элементов, фактически содержащихся в коллекции.<br/>Только для чтения **int**. |

Получает свойства элемента легенды, соответствующего Chart.ChartData.Series[0].DataPoints[index] в случае типа диаграммы из следующего списка:
              ChartType.BarOfPie,
              ChartType.ExplodedPie,
              ChartType.ExplodedPie3D,
              ChartType.Pie,
              ChartType.Pie3D,
              ChartType.PieOfPie;
            или соответствующего Chart.ChartData.Series[index] для других типов диаграмм.
