## bubble_size_scale свойство

Указывает коэффициент масштабирования для пузырчатой диаграммы (может быть от 0 до 300 % от размера по умолчанию). Это свойство относится не только к этой серии, но и ко всем сериям группы родительских серий — это проекция соответствующего свойства группы. Поэтому это свойство только для чтения. Используйте свойство ParentSeriesGroup для доступа к группе родительских серий. Для изменения значения используйте свойство ParentSeriesGroup.BubbleSizeScale, доступное для чтения и записи.
