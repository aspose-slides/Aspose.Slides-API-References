## gap_depth свойство
Возвращает или задает расстояние, выраженное в процентах от ширины маркера, между рядами данных в 3D-диаграмме.
            Это свойство относится не только к этому ряду, но и ко всем рядам группы родительских рядов — это проекция соответствующего свойства группы. Поэтому это свойство только для чтения.
            Используйте свойство ParentSeriesGroup для доступа к группе родительских рядов.
            Используйте свойство ParentSeriesGroup.GapDepth для чтения/записи, чтобы изменить значение.
            Только для чтения **int**.


### Примечания

Это проекция свойства ParentSeriesGroup.GapDepth.
