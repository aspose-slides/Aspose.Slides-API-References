## gap            width свойство
            Указывает расстояние между группами столбцов или колонок в процентах от ширины столбца или колонки.
            Это свойство относится не только к этой серии, но и ко всем сериям родительской группы серий 
            группы — это проекция соответствующего свойства группы. Поэтому это свойство 
            только для чтения.
            Используйте свойство ParentSeriesGroup для доступа к родительской группе серий.
            Используйте свойство ParentSeriesGroup.GapWidth для чтения/записи, чтобы изменить значение.
            Только для чтения **int**.

### Примечания

Это проекция свойства ParentSeriesGroup.GapWidth.
