## IChartCellCollection класс

Представляет коллекцию ячеек с данными.

Тип IChartCellCollection раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`count`](/slides/python-net/ru/aspose.slides.charts/ichartcellcollection/count/) | Получает количество ячеек в коллекции.<br/>            Только для чтения **int**. |

Возвращает ячейку (IChartDataCell) по индексу.

## Индексатор

| Имя | Описание |
| :- | :- |
| [`[index]`](/slides/python-net/ru/aspose.slides.charts/ichartcellcollection/__getitem__/) | Индекс ячейки. |

## Методы

| Метод | Описание |
| :- | :- |
| [`add(self, chart_data_cell)`](/slides/python-net/ru/aspose.slides.charts/ichartcellcollection/add/#ichartdatacell) | Добавляет новую ячейку в коллекцию. |
| [`add(self, value)`](/slides/python-net/ru/aspose.slides.charts/ichartcellcollection/add/#any) | Создаёт [`IChartDataCell`](/slides/python-net/ru/aspose.slides.charts/ichartdatacell) из указанного значения и добавляет его в коллекцию. |
| [`get_cells_address(self)`](/slides/python-net/ru/aspose.slides.charts/ichartcellcollection/get_cells_address/#) | Возвращает адрес набора ячеек в рабочей книге. |
| [`get_concatenated_values_from_cells(self)`](/slides/python-net/ru/aspose.slides.charts/ichartcellcollection/get_concatenated_values_from_cells/#) | Конкатенированная строка из строковых значений всех ячеек. |
| [`remove_at(self, index)`](/slides/python-net/ru/aspose.slides.charts/ichartcellcollection/remove_at/#int) | Удаляет ячейку из коллекции по индексу. |
