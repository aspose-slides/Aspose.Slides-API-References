## IChartDataPointCollection класс

Представляет коллекцию точек данных серии.

Тип IChartDataPointCollection раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`data_source_type_for_x_values`](/slides/python-net/ru/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_x_values/) | Указывает, является ли свойство AsCell или AsLiteralString или AsLiteralDouble актуальным в объекте свойства XValue точек данных. Другими словами, оно указывает тип значения свойства ChartDataPointEx.XValue.Data.<br/>            Чтение/запись [`DataSourceType`](/slides/python-net/ru/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_y_values`](/slides/python-net/ru/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_y_values/) | Указывает, является ли свойство AsCell или AsLiteralString или AsLiteralDouble актуальным в объекте свойства YValue точек данных. Другими словами, оно указывает тип значения свойства ChartDataPointEx.YValue.Data.<br/>            Чтение/запись [`DataSourceType`](/slides/python-net/ru/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_bubble_sizes`](/slides/python-net/ru/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_bubble_sizes/) | Указывает, является ли свойство AsCell или AsLiteralString или AsLiteralDouble актуальным в объекте свойства BubbleSize точек данных. Другими словами, оно указывает тип значения свойства ChartDataPointEx.BubbleSize.Data.<br/>            Чтение/запись [`DataSourceType`](/slides/python-net/ru/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_values`](/slides/python-net/ru/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_values/) | Указывает, является ли свойство AsCell или AsLiteralString или AsLiteralDouble актуальным в объекте свойства Value точек данных. Другими словами, оно указывает тип значения свойства ChartDataPoint.Value.Data.<br/>            Чтение/запись [`DataSourceType`](/slides/python-net/ru/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_error_bars_custom_values`](/slides/python-net/ru/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_error_bars_custom_values/) | Указывает тип значений в списке свойств ChartDataPoint.ErrorBarsCustomValues.<br/>            Только чтение [`IDataSourceTypeForErrorBarsCustomValues`](/slides/python-net/ru/aspose.slides.charts/idatasourcetypeforerrorbarscustomvalues). |

Возвращает точку данных серии по индексу (его порядковый номер в этой коллекции).
