## data_source_type свойство
Указывает, является ли свойство AsCell, AsCells, AsLiteralString или AsLiteralDouble актуальным в наследниках. Другими словами, определяет тип значения свойства Data. Чтение/запись [`DataSourceType`](/slides/python-net/ru/aspose.slides.charts/datasourcetype).

### Примечания
Для точек в ChartDataPointCollection это свойство только для чтения. В этом случае для изменения значения этого свойства можно использовать одно из свойств ChartDataPointCollection.DataSourceTypeFor<...>.
