## IErrorBarsCustomValues класс

Указывает значения линий ошибок. Его следует использовать только когда тип значения линий ошибок равен Custom.

Тип IErrorBarsCustomValues предоставляет следующие члены:

## Свойства

| Property | Description |
| :- | :- |
| [`x_minus`](/slides/python-net/ru/aspose.slides.charts/ierrorbarscustomvalues/x_minus/) | Указывает значение линии ошибки в отрицательном направлении. <br/>            Доступно, если тип значения линий ошибки равен Custom и разрешен ErrorBarsXFormat.<br/>            В остальных случаях это свойство возвращает None.  <br/>            Только для чтения [`IDoubleChartValue`](/slides/python-net/ru/aspose.slides.charts/idoublechartvalue). |
| [`y_minus`](/slides/python-net/ru/aspose.slides.charts/ierrorbarscustomvalues/y_minus/) | Указывает значение линии ошибки в отрицательном направлении. <br/>            Доступно, если тип значения линий ошибки равен Custom и разрешен ErrorBarsYFormat.<br/>            В остальных случаях это свойство возвращает None. <br/>            Только для чтения [`IDoubleChartValue`](/slides/python-net/ru/aspose.slides.charts/idoublechartvalue). |
| [`x_plus`](/slides/python-net/ru/aspose.slides.charts/ierrorbarscustomvalues/x_plus/) | Указывает значение линии ошибки в положительном направлении. <br/>            Доступно, если тип значения линий ошибки равен Custom и разрешен ErrorBarsXFormat.<br/>            В остальных случаях это свойство возвращает None. <br/>            Только для чтения [`IDoubleChartValue`](/slides/python-net/ru/aspose.slides.charts/idoublechartvalue). |
| [`y_plus`](/slides/python-net/ru/aspose.slides.charts/ierrorbarscustomvalues/y_plus/) | Указывает значение линии ошибки в положительном направлении. <br/>            Доступно, если тип значения линий ошибки равен Custom и разрешен ErrorBarsYFormat.<br/>            В остальных случаях это свойство возвращает None. <br/>            Только для чтения [`IDoubleChartValue`](/slides/python-net/ru/aspose.slides.charts/idoublechartvalue). |
