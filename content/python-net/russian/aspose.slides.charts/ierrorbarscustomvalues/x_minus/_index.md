## x_minus свойство
Specifies the error bar value in the negative direction. 
            Доступно, если тип значения линий ошибок — Custom, и разрешён ErrorBarsXFormat.
            В любом другом случае это свойство возвращает None.  
            Только для чтения [`IDoubleChartValue`](/slides/python-net/ru/aspose.slides.charts/idoublechartvalue).
