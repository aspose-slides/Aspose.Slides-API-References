## related_legend_entry свойство
Свойства соответствующей записи легенды в случае типа диаграммы из следующего списка:
            ChartType.BarOfPie,
            ChartType.ExplodedPie,
            ChartType.ExplodedPie3D,
            ChartType.Pie,
            ChartType.Pie3D,
            ChartType.PieOfPie.
Только для чтения [`ILegendEntryProperties`](/slides/python-net/ru/aspose.slides.charts/ilegendentryproperties).
