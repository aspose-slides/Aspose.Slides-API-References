## ParentLabelLayoutType перечисление

Представляет расположение подписей категорий данных. Используется только с рядом Treemap.

Тип ParentLabelLayoutType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| BANNER | Указывает, что подписи родительских категорий отображаются как баннер |
| NONE | Указывает, что подписи родительских категорий не рисуются |
| OVERLAPPING | Указывает, что подписи родительских категорий отображаются наложением |
