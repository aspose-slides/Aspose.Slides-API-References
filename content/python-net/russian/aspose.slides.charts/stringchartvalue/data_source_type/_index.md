## Свойство data_source_type
Указывает, является ли свойство AsCell, AsCells, AsLiteralString или AsLiteralDouble актуальным у наследников. Другими словами, он определяет тип значения свойства Data. Чтение/запись [`DataSourceType`](/slides/python-net/ru/aspose.slides.charts/datasourcetype).

### Примечания
Для точек в ChartDataPointCollection это свойство только для чтения. В этом случае для изменения значения этого свойства вы можете использовать одно из свойств ChartDataPointCollection.DataSourceTypeFor<...>.

@property
def data_source_type(self):
    ...

def data_source_type(self, value):
    ...
