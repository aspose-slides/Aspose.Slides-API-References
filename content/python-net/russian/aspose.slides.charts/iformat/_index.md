## IFormat класс

Представляет свойства формата графика.

Тип IFormat раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`fill`](/slides/python-net/ru/aspose.slides.charts/iformat/fill/) | Возвращает свойства заливки графика.<br/>            Только для чтения [`IFillFormat`](/slides/python-net/ru/aspose.slides/ifillformat). |
| [`line`](/slides/python-net/ru/aspose.slides.charts/iformat/line/) | Возвращает свойства линии графика.<br/>            Только для чтения [`ILineFormat`](/slides/python-net/ru/aspose.slides/ilineformat). |
| [`effect`](/slides/python-net/ru/aspose.slides.charts/iformat/effect/) | Возвращает эффекты, используемые для графика.<br/>            Только для чтения [`IEffectFormat`](/slides/python-net/ru/aspose.slides/ieffectformat). |
| [`effect_3d`](/slides/python-net/ru/aspose.slides.charts/iformat/effect_3d/) | Возвращает 3D-формат графика.<br/>            Только для чтения [`IThreeDFormat`](/slides/python-net/ru/aspose.slides/ithreedformat). |
