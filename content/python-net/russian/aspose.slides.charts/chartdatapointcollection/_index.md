## ChartDataPointCollection класс

Представляет коллекцию точек данных серии.

Тип ChartDataPointCollection раскрывает следующие члены:

## Свойства

| Property | Description |
| :- | :- |
| [`data_source_type_for_x_values`](/slides/python-net/ru/aspose.slides.charts/chartdatapointcollection/data_source_type_for_x_values/) | Указывает, является ли свойство AsCell, AsLiteralString или AsLiteralDouble <br/>            актуальным в объекте свойства XValue точки данных. Другими словами, указывает <br/>            тип значения свойства ChartDataPoint.XValue.Data.<br/>            Чтение/запись [`DataSourceType`](/slides/python-net/ru/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_y_values`](/slides/python-net/ru/aspose.slides.charts/chartdatapointcollection/data_source_type_for_y_values/) | Указывает, является ли свойство AsCell, AsLiteralString или AsLiteralDouble <br/>            актуальным в объекте свойства YValue точки данных. Другими словами, указывает <br/>            тип значения свойства ChartDataPoint.YValue.Data.<br/>            Чтение/запись [`DataSourceType`](/slides/python-net/ru/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_bubble_sizes`](/slides/python-net/ru/aspose.slides.charts/chartdatapointcollection/data_source_type_for_bubble_sizes/) | Указывает, является ли свойство AsCell, AsLiteralString или AsLiteralDouble <br/>            актуальным в объекте свойства BubbleSize точки данных. | [`data_source_type_for_values`](/slides/python-net/ru/aspose.slides.charts/chartdatapointcollection/data_source_type_for_values/) | Указывает, является ли свойство AsCell, AsLiteralString или AsLiteralDouble <br/>            актуальным в объекте свойства Value точки данных. Другими словами, указывает <br/>            тип значения свойства ChartDataPoint.Value.Data.<br/>            Чтение/запись [`DataSourceType`](/slides/python-net/ru/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_error_bars_custom_values`](/slides/python-net/ru/aspose.slides.charts/chartdatapointcollection/data_source_type_for_error_bars_custom_values/) | Указывает типы значений в списке свойств ChartDataPoint.ErrorBarsCustomValues.<br/>            Только чтение [`IDataSourceTypeForErrorBarsCustomValues`](/slides/python-net/ru/aspose.slides.charts/idatasourcetypeforerrorbarscustomvalues). |

Возвращает точку данных серии по индексу (его порядковый номер в этой коллекции).
