## data_source_type_for_y_values свойство
Указывает, является ли свойство AsCell или AsLiteralString или AsLiteralDouble актуальным в объекте свойства YValue точек данных. Другими словами, указывает тип значения свойства ChartDataPoint.YValue.Data. Чтение/запись [`DataSourceType`](/slides/python-net/ru/aspose.slides.charts/datasourcetype).
