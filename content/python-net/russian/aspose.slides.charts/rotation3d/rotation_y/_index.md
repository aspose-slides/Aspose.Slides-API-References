## Свойство rotation_y
Возвращает или задает угол вращения вокруг оси Y, т.е. в направлении оси X для 3D-диаграмм (от 0 до 360 градусов).
            Это свойство соответствует пункту 21.2.2.158 rotY (Y Rotation) в ECMA-376 и опции "X Rotation" в PowerPoint 2007+.
            Чтение/запись **int**.

### Определение:
```python
@property
def rotation_y(self):
    ...

@rotation_y.setter
def rotation_y(self, value):
    ...
```
