## rotation_x свойство
Возвращает или задаёт угол вращения вокруг оси X, т.е. в направлении Y для 3D-диаграмм (от -90 до 90 градусов).  
Это свойство соответствует элементу 21.2.157 rotX (X Rotation) в ECMA-376 и параметру "Y Rotation" в PowerPoint 2007+.  
Чтение/запись **int**.

### Определение:
```python
@property
def rotation_x(self):
    ...

@rotation_x.setter
def rotation_x(self, value):
    ...
```
