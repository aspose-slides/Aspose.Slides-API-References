## is_visible свойство
False означает, что метка данных не видима (and so all Show*-flags (ShowValue, ...) are false).
            Только для чтения **bool**.

### Примечания

Если метка данных видима, вы можете скрыть её с помощью метода Hide().
            Но если метка данных не видима (IsVisible is false), вы можете сделать метку данных видимой 
            установив флаги Show*-flags (ShowValue, ...) в состояние true.
