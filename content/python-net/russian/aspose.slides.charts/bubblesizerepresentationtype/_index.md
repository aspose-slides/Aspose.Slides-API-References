## BubbleSizeRepresentationType перечисление

Указывает возможные способы представления данных в виде размеров пузырчатой диаграммы.

Тип BubbleSizeRepresentationType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| AREA | Указывает, что площадь пузырей должна быть пропорциональна значению размера пузыря. |
| WIDTH | Указывает, что радиус пузырей должен быть пропорционален значению размера пузыря. |
