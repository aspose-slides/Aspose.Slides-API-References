## Перечисление PieSplitType

Представляет тип точек разбиения во втором круге или столбце на диаграмме круг-в-круге или столбец-в-круге.

Тип PieSplitType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| DEFAULT | Указывает, что точки данных должны быть разделены с использованием механизма по умолчанию <br/> для этого типа диаграммы. |
| CUSTOM | Указывает, что точки данных должны быть разделены между <br/> кругом и вторичной диаграммой в соответствии со значениями пользовательского разбиения. |
| BY_PERCENTAGE | Указывает, что точки данных должны быть разделены между кругом и <br/> вторичной диаграммой, помещая точки с процентом ниже <br/> процента позиции разбиения во вторую диаграмму. |
| BY_POS | Указывает, что точки данных должны быть разделены между кругом и <br/> вторичной диаграммой, помещая последнюю позицию разбиения точек данных <br/> во вторую диаграмму. |
| BY_VALUE | Указывает, что точки данных должны быть разделены между кругом и <br/> вторичной диаграммой, помещая точки данных со значением меньше <br/> позиции разбиения во вторую диаграмму. |
