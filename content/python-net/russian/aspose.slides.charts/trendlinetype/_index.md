## TrendlineType enumeration

Представляет тип линии тренда

Тип TrendlineType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| EXPONENTIAL | Указывает, что линия тренда должна быть экспоненциальной кривой в виде. |
| LINEAR | Указывает, что линия тренда должна быть линией в виде. |
| LOGARITHMIC | Указывает, что линия тренда должна быть логарифмической кривой в виде, где log — натуральный логарифм. |
| MOVING_AVERAGE | Указывает, что линия тренда должна быть скользящей средней периода Period. |
| POLYNOMIAL | Указывает, что линия тренда должна быть полиномиальной кривой порядка Order в виде. |
| POWER | Указывает, что линия тренда должна быть степенной кривой в виде. |
