## data_source_type свойство
Указывает, является ли свойство AsCell, AsCells, AsLiteralString или AsLiteralDouble 
актуальным в дочерних классах. Другими словами, указывает тип 
значения свойства Data.
Чтение/запись [`DataSourceType`](/slides/python-net/ru/aspose.slides.charts/datasourcetype).

### Примечания

Для точек в ChartDataPointCollection это свойство только для чтения. 
В этом случае для изменения значения этого свойства вы можете использовать одно из 
ChartDataPointCollection.DataSourceTypeFor<...> свойств.

### Определение:
```python
@property
def data_source_type(self):
    ...

@data_source_type.setter
def data_source_type(self, value):
    ...
```
