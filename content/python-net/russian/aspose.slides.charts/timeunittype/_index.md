## Перечисление TimeUnitType

Представляет базовую единицу для оси категорий

Тип TimeUnitType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| NONE | Значения будут отображаться как есть. |
| DAYS | Указывает, что данные диаграммы должны отображаться в днях. |
| MONTHS | Указывает, что данные диаграммы должны отображаться в месяцах. |
| YEARS | Указывает, что данные диаграммы должны отображаться в годах. |
