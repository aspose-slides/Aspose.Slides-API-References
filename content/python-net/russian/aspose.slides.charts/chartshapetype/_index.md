## ChartShapeType перечисление

Представляет форму диаграммы.

Тип ChartShapeType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| NOT_DEFINED | Форма диаграммы не определена. |
| BOX | Указывает, что диаграмма должна быть нарисована в виде коробки. |
| CONE | Указывает, что диаграмма должна быть изображена в виде конуса, при этом основание конуса находится на плоскости, а вершина конуса — в верхней точке маркера данных. |
| CONE_TO_MAX | Указывает, что диаграмма должна быть построена с усечёнными конусами так, чтобы вершина конуса соответствовала максимальному значению данных. |
| CYLINDER | Указывает, что диаграмма должна быть изображена в виде цилиндра. |
| PYRAMID | Указывает, что диаграмма должна быть изображена в виде прямоугольной пирамиды, при этом основание пирамиды находится на плоскости, а вершина пирамиды — в верхней точке маркера данных. |
| PYRAMID_TO_MAXIMUM | Указывает, что диаграмма должна быть построена с усечёнными конусами так, чтобы вершина конуса соответствовала максимальному значению данных. |
