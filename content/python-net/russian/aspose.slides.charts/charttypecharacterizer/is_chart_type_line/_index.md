## is_chart_type_line(chart_type) {#charttype}
Возвращает true, если chartType является одним из подтипов Line.
            Набор подтипов соответствует соответствующему набору в PowerPoint (см. диалоговое окно "Change Chart Type" в PowerPoint):
            [`ChartType.LINE`](/slides/python-net/ru/aspose.slides.charts/charttype/LINE),
            [`ChartType.LINE_WITH_MARKERS`](/slides/python-net/ru/aspose.slides.charts/charttype/LINE_WITH_MARKERS),
            [`ChartType.PERCENTS_STACKED_LINE`](/slides/python-net/ru/aspose.slides.charts/charttype/PERCENTS_STACKED_LINE),
            [`ChartType.PERCENTS_STACKED_LINE_WITH_MARKERS`](/slides/python-net/ru/aspose.slides.charts/charttype/PERCENTS_STACKED_LINE_WITH_MARKERS),
            [`ChartType.STACKED_LINE`](/slides/python-net/ru/aspose.slides.charts/charttype/STACKED_LINE),
            [`ChartType.STACKED_LINE_WITH_MARKERS`](/slides/python-net/ru/aspose.slides.charts/charttype/STACKED_LINE_WITH_MARKERS),
            [`ChartType.LINE_3D`](/slides/python-net/ru/aspose.slides.charts/charttype/LINE_3D).
