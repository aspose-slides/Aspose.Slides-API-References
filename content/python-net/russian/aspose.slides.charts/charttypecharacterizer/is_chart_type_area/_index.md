## is_chart_type_area(chart_type) {#charttype}
Возвращает true, если chartType является одним из подтипов Area.
            Набор подтипов соответствует соответствующему набору в PowerPoint (см. диалоговое окно "Change Chart Type" в PowerPoint):
            [`ChartType.AREA`](/slides/python-net/ru/aspose.slides.charts/charttype/AREA),
            [`ChartType.PERCENTS_STACKED_AREA`](/slides/python-net/ru/aspose.slides.charts/charttype/PERCENTS_STACKED_AREA),
            [`ChartType.PERCENTS_STACKED_AREA_3D`](/slides/python-net/ru/aspose.slides.charts/charttype/PERCENTS_STACKED_AREA_3D),
            [`ChartType.STACKED_AREA`](/slides/python-net/ru/aspose.slides.charts/charttype/STACKED_AREA),
            [`ChartType.STACKED_AREA_3D`](/slides/python-net/ru/aspose.slides.charts/charttype/STACKED_AREA_3D),
            [`ChartType.AREA_3D`](/slides/python-net/ru/aspose.slides.charts/charttype/AREA_3D).
