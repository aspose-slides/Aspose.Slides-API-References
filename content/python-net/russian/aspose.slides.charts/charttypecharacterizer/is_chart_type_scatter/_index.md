## is_chart_type_scatter(chart_type) {#charttype}
Возвращает true, если chartType является одним из подтипов Scatter.
            Набор подтипов соответствует соответствующему набору в PowerPoint (см. диалоговое окно "Change Chart Type" в PowerPoint):
            [`ChartType.SCATTER_WITH_MARKERS`](/slides/python-net/ru/aspose.slides.charts/charttype/SCATTER_WITH_MARKERS),
            [`ChartType.SCATTER_WITH_SMOOTH_LINES`](/slides/python-net/ru/aspose.slides.charts/charttype/SCATTER_WITH_SMOOTH_LINES),
            [`ChartType.SCATTER_WITH_SMOOTH_LINES_AND_MARKERS`](/slides/python-net/ru/aspose.slides.charts/charttype/SCATTER_WITH_SMOOTH_LINES_AND_MARKERS),
            [`ChartType.SCATTER_WITH_STRAIGHT_LINES`](/slides/python-net/ru/aspose.slides.charts/charttype/SCATTER_WITH_STRAIGHT_LINES),
            [`ChartType.SCATTER_WITH_STRAIGHT_LINES_AND_MARKERS`](/slides/python-net/ru/aspose.slides.charts/charttype/SCATTER_WITH_STRAIGHT_LINES_AND_MARKERS).
