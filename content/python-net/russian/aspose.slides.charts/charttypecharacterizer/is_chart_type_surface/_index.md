## is_chart_type_surface(chart_type) {#charttype}
Возвращает true, если chartType является одним из подтипов Surface.
            Набор подтипов соответствует соответствующему набору в PowerPoint (см. диалоговое окно "Change Chart Type" в PowerPoint):
            [`ChartType.SURFACE_3D`](/slides/python-net/ru/aspose.slides.charts/charttype/SURFACE_3D),
            [`ChartType.WIREFRAME_SURFACE_3D`](/slides/python-net/ru/aspose.slides.charts/charttype/WIREFRAME_SURFACE_3D),
            [`ChartType.CONTOUR`](/slides/python-net/ru/aspose.slides.charts/charttype/CONTOUR),
            [`ChartType.WIREFRAME_CONTOUR`](/slides/python-net/ru/aspose.slides.charts/charttype/WIREFRAME_CONTOUR).
