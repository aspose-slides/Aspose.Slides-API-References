## format свойство
Представляет format подписи данных.
            Только для чтения [`IFormat`](/slides/python-net/ru/aspose.slides.charts/iformat).


### Примечания

Если родительским объектом этого DataLabelFormat является коллекция DataLabelCollection подписи данных, то это свойство представляет format по умолчанию для новых подписей данных в коллекции DataLabelCollection.
