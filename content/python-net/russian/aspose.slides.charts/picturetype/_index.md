## PictureType перечисление

Определяет режим заполнения изображения баров.

Тип PictureType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| NOT_DEFINED | Не определено. |
| STACK | Изображение масштабируется так, чтобы повторяться максимум 15 раз в самом длинном сложенном баре. |
| STACK_SCALE | Изображение масштабируется до указанного количества единиц и повторяется по длине бара. |
| STRETCH | Изображение растягивается на всю длину сложенного бара. |
