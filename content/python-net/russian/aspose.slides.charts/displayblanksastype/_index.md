## DisplayBlanksAsType перечисление

Определяет, как будут отображаться отсутствующие данные.

Тип DisplayBlanksAsType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| GAP | Указывает, что пустые значения следует оставлять как пробел. |
| SPAN | Указывает, что пустые значения следует соединять линией. |
| ZERO | Указывает, что пустые значения следует рассматривать как ноль. |
