## use_cell свойство
Если true, то свойство AsCell актуально. 
            Другими словами, worksheet используется для хранения категории (в этом случае поддерживается многоуровневая категория).
            Если false, то свойство AsLiteral актуально. 
            Другими словами, worksheet НЕ используется для хранения категории (и этот случай не поддерживает многоуровневые категории).
            Только для чтения **bool**.


### Примечания

Для изменения значения этого свойства (для всех категорий в коллекции) установите новое значение свойства ChartCategoryCollection.UseCells свойство.
