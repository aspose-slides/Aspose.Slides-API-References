## Свойство value
Если UseCell равно true, то это свойство представляет свойство AsCell.Value.
Если UseCell равно false, то это свойство представляет свойство AsLiteral.
Чтение/запись **любое**.

### Определение:
```python
@property
def value(self):
    ...

@value.setter
def value(self, value):
    ...
```
