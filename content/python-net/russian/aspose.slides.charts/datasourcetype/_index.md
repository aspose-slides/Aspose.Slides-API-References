## Перечисление DataSourceType

Типы источников данных.

Тип DataSourceType раскрывает следующие члены:

## Поля

| Field | Description |
| :- | :- |
| WORKSHEET | Используйте объекты CellXls для хранения XValue, YValue, Value или BubbleSize точки данных в листе. |
| STRING_LITERALS | Используйте переменную строкового типа с быстрым доступом для хранения XValue, YValue, Value или BubbleSize <br/>            точки данных. Worksheet НЕ используется для хранения значений. |
| DOUBLE_LITERALS | Используйте переменную типа double с быстрым доступом для хранения XValue, YValue, Value или BubbleSize <br/>            точки данных. Worksheet НЕ используется для хранения значений. |
