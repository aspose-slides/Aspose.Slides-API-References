## PieSplitCustomPointCollection класс

Представляет набор точек для разбиения точки в диаграмме типа bar-of-pie или pie-of-pie с пользовательским разбиением.

Тип PieSplitCustomPointCollection раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`is_synchronized`](/slides/python-net/ru/aspose.slides.charts/piesplitcustompointcollection/is_synchronized/) | Возвращает значение, указывающее, синхронизирован ли доступ к коллекции (потокобезопасный).<br/>            Только для чтения **bool**. |
| [`sync_root`](/slides/python-net/ru/aspose.slides.charts/piesplitcustompointcollection/sync_root/) | Возвращает корень синхронизации.<br/>            Только для чтения **any**. |

Возвращает точку данных диаграммы для указанного индекса.
