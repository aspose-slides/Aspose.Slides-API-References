## IUpDownBarsManager класс

Обеспечивает доступ к верхним/нижним барам линейных или котировочных диаграмм.

Тип IUpDownBarsManager раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`up_bars_format`](/slides/python-net/ru/aspose.slides.charts/iupdownbarsmanager/up_bars_format/) | Возвращает формат верхних баров.<br/>            Только для чтения [`IFormat`](/slides/python-net/ru/aspose.slides.charts/iformat). |
| [`down_bars_format`](/slides/python-net/ru/aspose.slides.charts/iupdownbarsmanager/down_bars_format/) | Возвращает формат нижних баров.<br/>            Только для чтения [`IFormat`](/slides/python-net/ru/aspose.slides.charts/iformat). |
| [`has_up_down_bars`](/slides/python-net/ru/aspose.slides.charts/iupdownbarsmanager/has_up_down_bars/) | Определяет, имеет ли диаграмма верхние/нижние бары.<br/>            Чтение/запись **bool**. |
| [`gap_width`](/slides/python-net/ru/aspose.slides.charts/iupdownbarsmanager/gap_width/) | Возвращает или задаёт ширину промежутка.<br/>            Чтение/запись **int**. |
