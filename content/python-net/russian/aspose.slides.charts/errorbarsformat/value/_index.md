## Свойство value
Получает или задает value, который используется с типами значений Fixed, Percentage и StandardDeviation для определения длины линий погрешности.
            В любом другом случае будет возвращён NaN.
            Чтение/запись **float**.

### Определение:
```python
@property
def value(self):
    ...

@value.setter
def value(self, value):
    ...
```
