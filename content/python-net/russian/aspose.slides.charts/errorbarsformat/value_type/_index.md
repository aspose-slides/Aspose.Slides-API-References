## value_type свойство
Представляет возможные способы определения длины погрешностей. 
В случае пользовательского типа значения для указания значения используйте свойство [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/ru/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) конкретной точки данных в коллекции DataPoints серии.
В случае типов значения Fixed, Percentage или StandardDeviation используйте свойство Value для указания значения.  
Чтение/запись [`ErrorBarValueType`](/slides/python-net/ru/aspose.slides.charts/errorbarvaluetype).
