## TickLabelPositionType перечисление

Представляет тип положения меток отметок на указанной оси.

Тип TickLabelPositionType содержит следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| HIGH | Указывает, что подписи оси должны находиться в верхнем конце перпендикулярной оси. |
| LOW | Указывает, что подписи оси должны находиться в нижнем конце перпендикулярной оси. |
| NEXT_TO | Указывает, что подписи оси должны располагаться рядом с осью. |
| NONE | Указывает, что подписи оси не рисуются. |
