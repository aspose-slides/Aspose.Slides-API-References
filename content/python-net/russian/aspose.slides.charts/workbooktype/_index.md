## WorkbookType перечисление

Указывает тип файла рабочей книги Open XML.

Тип WorkbookType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| NOT_DEFINED | Тип рабочей книги не определён. |
| WORKBOOK | Рабочая книга Excel (*.xlsx). |
| WORKBOOK_MACRO | Рабочая книга Excel с поддержкой макросов (*.xlsm). |
| TEMPLATE | Шаблон Excel (*.xltx). |
| TEMPLATE_MACRO | Шаблон Excel с поддержкой макросов (*.xltm). |
| WORKBOOK_BINARY_MACRO | Бинарная рабочая книга Excel с поддержкой макросов (*.xlsb). |
