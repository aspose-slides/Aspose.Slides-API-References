## IMarker класс

Представляет маркер диаграммы.

Тип IMarker раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`symbol`](/slides/python-net/ru/aspose.slides.charts/imarker/symbol/) | Представляет стиль маркера в линейной диаграмме, точечной диаграмме или радиальной диаграмме.<br/>            Чтение/запись [`MarkerStyleType`](/slides/python-net/ru/aspose.slides.charts/markerstyletype). |
| [`format`](/slides/python-net/ru/aspose.slides.charts/imarker/format/) | Получает заполнение маркера.<br/>            Только для чтения [`IFormat`](/slides/python-net/ru/aspose.slides.charts/iformat). |
| [`size`](/slides/python-net/ru/aspose.slides.charts/imarker/size/) | Представляет размер маркера в линейной диаграмме, точечной диаграмме или радиальной диаграмме.<br/>            Чтение/запись **int**. |
