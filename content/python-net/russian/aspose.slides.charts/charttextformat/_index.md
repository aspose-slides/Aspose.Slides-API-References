## ChartTextFormat класс

Указывает форматирование текста по умолчанию для элементов текста диаграммы.

Тип ChartTextFormat предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`text_block_format`](/slides/python-net/ru/aspose.slides.charts/charttextformat/text_block_format/) | TextBlockFormat.<br/>            Только для чтения [`IChartTextBlockFormat`](/slides/python-net/ru/aspose.slides.charts/icharttextblockformat). |
| [`paragraph_format`](/slides/python-net/ru/aspose.slides.charts/charttextformat/paragraph_format/) | ParagraphFormat.<br/>            Только для чтения [`IChartParagraphFormat`](/slides/python-net/ru/aspose.slides.charts/ichartparagraphformat). |
| [`portion_format`](/slides/python-net/ru/aspose.slides.charts/charttextformat/portion_format/) | PortionFormat.<br/>            Только для чтения [`IChartPortionFormat`](/slides/python-net/ru/aspose.slides.charts/ichartportionformat). |
