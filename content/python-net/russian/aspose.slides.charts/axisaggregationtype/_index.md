## перечисление AxisAggregationType

Представляет тип агрегации оси категорий. Используется только с рядами Histogram или HistogramPareto.

Тип AxisAggregationType содержит следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| BY_CATEGORY | Агрегировать по категориям |
| AUTOMATIC | Автоматически агрегировать категории. |
| BY_BIN_WIDTH | Агрегировать категории по ширине корзины. Property IAxis.BinWidth must be setted. |
| BY_NUMBER_OF_BINS | Агрегировать категории по количеству корзин. Property IAxis.NumberOfBins must be setted. |
