## data_source_type свойство
Указывает, актуально ли свойство AsCell, AsCells, AsLiteralString или AsLiteralDouble 
            в дочерних элементах. Иными словами, он определяет тип 
            значения свойства Data.
            Чтение/запись [`DataSourceType`](/slides/python-net/ru/aspose.slides.charts/datasourcetype).


### Замечания

Для точек в ChartDataPointCollection это свойство доступно только для чтения. 
            В этом случае для изменения значения этого свойства можно использовать одно из свойств 
            ChartDataPointCollection.DataSourceTypeFor<...> properties.

```python
@property
def data_source_type(self):
    ...

@data_source_type.setter
def data_source_type(self, value):
    ...
```
