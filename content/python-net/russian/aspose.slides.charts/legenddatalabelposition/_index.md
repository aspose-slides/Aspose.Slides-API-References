## LegendDataLabelPosition перечисление

Определяет положение меток данных.

Тип LegendDataLabelPosition раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| NOT_DEFINED | Позиция не определена. |
| BOTTOM | Указывает, что метки данных должны отображаться ниже маркера данных. |
| BEST_FIT | Указывает, что метки данных должны отображаться в наилучшей позиции. |
| CENTER | Указывает, что метки данных должны отображаться по центру маркера данных. |
| INSIDE_BASE | Указывает, что метки данных должны отображаться внутри основания маркера данных. |
| INSIDE_END | Указывает, что метки данных должны отображаться внутри конца маркера данных. |
| LEFT | Указывает, что метки данных должны отображаться слева от маркера данных. |
| OUTSIDE_END | Указывает, что метки данных должны отображаться снаружи конца маркера данных. |
| RIGHT | Указывает, что метки данных должны отображаться справа от маркера данных. |
| TOP | Указывает, что метки данных должны отображаться выше маркера данных. |
