## use_cells свойство
Если true, то лист используется для хранения категорий (в этом случае поддерживаются многоуровневые категории).
            Если false, то лист НЕ используется для хранения значений (и в этом случае не поддерживаются 
            многоуровневые категории).
            Чтение/запись **bool**.
