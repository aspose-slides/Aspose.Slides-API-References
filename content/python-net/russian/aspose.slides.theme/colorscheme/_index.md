## ColorScheme класс

Хранит цвета, определённые темой.

Тип ColorScheme предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`dark1`](/slides/python-net/ru/aspose.slides.theme/colorscheme/dark1/) | Первый тёмный цвет в схеме.<br/>            Только для чтения [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`light1`](/slides/python-net/ru/aspose.slides.theme/colorscheme/light1/) | Первый светлый цвет в схеме.<br/>            Только для чтения [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`dark2`](/slides/python-net/ru/aspose.slides.theme/colorscheme/dark2/) | Второй тёмный цвет в схеме.<br/>            Только для чтения [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`light2`](/slides/python-net/ru/aspose.slides.theme/colorscheme/light2/) | Второй светлый цвет в схеме.<br/>            Только для чтения [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`accent1`](/slides/python-net/ru/aspose.slides.theme/colorscheme/accent1/) | Первый акцентный цвет в схеме.<br/>            Только для чтения [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`accent2`](/slides/python-net/ru/aspose.slides.theme/colorscheme/accent2/) | Второй акцентный цвет в схеме.<br/>            Только для чтения [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`accent3`](/slides/python-net/ru/aspose.slides.theme/colorscheme/accent3/) | Третий акцентный цвет в схеме.<br/>            Только для чтения [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`accent4`](/slides/python-net/ru/aspose.slides.theme/colorscheme/accent4/) | Четвёртый акцентный цвет в схеме.<br/>            Только для чтения [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`accent5`](/slides/python-net/ru/aspose.slides.theme/colorscheme/accent5/) | Пятый акцентный цвет в схеме.<br/>            Только для чтения [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`accent6`](/slides/python-net/ru/aspose.slides.theme/colorscheme/accent6/) | Шестой акцентный цвет в схеме.<br/>            Только для чтения [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`hyperlink`](/slides/python-net/ru/aspose.slides.theme/colorscheme/hyperlink/) | Цвет для гиперссылок.<br/>            Только для чтения [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`followed_hyperlink`](/slides/python-net/ru/aspose.slides.theme/colorscheme/followed_hyperlink/) | Цвет для посещённых гиперссылок.<br/>            Только для чтения [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`slide`](/slides/python-net/ru/aspose.slides.theme/colorscheme/slide/) | Возвращает родительский слайд.<br/>            Только для чтения [`IBaseSlide`](/slides/python-net/ru/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/ru/aspose.slides.theme/colorscheme/presentation/) | Возвращает родительскую презентацию.<br/>            Только для чтения [`IPresentation`](/slides/python-net/ru/aspose.slides/ipresentation). |
