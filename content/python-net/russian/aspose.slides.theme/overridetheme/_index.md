## OverrideTheme класс

Представляет переопределяющую тему.

**Наследование:**[`OverrideTheme`](/slides/python-net/ru/aspose.slides.theme/overridetheme) → [`Theme`](/slides/python-net/ru/aspose.slides.theme/theme)

Тип OverrideTheme предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`color_scheme`](/slides/python-net/ru/aspose.slides.theme/overridetheme/color_scheme/) | Возвращает цветовую схему.<br/>            Только для чтения [`IColorScheme`](/slides/python-net/ru/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/ru/aspose.slides.theme/overridetheme/font_scheme/) | Возвращает схему шрифтов.<br/>            Только для чтения [`IFontScheme`](/slides/python-net/ru/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/ru/aspose.slides.theme/overridetheme/format_scheme/) | Возвращает схему форматирования фигур.<br/>            Только для чтения [`IFormatScheme`](/slides/python-net/ru/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/ru/aspose.slides.theme/overridetheme/presentation/) | Возвращает родительскую презентацию.<br/>            Только для чтения [`IPresentation`](/slides/python-net/ru/aspose.slides/ipresentation). |
| [`is_empty`](/slides/python-net/ru/aspose.slides.theme/overridetheme/is_empty/) | Значение true означает, что ColorScheme, FontScheme, FormatScheme равны None и любые переопределения с этим объектом темы отключены.<br/>            Только для чтения **bool**. |
