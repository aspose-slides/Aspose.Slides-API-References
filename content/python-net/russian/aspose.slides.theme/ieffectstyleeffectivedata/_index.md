## IEffectStyleEffectiveData класс

Неизменяемый объект, содержащий эффективные свойства стиля эффекта.

Тип IEffectStyleEffectiveData предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`effect_format`](/slides/python-net/ru/aspose.slides.theme/ieffectstyleeffectivedata/effect_format/) | Возвращает формат эффекта.<br/>            Только для чтения [`IEffectFormatEffectiveData`](/slides/python-net/ru/aspose.slides/ieffectformateffectivedata). |
| [`three_d_format`](/slides/python-net/ru/aspose.slides.theme/ieffectstyleeffectivedata/three_d_format/) | Возвращает 3-d формат.<br/>            Только для чтения [`IThreeDFormatEffectiveData`](/slides/python-net/ru/aspose.slides/ithreedformateffectivedata). |


### Примечания
