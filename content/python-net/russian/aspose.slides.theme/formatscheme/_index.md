## Класс FormatScheme

Хранит форматы, определённые темой, для фигур.

Тип FormatScheme предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`fill_styles`](/slides/python-net/ru/aspose.slides.theme/formatscheme/fill_styles/) | Возвращает коллекцию стилей заливки, определённых темой.<br/>            Только для чтения [`IFillFormatCollection`](/slides/python-net/ru/aspose.slides.theme/ifillformatcollection). |
| [`line_styles`](/slides/python-net/ru/aspose.slides.theme/formatscheme/line_styles/) | Возвращает коллекцию стилей линий, определённых темой.<br/>            Только для чтения [`ILineFormatCollection`](/slides/python-net/ru/aspose.slides.theme/ilineformatcollection). |
| [`effect_styles`](/slides/python-net/ru/aspose.slides.theme/formatscheme/effect_styles/) | Возвращает коллекцию стилей эффектов, определённых темой.<br/>            Только для чтения [`IEffectStyleCollection`](/slides/python-net/ru/aspose.slides.theme/ieffectstylecollection). |
| [`background_fill_styles`](/slides/python-net/ru/aspose.slides.theme/formatscheme/background_fill_styles/) | Возвращает коллекцию стилей фоновой заливки, определённых темой.<br/>            Только для чтения [`IFillFormatCollection`](/slides/python-net/ru/aspose.slides.theme/ifillformatcollection). |
| [`slide`](/slides/python-net/ru/aspose.slides.theme/formatscheme/slide/) | Возвращает родительский слайд.<br/>            Только для чтения [`IBaseSlide`](/slides/python-net/ru/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/ru/aspose.slides.theme/formatscheme/presentation/) | Возвращает родительскую презентацию.<br/>            Только для чтения [`IPresentation`](/slides/python-net/ru/aspose.slides/ipresentation). |
