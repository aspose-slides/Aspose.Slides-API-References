## is_override_theme_enabled свойство
Determines whether OverrideTheme overrides inherited effective theme or not.
            Чтобы включить переопределение OverrideTheme, используйте методы OverrideTheme.Init*().
            Чтобы отключить переопределение OverrideTheme, используйте метод OverrideTheme.Clear().
            Только для чтения **bool**.
