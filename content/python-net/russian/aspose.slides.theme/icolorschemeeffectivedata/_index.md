## IColorSchemeEffectiveData класс

Неизменяемый объект, содержащий свойства эффективной цветовой схемы.

Тип IColorSchemeEffectiveData раскрывает следующие члены:

## Свойства

| Property | Description |
| :- | :- |
| [`dark1`](/slides/python-net/ru/aspose.slides.theme/icolorschemeeffectivedata/dark1/) | Первый темный цвет в схеме.<br/>            Только для чтения [`Color`](/slides/python-net/ru/aspose.slides/color). |
| [`light1`](/slides/python-net/ru/aspose.slides.theme/icolorschemeeffectivedata/light1/) | Первый светлый цвет в схеме.<br/>            Только для чтения [`Color`](/slides/python-net/ru/aspose.slides/color). |
| [`dark2`](/slides/python-net/ru/aspose.slides.theme/icolorschemeeffectivedata/dark2/) | Второй темный цвет в схеме.<br/>            Только для чтения [`Color`](/slides/python-net/ru/aspose.slides/color). |
| [`light2`](/slides/python-net/ru/aspose.slides.theme/icolorschemeeffectivedata/light2/) | Второй светлый цвет в схеме.<br/>            Только для чтения [`Color`](/slides/python-net/ru/aspose.slides/color). |
| [`accent1`](/slides/python-net/ru/aspose.slides.theme/icolorschemeeffectivedata/accent1/) | Первый цвет акцента в схеме.<br/>            Только для чтения [`Color`](/slides/python-net/ru/aspose.slides/color). |

| [`accent4`](/slides/python-net/ru/aspose.slides.theme/icolorschemeeffectivedata/accent4/) | Четвертый цвет акцента в схеме.<br/>            Только для чтения [`Color`](/slides/python-net/ru/aspose.slides/color). |
