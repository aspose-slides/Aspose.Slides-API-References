## IColorSchemeEffectiveData класс

Неизменяемый объект, содержащий эффективные свойства схемы цветов.

Тип IColorSchemeEffectiveData раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`dark1`](/slides/python-net/ru/aspose.slides.theme/icolorschemeeffectivedata/dark1/) | Первый тёмный цвет в схеме.<br/>Только для чтения **aspose.slides.Color**. |
| [`light1`](/slides/python-net/ru/aspose.slides.theme/icolorschemeeffectivedata/light1/) | Первый светлый цвет в схеме.<br/>Только для чтения **aspose.slides.Color**. |
| [`dark2`](/slides/python-net/ru/aspose.slides.theme/icolorschemeeffectivedata/dark2/) | Второй тёмный цвет в схеме.<br/>Только для чтения **aspose.slides.Color**. |
| [`light2`](/slides/python-net/ru/aspose.slides.theme/icolorschemeeffectivedata/light2/) | Второй светлый цвет в схеме.<br/>Только для чтения **aspose.slides.Color**. |
| [`accent1`](/slides/python-net/ru/aspose.slides.theme/icolorschemeeffectivedata/accent1/) | Первый акцентный цвет в схеме.<br/>Только для чтения **aspose.slides.Color**. |
