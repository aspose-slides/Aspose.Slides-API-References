## IFontSchemeEffectiveData класс

Неизменяемый объект, содержащий свойства эффективной схемы шрифтов.

Тип IFontSchemeEffectiveData предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`minor`](/slides/python-net/ru/aspose.slides.theme/ifontschemeeffectivedata/minor/) | Возвращает коллекцию шрифтов для части слайда "body".<br/>            Только для чтения [`IFontsEffectiveData`](/slides/python-net/ru/aspose.slides/ifontseffectivedata). |
| [`major`](/slides/python-net/ru/aspose.slides.theme/ifontschemeeffectivedata/major/) | Возвращает коллекцию шрифтов для части слайда "heading".<br/>            Только для чтения [`IFontsEffectiveData`](/slides/python-net/ru/aspose.slides/ifontseffectivedata). |
| [`name`](/slides/python-net/ru/aspose.slides.theme/ifontschemeeffectivedata/name/) | Возвращает имя схемы шрифтов.<br/>            Только для чтения **str**. |

### Примечания

Этот интерфейс используется как часть [`IThemeEffectiveData`](/slides/python-net/ru/aspose.slides.theme/ithemeeffectivedata).
