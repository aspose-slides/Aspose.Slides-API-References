## is_override_theme_enabled свойство
Определяет, переопределяет ли OverrideTheme унаследованную эффективную тему или нет.
            Чтобы включить OverrideTheme для переопределения, используйте методы OverrideTheme.Init*().
            Чтобы отключить OverrideTheme от переопределения, используйте метод OverrideTheme.Clear().
            Только для чтения **bool**.
