## FontScheme класс

Хранит шрифты, определённые темой.

Тип FontScheme предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`minor`](/slides/python-net/ru/aspose.slides.theme/fontscheme/minor/) | Возвращает коллекцию шрифтов для части "body" слайда.<br/>            Только для чтения [`IFonts`](/slides/python-net/ru/aspose.slides/ifonts). |
| [`major`](/slides/python-net/ru/aspose.slides.theme/fontscheme/major/) | Возвращает коллекцию шрифтов для части "heading" слайда.<br/>            Только для чтения [`IFonts`](/slides/python-net/ru/aspose.slides/ifonts). |
| [`name`](/slides/python-net/ru/aspose.slides.theme/fontscheme/name/) | Возвращает имя схемы шрифтов.<br/>            Чтение/запись **str**. |
