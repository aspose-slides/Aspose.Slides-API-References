## свойство is_override_theme_enabled
Определяет, переопределяет ли OverrideTheme наследуемую эффективную тему или нет.
            Чтобы включить OverrideTheme для переопределения, используйте методы OverrideTheme.Init*().
            Чтобы отключить переопределение OverrideTheme, используйте метод OverrideTheme.Clear().
            Только для чтения **bool**.
