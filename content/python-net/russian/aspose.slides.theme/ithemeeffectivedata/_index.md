## IThemeEffectiveData класс

Неизменяемый объект, содержащий эффективные свойства темы.

Тип IThemeEffectiveData раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`font_scheme`](/slides/python-net/ru/aspose.slides.theme/ithemeeffectivedata/font_scheme/) | Возвращает схему шрифтов.<br/>            Только для чтения [`IFontSchemeEffectiveData`](/slides/python-net/ru/aspose.slides.theme/ifontschemeeffectivedata). |
| [`format_scheme`](/slides/python-net/ru/aspose.slides.theme/ithemeeffectivedata/format_scheme/) | Возвращает схему форматов фигур.<br/>            Только для чтения [`IFormatSchemeEffectiveData`](/slides/python-net/ru/aspose.slides.theme/iformatschemeeffectivedata). |

## Методы

| Метод | Описание |
| :- | :- |
| [`get_color_scheme(self, style_color)`](/slides/python-net/ru/aspose.slides.theme/ithemeeffectivedata/get_color_scheme/#asposeslidescolor) | Возвращает схему цветов. |


### Замечания

Этот интерфейс используется вместе с интерфейсом [`ITheme`](/slides/python-net/ru/aspose.slides.theme/itheme) для возврата эффективных значений форматирования с применённым наследованием.
