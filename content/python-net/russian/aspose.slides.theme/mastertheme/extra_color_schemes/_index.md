## extra_color_schemes свойство
Возвращает коллекцию дополнительных цветовых схем.
            Эти схемы не влияют на внешний вид презентации, их можно выбрать в качестве основной цветовой схемы для слайда.
            Только для чтения [`IExtraColorSchemeCollection`](/slides/python-net/ru/aspose.slides.theme/iextracolorschemecollection).
