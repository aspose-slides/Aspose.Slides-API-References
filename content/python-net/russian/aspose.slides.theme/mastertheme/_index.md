## MasterTheme класс

Представляет мастер-тему.

**Наследование:**[`MasterTheme`](/slides/python-net/ru/aspose.slides.theme/mastertheme) → [`Theme`](/slides/python-net/ru/aspose.slides.theme/theme)

Тип MasterTheme раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`color_scheme`](/slides/python-net/ru/aspose.slides.theme/mastertheme/color_scheme/) | Возвращает схему цветов.<br/>            Только для чтения [`IColorScheme`](/slides/python-net/ru/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/ru/aspose.slides.theme/mastertheme/font_scheme/) | Возвращает схему шрифтов.<br/>            Только для чтения [`IFontScheme`](/slides/python-net/ru/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/ru/aspose.slides.theme/mastertheme/format_scheme/) | Возвращает схему формата фигур.<br/>            Только для чтения [`IFormatScheme`](/slides/python-net/ru/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/ru/aspose.slides.theme/mastertheme/presentation/) | Возвращает родительскую презентацию.<br/>            Только для чтения [`IPresentation`](/slides/python-net/ru/aspose.slides/ipresentation). |
| [`extra_color_schemes`](/slides/python-net/ru/aspose.slides.theme/mastertheme/extra_color_schemes/) | Возвращает коллекцию дополнительных схем цветов.<br/>            Эти схемы не влияют на внешний вид презентации, их можно выбрать в качестве основной схемы цветов для слайда.<br/>            Только для чтения [`IExtraColorSchemeCollection`](/slides/python-net/ru/aspose.slides.theme/iextracolorschemecollection). |
| [`name`](/slides/python-net/ru/aspose.slides.theme/mastertheme/name/) | Возвращает название темы.<br/>            Чтение/запись **str**. |
