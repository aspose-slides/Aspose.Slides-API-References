## IOverrideThemeManager класс

Обеспечивает доступ к различным типам переопределённых тем.

Тип IOverrideThemeManager раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`is_override_theme_enabled`](/slides/python-net/ru/aspose.slides.theme/ioverridethememanager/is_override_theme_enabled/) | Определяет, переопределяет ли OverrideTheme унаследованную эффективную тему или нет.<br/>            Чтобы включить переопределение темы, используйте методы OverrideTheme.Init*().<br/>            Чтобы отключить переопределение темы, используйте метод OverrideTheme.Clear().<br/>            Только чтение **bool**. |
| [`override_theme`](/slides/python-net/ru/aspose.slides.theme/ioverridethememanager/override_theme/) | Возвращает объект переопределяющей темы.<br/>            Чтение/запись [`IOverrideTheme`](/slides/python-net/ru/aspose.slides.theme/ioverridetheme). |
