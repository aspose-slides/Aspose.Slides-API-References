## Классы

| Класс | Описание |
| :- | :- |
| [`Collect`](/slides/python-net/ru/aspose.slides.lowcode/collect/) | Представляет группу методов, предназначенных для сбора объектных моделей различных типов из [`Presentation`](/slides/python-net/ru/aspose.slides/presentation). |
| [`Compress`](/slides/python-net/ru/aspose.slides.lowcode/compress/) | Представляет группу методов, предназначенных для сжатия [`Presentation`](/slides/python-net/ru/aspose.slides/presentation). |
| [`Convert`](/slides/python-net/ru/aspose.slides.lowcode/convert/) | Представляет группу методов, предназначенных для преобразования [`Presentation`](/slides/python-net/ru/aspose.slides/presentation). |
| [`ForEach`](/slides/python-net/ru/aspose.slides.lowcode/foreach/) | Представляет группу методов, предназначенных для итерации по различным объектам моделей [`Presentation`](/slides/python-net/ru/aspose.slides/presentation).<br/>            Эти методы могут быть полезны, если вам нужно пройтись и изменить форматирование или содержимое некоторых элементов Presentation,<br/>             например изменить форматирование каждой части. |
| [`Merger`](/slides/python-net/ru/aspose.slides.lowcode/merger/) | Представляет группу методов для объединения презентаций PowerPoint одинакового формата в один файл. |
