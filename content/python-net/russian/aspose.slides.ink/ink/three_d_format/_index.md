## three_d_format свойство
Returns the ThreeDFormat object that 3d effect properties for a shape.
            Примечание: can return None for certain types of shapes which don't have 3d properties.
            Только для чтения [`IThreeDFormat`](/slides/python-net/ru/aspose.slides/ithreedformat).
