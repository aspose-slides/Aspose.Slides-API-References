## line_format свойство
Возвращает объект LineFormat, который содержит свойства форматирования линий для фигуры.
            Примечание: может возвращать None для некоторых типов фигур, у которых нет свойств линий.
            Только для чтения [`ILineFormat`](/slides/python-net/ru/aspose.slides/ilineformat).
