## parent_group свойство
Возвращает объект parent GroupShape, если фигура сгруппирована. В противном случае возвращает None.
            Только для чтения [`IGroupShape`](/slides/python-net/ru/aspose.slides/igroupshape).

### Примечания

Свойство [`Shape.is_grouped`](/slides/python-net/ru/aspose.slides/shape/is_grouped) определяет, сгруппирована ли фигура.
