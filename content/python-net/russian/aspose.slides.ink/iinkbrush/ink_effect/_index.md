## ink_effect свойство
Получает тип эффекта чернил (например, Galaxy, Gold, Silver), определяющий визуальный стиль штриха чернила.
            Значение извлекается из свойства кисти "inkEffects". Если распознанный эффект не указан,
            [`InkEffectType.NOT_DEFINED`](/slides/python-net/ru/aspose.slides.ink/inkeffecttype/NOT_DEFINED) возвращается.
