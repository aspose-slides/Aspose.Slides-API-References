## ink_effect свойство
Получает тип эффекта чернил (e.g., Galaxy, Gold, Silver), определяющий визуальный стиль штриха чернила.
            Значение извлекается из свойства кисти "inkEffects". Если указан нераспознанный эффект,
            [`InkEffectType.NOT_DEFINED`](/slides/python-net/ru/aspose.slides.ink/inkeffecttype/NOT_DEFINED) возвращается.
