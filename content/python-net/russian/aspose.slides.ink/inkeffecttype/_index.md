## InkEffectType перечисление

Указывает набор предопределённых визуальных эффектов для отрисовки чернил.  
Каждый эффект соответствует текстуре или изображению, имитирующему стилизованный вид чернил.  
Эти значения могут использоваться для настройки визуального стиля цифровых штрихов чернил во время отрисовки.

Тип InkEffectType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| NOT_DEFINED | Эффект не определён или неизвестен. Это значение может использоваться как значение по умолчанию или резервное. |
| BRONZE | Тёплая, коричневатая металлическая текстура, напоминающая бронзовые чернила. |
| GALAXY | Яркая, мерцающая текстура, напоминающая галактику, с космическими оттенками. |
| GOLD | Светлая металлическая золотая текстура, придающая штрихам чернил роскошный вид. |
| LAVA | Огненная текстура, напоминающая расплавленную лаву, с красными и оранжевыми оттенками. |
| OCEAN | Глубокая синяя, похожая на жидкость текстура, имитирующая океанские волны или водные чернила. |
| RAINBOW_GLITTER | Яркий, мерцающий радужный блестящий эффект, используемый для праздничных или живых штрихов чернил. |
| ROSE_GOLD | Мягкое сочетание розового и золотого, похожее на розовое золото, для изящных штрихов чернил. |
| SILVER | Холодная металлическая серебряная текстура, имитирующая классические серебряные чернила. |
