## width свойство
Gets or sets the width of the shape, measured in points.
            Чтение/запись **float**.


### Примечания

Возвращаемое значение всегда определено и никогда **float**.
            Назначаемое значение также должно быть определено; присваивайте **float** только свойствам экземпляра `RawFrame`.
