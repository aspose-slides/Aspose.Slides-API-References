## z_order_position свойство
Возвращает позицию фигуры в z-порядке.
            Shapes[0] возвращает фигуру, находящуюся в задней части z-порядка,
            а Shapes[Shapes.Count - 1] возвращает фигуру, находящуюся в передней части z-порядка.
            Только для чтения **int**.
