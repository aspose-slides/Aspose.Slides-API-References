## TransitionMorphType перечисление

Представляет тип морфного перехода.

Тип TransitionMorphType предоставляет следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| BY_OBJECT | Переход морфа будет выполнен с учётом фигур как неделимых объектов. |
| BY_WORD | Переход морфа будет выполнен с переносом текста по словам, где это возможно. |
| BY_CHAR | Переход морфа будет выполнен с переносом текста по символам, где это возможно. |
