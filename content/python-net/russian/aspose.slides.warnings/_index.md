Содержит классы, представляющие различные типы предупреждений

## Классы

| Класс | Описание |
| :- | :- |
| [`IKnownIssueWarningInfo`](/slides/python-net/ru/aspose.slides.warnings/iknownissuewarninginfo/) | Представляет предупреждение о известной проблеме, которую в ближайшем будущем не исправят. |
| [`INotImplementedWarningInfo`](/slides/python-net/ru/aspose.slides.warnings/inotimplementedwarninginfo/) | Представляет предупреждение о известной не реализованной функции, которую в ближайшем будущем не реализуют. |
| [`IObsoletePresLockingBehaviorWarningInfo`](/slides/python-net/ru/aspose.slides.warnings/iobsoletepreslockingbehaviorwarninginfo/) | Это предупреждение указывает, что используется устаревшее поведение блокировки презентации. |
| [`IPresentationSignedWarningInfo`](/slides/python-net/ru/aspose.slides.warnings/ipresentationsignedwarninginfo/) | Это предупреждение указывает, что читаемая презентация имеет подпись <br/>            и эта подпись будет удалена во время обработки. |
| [`IWarningCallback`](/slides/python-net/ru/aspose.slides.warnings/iwarningcallback/) | Интерфейс для классов, получающих предупреждение |
| [`IWarningInfo`](/slides/python-net/ru/aspose.slides.warnings/iwarninginfo/) | Представляет базовый интерфейс для всех предупреждений. |
