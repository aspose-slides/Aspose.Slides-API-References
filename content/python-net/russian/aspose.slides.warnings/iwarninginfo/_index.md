## IWarningInfo класс

Представляет базовый интерфейс для всех предупреждений.

Тип IWarningInfo открывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`warning_type`](/slides/python-net/ru/aspose.slides.warnings/iwarninginfo/warning_type/) | Возвращает тип предупреждения.<br/>            Только для чтения [`IWarningInfo.warning_type`](/slides/python-net/ru/aspose.slides.warnings/iwarninginfo/warning_type). |
| [`description`](/slides/python-net/ru/aspose.slides.warnings/iwarninginfo/description/) | Возвращает человекочитаемое описание этого предупреждения.<br/>            Только для чтения **str**. |

## Методы

| Метод | Описание |
| :- | :- |
| [`send_warning(self, receiver)`](/slides/python-net/ru/aspose.slides.warnings/iwarninginfo/send_warning/#iwarningcallback) | Если receiver не None, завершает предупреждение указанному получателю и бросает <br/>            AbortRequestedException, если получатель решил прервать операцию. |
