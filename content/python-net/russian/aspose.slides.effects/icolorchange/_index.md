## IColorChange класс

Представляет эффект изменения цвета. Экземпляры FromColor заменяются экземплярами ToColor.

Тип IColorChange раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`from_color`](/slides/python-net/ru/aspose.slides.effects/icolorchange/from_color/) | Цвет, который будет заменён.<br/>            Только для чтения [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`to_color`](/slides/python-net/ru/aspose.slides.effects/icolorchange/to_color/) | Цвет, который заменит.<br/>            Только для чтения [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
