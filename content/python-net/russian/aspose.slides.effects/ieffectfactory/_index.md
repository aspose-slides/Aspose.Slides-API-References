## IEffectFactory класс

Позволяет создавать экземпляры эффектов

Тип IEffectFactory предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`image_transform_operation_factory`](/slides/python-net/ru/aspose.slides.effects/ieffectfactory/image_transform_operation_factory/) | Возвращает ImageTransformOperationFactory.<br/>            Только для чтения [`IImageTransformOperationFactory`](/slides/python-net/ru/aspose.slides.effects/iimagetransformoperationfactory). |

## Методы

| Метод | Описание |
| :- | :- |
| [`create_glow(self)`](/slides/python-net/ru/aspose.slides.effects/ieffectfactory/create_glow/#) | Создаёт эффект Glow. |
| [`create_inner_shadow(self)`](/slides/python-net/ru/aspose.slides.effects/ieffectfactory/create_inner_shadow/#) | Создаёт эффект внутренней тени. |
| [`create_outer_shadow(self)`](/slides/python-net/ru/aspose.slides.effects/ieffectfactory/create_outer_shadow/#) | Создаёт эффект внешней тени. |
| [`create_preset_shadow(self)`](/slides/python-net/ru/aspose.slides.effects/ieffectfactory/create_preset_shadow/#) | Создаёт предустановленный эффект тени. |
| [`create_reflection(self)`](/slides/python-net/ru/aspose.slides.effects/ieffectfactory/create_reflection/#) | Создаёт эффект отражения. |
| [`create_soft_edge(self)`](/slides/python-net/ru/aspose.slides.effects/ieffectfactory/create_soft_edge/#) | Создаёт эффект мягкой границы. |
