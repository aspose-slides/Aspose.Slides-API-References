## IOuterShadow класс

Представляет эффект внешней тени.

Тип IOuterShadow предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`blur_radius`](/slides/python-net/ru/aspose.slides.effects/ioutershadow/blur_radius/) | Радиус размытия в пунктах.<br/>            Значение по умолчанию – 0 pt.<br/>            Чтение/запись **float**. |
| [`direction`](/slides/python-net/ru/aspose.slides.effects/ioutershadow/direction/) | Направление тени в градусах.<br/>            Значение по умолчанию – 0 ° (слева направо).<br/>            Чтение/запись **float**. |
| [`distance`](/slides/python-net/ru/aspose.slides.effects/ioutershadow/distance/) | Расстояние тени от объекта в пунктах.<br/>            Значение по умолчанию – 0 pt.<br/>            Чтение/запись **float**. |
| [`shadow_color`](/slides/python-net/ru/aspose.slides.effects/ioutershadow/shadow_color/) | Цвет тени.<br/>            Значение по умолчанию – автоматический черный (зависит от темы).<br/>            Только для чтения [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`rectangle_align`](/slides/python-net/ru/aspose.slides.effects/ioutershadow/rectangle_align/) | Выравнивание прямоугольника.<br/>            Значение по умолчанию – [`RectangleAlignment.BOTTOM`](/slides/python-net/ru/aspose.slides/rectanglealignment/BOTTOM). <br/>            Чтение/запись [`RectangleAlignment`](/slides/python-net/ru/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/ru/aspose.slides.effects/ioutershadow/skew_horizontal/) | Горизонтальный угол наклона в градусах.<br/>            Значение по умолчанию – 0 °.<br/>            Чтение/запись **float**. |
| [`skew_vertical`](/slides/python-net/ru/aspose.slides.effects/ioutershadow/skew_vertical/) | Вертикальный угол наклона в градусах.<br/>            Значение по умолчанию – 0 °.<br/>            Чтение/запись **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/ru/aspose.slides.effects/ioutershadow/rotate_shadow_with_shape/) | Указывает, вращается ли тень вместе с фигурой.<br/>            Значение по умолчанию – true.<br/>            Чтение/запись **bool**. |
| [`scale_horizontal`](/slides/python-net/ru/aspose.slides.effects/ioutershadow/scale_horizontal/) | Коэффициент горизонтального масштабирования в процентах от оригинального размера.<br/>            Отрицательное масштабирование приводит к отражению.<br/>            Значение по умолчанию – 100 %.<br/>            Чтение/запись **float**. |
| [`scale_vertical`](/slides/python-net/ru/aspose.slides.effects/ioutershadow/scale_vertical/) | Коэффициент вертикального масштабирования в процентах от оригинального размера.<br/>            Отрицательное масштабирование приводит к отражению.<br/>            Значение по умолчанию – 100 %.<br/>            Чтение/запись **float**. |
