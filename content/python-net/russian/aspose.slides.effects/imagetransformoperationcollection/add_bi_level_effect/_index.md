## add_bi_level_effect(self, threshold) {#float}
Добавляет новый эффект Bi-Level (чёрный/белый) в конец коллекции.

### Возвращаемое значение

Индекс нового эффекта изображения в коллекции.



```python
def add_bi_level_effect(self, threshold):
    ...
```


| Параметр | Тип | Описание |
| :- | :- | :- |
| threshold | **float** | порог яркости для эффекта Bi-Level.<br/><br/>Значения, большие или равные порогу, устанавливаются в белый.<br/><br/>Значения, меньшие порога, устанавливаются в чёрный. |
