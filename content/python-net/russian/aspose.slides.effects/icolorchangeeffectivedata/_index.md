## IColorChangeEffectiveData класс

Неизменяемый объект, представляющий эффект изменения цвета.
            Экземпляры FromColor заменяются экземплярами ToColor.

Тип IColorChangeEffectiveData раскрывает следующие члены:

## Свойства

| Property | Description |
| :- | :- |
| [`from_color`](/slides/python-net/ru/aspose.slides.effects/icolorchangeeffectivedata/from_color/) | Цвет, который будет заменён.<br/>            Только для чтения **aspose.slides.Color**. |
| [`to_color`](/slides/python-net/ru/aspose.slides.effects/icolorchangeeffectivedata/to_color/) | Цвет, который заменит.<br/>            Только для чтения **aspose.slides.Color**. |
| [`use_alpha`](/slides/python-net/ru/aspose.slides.effects/icolorchangeeffectivedata/use_alpha/) | Возвращает логическое значение, определяющее, следует ли использовать альфа-компонент.<br/>            Только для чтения **bool**. |
