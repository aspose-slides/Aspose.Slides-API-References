## IColorChangeEffectiveData класс

Неизменяемый объект, представляющий эффект изменения цвета.
            Instances of FromColor are replaced with instances of ToColor.

Тип IColorChangeEffectiveData раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`from_color`](/slides/python-net/ru/aspose.slides.effects/icolorchangeeffectivedata/from_color/) | Цвет, который будет заменён.<br/>            Только для чтения [`Color`](/slides/python-net/ru/aspose.slides/color). |
| [`to_color`](/slides/python-net/ru/aspose.slides.effects/icolorchangeeffectivedata/to_color/) | Цвет, который заменит.<br/>            Только для чтения [`Color`](/slides/python-net/ru/aspose.slides/color). |
