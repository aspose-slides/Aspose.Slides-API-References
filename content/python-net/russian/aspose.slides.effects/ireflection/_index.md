## IReflection класс

Представляет эффект отражения.

Тип IReflection предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/ru/aspose.slides.effects/ireflection/start_pos_alpha/) | Указывает начальную позицию (по градиенту альфа) значения начального альфа (в процентах).<br/>            Чтение/запись **float**. |
| [`end_pos_alpha`](/slides/python-net/ru/aspose.slides.effects/ireflection/end_pos_alpha/) | Указывает конечную позицию (по градиенту альфа) значения конечного альфа (в процентах).<br/>            Чтение/запись **float**. |
| [`fade_direction`](/slides/python-net/ru/aspose.slides.effects/ireflection/fade_direction/) | Указывает направление смещения отражения. (угол).<br/>            Чтение/запись **float**. |
| [`start_reflection_opacity`](/slides/python-net/ru/aspose.slides.effects/ireflection/start_reflection_opacity/) | Начальная непрозрачность отражения. (проценты).<br/>            Чтение/запись **float**. |
| [`end_reflection_opacity`](/slides/python-net/ru/aspose.slides.effects/ireflection/end_reflection_opacity/) | Конечная непрозрачность отражения. (проценты).<br/>            Чтение/запись **float**. |
| [`blur_radius`](/slides/python-net/ru/aspose.slides.effects/ireflection/blur_radius/) | Радиус размытия.<br/>            Чтение/запись **float**. |
| [`direction`](/slides/python-net/ru/aspose.slides.effects/ireflection/direction/) | Направление отражения.<br/>            Чтение/запись **float**. |
| [`distance`](/slides/python-net/ru/aspose.slides.effects/ireflection/distance/) | Расстояние отражения.<br/>            Чтение/запись **float**. |
| [`rectangle_align`](/slides/python-net/ru/aspose.slides.effects/ireflection/rectangle_align/) | Выравнивание прямоугольника.<br/>            Чтение/запись [`RectangleAlignment`](/slides/python-net/ru/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/ru/aspose.slides.effects/ireflection/skew_horizontal/) | Указывает угол горизонтального наклона.<br/>            Чтение/запись **float**. |
| [`skew_vertical`](/slides/python-net/ru/aspose.slides.effects/ireflection/skew_vertical/) | Указывает угол вертикального наклона.<br/>            Чтение/запись **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/ru/aspose.slides.effects/ireflection/rotate_shadow_with_shape/) | Указывает, должен ли отражение вращаться вместе с фигурой, если фигура вращается.<br/>            Чтение/запись **bool**. |
| [`scale_horizontal`](/slides/python-net/ru/aspose.slides.effects/ireflection/scale_horizontal/) | Указывает горизонтальный коэффициент масштабирования, отрицательное масштабирование вызывает отражение. (проценты)<br/>            Чтение/запись **float**. |
| [`scale_vertical`](/slides/python-net/ru/aspose.slides.effects/ireflection/scale_vertical/) | Указывает вертикальный коэффициент масштабирования, отрицательное масштабирование вызывает отражение. (проценты)<br/>            Чтение/запись **float**. |
