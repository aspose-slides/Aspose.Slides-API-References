## IDuotoneEffectiveData класс

Неизменяемый объект, представляющий эффект Duotone.
            Для каждого пикселя комбинирует clr1 и clr2 с помощью линейной интерполяции, чтобы определить новый цвет этого пикселя.

Тип IDuotoneEffectiveData раскрывает следующие члены:

## Свойства

| Property | Description |
| :- | :- |
| [`color1`](/slides/python-net/ru/aspose.slides.effects/iduotoneeffectivedata/color1/) | Возвращает целевой формат цвета для темных пикселей.<br/>            Read-only **aspose.slides.Color**. |
| [`color2`](/slides/python-net/ru/aspose.slides.effects/iduotoneeffectivedata/color2/) | Возвращает целевой формат цвета для светлых пикселей.<br/>            Read-only **aspose.slides.Color**. |
