## IDuotoneEffectiveData класс

Неизменяемый объект, представляющий эффект дуотона.
            Для каждого пикселя сочетает clr1 и clr2 посредством линейной интерполяции, чтобы определить новый цвет этого пикселя.

Тип IDuotoneEffectiveData раскрывает следующие члены:
