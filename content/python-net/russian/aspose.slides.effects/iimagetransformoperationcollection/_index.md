## IImageTransformOperationCollection класс

Представляет коллекцию эффектов, применяемых к изображению.

Тип IImageTransformOperationCollection раскрывает следующие члены:

Возвращает [`IImageTransformOperation`](/slides/python-net/ru/aspose.slides.effects/iimagetransformoperation) из коллекции по его индексу.
