## IVbaProject класс

Представляет проект VBA с макросами презентации.

Тип IVbaProject раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`name`](/slides/python-net/ru/aspose.slides.vba/ivbaproject/name/) | Возвращает имя проекта VBA.<br/>            Только для чтения **str**. |
| [`modules`](/slides/python-net/ru/aspose.slides.vba/ivbaproject/modules/) | Возвращает список всех модулей, содержащихся в проекте VBA.<br/>            Только для чтения [`IVbaModuleCollection`](/slides/python-net/ru/aspose.slides.vba/ivbamodulecollection). |
| [`references`](/slides/python-net/ru/aspose.slides.vba/ivbaproject/references/) | Возвращает список всех ссылок, содержащихся в проекте VBA.<br/>            Только для чтения [`IVbaReferenceCollection`](/slides/python-net/ru/aspose.slides.vba/ivbareferencecollection). |
| [`is_password_protected`](/slides/python-net/ru/aspose.slides.vba/ivbaproject/is_password_protected/) | Указывает, защищён ли VBAProject паролем для просмотра свойств проекта.<br/>            Только для чтения **bool**. |

## Методы

| Метод | Описание |
| :- | :- |
| [`to_binary(self)`](/slides/python-net/ru/aspose.slides.vba/ivbaproject/to_binary/#) | Возвращает бинарное представление проекта VBA в виде OLE-контейнера.<br/>            Только для чтения **int**[]. |
