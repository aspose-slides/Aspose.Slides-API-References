## AfterAnimationType перечисление

Представляет тип анимации после анимационного эффекта.

Тип AfterAnimationType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| DO_NOT_DIM | Не затемнять после анимации. |
| COLOR | Цвет после анимации. |
| HIDE_AFTER_ANIMATION | Скрывать после анимации |
| HIDE_ON_NEXT_MOUSE_CLICK | Скрывать при следующем щелчке мыши после анимации. |
