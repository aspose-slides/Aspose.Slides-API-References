## ITextAnimation класс

Представляет анимацию текста.

Тип ITextAnimation раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`build_type`](/slides/python-net/ru/aspose.slides.animation/itextanimation/build_type/) | Список типов построения (for exp. Paragraph 1,2,3, All at Once) анимации текста.<br/>            Чтение/запись [`ITextAnimation.build_type`](/slides/python-net/ru/aspose.slides.animation/itextanimation/build_type). |
| [`effect_animate_background_shape`](/slides/python-net/ru/aspose.slides.animation/itextanimation/effect_animate_background_shape/) | Связанный эффект формы с группой или без (None)<br/>            Чтение/запись [`IEffect`](/slides/python-net/ru/aspose.slides.animation/ieffect). |

## Методы

| Метод | Описание |
| :- | :- |
| [`add_effect(self, effect_type, subtype, trigger_type)`](/slides/python-net/ru/aspose.slides.animation/itextanimation/add_effect/#effecttype-effectsubtype-effecttriggertype) | Добавить новый эффект в конец текущей последовательности к концу групповых анимаций текста.<br/>            Действительно только если количество текстовых параграфов равно или больше количества эффектов этой группы! |
