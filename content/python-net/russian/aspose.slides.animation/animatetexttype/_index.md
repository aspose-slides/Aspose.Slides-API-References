## Перечисление AnimateTextType

Представляет тип анимированного текста эффекта анимации.

Тип AnimateTextType включает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| ALL_AT_ONCE | Анимировать весь текст сразу. |
| BY_WORD | Анимировать текст по словам. |
| BY_LETTER | Анимировать текст по буквам. |
