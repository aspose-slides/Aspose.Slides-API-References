## IMotionEffect класс

Представляет поведение эффекта перемещения.

Тип IMotionEffect предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`from_address`](/slides/python-net/ru/aspose.slides.animation/imotioneffect/from_address/) | Указывает координату x/y, с которой начинается анимация (в процентах). <br/> Чтение/запись [`PointF`](/slides/python-net/ru/aspose.slides/pointf). |
| [`to`](/slides/python-net/ru/aspose.slides.animation/imotioneffect/to/) | Указывает целевое положение для эффекта перемещения анимации (в процентах).<br/> Чтение/запись [`PointF`](/slides/python-net/ru/aspose.slides/pointf). |
| [`by`](/slides/python-net/ru/aspose.slides.animation/imotioneffect/by/) | Описывает относительное значение смещения для анимации (в процентах).<br/> Чтение/запись [`PointF`](/slides/python-net/ru/aspose.slides/pointf). |
| [`rotation_center`](/slides/python-net/ru/aspose.slides.animation/imotioneffect/rotation_center/) | Описывает центр вращения, используемый для вращения траектории перемещения на угол X.<br/> Чтение/запись [`PointF`](/slides/python-net/ru/aspose.slides/pointf). |
| [`origin`](/slides/python-net/ru/aspose.slides.animation/imotioneffect/origin/) | Указывает, относительно чего находится начало траектории перемещения, например относительно макета слайда,<br/> или родителя.<br/> Чтение/запись [`MotionOriginType`](/slides/python-net/ru/aspose.slides.animation/motionorigintype). |
| [`path`](/slides/python-net/ru/aspose.slides.animation/imotioneffect/path/) | Указывает примитив пути, за которым следуют координаты для перемещения анимации.<br/> Чтение/запись [`IMotionPath`](/slides/python-net/ru/aspose.slides.animation/imotionpath). |
| [`path_edit_mode`](/slides/python-net/ru/aspose.slides.animation/imotioneffect/path_edit_mode/) | Указывает, как перемещается траектория перемещения, когда перемещается форма.<br/> Чтение/запись [`MotionPathEditMode`](/slides/python-net/ru/aspose.slides.animation/motionpatheditmode). |
| [`angle`](/slides/python-net/ru/aspose.slides.animation/imotioneffect/angle/) | Описывает относительный угол траектории перемещения.<br/> Чтение/запись **float**. |
