## IMotionEffect класс

Представляет поведение эффекта движения.

Тип IMotionEffect объявляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`from_address`](/slides/python-net/ru/aspose.slides.animation/imotioneffect/from_address/) | Указывает координату x/y, с которой начинается анимация (в процентах). <br/>            Чтение/запись **aspose.slides.PointF**. |
| [`to`](/slides/python-net/ru/aspose.slides.animation/imotioneffect/to/) | Указывает целевое расположение для эффекта анимации движения (в процентах).<br/>            Чтение/запись **aspose.slides.PointF**. |
| [`by`](/slides/python-net/ru/aspose.slides.animation/imotioneffect/by/) | Описывает относительное значение смещения для анимации (в процентах).<br/>            Чтение/запись **aspose.slides.PointF**. |
| [`rotation_center`](/slides/python-net/ru/aspose.slides.animation/imotioneffect/rotation_center/) | Описывает центр вращения, используемый для вращения пути движения на угол X.<br/>            Чтение/запись **aspose.slides.PointF**. |
| [`origin`](/slides/python-net/ru/aspose.slides.animation/imotioneffect/origin/) | Указывает, к чему относится начало пути движения, например к разметке слайда,<br/>            или к родительскому элементу.<br/>            Чтение/запись [`MotionOriginType`](/slides/python-net/ru/aspose.slides.animation/motionorigintype). |
| [`path`](/slides/python-net/ru/aspose.slides.animation/imotioneffect/path/) | Указывает примитив пути, за которым следуют координаты для движения анимации.<br/>            Чтение/запись [`IMotionPath`](/slides/python-net/ru/aspose.slides.animation/imotionpath). |
| [`path_edit_mode`](/slides/python-net/ru/aspose.slides.animation/imotioneffect/path_edit_mode/) | Указывает, как перемещается путь движения при перемещении формы.<br/>            Чтение/запись [`MotionPathEditMode`](/slides/python-net/ru/aspose.slides.animation/motionpatheditmode). |
| [`angle`](/slides/python-net/ru/aspose.slides.animation/imotioneffect/angle/) | Описывает относительный угол пути движения.<br/>            Чтение/запись **float**. |
