## IMotionEffect класс

Представляет поведение эффекта движения.

Тип IMotionEffect открывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`from_`](/slides/python-net/ru/aspose.slides.animation/imotioneffect/from_/) | Указывает координату x/y, с которой начинается анимация (в процентах). <br/>            Чтение/запись [`PointF`](/slides/python-net/ru/aspose.slides/pointf). |
| [`to`](/slides/python-net/ru/aspose.slides.animation/imotioneffect/to/) | Указывает целевое расположение для анимационного эффекта движения (в процентах).<br/>            Чтение/запись [`PointF`](/slides/python-net/ru/aspose.slides/pointf). |
| [`by`](/slides/python-net/ru/aspose.slides.animation/imotioneffect/by/) | Описывает относительное значение смещения для анимации (в процентах).<br/>            Чтение/запись [`PointF`](/slides/python-net/ru/aspose.slides/pointf). |
| [`rotation_center`](/slides/python-net/ru/aspose.slides.animation/imotioneffect/rotation_center/) | Описывает центр вращения, используемый для вращения траектории движения на угол X.<br/>            Чтение/запись [`PointF`](/slides/python-net/ru/aspose.slides/pointf). |
| [`origin`](/slides/python-net/ru/aspose.slides.animation/imotioneffect/origin/) | Указывает, от чего относительно определяется начало траектории движения, например от макета слайда,<br/>            или от родительского объекта.<br/>            Чтение/запись [`MotionOriginType`](/slides/python-net/ru/aspose.slides.animation/motionorigintype). |
| [`path`](/slides/python-net/ru/aspose.slides.animation/imotioneffect/path/) | Указывает примитив пути, за которым следуют координаты для анимационного движения.<br/>            Чтение/запись [`IMotionPath`](/slides/python-net/ru/aspose.slides.animation/imotionpath). |
| [`path_edit_mode`](/slides/python-net/ru/aspose.slides.animation/imotioneffect/path_edit_mode/) | Указывает, как траектория движения перемещается при перемещении фигуры.<br/>            Чтение/запись [`MotionPathEditMode`](/slides/python-net/ru/aspose.slides.animation/motionpatheditmode). |
| [`angle`](/slides/python-net/ru/aspose.slides.animation/imotioneffect/angle/) | Описывает относительный угол траектории движения.<br/>            Чтение/запись **float**. |
