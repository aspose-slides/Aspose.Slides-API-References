## Effect класс

Представляет анимационный эффект.

Тип Effect раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`sequence`](/slides/python-net/ru/aspose.slides.animation/effect/sequence/) | Returns a sequence for an effect.<br/>            Только для чтения [`ISequence`](/slides/python-net/ru/aspose.slides.animation/isequence). |
| [`text_animation`](/slides/python-net/ru/aspose.slides.animation/effect/text_animation/) | TextAnimation<br/>            Только для чтения [`ITextAnimation`](/slides/python-net/ru/aspose.slides.animation/itextanimation). |
| [`preset_class_type`](/slides/python-net/ru/aspose.slides.animation/effect/preset_class_type/) | Определяет класс эффекта.<br/>            Чтение/запись [`EffectPresetClassType`](/slides/python-net/ru/aspose.slides.animation/effectpresetclasstype). |
| [`type`](/slides/python-net/ru/aspose.slides.animation/effect/type/) | Определяет тип эффекта.<br/>            Чтение/запись [`EffectType`](/slides/python-net/ru/aspose.slides.animation/effecttype). |
| [`subtype`](/slides/python-net/ru/aspose.slides.animation/effect/subtype/) | Определяет подтип эффекта.<br/>            Чтение/запись [`EffectSubtype`](/slides/python-net/ru/aspose.slides.animation/effectsubtype). |
| [`behaviors`](/slides/python-net/ru/aspose.slides.animation/effect/behaviors/) | Возвращает коллекцию поведения для эффекта.<br/>            Чтение/запись [`IBehaviorCollection`](/slides/python-net/ru/aspose.slides.animation/ibehaviorcollection). |
| [`timing`](/slides/python-net/ru/aspose.slides.animation/effect/timing/) | Определяет значение времени для эффекта.<br/>            Чтение/запись [`ITiming`](/slides/python-net/ru/aspose.slides.animation/itiming). |
| [`target_shape`](/slides/python-net/ru/aspose.slides.animation/effect/target_shape/) | Возвращает целевую форму для эффекта.<br/>            Только для чтения [`IShape`](/slides/python-net/ru/aspose.slides/ishape). |
| [`sound`](/slides/python-net/ru/aspose.slides.animation/effect/sound/) | Определённый встроенный звук для эффекта.<br/>            Чтение/запись [`IAudio`](/slides/python-net/ru/aspose.slides/iaudio). |
| [`stop_previous_sound`](/slides/python-net/ru/aspose.slides.animation/effect/stop_previous_sound/) | Этот атрибут указывает, останавливает ли анимационный эффект предыдущее звучание.<br/>            Чтение/запись **bool**. |
| [`after_animation_type`](/slides/python-net/ru/aspose.slides.animation/effect/after_animation_type/) | Определяет тип пост-анимации для эффекта.<br/>            Чтение/запись [`Effect.after_animation_type`](/slides/python-net/ru/aspose.slides.animation/effect/after_animation_type). |
| [`after_animation_color`](/slides/python-net/ru/aspose.slides.animation/effect/after_animation_color/) | Определяет цвет пост-анимации для эффекта.<br/>            Чтение/запись [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`animate_text_type`](/slides/python-net/ru/aspose.slides.animation/effect/animate_text_type/) | Определяет тип анимации текста для эффекта.<br/>            Текст формы может анимироваться по буквам, по словам или сразу целиком.<br/>            Чтение/запись [`Effect.animate_text_type`](/slides/python-net/ru/aspose.slides.animation/effect/animate_text_type). |
| [`delay_between_text_parts`](/slides/python-net/ru/aspose.slides.animation/effect/delay_between_text_parts/) | Определяет задержку между частями анимированного текста (словами или буквами).<br/>            Положительное значение указывает процент от длительности эффекта.<br/>            Отрицательное значение указывает задержку в секундах.<br/>            Чтение/запись **float**. |
