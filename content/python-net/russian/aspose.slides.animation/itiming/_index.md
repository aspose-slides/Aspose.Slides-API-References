## ITiming класс

Представляет тайминг анимации.

Тип ITiming раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`accelerate`](/slides/python-net/ru/aspose.slides.animation/itiming/accelerate/) | Определяет процент длительности ускоряющего поведения эффекта.<br/>            Чтение/запись **float**. |
| [`decelerate`](/slides/python-net/ru/aspose.slides.animation/itiming/decelerate/) | Определяет процент длительности замедляющего поведения эффекта.<br/>            Чтение/запись **float**. |
| [`auto_reverse`](/slides/python-net/ru/aspose.slides.animation/itiming/auto_reverse/) | Определяет, следует ли автоматически воспроизводить анимацию в обратном направлении после<br/>            воспроизведения её в прямом направлении.<br/>            Чтение/запись **bool**. |
| [`duration`](/slides/python-net/ru/aspose.slides.animation/itiming/duration/) | Определяет длительность анимационного эффекта.<br/>            Чтение/запись **float**. |
| [`repeat_count`](/slides/python-net/ru/aspose.slides.animation/itiming/repeat_count/) | Определяет количество повторов эффекта.<br/>            Чтение/запись **float**. |
| [`repeat_until_end_slide`](/slides/python-net/ru/aspose.slides.animation/itiming/repeat_until_end_slide/) | Этот атрибут указывает, будет ли эффект повторяться до конца слайда.<br/>            Чтение/запись **bool**. |
| [`repeat_until_next_click`](/slides/python-net/ru/aspose.slides.animation/itiming/repeat_until_next_click/) | Этот атрибут указывает, будет ли эффект повторяться до следующего щелчка.<br/>            Чтение/запись **bool**. |
| [`repeat_duration`](/slides/python-net/ru/aspose.slides.animation/itiming/repeat_duration/) | Определяет количество повторов эффекта.<br/>            Чтение/запись **float**. |
| [`restart`](/slides/python-net/ru/aspose.slides.animation/itiming/restart/) | Указывает, следует ли перезапускать эффект после завершения.<br/>            Чтение/запись [`EffectRestartType`](/slides/python-net/ru/aspose.slides.animation/effectrestarttype). |
| [`speed`](/slides/python-net/ru/aspose.slides.animation/itiming/speed/) | Указывает процент ускорения (или замедления) тайминга.<br/>            Чтение/запись **float**. |
| [`trigger_delay_time`](/slides/python-net/ru/aspose.slides.animation/itiming/trigger_delay_time/) | Определяет задержку после срабатывания триггера.<br/>            Чтение/запись **float**. |
| [`trigger_type`](/slides/python-net/ru/aspose.slides.animation/itiming/trigger_type/) | Определяет тип триггера.<br/>            Чтение/запись [`EffectTriggerType`](/slides/python-net/ru/aspose.slides.animation/effecttriggertype). |
| [`rewind`](/slides/python-net/ru/aspose.slides.animation/itiming/rewind/) | Этот атрибут указывает, будет ли эффект перемотываться назад после завершения воспроизведения.<br/>            Чтение/запись **bool**. |
