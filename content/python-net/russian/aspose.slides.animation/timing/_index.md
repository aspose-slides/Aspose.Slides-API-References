## Timing класс

Представляет тайминг анимации.

Тип Timing предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`accelerate`](/slides/python-net/ru/aspose.slides.animation/timing/accelerate/) | Описывает процент длительности эффекта ускорения поведения.<br/>            Read/write **float**. |
| [`decelerate`](/slides/python-net/ru/aspose.slides.animation/timing/decelerate/) | Описывает процент длительности эффекта замедления поведения.<br/>            Read/write **float**. |
| [`auto_reverse`](/slides/python-net/ru/aspose.slides.animation/timing/auto_reverse/) | Описывает, следует ли автоматически воспроизводить анимацию в обратном направлении после<br/>            воспроизведения её в прямом направлении.<br/>            Read/write **bool**. |
| [`duration`](/slides/python-net/ru/aspose.slides.animation/timing/duration/) | Описывает длительность эффекта анимации.<br/>            Read/write **float**. |
| [`repeat_count`](/slides/python-net/ru/aspose.slides.animation/timing/repeat_count/) | Описывает количество повторений эффекта.<br/>            Read/write **float**. |
| [`repeat_until_end_slide`](/slides/python-net/ru/aspose.slides.animation/timing/repeat_until_end_slide/) | Этот атрибут указывает, будет ли эффект повторяться до конца слайда.<br/>            Read/write **bool**. |
| [`repeat_until_next_click`](/slides/python-net/ru/aspose.slides.animation/timing/repeat_until_next_click/) | Этот атрибут указывает, будет ли эффект повторяться до следующего щелчка.<br/>            Read/write **bool**. |
| [`repeat_duration`](/slides/python-net/ru/aspose.slides.animation/timing/repeat_duration/) | Описывает количество повторений эффекта.<br/>            Read/write **float**. |
| [`restart`](/slides/python-net/ru/aspose.slides.animation/timing/restart/) | Указывает, следует ли перезапустить эффект после завершения.<br/>            Read/write [`EffectRestartType`](/slides/python-net/ru/aspose.slides.animation/effectrestarttype). |
| [`rewind`](/slides/python-net/ru/aspose.slides.animation/timing/rewind/) | Этот атрибут указывает, будет ли эффект перематываться после завершения воспроизведения.<br/>            Read/write **bool**. |
| [`speed`](/slides/python-net/ru/aspose.slides.animation/timing/speed/) | Указывает процент, на который следует ускорить (или замедлить) тайминг.<br/>            Read/write **float**. |
| [`trigger_delay_time`](/slides/python-net/ru/aspose.slides.animation/timing/trigger_delay_time/) | Описывает время задержки после срабатывания.<br/>            Read/write **float**. |
| [`trigger_type`](/slides/python-net/ru/aspose.slides.animation/timing/trigger_type/) | Описывает тип триггера.<br/>            Read/write [`EffectTriggerType`](/slides/python-net/ru/aspose.slides.animation/effecttriggertype). |
