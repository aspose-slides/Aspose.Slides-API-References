## BuildType enumeration

Определяет, как текст будет отображаться на фигуре во время анимации.

Тип BuildType предоставляет следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| AS_ONE_OBJECT | С содержащей фигурой. |
| ALL_PARAGRAPHS_AT_ONCE | Все абзацы. |
| BY_LEVEL_PARAGRAPHS1 | По группам абзацев глубины 1. |
| BY_LEVEL_PARAGRAPHS2 | По группам абзацев глубины 2. |
| BY_LEVEL_PARAGRAPHS3 | По группам абзацев глубины 3. |
| BY_LEVEL_PARAGRAPHS4 | По группам абзацев глубины 4. |
| BY_LEVEL_PARAGRAPHS5 | По группам абзацев глубины 5. |
