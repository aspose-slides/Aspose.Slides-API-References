## IBehaviorCollection класс

Представляет коллекцию эффектов поведения.

Тип IBehaviorCollection раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`count`](/slides/python-net/ru/aspose.slides.animation/ibehaviorcollection/count/) | Возвращает количество поведений в коллекции.<br/>            Только для чтения **int**. |

Возвращает поведение по указанному индексу.

## Индексатор

| Имя | Описание |
| :- | :- |
| [`[index]`](/slides/python-net/ru/aspose.slides.animation/ibehaviorcollection/__getitem__/) | Индекс поведения, которое нужно вернуть. |

| Метод | Описание |
| :- | :- |
| [`add(self, item)`](/slides/python-net/ru/aspose.slides.animation/ibehaviorcollection/add/#ibehavior) | Добавляет новое поведение в коллекцию. |
| [`index_of(self, item)`](/slides/python-net/ru/aspose.slides.animation/ibehaviorcollection/index_of/#ibehavior) | Определяет индекс конкретного элемента в **System.Collections.Generic.IList`1**. |
| [`insert(self, index, item)`](/slides/python-net/ru/aspose.slides.animation/ibehaviorcollection/insert/#int-ibehavior) | Вставляет новое поведение в коллекцию по указанному индексу. |
| [`remove(self, item)`](/slides/python-net/ru/aspose.slides.animation/ibehaviorcollection/remove/#ibehavior) | Удаляет указанное поведение из коллекции. |
