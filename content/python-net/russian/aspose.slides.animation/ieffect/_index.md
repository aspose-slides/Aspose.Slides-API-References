## IEffect класс

Представляет анимационный эффект.

Тип IEffect предоставляет следующие члены:

## Свойства

| Property | Description |
| :- | :- |
| [`sequence`](/slides/python-net/ru/aspose.slides.animation/ieffect/sequence/) | Возвращает последовательность для эффекта.<br/> Только для чтения [`ISequence`](/slides/python-net/ru/aspose.slides.animation/isequence). |
| [`text_animation`](/slides/python-net/ru/aspose.slides.animation/ieffect/text_animation/) | Возвращает анимацию текста.<br/> Только для чтения [`ITextAnimation`](/slides/python-net/ru/aspose.slides.animation/itextanimation). |
| [`preset_class_type`](/slides/python-net/ru/aspose.slides.animation/ieffect/preset_class_type/) | Определяет класс эффекта.<br/> Чтение/запись [`EffectPresetClassType`](/slides/python-net/ru/aspose.slides.animation/effectpresetclasstype). |
| [`type`](/slides/python-net/ru/aspose.slides.animation/ieffect/type/) | Определяет тип эффекта.<br/> Чтение/запись [`EffectType`](/slides/python-net/ru/aspose.slides.animation/effecttype). |
| [`subtype`](/slides/python-net/ru/aspose.slides.animation/ieffect/subtype/) | Определяет подтип эффекта.<br/> Чтение/запись [`EffectSubtype`](/slides/python-net/ru/aspose.slides.animation/effectsubtype). |
| [`behaviors`](/slides/python-net/ru/aspose.slides.animation/ieffect/behaviors/) | Возвращает коллекцию поведения для эффекта.<br/> Чтение/запись [`IBehaviorCollection`](/slides/python-net/ru/aspose.slides.animation/ibehaviorcollection). |
| [`timing`](/slides/python-net/ru/aspose.slides.animation/ieffect/timing/) | Определяет значение времени для эффекта.<br/> Чтение/запись [`ITiming`](/slides/python-net/ru/aspose.slides.animation/itiming). |
| [`target_shape`](/slides/python-net/ru/aspose.slides.animation/ieffect/target_shape/) | Возвращает целевую форму для эффекта.<br/> Только для чтения [`IShape`](/slides/python-net/ru/aspose.slides/ishape). |
| [`sound`](/slides/python-net/ru/aspose.slides.animation/ieffect/sound/) | Определён встроенный звук для эффекта.<br/> Чтение/запись [`IAudio`](/slides/python-net/ru/aspose.slides/iaudio). |
| [`stop_previous_sound`](/slides/python-net/ru/aspose.slides.animation/ieffect/stop_previous_sound/) | Этот атрибут указывает, останавливает ли анимационный эффект предыдущий звук.<br/> Чтение/запись **bool**. |
| [`after_animation_type`](/slides/python-net/ru/aspose.slides.animation/ieffect/after_animation_type/) | Определён тип анимации после эффекта.<br/> Чтение/запись [`IEffect.after_animation_type`](/slides/python-net/ru/aspose.slides.animation/ieffect/after_animation_type). |
| [`after_animation_color`](/slides/python-net/ru/aspose.slides.animation/ieffect/after_animation_color/) | Определён цвет анимации после эффекта.<br/> Чтение/запись [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`animate_text_type`](/slides/python-net/ru/aspose.slides.animation/ieffect/animate_text_type/) | Определяет тип анимации текста для эффекта.<br/> Текст формы может быть анимирован буквой, словом или сразу полностью.<br/> Чтение/запись [`IEffect.animate_text_type`](/slides/python-net/ru/aspose.slides.animation/ieffect/animate_text_type). |
| [`delay_between_text_parts`](/slides/python-net/ru/aspose.slides.animation/ieffect/delay_between_text_parts/) | Определяет задержку между частями анимированного текста (словами или буквами).<br/> Положительное значение указывает процент длительности эффекта.<br/> Отрицательное значение указывает задержку в секундах.<br/> Чтение/запись **float**. |
