## EffectPresetClassType перечисление

Представляет типы классов эффектов.

Тип EffectPresetClassType открывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| ENTRANCE | Класс эффектов входа.<br/><br/><br/>Типы целевых фигур: Все |
| EXIT | Класс эффектов выхода.<br/><br/><br/>Типы целевых фигур: Все |
| EMPHASIS | Класс эффектов акцентирования.<br/><br/><br/>Типы целевых фигур: Все |
| PATH | Класс путей движения.<br/><br/><br/>Типы целевых фигур: Все |
| MEDIA_CALL | Класс медиаэффектов.<br/><br/><br/>Типы целевых фигур: [`IVideoFrame`](/slides/python-net/ru/aspose.slides/ivideoframe), [`IAudioFrame`](/slides/python-net/ru/aspose.slides/iaudioframe) |
| OLE_ACTION_VERBS | Класс OLE Action Verbs.<br/><br/><br/>Типы целевых фигур: [`IOleObjectFrame`](/slides/python-net/ru/aspose.slides/ioleobjectframe) |
