## BehaviorCollection класс

Представляет коллекцию эффектов поведения.

Тип BehaviorCollection раскрывает следующие члены:

## Свойства

| С свойство | Описание |
| :- | :- |
| [`count`](/slides/python-net/ru/aspose.slides.animation/behaviorcollection/count/) | Возвращает количество поведений в коллекции.<br/>            Read-only **int**. |
| [`is_read_only`](/slides/python-net/ru/aspose.slides.animation/behaviorcollection/is_read_only/) | Получает значение, указывающее, является ли **System.Collections.Generic.ICollection`1** только для чтения.<br/>            Read-only **bool**. |

Возвращает поведение по указанному индексу.

## Индексатор

| Имя | Описание |
| :- | :- |
| [`[index]`](/slides/python-net/ru/aspose.slides.animation/behaviorcollection/__getitem__/) | Индекс поведения для возврата. |

| Метод | Описание |

| [`insert(self, index, item)`](/slides/python-net/ru/aspose.slides.animation/behaviorcollection/insert/#int-ibehavior) | Вставляет новое поведение в коллекцию по указанному индексу. |
