## EffectChartMinorGroupingType перечисление

Представляет тип анимационного эффекта для элемента диаграммы в серии или категории.

Тип EffectChartMinorGroupingType предоставляет следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| BY_ELEMENT_IN_SERIES | Анимировать диаграмму по элементу в серии |
| BY_ELEMENT_IN_CATEGORY | Анимировать диаграмму по элементу в категории |
