## IPoint класс

Представляет точку анимации.

Тип IPoint раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`time`](/slides/python-net/ru/aspose.slides.animation/ipoint/time/) | Представляет значение времени.<br/>            Чтение/запись **float**. |
| [`value`](/slides/python-net/ru/aspose.slides.animation/ipoint/value/) | Представляет значение точки.<br/>            Только: bool, ColorFormat, float, int, string.<br/>            Чтение/запись **any**. |
| [`formula`](/slides/python-net/ru/aspose.slides.animation/ipoint/formula/) | Формулы в значениях, атрибутах from, to, by могут быть составлены из следующих элементов:<br/>            Стандартные арифметические операторы: ‘+’, ‘-‘, ‘*’, ‘/’, ‘^’, ‘%’ (mod)<br/>            Константы: ‘pi’ ‘e’<br/>            Условные операторы: ‘abs’, ‘min’, ‘max’, ‘?’ (if)<br/>            Операторы сравнения: '==', '>=', '', '!=', '!'<br/>            Тригонометрические операторы: ‘sin()’, ‘cos()’, ‘tan()’, ‘asin()’, ‘acos()’, ‘atan()’<br/>            Натуральный логарифм ‘ln()’<br/>            Ссылки на свойства (поддерживаемые хостом свойства)<br/>            <br/>            например: "#ppt_x+(cos(-2*pi*(1-$))*-#ppt_x-sin(-2*pi*(1-$))*(1-#ppt_y))*(1-$)"<br/>            Чтение/запись **str**. |
