## TiffCompressionTypes перечисление

Предоставляет параметры, которые управляют тем, как презентация сжимается в формате TIFF.

Тип TiffCompressionTypes раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| DEFAULT | Указывает схему сжатия по умолчанию (LZW). |
| NONE | Указывает отсутствие сжатия. |
| CCITT3 | Указывает схему сжатия CCITT3. |
| CCITT4 | Указывает схему сжатия CCITT4. |
| LZW | Указывает схему сжатия LZW (по умолчанию). |
| RLE | Указывает схему сжатия RLE. |
