## SvgCoordinateUnit перечисление

Представляет единицы координат CSS2, используемые для определения координат SVG.

Тип SvgCoordinateUnit предоставляет следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| INCH | Дюйм |
| CENTIMETER | Сантиметр. |
| MILLIMETER | Миллиметр. |
| POINT | Точка (1/72 дюйма), |
| PICA | Пика (1/6 дюйма). |
| EM | Размер EM шрифта содержащего элемента. |
| EX | Размер EX (размер строчной буквы, обычно "x") шрифта содержащего элемента. |
| PIXEL | Размер пикселя. |
| PERCENT | Процент. |
