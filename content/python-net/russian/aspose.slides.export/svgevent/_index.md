## Перечисление SvgEvent

Представляет варианты для SVG-формы.

Тип SvgEvent раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| ON_FOCUS_IN | Происходит, когда элемент получает фокус, например, когда текст становится выбранным. |
| ON_FOCUS_OUT | Происходит, когда элемент теряет фокус, например, когда текст становится невыбранным. |
| ON_ACTIVATE | Происходит, когда элемент активируется, например, щелчком мыши или нажатием клавиши. |
| ON_CLICK | Происходит, когда кнопка указательного устройства нажата над элементом. |
| ON_MOUSE_DOWN | Происходит, когда кнопка указательного устройства нажата над элементом. |
| ON_MOUSE_UP | Происходит, когда кнопка указательного устройства отпущена над элементом. |
| ON_MOUSE_OVER | Происходит, когда указательное устройство перемещается на элемент. |
| ON_MOUSE_MOVE | Происходит, когда указательное устройство перемещается, пока находится над элементом. |
| ON_MOUSE_OUT | Происходит, когда указательное устройство уходит от элемента. |
| ON_LOAD | Происходит, когда пользовательский агент полностью разобрал элемент, его потомков и все ссылки на ресурсы, необходимые для его отрисовки. |
| ON_UNLOAD | Происходит, когда реализация DOM удаляет документ из окна или фрейма. Применимо только к внешним элементам svg. |
| ON_ABORT | Происходит, когда загрузка страницы останавливается до полной загрузки элемента. |
| ON_ERROR | Происходит, когда элемент не загружается корректно или возникает ошибка во время выполнения скрипта. |
| ON_RESIZE | Происходит, когда представление документа изменяется в размере. Применимо только к внешним элементам svg. |
| ON_SCROLL | Происходит, когда представление документа смещается вдоль оси X, Y или обеих осей. Применимо только к внешним элементам svg. |
| ON_ZOOM | Происходит, когда уровень масштабирования представления документа меняется. Применимо только к внешним элементам svg. |
| ON_BEGIN | Происходит, когда начинается анимационный элемент. |
| ON_END | Происходит, когда анимационный элемент заканчивается. |
| ON_REPEAT | Происходит, когда анимационный элемент повторяется. |
