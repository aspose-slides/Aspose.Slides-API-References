## ISwfOptions класс

Предоставляет параметры, управляющие тем, как презентация сохраняется в формате SWF.

Тип ISwfOptions раскрывает следующие члены:

## Свойства

| Property | Description |
| :- | :- |
| [`compressed`](/slides/python-net/ru/aspose.slides.export/iswfoptions/compressed/) | Указывает, следует ли сжимать сгенерированный SWF-документ или нет.<br/>            По умолчанию `true`. |
| [`viewer_included`](/slides/python-net/ru/aspose.slides.export/iswfoptions/viewer_included/) | Указывает, следует ли включать в сгенерированный SWF-документ встроенный просмотрщик документов или нет.<br/>            По умолчанию `true`. |
| [`show_page_border`](/slides/python-net/ru/aspose.slides.export/iswfoptions/show_page_border/) | Указывает, должна ли отображаться граница вокруг страниц. По умолчанию true. |
| [`show_hidden_slides`](/slides/python-net/ru/aspose.slides.export/iswfoptions/show_hidden_slides/) | Указывает, следует ли включать в сгенерированный документ скрытые слайды или нет.<br/>            По умолчанию `false`. |
| [`show_full_screen`](/slides/python-net/ru/aspose.slides.export/iswfoptions/show_full_screen/) | Показать/скрыть кнопку полноэкранного режима. Может быть переопределено во flashvars. По умолчанию true. |
| [`show_page_stepper`](/slides/python-net/ru/aspose.slides.export/iswfoptions/show_page_stepper/) | Показать/скрыть переключатель страниц. Может быть переопределено во flashvars. По умолчанию true. |
| [`show_search`](/slides/python-net/ru/aspose.slides.export/iswfoptions/show_search/) | Показать/скрыть раздел поиска. Может быть переопределено во flashvars. По умолчанию true. |
| [`show_top_pane`](/slides/python-net/ru/aspose.slides.export/iswfoptions/show_top_pane/) | Показать/скрыть всю верхнюю панель. Может быть переопределено во flashvars. По умолчанию true. |
| [`show_bottom_pane`](/slides/python-net/ru/aspose.slides.export/iswfoptions/show_bottom_pane/) | Показать/скрыть нижнюю панель. Может быть переопределено во flashvars. По умолчанию true. |
| [`show_left_pane`](/slides/python-net/ru/aspose.slides.export/iswfoptions/show_left_pane/) | Показать/скрыть левую панель. Может быть переопределено во flashvars. По умолчанию true. |
| [`start_open_left_pane`](/slides/python-net/ru/aspose.slides.export/iswfoptions/start_open_left_pane/) | Начинать с открытой левой панелью. Может быть переопределено во flashvars. По умолчанию false. |
| [`enable_context_menu`](/slides/python-net/ru/aspose.slides.export/iswfoptions/enable_context_menu/) | Включить/отключить контекстное меню. По умолчанию true. |
| [`logo_image_bytes`](/slides/python-net/ru/aspose.slides.export/iswfoptions/logo_image_bytes/) | Изображение, которое будет отображаться в виде логотипа в правом верхнем углу просмотрщика.             <br/>            Изображение должно быть PNG размером 32×64 пикселя, иначе логотип может отображаться некорректно. |
| [`logo_link`](/slides/python-net/ru/aspose.slides.export/iswfoptions/logo_link/) | Получает или задает полный гиперссылочный адрес для логотипа.<br/>            Имеет эффект только если указано [`ISwfOptions.logo_image_bytes`](/slides/python-net/ru/aspose.slides.export/iswfoptions/logo_image_bytes). |
| [`jpeg_quality`](/slides/python-net/ru/aspose.slides.export/iswfoptions/jpeg_quality/) | Указывает качество JPEG-изображений.             <br/>            По умолчанию 95. |
| [`slides_layout_options`](/slides/python-net/ru/aspose.slides.export/iswfoptions/slides_layout_options/) | Получает или задает режим размещения слайдов на странице при экспорте презентации [`ISlidesLayoutOptions`](/slides/python-net/ru/aspose.slides.export/islideslayoutoptions).<br/>            Это свойство не поддерживает присваивание объектов типа `Aspose.Slides.Export.HandoutLayoutingOptions` |
| [`warning_callback`](/slides/python-net/ru/aspose.slides.export/iswfoptions/warning_callback/) |  |

| [`default_regular_font`](/slides/python-net/ru/aspose.slides.export/iswfoptions/default_regular_font/) |  |
