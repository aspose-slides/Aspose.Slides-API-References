## disable_font_ligatures свойство
Получает или задаёт значение, указывающее, отображается ли текст без использования лигатур.
            Когда установлено значение `true`, лигатуры будут отключены в выводе. По умолчанию это свойство имеет значение `false`.

    ...

    ...
