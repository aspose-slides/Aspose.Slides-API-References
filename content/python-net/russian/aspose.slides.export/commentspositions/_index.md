## Перечисление CommentsPositions

Представляет правило отображения комментариев в экспортируемом документе

Тип CommentsPositions раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| NONE | Указывает, что комментарии не должны отображаться вообще. |
| BOTTOM | Указывает, что комментарии должны отображаться внизу страницы. |
| RIGHT | Указывает, что комментарии должны отображаться справа от страницы. |
