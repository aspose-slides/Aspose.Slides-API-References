## TextInheritanceLimit перечисление

Контролирует глубину наследования свойств текста.

Тип TextInheritanceLimit предоставляет следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| ALL | Наследовать все свойства текста. |
| TEXT_BOX | Наследовать только стиль TextFrame. |
| PARAGRAPH_ONLY | Использовать только свойства, определённые для абзаца. |
