## EmbedFontCharacters перечисление

Представляет правило, используемое для добавления нового шрифта вложения в [`IPresentation`](/slides/python-net/ru/aspose.slides/ipresentation)

Тип EmbedFontCharacters раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| ONLY_USED | Встроить только символы, используемые в презентации (лучше для уменьшения размера файла). |
| ALL | Встроить все символы (лучше для редактирования другими людьми). |
