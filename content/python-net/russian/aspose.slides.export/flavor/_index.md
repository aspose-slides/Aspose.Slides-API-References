## Перечисление Flavor

Все спецификации markdown, используемые в программе.

Тип Flavor раскрывает следующие члены:

| Поле | Описание |

| GITHUB | Вариант Github. |
| GRUBER | Вариант Gruber. |

| KRAMDOWN | Вариант Kramdown. |

| MARUKU | Вариант Maruku. |

| REMARKABLE | Вариант Remarkable |
| SHOWDOWN | Вариант Showdown. |
| GHOST | Вариант Ghost. |
| GIT_LAB | Вариант Gitlab. |
| HAROOPAD | Вариант Haroopad. |
| IA_WRITER | Вариант IAWriter. |
| REDCARPET | Вариант Redcarpet. |
| SCHOLARLY_MARKDOWN | Вариант Scholarly markdown. |
| TAIGA | Вариант Taiga. |
