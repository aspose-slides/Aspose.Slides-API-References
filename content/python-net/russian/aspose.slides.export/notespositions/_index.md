## Перечисление NotesPositions

Представляет правило отрисовки нот в экспортируемом документе

Тип NotesPositions раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| NONE | Указывает, что нотки не должны отображаться вообще. |
| BOTTOM_FULL | Указывает, что нотки должны полностью отображаться, используя дополнительные страницы по мере необходимости. |
| BOTTOM_TRUNCATED | Указывает, что нотки должны отображаться только на одной странице. |
