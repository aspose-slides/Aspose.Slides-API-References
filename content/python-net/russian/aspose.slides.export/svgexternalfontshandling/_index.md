## SvgExternalFontsHandling перечисление

Представляет способ обработки внешних шрифтов, используемых для отрисовки текста.

Тип SvgExternalFontsHandling предоставляет следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| ADD_LINKS_TO_FONT_FILES | Добавить ссылки на отдельные файлы шрифтов в раздел style SVG-файла. |
| EMBED | Сохранить данные шрифтов непосредственно в SVG-файл. Пожалуйста, проверьте лицензионные соглашения всех внешних шрифтов перед использованием этой опции. |
| VECTORIZE | Сохранить весь текст, использующий внешние шрифты, как графику. |
