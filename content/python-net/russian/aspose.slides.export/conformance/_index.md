## Перечисление соответствия

Указывает класс соответствия, которому соответствует документ PresentationML.

Тип Conformance раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| ECMA_376_2006 | Указывает, что документ соответствует ECMA376:2006. |
| ISO_29500_2008_TRANSITIONAL | Указывает, что документ соответствует переходному классу соответствия ISO/IEC 29500:2008. |
| ISO_29500_2008_STRICT | Указывает, что документ соответствует строгому классу соответствия ISO/IEC 29500:2008. |
