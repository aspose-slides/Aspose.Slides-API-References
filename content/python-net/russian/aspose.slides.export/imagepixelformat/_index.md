## Перечисление ImagePixelFormat

Указывает формат пикселей для создаваемых изображений.

Тип ImagePixelFormat раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| FORMAT_1BPP_INDEXED | 1 бит на пиксель, индексированный. |
| FORMAT_4BPP_INDEXED | 4 бита на пиксель, индексированный. |
| FORMAT_8BPP_INDEXED | 8 бит на пиксель, индексированный. |
| FORMAT_24BPP_RGB | 24 бита на пиксель, RGB. |
| FORMAT_32BPP_ARGB | 32 бита на пиксель, ARGB. |
