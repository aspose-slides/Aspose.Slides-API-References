## image_size свойство
Указывает размер генерируемого TIFF изображения.
            Значение по умолчанию — 0x0, что означает, что размеры генерируемого изображения будут рассчитываться на основе значения размера слайда презентации.
            Чтение/запись **aspose.slides.Size**.
