## image_size свойство
Указывает размер генерируемого изображения TIFF.
            Значение по умолчанию — 0x0, что означает, что размеры генерируемого изображения будут вычисляться на основе значения размера слайда презентации.
            Чтение/запись [`Size`](/slides/python-net/ru/aspose.slides/size).
