## SaveFormat перечисление

Константы, определяющие формат сохраняемой презентации.

Тип SaveFormat предоставляет следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| PPT | Сохранить презентацию в формате PPT. |
| PDF | Сохранить презентацию в формате PDF. |
| XPS | Сохранить презентацию в формате XPS. |
| PPTX | Сохранить презентацию в формате PPTX. |
| PPSX | Сохранить презентацию в формате PPSX (слайдшоу). |
| TIFF | Сохранить презентацию в виде многостраничного изображения TIFF. |
| ODP | Сохранить презентацию в формате ODP. |
| PPTM | Сохранить презентацию в формате PPTM (презентация с поддержкой макросов). |
| PPSM | Сохранить презентацию в формате PPSM (слайдшоу с поддержкой макросов). |
| POTX | Сохранить презентацию в формате POTX (шаблон). |
| POTM | Сохранить презентацию в формате POTM (шаблон с поддержкой макросов). |
| HTML | Сохранить презентацию в формате HTML. |
| SWF | Сохранить презентацию в формате SWF. |
| OTP | Сохранить презентацию в формате OTP (шаблон презентации). |
| PPS | Сохранить презентацию в формате PPS. |
| POT | Сохранить презентацию в формате POT. |
| FODP | Сохранить презентацию в формате FODP. |
| GIF | Сохранить презентацию в формате GIF. |
| HTML5 | Сохранить презентацию в формате HTML с использованием новой системы шаблонов HTML5. |
| MD | Сохранить презентацию в формате Markdown. |
| XML | Сохранить презентацию в формате PowerPoint XML Presentation. |
