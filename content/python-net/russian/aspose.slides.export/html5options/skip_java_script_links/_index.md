## skip_java_script_links свойство
Указывает, следует ли пропускать гиперссылки с вызовами JavaScript при сохранении презентации. 
            Чтение/запись **bool**. Значение по умолчанию — **false** .


### Примечания

Когда это свойство установлено в **true**, гиперссылки с вызовами JavaScript будут игнорироваться при сохранении.

Когда это свойство установлено в **false**, все гиперссылки будут сохраняться.
