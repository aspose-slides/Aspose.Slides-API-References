## default_delay свойство
Получает или задает значение времени задержки по умолчанию [ms]. Это значение будет использовано, если [`ISlideShowTransition.advance_after_time`](/slides/python-net/ru/aspose.slides/islideshowtransition/advance_after_time) не установлен.
            Значение по умолчанию равно 1000.
