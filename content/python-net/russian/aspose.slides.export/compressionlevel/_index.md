## Перечисление CompressionLevel

Указывает уровни сжатия ZIP для файла OpenXML. Более высокие уровни обеспечивают лучшее сжатие за счёт более медленной обработки.

Тип CompressionLevel предоставляет следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| NONE | Сжатие не применяется. Файлы хранятся в исходном виде. |
| LEVEL1 | Самое быстрое сжатие с самым низким коэффициентом сжатия. |
| LEVEL2 | Более быстрое сжатие с немного лучшим коэффициентом сжатия, чем [`CompressionLevel.LEVEL1`](/slides/python-net/ru/aspose.slides.export/compressionlevel/LEVEL1). |
| LEVEL3 | Обеспечивает лучшее сжатие, чем [`CompressionLevel.LEVEL2`](/slides/python-net/ru/aspose.slides.export/compressionlevel/LEVEL2), с умеренным влиянием на производительность. |
| LEVEL4 | Обеспечивает лучшее сжатие, чем [`CompressionLevel.LEVEL3`](/slides/python-net/ru/aspose.slides.export/compressionlevel/LEVEL3). |
| LEVEL5 | Обеспечивает улучшенное сжатие по сравнению с [`CompressionLevel.LEVEL4`](/slides/python-net/ru/aspose.slides.export/compressionlevel/LEVEL4) с дополнительным временем обработки. |
| LEVEL6 | Стандартное сжатие, предлагающее хороший баланс между скоростью сжатия и размером файла.<br/>            Уровень сжатия по умолчанию. |
| LEVEL7 | Обеспечивает более высокое сжатие, чем [`CompressionLevel.LEVEL6`](/slides/python-net/ru/aspose.slides.export/compressionlevel/LEVEL6), с более медленной обработкой. |
| LEVEL8 | Обеспечивает более высокое сжатие, чем [`CompressionLevel.LEVEL7`](/slides/python-net/ru/aspose.slides.export/compressionlevel/LEVEL7). |
| LEVEL9 | Максимальное сжатие. Позволяет получить наименьший размер файла при самой медленной скорости обработки. |
