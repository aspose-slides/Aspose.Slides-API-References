## PdfCompliance перечисление

Константы, определяющие уровень соответствия стандартам PDF.

Тип PdfCompliance предоставляет следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| PDF15 | Выходной файл будет соответствовать стандарту PDF 1.5. |
| PDF16 | Выходной файл будет соответствовать стандарту PDF 1.6. |
| PDF17 | Выходной файл будет соответствовать стандарту PDF 1.7. |
| PDF_A1B | Выходной файл будет соответствовать стандарту PDF/A-1b. |
| PDF_A1A | Выходной файл будет соответствовать стандарту PDF/A-1a. |
| PDF_A2B | Выходной файл будет соответствовать стандарту PDF/A-2b. |
| PDF_A2A | Выходной файл будет соответствовать стандарту PDF/A-2a. |
| PDF_A3B | Выходной файл будет соответствовать стандарту PDF/A-3b. |
| PDF_A3A | Выходной файл будет соответствовать стандарту PDF/A-3a. |
| PDF_UA | Выходной файл будет соответствовать стандарту PDF/UA. |
| PDF_A2U | Выходной файл будет соответствовать стандарту PDF/A-2u. |
