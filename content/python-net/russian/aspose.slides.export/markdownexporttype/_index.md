## MarkdownExportType перечисление

Тип рендеринга документа.

Тип MarkdownExportType включает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| SEQUENTIAL | Рендерит все элементы отдельно. По одному. |
| TEXT_ONLY | Рендерит только текст. |
| VISUAL | Рендерит все элементы, элементы, которые сгруппированы — рендерятся вместе. |
