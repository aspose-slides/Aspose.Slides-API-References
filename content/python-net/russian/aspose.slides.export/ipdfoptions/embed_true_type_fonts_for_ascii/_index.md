## embed_true_type_fonts_for_ascii свойство
True, чтобы встраивать шрифты TrueType для символов ASCII 32-127.
            Шрифты для кодов символов более 127 всегда встраиваются.
            Чтение/запись **bool**.


### Примечания

По умолчанию **true**.
