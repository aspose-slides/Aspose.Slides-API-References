## best_images_compression_ratio свойство
Указывает, следует ли автоматически выбирать наиболее эффективное сжатие (вместо сжатия по умолчанию) для каждого изображения. Если установить значение **bool**.true, для каждого изображения в презентации будет выбран наиболее подходящий алгоритм сжатия, что приведёт к меньшему размеру результирующего PDF-документа. Выбор наилучшего коэффициента сжатия изображений требует значительных вычислительных ресурсов и дополнительной памяти, и эта опция по умолчанию **bool**.false.


### Замечания

По умолчанию **bool**.false.
