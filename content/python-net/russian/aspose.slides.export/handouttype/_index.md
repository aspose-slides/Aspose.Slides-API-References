## Перечисление HandoutType

Указывает, сколько слайдов и в какой последовательности будет размещено на странице.

Тип HandoutType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| HANDOUTS1 | Один слайд на страницу. |
| HANDOUTS2 | Два слайда на страницу. |
| HANDOUTS3 | Три слайда на страницу. |
| HANDOUTS_4_HORIZONTAL | Четыре слайда на страницу в горизонтальной последовательности. |
| HANDOUTS_4_VERTICAL | Четыре слайда на страницу в вертикальной последовательности. |
| HANDOUTS_6_HORIZONTAL | Шесть слайдов на страницу в горизонтальной последовательности. |
| HANDOUTS_6_VERTICAL | Шесть слайдов на страницу в вертикальной последовательности. |
| HANDOUTS_9_HORIZONTAL | Девять слайдов на страницу в горизонтальной последовательности. |
| HANDOUTS_9_VERTICAL | Девять слайдов на страницу в вертикальной последовательности. |
