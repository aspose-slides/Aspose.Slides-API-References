## default_delay свойство
Получает или задаёт значение времени задержки по умолчанию [мс]. Это значение будет использоваться, если [`ISlideShowTransition.advance_after_time`](/slides/python-net/ru/aspose.slides/islideshowtransition/advance_after_time) не установлен.
Значение по умолчанию равно 1000.
