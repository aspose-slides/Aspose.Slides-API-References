## disable_font_ligatures свойство
Получает или задает значение, указывающее, отображается ли текст без использования лигатур.
            Если установленo значение `true`, лигатуры будут отключены в выводе. По умолчанию это свойство имеет значение `false`.

@property
def disable_font_ligatures(self):
    ...

    ...
