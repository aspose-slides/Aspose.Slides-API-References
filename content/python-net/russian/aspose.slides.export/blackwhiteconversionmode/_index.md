## BlackWhiteConversionMode перечисление

Предоставляет параметры, которые контролируют, как изображения слайдов будут преобразованы в двуцветные изображения.

Тип BlackWhiteConversionMode раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| DEFAULT | Указывает отсутствие алгоритма преобразования. Будет использоваться алгоритм, реализованный в кодеке TIFF. (Default) |
| DITHERING | Указывает алгоритм дисперсии (Floyd-Steinberg). |
| DITHERING_FLOYD_STEINBERG | Указывает алгоритм дисперсии Floyd-Steinberg. |
| AUTO | Указывает автоматически рассчитываемый алгоритм пороговой обработки (Otsu). |
| AUTO_OTSU | Указывает автоматически рассчитываемый алгоритм порога Otsu. |
| THRESHOLD25 | Указывает статический алгоритм пороговой обработки (25%). |
| THRESHOLD50 | Указывает статический алгоритм пороговой обработки (50%). |
| THRESHOLD75 | Указывает статический алгоритм пороговой обработки (75%). |
