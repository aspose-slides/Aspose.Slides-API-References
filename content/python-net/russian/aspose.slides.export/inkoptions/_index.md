## InkOptions class

Тип InkOptions раскрывает следующие члены:

| :- | :- |
| [`hide_ink`](/slides/python-net/ru/aspose.slides.export/inkoptions/hide_ink/) | Показывает или скрывает элементы Ink в экспортируемом документе. |
| [`interpret_mask_op_as_opacity`](/slides/python-net/ru/aspose.slides.export/inkoptions/interpret_mask_op_as_opacity/) | Использует операцию ROP или непрозрачность для отрисовки кисти. |
