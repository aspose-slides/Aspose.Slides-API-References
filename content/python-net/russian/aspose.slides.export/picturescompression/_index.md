## PicturesCompression перечисление

Представляет уровень сжатия изображений

Тип PicturesCompression содержит следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| DPI330 | Хорошее качество для дисплеев высокой чёткости (HD) |
| DPI220 | Отличное качество на большинстве принтеров и экранов |
| DPI150 | Хорошо подходит для веб-страниц и проекторов |
| DPI96 | Минимизировать размер документа для обмена |
| DPI72 | Уровень сжатия по умолчанию |
| DOCUMENT_RESOLUTION | Использовать разрешение документа - изображение не будет сжато и будет использовано в документе как есть |
