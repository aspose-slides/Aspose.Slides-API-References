## LinkEmbedDecision перечисление

Определяет, как объект будет обрабатываться при сохранении.

Тип LinkEmbedDecision раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| LINK | Объект будет храниться внешне, ссылка будет указывать на URL |
| EMBED | Объект должен быть встроен в генерируемый файл, если это возможно. Если внедрение невозможно, будет вызван GetUrl, и в зависимости от результата объект будет ссылаться на URL или будет игнорироваться. |
| IGNORE | Объект будет игнорироваться. |
