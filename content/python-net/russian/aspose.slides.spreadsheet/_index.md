Содержит классы для работы с объектами электронных таблиц в презентациях Microsoft PowerPoint.
## Классы

| Класс | Описание |
| :- | :- |
| [`CellCircularReferenceException`](/slides/python-net/ru/aspose.slides.spreadsheet/cellcircularreferenceexception/) | Исключение, которое выбрасывается, когда обнаружено одно или несколько циклических ссылок, при которых формула ссылается на свою<br/>            собственную ячейку непосредственно или опосредованно. |
| [`CellInvalidFormulaException`](/slides/python-net/ru/aspose.slides.spreadsheet/cellinvalidformulaexception/) | Исключение, которое выбрасывается, когда вычисленная формула некорректна или не была разобрана. |
| [`CellInvalidReferenceException`](/slides/python-net/ru/aspose.slides.spreadsheet/cellinvalidreferenceexception/) | Исключение, которое выбрасывается, когда обнаружена недопустимая ссылка на ячейку. |
| [`CellUnsupportedDataException`](/slides/python-net/ru/aspose.slides.spreadsheet/cellunsupporteddataexception/) | Исключение, которое выбрасывается, когда в ячейке электронной таблицы обнаружены неподдерживаемые данные. |
