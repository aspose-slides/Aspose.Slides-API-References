## IShapeStyle класс

Представляет ссылку на стиль формы.

Тип IShapeStyle предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`line_color`](/slides/python-net/ru/aspose.slides/ishapestyle/line_color/) | Возвращает цвет контура формы.<br/>            Только для чтения [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`line_style_index`](/slides/python-net/ru/aspose.slides/ishapestyle/line_style_index/) | Возвращает или задает индекс столбца линии в матрице стилей.<br/>            Чтение/запись **int**. |
| [`fill_color`](/slides/python-net/ru/aspose.slides/ishapestyle/fill_color/) | Возвращает цвет заливки формы.<br/>            Только для чтения [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`fill_style_index`](/slides/python-net/ru/aspose.slides/ishapestyle/fill_style_index/) | Возвращает или задает индекс столбца заливки формы в матрицах стилей.<br/>            0 означает отсутствие заливки,<br/>            положительное значение — индекс в стилях заливки темы,<br/>            отрицательное значение — индекс в стилях фона темы.<br/>            Чтение/запись **int**. |
| [`effect_color`](/slides/python-net/ru/aspose.slides/ishapestyle/effect_color/) | Возвращает цвет эффекта формы.<br/>            Только для чтения [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`effect_style_index`](/slides/python-net/ru/aspose.slides/ishapestyle/effect_style_index/) | Возвращает или задает индекс столбца эффекта формы в матрице стилей.<br/>            Чтение/запись **int**. |
| [`font_color`](/slides/python-net/ru/aspose.slides/ishapestyle/font_color/) | Возвращает цвет шрифта формы.<br/>            Только для чтения [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`font_collection_index`](/slides/python-net/ru/aspose.slides/ishapestyle/font_collection_index/) | Возвращает или задает индекс шрифта формы в коллекции шрифтов.<br/>            Чтение/запись [`FontCollectionIndex`](/slides/python-net/ru/aspose.slides/fontcollectionindex). |
