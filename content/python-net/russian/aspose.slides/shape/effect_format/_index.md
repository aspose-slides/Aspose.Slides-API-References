## effect_format свойство
Возвращает объект EffectFormat, который содержит пиксельные эффекты, применённые к shape.
Примечание: может вернуть None для некоторых типов shape, у которых нет свойств effect.
Только для чтения [`IEffectFormat`](/slides/python-net/ru/aspose.slides/ieffectformat).
