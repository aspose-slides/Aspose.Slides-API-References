## line_format свойство
Возвращает объект LineFormat, содержащий свойства форматирования линий для фигуры.
            Примечание: может возвращать None для некоторых типов фигур, которые не имеют свойств линий.
            Только для чтения [`ILineFormat`](/slides/python-net/ru/aspose.slides/ilineformat).
