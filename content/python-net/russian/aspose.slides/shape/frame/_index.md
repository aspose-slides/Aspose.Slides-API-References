## свойство рамки
Возвращает или задает свойства рамки фигуры.
Чтение/запись [`IShapeFrame`](/slides/python-net/ru/aspose.slides/ishapeframe).


### Примечания
Значение каждого свойства возвращаемого экземпляра IShapeFrame не 
            неопределено (не NaN и не NotDefined).
            Значение каждого свойства присвоенного экземпляра IShapeFrame должно быть не 
            неопределено (должно быть не NaN и не NotDefined).
            Вы можете задавать неопределённые значения для свойств экземпляра RawFrame.

@property
def frame(self):
    ...

    ...
