## FillType перечисление

Указывает тип внутреннего заполнения различных визуальных объектов.

Тип FillType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| NOT_DEFINED | Тип заполнения не определён. |
| NO_FILL | Заполнение не применяется. |
| SOLID | Заполнено сплошным цветом. |
| GRADIENT | Заполнение градиентное. |
| PATTERN | Для заполнения объекта используется повторяющийся узор. |
| PICTURE | Для заполнения объекта используется одна картинка. |
| GROUP | Визуальный объект наследует свойства заливки от группы. |
