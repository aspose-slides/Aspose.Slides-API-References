## Перечисление SourceFormat

Представляет формат исходного файла.

Тип SourceFormat раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| PPT | Презентация Microsoft PowerPoint 97-2003 (*.ppt). |
| PPTX | Презентация Microsoft Office Open XML (*.pptx). |
| ODP | Презентация OpenDocument (*.odp). |
| PPTM | Презентация Microsoft Office Open XML с поддержкой макросов (*.pptm). |
| PPSX | Слайд-шоу Microsoft Office Open XML (*.ppsx). |
| PPSM | Слайд-шоу Microsoft Office Open XML с поддержкой макросов (*.ppsm). |
| POTX | Шаблон Microsoft Office Open XML (*.potx). |
| POTM | Шаблон Microsoft Office Open XML с поддержкой макросов (*.potm). |
| PPS | Слайд-шоу Microsoft PowerPoint 97-2003 (*.pps). |
| POT | Шаблон Microsoft PowerPoint 97-2003 (*.pot). |
| OTP | Шаблон презентации OpenDocument (*.otp). |
| FODP | Презентация Flat XML ODF (*.fodp). |
| XML | Презентация PowerPoint XML (*.xml). |
