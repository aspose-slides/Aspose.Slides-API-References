## blob_management_options свойство
Представляет параметры, которые могут использоваться для управления поведением обработки Binary Large Objects (BLOBs),
            например, использование временных файлов или максимального количества байтов BLOBs в памяти. Эти параметры предназначены для настройки
            оптимального соотношения производительность/потребление памяти для конкретной среды или требований.
            Binary Large Object (BLOB) представляет собой бинарные данные, хранящиеся как единый объект — то есть BLOB может
            быть аудио, видео или самой презентацией.
