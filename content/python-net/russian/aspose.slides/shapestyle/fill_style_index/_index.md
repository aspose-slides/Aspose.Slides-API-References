## fill_style_index свойство
Returns or sets shape's fill column index in style matrices.
            0 означает отсутствие заливки,
            положительное значение - индекс в стилях заливки темы,
            отрицательное значение - индекс в стилях фона темы.
            Чтение/запись **int**.
