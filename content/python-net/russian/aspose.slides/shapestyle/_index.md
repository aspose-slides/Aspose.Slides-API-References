## ShapeStyle класс

Представляет ссылку на стиль фигуры.

Тип ShapeStyle раскрывает следующие члены:

## Свойства

| СВОЙСТВО | Описание |
| :- | :- |
| [`line_color`](/slides/python-net/ru/aspose.slides/shapestyle/line_color/) | Возвращает цвет контура фигуры.<br/>            Только для чтения [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`line_style_index`](/slides/python-net/ru/aspose.slides/shapestyle/line_style_index/) | Возвращает или задает индекс столбца линии в матрице стилей.<br/>            Чтение/запись **int**. |
| [`fill_color`](/slides/python-net/ru/aspose.slides/shapestyle/fill_color/) | Возвращает цвет заполнения фигуры.<br/>            Только для чтения [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`fill_style_index`](/slides/python-net/ru/aspose.slides/shapestyle/fill_style_index/) | Возвращает или задает индекс столбца заполнения фигуры в матрицах стилей.<br/>            0 означает отсутствие заполнения,<br/>            положительное значение — индекс в стилях заливки темы,<br/>            отрицательное значение — индекс в стилях фона темы.<br/>            Чтение/запись **int**. |
| [`effect_color`](/slides/python-net/ru/aspose.slides/shapestyle/effect_color/) | Возвращает цвет эффекта фигуры.<br/>            Только для чтения [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`effect_style_index`](/slides/python-net/ru/aspose.slides/shapestyle/effect_style_index/) | Возвращает или задает индекс столбца эффекта фигуры в матрице стилей.<br/>            Чтение/запись **int**. |
| [`font_color`](/slides/python-net/ru/aspose.slides/shapestyle/font_color/) | Возвращает цвет шрифта фигуры.<br/>            Только для чтения [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`font_collection_index`](/slides/python-net/ru/aspose.slides/shapestyle/font_collection_index/) | Возвращает или задает индекс шрифта фигуры в коллекции шрифтов.<br/>            Чтение/запись [`FontCollectionIndex`](/slides/python-net/ru/aspose.slides/fontcollectionindex). |
