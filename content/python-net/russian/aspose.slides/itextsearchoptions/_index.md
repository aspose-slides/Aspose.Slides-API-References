## ITextSearchOptions класс

Представляет параметры, которые можно использовать для поиска текста в Presentation, Slide или TextFrame.

Тип ITextSearchOptions раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`case_sensitive`](/slides/python-net/ru/aspose.slides/itextsearchoptions/case_sensitive/) | Установите true, чтобы использовать поиск с учётом регистра, false — иначе.<br/>            Чтение/запись **bool**. |
| [`whole_words_only`](/slides/python-net/ru/aspose.slides/itextsearchoptions/whole_words_only/) | Установите true, чтобы совпадали только целые слова, false — иначе.<br/>            Чтение/запись **bool**. |
| [`include_notes`](/slides/python-net/ru/aspose.slides/itextsearchoptions/include_notes/) | Установите `true`, чтобы включить поиск текста, содержащегося в заметках слайдов <br/>            при выполнении операций поиска текста, замены или подсветки.<br/>            Значение по умолчанию — `false`. |
