## IShapeBevelEffectiveData класс

Неизменяемый объект, содержащий свойства рельефа грани формы.

Тип IShapeBevelEffectiveData предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`width`](/slides/python-net/ru/aspose.slides/ishapebeveleffectivedata/width/) | Ширина фаски.<br/>            Только для чтения **float**. |
| [`height`](/slides/python-net/ru/aspose.slides/ishapebeveleffectivedata/height/) | Высота фаски.<br/>            Только для чтения **float**. |
| [`bevel_type`](/slides/python-net/ru/aspose.slides/ishapebeveleffectivedata/bevel_type/) | Тип фаски.<br/>            Только для чтения [`BevelPresetType`](/slides/python-net/ru/aspose.slides/bevelpresettype). |


### Примечания
