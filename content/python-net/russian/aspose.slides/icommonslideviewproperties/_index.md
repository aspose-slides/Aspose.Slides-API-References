## ICommonSlideViewProperties класс

Представляет общие свойства представления слайда.

Тип ICommonSlideViewProperties раскрывает следующие члены:

## Свойства

| Property | Description |
| :- | :- |
| [`scale`](/slides/python-net/ru/aspose.slides/icommonslideviewproperties/scale/) | Указывает коэффициент масштабирования представления в процентах.<br/>            Чтение/запись **int**. |
| [`variable_scale`](/slides/python-net/ru/aspose.slides/icommonslideviewproperties/variable_scale/) | Указывает, что содержимое представления должно автоматически масштабироваться для наилучшего соответствия текущему размеру окна.<br/>            Чтение/запись **bool**. |
| [`drawing_guides`](/slides/python-net/ru/aspose.slides/icommonslideviewproperties/drawing_guides/) | Возвращает коллекцию вспомогательных направляющих рисования.<br/>            Только для чтения [`IDrawingGuidesCollection`](/slides/python-net/ru/aspose.slides/idrawingguidescollection) |
