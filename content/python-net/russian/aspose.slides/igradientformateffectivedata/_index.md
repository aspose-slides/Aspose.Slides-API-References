## IGradientFormatEffectiveData класс

Неизменяемый объект, содержащий эффективные свойства градиентного заполнения.

Тип IGradientFormatEffectiveData раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`tile_flip`](/slides/python-net/ru/aspose.slides/igradientformateffectivedata/tile_flip/) | Возвращает режим отражения для градиента.<br/>            Только для чтения [`TileFlip`](/slides/python-net/ru/aspose.slides/tileflip). |
| [`gradient_direction`](/slides/python-net/ru/aspose.slides/igradientformateffectivedata/gradient_direction/) | Возвращает стиль градиента.<br/>            Только для чтения [`GradientDirection`](/slides/python-net/ru/aspose.slides/gradientdirection). |
| [`linear_gradient_angle`](/slides/python-net/ru/aspose.slides/igradientformateffectivedata/linear_gradient_angle/) | Возвращает угол градиента.<br/>            Только для чтения **float**. |
| [`linear_gradient_scaled`](/slides/python-net/ru/aspose.slides/igradientformateffectivedata/linear_gradient_scaled/) | Определяет, масштабируется ли градиент.<br/>            Только для чтения **bool**. |
| [`gradient_shape`](/slides/python-net/ru/aspose.slides/igradientformateffectivedata/gradient_shape/) | Возвращает форму градиента.<br/>            Только для чтения [`GradientShape`](/slides/python-net/ru/aspose.slides/gradientshape). |
| [`gradient_stops`](/slides/python-net/ru/aspose.slides/igradientformateffectivedata/gradient_stops/) | Возвращает коллекцию градиентных остановок.<br/>            Только для чтения [`IGradientStopCollectionEffectiveData`](/slides/python-net/ru/aspose.slides/igradientstopcollectioneffectivedata). |

### Замечания

Этот интерфейс используется как часть [`IFillFormatEffectiveData`](/slides/python-net/ru/aspose.slides/ifillformateffectivedata) и [`ILineFillFormatEffectiveData`](/slides/python-net/ru/aspose.slides/ilinefillformateffectivedata).
