## ImageFormat перечисление

Представляет файловый формат изображения.

Тип ImageFormat раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| MEMORY_BMP | Представляет формат битмапа в памяти. |
| BMP | Представляет формат изображения bitmap (BMP). |
| EMF | Представляет формат изображения улучшенного метафайла (EMF). |
| WMF | Представляет формат изображения метафайла Windows (WMF). |
| GIF | Представляет формат изображения Graphics Interchange Format (GIF). |
| JPEG | Представляет формат изображения Joint Photographic Experts Group (JPEG). |
| PNG | Представляет формат изображения W3C Portable Network Graphics (PNG). |
| TIFF | Представляет формат изображения Tagged Image File Format (TIFF). |
| EXIF | Представляет формат Exchangeable Image File (Exif). |
| ICON | Представляет формат изображения иконки Windows. |
