## AutoShapeLock класс

Определяет, какие операции отключены у родительского AutoshapeEx.

**Наследование:**[`AutoShapeLock`](/slides/python-net/ru/aspose.slides/autoshapelock) → [`BaseShapeLock`](/slides/python-net/ru/aspose.slides/baseshapelock)

Тип AutoShapeLock раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`no_locks`](/slides/python-net/ru/aspose.slides/autoshapelock/no_locks/) | Возвращает true, если все флаги блокировки отключены.<br/>            Только для чтения **bool**. |
| [`grouping_locked`](/slides/python-net/ru/aspose.slides/autoshapelock/grouping_locked/) | Определяет, запрещено ли добавление этой формы в группу.<br/>            Чтение/запись **bool**. |
| [`select_locked`](/slides/python-net/ru/aspose.slides/autoshapelock/select_locked/) | Определяет, запрещено ли выделение этой формы.<br/>            Чтение/запись **bool**. |
| [`rotate_locked`](/slides/python-net/ru/aspose.slides/autoshapelock/rotate_locked/) | Определяет, запрещено ли изменение угла вращения этой формы.<br/>            Чтение/запись **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/ru/aspose.slides/autoshapelock/aspect_ratio_locked/) | Определяет, должна ли форма сохранять соотношение сторон при изменении размера.<br/>            Чтение/запись **bool**. |
| [`position_locked`](/slides/python-net/ru/aspose.slides/autoshapelock/position_locked/) | Определяет, запрещено ли перемещение этой формы.<br/>            Чтение/запись **bool**. |
| [`size_locked`](/slides/python-net/ru/aspose.slides/autoshapelock/size_locked/) | Определяет, запрещено ли изменение размера этой формы.<br/>            Чтение/запись **bool**. |
| [`edit_points_locked`](/slides/python-net/ru/aspose.slides/autoshapelock/edit_points_locked/) | Определяет, запрещено ли прямое изменение контура этой формы.<br/>            Чтение/запись **bool**. |
| [`adjust_handles_locked`](/slides/python-net/ru/aspose.slides/autoshapelock/adjust_handles_locked/) | Определяет, запрещено ли изменение значений корректировки.<br/>            Чтение/запись **bool**. |
| [`arrowheads_locked`](/slides/python-net/ru/aspose.slides/autoshapelock/arrowheads_locked/) | Определяет, запрещено ли изменение наконечников стрелок.<br/>            Чтение/запись **bool**. |
| [`shape_type_locked`](/slides/python-net/ru/aspose.slides/autoshapelock/shape_type_locked/) | Определяет, запрещено ли изменение типа формы.<br/>            Чтение/запись **bool**. |
| [`text_locked`](/slides/python-net/ru/aspose.slides/autoshapelock/text_locked/) | Определяет, запрещено ли редактирование текста.<br/>            Чтение/запись **bool**. |
