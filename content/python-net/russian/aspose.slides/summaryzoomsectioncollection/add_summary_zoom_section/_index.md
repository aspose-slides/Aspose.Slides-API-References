## add_summary_zoom_section(self, section) {#isection}
Создает новый объект Summary Zoom Section и добавляет его в коллекцию

### Возвращаемое значение

Добавлен [`ISummaryZoomFrame`](/slides/python-net/ru/aspose.slides/isummaryzoomframe) элемент



```python
def add_summary_zoom_section(self, section):
    ...
```


| Параметр | Тип | Описание |
| :- | :- | :- |
| section | [`ISection`](/slides/python-net/ru/aspose.slides/isection) | Раздел для нового элемента Summary Zoom Section [`ISection`](/slides/python-net/ru/aspose.slides/isection) |

### Замечания

Если элемент для этого раздела уже существует в коллекции, возвращается существующий элемент.

### Исключения

| Исключение | Описание |
| :- | :- |
| **RuntimeError(Proxy error(ArgumentException))** | Ссылка на раздел не принадлежит текущей презентации или не содержит каких-либо слайдов. |
