## INormalViewProperties класс

Представляет свойства нормального просмотра. Нормальный просмотр состоит из
трёх областей содержимого: самого слайда, боковой области содержимого и нижней области содержимого.

Тип INormalViewProperties раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`show_outline_icons`](/slides/python-net/ru/aspose.slides/inormalviewproperties/show_outline_icons/) | Указывает, должна ли система отображать значки при выводе контурного содержимого в любой<br/>            из областей содержимого режима нормального просмотра.<br/>            Чтение/запись **bool**. |
| [`snap_vertical_splitter`](/slides/python-net/ru/aspose.slides/inormalviewproperties/snap_vertical_splitter/) | Указывает, должен ли вертикальный разделитель переходить в состояние свёрнутого, когда боковая<br/>            область достаточно мала.<br/>            Чтение/запись **bool**. |
| [`vertical_bar_state`](/slides/python-net/ru/aspose.slides/inormalviewproperties/vertical_bar_state/) | Указывает состояние, в котором должна отображаться вертикальная полоса разделителя. <br/>            Вертикальная полоса разделителя отделяет слайд от боковой области содержимого. |
| [`horizontal_bar_state`](/slides/python-net/ru/aspose.slides/inormalviewproperties/horizontal_bar_state/) | Указывает состояние, в котором должна отображаться горизонтальная полоса разделителя.<br/>            Горизонтальная полоса разделителя отделяет слайд от области содержимого под слайдом. |
| [`prefer_single_view`](/slides/python-net/ru/aspose.slides/inormalviewproperties/prefer_single_view/) | Указывает, предпочитает ли пользователь видеть единственную область содержимого, занимающую всё окно, вместо стандартного нормального просмотра с тремя областями содержимого. При включении система может выбрать<br/>            отображение одной из областей содержимого на всём окне.<br/>            Чтение/запись **bool**. |
| [`restored_left`](/slides/python-net/ru/aspose.slides/inormalviewproperties/restored_left/) | Этот элемент задаёт размер боковой области содержимого нормального просмотра, когда область имеет переменный<br/>            восстановленный размер (не свёрнутый и не развернутый).<br/>            Только для чтения [`INormalViewRestoredProperties`](/slides/python-net/ru/aspose.slides/inormalviewrestoredproperties). |
| [`restored_top`](/slides/python-net/ru/aspose.slides/inormalviewproperties/restored_top/) | Этот элемент задаёт размер верхней области слайда в нормальном просмотре, когда область имеет переменный<br/>            восстановленный размер (не свёрнутый и не развернутый).<br/>            Только для чтения [`INormalViewRestoredProperties`](/slides/python-net/ru/aspose.slides/inormalviewrestoredproperties). |
