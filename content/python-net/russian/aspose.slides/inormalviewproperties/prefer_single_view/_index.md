## prefer_single_view свойство
Указывает, предпочитает ли пользователь видеть область с одним содержимым во всю окно вместо стандартного обычного представления с тремя областями содержимого. Если включено, приложение может выбрать отображать одну из областей содержимого на всём окне.
Чтение/запись **bool**.

```python
@property
def prefer_single_view(self):
    ...

@prefer_single_view.setter

    ...
```
