## CommonSlideViewProperties класс

Представляет общие свойства представления слайда.

Тип CommonSlideViewProperties раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`scale`](/slides/python-net/ru/aspose.slides/commonslideviewproperties/scale/) | Указывает коэффициент масштабирования представления в процентах.<br/>            Чтение/запись **int**. |
| [`variable_scale`](/slides/python-net/ru/aspose.slides/commonslideviewproperties/variable_scale/) | Указывает, что содержимое представления должно автоматически масштабироваться, чтобы наилучшим образом вписаться в текущий размер окна.<br/>            Чтение/запись **bool**. |
| [`drawing_guides`](/slides/python-net/ru/aspose.slides/commonslideviewproperties/drawing_guides/) | Возвращает коллекцию направляющих чертежа.<br/>            Только чтение [`IDrawingGuidesCollection`](/slides/python-net/ru/aspose.slides/idrawingguidescollection) |
