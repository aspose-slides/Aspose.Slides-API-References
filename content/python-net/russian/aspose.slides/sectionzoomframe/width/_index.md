## width свойство
Получает или задает значение width формы, измеряемое в пунктах.
            Чтение/запись **float**.


### Примечания

Возвращаемое значение всегда определено и никогда не является **float**.
            Присваиваемое значение также должно быть определено; присваивайте **float** только свойствам экземпляра `RawFrame`.
