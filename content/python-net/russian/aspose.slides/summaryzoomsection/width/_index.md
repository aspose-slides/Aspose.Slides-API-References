## width свойство
Получает или задает значение width фигуры, измеренное в пунктах.
            Чтение/запись **float**.


### Примечания

Возвращаемое значение всегда определено и никогда не является **float**.
            Назначенное значение также должно быть определено; присваивайте **float** только свойствам экземпляра `RawFrame`.
