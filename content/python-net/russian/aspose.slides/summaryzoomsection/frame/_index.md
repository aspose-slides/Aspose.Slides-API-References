## свойство frame
Возвращает или задает свойства рамки фигуры.
            Чтение/запись [`IShapeFrame`](/slides/python-net/ru/aspose.slides/ishapeframe).

### Примечания

Значение каждого свойства возвращаемого экземпляра IShapeFrame не 
            undefined (не NaN и не NotDefined).
            Значение каждого свойства присваиваемого экземпляра IShapeFrame должно быть не 
            undefined (не NaN и не NotDefined).
            Вы можете задавать undefined значения для свойств экземпляра RawFrame.

### Определение:
```python
@property
def frame(self):
    ...

@frame.setter
def frame(self, value):
    ...
```
