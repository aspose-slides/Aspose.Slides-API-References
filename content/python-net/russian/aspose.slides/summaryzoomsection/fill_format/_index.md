## fill_format свойство
Возвращает объект FillFormat, который содержит свойства форматирования заливки для формы.
            Примечание: может вернуть None для некоторых типов фигур, которые не имеют свойств заливки.
            Только для чтения [`IFillFormat`](/slides/python-net/ru/aspose.slides/ifillformat).
