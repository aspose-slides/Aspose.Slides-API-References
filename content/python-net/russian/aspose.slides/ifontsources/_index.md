## IFontSources класс

Предоставляет файлы и источники памяти для внешних шрифтов.

Тип IFontSources раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`font_folders`](/slides/python-net/ru/aspose.slides/ifontsources/font_folders/) | Папки, содержащие файлы шрифтов.<br/>            Все файлы шрифтов, находящиеся в этих папках, включаются в коллекцию. Папки, которые ищутся рекурсивно. |
| [`memory_fonts`](/slides/python-net/ru/aspose.slides/ifontsources/memory_fonts/) | Коллекция шрифтов, представленных в виде массивов байтов. |
