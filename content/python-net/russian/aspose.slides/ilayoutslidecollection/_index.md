## ILayoutSlideCollection класс

Представляет базовый класс для коллекции макетных слайдов.

Тип ILayoutSlideCollection раскрывает следующие члены:

Возвращает макетный слайд по индексу.
Только для чтения [`ILayoutSlide`](/slides/python-net/ru/aspose.slides/ilayoutslide).
