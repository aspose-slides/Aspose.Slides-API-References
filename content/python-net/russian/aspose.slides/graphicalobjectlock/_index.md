## GraphicalObjectLock класс

Определяет, какие операции отключены у родительского GraphicalObject.

**Наследование:**[`GraphicalObjectLock`](/slides/python-net/ru/aspose.slides/graphicalobjectlock) → [`BaseShapeLock`](/slides/python-net/ru/aspose.slides/baseshapelock)

Тип GraphicalObjectLock предоставляет следующие члены:

## Свойства

| Сводство | Описание |
| :- | :- |
| [`no_locks`](/slides/python-net/ru/aspose.slides/graphicalobjectlock/no_locks/) | Возвращает true, если все флаги блокировки отключены.<br/>            Только для чтения **bool**. |
| [`grouping_locked`](/slides/python-net/ru/aspose.slides/graphicalobjectlock/grouping_locked/) | Определяет, запрещено ли добавлять эту форму в группу.<br/>            Чтение/запись **bool**. |
| [`drilldown_locked`](/slides/python-net/ru/aspose.slides/graphicalobjectlock/drilldown_locked/) | Определяет, запрещено ли выбирать подформы этого объекта.<br/>            Чтение/запись **bool**. |
| [`select_locked`](/slides/python-net/ru/aspose.slides/graphicalobjectlock/select_locked/) | Определяет, запрещено ли выбирать эту форму.<br/>            Чтение/запись **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/ru/aspose.slides/graphicalobjectlock/aspect_ratio_locked/) | Определяет, должна ли форма сохранять соотношение сторон при изменении размера.<br/>            Чтение/запись **bool**. |
| [`position_locked`](/slides/python-net/ru/aspose.slides/graphicalobjectlock/position_locked/) | Определяет, запрещено ли перемещать эту форму.<br/>            Чтение/запись **bool**. |
| [`size_locked`](/slides/python-net/ru/aspose.slides/graphicalobjectlock/size_locked/) | Определяет, запрещено ли изменять размер этой формы.<br/>            Чтение/запись **bool**. |
