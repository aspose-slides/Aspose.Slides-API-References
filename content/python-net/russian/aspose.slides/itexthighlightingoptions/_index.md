## ITextHighlightingOptions класс

Представляет параметры, которые можно использовать для выделения текста в текстовом фрейме.

Тип ITextHighlightingOptions раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`case_sensitive`](/slides/python-net/ru/aspose.slides/itexthighlightingoptions/case_sensitive/) | Установите true, чтобы использовать поиск с учётом регистра, false — иначе.<br/>            Чтение/запись **bool**. |
| [`whole_words_only`](/slides/python-net/ru/aspose.slides/itexthighlightingoptions/whole_words_only/) | Установите true, чтобы сопоставлять только целые слова, false — иначе.<br/>            Чтение/запись **bool**. |
