## IBaseSlideHeaderFooterManager класс

Представляет менеджер, который управляет поведением плейсхолдров нижнего колонтитула, даты-времени и номера страницы для всех типов слайдов.

Тип IBaseSlideHeaderFooterManager раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`is_footer_visible`](/slides/python-net/ru/aspose.slides/ibaseslideheaderfootermanager/is_footer_visible/) | Получает значение, указывающее, что заполнитель нижнего колонтитула присутствует.<br/>            Чтение **bool**. |
| [`is_slide_number_visible`](/slides/python-net/ru/aspose.slides/ibaseslideheaderfootermanager/is_slide_number_visible/) | Получает значение, указывающее, что заполнитель номера страницы присутствует.<br/>            Чтение**bool**. |
| [`is_date_time_visible`](/slides/python-net/ru/aspose.slides/ibaseslideheaderfootermanager/is_date_time_visible/) | Получает значение, указывающее, что заполнитель даты-времени присутствует.<br/>            Чтение**bool**. |
