## ViewType перечисление

Типы представления презентации

Тип ViewType предоставляет следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| NOT_DEFINED | Значение не определено |
| SLIDE_VIEW | Обычный просмотр слайдов |
| SLIDE_MASTER_VIEW | Вид шаблона слайда |
| NOTES_VIEW | Вид заметок |
| HANDOUT_VIEW | Вид раздатки |
| NOTES_MASTER_VIEW | Вид шаблона заметок |
| OUTLINE_VIEW | Вид структуры |
| SLIDE_SORTER_VIEW | Вид сортировщика слайдов |
| SLIDE_THUMBNAIL_VIEW | Вид миниатюр слайдов |
