## Перечисление ShapeAdjustmentType

Указывает различные типы значений регулировки формы.

Тип ShapeAdjustmentType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| CUSTOM | Пользовательский тип (неизвестная коррекция) |
| CORNER_SIZE | Контролирует размер углов. |
| LEFT_UP_CORNER | Контролирует верхний левый угол. |
| RIGHT_UP_CORNER | Контролирует верхний правый угол. |
| UP_CORNERS | Контролирует верхние углы. |
| DOWN_CORNERS | Контролирует нижние углы. |
| THICKNESS | Контролирует толщину фигуры. |
| ARROW_TAIL_THICKNESS | Контролирует толщину хвоста стрелки. |
| ARROWHEAD_LENGTH | Контролирует длину стрелочной головки. |
| ARROWHEAD_WIDTH | Контролирует ширину стрелочной головки. |
| RADIUS | Контролирует размер радиуса фигуры или её части. |
| DEPTH | Контролирует глубину зубьев шестерни или эффект фаски. |
| SHAPE_PART_OFFSET | Контролирует смещение одной части фигуры относительно другой. |
| ANGLE | Контролирует угол для фигуры или её части. |
| START_ANGLE | Начальный угол для фигур сектора и дуги. |
| END_ANGLE | Конечный угол для фигур сектора и дуги. |
| START_POINT_X | Контролирует позицию X начальной точки выноски. |
| START_POINT_Y | Контролирует позицию Y начальной точки выноски. |
| CONNECTOR_POINT_1X | Контролирует горизонтальное положение точки регулировки угла выноски. |
| CONNECTOR_POINT_1Y | Контролирует вертикальное положение точки регулировки угла выноски. |
| CONNECTOR_POINT_2X | Контролирует горизонтальное положение точки регулировки угла выноски. |
| CONNECTOR_POINT_2Y | Контролирует вертикальное положение точки регулировки угла выноски. |
| CONNECTOR_BEND_POSITION_X | Контролирует горизонтальное положение изгиба в соединителе. |
| CONNECTOR_BEND_POSITION_Y | Контролирует вертикальное положение изгиба в соединителе. |
| ATTACH_Y | Контролирует вертикальную точку привязки фигуры. |
| ATTACH_X | Контролирует горизонтальную точку привязки фигуры. |
| CALLOUT_HEIGHT | Контролирует вертикальный размер выноски. |
| CALLOUT_WIDTH | Контролирует горизонтальный размер выноски. |
| CALLOUT_SIZE | Контролирует размер выноски. |
| CURVATURE | Кривизна изогнутой, скобки, изогнутой стрелки или фигуры. |
| HORIZONTAL_THICKNESS | Контролирует горизонтальную толщину угловой фигуры. |
| VERTICAL_THICKNESS | Контролирует вертикальную толщину угловой фигуры. |
| VERTICAL_SIZE | Контролирует вертикальный размер фигуры. |
| HORIZONTAL_SIZE | Контролирует горизонтальный размер фигуры. |
| TOP | Контролирует верхнюю сторону фигуры. |
