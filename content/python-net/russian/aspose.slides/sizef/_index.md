## SizeF класс

Хранит упорядоченную пару чисел с плавающей точкой, обычно ширину и высоту прямоугольника. Совместим с .NET `System.Drawing.SizeF`.

| Property | Description |
| :- | :- |
| [`width`](/slides/python-net/ru/aspose.slides/sizef/width/) | Возвращает горизонтальную компоненту этого размера.<br/>            Только для чтения **float**. |
| [`height`](/slides/python-net/ru/aspose.slides/sizef/height/) | Возвращает вертикальную компоненту этого размера.<br/>            Только для чтения **float**. |


### Примечания

Размеры сравниваются по их компонентам с помощью `==` и могут использоваться в качестве ключей словарей или элементов множеств.
