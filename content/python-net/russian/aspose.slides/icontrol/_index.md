## IControl класс

Представляет элемент управления ActiveX.

Тип IControl предоставляет следующие члены:

## Свойства

| Property | Description |
| :- | :- |
| [`name`](/slides/python-net/ru/aspose.slides/icontrol/name/) | Возвращает имя этого элемента управления.<br/>            Чтение/запись **str**. |
| [`class_id`](/slides/python-net/ru/aspose.slides/icontrol/class_id/) | Получает идентификатор класса этого элемента управления.<br/>            Только для чтения **System.Guid**. |
| [`substitute_picture_format`](/slides/python-net/ru/aspose.slides/icontrol/substitute_picture_format/) | Возвращает объект свойств заливки изображения ControlEx.<br/>            Только для чтения [`IPictureFillFormat`](/slides/python-net/ru/aspose.slides/ipicturefillformat). |
| [`frame`](/slides/python-net/ru/aspose.slides/icontrol/frame/) | Возвращает или задаёт рамку элемента управления.<br/>            Чтение/запись [`IShapeFrame`](/slides/python-net/ru/aspose.slides/ishapeframe). |
| [`properties`](/slides/python-net/ru/aspose.slides/icontrol/properties/) | Возвращает коллекцию свойств ActiveX.<br/>            Только для чтения [`IControlPropertiesCollection`](/slides/python-net/ru/aspose.slides/icontrolpropertiescollection). |
| [`persistence`](/slides/python-net/ru/aspose.slides/icontrol/persistence/) | Получает метод, используемый для сохранения свойств элемента управления ActiveX.<br/>            Только для чтения [`PersistenceType`](/slides/python-net/ru/aspose.slides/persistencetype). |
| [`active_x_control_binary`](/slides/python-net/ru/aspose.slides/icontrol/active_x_control_binary/) | Указывает способ сохранения элемента управления ActiveX, когда используемый метод сохранения — один из PersistStream, PersistStreamInit или PersistStorage. |
