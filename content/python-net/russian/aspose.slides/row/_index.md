## Класс Row

Представляет строку в таблице.

**Наследование:**[`Row`](/slides/python-net/ru/aspose.slides/row) → [`CellCollection`](/slides/python-net/ru/aspose.slides/cellcollection)

Тип Row предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`slide`](/slides/python-net/ru/aspose.slides/row/slide/) | Возвращает родительский слайд коллекции CellCollection.<br/>            Только для чтения [`IBaseSlide`](/slides/python-net/ru/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/ru/aspose.slides/row/presentation/) | Возвращает родительскую презентацию коллекции CellCollection.<br/>            Только для чтения [`IPresentation`](/slides/python-net/ru/aspose.slides/ipresentation). |
| [`height`](/slides/python-net/ru/aspose.slides/row/height/) | Возвращает высоту строки.<br/>            Только для чтения **float**. |
| [`minimal_height`](/slides/python-net/ru/aspose.slides/row/minimal_height/) | Возвращает или задает минимально возможную высоту строки.<br/>            Чтение/запись **float**. |
| [`row_format`](/slides/python-net/ru/aspose.slides/row/row_format/) | Возвращает объект RowFormat, содержащий свойства форматирования для этой строки.<br/>            Только для чтения [`IRowFormat`](/slides/python-net/ru/aspose.slides/irowformat). |
