## ICameraEffectiveData класс

Неизменяемый объект, содержащий эффективные свойства камеры.

Тип ICameraEffectiveData раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`camera_type`](/slides/python-net/ru/aspose.slides/icameraeffectivedata/camera_type/) | Тип камеры.<br/>            Только для чтения [`CameraPresetType`](/slides/python-net/ru/aspose.slides/camerapresettype). |
| [`field_of_view_angle`](/slides/python-net/ru/aspose.slides/icameraeffectivedata/field_of_view_angle/) | Поле зрения камеры (0-180 град, поле зрения).<br/>            Только для чтения **float**. |
| [`zoom`](/slides/python-net/ru/aspose.slides/icameraeffectivedata/zoom/) | Масштаб камеры (положительное значение в процентах).<br/>            Только для чтения **float**. |

## Методы

| Метод | Описание |
| :- | :- |
| [`get_rotation(self)`](/slides/python-net/ru/aspose.slides/icameraeffectivedata/get_rotation/#) | Поворот определяется с использованием координаты широты<br/>            координаты долготы и вращения вокруг оси <br/>            как координаты широты и долготы.<br/>            первый элемент возвращаемого массива — широта, второй — долгота, третий — вращение.<br/>            Возвращает None, если поворот не определён. |


### Примечания

Этот интерфейс используется как часть [`IThreeDFormatEffectiveData`](/slides/python-net/ru/aspose.slides/ithreedformateffectivedata).
