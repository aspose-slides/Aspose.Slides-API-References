## LayoutSlideCollection класс

Представляет базовый класс для коллекции слайдов макета.

Тип LayoutSlideCollection предоставляет следующие члены:

Возвращает слайд макета по индексу.
Только для чтения [`LayoutSlide`](/slides/python-net/ru/aspose.slides/layoutslide).
