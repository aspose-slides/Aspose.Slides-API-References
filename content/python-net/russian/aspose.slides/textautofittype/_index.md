## TextAutofitType перечисление

Представляет режим автоподгонки текста.

Тип TextAutofitType содержит следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| NOT_DEFINED | Не определено. |
| NONE | Нет автоподгонки. |
| NORMAL | Обычная автоподгонка. Размер шрифта и межстрочный интервал будут уменьшены, чтобы поместиться в форму. |
| SHAPE | Автоподгонка формы. Размер формы будет изменён, чтобы поместиться текст. |
