## ITagCollection класс

Представляет коллекцию тегов (пары строк, задаваемые пользователем)

Тип ITagCollection предоставляет следующие члены:

## Методы

| Метод | Описание |
| :- | :- |
| [`add(self, name, value)`](/slides/python-net/ru/aspose.slides/itagcollection/add/#str-str) | Добавляет новый тег в коллекцию. |
| [`remove(self, name)`](/slides/python-net/ru/aspose.slides/itagcollection/remove/#str) | Удаляет тег с указанным именем из коллекции. |
| [`index_of_name(self, name)`](/slides/python-net/ru/aspose.slides/itagcollection/index_of_name/#str) | Возвращает нулевой индекс указанного ключа в коллекции. |
| [`remove_at(self, index)`](/slides/python-net/ru/aspose.slides/itagcollection/remove_at/#int) | Удаляет тег по указанному индексу. |
| [`clear(self)`](/slides/python-net/ru/aspose.slides/itagcollection/clear/#) | Удаляет все теги из коллекции. |
| [`get_value_by_index(self, index)`](/slides/python-net/ru/aspose.slides/itagcollection/get_value_by_index/#int) | Возвращает значение тега по указанному индексу. |
