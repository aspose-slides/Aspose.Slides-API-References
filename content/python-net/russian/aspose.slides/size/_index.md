## Size класс

Хранит упорядоченную пару целых чисел, которая определяет ширину и высоту. Совместим с .NET `System.Drawing.Size`.

Тип Size раскрывает следующие члены:

## Конструкторы

| Конструктор | Описание |
| :- | :- |
| [`__init__(self, width=0, height=0)`](/slides/python-net/ru/aspose.slides/size/__init__/#int-int) | Создаёт размер с указанными шириной и высотой. Значения с плавающей запятой усекаются до целых. |

## Свойства

| Свойство | Описание |
| :- | :- |
| [`width`](/slides/python-net/ru/aspose.slides/size/width/) | Возвращает горизонтальную компоненту этого размера.<br/>            Только для чтения **int**. |
| [`height`](/slides/python-net/ru/aspose.slides/size/height/) | Возвращает вертикальную компоненту этого размера.<br/>            Только для чтения **int**. |


### Замечания

Размеры сравниваются по своим компонентам с помощью `==` и могут использоваться в качестве ключей словаря или элементов множества.
