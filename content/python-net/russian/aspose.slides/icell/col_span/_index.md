## col_span свойство
Возвращает количество столбцов сетки в таблице-родителе, которые должны быть охвачены текущей ячейкой. Это свойство позволяет ячейкам выглядеть как объединённые, поскольку они охватывают вертикальные границы других ячеек в таблице.
Только для чтения **int**.
