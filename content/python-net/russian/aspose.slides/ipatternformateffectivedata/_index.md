## IPatternFormatEffectiveData класс

Неизменяемый объект, содержащий свойства эффективного заполнения паттерном.

Тип IPatternFormatEffectiveData предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`pattern_style`](/slides/python-net/ru/aspose.slides/ipatternformateffectivedata/pattern_style/) | Возвращает стиль паттерна.<br/>            Только для чтения [`PatternStyle`](/slides/python-net/ru/aspose.slides/patternstyle). |
| [`fore_color`](/slides/python-net/ru/aspose.slides/ipatternformateffectivedata/fore_color/) | Возвращает цвет переднего плана паттерна.<br/>            Только для чтения [`Color`](/slides/python-net/ru/aspose.slides/color). |
| [`back_color`](/slides/python-net/ru/aspose.slides/ipatternformateffectivedata/back_color/) | Возвращает цвет фона паттерна.<br/>            Только для чтения [`Color`](/slides/python-net/ru/aspose.slides/color). |

## Методы

| Метод | Описание |
| :- | :- |
| [`get_tile_i_image(self, background, foreground)`](/slides/python-net/ru/aspose.slides/ipatternformateffectivedata/get_tile_i_image/#asposeslidescolor-asposeslidescolor) | Создает изображение плитки для заполнения паттерном с указанными цветами. |


### Примечания

Этот интерфейс используется как часть [`IFillFormatEffectiveData`](/slides/python-net/ru/aspose.slides/ifillformateffectivedata) и [`ILineFillFormatEffectiveData`](/slides/python-net/ru/aspose.slides/ilinefillformateffectivedata).
