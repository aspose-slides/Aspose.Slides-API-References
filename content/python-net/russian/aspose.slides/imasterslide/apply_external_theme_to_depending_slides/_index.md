## apply_external_theme_to_depending_slides(self, fname) {#str}
Создает новый MasterSlide на основе текущего, применяя к нему внешний шаблон, и применяет созданный MasterSlide ко всем зависимым слайдам.

### Возвращаемое значение

Новый тематический MasterSlide.



```python
def apply_external_theme_to_depending_slides(self, fname):
    ...
```


| Параметр | Тип | Описание |
| :- | :- | :- |
| fname | **str** | Путь к файлу внешнего шаблона (.thmx). |

| :- | :- |
