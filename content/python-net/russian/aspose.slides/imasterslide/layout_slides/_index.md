## layout_slides свойство
Возвращает коллекцию дочерних слайдов макета для этого мастер-слайда.
            Только для чтения [`IMasterLayoutSlideCollection`](/slides/python-net/ru/aspose.slides/imasterlayoutslidecollection).

### Примечания

Вы можете получить доступ к альтернативному API для добавления/вставки/удаления/клонирования слайдов макета 
            используя свойство [`IPresentation.layout_slides`](/slides/python-net/ru/aspose.slides/ipresentation/layout_slides).
