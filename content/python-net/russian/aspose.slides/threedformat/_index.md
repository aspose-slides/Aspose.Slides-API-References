## ThreeDFormat класс

| [`extrusion_height`](/slides/python-net/ru/aspose.slides/threedformat/extrusion_height/) | Возвращает или задает высоту эффекта вытягивания.<br/>            Чтение/запись **float**. |
| [`depth`](/slides/python-net/ru/aspose.slides/threedformat/depth/) | Возвращает или задает глубину 3D формы.<br/>            Чтение/запись **float**. |

| [`bevel_bottom`](/slides/python-net/ru/aspose.slides/threedformat/bevel_bottom/) | Возвращает или задает тип нижнего 3D фаски.<br/>            Только чтение [`IShapeBevel`](/slides/python-net/ru/aspose.slides/ishapebevel). |

| [`camera`](/slides/python-net/ru/aspose.slides/threedformat/camera/) | Возвращает или задает настройки камеры.<br/>            Только чтение [`ICamera`](/slides/python-net/ru/aspose.slides/icamera). |
