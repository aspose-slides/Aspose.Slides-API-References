## remove(self, item) {#icustomxmlpart}
Удаляет первое вхождение конкретного объекта из коллекции.

### Возвращаемое значение

`true` если объект успешно удалён; иначе — `false`.



```python
def remove(self, item):
    ...
```


| Параметр | Тип | Описание |
| :- | :- | :- |
| item | [`ICustomXmlPart`](/slides/python-net/ru/aspose.slides/icustomxmlpart) | Пользовательская XML-часть для удаления. |

### Исключения

| Исключение | Описание |
| :- | :- |
| **RuntimeError(Proxy error(ArgumentNullException))** | item имеет значение `None`. |
