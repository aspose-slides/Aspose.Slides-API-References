## refresh_charts_data(self, skip_failed_charts) {#bool}
Перезагружает данные для всех диаграмм в презентации из их исходных рабочих книг.

```python
def refresh_charts_data(self, skip_failed_charts):
    ...
```


| Параметр | Тип | Описание |
| :- | :- | :- |
| skip_failed_charts | **bool** | Определяет, будет ли процесс обновления продолжаться, если обновление диаграммы завершится ошибкой.<br/><br/>Если `true`, диаграммы, вызывающие исключение, пропускаются; в противном случае исключение передаётся дальше. |
