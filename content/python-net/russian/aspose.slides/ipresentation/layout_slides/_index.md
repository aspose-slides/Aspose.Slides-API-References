## layout_slides свойство
Returns a list of all layout slides that are defined in the presentation.
            Только для чтения [`IGlobalLayoutSlideCollection`](/slides/python-net/ru/aspose.slides/igloballayoutslidecollection).


### Примечания

Вы можете получить доступ к альтернативному API для добавления/вставки/удаления/клонирования слайдов макета 
            используя свойство IMasterSlide.LayoutSlides.
