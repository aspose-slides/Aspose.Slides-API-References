## layout_slides свойство
Возвращает список всех макетных слайдов, определённых в презентации.
Только для чтения [`IGlobalLayoutSlideCollection`](/slides/python-net/ru/aspose.slides/igloballayoutslidecollection).

### Примечания

Вы можете получить доступ к альтернативному API для добавления/вставки/удаления/клонирования макетных слайдов, используя свойство IMasterSlide.LayoutSlides.

    ...
