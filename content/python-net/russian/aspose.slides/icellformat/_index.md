## ICellFormat класс

Представляет формат ячейки таблицы.

Тип ICellFormat раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`fill_format`](/slides/python-net/ru/aspose.slides/icellformat/fill_format/) | Возвращает объект свойств заливки ячейки.<br/>            Только для чтения [`IFillFormat`](/slides/python-net/ru/aspose.slides/ifillformat). |
| [`border_left`](/slides/python-net/ru/aspose.slides/icellformat/border_left/) | Возвращает объект свойств линии левой границы.<br/>            Только для чтения [`ILineFormat`](/slides/python-net/ru/aspose.slides/ilineformat). |
| [`border_top`](/slides/python-net/ru/aspose.slides/icellformat/border_top/) | Возвращает объект свойств линии верхней границы.<br/>            Только для чтения [`ILineFormat`](/slides/python-net/ru/aspose.slides/ilineformat). |
| [`border_right`](/slides/python-net/ru/aspose.slides/icellformat/border_right/) | Возвращает объект свойств линии правой границы.<br/>            Только для чтения [`ILineFormat`](/slides/python-net/ru/aspose.slides/ilineformat). |
| [`border_bottom`](/slides/python-net/ru/aspose.slides/icellformat/border_bottom/) | Возвращает объект свойств линии нижней границы.<br/>            Только для чтения [`ILineFormat`](/slides/python-net/ru/aspose.slides/ilineformat). |
| [`border_diagonal_down`](/slides/python-net/ru/aspose.slides/icellformat/border_diagonal_down/) | Возвращает объект свойств диагональной линии от верхнего левого к нижнему правому.<br/>            Только для чтения [`ILineFormat`](/slides/python-net/ru/aspose.slides/ilineformat). |
| [`border_diagonal_up`](/slides/python-net/ru/aspose.slides/icellformat/border_diagonal_up/) | Возвращает объект свойств диагональной линии от нижнего левого к верхнему правому.<br/>            Только для чтения [`ILineFormat`](/slides/python-net/ru/aspose.slides/ilineformat). |
| [`transparency`](/slides/python-net/ru/aspose.slides/icellformat/transparency/) | Получает или задает прозрачноcть цвета заливки.<br/>            Чтение/запись **float**. |
