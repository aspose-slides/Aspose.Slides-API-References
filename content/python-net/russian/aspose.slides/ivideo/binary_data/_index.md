## binary_data свойство
Возвращает копию данных аудио. В случае большого объёма данных рекомендуется использовать 
            [`IVideo.get_stream`](/slides/python-net/ru/aspose.slides/ivideo/get_stream) метод для предотвращения ненужной загрузки данных видео в память 
            или даже OutOfMemoryException.
            Только для чтения **int**[].
