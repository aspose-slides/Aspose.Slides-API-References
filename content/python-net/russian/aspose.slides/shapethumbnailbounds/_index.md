## ShapeThumbnailBounds перечисление

Перечисление типов границ эскиза фигуры.

Тип ShapeThumbnailBounds содержит следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| SLIDE | Эскиз фигуры будет иметь размер, равный размеру слайда.<br/>            Позиция фигуры будет сохранена. |
| SHAPE | Эскиз фигуры будет иметь размер, равный прямоугольнику границ фигуры<br/>            с учётом настроек контура фигуры. |
| APPEARANCE | Эскиз фигуры будет иметь размер, равный внешнему виду фигуры (в границах слайда). <br/>            Возможны случаи, когда внешний вид фигуры не помещается в границы фигуры. Например,<br/>            вращение, соединение острого угла сгибом, 3D-эффекты и т.д. |
