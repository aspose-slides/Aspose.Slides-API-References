## GroupShapeLock класс

Определяет, какие операции отключены у родительского GroupShape.

**Наследование:**[`GroupShapeLock`](/slides/python-net/ru/aspose.slides/groupshapelock) → [`BaseShapeLock`](/slides/python-net/ru/aspose.slides/baseshapelock)

Тип GroupShapeLock предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`no_locks`](/slides/python-net/ru/aspose.slides/groupshapelock/no_locks/) | Возвращает true, если все флаги блокировки отключены.<br/>            Только для чтения **bool**. |
| [`grouping_locked`](/slides/python-net/ru/aspose.slides/groupshapelock/grouping_locked/) | Определяет, запрещено ли добавлять эту форму в группу.<br/>            Чтение/запись **bool**. |
| [`ungrouping_locked`](/slides/python-net/ru/aspose.slides/groupshapelock/ungrouping_locked/) | Определяет, запрещено ли разделять эту groupshape.<br/>            Чтение/запись **bool**. |
| [`select_locked`](/slides/python-net/ru/aspose.slides/groupshapelock/select_locked/) | Определяет, запрещено ли выделять эту форму.<br/>            Чтение/запись **bool**. |
| [`rotation_locked`](/slides/python-net/ru/aspose.slides/groupshapelock/rotation_locked/) | Определяет, запрещено ли изменять угол вращения этой формы.<br/>            Чтение/запись **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/ru/aspose.slides/groupshapelock/aspect_ratio_locked/) | Определяет, должна ли форма сохранять пропорции при изменении размера.<br/>            Чтение/запись **bool**. |
| [`position_locked`](/slides/python-net/ru/aspose.slides/groupshapelock/position_locked/) | Определяет, запрещено ли перемещать эту форму.<br/>            Чтение/запись **bool**. |
| [`size_locked`](/slides/python-net/ru/aspose.slides/groupshapelock/size_locked/) | Определяет, запрещено ли изменять размер этой формы.<br/>            Чтение/запись **bool**. |
