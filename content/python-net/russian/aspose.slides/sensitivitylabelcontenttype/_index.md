## SensitivityLabelContentType перечисление

Представляет типы маркировки содержимого, которые должны применяться к документу.

Тип SensitivityLabelContentType включает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| NONE | Означает, что метка применяется по умолчанию или автоматически. |
| HEADER | Означает, что метка была применена вручную.<br/>            Используйте для любой метки чувствительности, которая была непосредственно применена пользователем. |
| FOOTER | Означает, что метка была применена вручную.<br/>            Используйте для любой метки чувствительности, которая была непосредственно применена пользователем. |
| WATERMARK | Означает, что метка была применена вручную.<br/>            Используйте для любой метки чувствительности, которая была непосредственно применена пользователем. |
| ENCRYPTION | Означает, что метка была применена вручную.<br/>            Используйте для любой метки чувствительности, которая была непосредственно применена пользователем. |
