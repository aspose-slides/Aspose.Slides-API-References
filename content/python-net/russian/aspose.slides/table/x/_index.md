## Свойство x
Получает или задает x-координату верхнего левого угла фигуры, измеренную в пунктах.
            Чтение/запись **float**.

### Замечания

Возвращаемое значение всегда определено и никогда не **float**.
            Назначаемое значение также должно быть определено; присваивайте **float** только свойствам экземпляра `RawFrame`.

### Определение:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
