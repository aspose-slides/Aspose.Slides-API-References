## z_order_position свойство
Возвращает позицию фигуры в порядке z-order.
            Shapes[0] возвращает фигуру в задней части порядка z-order,
            а Shapes[Shapes.Count - 1] возвращает фигуру в передней части порядка z-order.
            Только для чтения **int**.
