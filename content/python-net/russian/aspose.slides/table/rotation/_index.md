## rotation свойство
Возвращает или задает количество градусов, на которое указанная фигура вращается вокруг оси z. Положительное значение указывает вращение по часовой стрелке; отрицательное значение — вращение против часовой стрелки. Чтение/запись **float**.

### Примечания

Возвращаемое значение всегда определено (не является float.NaN). Присваиваемое значение должно быть определено (не float.NaN). Вы можете задавать неопределённые значения для свойств экземпляра RawFrame.
