## VideoPlayModePreset перечисление

Константы, определяющие, как воспроизводится видео.

Тип VideoPlayModePreset раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| MIXED |  |
| AUTO | Воспроизводить автоматически. |
| ON_CLICK | Воспроизводить только при щелчке по кадру видео. |
| ALL_SLIDES | Воспроизводить на всех слайдах. |
| IN_CLICK_SEQUENCE | Воспроизводить автоматически по щелчку. |
