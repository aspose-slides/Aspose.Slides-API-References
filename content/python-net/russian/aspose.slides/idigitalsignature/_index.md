## IDigitalSignature класс

Электронная подпись в подписанном файле.

Тип IDigitalSignature раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`certificate`](/slides/python-net/ru/aspose.slides/idigitalsignature/certificate/) | Объект сертификата, использованный для подписи документа.<br/>            Только для чтения **System.Security.Cryptography.X509Certificates.X509Certificate2**. |
| [`is_valid`](/slides/python-net/ru/aspose.slides/idigitalsignature/is_valid/) | Если эта цифровая подпись действительна и документ не был изменён, это значение будет истинным.<br/>            Только для чтения **bool**. |
| [`sign_time`](/slides/python-net/ru/aspose.slides/idigitalsignature/sign_time/) | Время подписи документа.<br/>            Только для чтения **System.DateTime**. |
| [`comments`](/slides/python-net/ru/aspose.slides/idigitalsignature/comments/) | Цель подписи.<br/>            Чтение/запись **str**. |
