## IPictureFillFormatEffectiveData класс

Неизменяемый объект, содержащий свойства заливки картинкой.

Тип IPPictureFillFormatEffectiveData предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`dpi`](/slides/python-net/ru/aspose.slides/ipicturefillformateffectivedata/dpi/) | Возвращает dpi, используемый для заливки изображения.<br/>            Только для чтения **int**. |
| [`picture_fill_mode`](/slides/python-net/ru/aspose.slides/ipicturefillformateffectivedata/picture_fill_mode/) | Возвращает режим заливки изображением.<br/>            Только для чтения [`PictureFillMode`](/slides/python-net/ru/aspose.slides/picturefillmode). |
| [`picture`](/slides/python-net/ru/aspose.slides/ipicturefillformateffectivedata/picture/) | Возвращает изображение.<br/>            Только для чтения [`IPictureEffectiveData`](/slides/python-net/ru/aspose.slides/ipictureeffectivedata). |
| [`crop_left`](/slides/python-net/ru/aspose.slides/ipicturefillformateffectivedata/crop_left/) | Возвращает количество процентов реальной ширины изображения, обрезанных<br/>            слева от изображения. <br/>            Только для чтения **float**. |
| [`crop_top`](/slides/python-net/ru/aspose.slides/ipicturefillformateffectivedata/crop_top/) | Возвращает количество процентов реальной высоты изображения, обрезанных<br/>            сверху изображения. <br/>            Только для чтения **float**. |
| [`crop_right`](/slides/python-net/ru/aspose.slides/ipicturefillformateffectivedata/crop_right/) | Возвращает количество процентов реальной ширины изображения, обрезанных<br/>            справа от изображения. <br/>            Только для чтения **float**. |
| [`crop_bottom`](/slides/python-net/ru/aspose.slides/ipicturefillformateffectivedata/crop_bottom/) | Возвращает количество процентов реальной высоты изображения, обрезанных<br/>            снизу изображения. <br/>            Только для чтения **float**. |

### Примечания

Этот интерфейс используется как часть [`IFillFormatEffectiveData`](/slides/python-net/ru/aspose.slides/ifillformateffectivedata).
