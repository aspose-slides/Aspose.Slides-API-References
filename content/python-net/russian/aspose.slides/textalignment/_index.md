## Перечисление TextAlignment

Представляет различные стили выравнивания текста.

Тип TextAlignment предоставляет следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| NOT_DEFINED | Выравнивание по умолчанию. |
| LEFT | Выравнивание по левому краю. |
| CENTER | Выравнивание по центру. |
| RIGHT | Выравнивание по правому краю. |
| JUSTIFY | Выравнивание по ширине. |
| JUSTIFY_LOW | Выравнивание Kashida low. |
| DISTRIBUTED | Распределённое выравнивание. |
