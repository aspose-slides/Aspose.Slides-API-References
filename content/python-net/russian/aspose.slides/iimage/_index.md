## IImage класс

Представляет растровое или векторное изображение.

Тип IImage раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`size`](/slides/python-net/ru/aspose.slides/iimage/size/) | Возвращает размер изображения. |
| [`width`](/slides/python-net/ru/aspose.slides/iimage/width/) | Возвращает ширину изображения в пикселях. |
| [`height`](/slides/python-net/ru/aspose.slides/iimage/height/) | Возвращает высоту изображения в пикселях. |

## Методы

| Метод | Описание |
| :- | :- |
| [`save(self, filename)`](/slides/python-net/ru/aspose.slides/iimage/save/#str) | Сохраняет изображение в файл. |
| [`save(self, filename, format)`](/slides/python-net/ru/aspose.slides/iimage/save/#str-imageformat) | Сохраняет изображение в файл в указанном формате. |
| [`save(self, stream, format)`](/slides/python-net/ru/aspose.slides/iimage/save/#iorawiobase-imageformat) | Сохраняет изображение в поток в указанном формате. |
| [`save(self, filename, format, quality)`](/slides/python-net/ru/aspose.slides/iimage/save/#str-imageformat-int) | Сохраняет изображение в файл в указанном формате и качестве. |
| [`save(self, stream, format, quality)`](/slides/python-net/ru/aspose.slides/iimage/save/#iorawiobase-imageformat-int) | Сохраняет изображение в поток в указанном формате и качестве. |


### Примечания

Этот интерфейс предоставляет общую абстракцию для обработки как растровых, так и векторных изображений.  
Реализации могут различаться в зависимости от базового типа изображения.
