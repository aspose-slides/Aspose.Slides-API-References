## ControlPropertiesCollection класс

Коллекция свойств AcitveX.

Тип ControlPropertiesCollection предоставляет следующие члены:

## Свойства

| Property | Description |
| :- | :- |
| [`names_of_properties`](/slides/python-net/ru/aspose.slides/controlpropertiescollection/names_of_properties/) | Возвращает коллекцию имен свойств.<br/>            Только для чтения **list**. |
| [`count`](/slides/python-net/ru/aspose.slides/controlpropertiescollection/count/) | Возвращает количество свойств в коллекции.<br/>            Только для чтения **int**. |
