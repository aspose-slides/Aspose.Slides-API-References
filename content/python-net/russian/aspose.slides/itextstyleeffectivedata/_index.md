## ITextStyleEffectiveData класс

Неизменяемый объект, содержащий эффективные свойства стиля текста.

Тип ITextStyleEffectiveData раскрывает следующие члены:

## Свойства

| Property | Description |
| :- | :- |
| [`default_paragraph_format`](/slides/python-net/ru/aspose.slides/itextstyleeffectivedata/default_paragraph_format/) | Возвращает эффективные свойства абзаца по умолчанию.<br/>            Только для чтения [`IParagraphFormatEffectiveData`](/slides/python-net/ru/aspose.slides/iparagraphformateffectivedata). |

## Методы

| Method | Description |
| :- | :- |
| [`get_level(self, index)`](/slides/python-net/ru/aspose.slides/itextstyleeffectivedata/get_level/#int) | Возвращает уровень эффективного стиля. |


### Замечания

Этот интерфейс используется совместно с интерфейсом [`ITextStyle`](/slides/python-net/ru/aspose.slides/itextstyle) для возврата эффективных значений форматирования с учётом наследования.
