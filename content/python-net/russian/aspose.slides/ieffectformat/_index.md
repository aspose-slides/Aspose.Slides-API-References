## IEffectFormat класс

Представляет свойства эффектов формы.

Тип IEffectFormat предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`is_no_effects`](/slides/python-net/ru/aspose.slides/ieffectformat/is_no_effects/) | Возвращает true, если все эффекты отключены (как только создано, объект EffectFormat по умолчанию).<br/>            Только для чтения **bool**. |
| [`blur_effect`](/slides/python-net/ru/aspose.slides/ieffectformat/blur_effect/) | Эффект размытия.<br/>            Чтение/запись [`IBlur`](/slides/python-net/ru/aspose.slides.effects/iblur). |
| [`fill_overlay_effect`](/slides/python-net/ru/aspose.slides/ieffectformat/fill_overlay_effect/) | Эффект наложения заливки.<br/>            Чтение/запись [`IFillOverlay`](/slides/python-net/ru/aspose.slides.effects/ifilloverlay). |
| [`glow_effect`](/slides/python-net/ru/aspose.slides/ieffectformat/glow_effect/) | Эффект свечения.<br/>            Чтение/запись [`IGlow`](/slides/python-net/ru/aspose.slides.effects/iglow). |
| [`inner_shadow_effect`](/slides/python-net/ru/aspose.slides/ieffectformat/inner_shadow_effect/) | Внутренняя тень.<br/>            Чтение/запись [`IInnerShadow`](/slides/python-net/ru/aspose.slides.effects/iinnershadow). |
| [`outer_shadow_effect`](/slides/python-net/ru/aspose.slides/ieffectformat/outer_shadow_effect/) | Внешняя тень.<br/>            Чтение/запись [`IOuterShadow`](/slides/python-net/ru/aspose.slides.effects/ioutershadow). |
| [`preset_shadow_effect`](/slides/python-net/ru/aspose.slides/ieffectformat/preset_shadow_effect/) | Предустановленная тень.<br/>            Чтение/запись [`IPresetShadow`](/slides/python-net/ru/aspose.slides.effects/ipresetshadow). |
| [`reflection_effect`](/slides/python-net/ru/aspose.slides/ieffectformat/reflection_effect/) | Отражение. <br/>            Чтение/запись [`IReflection`](/slides/python-net/ru/aspose.slides.effects/ireflection). |
| [`soft_edge_effect`](/slides/python-net/ru/aspose.slides/ieffectformat/soft_edge_effect/) | Мягкая кромка.<br/>            Чтение/запись [`ISoftEdge`](/slides/python-net/ru/aspose.slides.effects/isoftedge). |
