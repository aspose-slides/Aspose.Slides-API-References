## Перечисление LoadFormat

Указывает формат документа, который необходимо загрузить.

Тип LoadFormat имеет следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| AUTO | Инструктирует Aspose.Slides автоматически определять формат. |
| PPT | Презентация Microsoft PowerPoint 97-2003. |
| PPS | Слайд-шоу Microsoft PowerPoint 97-2003. |
| PPTX | Документ Microsoft Office Open XML PresentationML. |
| PPSX | Слайд-шоу Microsoft Office Open XML PresentationML. |
| ODP | Презентация OpenOffice ODF. |
| POTX | Шаблон Microsoft Office Open XML PresentationML. |
| PPTM | Документ Microsoft Office Open XML PresentationML с поддержкой макросов. |
| PPSM | Слайд-шоу Microsoft Office Open XML PresentationML с поддержкой макросов. |
| POTM | Шаблон Microsoft Office Open XML PresentationML с поддержкой макросов. |
| OTP | Шаблон презентации OpenOffice OTP. |
| PPT95 | Презентация Microsoft PowerPoint 95. |
| POT | Шаблон презентации Microsoft PowerPoint 97-2003. |
| FODP | Презентация Flat XML ODF. |
| UNKNOWN | Неизвестный формат файла |
