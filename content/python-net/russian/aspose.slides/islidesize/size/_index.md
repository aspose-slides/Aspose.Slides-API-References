## size свойство
Получает размеры слайда в пунктах.


### Примечания

Назначение нового значения сбрасывает свойство [`ISlideSize.type`](/slides/python-net/ru/aspose.slides/islidesize/type) до [`SlideSizeType.CUSTOM`](/slides/python-net/ru/aspose.slides/slidesizetype/CUSTOM)
            и устанавливает [`ISlideSize.orientation`](/slides/python-net/ru/aspose.slides/islidesize/orientation).
