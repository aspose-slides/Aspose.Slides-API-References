## ISlideSize класс

Представляет размер и ориентацию слайда.

Тип ISlideSize раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`size`](/slides/python-net/ru/aspose.slides/islidesize/size/) | Возвращает размеры слайда в пунктах. |
| [`type`](/slides/python-net/ru/aspose.slides/islidesize/type/) | Возвращает тип размера слайда. |
| [`orientation`](/slides/python-net/ru/aspose.slides/islidesize/orientation/) | Возвращает или задает ориентацию слайда. |
