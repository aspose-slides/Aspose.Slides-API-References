## PathFillModeType перечисление

Указывает, каким образом путь должен быть заполнен

The PathFillModeType type exposes the following members:

## Поля

| Поле | Описание |
| :- | :- |
| NONE | No Path Fill<br/>            Указывает, что соответствующий путь не должен иметь заполнения. |
| NORMAL | Normal Path Fill<br/>            Указывает, что к заполнению соответствующего пути должна применяться обычная затенённая заливка. |
| LIGHTEN | Lighten Path Fill<br/>            Указывает, что к заполнению соответствующего пути должна применяться слегка затенённая заливка. |
| LIGHTEN_LESS | Lighten Path Fill Less<br/>            Указывает, что к заполнению соответствующего пути должна применяться немного более светлая затенённая заливка. |
| DARKEN | Darken Path Fill<br/>            Указывает, что к заполнению соответствующего пути должна применяться более тёмная затенённая заливка. |
| DARKEN_LESS | Darken Path Fill Less<br/>            Указывает, что к заполнению соответствующего пути должна применяться слегка более тёмная затенённая заливка. |
