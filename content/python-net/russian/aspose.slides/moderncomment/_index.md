## ModernComment класс

Представляет комментарий к слайду.

**Наследование:**[`ModernComment`](/slides/python-net/ru/aspose.slides/moderncomment) → [`Comment`](/slides/python-net/ru/aspose.slides/comment)

Тип ModernComment раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`text`](/slides/python-net/ru/aspose.slides/moderncomment/text/) | Возвращает или задает обычный текст комментария к слайду.<br/>            Чтение/запись **str**. |
| [`created_time`](/slides/python-net/ru/aspose.slides/moderncomment/created_time/) | Возвращает или задает время создания комментария.<br/>            Установка этого свойства в **System.DateTime** означает, что время комментария не задано.<br/>            Чтение/запись **System.DateTime**. |
| [`slide`](/slides/python-net/ru/aspose.slides/moderncomment/slide/) | Возвращает или задает родительский слайд комментария.<br/>            Только чтение [`ISlide`](/slides/python-net/ru/aspose.slides/islide). |
| [`author`](/slides/python-net/ru/aspose.slides/moderncomment/author/) | Возвращает автора комментария.<br/>            Только чтение [`ICommentAuthor`](/slides/python-net/ru/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/ru/aspose.slides/moderncomment/position/) | Возвращает или задает позицию комментария на слайде.<br/>            Чтение/запись [`PointF`](/slides/python-net/ru/aspose.slides/pointf). |
| [`parent_comment`](/slides/python-net/ru/aspose.slides/moderncomment/parent_comment/) | Возвращает или задает родительский комментарий.<br/>            Чтение/запись [`IComment`](/slides/python-net/ru/aspose.slides/icomment). |
| [`shape`](/slides/python-net/ru/aspose.slides/moderncomment/shape/) | Возвращает форму, связанную с комментарием.<br/>            Только чтение [`IShape`](/slides/python-net/ru/aspose.slides/ishape). |
| [`text_selection_start`](/slides/python-net/ru/aspose.slides/moderncomment/text_selection_start/) | Возвращает или задает начальную позицию выделения текста в текстовом фрейме, если комментарий связан с AutoShape.<br/>            Чтение/запись **int**. |
| [`text_selection_length`](/slides/python-net/ru/aspose.slides/moderncomment/text_selection_length/) | Возвращает или задает длину выделения текста в текстовом фрейме, если комментарий связан с AutoShape.<br/>            Чтение/запись **int**. |
| [`status`](/slides/python-net/ru/aspose.slides/moderncomment/status/) | Возвращает или задает статус комментария.<br/>            Чтение/запись [`ModernCommentStatus`](/slides/python-net/ru/aspose.slides/moderncommentstatus). |
