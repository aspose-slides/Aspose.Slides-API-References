## ISvgImage класс

Представляет SVG изображение.

Тип ISvgImage раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`svg_content`](/slides/python-net/ru/aspose.slides/isvgimage/svg_content/) | Возвращает содержимое SVG.<br/>            Только для чтения **str**. |
| [`svg_data`](/slides/python-net/ru/aspose.slides/isvgimage/svg_data/) | Возвращает данные SVG.<br/>            Только для чтения **int**[]. |
| [`external_resource_resolver`](/slides/python-net/ru/aspose.slides/isvgimage/external_resource_resolver/) | Возвращает интерфейс обратного вызова, используемый для разрешения внешних ресурсов во время импорта SVG-документов.<br/>            Только для чтения **IExternalResourceResolver**. |
| [`base_uri`](/slides/python-net/ru/aspose.slides/isvgimage/base_uri/) | Возвращает базовый URI указанного SVG. Используется для разрешения относительных ссылок.<br/>            Только для чтения **str**. |
