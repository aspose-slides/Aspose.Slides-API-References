## IPictureEffectiveData класс

Неизменяемый объект, содержащий эффективные свойства изображения.

Тип IPictureEffectiveData раскрывает следующие члены:

## Свойства

| Property | Description |
| :- | :- |
| [`image`](/slides/python-net/ru/aspose.slides/ipictureeffectivedata/image/) | Возвращает встроенное изображение.<br/>            Read-only [`IPPImage`](/slides/python-net/ru/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/ru/aspose.slides/ipictureeffectivedata/link_path_long/) | Возвращает URL связанного изображения.<br/>            Read-only **str**. |
| [`image_transform`](/slides/python-net/ru/aspose.slides/ipictureeffectivedata/image_transform/) | Возвращает коллекцию эффектов трансформации изображения.<br/>            Read-only [`IImageTransformOCollectionEffectiveData`](/slides/python-net/ru/aspose.slides.effects/iimagetransformocollectioneffectivedata). |


### Примечания

Этот интерфейс используется как часть [`IPictureFillFormatEffectiveData`](/slides/python-net/ru/aspose.slides/ipicturefillformateffectivedata) и [`IBulletFormatEffectiveData`](/slides/python-net/ru/aspose.slides/ibulletformateffectivedata).
