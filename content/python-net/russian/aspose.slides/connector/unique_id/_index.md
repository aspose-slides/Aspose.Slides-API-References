## unique_id свойство
Возвращает внутренний, ограниченный презентацией идентификатор, предназначенный для использования дополнениями или другим кодом.
            Поскольку это значение может быть переопределено пользователем или программно, его нельзя рассматривать
            как постоянный уникальный ключ.
            Только для чтения **int**.
            См. также [`Shape.office_interop_shape_id`](/slides/python-net/ru/aspose.slides/shape/office_interop_shape_id).
