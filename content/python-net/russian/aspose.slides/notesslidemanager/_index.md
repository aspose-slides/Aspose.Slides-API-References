## NotesSlideManager класс

Менеджер слайдов заметок.

Тип NotesSlideManager предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`notes_slide`](/slides/python-net/ru/aspose.slides/notesslidemanager/notes_slide/) | Возвращает слайд заметок для текущего слайда. Возвращает None, если у слайда нет слайда заметок.<br/>            Только для чтения [`INotesSlide`](/slides/python-net/ru/aspose.slides/inotesslide). |

## Методы

| Метод | Описание |
| :- | :- |
| [`add_notes_slide(self)`](/slides/python-net/ru/aspose.slides/notesslidemanager/add_notes_slide/#) | Возвращает слайд заметок для текущего слайда, создавая его, если он отсутствует. |
| [`remove_notes_slide(self)`](/slides/python-net/ru/aspose.slides/notesslidemanager/remove_notes_slide/#) | Удаляет слайд заметок текущего слайда. |
