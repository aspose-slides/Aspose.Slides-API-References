## свойство three_d_format
Возвращает объект ThreeDFormat, содержащий свойства 3d-эффекта формы.
            Примечание: может возвращать None для некоторых типов фигур, у которых нет 3d-свойств.
            Только для чтения [`IThreeDFormat`](/slides/python-net/ru/aspose.slides/ithreedformat).
