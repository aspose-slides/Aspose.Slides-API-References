## Свойство frame
Возвращает или задает свойства рамки фигуры.
            Чтение/запись [`IShapeFrame`](/slides/python-net/ru/aspose.slides/ishapeframe).

### Примечания

Значение каждого свойства возвращенного экземпляра IShapeFrame не 
            неопределено (не является NaN или NotDefined).
            Значение каждого свойства назначенного экземпляра IShapeFrame должно быть не 
            неопределено (должно быть не NaN или NotDefined).
            Вы можете установить неопределенные значения для свойств экземпляра RawFrame.

### Определение:
```python
@property
def frame(self):
    ...

@frame.setter
def frame(self, value):
    ...
```
