## ICustomXmlPart класс

Представляет пользовательскую XML-часть.

Тип ICustomXmlPart раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`xml_as_string`](/slides/python-net/ru/aspose.slides/icustomxmlpart/xml_as_string/) | Возвращает или задает данные xml в виде строки UTF-8.<br/>            Чтение/запись **str**.<br/>            значение равно `None`. значение пусто или xml-данные недействительны. |
| [`xml_data`](/slides/python-net/ru/aspose.slides/icustomxmlpart/xml_data/) | Возвращает или задает данные xml.<br/>            Чтение/запись **int**[].<br/>            значение равно `None`. значение пусто или xml-данные недействительны. |
| [`item_id`](/slides/python-net/ru/aspose.slides/icustomxmlpart/item_id/) | Указывает глобальный уникальный идентификатор (GUID), который уникально идентифицирует одну пользовательскую XML <br/>            часть внутри документа Office Open XML.<br/>            Только для чтения **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/ru/aspose.slides/icustomxmlpart/namespace_schemas/) | Возвращает набор XML-схем, связанных с пользовательской XML-частью.<br/>            Только для чтения **str**[]. |

## Методы

| Метод | Описание |
| :- | :- |
| [`remove(self)`](/slides/python-net/ru/aspose.slides/icustomxmlpart/remove/#) | Удаляет пользовательскую xml-часть из презентации. |
