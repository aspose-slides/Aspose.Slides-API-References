## IColumnCollection класс

Представляет коллекцию столбцов в таблице.

Тип IColumnCollection раскрывает следующие члены:

Возвращает столбец по указанному индексу.
Только для чтения [`IColumn`](/slides/python-net/ru/aspose.slides/icolumn).
