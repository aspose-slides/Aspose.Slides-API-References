## insert_clone(self, index, templ, with_attached_columns) {#int-icolumn-bool}

### Возвращаемое значение

Вставленные столбцы.



```python
def insert_clone(self, index, templ, with_attached_columns):
    ...
```


| Параметр | Тип | Описание |
| :- | :- | :- |
| index | **int** | Индекс нового столбца. |
| templ | [`IColumn`](/slides/python-net/ru/aspose.slides/icolumn) | Столбец, используемый в качестве шаблона. |
| with_attached_columns | **bool** | True, если также копировать все столбцы, присоединённые к шаблонному столбцу. |
