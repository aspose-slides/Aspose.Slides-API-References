## AudioPlayModePreset перечисление

Константы, определяющие, как воспроизводится звук.

Тип AudioPlayModePreset предоставляет следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| MIXED |  |
| AUTO | Воспроизводить автоматически. |
| ON_CLICK | Воспроизводить только при клике по значку. |
| ALL_SLIDES | Воспроизводить на всех слайдах. <br/>            Пожалуйста, используйте свойство [`IAudioFrame.play_across_slides`](/slides/python-net/ru/aspose.slides/iaudioframe/play_across_slides) вместо этого.<br/>            Этот элемент устарел с PowerPoint 2013. |
| IN_CLICK_SEQUENCE | Воспроизводить автоматически по клику. |
