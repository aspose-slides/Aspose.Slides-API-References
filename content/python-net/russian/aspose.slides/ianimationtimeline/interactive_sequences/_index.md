## interactive_sequences свойство
Возвращает коллекцию интерактивных последовательностей.
            Эти последовательности могут содержать только эффекты при «нажатии на форму» с указанной целевой формой.
            Только для чтения [`ISequenceCollection`](/slides/python-net/ru/aspose.slides.animation/isequencecollection).
