## IAnimationTimeLine класс

Представляет временную шкалу анимации.

Тип IAnimationTimeLine раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`interactive_sequences`](/slides/python-net/ru/aspose.slides/ianimationtimeline/interactive_sequences/) | Returns collection of interactive sequences.<br/>            This sequences may contain only effects by "click on shape" with specifies target shape.<br/>            Только для чтения [`ISequenceCollection`](/slides/python-net/ru/aspose.slides.animation/isequencecollection). |
| [`main_sequence`](/slides/python-net/ru/aspose.slides/ianimationtimeline/main_sequence/) | Returns main sequence which may contain only main effects collection.<br/>            Только для чтения [`ISequence`](/slides/python-net/ru/aspose.slides.animation/isequence). |
| [`text_animation_collection`](/slides/python-net/ru/aspose.slides/ianimationtimeline/text_animation_collection/) | Returns collection of text animations.<br/>            Только для чтения [`ITextAnimationCollection`](/slides/python-net/ru/aspose.slides.animation/itextanimationcollection). |
