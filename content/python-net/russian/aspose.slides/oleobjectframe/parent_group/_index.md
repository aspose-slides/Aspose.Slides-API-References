## parent_group свойство
Возвращает родительский объект GroupShape, если shape сгруппирована. В противном случае возвращает None.
            Только для чтения [`IGroupShape`](/slides/python-net/ru/aspose.slides/igroupshape).

### Примечания

Свойство [`Shape.is_grouped`](/slides/python-net/ru/aspose.slides/shape/is_grouped) определяет, сгруппирована ли shape.
