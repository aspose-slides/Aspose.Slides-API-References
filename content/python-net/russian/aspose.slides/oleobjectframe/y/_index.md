## свойство y
Получает или задает координату y верхнего левого угла фигуры, измеренную в пунктах.
            Чтение/запись **float**.


### Примечания

Возвращаемое значение всегда определено и никогда не **float**.
            Назначаемое значение также должно быть определено; присваивайте **float** только свойствам экземпляра `RawFrame`.

### Определение:
```python
@property
def y(self):
    ...

@y.setter
def y(self, value):
    ...
```
