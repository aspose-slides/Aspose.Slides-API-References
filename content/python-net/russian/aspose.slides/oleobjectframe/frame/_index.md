## Свойство frame
Возвращает или задает свойства shape frame.
Чтение/запись [`IShapeFrame`](/slides/python-net/ru/aspose.slides/ishapeframe).

### Примечания

Значение каждого свойства возвращённого экземпляра IShapeFrame не является неопределённым (не NaN и не NotDefined).
Значение каждого свойства назначенного экземпляра IShapeFrame должно быть не неопределённым (не NaN и не NotDefined).
Вы можете задать неопределённые значения для свойств экземпляра RawFrame.

### Определение:
```python
@property
def frame(self):
    ...

@frame.setter
def frame(self, value):
    ...
```
