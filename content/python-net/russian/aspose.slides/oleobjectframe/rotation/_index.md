## rotation свойство
Возвращает или задает количество градусов, на которое указанная фигура повернута вокруг оси z. Положительное значение указывает на вращение по часовой стрелке; отрицательное значение — против часовой стрелки.
Чтение/запись **float**.

### Примечания

Возвращаемое значение всегда определено (не является float.NaN).
Заданное значение должно быть определено (не является float.NaN). Вы можете задавать неопределённые значения для свойств экземпляра RawFrame.
