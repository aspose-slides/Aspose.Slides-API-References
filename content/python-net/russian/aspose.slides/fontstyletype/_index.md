## FontStyleType перечисление

Определяет стили форматирования, которые могут применяться к тексту.

Тип FontStyleType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| REGULAR | Стандартный текст. |
| BOLD | Жирный текст. |
| ITALIC | Курсивный текст. |
| UNDERLINE | Подчеркнутый текст. |
| STRIKEOUT | Текст, перечеркнутый горизонтальной линией. |
