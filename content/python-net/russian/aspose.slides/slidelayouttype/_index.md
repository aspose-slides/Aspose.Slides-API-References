## SlideLayoutType перечисление

Представляет тип макета слайда.

Тип SlideLayoutType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| CUSTOM | Пользовательский |
| TITLE | Заголовок |
| TEXT | Текст |
| TWO_COLUMN_TEXT | Текст в двух колонках |
| TABLE | Таблица |
| TEXT_AND_CHART | Текст и диаграмма |
| CHART_AND_TEXT | Диаграмма и текст |
| DIAGRAM | Диаграмма |
| CHART | Диаграмма |
| TEXT_AND_CLIP_ART | Текст и клипарт |
| CLIP_ART_AND_TEXT | Клипарт и текст |
| TITLE_ONLY | Только заголовок |
| BLANK | Пустой |
| TEXT_AND_OBJECT | Текст и объект |
| OBJECT_AND_TEXT | Объект и текст |
| OBJECT | Объект |
| TITLE_AND_OBJECT | Заголовок и объект |
| TEXT_AND_MEDIA | Текст и медиа |
| MEDIA_AND_TEXT | Медиа и текст |
| OBJECT_OVER_TEXT | Объект над текстом |
| TEXT_OVER_OBJECT | Текст над объектом |
| TEXT_AND_TWO_OBJECTS | Текст и два объекта |
| TWO_OBJECTS_AND_TEXT | Два объекта и текст |
| TWO_OBJECTS_OVER_TEXT | Два объекта над текстом |
| FOUR_OBJECTS | Четыре объекта |
| VERTICAL_TEXT | Вертикальный текст |
| CLIP_ART_AND_VERTICAL_TEXT | Клипарт и вертикальный текст |
| VERTICAL_TITLE_AND_TEXT | Вертикальный заголовок и текст |
| VERTICAL_TITLE_AND_TEXT_OVER_CHART | Вертикальный заголовок и текст над диаграммой |
| TWO_OBJECTS | Два объекта |
| OBJECT_AND_TWO_OBJECT | Объект и два объекта |
| TWO_OBJECTS_AND_OBJECT | Два объекта и объект |
| SECTION_HEADER | Заголовок раздела |
| TWO_TEXT_AND_TWO_OBJECTS | Два текста и два объекта |
| TITLE_OBJECT_AND_CAPTION | Заголовок, объект и подпись |
| PICTURE_AND_CAPTION | Изображение и подпись |
