## HeadingPair класс

Представляет свойство 'Heading pair' документа. 
Он указывает имя группы частей документа и количество частей в группе.

Тип HeadingPair раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`name`](/slides/python-net/ru/aspose.slides/headingpair/name/) | Возвращает имя группы частей документа.<br/>Только для чтения **str**. |
| [`count`](/slides/python-net/ru/aspose.slides/headingpair/count/) | Возвращает количество частей в группе.<br/>Только для чтения **int**. |
