## SensitivityLabel класс

Представляет метку конфиденциальности из Microsoft Purview Information Protection.

Тип SensitivityLabel предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`id`](/slides/python-net/ru/aspose.slides/sensitivitylabel/id/) | Возвращает или задает идентификатор метки конфиденциальности.<br/>            Чтение/запись **str**. |
| [`site_id`](/slides/python-net/ru/aspose.slides/sensitivitylabel/site_id/) | Возвращает или задает идентификатор сайта Azure Active Directory (Azure AD) <br/>            соответствующий политике метки конфиденциальности, описывающей эту метку.<br/>            Чтение/запись **System.Guid**. |
| [`is_enabled`](/slides/python-net/ru/aspose.slides/sensitivitylabel/is_enabled/) | Указывает, включена ли метка конфиденциальности. |
| [`is_removed`](/slides/python-net/ru/aspose.slides/sensitivitylabel/is_removed/) | Указывает, была ли метка конфиденциальности удалена. |
| [`assignment_method_type`](/slides/python-net/ru/aspose.slides/sensitivitylabel/assignment_method_type/) | Возвращает или задает метод назначения метки конфиденциальности.<br/>            Чтение/запись [`SensitivityLabelAssignmentType`](/slides/python-net/ru/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/ru/aspose.slides/sensitivitylabel/content_mark_types/) | Возвращает список типов пометок содержимого, которые следует применить к файлу. |
