## SlideSizeType перечисление

Представляет предустановку размера слайда.

Тип SlideSizeType раскрывает следующие члены:

## Поля

| Field | Description |
| :- | :- |
| ON_SCREEN | На экране 4x3 |
| LETTER_PAPER | Letter |
| A4_PAPER | A4 |
| SLIDE_35MM | Слайд 35 мм |
| OVERHEAD | Overhead |
| BANNER | Banner |
| CUSTOM | Пользовательский размер |
| LEDGER | Ledger |
| A3_PAPER | A3 |
| B4_ISO_PAPER | B4 ISO |
| B5_ISO_PAPER | B5 ISO |
| B4_JIS_PAPER | B4 JIS |
| B5_JIS_PAPER | B5 JIS |
| HAGAKI_CARD | Hagaki card |
| ON_SCREEN_16X9 | На экране 16x9 |
| ON_SCREEN_16X10 | На экране 16x10 |
| WIDESCREEN | Широкоэкранный |
