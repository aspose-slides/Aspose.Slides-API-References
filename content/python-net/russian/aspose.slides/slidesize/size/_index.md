## size свойство
Получает размеры слайда в пунктах.

### Примечания

Назначение нового значения сбрасывает свойство [`SlideSize.type`](/slides/python-net/ru/aspose.slides/slidesize/type) до [`SlideSizeType.CUSTOM`](/slides/python-net/ru/aspose.slides/slidesizetype/CUSTOM)
            и устанавливает [`SlideSize.orientation`](/slides/python-net/ru/aspose.slides/slidesize/orientation).
