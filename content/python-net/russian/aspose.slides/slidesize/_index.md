## SlideSize класс

Представляет размер и ориентацию слайда.

Тип SlideSize раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`size`](/slides/python-net/ru/aspose.slides/slidesize/size/) | Получает размеры слайда в пунктах. |
| [`type`](/slides/python-net/ru/aspose.slides/slidesize/type/) | Получает тип размера слайда. |
| [`orientation`](/slides/python-net/ru/aspose.slides/slidesize/orientation/) | Получает или задает ориентацию слайда. |

## Методы

| Метод | Описание |
| :- | :- |
| [`set_size(self, type, scale_type)`](/slides/python-net/ru/aspose.slides/slidesize/set_size/#slidesizetype-slidesizescaletype) | Устанавливает размер слайда по типу и масштабирует существующее содержимое. |
| [`set_size(self, width, height, scale_type)`](/slides/python-net/ru/aspose.slides/slidesize/set_size/#float-float-slidesizescaletype) | Устанавливает размеры слайда явно и масштабирует существующее содержимое. |
