## IColorFormat класс

Представляет цвет, используемый в презентации.

Тип IColorFormat раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`color_type`](/slides/python-net/ru/aspose.slides/icolorformat/color_type/) | Возвращает или задает метод определения цвета.<br/>            Чтение/запись [`ColorType`](/slides/python-net/ru/aspose.slides/colortype). |
| [`color`](/slides/python-net/ru/aspose.slides/icolorformat/color/) | Возвращает результирующий цвет (с учётом всех применённых цветовых преобразований).<br/>            Устанавливает RGB-цвета и сбрасывает все цветовые преобразования.<br/>            Чтение/запись **aspose.slides.Color**. |
| [`preset_color`](/slides/python-net/ru/aspose.slides/icolorformat/preset_color/) | Возвращает или задает предустановку цвета.<br/>            Чтение/запись [`PresetColor`](/slides/python-net/ru/aspose.slides/presetcolor). |
| [`system_color`](/slides/python-net/ru/aspose.slides/icolorformat/system_color/) | Возвращает или задает цвет, определённый системной таблицей цветов.<br/>            Чтение/запись [`SystemColor`](/slides/python-net/ru/aspose.slides/systemcolor). |
| [`scheme_color`](/slides/python-net/ru/aspose.slides/icolorformat/scheme_color/) | Возвращает или задает цвет, определённый цветовой схемой.<br/>            Чтение/запись [`SchemeColor`](/slides/python-net/ru/aspose.slides/schemecolor). |
| [`r`](/slides/python-net/ru/aspose.slides/icolorformat/r/) | Возвращает или задает красный компонент цвета. Все цветовые преобразования игнорируются.<br/>            Чтение/запись **int**. |
| [`g`](/slides/python-net/ru/aspose.slides/icolorformat/g/) | Возвращает или задает зелёный компонент цвета. Все цветовые преобразования игнорируются.<br/>            Чтение/запись **int**. |
| [`b`](/slides/python-net/ru/aspose.slides/icolorformat/b/) | Возвращает или задает синий компонент цвета. Все цветовые преобразования игнорируются.<br/>            Чтение/запись **int**. |
| [`float_r`](/slides/python-net/ru/aspose.slides/icolorformat/float_r/) | Возвращает или задает красный компонент цвета. Все цветовые преобразования игнорируются.<br/>            Чтение/запись **float**. |
| [`float_g`](/slides/python-net/ru/aspose.slides/icolorformat/float_g/) | Возвращает или задает зелёный компонент цвета. Все цветовые преобразования игнорируются.<br/>            Чтение/запись **float**. |
| [`float_b`](/slides/python-net/ru/aspose.slides/icolorformat/float_b/) | Возвращает или задает синий компонент цвета. Все цветовые преобразования игнорируются.<br/>            Чтение/запись **float**. |
| [`hue`](/slides/python-net/ru/aspose.slides/icolorformat/hue/) | Возвращает или задает компонент оттенка цвета в представлении HSL. Все цветовые преобразования игнорируются.<br/>            Чтение/запись **float**. |
| [`saturation`](/slides/python-net/ru/aspose.slides/icolorformat/saturation/) | Возвращает или задает компонент насыщенности цвета в представлении HSL. Все цветовые преобразования игнорируются.<br/>            Чтение/запись **float**. |
| [`luminance`](/slides/python-net/ru/aspose.slides/icolorformat/luminance/) | Возвращает или задает компонент яркости цвета в представлении HSL. Все цветовые преобразования игнорируются.<br/>            Чтение/запись **float**. |
| [`color_transform`](/slides/python-net/ru/aspose.slides/icolorformat/color_transform/) | Возвращает коллекцию цветовых преобразований, применённых к цвету.<br/>            Только для чтения [`IColorOperationCollection`](/slides/python-net/ru/aspose.slides/icoloroperationcollection). |
