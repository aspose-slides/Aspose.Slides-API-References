## GradientFormat класс

Представляет формат градиента.

**Наследование:**[`GradientFormat`](/slides/python-net/ru/aspose.slides/gradientformat) → [`PVIObject`](/slides/python-net/ru/aspose.slides/pviobject)

Тип GradientFormat предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`tile_flip`](/slides/python-net/ru/aspose.slides/gradientformat/tile_flip/) | Возвращает или задает режим отражения для градиента.<br/>            Чтение/запись [`TileFlip`](/slides/python-net/ru/aspose.slides/tileflip). |
| [`gradient_direction`](/slides/python-net/ru/aspose.slides/gradientformat/gradient_direction/) | Возвращает или задает стиль градиента.<br/>            Чтение/запись [`GradientDirection`](/slides/python-net/ru/aspose.slides/gradientdirection). |
| [`linear_gradient_angle`](/slides/python-net/ru/aspose.slides/gradientformat/linear_gradient_angle/) | Возвращает или задает угол градиента.<br/>            Чтение/запись **float**. |
| [`linear_gradient_scaled`](/slides/python-net/ru/aspose.slides/gradientformat/linear_gradient_scaled/) | Определяет, масштабируется ли градиент.<br/>            Чтение/запись [`NullableBool`](/slides/python-net/ru/aspose.slides/nullablebool). |
| [`gradient_shape`](/slides/python-net/ru/aspose.slides/gradientformat/gradient_shape/) | Возвращает или задает форму градиента.<br/>            Чтение/запись [`GradientShape`](/slides/python-net/ru/aspose.slides/gradientshape). |
