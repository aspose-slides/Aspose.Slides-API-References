Представляет собой коллекцию регулируемых направляющих рисования.

Тип IDrawingGuidesCollection раскрывает следующие члены:

## Свойства

| :- | :- |
| [`count`](/slides/python-net/ru/aspose.slides/idrawingguidescollection/count/) | Получает количество всех элементов в коллекции.<br/>            Только для чтения **int**. |
