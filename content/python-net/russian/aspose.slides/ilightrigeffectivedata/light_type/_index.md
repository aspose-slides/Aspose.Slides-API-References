## light_type свойство
Представляет предустановленный свет, который может быть применён к фигуре. 
            Набор освещения представляет собой группу светильников, ориентированных определённым образом относительно 3D-сцены.
            Только для чтения [`LightRigPresetType`](/slides/python-net/ru/aspose.slides/lightrigpresettype).
