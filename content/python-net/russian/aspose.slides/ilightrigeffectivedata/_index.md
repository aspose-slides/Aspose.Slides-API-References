## ILightRigEffectiveData класс

Неизменяемый объект, содержащий эффективные свойства световой установки.

Тип ILightRigEffectiveData раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`direction`](/slides/python-net/ru/aspose.slides/ilightrigeffectivedata/direction/) | Направление света.<br/>            Только для чтения [`LightingDirection`](/slides/python-net/ru/aspose.slides/lightingdirection). |
| [`light_type`](/slides/python-net/ru/aspose.slides/ilightrigeffectivedata/light_type/) | Представляет предустановленный свет, который может быть применён к фигуре.<br/>            Световая установка представляет группу светильников, ориентированных определённым образом относительно 3D-сцены.<br/>            Только для чтения [`LightRigPresetType`](/slides/python-net/ru/aspose.slides/lightrigpresettype). |

## Методы

| Метод | Описание |
| :- | :- |
| [`get_rotation(self)`](/slides/python-net/ru/aspose.slides/ilightrigeffectivedata/get_rotation/#) | Поворот определяется с помощью координаты широты, координаты долготы и революции вокруг оси, заданных широтой и долготой.<br/>            Первый элемент возвращаемого массива — широта, второй — долгота, третий — революция. |

### Примечания

Этот интерфейс используется как часть [`IThreeDFormatEffectiveData`](/slides/python-net/ru/aspose.slides/ithreedformateffectivedata).
