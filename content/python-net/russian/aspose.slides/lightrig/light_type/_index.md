## light_type свойство
Представляет предустановленное освещение, которое может быть применено к фигуре. 
Набор освещения представляет собой группу светильников, ориентированных определённым образом относительно 3D-сцены.
Чтение/запись [`LightRigPresetType`](/slides/python-net/ru/aspose.slides/lightrigpresettype).
