## insert_clone(self, index, templ, with_attached_columns) {#int-icolumn-bool}
Создает копию указанного шаблонного столбца и вставляет её в указанную позицию в таблице.

### Возвращаемое значение

Вставленные столбцы.



```python
def insert_clone(self, index, templ, with_attached_columns):
    ...
```


| Параметр | Тип | Описание |
| :- | :- | :- |
| index | **int** | Индекс нового столбца. |
| templ | [`IColumn`](/slides/python-net/ru/aspose.slides/icolumn) | Столбец, используемый в качестве шаблона. |
| with_attached_columns | **bool** | True, чтобы также скопировать все столбцы, прикрепленные к шаблонному столбцу. |
