## ColumnCollection класс

Представляет коллекцию столбцов в таблице.

Тип ColumnCollection раскрывает следующие члены:

Возвращает столбец по указанному индексу.
            Только для чтения [`Column`](/slides/python-net/ru/aspose.slides/column).
