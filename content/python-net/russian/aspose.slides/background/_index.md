## Background класс

Представляет фон слайда.

**Наследование:**[`Background`](/slides/python-net/ru/aspose.slides/background) → [`PVIObject`](/slides/python-net/ru/aspose.slides/pviobject)

Тип Background предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`type`](/slides/python-net/ru/aspose.slides/background/type/) | Возвращает тип заливки фона.<br/>            Чтение/запись [`BackgroundType`](/slides/python-net/ru/aspose.slides/backgroundtype). |
| [`fill_format`](/slides/python-net/ru/aspose.slides/background/fill_format/) | Возвращает FillFormat для заливки BackgroundType.OwnBackground.<br/>            Только чтение [`IFillFormat`](/slides/python-net/ru/aspose.slides/ifillformat). |
| [`effect_format`](/slides/python-net/ru/aspose.slides/background/effect_format/) | Возвращает EffectFormat для заливки BackgroundType.OwnBackground.<br/>            Только чтение [`IEffectFormat`](/slides/python-net/ru/aspose.slides/ieffectformat). |
| [`style_color`](/slides/python-net/ru/aspose.slides/background/style_color/) | Возвращает ColorFormat для заливки BackgroundType.Themed.<br/>            Только чтение [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`style_index`](/slides/python-net/ru/aspose.slides/background/style_index/) | Возвращает индекс заливки BackgroundType.Themed в коллекции тем фона.<br/>            0 означает отсутствие заливки.<br/>            1..999 — индекс.<br/>            Чтение/запись **int**. |
| [`slide`](/slides/python-net/ru/aspose.slides/background/slide/) | Возвращает родительский слайд фигуры.<br/>            Только чтение [`IBaseSlide`](/slides/python-net/ru/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/ru/aspose.slides/background/presentation/) | Возвращает родительскую презентацию слайда.<br/>            Только чтение [`IPresentation`](/slides/python-net/ru/aspose.slides/ipresentation). |
