## get_custom_property_name(self, index) {#int}
Возвращает имя пользовательского свойства по указанному индексу.

### Возвращаемое значение

Имя пользовательского свойства по указанному индексу.



```python
def get_custom_property_name(self, index):
    ...
```


| Параметр | Тип | Описание |
| :- | :- | :- |
| index | **int** | Нулевой (нумерация с нуля) индекс пользовательского свойства, которое необходимо получить. |

### Исключения

| Исключение | Описание |
| :- | :- |
| **RuntimeError(Proxy error(ArgumentOutOfRangeException))** | Индекс меньше нуля. Индекс равен или превышает значение Count. |
