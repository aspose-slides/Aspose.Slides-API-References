## check_password(self, password) {#str}
Проверяет, является ли пароль правильным для презентации, защищённой открытым паролем.

### Возвращаемое значение

True, если презентация защищена открытым паролем и пароль правильный, и false в противном случае.



```python
def check_password(self, password):
    ...
```


| Параметр | Тип | Описание |
| :- | :- | :- |
| password | **str** | Пароль для проверки. |

### Примечания

Когда пароль равен None или пустой, этот метод возвращает false.
