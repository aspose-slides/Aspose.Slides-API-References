## is_write_protected свойство
Получает значение, указывающее, защищена ли связанная презентация от записи.


### Примечания

Если презентация защищена паролем для открытия, значение свойства равно NotDefined.
            См. [`NullableBool`](/slides/python-net/ru/aspose.slides/nullablebool) перечисление.
