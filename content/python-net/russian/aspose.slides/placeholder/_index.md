## Класс Placeholder

Представляет заполнитель на слайде.

Тип Placeholder раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`orientation`](/slides/python-net/ru/aspose.slides/placeholder/orientation/) | Получает или задает ориентацию заполнителя.<br/>            Только чтение [`Orientation`](/slides/python-net/ru/aspose.slides/orientation). |
