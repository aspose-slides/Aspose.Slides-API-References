## CommentAuthor класс

Представляет автора комментариев.

Тип CommentAuthor раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`name`](/slides/python-net/ru/aspose.slides/commentauthor/name/) | Возвращает или задаёт имя автора.<br/>            Чтение/запись **str**. |
| [`initials`](/slides/python-net/ru/aspose.slides/commentauthor/initials/) | Возвращает или задаёт инициалы автора.<br/>            Чтение/запись **str**. |
| [`comments`](/slides/python-net/ru/aspose.slides/commentauthor/comments/) | Возвращает коллекцию комментариев, сделанных этим автором.<br/>            Только для чтения [`ICommentCollection`](/slides/python-net/ru/aspose.slides/icommentcollection). |

## Методы

| Метод | Описание |
| :- | :- |
| [`remove(self)`](/slides/python-net/ru/aspose.slides/commentauthor/remove/#) | Удаляет автора из родительской коллекции. |
