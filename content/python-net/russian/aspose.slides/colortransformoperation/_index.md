## ColorTransformOperation перечисление

Определяет операцию преобразования цвета.

Тип ColorTransformOperation содержит следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| TINT | Накладывает оттенок на цвет. Параметр находится в диапазоне от 0 (исходный цвет) до 1 (белый). |
| SHADE | Затемняет цвет. Параметр находится в диапазоне от 0 (исходный цвет) до 1 (чёрный). |
| COMPLEMENT | Преобразует цвет в комплементарный RGB.<br/>            m = Max(r, g, b);<br/>            r = m - r;<br/>            g = m - g;<br/>            b = m - b; |
| INVERSE | Преобразует цвет в инвертированный.<br/>            r = 1 - r;<br/>            g = 1 - g;<br/>            b = 1 - b; |
| GRAYSCALE | Преобразует цвет в оттенок серого с той же яркостью. Параметр игнорируется. |
| SET_ALPHA | Определяет альфа-компонент цвета. Параметр в диапазоне от 0 (прозрачный) до 1 (непрозрачный). |
| ADD_ALPHA | Добавляет значение параметра к альфа-компоненту цвета. Параметр в диапазоне от -1 до 1. |
| MULTIPLY_ALPHA | Умножает альфа-компонент на значение параметра. |
| SET_HUE | Изменяет компонент оттенка (hue) цвета на значение параметра. Параметр в диапазоне от 0 до 360. |
| ADD_HUE | Добавляет значение параметра к компоненту оттенка цвета. Параметр в диапазоне от -360 до 360. |
| MULTIPLY_HUE | Умножает компонент оттенка на значение параметра. |
| SET_SATURATION | Изменяет компонент насыщенности цвета на значение параметра. Параметр в диапазоне от 0 до 1. |
| ADD_SATURATION | Добавляет значение параметра к компоненту насыщенности цвета. Параметр в диапазоне от -1 до 1. |
| MULTIPLY_SATURATION | Умножает компонент насыщенности на значение параметра. |
| SET_LUMINANCE | Изменяет компонент светлоты цвета на значение параметра. Параметр в диапазоне от 0 до 1. |
| ADD_LUMINANCE | Добавляет значение параметра к компоненту светлоты цвета. Параметр в диапазоне от -1 до 1. |
| MULTIPLY_LUMINANCE | Умножает компонент светлоты на значение параметра. |
| SET_RED | Изменяет красный компонент цвета на значение параметра. Параметр в диапазоне от 0 до 1. |
| ADD_RED | Добавляет значение параметра к красному компоненту цвета. Параметр в диапазоне от -1 до 1. |
| MULTIPLY_RED | Умножает красный компонент на параметр. |
| SET_GREEN | Изменяет зелёный компонент цвета на значение параметра. Параметр в диапазоне от 0 до 1. |
| ADD_GREEN | Добавляет параметр к зелёному компоненту цвета. Параметр в диапазоне от -1 до 1. |
| MULTIPLY_GREEN | Умножает зелёный компонент цвета на значение параметра. |
| SET_BLUE | Изменяет синий компонент цвета на значение параметра. Параметр в диапазоне от 0 до 360. |
| ADD_BLUE | Добавляет значение параметра к синему компоненту цвета. Параметр в диапазоне от -1 до 1. |
| MULTIPLY_BLUE | Умножает синий компонент на значение параметра. |
| GAMMA | Гамма-коррекция. Параметр игнорируется. |
| INVERSE_GAMMA | Обратная гамма-коррекция. Параметр игнорируется. |
