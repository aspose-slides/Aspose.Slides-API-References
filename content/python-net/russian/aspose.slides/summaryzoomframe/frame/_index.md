## свойство кадра
Возвращает или задает свойства кадра фигуры.
Чтение/запись [`IShapeFrame`](/slides/python-net/ru/aspose.slides/ishapeframe).

### Примечания

Значение каждого свойства возвращённого экземпляра IShapeFrame не является undefined (не NaN и не NotDefined).
Значение каждого свойства назначенного экземпляра IShapeFrame должно быть не undefined (не должно быть NaN или NotDefined).
Вы можете установить значения undefined для свойств экземпляра RawFrame.

    ...
