## link_path_relative свойство
Возвращает относительный путь к связанному файлу, если он присутствует, в противном случае возвращает пустую строку.
Только для чтения **str**.

### Примечания

В презентациях Ppt некоторые ссылки на объекты Ole могут иметь относительное представление.
