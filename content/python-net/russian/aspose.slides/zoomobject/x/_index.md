## x свойство
Получает или задает координату x верхнего левого угла формы, измеренную в пунктах.
            Чтение/запись **float**.


### Замечания

Возвращаемое значение всегда определено и никогда не **float**.
            Значение, которое присваивается, также должно быть определено; присваивайте **float** только свойствам экземпляра `RawFrame`.

### Определение:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
