## height свойство
Получает или задает height формы, измеренный в точках.
            Чтение/запись **float**.


### Замечания

Возвращаемое значение всегда определено и никогда не **float**.
            Назначаемое значение также должно быть определено; присваивайте **float** только свойствам экземпляра `RawFrame`.


### Определение:
```python
@property
def height(self):
    ...

@height.setter
def height(self, value):
    ...
```
