## Свойство frame
Возвращает или задает свойства рамки формы.
            Чтение/запись [`IShapeFrame`](/slides/python-net/ru/aspose.slides/ishapeframe).


### Примечания

Значение каждого свойства возвращенного экземпляра IShapeFrame не является 
            undefined (не NaN и не NotDefined).
Значение каждого свойства назначенного экземпляра IShapeFrame должно быть 
            не undefined (должно быть не NaN и не NotDefined).
Вы можете задавать значения undefined для свойств экземпляра RawFrame.

### Определение:
```python
@property
def frame(self):
    ...

@frame.setter
def frame(self, value):
    ...
```
