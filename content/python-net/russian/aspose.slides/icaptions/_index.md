## ICaptions класс

Представляет закрытые субтитры WebVTT.

Тип ICaptions предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`caption_id`](/slides/python-net/ru/aspose.slides/icaptions/caption_id/) | Возвращает глобально уникальный идентификатор (GUID) закрытых субтитров.<br/>            Только для чтения **System.Guid**. |
| [`label`](/slides/python-net/ru/aspose.slides/icaptions/label/) | Возвращает или задает метку закрытых субтитров.<br/>            Чтение/запись **str**. |
| [`binary_data`](/slides/python-net/ru/aspose.slides/icaptions/binary_data/) | Возвращает бинарные данные закрытых субтитров.<br/>            Только для чтения **int**[]. |
| [`data_as_string`](/slides/python-net/ru/aspose.slides/icaptions/data_as_string/) | Возвращает данные закрытых субтитров в виде строки, закодированной в UTF-8<br/>            Только для чтения **str**. |
