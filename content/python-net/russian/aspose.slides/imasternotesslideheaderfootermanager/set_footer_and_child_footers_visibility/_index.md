## set_footer_and_child_footers_visibility(self, is_visible) {#bool}
Изменяет видимость заполнителя нижнего колонтитула слайда мастер-примечаний и всех дочерних заполнителей нижнего колонтитула.
Дочерние заполнители означают заполнители, содержащиеся в зависимых слайдах примечаний.
Зависимые слайды примечаний используют и зависят от слайда мастер-примечаний.

```python
def set_footer_and_child_footers_visibility(self, is_visible):
    ...
```

| Параметр | Тип | Описание |
| :- | :- | :- |
| is_visible | **bool** | true - делает заполнители нижнего колонтитула видимыми, иначе скрывает их. |
