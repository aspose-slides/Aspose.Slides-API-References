## set_date_time_and_child_date_times_visibility(self, is_visible) {#bool}
Изменяет видимость заполнителя даты и времени на слайде главных заметок и всех дочерних заполнителей даты и времени.
            Дочерние заполнители означают, что заполнители находятся на зависимых слайдах заметок.
            Зависимые слайды заметок используют и зависят от слайда главных заметок.

```python
def set_date_time_and_child_date_times_visibility(self, is_visible):
    ...
```

| Параметр | Тип | Описание |
| :- | :- | :- |
| is_visible | **bool** | true - делает заполнители даты и времени видимыми, иначе - скрывает их. |
