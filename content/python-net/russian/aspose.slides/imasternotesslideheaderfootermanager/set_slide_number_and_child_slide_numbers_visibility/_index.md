## set_slide_number_and_child_slide_numbers_visibility(self, is_visible) {#bool}
Изменяет видимость заполнителя номера страницы мастера заметок и всех дочерних заполнителей номеров страниц.
Дочерние заполнители означают, что заполнители находятся на зависимых слайдах заметок.
Зависимые слайды заметок используют и зависят от мастера слайда заметок.


```python
def set_slide_number_and_child_slide_numbers_visibility(self, is_visible):
    ...
```


| Параметр | Тип | Описание |
| :- | :- | :- |
| is_visible | **bool** | true — делает заполнители номера страницы видимыми, иначе — скрывает их. |
