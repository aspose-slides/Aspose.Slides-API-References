## ZoomImageType перечисление

Определяет, использует ли объект Zoom предварительный просмотр слайда или изображение обложки.

Тип ZoomImageType предоставляет следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| PREVIEW | Использовать изображение слайда или секции. |
| COVER | Использовать пользовательское изображение. |
