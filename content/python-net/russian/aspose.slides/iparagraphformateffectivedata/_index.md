## IParagraphFormatEffectiveData класс

Неизменяемый объект, содержащий эффективные свойства форматирования абзаца.

Тип IParagraphFormatEffectiveData предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`bullet`](/slides/python-net/ru/aspose.slides/iparagraphformateffectivedata/bullet/) | Возвращает формат маркера абзаца.<br/>            Только чтение [`IBulletFormatEffectiveData`](/slides/python-net/ru/aspose.slides/ibulletformateffectivedata). |
| [`depth`](/slides/python-net/ru/aspose.slides/iparagraphformateffectivedata/depth/) | Возвращает глубину абзаца.<br/>            Только чтение **int**. |
| [`alignment`](/slides/python-net/ru/aspose.slides/iparagraphformateffectivedata/alignment/) | Возвращает выравнивание текста в абзаце.<br/>            Только чтение [`TextAlignment`](/slides/python-net/ru/aspose.slides/textalignment). |
| [`space_within`](/slides/python-net/ru/aspose.slides/iparagraphformateffectivedata/space_within/) | Возвращает величину пробела между базовыми строками в абзаце.<br/>            Только чтение **float**. |
| [`space_before`](/slides/python-net/ru/aspose.slides/iparagraphformateffectivedata/space_before/) | Возвращает величину пробела перед первой строкой в абзаце.<br/>            Только чтение **float**. |
| [`space_after`](/slides/python-net/ru/aspose.slides/iparagraphformateffectivedata/space_after/) | Возвращает величину пробела после последней строки в абзаце.<br/>            Только чтение **float**. |
| [`east_asian_line_break`](/slides/python-net/ru/aspose.slides/iparagraphformateffectivedata/east_asian_line_break/) | Определяет, используется ли восточноазиатский разрыв строки в абзаце.<br/>            Только чтение **bool**. |
| [`right_to_left`](/slides/python-net/ru/aspose.slides/iparagraphformateffectivedata/right_to_left/) | Определяет, используется ли направление письма справа налево в абзаце.<br/>            Только чтение **bool**. |
| [`latin_line_break`](/slides/python-net/ru/aspose.slides/iparagraphformateffectivedata/latin_line_break/) | Определяет, используется ли латинский разрыв строки в абзаце.<br/>            Только чтение **bool**. |
| [`hanging_punctuation`](/slides/python-net/ru/aspose.slides/iparagraphformateffectivedata/hanging_punctuation/) | Определяет, используется ли висячая пунктуация в абзаце.<br/>            Только чтение **bool**. |
| [`margin_left`](/slides/python-net/ru/aspose.slides/iparagraphformateffectivedata/margin_left/) | Возвращает левый отступ в абзаце.<br/>            Только чтение **float**. |
| [`margin_right`](/slides/python-net/ru/aspose.slides/iparagraphformateffectivedata/margin_right/) | Возвращает правый отступ в абзаце.<br/>            Только чтение **float**. |
| [`indent`](/slides/python-net/ru/aspose.slides/iparagraphformateffectivedata/indent/) | Возвращает первый отступ строки/висячий отступ абзаца. Висячий отступ может быть задан отрицательными значениями.<br/>            Только чтение **float**. |
| [`default_tab_size`](/slides/python-net/ru/aspose.slides/iparagraphformateffectivedata/default_tab_size/) | Возвращает размер табуляции по умолчанию.<br/>            Только чтение **float**. |
| [`tabs`](/slides/python-net/ru/aspose.slides/iparagraphformateffectivedata/tabs/) | Возвращает табуляции абзаца.<br/>            Только чтение [`ITabEffectiveData`](/slides/python-net/ru/aspose.slides/itabeffectivedata)[]. |
| [`font_alignment`](/slides/python-net/ru/aspose.slides/iparagraphformateffectivedata/font_alignment/) | Возвращает выравнивание шрифта в абзаце.<br/>            Только чтение [`FontAlignment`](/slides/python-net/ru/aspose.slides/fontalignment). |
| [`default_portion_format`](/slides/python-net/ru/aspose.slides/iparagraphformateffectivedata/default_portion_format/) | Возвращает формат части по умолчанию абзаца.<br/>            Только чтение [`IPortionFormatEffectiveData`](/slides/python-net/ru/aspose.slides/iportionformateffectivedata). |

### Примечания

Этот интерфейс используется совместно с интерфейсом [`IParagraphFormat`](/slides/python-net/ru/aspose.slides/iparagraphformat) для возврата эффективных значений форматирования с применением наследования.
