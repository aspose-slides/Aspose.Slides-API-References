## AdjustValue класс

Представляет значение коррекции геометрической формы.  
Эти значения влияют на форму фигуры.

Тип AdjustValue открывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`raw_value`](/slides/python-net/ru/aspose.slides/adjustvalue/raw_value/) | Возвращает или задает значение коррекции «как есть».<br/>            Чтение/запись **int**. |
| [`angle_value`](/slides/python-net/ru/aspose.slides/adjustvalue/angle_value/) | Возвращает или задает значение, интерпретируя его как угол в градусах.<br/>            Чтение/запись **float**. |
| [`name`](/slides/python-net/ru/aspose.slides/adjustvalue/name/) | Возвращает имя этого значения коррекции.<br/>            Только для чтения **str**. |
| [`type`](/slides/python-net/ru/aspose.slides/adjustvalue/type/) | Возвращает тип коррекции формы.<br/>            Только для чтения [`ShapeAdjustmentType`](/slides/python-net/ru/aspose.slides/shapeadjustmenttype). |
