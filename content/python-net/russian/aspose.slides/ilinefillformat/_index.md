## ILineFillFormat класс

Представляет свойства для заполнения линий.

Тип ILineFillFormat открывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`fill_type`](/slides/python-net/ru/aspose.slides/ilinefillformat/fill_type/) | Возвращает или задаёт тип заливки.<br/>            Чтение/запись [`FillType`](/slides/python-net/ru/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/ru/aspose.slides/ilinefillformat/solid_fill_color/) | Возвращает цвет сплошной заливки.<br/>            Только для чтения [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`gradient_format`](/slides/python-net/ru/aspose.slides/ilinefillformat/gradient_format/) | Возвращает формат градиентной заливки.<br/>            Только для чтения [`IGradientFormat`](/slides/python-net/ru/aspose.slides/igradientformat). |
| [`pattern_format`](/slides/python-net/ru/aspose.slides/ilinefillformat/pattern_format/) | Возвращает формат узорной заливки.<br/>            Только для чтения [`IPatternFormat`](/slides/python-net/ru/aspose.slides/ipatternformat). |
| [`rotate_with_shape`](/slides/python-net/ru/aspose.slides/ilinefillformat/rotate_with_shape/) | Определяет, должна ли заливка вращаться вместе с фигурой.<br/>            Чтение/запись [`NullableBool`](/slides/python-net/ru/aspose.slides/nullablebool). |
