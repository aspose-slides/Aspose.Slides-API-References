## Класс Point

Представляет упорядоченную пару целочисленных координат x и y, определяющую точку в двумерной плоскости. Совместим с .NET `System.Drawing.Point`.

Тип Point предоставляет следующие члены:

## Конструкторы

| Конструктор | Описание |
| :- | :- |
| [`__init__(self, x=0, y=0)`](/slides/python-net/ru/aspose.slides/point/__init__/#int-int) | Создаёт точку с указанными координатами. Значения с плавающей запятой усекаются до целых. |

## Свойства

| Свойство | Описание |
| :- | :- |
| [`x`](/slides/python-net/ru/aspose.slides/point/x/) | Возвращает или задаёт координату x этой точки.<br/>            Чтение/запись **int**. |
| [`y`](/slides/python-net/ru/aspose.slides/point/y/) | Возвращает или задаёт координату y этой точки.<br/>            Чтение/запись **int**. |


### Примечания

Точки сравниваются по их координатам с помощью `==` и могут использоваться в качестве ключей словарей или элементов множеств.
