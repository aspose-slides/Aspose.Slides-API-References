## __init__(self, x=0, y=0) {#int-int}
Создает точку с указанными координатами. Значения с плавающей запятой отбрасываются до целых.


```python
def __init__(self, x=0, y=0):
    ...
```


| Параметр | Тип | Описание |
| :- | :- | :- |
| x | **int** | Горизонтальная позиция точки. |
| y | **int** | Вертикальная позиция точки. |

### Исключения

| Исключение | Описание |
| :- | :- |
| **TypeError** | Координата не является числом. |
