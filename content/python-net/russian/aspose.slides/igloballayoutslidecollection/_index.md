## IGlobalLayoutSlideCollection класс

Представляет собой коллекцию всех слайдов макета в презентации.  
Расширяет интерфейс ILayoutSlideCollection методами для добавления/клонирования слайдов макета в контексте объединения отдельных коллекций слайдов макета мастера.
