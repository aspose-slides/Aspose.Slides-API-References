## ILineFormat класс

Представляет формат линии.

Тип ILineFormat раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`is_format_not_defined`](/slides/python-net/ru/aspose.slides/ilineformat/is_format_not_defined/) | Возвращает true, если формат линии не определён (только что создан, по умолчанию).<br/>            Только для чтения **bool**. |
| [`fill_format`](/slides/python-net/ru/aspose.slides/ilineformat/fill_format/) | Возвращает формат заливки линии.<br/>            Только для чтения [`ILineFillFormat`](/slides/python-net/ru/aspose.slides/ilinefillformat). |

| [`alignment`](/slides/python-net/ru/aspose.slides/ilineformat/alignment/) | Возвращает или задаёт выравнивание линии.<br/>            Чтение/запись [`LineAlignment`](/slides/python-net/ru/aspose.slides/linealignment). |

| [`begin_arrowhead_style`](/slides/python-net/ru/aspose.slides/ilineformat/begin_arrowhead_style/) | Возвращает или задаёт стиль стрелки в начале линии.<br/>            Чтение/запись [`LineArrowheadStyle`](/slides/python-net/ru/aspose.slides/linearrowheadstyle). |
| [`end_arrowhead_style`](/slides/python-net/ru/aspose.slides/ilineformat/end_arrowhead_style/) | Возвращает или задаёт стиль стрелки в конце линии.<br/>            Чтение/запись [`LineArrowheadStyle`](/slides/python-net/ru/aspose.slides/linearrowheadstyle). |
| [`begin_arrowhead_width`](/slides/python-net/ru/aspose.slides/ilineformat/begin_arrowhead_width/) | Возвращает или задаёт ширину стрелки в начале линии.<br/>            Чтение/запись [`LineArrowheadWidth`](/slides/python-net/ru/aspose.slides/linearrowheadwidth). |
