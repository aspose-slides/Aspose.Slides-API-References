## ColorSchemeIndex перечисление

Представляет индекс в цветовой схеме.

Тип ColorSchemeIndex содержит следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| DARK1 | Темный 1. |
| LIGHT1 | Светлый 1. |
| DARK2 | Темный 2. |
| LIGHT2 | Светлый 2. |
| ACCENT1 | Акцент 1. |
| ACCENT2 | Акцент 2. |
| ACCENT3 | Акцент 3. |
| ACCENT4 | Акцент 4. |
| ACCENT5 | Акцент 5. |
| ACCENT6 | Акцент 6. |
| HYPERLINK | Гиперссылка. |
| FOLLOWED_HYPERLINK | Последующая гиперссылка. |
