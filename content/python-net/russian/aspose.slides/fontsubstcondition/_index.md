## FontSubstCondition перечисление

Представляет правило замены шрифта

Тип FontSubstCondition содержит следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| WHEN_INACCESSIBLE | Заменять, когда шрифт не найден |
| ALWAYS | Всегда заменять |
