## PictureFrameLock класс

Определяет, какие операции отключены у родительского PictureFrame.

**Наследование:**[`PictureFrameLock`](/slides/python-net/ru/aspose.slides/pictureframelock) → [`BaseShapeLock`](/slides/python-net/ru/aspose.slides/baseshapelock)

Тип PictureFrameLock раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`no_locks`](/slides/python-net/ru/aspose.slides/pictureframelock/no_locks/) | Возвращает true, если все lock-flags отключены.<br/>            Только для чтения **bool**. |
| [`grouping_locked`](/slides/python-net/ru/aspose.slides/pictureframelock/grouping_locked/) | Определяет, запрещено ли добавление этой фигуры в группу.<br/>            Чтение/запись **bool**. |

| [`rotation_locked`](/slides/python-net/ru/aspose.slides/pictureframelock/rotation_locked/) | Определяет, запрещено ли изменение угла вращения этой фигуры.<br/>            Чтение/запись **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/ru/aspose.slides/pictureframelock/aspect_ratio_locked/) | Определяет, должна ли фигура сохранять соотношение сторон при изменении размера.<br/>            Чтение/запись **bool**. |

| [`edit_points_locked`](/slides/python-net/ru/aspose.slides/pictureframelock/edit_points_locked/) | Определяет, запрещено ли прямое изменение контура этой фигуры.<br/>            Чтение/запись **bool**. |

| [`crop_locked`](/slides/python-net/ru/aspose.slides/pictureframelock/crop_locked/) | Определяет, запрещено ли обрезка изображения.<br/>            Чтение/запись **bool**. |
