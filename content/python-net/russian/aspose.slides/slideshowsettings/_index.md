## SlideShowSettings класс

Представляет настройки слайд-шоу для презентации.

Тип SlideShowSettings предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`slide_show_type`](/slides/python-net/ru/aspose.slides/slideshowsettings/slide_show_type/) | Получает или задает тип слайд-шоу. Представлен следующими [`SlideShowSettings.slide_show_type`](/slides/python-net/ru/aspose.slides/slideshowsettings/slide_show_type) предками: [`BrowsedAtKiosk`](/slides/python-net/ru/aspose.slides/browsedatkiosk), [`PresentedBySpeaker`](/slides/python-net/ru/aspose.slides/presentedbyspeaker) и [`BrowsedByIndividual`](/slides/python-net/ru/aspose.slides/browsedbyindividual) |
| [`loop`](/slides/python-net/ru/aspose.slides/slideshowsettings/loop/) | Повторять слайд-шоу |
| [`show_narration`](/slides/python-net/ru/aspose.slides/slideshowsettings/show_narration/) | Показывать озвучивание в слайд-шоу |
| [`show_animation`](/slides/python-net/ru/aspose.slides/slideshowsettings/show_animation/) | Показывать анимацию в слайд-шоу |
| [`pen_color`](/slides/python-net/ru/aspose.slides/slideshowsettings/pen_color/) | Цвет пера для слайд-шоу |
| [`slides`](/slides/python-net/ru/aspose.slides/slideshowsettings/slides/) | Диапазон слайдов |
| [`use_timings`](/ru/slides/python-net/aspose.slides/slideshowsettings/use_timings/) | Использовать тайминги в слайд-шоу |
| [`show_media_controls`](/slides/python-net/ru/aspose.slides/slideshowsettings/show_media_controls/) | Показывать элементы управления медиа |
