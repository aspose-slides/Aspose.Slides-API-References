## is_named_color свойство
Указывает, содержит ли этот цвет имя: он был создан из именованной константы, такой как `Color.red`, с [`from_name`](/slides/python-net/ru/aspose.slides/color/from_name/), или был возвращён библиотекой как именованный цвет.
Только для чтения **bool**.
