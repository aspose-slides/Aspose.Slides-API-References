## from_argb(argb) {#int}
Создает цвет из 32-битного значения ARGB.

### Возвращаемое значение

Цвет, созданный из указанного значения.



```python
@staticmethod
def from_argb(argb):
    ...
```


| Параметр | Тип | Описание |
| :- | :- | :- |
| argb | **int** | Значение, определяющее 32-битное значение ARGB (знаковое или беззнаковое). |

### Исключения

| Исключение | Описание |
| :- | :- |
| **ValueError** | Значение компонента меньше 0 или больше 255. |
| **TypeError** | Неправильное количество или тип аргументов. |
