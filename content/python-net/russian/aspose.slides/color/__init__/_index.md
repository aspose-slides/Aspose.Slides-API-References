| Параметр | Тип | Описание |
| :- | :- | :- |
| r | **int** | Значение красного компонента. Допустимые значения от 0 до 255. |
| g | **int** | Значение зеленого компонента. Допустимые значения от 0 до 255. |

| Исключение | Описание |
