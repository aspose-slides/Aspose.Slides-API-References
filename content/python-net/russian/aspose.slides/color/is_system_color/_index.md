## is_system_color свойство
Указывает, является ли данный цвет системным цветом: цветом, используемым для элемента отображения Windows, например `Control` или `ActiveBorder`.<br/>            Системные цвета не доступны как атрибуты `Color` и могут быть получены только с помощью [`from_known_color`](/slides/python-net/ru/aspose.slides/color/from_known_color/) или возвращены из библиотеки.
            Только для чтения **bool**.
