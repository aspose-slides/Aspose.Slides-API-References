## from_rgb(r, g, b) {#int-int-int}
Создаёт непрозрачный цвет (альфа = 255) из указанных значений красного, зелёного и синего каналов.

### Возвращаемое значение

Цвет, созданный из указанных значений.



```python
@staticmethod
def from_rgb(r, g, b):
    ...
```


| Параметр | Тип | Описание |
| :- | :- | :- |
| r | **int** | Значение красного компонента. Допустимые значения от 0 до 255. |
| g | **int** | Значение зелёного компонента. Допустимые значения от 0 до 255. |
| b | **int** | Значение синего компонента. Допустимые значения от 0 до 255. |

### Исключения

| Исключение | Описание |
| :- | :- |
| **ValueError** | Значение компонента меньше 0 или больше 255. |
