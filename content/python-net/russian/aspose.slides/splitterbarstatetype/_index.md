## SplitterBarStateType перечисление

Указывает состояние, в котором должна отображаться полоса разделителя. Полоса разделителя отделяет первичную и вторичную область внутри области просмотра.

Тип SplitterBarStateType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| MINIMIZED | Первичная область занимает наименьшее количество области просмотра, разрешённое приложением. |
| RESTORED | Первичная область имеет конкретный промежуточный размер. |
| MAXIMIZED | Первичная область занимает наибольшее количество области просмотра, разрешённое приложением. |
