## Comment класс

Представляет комментарий на слайде.

Тип Comment содержит следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`text`](/slides/python-net/ru/aspose.slides/comment/text/) | Возвращает или задает обычный текст комментария к слайду.<br/>            Чтение/запись **str**. |
| [`created_time`](/slides/python-net/ru/aspose.slides/comment/created_time/) | Возвращает или задает время создания комментария.<br/>            Установка этого свойства в **System.DateTime** означает, что время комментария не задано.<br/>            Чтение/запись **System.DateTime**. |
| [`slide`](/slides/python-net/ru/aspose.slides/comment/slide/) | Возвращает или задает слайд-родитель комментария.<br/>            Только для чтения [`ISlide`](/slides/python-net/ru/aspose.slides/islide). |
| [`author`](/slides/python-net/ru/aspose.slides/comment/author/) | Возвращает автора комментария.<br/>            Только для чтения [`ICommentAuthor`](/slides/python-net/ru/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/ru/aspose.slides/comment/position/) | Возвращает или задает позицию комментария на слайде.<br/>            Чтение/запись **aspose.slides.PointF**. |
| [`parent_comment`](/slides/python-net/ru/aspose.slides/comment/parent_comment/) | Возвращает или задает родительский комментарий.<br/>            Чтение/запись [`IComment`](/slides/python-net/ru/aspose.slides/icomment). |

## Методы

| Метод | Описание |
| :- | :- |
| [`remove(self)`](/slides/python-net/ru/aspose.slides/comment/remove/#) | Удаляет комментарий и все его ответы из родительской коллекции. |
