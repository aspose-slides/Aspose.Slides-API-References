## Comment класс

Представляет комментарий к слайду.

Тип Comment предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`text`](/slides/python-net/ru/aspose.slides/comment/text/) | Возвращает или задаёт простой текст комментария к слайду.<br/>            Чтение/запись **str**. |
| [`created_time`](/slides/python-net/ru/aspose.slides/comment/created_time/) | Возвращает или задаёт время создания комментария.<br/>            Установка этого свойства в **System.DateTime** означает, что время комментария не задано.<br/>            Чтение/запись **System.DateTime**. |
| [`slide`](/slides/python-net/ru/aspose.slides/comment/slide/) | Возвращает или задаёт родительский слайд комментария.<br/>            Только для чтения [`ISlide`](/slides/python-net/ru/aspose.slides/islide). |
| [`author`](/slides/python-net/ru/aspose.slides/comment/author/) | Возвращает автора комментария.<br/>            Только для чтения [`ICommentAuthor`](/slides/python-net/ru/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/ru/aspose.slides/comment/position/) | Возвращает или задаёт позицию комментария на слайде.<br/>            Чтение/запись [`PointF`](/slides/python-net/ru/aspose.slides/pointf). |
| [`parent_comment`](/slides/python-net/ru/aspose.slides/comment/parent_comment/) | Возвращает или задаёт родительский комментарий.<br/>            Чтение/запись [`IComment`](/slides/python-net/ru/aspose.slides/icomment). |

## Методы

| Метод | Описание |
| :- | :- |
| [`remove(self)`](/slides/python-net/ru/aspose.slides/comment/remove/#) | Удаляет комментарий и все его ответы из родительской коллекции. |
