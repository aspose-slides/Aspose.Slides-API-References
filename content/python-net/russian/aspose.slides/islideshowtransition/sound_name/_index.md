## sound_name свойство
Задает человеко-читаемое имя для звука перехода. Свойство [`ISlideShowTransition.sound`](/slides/python-net/ru/aspose.slides/islideshowtransition/sound) должно быть установлено для получения или задания имени звука.
            Чтение/запись **str**.

### Примечания
Это имя отображается в пользовательском интерфейсе PowerPoint при ручной настройке звука перехода.
