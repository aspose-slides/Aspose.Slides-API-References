## ITextFrameFormatEffectiveData класс

Неизменяемый объект, содержащий эффективные свойства форматирования текстовой рамки.

Тип ITextFrameFormatEffectiveData раскрывает следующие члены:

## Свойства

| Property | Description |
| :- | :- |
| [`text_style`](/slides/python-net/ru/aspose.slides/itextframeformateffectivedata/text_style/) | Возвращает стиль эффективного текста.<br/>            Только для чтения [`ITextStyleEffectiveData`](/slides/python-net/ru/aspose.slides/itextstyleeffectivedata). |
| [`margin_left`](/slides/python-net/ru/aspose.slides/itextframeformateffectivedata/margin_left/) | Возвращает левый отступ (points) в TextFrame.<br/>            Только для чтения **float**. |
| [`margin_right`](/slides/python-net/ru/aspose.slides/itextframeformateffectivedata/margin_right/) | Возвращает правый отступ (points) в TextFrame.<br/>            Только для чтения **float**. |
| [`margin_top`](/slides/python-net/ru/aspose.slides/itextframeformateffectivedata/margin_top/) | Возвращает верхний отступ (points) в TextFrame.<br/>            Только для чтения **float**. |
| [`margin_bottom`](/slides/python-net/ru/aspose.slides/itextframeformateffectivedata/margin_bottom/) | Возвращает нижний отступ (points) в TextFrame.<br/>            Только для чтения **float**. |
| [`wrap_text`](/slides/python-net/ru/aspose.slides/itextframeformateffectivedata/wrap_text/) | Возвращает, обернут ли текст по полям TextFrame.<br/>            Только для чтения **bool**. |
| [`anchoring_type`](/slides/python-net/ru/aspose.slides/itextframeformateffectivedata/anchoring_type/) | Возвращает вертикальный якорь текста в TextFrame.<br/>            Только для чтения [`TextAnchorType`](/slides/python-net/ru/aspose.slides/textanchortype). |
| [`center_text`](/slides/python-net/ru/aspose.slides/itextframeformateffectivedata/center_text/) | Возвращает, должен ли текст быть центрирован по горизонтали в коробке.<br/>            Только для чтения **bool**. |
| [`text_vertical_type`](/slides/python-net/ru/aspose.slides/itextframeformateffectivedata/text_vertical_type/) | Возвращает ориентацию текста.<br/>            Только для чтения [`TextVerticalType`](/slides/python-net/ru/aspose.slides/textverticaltype). |
| [`autofit_type`](/slides/python-net/ru/aspose.slides/itextframeformateffectivedata/autofit_type/) | Возвращает режим автоподгонки текста.<br/>            Только для чтения [`TextAutofitType`](/slides/python-net/ru/aspose.slides/textautofittype). |
| [`column_count`](/slides/python-net/ru/aspose.slides/itextframeformateffectivedata/column_count/) | Указывает количество столбцов текста в ограничивающем прямоугольнике.<br/>            Только для чтения **int**. |
| [`column_spacing`](/slides/python-net/ru/aspose.slides/itextframeformateffectivedata/column_spacing/) | Указывает интервал между столбцами текста в области текста (в points).<br/>            Только для чтения **float**. |

### Примечания

Этот интерфейс используется вместе с интерфейсом [`ITextFrameFormat`](/slides/python-net/ru/aspose.slides/itextframeformat) для возврата эффективных значений форматирования с применением наследования.
