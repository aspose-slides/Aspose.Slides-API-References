## ShapesAlignmentType перечисление

Определяет способ изменить размещение выбранных фигур на слайде.

Тип ShapesAlignmentType предоставляет следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| ALIGN_LEFT | Выровнять по левому краю |
| ALIGN_RIGHT | Выровнять по правому краю |
| ALIGN_CENTER | Выровнять по центру |
| ALIGN_TOP | Выровнять по верхнему краю |
| ALIGN_MIDDLE | Выровнять по середине |
| ALIGN_BOTTOM | Выровнять по нижнему краю |
| DISTRIBUTE_HORIZONTALLY | Распределить горизонтально |
| DISTRIBUTE_VERTICALLY | Распределить вертикально |
