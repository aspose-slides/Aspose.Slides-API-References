## Класс Picture

Представляет изображение в презентации.

Тип Picture раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`image`](/slides/python-net/ru/aspose.slides/picture/image/) | Возвращает или задает встроенное изображение.<br/>            Чтение/запись [`IPPImage`](/slides/python-net/ru/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/ru/aspose.slides/picture/link_path_long/) | Возвращает или задает URL связанного изображения.<br/>            Чтение/запись **str**. |
| [`image_transform`](/slides/python-net/ru/aspose.slides/picture/image_transform/) | Возвращает коллекцию эффектов преобразования изображения.<br/>            Только чтение [`IImageTransformOperationCollection`](/slides/python-net/ru/aspose.slides.effects/iimagetransformoperationcollection). |
| [`presentation`](/slides/python-net/ru/aspose.slides/picture/presentation/) | Возвращает презентацию.<br/>            Только чтение [`IPresentation`](/slides/python-net/ru/aspose.slides/ipresentation). |
| [`slide`](/slides/python-net/ru/aspose.slides/picture/slide/) | Возвращает слайд-родитель изображения.<br/>            Только чтение [`IBaseSlide`](/slides/python-net/ru/aspose.slides/ibaseslide). |
