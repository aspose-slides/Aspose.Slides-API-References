| :- | :- |
| [`master_notes_slide`](/slides/python-net/ru/aspose.slides/imasternotesslidemanager/master_notes_slide/) | Возвращает master для всех слайдов заметок этой презентации, если он существует, иначе возвращает None.<br/>            Только для чтения [`IMasterNotesSlide`](/slides/python-net/ru/aspose.slides/imasternotesslide). |
