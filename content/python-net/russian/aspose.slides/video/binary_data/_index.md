## binary_data свойство
Возвращает копию данных аудио. В случае большого объёма данных рассматривайте использование 
            [`Video.get_stream`](/slides/python-net/ru/aspose.slides/video/get_stream) метод, чтобы предотвратить ненужную загрузку данных видео в память 
            или даже OutOfMemoryException.
            Только для чтения **int**[].
