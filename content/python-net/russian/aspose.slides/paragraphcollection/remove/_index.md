## remove(self, item) {#iparagraph}
Удаляет первое вхождение указанного объекта из **System.Collections.Generic.ICollection`1**.

### Возвращаемое значение

true, если `item` был успешно удалён из **System.Collections.Generic.ICollection`1**; в противном случае — false. Этот метод также возвращает false, если `item` не найден в исходном **System.Collections.Generic.ICollection`1**.



```python
def remove(self, item):
    ...
```


| Параметр | Тип | Описание |
| :- | :- | :- |
| item | [`IParagraph`](/slides/python-net/ru/aspose.slides/iparagraph) | Объект, который следует удалить из **System.Collections.Generic.ICollection`1**. |

### Исключения

| Исключение | Описание |
| :- | :- |
| **RuntimeError(Proxy error(NotSupportedException))** | **System.Collections.Generic.ICollection`1** является только для чтения. |
