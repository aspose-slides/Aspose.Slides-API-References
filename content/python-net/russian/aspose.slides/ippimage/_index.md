## IPPImage класс

Представляет изображение в презентации.

Тип IPPImage раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`binary_data`](/slides/python-net/ru/aspose.slides/ippimage/binary_data/) | Возвращает копию данных изображения.<br/>            Только для чтения **int**[]. |
| [`image`](/slides/python-net/ru/aspose.slides/ippimage/image/) | Возвращает копию изображения.<br/>            Только для чтения [`IPPImage.image`](/slides/python-net/ru/aspose.slides/ippimage/image). |
| [`svg_image`](/slides/python-net/ru/aspose.slides/ippimage/svg_image/) | Возвращает или задает объект ISvgImage [`ISvgImage`](/slides/python-net/ru/aspose.slides/isvgimage) |
| [`content_type`](/slides/python-net/ru/aspose.slides/ippimage/content_type/) | Возвращает MIME-тип изображения, закодированный в [`IPPImage.binary_data`](/slides/python-net/ru/aspose.slides/ippimage/binary_data).<br/>            Только для чтения **str**. |
| [`width`](/slides/python-net/ru/aspose.slides/ippimage/width/) | Возвращает ширину изображения.<br/>            Только для чтения **int**. |
| [`height`](/slides/python-net/ru/aspose.slides/ippimage/height/) | Возвращает высоту изображения.<br/>            Только для чтения **int**. |
| [`x`](/slides/python-net/ru/aspose.slides/ippimage/x/) | Возвращает X-смещение изображения.<br/>            Только для чтения **int**. |
| [`y`](/slides/python-net/ru/aspose.slides/ippimage/y/) | Возвращает Y-смещение изображения.<br/>            Только для чтения **int**. |
