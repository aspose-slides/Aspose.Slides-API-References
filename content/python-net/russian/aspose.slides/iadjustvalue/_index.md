## IAdjustValue класс

Представляет значение корректировки геометрической фигуры.
            Эти значения влияют на форму фигуры.

Тип IAdjustValue раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`raw_value`](/slides/python-net/ru/aspose.slides/iadjustvalue/raw_value/) | Возвращает или задаёт значение корректировки “as is”.<br/>            Чтение/запись **int**. |
| [`angle_value`](/slides/python-net/ru/aspose.slides/iadjustvalue/angle_value/) | Возвращает или задаёт значение, интерпретируя его как угол в градусах.<br/>            Чтение/запись **float**. |
| [`name`](/slides/python-net/ru/aspose.slides/iadjustvalue/name/) | Возвращает имя этой корректирующей величины.<br/>            Только для чтения **str**. |
| [`type`](/slides/python-net/ru/aspose.slides/iadjustvalue/type/) | Возвращает тип корректировки фигуры.<br/>            Только для чтения [`ShapeAdjustmentType`](/slides/python-net/ru/aspose.slides/shapeadjustmenttype). |
