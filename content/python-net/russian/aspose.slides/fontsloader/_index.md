## FontsLoader класс

Класс для загрузки пользовательских шрифтов, определённых пользователем.
            Должен использоваться перед созданием любых объектов презентации.

Тип FontsLoader раскрывает следующие члены:

## Методы

| Метод | Описание |
| :- | :- |
| [`load_external_fonts(directories)`](/slides/python-net/ru/aspose.slides/fontsloader/load_external_fonts/#liststr) | Добавляет дополнительные папки для поиска шрифтов. |
| [`load_external_font(data)`](/slides/python-net/ru/aspose.slides/fontsloader/load_external_font/#bytes) | Добавляет шрифт из двоичных данных |
| [`get_font_folders()`](/slides/python-net/ru/aspose.slides/fontsloader/get_font_folders/#) | Получает папки шрифтов. Возвращает папки, которые были добавлены методом LoadExternalFonts, а также системные папки шрифтов |
| [`clear_cache()`](/slides/python-net/ru/aspose.slides/fontsloader/clear_cache/#) | Освобождает все пользовательские шрифты, определённые пользователем |
