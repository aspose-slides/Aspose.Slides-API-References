## Captions класс

Представляет закрытые субтитры WebVTT.

Тип Captions предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`caption_id`](/slides/python-net/ru/aspose.slides/captions/caption_id/) | Возвращает глобальный уникальный идентификатор (GUID) закрытых субтитров.<br/>            Только для чтения **System.Guid**. |
| [`label`](/slides/python-net/ru/aspose.slides/captions/label/) | Возвращает или задает метку закрытых субтитров.<br/>            Чтение/запись **str**. |
| [`binary_data`](/slides/python-net/ru/aspose.slides/captions/binary_data/) | Возвращает бинарные данные закрытых субтитров.<br/>            Только для чтения **int**[]. |
| [`data_as_string`](/slides/python-net/ru/aspose.slides/captions/data_as_string/) | Возвращает данные закрытых субтитров в виде строки, закодированной UTF-8<br/>            Только для чтения **str**. |
