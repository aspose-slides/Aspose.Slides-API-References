## encrypt_document_properties свойство
Это свойство имеет смысл, если презентация защищена паролем.
            Если true, тогда свойства документа зашифрованы в файле презентации.
            Если false, тогда свойства документа являются публичными, а презентация зашифрована.
            Чтение/запись **bool**.

### Определение:
```python
@property
def encrypt_document_properties(self):
    ...

@encrypt_document_properties.setter
def encrypt_document_properties(self, value):
    ...
```
