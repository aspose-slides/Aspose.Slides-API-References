## TextVerticalType перечисление

Определяет вертикальный режим написания текста.

Тип TextVerticalType содержит следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| NOT_DEFINED | Не определено. |
| HORIZONTAL | Горизонтальный текст. |
| VERTICAL | Вертикальный текст. |
| VERTICAL270 | Вертикальный текст под углом 270 градусов. |
| WORD_ART_VERTICAL | WordArt вертикальный текст. |
| EAST_ASIAN_VERTICAL | Восточно-азиатский вертикальный текст. |
| MONGOLIAN_VERTICAL | Монгольский вертикальный текст. |
| WORD_ART_VERTICAL_RIGHT_TO_LEFT | WordArt вертикальный текст справа налево. |
