## ICommentAuthor класс

Представляет автора комментариев.

Тип ICommentAuthor раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`name`](/slides/python-net/ru/aspose.slides/icommentauthor/name/) | Возвращает или задает имя автора.<br/>            Чтение/запись **str**. |
| [`initials`](/slides/python-net/ru/aspose.slides/icommentauthor/initials/) | Возвращает или задает инициалы автора.<br/>            Чтение/запись **str**. |
| [`comments`](/slides/python-net/ru/aspose.slides/icommentauthor/comments/) | Возвращает коллекцию комментариев, сделанных этим автором.<br/>            Только чтение [`ICommentCollection`](/slides/python-net/ru/aspose.slides/icommentcollection). |

## Методы

| :- | :- |
