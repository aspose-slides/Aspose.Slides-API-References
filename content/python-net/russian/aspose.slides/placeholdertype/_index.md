## Перечисление PlaceholderType

Представляет тип заполнителя.

Тип PlaceholderType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| TITLE | Заголовок. |
| BODY | Тело. |
| CENTERED_TITLE | Центрированный заголовок. |
| SUBTITLE | Подзаголовок. |
| DATE_AND_TIME | Дата и время. |
| SLIDE_NUMBER | Номер слайда. |
| FOOTER | Нижний колонтитул. |
| HEADER | Верхний колонтитул. |
| OBJECT | Объект. |
| CHART | Диаграмма. |
| TABLE | Таблица. |
| CLIP_ART | Клипарт. |
| DIAGRAM | Диаграмма. |
| MEDIA | Медиа. |
| SLIDE_IMAGE | Изображение слайда. |
| PICTURE | Изображение. |
