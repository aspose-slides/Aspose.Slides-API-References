## PathCommandType перечисление

Представляет команды графического пути

Тип PathCommandType предоставляет следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| CLOSE | Закрывает геометрический путь |
| MOVE_TO | Устанавливает позицию следующей точки геометрического пути |
| LINE_TO | Добавляет линию к геометрическому пути |
| ARC_TO | Добавляет указанный дугу к геометрическому пути. |
| QUAD_BEZIER_TO | Добавляет квадратичную кривую Безье к геометрическому пути |
| CUBIC_BEZIER_TO | Добавляет кубическую кривую Безье к геометрическому пути |
