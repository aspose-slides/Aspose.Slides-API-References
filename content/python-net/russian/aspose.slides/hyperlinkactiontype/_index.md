## HyperlinkActionType перечисление

Представляет тип действия гиперссылки.

Тип HyperlinkActionType содержит следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| UNKNOWN | Неизвестный тип действия. |
| NO_ACTION | Нет действия. |
| HYPERLINK | Обычная гиперссылка. |
| JUMP_FIRST_SLIDE | Перейти к первому слайду презентации. |
| JUMP_PREVIOUS_SLIDE | Перейти к предыдущему слайду. |
| JUMP_NEXT_SLIDE | Перейти к следующему слайду. |
| JUMP_LAST_SLIDE | Перейти к последнему слайду презентации. |
| JUMP_END_SHOW | Перейти к концу показа слайдов. |
| JUMP_LAST_VIEWED_SLIDE | Перейти к последнему просмотренному слайду. |
| JUMP_SPECIFIC_SLIDE | Перейти к конкретному слайду, указанному свойством [`IHyperlink.target_slide`](/slides/python-net/ru/aspose.slides/ihyperlink/target_slide). |
| START_CUSTOM_SLIDE_SHOW | Запустить пользовательский показ слайдов. |
| OPEN_FILE | Открыть указанный файл. |
| OPEN_PRESENTATION | Открыть указанную презентацию. |
| START_STOP_MEDIA | Запустить/остановить воспроизведение медиафайла. |
| START_MACRO | Запустить выполнение макроскрипта. |
| START_PROGRAM | Запустить программу. |
