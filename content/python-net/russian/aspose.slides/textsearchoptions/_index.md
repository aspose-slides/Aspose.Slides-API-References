## TextSearchOptions класс

Представляет параметры, которые можно использовать для поиска текста в объекте Presentation, Slide или TextFrame.

Тип TextSearchOptions содержит следующие члены:

## Конструкторы

| Constructor | Description |
| :- | :- |
| [`__init__(self)`](/slides/python-net/ru/aspose.slides/textsearchoptions/__init__/#) | Создаёт новые параметры поиска текста по умолчанию. |

## Свойства

| Property | Description |
| :- | :- |
| [`case_sensitive`](/slides/python-net/ru/aspose.slides/textsearchoptions/case_sensitive/) | Установите true для использования поиска с учётом регистра, false — иначе.<br/>            Чтение/запись **bool**. |
| [`whole_words_only`](/slides/python-net/ru/aspose.slides/textsearchoptions/whole_words_only/) | Установите true, чтобы соответствовать только целым словам, false — иначе.<br/>            Чтение/запись **bool**. |
| [`include_notes`](/slides/python-net/ru/aspose.slides/textsearchoptions/include_notes/) | Установите `true`, чтобы включить текст, содержащийся в заметках слайда ([`NotesSlide`](/slides/python-net/ru/aspose.slides/notesslide)) <br/>            при выполнении поиска текста, замены или выделения.<br/>            Значение по умолчанию — `false`. |
