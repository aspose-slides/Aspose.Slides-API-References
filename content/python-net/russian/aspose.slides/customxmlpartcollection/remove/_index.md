## remove(self, item) {#icustomxmlpart}
Удаляет первое вхождение конкретного объекта из коллекции.

### Возвращаемое значение

`true`, если item успешно удалён; иначе — `false`.

```python
def remove(self, item):
    ...
```

| Параметр | Тип | Описание |
| :- | :- | :- |
| item | [`ICustomXmlPart`](/slides/python-net/ru/aspose.slides/icustomxmlpart) | Настраиваемый XML-элемент, который следует удалить. |

### Исключения

| Исключение | Описание |
| :- | :- |
| **RuntimeError(Proxy error(ArgumentNullException))** | item равен `None`. |
