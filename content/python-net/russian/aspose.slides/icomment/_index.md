## IComment класс

Представляет комментарий к слайду.

Тип IComment раскрывает следующие члены:

## Свойства

| Property | Description |
| :- | :- |
| [`text`](/slides/python-net/ru/aspose.slides/icomment/text/) | Возвращает или задает простой текст комментария к слайду.<br/>            Чтение/запись **str**. |
| [`created_time`](/slides/python-net/ru/aspose.slides/icomment/created_time/) | Возвращает или задает время создания комментария.<br/>            Установка этого свойства в **System.DateTime** означает, что время комментария не задано.<br/>            Чтение/запись **System.DateTime**. |
| [`slide`](/slides/python-net/ru/aspose.slides/icomment/slide/) | Возвращает или задает родительский слайд комментария.<br/>            Только для чтения [`ISlide`](/slides/python-net/ru/aspose.slides/islide). |
| [`author`](/slides/python-net/ru/aspose.slides/icomment/author/) | Возвращает автора комментария.<br/>            Только для чтения [`ICommentAuthor`](/slides/python-net/ru/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/ru/aspose.slides/icomment/position/) | Возвращает или задает положение комментария на слайде.<br/>            Чтение/запись [`PointF`](/slides/python-net/ru/aspose.slides/pointf). |
| [`parent_comment`](/slides/python-net/ru/aspose.slides/icomment/parent_comment/) | Возвращает или задает родительский комментарий.<br/>            Чтение/запись [`IComment`](/slides/python-net/ru/aspose.slides/icomment). |

## Методы

| Method | Description |
| :- | :- |
| [`remove(self)`](/slides/python-net/ru/aspose.slides/icomment/remove/#) | Удаляет комментарий и все его ответы из родительской коллекции. |
