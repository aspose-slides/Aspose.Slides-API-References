## IControlPropertiesCollection класс

Коллекция элементов управления ActiveX.

Тип IControlPropertiesCollection раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`count`](/slides/python-net/ru/aspose.slides/icontrolpropertiescollection/count/) | Возвращает количество свойств в коллекции.<br/>            Только для чтения **int**. |
| [`names_of_properties`](/slides/python-net/ru/aspose.slides/icontrolpropertiescollection/names_of_properties/) | Возвращает количество свойств в коллекции.<br/>            Только для чтения **list**. |

## Методы

| Метод | Описание |
| :- | :- |
| [`add(self, name, value)`](/slides/python-net/ru/aspose.slides/icontrolpropertiescollection/add/#str-str) | Добавляет свойство в коллекцию. |
| [`remove(self, name)`](/slides/python-net/ru/aspose.slides/icontrolpropertiescollection/remove/#str) | Удаляет свойство с указанным именем. |
| [`clear(self)`](/slides/python-net/ru/aspose.slides/icontrolpropertiescollection/clear/#) | Удаляет все свойства. |
