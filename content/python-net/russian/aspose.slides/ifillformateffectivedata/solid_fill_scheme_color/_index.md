## solid_fill_scheme_color свойство
Gets the fill color defined by a color scheme.
            Значение [`SchemeColor.NOT_DEFINED`](/slides/python-net/ru/aspose.slides/schemecolor/NOT_DEFINED) указывает, что [`IFillFormatEffectiveData.solid_fill_color`](/slides/python-net/ru/aspose.slides/ifillformateffectivedata/solid_fill_color) 
            не является цветом схемы.
            Только для чтения [`SchemeColor`](/slides/python-net/ru/aspose.slides/schemecolor).
