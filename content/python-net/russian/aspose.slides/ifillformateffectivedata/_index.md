## IFillFormatEffectiveData class

Неизменяемый объект, содержащий эффективные свойства форматирования заливки.

Тип IFillFormatEffectiveData раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`fill_type`](/slides/python-net/ru/aspose.slides/ifillformateffectivedata/fill_type/) | Возвращает тип заливки.<br/>            Только для чтения [`FillType`](/slides/python-net/ru/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/ru/aspose.slides/ifillformateffectivedata/solid_fill_color/) | Возвращает цвет заливки.<br/>            Только для чтения **aspose.slides.Color**. |
| [`solid_fill_scheme_color`](/slides/python-net/ru/aspose.slides/ifillformateffectivedata/solid_fill_scheme_color/) | Получает цвет заливки, определенный цветовой схемой.<br/>            Значение [`SchemeColor.NOT_DEFINED`](/slides/python-net/ru/aspose.slides/schemecolor/NOT_DEFINED) указывает, что [`IFillFormatEffectiveData.solid_fill_color`](/slides/python-net/ru/aspose.slides/ifillformateffectivedata/solid_fill_color) <br/>            не является цветом схемы.<br/>            Только для чтения [`SchemeColor`](/slides/python-net/ru/aspose.slides/schemecolor). |
| [`gradient_format`](/slides/python-net/ru/aspose.slides/ifillformateffectivedata/gradient_format/) | Возвращает формат градиентной заливки.<br/>            Только для чтения [`IGradientFormatEffectiveData`](/slides/python-net/ru/aspose.slides/igradientformateffectivedata). |
| [`pattern_format`](/slides/python-net/ru/aspose.slides/ifillformateffectivedata/pattern_format/) | Возвращает формат узорной заливки.<br/>            Только для чтения [`IPatternFormatEffectiveData`](/slides/python-net/ru/aspose.slides/ipatternformateffectivedata). |
| [`picture_fill_format`](/slides/python-net/ru/aspose.slides/ifillformateffectivedata/picture_fill_format/) | Возвращает формат заливки картинкой.<br/>            Только для чтения [`IPictureFillFormatEffectiveData`](/slides/python-net/ru/aspose.slides/ipicturefillformateffectivedata). |
| [`rotate_with_shape`](/slides/python-net/ru/aspose.slides/ifillformateffectivedata/rotate_with_shape/) | Определяет, должна ли заливка вращаться вместе с фигурой.<br/>            Только для чтения **bool**. |


### Замечания

Этот интерфейс используется вместе с интерфейсом [`IFillFormat`](/slides/python-net/ru/aspose.slides/ifillformat) для возврата эффективных значений форматирования с применением наследования.
