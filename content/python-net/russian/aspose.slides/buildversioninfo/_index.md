## BuildVersionInfo класс

Содержит информацию о версии Aspose.Slides.

Тип BuildVersionInfo раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`ASSEMBLY_VERSION`](/slides/python-net/ru/aspose.slides/buildversioninfo/assembly_version/) | Версия сборки Aspose.Slides. |
| [`FILE_VERSION`](/slides/python-net/ru/aspose.slides/buildversioninfo/file_version/) | Версия файла сборки. |
| [`PRODUCT`](/slides/python-net/ru/aspose.slides/buildversioninfo/product/) | Имя продукта Aspose.Slides |
| [`PRODUCT_MAJOR`](/slides/python-net/ru/aspose.slides/buildversioninfo/product_major/) | Номер основной версии. |
| [`PRODUCT_MINOR`](/slides/python-net/ru/aspose.slides/buildversioninfo/product_minor/) | Номер вспомогательной версии. |
| [`RELEASE_DATE`](/slides/python-net/ru/aspose.slides/buildversioninfo/release_date/) | Дата выпуска сборки. |
