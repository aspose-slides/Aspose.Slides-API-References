## TagCollection класс

Представляет коллекцию тегов (пары строк, определённые пользователем)

Тип TagCollection предоставляет следующие члены:

## Методы

| Метод | Описание |
| :- | :- |
| [`add(self, name, value)`](/slides/python-net/ru/aspose.slides/tagcollection/add/#str-str) | Добавляет новый тег в коллекцию. |
| [`remove(self, name)`](/slides/python-net/ru/aspose.slides/tagcollection/remove/#str) | Удаляет тег с указанным именем из коллекции. |
| [`index_of_name(self, name)`](/slides/python-net/ru/aspose.slides/tagcollection/index_of_name/#str) | Возвращает нулевой индекс указанного ключа в коллекции. |
| [`remove_at(self, index)`](/slides/python-net/ru/aspose.slides/tagcollection/remove_at/#int) | Удаляет тег по указанному индексу. |
| [`clear(self)`](/slides/python-net/ru/aspose.slides/tagcollection/clear/#) | Удаляет все теги из коллекции. |
| [`get_value_by_index(self, index)`](/slides/python-net/ru/aspose.slides/tagcollection/get_value_by_index/#int) | Возвращает значение тега по указанному индексу. |
| [`get_name_by_index(self, index)`](/slides/python-net/ru/aspose.slides/tagcollection/get_name_by_index/#int) | Возвращает ключ тега по указанному индексу. |
