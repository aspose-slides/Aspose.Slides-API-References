## IThreeDFormatEffectiveData класс

Неизменяемый объект, представляющий эффективные свойства 3-D форматирования.

Тип IThreeDFormatEffectiveData предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`contour_width`](/slides/python-net/ru/aspose.slides/ithreedformateffectivedata/contour_width/) | Возвращает ширину 3D контура.<br/>            Только для чтения **float**. |
| [`extrusion_height`](/slides/python-net/ru/aspose.slides/ithreedformateffectivedata/extrusion_height/) | Возвращает высоту эффекта экструзии.<br/>            Только для чтения **float**. |
| [`depth`](/slides/python-net/ru/aspose.slides/ithreedformateffectivedata/depth/) | Возвращает глубину 3D фигуры.<br/>            Только для чтения **float**. |
| [`bevel_top`](/slides/python-net/ru/aspose.slides/ithreedformateffectivedata/bevel_top/) | Возвращает тип верхнего 3D фаски.<br/>            Только для чтения [`IShapeBevelEffectiveData`](/slides/python-net/ru/aspose.slides/ishapebeveleffectivedata). |
| [`bevel_bottom`](/slides/python-net/ru/aspose.slides/ithreedformateffectivedata/bevel_bottom/) | Возвращает тип нижнего 3D фаски.<br/>            Только для чтения [`IShapeBevelEffectiveData`](/slides/python-net/ru/aspose.slides/ishapebeveleffectivedata). |
| [`contour_color`](/slides/python-net/ru/aspose.slides/ithreedformateffectivedata/contour_color/) | Возвращает цвет контура.<br/>            Только для чтения [`Color`](/slides/python-net/ru/aspose.slides/color). |
| [`extrusion_color`](/slides/python-net/ru/aspose.slides/ithreedformateffectivedata/extrusion_color/) | Возвращает цвет экструзии.<br/>            Только для чтения [`Color`](/slides/python-net/ru/aspose.slides/color). |
| [`camera`](/slides/python-net/ru/aspose.slides/ithreedformateffectivedata/camera/) | Возвращает настройки камеры.<br/>            Только для чтения [`ICameraEffectiveData`](/slides/python-net/ru/aspose.slides/icameraeffectivedata). |
| [`light_rig`](/slides/python-net/ru/aspose.slides/ithreedformateffectivedata/light_rig/) | Возвращает тип освещения.<br/>            Только для чтения [`ILightRigEffectiveData`](/slides/python-net/ru/aspose.slides/ilightrigeffectivedata). |
| [`material`](/slides/python-net/ru/aspose.slides/ithreedformateffectivedata/material/) | Возвращает тип материала.<br/>            Только для чтения [`MaterialPresetType`](/slides/python-net/ru/aspose.slides/materialpresettype). |

### Замечания

Этот интерфейс используется совместно с интерфейсом [`IThreeDFormat`](/slides/python-net/ru/aspose.slides/ithreedformat) для возврата эффективных значений форматирования с применённым наследованием.
