## ICaptionsCollection класс

Представляет собой коллекцию закрытых субтитров.

Тип ICaptionsCollection раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`count`](/slides/python-net/ru/aspose.slides/icaptionscollection/count/) | Возвращает количество элементов в коллекции.<br/>            Только для чтения **int**. |

Возвращает закрытые субтитры по указанному индексу.
            Только для чтения [`ICaptions`](/slides/python-net/ru/aspose.slides/icaptions).
