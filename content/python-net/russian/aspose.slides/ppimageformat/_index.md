## PPImageFormat enumeration

Image formats. This enum is replacement for `System.Drawing.Imaging.ImageFormat` class.
            It's needed for COM compatibility.

Тип PPImageFormat раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| BMP | Возвращает формат битмапа (BMP). |
| EMF | Возвращает улучшенный метафайл (EMF) формат изображения. |
| EXIF | Возвращает формат Exchangeable Image File (Exif). |
| GIF | Возвращает формат Graphics Interchange Format (GIF). |
| ICON | Возвращает формат значка Windows (ICON). |
| JPEG | Возвращает формат Joint Photographic Experts Group (JPEG). |
| MEMORY_BMP | Возвращает формат битмапа в памяти. |
| PNG | Возвращает формат W3C Portable Network Graphics (PNG). |
| TIFF | Возвращает формат Tagged Image File Format (TIFF). |
| WMF | Возвращает формат Windows metafile (WMF). |
