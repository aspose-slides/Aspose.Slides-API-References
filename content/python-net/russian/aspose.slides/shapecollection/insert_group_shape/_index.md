## insert_group_shape(self, index) {#int}
Создаёт новую пустую групповую форму и вставляет её в коллекцию фигур по указанному индексу.  
Фрейм группы автоматически подгоняется под любые добавленные в неё фигуры.

### Возвращаемое значение

Созданный [`IGroupShape`](/slides/python-net/ru/aspose.slides/igroupshape).

```python
    ...
```


| Параметр | Тип | Описание |
| :- | :- | :- |
| index | **int** | Нулевой индекс, в котором следует вставить групповую форму. |
