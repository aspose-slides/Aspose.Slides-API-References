## insert_table(self, index, x, y, column_widths, row_heights) {#int-float-float-listfloat-listfloat}
Создает новую таблицу и вставляет её в коллекцию фигур по указанному индексу.

### Возвращаемое значение

Новосозданный [`ITable`](/slides/python-net/ru/aspose.slides/itable).



```python
def insert_table(self, index, x, y, column_widths, row_heights):
    ...
```


| Параметр | Тип | Описание |
| :- | :- | :- |
| index | **int** | Нулевой (отсчет с нуля) индекс, в котором вставляется таблица. |
| x | **float** | Координата x таблицы, в пунктах. |
| y | **float** | Координата y таблицы, в пунктах. |
| column_widths | **List[float]** | Массив чисел с плавающей точкой, представляющий ширины столбцов таблицы<br/><br/>            в пунктах. |
| row_heights | **List[float]** | Массив чисел с плавающей точкой, представляющий высоты строк таблицы<br/><br/>            в пунктах. |
