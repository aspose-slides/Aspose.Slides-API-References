## Перечисление EmbeddingLevel

Представляет лицензионные права на встраивание шрифта.

Тип EmbeddingLevel раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| INSTALLABLE | Шрифты с этой настройкой могут быть встроены и постоянно установлены в удалённой системе приложением.<br/>            Пользователь удалённой системы получает такие же права, обязательства и лицензии на этот шрифт, как у оригинального покупателя шрифта,<br/>            и подпадает под те же условия лицензии конечного пользователя, авторские права, патент на дизайн и/или товарный знак, как и оригинальный покупатель. |
| RESTRICTED | Шрифты, у которых установлен только этот бит, не могут быть изменены, встроены или переданы каким-либо образом без предварительного получения разрешения у законного владельца. |
| PREVIEW_PRINT | Когда установлен этот бит, шрифт может быть встроен и временно загружен в удалённую систему. Документы, содержащие шрифты Preview & Print, должны открываться «только для чтения»; изменения в документе недоступны. |
| EDITABLE | Когда установлен этот бит, шрифт может быть встроен, но должен устанавливаться только временно на других системах. В отличие от шрифтов Preview & Print, документы, содержащие шрифты Editable, могут открываться для чтения, редактирование разрешено, и изменения могут сохраняться. |
| NO_SUBSETTING | Когда установлен этот бит, шрифт не может быть субсетирован перед встраиванием. Также применяются другие ограничения встраивания, указанные в битах 0-3 и 9. |
| BITMAP_ONLY | Когда установлен этот бит, могут быть встроены только растровые изображения, содержащиеся в шрифте. Контурные данные встроены быть не могут. Если в шрифте нет растровых изображений, шрифт считается не встраиваемым, и службы встраивания завершатся с ошибкой. |
