## blob_management_options свойство
Represents the options which can be used to manage Binary Large Objects (BLOBs) handling behavior,
            например, использованием временных файлов или максимальным размером BLOB в памяти. Эти параметры предназначены для настройки
            оптимального соотношения производительности и потребления памяти для конкретной среды или требований.
            Большой двоичный объект (BLOB) — это бинарные данные, хранящиеся как единый объект, т.е. BLOB может 
            быть аудио, видео или самой презентацией.
