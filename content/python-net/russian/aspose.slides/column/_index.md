## Column класс

Представляет столбец в таблице.

**Inheritance:**[`Column`](/slides/python-net/ru/aspose.slides/column) → [`CellCollection`](/slides/python-net/ru/aspose.slides/cellcollection)

Тип Column раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`slide`](/slides/python-net/ru/aspose.slides/column/slide/) | Возвращает родительский слайд CellCollection.<br/>            Только для чтения [`IBaseSlide`](/slides/python-net/ru/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/ru/aspose.slides/column/presentation/) | Возвращает родительскую презентацию CellCollection.<br/>            Только для чтения [`IPresentation`](/slides/python-net/ru/aspose.slides/ipresentation). |
| [`width`](/slides/python-net/ru/aspose.slides/column/width/) | Возвращает или задает ширину столбца.<br/>            Чтение/запись **float**. |
| [`column_format`](/slides/python-net/ru/aspose.slides/column/column_format/) | Возвращает объект ColumnFormat, который содержит свойства форматирования для этого столбца.<br/>            Только для чтения [`IColumnFormat`](/slides/python-net/ru/aspose.slides/icolumnformat). |
