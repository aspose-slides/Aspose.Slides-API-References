## NormalViewProperties класс

Представляет свойства обычного представления. Обычное представление состоит из
            трех областей содержимого: самого слайда, боковой области содержимого и нижней области содержимого.

Тип NormalViewProperties раскрывает следующие члены:

## Свойства

| Property | Description |
| :- | :- |
| [`show_outline_icons`](/slides/python-net/ru/aspose.slides/normalviewproperties/show_outline_icons/) | Указывает, должен ли приложение показывать значки при отображении контурного содержимого в любой<br/>            из областей содержимого режима нормального просмотра.<br/>            Чтение/запись **bool**. |
| [`snap_vertical_splitter`](/slides/python-net/ru/aspose.slides/normalviewproperties/snap_vertical_splitter/) | Указывает, должен ли вертикальный разделитель переходить в минимизированное состояние, когда боковая<br/>            область достаточно мала.<br/>            Чтение/запись **bool**. |
| [`vertical_bar_state`](/slides/python-net/ru/aspose.slides/normalviewproperties/vertical_bar_state/) | Указывает состояние, в котором должна отображаться вертикальная панель разделителя. <br/>            Вертикальная панель разделителя отделяет слайд от боковой области содержимого. |
| [`horizontal_bar_state`](/slides/python-net/ru/aspose.slides/normalviewproperties/horizontal_bar_state/) | Указывает состояние, в котором должна отображаться горизонтальная панель разделителя.<br/>            Горизонтальная панель разделителя отделяет слайд от области содержимого под слайдом. |
| [`prefer_single_view`](/slides/python-net/ru/aspose.slides/normalviewproperties/prefer_single_view/) | Указывает, предпочитает ли пользователь видеть одно большое окно с единой областью содержимого вместо<br/>            стандартного нормального просмотра с тремя областями содержимого. При включении приложение может<br/>            выбрать отображение одной из областей содержимого во всем окне.<br/>            Чтение/запись **bool**. |
| [`restored_left`](/slides/python-net/ru/aspose.slides/normalviewproperties/restored_left/) | Этот элемент задает размер боковой области содержимого нормального просмотра, когда область имеет переменный<br/>            восстановленный размер (не минимизирована и не развернута).<br/>            Только для чтения [`INormalViewRestoredProperties`](/slides/python-net/ru/aspose.slides/inormalviewrestoredproperties). |
| [`restored_top`](/slides/python-net/ru/aspose.slides/normalviewproperties/restored_top/) | Этот элемент задает размер верхней области слайда нормального просмотра, когда область имеет переменный<br/>            восстановленный размер (не минимизирована и не развернута).<br/>            Только для чтения [`INormalViewRestoredProperties`](/slides/python-net/ru/aspose.slides/inormalviewrestoredproperties). |
