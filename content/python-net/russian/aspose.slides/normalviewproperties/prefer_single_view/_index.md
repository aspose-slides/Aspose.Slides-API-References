## prefer_single_view свойство
Указывает, предпочитает ли пользователь видеть одноблочную область полного окна вместо стандартного обычного представления с тремя областями содержимого. Если включено, приложение может выбрать отображать одну из областей содержимого во всем окне. Чтение/запись **bool**.

### Определение:
```python
@property
def prefer_single_view(self):
    ...

@prefer_single_view.setter
def prefer_single_view(self, value):
    ...
```
