## IFillFormat класс

Представляет параметры заливки.

Тип IFillFormat предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`fill_type`](/slides/python-net/ru/aspose.slides/ifillformat/fill_type/) | Возвращает или задает тип заливки.<br/>            Чтение/запись [`FillType`](/slides/python-net/ru/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/ru/aspose.slides/ifillformat/solid_fill_color/) | Возвращает цвет заливки.<br/>            Только для чтения [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`gradient_format`](/slides/python-net/ru/aspose.slides/ifillformat/gradient_format/) | Возвращает формат градиентной заливки.<br/>            Только для чтения [`IGradientFormat`](/slides/python-net/ru/aspose.slides/igradientformat). |
| [`pattern_format`](/slides/python-net/ru/aspose.slides/ifillformat/pattern_format/) | Возвращает формат узорной заливки.<br/>            Только для чтения [`IPatternFormat`](/slides/python-net/ru/aspose.slides/ipatternformat). |
| [`picture_fill_format`](/slides/python-net/ru/aspose.slides/ifillformat/picture_fill_format/) | Возвращает формат заливки изображением.<br/>            Только для чтения [`IPictureFillFormat`](/slides/python-net/ru/aspose.slides/ipicturefillformat). |
| [`rotate_with_shape`](/slides/python-net/ru/aspose.slides/ifillformat/rotate_with_shape/) | Определяет, должна ли заливка вращаться вместе с фигурой.<br/>            Чтение/запись [`NullableBool`](/slides/python-net/ru/aspose.slides/nullablebool). |
