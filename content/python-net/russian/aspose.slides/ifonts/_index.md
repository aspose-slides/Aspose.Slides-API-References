## IFonts класс

Представляет коллекцию шрифтов.

Тип IFonts раскрывает следующие члены:

## Свойства

| Property | Description |
| :- | :- |
| [`latin_font`](/slides/python-net/ru/aspose.slides/ifonts/latin_font/) | Возвращает или задает латинский шрифт.<br/>Чтение/запись [`IFontData`](/slides/python-net/ru/aspose.slides/ifontdata). |
| [`east_asian_font`](/slides/python-net/ru/aspose.slides/ifonts/east_asian_font/) | Возвращает или задает шрифт восточноазиатского текста.<br/>Чтение/запись [`IFontData`](/slides/python-net/ru/aspose.slides/ifontdata). |
| [`complex_script_font`](/slides/python-net/ru/aspose.slides/ifonts/complex_script_font/) | Возвращает или задает шрифт сложного сценария.<br/>Чтение/запись [`IFontData`](/slides/python-net/ru/aspose.slides/ifontdata). |

## Методы

| Method | Description |
| :- | :- |
| [`get_script_font_map(self)`](/slides/python-net/ru/aspose.slides/ifonts/get_script_font_map/#) | Возвращает список всех определений шрифтов сценариев в виде пар строка-строка в презентации. |
| [`get_script_font(self, script)`](/slides/python-net/ru/aspose.slides/ifonts/get_script_font/#str) | Получает имя шрифта, связанное с определённым тегом сценария из темы презентации. |
| [`set_script_font(self, script, font_name)`](/slides/python-net/ru/aspose.slides/ifonts/set_script_font/#str-str) | Назначает имя шрифта определённому тегу сценария, определяя, как будет отображаться текст этого сценария в презентации. |
| [`remove_script_font(self, script)`](/slides/python-net/ru/aspose.slides/ifonts/remove_script_font/#str) | Удаляет настройку шрифта, связанную с определённым тегом сценария, из коллекции шрифтов темы. |
