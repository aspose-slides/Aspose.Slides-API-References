## get_script_font(self, script) {#str}
Получает название шрифта, связанное с конкретным тегом сценария из темы презентации.

### Возвращаемое значение

Имя шрифта, используемого для указанного сценария, или `None`, если сценарий не определён.



```python
def get_script_font(self, script):
    ...
```


| Параметр | Тип | Описание |
| :- | :- | :- |
| script | **str** | Код сценария BCP-47 (например, "Latn", "Cyrl", "Jpan"), используемый для идентификации системы письма. |
