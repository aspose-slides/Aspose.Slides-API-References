## get_script_font(self, script) {#str}
Получает имя шрифта, связанное с определённым тегом скрипта из темы презентации.

### Возвращаемое значение

Имя шрифта, используемого для указанного скрипта, или `None`, если скрипт не определён.



```python
def get_script_font(self, script):
    ...
```


| Параметр | Тип | Описание |
| :- | :- | :- |
| script | **str** | Код сценария BCP-47 (например, "Latn", "Cyrl", "Jpan"), используемый для идентификации письменной системы. |
