## Класс Fonts

Коллекция шрифтов.

Тип Fonts предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`latin_font`](/slides/python-net/ru/aspose.slides/fonts/latin_font/) | Возвращает или задает латинский шрифт.<br/>            Чтение/запись [`IFontData`](/slides/python-net/ru/aspose.slides/ifontdata). |
| [`east_asian_font`](/slides/python-net/ru/aspose.slides/fonts/east_asian_font/) | Возвращает или задает шрифт восточно-азиатского текста.<br/>            Чтение/запись [`IFontData`](/slides/python-net/ru/aspose.slides/ifontdata). |
| [`complex_script_font`](/slides/python-net/ru/aspose.slides/fonts/complex_script_font/) | Возвращает или задает шрифт сложных сценариев.<br/>            Чтение/запись [`IFontData`](/slides/python-net/ru/aspose.slides/ifontdata). |

## Методы

| Метод | Описание |
| :- | :- |
| [`get_script_font_map(self)`](/slides/python-net/ru/aspose.slides/fonts/get_script_font_map/#) | Возвращает список всех определений шрифтов скриптов в виде пар строка-строка в презентации. |
| [`get_script_font(self, script)`](/slides/python-net/ru/aspose.slides/fonts/get_script_font/#str) | Получает имя шрифта, связанное с определённым тегом скрипта, из темы презентации. |
| [`set_script_font(self, script, font_name)`](/slides/python-net/ru/aspose.slides/fonts/set_script_font/#str-str) | Назначает имя шрифта определённому тегу скрипта, определяя, как будет отображаться текст этого скрипта в презентации. |
| [`remove_script_font(self, script)`](/slides/python-net/ru/aspose.slides/fonts/remove_script_font/#str) | Удаляет настройку шрифта, связанную с определённым тегом скрипта, из коллекции шрифтов темы. |
