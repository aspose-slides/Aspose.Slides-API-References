## PresetShadowType перечисление

Представляет предустановку для эффекта тени.

Тип PresetShadowType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| TOP_LEFT_DROP_SHADOW | Представляет верхнюю левую отбрасывающую тень. |
| TOP_LEFT_LARGE_DROP_SHADOW | Представляет большую верхнюю левую отбрасывающую тень. |
| BACK_LEFT_LONG_PERSPECTIVE_SHADOW | Представляет длинную перспективную тень сзади слева. |
| BACK_RIGHT_LONG_PERSPECTIVE_SHADOW | Представляет длинную перспективную тень сзади справа. |
| TOP_LEFT_DOUBLE_DROP_SHADOW | Представляет двойную верхнюю левую отбрасывающую тень. |
| BOTTOM_RIGHT_SMALL_DROP_SHADOW | Представляет небольшую нижнюю правую отбрасывающую тень. |
| FRONT_LEFT_LONG_PERSPECTIVE_SHADOW | Представляет длинную перспективную тень спереди слева. |
| FRONT_RIGHT_LONG_PERSPECTIVE_SHADOW | Представляет длинную перспективную тень спереди справа. |
| OUTER_BOX_SHADOW_3D | Представляет внешнюю 3D-тень коробки. |
| INNER_BOX_SHADOW_3D | Представляет внутреннюю 3D-тень коробки. |
| BACK_CENTER_PERSPECTIVE_SHADOW | Представляет центральную перспективную тень сзади. |
| TOP_RIGHT_DROP_SHADOW | Представляет верхнюю правую отбрасывающую тень. |
| FRONT_BOTTOM_SHADOW | Представляет нижнюю переднюю тень. |
| BACK_LEFT_PERSPECTIVE_SHADOW | Представляет перспективную тень сзади слева. |
| BACK_RIGHT_PERSPECTIVE_SHADOW | Представляет перспективную тень сзади справа. |
| BOTTOM_LEFT_DROP_SHADOW | Представляет нижнюю левую отбрасывающую тень. |
| BOTTOM_RIGHT_DROP_SHADOW | Представляет нижнюю правую отбрасывающую тень. |
| FRONT_LEFT_PERSPECTIVE_SHADOW | Представляет перспективную тень спереди слева. |
| FRONT_RIGHT_PERSPECTIVE_SHADOW | Представляет перспективную тень спереди справа. |
| TOP_LEFT_SMALL_DROP_SHADOW | Представляет небольшую верхнюю левую отбрасывающую тень. |
