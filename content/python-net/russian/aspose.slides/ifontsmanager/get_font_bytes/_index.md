## get_font_bytes(self, font_data, font_style) {#ifontdata-fontstyletype}
Получает массив байтов, представляющий данные шрифта для указанного стиля шрифта и данных шрифта.

### Возвращаемое значение

Массив байтов, содержащий данные шрифта для указанного стиля шрифта. Если данные шрифта или стиль не найдены, возвращает None.
