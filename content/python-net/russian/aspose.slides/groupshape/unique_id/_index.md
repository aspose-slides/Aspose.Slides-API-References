## unique_id свойство
Возвращает внутренний идентификатор, ограниченный областью презентации, предназначенный для использования надстройками или другим кодом.
            Поскольку это значение может быть переопределено пользователем или программно, его нельзя считать
            постоянным уникальным ключом.
            Только для чтения **int**.
            См. также [`Shape.office_interop_shape_id`](/slides/python-net/ru/aspose.slides/shape/office_interop_shape_id).
