## three_d_format свойство
Возвращает объект ThreeDFormat, содержащий свойства 3D-эффекта для формы.
            Примечание: может вернуть None для некоторых типов фигур, у которых нет 3D-свойств.
            Только для чтения [`IThreeDFormat`](/slides/python-net/ru/aspose.slides/ithreedformat).
