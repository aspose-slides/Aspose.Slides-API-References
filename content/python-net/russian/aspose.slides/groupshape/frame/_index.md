## свойство frame
Возвращает или задаёт свойства рамки формы.
            Чтение/запись [`IShapeFrame`](/slides/python-net/ru/aspose.slides/ishapeframe).

### Примечания

Значение каждого свойства возвращённого экземпляра IShapeFrame не является undefined (is not NaN or NotDefined).
            Значение каждого свойства назначенного экземпляра IShapeFrame должно быть не undefined (must be not NaN or NotDefined).
            Вы можете установить значения undefined для свойств экземпляра RawFrame.
