## IShapeFrame класс

Представляет свойства рамки формы.

Тип IShapeFrame содержит следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`x`](/slides/python-net/ru/aspose.slides/ishapeframe/x/) | Возвращает координату X верхнего левого угла рамки.<br/>            Только для чтения **float**. |
| [`y`](/slides/python-net/ru/aspose.slides/ishapeframe/y/) | Возвращает координату Y верхнего левого угла рамки.<br/>            Только для чтения **float**. |
| [`width`](/slides/python-net/ru/aspose.slides/ishapeframe/width/) | Возвращает ширину рамки.<br/>            Только для чтения **float**. |
| [`height`](/slides/python-net/ru/aspose.slides/ishapeframe/height/) | Возвращает высоту рамки.<br/>            Только для чтения **float**. |
| [`rotation`](/slides/python-net/ru/aspose.slides/ishapeframe/rotation/) | Возвращает количество градусов, на которое рамка повёрнута вокруг оси z.<br/>            Положительное значение указывает на вращение по часовой стрелке; отрицательное значение<br/>            указывает на вращение против часовой стрелки.<br/>            Только для чтения **float**. |
| [`center_x`](/slides/python-net/ru/aspose.slides/ishapeframe/center_x/) | Возвращает координату X центра рамки.<br/>            Только для чтения **float**. |
| [`center_y`](/slides/python-net/ru/aspose.slides/ishapeframe/center_y/) | Возвращает координату Y центра рамки.<br/>            Только для чтения **float**. |
| [`flip_h`](/slides/python-net/ru/aspose.slides/ishapeframe/flip_h/) | Определяет, отражена ли рамка по горизонтали.<br/>            Только для чтения [`NullableBool`](/slides/python-net/ru/aspose.slides/nullablebool). |
| [`flip_v`](/slides/python-net/ru/aspose.slides/ishapeframe/flip_v/) | Определяет, отражена ли рамка по вертикали.<br/>            Только для чтения [`NullableBool`](/slides/python-net/ru/aspose.slides/nullablebool). |
| [`rectangle`](/slides/python-net/ru/aspose.slides/ishapeframe/rectangle/) | Возвращает координаты рамки.<br/>            Только для чтения [`RectangleF`](/slides/python-net/ru/aspose.slides/rectanglef). |
