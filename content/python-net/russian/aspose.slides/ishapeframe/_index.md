## IShapeFrame класс

Представляет свойства кадра формы.

Тип IShapeFrame раскрывает следующие члены:

## Свойства

| Property | Description |
| :- | :- |
| [`x`](/slides/python-net/ru/aspose.slides/ishapeframe/x/) | Returns the X coordinate of the upper-left corner of a frame.<br/>            Только для чтения **float**. |
| [`y`](/slides/python-net/ru/aspose.slides/ishapeframe/y/) | Returns the Y coordinate of the upper-left corner of a frame.<br/>            Только для чтения **float**. |
| [`width`](/slides/python-net/ru/aspose.slides/ishapeframe/width/) | Returns the width of a frame.<br/>            Только для чтения **float**. |
| [`height`](/slides/python-net/ru/aspose.slides/ishapeframe/height/) | Returns the height of a frame.<br/>            Только для чтения **float**. |
| [`rotation`](/slides/python-net/ru/aspose.slides/ishapeframe/rotation/) | Returns the number of degrees a frame is rotated around the z-axis.<br/>            Положительное значение указывает на вращение по часовой стрелке; отрицательное — против часовой стрелки.<br/>            Только для чтения **float**. |
| [`center_x`](/slides/python-net/ru/aspose.slides/ishapeframe/center_x/) | Returns the X coordinate of a frame's center.<br/>            Только для чтения **float**. |
| [`center_y`](/slides/python-net/ru/aspose.slides/ishapeframe/center_y/) | Returns the Y coordinate of a frame's center.<br/>            Только для чтения **float**. |
| [`flip_h`](/slides/python-net/ru/aspose.slides/ishapeframe/flip_h/) | Determines whether a frame is flipped horizontally.<br/>            Только для чтения [`NullableBool`](/slides/python-net/ru/aspose.slides/nullablebool). |
| [`flip_v`](/slides/python-net/ru/aspose.slides/ishapeframe/flip_v/) | Determines whether a frame is flipped vertically.<br/>            Только для чтения [`NullableBool`](/slides/python-net/ru/aspose.slides/nullablebool). |
| [`rectangle`](/slides/python-net/ru/aspose.slides/ishapeframe/rectangle/) | Returns the coordinates of a frame.<br/>            Только для чтения **aspose.slides.RectangleF**. |
