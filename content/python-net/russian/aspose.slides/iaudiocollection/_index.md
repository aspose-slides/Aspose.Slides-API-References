## IAudioCollection класс

Представляет собой коллекцию встраиваемых аудиофайлов.

Тип IAudioCollection предоставляет следующие члены:

Получает элемент по указанному индексу.
            Только для чтения [`IAudio`](/slides/python-net/ru/aspose.slides/iaudio).
