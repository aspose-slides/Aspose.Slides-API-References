## IViewProperties класс

Свойства представления на уровне всей презентации.

Тип IViewProperties предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`last_view`](/slides/python-net/ru/aspose.slides/iviewproperties/last_view/) | Указывает режим просмотра, который был использован при последнем сохранении документа презентации.<br/>            Чтение/запись [`ViewType`](/slides/python-net/ru/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/ru/aspose.slides/iviewproperties/show_comments/) | Указывает, следует ли показывать комментарии к слайдам.<br/>            Чтение/запись [`NullableBool`](/slides/python-net/ru/aspose.slides/nullablebool). |
| [`slide_view_properties`](/slides/python-net/ru/aspose.slides/iviewproperties/slide_view_properties/) | Указывает общие свойства просмотра, связанные с режимом просмотра слайдов.<br/>            Только чтение [`ICommonSlideViewProperties`](/slides/python-net/ru/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/ru/aspose.slides/iviewproperties/notes_view_properties/) | Указывает общие свойства просмотра, связанные с режимом просмотра заметок.<br/>            Только чтение [`ICommonSlideViewProperties`](/slides/python-net/ru/aspose.slides/icommonslideviewproperties). |
| [`normal_view_properties`](/slides/python-net/ru/aspose.slides/iviewproperties/normal_view_properties/) | Представляет свойства обычного просмотра. Обычный просмотр состоит из<br/>            трёх областей содержимого: самого слайда, боковой области содержимого и нижней области содержимого.<br/>            Только чтение [`INormalViewProperties`](/slides/python-net/ru/aspose.slides/inormalviewproperties). |
| [`grid_spacing`](/slides/python-net/ru/aspose.slides/iviewproperties/grid_spacing/) | Возвращает или задаёт расстояние между линиями сетки, которое должно использоваться для сетки в документе презентации, в пунктах. <br/>            Чтение/запись **float**. |
