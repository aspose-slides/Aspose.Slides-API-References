## IFontFallBackRulesCollection класс

Представляет коллекцию правил FontFallBack, определённых пользователем

Тип IFontFallBackRulesCollection раскрывает следующие члены:

Получает правило по указанному индексу.
            Только для чтения [`IFontFallBackRule`](/slides/python-net/ru/aspose.slides/ifontfallbackrule).
