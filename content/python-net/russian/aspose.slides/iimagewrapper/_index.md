## IImageWrapper класс

Обёртка System.Drawing.Image для COM-интерфейса.

Тип IImageWrapper раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`image_source`](/slides/python-net/ru/aspose.slides/iimagewrapper/image_source/) | Получает изображение<br/>            Только для чтения **aspose.slides.Image**. |
| [`size`](/slides/python-net/ru/aspose.slides/iimagewrapper/size/) | Получает ширину и высоту изображения в пикселях<br/>            Только для чтения [`IImageWrapper.size`](/slides/python-net/ru/aspose.slides/iimagewrapper/size). |

| Метод | Описание |
