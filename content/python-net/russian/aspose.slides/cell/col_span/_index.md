## col_span свойство
Возвращает количество столбцов сетки в таблице-сетке родительской таблицы
            которые будут охвачены текущей ячейкой. Это свойство позволяет ячейкам
            получать вид слияния, поскольку они охватывают вертикальные границы
            других ячеек в таблице.
            Только для чтения **int**.
