## z_order_position свойство
Возвращает позицию фигуры в порядке z-слоя.
            Shapes[0] возвращает фигуру, находящуюся в задней части порядка z-слоя,
            а Shapes[Shapes.Count - 1] возвращает фигуру, находящуюся в передней части порядка z-слоя.
            Только для чтения **int**.
