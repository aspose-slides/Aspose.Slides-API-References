## IMasterSlideCollection класс

Представляет коллекцию шаблонных слайдов.

Тип IMasterSlideCollection раскрывает следующие члены:

Получает элемент с указанным индексом.
            Только для чтения [`IMasterSlide`](/slides/python-net/ru/aspose.slides/imasterslide).
