## compare_to(self, obj) {#any}
Сравнивает текущий экземпляр с другим объектом того же типа.

### Возвращаемое значение

32-битное целое число, указывающее относительный порядок сравниваемых объектов.
            Значение возвращаемого результата имеет следующие значения:
            
*  < 0 – Этот экземпляр меньше, чем obj. = 0 – Этот экземпляр равен obj. > 0 – Этот экземпляр больше, чем obj.

*  < 0 – Этот экземпляр меньше, чем obj. = 0 – Этот экземпляр равен obj. > 0 – Этот экземпляр больше, чем obj.

*  < 0 – Этот экземпляр меньше, чем obj. = 0 – Этот экземпляр равен obj. > 0 – Этот экземпляр больше, чем obj.
