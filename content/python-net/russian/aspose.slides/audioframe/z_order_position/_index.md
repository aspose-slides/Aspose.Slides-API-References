## z_order_position свойство
Возвращает позицию фигуры в z-order.
            Shapes[0] возвращает фигуру, находящуюся сзади в z-order,
            а Shapes[Shapes.Count - 1] возвращает фигуру, находящуюся спереди в z-order.
            Только для чтения **int**.
