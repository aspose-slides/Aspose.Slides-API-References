## effect_format свойство
Returns the EffectFormat object which contains pixel effects applied to a shape.
            Примечание: can return None for certain types of shapes which don't have effect properties.
            Только для чтения [`IEffectFormat`](/slides/python-net/ru/aspose.slides/ieffectformat).
