## свойство fill_format
Returns the FillFormat object that contains fill formatting properties for a shape.
            Примечание: can return None for certain types of shapes which don't have fill properties.
            Только для чтения [`IFillFormat`](/slides/python-net/ru/aspose.slides/ifillformat).
