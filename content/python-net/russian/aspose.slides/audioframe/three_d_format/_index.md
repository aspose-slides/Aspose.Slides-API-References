## three_d_format свойство
Возвращает объект ThreeDFormat, который представляет свойства 3d-эффекта для фигуры.
            Примечание: может возвращать None для некоторых типов фигур, которые не имеют 3d-свойств.
            Только для чтения [`IThreeDFormat`](/slides/python-net/ru/aspose.slides/ithreedformat).
