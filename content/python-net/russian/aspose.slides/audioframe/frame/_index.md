## свойство frame
Возвращает или задает свойства рамки фигуры.
            Read/write [`IShapeFrame`](/slides/python-net/ru/aspose.slides/ishapeframe).

### Примечания

Значение каждого свойства возвращенного экземпляра IShapeFrame не 
            является undefined (не NaN и не NotDefined).
Значение каждого свойства присвоенного экземпляра IShapeFrame должно быть не 
            undefined (не NaN и не NotDefined).
Вы можете установить значения undefined для свойств экземпляра RawFrame.

```python
@property
def frame(self):
    ...

@frame.setter
def frame(self, value):
    ...
```
