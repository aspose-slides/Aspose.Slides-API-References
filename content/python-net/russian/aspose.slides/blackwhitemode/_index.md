## BlackWhiteMode перечисление

Определяет, как цветная фигура должна быть преобразована в черно-белую.

Тип BlackWhiteMode содержит следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| NOT_DEFINED | Свойство не задано |
| COLOR | Объект отображается с обычной окраской |
| AUTOMATIC | Объект отображается с автоматической окраской |
| GRAY | Объект отображается с серой окраской |
| LIGHT_GRAY | Объект отображается со светло-серой окраской |
| INVERSE_GRAY | Объект отображается с инвертированной серой окраской |
| GRAY_WHITE | Объект отображается с серой и белой окраской |
| BLACK_GRAY | Объект отображается с черной и серой окраской |
| BLACK_WHITE | Объект отображается с черной и белой окраской |
| BLACK | Объект отображается только с черной окраской |
| WHITE | Объект отображается с белой окраской |
| HIDDEN | Объект не отображается |
