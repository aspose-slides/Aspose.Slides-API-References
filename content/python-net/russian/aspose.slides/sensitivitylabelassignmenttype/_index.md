## SensitivityLabelAssignmentType enumeration

Представляет метод назначения метки чувствительности.

Тип SensitivityLabelAssignmentType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| STANDARD | Используется для любой метки чувствительности, которая не была применена пользователем напрямую.<br/>Это включает любые метки по умолчанию, автоматически применяемые метки. |
| PRIVILEGED | Используется для любой метки чувствительности, которая была применена пользователем напрямую.<br/>Это включает любые вручную применённые метки чувствительности, а также рекомендованные<br/>или обязательные метки, либо любую функцию, где пользователь решает, какую метку чувствительности применить. |
