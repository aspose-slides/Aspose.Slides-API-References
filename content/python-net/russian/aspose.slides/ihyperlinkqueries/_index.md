## IHyperlinkQueries класс

Обеспечивает простой доступ к содержащимся гиперссылкам.

Тип IHyperlinkQueries раскрывает следующие члены:

## Методы

| Метод | Описание |
| :- | :- |
| [`get_hyperlink_clicks(self)`](/slides/python-net/ru/aspose.slides/ihyperlinkqueries/get_hyperlink_clicks/#) | Получить все подобъекты IHyperlinkContainer, которые содержат не None HyperlinkClick.<br/>            С данным объектом IHyperlinkContainer вы можете управлять его гиперссылкой (читать, обновлять или удалять). См. интерфейс IHyperlinkContainer. |
| [`get_hyperlink_mouse_overs(self)`](/slides/python-net/ru/aspose.slides/ihyperlinkqueries/get_hyperlink_mouse_overs/#) | Получить все подобъекты IHyperlinkContainer, которые содержат не None HyperlinkMouseOver.<br/>            С данным объектом IHyperlinkContainer вы можете управлять его гиперссылкой (читать, обновлять или удалять). См. интерфейс IHyperlinkContainer. |
| [`get_any_hyperlinks(self)`](/slides/python-net/ru/aspose.slides/ihyperlinkqueries/get_any_hyperlinks/#) | Получить все подобъекты IHyperlinkContainer, которые содержат не None HyperlinkMouseOver.<br/>            С данным объектом IHyperlinkContainer вы можете управлять его гиперссылкой (читать, обновлять или удалять). См. интерфейс IHyperlinkContainer. |
| [`remove_all_hyperlinks(self)`](/slides/python-net/ru/aspose.slides/ihyperlinkqueries/remove_all_hyperlinks/#) | Удаляет все содержащиеся гиперссылки HyperlinkClick и HyperlinkMouseOver (во всех подобъектах IHyperlinkContainer). |
