## ITextStyle класс

Свойства форматирования стиля текста.

Тип ITextStyle предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`default_paragraph_format`](/slides/python-net/ru/aspose.slides/itextstyle/default_paragraph_format/) | Свойства абзаца по умолчанию.<br/>            Только для чтения [`IParagraphFormat`](/slides/python-net/ru/aspose.slides/iparagraphformat). |

## Методы

| Метод | Описание |
| :- | :- |
| [`get_level(self, index)`](/slides/python-net/ru/aspose.slides/itextstyle/get_level/#int) | Если уровень стиля существует, возвращает его, в противном случае возвращает None. |
| [`get_effective(self)`](/slides/python-net/ru/aspose.slides/itextstyle/get_effective/#) | Получает данные эффективного форматирования стиля текста с применённым наследованием. |
