## IEffectFormatEffectiveData класс

Неизменяемый объект, содержащий свойства эффективного форматирования эффектов.

Тип IEffectFormatEffectiveData раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`is_no_effects`](/slides/python-net/ru/aspose.slides/ieffectformateffectivedata/is_no_effects/) | Возвращает true, если все эффекты отключены (как только что созданный объект EffectFormat по умолчанию).<br/>            Только для чтения **bool**. |
| [`blur_effect`](/slides/python-net/ru/aspose.slides/ieffectformateffectivedata/blur_effect/) | Эффект размытия.<br/>            Только для чтения [`IBlurEffectiveData`](/slides/python-net/ru/aspose.slides.effects/iblureffectivedata). |
| [`fill_overlay_effect`](/slides/python-net/ru/aspose.slides/ieffectformateffectivedata/fill_overlay_effect/) | Эффект наложения заливки.<br/>            Только для чтения [`IFillOverlayEffectiveData`](/slides/python-net/ru/aspose.slides.effects/ifilloverlayeffectivedata). |
| [`glow_effect`](/slides/python-net/ru/aspose.slides/ieffectformateffectivedata/glow_effect/) | Эффект свечения.<br/>            Только для чтения [`IGlowEffectiveData`](/slides/python-net/ru/aspose.slides.effects/igloweffectivedata). |
| [`inner_shadow_effect`](/slides/python-net/ru/aspose.slides/ieffectformateffectivedata/inner_shadow_effect/) | Внутренняя тень.<br/>            Только для чтения [`IInnerShadowEffectiveData`](/slides/python-net/ru/aspose.slides.effects/iinnershadoweffectivedata). |
| [`outer_shadow_effect`](/slides/python-net/ru/aspose.slides/ieffectformateffectivedata/outer_shadow_effect/) | Внешняя тень.<br/>            Только для чтения [`IOuterShadowEffectiveData`](/slides/python-net/ru/aspose.slides.effects/ioutershadoweffectivedata). |
| [`preset_shadow_effect`](/slides/python-net/ru/aspose.slides/ieffectformateffectivedata/preset_shadow_effect/) | Предустановленная тень.<br/>            Только для чтения [`IPresetShadowEffectiveData`](/slides/python-net/ru/aspose.slides.effects/ipresetshadoweffectivedata). |
| [`reflection_effect`](/slides/python-net/ru/aspose.slides/ieffectformateffectivedata/reflection_effect/) | Отражение.<br/>            Только для чтения [`IReflectionEffectiveData`](/slides/python-net/ru/aspose.slides.effects/ireflectioneffectivedata). |
| [`soft_edge_effect`](/slides/python-net/ru/aspose.slides/ieffectformateffectivedata/soft_edge_effect/) | Мягкий край.<br/>            Только для чтения [`ISoftEdgeEffectiveData`](/slides/python-net/ru/aspose.slides.effects/isoftedgeeffectivedata). |


### Примечания

Этот интерфейс используется вместе с интерфейсом [`IEffectFormat`](/slides/python-net/ru/aspose.slides/ieffectformat) для возврата эффективных значений форматирования с учётом наследования.
