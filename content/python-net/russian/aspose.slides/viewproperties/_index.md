## ViewProperties класс

Свойства представления, применяемые ко всей презентации.

Тип ViewProperties раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`last_view`](/slides/python-net/ru/aspose.slides/viewproperties/last_view/) | Указывает режим просмотра, который использовался при последнем сохранении документа презентации.<br/>            Чтение/запись [`ViewType`](/slides/python-net/ru/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/ru/aspose.slides/viewproperties/show_comments/) | Указывает, следует ли показывать комментарии к слайдам.<br/>            Чтение/запись [`NullableBool`](/slides/python-net/ru/aspose.slides/nullablebool). |
| [`normal_view_properties`](/slides/python-net/ru/aspose.slides/viewproperties/normal_view_properties/) | Представляет свойства обычного просмотра. Обычный просмотр состоит из<br/>            трех областей содержимого: самого слайда, боковой области содержимого и нижней области содержимого.<br/>            Только для чтения [`INormalViewProperties`](/slides/python-net/ru/aspose.slides/inormalviewproperties). |
| [`slide_view_properties`](/slides/python-net/ru/aspose.slides/viewproperties/slide_view_properties/) | Указывает общие свойства просмотра, связанные с режимом просмотра слайда.<br/>            Только для чтения [`ICommonSlideViewProperties`](/slides/python-net/ru/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/ru/aspose.slides/viewproperties/notes_view_properties/) | Указывает общие свойства просмотра, связанные с режимом просмотра заметок.<br/>            Только для чтения [`ICommonSlideViewProperties`](/slides/python-net/ru/aspose.slides/icommonslideviewproperties). |
| [`grid_spacing`](/slides/python-net/ru/aspose.slides/viewproperties/grid_spacing/) | Возвращает или задает расстояние сетки, которое должно использоваться для сетки, лежащей в основе документа презентации, в пунктах.<br/>            Чтение/запись **float**. |
