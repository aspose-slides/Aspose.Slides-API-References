## ResourceLoadingAction перечисление

Указывает режим загрузки внешних ресурсов.

Тип ResourceLoadingAction предоставляет следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| DEFAULT | Aspose.Slides будет загружать внешний ресурс как обычно. |
| SKIP | Aspose.Slides пропустит загрузку внешнего ресурса. Для изображения будет сохранена только ссылка без данных. |
| USER_PROVIDED | Aspose.Slides будет использовать массив байтов, предоставленный пользователем в **Aspose.Slides.IResourceLoadingArgs.SetData(Syste** в качестве данных изображения. |
