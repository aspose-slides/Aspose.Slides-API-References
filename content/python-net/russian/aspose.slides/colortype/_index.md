## Перечисление ColorType

Представляет различные режимы цвета.

Тип ColorType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| NOT_DEFINED | Цвет не определён вовсе. |
| RGB | Стандартный 24-битный цвет RGB. |
| RGB_PERCENTAGE | Цвет RGB высокой точности. |
| HSL | Цвет HSL высокой точности. |
| SCHEME | Цвет схемы. |
| SYSTEM | Системный цвет. |
| PRESET | Предустановленный цвет. |
