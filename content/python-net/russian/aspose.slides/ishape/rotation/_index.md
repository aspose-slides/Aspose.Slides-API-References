## rotation свойство
Возвращает или задает количество градусов, на которое указанная фигура вращается вокруг
            оси z. Положительное значение указывает на вращение по часовой стрелке; отрицательное значение
            указывает на вращение против часовой стрелки.
            Чтение/запись **float**.

### Примечания

Возвращаемое значение всегда определено (не является float.NaN).
            Назначаемое значение должно быть определено (не float.NaN). Вы можете задавать неопределенные значения для свойств экземпляра RawFrame.
