## свойство frame
Возвращает или задает свойства кадра формы.
            Чтение/запись [`IShapeFrame`](/slides/python-net/ru/aspose.slides/ishapeframe).

### Примечания

Значение каждого свойства возвращённого экземпляра IShapeFrame не 
            undefined (не NaN и не NotDefined).
Значение каждого свойства присвоенного экземпляра IShapeFrame должно быть не 
            undefined (не должно быть NaN или NotDefined).
Вы можете задавать значения undefined для свойств экземпляра RawFrame.

### Определение:
```python
@property
def frame(self):
    ...

@frame.setter
def frame(self, value):
    ...
```
