## parent_group свойство
Returns parent GroupShape object if shape is grouped. Otherwise returns None.
            Только для чтения [`IGroupShape`](/slides/python-net/ru/aspose.slides/igroupshape).


### Примечания

Свойство [`IShape.is_grouped`](/slides/python-net/ru/aspose.slides/ishape/is_grouped) определяет, сгруппирована ли фигура.
