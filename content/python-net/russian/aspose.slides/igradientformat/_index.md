## IGradientFormat класс

Представляет формат градиента.

Тип IGradientFormat раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`tile_flip`](/slides/python-net/ru/aspose.slides/igradientformat/tile_flip/) | Возвращает или задаёт режим отражения для градиента.<br/>            Чтение/запись [`TileFlip`](/slides/python-net/ru/aspose.slides/tileflip). |
| [`gradient_direction`](/slides/python-net/ru/aspose.slides/igradientformat/gradient_direction/) | Возвращает или задаёт стиль градиента.<br/>            Чтение/запись [`GradientDirection`](/slides/python-net/ru/aspose.slides/gradientdirection). |
| [`linear_gradient_angle`](/slides/python-net/ru/aspose.slides/igradientformat/linear_gradient_angle/) | Возвращает или задаёт угол градиента.<br/>            Чтение/запись **float**. |
| [`linear_gradient_scaled`](/slides/python-net/ru/aspose.slides/igradientformat/linear_gradient_scaled/) | Определяет, масштабируется ли градиент.<br/>            Чтение/запись [`NullableBool`](/slides/python-net/ru/aspose.slides/nullablebool). |
| [`gradient_shape`](/slides/python-net/ru/aspose.slides/igradientformat/gradient_shape/) | Возвращает или задаёт форму градиента.<br/>            Чтение/запись [`GradientShape`](/slides/python-net/ru/aspose.slides/gradientshape). |
| [`gradient_stops`](/slides/python-net/ru/aspose.slides/igradientformat/gradient_stops/) | Возвращает коллекцию остановок градиента.<br/>            Только для чтения [`IGradientStopCollection`](/slides/python-net/ru/aspose.slides/igradientstopcollection). |
