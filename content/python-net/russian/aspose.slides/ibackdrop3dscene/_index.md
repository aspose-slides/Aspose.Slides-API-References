## IBackdrop3DScene класс

Определяет плоскость, в которой эффекты, такие как сияние и тень, применяются относительно формы, к которой они применяются.

Тип IBackdrop3DScene раскрывает следующие члены:

## Свойства

| Property | Description |
| :- | :- |
| [`normal_vector`](/slides/python-net/ru/aspose.slides/ibackdrop3dscene/normal_vector/) | Возвращает или задает нормальный вектор. Точнее, этот атрибут определяет вектор<br/>            перпендикулярный поверхности плоскости фона. Вектор представлен массивом из 3 значений float,<br/>            определяющих координаты X, Y и Z.<br/>            Чтение/запись **float**[]. |
| [`anchor_point`](/slides/python-net/ru/aspose.slides/ibackdrop3dscene/anchor_point/) | Возвращает или задает точку в 3-мерном пространстве. Эта точка фиксирует плоскость фона в пространстве.<br/>            Трёхмерная точка представлена массивом из 3 значений float, определяющих координаты X, Y и Z.<br/>            Чтение/запись **float**[]. |
| [`up_vector`](/slides/python-net/ru/aspose.slides/ibackdrop3dscene/up_vector/) | Возвращает или задает вектор, указывающий вверх. Точнее, этот атрибут определяет вектор,<br/>            указывающий вверх относительно поверхности плоскости фона. Вектор представлен массивом<br/>            из 3 значений float, определяющих координаты X, Y и Z.<br/>            Чтение/запись **float**[]. |
