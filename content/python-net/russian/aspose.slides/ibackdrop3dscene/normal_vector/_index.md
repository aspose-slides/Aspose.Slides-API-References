## normal_vector свойство
Возвращает или задает нормальный вектор. Точнее, этот атрибут определяет вектор
            перпендикулярный плоскости фона. Вектор представлен массивом из 3 значений float,
            определяющих координаты X, Y и Z.
            Чтение/запись **float**[].
