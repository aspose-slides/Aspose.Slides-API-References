## PortionCollection класс

Представляет коллекцию частей.

Тип PortionCollection открывает доступ к следующим членам:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`count`](/slides/python-net/ru/aspose.slides/portioncollection/count/) | Получает количество элементов, фактически содержащихся в коллекции.<br/>            Только для чтения **int**. |
| [`is_read_only`](/slides/python-net/ru/aspose.slides/portioncollection/is_read_only/) | Получает значение, указывающее, является ли **System.Collections.Generic.ICollection`1** только для чтения.<br/>            Только для чтения **bool**. |

Получает элемент по указанному индексу.
