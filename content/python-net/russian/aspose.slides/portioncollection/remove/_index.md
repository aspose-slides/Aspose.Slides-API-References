## remove(self, item) {#iportion}
Удаляет первое вхождение конкретного объекта из **System.Collections.Generic.ICollection`1**.

### Возвращаемое значение

true, если `item` был успешно удалён из **System.Collections.Generic.ICollection`1**; иначе — false. Этот метод также возвращает false, если `item` не найден в исходной **System.Collections.Generic.ICollection`1**.



```python
def remove(self, item):
    ...
```


| Параметр | Тип | Описание |
| :- | :- | :- |
| item | [`IPortion`](/slides/python-net/ru/aspose.slides/iportion) | Объект, который необходимо удалить из **System.Collections.Generic.ICollection`1**. |

### Исключения

| Исключение | Описание |
| :- | :- |
| **RuntimeError(Proxy error(NotSupportedException))** | **System.Collections.Generic.ICollection`1** только для чтения. |
