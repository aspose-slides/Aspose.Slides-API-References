## Перечисление NumberedBulletStyle

Представляет стиль нумерованных маркеров.

Тип NumberedBulletStyle раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| NOT_DEFINED | Не определено. |
| BULLET_ALPHA_LC_PERIOD | Строчные буквенные символы с точкой. Пример: a., b., c., ... |
| BULLET_ALPHA_UC_PERIOD | Прописные буквенные символы с точкой. Пример: A., B., C., ... |
| BULLET_ARABIC_PAREN_RIGHT | Арабские цифры с закрывающей скобкой. Пример: 1), 2), 3), ... |
| BULLET_ARABIC_PERIOD | Арабские цифры с точкой. Пример: 1., 2., 3., ... |
| BULLET_ROMAN_LC_PAREN_BOTH | Строчные римские цифры с обеими скобками. Пример: (i), (ii), (iii), ... |
| BULLET_ROMAN_LC_PAREN_RIGHT | Строчные римские цифры с закрывающей скобкой. Пример: i), ii), iii), ... |
| BULLET_ROMAN_LC_PERIOD | Строчные римские цифры с точкой. Пример: i., ii., iii., ... |
| BULLET_ROMAN_UC_PERIOD | Прописные римские цифры с точкой. Пример: I., II., III., ... |
| BULLET_ALPHA_LC_PAREN_BOTH | Строчные буквенные символы с обеими скобками. Пример: (a), (b), (c), ... |
| BULLET_ALPHA_LC_PAREN_RIGHT | Строчные буквенные символы с закрывающей скобкой. Пример: a), b), c), ... |
| BULLET_ALPHA_UC_PAREN_BOTH | Прописные буквенные символы с обеими скобками. Пример: (A), (B), (C), ... |
| BULLET_ALPHA_UC_PAREN_RIGHT | Прописные буквенные символы с закрывающей скобкой. Пример: A), B), C), ... |
| BULLET_ARABIC_PAREN_BOTH | Арабские цифры с обеими скобками. Пример: (1), (2), (3), ... |
| BULLET_ARABIC_PLAIN | Арабские цифры. Пример: 1, 2, 3, ... |
| BULLET_ROMAN_UC_PAREN_BOTH | Прописные римские цифры с обеими скобками. Пример: (I), (II), (III), ... |
| BULLET_ROMAN_UC_PAREN_RIGHT | Прописные римские цифры с закрывающей скобкой. Пример: I), II), III), ... |
| BULLET_SIMP_CHIN_PLAIN | Упрощённый китайский без точки. |
| BULLET_SIMP_CHIN_PERIOD | Упрощённый китайский с точкой. |
| BULLET_CIRCLE_NUM_DB_PLAIN | Двухбайтовый окружной номер для значений до 10, от 11 — арабские цифры. |
| BULLET_CIRCLE_NUM_WD_WHITE_PLAIN | Номер, окрашенный в цвет текста, с окружностью того же цвета (Wingdings, белые круглые числа). От 11 — арабские цифры. |
| BULLET_CIRCLE_NUM_WD_BLACK_PLAIN | Номер тёмного цвета с окружным фоном обычного цвета текста (Wingdings, чёрные круглые числа). |
| BULLET_TRAD_CHIN_PLAIN | Традиционный китайский без точки. |
| BULLET_TRAD_CHIN_PERIOD | Традиционный китайский с точкой. |
| BULLET_ARABIC_ALPHA_DASH | Арабские буквенные символы с тире. |
| BULLET_ARABIC_ABJAD_DASH | Арабские абджадные алфавиты с тире. |
| BULLET_HEBREW_ALPHA_DASH | Ивритские буквенные символы с тире. |
| BULLET_KANJI_KOREAN_PLAIN | Японские/корейские цифры без точки. |
| BULLET_KANJI_KOREAN_PERIOD | Японские/корейские цифры с точкой. |
| BULLET_ARABIC_DB_PLAIN | Двухбайтовая арабская нумерация (без пунктуации). |
| BULLET_ARABIC_DB_PERIOD | Двухбайтовая арабская нумерация с двухбайтовой точкой. |
| BULLET_THAI_ALPHA_PERIOD | Тайский алфавит с точкой. |
| BULLET_THAI_ALPHA_PAREN_RIGHT | Тайский алфавит с закрывающей скобкой. |
| BULLET_THAI_ALPHA_PAREN_BOTH | Тайский алфавит с обоими скобками. |
| BULLET_THAI_NUM_PERIOD | Тайские цифры с точкой. |
| BULLET_THAI_NUM_PAREN_RIGHT | Тайские цифры с закрывающей скобкой. |
| BULLET_THAI_NUM_PAREN_BOTH | Тайские цифры с обоими скобками. |
| BULLET_HINDI_ALPHA_PERIOD | Хинди алфавит с точкой — гласные. |
| BULLET_HINDI_NUM_PERIOD | Хинди цифры с точкой. |
| BULLET_KANJI_SIMP_CHIN_DB_PERIOD | Кандзи простой китайский с двойным байтовым периодом. |
| BULLET_HINDI_NUM_PAREN_RIGHT | Хинди цифры с закрывающей скобкой. |
| BULLET_HINDI_ALPHA_1_PERIOD | Хинди алфавит с точкой — согласные. |
