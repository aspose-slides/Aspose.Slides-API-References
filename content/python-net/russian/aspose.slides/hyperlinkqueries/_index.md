## HyperlinkQueries класс

Обеспечивает простой доступ к содержащимся гиперссылкам.

Тип HyperlinkQueries раскрывает следующие члены:

## Методы

| Метод | Описание |
| :- | :- |
| [`get_hyperlink_clicks(self)`](/slides/python-net/ru/aspose.slides/hyperlinkqueries/get_hyperlink_clicks/#) | Получить все подконтейнеры IHyperlinkContainer, которые содержат не None HyperlinkClick.<br/>            С данным объектом IHyperlinkContainer вы можете управлять его гиперссылкой (читать, обновлять или удалять). См. интерфейс IHyperlinkContainer. |
| [`get_hyperlink_mouse_overs(self)`](/slides/python-net/ru/aspose.slides/hyperlinkqueries/get_hyperlink_mouse_overs/#) | Получить все подконтейнеры IHyperlinkContainer, которые содержат не None HyperlinkMouseOver.<br/>            С данным объектом IHyperlinkContainer вы можете управлять его гиперссылкой (читать, обновлять или удалять). См. интерфейс IHyperlinkContainer. |
| [`get_any_hyperlinks(self)`](/slides/python-net/ru/aspose.slides/hyperlinkqueries/get_any_hyperlinks/#) | Получить все подконтейнеры IHyperlinkContainer, которые содержат не None HyperlinkMouseOver.<br/>            С данным объектом IHyperlinkContainer вы можете управлять его гиперссылкой (читать, обновлять или удалять). См. интерфейс IHyperlinkContainer. |
| [`remove_all_hyperlinks(self)`](/slides/python-net/ru/aspose.slides/hyperlinkqueries/remove_all_hyperlinks/#) | Удаляет все содержащиеся гиперссылки HyperlinkClick и HyperlinkMouseOver (во всех подконтейнерах IHyperlinkContainer). |
