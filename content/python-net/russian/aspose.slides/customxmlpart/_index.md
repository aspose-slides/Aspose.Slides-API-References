## Класс CustomXmlPart

Представляет пользовательскую часть XML.

Тип CustomXmlPart раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`xml_data`](/slides/python-net/ru/aspose.slides/customxmlpart/xml_data/) | Возвращает или задает данные xml.<br/>            Чтение/запись **int**[].<br/>            значение равно `None`. значение пусто или xml-данные недействительны. |
| [`xml_as_string`](/slides/python-net/ru/aspose.slides/customxmlpart/xml_as_string/) | Возвращает или задает данные xml в виде строки UTF-8.<br/>            Чтение/запись **str**.<br/>            значение равно `None`. значение пусто или xml-данные недействительны. |
| [`item_id`](/slides/python-net/ru/aspose.slides/customxmlpart/item_id/) | Указывает глобальный уникальный идентификатор (GUID), который однозначно идентифицирует единственную пользовательскую часть XML <br/>            в документе Office Open XML.<br/>            Только чтение **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/ru/aspose.slides/customxmlpart/namespace_schemas/) | Возвращает набор схем XML, связанных с пользовательской частью XML.<br/>            Только чтение **str**[]. |

## Методы

| Метод | Описание |
| :- | :- |
| [`remove(self)`](/slides/python-net/ru/aspose.slides/customxmlpart/remove/#) | Удаляет пользовательскую часть XML из презентации. |
