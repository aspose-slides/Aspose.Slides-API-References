## Перечисление ZoomLayout

Указывает сводный макет Zoom.

Тип ZoomLayout раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| GRID_LAYOUT | Указывает, что макет является сеточным для списка объектов. |
| FIXED_LAYOUT | Указывает макет с пользовательским позиционированием Zoom. |
