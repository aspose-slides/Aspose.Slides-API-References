## write(self, buffer, offset, count) {#bytes-int-int}
записывает последовательность байтов в текущий поток и перемещает текущую позицию в этом потоке на количество записанных байтов.


```python
def write(self, buffer, offset, count):
    ...
```


| Параметр | Тип | Описание |
| :- | :- | :- |
| buffer | **bytes** | Массив байтов **int**[] |
| offset | **int** | Нулевое байтовое смещение в buffer, с которого начинается копирование байтов в текущий поток **int** |
| count | **int** | Количество байтов, которое будет записано в текущий поток **int** |
