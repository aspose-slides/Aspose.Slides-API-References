## MasterSlideCollection класс

Представляет коллекцию мастер-слайдов.

Тип MasterSlideCollection раскрывает следующие члены:

Получает элемент по указанному индексу.
            Только для чтения [`MasterSlide`](/slides/python-net/ru/aspose.slides/masterslide).
