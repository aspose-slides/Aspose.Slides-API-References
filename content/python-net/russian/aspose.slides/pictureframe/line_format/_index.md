## line_format свойство
Возвращает объект LineFormat, содержащий свойства форматирования линии для shape.
            Примечание: может вернуть None для некоторых типов shapes, у которых нет line properties.
            Только для чтения [`ILineFormat`](/slides/python-net/ru/aspose.slides/ilineformat).
