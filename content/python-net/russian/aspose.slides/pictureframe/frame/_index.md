## свойство frame
Возвращает или задает свойства рамки фигуры.
Чтение/запись [`IShapeFrame`](/slides/python-net/ru/aspose.slides/ishapeframe).

### Замечания

Значение каждого свойства возвращенного экземпляра IShapeFrame не является 
            undefined (is not NaN or NotDefined).
Значение каждого свойства назначенного экземпляра IShapeFrame должно быть не 
            undefined (must be not NaN or NotDefined).
Можно установить значения undefined для свойств экземпляра RawFrame.

    ...
