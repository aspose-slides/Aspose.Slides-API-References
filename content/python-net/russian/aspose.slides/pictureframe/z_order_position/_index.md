## z_order_position свойство
Возвращает позицию фигуры в z-порядке.
            Shapes[0] возвращает фигуру, находящуюся в задней части z-order,
            а Shapes[Shapes.Count - 1] возвращает фигуру, находящуюся в передней части z-order.
            Только для чтения **int**.
