## FontSources класс

Предоставляет файловые и память-ориентированные источники для внешних шрифтов.

Тип FontSources раскрывает следующие члены:

## Конструкторы

| Конструктор | Описание |
| :- | :- |
| [`__init__(self)`](/slides/python-net/ru/aspose.slides/fontsources/__init__/#) | Создаёт новые параметры шрифта по умолчанию. |

## Свойства

| Свойство | Описание |
| :- | :- |
| [`font_folders`](/slides/python-net/ru/aspose.slides/fontsources/font_folders/) | Папки, содержащие файлы шрифтов.<br/>            Все файлы шрифтов, находящиеся в этих папках, включаются в коллекцию. Папки, которые просматриваются рекурсивно. |
| [`memory_fonts`](/slides/python-net/ru/aspose.slides/fontsources/memory_fonts/) | Коллекция шрифтов, представленных в виде массивов байтов. |
