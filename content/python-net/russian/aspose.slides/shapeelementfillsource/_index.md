## ShapeElementFillSource перечисление

Представляет, как элемент формы должен быть заполнен.

Тип ShapeElementFillSource раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| NO_FILL | Не заполнять примитив. |
| SHAPE | Использовать заливку формы. |
| LIGHTEN | Использовать осветленную заливку формы. |
| LIGHTEN_LESS | Использовать менее осветленную заливку формы. |
| DARKEN | Использовать затемнённую заливку формы. |
| DARKEN_LESS | Использовать менее затемнённую заливку формы. |
