## IThreeDFormat класс

Представляет 3-D свойства.

Тип IThreeDFormat раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`contour_width`](/slides/python-net/ru/aspose.slides/ithreedformat/contour_width/) | Возвращает или задает ширину 3D контура.<br/>            Чтение/запись **float**. |
| [`extrusion_height`](/slides/python-net/ru/aspose.slides/ithreedformat/extrusion_height/) | Возвращает или задает высоту эффекта экструдирования.<br/>            Чтение/запись **float**. |
| [`depth`](/slides/python-net/ru/aspose.slides/ithreedformat/depth/) | Возвращает или задает глубину 3D фигуры.<br/>            Чтение/запись **float**. |
| [`bevel_top`](/slides/python-net/ru/aspose.slides/ithreedformat/bevel_top/) | Возвращает или задает тип верхней 3D фаски.<br/>            Только чтение [`IShapeBevel`](/slides/python-net/ru/aspose.slides/ishapebevel). |
| [`bevel_bottom`](/slides/python-net/ru/aspose.slides/ithreedformat/bevel_bottom/) | Возвращает или задает тип нижней 3D фаски.<br/>            Только чтение [`IShapeBevel`](/slides/python-net/ru/aspose.slides/ishapebevel). |
| [`contour_color`](/slides/python-net/ru/aspose.slides/ithreedformat/contour_color/) | Возвращает или задает цвет контура.<br/>            Только чтение [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`extrusion_color`](/slides/python-net/ru/aspose.slides/ithreedformat/extrusion_color/) | Возвращает или задает цвет экструдирования.<br/>            Только чтение [`IColorFormat`](/slides/python-net/ru/aspose.slides/icolorformat). |
| [`camera`](/slides/python-net/ru/aspose.slides/ithreedformat/camera/) | Возвращает или задает параметры камеры.<br/>            Только чтение [`ICamera`](/slides/python-net/ru/aspose.slides/icamera). |
| [`light_rig`](/slides/python-net/ru/aspose.slides/ithreedformat/light_rig/) | Возвращает или задает тип света.<br/>            Только чтение [`ILightRig`](/slides/python-net/ru/aspose.slides/ilightrig). |
| [`material`](/slides/python-net/ru/aspose.slides/ithreedformat/material/) | Возвращает или задает тип материала.<br/>            Чтение/запись [`MaterialPresetType`](/slides/python-net/ru/aspose.slides/materialpresettype). |
