## Свойство рамки
Возвращает или задает свойства рамки формы.
            Read/write [`IShapeFrame`](/slides/python-net/ru/aspose.slides/ishapeframe).

### Замечания

Значение каждого свойства возвращаемого экземпляра IShapeFrame не является 
            undefined (не NaN или NotDefined).
            Значение каждого свойства присвоенного экземпляра IShapeFrame должно быть не 
            undefined (должно быть не NaN или NotDefined).
            Вы можете задавать undefined значения для свойств экземпляра RawFrame.
