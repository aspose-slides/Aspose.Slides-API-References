## fill_format свойство
Возвращает объект FillFormat, который содержит свойства форматирования заливки для фигуры.
            Примечание: может вернуть None для некоторых типов фигур, у которых нет свойств заливки.
            Только для чтения [`IFillFormat`](/slides/python-net/ru/aspose.slides/ifillformat).
