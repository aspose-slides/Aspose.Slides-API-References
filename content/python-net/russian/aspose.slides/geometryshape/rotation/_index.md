## rotation свойство
Возвращает или задаёт количество градусов, на которое указанная фигура поворачивается вокруг
            оси z. Положительное значение указывает на вращение по часовой стрелке; отрицательное значение
            указывает на вращение против часовой стрелки.
            Чтение/запись **float**.


### Примечания

Возвращаемое значение всегда определено (не является float.NaN).
            Присваиваемое значение должно быть определено (не float.NaN). Вы можете установить неопределённые значения для свойств экземпляра RawFrame.
