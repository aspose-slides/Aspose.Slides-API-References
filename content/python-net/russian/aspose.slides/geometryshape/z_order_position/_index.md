## z_order_position свойство
Возвращает позицию фигуры в z-order.
            Shapes[0] возвращает фигуру в задней части z-order,
            а Shapes[Shapes.Count - 1] возвращает фигуру в передней части z-order.
            Только для чтения **int**.
