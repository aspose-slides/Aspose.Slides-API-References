## IBackgroundEffectiveData класс

Неизменяемый объект, содержащий эффективные свойства фона.

Тип IBackgroundEffectiveData раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`fill_format`](/slides/python-net/ru/aspose.slides/ibackgroundeffectivedata/fill_format/) | Возвращает эффективный формат заливки.<br/>            Только для чтения [`IFillFormatEffectiveData`](/slides/python-net/ru/aspose.slides/ifillformateffectivedata). |
| [`effect_format`](/slides/python-net/ru/aspose.slides/ibackgroundeffectivedata/effect_format/) | Возвращает эффективный формат эффекта.<br/>            Только для чтения [`IEffectFormatEffectiveData`](/slides/python-net/ru/aspose.slides/ieffectformateffectivedata). |


### Примечания

Этот интерфейс используется вместе с интерфейсом [`IBackground`](/slides/python-net/ru/aspose.slides/ibackground) для возврата эффективных значений форматирования с применённым наследованием.
