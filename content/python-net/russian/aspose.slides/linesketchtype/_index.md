## LineSketchType перечисление

Представляет тип эскиза или эффект, который был назначен фигуре.

Тип LineSketchType предоставляет следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| NOT_DEFINED | Указывает, что эффект Sketch для фигуры не определён. |
| NONE | Указывает, что у фигуры нет эффекта Sketch. Это эквивалентно тому, что это свойство пусто. |
| CURVED | Указывает, что у фигуры есть эффект Curved, который превращает каждое ребро фигуры в одну большую плавную кривую. |
| FREEHAND | Указывает, что у фигуры есть эффект Freehand, который наиболее похож на нарисованную от руки, но несовершенную линию. |
| SCRIBBLE | Указывает, что у фигуры есть эффект Scribble, который имеет преувеличенные колебания, словно нарисован преднамеренно неаккуратно. |
