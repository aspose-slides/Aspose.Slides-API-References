## ITabEffectiveData класс

Неизменяемый объект, содержащий свойства табуляции эффективного текста.

Тип ITabEffectiveData раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`position`](/slides/python-net/ru/aspose.slides/itabeffectivedata/position/) | Returns position of a tab.<br/>            Назначение этого свойства может изменить индекс табуляции в коллекции и сделать Enumerator недействительным.<br/>            Только для чтения **float**. |
| [`alignment`](/slides/python-net/ru/aspose.slides/itabeffectivedata/alignment/) | Returns align style of a tab.<br/>            Только для чтения [`TabAlignment`](/slides/python-net/ru/aspose.slides/tabalignment). |


### Примечания

Этот интерфейс используется как часть [`IParagraphFormatEffectiveData`](/slides/python-net/ru/aspose.slides/iparagraphformateffectivedata).
