## Перечисление PersistenceType

Тип PersistenceType раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| NOT_DEFINED | Идентификатор Persistance не указан. |
| PERSIST_PROPERTY_BAG | Указывает, что ActiveX-элемент сохраняется с использованием property-bag-based persistence. <br/>             Property-bag-based persistence сохраняет ActiveX-элемент посредством коллекции пар имя <br/>             и значение, которые определяют данные, сохраняемые ActiveX-элементом. |
| PERSIST_STREAM | Указывает, что ActiveX-элемент сохраняется с использованием stream-based persistence <br/>             который не поддерживает инициализацию ActiveX-элемента в состояние по умолчанию. |
| PERSIST_STREAM_INIT | Указывает, что ActiveX-элемент сохраняется с использованием stream-based persistence <br/>             который поддерживает инициализацию ActiveX-элемента в состояние по умолчанию. |
| PERSIST_STORAGE | Указывает, что ActiveX-элемент сохраняется с использованием storage-based persistence. |
