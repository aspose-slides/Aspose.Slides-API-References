## fill_format свойство
Возвращает объект FillFormat, который содержит свойства заливки для фигуры.
            Примечание: может вернуть None для определённых типов фигур, у которых нет свойств заливки.
            Только для чтения [`IFillFormat`](/slides/python-net/ru/aspose.slides/ifillformat).
