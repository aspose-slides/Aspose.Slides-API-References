## z_order_position свойство
Возвращает позицию фигуры в порядке наложения по оси Z.
            Shapes[0] возвращает фигуру в задней части порядка наложения по оси Z,
            а Shapes[Shapes.Count - 1] возвращает фигуру в передней части порядка наложения по оси Z.
            Только для чтения **int**.
