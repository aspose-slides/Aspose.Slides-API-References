## parent_group свойство
Возвращает объект GroupShape родительской группы, если объект входит в группу. В противном случае возвращает None.
            Только для чтения [`IGroupShape`](/slides/python-net/ru/aspose.slides/igroupshape).


### Примечания

Свойство [`Shape.is_grouped`](/slides/python-net/ru/aspose.slides/shape/is_grouped) определяет, входит ли объект в группу.
