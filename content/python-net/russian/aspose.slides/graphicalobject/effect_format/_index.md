## effect_format свойство
Возвращает объект EffectFormat, который содержит пиксельные эффекты, применённые к фигуре.
            Примечание: может возвращать None для некоторых типов фигур, у которых нет свойств эффекта.
            Только для чтения [`IEffectFormat`](/slides/python-net/ru/aspose.slides/ieffectformat).
