## EffectFormat класс

Представляет свойства эффектов фигуры.

**Наследование:**[`EffectFormat`](/slides/python-net/ru/aspose.slides/effectformat) → [`PVIObject`](/slides/python-net/ru/aspose.slides/pviobject)

Тип EffectFormat содержит следующие члены:

| Свойство | Описание |
| :- | :- |
| [`is_no_effects`](/slides/python-net/ru/aspose.slides/effectformat/is_no_effects/) | Возвращает true, если все эффекты отключены (как только создан объект EffectFormat по умолчанию).<br/>            Read-only **bool**. |

| [`glow_effect`](/slides/python-net/ru/aspose.slides/effectformat/glow_effect/) | Эффект свечения.<br/>            Read/write [`IGlow`](/slides/python-net/ru/aspose.slides.effects/iglow). |
| [`inner_shadow_effect`](/slides/python-net/ru/aspose.slides/effectformat/inner_shadow_effect/) | Внутренняя тень.<br/>            Read/write [`IInnerShadow`](/slides/python-net/ru/aspose.slides.effects/iinnershadow). |
| [`outer_shadow_effect`](/slides/python-net/ru/aspose.slides/effectformat/outer_shadow_effect/) | Внешняя тень.<br/>            Read/write [`IOuterShadow`](/slides/python-net/ru/aspose.slides.effects/ioutershadow). |
| [`preset_shadow_effect`](/slides/python-net/ru/aspose.slides/effectformat/preset_shadow_effect/) | Предустановленная тень.<br/>            Read/write [`IPresetShadow`](/slides/python-net/ru/aspose.slides.effects/ipresetshadow). |
| [`reflection_effect`](/slides/python-net/ru/aspose.slides/effectformat/reflection_effect/) | Отражение.<br/>            Read/write [`IReflection`](/slides/python-net/ru/aspose.slides.effects/ireflection). |
| [`soft_edge_effect`](/slides/python-net/ru/aspose.slides/effectformat/soft_edge_effect/) | Смягчённый край.<br/>            Read/write [`ISoftEdge`](/slides/python-net/ru/aspose.slides.effects/isoftedge). |
