## x свойство
Получает или задает координату x левого верхнего угла фигуры, измеряемую в пунктах.
            Чтение/запись **float**.

### Примечания

Возвращаемое значение всегда определено и никогда не **float**.
            Присваиваемое значение также должно быть определено; присваивать **float** только свойствам экземпляра `RawFrame`.

### Определение:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
