## effect_format свойство
Возвращает объект EffectFormat, содержащий пиксельные эффекты, применённые к фигуре.
            Примечание: может вернуть None для некоторых типов фигур, у которых нет свойств эффектов.
            Только для чтения [`IEffectFormat`](/slides/python-net/ru/aspose.slides/ieffectformat).
