## NormalViewRestoredProperties класс

Указывает размер области слайда ((ширина, когда элемент является дочерним для restoredTop, высота, когда элемент является дочерним для restoredLeft) обычного представления, когда область имеет переменный восстановленный размер (не свернута и не развернута).

Тип NormalViewRestoredProperties раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`dimension_size`](/slides/python-net/ru/aspose.slides/normalviewrestoredproperties/dimension_size/) | Указывает размер области слайда (ширина, когда элемент является дочерним для RestoredTop, высота, когда элемент является дочерним для RestoredLeft).<br/>            Чтение/запись **float**. |
| [`auto_adjust`](/slides/python-net/ru/aspose.slides/normalviewrestoredproperties/auto_adjust/) | Указывает, следует ли размер области бокового содержимого компенсировать новый размер<br/>            при изменении размера окна, содержащего представление в приложении<br/>            Чтение/запись **bool**. |
