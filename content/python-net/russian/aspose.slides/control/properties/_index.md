## свойства property
Возвращает коллекцию свойств ActiveX.
            Примечание: Aspose.Slides поддерживает только основанные на XML свойства ActiveX. Если свойства хранятся в бинарном формате, это свойство вернёт None.
            Только для чтения [`IControlPropertiesCollection`](/slides/python-net/ru/aspose.slides/icontrolpropertiescollection).

    ...
