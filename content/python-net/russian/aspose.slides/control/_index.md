## Control класс

Представляет элемент управления ActiveX.

Тип Control предоставляет следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`persistence`](/slides/python-net/ru/aspose.slides/control/persistence/) | Получает метод, используемый для хранения свойств элемента управления ActiveX.<br/>            Только чтение [`PersistenceType`](/slides/python-net/ru/aspose.slides/persistencetype). |
| [`name`](/slides/python-net/ru/aspose.slides/control/name/) | Получает или задает имя этого элемента управления.<br/>            Чтение/запись **str**. |
| [`class_id`](/slides/python-net/ru/aspose.slides/control/class_id/) | Получает идентификатор класса этого элемента управления.<br/>            Только чтение **System.Guid**. |
| [`substitute_picture_format`](/slides/python-net/ru/aspose.slides/control/substitute_picture_format/) | Возвращает объект свойств заполнения изображения элемента управления.<br/>            Только чтение [`IPictureFillFormat`](/slides/python-net/ru/aspose.slides/ipicturefillformat). |
| [`frame`](/slides/python-net/ru/aspose.slides/control/frame/) | Возвращает или задает рамку элемента управления.<br/>            Чтение/запись [`IShapeFrame`](/slides/python-net/ru/aspose.slides/ishapeframe). |
| [`properties`](/slides/python-net/ru/aspose.slides/control/properties/) | Возвращает коллекцию свойств ActiveX.<br/>            Примечание: Aspose.Slides поддерживает только свойства ActiveX на основе XML. Если свойства хранятся в бинарном формате, это свойство вернёт None.<br/>            Только чтение [`IControlPropertiesCollection`](/slides/python-net/ru/aspose.slides/icontrolpropertiescollection). |
| [`active_x_control_binary`](/slides/python-net/ru/aspose.slides/control/active_x_control_binary/) | Указывает, как сохранять элемент управления ActiveX, когда используемый метод сохранения — PersistStream, PersistStreamInit или PersistStorage. |
| [`slide`](/slides/python-net/ru/aspose.slides/control/slide/) |  |
