## SlideSizeScaleType перечисление

Представляет тип масштабирования содержимого слайда.

Тип SlideSizeScaleType предоставляет следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| DO_NOT_SCALE | Не масштабировать. |
| ENSURE_FIT | Масштабировать, чтобы обеспечить вписание. |
| MAXIMIZE | Максимизировать размер содержимого. |
