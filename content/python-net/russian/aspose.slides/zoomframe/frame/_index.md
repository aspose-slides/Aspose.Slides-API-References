## frame property
Возвращает или задает свойства рамки фигуры.
            Чтение/запись [`IShapeFrame`](/slides/python-net/ru/aspose.slides/ishapeframe).

### Примечание

Значение каждого свойства возвращенного IShapeFrame экземпляра не является undefined (не NaN и не NotDefined).
            Значение каждого свойства назначенного IShapeFrame экземпляра должно быть не undefined (не NaN и не NotDefined).
            Вы можете задавать значения undefined для свойств экземпляра RawResult.
