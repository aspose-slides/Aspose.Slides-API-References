## rotation свойство
Возвращает или задаёт число градусов, на которое указанная фигура вращается вокруг оси z. Положительное значение означает вращение по часовой стрелке; отрицательное значение означает вращение против часовой стрелки.
Чтение/запись **float**.


### Примечания

Возвращаемое значение всегда определено (is not float.NaN). Присвоенное значение должно быть определено (not float.NaN). Вы можете задавать неопределённые значения для свойств экземпляра RawFrame.
