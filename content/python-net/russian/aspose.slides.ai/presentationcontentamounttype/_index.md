## PresentationContentAmountType перечисление

Указывает количество содержимого, включённого в создаваемую презентацию, влияя как на число слайдов, так и на уровень детализации каждого слайда.

Тип PresentationContentAmountType предоставляет следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| BRIEF | Краткое и базовое содержимое. |
| MEDIUM | Умеренное количество содержимого. |
| DETAILED | Самый подробный вариант с обширным текстом. |
