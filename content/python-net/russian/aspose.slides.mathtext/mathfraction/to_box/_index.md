## to_box(self) {#}
Размещает этот элемент в невизуальном боксе (логическом объединении) 
            который используется для группировки компонентов уравнения или другого экземпляра математического текста.
            Запакованный объект может (например) выступать в роли эмулятора оператора с точкой выравнивания или без неё,
            служить точкой разрыва строки, либо быть сгруппированным так, чтобы не допускать разрывы строк внутри.
