## to_box(self) {#}
Размещает этот элемент в невизуальном блоке (логическая группировка) 
            который используется для группировки компонентов уравнения или другого экземпляра математического текста.
            Упакованный объект может (например) выступать в роли эмулятора оператора с точкой выравнивания или без неё, 
            служить точкой разрыва строки или быть сгруппирован так, чтобы не позволять разрывы строк внутри.

### Returns

Логический блок, содержащий этот элемент
