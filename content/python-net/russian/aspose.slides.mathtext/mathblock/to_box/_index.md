## to_box(self) {#}
Помещает этот элемент в невизуальный блок (логическое объединение) 
            который используется для группировки компонентов уравнения или другого фрагмента математического текста.
            Объект в блоке может (например) служить эмулятором оператора с точкой выравнивания или без неё, 
            служить точкой разрыва строки или быть сгруппированным таким образом, чтобы не допускать разрывы строк внутри.

### Возвращаемое значение

Логический блок, в котором размещён этот элемент

    ...
