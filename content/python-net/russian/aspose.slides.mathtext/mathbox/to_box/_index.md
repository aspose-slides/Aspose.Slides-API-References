## to_box(self) {#}
Помещает этот элемент в невизуальный блок (логическая группировка) 
            который используется для группировки компонентов уравнения или другого экземпляра математического текста.
            Блокированный объект может (например) выступать в качестве эмулятора оператора с точкой выравнивания или без неё, 
            служить точкой разрыва строки или быть сгруппирован так, чтобы не позволять разрывы строк внутри.

### Возвращаемое значение

Логический блок с размещённым внутри этим элементом

    ...
