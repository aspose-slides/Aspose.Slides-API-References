## no_break свойство
Без разрыва
            Это свойство указывает свойство "unbreakable" у объекта-коробки. Когда true, внутри коробки не может происходить переносов строк.
            Это может быть важно для эмуляторов операторов, состоящих более чем из одного двоичного оператора.
            Если этот элемент не указан, в коробке могут возникать разрывы.
            По умолчанию: true

```python
@property
def no_break(self):
    ...

@no_break.setter
def no_break(self, value):
    ...
```
