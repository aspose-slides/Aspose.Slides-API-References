## explicit_break свойство
Свойство explicit_break указывает, есть ли разрыв строки в начале объекта Box,
            так что строка переносится в начале объекта Box.
            Указывает номер оператора в предыдущей строке математического текста, который
            должен использоваться в качестве точки выравнивания для текущей строки математического текста
            возможные значения: 1..255
            По умолчанию: 0 (нет явного разрыва)
