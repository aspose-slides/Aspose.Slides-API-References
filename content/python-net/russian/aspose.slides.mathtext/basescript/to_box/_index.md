## to_box(self) {#}
Помещает этот элемент в невизуальный блок (логическую группу), 
            который используется для группировки компонентов уравнения или другого экземпляра математического текста.
            Объект в блоке может (например) служить эмулятором оператора с точкой выравнивания или без неё, 
            служить точкой разрыва строки или быть сгруппированным так, чтобы не допускать разрывов строк внутри.

### Возвращаемое значение

Логический блок с размещённым внутри этим элементом



```python
def to_box(self):
    ...
```
