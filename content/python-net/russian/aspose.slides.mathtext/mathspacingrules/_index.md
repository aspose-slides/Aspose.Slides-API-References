## MathSpacingRules перечисление

Типы промежутков (горизонтального расстояния) между столбцами матрицы

Тип MathSpacingRules предоставляет следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| SINGLE_SPACING_GAP | Одинарный (1 em для столбцов или 1 строка для строк) |
| ONE_AND_HALF_SPACING_GAP | Полтора (1.5 em для столбцов или 1.5 строки для строк) |
| DOUBLE_SPACING_GAP | Двойной интервал (2 em для столбцов или 2 строки для строк) |
| EXACTLY | Точное значение<br/>            Для столбцов, значение ColumnGap, измеряется в твипах<br/>            Для строк, значение RowGap, измеряется в твипах |
| MULTIPLE | Множественный<br/>            Для столбцов, значение ColumnGap, измеряется в шагах 0.5 em<br/>            Для строк, значение RowGap, измеряется в строках |
