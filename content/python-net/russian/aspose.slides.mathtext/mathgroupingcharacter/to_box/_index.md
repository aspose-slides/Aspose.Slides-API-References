## to_box(self) {#}
Помещает этот элемент в невизуальный блок (логическая группировка), который используется для группировки компонентов уравнения или другого примера математического текста. Объект в блоке может (например) служить эмулятором оператора с точкой выравнивания или без неё, служить точкой разрыва строки или быть сгруппирован так, чтобы не позволять разрывы строк внутри.

### Returns

Логический блок, в котором размещён этот элемент
