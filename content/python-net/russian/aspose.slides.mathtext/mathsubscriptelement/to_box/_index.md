## to_box(self) {#}
Размещает этот элемент в невизуальном блоке (логическая группировка), который используется для группирования компонентов уравнения или другого экземпляра математического текста.
Объект в блоке может (например) выступать в роли эмулятора оператора с точкой выравнивания или без неё, служить точкой разрыва строки или быть сгруппирован так, чтобы не допускать разрывы строк внутри.

### Возвращаемое значение

Логический блок с размещённым внутри этим элементом

def to_box(self):
    ...
