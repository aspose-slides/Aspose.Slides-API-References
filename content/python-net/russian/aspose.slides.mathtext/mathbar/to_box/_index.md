## to_box(self) {#}
Помещает этот элемент в невизуальный блок (логическая группировка), который используется для группировки компонентов уравнения или другого экземпляра математического текста. Упакованный объект может (например) служить эмулятором оператора с точкой выравнивания или без неё, служить точкой разрыва строки или быть сгруппированным так, чтобы не допускать разрывы строк внутри.

### Возвращаемое значение

Логический блок с размещённым внутри этим элементом

    ...
