## IMathBorderBox класс

Рисует прямоугольную или другую рамку вокруг IMMathElement.

Тип IMathBorderBox раскрывает следующие члены:

## Свойства

| Свойство | Описание |
| :- | :- |
| [`base`](/slides/python-net/ru/aspose.slides.mathtext/imathborderbox/base/) | Базовый аргумент |
| [`hide_top`](/slides/python-net/ru/aspose.slides.mathtext/imathborderbox/hide_top/) | Hide Top Edge (по умолчанию false) — указывает скрытое или показанное состояние верхнего края рамки. |
| [`hide_bottom`](/slides/python-net/ru/aspose.slides.mathtext/imathborderbox/hide_bottom/) | Hide Bottom Edge (по умолчанию false) — указывает скрытое или показанное состояние нижнего края рамки. |
| [`hide_left`](/slides/python-net/ru/aspose.slides.mathtext/imathborderbox/hide_left/) | Hide Left Edge (по умолчанию false) — указывает скрытое или показанное состояние левого края рамки. |
| [`hide_right`](/slides/python-net/ru/aspose.slides.mathtext/imathborderbox/hide_right/) | Hide Right Edge (по умолчанию false) — указывает скрытое или показанное состояние правого края рамки. |
| [`strikethrough_horizontal`](/slides/python-net/ru/aspose.slides.mathtext/imathborderbox/strikethrough_horizontal/) | Strikethrough Horizontal (по умолчанию false) — указывает скрытое или показанное состояние зачеркивающей горизонтальной линии. |
| [`strikethrough_vertical`](/slides/python-net/ru/aspose.slides.mathtext/imathborderbox/strikethrough_vertical/) | Strikethrough Vertical (по умолчанию false) — указывает скрытое или показанное состояние зачеркивающей вертикальной линии. |
| [`strikethrough_bottom_left_to_top_right`](/slides/python-net/ru/aspose.slides.mathtext/imathborderbox/strikethrough_bottom_left_to_top_right/) | Strikethrough Bottom-Left to Top-Right (по умолчанию false).<br/>            Указывает скрытое или показанное состояние зачеркивающей диагональной линии от нижнего левого угла до верхнего правого угла рамки. |
| [`strikethrough_top_left_to_bottom_right`](/slides/python-net/ru/aspose.slides.mathtext/imathborderbox/strikethrough_top_left_to_bottom_right/) | Strikethrough Top-Left to Bottom-Right (по умолчанию false).<br/>            Указывает скрытое или показанное состояние зачеркивающей диагональной линии от верхнего левого угла до нижнего правого угла рамки. |
