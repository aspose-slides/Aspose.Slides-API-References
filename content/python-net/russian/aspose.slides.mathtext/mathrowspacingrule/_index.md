## MathRowSpacingRule перечисление

Тип вертикального интервала между столбцами в матрице или массиве

Тип MathRowSpacingRule предоставляет следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| SINGLE_LINE_GAP | одинарный промежуток строки |
| ONE_AND_A_HALF_LINE_GAP | полуторный промежуток строки |
| TWO_LINE_GAP | двухстрочный промежуток |
| EXACTLY | Точно (зависит от значения свойства RowSpacing, измеряется в пунктах) |
| MULTIPLE | Множественно (зависит от значения свойства RowSpacing, измеряется в строках) |
