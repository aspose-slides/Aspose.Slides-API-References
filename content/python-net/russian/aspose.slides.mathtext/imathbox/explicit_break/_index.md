## explicit_break свойство
Явный разрыв указывает, существует ли разрыв строки в начале объекта Box, 
            что приводит к переносу строки в начале объекта box.
            Указывает номер оператора в предыдущей строке математического текста, который должен
            использоваться в качестве точки выравнивания для текущей строки математического текста
            возможные значения: 1..255
            По умолчанию: 0 (нет явного разрыва)
