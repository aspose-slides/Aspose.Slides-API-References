## no_break свойство
No break.
            Это свойство указывает свойство "unbreakable" на объектном блоке. Когда true, разрывы строк не могут возникать внутри блока.
            Это может быть важно для эмуляторов операторов, состоящих более чем из одного бинарного оператора.
            Если этот элемент не указан, разрывы могут происходить внутри блока.
            По умолчанию: true

### Определение:
```python
@property
def no_break(self):
    ...

@no_break.setter
def no_break(self, value):
    ...
```
