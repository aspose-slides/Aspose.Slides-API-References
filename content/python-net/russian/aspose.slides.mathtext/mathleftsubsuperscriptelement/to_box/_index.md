## to_box(self) {#}
Размещает этот элемент в невизуальном контейнере (логическое группирование) 
            который используется для группировки компонентов уравнения или другого случая математического текста.
            Объект в коробке может (например) служить эмулятором оператора с точкой выравнивания или без неё, 
            служить точкой разрыва строки, или быть сгруппированным так, чтобы не допускать разрывы строк внутри.

### Возвращаемое значение

Логический контейнер, в котором размещён этот элемент
