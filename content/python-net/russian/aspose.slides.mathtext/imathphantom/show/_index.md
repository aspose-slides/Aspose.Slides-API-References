## show свойство
Получает или задает значение, указывающее, отображается ли базовый элемент.


### Примечания

When `false`, базовый элемент скрыт, но может по-прежнему занимать место в зависимости 
            от других параметров phantom. Соответствует атрибуту OMML `m:show`.

### Определение:
```python
@property
def show(self):
    ...

@show.setter
def show(self, value):
    ...
```
