## свойство transp
Получает или задает значение, указывающее, является ли фантом прозрачным 
            для правил разметки, основанных на классах.


### Примечания

Когда `true`, операторы и символы внутри фантома всё ещё влияют 
            математической разметкой вокруг фантома (как если бы он был видимым). Когда `false`, 
            разметка, основанная на классах, игнорируется. Соответствует атрибуту OMML `m:transp`.

### Определение:
```python
@property
def transp(self):
    ...

@transp.setter
def transp(self, value):
    ...
```
