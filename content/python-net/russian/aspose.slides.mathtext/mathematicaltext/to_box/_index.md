## to_box(self) {#}
Размещает этот элемент в невизуальном контейнере (логическом объединении) 
            который используется для группировки компонентов уравнения или другого примера математического текста.
            Упакованный объект может (например) служить эмулятором оператора с точкой выравнивания или без неё,
            служить точкой разрыва строки или группироваться так, чтобы не допускать разрывы строк внутри.

### Returns

Логический контейнер с размещённым внутри этим элементом
