## Перечисление MathLimitLocations

Расположение пределов (подстрочный/надстрочный) в n-арных операторах.

Тип MathLimitLocations содержит следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| NOT_DEFINED | Не определено |
| UNDER_OVER | Пределы рисуются вверху и внизу символа оператора |
| SUBSCRIPT_SUPERSCRIPT | Пределы рисуются как подстрочный и надстрочный |
