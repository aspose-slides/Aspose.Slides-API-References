## to_box(self) {#}
Помещает этот элемент в невизуальный блок (логическое объединение) 
            который используется для группировки компонентов уравнения или другого экземпляра математического текста.
            Объект в блоке может (например) служить эмулятором оператора с точкой выравнивания или без неё,
            служить точкой разрыва строки или быть сгруппирован таким образом, чтобы не допустить разрывов строк внутри.

### Возвращаемое значение

Логический блок, содержащий этот элемент

def to_box(self):
    ...
