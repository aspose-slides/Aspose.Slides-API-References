## MathNaryOperatorTypes перечисление

Типы n-арных операторов IMathNaryOperator (за исключением интегралов)  
Для интегралов [`MathIntegralTypes`](/slides/python-net/ru/aspose.slides.mathtext/mathintegraltypes)

Тип MathNaryOperatorTypes раскрывает следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| SUMMATION | Суммирование: '∑' |
| PRODUCT | Произведение: '∏' |
| CO_PRODUCT | Копродукт: '∐' |
| INTERSECTION | Пересечение: '∩' |
| UNION | Объединение: '∪' |
| LOGICAL_AND | Логическое И: '∧' |
| LOGICAL_OR | Логическое ИЛИ: '∨' |
