## portion_format свойство
Возвращает объект форматирования, который содержит явно заданные свойства форматирования части текста без применения наследования.
            Только для чтения [`IPortionFormat`](/slides/python-net/ru/aspose.slides/iportionformat).


### Примечания

Объект форматирования содержит параметры форматирования, определённые только для текущей части, наследованные данные не применяются.


Чтобы получить эффективные значения, включая наследованные, используйте метод [`PortionFormat.get_effective`](/slides/python-net/ru/aspose.slides/portionformat/get_effective).
