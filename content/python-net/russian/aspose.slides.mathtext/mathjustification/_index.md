## Перечисление MathJustification

Указывает выравнивание математического абзаца (последовательность смежных экземпляров математического текста в рамках одного абзаца)

Тип MathJustification содержит следующие члены:

## Поля

| Поле | Описание |
| :- | :- |
| LEFT_JUSTIFIED | Выравнивает математический текст по левому краю |
| RIGHT_JUSTIFIED | Выравнивает математический текст по правому краю |
| CENTERED | Выравнивает математический текст по центру |
| CENTERED_AS_GROUP | Разместить по центру на странице всю группу блоков математики как единое целое.<br/>            Это означает, что отдельные элементы математического текста могут быть выравнены друг относительно друга, <br/>            но вся группа математического текста центрируется как единое целое. |
