## min_column_width свойство
Минимальная ширина столбца в твипсах (1/20 части пункта)
            Расстояние между колонками (также называемое «Column Gap» или «Gap Width») прибавляется к MinColumnWidth, чтобы определить общую ширину промежутка между столбцами матрицы (расстояние между одинаковыми краями разных столбцов). По умолчанию: 0.
