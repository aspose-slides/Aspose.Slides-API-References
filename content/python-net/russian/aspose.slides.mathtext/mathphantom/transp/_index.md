## transp свойство
Получает или задает значение, указывающее, прозрачен ли phantom для правил разметки, основанных на классах.

### Примечания

Когда `true`, операторы и символы внутри phantom все еще влияют на математическую разметку вокруг phantom (как будто он видим). Когда `false`, разметка, основанная на классах, игнорируется. Соответствует атрибуту OMML `m:transp`.

### Определение:
```python
@property
def transp(self):
    ...

@transp.setter
def transp(self, value):
    ...
```
