## show свойство
Получает или задает значение, указывающее, отображается ли базовый элемент.


### Примечания

Когда `false`, базовый элемент скрыт, но может по-прежнему занимать место в зависимости от других phantom-настроек. Соответствует атрибуту OMML `m:show`.

### Определение:
```python
@property
def show(self):
    ...

@show.setter
def show(self, value):
    ...
```
