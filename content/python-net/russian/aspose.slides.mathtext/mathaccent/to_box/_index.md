## to_box(self) {#}
Размещает этот элемент в невизуальном блоке (логическая группировка) 
            который используется для группировки компонентов уравнения или другого фрагмента математического текста.
            Объект в блоке может (например) служить эмулятором оператора с точкой выравнивания или без неё, 
            выступать в качестве точки разрыва строки или группироваться так, чтобы не разрешать разрывы строк внутри.

### Возвращаемое значение

Логический блок с размещённым внутри этим элементом

def to_box(self):
    ...
