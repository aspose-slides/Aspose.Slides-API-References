Περιέχει κλάσεις που αντιπροσωπεύουν διάφορους τύπους προειδοποιήσεων
## Κλάσεις

| Κλάση | Περιγραφή |
| :- | :- |
| [`IKnownIssueWarningInfo`](/slides/python-net/el/aspose.slides.warnings/iknownissuewarninginfo/) | Αναπαριστά μια προειδοποίηση σχετικά με γνωστό ζήτημα που δεν θα διορθωθεί στο άμεσο μέλλον. |
| [`INotImplementedWarningInfo`](/slides/python-net/el/aspose.slides.warnings/inotimplementedwarninginfo/) | Αναπαριστά μια προειδοποίηση σχετικά με γνωστή μη υλοποιηθείσα λειτουργία που δεν θα υλοποιηθεί στο άμεσο μέλλον. |
| [`IObsoletePresLockingBehaviorWarningInfo`](/slides/python-net/el/aspose.slides.warnings/iobsoletepreslockingbehaviorwarninginfo/) | Αυτή η προειδοποίηση δείχνει ότι χρησιμοποιείται μια παρωχημένη συμπεριφορά κλειδώματος παρουσίασης. |
| [`IPresentationSignedWarningInfo`](/slides/python-net/el/aspose.slides.warnings/ipresentationsignedwarninginfo/) | Αυτή η προειδοποίηση δείχνει ότι η παρουσίαση που διαβάζεται έχει την υπογραφή <br/>            και αυτή η υπογραφή θα αφαιρεθεί κατά την επεξεργασία. |
| [`IWarningCallback`](/slides/python-net/el/aspose.slides.warnings/iwarningcallback/) | Διεπαφή για κλάσεις που λαμβάνουν προειδοποίηση. |
| [`IWarningInfo`](/slides/python-net/el/aspose.slides.warnings/iwarninginfo/) | Αναπαριστά μια βασική διεπαφή για όλες τις προειδοποιήσεις. |

## Απαριθμήσεις

| Απαρίθμηση | Περιγραφή |
| :- | :- |
| [`ReturnAction`](/slides/python-net/el/aspose.slides.warnings/returnaction/) | Αναπαριστά επιλογές λήψης απόφασης για την κλήση επιστροφής προειδοποίησης. |
| [`WarningType`](/slides/python-net/el/aspose.slides.warnings/warningtype/) | Αναπαριστά έναν τύπο προειδοποίησης. |
