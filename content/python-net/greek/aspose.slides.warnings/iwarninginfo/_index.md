## IWarningInfo κλάση

Αναπαριστά μια βασική διεπαφή για όλες τις προειδοποιήσεις.

Ο τύπος IWarningInfo αποκαλύπτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`warning_type`](/slides/python-net/el/aspose.slides.warnings/iwarninginfo/warning_type/) | Επιστρέφει έναν τύπο προειδοποίησης.<br/>            Μόνο για ανάγνωση [`IWarningInfo.warning_type`](/slides/python-net/el/aspose.slides.warnings/iwarninginfo/warning_type). |
| [`description`](/slides/python-net/el/aspose.slides.warnings/iwarninginfo/description/) | Επιστρέφει μια ανθρώπινα αναγνώσιμη περιγραφή αυτής της προειδοποίησης.<br/>            Μόνο για ανάγνωση **str**. |

## Μέθοδοι

| Μέθοδος | Περιγραφή |
| :- | :- |
| [`send_warning(self, receiver)`](/slides/python-net/el/aspose.slides.warnings/iwarninginfo/send_warning/#iwarningcallback) | Εάν ο παραλήπτης δεν είναι None, ολοκληρώνει την προειδοποίηση σε έναν καθορισμένο παραλήπτη και ρίχνει το <br/>            AbortRequestedException εάν ο παραλήπτης αποφάσισε να ακυρώσει μια λειτουργία. |
