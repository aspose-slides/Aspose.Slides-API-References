## Απαρίθμηση WarningType

Αναπαριστά έναν τύπο προειδοποίησης.

Ο τύπος WarningType εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| SOURCE_FILE_CORRUPTION | Εντοπίστηκε ένα πρόβλημα στο πηγαίο έγγραφο το οποίο καθιστά πολύ πιθανό ότι το έγγραφο δεν θα μπορεί να ανοιχθεί αν αποθηκευτεί στην αρχική μορφή. |
| DATA_LOSS | Το κείμενο/διάγραμμα/εικόνα ή άλλα δεδομένα θα λείπουν εντελώς είτε από το δέντρο εγγράφου μετά τη φόρτωση, είτε από το δημιουργηθέν έγγραφο μετά την αποθήκευση. |
| MAJOR_FORMATTING_LOSS | Σημαντική απώλεια μορφοποίησης. |
| MINOR_FORMATTING_LOSS | Μικρή απώλεια μορφοποίησης. |
| COMPATIBILITY_ISSUE | Αυτό είναι γνωστό πρόβλημα που θα εμποδίσει το έγγραφο να ανοίξει από ορισμένους πελάτες ή από προηγούμενες εκδόσεις πελατών. |
| UNEXPECTED_CONTENT | Κάποιο περιεχόμενο στο πηγαίο έγγραφο δεν αναγνωρίστηκε (π.χ. δεν υποστηρίζεται), αυτό μπορεί ή δεν μπορεί να προκαλέσει προβλήματα ή να οδηγήσει σε απώλεια δεδομένων/μορφοποίησης. |
