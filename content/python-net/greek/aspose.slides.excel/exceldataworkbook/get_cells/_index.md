def get_cells(self, formula, skip_hidden_cells):

| Παράμετρος | Τύπος | Περιγραφή |
| :- | :- | :- |
| formula | **str** | Μια φόρμουλα ή έκφραση περιοχής (π.χ., "Sheet1!A1:B3") που χρησιμοποιείται για τον εντοπισμό των κελιών-στόχων. |
