## get_cells(self, formula, skip_hidden_cells) {#str-bool}
Ανακτά μια συλλογή από κελιά από το βιβλίο εργασίας που ταιριάζουν με τον καθορισμένο τύπο.

### Επιστρέφει

Μια λίστα μόνο για ανάγνωση από κελιά που ταιριάζουν με τον καθορισμένο τύπο.



```python
def get_cells(self, formula, skip_hidden_cells):
    ...
```


| Παράμετρος | Τύπος | Περιγραφή |
| :- | :- | :- |
| formula | **str** | Ένα τύπο ή έκφραση περιοχής (π.χ., "Sheet1!A1:B3") που χρησιμοποιείται για τον εντοπισμό των κελιών-στόχων. |
| skip_hidden_cells | **bool** | Αν `true`, τα κρυμμένα κελιά (π.χ., σε κρυμμένες σειρές ή στήλες) θα εξαλειφθούν από το αποτέλεσμα. |
