## IExcelDataCell κλάση

Αναπαριστά ένα μοναδικό κελί σε ένα βιβλίο εργασίας Excel.

Ο τύπος IExcelDataCell εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`value`](/slides/python-net/el/aspose.slides.excel/iexceldatacell/value/) | Λαμβάνει την τιμή που περιέχεται στο κελί Excel.<br/>            Μόνο για ανάγνωση **any**. |
| [`name`](/slides/python-net/el/aspose.slides.excel/iexceldatacell/name/) | Λαμβάνει το όνομα του κελιού δεδομένων γραφήματος.<br/>            Μόνο για ανάγνωση **str**. |
| [`row`](/slides/python-net/el/aspose.slides.excel/iexceldatacell/row/) | Λαμβάνει τον δείκτη μηδενικής βάσης της γραμμής στο φύλλο εργασίας όπου βρίσκεται το κελί.<br/>            Μόνο για ανάγνωση **int**. |
| [`column`](/slides/python-net/el/aspose.slides.excel/iexceldatacell/column/) | Λαμβάνει τον δείκτη μηδενικής βάσης της στήλης στο φύλλο εργασίας όπου βρίσκεται το κελί.<br/>            Μόνο για ανάγνωση **int**. |
