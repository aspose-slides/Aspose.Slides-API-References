## IFontSchemeEffectiveData κλάση

Αμετάβλητο αντικείμενο που περιέχει τις αποτελεσματικές ιδιότητες του σχήματος γραμματοσειράς.

Ο τύπος IFontSchemeEffectiveData εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`minor`](/slides/python-net/el/aspose.slides.theme/ifontschemeeffectivedata/minor/) | Επιστρέφει τη συλλογή γραμματοσειρών για το τμήμα "body" της διαφάνειας.<br/>            Μόνο για ανάγνωση [`IFontsEffectiveData`](/slides/python-net/el/aspose.slides/ifontseffectivedata). |
| [`major`](/slides/python-net/el/aspose.slides.theme/ifontschemeeffectivedata/major/) | Επιστρέφει τη συλλογή γραμματοσειρών για το τμήμα "heading" της διαφάνειας.<br/>            Μόνο για ανάγνωση [`IFontsEffectiveData`](/slides/python-net/el/aspose.slides/ifontseffectivedata). |
| [`name`](/slides/python-net/el/aspose.slides.theme/ifontschemeeffectivedata/name/) | Επιστρέφει το όνομα του σχήματος γραμματοσειρών.<br/>            Μόνο για ανάγνωση **str**. |


### Παρατηρήσεις

Αυτή η διεπαφή χρησιμοποιείται ως μέρος του [`IThemeEffectiveData`](/slides/python-net/el/aspose.slides.theme/ithemeeffectivedata).
