## FormatScheme κλάση

Αποθηκεύει μορφές που ορίζονται από το θέμα για τα σχήματα.

Ο τύπος FormatScheme εκθέτει τα ακόλουθα μέλη:

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`fill_styles`](/slides/python-net/el/aspose.slides.theme/formatscheme/fill_styles/) | Επιστρέφει μια συλλογή στυλ γεμίσματος που ορίζονται από το θέμα.<br/>            Μόνο για ανάγνωση [`IFillFormatCollection`](/slides/python-net/el/aspose.slides.theme/ifillformatcollection). |
| [`line_styles`](/slides/python-net/el/aspose.slides.theme/formatscheme/line_styles/) | Επιστρέφει μια συλλογή στυλ γραμμής που ορίζονται από το θέμα.<br/>            Μόνο για ανάγνωση [`ILineFormatCollection`](/slides/python-net/el/aspose.slides.theme/ilineformatcollection). |
| [`effect_styles`](/slides/python-net/el/aspose.slides.theme/formatscheme/effect_styles/) | Επιστρέφει μια συλλογή στυλ εφέ που ορίζονται από το θέμα.<br/>            Μόνο για ανάγνωση [`IEffectStyleCollection`](/slides/python-net/el/aspose.slides.theme/ieffectstylecollection). |
