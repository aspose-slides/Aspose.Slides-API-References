## MasterTheme κλάση

Αναπαριστά ένα κύριο θέμα.

**Inheritance:**[`MasterTheme`](/slides/python-net/el/aspose.slides.theme/mastertheme) → [`Theme`](/slides/python-net/el/aspose.slides.theme/theme)

Ο τύπος MasterTheme εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`color_scheme`](/slides/python-net/el/aspose.slides.theme/mastertheme/color_scheme/) | Returns the color scheme.<br/>            Μόνο ανάγνωση [`IColorScheme`](/slides/python-net/el/aspose.slides.theme/icolorscheme). |
