## OverrideTheme κλάση

Αναπαριστά ένα θέμα αντικατάστασης.

**Κληρονομικότητα:**[`OverrideTheme`](/slides/python-net/el/aspose.slides.theme/overridetheme) → [`Theme`](/slides/python-net/el/aspose.slides.theme/theme)

Ο τύπος OverrideTheme εμφανίζει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`color_scheme`](/slides/python-net/el/aspose.slides.theme/overridetheme/color_scheme/) | Επιστρέφει το χρωματικό σχήμα.<br/>            Μόνο για ανάγνωση [`IColorScheme`](/slides/python-net/el/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/el/aspose.slides.theme/overridetheme/font_scheme/) | Επιστρέφει το σχήμα γραμματοσειράς.<br/>            Μόνο για ανάγνωση [`IFontScheme`](/slides/python-net/el/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/el/aspose.slides.theme/overridetheme/format_scheme/) | Επιστρέφει το σχήμα μορφοποίησης σχήματος.<br/>            Μόνο για ανάγνωση [`IFormatScheme`](/slides/python-net/el/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/el/aspose.slides.theme/overridetheme/presentation/) | Επιστρέφει την κύρια παρουσίαση.<br/>            Μόνο για ανάγνωση [`IPresentation`](/slides/python-net/el/aspose.slides/ipresentation). |
| [`is_empty`](/slides/python-net/el/aspose.slides.theme/overridetheme/is_empty/) | Η αληθής τιμή σημαίνει ότι το ColorScheme, το FontScheme, το FormatScheme είναι None και οποιαδήποτε αντικατάσταση με αυτό το αντικείμενο θέματος είναι απενεργοποιημένη.<br/>            Μόνο για ανάγνωση **bool**. |
