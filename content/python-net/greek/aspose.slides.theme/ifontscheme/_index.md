## IFontScheme κλάση

Αποθηκεύει τις γραμματοσειρές που ορίζονται στο θέμα.

Ο τύπος IFontScheme εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`minor`](/slides/python-net/el/aspose.slides.theme/ifontscheme/minor/) | Επιστρέφει τη συλλογή γραμματοσειρών για το τμήμα "body" της διαφάνειας.<br/>            Μόνο για ανάγνωση [`IFonts`](/slides/python-net/el/aspose.slides/ifonts). |
| [`major`](/slides/python-net/el/aspose.slides.theme/ifontscheme/major/) | Επιστρέφει τη συλλογή γραμματοσειρών για το τμήμα "heading" της διαφάνειας.<br/>            Μόνο για ανάγνωση [`IFonts`](/slides/python-net/el/aspose.slides/ifonts). |
| [`name`](/slides/python-net/el/aspose.slides.theme/ifontscheme/name/) | Επιστρέφει το όνομα του σχήματος γραμματοσειράς.<br/>            Ανάγνωση/εγγραφή **str**. |
