## IThemeEffectiveData κλάση

Αμετάβλητο αντικείμενο που περιέχει αποτελεσματικές ιδιότητες θέματος.

Ο τύπος IThemeEffectiveData εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`font_scheme`](/slides/python-net/el/aspose.slides.theme/ithemeeffectivedata/font_scheme/) | Επιστρέφει το σχήμα γραμματοσειράς.<br/>            Μόνο ανάγνωση [`IFontSchemeEffectiveData`](/slides/python-net/el/aspose.slides.theme/ifontschemeeffectivedata). |
| [`format_scheme`](/slides/python-net/el/aspose.slides.theme/ithemeeffectivedata/format_scheme/) | Επιστρέφει το σχήμα μορφοποίησης σχήματος.<br/>            Μόνο ανάγνωση [`IFormatSchemeEffectiveData`](/slides/python-net/el/aspose.slides.theme/iformatschemeeffectivedata). |

## Μέθοδοι

| Μέθοδος | Περιγραφή |
| :- | :- |
| [`get_color_scheme(self, style_color)`](/slides/python-net/el/aspose.slides.theme/ithemeeffectivedata/get_color_scheme/#asposeslidescolor) | Επιστρέφει το σχήμα χρώματος. |

Αυτή η διεπαφή χρησιμοποιείται μαζί με τη διεπαφή [`ITheme`](/slides/python-net/el/aspose.slides.theme/itheme) για να επιστρέψει αποτελεσματικές τιμές μορφοποίησης με εφαρμογή κληρονομικότητας.
