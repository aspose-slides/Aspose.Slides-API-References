## FontScheme κλάση

Αποθηκεύει τις γραμματοσειρές που ορίζονται από το θέμα.

Ο τύπος FontScheme εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`minor`](/slides/python-net/el/aspose.slides.theme/fontscheme/minor/) | Επιστρέφει τη συλλογή γραμματοσειρών για το τμήμα "body" της διαφάνειας.<br/>Μόνο-ανάγνωση [`IFonts`](/slides/python-net/el/aspose.slides/ifonts). |
| [`major`](/slides/python-net/el/aspose.slides.theme/fontscheme/major/) | Επιστρέφει τη συλλογή γραμματοσειρών για το τμήμα "heading" της διαφάνειας.<br/>Μόνο-ανάγνωση [`IFonts`](/slides/python-net/el/aspose.slides/ifonts). |
| [`name`](/slides/python-net/el/aspose.slides.theme/fontscheme/name/) | Επιστρέφει το όνομα του σχήματος γραμματοσειράς.<br/>Ανάγνωση/εγγραφή **str**. |
