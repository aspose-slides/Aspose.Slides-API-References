## IExtraColorScheme κλάση

Αντιπροσωπεύει ένα πρόσθετο σχήμα χρωμάτων που μπορεί να ανατεθεί σε μια διαφάνεια.

Ο τύπος IExtraColorScheme εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`name`](/slides/python-net/el/aspose.slides.theme/iextracolorscheme/name/) | Επιστρέφει ένα όνομα αυτού του σχήματος.<br/>            Μόνο για ανάγνωση **str**. |
| [`color_scheme`](/slides/python-net/el/aspose.slides.theme/iextracolorscheme/color_scheme/) | Επιστρέφει ένα σχήμα χρωμάτων.<br/>            Μόνο για ανάγνωση [`IColorScheme`](/slides/python-net/el/aspose.slides.theme/icolorscheme). |
