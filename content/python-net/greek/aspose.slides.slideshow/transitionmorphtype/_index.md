## TransitionMorphType απαρίθμηση

Αναπαριστά έναν τύπο μετάβασης morph.

Ο τύπος TransitionMorphType εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| BY_OBJECT | Η μετάβαση morph θα πραγματοποιηθεί λαμβάνοντας υπόψη τα σχήματα ως αδιαίρετα αντικείμενα. |
| BY_WORD | Η μετάβαση morph θα πραγματοποιηθεί με τη μεταφορά κειμένου ανά λέξη όπου είναι δυνατόν. |
| BY_CHAR | Η μετάβαση morph θα πραγματοποιηθεί με τη μεταφορά κειμένου ανά χαρακτήρα όπου είναι δυνατόν. |
