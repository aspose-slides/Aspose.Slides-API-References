## SlideShowTransition κλάση

Αναπαριστά τη μετάβαση της προβολής διαφανειών.

Ο τύπος SlideShowTransition εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`sound`](/slides/python-net/el/aspose.slides.slideshow/slideshowtransition/sound/) | Επιστρέφει ή ορίζει τα ενσωματωμένα δεδομένα ήχου.<br/>            Read/write [`IAudio`](/slides/python-net/el/aspose.slides/iaudio). |
| [`sound_mode`](/slides/python-net/el/aspose.slides.slideshow/slideshowtransition/sound_mode/) | Ορίζει ή επιστρέφει τη λειτουργία ήχου για τη μετάβαση διαφανειών.<br/>            Read/write [`TransitionSoundMode`](/slides/python-net/el/aspose.slides.slideshow/transitionsoundmode). |
| [`sound_loop`](/slides/python-net/el/aspose.slides.slideshow/slideshowtransition/sound_loop/) | Αυτό το χαρακτηριστικό καθορίζει εάν ο ήχος θα επαναλαμβάνεται μέχρι να συμβεί το επόμενο γεγονός ήχου σε<br/>            παρουσίαση διαφανειών.<br/>            Read/write **bool**. |
| [`advance_on_click`](/slides/python-net/el/aspose.slides.slideshow/slideshowtransition/advance_on_click/) | Καθορίζει εάν ένα κλικ του ποντικιού θα προχωρήσει τη διαφάνεια ή όχι. Εάν αυτό το χαρακτηριστικό δεν<br/>            έχει οριστεί, τότε υποτίθεται τιμή true.<br/>            Read/write **bool**. |
| [`advance_after`](/slides/python-net/el/aspose.slides.slideshow/slideshowtransition/advance_after/) | Αυτό το χαρακτηριστικό καθορίζει εάν η παρουσίαση θα προχωρήσει στην επόμενη διαφάνεια μετά από κάποιο χρόνο.<br/>            Read/write **bool**. |
| [`advance_after_time`](/slides/python-net/el/aspose.slides.slideshow/slideshowtransition/advance_after_time/) | Καθορίζει το χρόνο, σε χιλιοστά του δευτερολέπτου, μετά τον οποίο η μετάβαση θα ξεκινήσει. Αυτή η ρύθμιση<br/>            μπορεί να χρησιμοποιηθεί μαζί με το χαρακτηριστικό advClick. Εάν αυτό το χαρακτηριστικό δεν έχει οριστεί<br/>            τότε υποτίθεται ότι δεν θα συμβεί αυτόματη μετάβαση.<br/>            Read/write **int**. |
| [`speed`](/slides/python-net/el/aspose.slides.slideshow/slideshowtransition/speed/) | Καθορίζει την ταχύτητα μετάβασης που θα χρησιμοποιηθεί κατά τη μετάβαση από την τρέχουσα διαφάνεια<br/>            στην επόμενη.<br/>            Read/write [`TransitionSpeed`](/slides/python-net/el/aspose.slides.slideshow/transitionspeed). |
| [`value`](/slides/python-net/el/aspose.slides.slideshow/slideshowtransition/value/) | Τιμή μετάβασης παρουσίασης διαφανειών.<br/>            Read-only [`ITransitionValueBase`](/slides/python-net/el/aspose.slides.slideshow/itransitionvaluebase). |
| [`type`](/slides/python-net/el/aspose.slides.slideshow/slideshowtransition/type/) | Τύπος μετάβασης.<br/>            Read/write [`TransitionType`](/slides/python-net/el/aspose.slides.slideshow/transitiontype). |
| [`sound_is_built_in`](/slides/python-net/el/aspose.slides.slideshow/slideshowtransition/sound_is_built_in/) | Καθορίζει εάν αυτός ο ήχος είναι ενσωματωμένος ή όχι. Εάν αυτό το χαρακτηριστικό οριστεί σε true τότε<br/>            η δημιουργική εφαρμογή ενημερώνεται για να ελέγξει το χαρακτηριστικό name που έχει οριστεί για αυτόν τον ήχο<br/>            στη λίστα ενσωματωμένων ήχων της και μπορεί τότε να εμφανίσει προσαρμοσμένο όνομα ή UI όπως απαιτείται.<br/>            Read-write **bool**. |
| [`sound_name`](/slides/python-net/el/aspose.slides.slideshow/slideshowtransition/sound_name/) | Καθορίζει ένα ανθρώπινα αναγνώσιμο όνομα για τον ήχο της μετάβασης. Η ιδιότητα [`SlideShowTransition.sound`](/slides/python-net/el/aspose.slides.slideshow/slideshowtransition/sound) πρέπει να εκχωρηθεί για να ληφθεί ή να οριστεί το όνομα του ήχου.<br/>            Read-write **str**. |
| [`duration`](/slides/python-net/el/aspose.slides.slideshow/slideshowtransition/duration/) | Λαμβάνει ή ορίζει τη διάρκεια του εφέ μετάβασης διαφάνειας σε χιλιοστά του δευτερολέπτου.<br/>            Read/write **int**. |
