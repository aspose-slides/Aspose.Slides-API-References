## name ιδιότητα
Επιστρέφει το όνομα αυτού του χρώματος.<br/>            Για ένα ονομασμένο χρώμα (μια ονομαστική σταθερά όπως `Color.red`, ή ένα χρώμα που δημιουργείται με [`from_name`](/slides/python-net/el/aspose.slides/color/from_name/)) επιστρέφεται το .NET όνομα, π.χ. `"Red"` ή `"LightBlue"`.<br/>            Για οποιοδήποτε άλλο χρώμα η τιμή ARGB επιστρέφεται ως δεκαεξαδικό πεζό χωρίς μηδενική συμπλήρωση, π.χ. `"ffff0000"`. `Color.empty.name` είναι `"0"`.
            Μόνο για ανάγνωση **str**.
