## from_rgb(r, g, b) {#int-int-int}
Δημιουργεί ένα αδιαπώνιο χρώμα (το άλφα είναι 255) από τις καθορισμένες τιμές κόκκινου, πράσινου και μπλε.

### Επιστρέφει

Το χρώμα που δημιουργείται από τις καθορισμένες τιμές.



```python
@staticmethod
def from_rgb(r, g, b):
    ...
```


| Παράμετρος | Τύπος | Περιγραφή |
| :- | :- | :- |
| r | **int** | Η τιμή του κόκκινου συνιστώσας. Οι έγκυρες τιμές είναι 0 έως 255. |
| g | **int** | Η τιμή του πράσινου συνιστώσας. Οι έγκυρες τιμές είναι 0 έως 255. |
| b | **int** | Η τιμή του μπλε συνιστώσας. Οι έγκυρες τιμές είναι 0 έως 255. |

### Εξαίρεσεις

| Εξαίρεση | Περιγραφή |
| :- | :- |
| **ValueError** | Μια τιμή συνιστώσας είναι μικρότερη από 0 ή μεγαλύτερη από 255. |
