## __init__(self, r=0, g=0, b=0, a=255) {#int-int-int-int}
Δημιουργεί ένα χρώμα από τις καθορισμένες τιμές των συνιστωσών κόκκινου, πράσινου, μπλε και άλφα.

```python
def __init__(self, r=0, g=0, b=0, a=255):
    ...
```

| Parameter | Type | Description |
| :- | :- | :- |
| r | **int** | Η τιμή της κόκκινης συνιστώσας. Οι έγκυρες τιμές είναι 0 έως 255. |
| g | **int** | Η τιμή της πράσινης συνιστώσας. Οι έγκυρες τιμές είναι 0 έως 255. |
| b | **int** | Η τιμή της μπλε συνιστώσας. Οι έγκυρες τιμές είναι 0 έως 255. |
| a | **int** | Η τιμή της άλφα συνιστώσας. Οι έγκυρες τιμές είναι 0 έως 255. |

### Εξαιρέσεις

| Exception | Description |
| :- | :- |
| **ValueError** | Μια τιμή συνιστώσας είναι μικρότερη από 0 ή μεγαλύτερη από 255. |
| **TypeError** | Μια τιμή συνιστώσας δεν είναι αριθμός. |
