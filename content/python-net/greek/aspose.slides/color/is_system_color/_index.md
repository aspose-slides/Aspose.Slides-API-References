## is_system_color ιδιότητα
Καθορίζει αν αυτό το χρώμα είναι σύστημα χρώματος: ένα χρώμα που χρησιμοποιείται για ένα στοιχείο εμφάνισης των Windows, όπως `Control` ή `ActiveBorder`.<br/>            Τα χρώματα συστήματος δεν εκτίθενται ως ιδιότητες `Color` και μπορούν να ληφθούν μόνο με [`from_known_color`](/slides/python-net/el/aspose.slides/color/from_known_color/) ή να επιστραφούν από τη βιβλιοθήκη.
            Μόνο για ανάγνωση **bool**.
