## from_argb(argb) {#int}
Δημιουργεί ένα χρώμα από μια τιμή ARGB 32-bit.

### Επιστρέφει

Το χρώμα που δημιουργήθηκε από την καθορισμένη τιμή.



```python
@staticmethod
def from_argb(argb):
    ...
```


| Παράμετρος | Τύπος | Περιγραφή |
| :- | :- | :- |
| argb | **int** | Μια τιμή που καθορίζει τη 32-bit τιμή ARGB (με πρόσημο ή χωρίς πρόσημο). |

### Εξαιρέσεις

| Exception | Description |
| :- | :- |
| **ValueError** | Μια τιμή στοιχείου είναι μικρότερη από 0 ή μεγαλύτερη από 255. |
| **TypeError** | Λάθος αριθμός ή τύπος ορισμάτων. |
