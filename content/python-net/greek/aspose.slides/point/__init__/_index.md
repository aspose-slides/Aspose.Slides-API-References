## __init__(self, x=0, y=0) {#int-int}
Δημιουργεί ένα σημείο με τις συγκεκριμένες συντεταγμένες. Οι τιμές κινητής υποδιαστολής περικοπώνται σε ακέραιους.


```python
def __init__(self, x=0, y=0):
    ...
```


| Παράμετρος | Τύπος | Περιγραφή |
| :- | :- | :- |
| x | **int** | Η οριζόντια θέση του σημείου. |
| y | **int** | Η κατακόρυφη θέση του σημείου. |

### Εξαιρέσεις

| Εξαίρεση | Περιγραφή |
| :- | :- |
| **TypeError** | Μια συντεταγμένη δεν είναι αριθμός. |
