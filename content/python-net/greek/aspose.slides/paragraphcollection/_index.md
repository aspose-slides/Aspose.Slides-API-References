## ParagraphCollection κλάση

Αντιπροσωπεύει μια συλλογή παραγράφων.

Ο τύπος ParagraphCollection εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`count`](/slides/python-net/el/aspose.slides/paragraphcollection/count/) | Λαμβάνει τον αριθμό των στοιχείων που περιέχονται πραγματικά στη συλλογή.<br/>            Μόνο για ανάγνωση **int**. |
| [`is_read_only`](/slides/python-net/el/aspose.slides/paragraphcollection/is_read_only/) | Λαμβάνει μια τιμή που υποδεικνύει εάν το **System.Collections.Generic.ICollection`1** είναι μόνο για ανάγνωση.<br/>            Μόνο για ανάγνωση **bool**. |
| [`slide`](/slides/python-net/el/aspose.slides/paragraphcollection/slide/) |  |
| [`presentation`](/slides/python-net/el/aspose.slides/paragraphcollection/presentation/) |  |

Λαμβάνει το στοιχείο στον καθορισμένο δείκτη.
