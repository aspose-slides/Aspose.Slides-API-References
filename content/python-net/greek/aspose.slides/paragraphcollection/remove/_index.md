## remove(self, item) {#iparagraph}
Αφαιρεί την πρώτη εμφάνιση ενός συγκεκριμένου αντικειμένου από το **System.Collections.Generic.ICollection`1**.

### Επιστρέφει

true εάν το `item` αφαιρέθηκε επιτυχώς από το **System.Collections.Generic.ICollection`1**· διαφορετικά, false. Αυτή η μέθοδος επιστρέφει επίσης false εάν το `item` δεν βρέθηκε στην αρχική **System.Collections.Generic.ICollection`1**.



```python
def remove(self, item):
    ...
```


| Παράμετρος | Τύπος | Περιγραφή |
| :- | :- | :- |
| item | [`IParagraph`](/slides/python-net/el/aspose.slides/iparagraph) | Το αντικείμενο που θα αφαιρεθεί από το **System.Collections.Generic.ICollection`1**. |

### Εξαιρέσεις

| Εξαίρεση | Περιγραφή |
| :- | :- |
| **RuntimeError(Proxy error(NotSupportedException))** | Το **System.Collections.Generic.ICollection`1** είναι μόνο για ανάγνωση. |
