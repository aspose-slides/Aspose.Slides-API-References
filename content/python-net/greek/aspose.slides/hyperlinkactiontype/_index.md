## Απαρίθμηση HyperlinkActionType

Αντιπροσωπεύει έναν τύπο ενέργειας υπερσύνδεσμου.

Ο τύπος HyperlinkActionType εκθέτει τα παρακάτω μέλη:

## Πεδία

| Field | Description |
| :- | :- |
| UNKNOWN | Μη αναγνωρίσιμος τύπος ενέργειας. |
| NO_ACTION | Καμία ενέργεια. |
| HYPERLINK | Συνηθισμένος υπερσύνδεσμος. |
| JUMP_FIRST_SLIDE | Μετάβαση στην πρώτη διαφάνεια της παρουσίασης. |
| JUMP_PREVIOUS_SLIDE | Μετάβαση στην προηγούμενη διαφάνεια. |
| JUMP_NEXT_SLIDE | Μετάβαση στην επόμενη διαφάνεια. |
| JUMP_LAST_SLIDE | Μετάβαση στην τελευταία διαφάνεια της παρουσίασης. |
| JUMP_END_SHOW | Μετάβαση στο τέλος της παρουσίασης διαφανειών. |
| JUMP_LAST_VIEWED_SLIDE | Μετάβαση στην τελευταία εμφανιζόμενη διαφάνεια. |
| JUMP_SPECIFIC_SLIDE | Μετάβαση σε συγκεκριμένη διαφάνεια, που αναφέρεται από την ιδιότητα [`IHyperlink.target_slide`](/slides/python-net/el/aspose.slides/ihyperlink/target_slide). |
| START_CUSTOM_SLIDE_SHOW | Έναρξη προσαρμοσμένης παρουσίασης διαφανειών. |
| OPEN_FILE | Άνοιγμα του αναφερθέντος αρχείου. |
| OPEN_PRESENTATION | Άνοιγμα της αναφερθένσης παρουσίασης. |
| START_STOP_MEDIA | Έναρξη/διακοπή αναπαραγωγής αρχείου μέσου. |
| START_MACRO | Έναρξη εκτέλεσης μακροεντολής. |
| START_PROGRAM | Έναρξη προγράμματος. |
