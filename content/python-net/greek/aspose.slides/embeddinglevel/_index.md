## EmbeddingLevel απαρίθμηση

Αντιπροσωπεύει τα δικαιώματα αδειοδότησης για την ενσωμάτωση της γραμματοσειράς.

Ο τύπος EmbeddingLevel εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| INSTALLABLE | Οι γραμματοσειρές με αυτή τη ρύθμιση υποδεικνύουν ότι μπορούν να ενσωματωθούν και να εγκατασταθούν μόνιμα στο απομακρυσμένο σύστημα από μια εφαρμογή. <br/>            Ο χρήστης του απομακρυσμένου συστήματος αποκτά τα ίδια δικαιώματα, υποχρεώσεις και άδειες για εκείνη τη γραμματοσειρά όπως ο αρχικός αγοραστής της γραμματοσειράς, <br/>            και υπόκειται στην ίδια συμφωνία τέλους χρήστη, πνευματικά δικαιώματα, σχεδιαστική πατέντα και/ή εμπορικό σήμα όπως ο αρχικός αγοραστής. |
| RESTRICTED | Οι γραμματοσειρές που έχουν μόνο αυτό το bit ενεργό δεν επιτρέπεται να τροποποιηθούν, ενσωματωθούν ή ανταλλαχθούν με οποιονδήποτε τρόπο χωρίς πρώτα να ληφθεί άδεια από τον νόμιμο ιδιοκτήτη. |
| PREVIEW_PRINT | Όταν αυτό το bit είναι ενεργό, η γραμματοσειρά μπορεί να ενσωματωθεί και να φορτωθεί προσωρινά στο απομακρυσμένο σύστημα. Τα έγγραφα που περιέχουν γραμματοσειρές Preview & <br/>            Print πρέπει να ανοίγονται "read-only;" δεν μπορούν να γίνουν επεξεργασίες στο έγγραφο. |
| EDITABLE | Όταν αυτό το bit είναι ενεργό, η γραμματοσειρά μπορεί να ενσωματωθεί αλλά πρέπει να εγκαθίσταται μόνο προσωρινά σε άλλα συστήματα. Σε αντίθεση με τις γραμματοσειρές Preview & <br/>            Print, τα έγγραφα που περιέχουν Editable γραμματοσειρές μπορούν να ανοίγονται για ανάγνωση, επιτρέπεται η επεξεργασία και μπορούν να αποθηκευτούν αλλαγές. |
| NO_SUBSETTING | Όταν αυτό το bit είναι ενεργό, η γραμματοσειρά δεν μπορεί να υποσύνολο προ της ενσωμάτωσης. Εφαρμόζονται επίσης άλλοι περιορισμοί ενσωμάτωσης που καθορίζονται στα bits 0-3 και 9. |
| BITMAP_ONLY | Όταν αυτό το bit είναι ενεργό, μόνο τα bitmap που περιέχονται στη γραμματοσειρά μπορούν να ενσωματωθούν. Δεν επιτρέπεται η ενσωμάτωση δεδομένων περιγράμματος. Εάν δεν υπάρχουν διαθέσιμα bitmap στη γραμματοσειρά, <br/>            τότε θεωρείται μη ενσωματώσιμη και οι υπηρεσίες ενσωμάτωσης θα αποτύχουν. |
