## SensitivityLabelContentType απαρίθμηση

Αντιπροσωπεύει τους τύπους σήμανσης περιεχομένου που πρέπει να εφαρμοστούν σε ένα έγγραφο.

Ο τύπος SensitivityLabelContentType εκθέτει τα παρακάτω μέλη:

## Πεδία

| Field | Description |
| :- | :- |
| NONE | Υποδηλώνει ότι η ετικέτα εφαρμόζεται εξ' ορισμού ή αυτόματα. |
| HEADER | Υποδηλώνει ότι η ετικέτα εφαρμόστηκε χειροκίνητα.<br/>            Χρησιμοποιήστε για οποιαδήποτε ετικέτα ευαισθησίας που εφαρμόστηκε άμεσα από τον χρήστη. |
| FOOTER | Υποδηλώνει ότι η ετικέτα εφαρμόστηκε χειροκίνητα.<br/>            Χρησιμοποιήστε για οποιαδήποτε ετικέτα ευαισθησίας που εφαρμόστηκε άμεσα από τον χρήστη. |
| WATERMARK | Υποδηλώνει ότι η ετικέτα εφαρμόστηκε χειροκίνητα.<br/>            Χρησιμοποιήστε για οποιαδήποτε ετικέτα ευαισθησίας που εφαρμόστηκε άμεσα από τον χρήστη. |
| ENCRYPTION | Υποδηλώνει ότι η ετικέτα εφαρμόστηκε χειροκίνητα.<br/>            Χρησιμοποιήστε για οποιαδήποτε ετικέτα ευαισθησίας που εφαρμόστηκε άμεσα από τον χρήστη. |
