## IPictureFillFormatEffectiveData κλάση

Αμετάβλητο αντικείμενο που περιέχει τις ιδιότητες της γέμισης εικόνας.

Ο τύπος IPictureFillFormatEffectiveData εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`dpi`](/slides/python-net/el/aspose.slides/ipicturefillformateffectivedata/dpi/) | Επιστρέφει το dpi που χρησιμοποιείται για τη γέμιση μιας εικόνας.<br/>            Μόνο για ανάγνωση **int**. |
| [`picture_fill_mode`](/slides/python-net/el/aspose.slides/ipicturefillformateffectivedata/picture_fill_mode/) | Επιστρέφει τη λειτουργία γέμισης εικόνας.<br/>            Μόνο για ανάγνωση [`PictureFillMode`](/slides/python-net/el/aspose.slides/picturefillmode). |
| [`picture`](/slides/python-net/el/aspose.slides/ipicturefillformateffectivedata/picture/) | Επιστρέφει την εικόνα.<br/>            Μόνο για ανάγνωση [`IPictureEffectiveData`](/slides/python-net/el/aspose.slides/ipictureeffectivedata). |
| [`crop_left`](/slides/python-net/el/aspose.slides/ipicturefillformateffectivedata/crop_left/) | Επιστρέφει τον αριθμό των ποσοστών του πραγματικού πλάτους της εικόνας που περικόπτονται<br/>            από την αριστερά της εικόνας. <br/>            Μόνο για ανάγνωση **float**. |
| [`crop_top`](/slides/python-net/el/aspose.slides/ipicturefillformateffectivedata/crop_top/) | Επιστρέφει τον αριθμό των ποσοστών του πραγματικού ύψους της εικόνας που περικόπτονται<br/>            από την κορυφή της εικόνας. <br/>            Μόνο για ανάγνωση **float**. |
| [`crop_right`](/slides/python-net/el/aspose.slides/ipicturefillformateffectivedata/crop_right/) | Επιστρέφει τον αριθμό των ποσοστών του πραγματικού πλάτους της εικόνας που περικόπτονται<br/>            από τη δεξιά της εικόνας. <br/>            Μόνο για ανάγνωση **float**. |
| [`crop_bottom`](/slides/python-net/el/aspose.slides/ipicturefillformateffectivedata/crop_bottom/) | Επιστρέφει τον αριθμό των ποσοστών του πραγματικού ύψους της εικόνας που περικόπτονται<br/>            από το κάτω μέρος της εικόνας. <br/>            Μόνο για ανάγνωση **float**. |
