## ResourceLoadingAction απαρίθμηση

Καθορίζει τη λειτουργία φόρτωσης εξωτερικών πόρων.

Ο τύπος ResourceLoadingAction εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| DEFAULT | Aspose.Slides θα φορτώνει εξωτερικούς πόρους όπως συνήθως. |
| SKIP | Aspose.Slides θα παραλείψει τη φόρτωση εξωτερικού πόρου. Θα αποθηκεύεται μόνο ο σύνδεσμος χωρίς δεδομένα για μια εικόνα. |
| USER_PROVIDED | Aspose.Slides θα χρησιμοποιήσει τον πίνακα byte που παρέχεται από τον χρήστη στη **Aspose.Slides.IResourceLoadingArgs.SetData(Syste** ως δεδομένα εικόνας. |
