## volume_value ιδιότητα
Επιστρέφει ή ορίζει την ακριβή ένταση βίντεο ως ποσοστό.
             Η τιμή εκφράζεται ως ποσοστό από 0 έως 100. Χρησιμοποιήστε αυτή την ιδιότητα για να διαβάζετε ή να ορίζετε τιμές έντασης που είναι πιο ακριβείς από τα προδιαγεγραμμένα επίπεδα που διατίθενται μέσω της [`VideoFrame.volume`](/slides/python-net/el/aspose.slides/videoframe/volume) ιδιότητας.
             Ανάγνωση/εγγραφή **float**.
