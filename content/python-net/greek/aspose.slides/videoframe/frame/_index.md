## ιδιότητα πλαισίου
Επιστρέφει ή ορίζει τις ιδιότητες του πλαισίου σχήματος.
Ανάγνωση/εγγραφή [`IShapeFrame`](/slides/python-net/el/aspose.slides/ishapeframe).

### Παρατηρήσεις

Η τιμή κάθε ιδιότητας του επιστρεφόμενου IShapeFrame δεν είναι undefined (δεν είναι NaN ή NotDefined).
Η τιμή κάθε ιδιότητας του εκχωρημένου IShapeFrame πρέπει να μην είναι undefined (πρέπει να μην είναι NaN ή NotDefined).
Μπορείτε να ορίσετε τιμές undefined για τις ιδιότητες του αντικειμένου RawFrame.
