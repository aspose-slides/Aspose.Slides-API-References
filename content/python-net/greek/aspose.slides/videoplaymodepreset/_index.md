## VideoPlayModePreset αρίθμηση

Σταθερές που ορίζουν πώς αναπαράγεται ένα βίντεο.

Ο τύπος VideoPlayModePreset εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| MIXED |  |
| AUTO | Αναπαράγεται αυτόματα. |
| ON_CLICK | Αναπαράγεται μόνο όταν γίνεται κλικ στο πλαίσιο του βίντεο. |
| ALL_SLIDES | Αναπαράγεται σε όλες τις διαφάνειες. |
| IN_CLICK_SEQUENCE | Αναπαράγεται αυτόματα με κλικ. |
