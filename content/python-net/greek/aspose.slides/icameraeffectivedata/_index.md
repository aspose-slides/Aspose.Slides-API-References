## ICameraEffectiveData class

Αμετάβλητο αντικείμενο που περιέχει τις αποτελεσματικές ιδιότητες της κάμερας.

Ο τύπος ICameraEffectiveData εκθέτει τα παρακάτω μέλη:

## Properties

| Property | Description |
| :- | :- |
| [`camera_type`](/slides/python-net/el/aspose.slides/icameraeffectivedata/camera_type/) | Τύπος κάμερας.<br/>Μόνο για ανάγνωση [`CameraPresetType`](/slides/python-net/el/aspose.slides/camerapresettype). |
| [`field_of_view_angle`](/slides/python-net/el/aspose.slides/icameraeffectivedata/field_of_view_angle/) | Γωνία θέασης κάμερας (0-180 deg, field of View).<br/>Μόνο για ανάγνωση **float**. |
| [`zoom`](/slides/python-net/el/aspose.slides/icameraeffectivedata/zoom/) | Ζουμ κάμερας (positive value in percentage).<br/>Μόνο για ανάγνωση **float**. |

## Methods

| Method | Description |
| :- | :- |
| [`get_rotation(self)`](/slides/python-net/el/aspose.slides/icameraeffectivedata/get_rotation/#) | Μια περιστροφή ορίζεται μέσω της χρήσης μιας συντεταγμένης γεωγραφικού πλάτους<br/>συντεταγμένης γεωγραφικού μήκους και μιας επανάληψης γύρω από τον άξονα <br/>ως οι συντεταγμένες γεωγραφικού πλάτους και μήκους.<br/>πρώτο στοιχείο στον πίνακα επιστροφής - πλάτος, δεύτερο - μήκος, τρίτο - επανάληψη.<br/>Επιστρέφει None αν δεν έχει οριστεί περιστροφή. |
