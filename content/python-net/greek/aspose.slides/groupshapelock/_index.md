## GroupShapeLock κλάση

Καθορίζει ποιες λειτουργίες είναι απενεργοποιημένες στο γονικό GroupShape.

**Κληρονομικότητα:**[`GroupShapeLock`](/slides/python-net/el/aspose.slides/groupshapelock) → [`BaseShapeLock`](/slides/python-net/el/aspose.slides/baseshapelock)

Ο τύπος GroupShapeLock εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`no_locks`](/slides/python-net/el/aspose.slides/groupshapelock/no_locks/) | Επιστρέφει true εάν όλα τα lock-flags είναι απενεργοποιημένα.<br/>            Μόνο για ανάγνωση **bool**. |
| [`grouping_locked`](/slides/python-net/el/aspose.slides/groupshapelock/grouping_locked/) | Καθορίζει εάν η προσθήκη αυτού του σχήματος σε ομάδα είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`ungrouping_locked`](/slides/python-net/el/aspose.slides/groupshapelock/ungrouping_locked/) | Καθορίζει εάν ο διαχωρισμός αυτού του groupshape είναι απαγορευμένος.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`select_locked`](/slides/python-net/el/aspose.slides/groupshapelock/select_locked/) | Καθορίζει εάν η επιλογή αυτού του σχήματος είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`rotation_locked`](/slides/python-net/el/aspose.slides/groupshapelock/rotation_locked/) | Καθορίζει εάν η αλλαγή της γωνίας περιστροφής αυτού του σχήματος είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/el/aspose.slides/groupshapelock/aspect_ratio_locked/) | Καθορίζει εάν το σχήμα πρέπει να διατηρεί την αναλογία διαστάσεων κατά την αλλαγή μεγέθους.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`position_locked`](/slides/python-net/el/aspose.slides/groupshapelock/position_locked/) | Καθορίζει εάν η μετακίνηση αυτού του σχήματος είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`size_locked`](/slides/python-net/el/aspose.slides/groupshapelock/size_locked/) | Καθορίζει εάν η αλλαγή μεγέθους αυτού του σχήματος είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
