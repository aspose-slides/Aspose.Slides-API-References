## PictureFrameLock κλάση

Καθορίζει ποιες λειτουργίες είναι απενεργοποιημένες στο γονικό PictureFrame.

**Κληρονομικότητα:**[`PictureFrameLock`](/slides/python-net/el/aspose.slides/pictureframelock) → [`BaseShapeLock`](/slides/python-net/el/aspose.slides/baseshapelock)

Ο τύπος PictureFrameLock εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`no_locks`](/slides/python-net/el/aspose.slides/pictureframelock/no_locks/) | Επιστρέφει true αν όλα τα lock-flags είναι απενεργοποιημένα.<br/>            Μόνο για ανάγνωση **bool**. |
| [`grouping_locked`](/slides/python-net/el/aspose.slides/pictureframelock/grouping_locked/) | Καθορίζει αν η προσθήκη αυτού του σχήματος σε μια ομάδα είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`select_locked`](/slides/python-net/el/aspose.slides/pictureframelock/select_locked/) | Καθορίζει αν η επιλογή αυτού του σχήματος είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`rotation_locked`](/slides/python-net/el/aspose.slides/pictureframelock/rotation_locked/) | Καθορίζει αν η αλλαγή της γωνίας περιστροφής αυτού του σχήματος είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/el/aspose.slides/pictureframelock/aspect_ratio_locked/) | Καθορίζει αν ένα σχήμα πρέπει να διατηρεί το λόγο διαστάσεων κατά την αλλαγή μεγέθους.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`position_locked`](/slides/python-net/el/aspose.slides/pictureframelock/position_locked/) | Καθορίζει αν η μετακίνηση αυτού του σχήματος είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`size_locked`](/slides/python-net/el/aspose.slides/pictureframelock/size_locked/) | Καθορίζει αν η αλλαγή μεγέθους αυτού του σχήματος είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`edit_points_locked`](/slides/python-net/el/aspose.slides/pictureframelock/edit_points_locked/) | Καθορίζει αν η άμεση αλλαγή του περιγράμματος αυτού του σχήματος είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`adjust_handles_locked`](/slides/python-net/el/aspose.slides/pictureframelock/adjust_handles_locked/) | Καθορίζει αν η αλλαγή των τιμών προσαρμογής είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`arrowheads_locked`](/slides/python-net/el/aspose.slides/pictureframelock/arrowheads_locked/) | Καθορίζει αν η αλλαγή των ακροβόλων είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`shape_type_locked`](/slides/python-net/el/aspose.slides/pictureframelock/shape_type_locked/) | Καθορίζει αν η αλλαγή του τύπου του σχήματος είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`crop_locked`](/slides/python-net/el/aspose.slides/pictureframelock/crop_locked/) | Καθορίζει αν η περικοπή εικόνας είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
