## IConnectorLock κλάση

Καθορίζει ποιες ενέργειες είναι απενεργοποιημένες στον γονικό Connector.

Ο τύπος IConnectorLock εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`grouping_locked`](/slides/python-net/el/aspose.slides/iconnectorlock/grouping_locked/) | Καθορίζει αν η προσθήκη αυτού του σχήματος σε ομάδα είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`select_locked`](/slides/python-net/el/aspose.slides/iconnectorlock/select_locked/) | Καθορίζει αν η επιλογή αυτού του σχήματος είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`rotate_locked`](/slides/python-net/el/aspose.slides/iconnectorlock/rotate_locked/) | Καθορίζει αν η αλλαγή της γωνίας περιστροφής αυτού του σχήματος είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/el/aspose.slides/iconnectorlock/aspect_ratio_locked/) | Καθορίζει αν ένα σχήμα πρέπει να διατηρεί την αναλογία διαστάσεων κατά την αλλαγή μεγέθους.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`position_move`](/slides/python-net/el/aspose.slides/iconnectorlock/position_move/) | Καθορίζει αν η μετακίνηση αυτού του σχήματος είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`size_locked`](/slides/python-net/el/aspose.slides/iconnectorlock/size_locked/) | Καθορίζει αν η αλλαγή μεγέθους αυτού του σχήματος είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`edit_points_locked`](/slides/python-net/el/aspose.slides/iconnectorlock/edit_points_locked/) | Καθορίζει αν η άμεση αλλαγή του περιγράμματος αυτού του σχήματος είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`adjust_handles_locked`](/slides/python-net/el/aspose.slides/iconnectorlock/adjust_handles_locked/) | Καθορίζει αν η αλλαγή των τιμών προσαρμογής είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`arrowheads_locked`](/slides/python-net/el/aspose.slides/iconnectorlock/arrowheads_locked/) | Καθορίζει αν η αλλαγή των άκρων βέλους είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`shape_type_locked`](/slides/python-net/el/aspose.slides/iconnectorlock/shape_type_locked/) | Καθορίζει αν η αλλαγή του τύπου σχήματος είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`no_locks`](/slides/python-net/el/aspose.slides/iconnectorlock/no_locks/) |  |
