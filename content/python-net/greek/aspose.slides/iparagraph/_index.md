## IParagraph κλάση

Αναπαριστά μια παράγραφο κειμένου.

Ο τύπος IParagraph εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Property | Description |
| :- | :- |
| [`portions`](/slides/python-net/el/aspose.slides/iparagraph/portions/) | Επιστρέφει τη συλλογή των τμημάτων κειμένου.<br/>            Μόνο για ανάγνωση [`IPortionCollection`](/slides/python-net/el/aspose.slides/iportioncollection). |
| [`paragraph_format`](/slides/python-net/el/aspose.slides/iparagraph/paragraph_format/) | Επιστρέφει το αντικείμενο μορφοποίησης για αυτήν την παράγραφο.<br/>            Μόνο για ανάγνωση [`IParagraphFormat`](/slides/python-net/el/aspose.slides/iparagraphformat). |
| [`text`](/slides/python-net/el/aspose.slides/iparagraph/text/) | Λαμβάνει ή ορίζει το ακατέργαστο κείμενο μιας παραγράφου.<br/>            Ανάγνωση/εγγραφή **str**. |
| [`end_paragraph_portion_format`](/slides/python-net/el/aspose.slides/iparagraph/end_paragraph_portion_format/) | Καθορίζει τις ιδιότητες τμήματος που θα χρησιμοποιηθούν εάν ένα άλλο τμήμα εισαχθεί μετά <br/>            το τελευταίο. |
| [`slide`](/slides/python-net/el/aspose.slides/iparagraph/slide/) |  |
| [`presentation`](/slides/python-net/el/aspose.slides/iparagraph/presentation/) |  |

## Μέθοδοι

| Method | Description |
| :- | :- |
| [`get_image`](/slides/python-net/el/aspose.slides/iparagraph/get_image/#) | Επιστρέφει μια εικόνα της παραγράφου. |
| [`get_image`](/slides/python-net/el/aspose.slides/iparagraph/get_image/#float-float) | Επιστρέφει μια εικόνα της παραγράφου με την καθορισμένη κλίμακα. |
| [`join_portions_with_same_formatting`](/slides/python-net/el/aspose.slides/iparagraph/join_portions_with_same_formatting/#) | Συνδέει τμήματα με την ίδια μορφοποίηση. |
| [`get_rect`](/slides/python-net/el/aspose.slides/iparagraph/get_rect/#) | Λαμβάνει τις συντεταγμένες του ορθογωνίου που περιορίζει την παράγραφο. Το ορθογώνιο περιλαμβάνει όλες τις γραμμές του<br/>            κειμένου στην παράγραφο, συμπεριλαμβανομένων και των κενών. |
| [`get_lines_count`](/slides/python-net/el/aspose.slides/iparagraph/get_lines_count/#) | Λαμβάνει τον αριθμό των γραμμών σε μια παράγραφο. |
