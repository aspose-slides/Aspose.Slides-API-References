## IParagraph κλάση

Αντιπροσωπεύει μια παράγραφο κειμένου.

Ο τύπος IParagraph εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`portions`](/slides/python-net/el/aspose.slides/iparagraph/portions/) | Returns the collection of a text portions.<br/>            Read-only [`IPortionCollection`](/slides/python-net/el/aspose.slides/iportioncollection). |
| [`paragraph_format`](/slides/python-net/el/aspose.slides/iparagraph/paragraph_format/) | Returns the formatting object for this paragraph.<br/>            Read-only [`IParagraphFormat`](/slides/python-net/el/aspose.slides/iparagraphformat). |
| [`text`](/slides/python-net/el/aspose.slides/iparagraph/text/) | Gets or sets the the plain text of a paragraph.<br/>            Read/write **str**. |
| [`end_paragraph_portion_format`](/slides/python-net/el/aspose.slides/iparagraph/end_paragraph_portion_format/) | Specifies the portion properties that are to be used if another portion is inserted after <br/>            the last one. |
| [`slide`](/slides/python-net/el/aspose.slides/iparagraph/slide/) |  |
| [`presentation`](/slides/python-net/el/aspose.slides/iparagraph/presentation/) |  |
