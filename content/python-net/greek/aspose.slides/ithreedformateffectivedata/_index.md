## IThreeDFormatEffectiveData κλάση

Αμετάβλητο αντικείμενο που αντιπροσωπεύει τις αποτελεσματικές ιδιότητες μορφοποίησης 3Δ.

Ο τύπος IThreeDFormatEffectiveData εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Property | Description |
| :- | :- |
| [`contour_width`](/slides/python-net/el/aspose.slides/ithreedformateffectivedata/contour_width/) | Επιστρέφει το πλάτος ενός 3Δ περιγράμματος.<br/>            Μόνο ανάγνωση **float**. |
| [`extrusion_height`](/slides/python-net/el/aspose.slides/ithreedformateffectivedata/extrusion_height/) | Επιστρέφει το ύψος ενός εφέ εξώθησης.<br/>            Μόνο ανάγνωση **float**. |
| [`depth`](/slides/python-net/el/aspose.slides/ithreedformateffectivedata/depth/) | Επιστρέφει το βάθος ενός 3Δ σχήματος.<br/>            Μόνο ανάγνωση **float**. |
| [`bevel_top`](/slides/python-net/el/aspose.slides/ithreedformateffectivedata/bevel_top/) | Επιστρέφει τον τύπο ενός επάνω 3Δ bevel.<br/>            Μόνο ανάγνωση [`IShapeBevelEffectiveData`](/slides/python-net/el/aspose.slides/ishapebeveleffectivedata). |
| [`bevel_bottom`](/slides/python-net/el/aspose.slides/ithreedformateffectivedata/bevel_bottom/) | Επιστρέφει τον τύπο ενός κάτω 3Δ bevel.<br/>            Μόνο ανάγνωση [`IShapeBevelEffectiveData`](/slides/python-net/el/aspose.slides/ishapebeveleffectivedata). |
| [`contour_color`](/slides/python-net/el/aspose.slides/ithreedformateffectivedata/contour_color/) | Επιστρέφει το χρώμα ενός περιγράμματος.<br/>            Μόνο ανάγνωση **aspose.slides.Color**. |
| [`extrusion_color`](/slides/python-net/el/aspose.slides/ithreedformateffectivedata/extrusion_color/) | Επιστρέφει το χρώμα μιας εξώθησης.<br/>            Μόνο ανάγνωση **aspose.slides.Color**. |
| [`camera`](/slides/python-net/el/aspose.slides/ithreedformateffectivedata/camera/) | Επιστρέφει τις ρυθμίσεις μιας κάμερας.<br/>            Μόνο ανάγνωση [`ICameraEffectiveData`](/slides/python-net/el/aspose.slides/icameraeffectivedata). |

| [`material`](/slides/python-net/el/aspose.slides/ithreedformateffectivedata/material/) | Επιστρέφει τον τύπο ενός υλικού.<br/>            Μόνο ανάγνωση [`MaterialPresetType`](/slides/python-net/el/aspose.slides/materialpresettype). |
