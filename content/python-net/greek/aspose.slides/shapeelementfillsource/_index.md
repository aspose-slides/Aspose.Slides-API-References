## ShapeElementFillSource απαρίθμηση

Αντιπροσωπεύει πώς πρέπει να γεμίσει το στοιχείο σχήματος.

Ο τύπος ShapeElementFillSource εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| NO_FILL | Δεν γεμίζει το primitive. |
| SHAPE | Χρησιμοποίησε το γέμισμα του σχήματος. |
| LIGHTEN | Χρησιμοποίησε το ελαφρύ γέμισμα του σχήματος. |
| LIGHTEN_LESS | Χρησιμοποίησε λιγότερο ελαφρύ γέμισμα του σχήματος. |
| DARKEN | Χρησιμοποίησε το σκοτεινό γέμισμα του σχήματος. |
| DARKEN_LESS | Χρησιμοποίησε λιγότερο σκοτεινό γέμισμα του σχήματος. |
