## insert_chart(self, type, x, y, width, height, index) {#asposeslideschartscharttype-float-float-float-float-int}
Δημιουργεί ένα νέο διάγραμμα, το αρχικοποιεί με δείγμα δεδομένων σειράς και ρυθμίσεις,
            και το εισάγει στη συλλογή σχήματος στο καθορισμένο ευρετήριο.

### Επιστρέφει

Το νέο δημιουργημένο [`IChart`](/slides/python-net/el/aspose.slides.charts/ichart).



```python
def insert_chart(self, type, x, y, width, height, index):
    ...
```


| Parameter | Type | Description |
| :- | :- | :- |
| type | [`ChartType`](/slides/python-net/el/aspose.slides.charts/charttype) | Ο τύπος του διαγράμματος προς δημιουργία. |
| x | **float** | Η συντεταγμένη x του νέου διαγράμματος, σε μονάδες σημείου. |
| y | **float** | Η συντεταγμένη y του νέου διαγράμματος, σε μονάδες σημείου. |
| width | **float** | Το πλάτος του νέου διαγράμματος, σε μονάδες σημείου. |
| height | **float** | Το ύψος του νέου διαγράμματος, σε μονάδες σημείου. |
| index | **int** | Ο δείκτης μηδενικής βάσης στο οποίο θα εισαχθεί το νέο διάγραμμα στη συλλογή σχήματος. |
