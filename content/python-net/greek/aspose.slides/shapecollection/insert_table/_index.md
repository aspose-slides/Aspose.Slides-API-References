## insert_table(self, index, x, y, column_widths, row_heights) {#int-float-float-listfloat-listfloat}
Δημιουργεί έναν νέο πίνακα και τον εισάγει στη συλλογή σχημάτων στην καθορισμένη θέση.

### Επιστρέφει

Το νέο [`ITable`](/slides/python-net/el/aspose.slides/itable).

```python
def insert_table(self, index, x, y, column_widths, row_heights):
    ...
```

| Παράμετρος | Τύπος | Περιγραφή |
| :- | :- | :- |
| index | **int** | Ο μηδενικός δείκτης στον οποίο θα εισαχθεί ο πίνακας. |
| x | **float** | Η συντεταγμένη x του πίνακα, σε μονάδες σημείου. |
| y | **float** | Η συντεταγμένη y του πίνακα, σε μονάδες σημείου. |
| column_widths | **List[float]** | Ένας πίνακας διπλών που αντιπροσωπεύει το πλάτος των στηλών του πίνακα<br/><br/>            σε μονάδες σημείου. |
| row_heights | **List[float]** | Ένας πίνακας διπλών που αντιπροσωπεύει το ύψος των γραμμών του πίνακα<br/><br/>            σε μονάδες σημείου. |
