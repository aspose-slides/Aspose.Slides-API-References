## insert_summary_zoom_frame(self, index, x, y, width, height) {#int-float-float-float-float}
Δημιουργεί ένα νέο πλαίσιο Summary Zoom και το τοποθετεί στη συλλογή σχημάτων στη συγκεκριμένη θέση.

### Returns

Το νεοδημιουργημένο [`ISummaryZoomFrame`](/slides/python-net/el/aspose.slides/isummaryzoomframe).



```python
def insert_summary_zoom_frame(self, index, x, y, width, height):
    ...
```


| Παράμετρος | Τύπος | Περιγραφή |
| :- | :- | :- |
| index | **int** | Ο μηδενικός δείκτης στο οποίο θα εισαχθεί το πλαίσιο Summary Zoom. |
| x | **float** | Η συντεταγμένη x του νέου πλαισίου Summary Zoom, σε μονάδες σημείου. |
| y | **float** | Η συντεταγμένη y του νέου πλαισίου Summary Zoom, σε μονάδες σημείου. |
| width | **float** | Το πλάτος του νέου πλαισίου Summary Zoom, σε μονάδες σημείου. |
| height | **float** | Το ύψος του νέου πλαισίου Summary Zoom, σε μονάδες σημείου. |

### Παρατηρήσεις

Αυτή η μέθοδος δημιουργεί ένα πλαίσιο Summary Zoom που συγκεντρώνει συνδέσμους σύνοψης για όλες τις ενότητες στην παρουσίαση.
