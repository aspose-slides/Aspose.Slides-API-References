```python
def insert_audio_frame_linked(self, index, x, y, width, height, fname):
    ...
```

| Παράμετρος | Τύπος | Περιγραφή |
| :- | :- | :- |
| index | **int** | Ο μηδενικής βάσης δείκτης στον οποίο θα εισαχθεί το πλαίσιο ήχου. |
| x | **float** | Η συντεταγμένη x του νέου πλαισίου ήχου, σε μονάδες σημείων. |
| y | **float** | Η συντεταγμένη y του νέου πλαισίου ήχου, σε μονάδες σημείων. |
