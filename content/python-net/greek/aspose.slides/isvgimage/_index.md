## ISvgImage κλάση

Αντιπροσωπεύει μια εικόνα SVG.

Ο τύπος ISSvgImage εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`svg_content`](/slides/python-net/el/aspose.slides/isvgimage/svg_content/) | Επιστρέφει το περιεχόμενο SVG.<br/>            Μόνο για ανάγνωση **str**. |
| [`svg_data`](/slides/python-net/el/aspose.slides/isvgimage/svg_data/) | Επιστρέφει τα δεδομένα SVG.<br/>            Μόνο για ανάγνωση **int**[]. |
| [`external_resource_resolver`](/slides/python-net/el/aspose.slides/isvgimage/external_resource_resolver/) | Επιστρέφει το interface callback που χρησιμοποιείται για την επίλυση εξωτερικών πόρων κατά την εισαγωγή εγγράφων SVG.<br/>            Μόνο για ανάγνωση **IExternalResourceResolver**. |
| [`base_uri`](/slides/python-net/el/aspose.slides/isvgimage/base_uri/) | Επιστρέφει το βασικό URI του συγκεκριμένου SVG. Χρησιμοποιείται για την επίλυση σχετικά συνδέσμων.<br/>            Μόνο για ανάγνωση **str**. |

## Μέθοδοι

| :- | :- |
