## FontSubstCondition απαρίθμηση

Αντιπροσωπεύει έναν κανόνα για την αντικατάσταση γραμματοσειράς

Ο τύπος FontSubstCondition εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| WHEN_INACCESSIBLE | Αντικατάσταση όταν η γραμματοσειρά δεν βρέθηκε |
| ALWAYS | Αντικατάσταση πάντα |
