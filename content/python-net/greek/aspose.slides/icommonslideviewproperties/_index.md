## ICommonSlideViewProperties κλάση

Αναπαριστά τις κοινές ιδιότητες προβολής διαφάνειας.

Ο τύπος ICommonSlideViewProperties εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`scale`](/slides/python-net/el/aspose.slides/icommonslideviewproperties/scale/) | Καθορίζει τον λόγο κλιμάκωσης προβολής σε ποσοστά.<br/>            Ανάγνωση/εγγραφή **int**. |
| [`variable_scale`](/slides/python-net/el/aspose.slides/icommonslideviewproperties/variable_scale/) | Καθορίζει ότι το περιεχόμενο προβολής πρέπει να κλιμακωθεί αυτόματα ώστε να ταιριάζει καλύτερα στο τρέχον μέγεθος παραθύρου.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`drawing_guides`](/slides/python-net/el/aspose.slides/icommonslideviewproperties/drawing_guides/) | Επιστρέφει τη συλλογή των οδηγών σχεδίασης.<br/>            Μόνο-ανάγνωση [`IDrawingGuidesCollection`](/slides/python-net/el/aspose.slides/idrawingguidescollection) |
