## BuildVersionInfo κλάση

Περιέχει πληροφορίες σχετικά με την έκδοση του Aspose.Slides.

Ο τύπος BuildVersionInfo εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`ASSEMBLY_VERSION`](/slides/python-net/el/aspose.slides/buildversioninfo/assembly_version/) | Έκδοση του assembly του Aspose.Slides. |
| [`FILE_VERSION`](/slides/python-net/el/aspose.slides/buildversioninfo/file_version/) | Έκδοση του αρχείου assembly. |
| [`PRODUCT`](/slides/python-net/el/aspose.slides/buildversioninfo/product/) | Όνομα προϊόντος του Aspose.Slides |
| [`PRODUCT_MAJOR`](/slides/python-net/el/aspose.slides/buildversioninfo/product_major/) | Αριθμός κύριας έκδοσης. |
| [`PRODUCT_MINOR`](/slides/python-net/el/aspose.slides/buildversioninfo/product_minor/) | Αριθμός μικρής έκδοσης. |
| [`RELEASE_DATE`](/slides/python-net/el/aspose.slides/buildversioninfo/release_date/) | Ημερομηνία κυκλοφορίας του assembly. |
