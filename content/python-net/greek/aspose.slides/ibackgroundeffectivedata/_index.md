## IBackgroundEffectiveData κλάση

Αμετάβλητο αντικείμενο που περιέχει τις αποτελεσματικές ιδιότητες του υποβάθρου.

Ο τύπος IBackgroundEffectiveData εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`fill_format`](/slides/python-net/el/aspose.slides/ibackgroundeffectivedata/fill_format/) | Επιστρέφει την αποτελεσματική μορφή γεμίσματος.<br/>            Μόνο για ανάγνωση [`IFillFormatEffectiveData`](/slides/python-net/el/aspose.slides/ifillformateffectivedata). |
| [`effect_format`](/slides/python-net/el/aspose.slides/ibackgroundeffectivedata/effect_format/) | Επιστρέφει την αποτελεσματική μορφή εφέ.<br/>            Μόνο για ανάγνωση [`IEffectFormatEffectiveData`](/slides/python-net/el/aspose.slides/ieffectformateffectivedata). |


### Σχόλια

Αυτή η διεπαφή χρησιμοποιείται μαζί με τη διεπαφή [`IBackground`](/slides/python-net/el/aspose.slides/ibackground) για την επιστροφή αποτελεσματικών τιμών μορφοποίησης με εφαρμογή κληρονομικότητας.
