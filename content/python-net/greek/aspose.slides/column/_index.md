## Column κλάση

Αντιπροσωπεύει μια στήλη σε έναν πίνακα.

**Κληρονομικότητα:**[`Column`](/slides/python-net/el/aspose.slides/column) → [`CellCollection`](/slides/python-net/el/aspose.slides/cellcollection)

Ο τύπος Column εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`slide`](/slides/python-net/el/aspose.slides/column/slide/) | Επιστρέφει τη γονική διαφάνεια μιας CellCollection.<br/>            Μόνο ανάγνωση [`IBaseSlide`](/slides/python-net/el/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/el/aspose.slides/column/presentation/) | Επιστρέφει τη γονική παρουσίαση μιας CellCollection.<br/>            Μόνο ανάγνωση [`IPresentation`](/slides/python-net/el/aspose.slides/ipresentation). |
| [`width`](/slides/python-net/el/aspose.slides/column/width/) | Επιστρέφει ή ορίζει το πλάτος μιας στήλης.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`column_format`](/slides/python-net/el/aspose.slides/column/column_format/) | Επιστρέφει το αντικείμενο ColumnFormat που περιέχει ιδιότητες διαμόρφωσης για αυτή τη στήλη.<br/>            Μόνο ανάγνωση [`IColumnFormat`](/slides/python-net/el/aspose.slides/icolumnformat). |
