## ITextSearchOptions κλάση

Καταγράφει επιλογές που μπορούν να χρησιμοποιηθούν για την αναζήτηση κειμένου σε μια Presentation, Slide ή TextFrame.

Ο τύπος ITextSearchOptions εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`case_sensitive`](/slides/python-net/el/aspose.slides/itextsearchoptions/case_sensitive/) | Ορίστε true για να χρησιμοποιήσετε αναζήτηση με διάκριση πεζών-κεφαλαίων, false - διαφορετικά.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`whole_words_only`](/slides/python-net/el/aspose.slides/itextsearchoptions/whole_words_only/) | Ορίστε true για να ταιριάξετε μόνο ολόκληρες λέξεις, false - διαφορετικά.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`include_notes`](/slides/python-net/el/aspose.slides/itextsearchoptions/include_notes/) | Ορίστε `true` για να συμπεριλάβετε κείμενο που περιέχεται σε σημειώσεις διαφάνειας <br/>            όταν εκτελείτε λειτουργίες αναζήτησης κειμένου, αντικατάστασης ή επισήμανσης.<br/>            Η προεπιλεγμένη τιμή είναι `false`. |
