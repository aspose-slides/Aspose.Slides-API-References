## HyperlinkQueries κλάση

Παρέχει εύκολη πρόσβαση σε ενσωματωμένους υπερσυνδέσμους.

Ο τύπος HyperlinkQueries εκθέτει τα παρακάτω μέλη:

## Μέθοδοι

| Method | Description |
| :- | :- |
| [`get_hyperlink_clicks(self)`](/slides/python-net/el/aspose.slides/hyperlinkqueries/get_hyperlink_clicks/#) | Λαμβάνει όλα τα υποαντικείμενα IHyperlinkContainer που περιέχουν όχι None HyperlinkClick.<br/>            Με το συγκεκριμένο αντικείμενο IHyperlinkContainer μπορείτε να διαχειριστείτε τον υπερσύνδεσμό του (ανάγνωση, ενημέρωση ή διαγραφή). Δείτε την διεπαφή IHyperlinkContainer. |
| [`get_hyperlink_mouse_overs(self)`](/slides/python-net/el/aspose.slides/hyperlinkqueries/get_hyperlink_mouse_overs/#) | Λαμβάνει όλα τα υποαντικείμενα IHyperlinkContainer που περιέχουν όχι None HyperlinkMouseOver.<br/>            Με το συγκεκριμένο αντικείμενο IHyperlinkContainer μπορείτε να διαχειριστείτε τον υπερσύνδεσμό του (ανάγνωση, ενημέρωση ή διαγραφή). Δείτε την διεπαφή IHyperlinkContainer. |
| [`get_any_hyperlinks(self)`](/slides/python-net/el/aspose.slides/hyperlinkqueries/get_any_hyperlinks/#) | Λαμβάνει όλα τα υποαντικείμενα IHyperlinkContainer που περιέχουν όχι None HyperlinkMouseOver.<br/>            Με το συγκεκριμένο αντικείμενο IHyperlinkContainer μπορείτε να διαχειριστείτε τον υπερσύνδεσμό του (ανάγνωση, ενημέρωση ή διαγραφή). Δείτε την διεπαφή IHyperlinkContainer. |
| [`remove_all_hyperlinks(self)`](/slides/python-net/el/aspose.slides/hyperlinkqueries/remove_all_hyperlinks/#) | Αφαιρεί όλα τα ενσωματωμένα υπερσυνδέσμους HyperlinkClick και HyperlinkMouseOver (σε όλα τα υποαντικείμενα IHyperlinkContainer). |
