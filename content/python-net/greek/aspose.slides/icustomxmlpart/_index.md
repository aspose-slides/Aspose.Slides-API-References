## ICustomXmlPart κλάση

Αναπαριστά προσαρμοσμένο τμήμα xml.

Ο τύπος ICustomXmlPart εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Property | Description |
| :- | :- |
| [`xml_as_string`](/slides/python-net/el/aspose.slides/icustomxmlpart/xml_as_string/) | Επιστρέφει ή ορίζει δεδομένα xml ως συμβολοσειρά UTF-8.<br/>            Read/write **str**.<br/>            τιμή είναι `None`.τιμή είναι κενή ή xml-data είναι μη έγκυρα. |
| [`xml_data`](/slides/python-net/el/aspose.slides/icustomxmlpart/xml_data/) | Επιστρέφει ή ορίζει δεδομένα xml.<br/>            Read/write **int**[].<br/>            τιμή είναι `None`.τιμή είναι κενή ή xml-data είναι μη έγκυρα. |
| [`item_id`](/slides/python-net/el/aspose.slides/icustomxmlpart/item_id/) | Καθορίζει έναν παγκόσμιο μοναδικό αναγνωριστή (GUID) που αναγνωρίζει μοναδικά ένα μόνο προσαρμοσμένο τμήμα XML <br/>            part within an Office Open XML document.<br/>            Read-only **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/el/aspose.slides/icustomxmlpart/namespace_schemas/) | Επιστρέφει τη συλλογή σχημάτων XML που συνδέονται με το προσαρμοσμένο τμήμα XML.<br/>            Read-only **str**[]. |

## Μέθοδοι
