## Κλάση Comment

Αναπαριστά ένα σχόλιο σε μια διαφάνεια.

Ο τύπος Comment εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`text`](/slides/python-net/el/aspose.slides/comment/text/) | Επιστρέφει ή ορίζει το απλό κείμενο ενός σχολίου διαφάνειας.<br/>            Ανάγνωση/Εγγραφή **str**. |
| [`created_time`](/slides/python-net/el/aspose.slides/comment/created_time/) | Επιστρέφει ή ορίζει την ώρα δημιουργίας ενός σχολίου.<br/>            Ορισμός αυτής της ιδιότητας σε **System.DateTime** σημαίνει ότι δεν έχει οριστεί ώρα σχολίου.<br/>            Ανάγνωση/Εγγραφή **System.DateTime**. |
| [`slide`](/slides/python-net/el/aspose.slides/comment/slide/) | Επιστρέφει ή ορίζει τη γονική διαφάνεια ενός σχολίου.<br/>            Μόνο για ανάγνωση [`ISlide`](/slides/python-net/el/aspose.slides/islide). |
| [`author`](/slides/python-net/el/aspose.slides/comment/author/) | Επιστρέφει τον δημιουργό ενός σχολίου.<br/>            Μόνο για ανάγνωση [`ICommentAuthor`](/slides/python-net/el/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/el/aspose.slides/comment/position/) | Επιστρέφει ή ορίζει τη θέση ενός σχολίου σε μια διαφάνεια.<br/>            Ανάγνωση/Εγγραφή **aspose.slides.PointF**. |
| [`parent_comment`](/slides/python-net/el/aspose.slides/comment/parent_comment/) | Επιστρέφει ή ορίζει το γονικό σχόλιο.<br/>            Ανάγνωση/Εγγραφή [`IComment`](/slides/python-net/el/aspose.slides/icomment). |
