## Κλάση Comment

Αναπαριστά ένα σχόλιο σε μια διαφάνεια.

Ο τύπος Comment εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`text`](/slides/python-net/el/aspose.slides/comment/text/) | Επιστρέφει ή ορίζει το απλό κείμενο ενός σχολίου διαφάνειας.<br/>            Ανάγνωση/εγγραφή **str**. |
| [`created_time`](/slides/python-net/el/aspose.slides/comment/created_time/) | Επιστρέφει ή ορίζει την ώρα δημιουργίας ενός σχολίου.<br/>            Ορίζοντας αυτήν την ιδιότητα σε **System.DateTime** σημαίνει ότι δεν έχει οριστεί ώρα σχολίου.<br/>            Ανάγνωση/εγγραφή **System.DateTime**. |
| [`slide`](/slides/python-net/el/aspose.slides/comment/slide/) | Επιστρέφει ή ορίζει τη γονική διαφάνεια ενός σχολίου.<br/>            Μόνο ανάγνωση [`ISlide`](/slides/python-net/el/aspose.slides/islide). |
| [`author`](/slides/python-net/el/aspose.slides/comment/author/) | Επιστρέφει τον συγγραφέα ενός σχολίου.<br/>            Μόνο ανάγνωση [`ICommentAuthor`](/slides/python-net/el/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/el/aspose.slides/comment/position/) | Επιστρέφει ή ορίζει τη θέση ενός σχολίου σε μια διαφάνεια.<br/>            Ανάγνωση/εγγραφή [`PointF`](/slides/python-net/el/aspose.slides/pointf). |
| [`parent_comment`](/slides/python-net/el/aspose.slides/comment/parent_comment/) | Επιστρέφει ή ορίζει το γονικό σχόλιο.<br/>            Ανάγνωση/εγγραφή [`IComment`](/slides/python-net/el/aspose.slides/icomment). |

## Μέθοδοι

| Μέθοδος | Περιγραφή |
| :- | :- |
