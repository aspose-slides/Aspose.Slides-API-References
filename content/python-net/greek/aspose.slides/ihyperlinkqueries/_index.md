## IHyperlinkQueries κλάση

Παρέχει εύκολη πρόσβαση σε ενσωματωμένους υπερσύνδεσμους.

Ο τύπος IHyperlinkQueries αποκαλύπτει τα παρακάτω μέλη:

## Μέθοδοι

| Μέθοδος | Περιγραφή |
| :- | :- |
| [`get_hyperlink_clicks(self)`](/slides/python-net/el/aspose.slides/ihyperlinkqueries/get_hyperlink_clicks/#) | Λαμβάνει όλα τα υπο-αντικείμενα IHyperlinkContainer που περιέχουν μη None HyperlinkClick.<br/>            Με το δεδομένο αντικείμενο IHyperlinkContainer μπορείτε να διαχειριστείτε τον υπερσύνδεσμό του (ανάγνωση, ενημέρωση ή διαγραφή). Δείτε τη διεπαφή IHyperlinkContainer. |
| [`get_hyperlink_mouse_overs(self)`](/slides/python-net/el/aspose.slides/ihyperlinkqueries/get_hyperlink_mouse_overs/#) | Λαμβάνει όλα τα υπο-αντικείμενα IHyperlinkContainer που περιέχουν μη None HyperlinkMouseOver.<br/>            Με το δεδομένο αντικείμενο IHyperlinkContainer μπορείτε να διαχειριστείτε τον υπερσύνδεσμό του (ανάγνωση, ενημέρωση ή διαγραφή). Δείτε τη διεπαφή IHyperlinkContainer. |
| [`get_any_hyperlinks(self)`](/slides/python-net/el/aspose.slides/ihyperlinkqueries/get_any_hyperlinks/#) | Λαμβάνει όλα τα υπο-αντικείμενα IHyperlinkContainer που περιέχουν μη None HyperlinkMouseOver.<br/>            Με το δεδομένο αντικείμενο IHyperlinkContainer μπορείτε να διαχειριστείτε τον υπερσύνδεσμό του (ανάγνωση, ενημέρωση ή διαγραφή). Δείτε τη διεπαφή IHyperlinkContainer. |
| [`remove_all_hyperlinks(self)`](/slides/python-net/el/aspose.slides/ihyperlinkqueries/remove_all_hyperlinks/#) | Αφαιρεί όλους τους ενσωματωμένους υπερσύνδεσμους HyperlinkClick και HyperlinkMouseOver (σε όλα τα υπο-αντικείμενα IHyperlinkContainer). |
