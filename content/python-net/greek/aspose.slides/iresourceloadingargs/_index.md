## IResourceLoadingArgs κλάση

Διεπαφή για εξωτερικά επιχειρήματα φόρτωσης πόρων.

Ο τύπος IResourceLoadingArgs εμφανίζει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`original_uri`](/slides/python-net/el/aspose.slides/iresourceloadingargs/original_uri/) | Αρχικό URI του πόρου όπως καθορίζεται στην εισαχθείσα παρουσίαση. |
| [`uri`](/slides/python-net/el/aspose.slides/iresourceloadingargs/uri/) | URI του πόρου που χρησιμοποιείται για λήψη εάν **Aspose.Slides.IResourceLoadingCallback.ResourceLoading(Aspose.Slide** <br/>            επιστρέφει [`ResourceLoadingAction.DEFAULT`](/slides/python-net/el/aspose.slides/resourceloadingaction/DEFAULT). <br/>            Αρχικά ορίζεται στο αρχικό URI του πόρου, αλλά μπορεί να επαναοριστεί σε οποιαδήποτε τιμή. |

## Μέθοδοι

| Μέθοδος | Περιγραφή |
| :- | :- |
| [`set_data(self, data)`](/slides/python-net/el/aspose.slides/iresourceloadingargs/set_data/#bytes) | Ορίζει τα δεδομένα που παρέχονται από τον χρήστη για τον πόρο που χρησιμοποιείται εάν **Aspose.Slides.IResourceLoadingCallback.ResourceLoading(Aspose.Slide** <br/>            επιστρέφει [`ResourceLoadingAction.USER_PROVIDED`](/slides/python-net/el/aspose.slides/resourceloadingaction/USER_PROVIDED). |
