## ITextFrameFormatEffectiveData κλάση

Αμετάβλητο αντικείμενο που περιέχει τις αποτελεσματικές ιδιότητες μορφοποίησης πλαισίου κειμένου.

Ο τύπος ITextFrameFormatEffectiveData εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`text_style`](/slides/python-net/el/aspose.slides/itextframeformateffectivedata/text_style/) | Επιστρέφει το στυλ του αποτελεσματικού κειμένου.<br/>            Μόνο για ανάγνωση [`ITextStyleEffectiveData`](/slides/python-net/el/aspose.slides/itextstyleeffectivedata). |
| [`margin_left`](/slides/python-net/el/aspose.slides/itextframeformateffectivedata/margin_left/) | Επιστρέφει το αριστερό περιθώριο (points) σε ένα TextFrame.<br/>            Μόνο για ανάγνωση **float**. |
| [`margin_right`](/slides/python-net/el/aspose.slides/itextframeformateffectivedata/margin_right/) | Επιστρέφει το δεξιό περιθώριο (points) σε ένα TextFrame.<br/>            Μόνο για ανάγνωση **float**. |
| [`margin_top`](/slides/python-net/el/aspose.slides/itextframeformateffectivedata/margin_top/) | Επιστρέφει το επάνω περιθώριο (points) σε ένα TextFrame.<br/>            Μόνο για ανάγνωση **float**. |
| [`margin_bottom`](/slides/python-net/el/aspose.slides/itextframeformateffectivedata/margin_bottom/) | Επιστρέφει το κάτω περιθώριο (points) σε ένα TextFrame.<br/>            Μόνο για ανάγνωση **float**. |
| [`wrap_text`](/slides/python-net/el/aspose.slides/itextframeformateffectivedata/wrap_text/) | Επιστρέφει αν το κείμενο τυλίγεται στις περιθώριες του TextFrame.<br/>            Μόνο για ανάγνωση **bool**. |
| [`anchoring_type`](/slides/python-net/el/aspose.slides/itextframeformateffectivedata/anchoring_type/) | Επιστρέφει το κατακόρυφο άγκυρο κειμένου σε ένα TextFrame.<br/>            Μόνο για ανάγνωση [`TextAnchorType`](/slides/python-net/el/aspose.slides/textanchortype). |
| [`center_text`](/slides/python-net/el/aspose.slides/itextframeformateffectivedata/center_text/) | Επιστρέφει αν το κείμενο πρέπει να κεντράρει οριζόντια στο κουτί.<br/>            Μόνο για ανάγνωση **bool**. |
| [`text_vertical_type`](/slides/python-net/el/aspose.slides/itextframeformateffectivedata/text_vertical_type/) | Επιστρέφει την προσανατολισμό του κειμένου.<br/>            Μόνο για ανάγνωση [`TextVerticalType`](/slides/python-net/el/aspose.slides/textverticaltype). |
| [`autofit_type`](/slides/python-net/el/aspose.slides/itextframeformateffectivedata/autofit_type/) | Επιστρέφει τη λειτουργία αυτόματης προσαρμογής κειμένου.<br/>            Μόνο για ανάγνωση [`TextAutofitType`](/slides/python-net/el/aspose.slides/textautofittype). |
| [`column_count`](/slides/python-net/el/aspose.slides/itextframeformateffectivedata/column_count/) | Καθορίζει τον αριθμό των στηλών κειμένου στο περιβάλλον ορθογώνιο.<br/>            Μόνο για ανάγνωση **int**. |
| [`column_spacing`](/slides/python-net/el/aspose.slides/itextframeformateffectivedata/column_spacing/) | Καθορίζει το κενό μεταξύ των στηλών κειμένου στην περιοχή κειμένου (σε points).<br/>            Μόνο για ανάγνωση **float**. |


### Παρατηρήσεις

Αυτή η διασύνδεση χρησιμοποιείται μαζί με τη διασύνδεση [`ITextFrameFormat`](/slides/python-net/el/aspose.slides/itextframeformat) για την επιστροφή αποτελεσματικών τιμών μορφοποίησης με την κληρονομικότητα εφαρμοσμένη.
