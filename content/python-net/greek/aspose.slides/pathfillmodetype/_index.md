## PathFillModeType απαρίθμηση

Καθορίζει τον τρόπο με τον οποίο πρέπει να γεμιστεί μια διαδρομή

Ο τύπος PathFillModeType εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| NONE | Καμία γεμιστική διαδρομή<br/>            Αυτό καθορίζει ότι η αντίστοιχη διαδρομή δεν πρέπει να έχει γέμισμα. |
| NORMAL | Κανονική γεμιστική διαδρομή<br/>            Αυτό καθορίζει ότι στην αντίστοιχη διαδρομή πρέπει να εφαρμοστεί ένα κανονικά σκιασμένο χρώμα στο γέμισμά της. |
| LIGHTEN | Φωτεινότερη γεμιστική διαδρομή<br/>            Αυτό καθορίζει ότι στην αντίστοιχη διαδρομή πρέπει να εφαρμοστεί ένα ελαφρώς σκιασμένο χρώμα στο γέμισμά της. |
| LIGHTEN_LESS | Λιγότερο φωτεινή γεμιστική διαδρομή<br/>            Αυτό καθορίζει ότι στην αντίστοιχη διαδρομή πρέπει να εφαρμοστεί ένα ελαφρώς πιο ανοιχτό σκιασμένο χρώμα στο γέμισμά της. |
| DARKEN | Σκοτεινότερη γεμιστική διαδρομή<br/>            Αυτό καθορίζει ότι στην αντίστοιχη διαδρομή πρέπει να εφαρμόζεται ένα πιο σκοτεινό σκιασμένο χρώμα στο γέμισμά της. |
| DARKEN_LESS | Λιγότερο σκοτεινή γεμιστική διαδρομή<br/>            Αυτό καθορίζει ότι στην αντίστοιχη διαδρομή πρέπει να εφαρμοστεί ένα ελαφρώς πιο σκοτεινό σκιασμένο χρώμα στο γέμισμά της. |
