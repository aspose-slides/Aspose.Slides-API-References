## CommonSlideViewProperties κλάση

Αντιπροσωπεύει τις κοινές ιδιότητες προβολής διαφάνειας.

Ο τύπος CommonSlideViewProperties εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`scale`](/slides/python-net/el/aspose.slides/commonslideviewproperties/scale/) | Καθορίζει το λόγο κλιμάκωσης προβολής σε ποσοστά.<br/>            Read/write **int**. |
| [`variable_scale`](/slides/python-net/el/aspose.slides/commonslideviewproperties/variable_scale/) | Καθορίζει ότι το περιεχόμενο της προβολής θα πρέπει αυτόματα να κλιμακωθεί ώστε να ταιριάζει καλύτερα στο τρέχον μέγεθος του παραθύρου.<br/>            Read/write **bool**. |
| [`drawing_guides`](/slides/python-net/el/aspose.slides/commonslideviewproperties/drawing_guides/) | Επιστρέφει τη συλλογή των οδηγών σχεδίασης.<br/>            Μόνο για ανάγνωση [`IDrawingGuidesCollection`](/slides/python-net/el/aspose.slides/idrawingguidescollection) |
