## Απαρίθμηση SourceFormat

Αναπαριστά τη μορφή αρχείου πηγής.

Ο τύπος SourceFormat εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| PPT | Microsoft PowerPoint 97-2003 Παρουσίαση (*.ppt). |
| PPTX | Microsoft Office Open XML Παρουσίαση (*.pptx). |
| ODP | OpenDocument Παρουσίαση (*.odp). |
| PPTM | Microsoft Office Open XML Παρουσίαση με μακροεντολές (*.pptm). |
| PPSX | Microsoft Office Open XML Παρουσίαση διαφανειών (*.ppsx). |
| PPSM | Microsoft Office Open XML Παρουσίαση διαφανειών με μακροεντολές (*.ppsm). |
| POTX | Microsoft Office Open XML Πρότυπο (*.potx). |
| POTM | Microsoft Office Open XML Πρότυπο με μακροεντολές (*.potm). |
| PPS | Microsoft PowerPoint 97-2003 Παρουσίαση διαφανειών (*.pps). |
| POT | Microsoft PowerPoint 97-2003 Πρότυπο (*.pot). |
| OTP | OpenDocument Πρότυπο Παρουσίασης (*.otp). |
| FODP | Flat XML ODF Παρουσίαση (*.fodp). |
| XML | PowerPoint XML Παρουσίαση (*.xml). |
