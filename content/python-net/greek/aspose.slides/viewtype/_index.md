## ViewType αρίθμηση

Τύποι προβολής παρουσίασης

Ο τύπος ViewType εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| NOT_DEFINED | Η τιμή δεν είναι ορισμένη |
| SLIDE_VIEW | Κανονική προβολή διαφάνειας |
| SLIDE_MASTER_VIEW | Προβολή κύριας διαφάνειας |
| NOTES_VIEW | Προβολή σημειώσεων |
| HANDOUT_VIEW | Προβολή φυλλαδίου |
| NOTES_MASTER_VIEW | Προβολή κύριας σημειώσεων |
| OUTLINE_VIEW | Προβολή Περιγράμματος |
| SLIDE_SORTER_VIEW | Προβολή ταξινόμησης διαφανειών |
| SLIDE_THUMBNAIL_VIEW | Προβολή μικρογραφιών διαφάνειας |
