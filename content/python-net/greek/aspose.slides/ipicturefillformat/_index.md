## IPictureFillFormat κλάση

Αναπαριστά ένα στυλ γεμίσματος εικόνας.

Ο τύπος IPictureFillFormat εκθέτει τα εξής μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`dpi`](/slides/python-net/el/aspose.slides/ipicturefillformat/dpi/) | Επιστρέφει ή ορίζει το dpi που χρησιμοποιείται για το γέμισμα μιας εικόνας.<br/>            Ανάγνωση/εγγραφή **int**. |
| [`picture_fill_mode`](/slides/python-net/el/aspose.slides/ipicturefillformat/picture_fill_mode/) | Επιστρέφει ή ορίζει τη λειτουργία γεμίσματος εικόνας.<br/>            Ανάγνωση/εγγραφή [`PictureFillMode`](/slides/python-net/el/aspose.slides/picturefillmode). |
| [`picture`](/slides/python-net/el/aspose.slides/ipicturefillformat/picture/) | Επιστρέφει την εικόνα.<br/>            Μόνο για ανάγνωση [`ISlidesPicture`](/slides/python-net/el/aspose.slides/islidespicture). |
| [`crop_left`](/slides/python-net/el/aspose.slides/ipicturefillformat/crop_left/) | Επιστρέφει ή ορίζει τον αριθμό των ποσοστών του πραγματικού πλάτους της εικόνας που περικόπτονται<br/>            από αριστερά της εικόνας. <br/>            Ανάγνωση/εγγραφή **float**. |
| [`crop_top`](/slides/python-net/el/aspose.slides/ipicturefillformat/crop_top/) | Επιστρέφει ή ορίζει τον αριθμό των ποσοστών του πραγματικού ύψους της εικόνας που περικόπτονται<br/>            από πάνω της εικόνας. <br/>            Ανάγνωση/εγγραφή **float**. |
| [`crop_right`](/slides/python-net/el/aspose.slides/ipicturefillformat/crop_right/) | Επιστρέφει ή ορίζει τον αριθμό των ποσοστών του πραγματικού πλάτους της εικόνας που περικόπτονται<br/>            από δεξιά της εικόνας. <br/>            Ανάγνωση/εγγραφή **float**. |
| [`crop_bottom`](/slides/python-net/el/aspose.slides/ipicturefillformat/crop_bottom/) | Επιστρέφει ή ορίζει τον αριθμό των ποσοστών του πραγματικού ύψους της εικόνας που περικόπτονται<br/>            από κάτω της εικόνας. <br/>            Ανάγνωση/εγγραφή **float**. |
| [`stretch_offset_left`](/slides/python-net/el/aspose.slides/ipicturefillformat/stretch_offset_left/) | Επιστρέφει ή ορίζει την αριστερή άκρη του ορθογωνίου γεμίσματος που ορίζεται από μια ποσοστιαία μετατόπιση <br/>            από την αριστερή άκρη του περιοριστικού πλαισίου του σχήματος. <br/>            Ένα θετικό ποσοστό καθορίζει εσοχή, ενώ ένα αρνητικό ποσοστό καθορίζει έξοδο.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`stretch_offset_top`](/slides/python-net/el/aspose.slides/ipicturefillformat/stretch_offset_top/) | Επιστρέφει ή ορίζει την άνω άκρη του ορθογωνίου γεμίσματος που ορίζεται από μια ποσοστιαία μετατόπιση <br/>            από την άνω άκρη του περιοριστικού πλαισίου του σχήματος. <br/>            Ένα θετικό ποσοστό καθορίζει εσοχή, ενώ ένα αρνητικό ποσοστό καθορίζει έξοδο.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`stretch_offset_right`](/slides/python-net/el/aspose.slides/ipicturefillformat/stretch_offset_right/) | Επιστρέφει ή ορίζει τη δεξιά άκρη του ορθογωνίου γεμίσματος που ορίζεται από μια ποσοστιαία μετατόπιση <br/>            από τη δεξιά άκρη του περιοριστικού πλαισίου του σχήματος. <br/>            Ένα θετικό ποσοστό καθορίζει εσοχή, ενώ ένα αρνητικό ποσοστό καθορίζει έξοδο.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`stretch_offset_bottom`](/slides/python-net/el/aspose.slides/ipicturefillformat/stretch_offset_bottom/) | Επιστρέφει ή ορίζει την κάτω άκρη του ορθογωνίου γεμίσματος που ορίζεται από μια ποσοστιαία μετατόπιση <br/>            από την κάτω άκρη του περιοριστικού πλαισίου του σχήματος. <br/>            Ένα θετικό ποσοστό καθορίζει εσοχή, ενώ ένα αρνητικό ποσοστό καθορίζει έξοδο.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`tile_offset_x`](/slides/python-net/el/aspose.slides/ipicturefillformat/tile_offset_x/) | Επιστρέφει ή ορίζει την οριζόντια μετατόπιση της υφής από το σημείο προέλευσης του σχήματος σε σημεία.<br/>             Μια θετική τιμή μετακινεί την υφή προς τα δεξιά, ενώ μια αρνητική τιμή τη μετακινεί προς τα αριστερά.<br/>             Ανάγνωση/εγγραφή **float**. |
| [`tile_offset_y`](/slides/python-net/el/aspose.slides/ipicturefillformat/tile_offset_y/) | Επιστρέφει ή ορίζει την κατακόρυφη μετατόπιση της υφής από το σημείο προέλευσης του σχήματος σε σημεία.<br/>             Μια θετική τιμή μετακινεί την υφή προς τα κάτω, ενώ μια αρνητική τιμή τη μετακινεί προς τα πάνω.<br/>             Ανάγνωση/εγγραφή **float**. |
| [`tile_scale_x`](/slides/python-net/el/aspose.slides/ipicturefillformat/tile_scale_x/) | Επιστρέφει ή ορίζει την οριζόντια κλίμακα για το γέμισμα υφής ως ποσοστό.<br/>             Ανάγνωση/εγγραφή **float**. |
| [`tile_scale_y`](/slides/python-net/el/aspose.slides/ipicturefillformat/tile_scale_y/) | Επιστρέφει ή ορίζει την κατακόρυφη κλίμακα για το γέμισμα υφής ως ποσοστό.<br/>             Ανάγνωση/εγγραφή **float**. |
| [`tile_alignment`](/slides/python-net/el/aspose.slides/ipicturefillformat/tile_alignment/) | Επιστρέφει ή ορίζει τον τρόπο στοίχισης της υφής εντός του σχήματος. Αυτή η ρύθμιση ελέγχει το σημείο εκκίνησης του μοτίβου της υφής και τον τρόπο επαναλαμβανόμενης εφαρμογής του σε όλο το σχήμα.<br/>             Ανάγνωση/εγγραφή [`RectangleAlignment`](/slides/python-net/el/aspose.slides/rectanglealignment). |
| [`tile_flip`](/slides/python-net/el/aspose.slides/ipicturefillformat/tile_flip/) | Αναστρέφει το πλακίδιο της υφής γύρω από τον οριζόντιο, κατακόρυφο ή και τους δύο άξονες.<br/>             Ανάγνωση/εγγραφή [`TileFlip`](/slides/python-net/el/aspose.slides/tileflip). |
