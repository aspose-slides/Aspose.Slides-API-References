## ViewProperties κλάση

Γενικές ιδιότητες προβολής του παρουσίασης.

Ο τύπος ViewProperties εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`last_view`](/slides/python-net/el/aspose.slides/viewproperties/last_view/) | Καθορίζει τη λειτουργία προβολής που χρησιμοποιήθηκε όταν το έγγραφο παρουσίασης αποθηκεύτηκε τελευταία φορά.<br/>            Ανάγνωση/εγγραφή [`ViewType`](/slides/python-net/el/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/el/aspose.slides/viewproperties/show_comments/) | Καθορίζει εάν πρέπει να εμφανίζονται τα σχόλια της διαφάνειας.<br/>            Ανάγνωση/εγγραφή [`NullableBool`](/slides/python-net/el/aspose.slides/nullablebool). |
| [`normal_view_properties`](/slides/python-net/el/aspose.slides/viewproperties/normal_view_properties/) | Αντιπροσωπεύει τις ιδιότητες κανονικής προβολής. Η κανονική προβολή αποτελείται από<br/>            τρεις περιοχές περιεχομένου: τη διαφάνεια ίδια, μια πλευρική περιοχή περιεχομένου και μια κάτω περιοχή περιεχομένου.<br/>            Μόνο για ανάγνωση [`INormalViewProperties`](/slides/python-net/el/aspose.slides/inormalviewproperties). |
| [`slide_view_properties`](/slides/python-net/el/aspose.slides/viewproperties/slide_view_properties/) | Καθορίζει κοινές ιδιότητες προβολής που σχετίζονται με τη λειτουργία προβολής διαφάνειας.<br/>            Μόνο για ανάγνωση [`ICommonSlideViewProperties`](/slides/python-net/el/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/el/aspose.slides/viewproperties/notes_view_properties/) | Καθορίζει κοινές ιδιότητες προβολής που σχετίζονται με τη λειτουργία προβολής σημειώσεων.<br/>            Μόνο για ανάγνωση [`ICommonSlideViewProperties`](/slides/python-net/el/aspose.slides/icommonslideviewproperties). |
| [`grid_spacing`](/slides/python-net/el/aspose.slides/viewproperties/grid_spacing/) | Επιστρέφει ή ορίζει την απόσταση του πλέγματος που πρέπει να χρησιμοποιείται για το πλέγμα που υποστηρίζει το έγγραφο παρουσίασης, σε σημεία.<br/>            Ανάγνωση/εγγραφή **float**. |
