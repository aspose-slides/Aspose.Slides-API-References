## ICaptions κλάση

Αναπαριστά τις κλειστές λεζάντες WebVTT.

Ο τύπος ICaptions εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`caption_id`](/slides/python-net/el/aspose.slides/icaptions/caption_id/) | Επιστρέφει το παγκοσμίως μοναδικό αναγνωριστικό (GUID) των κλειστών λεζαντών.<br/>            Μόνο για ανάγνωση **System.Guid**. |
| [`label`](/slides/python-net/el/aspose.slides/icaptions/label/) | Επιστρέφει ή θέτει την ετικέτα των κλειστών λεζαντών.<br/>            Ανάγνωση/εγγραφή **str**. |
| [`binary_data`](/slides/python-net/el/aspose.slides/icaptions/binary_data/) | Επιστρέφει τα δυαδικά δεδομένα των κλειστών λεζαντών.<br/>            Μόνο για ανάγνωση **int**[]. |
| [`data_as_string`](/slides/python-net/el/aspose.slides/icaptions/data_as_string/) | Επιστρέφει τα δεδομένα των κλειστών λεζαντών ως συμβολοσειρά κωδικοποιημένη σε UTF-8<br/>            Μόνο για ανάγνωση **str**. |
