## compare_to(self, obj) {#any}
Συγκρίνει την τρέχουσα παρουσία με ένα άλλο αντικείμενο του ίδιου τύπου.

### Επιστρέφει

Ένας ακέραιος 32-bit που υποδεικνύει τη σχετική σειρά των συγκρίσιμων.
            Η τιμή επιστροφής έχει τις παρακάτω σημασίες:
            
*  < 0 - Αυτή η παρουσία είναι μικρότερη από το obj. = 0 - Αυτή η παρουσία είναι ίση με το obj. > 0 - Αυτή η παρουσία είναι μεγαλύτερη από το obj.

*  < 0 - Αυτή η παρουσία είναι μικρότερη από το obj. = 0 - Αυτή η παρουσία είναι ίση με το obj. > 0 - Αυτή η παρουσία είναι μεγαλύτερη από το obj.

*  < 0 - Αυτή η παρουσία είναι μικρότερη από το obj. = 0 - Αυτή η παρουσία είναι ίση με το obj. > 0 - Αυτή η παρουσία είναι μεγαλύτερη από το obj.
