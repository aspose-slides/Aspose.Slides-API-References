## PPImageFormat απαρίθμηση

Μορφές εικόνας. Αυτή η enum είναι αντικατάσταση για την κλάση `System.Drawing.Imaging.ImageFormat`.
            Απαιτείται για συμβατότητα με COM.

Ο τύπος PPImageFormat εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| BMP | Παρέχει τη μορφή bitmap (BMP). |
| EMF | Παρέχει τη μορφή ενισχυμένου μετααρχείου (EMF). |
| EXIF | Παρέχει τη μορφή εναλλάξιμου αρχείου εικόνας (Exif). |
| GIF | Παρέχει τη μορφή μορφής ανταλλαγής γραφικών (GIF). |
| ICON | Παρέχει τη μορφή εικονιδίου Windows. |
| JPEG | Παρέχει τη μορφή Ομάδα Ειδικών Φωτογραφίας (JPEG). |
| MEMORY_BMP | Παρέχει τη μορφή bitmap στη μνήμη. |
| PNG | Παρέχει τη μορφή W3C Portable Network Graphics (PNG). |
| TIFF | Παρέχει τη μορφή Tagged Image File Format (TIFF). |
| WMF | Παρέχει τη μορφή μετααρχείου Windows (WMF). |
