## BlackWhiteMode απαρίθμηση

Καθορίζει πώς το χρωματισμένο σχήμα πρέπει να μετατραπεί σε ασπρόμαυρο.

Ο τύπος BlackWhiteMode περιέχει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| NOT_DEFINED | Η ιδιότητα δεν έχει οριστεί |
| COLOR | Το αντικείμενο αποδίδεται με κανονικό χρώμα |
| AUTOMATIC | Το αντικείμενο αποδίδεται με αυτόματο χρώμα |
| GRAY | Το αντικείμενο αποδίδεται με γκρι χρώμα |
| LIGHT_GRAY | Το αντικείμενο αποδίδεται με ανοιχτό γκρι χρώμα |
| INVERSE_GRAY | Το αντικείμενο αποδίδεται με αντίστροφο γκρι χρώμα |
| GRAY_WHITE | Το αντικείμενο αποδίδεται με γκρι και λευκό χρώμα |
| BLACK_GRAY | Το αντικείμενο αποδίδεται με μαύρο και γκρι χρώμα |
| BLACK_WHITE | Το αντικείμενο αποδίδεται με μαύρο και λευκό χρώμα |
| BLACK | Το αντικείμενο αποδίδεται μόνο με μαύρο χρώμα |
| WHITE | Το αντικείμενο αποδίδεται με λευκό χρώμα |
| HIDDEN | Το αντικείμενο δεν αποδίδεται |
