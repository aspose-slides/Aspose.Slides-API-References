## ICamera κλάση

Αναπαριστά την Κάμερα.

Ο τύπος ICamera εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Property | Description |
| :- | :- |
| [`camera_type`](/slides/python-net/el/aspose.slides/icamera/camera_type/) | Τύπος κάμερας<br/>            Ανάγνωση/εγγραφή [`CameraPresetType`](/slides/python-net/el/aspose.slides/camerapresettype). |
| [`field_of_view_angle`](/slides/python-net/el/aspose.slides/icamera/field_of_view_angle/) | FOV κάμερας (0-180 μοίρες, πεδίο θέασης)<br/>            Ανάγνωση/εγγραφή **float**. |
| [`zoom`](/slides/python-net/el/aspose.slides/icamera/zoom/) | Ζουμ κάμερας (θετική τιμή σε ποσοστό)<br/>            Ανάγνωση/εγγραφή **float**. |

## Μέθοδοι

| Method | Description |
| :- | :- |
| [`set_rotation(self, latitude, longitude, revolution)`](/slides/python-net/el/aspose.slides/icamera/set_rotation/#float-float-float) | Μια περιστροφή ορίζεται μέσω της χρήσης μιας συντεταγμένης γεωγραφικού πλάτους, μιας συντεταγμένης γεωγραφικού μήκους και μιας επανάληψης γύρω από τον άξονα όπως οι συντεταγμένες γεωγραφικού πλάτους και μήκους.<br/>            Εάν οποιαδήποτε τιμή συντεταγμένης είναι float.NaN, όλη η περιστροφή είναι ακαθόριστη. |
| [`get_rotation(self)`](/slides/python-net/el/aspose.slides/icamera/get_rotation/#) | Μια περιστροφή ορίζεται μέσω της χρήσης μιας συντεταγμένης γεωγραφικού πλάτους, μιας συντεταγμένης γεωγραφικού μήκους και μιας επανάληψης γύρω από τον άξονα όπως οι συντεταγμένες γεωγραφικού πλάτους και μήκους.<br/>            Το πρώτο στοιχείο στον πίνακα επιστροφής - γεωγραφικό πλάτος, το δεύτερο - γεωγραφικό μήκος, το τρίτο - επανάληψη.<br/>            Επιστρέφει None εάν δεν έχει οριστεί περιστροφή. |
