## ιδιότητα πλαισίου
Επιστρέφει ή θέτει τις ιδιότητες του πλαισίου σχήματος.
            Ανάγνωση/εγγραφή [`IShapeFrame`](/slides/python-net/el/aspose.slides/ishapeframe).


### Σχόλια

Η τιμή κάθε ιδιότητας του επιστρεφόμενου IShapeFrame δεν είναι undefined (δεν είναι NaN ή NotDefined). Η τιμή κάθε ιδιότητας του αντιστοιχισμένου IShapeFrame πρέπει να μην είναι undefined (πρέπει να μην είναι NaN ή NotDefined). Μπορείτε να ορίσετε τιμές undefined για τις ιδιότητες του RawFrame.
