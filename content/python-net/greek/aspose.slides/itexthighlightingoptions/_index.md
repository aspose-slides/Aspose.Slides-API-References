## ITextHighlightingOptions κλάση

Αναπαριστά επιλογές που μπορούν να χρησιμοποιηθούν για την επισήμανση κειμένου σε πλαίσιο κειμένου.

Ο τύπος ITextHighlightingOptions εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Property | Description |
| :- | :- |
| [`case_sensitive`](/slides/python-net/el/aspose.slides/itexthighlightingoptions/case_sensitive/) | Ορίστε true για χρήση αναζήτησης που διακρίνει πεζά-κεφαλαία, false - αλλιώς.<br/>            Read/write **bool**. |
| [`whole_words_only`](/slides/python-net/el/aspose.slides/itexthighlightingoptions/whole_words_only/) | Ορίστε true για αντιστοίχιση μόνο ολόκληρων λέξεων, false - αλλιώς.<br/>            Read/write **bool**. |
