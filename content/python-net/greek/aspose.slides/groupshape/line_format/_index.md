## ιδιότητα line_format
Επιστρέφει το αντικείμενο LineFormat που περιέχει τις ιδιότητες μορφοποίησης γραμμής για ένα σχήμα.
            Σημείωση: Επιστρέφει None για αντικείμενα GroupShape επειδή δεν έχουν ιδιότητες γραμμής.
            Μόνο για ανάγνωση [`ILineFormat`](/slides/python-net/el/aspose.slides/ilineformat).
