## parent_group ιδιότητα
Returns parent GroupShape object if shape is grouped. Otherwise returns None.
            Μόνο για ανάγνωση [`IGroupShape`](/slides/python-net/el/aspose.slides/igroupshape).

### Παρατηρήσεις

Ιδιότητα [`Shape.is_grouped`](/slides/python-net/el/aspose.slides/shape/is_grouped) καθορίζει εάν το σχήμα είναι ομαδοποιημένο.
