## ιδιότητα πλαισίου
Επιστρέφει ή ορίζει τις ιδιότητες του πλαισίου σχήματος.
            Ανάγνωση/εγγραφή [`IShapeFrame`](/slides/python-net/el/aspose.slides/ishapeframe).


### Σχόλια

Τιμή κάθε ιδιότητας του επιστρεφόμενου αντικειμένου IShapeFrame δεν είναι 
            undefined (δεν είναι NaN ή NotDefined).
            Τιμή κάθε ιδιότητας του εκχωρημένου αντικειμένου IShapeFrame πρέπει να μην είναι 
            undefined (πρέπει να μην είναι NaN ή NotDefined).
            Μπορείτε να ορίσετε undefined τιμές για τις ιδιότητες του αντικειμένου RawFrame.
