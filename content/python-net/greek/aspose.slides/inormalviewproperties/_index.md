## INormalViewProperties κλάση

Αντιπροσωπεύει τις ιδιότητες της κανονικής προβολής. Η κανονική προβολή αποτελείται από
            τρεις περιοχές περιεχομένου: τη διαφάνεια ίδια, μια πλαϊνή περιοχή περιεχομένου και μια κάτω περιοχή περιεχομένου.

Ο τύπος INormalViewProperties εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`show_outline_icons`](/slides/python-net/el/aspose.slides/inormalviewproperties/show_outline_icons/) | Καθορίζει αν η εφαρμογή πρέπει να εμφανίζει εικονίδια όταν εμφανίζει περιεχόμενο περίληψης σε οποιαδήποτε<br/> από τις περιοχές περιεχομένου της λειτουργίας κανονικής προβολής.<br/> Ανάγνωση/εγγραφή **bool**. |
| [`snap_vertical_splitter`](/slides/python-net/el/aspose.slides/inormalviewproperties/snap_vertical_splitter/) | Καθορίζει αν ο κάθετος διαχωριστής πρέπει να κλειδώνει σε κατάσταση ελαχιστοποίησης όταν η πλαϊνή<br/> περιοχή είναι επαρκώς μικρή.<br/> Ανάγνωση/εγγραφή **bool**. |
| [`vertical_bar_state`](/slides/python-net/el/aspose.slides/inormalviewproperties/vertical_bar_state/) | Καθορίζει την κατάσταση στην οποία πρέπει να εμφανίζεται η κάθετη γραμμή διαχωρισμού. <br/> Μια κάθετη γραμμή διαχωρισμού χωρίζει τη διαφάνεια από την πλαϊνή περιοχή περιεχομένου. |
| [`horizontal_bar_state`](/slides/python-net/el/aspose.slides/inormalviewproperties/horizontal_bar_state/) | Καθορίζει την κατάσταση στην οποία πρέπει να εμφανίζεται η οριζόντια γραμμή διαχωρισμού.<br/> Μια οριζόντια γραμμή διαχωρισμού χωρίζει τη διαφάνεια από την περιοχή περιεχομένου κάτω από τη διαφάνεια. |
| [`prefer_single_view`](/slides/python-net/el/aspose.slides/inormalviewproperties/prefer_single_view/) | Καθορίζει αν ο χρήστης προτιμά να βλέπει μία ενιαία περιοχή περιεχομένου πλήρους παραθύρου αντί της<br/> τυπικής κανονικής προβολής με τρεις περιοχές περιεχομένου. Εάν ενεργοποιηθεί, η εφαρμογή μπορεί να επιλέξει<br/> να εμφανίσει μία από τις περιοχές περιεχομένου σε ολόκληρο το παράθυρο.<br/> Ανάγνωση/εγγραφή **bool**. |
| [`restored_left`](/slides/python-net/el/aspose.slides/inormalviewproperties/restored_left/) | Αυτό το στοιχείο καθορίζει το μέγεθος της πλαϊνής περιοχής περιεχομένου της κανονικής προβολής, όταν η περιοχή έχει μεταβλητό<br/> επαναφερθέν μέγεθος (όχι ελαχιστοποιημένη ούτε μεγιστοποιημένη).<br/> Μόνο για ανάγνωση [`INormalViewRestoredProperties`](/slides/python-net/el/aspose.slides/inormalviewrestoredproperties). |
| [`restored_top`](/slides/python-net/el/aspose.slides/inormalviewproperties/restored_top/) | Αυτό το στοιχείο καθορίζει το μέγεθος της επάνω περιοχής της διαφάνειας στην κανονική προβολή, όταν η περιοχή έχει μεταβλητό<br/> επαναφερθέν μέγεθος (όχι ελαχιστοποιημένη ούτε μεγιστοποιημένη).<br/> Μόνο για ανάγνωση [`INormalViewRestoredProperties`](/slides/python-net/el/aspose.slides/inormalviewrestoredproperties). |
