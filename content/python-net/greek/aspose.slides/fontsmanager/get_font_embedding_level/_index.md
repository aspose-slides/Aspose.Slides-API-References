## get_font_embedding_level(self, font_bytes, font_name) {#bytes-str}
Καθορίζει το επίπεδο ενσωμάτωσης μιας γραμματοσειράς από τον δοσμένο πίνακα byte και το όνομα της γραμματοσειράς.

### Επιστρέφει

Το επίπεδο ενσωμάτωσης της συγκεκριμένης γραμματοσειράς.



```python
def get_font_embedding_level(self, font_bytes, font_name):
    ...
```


| Παράμετρος | Τύπος | Περιγραφή |
| :- | :- | :- |
| font_bytes | **bytes** | Ο πίνακας byte που περιέχει τα δεδομένα της γραμματοσειράς. |
| font_name | **str** | Το όνομα της γραμματοσειράς. |

### Εξαιρέσεις

| Εξαίρεση | Περιγραφή |
| :- | :- |
| **RuntimeError(Proxy error(ArgumentNullException))** | Προκαλείται όταν `font_bytes` είναι None. |
