## IFillFormat κλάση

Αντιπροσωπεύει τις επιλογές μορφοποίησης γεμίσματος.

Ο τύπος IFillFormat εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`fill_type`](/slides/python-net/el/aspose.slides/ifillformat/fill_type/) | Returns or sets the type of filling.<br/>            Read/write [`FillType`](/slides/python-net/el/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/el/aspose.slides/ifillformat/solid_fill_color/) | Returns the fill color.<br/>            Read-only [`IColorFormat`](/slides/python-net/el/aspose.slides/icolorformat). |
| [`gradient_format`](/slides/python-net/el/aspose.slides/ifillformat/gradient_format/) | Returns the gradient fill format.<br/>            Read-only [`IGradientFormat`](/slides/python-net/el/aspose.slides/igradientformat). |
| [`pattern_format`](/slides/python-net/el/aspose.slides/ifillformat/pattern_format/) | Returns the pattern fill format.<br/>            Read-only [`IPatternFormat`](/slides/python-net/el/aspose.slides/ipatternformat). |
| [`picture_fill_format`](/slides/python-net/el/aspose.slides/ifillformat/picture_fill_format/) | Returns the picture fill format.<br/>            Read-only [`IPictureFillFormat`](/slides/python-net/el/aspose.slides/ipicturefillformat). |
| [`rotate_with_shape`](/slides/python-net/el/aspose.slides/ifillformat/rotate_with_shape/) | Determines whether the fill should be rotated with shape.<br/>            Read/write [`NullableBool`](/slides/python-net/el/aspose.slides/nullablebool). |
