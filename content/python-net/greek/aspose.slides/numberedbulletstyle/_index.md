## NumberedBulletStyle απαρίθμηση

Αντιπροσωπεύει το στυλ των αριθμημένων κουκκίδων.

Ο τύπος NumberedBulletStyle εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| NOT_DEFINED | Δεν ορίζεται. |
| BULLET_ALPHA_LC_PERIOD | Χαρακτήρες αλφαβητικού πεζού με τελεία. Δείγμα: a., b., c., ... |
| BULLET_ALPHA_UC_PERIOD | Χαρακτήρες αλφαβητικού κεφαλαίου με τελεία. Δείγμα: A., B., C., ... |
| BULLET_ARABIC_PAREN_RIGHT | Αραβικοί αριθμοί με δεξιό παρενθέση. Δείγμα: 1), 2), 3), ... |
| BULLET_ARABIC_PERIOD | Αραβικοί αριθμοί με τελεία. Δείγμα: 1., 2., 3., ... |
| BULLET_ROMAN_LC_PAREN_BOTH | Ρωμαϊκοί αριθμοί πεζοί με και τις δύο παρενθέσεις. Δείγμα: (i), (ii), (iii), ... |
| BULLET_ROMAN_LC_PAREN_RIGHT | Ρωμαϊκοί αριθμοί πεζοί με δεξιό παρενθέση. Δείγμα: i), ii), iii), ... |
| BULLET_ROMAN_LC_PERIOD | Ρωμαϊκοί αριθμοί πεζοί με τελεία. Δείγμα: i., ii., iii., ... |
| BULLET_ROMAN_UC_PERIOD | Ρωμαϊκοί αριθμοί κεφαλαίοι με τελεία. Δείγμα: I., II., III., ... |
| BULLET_ALPHA_LC_PAREN_BOTH | Χαρακτήρες αλφαβητικού πεζού με και τις δύο παρενθέσεις. Δείγμα: (a), (b), (c), ... |
| BULLET_ALPHA_LC_PAREN_RIGHT | Χαρακτήρες αλφαβητικού πεζού με δεξιό παρενθέση. Δείγμα: a), b), c), ... |
| BULLET_ALPHA_UC_PAREN_BOTH | Χαρακτήρες αλφαβητικού κεφαλαίου με και τις δύο παρενθέσεις. Δείγμα: (A), (B), (C), ... |
| BULLET_ALPHA_UC_PAREN_RIGHT | Χαρακτήρες αλφαβητικού κεφαλαίου με δεξιό παρενθέση. Δείγμα: A), B), C), ... |
| BULLET_ARABIC_PAREN_BOTH | Αραβικοί αριθμοί με και τις δύο παρενθέσεις. Δείγμα: (1), (2), (3), ... |
| BULLET_ARABIC_PLAIN | Αραβικοί αριθμοί. Δείγμα: 1, 2, 3, ... |
| BULLET_ROMAN_UC_PAREN_BOTH | Ρωμαϊκοί αριθμοί κεφαλαίοι με και τις δύο παρενθέσεις. Δείγμα: (I), (II), (III), ... |
| BULLET_ROMAN_UC_PAREN_RIGHT | Ρωμαϊκοί αριθμοί κεφαλαίοι με δεξιό παρενθέση. Δείγμα: I), II), III), ... |
| BULLET_SIMP_CHIN_PLAIN | Απλοποιημένα κινέζικα χωρίς τελεία. |
| BULLET_SIMP_CHIN_PERIOD | Απλοποιημένα κινέζικα με τελεία. |
| BULLET_CIRCLE_NUM_DB_PLAIN | Αριθμός σε κυκλικό σχήμα διπλού byte για τιμές έως 10, από 11 - αραβικοί αριθμοί. |
| BULLET_CIRCLE_NUM_WD_WHITE_PLAIN | Αριθμός χρωματιστού κειμένου με κύκλο του ίδιου χρώματος γύρω του (αριθμοί λευκού κύκλου Wingdings). Από 11 - αραβικοί αριθμοί. |
| BULLET_CIRCLE_NUM_WD_BLACK_PLAIN | Αριθμός σκιώδους χρώματος με κυκλικό φόντο του κανονικού χρώματος κειμένου (αριθμοί μαύρου κύκλου Wingdings). |
| BULLET_TRAD_CHIN_PLAIN | Παραδοσιακά κινέζικα χωρίς τελεία. |
| BULLET_TRAD_CHIN_PERIOD | Παραδοσιακά κινέζικα με τελεία. |
| BULLET_ARABIC_ALPHA_DASH | Αραβικοί αλφαβητικοί χαρακτήρες με παύλα. |
| BULLET_ARABIC_ABJAD_DASH | Αραβικά αλφάβητα Abjad με παύλα. |
| BULLET_HEBREW_ALPHA_DASH | Εβραϊκοί αλφαβητικοί χαρακτήρες με παύλα. |
| BULLET_KANJI_KOREAN_PLAIN | Ιαπωνικοί/Κορεατικοί αριθμοί χωρίς τελεία. |
| BULLET_KANJI_KOREAN_PERIOD | Ιαπωνικοί/Κορεατικοί αριθμοί με τελεία. |
| BULLET_ARABIC_DB_PLAIN | Σχέδιο αρίθμησης αραβικών διπλού byte (χωρίς σημεία στίξης). |
| BULLET_ARABIC_DB_PERIOD | Σχέδιο αρίθμησης αραβικών διπλού byte με διπλό byte τελεία. |
| BULLET_THAI_ALPHA_PERIOD | Ταϊλανδικό αλφάβητο με τελεία. |
| BULLET_THAI_ALPHA_PAREN_RIGHT | Παρένθεση αλφαβήτου Thai - δεξιά. |
| BULLET_THAI_ALPHA_PAREN_BOTH | Παρένθεση αλφαβήτου Thai - και οι δύο. |
| BULLET_THAI_NUM_PERIOD | Ταϊλανδική αριθμητική με τελεία. |
| BULLET_THAI_NUM_PAREN_RIGHT | Παρένθεση αριθμών Thai - δεξιά. |
| BULLET_THAI_NUM_PAREN_BOTH | Παρένθεση αριθμών Thai - και οι δύο. |
| BULLET_HINDI_ALPHA_PERIOD | Ινδικό αλφάβητο με τελεία - φωνήεντα. |
| BULLET_HINDI_NUM_PERIOD | Ινδική αριθμητική με τελεία. |
| BULLET_KANJI_SIMP_CHIN_DB_PERIOD | Kanji απλό κινέζικο DBPeriod. |
| BULLET_HINDI_NUM_PAREN_RIGHT | Παρένθεση αριθμών Hindi - δεξιά. |
| BULLET_HINDI_ALPHA_1_PERIOD | Ινδικό αλφάβητο με τελεία - σύμφωνα. |
