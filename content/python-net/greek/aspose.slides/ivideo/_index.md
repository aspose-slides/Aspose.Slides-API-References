## IVideo κλάση

Αντιπροσωπεύει ένα βίντεο ενσωματωμένο σε μια παρουσίαση.

Ο τύπος IVideo εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`content_type`](/slides/python-net/el/aspose.slides/ivideo/content_type/) | Επιστρέφει έναν τύπο MIME ενός βίντεο, κωδικοποιημένο σε [`IVideo.binary_data`](/slides/python-net/el/aspose.slides/ivideo/binary_data).<br/> Μόνο για ανάγνωση **str**. |
| [`binary_data`](/slides/python-net/el/aspose.slides/ivideo/binary_data/) | Επιστρέφει το αντίγραφο των δεδομένων ήχου. Σε περίπτωση μεγάλης ποσότητας δεδομένων, εξετάστε τη χρήση της <br/> [`IVideo.get_stream`](/slides/python-net/el/aspose.slides/ivideo/get_stream) μεθόδου για την αποφυγή περιττών φορτώσεων των δεδομένων του βίντεο στη μνήμη <br/> ή ακόμη και OutOfMemoryException.<br/> Μόνο για ανάγνωση **int**[]. |

## Μέθοδοι

| Μέθοδος | Περιγραφή |
| :- | :- |
| [`get_stream(self)`](/slides/python-net/el/aspose.slides/ivideo/get_stream/#) | Επιστρέφει Stream ροή για ανάγνωση.<br/> Χρησιμοποιήστε 'using' ή κλείστε τη ροή μετά τη χρήση. |
