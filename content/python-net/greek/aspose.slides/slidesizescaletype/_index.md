## SlideSizeScaleType απαρίθμηση

Αναπαριστά τον τύπο κλίμακας του περιεχομένου της διαφάνειας.

Ο τύπος SlideSizeScaleType εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| DO_NOT_SCALE | Χωρίς κλιμάκωση. |
| ENSURE_FIT | Κλιμάκωση για εξασφάλιση προσαρμογής. |
| MAXIMIZE | Μεγιστοποίηση μεγέθους του περιεχομένου. |
