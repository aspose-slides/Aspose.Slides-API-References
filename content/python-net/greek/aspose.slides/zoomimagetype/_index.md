## ZoomImageType απαρίθμηση

Ο τύπος ZoomImageType εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| PREVIEW | Χρησιμοποίησει την εικόνα της διαφάνειας ή της ενότητας. |
| COVER | Χρησιμοποίησει μια προσαρμοσμένη εικόνα. |
