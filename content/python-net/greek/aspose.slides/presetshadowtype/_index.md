## Απαρίθμηση PresetShadowType

Αντιπροσωπεύει μια προεπιλογή για εφέ σκιάς.

Ο τύπος PresetShadowType εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| TOP_LEFT_DROP_SHADOW | Αντιπροσωπεύει σκιά πτώσης επάνω αριστερά. |
| TOP_LEFT_LARGE_DROP_SHADOW | Αντιπροσωπεύει μεγάλη σκιά πτώσης επάνω αριστερά. |
| BACK_LEFT_LONG_PERSPECTIVE_SHADOW | Αντιπροσωπεύει σκιά μακριάς προοπτικής πίσω αριστερά. |
| BACK_RIGHT_LONG_PERSPECTIVE_SHADOW | Αντιπροσωπεύει σκιά μακριάς προοπτικής πίσω δεξιά. |
| TOP_LEFT_DOUBLE_DROP_SHADOW | Αντιπροσωπεύει διπλή σκιά πτώσης επάνω αριστερά. |
| BOTTOM_RIGHT_SMALL_DROP_SHADOW | Αντιπροσωπεύει μικρή σκιά πτώσης κάτω δεξιά. |
| FRONT_LEFT_LONG_PERSPECTIVE_SHADOW | Αντιπροσωπεύει σκιά μακριάς προοπτικής εμπρός αριστερά. |
| FRONT_RIGHT_LONG_PERSPECTIVE_SHADOW | Αντιπροσωπεύει σκιά μακριάς προοπτικής εμπρός δεξιά. |
| OUTER_BOX_SHADOW_3D | Αντιπροσωπεύει σκιά εξωτερικού πλαισίου 3D. |
| INNER_BOX_SHADOW_3D | Αντιπροσωπεύει σκιά εσωτερικού πλαισίου 3D. |
| BACK_CENTER_PERSPECTIVE_SHADOW | Αντιπροσωπεύει σκιά προοπτικής πίσω κέντρο. |
| TOP_RIGHT_DROP_SHADOW | Αντιπροσωπεύει σκιά πτώσης επάνω δεξιά. |
| FRONT_BOTTOM_SHADOW | Αντιπροσωπεύει σκιά εμπρός κάτω. |
| BACK_LEFT_PERSPECTIVE_SHADOW | Αντιπροσωπεύει σκιά προοπτικής πίσω αριστερά. |
| BACK_RIGHT_PERSPECTIVE_SHADOW | Αντιπροσωπεύει σκιά προοπτικής πίσω δεξιά. |
| BOTTOM_LEFT_DROP_SHADOW | Αντιπροσωπεύει σκιά πτώσης κάτω αριστερά. |
| BOTTOM_RIGHT_DROP_SHADOW | Αντιπροσωπεύει σκιά πτώσης κάτω δεξιά. |
| FRONT_LEFT_PERSPECTIVE_SHADOW | Αντιπροσωπεύει σκιά προοπτικής εμπρός αριστερά. |
| FRONT_RIGHT_PERSPECTIVE_SHADOW | Αντιπροσωπεύει σκιά προοπτικής εμπρός δεξιά. |
| TOP_LEFT_SMALL_DROP_SHADOW | Αντιπροσωπεύει μικρή σκιά πτώσης επάνω αριστερά. |
