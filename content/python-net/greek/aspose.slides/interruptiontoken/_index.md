## InterruptionToken κλάση

Αυτή η κλάση αντιπροσωπεύει το διακριτικό που χρησιμοποιείται για την επισήμανση των εκτεταμένων εργασιών εάν ζητήθηκε η διακοπή.

Ο τύπος InterruptionToken εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`none`](/slides/python-net/el/aspose.slides/interruptiontoken/none/) | Αντιπροσωπεύει ένα κενό διακριτικό διακοπής.<br/>            Οι εκτεταμένες λειτουργίες δεν θα διακοπούν ποτέ μέσω [`InterruptionTokenSource.interrupt`](/slides/python-net/el/aspose.slides/interruptiontokensource/interrupt)<br/>            όταν χρησιμοποιείται αυτό το διακριτικό. |
| [`is_interruption_requested`](/slides/python-net/el/aspose.slides/interruptiontoken/is_interruption_requested/) | Επιστρέφει **bool**.true εάν ζητήθηκε η διακοπή. |

## Μέθοδοι

| Μέθοδος | Περιγραφή |
| :- | :- |
| [`throw_if_interruption_requested(self)`](/slides/python-net/el/aspose.slides/interruptiontoken/throw_if_interruption_requested/#) | Εκκινεί μια OperationCanceledException εάν<br/>            ζητήθηκε η διακοπή. |
