## TextAutofitType αρίθμηση

Αναπαριστά τη λειτουργία αυτόματης προσαρμογής κειμένου.

Ο τύπος TextAutofitType εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| NOT_DEFINED | Δεν ορίζεται. |
| NONE | Καμία αυτόματη προσαρμογή. |
| NORMAL | Κανονική αυτόματη προσαρμογή. Το μέγεθος γραμματοσειράς και το διάστημα γραμμών θα μειωθούν ώστε να ταιριάζουν στο σχήμα. |
| SHAPE | Αυτόματη προσαρμογή σχήματος. Το μέγεθος του σχήματος θα αλλάξει ώστε να ταιριάζει στο κείμενο. |
