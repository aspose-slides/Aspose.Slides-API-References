## TabAlignment απαρίθμηση

Αντιπροσωπεύει την ευθυγράμμιση του στηλοπαύλας.

Ο τύπος TabAlignment εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| LEFT | Αριστερή ευθυγράμμιση |
| CENTER | Κεντρική ευθυγράμμιση |
| RIGHT | Δεξιά ευθυγράμμιση |
| DECIMAL | Δεκαδική ευθυγράμμιση |
