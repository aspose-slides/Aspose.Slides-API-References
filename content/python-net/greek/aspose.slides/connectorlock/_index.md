## ConnectorLock κλάση

Determines which operations are disabled on the parent Connector.

**Κληρονομικότητα:**[`ConnectorLock`](/slides/python-net/el/aspose.slides/connectorlock) → [`BaseShapeLock`](/slides/python-net/el/aspose.slides/baseshapelock)

Ο τύπος ConnectorLock εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`no_locks`](/slides/python-net/el/aspose.slides/connectorlock/no_locks/) | Επιστρέφει true αν όλες οι σημαίες κλειδώματος είναι απενεργοποιημένες.<br/>            Μόνο ανάγνωση **bool**. |
| [`grouping_locked`](/slides/python-net/el/aspose.slides/connectorlock/grouping_locked/) | Καθορίζει εάν η προσθήκη αυτού του σχήματος σε μια ομάδα απαγορεύεται.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`select_locked`](/slides/python-net/el/aspose.slides/connectorlock/select_locked/) | Καθορίζει εάν η επιλογή αυτού του σχήματος απαγορεύεται.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`rotate_locked`](/slides/python-net/el/aspose.slides/connectorlock/rotate_locked/) | Καθορίζει εάν η αλλαγή της γωνίας περιστροφής αυτού του σχήματος απαγορεύεται.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/el/aspose.slides/connectorlock/aspect_ratio_locked/) | Καθορίζει εάν ένα σχήμα πρέπει να διατηρεί την αναλογία διαστάσεων κατά την αλλαγή μεγέθους.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`position_move`](/slides/python-net/el/aspose.slides/connectorlock/position_move/) | Καθορίζει εάν η μετακίνηση αυτού του σχήματος απαγορεύεται.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`size_locked`](/slides/python-net/el/aspose.slides/connectorlock/size_locked/) | Καθορίζει εάν η αλλαγή μεγέθους αυτού του σχήματος απαγορεύεται.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`edit_points_locked`](/slides/python-net/el/aspose.slides/connectorlock/edit_points_locked/) | Καθορίζει εάν η άμεση αλλαγή του περιγράμματος αυτού του σχήματος απαγορεύεται.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`adjust_handles_locked`](/slides/python-net/el/aspose.slides/connectorlock/adjust_handles_locked/) | Καθορίζει εάν η αλλαγή των τιμών προσαρμογής απαγορεύεται.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`arrowheads_locked`](/slides/python-net/el/aspose.slides/connectorlock/arrowheads_locked/) | Καθορίζει εάν η αλλαγή των άκρων των βελών απαγορεύεται.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`shape_type_locked`](/slides/python-net/el/aspose.slides/connectorlock/shape_type_locked/) | Καθορίζει εάν η αλλαγή τύπου σχήματος απαγορεύεται.<br/>            Ανάγνωση/εγγραφή **bool**. |
