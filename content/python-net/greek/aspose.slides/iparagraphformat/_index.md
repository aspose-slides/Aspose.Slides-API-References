## IParagraphFormat κλάση

Αυτή η κλάση περιέχει τις ιδιότητες μορφοποίησης παραγράφου. Σε αντίθεση με [`IParagraphFormatEffectiveData`](/slides/python-net/el/aspose.slides/iparagraphformateffectivedata), όλες οι ιδιότητες αυτής της κλάσης είναι εγγράψιμες.

### Παρατηρήσεις

Αυτή η κλάση χρησιμοποιείται για την επιστροφή και τη διαχείριση των ιδιοτήτων μορφοποίησης παραγράφου που ορίζονται για τη συγκεκριμένη παράγραφο. Αυτό σημαίνει ότι δεν εφαρμόζεται κληρονόμηση κατά τη λήψη των τιμών, έτσι για τις περισσότερες περιπτώσεις θα λάβετε τιμές που σημαίνουν «ακαθόριστη».

Για να λάβετε τις αποτελεσματικές τιμές παραμέτρων μορφοποίησης, συμπεριλαμβανομένων των κληρονομημένων, πρέπει να χρησιμοποιήσετε τη μέθοδο [`IParagraphFormat.get_effective`](/slides/python-net/el/aspose.slides/iparagraphformat/get_effective) 
            η οποία επιστρέφει μια παρουσία [`IParagraphFormatEffectiveData`](/slides/python-net/el/aspose.slides/iparagraphformateffectivedata).
