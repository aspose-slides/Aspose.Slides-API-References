## IBulletFormatEffectiveData κλάση

Αμετάβλητο αντικείμενο που περιέχει τις αποτελεσματικές ιδιότητες μορφοποίησης κουκίδων παραγράφου.

Ο τύπος IBulletFormatEffectiveData εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`type`](/slides/python-net/el/aspose.slides/ibulletformateffectivedata/type/) | Επιστρέφει τον τύπο της κουκίδας μιας παραγράφου.<br/>            Μόνο για ανάγνωση [`BulletType`](/slides/python-net/el/aspose.slides/bullettype). |
| [`char`](/slides/python-net/el/aspose.slides/ibulletformateffectivedata/char/) | Επιστρέφει το χαρακτήρα της κουκίδας μιας παραγράφου.<br/>            Μόνο για ανάγνωση **System.Char**. |
| [`actual_bullet_value`](/slides/python-net/el/aspose.slides/ibulletformateffectivedata/actual_bullet_value/) | Επιστρέφει την πραγματική τιμή της κουκίδας για τη γονική παράγραφο.<br/>            Μόνο για ανάγνωση **str**. |
| [`font`](/slides/python-net/el/aspose.slides/ibulletformateffectivedata/font/) | Επιστρέφει τη γραμματοσειρά της κουκίδας μιας παραγράφου.<br/>            Μόνο για ανάγνωση [`IFontData`](/slides/python-net/el/aspose.slides/ifontdata). |
| [`height`](/slides/python-net/el/aspose.slides/ibulletformateffectivedata/height/) | Επιστρέφει το ύψος της κουκίδας μιας παραγράφου.<br/>            Μόνο για ανάγνωση **float**. |
| [`numbered_bullet_start_with`](/slides/python-net/el/aspose.slides/ibulletformateffectivedata/numbered_bullet_start_with/) | Επιστρέφει τον πρώτο αριθμό που χρησιμοποιείται για ομάδα αριθμημένων κουκίδων.<br/>            Μόνο για ανάγνωση **int**. |
| [`numbered_bullet_style`](/slides/python-net/el/aspose.slides/ibulletformateffectivedata/numbered_bullet_style/) | Επιστρέφει το στυλ μιας αριθμημένης κουκίδας.<br/>            Μόνο για ανάγνωση [`NumberedBulletStyle`](/slides/python-net/el/aspose.slides/numberedbulletstyle). |
| [`is_bullet_hard_color`](/slides/python-net/el/aspose.slides/ibulletformateffectivedata/is_bullet_hard_color/) | Καθορίζει εάν η κουκίδα έχει δικό της χρώμα ή το κληρονομεί από το πρώτο τμήμα στην παράγραφο.<br/>            Επιστρέφει **true**  εάν η κουκίδα έχει δικό της χρώμα και **false**  εάν η κουκίδα κληρονομεί το χρώμα από το πρώτο τμήμα στην παράγραφο.<br/>            Μόνο για ανάγνωση **bool**. |
| [`is_bullet_hard_font`](/slides/python-net/el/aspose.slides/ibulletformateffectivedata/is_bullet_hard_font/) | Καθορίζει εάν η κουκίδα έχει δική της γραμματοσειρά ή την κληρονομεί από το πρώτο τμήμα στην παράγραφο.<br/>            Επιστρέφει **true**  εάν η κουκίδα έχει δική της γραμματοσειρά και **true**  εάν η κουκίδα κληρονομεί τη γραμματοσειρά από το πρώτο τμήμα στην παράγραφο.<br/>            Μόνο για ανάγνωση **bool**. |
| [`picture`](/slides/python-net/el/aspose.slides/ibulletformateffectivedata/picture/) | Επιστρέφει την εικόνα που χρησιμοποιείται ως κουκίδα στην παράγραφο.<br/>            Μόνο για ανάγνωση [`IPictureEffectiveData`](/slides/python-net/el/aspose.slides/ipictureeffectivedata). |
| [`fill_format`](/slides/python-net/el/aspose.slides/ibulletformateffectivedata/fill_format/) | Επιστρέφει τη μορφή γεμίσματος της κουκίδας μιας παραγράφου.<br/>            Μόνο για ανάγνωση [`IFillFormatEffectiveData`](/slides/python-net/el/aspose.slides/ifillformateffectivedata). |
