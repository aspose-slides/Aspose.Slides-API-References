## CommentAuthor κλάση

Αντιπροσωπεύει έναν συγγραφέα σχολίων.

Ο τύπος CommentAuthor εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`name`](/slides/python-net/el/aspose.slides/commentauthor/name/) | Επιστρέφει ή ορίζει το όνομα του συγγραφέα.<br/>            Ανάγνωση/Εγγραφή **str**. |
| [`initials`](/slides/python-net/el/aspose.slides/commentauthor/initials/) | Επιστρέφει ή ορίζει τα αρχικά του συγγραφέα.<br/>            Ανάγνωση/Εγγραφή **str**. |
| [`comments`](/slides/python-net/el/aspose.slides/commentauthor/comments/) | Επιστρέφει τη συλλογή των σχολίων που έκανε αυτός ο συγγραφέας.<br/>            Μόνο για ανάγνωση [`ICommentCollection`](/slides/python-net/el/aspose.slides/icommentcollection). |

## Μέθοδοι

| Μέθοδος | Περιγραφή |
| :- | :- |
| [`remove(self)`](/slides/python-net/el/aspose.slides/commentauthor/remove/#) | Αφαιρεί τον συγγραφέα από τη γονική συλλογή. |
