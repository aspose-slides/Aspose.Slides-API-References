## LoadFormat απαρίθμηση

Δείχνει τη μορφή του εγγράφου που πρέπει να φορτωθεί.

Ο τύπος LoadFormat εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| AUTO | Δίνει οδηγίες στο Aspose.Slides να αναγνωρίζει τη μορφή αυτόματα. |
| PPT | Microsoft PowerPoint 97-2003 Παρουσίαση. |
| PPS | Microsoft PowerPoint 97-2003 Παρουσίαση διαφανειών. |
| PPTX | Microsoft Office Open XML PresentationML Έγγραφο. |
| PPSX | Microsoft Office Open XML PresentationML Παρουσίαση διαφανειών. |
| ODP | OpenOffice ODF Παρουσίαση. |
| POTX | Microsoft Office Open XML PresentationML Πρότυπο. |
| PPTM | Microsoft Office Open XML PresentationML Έγγραφο με μακροεντολές. |
| PPSM | Microsoft Office Open XML PresentationML Παρουσίαση διαφανειών με μακροεντολές. |
| POTM | Microsoft Office Open XML PresentationML Πρότυπο με μακροεντολές. |
| OTP | OpenOffice OTP Πρότυπο παρουσίασης. |
| PPT95 | Microsoft PowerPoint 95 Παρουσίαση. |
| POT | Microsoft PowerPoint 97-2003 Πρότυπο παρουσίασης. |
| FODP | Flat XML ODF Παρουσίαση. |
| UNKNOWN | Άγνωστη μορφή αρχείου |
