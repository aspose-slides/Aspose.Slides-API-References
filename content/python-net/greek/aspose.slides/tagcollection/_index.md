## TagCollection κλάση

Αναπαριστά τη συλλογή των ετικετών (ζεύγη συμβολοσειρών που ορίζονται από τον χρήστη)

Ο τύπος TagCollection εκθέτει τα παρακάτω μέλη:

## Μέθοδοι

| Method | Περιγραφή |
| :- | :- |
| [`add(self, name, value)`](/slides/python-net/el/aspose.slides/tagcollection/add/#str-str) | Προσθέτει μια νέα ετικέτα στη συλλογή. |
| [`remove(self, name)`](/slides/python-net/el/aspose.slides/tagcollection/remove/#str) | Αφαιρεί την ετικέτα με το συγκεκριμένο όνομα από τη συλλογή. |
| [`index_of_name(self, name)`](/slides/python-net/el/aspose.slides/tagcollection/index_of_name/#str) | Επιστρέφει το μηδενικό δείκτη του καθορισμένου κλειδιού στη συλλογή. |
| [`remove_at(self, index)`](/slides/python-net/el/aspose.slides/tagcollection/remove_at/#int) | Αφαιρεί την ετικέτα στον καθορισμένο δείκτη. |
| [`clear(self)`](/slides/python-net/el/aspose.slides/tagcollection/clear/#) | Αφαιρεί όλες τις ετικέτες από τη συλλογή. |
| [`get_value_by_index(self, index)`](/slides/python-net/el/aspose.slides/tagcollection/get_value_by_index/#int) | Επιστρέφει την τιμή μιας ετικέτας στον καθορισμένο δείκτη. |
| [`get_name_by_index(self, index)`](/slides/python-net/el/aspose.slides/tagcollection/get_name_by_index/#int) | Επιστρέφει το κλειδί μιας ετικέτας στον καθορισμένο δείκτη. |
| [`get_names_of_tags(self)`](/slides/python-net/el/aspose.slides/tagcollection/get_names_of_tags/#) | Επιστρέφει τα ονόματα των ετικετών. |
