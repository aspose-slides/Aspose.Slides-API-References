## IEffectFormatEffectiveData κλάση

Αμετάβλητο αντικείμενο που περιέχει ιδιότητες μορφοποίησης αποτελεσματικών εφέ.

Ο τύπος IEffectFormatEffectiveData εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`is_no_effects`](/slides/python-net/el/aspose.slides/ieffectformateffectivedata/is_no_effects/) | Επιστρέφει true εάν όλα τα εφέ είναι απενεργοποιημένα (όπως μόλις δημιουργήθηκε, προεπιλεγμένο αντικείμενο EffectFormat).<br/>            Μόνο για ανάγνωση **bool**. |
| [`blur_effect`](/slides/python-net/el/aspose.slides/ieffectformateffectivedata/blur_effect/) | Εφέ θολώματος.<br/>            Μόνο για ανάγνωση [`IBlurEffectiveData`](/slides/python-net/el/aspose.slides.effects/iblureffectivedata). |
| [`fill_overlay_effect`](/slides/python-net/el/aspose.slides/ieffectformateffectivedata/fill_overlay_effect/) | Εφέ επικάλυψης γεμίσματος.<br/>            Μόνο για ανάγνωση [`IFillOverlayEffectiveData`](/slides/python-net/el/aspose.slides.effects/ifilloverlayeffectivedata). |
| [`glow_effect`](/slides/python-net/el/aspose.slides/ieffectformateffectivedata/glow_effect/) | Εφέ λάμψης.<br/>            Μόνο για ανάγνωση [`IGlowEffectiveData`](/slides/python-net/el/aspose.slides.effects/igloweffectivedata). |
| [`inner_shadow_effect`](/slides/python-net/el/aspose.slides/ieffectformateffectivedata/inner_shadow_effect/) | Εσωτερική σκιά.<br/>            Μόνο για ανάγνωση [`IInnerShadowEffectiveData`](/slides/python-net/el/aspose.slides.effects/iinnershadoweffectivedata). |
| [`outer_shadow_effect`](/slides/python-net/el/aspose.slides/ieffectformateffectivedata/outer_shadow_effect/) | Εξωτερική σκιά.<br/>            Μόνο για ανάγνωση [`IOuterShadowEffectiveData`](/slides/python-net/el/aspose.slides.effects/ioutershadoweffectivedata). |
| [`preset_shadow_effect`](/slides/python-net/el/aspose.slides/ieffectformateffectivedata/preset_shadow_effect/) | Προεπιλεγμένη σκιά.<br/>            Μόνο για ανάγνωση [`IPresetShadowEffectiveData`](/slides/python-net/el/aspose.slides.effects/ipresetshadoweffectivedata). |
| [`reflection_effect`](/slides/python-net/el/aspose.slides/ieffectformateffectivedata/reflection_effect/) | Αντανάκλαση.<br/>            Μόνο για ανάγνωση [`IReflectionEffectiveData`](/slides/python-net/el/aspose.slides.effects/ireflectioneffectivedata). |
| [`soft_edge_effect`](/slides/python-net/el/aspose.slides/ieffectformateffectivedata/soft_edge_effect/) | Απαλό άκρο.<br/>            Μόνο για ανάγνωση [`ISoftEdgeEffectiveData`](/slides/python-net/el/aspose.slides.effects/isoftedgeeffectivedata). |

### Σχόλια

Αυτή η διεπαφή χρησιμοποιείται μαζί με τη διεπαφή [`IEffectFormat`](/slides/python-net/el/aspose.slides/ieffectformat) για την επιστροφή αποτελεσματικών τιμών μορφοποίησης με εφαρμοσμένη κληρονομικότητα.
