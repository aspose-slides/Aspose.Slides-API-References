## sound_is_built_in ιδιότητα
Καθορίζει αν αυτός ο ήχος είναι ενσωματωμένος ή όχι. Εάν αυτό το χαρακτηριστικό οριστεί σε true τότε
            η δημιουργική εφαρμογή ειδοποιείται να ελέγξει το χαρακτηριστικό name που έχει καθοριστεί για αυτόν τον ήχο
            στη λίστα των ενσωματωμένων ήχων της και μπορεί στη συνέχεια να εμφανίσει ένα προσαρμοσμένο όνομα ή UI όπως απαιτείται.
            Ανάγνωση-εγγραφή **bool**.
