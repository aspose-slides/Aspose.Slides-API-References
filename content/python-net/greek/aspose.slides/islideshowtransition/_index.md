## ISlideShowTransition κλάση

Αντιπροσωπεύει τη μετάβαση παρουσίασης διαφάνειας.

Ο τύπος ISSlideShowTransition εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`sound`](/slides/python-net/el/aspose.slides/islideshowtransition/sound/) | Επιστρέφει ή ορίζει τα ενσωματωμένα δεδομένα ήχου.<br/>            Αναγνωση-εγγραφή [`IAudio`](/slides/python-net/el/aspose.slides/iaudio). |
| [`sound_mode`](/slides/python-net/el/aspose.slides/islideshowtransition/sound_mode/) | Ορίζει ή επιστρέφει τη λειτουργία ήχου για τη μετάβαση διαφάνειας.<br/>            Αναγνωση-εγγραφή [`TransitionSoundMode`](/slides/python-net/el/aspose.slides.slideshow/transitionsoundmode). |
| [`sound_loop`](/slides/python-net/el/aspose.slides/islideshowtransition/sound_loop/) | Αυτό το χαρακτηριστικό καθορίζει αν ο ήχος θα επαναλαμβάνεται μέχρι να συμβεί το επόμενο γεγονός ήχου στην παρουσίαση.<br/>            Αναγνωση-εγγραφή **bool**. |
| [`advance_on_click`](/slides/python-net/el/aspose.slides/islideshowtransition/advance_on_click/) | Καθορίζει αν ένα κλικ του ποντικιού θα προχωρήσει τη διαφάνεια ή όχι. Εάν αυτό το χαρακτηριστικό δεν καθοριστεί, τότε θεωρείται τιμή true.<br/>            Αναγνωση-εγγραφή **bool**. |
| [`advance_after`](/slides/python-net/el/aspose.slides/islideshowtransition/advance_after/) | Αυτό το χαρακτηριστικό καθορίζει αν η παρουσίαση θα μεταβεί στην επόμενη διαφάνεια μετά από κάποιο χρόνο.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`advance_after_time`](/slides/python-net/el/aspose.slides/islideshowtransition/advance_after_time/) | Καθορίζει το χρόνο, σε χιλιοστά του δευτερολέπτου, μετά τον οποίο η μετάβαση πρέπει να ξεκινήσει. Αυτή η ρύθμιση μπορεί να χρησιμοποιηθεί μαζί με το χαρακτηριστικό advClick. Εάν αυτό το χαρακτηριστικό δεν καθοριστεί, θεωρείται ότι δεν θα γίνει αυτόματη προώθηση.<br/>            Αναγνωση-εγγραφή **int**. |
| [`speed`](/slides/python-net/el/aspose.slides/islideshowtransition/speed/) | Καθορίζει την ταχύτητα της μετάβασης που θα χρησιμοποιηθεί όταν μεταβαίνει η τρέχουσα διαφάνεια στην επόμενη.<br/>            Αναγνωση-εγγραφή [`TransitionSpeed`](/slides/python-net/el/aspose.slides.slideshow/transitionspeed). |
| [`value`](/slides/python-net/el/aspose.slides/islideshowtransition/value/) | Τιμή μετάβασης παρουσίασης διαφάνειας.<br/>            Μόνο-ανάγνωση [`ITransitionValueBase`](/slides/python-net/el/aspose.slides.slideshow/itransitionvaluebase). |
| [`type`](/slides/python-net/el/aspose.slides/islideshowtransition/type/) | Τύπος μετάβασης.<br/>            Αναγνωση-εγγραφή [`TransitionType`](/slides/python-net/el/aspose.slides.slideshow/transitiontype). |
| [`sound_is_built_in`](/slides/python-net/el/aspose.slides/islideshowtransition/sound_is_built_in/) | Καθορίζει αν αυτός ο ήχος είναι ενσωματωμένος ή όχι. Εάν αυτό το χαρακτηριστικό οριστεί σε true, τότε η εφαρμογή δημιουργίας ειδοποιείται να ελέγξει το χαρακτηριστικό name που έχει οριστεί για αυτόν τον ήχο στη λίστα ενσωματωμένων ήχων της και μπορεί στη συνέχεια να εμφανίσει ένα προσαρμοσμένο όνομα ή UI όπως απαιτείται.<br/>            Αναγνωση-εγγραφή **bool**. |
| [`sound_name`](/slides/python-net/el/aspose.slides/islideshowtransition/sound_name/) | Καθορίζει ένα όνομα αναγνώσιμο από άνθρωπο για τον ήχο της μετάβασης. Η ιδιότητα [`ISlideShowTransition.sound`](/slides/python-net/el/aspose.slides/islideshowtransition/sound) πρέπει να οριστεί για να ληφθεί ή να οριστεί το όνομα του ήχου.<br/>            Αναγνωση-εγγραφή **str**. |
| [`duration`](/slides/python-net/el/aspose.slides/islideshowtransition/duration/) | Λαμβάνει ή ορίζει τη διάρκεια του εφέ μετάβασης διαφάνειας σε χιλιοστά του δευτερολέπτου.<br/>            Ανάγνωση/εγγραφή **int**. |
