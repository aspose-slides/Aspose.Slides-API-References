## IImage κλάση

Αναπαριστά μια ραστική ή διανυσματική εικόνα.

Ο τύπος IImage εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`size`](/slides/python-net/el/aspose.slides/iimage/size/) | Λαμβάνει το μέγεθος της εικόνας. |
| [`width`](/slides/python-net/el/aspose.slides/iimage/width/) | Λαμβάνει το πλάτος της εικόνας σε εικονοστοιχεία. |
| [`height`](/slides/python-net/el/aspose.slides/iimage/height/) | Λαμβάνει το ύψος της εικόνας σε εικονοστοιχεία. |

## Μέθοδοι

| Μέθοδος | Περιγραφή |
| :- | :- |
| [`save(self, filename)`](/slides/python-net/el/aspose.slides/iimage/save/#str) | Αποθηκεύει την εικόνα σε ένα αρχείο. |
| [`save(self, filename, format)`](/slides/python-net/el/aspose.slides/iimage/save/#str-imageformat) | Αποθηκεύει την εικόνα σε ένα αρχείο στη συγκεκριμένη μορφή. |
| [`save(self, stream, format)`](/slides/python-net/el/aspose.slides/iimage/save/#iorawiobase-imageformat) | Αποθηκεύει την εικόνα σε ρεύμα στη συγκεκριμένη μορφή. |
| [`save(self, filename, format, quality)`](/slides/python-net/el/aspose.slides/iimage/save/#str-imageformat-int) | Αποθηκεύει την εικόνα σε ένα αρχείο στη συγκεκριμένη μορφή και ποιότητα. |
| [`save(self, stream, format, quality)`](/slides/python-net/el/aspose.slides/iimage/save/#iorawiobase-imageformat-int) | Αποθηκεύει την εικόνα σε ρεύμα στη συγκεκριμένη μορφή και ποιότητα. |

### Παρατηρήσεις

Αυτή η διεπαφή παρέχει μια κοινή αφαίρεση για τη διαχείριση τόσο ραστικών όσο και διανυσματικών εικόνων.  
            Οι υλοποιήσεις μπορεί να διαφέρουν ανάλογα με τον υποκείμενο τύπο εικόνας.
