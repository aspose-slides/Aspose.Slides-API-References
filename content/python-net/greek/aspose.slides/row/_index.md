## Row κλάση

Αντιπροσωπεύει μια γραμμή σε έναν πίνακα.

**Κληρονομικότητα:**[`Row`](/slides/python-net/el/aspose.slides/row) → [`CellCollection`](/slides/python-net/el/aspose.slides/cellcollection)

Ο τύπος Row εκθέτει τα παρακάτω μέρη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`slide`](/slides/python-net/el/aspose.slides/row/slide/) | Επιστρέφει τη γονική διαφάνεια μιας CellCollection.<br/>            Μόνο-ανάγνωση [`IBaseSlide`](/slides/python-net/el/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/el/aspose.slides/row/presentation/) | Επιστρέφει την γονική παρουσίαση μιας CellCollection.<br/>            Μόνο-ανάγνωση [`IPresentation`](/slides/python-net/el/aspose.slides/ipresentation). |
| [`height`](/slides/python-net/el/aspose.slides/row/height/) | Επιστρέφει το ύψος μιας γραμμής.<br/>            Μόνο-ανάγνωση **float**. |
| [`minimal_height`](/slides/python-net/el/aspose.slides/row/minimal_height/) | Επιστρέφει ή ορίζει το ελάχιστο δυνατό ύψος μιας γραμμής.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`row_format`](/slides/python-net/el/aspose.slides/row/row_format/) | Επιστρέφει το αντικείμενο RowFormat που περιέχει ιδιότητες μορφοποίησης για αυτή τη γραμμή.<br/>            Μόνο-ανάγνωση [`IRowFormat`](/slides/python-net/el/aspose.slides/irowformat). |
