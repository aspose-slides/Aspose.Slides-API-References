## IEffectFormat κλάση

Αναπαριστά τις ιδιότητες εφέ του σχήματος.

Ο τύπος IEffectFormat εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Property | Description |
| :- | :- |
| [`is_no_effects`](/slides/python-net/el/aspose.slides/ieffectformat/is_no_effects/) | Επιστρέφει true εάν όλα τα εφέ είναι απενεργοποιημένα (όπως μόλις δημιουργήθηκε, προεπιλεγμένο αντικείμενο EffectFormat).<br/>            Μόνο για ανάγνωση **bool**. |
| [`blur_effect`](/slides/python-net/el/aspose.slides/ieffectformat/blur_effect/) | Εφέ θολώματος.<br/>            Ανάγνωση/εγγραφή [`IBlur`](/slides/python-net/el/aspose.slides.effects/iblur). |
| [`fill_overlay_effect`](/slides/python-net/el/aspose.slides/ieffectformat/fill_overlay_effect/) | Εφέ επικάλυψης γέμισης.<br/>            Ανάγνωση/εγγραφή [`IFillOverlay`](/slides/python-net/el/aspose.slides.effects/ifilloverlay). |
| [`glow_effect`](/slides/python-net/el/aspose.slides/ieffectformat/glow_effect/) | Εφέ λάμψης.<br/>            Ανάγνωση/εγγραφή [`IGlow`](/slides/python-net/el/aspose.slides.effects/iglow). |
| [`inner_shadow_effect`](/slides/python-net/el/aspose.slides/ieffectformat/inner_shadow_effect/) | Εσωτερική σκιά.<br/>            Ανάγνωση/εγγραφή [`IInnerShadow`](/slides/python-net/el/aspose.slides.effects/iinnershadow). |
| [`outer_shadow_effect`](/slides/python-net/el/aspose.slides/ieffectformat/outer_shadow_effect/) | Εξωτερική σκιά.<br/>            Ανάγνωση/εγγραφή [`IOuterShadow`](/slides/python-net/el/aspose.slides.effects/ioutershadow). |
| [`preset_shadow_effect`](/slides/python-net/el/aspose.slides/ieffectformat/preset_shadow_effect/) | Προκαθορισμένη σκιά.<br/>            Ανάγνωση/εγγραφή [`IPresetShadow`](/slides/python-net/el/aspose.slides.effects/ipresetshadow). |
| [`reflection_effect`](/slides/python-net/el/aspose.slides/ieffectformat/reflection_effect/) | Αντανάκλαση.<br/>            Ανάγνωση/εγγραφή [`IReflection`](/slides/python-net/el/aspose.slides.effects/ireflection). |
| [`soft_edge_effect`](/slides/python-net/el/aspose.slides/ieffectformat/soft_edge_effect/) | Απαλό άκρο.<br/>            Ανάγνωση/εγγραφή [`ISoftEdge`](/slides/python-net/el/aspose.slides.effects/isoftedge). |
