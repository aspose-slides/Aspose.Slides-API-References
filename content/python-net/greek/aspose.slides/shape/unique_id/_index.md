## unique_id ιδιότητα
Returns έναν εσωτερικό, περιορισμένο στην παρουσίαση, αναγνωριστικό που προορίζεται για χρήση από πρόσθετα ή άλλο κώδικα.
            Επειδή αυτή η τιμή μπορεί να επανακατανεμηθεί από τον χρήστη ή προγραμματιστικά, δεν πρέπει να θεωρείται ως μόνιμο μοναδικό κλειδί.
            Μόνο για ανάγνωση **int**.
            Δείτε επίσης [`Shape.office_interop_shape_id`](/slides/python-net/el/aspose.slides/shape/office_interop_shape_id).
