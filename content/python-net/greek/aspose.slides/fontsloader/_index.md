## FontsLoader κλάση

Κλάση για φόρτωση προσαρμοσμένων γραμματοσειρών που ορίζονται από τον χρήστη.
Πρέπει να χρησιμοποιείται πριν από τη δημιουργία οποιουδήποτε αντικειμένου παρουσίασης.

Ο τύπος FontsLoader εκθέτει τα παρακάτω μέλη:

## Μέθοδοι

| Μέθοδος | Περιγραφή |
| :- | :- |
| [`load_external_fonts(directories)`](/slides/python-net/el/aspose.slides/fontsloader/load_external_fonts/#liststr) | Προσθέτει επιπλέον φακέλους για την αναζήτηση γραμματοσειρών. |
| [`load_external_font(data)`](/slides/python-net/el/aspose.slides/fontsloader/load_external_font/#bytes) | Προσθέτει γραμματοσειρά από τα δυαδικά δεδομένα |
| [`get_font_folders()`](/slides/python-net/el/aspose.slides/fontsloader/get_font_folders/#) | Λαμβάνει φακέλους γραμματοσειρών. Επιστρέφει φακέλους που έχουν προστεθεί με τη μέθοδο LoadExternalFonts καθώς και φακέλους συστήματος |
| [`clear_cache()`](/slides/python-net/el/aspose.slides/fontsloader/clear_cache/#) | Απελευθερώνει όλες τις προσαρμοσμένες γραμματοσειρές που ορίζονται από τον χρήστη |
