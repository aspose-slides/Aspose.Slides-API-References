## Picture κλάση

Αναπαριστά μια εικόνα σε μια παρουσίαση.

Ο τύπος Picture εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`image`](/slides/python-net/el/aspose.slides/picture/image/) | Επιστρέφει ή ορίζει την ενσωματωμένη εικόνα.<br/>            Ανάγνωση/εγγραφή [`IPPImage`](/slides/python-net/el/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/el/aspose.slides/picture/link_path_long/) | Επιστρέφει ή ορίζει το URL της συνδεδεμένης εικόνας.<br/>            Ανάγνωση/εγγραφή **str**. |
| [`image_transform`](/slides/python-net/el/aspose.slides/picture/image_transform/) | Επιστρέφει τη συλλογή των εφέ μετασχηματισμού εικόνας.<br/>            Μόνο-ανάγνωση [`IImageTransformOperationCollection`](/slides/python-net/el/aspose.slides.effects/iimagetransformoperationcollection). |
| [`presentation`](/slides/python-net/el/aspose.slides/picture/presentation/) | Επιστρέφει την παρουσίαση.<br/>            Μόνο-ανάγνωση [`IPresentation`](/slides/python-net/el/aspose.slides/ipresentation). |
| [`slide`](/slides/python-net/el/aspose.slides/picture/slide/) | Επιστρέφει τη γονική διαφάνεια μιας εικόνας.<br/>            Μόνο-ανάγνωση [`IBaseSlide`](/slides/python-net/el/aspose.slides/ibaseslide). |
