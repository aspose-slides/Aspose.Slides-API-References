## PersistenceType Απαρίθμηση

Καθορίζει τη μέθοδο που χρησιμοποιείται για την αποθήκευση ιδιοτήτων του ελέγχου ActiveX.

Ο τύπος PersistenceType περιέχει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| NOT_DEFINED | Το αναγνωριστικό επιμονής δεν καθορίστηκε. |
| PERSIST_PROPERTY_BAG | Καθορίζει ότι ο έλεγχος ActiveX αποθηκεύεται χρησιμοποιώντας βάση επιμονής τύπου property-bag. <br/> Η βάση επιμονής τύπου property-bag αποθηκεύει έναν έλεγχο ActiveX μέσω μιας συλλογής ζευγών ονομασίας <br/> και τιμής που καθορίζουν τα δεδομένα που αποθηκεύει ο έλεγχος ActiveX. |
| PERSIST_STREAM | Καθορίζει ότι ο έλεγχος ActiveX αποθηκεύεται χρησιμοποιώντας βάση επιμονής τύπου ροής <br/> που δεν υποστηρίζει την προεπιλεγμένη αρχικοποίηση του ελέγχου ActiveX. |
| PERSIST_STREAM_INIT | Καθορίζει ότι ο έλεγχος ActiveX αποθηκεύεται χρησιμοποιώντας βάση επιμονής τύπου ροής <br/> που υποστηρίζει την αρχικοποίηση του ελέγχου ActiveX σε προεπιλεγμένη κατάσταση. |
| PERSIST_STORAGE | Καθορίζει ότι ο έλεγχος ActiveX αποθηκεύεται χρησιμοποιώντας βάση αποθήκευσης. |
