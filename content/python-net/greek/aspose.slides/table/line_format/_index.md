## line_format ιδιότητα
Επιστρέφει το αντικείμενο LineFormat που περιέχει ιδιότητες μορφοποίησης γραμμής για ένα σχήμα.
            Σημείωση: μπορεί να επιστρέψει None για ορισμένα είδη σχημάτων που δεν έχουν ιδιότητες γραμμής.
            Μόνο για ανάγνωση [`ILineFormat`](/slides/python-net/el/aspose.slides/ilineformat).
