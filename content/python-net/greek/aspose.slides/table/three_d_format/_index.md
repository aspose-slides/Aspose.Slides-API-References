## three_d_format ιδιότητα
Επιστρέφει το αντικείμενο ThreeDFormat που περιλαμβάνει τις ιδιότητες εφέ 3d για ένα σχήμα.
            Σημείωση: μπορεί να επιστρέψει None για ορισμένους τύπους σχημάτων που δεν έχουν ιδιότητες 3d.
            Μόνο για ανάγνωση [`IThreeDFormat`](/slides/python-net/el/aspose.slides/ithreedformat).
