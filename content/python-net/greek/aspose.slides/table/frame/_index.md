## ιδιότητα πλαισίου
Επιστρέφει ή ορίζει τις ιδιότητες του πλαισίου σχήματος.
            Ανάγνωση/Εγγραφή [`IShapeFrame`](/slides/python-net/el/aspose.slides/ishapeframe).

### Παρατηρήσεις

Η τιμή κάθε ιδιότητας της επιστρεφόμενης παρουσίας IShapeFrame δεν είναι undefined (δεν είναι NaN ή NotDefined).
            Η τιμή κάθε ιδιότητας της εκχωρημένης παρουσίας IShapeFrame πρέπει να μην είναι undefined (πρέπει να μην είναι NaN ή NotDefined).
            Μπορείτε να ορίσετε τιμές undefined για τις ιδιότητες της παρουσίας RawFrame.
