## Ενοποίηση AudioPlayModePreset

Σταθερές που ορίζουν πώς αναπαράγεται ένας ήχος.

Ο τύπος AudioPlayModePreset εκθέτει τα παρακάτω μέλη:

## Πεδία

| Field | Description |
| :- | :- |
| MIXED |  |
| AUTO | Αναπαραγωγή αυτόματα. |
| ON_CLICK | Αναπαραγωγή μόνο όταν κάνετε κλικ στο εικονίδιο. |
| ALL_SLIDES | Αναπαραγωγή σε όλες τις διαφάνειες. <br/>            Please use [`IAudioFrame.play_across_slides`](/slides/python-net/el/aspose.slides/iaudioframe/play_across_slides) property instead.<br/>            This element is out of date since PowerPoint 2013. |
| IN_CLICK_SEQUENCE | Αναπαραγωγή αυτόματα με κλικ. |
