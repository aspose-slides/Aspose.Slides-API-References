## insert_summary_zoom_frame(self, index, x, y, width, height) {#int-float-float-float-float}
Δημιουργεί ένα νέο πλαίσιο Summary Zoom και το εισάγει στη συλλογή σχημάτων στον καθορισμένο δείκτη.

### Επιστρέφει

Το νεοδημιουργημένο [`ISummaryZoomFrame`](/slides/python-net/el/aspose.slides/isummaryzoomframe).

```python
def insert_summary_zoom_frame(self, index, x, y, width, height):
    ...
```

| Παράμετρος | Τύπος | Περιγραφή |
| :- | :- | :- |
| index | **int** | Ο δείκτης μηδενικής βάσης στον οποίο θα εισαχθεί το πλαίσιο Summary Zoom. |
| x | **float** | Η συντεταγμένη x του νέου πλαισίου Summary Zoom, σε σημεία. |
| y | **float** | Η συντεταγμένη y του νέου πλαισίου Summary Zoom, σε σημεία. |
| width | **float** | Το πλάτος του νέου πλαισίου Summary Zoom, σε σημεία. |
| height | **float** | Το ύ ψος του νέου πλαισίου Summary Zoom, σε σημεία. |

### Σχόλια

Αυτή η μέθοδος δημιουργεί ένα πλαίσιο Summary Zoom που συγκεντρώνει συνδέσμους σύνοψης για όλα τα τμήματα στην παρουσίαση.
