## insert_chart(self, type, x, y, width, height, index) {#asposeslideschartscharttype-float-float-float-float-int}
Δημιουργεί ένα νέο γράφημα, το αρχικοποιεί με δείγματα δεδομένων σειράς και ρυθμίσεις, και το εισάγει στη συλλογή σχημάτων στον καθορισμένο δείκτη.

### Επιστρέφει

Το 신규 δημιουργημένο [`IChart`](/slides/python-net/el/aspose.slides.charts/ichart).



```python
def insert_chart(self, type, x, y, width, height, index):
    ...
```


| Parameter | Type | Description |
| :- | :- | :- |
| type | [`ChartType`](/slides/python-net/el/aspose.slides.charts/charttype) | Ο τύπος του γραφήματος που θα δημιουργηθεί. |
| x | **float** | Η x-συντεταγμένη του νέου γραφήματος, σε σημεία. |
| y | **float** | Η y-συντεταγμένη του νέου γραφήματος, σε σημεία. |
| width | **float** | Το πλάτος του νέου γραφήματος, σε σημεία. |
| height | **float** | Το ύψος του νέου γραφήματος, σε σημεία. |
| index | **int** | Ο δείκτης μηδενικής βάσης που θα χρησιμοποιηθεί για την εισαγωγή του νέου γραφήματος στη συλλογή σχημάτων. |

| x | **float** | Η x-συντεταγμένη του νέου γραφήματος, σε σημεία. |
