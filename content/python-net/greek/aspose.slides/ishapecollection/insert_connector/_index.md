            εφαρμόζοντας προεπιλεγμένο στιλ προτύπου.

```python
def insert_connector(self, index, shape_type, x, y, width, height):
    ...
```

| Παράμετρος | Τύπος | Περιγραφή |
| :- | :- | :- |
| index | **int** | Ο δείκτης με μηδενική βάση στον οποίο θα εισαχθεί το σχήμα σύνδεσης. |
| shape_type | [`ShapeType`](/slides/python-net/el/aspose.slides/shapetype) | Το [`ShapeType`](/slides/python-net/el/aspose.slides/shapetype) του σχήματος σύνδεσης προς εισαγωγή. |
| x | **float** | Η x-συντεταγμένη του πλαισίου του σύνδεσμου, σε μονάδες σημείου. |
| y | **float** | Η y-συντεταγμένη του πλαισίου του σύνδεσμου, σε μονάδες σημείου. |
| width | **float** | Το πλάτος του πλαισίου του σύνδεσμου, σε μονάδες σημείου. |
| height | **float** | Το ύψος του πλαισίου του σύνδεσμου, σε μονάδες σημείου. |
