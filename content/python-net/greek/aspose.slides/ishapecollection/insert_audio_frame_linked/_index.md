```python
    ...
```

| Παράμετρος | Τύπος | Περιγραφή |
| :- | :- | :- |
| index | **int** | Ο μηδενικός δείκτης όπου θα εισαχθεί το audio frame. |
| x | **float** | Η συντεταγμένη x του νέου audio frame, σε points. |
| y | **float** | Η συντεταγμένη y του νέου audio frame, σε points. |
| width | **float** | Το πλάτος του νέου audio frame, σε points. |
| height | **float** | Το ύψος του νέου audio frame, σε points. |
