## ColorTransformOperation απαρίθμηση

Καθορίζει τη λειτουργία μετασχηματισμού χρώματος.

Ο τύπος ColorTransformOperation εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| TINT | Τονίζει το χρώμα. Η παράμετρος είναι στο εύρος μεταξύ 0 (αρχικό χρώμα) και 1 (λευκό). |
| SHADE | Σκιάζει το χρώμα. Η παράμετρος είναι στο εύρος μεταξύ 0 (αρχικό χρώμα) και 1 (μαύρο). |
| COMPLEMENT | Αλλάζει το χρώμα σε ένα συμπληρωματικό RGB.<br/>            m = Max(r, g, b);<br/>            r = m - r;<br/>            g = m - g;<br/>            b = m - b; |
| INVERSE | Αλλάζει το χρώμα σε αντίστροφο χρώμα.<br/>            r = 1 - r;<br/>            g = 1 - g;<br/>            b = 1 - b; |
| GRAYSCALE | Αλλάζει το χρώμα σε γκρι με την ίδια φωτεινότητα. Η παράμετρος αγνοείται. |
| SET_ALPHA | Ορίζει ένα άλφα στοιχείο του χρώματος. Η παράμετρος είναι στο εύρος μεταξύ 0 (διαφανές) και 1 (αδιαφανές). |
| ADD_ALPHA | Προσθέτει την τιμή μιας παραμέτρου σε ένα άλφα στοιχείο του χρώματος. Η παράμετρος είναι στο εύρος μεταξύ -1 και 1. |
| MULTIPLY_ALPHA | Πολλαπλασιάζει ένα άλφα στοιχείο με την τιμή μιας παραμέτρου. |
| SET_HUE | Αλλάζει το στοιχείο απόχρωσης του χρώματος στην τιμή μιας παραμέτρου. Η παράμετρος είναι στο εύρος μεταξύ 0 και 360. |
| ADD_HUE | Προσθέτει την τιμή μιας παραμέτρου στο στοιχείο απόχρωσης του χρώματος. Η παράμετρος είναι στο εύρος μεταξύ -360 και 360. |
| MULTIPLY_HUE | Πολλαπλασιάζει το στοιχείο απόχρωσης με την τιμή μιας παραμέτρου. |
| SET_SATURATION | Αλλάζει το στοιχείο κορεσμού του χρώματος στην τιμή μιας παραμέτρου. Η παράμετρος είναι στο εύρος μεταξύ 0 και 1. |
| ADD_SATURATION | Προσθέτει την τιμή μιας παραμέτρου στο στοιχείο κορεσμού του χρώματος. Η παράμετρος είναι στο εύρος μεταξύ -1 και 1. |
| MULTIPLY_SATURATION | Πολλαπλασιάζει το στοιχείο κορεσμού με την τιμή μιας παραμέτρου. |
| SET_LUMINANCE | Αλλάζει το στοιχείο φωτεινότητας του χρώματος στην τιμή μιας παραμέτρου. Η παράμετρος είναι στο εύρος μεταξύ 0 και 1. |
| ADD_LUMINANCE | Προσθέτει την τιμή μιας παραμέτρου στο στοιχείο φωτεινότητας του χρώματος. Η παράμετρος είναι στο εύρος μεταξύ -1 και 1. |
| MULTIPLY_LUMINANCE | Πολλαπλασιάζει το στοιχείο φωτεινότητας με την τιμή μιας παραμέτρου. |
| SET_RED | Αλλάζει το κόκκινο στοιχείο του χρώματος στην τιμή μιας παραμέτρου. Η παράμετρος είναι στο εύρος μεταξύ 0 και 1. |
| ADD_RED | Προσθέτει την τιμή μιας παραμέτρου σε ένα κόκκινο στοιχείο του χρώματος. Η παράμετρος είναι στο εύρος μεταξύ -1 και 1. |
| MULTIPLY_RED | Πολλαπλασιάζει ένα κόκκινο στοιχείο με μια παράμετρο. |
| SET_GREEN | Αλλάζει το πράσινο στοιχείο του χρώματος στην τιμή μιας παραμέτρου. Η παράμετρος είναι στο εύρος μεταξύ 0 και 1. |
| ADD_GREEN | Προσθέτει μια παράμετρο σε ένα πράσινο στοιχείο του χρώματος. Η παράμετρος είναι στο εύρος μεταξύ -1 και 1. |
| MULTIPLY_GREEN | Πολλαπλασιάζει ένα πράσινο στοιχείο του χρώματος με την τιμή μιας παραμέτρου. |
| SET_BLUE | Αλλάζει το μπλε στοιχείο του χρώματος στην τιμή μιας παραμέτρου. Η παράμετρος είναι στο εύρος μεταξύ 0 και 360. |
| ADD_BLUE | Προσθέτει την τιμή μιας παραμέτρου σε ένα μπλε στοιχείο του χρώματος. Η παράμετρος είναι στο εύρος μεταξύ -1 και 1. |
| MULTIPLY_BLUE | Πολλαπλασιάζει ένα μπλε στοιχείο του χρώματος με την τιμή μιας παραμέτρου. |
| GAMMA | Διόρθωση γάμα. Η παράμετρος αγνοείται. |
| INVERSE_GAMMA | Αντίστροφη διόρθωση γάμα. Η παράμετρος αγνοείται. |
