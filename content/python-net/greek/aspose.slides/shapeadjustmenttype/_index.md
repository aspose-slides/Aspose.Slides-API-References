## ShapeAdjustmentType απαρίθμηση

Καθορίζει διαφορετικούς τύπους τιμών προσαρμογής σχήματος.

Ο τύπος ShapeAdjustmentType εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| CUSTOM | Προσαρμοσμένος τύπος (άγνωστη προσαρμογή) |
| CORNER_SIZE | Ελέγχει το μέγεθος των γωνιών. |
| LEFT_UP_CORNER | Ελέγχει την πάνω αριστερή γωνία. |
| RIGHT_UP_CORNER | Ελέγχει την πάνω δεξιά γωνία. |
| UP_CORNERS | Ελέγχει τις επάνω γωνίες. |
| DOWN_CORNERS | Ελέγχει τις κάτω γωνίες. |
| THICKNESS | Ελέγχει το πάχος του σχήματος. |
| ARROW_TAIL_THICKNESS | Ελέγχει το πάχος της ουράς του βέλους. |
| ARROWHEAD_LENGTH | Ελέγχει το μήκος της κεφαλής του βέλους. |
| ARROWHEAD_WIDTH | Ελέγχει το πλάτος της κεφαλής του βέλους. |
| RADIUS | Ελέγχει το μέγεθος της ακτίνας του σχήματος ή του τμήματός του. |
| DEPTH | Ελέγχει το βάθος των δοντιών του γραναζιού ή του εφέ λοξής τομής. |
| SHAPE_PART_OFFSET | Ελέγχει την αντιστάθμιση ενός τμήματος του σχήματος σε σχέση με άλλο. |
| ANGLE | Ελέγχει τη γωνία του σχήματος ή του τμήματός του. |
| START_ANGLE | Γωνία έναρξης για σχήματα πίτας και τόξου. |
| END_ANGLE | Γωνία λήξης για σχήματα πίτας και τόξου. |
| START_POINT_X | Ελέγχει τη θέση X του σημείου έναρξης του απόσπασματος. |
| START_POINT_Y | Ελέγχει τη θέση Y του σημείου έναρξης του απόσπασματος. |
| CONNECTOR_POINT_1X | Ελέγχει τη οριζόντια θέση του σημείου ρύθμισης γωνίας του απόσπασματος. |
| CONNECTOR_POINT_1Y | Ελέγχει την κάθετη θέση του σημείου ρύθμισης γωνίας του απόσπασματος. |
| CONNECTOR_POINT_2X | Ελέγχει τη οριζόντια θέση του σημείου ρύθμισης γωνίας του απόσπασματος. |
| CONNECTOR_POINT_2Y | Ελέγχει την κάθετη θέση του σημείου ρύθμισης γωνίας του απόσπασματος. |
| CONNECTOR_BEND_POSITION_X | Ελέγχει τη οριζόντια θέση της κάμψης στο σύνδεσμο. |
| CONNECTOR_BEND_POSITION_Y | Ελέγει την κάθετη θέση της κάμψης στο σύνδεσμο. |
| ATTACH_Y | Ελέγχει το κατακόρυφο σημείο προσάρτησης του σχήματος. |
| ATTACH_X | Ελέγει το οριζόντιο σημείο προσάρτησης του σχήματος. |
| CALLOUT_HEIGHT | Ελέγχει το κατακόρυφο μέγεθος του απόσπασματος. |
| CALLOUT_WIDTH | Ελέγει το οριζόντιο μέγεθος του απόσπασματος. |
| CALLOUT_SIZE | Ελέγει το μέγεθος του απόσπασματος. |
| CURVATURE | Καμπυλότητα λυγισμένου, αγκίστρου, καμπυλωτού βέλους ή σχήματος. |
| HORIZONTAL_THICKNESS | Ελέγχει το οριζόντιο πάχος του σχήματος γωνίας. |
| VERTICAL_THICKNESS | Ελέγει το κάθετο πάχος του σχήματος γωνίας. |
| VERTICAL_SIZE | Ελέγχει το κάθετο μέγεθος του σχήματος. |
| HORIZONTAL_SIZE | Ελέγει το οριζόντιο μέγεθος του σχήματος. |
| TOP | Ελέγει την επάνω πλευρά ενός σχήματος. |
