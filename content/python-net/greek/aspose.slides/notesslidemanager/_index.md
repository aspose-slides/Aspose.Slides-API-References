## NotesSlideManager κλάση

Διαχειριστής διαφανειών σημειώσεων.

Ο τύπος NotesSlideManager εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`notes_slide`](/slides/python-net/el/aspose.slides/notesslidemanager/notes_slide/) | Επιστρέφει τη διαφάνεια σημειώσεων για την τρέχουσα διαφάνεια. Επιστρέφει None εάν η διαφάνεια δεν έχει διαφάνεια σημειώσεων.<br/>            Μόνο για ανάγνωση [`INotesSlide`](/slides/python-net/el/aspose.slides/inotesslide). |

## Μέθοδοι

| Μέθοδος | Περιγραφή |
| :- | :- |
| [`add_notes_slide(self)`](/slides/python-net/el/aspose.slides/notesslidemanager/add_notes_slide/#) | Επιστρέφει τη διαφάνεια σημειώσεων για την τρέχουσα διαφάνεια, δημιουργώντας μία αν δεν υπάρχει. |
| [`remove_notes_slide(self)`](/slides/python-net/el/aspose.slides/notesslidemanager/remove_notes_slide/#) | Αφαιρεί τη διαφάνεια σημειώσεων της τρέχουσας διαφάνειας. |
