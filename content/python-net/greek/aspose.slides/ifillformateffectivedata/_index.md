## IFillFormatEffectiveData κλάση

Αμετάβλητο αντικείμενο που περιέχει τις αποτελεσματικές ιδιότητες μορφοποίησης γεμίσματος.

Ο τύπος IFillFormatEffectiveData εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`fill_type`](/slides/python-net/el/aspose.slides/ifillformateffectivedata/fill_type/) | Returns the type of filling.<br/>            Μόνο για ανάγνωση [`FillType`](/slides/python-net/el/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/el/aspose.slides/ifillformateffectivedata/solid_fill_color/) | Returns the fill color.<br/>            Μόνο για ανάγνωση [`Color`](/slides/python-net/el/aspose.slides/color). |
| [`solid_fill_scheme_color`](/slides/python-net/el/aspose.slides/ifillformateffectivedata/solid_fill_scheme_color/) | Gets the fill color defined by a color scheme.<br/>            The [`SchemeColor.NOT_DEFINED`](/slides/python-net/el/aspose.slides/schemecolor/NOT_DEFINED) value indicates that the [`IFillFormatEffectiveData.solid_fill_color`](/slides/python-net/el/aspose.slides/ifillformateffectivedata/solid_fill_color) <br/>            is not a scheme color.<br/>            Μόνο για ανάγνωση [`SchemeColor`](/slides/python-net/el/aspose.slides/schemecolor). |
| [`gradient_format`](/slides/python-net/el/aspose.slides/ifillformateffectivedata/gradient_format/) | Returns the gradient fill format.<br/>            Μόνο για ανάγνωση [`IGradientFormatEffectiveData`](/slides/python-net/el/aspose.slides/igradientformateffectivedata). |
| [`pattern_format`](/slides/python-net/el/aspose.slides/ifillformateffectivedata/pattern_format/) | Returns the pattern fill format.<br/>            Μόνο για ανάγνωση [`IPatternFormatEffectiveData`](/slides/python-net/el/aspose.slides/ipatternformateffectivedata). |
| [`picture_fill_format`](/slides/python-net/el/aspose.slides/ifillformateffectivedata/picture_fill_format/) | Returns the picture fill format.<br/>            Μόνο για ανάγνωση [`IPictureFillFormatEffectiveData`](/slides/python-net/el/aspose.slides/ipicturefillformateffectivedata). |
| [`rotate_with_shape`](/slides/python-net/el/aspose.slides/ifillformateffectivedata/rotate_with_shape/) | Determines whether the fill should be rotated with shape.<br/>            Μόνο για ανάγνωση **bool**. |

### Σχόλια

Αυτή η διεπαφή χρησιμοποιείται μαζί με τη [`IFillFormat`](/slides/python-net/el/aspose.slides/ifillformat) διεπαφή για την επιστροφή αποτελεσματικών τιμών μορφοποίησης με κληρονομικότητα.
