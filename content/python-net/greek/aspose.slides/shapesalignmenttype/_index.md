## ShapesAlignmentType απαρίθμηση

Ορίζει έναν τρόπο να αλλάξει η τοποθέτηση των επιλεγμένων σχημάτων στη διαφάνεια.

Ο τύπος ShapesAlignmentType εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| ALIGN_LEFT | Στοίχιση αριστερά |
| ALIGN_RIGHT | Στοίχιση δεξιά |
| ALIGN_CENTER | Στοίχιση κέντρο |
| ALIGN_TOP | Στοίχιση επάνω |
| ALIGN_MIDDLE | Στοίχιση μεσαία |
| ALIGN_BOTTOM | Στοίχιση κάτω |
| DISTRIBUTE_HORIZONTALLY | Διανομή οριζόντια |
| DISTRIBUTE_VERTICALLY | Διανομή κατακόρυφα |
