## GraphicalObjectLock κλάση

Καθορίζει ποιες λειτουργίες είναι απενεργοποιημένες στο γονικό GraphicalObject.

**Κληρονομικότητα:**[`GraphicalObjectLock`](/slides/python-net/el/aspose.slides/graphicalobjectlock) → [`BaseShapeLock`](/slides/python-net/el/aspose.slides/baseshapelock)

Ο τύπος GraphialObjectLock εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`no_locks`](/slides/python-net/el/aspose.slides/graphicalobjectlock/no_locks/) | Επιστρέφει true αν όλες οι σημαίες κλειδώματος είναι απενεργοποιημένες.<br/>            Μόνο-ανάγνωση **bool**. |
| [`grouping_locked`](/slides/python-net/el/aspose.slides/graphicalobjectlock/grouping_locked/) | Καθορίζει αν η προσθήκη αυτού του σχήματος σε μια ομάδα απαγορεύεται.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`drilldown_locked`](/slides/python-net/el/aspose.slides/graphicalobjectlock/drilldown_locked/) | Καθορίζει αν η επιλογή υποσχημάτων αυτού του αντικειμένου απαγορεύεται.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`select_locked`](/slides/python-net/el/aspose.slides/graphicalobjectlock/select_locked/) | Καθορίζει αν η επιλογή αυτού του σχήματος απαγορεύεται.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/el/aspose.slides/graphicalobjectlock/aspect_ratio_locked/) | Καθορίζει αν το σχήμα πρέπει να διατηρεί την αναλογία διαστάσεων κατά την αλλαγή μεγέθους.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`position_locked`](/slides/python-net/el/aspose.slides/graphicalobjectlock/position_locked/) | Καθορίζει αν η μετακίνηση αυτού του σχήματος απαγορεύεται.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`size_locked`](/slides/python-net/el/aspose.slides/graphicalobjectlock/size_locked/) | Καθορίζει αν η αλλαγή μεγέθους αυτού του σχήματος απαγορεύεται.<br/>            Ανάγνωση/εγγραφή **bool**. |
