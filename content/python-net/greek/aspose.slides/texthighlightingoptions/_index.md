## TextHighlightingOptions κλάση

Αντιπροσωπεύει επιλογές που μπορούν να χρησιμοποιηθούν για την επισήμανση κειμένου σε πλαίσιο κειμένου.

Ο τύπος TextHighlightingOptions εκθέτει τα παρακάτω μέλη:

## Κατασκευαστές

| Κατασκευαστής | Περιγραφή |
| :- | :- |
| [`__init__(self)`](/slides/python-net/el/aspose.slides/texthighlightingoptions/__init__/#) | Δημιουργεί νέες προεπιλεγμένες επιλογές επισήμανσης κειμένου. |

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`case_sensitive`](/slides/python-net/el/aspose.slides/texthighlightingoptions/case_sensitive/) | Ορίστε true για να χρησιμοποιήσετε αναζήτηση με διάκριση πεζών-κεφαλαίων, false - διαφορετικά.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`whole_words_only`](/slides/python-net/el/aspose.slides/texthighlightingoptions/whole_words_only/) | Ορίστε true για να ταιριάζει μόνο με ολόκληρες λέξεις, false - διαφορετικά.<br/>            Ανάγνωση/εγγραφή **bool**. |
