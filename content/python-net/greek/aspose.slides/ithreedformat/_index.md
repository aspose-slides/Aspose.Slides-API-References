## IThreeDFormat κλάση

Αντιπροσωπεύει ιδιότητες 3-Δ.

Ο τύπος IThreeDFormat εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`contour_width`](/slides/python-net/el/aspose.slides/ithreedformat/contour_width/) | Επιστρέφει ή ορίζει το πλάτος ενός 3Δ περιγράμματος.<br/>Ανάγνωση/εγγραφή **float**. |
| [`extrusion_height`](/slides/python-net/el/aspose.slides/ithreedformat/extrusion_height/) | Επιστρέφει ή ορίζει το ύψος ενός εφέ εξώθησης.<br/>Ανάγνωση/εγγραφή **float**. |
| [`depth`](/slides/python-net/el/aspose.slides/ithreedformat/depth/) | Επιστρέφει ή ορίζει το βάθος ενός 3Δ σχήματος.<br/>Ανάγνωση/εγγραφή **float**. |
| [`bevel_top`](/slides/python-net/el/aspose.slides/ithreedformat/bevel_top/) | Επιστρέφει ή ορίζει τον τύπο μιας άνω 3Δ λοξότητας.<br/>Μόνο για ανάγνωση [`IShapeBevel`](/slides/python-net/el/aspose.slides/ishapebevel). |
| [`bevel_bottom`](/slides/python-net/el/aspose.slides/ithreedformat/bevel_bottom/) | Επιστρέφει ή ορίζει τον τύπο μιας κάτω 3Δ λοξότητας.<br/>Μόνο για ανάγνωση [`IShapeBevel`](/slides/python-net/el/aspose.slides/ishapebevel). |
| [`contour_color`](/slides/python-net/el/aspose.slides/ithreedformat/contour_color/) | Επιστρέφει ή ορίζει το χρώμα ενός περιγράμματος.<br/>Μόνο για ανάγνωση [`IColorFormat`](/slides/python-net/el/aspose.slides/icolorformat). |
| [`extrusion_color`](/slides/python-net/el/aspose.slides/ithreedformat/extrusion_color/) | Επιστρέφει ή ορίζει το χρώμα μιας εξώθησης.<br/>Μόνο για ανάγνωση [`IColorFormat`](/slides/python-net/el/aspose.slides/icolorformat). |
| [`camera`](/slides/python-net/el/aspose.slides/ithreedformat/camera/) | Επιστρέφει ή ορίζει τις ρυθμίσεις μιας κάμερας.<br/>Μόνο για ανάγνωση [`ICamera`](/slides/python-net/el/aspose.slides/icamera). |
| [`light_rig`](/slides/python-net/el/aspose.slides/ithreedformat/light_rig/) | Επιστρέφει ή ορίζει τον τύπο ενός φωτός.<br/>Μόνο για ανάγνωση [`ILightRig`](/slides/python-net/el/aspose.slides/ilightrig). |
| [`material`](/slides/python-net/el/aspose.slides/ithreedformat/material/) | Επιστρέφει ή ορίζει τον τύπο ενός υλικού.<br/>Ανάγνωση/εγγραφή [`MaterialPresetType`](/slides/python-net/el/aspose.slides/materialpresettype). |
