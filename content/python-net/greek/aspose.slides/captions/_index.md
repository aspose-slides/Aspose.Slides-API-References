## Captions κλάση

Αντιπροσωπεύει τα κλειστά υπότιτλοι WebVTT.

Ο τύπος Captions εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`caption_id`](/slides/python-net/el/aspose.slides/captions/caption_id/) | Επιστρέφει το παγκοσμίως μοναδικό αναγνωριστικό (GUID) των κλειστών υποτίτλων.<br/>            Μόνο για ανάγνωση **System.Guid**. |
| [`label`](/slides/python-net/el/aspose.slides/captions/label/) | Επιστρέφει ή ορίζει την ετικέτα των κλειστών υποτίτλων.<br/>            Ανάγνωση/εγγραφή **str**. |
| [`binary_data`](/slides/python-net/el/aspose.slides/captions/binary_data/) | Επιστρέφει τα δυαδικά δεδομένα των κλειστών υποτίτλων.<br/>            Μόνο για ανάγνωση **int**[]. |
| [`data_as_string`](/slides/python-net/el/aspose.slides/captions/data_as_string/) | Επιστρέφει τα δεδομένα των κλειστών υποτίτλων ως συμβολοσειρά κωδικοποιημένη σε UTF-8<br/>            Μόνο για ανάγνωση **str**. |
