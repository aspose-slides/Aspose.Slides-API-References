## FontStyleType απαρίθμηση

Ορίζει στυλ μορφοποίησης που μπορούν να εφαρμοστούν σε κείμενο.

Ο τύπος FontStyleType εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| REGULAR | Τυπικό κείμενο. |
| BOLD | Έντονο κείμενο. |
| ITALIC | Πλάγιο κείμενο. |
| UNDERLINE | Υπόγραμμο κείμενο. |
| STRIKEOUT | Κείμενο διαγραμμένο με οριζόντια γραμμή. |
