## IAudio κλάση

Αντιπροσωπεύει ένα ενσωματωμένο αρχείο ήχου.

Ο τύπος IAudio εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`content_type`](/slides/python-net/el/aspose.slides/iaudio/content_type/) | Επιστρέφει έναν τύπο MIME ενός ήχου, κωδικοποιημένο σε [`IAudio.binary_data`](/slides/python-net/el/aspose.slides/iaudio/binary_data).<br/>            Μόνο για ανάγνωση **str**. |
| [`binary_data`](/slides/python-net/el/aspose.slides/iaudio/binary_data/) | Επιστρέφει το αντίγραφο των δεδομένων ενός ήχου. Σε περίπτωση μεγάλης ποσότητας δεδομένων, εξετάστε <br/>            τη χρήση της μεθόδου [`IAudio.get_stream`](/slides/python-net/el/aspose.slides/iaudio/get_stream) για να αποτρέψετε το περιττό φόρτωμα των δεδομένων του ήχου<br/>            στη μνήμη ή ακόμη και OutOfMemoryException.<br/>            Μόνο για ανάγνωση **int**[]. |

## Μεθόδοι

| Μέθοδος | Περιγραφή |
| :- | :- |
| [`get_stream(self)`](/slides/python-net/el/aspose.slides/iaudio/get_stream/#) | Επιστρέφει Stream stream για ανάγνωση.<br/>            Χρησιμοποιήστε 'using' ή κλείστε τη ροή μετά τη χρήση. |
