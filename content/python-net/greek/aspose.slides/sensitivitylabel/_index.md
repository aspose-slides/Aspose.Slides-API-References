## SensitivityLabel κλάση

Αντιπροσωπεύει την ετικέτα ευαισθησίας από το Microsoft Purview Information Protection.

Ο τύπος SensitivityLabel εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`id`](/slides/python-net/el/aspose.slides/sensitivitylabel/id/) | Επιστρέφει ή ορίζει το αναγνωριστικό της ετικέτας ευαισθησίας.<br/>            Ανάγνωση/εγγραφή **str**. |
| [`site_id`](/slides/python-net/el/aspose.slides/sensitivitylabel/site_id/) | Επιστρέφει ή ορίζει το αναγνωριστικό του ιστότοπου Azure Active Directory (Azure AD) <br/>            που αντιστοιχεί στην πολιτική ετικέτας ευαισθησίας που περιγράφει την ετικέτα ευαισθησίας.<br/>            Ανάγνωση/εγγραφή **System.Guid**. |
| [`is_enabled`](/slides/python-net/el/aspose.slides/sensitivitylabel/is_enabled/) | Δείχνει εάν η ετικέτα ευαισθησίας είναι ενεργοποιημένη. |
| [`is_removed`](/slides/python-net/el/aspose.slides/sensitivitylabel/is_removed/) | Δείχνει εάν η ετικέτα ευαισθησίας έχει αφαιρεθεί. |
| [`assignment_method_type`](/slides/python-net/el/aspose.slides/sensitivitylabel/assignment_method_type/) | Επιστρέφει ή ορίζει τη μέθοδο εκχώρησης για την ετικέτα ευαισθησίας.<br/>            Ανάγνωση/εγγραφή [`SensitivityLabelAssignmentType`](/slides/python-net/el/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/el/aspose.slides/sensitivitylabel/content_mark_types/) | Επιστρέφει τη λίστα των τύπων σήμανσης περιεχομένου που πρέπει να εφαρμοστούν σε ένα αρχείο. |
