## SlideLayoutType απαρίθμηση

Αναπαριστά τον τύπο διάταξης διαφάνειας.

Ο τύπος SlideLayoutType εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| CUSTOM | Προσαρμοσμένο |
| TITLE | Τίτλος |
| TEXT | Κείμενο |
| TWO_COLUMN_TEXT | Κείμενο δύο στηλών |
| TABLE | Πίνακας |
| TEXT_AND_CHART | Κείμενο και διάγραμμα |
| CHART_AND_TEXT | Διάγραμμα και κείμενο |
| DIAGRAM | Διάγραμμα |
| CHART | Διάγραμμα |
| TEXT_AND_CLIP_ART | Κείμενο και Clip Art |
| CLIP_ART_AND_TEXT | Clip Art και κείμενο |
| TITLE_ONLY | Μόνο τίτλος |
| BLANK | Κενό |
| TEXT_AND_OBJECT | Κείμενο και αντικείμενο |
| OBJECT_AND_TEXT | Αντικείμενο και κείμενο |
| OBJECT | Αντικείμενο |
| TITLE_AND_OBJECT | Τίτλος και αντικείμενο |
| TEXT_AND_MEDIA | Κείμενο και πολυμέσα |
| MEDIA_AND_TEXT | Πολυμέσα και κείμενο |
| OBJECT_OVER_TEXT | Αντικείμενο πάνω από κείμενο |
| TEXT_OVER_OBJECT | Κείμενο πάνω από αντικείμενο |
| TEXT_AND_TWO_OBJECTS | Κείμενο και δύο αντικείμενα |
| TWO_OBJECTS_AND_TEXT | Δύο αντικείμενα και κείμενο |
| TWO_OBJECTS_OVER_TEXT | Δύο αντικείμενα πάνω από κείμενο |
| FOUR_OBJECTS | Τέσσερα αντικείμενα |
| VERTICAL_TEXT | Κατακόρυφο κείμενο |
| CLIP_ART_AND_VERTICAL_TEXT | Clip Art και κατακόρυφο κείμενο |
| VERTICAL_TITLE_AND_TEXT | Κατακόρυφος τίτλος και κείμενο |
| VERTICAL_TITLE_AND_TEXT_OVER_CHART | Κατακόρυφος τίτλος και κείμενο πάνω από διάγραμμα |
| TWO_OBJECTS | Δύο αντικείμενα |
| OBJECT_AND_TWO_OBJECT | Αντικείμενο και δύο αντικείμενα |
| TWO_OBJECTS_AND_OBJECT | Δύο αντικείμενα και αντικείμενο |
| SECTION_HEADER | Κεφαλίδα ενότητας |
| TWO_TEXT_AND_TWO_OBJECTS | Δύο κείμενα και δύο αντικείμενα |
| TITLE_OBJECT_AND_CAPTION | Τίτλος, αντικείμενο και λεζάντα |
| PICTURE_AND_CAPTION | Εικόνα και λεζάντα |
