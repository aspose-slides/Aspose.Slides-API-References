## Απαρίθμηση TextAlignment

Αντιπροσωπεύει διαφορετικά στιλ στοίχισης κειμένου.

Ο τύπος TextAlignment εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδία | Περιγραφή |
| :- | :- |
| NOT_DEFINED | Προεπιλεγμένη στοίχιση. |
| LEFT | Αριστερή στοίχιση. |
| CENTER | Κεντρική στοίχιση. |
| RIGHT | Δεξιά στοίχιση. |
| JUSTIFY | Στοίχιση πλήρους. |
| JUSTIFY_LOW | Στοίχιση Kashida χαμηλή. |
| DISTRIBUTED | Κατανεμημένη στοίχιση. |
