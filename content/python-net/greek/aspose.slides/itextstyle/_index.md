## ITextStyle κλάση

Ιδιότητες μορφοποίησης στυλ κειμένου.

Ο τύπος ITextStyle εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Property | Description |
| :- | :- |
| [`default_paragraph_format`](/slides/python-net/el/aspose.slides/itextstyle/default_paragraph_format/) | Προεπιλεγμένες ιδιότητες παραγράφου.<br/>            Μόνο για ανάγνωση [`IParagraphFormat`](/slides/python-net/el/aspose.slides/iparagraphformat). |

## Μέθοδοι

| Method | Description |
| :- | :- |
| [`get_level(self, index)`](/slides/python-net/el/aspose.slides/itextstyle/get_level/#int) | Εάν υπάρχει επίπεδο στυλ, το επιστρέφει, διαφορετικά επιστρέφει None. |
| [`get_effective(self)`](/slides/python-net/el/aspose.slides/itextstyle/get_effective/#) | Λαμβάνει τα αποτελεσματικά δεδομένα μορφοποίησης στυλ κειμένου με την κληρονόμηση εφαρμοσμένη. |
