## get_script_font(self, script) {#str}
Αποκτά το όνομα της γραμματοσειράς που σχετίζεται με μια συγκεκριμένη ετικέτα script από το θέμα της παρουσίασης.

### Επιστροφή

Το όνομα της γραμματοσειράς που χρησιμοποιείται για το συγκεκριμένο script, ή `None` αν το script δεν είναι ορισμένο.



```python
def get_script_font(self, script):
    ...
```


| Παράμετρος | Τύπος | Περιγραφή |
| :- | :- | :- |
| script | **str** | Ο κώδικας script BCP-47 (π.χ., "Latn", "Cyrl", "Jpan") που χρησιμοποιείται για την αναγνώριση ενός συστήματος γραφής. |
