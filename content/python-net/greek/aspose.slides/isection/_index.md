## ISection κλάση

Αντιπροσωπεύει την ενότητα των διαφανειών.

Ο τύπος ISection εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`name`](/slides/python-net/el/aspose.slides/isection/name/) | Όνομα της ενότητας. |
| [`section_id`](/slides/python-net/el/aspose.slides/isection/section_id/) | Αναγνωριστικό ενότητας. |
| [`started_from_slide`](/slides/python-net/el/aspose.slides/isection/started_from_slide/) | Επιστρέφει τη πρώτη διαφάνεια της ενότητας. |
