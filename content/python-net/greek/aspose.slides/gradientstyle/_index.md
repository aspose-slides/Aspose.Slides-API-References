## GradientStyle απαρίθμηση

Αντιπροσωπεύει τα διαθέσιμα στυλ διαβάθμισης.

Ο τύπος GradientStyle εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| DEFAULT | Το προεπιλεγμένο στυλ διαβάθμισης. |
| POWER_POINT_UI | Το στυλ διαβάθμισης όπως εμφανίζεται στη διεπαφή χρήστη του PowerPoint. |
