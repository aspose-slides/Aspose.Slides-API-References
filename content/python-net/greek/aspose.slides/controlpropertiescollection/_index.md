## ControlPropertiesCollection κλάση

Μια συλλογή ιδιοτήτων AcitveX.

Ο τύπος ControlPropertiesCollection εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`names_of_properties`](/slides/python-net/el/aspose.slides/controlpropertiescollection/names_of_properties/) | Επιστρέφει τη συλλογή των ονομάτων των ιδιοτήτων.<br/>            Μόνο για ανάγνωση **list**. |
| [`count`](/slides/python-net/el/aspose.slides/controlpropertiescollection/count/) | Επιστρέφει έναν αριθμό ιδιοτήτων στη συλλογή.<br/>            Μόνο για ανάγνωση **int**. |

## Μέθοδοι

| Μέθοδος | Περιγραφή |
| :- | :- |
| [`add(self, name, value)`](/slides/python-net/el/aspose.slides/controlpropertiescollection/add/#str-str) | Προσθέτει μια ιδιότητα στη συλλογή. |
| [`remove(self, name)`](/slides/python-net/el/aspose.slides/controlpropertiescollection/remove/#str) | Αφαιρεί μια ιδιότητα με το καθορισμένο όνομα. |
| [`clear(self)`](/slides/python-net/el/aspose.slides/controlpropertiescollection/clear/#) | Αφαιρεί όλες τις ιδιότητες. |
