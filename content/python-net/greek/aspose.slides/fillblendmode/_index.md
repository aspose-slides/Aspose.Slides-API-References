## FillBlendMode απαρίθμηση

Καθορίζει τη λειτουργία ανάμειξης.

Ο τύπος FillBlendMode εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| DARKEN | Λειτουργία ανάμειξης σκίασης. |
| LIGHTEN | Λειτουργία ανάμειξης φωτισμού. |
| MULTIPLY | Λειτουργία ανάμειξης πολλαπλασιασμού. |
| OVERLAY | Λειτουργία ανάμειξης επικάλυψης. |
| SCREEN | Λειτουργία ανάμειξης οθόνης. |
