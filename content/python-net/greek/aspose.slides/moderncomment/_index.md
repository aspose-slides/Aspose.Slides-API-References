## ModernComment κλάση

Αναπαριστά ένα σχόλιο σε μια διαφάνεια.

**Κληρονομικότητα:**[`ModernComment`](/slides/python-net/el/aspose.slides/moderncomment) → [`Comment`](/slides/python-net/el/aspose.slides/comment)

Ο τύπος ModernComment εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`text`](/slides/python-net/el/aspose.slides/moderncomment/text/) | Επιστρέφει ή ορίζει το απλό κείμενο μιας διαφάνειας σχολίου.<br/>            Ανάγνωση/εγγραφή **str**. |
| [`created_time`](/slides/python-net/el/aspose.slides/moderncomment/created_time/) | Επιστρέφει ή ορίζει την ώρα δημιουργίας ενός σχολίου.<br/>            Ο ορισμός αυτής της ιδιότητας σε **System.DateTime** σημαίνει ότι δεν έχει οριστεί ώρα σχολίου.<br/>            Ανάγνωση/εγγραφή **System.DateTime**. |
| [`slide`](/slides/python-net/el/aspose.slides/moderncomment/slide/) | Επιστρέφει ή ορίζει τη γονική διαφάνεια ενός σχολίου.<br/>            Μόνο ανάγνωση [`ISlide`](/slides/python-net/el/aspose.slides/islide). |
| [`author`](/slides/python-net/el/aspose.slides/moderncomment/author/) | Επιστρέφει τον συγγραφέα ενός σχολίου.<br/>            Μόνο ανάγνωση [`ICommentAuthor`](/slides/python-net/el/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/el/aspose.slides/moderncomment/position/) | Επιστρέφει ή ορίζει τη θέση ενός σχολίου σε μια διαφάνεια.<br/>            Ανάγνωση/εγγραφή **aspose.slides.PointF**. |
| [`parent_comment`](/slides/python-net/el/aspose.slides/moderncomment/parent_comment/) | Αποκτά ή ορίζει γονικό σχόλιο.<br/>            Ανάγνωση/εγγραφή [`IComment`](/slides/python-net/el/aspose.slides/icomment). |
| [`shape`](/slides/python-net/el/aspose.slides/moderncomment/shape/) | Επιστρέφει ένα σχήμα συσχετισμένο με το σχόλιο.<br/>            Μόνο ανάγνωση [`IShape`](/slides/python-net/el/aspose.slides/ishape). |
| [`text_selection_start`](/slides/python-net/el/aspose.slides/moderncomment/text_selection_start/) | Αποκτά ή ορίζει τη θέση έναρξης της επιλογής κειμένου στο πλαίσιο κειμένου εάν το σχόλιο είναι συσχετισμένο με AutoShape.<br/>            Ανάγνωση/εγγραφή **int**. |
| [`text_selection_length`](/slides/python-net/el/aspose.slides/moderncomment/text_selection_length/) | Αποκτά ή ορίζει το μήκος της επιλογής κειμένου στο πλαίσιο κειμένου εάν το σχόλιο είναι συσχετισμένο με AutoShape.<br/>            Ανάγνωση/εγγραφή **int**. |
| [`status`](/slides/python-net/el/aspose.slides/moderncomment/status/) | Αποκτά ή ορίζει την κατάσταση του σχολίου.<br/>            Ανάγνωση/εγγραφή [`ModernCommentStatus`](/slides/python-net/el/aspose.slides/moderncommentstatus). |
