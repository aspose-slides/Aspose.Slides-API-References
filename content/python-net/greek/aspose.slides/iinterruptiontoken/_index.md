## IInterruptionToken κλάση

Αυτή η κλάση αντιπροσωπεύει το διακριτικό που χρησιμοποιείται για την ένδειξη σε μακροχρόνιες εργασίες εάν ζητήθηκε διακοπή.

Ο τύπος IInterruptionToken εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`is_interruption_requested`](/slides/python-net/el/aspose.slides/iinterruptiontoken/is_interruption_requested/) | Επιστρέφει **bool**.true εάν η διακοπή ζητήθηκε. |

## Μέθοδοι

| Μέθοδος | Περιγραφή |
| :- | :- |
| [`throw_if_interruption_requested(self)`](/slides/python-net/el/aspose.slides/iinterruptiontoken/throw_if_interruption_requested/#) | Ρίχνει ένα OperationCanceledException εάν<br/>            ζητήθηκε διακοπή.<br/>            Ρίχνεται όταν ζητήθηκε διακοπή. |
