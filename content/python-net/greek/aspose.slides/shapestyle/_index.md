## ShapeStyle κλάση

Αντιπροσωπεύει την αναφορά στυλ του σχήματος.

Ο τύπος ShapeStyle εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`line_color`](/slides/python-net/el/aspose.slides/shapestyle/line_color/) | Επιστρέφει το χρώμα περιγράμματος ενός σχήματος.<br/>            Μόνο για ανάγνωση [`IColorFormat`](/slides/python-net/el/aspose.slides/icolorformat). |
| [`line_style_index`](/slides/python-net/el/aspose.slides/shapestyle/line_style_index/) | Επιστρέφει ή ορίζει τον δείκτη στήλης της γραμμής σε έναν πίνακα στυλ.<br/>            Ανάγνωση/εγγραφή **int**. |
| [`fill_color`](/slides/python-net/el/aspose.slides/shapestyle/fill_color/) | Επιστρέφει το χρώμα γεμίσματος ενός σχήματος.<br/>            Μόνο για ανάγνωση [`IColorFormat`](/slides/python-net/el/aspose.slides/icolorformat). |
| [`fill_style_index`](/slides/python-net/el/aspose.slides/shapestyle/fill_style_index/) | Επιστρέφει ή ορίζει τον δείκτη στήλης γεμίσματος του σχήματος σε πίνακες στυλ.<br/>            0 σημαίνει χωρίς γέμισμα,<br/>            θετική τιμή - δείκτης στα στυλ γεμίσματος του θέματος,<br/>            αρνητική τιμή - δείκτης στα στυλ φόντου του θέματος.<br/>            Ανάγνωση/εγγραφή **int**. |
| [`effect_color`](/slides/python-net/el/aspose.slides/shapestyle/effect_color/) | Επιστρέφει το χρώμα εφέ ενός σχήματος.<br/>            Μόνο για ανάγνωση [`IColorFormat`](/slides/python-net/el/aspose.slides/icolorformat). |
| [`effect_style_index`](/slides/python-net/el/aspose.slides/shapestyle/effect_style_index/) | Επιστρέφει ή ορίζει τον δείκτη στήλης εφέ του σχήματος σε έναν πίνακα στυλ.<br/>            Ανάγνωση/εγγραφή **int**. |
| [`font_color`](/slides/python-net/el/aspose.slides/shapestyle/font_color/) | Επιστρέφει το χρώμα γραμματοσειράς του σχήματος.<br/>            Μόνο για ανάγνωση [`IColorFormat`](/slides/python-net/el/aspose.slides/icolorformat). |
| [`font_collection_index`](/slides/python-net/el/aspose.slides/shapestyle/font_collection_index/) | Επιστρέφει ή ορίζει τον δείκτη γραμματοσειράς του σχήματος σε μια συλλογή γραμματοσειρών.<br/>            Ανάγνωση/εγγραφή [`FontCollectionIndex`](/slides/python-net/el/aspose.slides/fontcollectionindex). |
