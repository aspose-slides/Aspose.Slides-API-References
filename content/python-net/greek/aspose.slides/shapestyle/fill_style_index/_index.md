## fill_style_index ιδιότητα
Επιστρέφει ή ορίζει τον δείκτη στήλης γεμίσματος του σχήματος στους πίνακες στυλ.
            0 σημαίνει χωρίς γέμισμα,
            θετική τιμή - δείκτης στα στυλ γεμίσματος του θέματος,
            αρνητική τιμή - δείκτης στα στυλ φόντου του θέματος.
            Ανάγνωση/εγγραφή **int**.
