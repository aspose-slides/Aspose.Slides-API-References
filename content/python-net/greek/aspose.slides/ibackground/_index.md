## IBackground κλάση

Αναπαριστά το παρασκήνιο μιας διαφάνειας.

Ο τύπος IBackground εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`type`](/slides/python-net/el/aspose.slides/ibackground/type/) | Επιστρέφει έναν τύπο γεμίσματος παρασκηνίου.<br/>            Ανάγνωση/εγγραφή [`BackgroundType`](/slides/python-net/el/aspose.slides/backgroundtype). |
| [`fill_format`](/slides/python-net/el/aspose.slides/ibackground/fill_format/) | Επιστρέφει ένα FillFormat για γέμισμα BackgroundType.OwnBackground.<br/>            Μόνο για ανάγνωση [`IFillFormat`](/slides/python-net/el/aspose.slides/ifillformat). |
| [`effect_format`](/slides/python-net/el/aspose.slides/ibackground/effect_format/) | Επιστρέφει ένα EffectFormat για γέμισμα BackgroundType.OwnBackground.<br/>            Μόνο για ανάγνωση [`IEffectFormat`](/slides/python-net/el/aspose.slides/ieffectformat). |
| [`style_color`](/slides/python-net/el/aspose.slides/ibackground/style_color/) | Επιστρέφει ένα ColorFormat για γέμισμα BackgroundType.Themed.<br/>            Μόνο για ανάγνωση [`IColorFormat`](/slides/python-net/el/aspose.slides/icolorformat). |
| [`style_index`](/slides/python-net/el/aspose.slides/ibackground/style_index/) | Επιστρέφει έναν δείκτη του γεμίσματος BackgroundType.Themed στη συλλογή θεμάτων παρασκηνίου.<br/>            0 σημαίνει χωρίς γέμισμα.<br/>            1..999 - δείκτης.<br/>            Ανάγνωση/εγγραφή **int**. |
