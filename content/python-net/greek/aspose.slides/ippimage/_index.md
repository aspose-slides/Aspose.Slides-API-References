## IPPImage κλάση

Αντιπροσωπεύει μια εικόνα σε μια παρουσίαση.

Ο τύπος IPPImage εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`binary_data`](/slides/python-net/el/aspose.slides/ippimage/binary_data/) | Επιστρέφει ένα αντίγραφο των δεδομένων μιας εικόνας.<br/>            Μόνο για ανάγνωση **int**[]. |
| [`image`](/slides/python-net/el/aspose.slides/ippimage/image/) | Επιστρέφει ένα αντίγραφο μιας εικόνας.<br/>            Μόνο για ανάγνωση [`IPPImage.image`](/slides/python-net/el/aspose.slides/ippimage/image). |
| [`svg_image`](/slides/python-net/el/aspose.slides/ippimage/svg_image/) | Επιστρέφει ή ορίζει το αντικείμενο ISvgImage [`ISvgImage`](/slides/python-net/el/aspose.slides/isvgimage) |
| [`content_type`](/slides/python-net/el/aspose.slides/ippimage/content_type/) | Επιστρέφει έναν τύπο MIME μιας εικόνας, κωδικοποιημένο σε [`IPPImage.binary_data`](/slides/python-net/el/aspose.slides/ippimage/binary_data).<br/>            Μόνο για ανάγνωση **str**. |
| [`width`](/slides/python-net/el/aspose.slides/ippimage/width/) | Επιστρέφει το πλάτος μιας εικόνας.<br/>            Μόνο για ανάγνωση **int**. |
| [`height`](/slides/python-net/el/aspose.slides/ippimage/height/) | Επιστρέφει το ύψος μιας εικόνας.<br/>            Μόνο για ανάγνωση **int**. |
| [`x`](/slides/python-net/el/aspose.slides/ippimage/x/) | Επιστρέφει τη μετατόπιση X μιας εικόνας.<br/>            Μόνο για ανάγνωση **int**. |
| [`y`](/slides/python-net/el/aspose.slides/ippimage/y/) | Επιστρέφει τη μετατόπιση Y μιας εικόνας.<br/>            Μόνο για ανάγνωση **int**. |
