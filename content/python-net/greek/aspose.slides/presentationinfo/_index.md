## PresentationInfo κλάση

Πληροφορίες για το αρχείο παρουσίασης

Ο τύπος PresentationInfo εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`is_encrypted`](/slides/python-net/el/aspose.slides/presentationinfo/is_encrypted/) | Επιστρέφει True εάν η συνδεδεμένη παρουσίαση είναι κρυπτογραφημένη, διαφορετικά False.<br/>            Μόνο για ανάγνωση **bool**. |
| [`is_password_protected`](/slides/python-net/el/aspose.slides/presentationinfo/is_password_protected/) | Επιστρέφει μια τιμή που δείχνει εάν η συνδεδεμένη παρουσίαση είναι προστατευμένη με κωδικό πρόσβασης για άνοιγμα. |
| [`is_write_protected`](/slides/python-net/el/aspose.slides/presentationinfo/is_write_protected/) | Επιστρέφει μια τιμή που δείχνει εάν η συνδεδεμένη παρουσίαση είναι προστατευμένη για εγγραφή. |
| [`load_format`](/slides/python-net/el/aspose.slides/presentationinfo/load_format/) | Επιστρέφει τη μορφή της συνδεδεμένης παρουσίασης.<br/>            Μόνο για ανάγνωση [`LoadFormat`](/slides/python-net/el/aspose.slides/loadformat). |

## Μέθοδοι

| Μέθοδος | Περιγραφή |

| [`write_binded_presentation(self, file)`](/slides/python-net/el/aspose.slides/presentationinfo/write_binded_presentation/#str) | Γράφει τη συνδεδεμένη παρουσίαση σε αρχείο. |
| [`check_password(self, password)`](/slides/python-net/el/aspose.slides/presentationinfo/check_password/#str) | Ελέγχει εάν ένας κωδικός πρόσβασης είναι σωστός για μια παρουσίαση προστατευμένη με κωδικό ανοίγματος. |
| [`check_write_protection(self, password)`](/slides/python-net/el/aspose.slides/presentationinfo/check_write_protection/#str) | Ελέγχει εάν ο κωδικός πρόσβασης για τροποποίηση είναι σωστός για μια παρουσίαση προστατευμένη από εγγραφή. |
