### Επιστρέφει

Το όνομα της προσαρμοσμένης ιδιότητας στο καθορισμένο δείκτη.



```python
def get_custom_property_name(self, index):
    ...
```


| Παράμετρος | Τύπος | Περιγραφή |
| :- | :- | :- |
| index | **int** | Ο δείκτης που αρχίζει από το μηδέν μιας προσαρμοσμένης ιδιότητας που θα ληφθεί. |
