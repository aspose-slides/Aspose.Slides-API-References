## GradientDirection απαρίθμηση

Αντιπροσωπεύει το στυλ διαβάθμισης.

Ο τύπος GradientDirection εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| NOT_DEFINED | Δεν ορίστηκε |
| FROM_CORNER1 | Από την πάνω αριστερή γωνία |
| FROM_CORNER2 | Από την πάνω δεξιά γωνία |
| FROM_CORNER3 | Από την κάτω αριστερή γωνία |
| FROM_CORNER4 | Από την κάτω δεξιά γωνία |
| FROM_CENTER | Από το κέντρο |
