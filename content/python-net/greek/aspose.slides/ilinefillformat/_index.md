## ILineFillFormat κλάση

Αναπαριστά τις ιδιότητες για το γέμισμα γραμμών.

Ο τύπος ILineFillFormat εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`fill_type`](/slides/python-net/el/aspose.slides/ilinefillformat/fill_type/) | Επιστρέφει ή ορίζει τον τύπο γεμίσματος.<br/>            Ανάγνωση/εγγραφή [`FillType`](/slides/python-net/el/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/el/aspose.slides/ilinefillformat/solid_fill_color/) | Επιστρέφει το χρώμα ενός συμπαγούς γεμίσματος.<br/>            Μόνο για ανάγνωση [`IColorFormat`](/slides/python-net/el/aspose.slides/icolorformat). |
| [`gradient_format`](/slides/python-net/el/aspose.slides/ilinefillformat/gradient_format/) | Επιστρέφει τη μορφή διαβάθμισης γεμίσματος.<br/>            Μόνο για ανάγνωση [`IGradientFormat`](/slides/python-net/el/aspose.slides/igradientformat). |
| [`pattern_format`](/slides/python-net/el/aspose.slides/ilinefillformat/pattern_format/) | Επιστρέφει τη μορφή μοτίβου γεμίσματος.<br/>            Μόνο για ανάγνωση [`IPatternFormat`](/slides/python-net/el/aspose.slides/ipatternformat). |
| [`rotate_with_shape`](/slides/python-net/el/aspose.slides/ilinefillformat/rotate_with_shape/) | Καθορίζει αν το γέμισμα πρέπει να περιστρέφεται με το σχήμα.<br/>            Ανάγνωση/εγγραφή [`NullableBool`](/slides/python-net/el/aspose.slides/nullablebool). |
