## HyperlinkManager κλάση

Παρέχει διαχείριση υπερσυνδέσμων (προσθήκη, αφαίρεση).

Ο τύπος HyperlinkManager εκθέτει τα παρακάτω μέλη:

| Μέθοδος | Περιγραφή |
| :- | :- |
| [`set_external_hyperlink_click(self, url)`](/slides/python-net/el/aspose.slides/hyperlinkmanager/set_external_hyperlink_click/#str) | Ορίζει εξωτερικό υπερσύνδεσμο στο κλικ. |
| [`set_internal_hyperlink_click(self, target_slide)`](/slides/python-net/el/aspose.slides/hyperlinkmanager/set_internal_hyperlink_click/#islide) | Ορίζει εσωτερικό υπερσύνδεσμο στο κλικ. |
