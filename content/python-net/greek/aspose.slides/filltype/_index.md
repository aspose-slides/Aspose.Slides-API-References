## Απαρίθμηση FillType

Καθορίζει τον εσωτερικό τύπο γεμίσματος διαφόρων οπτικών αντικειμένων.

Ο τύπος FillType εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδία | Περιγραφή |
| :- | :- |
| NOT_DEFINED | Ο τύπος γεμίσματος δεν έχει οριστεί. |
| NO_FILL | Δεν εφαρμόστηκε γέμισμα. |
| SOLID | Γεμισμένο με μονήχρωμο χρώμα. |
| GRADIENT | Το γέμισμα είναι διαβάθμιση. |
| PATTERN | Χρησιμοποιείται επαναλαμβανόμενο μοτίβο για το γέμισμα του αντικειμένου. |
| PICTURE | Μία ενιαία εικόνα χρησιμοποιείται για το γέμισμα του αντικειμένου. |
| GROUP | Το οπτικό αντικείμενο κληρονομεί τις ιδιότητες γεμίσματος από την ομάδα. |
