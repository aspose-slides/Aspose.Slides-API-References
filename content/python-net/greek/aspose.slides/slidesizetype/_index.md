## SlideSizeType απάριθμηση

Αντιπροσωπεύει την προκαθορισμένη διαστάση διαφάνειας.

Ο τύπος SlideSizeType εμφανίζει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| ON_SCREEN | Σε οθόνη 4x3 |
| LETTER_PAPER | Γράμμα |
| A4_PAPER | A4 |
| SLIDE_35MM | Διαφάνεια 35mm |
| OVERHEAD | Προβολή |
| BANNER | Μπάνερ |
| CUSTOM | Προσαρμοσμένο μέγεθος |
| LEDGER | Ledger |
| A3_PAPER | A3 |
| B4_ISO_PAPER | B4 ISO |
| B5_ISO_PAPER | B5 ISO |
| B4_JIS_PAPER | B4 JIS |
| B5_JIS_PAPER | B5 JIS |
| HAGAKI_CARD | Κάρτα Hagaki |
| ON_SCREEN_16X9 | Σε οθόνη 16x9 |
| ON_SCREEN_16X10 | Σε οθόνη 16x10 |
| WIDESCREEN | Πλατιά οθόνη |
