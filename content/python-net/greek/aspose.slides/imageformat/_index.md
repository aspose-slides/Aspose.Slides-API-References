## ImageFormat απαριθμητικό

Ο τύπος ImageFormat εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| MEMORY_BMP | Αντιπροσωπεύει τη μορφή ενός bitmap στη μνήμη. |
| BMP | Αντιπροσωπεύει τη μορφή εικόνας bitmap (BMP). |
| EMF | Αντιπροσωπεύει τη μορφή εικόνας βελτιωμένου metafile (EMF). |
| WMF | Αντιπροσωπεύει τη μορφή εικόνας Windows metafile (WMF). |
| GIF | Αντιπροσωπεύει τη μορφή εικόνας Graphics Interchange Format (GIF). |
| JPEG | Αντιπροσωπεύει τη μορφή εικόνας Joint Photographic Experts Group (JPEG). |
| PNG | Αντιπροσωπεύει τη μορφή εικόνας W3C Portable Network Graphics (PNG). |
| TIFF | Αντιπροσωπεύει τη μορφή εικόνας Tagged Image File Format (TIFF). |
| EXIF | Αντιπροσωπεύει τη μορφή Exchangeable Image File (Exif). |
| ICON | Αντιπροσωπεύει τη μορφή εικόνας Windows icon. |
