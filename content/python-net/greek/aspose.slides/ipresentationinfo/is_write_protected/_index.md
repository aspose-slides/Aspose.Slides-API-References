## is_write_protected ιδιότητα
Επιστρέφει μια τιμή που υποδεικνύει εάν μια δεσμευμένη παρουσίαση είναι προστατευμένη από γράψιμο.

### Σχόλια

Εάν η παρουσίαση είναι προστατευμένη με κωδικό πρόσβασης για άνοιγμα, η τιμή της ιδιότητας είναι ίση με NotDefined.
Δείτε [`NullableBool`](/slides/python-net/el/aspose.slides/nullablebool) απαρίθμηση.

@property
def is_write_protected(self):
    ...
