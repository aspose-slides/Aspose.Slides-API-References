## IColorOperation κλάση

Αναπαριστά διαφορετικές λειτουργίες χρώματος που χρησιμοποιούνται για μετασχηματισμούς χρώματος.

Ο τύπος IColorOperation εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Property | Description |
| :- | :- |
| [`operation_type`](/slides/python-net/el/aspose.slides/icoloroperation/operation_type/) | Επιστρέφει ή ορίζει τον τύπο μιας λειτουργίας.<br/>            Μόνο για ανάγνωση [`ColorTransformOperation`](/slides/python-net/el/aspose.slides/colortransformoperation). |
| [`parameter`](/slides/python-net/el/aspose.slides/icoloroperation/parameter/) | Επιστρέφει μια παράμετρο μιας λειτουργίας.<br/>            Μόνο για ανάγνωση **float**. |
