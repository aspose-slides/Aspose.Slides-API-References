## ιδιότητα περιστροφής
Returns or sets the number of degrees the specified shape is rotated around
            τον άξονα z. Μια θετική τιμή υποδεικνύει δεξιόστροφη περιστροφή· μια αρνητική τιμή
            υποδεικνύει αριστερόστροφη περιστροφή.
            Ανάγνωση/εγγραφή **float**.


### Σχόλια

Η επιστρεφόμενη τιμή είναι πάντα ορισμένη (δεν είναι float.NaN).
            Η τιμή που ορίζεται πρέπει να είναι ορισμένη (δεν είναι float.NaN). Μπορείτε να ορίσετε αόριστες τιμές για τις ιδιότητες της παρουσίασης RawFrame.
