## IPlaceholder κλάση

Αναπαριστά έναν placeholder σε μια διαφάνεια.

Ο τύπος IPlaceholder εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`orientation`](/slides/python-net/el/aspose.slides/iplaceholder/orientation/) | Λαμβάνει τον προσανατολισμό ενός placeholder.<br/>            Μόνο για ανάγνωση [`Orientation`](/slides/python-net/el/aspose.slides/orientation). |
| [`size`](/slides/python-net/el/aspose.slides/iplaceholder/size/) | Λαμβάνει το μέγεθος ενός placeholder.<br/>            Μόνο για ανάγνωση [`PlaceholderSize`](/slides/python-net/el/aspose.slides/placeholdersize). |
| [`type`](/slides/python-net/el/aspose.slides/iplaceholder/type/) | Λαμβάνει τον τύπο ενός placeholder.<br/>            Μόνο για ανάγνωση [`PlaceholderType`](/slides/python-net/el/aspose.slides/placeholdertype). |
| [`index`](/slides/python-net/el/aspose.slides/iplaceholder/index/) | Λαμβάνει το ευρετήριο ενός placeholder.<br/>            Μόνο για ανάγνωση **int**. |
