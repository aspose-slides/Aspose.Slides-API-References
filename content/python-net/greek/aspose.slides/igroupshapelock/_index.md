## IGroupShapeLock κλάση

Καθορίζει ποιες λειτουργίες είναι απενεργοποιημένες στη γονική GroupShape.

Ο τύπος IGroupShapeLock εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`grouping_locked`](/slides/python-net/el/aspose.slides/igroupshapelock/grouping_locked/) | Καθορίζει αν η προσθήκη αυτού του σχήματος σε μια ομάδα είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`ungrouping_locked`](/slides/python-net/el/aspose.slides/igroupshapelock/ungrouping_locked/) | Καθορίζει αν ο διαχωρισμός αυτού του groupshape είναι απαγορευμένος.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`select_locked`](/slides/python-net/el/aspose.slides/igroupshapelock/select_locked/) | Καθορίζει αν η επιλογή αυτού του σχήματος είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`rotation_locked`](/slides/python-net/el/aspose.slides/igroupshapelock/rotation_locked/) | Καθορίζει αν η αλλαγή της γωνίας περιστροφής αυτού του σχήματος είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/el/aspose.slides/igroupshapelock/aspect_ratio_locked/) | Καθορίζει αν το σχήμα πρέπει να διατηρεί την αναλογία διαστάσεων κατά την αλλαγή μεγέθους.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`position_locked`](/slides/python-net/el/aspose.slides/igroupshapelock/position_locked/) | Καθορίζει αν η μετακίνηση αυτού του σχήματος είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`size_locked`](/slides/python-net/el/aspose.slides/igroupshapelock/size_locked/) | Καθορίζει αν η αλλαγή μεγέθους αυτού του σχήματος είναι απαγορευμένη.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`no_locks`](/slides/python-net/el/aspose.slides/igroupshapelock/no_locks/) |  |
