## SlideShowSettings κλάση

Αντιπροσωπεύει τις ρυθμίσεις προβολής διαφανειών για την παρουσίαση.

Ο τύπος SlideShowSettings εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`slide_show_type`](/slides/python-net/el/aspose.slides/slideshowsettings/slide_show_type/) | Λαμβάνει ή ορίζει τον τύπο προβολής διαφανειών. Αναπαρίσταται από τους παρακάτω [`SlideShowSettings.slide_show_type`](/slides/python-net/el/aspose.slides/slideshowsettings/slide_show_type) προγόνους: [`BrowsedAtKiosk`](/slides/python-net/el/aspose.slides/browsedatkiosk), [`PresentedBySpeaker`](/slides/python-net/el/aspose.slides/presentedbyspeaker) και [`BrowsedByIndividual`](/slides/python-net/el/aspose.slides/browsedbyindividual) |
| [`loop`](/slides/python-net/el/aspose.slides/slideshowsettings/loop/) | Επανάληψη προβολής διαφανειών |
| [`show_narration`](/slides/python-net/el/aspose.slides/slideshowsettings/show_narration/) | Εμφάνιση αφήγησης στην προβολή διαφανειών |
| [`show_animation`](/slides/python-net/el/aspose.slides/slideshowsettings/show_animation/) | Εμφάνιση κίνησης στην προβολή διαφανειών |
| [`pen_color`](/slides/python-net/el/aspose.slides/slideshowsettings/pen_color/) | Χρώμα πένας για την προβολή διαφανειών |
| [`slides`](/slides/python-net/el/aspose.slides/slideshowsettings/slides/) | Εύρος διαφανειών |
| [`use_timings`](/el/slides/python-net/aspose.slides/slideshowsettings/use_timings/) | Χρήση χρονισμών στην προβολή διαφανειών |
| [`show_media_controls`](/slides/python-net/el/aspose.slides/slideshowsettings/show_media_controls/) | Εμφάνιση ελέγχων πολυμέσων |
