## IGradientFormatEffectiveData κλάση

Αμετάβλητο αντικείμενο που περιέχει αποτελεσματικές ιδιότητες γεμίσματος διαβάθμισης.

Ο τύπος IGradientFormatEffectiveData εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`tile_flip`](/slides/python-net/el/aspose.slides/igradientformateffectivedata/tile_flip/) | Επιστρέφει τη λειτουργία αναστροφής για μια διαβάθμιση.<br/>            Μόνο για ανάγνωση [`TileFlip`](/slides/python-net/el/aspose.slides/tileflip). |
| [`gradient_direction`](/slides/python-net/el/aspose.slides/igradientformateffectivedata/gradient_direction/) | Επιστρέφει το στυλ μιας διαβάθμισης.<br/>            Μόνο για ανάγνωση [`GradientDirection`](/slides/python-net/el/aspose.slides/gradientdirection). |
| [`linear_gradient_angle`](/slides/python-net/el/aspose.slides/igradientformateffectivedata/linear_gradient_angle/) | Επιστρέφει τη γωνία μιας διαβάθμισης.<br/>            Μόνο για ανάγνωση **float**. |
| [`linear_gradient_scaled`](/slides/python-net/el/aspose.slides/igradientformateffectivedata/linear_gradient_scaled/) | Καθορίζει αν μια διαβάθμιση κλιμακώνεται.<br/>            Μόνο για ανάγνωση **bool**. |
| [`gradient_shape`](/slides/python-net/el/aspose.slides/igradientformateffectivedata/gradient_shape/) | Επιστρέφει το σχήμα μιας διαβάθμισης.<br/>            Μόνο για ανάγνωση [`GradientShape`](/slides/python-net/el/aspose.slides/gradientshape). |
| [`gradient_stops`](/slides/python-net/el/aspose.slides/igradientformateffectivedata/gradient_stops/) | Επιστρέφει τη συλλογή των σημείων διαβάθμισης.<br/>            Μόνο για ανάγνωση [`IGradientStopCollectionEffectiveData`](/slides/python-net/el/aspose.slides/igradientstopcollectioneffectivedata). |


### Παρατηρήσεις

Αυτή η διεπαφή χρησιμοποιείται ως μέρος του [`IFillFormatEffectiveData`](/slides/python-net/el/aspose.slides/ifillformateffectivedata) και [`ILineFillFormatEffectiveData`](/slides/python-net/el/aspose.slides/ilinefillformateffectivedata).
