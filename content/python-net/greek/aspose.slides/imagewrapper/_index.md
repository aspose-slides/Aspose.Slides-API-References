## ImageWrapper κλάση

System.Drawing.Image πρόγραμμα περιτύλιξης για τη διεπαφή COM.

Ο τύπος ImageWrapper εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`image_source`](/slides/python-net/el/aspose.slides/imagewrapper/image_source/) | Λαμβάνει Image.<br/>Μόνο για ανάγνωση [`IImage`](/slides/python-net/el/aspose.slides/iimage). |
| [`size`](/slides/python-net/el/aspose.slides/imagewrapper/size/) | Λαμβάνει το πλάτος και το ύψος, σε εικονοστοιχεία, της Image.<br/>Μόνο για ανάγνωση [`ImageWrapper.size`](/slides/python-net/el/aspose.slides/imagewrapper/size). |

| Μέθοδος | Περιγραφή |
