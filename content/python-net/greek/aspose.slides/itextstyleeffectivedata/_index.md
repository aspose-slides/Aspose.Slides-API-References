## ITextStyleEffectiveData κλάση

Αμετάβλητο αντικείμενο που περιέχει τις αποτελεσματικές ιδιότητες του στυλ κειμένου.

Ο τύπος ITextStyleEffectiveData εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`default_paragraph_format`](/slides/python-net/el/aspose.slides/itextstyleeffectivedata/default_paragraph_format/) | Επιστρέφει τις αποτελεσματικές προεπιλεγμένες ιδιότητες παραγράφου.<br/>            Μόνο ανάγνωση [`IParagraphFormatEffectiveData`](/slides/python-net/el/aspose.slides/iparagraphformateffectivedata). |

## Μέθοδοι

| Μέθοδος | Περιγραφή |
| :- | :- |
| [`get_level(self, index)`](/slides/python-net/el/aspose.slides/itextstyleeffectivedata/get_level/#int) | Επιστρέφει το επίπεδο του αποτελεσματικού στυλ. |


### Σχόλια

Αυτή η διεπαφή χρησιμοποιείται μαζί με τη διεπαφή [`ITextStyle`](/slides/python-net/el/aspose.slides/itextstyle) για να επιστρέφει τις αποτελεσματικές τιμές μορφοποίησης με εφαρμοσμένη κληρονομικότητα.
