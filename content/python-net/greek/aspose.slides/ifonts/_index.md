## IFonts κλάση

Αντιπροσωπεύει τη συλλογή γραμματοσειρών.

Ο τύπος IFonts εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`latin_font`](/slides/python-net/el/aspose.slides/ifonts/latin_font/) | Επιστρέφει ή ορίζει τη λατινική γραμματοσειρά.<br/>            Ανάγνωση/εγγραφή [`IFontData`](/slides/python-net/el/aspose.slides/ifontdata). |
| [`east_asian_font`](/slides/python-net/el/aspose.slides/ifonts/east_asian_font/) | Επιστρέφει ή ορίζει τη γραμματοσειρά Ανατολικής Ασίας.<br/>            Ανάγνωση/εγγραφή [`IFontData`](/slides/python-net/el/aspose.slides/ifontdata). |
| [`complex_script_font`](/slides/python-net/el/aspose.slides/ifonts/complex_script_font/) | Επιστρέφει ή ορίζει τη γραμματοσειρά σύνθετου script.<br/>            Ανάγνωση/εγγραφή [`IFontData`](/slides/python-net/el/aspose.slides/ifontdata). |

## Μέθοδοι

| Μέθοδος | Περιγραφή |
| :- | :- |
| [`get_script_font_map(self)`](/slides/python-net/el/aspose.slides/ifonts/get_script_font_map/#) | Επιστρέφει μια λίστα με όλους τους ορισμούς γραμματοσειρών script σε ζεύγη συμβολοσειρά-συμβολοσειρά στην παρουσίαση. |
| [`get_script_font(self, script)`](/slides/python-net/el/aspose.slides/ifonts/get_script_font/#str) | Λαμβάνει το όνομα γραμματοσειράς που σχετίζεται με μια συγκεκριμένη ετικέτα script από το θέμα της παρουσίασης. |
| [`set_script_font(self, script, font_name)`](/slides/python-net/el/aspose.slides/ifonts/set_script_font/#str-str) | Αναθέτει ένα όνομα γραμματοσειράς σε μια συγκεκριμένη ετικέτα script, η οποία καθορίζει πώς θα αποδίδεται το κείμενο αυτού του script στην παρουσίαση. |
| [`remove_script_font(self, script)`](/slides/python-net/el/aspose.slides/ifonts/remove_script_font/#str) | Αφαιρεί τη ρύθμιση γραμματοσειράς που σχετίζεται με μια συγκεκριμένη ετικέτα script από τη συλλογή γραμματοσειρών του θέματος. |
