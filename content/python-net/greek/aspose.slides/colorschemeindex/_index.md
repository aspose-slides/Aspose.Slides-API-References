## ColorSchemeIndex απαρίθμηση

Αντιπροσωπεύει έναν δείκτη σε ένα σχήμα χρωμάτων.

Ο τύπος ColorSchemeIndex εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| DARK1 | Σκούρο 1. |
| LIGHT1 | Ανοιχτό 1. |
| DARK2 | Σκούρο 2. |
| LIGHT2 | Ανοιχτό 2. |
| ACCENT1 | Έμφαση 1. |
| ACCENT2 | Έμφαση 2. |
| ACCENT3 | Έμφαση 3. |
| ACCENT4 | Έμφαση 4. |
| ACCENT5 | Έμφαση 5. |
| ACCENT6 | Έμφαση 6. |
| HYPERLINK | Υπερσύνδεσμος. |
| FOLLOWED_HYPERLINK | Ακολουθούμενος υπερσύνδεσμος. |
