## IFontSources κλάση

Παρέχει πηγές αρχείων και μνήμης για εξωτερικές γραμματοσειρές.

Ο τύπος IFontSources εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`font_folders`](/slides/python-net/el/aspose.slides/ifontsources/font_folders/) | Φάκελοι που περιέχουν αρχεία γραμματοσειρών.<br/>            Όλα τα αρχεία γραμματοσειρών που βρίσκονται σε αυτούς τους φακέλους περιλαμβάνονται στη συλλογή. Φάκελοι που αναζητούνται αναδρομικά. |
| [`memory_fonts`](/slides/python-net/el/aspose.slides/ifontsources/memory_fonts/) | Μία συλλογή γραμματοσειρών που αντιπροσωπεύεται ως byte arrays. |
