## IPortion κλάση

Αναπαριστά ένα τμήμα κειμένου μέσα σε μια παράγραφο κειμένου.

Ο τύπος IPortion εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`portion_format`](/slides/python-net/el/aspose.slides/iportion/portion_format/) | Επιστρέφει το αντικείμενο διαμόρφωσης που περιέχει ρητά ορισμένες ιδιότητες διαμόρφωσης του τμήματος κειμένου χωρίς εφαρμογή κληρονομικότητας.<br/>            Μόνο για ανάγνωση [`IPortionFormat`](/slides/python-net/el/aspose.slides/iportionformat). |
| [`text`](/slides/python-net/el/aspose.slides/iportion/text/) | Λαμβάνει ή ορίζει το απλό κείμενο ενός τμήματος.<br/>            Ανάγνωση/εγγραφή **str**. |
| [`field`](/slides/python-net/el/aspose.slides/iportion/field/) | Επιστρέφει ένα πεδίο αυτού του τμήματος.<br/>            Μόνο για ανάγνωση [`IField`](/slides/python-net/el/aspose.slides/ifield). |
| [`slide`](/slides/python-net/el/aspose.slides/iportion/slide/) |  |
| [`presentation`](/slides/python-net/el/aspose.slides/iportion/presentation/) |  |

## Μέθοδοι

| Μέθοδος | Περιγραφή |
| :- | :- |
| [`add_field(self, field_type)`](/slides/python-net/el/aspose.slides/iportion/add_field/#ifieldtype) | Μετατρέπει αυτό το τμήμα σε αυτόματα ενημερωμένο πεδίο. |
| [`add_field(self, internal_string)`](/slides/python-net/el/aspose.slides/iportion/add_field/#str) | Μετατρέπει αυτό το τμήμα σε αυτόματα ενημερωμένο πεδίο. |
| [`remove_field(self)`](/slides/python-net/el/aspose.slides/iportion/remove_field/#) | Μετατρέπει αυτό το πεδίο τμήματος σε απλό τμήμα. |
| [`get_rect(self)`](/slides/python-net/el/aspose.slides/iportion/get_rect/#) | Λαμβάνει τις συντεταγμένες του ορθογωνίου που περιβάλλει το τμήμα. Το ορθογώνιο περιλαμβάνει όλες τις γραμμές του κειμένου στο τμήμα, συμπεριλαμβανομένων των κενών. |
| [`get_coordinates(self)`](/slides/python-net/el/aspose.slides/iportion/get_coordinates/#) | Λαμβάνει τις συντεταγμένες της αρχής του τμήματος. Η συντεταγμένη X του σημείου αντιπροσωπεύει την αρχή του τμήματος από τον πρώτο χαρακτήρα, συμπεριλαμβανομένης της αριστερής πλευρικής απόστασης. Η συντεταγμένη Y περιλαμβάνει την επάνω πλευρική απόσταση. |
