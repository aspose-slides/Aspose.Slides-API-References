## portion_format ιδιότητα
Returns formatting object which contains explicitly set formatting properties of the text portion with no inheritance applied.
            Μόνο για ανάγνωση [`IPortionFormat`](/slides/python-net/el/aspose.slides/iportionformat).

### Σχόλια

Το αντικείμενο μορφοποίησης περιέχει τις παραμέτρους μορφοποίησης που ορίζονται μόνο για το τρέχον τμήμα, τα κληρονομημένα δεδομένα δεν εφαρμόζονται.

Για να λάβετε τις αποτελεσματικές τιμές συμπεριλαμβανομένων των κληρονομημένων, χρησιμοποιήστε τη μέθοδο [`IPortionFormat.get_effective`](/slides/python-net/el/aspose.slides/iportionformat/get_effective).
