## TextVerticalType απαρίθμηση

Καθορίζει τη κάθετη λειτουργία γραφής για ένα κείμενο.

Ο τύπος TextVerticalType παρουσιάζει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| NOT_DEFINED | Δεν ορίζεται. |
| HORIZONTAL | Οριζόντιο κείμενο. |
| VERTICAL | Κάθετο κείμενο. |
| VERTICAL270 | Κάθετο κείμενο 270 μοιρών. |
| WORD_ART_VERTICAL | WordArt κάθετο κείμενο. |
| EAST_ASIAN_VERTICAL | Κάθετο κείμενο ανατολικής Ασίας. |
| MONGOLIAN_VERTICAL | Κάθετο κείμενο Μογγολικό. |
| WORD_ART_VERTICAL_RIGHT_TO_LEFT | WordArt κάθετο κείμενο από δεξιά προς τα αριστερά. |
