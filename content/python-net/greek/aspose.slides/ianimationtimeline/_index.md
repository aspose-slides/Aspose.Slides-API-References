## IAnimationTimeLine κλάση

Αντιπροσωπεύει τη γραμμή χρόνου της animation.

Ο τύπος IAnimationTimeLine εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Property | Description |
| :- | :- |
| [`interactive_sequences`](/slides/python-net/el/aspose.slides/ianimationtimeline/interactive_sequences/) | Επιστρέφει τη συλλογή των διαδραστικών ακολουθιών.<br/>            Αυτές οι ακολουθίες μπορεί να περιέχουν μόνο εφέ με "click on shape" με καθορισμένο στόχο σχήμα.<br/>            Read-only [`ISequenceCollection`](/slides/python-net/el/aspose.slides.animation/isequencecollection). |
| [`main_sequence`](/slides/python-net/el/aspose.slides/ianimationtimeline/main_sequence/) | Επιστρέφει την κύρια ακολουθία η οποία μπορεί να περιέχει μόνο τη συλλογή κύριων εφέ.<br/>            Read-only [`ISequence`](/slides/python-net/el/aspose.slides.animation/isequence). |
| [`text_animation_collection`](/slides/python-net/el/aspose.slides/ianimationtimeline/text_animation_collection/) | Επιστρέφει τη συλλογή των κειμενικών κινήσεων.<br/>            Read-only [`ITextAnimationCollection`](/slides/python-net/el/aspose.slides.animation/itextanimationcollection). |
