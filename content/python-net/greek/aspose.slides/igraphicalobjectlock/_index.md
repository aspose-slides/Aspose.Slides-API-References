## IGraphicalObjectLock κλάση

Καθορίζει ποιες λειτουργίες είναι απενεργοποιημένες στο γονικό GraphicalObjectEx.

Ο τύπος IGraphicalObjectLock εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`grouping_locked`](/slides/python-net/el/aspose.slides/igraphicalobjectlock/grouping_locked/) | Καθορίζει αν η προσθήκη αυτού του σχήματος σε ομάδα είναι απαγορευμένη.<br/>            Διάβασμα/Εγγραφή **bool**. |
| [`drilldown_locked`](/slides/python-net/el/aspose.slides/igraphicalobjectlock/drilldown_locked/) | Καθορίζει αν η επιλογή υποσχημάτων αυτού του αντικειμένου είναι απαγορευμένη.<br/>            Διάβασμα/Εγγραφή **bool**. |
| [`select_locked`](/slides/python-net/el/aspose.slides/igraphicalobjectlock/select_locked/) | Καθορίζει αν η επιλογή αυτού του σχήματος είναι απαγορευμένη.<br/>            Διάβασμα/Εγγραφή **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/el/aspose.slides/igraphicalobjectlock/aspect_ratio_locked/) | Καθορίζει αν το σχήμα πρέπει να διατηρεί την αναλογία διαστάσεων κατά την αλλαγή μεγέθους.<br/>            Διάβασμα/Εγγραφή **bool**. |
| [`position_locked`](/slides/python-net/el/aspose.slides/igraphicalobjectlock/position_locked/) | Καθορίζει αν η μετακίνηση αυτού του σχήματος είναι απαγορευμένη.<br/>            Διάβασμα/Εγγραφή **bool**. |
| [`size_locked`](/slides/python-net/el/aspose.slides/igraphicalobjectlock/size_locked/) | Καθορίζει αν η αλλαγή μεγέθους αυτού του σχήματος είναι απαγορευμένη.<br/>            Διάβασμα/Εγγραφή **bool**. |
| [`no_locks`](/slides/python-net/el/aspose.slides/igraphicalobjectlock/no_locks/) |  |
