## IDigitalSignature κλάση

Ψηφιακή υπογραφή σε υπογραμμένο αρχείο.

Ο τύπος IDigitalSignature εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`certificate`](/slides/python-net/el/aspose.slides/idigitalsignature/certificate/) | Αντικείμενο πιστοποιητικό που χρησιμοποιήθηκε για την υπογραφή του εγγράφου.<br/>            Μόνο για ανάγνωση **System.Security.Cryptography.X509Certificates.X509Certificate2**. |
| [`is_valid`](/slides/python-net/el/aspose.slides/idigitalsignature/is_valid/) | Εάν αυτή η ψηφιακή υπογραφή είναι έγκυρη και το έγγραφο δεν έχει παραποιηθεί, αυτή η τιμή θα είναι true.<br/>            Μόνο για ανάγνωση **bool**. |
| [`sign_time`](/slides/python-net/el/aspose.slides/idigitalsignature/sign_time/) | Η στιγμή που το έγγραφο υπογράφηκε.<br/>            Μόνο για ανάγνωση **System.DateTime**. |
| [`comments`](/slides/python-net/el/aspose.slides/idigitalsignature/comments/) | Ο σκοπός της υπογραφής.<br/>            Ανάγνωση/Εγγραφή **str**. |
