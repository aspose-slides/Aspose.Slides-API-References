## Background κλάση

Αντιπροσωπεύει το φόντο μιας slide.

**Κληρονόμηση:**[`Background`](/slides/python-net/el/aspose.slides/background) → [`PVIObject`](/slides/python-net/el/aspose.slides/pviobject)

Ο τύπος Background εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`type`](/slides/python-net/el/aspose.slides/background/type/) | Επιστρέφει έναν τύπο γεμίσματος φόντου.<br/>            Ανάγνωση/εγγραφή [`BackgroundType`](/slides/python-net/el/aspose.slides/backgroundtype). |
| [`fill_format`](/slides/python-net/el/aspose.slides/background/fill_format/) | Επιστρέφει ένα FillFormat για γεμίσματος BackgroundType.OwnBackground.<br/>            Μόνο-ανάγνωση [`IFillFormat`](/slides/python-net/el/aspose.slides/ifillformat). |
| [`effect_format`](/slides/python-net/el/aspose.slides/background/effect_format/) | Επιστρέφει ένα EffectFormat για γεμίσματος BackgroundType.OwnBackground.<br/>            Μνο-ανάγνωση [`IEffectFormat`](/slides/python-net/el/aspose.slides/ieffectformat). |
| [`style_color`](/slides/python-net/el/aspose.slides/background/style_color/) | Επιστρέφει ένα ColorFormat για ένα γεμίσματος BackgroundType.Themed.<br/>            Μόνο-ανάγνωση [`IColorFormat`](/slides/python-net/el/aspose.slides/icolorformat). |
| [`style_index`](/slides/python-net/el/aspose.slides/background/style_index/) | Επιστρέφει έναν δείκτη του γεμίσματος BackgroundType.Themed στη συλλογή θεμάτων φόντου.<br/>            0 σημαίνει χωρίς γέμισμα.<br/>            1..999 - δείκτης.<br/>            Ανάγνωση/εγγραφή **int**. |
| [`slide`](/slides/python-net/el/aspose.slides/background/slide/) | Επιστρέφει τη γονική slide ενός shape.<br/>            Μόνο-ανάγνωση [`IBaseSlide`](/slides/python-net/el/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/el/aspose.slides/background/presentation/) | Επιστρέφει τη γονική presentation μιας slide.<br/>            Μόνο-ανάγνωση [`IPresentation`](/slides/python-net/el/aspose.slides/ipresentation). |
