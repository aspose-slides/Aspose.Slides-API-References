## TextSearchOptions κλάση

Αντιπροσωπεύει επιλογές που μπορούν να χρησιμοποιηθούν για την αναζήτηση κειμένου σε μια Presentation, Slide ή TextFrame.

Ο τύπος TextSearchOptions εκθέτει τα παρακάτω μέλη:

## Κατασκευαστές

| Κατασκευαστής | Περιγραφή |
| :- | :- |
| [`__init__(self)`](/slides/python-net/el/aspose.slides/textsearchoptions/__init__/#) | Δημιουργεί νέες προεπιλεγμένες επιλογές αναζήτησης κειμένου. |

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`case_sensitive`](/slides/python-net/el/aspose.slides/textsearchoptions/case_sensitive/) | Ορίστε true για χρήση αναζήτησης που διακρίνει πεζά-κεφαλαία, false - αλλιώς.<br/>Ανάγνωση/εγγραφή **bool**. |
| [`whole_words_only`](/slides/python-net/el/aspose.slides/textsearchoptions/whole_words_only/) | Ορίστε true για αντιστοίχιση μόνο ολόκληρων λέξεων, false - αλλιώς.<br/>Ανάγνωση/εγγραφή **bool**. |
| [`include_notes`](/slides/python-net/el/aspose.slides/textsearchoptions/include_notes/) | Ορίστε `true` για να συμπεριλάβετε κείμενο που περιέχεται σε σημειώσεις διαφάνειας ([`NotesSlide`](/slides/python-net/el/aspose.slides/notesslide)) <br/>κατά την εκτέλεση αναζήτησης κειμένου, αντικατάστασης ή επισήμανσης.<br/>Η προεπιλεγμένη τιμή είναι `false`. |
