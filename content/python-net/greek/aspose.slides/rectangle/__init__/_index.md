Δημιουργεί ένα ορθογώνιο με την καθορισμένη θέση και μέγεθος. Οι τιμές κινητής υποδιαστολής περικόπτονται σε ακέραιους.


```python
def __init__(self, x=0, y=0, width=0, height=0):
    ...
```


| Παράμετρος | Τύπος | Περιγραφή |
| :- | :- | :- |
| x | **int** | Η συντεταγμένη x του επάνω αριστερού γωνίου του ορθογωνίου. |
| y | **int** | Η συντεταγμένη y του επάνω αριστερού γωνίου του ορθογωνίου. |
| width | **int** | Το πλάτος του ορθογωνίου. |
| height | **int** | Το ύψος του ορθογωνίου. |
