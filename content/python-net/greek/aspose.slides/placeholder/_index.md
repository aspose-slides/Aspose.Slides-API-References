## Placeholder κλάση

Αναπαριστά ένα σύμβολο κράτησης θέσης σε μια διαφάνεια.

Ο τύπος Placeholder εμφανίζει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`orientation`](/slides/python-net/el/aspose.slides/placeholder/orientation/) | Λαμβάνει ή ορίζει τον προσανατολισμό ενός σύμβολου κράτησης θέσης.<br/>            Μόνο για ανάγνωση [`Orientation`](/slides/python-net/el/aspose.slides/orientation). |
| [`size`](/slides/python-net/el/aspose.slides/placeholder/size/) | Λαμβάνει ή ορίζει το μέγεθος ενός σύμβολου κράτησης θέσης.<br/>            Μόνο για ανάγνωση [`PlaceholderSize`](/slides/python-net/el/aspose.slides/placeholdersize). |
| [`type`](/slides/python-net/el/aspose.slides/placeholder/type/) | Λαμβάνει ή ορίζει τον τύπο ενός σύμβολου κράτησης θέσης.<br/>            Μόνο για ανάγνωση [`PlaceholderType`](/slides/python-net/el/aspose.slides/placeholdertype). |
| [`index`](/slides/python-net/el/aspose.slides/placeholder/index/) | Λαμβάνει ή ορίζει το ευρετήριο ενός σύμβολου κράτησης θέσης.<br/>            Μόνο για ανάγνωση **int**. |
