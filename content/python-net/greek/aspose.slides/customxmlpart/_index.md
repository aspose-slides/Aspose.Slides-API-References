## CustomXmlPart κλάση

Αναπαριστά προσαρμοσμένο τμήμα xml.

Ο τύπος CustomXmlPart εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`xml_data`](/slides/python-net/el/aspose.slides/customxmlpart/xml_data/) | Επιστρέφει ή ορίζει δεδομένα xml.<br/>            Read/write **int**[].<br/>            value is `None`.η τιμή είναι κενή ή xml-data είναι άκυρο. |
| [`xml_as_string`](/slides/python-net/el/aspose.slides/customxmlpart/xml_as_string/) | Επιστρέφει ή ορίζει δεδομένα xml ως συμβολοσειρά UTF-8.<br/>            Read/write **str**.<br/>            value is `None`.η τιμή είναι κενή ή xml-data είναι άκυρο. |
| [`item_id`](/slides/python-net/el/aspose.slides/customxmlpart/item_id/) | Καθορίζει ένα παγκοσμίως μοναδικό αναγνωριστικό (GUID) που ταυτοποιεί μοναδικά ένα μόνο προσαρμοσμένο τμήμα XML <br/>            μέσα σε ένα έγγραφο Office Open XML.<br/>            Read-only **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/el/aspose.slides/customxmlpart/namespace_schemas/) | Επιστρέφει τα σχήματα XML της συλλογής που σχετίζονται με το προσαρμοσμένο τμήμα XML.<br/>            Read-only **str**[]. |

## Μέθοδοι

| Μέθοδος | Περιγραφή |
| :- | :- |
