## IColorFormat κλάση

Αναπαριστά ένα χρώμα που χρησιμοποιείται σε μια παρουσίαση.

Ο τύπος IColorFormat εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`color_type`](/slides/python-net/el/aspose.slides/icolorformat/color_type/) | Επιστρέφει ή ορίζει τη μέθοδο ορισμού χρώματος.<br/>            Ανάγνωση/Εγγραφή [`ColorType`](/slides/python-net/el/aspose.slides/colortype). |
| [`color`](/slides/python-net/el/aspose.slides/icolorformat/color/) | Επιστρέφει το αποτέλεσμα χρώματος (με όλες τις μετασχηματίσεις χρώματος εφαρμοσμένες).<br/>            Ορίζει χρώματα RGB και καθαρίζει όλες τις μετασχηματίσεις χρώματος.<br/>            Ανάγνωση/Εγγραφή **aspose.slides.Color**. |
| [`preset_color`](/slides/python-net/el/aspose.slides/icolorformat/preset_color/) | Επιστρέφει ή ορίζει την προεπιλογή χρώματος.<br/>            Ανάγνωση/Εγγραφή [`PresetColor`](/slides/python-net/el/aspose.slides/presetcolor). |
| [`system_color`](/slides/python-net/el/aspose.slides/icolorformat/system_color/) | Επιστρέφει ή ορίζει το χρώμα που προσδιορίζεται από τον πίνακα χρωμάτων του συστήματος.<br/>            Ανάγνωση/Εγγραφή [`SystemColor`](/slides/python-net/el/aspose.slides/systemcolor). |
| [`scheme_color`](/slides/python-net/el/aspose.slides/icolorformat/scheme_color/) | Επιστρέφει ή ορίζει το χρώμα που προσδιορίζεται από ένα σχήμα χρωμάτων.<br/>            Ανάγνωση/Εγγραφή [`SchemeColor`](/slides/python-net/el/aspose.slides/schemecolor). |
| [`r`](/slides/python-net/el/aspose.slides/icolorformat/r/) | Επιστρέφει ή ορίζει το κόκκινο συστατικό ενός χρώματος. Όλες οι μετασχηματίσεις χρώματος αγνοούνται.<br/>            Ανάγνωση/Εγγραφή **int**. |
| [`g`](/slides/python-net/el/aspose.slides/icolorformat/g/) | Επιστρέφει ή ορίζει το πράσινο συστατικό ενός χρώματος. Όλες οι μετασχηματίσεις χρώματος αγνοούνται.<br/>            Ανάγνωση/Εγγραφή **int**. |
| [`b`](/slides/python-net/el/aspose.slides/icolorformat/b/) | Επιστρέφει ή ορίζει το μπλε συστατικό ενός χρώματος. Όλες οι μετασχηματίσεις χρώματος αγνοούνται.<br/>            Ανάγνωση/Εγγραφή **int**. |
| [`float_r`](/slides/python-net/el/aspose.slides/icolorformat/float_r/) | Επιστρέφει ή ορίζει το κόκκινο συστατικό ενός χρώματος. Όλες οι μετασχηματίσεις χρώματος αγνοούνται.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`float_g`](/slides/python-net/el/aspose.slides/icolorformat/float_g/) | Επιστρέφει ή ορίζει το πράσινο συστατικό ενός χρώματος. Όλες οι μετασχηματίσεις χρώματος αγνοούνται.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`float_b`](/slides/python-net/el/aspose.slides/icolorformat/float_b/) | Επιστρέφει ή ορίζει το μπλε συστατικό ενός χρώματος. Όλες οι μετασχηματίσεις χρώματος αγνοούνται.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`hue`](/slides/python-net/el/aspose.slides/icolorformat/hue/) | Επιστρέφει ή ορίζει το συστατικό τόνο (hue) ενός χρώματος σε αναπαράσταση HSL.<br/>            Όλες οι μετασχηματίσεις χρώματος αγνοούνται.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`saturation`](/slides/python-net/el/aspose.slides/icolorformat/saturation/) | Επιστρέφει ή ορίζει το συστατικό κορεσμού ενός χρώματος σε αναπαράσταση HSL.<br/>            Όλες οι μετασχηματίσεις χρώματος αγνοούνται.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`luminance`](/slides/python-net/el/aspose.slides/icolorformat/luminance/) | Επιστρέφει ή ορίζει το συστατικό φωτεινότητας ενός χρώματος σε αναπαράσταση HSL.<br/>            Όλες οι μετασχηματίσεις χρώματος αγνοούνται.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`color_transform`](/slides/python-net/el/aspose.slides/icolorformat/color_transform/) | Επιστρέφει τη συλλογή των μετασχηματισμών χρώματος που εφαρμόζονται σε ένα χρώμα.<br/>            Μόνο για ανάγνωση [`IColorOperationCollection`](/slides/python-net/el/aspose.slides/icoloroperationcollection). |
