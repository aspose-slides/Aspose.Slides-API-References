## IColorFormat κλάση

Αναπαριστά ένα χρώμα που χρησιμοποιείται σε μια παρουσίαση.

Ο τύπος IColorFormat εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Property | Description |
| :- | :- |
| [`color_type`](/slides/python-net/el/aspose.slides/icolorformat/color_type/) | Επιστρέφει ή ορίζει τη μέθοδο ορισμού χρώματος.<br/>            Ανάγνωση/εγγραφή [`ColorType`](/slides/python-net/el/aspose.slides/colortype). |
| [`color`](/slides/python-net/el/aspose.slides/icolorformat/color/) | Επιστρέφει το αποτέλεσμα χρώματος (με όλες τις μετασχηματιστικές αλλαγές χρώματος εφαρμοσμένες).<br/>            Ορίζει χρώματα RGB και καθαρίζει όλες τις μετασχηματιστικές αλλαγές χρώματος.<br/>            Ανάγνωση/εγγραφή [`Color`](/slides/python-net/el/aspose.slides/color). |
| [`preset_color`](/slides/python-net/el/aspose.slides/icolorformat/preset_color/) | Επιστρέφει ή ορίζει την προεπιλεγμένη χρωματική ρύθμιση.<br/>            Ανάγνωση/εγγραφή [`PresetColor`](/slides/python-net/el/aspose.slides/presetcolor). |
| [`system_color`](/slides/python-net/el/aspose.slides/icolorformat/system_color/) | Επιστρέφει ή ορίζει το χρώμα που προσδιορίζεται από τον πίνακα συστημικών χρωμάτων.<br/>            Ανάγνωση/εγγραφή [`SystemColor`](/slides/python-net/el/aspose.slides/systemcolor). |
| [`scheme_color`](/slides/python-net/el/aspose.slides/icolorformat/scheme_color/) | Επιστρέφει ή ορίζει το χρώμα που προσδιορίζεται από ένα σχήμα χρωμάτων.<br/>            Ανάγνωση/εγγραφή [`SchemeColor`](/slides/python-net/el/aspose.slides/schemecolor). |
| [`r`](/slides/python-net/el/aspose.slides/icolorformat/r/) | Επιστρέφει ή ορίζει το κόκκινο συστατικό ενός χρώματος. Όλες οι μετασχηματιστικές αλλαγές χρώματος αγνοούνται.<br/>            Ανάγνωση/εγγραφή **int**. |
| [`g`](/slides/python-net/el/aspose.slides/icolorformat/g/) | Επιστρέφει ή ορίζει το πράσινο συστατικό ενός χρώματος. Όλες οι μετασχηματιστικές αλλαγές χρώματος αγνοούνται.<br/>            Ανάγνωση/εγγραφή **int**. |
| [`b`](/slides/python-net/el/aspose.slides/icolorformat/b/) | Επιστρέφει ή ορίζει το μπλε συστατικό ενός χρώματος. Όλες οι μετασχηματιστικές αλλαγές χρώματος αγνοούνται.<br/>            Ανάγνωση/εγγραφή **int**. |
| [`float_r`](/slides/python-net/el/aspose.slides/icolorformat/float_r/) | Επιστρέφει ή ορίζει το κόκκινο συστατικό ενός χρώματος. Όλες οι μετασχηματιστικές αλλαγές χρώματος αγνοούνται.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`float_g`](/slides/python-net/el/aspose.slides/icolorformat/float_g/) | Επιστρέφει ή ορίζει το πράσινο συστατικό ενός χρώματος. Όλες οι μετασχηματιστικές αλλαγές χρώματος αγνοούνται.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`float_b`](/slides/python-net/el/aspose.slides/icolorformat/float_b/) | Επιστρέφει ή ορίζει το μπλε συστατικό ενός χρώματος. Όλες οι μετασχηματιστικές αλλαγές χρώματος αγνοούνται.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`hue`](/slides/python-net/el/aspose.slides/icolorformat/hue/) | Επιστρέφει ή ορίζει το στοιχείο απόχρωσης (hue) ενός χρώματος σε αναπαράσταση HSL.<br/>            Όλες οι μετασχηματιστικές αλλαγές χρώματος αγνοούνται.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`saturation`](/slides/python-net/el/aspose.slides/icolorformat/saturation/) | Επιστρέφει ή ορίζει το στοιχείο κορεσμού (saturation) ενός χρώματος σε αναπαράσταση HSL.<br/>            Όλες οι μετασχηματιστικές αλλαγές χρώματος αγνοούνται.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`luminance`](/slides/python-net/el/aspose.slides/icolorformat/luminance/) | Επιστρέφει ή ορίζει το στοιχείο φωτεινότητας (luminance) ενός χρώματος σε αναπαράσταση HSL.<br/>            Όλες οι μετασχηματιστικές αλλαγές χρώματος αγνοούνται.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`color_transform`](/slides/python-net/el/aspose.slides/icolorformat/color_transform/) | Επιστρέφει τη συλλογή των μετασχηματισμών χρώματος που εφαρμόζονται σε ένα χρώμα.<br/>            Μόνο ανάγνωση [`IColorOperationCollection`](/slides/python-net/el/aspose.slides/icoloroperationcollection). |
