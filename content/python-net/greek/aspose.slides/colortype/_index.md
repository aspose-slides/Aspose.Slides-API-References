## ColorType απαρίθμηση

Αντιπροσωπεύει διαφορετικές λειτουργίες χρώματος.

Ο τύπος ColorType εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| NOT_DEFINED | Το χρώμα δεν ορίζεται καθόλου. |
| RGB | Τυπικό χρώμα RGB 24bit. |
| RGB_PERCENTAGE | Χρώμα RGB υψηλής ανάλυσης. |
| HSL | Χρώμα HSL υψηλής ανάλυσης. |
| SCHEME | Χρώμα σχήματος. |
| SYSTEM | Χρώμα συστήματος. |
| PRESET | Προκαθορισμένο χρώμα. |
