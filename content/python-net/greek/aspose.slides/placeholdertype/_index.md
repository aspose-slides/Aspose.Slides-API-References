## PlaceholderType απαρίθμηση

Αναπαριστά τον τύπο ενός σύμβολο κράτησης.

Ο τύπος PlaceholderType εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| TITLE | Τίτλος. |
| BODY | Κείμενο. |
| CENTERED_TITLE | Κεντρικός Τίτλος. |
| SUBTITLE | Υπότιτλος. |
| DATE_AND_TIME | Ημερομηνία και ώρα. |
| SLIDE_NUMBER | Αριθμός διαφάνειας. |
| FOOTER | Υποσέλιδο. |
| HEADER | Κεφαλίδα. |
| OBJECT | Αντικείμενο. |
| CHART | Διάγραμμα. |
| TABLE | Πίνακας. |
| CLIP_ART | Γραφικό Clip Art. |
| DIAGRAM | Διάγραμμα. |
| MEDIA | Πολυμέσα. |
| SLIDE_IMAGE | Εικόνα διαφάνειας. |
| PICTURE | Εικόνα. |
