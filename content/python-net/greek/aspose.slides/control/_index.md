## Κλάση Control

Αντιπροσωπεύει έναν έλεγχο ActiveX.

Ο τύπος Control εκθέτει τα εξής μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`persistence`](/slides/python-net/el/aspose.slides/control/persistence/) | Παίρνει τη μέθοδο που χρησιμοποιείται για αποθήκευση των ιδιοτήτων του ελέγχου ActiveX.<br/>            Μόνο ανάγνωση [`PersistenceType`](/slides/python-net/el/aspose.slides/persistencetype). |
| [`name`](/slides/python-net/el/aspose.slides/control/name/) | Παίρνει ή ορίζει το όνομα αυτού του ελέγχου.<br/>            Ανάγνωση/εγγραφή **str**. |
| [`class_id`](/slides/python-net/el/aspose.slides/control/class_id/) | Παίρνει το αναγνωριστικό κλάσης αυτού του ελέγχου.<br/>            Μόνο ανάγνωση **System.Guid**. |
| [`substitute_picture_format`](/slides/python-net/el/aspose.slides/control/substitute_picture_format/) | Επιστρέφει το αντικείμενο ιδιοτήτων γεμίσματος εικόνας Control.<br/>            Μόνο ανάγνωση [`IPictureFillFormat`](/slides/python-net/el/aspose.slides/ipicturefillformat). |
| [`frame`](/slides/python-net/el/aspose.slides/control/frame/) | Επιστρέφει ή ορίζει το πλαίσιο του ελέγχου.<br/>            Ανάγνωση/εγγραφή [`IShapeFrame`](/slides/python-net/el/aspose.slides/ishapeframe). |
| [`properties`](/slides/python-net/el/aspose.slides/control/properties/) | Επιστρέφει μια συλλογή ιδιοτήτων ActiveX.<br/>            Σημείωση: Το Aspose.Slides υποστηρίζει μόνο ιδιότητες ActiveX βασισμένες σε XML. Εάν οι ιδιότητες αποθηκεύονται σε δυαδική μορφή, αυτή η ιδιότητα θα επιστρέψει None.<br/>            Μόνο ανάγνωση [`IControlPropertiesCollection`](/slides/python-net/el/aspose.slides/icontrolpropertiescollection). |
| [`active_x_control_binary`](/slides/python-net/el/aspose.slides/control/active_x_control_binary/) | Καθορίζει τη διατήρηση ενός ελέγχου ActiveX όταν η μέθοδος που χρησιμοποιείται για διατήρηση είναι είτε PersistStream, PersistStreamInit ή PersistStorage. |
| [`slide`](/slides/python-net/el/aspose.slides/control/slide/) |  |
