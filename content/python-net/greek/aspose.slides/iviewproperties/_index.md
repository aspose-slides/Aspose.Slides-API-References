## IViewProperties κλάση

Ιδιότητες προβολής σε όλη την παρουσίαση.

Ο τύπος IViewProperties εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`last_view`](/slides/python-net/el/aspose.slides/iviewproperties/last_view/) | Καθορίζει τη λειτουργία προβολής που χρησιμοποιήθηκε όταν το έγγραφο παρουσίασης αποθηκεύτηκε τελευταία.<br/>            Read/write [`ViewType`](/slides/python-net/el/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/el/aspose.slides/iviewproperties/show_comments/) | Καθορίζει αν πρέπει να εμφανίζονται τα σχόλια της διαφάνειας.<br/>            Read/write [`NullableBool`](/slides/python-net/el/aspose.slides/nullablebool). |
| [`slide_view_properties`](/slides/python-net/el/aspose.slides/iviewproperties/slide_view_properties/) | Καθορίζει τις κοινές ιδιότητες προβολής που σχετίζονται με τη λειτουργία προβολής διαφάνειας.<br/>            Read-only [`ICommonSlideViewProperties`](/slides/python-net/el/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/el/aspose.slides/iviewproperties/notes_view_properties/) | Καθορίζει τις κοινές ιδιότητες προβολής που σχετίζονται με τη λειτουργία προβολής σημειώσεων.<br/>            Read-only [`ICommonSlideViewProperties`](/slides/python-net/el/aspose.slides/icommonslideviewproperties). |
| [`normal_view_properties`](/slides/python-net/el/aspose.slides/iviewproperties/normal_view_properties/) | Αντιπροσωπεύει τις ιδιότητες κανονικής προβολής. Η κανονική προβολή αποτελείται από<br/>            τρεις περιοχές περιεχομένου: τη διαφάνεια, μια πλευρική περιοχή περιεχομένου, και μια κάτω περιοχή περιεχομένου.<br/>            Read-only [`INormalViewProperties`](/slides/python-net/el/aspose.slides/inormalviewproperties). |
| [`grid_spacing`](/slides/python-net/el/aspose.slides/iviewproperties/grid_spacing/) | Επιστρέφει ή ορίζει την απόσταση του πλέγματος που πρέπει να χρησιμοποιείται για το πλέγμα του εγγράφου παρουσίασης, σε σημείο. <br/>            Read/write **float**. |
