## SplitterBarStateType απαριθμητικός τύπος

Καθορίζει την κατάσταση στην οποία πρέπει να εμφανίζεται η γραμμή διαχωριστή. Η γραμμή διαχωριστή χωρίζει μια κύρια και μια δευτερεύουσα περιοχή μέσα σε μια περιοχή προβολής.

Ο τύπος SplitterBarStateType εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| MINIMIZED | Η κύρια περιοχή καταλαμβάνει το μικρότερο δυνατό μέρος της περιοχής προβολής που επιτρέπεται από την εφαρμογή. |
| RESTORED | Η κύρια περιοχή έχει ένα συγκεκριμένο ενδιάμεσο μέγεθος. |
| MAXIMIZED | Η κύρια περιοχή καταλαμβάνει το μεγαλύτερο δυνατό μέρος της περιοχής προβολής που επιτρέπεται από την εφαρμογή. |
