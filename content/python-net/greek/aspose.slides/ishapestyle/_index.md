## IShapeStyle κλάση

Αναπαριστά την αναφορά του στυλ του σχήματος.

Ο τύπος IShapeStyle εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`line_color`](/slides/python-net/el/aspose.slides/ishapestyle/line_color/) | Επιστρέφει το χρώμα περιγράμματος ενός σχήματος.<br/>            Μόνο-ανάγνωση [`IColorFormat`](/slides/python-net/el/aspose.slides/icolorformat). |
| [`line_style_index`](/slides/python-net/el/aspose.slides/ishapestyle/line_style_index/) | Επιστρέφει ή ορίζει τον δείκτη στήλης της γραμμής σε ένα πλέγμα στυλ.<br/>            Ανάγνωση/εγγραφή **int**. |
| [`fill_color`](/slides/python-net/el/aspose.slides/ishapestyle/fill_color/) | Επιστρέφει το χρώμα γεμίσματος ενός σχήματος.<br/>            Μόνο-ανάγνωση [`IColorFormat`](/slides/python-net/el/aspose.slides/icolorformat). |
| [`fill_style_index`](/slides/python-net/el/aspose.slides/ishapestyle/fill_style_index/) | Επιστρέφει ή ορίζει τον δείκτη στήλης γεμίσματος του σχήματος σε πλέγματα στυλ.<br/>            0 σημαίνει χωρίς γέμισμα,<br/>            θετική τιμή - δείκτη στα γεμίσματα του θέματος,<br/>            αρνητική τιμή - δείκτη στα στυλ φόντου του θέματος.<br/>            Ανάγνωση/εγγραφή **int**. |
| [`effect_color`](/slides/python-net/el/aspose.slides/ishapestyle/effect_color/) | Επιστρέφει το χρώμα εφέ ενός σχήματος.<br/>            Μόνο-ανάγνωση [`IColorFormat`](/slides/python-net/el/aspose.slides/icolorformat). |
| [`effect_style_index`](/slides/python-net/el/aspose.slides/ishapestyle/effect_style_index/) | Επιστρέφει ή ορίζει τον δείκτη στήλης εφέ του σχήματος σε ένα πλέγμα στυλ.<br/>            Ανάγνωση/εγγραφή **int**. |
| [`font_color`](/slides/python-net/el/aspose.slides/ishapestyle/font_color/) | Επιστρέφει το χρώμα γραμματοσειράς ενός σχήματος.<br/>            Μόνο-ανάγνωση [`IColorFormat`](/slides/python-net/el/aspose.slides/icolorformat). |
| [`font_collection_index`](/slides/python-net/el/aspose.slides/ishapestyle/font_collection_index/) | Επιστρέφει ή ορίζει το δείκτη γραμματοσειράς του σχήματος σε μια συλλογή γραμματοσειρών.<br/>            Ανάγνωση/εγγραφή [`FontCollectionIndex`](/slides/python-net/el/aspose.slides/fontcollectionindex). |
