## ISensitivityLabel κλάση

Αντιπροσωπεύει την ετικέτα ευαισθησίας από το Microsoft Purview Information Protection.

Ο τύπος ISensitivityLabel εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`id`](/slides/python-net/el/aspose.slides/isensitivitylabel/id/) | Επιστρέφει ή ορίζει το id της ετικέτας ευαισθησίας.<br/>            Ανάγνωση/εγγραφή **str**. |
| [`site_id`](/slides/python-net/el/aspose.slides/isensitivitylabel/site_id/) | Επιστρέφει ή ορίζει το αναγνωριστικό τοποθεσίας του Azure Active Directory (Azure AD) <br/>            που αντιστοιχεί στην πολιτική ετικέτας ευαισθησίας που περιγράφει την ετικέτα ευαισθησίας.<br/>            Ανάγνωση/εγγραφή **System.Guid**. |
| [`is_enabled`](/slides/python-net/el/aspose.slides/isensitivitylabel/is_enabled/) | Δείχνει αν η ετικέτα ευαισθησίας είναι ενεργοποιημένη. |
| [`is_removed`](/slides/python-net/el/aspose.slides/isensitivitylabel/is_removed/) | Δείχνει αν η ετικέτα ευαισθησίας αφαιρέθηκε. |
| [`assignment_method_type`](/slides/python-net/el/aspose.slides/isensitivitylabel/assignment_method_type/) | Επιστρέφει ή ορίζει τη μέθοδο ανάθεσης για την ετικέτα ευαισθησίας.<br/>            Ανάγνωση/εγγραφή [`SensitivityLabelAssignmentType`](/slides/python-net/el/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/el/aspose.slides/isensitivitylabel/content_mark_types/) | Επιστρέφει τη λίστα τύπων σήμανσης περιεχομένου που πρέπει να εφαρμοστούν σε ένα αρχείο. |
