## IPictureEffectiveData κλάση

Αμετάβλητο αντικείμενο που περιέχει τις αποτελεσματικές ιδιότητες της εικόνας.

Ο τύπος IPictureEffectiveData εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`image`](/slides/python-net/el/aspose.slides/ipictureeffectivedata/image/) | Επιστρέφει την ενσωματωμένη εικόνα.<br/>            Μόνο για ανάγνωση [`IPPImage`](/slides/python-net/el/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/el/aspose.slides/ipictureeffectivedata/link_path_long/) | Επιστρέφει τη διεύθυνση URL της συνδεδεμένης εικόνας.<br/>            Μόνο για ανάγνωση **str**. |
| [`image_transform`](/slides/python-net/el/aspose.slides/ipictureeffectivedata/image_transform/) | Επιστρέφει τη συλλογή των μετασχηματισμών εικόνας.<br/>            Μόνο για ανάγνωση [`IImageTransformOCollectionEffectiveData`](/slides/python-net/el/aspose.slides.effects/iimagetransformocollectioneffectivedata). |

### Παρατηρήσεις

Αυτή η διεπαφή χρησιμοποιείται ως μέρος του [`IPictureFillFormatEffectiveData`](/slides/python-net/el/aspose.slides/ipicturefillformateffectivedata) και [`IBulletFormatEffectiveData`](/slides/python-net/el/aspose.slides/ibulletformateffectivedata).
