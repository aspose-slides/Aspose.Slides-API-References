## add_vertical_content_placeholder(self, x, y, width, height) {#float-float-float-float}
Προσθέτει ένα νέο σχήμα placeholder στη διαφάνεια διάταξης για να διατηρεί περιεχόμενο, όπως εικόνα, πίνακας, πολυμέσα ή κείμενο σε κατακόρυφη κατεύθυνση.

### Επιστρέφει

Δημιουργήθηκε [`IAutoShape`](/slides/python-net/el/aspose.slides/iautoshape) με ένα Placeholder (Κατακόρυφο) placeholder.

```python
def add_vertical_content_placeholder(self, x, y, width, height):
    ...
```

| Παράμετρος | Τύπος | Περιγραφή |
| :- | :- | :- |
| x | **float** | Η συντεταγμένη X του νέου σχήματος placeholder. |
| y | **float** | Η συντεταγμένη Y του νέου σχήματος placeholder. |
| width | **float** | Το πλάτος του νέου σχήματος placeholder. |
| height | **float** | Το ύψος του νέου σχήματος placeholder. |
