Περιέχει κλάσεις που παρέχουν δυνατότητες AI για την ανάλυση και την επεξεργασία παρουσιάσεων PowerPoint.
## Κλάσεις

| Κλάση | Περιγραφή |
| :- | :- |
| [`AsposeAIWebClient`](/slides/python-net/el/aspose.slides.ai/asposeaiwebclient/) | Μία ενσωματωμένη υλοποίηση του [`IAIWebClient`](/slides/python-net/el/aspose.slides.ai/iaiwebclient) που συνδέεται με το δικό LLM της Aspose.<br/>            Αυτό είναι ο προεπιλεγμένος πελάτης που χρησιμοποιείται από τον κατασκευαστή **SlidesAIAgent.#ctor** χωρίς παραμέτρους. |
| [`IAIConversation`](/slides/python-net/el/aspose.slides.ai/iaiconversation/) | Αναπαριστά ένα στιγμιότυπο συζήτησης. Σε αντίθεση με τις κανονικές κλήσεις AI, οι συνομιλίες διατηρούν όλο το περιεχόμενο. |
| [`IAIWebClient`](/slides/python-net/el/aspose.slides.ai/iaiwebclient/) | Διεπαφή AI Web client. Αυτή η διεπαφή επιτρέπει την αντικατάσταση διαφορετικών μοντέλων γλώσσας AI.<br/>            Οι κλάσεις που υλοποιούν αυτή τη διεπαφή προορίζονται να χρησιμοποιηθούν μαζί με `SlidesAIAgent`. |
| [`OpenAICompatibleWebClient`](/slides/python-net/el/aspose.slides.ai/openaicompatiblewebclient/) | Μία ενσωματωμένη υλοποίηση του [`IAIWebClient`](/slides/python-net/el/aspose.slides.ai/iaiwebclient) που συνδέεται σε έναν παροχέα LLM συμβατό με OpenAI<br/>            σε μια καθορισμένη βασική διεύθυνση URL. |
| [`OpenAIWebClient`](/slides/python-net/el/aspose.slides.ai/openaiwebclient/) | Μία ενσωματωμένη υλοποίηση του [`IAIWebClient`](/slides/python-net/el/aspose.slides.ai/iaiwebclient) που συνδέεται στο OpenAI API. |
| [`SlidesAIAgent`](/slides/python-net/el/aspose.slides.ai/slidesaiagent/) | Παρέχει δυνατότητες με τεχνητή νοημοσύνη για την επεξεργασία παρουσιάσεων. |
| [`SlidesAIAgentException`](/slides/python-net/el/aspose.slides.ai/slidesaiagentexception/) | Αναπαριστά εξαιρέσεις που σχετίζονται με το Slides AI Agent. |

## Απαριθμήσεις

| Απαρίθμηση | Περιγραφή |
| :- | :- |
| [`PresentationContentAmountType`](/slides/python-net/el/aspose.slides.ai/presentationcontentamounttype/) | Καθορίζει την ποσότητα του περιεχομένου που περιλαμβάνεται στην παραγόμενη παρουσίαση, επηρεάζοντας τόσο τον αριθμό των διαφανειών όσο και το επίπεδο λεπτομέρειας ανά διαφάνεια. |
