## line_format ιδιότητα
Επιστρέφει το αντικείμενο LineFormat που περιέχει ιδιότητες μορφοποίησης γραμμής για ένα shape.
            Σημείωση: μπορεί να επιστρέψει None για ορισμένους τύπους σχήματος που δεν έχουν ιδιότητες γραμμής.
            Μόνο για ανάγνωση [`ILineFormat`](/slides/python-net/el/aspose.slides/ilineformat).
