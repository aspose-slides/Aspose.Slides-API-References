## bullet_fill_format ιδιότητα
Επιστρέφει το αντικείμενο FillFormat που περιέχει τις ιδιότητες διαμόρφωσης γεμίσματος για μια κουκίδα κόμβου.
            Σημείωση: μπορεί να επιστρέψει None για ορισμένους τύπους διάταξης SmartArt που δεν παρέχουν κουκίδες για κόμβους.
            Μόνο για ανάγνωση [`IFillFormat`](/slides/python-net/el/aspose.slides/ifillformat).
