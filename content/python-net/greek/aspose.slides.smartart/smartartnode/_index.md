## SmartArtNode κλάση

Αντιπροσωπεύει έναν κόμβο αντικειμένου SmartArt

Ο τύπος SmartArtNode εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Property | Description |
| :- | :- |
| [`child_nodes`](/slides/python-net/el/aspose.slides.smartart/smartartnode/child_nodes/) | Επιστρέφει συλλογές όλων των θυγατρικών κόμβων του τρέχοντος κόμβου.<br/>            Μόνο-ανάγνωση [`ISmartArtNodeCollection`](/slides/python-net/el/aspose.slides.smartart/ismartartnodecollection). |
| [`shapes`](/slides/python-net/el/aspose.slides.smartart/smartartnode/shapes/) | Επιστρέφει συλλογές όλων των σχημάτων που συσχετίζονται με τον κόμβο.<br/>            Μόνο-ανάγνωση [`ISmartArtShapeCollection`](/slides/python-net/el/aspose.slides.smartart/ismartartshapecollection). |
| [`text_frame`](/slides/python-net/el/aspose.slides.smartart/smartartnode/text_frame/) | Επιστρέφει το πλαίσιο κειμένου του κόμβου.<br/>            Μόνο-ανάγνωση [`ITextFrame`](/slides/python-net/el/aspose.slides/itextframe). |
| [`is_assistant`](/slides/python-net/el/aspose.slides.smartart/smartartnode/is_assistant/) | Επιστρέφει ή ορίζει τον κόμβο ως βοηθό.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`level`](/slides/python-net/el/aspose.slides.smartart/smartartnode/level/) | Επιστρέφει το επίπεδο εμφώλευσης του κόμβου.<br/>            Μόνο-ανάγνωση **int**. |
| [`bullet_fill_format`](/slides/python-net/el/aspose.slides.smartart/smartartnode/bullet_fill_format/) | Επιστρέφει το αντικείμενο FillFormat που περιέχει τις ιδιότητες μορφοποίησης γεμίσματος για τη σφαίρα κουκκίδας ενός κόμβου.<br/>            Σημείωση: μπορεί να επιστρέψει None για ορισμένους τύπους διάταξης SmartArt που δεν παρέχουν κουκκίδες για κόμβους.<br/>            Μόνο-ανάγνωση [`IFillFormat`](/slides/python-net/el/aspose.slides/ifillformat). |
| [`position`](/slides/python-net/el/aspose.slides.smartart/smartartnode/position/) | Επιστρέφει ή ορίζει τη θέση με μηδενική βάση του κόμβου μεταξύ των αδελφών κόμβων.<br/>            Ανάγνωση/εγγραφή **int**. |
| [`is_hidden`](/slides/python-net/el/aspose.slides.smartart/smartartnode/is_hidden/) | Επιστρέφει true εάν αυτός ο κόμβος είναι κρυμμένος στον μοντέλο δεδομένων.<br/>            Μόνο-ανάγνωση **bool**. |
| [`organization_chart_layout`](/slides/python-net/el/aspose.slides.smartart/smartartnode/organization_chart_layout/) | Επιστρέφει ή ορίζει τον τύπο διάταξης οργανωτικού διαγράμματος που σχετίζεται με τον τρέχοντα κόμβο.<br/>            Ανάγνωση/εγγραφή [`OrganizationChartLayoutType`](/slides/python-net/el/aspose.slides.smartart/organizationchartlayouttype). |
