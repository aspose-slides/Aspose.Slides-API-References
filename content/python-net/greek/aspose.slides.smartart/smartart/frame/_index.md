## ιδιότητα πλαισίου
Returns or sets the shape frame's properties.
            Ανάγνωση/Εγγραφή [`IShapeFrame`](/slides/python-net/el/aspose.slides/ishapeframe).

### Σημειώσεις

Η τιμή κάθε ιδιότητας του επιστρεφόμενου στιγμιότυπου IShapeFrame δεν είναι 
            απροσδιόριστη (δεν είναι NaN ή NotDefined).
Η τιμή κάθε ιδιότητας του εκχωρημένου στιγμιότυπου IShapeFrame πρέπει να μην είναι 
            απροσδιόριστη (πρέπει να μην είναι NaN ή NotDefined).
Μπορείτε να ορίσετε απροσδιόριστες τιμές για τις ιδιότητες του στιγμιότυπου RawFrame.
