## ISmartArtNode κλάση

Αντιπροσωπεύει έναν κόμβο διαγράμματος SmartArt.

Ο τύπος ISmartArtNode εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`child_nodes`](/slides/python-net/el/aspose.slides.smartart/ismartartnode/child_nodes/) | Επιστρέφει συλλογές όλων των παιδιών κόμβων του τρέχοντος κόμβου.<br/>            Μόνο για ανάγνωση [`ISmartArtNodeCollection`](/slides/python-net/el/aspose.slides.smartart/ismartartnodecollection). |
| [`shapes`](/slides/python-net/el/aspose.slides.smartart/ismartartnode/shapes/) | Επιστρέφει συλλογές όλων των σχημάτων που συνδέονται με τον κόμβο.<br/>            Μόνο για ανάγνωση [`ISmartArtShapeCollection`](/slides/python-net/el/aspose.slides.smartart/ismartartshapecollection). |
| [`text_frame`](/slides/python-net/el/aspose.slides.smartart/ismartartnode/text_frame/) | Επιστρέφει ή ορίζει το κείμενο του κόμβου.<br/>            Μόνο για ανάγνωση [`ITextFrame`](/slides/python-net/el/aspose.slides/itextframe). |
| [`is_assistant`](/slides/python-net/el/aspose.slides.smartart/ismartartnode/is_assistant/) | Επιστρέφει ή ορίζει τον κόμβο ως βοηθό.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`level`](/slides/python-net/el/aspose.slides.smartart/ismartartnode/level/) | Επιστρέφει το επίπεδο εμφώλευσης του κόμβου.<br/>            Μόνο για ανάγνωση **int**. |
| [`bullet_fill_format`](/slides/python-net/el/aspose.slides.smartart/ismartartnode/bullet_fill_format/) | Επιστρέφει το αντικείμενο FillFormat που περιέχει τις ιδιότητες μορφοποίησης γεμίσματος για τη σφαίρα ενός κόμβου.<br/>            Σημείωση: μπορεί να επιστρέψει None για ορισμένους τύπους διάταξης SmartArt που δεν παρέχουν σφαίρες για κόμβους.<br/>            Μόνο για ανάγνωση [`IFillFormat`](/slides/python-net/el/aspose.slides/ifillformat). |
| [`position`](/slides/python-net/el/aspose.slides.smartart/ismartartnode/position/) | Επιστρέφει ή ορίζει τη θέση μηδενικής βάσης του κόμβου μεταξύ των αδερφικών κόμβων.<br/>            Ανάγνωση/εγγραφή **int**. |
| [`is_hidden`](/slides/python-net/el/aspose.slides.smartart/ismartartnode/is_hidden/) | Επιστρέφει true εάν αυτός ο κόμβος είναι κρυφός στον μοντέλο δεδομένων.<br/>            Μόνο για ανάγνωση **bool**. |
| [`organization_chart_layout`](/slides/python-net/el/aspose.slides.smartart/ismartartnode/organization_chart_layout/) | Επιστρέφει ή ορίζει τον τύπο διάταξης διαγράμματος οργάνωσης που σχετίζεται με τον τρέχοντα κόμβο.<br/>            Ανάγνωση/εγγραφή [`OrganizationChartLayoutType`](/slides/python-net/el/aspose.slides.smartart/organizationchartlayouttype). |
