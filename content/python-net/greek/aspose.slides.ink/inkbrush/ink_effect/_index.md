## ink_effect ιδιότητα
Gets the ink effect type (e.g., Galaxy, Gold, Silver) that defines the visual style of the ink stroke.
            The value is parsed from the brush ιδιότητα "inkEffects". If no recognized effect is specified,
            [`InkEffectType.NOT_DEFINED`](/slides/python-net/el/aspose.slides.ink/inkeffecttype/NOT_DEFINED) is returned.
