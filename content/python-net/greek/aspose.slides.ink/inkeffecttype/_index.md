## InkEffectType απαρίθμηση

Καθορίζει ένα σύνολο προεγκατεστημένων οπτικών εφέ για την απόδοση μελάνης.  
Κάθε εφέ αντιστοιχεί σε μια υφή ή εικόνα που προσομοιώνει μια στιλιζαρισμένη εμφάνιση μελάνης.  
Αυτές οι τιμές μπορούν να χρησιμοποιηθούν για να προσαρμόσουν το οπτικό στυλ των ψηφιακών γραμμών μελάνης κατά την απόδοση.

Ο τύπος InkEffectType εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| NOT_DEFINED | Το εφέ δεν είναι ορισμένο ή είναι άγνωστο. Αυτή η τιμή μπορεί να χρησιμοποιηθεί ως προεπιλογή ή εφεδρική επιλογή. |
| BRONZE | Μια ζεστή, καφετί μεταλλική υφή που θυμίζει μελάνη χάλκου. |
| GALAXY | Μια πολύχρωμη, λαμπρή υφή που θυμίζει γαλαξία, με κοσμικούς τόνους. |
| GOLD | Μια φωτεινή, μεταλλική χρυσή υφή που δίνει στις γραμμές μελάνης μια πολυτελή εμφάνιση. |
| LAVA | Μια φουρτουνωτή υφή που θυμίζει τρεχούμενο λάβα, με κόκκινες και πορτοκαλί αποχρώσεις. |
| OCEAN | Μια βαθύ μπλε, ρευστή υφή που μιμείται τα κύματα του ωκεανού ή τη μελάνη υδατικού τύπου. |
| RAINBOW_GLITTER | Ένα πολύχρωμο, λαμπερό εφέ διαμαντιού ουράνιου τόξου που χρησιμοποιείται για εορταστικές ή ζωντανές γραμμές μελάνης. |
| ROSE_GOLD | Μια απαλή μείγμα ροζ-χρυσού, παρόμοιο με ροζ χρυσό, για κομψές γραμμές μελάνης. |
| SILVER | Μια ψυχρή, μεταλλική ασημένια υφή που προσομοιώνει κλασική ασημένια μελάνη. |
