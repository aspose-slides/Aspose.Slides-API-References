## ιδιότητα frame
Επιστρέφει ή ορίζει τις ιδιότητες του πλαισίου σχήματος.
            Ανάγνωση/εγγραφή [`IShapeFrame`](/slides/python-net/el/aspose.slides/ishapeframe).

### Σχόλια
Η τιμή κάθε ιδιότητας της επιστρεφόμενης IShapeFrame δεν είναι undefined (δεν είναι NaN ή NotDefined).
            Η τιμή κάθε ιδιότητας της εκχωρημένης IShapeFrame πρέπει να μην είναι undefined (πρέπει να μην είναι NaN ή NotDefined).
            Μπορείτε να ορίσετε τιμές undefined για τις ιδιότητες της εμφάνισης RawFrame.
