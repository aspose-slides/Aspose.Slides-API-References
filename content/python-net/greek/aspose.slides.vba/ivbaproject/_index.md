## IVbaProject κλάση

Αναπαριστά το έργο VBA με μακροεντολές παρουσίασης.

Ο τύπος IVbaProject εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`name`](/slides/python-net/el/aspose.slides.vba/ivbaproject/name/) | Επιστρέφει το όνομα του έργου VBA.<br/>            Μόνο για ανάγνωση **str**. |
| [`modules`](/slides/python-net/el/aspose.slides.vba/ivbaproject/modules/) | Επιστρέφει τη λίστα όλων των μονάδων που περιλαμβάνονται στο έργο VBA.<br/>            Μόνο για ανάγνωση [`IVbaModuleCollection`](/slides/python-net/el/aspose.slides.vba/ivbamodulecollection). |
| [`references`](/slides/python-net/el/aspose.slides.vba/ivbaproject/references/) | Επιστρέφει τη λίστα όλων των αναφορών που περιλαμβάνονται στο έργο VBA.<br/>            Μόνο για ανάγνωση [`IVbaReferenceCollection`](/slides/python-net/el/aspose.slides.vba/ivbareferencecollection). |
| [`is_password_protected`](/slides/python-net/el/aspose.slides.vba/ivbaproject/is_password_protected/) | Δείχνει εάν το VBAProject προστατεύεται με κωδικό πρόσβασης για την προβολή των ιδιοτήτων του έργου.<br/>            Μόνο για ανάγνωση **bool**. |

## Μέθοδοι

| Μέθοδος | Περιγραφή |
| :- | :- |
| [`to_binary(self)`](/slides/python-net/el/aspose.slides.vba/ivbaproject/to_binary/#) | Επιστρέφει την δυαδική αναπαράσταση του έργου VBA ως κοντέινερ OLE.<br/>            Μόνο για ανάγνωση **int**[]. |
