## VbaProject κλάση

Αντιπροσωπεί ένα έργο VBA με μακροεντολές παρουσίασης.

Ο τύπος VbaProject εκθέτει τα παρακάτω μέλη:

## Κατασκευαστές

| Κατασκευαστής | Περιγραφή |
| :- | :- |
| [`__init__(self)`](/slides/python-net/el/aspose.slides.vba/vbaproject/__init__/#) | Αυτός ο κατασκευαστής δημιουργεί νέο έργο VBA από την αρχή.<br/>            Το έργο θα δημιουργηθεί με κωδικοσελίδα 1252 Windows Latin 1 (ANSI) |
| [`__init__(self, data)`](/slides/python-net/el/aspose.slides.vba/vbaproject/__init__/#bytes) | Αυτός ο κατασκευαστής φορτώνει έργο VBA από δυαδική αναπαράσταση του κουβώτιου OLE. |

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`name`](/slides/python-net/el/aspose.slides.vba/vbaproject/name/) | Επιστρέφει το όνομα του έργου VBA.<br/>            Μόνο για ανάγνωση **str**. |
| [`modules`](/slides/python-net/el/aspose.slides.vba/vbaproject/modules/) | Επιστρέφει τη λίστα όλων των μονάδων που περιέχονται στο έργο VBA.<br/>            Μόνο για ανάγνωση [`IVbaModuleCollection`](/slides/python-net/el/aspose.slides.vba/ivbamodulecollection). |
| [`references`](/slides/python-net/el/aspose.slides.vba/vbaproject/references/) | Επιστρέφει τη λίστα όλων των παραπομπών που περιέχονται στο έργο VBA.<br/>            Μόνο για ανάγνωση [`IVbaReferenceCollection`](/slides/python-net/el/aspose.slides.vba/ivbareferencecollection). |
| [`is_password_protected`](/slides/python-net/el/aspose.slides.vba/vbaproject/is_password_protected/) | Δηλώνει εάν το VBAProject είναι προστατευμένο με κωδικό πρόσβασης για προβολή ιδιοτήτων του έργου.<br/>            Μόνο για ανάγνωση **bool**. |
