## AfterAnimationType απαρίθμηση

Αντιπροσωπεύει τον τύπο μετά την κίνηση ενός εφέ κίνησης.

Ο τύπος AfterAnimationType εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| DO_NOT_DIM | Να μην μειώνεται η φωτεινότητα μετά το animation. |
| COLOR | Χρώμα μετά το animation. |
| HIDE_AFTER_ANIMATION | Απόκρυψη μετά το animation. |
| HIDE_ON_NEXT_MOUSE_CLICK | Απόκρυψη με το επόμενο κλικ του ποντικιού μετά το animation. |
