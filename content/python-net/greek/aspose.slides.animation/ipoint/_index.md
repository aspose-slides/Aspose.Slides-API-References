## IPoint κλάση

Αντιπροσωπεύει σημείο animation.

Ο τύπος IPoint εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`time`](/slides/python-net/el/aspose.slides.animation/ipoint/time/) | Αντιπροσωπεύει την τιμή χρόνου.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`value`](/slides/python-net/el/aspose.slides.animation/ipoint/value/) | Αντιπροσωπεύει την τιμή σημείου.<br/>            Μόνο: bool, ColorFormat, float, int, string.<br/>            Ανάγνωση/εγγραφή **any**. |
| [`formula`](/slides/python-net/el/aspose.slides.animation/ipoint/formula/) | Οι τύποι εντός των τιμών, των χαρακτηριστικών from, to, by μπορούν να αποτελούνται από τα παρακάτω:<br/>            Τυπικοί αριθμητικοί τελεστές: ‘+’, ‘-‘, ‘*’, ‘/’, ‘^’, ‘%’ (mod)<br/>            Σταθερές: ‘pi’ ‘e’<br/>            Συνθήκες τελεστές: ‘abs’, ‘min’, ‘max’, ‘?’ (if)<br/>            Τελεστές σύγκρισης: '==', '>=', '', '!=', '!'<br/>            Τριγωνομετρικοί τελεστές: ‘sin()’, ‘cos()’, ‘tan()’, ‘asin()’, ‘acos()’, ‘atan()’<br/>            Φυσικός λογάριθμος ‘ln()’<br/>            Αναφορές ιδιοτήτων (host supported properties)<br/>            <br/>            για παράδειγμα: "#ppt_x+(cos(-2*pi*(1-$))*-#ppt_x-sin(-2*pi*(1-$))*(1-#ppt_y))*(1-$)"<br/>            Ανάγνωση/εγγραφή **str**. |
