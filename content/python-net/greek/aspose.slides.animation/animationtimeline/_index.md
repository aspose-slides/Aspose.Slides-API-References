## AnimationTimeLine κλάση

Αναπαριστά τη χρονογραμμή της κίνησης.

Ο τύπος AnimationTimeLine εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`interactive_sequences`](/slides/python-net/el/aspose.slides.animation/animationtimeline/interactive_sequences/) | Επιστρέφει τη συλλογή των διαδραστικών ακολουθιών.<br/>            Αυτές οι ακολουθίες μπορεί να περιέχουν μόνο εφέ με «click on shape» που καθορίζει το σχήμα-στόχο.<br/>            Μόνο για ανάγνωση [`ISequenceCollection`](/slides/python-net/el/aspose.slides.animation/isequencecollection). |
| [`main_sequence`](/slides/python-net/el/aspose.slides.animation/animationtimeline/main_sequence/) | Επιστρέφει την κύρια ακολουθία που μπορεί να περιέχει μόνο τη συλλογή κύριας εφέ.<br/>            Μόνο για ανάγνωση [`ISequence`](/slides/python-net/el/aspose.slides.animation/isequence). |
| [`text_animation_collection`](/slides/python-net/el/aspose.slides.animation/animationtimeline/text_animation_collection/) | Επιστρέφει τη συλλογή των κειμενικών κινούμενων γραφικών.<br/>            Μόνο για ανάγνωση [`ITextAnimationCollection`](/slides/python-net/el/aspose.slides.animation/itextanimationcollection). |
