## BehaviorCollection κλάση

Αναπαριστά μια συλλογή από εφέ συμπεριφοράς.

Ο τύπος BehaviorCollection εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`count`](/slides/python-net/el/aspose.slides.animation/behaviorcollection/count/) | Επιστρέφει τον αριθμό των συμπεριφορών σε μια συλλογή.<br/>            μόνο ανάγνωση **int**. |
| [`is_read_only`](/slides/python-net/el/aspose.slides.animation/behaviorcollection/is_read_only/) | Λαμβάνει μια τιμή που υποδεικνύει εάν το **System.Collections.Generic.ICollection`1** είναι μόνο ανάγνωση.<br/>            μόνο ανάγνωση **bool**. |

Επιστρέφει μια συμπεριφορά στον καθορισμένο δείκτη.
