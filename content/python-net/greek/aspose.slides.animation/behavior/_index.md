## Κλάση Behavior

Αντιπροσωπεύει τη βασική συμπεριφορά κλάσης του εφέ.

Ο τύπος Behavior εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`accumulate`](/slides/python-net/el/aspose.slides.animation/behavior/accumulate/) | Αναπαριστά εάν οι συμπεριφορές κίνησης είναι συσσωρευμένες.<br/>            Ανάγνωση/εγγραφή [`NullableBool`](/slides/python-net/el/aspose.slides/nullablebool). |
| [`additive`](/slides/python-net/el/aspose.slides.animation/behavior/additive/) | Αναπαριστά εάν η τρέχουσα συμπεριφορά κίνησης συνδυάζεται με άλλες ενεργές κινήσεις.<br/>            Ανάγνωση/εγγραφή [`BehaviorAdditiveType`](/slides/python-net/el/aspose.slides.animation/behavioradditivetype). |

| [`timing`](/slides/python-net/el/aspose.slides.animation/behavior/timing/) | Αναπαριστά τις χρονικές ιδιότητες για τη συμπεριφορά του εφέ.<br/>            Ανάγνωση/εγγραφή [`ITiming`](/slides/python-net/el/aspose.slides.animation/itiming). |
