## IMotionEffect κλάση

Αναπαριστά τη συμπεριφορά του εφέ κίνησης του εφέ.

Ο τύπος IMotionEffect εκθέτει τα ακόλουθα μέλη:

| [`from_address`](/slides/python-net/el/aspose.slides.animation/imotioneffect/from_address/) | Καθορίζει μια συντεταγμένη x/y για έναρξη της animation από (σε ποσοστό). <br/>            Ανάγνωση/εγγραφή **aspose.slides.PointF**. |
| [`to`](/slides/python-net/el/aspose.slides.animation/imotioneffect/to/) | Καθορίζει τη θέση στόχο για ένα εφέ κίνησης animation (σε ποσοστό).<br/>            Ανάγνωση/εγγραφή **aspose.slides.PointF**. |
| [`by`](/slides/python-net/el/aspose.slides.animation/imotioneffect/by/) | Περιγράφει τη σχετική τιμή offset για την animation (σε ποσοστό).<br/>            Ανάγνωση/εγγραφή **aspose.slides.PointF**. |
