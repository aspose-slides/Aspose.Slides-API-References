## IColorEffect κλάση

Αντιπροσωπεύει ένα εφέ χρώματος για μια κίνηση συμπεριφοράς.

Ο τύπος IColorEffect εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`from_address`](/slides/python-net/el/aspose.slides.animation/icoloreffect/from_address/) | Αυτή η τιμή χρησιμοποιείται για τον καθορισμό του αρχικού χρώματος της συμπεριφοράς.<br/>            Ανάγνωση/εγγραφή [`IColorFormat`](/slides/python-net/el/aspose.slides/icolorformat). |
| [`to`](/slides/python-net/el/aspose.slides.animation/icoloreffect/to/) | Περιγράφει το τελικό χρώμα για την αλλαγή χρώματος της κίνησης.<br/>            Ανάγνωση/εγγραφή [`IColorFormat`](/slides/python-net/el/aspose.slides/icolorformat). |
| [`by`](/slides/python-net/el/aspose.slides.animation/icoloreffect/by/) | Περιγράφει τη σχετική τιμή μετατόπισης για την κίνηση χρώματος.<br/>            Ανάγνωση/εγγραφή [`IColorOffset`](/slides/python-net/el/aspose.slides.animation/icoloroffset). |
| [`color_space`](/slides/python-net/el/aspose.slides.animation/icoloreffect/color_space/) | Αντιπροσωπεύει το χώρο χρώματος της συμπεριφοράς.<br/>            Ανάγνωση/εγγραφή [`IColorEffect.color_space`](/slides/python-net/el/aspose.slides.animation/icoloreffect/color_space). |
