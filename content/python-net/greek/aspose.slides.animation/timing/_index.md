## Timing κλάση

Αναπαριστά το χρονισμό της κίνησης.

Ο τύπος Timing εμφανίζει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`accelerate`](/slides/python-net/el/aspose.slides.animation/timing/accelerate/) | Περιγράφει το ποσοστό του χρόνου της επιτάχυνσης.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`decelerate`](/slides/python-net/el/aspose.slides.animation/timing/decelerate/) | Περιγράφει το ποσοστό του χρόνου της επιβράδυνσης.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`auto_reverse`](/slides/python-net/el/aspose.slides.animation/timing/auto_reverse/) | Περιγράφει αν θα αναπαράγεται αυτόματα η κίνηση ανάποδα μετά<br/>            την αναπαραγωγή της προς τα εμπρός.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`duration`](/slides/python-net/el/aspose.slides.animation/timing/duration/) | Περιγράφει τη διάρκεια του εφέ κίνησης.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`repeat_count`](/slides/python-net/el/aspose.slides.animation/timing/repeat_count/) | Περιγράφει τον αριθμό των επαναλήψεων του εφέ.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`repeat_until_end_slide`](/slides/python-net/el/aspose.slides.animation/timing/repeat_until_end_slide/) | Αυτό το χαρακτηριστικό καθορίζει εάν το εφέ θα επαναλαμβάνεται μέχρι το τέλος της διαφάνειας.<br/>             Ανάγνωση/εγγραφή **bool**. |
| [`repeat_until_next_click`](/slides/python-net/el/aspose.slides.animation/timing/repeat_until_next_click/) | Αυτό το χαρακτηριστικό καθορίζει εάν το εφέ θα επαναληφθεί μέχρι το επόμενο κλικ.<br/>             Ανάγνωση/εγγραφή **bool**. |
| [`repeat_duration`](/slides/python-net/el/aspose.slides.animation/timing/repeat_duration/) | Περιγράφει τον αριθμό των επαναλήψεων του εφέ.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`restart`](/slides/python-net/el/aspose.slides.animation/timing/restart/) | Καθορίζει εάν ένα εφέ θα επανεκκινήσει μετά την ολοκλήρωση.<br/>            Ανάγνωση/εγγραφή [`EffectRestartType`](/slides/python-net/el/aspose.slides.animation/effectrestarttype). |
| [`rewind`](/slides/python-net/el/aspose.slides.animation/timing/rewind/) | Αυτό το χαρακτηριστικό καθορίζει εάν το εφέ θα γίνει επαναφορά όταν ολοκληρωθεί η αναπαραγωγή.<br/>             Ανάγνωση/εγγραφή **bool**. |
| [`speed`](/slides/python-net/el/aspose.slides.animation/timing/speed/) | Καθορίζει το ποσοστό με το οποίο θα επιταχυνθεί (ή θα επιβραδυνθεί) ο χρονισμός.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`trigger_delay_time`](/slides/python-net/el/aspose.slides.animation/timing/trigger_delay_time/) | Περιγράφει το χρόνο καθυστέρησης μετά το ενεργοποιητή.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`trigger_type`](/slides/python-net/el/aspose.slides.animation/timing/trigger_type/) | Περιγράφει τον τύπο του ενεργοποιητή.<br/>            Ανάγνωση/εγγραφή [`EffectTriggerType`](/slides/python-net/el/aspose.slides.animation/effecttriggertype). |
