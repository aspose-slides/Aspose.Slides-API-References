## Effect κλάση

Αντιπροσωπεύει το εφέ κίνησης.

Ο τύπος Effect εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`sequence`](/slides/python-net/el/aspose.slides.animation/effect/sequence/) | Επιστρέφει μια ακολουθία για ένα εφέ.<br/>            Μόνο για ανάγνωση [`ISequence`](/slides/python-net/el/aspose.slides.animation/isequence). |
| [`text_animation`](/slides/python-net/el/aspose.slides.animation/effect/text_animation/) | TextAnimation<br/>            Μόνο για ανάγνωση [`ITextAnimation`](/slides/python-net/el/aspose.slides.animation/itextanimation). |
| [`preset_class_type`](/slides/python-net/el/aspose.slides.animation/effect/preset_class_type/) | Ορίζει την κλάση του εφέ.<br/>            Ανάγνωση/Εγγραφή [`EffectPresetClassType`](/slides/python-net/el/aspose.slides.animation/effectpresetclasstype). |
| [`type`](/slides/python-net/el/aspose.slides.animation/effect/type/) | Ορίζει τον τύπο του εφέ.<br/>            Ανάγνωση/Εγγραφή [`EffectType`](/slides/python-net/el/aspose.slides.animation/effecttype). |
| [`subtype`](/slides/python-net/el/aspose.slides.animation/effect/subtype/) | Ορίζει το υποτύπο του εφέ.<br/>            Ανάγνωση/Εγγραφή [`EffectSubtype`](/slides/python-net/el/aspose.slides.animation/effectsubtype). |
| [`behaviors`](/slides/python-net/el/aspose.slides.animation/effect/behaviors/) | Επιστρέφει τη συλλογή συμπεριφορών για το εφέ.<br/>            Ανάγνωση/Εγγραφή [`IBehaviorCollection`](/slides/python-net/el/aspose.slides.animation/ibehaviorcollection). |
| [`timing`](/slides/python-net/el/aspose.slides.animation/effect/timing/) | Ορίζει την τιμή χρόνου για το εφέ.<br/>            Ανάγνωση/Εγγραφή [`ITiming`](/slides/python-net/el/aspose.slides.animation/itiming). |
| [`target_shape`](/slides/python-net/el/aspose.slides.animation/effect/target_shape/) | Επιστρέφει το σχήμα-στόχο για το εφέ.<br/>            Μόνο για ανάγνωση [`IShape`](/slides/python-net/el/aspose.slides/ishape). |
| [`sound`](/slides/python-net/el/aspose.slides.animation/effect/sound/) | Καθορίζει ενσωματωμένο ήχο για το εφέ.<br/>            Ανάγνωση/Εγγραφή [`IAudio`](/slides/python-net/el/aspose.slides/iaudio). |
| [`stop_previous_sound`](/slides/python-net/el/aspose.slides.animation/effect/stop_previous_sound/) | Αυτό το χαρακτηριστικό καθορίζει εάν το εφέ animation σταματά τον προηγούμενο ήχο.<br/>            Ανάγνωση/Εγγραφή **bool**. |
| [`after_animation_type`](/slides/python-net/el/aspose.slides.animation/effect/after_animation_type/) | Ορίζει τον τύπο after animation για το εφέ.<br/>            Ανάγνωση/Εγγραφή [`Effect.after_animation_type`](/slides/python-net/el/aspose.slides.animation/effect/after_animation_type). |
| [`after_animation_color`](/slides/python-net/el/aspose.slides.animation/effect/after_animation_color/) | Ορίζει το χρώμα after animation για το εφέ.<br/>            Ανάγνωση/Εγγραφή [`IColorFormat`](/slides/python-net/el/aspose.slides/icolorformat). |
| [`animate_text_type`](/slides/python-net/el/aspose.slides.animation/effect/animate_text_type/) | Ορίζει τον τύπο animate text για το εφέ.<br/>            Το κείμενο του σχήματος μπορεί να αναπαράγεται ανά γράμμα, ανά λέξη ή ολόκληρο ταυτόχρονα.<br/>            Ανάγνωση/Εγγραφή [`Effect.animate_text_type`](/slides/python-net/el/aspose.slides.animation/effect/animate_text_type). |
| [`delay_between_text_parts`](/slides/python-net/el/aspose.slides.animation/effect/delay_between_text_parts/) | Ορίζει καθυστέρηση μεταξύ των τμημάτων του κειμένου animation (λέξεις ή γράμματα).<br/>            Μία θετική τιμή καθορίζει το ποσοστό της διάρκειας του εφέ.<br/>            Μία αρνητική τιμή καθορίζει την καθυστέρηση σε δευτερόλεπτα.<br/>            Ανάγνωση/Εγγραφή **float**. |
