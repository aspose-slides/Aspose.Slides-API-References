## ITiming κλάση

Αντιπροσωπεύει τον χρόνο του animation.

Ο τύπος ITTiming εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`accelerate`](/slides/python-net/el/aspose.slides.animation/itiming/accelerate/) | Περιγράφει το ποσοστό της διάρκειας που επηρεάζει την επιτάχυνση.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`decelerate`](/slides/python-net/el/aspose.slides.animation/itiming/decelerate/) | Περιγράφει το ποσοστό της διάρκειας που επηρεάζει την επιβράδυνση.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`auto_reverse`](/slides/python-net/el/aspose.slides.animation/itiming/auto_reverse/) | Περιγράφει εάν θα αναπαραχθεί αυτόματα το animation σε αντίστροφη κατεύθυνση μετά την αναπαραγωγή του προς τα εμπρός.<br/>            Ανάγνωση/Εγγραφή **bool**. |
| [`duration`](/slides/python-net/el/aspose.slides.animation/itiming/duration/) | Περιγράφει τη διάρκεια του εφέ animation.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`repeat_count`](/slides/python-net/el/aspose.slides.animation/itiming/repeat_count/) | Περιγράφει τον αριθμό των φορών που πρέπει να επαναληφθεί το εφέ.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`repeat_until_end_slide`](/slides/python-net/el/aspose.slides.animation/itiming/repeat_until_end_slide/) | Αυτό το χαρακτηριστικό καθορίζει εάν το εφέ θα επαναληφθεί μέχρι το τέλος της διαφάνειας.<br/>             Ανάγνωση/Εγγραφή **bool**. |
| [`repeat_until_next_click`](/slides/python-net/el/aspose.slides.animation/itiming/repeat_until_next_click/) | Αυτό το χαρακτηριστικό καθορίζει εάν το εφέ θα επαναληφθεί μέχρι το επόμενο κλικ.<br/>             Ανάγνωση/Εγγραφή **bool**. |
| [`repeat_duration`](/slides/python-net/el/aspose.slides.animation/itiming/repeat_duration/) | Περιγράφει τον αριθμό των φορών που πρέπει να επαναληφθεί το εφέ.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`restart`](/slides/python-net/el/aspose.slides.animation/itiming/restart/) | Καθορίζει εάν ένα εφέ θα επανεκκινήσει μετά την ολοκλήρωση.<br/>            Ανάγνωση/Εγγραφή [`EffectRestartType`](/slides/python-net/el/aspose.slides.animation/effectrestarttype). |
| [`speed`](/slides/python-net/el/aspose.slides.animation/itiming/speed/) | Καθορίζει το ποσοστό με το οποίο θα επιταχυνθεί (ή θα επιβραδυνθεί) ο χρόνος.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`trigger_delay_time`](/slides/python-net/el/aspose.slides.animation/itiming/trigger_delay_time/) | Περιγράφει τον χρόνο καθυστέρησης μετά το trigger.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`trigger_type`](/slides/python-net/el/aspose.slides.animation/itiming/trigger_type/) | Περιγράφει τον τύπο του trigger.<br/>            Ανάγνωση/Εγγραφή [`EffectTriggerType`](/slides/python-net/el/aspose.slides.animation/effecttriggertype). |
| [`rewind`](/slides/python-net/el/aspose.slides.animation/itiming/rewind/) | Αυτό το χαρακτηριστικό καθορίζει εάν το εφέ θα επανέλθει στην αρχή όταν ολοκληρωθεί η αναπαραγωγή.<br/>             Ανάγνωση/Εγγραφή **bool**. |
