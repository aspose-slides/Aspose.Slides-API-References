## BuildType απαρίθμηση

Καθορίζει πώς το κείμενο θα εμφανίζεται σε ένα σχήμα κατά τη διάρκεια της κίνησης.

Ο τύπος BuildType εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| AS_ONE_OBJECT | Με το περιέχον σχήμα. |
| ALL_PARAGRAPHS_AT_ONCE | Όλες οι παράγραφοι. |
| BY_LEVEL_PARAGRAPHS1 | Κατά ομάδες παραγράφων βάθους 1. |
| BY_LEVEL_PARAGRAPHS2 | Κατά ομάδες παραγράφων βάθους 2. |
| BY_LEVEL_PARAGRAPHS3 | Κατά ομάδες παραγράφων βάθους 3. |
| BY_LEVEL_PARAGRAPHS4 | Κατά ομάδες παραγράφων βάθους 4. |
| BY_LEVEL_PARAGRAPHS5 | Κατά ομάδες παραγράφων βάθους 5. |
