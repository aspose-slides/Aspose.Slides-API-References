## IBehavior κλάση

Αναπαριστά τη συμπεριφορά της βασικής κλάσης του εφέ.

Ο τύπος IBehavior εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`accumulate`](/slides/python-net/el/aspose.slides.animation/ibehavior/accumulate/) | Αντιπροσωπεύει εάν οι συμπεριφορές animation συσσωρεύονται.<br/>            Ανάγνωση/εγγραφή [`NullableBool`](/slides/python-net/el/aspose.slides/nullablebool). |
| [`additive`](/slides/python-net/el/aspose.slides.animation/ibehavior/additive/) | Αντιπροσωπεύει εάν η τρέχουσα συμπεριφορά animation συνδυάζεται με άλλες ενεργές animations.<br/>            Ανάγνωση/εγγραφή [`BehaviorAdditiveType`](/slides/python-net/el/aspose.slides.animation/behavioradditivetype). |
| [`properties`](/slides/python-net/el/aspose.slides.animation/ibehavior/properties/) | Αντιπροσωπεύει τις ιδιότητες της συμπεριφοράς.<br/>            Μόνο ανάγνωση [`IBehaviorPropertyCollection`](/slides/python-net/el/aspose.slides.animation/ibehaviorpropertycollection). |
| [`timing`](/slides/python-net/el/aspose.slides.animation/ibehavior/timing/) | Αντιπροσωπεύει τις ιδιότητες χρονισμού για τη συμπεριφορά του εφέ.<br/>            Ανάγνωση/εγγραφή [`ITiming`](/slides/python-net/el/aspose.slides.animation/itiming). |
