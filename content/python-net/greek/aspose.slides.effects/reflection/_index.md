## Reflection κλάση

Αναπαριστά ένα εφέ Reflection.

Ο τύπος Reflection εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/el/aspose.slides.effects/reflection/start_pos_alpha/) | Καθορίζει τη θέση εκκίνησης (κατά μήκος της κλίμακας διαβάθμισης άλφα) της αρχικής τιμής άλφα (ποσοστά).<br/>            Ανάγνωση/εγγραφή **float**. |
| [`end_pos_alpha`](/slides/python-net/el/aspose.slides.effects/reflection/end_pos_alpha/) | Καθορίζει τη θέση λήξης (κατά μήκος της κλίμακας διαβάθμισης άλφα) της τελικής τιμής άλφα (ποσοστά).<br/>            Ανάγνωση/εγγραφή **float**. |
| [`fade_direction`](/slides/python-net/el/aspose.slides.effects/reflection/fade_direction/) | Καθορίζει την κατεύθυνση για την μετατόπιση της αντανάκλασης. (γωνία).<br/>            Ανάγνωση/εγγραφή **float**. |
| [`start_reflection_opacity`](/slides/python-net/el/aspose.slides.effects/reflection/start_reflection_opacity/) | Αρχική αδιαφάνεια αντανάκλασης. (ποσοστά).<br/>            Ανάγνωση/εγγραφή **float**. |
| [`end_reflection_opacity`](/slides/python-net/el/aspose.slides.effects/reflection/end_reflection_opacity/) | Τελική αδιαφάνεια αντανάκλασης. (ποσοστά).<br/>            Ανάγνωση/εγγραφή **float**. |
| [`blur_radius`](/slides/python-net/el/aspose.slides.effects/reflection/blur_radius/) | Ακτίνα θολώματος.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`direction`](/slides/python-net/el/aspose.slides.effects/reflection/direction/) | Κατεύθυνση αντανάκλασης.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`distance`](/slides/python-net/el/aspose.slides.effects/reflection/distance/) | Απόσταση αντανάκλασης.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`rectangle_align`](/slides/python-net/el/aspose.slides.effects/reflection/rectangle_align/) | Στοίχιση ορθογωνίου.<br/>            Ανάγνωση/εγγραφή [`RectangleAlignment`](/slides/python-net/el/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/el/aspose.slides.effects/reflection/skew_horizontal/) | Καθορίζει τη γωνία οριζόντιας παραμόρφωσης.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`skew_vertical`](/slides/python-net/el/aspose.slides.effects/reflection/skew_vertical/) | Καθορίζει τη γωνία κατακόρυφης παραμόρφωσης.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/el/aspose.slides.effects/reflection/rotate_shadow_with_shape/) | Καθορίζει εάν η αντανάκλαση πρέπει να περιστρέφεται μαζί με το σχήμα αν το σχήμα περιστραφεί.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`scale_horizontal`](/slides/python-net/el/aspose.slides.effects/reflection/scale_horizontal/) | Καθορίζει το οριζόντιο συντελεστή κλίμακας, η αρνητική κλίμακα προκαλεί αντιστροφή. (ποσοστά)<br/>            Ανάγνωση/εγγραφή **float**. |
| [`scale_vertical`](/slides/python-net/el/aspose.slides.effects/reflection/scale_vertical/) | Καθορίζει το κατακόρυφο συντελεστή κλίμακας, η αρνητική κλίμακα προκαλεί αντιστροφή. (ποσοστά)<br/>            Ανάγνωση/εγγραφή **float**. |
