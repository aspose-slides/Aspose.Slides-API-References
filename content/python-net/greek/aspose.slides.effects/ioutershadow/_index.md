## IOuterShadow κλάση

Αντιπροσωπεύει ένα εφέ Εξωτερικής Σκιάς.

Ο τύπος IOuterShadow εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`blur_radius`](/slides/python-net/el/aspose.slides.effects/ioutershadow/blur_radius/) | Ακτίνα θολώματος, σε σημεία.<br/>            Προεπιλεγμένη τιμή – 0 pt.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`direction`](/slides/python-net/el/aspose.slides.effects/ioutershadow/direction/) | Κατεύθυνση της σκιάς, σε μοίρες.<br/>            Προεπιλεγμένη τιμή – 0 ° (αριστερά προς δεξιά).<br/>            Ανάγνωση/εγγραφή **float**. |
| [`distance`](/slides/python-net/el/aspose.slides.effects/ioutershadow/distance/) | Απόσταση της σκιάς από το αντικείμενο, σε σημεία.<br/>            Προεπιλεγμένη τιμή – 0 pt.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`shadow_color`](/slides/python-net/el/aspose.slides.effects/ioutershadow/shadow_color/) | Χρώμα της σκιάς.<br/>            Προεπιλεγμένη τιμή – αυτόματο μαύρο (ανάλογα με το θέμα).<br/>            Μόνο για ανάγνωση [`IColorFormat`](/slides/python-net/el/aspose.slides/icolorformat). |
| [`rectangle_align`](/slides/python-net/el/aspose.slides.effects/ioutershadow/rectangle_align/) | Στοίχιση ορθογωνίου.<br/>            Προεπιλεγμένη τιμή – [`RectangleAlignment.BOTTOM`](/slides/python-net/el/aspose.slides/rectanglealignment/BOTTOM). <br/>            Ανάγνωση/εγγραφή [`RectangleAlignment`](/slides/python-net/el/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/el/aspose.slides.effects/ioutershadow/skew_horizontal/) | Οριζόντια κλίση γωνίας, σε μοίρες.<br/>            Προεπιλεγμένη τιμή – 0 °.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`skew_vertical`](/slides/python-net/el/aspose.slides.effects/ioutershadow/skew_vertical/) | Κάθετη κλίση γωνίας, σε μοίρες.<br/>            Προεπιλεγμένη τιμή – 0 °.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/el/aspose.slides.effects/ioutershadow/rotate_shadow_with_shape/) | Υποδεικνύει αν η σκιά περιστρέφεται μαζί με το σχήμα.<br/>            Προεπιλεγμένη τιμή – true.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`scale_horizontal`](/slides/python-net/el/aspose.slides.effects/ioutershadow/scale_horizontal/) | Οριζόντιος παράγοντας κλίμακας, σε ποσοστό του αρχικού μεγέθους.<br/>            Η αρνητική κλίμακα προκαλεί αναστροφή.<br/>            Προεπιλεγμένη τιμή – 100 %.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`scale_vertical`](/slides/python-net/el/aspose.slides.effects/ioutershadow/scale_vertical/) | Κάθετος παράγοντας κλίμακας, σε ποσοστό του αρχικού μεγέθους.<br/>            Η αρνητική κλίμακα προκαλεί αναστροφή.<br/>            Προεπιλεγμένη τιμή – 100 %.<br/>            Ανάγνωση/εγγραφή **float**. |
