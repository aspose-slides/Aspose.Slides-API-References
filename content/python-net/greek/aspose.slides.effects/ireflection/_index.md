## IReflection κλάση

Αναπαριστά ένα εφέ ανάκλασης.

Ο τύπος IReflection εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/el/aspose.slides.effects/ireflection/start_pos_alpha/) | Καθορίζει τη θέση έναρξης (κατά μήκος της κλίμακας διαβάθμισης άλφα) της τιμής άλφα έναρξης (ποσοστά).<br/>            Ανάγνωση/εγγραφή **float**. |
| [`end_pos_alpha`](/slides/python-net/el/aspose.slides.effects/ireflection/end_pos_alpha/) | Καθορίζει τη θέση λήξης (κατά μήκος της κλίμακας διαβάθμισης άλφα) της τιμής άλφα λήξης (ποσοστά).<br/>            Ανάγνωση/εγγραφή **float**. |
| [`fade_direction`](/slides/python-net/el/aspose.slides.effects/ireflection/fade_direction/) | Καθορίζει την κατεύθυνση μετατόπισης της ανάκλασης. (γωνία).<br/>            Ανάγνωση/εγγραφή **float**. |
| [`start_reflection_opacity`](/slides/python-net/el/aspose.slides.effects/ireflection/start_reflection_opacity/) | Αρχική διαφάνεια ανάκλασης. (ποσοστά).<br/>            Ανάγνωση/εγγραφή **float**. |
| [`end_reflection_opacity`](/slides/python-net/el/aspose.slides.effects/ireflection/end_reflection_opacity/) | Τελική διαφάνεια ανάκλασης. (ποσοστά).<br/>            Ανάγνωση/εγγραφή **float**. |
| [`blur_radius`](/slides/python-net/el/aspose.slides.effects/ireflection/blur_radius/) | Ακτίνα θολώματος.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`direction`](/slides/python-net/el/aspose.slides.effects/ireflection/direction/) | Κατεύθυνση ανάκλασης.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`distance`](/slides/python-net/el/aspose.slides.effects/ireflection/distance/) | Απόσταση ανάκλασης.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`rectangle_align`](/slides/python-net/el/aspose.slides.effects/ireflection/rectangle_align/) | Στοίχιση ορθογωνίου.<br/>            Ανάγνωση/εγγραφή [`RectangleAlignment`](/slides/python-net/el/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/el/aspose.slides.effects/ireflection/skew_horizontal/) | Καθορίζει την οριζόντια γωνία λοξότητας.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`skew_vertical`](/slides/python-net/el/aspose.slides.effects/ireflection/skew_vertical/) | Καθορίζει την κατακόρυφη γωνία λοξότητας.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/el/aspose.slides.effects/ireflection/rotate_shadow_with_shape/) | Καθορίζει εάν η ανάκλαση πρέπει να περιστραφεί μαζί με το σχήμα εάν το σχήμα είναι περιστροφομένο.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`scale_horizontal`](/slides/python-net/el/aspose.slides.effects/ireflection/scale_horizontal/) | Καθορίζει τον οριζόντιο παράγοντα κλιμάκωσης, η αρνητική κλιμάκωση προκαλεί αναστροφή. (ποσοστά)<br/>            Ανάγνωση/εγγραφή **float**. |
| [`scale_vertical`](/slides/python-net/el/aspose.slides.effects/ireflection/scale_vertical/) | Καθορίζει τον κατακόρυφο παράγοντα κλιμάκωσης, η αρνητική κλιμάκωση προκαλεί αναστροφή. (ποσοστά)<br/>            Ανάγνωση/εγγραφή **float**. |
