## OuterShadow κλάση

Αναπαριστά ένα εφέ Εξωτερικής Σκιάς.

Ο τύπος OuterShadow εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`blur_radius`](/slides/python-net/el/aspose.slides.effects/outershadow/blur_radius/) | Ακτίνα θολώματος, σε σημεία.<br/>            Προεπιλεγμένη τιμή – 0 pt.<br/>            Μόνο-ανάγνωση **float**. |
| [`direction`](/slides/python-net/el/aspose.slides.effects/outershadow/direction/) | Κατεύθυνση της σκιάς, σε μοίρες.<br/>            Προεπιλεγμένη τιμή – 0 ° (αριστερά προς δεξιά).<br/>            Μόνο-ανάγνωση **float**. |
| [`distance`](/slides/python-net/el/aspose.slides.effects/outershadow/distance/) | Απόσταση της σκιάς από το αντικείμενο, σε σημεία.<br/>            Προεπιλεγμένη τιμή – 0 pt.<br/>            Μόνο-ανάγνωση **float**. |
| [`shadow_color`](/slides/python-net/el/aspose.slides.effects/outershadow/shadow_color/) | Χρώμα της σκιάς.<br/>            Προεπιλεγμένη τιμή – αυτόματο μαύρο (ανάλογα με το θέμα).<br/>            Μόνο-ανάγνωση [`IColorFormat`](/slides/python-net/el/aspose.slides/icolorformat). |
| [`rectangle_align`](/slides/python-net/el/aspose.slides.effects/outershadow/rectangle_align/) | Στοίχιση του ορθογωνίου.<br/>            Προεπιλεγμένη τιμή – [`RectangleAlignment.BOTTOM`](/slides/python-net/el/aspose.slides/rectanglealignment/BOTTOM). <br/>            Ανάγνωση/Εγγραφή [`RectangleAlignment`](/slides/python-net/el/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/el/aspose.slides.effects/outershadow/skew_horizontal/) | Οριζόντια γωνία παραμόρφωσης, σε μοίρες.<br/>            Προεπιλεγμένη τιμή – 0 °.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`skew_vertical`](/slides/python-net/el/aspose.slides.effects/outershadow/skew_vertical/) | Κατακόρυφη γωνία παραμόρφωσης, σε μοίρες.<br/>            Προεπιλεγμένη τιμή – 0 °.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/el/aspose.slides.effects/outershadow/rotate_shadow_with_shape/) | Καθορίζει αν η σκιά περιστρέφεται μαζί με το σχήμα.<br/>            Προεπιλεγμένη τιμή – true.<br/>            Ανάγνωση/Εγγραφή **bool**. |
| [`scale_horizontal`](/slides/python-net/el/aspose.slides.effects/outershadow/scale_horizontal/) | Οριζόντιος παράγοντας κλιμάκωσης, σε ποσοστό του αρχικού μεγέθους.<br/>            Η αρνητική κλιμάκωση προκαλεί αντιστροφή.<br/>            Προεπιλεγμένη τιμή – 100 %.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`scale_vertical`](/slides/python-net/el/aspose.slides.effects/outershadow/scale_vertical/) | Κατακόρυφος παράγοντας κλιμάκωσης, σε ποσοστό του αρχικού μεγέθους.<br/>            Η αρνητική κλιμάκωση προκαλεί αντιστροφή.<br/>            Προεπιλεγμένη τιμή – 100 %.<br/>            Ανάγνωση/Εγγραφή **float**. |
