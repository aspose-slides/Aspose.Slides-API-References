## IColorChangeEffectiveData κλάση

Αμετάβλητο αντικείμενο που αντιπροσωπεύει ένα εφέ αλλαγής χρώματος.
            Παραδείγματα του FromColor αντικαθίστανται με παραδείγματα του ToColor.

Ο τύπος IColorChangeEffectiveData εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`from_color`](/slides/python-net/el/aspose.slides.effects/icolorchangeeffectivedata/from_color/) | Color που θα αντικατασταθεί.<br/>            Μόνο ανάγνωση [`Color`](/slides/python-net/el/aspose.slides/color). |
| [`to_color`](/slides/python-net/el/aspose.slides.effects/icolorchangeeffectivedata/to_color/) | Color που θα αντικαταστήσει.<br/>            Μόνο ανάγνωση [`Color`](/slides/python-net/el/aspose.slides/color). |
| [`use_alpha`](/slides/python-net/el/aspose.slides.effects/icolorchangeeffectivedata/use_alpha/) | Επιστρέφει μια boolean τιμή που καθορίζει αν πρέπει να χρησιμοποιηθεί το συστατικό alpha.<br/>            Μόνο ανάγνωση **bool**. |
