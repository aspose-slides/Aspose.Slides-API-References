## IReflectionEffectiveData κλάση

Αμετάβλητο αντικείμενο που αντιπροσωπεύει ένα εφέ Αντανάκλασης.

Ο τύπος IReflectionEffectiveData εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/el/aspose.slides.effects/ireflectioneffectivedata/start_pos_alpha/) | Καθορίζει τη θέση έναρξης (κατά μήκος της κλίμακας διαβάθμισης άλφα) της τιμής άλφα εκκίνησης (ποσοστά).<br/>            Μόνο για ανάγνωση **float**. |
| [`end_pos_alpha`](/slides/python-net/el/aspose.slides.effects/ireflectioneffectivedata/end_pos_alpha/) | Καθορίζει τη θέση λήξης (κατά μήκος της κλίμακας διαβάθμισης άλφα) της τιμής άλφα λήξης (ποσοστά).<br/>            Μόνο για ανάγνωση **float**. |
| [`fade_direction`](/slides/python-net/el/aspose.slides.effects/ireflectioneffectivedata/fade_direction/) | Καθορίζει την κατεύθυνση μετατόπισης της αντανάκλασης. (γωνία).<br/>            Μόνο για ανάγνωση **float**. |
| [`start_reflection_opacity`](/slides/python-net/el/aspose.slides.effects/ireflectioneffectivedata/start_reflection_opacity/) | Αρχική αδιαφάνεια αντανάκλασης. (ποσοστά).<br/>            Μόνο για ανάγνωση **float**. |
| [`end_reflection_opacity`](/slides/python-net/el/aspose.slides.effects/ireflectioneffectivedata/end_reflection_opacity/) | Τελική αδιαφάνεια αντανάκλασης. (ποσοστά).<br/>            Μόνο για ανάγνωση **float**. |
| [`blur_radius`](/slides/python-net/el/aspose.slides.effects/ireflectioneffectivedata/blur_radius/) | Ακτίνα θολώματος.<br/>            Μόνο για ανάγνωση **float**. |
| [`direction`](/slides/python-net/el/aspose.slides.effects/ireflectioneffectivedata/direction/) | Κατεύθυνση της αντανάκλασης.<br/>            Μόνο για ανάγνωση **float**. |
| [`distance`](/slides/python-net/el/aspose.slides.effects/ireflectioneffectivedata/distance/) | Απόσταση της αντανάκλασης.<br/>            Μόνο για ανάγνωση **float**. |
| [`rectangle_align`](/slides/python-net/el/aspose.slides.effects/ireflectioneffectivedata/rectangle_align/) | Στοίχιση παραλληλόγραμμου.<br/>            Μόνο για ανάγνωση [`RectangleAlignment`](/slides/python-net/el/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/el/aspose.slides.effects/ireflectioneffectivedata/skew_horizontal/) | Καθορίζει την οριζόντια γωνία πλαγίωσης.<br/>            Μόνο για ανάγνωση **float**. |
| [`skew_vertical`](/slides/python-net/el/aspose.slides.effects/ireflectioneffectivedata/skew_vertical/) | Καθορίζει την κάθετη γωνία πλαγίωσης.<br/>            Μόνο για ανάγνωση **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/el/aspose.slides.effects/ireflectioneffectivedata/rotate_shadow_with_shape/) | Καθορίζει αν η αντανάκλαση πρέπει να περιστρέφεται μαζί με το σχήμα εάν το σχήμα περιστραφεί.<br/>            Μόνο για ανάγνωση **bool**. |
| [`scale_horizontal`](/slides/python-net/el/aspose.slides.effects/ireflectioneffectivedata/scale_horizontal/) | Καθορίζει τον οριζόντιο συντελεστή κλιμάκωσης, η αρνητική κλιμάκωση προκαλεί αναστροφή. (ποσοστά)<br/>            Μόνο για ανάγνωση **float**. |
| [`scale_vertical`](/slides/python-net/el/aspose.slides.effects/ireflectioneffectivedata/scale_vertical/) | Καθορίζει τον κάθετο συντελεστή κλιμάκωσης, η αρνητική κλιμάκωση προκαλεί αναστροφή. (ποσοστά)<br/>            Μόνο για ανάγνωση **float**. |
