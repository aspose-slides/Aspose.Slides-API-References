## IBlurEffectiveData κλάση

Αμετάβλητο αντικείμενο που αντιπροσωπεύει ένα εφέ θόλωσης που εφαρμόζεται σε ολόκληρο το σχήμα, συμπεριλαμβανομένου του γεμίσματος του.  
Όλα τα κανάλια χρώματος, συμπεριλαμβανομένου του άλφα, επηρεάζονται.

Ο τύπος IBlurEffectiveData εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`radius`](/slides/python-net/el/aspose.slides.effects/iblureffectivedata/radius/) | Επιστρέφει ή ορίζει την ακτίνα θόλωσης.<br/>            Μόνο για ανάγνωση **float**. |
| [`grow`](/slides/python-net/el/aspose.slides.effects/iblureffectivedata/grow/) | Καθορίζει αν τα όρια του αντικειμένου πρέπει να αυξηθούν ως αποτέλεσμα της θόλωσης.<br/>            True υποδεικνύει ότι τα όρια αυξάνονται ενώ false υποδεικνύει ότι δεν αυξάνονται.<br/>            Μόνο για ανάγνωση **bool**. |
