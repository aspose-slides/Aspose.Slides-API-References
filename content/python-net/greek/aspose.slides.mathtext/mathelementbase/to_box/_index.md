## to_box(self) {#}
Τοποθετεί αυτό το στοιχείο σε ένα μη οπτικό κουτί (λογική ομαδοποίηση) 
            που χρησιμοποιείται για να ομαδοποιήσει τα συστατικά μιας εξίσωσης ή άλλης μορφής μαθηματικού κειμένου.
            Ένα κουτί μπορεί (για παράδειγμα) να λειτουργήσει ως προσομοιωτής τελεστή με ή χωρίς σημείο στοίχισης,
            να λειτουργήσει ως σημείο αλλαγής γραμμής, ή να ομαδοποιηθεί έτσι ώστε να μην επιτρέπεται αλλαγή γραμμής εντός.
