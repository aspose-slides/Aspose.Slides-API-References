## MathRowSpacingRule απαρίθμηση

Ο τύπος της κάθετης απόστασης μεταξύ των στηλών σε έναν πίνακα ή μια διάταξη

Ο τύπος MathRowSpacingRule εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| SINGLE_LINE_GAP | διάστημα μίας γραμμής |
| ONE_AND_A_HALF_LINE_GAP | διάστημα μίας και μισής γραμμής |
| TWO_LINE_GAP | διάστημα δύο γραμμών |
| EXACTLY | Ακριβώς (εξαρτάται από την τιμή της ιδιότητας RowSpacing, μετρημένη σε σημεία) |
| MULTIPLE | Πολλαπλό (εξαρτάται από την τιμή της ιδιότητας RowSpacing, μετρημένη σε γραμμές) |
