## to_box(self) {#}
Τοποθετεί αυτό το στοιχείο σε ένα μη οπτικό κουτί (λογική ομαδοποίηση) 
            που χρησιμοποιείται για την ομαδοποίηση στοιχείων μιας εξίσωσης ή άλλης μορφής μαθηματικού κειμένου.
            Ένα αντικείμενο σε κουτί μπορεί (π.χ.) να λειτουργήσει ως προσομοιωτής τελεστή με ή χωρίς σημείο ευθυγράμμισης, 
            να λειτουργεί ως σημείο διακοπής γραμμής, ή να ομαδοποιηθεί έτσι ώστε να μην επιτρέπει διακοπές γραμμής εντός.
