            που χρησιμοποιείται για να ομαδοποιήσει τα στοιχεία μιας εξίσωσης ή άλλης μορφής μαθηματικού κειμένου.

            να λειτουργεί ως σημείο αλλαγής γραμμής, ή να ομαδοποιείται έτσι ώστε να μην επιτρέπεται η αλλαγή γραμμής μέσα του.
