## portion_format ιδιότητα
Returns oformatting bject which contains explicitly set formatting properties of the text portion with no inheritance applied.
            Μόνο-ανάγνωση [`IPortionFormat`](/slides/python-net/el/aspose.slides/iportionformat).

### Παρατηρήσεις

Το αντικείμενο μορφοποίησης περιέχει τις παραμέτρους μορφοποίησης που ορίζονται μόνο για το τρέχων τμήμα, τα κληρονομημένα δεδομένα δεν εφαρμόζονται.

Για να λάβετε τις αποτελεσματικές τιμές συμπεριλαμβανομένων των κληρονομημένων, χρησιμοποιήστε τη μέθοδο [`PortionFormat.get_effective`](/slides/python-net/el/aspose.slides/portionformat/get_effective).
