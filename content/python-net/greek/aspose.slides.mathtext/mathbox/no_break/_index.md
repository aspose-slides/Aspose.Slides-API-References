## no_break ιδιότητα
Χωρίς διάλειμμα
            Αυτή η ιδιότητα καθορίζει την ιδιότητα "unbreakable" στο κουτί αντικειμένου. Όταν είναι true, δεν μπορούν να εμφανιστούν αλλαγές γραμμής μέσα στο κουτί.
            Αυτό μπορεί να είναι σημαντικό για τους εξομοιωτές τελεστών που αποτελούνται από περισσότερους από έναν δυαδικό τελεστή.
            Όταν αυτό το στοιχείο δεν καθορίζεται, μπορούν να εμφανιστούν διακοπές μέσα στο κουτί.
            Προεπιλογή: true
