## ιδιότητα operator_emulator
Εξομοιωτής χειριστή.
            Όταν είναι true, το πλαίσιο και το περιεχόμενό του συμπεριφέρονται ως ένας ενιαίος χειριστής και κληρονομούν τις ιδιότητες ενός χειριστή.
            Αυτό σημαίνει, για παράδειγμα, ότι ο χαρακτήρας μπορεί να λειτουργήσει ως σημείο για αλλαγή γραμμής και να ευθυγραμμιστεί με άλλους χειριστές.
            Οι Εξομοιωτές χειριστών χρησιμοποιούνται συχνά όταν ένα ή περισσότερα σύμβολα συνδυάζονται για να σχηματίσουν έναν χειριστή, όπως το '=='.
            Προεπιλεγμένη τιμή: false
