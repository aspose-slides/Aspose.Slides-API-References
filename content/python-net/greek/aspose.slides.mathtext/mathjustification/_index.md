## MathJustification απαρίθμηση

Καθορίζει την στοίχιση της παραγράφου μαθηματικών (μια σειρά από παρακείμενες εμφανίσεις μαθηματικού κειμένου μέσα στην ίδια παράγραφο)

Ο τύπος MathJustification εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| LEFT_JUSTIFIED | Στοίχιση μαθηματικού κειμένου προς τα αριστερά |
| RIGHT_JUSTIFIED | Στοίχιση μαθηματικού κειμένου προς τα δεξιά |
| CENTERED | Στοίχιση μαθηματικού κειμένου στο κέντρο |
| CENTERED_AS_GROUP | Κεντράρει στη σελίδα ολόκληρη την ομάδα των μπλοκ μαθηματικών ως μία ενιαία μονάδα.<br/>            Αυτό σημαίνει ότι οι εμφανίσεις του μαθηματικού κειμένου μπορούν να ευθυγραμμιστούν μεταξύ τους, <br/>            αλλά η ολόκληρη ομάδα του μαθηματικού κειμένου κεντράρεται ως σύνολο. |
