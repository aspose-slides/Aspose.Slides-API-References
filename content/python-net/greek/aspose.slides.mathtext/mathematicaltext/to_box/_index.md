## to_box(self) {#}
Τοποθετεί αυτό το στοιχείο σε ένα μη-οπτικό κουτί (λογική ομαδοποίηση) 
            που χρησιμοποιείται για ομαδοποίηση των στοιχείων μιας εξίσωσης ή άλλης παρουσίασης μαθηματικού κειμένου.
            Ένα αντικείμενο σε κουτί μπορεί (για παράδειγμα) να λειτουργήσει ως προσομοιωτής τελεστή με ή χωρίς σημείο στοίχισης, 
            να λειτουργήσει ως σημείο αλλαγής γραμμής, ή να ομαδοποιηθεί έτσι ώστε να μην επιτρέπονται αλλαγές γραμμής εντός.
