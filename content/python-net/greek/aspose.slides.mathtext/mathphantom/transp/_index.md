## ιδιότητα transp
Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει αν το φάντασμα είναι διαφανές 
            για τους κανόνες απόστασης βάσει κλάσης.

### Παρατηρήσεις

Όταν `true`, operators and symbols inside the phantom still affect 
            mathematical spacing around the phantom (as if visible). Όταν `false`, 
            class-based spacing is ignored. Συμφωνεί με το χαρακτηριστικό OMML `m:transp`.

### Ορισμός:
```python
@property
def transp(self):
    ...

@transp.setter
def transp(self, value):
    ...
```
