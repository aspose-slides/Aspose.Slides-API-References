            που χρησιμοποιείται για την ομαδοποίηση στοιχείων μιας εξίσωσης ή άλλης μορφής μαθηματικού κειμένου.

            να λειτουργήσει ως σημείο αλλαγής γραμμής ή να ομαδοποιηθεί έτσι ώστε να μην επιτρέπεται η αλλαγή γραμμής εντός.
