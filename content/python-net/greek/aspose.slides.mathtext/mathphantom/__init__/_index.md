## __init__(self, element) {#imathelement}
Δημιουργεί μια νέα παρουσία της κλάσης [`MathPhantom`](/slides/python-net/el/aspose.slides.mathtext/mathphantom) 
            χρησιμοποιώντας το καθορισμένο βασικό μαθηματικό στοιχείο.


```python
def __init__(self, element):
    ...
```


| Παράμετρος | Τύπος | Περιγραφή |
| :- | :- | :- |
| element | [`IMathElement`](/slides/python-net/el/aspose.slides.mathtext/imathelement) | Το βασικό [`IMathElement`](/slides/python-net/el/aspose.slides.mathtext/imathelement) του οποίου η ορατότητα και η διάταξη θα ελεγχθούν <br/><br/>            από το phantom. Αυτό το στοιχείο ορίζει το περιεχόμενο που μπορεί να κρύβεται ή να εμφανίζεται, <br/><br/>            ενώ εξακολουθεί να επηρεάζει την γεωμετρική ευθυγράμμιση των γύρω μαθηματικών. |

### Σχόλια

Το στοιχείο phantom χρησιμοποιείται για να κρατήσει ή να καταστέλλει τον οπτικό χώρο του βασικού του 
            έκφρασης χωρίς απαραίτητα να το εμφανίζει. Αντιστοιχεί στο στοιχείο OMML 
            `<m:phant>`.
