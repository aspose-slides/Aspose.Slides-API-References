## MathSpacingRules απαρίθμηση

Τύποι κενών (οριζόντια απόσταση) μεταξύ στηλών ενός πίνακα

Ο τύπος MathSpacingRules εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| SINGLE_SPACING_GAP | Μονό (1 em για στήλες ή 1 γραμμή για σειρές) |
| ONE_AND_HALF_SPACING_GAP | Μία και μισή (1.5 ems για στήλες ή 1.5 γραμμές για σειρές) |
| DOUBLE_SPACING_GAP | Διπλή απόσταση (2 ems για στήλες ή 2 γραμμές για σειρές) |
| EXACTLY | Ακριβής τιμή<br/>            Για στήλες, βασίζεται στην τιμή του ColumnGap, μετρημένη σε twips<br/>            Για σειρές, βασίζεται στην τιμή του RowGap, μετρημένη σε twips |
| MULTIPLE | Πολλαπλό<br/>            Για στήλες, βασίζεται στην τιμή του ColumnGap, μετρημένη σε βήματα 0.5 em<br/>            Για σειρές, βασίζεται στην τιμή του RowGap, μετρημένη σε γραμμές |
