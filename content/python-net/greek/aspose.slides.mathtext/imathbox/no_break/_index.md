## no_break ιδιότητα
Καμία διακοπή.
            Αυτή η ιδιότητα καθορίζει την ιδιότητα "unbreakable" στο πλαίσιο του αντικειμένου. Όταν είναι αληθής, δεν μπορούν να εμφανιστούν αλλαγές γραμμής μέσα στο πλαίσιο.
            Αυτό μπορεί να είναι σημαντικό για προσομοιωτές τελεστών που αποτελούνται από περισσότερους από έναν δυαδικό τελεστή. 
            Όταν αυτό το στοιχείο δεν καθορίζεται, μπορούν να εμφανιστούν διακοπές μέσα στο πλαίσιο.
            Προεπιλογή: true
