## ιδιότητα explicit_break
Η ρητή διακοπή καθορίζει εάν υπάρχει αλλαγή γραμμής στην αρχή του αντικειμένου Box,
            ώστε η γραμμή να τυλίγεται στην αρχή του αντικειμένου box.
            Καθορίζει τον αριθμό του τελεστή στην προηγούμενη γραμμή μαθηματικού κειμένου που πρέπει
            να χρησιμοποιηθεί ως σημείο ευθυγράμμισης για την τρέχουσα γραμμή μαθηματικού κειμένου
            πιθανές τιμές: 1..255
            Προεπιλογή: 0 (χωρίς ρητή διακοπή)
