## operator_emulator ιδιότητα
Operator Emulator.
            Όταν είναι αληθής, το πλαίσιο και το περιεχόμενό του συμπεριφέρονται ως ένας ενιαίος τελεστής και κληρονομούν τις ιδιότητες ενός τελεστή. 
            Αυτό σημαίνει, για παράδειγμα, ότι ο χαρακτήρας μπορεί να λειτουργήσει ως σημείο διακοπής γραμμής και μπορεί να ευθυγραμμιστεί με άλλους τελεστές.
            Operator Emulators χρησιμοποιούνται συχνά όταν ένας ή περισσότερα στοιχεία συνδυάζονται για να δημιουργήσουν έναν τελεστή, όπως το '=='.
            Προεπιλεγμένη τιμή: false
