## IMathBorderBox κλάση

Σχεδιάζει ένα ορθογώνιο ή κάποιο άλλο περίγραμμα γύρω από το IMathElement.

Ο τύπος IMathBorderBox εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`base`](/slides/python-net/el/aspose.slides.mathtext/imathborderbox/base/) | Βασικό επιχείρημα |
| [`hide_top`](/slides/python-net/el/aspose.slides.mathtext/imathborderbox/hide_top/) | Απόκρυψη Άνω Άκρου (default is false) - καθορίζει την κατάσταση κρυμμένης ή εμφανιζόμενης του άνω άκρου του πλαισίου περιγράμματος. |
| [`hide_bottom`](/slides/python-net/el/aspose.slides.mathtext/imathborderbox/hide_bottom/) | Απόκρυψη Κάτω Άκρου (default is false) - καθορίζει την κατάσταση κρυμμένης ή εμφανιζόμενης του κάτω άκρου του πλαισίου περιγράμματος. |
| [`hide_left`](/slides/python-net/el/aspose.slides.mathtext/imathborderbox/hide_left/) | Απόκρυψη Αριστερού Άκρου (default is false) - καθορίζει την κατάσταση κρυμμένης ή εμφανιζόμενης του αριστερού άκρου του πλαισίου περιγράμματος. |
| [`hide_right`](/slides/python-net/el/aspose.slides.mathtext/imathborderbox/hide_right/) | Απόκρυψη Δεξιού Άκρου (default is false) - καθορίζει την κατάσταση κρυμμένης ή εμφανιζόμενης του δεξιού άκρου του πλαισίου περιγράμματος. |
| [`strikethrough_horizontal`](/slides/python-net/el/aspose.slides.mathtext/imathborderbox/strikethrough_horizontal/) | Οριζόντια Διαγραμμή (default is false) - καθορίζει την κατάσταση κρυμμένης ή εμφανιζόμενης μιας οριζόντιας γραμμής διαγραφής. |
| [`strikethrough_vertical`](/slides/python-net/el/aspose.slides.mathtext/imathborderbox/strikethrough_vertical/) | Κάθετη Διαγραμμή (default is false) - καθορίζει την κατάσταση κρυμμένης ή εμφανιζόμενης μιας κάθετης γραμμής διαγραφής. |
| [`strikethrough_bottom_left_to_top_right`](/slides/python-net/el/aspose.slides.mathtext/imathborderbox/strikethrough_bottom_left_to_top_right/) | Διαγραμμή Κάτω-Αριστερά προς Πάνω-Δεξιά (default is false).<br/>Καθορίζει την κατάσταση κρυμμένης ή εμφανιζόμενης μιας διαγώνιας γραμμής διαγραφής από την κάτω αριστερή γωνία προς την πάνω δεξιά γωνία του πλαισίου περιγράμματος. |
| [`strikethrough_top_left_to_bottom_right`](/slides/python-net/el/aspose.slides.mathtext/imathborderbox/strikethrough_top_left_to_bottom_right/) | Διαγραμμή Πάνω-Αριστερά προς Κάτω-Δεξιά (default is false).<br/>Καθορίζει την κατάσταση κρυμμένης ή εμφανιζόμενης μιας διαγώνιας γραμμής διαγραφής από την πάνω αριστερή γωνία προς την κάτω δεξιά γωνία του πλαισίου περιγράμματος. |
