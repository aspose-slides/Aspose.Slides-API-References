## IMMathNaryOperatorProperties κλάση

Καθορίζει τις ιδιότητες του IMathNaryOperator

Ο τύπος IMathNaryOperatorProperties εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`operator`](/slides/python-net/el/aspose.slides.mathtext/imathnaryoperatorproperties/operator/) | Χαρακτήρας τελεστή Nary<br/>            Για παράδειγμα: '∑', '∫' |
| [`limit_location`](/slides/python-net/el/aspose.slides.mathtext/imathnaryoperatorproperties/limit_location/) | Η θέση των ορίων (δείκτη και εκθέτη) |
| [`grow_to_match_operand_height`](/slides/python-net/el/aspose.slides.mathtext/imathnaryoperatorproperties/grow_to_match_operand_height/) | Ο χαρακτήρας του τελεστή μεγαλώνει κατακόρυφα για να ταιριάζει με το ύψος του τελεστέου |
| [`hide_subscript`](/slides/python-net/el/aspose.slides.mathtext/imathnaryoperatorproperties/hide_subscript/) | Απόκρυψη δείκτη |
| [`hide_superscript`](/slides/python-net/el/aspose.slides.mathtext/imathnaryoperatorproperties/hide_superscript/) | Απόκρυψη εκθέτη |
