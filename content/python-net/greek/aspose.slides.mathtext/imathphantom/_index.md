## IMathPhantom κλάση

Αντιπροσωπεύει ένα φανταστικό μαθηματικό αντικείμενο (<m:phant>) που επηρεάζει τη διάταξη του στοιχείου-παιδιού χωρίς απαραίτητα να το εμφανίζει. Ένα φαντάσμα μπορεί να κρύβει την βασική του έκφραση ενώ διατηρεί το πλάτος, το ύψος ή το βάθος του για να ευθυγραμμίζει τύπους ή να διατηρεί χώρο. Η ορατότητα και η γεωμετρική συμπεριφορά ελέγχονται από ιδιότητες όπως Show, ZeroWid, ZeroAsc, ZeroDesc και Transp.

Ο τύπος IMathPhantom εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`base`](/slides/python-net/el/aspose.slides.mathtext/imathphantom/base/) | Βασικό όρισμα |
| [`show`](/slides/python-net/el/aspose.slides.mathtext/imathphantom/show/) | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν το βασικό στοιχείο εμφανίζεται. |
| [`zero_width`](/slides/python-net/el/aspose.slides.mathtext/imathphantom/zero_width/) | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν το πλάτος του βασικού στοιχείου <br/>            πρέπει να θεωρείται μηδέν. |
| [`zero_asc`](/slides/python-net/el/aspose.slides.mathtext/imathphantom/zero_asc/) | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν η άνοδος (ύψος πάνω από τη γραμμή βάσης) <br/>            του βασικού στοιχείου πρέπει να θεωρείται μηδέν. |
| [`zero_desc`](/slides/python-net/el/aspose.slides.mathtext/imathphantom/zero_desc/) | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν η κατάβαση (βάθος κάτω από τη γραμμή βάσης)<br/>            του βασικού στοιχείου πρέπει να θεωρείται μηδέν. |
| [`transp`](/slides/python-net/el/aspose.slides.mathtext/imathphantom/transp/) | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν το φάντασμα είναι διαυδές <br/>            για κανόνες απόστασης βασισμένους στην κλάση. |
