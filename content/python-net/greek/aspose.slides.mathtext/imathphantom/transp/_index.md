## transp ιδιότητα
Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν το φανταστικό είναι διάφανο για κανόνες διαστήματος που βασίζονται σε κλάση.

### Παρατηρήσεις

Όταν `true`, οι τελεστές και τα σύμβολα μέσα στο φανταστικό εξακολουθούν να επηρεάζουν το μαθηματικό διάστημα γύρω από το φανταστικό (σαν να είναι ορατό). Όταν `false`, το διάστημα βάσει κλάσης αγνοείται. Αντιστοιχεί στο χαρακτηριστικό OMML `m:transp`.

### Ορισμός:
```python
@property
def transp(self):
    ...

@transp.setter
def transp(self, value):
    ...
```
