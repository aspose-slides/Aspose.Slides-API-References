## to_box(self) {#}
Τοποθετεί αυτό το στοιχείο σε ένα μη οπτικό πλαίσιο (λογική ομαδοποίηση) 
που χρησιμοποιείται για να ομαδοποιήσει στοιχεία μιας εξίσωσης ή άλλης μορφής μαθηματικού κειμένου.
Ένα πλαίσιο μπορεί (για παράδειγμα) να λειτουργήσει ως προσομοιωτής τελεστή με ή χωρίς σημείο στοίχισης,
να λειτουργήσει ως σημείο αλλαγής γραμμής ή να ομαδοποιηθεί ώστε να μην επιτρέπεται αλλαγή γραμμής εντός.
