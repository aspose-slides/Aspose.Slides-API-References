## Compress κλάση

Αντιπροσωπεύει μια ομάδα μεθόδων που προορίζονται να συμπιέσουν [`Presentation`](/slides/python-net/el/aspose.slides/presentation).

Ο τύπος Compress εκθέτει τα παρακάτω μέλη:

## Μέθοδοι

| Μέθοδος | Περιγραφή |
| :- | :- |
| [`compress_presentation(presentation)`](/slides/python-net/el/aspose.slides.lowcode/compress/compress_presentation/#presentation) | Μειώνει το μέγεθος μιας παρουσίασης εφαρμόζοντας όλα τα διαθέσιμα βήματα συμπίεσης:<br/>            <br/>* Αφαιρεί αχρησιμοποίητες διαφάνειες master **Aspose.Slides.LowCode.Compress.RemoveUnusedMasterSlides(Aspose.Slide**.<br/>* Αφαιρεί αχρησιμοποίητες διαφάνειες layout **Aspose.Slides.LowCode.Compress.RemoveUnusedLayoutSlides(Aspose.Slide**.<br/>* Διατηρεί μόνο τα γλύφους που χρησιμοποιούνται πραγματικά στις ενσωματωμένες γραμματοσειρές **Aspose.Slides.LowCode.Compress.CompressEmbeddedFonts(Aspose.Slide**.<br/>* Μειώνει την ανάλυση των εικόνων σε 150 DPI και διαγράφει τις περικομμένες περιοχές των εικόνων **Aspose.Slides.LowCode.Compress.CompressImages(Aspose.Slides.IPresentation,Aspose.Slides.Expor**. |
| [`remove_unused_master_slides(pres)`](/slides/python-net/el/aspose.slides.lowcode/compress/remove_unused_master_slides/#presentation) | Κάνει συμπίεση του [`Presentation`](/slides/python-net/el/aspose.slides/presentation) αφαιρώντας αχρησιμοποίητες διαφάνειες master. |
| [`remove_unused_layout_slides(pres)`](/slides/python-net/el/aspose.slides.lowcode/compress/remove_unused_layout_slides/#presentation) | Κάνει συμπίεση του [`Presentation`](/slides/python-net/el/aspose.slides/presentation) αφαιρώντας αχρησιμοποίητες διαφάνειες layout. |
| [`compress_embedded_fonts(pres)`](/slides/python-net/el/aspose.slides.lowcode/compress/compress_embedded_fonts/#presentation) | Κάνει συμπίεση του [`Presentation`](/slides/python-net/el/aspose.slides/presentation) αφαιρώντας αχρησιμοποίητους χαρακτήρες από ενσωματωμένες γραμματοσειρές. |
| [`compress_images(presentation, resolution)`](/slides/python-net/el/aspose.slides.lowcode/compress/compress_images/#ipresentation-asposeslidesexportpicturescompression) | Μειώνει την ανάλυση των εικόνων στην παρουσίαση και διαγράφει τις περικομμένες περιοχές τους,<br/>            παρόμοιο με το "Compress Pictures" του PowerPoint που εφαρμόζεται σε όλες τις εικόνες.<br/>            Επεξεργάζονται εικόνες σε διαφάνειες, διαφάνειες layout και διαφάνειες master, συμπεριλαμβανομένων των εικόνων μέσα σε ομαδικά σχήματα<br/>            και των γεμίσματος εικόνας των σχημάτων. |
