Περιέχει κλάσεις και μεθόδους για τη διαχείριση πολύπλοκων γενικών λειτουργιών με τρόπο low code.
## Κλάσεις

| Κλάση | Περιγραφή |
| :- | :- |
| [`Collect`](/slides/python-net/el/aspose.slides.lowcode/collect/) | Αντιπροσωπεύει μια ομάδα μεθόδων που προορίζονται για τη συλλογή αντικειμένων μοντέλου διαφορετικών τύπων από [`Presentation`](/slides/python-net/el/aspose.slides/presentation). |
| [`Compress`](/slides/python-net/el/aspose.slides.lowcode/compress/) | Αντιπροσωπεύει μια ομάδα μεθόδων που προορίζονται για τη συμπίεση του [`Presentation`](/slides/python-net/el/aspose.slides/presentation). |
| [`Convert`](/slides/python-net/el/aspose.slides.lowcode/convert/) | Αντιπροσωπεύει μια ομάδα μεθόδων που προορίζονται για τη μετατροπή του [`Presentation`](/slides/python-net/el/aspose.slides/presentation). |
| [`ForEach`](/slides/python-net/el/aspose.slides.lowcode/foreach/) | Αντιπροσωπεύει μια ομάδα μεθόδων που προορίζονται για την επανάληψη σε διαφορετικά αντικείμενα μοντέλου [`Presentation`](/slides/python-net/el/aspose.slides/presentation).<br/>            Αυτές οι μέθοδοι μπορούν να είναι χρήσιμες εάν χρειάζεται να επαναλάβετε και να αλλάξετε τη μορφοποίηση ή το περιεχόμενο ορισμένων στοιχείων του Presentation',<br/>             π.χ. να αλλάξετε τη μορφοποίηση κάθε τμήματος. |
| [`Merger`](/slides/python-net/el/aspose.slides.lowcode/merger/) | Αντιπροσωπεύει μια ομάδα μεθόδων για τη συγχώνευση παρουσιάσεων PowerPoint του ίδιου μορφότυπου σε ένα αρχείο. |
