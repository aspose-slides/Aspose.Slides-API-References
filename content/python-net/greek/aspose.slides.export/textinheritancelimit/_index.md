## TextInheritanceLimit απαρίθμηση

Ρυθμίζει το βάθος της κληρονομικότητας των ιδιοτήτων κειμένου.

Ο τύπος TextInheritanceLimit εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| ALL | Κληρονομεί όλες τις ιδιότητες κειμένου. |
| TEXT_BOX | Κληρονομεί μόνο από το στυλ του TextFrame. |
| PARAGRAPH_ONLY | Χρησιμοποιεί μόνο τις ιδιότητες που ορίζονται για την παράγραφο. |
