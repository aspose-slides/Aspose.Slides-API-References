## skip_java_script_links ιδιότητα
Καθορίζει εάν θα παραλείπονται οι υπερσυνδέσμοι με κλήσεις JavaScript κατά την αποθήκευση της παρουσίασης. 
            Ανάγνωση/Εγγραφή **bool**. Η προεπιλεγμένη τιμή είναι **false** .


### Παρατηρήσεις

Όταν αυτή η ιδιότητα οριστεί σε **true** , οι υπερσυνδέσμοι με κλήσεις JavaScript θα αγνοούνται κατά την αποθήκευση.


Όταν αυτή η ιδιότητα οριστεί σε **false** , όλοι οι υπερσυνδέσμοι θα αποθηκευτούν.
