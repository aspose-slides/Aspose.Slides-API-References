## SvgExternalFontsHandling Απαρίθμηση

Αναπαριστά έναν τρόπο διαχείρισης εξωτερικών γραμματοσειρών που χρησιμοποιούνται για τη σχεδίαση κειμένου.

Ο τύπος SvgExternalFontsHandling εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| ADD_LINKS_TO_FONT_FILES | Προσθέτει συνδέσμους σε ξεχωριστά αρχεία γραμματοσειρών στην ενότητα style του αρχείου SVG. |
| EMBED | Αποθηκεύει τα δεδομένα των γραμματοσειρών απευθείας στο αρχείο SVG. Παρακαλούμε ελέγξτε όλες τις άδειες χρήσης των εξωτερικών γραμματοσειρών πριν χρησιμοποιήσετε αυτήν την επιλογή. |
| VECTORIZE | Αποθηκεύει όλο το κείμενο που χρησιμοποιεί εξωτερικές γραμματοσειρές ως γραφικά. |
