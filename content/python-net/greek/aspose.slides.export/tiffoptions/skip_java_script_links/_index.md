## skip_java_script_links ιδιότητα
Καθορίζει αν θα παραλειφθούν οι υπερσύνδεσμοι με κλήσεις JavaScript κατά την αποθήκευση της παρουσίασης. 
            Ανάγνωση/εγγραφή **bool**. Η προεπιλεγμένη τιμή είναι **false** .


### Σχόλια

Όταν αυτή η ιδιότητα είναι ορισμένη σε **true**, οι υπερσύνδεσμοι με κλήσεις JavaScript θα αγνοηθούν κατά την αποθήκευση.


Όταν αυτή η ιδιότητα είναι ορισμένη σε **false**, όλοι οι υπερσύνδεσμοι θα αποθηκευτούν.
