## PicturesCompression απαρίθμηση

Αντιπροσωπεύει το επίπεδο συμπίεσης εικόνων

Ο τύπος PicturesCompression αποκαλύπτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| DPI330 | Καλή ποιότητα για οθόνες υψηλής ανάλυσης (HD) |
| DPI220 | Εξαιρετική ποιότητα στα περισσότερα εκτυπωτές και οθόνες |
| DPI150 | Καλή για ιστοσελίδες και προβολείς |
| DPI96 | Μειώνει το μέγεθος του εγγράφου για κοινή χρήση |
| DPI72 | Προεπιλεγμένο επίπεδο συμπίεσης |
| DOCUMENT_RESOLUTION | Χρήση ανάλυσης εγγράφου - η εικόνα δεν θα συμπιεστεί και θα χρησιμοποιηθεί στο έγγραφο όπως είναι |
