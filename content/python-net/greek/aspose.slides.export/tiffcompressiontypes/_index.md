## TiffCompressionTypes αρίθμηση

Παρέχει επιλογές που ελέγχουν πώς μια παρουσίαση συμπιέζεται σε μορφή TIFF.

Ο τύπος TiffCompressionTypes εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| DEFAULT | Καθορίζει το προεπιλεγμένο σχήμα συμπίεσης (LZW). |
| NONE | Καθορίζει καμία συμπίεση. |
| CCITT3 | Καθορίζει το σχήμα συμπίεσης CCITT3. |
| CCITT4 | Καθορίζει το σχήμα συμπίεσης CCITT4. |
| LZW | Καθορίζει το σχήμα συμπίεσης LZW (Προεπιλογή). |
| RLE | Καθορίζει το σχήμα συμπίεσης RLE. |
