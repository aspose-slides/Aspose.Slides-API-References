## LinkEmbedDecision απαρίθμηση

Καθορίζει πώς θα επεξεργαστεί το αντικείμενο κατά την αποθήκευση.

Ο τύπος LinkEmbedDecision εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| LINK | Το αντικείμενο θα αποθηκευτεί εξωτερικά, αναφερόμενο μέσω URL |
| EMBED | Το αντικείμενο θα πρέπει να ενσωματωθεί σε ένα παραγόμενο αρχείο εάν είναι δυνατόν. Εάν η ενσωμάτωση είναι αδύνατη, θα κληθεί το GetUrl και, ανάλογα με το αποτέλεσμα, το αντικείμενο θα αναφερθεί μέσω URL ή θα αγνοηθεί. |
| IGNORE | Το αντικείμενο θα αγνοηθεί. |
