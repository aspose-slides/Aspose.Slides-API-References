## Zip64Mode απαρίθμηση

Specifies when to use ZIP64 format extensions for OpenXML file.

The Zip64Mode type exposes the following members:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| NEVER | Να μην χρησιμοποιούνται επεκτάσεις μορφής ZIP64. |
| IF_NECESSARY | Να χρησιμοποιηθούν επεκτάσεις μορφής ZIP64 εάν είναι απαραίτητο. |
| ALWAYS | Να χρησιμοποιούνται πάντα επεκτάσεις μορφής ZIP64. |


### Παρατηρήσεις

Το αρχείο OpenXML είναι ένα αρχείο ZIP που έχει όριο 4 GB (2^32 byte) στο μη συμπιεσμένο μέγεθος ενός αρχείου, στο συμπιεσμένο μέγεθος ενός αρχείου και στο συνολικό μέγεθος του αρχειοθέτη, καθώς και όριο 65 535 (2^16-1) αρχείων στο αρχείο. Οι επεκτάσεις μορφής ZIP64 αυξάνουν τα όρια στα 2^64.
