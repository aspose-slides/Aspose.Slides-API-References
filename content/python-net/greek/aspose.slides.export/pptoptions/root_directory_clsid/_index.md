## root_directory_clsid ιδιότητα
Αντιπροσωπεύει το GUID (CLSID) της κλάσης αντικειμένου που αποθηκεύεται στην καταχώρηση του ριζικού καταλόγου. Μπορεί να χρησιμοποιηθεί για COM
            ενεργοποίηση της εφαρμογής του εγγράφου.
            Η προεπιλεγμένη τιμή είναι '64818D11-4F9B-11CF-86EA-00AA00B929E8' που αντιστοιχεί στο 'Microsoft Powerpoint.Slide.8'.
