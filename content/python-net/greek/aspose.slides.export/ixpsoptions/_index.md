## IXpsOptions κλάση

Παρέχει επιλογές που ελέγχουν πώς αποθηκεύεται μια παρουσίαση σε μορφή XPS.

Ο τύπος IXpsOptions εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Property | Description |
| :- | :- |
| [`save_metafiles_as_png`](/slides/python-net/el/aspose.slides.export/ixpsoptions/save_metafiles_as_png/) | True για τη μετατροπή όλων των μετααρχείων που χρησιμοποιούνται σε μια παρουσίαση σε εικόνες PNG.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`draw_slides_frame`](/slides/python-net/el/aspose.slides.export/ixpsoptions/draw_slides_frame/) | True για σχεδίαση μαύρου πλαισίου γύρω από κάθε διαφάνεια.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`show_hidden_slides`](/slides/python-net/el/aspose.slides.export/ixpsoptions/show_hidden_slides/) | Καθορίζει εάν το παραγόμενο έγγραφο πρέπει να περιλαμβάνει κρυφές διαφάνειες ή όχι.<br/>            Η προεπιλογή είναι `false`. |
| [`warning_callback`](/slides/python-net/el/aspose.slides.export/ixpsoptions/warning_callback/) |  |
