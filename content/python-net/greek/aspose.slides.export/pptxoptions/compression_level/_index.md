## compression_level ιδιότητα
Specifies the compression level used when saving the presentation document.
            Η προεπιλεγμένη τιμή είναι [`CompressionLevel.LEVEL6`](/slides/python-net/el/aspose.slides.export/compressionlevel/LEVEL6).

### Παρατηρήσεις

Higher compression levels produce smaller files but require more processing time.
            Η πραγματική αναλογία συμπίεσης εξαρτάται από το περιεχόμενο της παρουσίασης.
