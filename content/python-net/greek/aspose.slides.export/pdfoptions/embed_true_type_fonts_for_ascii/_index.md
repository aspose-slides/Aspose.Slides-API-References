## embed_true_type_fonts_for_ascii ιδιότητα
Καθορίζει εάν το Aspose.Slides θα ενσωματώσει κοινές γραμματοσειρές για κείμενο ASCII (33..127 code range) text.
            Οι γραμματοσειρές για κωδικούς χαρακτήρων μεγαλύτερους από 127 ενσωματώνονται πάντα.
            Η λίστα κοινών γραμματοσειρών περιλαμβάνει τις 14 βασικές γραμματοσειρές του PDF και επιπλέον γραμματοσειρές που καθορίζονται από τον χρήστη.
            Ανάγνωση/εγγραφή **bool**.


### Παρατηρήσεις

Η προεπιλογή είναι **true** .
