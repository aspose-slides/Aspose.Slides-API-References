## HandoutType απαρίθμηση

Καθορίζει πόσες διαφάνειες και σε ποια ακολουθία θα τοποθετηθούν στη σελίδα.

Ο τύπος HandoutType εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| HANDOUTS1 | Μία διαφάνεια ανά σελίδα. |
| HANDOUTS2 | Δύο διαφάνειες ανά σελίδα. |
| HANDOUTS3 | Τρεις διαφάνειες ανά σελίδα. |
| HANDOUTS_4_HORIZONTAL | Τέσσερις διαφάνειες ανά σελίδα σε οριζόντια ακολουθία. |
| HANDOUTS_4_VERTICAL | Τέσσερις διαφάνειες ανά σελίδα σε κατακόρυφη ακολουθία. |
| HANDOUTS_6_HORIZONTAL | Έξι διαφάνειες ανά σελίδα σε οριζόντια ακολουθία. |
| HANDOUTS_6_VERTICAL | Έξι διαφάνειες ανά σελίδα σε κατακόρυφη ακολουθία. |
| HANDOUTS_9_HORIZONTAL | Εννέα διαφάνειες ανά σελίδα σε οριζόντια ακολουθία. |
| HANDOUTS_9_VERTICAL | Εννέα διαφάνειες ανά σελίδα σε κατακόρυφη ακολουθία. |
