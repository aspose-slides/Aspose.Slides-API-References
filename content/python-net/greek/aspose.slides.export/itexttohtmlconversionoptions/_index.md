## ITextToHtmlConversionOptions κλάση

Επιλογές για την εξαγωγή HTML από το κείμενο Pptx.

Ο τύπος ITextToHtmlConversionOptions εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`add_clipboard_fragment_header`](/slides/python-net/el/aspose.slides.export/itexttohtmlconversionoptions/add_clipboard_fragment_header/) | Επιστρέφει ή ορίζει τιμή, υποδεικνύοντας αν πρέπει να προστεθούν κεφαλίδες Clipboard.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`text_inheritance_limit`](/slides/python-net/el/aspose.slides.export/itexttohtmlconversionoptions/text_inheritance_limit/) | Επιστρέφει ή ορίζει το βάθος κληρονομίας για τις ιδιότητες κειμένου.<br/>            Ανάγνωση/εγγραφή [`ITextToHtmlConversionOptions.text_inheritance_limit`](/slides/python-net/el/aspose.slides.export/itexttohtmlconversionoptions/text_inheritance_limit). |
| [`link_embed_controller`](/slides/python-net/el/aspose.slides.export/itexttohtmlconversionoptions/link_embed_controller/) | Επιστρέφει ή ορίζει ένα αντικείμενο callback που ελέγχει πώς θα αποθηκευτεί το εξωτερικό αντικείμενο.<br/>            Ανάγνωση/εγγραφή [`ILinkEmbedController`](/slides/python-net/el/aspose.slides.export/ilinkembedcontroller). |
| [`encoding_name`](/slides/python-net/el/aspose.slides.export/itexttohtmlconversionoptions/encoding_name/) | Επιστρέφει ή ορίζει το όνομα κωδικοποίησης html.<br/>            Αυτή η τιμή θα αποθηκευθεί στο παραγόμενο αρχείο HTML, αλλά εξαρτάται από τον καλούντα να διασφαλίσει ότι το αρχείο θα αποθηκευτεί με αυτήν την κωδικοποίηση.<br/>            Ανάγνωση/εγγραφή **str**. |
