## IRenderingOptions κλάση

Παρέχει επιλογές που ελέγχουν πώς αποδίδεται μια παρουσίαση/διαφάνεια.

Ο τύπος IRenderingOptions εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`slides_layout_options`](/slides/python-net/el/aspose.slides.export/irenderingoptions/slides_layout_options/) | Λαμβάνει ή ορίζει τη λειτουργία με την οποία οι διαφάνειες τοποθετούνται στη σελίδα κατά την εξαγωγή μιας παρουσίασης [`ISlidesLayoutOptions`](/slides/python-net/el/aspose.slides.export/islideslayoutoptions). |
| [`ink_options`](/slides/python-net/el/aspose.slides.export/irenderingoptions/ink_options/) | Παρέχει επιλογές που ελέγχουν την εμφάνιση των αντικειμένων Ink σε εξαγόμενο έγγραφο.<br/>            Μόνο ανάγνωση [`IInkOptions`](/slides/python-net/el/aspose.slides.export/iinkoptions) |
| [`disable_font_ligatures`](/slides/python-net/el/aspose.slides.export/irenderingoptions/disable_font_ligatures/) | Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν το κείμενο αποδίδεται χωρίς χρήση λιγκατούρων.<br/>            Όταν ορίζεται σε `true`, οι λιγκατούρες θα απενεργοποιηθούν στην αποδομένη έξοδο. Προεπιλογή, αυτή η ιδιότητα είναι ορισμένη σε `false`. |
