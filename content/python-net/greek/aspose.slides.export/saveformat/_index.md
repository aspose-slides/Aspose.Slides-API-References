## Απαρίθμηση SaveFormat

Σταθερές που ορίζουν τη μορφή μιας αποθηκευμένης παρουσίασης.

Ο τύπος SaveFormat αποκαλύπτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| PPT | Αποθήκευση παρουσίασης σε μορφή PPT. |
| PDF | Αποθήκευση παρουσίασης σε μορφή PDF. |
| XPS | Αποθήκευση παρουσίασης σε μορφή XPS. |
| PPTX | Αποθήκευση παρουσίασης σε μορφή PPTX. |
| PPSX | Αποθήκευση παρουσίασης σε μορφή PPSX (παρουσίαση διαφανειών). |
| TIFF | Αποθήκευση παρουσίασης ως πολυ-σελίδα εικόνα TIFF. |
| ODP | Αποθήκευση παρουσίασης σε μορφή ODP. |
| PPTM | Αποθήκευση παρουσίασης σε μορφή PPTM (παρουσίαση με μακροεντολές). |
| PPSM | Αποθήκευση παρουσίασης σε μορφή PPSM (παρουσίαση διαφανειών με μακροεντολές). |
| POTX | Αποθήκευση παρουσίασης σε μορφή POTX (πρότυπο). |
| POTM | Αποθήκευση παρουσίασης σε μορφή POTM (πρότυπο με μακροεντολές). |
| HTML | Αποθήκευση παρουσίασης σε μορφή HTML. |
| SWF | Αποθήκευση παρουσίασης σε μορφή SWF. |
| OTP | Αποθήκευση παρουσίασης σε μορφή OTP (πρότυπο παρουσίασης). |
| PPS | Αποθήκευση παρουσίασης σε μορφή PPS. |
| POT | Αποθήκευση παρουσίασης σε μορφή POT. |
| FODP | Αποθήκευση παρουσίασης σε μορφή FODP. |
| GIF | Αποθήκευση παρουσίασης σε μορφή GIF. |
| HTML5 | Αποθήκευση παρουσίασης σε μορφή HTML χρησιμοποιώντας το νέο σύστημα προτύπων HTML5. |
| MD | Αποθήκευση παρουσίασης σε μορφή Markdown. |
| XML | Αποθήκευση παρουσίασης σε μορφή PowerPoint XML Presentation. |
