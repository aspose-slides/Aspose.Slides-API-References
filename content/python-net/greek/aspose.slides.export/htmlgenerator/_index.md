## HtmlGenerator κλάση

Γεννήτρια HTML.

Ο τύπος HtmlGenerator εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`slide_image_size`](/slides/python-net/el/aspose.slides.export/htmlgenerator/slide_image_size/) | Επιστρέφει το μέγεθος της εικόνας της διαφάνειας.<br/>            Μόνο για ανάγνωση **aspose.slides.SizeF**. |
| [`slide_image_size_unit`](/slides/python-net/el/aspose.slides.export/htmlgenerator/slide_image_size_unit/) | Επιστρέφει τη μονάδα στην οποία καθορίζεται το μέγεθος της εικόνας της διαφάνειας.<br/>            Μόνο για ανάγνωση [`SvgCoordinateUnit`](/slides/python-net/el/aspose.slides.export/svgcoordinateunit). |
| [`slide_image_size_unit_code`](/slides/python-net/el/aspose.slides.export/htmlgenerator/slide_image_size_unit_code/) | Επιστρέφει τον κωδικό css της μονάδας στην οποία καθορίζεται το μέγεθος της εικόνας της διαφάνειας.<br/>            Μόνο για ανάγνωση **str**. |
| [`previous_slide_index`](/slides/python-net/el/aspose.slides.export/htmlgenerator/previous_slide_index/) | Επιστρέφει το ευρετήριο της προηγούμενης επεξεργασμένης διαφάνειας ή -1 αν η πρώτη διαφάνεια βρίσκεται σε επεξεργασία.<br/>            Μόνο για ανάγνωση **int**. |
| [`slide_index`](/slides/python-net/el/aspose.slides.export/htmlgenerator/slide_index/) | Επιστρέφει το ευρετήριο της τρέχουσας επεξεργασμένης διαφάνειας.<br/>            Μόνο για ανάγνωση **int**. |
| [`next_slide_index`](/slides/python-net/el/aspose.slides.export/htmlgenerator/next_slide_index/) | Επιστρέφει το ευρετήριο μιας διαφάνειας που θα επεξεργασθεί μετά την τρέχουσα διαφάνεια ή -1 αν η τρέχουσα είναι η τελευταία.<br/>            Μόνο για ανάγνωση **int**. |
