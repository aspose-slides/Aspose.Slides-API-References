## IGifOptions κλάση

Αντιπροσωπεύει τις επιλογές εξαγώγησης GIF.

Ο τύπος IGifOptions εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`frame_size`](/slides/python-net/el/aspose.slides.export/igifoptions/frame_size/) | Λαμβάνει ή ορίζει το μέγεθος του πλαισίου. |
| [`export_hidden_slides`](/slides/python-net/el/aspose.slides.export/igifoptions/export_hidden_slides/) | Καθορίζει αν οι κρυφές διαφάνειες θα εξαχθούν.<br/>            Η προεπιλεγμένη τιμή είναι false. |
| [`transition_fps`](/slides/python-net/el/aspose.slides.export/igifoptions/transition_fps/) | Λαμβάνει ή ορίζει το FPS μετάβασης [frames/sec]<br/>            Η προεπιλεγμένη τιμή είναι 25. |
| [`default_delay`](/slides/python-net/el/aspose.slides.export/igifoptions/default_delay/) | Λαμβάνει ή ορίζει το προεπιλεγμένο χρόνο καθυστέρησης [ms]. Αυτή η τιμή θα χρησιμοποιηθεί εάν δεν έχει οριστεί το [`ISlideShowTransition.advance_after_time`](/slides/python-net/el/aspose.slides/islideshowtransition/advance_after_time).<br/>            Η προεπιλεγμένη τιμή είναι 1000. |
| [`warning_callback`](/slides/python-net/el/aspose.slides.export/igifoptions/warning_callback/) |  |
| [`progress_callback`](/slides/python-net/el/aspose.slides.export/igifoptions/progress_callback/) |  |
| [`default_regular_font`](/slides/python-net/el/aspose.slides.export/igifoptions/default_regular_font/) |  |
