## SaveOptions κλάση

Απόρρητη κλάση με επιλογές που ελέγχουν πώς αποθηκεύεται μια παρουσίαση.

Ο τύπος SaveOptions εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`warning_callback`](/slides/python-net/el/aspose.slides.export/saveoptions/warning_callback/) | Επιστρέφει ή θέτει ένα αντικείμενο που λαμβάνει προειδοποιήσεις και αποφασίζει αν η διαδικασία φόρτωσης θα συνεχιστεί ή θα τερματιστεί.<br/>Ανάγνωση/εγγραφή [`IWarningCallback`](/slides/python-net/el/aspose.slides.warnings/iwarningcallback). |
| [`progress_callback`](/slides/python-net/el/aspose.slides.export/saveoptions/progress_callback/) | Αντιπροσωπεύει ένα αντικείμενο κλήσης επιστροφής για ενημερώσεις προόδου αποθήκευσης σε ποσοστό.<br/>Δείτε [`IProgressCallback`](/slides/python-net/el/aspose.slides/iprogresscallback). |
| [`default_regular_font`](/slides/python-net/el/aspose.slides.export/saveoptions/default_regular_font/) | Επιστρέφει ή θέτει τη γραμματοσειρά που χρησιμοποιείται στην περίπτωση που η πηγαία γραμματοσειρά δεν βρεθεί.<br/>Ανάγνωση-εγγραφή **str**. |
| [`gradient_style`](/slides/python-net/el/aspose.slides.export/saveoptions/gradient_style/) | Επιστρέφει ή θέτει το οπτικό στυλ της κλίμακας χρώματος.<br/>Ανάγνωση/εγγραφή [`GradientStyle`](/slides/python-net/el/aspose.slides/gradientstyle). |
| [`skip_java_script_links`](/slides/python-net/el/aspose.slides.export/saveoptions/skip_java_script_links/) | Καθορίζει αν θα παραλειφθούν υπερσυνδέσεις με κλήσεις JavaScript κατά την αποθήκευση της παρουσίασης.<br/>Ανάγνωση/εγγραφή **bool**. Η προεπιλεγμένη τιμή είναι **false**. |
