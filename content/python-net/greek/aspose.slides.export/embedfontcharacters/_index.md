## EmbedFontCharacters απαρίθμηση

Αντιπροσωπεύει τον κανόνα που χρησιμοποιείται για την προσθήκη νέας γραμματοσειράς ενσωμάτωσης στο [`IPresentation`](/slides/python-net/el/aspose.slides/ipresentation)

Ο τύπος EmbedFontCharacters εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| ONLY_USED | Ενσωματώστε μόνο τους χαρακτήρες που χρησιμοποιούνται στην παρουσίαση (καλύτερο για μείωση του μεγέθους του αρχείου). |
| ALL | Ενσωματώστε όλους τους χαρακτήρες (καλύτερο για επεξεργασία από άλλους ανθρώπους). |
