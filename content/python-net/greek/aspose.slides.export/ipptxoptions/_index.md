## IPptxOptions κατηγορία

Αναπαριστά επιλογές για την αποθήκευση παρουσιάσεων OpenXml (PPTX, PPSX, POTX, PPTM, PPSM, POTM).

Ο τύπος IPptxOptions εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`conformance`](/slides/python-net/el/aspose.slides.export/ipptxoptions/conformance/) | Καθορίζει την κλάση συμμόρφωσης στην οποία συμμορφώνεται το έγγραφο Presentation.<br/>            Η προεπιλεγμένη τιμή είναι [`Conformance.ECMA_376_2006`](/slides/python-net/el/aspose.slides.export/conformance/ECMA_376_2006) |
| [`zip_64_mode`](/slides/python-net/el/aspose.slides.export/ipptxoptions/zip_64_mode/) | Καθορίζει αν χρησιμοποιείται η μορφή ZIP64 για το έγγραφο Presentation.<br/>            Η προεπιλεγμένη τιμή είναι [`Zip64Mode.IF_NECESSARY`](/slides/python-net/el/aspose.slides.export/zip64mode/IF_NECESSARY) |
| [`refresh_thumbnail`](/slides/python-net/el/aspose.slides.export/ipptxoptions/refresh_thumbnail/) | Καθορίζει αν θα ανανεωθεί η μικρογραφία της παρουσίασης.<br/>            Ανάγνωση/εγγραφή **bool**.<br/>            Η προεπιλεγμένη τιμή είναι **true** . |
| [`compression_level`](/slides/python-net/el/aspose.slides.export/ipptxoptions/compression_level/) | Καθορίζει το επίπεδο συμπίεσης που χρησιμοποιείται κατά την αποθήκευση του εγγράφου παρουσίασης.<br/>            Η προεπιλεγμένη τιμή είναι [`CompressionLevel.LEVEL6`](/slides/python-net/el/aspose.slides.export/compressionlevel/LEVEL6). |
