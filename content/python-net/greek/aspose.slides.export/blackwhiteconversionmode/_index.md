## BlackWhiteConversionMode απαρίθμηση

Παρέχει επιλογές που ελέγχουν τον τρόπο με τον οποίο οι εικόνες των διαφανειών θα μετατραπούν σε δυοτονικές εικόνες.

Ο τύπος BlackWhiteConversionMode εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| DEFAULT | Καθορίζει ότι δεν υπάρχει αλγόριθμος μετατροπής. Θα χρησιμοποιηθεί ο αλγόριθμος που υλοποιείται στον κωδικοποιητή TIFF. (Προεπιλογή) |
| DITHERING | Καθορίζει τον αλγόριθμο ψευδοντσιοματισμού (Floyd-Steinberg). |
| DITHERING_FLOYD_STEINBERG | Καθορίζει τον αλγόριθμο ψευδοντσιοματισμού Floyd-Steinberg. |
| AUTO | Καθορίζει τον αλγόριθμο κατωφλίου που υπολογίζεται αυτόματα (Otsu). |
| AUTO_OTSU | Καθορίζει τον αυτόματα υπολογιζόμενο αλγόριθμο κατωφλίου του Otsu. |
| THRESHOLD25 | Καθορίζει τον στατικό αλγόριθμο κατωφλίου (25%). |
| THRESHOLD50 | Καθορίζει τον στατικό αλγόριθμο κατωφλίου (50%). |
| THRESHOLD75 | Καθορίζει τον στατικό αλγόριθμο κατωφλίου (75%). |
