## SvgCoordinateUnit απαρίθμηση

Αναπαριστά τις μονάδες συντεταγμένων CSS2 που χρησιμοποιούνται για τον ορισμό των συντεταγμένων SVG.

Ο τύπος SvgCoordinateUnit εμφανίζει τα εξής μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| INCH | Ίντσα |
| CENTIMETER | Εκατοστόμετρο. |
| MILLIMETER | Χιλιοστόμετρο. |
| POINT | Σημείο (1/72 ίντσας), |
| PICA | Pica (1/6 ίντσας). |
| EM | Μέγεθος Em μιας γραμματοσειράς του περιέχοντος στοιχείου. |
| EX | Μέγεθος Ex (μέγεθος πεζού γράμματος, συνήθως "x") της γραμματοσειράς του περιέχοντος στοιχείου. |
| PIXEL | Μέγεθος pixel. |
| PERCENT | Ποσοστό. |
