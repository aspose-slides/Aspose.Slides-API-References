## slide_number_format ιδιότητα
Gets or sets the format string used for slide number headers in Markdown output.
            Η μορφή πρέπει να περιλαμβάνει το "{0}" placeholder, το οποίο θα αντικατασταθεί με τον δείκτη διαφάνειας κατά την εξαγωγή.
            Παράδειγμα: "# Slide {0}" θα παράγει "# Slide 1", "# Slide 2", κ.λπ.
