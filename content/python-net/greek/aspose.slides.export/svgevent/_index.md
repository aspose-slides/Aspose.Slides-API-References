## SvgEvent απαρίθμηση

Αντιπροσωπεύει επιλογές για το σχήμα SVG.

Ο τύπος SvgEvent εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| ON_FOCUS_IN | Συμβαίνει όταν ένα στοιχείο λαμβάνει εστίαση, όπως όταν κείμενο επιλέγεται. |
| ON_FOCUS_OUT | Συμβαίνει όταν ένα στοιχείο χάνει την εστίαση, όπως όταν κείμενο αποεπιλέγεται. |
| ON_ACTIVATE | Συμβαίνει όταν ένα στοιχείο ενεργοποιείται, για παράδειγμα μέσω κλικ του ποντικιού ή πατήματος πλήκτρου. |
| ON_CLICK | Συμβαίνει όταν το κουμπί της συσκευής δείκτη κάνει κλικ πάνω σε ένα στοιχείο. |
| ON_MOUSE_DOWN | Συμβαίνει όταν το κουμπί της συσκευής δείκτη πατιέται πάνω σε ένα στοιχείο. |
| ON_MOUSE_UP | Συμβαίνει όταν το κουμπί της συσκευής δείκτη απελευθερώνεται πάνω σε ένα στοιχείο. |
| ON_MOUSE_OVER | Συμβαίνει όταν η συσκευή δείκτη μετακινείται πάνω σε ένα στοιχείο. |
| ON_MOUSE_MOVE | Συμβαίνει όταν η συσκευή δείκτη μετακινείται ενώ είναι πάνω σε ένα στοιχείο. |
| ON_MOUSE_OUT | Συμβαίνει όταν η συσκευή δείκτη μετακινείται μακριά από ένα στοιχείο. |
| ON_LOAD | Συμβαίνει όταν ο πελάτης έχει πλήρως αναλύσει το στοιχείο και τα τέκνα του και όλους τους αναφερόμενους πόρους, που απαιτούνται για την απόδοσή του. |
| ON_UNLOAD | Συμβαίνει όταν η υλοποίηση DOM αφαιρεί ένα έγγραφο από ένα παράθυρο ή πλαίσιο. Εφαρμόζεται μόνο στα εξωτερικά στοιχεία svg. |
| ON_ABORT | Συμβαίνει όταν η φόρτωση της σελίδας σταματά πριν το στοιχείο φορτωθεί πλήρως. |
| ON_ERROR | Συμβαίνει όταν ένα στοιχείο δεν φορτώνεται σωστά ή όταν προκύπτει σφάλμα κατά την εκτέλεση του script. |
| ON_RESIZE | Συμβαίνει όταν η προβολή του εγγράφου αλλάζει μέγεθος. Εφαρμόζεται μόνο στα εξωτερικά στοιχεία svg. |
| ON_SCROLL | Συμβαίνει όταν η προβολή του εγγράφου μετακινείται κατά μήκος του άξονα X ή Y ή και των δύο. Εφαρμόζεται μόνο στα εξωτερικά στοιχεία svg. |
| ON_ZOOM | Συμβαίνει όταν αλλάζει το επίπεδο ζουμ της προβολής του εγγράφου. Εφαρμόζεται μόνο στα εξωτερικά στοιχεία svg. |
| ON_BEGIN | Συμβαίνει όταν ένα στοιχείο animation αρχίζει. |
| ON_END | Συμβαίνει όταν ένα στοιχείο animation λήγει. |
| ON_REPEAT | Συμβαίνει όταν ένα στοιχείο animation επαναλαμβάνεται. |
