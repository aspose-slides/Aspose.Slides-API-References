## NotesPositions απαρίθμηση

Αναπαριστά τον κανόνα για την απόδοση των σημειώσεων στο εξαγόμενο έγγραφο

Ο τύπος NotesPositions εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| NONE | Καθορίζει ότι οι σημειώσεις δεν πρέπει να εμφανιστούν καθόλου. |
| BOTTOM_FULL | Καθορίζει ότι οι σημειώσεις πρέπει να εμφανίζονται πλήρως χρησιμοποιώντας πρόσθετες σελίδες όποτε απαιτείται. |
| BOTTOM_TRUNCATED | Καθορίζει ότι οι σημειώσεις πρέπει να εμφανιστούν σε μία μόνο σελίδα. |
