## skip_java_script_links ιδιότητα
Καθορίζει αν θα παραλειφθούν οι υπερσυνδέσεις με κλήσεις JavaScript κατά την αποθήκευση της παρουσίασης. 
            Ανάγνωση/εγγραφή **bool**. Η προεπιλεγμένη τιμή είναι **false** .


### Παρατηρήσεις

Όταν αυτή η ιδιότητα έχει οριστεί σε **true** , οι υπερσυνδέσεις με κλήσεις JavaScript θα αγνοηθούν κατά την αποθήκευση.


Όταν αυτή η ιδιότητα έχει οριστεί σε **false** , όλες οι υπερσυνδέσεις θα αποθηκευτούν.
