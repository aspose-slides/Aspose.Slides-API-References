## IHtmlGenerator κλάση

Δημιουργός HTML.

Ο τύπος IHtmlGenerator εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`slide_image_size`](/slides/python-net/el/aspose.slides.export/ihtmlgenerator/slide_image_size/) | Επιστρέφει το μέγεθος της εικόνας της διαφάνειας.<br/>            Μόνο ανάγνωση **aspose.slides.SizeF**. |
| [`slide_image_size_unit`](/slides/python-net/el/aspose.slides.export/ihtmlgenerator/slide_image_size_unit/) | Επιστρέφει τη μονάδα με την οποία καθορίζεται το μέγεθος της εικόνας της διαφάνειας.<br/>            Μόνο ανάγνωση [`SvgCoordinateUnit`](/slides/python-net/el/aspose.slides.export/svgcoordinateunit). |
| [`slide_image_size_unit_code`](/slides/python-net/el/aspose.slides.export/ihtmlgenerator/slide_image_size_unit_code/) | Επιστρέφει έναν κώδικα css της μονάδας με την οποία καθορίζεται το μέγεθος της εικόνας της διαφάνειας.<br/>            Μόνο ανάγνωση **str**. |
| [`previous_slide_index`](/slides/python-net/el/aspose.slides.export/ihtmlgenerator/previous_slide_index/) | Επιστρέφει τον δείκτη της προηγούμενης διαφάνειας που αποδόθηκε ή -1 αν αποδίδεται η πρώτη διαφάνεια.<br/>            Μόνο ανάγνωση **int**. |
| [`slide_index`](/slides/python-net/el/aspose.slides.export/ihtmlgenerator/slide_index/) | Επιστρέφει τον δείκτη της τρέχουσας διαφάνειας που αποδίδεται.<br/>            Μόνο ανάγνωση **int**. |
| [`next_slide_index`](/slides/python-net/el/aspose.slides.export/ihtmlgenerator/next_slide_index/) | Επιστρέφει τον δείκτη μιας διαφάνειας που θα αποδοθεί μετά την τρέχουσα διαφάνεια ή -1 αν η τρέχουσα διαφάνεια είναι η τελευταία.<br/>            Μόνο ανάγνωση **int**. |
