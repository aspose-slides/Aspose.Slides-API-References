## IHtmlGenerator κλάση

Γεννήτρια HTML.

Ο τύπος IHtmlGenerator εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`slide_image_size`](/slides/python-net/el/aspose.slides.export/ihtmlgenerator/slide_image_size/) | Επιστρέφει το μέγεθος της εικόνας της διαφάνειας.<br/>            Μόνο για ανάγνωση [`SizeF`](/slides/python-net/el/aspose.slides/sizef). |
| [`slide_image_size_unit`](/slides/python-net/el/aspose.slides.export/ihtmlgenerator/slide_image_size_unit/) | Επιστρέφει τη μονάδα στην οποία καθορίζεται το μέγεθος της εικόνας της διαφάνειας.<br/>            Μόνο για ανάγνωση [`SvgCoordinateUnit`](/slides/python-net/el/aspose.slides.export/svgcoordinateunit). |
| [`slide_image_size_unit_code`](/slides/python-net/el/aspose.slides.export/ihtmlgenerator/slide_image_size_unit_code/) | Επιστρέφει έναν κώδικα css της μονάδας στην οποία καθορίζεται το μέγεθος της εικόνας της διαφάνειας.<br/>            Μόνο για ανάγνωση **str**. |
| [`previous_slide_index`](/slides/python-net/el/aspose.slides.export/ihtmlgenerator/previous_slide_index/) | Επιστρέφει το δείκτη της προηγούμενης απεικόνισης διαφάνειας ή -1 αν η πρώτη διαφάνεια βρίσκεται σε απόδοση.<br/>            Μόνο για ανάγνωση **int**. |
| [`slide_index`](/slides/python-net/el/aspose.slides.export/ihtmlgenerator/slide_index/) | Επιστρέφει το δείκτη της τρέχουσας απεικόνισης διαφάνειας.<br/>            Μόνο για ανάγνωση **int**. |
| [`next_slide_index`](/slides/python-net/el/aspose.slides.export/ihtmlgenerator/next_slide_index/) | Επιστρέφει το δείκτη μιας διαφάνειας που θα απεικονιστεί μετά την τρέχουσα διαφάνεια ή -1 αν η τρέχουσα είναι η τελευταία.<br/>            Μόνο για ανάγνωση **int**. |
