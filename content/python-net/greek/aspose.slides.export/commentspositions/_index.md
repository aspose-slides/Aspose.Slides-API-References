## απαρίθμηση CommentsPositions

Αντιπροσωπεύει τον κανόνα για την απόδοση σχολίων στο εξαγόμενο έγγραφο

Ο τύπος CommentsPositions εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| NONE | Καθορίζει ότι τα σχόλια δεν πρέπει να εμφανίζονται καθόλου. |
| BOTTOM | Καθορίζει ότι τα σχόλια πρέπει να εμφανίζονται στο κάτω μέρος της σελίδας. |
| RIGHT | Καθορίζει ότι τα σχόλια πρέπει να εμφανίζονται δεξιά της σελίδας. |
