## IInkOptions κλάση

Παρέχει επιλογές που ελέγχουν την εμφάνιση των Ink αντικειμένων σε εξαγόμενο έγγραφο.

Ο τύπος IInkOptions εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`hide_ink`](/slides/python-net/el/aspose.slides.export/iinkoptions/hide_ink/) | Εμφανίζει ή κρύβει τα στοιχεία Ink σε εξαγόμενο έγγραφο. |
| [`interpret_mask_op_as_opacity`](/slides/python-net/el/aspose.slides.export/iinkoptions/interpret_mask_op_as_opacity/) | Χρησιμοποιεί την ενέργεια ROP ή Opacity για την απόδοση του πινέλου. |
