## CompressionLevel απαρίθμηση

Καθορίζει τα επίπεδα συμπίεσης ZIP για το αρχείο OpenXML.
Τα υψηλότερα επίπεδα προσφέρουν καλύτερη συμπίεση με κόστος πιο αργής επεξεργασίας.

Ο τύπος CompressionLevel εκθέτει τα παρακάτω μέλη:

## Πεδία

| Field | Description |
| :- | :- |
| NONE | Δεν εφαρμόζεται συμπίεση. Τα αρχεία αποθηκεύονται όπως είναι. |
| LEVEL1 | Η πιο γρήγορη συμπίεση με τη χαμηλότερη αναλογία συμπίεσης. |
| LEVEL2 | Ταχύτερη συμπίεση με ελαφρώς καλύτερη αναλογία συμπίεσης από το [`CompressionLevel.LEVEL1`](/slides/python-net/el/aspose.slides.export/compressionlevel/LEVEL1). |
| LEVEL3 | Παρέχει καλύτερη συμπίεση από το [`CompressionLevel.LEVEL2`](/slides/python-net/el/aspose.slides.export/compressionlevel/LEVEL2) με μέτρια επίδραση στην απόδοση. |
| LEVEL4 | Παρέχει καλύτερη συμπίεση από το [`CompressionLevel.LEVEL3`](/slides/python-net/el/aspose.slides.export/compressionlevel/LEVEL3). |
| LEVEL5 | Παρέχει βελτιωμένη συμπίεση σε σχέση με το [`CompressionLevel.LEVEL4`](/slides/python-net/el/aspose.slides.export/compressionlevel/LEVEL4) με πρόσθετο χρόνο επεξεργασίας. |
| LEVEL6 | Κανονική συμπίεση, προσφέροντας μια καλή ισορροπία μεταξύ ταχύτητας συμπίεσης και μεγέθους αρχείου.<br/>            Το προεπιλεγμένο επίπεδο συμπίεσης. |
| LEVEL7 | Παρέχει υψηλότερη συμπίεση από το [`CompressionLevel.LEVEL6`](/slides/python-net/el/aspose.slides.export/compressionlevel/LEVEL6) με πιο αργή επεξεργασία. |
| LEVEL8 | Παρέχει υψηλότερη συμπίεση από το [`CompressionLevel.LEVEL7`](/slides/python-net/el/aspose.slides.export/compressionlevel/LEVEL7). |
| LEVEL9 | Μέγιστη συμπίεση. Παράγει το μικρότερο μέγεθος αρχείου με την πιο αργή ταχύτητα επεξεργασίας. |
