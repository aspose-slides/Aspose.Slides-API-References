## embed_true_type_fonts_for_ascii ιδιότητα
True για την ενσωμάτωση γραμματοσειρών TrueType για χαρακτήρες ASCII 32-127.
            Οι γραμματοσειρές για κωδικούς χαρακτήρων μεγαλύτερους από 127 ενσωματώνονται πάντα.
            Ανάγνωση/Εγγραφή **bool**.


### Παρατηρήσεις

Η προεπιλογή είναι **true** .
