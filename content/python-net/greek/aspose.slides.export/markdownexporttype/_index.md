## MarkdownExportType enumeration

Τύπος απόδοσης εγγράφου.

Ο τύπος MarkdownExportType εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| SEQUENTIAL | Απόδοση όλων των στοιχείων ξεχωριστά. Ένα-ένα. |
| TEXT_ONLY | Απόδοση μόνο κειμένου. |
| VISUAL | Απόδοση όλων των στοιχείων, των στοιχείων που είναι ομαδοποιημένα - απόδοση μαζί. |
