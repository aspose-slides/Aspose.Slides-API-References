## skip_java_script_links ιδιότητα
Καθορίζει εάν θα παραλειφθούν υπερσύνδεσμοι με κλήσεις JavaScript κατά την αποθήκευση της παρουσίασης. 
            Ανάγνωση/εγγραφή **bool**. Η προεπιλεγμένη τιμή είναι **false** .


### Παρατηρήσεις

Όταν αυτή η ιδιότητα ορίζεται σε **true** , οι υπερσύνδεσμοι με κλήσεις JavaScript θα αγνοηθούν κατά την αποθήκευση.


Όταν αυτή η ιδιότητα ορίζεται σε **false** , όλοι οι υπερσύνδεσμοι θα αποθηκευτούν.
