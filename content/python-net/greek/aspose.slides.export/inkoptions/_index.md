## InkOptions κλάση

Παρέχει επιλογές που ελέγχουν την εμφάνιση των αντικειμένων Ink σε εξαγόμενο έγγραφο.

Ο τύπος InkOptions εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`hide_ink`](/slides/python-net/el/aspose.slides.export/inkoptions/hide_ink/) | Εμφανίζει ή αποκρύπτει στοιχεία Ink σε εξαγόμενο έγγραφο. |
| [`interpret_mask_op_as_opacity`](/slides/python-net/el/aspose.slides.export/inkoptions/interpret_mask_op_as_opacity/) | Χρησιμοποιεί λειτουργία ROP ή Opacity για την απόδοση του πινέλου. |
