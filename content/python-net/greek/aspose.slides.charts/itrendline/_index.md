## ITrendline κλάση

Η κλάση αντιπροσωπεύει τη γραμμή τάσης της σειράς διαγράμματος

Ο τύπος ITrendline εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`trendline_name`](/slides/python-net/el/aspose.slides.charts/itrendline/trendline_name/) | Λαμβάνει ή ορίζει το όνομα της γραμμής τάσης.<br/>            Ανάγνωση/εγγραφή **str**. |
| [`trendline_type`](/slides/python-net/el/aspose.slides.charts/itrendline/trendline_type/) | Λαμβάνει ή ορίζει τον τύπο της γραμμής τάσης. <br/>            Ανάγνωση/εγγραφή [`ITrendline.trendline_type`](/slides/python-net/el/aspose.slides.charts/itrendline/trendline_type). |
| [`format`](/slides/python-net/el/aspose.slides.charts/itrendline/format/) | Αναπαριστά τη μορφή της γραμμής τάσης.<br/>            Ανάγνωση/εγγραφή [`IFormat`](/slides/python-net/el/aspose.slides.charts/iformat). |
| [`backward`](/slides/python-net/el/aspose.slides.charts/itrendline/backward/) | Καθορίζει τον αριθμό των κατηγοριών (ή μονάδων σε διάγραμμα διασποράς) που επεκτείνεται η γραμμή τάσης πριν<br/>            τα δεδομένα της σειράς που υποβάλλεται σε τάση. Σε διαγράμματα διασποράς και μη-διασποράς, η τιμή πρέπει να είναι οποιαδήποτε μη-αρνητική<br/>            τιμή.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`forward`](/slides/python-net/el/aspose.slides.charts/itrendline/forward/) | Καθορίζει τον αριθμό των κατηγοριών (ή μονάδων σε διάγραμμα διασποράς) που η γραμμή τάσης επεκτείνεται μετά το<br/>            δεδομένα της σειράς που υποβάλλεται σε τάση. Σε διαγράμματα διασποράς και μη-διασποράς, η τιμή πρέπει να είναι οποιαδήποτε μη-αρνητική<br/>            τιμή.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`intercept`](/slides/python-net/el/aspose.slides.charts/itrendline/intercept/) | Καθορίζει την τιμή στην οποία η γραμμή τάσης θα διασχίσει τον άξονα y. Αυτή η ιδιότητα υποστηρίζεται μόνο<br/>            όταν ο τύπος της γραμμής τάσης είναι exp, linear ή poly.<br/>            Ανάγνωση/εγγραφή **float**. |
| [`display_equation`](/slides/python-net/el/aspose.slides.charts/itrendline/display_equation/) | Καθορίζει ότι η εξίσωση της γραμμής τάσης εμφανίζεται στο διάγραμμα (στο ίδιο ετικέτα με την τιμή Rsquaredvalue).<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`order`](/slides/python-net/el/aspose.slides.charts/itrendline/order/) | Καθορίζει τη σειρά της πολυωνυμικής γραμμής τάσης. Παραβλέπεται για άλλους τύπους γραμμής τάσης. Η τιμή πρέπει να είναι μεταξύ 2 και 6.<br/>            Ανάγνωση/εγγραφή **int**. |
| [`period`](/slides/python-net/el/aspose.slides.charts/itrendline/period/) | Καθορίζει την περίοδο της γραμμής τάσης για μια γραμμή τάσης κινητού μέσου. Παραβλέπεται για άλλες παραλλαγές γραμμής τάσης.<br/>            Η τιμή πρέπει να είναι μεταξύ 2 και 255.<br/>            Ανάγνωση/εγγραφή **int**. |
| [`display_r_squared_value`](/slides/python-net/el/aspose.slides.charts/itrendline/display_r_squared_value/) | Καθορίζει ότι η τιμή R-squared της γραμμής τάσης εμφανίζεται στο διάγραμμα (στο ίδιο ετικέτα με την εξίσωση).<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`related_legend_entry`](/slides/python-net/el/aspose.slides.charts/itrendline/related_legend_entry/) | Αναπαριστά την καταχώρηση του υπομνήματος που σχετίζεται με αυτή τη γραμμή τάσης<br/>            Μόνο-ανάγνωση [`ILegendEntryProperties`](/slides/python-net/el/aspose.slides.charts/ilegendentryproperties). |
| [`text_frame_for_overriding`](/slides/python-net/el/aspose.slides.charts/itrendline/text_frame_for_overriding/) |  |
