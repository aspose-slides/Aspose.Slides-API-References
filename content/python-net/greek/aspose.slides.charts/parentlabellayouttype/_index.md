## ParentLabelLayoutType απαρίθμηση

Αναπαριστά τη διάταξη των ετικετών δεδομένων κατηγορίας. Χρησιμοποιείται μόνο με τη σειρά Treemap.

Ο τύπος ParentLabelLayoutType εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| BANNER | Καθορίζει ότι οι ετικέτες γονικής κατηγορίας εμφανίζονται ως πανό |
| NONE | Καθορίζει ότι οι ετικέτες γονικής κατηγορίας δεν σχεδιάζονται |
| OVERLAPPING | Καθορίζει ότι οι ετικέτες γονικής κατηγορίας εμφανίζονται ως επικάλυψη |
