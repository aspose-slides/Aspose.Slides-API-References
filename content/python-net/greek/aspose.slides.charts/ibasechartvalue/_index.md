## IBaseChartValue κλάση

Αντιπροσωπεύει μια τιμή ενός διαγράμματος.

Ο τύπος IBaseChartValue εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`data_source_type`](/slides/python-net/el/aspose.slides.charts/ibasechartvalue/data_source_type/) | Καθορίζει αν η ιδιότητα AsCell ή AsLiteralString ή AsLiteralDouble είναι ενεργή. <br/>            Με άλλα λόγια, καθορίζει τον τύπο τιμής της ιδιότητας Data. <br/>            Αυτή η ιδιότητα είναι μόνο για ανάγνωση. Για την αλλαγή της τιμής αυτής της ιδιότητας μπορείτε να χρησιμοποιήσετε <br/>            μία από τις ιδιότητες ChartDataPointCollection.DataSourceTypeFor<...>. <br/>            Ανάγνωση/εγγραφή [`IBaseChartValue.data_source_type`](/slides/python-net/el/aspose.slides.charts/ibasechartvalue/data_source_type). |
| [`data`](/slides/python-net/el/aspose.slides.charts/ibasechartvalue/data/) | Ανάγνωση/εγγραφή **οποιοδήποτε**. |
