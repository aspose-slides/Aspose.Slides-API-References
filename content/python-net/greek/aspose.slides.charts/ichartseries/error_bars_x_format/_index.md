## error_bars_x_format ιδιότητα
Αντιπροσωπεύει ErrorBars της σειράς με κατεύθυνση X.

            Τα ErrorBars με κατεύθυνση X είναι διαθέσιμα για σειρές τύπου area, bar, scatter και bubble.
            Για οποιουσδήποτε άλλους τύπους γραφήματος αυτή η ιδιότητα επιστρέφει None (συμπεριλαμβανομένων των 3D γραφημάτων).
            Σε περίπτωση προσαρμοσμένων τιμών χρησιμοποιήστε τη συλλογή DataPoints για να καθορίσετε την τιμή
            (with [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/el/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) ιδιότητα).

            Μόνο-ανάγνωση [`IErrorBarsFormat`](/slides/python-net/el/aspose.slides.charts/ierrorbarsformat).
