## ChartPlotArea κλάση

Αναπαριστά το ορθογώνιο όπου θα σχεδιαστεί το γράφημα.

Ο τύπος ChartPlotArea εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`format`](/slides/python-net/el/aspose.slides.charts/chartplotarea/format/) | Επιστρέφει τη μορφή μιας περιοχής διαγράμματος.<br/>            Μόνο για ανάγνωση [`IFormat`](/slides/python-net/el/aspose.slides.charts/iformat). |
| [`x`](/slides/python-net/el/aspose.slides.charts/chartplotarea/x/) | Επιστρέφει ή ορίζει τη συντεταγμένη x του άνω αριστερού γωνιακού σημείου του πλαισίου περιοχής διαγράμματος ως κλάσμα του πλάτους του γραφήματος (από 0 έως 1).<br/>            Ανάγνωση/εγγραφή **float**. |
| [`y`](/slides/python-net/el/aspose.slides.charts/chartplotarea/y/) | Επιστρέφει ή ορίζει τη συντεταγμένη y του άνω αριστερού γωνιακού σημείου του πλαισίου περιοχής διαγράμματος ως κλάσμα του ύψους του γραφήματος (από 0 έως 1).<br/>            Ανάγνωση/εγγραφή **float**. |
| [`width`](/slides/python-net/el/aspose.slides.charts/chartplotarea/width/) | Επιστρέφει ή ορίζει το πλάτος του πλαισίου περιοχής διαγράμματος ως κλάσμα του πλάτους του γραφήματος (από 0 έως 1).<br/>            Ανάγνωση/εγγραφή **float**. |
| [`height`](/slides/python-net/el/aspose.slides.charts/chartplotarea/height/) | Επιστρέφει ή ορίζει το ύψος του πλαισίου περιοχής διαγράμματος ως κλάσμα του ύψους του γραφήματος (από 0 έως 1).<br/>            Ανάγνωση/εγγραφή **float**. |
| [`right`](/slides/python-net/el/aspose.slides.charts/chartplotarea/right/) | Δεξιά.<br/>            Μόνο για ανάγνωση **float**. |
| [`bottom`](/slides/python-net/el/aspose.slides.charts/chartplotarea/bottom/) | Κάτω.<br/>            Μόνο για ανάγνωση **float**. |
| [`chart`](/slides/python-net/el/aspose.slides.charts/chartplotarea/chart/) | Διάγραμμα.<br/>            Μόνο για ανάγνωση [`IChart`](/slides/python-net/el/aspose.slides.charts/ichart). |
| [`is_location_autocalculated`](/slides/python-net/el/aspose.slides.charts/chartplotarea/is_location_autocalculated/) | Καθορίζει πώς πρέπει να υπολογίζεται η θέση: true – υπολογίζεται αυτόματα· ορίζεται από τις ιδιότητες X, Y, Width, Height.<br/>            Μόνο για ανάγνωση **bool**. |
| [`layout_target_type`](/slides/python-net/el/aspose.slides.charts/chartplotarea/layout_target_type/) | Εάν η διάταξη της περιοχής διαγράμματος ορίζεται χειροκίνητα, αυτή η ιδιότητα καθορίζει εάν <br/>             να διατεθεί η περιοχή διαγράμματος από το εσωτερικό της (χωρίς άξονα και ετικέτες άξονα) ή από το εξωτερικό<br/>             (με άξονα και ετικέτες άξονα).<br/>             Ανάγνωση/εγγραφή [`ChartPlotArea.layout_target_type`](/slides/python-net/el/aspose.slides.charts/chartplotarea/layout_target_type). |
| [`actual_x`](/slides/python-net/el/aspose.slides.charts/chartplotarea/actual_x/) | Καθορίζει την πραγματική θέση x (αριστερά) του στοιχείου του γραφήματος σε σχέση με την αριστερή άνω γωνία του γραφήματος.<br/>            Κλήση μεθόδου IChart.ValidateChartLayout() πριν για λήψη των πραγματικών τιμών. <br/>            Ανάγνωση **float**. |
| [`actual_y`](/slides/python-net/el/aspose.slides.charts/chartplotarea/actual_y/) | Καθορίζει το πραγματικό πάνω μέρος του στοιχείου του γραφήματος σε σχέση με την αριστερή άνω γωνία του γραφήματος.<br/>            Κλήση μεθόδου IChart.ValidateChartLayout() πριν για λήψη των πραγματικών τιμών. <br/>            Ανάγνωση **float**. |
| [`actual_width`](/slides/python-net/el/aspose.slides.charts/chartplotarea/actual_width/) | Καθορίζει το πραγματικό πλάτος του στοιχείου του γραφήματος. Κλήση μεθόδου IChart.ValidateChartLayout() πριν για λήψη των πραγματικών τιμών. <br/>            Ανάγνωση **float**. |
| [`actual_height`](/slides/python-net/el/aspose.slides.charts/chartplotarea/actual_height/) | Καθορίζει το πραγματικό ύψος του στοιχείου του γραφήματος. Κλήση μεθόδου IChart.ValidateChartLayout() πριν για λήψη των πραγματικών τιμών. <br/>            Ανάγνωση **float**. |
