## ChartTextFormat κλάση

Καθορίζει την προεπιλεγμένη μορφοποίηση κειμένου για στοιχεία κειμένου διαγράμματος.

Ο τύπος ChartTextFormat εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`text_block_format`](/slides/python-net/el/aspose.slides.charts/charttextformat/text_block_format/) | TextBlockFormat.<br/>            Μόνο για ανάγνωση [`IChartTextBlockFormat`](/slides/python-net/el/aspose.slides.charts/icharttextblockformat). |
| [`paragraph_format`](/slides/python-net/el/aspose.slides.charts/charttextformat/paragraph_format/) | ParagraphFormat.<br/>            Μόνο για ανάγνωση [`IChartParagraphFormat`](/slides/python-net/el/aspose.slides.charts/ichartparagraphformat). |
| [`portion_format`](/slides/python-net/el/aspose.slides.charts/charttextformat/portion_format/) | PortionFormat.<br/>            Μόνο για ανάγνωση [`IChartPortionFormat`](/slides/python-net/el/aspose.slides.charts/ichartportionformat). |
