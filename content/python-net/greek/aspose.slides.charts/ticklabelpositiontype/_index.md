## TickLabelPositionType αρίθμηση

Αναπαριστά τον τύπο θέσης των ετικετών των σημείων σήμανσης στον καθορισμένο άξονα.

Ο τύπος TickLabelPositionType εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| HIGH | Καθορίζει ότι οι ετικέτες του άξονα θα βρίσκονται στο υψηλό άκρο του κάθετου άξονα. |
| LOW | Καθορίζει ότι οι ετικέτες του άξονα θα βρίσκονται στο χαμηλό άκρο του κάθετου άξονα. |
| NEXT_TO | Καθορίζει ότι οι ετικέτες του άξονα θα βρίσκονται δίπλα στον άξονα. |
| NONE | Καθορίζει ότι οι ετικέτες του άξονα δεν σχεδιάζονται. |
