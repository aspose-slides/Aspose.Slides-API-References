## data_source_type_for_x_values ιδιότητα

            είναι ενεργή στο αντικείμενο ιδιότητας XValue των σημείων δεδομένων. Με άλλα λόγια, καθορίζει
            τον τύπο τιμής της ιδιότητας ChartDataPointEx.XValue.Data.
