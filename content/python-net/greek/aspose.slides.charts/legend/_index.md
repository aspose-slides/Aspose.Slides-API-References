## Legend κλάση

Αναπαριστά τις ιδιότητες του υπομνήματος του γραφήματος.

Ο τύπος Legend εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`x`](/slides/python-net/el/aspose.slides.charts/legend/x/) | Επιστρέφει ή ορίζει τη συντεταγμένη x ενός υπομνήματος ως κλάσμα του πλάτους του γραφήματος.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`y`](/slides/python-net/el/aspose.slides.charts/legend/y/) | Επιστρέφει ή ορίζει τη συντεταγμένη y ενός υπομνήματος ως κλάσμα του ύψους του γραφήματος.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`width`](/slides/python-net/el/aspose.slides.charts/legend/width/) | Επιστρέφει ή ορίζει το πλάτος ενός υπομνήματος ως κλάσμα του πλάτους του γραφήματος.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`height`](/slides/python-net/el/aspose.slides.charts/legend/height/) | Επιστρέφει ή ορίζει το ύψος ενός υπομνήματος ως κλάσμα του ύψους του γραφήματος.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`right`](/slides/python-net/el/aspose.slides.charts/legend/right/) | Δεξιά.<br/>            Μόνο-ανάγνωση **float**. |
| [`bottom`](/slides/python-net/el/aspose.slides.charts/legend/bottom/) | Κάτω.<br/>            Μόνο-ανάγνωση **float**. |
| [`overlay`](/slides/python-net/el/aspose.slides.charts/legend/overlay/) | Καθορίζει εάν άλλα στοιχεία του γραφήματος επιτρέπεται να επικαλύπτουν το υπόμνημα.<br/>            Ανάγνωση/Εγγραφή **bool**. |
| [`text_format`](/slides/python-net/el/aspose.slides.charts/legend/text_format/) | Μορφή κειμένου.<br/>            Μόνο-ανάγνωση [`IChartTextFormat`](/slides/python-net/el/aspose.slides.charts/icharttextformat). |
| [`position`](/slides/python-net/el/aspose.slides.charts/legend/position/) | Καθορίζει τη θέση του υπομνήματος σε ένα γράφημα.<br/>            Μη-NaN τιμές των ιδιοτήτων X, Y, Width, Height παρακάμπτουν την επίδραση αυτής της ιδιότητας.<br/>            Ανάγνωση/Εγγραφή [`LegendPositionType`](/slides/python-net/el/aspose.slides.charts/legendpositiontype). |
| [`format`](/slides/python-net/el/aspose.slides.charts/legend/format/) | Επιστρέφει τη μορφή ενός υπομνήματος.<br/>            Μόνο-ανάγνωση [`IFormat`](/slides/python-net/el/aspose.slides.charts/iformat). |
| [`chart`](/slides/python-net/el/aspose.slides.charts/legend/chart/) | Επιστρέφει το γράφημα.<br/>            Μόνο-ανάγνωση [`IChart`](/slides/python-net/el/aspose.slides.charts/ichart). |
| [`entries`](/slides/python-net/el/aspose.slides.charts/legend/entries/) | Ανακτά τις καταχωρίσεις του υπομνήματος.<br/>            Μόνο-ανάγνωση [`ILegendEntryCollection`](/slides/python-net/el/aspose.slides.charts/ilegendentrycollection). |
| [`actual_x`](/slides/python-net/el/aspose.slides.charts/legend/actual_x/) | Καθορίζει την πραγματική τοποθεσία x (αριστερά) του στοιχείου γραφήματος σε σχέση με την αριστερή επάνω γωνία του γραφήματος.<br/>            Κλήση μεθόδου IChart.ValidateChartLayout() πριν για λήψη πραγματικών τιμών. <br/>            Ανάγνωση **float**. |
| [`actual_y`](/slides/python-net/el/aspose.slides.charts/legend/actual_y/) | Καθορίζει το πραγματικό επάνω μέρος του στοιχείου γραφήματος σε σχέση με την αριστερή επάνω γωνία του γραφήματος.<br/>            Κλήση μεθόδου IChart.ValidateChartLayout() πριν για λήψη πραγματικών τιμών. <br/>            Ανάγνωση **float**. |
| [`actual_width`](/slides/python-net/el/aspose.slides.charts/legend/actual_width/) | Καθορίζει το πραγματικό πλάτος του στοιχείου γραφήματος. Κλήση μεθόδου IChart.ValidateChartLayout() πριν για λήψη πραγματικών τιμών. <br/>            Ανάγνωση **float**. |
| [`actual_height`](/slides/python-net/el/aspose.slides.charts/legend/actual_height/) | Καθορίζει το πραγματικό ύψος του στοιχείου γραφήματος. Κλήση μεθόδου IChart.ValidateChartLayout() πριν για λήψη πραγματικών τιμών. <br/>            Ανάγνωση **float**. |
