## Απαρίθμηση LegendDataLabelPosition

Καθορίζει τη θέση των ετικετών δεδομένων.

Ο τύπος LegendDataLabelPosition εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| NOT_DEFINED | Η θέση δεν έχει οριστεί. |
| BOTTOM | Καθορίζει ότι οι ετικέτες δεδομένων θα εμφανίζονται κάτω από το σημάδι δεδομένων. |
| BEST_FIT | Καθορίζει ότι οι ετικέτες δεδομένων θα εμφανίζονται στην καλύτερη θέση. |
| CENTER | Καθορίζει ότι οι ετικέτες δεδομένων θα εμφανίζονται κεντραρισμένες στο σημάδι δεδομένων. |
| INSIDE_BASE | Καθορίζει ότι οι ετικέτες δεδομένων θα εμφανίζονται μέσα στη βάση του σημαδιού δεδομένων. |
| INSIDE_END | Καθορίζει ότι οι ετικέτες δεδομένων θα εμφανίζονται μέσα στο άκρο του σημαδιού δεδομένων. |
| LEFT | Καθορίζει ότι οι ετικέτες δεδομένων θα εμφανίζονται στα αριστερά του σημαδιού δεδομένων. |
| OUTSIDE_END | Καθορίζει ότι οι ετικέτες δεδομένων θα εμφανίζονται έξω από το άκρο του σημαδιού δεδομένων. |
| RIGHT | Καθορίζει ότι οι ετικέτες δεδομένων θα εμφανίζονται στα δεξιά του σημαδιού δεδομένων. |
| TOP | Καθορίζει ότι οι ετικέτες δεδομένων θα εμφανίζονται πάνω από το σημάδι δεδομένων. |
