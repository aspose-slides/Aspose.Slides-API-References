## Απαρίθμηση DataSourceType

Τύποι πηγής δεδομένων.

Ο τύπος DataSourceType εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδία | Περιγραφή |
| :- | :- |
| WORKSHEET | Χρησιμοποιήστε αντικείμενα CellXls για την αποθήκευση του XValue, YValue, Value ή BubbleSize του σημείου δεδομένων στο φύλλο εργασίας. |
| STRING_LITERALS | Χρησιμοποιήστε μεταβλητή συμβολοσειράς γρήγορης πρόσβασης για την αποθήκευση του XValue, YValue, Value ή BubbleSize του <br/>            σημείου δεδομένων. Το φύλλο εργασίας ΔΕΝ χρησιμοποιείται για την αποθήκευση των τιμών. |
| DOUBLE_LITERALS | Χρησιμοποιήστε μεταβλητή double γρήγορης πρόσβασης για την αποθήκευση του XValue, YValue, Value ή BubbleSize του <br/>            σημείου δεδομένων. Το φύλλο εργασίας ΔΕΝ χρησιμοποιείται για την αποθήκευση των τιμών. |
