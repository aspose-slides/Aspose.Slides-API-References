## use_cells ιδιότητα
Αν είναι true τότε το worksheet χρησιμοποιείται για την αποθήκευση κατηγοριών (αυτή η περίπτωση υποστηρίζει κατηγορίες πολλαπλών επιπέδων).
Αν είναι false τότε το worksheet ΔΕΝ χρησιμοποιείται για την αποθήκευση τιμών (και αυτή η περίπτωση δεν υποστηρίζει κατηγορίες πολλαπλών επιπέδων).
Ανάγνωση/εγγραφή **bool**.
