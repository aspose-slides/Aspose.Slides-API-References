## ChartCategoryCollection κλάση

Αντιπροσωπεύει τη συλλογή των [`ChartCategory`](/slides/python-net/el/aspose.slides.charts/chartcategory)

Ο τύπος ChartCategoryCollection εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`use_cells`](/slides/python-net/el/aspose.slides.charts/chartcategorycollection/use_cells/) | Εάν είναι true τότε το φύλλο εργασίας χρησιμοποιείται για την αποθήκευση κατηγοριών (σε αυτήν την περίπτωση υποστηρίζονται κατηγορίες πολλαπλών επιπέδων).<br/>            Εάν είναι false τότε το φύλλο εργασίας ΔΕΝ χρησιμοποιείται για την αποθήκευση τιμών (και αυτή η περίπτωση δεν υποστηρίζει <br/>            κατηγορίες πολλαπλών επιπέδων).<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`grouping_level_count`](/slides/python-net/el/aspose.slides.charts/chartcategorycollection/grouping_level_count/) | Επιστρέφει τον αριθμό των επιπέδων ομαδοποίησης κατηγοριών που χρησιμοποιούνται.<br/>            Είναι μεγαλύτερο του ενός για κατηγορίες πολλαπλών επιπέδων.<br/>            Μόνο ανάγνωση **int**. |

Αποκτά το στοιχείο στον καθορισμένο δείκτη.
