## IChartTextBlockFormat κλάση

Αντιπροσωπεύει τις ιδιότητες μορφοποίησης για στοιχεία κειμένου γραφήματος.

Ο τύπος IChartTextBlockFormat εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`anchoring_type`](/slides/python-net/el/aspose.slides.charts/icharttextblockformat/anchoring_type/) | Επιστρέφει ή ορίζει το κατακόρυφο άγκυρο κειμένου σε ένα TextFrame.<br/>            Ανάγνωση/Εγγραφή [`TextAnchorType`](/slides/python-net/el/aspose.slides/textanchortype). |
| [`center_text`](/slides/python-net/el/aspose.slides.charts/icharttextblockformat/center_text/) | Εάν NullableBool.True τότε το κείμενο πρέπει να κεντραριστεί οριζόντια στο κουτί.<br/>            Ανάγνωση/Εγγραφή [`NullableBool`](/slides/python-net/el/aspose.slides/nullablebool). |
| [`text_vertical_type`](/slides/python-net/el/aspose.slides.charts/icharttextblockformat/text_vertical_type/) | Καθορίζει τον προσανατολισμό του κειμένου.<br/>            Η προκύπτουσα τιμή της οπτικής περιστροφής του κειμένου συνοψίζεται από αυτήν την ιδιότητα και την προσαρμοσμένη γωνία<br/>            στην ιδιότητα RotationAngle.<br/>            Ανάγνωση/Εγγραφή [`TextVerticalType`](/slides/python-net/el/aspose.slides/textverticaltype). |
| [`margin_left`](/slides/python-net/el/aspose.slides.charts/icharttextblockformat/margin_left/) | Επιστρέφει ή ορίζει το αριστερό περιθώριο (points) σε ένα TextFrame.<br/>            Η αλλαγή αυτής της ιδιότητας μπορεί να επηρεάσει μόνο τα παρακάτω τμήματα γραφήματος: <br/>            DataLabel και DataLabelFormat (πλήρης υποστήριξη στο PowerPoint 2013· στο PowerPoint 2007 δεν υπάρχει επίδραση στην απόδοση).<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`margin_right`](/slides/python-net/el/aspose.slides.charts/icharttextblockformat/margin_right/) | Επιστρέφει ή ορίζει το δεξί περιθώριο (points) σε ένα TextFrame.<br/>            Η αλλαγή αυτής της ιδιότητας μπορεί να επηρεάσει μόνο τα παρακάτω τμήματα γραφήματος: <br/>            DataLabel και DataLabelFormat (πλήρης υποστήριξη στο PowerPoint 2013· στο PowerPoint 2007 δεν υπάρχει επίδραση στην απόδοση).<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`margin_top`](/slides/python-net/el/aspose.slides.charts/icharttextblockformat/margin_top/) | Επιστρέφει ή ορίζει το άνω περιθώριο (points) σε ένα TextFrame.<br/>            Η αλλαγή αυτής της ιδιότητας μπορεί να επηρεάσει μόνο τα παρακάτω τμήματα γραφήματος: <br/>            DataLabel και DataLabelFormat (πλήρης υποστήριξη στο PowerPoint 2013· στο PowerPoint 2007 δεν υπάρχει επίδραση στην απόδοση).<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`margin_bottom`](/slides/python-net/el/aspose.slides.charts/icharttextblockformat/margin_bottom/) | Επιστρέφει ή ορίζει το κάτω περιθώριο (points) σε ένα TextFrame.<br/>            Η αλλαγή αυτής της ιδιότητας μπορεί να επηρεάσει μόνο τα παρακάτω τμήματα γραφήματος: <br/>            DataLabel και DataLabelFormat (πλήρης υποστήριξη στο PowerPoint 2013· στο PowerPoint 2007 δεν υπάρχει επίδραση στην απόδοση).<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`wrap_text`](/slides/python-net/el/aspose.slides.charts/icharttextblockformat/wrap_text/) | **True** εάν το κείμενο είναι αναδιπλωμένο στα περιθώρια του TextFrame.<br/>            Η αλλαγή αυτής της ιδιότητας μπορεί να επηρεάσει μόνο τα παρακάτω τμήματα γραφήματος: <br/>            DataLabel και DataLabelFormat (πλήρης υποστήριξη στο PowerPoint 2007/2013).<br/>            Ανάγνωση/Εγγραφή [`NullableBool`](/slides/python-net/el/aspose.slides/nullablebool). |
| [`autofit_type`](/slides/python-net/el/aspose.slides.charts/icharttextblockformat/autofit_type/) | Επιστρέφει ή ορίζει τη λειτουργία αυτόματης προσαρμογής του κειμένου.<br/>            Η αλλαγή αυτής της ιδιότητας μπορεί να επηρεάσει μόνο τα παρακάτω τμήματα γραφήματος: <br/>            DataLabel και DataLabelFormat (πλήρης υποστήριξη στο PowerPoint 2013· στο PowerPoint 2007 δεν υπάρχει επίδραση στην απόδοση).<br/>            Ανάγνωση/Εγγραφή [`TextAutofitType`](/slides/python-net/el/aspose.slides/textautofittype). |
| [`rotation_angle`](/slides/python-net/el/aspose.slides.charts/icharttextblockformat/rotation_angle/) | Καθορίζει την προσαρμοσμένη περιστροφή που εφαρμόζεται στο κείμενο μέσα στο περιβάλλον κουτί. Εάν δεν έχει<br/>            καθοριστεί, χρησιμοποιείται η περιστροφή του σχετικού σχήματος. Εάν καθοριστεί, τότε αυτή<br/>            εφαρμόζεται ανεξάρτητα από το σχήμα. Δηλαδή το σχήμα μπορεί να έχει μια περιστροφή που εφαρμόζεται<br/>            εκτός από την περιστροφή του ίδιου του κειμένου.<br/>            Η προκύπτουσα τιμή της οπτικής περιστροφής του κειμένου συνοψίζεται από αυτήν την ιδιότητα και τον προκαθορισμένο<br/>            κατακόρυφο τύπο στην ιδιότητα TextVerticalType.<br/>            Ανάγνωση/Εγγραφή **float**. |
