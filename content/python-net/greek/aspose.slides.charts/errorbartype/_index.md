## ErrorBarType απαρίθμηση

Αντιπροσωπεύει τον τύπο της γραμμής σφάλματος

Ο τύπος ErrorBarType εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| BOTH | Καθορίζει ότι οι γραμμές σφάλματος θα εμφανιστούν στις θετικές και αρνητικές κατευθύνσεις. |
| MINUS | Καθορίζει ότι οι γραμμές σφάλματος θα εμφανιστούν μόνο στην αρνητική κατεύθυνση. |
| PLUS | Καθορίζει ότι οι γραμμές σφάλματος θα εμφανιστούν μόνο στην θετική κατεύθυνση. |
