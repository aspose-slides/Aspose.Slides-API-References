## ChartDataCell κλάση

Αναπαριστά κελί για δεδομένα γραφήματος.

Ο τύπος ChartDataCell εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`row`](/slides/python-net/el/aspose.slides.charts/chartdatacell/row/) | Επιστρέφει το ευρετήριο της γραμμής του φύλλου εργασίας όπου βρίσκεται το κελί.<br/>Μόνο ανάγνωση **int**. |
| [`column`](/slides/python-net/el/aspose.slides.charts/chartdatacell/column/) | Επιστρέφει το ευρετήριο της στήλης του φύλλου εργασίας όπου βρίσκεται το κελί.<br/>Μόνο ανάγνωση **int**. |
| [`value`](/slides/python-net/el/aspose.slides.charts/chartdatacell/value/) | Ανάγνωση ή εγγραφή της τιμής ενός κελιού.<br/>Ανάγνωση/εγγραφή **any**. |
| [`formula`](/slides/python-net/el/aspose.slides.charts/chartdatacell/formula/) | Ανάγνωση ή εγγραφή του τύπου σε μορφή A1. |
| [`r1c1_formula`](/slides/python-net/el/aspose.slides.charts/chartdatacell/r1c1_formula/) | Ανάγνωση ή εγγραφή του τύπου σε μορφή R1C1. |
| [`chart_data_worksheet`](/slides/python-net/el/aspose.slides.charts/chartdatacell/chart_data_worksheet/) | Ανάγνωση του φύλλου εργασίας.<br/>Μόνο ανάγνωση [`IChartDataWorksheet`](/slides/python-net/el/aspose.slides.charts/ichartdataworksheet). |
| [`is_hidden`](/slides/python-net/el/aspose.slides.charts/chartdatacell/is_hidden/) | Καθορίζει αν το κελί είναι κρυμμένο.<br/>Μόνο ανάγνωση **bool**. |
| [`custom_number_format`](/slides/python-net/el/aspose.slides.charts/chartdatacell/custom_number_format/) | Ανάγνωση ή εγγραφή της προσαρμοσμένης μορφής εμφάνισης αριθμών και ημερομηνιών. <br/>Εάν η τιμή είναι κενή, θα χρησιμοποιηθεί η τιμή PresetNumberFormat.<br/>Ανάγνωση/εγγραφή **str**. |
| [`preset_number_format`](/slides/python-net/el/aspose.slides.charts/chartdatacell/preset_number_format/) | Ανάγνωση ή εγγραφή της ενσωματωμένης μορφής εμφάνισης αριθμών και ημερομηνιών. Ο προεπιλεγμένος αριθμός πρέπει να είναι σε [0..22] ή [37..49].<br/>Ανάγνωση/εγγραφή **int**. |

## Μεθόδοι

| Μέθοδος | Περιγραφή |
| :- | :- |
| [`calculate(self, update_values)`](/slides/python-net/el/aspose.slides.charts/chartdatacell/calculate/#bool) | Εάν το κελί περιέχει τύπο, η τιμή θα ενημερωθεί βάσει αυτού του τύπου. |
