## ChartDataPointCollection κλάση

Αντιπροσωπεύει τη συλλογή ενός σημείου δεδομένων σειράς.

Ο τύπος ChartDataPointCollection εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`data_source_type_for_x_values`](/slides/python-net/el/aspose.slides.charts/chartdatapointcollection/data_source_type_for_x_values/) | Καθορίζει εάν η ιδιότητα AsCell ή AsLiteralString ή AsLiteralDouble <br/> είναι ενεργή στο αντικείμενο ιδιότητας XValue των σημείων δεδομένων. Με άλλα λόγια καθορίζει <br/> τον τύπο τιμής της ιδιότητας ChartDataPoint.XValue.Data.<br/> Ανάγνωση/εγγραφή [`DataSourceType`](/slides/python-net/el/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_y_values`](/slides/python-net/el/aspose.slides.charts/chartdatapointcollection/data_source_type_for_y_values/) | Καθορίζει εάν η ιδιότητα AsCell ή AsLiteralString ή AsLiteralDouble <br/> είναι ενεργή στο αντικείμενο ιδιότητας YValue των σημείων δεδομένων. Με άλλα λόγια καθορίζει <br/> τον τύπο τιμής της ιδιότητας ChartDataPoint.YValue.Data.<br/> Ανάγνωση/εγγραφή [`DataSourceType`](/slides/python-net/el/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_bubble_sizes`](/slides/python-net/el/aspose.slides.charts/chartdatapointcollection/data_source_type_for_bubble_sizes/) | Καθορίζει εάν η ιδιότητα AsCell ή AsLiteralString ή AsLiteralDouble <br/> είναι ενεργή στο αντικείμενο ιδιότητας BubbleSize των σημείων δεδομένων. Με άλλα λόγια καθορίζει <br/> τον τύπο τιμής της ιδιότητας ChartDataPoint.BubbleSize.Data.<br/> Ανάγνωση/εγγραφή [`DataSourceType`](/slides/python-net/el/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_values`](/slides/python-net/el/aspose.slides.charts/chartdatapointcollection/data_source_type_for_values/) | Καθορίζει εάν η ιδιότητα AsCell ή AsLiteralString ή AsLiteralDouble <br/> είναι ενεργή στο αντικείμενο ιδιότητας Value των σημείων δεδομένων. Με άλλα λόγια καθορίζει <br/> τον τύπο τιμής της ιδιότητας ChartDataPoint.Value.Data.<br/> Ανάγνωση/εγγραφή [`DataSourceType`](/slides/python-net/el/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_error_bars_custom_values`](/slides/python-net/el/aspose.slides.charts/chartdatapointcollection/data_source_type_for_error_bars_custom_values/) | Καθορίζει τους τύπους τιμών στη λίστα ιδιοτήτων ChartDataPoint.ErrorBarsCustomValues.<br/> Μόνο για ανάγνωση [`IDataSourceTypeForErrorBarsCustomValues`](/slides/python-net/el/aspose.slides.charts/idatasourcetypeforerrorbarscustomvalues). |

Επιστρέφει το σημείο δεδομένων σειράς με βάση το ευρετήριο (ο σειριακός αριθμός του σε αυτή τη συλλογή).
