## StringOrDoubleChartValue κλάση

Αντιπροσωπεύει τιμή τύπου string ή double που μπορεί να αποθηκευτεί σε έγγραφο παρουσίασης pptx με δύο τρόπους:
            1) σε κελί/κελιά του φύλλου εργασίας που σχετίζονται με το γράφημα·
            2) ως κυριολεκτική τιμή.
