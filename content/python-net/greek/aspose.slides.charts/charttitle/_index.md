## ChartTitle κλάση

Αντιπροσωπεύει τις ιδιότητες του τίτλου του διαγράμματος.

Ο τύπος ChartTitle εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`x`](/slides/python-net/el/aspose.slides.charts/charttitle/x/) | Επιστρέφει ή ορίζει τη συντεταγμένη x του τίτλου ως κλάσμα του πλάτους του διαγράμματος.<br/>            **Ανάγνωση/εγγραφή** **float**. |
| [`y`](/slides/python-net/el/aspose.slides.charts/charttitle/y/) | Επιστρέφει ή ορίζει τη συντεταγμένη y του τίτλου ως κλάσμα του ύψους του διαγράμματος.<br/>            **Ανάγνωση/εγγραφή** **float**. |
| [`width`](/slides/python-net/el/aspose.slides.charts/charttitle/width/) | Επιστρέφει ή ορίζει το πλάτος του τίτλου ως κλάσμα του πλάτους του διαγράμματος.<br/>            **Ανάγνωση/εγγραφή** **float**. |
| [`height`](/slides/python-net/el/aspose.slides.charts/charttitle/height/) | Επιστρέφει ή ορίζει το ύψος του τίτλου ως κλάσμα του ύψους του διαγράμματος.<br/>            **Ανάγνωση/εγγραφή** **float**. |
| [`right`](/slides/python-net/el/aspose.slides.charts/charttitle/right/) | Δεξιά.<br/>            **Μόνο για ανάγνωση** **float**. |
| [`bottom`](/slides/python-net/el/aspose.slides.charts/charttitle/bottom/) | Κάτω.<br/>            **Μόνο για ανάγνωση** **float**. |
| [`overlay`](/slides/python-net/el/aspose.slides.charts/charttitle/overlay/) | Καθορίζει εάν άλλα στοιχεία του διαγράμματος θα επιτρέπεται να επικαλύπτουν τον τίτλο.<br/>            **Ανάγνωση/εγγραφή** **bool**. |
| [`format`](/slides/python-net/el/aspose.slides.charts/charttitle/format/) | Επιστρέφει τα στυλ γεμίσματος, γραμμής, εφέ ενός τίτλου.<br/>            **Μόνο για ανάγνωση** [`IFormat`](/slides/python-net/el/aspose.slides.charts/iformat). |
| [`text_frame_for_overriding`](/slides/python-net/el/aspose.slides.charts/charttitle/text_frame_for_overriding/) | Μπορεί να περιέχει πλούσιο μορφοποιημένο κείμενο. Εάν αυτή η ιδιότητα δεν είναι None, τότε αυτή η <br/>            μορφοποιημένη τιμή κειμένου αντικαθιστά το αυτόματα δημιουργημένο κείμενο.<br/>            Το αυτόματα δημιουργημένο κείμενο είναι μια έμμεση ιδιότητα της ετικέτας δεδομένων, της ετικέτας μονάδας εμφάνισης του άξονα τιμών, του τίτλου άξονα, του τίτλου διαγράμματος, της ετικέτας της γραμμής τάσης.<br/>            Το αυτόματα δημιουργημένο κείμενο μορφοποιείται με την ιδιότητα IFormattedTextContainer.TextFormat.<br/>            **Μόνο για ανάγνωση** [`ITextFrame`](/slides/python-net/el/aspose.slides/itextframe). |
| [`text_format`](/slides/python-net/el/aspose.slides.charts/charttitle/text_format/) | Επιστρέφει τη μορφή κειμένου.<br/>            **Μόνο για ανάγνωση** [`IChartTextFormat`](/slides/python-net/el/aspose.slides.charts/icharttextformat). |
| [`actual_x`](/slides/python-net/el/aspose.slides.charts/charttitle/actual_x/) | Καθορίζει την πραγματική θέση x (αριστερά) του στοιχείου διαγράμματος σε σχέση με την αριστερή άνω γωνία του διαγράμματος.<br/>            Κλήση της μεθόδου IChart.ValidateChartLayout() πριν για λήψη πραγματικών τιμών. <br/>            **Ανάγνωση** **float**. |
| [`actual_y`](/slides/python-net/el/aspose.slides.charts/charttitle/actual_y/) | Καθορίζει το πραγματικό επάνω μέρος του στοιχείου διαγράμματος σε σχέση με την αριστερή άνω γωνία του διαγράμματος.<br/>            Κλήση της μεθόδου IChart.ValidateChartLayout() πριν για λήψη πραγματικών τιμών. <br/>            **Ανάγνωση** **float**. |
| [`actual_width`](/slides/python-net/el/aspose.slides.charts/charttitle/actual_width/) | Καθορίζει το πραγματικό πλάτος του στοιχείου διαγράμματος. Κλήση της μεθόδου IChart.ValidateChartLayout() πριν για λήψη πραγματικών τιμών. <br/>            **Ανάγνωση** **float**. |
| [`actual_height`](/slides/python-net/el/aspose.slides.charts/charttitle/actual_height/) | Καθορίζει το πραγματικό ύψος του στοιχείου διαγράμματος. Κλήση της μεθόδου IChart.ValidateChartLayout() πριν για λήψη πραγματικών τιμών. <br/>            **Ανάγνωση** **float**. |
| [`chart`](/slides/python-net/el/aspose.slides.charts/charttitle/chart/) | Επιστρέφει το γονικό διάγραμμα.<br/>            **Μόνο για ανάγνωση** [`IChart`](/slides/python-net/el/aspose.slides.charts/ichart). |
| [`slide`](/slides/python-net/el/aspose.slides.charts/charttitle/slide/) |  |
| [`presentation`](/slides/python-net/el/aspose.slides.charts/charttitle/presentation/) |  |
