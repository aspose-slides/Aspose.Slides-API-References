## hide(self) {#}
Κάντε την ετικέτα δεδομένων κρυφή από προεπιλογή ορίζοντας όλες τις Show*-flags (ShowValue, ...) της ιδιότητας DefaultDataLabelFormat σε κατάσταση ψευδής.
            Το IsVisible θα είναι ψευδές μετά από αυτό.


```python
def hide(self):
    ...
```


### Παρατηρήσεις

Εάν η ετικέτα δεδομένων δεν είναι ορατή από προεπιλογή (IsVisible είναι ψευδές) μπορείτε να κάνετε την ετικέτα δεδομένων "ορατή 
            από προεπιλογή" ορίζοντας τις Show*-flags (ShowValue, ...) της ιδιότητας DefaultDataLabelFormat σε κατάσταση αληθής.
