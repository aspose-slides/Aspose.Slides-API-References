## default_label_shape_type ιδιότητα
Αποκτά ή ορίζει τον προεπιλεγμένο τύπο σχήματος για τις ετικέτες δεδομένων.
             Επιστρέφει [`ShapeType.NOT_DEFINED`](/slides/python-net/el/aspose.slides/shapetype/NOT_DEFINED) εάν δεν οριστεί σχήμα.

### Σχόλια

Η ρύθμιση αυτής της ιδιότητας ορίζει επίσης την ιδιότητα [`IDataLabel.label_shape_type`](/slides/python-net/el/aspose.slides.charts/idatalabel/label_shape_type)
             για όλες τις ετικέτες δεδομένων στη συλλογή στην ίδια τιμή.
