## Rotation3D κλάση

Represents 3D rotation of a chart.

The Rotation3D type exposes the following members:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`rotation_x`](/slides/python-net/el/aspose.slides.charts/rotation3d/rotation_x/) | Επιστρέφει ή ορίζει το βαθμό περιστροφής γύρω από τον άξονα X, δηλαδή στην κατεύθυνση Y για 3D διαγράμματα (μεταξύ -90 και 90 μοιρών).<br/>            Η ιδιότητα ταιριάζει με το στοιχείο 21.2.2.157 rotX (X Rotation) στο ECMA-376 και με την επιλογή "Y Rotation" στο PowerPoint 2007+.<br/>            Ανάγνωση/εγγραφή **int**. |
| [`rotation_y`](/slides/python-net/el/aspose.slides.charts/rotation3d/rotation_y/) | Επιστρέφει ή ορίζει το βαθμό περιστροφής γύρω από τον άξονα Y, δηλαδή στην κατεύθυνση X για 3D διαγράμματα (μεταξύ 0 και 360 μοιρών).<br/>            Η ιδιότητα ταιριάζει με το στοιχείο 21.2.2.158 rotY (Y Rotation) στο ECMA-376 και με την επιλογή "X Rotation" στο PowerPoint 2007+.<br/>            Ανάγνωση/εγγραφή **int**. |
| [`perspective`](/slides/python-net/el/aspose.slides.charts/rotation3d/perspective/) | Επιστρέφει ή ορίζει την τιμή προοπτικής (γωνία πεδίου θέασης) για 3D διαγράμματα (μεταξύ 0 και 240).<br/>            Αγνοείται εάν η τιμή της ιδιότητας RightAngleAxes είναι true.<br/>            Ανάγνωση/εγγραφή **int**. |
| [`right_angle_axes`](/slides/python-net/el/aspose.slides.charts/rotation3d/right_angle_axes/) | Καθορίζει εάν οι άξονες του διαγράμματος είναι σε ορθές γωνίες, αντί να σχεδιάζονται σε προοπτική.<br/>            Με άλλα λόγια, καθορίζει εάν οι γωνίες των αξόνων του διαγράμματος είναι ανεξάρτητες από το διάγραμμα <br/>            περιστροφή ή υψόμετρο.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`depth_percents`](/slides/python-net/el/aspose.slides.charts/rotation3d/depth_percents/) | Επιστρέφει ή ορίζει το βάθος ενός 3D διαγράμματος ως ποσοστό του πλάτους του διαγράμματος (μεταξύ 20 και 2000 τοις εκατό).<br/>            Ανάγνωση/εγγραφή **int**. |
| [`height_percents`](/slides/python-net/el/aspose.slides.charts/rotation3d/height_percents/) | Καθορίζει το ύψος ενός 3-D διαγράμματος ως ποσοστό του πλάτους του διαγράμματος (μεταξύ 5 και 500 τοις εκατό).<br/>            Ανάγνωση/εγγραφή **int**. |
