## LegendEntryProperties κλάση

Αντιπροσωπεύει τις ιδιότητες του υπομνήματος ενός διαγράμματος.

Ο τύπος LegendEntryProperties εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`text_format`](/slides/python-net/el/aspose.slides.charts/legendentryproperties/text_format/) | Επιστρέφει μορφή κειμένου.<br/>            Μόνο για ανάγνωση [`IChartTextFormat`](/slides/python-net/el/aspose.slides.charts/icharttextformat). |
| [`hide`](/slides/python-net/el/aspose.slides.charts/legendentryproperties/hide/) | Καθορίζει εάν η καταχώριση του υπομνήματος είναι κρυφή.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`chart`](/slides/python-net/el/aspose.slides.charts/legendentryproperties/chart/) | Επιστρέφει το γονικό διάγραμμα.<br/>            Μόνο για ανάγνωση [`IChart`](/slides/python-net/el/aspose.slides.charts/ichart). |
| [`slide`](/slides/python-net/el/aspose.slides.charts/legendentryproperties/slide/) |  |
