## AxisFormat κλάση

Αντιπροσωπεύει τις ιδιότητες μορφοποίησης γραφήματος.

Ο τύπος AxisFormat εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`fill`](/slides/python-net/el/aspose.slides.charts/axisformat/fill/) | Επιστρέφει τις ιδιότητες στυλ γεμίσματος ενός άξονα.<br/>            Μόνο-ανάγνωση [`IFillFormat`](/slides/python-net/el/aspose.slides/ifillformat). |
| [`line`](/slides/python-net/el/aspose.slides.charts/axisformat/line/) | Επιστρέφει τις ιδιότητες στυλ γραμμής ενός άξονα.<br/>            Μόνο-ανάγνωση [`ILineFormat`](/slides/python-net/el/aspose.slides/ilineformat). |
| [`effect`](/slides/python-net/el/aspose.slides.charts/axisformat/effect/) | Επιστρέφει τα εφέ που χρησιμοποιούνται για έναν άξονα.<br/>            Μόνο-ανάγνωση [`IEffectFormat`](/slides/python-net/el/aspose.slides/ieffectformat). |
