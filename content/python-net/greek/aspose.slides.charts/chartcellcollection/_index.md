## ChartCellCollection κλάση

Αντιπροσωπεύει μια συλλογή κελιών με δεδομένα.

Ο τύπος ChartCellCollection εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`count`](/slides/python-net/el/aspose.slides.charts/chartcellcollection/count/) | Επιστρέφει τον αριθμό των κελιών στη συλλογή.<br/>            Μόνο για ανάγνωση **int**. |

Επιστρέφει ένα κελί (IChartDataCell) με βάση το δείκτη.

## Δείκτης

| Όνομα | Περιγραφή |
| :- | :- |
| [`[index]`](/slides/python-net/el/aspose.slides.charts/chartcellcollection/__getitem__/) | Δείκτης ενός κελιού. |

## Μέθοδοι

| Μέθοδος | Περιγραφή |
| :- | :- |
| [`add(self, cell)`](/slides/python-net/el/aspose.slides.charts/chartcellcollection/add/#ichartdatacell) | Προσθέτει νέο κελί στη συλλογή. |
| [`add(self, value)`](/slides/python-net/el/aspose.slides.charts/chartcellcollection/add/#any) | Δημιουργεί [`ChartDataCell`](/slides/python-net/el/aspose.slides.charts/chartdatacell) από την καθορισμένη τιμή και το προσθέτει στη συλλογή. |
| [`get_cells_address(self)`](/slides/python-net/el/aspose.slides.charts/chartcellcollection/get_cells_address/#) | Επιστρέφει τη διεύθυνση του συνόλου των κελιών στο βιβλίο εργασίας. |
| [`get_concatenated_values_from_cells(self)`](/slides/python-net/el/aspose.slides.charts/chartcellcollection/get_concatenated_values_from_cells/#) | Συγκεντρώνει συμβολοσειρά από όλες τις τιμές των κελιών. |
| [`remove_at(self, index)`](/slides/python-net/el/aspose.slides.charts/chartcellcollection/remove_at/#int) | Αφαιρεί ένα κελί από τη συλλογή με βάση το δείκτη. |
