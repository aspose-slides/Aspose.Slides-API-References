## ErrorBarValueType απαρίθμηση

Αναπαριστά τον τύπο της τιμής γραμμής σφάλματος

Ο τύπος ErrorBarValueType εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| CUSTOM | Καθορίζει ότι το μήκος των γραμμών σφάλματος πρέπει να καθορίζεται από τα στοιχεία Plus και Minus. |
| FIXED | Καθορίζει ότι το μήκος των γραμμών σφάλματος πρέπει να είναι η σταθερή τιμή που καθορίζεται από το Error Bar Value. |
| PERCENTAGE | Καθορίζει ότι το μήκος των γραμμών σφάλματος πρέπει να είναι το ποσοστό Error Bar Value των δεδομένων. |
| STANDARD_DEVIATION | Καθορίζει ότι το μήκος των γραμμών σφάλματος πρέπει να είναι το Error Bar Value τυπικές αποκλίσεις των δεδομένων. |
| STANDARD_ERROR | Καθορίζει ότι το μήκος των γραμμών σφάλματος πρέπει να είναι το Error Bar Value τυπικά σφάλματα των δεδομένων. |
