## TickMarkType απαρίθμηση

Αντιπροσωπεύει τον τύπο σημείου στίξης για τον καθορισμένο άξονα.

Ο τύπος TickMarkType εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| CROSS | Καθορίζει ότι τα σημεία στίξης θα διασχίζουν τον άξονα. |
| INSIDE | Καθορίζει ότι τα σημεία στίξης θα είναι μέσα στην περιοχή του διαγράμματος. |
| NONE | Καθορίζει ότι δεν θα υπάρχουν σημεία στίξης. |
| OUTSIDE | Καθορίζει ότι τα σημεία στίξης θα είναι έξω από την περιοχή του διαγράμματος. |
