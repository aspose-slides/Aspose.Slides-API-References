## UpDownBarsManager κλάση

Παρέχει πρόσβαση στις μπάρες up/down των διαγραμμάτων Line ή Stock.

Ο τύπος UpDownBarsManager εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Property | Description |
| :- | :- |
| [`up_bars_format`](/slides/python-net/el/aspose.slides.charts/updownbarsmanager/up_bars_format/) | Επιστρέφει τη μορφή UpBars.<br/>            Μόνο ανάγνωση [`IFormat`](/slides/python-net/el/aspose.slides.charts/iformat). |
| [`down_bars_format`](/slides/python-net/el/aspose.slides.charts/updownbarsmanager/down_bars_format/) | Επιστρέφει τη μορφή DownBars.<br/>            Μόνο ανάγνωση [`IFormat`](/slides/python-net/el/aspose.slides.charts/iformat). |
