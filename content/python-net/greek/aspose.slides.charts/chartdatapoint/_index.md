## ChartDataPoint κλάση

Αναπαριστά το σημείο δεδομένων της σειράς.

Ο τύπος ChartDataPoint εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`x_value`](/slides/python-net/el/aspose.slides.charts/chartdatapoint/x_value/) | XValue.<br/>            Μόνο για ανάγνωση [`IStringOrDoubleChartValue`](/slides/python-net/el/aspose.slides.charts/istringordoublechartvalue). |
| [`y_value`](/slides/python-net/el/aspose.slides.charts/chartdatapoint/y_value/) | YValue.<br/>            Μόνο για ανάγνωση [`IDoubleChartValue`](/slides/python-net/el/aspose.slides.charts/idoublechartvalue). |
| [`bubble_size`](/slides/python-net/el/aspose.slides.charts/chartdatapoint/bubble_size/) | BubbleSize.<br/>            Μόνο για ανάγνωση [`IDoubleChartValue`](/slides/python-net/el/aspose.slides.charts/idoublechartvalue). |
| [`value`](/slides/python-net/el/aspose.slides.charts/chartdatapoint/value/) | Value.<br/>            Μόνο για ανάγνωση [`IDoubleChartValue`](/slides/python-net/el/aspose.slides.charts/idoublechartvalue). |
| [`size_value`](/slides/python-net/el/aspose.slides.charts/chartdatapoint/size_value/) | Επιστρέφει την τιμή μεγέθους του σημείου δεδομένων του διαγράμματος.<br/>            Χρησιμοποιείται με διαγράμματα Treemap και Sunburst.<br/>            Μόνο για ανάγνωση [`IDoubleChartValue`](/slides/python-net/el/aspose.slides.charts/idoublechartvalue). |
| [`color_value`](/slides/python-net/el/aspose.slides.charts/chartdatapoint/color_value/) | Επιστρέφει την τιμή χρώματος του σημείου δεδομένων του διαγράμματος.<br/>            Χρησιμοποιείται με χάρτες.<br/>            Μόνο για ανάγνωση [`IDoubleChartValue`](/slides/python-net/el/aspose.slides.charts/idoublechartvalue). |
| [`error_bars_custom_values`](/slides/python-net/el/aspose.slides.charts/chartdatapoint/error_bars_custom_values/) | Αναπαριστά τις τιμές ράβδων σφάλματος σειράς στην περίπτωση τύπου τιμής Custom.<br/>            Μόνο για ανάγνωση [`IErrorBarsCustomValues`](/slides/python-net/el/aspose.slides.charts/ierrorbarscustomvalues). |
| [`label`](/slides/python-net/el/aspose.slides.charts/chartdatapoint/label/) | Ετικέτα.<br/>            Μόνο για ανάγνωση [`IDataLabel`](/slides/python-net/el/aspose.slides.charts/idatalabel). |
| [`is_bubble_3d`](/slides/python-net/el/aspose.slides.charts/chartdatapoint/is_bubble_3d/) | Καθορίζει ότι οι φυσαλίδες έχουν εφαρμοσμένο εφέ 3-Δ.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`explosion`](/slides/python-net/el/aspose.slides.charts/chartdatapoint/explosion/) | Καθορίζει το ποσό που το σημείο δεδομένων θα μετακινηθεί από το κέντρο του πίτας.<br/>            Ανάγνωση/εγγραφή **int**. |
| [`format`](/slides/python-net/el/aspose.slides.charts/chartdatapoint/format/) | Αναπαριστά τις ιδιότητες μορφοποίησης.<br/>            Ανάγνωση/εγγραφή [`IFormat`](/slides/python-net/el/aspose.slides.charts/iformat). |
| [`marker`](/slides/python-net/el/aspose.slides.charts/chartdatapoint/marker/) | Καθορίζει έναν δείκτη δεδομένων.<br/>            Μόνο για ανάγνωση [`IMarker`](/slides/python-net/el/aspose.slides.charts/imarker). |
| [`set_as_total`](/slides/python-net/el/aspose.slides.charts/chartdatapoint/set_as_total/) | Ορίζει το σημείο δεδομένων ως σύνολο. Εφαρμόζεται μόνο για τύπο σειράς Waterfall. |
| [`related_legend_entry`](/slides/python-net/el/aspose.slides.charts/chartdatapoint/related_legend_entry/) | Ιδιότητες της αντίστοιχης εγγραφής υπομείγματος στην περίπτωση τύπου διαγράμματος από αυτή τη λίστα:<br/>            ChartType.BarOfPie,<br/>            ChartType.ExplodedPie,<br/>            ChartType.ExplodedPie3D,<br/>            ChartType.Pie,<br/>            ChartType.Pie3D,<br/>            ChartType.PieOfPie.<br/>            Μόνο για ανάγνωση [`ILegendEntryProperties`](/slides/python-net/el/aspose.slides.charts/ilegendentryproperties). |
| [`data_point_levels`](/slides/python-net/el/aspose.slides.charts/chartdatapoint/data_point_levels/) | Επιστρέφει το κοντέινερ των επιπέδων σημείου δεδομένων. Εφαρμόζεται για σειρές Treeamp και Sunburst.<br/>            Η αρίθμηση επιπέδων σημείου δεδομένων ξεκινά από μηδέν. |
| [`index`](/slides/python-net/el/aspose.slides.charts/chartdatapoint/index/) |  |
| [`invert_if_negative`](/slides/python-net/el/aspose.slides.charts/chartdatapoint/invert_if_negative/) | Καθορίζει ότι το σημείο δεδομένων θα αντιστρέψει τα χρώματά του εάν η τιμή είναι αρνητική.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`actual_x`](/slides/python-net/el/aspose.slides.charts/chartdatapoint/actual_x/) | Καθορίζει την πραγματική θέση x (αριστερά) του στοιχείου διαγράμματος σε σχέση με την αριστερό-πάνω γωνία του διαγράμματος.<br/>            Κλήση μεθόδου IChart.ValidateChartLayout() πριν ληφθούν οι πραγματικές τιμές.<br/>            Ανάγνωση **float**. |
| [`actual_y`](/slides/python-net/el/aspose.slides.charts/chartdatapoint/actual_y/) | Καθορίζει το πραγματικό πάνω του στοιχείου διαγράμματος σε σχέση με την αριστερό-πάνω γωνία του διαγράμματος.<br/>            Κλήση μεθόδου IChart.ValidateChartLayout() πριν ληφθούν οι πραγματικές τιμές.<br/>            Ανάγνωση **float**. |
| [`actual_width`](/slides/python-net/el/aspose.slides.charts/chartdatapoint/actual_width/) | Καθορίζει το πραγματικό πλάτος του στοιχείου διαγράμματος. Κλήση μεθόδου IChart.ValidateChartLayout() πριν ληφθούν οι πραγματικές τιμές.<br/>            Ανάγνωση **float**. |
| [`actual_height`](/slides/python-net/el/aspose.slides.charts/chartdatapoint/actual_height/) | Καθορίζει το πραγματικό ύψος του στοιχείου διαγράμματος. Κλήση μεθόδου IChart.ValidateChartLayout() πριν ληφθούν οι πραγματικές τιμές.<br/>            Ανάγνωση **float**. |
