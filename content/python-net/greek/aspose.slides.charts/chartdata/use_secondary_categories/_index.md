## use_secondary_categories ιδιότητα
Αν είναι false τότε [`ChartData.secondary_categories`](/slides/python-net/el/aspose.slides.charts/chartdata/secondary_categories) ιδιότητα επιστρέφει None και τα δεδομένα 
            στην [`ChartData.categories`](/slides/python-net/el/aspose.slides.charts/chartdata/categories) ιδιότητα χρησιμοποιείται τόσο για τις πρωτεύουσες όσο και για τις δευτερεύουσες σειρές.
            Αν είναι true τότε τα δεδομένα στην [`ChartData.secondary_categories`](/slides/python-net/el/aspose.slides.charts/chartdata/secondary_categories) ιδιότητα χρησιμοποιούνται για τις δευτερεύουσες σειρές και τα δεδομένα 
            στην [`ChartData.categories`](/slides/python-net/el/aspose.slides.charts/chartdata/categories) ιδιότητα χρησιμοποιείται για τις πρωτεύουσες σειρές.
            Ανάγνωση/Εγγραφή **bool**.
