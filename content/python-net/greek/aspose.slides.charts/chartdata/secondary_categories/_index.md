## secondary_categories ιδιότητα
Λαμβάνει τις δευτερεύουσες κατηγορίες εάν η [`ChartData.use_secondary_categories`](/slides/python-net/el/aspose.slides.charts/chartdata/use_secondary_categories) ιδιότητα είναι αληθής.
Μόνο για ανάγνωση [`IChartCategoryCollection`](/slides/python-net/el/aspose.slides.charts/ichartcategorycollection).

### Παρατηρήσεις

Εάν η [`ChartData.use_secondary_categories`](/slides/python-net/el/aspose.slides.charts/chartdata/use_secondary_categories) ιδιότητα είναι ψευδής, τότε αυτή η [`ChartData.secondary_categories`](/slides/python-net/el/aspose.slides.charts/chartdata/secondary_categories) ιδιότητα επιστρέφει None και τα δεδομένα στην [`ChartData.categories`](/slides/python-net/el/aspose.slides.charts/chartdata/categories) ιδιότητα χρησιμοποιούνται τόσο για τις πρωτεύουσες όσο και για τις δευτερεύουσες σειρές.
Εάν η [`ChartData.use_secondary_categories`](/slides/python-net/el/aspose.slides.charts/chartdata/use_secondary_categories) ιδιότητα είναι αληθής, τότε τα δεδομένα στην αυτή τη [`ChartData.secondary_categories`](/slides/python-net/el/aspose.slides.charts/chartdata/secondary_categories) ιδιότητα χρησιμοποιούνται για δευτερεύουσες σειρές και τα δεδομένα στην [`ChartData.categories`](/slides/python-net/el/aspose.slides.charts/chartdata/categories) ιδιότητα χρησιμοποιούνται για πρωτεύουσες σειρές.
