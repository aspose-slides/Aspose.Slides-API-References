## IDataTable κλάση

Αντιπροσωπεί τις ιδιότητες του πίνακα δεδομένων.

Ο τύπος IDataTable εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`format`](/slides/python-net/el/aspose.slides.charts/idatatable/format/) | Επιστρέφει τα στυλ γραμμής, γεμίσματος και εφέ ενός αντικειμένου.<br/>            Μόνο για ανάγνωση [`IFormat`](/slides/python-net/el/aspose.slides.charts/iformat). |
| [`has_border_horizontal`](/slides/python-net/el/aspose.slides.charts/idatatable/has_border_horizontal/) | Αληθές εάν ο πίνακας δεδομένων γραφήματος έχει οριζόντια σύνορα κελιών.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`has_border_outline`](/slides/python-net/el/aspose.slides.charts/idatatable/has_border_outline/) | Αληθές εάν ο πίνακας δεδομένων γραφήματος έχει περίγραμμα.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`has_border_vertical`](/slides/python-net/el/aspose.slides.charts/idatatable/has_border_vertical/) | Αληθές εάν ο πίνακας δεδομένων γραφήματος έχει κάθετα σύνορα κελιών.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`show_legend_key`](/slides/python-net/el/aspose.slides.charts/idatatable/show_legend_key/) | Αληθές εάν το κλειδί υπομνήματος ετικέτας δεδομένων είναι ορατό.<br/>            Ανάγνωση/εγγραφή **bool**. |
