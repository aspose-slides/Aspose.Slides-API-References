## TimeUnitType απαρίθμηση

Αντιπροσωπεύει τη βασική μονάδα για τον άξονα κατηγοριών

Ο τύπος TimeUnitType εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| NONE | Οι τιμές θα εμφανιστούν όπως είναι. |
| DAYS | Καθορίζει ότι τα δεδομένα του διαγράμματος θα εμφανιστούν σε ημέρες. |
| MONTHS | Καθορίζει ότι τα δεδομένα του διαγράμματος θα εμφανιστούν σε μήνες. |
| YEARS | Καθορίζει ότι τα δεδομένα του διαγράμματος θα εμφανιστούν σε χρόνια. |
