## ChartLinesFormat κλάση

Αναπαριστά τις ιδιότητες μορφοποίησης των γραμμών πλέγματος.

Ο τύπος ChartLinesFormat εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`line`](/slides/python-net/el/aspose.slides.charts/chartlinesformat/line/) | Επιστρέφει τις ιδιότητες στιλ γραμμής ενός διαγράμματος.<br/>            Μόνο για ανάγνωση [`ILineFormat`](/slides/python-net/el/aspose.slides/ilineformat). |
| [`effect`](/slides/python-net/el/aspose.slides.charts/chartlinesformat/effect/) | Επιστρέφει τα εφέ που χρησιμοποιούνται για μια γραμμή διαγράμματος.<br/>            Μόνο για ανάγνωση [`IEffectFormat`](/slides/python-net/el/aspose.slides/ieffectformat). |
