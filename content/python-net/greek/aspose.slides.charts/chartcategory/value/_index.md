## ιδιότητα value
Αν UseCell είναι true, τότε αυτή η ιδιότητα αντιπροσωπεύει την ιδιότητα AsCell.Value.
Αν UseCell είναι false, τότε αυτή η ιδιότητα αντιπροσωπεύει την ιδιότητα AsLiteral.
Ανάγνωση/εγγραφή **οποιοδήποτε**.

    ...
