## DataTable κλάση

Αντιπροσωπεύει τις ιδιότητες του πίνακα δεδομένων.

Ο τύπος DataTable εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`format`](/slides/python-net/el/aspose.slides.charts/datatable/format/) | Επιστρέφει τα στυλ γραμμής, γεμίσματος και εφέ ενός αντικειμένου.<br/>            Μόνο για ανάγνωση [`IFormat`](/slides/python-net/el/aspose.slides.charts/iformat). |
| [`has_border_horizontal`](/slides/python-net/el/aspose.slides.charts/datatable/has_border_horizontal/) | Αληθές εάν ο πίνακας δεδομένων του διαγράμματος έχει οριζόντια σύνορα κελιών.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`has_border_outline`](/slides/python-net/el/aspose.slides.charts/datatable/has_border_outline/) | Αληθές εάν ο πίνακας δεδομένων του διαγράμματος έχει περιγράμματα.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`has_border_vertical`](/slides/python-net/el/aspose.slides.charts/datatable/has_border_vertical/) | Αληθές εάν ο πίνακας δεδομένων του διαγράμματος έχει κάθετα σύνορα κελιών.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`show_legend_key`](/slides/python-net/el/aspose.slides.charts/datatable/show_legend_key/) | Αληθές εάν το κλειδί του υπομνήματος ετικέτας δεδομένων είναι ορατό.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`chart`](/slides/python-net/el/aspose.slides.charts/datatable/chart/) | Επιστρέφει το διάγραμμα.<br/>            Μόνο για ανάγνωση [`IChart`](/slides/python-net/el/aspose.slides.charts/ichart). |
| [`text_format`](/slides/python-net/el/aspose.slides.charts/datatable/text_format/) | Επιστρέφει τη μορφή κειμένου.<br/>            Μόνο για ανάγνωση [`IChartTextFormat`](/slides/python-net/el/aspose.slides.charts/icharttextformat). |
| [`slide`](/slides/python-net/el/aspose.slides.charts/datatable/slide/) |  |
| [`presentation`](/slides/python-net/el/aspose.slides.charts/datatable/presentation/) |  |
