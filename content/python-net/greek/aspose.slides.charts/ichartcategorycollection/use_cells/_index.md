## use_cells ιδιότητα
Εάν είναι true τότε το worksheet χρησιμοποιείται για την αποθήκευση κατηγοριών (αυτή η περίπτωση υποστηρίζει πολυεπίπεδες κατηγορίες).
            Εάν είναι false τότε το worksheet ΔΕΝ χρησιμοποιείται για την αποθήκευση τιμών (και αυτή η περίπτωση δεν υποστηρίζει 
            πολυεπίπεδες κατηγορίες).
            Ανάγνωση/εγγραφή **bool**.
