## IChartCategoryCollection κλάση

Αντιπροσωπεύει τη συλλογή του [`IChartCategory`](/slides/python-net/el/aspose.slides.charts/ichartcategory)

Ο τύπος IChartCategoryCollection εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`use_cells`](/slides/python-net/el/aspose.slides.charts/ichartcategorycollection/use_cells/) | Αν είναι true τότε το φύλλο εργασίας χρησιμοποιείται για την αποθήκευση κατηγοριών (αυτή η περίπτωση υποστηρίζει κατηγορίες πολλαπλών επιπέδων).<br/>            Αν είναι false τότε το φύλλο εργασίας ΔΕΝ χρησιμοποιείται για την αποθήκευση τιμών (και αυτή η περίπτωση δεν υποστηρίζει <br/>            κατηγορίες πολλαπλών επιπέδων).<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`grouping_level_count`](/slides/python-net/el/aspose.slides.charts/ichartcategorycollection/grouping_level_count/) | Επιστρέφει τον αριθμό των επιπέδων ομαδοποίησης κατηγοριών που χρησιμοποιούνται.<br/>            Είναι μεγαλύτερο από ένα για κατηγορίες πολλαπλών επιπέδων.<br/>            Μόνο ανάγνωση **int**. |

Αποκτά το στοιχείο στον καθορισμένο δείκτη.
