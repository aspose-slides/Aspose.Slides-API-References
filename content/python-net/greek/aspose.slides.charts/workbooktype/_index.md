## WorkbookType απαρίθμηση

Καθορίζει τον τύπο του αρχείου εργασίας Open XML.

Ο τύπος WorkbookType εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| NOT_DEFINED | Ο τύπος του βιβλίου εργασίας δεν ορίζεται. |
| WORKBOOK | Excel βιβλίο εργασίας (*.xlsx). |
| WORKBOOK_MACRO | Excel βιβλίο εργασίας με ενεργοποιημένες μακροεντολές (*.xlsm). |
| TEMPLATE | Excel πρότυπο (*.xltx). |
| TEMPLATE_MACRO | Excel πρότυπο με ενεργοποιημένες μακροεντολές (*.xltm). |
| WORKBOOK_BINARY_MACRO | Excel δυαδικό βιβλίο εργασίας με ενεργοποιημένες μακροεντολές (*.xlsb). |
