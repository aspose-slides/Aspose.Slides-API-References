## data_source_type ιδιότητα
Καθορίζει εάν η ιδιότητα AsCell, AsCells, AsLiteralString ή AsLiteralDouble είναι ενεργή σε απογόνους. Με άλλα λόγια, καθορίζει τον τύπο της τιμής της ιδιότητας Data. Ανάγνωση/εγγραφή [`DataSourceType`](/slides/python-net/el/aspose.slides.charts/datasourcetype).

### Παρατηρήσεις

Για τα σημεία στο ChartDataPointCollection αυτή η ιδιότητα είναι μόνο για ανάγνωση. Σε αυτή την περίπτωση, για την αλλαγή της τιμής αυτής της ιδιότητας μπορείτε να χρησιμοποιήσετε μία από τις ιδιότητες ChartDataPointCollection.DataSourceTypeFor<...>.
