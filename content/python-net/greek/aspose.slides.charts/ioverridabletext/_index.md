## IOverridableText κλάση

Αναπαριστά κείμενο με δυνατότητα παράκαμψης για ένα γράφημα.

Ο τύπος IOverridableText εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Property | Description |
| :- | :- |
| [`text_frame_for_overriding`](/slides/python-net/el/aspose.slides.charts/ioverridabletext/text_frame_for_overriding/) | Μπορεί να περιέχει πλούσιο μορφοποιημένο κείμενο. Εάν αυτή η ιδιότητα δεν είναι None, τότε αυτή η <br/>            μορφοποιημένη τιμή κειμένου αντικαθιστά το αυτόματα παραγόμενο κείμενο.<br/>            Το αυτόματα παραγόμενο κείμενο είναι μια έμμεση ιδιότητα της ετικέτας δεδομένων, της ετικέτας μονάδας εμφάνισης του άξονα τιμών, του τίτλου άξονα, του τίτλου γραφήματος, της ετικέτας της γραμμής τάσης.<br/>            Το αυτόματα παραγόμενο κείμενο μορφοποιείται με την ιδιότητα IFormattedTextContainer.TextFormat.<br/>            Μόνο για ανάγνωση [`ITextFrame`](/slides/python-net/el/aspose.slides/itextframe). |
