## IUpDownBarsManager κλάση

Παρέχει πρόσβαση στις μπάρες ανοδικής/καθοδικής γραμμής ή διαγράμματος κεριών.

Ο τύπος IUpDownBarsManager εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`up_bars_format`](/slides/python-net/el/aspose.slides.charts/iupdownbarsmanager/up_bars_format/) | Επιστρέφει τη μορφή των ανοδικών μπάρων.<br/>            Μόνο ανάγνωση [`IFormat`](/slides/python-net/el/aspose.slides.charts/iformat). |
| [`down_bars_format`](/slides/python-net/el/aspose.slides.charts/iupdownbarsmanager/down_bars_format/) | Επιστρέφει τη μορφή των καθοδικών μπάρων.<br/>            Μόνο ανάγνωση [`IFormat`](/slides/python-net/el/aspose.slides.charts/iformat). |
| [`has_up_down_bars`](/slides/python-net/el/aspose.slides.charts/iupdownbarsmanager/has_up_down_bars/) | Καθορίζει εάν το διάγραμμα έχει μπάρες ανοδικής/καθοδικής.<br/>            Ανάγνωση/Εγγραφή **bool**. |
| [`gap_width`](/slides/python-net/el/aspose.slides.charts/iupdownbarsmanager/gap_width/) | Επιστρέφει ή ορίζει το πλάτος του κενών.<br/>            Ανάγνωση/Εγγραφή **int**. |
