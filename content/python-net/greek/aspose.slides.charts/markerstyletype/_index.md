## MarkerStyleType απαρίθμηση

Καθορίζει τη μορφή του δείκτη στο σημείο δεδομένων του διαγράμματος.

Ο τύπος MarkerStyleType εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| NOT_DEFINED |  |
| CIRCLE | Καθορίζει ότι θα σχεδιαστεί ένας κύκλος σε κάθε σημείο δεδομένων. |
| DASH | Καθορίζει ότι θα σχεδιαστεί μια παύλα σε κάθε σημείο δεδομένων. |
| DIAMOND | Καθορίζει ότι θα σχεδιαστεί ένα διαμάντι σε κάθε σημείο δεδομένων. |
| DOT | Καθορίζει ότι θα σχεδιαστεί μια τελεία σε κάθε σημείο δεδομένων. |
| NONE | Καθορίζει ότι δεν θα σχεδιαστεί τίποτα σε κάθε σημείο δεδομένων. |
| PICTURE | Καθορίζει ότι θα σχεδιαστεί μια εικόνα σε κάθε σημείο δεδομένων. |
| PLUS | Καθορίζει ότι θα σχεδιαστεί ένα σύμβολο συν σε κάθε σημείο δεδομένων. |
| SQUARE | Καθορίζει ότι θα σχεδιαστεί ένα τετράγωνο σε κάθε σημείο δεδομένων. |
| STAR | Καθορίζει ότι θα σχεδιαστεί ένα αστέρι σε κάθε σημείο δεδομένων. |
| TRIANGLE | Καθορίζει ότι θα σχεδιαστεί ένα τρίγωνο σε κάθε σημείο δεδομένων. |
| X | Καθορίζει ότι θα σχεδιαστεί ένα X σε κάθε σημείο δεδομένων. |
