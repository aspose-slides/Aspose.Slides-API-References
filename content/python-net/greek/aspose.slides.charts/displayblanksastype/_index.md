## DisplayBlanksAsType απαρίθμηση

Καθορίζει πώς θα εμφανίζονται τα ελλιπή δεδομένα.

Ο τύπος DisplayBlanksAsType εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| GAP | Καθορίζει ότι οι κενές τιμές θα παραμείνουν ως κενό. |
| SPAN | Καθορίζει ότι οι κενές τιμές θα καλυφθούν με μια γραμμή. |
| ZERO | Καθορίζει ότι οι κενές τιμές θα αντιμετωπίζονται ως μηδέν. |
