## IChartDataPoint κλάση

Αναπαριστά το σημείο δεδομένων σειράς.

Ο τύπος IChartDataPoint εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`x_value`](/slides/python-net/el/aspose.slides.charts/ichartdatapoint/x_value/) | Επιστρέφει την τιμή x του σημείου δεδομένων του διαγράμματος.<br/>            Μόνο ανάγνωση [`IStringOrDoubleChartValue`](/slides/python-net/el/aspose.slides.charts/istringordoublechartvalue). |
| [`y_value`](/slides/python-net/el/aspose.slides.charts/ichartdatapoint/y_value/) | Επιστρέφει την τιμή y του σημείου δεδομένων του διαγράμματος.<br/>            Μόνο ανάγνωση [`IDoubleChartValue`](/slides/python-net/el/aspose.slides.charts/idoublechartvalue). |
| [`bubble_size`](/slides/python-net/el/aspose.slides.charts/ichartdatapoint/bubble_size/) | Επιστρέφει το μέγεθος φούσκας του σημείου δεδομένων του διαγράμματος.<br/>            Μόνο ανάγνωση [`IDoubleChartValue`](/slides/python-net/el/aspose.slides.charts/idoublechartvalue). |
| [`value`](/slides/python-net/el/aspose.slides.charts/ichartdatapoint/value/) | Επιστρέφει την τιμή του σημείου δεδομένων του διαγράμματος.<br/>            Μόνο ανάγνωση [`IDoubleChartValue`](/slides/python-net/el/aspose.slides.charts/idoublechartvalue). |
| [`size_value`](/slides/python-net/el/aspose.slides.charts/ichartdatapoint/size_value/) | Επιστρέφει την τιμή μεγέθους του σημείου δεδομένων του διαγράμματος.<br/>            Χρησιμοποιείται με διαγράμματα Treemap και Sunburst.<br/>            Μόνο ανάγνωση [`IDoubleChartValue`](/slides/python-net/el/aspose.slides.charts/idoublechartvalue). |
| [`color_value`](/slides/python-net/el/aspose.slides.charts/ichartdatapoint/color_value/) | Επιστρέφει την τιμή χρώματος του σημείου δεδομένων του διαγράμματος.<br/>            Χρησιμοποιείται με χάρτες.<br/>            Μόνο ανάγνωση [`IDoubleChartValue`](/slides/python-net/el/aspose.slides.charts/idoublechartvalue). |
| [`error_bars_custom_values`](/slides/python-net/el/aspose.slides.charts/ichartdatapoint/error_bars_custom_values/) | Αναπαριστά τις τιμές των γραμμών σφάλματος σειράς στην περίπτωση προσαρμοσμένου τύπου τιμής.<br/>            Μόνο ανάγνωση [`IErrorBarsCustomValues`](/slides/python-net/el/aspose.slides.charts/ierrorbarscustomvalues). |
| [`label`](/slides/python-net/el/aspose.slides.charts/ichartdatapoint/label/) | Αναπαριστά την ετικέτα του σημείου δεδομένων του διαγράμματος.<br/>            Μόνο ανάγνωση [`IDataLabel`](/slides/python-net/el/aspose.slides.charts/idatalabel). |
| [`is_bubble_3d`](/slides/python-net/el/aspose.slides.charts/ichartdatapoint/is_bubble_3d/) | Καθορίζει ότι οι φούσκες έχουν εφαρμοσμένο 3-Δ εφέ.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`explosion`](/slides/python-net/el/aspose.slides.charts/ichartdatapoint/explosion/) | Καθορίζει την απόσταση που το σημείο δεδομένων θα μετακινηθεί από το κέντρο του πίτας.<br/>            Ανάγνωση/εγγραφή **int**. |
| [`format`](/slides/python-net/el/aspose.slides.charts/ichartdatapoint/format/) | Αναπαριστά τις ιδιότητες μορφοποίησης.<br/>            Ανάγνωση/εγγραφή [`IFormat`](/slides/python-net/el/aspose.slides.charts/iformat). |
| [`marker`](/slides/python-net/el/aspose.slides.charts/ichartdatapoint/marker/) | Καθορίζει έναν δείκτη δεδομένων.<br/>            Μόνο ανάγνωση [`IMarker`](/slides/python-net/el/aspose.slides.charts/imarker). |
| [`related_legend_entry`](/slides/python-net/el/aspose.slides.charts/ichartdatapoint/related_legend_entry/) | Ιδιότητες του αντίστοιχου στοιχείου υπομνήματος στην περίπτωση τύπου διαγράμματος από αυτήν τη λίστα:<br/>            ChartType.BarOfPie,<br/>            ChartType.ExplodedPie,<br/>            ChartType.ExplodedPie3D,<br/>            ChartType.Pie,<br/>            ChartType.Pie3D,<br/>            ChartType.PieOfPie.<br/>            Μόνο ανάγνωση [`ILegendEntryProperties`](/slides/python-net/el/aspose.slides.charts/ilegendentryproperties). |
| [`set_as_total`](/slides/python-net/el/aspose.slides.charts/ichartdatapoint/set_as_total/) | Ορίζει το σημείο δεδομένων ως σύνολο. Εφαρμόζεται μόνο για τύπο σειράς Waterfall. |
| [`invert_if_negative`](/slides/python-net/el/aspose.slides.charts/ichartdatapoint/invert_if_negative/) | Καθορίζει ότι το σημείο δεδομένων θα αντιστρέψει τα χρώματά του αν η τιμή είναι αρνητική.<br/>            Ανάγνωση/εγγραφή **bool**. |
| [`data_point_levels`](/slides/python-net/el/aspose.slides.charts/ichartdatapoint/data_point_levels/) | Επιστρέφει το περιεχόμενο των επιπέδων του σημείου δεδομένων. Εφαρμόζεται για σειρές Treeamp και Sunburst.<br/>            Η αρίθμηση των επιπέδων του σημείου δεδομένων ξεκινά από το μηδέν. |
| [`index`](/slides/python-net/el/aspose.slides.charts/ichartdatapoint/index/) | Καθορίζει σε ποιο υποσύνολο παιδιών του γονέα ανήκει αυτό το σημείο δεδομένων.<br/>            Ανάγνωση **int**. |
| [`actual_x`](/slides/python-net/el/aspose.slides.charts/ichartdatapoint/actual_x/) |  |
