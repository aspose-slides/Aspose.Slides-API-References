## AxesManager κλάση

Παρέχει πρόσβαση στους άξονες του γραφήματος.

Ο τύπος AxesManager εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`horizontal_axis`](/slides/python-net/el/aspose.slides.charts/axesmanager/horizontal_axis/) | Λαμβάνει τον οριζόντιο άξονα του γραφήματος.<br/>             Μόνο για ανάγνωση [`IAxis`](/slides/python-net/el/aspose.slides.charts/iaxis). |
| [`secondary_horizontal_axis`](/slides/python-net/el/aspose.slides.charts/axesmanager/secondary_horizontal_axis/) | Λαμβάνει τον δευτερεύοντα οριζόντιο άξονα του γραφήματος.<br/>             Μόνο για ανάγνωση [`IAxis`](/slides/python-net/el/aspose.slides.charts/iaxis). |
| [`vertical_axis`](/slides/python-net/el/aspose.slides.charts/axesmanager/vertical_axis/) | Λαμβάνει τον κατακόρυφο άξονα του γραφήματος.<br/>             Μόνο για ανάγνωση [`IAxis`](/slides/python-net/el/aspose.slides.charts/iaxis). |
| [`secondary_vertical_axis`](/slides/python-net/el/aspose.slides.charts/axesmanager/secondary_vertical_axis/) | Λαμβάνει τον δευτερεύοντα κατακόρυφο άξονα του γραφήματος.<br/>             Μόνο για ανάγνωση [`IAxis`](/slides/python-net/el/aspose.slides.charts/iaxis). |
| [`series_axis`](/slides/python-net/el/aspose.slides.charts/axesmanager/series_axis/) | Λαμβάνει τον άξονα σειράς του γραφήματος.<br/>             Μόνο για ανάγνωση [`IAxis`](/slides/python-net/el/aspose.slides.charts/iaxis). |
