## Απαρίθμηση TrendlineType

Αναπαριστά τον τύπο της γραμμής τάσης

Ο τύπος TrendlineType εκθέτει τα παρακάτω μέλη:

## Πεδία

| Πεδίο | Περιγραφή |
| :- | :- |
| EXPONENTIAL | Καθορίζει ότι η γραμμή τάσης πρέπει να είναι εκθετική καμπύλη στη μορφή. |
| LINEAR | Καθορίζει ότι η γραμμή τάσης πρέπει να είναι γραμμή στη μορφή. |
| LOGARITHMIC | Καθορίζει ότι η γραμμή τάσης πρέπει να είναι λογαριθμική καμπύλη στη μορφή , όπου log είναι ο φυσικός λογαριθμός. |
| MOVING_AVERAGE | Καθορίζει ότι η γραμμή τάσης πρέπει να είναι κινητός μέσος με περίοδο Period. |
| POLYNOMIAL | Καθορίζει ότι η γραμμή τάσης πρέπει να είναι πολυωνυμική καμπύλη τάξης Order στη μορφή. |
| POWER | Καθορίζει ότι η γραμμή τάσης πρέπει να είναι καμπύλη δύναμης στη μορφή. |
