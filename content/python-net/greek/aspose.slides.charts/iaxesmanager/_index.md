## IAxesManager κλάση

Παρέχει πρόσβαση στους άξονες του διαγράμματος.

Ο τύπος IAxesManager εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`horizontal_axis`](/slides/python-net/el/aspose.slides.charts/iaxesmanager/horizontal_axis/) | Λαμβάνει τον οριζόντιο άξονα του διαγράμματος.<br/> Μόνο για ανάγνωση [`IAxis`](/slides/python-net/el/aspose.slides.charts/iaxis). |
| [`secondary_horizontal_axis`](/slides/python-net/el/aspose.slides.charts/iaxesmanager/secondary_horizontal_axis/) | Λαμβάνει τον δευτερεύοντα οριζόντιο άξονα του διαγράμματος.<br/> Μόνο για ανάγνωση [`IAxis`](/slides/python-net/el/aspose.slides.charts/iaxis). |
| [`vertical_axis`](/slides/python-net/el/aspose.slides.charts/iaxesmanager/vertical_axis/) | Λαμβάνει τον κατακόρυφο άξονα του διαγράμματος.<br/> Μόνο για ανάγνωση [`IAxis`](/slides/python-net/el/aspose.slides.charts/iaxis). |
| [`secondary_vertical_axis`](/slides/python-net/el/aspose.slides.charts/iaxesmanager/secondary_vertical_axis/) | Λαμβάνει τον δευτερεύοντα κατακόρυφο άξονα του διαγράμματος.<br/> Μόνο για ανάγνωση [`IAxis`](/slides/python-net/el/aspose.slides.charts/iaxis). |
| [`series_axis`](/slides/python-net/el/aspose.slides.charts/iaxesmanager/series_axis/) | Λαμβάνει τον άξονα σειράς του διαγράμματος.<br/> Μόνο για ανάγνωση [`IAxis`](/slides/python-net/el/aspose.slides.charts/iaxis). |
