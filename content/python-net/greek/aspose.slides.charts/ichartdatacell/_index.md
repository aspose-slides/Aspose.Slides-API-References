## IChartDataCell κλάση

Αντιπροσωπεύει το κελί για δεδομένα διαγράμματος.

Ο τύπος IChartDataCell εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`row`](/slides/python-net/el/aspose.slides.charts/ichartdatacell/row/) | Επιστρέφει τον δείκτη της γραμμής του φύλλου εργασίας στο οποίο βρίσκεται το κελί.<br/>            Μόνο-ανάγνωση **int**. |
| [`column`](/slides/python-net/el/aspose.slides.charts/ichartdatacell/column/) | Επιστρέφει τον δείκτη της στήλης του φύλλου εργασίας στο οποίο βρίσκεται το κελί.<br/>            Μόνο-ανάγνωση **int**. |
| [`value`](/slides/python-net/el/aspose.slides.charts/ichartdatacell/value/) | Λαμβάνει ή ορίζει την τιμή ενός κελιού.<br/>            Ανάγνωση/εγγραφή **any**. |
| [`formula`](/slides/python-net/el/aspose.slides.charts/ichartdatacell/formula/) | Λαμβάνει ή ορίζει τον τύπο σε στυλ A1. |
| [`r1c1_formula`](/slides/python-net/el/aspose.slides.charts/ichartdatacell/r1c1_formula/) | Λαμβάνει ή ορίζει τον τύπο σε στυλ R1C1. |
| [`chart_data_worksheet`](/slides/python-net/el/aspose.slides.charts/ichartdatacell/chart_data_worksheet/) | Λαμβάνει το φύλλο εργασίας.<br/>            Μόνο-ανάγνωση [`IChartDataWorksheet`](/slides/python-net/el/aspose.slides.charts/ichartdataworksheet). |
| [`is_hidden`](/slides/python-net/el/aspose.slides.charts/ichartdatacell/is_hidden/) | Καθορίζει αν το κελί είναι κρυμμένο.<br/>            Μόνο-ανάγνωση **bool**. |
| [`custom_number_format`](/slides/python-net/el/aspose.slides.charts/ichartdatacell/custom_number_format/) | Λαμβάνει ή ορίζει το προσαρμοσμένο σχήμα εμφάνισης αριθμών και ημερομηνιών.<br/>            Εάν η τιμή είναι κενή, θα χρησιμοποιηθεί η τιμή PresetNumberFormat.<br/>            Ανάγνωση/εγγραφή **str**. |
| [`preset_number_format`](/slides/python-net/el/aspose.slides.charts/ichartdatacell/preset_number_format/) | Λαμβάνει ή ορίζει το ενσωματωμένο σχήμα εμφάνισης αριθμών και ημερομηνιών. Η προεπιλεγμένη τιμή πρέπει να είναι στο [0..22] ή [37..49].<br/>            Ανάγνωση/εγγραφή **int**. |

## Μέθοδοι

| Μέθοδος | Περιγραφή |
| :- | :- |
| [`calculate(self, update_values)`](/slides/python-net/el/aspose.slides.charts/ichartdatacell/calculate/#bool) | Εάν το κελί περιέχει τύπο, η τιμή θα ενημερωθεί βάσει αυτού του τύπου. |
