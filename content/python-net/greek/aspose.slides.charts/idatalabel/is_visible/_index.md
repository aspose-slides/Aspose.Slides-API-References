## is_visible ιδιότητα
False σημαίνει ότι η ετικέτα δεδομένων δεν είναι ορατή (και έτσι όλες οι σημαίες Show*-flags (ShowValue, ...) είναι false).
            Μόνο για ανάγνωση **bool**.


### Παρατηρήσεις

Εάν η ετικέτα δεδομένων είναι ορατή, μπορείτε να τη κρύψετε με τη μέθοδο Hide().
            Αλλά εάν η ετικέτα δεδομένων δεν είναι ορατή (IsVisible is false) μπορείτε να κάνετε την ετικέτα δεδομένων ορατή 
            ορίζοντας τις σημαίες Show*-flags (ShowValue, ...) σε κατάσταση true.
