## is_chart_type_line(chart_type) {#charttype}
Επιστρέφει true εάν το chartType είναι ένας από τα υποτύπους Line.

            [`ChartType.STACKED_LINE_WITH_MARKERS`](/slides/python-net/el/aspose.slides.charts/charttype/STACKED_LINE_WITH_MARKERS),
