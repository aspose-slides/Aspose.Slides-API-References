## PieSplitType απαρίθμηση

Αναπαριστά έναν τύπο σημείων διαχωρισμού στο δεύτερο κομμάτι ή ράβδο σε γράφημα τύπου πίτα-σε-πίτα ή ράβδο-σε-πίτα.

Ο τύπος PieSplitType εκθέτει τα παρακάτω μέλη:

## Fields

| Πεδίο | Περιγραφή |
| :- | :- |
| DEFAULT | Καθορίζει ότι τα σημεία δεδομένων θα πρέπει να χωριστούν χρησιμοποιώντας τον προεπιλεγμένο <br/> μηχανισμό για αυτόν τον τύπο διαγράμματος. |
| CUSTOM | Καθορίζει ότι τα σημεία δεδομένων θα πρέπει να χωριστούν μεταξύ της <br/> πίτας και του δεύτερου διαγράμματος σύμφωνα με τις τιμές Custom Split. |
| BY_PERCENTAGE | Καθορίζει ότι τα σημεία δεδομένων θα πρέπει να χωριστούν μεταξύ της πίτας και του <br/> δεύτερου διαγράμματος τοποθετώντας τα σημεία με ποσοστό μικρότερο από το <br/> ποσοστό Split Position στο δεύτερο γράφημα. |
| BY_POS | Καθορίζει ότι τα σημεία δεδομένων θα πρέπει να χωριστούν μεταξύ της πίτας και του <br/> δεύτερου διαγράμματος τοποθετώντας την τελευταία θέση Split Position των σημείων δεδομένων <br/> στο δεύτερο γράφημα. |
| BY_VALUE | Καθορίζει ότι τα σημεία δεδομένων θα πρέπει να χωριστούν μεταξύ της πίτας και του <br/> δεύτερου διαγράμματος τοποθετώντας τα σημεία δεδομένων με τιμή μικρότερη από το <br/> Split Position στο δεύτερο γράφημα. |
