## DisplayUnitType Απαρίθμηση

Καθορίζει τον πολλαπλασιασμό των εμφανιζόμενων δεδομένων.

Ο τύπος DisplayUnitType εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Πεδία | Περιγραφή |
| :- | :- |
| NONE | Οι τιμές θα εμφανίζονται όπως είναι. |
| HUNDREDS | Καθορίζει ότι οι τιμές στο γράφημα θα διαιρεθούν με το 100. |
| THOUSANDS | Καθορίζει ότι οι τιμές στο γράφημα θα διαιρεθούν με το 1,000. |
| TEN_THOUSANDS | Καθορίζει ότι οι τιμές στο γράφημα θα διαιρεθούν με το 10,000. |
| HUNDRED_THOUSANDS | Καθορίζει ότι οι τιμές στο γράφημα θα διαιρεθούν με το 100,000. |
| MILLIONS | Καθορίζει ότι οι τιμές στο γράφημα θα διαιρεθούν με το 1,000,000. |
| TEN_MILLIONS | Καθορίζει ότι οι τιμές στο γράφημα θα διαιρεθούν με το 10,000,000. |
| HUNDRED_MILLIONS | Καθορίζει ότι οι τιμές στο γράφημα θα διαιρεθούν με το 100,000,000. |
| BILLIONS | Καθορίζει ότι οι τιμές στο γράφημα θα διαιρεθούν με το 1,000,000,000. |
| TRILLIONS | Καθορίζει ότι οι τιμές στο γράφημα θα διαιρεθούν με το 1,000,000,000,000. |
| CUSTOM_VALUE | Καθορίζει ότι οι τιμές στο γράφημα θα διαιρεθούν με μια προσαρμοσμένη τιμή. |
