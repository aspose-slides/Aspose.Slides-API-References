## error_bars_x_format ιδιότητα
Represents ErrorBars of series with derection X. 
            
            ErrorBars με κατεύθυνση X είναι διαθέσιμα για σειρές τύπου επιφάνειας, στήλης, διασποράς και φυσαλίδας. 
            Για οποιουσδήποτε άλλους τύπους διαγράμματος αυτή η ιδιότητα επιστρέφει None (συμπεριλαμβανομένων των 3D διαγραμμάτων).
            Σε περίπτωση προσαρμοσμένων τιμών χρησιμοποιήστε τη συλλογή DataPoints για να καθορίσετε την τιμή
            (with [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/el/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) ιδιότητα).
            
            Μόνο για ανάγνωση [`IErrorBarsFormat`](/slides/python-net/el/aspose.slides.charts/ierrorbarsformat).
