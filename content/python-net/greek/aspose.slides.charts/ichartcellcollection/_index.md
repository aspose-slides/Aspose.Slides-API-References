## IChartCellCollection κλάση

Αναπαριστά μια συλλογή κελιών με δεδομένα.

Ο τύπος IChartCellCollection εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`count`](/slides/python-net/el/aspose.slides.charts/ichartcellcollection/count/) | Λαμβάνει τον αριθμό των κελιάς στη συλλογή.<br/>            Μόνο για ανάγνωση **int**. |

Επιστρέφει ένα κελί (IChartDataCell) κατά δείκτη.

## Δείκτης

| Όνομα | Περιγραφή |
| :- | :- |
| [`[index]`](/slides/python-net/el/aspose.slides.charts/ichartcellcollection/__getitem__/) | Δείκτης ενός κελιού. |

## Μέθοδοι

| Μέθοδος | Περιγραφή |
| :- | :- |
| [`add(self, chart_data_cell)`](/slides/python-net/el/aspose.slides.charts/ichartcellcollection/add/#ichartdatacell) | Προσθέτει νέο κελί στη συλλογή. |
| [`add(self, value)`](/slides/python-net/el/aspose.slides.charts/ichartcellcollection/add/#any) | Δημιουργεί [`IChartDataCell`](/slides/python-net/el/aspose.slides.charts/ichartdatacell) από την καθορισμένη τιμή και το προσθέτει στη συλλογή. |
| [`get_cells_address(self)`](/slides/python-net/el/aspose.slides.charts/ichartcellcollection/get_cells_address/#) | Επιστρέφει τη διεύθυνση του συνόλου των κελιών στο βιβλίο εργασίας. |
| [`get_concatenated_values_from_cells(self)`](/slides/python-net/el/aspose.slides.charts/ichartcellcollection/get_concatenated_values_from_cells/#) | Συνεκτικό συμβολοσειρά από όλες τις τιμές συμβολοσειράς των κελιών. |
| [`remove_at(self, index)`](/slides/python-net/el/aspose.slides.charts/ichartcellcollection/remove_at/#int) | Αφαιρεί ένα κελί από τη συλλογή κατά δείκτη. |
