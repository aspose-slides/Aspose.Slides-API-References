## hide(self) {#}
Κάντε την ετικέτα δεδομένων κρυφή ορίζοντας όλα τα Show*-flags (ShowValue, ...) σε κατάσταση ψευδούς.
            Το IsVisible θα είναι ψευδές μετά από αυτό.


```python
def hide(self):
    ...
```


### Παρατηρήσεις

Εάν η ετικέτα δεδομένων δεν είναι ορατή (IsVisible είναι ψευδές) μπορείτε να κάνετε την ετικέτα δεδομένων ορατή με
            ορίζοντας τα Show*-flags (ShowValue, ...) σε κατάσταση αληθούς.
