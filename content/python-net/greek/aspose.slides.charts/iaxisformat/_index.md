## IAxisFormat κλάση

Αναπαριστά τις ιδιότητες μορφοποίησης διαγράμματος.

Ο τύπος IAxisFormat εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`fill`](/slides/python-net/el/aspose.slides.charts/iaxisformat/fill/) | Επιστρέφει τις ιδιότητες γεμίσματος ενός άξονα.<br/>            Μόνο για ανάγνωση [`IFillFormat`](/slides/python-net/el/aspose.slides/ifillformat). |
| [`line`](/slides/python-net/el/aspose.slides.charts/iaxisformat/line/) | Επιστρέφει τις ιδιότητες γραμμής ενός άξονα.<br/>            Μόνο για ανάγνωση [`ILineFormat`](/slides/python-net/el/aspose.slides/ilineformat). |
| [`effect`](/slides/python-net/el/aspose.slides.charts/iaxisformat/effect/) | Επιστρέφει τις επιδράσεις που χρησιμοποιούνται για έναν άξονα.<br/>            Μόνο για ανάγνωση [`IEffectFormat`](/slides/python-net/el/aspose.slides/ieffectformat). |
