## IMarker κλάση

Αντιπροσωπεύει έναν δείκτη ενός σχιστόλιθου.

Ο τύπος IMarker εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Property | Description |
| :- | :- |
| [`symbol`](/slides/python-net/el/aspose.slides.charts/imarker/symbol/) | Αντιπροσωπεύει το στυλ του δείκτη σε γράφημα γραμμής, γράφημα διασκορπισμού ή γράφημα ραντάρ.<br/>            Ανάγνωση/εγγραφή [`MarkerStyleType`](/slides/python-net/el/aspose.slides.charts/markerstyletype). |
| [`format`](/slides/python-net/el/aspose.slides.charts/imarker/format/) | Λαμβάνει το γέμισμα του δείκτη.<br/>            Μόνο ανάγνωση [`IFormat`](/slides/python-net/el/aspose.slides.charts/iformat). |
| [`size`](/slides/python-net/el/aspose.slides.charts/imarker/size/) | Αντιπροσωπεύει το μέγεθος του δείκτη σε γράφημα γραμμής, γράφημα διασκορπισμού ή γράφημα ραντάρ.<br/>            Ανάγνωση/εγγραφή **int**. |
