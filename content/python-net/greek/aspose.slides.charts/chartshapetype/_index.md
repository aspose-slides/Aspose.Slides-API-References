## Απαρίθμηση ChartShapeType

Αντιπροσωπεί ένα σχήμα γραφήματος.

Ο τύπος ChartShapeType εκθέτει τα ακόλουθα μέλη:

## Πεδία

| Field | Description |
| :- | :- |
| NOT_DEFINED | Το σχήμα γραφήματος δεν είναι καθορισμένο. |
| BOX | Καθορίζει ότι το γράφημα θα σχεδιαστεί με σχήμα κουτιού. |
| CONE | Καθορίζει ότι το γράφημα θα σχεδιαστεί ως κώνος, με τη βάση του κώνου στο πάτωμα και την άκρη του κώνου στην κορυφή του δείκτη δεδομένων. |
| CONE_TO_MAX | Καθορίζει ότι το γράφημα θα σχεδιαστεί με αποκομμένους κώνους ώστε η άκρη του κώνου να είναι η μέγιστη τιμή δεδομένων. |
| CYLINDER | Καθορίζει ότι το γράφημα θα σχεδιαστεί ως κύλιντρος. |
| PYRAMID | Καθορίζει ότι το γράφημα θα σχεδιαστεί ως ορθογώνια πυραμίδα, με τη βάση της πυραμίδας στο πάτωμα και την άκρη της πυραμίδας στην κορυφή του δείκτη δεδομένων. |
| PYRAMID_TO_MAXIMUM | Καθορίζει ότι το γράφημα θα σχεδιαστεί με αποκομμένες πυραμίδες ώστε η άκρη της πυραμίδας να είναι η μέγιστη τιμή δεδομένων. |
