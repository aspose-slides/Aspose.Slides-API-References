## IChartLinesFormat κλάση

Αντιπροσωπεύει τις ιδιότητες μορφοποίησης των γραμμών πλέγματος.

Ο τύπος IChartLinesFormat εκθέτει τα παρακάτω μέλη:

## Ιδιότητες

| Property | Description |
| :- | :- |
| [`line`](/slides/python-net/el/aspose.slides.charts/ichartlinesformat/line/) | Επιστρέφει τις ιδιότητες στυλ γραμμής ενός γραφήματος.<br/>            Μόνο-ανάγνωση [`ILineFormat`](/slides/python-net/el/aspose.slides/ilineformat). |
| [`effect`](/slides/python-net/el/aspose.slides.charts/ichartlinesformat/effect/) | Επιστρέφει τα εφέ που χρησιμοποιούνται για μια γραμμή διαγράμματος.<br/>            Μόνο-ανάγνωση [`IEffectFormat`](/slides/python-net/el/aspose.slides/ieffectformat). |
