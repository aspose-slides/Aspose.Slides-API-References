## IActualLayout κλάση

Καθορίζει την πραγματική θέση ενός στοιχείου γραφήματος.

Ο τύπος IActualLayout εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`actual_x`](/slides/python-net/el/aspose.slides.charts/iactuallayout/actual_x/) | Καθορίζει την πραγματική θέση x (αριστερά) του στοιχείου γραφήματος σε σχέση με την αριστερή επάνω γωνία του γραφήματος.<br/>            Call method IChart.ValidateChartLayout() before to get actual values. <br/>            Ανάγνωση **float**. |
| [`actual_y`](/slides/python-net/el/aspose.slides.charts/iactuallayout/actual_y/) | Καθορίζει το πραγματικό πάνω μέρος του στοιχείου γραφήματος σε σχέση με την αριστερή επάνω γωνία του γραφήματος.<br/>            Call method IChart.ValidateChartLayout() before to get actual values. <br/>            Ανάγνωση **float**. |
| [`actual_width`](/slides/python-net/el/aspose.slides.charts/iactuallayout/actual_width/) | Καθορίζει το πραγματικό πλάτος του στοιχείου γραφήματος. Call method IChart.ValidateChartLayout() before to get actual values. <br/>            Ανάγνωση **float**. |
| [`actual_height`](/slides/python-net/el/aspose.slides.charts/iactuallayout/actual_height/) | Καθορίζει το πραγματικό ύψος του στοιχείου γραφήματος. Call method IChart.ValidateChartLayout() before to get actual values. <br/>            Ανάγνωση **float**. |
