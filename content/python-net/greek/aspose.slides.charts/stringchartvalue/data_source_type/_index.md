## ιδιότητα data_source_type
Καθορίζει αν η ιδιότητα AsCell, AsCells, AsLiteralString ή AsLiteralDouble είναι ενεργή στα απογόνους. Με άλλα λόγια καθορίζει τον τύπο της τιμής της ιδιότητας Data. Ανάγνωση/εγγραφή [`DataSourceType`](/slides/python-net/el/aspose.slides.charts/datasourcetype).

### Παρατηρήσεις

Για τα σημεία στο ChartDataPointCollection αυτή η ιδιότητα είναι μόνο για ανάγνωση. Σε αυτήν την περίπτωση, για αλλαγή της τιμής αυτής της ιδιότητας μπορείτε να χρησιμοποιήσετε μία από τις ιδιότητες ChartDataPointCollection.DataSourceTypeFor<...>.
