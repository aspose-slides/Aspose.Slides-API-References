## IStringOrDoubleChartValue κλάση

Αναπαριστά μια τιμή τύπου string ή double που μπορεί να αποθηκευτεί σε έγγραφο παρουσίασης pptx με δύο τρόπους:
            1) σε κελί/κελιά του φύλλου εργασίας που σχετίζεται με το διάγραμμα;
            2) ως κυριολασία τιμή.

Ο τύπος IStringOrDoubleChartValue εκθέτει τα ακόλουθα μέλη:
