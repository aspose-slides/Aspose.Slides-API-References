## Marker κλάση

Αντιπροσωπεύει το σημάδι ενός χέρτ.

Ο τύπος Marker εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`symbol`](/slides/python-net/el/aspose.slides.charts/marker/symbol/) | Αντιπροσωπεύει το στυλ του σημειωτή σε γραμμικό διάγραμμα, διάγραμμα διασποράς ή διάγραμμα ραδίου.<br/>            Ανάγνωση/εγγραφή [`MarkerStyleType`](/slides/python-net/el/aspose.slides.charts/markerstyletype). |

| [`size`](/slides/python-net/el/aspose.slides.charts/marker/size/) | Αντιπροσωπεύει το μέγεθος του σημειωτή σε γραμμικό διάγραμμα, διάγραμμα διασποράς ή διάγραμμα ραδίου.<br/>            Ανάγνωση/εγγραφή **int**. |
