## IChartParagraphFormat κλάση

Αντιπροσωπεί τις ιδιότητες μορφοποίησης παραγράφου ενός διαγράμματος.

Ο τύπος IChartParagraphFormat εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Ιδιότητα | Περιγραφή |
| :- | :- |
| [`alignment`](/slides/python-net/el/aspose.slides.charts/ichartparagraphformat/alignment/) | Επιστρέφει ή ορίζει την ευθυγράμμιση κειμένου σε μια παράγραφο.<br/>            Ανάγνωση/Εγγραφή [`TextAlignment`](/slides/python-net/el/aspose.slides/textalignment). |
| [`space_within`](/slides/python-net/el/aspose.slides.charts/ichartparagraphformat/space_within/) | Επιστρέφει ή ορίζει το ποσό του διαστήματος μεταξύ βασικών γραμμών σε μια παράγραφο.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`space_before`](/slides/python-net/el/aspose.slides.charts/ichartparagraphformat/space_before/) | Επιστρέφει ή ορίζει το ποσό του διαστήματος πριν από την πρώτη γραμμή σε μια παράγραφο.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`space_after`](/slides/python-net/el/aspose.slides.charts/ichartparagraphformat/space_after/) | Επιστρέφει ή ορίζει το ποσό του διαστήματος μετά την τελευταία γραμμή σε μια παράγραφο.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`east_asian_line_break`](/slides/python-net/el/aspose.slides.charts/ichartparagraphformat/east_asian_line_break/) | Καθορίζει εάν χρησιμοποιείται η αλλαγή γραμμής Ανατολικής Ασίας σε μια παράγραφο.<br/>            Ανάγνωση/Εγγραφή [`NullableBool`](/slides/python-net/el/aspose.slides/nullablebool). |
| [`right_to_left`](/slides/python-net/el/aspose.slides.charts/ichartparagraphformat/right_to_left/) | Καθορίζει εάν χρησιμοποιείται η γραφή Δεξιά προς Αριστερά σε μια παράγραφο.<br/>            Ανάγνωση/Εγγραφή [`NullableBool`](/slides/python-net/el/aspose.slides/nullablebool). |
| [`latin_line_break`](/slides/python-net/el/aspose.slides.charts/ichartparagraphformat/latin_line_break/) | Καθορίζει εάν χρησιμοποιείται η αλλαγή γραμμής Λατινικού σε μια παράγραφο.<br/>            Ανάγνωση/Εγγραφή [`NullableBool`](/slides/python-net/el/aspose.slides/nullablebool). |
| [`hanging_punctuation`](/slides/python-net/el/aspose.slides.charts/ichartparagraphformat/hanging_punctuation/) | Καθορίζει εάν χρησιμοποιείται η κρεμαστή στίξη σε μια παράγραφο.<br/>            Ανάγνωση/Εγγραφή [`NullableBool`](/slides/python-net/el/aspose.slides/nullablebool). |
| [`margin_left`](/slides/python-net/el/aspose.slides.charts/ichartparagraphformat/margin_left/) | Επιστρέφει ή ορίζει το αριστερό περιθώριο σε μια παράγραφο.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`margin_right`](/slides/python-net/el/aspose.slides.charts/ichartparagraphformat/margin_right/) | Επιστρέφει ή ορίζει το δεξιό περιθώριο σε μια παράγραφο.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`indent`](/slides/python-net/el/aspose.slides.charts/ichartparagraphformat/indent/) | Επιστρέφει ή ορίζει την εσοχή πρώτης γραμμής/κρεμαστής εσοχής της παραγράφου. Η κρεμαστή εσοχή μπορεί να οριστεί με αρνητικές τιμές.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`default_tab_size`](/slides/python-net/el/aspose.slides.charts/ichartparagraphformat/default_tab_size/) | Επιστρέφει ή ορίζει το προεπιλεγμένο μέγεθος εσοχής.<br/>            Ανάγνωση/Εγγραφή **float**. |
| [`tabs`](/slides/python-net/el/aspose.slides.charts/ichartparagraphformat/tabs/) | Επιστρέφει τις εσοχές μιας παραγράφου.<br/>            Μόνο ανάγνωση [`ITabCollection`](/slides/python-net/el/aspose.slides/itabcollection). |
| [`font_alignment`](/slides/python-net/el/aspose.slides.charts/ichartparagraphformat/font_alignment/) | Επιστρέφει ή ορίζει την ευθυγράμμιση γραμματοσειράς σε μια παράγραφο.<br/>            Ανάγνωση/Εγγραφή [`FontAlignment`](/slides/python-net/el/aspose.slides/fontalignment). |
