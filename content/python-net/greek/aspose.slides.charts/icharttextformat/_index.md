## IChartTextFormat κλάση

Το Chart λειτουργεί με περιορισμένο σύνολο ιδιοτήτων μορφοποίησης κειμένου.  
Οι διεπαφές IChartTextFormat, IChartTextBlockFormat, IChartParagraphFormat, IChartPortionFormat περιγράφουν αυτό το περιορισμένο σύνολο.

Ο τύπος IChartTextFormat εκθέτει τα ακόλουθα μέλη:

## Ιδιότητες

| Property | Description |
| :- | :- |
| [`text_block_format`](/slides/python-net/el/aspose.slides.charts/icharttextformat/text_block_format/) | Επιστρέφει τη μορφοποίηση για τα στοιχεία κειμένου του chart.<br/>            Μόνο ανάγνωση [`IChartTextBlockFormat`](/slides/python-net/el/aspose.slides.charts/icharttextblockformat). |
| [`paragraph_format`](/slides/python-net/el/aspose.slides.charts/icharttextformat/paragraph_format/) | Επιστρέφει τη μορφοποίηση παραγράφου.<br/>            Μόνο ανάγνωση [`IChartParagraphFormat`](/slides/python-net/el/aspose.slides.charts/ichartparagraphformat). |
| [`portion_format`](/slides/python-net/el/aspose.slides.charts/icharttextformat/portion_format/) | Επιστρέφει τη μορφοποίηση τμήματος.<br/>            Μόνο ανάγνωση [`IChartPortionFormat`](/slides/python-net/el/aspose.slides.charts/ichartportionformat). |
