## show_value ιδιότητα
Represents a specified chart's data label percentage value display behavior. 
            True displays the percentage value. False to hide.
            Read/write **bool**.

### Παρατηρήσεις

Αν ο γονέας αυτού του αντικειμένου DataLabelFormat είναι μια συλλογή DataLabelCollection ετικετών δεδομένων, τότε αυτή η ιδιότητα λαμβάνει ή ορίζει την προεπιλεγμένη τιμή της ShowValue ιδιότητας για τις νέες ετικέτες δεδομένων στη συλλογή DataLabelCollection. 
            Η ρύθμιση αυτής της ιδιότητας με τιμή επίσης ορίζει αυτή την τιμή στην ShowValue ιδιότητα για όλες τις ετικέτες δεδομένων στη συλλογή DataLabelCollection 
            (i.e. "DataLabels.DefaultDataLabelFormat.ShowValue = val;" cause to 
            all DataLabels[i].ShowValue is equal to val).
