## show_legend_key ιδιότητα
Αντιπροσωπεύει τη συμπεριφορά εμφάνισης του κλειδιού υπομνήματος ετικέτας δεδομένων ενός συγκεκριμένου διαγράμματος.
            True εάν το κλειδί υπομνήματος ετικέτας δεδομένων είναι ορατό.
            Ανάγνωση/εγγραφή **bool**.

### Παρατηρήσεις

Εάν ο γονέας αυτού του αντικειμένου DataLabelFormat είναι μια συλλογή DataLabelCollection ετικετών δεδομένων, τότε αυτό
            η ιδιότητα λαμβάνει ή ορίζει την προεπιλεγμένη τιμή της ιδιότητας ShowLegendKey για τις νέες ετικέτες δεδομένων 
            στη συλλογή DataLabelCollection.
            Ορίστε αυτή την ιδιότητα με τιμή επίσης ορίζει αυτή τη τιμή στην ιδιότητα ShowLegendKey 
            για όλες τις ετικέτες δεδομένων στη συλλογή DataLabelCollection
            (π.χ. "DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;" προκαλεί 
            όλα τα DataLabels[i].ShowLegendKey να είναι ίσα με val).
