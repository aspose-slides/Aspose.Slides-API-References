## LegendDataLabelPosition تعداد

يحدد موضع تسميات البيانات.

نوع LegendDataLabelPosition يعرض الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| NOT_DEFINED | الموضع غير معرف. |
| BOTTOM | يحدد أن تُعرض تسميات البيانات أسفل علامة البيانات. |
| BEST_FIT | يحدد أن تُعرض تسميات البيانات في أفضل موضع. |
| CENTER | يحدد أن تُعرض تسميات البيانات مركزة على علامة البيانات. |
| INSIDE_BASE | يحدد أن تُعرض تسميات البيانات داخل قاعدة علامة البيانات. |
| INSIDE_END | يحدد أن تُعرض تسميات البيانات داخل نهاية علامة البيانات. |
| LEFT | يحدد أن تُعرض تسميات البيانات إلى يسار علامة البيانات. |
| OUTSIDE_END | يحدد أن تُعرض تسميات البيانات خارج نهاية علامة البيانات. |
| RIGHT | يحدد أن تُعرض تسميات البيانات إلى يمين علامة البيانات. |
| TOP | يحدد أن تُعرض تسميات البيانات فوق علامة البيانات. |
