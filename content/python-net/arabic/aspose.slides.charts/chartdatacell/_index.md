## فئة ChartDataCell

يمثّل خلية لبيانات المخطط.

يُظهر نوع ChartDataCell الأعضاء التالية:

## الخصائص

| الخاصية | الوصف |
| :- | :- |
| [`row`](/slides/python-net/ar/aspose.slides.charts/chartdatacell/row/) | يعيد فهرس الصف في ورقة العمل التي توجد فيها الخلية.<br/>            قراءة فقط **int**. |
| [`column`](/slides/python-net/ar/aspose.slides.charts/chartdatacell/column/) | يعيد فهرس العمود في ورقة العمل التي توجد فيها الخلية.<br/>            قراءة فقط **int**. |
| [`value`](/slides/python-net/ar/aspose.slides.charts/chartdatacell/value/) | تسترجع أو تعين قيمة الخلية.<br/>            قراءة/كتابة **any**. |
| [`formula`](/slides/python-net/ar/aspose.slides.charts/chartdatacell/formula/) | تسترجع أو تعين الصيغة بنمط A1-style. |
| [`r1c1_formula`](/slides/python-net/ar/aspose.slides.charts/chartdatacell/r1c1_formula/) | تسترجع أو تعين الصيغة بنمط R1C1-style. |
| [`chart_data_worksheet`](/slides/python-net/ar/aspose.slides.charts/chartdatacell/chart_data_worksheet/) | تسترجع ورقة العمل.<br/>            قراءة فقط [`IChartDataWorksheet`](/slides/python-net/ar/aspose.slides.charts/ichartdataworksheet). |
| [`is_hidden`](/slides/python-net/ar/aspose.slides.charts/chartdatacell/is_hidden/) | يحدد ما إذا كانت الخلية مخفية.<br/>            قراءة فقط **bool**. |
| [`custom_number_format`](/slides/python-net/ar/aspose.slides.charts/chartdatacell/custom_number_format/) | تسترجع أو تعين تنسيق العرض المخصص للأعداد والتواريخ.<br/>            إذا كان القيمة فارغة سيُستخدم قيمة PresetNumberFormat.<br/>            قراءة/كتابة **str**. |
| [`preset_number_format`](/slides/python-net/ar/aspose.slides.charts/chartdatacell/preset_number_format/) | تسترجع أو تعين تنسيق العرض المدمج للأعداد والتواريخ. يجب أن يكون الرقم المسبق ضمن [0..22] أو [37..49].<br/>            قراءة/كتابة **int**. |
