## ParentLabelLayoutType تعداد

يمثل تخطيط تسميات بيانات الفئة. يُستخدم مع سلسلة Treemap فقط.

يعرض نوع ParentLabelLayoutType الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| BANNER | يحدد أن تسميات الفئة الأصلية تُعرض كبانر |
| NONE | يحدد أن تسميات الفئة الأصلية غير مرسومة |
| OVERLAPPING | يحدد أن تسميات الفئة الأصلية تُعرض متداخلة |
