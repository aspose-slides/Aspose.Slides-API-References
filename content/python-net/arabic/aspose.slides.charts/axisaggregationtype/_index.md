## AxisAggregationType التعداد

يمثل نوع التجميع لمحور الفئة. يُستخدم مع سلاسل Histogram أو HistogramPareto فقط.

يعرض نوع AxisAggregationType الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| BY_CATEGORY | تجميع حسب الفئات |
| AUTOMATIC | تجميع الفئات تلقائيًا. |
| BY_BIN_WIDTH | تجميع الفئات وفقًا لعرض الصندوق. يجب ضبط الخاصية IAxis.BinWidth. |
| BY_NUMBER_OF_BINS | تجميع الفئات وفقًا لعدد الصناديق. يجب ضبط الخاصية IAxis.NumberOfBins. |
