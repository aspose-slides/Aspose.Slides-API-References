## خاصية bubble_size_representation
Specifies how the bubble size values are represented on the bubble chart.
            هذه الخاصية ليست خاصة بهذه السلسلة فقط، بل بكل سلاسل السلسلة الأصلية 
            المجموعة - هذا تمثيل للخاصية المناسبة للمجموعة. وبالتالي هذه الخاصية 
            للقراءة فقط.
            استخدم خاصية ParentSeriesGroup للوصول إلى مجموعة السلسلة الأصلية.
            استخدم خاصية ParentSeriesGroup.BubbleSizeRepresentation قراءة/كتابة لتغيير القيمة.
