## hide(self) {#}
اجعل تسمية البيانات مخفية بشكل افتراضي عبر ضبط جميع علمي Show*-flags (ShowValue, ...) من 
            الخاصية DefaultDataLabelFormat إلى الحالة false.
            سيكون IsVisible false بعد ذلك.


```python
def hide(self):
    ...
```


### ملاحظات
إذا لم تكن تسمية البيانات مرئية بشكل افتراضي (IsVisible is false) يمكنك جعل تسمية البيانات "مرئية 
            بشكل افتراضي" بإعداد علمي Show*-flags (ShowValue, ...) من الخاصية DefaultDataLabelFormat 
            إلى الحالة true.
