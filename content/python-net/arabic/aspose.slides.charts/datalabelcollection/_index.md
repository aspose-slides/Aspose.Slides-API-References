| الخاصية | الوصف |
| :- | :- |
| [`chart`](/slides/python-net/ar/aspose.slides.charts/datalabelcollection/chart/) | يعيد المخطط الأصلى.<br/>            للقراءة فقط [`IChart`](/slides/python-net/ar/aspose.slides.charts/ichart). |
| [`is_visible`](/slides/python-net/ar/aspose.slides.charts/datalabelcollection/is_visible/) | False يعني أن تسمية البيانات غير مرئية بشكل افتراضي (وبالتالي تكون جميع <br/>            Show*-flags (ShowValue, ...) لخاصية DefaultDataLabelFormat هي false).<br/>            للقراءة فقط **bool**. |
| [`count_of_visible_data_labels`](/slides/python-net/ar/aspose.slides.charts/datalabelcollection/count_of_visible_data_labels/) | يحصل على عدد تسميات البيانات المرئية في المجموعة.<br/>            للقراءة فقط **int**. |
| [`count`](/slides/python-net/ar/aspose.slides.charts/datalabelcollection/count/) | يحصل على عدد جميع تسميات البيانات في المجموعة.<br/>            للقراءة فقط **int**. |
| [`default_data_label_format`](/slides/python-net/ar/aspose.slides.charts/datalabelcollection/default_data_label_format/) | يحصل على تنسيق تسمية البيانات الافتراضي.<br/>            للقراءة فقط [`IDataLabelFormat`](/slides/python-net/ar/aspose.slides.charts/idatalabelformat). |
| [`leader_lines_format`](/slides/python-net/ar/aspose.slides.charts/datalabelcollection/leader_lines_format/) | يمثل تنسيق خطوط رصاص تسميات البيانات.<br/>             للقراءة فقط [`IChartLinesFormat`](/slides/python-net/ar/aspose.slides.charts/ichartlinesformat). |
| [`parent_series`](/slides/python-net/ar/aspose.slides.charts/datalabelcollection/parent_series/) | يحصل على السلسلة الأصلية.<br/>            للقراءة فقط [`IChartSeries`](/slides/python-net/ar/aspose.slides.charts/ichartseries). |
