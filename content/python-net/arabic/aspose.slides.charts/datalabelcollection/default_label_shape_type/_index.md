## default_label_shape_type خاصية
يحصل أو يضبط نوع الشكل الافتراضي لتسميات البيانات.
             يعيد [`ShapeType.NOT_DEFINED`](/slides/python-net/ar/aspose.slides/shapetype/NOT_DEFINED) إذا لم يتم تعريف أي شكل.


### ملاحظات

             لجميع تسميات البيانات في المجموعة إلى نفس القيمة.
