## TickLabelPositionType تعداد

يمثل نوع موضع تسميات علامات الفواصل على المحور المحدد.

نوع TickLabelPositionType يعرض الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| HIGH | يحدد أن تسميات المحور تكون عند الطرف الأعلى للمحور المتعامد. |
| LOW | يحدد أن تسميات المحور تكون عند الطرف الأدنى للمحور المتعامد. |
| NEXT_TO | يحدد أن تسميات المحور تكون بجوار المحور. |
| NONE | يحدد أن تسميات المحور لا تُرسم. |
