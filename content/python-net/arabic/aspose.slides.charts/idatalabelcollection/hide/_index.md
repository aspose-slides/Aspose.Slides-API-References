## hide(self) {#}

```python
def hide(self):
    ...
```


### ملاحظات

إذا لم تكن تسمية البيانات مرئية افتراضيًا (IsVisible هو false) يمكنك جعل تسمية البيانات "مرئية افتراضيًا" عن طريق تعيين علامات Show*-flags (ShowValue, ...) للخاصية DefaultDataLabelFormat إلى الحالة true.
