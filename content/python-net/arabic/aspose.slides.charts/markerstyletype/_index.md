## MarkerStyleType التعداد

يحدد شكل العلامة على نقطة البيانات في المخطط.

يعرض نوع MarkerStyleType الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| NOT_DEFINED |  |
| CIRCLE | يحدد أنه سيتم رسم دائرة عند كل نقطة بيانات. |
| DASH | يحدد أنه سيتم رسم شرطة عند كل نقطة بيانات. |
| DIAMOND | يحدد أنه سيتم رسم ماسة عند كل نقطة بيانات. |
| DOT | يحدد أنه سيتم رسم نقطة عند كل نقطة بيانات. |
| NONE | يحدد عدم رسم أي شيء عند كل نقطة بيانات. |
| PICTURE | يحدد أنه سيتم رسم صورة عند كل نقطة بيانات. |
| PLUS | يحدد أنه سيتم رسم علامة زائد عند كل نقطة بيانات. |
| SQUARE | يحدد أنه سيتم رسم مربع عند كل نقطة بيانات. |
| STAR | يحدد أنه سيتم رسم نجمة عند كل نقطة بيانات. |
| TRIANGLE | يحدد أنه سيتم رسم مثلث عند كل نقطة بيانات. |
| X | يحدد أنه سيتم رسم X عند كل نقطة بيانات. |
