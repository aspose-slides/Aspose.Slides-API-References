## IChartDataCell فئة

يمثل خلية لبيانات المخطط.

نوع IChartDataCell يعرض الأعضاء التالية:

## الخصائص

| الخاصية | الوصف |
| :- | :- |
| [`row`](/slides/python-net/ar/aspose.slides.charts/ichartdatacell/row/) | يُعيد فهرس الصف في ورقة العمل التي توجد فيها الخلية.<br/>            للقراءة فقط **int**. |
| [`column`](/slides/python-net/ar/aspose.slides.charts/ichartdatacell/column/) | يُعيد فهرس العمود في ورقة العمل التي توجد فيها الخلية.<br/>            للقراءة فقط **int**. |
| [`value`](/slides/python-net/ar/aspose.slides.charts/ichartdatacell/value/) | يحصل أو يضبط قيمة الخلية.<br/>            قراءة/كتابة **any**. |
| [`formula`](/slides/python-net/ar/aspose.slides.charts/ichartdatacell/formula/) | يحصل أو يضبط الصيغة بنمط A1.<br/>            قراءة/كتابة. |
| [`r1c1_formula`](/slides/python-net/ar/aspose.slides.charts/ichartdatacell/r1c1_formula/) | يحصل أو يضبط الصيغة بنمط R1C1.<br/>            قراءة/كتابة. |
| [`chart_data_worksheet`](/slides/python-net/ar/aspose.slides.charts/ichartdatacell/chart_data_worksheet/) | يحصل على ورقة العمل.<br/>            للقراءة فقط [`IChartDataWorksheet`](/slides/python-net/ar/aspose.slides.charts/ichartdataworksheet). |
| [`is_hidden`](/slides/python-net/ar/aspose.slides.charts/ichartdatacell/is_hidden/) | يحدد ما إذا كانت الخلية مخفية.<br/>            للقراءة فقط **bool**. |
| [`custom_number_format`](/slides/python-net/ar/aspose.slides.charts/ichartdatacell/custom_number_format/) | يحصل أو يضبط تنسيق العرض المخصص للأرقام والتواريخ.<br/>            إذا كانت القيمة فارغة سيُستخدم قيمة PresetNumberFormat.<br/>            قراءة/كتابة **str**. |
| [`preset_number_format`](/slides/python-net/ar/aspose.slides.charts/ichartdatacell/preset_number_format/) | يحصل أو يضبط تنسيق العرض المدمج للأرقام والتواريخ. يجب أن يكون الرقم المسبق في النطاق [0..22] أو [37..49].<br/>            قراءة/كتابة **int**. |
