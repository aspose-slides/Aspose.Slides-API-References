| الخاصية | الوصف |
| :- | :- |
| [`x`](/slides/python-net/ar/aspose.slides.charts/legend/x/) | يعيد أو يعيّن إحداثي x للأسطورة كنسبة من عرض المخطط.<br/>            قراءة/كتابة **float**. |
| [`y`](/slides/python-net/ar/aspose.slides.charts/legend/y/) | يعيد أو يعيّن إحداثي y للأسطورة كنسبة من ارتفاع المخطط.<br/>            قراءة/كتابة **float**. |
| [`width`](/slides/python-net/ar/aspose.slides.charts/legend/width/) | يعيد أو يعيّن عرض الأسطورة كنسبة من عرض المخطط.<br/>            قراءة/كتابة **float**. |
| [`height`](/slides/python-net/ar/aspose.slides.charts/legend/height/) | يعيد أو يعيّن ارتفاع الأسطورة كنسبة من ارتفاع المخطط.<br/>            قراءة/كتابة **float**. |
| [`right`](/slides/python-net/ar/aspose.slides.charts/legend/right/) | يمين.<br/>            قراءة فقط **float**. |
| [`bottom`](/slides/python-net/ar/aspose.slides.charts/legend/bottom/) | أسفل.<br/>            قراءة فقط **float**. |
| [`overlay`](/slides/python-net/ar/aspose.slides.charts/legend/overlay/) | يحدد ما إذا كان يُسمح لعناصر المخطط الأخرى بالتداخل مع الأسطورة.<br/>            قراءة/كتابة **bool**. |
| [`text_format`](/slides/python-net/ar/aspose.slides.charts/legend/text_format/) | تنسيق النص.<br/>            قراءة فقط [`IChartTextFormat`](/slides/python-net/ar/aspose.slides.charts/icharttextformat). |
| [`position`](/slides/python-net/ar/aspose.slides.charts/legend/position/) | يحدد موضع الأسطورة على المخطط.<br/>            القيم غير NaN للخاصيات X, Y, Width, Heigt تتجاوز تأثير هذه الخاصية.<br/>            قراءة/كتابة [`LegendPositionType`](/slides/python-net/ar/aspose.slides.charts/legendpositiontype). |
| [`format`](/slides/python-net/ar/aspose.slides.charts/legend/format/) | يعيد تنسيق الأسطورة.<br/>            قراءة فقط [`IFormat`](/slides/python-net/ar/aspose.slides.charts/iformat). |
| [`chart`](/slides/python-net/ar/aspose.slides.charts/legend/chart/) | يعيد المخطط.<br/>            قراءة فقط [`IChart`](/slides/python-net/ar/aspose.slides.charts/ichart). |
| [`entries`](/slides/python-net/ar/aspose.slides.charts/legend/entries/) | يحصل على مدخلات الأسطورة.<br/>            قراءة فقط [`ILegendEntryCollection`](/slides/python-net/ar/aspose.slides.charts/ilegendentrycollection). |
| [`actual_x`](/slides/python-net/ar/aspose.slides.charts/legend/actual_x/) | يحدد الموقع الفعلي x (اليسار) لعنصر المخطط بالنسبة إلى الزاوية اليسرى العليا للمخطط.<br/>            استدعِ الطريقة IChart.ValidateChartLayout() أولاً للحصول على القيم الفعلية. <br/>            قراءة **float**. |
| [`actual_y`](/slides/python-net/ar/aspose.slides.charts/legend/actual_y/) | يحدد أعلى العنصر الفعلي للمخطط بالنسبة إلى الزاوية اليسرى العليا للمخطط.<br/>            استدعِ الطريقة IChart.ValidateChartLayout() أولاً للحصول على القيم الفعلية. <br/>            قراءة **float**. |
| [`actual_width`](/slides/python-net/ar/aspose.slides.charts/legend/actual_width/) | يحدد العرض الفعلي لعنصر المخطط. استدعِ الطريقة IChart.ValidateChartLayout() أولاً للحصول على القيم الفعلية. <br/>            قراءة **float**. |
| [`actual_height`](/slides/python-net/ar/aspose.slides.charts/legend/actual_height/) | يحدد الارتفاع الفعلي لعنصر المخطط. استدعِ الطريقة IChart.ValidateChartLayout() أولاً للحصول على القيم الفعلية. <br/>            قراءة **float**. |
