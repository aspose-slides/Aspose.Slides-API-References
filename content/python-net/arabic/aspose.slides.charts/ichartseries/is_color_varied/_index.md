## خاصية is_color_varied
Specifies that each data marker in the series has a different color.
            هذه الخاصية ليست فقط لهذه السلسلة ولكن لجميع سلاسل مجموعة السلاسل الأصلية 
            - هذه نسخة من خاصية المجموعة المناسبة. وبالتالي هذه الخاصية 
            للقراءة فقط.
            استخدم خاصية ParentSeriesGroup للوصول إلى مجموعة السلاسل الأصلية.
            استخدم خاصية ParentSeriesGroup.IsColorVaried للقراءة/الكتابة لتغيير القيمة.
            للقراءة فقط **bool**.
