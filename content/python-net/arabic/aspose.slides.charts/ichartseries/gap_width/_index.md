## خاصية gap_width
Specifies the space between bar or column clusters, as a percentage of the bar or column width.
            هذه الخاصية ليست فقط لهذه السلسلة بل لجميع سلاسل مجموعة السلسلة الأصلية - هذه تمثيل للخاصية المناسبة للمجموعة. وبالتالي هذه الخاصية للقراءة فقط.
            استخدم خاصية ParentSeriesGroup للوصول إلى مجموعة السلسلة الأصلية.
            استخدم خاصية ParentSeriesGroup.GapWidth القراءة/الكتابة لتغيير القيمة.
            للقراءة فقط **int**.
