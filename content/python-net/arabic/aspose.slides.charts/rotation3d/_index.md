## Rotation3D فئة

يمثِّل دوران ثلاثي الأبعاد للمخطط.

يعرض نوع Rotation3D الأعضاء التالية:

## الخصائص

| الخاصية | الوصف |
| :- | :- |
| [`rotation_x`](/slides/python-net/ar/aspose.slides.charts/rotation3d/rotation_x/) | يرجع أو يعيّن درجة الدوران حول محور X، أي في الاتجاه Y للمخططات ثلاثية الأبعاد (بين -90 و 90 درجة).<br/>            تتطابق الخاصية مع العنصر 21.2.2.157 rotX (X Rotation) في ECMA-376 ومع خيار "Y Rotation" في PowerPoint 2007+.<br/>            قراءة/كتابة **int**. |
| [`rotation_y`](/slides/python-net/ar/aspose.slides.charts/rotation3d/rotation_y/) | يرجع أو يعيّن درجة الدوران حول محور Y، أي في الاتجاه X للمخططات ثلاثية الأبعاد (بين 0 و 360 درجة).<br/>            تتطابق الخاصية مع العنصر 21.2.2.158 rotY (Y Rotation) في ECMA-376 ومع خيار "X Rotation" في PowerPoint 2007+.<br/>            قراءة/كتابة **int**. |
| [`perspective`](/slides/python-net/ar/aspose.slides.charts/rotation3d/perspective/) | يرجع أو يعيّن قيمة المنظور (زاوية مجال الرؤية) للمخططات ثلاثية الأبعاد (بين 0 و 240).<br/>            يتم تجاهلها إذا كانت قيمة الخاصية RightAngleAxes صحيحة.<br/>            قراءة/كتابة **int**. |
| [`right_angle_axes`](/slides/python-net/ar/aspose.slides.charts/rotation3d/right_angle_axes/) | يحدد ما إذا كانت محاور المخطط بزاويا قائمة، بدلاً من رسمها بمنظور.<br/>            بعبارة أخرى يحدد ما إذا كانت زوايا محاور المخطط مستقلة عن دوران أو ارتفاع المخطط.<br/>            قراءة/كتابة **bool**. |
| [`depth_percents`](/slides/python-net/ar/aspose.slides.charts/rotation3d/depth_percents/) | يرجع أو يعيّن عمق المخطط ثلاثي الأبعاد كنسبة مئوية لعرض المخطط (بين 20 و 2000 بالمائة).<br/>            قراءة/كتابة **int**. |
| [`height_percents`](/slides/python-net/ar/aspose.slides.charts/rotation3d/height_percents/) | يحدد ارتفاع المخطط ثلاثي الأبعاد كنسبة مئوية لعرض المخطط (بين 5 و 500 بالمائة).<br/>            قراءة/كتابة **int**. |
