## تعداد ChartShapeType

يمثل شكلاً للمخطط.

يوفر النوع ChartShapeType الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| NOT_DEFINED | شكل المخطط غير معرف. |
| BOX | يحدد أن يتم رسم المخطط بشكل صندوق. |
| CONE | يحدد أن يتم رسم المخطط كقمع، مع قاعدة القمع على الأرض وقمة القمع في أعلى مؤشر البيانات. |
| CONE_TO_MAX | يحدد أن يتم رسم المخطط بأقماع مقصوصة بحيث تكون قمة القمع هي القيمة القصوى للبيانات. |
| CYLINDER | يحدد أن يتم رسم المخطط كأسطوانة. |
| PYRAMID | يحدد أن يتم رسم المخطط كهرم مستطيل، مع قاعدة الهرم على الأرض وقمة الهرم في أعلى مؤشر البيانات. |
| PYRAMID_TO_MAXIMUM | يحدد أن يتم رسم المخطط بأقماع مقصوصة بحيث تكون قمة القمع هي القيمة القصوى للبيانات. |
