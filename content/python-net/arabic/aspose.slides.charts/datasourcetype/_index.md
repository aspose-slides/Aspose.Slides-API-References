## تعداد DataSourceType

أنواع مصادر البيانات.

يوفر نوع DataSourceType الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| WORKSHEET | استخدم كائنات CellXls لتخزين XValue و YValue و Value أو BubbleSize لنقطة البيانات في ورقة العمل. |
| STRING_LITERALS | استخدم متغير سلسلة سريع الوصول لتخزين XValue و YValue و Value أو BubbleSize من <br/>            نقطة البيانات. ورقة العمل لا تُستخدم لتخزين القيم. |
| DOUBLE_LITERALS | استخدم متغير مزدوج سريع الوصول لتخزين XValue و YValue و Value أو BubbleSize من <br/>            نقطة البيانات. ورقة العمل لا تُستخدم لتخزين القيم. |
