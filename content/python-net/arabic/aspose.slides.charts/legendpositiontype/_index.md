## LegendPositionType التعداد

يحدد موضع المفتاح في الرسم البياني.

يعرض نوع LegendPositionType الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| BOTTOM | يحدد أن يتم رسم المفتاح في أسفل الرسم البياني. |
| LEFT | يحدد أن يتم رسم المفتاح على يسار الرسم البياني. |
| RIGHT | يحدد أن يتم رسم المفتاح على يمين الرسم البياني. |
| TOP | يحدد أن يتم رسم المفتاح في أعلى الرسم البياني. |
| TOP_RIGHT | يحدد أن يتم رسم المفتاح في أعلى يمين الرسم البياني. |
