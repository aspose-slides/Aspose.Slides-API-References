## تعداد TickMarkType

يمثل نوع علامة الفاصل للمحور المحدد.

يُظهر تعداد TickMarkType الأعضاء التالية:

## الحقول

| Field | Description |
| :- | :- |
| CROSS | يحدد أن علامات الفواصل يجب أن تتقاطع مع المحور. |
| INSIDE | يحدد أن علامات الفواصل يجب أن تكون داخل منطقة الرسم. |
| NONE | يحدد عدم وجود علامات الفواصل. |
| OUTSIDE | يحدد أن علامات الفواصل يجب أن تكون خارج منطقة الرسم. |
