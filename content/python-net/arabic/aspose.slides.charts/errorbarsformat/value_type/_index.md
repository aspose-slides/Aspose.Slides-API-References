## value_type خاصية
يمثِّل الطرق الممكنة لتحديد طول أشرطة الخطأ. 
            في حالة نوع القيمة المخصص لتحديد القيمة، استخدم خاصية [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/ar/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) لنقطة البيانات المحددة في مجموعة DataPoints للسلسلة.
            في حالة نوع القيمة Fixed أو Percentage أو StandardDeviation، استخدم خاصية Value لتحديد القيمة.  
            قراءة/كتابة [`ErrorBarValueType`](/slides/python-net/ar/aspose.slides.charts/errorbarvaluetype).
