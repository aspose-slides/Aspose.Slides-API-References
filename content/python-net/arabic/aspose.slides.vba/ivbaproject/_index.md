## فئة IVbaProject

يمثل مشروع VBA مع وحدات ماكرو للعرض.

يعرض نوع IVbaProject الأعضاء التالية:

## الخصائص

| الخاصية | الوصف |
| :- | :- |
| [`name`](/slides/python-net/ar/aspose.slides.vba/ivbaproject/name/) | يرجع اسم مشروع VBA.<br/>            للقراءة فقط **str**. |
| [`modules`](/slides/python-net/ar/aspose.slides.vba/ivbaproject/modules/) | يرجع قائمة جميع الوحدات التي يحتويها مشروع VBA.<br/>            للقراءة فقط [`IVbaModuleCollection`](/slides/python-net/ar/aspose.slides.vba/ivbamodulecollection). |
| [`references`](/slides/python-net/ar/aspose.slides.vba/ivbaproject/references/) | يرجع قائمة جميع المراجع التي يحتويها مشروع VBA.<br/>            للقراءة فقط [`IVbaReferenceCollection`](/slides/python-net/ar/aspose.slides.vba/ivbareferencecollection). |
| [`is_password_protected`](/slides/python-net/ar/aspose.slides.vba/ivbaproject/is_password_protected/) | يشير إلى ما إذا كان VBAProject محميًا بكلمة مرور لعرض خصائص المشروع.<br/>            للقراءة فقط **bool**. |
