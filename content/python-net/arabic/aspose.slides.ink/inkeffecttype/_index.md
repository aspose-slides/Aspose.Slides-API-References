## InkEffectType تعداد

يحدد مجموعة من التأثيرات البصرية المحددة مسبقًا لتصيير الحبر. كل تأثير يتCorrespond to a texture or image that simulates a stylized ink appearance. These values can be used to customize the visual style of digital ink strokes during rendering.

يُظهر نوع InkEffectType الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| NOT_DEFINED | التأثير غير معرف أو غير معروف. يمكن استخدام هذه القيمة كقيمة افتراضية أو احتياطية. |
| BRONZE | نقشة معدنية دافئة بنية اللون تشبه حبر البرونز. |
| GALAXY | نقشة ملونة متلألئة تشبه مجرة، بألوان كونية. |
| GOLD | نقشة ذهبية معدنية لامعة تمنح ضربات الحبر مظهراً فاخراً. |
| LAVA | نقشة نارية تشبه الحمم المنصهرة، بألوان حمراء وبرتقالية. |
| OCEAN | نقشة زرقاء عميقة تشبه السائل، تحاكي أمواج المحيط أو الحبر القائم على الماء. |
| RAINBOW_GLITTER | تأثير بريق قوس قزح ملون ومتألق يُستخدم لضربات حبر احتفالية أو حيوية. |
| ROSE_GOLD | مزيج ناعم من اللون الوردي والذهب، مشابه للذهب الوردي، لضربات حبر أنيقة. |
| SILVER | نقشة فضية معدنية باردة تحاكي حبر الفضة التقليدي. |
