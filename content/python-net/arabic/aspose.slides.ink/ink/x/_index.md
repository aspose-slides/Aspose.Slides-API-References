## خاصية x
يقوم بالحصول أو تعيين الإحداثي السيني للزاوية العلوية اليسرى للكيان، مقاسًا بالنقاط.
            قراءة/كتابة **float**.

### ملاحظات

القيمة المرتجعة تكون دائمًا مُعَرَّفة ولا تكون أبدًا **float**.
            يجب أيضًا أن تكون القيمة المعطاة مُعَرَّفة؛ قم بتعيين **float** فقط إلى خصائص كائن `RawFrame`.

### التعريف:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
