## تعداد التوافق

يحدد فئة التوافق التي يتطابق معها مستند PresentationML.

نوع Conformance يعرض الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| ECMA_376_2006 | يحدد أن المستند يتطابق مع ECMA376:2006. |
| ISO_29500_2008_TRANSITIONAL | يحدد أن المستند يتطابق مع الفئة الانتقالية لتوافق ISO/IEC 29500:2008. |
| ISO_29500_2008_STRICT | يحدد أن المستند يتطابق مع الفئة الصارمة لتوافق ISO/IEC 29500:2008. |
