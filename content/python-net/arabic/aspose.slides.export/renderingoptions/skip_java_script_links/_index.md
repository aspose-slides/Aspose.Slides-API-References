## skip_java_script_links خاصية
يحدد ما إذا كان يجب تخطي الروابط التشعبية التي تستدعي JavaScript عند حفظ العرض التقديمي. 
            قراءة/كتابة **bool**. القيمة الافتراضية هي **false** .

### ملاحظات

عند تعيين هذه الخاصية إلى **true** ، سيتم تجاهل الروابط التشعبية التي تستدعي JavaScript أثناء الحفظ.

عند تعيين هذه الخاصية إلى **false** ، سيتم حفظ جميع الروابط التشعبية.
