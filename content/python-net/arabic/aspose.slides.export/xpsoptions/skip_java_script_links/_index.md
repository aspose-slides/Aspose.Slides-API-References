## خاصية skip_java_script_links
يحدد ما إذا كان يجب تخطي الارتباطات التشعبية التي تستدعي JavaScript عند حفظ العرض التقديمي. 
قراءة/كتابة **bool**. القيمة الافتراضية هي **false** .


### ملاحظات

عند ضبط هذه الخاصية على **true** , سيتجاهل الارتباطات التشعبية التي تستدعي JavaScript أثناء الحفظ.

عند ضبط هذه الخاصية على **false** , سيتم حفظ جميع الارتباطات التشعبية.
