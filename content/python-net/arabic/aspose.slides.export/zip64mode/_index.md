## Zip64Mode تعداد

يحدد متى يتم استخدام امتدادات تنسيق ZIP64 لملف OpenXML.

يعرض نوع Zip64Mode الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| NEVER | لا تستخدم امتدادات تنسيق ZIP64. |
| IF_NECESSARY | استخدم امتدادات تنسيق ZIP64 إذا لزم الأمر. |
| ALWAYS | استخدم امتدادات تنسيق ZIP64 دائمًا. |


### ملاحظات

ملف OpenXML هو أرشيف ZIP له حد 4 جيجابايت (2^32 بايت) على الحجم غير المضغوط للملف، الحجم المضغوط للملف، والحجم الكلي للأرشيف، بالإضافة إلى حد 65,535 (2^16-1) ملفًا في الأرشيف. تُزيد امتدادات تنسيق ZIP64 هذه الحدود إلى 2^64.
