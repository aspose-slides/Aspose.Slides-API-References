## SvgExternalFontsHandling التعداد

يمثل طريقة للتعامل مع الخطوط الخارجية المستخدمة في رسم النص.

نوع SvgExternalFontsHandling يكشف عن الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| ADD_LINKS_TO_FONT_FILES | إضافة روابط إلى ملفات خطوط منفصلة في قسم النمط لملف SVG. |
| EMBED | حفظ بيانات الخطوط مباشرةً إلى ملف SVG. يرجى التحقق من جميع اتفاقيات ترخيص الخطوط الخارجية قبل استخدام هذا الخيار. |
| VECTORIZE | حفظ كل النص باستخدام الخطوط الخارجية كرسوميات. |
