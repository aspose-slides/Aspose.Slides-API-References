## التعداد CommentsPositions

يمثل القاعدة لتصوير التعليقات في المستند المُصدّر

يعرض نوع CommentsPositions الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| NONE | يحدد أنه لا ينبغي عرض التعليقات على الإطلاق. |
| BOTTOM | يحدد أنه يجب عرض التعليقات في أسفل الصفحة. |
| RIGHT | يحدد أنه يجب عرض التعليقات إلى يمين الصفحة. |
