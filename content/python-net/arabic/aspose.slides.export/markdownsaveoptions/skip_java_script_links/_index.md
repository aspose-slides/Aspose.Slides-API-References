## skip_java_script_links الخاصية
يحدد ما إذا كان يجب تخطي الروابط التشعبية التي تستدعي جافا سكريبت عند حفظ العرض التقديمي. 
            قراءة/كتابة **bool**. القيمة الافتراضية هي **false** .


### ملاحظات

عند تعيين هذه الخاصية إلى **true**, الروابط التشعبية التي تستدعي جافا سكريبت سيتم تجاهلها أثناء الحفظ.


عند تعيين هذه الخاصية إلى **false**, سيتم حفظ جميع الروابط التشعبية.
