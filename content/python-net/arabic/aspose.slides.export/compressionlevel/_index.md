## CompressionLevel التعداد

يحدد مستويات ضغط ZIP لملف OpenXML.
توفر المستويات الأعلى ضغطًا أفضل على حساب معالجة أبطأ.

يعرض نوع CompressionLevel الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| NONE | لا يتم تطبيق ضغط. تُخزن الملفات كما هي. |
| LEVEL1 | أسرع ضغط مع أقل نسبة ضغط. |
| LEVEL2 | ضغط أسرع مع نسبة ضغط أفضل قليلاً من [`CompressionLevel.LEVEL1`](/slides/python-net/ar/aspose.slides.export/compressionlevel/LEVEL1). |
| LEVEL3 | يوفر ضغطًا أفضل من [`CompressionLevel.LEVEL2`](/slides/python-net/ar/aspose.slides.export/compressionlevel/LEVEL2) مع تأثير متوسط على الأداء. |
| LEVEL4 | يوفر ضغطًا أفضل من [`CompressionLevel.LEVEL3`](/slides/python-net/ar/aspose.slides.export/compressionlevel/LEVEL3). |
| LEVEL5 | يوفر ضغطًا محسّنًا مقارنةً بـ [`CompressionLevel.LEVEL4`](/slides/python-net/ar/aspose.slides.export/compressionlevel/LEVEL4) مع وقت معالجة إضافي. |
| LEVEL6 | ضغط قياسي، يقدم توازنًا جيدًا بين سرعة الضغط وحجم الملف.<br/>            مستوى الضغط الافتراضي. |
| LEVEL7 | يوفر ضغطًا أعلى من [`CompressionLevel.LEVEL6`](/slides/python-net/ar/aspose.slides.export/compressionlevel/LEVEL6) مع معالجة أبطأ. |
| LEVEL8 | يوفر ضغطًا أعلى من [`CompressionLevel.LEVEL7`](/slides/python-net/ar/aspose.slides.export/compressionlevel/LEVEL7). |
| LEVEL9 | أقصى ضغط. ينتج أصغر حجم ملف بأبطأ سرعة معالجة. |
