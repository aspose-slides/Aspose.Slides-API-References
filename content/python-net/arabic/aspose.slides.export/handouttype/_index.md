## HandoutType تعداد

يحدد عدد الشرائح والترتيب الذي سيتم وضعها فيه على الصفحة.

ي exposé نوع HandoutType الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| HANDOUTS1 | شريحة واحدة لكل صفحة. |
| HANDOUTS2 | شريحتان لكل صفحة. |
| HANDOUTS3 | ثلاث شرائح لكل صفحة. |
| HANDOUTS_4_HORIZONTAL | أربع شرائح لكل صفحة بترتيب أفقي. |
| HANDOUTS_4_VERTICAL | أربع شرائح لكل صفحة بترتيب عمودي. |
| HANDOUTS_6_HORIZONTAL | ست شرائح لكل صفحة بترتيب أفقي. |
| HANDOUTS_6_VERTICAL | ست شرائح لكل صفحة بترتيب عمودي. |
| HANDOUTS_9_HORIZONTAL | تسع شرائح لكل صفحة بترتيب أفقي. |
| HANDOUTS_9_VERTICAL | تسع شرائح لكل صفحة بترتيب عمودي. |
