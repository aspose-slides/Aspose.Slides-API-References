## BlackWhiteConversionMode تعداد

يوفر خيارات تتحكم في كيفية تحويل صور الشرائح إلى صور ذات تدرجين لونيين.

يعرض نوع BlackWhiteConversionMode الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| DEFAULT | يحدد عدم وجود خوارزمية تحويل. سيتم استخدام الخوارزمية المنفذة في برنامج الترميز TIFF. (الافتراضي) |
| DITHERING | يحدد خوارزمية التهليل (Floyd-Steinberg). |
| DITHERING_FLOYD_STEINBERG | يحدد خوارزمية تهليل Floyd-Steinberg. |
| AUTO | يحدد خوارزمية العتبة المُحسبَة تلقائيًا (Otsu). |
| AUTO_OTSU | يحدد خوارزمية عتبة Otsu المُحسبَة تلقائيًا. |
| THRESHOLD25 | يحدد خوارزمية العتبة الثابتة (25%). |
| THRESHOLD50 | يحدد خوارزمية العتبة الثابتة (50%). |
| THRESHOLD75 | يحدد خوارزمية العتبة الثابتة (75%). |
