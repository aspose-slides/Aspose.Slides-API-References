## skip_java_script_links الخاصية
Specifies whether to skip hyperlinks with JavaScript calls when saving the presentation. 
            قراءة/كتابة **bool**. القيمة الافتراضية هي **false** .

### ملاحظات

When this property is set to **true** , سيتم تجاهل الروابط التشعبية التي تستدعي جافا سكريبت أثناء الحفظ.

When this property is set to **false** , سيتم حفظ جميع الروابط التشعبية.
