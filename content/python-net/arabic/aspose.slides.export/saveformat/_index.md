## تعداد SaveFormat

الثوابت التي تحدد تنسيق عرض تقديمي محفوظ.

نوع SaveFormat يعرض الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| PPT | حفظ العرض التقديمي بصيغة PPT. |
| PDF | حفظ العرض التقديمي بصيغة PDF. |
| XPS | حفظ العرض التقديمي بصيغة XPS. |
| PPTX | حفظ العرض التقديمي بصيغة PPTX. |
| PPSX | حفظ العرض التقديمي بصيغة PPSX (عرض شرائح). |
| TIFF | حفظ العرض التقديمي كصورة TIFF متعددة الصفحات. |
| ODP | حفظ العرض التقديمي بصيغة ODP. |
| PPTM | حفظ العرض التقديمي بصيغة PPTM (عرض تقديمي يدعم الماكرو). |
| PPSM | حفظ العرض التقديمي بصيغة PPSM (عرض شرائح يدعم الماكرو). |
| POTX | حفظ العرض التقديمي بصيغة POTX (قالب). |
| POTM | حفظ العرض التقديمي بصيغة POTM (قالب يدعم الماكرو). |
| HTML | حفظ العرض التقديمي بصيغة HTML. |
| SWF | حفظ العرض التقديمي بصيغة SWF. |
| OTP | حفظ العرض التقديمي بصيغة OTP (قالب عرض تقديمي). |
| PPS | حفظ العرض التقديمي بصيغة PPS. |
| POT | حفظ العرض التقديمي بصيغة POT. |
| FODP | حفظ العرض التقديمي بصيغة FODP. |
| GIF | حفظ العرض التقديمي بصيغة GIF. |
| HTML5 | حفظ العرض التقديمي بصيغة HTML باستخدام نظام القوالب الجديد HTML5. |
| MD | حفظ العرض التقديمي بصيغة Markdown |
| XML | حفظ العرض التقديمي بصيغة PowerPoint XML Presentation. |
