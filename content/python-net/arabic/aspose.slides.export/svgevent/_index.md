## تعداد SvgEvent

يمثل خيارات شكل SVG.

يعرض نوع SvgEvent الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| ON_FOCUS_IN | يحدث عندما يحصل عنصر على التركيز، مثل عندما يُحدَّد نص. |
| ON_FOCUS_OUT | يحدث عندما يفقد عنصر التركيز، مثل عندما يُلغى تحديد النص. |
| ON_ACTIVATE | يحدث عندما يتم تفعيل عنصر، على سبيل المثال، عبر نقرة فأرة أو ضغط مفتاح. |
| ON_CLICK | يحدث عندما يُنقر زر جهاز الإشارة فوق عنصر. |
| ON_MOUSE_DOWN | يحدث عندما يُضغط زر جهاز الإشارة فوق عنصر. |
| ON_MOUSE_UP | يحدث عندما يُرفع زر جهاز الإشارة فوق عنصر. |
| ON_MOUSE_OVER | يحدث عندما يتحرك جهاز الإشارة إلى عنصر. |
| ON_MOUSE_MOVE | يحدث عندما يتحرك جهاز الإشارة وهو فوق عنصر. |
| ON_MOUSE_OUT | يحدث عندما يتحرك جهاز الإشارة بعيدًا عن عنصر. |
| ON_LOAD | يحدث عندما يقوم وكيل المستخدم بتحليل العنصر وسلالته وجميع الموارد المرجعية اللازمة لعرضه بالكامل. |
| ON_UNLOAD | يحدث عندما يزيل تنفيذ DOM مستندًا من نافذة أو إطار. ينطبق فقط على عناصر svg الخارجية. |
| ON_ABORT | يحدث عندما يتم إيقاف تحميل الصفحة قبل أن يُسمح للعنصر بالتحميل بالكامل. |
| ON_ERROR | يحدث عندما لا يتم تحميل العنصر بشكل صحيح أو عندما يحدث خطأ أثناء تنفيذ النص البرمجي. |
| ON_RESIZE | يحدث عندما يتم تغيير حجم عرض المستند. ينطبق فقط على عناصر svg الخارجية. |
| ON_SCROLL | يحدث عندما يتم تحريك عرض المستند على المحور X أو Y أو كليهما. ينطبق فقط على عناصر svg الخارجية. |
| ON_ZOOM | يحدث عندما يتم تغيير مستوى التكبير في عرض المستند. ينطبق فقط على عناصر svg الخارجية. |
| ON_BEGIN | يحدث عندما يبدأ عنصر الرسوم المتحركة. |
| ON_END | يحدث عندما ينتهي عنصر الرسوم المتحركة. |
| ON_REPEAT | يحدث عندما يتكرر عنصر الرسوم المتحركة. |
