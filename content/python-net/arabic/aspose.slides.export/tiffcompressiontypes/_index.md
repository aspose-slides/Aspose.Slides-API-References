## TiffCompressionTypes تعداد

يوفر خيارات تتحكم في كيفية ضغط عرض تقديمي بصيغة TIFF.

يظهر نوع TiffCompressionTypes الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| DEFAULT | يحدد نظام الضغط الافتراضي (LZW). |
| NONE | يحدد عدم وجود ضغط. |
| CCITT3 | يحدد نظام ضغط CCITT3. |
| CCITT4 | يحدد نظام ضغط CCITT4. |
| LZW | يحدد نظام ضغط LZW (الافتراضي). |
| RLE | يحدد نظام ضغط RLE. |
