## AfterAnimationType تعداد

يمثل نوع الرسوم المتحركة بعد التنفيذ لتأثير الرسوم المتحركة.

يكشف نوع AfterAnimationType عن الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| DO_NOT_DIM | عدم تعتيم بعد نوع الرسوم المتحركة. |
| COLOR | لون بعد نوع الرسوم المتحركة. |
| HIDE_AFTER_ANIMATION | إخفاء بعد نوع الرسوم المتحركة |
| HIDE_ON_NEXT_MOUSE_CLICK | إخفاء عند النقر بالفأرة التالي بعد نوع الرسوم المتحركة. |
