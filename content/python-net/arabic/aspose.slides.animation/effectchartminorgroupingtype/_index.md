## EffectChartMinorGroupingType تعداد

يمثل نوع تأثير الرسوم المتحركة لعنصر المخطط في السلسلة أو الفئة.

نوع EffectChartMinorGroupingType يعرض الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| BY_ELEMENT_IN_SERIES | تحريك المخطط حسب العنصر في السلسلة |
| BY_ELEMENT_IN_CATEGORY | تحريك المخطط حسب العنصر في الفئة |
