## التعداد OrganizationChartLayoutType

يمثل نوع تنسيق العقد الفرعية في مخطط المنظمة

يبين نوع OrganizationChartLayoutType الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| INITIAL | نوع التخطيط الأولي |
| STANDART | يوضع العقد الفرعية أفقياً أسفل العقدة الأصلية. |
| BOTH_HANGING | يوضع العقد الفرعية عموديًا أسفل العقدة الأصلية على الجانب الأيسر والجانب الأيمن. |
| LEFT_HANGING | يوضع العقد الفرعية عموديًا أسفل العقدة الأصلية على الجانب الأيسر. |
| RIGHT_HANGING | يوضع العقد الفرعية عموديًا أسفل العقدة الأصلية على الجانب الأيمن. |
