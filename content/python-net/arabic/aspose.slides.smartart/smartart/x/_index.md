## خاصية x
يحصل أو يحدد إحداثي x للزاوية العليا اليسرى للشكل، مقاساً بالنقاط.
            قراءة/كتابة **float**.


### ملاحظات

القيمة المعادة دائماً معرفة ولا تكون أبداً **float**.
            يجب أن تكون القيمة المعينة أيضًا معرفة؛ خصّص **float** فقط لخصائص كائن `RawFrame` instance.

### التعريف:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
