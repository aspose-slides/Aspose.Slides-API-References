## beginning_character خاصية
Delimiter Beginning Character يحدد البداية أو الحرف الافتتاحي للفواصل. 
            الفواصل الرياضية هي أحرف إحاطة مثل الأقواس المستديرة، والأقواس المربعة، والأقواس المعقوفة.
            القيمة الافتراضية: '('.
