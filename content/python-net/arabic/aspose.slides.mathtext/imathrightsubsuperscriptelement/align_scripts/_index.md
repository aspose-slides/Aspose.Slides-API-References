## خاصية align_scripts
يحدد محاذاة النص السفلي/العلوي. 
            عندما true، يتم محاذاة النص السفلي والعلوي أفقياً إلى بعضهما.
            عندما false، يتم ضبطهما وفقًا لشكل القاعدة.
            القيمة الافتراضية هي false.
