| [`advance_after`](/slides/python-net/ar/aspose.slides.slideshow/slideshowtransition/advance_after/) | تحدد هذه السمة ما إذا كان عرض الشرائح سيتنقل إلى الشريحة التالية بعد وقت معين.<br/>            قراءة/كتابة **bool**. |
| [`advance_after_time`](/slides/python-net/ar/aspose.slides.slideshow/slideshowtransition/advance_after_time/) | تحدد الوقت، بالميليثانية، الذي يجب أن يبدأ بعده الانتقال.<br/>            قد يُستخدم هذا الإعداد بالاشتراك مع سمة advClick.<br/>            إذا لم يتم تحديد هذه السمة<br/>            فإنه يُفترض عدم حدوث تقدم تلقائي.<br/>            قراءة/كتابة **int**. |

| [`value`](/slides/python-net/ar/aspose.slides.slideshow/slideshowtransition/value/) | قيمة انتقال عرض الشرائح.<br/>            قراءة فقط [`ITransitionValueBase`](/slides/python-net/ar/aspose.slides.slideshow/itransitionvaluebase). |
| [`type`](/slides/python-net/ar/aspose.slides.slideshow/slideshowtransition/type/) | نوع الانتقال.<br/>            قراءة/كتابة [`TransitionType`](/slides/python-net/ar/aspose.slides.slideshow/transitiontype). |

| [`duration`](/slides/python-net/ar/aspose.slides.slideshow/slideshowtransition/duration/) | يحصل على أو يضبط مدة تأثير انتقال الشريحة بالميليثانية.<br/>            قراءة/كتابة **int**. |
