## TextAlignment التعداد

يمثل أنماط محاذاة النص المختلفة.

نوع TextAlignment يعرض الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| NOT_DEFINED | المحاذاة الافتراضية. |
| LEFT | محاذاة لليسار. |
| CENTER | محاذاة للوسط. |
| RIGHT | محاذاة لليمين. |
| JUSTIFY | محاذاة ضبط. |
| JUSTIFY_LOW | محاذاة كاشدة منخفضة. |
| DISTRIBUTED | محاذاة موزعة. |
