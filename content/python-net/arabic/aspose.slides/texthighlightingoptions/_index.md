## TextHighlightingOptions فئة

يمثل الخيارات التي يمكن استخدامها لتسليط الضوء على النص داخل إطار النص.

يعرض النوع TextHighlightingOptions الأعضاء التالية:

## المنشئات

| المنشئ | الوصف |
| :- | :- |
| [`__init__(self)`](/slides/python-net/ar/aspose.slides/texthighlightingoptions/__init__/#) | ينشئ خيارات تسليط الضوء على النص الافتراضية الجديدة. |

| الخاصية | الوصف |
| :- | :- |
| [`case_sensitive`](/slides/python-net/ar/aspose.slides/texthighlightingoptions/case_sensitive/) | اجعل القيمة true لاستخدام البحث حسّاس لحالة الأحرف، false - خلاف ذلك.<br/>            قراءة/كتابة **bool**. |
