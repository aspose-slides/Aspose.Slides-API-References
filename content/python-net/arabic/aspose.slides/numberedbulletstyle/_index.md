## تعداد NumberedBulletStyle

يمثل نمط القوائم المرقمة.

نوع NumberedBulletStyle يعرّف الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| NOT_DEFINED | غير معرّف. |
| BULLET_ALPHA_LC_PERIOD | أحرف أبجدية صغيرة مع نقطة. مثال: a., b., c., ... |
| BULLET_ALPHA_UC_PERIOD | أحرف أبجدية كبيرة مع نقطة. مثال: A., B., C., ... |
| BULLET_ARABIC_PAREN_RIGHT | أرقام عربية مع قوس إغلاق. مثال: 1), 2), 3), ... |
| BULLET_ARABIC_PERIOD | أرقام عربية مع نقطة. مثال: 1., 2., 3., ... |
| BULLET_ROMAN_LC_PAREN_BOTH | أرقام رومانية صغيرة مع قوسين. مثال: (i), (ii), (iii), ... |
| BULLET_ROMAN_LC_PAREN_RIGHT | أرقام رومانية صغيرة مع قوس إغلاق. مثال: i), ii), iii), ... |
| BULLET_ROMAN_LC_PERIOD | أرقام رومانية صغيرة مع نقطة. مثال: i., ii., iii., ... |
| BULLET_ROMAN_UC_PERIOD | أرقام رومانية كبيرة مع نقطة. مثال: I., II., III., ... |
| BULLET_ALPHA_LC_PAREN_BOTH | أحرف أبجدية صغيرة مع قوسين. مثال: (a), (b), (c), ... |
| BULLET_ALPHA_LC_PAREN_RIGHT | أحرف أبجدية صغيرة مع قوس إغلاق. مثال: a), b), c), ... |
| BULLET_ALPHA_UC_PAREN_BOTH | أحرف أبجدية كبيرة مع قوسين. مثال: (A), (B), (C), ... |
| BULLET_ALPHA_UC_PAREN_RIGHT | أحرف أبجدية كبيرة مع قوس إغلاق. مثال: A), B), C), ... |
| BULLET_ARABIC_PAREN_BOTH | أرقام عربية مع قوسين. مثال: (1), (2), (3), ... |
| BULLET_ARABIC_PLAIN | أرقام عربية. مثال: 1, 2, 3, ... |
| BULLET_ROMAN_UC_PAREN_BOTH | أرقام رومانية كبيرة مع قوسين. مثال: (I), (II), (III), ... |
| BULLET_ROMAN_UC_PAREN_RIGHT | أرقام رومانية كبيرة مع قوس إغلاق. مثال: I), II), III), ... |
| BULLET_SIMP_CHIN_PLAIN | الصينية المبسطة بدون نقطة. |
| BULLET_SIMP_CHIN_PERIOD | الصينية المبسطة مع نقطة. |
| BULLET_CIRCLE_NUM_DB_PLAIN | عدد محاط بدائرة مزدوجة للقيّم حتى 10، من 11 - أرقام عربية. |
| BULLET_CIRCLE_NUM_WD_WHITE_PLAIN | رقم ملون بالنص مع دائرة بنفس اللون حوله (أرقام دائرة بيضاء Wingdings). من 11 - أرقام عربية. |
| BULLET_CIRCLE_NUM_WD_BLACK_PLAIN | رقم لون الظل مع خلفية دائرية بلون النص العادي (أرقام دائرة سوداء Wingdings). |
| BULLET_TRAD_CHIN_PLAIN | الصينية التقليدية بدون نقطة. |
| BULLET_TRAD_CHIN_PERIOD | الصينية التقليدية مع نقطة. |
| BULLET_ARABIC_ALPHA_DASH | أحرف أبجدية عربية مع شرطة. |
| BULLET_ARABIC_ABJAD_DASH | أبجدية عربية مع شرطة. |
| BULLET_HEBREW_ALPHA_DASH | أحرف أبجدية عبرية مع شرطة. |
| BULLET_KANJI_KOREAN_PLAIN | أرقام يابانية/كورية بدون نقطة. |
| BULLET_KANJI_KOREAN_PERIOD | أرقام يابانية/كورية مع نقطة. |
| BULLET_ARABIC_DB_PLAIN | نظام ترقيم عربي مزدوج البايت (بدون علامات ترقيم). |
| BULLET_ARABIC_DB_PERIOD | نظام ترقيم عربي مزدوج البايت مع نقطة مزدوجة البايت. |
| BULLET_THAI_ALPHA_PERIOD | نقطة أبجدية تايلاندية. |
| BULLET_THAI_ALPHA_PAREN_RIGHT | قوس أبجدية تايلاندية - يمين. |
| BULLET_THAI_ALPHA_PAREN_BOTH | قوس أبجدية تايلاندية - كليهما. |
| BULLET_THAI_NUM_PERIOD | نقطة عدد تايلاندية. |
| BULLET_THAI_NUM_PAREN_RIGHT | قوس عدد تايلاندية - يمين. |
| BULLET_THAI_NUM_PAREN_BOTH | قوس عدد تايلاندية - كليهما. |
| BULLET_HINDI_ALPHA_PERIOD | نقطة أبجدية هندية - الحركات. |
| BULLET_HINDI_NUM_PERIOD | نقطة عدد هندية. |
| BULLET_KANJI_SIMP_CHIN_DB_PERIOD | كانجي صينية مبسطة DBPeriod. |
| BULLET_HINDI_NUM_PAREN_RIGHT | قوس عدد هندية - يمين. |
| BULLET_HINDI_ALPHA_1_PERIOD | نقطة أبجدية هندية - الحروف الساكنة. |
