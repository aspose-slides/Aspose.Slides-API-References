## تعداد PPImageFormat

تنسيقات الصور. هذا التعداد هو بديل لفئة `System.Drawing.Imaging.ImageFormat`. إنه مطلوب لتوافق COM.

يعرض نوع PPImageFormat الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| BMP | يحصل على تنسيق صورة bitmap (BMP). |
| EMF | يحصل على تنسيق صورة enhanced metafile (EMF). |
| EXIF | يحصل على تنسيق ملف الصورة القابل للتبادل (Exif). |
| GIF | يحصل على تنسيق صورة Graphics Interchange Format (GIF). |
| ICON | يحصل على تنسيق صورة أيقونة Windows. |
| JPEG | يحصل على تنسيق صورة Joint Photographic Experts Group (JPEG). |
| MEMORY_BMP | يحصل على تنسيق bitmap في الذاكرة. |
| PNG | يحصل على تنسيق صورة W3C Portable Network Graphics (PNG). |
| TIFF | يحصل على تنسيق صورة Tagged Image File Format (TIFF). |
| WMF | يحصل على تنسيق صورة Windows metafile (WMF). |
