## خاصية delete_embedded_binary_objects

أنواع الكائنات الثنائية المضمنة:

* مشروع VBA [`IPresentation.vba_project`](/slides/python-net/ar/aspose.slides/ipresentation/vba_project)
* بيانات OLE Object المضمنة [`IOleEmbeddedDataInfo.embedded_file_data`](/slides/python-net/ar/aspose.slides/ioleembeddeddatainfo/embedded_file_data)
* بيانات ActiveX Control الثنائية [`IControl.active_x_control_binary`](/slides/python-net/ar/aspose.slides/icontrol/active_x_control_binary)
