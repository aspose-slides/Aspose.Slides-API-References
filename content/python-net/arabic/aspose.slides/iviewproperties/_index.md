## IViewProperties الفئة

خصائص العرض على مستوى العرض التقديمي.

يعرض نوع IViewProperties الأعضاء التالية:

## الخصائص

| الخاصية | الوصف |
| :- | :- |
| [`last_view`](/slides/python-net/ar/aspose.slides/iviewproperties/last_view/) | يحدد وضع العرض الذي تم استخدامه عندما تم حفظ مستند العرض التقديمي آخر مرة.<br/>            قراءة/كتابة [`ViewType`](/slides/python-net/ar/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/ar/aspose.slides/iviewproperties/show_comments/) | يحدد ما إذا كان يجب إظهار تعليقات الشريحة.<br/>            قراءة/كتابة [`NullableBool`](/slides/python-net/ar/aspose.slides/nullablebool). |
| [`slide_view_properties`](/slides/python-net/ar/aspose.slides/iviewproperties/slide_view_properties/) | يحدد خصائص العرض العامة المرتبطة بوضع عرض الشريحة.<br/>            قراءة فقط [`ICommonSlideViewProperties`](/slides/python-net/ar/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/ar/aspose.slides/iviewproperties/notes_view_properties/) | يحدد خصائص العرض العامة المرتبطة بوضع عرض الملاحظات.<br/>            قراءة فقط [`ICommonSlideViewProperties`](/slides/python-net/ar/aspose.slides/icommonslideviewproperties). |
| [`normal_view_properties`](/slides/python-net/ar/aspose.slides/iviewproperties/normal_view_properties/) | يمثل خصائص العرض العادي. يتكون العرض العادي من<br/>            ثلاث مناطق محتوى: الشريحة نفسها، منطقة محتوى جانبية، ومنطقة محتوى سفلية.<br/>            قراءة فقط [`INormalViewProperties`](/slides/python-net/ar/aspose.slides/inormalviewproperties). |
| [`grid_spacing`](/slides/python-net/ar/aspose.slides/iviewproperties/grid_spacing/) | يعيد أو يحدد تباعد الشبكة الذي يجب استخدامه للشبكة الأساسية لمستند العرض التقديمي، بالنقاط.<br/>            قراءة/كتابة **float**. |
