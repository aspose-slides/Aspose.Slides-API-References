## فئة ViewProperties

خصائص العرض على مستوى العرض التقديمي.

نوع ViewProperties يكشف عن الأعضاء التالية:

## Properties

| خاصية | الوصف |
| :- | :- |
| [`last_view`](/slides/python-net/ar/aspose.slides/viewproperties/last_view/) | يحدد وضع العرض الذي تم استخدامه عندما تم حفظ مستند العرض التقديمي آخر مرة.<br/>            قراءة/كتابة [`ViewType`](/slides/python-net/ar/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/ar/aspose.slides/viewproperties/show_comments/) | يحدد ما إذا كان يجب إظهار تعليقات الشريحة.<br/>            قراءة/كتابة [`NullableBool`](/slides/python-net/ar/aspose.slides/nullablebool). |
| [`normal_view_properties`](/slides/python-net/ar/aspose.slides/viewproperties/normal_view_properties/) | يمثل خصائص العرض العادي. يتكون العرض العادي من<br/>            ثلاث مناطق محتوى: الشريحة نفسها، منطقة محتوى جانبية، ومنطقة محتوى سفلية.<br/>            قراءة فقط [`INormalViewProperties`](/slides/python-net/ar/aspose.slides/inormalviewproperties). |

| [`notes_view_properties`](/slides/python-net/ar/aspose.slides/viewproperties/notes_view_properties/) | يحدد خصائص العرض المشتركة المرتبطة بوضع عرض الملاحظات.<br/>            قراءة فقط [`ICommonSlideViewProperties`](/slides/python-net/ar/aspose.slides/icommonslideviewproperties). |
| [`grid_spacing`](/slides/python-net/ar/aspose.slides/viewproperties/grid_spacing/) | يرجع أو يضبط تباعد الشبكة الذي يجب استخدامه للشبكة الأساسية لمستند العرض التقديمي، بالنقاط. <br/>            قراءة/كتابة **float**. |
