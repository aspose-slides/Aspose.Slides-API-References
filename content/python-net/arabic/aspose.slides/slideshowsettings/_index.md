## SlideShowSettings فئة

يمثل إعدادات عرض الشرائح للعرض التقديمي.

نوع SlideShowSettings يكشف عن الأعضاء التالية:

## الخصائص

| خاصية | الوصف |
| :- | :- |
| [`slide_show_type`](/slides/python-net/ar/aspose.slides/slideshowsettings/slide_show_type/) | يحصل أو يضبط نوع عرض الشرائح. ممثلة بالأسلاف [`SlideShowSettings.slide_show_type`](/slides/python-net/ar/aspose.slides/slideshowsettings/slide_show_type) التالية: [`BrowsedAtKiosk`](/slides/python-net/ar/aspose.slides/browsedatkiosk)، [`PresentedBySpeaker`](/slides/python-net/ar/aspose.slides/presentedbyspeaker) و [`BrowsedByIndividual`](/slides/python-net/ar/aspose.slides/browsedbyindividual) |
| [`loop`](/slides/python-net/ar/aspose.slides/slideshowsettings/loop/) | تكرار عرض الشرائح |
| [`show_narration`](/slides/python-net/ar/aspose.slides/slideshowsettings/show_narration/) | إظهار السرد في عرض الشرائح |
| [`show_animation`](/slides/python-net/ar/aspose.slides/slideshowsettings/show_animation/) | إظهار الرسوم المتحركة في عرض الشرائح |
| [`pen_color`](/slides/python-net/ar/aspose.slides/slideshowsettings/pen_color/) | لون القلم لعرض الشرائح |
| [`slides`](/slides/python-net/ar/aspose.slides/slideshowsettings/slides/) | نطاق الشرائح |
| [`use_timings`](/ar/slides/python-net/aspose.slides/slideshowsettings/use_timings/) | استخدام التوقيتات في عرض الشرائح |
| [`show_media_controls`](/slides/python-net/ar/aspose.slides/slideshowsettings/show_media_controls/) | إظهار أدوات التحكم في الوسائط |
