## تعداد FillType

يحدد نوع التعبئة الداخلي للكائنات البصرية المختلفة.

نوع FillType يُظهر الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| NOT_DEFINED | نوع التعبئة غير معرف. |
| NO_FILL | لم يتم تطبيق تعبئة. |
| SOLID | مُعبأ بلون ثابت. |
| GRADIENT | التعبئة متدرجة. |
| PATTERN | نمط متكرر يُستخدم لتعبئة الكائن. |
| PICTURE | صورة واحدة تُستخدم لتعبئة الكائن. |
| GROUP | الكائن البصري يرث خصائص التعبئة من المجموعة. |
