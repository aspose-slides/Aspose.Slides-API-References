## IResourceLoadingArgs فئة

واجهة لوسائط تحميل الموارد الخارجية.

نوع IResourceLoadingArgs يعرض الأعضاء التالية:

## الخصائص

| الخاصية | الوصف |
| :- | :- |
| [`original_uri`](/slides/python-net/ar/aspose.slides/iresourceloadingargs/original_uri/) | URI الأصلي للمورد كما هو محدد في العرض التقديمي المستورد. |
| [`uri`](/slides/python-net/ar/aspose.slides/iresourceloadingargs/uri/) | URI للمورد الذي يُستخدم للتنزيل إذا **Aspose.Slides.IResourceLoadingCallback.ResourceLoading(Aspose.Slide** <br/>            returns [`ResourceLoadingAction.DEFAULT`](/slides/python-net/ar/aspose.slides/resourceloadingaction/DEFAULT). <br/>            في البداية يتم تعيينه إلى URI الأصلي للمورد، لكن يمكن إعادة تعريفه إلى أي قيمة. |
