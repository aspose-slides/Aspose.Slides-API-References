## BlackWhiteMode تعداد

يحدد كيفية تحويل الشكل الملون إلى أبيض وأسود.

يعرض نوع BlackWhiteMode الأعضاء التاليين:

## الحقول

| الحقل | الوصف |
| :- | :- |
| NOT_DEFINED | الخاصية غير محددة |
| COLOR | الكائن يُعرض بالألوان الطبيعية |
| AUTOMATIC | الكائن يُعرض بالألوان التلقائية |
| GRAY | الكائن يُعرض باللون الرمادي |
| LIGHT_GRAY | الكائن يُعرض باللون الرمادي الفاتح |
| INVERSE_GRAY | الكائن يُعرض باللون الرمادي المعكوس |
| GRAY_WHITE | الكائن يُعرض بالألوان الرمادي والأبيض |
| BLACK_GRAY | الكائن يُعرض بالألوان الأسود والرمادي |
| BLACK_WHITE | الكائن يُعرض بالألوان الأسود والأبيض |
| BLACK | الكائن يُعرض باللون الأسود فقط |
| WHITE | الكائن يُعرض باللون الأبيض |
| HIDDEN | الكائن غير معروض |
