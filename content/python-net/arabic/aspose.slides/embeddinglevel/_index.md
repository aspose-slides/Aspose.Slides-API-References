## تعداد EmbeddingLevel

Represents the licensing rights for embedding the font.

The EmbeddingLevel type exposes the following members:

## الحقول

| الحقل | الوصف |
| :- | :- |
| INSTALLABLE | الخطوط التي لديها هذا الإعداد تشير إلى إمكانية تضمينها وتثبيتها بشكل دائم على النظام البعيد بواسطة تطبيق. <br/>            يحصل مستخدم النظام البعيد على نفس الحقوق والالتزامات والتراخيص لهذا الخط كما للمشتري الأصلي للخط، <br/>            ويخضع لنفس اتفاقية ترخيص المستخدم النهائي، حقوق الطبع والنشر، براءة الاختراع التصميمية، و/أو العلامة التجارية كما كان المشتري الأصلي. |
| RESTRICTED | الخطوط التي تحتوي فقط على هذه العلامة لا يجوز تعديلها أو تضمينها أو تبادلها بأي طريقة دون الحصول أولاً على إذن المالك القانوني. |
| PREVIEW_PRINT | عند تعيين هذه العلامة، يمكن تضمين الخط وتحميله مؤقتًا على النظام البعيد. يجب فتح المستندات التي تحتوي على خطوط Preview & <br/>            Print في وضع "read-only;" لا يمكن إجراء تعديلات على المستند. |
| EDITABLE | عند تعيين هذه العلامة، يمكن تضمين الخط ولكن يجب تثبيته مؤقتًا فقط على الأنظمة الأخرى. بالمقارنة مع خطوط Preview & <br/>            Print، يمكن فتح المستندات التي تحتوي على خطوط Editable للقراءة، وتسمح بالتعديل، ويمكن حفظ التغييرات. |
| NO_SUBSETTING | عند تعيين هذه العلامة، لا يجوز تقليل الخط إلى مجموعة فرعية قبل التضمين. تنطبق أيضًا قيود التضمين الأخرى المحددة في العلامات 0-3 و9. |
| BITMAP_ONLY | عند تعيين هذه العلامة، يمكن فقط تضمين الصور النقطية الموجودة في الخط. لا يجوز تضمين بيانات المخطط. إذا لم تتوفر أي صور نقطية في الخط، <br/>            فإن الخط يُعتبر غير قابل للتضمين وستفشل خدمات التضمين. |
