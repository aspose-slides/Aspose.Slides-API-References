## ShapeAdjustmentType تعداد

يحدد أنواعًا مختلفة من قيم تعديل الشكل.

يعرض نوع ShapeAdjustmentType الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| CUSTOM | نوع مخصص (تعديل غير معروف) |
| CORNER_SIZE | يتحكم في حجم الزوايا. |
| LEFT_UP_CORNER | يتحكم في الزاوية العليا اليسرى. |
| RIGHT_UP_CORNER | يتحكم في الزاوية العليا اليمنى. |
| UP_CORNERS | يتحكم في الزوايا العلوية. |
| DOWN_CORNERS | يتحكم في الزوايا السفلية. |
| THICKNESS | يتحكم في سمك الشكل. |
| ARROW_TAIL_THICKNESS | يتحكم في سمك ذيل السهم. |
| ARROWHEAD_LENGTH | يتحكم في طول رأس السهم. |
| ARROWHEAD_WIDTH | يتحكم في عرض رأس السهم. |
| RADIUS | يتحكم في حجم نصف قطر الشكل أو جزئه. |
| DEPTH | يتحكم في عمق أسنان الترس أو تأثير التشطيب. |
| SHAPE_PART_OFFSET | يتحكم في إزاحة جزء من الشكل بالنسبة لجزء آخر. |
| ANGLE | يتحكم في الزاوية للشكل أو جزئه. |
| START_ANGLE | زاوية البداية للأشكال الدائرية والقوسية. |
| END_ANGLE | زاوية النهاية للأشكال الدائرية والقوسية. |
| START_POINT_X | يتحكم في موضع X لنقطة البداية للملصق. |
| START_POINT_Y | يتحكم في موضع Y لنقطة البداية للملصق. |
| CONNECTOR_POINT_1X | يتحكم في الموضع الأفقي لنقطة تعديل زاوية الملصق. |
| CONNECTOR_POINT_1Y | يتحكم في الموضع الرأسي لنقطة تعديل زاوية الملصق. |
| CONNECTOR_POINT_2X | يتحكم في الموضع الأفقي لنقطة تعديل زاوية الملصق. |
| CONNECTOR_POINT_2Y | يتحكم في الموضع الرأسي لنقطة تعديل زاوية الملصق. |
| CONNECTOR_BEND_POSITION_X | يتحكم في الموضع الأفقي للانحناء في الموصل. |
| CONNECTOR_BEND_POSITION_Y | يتحكم في الموضع الرأسي للانحناء في الموصل. |
| ATTACH_Y | يتحكم في نقطة التثبيت العمودية للشكل. |
| ATTACH_X | يتحكم في نقطة التثبيت الأفقية للشكل. |
| CALLOUT_HEIGHT | يتحكم في الحجم العمودي للملصق. |
| CALLOUT_WIDTH | يتحكم في الحجم الأفقي للملصق. |
| CALLOUT_SIZE | يتحكم في حجم الملصق. |
| CURVATURE | انحناء قطعة مرفوعة أو أقواس أو سهم منحني أو شكل. |
| HORIZONTAL_THICKNESS | يتحكم في السمك الأفقي لشكل الزاوية. |
| VERTICAL_THICKNESS | يتحكم في السمك العمودي لشكل الزاوية. |
| VERTICAL_SIZE | يتحكم في الحجم العمودي للشكل. |
| HORIZONTAL_SIZE | يتحكم في الحجم الأفقي للشكل. |
| TOP | يتحكم في الجانب العلوي للشكل. |
