## فئة IImage

يمثل صورة نقطية أو متجهة.

يُظهر نوع IImage الأعضاء التالية:

## الخصائص

| الخاصية | الوصف |
| :- | :- |
| [`size`](/slides/python-net/ar/aspose.slides/iimage/size/) | يرجع حجم الصورة. |
| [`width`](/slides/python-net/ar/aspose.slides/iimage/width/) | يرجع عرض الصورة بالبكسل. |
| [`height`](/slides/python-net/ar/aspose.slides/iimage/height/) | يرجع ارتفاع الصورة بالبكسل. |

## الطرق

| الطريقة | الوصف |
| :- | :- |
| [`save(self, filename)`](/slides/python-net/ar/aspose.slides/iimage/save/#str) | يحفظ الصورة إلى ملف. |
| [`save(self, filename, format)`](/slides/python-net/ar/aspose.slides/iimage/save/#str-imageformat) | يحفظ الصورة إلى ملف بالتنسيق المحدد. |
| [`save(self, stream, format)`](/slides/python-net/ar/aspose.slides/iimage/save/#iorawiobase-imageformat) | يحفظ الصورة إلى تدفق بالتنسيق المحدد. |
| [`save(self, filename, format, quality)`](/slides/python-net/ar/aspose.slides/iimage/save/#str-imageformat-int) | يحفظ الصورة إلى ملف بالتنسيق المحدد والجودة. |
| [`save(self, stream, format, quality)`](/slides/python-net/ar/aspose.slides/iimage/save/#iorawiobase-imageformat-int) | يحفظ الصورة إلى تدفق بالتنسيق المحدد والجودة. |


### ملاحظات

توفر هذه الواجهة تجريداً شائعاً للتعامل مع كل من الصور النقطية والمتجهة.  
قد تختلف تطبيقات الواجهة وفقًا لنوع الصورة الأساسي.
