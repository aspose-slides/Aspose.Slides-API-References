## IFillFormatEffectiveData الفئة

كائن غير قابل للتغيير يحتوي على خصائص تنسيق التعبئة الفعالة.

نوع IFillFormatEffectiveData يعرض الأعضاء التالية:

## الخصائص

| Property | Description |
| :- | :- |
| [`fill_type`](/slides/python-net/ar/aspose.slides/ifillformateffectivedata/fill_type/) | يعيد نوع التعبئة.<br/>            للقراءة فقط [`FillType`](/slides/python-net/ar/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/ar/aspose.slides/ifillformateffectivedata/solid_fill_color/) | يعيد لون التعبئة.<br/>            للقراءة فقط **aspose.slides.Color**. |
| [`solid_fill_scheme_color`](/slides/python-net/ar/aspose.slides/ifillformateffectivedata/solid_fill_scheme_color/) | يحصل على لون التعبئة المحدد بواسطة مخطط ألوان.<br/>            القيمة [`SchemeColor.NOT_DEFINED`](/slides/python-net/ar/aspose.slides/schemecolor/NOT_DEFINED) تشير إلى أن [`IFillFormatEffectiveData.solid_fill_color`](/slides/python-net/ar/aspose.slides/ifillformateffectivedata/solid_fill_color) <br/>            ليس لون مخطط.<br/>            للقراءة فقط [`SchemeColor`](/slides/python-net/ar/aspose.slides/schemecolor). |
| [`gradient_format`](/slides/python-net/ar/aspose.slides/ifillformateffectivedata/gradient_format/) | يعيد تنسيق تعبئة التدرج.<br/>            للقراءة فقط [`IGradientFormatEffectiveData`](/slides/python-net/ar/aspose.slides/igradientformateffectivedata). |
| [`pattern_format`](/slides/python-net/ar/aspose.slides/ifillformateffectivedata/pattern_format/) | يعيد تنسيق تعبئة النمط.<br/>            للقراءة فقط [`IPatternFormatEffectiveData`](/slides/python-net/ar/aspose.slides/ipatternformateffectivedata). |
| [`picture_fill_format`](/slides/python-net/ar/aspose.slides/ifillformateffectivedata/picture_fill_format/) | يعيد تنسيق تعبئة الصورة.<br/>            للقراءة فقط [`IPictureFillFormatEffectiveData`](/slides/python-net/ar/aspose.slides/ipicturefillformateffectivedata). |
| [`rotate_with_shape`](/slides/python-net/ar/aspose.slides/ifillformateffectivedata/rotate_with_shape/) | يحدد ما إذا كان يجب تدوير التعبئة مع الشكل.<br/>            للقراءة فقط **bool**. |

### ملاحظات

تُستخدم هذه الواجهة مع الواجهة [`IFillFormat`](/slides/python-net/ar/aspose.slides/ifillformat) لإرجاع قيم التنسيق الفعالة مع تطبيق الوراثة.
