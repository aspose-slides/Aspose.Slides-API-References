## IFillFormatEffectiveData فئة

كائن غير قابل للتغيير يحتوي على خصائص تنسيق التعبئة الفعّالة.

يعرض نوع IFillFormatEffectiveData الأعضاء التالية:

## الخصائص

| خاصية | الوصف |
| :- | :- |
| [`fill_type`](/slides/python-net/ar/aspose.slides/ifillformateffectivedata/fill_type/) | يعيد نوع التعبئة.<br/>            للقراءة فقط [`FillType`](/slides/python-net/ar/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/ar/aspose.slides/ifillformateffectivedata/solid_fill_color/) | يعيد لون التعبئة.<br/>            للقراءة فقط [`Color`](/slides/python-net/ar/aspose.slides/color). |
| [`solid_fill_scheme_color`](/slides/python-net/ar/aspose.slides/ifillformateffectivedata/solid_fill_scheme_color/) | يجلب لون التعبئة المحدد بواسطة نظام ألوان.<br/>            القيمة [`SchemeColor.NOT_DEFINED`](/slides/python-net/ar/aspose.slides/schemecolor/NOT_DEFINED) تشير إلى أن [`IFillFormatEffectiveData.solid_fill_color`](/slides/python-net/ar/aspose.slides/ifillformateffectivedata/solid_fill_color) <br/>            ليس لون نظام.<br/>            للقراءة فقط [`SchemeColor`](/slides/python-net/ar/aspose.slides/schemecolor). |
| [`gradient_format`](/slides/python-net/ar/aspose.slides/ifillformateffectivedata/gradient_format/) | يعيد تنسيق تعبئة التدرج.<br/>            للقراءة فقط [`IGradientFormatEffectiveData`](/slides/python-net/ar/aspose.slides/igradientformateffectivedata). |
| [`pattern_format`](/slides/python-net/ar/aspose.slides/ifillformateffectivedata/pattern_format/) | يعيد تنسيق تعبئة النمط.<br/>            للقراءة فقط [`IPatternFormatEffectiveData`](/slides/python-net/ar/aspose.slides/ipatternformateffectivedata). |
| [`picture_fill_format`](/slides/python-net/ar/aspose.slides/ifillformateffectivedata/picture_fill_format/) | يعيد تنسيق تعبئة الصورة.<br/>            للقراءة فقط [`IPictureFillFormatEffectiveData`](/slides/python-net/ar/aspose.slides/ipicturefillformateffectivedata). |
