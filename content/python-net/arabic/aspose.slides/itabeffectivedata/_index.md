## فئة ITabEffectiveData

نوع ITabEffectiveData يعرض الأعضاء التالية:

## الخصائص

| الخاصية | الوصف |
| :- | :- |
| [`position`](/slides/python-net/ar/aspose.slides/itabeffectivedata/position/) | يرجع موضع علامة الجدولة.<br/>            يمكن لتعيين هذه الخاصية تغيير فهرس العلامة في المجموعة وإبطال Enumerator.<br/>            قراءة فقط **float**. |
| [`alignment`](/slides/python-net/ar/aspose.slides/itabeffectivedata/alignment/) | يرجع نمط محاذاة علامة الجدولة.<br/>            قراءة فقط [`TabAlignment`](/slides/python-net/ar/aspose.slides/tabalignment). |
