## TextSearchOptions فئة

يمثل الخيارات التي يمكن استخدامها للبحث عن نص في Presentation أو Slide أو TextFrame.

يعرض نوع TextSearchOptions الأعضاء التالية:

## المنشئات

| المنصف | الوصف |
| :- | :- |
| [`__init__(self)`](/slides/python-net/ar/aspose.slides/textsearchoptions/__init__/#) | ينشئ خيارات بحث نص افتراضية جديدة. |

## الخصائص

| الخاصية | الوصف |
| :- | :- |
| [`case_sensitive`](/slides/python-net/ar/aspose.slides/textsearchoptions/case_sensitive/) | اجعل القيمة true لاستخدام بحث حساس لحالة الأحرف، false - خلاف ذلك.<br/>            قراءة/كتابة **bool**. |
| [`whole_words_only`](/slides/python-net/ar/aspose.slides/textsearchoptions/whole_words_only/) | اجعل القيمة true لمطابقة الكلمات الكاملة فقط، false - خلاف ذلك.<br/>            قراءة/كتابة **bool**. |
| [`include_notes`](/slides/python-net/ar/aspose.slides/textsearchoptions/include_notes/) | اجعل القيمة `true` لتضمين النص الموجود في ملاحظات الشريحة ([`NotesSlide`](/slides/python-net/ar/aspose.slides/notesslide)) <br/>            عند إجراء عمليات البحث عن النص أو الاستبدال أو التمييز.<br/>            القيمة الافتراضية هي `false`. |
