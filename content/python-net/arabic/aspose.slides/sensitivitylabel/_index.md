## فئة SensitivityLabel

يمثل علامة الحساسية من Microsoft Purview Information Protection.

يعرض نوع SensitivityLabel الأعضاء التالية:

## الخصائص

| الخاصية | الوصف |
| :- | :- |
| [`id`](/slides/python-net/ar/aspose.slides/sensitivitylabel/id/) | تُرجع أو تعين معرف علامة الحساسية.<br/>            قراءة/كتابة **str**. |
| [`site_id`](/slides/python-net/ar/aspose.slides/sensitivitylabel/site_id/) | تُرجع أو تعين معرّف موقع Azure Active Directory (Azure AD) المقابل لسياسة علامة الحساسية التي تصف علامة الحساسية.<br/>            قراءة/كتابة **System.Guid**. |
| [`is_enabled`](/slides/python-net/ar/aspose.slides/sensitivitylabel/is_enabled/) | يشير إلى ما إذا كانت علامة الحساسية مفعلة. |
| [`is_removed`](/slides/python-net/ar/aspose.slides/sensitivitylabel/is_removed/) | يشير إلى ما إذا تم إزالة علامة الحساسية. |
| [`assignment_method_type`](/slides/python-net/ar/aspose.slides/sensitivitylabel/assignment_method_type/) | تُرجع أو تعين طريقة التعيين لعلامة الحساسية.<br/>            قراءة/كتابة [`SensitivityLabelAssignmentType`](/slides/python-net/ar/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/ar/aspose.slides/sensitivitylabel/content_mark_types/) | تُرجع قائمة بأنواع تعليم المحتوى التي يجب تطبيقها على ملف. |
