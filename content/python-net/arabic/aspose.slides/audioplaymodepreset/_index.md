## تعداد AudioPlayModePreset

الثوابت التي تحدد كيفية تشغيل الصوت.

نوع AudioPlayModePreset يعرض الأعضاء التالية:

## الحقول

| Field | Description |
| :- | :- |
| MIXED |  |
| AUTO | تشغيل تلقائيًا. |
| ON_CLICK | تشغيل فقط عندما يُنقر على الأيقونة. |
| ALL_SLIDES | تشغيل على جميع الشرائح.<br/>            يرجى استخدام خاصية [`IAudioFrame.play_across_slides`](/slides/python-net/ar/aspose.slides/iaudioframe/play_across_slides) بدلاً من ذلك.<br/>            هذا العنصر غير محدث منذ PowerPoint 2013. |
| IN_CLICK_SEQUENCE | تشغيل تلقائيًا مع نقرة. |
