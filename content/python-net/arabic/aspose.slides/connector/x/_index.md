## خاصية x
تحصل أو تعين إحداثي x لزاوية الشكل العليا اليسرى، مقاسًا بالنقاط.
            قراءة/كتابة **float**.


### ملاحظات

القيمة التي يتم إرجاعها تكون دائمًا معرفة ولا تكون أبدًا **float**.
            يجب أن تكون القيمة المعينة أيضًا معرفة؛ عيّن **float** فقط إلى خصائص كائن `RawFrame` instance.

### التعريف:

@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
