## تعداد ColorTransformOperation

يعرف عملية تحويل اللون.

يعرض نوع ColorTransformOperation الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| TINT | يضيف صبغة للون. المعامل في النطاق بين 0 (اللون الأصلي) و 1 (أبيض). |
| SHADE | يضيف ظل للون. المعامل في النطاق بين 0 (اللون الأصلي) و 1 (أسود). |
| COMPLEMENT | يغيّر اللون إلى مكمل RGB.<br/>            m = Max(r, g, b);<br/>            r = m - r;<br/>            g = m - g;<br/>            b = m - b; |
| INVERSE | يغيّر اللون إلى لون معكوس.<br/>            r = 1 - r;<br/>            g = 1 - g;<br/>            b = 1 - b; |
| GRAYSCALE | يغيّر اللون إلى اللون الرمادي بنفس السطوع. يتم تجاهل المعامل. |
| SET_ALPHA | يحدد مكوّن ألفا للون. المعامل في النطاق بين 0 (شفاف) و 1 (معتم). |
| ADD_ALPHA | يضيف قيمة المعامل إلى مكوّن ألفا للون. المعامل في النطاق بين -1 و 1. |
| MULTIPLY_ALPHA | يضرب مكوّن ألفا في قيمة المعامل. |
| SET_HUE | يغيّر مكوّن الصبغة للون إلى قيمة المعامل. المعامل في النطاق بين 0 و 360. |
| ADD_HUE | يضيف قيمة المعامل إلى مكوّن الصبغة للون. المعامل في النطاق بين -360 و 360. |
| MULTIPLY_HUE | يضرب مكوّن الصبغة في قيمة المعامل. |
| SET_SATURATION | يغيّر مكوّن التشبع للون إلى قيمة المعامل. المعامل في النطاق بين 0 و 1. |
| ADD_SATURATION | يضيف قيمة المعامل إلى مكوّن التشبع للون. المعامل في النطاق بين -1 و 1. |
| MULTIPLY_SATURATION | يضرب مكوّن التشبع في قيمة المعامل. |
| SET_LUMINANCE | يغيّر مكوّن الإضاءة للون إلى قيمة المعامل. المعامل في النطاق بين 0 و 1. |
| ADD_LUMINANCE | يضيف قيمة المعامل إلى مكوّن الإضاءة للون. المعامل في النطاق بين -1 و 1. |
| MULTIPLY_LUMINANCE | يضرب مكوّن الإضاءة في قيمة المعامل. |
| SET_RED | يغيّر المكوّن الأحمر للون إلى قيمة المعامل. المعامل في النطاق بين 0 و 1. |
| ADD_RED | يضيف قيمة المعامل إلى المكوّن الأحمر للون. المعامل في النطاق بين -1 و 1. |
| MULTIPLY_RED | يضرب المكوّن الأحمر في المعامل. |
| SET_GREEN | يغيّر المكوّن الأخضر للون إلى قيمة المعامل. المعامل في النطاق بين 0 و 1. |
| ADD_GREEN | يضيف المعامل إلى المكوّن الأخضر للون. المعامل في النطاق بين -1 و 1. |
| MULTIPLY_GREEN | يضرب المكوّن الأخضر في قيمة المعامل. |
| SET_BLUE | يغيّر المكوّن الأزرق للون إلى قيمة المعامل. المعامل في النطاق بين 0 و 360. |
| ADD_BLUE | يضيف قيمة المعامل إلى المكوّن الأزرق للون. المعامل في النطاق بين -1 و 1. |
| MULTIPLY_BLUE | يضرب المكوّن الأزرق في قيمة المعامل. |
| GAMMA | تصحيح غاما. يتم تجاهل المعامل. |
| INVERSE_GAMMA | تصحيح غاما عكسي. يتم تجاهل المعامل. |
