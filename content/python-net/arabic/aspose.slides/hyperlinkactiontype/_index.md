## تعداد HyperlinkActionType

يمثل نوعًا من إجراء الارتباط التشعيبي.

نوع HyperlinkActionType يعرّف الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| UNKNOWN | نوع الإجراء غير معروف. |
| NO_ACTION | بدون إجراء. |
| HYPERLINK | ارتباط تشعبي عادي. |
| JUMP_FIRST_SLIDE | الانتقال إلى الشريحة الأولى من العرض. |
| JUMP_PREVIOUS_SLIDE | الانتقال إلى الشريحة السابقة. |
| JUMP_NEXT_SLIDE | الانتقال إلى الشريحة التالية. |
| JUMP_LAST_SLIDE | الانتقال إلى الشريحة الأخيرة من العرض. |
| JUMP_END_SHOW | الانتقال إلى نهاية العرض الشرائحي. |
| JUMP_LAST_VIEWED_SLIDE | الانتقال إلى الشريحة التي تمت مشاهدتها آخرًا. |
| JUMP_SPECIFIC_SLIDE | الانتقال إلى شريحة محددة، المشار إليها بخصيصة [`IHyperlink.target_slide`](/slides/python-net/ar/aspose.slides/ihyperlink/target_slide). |
| START_CUSTOM_SLIDE_SHOW | بدء عرض شرائح مخصص. |
| OPEN_FILE | فتح الملف المشار إليه. |
| OPEN_PRESENTATION | فتح العرض التقديمي المشار إليه. |
| START_STOP_MEDIA | بدء/إيقاف تشغيل ملف الوسائط. |
| START_MACRO | بدء تنفيذ سكريبت الماكرو. |
| START_PROGRAM | بدء البرنامج. |
