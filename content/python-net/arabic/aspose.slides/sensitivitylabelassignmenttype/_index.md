## SensitivityLabelAssignmentType تعداد

يمثل طريقة تعيين تسمية الحساسية.

نوع SensitivityLabelAssignmentType يعرض الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| STANDARD | استخدم لأي تسمية حساسية لم يتم تطبيقها مباشرةً من قبل المستخدم. <br/>            يشمل ذلك أي تسميات افتراضية، تسميات مطبقة تلقائيًا. |
| PRIVILEGED | استخدم لأي تسمية حساسية تم تطبيقها مباشرةً من قبل المستخدم. <br/>            يشمل ذلك أي تسميات حساسية تم تطبيقها يدويًا بالإضافة إلى التسمية الموصى بها<br/>            أو الإلزامية أو أي ميزة يقرر فيها المستخدم أي تسمية حساسية يجب تطبيقها. |
