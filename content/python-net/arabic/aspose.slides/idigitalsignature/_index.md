## IDigitalSignature فئة

التوقيع الرقمي في ملف موقّع.

نوع IDigitalSignature يكشف عن الأعضاء التالية:

## الخصائص

| الخاصية | الوصف |
| :- | :- |
| [`certificate`](/slides/python-net/ar/aspose.slides/idigitalsignature/certificate/) | كائن الشهادة الذي تم استخدامه لتوقيع المستند.<br/>            قراءة فقط **System.Security.Cryptography.X509Certificates.X509Certificate2**. |
| [`is_valid`](/slides/python-net/ar/aspose.slides/idigitalsignature/is_valid/) | إذا كان هذا التوقيع الرقمي صالحًا ولم يتم العبث بالمستند، فإن هذه القيمة ستكون true.<br/>            قراءة فقط **bool**. |
| [`sign_time`](/slides/python-net/ar/aspose.slides/idigitalsignature/sign_time/) | الوقت الذي تم فيه توقيع المستند.<br/>            قراءة فقط **System.DateTime**. |
| [`comments`](/slides/python-net/ar/aspose.slides/idigitalsignature/comments/) | غرض التوقيع.<br/>            قراءة/كتابة **str**. |
