## خاصية x
يحصل أو يعيّن إحداثي x للزاوية العليا اليسرى للشكل، مقاسًا بالنقاط.
قراءة/كتابة **float**.

### ملاحظات

القيمة المُرجعة دائمًا معرفة ولا تكون أبداً **float**.
يجب أن تكون القيمة المعينّة أيضًا معرفة؛ عيّن **float** فقط لخصائص كائن `RawFrame`.

### التعريف:

@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
