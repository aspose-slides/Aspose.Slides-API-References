## تعداد LoadFormat

يشير إلى تنسيق المستند الذي سيُحمَّل.

يعرض نوع LoadFormat الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| AUTO | يُعطي Aspose.Slides أمرًا بالتعرف على التنسيق تلقائيًا. |
| PPT | Microsoft PowerPoint 97-2003 عرض تقديمي. |
| PPS | Microsoft PowerPoint 97-2003 عرض شرائح. |
| PPTX | Microsoft Office Open XML PresentationML مستند. |
| PPSX | Microsoft Office Open XML PresentationML عرض شرائح. |
| ODP | OpenOffice ODF عرض تقديمي. |
| POTX | Microsoft Office Open XML PresentationML قالب. |
| PPTM | Microsoft Office Open XML PresentationML مستند يدعم وحدات الماكرو. |
| PPSM | Microsoft Office Open XML PresentationML عرض شرائح يدعم وحدات الماكرو. |
| POTM | Microsoft Office Open XML PresentationML قالب يدعم وحدات الماكرو. |
| OTP | OpenOffice OTP قالب عرض تقديمي. |
| PPT95 | Microsoft PowerPoint 95 عرض تقديمي. |
| POT | Microsoft PowerPoint 97-2003 قالب عرض تقديمي. |
| FODP | Flat XML ODF عرض تقديمي. |
| UNKNOWN | تنسيق ملف غير معروف |
