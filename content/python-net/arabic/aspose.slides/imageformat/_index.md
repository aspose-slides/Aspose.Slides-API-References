## تعداد ImageFormat

يمثل تنسيق ملف الصورة.

يعرض نوع ImageFormat الأعضاء التالية:

## الحقول

| الحقل | الوصف |
| :- | :- |
| MEMORY_BMP | يمثل تنسيق صورة نقطية في الذاكرة. |
| BMP | يمثل تنسيق صورة bitmap (BMP). |
| EMF | يمثل تنسيق ملف الميتا المحسن (EMF). |
| WMF | يمثل تنسيق ملف الميتا لـ Windows (WMF). |
| GIF | يمثل تنسيق Graphics Interchange Format (GIF). |
| JPEG | يمثل تنسيق Joint Photographic Experts Group (JPEG). |
| PNG | يمثل تنسيق W3C Portable Network Graphics (PNG). |
| TIFF | يمثل تنسيق Tagged Image File Format (TIFF). |
| EXIF | يمثل تنسيق Exchangeable Image File (Exif). |
| ICON | يمثل تنسيق أيقونة Windows. |
