## x خاصية
الحصول على قيمة أو تعيين الإحداثي x للزاوية العلوية اليسرى للشكل، ويقاس بالنقاط.
            قراءة/كتابة **float**.


### ملاحظات

القيمة المرتجعة دائمًا معرفة ولا تكون **float** أبداً.
            يجب أن تكون القيمة المعينة أيضًا معرفة؛ عيّن **float** فقط للخصائص الخاصة بـ `RawFrame` instance.

### التعريف:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
