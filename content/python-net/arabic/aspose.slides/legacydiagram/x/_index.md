## خاصية x
يحصل أو يضبط إحداثي x للزاوية العليا اليسرى للشكل، مقاسًا بالنقاط.
            قراءة/كتابة **float**.


### ملاحظات

القيمة المرتجعة تكون دائمًا معرفة ولا تكون أبدًا **float**.
            القيمة المعينة يجب أن تكون أيضًا معرفة؛ عيّن **float** فقط للخصائص الخاصة بـ `RawFrame`.

def x(self):
    ...

@x.setter

    ...
