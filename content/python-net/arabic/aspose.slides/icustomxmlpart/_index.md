## ICustomXmlPart فئة

يمثل جزء XML مخصص.

نوع ICustomXmlPart يُظهر الأعضاء التالية:

## الخصائص

| الخاصية | الوصف |
| :- | :- |
| [`xml_as_string`](/slides/python-net/ar/aspose.slides/icustomxmlpart/xml_as_string/) | يرجع أو يعيّن بيانات xml كسلسلة UTF-8.<br/>            قراءة/كتابة **str**.<br/>            القيمة هي `None`.القيمة فارغة أو بيانات xml غير صالحة. |
| [`xml_data`](/slides/python-net/ar/aspose.slides/icustomxmlpart/xml_data/) | يرجع أو يعيّن بيانات xml.<br/>            قراءة/كتابة **int**[].<br/>            القيمة هي `None`.القيمة فارغة أو بيانات xml غير صالحة. |
| [`item_id`](/slides/python-net/ar/aspose.slides/icustomxmlpart/item_id/) | يحدد معرّفًا فريدًا عالميًا (GUID) يميّز جزء XML مخصص واحد داخل مستند Office Open XML.<br/>            قراءة فقط **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/ar/aspose.slides/icustomxmlpart/namespace_schemas/) | يرجع مجموعة مخططات XML المرتبطة بجزء XML المخصص.<br/>            قراءة فقط **str**[]. |
