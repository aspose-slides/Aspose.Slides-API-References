## ITextSearchOptions فئة

يمثل الخيارات التي يمكن استخدامها للبحث عن النص في Presentation أو Slide أو TextFrame.

يعرض نوع ITextSearchOptions الأعضاء التالية:

## الخصائص

| الخاصية | الوصف |
| :- | :- |
| [`case_sensitive`](/slides/python-net/ar/aspose.slides/itextsearchoptions/case_sensitive/) | ضبط true لاستخدام البحث حسّاس لحالة الأحرف، false - خلاف ذلك.<br/>            قراءة/كتابة **bool**. |
| [`whole_words_only`](/slides/python-net/ar/aspose.slides/itextsearchoptions/whole_words_only/) | ضبط true لمطابقة الكلمات الكاملة فقط، false - خلاف ذلك.<br/>            قراءة/كتابة **bool**. |
| [`include_notes`](/slides/python-net/ar/aspose.slides/itextsearchoptions/include_notes/) | ضبط `true` لتضمين النص الموجود في ملاحظات الشريحة <br/>            عند إجراء عمليات البحث عن النص أو الاستبدال أو التمييز.<br/>            القيمة الافتراضية هي `false`. |
