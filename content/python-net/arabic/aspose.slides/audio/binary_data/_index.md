## binary_data خاصية
Returns the copy of an audio's data. In case of large amount of data consider 
            using of [`Audio.get_stream`](/slides/python-net/ar/aspose.slides/audio/get_stream) method to prevent unnecessary  loading of audio's
            data into memory or even OutOfMemoryException.
            للقراءة فقط **int**[].
