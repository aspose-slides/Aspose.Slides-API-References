## ICameraEffectiveData الفئة

كائن ثابت لا يمكن تعديله يحتوي على خصائص الكاميرا الفعالة.

يعرض نوع ICameraEffectiveData الأعضاء التالية:

## الخصائص

| الخاصية | الوصف |
| :- | :- |
| [`camera_type`](/slides/python-net/ar/aspose.slides/icameraeffectivedata/camera_type/) | نوع الكاميرا.<br/>            للقراءة فقط [`CameraPresetType`](/slides/python-net/ar/aspose.slides/camerapresettype). |
| [`field_of_view_angle`](/slides/python-net/ar/aspose.slides/icameraeffectivedata/field_of_view_angle/) | مجال رؤية الكاميرا (0-180 درجة، مجال الرؤية).<br/>            للقراءة فقط **float**. |
| [`zoom`](/slides/python-net/ar/aspose.slides/icameraeffectivedata/zoom/) | تكبير الكاميرا (قيمة موجبة بالنسبة المئوية).<br/>            للقراءة فقط **float**. |

## الطرق

| الطريقة | الوصف |
| :- | :- |
| [`get_rotation(self)`](/slides/python-net/ar/aspose.slides/icameraeffectivedata/get_rotation/#) | يتم تعريف دوران من خلال استخدام إحداثي خط عرض<br/>            وإحداثي خط طول، وثورة حول المحور <br/>            كما إحداثيات خط العرض وخط الطول.<br/>            العنصر الأول في مصفوفة الإرجاع - خط العرض، الثاني - خط الطول، الثالث - الثورة.<br/>            تُرجع None إذا لم يتم تعريف دوران. |
