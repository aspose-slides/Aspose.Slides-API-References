## InterruptionToken فئة

تمثل هذه الفئة الرمز الذي يُستخدم للإشارة إلى ما إذا تم طلب الانقطاع للمهام طويلة التنفيذ.

يعرض نوع InterruptionToken الأعضاء التالية:

## الخصائص

| خاصية | الوصف |
| :- | :- |
| [`none`](/slides/python-net/ar/aspose.slides/interruptiontoken/none/) | يمثل رمز انقطاع فارغ.<br/>            لن تُقاطع عمليات طويلة التنفيذ عبر [`InterruptionTokenSource.interrupt`](/slides/python-net/ar/aspose.slides/interruptiontokensource/interrupt)<br/>            عند استخدام هذا الرمز. |
| [`is_interruption_requested`](/slides/python-net/ar/aspose.slides/interruptiontoken/is_interruption_requested/) | تُرجِع **bool**.true إذا تم طلب الانقطاع. |

## الطرق

| طريقة | الوصف |
| :- | :- |
| [`throw_if_interruption_requested(self)`](/slides/python-net/ar/aspose.slides/interruptiontoken/throw_if_interruption_requested/#) | يرمي OperationCanceledException إذا<br/>            تم طلب الانقطاع. |
