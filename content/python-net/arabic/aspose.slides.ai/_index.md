| الفئة | الوصف |
| :- | :- |

| [`OpenAIWebClient`](/slides/python-net/ar/aspose.slides.ai/openaiwebclient/) | تنفيذ مدمج [`IAIWebClient`](/slides/python-net/ar/aspose.slides.ai/iaiwebclient) يتصل بواجهة برمجة تطبيقات OpenAI. |
| [`SlidesAIAgent`](/slides/python-net/ar/aspose.slides.ai/slidesaiagent/) | يوفر ميزات مدعومة بالذكاء الاصطناعي لمعالجة العروض التقديمية. |
| [`SlidesAIAgentException`](/slides/python-net/ar/aspose.slides.ai/slidesaiagentexception/) | يمثل الاستثناءات المتعلقة بـ Slides AI Agent. |
