## WarningType-enum

Representerar en typ av varning.

WarningType-typen exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| SOURCE_FILE_CORRUPTION | Ett problem har upptäckts i källdokumentet vilket gör det mycket sannolikt att dokumentet inte kan öppnas om det sparas i sitt ursprungliga format. |
| DATA_LOSS | Text/diagram/bild eller annan data kommer att saknas helt från antingen dokumentträdet efter inläsning, eller det skapade dokumentet efter sparning. |
| MAJOR_FORMATTING_LOSS | Större formatförlust. |
| MINOR_FORMATTING_LOSS | Mindre formatförlust. |
| COMPATIBILITY_ISSUE | Detta är ett känt problem som hindrar dokumentet från att öppnas av vissa användaragenter eller tidigare versioner av användaragenter. |
| UNEXPECTED_CONTENT | Viss innehåll i källdokumentet kunde inte kännas igen (dvs. stöds inte), detta kan eventuellt orsaka problem eller leda till data-/formatförlust. |
