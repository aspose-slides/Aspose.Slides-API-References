Innehåller klasser som representerar olika typer av varningar
## Klasser

| Klass | Beskrivning |
| :- | :- |
| [`IKnownIssueWarningInfo`](/slides/python-net/sv/aspose.slides.warnings/iknownissuewarninginfo/) | Representerar en varning om ett känt problem som inte kommer att åtgärdas inom den närmaste framtiden. |
| [`INotImplementedWarningInfo`](/slides/python-net/sv/aspose.slides.warnings/inotimplementedwarninginfo/) | Representerar en varning om en känd icke implementerad funktion som inte kommer att implementeras inom den närmaste framtiden. |
| [`IObsoletePresLockingBehaviorWarningInfo`](/slides/python-net/sv/aspose.slides.warnings/iobsoletepreslockingbehaviorwarninginfo/) | Denna varning indikerar att ett föråldrat låsningsbeteende för presentationen används. |
| [`IPresentationSignedWarningInfo`](/slides/python-net/sv/aspose.slides.warnings/ipresentationsignedwarninginfo/) | Denna varning indikerar att den lästa presentationen har signaturen <br/>            och att denna signatur kommer att tas bort under bearbetning. |
| [`IWarningCallback`](/slides/python-net/sv/aspose.slides.warnings/iwarningcallback/) | Gränssnitt för klasser som tar emot varning |
| [`IWarningInfo`](/slides/python-net/sv/aspose.slides.warnings/iwarninginfo/) | Representerar ett basgränssnitt för alla varningar. |
