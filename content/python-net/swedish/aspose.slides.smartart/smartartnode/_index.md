## SmartArtNode klass

Representerar en nod i ett SmartArt-objekt

SmartArtNode-typen exponerar följande medlemmar:

## Egenskaper

| Property | Description |
| :- | :- |
| [`child_nodes`](/slides/python-net/sv/aspose.slides.smartart/smartartnode/child_nodes/) | Returnerar samlingar av alla underordnade noder till den aktuella noden.<br/>            Skrivskyddad [`ISmartArtNodeCollection`](/slides/python-net/sv/aspose.slides.smartart/ismartartnodecollection). |
| [`shapes`](/slides/python-net/sv/aspose.slides.smartart/smartartnode/shapes/) | Returnerar samlingar av alla former som är associerade med noden.<br/>            Skrivskyddad [`ISmartArtShapeCollection`](/slides/python-net/sv/aspose.slides.smartart/ismartartshapecollection). |
| [`text_frame`](/slides/python-net/sv/aspose.slides.smartart/smartartnode/text_frame/) | Returnerar textramen för noden.<br/>            Skrivskyddad [`ITextFrame`](/slides/python-net/sv/aspose.slides/itextframe). |
| [`is_assistant`](/slides/python-net/sv/aspose.slides.smartart/smartartnode/is_assistant/) | Returnerar eller anger noden som assistent.<br/>            Läs/skriv **bool**. |
| [`level`](/slides/python-net/sv/aspose.slides.smartart/smartartnode/level/) | Returnerar nästlingsnivån för noden.<br/>            Skrivskyddad **int**. |
| [`bullet_fill_format`](/slides/python-net/sv/aspose.slides.smartart/smartartnode/bullet_fill_format/) | Returnerar FillFormat-objektet som innehåller fyllningsformateringsegenskaper för en nodpunkt.<br/>            Obs: kan returnera None för vissa typer av SmartArt-layout som inte tillhandahåller punkter för noder.<br/>            Skrivskyddad [`IFillFormat`](/slides/python-net/sv/aspose.slides/ifillformat). |
| [`position`](/slides/python-net/sv/aspose.slides.smartart/smartartnode/position/) | Returnerar eller anger nollbaserad position för noden bland syskonnoder.<br/>            Läs/skriv **int**. |
| [`is_hidden`](/slides/python-net/sv/aspose.slides.smartart/smartartnode/is_hidden/) | Returnerar true om denna nod är en dold nod i datamodellen.<br/>            Skrivskyddad **bool**. |
| [`organization_chart_layout`](/slides/python-net/sv/aspose.slides.smartart/smartartnode/organization_chart_layout/) | Returnerar eller anger organisationdiagrammets layouttyp som är associerad med den aktuella noden.<br/>            Läs/skriv [`OrganizationChartLayoutType`](/slides/python-net/sv/aspose.slides.smartart/organizationchartlayouttype). |
