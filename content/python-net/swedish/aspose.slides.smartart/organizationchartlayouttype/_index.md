## OrganizationChartLayoutType enum

Representerar formateringstypen för undernoderna i ett organisationsdiagram

Typen OrganizationChartLayoutType exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| INITIAL | Initial layouttyp |
| STANDART | Placera undernoder horisontellt under föräldernoden. |
| BOTH_HANGING | Placera undernoder vertikalt under föräldernoden på både vänster och höger sida. |
| LEFT_HANGING | Placera undernoder vertikalt under föräldernoden på vänster sida. |
| RIGHT_HANGING | Placera undernoder vertikalt under föräldernoden på höger sida. |
