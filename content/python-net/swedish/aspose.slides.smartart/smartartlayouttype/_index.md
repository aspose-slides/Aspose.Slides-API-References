## SmartArtLayoutType enumeration

Representerar layouttyp för ett SmartArt-diagram.

Typen SmartArtLayoutType exponerar följande medlemmar:

## Fält

| Field | Description |
| :- | :- |
| ACCENT_PROCESS | Använd för att visa en progression, en tidslinje eller sekventiella steg i en uppgift, process eller arbetsflöde. Fungerar bra för att illustrera både nivå 1 och nivå 2 text. |
| ACCENTED_PICTURE | Använd för att visa en central, fotografisk idé med relaterade idéer på sidan. Den övre nivå 1-texten visas över den centrala bilden. Motsvarande text för andra nivå 1-former visas bredvid de små cirkulära bilderna. Denna layout fungerar också bra utan text. |
| ALTERNATING_FLOW | Använd för att visa grupper av information eller sekventiella steg i en uppgift, process eller arbetsflöde. Betonar interaktionen eller relationerna mellan informationsgrupperna. |
| ALTERNATING_HEXAGONS | Använd för att representera en serie av sammanlänkade idéer. Nivå 1-text visas inuti hexagonalerna. Nivå 2-text visas utanför formerna. |
| ALTERNATING_PICTURE_BLOCKS | Använd för att visa en serie av bilder från toppen till botten. Text visas växlande till höger eller vänster om bilden. |
| ALTERNATING_PICTURE_CIRCLES | Använd för att visa en uppsättning bilder med text. Den motsvarande texten visas i de centrala cirklarna med bilderna växlande från vänster till höger. |
| ARROW_RIBBON | Använd för att visa antingen relaterade eller kontrasterande begrepp med någon koppling, till exempel motsatta krafter. De två första raderna av nivå 1-text används för text i pilarna. Oanvänd text visas inte, men förblir tillgänglig om du byter layout. |
| ASCENDING_PICTURE_ACCENT_PROCESS | Använd för att visa en stigande serie av bilder med beskrivande text. Fungerar bäst med en liten mängd text. |
| BALANCE | Använd för att jämföra eller visa relationen mellan två idéer. Varje av de två första raderna av nivå 1-text motsvarar text högst upp på en sida av mittpunkten. Betonar nivå 2-text, som är begränsad till fyra former på varje sida av mittpunkten. Balansen tippar mot den sida som har flest former som innehåller nivå 2-text. Oanvänd text visas inte, men förblir tillgänglig om du byter layout. |
| BASIC_BENDING_PROCESS | Använd för att visa en progression eller sekventiella steg i en uppgift, process eller arbetsflöde. Maximerar både horisontellt och vertikalt utrymme för former. |
| BASIC_BLOCK_LIST | Använd för att visa icke-sekventiella eller grupperade informationsblock. Maximerar både horisontellt och vertikalt utrymme för former. |
| BASIC_CHEVRON_PROCESS | Använd för att visa en progression; en tidslinje; sekventiella steg i en uppgift, process eller arbetsflöde; eller för att betona rörelse eller riktning. Nivå 1-text visas inuti en pilform medan nivå 2-text visas under pilformerna. |
| BASIC_CYCLE | Använd för att representera en fortsättande sekvens av steg, uppgifter eller händelser i ett cirkulärt flöde. Betonar stegen snarare än de sammankopplande pilarna eller flödet. Fungerar bäst med endast nivå 1-text. |
| BASIC_MATRIX | Använd för att visa förhållandet mellan komponenter och en helhet i kvadranter. De fyra första raderna av nivå 1-text visas i kvadranterna. Oanvänd text visas inte, men förblir tillgänglig om du byter layout. |
| BASIC_PIE | Använd för att visa hur enskilda delar bildar en helhet. De sju första raderna av nivå 1-text motsvarar de jämnt fördelade klyft- eller pajformerna. Den övre nivå 1-textformen visas utanför resten av pajen för att betona. Oanvänd text visas inte, men förblir tillgänglig om du byter layout. |
| BASIC_PROCESS | Använd för att visa en progression eller sekventiella steg i en uppgift, process eller arbetsflöde. |
| BASIC_PYRAMID | Använd för att visa proportionella, sammanlänkade eller hierarkiska relationer med den största komponenten längst ner och smalnande uppåt. Nivå 1-text visas i pyramidsegmenten och nivå 2-text visas i former bredvid varje segment. |
| BASIC_RADIAL | Använd för att visa förhållandet till en central idé i en cykel. Den första raden av nivå 1-text motsvarar den centrala formen, och dess nivå 2-text motsvarar de omgivande cirkulära formerna. Oanvänd text visas inte, men förblir tillgänglig om du byter layout. |
| BASIC_TARGET | Använd för att visa inneslutning, graderingar eller hierarkiska relationer. De fem första raderna av nivå 1-text är kopplade till en cirkel. Oanvänd text visas inte, men förblir tillgänglig om du byter layout. |
| BASIC_TIMELINE | Använd för att visa sekventiella steg i en uppgift, process eller arbetsflöde, eller för att visa tidslinjeinformation. Fungerar bra med både nivå 1- och nivå 2-text. |
| BASIC_VENN | Använd för att visa överlappande eller sammanlänkade relationer. De sju första raderna av nivå 1-text motsvarar en cirkel. Om det finns fyra eller färre rader av nivå 1-text är texten inne i cirklarna. Om det finns mer än fyra rader av nivå 1-text är texten utanför cirklarna. Oanvänd text visas inte, men förblir tillgänglig om du byter layout. |
| BENDING_PICTURE_ACCENT_LIST | Använd för att visa icke-sekventiella eller grupperade informationsblock. De små cirkulära formerna är avsedda att innehålla bilder. Fungerar bra för att illustrera både nivå 1- och nivå 2-text. Maximerar både horisontellt och vertikalt utrymme för former. |
| BENDING_PICTURE_BLOCKS | Använd för att visa en serie av bilder. Rutan som täcker det nedre hörnet kan innehålla små mängder text. |
| BENDING_PICTURE_CAPTION | Använd för att visa en sekventiell serie av bilder. Rutan som täcker det nedre hörnet kan innehålla små mängder text. |
| BENDING_PICTURE_CAPTION_LIST | Använd för att visa en serie av bilder. Titel och beskrivning visas i en anropsform under varje bild. |
| BENDING_PICTURE_SEMI_TRANSPARENT_TEXT | Använd för att visa en serie av bilder. En halvtransparent ruta täcker den nedre delen av bilden och innehåller all text på alla nivåer. |
| BLOCK_CYCLE | Använd för att representera en fortsättande sekvens av steg, uppgifter eller händelser i ett cirkulärt flöde. Betonar stegen snarare än de sammankopplande pilarna eller flödet. |
| BUBBLE_PICTURE_LIST | Använd för att visa en serie av bilder. Kan innehålla upp till åtta nivå 1-bilder. Oanvänd text och bilder visas inte, men förblir tillgängliga om du byter layout. Fungerar bäst med små mängder text. |
| CAPTIONED_PICTURES | Använd för att visa bilder med flera nivåer av text.  Fungerar bäst med en liten mängd nivå 1-text och en medelmåttig mängd nivå 2-text. |
| CHEVRON_LIST | Använd för att visa en progression genom flera processer som utgör ett övergripande arbetsflöde. Fungerar också för att illustrera kontrasterande processer. Nivå 1-text motsvarar den första pilformen till vänster, medan nivå 2-text motsvarar horisontella delsteg för varje form som innehåller nivå 1-text. |
| CIRCLE_ACCENT_TIMELINE | Använd för att visa en serie av händelser eller tidslinjeinformation. Nivå 1-text visas bredvid större cirkulära former. Nivå 2-text visas bredvid mindre cirkulära former. |
| CIRCLE_ARROW_PROCESS | Använd för att visa sekventiella objekt med stödjande text för varje objekt. Detta diagram fungerar bäst med små mängder nivå 1-text. |
| CIRCLE_PICTURE_HIERARCHY | Använd för att visa hierarkisk information eller rapporteringsrelationer i en organisation. Bilder visas i cirklar och motsvarande text visas bredvid bilderna. |
| CIRCLE_RELATIONSHIP | Använd för att visa relationen till eller från en central idé. Nivå 2-text läggs till icke-sekventiellt och är begränsad till fem objekt. Det kan bara finnas ett nivå 1-objekt. |
| CIRCULAR_BENDING_PROCESS | Använd för att visa en lång eller icke-linjär sekvens eller steg i en uppgift, process eller arbetsflöde. Fungerar bäst med endast nivå 1-text. Maximerar både horisontellt och vertikalt utrymme för former. |
| CIRCULAR_PICTURE_CALLOUT | Använd för att visa en central idé och underidéer eller relaterade objekt. Texten för den första bilden täcker den nedre delen av bilden. Motsvarande text för andra nivå 1-former visas bredvid de små cirkulära bilderna. Detta diagram fungerar också bra utan text. |
| CLOSED_CHEVRON_PROCESS | Använd för att visa en progression, en tidslinje eller sekventiella steg i en uppgift, process eller arbetsflöde, eller för att betona rörelse eller riktning. Kan användas för att betona information i startformen. Fungerar bäst med endast nivå 1-text. |
| CONTINUOUS_ARROW_PROCESS | Använd för att visa en tidslinje eller sekventiella steg i en uppgift, process eller arbetsflöde. Fungerar bäst med nivå 1-text eftersom varje rad av nivå 1-text visas inuti pilformen. Nivå 2-text visas utanför pilformen. |
| CONTINUOUS_BLOCK_PROCESS | Använd för att visa en progression eller sekventiella steg i en uppgift, process eller arbetsflöde. Fungerar bäst med minimal nivå 1- och nivå 2-text. |
| CONTINUOUS_CYCLE | Använd för att representera en fortsättande sekvens av steg, uppgifter eller händelser i ett cirkulärt flöde. Betonar kopplingen mellan alla komponenter. Fungerar bäst med endast nivå 1-text. |
| CONTINUOUS_PICTURE_LIST | Använd för att visa grupper av sammanlänkad information. De cirkulära formerna är avsedda att innehålla bilder. |
| CONVERGING_ARROWS | Använd för att visa idéer eller begrepp som konvergerar till en central punkt. Fungerar bäst med endast nivå 1-text. |
| CONVERGING_RADIAL | Använd för att visa relationer mellan begrepp eller komponenter till en central idé i en cykel. Den första raden av nivå 1-text motsvarar den centrala cirkulära formen och raderna av nivå 2-text motsvarar de omgivande rektangulära formerna. Oanvänd text visas inte, men förblir tillgänglig om du byter layout. |
| COUNTERBALANCE_ARROWS | Använd för att visa två motsatta idéer eller begrepp. Varje av de två första raderna av nivå 1-text motsvarar en pil och fungerar bra med nivå 2-text. Oanvänd text visas inte, men förblir tillgänglig om du byter layout. |
| CYCLE_MATRIX | Använd för att visa förhållandet till en central idé i en cyklisk progression. Varje av de fyra första raderna av nivå 1-text motsvarar en klyfta eller pajform, och nivå 2-text visas i en rektangulär form bredvid klyftan eller pajformen. Oanvänd text visas inte, men förblir tillgänglig om du byter layout. |
| DESCENDING_BLOCK_LIST | Använd för att visa grupper av relaterade idéer eller informationslistor. Textformerna minskar i höjd sekventiellt, och nivå 1-text visas vertikalt. |
| DESCENDING_PROCESS | Använd för att visa en fallande serie av händelser. Den första nivå 1-texten är högst upp på pilen, och den sista nivå 1-texten visas längst ner på pilen. Endast de första sju nivå 1-objekten visas. Fungerar bäst med små till medelstora mängder text. |
| DETAILED_PROCESS | Använd med stora mängder nivå 2-text för att visa en progression genom steg. |
| DIVERGING_ARROWS | Använd för att visa idéer eller begrepp som utvecklas utåt från en central källa. Fungerar bäst med endast nivå 1-text. |
| DIVERGING_RADIAL | Använd för att visa relationer till en central idé i en cykel. Den första nivå 1-texten motsvarar den centrala cirkulära formen. Betonar de omgivande cirklarna snarare än den centrala idén. Oanvänd text visas inte, men förblir tillgänglig om du byter layout. |
| EQUATION | Använd för att visa sekventiella steg eller uppgifter som beskriver en plan eller ett resultat. Den sista nivå 1-texten visas efter likhetstecknet (=). Fungerar bäst med endast nivå 1-text. |
| FRAMED_TEXT_PICTURE | Använd för att visa bilder med motsvarande nivå 1-text som visas i en ram. |
| FUNNEL | Använd för att visa filtrering av information eller hur delar går samman till en helhet. Betonar det slutgiltiga resultatet. Kan innehålla upp till fyra rader av nivå 1-text; den sista av dessa fyra nivå 1-rader visas under tratten och de andra raderna motsvarar en cirkulär form. Oanvänd text visas inte, men förblir tillgänglig om du byter layout. |
| GEAR | Använd för att visa sammanlänkade idéer. Varje av de tre första raderna av nivå 1-text motsvarar en kuggeform, och deras motsvarande nivå 2-text visas i rektanglar bredvid kuggeformen. Oanvänd text visas inte, men förblir tillgänglig om du byter layout. |
| GRID_MATRIX | Används för att visa placeringen av koncept längs två axlar. Betonar de enskilda komponenterna snarare än helheten. De första fyra raderna av nivå 1 text visas i kvadranterna. Oanvänd text visas inte, men förblir tillgänglig om du byter layout. |
| GROUPED_LIST | Används för att visa grupper och undergrupper av information, eller steg och understeg i en uppgift, process eller arbetsflöde. Nivå 1 text motsvarar de översta horisontella formerna, och nivå 2 text motsvarar vertikala understeg under varje relaterad överstående form. Fungerar bra för att betona undergrupper eller understeg, hierarkisk information eller flera informationslistor. |
| HALF_CIRCLE_ORGANIZATION_CHART | Används för att visa hierarkisk information eller rapporteringsrelationer i en organisation. Assistentformerna och hängande Org Chart-layouter är tillgängliga med denna layout. |
| HEXAGON_CLUSTER | Används för att visa bilder med tillhörande beskrivande text. Små hexagoner visar bild- och textparet. Fungerar bäst med små mängder text. |
| HIERARCHY | Används för att visa hierarkiska relationer som går från toppen till botten. |
| HIERARCHY_LIST | Används för att visa hierarkiska relationer som fortskrider över grupper. Kan också användas för att gruppera eller lista information. |
