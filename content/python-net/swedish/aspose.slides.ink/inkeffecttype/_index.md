## InkEffectType enumeration

Anger en uppsättning fördefinierade visuella effekter för bläckåtergivning.  
Varje effekt motsvarar en textur eller bild som simulerar ett stiliserat bläckutseende.  
Dessa värden kan användas för att anpassa den visuella stilen för digitala bläckstift under rendering.

The InkEffectType type exposes the following members:

## Fält

| Field | Description |
| :- | :- |
| NOT_DEFINED | Effekten är inte definierad eller är okänd. Detta värde kan användas som standard eller reserv. |
| BRONZE | En varm, brunaktig metallisk textur som liknar bronsbläck. |
| GALAXY | En färgglad, skimrande textur som liknar en galax, med kosmiska toner. |
| GOLD | En ljus, metallisk guldfärgad textur som ger bläckstift ett lyxigt utseende. |
| LAVA | En eldig textur som liknar smält lava, med röda och orange nyanser. |
| OCEAN | En djupblå, fluidliknande textur som imiterar havsvågor eller vattenbaserat bläck. |
| RAINBOW_GLITTER | En färgglad, glittrig regnbågseffekt som används för festliga eller livfulla bläckstift. |
| ROSE_GOLD | En mjuk rosa-guldblandning, liknande roséguld, för eleganta bläckstift. |
| SILVER | En kall, metallisk silvertextur som simulerar klassiskt silverbläck. |
