## IInkBrush klass

Representerar spårpenseln.

IInkBrush-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`color`](/slides/python-net/sv/aspose.slides.ink/iinkbrush/color/) | Hämtar eller anger borstens färg för en linje. |
| [`size`](/slides/python-net/sv/aspose.slides.ink/iinkbrush/size/) | Hämtar eller anger borststorleken för en linje i punkter. |
| [`ink_effect`](/slides/python-net/sv/aspose.slides.ink/iinkbrush/ink_effect/) | Hämtar bläckeffekttypen (t.ex. Om ingen igenkänd effekt är angiven,<br/>            [`InkEffectType.NOT_DEFINED`](/slides/python-net/sv/aspose.slides.ink/inkeffecttype/NOT_DEFINED) returneras. |
