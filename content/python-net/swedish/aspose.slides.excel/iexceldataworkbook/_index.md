## IExcelDataWorkbook klass

Representerar en arbetsbok som ger åtkomst till Excel-data för allmän användning.

IExcelDataWorkbook-typen exponerar följande medlemmar:

## Metoder

| Metod | Beskrivning |
| :- | :- |
| [`get_cell(self, worksheet_index, row, column)`](/slides/python-net/sv/aspose.slides.excel/iexceldataworkbook/get_cell/#int-int-int) | Hämtar en cell från det angivna arbetsbladet med hjälp av dess index och cellkoordinater. |
| [`get_cell(self, worksheet_name, row, column)`](/slides/python-net/sv/aspose.slides.excel/iexceldataworkbook/get_cell/#str-int-int) | Hämtar en cell från det angivna arbetsbladet med hjälp av dess namn och cellkoordinater. |
| [`get_cell(self, worksheet_index, cell_name)`](/slides/python-net/sv/aspose.slides.excel/iexceldataworkbook/get_cell/#int-str) | Hämtar en cell från det angivna arbetsbladet med hjälp av dess index och Excel-stil cellnamn (t.ex. "B2"). |
| [`get_cell(self, worksheet_name, cell_name)`](/slides/python-net/sv/aspose.slides.excel/iexceldataworkbook/get_cell/#str-str) | Hämtar en cell från det angivna arbetsbladet med hjälp av Excel-stil cellnamn (t.ex. "B2"). |
| [`get_cells(self, formula, skip_hidden_cells)`](/slides/python-net/sv/aspose.slides.excel/iexceldataworkbook/get_cells/#str-bool) | Hämtar en samling av celler från arbetsboken som matchar den angivna formeln. |

| [`get_worksheet_names(self)`](/slides/python-net/sv/aspose.slides.excel/iexceldataworkbook/get_worksheet_names/#) | Hämtar namnen på alla arbetsblad som finns i Excel-arbetsboken. |
