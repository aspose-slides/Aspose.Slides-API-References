## get_cells(self, formula, skip_hidden_cells) {#str-bool}
Hämtar en samling celler från arbetsboken som matchar den angivna formeln.

### Returnerar

En skrivskyddad lista med celler som matchar den angivna formeln.

```python
    ...
```


| Parameter | Typ | Beskrivning |
| :- | :- | :- |
| formula | **str** | En formel eller områdeuttryck (t.ex. "Sheet1!A1:B3") som används för att identifiera målcellerna. |
| skip_hidden_cells | **bool** | Om `true` kommer dolda celler (t.ex. i dolda rader eller kolumner) att uteslutas från resultatet. |
