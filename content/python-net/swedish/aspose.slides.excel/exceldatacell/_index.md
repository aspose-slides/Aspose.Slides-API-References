## ExcelDataCell klass

Representerar en enskild cell i en Excel-arbetsbok.

ExcelDataCell-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`value`](/slides/python-net/sv/aspose.slides.excel/exceldatacell/value/) | Hämtar värdet som finns i Excel-cellen. |
| [`name`](/slides/python-net/sv/aspose.slides.excel/exceldatacell/name/) | Hämtar namnet på diagrammets datacell. |
| [`row`](/slides/python-net/sv/aspose.slides.excel/exceldatacell/row/) | Hämtar nollbaserat index för raden i arbetsbladet där cellen finns.<br/>            Skrivskyddad **int**. |
| [`column`](/slides/python-net/sv/aspose.slides.excel/exceldatacell/column/) | Hämtar nollbaserat index för kolumnen i arbetsbladet där cellen finns.<br/>            Skrivskyddad **int**. |
