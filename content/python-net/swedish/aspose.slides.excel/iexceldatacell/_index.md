## IExcelDataCell klass

Representerar en enda cell i en Excel-arbetsbok.

IExcelDataCell-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`value`](/slides/python-net/sv/aspose.slides.excel/iexceldatacell/value/) | Hämtar värdet som finns i Excel-cellen.<br/>            Skrivskyddad **any**. |
| [`name`](/slides/python-net/sv/aspose.slides.excel/iexceldatacell/name/) | Hämtar namnet på diagrammets datacell.<br/>            Skrivskyddad **str**. |
| [`row`](/slides/python-net/sv/aspose.slides.excel/iexceldatacell/row/) | Hämtar det nollbaserade indexet för raden i kalkylbladet där cellen är placerad.<br/>            Skrivskyddad **int**. |
| [`column`](/slides/python-net/sv/aspose.slides.excel/iexceldatacell/column/) | Hämtar det nollbaserade indexet för kolumnen i kalkylbladet där cellen är placerad.<br/>            Skrivskyddad **int**. |
