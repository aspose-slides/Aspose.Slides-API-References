## skip_java_script_links egenskap
Specificerar om hyperlänkar med JavaScript-anrop ska hoppas över när presentationen sparas. 
            Läs/skriv **bool**. Standardvärdet är **false** .


### Anmärkningar

När denna egenskap är satt till **true** , hyperlänkar med JavaScript-anrop kommer att ignoreras vid sparning.


När denna egenskap är satt till **false** , alla hyperlänkar kommer att sparas.
