## no_break egenskap
Ingen avbrott
            Denna egenskap specificerar egenskapen "unbreakable" på objektlådan. När true kan inga radbrytningar uppstå inom lådan.
            Detta kan vara viktigt för operator-emulatorer som består av mer än en binär operator. 
            När detta element inte anges kan brytningar inträffa i lådan.
            Standard: true
