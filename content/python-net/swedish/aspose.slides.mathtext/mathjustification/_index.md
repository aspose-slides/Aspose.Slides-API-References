## MathJustification enumeration

Anger justeringen av det matematiska stycket (en serie av intilliggande instanser av matematisk text inom samma stycke)

MathJustification-typen exponerar följande medlemmar:

## Fält

| Field | Description |
| :- | :- |
| LEFT_JUSTIFIED | Justera matematisk text till vänster |
| RIGHT_JUSTIFIED | Justera matematisk text till höger |
| CENTERED | Justera matematisk text till mitten |
| CENTERED_AS_GROUP | Centrera på sidan hela gruppen av matematiska block som en enhet.<br/>            Detta betyder att instanserna av matematisk text kan justeras i förhållande till varandra, <br/>            men hela gruppen av matematisk text är centrerad som helhet. |
