## MathRowSpacingRule uppräkning

Typen av vertikal avstånd mellan kolumner i en matris eller array

MathRowSpacingRule-typen exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| SINGLE_LINE_GAP | enkel radavstånd |
| ONE_AND_A_HALF_LINE_GAP | En och en halv radavstånd |
| TWO_LINE_GAP | Två radavstånd |
| EXACTLY | Exactly (baseras på värdet av RowSpacing-egenskapen, mätt i punkter) |
| MULTIPLE | Multiple (baseras på värdet av RowSpacing-egenskapen, mätt i rader) |
