## IBlurEffectiveData klass

Oföränderligt objekt som representerar en oskärpeeffekt som tillämpas på hela formen, inklusive dess fyllning. Alla färgkanaler, inklusive alfa, påverkas.

IBlurEffectiveData-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`radius`](/slides/python-net/sv/aspose.slides.effects/iblureffectivedata/radius/) | Returnerar eller anger oskärperadie.<br/>            Skrivskyddad **float**. |
| [`grow`](/slides/python-net/sv/aspose.slides.effects/iblureffectivedata/grow/) | Bestämmer om objektets gränser ska utökas som ett resultat av oskärpan.<br/>            True indikerar att gränserna utökas medan false indikerar att de inte gör det.<br/>            Skrivskyddad **bool**. |
