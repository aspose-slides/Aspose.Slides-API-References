## IOuterShadow klass

Representerar en yttre skuggeffekt.

Typen IOuterShadow exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`blur_radius`](/slides/python-net/sv/aspose.slides.effects/ioutershadow/blur_radius/) | Suddighetsradie, i punkter.<br/>            Standardvärde – 0 pt.<br/>            Läs/skriv **float**. |
| [`direction`](/slides/python-net/sv/aspose.slides.effects/ioutershadow/direction/) | Skuggans riktning, i grader.<br/>            Standardvärde – 0 ° (vänster-till-höger).<br/>            Läs/skriv **float**. |
| [`distance`](/slides/python-net/sv/aspose.slides.effects/ioutershadow/distance/) | Avståndet för skuggan från objektet, i punkter.<br/>            Standardvärde – 0 pt.<br/>            Läs/skriv **float**. |
| [`shadow_color`](/slides/python-net/sv/aspose.slides.effects/ioutershadow/shadow_color/) | Skuggans färg.<br/>            Standardvärde – automatisk svart (temaberoende).<br/>            Skrivskyddad [`IColorFormat`](/slides/python-net/sv/aspose.slides/icolorformat). |
| [`rectangle_align`](/slides/python-net/sv/aspose.slides.effects/ioutershadow/rectangle_align/) | Rektangeljustering.<br/>            Standardvärde – [`RectangleAlignment.BOTTOM`](/slides/python-net/sv/aspose.slides/rectanglealignment/BOTTOM). <br/>            Läs/skriv [`RectangleAlignment`](/slides/python-net/sv/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/sv/aspose.slides.effects/ioutershadow/skew_horizontal/) | Horisontell skevningsvinkel, i grader.<br/>            Standardvärde – 0 °.<br/>            Läs/skriv **float**. |
| [`skew_vertical`](/slides/python-net/sv/aspose.slides.effects/ioutershadow/skew_vertical/) | Vertikal skevningsvinkel, i grader.<br/>            Standardvärde – 0 °.<br/>            Läs/skriv **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/sv/aspose.slides.effects/ioutershadow/rotate_shadow_with_shape/) | Anger om skuggan roterar tillsammans med formen.<br/>            Standardvärde – true.<br/>            Läs/skriv **bool**. |

| [`scale_vertical`](/slides/python-net/sv/aspose.slides.effects/ioutershadow/scale_vertical/) | Vertikal skalningsfaktor, i procent av originalstorleken.<br/>            Negativ skalning orsakar en spegling.<br/>            Standardvärde – 100 %.<br/>            Läs/skriv **float**. |
