## IReflectionEffectiveData klass

Oföränderligt objekt som representerar en reflektionseffekt.

IReflectionEffectiveData-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/sv/aspose.slides.effects/ireflectioneffectivedata/start_pos_alpha/) | Anger startpositionen (längs alfa-gradientens ramp) för start-alfavärdet (procent).<br/>            Endast läsning **float**. |
| [`end_pos_alpha`](/slides/python-net/sv/aspose.slides.effects/ireflectioneffectivedata/end_pos_alpha/) | Anger slutpositionen (längs alfa-gradientens ramp) för slut-alfavärdet (procent).<br/>            Endast läsning **float**. |
| [`fade_direction`](/slides/python-net/sv/aspose.slides.effects/ireflectioneffectivedata/fade_direction/) | Anger riktningen för att förskjuta reflektionen. (vinkel).<br/>            Endast läsning **float**. |
| [`start_reflection_opacity`](/slides/python-net/sv/aspose.slides.effects/ireflectioneffectivedata/start_reflection_opacity/) | Startande reflektionens opacitet. (procent).<br/>            Endast läsning **float**. |
| [`end_reflection_opacity`](/slides/python-net/sv/aspose.slides.effects/ireflectioneffectivedata/end_reflection_opacity/) | Slutreflektionens opacitet. (procent).<br/>            Endast läsning **float**. |
| [`blur_radius`](/slides/python-net/sv/aspose.slides.effects/ireflectioneffectivedata/blur_radius/) | Suddighetsradie.<br/>            Endast läsning **float**. |
| [`direction`](/slides/python-net/sv/aspose.slides.effects/ireflectioneffectivedata/direction/) | Riktning för reflektion.<br/>            Endast läsning **float**. |
| [`distance`](/slides/python-net/sv/aspose.slides.effects/ireflectioneffectivedata/distance/) | Avstånd för reflektion.<br/>            Endast läsning **float**. |
| [`rectangle_align`](/slides/python-net/sv/aspose.slides.effects/ireflectioneffectivedata/rectangle_align/) | Rektangeljustering.<br/>            Endast läsning [`RectangleAlignment`](/slides/python-net/sv/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/sv/aspose.slides.effects/ireflectioneffectivedata/skew_horizontal/) | Anger den horisontella skevningsvinkeln.<br/>            Endast läsning **float**. |
| [`skew_vertical`](/slides/python-net/sv/aspose.slides.effects/ireflectioneffectivedata/skew_vertical/) | Anger den vertikala skevningsvinkeln.<br/>            Endast läsning **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/sv/aspose.slides.effects/ireflectioneffectivedata/rotate_shadow_with_shape/) | Anger om reflektionen ska rotera med formen när formen roteras.<br/>            Endast läsning **bool**. |
| [`scale_horizontal`](/slides/python-net/sv/aspose.slides.effects/ireflectioneffectivedata/scale_horizontal/) | Anger den horisontella skalfaktorn, negativ skalning orsakar en spegling. (procent)<br/>            Endast läsning **float**. |
| [`scale_vertical`](/slides/python-net/sv/aspose.slides.effects/ireflectioneffectivedata/scale_vertical/) | Anger den vertikala skalfaktorn, negativ skalning orsakar en spegling. (procent)<br/>            Endas läsning **float**. |
