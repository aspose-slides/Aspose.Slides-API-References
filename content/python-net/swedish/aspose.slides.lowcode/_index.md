Innehåller klasser och metoder för att hantera komplexa allmänna operationer på ett lågkodsätt.
## Klasser

| Klass | Beskrivning |
| :- | :- |
| [`Collect`](/slides/python-net/sv/aspose.slides.lowcode/collect/) | Representerar en grupp metoder avsedda att samla modellobjekt av olika typer från [`Presentation`](/slides/python-net/sv/aspose.slides/presentation). |
| [`Compress`](/slides/python-net/sv/aspose.slides.lowcode/compress/) | Representerar en grupp metoder avsedda att komprimera [`Presentation`](/slides/python-net/sv/aspose.slides/presentation). |
| [`Convert`](/slides/python-net/sv/aspose.slides.lowcode/convert/) | Representerar en grupp metoder avsedda att konvertera [`Presentation`](/slides/python-net/sv/aspose.slides/presentation). |
| [`ForEach`](/slides/python-net/sv/aspose.slides.lowcode/foreach/) | Representerar en grupp metoder avsedda att iterera över olika [`Presentation`](/slides/python-net/sv/aspose.slides/presentation) modellobjekt.<br/>            Dessa metoder kan vara användbara om du behöver iterera och ändra några Presentation-elementens formatering eller innehåll,<br/>             t.ex. ändra varje portions formatering. |
| [`Merger`](/slides/python-net/sv/aspose.slides.lowcode/merger/) | Representerar en grupp metoder för att slå samman PowerPoint-presentationer av samma format till en fil. |
