## MasterTheme klass

Representerar ett mastertema.

**Arv:**[`MasterTheme`](/slides/python-net/sv/aspose.slides.theme/mastertheme) → [`Theme`](/slides/python-net/sv/aspose.slides.theme/theme)

MasterTheme-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`color_scheme`](/slides/python-net/sv/aspose.slides.theme/mastertheme/color_scheme/) | Returnerar färgschemat.<br/>            Endast läsning [`IColorScheme`](/slides/python-net/sv/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/sv/aspose.slides.theme/mastertheme/font_scheme/) | Returnerar typsnittsschemat.<br/>            Endast läsning [`IFontScheme`](/slides/python-net/sv/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/sv/aspose.slides.theme/mastertheme/format_scheme/) | Returnerar formformatmall.<br/>            Endast läsning [`IFormatScheme`](/slides/python-net/sv/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/sv/aspose.slides.theme/mastertheme/presentation/) | Returnerar den överordnade presentationen.<br/>            Endast läsning [`IPresentation`](/slides/python-net/sv/aspose.slides/ipresentation). |
| [`extra_color_schemes`](/slides/python-net/sv/aspose.slides.theme/mastertheme/extra_color_schemes/) | Returnerar samlingen av ytterligare färgscheman.<br/>            Dessa scheman påverkar inte presentationens utseende, de kan väljas som huvudfärgschema för en bild.<br/>            Endast läsning [`IExtraColorSchemeCollection`](/slides/python-net/sv/aspose.slides.theme/iextracolorschemecollection). |
| [`name`](/slides/python-net/sv/aspose.slides.theme/mastertheme/name/) | Returnerar namnet på ett tema.<br/>            Läs/skriv **str**. |
