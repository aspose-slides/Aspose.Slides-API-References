## is_override_theme_enabled egenskap
Bestämmer om OverrideTheme åsidosätter ärvt effektivt tema eller inte.
            För att aktivera OverrideTheme för överskrivning, använd OverrideTheme.Init*()-metoderna.
            För att inaktivera OverrideTheme från att överskriva, använd OverrideTheme.Clear()-metoden.
            Skrivskyddad **bool**.
