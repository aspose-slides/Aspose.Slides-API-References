## is_override_theme_enabled egenskap
Bestämmer om OverrideTheme åsidosätter ärvt effektivt tema eller inte.
            För att aktivera OverrideTheme för överskrivning använd OverrideTheme.Init*() metoder.
            För att inaktivera OverrideTheme från överskrivning använd OverrideTheme.Clear() metod.
            Skrivskyddad **bool**.
