## is_override_theme_enabled egenskap
Bestämmer om OverrideTheme åsidosätter ärvt effektivt tema eller inte.
            För att aktivera OverrideTheme för åsidosättning, använd OverrideTheme.Init*() metoder.
            För att inaktivera OverrideTheme från åsidosättning, använd OverrideTheme.Clear() metod.
            Skrivskyddad **bool**.
