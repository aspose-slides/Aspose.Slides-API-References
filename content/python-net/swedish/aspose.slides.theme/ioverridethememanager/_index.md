## IOverrideThemeManager klass

Tillhandahåller åtkomst till olika typer av överskrivna teman.

Typen IOverrideThemeManager exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`is_override_theme_enabled`](/slides/python-net/sv/aspose.slides.theme/ioverridethememanager/is_override_theme_enabled/) | Bestämmer om OverrideTheme överskrider det ärvda effektiva temat eller inte.<br/>            För att aktivera OverrideTheme för överskrivning, använd OverrideTheme.Init*()-metoderna.<br/>            För att inaktivera OverrideTheme från att överskriva, använd OverrideTheme.Clear()-metoden.<br/>            Skrivskyddad **bool**. |
| [`override_theme`](/slides/python-net/sv/aspose.slides.theme/ioverridethememanager/override_theme/) | Returnerar det överskrivna temaobjektet.<br/>            Läs/skriv [`IOverrideTheme`](/slides/python-net/sv/aspose.slides.theme/ioverridetheme). |
