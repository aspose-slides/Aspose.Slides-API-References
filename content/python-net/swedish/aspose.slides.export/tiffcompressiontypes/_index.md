## TiffCompressionTypes enumeration

Tillhandahåller alternativ som styr hur en presentation komprimeras i TIFF-format.

TiffCompressionTypes-typen visar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| DEFAULT | Anger standardkomprimeringsschemat (LZW). |
| NONE | Anger ingen komprimering. |
| CCITT3 | Anger CCITT3-komprimeringsschemat. |
| CCITT4 | Anger CCITT4-komprimeringsschemat. |
| LZW | Anger LZW-komprimeringsschemat (standard). |
| RLE | Anger RLE-komprimeringsschemat. |
