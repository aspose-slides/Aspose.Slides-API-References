## LinkEmbedDecision uppräkning

Bestämmer hur objektet kommer att behandlas vid sparande.

LinkEmbedDecision-typen visar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| LINK | Objektet kommer att lagras externt, refererat via URL |
| EMBED | Objektet bör inbäddas i en genererad fil om möjligt. Om inbäddning är omöjligt, kommer GetUrl att anropas och, beroende på resultatet, kommer objektet att refereras via URL eller ignoreras. |
| IGNORE | Objektet kommer att ignoreras. |
