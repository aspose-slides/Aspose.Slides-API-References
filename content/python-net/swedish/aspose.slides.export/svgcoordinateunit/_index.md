## SvgCoordinateUnit uppräkning

Representerar CSS2-koordinatenheter som används för att definiera SVG-koordinater.

SvgCoordinateUnit-typen exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| INCH | Tum |
| CENTIMETER | Centimeter. |
| MILLIMETER | Millimeter. |
| POINT | Punkt (1/72 av tum), |
| PICA | Pica (1/6 av tum). |
| EM | Em-storlek för en font i det omgivande elementet. |
| EX | Ex-storlek (storlek på en gemen bokstav, vanligtvis "x") för font i det omgivande elementet. |
| PIXEL | Pixelstorlek. |
| PERCENT | Procent. |
