## CompressionLevel uppräkning

Anger ZIP-komprimeringsnivåer för OpenXML-filen.
Högre nivåer ger bättre kompression på bekostnad av långsammare behandling.

CompressionLevel-typen exponerar följande medlemmar:

## Fält

| Field | Description |
| :- | :- |
| NONE | Ingen kompression tillämpas. Filer lagras som de är. |
| LEVEL1 | Snabbast kompression med den lägsta komprimeringsgraden. |
| LEVEL2 | Snabbare kompression med något bättre komprimeringsgrad än [`CompressionLevel.LEVEL1`](/slides/python-net/sv/aspose.slides.export/compressionlevel/LEVEL1). |
| LEVEL3 | Ger bättre kompression än [`CompressionLevel.LEVEL2`](/slides/python-net/sv/aspose.slides.export/compressionlevel/LEVEL2) med måttlig prestandapåverkan. |
| LEVEL4 | Ger bättre kompression än [`CompressionLevel.LEVEL3`](/slides/python-net/sv/aspose.slides.export/compressionlevel/LEVEL3). |
| LEVEL5 | Ger förbättrad kompression jämfört med [`CompressionLevel.LEVEL4`](/slides/python-net/sv/aspose.slides.export/compressionlevel/LEVEL4) med extra behandlingstid. |
| LEVEL6 | Standardkompression, som erbjuder en bra balans mellan komprimeringshastighet och filstorlek.<br/>            Standardkomprimeringsnivån. |
| LEVEL7 | Ger högre kompression än [`CompressionLevel.LEVEL6`](/slides/python-net/sv/aspose.slides.export/compressionlevel/LEVEL6) med långsammare behandling. |
| LEVEL8 | Ger högre kompression än [`CompressionLevel.LEVEL7`](/slides/python-net/sv/aspose.slides.export/compressionlevel/LEVEL7). |
| LEVEL9 | Maximal kompression. Skapar den minsta filstorleken med den långsammaste behandlingshastigheten. |
