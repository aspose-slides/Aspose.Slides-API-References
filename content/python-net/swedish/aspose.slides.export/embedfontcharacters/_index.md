## EmbedFontCharacters enumeration
Representerar regeln som ska användas för att lägga till ett nytt inbäddat teckensnitt i [`IPresentation`](/slides/python-net/sv/aspose.slides/ipresentation)

Typen EmbedFontCharacters exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| ONLY_USED | Bädda endast in de tecken som används i presentationen (bäst för att minska filstorleken). |
| ALL | Bädda in alla tecken (bäst för redigering av andra). |
