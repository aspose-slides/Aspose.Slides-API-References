## SaveFormat-enumeration

Konstanter som definierar formatet för en sparad presentation.

SaveFormat-typen exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| PPT | Spara presentation i PPT-format. |
| PDF | Spara presentation i PDF-format. |
| XPS | Spara presentation i XPS-format. |
| PPTX | Spara presentation i PPTX-format. |
| PPSX | Spara presentation i PPSX (bildspel) format. |
| TIFF | Spara presentation som flersidig TIFF-bild. |
| ODP | Spara presentation i ODP-format. |
| PPTM | Spara presentation i PPTM (makroaktiverad presentation) format. |
| PPSM | Spara presentation i PPSM (makroaktiverat bildspel) format. |
| POTX | Spara presentation i POTX (mall) format. |
| POTM | Spara presentation i POTM (makroaktiverad mall) format. |
| HTML | Spara presentation i HTML-format. |
| SWF | Spara presentation i SWF-format. |
| OTP | Spara presentation i OTP (presentationsmall) format. |
| PPS | Spara presentation i PPS-format. |
| POT | Spara presentation i POT-format. |
| FODP | Spara presentation i FODP-format. |
| GIF | Spara presentation i GIF-format. |
| HTML5 | Spara presentation i HTML-format med det nya HTML5-mallsystemet. |
| MD | Spara presentation i Markdown-format |
| XML | Spara presentation i PowerPoint XML-presentationsformat. |
