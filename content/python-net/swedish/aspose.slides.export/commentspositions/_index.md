## CommentsPositions enumeration

Representerar regeln för att rendera kommentarer i exporterade dokument

Typen CommentsPositions exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| NONE | Anger att kommentarer inte ska visas alls. |
| BOTTOM | Anger att kommentarer ska visas längst ner på sidan. |
| RIGHT | Anger att kommentarer ska visas till höger på sidan. |
