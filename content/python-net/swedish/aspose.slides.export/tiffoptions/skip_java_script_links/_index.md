## skip_java_script_links egenskap
Anger om hyperlänkar med JavaScript-anrop ska hoppas över vid sparande av presentationen. 
            Läs/skriv **bool**. Standardvärdet är **false** .


### Anmärkningar

När egenskapen är satt till **true** , hyperlänkar med JavaScript-anrop kommer att ignoreras vid sparande.


När egenskapen är satt till **false** , alla hyperlänkar kommer att sparas.
