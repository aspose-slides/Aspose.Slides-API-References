## MarkdownExportType enumeration

Typ av renderingsdokument.

Typen MarkdownExportType exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| SEQUENTIAL | Renderar alla objekt separat. Ett i taget. |
| TEXT_ONLY | Renderar endast text. |
| VISUAL | Renderar alla objekt, objekt som är grupperade - renderar tillsammans. |
