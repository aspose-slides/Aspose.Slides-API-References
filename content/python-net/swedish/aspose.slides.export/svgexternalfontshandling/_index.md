## SvgExternalFontsHandling uppräkning

Representerar ett sätt att hantera externa teckensnitt som används för textritning.

Typen SvgExternalFontsHandling exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| ADD_LINKS_TO_FONT_FILES | Lägg till länkar till separata teckensnittsfiler i stilsektionen i SVG-filen. |
| EMBED | Spara teckensnittens data direkt i SVG-filen. Kontrollera alla licensavtal för externa teckensnitt innan du använder detta alternativ. |
| VECTORIZE | Spara all text som använder externa teckensnitt som grafik. |
