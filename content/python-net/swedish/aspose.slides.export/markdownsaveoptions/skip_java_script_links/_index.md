## skip_java_script_links egenskap
Specificerar om hyperlänkar med JavaScript-anrop ska hoppas över när presentationen sparas. 
            Läs/skriv **bool**. Standardvärdet är **false** .


### Anmärkningar

När denna egenskap är satt till **true** , kommer hyperlänkar med JavaScript-anrop att ignoreras vid sparande.

När denna egenskap är satt till **false** , sparas alla hyperlänkar.
