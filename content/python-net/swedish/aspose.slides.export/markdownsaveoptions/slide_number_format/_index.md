## slide_number_format egenskap
Hämtar eller anger formatsträngen som används för sidnummerrubriker i Markdown-utdata.
Formatet måste innehålla platshållaren "{0}", som kommer att ersättas med bildens index vid export.
Exempel: "# Slide {0}" kommer att producera "# Slide 1", "# Slide 2", osv.
