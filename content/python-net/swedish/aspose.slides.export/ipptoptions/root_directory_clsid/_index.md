## root_directory_clsid egenskap
Representerar objektklassens GUID (CLSID) som lagras i rotkatalogsposten. Kan användas för COM-aktivering av dokumentets program. Standardvärdet är '64818D11-4F9B-11CF-86EA-00AA00B929E8' vilket motsvarar 'Microsoft Powerpoint.Slide.8'.
