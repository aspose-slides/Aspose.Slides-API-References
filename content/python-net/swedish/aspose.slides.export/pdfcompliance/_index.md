## PdfCompliance uppräkning

Konstanter som definierar PDF-standardernas efterlevnadsnivå.

PdfCompliance-typen visar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| PDF15 | Utmatningsfilen kommer att följa PDF 1.5 standard. |
| PDF16 | Utmatningsfilen kommer att följa PDF 1.6 standard. |
| PDF17 | Utmatningsfilen kommer att följa PDF 1.7 standard. |
| PDF_A1B | Utmatningsfilen kommer att följa PDF/A-1b standarden. |
| PDF_A1A | Utmatningsfilen kommer att följa PDF/A-1a standarden. |
| PDF_A2B | Utmatningsfilen kommer att följa PDF/A-2b standarden. |
| PDF_A2A | Utmatningsfilen kommer att följa PDF/A-2a standarden. |
| PDF_A3B | Utmatningsfilen kommer att följa PDF/A-3b standarden. |
| PDF_A3A | Utmatningsfilen kommer att följa PDF/A-3a standarden. |
| PDF_UA | Utmatningsfilen kommer att följa PDF/UA standarden. |
| PDF_A2U | Utmatningsfilen kommer att följa PDF/A-2u standarden. |
