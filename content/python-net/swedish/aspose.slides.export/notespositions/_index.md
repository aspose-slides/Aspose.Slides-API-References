## NotesPositions uppräkning

Representerar regeln för att rendera anteckningar i exporterade dokument

Typen NotesPositions exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| NONE | Anger att anteckningar inte ska visas alls. |
| BOTTOM_FULL | Anger att anteckningar ska visas helt och hållet med hjälp av extra sidor vid behov. |
| BOTTOM_TRUNCATED | Anger att anteckningar ska visas på endast en sida. |
