## PicturesCompression-enumeration

Representerar bildkomprimeringsnivå

Typen PicturesCompression exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| DPI330 | God kvalitet för högupplösta (HD) skärmar |
| DPI220 | Utmärkt kvalitet på de flesta skrivare och skärmar |
| DPI150 | Bra för webbsidor och projektorer |
| DPI96 | Minimera dokumentstorlek för delning |
| DPI72 | Standardkomprimeringsnivå |
| DOCUMENT_RESOLUTION | Använd dokumentupplösning - bilden komprimeras inte och används i dokumentet som den är |
