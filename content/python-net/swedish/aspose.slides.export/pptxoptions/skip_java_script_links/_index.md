## egenskapen skip_java_script_links
Anger om hyperlänkar med JavaScript-anrop ska hoppas över när presentationen sparas.
            Läs/skriv **bool**. Standardvärdet är **false** .

### Anmärkningar

När denna egenskap är satt till **true** ignoreras hyperlänkar med JavaScript-anrop vid sparande.

När denna egenskap är satt till **false** sparas alla hyperlänkar.
