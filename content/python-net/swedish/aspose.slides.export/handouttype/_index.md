## HandoutType uppräkning

Anger hur många bilder och i vilken sekvens de placeras på sidan.

HandoutType-typen exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| HANDOUTS1 | En bild per sida. |
| HANDOUTS2 | Två bilder per sida. |
| HANDOUTS3 | Tre bilder per sida. |
| HANDOUTS_4_HORIZONTAL | Fyra bilder per sida i en horisontell sekvens. |
| HANDOUTS_4_VERTICAL | Fyra bilder per sida i en vertikal sekvens. |
| HANDOUTS_6_HORIZONTAL | Sex bilder per sida i en horisontell sekvens. |
| HANDOUTS_6_VERTICAL | Sex bilder per sida i en vertikal sekvens. |
| HANDOUTS_9_HORIZONTAL | Nio bilder per sida i en horisontell sekvens. |
| HANDOUTS_9_VERTICAL | Nio bilder per sida i en vertikal sekvens. |
