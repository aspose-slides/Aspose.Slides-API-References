## SvgEvent uppräkning

Representerar alternativ för SVG-form.

SvgEvent-typen exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| ON_FOCUS_IN | Inträffar när ett element får fokus, till exempel när en text blir markerad. |
| ON_FOCUS_OUT | Inträffar när ett element förlorar fokus, till exempel när en text avmarkeras. |
| ON_ACTIVATE | Inträffar när ett element aktiveras, till exempel genom ett musklick eller ett tangenttryck. |
| ON_CLICK | Inträffar när pekaren klickas på ett element. |
| ON_MOUSE_DOWN | Inträffar när pekaren trycks ner på ett element. |
| ON_MOUSE_UP | Inträffar när pekaren släpps över ett element. |
| ON_MOUSE_OVER | Inträffar när pekaren flyttas över ett element. |
| ON_MOUSE_MOVE | Inträffar när pekaren flyttas medan den är över ett element. |
| ON_MOUSE_OUT | Inträffar när pekaren flyttas bort från ett element. |
| ON_LOAD | Inträffar när användaragenter har fullständigt analyserat elementet och dess underelement samt alla refererade resurser som krävs för att rendera det. |
| ON_UNLOAD | Inträffar när DOM-implementationen tar bort ett dokument från ett fönster eller en ram. Gäller endast för yttre svg-element. |
| ON_ABORT | Inträffar när sidladdning stoppas innan ett element har fått laddas färdigt. |
| ON_ERROR | Inträffar när ett element inte laddas korrekt eller när ett fel uppstår under skriptexekvering. |
| ON_RESIZE | Inträffar när en dokumentvy ändras i storlek. Gäller endast för yttre svg-element. |
| ON_SCROLL | Inträffar när en dokumentvy flyttas längs X- eller Y-axeln eller båda. Gäller endast för yttre svg-element. |
| ON_ZOOM | Inträffar när zoomnivån för en dokumentvy ändras. Gäller endast för yttre svg-element. |
| ON_BEGIN | Inträffar när ett animeringselement startar. |
| ON_END | Inträffar när ett animeringselement slutar. |
| ON_REPEAT | Inträffar när ett animeringselement upprepas. |
