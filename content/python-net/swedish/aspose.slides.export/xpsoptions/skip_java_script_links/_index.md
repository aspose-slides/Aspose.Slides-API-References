## skip_java_script_links egenskap
Anger om hyperlänkar med JavaScript-anrop ska hoppas över vid sparande av presentationen.
Läs/skriv **bool**. Standardvärdet är **false**.

### Anmärkningar

När denna egenskap är inställd på **true** ignoreras hyperlänkar med JavaScript-anrop vid sparande.

När denna egenskap är inställd på **false** sparas alla hyperlänkar.
