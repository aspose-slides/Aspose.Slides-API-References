## ImagePixelFormat uppräkning

Specificerar pixelformatet för de genererade bilderna.

Typen ImagePixelFormat exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| FORMAT_1BPP_INDEXED | 1 bit per pixel, indexerad. |
| FORMAT_4BPP_INDEXED | 4 bitar per pixel, indexerad. |
| FORMAT_8BPP_INDEXED | 8 bitar per pixel, indexerad. |
| FORMAT_24BPP_RGB | 24 bitar per pixel, RGB. |
| FORMAT_32BPP_ARGB | 32 bitar per pixel, ARGB. |
