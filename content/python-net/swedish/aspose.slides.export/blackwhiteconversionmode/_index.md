## BlackWhiteConversionMode uppräkning

Ger alternativ som styr hur bildspelens bilder konverteras till bitonala bilder.

BlackWhiteConversionMode-typen visar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| DEFAULT | Anger ingen konverteringsalgoritm. Algoritmen som implementeras i TIFF-codec:n kommer att användas. (Standard) |
| DITHERING | Anger dithering-algoritmen (Floyd-Steinberg). |
| DITHERING_FLOYD_STEINBERG | Anger Floyd-Steinberg-dithering-algoritmen. |
| AUTO | Anger den automatiskt beräknade tröskelalgoritmen (Otsu). |
| AUTO_OTSU | Anger den automatiskt beräknade Otsus tröskelalgoritm. |
| THRESHOLD25 | Anger den statiska tröskelalgoritmen (25%). |
| THRESHOLD50 | Anger den statiska tröskelalgoritmen (50%). |
| THRESHOLD75 | Anger den statiska tröskelalgoritmen (75%). |
