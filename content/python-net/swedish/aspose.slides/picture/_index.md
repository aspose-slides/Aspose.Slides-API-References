## Picture klass

Representerar en bild i en presentation.

Picture-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`image`](/slides/python-net/sv/aspose.slides/picture/image/) | Returnerar eller anger den inbäddade bilden.<br/>            Läs/skriv [`IPPImage`](/slides/python-net/sv/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/sv/aspose.slides/picture/link_path_long/) | Returnerar eller anger den länkade bildens URL.<br/>            Läs/skriv **str**. |
| [`image_transform`](/slides/python-net/sv/aspose.slides/picture/image_transform/) | Returnerar samlingen av bildtransformeringseffekter.<br/>            Skrivskyddad [`IImageTransformOperationCollection`](/slides/python-net/sv/aspose.slides.effects/iimagetransformoperationcollection). |
| [`presentation`](/slides/python-net/sv/aspose.slides/picture/presentation/) | Returnerar presentationen. <br/>            Skrivskyddad [`IPresentation`](/slides/python-net/sv/aspose.slides/ipresentation). |
| [`slide`](/slides/python-net/sv/aspose.slides/picture/slide/) | Returnerar den föräldra-slide som en bild tillhör.<br/>            Skrivskyddad [`IBaseSlide`](/slides/python-net/sv/aspose.slides/ibaseslide). |
