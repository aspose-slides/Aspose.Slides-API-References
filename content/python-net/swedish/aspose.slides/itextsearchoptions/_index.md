## ITextSearchOptions klass

Representerar alternativ som kan användas för att söka efter text i en Presentation, Slide eller TextFrame.

ITextSearchOptions-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`case_sensitive`](/slides/python-net/sv/aspose.slides/itextsearchoptions/case_sensitive/) | Ange true för att använda skiftlägeskänslig sökning, false - annars.<br/>            Läs/skriv **bool**. |
| [`whole_words_only`](/slides/python-net/sv/aspose.slides/itextsearchoptions/whole_words_only/) | Ange true för att endast matcha hela ord, false - annars.<br/>            Läs/skriv **bool**. |
| [`include_notes`](/slides/python-net/sv/aspose.slides/itextsearchoptions/include_notes/) | Ange `true` för att inkludera text som finns i bildanteckningar <br/>            när du utför textsökning, ersättning eller markeringsoperationer.<br/>            Standardvärdet är `false`. |
