## PlaceholderType enumeration

Representerar typen av en platshållare.

PlaceholderType-typen exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| TITLE | Titel. |
| BODY | Kropp. |
| CENTERED_TITLE | Centrerad titel. |
| SUBTITLE | Undertitel. |
| DATE_AND_TIME | Datum och tid. |
| SLIDE_NUMBER | Bildnummer. |
| FOOTER | Sidfot. |
| HEADER | Sidhuvud. |
| OBJECT | Objekt. |
| CHART | Diagram. |
| TABLE | Tabell. |
| CLIP_ART | Clip art. |
| DIAGRAM | Diagram. |
| MEDIA | Media. |
| SLIDE_IMAGE | Bild på bildspel. |
| PICTURE | Bild. |
