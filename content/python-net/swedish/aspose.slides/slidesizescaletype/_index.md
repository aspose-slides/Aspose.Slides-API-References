## SlideSizeScaleType enumeration

Representerar skaltypen för bildinnehåll.

Typen SlideSizeScaleType exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| DO_NOT_SCALE | Skala inte. |
| ENSURE_FIT | Skala för att säkerställa passning. |
| MAXIMIZE | Maximera storleken på innehållet. |
