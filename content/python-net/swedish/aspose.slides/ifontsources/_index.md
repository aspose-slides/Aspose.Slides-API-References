## IFontSources klass

Tillhandahåller fil- och minneskällor för externa teckensnitt.

Typen IFontSources exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`font_folders`](/slides/python-net/sv/aspose.slides/ifontsources/font_folders/) | Mappar som innehåller teckensnittsfiler.<br/> All teckensnittsfiler som finns i dessa mappar inkluderas i samlingen. Mappar som söks rekursivt. |
| [`memory_fonts`](/slides/python-net/sv/aspose.slides/ifontsources/memory_fonts/) | En samling teckensnitt representerade som byte-arrayer. |
