## IThreeDFormat klass

Representerar 3-D-egenskaper.

Typen IThreeDFormat exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`contour_width`](/slides/python-net/sv/aspose.slides/ithreedformat/contour_width/) | Returnerar eller anger bredden på en 3D-kontur.<br/>            Endast läsning **float**. |
| [`extrusion_height`](/slides/python-net/sv/aspose.slides/ithreedformat/extrusion_height/) | Returnerar eller anger höjden på en extruderingseffekt.<br/>            Endast läsning **float**. |
| [`depth`](/slides/python-net/sv/aspose.slides/ithreedformat/depth/) | Returnerar eller anger djupet på en 3D-form.<br/>            Endast läsning **float**. |
| [`bevel_top`](/slides/python-net/sv/aspose.slides/ithreedformat/bevel_top/) | Returnerar eller anger typen av en övre 3D-fasning.<br/>            Endast läsning [`IShapeBevel`](/slides/python-net/sv/aspose.slides/ishapebevel). |
| [`bevel_bottom`](/slides/python-net/sv/aspose.slides/ithreedformat/bevel_bottom/) | Returnerar eller anger typen av en nedre 3D-fasning.<br/>            Endast läsning [`IShapeBevel`](/slides/python-net/sv/aspose.slides/ishapebevel). |
| [`contour_color`](/slides/python-net/sv/aspose.slides/ithreedformat/contour_color/) | Returnerar eller anger färgen på en kontur.<br/>            Endast läsning [`IColorFormat`](/slides/python-net/sv/aspose.slides/icolorformat). |
| [`extrusion_color`](/slides/python-net/sv/aspose.slides/ithreedformat/extrusion_color/) | Returnerar eller anger färgen på en extrudering.<br/>            Endast läsning [`IColorFormat`](/slides/python-net/sv/aspose.slides/icolorformat). |
| [`camera`](/slides/python-net/sv/aspose.slides/ithreedformat/camera/) | Returnerar eller anger inställningarna för en kamera.<br/>            Endast läsning [`ICamera`](/slides/python-net/sv/aspose.slides/icamera). |
| [`light_rig`](/slides/python-net/sv/aspose.slides/ithreedformat/light_rig/) | Returnerar eller anger typen av ett ljus.<br/>            Endast läsning [`ILightRig`](/slides/python-net/sv/aspose.slides/ilightrig). |
| [`material`](/slides/python-net/sv/aspose.slides/ithreedformat/material/) | Returnerar eller anger typen av ett material.<br/>            Läs/skriv [`MaterialPresetType`](/slides/python-net/sv/aspose.slides/materialpresettype). |
