## FontsLoader klass

Klass för att ladda anpassade teckensnitt som definierats av användaren.
            Ska användas innan några presentationsobjekt skapas.

FontsLoader-typen exponerar följande medlemmar:

## Metoder

| Metod | Beskrivning |
| :- | :- |
| [`load_external_fonts(directories)`](/slides/python-net/sv/aspose.slides/fontsloader/load_external_fonts/#liststr) | Lägger till ytterligare mappar för att söka teckensnitt. |
| [`load_external_font(data)`](/slides/python-net/sv/aspose.slides/fontsloader/load_external_font/#bytes) | Lägger till teckensnitt från binärdata |
| [`get_font_folders()`](/slides/python-net/sv/aspose.slides/fontsloader/get_font_folders/#) | Hämtar teckensnittsmappar. Returnerar mappar som har lagts till med LoadExternalFonts-metoden samt systemteckensnittsmappar |
| [`clear_cache()`](/slides/python-net/sv/aspose.slides/fontsloader/clear_cache/#) | Frigör alla anpassade teckensnitt som definierats av användaren |
