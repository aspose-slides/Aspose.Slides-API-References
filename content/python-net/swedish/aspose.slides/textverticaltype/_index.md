## TextVerticalType-enumeration

Bestämmer vertikalt skrivläge för en text.

TextVerticalType-typen exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| NOT_DEFINED | Ej definierad. |
| HORIZONTAL | Horisontell text. |
| VERTICAL | Vertikal text. |
| VERTICAL270 | Vertikal 270 grader text. |
| WORD_ART_VERTICAL | WordArt vertikal text. |
| EAST_ASIAN_VERTICAL | Östasiatisk vertikal text. |
| MONGOLIAN_VERTICAL | Mongolisk vertikal text. |
| WORD_ART_VERTICAL_RIGHT_TO_LEFT | WordArt vertikal text från höger till vänster. |
