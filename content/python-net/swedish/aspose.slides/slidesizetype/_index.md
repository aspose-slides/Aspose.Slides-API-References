## SlideSizeType-enumeration

Representerar förinställning för bildstorlek.

SlideSizeType-typen exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| ON_SCREEN | På skärm 4x3 |
| LETTER_PAPER | Letter |
| A4_PAPER | A4 |
| SLIDE_35MM | Bild 35mm |
| OVERHEAD | Overhead |
| BANNER | Banner |
| CUSTOM | Anpassad storlek |
| LEDGER | Ledger |
| A3_PAPER | A3 |
| B4_ISO_PAPER | B4 ISO |
| B5_ISO_PAPER | B5 ISO |
| B4_JIS_PAPER | B4 JIS |
| B5_JIS_PAPER | B5 JIS |
| HAGAKI_CARD | Hagaki-kort |
| ON_SCREEN_16X9 | På skärm 16x9 |
| ON_SCREEN_16X10 | På skärm 16x10 |
| WIDESCREEN | Bredskärm |
