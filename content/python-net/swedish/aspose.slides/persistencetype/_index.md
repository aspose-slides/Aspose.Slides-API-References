## PersistenceType enumeration

Anger metoden som används för att lagra egenskaperna för ActiveX-kontrollen.

Typen PersistenceType visar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| NOT_DEFINED | Persistens-id ej specificerat. |
| PERSIST_PROPERTY_BAG | Anger att ActiveX-kontrollen sparas med property-bag-baserad persistens. <br/>             Property-bag-baserad persistens lagrar en ActiveX-kontroll genom en samling av namn <br/>             och värde-par som specificerar de data som sparas av ActiveX-kontrollen. |
| PERSIST_STREAM | Anger att ActiveX-kontrollen sparas med stream-baserad persistens <br/>             som inte stöder initiering av ActiveX-kontrollen till ett standardtillstånd. |
| PERSIST_STREAM_INIT | Anger att ActiveX-kontrollen sparas med stream-baserad persistens <br/>             som stöder initiering av ActiveX-kontrollen till ett standardtillstånd. |
| PERSIST_STORAGE | Anger att ActiveX-kontrollen sparas med storage-baserad persistens. |
