## Comment klass

Representerar en kommentar på en bild.

Comment-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`text`](/slides/python-net/sv/aspose.slides/comment/text/) | Returnerar eller anger den rena texten för en bildkommentar.<br/>            Läs/skriv **str**. |
| [`created_time`](/slides/python-net/sv/aspose.slides/comment/created_time/) | Returnerar eller anger tiden då kommentaren skapades.<br/>            Att sätta denna egenskap till **System.DateTime** betyder att ingen kommentarstid har ställts in.<br/>            Läs/skriv **System.DateTime**. |
| [`slide`](/slides/python-net/sv/aspose.slides/comment/slide/) | Returnerar eller anger den överordnade bilden för en kommentar.<br/>            Endast läs [`ISlide`](/slides/python-net/sv/aspose.slides/islide). |
| [`author`](/slides/python-net/sv/aspose.slides/comment/author/) | Returnerar författaren till en kommentar.<br/>            Endast läs [`ICommentAuthor`](/slides/python-net/sv/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/sv/aspose.slides/comment/position/) | Returnerar eller anger positionen för en kommentar på en bild.<br/>            Läs/skriv [`PointF`](/slides/python-net/sv/aspose.slides/pointf). |
| [`parent_comment`](/slides/python-net/sv/aspose.slides/comment/parent_comment/) | Hämtar eller anger överordnad kommentar.<br/>            Läs/skriv [`IComment`](/slides/python-net/sv/aspose.slides/icomment). |

## Metoder

| Metod | Beskrivning |
| :- | :- |
| [`remove(self)`](/slides/python-net/sv/aspose.slides/comment/remove/#) | Tar bort kommentaren och alla dess svar från den överordnade samlingen. |
