## NumberedBulletStyle enumeration

Representerar stilen för de numrerade punkterna.

Typen NumberedBulletStyle exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| NOT_DEFINED | Inte definierad. |
| BULLET_ALPHA_LC_PERIOD | Gemena alfabetiska tecken med en punkt. Exempel: a., b., c., ... |
| BULLET_ALPHA_UC_PERIOD | Versala alfabetiska tecken med en punkt. Exempel: A., B., C., ... |
| BULLET_ARABIC_PAREN_RIGHT | Arabiska siffror med avslutande parentes. Exempel: 1), 2), 3), ... |
| BULLET_ARABIC_PERIOD | Arabiska siffror med en punkt. Exempel: 1., 2., 3., ... |
| BULLET_ROMAN_LC_PAREN_BOTH | Gemena romerska siffror med båda parenteserna. Exempel: (i), (ii), (iii), ... |
| BULLET_ROMAN_LC_PAREN_RIGHT | Gemena romerska siffror med avslutande parentes. Exempel: i), ii), iii), ... |
| BULLET_ROMAN_LC_PERIOD | Gemena romerska siffror med punkt. Exempel: i., ii., iii., ... |
| BULLET_ROMAN_UC_PERIOD | Versala romerska siffror med punkt. Exempel: I., II., III., ... |
| BULLET_ALPHA_LC_PAREN_BOTH | Gemena alfabetiska tecken med båda parenteserna. Exempel: (a), (b), (c), ... |
| BULLET_ALPHA_LC_PAREN_RIGHT | Gemena alfabetiska tecken med avslutande parentes. Exempel: a), b), c), ... |
| BULLET_ALPHA_UC_PAREN_BOTH | Versala alfabetiska tecken med båda parenteserna. Exempel: (A), (B), (C), ... |
| BULLET_ALPHA_UC_PAREN_RIGHT | Versala alfabetiska tecken med avslutande parentes. Exempel: A), B), C), ... |
| BULLET_ARABIC_PAREN_BOTH | Arabiska siffror med båda parenteserna. Exempel: (1), (2), (3), ... |
| BULLET_ARABIC_PLAIN | Arabiska siffror. Exempel: 1, 2, 3, ... |
| BULLET_ROMAN_UC_PAREN_BOTH | Versala romerska siffror med båda parenteserna. Exempel: (I), (II), (III), ... |
| BULLET_ROMAN_UC_PAREN_RIGHT | Versala romerska siffror med avslutande parentes. Exempel: I), II), III), ... |
| BULLET_SIMP_CHIN_PLAIN | Förenklad kinesiska utan punkt. |
| BULLET_SIMP_CHIN_PERIOD | Förenklad kinesiska med punkt. |
| BULLET_CIRCLE_NUM_DB_PLAIN | Dubbla byte-cirkulära siffror för värden upp till 10, från 11 - arabiska siffror. |
| BULLET_CIRCLE_NUM_WD_WHITE_PLAIN | Textfärgad siffra med cirkel i samma färg runt den (Wingdings vita cirkelsiffror). Från 11 - arabiska siffror. |
| BULLET_CIRCLE_NUM_WD_BLACK_PLAIN | Skuggfärgad siffra med cirkulär bakgrund i normal textfärg (Wingdings svarta cirkelsiffror). |
| BULLET_TRAD_CHIN_PLAIN | Traditionell kinesiska utan punkt. |
| BULLET_TRAD_CHIN_PERIOD | Traditionell kinesiska med punkt. |
| BULLET_ARABIC_ALPHA_DASH | Arabiska alfabetiska tecken med ett bindestreck. |
| BULLET_ARABIC_ABJAD_DASH | Arabiska Abjad-alfabet med ett bindestreck. |
| BULLET_HEBREW_ALPHA_DASH | Hebreiska alfabetiska tecken med ett bindestreck. |
| BULLET_KANJI_KOREAN_PLAIN | Japanska/Koreanska siffror utan punkt. |
| BULLET_KANJI_KOREAN_PERIOD | Japanska/Koreanska siffror med punkt. |
| BULLET_ARABIC_DB_PLAIN | Dubbel-byte arabisk numreringsschema (utan skiljetecken). |
| BULLET_ARABIC_DB_PERIOD | Dubbel-byte arabisk numreringsschema med dubbel-byte punkt. |
| BULLET_THAI_ALPHA_PERIOD | Thailändskt alfabet med punkt. |
| BULLET_THAI_ALPHA_PAREN_RIGHT | Thailändskt alfabet parenteser - höger. |
| BULLET_THAI_ALPHA_PAREN_BOTH | Thailändskt alfabet parenteser - båda. |
| BULLET_THAI_NUM_PERIOD | Thailändska siffror med punkt. |
| BULLET_THAI_NUM_PAREN_RIGHT | Thailändska siffror parenteser - höger. |
| BULLET_THAI_NUM_PAREN_BOTH | Thailändska siffror parenteser - båda. |
| BULLET_HINDI_ALPHA_PERIOD | Hindi alfabet punkt - vokaler. |
| BULLET_HINDI_NUM_PERIOD | Hindi siffror med punkt. |
| BULLET_KANJI_SIMP_CHIN_DB_PERIOD | Kanji enkel kinesiska DB-period. |
| BULLET_HINDI_NUM_PAREN_RIGHT | Hindi siffror parenteser - höger. |
| BULLET_HINDI_ALPHA_1_PERIOD | Hindi alfabet punkt - konsonanter. |
