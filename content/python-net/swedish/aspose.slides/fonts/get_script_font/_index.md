## get_script_font(self, script) {#str}
Hämtar fontnamnet som är associerat med en specifik skripttagg från presentationens tema.

### Returnerar

Namnet på den font som används för det specifika skriptet, eller `None` om skriptet inte är definierat.

```python
def get_script_font(self, script):
    ...
```


| Parameter | Typ | Beskrivning |
| :- | :- | :- |
| script | **str** | BCP-47 skriptkod (t.ex. "Latn", "Cyrl", "Jpan") som används för att identifiera ett skriftsystem. |
