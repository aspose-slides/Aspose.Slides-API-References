## AdjustValue klass

Representerar ett geometriskt formes justeringsvärde.
            Dessa värden påverkar formens utseende.

Typen AdjustValue exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`raw_value`](/slides/python-net/sv/aspose.slides/adjustvalue/raw_value/) | Returnerar eller sätter justeringsvärdet "as is".<br/>            Läs/skriv **int**. |
| [`angle_value`](/slides/python-net/sv/aspose.slides/adjustvalue/angle_value/) | Returnerar eller sätter värdet, tolkat som en vinkel i grader.<br/>            Läs/skriv **float**. |
| [`name`](/slides/python-net/sv/aspose.slides/adjustvalue/name/) | Returnerar ett namn på detta justeringsvärde.<br/>            Endast läsning **str**. |
| [`type`](/slides/python-net/sv/aspose.slides/adjustvalue/type/) | Returnerar typen av formjusteringen.<br/>            Endast läsning [`ShapeAdjustmentType`](/slides/python-net/sv/aspose.slides/shapeadjustmenttype). |
