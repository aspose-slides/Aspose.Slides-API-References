## SlideShowSettings klass

Representerar bildspelsinställningarna för presentationen.

SlideShowSettings-typen exponerar följande medlemmar:

## Egenskaper

| Property | Description |
| :- | :- |
| [`slide_show_type`](/slides/python-net/sv/aspose.slides/slideshowsettings/slide_show_type/) | Hämtar eller anger bildspels-typen. Representeras av följande [`SlideShowSettings.slide_show_type`](/slides/python-net/sv/aspose.slides/slideshowsettings/slide_show_type)-förfäder: [`BrowsedAtKiosk`](/slides/python-net/sv/aspose.slides/browsedatkiosk), [`PresentedBySpeaker`](/slides/python-net/sv/aspose.slides/presentedbyspeaker) och [`BrowsedByIndividual`](/slides/python-net/sv/aspose.slides/browsedbyindividual) |
| [`loop`](/slides/python-net/sv/aspose.slides/slideshowsettings/loop/) | Loop bildspel |
| [`show_narration`](/slides/python-net/sv/aspose.slides/slideshowsettings/show_narration/) | Visa berättelse i bildspel |
| [`show_animation`](/slides/python-net/sv/aspose.slides/slideshowsettings/show_animation/) | Visa animation i bildspel |
| [`pen_color`](/slides/python-net/sv/aspose.slides/slideshowsettings/pen_color/) | Pen-färg för bildspel |
| [`slides`](/slides/python-net/sv/aspose.slides/slideshowsettings/slides/) | Bildintervall |
| [`use_timings`](/sv/slides/python-net/aspose.slides/slideshowsettings/use_timings/) | Använd tidsinställningar i bildspel |
| [`show_media_controls`](/slides/python-net/sv/aspose.slides/slideshowsettings/show_media_controls/) | Visa mediekontroller |
