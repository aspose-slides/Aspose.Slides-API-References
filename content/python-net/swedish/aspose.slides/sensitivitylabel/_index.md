## SensitivityLabel klass

Representerar känslighetsetiketten från Microsoft Purview Information Protection.

SensitivityLabel-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`id`](/slides/python-net/sv/aspose.slides/sensitivitylabel/id/) | Returnerar eller anger id för känslighetsetiketten.<br/>            Läs/skriv **str**. |
| [`site_id`](/slides/python-net/sv/aspose.slides/sensitivitylabel/site_id/) | Returnerar eller anger Azure Active Directory (Azure AD) webbplatsidentifieraren <br/>            som motsvarar policyn för känslighetsetiketten som beskriver känslighetsetiketten.<br/>            Läs/skriv **System.Guid**. |
| [`is_enabled`](/slides/python-net/sv/aspose.slides/sensitivitylabel/is_enabled/) | Indikerar om känslighetsetiketten är aktiverad. |
| [`is_removed`](/slides/python-net/sv/aspose.slides/sensitivitylabel/is_removed/) | Indikerar om känslighetsetiketten har tagits bort. |
| [`assignment_method_type`](/slides/python-net/sv/aspose.slides/sensitivitylabel/assignment_method_type/) | Returnerar eller anger tilldelningsmetoden för känslighetsetiketten.<br/>            Läs/skriv [`SensitivityLabelAssignmentType`](/slides/python-net/sv/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/sv/aspose.slides/sensitivitylabel/content_mark_types/) | Returnerar listan över typer av innehållsmärkning som bör tillämpas på en fil. |
