## height egenskap
Returnerar eller anger bullet height för ett stycke utan arv.
            Value float.NaN bestämmer att bullet ärver height från den första delen i stycket.
            Läs/skriv **float**.


### Anmärkningar

Ett negativt height-värde betyder att height anges i punkter och
            ett positivt värde betyder att height är en procentsats av den omgivande texten.
