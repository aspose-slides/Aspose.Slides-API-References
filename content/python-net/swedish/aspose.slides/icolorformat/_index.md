## IColorFormat klass

Representerar en färg som används i en presentation.

IColorFormat-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`color_type`](/slides/python-net/sv/aspose.slides/icolorformat/color_type/) | Returnerar eller anger färgdefinitionsmetoden.<br/>            Läs/skriv [`ColorType`](/slides/python-net/sv/aspose.slides/colortype). |
| [`color`](/slides/python-net/sv/aspose.slides/icolorformat/color/) | Returnerar den resulterande färgen (med alla färgtransformeringar tillämpade).<br/>            Anger RGB-färger och rensar alla färgtransformeringar.<br/>            Läs/skriv **aspose.slides.Color**. |
| [`preset_color`](/slides/python-net/sv/aspose.slides/icolorformat/preset_color/) | Returnerar eller anger färgförinställningen.<br/>            Läs/skriv [`PresetColor`](/slides/python-net/sv/aspose.slides/presetcolor). |
| [`system_color`](/slides/python-net/sv/aspose.slides/icolorformat/system_color/) | Returnerar eller anger färgen som identifieras av systemets färgtabell.<br/>            Läs/skriv [`SystemColor`](/slides/python-net/sv/aspose.slides/systemcolor). |
| [`scheme_color`](/slides/python-net/sv/aspose.slides/icolorformat/scheme_color/) | Returnerar eller anger färgen som identifieras av ett färgschema.<br/>            Läs/skriv [`SchemeColor`](/slides/python-net/sv/aspose.slides/schemecolor). |
| [`r`](/slides/python-net/sv/aspose.slides/icolorformat/r/) | Returnerar eller anger den röda komponenten i en färg. Alla färgtransformeringar ignoreras.<br/>            Läs/skriv **int**. |
| [`g`](/slides/python-net/sv/aspose.slides/icolorformat/g/) | Returnerar eller anger den gröna komponenten i en färg. Alla färgtransformeringar ignoreras.<br/>            Läs/skriv **int**. |
| [`b`](/slides/python-net/sv/aspose.slides/icolorformat/b/) | Returnerar eller anger den blåa komponenten i en färg. Alla färgtransformeringar ignoreras.<br/>            Läs/skriv **int**. |
| [`float_r`](/slides/python-net/sv/aspose.slides/icolorformat/float_r/) | Returnerar eller anger den röda komponenten i en färg. Alla färgtransformeringar ignoreras.<br/>            Läs/skriv **float**. |
| [`float_g`](/slides/python-net/sv/aspose.slides/icolorformat/float_g/) | Returnerar eller anger den gröna komponenten i en färg. Alla färgtransformeringar ignoreras.<br/>            Läs/skriv **float**. |
| [`float_b`](/slides/python-net/sv/aspose.slides/icolorformat/float_b/) | Returnerar eller anger den blåa komponenten i en färg. Alla färgtransformeringar ignoreras.<br/>            Läs/skriv **float**. |
| [`hue`](/slides/python-net/sv/aspose.slides/icolorformat/hue/) | Returnerar eller anger nyanskomponenten i en färg i HSL-representation.<br/>            Alla färgtransformeringar ignoreras.<br/>            Läs/skriv **float**. |
| [`saturation`](/slides/python-net/sv/aspose.slides/icolorformat/saturation/) | Returnerar eller anger mättnadskomponenten i en färg i HSL-representation.<br/>            Alla färgtransformeringar ignoreras.<br/>            Läs/skriv **float**. |
| [`luminance`](/slides/python-net/sv/aspose.slides/icolorformat/luminance/) | Returnerar eller anger luminanskomponenten i en färg i HSL-representation.<br/>            Alla färgtransformeringar ignoreras.<br/>            Läs/skriv **float**. |
| [`color_transform`](/slides/python-net/sv/aspose.slides/icolorformat/color_transform/) | Returnerar samlingen av färgtransformeringar som tillämpas på en färg.<br/>            Skrivskyddad [`IColorOperationCollection`](/slides/python-net/sv/aspose.slides/icoloroperationcollection). |
