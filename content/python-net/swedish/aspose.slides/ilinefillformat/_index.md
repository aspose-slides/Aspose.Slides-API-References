## ILineFillFormat klass

Representerar egenskaper för fyllning av linjer.

ILineFillFormat-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`fill_type`](/slides/python-net/sv/aspose.slides/ilinefillformat/fill_type/) | Returnerar eller anger fyllningstypen.<br/>            Läs/skriv [`FillType`](/slides/python-net/sv/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/sv/aspose.slides/ilinefillformat/solid_fill_color/) | Returnerar färgen på en solid fyllning.<br/>            Endast läsning [`IColorFormat`](/slides/python-net/sv/aspose.slides/icolorformat). |

| [`pattern_format`](/slides/python-net/sv/aspose.slides/ilinefillformat/pattern_format/) | Returnerar mönsterfyllningsformatet.<br/>            Endast läsning [`IPatternFormat`](/slides/python-net/sv/aspose.slides/ipatternformat). |
| [`rotate_with_shape`](/slides/python-net/sv/aspose.slides/ilinefillformat/rotate_with_shape/) | Bestämmer om fyllningen ska roteras med en form.<br/>            Läs/skriv [`NullableBool`](/slides/python-net/sv/aspose.slides/nullablebool). |
