## ICommentAuthor klass

Representerar en författare till kommentarer.

ICommentAuthor-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`name`](/slides/python-net/sv/aspose.slides/icommentauthor/name/) | Returnerar eller anger författarens namn.<br/>            Läs/skriv **str**. |
| [`initials`](/slides/python-net/sv/aspose.slides/icommentauthor/initials/) | Returnerar eller anger författarens initialer.<br/>            Läs/skriv **str**. |
| [`comments`](/slides/python-net/sv/aspose.slides/icommentauthor/comments/) | Returnerar samlingen av kommentarer som gjorts av denna författare.<br/>            Skriftskyddad [`ICommentCollection`](/slides/python-net/sv/aspose.slides/icommentcollection). |

## Metoder

| Metod | Beskrivning |
| :- | :- |
| [`remove(self)`](/slides/python-net/sv/aspose.slides/icommentauthor/remove/#) | Tar bort författaren från den överordnade samlingen. |
