## Size-klass

Lagrar ett ordnat par heltal som specificerar en bredd och en höjd. Kompatibel med .NET `System.Drawing.Size`.

Typen Size exponerar följande medlemmar:

## Konstruktörer

| Konstruktor | Beskrivning |
| :- | :- |
| [`__init__(self, width=0, height=0)`](/slides/python-net/sv/aspose.slides/size/__init__/#int-int) | Skapar en Size med den specificerade bredden och höjden. Flyttal trunkeras till heltal. |

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`width`](/slides/python-net/sv/aspose.slides/size/width/) | Hämtar den horisontella komponenten i denna Size.<br/>            Skrivskyddad **int**. |
| [`height`](/slides/python-net/sv/aspose.slides/size/height/) | Hämtar den vertikala komponenten i denna Size.<br/>            Skrivskyddad **int**. |


### Kommentarer

Storlekar jämförs efter deras komponenter med `==` och kan användas som nycklar i ordböcker eller som medlemmar i mängder.
