## ModernComment klass

Representerar en kommentar på en bild.

**Arv:**[`ModernComment`](/slides/python-net/sv/aspose.slides/moderncomment) → [`Comment`](/slides/python-net/sv/aspose.slides/comment)

ModernComment-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`text`](/slides/python-net/sv/aspose.slides/moderncomment/text/) | Returnerar eller anger vanlig text för en bildkommentar.<br/>            Läs/skriv **str**. |
| [`created_time`](/slides/python-net/sv/aspose.slides/moderncomment/created_time/) | Returnerar eller anger tiden för en kommentarens skapande.<br/>            Att ange denna egenskap till **System.DateTime** betyder att ingen kommentarstid är satt.<br/>            Läs/skriv **System.DateTime**. |
| [`slide`](/slides/python-net/sv/aspose.slides/moderncomment/slide/) | Returnerar eller anger föräldrabilden för en kommentar.<br/>            Endast läs [`ISlide`](/slides/python-net/sv/aspose.slides/islide). |
| [`author`](/slides/python-net/sv/aspose.slides/moderncomment/author/) | Returnerar författaren till en kommentar.<br/>            Endast läs [`ICommentAuthor`](/slides/python-net/sv/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/sv/aspose.slides/moderncomment/position/) | Returnerar eller anger positionen för en kommentar på en bild.<br/>            Läs/skriv [`PointF`](/slides/python-net/sv/aspose.slides/pointf). |
| [`parent_comment`](/slides/python-net/sv/aspose.slides/moderncomment/parent_comment/) | Hämtar eller anger föräldrakommentar.<br/>            Läs/skriv [`IComment`](/slides/python-net/sv/aspose.slides/icomment). |
| [`shape`](/slides/python-net/sv/aspose.slides/moderncomment/shape/) | Returnerar en form som är associerad med kommentaren.<br/>            Endast läs [`IShape`](/slides/python-net/sv/aspose.slides/ishape). |
| [`text_selection_start`](/slides/python-net/sv/aspose.slides/moderncomment/text_selection_start/) | Hämtar eller anger startpositionen för textmarkering i textrutan om kommentaren är associerad med AutoShape.<br/>            Läs/skriv **int**. |
| [`text_selection_length`](/slides/python-net/sv/aspose.slides/moderncomment/text_selection_length/) | Hämtar eller anger längden på textmarkeringen i textrutan om kommentaren är associerad med AutoShape.<br/>            Läs/skriv **int**. |
| [`status`](/slides/python-net/sv/aspose.slides/moderncomment/status/) | Hämtar eller anger statusen för kommentaren.<br/>            Läs/skriv [`ModernCommentStatus`](/slides/python-net/sv/aspose.slides/moderncommentstatus). |

## Metoder

| :- | :- |
