## AudioPlayModePreset uppräkning

Konstanter som definierar hur ett ljud spelas.

Typen AudioPlayModePreset exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| MIXED |  |
| AUTO | Spela automatiskt. |
| ON_CLICK | Spela endast när ikonen klickas på. |
| ALL_SLIDES | Spela på alla bilder. <br/>            Använd [`IAudioFrame.play_across_slides`](/slides/python-net/sv/aspose.slides/iaudioframe/play_across_slides) egenskap istället.<br/>            Detta element är föråldrat sedan PowerPoint 2013. |
| IN_CLICK_SEQUENCE | Spela automatiskt med ett klick. |
