## TextAutofitType enumeration

Representerar textautofitläge.

TextAutofitType-typen visar följande medlemmar:

## Fält

| Field | Description |
| :- | :- |
| NOT_DEFINED | Ej definierad. |
| NONE | Ingen autofit. |
| NORMAL | Normal autofit. Teckenstorlek och radavstånd kommer att minskas för att passa formen. |
| SHAPE | Formautofit. Formens storlek kommer att ändras för att passa texten. |
