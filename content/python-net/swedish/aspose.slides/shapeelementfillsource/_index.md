## ShapeElementFillSource uppräkning

Representerar hur formelementet ska fyllas.

Typen ShapeElementFillSource exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| NO_FILL | Fyll inte primitiv. |
| SHAPE | Använd formens fyllning. |
| LIGHTEN | Använd ljusare fyllning av formen. |
| LIGHTEN_LESS | Använd mindre ljus fyllning av formen. |
| DARKEN | Använd mörkare fyllning av formen. |
| DARKEN_LESS | Använd mindre mörk fyllning av formen. |
