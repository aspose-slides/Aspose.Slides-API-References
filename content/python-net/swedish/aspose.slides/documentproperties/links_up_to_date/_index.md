## links_up_to_date egenskap
Anger om hyperlänkar i ett dokument är uppdaterade. 
Ställ in detta element till **true** för att ange att hyperlänkar är uppdaterade. 
Ställ in detta element till **false** för att ange att hyperlänkar är föråldrade.
Läs/skriv **bool**.
