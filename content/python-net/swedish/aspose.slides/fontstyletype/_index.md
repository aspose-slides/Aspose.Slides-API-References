## FontStyleType uppräkning

Definierar formateringsstilar som kan tillämpas på text.

FontStyleType-typen exponeras följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| REGULAR | Standardtext. |
| BOLD | Fet text. |
| ITALIC | Kursiv text. |
| UNDERLINE | Understruken text. |
| STRIKEOUT | Text genomstruken med en horisontell linje. |
