## fill_style_index egenskap
Returnerar eller anger figurens fyllningskolumnindex i stilmatriser.
            0 betyder ingen fyllning,
            positivt värde - index i temats fyllningsstilar,
            negativt värde - index i temats bakgrundsstilar.
            Läs/skriv **int**.
