## IShapeStyle class

Representerar formens stilreferens.

IShapeStyle-typen exponerar följande medlemmar:

## Egenskaper

| Property | Description |
| :- | :- |
| [`line_color`](/slides/python-net/sv/aspose.slides/ishapestyle/line_color/) | Returnerar formens konturfärg.<br/>            Skrivskyddad [`IColorFormat`](/slides/python-net/sv/aspose.slides/icolorformat). |
| [`line_style_index`](/slides/python-net/sv/aspose.slides/ishapestyle/line_style_index/) | Returnerar eller anger radens kolumnindex i en stilmatris.<br/>            Läs/skriv **int**. |
| [`fill_color`](/slides/python-net/sv/aspose.slides/ishapestyle/fill_color/) | Returnerar formens fyllningsfärg.<br/>            Skrivskyddad [`IColorFormat`](/slides/python-net/sv/aspose.slides/icolorformat). |
| [`fill_style_index`](/slides/python-net/sv/aspose.slides/ishapestyle/fill_style_index/) | Returnerar eller anger formens fyllningskolumnindex i stilmatriser.<br/>            0 betyder ingen fyllning,<br/>            positivt värde - index i temats fyllningsstilar,<br/>            negativt värde - index i temats bakgrundsstilar.<br/>            Läs/skriv **int**. |
| [`effect_color`](/slides/python-net/sv/aspose.slides/ishapestyle/effect_color/) | Returnerar formens effektsfärg.<br/>            Skrivskyddad [`IColorFormat`](/slides/python-net/sv/aspose.slides/icolorformat). |
| [`effect_style_index`](/slides/python-net/sv/aspose.slides/ishapestyle/effect_style_index/) | Returnerar eller anger formens effektkolumnindex i en stilmatris.<br/>            Läs/skriv **int**. |
| [`font_color`](/slides/python-net/sv/aspose.slides/ishapestyle/font_color/) | Returnerar formens teckensnittsfärg.<br/>            Skrivskyddad [`IColorFormat`](/slides/python-net/sv/aspose.slides/icolorformat). |
| [`font_collection_index`](/slides/python-net/sv/aspose.slides/ishapestyle/font_collection_index/) | Returnerar eller anger formens teckensnittindex i en teckensnittssamling.<br/>            Läs/skriv [`FontCollectionIndex`](/slides/python-net/sv/aspose.slides/fontcollectionindex). |
