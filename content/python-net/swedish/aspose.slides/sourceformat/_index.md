## SourceFormat enumeration

Representerar källfilformat.

SourceFormat-typen visar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| PPT | Microsoft PowerPoint 97-2003-presentation (*.ppt). |
| PPTX | Microsoft Office Open XML-presentation (*.pptx). |
| ODP | OpenDocument-presentation (*.odp). |
| PPTM | Microsoft Office Open XML-makroaktiverad presentation (*.pptm). |
| PPSX | Microsoft Office Open XML bildspel (*.ppsx). |
| PPSM | Microsoft Office Open XML-makroaktiverat bildspel (*.ppsm). |
| POTX | Microsoft Office Open XML-mall (*.potx). |
| POTM | Microsoft Office Open XML-makroaktiverad mall (*.potm). |
| PPS | Microsoft PowerPoint 97-2003 bildspel (*.pps). |
| POT | Microsoft PowerPoint 97-2003 mall (*.pot). |
| OTP | OpenDocument presentationsmall (*.otp). |
| FODP | Platt XML ODF-presentation (*.fodp). |
| XML | PowerPoint XML-presentation (*.xml). |
