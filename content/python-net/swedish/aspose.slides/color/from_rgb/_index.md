## from_rgb(r, g, b) {#int-int-int}
Skapar en ogenomskinlig färg (alpha är 255) från de angivna röda, gröna och blåa värdena.

### Returnerar

Färgen som skapats från de angivna värdena.



```python
@staticmethod
def from_rgb(r, g, b):
    ...
```


| Parameter | Typ | Beskrivning |
| :- | :- | :- |
| r | **int** | Det röda komponentvärdet. Giltiga värden är 0 till 255. |
| g | **int** | Det gröna komponentvärdet. Giltiga värden är 0 till 255. |
| b | **int** | Det blåa komponentvärdet. Giltiga värden är 0 till 255. |

### Undantag

| Undantag | Beskrivning |
| :- | :- |
| **ValueError** | Ett komponentvärde är mindre än 0 eller större än 255. |
