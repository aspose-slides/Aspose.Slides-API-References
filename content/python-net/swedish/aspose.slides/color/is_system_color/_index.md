## is_system_color egenskap
Anger om denna färg är en systemfärg: en färg som används för ett Windows-display-element, såsom `Control` eller `ActiveBorder`.<br/>            Systemfärger exponeras inte som `Color`-attribut och kan endast erhållas med [`from_known_color`](/slides/python-net/sv/aspose.slides/color/from_known_color/) eller returneras från biblioteket.
            Skrivskyddad **bool**.
