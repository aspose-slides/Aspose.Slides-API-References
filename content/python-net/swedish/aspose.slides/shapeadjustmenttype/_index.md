## ShapeAdjustmentType-enumeration

Specificerar olika typer av justeringsvärden för former.

Typen ShapeAdjustmentType exponerar följande medlemmar:

## Fält

| Field | Beskrivning |
| :- | :- |
| CUSTOM | Anpassad typ (okänd justering) |
| CORNER_SIZE | Styr storleken på hörnen. |
| LEFT_UP_CORNER | Styr det övre vänstra hörnet. |
| RIGHT_UP_CORNER | Styr det övre högra hörnet. |
| UP_CORNERS | Styr de övre hörnen. |
| DOWN_CORNERS | Styr de nedre hörnen. |
| THICKNESS | Styr figurens tjocklek. |
| ARROW_TAIL_THICKNESS | Styr tjockleken på pilens svans. |
| ARROWHEAD_LENGTH | Styr längden på pilspetsen. |
| ARROWHEAD_WIDTH | Styr bredden på pilspetsen. |
| RADIUS | Styr radiestorleken på formen eller dess del. |
| DEPTH | Styr djupet på kuggtandarna eller avfasningseffekten. |
| SHAPE_PART_OFFSET | Styr förskjutningen av en del av figuren relativt en annan. |
| ANGLE | Styr vinkeln för figuren eller dess del. |
| START_ANGLE | Startvinkel för paj- och bågformer. |
| END_ANGLE | Slutvinkel för paj- och bågformer. |
| START_POINT_X | Styr X-positionen för samtalsruta startpunkt. |
| START_POINT_Y | Styr Y-positionen för samtalsruta startpunkt. |
| CONNECTOR_POINT_1X | Styr den horisontella positionen för justeringspunkten för samtalsrutans vinkel. |
| CONNECTOR_POINT_1Y | Styr den vertikala positionen för justeringspunkten för samtalsrutans vinkel. |
| CONNECTOR_POINT_2X | Styr den horisontella positionen för justeringspunkten för samtalsrutans vinkel. |
| CONNECTOR_POINT_2Y | Styr den vertikala positionen för justeringspunkten för samtalsrutans vinkel. |
| CONNECTOR_BEND_POSITION_X | Styr den horisontella positionen för böjningen i anslutningen. |
| CONNECTOR_BEND_POSITION_Y | Styr den vertikala positionen för böjningen i anslutningen. |
| ATTACH_Y | Styr den vertikala fästpunkten för figuren. |
| ATTACH_X | Styr den horisontella fästpunkten för figuren. |
| CALLOUT_HEIGHT | Styr den vertikala storleken på samtalsrutan. |
| CALLOUT_WIDTH | Styr den horisontella storleken på samtalsrutan. |
| CALLOUT_SIZE | Styr storleken på samtalsrutan. |
| CURVATURE | Kurvatur för en böjd, stödjande, krökt pil eller form. |
| HORIZONTAL_THICKNESS | Styr den horisontella tjockleken på hörnformen. |
| VERTICAL_THICKNESS | Styr den vertikala tjockleken på hörnformen. |
| VERTICAL_SIZE | Styr den vertikala storleken på formen. |
| HORIZONTAL_SIZE | Styr den horisontella storleken på formen. |
| TOP | Styr den övre sidan av en form. |
