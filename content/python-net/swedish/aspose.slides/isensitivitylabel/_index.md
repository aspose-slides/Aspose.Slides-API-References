## ISensitivityLabel klass

Representerar känslighetsetiketten från Microsoft Purview Information Protection.

ISensitivityLabel-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`id`](/slides/python-net/sv/aspose.slides/isensitivitylabel/id/) | Returnerar eller anger id för känslighetsetikett.<br/>            Read/write **str**. |
| [`site_id`](/slides/python-net/sv/aspose.slides/isensitivitylabel/site_id/) | Returnerar eller anger Azure Active Directory (Azure AD)-platsidentifieraren <br/>            som motsvarar policyn för känslighetsetikett som beskriver känslighetsetiketten.<br/>            Read/write **System.Guid**. |
| [`is_enabled`](/slides/python-net/sv/aspose.slides/isensitivitylabel/is_enabled/) | Anger om känslighetsetiketten är aktiverad. |
| [`is_removed`](/slides/python-net/sv/aspose.slides/isensitivitylabel/is_removed/) | Anger om känslighetsetiketten har tagits bort. |
| [`assignment_method_type`](/slides/python-net/sv/aspose.slides/isensitivitylabel/assignment_method_type/) | Returnerar eller anger tilldelningsmetoden för känslighetsetiketten.<br/>            Read/write [`SensitivityLabelAssignmentType`](/slides/python-net/sv/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/sv/aspose.slides/isensitivitylabel/content_mark_types/) | Returnerar listan över typer av innehållsmärkning som bör tillämpas på en fil. |
