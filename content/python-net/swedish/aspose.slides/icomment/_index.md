## IComment-klass

Representerar en kommentar på en bild.

Typen IComment exponerar följande medlemmar:

## Egenskaper

| Property | Description |
| :- | :- |
| [`text`](/slides/python-net/sv/aspose.slides/icomment/text/) | Returnerar eller anger vanlig text för en bildkommentar.<br/>            Läs/skriv **str**. |
| [`created_time`](/slides/python-net/sv/aspose.slides/icomment/created_time/) | Returnerar eller anger tiden för en kommentarskapning.<br/>            Att sätta denna egenskap till **System.DateTime** betyder att ingen kommentartid är angiven.<br/>            Läs/skriv **System.DateTime**. |
| [`slide`](/slides/python-net/sv/aspose.slides/icomment/slide/) | Returnerar eller anger föräldrabilden för en kommentar.<br/>            Skrivskyddad [`ISlide`](/slides/python-net/sv/aspose.slides/islide). |
| [`author`](/slides/python-net/sv/aspose.slides/icomment/author/) | Returnerar författaren till en kommentar.<br/>            Skrivskyddad [`ICommentAuthor`](/slides/python-net/sv/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/sv/aspose.slides/icomment/position/) | Returnerar eller anger positionen för en kommentar på en bild.<br/>            Läs/skriv [`PointF`](/slides/python-net/sv/aspose.slides/pointf). |
| [`parent_comment`](/slides/python-net/sv/aspose.slides/icomment/parent_comment/) | Hämtar eller anger föräldrakommentar.<br/>            Läs/skriv [`IComment`](/slides/python-net/sv/aspose.slides/icomment). |

## Metoder

| Method | Description |
| :- | :- |
| [`remove(self)`](/slides/python-net/sv/aspose.slides/icomment/remove/#) | Tar bort kommentaren och alla dess svar från föräldersamlingen. |
