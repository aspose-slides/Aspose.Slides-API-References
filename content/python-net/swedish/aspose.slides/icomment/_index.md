## IComment klass

Representerar en kommentar på en bild.

IComment-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`text`](/slides/python-net/sv/aspose.slides/icomment/text/) | Returnerar eller anger den rena texten för en bildkommentar.<br/>            Läs/skriv **str**. |
| [`created_time`](/slides/python-net/sv/aspose.slides/icomment/created_time/) | Returnerar eller anger tidpunkten för en kommentarsskapande.<br/>            Att sätta denna egenskap till **System.DateTime** innebär att ingen kommentarstid är angiven.<br/>            Läs/skriv **System.DateTime**. |
| [`slide`](/slides/python-net/sv/aspose.slides/icomment/slide/) | Returnerar eller anger den överordnade bilden för en kommentar.<br/>            Endast läsning [`ISlide`](/slides/python-net/sv/aspose.slides/islide). |
| [`author`](/slides/python-net/sv/aspose.slides/icomment/author/) | Returnerar författaren till en kommentar.<br/>            Endast läsning [`ICommentAuthor`](/slides/python-net/sv/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/sv/aspose.slides/icomment/position/) | Returnerar eller anger positionen för en kommentar på en bild.<br/>            Läs/skriv **aspose.slides.PointF**. |
| [`parent_comment`](/slides/python-net/sv/aspose.slides/icomment/parent_comment/) | Returnerar eller anger överordnad kommentar.<br/>            Läs/skriv [`IComment`](/slides/python-net/sv/aspose.slides/icomment). |

## Metoder

| Metod | Beskrivning |
| :- | :- |
| [`remove(self)`](/slides/python-net/sv/aspose.slides/icomment/remove/#) | Tar bort kommentaren och alla dess svar från den överordnade samlingen. |
