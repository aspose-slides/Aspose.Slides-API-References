## ICameraEffectiveData klass

Oföränderligt objekt som innehåller effektiva kamerainställningar.

Typen ICameraEffectiveData exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`camera_type`](/slides/python-net/sv/aspose.slides/icameraeffectivedata/camera_type/) | Kameratyp.<br/>            Skrivskyddad [`CameraPresetType`](/slides/python-net/sv/aspose.slides/camerapresettype). |
| [`field_of_view_angle`](/slides/python-net/sv/aspose.slides/icameraeffectivedata/field_of_view_angle/) | Kamerans FOV (0-180 grader, synfält).<br/>            Skrivskyddad **float**. |
| [`zoom`](/slides/python-net/sv/aspose.slides/icameraeffectivedata/zoom/) | Kamerany zoom (positivt värde i procent).<br/>            Skrivskyddad **float**. |
