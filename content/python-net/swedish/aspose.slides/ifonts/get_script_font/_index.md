## get_script_font(self, script) {#str}
Hämtar teckensnittets namn som är associerat med en specifik skripttagg från presentationens tema.

### Returnerar

Namnet på teckensnittet som används för det angivna skriptet, eller `None` om skriptet inte är definierat.

```python
def get_script_font(self, script):
    ...
```


| Parameter | Typ | Beskrivning |
| :- | :- | :- |
| script | **str** | BCP-47-skriptkoden (t.ex. "Latn", "Cyrl", "Jpan") som används för att identifiera ett skriftsystem. |
