## IFonts klass

Representerar en samling av typsnitt.

IFonts-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`latin_font`](/slides/python-net/sv/aspose.slides/ifonts/latin_font/) | Returnerar eller anger det latinska typsnittet.<br/>            Läs/skriv [`IFontData`](/slides/python-net/sv/aspose.slides/ifontdata). |
| [`east_asian_font`](/slides/python-net/sv/aspose.slides/ifonts/east_asian_font/) | Returnerar eller anger det östasiatiska typsnittet.<br/>            Läs/skriv [`IFontData`](/slides/python-net/sv/aspose.slides/ifontdata). |
| [`complex_script_font`](/slides/python-net/sv/aspose.slides/ifonts/complex_script_font/) | Returnerar eller anger det komplexa skript-typsnittet.<br/>            Läs/skriv [`IFontData`](/slides/python-net/sv/aspose.slides/ifontdata). |

## Metoder

| Metod | Beskrivning |
| :- | :- |
| [`get_script_font_map(self)`](/slides/python-net/sv/aspose.slides/ifonts/get_script_font_map/#) | Returnerar en lista med alla sträng-sträng-par för skript-typsnittsdefinitioner i presentationen. |
| [`get_script_font(self, script)`](/slides/python-net/sv/aspose.slides/ifonts/get_script_font/#str) | Hämtar typsnittsnamnet som är associerat med en specifik skripttagg från presentationens tema. |
| [`set_script_font(self, script, font_name)`](/slides/python-net/sv/aspose.slides/ifonts/set_script_font/#str-str) | Tilldelar ett typsnittsnamn till en specifik skripttagg, vilket definierar hur text i det skriptet kommer att renderas i presentationen. |
| [`remove_script_font(self, script)`](/slides/python-net/sv/aspose.slides/ifonts/remove_script_font/#str) | Tar bort typsnittsinställningen som är associerad med en specifik skripttagg från temats typsnittssamling. |
