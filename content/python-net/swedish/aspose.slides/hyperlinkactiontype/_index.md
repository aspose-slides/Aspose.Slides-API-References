## HyperlinkActionType enumeration

Representerar en typ av hyperlänksåtgärd.

Typen HyperlinkActionType exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| UNKNOWN | Okänd åtgärdstyp. |
| NO_ACTION | Ingen åtgärd. |
| HYPERLINK | Vanlig hyperlänk. |
| JUMP_FIRST_SLIDE | Hoppa till den första bilden i presentationen. |
| JUMP_PREVIOUS_SLIDE | Hoppa till föregående bild. |
| JUMP_NEXT_SLIDE | Hoppa till nästa bild. |
| JUMP_LAST_SLIDE | Hoppa till den sista bilden i presentationen. |
| JUMP_END_SHOW | Hoppa till slutet av bildspelet. |
| JUMP_LAST_VIEWED_SLIDE | Hoppa till den senast visade bilden. |
| JUMP_SPECIFIC_SLIDE | Hoppa till en specifik bild, refererad av egenskapen [`IHyperlink.target_slide`](/slides/python-net/sv/aspose.slides/ihyperlink/target_slide). |
| START_CUSTOM_SLIDE_SHOW | Starta anpassat bildspel. |
| OPEN_FILE | Öppna refererad fil. |
| OPEN_PRESENTATION | Öppna refererad presentation. |
| START_STOP_MEDIA | Starta/stoppa uppspelning av mediefil. |
| START_MACRO | Starta körning av makroskript. |
| START_PROGRAM | Starta program. |
