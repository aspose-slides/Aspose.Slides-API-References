## IFontFallBackRule klass

Representerar fontfallback-regel

Typen IFontFallBackRule exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`range_start_index`](/slides/python-net/sv/aspose.slides/ifontfallbackrule/range_start_index/) | Hämtar första indexet för ett kontinuerligt Unicode-intervall. |
| [`range_end_index`](/slides/python-net/sv/aspose.slides/ifontfallbackrule/range_end_index/) | Hämtar sista indexet för ett kontinuerligt Unicode-intervall. |
| [`count`](/slides/python-net/sv/aspose.slides/ifontfallbackrule/count/) | Hämtar antalet typsnitt som faktiskt definierats för intervallet. |

Hämtar typsnittsnamnet på det angivna indexet.
