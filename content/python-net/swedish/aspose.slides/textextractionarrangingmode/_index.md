## TextExtractionArrangingMode uppräkning

Representerar läget som ska användas vid textutdragning

Typen TextExtractionArrangingMode exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| UNARRANGED | Rå text utan hänsyn till position på bilden |
| ARRANGED | Texten är placerad i samma ordning som på bilden |
