## Captions klass

Representerar WebVTT-stängda undertexter.

Captions-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`caption_id`](/slides/python-net/sv/aspose.slides/captions/caption_id/) | Returnerar den globalt unika identifieraren (GUID) för de stängda undertexterna.<br/>            Skrivskyddad **System.Guid**. |
| [`label`](/slides/python-net/sv/aspose.slides/captions/label/) | Returnerar eller anger etiketten för de stängda undertexterna.<br/>            Läs/skriv **str**. |
| [`binary_data`](/slides/python-net/sv/aspose.slides/captions/binary_data/) | Returnerar de binära data för de stängda undertexterna.<br/>            Skrivskyddad **int**[]. |
| [`data_as_string`](/slides/python-net/sv/aspose.slides/captions/data_as_string/) | Returnerar de stängda undertexternas data som en UTF-8-kodad sträng<br/>            Skrivskyddad **str**. |
