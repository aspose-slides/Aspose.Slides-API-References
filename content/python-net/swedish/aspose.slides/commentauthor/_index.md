## CommentAuthor klass

Representerar en författare av kommentarer.

CommentAuthor-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`name`](/slides/python-net/sv/aspose.slides/commentauthor/name/) | Returnerar eller anger författarens namn.<br/>            Läs/skriv **str**. |
| [`initials`](/slides/python-net/sv/aspose.slides/commentauthor/initials/) | Returnerar eller anger författarens initialer.<br/>            Läs/skriv **str**. |
| [`comments`](/slides/python-net/sv/aspose.slides/commentauthor/comments/) | Returnerar samlingen av kommentarer som gjorts av denna författare.<br/>            Skrivskyddad [`ICommentCollection`](/slides/python-net/sv/aspose.slides/icommentcollection). |

## Metoder

| Metod | Beskrivning |
| :- | :- |
