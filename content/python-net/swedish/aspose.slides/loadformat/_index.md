## LoadFormat uppräkning

Anger formatet för dokumentet som ska laddas.

LoadFormat-typen exponerar följande medlemmar:

## Fält

| Field | Description |
| :- | :- |
| AUTO | Instruerar Aspose.Slides att känna igen formatet automatiskt. |
| PPT | Microsoft PowerPoint 97-2003-presentation. |
| PPS | Microsoft PowerPoint 97-2003 Bildspel. |
| PPTX | Microsoft Office Open XML PresentationML-dokument. |
| PPSX | Microsoft Office Open XML PresentationML-bildspel. |
| ODP | OpenOffice ODF-presentation. |
| POTX | Microsoft Office Open XML PresentationML-mall. |
| PPTM | Microsoft Office Open XML PresentationML-makroaktiverat dokument. |
| PPSM | Microsoft Office Open XML PresentationML-makroaktiverat bildspel. |
| POTM | Microsoft Office Open XML PresentationML-makroaktiverad mall. |
| OTP | OpenOffice OTP-presentationmall. |
| PPT95 | Microsoft PowerPoint 95-presentation. |
| POT | Microsoft PowerPoint 97-2003-presentationmall. |
| FODP | Flat XML ODF-presentation. |
| UNKNOWN | Okänt filformat |
