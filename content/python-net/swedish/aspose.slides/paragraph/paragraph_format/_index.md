## paragraph_format egenskap
Returnerar formateringsobjektet för detta stycke.
Skrivskyddad [`IParagraphFormat`](/slides/python-net/sv/aspose.slides/iparagraphformat).

### Anmärkningar

Formateringsobjektet innehåller formateringsparametrarna som definierats endast för det aktuella stycket, ärvd data tillämpas inte.

För att få de effektiva värdena inklusive ärvda värden, använd [`ParagraphFormat.get_effective`](/slides/python-net/sv/aspose.slides/paragraphformat/get_effective)-metoden.
