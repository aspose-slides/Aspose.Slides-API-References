## IDigitalSignature klass

Digital signatur i den signerade filen.

IDigitalSignature-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`certificate`](/slides/python-net/sv/aspose.slides/idigitalsignature/certificate/) | Certifikatobjekt som användes för att signera dokumentet.<br/>            Skrivskyddad **System.Security.Cryptography.X509Certificates.X509Certificate2**. |
| [`is_valid`](/slides/python-net/sv/aspose.slides/idigitalsignature/is_valid/) | Om denna digitala signatur är giltig och dokumentet inte har manipulerats, kommer detta värde att vara true.<br/>            Skrivskyddad **bool**. |
| [`sign_time`](/slides/python-net/sv/aspose.slides/idigitalsignature/sign_time/) | Tidpunkten då dokumentet signerades.<br/>            Skrivskyddad **System.DateTime**. |
| [`comments`](/slides/python-net/sv/aspose.slides/idigitalsignature/comments/) | Syftet med signaturen.<br/>            Läs/skriv **str**. |
