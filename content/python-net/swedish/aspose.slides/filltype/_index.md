## FillType enumeration

Anger den inre fyllningstypen för olika visuella objekt.

FillType-typen exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| NOT_DEFINED | Fyllningstypen är inte definierad. |
| NO_FILL | Ingen fyllning tillämpas. |
| SOLID | Fylld med en enhetlig färg. |
| GRADIENT | Fyllningen är en gradient. |
| PATTERN | Upprepande mönster används för att fylla objektet. |
| PICTURE | En enda bild används för att fylla objektet. |
| GROUP | Det visuella objektet ärver fyllningsegenskaperna från gruppen. |
