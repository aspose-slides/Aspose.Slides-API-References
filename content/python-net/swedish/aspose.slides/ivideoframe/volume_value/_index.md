## volume_value egenskap
Returnerar eller anger den exakta videovolymen som en procentandel.
             Värdet uttrycks som en procentandel från 0 till 100. Använd den här egenskapen
             för att läsa eller ange volymvärden som är mer precisa än de fördefinierade
             nivåerna som finns tillgängliga via [`IVideoFrame.volume`](/slides/python-net/sv/aspose.slides/ivideoframe/volume) egenskapen.
             Läs/skriv **float**.
