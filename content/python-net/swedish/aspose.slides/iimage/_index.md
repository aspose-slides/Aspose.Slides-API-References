## IImage klass

Representerar en raster- eller vektorbild.

IImage-typen exponerar följande medlemmar:

## Egenskaper

| Property | Description |
| :- | :- |
| [`size`](/slides/python-net/sv/aspose.slides/iimage/size/) | Hämtar bildens storlek. |
| [`width`](/slides/python-net/sv/aspose.slides/iimage/width/) | Hämtar bildens bredd i pixlar. |
| [`height`](/slides/python-net/sv/aspose.slides/iimage/height/) | Hämtar bildens höjd i pixlar. |

## Metoder

| Method | Description |
| :- | :- |
| [`save(self, filename)`](/slides/python-net/sv/aspose.slides/iimage/save/#str) | Sparar bilden till en fil. |
| [`save(self, filename, format)`](/slides/python-net/sv/aspose.slides/iimage/save/#str-imageformat) | Sparar bilden till en fil i det angivna formatet. |
| [`save(self, stream, format)`](/slides/python-net/sv/aspose.slides/iimage/save/#iorawiobase-imageformat) | Sparar bilden till en ström i det angivna formatet. |
| [`save(self, filename, format, quality)`](/slides/python-net/sv/aspose.slides/iimage/save/#str-imageformat-int) | Sparar bilden till en fil i det angivna formatet och kvaliteten. |
| [`save(self, stream, format, quality)`](/slides/python-net/sv/aspose.slides/iimage/save/#iorawiobase-imageformat-int) | Sparar bilden till en ström i det angivna formatet och kvaliteten. |


### Anmärkningar

Detta gränssnitt tillhandahåller en gemensam abstraktion för hantering av både raster- och vektorbilder.  
            Implementeringar kan variera beroende på den underliggande bildtypen.
