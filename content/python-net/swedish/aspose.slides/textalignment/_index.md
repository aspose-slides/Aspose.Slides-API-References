## TextAlignment uppräkning

Representerar olika textjusteringsstilar.

Typen TextAlignment exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| NOT_DEFINED | Standardjustering. |
| LEFT | Vänsterjustering. |
| CENTER | Centrerad justering. |
| RIGHT | Högerjustering. |
| JUSTIFY | Justering. |
| JUSTIFY_LOW | Kashida-justering låg. |
| DISTRIBUTED | Distribuerad justering. |
