## Point klass

Representerar ett ordnat par av heltals x- och y-koordinater som definierar en punkt i ett tvådimensionellt plan. Kompatibel med .NET `System.Drawing.Point`.

Point-typen exponerar följande medlemmar:

## Konstruktörer

| Konstruktor | Beskrivning |
| :- | :- |
| [`__init__(self, x=0, y=0)`](/slides/python-net/sv/aspose.slides/point/__init__/#int-int) | Skapar en punkt med de angivna koordinaterna. float-värden trunceras till heltal. |

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`x`](/slides/python-net/sv/aspose.slides/point/x/) | Hämtar eller anger x-koordinaten för denna punkt.<br/>            Läs/skriv **int**. |
| [`y`](/slides/python-net/sv/aspose.slides/point/y/) | Hämtar eller anger y-koordinaten för denna punkt.<br/>            Läs/skriv **int**. |

### Anmärkningar

Punkter jämförs med sina koordinater med `==` och kan användas som nycklar i ordböcker eller som element i mängder.
