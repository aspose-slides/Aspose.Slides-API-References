## BlackWhiteMode enumeration

Bestämmer hur en färgad form ska omvandlas till svartvitt.

BlackWhiteMode-typen exponerar följande medlemmar:

## Fält

| Field | Description |
| :- | :- |
| NOT_DEFINED | Egenskapen är inte satt |
| COLOR | Objektet renderas med normal färgning |
| AUTOMATIC | Objektet renderas med automatisk färgning |
| GRAY | Objektet renderas med grå färgning |
| LIGHT_GRAY | Objektet renderas med ljusgrå färgning |
| INVERSE_GRAY | Objektet renderas med omvänd grå färgning |
| GRAY_WHITE | Objektet renderas med grå och vit färgning |
| BLACK_GRAY | Objektet renderas med svart och grå färgning |
| BLACK_WHITE | Objektet renderas med svart och vit färgning |
| BLACK | Objektet renderas endast med svart färgning |
| WHITE | Objektet renderas med vit färgning |
| HIDDEN | Objektet renderas inte |
