## ColorType enumeration

Representerar olika färglägen.

ColorType-typen exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| NOT_DEFINED | Färgen är inte definierad alls. |
| RGB | Standard 24-bit RGB-färg. |
| RGB_PERCENTAGE | Högupplöst RGB-färg. |
| HSL | Högupplöst HSL-färg. |
| SCHEME | Schemafärg. |
| SYSTEM | Systemfärg. |
| PRESET | Förinställd färg. |
