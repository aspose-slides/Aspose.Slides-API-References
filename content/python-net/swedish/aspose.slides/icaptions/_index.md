## ICaptions klass

Representerar WebVTT stängda undertexter.

ICaptions-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`caption_id`](/slides/python-net/sv/aspose.slides/icaptions/caption_id/) | Returnerar den globalt unika identifieraren (GUID) för de stängda undertexterna.<br/>            Skrivskyddad **System.Guid**. |
| [`label`](/slides/python-net/sv/aspose.slides/icaptions/label/) | Returnerar eller anger etiketten för de stängda undertexterna.<br/>            Läs/skriv **str**. |
| [`binary_data`](/slides/python-net/sv/aspose.slides/icaptions/binary_data/) | Returnerar de binära data för de stängda undertexterna.<br/>            Skrivskyddad **int**[]. |
| [`data_as_string`](/slides/python-net/sv/aspose.slides/icaptions/data_as_string/) | Returnerar data för de stängda undertexterna som UTF-8-kodad sträng<br/>            Skrivskyddad **str**. |
