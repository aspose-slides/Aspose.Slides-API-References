## Control klass

Representerar en ActiveX-kontroll.

Control-typen exponerar följande medlemmar:

## Egenskaper

| Property | Description |
| :- | :- |
| [`persistence`](/slides/python-net/sv/aspose.slides/control/persistence/) | Hämtar metoden som används för att lagra egenskaper för ActiveX-kontrollen.<br/>            Endast läs [`PersistenceType`](/slides/python-net/sv/aspose.slides/persistencetype). |
| [`name`](/slides/python-net/sv/aspose.slides/control/name/) | Hämtar eller anger namnet på denna kontroll.<br/>            Läs/skriv **str**. |
| [`class_id`](/slides/python-net/sv/aspose.slides/control/class_id/) | Hämtar klass-id för denna kontroll.<br/>            Endast läs **System.Guid**. |
| [`substitute_picture_format`](/slides/python-net/sv/aspose.slides/control/substitute_picture_format/) | Returnerar Control-bild fyllningsegenskapsobjekt.<br/>            Endast läs [`IPictureFillFormat`](/slides/python-net/sv/aspose.slides/ipicturefillformat). |
| [`frame`](/slides/python-net/sv/aspose.slides/control/frame/) | Returnerar eller anger kontrollens ram.<br/>            Läs/skriv [`IShapeFrame`](/slides/python-net/sv/aspose.slides/ishapeframe). |
| [`properties`](/slides/python-net/sv/aspose.slides/control/properties/) | Returnerar en samling av ActiveX-egenskaper.<br/>            Obs: Aspose.Slides stödjer endast XML-baserade ActiveX-egenskaper. Om egenskaper lagras i binärt format kommer denna egenskap att returnera None.<br/>            Endast läs [`IControlPropertiesCollection`](/slides/python-net/sv/aspose.slides/icontrolpropertiescollection). |
| [`active_x_control_binary`](/slides/python-net/sv/aspose.slides/control/active_x_control_binary/) | Anger beständigheten för en ActiveX-kontroll när metoden som används för att bevara är antingen PersistStream, PersistStreamInit eller PersistStorage. |
