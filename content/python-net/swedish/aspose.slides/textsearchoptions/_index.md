## TextSearchOptions klass

Representerar alternativ som kan användas för att söka efter text i en Presentation, Slide eller TextFrame.

TextSearchOptions-typen exponerar följande medlemmar:

## Konstruktorer

| Konstruktor | Beskrivning |
| :- | :- |
| [`__init__(self)`](/slides/python-net/sv/aspose.slides/textsearchoptions/__init__/#) | Skapar nya standardalternativ för textsökning. |

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`case_sensitive`](/slides/python-net/sv/aspose.slides/textsearchoptions/case_sensitive/) | Ange true för att använda skiftlägeskänslig sökning, false annars.<br/>            Läs/skriv **bool**. |
| [`whole_words_only`](/slides/python-net/sv/aspose.slides/textsearchoptions/whole_words_only/) | Ange true för att endast matcha hela ord, false annars.<br/>            Läs/skriv **bool**. |
| [`include_notes`](/slides/python-net/sv/aspose.slides/textsearchoptions/include_notes/) | Ange `true` för att inkludera text som finns i bildanteckningar ([`NotesSlide`](/slides/python-net/sv/aspose.slides/notesslide)) <br/>            när du utför textsökning, ersättning eller markeringsoperationer.<br/>            Standardvärdet är `false`. |
