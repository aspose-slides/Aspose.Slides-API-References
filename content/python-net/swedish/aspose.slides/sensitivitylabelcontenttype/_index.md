## SensitivityLabelContentType enumeration

Representerar typerna av innehållsmärkning som bör tillämpas på ett dokument.

Typen SensitivityLabelContentType visar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| NONE | Indikerar att etiketten tillämpas som standard eller automatiskt. |
| HEADER | Indikerar att etiketten har applicerats manuellt.<br/>            Använd för alla känslighetsetiketter som applicerades direkt av användaren. |
| FOOTER | Indikerar att etiketten har applicerats manuellt.<br/>            Använd för alla känslighetsetiketter som applicerades direkt av användaren. |
| WATERMARK | Indikerar att etiketten har applicerats manuellt.<br/>            Använd för alla känslighetsetiketter som applicerades direkt av användaren. |
| ENCRYPTION | Indikerar att etiketten har applicerats manuellt.<br/>            Använd för alla känslighetsetiketter som applicerades direkt av användaren. |
