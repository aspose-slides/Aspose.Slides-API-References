## compare_to(self, obj) {#any}
Jämför den aktuella instansen med ett annat objekt av samma typ.

### Returnerar

Ett 32-bitars heltal som indikerar den relativa ordningen för de jämförda objekten.
            Returvärdet har följande betydelser:
            
*  < 0 - Denna instans är mindre än obj. = 0 - Denna instans är lika med obj. > 0 - Denna instans är större än obj.

*  < 0 - Denna instans är mindre än obj. = 0 - Denna instans är lika med obj. > 0 - Denna instans är större än obj.

*  < 0 - Denna instans är mindre än obj. = 0 - Denna instans är lika med obj. > 0 - Denna instans är större än obj.
