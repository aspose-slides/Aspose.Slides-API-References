## Background klass

Representerar bakgrund för en bild.

**Arv:**[`Background`](/slides/python-net/sv/aspose.slides/background) → [`PVIObject`](/slides/python-net/sv/aspose.slides/pviobject)

Typen Background exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`type`](/slides/python-net/sv/aspose.slides/background/type/) | Returnerar en typ av bakgrundsfyllning.<br/>            Läs/skriv [`BackgroundType`](/slides/python-net/sv/aspose.slides/backgroundtype). |
| [`fill_format`](/slides/python-net/sv/aspose.slides/background/fill_format/) | Returnerar ett FillFormat för fyllning av BackgroundType.OwnBackground.<br/>            Endast läsning [`IFillFormat`](/slides/python-net/sv/aspose.slides/ifillformat). |
| [`effect_format`](/slides/python-net/sv/aspose.slides/background/effect_format/) | Returnerar ett EffectFormat för fyllning av BackgroundType.OwnBackground.<br/>            Endast läsning [`IEffectFormat`](/slides/python-net/sv/aspose.slides/ieffectformat). |
| [`style_color`](/slides/python-net/sv/aspose.slides/background/style_color/) | Returnerar ett ColorFormat för en BackgroundType.Themed-fyllning.<br/>            Endast läsning [`IColorFormat`](/slides/python-net/sv/aspose.slides/icolorformat). |
| [`style_index`](/slides/python-net/sv/aspose.slides/background/style_index/) | Returnerar ett index för BackgroundType.Themed-fyllning i samling av bakgrundsteman.<br/>            0 betyder ingen fyllning.<br/>            1..999 – index.<br/>            Läs/skriv **int**. |
| [`slide`](/slides/python-net/sv/aspose.slides/background/slide/) | Returnerar föräldrabilden för en form.<br/>            Endast läsning [`IBaseSlide`](/slides/python-net/sv/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/sv/aspose.slides/background/presentation/) | Returnerar föräldrapresentationen för en bild.<br/>            Endast läsning [`IPresentation`](/slides/python-net/sv/aspose.slides/ipresentation). |
