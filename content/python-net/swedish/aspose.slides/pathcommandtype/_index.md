## PathCommandType enum

Representerar grafikens sökvägkommandon

PathCommandType-typen exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| CLOSE | Stänger geometrisk bana |
| MOVE_TO | Ställer in nästa punkts position för geometrisk bana |
| LINE_TO | Lägger till en linje till geometrisk bana |
| ARC_TO | Lägger till den angivna bågen till geometrisk bana. |
| QUAD_BEZIER_TO | Lägger till en kvadratisk Bezier-kurva till geometrisk bana |
| CUBIC_BEZIER_TO | Lägger till en kubisk Bezier-kurva till geometrisk bana |
