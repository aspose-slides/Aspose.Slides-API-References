## IFillFormat klass

Representerar alternativ för fyllningsformatering.

IFillFormat-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`fill_type`](/slides/python-net/sv/aspose.slides/ifillformat/fill_type/) | Returnerar eller sätter fyllningstypen.<br/>            Läs/skriv [`FillType`](/slides/python-net/sv/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/sv/aspose.slides/ifillformat/solid_fill_color/) | Returnerar fyllningsfärgen.<br/>            Endast läs [`IColorFormat`](/slides/python-net/sv/aspose.slides/icolorformat). |
| [`gradient_format`](/slides/python-net/sv/aspose.slides/ifillformat/gradient_format/) | Returnerar gradientfyllningsformatet.<br/>            Endast läs [`IGradientFormat`](/slides/python-net/sv/aspose.slides/igradientformat). |
| [`pattern_format`](/slides/python-net/sv/aspose.slides/ifillformat/pattern_format/) | Returnerar mönsterfyllningsformatet.<br/>            Endast läs [`IPatternFormat`](/slides/python-net/sv/aspose.slides/ipatternformat). |
| [`picture_fill_format`](/slides/python-net/sv/aspose.slides/ifillformat/picture_fill_format/) | Returnerar bildfyllningsformatet.<br/>            Endast läs [`IPictureFillFormat`](/slides/python-net/sv/aspose.slides/ipicturefillformat). |
