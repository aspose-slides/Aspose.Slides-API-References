## ViewProperties-klass

Visningsinställningar för hela presentationen.

Typen ViewProperties exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`last_view`](/slides/python-net/sv/aspose.slides/viewproperties/last_view/) | Anger det visningsläge som användes när presentationsdokumentet senast sparades.<br/>            Läs/skriv [`ViewType`](/slides/python-net/sv/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/sv/aspose.slides/viewproperties/show_comments/) | Anger huruvida bildkommentarer ska visas.<br/>            Läs/skriv [`NullableBool`](/slides/python-net/sv/aspose.slides/nullablebool). |
| [`normal_view_properties`](/slides/python-net/sv/aspose.slides/viewproperties/normal_view_properties/) | Representerar egenskaper för normal vy. Den normala vyn består av<br/>            tre innehållsområden: själva bilden, ett sidoinnehållsområde och ett botteninnehållsområde.<br/>            Endast läsning [`INormalViewProperties`](/slides/python-net/sv/aspose.slides/inormalviewproperties). |
| [`slide_view_properties`](/slides/python-net/sv/aspose.slides/viewproperties/slide_view_properties/) | Anger gemensamma vyegenskaper som är kopplade till bildvy-läget.<br/>            Endast läsning [`ICommonSlideViewProperties`](/slides/python-net/sv/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/sv/aspose.slides/viewproperties/notes_view_properties/) | Anger gemensamma vyegenskaper som är kopplade till anteckningsvy-läget.<br/>            Endast läsning [`ICommonSlideViewProperties`](/slides/python-net/sv/aspose.slides/icommonslideviewproperties). |
| [`grid_spacing`](/slides/python-net/sv/aspose.slides/viewproperties/grid_spacing/) | Returnerar eller anger rutnätsavståndet som ska användas för rutnätet under presentationsdokumentet, i punkter.<br/>            Läs/skriv **float**. |
