## links_up_to_date egenskap
Indikerar om hyperlänkar i ett dokument är aktuella. 
            Ställ in detta element till **true** för att indikera att hyperlänkar är uppdaterade. 
            Ställ in detta element till **false** för att indikera att hyperlänkar är föråldrade.
            Läs/skriv **bool**.
