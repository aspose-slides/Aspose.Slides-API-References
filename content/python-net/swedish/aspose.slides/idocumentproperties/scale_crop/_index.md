## scale_crop egenskap
Anger visningsläget för dokumentets miniatyrbild. 
Ställ in detta element till **true** för att möjliggöra skalning av dokumentets miniatyrbild till visningen. 
Ställ in detta element till **false** för att möjliggöra beskärning av dokumentets miniatyrbild så att endast sektioner som passar visningen visas. 
Läs/skriv **bool**.
