## ICellFormat klass

Representerar formatet för en tabellcell.

Typen ICellFormat exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`fill_format`](/slides/python-net/sv/aspose.slides/icellformat/fill_format/) | Returnerar ett objekt med cellens fyllningsegenskaper.<br/>            Skrivskyddad [`IFillFormat`](/slides/python-net/sv/aspose.slides/ifillformat). |
| [`border_left`](/slides/python-net/sv/aspose.slides/icellformat/border_left/) | Returnerar ett objekt med egenskaper för vänster kantlinje.<br/>            Skrivskyddad [`ILineFormat`](/slides/python-net/sv/aspose.slides/ilineformat). |
| [`border_top`](/slides/python-net/sv/aspose.slides/icellformat/border_top/) | Returnerar ett objekt med egenskaper för överkantslinje.<br/>            Skrivskyddad [`ILineFormat`](/slides/python-net/sv/aspose.slides/ilineformat). |
| [`border_right`](/slides/python-net/sv/aspose.slides/icellformat/border_right/) | Returnerar ett objekt med egenskaper för höger kantlinje.<br/>            Skrivskyddad [`ILineFormat`](/slides/python-net/sv/aspose.slides/ilineformat). |
| [`border_bottom`](/slides/python-net/sv/aspose.slides/icellformat/border_bottom/) | Returnerar ett objekt med egenskaper för nederkantslinje.<br/>            Skrivskyddad [`ILineFormat`](/slides/python-net/sv/aspose.slides/ilineformat). |
| [`border_diagonal_down`](/slides/python-net/sv/aspose.slides/icellformat/border_diagonal_down/) | Returnerar ett objekt med egenskaper för diagonal linje från övre vänstra till nedre högra.<br/>            Skrivskyddad [`ILineFormat`](/slides/python-net/sv/aspose.slides/ilineformat). |
| [`border_diagonal_up`](/slides/python-net/sv/aspose.slides/icellformat/border_diagonal_up/) | Returnerar ett objekt med egenskaper för diagonal linje från nedre vänstra till övre högra.<br/>            Skrivskyddad [`ILineFormat`](/slides/python-net/sv/aspose.slides/ilineformat). |
| [`transparency`](/slides/python-net/sv/aspose.slides/icellformat/transparency/) | Hämtar eller anger genomskinligheten för fyllningsfärgen.<br/>            Läs/skriv **float**. |
