## PPImageFormat enumeration

Bildformat. Denna enum ersätter klassen `System.Drawing.Imaging.ImageFormat`. Den behövs för COM-kompatibilitet.

Typen PPImageFormat exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| BMP | Hämtar bitmap (BMP) bildformatet. |
| EMF | Hämtar den förbättrade metafilen (EMF) bildformatet. |
| EXIF | Hämtar Exchangeable Image File (Exif)-formatet. |
| GIF | Hämtar Graphics Interchange Format (GIF) bildformatet. |
| ICON | Hämtar Windows-ikon bildformatet. |
| JPEG | Hämtar Joint Photographic Experts Group (JPEG) bildformatet. |
| MEMORY_BMP | Hämtar formatet för en bitmap i minnet. |
| PNG | Hämtar W3C Portable Network Graphics (PNG) bildformatet. |
| TIFF | Hämtar Tagged Image File Format (TIFF) bildformatet. |
| WMF | Hämtar Windows-metafilen (WMF) bildformatet. |
