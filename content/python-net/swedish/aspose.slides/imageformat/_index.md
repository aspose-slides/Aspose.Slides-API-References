## ImageFormat uppräkning

Representerar bildens filformat.

ImageFormat-typen exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| MEMORY_BMP | Representerar formatet för en bitmap i minnet. |
| BMP | Representerar bitmap (BMP)-bildformatet. |
| EMF | Representerar det förbättrade metafilformatet (EMF). |
| WMF | Representerar Windows-metafilet (WMF) bildformat. |
| GIF | Representerar Graphics Interchange Format (GIF)-bildformatet. |
| JPEG | Representerar Joint Photographic Experts Group (JPEG)-bildformatet. |
| PNG | Representerar W3C Portable Network Graphics (PNG)-bildformatet. |
| TIFF | Representerar Tagged Image File Format (TIFF)-bildformatet. |
| EXIF | Representerar Exchangeable Image File (Exif)-formatet. |
| ICON | Representerar Windows-ikonbildformatet. |
