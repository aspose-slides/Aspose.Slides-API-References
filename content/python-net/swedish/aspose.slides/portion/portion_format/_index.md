## portion_format egenskap
Returnerar ett formateringsobjekt som innehåller explicit inställda formateringsegenskaper för textavsnittet utan att arv tillämpas.
            Skrivskyddad [`IPortionFormat`](/slides/python-net/sv/aspose.slides/iportionformat).

### Anmärkningar

Formateringsobjektet innehåller de formateringsparametrar som är definierade endast för det aktuella avsnittet; ärvd data tillämpas inte.

För att få de effektiva värdena inklusive ärvda, använd [`PortionFormat.get_effective`](/slides/python-net/sv/aspose.slides/portionformat/get_effective)-metoden.
