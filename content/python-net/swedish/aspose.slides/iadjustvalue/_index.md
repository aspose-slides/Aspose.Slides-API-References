## IAdjustValue klass

Representerar ett geometriskt formjusteringsvärde.
            Dessa värden påverkar figurens form.

IAdjustValue-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`raw_value`](/slides/python-net/sv/aspose.slides/iadjustvalue/raw_value/) | Returnerar eller anger justeringsvärdet "as is".<br/>            Läs/skriv **int**. |
| [`angle_value`](/slides/python-net/sv/aspose.slides/iadjustvalue/angle_value/) | Returnerar eller anger värdet, tolkar det som en vinkel i grader.<br/>            Läs/skriv **float**. |
| [`name`](/slides/python-net/sv/aspose.slides/iadjustvalue/name/) | Returnerar namnet på detta justeringsvärde.<br/>            Endast läsning **str**. |
| [`type`](/slides/python-net/sv/aspose.slides/iadjustvalue/type/) | Returnerar typen av formjusteringen.<br/>            Endast läsning [`ShapeAdjustmentType`](/slides/python-net/sv/aspose.slides/shapeadjustmenttype). |
