## remove(self, item) {#iportion}
Tar bort den första förekomsten av ett specifikt objekt från **System.Collections.Generic.ICollection`1**.

### Returnerar

true om `item` framgångsrikt togs bort från **System.Collections.Generic.ICollection`1**; annars false. Denna metod returnerar också false om `item` inte hittas i den ursprungliga **System.Collections.Generic.ICollection`1**.
