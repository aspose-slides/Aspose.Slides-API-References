## IViewProperties klass

Visningsinställningar för hela presentationen.

Typen IViewProperties exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`last_view`](/slides/python-net/sv/aspose.slides/iviewproperties/last_view/) | Anger visningsläget som användes när presentationsdokumentet senast sparades.<br/>            Läs/skriv [`ViewType`](/slides/python-net/sv/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/sv/aspose.slides/iviewproperties/show_comments/) | Anger om bildkommentarer ska visas.<br/>            Läs/skriv [`NullableBool`](/slides/python-net/sv/aspose.slides/nullablebool). |
| [`slide_view_properties`](/slides/python-net/sv/aspose.slides/iviewproperties/slide_view_properties/) | Anger vanliga visningsinställningar som är associerade med bildvisningsläget.<br/>            Endast läsning [`ICommonSlideViewProperties`](/slides/python-net/sv/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/sv/aspose.slides/iviewproperties/notes_view_properties/) | Anger gemensamma visningsinställningar som är associerade med notes-visningsläget.<br/>            Endast läsning [`ICommonSlideViewProperties`](/slides/python-net/sv/aspose.slides/icommonslideviewproperties). |
| [`normal_view_properties`](/slides/python-net/sv/aspose.slides/iviewproperties/normal_view_properties/) | Representerar normala visningsinställningar. Den normala vyn består av<br/>            tre innehållsområden: själva bilden, ett sidoinnehållsområde och ett botteninnehållsområde.<br/>            Endast läsning [`INormalViewProperties`](/slides/python-net/sv/aspose.slides/inormalviewproperties). |
| [`grid_spacing`](/slides/python-net/sv/aspose.slides/iviewproperties/grid_spacing/) | Returnerar eller ställer in rasteravståndet som ska användas för rastern under presentationsdokumentet, i punkter. <br/>            Läs/skriv **float**. |
