## IControl klass

Representerar en ActiveX-kontroll.

IControl-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`name`](/slides/python-net/sv/aspose.slides/icontrol/name/) | Returnerar namnet på denna kontroll.<br/>            Läs/skriv **str**. |
| [`class_id`](/slides/python-net/sv/aspose.slides/icontrol/class_id/) | Hämtar klass-id för denna kontroll.<br/>            Skrivskyddad **System.Guid**. |
| [`substitute_picture_format`](/slides/python-net/sv/aspose.slides/icontrol/substitute_picture_format/) | Returnerar ControlEx bildfyllnings-egenskapsobjekt.<br/>            Skrivskyddad [`IPictureFillFormat`](/slides/python-net/sv/aspose.slides/ipicturefillformat). |
| [`frame`](/slides/python-net/sv/aspose.slides/icontrol/frame/) | Returnerar eller anger kontrollens ram.<br/>            Läs/skriv [`IShapeFrame`](/slides/python-net/sv/aspose.slides/ishapeframe). |
| [`properties`](/slides/python-net/sv/aspose.slides/icontrol/properties/) | Returnerar en samling av ActiveX-egenskaper.<br/>            Skrivskyddad [`IControlPropertiesCollection`](/slides/python-net/sv/aspose.slides/icontrolpropertiescollection). |
| [`persistence`](/slides/python-net/sv/aspose.slides/icontrol/persistence/) | Hämtar metoden som används för att lagra egenskaper för ActiveX-kontrollen.<br/>            Skrivskyddad [`PersistenceType`](/slides/python-net/sv/aspose.slides/persistencetype). |
| [`active_x_control_binary`](/slides/python-net/sv/aspose.slides/icontrol/active_x_control_binary/) | Anger beständigheten för en ActiveX-kontroll när den metod som används för att bestå är antingen PersistStream, PersistStreamInit eller PersistStorage. |
