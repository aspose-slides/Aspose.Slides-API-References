## ResourceLoadingAction enum

Anger läget för laddning av externa resurser.

ResourceLoadingAction-typen exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| DEFAULT | Aspose.Slides laddar externa resurser som vanligt. |
| SKIP | Aspose.Slides hoppar över laddning av externa resurser. Endast länken utan data lagras för en bild. |
| USER_PROVIDED | Aspose.Slides använder bytearray som tillhandahålls av användaren i **Aspose.Slides.IResourceLoadingArgs.SetData(Syste** som bilddata. |
