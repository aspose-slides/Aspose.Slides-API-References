## ITextHighlightingOptions klass

Representerar alternativ som kan användas för att markera text i en textram.

Typen ITextHighlightingOptions exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`case_sensitive`](/slides/python-net/sv/aspose.slides/itexthighlightingoptions/case_sensitive/) | Ange true för att använda skiftlägeskänslig sökning, false annars.<br/>            Läs/skriv **bool**. |
| [`whole_words_only`](/slides/python-net/sv/aspose.slides/itexthighlightingoptions/whole_words_only/) | Ange true för att endast matcha hela ord, false annars.<br/>            Läs/skriv **bool**. |
