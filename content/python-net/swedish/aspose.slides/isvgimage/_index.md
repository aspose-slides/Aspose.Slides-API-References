## ISvgImage klass

Representerar en SVG-bild.

ISvgImage-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`svg_content`](/slides/python-net/sv/aspose.slides/isvgimage/svg_content/) | Returnerar SVG-innehåll.<br/>            Skrivskyddad **str**. |
| [`svg_data`](/slides/python-net/sv/aspose.slides/isvgimage/svg_data/) | Returnerar SVG-data.<br/>            Skrivskyddad **int**[]. |
| [`external_resource_resolver`](/slides/python-net/sv/aspose.slides/isvgimage/external_resource_resolver/) | Returnerar återuppringningsgränssnitt som används för att lösa externa resurser under SVG-dokumentimport.<br/>            Skrivskyddad **IExternalResourceResolver**. |
| [`base_uri`](/slides/python-net/sv/aspose.slides/isvgimage/base_uri/) | Returnerar bas-URI för den angivna SVG:n. Används för att lösa relativa länkar.<br/>            Skrivskyddad **str**. |
