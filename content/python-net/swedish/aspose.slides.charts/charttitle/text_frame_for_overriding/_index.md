## text_frame_for_overriding egenskap

Kan innehålla rik formatterad text. Om denna egenskap inte är None så
            det formaterade textvärdet åsidosätter automatiskt genererad text.
            Automatiskt genererad text är en implicit egenskap för datamärket, display 
            enhetsetiketten för värdeaxeln, axeltiteln, diagramtiteln, trendlinjens etikett.
            Automatiskt genererad text formateras med IFormattedTextContainer.TextFormat egenskap.
            Skrivskyddad [`ITextFrame`](/slides/python-net/sv/aspose.slides/itextframe).
