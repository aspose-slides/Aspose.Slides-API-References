## use_secondary_categories egenskap
Om falskt returnerar [`IChartData.secondary_categories`](/slides/python-net/sv/aspose.slides.charts/ichartdata/secondary_categories) egenskap None och data 
            och data i [`IChartData.categories`](/slides/python-net/sv/aspose.slides.charts/ichartdata/categories) egenskap används både för primära och sekundära serier.
            Om sant används data i [`IChartData.secondary_categories`](/slides/python-net/sv/aspose.slides.charts/ichartdata/secondary_categories) egenskap för sekundära serier och data 
            i [`IChartData.categories`](/slides/python-net/sv/aspose.slides.charts/ichartdata/categories) egenskap används för primära serier.
            Läs/skriv **bool**.
