## hide(self) {#}
Gör datamärket dolt genom att sätta alla Show*-flags (ShowValue, ...) till falskt tillstånd.
            IsVisible kommer att vara falskt efter detta.


```python
def hide(self):
    ...
```


### Anmärkningar

Om datamärket inte är synligt (IsVisible är falskt) kan du göra datamärket synligt genom att
            sätta Show*-flags (ShowValue, ...) till sant tillstånd.
