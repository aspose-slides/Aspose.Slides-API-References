## ChartShapeType enumeration

Representerar en form av diagram.

ChartShapeType-typen exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| NOT_DEFINED | Diagramformen är inte definierad. |
| BOX | Anger att diagrammet ska ritas med en lådform. |
| CONE | Anger att diagrammet ska ritas som en kon, med konens bas på golvet och konens spets högst upp på datamarkören. |
| CONE_TO_MAX | Anger att diagrammet ska ritas med avkortade koner så att konens spets motsvarar det maximala datavärdet. |
| CYLINDER | Anger att diagrammet ska ritas som en cylinder. |
| PYRAMID | Anger att diagrammet ska ritas som en rektangulär pyramid, med pyramidens bas på golvet och pyramidens spets högst upp på datamarkören. |
| PYRAMID_TO_MAXIMUM | Anger att diagrammet ska ritas med avkortade koner så att konens spets motsvarar det maximala datavärdet. |
