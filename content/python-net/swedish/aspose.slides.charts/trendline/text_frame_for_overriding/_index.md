## text_frame_for_overriding egenskap
Kan innehålla en rik formaterad text. Om denna egenskap inte är None så är detta 
            formattextvärdet åsidosätter automatiskt genererad text för datamärket.
            Automatiskt genererad text för datamärket betyder text som hanteras av ShowSeriesName, 
            ShowValue, ... egenskaper och formateras med TextFormatManager.TextFormat-egenskapen.
            Skrivskyddad [`ITextFrame`](/slides/python-net/sv/aspose.slides/itextframe).
