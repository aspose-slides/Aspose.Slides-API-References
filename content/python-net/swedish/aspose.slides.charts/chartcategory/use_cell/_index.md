## use_cell egenskap
If true then AsCell egenskap is actual. In other words, worksheet is used for 
            lagra kategori (this case supports a multi-level category).
            If false then AsLiteral egenskap is actual. In other words, worksheet is NOT used 
            för att lagra kategori (and this case doesn't support a multi-level categories).
            Skrivskyddad **bool**.


### Anmärkningar

For change value of this property (for all categories in collection) set new 
            value to ChartCategoryCollection.UseCells property.
