## use_cell egenskap
Om true är AsCell egenskap aktuell. Med andra ord, worksheet används för att lagra kategori (detta fall stöder en flernivåkategori). Om false är AsLiteral egenskap aktuell. Med andra ord, worksheet används INTE för att lagra kategori (och detta fall stödjer inte flernivåkategorier). Skrivskyddad **bool**.

### Anmärkningar

För att ändra värdet på denna egenskap (för alla kategorier i samlingen) sätt det nya värdet till ChartCategoryCollection.UseCells egenskap.
