## value_type egenskap
Representerar möjliga sätt att bestämma längden på felstaplarna. 
            Om anpassad värdetyp används för att ange värde, använd [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/sv/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) egenskap för den specifika datapunkten i DataPoints-samlingen för serien.
            Om värdetypen är Fixed, Percentage eller StandardDeviation, använd Value egenskap för att ange värde.  
            Läs/skriv [`ErrorBarValueType`](/slides/python-net/sv/aspose.slides.charts/errorbarvaluetype).
