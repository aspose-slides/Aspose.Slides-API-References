## AxisAggregationType enumeration

Representerar aggregeringstyp för kategoraxel. Används endast med Histogram eller HistogramPareto-serier.

Typen AxisAggregationType exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| BY_CATEGORY | Aggregera efter kategorier |
| AUTOMATIC | Aggregera kategorier automatiskt. |
| BY_BIN_WIDTH | Aggregera kategorier efter stapelbredd. Egenskap IAxis.BinWidth måste sättas. |
| BY_NUMBER_OF_BINS | Aggregera kategorier efter antal staplar. Egenskap IAxis.NumberOfBins måste sättas. |
