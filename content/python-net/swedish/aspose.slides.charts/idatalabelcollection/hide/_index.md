## hide(self) {#}
Gör dataetiketten dold som standard genom att sätta alla Show*-flags (ShowValue, ...) för DefaultDataLabelFormat egenskapen till falskt tillstånd. IsVisible blir falskt efter detta.


```python
def hide(self):
    ...
```


### Anmärkningar

Om dataetiketten inte är synlig som standard (IsVisible är false) kan du göra dataetiketten "synlig som standard" med att sätta Show*-flags (ShowValue, ...) för DefaultDataLabelFormat egenskapen till true-tillstånd.
