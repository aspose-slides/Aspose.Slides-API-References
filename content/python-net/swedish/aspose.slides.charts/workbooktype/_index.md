## WorkbookType enumeration

Anger typen av Open XML-arbetsbokfil.

Typen WorkbookType visar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| NOT_DEFINED | Arbetsbokstypen är inte definierad. |
| WORKBOOK | Excel-arbetsbok (*.xlsx). |
| WORKBOOK_MACRO | Excel-makroaktiverad arbetsbok (*.xlsm). |
| TEMPLATE | Excel-mall (*.xltx). |
| TEMPLATE_MACRO | Excel-makroaktiverad mall (*.xltm). |
| WORKBOOK_BINARY_MACRO | Excel binär makroaktiverad arbetsbok (*.xlsb). |
