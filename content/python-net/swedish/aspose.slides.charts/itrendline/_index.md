## ITrendline klass

Klassen representerar trendlinjen för en diagramserie

ITrendline-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`trendline_name`](/slides/python-net/sv/aspose.slides.charts/itrendline/trendline_name/) | Hämtar eller anger namn på trendlinjen.<br/>            Läs/skriv **str**. |
| [`trendline_type`](/slides/python-net/sv/aspose.slides.charts/itrendline/trendline_type/) | Hämtar eller anger typ av trendlinje. <br/>            Läs/skriv [`ITrendline.trendline_type`](/slides/python-net/sv/aspose.slides.charts/itrendline/trendline_type). |
| [`format`](/slides/python-net/sv/aspose.slides.charts/itrendline/format/) | Representerar formatet för trendlinjen.<br/>            Läs/skriv [`IFormat`](/slides/python-net/sv/aspose.slides.charts/iformat). |
| [`backward`](/slides/python-net/sv/aspose.slides.charts/itrendline/backward/) | Anger antalet kategorier (eller enheter i ett spridningsdiagram) som trendlinjen sträcker sig innan<br/>            data för den serie som trenderas. I spridnings- och icke-spridningsdiagram ska värdet vara ett icke-negativt<br/>            värde.<br/>            Läs/skriv **float**. |
| [`forward`](/slides/python-net/sv/aspose.slides.charts/itrendline/forward/) | Anger antalet kategorier (eller enheter i ett spridningsdiagram) som trendlinjen sträcker sig efter<br/>            data för den serie som trenderas. I spridnings- och icke-spridningsdiagram ska värdet vara ett icke-negativt<br/>            värde.<br/>            Läs/skriv **float**. |
| [`intercept`](/slides/python-net/sv/aspose.slides.charts/itrendline/intercept/) | Anger värdet där trendlinjen ska korsa y-axeln. Denna egenskap ska endast stödjas<br/>            när trendlinjetypen är exp, linear eller poly.<br/>            Läs/skriv **float**. |
| [`display_equation`](/slides/python-net/sv/aspose.slides.charts/itrendline/display_equation/) | Anger att ekvationen för trendlinjen visas i diagrammet (i samma etikett som R-kvadrerat-värdet).<br/>            Läs/skriv **bool**. |
| [`order`](/slides/python-net/sv/aspose.slides.charts/itrendline/order/) | Anger ordningen för den polynomiska trendlinjen. Den ignoreras för andra trendlinjetyper. Värdet måste vara mellan 2 och 6.<br/>            Läs/skriv **int**. |
| [`period`](/slides/python-net/sv/aspose.slides.charts/itrendline/period/) | Anger perioden för trendlinjen för ett glidande medelvärde. Den ignoreras för andra trend<br/>            linjevarianter. Värdet måste vara mellan 2 och 255.<br/>            Läs/skriv **int**. |
| [`display_r_squared_value`](/slides/python-net/sv/aspose.slides.charts/itrendline/display_r_squared_value/) | Anger att R-kvadrerat-värdet för trendlinjen visas i diagrammet (i samma etikett som ekvationen).<br/>            Läs/skriv **bool**. |
| [`related_legend_entry`](/slides/python-net/sv/aspose.slides.charts/itrendline/related_legend_entry/) | Representerar legendpost som är relaterad till denna trendlinje<br/>            Läs-endast [`ILegendEntryProperties`](/slides/python-net/sv/aspose.slides.charts/ilegendentryproperties). |
| [`text_frame_for_overriding`](/slides/python-net/sv/aspose.slides.charts/itrendline/text_frame_for_overriding/) |  |
| [`text_format`](/slides/python-net/sv/aspose.slides.charts/itrendline/text_format/) |  |
