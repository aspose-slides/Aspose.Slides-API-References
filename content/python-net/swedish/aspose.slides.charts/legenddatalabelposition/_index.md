## LegendDataLabelPosition enumeration

Bestämmer positionen för datamärkningar.

Typen LegendDataLabelPosition exponerar följande medlemmar:

## Fält

| Field | Description |
| :- | :- |
| NOT_DEFINED | Position är inte definierad. |
| BOTTOM | Anger att datamärkningar ska visas under datamarkören. |
| BEST_FIT | Anger att datamärkningar ska visas i den bästa positionen. |
| CENTER | Anger att datamärkningar ska visas centrerade på datamarkören. |
| INSIDE_BASE | Anger att datamärkningar ska visas inne i basen av datamarkören. |
| INSIDE_END | Anger att datamärkningar ska visas inne i slutet av datamarkören. |
| LEFT | Anger att datamärkningar ska visas till vänster om datamarkören. |
| OUTSIDE_END | Anger att datamärkningar ska visas utanför slutet av datamarkören. |
| RIGHT | Anger att datamärkningar ska visas till höger om datamarkören. |
| TOP | Anger att datamärkningar ska visas ovanför datamarkören. |
