## ChartDataCell klass

Representerar cell för diagramdata.

ChartDataCell-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`row`](/slides/python-net/sv/aspose.slides.charts/chartdatacell/row/) | Returnerar index för raden i kalkylbladet där cellen är placerad.<br/>            Skrivskyddad **int**. |
| [`column`](/slides/python-net/sv/aspose.slides.charts/chartdatacell/column/) | Returnerar index för kolumnen i kalkylbladet där cellen är placerad.<br/>            Skrivskyddad **int**. |
| [`value`](/slides/python-net/sv/aspose.slides.charts/chartdatacell/value/) | Hämtar eller anger värdet för en cell.<br/>            Läs/skriv **any**. |
| [`formula`](/slides/python-net/sv/aspose.slides.charts/chartdatacell/formula/) | Hämtar eller anger formeln i A1-stil. |
| [`r1c1_formula`](/slides/python-net/sv/aspose.slides.charts/chartdatacell/r1c1_formula/) | Hämtar eller anger formeln i R1C1-stil. |
| [`chart_data_worksheet`](/slides/python-net/sv/aspose.slides.charts/chartdatacell/chart_data_worksheet/) | Hämtar kalkylbladet.<br/>            Skrivskyddad [`IChartDataWorksheet`](/slides/python-net/sv/aspose.slides.charts/ichartdataworksheet). |
| [`is_hidden`](/slides/python-net/sv/aspose.slides.charts/chartdatacell/is_hidden/) | Avgör om cellen är dold.<br/>            Skrivskyddad **bool**. |
| [`custom_number_format`](/slides/python-net/sv/aspose.slides.charts/chartdatacell/custom_number_format/) | Hämtar eller anger det anpassade visningsformatet för tal och datum. <br/>            Om värdet är tomt används PresetNumberFormat-värdet.<br/>            Läs/skriv **str**. |
| [`preset_number_format`](/slides/python-net/sv/aspose.slides.charts/chartdatacell/preset_number_format/) | Hämtar eller anger det inbyggda visningsformatet för tal och datum. Förinställt nummer måste vara i [0..22] eller [37..49].<br/>            Läs/skriv **int**. |
