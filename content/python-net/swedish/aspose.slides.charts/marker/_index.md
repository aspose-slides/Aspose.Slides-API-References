## Marker klass

Representerar markör av en chert.

Marker-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`symbol`](/slides/python-net/sv/aspose.slides.charts/marker/symbol/) | Representerar markörstilen i ett linjediagram, spridningsdiagram eller radardiagram.<br/>            Läs/skriv [`MarkerStyleType`](/slides/python-net/sv/aspose.slides.charts/markerstyletype). |
| [`format`](/slides/python-net/sv/aspose.slides.charts/marker/format/) | Hämtar eller anger markerfyllning.<br/>            Skrivskyddad [`IFormat`](/slides/python-net/sv/aspose.slides.charts/iformat). |
| [`size`](/slides/python-net/sv/aspose.slides.charts/marker/size/) | Representerar markeringsstorleken i ett linjediagram, spridningsdiagram eller radardiagram.<br/>            Läs/skriv **int**. |
