## use_cells egenskap
Om true är worksheet används för att lagra kategorier (detta fall stödjer flernivåskategorier).
            Om false är worksheet INTE används för att lagra värden (och detta fall stödjer inte 
            flernivåskategorier).
            Läs/skriv **bool**.
