## MarkerStyleType uppräkning

Bestämmer markeringsformen på diagrammets datapunkt.

Typen MarkerStyleType exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| NOT_DEFINED |  |
| CIRCLE | Anger att en cirkel ska ritas vid varje datapunkt. |
| DASH | Anger att ett streck ska ritas vid varje datapunkt. |
| DIAMOND | Anger att en romb ska ritas vid varje datapunkt. |
| DOT | Anger att en punkt ska ritas vid varje datapunkt. |
| NONE | Anger att ingenting ska ritas vid varje datapunkt. |
| PICTURE | Anger att en bild ska ritas vid varje datapunkt. |
| PLUS | Anger att ett plustecken ska ritas vid varje datapunkt. |
| SQUARE | Anger att en fyrkant ska ritas vid varje datapunkt. |
| STAR | Anger att en stjärna ska ritas vid varje datapunkt. |
| TRIANGLE | Anger att en triangel ska ritas vid varje datapunkt. |
| X | Anger att ett X ska ritas vid varje datapunkt. |
