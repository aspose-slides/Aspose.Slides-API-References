## IChartParagraphFormat klass

Representerar formatinställningar för ett stycke i ett diagram.

IChartParagraphFormat-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`alignment`](/slides/python-net/sv/aspose.slides.charts/ichartparagraphformat/alignment/) | Returnerar eller anger textjusteringen i ett stycke.<br/>            Läs/skriv [`TextAlignment`](/slides/python-net/sv/aspose.slides/textalignment). |
| [`space_within`](/slides/python-net/sv/aspose.slides.charts/ichartparagraphformat/space_within/) | Returnerar eller anger avståndet mellan baslinjer i ett stycke.<br/>            Läs/skriv **float**. |
| [`space_before`](/slides/python-net/sv/aspose.slides.charts/ichartparagraphformat/space_before/) | Returnerar eller anger avståndet före den första raden i ett stycke.<br/>            Läs/skriv **float**. |
| [`space_after`](/slides/python-net/sv/aspose.slides.charts/ichartparagraphformat/space_after/) | Returnerar eller anger avståndet efter den sista raden i ett stycke.<br/>            Läs/skriv **float**. |
| [`east_asian_line_break`](/slides/python-net/sv/aspose.slides.charts/ichartparagraphformat/east_asian_line_break/) | Avgör om östasiatisk radbrytning används i ett stycke.<br/>            Läs/skriv [`NullableBool`](/slides/python-net/sv/aspose.slides/nullablebool). |
| [`right_to_left`](/slides/python-net/sv/aspose.slides.charts/ichartparagraphformat/right_to_left/) | Avgör om från höger till vänster-skrivning används i ett stycke.<br/>            Läs/skriv [`NullableBool`](/slides/python-net/sv/aspose.slides/nullablebool). |
| [`latin_line_break`](/slides/python-net/sv/aspose.slides.charts/ichartparagraphformat/latin_line_break/) | Avgör om latinisk radbrytning används i ett stycke.<br/>            Läs/skriv [`NullableBool`](/slides/python-net/sv/aspose.slides/nullablebool). |
| [`hanging_punctuation`](/slides/python-net/sv/aspose.slides.charts/ichartparagraphformat/hanging_punctuation/) | Avgör om hängande interpunktion används i ett stycke.<br/>            Läs/skriv [`NullableBool`](/slides/python-net/sv/aspose.slides/nullablebool). |
| [`margin_left`](/slides/python-net/sv/aspose.slides.charts/ichartparagraphformat/margin_left/) | Returnerar eller anger vänstermarginalen i ett stycke.<br/>            Läs/skriv **float**. |
| [`margin_right`](/slides/python-net/sv/aspose.slides.charts/ichartparagraphformat/margin_right/) | Returnerar eller anger högermarginalen i ett stycke.<br/>            Läs/skriv **float**. |
| [`indent`](/slides/python-net/sv/aspose.slides.charts/ichartparagraphformat/indent/) | Returnerar eller anger första radindragning/hängande indragning för stycket. Hängande indragning kan definieras med negativa värden.<br/>            Läs/skriv **float**. |
| [`default_tab_size`](/slides/python-net/sv/aspose.slides.charts/ichartparagraphformat/default_tab_size/) | Returnerar eller anger standardtabulatorns storlek.<br/>            Läs/skriv **float**. |
| [`tabs`](/slides/python-net/sv/aspose.slides.charts/ichartparagraphformat/tabs/) | Returnerar tabulatorer för ett stycke.<br/>            Endast läsning [`ITabCollection`](/slides/python-net/sv/aspose.slides/itabcollection). |
| [`font_alignment`](/slides/python-net/sv/aspose.slides.charts/ichartparagraphformat/font_alignment/) | Returnerar eller anger en teckensnittjustering i ett stycke.<br/>            Läs/skriv [`FontAlignment`](/slides/python-net/sv/aspose.slides/fontalignment). |
