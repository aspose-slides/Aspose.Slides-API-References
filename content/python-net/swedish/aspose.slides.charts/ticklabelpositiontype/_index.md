## TickLabelPositionType enumeration

Representerar vilken typ av position som tick-markeringarnas etiketter har på den angivna axeln.

TickLabelPositionType-typen exponerar följande medlemmar:

## Fields

| Field | Description |
| :- | :- |
| HIGH | Anger att axelns etiketter ska vara på den högra änden av den ortogonala axeln. |
| LOW | Anger att axelns etiketter ska vara på den låga änden av den ortogonala axeln. |
| NEXT_TO | Anger att axelns etiketter ska vara intill axeln. |
| NONE | Anger att axelns etiketter inte ritas. |
