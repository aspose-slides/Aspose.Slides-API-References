## Rotation3D klass

Representerar 3D-rotation av ett diagram.

Rotation3D-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`rotation_x`](/slides/python-net/sv/aspose.slides.charts/rotation3d/rotation_x/) | Returnerar eller anger rotationsgraden runt X-axeln, d.v.s. i Y-riktningen för 3D-diagram (mellan -90 och 90 grader).<br/>            Egendomen matchar med 21.2.2.157 rotX (X Rotation)-elementet i ECMA-376 och med "Y Rotation"-alternativet i PowerPoint 2007+.<br/>            Läs/skriv **int**. |
| [`rotation_y`](/slides/python-net/sv/aspose.slides.charts/rotation3d/rotation_y/) | Returnerar eller anger rotationsgraden runt Y-axeln, d.v.s. i X-riktningen för 3D-diagram (mellan 0 och 360 grader).<br/>            Egendomen matchar med 21.2.2.158 rotY (Y Rotation)-elementet i ECMA-376 och med "X Rotation"-alternativet i PowerPoint 2007+.<br/>            Läs/skriv **int**. |
| [`perspective`](/slides/python-net/sv/aspose.slides.charts/rotation3d/perspective/) | Returnerar eller anger perspektivvärdet (fältavståndsvinkel) för 3D-diagram (mellan 0 och 240).<br/>            Ignoreras om RightAngleAxes-egenskapens värde är sant.<br/>            Läs/skriv **int**. |
| [`right_angle_axes`](/slides/python-net/sv/aspose.slides.charts/rotation3d/right_angle_axes/) | Bestämmer om diagramaxlarna är i räta vinklar, snarare än ritade i perspektiv.<br/>            Med andra ord bestämmer den om diagrammets axelvinklar är oberoende av diagrammets <br/>            rotation eller höjd.<br/>            Läs/skriv **bool**. |
| [`depth_percents`](/slides/python-net/sv/aspose.slides.charts/rotation3d/depth_percents/) | Returnerar eller anger djupet för ett 3D-diagram som en procentsats av diagrammets bredd (mellan 20 och 2000 procent).<br/>            Läs/skriv **int**. |
| [`height_percents`](/slides/python-net/sv/aspose.slides.charts/rotation3d/height_percents/) | Anger höjden för ett 3-D-diagram som en procentsats av diagrammets bredd (mellan 5 och 500 procent).<br/>            Läs/skriv **int**. |
