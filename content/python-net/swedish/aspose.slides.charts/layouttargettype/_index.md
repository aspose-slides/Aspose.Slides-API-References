## LayoutTargetType enumeration

Om layouten för plotområdet definieras manuellt anger denna egenskap huruvida 
            plotområdet ska läggas upp på insidan (utan axlar och axelrubriker) eller på utsidan
            (med axlar och axelrubriker).

Typen LayoutTargetType exponerar följande medlemmar:

## Fält

| Field | Description |
| :- | :- |
| INNER | Anger att storleken på plotområdet ska bestämma<br/>            storleken på plotområdet, utan tick-markeringar och<br/>            axelrubriker. |
| OUTER | Anger att storleken på plotområdet ska bestämma<br/>            storleken på plotområdet, tick-markeringarna och axelrubrikerna. |
