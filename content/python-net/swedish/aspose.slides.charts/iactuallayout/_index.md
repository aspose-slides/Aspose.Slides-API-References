## IActualLayout klass

Anger den faktiska positionen för ett diagramlement.

IActualLayout-typen visar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`actual_x`](/slides/python-net/sv/aspose.slides.charts/iactuallayout/actual_x/) | Anger den faktiska x-positionen (vänster) för diagrammetlementet i förhållande till diagrammets vänstra övre hörn.<br/>            Anropa metoden IChart.ValidateChartLayout() innan för att få faktiska värden. <br/>            Läs **float**. |
| [`actual_y`](/slides/python-net/sv/aspose.slides.charts/iactuallayout/actual_y/) | Anger den faktiska övre kanten på diagrammetlementet i förhållande till diagrammets vänstra övre hörn.<br/>            Anropa metoden IChart.ValidateChartLayout() innan för att få faktiska värden. <br/>            Läs **float**. |
| [`actual_width`](/slides/python-net/sv/aspose.slides.charts/iactuallayout/actual_width/) | Anger den faktiska bredden på diagrammetlementet. Anropa metoden IChart.ValidateChartLayout() innan för att få faktiska värden. <br/>            Läs **float**. |
| [`actual_height`](/slides/python-net/sv/aspose.slides.charts/iactuallayout/actual_height/) | Anger den faktiska höjden på diagrammetlementet. Anropa metoden IChart.ValidateChartLayout() innan för att få faktiska värden. <br/>            Läs **float**. |
