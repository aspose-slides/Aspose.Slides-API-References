## hide(self) {#}
Gör dataetiketten dold genom att sätta alla Show*-flaggor (ShowValue, ...) till falskt tillstånd.
            IsVisible kommer att vara falskt efter detta.


```python
def hide(self):
    ...
```


### Anmärkningar

Om dataetiketten inte är synlig (IsVisible är falskt) kan du göra dataetiketten synlig genom att
            sätta Show*-flaggor (ShowValue, ...) till sant tillstånd.
