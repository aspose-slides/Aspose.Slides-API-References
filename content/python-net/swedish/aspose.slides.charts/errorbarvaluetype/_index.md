## ErrorBarValueType uppräkning

Representerar typen av felstapelsvärde

ErrorBarValueType-typen exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| CUSTOM | Anger att längden på felstaplarna ska bestämmas av Plus och Minus element. |
| FIXED | Anger att längden på felstaplarna ska vara det fasta värdet som bestäms av Error Bar Value. |
| PERCENTAGE | Anger att längden på felstaplarna ska vara Error Bar Value procent av data. |
| STANDARD_DEVIATION | Anger att längden på felstaplarna ska vara Error Bar Value standardavvikelser av data. |
| STANDARD_ERROR | Anger att längden på felstaplarna ska vara Error Bar Value standardfel av data. |
