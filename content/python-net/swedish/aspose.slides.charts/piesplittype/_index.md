## PieSplitType enumeration

Representerar en typ av delningspunkter i den andra pajen eller stapeln på ett paj-i-paj- eller stapel-i-paj-diagram.

Typen PieSplitType exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| DEFAULT | Anger att datapunkterna ska delas med standard<br/>mekanismen för denna diagramtyp. |
| CUSTOM | Anger att datapunkterna ska delas mellan <br/> pajen och det andra diagrammet enligt Custom Split values. |
| BY_PERCENTAGE | Anger att datapunkterna ska delas mellan pajen och <br/> det andra diagrammet genom att placera de punkter med procentandel mindre än <br/> Split Position percent i det andra diagrammet. |
| BY_POS | Anger att datapunkterna ska delas mellan pajen och <br/> det andra diagrammet genom att placera den sista Split Position för datapunkterna <br/> i det andra diagrammet. |
| BY_VALUE | Anger att datapunkterna ska delas mellan pajen och <br/> det andra diagrammet genom att placera de datapunkter med värde mindre än <br/> Split Position i det andra diagrammet. |
