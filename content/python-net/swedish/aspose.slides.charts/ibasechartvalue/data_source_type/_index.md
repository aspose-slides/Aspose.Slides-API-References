## data_source_type egenskap
Anger om AsCell eller AsLiteralString eller AsLiteralDouble egenskap är aktuell. Med andra ord anger den typen av värde för Data egenskapen. Denna egenskap är skrivskyddad. För att ändra värdet på denna egenskap kan du använda en av ChartDataPointCollection.DataSourceTypeFor<...> egenskaperna. Läs/skriv [`IBaseChartValue.data_source_type`](/slides/python-net/sv/aspose.slides.charts/ibasechartvalue/data_source_type).
