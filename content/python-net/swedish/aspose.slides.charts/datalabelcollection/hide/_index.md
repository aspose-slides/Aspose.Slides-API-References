## hide(self) {#}
Gör dataetiketten dold som standard genom att sätta alla Show*-flags (ShowValue, ...) av 
            DefaultDataLabelFormat-egenskapen till falskt läge.
            IsVisible kommer att vara falskt efter detta.


```python
def hide(self):
    ...
```


### Anmärkningar

Om dataetiketten inte är synlig som standard (IsVisible är falskt) kan du göra dataetiketten "synlig 
            som standard" genom att sätta Show*-flags (ShowValue, ...) på DefaultDataLabelFormat-egenskapen
            till sant läge.
