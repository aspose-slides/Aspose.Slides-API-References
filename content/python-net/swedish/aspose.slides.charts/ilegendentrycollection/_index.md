## ILegendEntryCollection klass

Representerar en samling legender.

ILegendEntryCollection-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`count`](/slides/python-net/sv/aspose.slides.charts/ilegendentrycollection/count/) | Hämtar antalet element som faktiskt finns i samlingen.<br/>            Skrivskyddad **int**. |

Hämtar egenskaperna för legendposten som motsvarar Chart.ChartData.Series[0].DataPoints[index] i fallet med diagramtyp från denna lista:
              ChartType.BarOfPie,
              ChartType.ExplodedPie,
              ChartType.ExplodedPie3D,
              ChartType.Pie,
              ChartType.Pie3D,
              ChartType.PieOfPie;
            eller motsvarande till Chart.ChartData.Series[index] för andra diagramtyper.
