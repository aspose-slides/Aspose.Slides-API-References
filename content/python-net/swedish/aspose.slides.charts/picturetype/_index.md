## PictureType-enumeration

Bestämmer läget för stapelbildens fyllning.

PictureType-typen exponerar följande medlemmar:

## Fält

| Field | Description |
| :- | :- |
| NOT_DEFINED | Inte definierad. |
| STACK | Bilden storas för att upprepas högst 15 gånger i den längst staplade stapeln. |
| STACK_SCALE | Bilden storas till ett angivet antal enheter och upprepas längs stapelns längd. |
| STRETCH | Bilden sträcks över hela stapelns längd. |
