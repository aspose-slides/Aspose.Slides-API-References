## IRotation3D klass

Representerar 3D-rotation av ett diagram.

IRotation3D-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`rotation_x`](/slides/python-net/sv/aspose.slides.charts/irotation3d/rotation_x/) | Returnerar eller anger rotationsgraden runt X-axeln, dvs. i Y-riktning för 3D-diagram (mellan -90 och 90 grader).<br/>            Egenskapen motsvarar 21.2.2.157 rotX (X Rotation)-elementet i ECMA-376 och alternativet "Y Rotation" i PowerPoint 2007+.<br/>            Läs/skriv **int**. |
| [`rotation_y`](/slides/python-net/sv/aspose.slides.charts/irotation3d/rotation_y/) | Returnerar eller anger rotationsgraden runt Y-axeln, dvs. i X-riktning för 3D-diagram (mellan 0 och 360 grader).<br/>            Egenskapen motsvarar 21.2.2.158 rotY (Y Rotation)-elementet i ECMA-376 och alternativet "X Rotation" i PowerPoint 2007+.<br/>            Läs/skriv **int**. |
| [`perspective`](/slides/python-net/sv/aspose.slides.charts/irotation3d/perspective/) | Returnerar eller anger perspektivvärdet (fältvinkel) för 3D-diagram (mellan 0 och 100).<br/>            Ignoreras om RightAngleAxes-egenskapens värde är sant.<br/>            Läs/skriv **int**. |
| [`right_angle_axes`](/slides/python-net/sv/aspose.slides.charts/irotation3d/right_angle_axes/) | Bestämmer om diagramaxlarna är i räta vinklar, snarare än ritade i perspektiv.<br/>            Med andra ord bestämmer den om diagrammets axelvinklar är oberoende av diagrammets <br/>            rotation eller höjd.<br/>            Läs/skriv **bool**. |
| [`depth_percents`](/slides/python-net/sv/aspose.slides.charts/irotation3d/depth_percents/) | Returnerar eller anger djupet på ett 3D-diagram som en procentandel av diagrammets bredd (mellan 20 och 2000 procent).<br/>            Läs/skriv **int**. |
| [`height_percents`](/slides/python-net/sv/aspose.slides.charts/irotation3d/height_percents/) | Anger höjden på ett 3-D-diagram som en procentandel av diagrammets bredd (mellan 5 och 500 procent).<br/>            Läs/skriv **int**. |
