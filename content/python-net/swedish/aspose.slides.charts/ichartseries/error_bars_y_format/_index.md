## error_bars_y_format egenskap
Representerar ErrorBars för serier med riktning Y.
            
            ErrorBars med Y-riktning är tillgängliga för serier av typen area, bar, line, scatter och bubble. 
            För alla andra diagramtyper returnerar denna egenskap None (inklusive 3D-diagram). 
            Om du använder anpassade värden, använd DataPoints-samlingen för att ange värdet
            (med [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/sv/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) egenskap).
            
            Skrivskyddad [`IErrorBarsFormat`](/slides/python-net/sv/aspose.slides.charts/ierrorbarsformat).
