## Legend-klass

Representerar diagrammets legendegenskaper.

Legend-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`x`](/slides/python-net/sv/aspose.slides.charts/legend/x/) | Returnerar eller anger x-koordinaten för en legend som en bråkdel av diagrammets bredd.<br/>            Läs/skriv **float**. |
| [`y`](/slides/python-net/sv/aspose.slides.charts/legend/y/) | Returnerar eller anger y-koordinaten för en legend som en bråkdel av diagrammets höjd.<br/>            Läs/skriv **float**. |
| [`width`](/slides/python-net/sv/aspose.slides.charts/legend/width/) | Returnerar eller anger bredden för en legend som en bråkdel av diagrammets bredd.<br/>            Läs/skriv **float**. |
| [`height`](/slides/python-net/sv/aspose.slides.charts/legend/height/) | Returnerar eller anger höjden för en legend som en bråkdel av diagrammets höjd.<br/>            Läs/skriv **float**. |
| [`right`](/slides/python-net/sv/aspose.slides.charts/legend/right/) | Höger.<br/>            Endast läsning **float**. |
| [`bottom`](/slides/python-net/sv/aspose.slides.charts/legend/bottom/) | Nederst.<br/>            Endast läsning **float**. |
| [`overlay`](/slides/python-net/sv/aspose.slides.charts/legend/overlay/) | Bestämmer om andra diagramelement får överlappa legend.<br/>            Läs/skriv **bool**. |
| [`text_format`](/slides/python-net/sv/aspose.slides.charts/legend/text_format/) | Textformat.<br/>            Endast läsning [`IChartTextFormat`](/slides/python-net/sv/aspose.slides.charts/icharttextformat). |
| [`position`](/slides/python-net/sv/aspose.slides.charts/legend/position/) | Anger legendens position i ett diagram.<br/>            Icke-NaN-värden för egenskaperna X, Y, Width, Heigt åsidosätter effekten av denna egenskap.<br/>            Läs/skriv [`LegendPositionType`](/slides/python-net/sv/aspose.slides.charts/legendpositiontype). |
| [`format`](/slides/python-net/sv/aspose.slides.charts/legend/format/) | Returnerar formatet för en legend.<br/>            Endast läsning [`IFormat`](/slides/python-net/sv/aspose.slides.charts/iformat). |
| [`chart`](/slides/python-net/sv/aspose.slides.charts/legend/chart/) | Returnerar diagrammet.<br/>            Endast läsning [`IChart`](/slides/python-net/sv/aspose.slides.charts/ichart). |
| [`entries`](/slides/python-net/sv/aspose.slides.charts/legend/entries/) | Hämtar legendposter.<br/>            Endast läsning [`ILegendEntryCollection`](/slides/python-net/sv/aspose.slides.charts/ilegendentrycollection). |
| [`actual_x`](/slides/python-net/sv/aspose.slides.charts/legend/actual_x/) | Anger den faktiska x-positionen (vänster) för diagrammets element relativt diagrammets vänstra övre hörn.<br/>            Anropa metoden IChart.ValidateChartLayout() innan för att få faktiska värden. <br/>            Läs **float**. |
| [`actual_y`](/slides/python-net/sv/aspose.slides.charts/legend/actual_y/) | Anger den faktiska toppen för diagrammets element relativt diagrammets vänstra övre hörn.<br/>            Anropa metoden IChart.ValidateChartLayout() innan för att få faktiska värden. <br/>            Läs **float**. |
| [`actual_width`](/slides/python-net/sv/aspose.slides.charts/legend/actual_width/) | Anger den faktiska bredden för diagrammets element. Anropa metoden IChart.ValidateChartLayout() innan för att få faktiska värden. <br/>            Läs **float**. |
| [`actual_height`](/slides/python-net/sv/aspose.slides.charts/legend/actual_height/) | Anger den faktiska höjden för diagrammets element. Anropa metoden IChart.ValidateChartLayout() innan för att få faktiska värden. <br/>            Läs **float**. |
