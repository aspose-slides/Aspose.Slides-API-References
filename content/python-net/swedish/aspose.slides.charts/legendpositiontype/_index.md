## LegendPositionType enumeration

Bestämmer legendens position på ett diagram.

Typen LegendPositionType exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| BOTTOM | Anger att legenden ska ritas längst ner på diagrammet. |
| LEFT | Anger att legenden ska ritas längst till vänster på diagrammet. |
| RIGHT | Anger att legenden ska ritas längst till höger på diagrammet. |
| TOP | Anger att legenden ska ritas högst upp på diagrammet. |
| TOP_RIGHT | Anger att legenden ska ritas uppe till höger på diagrammet. |
