## IErrorBarsFormat klass

Representerar felstaplar för diagramserier. ErrorBars anpassade värden finns i IChartDataPointCollection
            (i [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/sv/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) egenskap).

IErrorBarsFormat-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`type`](/slides/python-net/sv/aspose.slides.charts/ierrorbarsformat/type/) | Hämtar eller anger typ av felstaplar. <br/>            Läs/skriv [`ErrorBarType`](/slides/python-net/sv/aspose.slides.charts/errorbartype). |
| [`value_type`](/slides/python-net/sv/aspose.slides.charts/ierrorbarsformat/value_type/) | Representerar möjliga sätt att bestämma längden på felstaplarna. <br/>            Vid anpassad värdetyp för att specificera värde, använd [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/sv/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) egenskap för specifik datapunkt i DataPoints-samlingen för serien.  <br/>            Läs/skriv [`ErrorBarValueType`](/slides/python-net/sv/aspose.slides.charts/errorbarvaluetype). |
| [`has_end_cap`](/slides/python-net/sv/aspose.slides.charts/ierrorbarsformat/has_end_cap/) | Anger att en ändkappa inte ritas på felstaplarna.<br/>            Läs/skriv **bool**. |
| [`value`](/slides/python-net/sv/aspose.slides.charts/ierrorbarsformat/value/) | Hämtar eller anger värde som används med Fixed, Percentage och StandardDeviation värdetyper för att bestämma längden på felstaplarna. <br/>            Läs/skriv **float**. |
| [`format`](/slides/python-net/sv/aspose.slides.charts/ierrorbarsformat/format/) | Representerar formatet för felstaplarna.<br/>            Läs/skriv [`IFormat`](/slides/python-net/sv/aspose.slides.charts/iformat). |
| [`is_visible`](/slides/python-net/sv/aspose.slides.charts/ierrorbarsformat/is_visible/) | Hämtar eller anger synlighet för Error Bars.<br/>            Läs/skriv **bool**. |
