## use_cells egenskap
Om true så används kalkylbladet för att lagra kategorier (detta fall stöder kategorier med flera nivåer).
            Om false så används kalkylbladet INTE för att lagra värden (och detta fall stöder inte 
            kategorier med flera nivåer).
            Läs/skriv **bool**.
