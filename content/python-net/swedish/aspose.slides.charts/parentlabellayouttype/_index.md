## ParentLabelLayoutType uppräkning

Representerar layout för kategori-datatetiketter. Används endast med Treemap-serier.

ParentLabelLayoutType-typen exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| BANNER | Anger att föräldrakategori-etiketter visas som banner |
| NONE | Anger att föräldrakategori-etiketter inte ritas |
| OVERLAPPING | Anger att föräldrakategori-etiketter visas som överlappande |
