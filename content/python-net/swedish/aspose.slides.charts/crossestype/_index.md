## CrossesType enumeration

Bestämmer var axeln korsas.

CrossesType-typen exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| AXIS_CROSSES_AT_ZERO | Kategoriekaxeln korsas vid nollpunkten på värdeaxeln (om möjligt), annars vid minsta värdet (om minsta är större än noll) eller högsta värdet (om högsta är mindre än noll). |
| MAXIMUM | Axeln korsas vid det maximala värdet. |
| CUSTOM | Anpassat värde från egenskapen CrossAt |
