## TickMarkType enumeration

Representerar tickmark-typen för den angivna axeln.

TickMarkType-typen exponerar följande medlemmar:

## Fields

| Fält | Beskrivning |
| :- | :- |
| CROSS | Anger att ticmarkeringarna ska korsa axeln. |
| INSIDE | Anger att ticmarkeringarna ska vara inne i plotområdet. |
| NONE | Anger att det inte skall finnas några ticmarkeringar. |
| OUTSIDE | Anger att ticmarkeringarna ska vara utanför plotområdet. |
