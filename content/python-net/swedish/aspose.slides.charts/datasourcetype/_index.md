## DataSourceType enumeration

Datakälltyper.

DataSourceType-typen exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| WORKSHEET | Använd CellXls-objekt för att lagra XValue, YValue, Value eller BubbleSize för datapunkt i kalkylbladet. |
| STRING_LITERALS | Använd snabbåtkomst-strängvariabel för att lagra XValue, YValue, Value eller BubbleSize för <br/>            datapunkt. Kalkylbladet används INTE för att lagra värden. |
| DOUBLE_LITERALS | Använd snabbåtkomst-double-variabel för att lagra XValue, YValue, Value eller BubbleSize för <br/>            datapunkt. Kalkylbladet använder INTE för att lagra värden. |
