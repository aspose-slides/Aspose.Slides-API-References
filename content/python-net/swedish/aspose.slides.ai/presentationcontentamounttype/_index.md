## PresentationContentAmountType enumeration

Anger mängden innehåll som inkluderas i den genererade presentationen, vilket påverkar både antalet bilder och detaljnivån per bild.

Typen PresentationContentAmountType exponeras följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| BRIEF | Kort och grundläggande innehåll. |
| MEDIUM | En måttlig mängd innehåll. |
| DETAILED | Det mest detaljerade alternativet med omfattande text. |
