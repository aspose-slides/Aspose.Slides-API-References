## BuildType uppräkning

Bestämmer hur text kommer att visas på en form under animation.

BuildType-typen exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| AS_ONE_OBJECT | Med den innehållande formen. |
| ALL_PARAGRAPHS_AT_ONCE | Alla stycken. |
| BY_LEVEL_PARAGRAPHS1 | Efter grupper av stycken med djup 1. |
| BY_LEVEL_PARAGRAPHS2 | Efter grupper av stycken med djup 2. |
| BY_LEVEL_PARAGRAPHS3 | Efter grupper av stycken med djup 3. |
| BY_LEVEL_PARAGRAPHS4 | Efter grupper av stycken med djup 4. |
| BY_LEVEL_PARAGRAPHS5 | Efter grupper av stycken med djup 5. |
