## ITiming klass

Representerar animationstiming.

ITiming-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`accelerate`](/slides/python-net/sv/aspose.slides.animation/itiming/accelerate/) | Beskriver procentsatsen av varaktigheten för accelerationsbeteendeeffekten.<br/>            Läsa/skriva **float**. |

| [`auto_reverse`](/slides/python-net/sv/aspose.slides.animation/itiming/auto_reverse/) | Beskriver huruvida animationen ska spelas automatiskt i omvänd riktning efter<br/>            att den spelats i framåtriktning.<br/>            Läsa/skriva **bool**. |
| [`duration`](/slides/python-net/sv/aspose.slides.animation/itiming/duration/) | Beskriver varaktigheten för animationseffekten.<br/>            Läsa/skriva **float**. |
| [`repeat_count`](/slides/python-net/sv/aspose.slides.animation/itiming/repeat_count/) | Beskriver antalet gånger effekten ska upprepas.<br/>            Läsa/skriva **float**. |

| [`rewind`](/slides/python-net/sv/aspose.slides.animation/itiming/rewind/) | Detta attribut anger om effekten ska spolas tillbaka när den är klar.<br/>             Läsa/skriva **bool**. |
