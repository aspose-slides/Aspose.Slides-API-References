## Timing-klass

Representerar animeringstid.

Timing-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`accelerate`](/slides/python-net/sv/aspose.slides.animation/timing/accelerate/) | Beskriver procentsatsen av varaktigheten för accelererande beteendeeffekt.<br/>            Läs/skriv **float**. |
| [`decelerate`](/slides/python-net/sv/aspose.slides.animation/timing/decelerate/) | Beskriver procentsatsen av varaktigheten för decelererande beteendeeffekt.<br/>            Läs/skriv **float**. |
| [`auto_reverse`](/slides/python-net/sv/aspose.slides.animation/timing/auto_reverse/) | Beskriver om animationen automatiskt ska spelas upp i omvänd riktning efter<br/>            att den spelats framåt.<br/>            Läs/skriv **bool**. |
| [`duration`](/slides/python-net/sv/aspose.slides.animation/timing/duration/) | Beskriver varaktigheten för animationseffekten.<br/>            Läs/skriv **float**. |
| [`repeat_count`](/slides/python-net/sv/aspose.slides.animation/timing/repeat_count/) | Beskriver hur många gånger effekten ska upprepas.<br/>            Läs/skriv **float**. |
| [`repeat_until_end_slide`](/slides/python-net/sv/aspose.slides.animation/timing/repeat_until_end_slide/) | Detta attribut anger om effekten ska upprepas tills slutet av bilden.<br/>            Läs/skriv **bool**. |
| [`repeat_until_next_click`](/slides/python-net/sv/aspose.slides.animation/timing/repeat_until_next_click/) | Detta attribut anger om effekten ska upprepas tills nästa klick.<br/>            Läs/skriv **bool**. |
| [`repeat_duration`](/slides/python-net/sv/aspose.slides.animation/timing/repeat_duration/) | Beskriver hur många gånger effekten ska upprepas.<br/>            Läs/skriv **float**. |
| [`restart`](/slides/python-net/sv/aspose.slides.animation/timing/restart/) | Anger om en effekt ska startas om efter att den är klar.<br/>            Läs/skriv [`EffectRestartType`](/slides/python-net/sv/aspose.slides.animation/effectrestarttype). |
| [`rewind`](/slides/python-net/sv/aspose.slides.animation/timing/rewind/) | Detta attribut anger om effekten ska spolas tillbaka när den är spelad färdigt.<br/>            Läs/skriv **bool**. |
| [`speed`](/slides/python-net/sv/aspose.slides.animation/timing/speed/) | Anger procentsatsen för hur mycket tidsinställningen ska accelereras (eller bromsas).<br/>            Läs/skriv **float**. |
| [`trigger_delay_time`](/slides/python-net/sv/aspose.slides.animation/timing/trigger_delay_time/) | Beskriver fördröjningstid efter utlösare.<br/>            Läs/skriv **float**. |
| [`trigger_type`](/slides/python-net/sv/aspose.slides.animation/timing/trigger_type/) | Beskriver utlöstyp.<br/>            Läs/skriv [`EffectTriggerType`](/slides/python-net/sv/aspose.slides.animation/effecttriggertype). |
