## IPoint klass

Representerar animeringspunkt.

IPoint-typen exponeras följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`time`](/slides/python-net/sv/aspose.slides.animation/ipoint/time/) | Representerar tidsvärde.<br/>            Läs/skriv **float**. |
| [`value`](/slides/python-net/sv/aspose.slides.animation/ipoint/value/) | Representerar punktvärde.<br/>            Endast: bool, ColorFormat, float, int, string.<br/>            Läs/skriv **any**. |
