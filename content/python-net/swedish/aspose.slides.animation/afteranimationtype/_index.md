## AfterAnimationType enumeration

Representerar typen av efteranimation för en animationseffekt.

Typen AfterAnimationType exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| DO_NOT_DIM | Dimma inte efter animationstyp. |
| COLOR | Färg efter animationstyp. |
| HIDE_AFTER_ANIMATION | Dölj efter animationstyp |
| HIDE_ON_NEXT_MOUSE_CLICK | Dölj vid nästa musklick efter animationstyp. |
