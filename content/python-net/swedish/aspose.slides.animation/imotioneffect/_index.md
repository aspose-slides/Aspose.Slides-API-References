## IMotionEffect klass

Representerar rörelseeffektens beteende för effekten.

IMotionEffect-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`from_address`](/slides/python-net/sv/aspose.slides.animation/imotioneffect/from_address/) | Anger en x/y-koordinat för att starta animationen från (i procent). <br/>            Läs/skriv [`PointF`](/slides/python-net/sv/aspose.slides/pointf). |
| [`to`](/slides/python-net/sv/aspose.slides.animation/imotioneffect/to/) | Anger målplatsen för en animationens rörelseeffekt (i procent).<br/>            Läs/skriv [`PointF`](/slides/python-net/sv/aspose.slides/pointf). |
| [`by`](/slides/python-net/sv/aspose.slides.animation/imotioneffect/by/) | Beskriver det relativa förskjutningsvärdet för animationen (i procent).<br/>            Läs/skriv [`PointF`](/slides/python-net/sv/aspose.slides/pointf). |
| [`rotation_center`](/slides/python-net/sv/aspose.slides.animation/imotioneffect/rotation_center/) | Beskriver rotationscentrumet som används för att rotera en rörelsebana med X vinkel.<br/>            Läs/skriv [`PointF`](/slides/python-net/sv/aspose.slides/pointf). |
| [`origin`](/slides/python-net/sv/aspose.slides.animation/imotioneffect/origin/) | Anger vad ursprunget för rörelsebanan är relativt till exempel layouten på bilden,<br/>            eller föräldern.<br/>            Läs/skriv [`MotionOriginType`](/slides/python-net/sv/aspose.slides.animation/motionorigintype). |
| [`path`](/slides/python-net/sv/aspose.slides.animation/imotioneffect/path/) | Anger banprimitivet följt av koordinater för animationens rörelse.<br/>            Läs/skriv [`IMotionPath`](/slides/python-net/sv/aspose.slides.animation/imotionpath). |
| [`path_edit_mode`](/slides/python-net/sv/aspose.slides.animation/imotioneffect/path_edit_mode/) | Anger hur rörelsebanan rör sig när formen flyttas.<br/>            Läs/skriv [`MotionPathEditMode`](/slides/python-net/sv/aspose.slides.animation/motionpatheditmode). |
| [`angle`](/slides/python-net/sv/aspose.slides.animation/imotioneffect/angle/) | Beskriver den relativa vinkeln för rörelsebanan.<br/>            Läs/skriv **float**. |
