## IMotionEffect klass

Representerar beteendet för en rörelseeffekt.

IMotionEffect-typen visar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`from_address`](/slides/python-net/sv/aspose.slides.animation/imotioneffect/from_address/) | Anger en x/y-koordinat för att starta animationen från (i procent). <br/>            Läs/skriv **aspose.slides.PointF**. |
| [`to`](/slides/python-net/sv/aspose.slides.animation/imotioneffect/to/) | Anger målplatsen för en animationsrörelseeffekt (i procent).<br/>            Läs/skriv **aspose.slides.PointF**. |
| [`by`](/slides/python-net/sv/aspose.slides.animation/imotioneffect/by/) | Beskriver det relativa offset-värdet för animationen (i procent).<br/>            Läs/skriv **aspose.slides.PointF**. |
| [`rotation_center`](/slides/python-net/sv/aspose.slides.animation/imotioneffect/rotation_center/) | Beskriver rotationscentrum som används för att rotera en rörelsespår med X vinkel.<br/>            Läs/skriv **aspose.slides.PointF**. |
| [`origin`](/slides/python-net/sv/aspose.slides.animation/imotioneffect/origin/) | Anger vad ursprunget för rörelsespåret är relativt till, till exempel layouten av bildspelet,<br/>            eller föräldern.<br/>            Läs/skriv [`MotionOriginType`](/slides/python-net/sv/aspose.slides.animation/motionorigintype). |
| [`path`](/slides/python-net/sv/aspose.slides.animation/imotioneffect/path/) | Anger den grundläggande spåret som följs av koordinater för animationsrörelsen.<br/>            Läs/skriv [`IMotionPath`](/slides/python-net/sv/aspose.slides.animation/imotionpath). |
| [`path_edit_mode`](/slides/python-net/sv/aspose.slides.animation/imotioneffect/path_edit_mode/) | Anger hur rörelsespåret rör sig när formen flyttas.<br/>            Läs/skriv [`MotionPathEditMode`](/slides/python-net/sv/aspose.slides.animation/motionpatheditmode). |
| [`angle`](/slides/python-net/sv/aspose.slides.animation/imotioneffect/angle/) | Beskriver den relativa vinkeln för rörelsespåret.<br/>            Läs/skriv **float**. |
