Effect-typen exponerar följande medlemmar:

| Property | Description |
| :- | :- |
| [`sequence`](/slides/python-net/sv/aspose.slides.animation/effect/sequence/) | Returns a sequence for an effect.<br/>            Skrivskyddad [`ISequence`](/slides/python-net/sv/aspose.slides.animation/isequence). |

| [`preset_class_type`](/slides/python-net/sv/aspose.slides.animation/effect/preset_class_type/) | Definierar klass av effekt.<br/>            Läs/skriv [`EffectPresetClassType`](/slides/python-net/sv/aspose.slides.animation/effectpresetclasstype). |
| [`type`](/slides/python-net/sv/aspose.slides.animation/effect/type/) | Definierar typ av effekt.<br/>            Läs/skriv [`EffectType`](/slides/python-net/sv/aspose.slides.animation/effecttype). |
| [`subtype`](/slides/python-net/sv/aspose.slides.animation/effect/subtype/) | Definierar undertyp av effekt.<br/>            Läs/skriv [`EffectSubtype`](/slides/python-net/sv/aspose.slides.animation/effectsubtype). |
| [`behaviors`](/slides/python-net/sv/aspose.slides.animation/effect/behaviors/) | Returnerar en samling av beteenden för en effekt.<br/>            Läs/skriv [`IBehaviorCollection`](/slides/python-net/sv/aspose.slides.animation/ibehaviorcollection). |
| [`timing`](/slides/python-net/sv/aspose.slides.animation/effect/timing/) | Definierar tidsvärde för effekt.<br/>            Läs/skriv [`ITiming`](/slides/python-net/sv/aspose.slides.animation/itiming). |
| [`target_shape`](/slides/python-net/sv/aspose.slides.animation/effect/target_shape/) | Returnerar målform för effekt.<br/>            Skrivskyddad [`IShape`](/slides/python-net/sv/aspose.slides/ishape). |
| [`sound`](/slides/python-net/sv/aspose.slides.animation/effect/sound/) | Definierar inbäddat ljud för effekt.<br/>            Läs/skriv [`IAudio`](/slides/python-net/sv/aspose.slides/iaudio). |
| [`stop_previous_sound`](/slides/python-net/sv/aspose.slides.animation/effect/stop_previous_sound/) | Detta attribut anger om animationseffekten stoppar det föregående ljudet.<br/>            Läs/skriv **bool**. |

| [`animate_text_type`](/slides/python-net/sv/aspose.slides.animation/effect/animate_text_type/) | Definierar en typ av animerad text för effekt. <br/>            Formens text kan animeras per bokstav, per ord eller hela på en gång.<br/>            Läs/skriv [`Effect.animate_text_type`](/slides/python-net/sv/aspose.slides.animation/effect/animate_text_type). |
| [`delay_between_text_parts`](/slides/python-net/sv/aspose.slides.animation/effect/delay_between_text_parts/) | Definierar en fördröjning mellan animerade textrdelar (ord eller bokstäver).<br/>            Ett positivt värde anger procenten av effektens varaktighet.<br/>            Ett negativt värde anger fördröjningen i sekunder.<br/>            Läs/skriv **float**. |
