## AnimateTextType enum

Representerar animeringstexttypen för en animationseffekt.

AnimateTextType-typen exponerar följande medlemmar:

## Fält

| Fält | Beskrivning |
| :- | :- |
| ALL_AT_ONCE | Animera all text på en gång. |
| BY_WORD | Animera text per ord. |
| BY_LETTER | Animera text per bokstav. |
