## AnimationTimeLine klass

Representerar tidslinjen för animation.

AnimationTimeLine-typen exponerar följande medlemmar:

## Egenskaper

| Egenskap | Beskrivning |
| :- | :- |
| [`interactive_sequences`](/slides/python-net/sv/aspose.slides.animation/animationtimeline/interactive_sequences/) | Returnerar en samling interaktiva sekvenser.<br/>            Denna sekvens får endast innehålla effekter genom "klicka på form" med specificerat målform.<br/>            Skrivskyddad [`ISequenceCollection`](/slides/python-net/sv/aspose.slides.animation/isequencecollection). |
| [`main_sequence`](/slides/python-net/sv/aspose.slides.animation/animationtimeline/main_sequence/) | Returnerar huvudsekvensen som kan innehålla endast en samling av huvud-effekter.<br/>            Skrivskyddad [`ISequence`](/slides/python-net/sv/aspose.slides.animation/isequence). |
| [`text_animation_collection`](/slides/python-net/sv/aspose.slides.animation/animationtimeline/text_animation_collection/) | Returnerar en samling textanimationer.<br/>            Skrivskyddad [`ITextAnimationCollection`](/slides/python-net/sv/aspose.slides.animation/itextanimationcollection). |
