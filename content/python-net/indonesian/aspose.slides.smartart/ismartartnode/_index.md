## ISmartArtNode kelas

Mewakili node dari diagram SmartArt.

Tipe ISmartArtNode mengekspos anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`child_nodes`](/slides/python-net/id/aspose.slides.smartart/ismartartnode/child_nodes/) | Mengembalikan koleksi semua node anak dari node saat ini.<br/>            Hanya-baca [`ISmartArtNodeCollection`](/slides/python-net/id/aspose.slides.smartart/ismartartnodecollection). |
| [`shapes`](/slides/python-net/id/aspose.slides.smartart/ismartartnode/shapes/) | Mengembalikan koleksi semua shape yang terkait dengan node.<br/>            Hanya-baca [`ISmartArtShapeCollection`](/slides/python-net/id/aspose.slides.smartart/ismartartshapecollection). |
| [`text_frame`](/slides/python-net/id/aspose.slides.smartart/ismartartnode/text_frame/) | Mengembalikan atau mengatur teks node.<br/>            Hanya-baca [`ITextFrame`](/slides/python-net/id/aspose.slides/itextframe). |
| [`is_assistant`](/slides/python-net/id/aspose.slides.smartart/ismartartnode/is_assistant/) | Mengembalikan atau mengatur node sebagai asisten.<br/>            Baca/tulis **bool**. |
| [`level`](/slides/python-net/id/aspose.slides.smartart/ismartartnode/level/) | Mengembalikan tingkat penumpukan node.<br/>            Hanya-baca **int**. |
| [`bullet_fill_format`](/slides/python-net/id/aspose.slides.smartart/ismartartnode/bullet_fill_format/) | Mengembalikan objek FillFormat yang berisi properti pemformatan isian untuk bullet node.<br/>            Catatan: dapat mengembalikan None untuk beberapa jenis tata letak SmartArt yang tidak menyediakan bullet untuk node.<br/>            Hanya-baca [`IFillFormat`](/slides/python-net/id/aspose.slides/ifillformat). |
| [`position`](/slides/python-net/id/aspose.slides.smartart/ismartartnode/position/) | Mengembalikan atau mengatur posisi berbasis nol node di antara node saudara.<br/>            Baca/tulis **int**. |
| [`is_hidden`](/slides/python-net/id/aspose.slides.smartart/ismartartnode/is_hidden/) | Mengembalikan true jika node ini adalah node tersembunyi dalam model data.<br/>            Hanya-baca **bool**. |
| [`organization_chart_layout`](/slides/python-net/id/aspose.slides.smartart/ismartartnode/organization_chart_layout/) | Mengembalikan atau mengatur tipe tata letak diagram organisasi yang terkait dengan node saat ini.<br/>            Baca/tulis [`OrganizationChartLayoutType`](/slides/python-net/id/aspose.slides.smartart/organizationchartlayouttype). |

## Metode

| Metode | Deskripsi |
| :- | :- |
| [`remove(self)`](/slides/python-net/id/aspose.slides.smartart/ismartartnode/remove/#) | Hapus node saat ini. |
