## OrganizationChartLayoutType enumerasi

Mewakili jenis pemformatan node anak dalam diagram organisasi

Tipe OrganizationChartLayoutType memperlihatkan anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| INITIAL | Tipe tata letak awal |
| STANDART | Menempatkan node anak secara horizontal di bawah node induk. |
| BOTH_HANGING | Menempatkan node anak secara vertikal di bawah node induk pada sisi kiri dan kanan. |
| LEFT_HANGING | Menempatkan node anak secara vertikal di bawah node induk pada sisi kiri. |
| RIGHT_HANGING | Menempatkan node anak secara vertikal di bawah node induk pada sisi kanan. |
