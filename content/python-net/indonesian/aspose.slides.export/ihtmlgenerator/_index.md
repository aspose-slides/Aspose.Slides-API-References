## IHtmlGenerator kelas

Generator HTML.

Tipe IHtmlGenerator menampilkan anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`slide_image_size`](/slides/python-net/id/aspose.slides.export/ihtmlgenerator/slide_image_size/) | Mengembalikan ukuran gambar slide.<br/>            Baca-saja **aspose.slides.SizeF**. |
| [`slide_image_size_unit`](/slides/python-net/id/aspose.slides.export/ihtmlgenerator/slide_image_size_unit/) | Mengembalikan satuan yang digunakan untuk menentukan ukuran gambar slide.<br/>            Baca-saja [`SvgCoordinateUnit`](/slides/python-net/id/aspose.slides.export/svgcoordinateunit). |
| [`slide_image_size_unit_code`](/slides/python-net/id/aspose.slides.export/ihtmlgenerator/slide_image_size_unit_code/) | Mengembalikan kode css dari satuan yang digunakan untuk menentukan ukuran gambar slide.<br/>            Baca-saja **str**. |
| [`previous_slide_index`](/slides/python-net/id/aspose.slides.export/ihtmlgenerator/previous_slide_index/) | Mengembalikan indeks slide yang telah dirender sebelumnya atau -1 jika slide pertama sedang dirender.<br/>            Baca-saja **int**. |
| [`slide_index`](/slides/python-net/id/aspose.slides.export/ihtmlgenerator/slide_index/) | Mengembalikan indeks slide yang sedang dirender.<br/>            Baca-saja **int**. |
| [`next_slide_index`](/slides/python-net/id/aspose.slides.export/ihtmlgenerator/next_slide_index/) | Mengembalikan indeks slide yang akan dirender setelah slide saat ini atau -1 jika slide terakhir sedang dirender.<br/>            Baca-saja **int**. |
