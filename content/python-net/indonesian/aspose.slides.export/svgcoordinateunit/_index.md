## SvgCoordinateUnit enumerasi

Mewakili satuan koordinat CSS2 yang digunakan untuk mendefinisikan koordinat SVG.

Tipe SvgCoordinateUnit menampilkan anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| INCH | Inci |
| CENTIMETER | Sentimeter. |
| MILLIMETER | Milimeter. |
| POINT | Poin (1/72 inci), |
| PICA | Pika (1/6 inci). |
| EM | Ukuran Em dari font elemen yang memuatnya. |
| EX | Ukuran Ex (ukuran huruf kecil, biasanya "x") dari font elemen yang memuatnya. |
| PIXEL | Ukuran piksel. |
| PERCENT | Persen. |
