## SaveFormat enumerasi

Konstanta yang menentukan format presentasi yang disimpan.

Tipe SaveFormat menampilkan anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| PPT | Simpan presentasi dalam format PPT. |
| PDF | Simpan presentasi dalam format PDF. |
| XPS | Simpan presentasi dalam format XPS. |
| PPTX | Simpan presentasi dalam format PPTX. |
| PPSX | Simpan presentasi dalam format PPSX (slideshow). |
| TIFF | Simpan presentasi sebagai gambar TIFF multi-halaman. |
| ODP | Simpan presentasi dalam format ODP. |
| PPTM | Simpan presentasi dalam format PPTM (presentasi dengan makro). |
| PPSM | Simpan presentasi dalam format PPSM (slideshow dengan makro). |
| POTX | Simpan presentasi dalam format POTX (template). |
| POTM | Simpan presentasi dalam format POTM (template dengan makro). |
| HTML | Simpan presentasi dalam format HTML. |
| SWF | Simpan presentasi dalam format SWF. |
| OTP | Simpan presentasi dalam format OTP (template presentasi). |
| PPS | Simpan presentasi dalam format PPS. |
| POT | Simpan presentasi dalam format POT. |
| FODP | Simpan presentasi dalam format FODP. |
| GIF | Simpan presentasi dalam format GIF. |
| HTML5 | Simpan presentasi dalam format HTML menggunakan sistem templat HTML5 baru. |
| MD | Simpan presentasi dalam format Markdown |
| XML | Simpan presentasi dalam format PowerPoint XML Presentation. |
