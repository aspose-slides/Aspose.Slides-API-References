## enumerasi HandoutType

Menentukan berapa banyak slide dan dalam urutan apa yang akan ditempatkan pada halaman.

Tipe HandoutType menyajikan anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| HANDOUTS1 | Satu slide per halaman. |
| HANDOUTS2 | Dua slide per halaman. |
| HANDOUTS3 | Tiga slide per halaman. |
| HANDOUTS_4_HORIZONTAL | Empat slide per halaman dalam urutan horizontal. |
| HANDOUTS_4_VERTICAL | Empat slide per halaman dalam urutan vertikal. |
| HANDOUTS_6_HORIZONTAL | Enam slide per halaman dalam urutan horizontal. |
| HANDOUTS_6_VERTICAL | Enam slide per halaman dalam urutan vertikal. |
| HANDOUTS_9_HORIZONTAL | Sembilan slide per halaman dalam urutan horizontal. |
| HANDOUTS_9_VERTICAL | Sembilan slide per halaman dalam urutan vertikal. |
