## disable_line_end_cropping properti
SVG 1.1 tidak memiliki kemampuan untuk mendefinisikan inset untuk penanda.
            Aspose.Slides SVG writing engine memiliki solusi untuk masalah itu:
            ia memotong ujung garis dengan panah, sehingga garis tidak tumpang tindih dengan penanda.
            Opsi ini menonaktifkan perilaku tersebut.
            Baca/tulis **bool**.
