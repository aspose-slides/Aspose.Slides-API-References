## HtmlGenerator kelas

Generator HTML.

Tipe HtmlGenerator mengekspos anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`slide_image_size`](/slides/python-net/id/aspose.slides.export/htmlgenerator/slide_image_size/) | Mengembalikan ukuran gambar slide.<br/>            Hanya-baca **aspose.slides.SizeF**. |
| [`slide_image_size_unit`](/slides/python-net/id/aspose.slides.export/htmlgenerator/slide_image_size_unit/) | Mengembalikan satuan di mana ukuran gambar slide ditentukan.<br/>            Hanya-baca [`SvgCoordinateUnit`](/slides/python-net/id/aspose.slides.export/svgcoordinateunit). |
| [`slide_image_size_unit_code`](/slides/python-net/id/aspose.slides.export/htmlgenerator/slide_image_size_unit_code/) | Mengembalikan kode CSS satuan di mana ukuran gambar slide ditentukan.<br/>            Hanya-baca **str**. |
| [`previous_slide_index`](/slides/python-net/id/aspose.slides.export/htmlgenerator/previous_slide_index/) | Mengembalikan indeks slide yang sebelumnya dirender atau -1 jika slide pertama sedang dirender.<br/>            Hanya-baca **int**. |
| [`slide_index`](/slides/python-net/id/aspose.slides.export/htmlgenerator/slide_index/) | Mengembalikan indeks slide yang sedang dirender.<br/>            Hanya-baca **int**. |
| [`next_slide_index`](/slides/python-net/id/aspose.slides.export/htmlgenerator/next_slide_index/) | Mengembalikan indeks slide yang akan dirender setelah slide saat ini atau -1 jika sedang merender slide terakhir.<br/>            Hanya-baca **int**. |
