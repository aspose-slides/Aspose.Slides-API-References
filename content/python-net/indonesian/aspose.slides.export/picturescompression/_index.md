## PicturesCompression enumerasi

Mewakili tingkat kompresi gambar

Tipe PicturesCompression menampilkan anggota berikut:

## Bidang

| Field | Description |
| :- | :- |
| DPI330 | Kualitas baik untuk tampilan definisi tinggi (HD) |
| DPI220 | Kualitas sangat baik pada sebagian besar printer dan layar |
| DPI150 | Baik untuk halaman web dan proyektor |
| DPI96 | Meminimalkan ukuran dokumen untuk berbagi |
| DPI72 | Tingkat kompresi default |
| DOCUMENT_RESOLUTION | Gunakan resolusi dokumen - gambar tidak akan dikompresi dan digunakan dalam dokumen apa adanya |
