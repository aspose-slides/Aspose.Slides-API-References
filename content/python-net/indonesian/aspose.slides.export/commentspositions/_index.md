## Enumerasi CommentsPositions

Mewakili aturan untuk merender komentar ke dalam dokumen yang diekspor

Tipe CommentsPositions mengekspos anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| NONE | Menentukan bahwa komentar tidak ditampilkan sama sekali. |
| BOTTOM | Menentukan bahwa komentar ditampilkan di bagian bawah halaman. |
| RIGHT | Menentukan bahwa komentar ditampilkan di sebelah kanan halaman. |
