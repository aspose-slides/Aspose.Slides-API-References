## Enumerasi Zip64Mode

Menentukan kapan harus menggunakan ekstensi format ZIP64 untuk file OpenXML.

Tipe Zip64Mode menampilkan anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| NEVER | Jangan gunakan ekstensi format ZIP64. |
| IF_NECESSARY | Gunakan ekstensi format ZIP64 jika diperlukan. |
| ALWAYS | Selalu gunakan ekstensi format ZIP64. |


### Catatan

File OpenXML adalah arsip ZIP yang memiliki batas 4 GB (2^32 byte) pada ukuran tidak terkompresi sebuah file, 
            ukuran terkompresi sebuah file, dan total ukuran arsip, serta batas 65.535 (2^16-1) file dalam arsip. 
            Ekstensi format ZIP64 meningkatkan batas menjadi 2^64.
