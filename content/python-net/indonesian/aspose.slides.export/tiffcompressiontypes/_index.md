## TiffCompressionTypes enumerasi

Menyediakan opsi yang mengontrol bagaimana sebuah presentasi dikompresi dalam format TIFF.

Tipe TiffCompressionTypes menampilkan anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| DEFAULT | Menentukan skema kompresi default (LZW). |
| NONE | Menentukan tidak ada kompresi. |
| CCITT3 | Menentukan skema kompresi CCITT3. |
| CCITT4 | Menentukan skema kompresi CCITT4. |
| LZW | Menentukan skema kompresi LZW (Default). |
| RLE | Menentukan skema kompresi RLE. |
