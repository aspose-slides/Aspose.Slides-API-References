## NotesPositions enumerasi

Mewakili aturan untuk merender catatan ke dalam dokumen yang diekspor

Tipe NotesPositions menampilkan anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| NONE | Menentukan bahwa catatan tidak boleh ditampilkan sama sekali. |
| BOTTOM_FULL | Menentukan bahwa catatan harus ditampilkan sepenuhnya menggunakan halaman tambahan sesuai kebutuhan. |
| BOTTOM_TRUNCATED | Menentukan bahwa catatan harus ditampilkan dalam satu halaman saja. |
