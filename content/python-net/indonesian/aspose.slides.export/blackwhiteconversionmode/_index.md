## BlackWhiteConversionMode enumerasi

Menyediakan opsi yang mengontrol bagaimana gambar slide akan dikonversi menjadi gambar bitonal.

Tipe BlackWhiteConversionMode menampilkan anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| DEFAULT | Menentukan tidak ada algoritma konversi. Algoritma yang diimplementasikan dalam codec TIFF akan digunakan. (Default) |
| DITHERING | Menentukan algoritma dithering (Floyd-Steinberg). |
| DITHERING_FLOYD_STEINBERG | Menentukan algoritma dithering Floyd-Steinberg. |
| AUTO | Menentukan algoritma ambang batas yang dihitung secara otomatis (Otsu). |
| AUTO_OTSU | Menentukan algoritma ambang batas Otsu yang dihitung secara otomatis. |
| THRESHOLD25 | Menentukan algoritma ambang batas statis (25%). |
| THRESHOLD50 | Menentukan algoritma ambang batas statis (50%). |
| THRESHOLD75 | Menentukan algoritma ambang batas statis (75%). |
