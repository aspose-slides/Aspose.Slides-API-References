## Enumerasi Kesesuaian

Menentukan kelas kesesuaian yang dipatuhi oleh dokumen PresentationML.

Tipe Conformance menampilkan anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| ECMA_376_2006 | Menunjukkan bahwa dokumen mematuhi ECMA376:2006. |
| ISO_29500_2008_TRANSITIONAL | Menunjukkan bahwa dokumen mematuhi kelas kesesuaian Transitional ISO/IEC 29500:2008. |
| ISO_29500_2008_STRICT | Menunjukkan bahwa dokumen mematuhi kelas kesesuaian Strict ISO/IEC 29500:2008. |
