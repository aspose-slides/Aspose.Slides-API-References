## IPptxOptions kelas

Mewakili opsi untuk menyimpan presentasi OpenXml (PPTX, PPSX, POTX, PPTM, PPSM, POTM).

Tipe IPptxOptions menampilkan anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`conformance`](/slides/python-net/id/aspose.slides.export/ipptxoptions/conformance/) | Menentukan kelas kepatuhan yang diikuti oleh dokumen Presentation.<br/>            Nilai default adalah [`Conformance.ECMA_376_2006`](/slides/python-net/id/aspose.slides.export/conformance/ECMA_376_2006) |
| [`zip_64_mode`](/slides/python-net/id/aspose.slides.export/ipptxoptions/zip_64_mode/) | Menentukan apakah format ZIP64 digunakan untuk dokumen Presentation. <br/>            Nilai default adalah [`Zip64Mode.IF_NECESSARY`](/slides/python-net/id/aspose.slides.export/zip64mode/IF_NECESSARY) |
| [`refresh_thumbnail`](/slides/python-net/id/aspose.slides.export/ipptxoptions/refresh_thumbnail/) | Menentukan apakah thumbnail presentasi akan diperbarui. <br/>            Baca/tulis **bool**.<br/>            Nilai default adalah **true**. |
| [`compression_level`](/slides/python-net/id/aspose.slides.export/ipptxoptions/compression_level/) | Menentukan tingkat kompresi yang digunakan saat menyimpan dokumen presentasi.<br/>            Nilai default adalah [`CompressionLevel.LEVEL6`](/slides/python-net/id/aspose.slides.export/compressionlevel/LEVEL6). |
| [`warning_callback`](/slides/python-net/id/aspose.slides.export/ipptxoptions/warning_callback/) |  |
| [`progress_callback`](/slides/python-net/id/aspose.slides.export/ipptxoptions/progress_callback/) |  |
