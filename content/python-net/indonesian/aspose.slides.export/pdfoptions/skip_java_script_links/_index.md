## skip_java_script_links properti
Menentukan apakah akan melewatkan hyperlink dengan panggilan JavaScript saat menyimpan presentasi. 
            Baca/tulis **bool**. Nilai default adalah **false** .


### Catatan

Ketika properti ini disetel ke **true** , hyperlink dengan panggilan JavaScript akan diabaikan saat menyimpan.


Ketika properti ini disetel ke **false** , semua hyperlink akan disimpan.
