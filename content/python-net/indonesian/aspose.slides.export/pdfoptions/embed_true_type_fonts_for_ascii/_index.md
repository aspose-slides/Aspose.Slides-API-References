## embed_true_type_fonts_for_ascii properti
Menentukan apakah Aspose.Slides akan menyematkan font umum untuk teks ASCII (rentang kode 33..127).
Font untuk kode karakter yang lebih besar dari 127 selalu disematkan.
Daftar font umum mencakup 14 font dasar PDF dan font tambahan yang ditentukan pengguna.
Baca/tulis **bool**.

### Catatan

Nilai default adalah **true** .
