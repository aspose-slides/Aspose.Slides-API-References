## LinkEmbedDecision enumerasi

Menentukan bagaimana objek akan diproses selama penyimpanan.

Tipe LinkEmbedDecision menampilkan anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| LINK | Objek akan disimpan secara eksternal, dirujuk dengan URL |
| EMBED | Objek harus disematkan ke file yang dihasilkan jika memungkinkan. Jika penyematan tidak memungkinkan, GetUrl akan dipanggil dan, tergantung pada hasilnya, objek akan dirujuk dengan URL atau diabaikan. |
| IGNORE | Objek akan diabaikan. |
