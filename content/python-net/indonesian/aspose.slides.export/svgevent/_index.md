## Enumerasi SvgEvent

Mewakili opsi untuk bentuk SVG.

Tipe SvgEvent mengekspos anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| ON_FOCUS_IN | Terjadi ketika sebuah elemen menerima fokus, seperti ketika teks menjadi dipilih. |
| ON_FOCUS_OUT | Terjadi ketika sebuah elemen kehilangan fokus, seperti ketika teks menjadi tidak dipilih. |
| ON_ACTIVATE | Terjadi ketika sebuah elemen diaktifkan, misalnya melalui klik mouse atau penekanan tombol. |
| ON_CLICK | Terjadi ketika tombol perangkat penunjuk diklik di atas elemen. |
| ON_MOUSE_DOWN | Terjadi ketika tombol perangkat penunjuk ditekan di atas elemen. |
| ON_MOUSE_UP | Terjadi ketika tombol perangkat penunjuk dilepaskan di atas elemen. |
| ON_MOUSE_OVER | Terjadi ketika perangkat penunjuk dipindahkan ke atas elemen. |
| ON_MOUSE_MOVE | Terjadi ketika perangkat penunjuk dipindahkan saat berada di atas elemen. |
| ON_MOUSE_OUT | Terjadi ketika perangkat penunjuk dipindahkan menjauh dari elemen. |
| ON_LOAD | Terjadi ketika agen pengguna telah sepenuhnya mengurai elemen dan turunannya serta semua sumber daya yang direferensikan, diperlukan untuk merendernya. |
| ON_UNLOAD | Terjadi ketika implementasi DOM menghapus dokumen dari jendela atau bingkai. Hanya berlaku untuk elemen svg paling luar. |
| ON_ABORT | Terjadi ketika pemuatan halaman dihentikan sebelum sebuah elemen selesai dimuat sepenuhnya. |
| ON_ERROR | Terjadi ketika sebuah elemen tidak dimuat dengan benar atau ketika terjadi kesalahan selama eksekusi skrip. |
| ON_RESIZE | Terjadi ketika tampilan dokumen diubah ukurannya. Hanya berlaku untuk elemen svg paling luar. |
| ON_SCROLL | Terjadi ketika tampilan dokumen digeser sepanjang sumbu X atau Y atau keduanya. Hanya berlaku untuk elemen svg paling luar. |
| ON_ZOOM | Terjadi ketika tingkat zoom tampilan dokumen diubah. Hanya berlaku untuk elemen svg paling luar. |
| ON_BEGIN | Terjadi ketika elemen animasi dimulai. |
| ON_END | Terjadi ketika elemen animasi berakhir. |
| ON_REPEAT | Terjadi ketika elemen animasi diulang. |
