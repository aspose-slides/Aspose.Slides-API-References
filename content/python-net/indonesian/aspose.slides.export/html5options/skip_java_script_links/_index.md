## skip_java_script_links properti
Menentukan apakah akan melewatkan tautan hiperteks dengan panggilan JavaScript saat menyimpan presentasi. 
            Baca/tulis **bool**. Nilai default adalah **false** .


### Catatan

Ketika properti ini diatur ke **true** , tautan hiperteks dengan panggilan JavaScript akan diabaikan saat menyimpan.

Ketika properti ini diatur ke **false** , semua tautan hiperteks akan disimpan.
