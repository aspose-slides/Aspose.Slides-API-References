## SvgExternalFontsHandling enumerasi

Mewakili cara untuk menangani font eksternal yang digunakan untuk menggambar teks.

Tipe SvgExternalFontsHandling menampilkan anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| ADD_LINKS_TO_FONT_FILES | Tambahkan tautan ke file font terpisah ke bagian style dari file SVG. |
| EMBED | Simpan data font langsung ke file SVG. Harap periksa semua perjanjian lisensi font eksternal sebelum menggunakan opsi ini. |
| VECTORIZE | Simpan semua teks yang menggunakan font eksternal sebagai grafis. |
