## XpsOptions kelas

Menyediakan opsi yang mengontrol bagaimana sebuah presentasi disimpan dalam format Xps.

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`warning_callback`](/slides/python-net/id/aspose.slides.export/xpsoptions/warning_callback/) | Mengembalikan atau mengatur sebuah objek yang menerima peringatan dan menentukan apakah proses pemuatan akan dilanjutkan atau dibatalkan.<br/>            Baca/tulis [`IWarningCallback`](/slides/python-net/id/aspose.slides.warnings/iwarningcallback). |
| [`progress_callback`](/slides/python-net/id/aspose.slides.export/xpsoptions/progress_callback/) | Mewakili objek panggilan balik untuk pembaruan kemajuan penyimpanan dalam persentase.<br/>            Lihat [`IProgressCallback`](/slides/python-net/id/aspose.slides/iprogresscallback). |
| [`default_regular_font`](/slides/python-net/id/aspose.slides.export/xpsoptions/default_regular_font/) | Mengembalikan atau mengatur font yang digunakan jika font sumber tidak ditemukan.<br/>            Baca/tulis **str**. |
| [`gradient_style`](/slides/python-net/id/aspose.slides.export/xpsoptions/gradient_style/) | Mengembalikan atau mengatur gaya visual gradien.<br/>            Baca/tulis [`GradientStyle`](/slides/python-net/id/aspose.slides/gradientstyle). |
| [`skip_java_script_links`](/slides/python-net/id/aspose.slides.export/xpsoptions/skip_java_script_links/) | Menentukan apakah akan melewatkan hyperlink dengan pemanggilan JavaScript saat menyimpan presentasi.<br/>            Baca/tulis **bool**. Nilai default adalah **false** . |
| [`show_hidden_slides`](/slides/python-net/id/aspose.slides.export/xpsoptions/show_hidden_slides/) | Menentukan apakah dokumen yang dihasilkan harus menyertakan slide tersembunyi atau tidak.<br/>            Nilai default adalah `false`. |
| [`save_metafiles_as_png`](/slides/python-net/id/aspose.slides.export/xpsoptions/save_metafiles_as_png/) | Benar untuk mengonversi semua metafile yang digunakan dalam presentasi ke gambar PNG.<br/>            Baca/tulis **bool**. |
| [`draw_slides_frame`](/slides/python-net/id/aspose.slides.export/xpsoptions/draw_slides_frame/) | Benar untuk menggambar bingkai hitam di sekitar setiap slide.<br/>            Baca/tulis **bool**. |
