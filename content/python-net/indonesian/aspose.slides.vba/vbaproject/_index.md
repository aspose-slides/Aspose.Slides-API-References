## VbaProject kelas

Mewakili proyek VBA dengan makro presentasi.

Tipe VbaProject mengekspos anggota berikut:

## Konstruktor

| Konstruktor | Deskripsi |
| :- | :- |
| [`__init__(self)`](/slides/python-net/id/aspose.slides.vba/vbaproject/__init__/#) | Konstruktor ini membuat proyek VBA baru dari awal.<br/>            Proyek akan dibuat dalam kode halaman 1252 Windows Latin 1 (ANSI) |
| [`__init__(self, data)`](/slides/python-net/id/aspose.slides.vba/vbaproject/__init__/#bytes) | Konstruktor ini memuat proyek VBA dari representasi biner kontainer OLE. |

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`name`](/slides/python-net/id/aspose.slides.vba/vbaproject/name/) | Mengembalikan nama proyek VBA.<br/>            Hanya-baca **str**. |
| [`modules`](/slides/python-net/id/aspose.slides.vba/vbaproject/modules/) | Mengembalikan daftar semua modul yang terdapat dalam proyek VBA.<br/>            Hanya-baca [`IVbaModuleCollection`](/slides/python-net/id/aspose.slides.vba/ivbamodulecollection). |
| [`references`](/slides/python-net/id/aspose.slides.vba/vbaproject/references/) | Mengembalikan daftar semua referensi yang terdapat dalam proyek VBA.<br/>            Hanya-baca [`IVbaReferenceCollection`](/slides/python-net/id/aspose.slides.vba/ivbareferencecollection). |
| [`is_password_protected`](/slides/python-net/id/aspose.slides.vba/vbaproject/is_password_protected/) | Menunjukkan apakah VBAProject dilindungi dengan kata sandi untuk melihat properti proyek.<br/>            Hanya-baca **bool**. |
