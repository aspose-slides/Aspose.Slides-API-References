## IVbaProject kelas

Mewakili proyek VBA dengan makro presentasi.

Tipe IVbaProject menampilkan anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`name`](/slides/python-net/id/aspose.slides.vba/ivbaproject/name/) | Mengembalikan nama proyek VBA.<br/>            Baca-saja **str**. |
| [`modules`](/slides/python-net/id/aspose.slides.vba/ivbaproject/modules/) | Mengembalikan daftar semua modul yang terdapat dalam proyek VBA.<br/>            Baca-saja [`IVbaModuleCollection`](/slides/python-net/id/aspose.slides.vba/ivbamodulecollection). |
| [`references`](/slides/python-net/id/aspose.slides.vba/ivbaproject/references/) | Mengembalikan daftar semua referensi yang terdapat dalam proyek VBA.<br/>            Baca-saja [`IVbaReferenceCollection`](/slides/python-net/id/aspose.slides.vba/ivbareferencecollection). |
| [`is_password_protected`](/slides/python-net/id/aspose.slides.vba/ivbaproject/is_password_protected/) | Menunjukkan apakah VBAProject dilindungi oleh kata sandi untuk melihat properti proyek.<br/>            Baca-saja **bool**. |

## Metode

| Metode | Deskripsi |
| :- | :- |
| [`to_binary(self)`](/slides/python-net/id/aspose.slides.vba/ivbaproject/to_binary/#) | Mengembalikan representasi biner dari proyek VBA sebagai kontainer OLE.<br/>            Baca-saja **int**[]. |
