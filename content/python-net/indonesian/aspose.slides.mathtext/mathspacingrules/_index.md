## MathSpacingRules enumerasi

Jenis celah (spasi horisontal) antara kolom dalam matriks

Tipe MathSpacingRules menampilkan anggota-anggota berikut:

## Field

| Field | Deskripsi |
| :- | :- |
| SINGLE_SPACING_GAP | Single (1 em untuk kolom atau 1 baris) |
| ONE_AND_HALF_SPACING_GAP | Satu setengah (1.5 em untuk kolom atau 1.5 baris) |
| DOUBLE_SPACING_GAP | Spasi ganda (2 em untuk kolom atau 2 baris) |
| EXACTLY | Exactly value<br/>            Untuk kolom, mengandalkan nilai ColumnGap, diukur dalam twips<br/>            Untuk baris, mengandalkan nilai RowGap, diukur dalam twips |
| MULTIPLE | Multiple<br/>            Untuk kolom, mengandalkan nilai ColumnGap, diukur dalam kelipatan 0.5 em<br/>            Untuk baris, mengandalkan nilai RowGap, diukur dalam baris |
