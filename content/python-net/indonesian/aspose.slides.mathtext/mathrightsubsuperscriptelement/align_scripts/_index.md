## properti align_scripts
Menentukan penyelarasan subskrip/superskrip. 
            Jika true, subskrip dan superskrip diselaraskan secara horizontal satu sama lain.
            Jika false, mereka di-kerning ke bentuk dasar.
            Nilai default adalah false.
