## MathJustification enumerasi

Menentukan perataan paragraf matematika (serangkaian instance teks matematika yang berdekatan dalam paragraf yang sama)

Tipe MathJustification menyediakan anggota-anggota berikut:

## Bidang

| Field | Deskripsi |
| :- | :- |
| LEFT_JUSTIFIED | Menyelaraskan teks matematika ke kiri |
| RIGHT_JUSTIFIED | Menyelaraskan teks matematika ke kanan |
| CENTERED | Menyelaraskan teks matematika ke tengah |
| CENTERED_AS_GROUP | Pusatkan pada halaman seluruh grup blok matematika sebagai satu unit.<br/>            Ini berarti bahwa instance teks matematika dapat disejajarkan satu sama lain, <br/>            tetapi seluruh grup teks matematika dipusatkan sebagai keseluruhan. |
