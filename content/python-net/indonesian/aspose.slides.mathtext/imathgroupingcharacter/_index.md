## IMathGroupingCharacter kelas

Menentukan simbol pengelompokan di atas atau di bawah sebuah ekspresi, biasanya untuk menyoroti hubungan antar elemen

Tipe IMathGroupingCharacter menampilkan anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`base`](/slides/python-net/id/aspose.slides.mathtext/imathgroupingcharacter/base/) | Argumen dasar |
| [`character`](/slides/python-net/id/aspose.slides.mathtext/imathgroupingcharacter/character/) | Karakter Pengelompokan<br/>            Nilai default: U+23DF (BOTTOM CURLY BRACKET) |
| [`position`](/slides/python-net/id/aspose.slides.mathtext/imathgroupingcharacter/position/) | Posisi karakter pengelompokan.<br/>            Nilai default: Bottom |
| [`vertical_justification`](/slides/python-net/id/aspose.slides.mathtext/imathgroupingcharacter/vertical_justification/) | Justifikasi vertikal karakter grup.<br/>            Menentukan perataan objek terhadap garis dasar.<br/>            Sebagai contoh, ketika karakter grup berada di atas objek, <br/>            VerticalJustification of Top menandakan bahwa bagian atas objek berada pada garis dasar;<br/>            ketika VerticalJustification diatur ke Bottom, bagian bawah objek berada pada garis dasar<br/>            Nilai default: Bottom untuk Position=Top, dan Top untuk Position=Bottom |
