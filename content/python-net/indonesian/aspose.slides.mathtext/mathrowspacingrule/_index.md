## MathRowSpacingRule enumerasi

Tipe jarak vertikal antara kolom dalam matriks atau larik

Tipe MathRowSpacingRule menampilkan anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| SINGLE_LINE_GAP | jarak satu baris |
| ONE_AND_A_HALF_LINE_GAP | jarak satu setengah baris |
| TWO_LINE_GAP | jarak dua baris |
| EXACTLY | Tepat (mengandalkan nilai properti RowSpacing, diukur dalam point) |
| MULTIPLE | Berkelipatan (mengandalkan nilai properti RowSpacing, diukur dalam baris) |
