## properti explicit_break
Explicit break menentukan apakah ada pemutusan baris di awal objek Box, 
            sehingga baris terbungkus di awal objek kotak.
            Menentukan nomor operator pada baris sebelumnya dari teks matematis yang akan
            digunakan sebagai titik perataan untuk baris teks matematis saat ini
            nilai yang mungkin: 1..255
            Bawaan: 0 (tidak ada pemutusan eksplisit)
