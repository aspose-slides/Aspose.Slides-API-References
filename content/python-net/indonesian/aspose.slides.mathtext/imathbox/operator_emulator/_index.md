## operator_emulator properti
Emulator Operator.
            Ketika true, kotak dan isinya berperilaku sebagai satu operator dan mewarisi properti sebuah operator.
            Ini berarti, misalnya, bahwa karakter dapat berfungsi sebagai titik untuk pemutusan baris dan dapat diselaraskan dengan operator lain.
            Operator Emulators sering digunakan ketika satu atau beberapa glyph digabungkan membentuk sebuah operator, seperti '=='.
            Nilai default: false
