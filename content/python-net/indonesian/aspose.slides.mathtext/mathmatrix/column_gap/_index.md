## column_gap properti
Nilai jarak horizontal antara kolom matriks;
            Jika ColumnGapRule diatur ke 3 ("Exactly"), maka satuan diinterpretasikan sebagai twips (1/20 poin)
            Jika ColumnGapRule diatur ke 4 ("Multiple"), maka satuan diinterpretasikan sebagai jumlah kenaikan 0.5 em.
            Di kasus lain diabaikan.
            Bawaan: 0
