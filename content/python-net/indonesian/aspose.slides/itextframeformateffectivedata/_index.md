## ITextFrameFormatEffectiveData kelas

Objek tak berubah yang berisi properti pemformatan TextFrame yang efektif.

Tipe ITextFrameFormatEffectiveData mengungkapkan anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`text_style`](/slides/python-net/id/aspose.slides/itextframeformateffectivedata/text_style/) | Mengembalikan gaya teks yang efektif.<br/>            Hanya-baca [`ITextStyleEffectiveData`](/slides/python-net/id/aspose.slides/itextstyleeffectivedata). |
| [`margin_left`](/slides/python-net/id/aspose.slides/itextframeformateffectivedata/margin_left/) | Mengembalikan margin kiri (poin) dalam TextFrame.<br/>            Hanya-baca **float**. |
| [`margin_right`](/slides/python-net/id/aspose.slides/itextframeformateffectivedata/margin_right/) | Mengembalikan margin kanan (poin) dalam TextFrame.<br/>            Hanya-baca **float**. |
| [`margin_top`](/slides/python-net/id/aspose.slides/itextframeformateffectivedata/margin_top/) | Mengembalikan margin atas (poin) dalam TextFrame.<br/>            Hanya-baca **float**. |
| [`margin_bottom`](/slides/python-net/id/aspose.slides/itextframeformateffectivedata/margin_bottom/) | Mengembalikan margin bawah (poin) dalam TextFrame.<br/>            Hanya-baca **float**. |
| [`wrap_text`](/slides/python-net/id/aspose.slides/itextframeformateffectivedata/wrap_text/) | Mengembalikan apakah teks dibungkus pada margin TextFrame.<br/>            Hanya-baca **bool**. |
| [`anchoring_type`](/slides/python-net/id/aspose.slides/itextframeformateffectivedata/anchoring_type/) | Mengembalikan teks jangkar vertikal dalam TextFrame.<br/>            Hanya-baca [`TextAnchorType`](/slides/python-net/id/aspose.slides/textanchortype). |
| [`center_text`](/slides/python-net/id/aspose.slides/itextframeformateffectivedata/center_text/) | Mengembalikan apakah teks harus dipusatkan secara horizontal dalam kotak.<br/>            Hanya-baca **bool**. |
| [`text_vertical_type`](/slides/python-net/id/aspose.slides/itextframeformateffectivedata/text_vertical_type/) | Mengembalikan orientasi teks.<br/>            Hanya-baca [`TextVerticalType`](/slides/python-net/id/aspose.slides/textverticaltype). |
| [`autofit_type`](/slides/python-net/id/aspose.slides/itextframeformateffectivedata/autofit_type/) | Mengembalikan mode penyesuaian otomatis teks.<br/>            Hanya-baca [`TextAutofitType`](/slides/python-net/id/aspose.slides/textautofittype). |
| [`column_count`](/slides/python-net/id/aspose.slides/itextframeformateffectivedata/column_count/) | Menentukan jumlah kolom teks dalam persegi panjang pembatas.<br/>            Hanya-baca **int**. |
| [`column_spacing`](/slides/python-net/id/aspose.slides/itextframeformateffectivedata/column_spacing/) | Menentukan ruang antara kolom teks dalam area teks (dalam poin).<br/>            Hanya-baca **float**. |

### Catatan

Antarmuka ini digunakan bersama dengan antarmuka [`ITextFrameFormat`](/slides/python-net/id/aspose.slides/itextframeformat) untuk mengembalikan nilai format yang efektif dengan pewarisan diterapkan.
