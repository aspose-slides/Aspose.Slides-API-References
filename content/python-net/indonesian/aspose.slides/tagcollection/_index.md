## TagCollection kelas

Mewakili koleksi tag (pasangan string yang ditentukan pengguna)

Tipe TagCollection menampilkan anggota-anggota berikut:

## Metode

| Metode | Deskripsi |
| :- | :- |
| [`add(self, name, value)`](/slides/python-net/id/aspose.slides/tagcollection/add/#str-str) | Menambahkan tag baru ke koleksi. |
| [`remove(self, name)`](/slides/python-net/id/aspose.slides/tagcollection/remove/#str) | Menghapus tag dengan nama yang ditentukan dari koleksi. |
| [`index_of_name(self, name)`](/slides/python-net/id/aspose.slides/tagcollection/index_of_name/#str) | Mengembalikan indeks berbasis nol dari kunci yang ditentukan dalam koleksi. |
| [`remove_at(self, index)`](/slides/python-net/id/aspose.slides/tagcollection/remove_at/#int) | Menghapus tag pada indeks yang ditentukan. |
| [`clear(self)`](/slides/python-net/id/aspose.slides/tagcollection/clear/#) | Menghapus semua tag dari koleksi. |
| [`get_value_by_index(self, index)`](/slides/python-net/id/aspose.slides/tagcollection/get_value_by_index/#int) | Mengembalikan nilai tag pada indeks yang ditentukan. |
| [`get_name_by_index(self, index)`](/slides/python-net/id/aspose.slides/tagcollection/get_name_by_index/#int) | Mengembalikan kunci tag pada indeks yang ditentukan. |
| [`get_names_of_tags(self)`](/slides/python-net/id/aspose.slides/tagcollection/get_names_of_tags/#) | Mengembalikan nama-nama tag. |
