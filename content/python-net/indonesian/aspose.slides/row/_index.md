## Kelas Row

Mewakili sebuah baris dalam sebuah tabel.

**Inheritance:**[`Row`](/slides/python-net/id/aspose.slides/row) → [`CellCollection`](/slides/python-net/id/aspose.slides/cellcollection)

| Properti | Deskripsi |
| :- | :- |
| [`slide`](/slides/python-net/id/aspose.slides/row/slide/) | Mengembalikan slide induk dari CellCollection.<br/>            Hanya-baca [`IBaseSlide`](/slides/python-net/id/aspose.slides/ibaseslide). |

| [`minimal_height`](/slides/python-net/id/aspose.slides/row/minimal_height/) | Mengembalikan atau mengatur tinggi minimal yang mungkin untuk baris.<br/>            Baca/tulis **float**. |
