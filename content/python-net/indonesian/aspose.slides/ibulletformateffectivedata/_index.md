## IBulletFormatEffectiveData kelas

Objek tak dapat diubah yang berisi properti pemformatan bullet paragraf yang efektif.

Tipe IBulletFormatEffectiveData menampilkan anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`type`](/slides/python-net/id/aspose.slides/ibulletformateffectivedata/type/) | Mengembalikan tipe bullet dari sebuah paragraf.<br/>            Hanya baca [`BulletType`](/slides/python-net/id/aspose.slides/bullettype). |
| [`char`](/slides/python-net/id/aspose.slides/ibulletformateffectivedata/char/) | Mengembalikan karakter bullet dari sebuah paragraf.<br/>            Hanya baca **System.Char**. |
| [`actual_bullet_value`](/slides/python-net/id/aspose.slides/ibulletformateffectivedata/actual_bullet_value/) | Mengembalikan nilai bullet sebenarnya untuk paragraf induk.<br/>            Hanya baca **str**. |
| [`font`](/slides/python-net/id/aspose.slides/ibulletformateffectivedata/font/) | Mengembalikan font bullet dari sebuah paragraf.<br/>            Hanya baca [`IFontData`](/slides/python-net/id/aspose.slides/ifontdata). |
| [`height`](/slides/python-net/id/aspose.slides/ibulletformateffectivedata/height/) | Mengembalikan tinggi bullet dari sebuah paragraf.<br/>            Hanya baca **float**. |
| [`numbered_bullet_start_with`](/slides/python-net/id/aspose.slides/ibulletformateffectivedata/numbered_bullet_start_with/) | Mengembalikan nomor pertama yang digunakan untuk grup bullet bernomor.<br/>            Hanya baca **int**. |
| [`numbered_bullet_style`](/slides/python-net/id/aspose.slides/ibulletformateffectivedata/numbered_bullet_style/) | Mengembalikan gaya bullet bernomor.<br/>            Hanya baca [`NumberedBulletStyle`](/slides/python-net/id/aspose.slides/numberedbulletstyle). |
| [`is_bullet_hard_color`](/slides/python-net/id/aspose.slides/ibulletformateffectivedata/is_bullet_hard_color/) | Menentukan apakah bullet memiliki warna sendiri atau mewarisinya dari bagian pertama dalam paragraf.<br/>            Mengembalikan **true** jika bullet memiliki warna sendiri dan **false** jika bullet mewarisi warna dari bagian pertama dalam paragraf.<br/>            Hanya baca **bool**. |
| [`is_bullet_hard_font`](/slides/python-net/id/aspose.slides/ibulletformateffectivedata/is_bullet_hard_font/) | Menentukan apakah bullet memiliki font sendiri atau mewarisinya dari bagian pertama dalam paragraf.<br/>            Mengembalikan **true** jika bullet memiliki font sendiri dan **true** jika bullet mewarisi font dari bagian pertama dalam paragraf.<br/>            Hanya baca **bool**. |
| [`picture`](/slides/python-net/id/aspose.slides/ibulletformateffectivedata/picture/) | Mengembalikan gambar yang digunakan sebagai bullet dalam paragraf.<br/>            Hanya baca [`IPictureEffectiveData`](/slides/python-net/id/aspose.slides/ipictureeffectivedata). |
| [`fill_format`](/slides/python-net/id/aspose.slides/ibulletformateffectivedata/fill_format/) | Mengembalikan format isi bullet dari sebuah paragraf.<br/>            Hanya baca [`IFillFormatEffectiveData`](/slides/python-net/id/aspose.slides/ifillformateffectivedata). |

### Catatan

Antarmuka ini digunakan sebagai bagian dari [`IParagraphFormatEffectiveData`](/slides/python-net/id/aspose.slides/iparagraphformateffectivedata).
