## IFonts kelas

Mewakili koleksi font.

Tipe IFonts menampilkan anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`latin_font`](/slides/python-net/id/aspose.slides/ifonts/latin_font/) | Mengembalikan atau mengatur font Latin.<br/>            Baca/tulis [`IFontData`](/slides/python-net/id/aspose.slides/ifontdata). |
| [`east_asian_font`](/slides/python-net/id/aspose.slides/ifonts/east_asian_font/) | Mengembalikan atau mengatur font Asia Timur.<br/>            Baca/tulis [`IFontData`](/slides/python-net/id/aspose.slides/ifontdata). |
| [`complex_script_font`](/slides/python-net/id/aspose.slides/ifonts/complex_script_font/) | Mengembalikan atau mengatur font skrip kompleks.<br/>            Baca/tulis [`IFontData`](/slides/python-net/id/aspose.slides/ifontdata). |

## Metode

| Metode | Deskripsi |
| :- | :- |
| [`get_script_font_map(self)`](/slides/python-net/id/aspose.slides/ifonts/get_script_font_map/#) | Mengembalikan daftar semua pasangan string-string definisi font skrip dalam presentasi. |
| [`get_script_font(self, script)`](/slides/python-net/id/aspose.slides/ifonts/get_script_font/#str) | Mendapatkan nama font yang terkait dengan tag skrip tertentu dari tema presentasi. |
| [`set_script_font(self, script, font_name)`](/slides/python-net/id/aspose.slides/ifonts/set_script_font/#str-str) | Menetapkan nama font ke tag skrip tertentu, yang menentukan bagaimana teks skrip tersebut akan ditampilkan dalam presentasi. |
| [`remove_script_font(self, script)`](/slides/python-net/id/aspose.slides/ifonts/remove_script_font/#str) | Menghapus pengaturan font yang terkait dengan tag skrip tertentu dari koleksi font tema. |
