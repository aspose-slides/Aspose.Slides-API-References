## PPImageFormat enumerasi

Format gambar. Enum ini menggantikan kelas `System.Drawing.Imaging.ImageFormat`.
            Diperlukan untuk kompatibilitas COM.

Tipe PPImageFormat menampilkan anggota-anggota berikut:

## Bidang

| Field | Deskripsi |
| :- | :- |
| BMP | Mendapatkan format gambar bitmap (BMP). |
| EMF | Mendapatkan format gambar enhanced metafile (EMF). |
| EXIF | Mendapatkan format Exchangeable Image File (Exif). |
| GIF | Mendapatkan format Graphics Interchange Format (GIF). |
| ICON | Mendapatkan format gambar ikon Windows. |
| JPEG | Mendapatkan format Joint Photographic Experts Group (JPEG). |
| MEMORY_BMP | Mendapatkan format bitmap di memori. |
| PNG | Mendapatkan format W3C Portable Network Graphics (PNG). |
| TIFF | Mendapatkan format Tagged Image File Format (TIFF). |
| WMF | Mendapatkan format Windows metafile (WMF). |
