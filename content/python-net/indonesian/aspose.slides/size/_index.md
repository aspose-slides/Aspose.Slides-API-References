## Size kelas

Menyimpan sepasang bilangan bulat yang terurut, yang menentukan lebar dan tinggi. Kompatibel dengan .NET `System.Drawing.Size`.

Tipe Size mengekspos anggota-anggota berikut:

## Konstruktor

| Konstruktor | Deskripsi |
| :- | :- |
| [`__init__(self, width=0, height=0)`](/slides/python-net/id/aspose.slides/size/__init__/#int-int) | Membuat sebuah size dengan lebar dan tinggi yang ditentukan. Nilai float dipotong menjadi integer. |

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`width`](/slides/python-net/id/aspose.slides/size/width/) | Mendapatkan komponen horizontal dari size ini.<br/>            Baca-saja **int**. |
| [`height`](/slides/python-net/id/aspose.slides/size/height/) | Mendapatkan komponen vertikal dari size ini.<br/>            Baca-saja **int**. |


### Catatan

Size dibandingkan berdasarkan komponennya dengan `==` dan dapat digunakan sebagai kunci kamus atau anggota set.
