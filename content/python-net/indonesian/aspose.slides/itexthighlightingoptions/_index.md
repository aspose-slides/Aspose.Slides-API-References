## ITextHighlightingOptions kelas

Mewakili opsi yang dapat digunakan untuk menyorot teks dalam bingkai teks.

Tipe ITextHighlightingOptions mengekspos anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`case_sensitive`](/slides/python-net/id/aspose.slides/itexthighlightingoptions/case_sensitive/) | Atur true untuk menggunakan pencarian yang memperhatikan huruf, false - lainnya.<br/>            Baca/tulis **bool**. |
| [`whole_words_only`](/slides/python-net/id/aspose.slides/itexthighlightingoptions/whole_words_only/) | Atur true untuk mencocokkan hanya kata penuh, false - lainnya.<br/>            Baca/tulis **bool**. |
