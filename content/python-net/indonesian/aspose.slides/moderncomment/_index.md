## Kelas ModernComment

Mewakili komentar pada sebuah slide.

**Pewarisan:**[`ModernComment`](/slides/python-net/id/aspose.slides/moderncomment) → [`Comment`](/slides/python-net/id/aspose.slides/comment)

Tipe ModernComment mengekspos anggota-anggota berikut:

## Properti

| Property | Description |
| :- | :- |
| [`text`](/slides/python-net/id/aspose.slides/moderncomment/text/) | Mengembalikan atau mengatur teks biasa dari komentar slide.<br/>            Baca/tulis **str**. |
| [`created_time`](/slides/python-net/id/aspose.slides/moderncomment/created_time/) | Mengembalikan atau mengatur waktu pembuatan komentar.<br/>            Mengatur properti ini ke **System.DateTime** berarti tidak ada waktu komentar yang diatur.<br/>            Baca/tulis **System.DateTime**. |
| [`slide`](/slides/python-net/id/aspose.slides/moderncomment/slide/) | Mengembalikan atau mengatur slide induk dari komentar.<br/>            Baca-saja [`ISlide`](/slides/python-net/id/aspose.slides/islide). |
| [`author`](/slides/python-net/id/aspose.slides/moderncomment/author/) | Mengembalikan penulis komentar.<br/>            Baca-saja [`ICommentAuthor`](/slides/python-net/id/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/id/aspose.slides/moderncomment/position/) | Mengembalikan atau mengatur posisi komentar pada slide.<br/>            Baca/tulis **aspose.slides.PointF**. |
| [`parent_comment`](/slides/python-net/id/aspose.slides/moderncomment/parent_comment/) | Mengambil atau mengatur komentar induk.<br/>            Baca/tulis [`IComment`](/slides/python-net/id/aspose.slides/icomment). |
| [`shape`](/slides/python-net/id/aspose.slides/moderncomment/shape/) | Mengembalikan bentuk yang terkait dengan komentar.<br/>            Baca-saja [`IShape`](/slides/python-net/id/aspose.slides/ishape). |
| [`text_selection_start`](/slides/python-net/id/aspose.slides/moderncomment/text_selection_start/) | Mengambil atau mengatur posisi awal pemilihan teks dalam bingkai teks jika komentar terkait dengan AutoShape.<br/>            Baca/tulis **int**. |
| [`text_selection_length`](/slides/python-net/id/aspose.slides/moderncomment/text_selection_length/) | Mengambil atau mengatur panjang pemilihan teks dalam bingkai teks jika komentar terkait dengan AutoShape.<br/>            Baca/tulis **int**. |
| [`status`](/slides/python-net/id/aspose.slides/moderncomment/status/) | Mengambil atau mengatur status komentar.<br/>            Baca/tulis [`ModernCommentStatus`](/slides/python-net/id/aspose.slides/moderncommentstatus). |

## Metode

| Metode | Deskripsi |
| :- | :- |
| [`remove(self)`](/slides/python-net/id/aspose.slides/moderncomment/remove/#) | Menghapus komentar dan semua balasannya dari koleksi induk. |
