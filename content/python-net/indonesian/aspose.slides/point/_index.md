## Point kelas

Mewakili pasangan terurut dari koordinat x- dan y-integer yang mendefinisikan sebuah titik pada bidang dua dimensi. Kompatibel dengan .NET `System.Drawing.Point`.

Tipe Point menampilkan anggota-anggota berikut:

## Konstruktor

| Konstruktor | Deskripsi |
| :- | :- |
| [`__init__(self, x=0, y=0)`](/slides/python-net/id/aspose.slides/point/__init__/#int-int) | Membuat titik dengan koordinat yang ditentukan. Nilai float dipotong menjadi integer. |

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`x`](/slides/python-net/id/aspose.slides/point/x/) | Mendapatkan atau mengatur koordinat x dari titik ini.<br/>            Baca/tulis **int**. |
| [`y`](/slides/python-net/id/aspose.slides/point/y/) | Mendapatkan atau mengatur koordinat y dari titik ini.<br/>            Baca/tulis **int**. |


### Catatan

Titik dibandingkan berdasarkan koordinatnya dengan `==` dan dapat digunakan sebagai kunci kamus atau anggota set.
