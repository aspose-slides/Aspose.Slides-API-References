## remove(self, item) {#iportion}
Menghapus kemunculan pertama dari objek tertentu dari **System.Collections.Generic.ICollection`1**.

### Mengembalikan

true jika `item` berhasil dihapus dari **System.Collections.Generic.ICollection`1**; jika tidak, false. Metode ini juga mengembalikan false jika `item` tidak ditemukan dalam **System.Collections.Generic.ICollection`1** asli.

def remove(self, item):
    ...
