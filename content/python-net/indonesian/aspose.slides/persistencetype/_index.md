## Enumerasi PersistenceType

Menentukan metode yang digunakan untuk menyimpan properti kontrol ActiveX.

Tipe PersistenceType menampilkan anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| NOT_DEFINED | ID persistance tidak ditentukan. |
| PERSIST_PROPERTY_BAG | Menentukan bahwa kontrol ActiveX dipertahankan menggunakan persistence berbasis property-bag. <br/>             Persistence berbasis property-bag menyimpan kontrol ActiveX melalui koleksi pasangan nama <br/>             dan nilai yang menentukan data yang dipertahankan oleh kontrol ActiveX. |
| PERSIST_STREAM | Menentukan bahwa kontrol ActiveX dipertahankan menggunakan persistence berbasis stream <br/>             yang tidak mendukung inisialisasi kontrol ActiveX ke keadaan default. |
| PERSIST_STREAM_INIT | Menentukan bahwa kontrol ActiveX dipertahankan menggunakan persistence berbasis stream <br/>             yang mendukung inisialisasi kontrol ActiveX ke keadaan default. |
| PERSIST_STORAGE | Menentukan bahwa kontrol ActiveX dipertahankan menggunakan persistence berbasis storage. |
