## enumerasi ResourceLoadingAction

Menentukan mode pemuatan sumber daya eksternal.

Tipe ResourceLoadingAction menampilkan anggota-anggota berikut:

## Bidang

| Kolom | Deskripsi |
| :- | :- |
| DEFAULT | Aspose.Slides akan memuat sumber daya eksternal seperti biasa. |
| SKIP | Aspose.Slides akan melewati pemuatan sumber daya eksternal. Hanya tautan tanpa data yang akan disimpan untuk gambar. |
| USER_PROVIDED | Aspose.Slides akan menggunakan byte array yang disediakan pengguna dalam **Aspose.Slides.IResourceLoadingArgs.SetData(Syste** sebagai data gambar. |
