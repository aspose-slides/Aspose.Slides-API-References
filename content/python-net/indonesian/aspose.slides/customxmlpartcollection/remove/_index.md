## remove(self, item) {#icustomxmlpart}
Menghapus kemunculan pertama dari objek tertentu dari koleksi.

### Mengembalikan

`true` jika item berhasil dihapus; jika tidak, `false`.

```python
def remove(self, item):
    ...
```

| Parameter | Tipe | Deskripsi |
| :- | :- | :- |
| item | [`ICustomXmlPart`](/slides/python-net/id/aspose.slides/icustomxmlpart) | Bagian XML khusus yang akan dihapus. |

### Pengecualian

| Pengecualian | Deskripsi |
