## ICommentAuthor kelas

Mewakili seorang penulis komentar.

Tipe ICommentAuthor menampilkan anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`name`](/slides/python-net/id/aspose.slides/icommentauthor/name/) | Mengembalikan atau mengatur nama penulis.<br/>            Baca/tulis **str**. |
| [`initials`](/slides/python-net/id/aspose.slides/icommentauthor/initials/) | Mengembalikan atau mengatur inisial penulis.<br/>            Baca/tulis **str**. |
| [`comments`](/slides/python-net/id/aspose.slides/icommentauthor/comments/) | Mengembalikan koleksi komentar yang dibuat oleh penulis ini.<br/>            Baca-saja [`ICommentCollection`](/slides/python-net/id/aspose.slides/icommentcollection). |

## Metode

| Metode | Deskripsi |
| :- | :- |
| [`remove(self)`](/slides/python-net/id/aspose.slides/icommentauthor/remove/#) | Menghapus penulis dari koleksi induk. |
