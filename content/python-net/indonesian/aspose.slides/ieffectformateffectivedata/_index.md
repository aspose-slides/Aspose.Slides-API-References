## IEffectFormatEffectiveData kelas

Objek tidak dapat diubah yang berisi properti pemformatan efek yang efektif.

Tipe IEffectFormatEffectiveData mengekspos anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`is_no_effects`](/slides/python-net/id/aspose.slides/ieffectformateffectivedata/is_no_effects/) | Mengembalikan true jika semua efek dinonaktifkan (seperti baru dibuat, objek EffectFormat default).<br/>            Hanya-baca **bool**. |
| [`blur_effect`](/slides/python-net/id/aspose.slides/ieffectformateffectivedata/blur_effect/) | Efek blur.<br/>            Hanya-baca [`IBlurEffectiveData`](/slides/python-net/id/aspose.slides.effects/iblureffectivedata). |
| [`fill_overlay_effect`](/slides/python-net/id/aspose.slides/ieffectformateffectivedata/fill_overlay_effect/) | Efek overlay isi.<br/>            Hanya-baca [`IFillOverlayEffectiveData`](/slides/python-net/id/aspose.slides.effects/ifilloverlayeffectivedata). |
| [`glow_effect`](/slides/python-net/id/aspose.slides/ieffectformateffectivedata/glow_effect/) | Efek glow.<br/>            Hanya-baca [`IGlowEffectiveData`](/slides/python-net/id/aspose.slides.effects/igloweffectivedata). |
| [`inner_shadow_effect`](/slides/python-net/id/aspose.slides/ieffectformateffectivedata/inner_shadow_effect/) | Bayangan dalam.<br/>            Hanya-baca [`IInnerShadowEffectiveData`](/slides/python-net/id/aspose.slides.effects/iinnershadoweffectivedata). |
| [`outer_shadow_effect`](/slides/python-net/id/aspose.slides/ieffectformateffectivedata/outer_shadow_effect/) | Bayangan luar.<br/>            Hanya-baca [`IOuterShadowEffectiveData`](/slides/python-net/id/aspose.slides.effects/ioutershadoweffectivedata). |
| [`preset_shadow_effect`](/slides/python-net/id/aspose.slides/ieffectformateffectivedata/preset_shadow_effect/) | Bayangan preset.<br/>            Hanya-baca [`IPresetShadowEffectiveData`](/slides/python-net/id/aspose.slides.effects/ipresetshadoweffectivedata). |
| [`reflection_effect`](/slides/python-net/id/aspose.slides/ieffectformateffectivedata/reflection_effect/) | Refleksi.<br/>            Hanya-baca [`IReflectionEffectiveData`](/slides/python-net/id/aspose.slides.effects/ireflectioneffectivedata). |
| [`soft_edge_effect`](/slides/python-net/id/aspose.slides/ieffectformateffectivedata/soft_edge_effect/) | Tepi halus.<br/>            Hanya-baca [`ISoftEdgeEffectiveData`](/slides/python-net/id/aspose.slides.effects/isoftedgeeffectivedata). |


### Keterangan

Antarmuka ini digunakan bersama dengan antarmuka [`IEffectFormat`](/slides/python-net/id/aspose.slides/ieffectformat) untuk mengembalikan nilai pemformatan yang efektif dengan penerapan pewarisan.
