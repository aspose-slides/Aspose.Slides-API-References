## kelas Audio

Mewakili file audio tertanam.

Tipe Audio mengekspos anggota-anggota berikut:

## Properti

| Property | Description |
| :- | :- |
| [`content_type`](/slides/python-net/id/aspose.slides/audio/content_type/) | Mengembalikan tipe MIME audio, yang dikodekan dalam [`Audio.binary_data`](/slides/python-net/id/aspose.slides/audio/binary_data).<br/>            Hanya-baca **str**. |
| [`binary_data`](/slides/python-net/id/aspose.slides/audio/binary_data/) | Mengembalikan salinan data audio. Jika jumlah data besar, pertimbangkan <br/>            penggunaan metode [`Audio.get_stream`](/slides/python-net/id/aspose.slides/audio/get_stream) untuk mencegah pemuatan data audio yang tidak perlu<br/>            ke memori atau bahkan OutOfMemoryException.<br/>            Hanya-baca **int**[]. |

## Metode

| Method | Description |
| :- | :- |
| [`get_stream(self)`](/slides/python-net/id/aspose.slides/audio/get_stream/#) | Mengembalikan Stream stream untuk membaca.<br/>            Gunakan 'using' atau tutup stream setelah digunakan. |
