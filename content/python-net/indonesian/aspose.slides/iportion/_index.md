## IPortion kelas

Mewakili bagian teks di dalam paragraf teks.

Tipe IPortion mengekspos anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`portion_format`](/slides/python-net/id/aspose.slides/iportion/portion_format/) | Mengembalikan objek format yang berisi properti format yang diatur secara eksplisit dari bagian teks tanpa penerapan pewarisan.<br/>            Baca-saja [`IPortionFormat`](/slides/python-net/id/aspose.slides/iportionformat). |
| [`text`](/slides/python-net/id/aspose.slides/iportion/text/) | Mendapatkan atau mengatur teks biasa dari sebuah bagian.<br/>            Baca/tulis **str**. |
| [`field`](/slides/python-net/id/aspose.slides/iportion/field/) | Mengembalikan bidang dari bagian ini.<br/>            Baca-saja [`IField`](/slides/python-net/id/aspose.slides/ifield). |
| [`slide`](/slides/python-net/id/aspose.slides/iportion/slide/) |  |
| [`presentation`](/slides/python-net/id/aspose.slides/iportion/presentation/) |  |

## Metode

| Metode | Deskripsi |
| :- | :- |
| [`add_field(self, field_type)`](/slides/python-net/id/aspose.slides/iportion/add_field/#ifieldtype) | Mengonversi bagian ini menjadi bidang yang diperbarui secara otomatis. |
| [`add_field(self, internal_string)`](/slides/python-net/id/aspose.slides/iportion/add_field/#str) | Mengonversi bagian ini menjadi bidang yang diperbarui secara otomatis. |

| [`get_coordinates(self)`](/slides/python-net/id/aspose.slides/iportion/get_coordinates/#) | Mendapatkan koordinat awal bagian. Koordinat X titik mewakili awal bagian dari karakter pertama termasuk bearing sisi kiri.<br/>            Koordinat Y mencakup bearing sisi atas. |
