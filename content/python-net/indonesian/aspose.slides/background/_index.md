## Kelas Background

Mewakili latar belakang slide.

**Pewarisan:**[`Background`](/slides/python-net/id/aspose.slides/background) → [`PVIObject`](/slides/python-net/id/aspose.slides/pviobject)

Tipe Background menampilkan anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`type`](/slides/python-net/id/aspose.slides/background/type/) | Mengembalikan tipe isian latar belakang.<br/>            Baca/tulis [`BackgroundType`](/slides/python-net/id/aspose.slides/backgroundtype). |
| [`fill_format`](/slides/python-net/id/aspose.slides/background/fill_format/) | Mengembalikan FillFormat untuk isian BackgroundType.OwnBackground.<br/>            Baca-saja [`IFillFormat`](/slides/python-net/id/aspose.slides/ifillformat). |
| [`effect_format`](/slides/python-net/id/aspose.slides/background/effect_format/) | Mengembalikan EffectFormat untuk isian BackgroundType.OwnBackground.<br/>            Baca-saja [`IEffectFormat`](/slides/python-net/id/aspose.slides/ieffectformat). |
| [`style_color`](/slides/python-net/id/aspose.slides/background/style_color/) | Mengembalikan ColorFormat untuk isian BackgroundType.Themed.<br/>            Baca-saja [`IColorFormat`](/slides/python-net/id/aspose.slides/icolorformat). |
| [`style_index`](/slides/python-net/id/aspose.slides/background/style_index/) | Mengembalikan indeks isian BackgroundType.Themed dalam koleksi tema latar belakang.<br/>            0 berarti tidak ada isian.<br/>            1..999 - indeks.<br/>            Baca/tulis **int**. |
| [`slide`](/slides/python-net/id/aspose.slides/background/slide/) | Mengembalikan slide induk dari sebuah shape.<br/>            Baca-saja [`IBaseSlide`](/slides/python-net/id/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/id/aspose.slides/background/presentation/) | Mengembalikan presentasi induk dari sebuah slide.<br/>            Baca-saja [`IPresentation`](/slides/python-net/id/aspose.slides/ipresentation). |

## Metode
