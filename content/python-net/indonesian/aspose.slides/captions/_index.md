## Kelas Captions

Mewakili caption tertutup WebVTT.

Tipe Captions menampilkan anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`caption_id`](/slides/python-net/id/aspose.slides/captions/caption_id/) | Mengembalikan pengidentifikasi unik global (GUID) dari caption tertutup.<br/>            Hanya-baca **System.Guid**. |
| [`label`](/slides/python-net/id/aspose.slides/captions/label/) | Mengembalikan atau mengatur label caption tertutup.<br/>            Baca/tulis **str**. |
| [`binary_data`](/slides/python-net/id/aspose.slides/captions/binary_data/) | Mengembalikan data biner caption tertutup.<br/>            Hanya-baca **int**[]. |
| [`data_as_string`](/slides/python-net/id/aspose.slides/captions/data_as_string/) | Mengembalikan data caption tertutup sebagai string ber-enkode UTF-8<br/>            Hanya-baca **str**. |
