## IParagraphFormatEffectiveData kelas

Objek tak dapat diubah yang berisi properti pemformatan paragraf yang efektif.

Tipe IParagraphFormatEffectiveData mengekspos anggota berikut:

## Properti

| Property | Description |
| :- | :- |
| [`bullet`](/slides/python-net/id/aspose.slides/iparagraphformateffectivedata/bullet/) | Mengembalikan format bullet dari sebuah paragraf.<br/>            Hanya baca [`IBulletFormatEffectiveData`](/slides/python-net/id/aspose.slides/ibulletformateffectivedata). |
| [`depth`](/slides/python-net/id/aspose.slides/iparagraphformateffectivedata/depth/) | Mengembalikan kedalaman sebuah paragraf.<br/>            Hanya baca **int**. |
| [`alignment`](/slides/python-net/id/aspose.slides/iparagraphformateffectivedata/alignment/) | Mengembalikan perataan teks dalam paragraf.<br/>            Hanya baca [`TextAlignment`](/slides/python-net/id/aspose.slides/textalignment). |
| [`space_within`](/slides/python-net/id/aspose.slides/iparagraphformateffectivedata/space_within/) | Mengembalikan jumlah ruang antara garis dasar dalam paragraf.<br/>            Hanya baca **float**. |
| [`space_before`](/slides/python-net/id/aspose.slides/iparagraphformateffectivedata/space_before/) | Mengembalikan jumlah ruang sebelum baris pertama dalam paragraf.<br/>            Hanya baca **float**. |
| [`space_after`](/slides/python-net/id/aspose.slides/iparagraphformateffectivedata/space_after/) | Mengembalikan jumlah ruang setelah baris terakhir dalam paragraf.<br/>            Hanya baca **float**. |
| [`east_asian_line_break`](/slides/python-net/id/aspose.slides/iparagraphformateffectivedata/east_asian_line_break/) | Menentukan apakah pemenggalan baris Asia Timur digunakan dalam paragraf.<br/>            Hanya baca **bool**. |
| [`right_to_left`](/slides/python-net/id/aspose.slides/iparagraphformateffectivedata/right_to_left/) | Menentukan apakah penulisan Right to Left digunakan dalam paragraf.<br/>            Hanya baca **bool**. |
| [`latin_line_break`](/slides/python-net/id/aspose.slides/iparagraphformateffectivedata/latin_line_break/) | Menentukan apakah pemenggalan baris Latin digunakan dalam paragraf.<br/>            Hanya baca **bool**. |
| [`hanging_punctuation`](/slides/python-net/id/aspose.slides/iparagraphformateffectivedata/hanging_punctuation/) | Menentukan apakah tanda baca gantung digunakan dalam paragraf.<br/>            Hanya baca **bool**. |
| [`margin_left`](/slides/python-net/id/aspose.slides/iparagraphformateffectivedata/margin_left/) | Mengembalikan margin kiri dalam paragraf.<br/>            Hanya baca **float**. |
| [`margin_right`](/slides/python-net/id/aspose.slides/iparagraphformateffectivedata/margin_right/) | Mengembalikan margin kanan dalam paragraf.<br/>            Hanya baca **float**. |
| [`indent`](/slides/python-net/id/aspose.slides/iparagraphformateffectivedata/indent/) | Mengembalikan Indent Baris Pertama/Indent Gantung paragraf. Indent Gantung dapat didefinisikan dengan nilai negatif.<br/>            Hanya baca **float**. |
| [`default_tab_size`](/slides/python-net/id/aspose.slides/iparagraphformateffectivedata/default_tab_size/) | Mengembalikan ukuran tabulasi default.<br/>            Hanya baca **float**. |
| [`tabs`](/slides/python-net/id/aspose.slides/iparagraphformateffectivedata/tabs/) | Mengembalikan tabulasi paragraf.<br/>            Hanya baca [`ITabEffectiveData`](/slides/python-net/id/aspose.slides/itabeffectivedata)[]. |
| [`font_alignment`](/slides/python-net/id/aspose.slides/iparagraphformateffectivedata/font_alignment/) | Mengembalikan perataan font dalam paragraf.<br/>            Hanya baca [`FontAlignment`](/slides/python-net/id/aspose.slides/fontalignment). |
| [`default_portion_format`](/slides/python-net/id/aspose.slides/iparagraphformateffectivedata/default_portion_format/) | Mengembalikan format bagian default paragraf.<br/>            Hanya baca [`IPortionFormatEffectiveData`](/slides/python-net/id/aspose.slides/iportionformateffectivedata). |

### Catatan

Antarmuka ini digunakan bersama dengan antarmuka [`IParagraphFormat`](/slides/python-net/id/aspose.slides/iparagraphformat) untuk mengembalikan nilai pemformatan yang efektif dengan penerapan pewarisan.
