## IPictureFillFormatEffectiveData kelas

Objek tidak dapat diubah yang berisi properti pengisian gambar.

Tipe IPictureFillFormatEffectiveData menampilkan anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`dpi`](/slides/python-net/id/aspose.slides/ipicturefillformateffectivedata/dpi/) | Mengembalikan dpi yang digunakan untuk mengisi gambar.<br/>            Hanya-baca **int**. |
| [`picture_fill_mode`](/slides/python-net/id/aspose.slides/ipicturefillformateffectivedata/picture_fill_mode/) | Mengembalikan mode pengisian gambar.<br/>            Hanya-baca [`PictureFillMode`](/slides/python-net/id/aspose.slides/picturefillmode). |
| [`picture`](/slides/python-net/id/aspose.slides/ipicturefillformateffectivedata/picture/) | Mengembalikan gambar.<br/>            Hanya-baca [`IPictureEffectiveData`](/slides/python-net/id/aspose.slides/ipictureeffectivedata). |
| [`crop_left`](/slides/python-net/id/aspose.slides/ipicturefillformateffectivedata/crop_left/) | Mengembalikan persentase lebar gambar asli yang dipotong<br/>            di sisi kiri gambar. <br/>            Hanya-baca **float**. |
| [`crop_top`](/slides/python-net/id/aspose.slides/ipicturefillformateffectivedata/crop_top/) | Mengembalikan persentase tinggi gambar asli yang dipotong<br/>            di bagian atas gambar. <br/>            Hanya-baca **float**. |
| [`crop_right`](/slides/python-net/id/aspose.slides/ipicturefillformateffectivedata/crop_right/) | Mengembalikan persentase lebar gambar asli yang dipotong<br/>            di sisi kanan gambar. <br/>            Hanya-baca **float**. |
