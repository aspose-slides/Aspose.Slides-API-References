## ShapeAdjustmentType enumerasi

Menentukan berbagai tipe nilai penyesuaian bentuk.

Tipe ShapeAdjustmentType mengekspos anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| CUSTOM | Tipe khusus (penyesuaian tidak diketahui) |
| CORNER_SIZE | Mengontrol ukuran sudut. |
| LEFT_UP_CORNER | Mengontrol sudut kiri atas. |
| RIGHT_UP_CORNER | Mengontrol sudut kanan atas. |
| UP_CORNERS | Mengontrol sudut atas. |
| DOWN_CORNERS | Mengontrol sudut bawah. |
| THICKNESS | Mengontrol ketebalan gambar. |
| ARROW_TAIL_THICKNESS | Mengontrol ketebalan ekor panah. |
| ARROWHEAD_LENGTH | Mengontrol panjang kepala panah. |
| ARROWHEAD_WIDTH | Mengontrol lebar kepala panah. |
| RADIUS | Mengontrol ukuran jari-jari bentuk atau bagiannya. |
| DEPTH | Mengontrol kedalaman gigi roda gigi atau efek bevel. |
| SHAPE_PART_OFFSET | Mengontrol offset satu bagian gambar relatif terhadap bagian lain. |
| ANGLE | Mengontrol sudut untuk gambar atau bagiannya. |
| START_ANGLE | Sudut awal untuk bentuk pai dan busur. |
| END_ANGLE | Sudut akhir untuk bentuk pai dan busur. |
| START_POINT_X | Mengontrol posisi X titik awal callout. |
| START_POINT_Y | Mengontrol posisi Y titik awal callout. |
| CONNECTOR_POINT_1X | Mengontrol posisi horizontal titik penyesuaian sudut callout. |
| CONNECTOR_POINT_1Y | Mengontrol posisi vertikal titik penyesuaian sudut callout. |
| CONNECTOR_POINT_2X | Mengontrol posisi horizontal titik penyesuaian sudut callout. |
| CONNECTOR_POINT_2Y | Mengontrol posisi vertikal titik penyesuaian sudut callout. |
| CONNECTOR_BEND_POSITION_X | Mengontrol posisi horizontal lekukan pada konektor. |
| CONNECTOR_BEND_POSITION_Y | Mengontrol posisi vertikal lekukan pada konektor. |
| ATTACH_Y | Mengontrol titik lampiran vertikal gambar. |
| ATTACH_X | Mengontrol titik lampiran horizontal gambar. |
| CALLOUT_HEIGHT | Mengontrol ukuran vertikal callout. |
| CALLOUT_WIDTH | Mengontrol ukuran horizontal callout. |
| CALLOUT_SIZE | Mengontrol ukuran callout. |
| CURVATURE | Kelengkungan lengkungan, penyangga, panah melengkung, atau bentuk. |
| HORIZONTAL_THICKNESS | Mengontrol ketebalan horizontal bentuk sudut. |
| VERTICAL_THICKNESS | Mengontrol ketebalan vertikal bentuk sudut. |
| VERTICAL_SIZE | Mengontrol ukuran vertikal bentuk. |
| HORIZONTAL_SIZE | Mengontrol ukuran horizontal bentuk. |
| TOP | Mengontrol sisi atas sebuah bentuk. |
