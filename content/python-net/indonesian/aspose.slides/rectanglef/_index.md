## RectangleF kelas

Menyimpan satu set empat angka floating-point yang mewakili lokasi dan ukuran sebuah persegi panjang. Kompatibel dengan .NET `System.Drawing.RectangleF`.

**Pewarisan:**[`RectangleF`](/slides/python-net/id/aspose.slides/rectanglef) → [`Rectangle`](/slides/python-net/id/aspose.slides/rectangle)

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`x`](/slides/python-net/id/aspose.slides/rectanglef/x/) | Mengambil koordinat x dari sudut kiri atas persegi panjang ini.<br/>            Baca-saja **float**. |
| [`y`](/slides/python-net/id/aspose.slides/rectanglef/y/) | Mengambil koordinat y dari sudut kiri atas persegi panjang ini.<br/>            Baca-saja **float**. |
| [`width`](/slides/python-net/id/aspose.slides/rectanglef/width/) | Mengambil lebar persegi panjang ini.<br/>            Baca-saja **float**. |
| [`height`](/slides/python-net/id/aspose.slides/rectanglef/height/) | Mengambil tinggi persegi panjang ini.<br/>            Baca-saja **float**. |
| [`left`](/slides/python-net/id/aspose.slides/rectanglef/left/) | Mengambil koordinat x dari tepi kiri persegi panjang ini. Sama dengan `x`.<br/>            Baca-saja **float**. |
| [`top`](/slides/python-net/id/aspose.slides/rectanglef/top/) | Mengambil koordinat y dari tepi atas persegi panjang ini. Sama dengan `y`.<br/>            Baca-saja **float**. |
| [`right`](/slides/python-net/id/aspose.slides/rectanglef/right/) | Mengambil koordinat x yang merupakan hasil penjumlahan `x` dan `width` persegi panjang ini.<br/>            Baca-saja **float**. |
| [`bottom`](/slides/python-net/id/aspose.slides/rectanglef/bottom/) | Mengambil koordinat y yang merupakan hasil penjumlahan `y` dan `height` persegi panjang ini.<br/>            Baca-saja **float**. |
| [`is_empty`](/slides/python-net/id/aspose.slides/rectanglef/is_empty/) | Menentukan apakah semua properti numerik persegi panjang ini bernilai nol.<br/>            Baca-saja **bool**. |

### Catatan

Persegi panjang dibandingkan berdasarkan lokasi dan ukurannya dengan `==` dan dapat digunakan sebagai kunci kamus atau anggota set.
