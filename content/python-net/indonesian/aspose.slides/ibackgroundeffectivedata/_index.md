## IBackgroundEffectiveData kelas

Objek tak berubah yang berisi properti latar belakang efektif.

Tipe IBackgroundEffectiveData menyajikan anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`fill_format`](/slides/python-net/id/aspose.slides/ibackgroundeffectivedata/fill_format/) | Mengembalikan format isian efektif.<br/>            Hanya-baca [`IFillFormatEffectiveData`](/slides/python-net/id/aspose.slides/ifillformateffectivedata). |
| [`effect_format`](/slides/python-net/id/aspose.slides/ibackgroundeffectivedata/effect_format/) | Mengembalikan format efek efektif.<br/>            Hanya-baca [`IEffectFormatEffectiveData`](/slides/python-net/id/aspose.slides/ieffectformateffectivedata). |


### Catatan

Antarmuka ini digunakan bersama dengan antarmuka [`IBackground`](/slides/python-net/id/aspose.slides/ibackground) untuk mengembalikan nilai format efektif dengan pewarisan yang diterapkan.
