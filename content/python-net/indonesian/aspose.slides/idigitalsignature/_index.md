## IDigitalSignature kelas

Tanda tangan digital dalam file yang ditandatangani.

Tipe IDigitalSignature menyajikan anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`certificate`](/slides/python-net/id/aspose.slides/idigitalsignature/certificate/) | Objek sertifikat yang digunakan untuk menandatangani dokumen.<br/>            Hanya-baca **System.Security.Cryptography.X509Certificates.X509Certificate2**. |
| [`is_valid`](/slides/python-net/id/aspose.slides/idigitalsignature/is_valid/) | Jika tanda tangan digital ini valid dan dokumen tidak dimanipulasi, nilai ini akan bernilai true.<br/>            Hanya-baca **bool**. |
| [`sign_time`](/slides/python-net/id/aspose.slides/idigitalsignature/sign_time/) | Waktu saat dokumen ditandatangani.<br/>            Hanya-baca **System.DateTime**. |
| [`comments`](/slides/python-net/id/aspose.slides/idigitalsignature/comments/) | Tujuan tanda tangan.<br/>            Baca/tulis **str**. |
