## properti frame
Mengembalikan atau mengatur properti frame bentuk.
            Read/write [`IShapeFrame`](/slides/python-net/id/aspose.slides/ishapeframe).

### Remarks

Nilai setiap properti dari instance IShapeFrame yang dikembalikan tidak undefined (is not NaN atau NotDefined).
            Nilai setiap properti dari instance IShapeFrame yang ditetapkan harus tidak undefined (must be not NaN atau NotDefined).
            Anda dapat menetapkan nilai undefined untuk properti instance RawFrame.
