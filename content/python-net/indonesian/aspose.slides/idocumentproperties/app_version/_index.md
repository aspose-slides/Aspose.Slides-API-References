## app_version properti
Returns the app version.
            Read-only **str**.

### Keterangan

Konten elemen ini harus dalam bentuk XX.YYYY, dimana X dan Y mewakili nilai numerik;
            jika tidak, dokumen dianggap tidak sesuai.
            Aspose.Slides merepresentasikan versinya dalam format XX.YYZZ, dimana:
            XX - versi utama
            YY - versi minor
            ZZ - versi patch
            sebagai contoh, nilai 23.0105 berarti versi Aspose.Slides 23.1.5.
