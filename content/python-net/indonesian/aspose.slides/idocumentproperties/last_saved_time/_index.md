## last_saved_time properti
Returns the date a presentation was last modified.
            Values are in UTC.P
            Baca-saja in case of Presentation.DocumentProperties (because it will be updated internally while IPresentation object saving process). 
            Dapat diubah melalui DocumentProperties instance returning by method [`IPresentationInfo.read_document_properties`](/slides/python-net/id/aspose.slides/ipresentationinfo/read_document_properties)
            Silakan lihat contoh dalam **Aspose.Slides.IPresentationInfo.UpdateDocumentProperties(Aspose.Slide** method summary.
