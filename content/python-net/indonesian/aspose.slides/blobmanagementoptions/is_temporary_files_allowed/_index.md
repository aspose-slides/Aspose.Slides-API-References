## is_temporary_files_allowed properti
Properti ini mendefinisikan apakah file sementara dapat dibuat saat bekerja dengan BLOB, yang secara signifikan 
            mengurangi konsumsi memori tetapi memerlukan izin untuk membuat file.
            Semua file akan dihapus setelah pekerjaan dengan presentasi selesai.
