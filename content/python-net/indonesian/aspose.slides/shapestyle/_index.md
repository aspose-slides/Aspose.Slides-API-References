## ShapeStyle kelas

Mewakili referensi gaya shape.

Tipe ShapeStyle menampilkan anggota-anggota berikut:

## Properti

| Property | Description |
| :- | :- |
| [`line_color`](/slides/python-net/id/aspose.slides/shapestyle/line_color/) | Mengembalikan warna outline shape.<br/>            Hanya-baca [`IColorFormat`](/slides/python-net/id/aspose.slides/icolorformat). |
| [`line_style_index`](/slides/python-net/id/aspose.slides/shapestyle/line_style_index/) | Mengembalikan atau mengatur indeks kolom garis dalam matriks gaya.<br/>            Baca/tulis **int**. |
| [`fill_color`](/slides/python-net/id/aspose.slides/shapestyle/fill_color/) | Mengembalikan warna isian shape.<br/>            Hanya-baca [`IColorFormat`](/slides/python-net/id/aspose.slides/icolorformat). |
| [`fill_style_index`](/slides/python-net/id/aspose.slides/shapestyle/fill_style_index/) | Mengembalikan atau mengatur indeks kolom isian shape dalam matriks gaya.<br/>            0 berarti tidak ada isian,<br/>            nilai positif - indeks dalam gaya isian tema,<br/>            nilai negatif - indeks dalam gaya latar belakang tema.<br/>            Baca/tulis **int**. |
| [`effect_color`](/slides/python-net/id/aspose.slides/shapestyle/effect_color/) | Mengembalikan warna efek shape.<br/>            Hanya-baca [`IColorFormat`](/slides/python-net/id/aspose.slides/icolorformat). |
| [`effect_style_index`](/slides/python-net/id/aspose.slides/shapestyle/effect_style_index/) | Mengembalikan atau mengatur indeks kolom efek shape dalam matriks gaya.<br/>            Baca/tulis **int**. |
| [`font_color`](/slides/python-net/id/aspose.slides/shapestyle/font_color/) | Mengembalikan warna font shape.<br/>            Hanya-baca [`IColorFormat`](/slides/python-net/id/aspose.slides/icolorformat). |
| [`font_collection_index`](/slides/python-net/id/aspose.slides/shapestyle/font_collection_index/) | Mengembalikan atau mengatur indeks font shape dalam koleksi font.<br/>            Baca/tulis [`FontCollectionIndex`](/slides/python-net/id/aspose.slides/fontcollectionindex). |
