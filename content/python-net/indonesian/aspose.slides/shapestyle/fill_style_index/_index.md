## fill_style_index properti
Mengembalikan atau mengatur indeks kolom isian shape dalam matriks gaya.
            0 berarti tidak ada isian,
            nilai positif - indeks dalam gaya isian tema,
            nilai negatif - indeks dalam gaya latar belakang tema.
            Baca/tulis **int**.
