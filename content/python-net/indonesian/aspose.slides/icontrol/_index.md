## IControl kelas

Mewakili kontrol ActiveX.

Tipe IControl mengekspos anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`name`](/slides/python-net/id/aspose.slides/icontrol/name/) | Mengembalikan nama kontrol ini.<br/>            Baca/tulis **str**. |
| [`class_id`](/slides/python-net/id/aspose.slides/icontrol/class_id/) | Mendapatkan ID kelas dari kontrol ini.<br/>            Baca saja **System.Guid**. |
| [`substitute_picture_format`](/slides/python-net/id/aspose.slides/icontrol/substitute_picture_format/) | Mengembalikan objek properti pengisian gambar ControlEx.<br/>            Baca saja [`IPictureFillFormat`](/slides/python-net/id/aspose.slides/ipicturefillformat). |
| [`frame`](/slides/python-net/id/aspose.slides/icontrol/frame/) | Mengembalikan atau mengatur bingkai kontrol.<br/>            Baca/tulis [`IShapeFrame`](/slides/python-net/id/aspose.slides/ishapeframe). |
| [`properties`](/slides/python-net/id/aspose.slides/icontrol/properties/) | Mengembalikan koleksi properti ActiveX.<br/>            Baca saja [`IControlPropertiesCollection`](/slides/python-net/id/aspose.slides/icontrolpropertiescollection). |
| [`persistence`](/slides/python-net/id/aspose.slides/icontrol/persistence/) | Mendapatkan metode yang digunakan untuk menyimpan properti kontrol ActiveX.<br/>            Baca saja [`PersistenceType`](/slides/python-net/id/aspose.slides/persistencetype). |
| [`active_x_control_binary`](/slides/python-net/id/aspose.slides/icontrol/active_x_control_binary/) | Menentukan keberlangsungan kontrol ActiveX ketika metode yang digunakan untuk menyimpan adalah PersistStream, PersistStreamInit, atau PersistStorage. |
