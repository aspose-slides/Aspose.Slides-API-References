            di mana setiap elemen sesuai dengan satu kolom teks terpisah di dalam frame.

### Mengembalikan

Sebuah array string, di mana setiap string mewakili konten teks dari kolom tertentu di dalam [`ITextFrame`](/slides/python-net/id/aspose.slides/itextframe).

            Kolom kosong akan direpresentasikan sebagai string kosong dalam array.
