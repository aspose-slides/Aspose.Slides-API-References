## IGradientFormatEffectiveData kelas

Objek yang tidak dapat diubah yang berisi properti pengisian gradien yang efektif.

Tipe IGradientFormatEffectiveData menampilkan anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`tile_flip`](/slides/python-net/id/aspose.slides/igradientformateffectivedata/tile_flip/) | Mengembalikan mode pembalikan untuk gradien.<br/>            Baca-saja [`TileFlip`](/slides/python-net/id/aspose.slides/tileflip). |
| [`gradient_direction`](/slides/python-net/id/aspose.slides/igradientformateffectivedata/gradient_direction/) | Mengembalikan gaya gradien.<br/>            Baca-saja [`GradientDirection`](/slides/python-net/id/aspose.slides/gradientdirection). |
| [`linear_gradient_angle`](/slides/python-net/id/aspose.slides/igradientformateffectivedata/linear_gradient_angle/) | Mengembalikan sudut gradien.<br/>            Baca-saja **float**. |
| [`linear_gradient_scaled`](/slides/python-net/id/aspose.slides/igradientformateffectivedata/linear_gradient_scaled/) | Menentukan apakah gradien diskalakan.<br/>            Baca-saja **bool**. |
| [`gradient_shape`](/slides/python-net/id/aspose.slides/igradientformateffectivedata/gradient_shape/) | Mengembalikan bentuk gradien.<br/>            Baca-saja [`GradientShape`](/slides/python-net/id/aspose.slides/gradientshape). |
| [`gradient_stops`](/slides/python-net/id/aspose.slides/igradientformateffectivedata/gradient_stops/) | Mengembalikan kumpulan titik henti gradien.<br/>            Baca-saja [`IGradientStopCollectionEffectiveData`](/slides/python-net/id/aspose.slides/igradientstopcollectioneffectivedata). |


### Catatan

Antarmuka ini digunakan sebagai bagian dari [`IFillFormatEffectiveData`](/slides/python-net/id/aspose.slides/ifillformateffectivedata) dan [`ILineFillFormatEffectiveData`](/slides/python-net/id/aspose.slides/ilinefillformateffectivedata).
