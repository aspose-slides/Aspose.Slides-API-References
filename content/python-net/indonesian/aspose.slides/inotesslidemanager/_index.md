## INotesSlideManager kelas

Manajer slide catatan.

Tipe INotesSlideManager menampilkan anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`notes_slide`](/slides/python-net/id/aspose.slides/inotesslidemanager/notes_slide/) | Mengembalikan slide catatan untuk slide saat ini. Mengembalikan None jika slide tidak memiliki slide catatan.<br/>            Hanya-baca [`INotesSlide`](/slides/python-net/id/aspose.slides/inotesslide). |

## Metode

| Metode | Deskripsi |
| :- | :- |
| [`add_notes_slide(self)`](/slides/python-net/id/aspose.slides/inotesslidemanager/add_notes_slide/#) | Mengembalikan slide catatan untuk slide saat ini, membuat satu jika tidak ada. |
| [`remove_notes_slide(self)`](/slides/python-net/id/aspose.slides/inotesslidemanager/remove_notes_slide/#) | Menghapus slide catatan dari slide saat ini. |
