## Kelas Control

Mewakili kontrol ActiveX.

Tipe Control mengekspos anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`persistence`](/slides/python-net/id/aspose.slides/control/persistence/) | Mendapatkan metode yang digunakan untuk menyimpan properti kontrol ActiveX.<br/>            Baca saja [`PersistenceType`](/slides/python-net/id/aspose.slides/persistencetype). |
| [`name`](/slides/python-net/id/aspose.slides/control/name/) | Mendapatkan atau mengatur nama kontrol ini.<br/>            Baca/tulis **str**. |
| [`class_id`](/slides/python-net/id/aspose.slides/control/class_id/) | Mendapatkan id kelas kontrol ini.<br/>            Baca saja **System.Guid**. |
| [`substitute_picture_format`](/slides/python-net/id/aspose.slides/control/substitute_picture_format/) | Mengembalikan objek properti pengisian gambar kontrol.<br/>            Baca saja [`IPictureFillFormat`](/slides/python-net/id/aspose.slides/ipicturefillformat). |
| [`frame`](/slides/python-net/id/aspose.slides/control/frame/) | Mengembalikan atau mengatur bingkai kontrol.<br/>            Baca/tulis [`IShapeFrame`](/slides/python-net/id/aspose.slides/ishapeframe). |
| [`properties`](/slides/python-net/id/aspose.slides/control/properties/) | Mengembalikan koleksi properti ActiveX.<br/>            Catatan: Aspose.Slides hanya mendukung properti ActiveX berbasis XML. Jika properti disimpan dalam format biner, properti ini akan mengembalikan None.<br/>            Baca saja [`IControlPropertiesCollection`](/slides/python-net/id/aspose.slides/icontrolpropertiescollection). |
| [`active_x_control_binary`](/slides/python-net/id/aspose.slides/control/active_x_control_binary/) | Menentukan keberlangsungan sebuah kontrol ActiveX ketika metode yang digunakan untuk mempertahankannya adalah PersistStream, PersistStreamInit, atau PersistStorage. |

| [`presentation`](/slides/python-net/id/aspose.slides/control/presentation/) |  |
