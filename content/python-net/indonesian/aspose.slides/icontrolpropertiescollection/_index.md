## IControlPropertiesCollection kelas

Koleksi kontrol ActiveX.

Tipe IControlPropertiesCollection mengekspos anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`count`](/slides/python-net/id/aspose.slides/icontrolpropertiescollection/count/) | Mengembalikan jumlah properti dalam koleksi.<br/>            Hanya-baca **int**. |
| [`names_of_properties`](/slides/python-net/id/aspose.slides/icontrolpropertiescollection/names_of_properties/) | Mengembalikan jumlah properti dalam koleksi.<br/>            Hanya-baca **list**. |

| Metode | Deskripsi |
| :- | :- |
