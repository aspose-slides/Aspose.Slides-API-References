## NormalViewProperties kelas

Mewakili properti tampilan normal. Tampilan normal terdiri dari tiga wilayah konten: slide itu sendiri, wilayah konten samping, dan wilayah konten bawah.

Tipe NormalViewProperties mengekspose anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`show_outline_icons`](/slides/python-net/id/aspose.slides/normalviewproperties/show_outline_icons/) | Menentukan apakah aplikasi harus menampilkan ikon jika menampilkan konten outline di salah satu<br/>            wilayah konten mode tampilan normal.<br/>            Baca/tulis **bool**. |
| [`snap_vertical_splitter`](/slides/python-net/id/aspose.slides/normalviewproperties/snap_vertical_splitter/) | Menentukan apakah splitter vertikal harus menempel pada keadaan diminimalkan ketika wilayah samping<br/>            cukup kecil.<br/>            Baca/tulis **bool**. |
| [`vertical_bar_state`](/slides/python-net/id/aspose.slides/normalviewproperties/vertical_bar_state/) | Menentukan keadaan di mana bar splitter vertikal harus ditampilkan. <br/>            Bar splitter vertikal memisahkan slide dari wilayah konten samping. |
| [`horizontal_bar_state`](/slides/python-net/id/aspose.slides/normalviewproperties/horizontal_bar_state/) | Menentukan keadaan di mana bar splitter horizontal harus ditampilkan.<br/>            Bar splitter horizontal memisahkan slide dari wilayah konten di bawah slide. |
| [`prefer_single_view`](/slides/python-net/id/aspose.slides/normalviewproperties/prefer_single_view/) | Menentukan apakah pengguna lebih suka melihat satu wilayah konten tunggal penuh jendela dibandingkan<br/>            tampilan normal standar dengan tiga wilayah konten. Jika diaktifkan, aplikasi dapat memilih<br/>            untuk menampilkan salah satu wilayah konten di seluruh jendela.<br/>            Baca/tulis **bool**. |
| [`restored_left`](/slides/python-net/id/aspose.slides/normalviewproperties/restored_left/) | Elemen ini menentukan ukuran wilayah konten samping tampilan normal, ketika wilayah tersebut berukuran variabel<br/>            (tidak diminimalkan maupun dimaksimalkan).<br/>            Baca saja [`INormalViewRestoredProperties`](/slides/python-net/id/aspose.slides/inormalviewrestoredproperties). |
| [`restored_top`](/slides/python-net/id/aspose.slides/normalviewproperties/restored_top/) | Elemen ini menentukan ukuran wilayah slide atas tampilan normal, ketika wilayah tersebut berukuran variabel<br/>            (tidak diminimalkan maupun dimaksimalkan).<br/>            Baca saja [`INormalViewRestoredProperties`](/slides/python-net/id/aspose.slides/inormalviewrestoredproperties). |
