## Kelas Picture

Mewakili gambar dalam presentasi.

Tipe Picture menyediakan anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`image`](/slides/python-net/id/aspose.slides/picture/image/) | Mengembalikan atau mengatur gambar yang disematkan.<br/>            Baca/tulis [`IPPImage`](/slides/python-net/id/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/id/aspose.slides/picture/link_path_long/) | Mengembalikan atau mengatur URL gambar yang ditautkan.<br/>            Baca/tulis **str**. |
| [`image_transform`](/slides/python-net/id/aspose.slides/picture/image_transform/) | Mengembalikan koleksi efek transformasi gambar.<br/>            Baca-saja [`IImageTransformOperationCollection`](/slides/python-net/id/aspose.slides.effects/iimagetransformoperationcollection). |
| [`presentation`](/slides/python-net/id/aspose.slides/picture/presentation/) | Mengembalikan presentasi.<br/>            Baca-saja [`IPresentation`](/slides/python-net/id/aspose.slides/ipresentation). |
| [`slide`](/slides/python-net/id/aspose.slides/picture/slide/) | Mengembalikan slide induk dari gambar.<br/>            Baca-saja [`IBaseSlide`](/slides/python-net/id/aspose.slides/ibaseslide). |
