## IPPImage kelas

Mewakili sebuah gambar dalam presentasi.

Tipe IPPImage menampilkan anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`binary_data`](/slides/python-net/id/aspose.slides/ippimage/binary_data/) | Mengembalikan salinan data gambar.<br/>            Hanya-baca **int**[]. |
| [`image`](/slides/python-net/id/aspose.slides/ippimage/image/) | Mengembalikan salinan gambar.<br/>            Hanya-baca [`IPPImage.image`](/slides/python-net/id/aspose.slides/ippimage/image). |
| [`svg_image`](/slides/python-net/id/aspose.slides/ippimage/svg_image/) | Mengembalikan atau mengatur objek ISvgImage [`ISvgImage`](/slides/python-net/id/aspose.slides/isvgimage) |
| [`content_type`](/slides/python-net/id/aspose.slides/ippimage/content_type/) | Mengembalikan tipe MIME gambar, terenkode dalam [`IPPImage.binary_data`](/slides/python-net/id/aspose.slides/ippimage/binary_data).<br/>            Hanya-baca **str**. |
| [`width`](/slides/python-net/id/aspose.slides/ippimage/width/) | Mengembalikan lebar gambar.<br/>            Hanya-baca **int**. |
| [`height`](/slides/python-net/id/aspose.slides/ippimage/height/) | Mengembalikan tinggi gambar.<br/>            Hanya-baca **int**. |
| [`x`](/slides/python-net/id/aspose.slides/ippimage/x/) | Mengembalikan offset X gambar.<br/>            Hanya-baca **int**. |
| [`y`](/slides/python-net/id/aspose.slides/ippimage/y/) | Mengembalikan offset Y gambar.<br/>            Hanya-baca **int**. |
