## ColorSchemeIndex enumerasi

Mewakili sebuah indeks dalam skema warna.

Tipe ColorSchemeIndex menampilkan anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| DARK1 | Gelap 1. |
| LIGHT1 | Terang 1. |
| DARK2 | Gelap 2. |
| LIGHT2 | Terang 2. |
| ACCENT1 | Aksen 1. |
| ACCENT2 | Aksen 2. |
| ACCENT3 | Aksen 3. |
| ACCENT4 | Aksen 4. |
| ACCENT5 | Aksen 5. |
| ACCENT6 | Aksen 6. |
| HYPERLINK | Tautan. |
| FOLLOWED_HYPERLINK | Tautan yang diikuti. |
