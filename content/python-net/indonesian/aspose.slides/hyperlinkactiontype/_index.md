## enumerasi HyperlinkActionType

Mewakili tipe tindakan hyperlink.

Tipe HyperlinkActionType menampilkan anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| UNKNOWN | Tipe tindakan tidak dikenali. |
| NO_ACTION | Tidak ada tindakan. |
| HYPERLINK | Hyperlink biasa. |
| JUMP_FIRST_SLIDE | Melompat ke slide pertama presentasi. |
| JUMP_PREVIOUS_SLIDE | Melompat ke slide sebelumnya. |
| JUMP_NEXT_SLIDE | Melompat ke slide berikutnya. |
| JUMP_LAST_SLIDE | Melompat ke slide terakhir presentasi. |
| JUMP_END_SHOW | Melompat ke akhir pertunjukan slide. |
| JUMP_LAST_VIEWED_SLIDE | Melompat ke slide terakhir yang dilihat. |
| JUMP_SPECIFIC_SLIDE | Melompat ke slide tertentu, yang dirujuk oleh properti [`IHyperlink.target_slide`](/slides/python-net/id/aspose.slides/ihyperlink/target_slide). |
| START_CUSTOM_SLIDE_SHOW | Mulai pertunjukan slide khusus. |
| OPEN_FILE | Buka file yang dirujuk. |
| OPEN_PRESENTATION | Buka presentasi yang dirujuk. |
| START_STOP_MEDIA | Mulai/berhenti memutar file media. |
| START_MACRO | Mulai mengeksekusi skrip makro. |
| START_PROGRAM | Mulai program. |
