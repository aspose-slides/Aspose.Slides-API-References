## CommentAuthor kelas

Mewakili penulis komentar.

Tipe CommentAuthor mengekspos anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`name`](/slides/python-net/id/aspose.slides/commentauthor/name/) | Mengembalikan atau mengatur nama penulis.<br/>            Baca/tulis **str**. |
| [`initials`](/slides/python-net/id/aspose.slides/commentauthor/initials/) | Mengembalikan atau mengatur inisial penulis.<br/>            Baca/tulis **str**. |
| [`comments`](/slides/python-net/id/aspose.slides/commentauthor/comments/) | Mengembalikan kumpulan komentar yang dibuat oleh penulis ini.<br/>            Baca-saja [`ICommentCollection`](/slides/python-net/id/aspose.slides/icommentcollection). |

## Metode

| Metode | Deskripsi |
| :- | :- |
| [`remove(self)`](/slides/python-net/id/aspose.slides/commentauthor/remove/#) | Menghapus penulis dari koleksi induk. |
