## TextAutofitType enumerasi

Mewakili mode autofit teks.

Tipe TextAutofitType menampilkan anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| NOT_DEFINED | Tidak didefinisikan. |
| NONE | Tidak ada autofit. |
| NORMAL | Autofit normal. Ukuran font dan spasi baris akan dikurangi agar sesuai dengan bentuk. |
| SHAPE | Autofit bentuk. Ukuran bentuk akan diubah agar sesuai dengan teks. |
