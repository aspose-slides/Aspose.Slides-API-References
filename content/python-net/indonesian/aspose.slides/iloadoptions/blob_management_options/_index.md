## blob_management_options properti
Mewakili opsi yang dapat digunakan untuk mengelola perilaku penanganan Binary Large Objects (BLOBs),
            seperti penggunaan file sementara atau maksimum byte BLOBs dalam memori. Opsi-opsi ini dimaksudkan untuk mengatur
            rasio kinerja/konsumsi memori terbaik untuk lingkungan atau kebutuhan tertentu.
            Binary Large Object (BLOB) adalah data biner yang disimpan sebagai satu entitas - yaitu BLOB dapat
            menjadi audio, video, atau presentasi itu sendiri.
