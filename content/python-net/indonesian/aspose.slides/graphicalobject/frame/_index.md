            Baca/tulis [`IShapeFrame`](/slides/python-net/id/aspose.slides/ishapeframe).

### Catatan

Nilai setiap properti pada instance IShapeFrame yang dikembalikan tidak 
            undefined (bukan NaN atau NotDefined).
            Nilai setiap properti pada instance IShapeFrame yang ditetapkan harus tidak 
            undefined (harus bukan NaN atau NotDefined).
            Anda dapat mengatur nilai undefined untuk properti instance RawFrame.
