## Kelas Column

Mewakili sebuah kolom dalam sebuah tabel.

**Pewarisan:**[`Column`](/slides/python-net/id/aspose.slides/column) → [`CellCollection`](/slides/python-net/id/aspose.slides/cellcollection)

Tipe Column menampilkan anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`slide`](/slides/python-net/id/aspose.slides/column/slide/) | Mengembalikan slide induk dari sebuah CellCollection.<br/>            Baca-saja [`IBaseSlide`](/slides/python-net/id/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/id/aspose.slides/column/presentation/) | Mengembalikan presentasi induk dari sebuah CellCollection.<br/>            Baca-saja [`IPresentation`](/slides/python-net/id/aspose.slides/ipresentation). |
| [`width`](/slides/python-net/id/aspose.slides/column/width/) | Mengembalikan atau mengatur lebar kolom.<br/>            Baca/tulis **float**. |
| [`column_format`](/slides/python-net/id/aspose.slides/column/column_format/) | Mengembalikan objek ColumnFormat yang berisi properti format untuk kolom ini.<br/>            Baca-saja [`IColumnFormat`](/slides/python-net/id/aspose.slides/icolumnformat). |
