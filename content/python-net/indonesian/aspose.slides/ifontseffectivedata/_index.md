## IFontsEffectiveData kelas

Objek tidak dapat diubah yang berisi kumpulan font efektif.

Tipe IFontsEffectiveData mengekspos anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`latin_font`](/slides/python-net/id/aspose.slides/ifontseffectivedata/latin_font/) | Mengembalikan font Latin.<br/>            Hanya-baca [`IFontData`](/slides/python-net/id/aspose.slides/ifontdata). |
| [`east_asian_font`](/slides/python-net/id/aspose.slides/ifontseffectivedata/east_asian_font/) | Mengembalikan font Asia Timur.<br/>            Hanya-baca [`IFontData`](/slides/python-net/id/aspose.slides/ifontdata). |
| [`complex_script_font`](/slides/python-net/id/aspose.slides/ifontseffectivedata/complex_script_font/) | Mengembalikan font skrip kompleks.<br/>            Hanya-baca [`IFontData`](/slides/python-net/id/aspose.slides/ifontdata). |

### Keterangan

Antarmuka ini digunakan sebagai bagian dari antarmuka [`IBasePortionFormatEffectiveData`](/slides/python-net/id/aspose.slides/ibaseportionformateffectivedata) dan [`IFontSchemeEffectiveData`](/slides/python-net/id/aspose.slides.theme/ifontschemeeffectivedata).
