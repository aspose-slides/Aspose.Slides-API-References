## check_password(self, password) {#str}
Memeriksa apakah kata sandi benar untuk presentasi yang dilindungi dengan kata sandi terbuka.

### Mengembalikan

True jika presentasi dilindungi dengan kata sandi terbuka dan kata sandinya benar, dan false jika tidak.



```python
def check_password(self, password):
    ...
```


| Parameter | Tipe | Deskripsi |
| :- | :- | :- |
| password | **str** | Password yang akan diperiksa. |

### Catatan

Ketika password bernilai None atau kosong, metode ini mengembalikan false.
