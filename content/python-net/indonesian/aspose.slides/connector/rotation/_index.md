## rotation properti
Returns or sets the number of degrees the specified shape is rotated around
            the z-axis. A positive value indicates clockwise rotation; a negative value
            indicates counterclockwise rotation.
            Baca/tulis **float**.

### Catatan

Returned value is always defined (is not float.NaN).
            Assigned value must be defined (not float.NaN). Anda dapat mengatur nilai tak terdefinisi untuk properti instance RawFrame.
