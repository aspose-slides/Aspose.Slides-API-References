## VideoPlayModePreset enumerasi

Konstanta yang menentukan cara video diputar.

Tipe VideoPlayModePreset menampilkan anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| MIXED |  |
| AUTO | Putar secara otomatis. |
| ON_CLICK | Putar hanya ketika bingkai video diklik. |
| ALL_SLIDES | Putar pada semua slide. |
| IN_CLICK_SEQUENCE | Putar otomatis dengan klik. |
