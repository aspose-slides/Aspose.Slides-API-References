## IDrawingGuide kelas

Mewakili panduan gambar yang dapat disesuaikan.

Tipe IDrawingGuide menyediakan anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`orientation`](/slides/python-net/id/aspose.slides/idrawingguide/orientation/) | Mengembalikan atau mengatur orientasi panduan gambar.<br/>            Read/write [`Orientation`](/slides/python-net/id/aspose.slides/orientation). |
| [`position`](/slides/python-net/id/aspose.slides/idrawingguide/position/) | Mengembalikan atau mengatur posisi panduan gambar dalam poin dari sudut kiri atas slide.<br/>            Read/write **float**. |
| [`color`](/slides/python-net/id/aspose.slides/idrawingguide/color/) | Mengembalikan atau mengatur warna panduan gambar.<br/>            Read/write **aspose.slides.Color**. |
