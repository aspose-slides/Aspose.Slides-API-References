## layout_slides properti
Mengembalikan daftar semua slide tata letak yang didefinisikan dalam presentasi.
            Baca-saja [`IGlobalLayoutSlideCollection`](/slides/python-net/id/aspose.slides/igloballayoutslidecollection).

### Catatan

Anda dapat mengakses API alternatif untuk menambahkan/menyisipkan/menghapus/menggandakan slide tata letak 
            dengan menggunakan properti IMasterSlide.LayoutSlides.
