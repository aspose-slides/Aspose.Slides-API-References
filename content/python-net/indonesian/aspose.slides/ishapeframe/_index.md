## IShapeFrame kelas

Mewakili properti shape frame.

Tipe IShapeFrame menampilkan anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`x`](/slides/python-net/id/aspose.slides/ishapeframe/x/) | Mengembalikan koordinat X sudut kiri atas sebuah frame.<br/>            Baca-saja **float**. |
| [`y`](/slides/python-net/id/aspose.slides/ishapeframe/y/) | Mengembalikan koordinat Y sudut kiri atas sebuah frame.<br/>            Baca-saja **float**. |
| [`width`](/slides/python-net/id/aspose.slides/ishapeframe/width/) | Mengembalikan lebar sebuah frame.<br/>            Baca-saja **float**. |
| [`height`](/slides/python-net/id/aspose.slides/ishapeframe/height/) | Mengembalikan tinggi sebuah frame.<br/>            Baca-saja **float**. |
| [`rotation`](/slides/python-net/id/aspose.slides/ishapeframe/rotation/) | Mengembalikan jumlah derajat rotasi frame sekitar sumbu z. Nilai positif menunjukkan rotasi searah jarum jam; nilai negatif menunjukkan rotasi berlawanan arah jarum jam.<br/>            Baca-saja **float**. |
| [`center_x`](/slides/python-net/id/aspose.slides/ishapeframe/center_x/) | Mengembalikan koordinat X pusat sebuah frame.<br/>            Baca-saja **float**. |
| [`center_y`](/slides/python-net/id/aspose.slides/ishapeframe/center_y/) | Mengembalikan koordinat Y pusat sebuah frame.<br/>            Baca-saja **float**. |
| [`flip_h`](/slides/python-net/id/aspose.slides/ishapeframe/flip_h/) | Menentukan apakah sebuah frame dibalik secara horizontal.<br/>            Baca-saja [`NullableBool`](/slides/python-net/id/aspose.slides/nullablebool). |
| [`flip_v`](/slides/python-net/id/aspose.slides/ishapeframe/flip_v/) | Menentukan apakah sebuah frame dibalik secara vertikal.<br/>            Baca-saja [`NullableBool`](/slides/python-net/id/aspose.slides/nullablebool). |
| [`rectangle`](/slides/python-net/id/aspose.slides/ishapeframe/rectangle/) | Mengembalikan koordinat sebuah frame.<br/>            Baca-saja [`RectangleF`](/slides/python-net/id/aspose.slides/rectanglef). |
