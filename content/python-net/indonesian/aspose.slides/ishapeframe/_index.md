## IShapeFrame kelas

Mewakili properti bingkai bentuk.

Tipe IShapeFrame menampilkan anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`x`](/slides/python-net/id/aspose.slides/ishapeframe/x/) | Mengembalikan koordinat X sudut kiri atas sebuah bingkai.<br/>            Hanya baca **float**. |
| [`y`](/slides/python-net/id/aspose.slides/ishapeframe/y/) | Mengembalikan koordinat Y sudut kiri atas sebuah bingkai.<br/>            Hanya baca **float**. |
| [`width`](/slides/python-net/id/aspose.slides/ishapeframe/width/) | Mengembalikan lebar sebuah bingkai.<br/>            Hanya baca **float**. |
| [`height`](/slides/python-net/id/aspose.slides/ishapeframe/height/) | Mengembalikan tinggi sebuah bingkai.<br/>            Hanya baca **float**. |
| [`rotation`](/slides/python-net/id/aspose.slides/ishapeframe/rotation/) | Mengembalikan jumlah derajat bingkai diputar di sekitar sumbu z.<br/>            Nilai positif menunjukkan putaran searah jarum jam; nilai negatif<br/>            menunjukkan putaran berlawanan arah jarum jam.<br/>            Hanya baca **float**. |
| [`center_x`](/slides/python-net/id/aspose.slides/ishapeframe/center_x/) | Mengembalikan koordinat X pusat sebuah bingkai.<br/>            Hanya baca **float**. |
| [`center_y`](/slides/python-net/id/aspose.slides/ishapeframe/center_y/) | Mengembalikan koordinat Y pusat sebuah bingkai.<br/>            Hanya baca **float**. |
| [`flip_h`](/slides/python-net/id/aspose.slides/ishapeframe/flip_h/) | Menentukan apakah bingkai dibalik secara horizontal.<br/>            Hanya baca [`NullableBool`](/slides/python-net/id/aspose.slides/nullablebool). |
| [`flip_v`](/slides/python-net/id/aspose.slides/ishapeframe/flip_v/) | Menentukan apakah bingkai dibalik secara vertikal.<br/>            Hanya baca [`NullableBool`](/slides/python-net/id/aspose.slides/nullablebool). |
| [`rectangle`](/slides/python-net/id/aspose.slides/ishapeframe/rectangle/) | Mengembalikan koordinat sebuah bingkai.<br/>            Hanya baca **aspose.slides.RectangleF**. |
