## ImageFormat enumerasi

Mewakili format berkas gambar.

Tipe ImageFormat mengekspos anggota-anggota berikut:

## Bidang

| Field | Description |
| :- | :- |
| MEMORY_BMP | Mewakili format bitmap dalam memori. |
| BMP | Mewakili format gambar bitmap (BMP). |
| EMF | Mewakili format gambar metafile yang ditingkatkan (EMF). |
| WMF | Mewakili format gambar metafile Windows (WMF). |
| GIF | Mewakili format gambar Graphics Interchange Format (GIF). |
| JPEG | Mewakili format gambar Joint Photographic Experts Group (JPEG). |
| PNG | Mewakili format gambar Portable Network Graphics (PNG) W3C. |
| TIFF | Mewakili format gambar Tagged Image File Format (TIFF). |
| EXIF | Mewakili format Exchangeable Image File (Exif). |
| ICON | Mewakili format gambar ikon Windows. |
