## SizeF kelas

Menyimpan sepasang nilai floating-point yang berurutan, biasanya lebar dan tinggi sebuah persegi panjang. Kompatibel dengan .NET `System.Drawing.SizeF`.

Tipe SizeF menyediakan anggota-anggota berikut:

## Konstruktor

| Constructor | Description |
| :- | :- |
| [`__init__(self, width=0.0, height=0.0)`](/slides/python-net/id/aspose.slides/sizef/__init__/#float-float) | Membuat ukuran dengan lebar dan tinggi yang ditentukan. |

## Properti

| Property | Description |
| :- | :- |
| [`width`](/slides/python-net/id/aspose.slides/sizef/width/) | Mendapatkan komponen horizontal dari ukuran ini.<br/>            Hanya-baca **float**. |
| [`height`](/slides/python-net/id/aspose.slides/sizef/height/) | Mendapatkan komponen vertikal dari ukuran ini.<br/>            Hanya-baca **float**. |


### Catatan

Ukuran dibandingkan berdasarkan komponennya dengan `==` dan dapat digunakan sebagai kunci kamus atau anggota set.
