## ShapesAlignmentType enumerasi

Mendefinisikan cara mengubah penempatan bentuk yang dipilih pada slide.

Tipe ShapesAlignmentType menampilkan anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| ALIGN_LEFT | Rata kiri |
| ALIGN_RIGHT | Rata kanan |
| ALIGN_CENTER | Rata tengah |
| ALIGN_TOP | Rata atas |
| ALIGN_MIDDLE | Rata tengah |
| ALIGN_BOTTOM | Rata bawah |
| DISTRIBUTE_HORIZONTALLY | Distribusikan secara horizontal |
| DISTRIBUTE_VERTICALLY | Distribusikan secara vertikal |
