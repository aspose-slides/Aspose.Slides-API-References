## Kelas ICellFormat

Mewakili format sel tabel.

Tipe ICellFormat mengekspos anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`fill_format`](/slides/python-net/id/aspose.slides/icellformat/fill_format/) | Mengembalikan objek properti isi sel.<br/>            Hanya baca [`IFillFormat`](/slides/python-net/id/aspose.slides/ifillformat). |
| [`border_left`](/slides/python-net/id/aspose.slides/icellformat/border_left/) | Mengembalikan objek properti garis batas kiri.<br/>            Hanya baca [`ILineFormat`](/slides/python-net/id/aspose.slides/ilineformat). |
| [`border_top`](/slides/python-net/id/aspose.slides/icellformat/border_top/) | Mengembalikan objek properti garis batas atas.<br/>            Hanya baca [`ILineFormat`](/slides/python-net/id/aspose.slides/ilineformat). |
| [`border_right`](/slides/python-net/id/aspose.slides/icellformat/border_right/) | Mengembalikan objek properti garis batas kanan.<br/>            Hanya baca [`ILineFormat`](/slides/python-net/id/aspose.slides/ilineformat). |
| [`border_bottom`](/slides/python-net/id/aspose.slides/icellformat/border_bottom/) | Mengembalikan objek properti garis batas bawah.<br/>            Hanya baca [`ILineFormat`](/slides/python-net/id/aspose.slides/ilineformat). |
| [`border_diagonal_down`](/slides/python-net/id/aspose.slides/icellformat/border_diagonal_down/) | Mengembalikan objek properti garis diagonal kiri-atas ke kanan-bawah.<br/>            Hanya baca [`ILineFormat`](/slides/python-net/id/aspose.slides/ilineformat). |
| [`border_diagonal_up`](/slides/python-net/id/aspose.slides/icellformat/border_diagonal_up/) | Mengembalikan objek properti garis diagonal kiri-bawah ke kanan-atas.<br/>            Hanya baca [`ILineFormat`](/slides/python-net/id/aspose.slides/ilineformat). |
| [`transparency`](/slides/python-net/id/aspose.slides/icellformat/transparency/) | Mendapatkan atau mengatur transparansi warna isi.<br/>            Baca/tulis **float**. |
