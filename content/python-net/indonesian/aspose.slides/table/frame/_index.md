## properti frame
Mengembalikan atau mengatur properti frame bentuk.
            Baca/tulis [`IShapeFrame`](/slides/python-net/id/aspose.slides/ishapeframe).

### Catatan

Nilai setiap properti dari instance IShapeFrame yang dikembalikan tidak 
            terdefinisi (bukan NaN atau NotDefined).
            Nilai setiap properti dari instance IShapeFrame yang ditetapkan harus tidak 
            terdefinisi (harus bukan NaN atau NotDefined).
            Anda dapat mengatur nilai tidak terdefinisi untuk properti instance RawFrame.
