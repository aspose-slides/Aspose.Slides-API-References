## AudioPlayModePreset enumerasi

Konstanta yang menentukan cara suara diputar.

Tipe AudioPlayModePreset menampilkan anggota berikut:

## Bidang

| Field | Description |
| :- | :- |
| MIXED |  |
| AUTO | Putar secara otomatis. |
| ON_CLICK | Putar hanya ketika ikon diklik. |
| ALL_SLIDES | Putar pada semua slide. <br/>            Silakan gunakan properti [`IAudioFrame.play_across_slides`](/slides/python-net/id/aspose.slides/iaudioframe/play_across_slides) sebagai gantinya.<br/>            Elemen ini sudah tidak berlaku sejak PowerPoint 2013. |
| IN_CLICK_SEQUENCE | Putar secara otomatis dengan satu klik. |
