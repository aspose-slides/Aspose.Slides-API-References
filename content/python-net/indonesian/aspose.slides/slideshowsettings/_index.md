## SlideShowSettings kelas

Mewakili pengaturan slide show untuk presentasi.

Tipe SlideShowSettings menampilkan anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`slide_show_type`](/slides/python-net/id/aspose.slides/slideshowsettings/slide_show_type/) | Mendapatkan atau mengatur tipe slide show. Diwakili oleh [`SlideShowSettings.slide_show_type`](/slides/python-net/id/aspose.slides/slideshowsettings/slide_show_type) nenek moyang berikut: [`BrowsedAtKiosk`](/slides/python-net/id/aspose.slides/browsedatkiosk), [`PresentedBySpeaker`](/slides/python-net/id/aspose.slides/presentedbyspeaker) dan [`BrowsedByIndividual`](/slides/python-net/id/aspose.slides/browsedbyindividual) |
| [`loop`](/slides/python-net/id/aspose.slides/slideshowsettings/loop/) | Putar Ulang Slide Show |
| [`show_narration`](/slides/python-net/id/aspose.slides/slideshowsettings/show_narration/) | Tampilkan Narasi dalam Slide Show |
| [`show_animation`](/slides/python-net/id/aspose.slides/slideshowsettings/show_animation/) | Tampilkan Animasi dalam Slide Show |
| [`pen_color`](/slides/python-net/id/aspose.slides/slideshowsettings/pen_color/) | Warna Pena untuk Slide Show |
| [`slides`](/slides/python-net/id/aspose.slides/slideshowsettings/slides/) | Rentang Slide |
| [`use_timings`](/id/slides/python-net/aspose.slides/slideshowsettings/use_timings/) | Gunakan Waktu dalam Slide Show |
| [`show_media_controls`](/slides/python-net/id/aspose.slides/slideshowsettings/show_media_controls/) | Tampilkan Kontrol Media |
