## ICustomXmlPart kelas

Mewakili bagian xml khusus.

Tipe ICustomXmlPart mengekspos anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`xml_as_string`](/slides/python-net/id/aspose.slides/icustomxmlpart/xml_as_string/) | Mengembalikan atau mengatur data xml sebagai string UTF-8.<br/>            Baca/tulis **str**.<br/>            nilai adalah `None`. nilai kosong atau data xml tidak valid. |
| [`xml_data`](/slides/python-net/id/aspose.slides/icustomxmlpart/xml_data/) | Mengembalikan atau mengatur data xml.<br/>            Baca/tulis **int**[].<br/>            nilai adalah `None`. nilai kosong atau data xml tidak valid. |
| [`item_id`](/slides/python-net/id/aspose.slides/icustomxmlpart/item_id/) | Menentukan pengidentifikasi unik secara global (GUID) yang secara unik mengidentifikasi satu bagian XML khusus dalam dokumen Office Open XML.<br/>            Baca-saja **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/id/aspose.slides/icustomxmlpart/namespace_schemas/) | Mengembalikan kumpulan skema XML yang terkait dengan bagian XML khusus.<br/>            Baca-saja **str**[]. |

## Metode

| Metode | Deskripsi |
| :- | :- |
| [`remove(self)`](/slides/python-net/id/aspose.slides/icustomxmlpart/remove/#) | Menghapus bagian xml khusus dari presentasi. |
