## Enumerasi FillType

Menentukan jenis isian interior dari berbagai objek visual.

Tipe FillType menampilkan anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| NOT_DEFINED | Jenis isian tidak ditentukan. |
| NO_FILL | Tidak ada isian yang diterapkan. |
| SOLID | Diisi dengan warna solid. |
| GRADIENT | Isian berupa gradien. |
| PATTERN | Pola berulang digunakan untuk mengisi objek. |
| PICTURE | Satu gambar digunakan untuk mengisi objek. |
| GROUP | Objek visual mewarisi properti isian dari grup. |
