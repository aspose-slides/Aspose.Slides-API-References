## IFontFallBackRule kelas

Mewakili aturan fallback font

Tipe IFontFallBackRule menampilkan anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`range_start_index`](/slides/python-net/id/aspose.slides/ifontfallbackrule/range_start_index/) | Mengambil indeks pertama dari rentang unicode berkelanjutan. |
| [`range_end_index`](/slides/python-net/id/aspose.slides/ifontfallbackrule/range_end_index/) | Mengambil indeks terakhir dari rentang unicode berkelanjutan. |
| [`count`](/slides/python-net/id/aspose.slides/ifontfallbackrule/count/) | Mendapatkan jumlah font yang sebenarnya didefinisikan untuk rentang. |

Mendapatkan nama font pada indeks yang ditentukan.
