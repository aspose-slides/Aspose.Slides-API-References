## ITagCollection kelas

Mewakili koleksi tag (pasangan string yang didefinisikan pengguna)

Tipe ITagCollection mengekspos anggota-anggota berikut:

## Metode

| Metode | Deskripsi |
| :- | :- |
| [`add(self, name, value)`](/slides/python-net/id/aspose.slides/itagcollection/add/#str-str) | Menambahkan tag baru ke koleksi. |
| [`remove(self, name)`](/slides/python-net/id/aspose.slides/itagcollection/remove/#str) | Menghapus tag dengan nama yang ditentukan dari koleksi. |
| [`index_of_name(self, name)`](/slides/python-net/id/aspose.slides/itagcollection/index_of_name/#str) | Mengembalikan indeks berbasis nol dari kunci yang ditentukan dalam koleksi. |
| [`remove_at(self, index)`](/slides/python-net/id/aspose.slides/itagcollection/remove_at/#int) | Menghapus tag pada indeks yang ditentukan. |
| [`clear(self)`](/slides/python-net/id/aspose.slides/itagcollection/clear/#) | Menghapus semua tag dari koleksi. |
| [`get_value_by_index(self, index)`](/slides/python-net/id/aspose.slides/itagcollection/get_value_by_index/#int) | Mengembalikan nilai tag pada indeks yang ditentukan. |
| [`get_name_by_index(self, index)`](/slides/python-net/id/aspose.slides/itagcollection/get_name_by_index/#int) | Mengembalikan kunci tag pada indeks yang ditentukan. |
| [`get_names_of_tags(self)`](/slides/python-net/id/aspose.slides/itagcollection/get_names_of_tags/#) | Mengembalikan nama-nama tag. |
