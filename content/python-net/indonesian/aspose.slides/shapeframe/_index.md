## Properti

| Properti | Deskripsi |
| :- | :- |
| [`x`](/slides/python-net/id/aspose.slides/shapeframe/x/) | Mengembalikan koordinat X sudut kiri atas sebuah frame.<br/>            Hanya-baca **float**. |
| [`y`](/slides/python-net/id/aspose.slides/shapeframe/y/) | Mengembalikan koordinat Y sudut kiri atas sebuah frame.<br/>            Hanya-baca **float**. |
| [`width`](/slides/python-net/id/aspose.slides/shapeframe/width/) | Mengembalikan lebar sebuah frame.<br/>            Hanya-baca **float**. |
| [`height`](/slides/python-net/id/aspose.slides/shapeframe/height/) | Mengembalikan tinggi sebuah frame.<br/>            Hanya-baca **float**. |
| [`rotation`](/slides/python-net/id/aspose.slides/shapeframe/rotation/) | Mengembalikan jumlah derajat frame diputar di sekitar sumbu z.<br/>            Nilai positif menunjukkan rotasi searah jarum jam; nilai negatif<br/>            menunjukkan rotasi berlawanan arah jarum jam.<br/>            Hanya-baca **float**. |
| [`center_x`](/slides/python-net/id/aspose.slides/shapeframe/center_x/) | Mengembalikan koordinat X pusat sebuah frame.<br/>            Hanya-baca **float**. |
| [`center_y`](/slides/python-net/id/aspose.slides/shapeframe/center_y/) | Mengembalikan koordinat Y pusat sebuah frame.<br/>            Hanya-baca **float**. |
| [`flip_h`](/slides/python-net/id/aspose.slides/shapeframe/flip_h/) | Menentukan apakah sebuah frame dibalik secara horizontal.<br/>            Hanya-baca [`NullableBool`](/slides/python-net/id/aspose.slides/nullablebool). |
| [`flip_v`](/slides/python-net/id/aspose.slides/shapeframe/flip_v/) | Menentukan apakah sebuah frame dibalik secara vertikal.<br/>            Hanya-baca [`NullableBool`](/slides/python-net/id/aspose.slides/nullablebool). |
| [`rectangle`](/slides/python-net/id/aspose.slides/shapeframe/rectangle/) | Mengembalikan koordinat sebuah frame.<br/>            Hanya-baca [`RectangleF`](/slides/python-net/id/aspose.slides/rectanglef). |
