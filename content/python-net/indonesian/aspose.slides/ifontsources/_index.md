## IFontSources class

Menyediakan sumber file dan memori untuk font eksternal.

Tipe IFontSources mengekspos anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`font_folders`](/slides/python-net/id/aspose.slides/ifontsources/font_folders/) | Folder yang berisi file font.<br/>Semua file font yang berada di folder ini disertakan dalam koleksi. Folder yang dicari secara rekursif. |
| [`memory_fonts`](/slides/python-net/id/aspose.slides/ifontsources/memory_fonts/) | Koleksi font yang direpresentasikan sebagai array byte. |
