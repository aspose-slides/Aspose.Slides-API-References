## compare_to(self, obj) {#any}
Membandingkan instance saat ini dengan objek lain dengan tipe yang sama.

### Mengembalikan

Integer 32-bit yang menunjukkan urutan relatif dari kedua objek yang dibandingkan.
            Nilai kembali memiliki makna berikut:
            
*  < 0 - Instance ini kurang dari obj. = 0 - Instance ini sama dengan obj. > 0 - Instance ini lebih besar dari obj.

*  < 0 - Instance ini kurang dari obj. = 0 - Instance ini sama dengan obj. > 0 - Instance ini lebih besar dari obj.

*  < 0 - Instance ini kurang dari obj. = 0 - Instance ini sama dengan obj. > 0 - Instance ini lebih besar dari obj.
