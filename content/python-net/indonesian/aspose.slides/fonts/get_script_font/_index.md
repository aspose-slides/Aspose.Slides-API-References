## get_script_font(self, script) {#str}
Mengambil nama font yang terkait dengan tag skrip tertentu dari tema presentasi.

### Mengembalikan

Nama font yang digunakan untuk skrip yang ditentukan, atau `None` jika skrip tidak didefinisikan.



```python
def get_script_font(self, script):
    ...
```


| Parameter | Tipe | Deskripsi |
| :- | :- | :- |
| script | **str** | Kode skrip BCP-47 (misalnya "Latn", "Cyrl", "Jpan") yang digunakan untuk mengidentifikasi sistem penulisan. |
