## ICaptions kelas

Mewakili caption tertutup WebVTT.

Tipe ICaptions menampilkan anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`caption_id`](/slides/python-net/id/aspose.slides/icaptions/caption_id/) | Mengembalikan pengenal unik global (GUID) dari caption tertutup.<br/>            Baca-saja **System.Guid**. |
| [`label`](/slides/python-net/id/aspose.slides/icaptions/label/) | Mengembalikan atau mengatur label caption tertutup.<br/>            Baca/tulis **str**. |
| [`binary_data`](/slides/python-net/id/aspose.slides/icaptions/binary_data/) | Mengembalikan data biner caption tertutup.<br/>            Baca-saja **int**[]. |
| [`data_as_string`](/slides/python-net/id/aspose.slides/icaptions/data_as_string/) | Mengembalikan data caption tertutup sebagai string ber-encoding UTF-8<br/>            Baca-saja **str**. |
