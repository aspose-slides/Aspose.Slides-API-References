## __init__(self, r=0, g=0, b=0, a=255) {#int-int-int-int}
Membuat warna dari nilai komponen merah, hijau, biru, dan alfa yang ditentukan.


```python
def __init__(self, r=0, g=0, b=0, a=255):
    ...
```


| Parameter | Tipe | Deskripsi |
| :- | :- | :- |
| r | **int** | Nilai komponen merah. Nilai yang valid adalah 0 hingga 255. |
| g | **int** | Nilai komponen hijau. Nilai yang valid adalah 0 hingga 255. |
| b | **int** | Nilai komponen biru. Nilai yang valid adalah 0 hingga 255. |
| a | **int** | Nilai komponen alfa. Nilai yang valid adalah 0 hingga 255. |

### Pengecualian

| Pengecualian | Deskripsi |
| :- | :- |
| **ValueError** | Nilai komponen kurang dari 0 atau lebih besar dari 255. |
| **TypeError** | Nilai komponen bukan angka. |
