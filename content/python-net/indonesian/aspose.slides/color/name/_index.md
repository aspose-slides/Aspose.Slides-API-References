## properti name
Mendapatkan nama warna ini.<br/>            Untuk warna bernama (konstanta bernama seperti `Color.red`, atau warna yang dibuat dengan [`from_name`](/slides/python-net/id/aspose.slides/color/from_name/)) nama .NET dikembalikan, misalnya `"Red"` atau `"LightBlue"`.<br/>            Untuk warna lain nilai ARGB dikembalikan sebagai heksadesimal huruf kecil tanpa padding nol, misalnya `"ffff0000"`. `Color.empty.name` adalah `"0"`.
            Baca-saja **str**.
