## ITextSearchOptions kelas

Mewakili opsi yang dapat digunakan untuk mencari teks dalam Presentation, Slide, atau TextFrame.

Tipe ITextSearchOptions menyajikan anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`case_sensitive`](/slides/python-net/id/aspose.slides/itextsearchoptions/case_sensitive/) | Atur true untuk menggunakan pencarian yang sensitif huruf, false - lainnya.<br/>            Baca/tulis **bool**. |
| [`whole_words_only`](/slides/python-net/id/aspose.slides/itextsearchoptions/whole_words_only/) | Atur true untuk mencocokkan hanya kata lengkap, false - lainnya.<br/>            Baca/tulis **bool**. |
| [`include_notes`](/slides/python-net/id/aspose.slides/itextsearchoptions/include_notes/) | Atur `true` untuk menyertakan teks yang terdapat dalam catatan slide <br/>            saat melakukan pencarian teks, penggantian, atau operasi penyorotan.<br/>            Nilai default adalah `false`. |
