## enumerasi LoadFormat

Menunjukkan format dokumen yang akan dimuat.

Tipe LoadFormat memperlihatkan anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| AUTO | Menginstruksikan Aspose.Slides untuk mengenali format secara otomatis. |
| PPT | Microsoft PowerPoint Presentasi 97-2003. |
| PPS | Microsoft PowerPoint SlideShow 97-2003. |
| PPTX | Dokumen Microsoft Office Open XML PresentationML. |
| PPSX | SlideShow Microsoft Office Open XML PresentationML. |
| ODP | Presentasi OpenOffice ODF. |
| POTX | Templat Microsoft Office Open XML PresentationML. |
| PPTM | Dokumen Microsoft Office Open XML PresentationML yang mendukung makro. |
| PPSM | SlideShow Microsoft Office Open XML PresentationML yang mendukung makro. |
| POTM | Templat Microsoft Office Open XML PresentationML yang mendukung makro. |
| OTP | Templat Presentasi OpenOffice OTP. |
| PPT95 | Presentasi Microsoft PowerPoint 95. |
| POT | Templat Presentasi Microsoft PowerPoint 97-2003. |
| FODP | Presentasi Flat XML ODF. |
| UNKNOWN | Format file tidak diketahui |
