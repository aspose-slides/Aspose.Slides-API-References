## Comment kelas

Mewakili komentar pada slide.

Tipe Comment menampilkan anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`text`](/slides/python-net/id/aspose.slides/comment/text/) | Mengembalikan atau mengatur teks polos komentar slide.<br/>            Baca/tulis **str**. |
| [`created_time`](/slides/python-net/id/aspose.slides/comment/created_time/) | Mengembalikan atau mengatur waktu pembuatan komentar.<br/>            Menetapkan properti ini ke **System.DateTime** berarti tidak ada waktu komentar yang diatur.<br/>            Baca/tulis **System.DateTime**. |
| [`slide`](/slides/python-net/id/aspose.slides/comment/slide/) | Mengembalikan atau mengatur slide induk dari komentar.<br/>            Baca-saja [`ISlide`](/slides/python-net/id/aspose.slides/islide). |
| [`author`](/slides/python-net/id/aspose.slides/comment/author/) | Mengembalikan penulis komentar.<br/>            Baca-saja [`ICommentAuthor`](/slides/python-net/id/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/id/aspose.slides/comment/position/) | Mengembalikan atau mengatur posisi komentar pada slide.<br/>            Baca/tulis [`PointF`](/slides/python-net/id/aspose.slides/pointf). |
| [`parent_comment`](/slides/python-net/id/aspose.slides/comment/parent_comment/) | Mengambil atau mengatur komentar induk.<br/>            Baca/tulis [`IComment`](/slides/python-net/id/aspose.slides/icomment). |

## Metode

| Metode | Deskripsi |
| :- | :- |
| [`remove(self)`](/slides/python-net/id/aspose.slides/comment/remove/#) | Menghapus komentar dan semua balasannya dari koleksi induk. |
