## IResourceLoadingArgs kelas

Antarmuka untuk argumen pemuatan sumber daya eksternal.

Tipe IResourceLoadingArgs menampilkan anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`original_uri`](/slides/python-net/id/aspose.slides/iresourceloadingargs/original_uri/) | URI asli sumber daya sebagaimana ditentukan dalam presentasi yang diimpor. |
| [`uri`](/slides/python-net/id/aspose.slides/iresourceloadingargs/uri/) | URI sumber daya yang digunakan untuk mengunduh jika **Aspose.Slides.IResourceLoadingCallback.ResourceLoading(Aspose.Slide** <br/>            returns [`ResourceLoadingAction.DEFAULT`](/slides/python-net/id/aspose.slides/resourceloadingaction/DEFAULT). <br/>            Awalnya diatur ke URI asli sumber daya, tetapi dapat didefinisikan ulang ke nilai apa pun. |

## Metode

| Metode | Deskripsi |
| :- | :- |
| [`set_data(self, data)`](/slides/python-net/id/aspose.slides/iresourceloadingargs/set_data/#bytes) | Mengatur data yang disediakan pengguna untuk sumber daya yang digunakan jika **Aspose.Slides.IResourceLoadingCallback.ResourceLoading(Aspose.Slide** <br/>            returns [`ResourceLoadingAction.USER_PROVIDED`](/slides/python-net/id/aspose.slides/resourceloadingaction/USER_PROVIDED). |
