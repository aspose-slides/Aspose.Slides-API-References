## SlideSize kelas

Mewakili ukuran dan orientasi slide.

Tipe SlideSize mengekspos anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`size`](/slides/python-net/id/aspose.slides/slidesize/size/) | Mengambil dimensi slide dalam poin. |
| [`type`](/slides/python-net/id/aspose.slides/slidesize/type/) | Mengambil tipe ukuran slide. |
| [`orientation`](/slides/python-net/id/aspose.slides/slidesize/orientation/) | Mengambil atau mengatur orientasi slide. |
