## is_bullet_hard_font properti
Menentukan apakah bullet memiliki font sendiri atau mewarisinya dari bagian pertama dalam paragraf.
            **NullableBool.True**  if bullet has own font and **NullableBool.False**  if bullet
            inherits font from the first portion in the paragraph.
            Baca/tulis [`NullableBool`](/slides/python-net/id/aspose.slides/nullablebool).
