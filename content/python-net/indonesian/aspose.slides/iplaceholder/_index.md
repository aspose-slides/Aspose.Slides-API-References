## IPlaceholder kelas

Mewakili placeholder pada slide.

Tipe IPlaceholder menampilkan anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`orientation`](/slides/python-net/id/aspose.slides/iplaceholder/orientation/) | Mendapatkan orientasi placeholder.<br/>            Baca-saja [`Orientation`](/slides/python-net/id/aspose.slides/orientation). |
| [`size`](/slides/python-net/id/aspose.slides/iplaceholder/size/) | Mendapatkan ukuran placeholder.<br/>            Baca-saja [`PlaceholderSize`](/slides/python-net/id/aspose.slides/placeholdersize). |
| [`type`](/slides/python-net/id/aspose.slides/iplaceholder/type/) | Mendapatkan tipe placeholder.<br/>            Baca-saja [`PlaceholderType`](/slides/python-net/id/aspose.slides/placeholdertype). |
| [`index`](/slides/python-net/id/aspose.slides/iplaceholder/index/) | Mendapatkan indeks placeholder.<br/>            Baca-saja **int**. |
