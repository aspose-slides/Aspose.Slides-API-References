## ImageWrapper kelas

Pembungkus System.Drawing.Image untuk antarmuka COM.

Tipe ImageWrapper menampilkan anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`image_source`](/slides/python-net/id/aspose.slides/imagewrapper/image_source/) | Mendapatkan Image.<br/>            Baca-saja [`IImage`](/slides/python-net/id/aspose.slides/iimage). |
| [`size`](/slides/python-net/id/aspose.slides/imagewrapper/size/) | Mendapatkan lebar dan tinggi, dalam piksel, dari Image.<br/>            Baca-saja [`ImageWrapper.size`](/slides/python-net/id/aspose.slides/imagewrapper/size). |
