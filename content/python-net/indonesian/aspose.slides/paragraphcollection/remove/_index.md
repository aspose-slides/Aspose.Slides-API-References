## remove(self, item) {#iparagraph}
Menghapus kemunculan pertama dari objek tertentu dari **System.Collections.Generic.ICollection`1**.

### Mengembalikan

true jika `item` berhasil dihapus dari **System.Collections.Generic.ICollection`1**; jika tidak, false. Metode ini juga mengembalikan false jika `item` tidak ditemukan dalam **System.Collections.Generic.ICollection`1** yang asli.



```python
def remove(self, item):
    ...
```


| Parameter | Tipe | Deskripsi |
| :- | :- | :- |
| item | [`IParagraph`](/slides/python-net/id/aspose.slides/iparagraph) | Objek yang akan dihapus dari **System.Collections.Generic.ICollection`1**. |

### Pengecualian

| Pengecualian | Deskripsi |
| :- | :- |
| **RuntimeError(Proxy error(NotSupportedException))** | **System.Collections.Generic.ICollection`1** bersifat hanya-baca. |
