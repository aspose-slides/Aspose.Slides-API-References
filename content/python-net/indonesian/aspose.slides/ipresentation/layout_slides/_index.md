## layout_slides properti
Mengembalikan daftar semua layout slide yang didefinisikan dalam presentasi.
            Hanya baca [`IGlobalLayoutSlideCollection`](/slides/python-net/id/aspose.slides/igloballayoutslidecollection).


### Catatan

Anda dapat mengakses API alternatif untuk menambahkan/menyisipkan/menghapus/menyalin layout slide dengan menggunakan IMasterSlide.LayoutSlides properti.
