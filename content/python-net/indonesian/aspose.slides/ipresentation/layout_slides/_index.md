## layout_slides properti
Mengembalikan daftar semua slide tata letak yang didefinisikan dalam presentasi.
            Hanya-baca [`IGlobalLayoutSlideCollection`](/slides/python-net/id/aspose.slides/igloballayoutslidecollection).

### Catatan

Anda dapat mengakses API alternatif untuk menambah/memasukkan/menghapus/menduplikasi slide tata letak 
            dengan menggunakan properti IMasterSlide.LayoutSlides.
