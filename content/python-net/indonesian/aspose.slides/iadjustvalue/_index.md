## IAdjustValue kelas

Mewakili nilai penyesuaian bentuk geometris.
            Nilai-nilai ini memengaruhi bentuk shape.

Tipe IAdjustValue menampilkan anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`raw_value`](/slides/python-net/id/aspose.slides/iadjustvalue/raw_value/) | Mengembalikan atau mengatur nilai penyesuaian "as is".<br/>            Baca/tulis **int**. |
| [`angle_value`](/slides/python-net/id/aspose.slides/iadjustvalue/angle_value/) | Mengembalikan atau mengatur nilai, menginterpretasikannya sebagai sudut dalam derajat.<br/>            Baca/tulis **float**. |
| [`name`](/slides/python-net/id/aspose.slides/iadjustvalue/name/) | Mengembalikan nama nilai penyesuaian ini.<br/>            Hanya-baca **str**. |
| [`type`](/slides/python-net/id/aspose.slides/iadjustvalue/type/) | Mengembalikan tipe penyesuaian bentuk.<br/>            Hanya-baca [`ShapeAdjustmentType`](/slides/python-net/id/aspose.slides/shapeadjustmenttype). |
