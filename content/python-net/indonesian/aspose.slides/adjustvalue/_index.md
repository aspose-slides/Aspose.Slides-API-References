## kelas AdjustValue

Mewakili nilai penyesuaian bentuk geometri.  
These values affect shape's form.

Tipe AdjustValue mengekspos anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`raw_value`](/slides/python-net/id/aspose.slides/adjustvalue/raw_value/) | Mengembalikan atau mengatur nilai penyesuaian "as is".<br/>            Baca/tulis **int**. |
| [`angle_value`](/slides/python-net/id/aspose.slides/adjustvalue/angle_value/) | Mengembalikan atau mengatur nilai, menginterpretasikannya sebagai sudut dalam derajat.<br/>            Baca/tulis **float**. |
| [`name`](/slides/python-net/id/aspose.slides/adjustvalue/name/) | Mengembalikan nama nilai penyesuaian ini.<br/>            Baca-saja **str**. |
| [`type`](/slides/python-net/id/aspose.slides/adjustvalue/type/) | Mengembalikan tipe penyesuaian bentuk.<br/>            Baca-saja [`ShapeAdjustmentType`](/slides/python-net/id/aspose.slides/shapeadjustmenttype). |
