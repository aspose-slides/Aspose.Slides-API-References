## FontsLoader kelas

Kelas untuk memuat font khusus yang didefinisikan oleh pengguna.
Harus digunakan sebelum membuat objek presentasi apa pun.

Tipe FontsLoader mengekspos anggota-anggota berikut:

## Metode

| Metode | Deskripsi |
| :- | :- |
| [`load_external_fonts(directories)`](/slides/python-net/id/aspose.slides/fontsloader/load_external_fonts/#liststr) | Menambahkan folder tambahan untuk mencari font. |
| [`load_external_font(data)`](/slides/python-net/id/aspose.slides/fontsloader/load_external_font/#bytes) | Menambahkan font dari data biner |
| [`get_font_folders()`](/slides/python-net/id/aspose.slides/fontsloader/get_font_folders/#) | Mendapatkan folder font. Mengembalikan folder yang telah ditambahkan dengan metode LoadExternalFonts serta folder font sistem |
| [`clear_cache()`](/slides/python-net/id/aspose.slides/fontsloader/clear_cache/#) | Melepaskan semua font khusus yang didefinisikan oleh pengguna |
