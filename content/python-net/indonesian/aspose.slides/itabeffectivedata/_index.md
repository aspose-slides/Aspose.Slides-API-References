## kelas ITabEffectiveData

Objek tidak dapat diubah yang berisi properti tabulasi penghentian teks efektif.

Tipe ITabEffectiveData mengekspos anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`position`](/slides/python-net/id/aspose.slides/itabeffectivedata/position/) | Mengembalikan posisi tab.<br/>            Menetapkan properti ini dapat mengubah indeks tab dalam koleksi dan membatalkan Enumerator.<br/>            Hanya-baca **float**. |
| [`alignment`](/slides/python-net/id/aspose.slides/itabeffectivedata/alignment/) | Mengembalikan gaya perataan tab.<br/>            Hanya-baca [`TabAlignment`](/slides/python-net/id/aspose.slides/tabalignment). |


### Catatan

Antarmuka ini digunakan sebagai bagian dari [`IParagraphFormatEffectiveData`](/slides/python-net/id/aspose.slides/iparagraphformateffectivedata).
