## CustomXmlPart kelas

Mewakili bagian xml khusus.

Tipe CustomXmlPart mengekspos anggota berikut:

## Properti

| Property | Description |
| :- | :- |
| [`xml_data`](/slides/python-net/id/aspose.slides/customxmlpart/xml_data/) | Mengembalikan atau mengatur data xml.<br/>            Baca/tulis **int**[].<br/>            nilai adalah `None`.nilai kosong atau data xml tidak valid. |
| [`xml_as_string`](/slides/python-net/id/aspose.slides/customxmlpart/xml_as_string/) | Mengembalikan atau mengatur data xml sebagai string UTF-8.<br/>            Baca/tulis **str**.<br/>            nilai adalah `None`.nilai kosong atau data xml tidak valid. |
| [`item_id`](/slides/python-net/id/aspose.slides/customxmlpart/item_id/) | Menentukan pengidentifikasi unik global (GUID) yang secara unik mengidentifikasi satu bagian XML khusus <br/>            dalam dokumen Office Open XML.<br/>            Hanya-baca **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/id/aspose.slides/customxmlpart/namespace_schemas/) | Mengembalikan kumpulan skema XML yang terkait dengan bagian XML khusus.<br/>            Hanya-baca **str**[]. |
