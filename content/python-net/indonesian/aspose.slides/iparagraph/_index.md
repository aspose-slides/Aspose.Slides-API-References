## IParagraph kelas

Mewakili sebuah paragraf teks.

Tipe IParagraph menampilkan anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`portions`](/slides/python-net/id/aspose.slides/iparagraph/portions/) | Mengembalikan koleksi bagian teks.<br/>            Hanya-baca [`IPortionCollection`](/slides/python-net/id/aspose.slides/iportioncollection). |
| [`paragraph_format`](/slides/python-net/id/aspose.slides/iparagraph/paragraph_format/) | Mengembalikan objek pemformatan untuk paragraf ini.<br/>            Hanya-baca [`IParagraphFormat`](/slides/python-net/id/aspose.slides/iparagraphformat). |
| [`text`](/slides/python-net/id/aspose.slides/iparagraph/text/) | Mendapatkan atau mengatur teks polos dari sebuah paragraf.<br/>            Baca/tulis **str**. |
| [`end_paragraph_portion_format`](/slides/python-net/id/aspose.slides/iparagraph/end_paragraph_portion_format/) | Menentukan properti bagian yang akan digunakan jika satu bagian lain disisipkan setelah <br/>            yang terakhir. |
| [`slide`](/slides/python-net/id/aspose.slides/iparagraph/slide/) |  |
| [`presentation`](/slides/python-net/id/aspose.slides/iparagraph/presentation/) |  |

## Metode

| Metode | Deskripsi |
| :- | :- |
| [`get_image`](/slides/python-net/id/aspose.slides/iparagraph/get_image/#) | Mengembalikan gambar paragraf. |
| [`get_image`](/slides/python-net/id/aspose.slides/iparagraph/get_image/#float-float) | Mengembalikan gambar paragraf dengan skala yang ditentukan. |
| [`join_portions_with_same_formatting`](/slides/python-net/id/aspose.slides/iparagraph/join_portions_with_same_formatting/#) | Menggabungkan run dengan pemformatan yang sama. |
| [`get_rect`](/slides/python-net/id/aspose.slides/iparagraph/get_rect/#) | Mendapatkan koordinat rect yang membatasi paragraf. Rect mencakup semua baris<br/>            teks dalam paragraf, termasuk yang kosong. |
| [`get_lines_count`](/slides/python-net/id/aspose.slides/iparagraph/get_lines_count/#) | Mendapatkan jumlah baris dalam paragraf. |
