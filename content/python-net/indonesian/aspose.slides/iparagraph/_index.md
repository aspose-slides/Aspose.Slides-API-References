## IParagraph kelas

Mewakili sebuah paragraf teks.

Tipe IParagraph memperlihatkan anggota-anggota berikut:

## Properti

| Property | Description |
| :- | :- |
| [`portions`](/slides/python-net/id/aspose.slides/iparagraph/portions/) | Mengembalikan koleksi bagian teks.<br/>            Baca-saja [`IPortionCollection`](/slides/python-net/id/aspose.slides/iportioncollection). |
| [`paragraph_format`](/slides/python-net/id/aspose.slides/iparagraph/paragraph_format/) | Mengembalikan objek format untuk paragraf ini.<br/>            Baca-saja [`IParagraphFormat`](/slides/python-net/id/aspose.slides/iparagraphformat). |
| [`text`](/slides/python-net/id/aspose.slides/iparagraph/text/) | Mendapatkan atau mengatur teks polos paragraf.<br/>            Baca/tulis **str**. |
| [`end_paragraph_portion_format`](/slides/python-net/id/aspose.slides/iparagraph/end_paragraph_portion_format/) | Menentukan properti bagian yang akan digunakan jika bagian lain disisipkan setelah <br/>            yang terakhir. |
| [`slide`](/slides/python-net/id/aspose.slides/iparagraph/slide/) |  |
| [`presentation`](/slides/python-net/id/aspose.slides/iparagraph/presentation/) |  |

## Metode

| Method | Description |
