## BlackWhiteMode enumerasi

Menentukan bagaimana bentuk berwarna harus diubah menjadi hitam putih.

Tipe BlackWhiteMode menampilkan anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| NOT_DEFINED | Properti belum diatur |
| COLOR | Objek dirender dengan pewarnaan normal |
| AUTOMATIC | Objek dirender dengan pewarnaan otomatis |
| GRAY | Objek dirender dengan pewarnaan abu-abu |
| LIGHT_GRAY | Objek dirender dengan pewarnaan abu-abu terang |
| INVERSE_GRAY | Objek dirender dengan pewarnaan abu-abu terbalik |
| GRAY_WHITE | Objek dirender dengan pewarnaan abu-abu dan putih |
| BLACK_GRAY | Objek dirender dengan pewarnaan hitam dan abu-abu |
| BLACK_WHITE | Objek dirender dengan pewarnaan hitam dan putih |
| BLACK | Objek dirender hanya dengan pewarnaan hitam |
| WHITE | Objek dirender dengan pewarnaan putih |
| HIDDEN | Objek tidak dirender |
