## Kelas IColorFormat

Mewakili warna yang digunakan dalam presentasi.

Tipe IColorFormat mengekspos anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`color_type`](/slides/python-net/id/aspose.slides/icolorformat/color_type/) | Mengembalikan atau mengatur metode definisi warna.<br/>            Baca/tulis [`ColorType`](/slides/python-net/id/aspose.slides/colortype). |
| [`color`](/slides/python-net/id/aspose.slides/icolorformat/color/) | Mengembalikan warna hasil (dengan semua transformasi warna diterapkan).<br/>            Mengatur warna RGB dan menghapus semua transformasi warna.<br/>            Baca/tulis **aspose.slides.Color**. |
| [`preset_color`](/slides/python-net/id/aspose.slides/icolorformat/preset_color/) | Mengembalikan atau mengatur preset warna.<br/>            Baca/tulis [`PresetColor`](/slides/python-net/id/aspose.slides/presetcolor). |
| [`system_color`](/slides/python-net/id/aspose.slides/icolorformat/system_color/) | Mengembalikan atau mengatur warna yang diidentifikasi oleh tabel warna sistem.<br/>            Baca/tulis [`SystemColor`](/slides/python-net/id/aspose.slides/systemcolor). |
| [`scheme_color`](/slides/python-net/id/aspose.slides/icolorformat/scheme_color/) | Mengembalikan atau mengatur warna yang diidentifikasi oleh skema warna.<br/>            Baca/tulis [`SchemeColor`](/slides/python-net/id/aspose.slides/schemecolor). |
| [`r`](/slides/python-net/id/aspose.slides/icolorformat/r/) | Mengembalikan atau mengatur komponen merah dari sebuah warna. Semua transformasi warna diabaikan.<br/>            Baca/tulis **int**. |
| [`g`](/slides/python-net/id/aspose.slides/icolorformat/g/) | Mengembalikan atau mengatur komponen hijau dari sebuah warna. Semua transformasi warna diabaikan.<br/>            Baca/tulis **int**. |
| [`b`](/slides/python-net/id/aspose.slides/icolorformat/b/) | Mengembalikan atau mengatur komponen biru dari sebuah warna. Semua transformasi warna diabaikan.<br/>            Baca/tulis **int**. |
| [`float_r`](/slides/python-net/id/aspose.slides/icolorformat/float_r/) | Mengembalikan atau mengatur komponen merah dari sebuah warna. Semua transformasi warna diabaikan.<br/>            Baca/tulis **float**. |
| [`float_g`](/slides/python-net/id/aspose.slides/icolorformat/float_g/) | Mengembalikan atau mengatur komponen hijau dari sebuah warna. Semua transformasi warna diabaikan.<br/>            Baca/tulis **float**. |
| [`float_b`](/slides/python-net/id/aspose.slides/icolorformat/float_b/) | Mengembalikan atau mengatur komponen biru dari sebuah warna. Semua transformasi warna diabaikan.<br/>            Baca/tulis **float**. |
| [`hue`](/slides/python-net/id/aspose.slides/icolorformat/hue/) | Mengembalikan atau mengatur komponen hue dari sebuah warna dalam representasi HSL.<br/>            Semua transformasi warna diabaikan.<br/>            Baca/tulis **float**. |
| [`saturation`](/slides/python-net/id/aspose.slides/icolorformat/saturation/) | Mengembalikan atau mengatur komponen saturasi dari sebuah warna dalam representasi HSL.<br/>            Semua transformasi warna diabaikan.<br/>            Baca/tulis **float**. |
| [`luminance`](/slides/python-net/id/aspose.slides/icolorformat/luminance/) | Mengembalikan atau mengatur komponen luminansi dari sebuah warna dalam representasi HSL.<br/>            Semua transformasi warna diabaikan.<br/>            Baca/tulis **float**. |
| [`color_transform`](/slides/python-net/id/aspose.slides/icolorformat/color_transform/) | Mengembalikan koleksi transformasi warna yang diterapkan pada sebuah warna.<br/>            Baca-saja [`IColorOperationCollection`](/slides/python-net/id/aspose.slides/icoloroperationcollection). |
