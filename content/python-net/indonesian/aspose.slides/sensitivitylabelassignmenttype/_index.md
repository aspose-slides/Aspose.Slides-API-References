## SensitivityLabelAssignmentType enumerasi

Mewakili metode penugasan untuk label sensitivitas.

Tipe SensitivityLabelAssignmentType menampilkan anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| STANDARD | Gunakan untuk label sensitivitas apa pun yang tidak diterapkan secara langsung oleh pengguna. <br/>            Ini termasuk label default apa pun, label yang diterapkan secara otomatis. |
| PRIVILEGED | Gunakan untuk label sensitivitas apa pun yang diterapkan secara langsung oleh pengguna. <br/>            Ini termasuk label sensitivitas yang diterapkan secara manual serta label yang direkomendasikan<br/>            atau wajib, atau fitur apa pun di mana pengguna memutuskan label sensitivitas mana yang akan diterapkan. |
