## ISensitivityLabel kelas

Mewakili label sensitivitas dari Microsoft Purview Information Protection.

Tipe ISensitivityLabel menampilkan anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`id`](/slides/python-net/id/aspose.slides/isensitivitylabel/id/) | Mengembalikan atau mengatur id label sensitivitas.<br/>            Baca/tulis **str**. |
| [`site_id`](/slides/python-net/id/aspose.slides/isensitivitylabel/site_id/) | Mengembalikan atau mengatur pengidentifikasi situs Azure Active Directory (Azure AD) <br/>            yang sesuai dengan kebijakan label sensitivitas yang menjelaskan label sensitivitas.<br/>            Baca/tulis **System.Guid**. |
| [`is_enabled`](/slides/python-net/id/aspose.slides/isensitivitylabel/is_enabled/) | Menunjukkan apakah label sensitivitas diaktifkan. |
| [`is_removed`](/slides/python-net/id/aspose.slides/isensitivitylabel/is_removed/) | Menunjukkan apakah label sensitivitas telah dihapus. |
| [`assignment_method_type`](/slides/python-net/id/aspose.slides/isensitivitylabel/assignment_method_type/) | Mengembalikan atau mengatur metode penugasan untuk label sensitivitas.<br/>            Baca/tulis [`SensitivityLabelAssignmentType`](/slides/python-net/id/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/id/aspose.slides/isensitivitylabel/content_mark_types/) | Mengembalikan daftar tipe penandaan konten yang harus diterapkan pada file. |
