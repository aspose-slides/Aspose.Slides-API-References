## NumberedBulletStyle enumerasi

Mewakili gaya bullet bernomor.

Tipe NumberedBulletStyle menyediakan anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| NOT_DEFINED | Tidak didefinisikan. |
| BULLET_ALPHA_LC_PERIOD | Karakter alfabet huruf kecil dengan titik. Contoh: a., b., c., ... |
| BULLET_ALPHA_UC_PERIOD | Karakter alfabet huruf besar dengan titik. Contoh: A., B., C., ... |
| BULLET_ARABIC_PAREN_RIGHT | Nomor Arab dengan tanda kurung tutup. Contoh: 1), 2), 3), ... |
| BULLET_ARABIC_PERIOD | Nomor Arab dengan titik. Contoh: 1., 2., 3., ... |
| BULLET_ROMAN_LC_PAREN_BOTH | Nomor Romawi huruf kecil dengan kedua tanda kurung. Contoh: (i), (ii), (iii), ... |
| BULLET_ROMAN_LC_PAREN_RIGHT | Nomor Romawi huruf kecil dengan tanda kurung tutup. Contoh: i), ii), iii), ... |
| BULLET_ROMAN_LC_PERIOD | Nomor Romawi huruf kecil dengan titik. Contoh: i., ii., iii., ... |
| BULLET_ROMAN_UC_PERIOD | Nomor Romawi huruf besar dengan titik. Contoh: I., II., III., ... |
| BULLET_ALPHA_LC_PAREN_BOTH | Karakter alfabet huruf kecil dengan kedua tanda kurung. Contoh: (a), (b), (c), ... |
| BULLET_ALPHA_LC_PAREN_RIGHT | Karakter alfabet huruf kecil dengan tanda kurung tutup. Contoh: a), b), c), ... |
| BULLET_ALPHA_UC_PAREN_BOTH | Karakter alfabet huruf besar dengan kedua tanda kurung. Contoh: (A), (B), (C), ... |
| BULLET_ALPHA_UC_PAREN_RIGHT | Karakter alfabet huruf besar dengan tanda kurung tutup. Contoh: A), B), C), ... |
| BULLET_ARABIC_PAREN_BOTH | Nomor Arab dengan kedua tanda kurung. Contoh: (1), (2), (3), ... |
| BULLET_ARABIC_PLAIN | Nomor Arab. Contoh: 1, 2, 3, ... |
| BULLET_ROMAN_UC_PAREN_BOTH | Nomor Romawi huruf besar dengan kedua tanda kurung. Contoh: (I), (II), (III), ... |
| BULLET_ROMAN_UC_PAREN_RIGHT | Nomor Romawi huruf besar dengan tanda kurung tutup. Contoh: I), II), III), ... |
| BULLET_SIMP_CHIN_PLAIN | Bahasa Tionghoa Sederhana tanpa titik. |
| BULLET_SIMP_CHIN_PERIOD | Bahasa Tionghoa Sederhana dengan titik. |
| BULLET_CIRCLE_NUM_DB_PLAIN | Nomor bulat double-byte untuk nilai hingga 10, dari 11 - nomor Arab. |
| BULLET_CIRCLE_NUM_WD_WHITE_PLAIN | Nomor berwarna teks dengan lingkaran berwarna sama di sekitarnya (angka lingkaran putih Wingdings). Dari 11 - nomor Arab. |
| BULLET_CIRCLE_NUM_WD_BLACK_PLAIN | Nomor berwarna bayangan dengan latar belakang lingkaran berwarna teks normal (angka lingkaran hitam Wingdings). |
| BULLET_TRAD_CHIN_PLAIN | Bahasa Tionghoa Tradisional tanpa titik. |
| BULLET_TRAD_CHIN_PERIOD | Bahasa Tionghoa Tradisional dengan titik. |
| BULLET_ARABIC_ALPHA_DASH | Karakter alfabet bahasa Arab dengan tanda hubung. |
| BULLET_ARABIC_ABJAD_DASH | Abjad Arab dengan tanda hubung. |
| BULLET_HEBREW_ALPHA_DASH | Karakter alfabet bahasa Ibrani dengan tanda hubung. |
| BULLET_KANJI_KOREAN_PLAIN | Angka Jepang/Korea tanpa titik. |
| BULLET_KANJI_KOREAN_PERIOD | Angka Jepang/Korea dengan titik. |
| BULLET_ARABIC_DB_PLAIN | Skema penomoran Arab double-byte (tanpa tanda baca). |
| BULLET_ARABIC_DB_PERIOD | Skema penomoran Arab double-byte dengan titik double-byte. |
| BULLET_THAI_ALPHA_PERIOD | Alfabet Thai dengan titik. |
| BULLET_THAI_ALPHA_PAREN_RIGHT | Tanda kurung alfabet Thai - kanan. |
| BULLET_THAI_ALPHA_PAREN_BOTH | Tanda kurung alfabet Thai - keduanya. |
| BULLET_THAI_NUM_PERIOD | Angka Thai dengan titik. |
| BULLET_THAI_NUM_PAREN_RIGHT | Tanda kurung angka Thai - kanan. |
| BULLET_THAI_NUM_PAREN_BOTH | Tanda kurung angka Thai - keduanya. |
| BULLET_HINDI_ALPHA_PERIOD | Alfabet Hindi dengan titik - vokal. |
| BULLET_HINDI_NUM_PERIOD | Angka Hindi dengan titik. |
| BULLET_KANJI_SIMP_CHIN_DB_PERIOD | Kanji Bahasa Cina Sederhana DBPeriod. |
| BULLET_HINDI_NUM_PAREN_RIGHT | Tanda kurung angka Hindi - kanan. |
| BULLET_HINDI_ALPHA_1_PERIOD | Alfabet Hindi dengan titik - konsonan. |
