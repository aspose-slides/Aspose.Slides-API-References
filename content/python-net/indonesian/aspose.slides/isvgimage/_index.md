## ISvgImage kelas

Mewakili sebuah gambar SVG.

Tipe ISvgImage mengekspos anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`svg_content`](/slides/python-net/id/aspose.slides/isvgimage/svg_content/) | Mengembalikan konten SVG.<br/>            Baca-saja **str**. |
| [`svg_data`](/slides/python-net/id/aspose.slides/isvgimage/svg_data/) | Mengembalikan data SVG.<br/>            Baca-saja **int**[]. |
| [`external_resource_resolver`](/slides/python-net/id/aspose.slides/isvgimage/external_resource_resolver/) | Mengembalikan antarmuka callback yang digunakan untuk memecahkan sumber daya eksternal selama impor dokumen SVG.<br/>            Baca-saja **IExternalResourceResolver**. |
| [`base_uri`](/slides/python-net/id/aspose.slides/isvgimage/base_uri/) | Mengembalikan URI dasar SVG yang ditentukan. Digunakan untuk memecahkan tautan relatif.<br/>            Baca-saja **str**. |

## Metode

| Metode | Deskripsi |
| :- | :- |
| [`write_as_emf(self, stream)`](/slides/python-net/id/aspose.slides/isvgimage/write_as_emf/#iorawiobase) | Menyimpan gambar SVG sebagai file EMF. |
