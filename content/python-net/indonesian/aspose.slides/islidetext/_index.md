## ISlideText kelas

Mewakili teks yang diambil dari slide

Tipe ISlideText mengekspos anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`text`](/slides/python-net/id/aspose.slides/islidetext/text/) | Teks pada bentuk slide |
| [`master_text`](/slides/python-net/id/aspose.slides/islidetext/master_text/) | Teks pada bentuk halaman master untuk slide ini |
| [`layout_text`](/slides/python-net/id/aspose.slides/islidetext/layout_text/) | Teks pada bentuk halaman tata letak untuk slide ini |
| [`notes_text`](/slides/python-net/id/aspose.slides/islidetext/notes_text/) | Teks pada bentuk halaman catatan untuk slide ini |
| [`comments_text`](/slides/python-net/id/aspose.slides/islidetext/comments_text/) | Teks komentar slide |
