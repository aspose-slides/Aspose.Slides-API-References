## PathCommandType enumerasi

Mewakili perintah jalur grafik

Tipe PathCommandType mengekspos anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| CLOSE | Menutup jalur geometri |
| MOVE_TO | Menetapkan posisi titik berikutnya dari jalur geometri |
| LINE_TO | Menambahkan garis ke jalur geometri |
| ARC_TO | Menambahkan busur yang ditentukan ke jalur geometri. |
| QUAD_BEZIER_TO | Menambahkan kurva Bezier kuadratik ke jalur geometri |
| CUBIC_BEZIER_TO | Menambahkan kurva Bezier kubik ke jalur geometri |
