## SourceFormat enumerasi

Mewakili format file sumber.

Tipe SourceFormat menampilkan anggota berikut:

## Bidang

| Field | Deskripsi |
| :- | :- |
| PPT | Microsoft PowerPoint 97-2003 Presentasi (*.ppt). |
| PPTX | Microsoft Office Open XML Presentasi (*.pptx). |
| ODP | OpenDocument Presentasi (*.odp). |
| PPTM | Microsoft Office Open XML Presentasi dengan Makro (*.pptm). |
| PPSX | Microsoft Office Open XML Pertunjukan Slide (*.ppsx). |
| PPSM | Microsoft Office Open XML Pertunjukan Slide dengan Makro (*.ppsm). |
| POTX | Microsoft Office Open XML Templat (*.potx). |
| POTM | Microsoft Office Open XML Templat dengan Makro (*.potm). |
| PPS | Microsoft PowerPoint 97-2003 Pertunjukan Slide (*.pps). |
| POT | Microsoft PowerPoint 97-2003 Templat (*.pot). |
| OTP | OpenDocument Presentasi Templat (*.otp). |
| FODP | Flat XML ODF Presentasi (*.fodp). |
| XML | PowerPoint XML Presentasi (*.xml). |
