## TextAlignment enumerasi

Mewakili berbagai gaya perataan teks.

Tipe TextAlignment menampilkan anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| NOT_DEFINED | Penjajaran default. |
| LEFT | Penjajaran kiri. |
| CENTER | Penjajaran tengah. |
| RIGHT | Penjajaran kanan. |
| JUSTIFY | Penjajaran rata. |
| JUSTIFY_LOW | Kashida rata rendah. |
| DISTRIBUTED | Penjajaran tersebar. |
