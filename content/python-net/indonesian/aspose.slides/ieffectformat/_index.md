## IEffectFormat kelas

Mewakili properti efek dari bentuk.

Tipe IEffectFormat menampilkan anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`is_no_effects`](/slides/python-net/id/aspose.slides/ieffectformat/is_no_effects/) | Mengembalikan true jika semua efek dinonaktifkan (seperti baru dibuat, objek EffectFormat default).<br/>            Hanya-baca **bool**. |
| [`blur_effect`](/slides/python-net/id/aspose.slides/ieffectformat/blur_effect/) | Efek blur.<br/>            Baca/tulis [`IBlur`](/slides/python-net/id/aspose.slides.effects/iblur). |
| [`fill_overlay_effect`](/slides/python-net/id/aspose.slides/ieffectformat/fill_overlay_effect/) | Efek overlay isi.<br/>            Baca/tulis [`IFillOverlay`](/slides/python-net/id/aspose.slides.effects/ifilloverlay). |
| [`glow_effect`](/slides/python-net/id/aspose.slides/ieffectformat/glow_effect/) | Efek glow.<br/>            Baca/tulis [`IGlow`](/slides/python-net/id/aspose.slides.effects/iglow). |
| [`inner_shadow_effect`](/slides/python-net/id/aspose.slides/ieffectformat/inner_shadow_effect/) | Bayangan dalam.<br/>            Baca/tulis [`IInnerShadow`](/slides/python-net/id/aspose.slides.effects/iinnershadow). |
| [`outer_shadow_effect`](/slides/python-net/id/aspose.slides/ieffectformat/outer_shadow_effect/) | Bayangan luar.<br/>            Baca/tulis [`IOuterShadow`](/slides/python-net/id/aspose.slides.effects/ioutershadow). |
| [`preset_shadow_effect`](/slides/python-net/id/aspose.slides/ieffectformat/preset_shadow_effect/) | Bayangan preset.<br/>            Baca/tulis [`IPresetShadow`](/slides/python-net/id/aspose.slides.effects/ipresetshadow). |
| [`reflection_effect`](/slides/python-net/id/aspose.slides/ieffectformat/reflection_effect/) | Refleksi.<br/>            Baca/tulis [`IReflection`](/slides/python-net/id/aspose.slides.effects/ireflection). |
| [`soft_edge_effect`](/slides/python-net/id/aspose.slides/ieffectformat/soft_edge_effect/) | Tepi lembut.<br/>            Baca/tulis [`ISoftEdge`](/slides/python-net/id/aspose.slides.effects/isoftedge). |
