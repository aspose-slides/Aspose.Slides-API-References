## INormalViewProperties kelas

Mewakili properti tampilan normal. Tampilan normal terdiri dari tiga wilayah konten: slide itu sendiri, wilayah konten samping, dan wilayah konten bawah.

Tipe INormalViewProperties mengekspos anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`show_outline_icons`](/slides/python-net/id/aspose.slides/inormalviewproperties/show_outline_icons/) | Menentukan apakah aplikasi harus menampilkan ikon jika menampilkan konten garis besar di salah satu wilayah konten mode tampilan normal. Baca/tulis **bool**. |
| [`snap_vertical_splitter`](/slides/python-net/id/aspose.slides/inormalviewproperties/snap_vertical_splitter/) | Menentukan apakah pemisah vertikal harus menempel pada keadaan diminimalkan ketika wilayah samping cukup kecil. Baca/tulis **bool**. |
| [`vertical_bar_state`](/slides/python-net/id/aspose.slides/inormalviewproperties/vertical_bar_state/) | Menentukan keadaan yang harus ditampilkan pada bilah pemisah vertikal. Bilah pemisah vertikal memisahkan slide dari wilayah konten samping. |
| [`horizontal_bar_state`](/slides/python-net/id/aspose.slides/inormalviewproperties/horizontal_bar_state/) | Menentukan keadaan yang harus ditampilkan pada bilah pemisah horizontal. Bilah pemisah horizontal memisahkan slide dari wilayah konten di bawah slide. |
| [`prefer_single_view`](/slides/python-net/id/aspose.slides/inormalviewproperties/prefer_single_view/) | Menentukan apakah pengguna lebih memilih melihat satu wilayah konten penuh-jendela dibandingkan tampilan normal standar dengan tiga wilayah konten. Jika diaktifkan, aplikasi dapat memilih untuk menampilkan salah satu wilayah konten di seluruh jendela. Baca/tulis **bool**. |
| [`restored_left`](/slides/python-net/id/aspose.slides/inormalviewproperties/restored_left/) | Elemen ini menentukan ukuran wilayah konten samping pada tampilan normal, ketika wilayah tersebut memiliki ukuran pulih yang variabel (tidak diminimalkan maupun dimaksimalkan). Baca saja [`INormalViewRestoredProperties`](/slides/python-net/id/aspose.slides/inormalviewrestoredproperties). |
| [`restored_top`](/slides/python-net/id/aspose.slides/inormalviewproperties/restored_top/) | Elemen ini menentukan ukuran wilayah slide atas pada tampilan normal, ketika wilayah tersebut memiliki ukuran pulih yang variabel (tidak diminimalkan maupun dimaksimalkan). Baca saja [`INormalViewRestoredProperties`](/slides/python-net/id/aspose.slides/inormalviewrestoredproperties). |
