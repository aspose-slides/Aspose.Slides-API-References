## IImage kelas

Mewakili gambar raster atau vektor.

Tipe IImage mengekspos anggota-anggota berikut:

## Properti

| Property | Description |
| :- | :- |
| [`size`](/slides/python-net/id/aspose.slides/iimage/size/) | Mendapatkan ukuran gambar. |
| [`width`](/slides/python-net/id/aspose.slides/iimage/width/) | Mendapatkan lebar gambar dalam piksel. |
| [`height`](/slides/python-net/id/aspose.slides/iimage/height/) | Mendapatkan tinggi gambar dalam piksel. |

## Metode

| Method | Description |
| :- | :- |
| [`save(self, filename)`](/slides/python-net/id/aspose.slides/iimage/save/#str) | Menyimpan gambar ke file. |
| [`save(self, filename, format)`](/slides/python-net/id/aspose.slides/iimage/save/#str-imageformat) | Menyimpan gambar ke file dalam format yang ditentukan. |
| [`save(self, stream, format)`](/slides/python-net/id/aspose.slides/iimage/save/#iorawiobase-imageformat) | Menyimpan gambar ke aliran dalam format yang ditentukan. |
| [`save(self, filename, format, quality)`](/slides/python-net/id/aspose.slides/iimage/save/#str-imageformat-int) | Menyimpan gambar ke file dalam format dan kualitas yang ditentukan. |
| [`save(self, stream, format, quality)`](/slides/python-net/id/aspose.slides/iimage/save/#iorawiobase-imageformat-int) | Menyimpan gambar ke aliran dalam format dan kualitas yang ditentukan. |


### Catatan

Antarmuka ini menyediakan abstraksi umum untuk menangani gambar raster dan vektor.  
Implementasi dapat bervariasi tergantung pada tipe gambar yang mendasarinya.
