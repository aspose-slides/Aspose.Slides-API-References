## TextSearchOptions kelas

Mewakili opsi yang dapat digunakan untuk mencari teks dalam Presentation, Slide, atau TextFrame.

Tipe TextSearchOptions mengekspos anggota berikut:

## Konstruktor

| Konstruktor | Deskripsi |
| :- | :- |
| [`__init__(self)`](/slides/python-net/id/aspose.slides/textsearchoptions/__init__/#) | Membuat opsi pencarian teks default baru. |

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`case_sensitive`](/slides/python-net/id/aspose.slides/textsearchoptions/case_sensitive/) | Atur true untuk menggunakan pencarian yang peka huruf besar/kecil, false - lainnya.<br/>            Baca/tulis **bool**. |
| [`whole_words_only`](/slides/python-net/id/aspose.slides/textsearchoptions/whole_words_only/) | Atur true untuk mencocokkan hanya kata utuh, false - lainnya.<br/>            Baca/tulis **bool**. |
| [`include_notes`](/slides/python-net/id/aspose.slides/textsearchoptions/include_notes/) | Atur `true` untuk menyertakan teks yang terdapat dalam catatan slide ([`NotesSlide`](/slides/python-net/id/aspose.slides/notesslide)) <br/>            saat melakukan pencarian teks, penggantian, atau operasi menyorot.<br/>            Nilai default adalah `false`. |
