## GraphicalObjectLock kelas

Menentukan operasi mana yang dinonaktifkan pada GraphicalObject induk.

**Pewarisan:**[`GraphicalObjectLock`](/slides/python-net/id/aspose.slides/graphicalobjectlock) → [`BaseShapeLock`](/slides/python-net/id/aspose.slides/baseshapelock)

Tipe GraphicalObjectLock mengekspos anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`no_locks`](/slides/python-net/id/aspose.slides/graphicalobjectlock/no_locks/) | Kembalikan true jika semua lock-flags dinonaktifkan.<br/>            Hanya-baca **bool**. |
| [`grouping_locked`](/slides/python-net/id/aspose.slides/graphicalobjectlock/grouping_locked/) | Menentukan apakah menambahkan shape ini ke grup dilarang.<br/>            Baca/tulis **bool**. |
| [`drilldown_locked`](/slides/python-net/id/aspose.slides/graphicalobjectlock/drilldown_locked/) | Menentukan apakah memilih subshape dari objek ini dilarang.<br/>            Baca/tulis **bool**. |
| [`select_locked`](/slides/python-net/id/aspose.slides/graphicalobjectlock/select_locked/) | Menentukan apakah memilih shape ini dilarang.<br/>            Baca/tulis **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/id/aspose.slides/graphicalobjectlock/aspect_ratio_locked/) | Menentukan apakah shape harus mempertahankan rasio aspek saat diubah ukuran.<br/>            Baca/tulis **bool**. |
| [`position_locked`](/slides/python-net/id/aspose.slides/graphicalobjectlock/position_locked/) | Menentukan apakah memindahkan shape ini dilarang.<br/>            Baca/tulis **bool**. |
| [`size_locked`](/slides/python-net/id/aspose.slides/graphicalobjectlock/size_locked/) | Menentukan apakah mengubah ukuran shape ini dilarang.<br/>            Baca/tulis **bool**. |
