## Enumerasi TextVerticalType

Menentukan mode penulisan vertikal untuk sebuah teks.

Tipe TextVerticalType menyediakan anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| NOT_DEFINED | Tidak didefinisikan. |
| HORIZONTAL | Teks horizontal. |
| VERTICAL | Teks vertikal. |
| VERTICAL270 | Teks vertikal 270 derajat. |
| WORD_ART_VERTICAL | Teks vertikal WordArt. |
| EAST_ASIAN_VERTICAL | Teks vertikal Asia timur. |
| MONGOLIAN_VERTICAL | Teks vertikal Mongolia. |
| WORD_ART_VERTICAL_RIGHT_TO_LEFT | Teks vertikal WordArt kanan ke kiri. |
