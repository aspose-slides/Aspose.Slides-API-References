## ViewProperties kelas

Properti tampilan pada tingkat presentasi.

Tipe ViewProperties mengekspos anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`last_view`](/slides/python-net/id/aspose.slides/viewproperties/last_view/) | Menentukan mode tampilan yang digunakan saat dokumen presentasi terakhir disimpan.<br/>            Baca/tulis [`ViewType`](/slides/python-net/id/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/id/aspose.slides/viewproperties/show_comments/) | Menentukan apakah komentar slide harus ditampilkan.<br/>            Baca/tulis [`NullableBool`](/slides/python-net/id/aspose.slides/nullablebool). |
| [`normal_view_properties`](/slides/python-net/id/aspose.slides/viewproperties/normal_view_properties/) | Mewakili properti tampilan normal. Tampilan normal terdiri dari<br/>            tiga wilayah konten: slide itu sendiri, wilayah konten samping, dan wilayah konten bawah.<br/>            Baca-saja [`INormalViewProperties`](/slides/python-net/id/aspose.slides/inormalviewproperties). |
| [`slide_view_properties`](/slides/python-net/id/aspose.slides/viewproperties/slide_view_properties/) | Menentukan properti tampilan umum yang terkait dengan mode tampilan slide.<br/>            Baca-saja [`ICommonSlideViewProperties`](/slides/python-net/id/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/id/aspose.slides/viewproperties/notes_view_properties/) | Menentukan properti tampilan umum yang terkait dengan mode tampilan catatan.<br/>            Baca-saja [`ICommonSlideViewProperties`](/slides/python-net/id/aspose.slides/icommonslideviewproperties). |
| [`grid_spacing`](/slides/python-net/id/aspose.slides/viewproperties/grid_spacing/) | Mengembalikan atau mengatur jarak grid yang harus digunakan untuk grid yang mendasari dokumen presentasi, dalam poin. <br/>            Baca/tulis **float**. |
