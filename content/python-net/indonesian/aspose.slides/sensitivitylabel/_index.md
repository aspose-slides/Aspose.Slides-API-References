## SensitivityLabel kelas

Mewakili sensitivity label dari Microsoft Purview Information Protection.

Tipe SensitivityLabel mengekspos anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`id`](/slides/python-net/id/aspose.slides/sensitivitylabel/id/) | Mengembalikan atau mengatur id sensitivity label.<br/>            Read/write **str**. |
| [`site_id`](/slides/python-net/id/aspose.slides/sensitivitylabel/site_id/) | Mengembalikan atau mengatur pengidentifikasi situs Azure Active Directory (Azure AD) <br/>            yang sesuai dengan kebijakan sensitivity label yang menjelaskan sensitivity label.<br/>            Read/write **System.Guid**. |
| [`is_enabled`](/slides/python-net/id/aspose.slides/sensitivitylabel/is_enabled/) | Menunjukkan apakah sensitivity label diaktifkan. |
| [`is_removed`](/slides/python-net/id/aspose.slides/sensitivitylabel/is_removed/) | Menunjukkan apakah sensitivity label telah dihapus. |
| [`assignment_method_type`](/slides/python-net/id/aspose.slides/sensitivitylabel/assignment_method_type/) | Mengembalikan atau mengatur metode penugasan untuk sensitivity label.<br/>            Read/write [`SensitivityLabelAssignmentType`](/slides/python-net/id/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/id/aspose.slides/sensitivitylabel/content_mark_types/) | Mengembalikan daftar tipe penandaan konten yang seharusnya diterapkan pada sebuah berkas. |
