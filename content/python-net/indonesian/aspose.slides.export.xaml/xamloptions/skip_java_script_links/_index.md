## properti skip_java_script_links
Menentukan apakah akan melewatkan tautan dengan panggilan JavaScript saat menyimpan presentasi. 
            Baca/tulis **bool**. Nilai default adalah **false** .


### Catatan

Saat properti ini diatur ke **true** , tautan dengan panggilan JavaScript akan diabaikan saat menyimpan.


Saat properti ini diatur ke **false** , semua tautan akan disimpan.
