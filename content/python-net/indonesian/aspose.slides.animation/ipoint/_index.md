## IPoint kelas

Mewakili titik animasi.

Tipe IPoint mengekspos anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`time`](/slides/python-net/id/aspose.slides.animation/ipoint/time/) | Mewakili nilai waktu.<br/>            Baca/tulis **float**. |
| [`value`](/slides/python-net/id/aspose.slides.animation/ipoint/value/) | Mewakili nilai titik.<br/>            Hanya: bool, ColorFormat, float, int, string.<br/>            Baca/tulis **any**. |
| [`formula`](/slides/python-net/id/aspose.slides.animation/ipoint/formula/) | Formula dalam nilai, atribut from, to, by dapat terdiri dari hal-hal berikut:<br/>            Operator aritmetika standar: ‘+’, ‘-‘, ‘*’, ‘/’, ‘^’, ‘%’ (mod)<br/>            Konstanta: ‘pi’ ‘e’<br/>            Operator bersyarat: ‘abs’, ‘min’, ‘max’, ‘?’ (if)<br/>            Operator perbandingan: '==', '>=', '', '!=', '!'<br/>            Operator trigonometri: ‘sin()’, ‘cos()’, ‘tan()’, ‘asin()’, ‘acos()’, ‘atan()’<br/>            Logaritma natural ‘ln()’<br/>            Referensi properti (properti yang didukung host)<br/>            <br/>            misalnya: "#ppt_x+(cos(-2*pi*(1-$))*-#ppt_x-sin(-2*pi*(1-$))*(1-#ppt_y))*(1-$)"<br/>            Baca/tulis **str**. |
