## Kelas Behavior

Mewakili perilaku kelas dasar dari efek.

Tipe Behavior menampilkan anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`accumulate`](/slides/python-net/id/aspose.slides.animation/behavior/accumulate/) | Menyatakan apakah perilaku animasi diakumulasi.<br/>            Baca/tulis [`NullableBool`](/slides/python-net/id/aspose.slides/nullablebool). |
| [`additive`](/slides/python-net/id/aspose.slides.animation/behavior/additive/) | Menyatakan apakah perilaku animasi saat ini digabungkan dengan animasi lain yang sedang berjalan.<br/>            Baca/tulis [`BehaviorAdditiveType`](/slides/python-net/id/aspose.slides.animation/behavioradditivetype). |
| [`properties`](/slides/python-net/id/aspose.slides.animation/behavior/properties/) | Menyatakan properti perilaku.<br/>            Baca-saja [`IBehaviorPropertyCollection`](/slides/python-net/id/aspose.slides.animation/ibehaviorpropertycollection). |
| [`timing`](/slides/python-net/id/aspose.slides.animation/behavior/timing/) | Menyatakan properti timing untuk perilaku efek.<br/>            Baca/tulis [`ITiming`](/slides/python-net/id/aspose.slides.animation/itiming). |
