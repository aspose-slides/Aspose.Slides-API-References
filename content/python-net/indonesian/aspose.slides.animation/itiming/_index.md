## ITiming kelas

Mewakili timing animasi.

Tipe ITiming mengekspos anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`accelerate`](/slides/python-net/id/aspose.slides.animation/itiming/accelerate/) | Menjelaskan persentase efek perilaku percepatan durasi.<br/>            Baca/tulis **float**. |
| [`decelerate`](/slides/python-net/id/aspose.slides.animation/itiming/decelerate/) | Menjelaskan persentase efek perilaku perlambatan durasi.<br/>            Baca/tulis **float**. |
| [`auto_reverse`](/slides/python-net/id/aspose.slides.animation/itiming/auto_reverse/) | Menjelaskan apakah animasi akan diputar secara otomatis mundur setelah<br/>            diputar dalam arah maju.<br/>            Baca/tulis **bool**. |
| [`duration`](/slides/python-net/id/aspose.slides.animation/itiming/duration/) | Menjelaskan durasi efek animasi.<br/>            Baca/tulis **float**. |
| [`repeat_count`](/slides/python-net/id/aspose.slides.animation/itiming/repeat_count/) | Menjelaskan jumlah kali efek harus diulang.<br/>            Baca/tulis **float**. |
| [`repeat_until_end_slide`](/slides/python-net/id/aspose.slides.animation/itiming/repeat_until_end_slide/) | Atribut ini menentukan apakah efek akan berulang hingga akhir slide.<br/>             Baca/tulis **bool**. |
| [`repeat_until_next_click`](/slides/python-net/id/aspose.slides.animation/itiming/repeat_until_next_click/) | Atribut ini menentukan apakah efek akan berulang hingga klik berikutnya.<br/>             Baca/tulis **bool**. |
| [`repeat_duration`](/slides/python-net/id/aspose.slides.animation/itiming/repeat_duration/) | Menjelaskan jumlah kali efek harus diulang.<br/>            Baca/tulis **float**. |
| [`restart`](/slides/python-net/id/aspose.slides.animation/itiming/restart/) | Menentukan apakah efek akan dimulai kembali setelah selesai.<br/>            Baca/tulis [`EffectRestartType`](/slides/python-net/id/aspose.slides.animation/effectrestarttype). |
| [`speed`](/slides/python-net/id/aspose.slides.animation/itiming/speed/) | Menentukan persentase percepatan (atau perlambatan) waktu.<br/>            Baca/tulis **float**. |
| [`trigger_delay_time`](/slides/python-net/id/aspose.slides.animation/itiming/trigger_delay_time/) | Menjelaskan waktu tunda setelah pemicu.<br/>            Baca/tulis **float**. |
| [`trigger_type`](/slides/python-net/id/aspose.slides.animation/itiming/trigger_type/) | Menjelaskan tipe pemicu.<br/>            Baca/tulis [`EffectTriggerType`](/slides/python-net/id/aspose.slides.animation/effecttriggertype). |
| [`rewind`](/slides/python-net/id/aspose.slides.animation/itiming/rewind/) | Atribut ini menentukan apakah efek akan diputar kembali setelah selesai diputar.<br/>             Baca/tulis **bool**. |
