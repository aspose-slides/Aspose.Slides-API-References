## Kelas Effect

Mewakili efek animasi.

Tipe Effect menampilkan anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`sequence`](/slides/python-net/id/aspose.slides.animation/effect/sequence/) | Mengembalikan urutan untuk sebuah efek.<br/>            Hanya-baca [`ISequence`](/slides/python-net/id/aspose.slides.animation/isequence). |
| [`text_animation`](/slides/python-net/id/aspose.slides.animation/effect/text_animation/) | TextAnimation<br/>            Hanya-baca [`ITextAnimation`](/slides/python-net/id/aspose.slides.animation/itextanimation). |
| [`preset_class_type`](/slides/python-net/id/aspose.slides.animation/effect/preset_class_type/) | Mendefinisikan kelas efek.<br/>            Baca/tulis [`EffectPresetClassType`](/slides/python-net/id/aspose.slides.animation/effectpresetclasstype). |
| [`type`](/slides/python-net/id/aspose.slides.animation/effect/type/) | Mendefinisikan tipe efek.<br/>            Baca/tulis [`EffectType`](/slides/python-net/id/aspose.slides.animation/effecttype). |
| [`subtype`](/slides/python-net/id/aspose.slides.animation/effect/subtype/) | Mendefinisikan subtipe efek.<br/>            Baca/tulis [`EffectSubtype`](/slides/python-net/id/aspose.slides.animation/effectsubtype). |
| [`behaviors`](/slides/python-net/id/aspose.slides.animation/effect/behaviors/) | Mengembalikan koleksi perilaku untuk efek.<br/>            Baca/tulis [`IBehaviorCollection`](/slides/python-net/id/aspose.slides.animation/ibehaviorcollection). |
| [`timing`](/slides/python-net/id/aspose.slides.animation/effect/timing/) | Mendefinisikan nilai timing untuk efek.<br/>            Baca/tulis [`ITiming`](/slides/python-net/id/aspose.slides.animation/itiming). |
| [`target_shape`](/slides/python-net/id/aspose.slides.animation/effect/target_shape/) | Mengembalikan bentuk target untuk efek.<br/>            Hanya-baca [`IShape`](/slides/python-net/id/aspose.slides/ishape). |
| [`sound`](/slides/python-net/id/aspose.slides.animation/effect/sound/) | Mendefinisikan suara tertanam untuk efek.<br/>            Baca/tulis [`IAudio`](/slides/python-net/id/aspose.slides/iaudio). |
| [`stop_previous_sound`](/slides/python-net/id/aspose.slides.animation/effect/stop_previous_sound/) | Atribut ini menentukan apakah efek animasi menghentikan suara sebelumnya.<br/>            Baca/tulis **bool**. |
| [`after_animation_type`](/slides/python-net/id/aspose.slides.animation/effect/after_animation_type/) | Mendefinisikan tipe animasi setelah untuk efek.<br/>            Baca/tulis [`Effect.after_animation_type`](/slides/python-net/id/aspose.slides.animation/effect/after_animation_type). |
| [`after_animation_color`](/slides/python-net/id/aspose.slides.animation/effect/after_animation_color/) | Mendefinisikan warna animasi setelah untuk efek.<br/>            Baca/tulis [`IColorFormat`](/slides/python-net/id/aspose.slides/icolorformat). |
| [`animate_text_type`](/slides/python-net/id/aspose.slides.animation/effect/animate_text_type/) | Mendefinisikan tipe teks animasi untuk efek. <br/>            Teks bentuk dapat dianimasikan per huruf, per kata atau sekaligus.<br/>            Baca/tulis [`Effect.animate_text_type`](/slides/python-net/id/aspose.slides.animation/effect/animate_text_type). |
| [`delay_between_text_parts`](/slides/python-net/id/aspose.slides.animation/effect/delay_between_text_parts/) | Mendefinisikan jeda antara bagian teks yang dianimasikan (kata atau huruf).<br/>            Nilai positif menentukan persentase durasi efek.<br/>            Nilai negatif menentukan jeda dalam detik.<br/>            Baca/tulis **float**. |
