## BuildType enumerasi

Menentukan bagaimana teks akan muncul pada shape selama animasi.

Tipe BuildType mengekspos anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| AS_ONE_OBJECT | Dengan shape yang mengandung. |
| ALL_PARAGRAPHS_AT_ONCE | Semua paragraf. |
| BY_LEVEL_PARAGRAPHS1 | Menurut grup paragraf dengan kedalaman 1. |
| BY_LEVEL_PARAGRAPHS2 | Menurut grup paragraf dengan kedalaman 2. |
| BY_LEVEL_PARAGRAPHS3 | Menurut grup paragraf dengan kedalaman 3. |
| BY_LEVEL_PARAGRAPHS4 | Menurut grup paragraf dengan kedalaman 4. |
| BY_LEVEL_PARAGRAPHS5 | Menurut grup paragraf dengan kedalaman 5. |
