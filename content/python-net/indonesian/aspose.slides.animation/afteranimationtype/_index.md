## AfterAnimationType enumerasi

Mewakili tipe after animation dari sebuah efek animasi.

Tipe AfterAnimationType menampilkan anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| DO_NOT_DIM | Jangan redup setelah tipe animasi. |
| COLOR | Warna setelah tipe animasi. |
| HIDE_AFTER_ANIMATION | Sembunyikan tipe After Animation |
| HIDE_ON_NEXT_MOUSE_CLICK | Sembunyikan pada Klik Mouse Berikutnya setelah tipe animasi. |
