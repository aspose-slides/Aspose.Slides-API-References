## Timing kelas

Mewakili waktu animasi.

Tipe Timing mengungkapkan anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`accelerate`](/slides/python-net/id/aspose.slides.animation/timing/accelerate/) | Menjelaskan persentase durasi efek percepatan.<br/>            Baca/tulis **float**. |
| [`decelerate`](/slides/python-net/id/aspose.slides.animation/timing/decelerate/) | Menjelaskan persentase durasi efek perlambatan.<br/>            Baca/tulis **float**. |
| [`auto_reverse`](/slides/python-net/id/aspose.slides.animation/timing/auto_reverse/) | Menjelaskan apakah animasi akan diputar otomatis secara terbalik setelah<br/>            diputar maju.<br/>            Baca/tulis **bool**. |
| [`duration`](/slides/python-net/id/aspose.slides.animation/timing/duration/) | Menjelaskan durasi efek animasi.<br/>            Baca/tulis **float**. |
| [`repeat_count`](/slides/python-net/id/aspose.slides.animation/timing/repeat_count/) | Menjelaskan jumlah kali efek harus diulang.<br/>            Baca/tulis **float**. |
| [`repeat_until_end_slide`](/slides/python-net/id/aspose.slides.animation/timing/repeat_until_end_slide/) | Atribut ini menentukan apakah efek akan diulang sampai akhir slide.<br/>             Baca/tulis **bool**. |
| [`repeat_until_next_click`](/slides/python-net/id/aspose.slides.animation/timing/repeat_until_next_click/) | Atribut ini menentukan apakah efek akan diulang sampai klik berikutnya.<br/>             Baca/tulis **bool**. |
| [`repeat_duration`](/slides/python-net/id/aspose.slides.animation/timing/repeat_duration/) | Menjelaskan jumlah kali efek harus diulang.<br/>            Baca/tulis **float**. |
| [`restart`](/slides/python-net/id/aspose.slides.animation/timing/restart/) | Menentukan apakah efek harus dimulai ulang setelah selesai.<br/>            Baca/tulis [`EffectRestartType`](/slides/python-net/id/aspose.slides.animation/effectrestarttype). |
| [`rewind`](/slides/python-net/id/aspose.slides.animation/timing/rewind/) | Atribut ini menentukan apakah efek akan diputar kembali setelah selesai diputar.<br/>             Baca/tulis **bool**. |
| [`speed`](/slides/python-net/id/aspose.slides.animation/timing/speed/) | Menentukan persentase percepatan (atau perlambatan) waktu.<br/>            Baca/tulis **float**. |
| [`trigger_delay_time`](/slides/python-net/id/aspose.slides.animation/timing/trigger_delay_time/) | Menjelaskan waktu tunggu setelah pemicu.<br/>            Baca/tulis **float**. |
| [`trigger_type`](/slides/python-net/id/aspose.slides.animation/timing/trigger_type/) | Menjelaskan tipe pemicu.<br/>            Baca/tulis [`EffectTriggerType`](/slides/python-net/id/aspose.slides.animation/effecttriggertype). |
