## AnimateTextType enumerasi

Mewakili tipe teks animasi dari efek animasi.

Tipe AnimateTextType menyajikan anggota-anggota berikut:

## Bidang

| Field | Deskripsi |
| :- | :- |
| ALL_AT_ONCE | Animasi semua teks sekaligus. |
| BY_WORD | Animasi teks per kata. |
| BY_LETTER | Animasi teks per huruf. |
