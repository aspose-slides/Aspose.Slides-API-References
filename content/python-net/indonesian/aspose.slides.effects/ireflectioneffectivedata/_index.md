## IReflectionEffectiveData kelas

Objek tidak dapat diubah yang mewakili efek Refleksi.

Tipe IReflectionEffectiveData menampilkan anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/id/aspose.slides.effects/ireflectioneffectivedata/start_pos_alpha/) | Menentukan posisi awal (sepanjang lereng gradien alfa) dari nilai alfa awal (persen).<br/>            Hanya-baca **float**. |
| [`end_pos_alpha`](/slides/python-net/id/aspose.slides.effects/ireflectioneffectivedata/end_pos_alpha/) | Menentukan posisi akhir (sepanjang lereng gradien alfa) dari nilai alfa akhir (persen).<br/>            Hanya-baca **float**. |
| [`fade_direction`](/slides/python-net/id/aspose.slides.effects/ireflectioneffectivedata/fade_direction/) | Menentukan arah offset refleksi. (sudut).<br/>            Hanya-baca **float**. |
| [`start_reflection_opacity`](/slides/python-net/id/aspose.slides.effects/ireflectioneffectivedata/start_reflection_opacity/) | Opasitas refleksi awal. (persen).<br/>            Hanya-baca **float**. |
| [`end_reflection_opacity`](/slides/python-net/id/aspose.slides.effects/ireflectioneffectivedata/end_reflection_opacity/) | Opasitas refleksi akhir. (persen).<br/>            Hanya-baca **float**. |
| [`blur_radius`](/slides/python-net/id/aspose.slides.effects/ireflectioneffectivedata/blur_radius/) | Radius blur.<br/>            Hanya-baca **float**. |
