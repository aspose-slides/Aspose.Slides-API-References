## IOuterShadow kelas

Mewakili efek Outer Shadow.

Tipe IOuterShadow menampilkan anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`blur_radius`](/slides/python-net/id/aspose.slides.effects/ioutershadow/blur_radius/) | Radius blur, dalam poin.<br/>            Nilai default – 0 pt.<br/>            Baca/tulis **float**. |
| [`direction`](/slides/python-net/id/aspose.slides.effects/ioutershadow/direction/) | Arah bayangan, dalam derajat.<br/>            Nilai default – 0 ° (kiri-ke-kanan).<br/>            Baca/tulis **float**. |
| [`distance`](/slides/python-net/id/aspose.slides.effects/ioutershadow/distance/) | Jarak bayangan dari objek, dalam poin.<br/>            Nilai default – 0 pt.<br/>            Baca/tulis **float**. |
| [`shadow_color`](/slides/python-net/id/aspose.slides.effects/ioutershadow/shadow_color/) | Warna bayangan.<br/>            Nilai default – hitam otomatis (tergantung tema).<br/>            Baca-saja [`IColorFormat`](/slides/python-net/id/aspose.slides/icolorformat). |
| [`rectangle_align`](/slides/python-net/id/aspose.slides.effects/ioutershadow/rectangle_align/) | Penjajaran persegi panjang.<br/>            Nilai default – [`RectangleAlignment.BOTTOM`](/slides/python-net/id/aspose.slides/rectanglealignment/BOTTOM). <br/>            Baca/tulis [`RectangleAlignment`](/slides/python-net/id/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/id/aspose.slides.effects/ioutershadow/skew_horizontal/) | Sudut skew horizontal, dalam derajat.<br/>            Nilai default – 0 °.<br/>            Baca/tulis **float**. |
| [`skew_vertical`](/slides/python-net/id/aspose.slides.effects/ioutershadow/skew_vertical/) | Sudut skew vertikal, dalam derajat.<br/>            Nilai default – 0 °.<br/>            Baca/tulis **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/id/aspose.slides.effects/ioutershadow/rotate_shadow_with_shape/) | Menunjukkan apakah bayangan berotasi bersama bentuk.<br/>            Nilai default – true.<br/>            Baca/tulis **bool**. |
| [`scale_horizontal`](/slides/python-net/id/aspose.slides.effects/ioutershadow/scale_horizontal/) | Faktor skala horizontal, dalam persen ukuran asli.<br/>            Skala negatif menyebabkan flip.<br/>            Nilai default – 100 %.<br/>            Baca/tulis **float**. |
| [`scale_vertical`](/slides/python-net/id/aspose.slides.effects/ioutershadow/scale_vertical/) | Faktor skala vertikal, dalam persen ukuran asli.<br/>            Skala negatif menyebabkan flip.<br/>            Nilai default – 100 %.<br/>            Baca/tulis **float**. |
