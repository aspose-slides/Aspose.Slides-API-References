## IBlur kelas

Mewakili efek Blur yang diterapkan pada seluruh bentuk, termasuk isinya.
Semua saluran warna, termasuk alfa, terpengaruh.

Tipe IBlur mengekspos anggota-anggota berikut:

## Properti

| Property | Description |
| :- | :- |
| [`radius`](/slides/python-net/id/aspose.slides.effects/iblur/radius/) | Mengembalikan atau mengatur radius blur.<br/> Baca/tulis **float**. |
| [`grow`](/slides/python-net/id/aspose.slides.effects/iblur/grow/) | Menentukan apakah batas objek harus diperbesar akibat proses blur.<br/> True menunjukkan batas diperbesar sementara false menunjukkan tidak.<br/> Baca/tulis **bool**. |
