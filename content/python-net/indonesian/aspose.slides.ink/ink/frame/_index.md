## properti frame
Mengembalikan atau mengatur properti frame bentuk.
            Baca/tulis [`IShapeFrame`](/slides/python-net/id/aspose.slides/ishapeframe).


### Catatan

Nilai setiap properti dari instance IShapeFrame yang dikembalikan tidak undefined (is not NaN or NotDefined).
            Nilai setiap properti dari instance IShapeFrame yang ditetapkan harus tidak undefined (must be not NaN or NotDefined).
            Anda dapat mengatur nilai undefined untuk properti instance RawFrame.
