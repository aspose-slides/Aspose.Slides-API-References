## InkBrush kelas

Mewakili objek inkBrush.

Tipe InkBrush mengekspos anggota-anggota berikut:

## Properti

| Property | Description |
| :- | :- |
| [`color`](/slides/python-net/id/aspose.slides.ink/inkbrush/color/) | Mendapatkan atau mengatur warna sikat untuk sebuah garis. |
| [`size`](/slides/python-net/id/aspose.slides.ink/inkbrush/size/) | Mendapatkan atau mengatur ukuran sikat untuk sebuah garis dalam poin. |
| [`ink_effect`](/slides/python-net/id/aspose.slides.ink/inkbrush/ink_effect/) | Mendapatkan tipe efek tinta (mis., Galaxy, Gold, Silver) yang menentukan gaya visual goresan tinta.<br/>            Nilai diurai dari properti sikat "inkEffects". Jika tidak ada efek yang dikenali yang ditentukan,<br/>            [`InkEffectType.NOT_DEFINED`](/slides/python-net/id/aspose.slides.ink/inkeffecttype/NOT_DEFINED) dikembalikan. |
