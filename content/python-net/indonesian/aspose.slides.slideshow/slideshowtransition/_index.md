## SlideShowTransition kelas

Mewakili transisi pertunjukan slide.

Tipe SlideShowTransition menampilkan anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`sound`](/slides/python-net/id/aspose.slides.slideshow/slideshowtransition/sound/) | Mengembalikan atau mengatur data audio yang disematkan.<br/>            Baca/tulis [`IAudio`](/slides/python-net/id/aspose.slides/iaudio). |
| [`sound_mode`](/slides/python-net/id/aspose.slides.slideshow/slideshowtransition/sound_mode/) | Mengatur atau mengembalikan mode suara untuk transisi slide.<br/>            Baca/tulis [`TransitionSoundMode`](/slides/python-net/id/aspose.slides.slideshow/transitionsoundmode). |
| [`sound_loop`](/slides/python-net/id/aspose.slides.slideshow/slideshowtransition/sound_loop/) | Atribut ini menentukan apakah suara akan berulang sampai peristiwa suara berikutnya terjadi dalam slideshow.<br/>            Baca/tulis **bool**. |
| [`advance_on_click`](/slides/python-net/id/aspose.slides.slideshow/slideshowtransition/advance_on_click/) | Menentukan apakah klik mouse akan maju ke slide berikutnya atau tidak. Jika atribut ini tidak<br/>            ditentukan maka nilai true diasumsikan.<br/>            Baca/tulis **bool**. |
| [`advance_after`](/slides/python-net/id/aspose.slides.slideshow/slideshowtransition/advance_after/) | Atribut ini menentukan apakah slideshow akan berpindah ke slide berikutnya setelah waktu tertentu.<br/>            Baca/tulis **bool**. |
| [`advance_after_time`](/slides/python-net/id/aspose.slides.slideshow/slideshowtransition/advance_after_time/) | Menentukan waktu, dalam milidetik, setelah mana transisi harus dimulai. Pengaturan ini<br/>            dapat digunakan bersamaan dengan atribut advClick. Jika atribut ini tidak<br/>            ditentukan maka diasumsikan tidak ada auto-advance yang akan terjadi.<br/>            Baca/tulis **int**. |
| [`speed`](/slides/python-net/id/aspose.slides.slideshow/slideshowtransition/speed/) | Menentukan kecepatan transisi yang akan digunakan saat berpindah dari slide saat ini<br/>            ke slide berikutnya.<br/>            Baca/tulis [`TransitionSpeed`](/slides/python-net/id/aspose.slides.slideshow/transitionspeed). |
| [`value`](/slides/python-net/id/aspose.slides.slideshow/slideshowtransition/value/) | Nilai transisi pertunjukan slide.<br/>            Baca-saja [`ITransitionValueBase`](/slides/python-net/id/aspose.slides.slideshow/itransitionvaluebase). |
| [`type`](/slides/python-net/id/aspose.slides.slideshow/slideshowtransition/type/) | Jenis transisi.<br/>            Baca/tulis [`TransitionType`](/slides/python-net/id/aspose.slides.slideshow/transitiontype). |
| [`sound_is_built_in`](/slides/python-net/id/aspose.slides.slideshow/slideshowtransition/sound_is_built_in/) | Menentukan apakah suara ini merupakan suara bawaan atau tidak. Jika atribut ini diatur ke true maka<br/>            aplikasi pembuat akan diperingatkan untuk memeriksa atribut name yang ditentukan untuk suara ini<br/>            dalam daftar suara bawaan dan dapat menampilkan nama khusus atau UI sesuai kebutuhan.<br/>            Baca/tulis **bool**. |
| [`sound_name`](/slides/python-net/id/aspose.slides.slideshow/slideshowtransition/sound_name/) | Menentukan nama yang dapat dibaca manusia untuk suara transisi. Properti [`SlideShowTransition.sound`](/slides/python-net/id/aspose.slides.slideshow/slideshowtransition/sound) harus diberikan untuk mendapatkan atau mengatur nama suara.<br/>            Baca/tulis **str**. |
| [`duration`](/slides/python-net/id/aspose.slides.slideshow/slideshowtransition/duration/) | Mengambil atau mengatur durasi efek transisi slide dalam milidetik.<br/>            Baca/tulis **int**. |
