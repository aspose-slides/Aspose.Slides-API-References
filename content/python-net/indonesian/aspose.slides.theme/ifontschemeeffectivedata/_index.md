## IFontSchemeEffectiveData kelas

Objek tidak dapat diubah yang berisi properti skema font efektif.

Tipe IFontSchemeEffectiveData menampilkan anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`minor`](/slides/python-net/id/aspose.slides.theme/ifontschemeeffectivedata/minor/) | Mengembalikan koleksi font untuk bagian "body" dari slide.<br/>            Hanya-baca [`IFontsEffectiveData`](/slides/python-net/id/aspose.slides/ifontseffectivedata). |
| [`major`](/slides/python-net/id/aspose.slides.theme/ifontschemeeffectivedata/major/) | Mengembalikan koleksi font untuk bagian "heading" dari slide.<br/>            Hanya-baca [`IFontsEffectiveData`](/slides/python-net/id/aspose.slides/ifontseffectivedata). |
| [`name`](/slides/python-net/id/aspose.slides.theme/ifontschemeeffectivedata/name/) | Mengembalikan nama skema font.<br/>            Hanya-baca **str**. |


### Catatan

Antarmuka ini digunakan sebagai bagian dari [`IThemeEffectiveData`](/slides/python-net/id/aspose.slides.theme/ithemeeffectivedata).
