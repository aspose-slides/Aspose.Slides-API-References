## IFontScheme kelas

Menyimpan font yang ditentukan tema.

Tipe IFontScheme menampilkan anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`minor`](/slides/python-net/id/aspose.slides.theme/ifontscheme/minor/) | Mengembalikan koleksi font untuk bagian "body" dari slide.<br/>            Hanya-baca [`IFonts`](/slides/python-net/id/aspose.slides/ifonts). |
| [`major`](/slides/python-net/id/aspose.slides.theme/ifontscheme/major/) | Mengembalikan koleksi font untuk bagian "heading" dari slide.<br/>            Hanya-baca [`IFonts`](/slides/python-net/id/aspose.slides/ifonts). |
| [`name`](/slides/python-net/id/aspose.slides.theme/ifontscheme/name/) | Mengembalikan nama skema font.<br/>            Baca/tulis **str**. |
