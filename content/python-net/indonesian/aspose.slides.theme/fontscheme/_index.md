## FontScheme kelas

Menyimpan font yang didefinisikan tema.

Tipe FontScheme mengekspos anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`minor`](/slides/python-net/id/aspose.slides.theme/fontscheme/minor/) | Mengembalikan koleksi fonts untuk bagian "body" dari slide.<br/>            Hanya-baca [`IFonts`](/slides/python-net/id/aspose.slides/ifonts). |
| [`major`](/slides/python-net/id/aspose.slides.theme/fontscheme/major/) | Mengembalikan koleksi fonts untuk bagian "heading" dari slide.<br/>            Hanya-baca [`IFonts`](/slides/python-net/id/aspose.slides/ifonts). |
| [`name`](/slides/python-net/id/aspose.slides.theme/fontscheme/name/) | Mengembalikan nama skema font.<br/>            Baca/tulis **str**. |
