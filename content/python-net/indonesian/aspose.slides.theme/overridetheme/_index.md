## OverrideTheme kelas

Mewakili tema yang menimpa.

**Pewarisan:**[`OverrideTheme`](/slides/python-net/id/aspose.slides.theme/overridetheme) → [`Theme`](/slides/python-net/id/aspose.slides.theme/theme)

Tipe OverrideTheme menampilkan anggota berikut:

## Properti

| Property | Description |
| :- | :- |
| [`color_scheme`](/slides/python-net/id/aspose.slides.theme/overridetheme/color_scheme/) | Mengembalikan skema warna.<br/> Baca-saja [`IColorScheme`](/slides/python-net/id/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/id/aspose.slides.theme/overridetheme/font_scheme/) | Mengembalikan skema font.<br/> Baca-saja [`IFontScheme`](/slides/python-net/id/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/id/aspose.slides.theme/overridetheme/format_scheme/) | Mengembalikan skema format bentuk.<br/> Baca-saja [`IFormatScheme`](/slides/python-net/id/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/id/aspose.slides.theme/overridetheme/presentation/) | Mengembalikan presentasi induk.<br/> Baca-saja [`IPresentation`](/slides/python-net/id/aspose.slides/ipresentation). |
| [`is_empty`](/slides/python-net/id/aspose.slides.theme/overridetheme/is_empty/) | Nilai true berarti bahwa ColorScheme, FontScheme, FormatScheme adalah None dan semua penimpaan dengan objek tema ini dinonaktifkan.<br/> Baca-saja **bool**. |
