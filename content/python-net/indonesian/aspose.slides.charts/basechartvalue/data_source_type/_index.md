## data_source_type properti
Menentukan apakah properti AsCell, AsCells, AsLiteralString, atau AsLiteralDouble aktual pada keturunan. Dengan kata lain, ini menentukan tipe nilai properti Data. Baca/tulis [`DataSourceType`](/slides/python-net/id/aspose.slides.charts/datasourcetype).

### Catatan

Untuk poin dalam ChartDataPointCollection, properti ini bersifat baca-saja. Dalam kasus ini, untuk mengubah nilai properti ini Anda dapat menggunakan salah satu properti ChartDataPointCollection.DataSourceTypeFor<...>.
