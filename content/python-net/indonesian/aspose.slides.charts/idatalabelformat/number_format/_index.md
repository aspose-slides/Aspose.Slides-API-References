## number_format properti
Mewakili string format untuk objek DataLabels.
Baca/tulis **str**.

### Catatan

Jika induk dari objek DataLabelFormat ini adalah koleksi DataLabelCollection berisi label data, maka properti ini mengambil atau mengatur nilai default properti NumberFormat untuk label data baru dalam koleksi DataLabelCollection. Ketika properti ini diatur dengan sebuah nilai, nilai tersebut juga diatur untuk properti NumberFormat untuk semua label data dalam koleksi DataLabelCollection (misalnya "DataLabels.DefaultDataLabelFormat.NumberFormat = val;" menyebabkan semua DataLabels[i].NumberFormat menjadi nilai val).
