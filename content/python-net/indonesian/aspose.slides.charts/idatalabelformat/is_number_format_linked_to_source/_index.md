## is_number_format_linked_to_source properti
Baca/tulis **bool**.

### Catatan

Jika induk dari objek DataLabelFormat ini adalah sebuah koleksi DataLabelCollection dari label data, maka properti ini mendapatkan atau mengatur nilai default dari properti IsNumberFormatLinkedToSource untuk label data baru dalam koleksi DataLabelCollection. Mengatur properti ini dengan nilai juga mengatur nilai ini ke properti IsNumberFormatLinkedToSource untuk semua label data dalam koleksi DataLabelCollection (i.e. "DataLabels.DefaultDataLabelFormat.IsNumberFormatLinkedToSource = val;" menyebabkan semua DataLabels[i].IsNumberFormatLinkedToSource sama dengan val).
