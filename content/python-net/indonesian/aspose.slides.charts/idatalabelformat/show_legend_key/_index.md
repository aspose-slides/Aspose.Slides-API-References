## show_legend_key properti
Mewakili perilaku tampilan legend key label data pada diagram tertentu. 
            True jika legend key label data terlihat.
            Baca/tulis **bool**.

### Catatan

Jika induk dari objek DataLabelFormat ini adalah koleksi DataLabelCollection dari label data, maka properti ini mendapatkan atau mengatur nilai default properti ShowLegendKey untuk label data baru dalam koleksi DataLabelCollection.
            Mengatur properti ini dengan nilai juga mengatur nilai ini ke properti ShowLegendKey untuk semua label data dalam koleksi DataLabelCollection
            (i.e. "DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;" menyebabkan semua DataLabels[i].ShowLegendKey menjadi sama dengan val).
