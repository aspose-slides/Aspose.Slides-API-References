## position properti
Mewakili position label data.
Baca/tulis [`LegendDataLabelPosition`](/slides/python-net/id/aspose.slides.charts/legenddatalabelposition).

### Catatan

Jika induk dari objek DataLabelFormat ini adalah koleksi DataLabelCollection dari label data maka properti ini mendapatkan atau mengatur nilai default dari properti Position untuk label data baru dalam koleksi DataLabelCollection.
Mewakili position untuk objek DataLabel.
Mengatur properti ini dengan nilai juga mengatur nilai tersebut ke properti Position untuk semua label data dalam koleksi DataLabelCollection (misalnya "DataLabels.DefaultDataLabelFormat.Position = val;" menyebabkan semua DataLabels[i].Position menjadi sama dengan val).
