## IChartTextFormat kelas

Chart beroperasi dengan set terbatas properti format teks.
IChartTextFormat, IChartTextBlockFormat, IChartParagraphFormat, IChartPortionFormat antarmuka menjelaskan set terbatas ini.

Tipe IChartTextFormat mengekspos anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`text_block_format`](/slides/python-net/id/aspose.slides.charts/icharttextformat/text_block_format/) | Mengembalikan format untuk elemen teks chart.<br/>            Hanya-baca [`IChartTextBlockFormat`](/slides/python-net/id/aspose.slides.charts/icharttextblockformat). |
| [`paragraph_format`](/slides/python-net/id/aspose.slides.charts/icharttextformat/paragraph_format/) | Mengembalikan format paragraf.<br/>            Hanya-baca [`IChartParagraphFormat`](/slides/python-net/id/aspose.slides.charts/ichartparagraphformat). |
| [`portion_format`](/slides/python-net/id/aspose.slides.charts/icharttextformat/portion_format/) | Mengembalikan format bagian.<br/>            Hanya-baca [`IChartPortionFormat`](/slides/python-net/id/aspose.slides.charts/ichartportionformat). |
