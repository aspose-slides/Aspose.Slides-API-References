## AxisAggregationType enumerasi

Mewakili tipe agregasi sumbu kategori. Hanya digunakan dengan seri Histogram atau HistogramPareto.

Tipe AxisAggregationType menampilkan anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| BY_CATEGORY | Agregasi berdasarkan kategori |
| AUTOMATIC | Agregasi kategori secara otomatis. |
| BY_BIN_WIDTH | Agregasi kategori berdasarkan lebar bin. Properti IAxis.BinWidth harus disetel. |
| BY_NUMBER_OF_BINS | Agregasi kategori berdasarkan jumlah bin. Properti IAxis.NumberOfBins harus disetel. |
