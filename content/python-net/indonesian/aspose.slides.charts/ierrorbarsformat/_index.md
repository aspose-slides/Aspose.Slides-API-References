## IErrorBarsFormat kelas

Mewakili error bars seri chart. Nilai khusus ErrorBars berada di IChartDataPointCollection (pada [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/id/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) properti).

Tipe IErrorBarsFormat menampilkan anggota berikut:

## Properti

| Property | Description |
| :- | :- |
| [`type`](/slides/python-net/id/aspose.slides.charts/ierrorbarsformat/type/) | Mendapatkan atau mengatur tipe error bars. <br/>            Baca/tulis [`ErrorBarType`](/slides/python-net/id/aspose.slides.charts/errorbartype). |
| [`value_type`](/slides/python-net/id/aspose.slides.charts/ierrorbarsformat/value_type/) | Mewakili cara-cara yang mungkin untuk menentukan panjang error bars. <br/>            Jika menggunakan tipe nilai khusus untuk menentukan nilai, gunakan [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/id/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) properti pada titik data tertentu dalam koleksi DataPoints serii.  <br/>            Baca/tulis [`ErrorBarValueType`](/slides/python-net/id/aspose.slides.charts/errorbarvaluetype). |
| [`has_end_cap`](/slides/python-net/id/aspose.slides.charts/ierrorbarsformat/has_end_cap/) | Menentukan bahwa ujung penutup tidak digambar pada error bars.<br/>            Baca/tulis **bool**. |
| [`value`](/slides/python-net/id/aspose.slides.charts/ierrorbarsformat/value/) | Mendapatkan atau mengatur nilai yang digunakan dengan tipe nilai Fixed, Percentage dan StandardDeviation untuk menentukan panjang error bars. <br/>            Baca/tulis **float**. |
| [`format`](/slides/python-net/id/aspose.slides.charts/ierrorbarsformat/format/) | Mewakili format error bars.<br/>            Baca/tulis [`IFormat`](/slides/python-net/id/aspose.slides.charts/iformat). |
| [`is_visible`](/slides/python-net/id/aspose.slides.charts/ierrorbarsformat/is_visible/) | Mendapatkan atau mengatur visibilitas Error Bars.<br/>            Baca/tulis **bool**. |
