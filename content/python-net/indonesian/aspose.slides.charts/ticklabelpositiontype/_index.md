## TickLabelPositionType enumerasi

Mewakili tipe posisi label tick-mark pada sumbu yang ditentukan.

Tipe TickLabelPositionType menampilkan anggota-anggota berikut:

## Fields

| Field | Description |
| :- | :- |
| HIGH | Menentukan label sumbu berada pada ujung tinggi dari sumbu tegak lurus. |
| LOW | Menentukan label sumbu berada pada ujung rendah dari sumbu tegak lurus. |
| NEXT_TO | Menentukan label sumbu berada di sebelah sumbu. |
| NONE | Menentukan label sumbu tidak digambar. |
