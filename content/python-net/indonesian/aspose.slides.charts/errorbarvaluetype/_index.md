## ErrorBarValueType enumerasi

Mewakili tipe nilai bar kesalahan

Tipe ErrorBarValueType menampilkan anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| CUSTOM | Menentukan bahwa panjang bar kesalahan harus ditentukan oleh elemen Plus dan Minus. |
| FIXED | Menentukan bahwa panjang bar kesalahan harus berupa nilai tetap yang ditentukan oleh Error Bar Value. |
| PERCENTAGE | Menentukan bahwa panjang bar kesalahan harus berupa persentase Error Bar Value dari data. |
| STANDARD_DEVIATION | Menentukan bahwa panjang bar kesalahan harus berupa standar deviasi Error Bar Value dari data. |
| STANDARD_ERROR | Menentukan bahwa panjang bar kesalahan harus berupa kesalahan standar Error Bar Value dari data. |
