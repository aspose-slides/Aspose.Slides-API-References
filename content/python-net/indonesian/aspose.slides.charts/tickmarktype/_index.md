## enumerasi TickMarkType

Mewakili tipe tanda centang untuk sumbu yang ditentukan.

Tipe TickMarkType mengekspos anggota berikut:

## Bidang

| Field | Deskripsi |
| :- | :- |
| CROSS | Menentukan bahwa tanda centang harus melintasi sumbu. |
| INSIDE | Menentukan bahwa tanda centang harus berada di dalam area plot. |
| NONE | Menentukan tidak ada tanda centang. |
| OUTSIDE | Menentukan bahwa tanda centang harus berada di luar area plot. |
