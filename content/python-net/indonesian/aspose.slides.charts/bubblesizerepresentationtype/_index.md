## BubbleSizeRepresentationType enumerasi

Menentukan cara-cara yang mungkin untuk merepresentasikan data sebagai ukuran diagram gelembung.

Tipe BubbleSizeRepresentationType mengekspos anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| AREA | Menentukan bahwa area gelembung harus proporsional dengan nilai ukuran gelembung. |
| WIDTH | Menentukan bahwa jari-jari gelembung harus proporsional dengan nilai ukuran gelembung. |
