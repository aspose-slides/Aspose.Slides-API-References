## use_secondary_categories properti
Jika false maka [`ChartData.secondary_categories`](/slides/python-net/id/aspose.slides.charts/chartdata/secondary_categories) properti return None dan data 
            di [`ChartData.categories`](/slides/python-net/id/aspose.slides.charts/chartdata/categories) properti digunakan baik untuk seri utama maupun sekunder.
            Jika true maka data di [`ChartData.secondary_categories`](/slides/python-net/id/aspose.slides.charts/chartdata/secondary_categories) properti digunakan untuk seri sekunder dan data 
            di [`ChartData.categories`](/slides/python-net/id/aspose.slides.charts/chartdata/categories) properti digunakan untuk seri utama.
            Baca/tulis **bool**.
