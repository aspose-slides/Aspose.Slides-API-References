## use_cells properti
Jika true maka lembar kerja digunakan untuk menyimpan kategori (kasus ini mendukung kategori berjenjang).
            Jika false maka lembar kerja TIDAK digunakan untuk menyimpan nilai (dan kasus ini tidak mendukung 
            kategori berjenjang).
            Baca/tulis **bool**.
