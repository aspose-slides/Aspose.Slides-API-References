## ChartCategoryCollection kelas

Mewakili koleksi [`ChartCategory`](/slides/python-net/id/aspose.slides.charts/chartcategory)

Tipe ChartCategoryCollection mengekspos anggota-anggota berikut:

## Properti

| Property | Description |
| :- | :- |
| [`use_cells`](/slides/python-net/id/aspose.slides.charts/chartcategorycollection/use_cells/) | Jika true maka worksheet digunakan untuk menyimpan kategori (kasus ini mendukung kategori bertingkat).<br/>Jika false maka worksheet TIDAK digunakan untuk menyimpan nilai (dan kasus ini tidak mendukung kategori bertingkat).<br/>Baca/tulis **bool**. |
| [`grouping_level_count`](/slides/python-net/id/aspose.slides.charts/chartcategorycollection/grouping_level_count/) | Mengembalikan jumlah tingkat pengelompokan kategori yang digunakan.<br/>            Lebih dari satu untuk kategori bertingkat.<br/>            Hanya-baca **int**. |

Mendapatkan elemen pada indeks yang ditentukan.
