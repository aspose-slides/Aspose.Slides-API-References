## enumerasi TimeUnitType

Mewakili unit dasar untuk sumbu kategori

Tipe TimeUnitType menampilkan anggota-anggota berikut:

## Bidang

| Field | Deskripsi |
| :- | :- |
| NONE | Nilai akan ditampilkan sebagaimana adanya. |
| DAYS | Menentukan bahwa data diagram akan ditampilkan dalam hari. |
| MONTHS | Menentukan bahwa data diagram akan ditampilkan dalam bulan. |
| YEARS | Menentukan bahwa data diagram akan ditampilkan dalam tahun. |
