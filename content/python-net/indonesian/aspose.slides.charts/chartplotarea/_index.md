## ChartPlotArea kelas

Mewakili persegi panjang tempat grafik harus digambar.

Tipe ChartPlotArea mengekspos anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`format`](/slides/python-net/id/aspose.slides.charts/chartplotarea/format/) | Mengembalikan format area plot.<br/>            Baca-saja [`IFormat`](/slides/python-net/id/aspose.slides.charts/iformat). |
| [`x`](/slides/python-net/id/aspose.slides.charts/chartplotarea/x/) | Mengembalikan atau mengatur koordinat x sudut kiri atas kotak pembatas area plot sebagai pecahan lebar grafik (dari 0 hingga 1).<br/>            Baca/tulis **float**. |
| [`y`](/slides/python-net/id/aspose.slides.charts/chartplotarea/y/) | Mengembalikan atau mengatur koordinat y sudut kiri atas kotak pembatas area plot sebagai pecahan tinggi grafik (dari 0 hingga 1).<br/>            Baca/tulis **float**. |
| [`width`](/slides/python-net/id/aspose.slides.charts/chartplotarea/width/) | Mengembalikan atau mengatur lebar kotak pembatas area plot sebagai pecahan lebar grafik (dari 0 hingga 1).<br/>            Baca/tulis **float**. |
| [`height`](/slides/python-net/id/aspose.slides.charts/chartplotarea/height/) | Mengembalikan atau mengatur tinggi kotak pembatas area plot sebagai pecahan tinggi grafik (dari 0 hingga 1).<br/>            Baca/tulis **float**. |
| [`right`](/slides/python-net/id/aspose.slides.charts/chartplotarea/right/) | Kanan.<br/>            Baca-saja **float**. |
| [`bottom`](/slides/python-net/id/aspose.slides.charts/chartplotarea/bottom/) | Bawah.<br/>            Baca-saja **float**. |
| [`chart`](/slides/python-net/id/aspose.slides.charts/chartplotarea/chart/) | Diagram.<br/>            Baca-saja [`IChart`](/slides/python-net/id/aspose.slides.charts/ichart). |
| [`is_location_autocalculated`](/slides/python-net/id/aspose.slides.charts/chartplotarea/is_location_autocalculated/) | Menentukan bagaimana lokasi dihitung: true – dihitung secara otomatis; ditentukan oleh properti X, Y, Width, Height.<br/>            Baca-saja **bool**. |
| [`layout_target_type`](/slides/python-net/id/aspose.slides.charts/chartplotarea/layout_target_type/) | Jika tata letak area plot ditentukan secara manual properti ini menentukan apakah menata area plot dari dalam (tidak termasuk sumbu dan label sumbu) atau dari luar (termasuk sumbu dan label sumbu).<br/>            Baca/tulis [`ChartPlotArea.layout_target_type`](/slides/python-net/id/aspose.slides.charts/chartplotarea/layout_target_type). |
| [`actual_x`](/slides/python-net/id/aspose.slides.charts/chartplotarea/actual_x/) | Menentukan lokasi x aktual (kiri) elemen diagram relatif terhadap sudut kiri atas diagram.<br/>            Panggil metode IChart.ValidateChartLayout() sebelum untuk mendapatkan nilai aktual. <br/>            Baca **float**. |
| [`actual_y`](/slides/python-net/id/aspose.slides.charts/chartplotarea/actual_y/) | Menentukan lokasi atas aktual elemen diagram relatif terhadap sudut kiri atas diagram.<br/>            Panggil metode IChart.ValidateChartLayout() sebelum untuk mendapatkan nilai aktual. <br/>            Baca **float**. |
| [`actual_width`](/slides/python-net/id/aspose.slides.charts/chartplotarea/actual_width/) | Menentukan lebar aktual elemen diagram. Panggil metode IChart.ValidateChartLayout() sebelum untuk mendapatkan nilai aktual. <br/>            Baca **float**. |
| [`actual_height`](/slides/python-net/id/aspose.slides.charts/chartplotarea/actual_height/) | Menentukan tinggi aktual elemen diagram. Panggil metode IChart.ValidateChartLayout() sebelum untuk mendapatkan nilai aktual. <br/>            Baca **float**. |
