## IAxesManager kelas

Menyediakan akses ke sumbu grafik.

Tipe IAxesManager mengekspos anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`horizontal_axis`](/slides/python-net/id/aspose.slides.charts/iaxesmanager/horizontal_axis/) | Mendapatkan sumbu horizontal grafik.<br/>             Hanya baca [`IAxis`](/slides/python-net/id/aspose.slides.charts/iaxis). |
| [`secondary_horizontal_axis`](/slides/python-net/id/aspose.slides.charts/iaxesmanager/secondary_horizontal_axis/) | Mendapatkan sumbu horizontal sekunder grafik.<br/>             Hanya baca [`IAxis`](/slides/python-net/id/aspose.slides.charts/iaxis). |
| [`vertical_axis`](/slides/python-net/id/aspose.slides.charts/iaxesmanager/vertical_axis/) | Mendapatkan sumbu vertikal grafik.<br/>             Hanya baca [`IAxis`](/slides/python-net/id/aspose.slides.charts/iaxis). |
| [`secondary_vertical_axis`](/slides/python-net/id/aspose.slides.charts/iaxesmanager/secondary_vertical_axis/) | Mendapatkan sumbu vertikal sekunder grafik.<br/>             Hanya baca [`IAxis`](/slides/python-net/id/aspose.slides.charts/iaxis). |
| [`series_axis`](/slides/python-net/id/aspose.slides.charts/iaxesmanager/series_axis/) | Mendapatkan sumbu seri grafik.<br/>             Hanya baca [`IAxis`](/slides/python-net/id/aspose.slides.charts/iaxis). |
