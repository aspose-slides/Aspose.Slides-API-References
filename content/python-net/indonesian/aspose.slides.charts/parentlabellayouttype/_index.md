## ParentLabelLayoutType enumerasi

Mewakili tata letak label data kategori. Hanya digunakan dengan seri Treemap.

Tipe ParentLabelLayoutType menampilkan anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| BANNER | Menentukan bahwa label kategori induk ditampilkan sebagai spanduk |
| NONE | Menentukan bahwa label kategori induk tidak digambar |
| OVERLAPPING | Menentukan bahwa label kategori induk ditampilkan secara tumpang tindih |
