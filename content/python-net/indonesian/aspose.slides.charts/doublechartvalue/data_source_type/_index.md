## data_source_type properti
Specifies whether AsCell, AsCells, AsLiteralString or AsLiteralDouble 
            properti is actual in descendants. In other words it specifies the type 
            of nilai of the Data properti.
            Baca/tulis [`DataSourceType`](/slides/python-net/id/aspose.slides.charts/datasourcetype).


### Catatan

For points in ChartDataPointCollection this properti is hanya-baca. 
            In this case for changing nilai of this properti you can use one of the 
            ChartDataPointCollection.DataSourceTypeFor<...> properti.
