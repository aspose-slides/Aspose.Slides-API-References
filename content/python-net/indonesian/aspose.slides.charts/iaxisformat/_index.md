## IAxisFormat kelas

Mewakili properti format diagram.

Tipe IAxisFormat menyajikan anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`fill`](/slides/python-net/id/aspose.slides.charts/iaxisformat/fill/) | Mengembalikan properti gaya isian dari sumbu.<br/>            Hanya baca [`IFillFormat`](/slides/python-net/id/aspose.slides/ifillformat). |
| [`line`](/slides/python-net/id/aspose.slides.charts/iaxisformat/line/) | Mengembalikan properti gaya garis dari sumbu.<br/>            Hanya baca [`ILineFormat`](/slides/python-net/id/aspose.slides/ilineformat). |
| [`effect`](/slides/python-net/id/aspose.slides.charts/iaxisformat/effect/) | Mengembalikan efek yang digunakan untuk sumbu.<br/>            Hanya baca [`IEffectFormat`](/slides/python-net/id/aspose.slides/ieffectformat). |
