## Enumerasi ChartShapeType

Mewakili bentuk bagan.

Tipe ChartShapeType menampilkan anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| NOT_DEFINED | Bentuk bagan tidak didefinisikan. |
| BOX | Menentukan bagan harus digambar dengan bentuk kotak. |
| CONE | Menentukan bagan harus digambar sebagai kerucut, dengan basis kerucut di lantai dan puncak kerucut di atas penanda data. |
| CONE_TO_MAX | Menentukan bagan harus digambar dengan kerucut terpotong sehingga puncak kerucut adalah nilai data maksimum. |
| CYLINDER | Menentukan bagan harus digambar sebagai silinder. |
| PYRAMID | Menentukan bagan harus digambar sebagai piramida persegi panjang, dengan basis piramida di lantai dan puncak piramida di atas penanda data. |
| PYRAMID_TO_MAXIMUM | Menentukan bagan harus digambar dengan kerucut terpotong sehingga puncak kerucut adalah nilai data maksimum. |
