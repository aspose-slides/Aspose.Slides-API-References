## DisplayUnitType enumerasi

Menentukan banyaknya data yang ditampilkan.

Tipe DisplayUnitType menampilkan anggota-anggota berikut:

## Field

| Bidang | Deskripsi |
| :- | :- |
| NONE | Nilai akan ditampilkan sebagaimana adanya. |
| HUNDREDS | Menentukan nilai pada diagram akan dibagi dengan 100. |
| THOUSANDS | Menentukan nilai pada diagram akan dibagi dengan 1,000. |
| TEN_THOUSANDS | Menentukan nilai pada diagram akan dibagi dengan 10,000. |
| HUNDRED_THOUSANDS | Menentukan nilai pada diagram akan dibagi dengan 100,000. |
| MILLIONS | Menentukan nilai pada diagram akan dibagi dengan 1,000,000. |
| TEN_MILLIONS | Menentukan nilai pada diagram akan dibagi dengan 10,000,000. |
| HUNDRED_MILLIONS | Menentukan nilai pada diagram akan dibagi dengan 100,000,000. |
| BILLIONS | Menentukan nilai pada diagram akan dibagi dengan 1,000,000,000. |
| TRILLIONS | Menentukan nilai pada diagram akan dibagi dengan 1,000,000,000,000. |
| CUSTOM_VALUE | Menentukan nilai pada diagram akan dibagi dengan nilai khusus. |
