## ChartType enumerasi

Mewakili jenis diagram.

Tipe ChartType menampilkan anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| CLUSTERED_COLUMN | Mewakili Diagram Kolom Terkelompok. |
| STACKED_COLUMN | Mewakili Diagram Kolom Bertumpuk. |
| PERCENTS_STACKED_COLUMN | Mewakili Diagram Kolom 100% Bertumpuk. |

| STACKED_CYLINDER | Mewakili Diagram Silinder Bertumpuk. |
| PERCENTS_STACKED_CYLINDER | Mewakili Diagram Silinder 100% Bertumpuk. |
| CYLINDER_3D | Mewakili Diagram Silinder 3D. |
| CLUSTERED_CONE | Mewakili Diagram Kerucut Terkelompok. |
| STACKED_CONE | Mewakili Diagram Kerucut Bertumpuk. |
| PERCENTS_STACKED_CONE | Mewakili Diagram Kerucut 100% Bertumpuk. |

| PIE_3D | Mewakili Diagram Lingkaran 3D. |
