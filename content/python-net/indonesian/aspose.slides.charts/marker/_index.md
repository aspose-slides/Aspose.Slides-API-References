## Kelas Marker

Mewakili penanda dari sebuah chert.

Tipe Marker menyediakan anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`symbol`](/slides/python-net/id/aspose.slides.charts/marker/symbol/) | Mewakili gaya penanda dalam grafik garis, grafik sebar, atau grafik radar.<br/>            Baca/tulis [`MarkerStyleType`](/slides/python-net/id/aspose.slides.charts/markerstyletype). |
| [`format`](/slides/python-net/id/aspose.slides.charts/marker/format/) | Mendapatkan atau mengatur isian penanda.<br/>            Baca-saja [`IFormat`](/slides/python-net/id/aspose.slides.charts/iformat). |
| [`size`](/slides/python-net/id/aspose.slides.charts/marker/size/) | Mewakili ukuran penanda dalam grafik garis, grafik sebar, atau grafik radar.<br/>            Baca/tulis **int**. |
