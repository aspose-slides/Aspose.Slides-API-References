## Rotation3D kelas

Mewakili rotasi 3D sebuah diagram.

Tipe Rotation3D mengekspos anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`rotation_x`](/slides/python-net/id/aspose.slides.charts/rotation3d/rotation_x/) | Mengembalikan atau mengatur derajat rotasi di sekitar sumbu X, yaitu pada arah Y untuk diagram 3D (antara -90 dan 90 derajat).<br/>            Properti ini sesuai dengan item 21.2.2.157 rotX (Rotasi X) dalam ECMA-376 dan dengan opsi "Y Rotation" di PowerPoint 2007+.<br/>            Baca/tulis **int**. |
| [`rotation_y`](/slides/python-net/id/aspose.slides.charts/rotation3d/rotation_y/) | Mengembalikan atau mengatur derajat rotasi di sekitar sumbu Y, yaitu pada arah X untuk diagram 3D (antara 0 dan 360 derajat).<br/>            Properti ini sesuai dengan item 21.2.2.158 rotY (Rotasi Y) dalam ECMA-376 dan dengan opsi "X Rotation" di PowerPoint 2007+.<br/>            Baca/tulis **int**. |
| [`perspective`](/slides/python-net/id/aspose.slides.charts/rotation3d/perspective/) | Mengembalikan atau mengatur nilai perspektif (sudut bidang pandang) untuk diagram 3D (antara 0 dan 240).<br/>            Diabaikan jika nilai properti RightAngleAxes true.<br/>            Baca/tulis **int**. |
| [`right_angle_axes`](/slides/python-net/id/aspose.slides.charts/rotation3d/right_angle_axes/) | Menentukan apakah sumbu diagram berada pada sudut kanan, bukan digambar dalam perspektif.<br/>            Dengan kata lain, ini menentukan apakah sudut sumbu diagram independen dari rotasi atau elevasi diagram.<br/>            Baca/tulis **bool**. |
| [`depth_percents`](/slides/python-net/id/aspose.slides.charts/rotation3d/depth_percents/) | Mengembalikan atau mengatur kedalaman diagram 3D sebagai persentase lebar diagram (antara 20 dan 2000 persen).<br/>            Baca/tulis **int**. |
| [`height_percents`](/slides/python-net/id/aspose.slides.charts/rotation3d/height_percents/) | Menentukan tinggi diagram 3-D sebagai persentase lebar diagram (antara 5 dan 500 persen).<br/>            Baca/tulis **int**. |
