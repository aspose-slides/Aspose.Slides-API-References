## ITrendline kelas

Kelas mewakili garis tren dari seri diagram

Tipe ITrendline menampilkan anggota-anggota berikut:

## Properti

| Property | Description |
| :- | :- |
| [`trendline_name`](/slides/python-net/id/aspose.slides.charts/itrendline/trendline_name/) | Mendapatkan atau mengatur nama garis tren.<br/>            Baca/tulis **str**. |
| [`trendline_type`](/slides/python-net/id/aspose.slides.charts/itrendline/trendline_type/) | Mendapatkan atau mengatur jenis garis tren. <br/>            Baca/tulis [`ITrendline.trendline_type`](/slides/python-net/id/aspose.slides.charts/itrendline/trendline_type). |
| [`format`](/slides/python-net/id/aspose.slides.charts/itrendline/format/) | Mewakili format garis tren.<br/>            Baca/tulis [`IFormat`](/slides/python-net/id/aspose.slides.charts/iformat). |
| [`backward`](/slides/python-net/id/aspose.slides.charts/itrendline/backward/) | Menentukan jumlah kategori (atau unit pada diagram sebar) yang garis tren memperpanjang sebelum<br/>            data untuk seri yang sedang ditrend. Pada diagram sebar dan non-sebar, nilai harus berupa nonnegative<br/>            apa pun.<br/>            Baca/tulis **float**. |
| [`forward`](/slides/python-net/id/aspose.slides.charts/itrendline/forward/) | Menentukan jumlah kategori (atau unit pada diagram sebar) yang trendline memperpanjang setelah<br/>            data untuk seri yang sedang ditrend. Pada diagram sebar dan non-sebar, nilai harus berupa non-negative<br/>            apa pun.<br/>            Baca/tulis **float**. |
| [`intercept`](/slides/python-net/id/aspose.slides.charts/itrendline/intercept/) | Menentukan nilai di mana trendline memotong sumbu y. Properti ini hanya didukung<br/>            ketika jenis trendline adalah exp, linear, atau poly.<br/>            Baca/tulis **float**. |
| [`display_equation`](/slides/python-net/id/aspose.slides.charts/itrendline/display_equation/) | Menentukan bahwa persamaan untuk trendline ditampilkan pada diagram (dalam label yang sama dengan nilai Rsquared).<br/>            Baca/tulis **bool**. |
| [`order`](/slides/python-net/id/aspose.slides.charts/itrendline/order/) | Menentukan urutan garis tren polinomial. Diabaikan untuk jenis garis tren lainnya. Nilai harus antara 2 dan 6.<br/>            Baca/tulis **int**. |
| [`period`](/slides/python-net/id/aspose.slides.charts/itrendline/period/) | Menentukan periode garis tren untuk garis tren rata-rata bergerak. Diabaikan untuk varian<br/>            garis tren lainnya. Nilai harus antara 2 dan 255.<br/>            Baca/tulis **int**. |
| [`display_r_squared_value`](/slides/python-net/id/aspose.slides.charts/itrendline/display_r_squared_value/) | Menentukan bahwa nilai R-squared dari trendline ditampilkan pada diagram (dalam label yang sama dengan persamaan).<br/>            Baca/tulis **bool**. |
| [`related_legend_entry`](/slides/python-net/id/aspose.slides.charts/itrendline/related_legend_entry/) | Mewakili entri legenda yang terkait dengan trendline ini<br/>            Baca-saja [`ILegendEntryProperties`](/slides/python-net/id/aspose.slides.charts/ilegendentryproperties). |
| [`text_frame_for_overriding`](/slides/python-net/id/aspose.slides.charts/itrendline/text_frame_for_overriding/) |  |
