## bubble_size_representation properti
Specifies how the bubble size values are represented on the bubble chart.
            Ini adalah properti bukan hanya untuk seri ini tetapi untuk semua seri dari grup seri induk 
            - ini adalah proyeksi properti grup yang sesuai. Dan sehingga properti ini 
            hanya-baca.
            Gunakan properti ParentSeriesGroup untuk mengakses grup seri induk.
            Gunakan properti ParentSeriesGroup.BubbleSizeRepresentation baca/tulis untuk mengubah nilai.


### Catatan

Ini adalah proyeksi dari properti ParentSeriesGroup.BubbleSizeRepresentation.
