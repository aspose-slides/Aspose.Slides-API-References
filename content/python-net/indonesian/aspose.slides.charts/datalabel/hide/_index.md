## hide(self) {#}
Buat label data tersembunyi dengan mengatur semua Show*-flags (ShowValue, ...) ke keadaan false. IsVisible akan menjadi false setelah ini.

```python
def hide(self):
    ...
```

### Catatan
Jika label data tidak terlihat (IsVisible false) Anda dapat membuat label data terlihat dengan mengatur Show*-flags (ShowValue, ...) ke keadaan true.
