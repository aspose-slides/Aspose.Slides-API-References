## is_visible properti
False berarti bahwa label data tidak terlihat (dan sehingga semua Show*-flags (ShowValue, ...) adalah false).
            Hanya-baca **bool**.


### Catatan

Jika label data terlihat Anda dapat menyembunyikannya dengan metode Hide().
            Tetapi jika label data tidak terlihat (IsVisible false) Anda dapat membuat label data terlihat 
            dengan mengatur Show*-flags (ShowValue, ...) ke keadaan true.
