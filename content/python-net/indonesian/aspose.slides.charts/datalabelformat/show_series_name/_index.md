## show_series_name properti
Mengembalikan atau mengatur Boolean untuk menunjukkan perilaku tampilan nama seri untuk label data pada grafik. 
True untuk menampilkan nama seri. False untuk menyembunyikan.
Baca/tulis **bool**.

### Keterangan

Jika induk dari objek DataLabelFormat ini adalah koleksi DataLabelCollection dari label data maka ini
            properti mendapatkan atau mengatur nilai default dari properti ShowSeriesName untuk label data baru
            dalam koleksi DataLabelCollection.
            Atur properti ini dengan nilai juga akan mengatur nilai ini ke properti ShowSeriesName
            untuk semua label data dalam koleksi DataLabelCollection
            (misalnya "DataLabels.DefaultDataLabelFormat.ShowSeriesName = val;" menyebabkan
            semua DataLabels[i].ShowSeriesName menjadi sama dengan val).
