## show_label_value_from_cell properti
Mewakili perilaku tampilan nilai sel label data pada diagram yang ditentukan. 
            True menampilkan nilai sel. False untuk menyembunyikan.
            Baca/tulis **bool**.


### Catatan

Jika induk dari objek DataLabelFormat ini adalah koleksi DataLabelCollection dari label data maka properti ini mendapatkan atau mengatur nilai default dari properti ShowLabelValueFromCell untuk label data baru di koleksi DataLabelCollection.
            Mengatur properti ini dengan nilai juga mengatur nilai ini ke properti ShowLabelValueFromCell untuk semua label data dalam koleksi DataLabelCollection (misalnya "DataLabels.DefaultDataLabelFormat.ShowLabelValueFromCell = val;" menyebabkan semua DataLabels[i].ShowLabelValueFromCell menjadi sama dengan val).
