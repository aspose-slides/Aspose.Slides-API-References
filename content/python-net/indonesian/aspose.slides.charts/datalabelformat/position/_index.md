## properti posisi
Mewakili posisi label data.
            Baca/tulis [`LegendDataLabelPosition`](/slides/python-net/id/aspose.slides.charts/legenddatalabelposition).

### Catatan

Jika induk dari objek DataLabelFormat ini adalah koleksi DataLabelCollection dari label data maka properti ini mendapatkan atau mengatur nilai default properti Position untuk label data baru dalam koleksi DataLabelCollection.
            Mewakili posisi untuk objek DataLabel.
            Atur properti ini dengan nilai juga mengatur nilai ini ke properti Position untuk semua label data dalam koleksi DataLabelCollection (i.e. "DataLabels.DefaultDataLabelFormat.Position = val;" menyebabkan semua DataLabels[i].Position menjadi sama dengan val).
