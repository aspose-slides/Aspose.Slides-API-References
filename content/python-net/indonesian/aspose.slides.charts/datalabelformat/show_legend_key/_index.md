## show_legend_key property
Mewakili perilaku tampilan kunci legenda label data pada chart tertentu. 
            Benar jika kunci legenda label data terlihat.
            Baca/tulis **bool**.


### Catatan

Jika induk objek DataLabelFormat ini adalah koleksi DataLabelCollection dari label data, maka properti ini mendapatkan atau mengatur nilai default properti ShowLegendKey untuk label data baru di dalam koleksi DataLabelCollection. 
            Menetapkan properti ini dengan nilai juga mengatur nilai ini ke properti ShowLegendKey untuk semua label data dalam koleksi DataLabelCollection (misalnya "DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;" menyebabkan semua DataLabels[i].ShowLegendKey menjadi sama dengan val).
