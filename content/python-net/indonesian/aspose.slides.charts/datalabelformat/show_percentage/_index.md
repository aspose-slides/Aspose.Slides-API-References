## show_percentage properti
Mewakili perilaku tampilan nilai persentase label data pada diagram yang ditentukan. 
            True menampilkan nilai persentase. False menyembunyikannya.
            Baca/tulis **bool**.

### Catatan

Jika induk dari objek DataLabelFormat ini adalah koleksi DataLabelCollection dari label data maka properti ini
            properti ini mendapatkan atau mengatur nilai default dari properti ShowPercentage untuk data baru 
            label dalam koleksi DataLabelCollection.
            Menetapkan properti ini dengan nilai juga mengatur nilai ini ke properti ShowPercentage 
            untuk semua label data dalam koleksi DataLabelCollection
            (misalnya "DataLabels.DefaultDataLabelFormat.ShowPercentage = val;" menyebabkan
            semua DataLabels[i].ShowPercentage menjadi sama dengan val).
