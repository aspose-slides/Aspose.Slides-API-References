## LegendDataLabelPosition enumerasi

Menentukan posisi label data.

Tipe LegendDataLabelPosition menampilkan anggota berikut:

## Bidang

| Field | Description |
| :- | :- |
| NOT_DEFINED | Posisi tidak didefinisikan. |
| BOTTOM | Menentukan bahwa label data harus ditampilkan di bawah penanda data. |
| BEST_FIT | Menentukan bahwa label data harus ditampilkan pada posisi terbaik. |
| CENTER | Menentukan bahwa label data harus ditampilkan di tengah penanda data. |
| INSIDE_BASE | Menentukan bahwa label data harus ditampilkan di dalam basis penanda data. |
| INSIDE_END | Menentukan bahwa label data harus ditampilkan di dalam ujung penanda data. |
| LEFT | Menentukan bahwa label data harus ditampilkan di sebelah kiri penanda data. |
| OUTSIDE_END | Menentukan bahwa label data harus ditampilkan di luar ujung penanda data. |
| RIGHT | Menentukan bahwa label data harus ditampilkan di sebelah kanan penanda data. |
| TOP | Menentukan bahwa label data harus ditampilkan di atas penanda data. |
