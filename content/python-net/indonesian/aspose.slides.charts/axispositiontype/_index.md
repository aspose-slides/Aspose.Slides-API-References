## AxisPositionType enumerasi

Menentukan posisi sumbu.

Tipe AxisPositionType mengekspose anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| BOTTOM | Menetapkan bahwa sumbu akan ditampilkan di bagian bawah area plot. |
| LEFT | Menetapkan bahwa sumbu akan ditampilkan di sebelah kiri area plot. |
| RIGHT | Menetapkan bahwa sumbu akan ditampilkan di sebelah kanan area plot. |
| TOP | Menetapkan bahwa sumbu akan ditampilkan di bagian atas area plot. |
