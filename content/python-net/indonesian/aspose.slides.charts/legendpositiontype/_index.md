## LegendPositionType enumerasi

Menentukan posisi legenda pada diagram.

Tipe LegendPositionType mengungkapkan anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| BOTTOM | Menentukan bahwa legenda harus digambar di bagian bawah diagram. |
| LEFT | Menentukan bahwa legenda harus digambar di sebelah kiri diagram. |
| RIGHT | Menentukan bahwa legenda harus digambar di sebelah kanan diagram. |
| TOP | Menentukan bahwa legenda harus digambar di bagian atas diagram. |
| TOP_RIGHT | Menentukan bahwa legenda harus digambar di kanan atas diagram. |
