## Legend kelas

Mewakili properti legenda chart.

Tipe Legend mengekspos anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`x`](/slides/python-net/id/aspose.slides.charts/legend/x/) | Mengembalikan atau mengatur koordinat x dari legenda sebagai fraksi lebar chart.<br/>            Baca/tulis **float**. |
| [`y`](/slides/python-net/id/aspose.slides.charts/legend/y/) | Mengembalikan atau mengatur koordinat y dari legenda sebagai fraksi tinggi chart.<br/>            Baca/tulis **float**. |
| [`width`](/slides/python-net/id/aspose.slides.charts/legend/width/) | Mengembalikan atau mengatur lebar legenda sebagai fraksi lebar chart.<br/>            Baca/tulis **float**. |
| [`height`](/slides/python-net/id/aspose.slides.charts/legend/height/) | Mengembalikan atau mengatur tinggi legenda sebagai fraksi tinggi chart.<br/>            Baca/tulis **float**. |
| [`right`](/slides/python-net/id/aspose.slides.charts/legend/right/) | Kanan.<br/>            Baca-saja **float**. |
| [`bottom`](/slides/python-net/id/aspose.slides.charts/legend/bottom/) | Bawah.<br/>            Baca-saja **float**. |
| [`overlay`](/slides/python-net/id/aspose.slides.charts/legend/overlay/) | Menentukan apakah elemen chart lain diizinkan tumpang tindih dengan legenda.<br/>            Baca/tulis **bool**. |
| [`text_format`](/slides/python-net/id/aspose.slides.charts/legend/text_format/) | Format teks.<br/>            Baca-saja [`IChartTextFormat`](/slides/python-net/id/aspose.slides.charts/icharttextformat). |
| [`position`](/slides/python-net/id/aspose.slides.charts/legend/position/) | Menentukan posisi legenda pada chart.<br/>            Nilai Non-NaN dari properti X, Y, Width, Heigt akan menggantikan efek properti ini.<br/>            Baca/tulis [`LegendPositionType`](/slides/python-net/id/aspose.slides.charts/legendpositiontype). |
| [`format`](/slides/python-net/id/aspose.slides.charts/legend/format/) | Mengembalikan format legenda.<br/>            Baca-saja [`IFormat`](/slides/python-net/id/aspose.slides.charts/iformat). |
| [`chart`](/slides/python-net/id/aspose.slides.charts/legend/chart/) | Mengembalikan chart.<br/>            Baca-saja [`IChart`](/slides/python-net/id/aspose.slides.charts/ichart). |
| [`entries`](/slides/python-net/id/aspose.slides.charts/legend/entries/) | Mendapatkan entri legenda.<br/>            Baca-saja [`ILegendEntryCollection`](/slides/python-net/id/aspose.slides.charts/ilegendentrycollection). |
| [`actual_x`](/slides/python-net/id/aspose.slides.charts/legend/actual_x/) | Menentukan lokasi x aktual (kiri) dari elemen chart relatif terhadap pojok kiri atas chart.<br/>            Panggil metode IChart.ValidateChartLayout() sebelum untuk mendapatkan nilai aktual. <br/>            Baca **float**. |
| [`actual_y`](/slides/python-net/id/aspose.slides.charts/legend/actual_y/) | Menentukan posisi atas aktual elemen chart relatif terhadap pojok kiri atas chart.<br/>            Panggil metode IChart.ValidateChartLayout() sebelum untuk mendapatkan nilai aktual. <br/>            Baca **float**. |
| [`actual_width`](/slides/python-net/id/aspose.slides.charts/legend/actual_width/) | Menentukan lebar aktual elemen chart. Panggil metode IChart.ValidateChartLayout() sebelum untuk mendapatkan nilai aktual. <br/>            Baca **float**. |
| [`actual_height`](/slides/python-net/id/aspose.slides.charts/legend/actual_height/) | Menentukan tinggi aktual elemen chart. Panggil metode IChart.ValidateChartLayout() sebelum untuk mendapatkan nilai aktual. <br/>            Baca **float**. |
| [`slide`](/slides/python-net/id/aspose.slides.charts/legend/slide/) |  |
