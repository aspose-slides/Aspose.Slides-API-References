## ChartWall kelas

Mewakili dinding pada grafik 3d.

Tipe ChartWall mengungkapkan anggota-anggota berikut:

## Properti

| Property | Description |
| :- | :- |
| [`thickness`](/slides/python-net/id/aspose.slides.charts/chartwall/thickness/) | Mengembalikan atau mengatur ketebalan dinding sebagai persentase dari dimensi terbesar <br/>            volume plot.<br/>            Baca/tulis **int**. |
