## value_type properti
Mewakili cara-cara yang mungkin untuk menentukan panjang bar kesalahan. 
            Jika menggunakan tipe nilai khusus untuk menentukan nilai, gunakan properti [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/id/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) dari titik data spesifik dalam koleksi DataPoints pada seri.
            Jika tipe nilai Fixed, Percentage, atau StandardDeviation, gunakan properti Value untuk menentukan nilai.  
            Baca/tulis [`ErrorBarValueType`](/slides/python-net/id/aspose.slides.charts/errorbarvaluetype).
