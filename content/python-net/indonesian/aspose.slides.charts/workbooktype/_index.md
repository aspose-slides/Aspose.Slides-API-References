## WorkbookType enumerasi

Menentukan jenis file workbook Open XML.

Tipe WorkbookType menampilkan anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| NOT_DEFINED | Jenis workbook tidak ditentukan. |
| WORKBOOK | Workbook Excel (*.xlsx). |
| WORKBOOK_MACRO | Workbook Excel yang mendukung makro (*.xlsm). |
| TEMPLATE | Template Excel (*.xltx). |
| TEMPLATE_MACRO | Template Excel yang mendukung makro (*.xltm). |
| WORKBOOK_BINARY_MACRO | Workbook Excel biner yang mendukung makro (*.xlsb). |
