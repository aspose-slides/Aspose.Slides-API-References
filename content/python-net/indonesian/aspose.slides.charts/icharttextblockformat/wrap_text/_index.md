## wrap_text properti
**True**  if text is wrapped at TextFrame's margins.
            Changing of this property can produce a certain influence only for these chart parts: 
            DataLabel and DataLabelFormat (dukungan penuh in PowerPoint 2007/2013).
            Baca/tulis [`NullableBool`](/slides/python-net/id/aspose.slides/nullablebool).
