## IChartTextBlockFormat kelas

Mewakili properti pemformatan untuk elemen teks diagram.

Tipe IChartTextBlockFormat mengekspos anggota berikut:

## Properti

| Property | Description |
| :- | :- |
| [`anchoring_type`](/slides/python-net/id/aspose.slides.charts/icharttextblockformat/anchoring_type/) | Mengembalikan atau mengatur teks jangkar vertikal dalam TextFrame.<br/>            Read/write [`TextAnchorType`](/slides/python-net/id/aspose.slides/textanchortype). |
| [`center_text`](/slides/python-net/id/aspose.slides.charts/icharttextblockformat/center_text/) | Jika NullableBool.True maka teks harus dipusatkan secara horizontal di dalam kotak.<br/>            Read/write [`NullableBool`](/slides/python-net/id/aspose.slides/nullablebool). |
| [`text_vertical_type`](/slides/python-net/id/aspose.slides.charts/icharttextblockformat/text_vertical_type/) | Menentukan orientasi teks.<br/>            Nilai hasil rotasi visual teks diringkas dari properti ini dan sudut khusus<br/>            di properti RotationAngle.<br/>            Read/write [`TextVerticalType`](/slides/python-net/id/aspose.slides/textverticaltype). |
| [`margin_left`](/slides/python-net/id/aspose.slides.charts/icharttextblockformat/margin_left/) | Mengembalikan atau mengatur margin kiri (points) dalam TextFrame.<br/>            Perubahan properti ini dapat menghasilkan pengaruh tertentu hanya untuk bagian diagram berikut: <br/>            DataLabel dan DataLabelFormat (dukungan penuh di PowerPoint 2013; di PowerPoint 2007 tidak ada efek pada rendering).<br/>            Read/write **float**. |
| [`margin_right`](/slides/python-net/id/aspose.slides.charts/icharttextblockformat/margin_right/) | Mengembalikan atau mengatur margin kanan (points) dalam TextFrame.<br/>            Perubahan properti ini dapat menghasilkan pengaruh tertentu hanya untuk bagian diagram berikut: <br/>            DataLabel dan DataLabelFormat (dukungan penuh di PowerPoint 2013; di PowerPoint 2007 tidak ada efek pada rendering).<br/>            Read/write **float**. |
| [`margin_top`](/slides/python-net/id/aspose.slides.charts/icharttextblockformat/margin_top/) | Mengembalikan atau mengatur margin atas (points) dalam TextFrame.<br/>            Perubahan properti ini dapat menghasilkan pengaruh tertentu hanya untuk bagian diagram berikut: <br/>            DataLabel dan DataLabelFormat (dukungan penuh di PowerPoint 2013; di PowerPoint 2007 tidak ada efek pada rendering).<br/>            Read/write **float**. |
| [`margin_bottom`](/slides/python-net/id/aspose.slides.charts/icharttextblockformat/margin_bottom/) | Mengembalikan atau mengatur margin bawah (points) dalam TextFrame.<br/>            Perubahan properti ini dapat menghasilkan pengaruh tertentu hanya untuk bagian diagram berikut: <br/>            DataLabel dan DataLabelFormat (dukungan penuh di PowerPoint 2013; di PowerPoint 2007 tidak ada efek pada rendering).<br/>            Read/write **float**. |
| [`wrap_text`](/slides/python-net/id/aspose.slides.charts/icharttextblockformat/wrap_text/) | **True**  jika teks dibungkus pada margin TextFrame.<br/>            Perubahan properti ini dapat menghasilkan pengaruh tertentu hanya untuk bagian diagram berikut: <br/>            DataLabel dan DataLabelFormat (dukungan penuh di PowerPoint 2007/2013).<br/>            Read/write [`NullableBool`](/slides/python-net/id/aspose.slides/nullablebool). |
| [`autofit_type`](/slides/python-net/id/aspose.slides.charts/icharttextblockformat/autofit_type/) | Mengembalikan atau mengatur mode autofit teks.<br/>            Perubahan properti ini dapat menghasilkan pengaruh tertentu hanya untuk bagian diagram berikut: <br/>            DataLabel dan DataLabelFormat (dukungan penuh di PowerPoint 2013; di PowerPoint 2007 tidak ada efek pada rendering).<br/>            Read/write [`TextAutofitType`](/slides/python-net/id/aspose.slides/textautofittype). |
| [`rotation_angle`](/slides/python-net/id/aspose.slides.charts/icharttextblockformat/rotation_angle/) | Menentukan rotasi khusus yang diterapkan pada teks di dalam kotak pembatas. Jika tidak ditentukan, rotasi bentuk yang menyertainya digunakan. Jika ditentukan, maka rotasi ini diterapkan secara independen dari bentuk. Artinya bentuk dapat memiliki rotasi yang diterapkan selain rotasi teks itu sendiri.<br/>            Nilai hasil rotasi visual teks diringkas dari properti ini dan tipe vertikal yang telah ditentukan sebelumnya dalam properti TextVerticalType.<br/>            Read/write **float**. |
