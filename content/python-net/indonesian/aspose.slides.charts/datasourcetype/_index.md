## DataSourceType enumerasi

Tipe sumber data.

Tipe DataSourceType mengekspos anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| WORKSHEET | Gunakan objek CellXls untuk menyimpan XValue, YValue, Value, atau BubbleSize dari titik data di worksheet. |
| STRING_LITERALS | Gunakan variabel string akses cepat untuk menyimpan XValue, YValue, Value, atau BubbleSize dari <br/>            titik data. Worksheet TIDAK digunakan untuk menyimpan nilai. |
| DOUBLE_LITERALS | Gunakan variabel double akses cepat untuk menyimpan XValue, YValue, Value, atau BubbleSize dari <br/>            titik data. Worksheet TIDAK digunakan untuk menyimpan nilai. |
