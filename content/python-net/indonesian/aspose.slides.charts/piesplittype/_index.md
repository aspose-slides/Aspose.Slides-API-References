## PieSplitType enumerasi

Mewakili jenis titik pemisahan pada diagram pie atau bar kedua pada diagram pie-of-pie atau bar-of-pie.

The PieSplitType type exposes the following members:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| DEFAULT | Menentukan bahwa titik data akan dibagi menggunakan mekanisme default <br/> untuk tipe diagram ini. |
| CUSTOM | Menentukan bahwa titik data akan dibagi antara <br/> pie dan diagram kedua sesuai dengan nilai Custom Split. |
| BY_PERCENTAGE | Menentukan bahwa titik data akan dibagi antara pie dan <br/> diagram kedua dengan menempatkan titik yang persentasenya kurang dari <br/> persentase Split Position ke dalam diagram kedua. |
| BY_POS | Menentukan bahwa titik data akan dibagi antara pie dan <br/> diagram kedua dengan menempatkan posisi Split Position terakhir dari titik data <br/> ke dalam diagram kedua. |
| BY_VALUE | Menentukan bahwa titik data akan dibagi antara pie dan <br/> diagram kedua dengan menempatkan titik data yang nilainya kurang dari <br/> Split Position ke dalam diagram kedua. |
