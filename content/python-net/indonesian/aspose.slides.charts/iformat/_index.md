## IFormat kelas

Mewakili properti format diagram.

Tipe IFormat mengekspos anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`fill`](/slides/python-net/id/aspose.slides.charts/iformat/fill/) | Mengembalikan properti gaya isi dari diagram.<br/>            Hanya-baca [`IFillFormat`](/slides/python-net/id/aspose.slides/ifillformat). |
| [`line`](/slides/python-net/id/aspose.slides.charts/iformat/line/) | Mengembalikan properti gaya garis dari diagram.<br/>            Hanya-baca [`ILineFormat`](/slides/python-net/id/aspose.slides/ilineformat). |
| [`effect`](/slides/python-net/id/aspose.slides.charts/iformat/effect/) | Mengembalikan efek yang digunakan untuk diagram.<br/>            Hanya-baca [`IEffectFormat`](/slides/python-net/id/aspose.slides/ieffectformat). |
| [`effect_3d`](/slides/python-net/id/aspose.slides.charts/iformat/effect_3d/) | Mengembalikan format 3D dari diagram.<br/>            Hanya-baca [`IThreeDFormat`](/slides/python-net/id/aspose.slides/ithreedformat). |
