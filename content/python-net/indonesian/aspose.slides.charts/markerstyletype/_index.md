## MarkerStyleType enumerasi

Menentukan bentuk penanda pada titik data grafik.

Tipe MarkerStyleType menampilkan anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| NOT_DEFINED |  |
| CIRCLE | Menentukan sebuah lingkaran akan digambar pada setiap titik data. |
| DASH | Menentukan sebuah dash akan digambar pada setiap titik data. |
| DIAMOND | Menentukan sebuah belah ketupat akan digambar pada setiap titik data. |
| DOT | Menentukan sebuah titik akan digambar pada setiap titik data. |
| NONE | Menentukan tidak ada yang akan digambar pada setiap titik data. |
| PICTURE | Menentukan sebuah gambar akan digambar pada setiap titik data. |
| PLUS | Menentukan sebuah tanda plus akan digambar pada setiap titik data. |
| SQUARE | Menentukan sebuah persegi akan digambar pada setiap titik data. |
| STAR | Menentukan sebuah bintang akan digambar pada setiap titik data. |
| TRIANGLE | Menentukan sebuah segitiga akan digambar pada setiap titik data. |
| X | Menentukan sebuah X akan digambar pada setiap titik data. |
