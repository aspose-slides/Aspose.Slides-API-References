## Kelas IChartParagraphFormat

Mewakili properti pemformatan paragraf dari sebuah bagan.

Tipe IChartParagraphFormat menampilkan anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`alignment`](/slides/python-net/id/aspose.slides.charts/ichartparagraphformat/alignment/) | Mengembalikan atau mengatur perataan teks dalam sebuah paragraf.<br/>            Baca/tulis [`TextAlignment`](/slides/python-net/id/aspose.slides/textalignment). |
| [`space_within`](/slides/python-net/id/aspose.slides.charts/ichartparagraphformat/space_within/) | Mengembalikan atau mengatur jarak ruang antara garis dasar dalam sebuah paragraf.<br/>            Baca/tulis **float**. |
| [`space_before`](/slides/python-net/id/aspose.slides.charts/ichartparagraphformat/space_before/) | Mengembalikan atau mengatur jarak ruang sebelum baris pertama dalam sebuah paragraf.<br/>            Baca/tulis **float**. |
| [`space_after`](/slides/python-net/id/aspose.slides.charts/ichartparagraphformat/space_after/) | Mengembalikan atau mengatur jarak ruang setelah baris terakhir dalam sebuah paragraf.<br/>            Baca/tulis **float**. |
| [`east_asian_line_break`](/slides/python-net/id/aspose.slides.charts/ichartparagraphformat/east_asian_line_break/) | Menentukan apakah pemutus baris Asia Timur digunakan dalam sebuah paragraf.<br/>            Baca/tulis [`NullableBool`](/slides/python-net/id/aspose.slides/nullablebool). |
| [`right_to_left`](/slides/python-net/id/aspose.slides.charts/ichartparagraphformat/right_to_left/) | Menentukan apakah penulisan Dari Kanan ke Kiri digunakan dalam sebuah paragraf.<br/>            Baca/tulis [`NullableBool`](/slides/python-net/id/aspose.slides/nullablebool). |
| [`latin_line_break`](/slides/python-net/id/aspose.slides.charts/ichartparagraphformat/latin_line_break/) | Menentukan apakah pemutus baris Latin digunakan dalam sebuah paragraf.<br/>            Baca/tulis [`NullableBool`](/slides/python-net/id/aspose.slides/nullablebool). |
| [`hanging_punctuation`](/slides/python-net/id/aspose.slides.charts/ichartparagraphformat/hanging_punctuation/) | Menentukan apakah tanda baca menggantung digunakan dalam sebuah paragraf.<br/>            Baca/tulis [`NullableBool`](/slides/python-net/id/aspose.slides/nullablebool). |
| [`margin_left`](/slides/python-net/id/aspose.slides.charts/ichartparagraphformat/margin_left/) | Mengembalikan atau mengatur margin kiri dalam sebuah paragraf.<br/>            Baca/tulis **float**. |
| [`margin_right`](/slides/python-net/id/aspose.slides.charts/ichartparagraphformat/margin_right/) | Mengembalikan atau mengatur margin kanan dalam sebuah paragraf.<br/>            Baca/tulis **float**. |
| [`indent`](/slides/python-net/id/aspose.slides.charts/ichartparagraphformat/indent/) | Mengembalikan atau mengatur Inden Baris Pertama/Inden Menggantung paragraf. Inden Menggantung dapat didefinisikan dengan nilai negatif.<br/>            Baca/tulis **float**. |
| [`default_tab_size`](/slides/python-net/id/aspose.slides.charts/ichartparagraphformat/default_tab_size/) | Mengembalikan atau mengatur ukuran tabulasi default.<br/>            Baca/tulis **float**. |
| [`tabs`](/slides/python-net/id/aspose.slides.charts/ichartparagraphformat/tabs/) | Mengembalikan tabulasi sebuah paragraf.<br/>            Baca-saja [`ITabCollection`](/slides/python-net/id/aspose.slides/itabcollection). |
| [`font_alignment`](/slides/python-net/id/aspose.slides.charts/ichartparagraphformat/font_alignment/) | Mengembalikan atau mengatur perataan font dalam sebuah paragraf.<br/>            Baca/tulis [`FontAlignment`](/slides/python-net/id/aspose.slides/fontalignment). |
