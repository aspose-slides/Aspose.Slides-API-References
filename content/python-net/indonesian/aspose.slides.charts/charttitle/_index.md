## ChartTitle kelas

Mewakili properti judul bagan.

Tipe ChartTitle mengekspos anggota berikut:

## Properti

| Property | Description |
| :- | :- |
| [`x`](/slides/python-net/id/aspose.slides.charts/charttitle/x/) | Mengembalikan atau mengatur koordinat x dari judul sebagai pecahan lebar bagan.<br/>            Baca/tulis **float**. |
| [`y`](/slides/python-net/id/aspose.slides.charts/charttitle/y/) | Mengembalikan atau mengatur koordinat y dari judul sebagai pecahan tinggi bagan.<br/>            Baca/tulis **float**. |
| [`width`](/slides/python-net/id/aspose.slides.charts/charttitle/width/) | Mengembalikan atau mengatur lebar judul sebagai pecahan lebar bagan.<br/>            Baca/tulis **float**. |
| [`height`](/slides/python-net/id/aspose.slides.charts/charttitle/height/) | Mengembalikan atau mengatur tinggi judul sebagai pecahan tinggi bagan.<br/>            Baca/tulis **float**. |
| [`right`](/slides/python-net/id/aspose.slides.charts/charttitle/right/) | Kanan.<br/>            Baca-saja **float**. |
| [`bottom`](/slides/python-net/id/aspose.slides.charts/charttitle/bottom/) | Bawah.<br/>            Baca-saja **float**. |
| [`overlay`](/slides/python-net/id/aspose.slides.charts/charttitle/overlay/) | Menentukan apakah elemen bagan lain diizinkan menimpa judul.<br/>            Baca/tulis **bool**. |
| [`format`](/slides/python-net/id/aspose.slides.charts/charttitle/format/) | Mengembalikan gaya isi, garis, efek dari judul.<br/>            Baca-saja [`IFormat`](/slides/python-net/id/aspose.slides.charts/iformat). |
| [`text_frame_for_overriding`](/slides/python-net/id/aspose.slides.charts/charttitle/text_frame_for_overriding/) | Dapat berisi teks terformat kaya. Jika properti ini tidak None maka nilai teks terformat ini menggantikan teks yang dihasilkan secara otomatis.<br/>            Teks yang dihasilkan secara otomatis adalah properti implisit dari label data, label unit tampilan dari sumbu nilai, judul sumbu, judul bagan, label garis tren.<br/>            Teks yang dihasilkan secara otomatis diformat dengan properti IFormattedTextContainer.TextFormat.<br/>            Baca-saja [`ITextFrame`](/slides/python-net/id/aspose.slides/itextframe). |
| [`text_format`](/slides/python-net/id/aspose.slides.charts/charttitle/text_format/) | Mengembalikan format teks.<br/>            Baca-saja [`IChartTextFormat`](/slides/python-net/id/aspose.slides.charts/icharttextformat). |
| [`actual_x`](/slides/python-net/id/aspose.slides.charts/charttitle/actual_x/) | Menentukan lokasi x aktual (kiri) dari elemen bagan relatif terhadap sudut kiri atas bagan.<br/>            Panggil metode IChart.ValidateChartLayout() terlebih dahulu untuk mendapatkan nilai aktual. <br/>            Baca **float**. |
| [`actual_y`](/slides/python-net/id/aspose.slides.charts/charttitle/actual_y/) | Menentukan posisi atas aktual dari elemen bagan relatif terhadap sudut kiri atas bagan.<br/>            Panggil metode IChart.ValidateChartLayout() terlebih dahulu untuk mendapatkan nilai aktual. <br/>            Baca **float**. |
| [`actual_width`](/slides/python-net/id/aspose.slides.charts/charttitle/actual_width/) | Menentukan lebar aktual elemen bagan. Panggil metode IChart.ValidateChartLayout() terlebih dahulu untuk mendapatkan nilai aktual. <br/>            Baca **float**. |
| [`actual_height`](/slides/python-net/id/aspose.slides.charts/charttitle/actual_height/) | Menentukan tinggi aktual elemen bagan. Panggil metode IChart.ValidateChartLayout() terlebih dahulu untuk mendapatkan nilai aktual. <br/>            Baca **float**. |
| [`chart`](/slides/python-net/id/aspose.slides.charts/charttitle/chart/) | Mengembalikan bagan induk.<br/>            Baca-saja [`IChart`](/slides/python-net/id/aspose.slides.charts/ichart). |
