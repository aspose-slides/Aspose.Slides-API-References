## enumerasi TrendlineType

Mewakili tipe garis tren

Tipe TrendlineType menampilkan anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| EXPONENTIAL | Menentukan bahwa trendline harus berupa kurva eksponensial dalam bentuk. |
| LINEAR | Menentukan bahwa trendline harus berupa garis dalam bentuk. |
| LOGARITHMIC | Menentukan bahwa trendline harus berupa kurva logaritmik dalam bentuk, dimana log adalah logaritma natural. |
| MOVING_AVERAGE | Menentukan bahwa trendline harus berupa rata-rata bergerak dengan periode Period. |
| POLYNOMIAL | Menentukan bahwa trendline harus berupa kurva polinomial dengan urutan Order dalam bentuk. |
| POWER | Menentukan bahwa trendline harus berupa kurva pangkat dalam bentuk. |
