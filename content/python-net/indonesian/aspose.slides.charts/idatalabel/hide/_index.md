## hide(self) {#}
Membuat label data tersembunyi dengan mengatur semua flag Show*- (ShowValue, ...) ke status false.
IsVisible akan menjadi false setelah ini.


```python
def hide(self):
    ...
```


### Catatan

Jika label data tidak terlihat (IsVisible false) Anda dapat membuat label data terlihat dengan mengatur flag Show*- (ShowValue, ...) ke status true.
