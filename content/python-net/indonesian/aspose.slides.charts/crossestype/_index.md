## enumerasi CrossesType

Menentukan di mana sumbu akan melintasi.

Tipe CrossesType menampilkan anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| AXIS_CROSSES_AT_ZERO | Sumbu kategori melintasi pada titik nol sumbu nilai (jika memungkinkan), atau nilai minimum (jika minimum lebih besar dari nol) atau maksimum (jika maksimum kurang dari nol). |
| MAXIMUM | Sumbu melintasi pada nilai maksimum. |
| CUSTOM | Nilai khusus dari properti CrossAt |
