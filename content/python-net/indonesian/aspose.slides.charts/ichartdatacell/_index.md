## IChartDataCell kelas

Mewakili sel untuk data bagan.

Tipe IChartDataCell menampilkan anggota berikut:

## Properti

| Property | Description |
| :- | :- |
| [`row`](/slides/python-net/id/aspose.slides.charts/ichartdatacell/row/) | Mengembalikan indeks baris worksheet di mana sel berada.<br/>            Hanya-baca **int**. |
| [`column`](/slides/python-net/id/aspose.slides.charts/ichartdatacell/column/) | Mengembalikan indeks kolom worksheet di mana sel berada.<br/>            Hanya-baca **int**. |
| [`value`](/slides/python-net/id/aspose.slides.charts/ichartdatacell/value/) | Mendapatkan atau mengatur nilai sel.<br/>            Baca/tulis **any**. |
| [`formula`](/slides/python-net/id/aspose.slides.charts/ichartdatacell/formula/) | Mendapatkan atau mengatur rumus dalam gaya A1. |
| [`r1c1_formula`](/slides/python-net/id/aspose.slides.charts/ichartdatacell/r1c1_formula/) | Mendapatkan atau mengatur rumus dalam gaya R1C1. |
| [`chart_data_worksheet`](/slides/python-net/id/aspose.slides.charts/ichartdatacell/chart_data_worksheet/) | Mendapatkan worksheet.<br/>            Hanya-baca [`IChartDataWorksheet`](/slides/python-net/id/aspose.slides.charts/ichartdataworksheet). |
| [`is_hidden`](/slides/python-net/id/aspose.slides.charts/ichartdatacell/is_hidden/) | Menentukan apakah sel tersembunyi.<br/>            Hanya-baca **bool**. |
| [`custom_number_format`](/slides/python-net/id/aspose.slides.charts/ichartdatacell/custom_number_format/) | Mendapatkan atau mengatur format tampilan khusus untuk angka dan tanggal. <br/>            Jika nilai kosong akan digunakan nilai PresetNumberFormat.<br/>            Baca/tulis **str**. |
| [`preset_number_format`](/slides/python-net/id/aspose.slides.charts/ichartdatacell/preset_number_format/) | Mendapatkan atau mengatur format tampilan bawaan untuk angka dan tanggal. Nomor preset harus berada dalam [0..22] atau [37..49].<br/>             Baca/tulis **int**. |

## Metode
