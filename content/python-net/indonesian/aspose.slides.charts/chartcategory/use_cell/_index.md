## use_cell properti
If true maka properti AsCell berlaku. Dengan kata lain, worksheet digunakan untuk  
            menyimpan kategori (kasus ini mendukung kategori multi-tingkat).  
            Jika false maka properti AsLiteral berlaku. Dengan kata lain, worksheet TIDAK digunakan  
            untuk menyimpan kategori (dan kasus ini tidak mendukung kategori multi-tingkat).  
            Hanya-baca **bool**.

### Keterangan

Untuk mengubah nilai properti ini (untuk semua kategori dalam koleksi) setel nilai baru ke properti ChartCategoryCollection.UseCells.
