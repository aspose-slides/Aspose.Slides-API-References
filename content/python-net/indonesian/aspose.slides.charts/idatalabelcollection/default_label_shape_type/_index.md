## default_label_shape_type properti
Mendapatkan atau menetapkan jenis bentuk default untuk label data.
             Mengembalikan [`ShapeType.NOT_DEFINED`](/slides/python-net/id/aspose.slides/shapetype/NOT_DEFINED) jika tidak ada bentuk yang didefinisikan.


### Catatan

Menetapkan properti ini juga menetapkan properti [`IDataLabel.label_shape_type`](/slides/python-net/id/aspose.slides.charts/idatalabel/label_shape_type) untuk semua label data dalam koleksi ke nilai yang sama.
