## hide(self) {#}
Buat label data tersembunyi secara default dengan mengatur semua Show*-flags (ShowValue, ...) dari 
            properti DefaultDataLabelFormat ke keadaan false.
            IsVisible akan menjadi false setelah ini.

```python
def hide(self):
    ...
```

### Catatan

Jika label data tidak terlihat secara default (IsVisible false) Anda dapat membuat label data "terlihat 
            secara default" dengan mengatur Show*-flags (ShowValue, ...) dari properti DefaultDataLabelFormat
            ke keadaan true.
