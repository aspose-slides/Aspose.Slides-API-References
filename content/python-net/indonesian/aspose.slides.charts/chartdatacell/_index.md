## ChartDataCell kelas

Mewakili sel untuk data diagram.

Tipe ChartDataCell mengekspos anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`row`](/slides/python-net/id/aspose.slides.charts/chartdatacell/row/) | Mengembalikan indeks baris worksheet tempat sel berada.<br/>            Baca-saja **int**. |
| [`column`](/slides/python-net/id/aspose.slides.charts/chartdatacell/column/) | Mengembalikan indeks kolom worksheet tempat sel berada.<br/>            Baca-saja **int**. |
| [`value`](/slides/python-net/id/aspose.slides.charts/chartdatacell/value/) | Mendapatkan atau menetapkan nilai sel.<br/>            Baca/tulis **any**. |
| [`formula`](/slides/python-net/id/aspose.slides.charts/chartdatacell/formula/) | Mendapatkan atau menetapkan rumus dalam gaya A1. |
| [`r1c1_formula`](/slides/python-net/id/aspose.slides.charts/chartdatacell/r1c1_formula/) | Mendapatkan atau menetapkan rumus dalam gaya R1C1. |
| [`chart_data_worksheet`](/slides/python-net/id/aspose.slides.charts/chartdatacell/chart_data_worksheet/) | Mendapatkan worksheet.<br/>            Baca-saja [`IChartDataWorksheet`](/slides/python-net/id/aspose.slides.charts/ichartdataworksheet). |
| [`is_hidden`](/slides/python-net/id/aspose.slides.charts/chartdatacell/is_hidden/) | Menentukan apakah sel disembunyikan.<br/>            Baca-saja **bool**. |
| [`custom_number_format`](/slides/python-net/id/aspose.slides.charts/chartdatacell/custom_number_format/) | Mendapatkan atau menetapkan format tampilan khusus untuk angka dan tanggal. <br/>            Jika nilai kosong, akan digunakan nilai PresetNumberFormat.<br/>            Baca/tulis **str**. |
| [`preset_number_format`](/slides/python-net/id/aspose.slides.charts/chartdatacell/preset_number_format/) | Mendapatkan atau menetapkan format tampilan bawaan untuk angka dan tanggal. Nomor preset harus berada dalam [0..22] atau [37..49].<br/>             Baca/tulis **int**. |

## Metode

| Metode | Deskripsi |
| :- | :- |
| [`calculate(self, update_values)`](/slides/python-net/id/aspose.slides.charts/chartdatacell/calculate/#bool) | Jika sel berisi rumus, nilai akan diperbarui berdasarkan rumus tersebut. |
