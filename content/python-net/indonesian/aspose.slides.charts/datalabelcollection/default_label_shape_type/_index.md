## default_label_shape_type properti
Mendapatkan atau mengatur tipe bentuk default untuk label data.
             Mengembalikan [`ShapeType.NOT_DEFINED`](/slides/python-net/id/aspose.slides/shapetype/NOT_DEFINED) jika tidak ada bentuk yang didefinisikan.

### Catatan

Mengatur properti ini juga mengatur [`IDataLabel.label_shape_type`](/slides/python-net/id/aspose.slides.charts/idatalabel/label_shape_type) properti
             untuk semua label data dalam koleksi ke nilai yang sama.
