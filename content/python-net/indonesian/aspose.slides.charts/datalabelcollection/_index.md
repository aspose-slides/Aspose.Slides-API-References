## DataLabelCollection kelas

Mewakili label seri.

Tipe DataLabelCollection menampilkan anggota-anggota berikut:

## Properti

| Property | Deskripsi |
| :- | :- |
| [`chart`](/slides/python-net/id/aspose.slides.charts/datalabelcollection/chart/) | Mengembalikan chart induk.<br/>            Hanya-baca [`IChart`](/slides/python-net/id/aspose.slides.charts/ichart). |
| [`is_visible`](/slides/python-net/id/aspose.slides.charts/datalabelcollection/is_visible/) | False berarti label data tidak terlihat secara default (dan sehingga semua <br/>            Show*-flags (ShowValue, ...) dari properti DefaultDataLabelFormat bernilai false).<br/>            Hanya-baca **bool**. |
| [`count_of_visible_data_labels`](/slides/python-net/id/aspose.slides.charts/datalabelcollection/count_of_visible_data_labels/) | Mendapatkan jumlah label data yang terlihat dalam koleksi.<br/>            Hanya-baca **int**. |
| [`count`](/slides/python-net/id/aspose.slides.charts/datalabelcollection/count/) | Mendapatkan jumlah semua label data dalam koleksi.<br/>            Hanya-baca **int**. |
| [`default_data_label_format`](/slides/python-net/id/aspose.slides.charts/datalabelcollection/default_data_label_format/) | Mendapatkan format label data default.<br/>            Hanya-baca [`IDataLabelFormat`](/slides/python-net/id/aspose.slides.charts/idatalabelformat). |
| [`leader_lines_format`](/slides/python-net/id/aspose.slides.charts/datalabelcollection/leader_lines_format/) | Mewakili format garis pemimpin label data.<br/>             Hanya-baca [`IChartLinesFormat`](/slides/python-net/id/aspose.slides.charts/ichartlinesformat). |
| [`parent_series`](/slides/python-net/id/aspose.slides.charts/datalabelcollection/parent_series/) | Mendapatkan seri induk.<br/>            Hanya-baca [`IChartSeries`](/slides/python-net/id/aspose.slides.charts/ichartseries). |
| [`slide`](/slides/python-net/id/aspose.slides.charts/datalabelcollection/slide/) |  |
| [`presentation`](/slides/python-net/id/aspose.slides.charts/datalabelcollection/presentation/) |  |

Mendapatkan label data untuk titik data dengan indeks yang ditentukan.
