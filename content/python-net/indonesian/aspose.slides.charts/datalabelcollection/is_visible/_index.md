## is_visible properti
False berarti label data tidak terlihat secara default (dan sehingga semua 
            Show*-flags (ShowValue, ...) dari properti DefaultDataLabelFormat adalah false).
            Hanya-baca **bool**.

### Catatan

Jika label data terlihat secara default Anda dapat menyembunyikannya secara default dengan metode Hide().
            Tetapi jika label data tidak terlihat secara default (IsVisible adalah false) Anda dapat menjadikan label data "terlihat 
            secara default" dengan mengatur Show*-flags (ShowValue, ...) dari properti DefaultDataLabelFormat
            ke keadaan true.
