## properti is_visible
False berarti bahwa label data tidak terlihat secara default (dan sehingga semua Show*-flags (ShowValue, ...) dari DefaultDataLabelFormat properti bernilai false).
Baca-saja **bool**.

### Catatan

Jika label data terlihat secara default, Anda dapat menjadikannya tersembunyi secara default dengan metode Hide().
            Namun jika label data tidak terlihat secara default (IsVisible false) Anda dapat menjadikan label data "terlihat 
            secara default" dengan mengatur Show*-flags (ShowValue, ...) dari DefaultDataLabelFormat properti
            ke keadaan true.
