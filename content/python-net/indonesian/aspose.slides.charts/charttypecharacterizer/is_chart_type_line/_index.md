## is_chart_type_line(chart_type) {#charttype}
Mengembalikan true jika chartType adalah salah satu subtipe Line.
            Subtype set sesuai dengan set yang tepat di PowerPoint (lihat dialog "Change Chart Type" di PowerPoint):
            [`ChartType.LINE`](/slides/python-net/id/aspose.slides.charts/charttype/LINE),
            [`ChartType.LINE_WITH_MARKERS`](/slides/python-net/id/aspose.slides.charts/charttype/LINE_WITH_MARKERS),
            [`ChartType.PERCENTS_STACKED_LINE`](/slides/python-net/id/aspose.slides.charts/charttype/PERCENTS_STACKED_LINE),
            [`ChartType.PERCENTS_STACKED_LINE_WITH_MARKERS`](/slides/python-net/id/aspose.slides.charts/charttype/PERCENTS_STACKED_LINE_WITH_MARKERS),
            [`ChartType.STACKED_LINE`](/slides/python-net/id/aspose.slides.charts/charttype/STACKED_LINE),
            [`ChartType.STACKED_LINE_WITH_MARKERS`](/slides/python-net/id/aspose.slides.charts/charttype/STACKED_LINE_WITH_MARKERS),
            [`ChartType.LINE_3D`](/slides/python-net/id/aspose.slides.charts/charttype/LINE_3D).
