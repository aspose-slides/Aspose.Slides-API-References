## is_chart_type_scatter(chart_type) {#charttype}
Mengembalikan true jika chartType adalah salah satu subtipe Scatter.
            Set subtipe sesuai dengan set yang tepat di PowerPoint (lihat dialog "Change Chart Type" di PowerPoint):
            [`ChartType.SCATTER_WITH_MARKERS`](/slides/python-net/id/aspose.slides.charts/charttype/SCATTER_WITH_MARKERS),
            [`ChartType.SCATTER_WITH_SMOOTH_LINES`](/slides/python-net/id/aspose.slides.charts/charttype/SCATTER_WITH_SMOOTH_LINES),
            [`ChartType.SCATTER_WITH_SMOOTH_LINES_AND_MARKERS`](/slides/python-net/id/aspose.slides.charts/charttype/SCATTER_WITH_SMOOTH_LINES_AND_MARKERS),
            [`ChartType.SCATTER_WITH_STRAIGHT_LINES`](/slides/python-net/id/aspose.slides.charts/charttype/SCATTER_WITH_STRAIGHT_LINES),
            [`ChartType.SCATTER_WITH_STRAIGHT_LINES_AND_MARKERS`](/slides/python-net/id/aspose.slides.charts/charttype/SCATTER_WITH_STRAIGHT_LINES_AND_MARKERS).
