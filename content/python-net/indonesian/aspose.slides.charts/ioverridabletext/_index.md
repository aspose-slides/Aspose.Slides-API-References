## IOverridableText kelas

Mewakili teks yang dapat ditimpa untuk sebuah diagram.

Tipe IOverridableText menampilkan anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`text_frame_for_overriding`](/slides/python-net/id/aspose.slides.charts/ioverridabletext/text_frame_for_overriding/) | Dapat berisi teks berformat kaya. Jika properti ini bukan None maka nilai teks berformat ini menimpa teks yang dihasilkan secara otomatis.<br/>            Teks yang dihasilkan secara otomatis adalah properti implisit dari label data, label unit tampilan pada sumbu nilai, judul sumbu, judul diagram, label garis tren.<br/>            Teks yang dihasilkan secara otomatis diformat dengan properti IFormattedTextContainer.TextFormat.<br/>            Hanya-baca [`ITextFrame`](/slides/python-net/id/aspose.slides/itextframe). |
| [`text_format`](/slides/python-net/id/aspose.slides.charts/ioverridabletext/text_format/) |  |
| [`chart`](/slides/python-net/id/aspose.slides.charts/ioverridabletext/chart/) |  |
