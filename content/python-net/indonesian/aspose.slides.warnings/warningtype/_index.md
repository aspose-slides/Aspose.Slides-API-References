## enumerasi WarningType

Mewakili jenis peringatan.

Tipe WarningType menampilkan anggota-anggota berikut:

## Bidang

| Bidang | Deskripsi |
| :- | :- |
| SOURCE_FILE_CORRUPTION | Masalah terdeteksi dalam dokumen sumber yang membuat sangat mungkin dokumen tidak dapat dibuka jika disimpan dalam format aslinya. |
| DATA_LOSS | Teks/diagram/gambar atau data lainnya akan sepenuhnya hilang baik dari pohon dokumen setelah pemuatan, atau dari dokumen yang dibuat setelah penyimpanan. |
| MAJOR_FORMATTING_LOSS | Kehilangan format utama. |
| MINOR_FORMATTING_LOSS | Kehilangan format kecil. |
| COMPATIBILITY_ISSUE | Ini adalah masalah yang diketahui yang akan mencegah dokumen dibuka oleh agen pengguna tertentu, atau versi sebelumnya dari agen pengguna. |
| UNEXPECTED_CONTENT | Beberapa konten dalam dokumen sumber tidak dapat dikenali (misalnya tidak didukung), hal ini mungkin menyebabkan masalah atau tidak, atau mengakibatkan kehilangan data/format. |
