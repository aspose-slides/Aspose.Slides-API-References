## IWarningInfo kelas

Mewakili antarmuka dasar untuk semua peringatan.

Tipe IWarningInfo mengekspos anggota-anggota berikut:

## Properti

| Property | Description |
| :- | :- |
| [`warning_type`](/slides/python-net/id/aspose.slides.warnings/iwarninginfo/warning_type/) | Mengembalikan tipe peringatan.<br/>            Hanya-baca [`IWarningInfo.warning_type`](/slides/python-net/id/aspose.slides.warnings/iwarninginfo/warning_type). |
| [`description`](/slides/python-net/id/aspose.slides.warnings/iwarninginfo/description/) | Mengembalikan deskripsi yang dapat dibaca manusia untuk peringatan ini.<br/>            Hanya-baca **str**. |

| Method | Description |
| :- | :- |
| [`send_warning(self, receiver)`](/slides/python-net/id/aspose.slides.warnings/iwarninginfo/send_warning/#iwarningcallback) | Jika receiver tidak None mengakhiri peringatan ke receiver yang ditentukan dan melempar AbortRequestedException jika receiver memutuskan untuk abort operasi. |
