## ExcelDataCell kelas

Mewakili satu sel dalam buku kerja Excel.

Tipe ExcelDataCell menampilkan anggota-anggota berikut:

## Properti

| Properti | Deskripsi |
| :- | :- |
| [`value`](/slides/python-net/id/aspose.slides.excel/exceldatacell/value/) | Mengambil nilai yang terdapat dalam sel Excel. |
| [`name`](/slides/python-net/id/aspose.slides.excel/exceldatacell/name/) | Mengambil nama sel data grafik. |
| [`row`](/slides/python-net/id/aspose.slides.excel/exceldatacell/row/) | Mengambil indeks berbasis nol baris di lembar kerja tempat sel berada.<br/>            Hanya-baca **int**. |
| [`column`](/slides/python-net/id/aspose.slides.excel/exceldatacell/column/) | Mengambil indeks berbasis nol kolom di lembar kerja tempat sel berada.<br/>            Hanya-baca **int**. |
