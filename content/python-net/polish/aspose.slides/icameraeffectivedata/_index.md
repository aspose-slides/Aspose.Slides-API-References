## ICameraEffectiveData klasa

Niezmienny obiekt, który zawiera efektywne właściwości kamery.

Typ ICameraEffectiveData udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`camera_type`](/slides/python-net/pl/aspose.slides/icameraeffectivedata/camera_type/) | Typ kamery.<br/>            tylko do odczytu [`CameraPresetType`](/slides/python-net/pl/aspose.slides/camerapresettype). |
| [`field_of_view_angle`](/slides/python-net/pl/aspose.slides/icameraeffectivedata/field_of_view_angle/) | Kąt widzenia kamery (0-180 deg, field of View).<br/>            tylko do odczytu **float**. |
| [`zoom`](/slides/python-net/pl/aspose.slides/icameraeffectivedata/zoom/) | Zoom kamery (wartość dodatnia w procentach).<br/>            tylko do odczytu **float**. |

## Metody

| Metoda | Opis |
| :- | :- |
| [`get_rotation(self)`](/slides/python-net/pl/aspose.slides/icameraeffectivedata/get_rotation/#) | Rotacja jest określana przy użyciu współrzędnej szerokości geograficznej<br/>            współrzędnej długości geograficznej oraz obrotu wokół osi <br/>            określanych przez współrzędne szerokości i długości.<br/>            pierwszy element w zwracanej tablicy – szerokość, drugi – długość, trzeci – obrót.<br/>            Zwraca None, jeśli nie zdefiniowano rotacji. |


### Uwagi
