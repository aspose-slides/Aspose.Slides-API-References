## ShapeElementFillSource enumeracja

Reprezentuje sposób wypełniania elementu kształtu.

Typ ShapeElementFillSource udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| NO_FILL | Nie wypełnia prymitywu. |
| SHAPE | Użyj wypełnienia kształtu. |
| LIGHTEN | Użyj rozjaśnionego wypełnienia kształtu. |
| LIGHTEN_LESS | Użyj mniej rozjaśnionego wypełnienia kształtu. |
| DARKEN | Użyj przyciemnionego wypełnienia kształtu. |
| DARKEN_LESS | Użyj mniej przyciemnionego wypełnienia kształtu. |
