## IGradientFormatEffectiveData klasa

Niezmienny obiekt, który zawiera efektywne właściwości wypełnienia gradientem.

Typ IGradientFormatEffectiveData udostępnia następujące członków:

## Właściwości

| Property | Description |
| :- | :- |
| [`tile_flip`](/slides/python-net/pl/aspose.slides/igradientformateffectivedata/tile_flip/) | Zwraca tryb odbicia dla gradientu.<br/>            Tylko do odczytu [`TileFlip`](/slides/python-net/pl/aspose.slides/tileflip). |
| [`gradient_direction`](/slides/python-net/pl/aspose.slides/igradientformateffectivedata/gradient_direction/) | Zwraca styl gradientu.<br/>            Tylko do odczytu [`GradientDirection`](/slides/python-net/pl/aspose.slides/gradientdirection). |
| [`linear_gradient_angle`](/slides/python-net/pl/aspose.slides/igradientformateffectivedata/linear_gradient_angle/) | Zwraca kąt gradientu.<br/>            Tylko do odczytu **float**. |
| [`linear_gradient_scaled`](/slides/python-net/pl/aspose.slides/igradientformateffectivedata/linear_gradient_scaled/) | Określa, czy gradient jest skalowany.<br/>            Tylko do odczytu **bool**. |
| [`gradient_shape`](/slides/python-net/pl/aspose.slides/igradientformateffectivedata/gradient_shape/) | Zwraca kształt gradientu.<br/>            Tylko do odczytu [`GradientShape`](/slides/python-net/pl/aspose.slides/gradientshape). |
| [`gradient_stops`](/slides/python-net/pl/aspose.slides/igradientformateffectivedata/gradient_stops/) | Zwraca kolekcję punktów gradientu.<br/>            Tylko do odczytu [`IGradientStopCollectionEffectiveData`](/slides/python-net/pl/aspose.slides/igradientstopcollectioneffectivedata). |
