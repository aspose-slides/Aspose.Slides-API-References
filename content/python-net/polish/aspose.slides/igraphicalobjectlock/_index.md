## IGraphicalObjectLock klasa

Określa, które operacje są wyłączone w rodzicu GraphicalObjectEx.

Typ IGraphicalObjectLock udostępnia następujące elementy:

| Właściwość | Opis |
| :- | :- |
| [`grouping_locked`](/slides/python-net/pl/aspose.slides/igraphicalobjectlock/grouping_locked/) | Określa, czy dodawanie tego kształtu do grupy jest zabronione.<br/>            Odczyt/zapis **bool**. |

| [`aspect_ratio_locked`](/slides/python-net/pl/aspose.slides/igraphicalobjectlock/aspect_ratio_locked/) | Określa, czy kształt musi zachować proporcje podczas zmiany rozmiaru.<br/>            Odczyt/zapis **bool**. |
| [`position_locked`](/slides/python-net/pl/aspose.slides/igraphicalobjectlock/position_locked/) | Określa, czy przemieszczanie tego kształtu jest zabronione.<br/>            Odczyt/zapis **bool**. |
