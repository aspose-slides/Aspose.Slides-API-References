## width właściwość
Pobiera lub ustawia width kształtu, mierzoną w punktach.
            Odczyt/zapis **float**.


### Uwagi

Zwracana wartość jest zawsze określona i nigdy nie jest **float**.
            Przypisywana wartość musi również być określona; przypisuj **float** wyłącznie do właściwości instancji `RawFrame`.
