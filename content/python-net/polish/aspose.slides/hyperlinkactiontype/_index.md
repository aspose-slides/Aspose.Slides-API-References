## HyperlinkActionType enumeracja

Reprezentuje typ działania hiperłącza.

Typ HyperlinkActionType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| UNKNOWN | Nierozpoznany typ działania. |
| NO_ACTION | Brak działania. |
| HYPERLINK | Zwykłe hiperłącze. |
| JUMP_FIRST_SLIDE | Przejdź do pierwszego slajdu prezentacji. |
| JUMP_PREVIOUS_SLIDE | Przejdź do poprzedniego slajdu. |
| JUMP_NEXT_SLIDE | Przejdź do następnego slajdu. |
| JUMP_LAST_SLIDE | Przejdź do ostatniego slajdu prezentacji. |
| JUMP_END_SHOW | Przejdź do końca pokazu slajdów. |
| JUMP_LAST_VIEWED_SLIDE | Przejdź do ostatnio wyświetlanego slajdu. |
| JUMP_SPECIFIC_SLIDE | Przejdź do określonego slajdu, odwołując się do właściwości [`IHyperlink.target_slide`](/slides/python-net/pl/aspose.slides/ihyperlink/target_slide). |
| START_CUSTOM_SLIDE_SHOW | Rozpocznij niestandardowy pokaz slajdów. |
| OPEN_FILE | Otwórz odwołany plik. |
| OPEN_PRESENTATION | Otwórz odwołaną prezentację. |
| START_STOP_MEDIA | Rozpocznij/zatrzymaj odtwarzanie pliku multimedialnego. |
| START_MACRO | Rozpocznij wykonywanie skryptu makra. |
| START_PROGRAM | Uruchom program. |
