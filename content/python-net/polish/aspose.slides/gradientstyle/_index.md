## enumeracja GradientStyle

Reprezentuje dostępne style gradientu.

Typ GradientStyle udostępnia następujące człony:

## Pola

| Pole | Opis |
| :- | :- |
| DEFAULT | Domyślny styl gradientu. |
| POWER_POINT_UI | Styl gradientu tak jak pojawia się w interfejsie użytkownika PowerPointa. |
