## NumberedBulletStyle enumeracja

Reprezentuje styl numerowanych wypunktowań.

Typ NumberedBulletStyle udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| NOT_DEFINED | Nie określono. |
| BULLET_ALPHA_LC_PERIOD | Małe litery alfabetu z kropką. Przykład: a., b., c., ... |
| BULLET_ALPHA_UC_PERIOD | Wielkie litery alfabetu z kropką. Przykład: A., B., C., ... |
| BULLET_ARABIC_PAREN_RIGHT | Cyfry arabskie z zamykającym nawiasem. Przykład: 1), 2), 3), ... |
| BULLET_ARABIC_PERIOD | Cyfry arabskie z kropką. Przykład: 1., 2., 3., ... |
| BULLET_ROMAN_LC_PAREN_BOTH | Małe liczby rzymskie z oboma nawiasami. Przykład: (i), (ii), (iii), ... |
| BULLET_ROMAN_LC_PAREN_RIGHT | Małe liczby rzymskie z zamykającym nawiasem. Przykład: i), ii), iii), ... |
| BULLET_ROMAN_LC_PERIOD | Małe liczby rzymskie z kropką. Przykład: i., ii., iii., ... |
| BULLET_ROMAN_UC_PERIOD | Wielkie liczby rzymskie z kropką. Przykład: I., II., III., ... |
| BULLET_ALPHA_LC_PAREN_BOTH | Małe litery alfabetu z oboma nawiasami. Przykład: (a), (b), (c), ... |
| BULLET_ALPHA_LC_PAREN_RIGHT | Małe litery alfabetu z zamykającym nawiasem. Przykład: a), b), c), ... |
| BULLET_ALPHA_UC_PAREN_BOTH | Wielkie litery alfabetu z oboma nawiasami. Przykład: (A), (B), (C), ... |
| BULLET_ALPHA_UC_PAREN_RIGHT | Wielkie litery alfabetu z zamykającym nawiasem. Przykład: A), B), C), ... |
| BULLET_ARABIC_PAREN_BOTH | Cyfry arabskie z oboma nawiasami. Przykład: (1), (2), (3), ... |
| BULLET_ARABIC_PLAIN | Cyfry arabskie. Przykład: 1, 2, 3, ... |
| BULLET_ROMAN_UC_PAREN_BOTH | Wielkie liczby rzymskie z oboma nawiasami. Przykład: (I), (II), (III), ... |
| BULLET_ROMAN_UC_PAREN_RIGHT | Wielkie liczby rzymskie z zamykającym nawiasem. Przykład: I), II), III), ... |
| BULLET_SIMP_CHIN_PLAIN | chiński uproszczony bez kropki. |
| BULLET_SIMP_CHIN_PERIOD | chiński uproszczony z kropką. |
| BULLET_CIRCLE_NUM_DB_PLAIN | Dwubajtowa liczba w okręgu dla wartości do 10, od  11 - liczby arabskie. |
| BULLET_CIRCLE_NUM_WD_WHITE_PLAIN | Liczba w kolorze tekstu z takim samym kolorowym okręgiem narysowanym wokół (Wingdings white circle numbers). Od  11 - liczby arabskie. |
| BULLET_CIRCLE_NUM_WD_BLACK_PLAIN | Liczba w kolorze cienia z okrągłym tłem w normalnym kolorze tekstu (Wingdings black circle numbers). |
| BULLET_TRAD_CHIN_PLAIN | chiński tradycyjny bez kropki. |
| BULLET_TRAD_CHIN_PERIOD | chiński tradycyjny z kropką. |
| BULLET_ARABIC_ALPHA_DASH | Alfabet arabskie z myślnikiem. |
| BULLET_ARABIC_ABJAD_DASH | Alfabet Abjad arabskiego z myślnikiem. |
| BULLET_HEBREW_ALPHA_DASH | Alfabet hebrajskie z myślnikiem. |
| BULLET_KANJI_KOREAN_PLAIN | Japońskie/koreańskie liczby bez kropki. |
| BULLET_KANJI_KOREAN_PERIOD | Japońskie/koreańskie liczby z kropką. |
| BULLET_ARABIC_DB_PLAIN | Dwubajtowy schemat numeracji arabskiej (bez interpunkcji). |
| BULLET_ARABIC_DB_PERIOD | Dwubajtowy schemat numeracji arabskiej z dwubajtową kropką. |
| BULLET_THAI_ALPHA_PERIOD | Alfabet tajski z kropką. |
| BULLET_THAI_ALPHA_PAREN_RIGHT | Alfabet tajski nawiasy – prawy. |
| BULLET_THAI_ALPHA_PAREN_BOTH | Alfabet tajski nawiasy – oba. |
| BULLET_THAI_NUM_PERIOD | Cyfry tajskie z kropką. |
| BULLET_THAI_NUM_PAREN_RIGHT | Cyfry tajskie nawiasy – prawy. |
| BULLET_THAI_NUM_PAREN_BOTH | Cyfry tajskie nawiasy – oba. |
| BULLET_HINDI_ALPHA_PERIOD | Alfabet hindi z kropką – samogłoski. |
| BULLET_HINDI_NUM_PERIOD | Cyfry hindi z kropką. |
| BULLET_KANJI_SIMP_CHIN_DB_PERIOD | Kanji chiński uproszczony DBPeriod. |
| BULLET_HINDI_NUM_PAREN_RIGHT | Cyfry hindi nawiasy – prawy. |
| BULLET_HINDI_ALPHA_1_PERIOD | Alfabet hindi z kropką – spółgłoski. |
