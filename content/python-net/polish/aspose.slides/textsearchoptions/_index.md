## TextSearchOptions klasa

Reprezentuje opcje, które mogą być użyte do wyszukiwania tekstu w Presentation, Slide lub TextFrame.

Typ TextSearchOptions udostępnia następujące elementy:

## Konstruktory

| Konstruktor | Opis |
| :- | :- |
| [`__init__(self)`](/slides/python-net/pl/aspose.slides/textsearchoptions/__init__/#) | Tworzy nowe domyślne opcje wyszukiwania tekstu. |

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`case_sensitive`](/slides/python-net/pl/aspose.slides/textsearchoptions/case_sensitive/) | Ustaw true, aby używać wyszukiwania z uwzględnieniem wielkości liter, false – w przeciwnym razie.<br/>            Read/write **bool**. |
| [`whole_words_only`](/slides/python-net/pl/aspose.slides/textsearchoptions/whole_words_only/) | Ustaw true, aby dopasowywać tylko całe słowa, false – w przeciwnym razie.<br/>            Read/write **bool**. |
| [`include_notes`](/slides/python-net/pl/aspose.slides/textsearchoptions/include_notes/) | Ustaw `true`, aby uwzględnić tekst zawarty w notatkach slajdu ([`NotesSlide`](/slides/python-net/pl/aspose.slides/notesslide)) <br/>            podczas wykonywania operacji wyszukiwania tekstu, zamiany lub podświetlania.<br/>            Domyślna wartość to `false`. |
