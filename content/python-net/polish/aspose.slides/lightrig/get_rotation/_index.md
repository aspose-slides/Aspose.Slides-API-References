## get_rotation(self) {#}
Rotacja jest definiowana przy użyciu współrzędnej szerokości, współrzędnej długości oraz obrotu wokół osi jako współrzędnych szerokości i długości.
pierwszy element w zwracanej tablicy - szerokość, drugi - długość, trzeci - obrót.
Zwraca None, jeśli rotacja nie jest zdefiniowana.
