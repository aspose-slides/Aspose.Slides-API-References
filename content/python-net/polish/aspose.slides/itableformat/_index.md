## ITableFormat klasa

Reprezentuje format tabeli.

Typ ITableFormat udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`fill_format`](/slides/python-net/pl/aspose.slides/itableformat/fill_format/) | Zwraca obiekt właściwości wypełnienia tabeli.<br/>            Tylko do odczytu [`IFillFormat`](/slides/python-net/pl/aspose.slides/ifillformat). |
| [`transparency`](/slides/python-net/pl/aspose.slides/itableformat/transparency/) | Pobiera lub ustawia przezroczystość koloru wypełnienia.<br/>            Odczyt/zapis **float**. |

## Metody

| Metoda | Opis |
| :- | :- |
| [`get_effective(self)`](/slides/python-net/pl/aspose.slides/itableformat/get_effective/#) | Pobiera efektywne właściwości formatowania tabeli z uwzględnieniem dziedziczenia i zastosowanych stylów tabeli. |
