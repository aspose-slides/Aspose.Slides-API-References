## ICellFormat klasa

Reprezentuje format komórki tabeli.

Typ ICellFormat udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`fill_format`](/slides/python-net/pl/aspose.slides/icellformat/fill_format/) | Zwraca obiekt właściwości wypełnienia komórki.<br/>            Tylko do odczytu [`IFillFormat`](/slides/python-net/pl/aspose.slides/ifillformat). |
| [`border_left`](/slides/python-net/pl/aspose.slides/icellformat/border_left/) | Zwraca obiekt właściwości linii lewej krawędzi.<br/>            Tylko do odczytu [`ILineFormat`](/slides/python-net/pl/aspose.slides/ilineformat). |
| [`border_top`](/slides/python-net/pl/aspose.slides/icellformat/border_top/) | Zwraca obiekt właściwości linii górnej krawędzi.<br/>            Tylko do odczytu [`ILineFormat`](/slides/python-net/pl/aspose.slides/ilineformat). |
| [`border_right`](/slides/python-net/pl/aspose.slides/icellformat/border_right/) | Zwraca obiekt właściwości linii prawej krawędzi.<br/>            Tylko do odczytu [`ILineFormat`](/slides/python-net/pl/aspose.slides/ilineformat). |
| [`border_bottom`](/slides/python-net/pl/aspose.slides/icellformat/border_bottom/) | Zwraca obiekt właściwości linii dolnej krawędzi.<br/>            Tylko do odczytu [`ILineFormat`](/slides/python-net/pl/aspose.slides/ilineformat). |
| [`border_diagonal_down`](/slides/python-net/pl/aspose.slides/icellformat/border_diagonal_down/) | Zwraca obiekt właściwości linii ukośnej od lewego górnego do prawego dolnego.<br/>            Tylko do odczytu [`ILineFormat`](/slides/python-net/pl/aspose.slides/ilineformat). |
| [`border_diagonal_up`](/slides/python-net/pl/aspose.slides/icellformat/border_diagonal_up/) | Zwraca obiekt właściwości linii ukośnej od lewego dolnego do prawego górnego.<br/>            Tylko do odczytu [`ILineFormat`](/slides/python-net/pl/aspose.slides/ilineformat). |
| [`transparency`](/slides/python-net/pl/aspose.slides/icellformat/transparency/) | Pobiera lub ustawia przeźroczystość koloru wypełnienia.<br/>            Odczyt/zapis **float**. |
