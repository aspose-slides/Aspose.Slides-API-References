## ISlideText klasa

Reprezentuje tekst wyodrębniony ze slajdu

Typ ISlideText udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`text`](/slides/python-net/pl/aspose.slides/islidetext/text/) | Tekst na kształtach slajdu |
| [`master_text`](/slides/python-net/pl/aspose.slides/islidetext/master_text/) | Tekst na kształtach strony wzorcowej dla tego slajdu |
| [`layout_text`](/slides/python-net/pl/aspose.slides/islidetext/layout_text/) | Tekst na kształtach strony układu dla tego slajdu |
| [`notes_text`](/slides/python-net/pl/aspose.slides/islidetext/notes_text/) | Tekst na kształtach strony notatek dla tego slajdu |
| [`comments_text`](/slides/python-net/pl/aspose.slides/islidetext/comments_text/) | Tekst komentarzy slajdu |
