## Wyliczenie FillType

Określa wewnętrzny typ wypełnienia różnych obiektów wizualnych.

Typ FillType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| NOT_DEFINED | Typ wypełnienia nie jest określony. |
| NO_FILL | Nie zastosowano wypełnienia. |
| SOLID | Wypełnione jednolitym kolorem. |
| GRADIENT | Wypełnienie jest gradientem. |
| PATTERN | Używany jest powtarzający się wzór do wypełnienia obiektu. |
| PICTURE | Do wypełnienia obiektu używany jest pojedynczy obraz. |
| GROUP | Obiekt wizualny dziedziczy właściwości wypełnienia z grupy. |
