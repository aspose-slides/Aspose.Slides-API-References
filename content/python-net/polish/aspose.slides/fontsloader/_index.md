## FontsLoader klasa

Klasa do ładowania niestandardowych czcionek zdefiniowanych przez użytkownika.  
Powinna być używana przed tworzeniem jakichkolwiek obiektów prezentacji.

Typ FontsLoader udostępnia następujące elementy:

## Metody

| Metoda | Opis |
| :- | :- |
| [`load_external_fonts(directories)`](/slides/python-net/pl/aspose.slides/fontsloader/load_external_fonts/#liststr) | Dodaje dodatkowe foldery, w których szukać czcionek. |
| [`load_external_font(data)`](/slides/python-net/pl/aspose.slides/fontsloader/load_external_font/#bytes) | Dodaje czcionkę z danych binarnych |
| [`get_font_folders()`](/slides/python-net/pl/aspose.slides/fontsloader/get_font_folders/#) | Pobiera foldery czcionek. Zwraca foldery dodane metodą LoadExternalFonts oraz foldery czcionek systemowych |
| [`clear_cache()`](/slides/python-net/pl/aspose.slides/fontsloader/clear_cache/#) | Zwalnia wszystkie niestandardowe czcionki zdefiniowane przez użytkownika |
