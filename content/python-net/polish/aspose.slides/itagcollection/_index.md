## ITagCollection klasa

Reprezentuje kolekcję tagów (pary łańcuchów definiowane przez użytkownika)

Typ ITagCollection udostępnia następujące elementy:

## Metody

| Metoda | Opis |
| :- | :- |
| [`add(self, name, value)`](/slides/python-net/pl/aspose.slides/itagcollection/add/#str-str) | Dodaje nowy tag do kolekcji. |
| [`remove(self, name)`](/slides/python-net/pl/aspose.slides/itagcollection/remove/#str) | Usuwa tag o określonej nazwie z kolekcji. |
| [`index_of_name(self, name)`](/slides/python-net/pl/aspose.slides/itagcollection/index_of_name/#str) | Zwraca indeks zerowy określonego klucza w kolekcji. |
| [`remove_at(self, index)`](/slides/python-net/pl/aspose.slides/itagcollection/remove_at/#int) | Usuwa tag pod określonym indeksem. |
| [`clear(self)`](/slides/python-net/pl/aspose.slides/itagcollection/clear/#) | Usuwa wszystkie tagi z kolekcji. |
| [`get_value_by_index(self, index)`](/slides/python-net/pl/aspose.slides/itagcollection/get_value_by_index/#int) | Zwraca wartość tagu pod określonym indeksem. |
| [`get_name_by_index(self, index)`](/slides/python-net/pl/aspose.slides/itagcollection/get_name_by_index/#int) | Zwraca klucz tagu pod określonym indeksem. |
| [`get_names_of_tags(self)`](/slides/python-net/pl/aspose.slides/itagcollection/get_names_of_tags/#) | Zwraca nazwy tagów. |
