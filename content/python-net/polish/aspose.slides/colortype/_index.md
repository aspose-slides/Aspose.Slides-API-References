## ColorType enumeracja

Reprezentuje różne tryby kolorów.

Typ ColorType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| NOT_DEFINED | Kolor nie jest w ogóle określony. |
| RGB | Standardowy 24bitowy kolor RGB. |
| RGB_PERCENTAGE | Kolor RGB w wysokiej rozdzielczości. |
| HSL | Kolor HSL w wysokiej rozdzielczości. |
| SCHEME | Kolor schematu. |
| SYSTEM | Kolor systemowy. |
| PRESET | Predefiniowany kolor. |
