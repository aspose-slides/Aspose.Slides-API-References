## właściwość ramki
Zwraca lub ustawia właściwości ramki kształtu.
            Odczyt/zapis [`IShapeFrame`](/slides/python-net/pl/aspose.slides/ishapeframe).


### Uwagi

Wartość każdej właściwości zwróconego wystąpienia IShapeFrame nie jest
            niezdefiniowana (nie jest NaN lub NotDefined).
Wartość każdej właściwości przypisanego wystąpienia IShapeFrame nie może być
            niezdefiniowana (musi nie być NaN lub NotDefined).
Możesz ustawić niezdefiniowane wartości dla właściwości wystąpienia RawFrame.
