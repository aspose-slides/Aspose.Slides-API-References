## IShapeFrame klasa

Reprezentuje właściwości ramki kształtu.

Typ IShapeFrame udostępnia następujące elementy:

## Właściwości

| Property | Description |
| :- | :- |
| [`x`](/slides/python-net/pl/aspose.slides/ishapeframe/x/) | Zwraca współrzędną X lewego górnego rogu ramki.<br/>            tylko do odczytu **float**. |
| [`y`](/slides/python-net/pl/aspose.slides/ishapeframe/y/) | Zwraca współrzędną Y lewego górnego rogu ramki.<br/>            tylko do odczytu **float**. |
| [`width`](/slides/python-net/pl/aspose.slides/ishapeframe/width/) | Zwraca szerokość ramki.<br/>            tylko do odczytu **float**. |
| [`height`](/slides/python-net/pl/aspose.slides/ishapeframe/height/) | Zwraca wysokość ramki.<br/>            tylko do odczytu **float**. |
| [`rotation`](/slides/python-net/pl/aspose.slides/ishapeframe/rotation/) | Zwraca liczbę stopni, o którą ramka jest obrócona wokół osi Z.<br/>            Wartość dodatnia oznacza obrót zgodny z ruchem wskazówek zegara; wartość ujemna<br/>            oznacza obrót przeciwny do ruchu wskazówek zegara.<br/>            tylko do odczytu **float**. |
| [`center_x`](/slides/python-net/pl/aspose.slides/ishapeframe/center_x/) | Zwraca współrzędną X środka ramki.<br/>            tylko do odczytu **float**. |
| [`center_y`](/slides/python-net/pl/aspose.slides/ishapeframe/center_y/) | Zwraca współrzędną Y środka ramki.<br/>            tylko do odczytu **float**. |
| [`flip_h`](/slides/python-net/pl/aspose.slides/ishapeframe/flip_h/) | Określa, czy ramka jest odwrócona poziomo.<br/>            tylko do odczytu [`NullableBool`](/slides/python-net/pl/aspose.slides/nullablebool). |
| [`flip_v`](/slides/python-net/pl/aspose.slides/ishapeframe/flip_v/) | Określa, czy ramka jest odwrócona pionowo.<br/>            tylko do odczytu [`NullableBool`](/slides/python-net/pl/aspose.slides/nullablebool). |
| [`rectangle`](/slides/python-net/pl/aspose.slides/ishapeframe/rectangle/) | Zwraca współrzędne ramki.<br/>            tylko do odczytu **aspose.slides.RectangleF**. |
