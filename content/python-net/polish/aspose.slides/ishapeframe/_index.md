## IShapeFrame klasa

Reprezentuje właściwości ramki kształtu.

Typ IShapeFrame udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`x`](/slides/python-net/pl/aspose.slides/ishapeframe/x/) | Zwraca współrzędną X lewego górnego rogu ramki.<br/>            Tylko do odczytu **float**. |
| [`y`](/slides/python-net/pl/aspose.slides/ishapeframe/y/) | Zwraca współrzędną Y lewego górnego rogu ramki.<br/>            Tylko do odczytu **float**. |
| [`width`](/slides/python-net/pl/aspose.slides/ishapeframe/width/) | Zwraca szerokość ramki.<br/>            Tylko do odczytu **float**. |
| [`height`](/slides/python-net/pl/aspose.slides/ishapeframe/height/) | Zwraca wysokość ramki.<br/>            Tylko do odczytu **float**. |
| [`rotation`](/slides/python-net/pl/aspose.slides/ishapeframe/rotation/) | Zwraca liczbę stopni, o które ramka jest obrócona wokół osi z.<br/>            Wartość dodatnia oznacza obrót zgodny z ruchem wskazówek zegara; wartość ujemna oznacza obrót przeciwny do ruchu wskazówek zegara.<br/>            Tylko do odczytu **float**. |
| [`center_x`](/slides/python-net/pl/aspose.slides/ishapeframe/center_x/) | Zwraca współrzędną X środka ramki.<br/>            Tylko do odczytu **float**. |
| [`center_y`](/slides/python-net/pl/aspose.slides/ishapeframe/center_y/) | Zwraca współrzędną Y środka ramki.<br/>            Tylko do odczytu **float**. |
| [`flip_h`](/slides/python-net/pl/aspose.slides/ishapeframe/flip_h/) | Określa, czy ramka jest odbita w poziomie.<br/>            Tylko do odczytu [`NullableBool`](/slides/python-net/pl/aspose.slides/nullablebool). |
| [`flip_v`](/slides/python-net/pl/aspose.slides/ishapeframe/flip_v/) | Określa, czy ramka jest odbita w pionie.<br/>            Tylko do odczytu [`NullableBool`](/slides/python-net/pl/aspose.slides/nullablebool). |
| [`rectangle`](/slides/python-net/pl/aspose.slides/ishapeframe/rectangle/) | Zwraca współrzędne ramki.<br/>            Tylko do odczytu [`RectangleF`](/slides/python-net/pl/aspose.slides/rectanglef). |
