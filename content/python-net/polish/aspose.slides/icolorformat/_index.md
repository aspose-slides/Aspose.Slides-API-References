## IColorFormat klasa

Reprezentuje kolor używany w prezentacji.

Typ IColorFormat udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`color_type`](/slides/python-net/pl/aspose.slides/icolorformat/color_type/) | Zwraca lub ustawia metodę definiowania koloru.<br/>            Odczyt/zapis [`ColorType`](/slides/python-net/pl/aspose.slides/colortype). |
| [`color`](/slides/python-net/pl/aspose.slides/icolorformat/color/) | Zwraca wynikowy kolor (z zastosowanymi wszystkimi transformacjami koloru).<br/>            Ustawia kolory RGB i usuwa wszystkie transformacje koloru.<br/>            Odczyt/zapis **aspose.slides.Color**. |
| [`preset_color`](/slides/python-net/pl/aspose.slides/icolorformat/preset_color/) | Zwraca lub ustawia predefiniowany kolor.<br/>            Odczyt/zapis [`PresetColor`](/slides/python-net/pl/aspose.slides/presetcolor). |
| [`system_color`](/slides/python-net/pl/aspose.slides/icolorformat/system_color/) | Zwraca lub ustawia kolor określony w systemowej tabeli kolorów.<br/>            Odczyt/zapis [`SystemColor`](/slides/python-net/pl/aspose.slides/systemcolor). |
| [`scheme_color`](/slides/python-net/pl/aspose.slides/icolorformat/scheme_color/) | Zwraca lub ustawia kolor określony w schemacie kolorów.<br/>            Odczyt/zapis [`SchemeColor`](/slides/python-net/pl/aspose.slides/schemecolor). |
| [`r`](/slides/python-net/pl/aspose.slides/icolorformat/r/) | Zwraca lub ustawia składową czerwoną koloru. Wszystkie transformacje koloru są ignorowane.<br/>            Odczyt/zapis **int**. |
| [`g`](/slides/python-net/pl/aspose.slides/icolorformat/g/) | Zwraca lub ustawia składową zieloną koloru. Wszystkie transformacje koloru są ignorowane.<br/>            Odczyt/zapis **int**. |
| [`b`](/slides/python-net/pl/aspose.slides/icolorformat/b/) | Zwraca lub ustawia składową niebieską koloru. Wszystkie transformacje koloru są ignorowane.<br/>            Odczyt/zapis **int**. |
| [`float_r`](/slides/python-net/pl/aspose.slides/icolorformat/float_r/) | Zwraca lub ustawia składową czerwoną koloru. Wszystkie transformacje koloru są ignorowane.<br/>            Odczyt/zapis **float**. |
| [`float_g`](/slides/python-net/pl/aspose.slides/icolorformat/float_g/) | Zwraca lub ustawia składową zieloną koloru. Wszystkie transformacje koloru są ignorowane.<br/>            Odczyt/zapis **float**. |
| [`float_b`](/slides/python-net/pl/aspose.slides/icolorformat/float_b/) | Zwraca lub ustawia składową niebieską koloru. Wszystkie transformacje koloru są ignorowane.<br/>            Odczyt/zapis **float**. |
| [`hue`](/slides/python-net/pl/aspose.slides/icolorformat/hue/) | Zwraca lub ustawia składową odcienia koloru w reprezentacji HSL.<br/>            Wszystkie transformacje koloru są ignorowane.<br/>            Odczyt/zapis **float**. |
| [`saturation`](/slides/python-net/pl/aspose.slides/icolorformat/saturation/) | Zwraca lub ustawia składową nasycenia koloru w reprezentacji HSL.<br/>            Wszystkie transformacje koloru są ignorowane.<br/>            Odczyt/zapis **float**. |
| [`luminance`](/slides/python-net/pl/aspose.slides/icolorformat/luminance/) | Zwraca lub ustawia składową luminancji koloru w reprezentacji HSL.<br/>            Wszystkie transformacje koloru są ignorowane.<br/>            Odczyt/zapis **float**. |
| [`color_transform`](/slides/python-net/pl/aspose.slides/icolorformat/color_transform/) | Zwraca kolekcję transformacji kolorów zastosowanych do koloru.<br/>            Tylko do odczytu [`IColorOperationCollection`](/slides/python-net/pl/aspose.slides/icoloroperationcollection). |
