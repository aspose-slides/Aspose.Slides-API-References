## AudioPlayModePreset enumeracja

Stałe definiujące, jak odtwarzany jest dźwięk.

Typ AudioPlayModePreset udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| MIXED |  |
| AUTO | Odtwarzaj automatycznie. |
| ON_CLICK | Odtwarzaj tylko po kliknięciu ikony. |
| ALL_SLIDES | Odtwarzaj na wszystkich slajdach.<br/>            Użyj właściwości [`IAudioFrame.play_across_slides`](/slides/python-net/pl/aspose.slides/iaudioframe/play_across_slides) zamiast tego.<br/>            Ten element jest nieaktualny od wersji PowerPoint 2013. |
| IN_CLICK_SEQUENCE | Odtwarzaj automatycznie po kliknięciu. |
