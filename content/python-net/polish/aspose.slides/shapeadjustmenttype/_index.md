## ShapeAdjustmentType enumeracja

Określa różne typy wartości dopasowania kształtu.

Typ ShapeAdjustmentType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| CUSTOM | Typ niestandardowy (nieznane dopasowanie) |
| CORNER_SIZE | Kontroluje rozmiar narożników. |
| LEFT_UP_CORNER | Kontroluje górny lewy narożnik. |
| RIGHT_UP_CORNER | Kontroluje górny prawy narożnik. |
| UP_CORNERS | Kontroluje górne narożniki. |
| DOWN_CORNERS | Kontroluje dolne narożniki. |
| THICKNESS | Kontroluje grubość figury. |
| ARROW_TAIL_THICKNESS | Kontroluje grubość ogona strzały. |
| ARROWHEAD_LENGTH | Kontroluje długość grotu strzały. |
| ARROWHEAD_WIDTH | Kontroluje szerokość grotu strzały. |
| RADIUS | Kontroluje rozmiar promienia kształtu lub jego części. |
| DEPTH | Kontroluje głębokość zębów koła zębatego lub efekt sfazowania. |
| SHAPE_PART_OFFSET | Kontroluje przesunięcie jednej części figury względem drugiej. |
| ANGLE | Kontroluje kąt figury lub jej części. |
| START_ANGLE | Kąt początkowy dla kształtów koła i łuku. |
| END_ANGLE | Kąt końcowy dla kształtów koła i łuku. |
| START_POINT_X | Kontroluje pozycję X punktu początkowego dymku. |
| START_POINT_Y | Kontroluje pozycję Y punktu początkowego dymku. |
| CONNECTOR_POINT_1X | Kontroluje położenie poziome punktu regulacji kąta dymku. |
| CONNECTOR_POINT_1Y | Kontroluje położenie pionowe punktu regulacji kąta dymku. |
| CONNECTOR_POINT_2X | Kontroluje położenie poziome punktu regulacji kąta dymku. |
| CONNECTOR_POINT_2Y | Kontroluje położenie pionowe punktu regulacji kąta dymku. |
| CONNECTOR_BEND_POSITION_X | Kontroluje położenie poziome zgięcia w łączniku. |
| CONNECTOR_BEND_POSITION_Y | Kontroluje położenie pionowe zgięcia w łączniku. |
| ATTACH_Y | Kontroluje pionowy punkt przyłączenia figury. |
| ATTACH_X | Kontroluje poziomy punkt przyłączenia figury. |
| CALLOUT_HEIGHT | Kontroluje pionowy rozmiar dymku. |
| CALLOUT_WIDTH | Kontroluje poziomy rozmiar dymku. |
| CALLOUT_SIZE | Kontroluje rozmiar dymku. |
| CURVATURE | Krzywizna wygiętego, podparcia, zakrzywionej strzałki lub kształtu. |
| HORIZONTAL_THICKNESS | Kontroluje poziomą grubość kształtu narożnika. |
| VERTICAL_THICKNESS | Kontroluje pionową grubość kształtu narożnika. |
| VERTICAL_SIZE | Kontroluje pionowy rozmiar kształtu. |
| HORIZONTAL_SIZE | Kontroluje poziomy rozmiar kształtu. |
| TOP | Kontroluje górną stronę kształtu. |
