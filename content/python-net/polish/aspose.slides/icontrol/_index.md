## IControl klasa

Reprezentuje kontrolkę ActiveX.

Typ IControl udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`name`](/slides/python-net/pl/aspose.slides/icontrol/name/) | Zwraca nazwę tej kontrolki.<br/>            Odczyt/zapis **str**. |
| [`class_id`](/slides/python-net/pl/aspose.slides/icontrol/class_id/) | Pobiera identyfikator klasy tej kontrolki.<br/>            Tylko do odczytu **System.Guid**. |
| [`substitute_picture_format`](/slides/python-net/pl/aspose.slides/icontrol/substitute_picture_format/) | Zwraca obiekt właściwości wypełnienia obrazu ControlEx.<br/>            Tylko do odczytu [`IPictureFillFormat`](/slides/python-net/pl/aspose.slides/ipicturefillformat). |
| [`frame`](/slides/python-net/pl/aspose.slides/icontrol/frame/) | Zwraca lub ustawia ramkę kontrolki.<br/>            Odczyt/zapis [`IShapeFrame`](/slides/python-net/pl/aspose.slides/ishapeframe). |
| [`properties`](/slides/python-net/pl/aspose.slides/icontrol/properties/) | Zwraca kolekcję właściwości ActiveX.<br/>            Tylko do odczytu [`IControlPropertiesCollection`](/slides/python-net/pl/aspose.slides/icontrolpropertiescollection). |
| [`persistence`](/slides/python-net/pl/aspose.slides/icontrol/persistence/) | Pobiera metodę używaną do przechowywania właściwości kontrolki ActiveX.<br/>            Tylko do odczytu [`PersistenceType`](/slides/python-net/pl/aspose.slides/persistencetype). |
| [`active_x_control_binary`](/slides/python-net/pl/aspose.slides/icontrol/active_x_control_binary/) | Określa trwałość kontrolki ActiveX, gdy używaną metodą jest PersistStream, PersistStreamInit lub PersistStorage. |
| [`slide`](/slides/python-net/pl/aspose.slides/icontrol/slide/) |  |
| [`presentation`](/slides/python-net/pl/aspose.slides/icontrol/presentation/) |  |
