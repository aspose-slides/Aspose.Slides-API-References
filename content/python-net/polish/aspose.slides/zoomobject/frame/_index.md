## właściwość ramki
Zwraca lub ustawia właściwości ramki kształtu.
            Odczyt/zapis [`IShapeFrame`](/slides/python-net/pl/aspose.slides/ishapeframe).


### Uwagi

Wartość każdej właściwości zwróconego obiektu IShapeFrame nie jest 
            niezdefiniowana (nie jest NaN ani NotDefined).
            Wartość każdej właściwości przypisanego obiektu IShapeFrame musi nie być 
            niezdefiniowana (musi nie być NaN ani NotDefined).
            Możesz ustawić niezdefiniowane wartości dla właściwości obiektu RawFrame.
