## height właściwość
Pobiera lub ustawia wysokość kształtu, mierzoną w punktach.
            Odczyt/zapis **float**.


### Uwagi

Zwracana wartość jest zawsze określona i nigdy nie jest **float**.
            Przypisywana wartość musi również być określona; przypisuj **float** tylko do właściwości instancji `RawFrame`.
