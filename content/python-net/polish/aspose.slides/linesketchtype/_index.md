## LineSketchType enumeracja

Reprezentuje, jaki typ szkicu lub efekt został przypisany kształtowi.

Typ LineSketchType udostępnia następujące elementy:

## Pola

| Field | Description |
| :- | :- |
| NOT_DEFINED | Określa, że efekt Sketch kształtu jest niezdefiniowany. |
| NONE | Określa, że kształt nie ma efektu Sketch. Jest to równoważne, gdy ta właściwość jest pusta. |
| CURVED | Określa, że kształt ma efekt Curved, który zamienia każdą krawędź kształtu w jedną dużą łagodną krzywiznę. |
| FREEHAND | Określa, że kształt ma efekt Freehand, który najbardziej przypomina niedoskonałą narysowaną linię. |
| SCRIBBLE | Określa, że kształt ma efekt Scribble, który ma przesadzone oscylacje, jakby został celowo narysowany niechlujnie. |
