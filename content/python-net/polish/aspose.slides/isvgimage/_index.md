## ISvgImage klasa

Reprezentuje obraz SVG.

Typ ISvgImage udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`svg_content`](/slides/python-net/pl/aspose.slides/isvgimage/svg_content/) | Zwraca zawartość SVG.<br/>Tylko do odczytu **str**. |
| [`svg_data`](/slides/python-net/pl/aspose.slides/isvgimage/svg_data/) | Zwraca dane SVG.<br/>Tylko do odczytu **int**[]. |
| [`external_resource_resolver`](/slides/python-net/pl/aspose.slides/isvgimage/external_resource_resolver/) | Zwraca interfejs wywołania zwrotnego używany do rozwiązywania zewnętrznych zasobów podczas importu dokumentów SVG.<br/>Tylko do odczytu **IExternalResourceResolver**. |
| [`base_uri`](/slides/python-net/pl/aspose.slides/isvgimage/base_uri/) | Zwraca bazowy URI określonego SVG. Używany do rozwiązywania linków względnych.<br/>Tylko do odczytu **str**. |

## Metody

| Metoda | Opis |
| :- | :- |
| [`write_as_emf(self, stream)`](/slides/python-net/pl/aspose.slides/isvgimage/write_as_emf/#iorawiobase) | Zapisuje obraz SVG jako plik EMF. |
