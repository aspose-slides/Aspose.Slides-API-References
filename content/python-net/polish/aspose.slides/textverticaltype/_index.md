## TextVerticalType wyliczenie

Określa pionowy tryb pisania dla tekstu.

Typ TextVerticalType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| NOT_DEFINED | Nie zdefiniowano. |
| HORIZONTAL | Tekst poziomy. |
| VERTICAL | Tekst pionowy. |
| VERTICAL270 | Tekst pionowy 270 stopni. |
| WORD_ART_VERTICAL | Pionowy tekst WordArt. |
| EAST_ASIAN_VERTICAL | Pionowy tekst wschodnioazjatycki. |
| MONGOLIAN_VERTICAL | Pionowy tekst mongolski. |
| WORD_ART_VERTICAL_RIGHT_TO_LEFT | Pionowy tekst WordArt od prawej do lewej. |
