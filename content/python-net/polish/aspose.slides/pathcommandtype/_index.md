## PathCommandType enumeracja

Reprezentuje polecenia ścieżki graficznej

Typ PathCommandType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| CLOSE | Zamyka ścieżkę geometryczną |
| MOVE_TO | Ustawia pozycję następnego punktu ścieżki geometrycznej |
| LINE_TO | Dodaje linię do ścieżki geometrycznej |
| ARC_TO | Dodaje określony łuk do ścieżki geometrycznej. |
| QUAD_BEZIER_TO | Dodaje krzywą kwadratową Bézier do ścieżki geometrycznej |
| CUBIC_BEZIER_TO | Dodaje krzywą sześcienną Bézier do ścieżki geometrycznej |
