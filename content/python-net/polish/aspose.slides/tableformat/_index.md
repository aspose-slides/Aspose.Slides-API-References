## TableFormat klasa

Reprezentuje format tabeli.

Typ TableFormat udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`fill_format`](/slides/python-net/pl/aspose.slides/tableformat/fill_format/) | Zwraca obiekt właściwości wypełnienia tabeli.<br/>            Tylko odczyt [`IFillFormat`](/slides/python-net/pl/aspose.slides/ifillformat). |
| [`transparency`](/slides/python-net/pl/aspose.slides/tableformat/transparency/) | Pobiera lub ustawia przezroczystość koloru wypełnienia.<br/>            Odczyt/zapis **float**. |

## Metody

| Metoda | Opis |
| :- | :- |
| [`get_effective(self)`](/slides/python-net/pl/aspose.slides/tableformat/get_effective/#) | Pobiera efektywne właściwości formatowania tabeli z zastosowanym dziedziczeniem i stylami tabeli. |
