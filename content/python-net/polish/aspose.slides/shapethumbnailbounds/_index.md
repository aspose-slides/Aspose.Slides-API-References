## ShapeThumbnailBounds wyliczenie

Wyliczenie typów ograniczeń miniatury kształtu.

Typ ShapeThumbnailBounds zawiera następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| SLIDE | Miniatura kształtu będzie mieć rozmiar równy rozmiarowi slide.<br/>            Pozycja kształtu zostanie zapisana. |
| SHAPE | Miniatura kształtu będzie mieć rozmiar równy prostokątowi ograniczeń kształtu<br/>            z uwzględnieniem ustawień konturu kształtu. |
| APPEARANCE | Miniatura kształtu będzie mieć rozmiar równy wyglądowi kształtu (w granicach slide). <br/>            Mogą wystąpić przypadki, gdy wygląd kształtu nie mieści się w granicach kształtu. Np.<br/>            rotacja, połączenie miecza ostrego kąta, efekty 3D itd. |
