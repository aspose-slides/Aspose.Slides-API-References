## FontStyleType enumeracja

Definiuje style formatowania, które mogą być zastosowane do tekstu.

Typ FontStyleType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| REGULAR | Standardowy tekst. |
| BOLD | Tekst pogrubiony. |
| ITALIC | Tekst pochylony. |
| UNDERLINE | Tekst podkreślony. |
| STRIKEOUT | Tekst przekreślony poziomą linią. |
