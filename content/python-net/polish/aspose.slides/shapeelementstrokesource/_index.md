## ShapeElementStrokeSource enumeracja

Reprezentuje sposób, w jaki element kształtu powinien być rysowany.

Typ ShapeElementStrokeSource udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| NO_STROKE | Nie rysować obrysu prymitywu. |
| SHAPE | Użyj LineFormat kształtu. |
| OWN_STROKE | Użyj własnego obrysu. |
