## ITextFrameFormatEffectiveData klasa

Niezmienny obiekt zawierający skuteczne właściwości formatowania ramki tekstu.

Typ ITextFrameFormatEffectiveData udostępnia następujące elementy:

## Properties

| Property | Description |
| :- | :- |
| [`text_style`](/slides/python-net/pl/aspose.slides/itextframeformateffectivedata/text_style/) | Zwraca skuteczny styl tekstu.<br/>            Tylko do odczytu [`ITextStyleEffectiveData`](/slides/python-net/pl/aspose.slides/itextstyleeffectivedata). |
| [`margin_left`](/slides/python-net/pl/aspose.slides/itextframeformateffectivedata/margin_left/) | Zwraca lewy margines (punkty) w TextFrame.<br/>            Tylko do odczytu **float**. |
| [`margin_right`](/slides/python-net/pl/aspose.slides/itextframeformateffectivedata/margin_right/) | Zwraca prawy margines (punkty) w TextFrame.<br/>            Tylko do odczytu **float**. |
| [`margin_top`](/slides/python-net/pl/aspose.slides/itextframeformateffectivedata/margin_top/) | Zwraca górny margines (punkty) w TextFrame.<br/>            Tylko do odczytu **float**. |
| [`margin_bottom`](/slides/python-net/pl/aspose.slides/itextframeformateffectivedata/margin_bottom/) | Zwraca dolny margines (punkty) w TextFrame.<br/>            Tylko do odczytu **float**. |
| [`wrap_text`](/slides/python-net/pl/aspose.slides/itextframeformateffectivedata/wrap_text/) | Zwraca, czy tekst jest zawijany przy marginesach TextFrame.<br/>            Tylko do odczytu **bool**. |
| [`anchoring_type`](/slides/python-net/pl/aspose.slides/itextframeformateffectivedata/anchoring_type/) | Zwraca pionowy punkt zaczepienia tekstu w TextFrame.<br/>            Tylko do odczytu [`TextAnchorType`](/slides/python-net/pl/aspose.slides/textanchortype). |
| [`center_text`](/slides/python-net/pl/aspose.slides/itextframeformateffectivedata/center_text/) | Zwraca, czy tekst powinien być wyśrodkowany w poziomie w ramce.<br/>            Tylko do odczytu **bool**. |
| [`text_vertical_type`](/slides/python-net/pl/aspose.slides/itextframeformateffectivedata/text_vertical_type/) | Zwraca orientację tekstu.<br/>            Tylko do odczytu [`TextVerticalType`](/slides/python-net/pl/aspose.slides/textverticaltype). |
| [`autofit_type`](/slides/python-net/pl/aspose.slides/itextframeformateffectivedata/autofit_type/) | Zwraca tryb automatycznego dopasowania tekstu.<br/>            Tylko do odczytu [`TextAutofitType`](/slides/python-net/pl/aspose.slides/textautofittype). |
| [`column_count`](/slides/python-net/pl/aspose.slides/itextframeformateffectivedata/column_count/) | Określa liczbę kolumn tekstu w otaczającym prostokącie.<br/>            Tylko do odczytu **int**. |
| [`column_spacing`](/slides/python-net/pl/aspose.slides/itextframeformateffectivedata/column_spacing/) | Określa odstęp między kolumnami tekstu w obszarze tekstowym (w punktach).<br/>            Tylko do odczytu **float**. |


### Uwagi

Ten interfejs jest używany razem z interfejsem [`ITextFrameFormat`](/slides/python-net/pl/aspose.slides/itextframeformat), aby zwrócić skuteczne wartości formatowania z uwzględnieniem dziedziczenia.
