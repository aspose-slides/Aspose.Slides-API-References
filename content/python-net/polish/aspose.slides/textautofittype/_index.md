## TextAutofitType enumeracja

Reprezentuje tryb automatycznego dopasowania tekstu.

Typ TextAutofitType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| NOT_DEFINED | Nie określono. |
| NONE | Brak automatycznego dopasowania. |
| NORMAL | Normalne automatyczne dopasowanie. Rozmiar czcionki i interlinię zostaną zmniejszone, aby dopasować kształt. |
| SHAPE | Automatyczne dopasowanie kształtu. Rozmiar kształtu zostanie zmieniony, aby dopasować tekst. |
