## SizeF klasa

Przechowuje uporządkowaną parę liczb zmiennoprzecinkowych, zwykle szerokość i wysokość prostokąta. Zgodny z .NET `System.Drawing.SizeF`.

Typ SizeF udostępnia następujące elementy:

## Konstruktorzy

| Konstruktor | Opis |
| :- | :- |
| [`__init__(self, width=0.0, height=0.0)`](/slides/python-net/pl/aspose.slides/sizef/__init__/#float-float) | Tworzy rozmiar o podanej szerokości i wysokości. |

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`width`](/slides/python-net/pl/aspose.slides/sizef/width/) | Zwraca poziomy składnik tego rozmiaru.<br/>            Tylko do odczytu **float**. |
| [`height`](/slides/python-net/pl/aspose.slides/sizef/height/) | Zwraca pionowy składnik tego rozmiaru.<br/>            Tylko do odczytu **float**. |


### Uwagi

Rozmiary są porównywane według ich składników za pomocą `==` i mogą być używane jako klucze słowników lub elementy zbiorów.
