## Klasa Video

Reprezentuje obraz osadzony w prezentacji.

Typ Video udostępnia następujące członki:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`content_type`](/slides/python-net/pl/aspose.slides/video/content_type/) | Zwraca typ MIME wideo, zakodowany w [`Video.binary_data`](/slides/python-net/pl/aspose.slides/video/binary_data).<br/>            Tylko do odczytu **str**. |
| [`binary_data`](/slides/python-net/pl/aspose.slides/video/binary_data/) | Zwraca kopię danych audio. W przypadku dużej ilości danych rozważ użycie <br/>            [`Video.get_stream`](/slides/python-net/pl/aspose.slides/video/get_stream) metody, aby zapobiec niepotrzebnemu ładowaniu danych wideo do pamięci <br/>            lub nawet OutOfMemoryException.<br/>            Tylko do odczytu **int**[]. |

## Metody

| Metoda | Opis |
| :- | :- |
| [`get_stream(self)`](/slides/python-net/pl/aspose.slides/video/get_stream/#) | Zwraca strumień Stream do odczytu.<br/>            Użyj 'using' lub zamknij strumień po użyciu. |
