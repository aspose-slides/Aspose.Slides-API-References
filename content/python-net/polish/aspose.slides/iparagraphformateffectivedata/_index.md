## IParagraphFormatEffectiveData klasa

Niezmienny obiekt, który zawiera efektywne właściwości formatowania akapitu.

Typ IParagraphFormatEffectiveData udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`bullet`](/slides/python-net/pl/aspose.slides/iparagraphformateffectivedata/bullet/) | Zwraca format wypunktowania akapitu.<br/>            Tylko do odczytu [`IBulletFormatEffectiveData`](/slides/python-net/pl/aspose.slides/ibulletformateffectivedata). |
| [`depth`](/slides/python-net/pl/aspose.slides/iparagraphformateffectivedata/depth/) | Zwraca głębokość akapitu.<br/>            Tylko do odczytu **int**. |
| [`alignment`](/slides/python-net/pl/aspose.slides/iparagraphformateffectivedata/alignment/) | Zwraca wyrównanie tekstu w akapicie.<br/>            Tylko do odczytu [`TextAlignment`](/slides/python-net/pl/aspose.slides/textalignment). |
| [`space_within`](/slides/python-net/pl/aspose.slides/iparagraphformateffectivedata/space_within/) | Zwraca ilość odstępu między liniami bazowymi w akapicie.<br/>            Tylko do odczytu **float**. |
| [`space_before`](/slides/python-net/pl/aspose.slides/iparagraphformateffectivedata/space_before/) | Zwraca ilość odstępu przed pierwszą linią w akapicie.<br/>            Tylko do odczytu **float**. |
| [`space_after`](/slides/python-net/pl/aspose.slides/iparagraphformateffectivedata/space_after/) | Zwraca ilość odstępu po ostatniej linii w akapicie.<br/>            Tylko do odczytu **float**. |
| [`east_asian_line_break`](/slides/python-net/pl/aspose.slides/iparagraphformateffectivedata/east_asian_line_break/) | Określa, czy w akapicie używany jest podział linii wschodnioazjatycki.<br/>            Tylko do odczytu **bool**. |
| [`right_to_left`](/slides/python-net/pl/aspose.slides/iparagraphformateffectivedata/right_to_left/) | Określa, czy w akapicie używany jest zapis od prawej do lewej.<br/>            Tylko do odczytu **bool**. |
| [`latin_line_break`](/slides/python-net/pl/aspose.slides/iparagraphformateffectivedata/latin_line_break/) | Określa, czy w akapicie używany jest łaciński podział linii.<br/>            Tylko do odczytu **bool**. |
| [`hanging_punctuation`](/slides/python-net/pl/aspose.slides/iparagraphformateffectivedata/hanging_punctuation/) | Określa, czy w akapicie używana jest wieszająca interpunkcja.<br/>            Tylko do odczytu **bool**. |
| [`margin_left`](/slides/python-net/pl/aspose.slides/iparagraphformateffectivedata/margin_left/) | Zwraca lewy margines w akapicie.<br/>            Tylko do odczytu **float**. |
| [`margin_right`](/slides/python-net/pl/aspose.slides/iparagraphformateffectivedata/margin_right/) | Zwraca prawy margines w akapicie.<br/>            Tylko do odczytu **float**. |
| [`indent`](/slides/python-net/pl/aspose.slides/iparagraphformateffectivedata/indent/) | Zwraca wcięcie pierwszej linii/odwieszenie akapitu. Odwieszenie można zdefiniować ujemnymi wartościami.<br/>            Tylko do odczytu **float**. |
| [`default_tab_size`](/slides/python-net/pl/aspose.slides/iparagraphformateffectivedata/default_tab_size/) | Zwraca domyślny rozmiar tabulacji.<br/>            Tylko do odczytu **float**. |
| [`tabs`](/slides/python-net/pl/aspose.slides/iparagraphformateffectivedata/tabs/) | Zwraca tabulacje w akapicie.<br/>            Tylko do odczytu [`ITabEffectiveData`](/slides/python-net/pl/aspose.slides/itabeffectivedata)[]. |
| [`font_alignment`](/slides/python-net/pl/aspose.slides/iparagraphformateffectivedata/font_alignment/) | Zwraca wyrównanie czcionki w akapicie.<br/>            Tylko do odczytu [`FontAlignment`](/slides/python-net/pl/aspose.slides/fontalignment). |
| [`default_portion_format`](/slides/python-net/pl/aspose.slides/iparagraphformateffectivedata/default_portion_format/) | Zwraca domyślny format części akapitu.<br/>            Tylko do odczytu [`IPortionFormatEffectiveData`](/slides/python-net/pl/aspose.slides/iportionformateffectivedata). |

### Uwagi

Ten interfejs jest używany razem z interfejsem [`IParagraphFormat`](/slides/python-net/pl/aspose.slides/iparagraphformat) aby zwrócić efektywne wartości formatowania z zastosowanym dziedziczeniem.
