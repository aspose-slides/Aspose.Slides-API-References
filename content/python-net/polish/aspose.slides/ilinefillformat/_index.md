## ILineFillFormat klasa

Reprezentuje właściwości wypełniania linii.

Typ ILineFillFormat udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`fill_type`](/slides/python-net/pl/aspose.slides/ilinefillformat/fill_type/) | Zwraca lub ustawia typ wypełnienia.<br/>            Odczyt/zapis [`FillType`](/slides/python-net/pl/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/pl/aspose.slides/ilinefillformat/solid_fill_color/) | Zwraca kolor jednolitego wypełnienia.<br/>            Tylko do odczytu [`IColorFormat`](/slides/python-net/pl/aspose.slides/icolorformat). |
| [`gradient_format`](/slides/python-net/pl/aspose.slides/ilinefillformat/gradient_format/) | Zwraca format wypełnienia gradientowego.<br/>            Tylko do odczytu [`IGradientFormat`](/slides/python-net/pl/aspose.slides/igradientformat). |
| [`pattern_format`](/slides/python-net/pl/aspose.slides/ilinefillformat/pattern_format/) | Zwraca format wypełnienia wzorem.<br/>            Tylko do odczytu [`IPatternFormat`](/slides/python-net/pl/aspose.slides/ipatternformat). |
| [`rotate_with_shape`](/slides/python-net/pl/aspose.slides/ilinefillformat/rotate_with_shape/) | Określa, czy wypełnienie ma być obracane wraz z kształtem.<br/>            Odczyt/zapis [`NullableBool`](/slides/python-net/pl/aspose.slides/nullablebool). |
