## PlaceholderType wyliczenie

Reprezentuje typ pola zastępczego.

Typ PlaceholderType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| TITLE | Tytuł. |
| BODY | Treść. |
| CENTERED_TITLE | Wyśrodkowany tytuł. |
| SUBTITLE | Podtytuł. |
| DATE_AND_TIME | Data i godzina. |
| SLIDE_NUMBER | Numer slajdu. |
| FOOTER | Stopka. |
| HEADER | Nagłówek. |
| OBJECT | Obiekt. |
| CHART | Wykres. |
| TABLE | Tabela. |
| CLIP_ART | Grafika. |
| DIAGRAM | Diagram. |
| MEDIA | Media. |
| SLIDE_IMAGE | Obraz slajdu. |
| PICTURE | Obraz. |
