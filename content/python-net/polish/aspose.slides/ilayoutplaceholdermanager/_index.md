## ILayoutPlaceholderManager klasa

Reprezentuje menedżera, który umożliwia dodawanie symboli zastępczych do slajdu układu.

Typ ILayoutPlaceholderManager udostępnia następujących członków:

## Metody

| Metoda | Opis |
| :- | :- |
| [`add_content_placeholder(self, x, y, width, height)`](/slides/python-net/pl/aspose.slides/ilayoutplaceholdermanager/add_content_placeholder/#float-float-float-float) | Dodaje nowy kształt symbolu zastępczego do slajdu układu, aby pomieścić treść, taką jak obraz, tabela, media lub tekst. |
| [`add_vertical_content_placeholder(self, x, y, width, height)`](/slides/python-net/pl/aspose.slides/ilayoutplaceholdermanager/add_vertical_content_placeholder/#float-float-float-float) | Dodaje nowy kształt symbolu zastępczego do slajdu układu, aby pomieścić treść, taką jak obraz, tabela, media <br/>            lub tekst w pionowym kierunku. |
| [`add_text_placeholder(self, x, y, width, height)`](/slides/python-net/pl/aspose.slides/ilayoutplaceholdermanager/add_text_placeholder/#float-float-float-float) | Dodaje nowy kształt symbolu zastępczego do slajdu układu, aby pomieścić treść tekstową. |
| [`add_vertical_text_placeholder(self, x, y, width, height)`](/slides/python-net/pl/aspose.slides/ilayoutplaceholdermanager/add_vertical_text_placeholder/#float-float-float-float) | Dodaje nowy kształt symbolu zastępczego do slajdu układu, aby pomieścić treść tekstową w pionowym kierunku. |
