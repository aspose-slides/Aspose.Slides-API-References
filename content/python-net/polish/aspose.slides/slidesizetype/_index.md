## enumeracja SlideSizeType

Reprezentuje predefiniowany rozmiar slajdu.

Typ SlideSizeType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| ON_SCREEN | Na ekranie 4x3 |
| LETTER_PAPER | List |
| A4_PAPER | A4 |
| SLIDE_35MM | Slajd 35 mm |
| OVERHEAD | Prezentacja |
| BANNER | Baner |
| CUSTOM | Niestandardowy rozmiar |
| LEDGER | Ledger |
| A3_PAPER | A3 |
| B4_ISO_PAPER | B4 ISO |
| B5_ISO_PAPER | B5 ISO |
| B4_JIS_PAPER | B4 JIS |
| B5_JIS_PAPER | B5 JIS |
| HAGAKI_CARD | Karta hagaki |
| ON_SCREEN_16X9 | Na ekranie 16x9 |
| ON_SCREEN_16X10 | Na ekranie 16x10 |
| WIDESCREEN | Szeroki ekran |
