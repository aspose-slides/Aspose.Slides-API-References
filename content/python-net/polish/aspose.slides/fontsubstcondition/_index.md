## FontSubstCondition enumeracja

Reprezentuje regułę zamiany czcionki

Typ FontSubstCondition udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| WHEN_INACCESSIBLE | Zamień, gdy czcionka nie zostanie znaleziona |
| ALWAYS | Zamień zawsze |
