## ITextStyle klasa

Właściwości formatowania stylu tekstu.

Typ ITextStyle udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`default_paragraph_format`](/slides/python-net/pl/aspose.slides/itextstyle/default_paragraph_format/) | Domyślne właściwości akapitu.<br/>            Tylko do odczytu [`IParagraphFormat`](/slides/python-net/pl/aspose.slides/iparagraphformat). |

## Metody

| Metoda | Opis |
| :- | :- |
| [`get_level(self, index)`](/slides/python-net/pl/aspose.slides/itextstyle/get_level/#int) | Jeśli istnieje poziom stylu, zwraca go, w przeciwnym razie zwraca None. |
| [`get_effective(self)`](/slides/python-net/pl/aspose.slides/itextstyle/get_effective/#) | Pobiera efektywne dane formatowania stylu tekstu z zastosowaną dziedziczeniem. |
