## SensitivityLabelContentType enumeracja

Reprezentuje typy oznaczania treści, które powinny być zastosowane w dokumencie.

Typ SensitivityLabelContentType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| NONE | Oznacza, że etykieta jest stosowana domyślnie lub automatycznie. |
| HEADER | Oznacza, że etykieta została zastosowana ręcznie.<br/>            Użyj dowolnej etykiety poufności, która została bezpośrednio zastosowana przez użytkownika. |
| FOOTER | Oznacza, że etykieta została zastosowana ręcznie.<br/>            Użyj dowolnej etykiety poufności, która została bezpośrednio zastosowana przez użytkownika. |
| WATERMARK | Oznacza, że etykieta została zastosowana ręcznie.<br/>            Użyj dowolnej etykiety poufności, która została bezpośrednio zastosowana przez użytkownika. |
| ENCRYPTION | Oznacza, że etykieta została zastosowana ręcznie.<br/>            Użyj dowolnej etykiety poufności, która została bezpośrednio zastosowana przez użytkownika. |
