## IPlaceholder klasa

Reprezentuje symbol zastępczy na slajdzie.

Typ IPlaceholder udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`orientation`](/slides/python-net/pl/aspose.slides/iplaceholder/orientation/) | Pobiera orientację symbolu zastępczego.<br/>            Tylko do odczytu [`Orientation`](/slides/python-net/pl/aspose.slides/orientation). |
| [`size`](/slides/python-net/pl/aspose.slides/iplaceholder/size/) | Pobiera rozmiar symbolu zastępczego.<br/>            Tylko do odczytu [`PlaceholderSize`](/slides/python-net/pl/aspose.slides/placeholdersize). |
| [`type`](/slides/python-net/pl/aspose.slides/iplaceholder/type/) | Pobiera typ symbolu zastępczego.<br/>            Tylko do odczytu [`PlaceholderType`](/slides/python-net/pl/aspose.slides/placeholdertype). |
| [`index`](/slides/python-net/pl/aspose.slides/iplaceholder/index/) | Pobiera indeks symbolu zastępczego.<br/>            Tylko do odczytu **int**. |
