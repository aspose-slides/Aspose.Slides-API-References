## właściwość ramki
Zwraca lub ustawia właściwości ramki kształtu.
            Odczyt/zapis [`IShapeFrame`](/slides/python-net/pl/aspose.slides/ishapeframe).

### Uwagi

Wartość każdej właściwości zwróconej instancji IShapeFrame nie jest undefined (nie jest NaN ani NotDefined).
            Wartość każdej właściwości przypisanej instancji IShapeFrame musi nie być undefined (musi nie być NaN ani NotDefined).
            Można ustawić wartości undefined dla właściwości instancji RawFrame.
