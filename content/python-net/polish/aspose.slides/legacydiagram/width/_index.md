## właściwość width
Pobiera lub ustawia width kształtu, mierzoną w punktach.
            Odczyt/zapis **float**.


### Uwagi

Zwracana wartość jest zawsze określona i nigdy nie jest **float**.
            Przypisana wartość musi być również określona; przypisuj **float** tylko do właściwości instancji `RawFrame`.
