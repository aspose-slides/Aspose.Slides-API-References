## ITextStyleEffectiveData klasa

Niezmienny obiekt zawierający skuteczne właściwości stylu tekstu.

Typ ITextStyleEffectiveData udostępnia następujących członków:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`default_paragraph_format`](/slides/python-net/pl/aspose.slides/itextstyleeffectivedata/default_paragraph_format/) | Zwraca skuteczne domyślne właściwości akapitu.<br/>            Tylko do odczytu [`IParagraphFormatEffectiveData`](/slides/python-net/pl/aspose.slides/iparagraphformateffectivedata). |

## Metody

| Metoda | Opis |
| :- | :- |
| [`get_level(self, index)`](/slides/python-net/pl/aspose.slides/itextstyleeffectivedata/get_level/#int) | Zwraca poziom skutecznego stylu. |


### Uwagi

Ten interfejs jest używany razem z interfejsem [`ITextStyle`](/slides/python-net/pl/aspose.slides/itextstyle) do zwracania skutecznych wartości formatowania z zastosowanym dziedziczeniem.
