## CommonSlideViewProperties klasa

Reprezentuje wspólne właściwości widoku slajdu.

Typ CommonSlideViewProperties udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`scale`](/slides/python-net/pl/aspose.slides/commonslideviewproperties/scale/) | Określa współczynnik skalowania widoku w procentach.<br/>            Odczyt/Zapis **int**. |
| [`variable_scale`](/slides/python-net/pl/aspose.slides/commonslideviewproperties/variable_scale/) | Określa, że zawartość widoku powinna być automatycznie skalowana, aby najlepiej dopasować się do bieżącego rozmiaru okna.<br/>            Odczyt/Zapis **bool**. |
| [`drawing_guides`](/slides/python-net/pl/aspose.slides/commonslideviewproperties/drawing_guides/) | Zwraca kolekcję prowadnic rysowania.<br/>            Tylko do odczytu [`IDrawingGuidesCollection`](/slides/python-net/pl/aspose.slides/idrawingguidescollection) |
