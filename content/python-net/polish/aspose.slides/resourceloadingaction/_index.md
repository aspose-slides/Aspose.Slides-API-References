## enumeracja ResourceLoadingAction

Określa tryb ładowania zasobów zewnętrznych.

Typ ResourceLoadingAction udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| DEFAULT | Aspose.Slides załaduje zasób zewnętrzny w zwykły sposób. |
| SKIP | Aspose.Slides pominie ładowanie zasobu zewnętrznego. Tylko odnośnik bez danych zostanie zapisany dla obrazu. |
| USER_PROVIDED | Aspose.Slides użyje tablicy bajtów dostarczonej przez użytkownika w **Aspose.Slides.IResourceLoadingArgs.SetData(Syste** jako dane obrazu. |
