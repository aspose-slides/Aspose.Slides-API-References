## ModernComment klasa

Reprezentuje komentarz na slajdzie.

**Dziedziczenie:**[`ModernComment`](/slides/python-net/pl/aspose.slides/moderncomment) → [`Comment`](/slides/python-net/pl/aspose.slides/comment)

Typ ModernComment udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`text`](/slides/python-net/pl/aspose.slides/moderncomment/text/) | Zwraca lub ustawia zwykły tekst komentarza slajdu.<br/>            Odczyt/zapis **str**. |
| [`created_time`](/slides/python-net/pl/aspose.slides/moderncomment/created_time/) | Zwraca lub ustawia czas utworzenia komentarza.<br/>            Ustawienie tej właściwości na **System.DateTime** oznacza brak ustawionego czasu komentarza.<br/>            Odczyt/zapis **System.DateTime**. |
| [`slide`](/slides/python-net/pl/aspose.slides/moderncomment/slide/) | Zwraca lub ustawia slajd nadrzędny komentarza.<br/>            Tylko do odczytu [`ISlide`](/slides/python-net/pl/aspose.slides/islide). |
| [`author`](/slides/python-net/pl/aspose.slides/moderncomment/author/) | Zwraca autora komentarza.<br/>            Tylko do odczytu [`ICommentAuthor`](/slides/python-net/pl/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/pl/aspose.slides/moderncomment/position/) | Zwraca lub ustawia pozycję komentarza na slajdzie.<br/>            Odczyt/zapis [`PointF`](/slides/python-net/pl/aspose.slides/pointf). |
| [`parent_comment`](/slides/python-net/pl/aspose.slides/moderncomment/parent_comment/) | Pobiera lub ustawia komentarz nadrzędny.<br/>            Odczyt/zapis [`IComment`](/slides/python-net/pl/aspose.slides/icomment). |
| [`shape`](/slides/python-net/pl/aspose.slides/moderncomment/shape/) | Zwraca kształt powiązany z komentarzem.<br/>            Tylko do odczytu [`IShape`](/slides/python-net/pl/aspose.slides/ishape). |
| [`text_selection_start`](/slides/python-net/pl/aspose.slides/moderncomment/text_selection_start/) | Pobiera lub ustawia początkową pozycję zaznaczenia tekstu w ramce tekstowej, jeśli komentarz jest powiązany z AutoShape.<br/>            Odczyt/zapis **int**. |
| [`text_selection_length`](/slides/python-net/pl/aspose.slides/moderncomment/text_selection_length/) | Pobiera lub ustawia długość zaznaczenia tekstu w ramce tekstowej, jeśli komentarz jest powiązany z AutoShape.<br/>            Odczyt/zapis **int**. |
| [`status`](/slides/python-net/pl/aspose.slides/moderncomment/status/) | Pobiera lub ustawia status komentarza.<br/>            Odczyt/zapis [`ModernCommentStatus`](/slides/python-net/pl/aspose.slides/moderncommentstatus). |
