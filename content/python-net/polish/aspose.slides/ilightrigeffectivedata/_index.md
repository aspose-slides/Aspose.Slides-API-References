## ILightRigEffectiveData klasa

Niezmienny obiekt, który zawiera efektywne właściwości układu oświetlenia.

Typ ILightRigEffectiveData udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`direction`](/slides/python-net/pl/aspose.slides/ilightrigeffectivedata/direction/) | Kierunek światła.<br/>            Tylko do odczytu [`LightingDirection`](/slides/python-net/pl/aspose.slides/lightingdirection). |
| [`light_type`](/slides/python-net/pl/aspose.slides/ilightrigeffectivedata/light_type/) | Reprezentuje wstępny zestaw światła po prawej, który może być zastosowany do kształtu.<br/>            Układ oświetlenia reprezentuje grupę świateł skierowanych w określony sposób względem sceny 3D.<br/>            Tylko do odczytu [`LightRigPresetType`](/slides/python-net/pl/aspose.slides/lightrigpresettype). |

## Metody

| Metoda | Opis |
| :- | :- |
| [`get_rotation(self)`](/slides/python-net/pl/aspose.slides/ilightrigeffectivedata/get_rotation/#) | Rotacja jest definiowana przy użyciu współrzędnej szerokości geograficznej, współrzędnej długości geograficznej oraz obrotu wokół osi jako współrzędnych szerokości i długości.<br/>            Pierwszy element w zwracanej tablicy – szerokość, drugi – długość, trzeci – obrót. |

### Uwagi
