## Klasa Point

Reprezentuje uporządkowaną parę całkowitych współrzędnych x i y, które definiują punkt w dwuwymiarowej płaszczyźnie. Zgodny z .NET `System.Drawing.Point`.

Typ Point udostępnia następujące elementy:

## Konstruktory

| Konstruktor | Opis |
| :- | :- |
| [`__init__(self, x=0, y=0)`](/slides/python-net/pl/aspose.slides/point/__init__/#int-int) | Tworzy punkt o podanych współrzędnych. Wartości zmiennoprzecinkowe są obcinane do liczb całkowitych. |

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`x`](/slides/python-net/pl/aspose.slides/point/x/) | Pobiera lub ustawia współrzędną x tego punktu.<br/>            Odczyt/zapis **int**. |
| [`y`](/slides/python-net/pl/aspose.slides/point/y/) | Pobiera lub ustawia współrzędną y tego punktu.<br/>            Odczyt/zapis **int**. |


### Uwagi

Punkty są porównywane według ich współrzędnych za pomocą `==` i mogą być używane jako klucze słownika lub elementy zbioru.
