## IViewProperties klasa

Właściwości widoku obejmujące całą prezentację.

Typ IViewProperties udostępnia następujące elementy:

## Properties

| Property | Description |
| :- | :- |
| [`last_view`](/slides/python-net/pl/aspose.slides/iviewproperties/last_view/) | Określa tryb widoku, który został użyty przy ostatnim zapisie dokumentu prezentacji.<br/>            Odczyt/zapis [`ViewType`](/slides/python-net/pl/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/pl/aspose.slides/iviewproperties/show_comments/) | Określa, czy komentarze slajdu powinny być wyświetlane.<br/>            Odczyt/zapis [`NullableBool`](/slides/python-net/pl/aspose.slides/nullablebool). |
| [`slide_view_properties`](/slides/python-net/pl/aspose.slides/iviewproperties/slide_view_properties/) | Określa wspólne właściwości widoku powiązane z trybem widoku slajdu.<br/>            Tylko do odczytu [`ICommonSlideViewProperties`](/slides/python-net/pl/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/pl/aspose.slides/iviewproperties/notes_view_properties/) | Określa wspólne właściwości widoku powiązane z trybem widoku notatek.<br/>            Tylko do odczytu [`ICommonSlideViewProperties`](/slides/python-net/pl/aspose.slides/icommonslideviewproperties). |
| [`normal_view_properties`](/slides/python-net/pl/aspose.slides/iviewproperties/normal_view_properties/) | Reprezentuje właściwości normalnego widoku. Normalny widok składa się z trzech obszarów zawartości: samego slajdu, bocznego obszaru zawartości oraz dolnego obszaru zawartości.<br/>            Tylko do odczytu [`INormalViewProperties`](/slides/python-net/pl/aspose.slides/inormalviewproperties). |
| [`grid_spacing`](/slides/python-net/pl/aspose.slides/iviewproperties/grid_spacing/) | Zwraca lub ustawia odstęp siatki, który powinien być używany dla siatki leżącej w podstawie dokumentu prezentacji, w punktach.<br/>            Odczyt/zapis **float**. |
