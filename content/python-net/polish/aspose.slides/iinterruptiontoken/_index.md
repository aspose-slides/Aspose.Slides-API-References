## IInterruptionToken klasa

Ta klasa reprezentuje token używany do sygnalizowania długotrwałym zadaniom, czy przerwanie zostało żądane.

Typ IInterruptionToken udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`is_interruption_requested`](/slides/python-net/pl/aspose.slides/iinterruptiontoken/is_interruption_requested/) | Zwraca **bool**.true jeśli przerwanie zostało żądane. |

## Metody

| Metoda | Opis |
| :- | :- |
| [`throw_if_interruption_requested(self)`](/slides/python-net/pl/aspose.slides/iinterruptiontoken/throw_if_interruption_requested/#) | Rzuca OperationCanceledException, jeśli<br/>            przerwanie zostało żądane.<br/>            Rzucony, gdy przerwanie zostało żądane. |
