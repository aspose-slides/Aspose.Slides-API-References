## IFillFormatEffectiveData klasa

Niezmienny obiekt zawierający skuteczne właściwości formatowania wypełnienia.

Typ IFillFormatEffectiveData udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`fill_type`](/slides/python-net/pl/aspose.slides/ifillformateffectivedata/fill_type/) | Zwraca typ wypełnienia.<br/>            Tylko do odczytu [`FillType`](/slides/python-net/pl/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/pl/aspose.slides/ifillformateffectivedata/solid_fill_color/) | Zwraca kolor wypełnienia.<br/>            Tylko do odczytu [`Color`](/slides/python-net/pl/aspose.slides/color). |
| [`solid_fill_scheme_color`](/slides/python-net/pl/aspose.slides/ifillformateffectivedata/solid_fill_scheme_color/) | Pobiera kolor wypełnienia określony w schemacie kolorów.<br/>            Wartość [`SchemeColor.NOT_DEFINED`](/slides/python-net/pl/aspose.slides/schemecolor/NOT_DEFINED) wskazuje, że [`IFillFormatEffectiveData.solid_fill_color`](/slides/python-net/pl/aspose.slides/ifillformateffectivedata/solid_fill_color) <br/>            nie jest kolorem schematu.<br/>            Tylko do odczytu [`SchemeColor`](/slides/python-net/pl/aspose.slides/schemecolor). |
| [`gradient_format`](/slides/python-net/pl/aspose.slides/ifillformateffectivedata/gradient_format/) | Zwraca format wypełnienia gradientowego.<br/>            Tylko do odczytu [`IGradientFormatEffectiveData`](/slides/python-net/pl/aspose.slides/igradientformateffectivedata). |
| [`pattern_format`](/slides/python-net/pl/aspose.slides/ifillformateffectivedata/pattern_format/) | Zwraca format wypełnienia wzorem.<br/>            Tylko do odczytu [`IPatternFormatEffectiveData`](/slides/python-net/pl/aspose.slides/ipatternformateffectivedata). |
| [`picture_fill_format`](/slides/python-net/pl/aspose.slides/ifillformateffectivedata/picture_fill_format/) | Zwraca format wypełnienia obrazem.<br/>            Tylko do odczytu [`IPictureFillFormatEffectiveData`](/slides/python-net/pl/aspose.slides/ipicturefillformateffectivedata). |
| [`rotate_with_shape`](/slides/python-net/pl/aspose.slides/ifillformateffectivedata/rotate_with_shape/) | Określa, czy wypełnienie powinno być obracane wraz z kształtem.<br/>            Tylko do odczytu **bool**. |


### Uwagi

Ten interfejs jest używany razem z interfejsem [`IFillFormat`](/slides/python-net/pl/aspose.slides/ifillformat) w celu zwrócenia skutecznych wartości formatowania z zastosowanym dziedziczeniem.
