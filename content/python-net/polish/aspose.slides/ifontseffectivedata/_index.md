## IFontsEffectiveData class

Obiekt niemutowalny, który zawiera zestaw efektywnych czcionek.

Typ IFontsEffectiveData udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`latin_font`](/slides/python-net/pl/aspose.slides/ifontseffectivedata/latin_font/) | Zwraca czcionkę łacińską.<br/>            Tylko do odczytu [`IFontData`](/slides/python-net/pl/aspose.slides/ifontdata). |
| [`east_asian_font`](/slides/python-net/pl/aspose.slides/ifontseffectivedata/east_asian_font/) | Zwraca czcionkę wschodnioazjatycką.<br/>            Tylko do odczytu [`IFontData`](/slides/python-net/pl/aspose.slides/ifontdata). |
| [`complex_script_font`](/slides/python-net/pl/aspose.slides/ifontseffectivedata/complex_script_font/) | Zwraca czcionkę dla skryptów złożonych.<br/>            Tylko do odczytu [`IFontData`](/slides/python-net/pl/aspose.slides/ifontdata). |


### Uwagi

Ten interfejs jest używany jako część interfejsów [`IBasePortionFormatEffectiveData`](/slides/python-net/pl/aspose.slides/ibaseportionformateffectivedata) i [`IFontSchemeEffectiveData`](/slides/python-net/pl/aspose.slides.theme/ifontschemeeffectivedata).
