## Captions klasa

Reprezentuje napisy zamknięte WebVTT.

Typ Captions udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`caption_id`](/slides/python-net/pl/aspose.slides/captions/caption_id/) | Zwraca globalnie unikalny identyfikator (GUID) napisów zamkniętych.<br/>            Tylko do odczytu **System.Guid**. |
| [`label`](/slides/python-net/pl/aspose.slides/captions/label/) | Zwraca lub ustawia etykietę napisów zamkniętych.<br/>            Do odczytu i zapisu **str**. |
| [`binary_data`](/slides/python-net/pl/aspose.slides/captions/binary_data/) | Zwraca dane binarne napisów zamkniętych.<br/>            Tylko do odczytu **int**[]. |
| [`data_as_string`](/slides/python-net/pl/aspose.slides/captions/data_as_string/) | Zwraca dane napisów zamkniętych jako ciąg zakodowany UTF-8<br/>            Tylko do odczytu **str**. |
