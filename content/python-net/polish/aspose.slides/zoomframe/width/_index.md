## width właściwość
Pobiera lub ustawia szerokość kształtu, mierzoną w punktach.
            Odczyt/zapis **float**.


### Uwagi

Zwracana wartość jest zawsze zdefiniowana i nigdy nie jest **float**.
            Przypisywana wartość musi również być zdefiniowana; przypisuj **float** tylko do właściwości instancji `RawFrame`.
