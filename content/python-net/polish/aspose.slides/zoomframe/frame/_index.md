            Odczyt/zapis [`IShapeFrame`](/slides/python-net/pl/aspose.slides/ishapeframe).


### Uwagi

Wartość każdej właściwości zwróconego wystąpienia IShapeFrame nie jest niezdefiniowana (nie jest NaN ani NotDefined).
            Wartość każdej właściwości przypisanego wystąpienia IShapeFrame musi nie być niezdefiniowana (musi nie być NaN ani NotDefined).
            Możesz ustawić niezdefiniowane wartości dla właściwości wystąpienia RawFrame.
