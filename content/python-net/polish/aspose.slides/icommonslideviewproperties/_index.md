## ICommonSlideViewProperties klasa

Reprezentuje wspólne właściwości widoku slajdu.

Typ ICommonSlideViewProperties udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`scale`](/slides/python-net/pl/aspose.slides/icommonslideviewproperties/scale/) | Określa współczynnik skalowania widoku w procentach.<br/>            Odczyt/zapis **int**. |
| [`variable_scale`](/slides/python-net/pl/aspose.slides/icommonslideviewproperties/variable_scale/) | Określa, że treść widoku powinna automatycznie skalować się, aby jak najlepiej dopasować do bieżącego rozmiaru okna.<br/>            Odczyt/zapis **bool**. |
| [`drawing_guides`](/slides/python-net/pl/aspose.slides/icommonslideviewproperties/drawing_guides/) | Zwraca kolekcję linii prowadnic rysunkowych.<br/>            Tylko do odczytu [`IDrawingGuidesCollection`](/slides/python-net/pl/aspose.slides/idrawingguidescollection) |
