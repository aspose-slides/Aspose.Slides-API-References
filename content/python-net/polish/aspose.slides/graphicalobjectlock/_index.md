## GraphicalObjectLock klasa

Określa, które operacje są wyłączone w nadrzędnym obiekcie GraphicalObject.

**Dziedziczenie:**[`GraphicalObjectLock`](/slides/python-net/pl/aspose.slides/graphicalobjectlock) → [`BaseShapeLock`](/slides/python-net/pl/aspose.slides/baseshapelock)

Typ GraphicalObjectLock udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`no_locks`](/slides/python-net/pl/aspose.slides/graphicalobjectlock/no_locks/) | Zwraca true, jeśli wszystkie flagi blokady są wyłączone.<br/>            Tylko do odczytu **bool**. |
| [`grouping_locked`](/slides/python-net/pl/aspose.slides/graphicalobjectlock/grouping_locked/) | Określa, czy dodawanie tego kształtu do grupy jest zabronione.<br/>            Do odczytu i zapisu **bool**. |
| [`drilldown_locked`](/slides/python-net/pl/aspose.slides/graphicalobjectlock/drilldown_locked/) | Określa, czy wybieranie podkształtów tego obiektu jest zabronione.<br/>            Do odczytu i zapisu **bool**. |
| [`select_locked`](/slides/python-net/pl/aspose.slides/graphicalobjectlock/select_locked/) | Określa, czy wybieranie tego kształtu jest zabronione.<br/>            Do odczytu i zapisu **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/pl/aspose.slides/graphicalobjectlock/aspect_ratio_locked/) | Określa, czy kształt musi zachować proporcje przy zmianie rozmiaru.<br/>            Do odczytu i zapisu **bool**. |
| [`position_locked`](/slides/python-net/pl/aspose.slides/graphicalobjectlock/position_locked/) | Określa, czy przemieszczanie tego kształtu jest zabronione.<br/>            Do odczytu i zapisu **bool**. |
| [`size_locked`](/slides/python-net/pl/aspose.slides/graphicalobjectlock/size_locked/) | Określa, czy zmiana rozmiaru tego kształtu jest zabroniona.<br/>            Do odczytu i zapisu **bool**. |
