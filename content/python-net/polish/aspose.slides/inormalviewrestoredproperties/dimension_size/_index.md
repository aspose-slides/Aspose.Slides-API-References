## dimension_size właściwość
Określa rozmiar obszaru slajdu (szerokość, gdy jest potomkiem RestoredTop, wysokość, gdy jest potomkiem RestoredLeft).
Odczyt/zapis **float**.
Generuje wyjątek, gdy wartość jest mniejsza niż 0 lub większa niż 100.
