## INormalViewRestoredProperties klasa

Określa rozmiar obszaru slajdu ((szerokość, gdy jest dzieckiem restoredTop, wysokość, gdy jest dzieckiem restoredLeft) normalnego widoku, gdy obszar ma zmienny rozmiar przywrócony (nie zminimalizowany ani zmaksymalizowany).

Typ INormalViewRestoredProperties udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`dimension_size`](/slides/python-net/pl/aspose.slides/inormalviewrestoredproperties/dimension_size/) | Określa rozmiar obszaru slajdu (szerokość, gdy jest dzieckiem RestoredTop, wysokość, gdy jest dzieckiem RestoredLeft).<br/>            Odczyt/zapis **float**.<br/>            Rzuca wyjątek, gdy wartość jest mniejsza niż 0 lub większa niż 100. |
| [`auto_adjust`](/slides/python-net/pl/aspose.slides/inormalviewrestoredproperties/auto_adjust/) | Określa, czy rozmiar bocznego regionu treści powinien kompensować nowy rozmiar<br/>            przy zmianie rozmiaru okna zawierającego widok w aplikacji<br/>            Odczyt/zapis **bool**. |
