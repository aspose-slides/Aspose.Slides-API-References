## ZoomImageType enumeracja

Określa, czy obiekt Zoom używa podglądu slajdu lub obrazu okładki.

Typ ZoomImageType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| PREVIEW | Użyj obrazu slajdu lub sekcji. |
| COVER | Użyj własnego obrazu. |
