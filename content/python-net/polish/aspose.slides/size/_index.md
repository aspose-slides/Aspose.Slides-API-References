## Size klasa

Przechowuje uporządkowaną parę liczb całkowitych, określającą szerokość i wysokość. Zgodny z .NET `System.Drawing.Size`.

Typ Size udostępnia następujące elementy:

## Konstruktorzy

| Konstruktor | Opis |
| :- | :- |
| [`__init__(self, width=0, height=0)`](/slides/python-net/pl/aspose.slides/size/__init__/#int-int) | Tworzy rozmiar o określonej szerokości i wysokości. Wartości zmiennoprzecinkowe są obcinane do liczb całkowitych. |

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`width`](/slides/python-net/pl/aspose.slides/size/width/) | Zwraca poziomy komponent tego rozmiaru.<br/>            Tylko do odczytu **int**. |
| [`height`](/slides/python-net/pl/aspose.slides/size/height/) | Zwraca pionowy komponent tego rozmiaru.<br/>            Tylko do odczytu **int**. |


### Uwagi

Rozmiary są porównywane według ich komponentów za pomocą `==` i mogą być używane jako klucze słowników lub elementy zestawów.
