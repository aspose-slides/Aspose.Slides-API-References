## IFillFormat klasa

Reprezentuje opcje formatowania wypełnienia.

Typ IFillFormat udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`fill_type`](/slides/python-net/pl/aspose.slides/ifillformat/fill_type/) | Zwraca lub ustawia typ wypełnienia.<br/>            Odczyt/Zapis [`FillType`](/slides/python-net/pl/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/pl/aspose.slides/ifillformat/solid_fill_color/) | Zwraca kolor wypełnienia.<br/>            Tylko do odczytu [`IColorFormat`](/slides/python-net/pl/aspose.slides/icolorformat). |
| [`gradient_format`](/slides/python-net/pl/aspose.slides/ifillformat/gradient_format/) | Zwraca format wypełnienia gradientowego.<br/>            Tylko do odczytu [`IGradientFormat`](/slides/python-net/pl/aspose.slides/igradientformat). |
| [`pattern_format`](/slides/python-net/pl/aspose.slides/ifillformat/pattern_format/) | Zwraca format wypełnienia wzorem.<br/>            Tylko do odczytu [`IPatternFormat`](/slides/python-net/pl/aspose.slides/ipatternformat). |
| [`picture_fill_format`](/slides/python-net/pl/aspose.slides/ifillformat/picture_fill_format/) | Zwraca format wypełnienia obrazu.<br/>            Tylko do odczytu [`IPictureFillFormat`](/slides/python-net/pl/aspose.slides/ipicturefillformat). |
| [`rotate_with_shape`](/slides/python-net/pl/aspose.slides/ifillformat/rotate_with_shape/) | Określa, czy wypełnienie powinno być obracane wraz z kształtem.<br/>            Odczyt/Zapis [`NullableBool`](/slides/python-net/pl/aspose.slides/nullablebool). |
