## enumeracja BlackWhiteMode

Określa, jak kolorowy kształt powinien być przekształcany na czarno-biały.

Typ BlackWhiteMode udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| NOT_DEFINED | Właściwość nie jest ustawiona |
| COLOR | Obiekt jest renderowany z normalnym kolorowaniem |
| AUTOMATIC | Obiekt jest renderowany z automatycznym kolorowaniem |
| GRAY | Obiekt jest renderowany w odcieniach szarości |
| LIGHT_GRAY | Obiekt jest renderowany w jasnoszarym kolorze |
| INVERSE_GRAY | Obiekt jest renderowany w odwróconej szarości |
| GRAY_WHITE | Obiekt jest renderowany w szaro-białym kolorze |
| BLACK_GRAY | Obiekt jest renderowany w czarno-szarym kolorze |
| BLACK_WHITE | Obiekt jest renderowany w czarno-białym kolorze |
| BLACK | Obiekt jest renderowany wyłącznie w czarnym kolorze |
| WHITE | Obiekt jest renderowany w białym kolorze |
| HIDDEN | Obiekt nie jest renderowany |
