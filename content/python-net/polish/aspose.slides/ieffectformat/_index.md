## IEffectFormat klasa

Reprezentuje właściwości efektu kształtu.

Typ IEffectFormat udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`is_no_effects`](/slides/python-net/pl/aspose.slides/ieffectformat/is_no_effects/) | Zwraca true, jeśli wszystkie efekty są wyłączone (tak jak przy nowo utworzonym, domyślnym obiekcie EffectFormat).<br/>            Tylko do odczytu **bool**. |
| [`blur_effect`](/slides/python-net/pl/aspose.slides/ieffectformat/blur_effect/) | Efekt rozmycia.<br/>            Odczyt/zapis [`IBlur`](/slides/python-net/pl/aspose.slides.effects/iblur). |
| [`fill_overlay_effect`](/slides/python-net/pl/aspose.slides/ieffectformat/fill_overlay_effect/) | Efekt nakładki wypełnienia.<br/>            Odczyt/zapis [`IFillOverlay`](/slides/python-net/pl/aspose.slides.effects/ifilloverlay). |
| [`glow_effect`](/slides/python-net/pl/aspose.slides/ieffectformat/glow_effect/) | Efekt poświaty.<br/>            Odczyt/zapis [`IGlow`](/slides/python-net/pl/aspose.slides.effects/iglow). |
| [`inner_shadow_effect`](/slides/python-net/pl/aspose.slides/ieffectformat/inner_shadow_effect/) | Cień wewnętrzny.<br/>            Odczyt/zapis [`IInnerShadow`](/slides/python-net/pl/aspose.slides.effects/iinnershadow). |
| [`outer_shadow_effect`](/slides/python-net/pl/aspose.slides/ieffectformat/outer_shadow_effect/) | Cień zewnętrzny.<br/>            Odczyt/zapis [`IOuterShadow`](/slides/python-net/pl/aspose.slides.effects/ioutershadow). |
| [`preset_shadow_effect`](/slides/python-net/pl/aspose.slides/ieffectformat/preset_shadow_effect/) | Cień wstępnie ustawiony.<br/>            Odczyt/zapis [`IPresetShadow`](/slides/python-net/pl/aspose.slides.effects/ipresetshadow). |
| [`reflection_effect`](/slides/python-net/pl/aspose.slides/ieffectformat/reflection_effect/) | Odbicie.<br/>            Odczyt/zapis [`IReflection`](/slides/python-net/pl/aspose.slides.effects/ireflection). |
| [`soft_edge_effect`](/slides/python-net/pl/aspose.slides/ieffectformat/soft_edge_effect/) | Miękka krawędź.<br/>            Odczyt/zapis [`ISoftEdge`](/slides/python-net/pl/aspose.slides.effects/isoftedge). |
