## Właściwość ramki
Zwraca lub ustawia właściwości ramki kształtu.
            Odczyt/zapis [`IShapeFrame`](/slides/python-net/pl/aspose.slides/ishapeframe).


### Uwagi

Wartość każdej właściwości zwróconego egzemplarza IShapeFrame nie jest 
            undefined (nie jest NaN ani NotDefined).
Wartość każdej właściwości przypisanego egzemplarza IShapeFrame musi nie być 
            undefined (musi nie być NaN ani NotDefined).
Możesz ustawić wartości undefined dla właściwości egzemplarza RawFrame.
