## CustomXmlPart klasa

Reprezentuje niestandardową część xml.

Typ CustomXmlPart udostępnia następujące elementy:

## Właściwości

| Property | Description |
| :- | :- |
| [`xml_data`](/slides/python-net/pl/aspose.slides/customxmlpart/xml_data/) | Zwraca lub ustawia dane xml.<br/>            Read/write **int**[].<br/>            wartość to `None`.wartość jest pusta lub dane xml są nieprawidłowe. |
| [`xml_as_string`](/slides/python-net/pl/aspose.slides/customxmlpart/xml_as_string/) | Zwraca lub ustawia dane xml jako ciąg UTF-8.<br/>            Read/write **str**.<br/>            wartość to `None`.wartość jest pusta lub dane xml są nieprawidłowe. |
| [`item_id`](/slides/python-net/pl/aspose.slides/customxmlpart/item_id/) | Określa globalnie unikalny identyfikator (GUID), który jednoznacznie identyfikuje pojedynczą niestandardową część XML <br/>            w dokumencie Office Open XML.<br/>            Read-only **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/pl/aspose.slides/customxmlpart/namespace_schemas/) | Zwraca kolekcję schematów XML powiązanych z niestandardową częścią XML.<br/>            Read-only **str**[]. |

| :- | :- |
