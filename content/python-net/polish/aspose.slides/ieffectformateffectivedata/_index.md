## IEffectFormatEffectiveData klasa

Niezmienny obiekt zawierający efektywne właściwości formatowania efektów.

Typ IEffectFormatEffectiveData udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`is_no_effects`](/slides/python-net/pl/aspose.slides/ieffectformateffectivedata/is_no_effects/) | Zwraca true, jeśli wszystkie efekty są wyłączone (tak jak w nowo utworzonym, domyślnym obiekcie EffectFormat).<br/>            Tylko do odczytu **bool**. |
| [`blur_effect`](/slides/python-net/pl/aspose.slides/ieffectformateffectivedata/blur_effect/) | Efekt rozmycia.<br/>            Tylko do odczytu [`IBlurEffectiveData`](/slides/python-net/pl/aspose.slides.effects/iblureffectivedata). |
| [`fill_overlay_effect`](/slides/python-net/pl/aspose.slides/ieffectformateffectivedata/fill_overlay_effect/) | Efekt nakładki wypełnienia.<br/>            Tylko do odczytu [`IFillOverlayEffectiveData`](/slides/python-net/pl/aspose.slides.effects/ifilloverlayeffectivedata). |
| [`glow_effect`](/slides/python-net/pl/aspose.slides/ieffectformateffectivedata/glow_effect/) | Efekt poświaty.<br/>            Tylko do odczytu [`IGlowEffectiveData`](/slides/python-net/pl/aspose.slides.effects/igloweffectivedata). |
| [`inner_shadow_effect`](/slides/python-net/pl/aspose.slides/ieffectformateffectivedata/inner_shadow_effect/) | Cień wewnętrzny.<br/>            Tylko do odczytu [`IInnerShadowEffectiveData`](/slides/python-net/pl/aspose.slides.effects/iinnershadoweffectivedata). |
| [`outer_shadow_effect`](/slides/python-net/pl/aspose.slides/ieffectformateffectivedata/outer_shadow_effect/) | Cień zewnętrzny.<br/>            Tylko do odczytu [`IOuterShadowEffectiveData`](/slides/python-net/pl/aspose.slides.effects/ioutershadoweffectivedata). |
| [`preset_shadow_effect`](/slides/python-net/pl/aspose.slides/ieffectformateffectivedata/preset_shadow_effect/) | Cień wstępnie ustawiony.<br/>            Tylko do odczytu [`IPresetShadowEffectiveData`](/slides/python-net/pl/aspose.slides.effects/ipresetshadoweffectivedata). |
| [`reflection_effect`](/slides/python-net/pl/aspose.slides/ieffectformateffectivedata/reflection_effect/) | Odbicie.<br/>            Tylko do odczytu [`IReflectionEffectiveData`](/slides/python-net/pl/aspose.slides.effects/ireflectioneffectivedata). |
| [`soft_edge_effect`](/slides/python-net/pl/aspose.slides/ieffectformateffectivedata/soft_edge_effect/) | Miękka krawędź.<br/>            Tylko do odczytu [`ISoftEdgeEffectiveData`](/slides/python-net/pl/aspose.slides.effects/isoftedgeeffectivedata). |

### Uwagi

Ten interfejs jest używany razem z interfejsem [`IEffectFormat`](/slides/python-net/pl/aspose.slides/ieffectformat), aby zwrócić efektywne wartości formatowania z zastosowanym dziedziczeniem.
