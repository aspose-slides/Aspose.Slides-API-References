## TextAlignment enumeracja

Reprezentuje różne style wyrównania tekstu.

Typ TextAlignment udostępnia następujących członków:

## Pola

| Pole | Opis |
| :- | :- |
| NOT_DEFINED | Domyślne wyrównanie. |
| LEFT | Wyrównanie do lewej. |
| CENTER | Wyrównanie do środka. |
| RIGHT | Wyrównanie do prawej. |
| JUSTIFY | Wyrównanie justowane. |
| JUSTIFY_LOW | Kashida justowanie niskie. |
| DISTRIBUTED | Rozproszone wyrównanie. |
