## check_password(self, password) {#str}
Sprawdza, czy hasło jest poprawne dla prezentacji zabezpieczonej otwartym hasłem.

### Zwraca

True, jeśli prezentacja jest zabezpieczona otwartym hasłem i hasło jest poprawne, w przeciwnym razie false.



```python
def check_password(self, password):
    ...
```


| Parameter | Type | Description |
| :- | :- | :- |
| password | **str** | Hasło do sprawdzenia. |

### Uwaga

Gdy hasło jest None lub puste, ta metoda zwraca false.
