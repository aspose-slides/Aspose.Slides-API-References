## NormalViewRestoredProperties klasa

Określa rozmiary regionu slajdu ((szerokość, gdy jest dzieckiem restoredTop, wysokość, gdy jest dzieckiem restoredLeft) normalnego widoku, gdy region ma zmienny rozmiar przywrócony (niezminimalizowany ani nie zmaksymalizowany).

Typ NormalViewRestoredProperties udostępnia następujące elementy:

## Właściwości

| Property | Description |
| :- | :- |
| [`dimension_size`](/slides/python-net/pl/aspose.slides/normalviewrestoredproperties/dimension_size/) | Określa rozmiar regionu slajdu (szerokość, gdy jest dzieckiem RestoredTop, wysokość, gdy jest dzieckiem RestoredLeft).<br/>            Odczyt/zapis **float**. |
| [`auto_adjust`](/slides/python-net/pl/aspose.slides/normalviewrestoredproperties/auto_adjust/) | Określa, czy rozmiar bocznego regionu zawartości powinien kompensować nowy rozmiar<br/>            przy zmianie rozmiaru okna zawierającego widok w aplikacji<br/>            Odczyt/zapis **bool**. |
