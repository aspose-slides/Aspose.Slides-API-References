## klasa IFonts

Reprezentuje kolekcję czcionek.

Typ IFonts udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`latin_font`](/slides/python-net/pl/aspose.slides/ifonts/latin_font/) | Zwraca lub ustawia czcionkę łacińską.<br/>            Odczyt/zapis [`IFontData`](/slides/python-net/pl/aspose.slides/ifontdata). |
| [`east_asian_font`](/slides/python-net/pl/aspose.slides/ifonts/east_asian_font/) | Zwraca lub ustawia czcionkę wschodnioazjatycką.<br/>            Odczyt/zapis [`IFontData`](/slides/python-net/pl/aspose.slides/ifontdata). |
| [`complex_script_font`](/slides/python-net/pl/aspose.slides/ifonts/complex_script_font/) | Zwraca lub ustawia czcionkę złożonych skryptów.<br/>            Odczyt/zapis [`IFontData`](/slides/python-net/pl/aspose.slides/ifontdata). |

## Metody

| Metoda | Opis |
| :- | :- |
| [`get_script_font_map(self)`](/slides/python-net/pl/aspose.slides/ifonts/get_script_font_map/#) | Zwraca listę wszystkich definicji czcionek skryptu w postaci par ciąg-ciąg w prezentacji. |
| [`get_script_font(self, script)`](/slides/python-net/pl/aspose.slides/ifonts/get_script_font/#str) | Pobiera nazwę czcionki powiązaną z określonym tagiem skryptu z motywu prezentacji. |
| [`set_script_font(self, script, font_name)`](/slides/python-net/pl/aspose.slides/ifonts/set_script_font/#str-str) | Przypisuje nazwę czcionki do określonego tagu skryptu, co definiuje sposób renderowania tekstu tego skryptu w prezentacji. |
| [`remove_script_font(self, script)`](/slides/python-net/pl/aspose.slides/ifonts/remove_script_font/#str) | Usuwa ustawienie czcionki powiązane z określonym tagiem skryptu z kolekcji czcionek motywu. |
