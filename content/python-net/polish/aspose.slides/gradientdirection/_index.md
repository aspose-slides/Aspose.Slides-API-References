## GradientDirection enumeracja

Reprezentuje styl gradientu.

Typ GradientDirection udostępnia następujących członków:

## Pola

| Pole | Opis |
| :- | :- |
| NOT_DEFINED | Nie określono |
| FROM_CORNER1 | Z lewego górnego rogu |
| FROM_CORNER2 | Z prawego górnego rogu |
| FROM_CORNER3 | Z lewego dolnego rogu |
| FROM_CORNER4 | Z prawego dolnego rogu |
| FROM_CENTER | Z środka |
