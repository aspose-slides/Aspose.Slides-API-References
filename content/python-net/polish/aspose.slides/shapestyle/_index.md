## ShapeStyle klasa

Reprezentuje odwołanie do stylu kształtu.

Typ ShapeStyle udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`line_color`](/slides/python-net/pl/aspose.slides/shapestyle/line_color/) | Zwraca kolor konturu kształtu.<br/>            Tylko do odczytu [`IColorFormat`](/slides/python-net/pl/aspose.slides/icolorformat). |
| [`line_style_index`](/slides/python-net/pl/aspose.slides/shapestyle/line_style_index/) | Zwraca lub ustawia indeks kolumny linii w macierzy stylu.<br/>            Odczyt/zapis **int**. |
| [`fill_color`](/slides/python-net/pl/aspose.slides/shapestyle/fill_color/) | Zwraca kolor wypełnienia kształtu.<br/>            Tylko do odczytu [`IColorFormat`](/slides/python-net/pl/aspose.slides/icolorformat). |
| [`fill_style_index`](/slides/python-net/pl/aspose.slides/shapestyle/fill_style_index/) | Zwraca lub ustawia indeks kolumny wypełnienia kształtu w macierzach stylów.<br/>            0 oznacza brak wypełnienia,<br/>            dodatnia wartość - indeks w stylach wypełnienia motywu,<br/>            ujemna wartość - indeks w stylach tła motywu.<br/>            Odczyt/zapis **int**. |
| [`effect_color`](/slides/python-net/pl/aspose.slides/shapestyle/effect_color/) | Zwraca kolor efektu kształtu.<br/>            Tylko do odczytu [`IColorFormat`](/slides/python-net/pl/aspose.slides/icolorformat). |
| [`effect_style_index`](/slides/python-net/pl/aspose.slides/shapestyle/effect_style_index/) | Zwraca lub ustawia indeks kolumny efektu kształtu w macierzy stylu.<br/>            Odczyt/zapis **int**. |
| [`font_color`](/slides/python-net/pl/aspose.slides/shapestyle/font_color/) | Zwraca kolor czcionki kształtu.<br/>            Tylko do odczytu [`IColorFormat`](/slides/python-net/pl/aspose.slides/icolorformat). |
| [`font_collection_index`](/slides/python-net/pl/aspose.slides/shapestyle/font_collection_index/) | Zwraca lub ustawia indeks czcionki kształtu w kolekcji czcionek.<br/>            Odczyt/zapis [`FontCollectionIndex`](/slides/python-net/pl/aspose.slides/fontcollectionindex). |
