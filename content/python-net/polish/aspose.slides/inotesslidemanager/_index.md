## INotesSlideManager klasa

Menedżer slajdów notatek.

Typ INotesSlideManager udostępnia następujące członki:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`notes_slide`](/slides/python-net/pl/aspose.slides/inotesslidemanager/notes_slide/) | Zwraca slajd notatek dla bieżącego slajdu. Zwraca None, jeśli slajd nie ma slajdu notatek.<br/>            Tylko do odczytu [`INotesSlide`](/slides/python-net/pl/aspose.slides/inotesslide). |

## Metody

| Metoda | Opis |
| :- | :- |
| [`add_notes_slide(self)`](/slides/python-net/pl/aspose.slides/inotesslidemanager/add_notes_slide/#) | Zwraca slajd notatek dla bieżącego slajdu, tworząc go, jeśli nie istnieje. |
