## ITextHighlightingOptions klasa

Reprezentuje opcje, które mogą być użyte do podświetlania tekstu w ramce tekstowej.

Typ ITextHighlightingOptions udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`case_sensitive`](/slides/python-net/pl/aspose.slides/itexthighlightingoptions/case_sensitive/) | Ustaw true, aby użyć wyszukiwania rozróżniającego wielkość liter, false - w przeciwnym razie.<br/>            Odczyt/zapis **bool**. |
| [`whole_words_only`](/slides/python-net/pl/aspose.slides/itexthighlightingoptions/whole_words_only/) | Ustaw true, aby dopasować wyłącznie całe słowa, false - w przeciwnym razie.<br/>            Odczyt/zapis **bool**. |
