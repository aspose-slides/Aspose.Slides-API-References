## Klasa TagCollection

Reprezentuje kolekcję tagów (pary łańcuchów definiowane przez użytkownika)

Typ TagCollection udostępnia następujące członki:

## Metody

| Metoda | Opis |
| :- | :- |
| [`add(self, name, value)`](/slides/python-net/pl/aspose.slides/tagcollection/add/#str-str) | Adds a new tag to collection. |
| [`remove(self, name)`](/slides/python-net/pl/aspose.slides/tagcollection/remove/#str) | Removes the tag with a specified name from the collection. |
| [`index_of_name(self, name)`](/slides/python-net/pl/aspose.slides/tagcollection/index_of_name/#str) | Returns the zero-based index of the specified key in the collection. |
| [`remove_at(self, index)`](/slides/python-net/pl/aspose.slides/tagcollection/remove_at/#int) | Removes the tag at the specified index. |
| [`clear(self)`](/slides/python-net/pl/aspose.slides/tagcollection/clear/#) | Removes all tags from the collection. |
| [`get_value_by_index(self, index)`](/slides/python-net/pl/aspose.slides/tagcollection/get_value_by_index/#int) | Returns value of a tag at the specified index. |
| [`get_name_by_index(self, index)`](/slides/python-net/pl/aspose.slides/tagcollection/get_name_by_index/#int) | Returns key of a tag at the specified index. |
| [`get_names_of_tags(self)`](/slides/python-net/pl/aspose.slides/tagcollection/get_names_of_tags/#) | Returns names of tags. |
