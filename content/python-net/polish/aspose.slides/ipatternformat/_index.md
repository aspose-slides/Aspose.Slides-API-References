## IPatternFormat klasa

Reprezentuje wzorzec do wypełniania kształtu.

Typ IPatternFormat udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`pattern_style`](/slides/python-net/pl/aspose.slides/ipatternformat/pattern_style/) | Zwraca lub ustawia styl wzorca.<br/>            Odczyt/zapis [`PatternStyle`](/slides/python-net/pl/aspose.slides/patternstyle). |
| [`fore_color`](/slides/python-net/pl/aspose.slides/ipatternformat/fore_color/) | Zwraca kolor pierwszego planu wzorca.<br/>            Tylko do odczytu [`IColorFormat`](/slides/python-net/pl/aspose.slides/icolorformat). |
| [`back_color`](/slides/python-net/pl/aspose.slides/ipatternformat/back_color/) | Zwraca kolor tła wzorca.<br/>            Tylko do odczytu [`IColorFormat`](/slides/python-net/pl/aspose.slides/icolorformat). |
