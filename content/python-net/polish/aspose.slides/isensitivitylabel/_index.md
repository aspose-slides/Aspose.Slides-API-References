## ISensitivityLabel klasa

Reprezentuje etykietę wrażliwości z Microsoft Purview Information Protection.

Typ ISensitivityLabel ujawnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`id`](/slides/python-net/pl/aspose.slides/isensitivitylabel/id/) | Zwraca lub ustawia identyfikator etykiety wrażliwości.<br/>            Odczyt/zapis **str**. |
| [`site_id`](/slides/python-net/pl/aspose.slides/isensitivitylabel/site_id/) | Zwraca lub ustawia identyfikator witryny Azure Active Directory (Azure AD) <br/>            odpowiadający polityce etykiety wrażliwości, która opisuje etykietę wrażliwości.<br/>            Odczyt/zapis **System.Guid**. |
| [`is_enabled`](/slides/python-net/pl/aspose.slides/isensitivitylabel/is_enabled/) | Wskazuje, czy etykieta wrażliwości jest włączona. |
| [`is_removed`](/slides/python-net/pl/aspose.slides/isensitivitylabel/is_removed/) | Wskazuje, czy etykieta wrażliwości została usunięta. |
| [`assignment_method_type`](/slides/python-net/pl/aspose.slides/isensitivitylabel/assignment_method_type/) | Zwraca lub ustawia metodę przypisania etykiety wrażliwości.<br/>            Odczyt/zapis [`SensitivityLabelAssignmentType`](/slides/python-net/pl/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/pl/aspose.slides/isensitivitylabel/content_mark_types/) | Zwraca listę typów oznaczeń treści, które powinny być zastosowane do pliku. |
