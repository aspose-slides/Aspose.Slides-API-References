## volume_value właściwość
Zwraca lub ustawia dokładną głośność wideo jako procent.
             Wartość jest wyrażona jako procent od 0 do 100. Użyj tej właściwości, aby odczytać lub ustawić wartości głośności, które są dokładniejsze niż predefiniowane poziomy dostępne poprzez właściwość [`VideoFrame.volume`](/slides/python-net/pl/aspose.slides/videoframe/volume).
             Odczyt/zapis **float**.
