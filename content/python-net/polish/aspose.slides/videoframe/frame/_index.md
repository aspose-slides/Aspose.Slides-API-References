## właściwość ramki
Zwraca lub ustawia właściwości ramki kształtu.
            Odczyt/zapis [`IShapeFrame`](/slides/python-net/pl/aspose.slides/ishapeframe).

### Uwagi

Wartość każdej właściwości zwróconego wystąpienia IShapeFrame nie jest nieokreślona (nie jest NaN ani NotDefined).
            Wartość każdej właściwości przypisanego wystąpienia IShapeFrame musi nie być nieokreślona (musi nie być NaN ani NotDefined).
            Można ustawić nieokreślone wartości dla właściwości wystąpienia RawFrame.
