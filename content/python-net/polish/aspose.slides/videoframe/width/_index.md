## właściwość width

            Odczyt/zapis **float**.

### Uwagi

Zwracana wartość jest zawsze określona i nigdy nie jest **float**.
            Przypisana wartość musi również być określona; przypisuj **float** tylko do właściwości instancji `RawFrame`.
