## SlideLayoutType enumeracja

Reprezentuje typ układu slajdu.

Typ SlideLayoutType udostępnia następujące członki:

## Pola

| Pole | Opis |
| :- | :- |
| CUSTOM | Niestandardowy |
| TITLE | Tytuł |
| TEXT | Tekst |
| TWO_COLUMN_TEXT | Tekst w dwóch kolumnach |
| TABLE | Tabela |
| TEXT_AND_CHART | Tekst i wykres |
| CHART_AND_TEXT | Wykres i tekst |
| DIAGRAM | Diagram |
| CHART | Wykres |
| TEXT_AND_CLIP_ART | Tekst i grafika Clip Art |
| CLIP_ART_AND_TEXT | Grafika Clip Art i tekst |
| TITLE_ONLY | Tylko tytuł |
| BLANK | Pusty |
| TEXT_AND_OBJECT | Tekst i obiekt |
| OBJECT_AND_TEXT | Obiekt i tekst |
| OBJECT | Obiekt |
| TITLE_AND_OBJECT | Tytuł i obiekt |
| TEXT_AND_MEDIA | Tekst i multimedia |
| MEDIA_AND_TEXT | Multimedia i tekst |
| OBJECT_OVER_TEXT | Obiekt nad tekstem |
| TEXT_OVER_OBJECT | Tekst nad obiektem |
| TEXT_AND_TWO_OBJECTS | Tekst i dwa obiekty |
| TWO_OBJECTS_AND_TEXT | Dwa obiekty i tekst |
| TWO_OBJECTS_OVER_TEXT | Dwa obiekty nad tekstem |
| FOUR_OBJECTS | Cztery obiekty |
| VERTICAL_TEXT | Pionowy tekst |
| CLIP_ART_AND_VERTICAL_TEXT | Grafika Clip Art i pionowy tekst |
| VERTICAL_TITLE_AND_TEXT | Pionowy tytuł i tekst |
| VERTICAL_TITLE_AND_TEXT_OVER_CHART | Pionowy tytuł i tekst nad wykresem |
| TWO_OBJECTS | Dwa obiekty |
| OBJECT_AND_TWO_OBJECT | Obiekt i dwa obiekty |
| TWO_OBJECTS_AND_OBJECT | Dwa obiekty i obiekt |
| SECTION_HEADER | Nagłówek sekcji |
| TWO_TEXT_AND_TWO_OBJECTS | Dwa teksty i dwa obiekty |
| TITLE_OBJECT_AND_CAPTION | Tytuł, obiekt i podpis |
| PICTURE_AND_CAPTION | Obraz i podpis |
