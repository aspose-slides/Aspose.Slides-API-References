## IBackgroundEffectiveData klasa

Obiekt niezmienny, który zawiera skuteczne właściwości tła.

Typ IBackgroundEffectiveData udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`fill_format`](/slides/python-net/pl/aspose.slides/ibackgroundeffectivedata/fill_format/) | Zwraca efektywny format wypełnienia.<br/>            Tylko do odczytu [`IFillFormatEffectiveData`](/slides/python-net/pl/aspose.slides/ifillformateffectivedata). |
| [`effect_format`](/slides/python-net/pl/aspose.slides/ibackgroundeffectivedata/effect_format/) | Zwraca efektywny format efektu.<br/>            Tylko do odczytu [`IEffectFormatEffectiveData`](/slides/python-net/pl/aspose.slides/ieffectformateffectivedata). |


### Uwagi

Ten interfejs jest używany razem z interfejsem [`IBackground`](/slides/python-net/pl/aspose.slides/ibackground), aby zwrócić skuteczne wartości formatowania z zastosowanym dziedziczeniem.
