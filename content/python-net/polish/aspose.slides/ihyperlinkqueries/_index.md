## IHyperlinkQueries klasa

Umożliwia łatwy dostęp do zawartych hiperłączy.

Typ IHyperlinkQueries udostępnia następujące elementy:

## Metody

| Metoda | Opis |
| :- | :- |
| [`get_hyperlink_clicks(self)`](/slides/python-net/pl/aspose.slides/ihyperlinkqueries/get_hyperlink_clicks/#) | Pobiera wszystkie podobiekty IHyperlinkContainer, które zawierają niepusty HyperlinkClick.<br/>            Za pomocą podanego obiektu IHyperlinkContainer można zarządzać jego hiperłączem (odczyt, aktualizacja lub usunięcie). Zobacz interfejs IHyperlinkContainer. |

Zobacz interfejs IHyperlinkContainer. |
| [`get_any_hyperlinks(self)`](/slides/python-net/pl/aspose.slides/ihyperlinkqueries/get_any_hyperlinks/#) | Pobiera wszystkie podobiekty IHyperlinkContainer, które zawierają niepusty HyperlinkMouseOver.<br/>            Za pomocą podanego obiektu IHyperlinkContainer można zarządzać jego hiperłączem (odczyt, aktualizacja lub usunięcie).
