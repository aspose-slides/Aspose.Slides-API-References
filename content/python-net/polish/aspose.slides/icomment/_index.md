## IComment klasa

Reprezentuje komentarz na slajdzie.

Typ IComment udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`text`](/slides/python-net/pl/aspose.slides/icomment/text/) | Zwraca lub ustawia zwykły tekst komentarza slajdu.<br/>            Odczyt/zapis **str**. |
| [`created_time`](/slides/python-net/pl/aspose.slides/icomment/created_time/) | Zwraca lub ustawia czas utworzenia komentarza.<br/>            Ustawienie tej właściwości na **System.DateTime** oznacza, że nie ustawiono czasu komentarza.<br/>            Odczyt/zapis **System.DateTime**. |
| [`slide`](/slides/python-net/pl/aspose.slides/icomment/slide/) | Zwraca lub ustawia slajd nadrzędny komentarza.<br/>            Tylko do odczytu [`ISlide`](/slides/python-net/pl/aspose.slides/islide). |
| [`author`](/slides/python-net/pl/aspose.slides/icomment/author/) | Zwraca autora komentarza.<br/>            Tylko do odczytu [`ICommentAuthor`](/slides/python-net/pl/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/pl/aspose.slides/icomment/position/) | Zwraca lub ustawia pozycję komentarza na slajdzie.<br/>            Odczyt/zapis [`PointF`](/slides/python-net/pl/aspose.slides/pointf). |
| [`parent_comment`](/slides/python-net/pl/aspose.slides/icomment/parent_comment/) | Zwraca lub ustawia komentarz nadrzędny.<br/>            Odczyt/zapis [`IComment`](/slides/python-net/pl/aspose.slides/icomment). |

## Metody

| Metoda | Opis |
| :- | :- |
| [`remove(self)`](/slides/python-net/pl/aspose.slides/icomment/remove/#) | Usuwa komentarz i wszystkie jego odpowiedzi z kolekcji nadrzędnej. |
