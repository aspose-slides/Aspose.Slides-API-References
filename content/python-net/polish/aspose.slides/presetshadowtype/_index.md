## Wyliczenie PresetShadowType

Reprezentuje zestaw ustawień dla efektu cienia.

Typ PresetShadowType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| TOP_LEFT_DROP_SHADOW | Reprezentuje cień opadający w lewym górnym rogu. |
| TOP_LEFT_LARGE_DROP_SHADOW | Reprezentuje duży cień opadający w lewym górnym rogu. |
| BACK_LEFT_LONG_PERSPECTIVE_SHADOW | Reprezentuje długi cień perspektywiczny z tyłu po lewej. |
| BACK_RIGHT_LONG_PERSPECTIVE_SHADOW | Reprezentuje długi cień perspektywiczny z tyłu po prawej. |
| TOP_LEFT_DOUBLE_DROP_SHADOW | Reprezentuje podwójny cień opadający w lewym górnym rogu. |
| BOTTOM_RIGHT_SMALL_DROP_SHADOW | Reprezentuje mały cień opadający w prawym dolnym rogu. |
| FRONT_LEFT_LONG_PERSPECTIVE_SHADOW | Reprezentuje długi cień perspektywiczny z przodu po lewej. |
| FRONT_RIGHT_LONG_PERSPECTIVE_SHADOW | Reprezentuje długi cień perspektywiczny z przodu po prawej. |
| OUTER_BOX_SHADOW_3D | Reprezentuje zewnętrzny cień pudełkowy 3D. |
| INNER_BOX_SHADOW_3D | Reprezentuje wewnętrzny cień pudełkowy 3D. |
