## IInterruptionTokenSource klasa

Reprezentuje źródło [`IInterruptionToken`](/slides/python-net/pl/aspose.slides/iinterruptiontoken).

Typ IInterruptionTokenSource udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`token`](/slides/python-net/pl/aspose.slides/iinterruptiontokensource/token/) | Zwraca nowy token powiązany z tym [`IInterruptionTokenSource`](/slides/python-net/pl/aspose.slides/iinterruptiontokensource). |
| [`is_interruption_requested`](/slides/python-net/pl/aspose.slides/iinterruptiontokensource/is_interruption_requested/) | Zwraca true jeśli żądane jest przerwanie, false w przeciwnym razie. |

## Metody

| Metoda | Opis |
| :- | :- |
| [`interrupt(self)`](/slides/python-net/pl/aspose.slides/iinterruptiontokensource/interrupt/#) | Zainicjalizuj żądanie przerwania. |
