## PathFillModeType enumeracja

Określa sposób, w jaki ścieżka powinna być wypełniona

Typ PathFillModeType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| NONE | Brak wypełnienia ścieżki<br/>            To określa, że dana ścieżka nie powinna mieć wypełnienia. |
| NORMAL | Normalne wypełnienie ścieżki<br/>            To określa, że dana ścieżka powinna mieć zwykle cieniowany kolor zastosowany do jej wypełnienia. |
| LIGHTEN | Rozjaśnienie wypełnienia ścieżki<br/>            To określa, że dana ścieżka powinna mieć lekko cieniowany kolor zastosowany do jej wypełnienia. |
| LIGHTEN_LESS | Mniej rozjaśnione wypełnienie ścieżki<br/>            To określa, że dana ścieżka powinna mieć nieco jaśniejszy cieniowany kolor zastosowany do jej wypełnienia. |
| DARKEN | Przyciemnienie wypełnienia ścieżki<br/>            To określa, że dana ścieżka powinna mieć ciemniej cieniowany kolor zastosowany do jej wypełnienia. |
| DARKEN_LESS | Mniej przyciemnione wypełnienie ścieżki<br/>            To określa, że dana ścieżka powinna mieć nieco ciemniejszy cieniowany kolor zastosowany do jej wypełnienia. |
