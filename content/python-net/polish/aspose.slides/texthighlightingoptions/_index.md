## TextHighlightingOptions klasa

Reprezentuje opcje, które mogą być użyte do podświetlania tekstu w ramce tekstowej.

Typ TextHighlightingOptions udostępnia następujące elementy:

## Konstruktory

| Konstruktor | Opis |
| :- | :- |
| [`__init__(self)`](/slides/python-net/pl/aspose.slides/texthighlightingoptions/__init__/#) | Tworzy nowe domyślne opcje podświetlania tekstu. |

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`case_sensitive`](/slides/python-net/pl/aspose.slides/texthighlightingoptions/case_sensitive/) | Ustaw true, aby używać wyszukiwania z rozróżnieniem wielkości liter, false - w przeciwnym razie.<br/>            Odczyt/zapis **bool**. |
| [`whole_words_only`](/slides/python-net/pl/aspose.slides/texthighlightingoptions/whole_words_only/) | Ustaw true, aby dopasowywać tylko całe wyrazy, false - w przeciwnym razie.<br/>            Odczyt/zapis **bool**. |
