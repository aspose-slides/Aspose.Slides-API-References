## SlideShowSettings class

Reprezentuje ustawienia pokazu slajdów dla prezentacji.

Typ SlideShowSettings udostępnia następujące elementy:

## Właściwości

| Property | Description |
| :- | :- |
| [`slide_show_type`](/slides/python-net/pl/aspose.slides/slideshowsettings/slide_show_type/) | Pobiera lub ustawia typ pokazu slajdów. Reprezentowany przez następujących przodków [`SlideShowSettings.slide_show_type`](/slides/python-net/pl/aspose.slides/slideshowsettings/slide_show_type): [`BrowsedAtKiosk`](/slides/python-net/pl/aspose.slides/browsedatkiosk), [`PresentedBySpeaker`](/slides/python-net/pl/aspose.slides/presentedbyspeaker) i [`BrowsedByIndividual`](/slides/python-net/pl/aspose.slides/browsedbyindividual) |
| [`loop`](/slides/python-net/pl/aspose.slides/slideshowsettings/loop/) | Pętla pokazu slajdów |
| [`show_narration`](/slides/python-net/pl/aspose.slides/slideshowsettings/show_narration/) | Wyświetl narrację w pokazie slajdów |
| [`show_animation`](/slides/python-net/pl/aspose.slides/slideshowsettings/show_animation/) | Wyświetl animację w pokazie slajdów |
| [`pen_color`](/slides/python-net/pl/aspose.slides/slideshowsettings/pen_color/) | Kolor pióra dla pokazu slajdów |
| [`slides`](/slides/python-net/pl/aspose.slides/slideshowsettings/slides/) | Zakres slajdów |
| [`use_timings`](/pl/slides/python-net/aspose.slides/slideshowsettings/use_timings/) | Użyj synchronizacji czasowej w pokazie slajdów |
| [`show_media_controls`](/slides/python-net/pl/aspose.slides/slideshowsettings/show_media_controls/) | Wyświetl sterowanie multimediami |
