## Wyliczenie SourceFormat

Reprezentuje format pliku źródłowego.

Typ SourceFormat udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| PPT | Microsoft PowerPoint 97-2003 Prezentacja (*.ppt). |
| PPTX | Microsoft Office Open XML Prezentacja (*.pptx). |
| ODP | OpenDocument Prezentacja (*.odp). |
| PPTM | Microsoft Office Open XML Prezentacja z obsługą makr (*.pptm). |
| PPSX | Microsoft Office Open XML Pokaz slajdów (*.ppsx). |
| PPSM | Microsoft Office Open XML Pokaz slajdów z obsługą makr (*.ppsm). |
| POTX | Microsoft Office Open XML Szablon (*.potx). |
| POTM | Microsoft Office Open XML Szablon z obsługą makr (*.potm). |
| PPS | Microsoft PowerPoint 97-2003 Pokaz slajdów (*.pps). |
| POT | Microsoft PowerPoint 97-2003 Szablon (*.pot). |
| OTP | OpenDocument Szablon prezentacji (*.otp). |
| FODP | Płaska prezentacja XML ODF (*.fodp). |
| XML | PowerPoint XML Prezentacja (*.xml). |
