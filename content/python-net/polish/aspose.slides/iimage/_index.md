## IImage klasa

Reprezentuje obraz rastrowy lub wektorowy.

Typ IImage udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`size`](/slides/python-net/pl/aspose.slides/iimage/size/) | Pobiera rozmiar obrazu. |
| [`width`](/slides/python-net/pl/aspose.slides/iimage/width/) | Pobiera szerokość obrazu w pikselach. |
| [`height`](/slides/python-net/pl/aspose.slides/iimage/height/) | Pobiera wysokość obrazu w pikselach. |

## Metody

| Metoda | Opis |
| :- | :- |
| [`save(self, filename)`](/slides/python-net/pl/aspose.slides/iimage/save/#str) | Zapisuje obraz do pliku. |
| [`save(self, filename, format)`](/slides/python-net/pl/aspose.slides/iimage/save/#str-imageformat) | Zapisuje obraz do pliku w określonym formacie. |
| [`save(self, stream, format)`](/slides/python-net/pl/aspose.slides/iimage/save/#iorawiobase-imageformat) | Zapisuje obraz do strumienia w określonym formacie. |
| [`save(self, filename, format, quality)`](/slides/python-net/pl/aspose.slides/iimage/save/#str-imageformat-int) | Zapisuje obraz do pliku w określonym formacie i jakości. |
| [`save(self, stream, format, quality)`](/slides/python-net/pl/aspose.slides/iimage/save/#iorawiobase-imageformat-int) | Zapisuje obraz do strumienia w określonym formacie i jakości. |

### Uwagi

Ten interfejs zapewnia wspólną abstrakcję dla obsługi zarówno obrazów rastrowych, jak i wektorowych.  
Implementacje mogą się różnić w zależności od podstawowego typu obrazu.
