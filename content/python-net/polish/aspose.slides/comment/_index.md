## Comment klasa

Reprezentuje komentarz na slajdzie.

Typ Comment udostępnia następujące elementy:

## Właściwości

| Property | Description |
| :- | :- |
| [`text`](/slides/python-net/pl/aspose.slides/comment/text/) | Zwraca lub ustawia zwykły tekst komentarza slajdu.<br/>            Odczyt/zapis **str**. |
| [`created_time`](/slides/python-net/pl/aspose.slides/comment/created_time/) | Zwraca lub ustawia czas utworzenia komentarza.<br/>            Ustawienie tej właściwości na **System.DateTime** oznacza, że nie ustalono czasu komentarza.<br/>            Odczyt/zapis **System.DateTime**. |
| [`slide`](/slides/python-net/pl/aspose.slides/comment/slide/) | Zwraca lub ustawia slajd nadrzędny komentarza.<br/>            Tylko odczyt [`ISlide`](/slides/python-net/pl/aspose.slides/islide). |
| [`author`](/slides/python-net/pl/aspose.slides/comment/author/) | Zwraca autora komentarza.<br/>            Tylko odczyt [`ICommentAuthor`](/slides/python-net/pl/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/pl/aspose.slides/comment/position/) | Zwraca lub ustawia pozycję komentarza na slajdzie.<br/>            Odczyt/zapis **aspose.slides.PointF**. |
| [`parent_comment`](/slides/python-net/pl/aspose.slides/comment/parent_comment/) | Zwraca lub ustawia komentarz nadrzędny.<br/>            Odczyt/zapis [`IComment`](/slides/python-net/pl/aspose.slides/icomment). |

## Metody

| Method | Description |
| :- | :- |
| [`remove(self)`](/slides/python-net/pl/aspose.slides/comment/remove/#) | Usuwa komentarz oraz wszystkie jego odpowiedzi z kolekcji nadrzędnej. |
