## volume_value właściwość
Zwraca lub ustawia dokładną głośność wideo jako procent.
             Wartość jest wyrażana jako procent od 0 do 100. Użyj tej właściwości
             aby odczytać lub ustawić wartości głośności, które są dokładniejsze niż predefiniowane
             poziomy dostępne za pośrednictwem właściwości [`IVideoFrame.volume`](/slides/python-net/pl/aspose.slides/ivideoframe/volume).
             Odczyt/zapis **float**.
