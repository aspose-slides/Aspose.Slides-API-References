## Enumeracja ImageFormat

Typ ImageFormat udostępnia następujące członkowie:

## Pola

| Pole | Opis |
| :- | :- |
| MEMORY_BMP | Reprezentuje format bitmapy w pamięci. |
| BMP | Reprezentuje format obrazu bitmapowego (BMP). |
| EMF | Reprezentuje format obrazu rozszerzonego metafile (EMF). |
| WMF | Reprezentuje format obrazu metafile Windows (WMF). |
| GIF | Reprezentuje format obrazu Graphics Interchange Format (GIF). |
| JPEG | Reprezentuje format obrazu Joint Photographic Experts Group (JPEG). |
| PNG | Reprezentuje format obrazu W3C Portable Network Graphics (PNG). |
| TIFF | Reprezentuje format obrazu Tagged Image File Format (TIFF). |
| EXIF | Reprezentuje format Exchangeable Image File (Exif). |
| ICON | Reprezentuje format obrazu ikony Windows. |
