## SlideSize klasa

Reprezentuje rozmiar i orientację slajdu.

Typ SlideSize udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`size`](/slides/python-net/pl/aspose.slides/slidesize/size/) | Pobiera wymiary slajdu w punktach. |
| [`type`](/slides/python-net/pl/aspose.slides/slidesize/type/) | Pobiera typ rozmiaru slajdu. |
| [`orientation`](/slides/python-net/pl/aspose.slides/slidesize/orientation/) | Pobiera lub ustawia orientację slajdu. |

## Metody

| Metoda | Opis |
| :- | :- |
| [`set_size(self, type, scale_type)`](/slides/python-net/pl/aspose.slides/slidesize/set_size/#slidesizetype-slidesizescaletype) | Ustawia rozmiar slajdu według typu i skaluje istniejącą zawartość. |
| [`set_size(self, width, height, scale_type)`](/slides/python-net/pl/aspose.slides/slidesize/set_size/#float-float-slidesizescaletype) | Ustawia wymiary slajdu jawnie i skaluje istniejącą zawartość. |
