## height właściwość
Zwraca lub ustawia height wypunktowania akapitu bez dziedziczenia.
            Wartość float.NaN określa, że bullet dziedziczy height z pierwszej części w akapicie.
            Odczyt/zapis **float**.


### Uwagi

Ujemna wartość height oznacza, że height jest podana w punktach, a dodatnia wartość oznacza, że height jest procentem otaczającego tekstu.
