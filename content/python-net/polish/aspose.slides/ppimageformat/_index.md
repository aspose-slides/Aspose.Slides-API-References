## PPImageFormat enumeracja

Formaty obrazu. Ten wylicznik jest zamiennikiem klasy `System.Drawing.Imaging.ImageFormat`. Jest potrzebny dla zgodności z COM.

Typ PPImageFormat udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| BMP | Zwraca format obrazu bitmapowego (BMP). |
| EMF | Zwraca format obrazu rozszerzonego metafilu (EMF). |
| EXIF | Zwraca format wymiennego pliku obrazu (Exif). |
| GIF | Zwraca format obrazu Graphics Interchange Format (GIF). |
| ICON | Zwraca format obrazu ikony Windows. |
| JPEG | Zwraca format obrazu Joint Photographic Experts Group (JPEG). |
| MEMORY_BMP | Zwraca format bitmapy w pamięci. |
| PNG | Zwraca format obrazu W3C Portable Network Graphics (PNG). |
| TIFF | Zwraca format obrazu Tagged Image File Format (TIFF). |
| WMF | Zwraca format obrazu Windows metafile (WMF). |
