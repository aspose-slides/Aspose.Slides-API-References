## IAdjustValue klasa

Reprezentuje wartość dopasowania kształtu geometrycznego.
            Te wartości wpływają na formę kształtu.

Typ IAdjustValue udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`raw_value`](/slides/python-net/pl/aspose.slides/iadjustvalue/raw_value/) | Zwraca lub ustawia wartość dopasowania "as is".<br/>            odczyt/zapis **int**. |
| [`angle_value`](/slides/python-net/pl/aspose.slides/iadjustvalue/angle_value/) | Zwraca lub ustawia wartość, interpretując ją jako kąt w stopniach.<br/>            odczyt/zapis **float**. |
| [`name`](/slides/python-net/pl/aspose.slides/iadjustvalue/name/) | Zwraca nazwę tej wartości dopasowania.<br/>            tylko do odczytu **str**. |
| [`type`](/slides/python-net/pl/aspose.slides/iadjustvalue/type/) | Zwraca typ dopasowania kształtu.<br/>            tylko do odczytu [`ShapeAdjustmentType`](/slides/python-net/pl/aspose.slides/shapeadjustmenttype). |
