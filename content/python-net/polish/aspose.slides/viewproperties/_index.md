## ViewProperties klasa

Właściwości widoku obejmujące całą prezentację.

Typ ViewProperties udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`last_view`](/slides/python-net/pl/aspose.slides/viewproperties/last_view/) | Określa tryb widoku, który został użyty, gdy dokument prezentacji został ostatnio zapisany.<br/>            Odczyt/zapis [`ViewType`](/slides/python-net/pl/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/pl/aspose.slides/viewproperties/show_comments/) | Określa, czy komentarze slajdu powinny być wyświetlane.<br/>            Odczyt/zapis [`NullableBool`](/slides/python-net/pl/aspose.slides/nullablebool). |
| [`normal_view_properties`](/slides/python-net/pl/aspose.slides/viewproperties/normal_view_properties/) | Reprezentuje właściwości normalnego widoku. Normalny widok składa się z<br/>            trzech obszarów treści: samego slajdu, bocznego obszaru treści oraz dolnego obszaru treści.<br/>            Tylko do odczytu [`INormalViewProperties`](/slides/python-net/pl/aspose.slides/inormalviewproperties). |
| [`slide_view_properties`](/slides/python-net/pl/aspose.slides/viewproperties/slide_view_properties/) | Określa wspólne właściwości widoku powiązane z trybem widoku slajdu.<br/>            Tylko do odczytu [`ICommonSlideViewProperties`](/slides/python-net/pl/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/pl/aspose.slides/viewproperties/notes_view_properties/) | Określa wspólne właściwości widoku powiązane z trybem widoku notatek.<br/>            Tylko do odczytu [`ICommonSlideViewProperties`](/slides/python-net/pl/aspose.slides/icommonslideviewproperties). |
| [`grid_spacing`](/slides/python-net/pl/aspose.slides/viewproperties/grid_spacing/) | Zwraca lub ustawia odstęp siatki, który powinien być używany dla siatki leżącej u podstaw dokumentu prezentacji, w punktach. <br/>            Odczyt/zapis **float**. |
