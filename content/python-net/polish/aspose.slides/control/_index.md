## Control klasa

Reprezentuje kontrolkę ActiveX.

Typ Control udostępnia następujące członków:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`persistence`](/slides/python-net/pl/aspose.slides/control/persistence/) | Pobiera metodę używaną do przechowywania właściwości kontrolki ActiveX.<br/>            Tylko do odczytu [`PersistenceType`](/slides/python-net/pl/aspose.slides/persistencetype). |
| [`name`](/slides/python-net/pl/aspose.slides/control/name/) | Pobiera lub ustawia nazwę tej kontrolki.<br/>            Odczyt/zapis **str**. |
| [`class_id`](/slides/python-net/pl/aspose.slides/control/class_id/) | Pobiera identyfikator klasy tej kontrolki.<br/>            Tylko do odczytu **System.Guid**. |
| [`substitute_picture_format`](/slides/python-net/pl/aspose.slides/control/substitute_picture_format/) | Zwraca obiekt właściwości wypełnienia obrazu Control.<br/>            Tylko do odczytu [`IPictureFillFormat`](/slides/python-net/pl/aspose.slides/ipicturefillformat). |
| [`frame`](/slides/python-net/pl/aspose.slides/control/frame/) | Zwraca lub ustawia ramkę kontrolki.<br/>            Odczyt/zapis [`IShapeFrame`](/slides/python-net/pl/aspose.slides/ishapeframe). |
| [`properties`](/slides/python-net/pl/aspose.slides/control/properties/) | Zwraca kolekcję właściwości ActiveX.<br/>            Uwaga: Aspose.Slides obsługuje tylko właściwości ActiveX oparte na XML. Jeśli właściwości są przechowywane w formacie binarnym, ta właściwość zwróci None.<br/>            Tylko do odczytu [`IControlPropertiesCollection`](/slides/python-net/pl/aspose.slides/icontrolpropertiescollection). |
| [`active_x_control_binary`](/slides/python-net/pl/aspose.slides/control/active_x_control_binary/) | Określa trwałość kontrolki ActiveX, gdy metodą utrwalania jest PersistStream, PersistStreamInit lub PersistStorage. |
