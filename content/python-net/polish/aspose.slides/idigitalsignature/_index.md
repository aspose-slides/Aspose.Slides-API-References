## IDigitalSignature klasa

Podpis cyfrowy w podpisanym pliku.

Typ IDigitalSignature udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`certificate`](/slides/python-net/pl/aspose.slides/idigitalsignature/certificate/) | Obiekt certyfikatu użyty do podpisania dokumentu.<br/>            Read-only **System.Security.Cryptography.X509Certificates.X509Certificate2**. |
| [`is_valid`](/slides/python-net/pl/aspose.slides/idigitalsignature/is_valid/) | Jeśli ten podpis cyfrowy jest ważny i dokument nie został podmieniony, ta wartość będzie prawdziwa.<br/>            Read-only **bool**. |
| [`sign_time`](/slides/python-net/pl/aspose.slides/idigitalsignature/sign_time/) | Czas, w którym dokument został podpisany.<br/>            Read-only **System.DateTime**. |
| [`comments`](/slides/python-net/pl/aspose.slides/idigitalsignature/comments/) | Cel podpisu.<br/>            Read/write **str**. |
