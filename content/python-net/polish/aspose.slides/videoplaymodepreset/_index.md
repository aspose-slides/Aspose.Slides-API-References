## VideoPlayModePreset enumeracja

Stałe określające, jak odtwarzane jest wideo.

Typ VideoPlayModePreset udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| MIXED |  |
| AUTO | Odtwarzaj automatycznie. |
| ON_CLICK | Odtwarzaj tylko po kliknięciu ramki wideo. |
| ALL_SLIDES | Odtwarzaj na wszystkich slajdach. |
| IN_CLICK_SEQUENCE | Odtwarzaj automatycznie po kliknięciu. |
