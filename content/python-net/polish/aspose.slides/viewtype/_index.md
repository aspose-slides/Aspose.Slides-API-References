## ViewType wyliczenie

Typy widoków prezentacji

Typ ViewType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| NOT_DEFINED | Wartość nie jest określona |
| SLIDE_VIEW | Normalny widok slajdu |
| SLIDE_MASTER_VIEW | Widok głównego slajdu |
| NOTES_VIEW | Widok notatek |
| HANDOUT_VIEW | Widok wersji rozdawnika |
| NOTES_MASTER_VIEW | Widok głównego notatnika |
| OUTLINE_VIEW | Widok konspektu |
| SLIDE_SORTER_VIEW | Widok sortera slajdów |
| SLIDE_THUMBNAIL_VIEW | Widok miniatur slajdów |
