## ICommentAuthor klasa

Reprezentuje autora komentarzy.

Typ ICommentAuthor udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`name`](/slides/python-net/pl/aspose.slides/icommentauthor/name/) | Zwraca lub ustawia nazwę autora.<br/>            Odczyt/zapis **str**. |
| [`initials`](/slides/python-net/pl/aspose.slides/icommentauthor/initials/) | Zwraca lub ustawia inicjały autora.<br/>            Odczyt/zapis **str**. |
| [`comments`](/slides/python-net/pl/aspose.slides/icommentauthor/comments/) | Zwraca kolekcję komentarzy utworzonych przez tego autora.<br/>            Tylko do odczytu [`ICommentCollection`](/slides/python-net/pl/aspose.slides/icommentcollection). |

## Metody

| Metoda | Opis |
| :- | :- |
| [`remove(self)`](/slides/python-net/pl/aspose.slides/icommentauthor/remove/#) | Usuwa autora z nadrzędnej kolekcji. |
