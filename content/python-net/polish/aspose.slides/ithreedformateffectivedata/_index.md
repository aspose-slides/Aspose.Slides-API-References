## IThreeDFormatEffectiveData klasa

Niezmienny obiekt, który reprezentuje efektywne właściwości formatowania 3-D.

Typ IThreeDFormatEffectiveData udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`contour_width`](/slides/python-net/pl/aspose.slides/ithreedformateffectivedata/contour_width/) | Returns the width of a 3D contour.<br/>            Tylko do odczytu **float**. |
| [`extrusion_height`](/slides/python-net/pl/aspose.slides/ithreedformateffectivedata/extrusion_height/) | Returns the height of an extrusion effect.<br/>            Tylko do odczytu **float**. |
| [`depth`](/slides/python-net/pl/aspose.slides/ithreedformateffectivedata/depth/) | Returns the depth of a 3D shape.<br/>            Tylko do odczytu **float**. |
| [`bevel_top`](/slides/python-net/pl/aspose.slides/ithreedformateffectivedata/bevel_top/) | Returns the type of a top 3D bevel.<br/>            Tylko do odczytu [`IShapeBevelEffectiveData`](/slides/python-net/pl/aspose.slides/ishapebeveleffectivedata). |
| [`bevel_bottom`](/slides/python-net/pl/aspose.slides/ithreedformateffectivedata/bevel_bottom/) | Returns the type of a bottom 3D bevel.<br/>            Tylko do odczytu [`IShapeBevelEffectiveData`](/slides/python-net/pl/aspose.slides/ishapebeveleffectivedata). |
| [`contour_color`](/slides/python-net/pl/aspose.slides/ithreedformateffectivedata/contour_color/) | Returns the color of a contour.<br/>            Tylko do odczytu [`Color`](/slides/python-net/pl/aspose.slides/color). |
| [`extrusion_color`](/slides/python-net/pl/aspose.slides/ithreedformateffectivedata/extrusion_color/) | Returns the color of an extrusion.<br/>            Tylko do odczytu [`Color`](/slides/python-net/pl/aspose.slides/color). |
| [`camera`](/slides/python-net/pl/aspose.slides/ithreedformateffectivedata/camera/) | Returns the settings of a camera.<br/>            Tylko do odczytu [`ICameraEffectiveData`](/slides/python-net/pl/aspose.slides/icameraeffectivedata). |
| [`light_rig`](/slides/python-net/pl/aspose.slides/ithreedformateffectivedata/light_rig/) | Returns the type of a light.<br/>            Tylko do odczytu [`ILightRigEffectiveData`](/slides/python-net/pl/aspose.slides/ilightrigeffectivedata). |
| [`material`](/slides/python-net/pl/aspose.slides/ithreedformateffectivedata/material/) | Returns the type of a material.<br/>            Tylko do odczytu [`MaterialPresetType`](/slides/python-net/pl/aspose.slides/materialpresettype). |


### Uwagi

Ten interfejs jest używany razem z interfejsem [`IThreeDFormat`](/slides/python-net/pl/aspose.slides/ithreedformat), aby zwrócić efektywne wartości formatowania z zastosowanym dziedziczeniem.
