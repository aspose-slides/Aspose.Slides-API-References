## IThreeDFormatEffectiveData klasa

Niezmienny obiekt reprezentujący efektywne właściwości formatowania 3-D.

Typ IThreeDFormatEffectiveData udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`contour_width`](/slides/python-net/pl/aspose.slides/ithreedformateffectivedata/contour_width/) | Zwraca szerokość konturu 3-D.<br/>            Tylko do odczytu **float**. |
| [`extrusion_height`](/slides/python-net/pl/aspose.slides/ithreedformateffectivedata/extrusion_height/) | Zwraca wysokość efektu ekstruzji.<br/>            Tylko do odczytu **float**. |
| [`depth`](/slides/python-net/pl/aspose.slides/ithreedformateffectivedata/depth/) | Zwraca głębokość kształtu 3-D.<br/>            Tylko do odczytu **float**. |
| [`bevel_top`](/slides/python-net/pl/aspose.slides/ithreedformateffectivedata/bevel_top/) | Zwraca typ górnego 3-D bevel.<br/>            Tylko do odczytu [`IShapeBevelEffectiveData`](/slides/python-net/pl/aspose.slides/ishapebeveleffectivedata). |
| [`bevel_bottom`](/slides/python-net/pl/aspose.slides/ithreedformateffectivedata/bevel_bottom/) | Zwraca typ dolnego 3-D bevel.<br/>            Tylko do odczytu [`IShapeBevelEffectiveData`](/slides/python-net/pl/aspose.slides/ishapebeveleffectivedata). |
| [`contour_color`](/slides/python-net/pl/aspose.slides/ithreedformateffectivedata/contour_color/) | Zwraca kolor konturu.<br/>            Tylko do odczytu **aspose.slides.Color**. |
| [`extrusion_color`](/slides/python-net/pl/aspose.slides/ithreedformateffectivedata/extrusion_color/) | Zwraca kolor ekstruzji.<br/>            Tylko do odczytu **aspose.slides.Color**. |
| [`camera`](/slides/python-net/pl/aspose.slides/ithreedformateffectivedata/camera/) | Zwraca ustawienia kamery.<br/>            Tylko do odczytu [`ICameraEffectiveData`](/slides/python-net/pl/aspose.slides/icameraeffectivedata). |
| [`light_rig`](/slides/python-net/pl/aspose.slides/ithreedformateffectivedata/light_rig/) | Zwraca typ światła.<br/>            Tylko do odczytu [`ILightRigEffectiveData`](/slides/python-net/pl/aspose.slides/ilightrigeffectivedata). |
| [`material`](/slides/python-net/pl/aspose.slides/ithreedformateffectivedata/material/) | Zwraca typ materiału.<br/>            Tylko do odczytu [`MaterialPresetType`](/slides/python-net/pl/aspose.slides/materialpresettype). |


### Uwagi

Ten interfejs jest używany razem z interfejsem [`IThreeDFormat`](/slides/python-net/pl/aspose.slides/ithreedformat), aby zwracać efektywne wartości formatowania z zastosowanym dziedziczeniem.
