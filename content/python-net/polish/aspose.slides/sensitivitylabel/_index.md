## SensitivityLabel klasa

Reprezentuje etykietę wrażliwości z Microsoft Purview Information Protection.

Typ SensitivityLabel udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`id`](/slides/python-net/pl/aspose.slides/sensitivitylabel/id/) | Zwraca lub ustawia identyfikator etykiety wrażliwości.<br/>            Odczyt/zapis **str**. |
| [`site_id`](/slides/python-net/pl/aspose.slides/sensitivitylabel/site_id/) | Zwraca lub ustawia identyfikator witryny Azure Active Directory (Azure AD) <br/>            odpowiadający polityce etykiety wrażliwości opisującej etykietę wrażliwości.<br/>            Odczyt/zapis **System.Guid**. |
| [`is_enabled`](/slides/python-net/pl/aspose.slides/sensitivitylabel/is_enabled/) | Wskazuje, czy etykieta wrażliwości jest włączona. |
| [`is_removed`](/slides/python-net/pl/aspose.slides/sensitivitylabel/is_removed/) | Wskazuje, czy etykieta wrażliwości została usunięta. |
| [`assignment_method_type`](/slides/python-net/pl/aspose.slides/sensitivitylabel/assignment_method_type/) | Zwraca lub ustawia metodę przypisania etykiety wrażliwości.<br/>            Odczyt/zapis [`SensitivityLabelAssignmentType`](/slides/python-net/pl/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/pl/aspose.slides/sensitivitylabel/content_mark_types/) | Zwraca listę typów oznaczania treści, które powinny być zastosowane do pliku. |
