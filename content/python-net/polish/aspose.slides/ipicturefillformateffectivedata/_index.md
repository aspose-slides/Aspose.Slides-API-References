## IPictureFillFormatEffectiveData klasa

Niezmienny obiekt zawierający właściwości wypełnienia obrazu.

Typ IPictureFillFormatEffectiveData udostępnia następujące elementy:

## Właściwości

| Property | Description |
| :- | :- |
| [`dpi`](/slides/python-net/pl/aspose.slides/ipicturefillformateffectivedata/dpi/) | Zwraca dpi używane do wypełniania obrazu.<br/>            Tylko do odczytu **int**. |
| [`picture_fill_mode`](/slides/python-net/pl/aspose.slides/ipicturefillformateffectivedata/picture_fill_mode/) | Zwraca tryb wypełniania obrazu.<br/>            Tylko do odczytu [`PictureFillMode`](/slides/python-net/pl/aspose.slides/picturefillmode). |
| [`picture`](/slides/python-net/pl/aspose.slides/ipicturefillformateffectivedata/picture/) | Zwraca obraz.<br/>            Tylko do odczytu [`IPictureEffectiveData`](/slides/python-net/pl/aspose.slides/ipictureeffectivedata). |
| [`crop_left`](/slides/python-net/pl/aspose.slides/ipicturefillformateffectivedata/crop_left/) | Zwraca liczbę procent rzeczywistej szerokości obrazu, które są obcięte po lewej stronie obrazu.<br/>            Tylko do odczytu **float**. |
| [`crop_top`](/slides/python-net/pl/aspose.slides/ipicturefillformateffectivedata/crop_top/) | Zwraca liczbę procent rzeczywistej wysokości obrazu, które są obcięte na górze obrazu.<br/>            Tylko do odczytu **float**. |
| [`crop_right`](/slides/python-net/pl/aspose.slides/ipicturefillformateffectivedata/crop_right/) | Zwraca liczbę procent rzeczywistej szerokości obrazu, które są obcięte po prawej stronie obrazu.<br/>            Tylko do odczytu **float**. |
| [`crop_bottom`](/slides/python-net/pl/aspose.slides/ipicturefillformateffectivedata/crop_bottom/) | Zwraca liczbę procent rzeczywistej wysokości obrazu, które są obcięte na dole obrazu.<br/>            Tylko do odczytu **float**. |
