### Zwraca

Kolor utworzony z podanych wartości.



```python

    ...
```


| Parametr | Typ | Opis |
| :- | :- | :- |
| r | **int** | Wartość składowej czerwonej. Dopuszczalne wartości to od 0 do 255. |
| g | **int** | Wartość składowej zielonej. Dopuszczalne wartości to od 0 do 255. |
| b | **int** | Wartość składowej niebieskiej. Dopuszczalne wartości to od 0 do 255. |

### Wyjątki

| Exception | Description |
| :- | :- |
