## własność name
Zwraca nazwę tego koloru.<br/> Dla koloru o nazwie (stałej o nazwie, takiej jak `Color.red`, lub koloru utworzonego przy pomocy [`from_name`](/slides/python-net/pl/aspose.slides/color/from_name/)) zwracana jest nazwa .NET, np. `"Red"` lub `"LightBlue"`.<br/> Dla każdego innego koloru zwracana jest wartość ARGB jako szesnastkowa małymi literami bez wiodących zer, np. `"ffff0000"`. `Color.empty.name` to `"0"`. Tylko do odczytu **str**.
