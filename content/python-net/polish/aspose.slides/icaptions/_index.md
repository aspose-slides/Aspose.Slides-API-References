## ICaptions klasa

Reprezentuje napisy zamknięte WebVTT.

Typ ICaptions udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`caption_id`](/slides/python-net/pl/aspose.slides/icaptions/caption_id/) | Zwraca globalnie unikalny identyfikator (GUID) napisów zamkniętych.<br/>            Tylko do odczytu **System.Guid**. |
| [`label`](/slides/python-net/pl/aspose.slides/icaptions/label/) | Zwraca lub ustawia etykietę napisów zamkniętych.<br/>            Odczyt/zapis **str**. |
| [`binary_data`](/slides/python-net/pl/aspose.slides/icaptions/binary_data/) | Zwraca dane binarne napisów zamkniętych.<br/>            Tylko do odczytu **int**[]. |
| [`data_as_string`](/slides/python-net/pl/aspose.slides/icaptions/data_as_string/) | Zwraca dane napisów zamkniętych jako ciąg znaków zakodowany UTF-8.<br/>            Tylko do odczytu **str**. |
