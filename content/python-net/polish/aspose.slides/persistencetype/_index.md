## Enumeracja PersistenceType

Określa metodę używaną do przechowywania właściwości kontrolki ActiveX.

Typ PersistenceType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| NOT_DEFINED | Id persystencji nie określono. |
| PERSIST_PROPERTY_BAG | Określa, że kontrolka ActiveX jest przechowywana przy użyciu persystencji opartej na woreczku właściwości. <br/>             Persystencja oparta na woreczku właściwości przechowuje kontrolkę ActiveX przy użyciu kolekcji par nazw i wartości, które określają dane przechowywane przez kontrolkę ActiveX. |
| PERSIST_STREAM | Określa, że kontrolka ActiveX jest przechowywana przy użyciu persystencji opartej na strumieniu <br/>             która nie obsługuje inicjalizacji kontrolki ActiveX do stanu domyślnego. |
| PERSIST_STREAM_INIT | Określa, że kontrolka ActiveX jest przechowywana przy użyciu persystencji opartej na strumieniu <br/>             która obsługuje inicjalizację kontrolki ActiveX do stanu domyślnego. |
| PERSIST_STORAGE | Określa, że kontrolka ActiveX jest przechowywana przy użyciu persystencji opartej na magazynie. |
