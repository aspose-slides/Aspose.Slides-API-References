## NotesSlideManager klasa

Menedżer slajdów notatek.

Typ NotesSlideManager udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`notes_slide`](/slides/python-net/pl/aspose.slides/notesslidemanager/notes_slide/) | Zwraca slajd notatek dla bieżącego slajdu. Zwraca None, jeśli slajd nie ma slajdu notatek.<br/>            Tylko do odczytu [`INotesSlide`](/slides/python-net/pl/aspose.slides/inotesslide). |

## Metody

| Metoda | Opis |
| :- | :- |
| [`add_notes_slide(self)`](/slides/python-net/pl/aspose.slides/notesslidemanager/add_notes_slide/#) | Zwraca slajd notatek dla bieżącego slajdu, tworząc go, jeśli go nie ma. |
| [`remove_notes_slide(self)`](/slides/python-net/pl/aspose.slides/notesslidemanager/remove_notes_slide/#) | Usuwa slajd notatek bieżącego slajdu. |
