## ICustomXmlPart klasa

Reprezentuje niestandardową część XML.

Typ ICustomXmlPart udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`xml_as_string`](/slides/python-net/pl/aspose.slides/icustomxmlpart/xml_as_string/) | Zwraca lub ustawia dane xml jako ciąg UTF-8.<br/>            Odczyt/zapis **str**.<br/>            wartość to `None`.wartość jest pusta lub dane xml są nieprawidłowe. |
| [`xml_data`](/slides/python-net/pl/aspose.slides/icustomxmlpart/xml_data/) | Zwraca lub ustawia dane xml.<br/>            Odczyt/zapis **int**[].<br/>            wartość to `None`.wartość jest pusta lub dane xml są nieprawidłowe. |
| [`item_id`](/slides/python-net/pl/aspose.slides/icustomxmlpart/item_id/) | Określa globalnie unikalny identyfikator (GUID), który jednoznacznie identyfikuje pojedynczą niestandardową część XML <br/>            w dokumencie Office Open XML.<br/>            Tylko do odczytu **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/pl/aspose.slides/icustomxmlpart/namespace_schemas/) | Zwraca kolekcję schematów XML powiązanych z niestandardową częścią XML.<br/>            Tylko do odczytu **str**[]. |

## Metody

| Metoda | Opis |
| :- | :- |
| [`remove(self)`](/slides/python-net/pl/aspose.slides/icustomxmlpart/remove/#) | Usuwa niestandardową część XML z prezentacji. |
