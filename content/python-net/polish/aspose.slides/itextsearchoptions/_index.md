## ITextSearchOptions klasa

Represents options that can be used to search for text in a Presentation, Slide or TextFrame.

The ITextSearchOptions type exposes the following members:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`case_sensitive`](/slides/python-net/pl/aspose.slides/itextsearchoptions/case_sensitive/) | Ustaw true, aby używać wyszukiwania z rozróżnianiem wielkości liter, false – w przeciwnym razie.<br/>            Odczyt/zapis **bool**. |
| [`whole_words_only`](/slides/python-net/pl/aspose.slides/itextsearchoptions/whole_words_only/) | Ustaw true, aby dopasowywać tylko całe wyrazy, false – w przeciwnym razie.<br/>            Odczyt/zapis **bool**. |
| [`include_notes`](/slides/python-net/pl/aspose.slides/itextsearchoptions/include_notes/) | Ustaw `true`, aby uwzględnić tekst zawarty w notatkach slajdu <br/>            podczas wykonywania operacji wyszukiwania tekstu, zamiany lub podświetlania.<br/>            Domyślna wartość to `false`. |
