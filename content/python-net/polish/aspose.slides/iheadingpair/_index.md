## IHeadingPair klasa

Reprezentuje właściwość 'Heading pair' dokumentu. 
            Wskazuje nazwę grupy części dokumentu oraz liczbę części w grupie.

Typ IHeadingPair udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`name`](/slides/python-net/pl/aspose.slides/iheadingpair/name/) | Zwraca nazwę grupy części dokumentu.<br/>            Tylko do odczytu **str**. |
| [`count`](/slides/python-net/pl/aspose.slides/iheadingpair/count/) | Zwraca liczbę części w grupie.<br/>            Tylko do odczytu **int**. |
