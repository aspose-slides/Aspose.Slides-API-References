## ITableFormatEffectiveData klasa

Niezmienny obiekt, który zawiera efektywne właściwości formatowania tabeli.

Typ ITableFormatEffectiveData udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`transparency`](/slides/python-net/pl/aspose.slides/itableformateffectivedata/transparency/) | Zwraca przejrzystość koloru wypełnienia.<br/>            Odczyt **float**. |
| [`fill_format`](/slides/python-net/pl/aspose.slides/itableformateffectivedata/fill_format/) |  |
| [`border_left`](/slides/python-net/pl/aspose.slides/itableformateffectivedata/border_left/) |  |

Ten interfejs jest używany razem z interfejsem [`ITableFormat`](/slides/python-net/pl/aspose.slides/itableformat) do zwracania efektywnych wartości formatowania z zastosowaną dziedzicznością i stylami tabeli.
