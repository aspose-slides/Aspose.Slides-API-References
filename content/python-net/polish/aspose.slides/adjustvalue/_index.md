## AdjustValue klasa

Reprezentuje wartość dopasowania kształtu geometrycznego.  
Te wartości wpływają na formę kształtu.

Typ AdjustValue udostępnia następujące członki:

## Właściwości

| Property | Description |
| :- | :- |
| [`raw_value`](/slides/python-net/pl/aspose.slides/adjustvalue/raw_value/) | Zwraca lub ustawia wartość dopasowania „as is”.<br/>            Odczyt/zapis **int**. |
| [`angle_value`](/slides/python-net/pl/aspose.slides/adjustvalue/angle_value/) | Zwraca lub ustawia wartość, interpretując ją jako kąt w stopniach.<br/>            Odczyt/zapis **float**. |
| [`name`](/slides/python-net/pl/aspose.slides/adjustvalue/name/) | Zwraca nazwę tej wartości dopasowania.<br/>            Tylko do odczytu **str**. |
| [`type`](/slides/python-net/pl/aspose.slides/adjustvalue/type/) | Zwraca typ dopasowania kształtu.<br/>            Tylko do odczytu [`ShapeAdjustmentType`](/slides/python-net/pl/aspose.slides/shapeadjustmenttype). |
