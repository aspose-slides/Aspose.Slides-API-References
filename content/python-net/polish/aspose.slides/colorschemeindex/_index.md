| Pole | Opis |
| :- | :- |

| LIGHT1 | Jasny 1. |
| DARK2 | Ciemny 2. |
| LIGHT2 | Jasny 2. |
| ACCENT1 | Akcent 1. |
| ACCENT2 | Akcent 2. |
| ACCENT3 | Akcent 3. |
| ACCENT4 | Akcent 4. |
| ACCENT5 | Akcent 5. |
| ACCENT6 | Akcent 6. |
| HYPERLINK | Odnośnik. |
