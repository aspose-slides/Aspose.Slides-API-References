## IResourceLoadingArgs klasa

Interfejs dla argumentów zewnętrznego ładowania zasobów.

Typ IResourceLoadingArgs udostępnia następujące członków:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`original_uri`](/slides/python-net/pl/aspose.slides/iresourceloadingargs/original_uri/) | Oryginalny URI zasobu określony w importowanej prezentacji. |
| [`uri`](/slides/python-net/pl/aspose.slides/iresourceloadingargs/uri/) | URI zasobu używanego do pobierania, jeśli **Aspose.Slides.IResourceLoadingCallback.ResourceLoading(Aspose.Slide** <br/>            zwraca [`ResourceLoadingAction.DEFAULT`](/slides/python-net/pl/aspose.slides/resourceloadingaction/DEFAULT). <br/>            Początkowo jest ustawione na oryginalny URI zasobu, ale może być zmienione na dowolną wartość. |

## Metody

| Metoda | Opis |
| :- | :- |
| [`set_data(self, data)`](/slides/python-net/pl/aspose.slides/iresourceloadingargs/set_data/#bytes) | Ustawia dane zasobu dostarczone przez użytkownika, które są używane, jeśli **Aspose.Slides.IResourceLoadingCallback.ResourceLoading(Aspose.Slide** <br/>            zwraca [`ResourceLoadingAction.USER_PROVIDED`](/slides/python-net/pl/aspose.slides/resourceloadingaction/USER_PROVIDED). |
