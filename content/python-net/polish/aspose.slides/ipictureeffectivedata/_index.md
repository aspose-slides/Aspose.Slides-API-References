## IPictureEffectiveData class

Niezmienny obiekt, który zawiera efektywne właściwości obrazu.

Typ IPictureEffectiveData udostępnia następujące członki:

## Właściwości

| Property | Description |
| :- | :- |
| [`image`](/slides/python-net/pl/aspose.slides/ipictureeffectivedata/image/) | Returns the embedded image.<br/>            Tylko do odczytu [`IPPImage`](/slides/python-net/pl/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/pl/aspose.slides/ipictureeffectivedata/link_path_long/) | Returns linked image's URL.<br/>            Tylko do odczytu **str**. |
| [`image_transform`](/slides/python-net/pl/aspose.slides/ipictureeffectivedata/image_transform/) | Returns the collection of image transform effects.<br/>            Tylko do odczytu [`IImageTransformOCollectionEffectiveData`](/slides/python-net/pl/aspose.slides.effects/iimagetransformocollectioneffectivedata). |
