## Właściwość ramki
Zwraca lub ustawia właściwości ramki kształtu.
            Odczyt/zapis [`IShapeFrame`](/slides/python-net/pl/aspose.slides/ishapeframe).


### Uwagi

Wartość każdej właściwości zwróconego IShapeFrame nie jest 
            niezdefiniowana (nie jest NaN ani NotDefined).
            Wartość każdej właściwości przypisanego IShapeFrame musi być nie 
            niezdefiniowana (musi nie być NaN ani NotDefined).
            Można ustawić niezdefiniowane wartości dla właściwości obiektu RawFrame.
