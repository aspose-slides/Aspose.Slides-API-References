## ICellFormatEffectiveData klasa

Niezmienny obiekt, który zawiera efektywne właściwości formatowania komórek tabeli.

Typ ICellFormatEffectiveData udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`transparency`](/slides/python-net/pl/aspose.slides/icellformateffectivedata/transparency/) | Pobiera przejrzystość koloru wypełnienia.<br/>            Odczyt **float**. |
| [`fill_format`](/slides/python-net/pl/aspose.slides/icellformateffectivedata/fill_format/) |  |
| [`border_left`](/slides/python-net/pl/aspose.slides/icellformateffectivedata/border_left/) |  |

Ten interfejs jest używany razem z interfejsem [`ICellFormat`](/slides/python-net/pl/aspose.slides/icellformat) do zwracania efektywnych wartości formatowania z zastosowanym dziedziczeniem i stylami tabeli.
