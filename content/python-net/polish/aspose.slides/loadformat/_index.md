## enumeracja LoadFormat

Określa format dokumentu, który ma zostać załadowany.

Typ LoadFormat udostępnia następujących członków:

## Pola

| Pole | Opis |
| :- | :- |
| AUTO | Nakazuje Aspose.Slides automatycznie rozpoznać format. |
| PPT | Prezentacja Microsoft PowerPoint 97-2003. |
| PPS | Pokaz slajdów Microsoft PowerPoint 97-2003. |
| PPTX | Dokument Microsoft Office Open XML PresentationML. |
| PPSX | Pokaz slajdów Microsoft Office Open XML PresentationML. |
| ODP | Prezentacja OpenOffice ODF. |
| POTX | Szablon Microsoft Office Open XML PresentationML. |
| PPTM | Dokument Microsoft Office Open XML PresentationML z obsługą makr. |
| PPSM | Pokaz slajdów Microsoft Office Open XML PresentationML z obsługą makr. |
| POTM | Szablon Microsoft Office Open XML PresentationML z obsługą makr. |
| OTP | Szablon prezentacji OpenOffice OTP. |
| PPT95 | Prezentacja Microsoft PowerPoint 95. |
| POT | Szablon prezentacji Microsoft PowerPoint 97-2003. |
| FODP | Prezentacja Flat XML ODF. |
| UNKNOWN | Nieznany format pliku |
