## IVbaProject klasa

Reprezentuje projekt VBA z makrami prezentacji.

Typ IVbaProject udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`name`](/slides/python-net/pl/aspose.slides.vba/ivbaproject/name/) | Zwraca nazwę projektu VBA.<br/>            Tylko do odczytu **str**. |
| [`modules`](/slides/python-net/pl/aspose.slides.vba/ivbaproject/modules/) | Zwraca listę wszystkich modułów zawartych w projekcie VBA.<br/>            Tylko do odczytu [`IVbaModuleCollection`](/slides/python-net/pl/aspose.slides.vba/ivbamodulecollection). |
| [`references`](/slides/python-net/pl/aspose.slides.vba/ivbaproject/references/) | Zwraca listę wszystkich odwołań zawartych w projekcie VBA.<br/>            Tylko do odczytu [`IVbaReferenceCollection`](/slides/python-net/pl/aspose.slides.vba/ivbareferencecollection). |
| [`is_password_protected`](/slides/python-net/pl/aspose.slides.vba/ivbaproject/is_password_protected/) | Wskazuje, czy VBAProject jest chroniony hasłem do przeglądania właściwości projektu.<br/>            Tylko do odczytu **bool**. |

## Metody

| Metoda | Opis |
| :- | :- |
| [`to_binary(self)`](/slides/python-net/pl/aspose.slides.vba/ivbaproject/to_binary/#) | Zwraca binarną reprezentację projektu VBA jako kontener OLE.<br/>            Tylko do odczytu **int**[]. |
