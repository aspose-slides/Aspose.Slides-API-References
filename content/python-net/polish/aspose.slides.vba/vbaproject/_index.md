## VbaProject klasa

Reprezentuje projekt VBA zawierający makra prezentacji.

Typ VbaProject udostępnia następujące elementy:

## Konstruktory

| Constructor | Description |
| :- | :- |
| [`__init__(self)`](/slides/python-net/pl/aspose.slides.vba/vbaproject/__init__/#) | Ten konstruktor tworzy nowy projekt VBA od zera.<br/>            Projekt zostanie utworzony w kodowaniu 1252 Windows Latin 1 (ANSI) |
| [`__init__(self, data)`](/slides/python-net/pl/aspose.slides.vba/vbaproject/__init__/#bytes) | Ten konstruktor ładuje projekt VBA z binarnej reprezentacji kontenera OLE. |

## Właściwości

| Property | Description |
| :- | :- |
| [`name`](/slides/python-net/pl/aspose.slides.vba/vbaproject/name/) | Zwraca nazwę projektu VBA.<br/>            Tylko do odczytu **str**. |
| [`modules`](/slides/python-net/pl/aspose.slides.vba/vbaproject/modules/) | Zwraca listę wszystkich modułów zawartych w projekcie VBA.<br/>            Tylko do odczytu [`IVbaModuleCollection`](/slides/python-net/pl/aspose.slides.vba/ivbamodulecollection). |
| [`references`](/slides/python-net/pl/aspose.slides.vba/vbaproject/references/) | Zwraca listę wszystkich referencji zawartych w projekcie VBA.<br/>            Tylko do odczytu [`IVbaReferenceCollection`](/slides/python-net/pl/aspose.slides.vba/ivbareferencecollection). |
| [`is_password_protected`](/slides/python-net/pl/aspose.slides.vba/vbaproject/is_password_protected/) | Wskazuje, czy VBAProject jest chroniony hasłem przed podglądem właściwości projektu.<br/>            Tylko do odczytu **bool**. |
