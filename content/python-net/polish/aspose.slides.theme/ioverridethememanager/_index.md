## IOverrideThemeManager klasa

Umożliwia dostęp do różnych typów nadpisanych motywów.

Typ IOverrideThemeManager udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`is_override_theme_enabled`](/slides/python-net/pl/aspose.slides.theme/ioverridethememanager/is_override_theme_enabled/) | Określa, czy OverrideTheme nadpisuje odziedziczony efektywny motyw, czy nie.<br/>            Aby włączyć OverrideTheme do nadpisywania, użyj metod OverrideTheme.Init*().<br/>            Aby wyłączyć OverrideTheme z nadpisywania, użyj metody OverrideTheme.Clear().<br/>            Tylko do odczytu **bool**. |
| [`override_theme`](/slides/python-net/pl/aspose.slides.theme/ioverridethememanager/override_theme/) | Zwraca obiekt nadpisującego motywu.<br/>            Odczyt/zapis [`IOverrideTheme`](/slides/python-net/pl/aspose.slides.theme/ioverridetheme). |
