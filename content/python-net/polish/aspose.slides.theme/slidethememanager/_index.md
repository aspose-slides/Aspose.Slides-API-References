## SlideThemeManager klasa

Umożliwia dostęp do nadpisanego motywu slajdu.

**Dziedziczenie:**[`SlideThemeManager`](/slides/python-net/pl/aspose.slides.theme/slidethememanager) → [`BaseOverrideThemeManager`](/slides/python-net/pl/aspose.slides.theme/baseoverridethememanager) → [`BaseThemeManager`](/slides/python-net/pl/aspose.slides.theme/basethememanager)

Typ SlideThemeManager udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`override_theme`](/slides/python-net/pl/aspose.slides.theme/slidethememanager/override_theme/) | Zwraca obiekt nadpisującego motywu.<br/>            Odczyt/zapis [`IOverrideTheme`](/slides/python-net/pl/aspose.slides.theme/ioverridetheme). |
| [`is_override_theme_enabled`](/slides/python-net/pl/aspose.slides.theme/slidethememanager/is_override_theme_enabled/) | Określa, czy OverrideTheme nadpisuje odziedziczony efektywny motyw, czy nie.<br/>            Aby włączyć OverrideTheme do nadpisywania, użyj metod OverrideTheme.Init*() .<br/>            Aby wyłączyć OverrideTheme z nadpisywania, użyj metody OverrideTheme.Clear() .<br/>            Tylko do odczytu **bool**. |
