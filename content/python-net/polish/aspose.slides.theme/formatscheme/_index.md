## FormatScheme klasa

Przechowuje formaty zdefiniowane w motywie dla kształtów.

Typ FormatScheme udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`fill_styles`](/slides/python-net/pl/aspose.slides.theme/formatscheme/fill_styles/) | Zwraca kolekcję stylów wypełnienia zdefiniowanych w motywie.<br/>            Tylko do odczytu [`IFillFormatCollection`](/slides/python-net/pl/aspose.slides.theme/ifillformatcollection). |
| [`line_styles`](/slides/python-net/pl/aspose.slides.theme/formatscheme/line_styles/) | Zwraca kolekcję stylów linii zdefiniowanych w motywie.<br/>            Tylko do odczytu [`ILineFormatCollection`](/slides/python-net/pl/aspose.slides.theme/ilineformatcollection). |
| [`effect_styles`](/slides/python-net/pl/aspose.slides.theme/formatscheme/effect_styles/) | Zwraca kolekcję stylów efektów zdefiniowanych w motywie.<br/>            Tylko do odczytu [`IEffectStyleCollection`](/slides/python-net/pl/aspose.slides.theme/ieffectstylecollection). |
| [`background_fill_styles`](/slides/python-net/pl/aspose.slides.theme/formatscheme/background_fill_styles/) | Zwraca kolekcję stylów wypełnienia tła zdefiniowanych w motywie.<br/>            Tylko do odczytu [`IFillFormatCollection`](/slides/python-net/pl/aspose.slides.theme/ifillformatcollection). |
| [`slide`](/slides/python-net/pl/aspose.slides.theme/formatscheme/slide/) | Zwraca slajd nadrzędny.<br/>            Tylko do odczytu [`IBaseSlide`](/slides/python-net/pl/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/pl/aspose.slides.theme/formatscheme/presentation/) | Zwraca prezentację nadrzędną.<br/>            Tylko do odczytu [`IPresentation`](/slides/python-net/pl/aspose.slides/ipresentation). |
