## IFontScheme klasa

Przechowuje czcionki zdefiniowane w motywie.

Typ IFontScheme udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`minor`](/slides/python-net/pl/aspose.slides.theme/ifontscheme/minor/) | Zwraca kolekcję czcionek dla części „body” slajdu.<br/>            Tylko do odczytu [`IFonts`](/slides/python-net/pl/aspose.slides/ifonts). |
| [`major`](/slides/python-net/pl/aspose.slides.theme/ifontscheme/major/) | Zwraca kolekcję czcionek dla części „heading” slajdu.<br/>            Tylko do odczytu [`IFonts`](/slides/python-net/pl/aspose.slides/ifonts). |
| [`name`](/slides/python-net/pl/aspose.slides.theme/ifontscheme/name/) | Zwraca nazwę schematu czcionek.<br/>            Odczyt/zapis **str**. |
