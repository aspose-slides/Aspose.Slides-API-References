## OverrideTheme klasa

Reprezentuje nadpisujący motyw.

**Dziedziczenie:**[`OverrideTheme`](/slides/python-net/pl/aspose.slides.theme/overridetheme) → [`Theme`](/slides/python-net/pl/aspose.slides.theme/theme)

Typ OverrideTheme udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`color_scheme`](/slides/python-net/pl/aspose.slides.theme/overridetheme/color_scheme/) | Zwraca schemat kolorów.<br/>            Tylko do odczytu [`IColorScheme`](/slides/python-net/pl/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/pl/aspose.slides.theme/overridetheme/font_scheme/) | Zwraca schemat czcionek.<br/>            Tylko do odczytu [`IFontScheme`](/slides/python-net/pl/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/pl/aspose.slides.theme/overridetheme/format_scheme/) | Zwraca schemat formatu kształtu.<br/>            Tylko do odczytu [`IFormatScheme`](/slides/python-net/pl/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/pl/aspose.slides.theme/overridetheme/presentation/) | Zwraca prezentację nadrzędną.<br/>            Tylko do odczytu [`IPresentation`](/slides/python-net/pl/aspose.slides/ipresentation). |
| [`is_empty`](/slides/python-net/pl/aspose.slides.theme/overridetheme/is_empty/) | Wartość true oznacza, że ColorScheme, FontScheme, FormatScheme jest None i wszelkie nadpisywanie przy użyciu tego obiektu motywu jest wyłączone.<br/>            Tylko do odczytu **bool**. |
