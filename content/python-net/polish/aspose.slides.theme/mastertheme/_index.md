## MasterTheme klasa

Reprezentuje motyw główny.

**Dziedziczenie:**[`MasterTheme`](/slides/python-net/pl/aspose.slides.theme/mastertheme) → [`Theme`](/slides/python-net/pl/aspose.slides.theme/theme)

Typ MasterTheme udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`color_scheme`](/slides/python-net/pl/aspose.slides.theme/mastertheme/color_scheme/) | Zwraca schemat kolorów.<br/>            Tylko do odczytu [`IColorScheme`](/slides/python-net/pl/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/pl/aspose.slides.theme/mastertheme/font_scheme/) | Zwraca schemat czcionek.<br/>            Tylko do odczytu [`IFontScheme`](/slides/python-net/pl/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/pl/aspose.slides.theme/mastertheme/format_scheme/) | Zwraca schemat formatowania kształtów.<br/>            Tylko do odczytu [`IFormatScheme`](/slides/python-net/pl/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/pl/aspose.slides.theme/mastertheme/presentation/) | Zwraca prezentację nadrzędną.<br/>            Tylko do odczytu [`IPresentation`](/slides/python-net/pl/aspose.slides/ipresentation). |
| [`extra_color_schemes`](/slides/python-net/pl/aspose.slides.theme/mastertheme/extra_color_schemes/) | Zwraca kolekcję dodatkowych schematów kolorów.<br/>            Te schematy nie wpływają na wygląd prezentacji, mogą być wybrane jako główny schemat kolorów dla slajdu.<br/>            Tylko do odczytu [`IExtraColorSchemeCollection`](/slides/python-net/pl/aspose.slides.theme/iextracolorschemecollection). |
| [`name`](/slides/python-net/pl/aspose.slides.theme/mastertheme/name/) | Zwraca nazwę motywu.<br/>            Odczyt/zapis **str**. |

## Metody

| Metoda | Opis |
| :- | :- |
