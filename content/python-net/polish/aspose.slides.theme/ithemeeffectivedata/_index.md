## IThemeEffectiveData klasa

Niezmienny obiekt, który zawiera efektywne właściwości motywu.

Typ IThemeEffectiveData udostępnia następujące członki:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`font_scheme`](/slides/python-net/pl/aspose.slides.theme/ithemeeffectivedata/font_scheme/) | Zwraca schemat czcionek.<br/> Tylko do odczytu [`IFontSchemeEffectiveData`](/slides/python-net/pl/aspose.slides.theme/ifontschemeeffectivedata). |
| [`format_scheme`](/slides/python-net/pl/aspose.slides.theme/ithemeeffectivedata/format_scheme/) | Zwraca schemat formatowania kształtu.<br/> Tylko do odczytu [`IFormatSchemeEffectiveData`](/slides/python-net/pl/aspose.slides.theme/iformatschemeeffectivedata). |

## Metody

| Metoda | Opis |
| :- | :- |
| [`get_color_scheme(self, style_color)`](/slides/python-net/pl/aspose.slides.theme/ithemeeffectivedata/get_color_scheme/#asposeslidescolor) | Zwraca schemat kolorów. |

### Uwagi

Ten interfejs jest używany razem z interfejsem [`ITheme`](/slides/python-net/pl/aspose.slides.theme/itheme), aby zwrócić efektywne wartości formatowania z zastosowanym dziedziczeniem.
