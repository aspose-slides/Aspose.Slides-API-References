## IFontSchemeEffectiveData klasa

Niezmienny obiekt zawierający właściwości efektywnego schematu czcionek.

Typ IFontSchemeEffectiveData udostępnia następujące członki:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`minor`](/slides/python-net/pl/aspose.slides.theme/ifontschemeeffectivedata/minor/) | Zwraca kolekcję czcionek dla części „body” slajdu.<br/>            Tylko do odczytu [`IFontsEffectiveData`](/slides/python-net/pl/aspose.slides/ifontseffectivedata). |
| [`major`](/slides/python-net/pl/aspose.slides.theme/ifontschemeeffectivedata/major/) | Zwraca kolekcję czcionek dla części „heading” slajdu.<br/>            Tylko do odczytu [`IFontsEffectiveData`](/slides/python-net/pl/aspose.slides/ifontseffectivedata). |
| [`name`](/slides/python-net/pl/aspose.slides.theme/ifontschemeeffectivedata/name/) | Zwraca nazwę schematu czcionek.<br/>            Tylko do odczytu **str**. |

### Uwagi

Ten interfejs jest używany jako część [`IThemeEffectiveData`](/slides/python-net/pl/aspose.slides.theme/ithemeeffectivedata).
