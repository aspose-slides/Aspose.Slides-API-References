## FontScheme klasa

Przechowuje czcionki zdefiniowane w motywie.

Typ FontScheme udostępnia następujące elementy:

## Właściwości

| Property | Opis |
| :- | :- |
| [`minor`](/slides/python-net/pl/aspose.slides.theme/fontscheme/minor/) | Zwraca kolekcję czcionek dla części „body” slajdu.<br/>            Tylko do odczytu [`IFonts`](/slides/python-net/pl/aspose.slides/ifonts). |
| [`major`](/slides/python-net/pl/aspose.slides.theme/fontscheme/major/) | Zwraca kolekcję czcionek dla części „heading” slajdu.<br/>            Tylko do odczytu [`IFonts`](/slides/python-net/pl/aspose.slides/ifonts). |
| [`name`](/slides/python-net/pl/aspose.slides.theme/fontscheme/name/) | Zwraca nazwę schematu czcionek.<br/>            Odczyt/zapis **str**. |
