## IEffectStyleEffectiveData klasa

Niezmienny obiekt, który zawiera skuteczne właściwości stylu efektu.

Typ IEffectStyleEffectiveData udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`effect_format`](/slides/python-net/pl/aspose.slides.theme/ieffectstyleeffectivedata/effect_format/) | Zwraca format efektu.<br/>            Tylko do odczytu [`IEffectFormatEffectiveData`](/slides/python-net/pl/aspose.slides/ieffectformateffectivedata). |
| [`three_d_format`](/slides/python-net/pl/aspose.slides.theme/ieffectstyleeffectivedata/three_d_format/) | Zwraca format 3D.<br/>            Tylko do odczytu [`IThreeDFormatEffectiveData`](/slides/python-net/pl/aspose.slides/ithreedformateffectivedata). |


### Uwagi

Ten interfejs jest używany jako część [`IEffectStyleCollectionEffectiveData`](/slides/python-net/pl/aspose.slides.theme/ieffectstylecollectioneffectivedata).
