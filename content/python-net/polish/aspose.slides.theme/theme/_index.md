## klasa Theme

Reprezentuje motyw.

Typ Theme udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`color_scheme`](/slides/python-net/pl/aspose.slides.theme/theme/color_scheme/) | Zwraca schemat kolorów.<br/>            Tylko do odczytu [`IColorScheme`](/slides/python-net/pl/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/pl/aspose.slides.theme/theme/font_scheme/) | Zwraca schemat czcionek.<br/>            Tylko do odczytu [`IFontScheme`](/slides/python-net/pl/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/pl/aspose.slides.theme/theme/format_scheme/) | Zwraca schemat formatu kształtów.<br/>            Tylko do odczytu [`IFormatScheme`](/slides/python-net/pl/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/pl/aspose.slides.theme/theme/presentation/) | Zwraca prezentację nadrzędną.<br/>            Tylko do odczytu [`IPresentation`](/slides/python-net/pl/aspose.slides/ipresentation). |

## Metody

| Metoda | Opis |
| :- | :- |
