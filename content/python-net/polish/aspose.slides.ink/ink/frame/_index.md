Zwraca lub ustawia właściwości ramki kształtu.
            Odczyt/zapis [`IShapeFrame`](/slides/python-net/pl/aspose.slides/ishapeframe).

### Uwagi

Wartość każdej właściwości zwróconego obiektu IShapeFrame nie jest undefined (nie jest NaN ani NotDefined).
            Wartość każdej właściwości przypisanego obiektu IShapeFrame musi nie być undefined (musi nie być NaN ani NotDefined).
            Możesz ustawiać wartości undefined dla właściwości obiektu RawFrame.
