## InkBrush klasa

Reprezentuje obiekt inkBrush.

Typ InkBrush udostępnia następujące członków:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`color`](/slides/python-net/pl/aspose.slides.ink/inkbrush/color/) | Pobiera lub ustawia kolor pędzla dla linii. |
| [`size`](/slides/python-net/pl/aspose.slides.ink/inkbrush/size/) | Pobiera lub ustawia rozmiar pędzla dla linii w punktach. |
| [`ink_effect`](/slides/python-net/pl/aspose.slides.ink/inkbrush/ink_effect/) | Pobiera typ efektu tuszu (np. Galaxy, Gold, Silver), który określa styl wizualny pociągnięcia tuszu.<br/>            Wartość jest analizowana z właściwości pędzla "inkEffects". Jeśli nie określono rozpoznawalnego efektu,<br/>            [`InkEffectType.NOT_DEFINED`](/slides/python-net/pl/aspose.slides.ink/inkeffecttype/NOT_DEFINED) zostaje zwrócone. |
