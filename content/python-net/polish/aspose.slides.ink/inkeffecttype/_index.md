## InkEffectType enumeracja

Określa zestaw predefiniowanych efektów wizualnych dla renderowania tuszu.
Każdy efekt odpowiada teksturze lub obrazowi, które symulują stylizowany wygląd tuszu.
Te wartości mogą być użyte do dostosowania wizualnego stylu cyfrowych pociągnięć tuszu podczas renderowania.

Typ InkEffectType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| NOT_DEFINED | Efekt nie jest zdefiniowany lub jest nieznany. Ta wartość może być użyta jako domyślna lub zapasowa. |
| BRONZE | Ciepła, brązowawa metaliczna tekstura przypominająca atrament w kolorze brązu. |
| GALAXY | Kolorowa, migotliwa tekstura przypominająca galaktykę, z kosmicznymi tonami. |
| GOLD | Jasna, metaliczna złota tekstura, która nadaje pociągnięciom tuszu luksusowy wygląd. |
| LAVA | Ognista tekstura przypominająca płynną lawę, z czerwonymi i pomarańczowymi odcieniami. |
| OCEAN | Głęboka niebieska, płynna tekstura, która naśladuje fale oceanu lub tusz na bazie wody. |
| RAINBOW_GLITTER | Kolorowy, błyszczący efekt tęczowego brokatu używany do świątecznych lub żywych pociągnięć tuszu. |
| ROSE_GOLD | Delikatne połączenie różowego i złotego, podobne do różowego złota, dla eleganckich pociągnięć tuszu. |
| SILVER | Chłodna, metaliczna srebrna tekstura, która symuluje klasyczny srebrny tusz. |
