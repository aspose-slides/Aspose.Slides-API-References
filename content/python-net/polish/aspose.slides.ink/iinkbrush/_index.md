## IInkBrush klasa

Reprezentuje pędzel śladu.

Typ IInkBrush udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`color`](/slides/python-net/pl/aspose.slides.ink/iinkbrush/color/) | Pobiera lub ustawia kolor pędzla dla linii. |
| [`size`](/slides/python-net/pl/aspose.slides.ink/iinkbrush/size/) | Pobiera lub ustawia rozmiar pędzla dla linii w punktach. |
| [`ink_effect`](/slides/python-net/pl/aspose.slides.ink/iinkbrush/ink_effect/) | Pobiera typ efektu tuszu (np., Galaxy, Gold, Silver), który definiuje wizualny styl pociągnięcia tuszu.<br/>            Wartość jest parsowana z właściwości pędzla "inkEffects". Jeśli nie określono rozpoznanego efektu,<br/>            [`InkEffectType.NOT_DEFINED`](/slides/python-net/pl/aspose.slides.ink/inkeffecttype/NOT_DEFINED) jest zwracane. |
