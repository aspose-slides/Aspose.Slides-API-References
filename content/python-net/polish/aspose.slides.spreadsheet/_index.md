Zawiera klasy do pracy z obiektami arkuszy kalkulacyjnych w prezentacjach Microsoft PowerPoint.
## Klasy

| Klasa | Opis |
| :- | :- |
| [`CellCircularReferenceException`](/slides/python-net/pl/aspose.slides.spreadsheet/cellcircularreferenceexception/) | Wyjątek jest rzucany, gdy wykryto jedną lub więcej odwołań cyklicznych, w których formuła odnosi się do swojej<br/>            komórki bezpośrednio lub pośrednio. |
| [`CellInvalidFormulaException`](/slides/python-net/pl/aspose.slides.spreadsheet/cellinvalidformulaexception/) | Wyjątek jest rzucany, gdy obliczona formuła jest niepoprawna lub nie została sparsowana. |
| [`CellInvalidReferenceException`](/slides/python-net/pl/aspose.slides.spreadsheet/cellinvalidreferenceexception/) | Wyjątek jest rzucany, gdy napotkano nieprawidłowe odwołanie do komórki. |
| [`CellUnsupportedDataException`](/slides/python-net/pl/aspose.slides.spreadsheet/cellunsupporteddataexception/) | Wyjątek jest rzucany, gdy w komórce arkusza napotkano nieobsługiwane dane. |
