## IUpDownBarsManager klasa

Udostępnia dostęp do pasków górnych i dolnych wykresu liniowego lub giełdowego.

Typ IUpDownBarsManager udostępnia następujących członków:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`up_bars_format`](/slides/python-net/pl/aspose.slides.charts/iupdownbarsmanager/up_bars_format/) | Zwraca format pasków górnych.<br/>            Tylko do odczytu [`IFormat`](/slides/python-net/pl/aspose.slides.charts/iformat). |
| [`down_bars_format`](/slides/python-net/pl/aspose.slides.charts/iupdownbarsmanager/down_bars_format/) | Zwraca format pasków dolnych.<br/>            Tylko do odczytu [`IFormat`](/slides/python-net/pl/aspose.slides.charts/iformat). |
| [`has_up_down_bars`](/slides/python-net/pl/aspose.slides.charts/iupdownbarsmanager/has_up_down_bars/) | Określa, czy wykres ma paski górne/dolne.<br/>            Odczyt/zapis **bool**. |
| [`gap_width`](/slides/python-net/pl/aspose.slides.charts/iupdownbarsmanager/gap_width/) | Zwraca lub ustawia szerokość przerwy.<br/>            Odczyt/zapis **int**. |
