## CategoryAxisType enumeracja

Reprezentuje typ osi kategorii.

Typ CategoryAxisType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| TEXT | Określa, że oś kategorii jest osią tekstową. |
| DATE | Określa, że oś kategorii jest osią datową. |
