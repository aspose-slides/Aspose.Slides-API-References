## bubble_size_scale właściwość
Określa współczynnik skali dla wykresu bąbelkowego (może być 
            pomiędzy 0 a 300 procent domyślnego rozmiaru).
            To jest właściwość nie tylko tej serii, ale wszystkich serii grupy serii nadrzędnej 
            grupy - jest to projekcja odpowiedniej właściwości grupy. A więc ta właściwość 
            jest tylko do odczytu.
            Użyj właściwości ParentSeriesGroup, aby uzyskać dostęp do grupy serii nadrzędnej.
            Użyj właściwości ParentSeriesGroup.BubbleSizeScale do odczytu/zapisu, aby zmienić wartość.

### Uwagi

To jest projekcja właściwości ParentSeriesGroup.BubbleSizeScale.
