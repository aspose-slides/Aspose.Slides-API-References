## ILayoutable klasa

Określa dokładną pozycję elementu wykresu.

Typ ILayoutable udostępnia następujące członków:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`x`](/slides/python-net/pl/aspose.slides.charts/ilayoutable/x/) | Określa położenie x (lewe) elementu wykresu jako ułamek szerokości wykresu.<br/>Odczyt/zapis **float**. |
| [`y`](/slides/python-net/pl/aspose.slides.charts/ilayoutable/y/) | Określa górę elementu wykresu jako ułamek wysokości wykresu.<br/>Odczyt/zapis **float**. |
| [`width`](/slides/python-net/pl/aspose.slides.charts/ilayoutable/width/) | Określa szerokość elementu wykresu jako ułamek szerokości wykresu.<br/>Odczyt/zapis **float**. |
| [`height`](/slides/python-net/pl/aspose.slides.charts/ilayoutable/height/) | Określa wysokość elementu wykresu jako ułamek wysokości wykresu.<br/>Odczyt/zapis **float**. |
| [`right`](/slides/python-net/pl/aspose.slides.charts/ilayoutable/right/) | Zwraca prawą krawędź elementu wykresu jako ułamek szerokości wykresu.<br/>Tylko do odczytu **float**. |
| [`bottom`](/slides/python-net/pl/aspose.slides.charts/ilayoutable/bottom/) | Zwraca górę elementu wykresu jako ułamek wysokości wykresu.<br/>Tylko do odczytu **float**. |
