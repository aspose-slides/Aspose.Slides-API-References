## IErrorBarsCustomValues klasa

Określa wartości pasków błędów. Powinien być używany tylko wtedy, gdy typ wartości pasków błędów jest Custom.

Typ IErrorBarsCustomValues udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`x_minus`](/slides/python-net/pl/aspose.slides.charts/ierrorbarscustomvalues/x_minus/) | Określa wartość paska błędów w kierunku ujemnym.<br/>            Dostępny, jeśli typ wartości pasków błędów jest Custom i ErrorBarsXFormat jest dozwolony.<br/>            W każdym innym przypadku ta właściwość zwraca None.<br/>            Tylko do odczytu [`IDoubleChartValue`](/slides/python-net/pl/aspose.slides.charts/idoublechartvalue). |
| [`y_minus`](/slides/python-net/pl/aspose.slides.charts/ierrorbarscustomvalues/y_minus/) | Określa wartość paska błędów w kierunku ujemnym.<br/>            Dostępny, jeśli typ wartości pasków błędów jest Custom i ErrorBarsYFormat jest dozwolony.<br/>            W każdym innym przypadku ta właściwość zwraca None.<br/>            Tylko do odczytu [`IDoubleChartValue`](/slides/python-net/pl/aspose.slides.charts/idoublechartvalue). |
| [`x_plus`](/slides/python-net/pl/aspose.slides.charts/ierrorbarscustomvalues/x_plus/) | Określa wartość paska błędów w kierunku dodatnim.<br/>            Dostępny, jeśli typ wartości pasków błędów jest Custom i ErrorBarsXFormat jest dozwolony.<br/>            W każdym innym przypadku ta właściwość zwraca None.<br/>            Tylko do odczytu [`IDoubleChartValue`](/slides/python-net/pl/aspose.slides.charts/idoublechartvalue). |
| [`y_plus`](/slides/python-net/pl/aspose.slides.charts/ierrorbarscustomvalues/y_plus/) | Określa wartość paska błędów w kierunku dodatnim.<br/>            Dostępny, jeśli typ wartości pasków błędów jest Custom i ErrorBarsYFormat jest dozwolony.<br/>            W każdym innym przypadku ta właściwość zwraca None.<br/>            Tylko do odczytu [`IDoubleChartValue`](/slides/python-net/pl/aspose.slides.charts/idoublechartvalue). |
