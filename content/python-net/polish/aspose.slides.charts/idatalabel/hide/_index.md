## hide(self) {#}
Ustaw etykietę danych jako ukrytą, ustawiając wszystkie flagi Show*-flags (ShowValue, ...) na stan false.
            IsVisible będzie false po tym.

```python
def hide(self):
    ...
```

### Uwagi
Jeśli etykieta danych nie jest widoczna (IsVisible jest false) możesz uczynić etykietę danych widoczną poprzez 
            ustawienie flag Show*-flags (ShowValue, ...) na stan true.
