## MarkerStyleType wyliczenie

Określa formę znacznika na punkcie danych wykresu.

Typ MarkerStyleType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| NOT_DEFINED |  |
| CIRCLE | Określa, że przy każdym punkcie danych zostanie narysowane koło. |
| DASH | Określa, że przy każdym punkcie danych zostanie narysowana kreska. |
| DIAMOND | Określa, że przy każdym punkcie danych zostanie narysowany diament. |
| DOT | Określa, że przy każdym punkcie danych zostanie narysowana kropka. |
| NONE | Określa, że przy każdym punkcie danych nie zostanie nic narysowane. |
| PICTURE | Określa, że przy każdym punkcie danych zostanie narysowany obraz. |
| PLUS | Określa, że przy każdym punkcie danych zostanie narysowany znak plus. |
| SQUARE | Określa, że przy każdym punkcie danych zostanie narysowany kwadrat. |
| STAR | Określa, że przy każdym punkcie danych zostanie narysowana gwiazda. |
| TRIANGLE | Określa, że przy każdym punkcie danych zostanie narysowany trójkąt. |
| X | Określa, że przy każdym punkcie danych zostanie narysowane X. |
