## ChartPlotArea klasa

Reprezentuje prostokąt, w którym powinien być rysowany wykres.

Typ ChartPlotArea udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`format`](/slides/python-net/pl/aspose.slides.charts/chartplotarea/format/) | Zwraca format obszaru wykresu.<br/>            Tylko do odczytu [`IFormat`](/slides/python-net/pl/aspose.slides.charts/iformat). |
| [`x`](/slides/python-net/pl/aspose.slides.charts/chartplotarea/x/) | Zwraca lub ustawia współrzędną x lewego górnego rogu ramki ograniczającej obszar wykresu jako ułamek szerokości wykresu (od 0 do 1).<br/>            Odczyt/zapis **float**. |
| [`y`](/slides/python-net/pl/aspose.slides.charts/chartplotarea/y/) | Zwraca lub ustawia współrzędną y lewego górnego rogu ramki ograniczającej obszar wykresu jako ułamek wysokości wykresu (od 0 do 1).<br/>            Odczyt/zapis **float**. |
| [`width`](/slides/python-net/pl/aspose.slides.charts/chartplotarea/width/) | Zwraca lub ustawia szerokość ramki ograniczającej obszar wykresu jako ułamek szerokości wykresu (od 0 do 1).<br/>            Odczyt/zapis **float**. |
| [`height`](/slides/python-net/pl/aspose.slides.charts/chartplotarea/height/) | Zwraca lub ustawia wysokość ramki ograniczającej obszar wykresu jako ułamek wysokości wykresu (od 0 do 1).<br/>            Odczyt/zapis **float**. |
| [`right`](/slides/python-net/pl/aspose.slides.charts/chartplotarea/right/) | Prawo.<br/>            Tylko do odczytu **float**. |
| [`bottom`](/slides/python-net/pl/aspose.slides.charts/chartplotarea/bottom/) | Dół.<br/>            Tylko do odczytu **float**. |
| [`chart`](/slides/python-net/pl/aspose.slides.charts/chartplotarea/chart/) | Wykres.<br/>            Tylko do odczytu [`IChart`](/slides/python-net/pl/aspose.slides.charts/ichart). |
| [`is_location_autocalculated`](/slides/python-net/pl/aspose.slides.charts/chartplotarea/is_location_autocalculated/) | Określa, jak powinno być obliczane położenie: true – obliczane automatycznie; określone przez właściwości X, Y, Width, Height.<br/>            Tylko do odczytu **bool**. |
| [`layout_target_type`](/slides/python-net/pl/aspose.slides.charts/chartplotarea/layout_target_type/) | Jeśli układ obszaru wykresu jest określony ręcznie, ta właściwość określa, czy układać obszar wykresu wewnątrz (bez osi i etykiet osi) czy na zewnątrz (z osiami i etykietami osi).<br/>            Odczyt/zapis [`ChartPlotArea.layout_target_type`](/slides/python-net/pl/aspose.slides.charts/chartplotarea/layout_target_type). |
| [`actual_x`](/slides/python-net/pl/aspose.slides.charts/chartplotarea/actual_x/) | Określa rzeczywiste położenie x (lewe) elementu wykresu względem lewego górnego rogu wykresu.<br/>            Wywołaj metodę IChart.ValidateChartLayout() przed uzyskaniem rzeczywistych wartości. <br/>            Odczyt **float**. |
| [`actual_y`](/slides/python-net/pl/aspose.slides.charts/chartplotarea/actual_y/) | Określa rzeczywistą górną pozycję elementu wykresu względem lewego górnego rogu wykresu.<br/>            Wywołaj metodę IChart.ValidateChartLayout() przed uzyskaniem rzeczywistych wartości. <br/>            Odczyt **float**. |
| [`actual_width`](/slides/python-net/pl/aspose.slides.charts/chartplotarea/actual_width/) | Określa rzeczywistą szerokość elementu wykresu. Wywołaj metodę IChart.ValidateChartLayout() przed uzyskaniem rzeczywistych wartości. <br/>            Odczyt **float**. |
| [`actual_height`](/slides/python-net/pl/aspose.slides.charts/chartplotarea/actual_height/) | Określa rzeczywistą wysokość elementu wykresu. Wywołaj metodę IChart.ValidateChartLayout() przed uzyskaniem rzeczywistych wartości. <br/>            Odczyt **float**. |
