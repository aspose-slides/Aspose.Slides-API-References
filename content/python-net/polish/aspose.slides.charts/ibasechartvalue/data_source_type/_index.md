## data_source_type właściwość
Określa, czy właściwość AsCell, AsLiteralString lub AsLiteralDouble jest aktualna. Innymi słowy określa typ wartości właściwości Data. Ta właściwość jest tylko do odczytu. Aby zmienić wartość tej właściwości, możesz użyć jednej z właściwości ChartDataPointCollection.DataSourceTypeFor<...>.
