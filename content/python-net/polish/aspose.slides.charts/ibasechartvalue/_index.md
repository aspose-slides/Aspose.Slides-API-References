## IBaseChartValue klasa

Reprezentuje wartość wykresu.

Typ IBaseChartValue udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`data_source_type`](/slides/python-net/pl/aspose.slides.charts/ibasechartvalue/data_source_type/) | Określa, czy właściwość AsCell lub AsLiteralString lub AsLiteralDouble jest aktualna. In other words it specifies the type of value of the Data property.<br/>            Ta właściwość jest tylko do odczytu. Aby zmienić wartość tej właściwości, możesz użyć<br/>            jednej z właściwości ChartDataPointCollection.DataSourceTypeFor<...>.<br/>            Odczyt/zapis [`IBaseChartValue.data_source_type`](/slides/python-net/pl/aspose.slides.charts/ibasechartvalue/data_source_type). |
| [`data`](/slides/python-net/pl/aspose.slides.charts/ibasechartvalue/data/) | Odczyt/zapis **dowolny**. |
