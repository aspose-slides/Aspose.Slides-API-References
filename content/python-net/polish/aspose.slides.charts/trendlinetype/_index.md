## TrendlineType enumeracja

Reprezentuje typ linii trendu

Typ TrendlineType udostępnia następujące elementy:

## Pola

| Field | Description |
| :- | :- |
| EXPONENTIAL | Określa, że linia trendu ma być krzywą wykładniczą w postaci. |
| LINEAR | Określa, że linia trendu ma być linią w postaci. |
| LOGARITHMIC | Określa, że linia trendu ma być krzywą logarytmiczną w postaci, gdzie log jest logarytmem naturalnym. |
| MOVING_AVERAGE | Określa, że linia trendu ma być średnią kroczącą okresu Period. |
| POLYNOMIAL | Określa, że linia trendu ma być krzywą wielomianową rzędu Order w postaci. |
| POWER | Określa, że linia trendu ma być krzywą potęgową w postaci. |
