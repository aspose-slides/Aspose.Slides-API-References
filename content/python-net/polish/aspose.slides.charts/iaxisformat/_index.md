## IAxisFormat klasa

Reprezentuje właściwości formatu wykresu.

Typ IAxisFormat udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`fill`](/slides/python-net/pl/aspose.slides.charts/iaxisformat/fill/) | Zwraca właściwości stylu wypełnienia osi.<br/>            Tylko do odczytu [`IFillFormat`](/slides/python-net/pl/aspose.slides/ifillformat). |
| [`line`](/slides/python-net/pl/aspose.slides.charts/iaxisformat/line/) | Zwraca właściwości stylu linii osi.<br/>            Tylko do odczytu [`ILineFormat`](/slides/python-net/pl/aspose.slides/ilineformat). |
| [`effect`](/slides/python-net/pl/aspose.slides.charts/iaxisformat/effect/) | Zwraca efekty używane dla osi.<br/>            Tylko do odczytu [`IEffectFormat`](/slides/python-net/pl/aspose.slides/ieffectformat). |
