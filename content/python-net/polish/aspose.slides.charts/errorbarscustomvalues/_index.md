## ErrorBarsCustomValues klasa

Określa wartości słupków błędów. Powinien być używany tylko wtedy, gdy typ wartości słupków błędów jest Custom.

Typ ErrorBarsCustomValues udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`x_minus`](/slides/python-net/pl/aspose.slides.charts/errorbarscustomvalues/x_minus/) | Określa wartość słupka błędu w kierunku ujemnym. <br/>            Dostępny, jeśli typ wartości słupków błędów jest Custom i ErrorBarsXFormat jest dozwolony.<br/>            W każdym innym przypadku ta właściwość zwraca None.<br/>            Tylko do odczytu [`IDoubleChartValue`](/slides/python-net/pl/aspose.slides.charts/idoublechartvalue). |
| [`y_minus`](/slides/python-net/pl/aspose.slides.charts/errorbarscustomvalues/y_minus/) | Określa wartość słupka błędu w kierunku ujemnym. <br/>            Dostępny, jeśli typ wartości słupków błędów jest Custom i ErrorBarsYFormat jest dozwolony. <br/>            W każdym innym przypadku ta właściwość zwraca None. <br/>            Tylko do odczytu [`IDoubleChartValue`](/slides/python-net/pl/aspose.slides.charts/idoublechartvalue). |
| [`x_plus`](/slides/python-net/pl/aspose.slides.charts/errorbarscustomvalues/x_plus/) | Określa wartość słupka błędu w kierunku dodatnim. <br/>            Dostępny, jeśli typ wartości słupków błędów jest Custom i ErrorBarsXFormat jest dozwolony. <br/>            W każdym innym przypadku ta właściwość zwraca None. <br/>            Tylko do odczytu [`IDoubleChartValue`](/slides/python-net/pl/aspose.slides.charts/idoublechartvalue). |
| [`y_plus`](/slides/python-net/pl/aspose.slides.charts/errorbarscustomvalues/y_plus/) | Określa wartość słupka błędu w kierunku dodatnim. <br/>            Dostępny, jeśli typ wartości słupków błędów jest Custom i ErrorBarsYFormat jest dozwolony.<br/>            W każdym innym przypadku ta właściwość zwraca None. <br/>            Tylko do odczytu [`IDoubleChartValue`](/slides/python-net/pl/aspose.slides.charts/idoublechartvalue). |
