## Wyliczenie ErrorBarValueType

Reprezentuje typ wartości słupka błędu

Typ ErrorBarValueType udostępnia następujące członki:

## Pola

| Pole | Opis |
| :- | :- |
| CUSTOM | Określa, że długość słupków błędu ma być określona przez elementy Plus i Minus. |
| FIXED | Określa, że długość słupków błędu ma być stałą wartością określoną przez Error Bar Value. |
| PERCENTAGE | Określa, że długość słupków błędu ma być procentem Error Bar Value danych. |
| STANDARD_DEVIATION | Określa, że długość słupków błędu ma być odchyleniem standardowym Error Bar Value danych. |
| STANDARD_ERROR | Określa, że długość słupków błędu ma być błędem standardowym Error Bar Value danych. |
