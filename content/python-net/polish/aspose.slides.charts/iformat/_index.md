## IFormat klasa

Reprezentuje właściwości formatu wykresu.

Typ IFormat udostępnia następujące elementy:

## Właściwości

| Property | Description |
| :- | :- |
| [`fill`](/slides/python-net/pl/aspose.slides.charts/iformat/fill/) | Zwraca właściwości stylu wypełnienia wykresu.<br/>            Tylko do odczytu [`IFillFormat`](/slides/python-net/pl/aspose.slides/ifillformat). |
| [`line`](/slides/python-net/pl/aspose.slides.charts/iformat/line/) | Zwraca właściwości stylu linii wykresu.<br/>            Tylko do odczytu [`ILineFormat`](/slides/python-net/pl/aspose.slides/ilineformat). |
