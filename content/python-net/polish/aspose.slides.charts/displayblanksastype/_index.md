## DisplayBlanksAsType wyliczenie

Określa, w jaki sposób będą wyświetlane brakujące dane.

Typ DisplayBlanksAsType udostępnia następujących członków:

## Pola

| Pole | Opis |
| :- | :- |
| GAP | Określa, że puste wartości mają pozostać jako przerwa. |
| SPAN | Określa, że puste wartości mają być rozciągnięte linią. |
| ZERO | Określa, że puste wartości mają być traktowane jako zero. |
