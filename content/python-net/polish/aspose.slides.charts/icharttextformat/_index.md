## IChartTextFormat klasa

Wykres działa z ograniczonym zestawem właściwości formatu tekstu.  
IChartTextFormat, IChartTextBlockFormat, IChartParagraphFormat, IChartPortionFormat interfejsy opisują ten ograniczony zestaw.

Typ IChartTextFormat udostępnia następujące członki:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`text_block_format`](/slides/python-net/pl/aspose.slides.charts/icharttextformat/text_block_format/) | Zwraca format dla elementów tekstu wykresu.<br/>            Tylko do odczytu [`IChartTextBlockFormat`](/slides/python-net/pl/aspose.slides.charts/icharttextblockformat). |
| [`paragraph_format`](/slides/python-net/pl/aspose.slides.charts/icharttextformat/paragraph_format/) | Zwraca format akapitu.<br/>            Tylko do odczytu [`IChartParagraphFormat`](/slides/python-net/pl/aspose.slides.charts/ichartparagraphformat). |
| [`portion_format`](/slides/python-net/pl/aspose.slides.charts/icharttextformat/portion_format/) | Zwraca format części.<br/>            Tylko do odczytu [`IChartPortionFormat`](/slides/python-net/pl/aspose.slides.charts/ichartportionformat). |
