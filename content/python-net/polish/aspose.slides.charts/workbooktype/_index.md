## WorkbookType wyliczenie

Określa typ pliku skoroszytu Open XML.

Typ WorkbookType udostępnia następujących członków:

## Pola

| Pole | Opis |
| :- | :- |
| NOT_DEFINED | Typ skoroszytu nie jest zdefiniowany. |
| WORKBOOK | Skoroszyt Excel (*.xlsx). |
| WORKBOOK_MACRO | Skoroszyt Excel obsługujący makra (*.xlsm). |
| TEMPLATE | Szablon Excel (*.xltx). |
| TEMPLATE_MACRO | Szablon Excel obsługujący makra (*.xltm). |
| WORKBOOK_BINARY_MACRO | Skoroszyt Excel binarny obsługujący makra (*.xlsb). |
