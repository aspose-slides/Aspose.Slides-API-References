## Wyliczenie PieSplitType

Reprezentuje typ punktów podziału w drugim wykresie kołowym lub słupkowym na wykresie typu pie-of-pie lub bar-of-pie chart.

Typ PieSplitType udostępnia następujących członków:

## Pola

| Pole | Opis |
| :- | :- |
| DEFAULT | Określa, że punkty danych mają być podzielone przy użyciu domyślnego <br/>            mechanizmu dla tego typu wykresu. |
| CUSTOM | Określa, że punkty danych mają być podzielone pomiędzy <br/>            wykres kołowy a drugi wykres zgodnie z wartościami niestandardowego podziału. |
| BY_PERCENTAGE | Określa, że punkty danych mają być podzielone pomiędzy wykres kołowy a <br/>            drugi wykres, umieszczając punkty o procencie mniejszym niż <br/>            Split Position percent w drugim wykresie. |
| BY_POS | Określa, że punkty danych mają być podzielone pomiędzy wykres kołowy a <br/>            drugi wykres, umieszczając ostatnią pozycję Split Position punktów danych <br/>            w drugim wykresie. |
| BY_VALUE | Określa, że punkty danych mają być podzielone pomiędzy wykres kołowy a <br/>            drugi wykres, umieszczając punkty danych o wartości mniejszej niż <br/>            Split Position w drugim wykresie. |
