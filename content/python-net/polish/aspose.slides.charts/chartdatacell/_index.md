## ChartDataCell klasa

Reprezentuje komórkę danych wykresu.

Typ ChartDataCell udostępnia następujące elementy:

## Właściwości

| Property | Description |
| :- | :- |
| [`row`](/slides/python-net/pl/aspose.slides.charts/chartdatacell/row/) | Zwraca indeks wiersza arkusza, w którym znajduje się komórka.<br/>            Tylko do odczytu **int**. |
| [`column`](/slides/python-net/pl/aspose.slides.charts/chartdatacell/column/) | Zwraca indeks kolumny arkusza, w którym znajduje się komórka.<br/>            Tylko do odczytu **int**. |
| [`value`](/slides/python-net/pl/aspose.slides.charts/chartdatacell/value/) | Pobiera lub ustawia wartość komórki.<br/>            Odczyt/zapis **any**. |
| [`formula`](/slides/python-net/pl/aspose.slides.charts/chartdatacell/formula/) | Pobiera lub ustawia formułę w stylu A1. |
| [`r1c1_formula`](/slides/python-net/pl/aspose.slides.charts/chartdatacell/r1c1_formula/) | Pobiera lub ustawia formułę w stylu R1C1. |
| [`chart_data_worksheet`](/slides/python-net/pl/aspose.slides.charts/chartdatacell/chart_data_worksheet/) | Pobiera arkusz.<br/>            Tylko do odczytu [`IChartDataWorksheet`](/slides/python-net/pl/aspose.slides.charts/ichartdataworksheet). |
| [`is_hidden`](/slides/python-net/pl/aspose.slides.charts/chartdatacell/is_hidden/) | Określa, czy komórka jest ukryta.<br/>            Tylko do odczytu **bool**. |
| [`custom_number_format`](/slides/python-net/pl/aspose.slides.charts/chartdatacell/custom_number_format/) | Pobiera lub ustawia niestandardowy format wyświetlania liczb i dat.<br/>            Jeśli wartość jest pusta, zostanie użyta wartość PresetNumberFormat.<br/>            Odczyt/zapis **str**. |
| [`preset_number_format`](/slides/python-net/pl/aspose.slides.charts/chartdatacell/preset_number_format/) | Pobiera lub ustawia wbudowany format wyświetlania liczb i dat. Numer preset musi być w przedziale [0..22] lub [37..49].<br/>            Odczyt/zapis **int**. |
