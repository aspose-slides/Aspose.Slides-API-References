## ChartDataPointCollection klasa

Reprezentuje kolekcję punktów danych serii.

Typ ChartDataPointCollection udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`data_source_type_for_x_values`](/slides/python-net/pl/aspose.slides.charts/chartdatapointcollection/data_source_type_for_x_values/) | Określa, czy właściwość AsCell lub AsLiteralString lub AsLiteralDouble <br/>            jest aktualna w obiekcie właściwości XValue punktów danych. Innymi słowy określa <br/>            typ wartości właściwości ChartDataPoint.XValue.Data.<br/>            Odczyt/zapis [`DataSourceType`](/slides/python-net/pl/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_y_values`](/slides/python-net/pl/aspose.slides.charts/chartdatapointcollection/data_source_type_for_y_values/) | Określa, czy właściwość AsCell lub AsLiteralString lub AsLiteralDouble <br/>            jest aktualna w obiekcie właściwości YValue punktów danych. Innymi słowy określa <br/>            typ wartości właściwości ChartDataPoint.YValue.Data.<br/>            Odczyt/zapis [`DataSourceType`](/slides/python-net/pl/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_bubble_sizes`](/slides/python-net/pl/aspose.slides.charts/chartdatapointcollection/data_source_type_for_bubble_sizes/) | Określa, czy właściwość AsCell lub AsLiteralString lub AsLiteralDouble <br/>            jest aktualna w obiekcie właściwości BubbleSize punktów danych. | [`data_source_type_for_values`](/slides/python-net/pl/aspose.slides.charts/chartdatapointcollection/data_source_type_for_values/) | Określa, czy właściwość AsCell lub AsLiteralString lub AsLiteralDouble <br/>            jest aktualna w obiekcie właściwości Value punktów danych. Innymi słowy określa <br/>            typ wartości właściwości ChartDataPoint.Value.Data.<br/>            Odczyt/zapis [`DataSourceType`](/slides/python-net/pl/aspose.slides.charts/datasourcetype). |
