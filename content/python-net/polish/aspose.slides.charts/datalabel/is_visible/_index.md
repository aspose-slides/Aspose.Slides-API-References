## is_visible właściwość
False oznacza, że etykieta danych nie jest widoczna (a więc wszystkie Show*-flags (ShowValue, ...) są false).
            Tylko do odczytu **bool**.


### Uwagi

Jeśli etykieta danych jest widoczna, możesz ukryć ją metodą Hide().
            Ale jeśli etykieta danych nie jest widoczna (IsVisible is false), możesz sprawić, że etykieta danych będzie widoczna 
            ustawiając Show*-flags (ShowValue, ...) na stan true.
