## Rotation3D klasa

Reprezentuje trójwymiarowy obrót wykresu.

Typ Rotation3D udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`rotation_x`](/slides/python-net/pl/aspose.slides.charts/rotation3d/rotation_x/) | Zwraca lub ustawia stopień obrotu wokół osi X, tj. w kierunku Y dla wykresów 3D (między -90 a 90 stopni).<br/>            Właściwość odpowiada elementowi 21.2.2.157 rotX (X Rotation) w ECMA-376 oraz opcji "Y Rotation" w PowerPoint 2007+.<br/>            Odczyt/zapis **int**. |
| [`rotation_y`](/slides/python-net/pl/aspose.slides.charts/rotation3d/rotation_y/) | Zwraca lub ustawia stopień obrotu wokół osi Y, tj. w kierunku X dla wykresów 3D (między 0 a 360 stopni).<br/>            Właściwość odpowiada elementowi 21.2.2.158 rotY (Y Rotation) w ECMA-376 oraz opcji "X Rotation" w PowerPoint 2007+.<br/>            Odczyt/zapis **int**. |
| [`perspective`](/slides/python-net/pl/aspose.slides.charts/rotation3d/perspective/) | Zwraca lub ustawia wartość perspektywy (kąt pola widzenia) dla wykresów 3D (między 0 a 240).<br/>            Ignorowane, jeśli wartość właściwości RightAngleAxes jest true.<br/>            Odczyt/zapis **int**. |
| [`right_angle_axes`](/slides/python-net/pl/aspose.slides.charts/rotation3d/right_angle_axes/) | Określa, czy osie wykresu są pod kątem prostym, a nie rysowane w perspektywie.<br/>            Inaczej mówiąc, określa, czy kąty osi wykresu są niezależne od obrotu <br/>            wykresu lub elewacji.<br/>            Odczyt/zapis **bool**. |
| [`depth_percents`](/slides/python-net/pl/aspose.slides.charts/rotation3d/depth_percents/) | Zwraca lub ustawia głębokość wykresu 3D jako procent szerokości wykresu (między 20 a 2000 procent).<br/>            Odczyt/zapis **int**. |
| [`height_percents`](/slides/python-net/pl/aspose.slides.charts/rotation3d/height_percents/) | Określa wysokość wykresu 3-D jako procent szerokości wykresu (między 5 a 500 procent).<br/>            Odczyt/zapis **int**. |
