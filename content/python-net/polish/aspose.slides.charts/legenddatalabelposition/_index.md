## LegendDataLabelPosition - enumeracja

Określa położenie etykiet danych.

Typ LegendDataLabelPosition udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| NOT_DEFINED | Pozycja nie jest określona. |
| BOTTOM | Określa, że etykiety danych mają być wyświetlane pod znacznikiem danych. |
| BEST_FIT | Określa, że etykiety danych mają być wyświetlane w najlepszej pozycji. |
| CENTER | Określa, że etykiety danych mają być wyświetlane wyśrodkowane na znaczniku danych. |
| INSIDE_BASE | Określa, że etykiety danych mają być wyświetlane wewnątrz podstawy znacznika danych. |
| INSIDE_END | Określa, że etykiety danych mają być wyświetlane wewnątrz końca znacznika danych. |
| LEFT | Określa, że etykiety danych mają być wyświetlane po lewej stronie znacznika danych. |
| OUTSIDE_END | Określa, że etykiety danych mają być wyświetlane na zewnątrz końca znacznika danych. |
| RIGHT | Określa, że etykiety danych mają być wyświetlane po prawej stronie znacznika danych. |
| TOP | Określa, że etykiety danych mają być wyświetlane nad znacznikiem danych. |
