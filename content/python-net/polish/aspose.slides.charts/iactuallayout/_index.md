## IActualLayout klasa

Określa rzeczywistą pozycję elementu wykresu.

Typ IActualLayout udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`actual_x`](/slides/python-net/pl/aspose.slides.charts/iactuallayout/actual_x/) | Określa rzeczywistą pozycję x (lewo) elementu wykresu względem lewego górnego rogu wykresu.<br/>            Wywołaj metodę IChart.ValidateChartLayout() przed uzyskaniem rzeczywistych wartości. <br/>            Odczytaj **float**. |
| [`actual_y`](/slides/python-net/pl/aspose.slides.charts/iactuallayout/actual_y/) | Określa rzeczywistą górną pozycję elementu wykresu względem lewego górnego rogu wykresu.<br/>            Wywołaj metodę IChart.ValidateChartLayout() przed uzyskaniem rzeczywistych wartości. <br/>            Odczytaj **float**. |
| [`actual_width`](/slides/python-net/pl/aspose.slides.charts/iactuallayout/actual_width/) | Określa rzeczywistą szerokość elementu wykresu. Wywołaj metodę IChart.ValidateChartLayout() przed uzyskaniem rzeczywistych wartości. <br/>            Odczytaj **float**. |
| [`actual_height`](/slides/python-net/pl/aspose.slides.charts/iactuallayout/actual_height/) | Określa rzeczywistą wysokość elementu wykresu. Wywołaj metodę IChart.ValidateChartLayout() przed uzyskaniem rzeczywistych wartości. <br/>            Odczytaj **float**. |
