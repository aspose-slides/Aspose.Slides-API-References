## Klasa ChartTitle

Reprezentuje właściwości tytułu wykresu.

Typ ChartTitle udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`x`](/slides/python-net/pl/aspose.slides.charts/charttitle/x/) | Zwraca lub ustawia współrzędną x tytułu jako ułamek szerokości wykresu.<br/>            Odczyt/zapis **float**. |
| [`y`](/slides/python-net/pl/aspose.slides.charts/charttitle/y/) | Zwraca lub ustawia współrzędną y tytułu jako ułamek wysokości wykresu.<br/>            Odczyt/zapis **float**. |
| [`width`](/slides/python-net/pl/aspose.slides.charts/charttitle/width/) | Zwraca lub ustawia szerokość tytułu jako ułamek szerokości wykresu.<br/>            Odczyt/zapis **float**. |
| [`height`](/slides/python-net/pl/aspose.slides.charts/charttitle/height/) | Zwraca lub ustawia wysokość tytułu jako ułamek wysokości wykresu.<br/>            Odczyt/zapis **float**. |
| [`right`](/slides/python-net/pl/aspose.slides.charts/charttitle/right/) | Prawo.<br/>            Tylko do odczytu **float**. |
| [`bottom`](/slides/python-net/pl/aspose.slides.charts/charttitle/bottom/) | Dół.<br/>            Tylko do odczytu **float**. |
| [`overlay`](/slides/python-net/pl/aspose.slides.charts/charttitle/overlay/) | Określa, czy inne elementy wykresu mogą nachodzić na tytuł.<br/>            Odczyt/zapis **bool**. |
| [`format`](/slides/python-net/pl/aspose.slides.charts/charttitle/format/) | Zwraca style wypełnienia, linii i efektów tytułu.<br/>            Tylko do odczytu [`IFormat`](/slides/python-net/pl/aspose.slides.charts/iformat). |
| [`text_frame_for_overriding`](/slides/python-net/pl/aspose.slides.charts/charttitle/text_frame_for_overriding/) | Może zawierać bogato sformatowany tekst. Jeśli ta właściwość nie jest None, to ta <br/>            sformatowana wartość tekstu zastępuje tekst generowany automatycznie.<br/>            Tekst generowany automatycznie jest domyślną właściwością etykiety danych, etykiety jednostki wyświetlania osi wartości, tytułu osi, tytułu wykresu, etykiety linii trendu.<br/>            Tekst generowany automatycznie jest formatowany właściwością IFormattedTextContainer.TextFormat.<br/>            Tylko do odczytu [`ITextFrame`](/slides/python-net/pl/aspose.slides/itextframe). |
| [`text_format`](/slides/python-net/pl/aspose.slides.charts/charttitle/text_format/) | Zwraca format tekstu.<br/>            Tylko do odczytu [`IChartTextFormat`](/slides/python-net/pl/aspose.slides.charts/icharttextformat). |
| [`actual_x`](/slides/python-net/pl/aspose.slides.charts/charttitle/actual_x/) | Określa rzeczywistą lokalizację x (lewy) elementu wykresu względem lewego górnego rogu wykresu.<br/>            Wywołaj metodę IChart.ValidateChartLayout() przed, aby uzyskać rzeczywiste wartości. <br/>            Odczyt **float**. |
| [`actual_y`](/slides/python-net/pl/aspose.slides.charts/charttitle/actual_y/) | Określa rzeczywistą górną pozycję elementu wykresu względem lewego górnego rogu wykresu.<br/>            Wywołaj metodę IChart.ValidateChartLayout() przed, aby uzyskać rzeczywiste wartości. <br/>            Odczyt **float**. |
| [`actual_width`](/slides/python-net/pl/aspose.slides.charts/charttitle/actual_width/) | Określa rzeczywistą szerokość elementu wykresu. Wywołaj metodę IChart.ValidateChartLayout() przed, aby uzyskać rzeczywiste wartości. <br/>            Odczyt **float**. |
| [`actual_height`](/slides/python-net/pl/aspose.slides.charts/charttitle/actual_height/) | Określa rzeczywistą wysokość elementu wykresu. Wywołaj metodę IChart.ValidateChartLayout() przed, aby uzyskać rzeczywiste wartości. <br/>            Odczyt **float**. |
| [`chart`](/slides/python-net/pl/aspose.slides.charts/charttitle/chart/) | Zwraca wykres nadrzędny.<br/>            Tylko do odczytu [`IChart`](/slides/python-net/pl/aspose.slides.charts/ichart). |
| [`slide`](/slides/python-net/pl/aspose.slides.charts/charttitle/slide/) |  |
