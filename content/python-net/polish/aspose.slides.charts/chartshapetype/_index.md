## ChartShapeType wyliczenie

Reprezentuje kształt wykresu.

Typ ChartShapeType udostępnia następujące elementy:

## Pola

| Field | Description |
| :- | :- |
| NOT_DEFINED | Kształt wykresu nie jest określony. |
| BOX | Określa, że wykres ma być rysowany w kształcie prostokąta. |
| CONE | Określa, że wykres ma być rysowany jako stożek, przy czym podstawa stożka znajduje się na podłodze, a wierzchołek stożka na szczycie wskaźnika danych. |
| CONE_TO_MAX | Określa, że wykres ma być rysowany przyciętymi stożkami tak, aby wierzchołek stożka odpowiadał maksymalnej wartości danych. |
| CYLINDER | Określa, że wykres ma być rysowany jako cylinder. |
| PYRAMID | Określa, że wykres ma być rysowany jako prostokątna piramida, przy czym podstawa piramidy znajduje się na podłodze, a wierzchołek piramidy na szczycie wskaźnika danych. |
| PYRAMID_TO_MAXIMUM | Określa, że wykres ma być rysowany przyciętymi stożkami tak, aby wierzchołek stożka odpowiadał maksymalnej wartości danych. |
