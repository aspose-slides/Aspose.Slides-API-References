## default_label_shape_type właściwość
Pobiera lub ustawia domyślny typ kształtu dla etykiet danych.
             Zwraca [`ShapeType.NOT_DEFINED`](/slides/python-net/pl/aspose.slides/shapetype/NOT_DEFINED) jeśli nie określono kształtu.


### Uwagi

Ustawienie tej właściwości powoduje również ustawienie [`IDataLabel.label_shape_type`](/slides/python-net/pl/aspose.slides.charts/idatalabel/label_shape_type) właściwości
             dla wszystkich etykiet danych w kolekcji na tę samą wartość.
