## hide(self) {#}
Ukryj etykietę danych domyślnie, ustawiając wszystkie flagi Show*-flags (ShowValue, ...) własności DefaultDataLabelFormat na stan false. 
            IsVisible będzie false po tym.


```python
def hide(self):
    ...
```


### Remarks
Jeśli etykieta danych nie jest widoczna domyślnie (IsVisible jest false), możesz uczynić etykietę danych „visible 
            by default” ustawiając flagi Show*-flags (ShowValue, ...) własności DefaultDataLabelFormat na stan true.
