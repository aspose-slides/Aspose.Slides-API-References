## is_visible właściwość
False oznacza, że etykieta danych nie jest widoczna domyślnie (a więc wszystkie flagi Show*-flags (ShowValue, ...) własności DefaultDataLabelFormat są false).
            Tylko do odczytu **bool**.


### Uwagi

Jeśli etykieta danych jest widoczna domyślnie, możesz ją ukryć domyślnie metodą Hide().
            Jednak jeśli etykieta danych nie jest widoczna domyślnie (IsVisible jest false), możesz ustawić etykietę danych jako „widoczną domyślnie” poprzez ustawienie flag Show*-flags (ShowValue, ...) własności DefaultDataLabelFormat na stan true.
