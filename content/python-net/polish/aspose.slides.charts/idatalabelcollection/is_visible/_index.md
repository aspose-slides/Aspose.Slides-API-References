## is_visible właściwość
False oznacza, że etykieta danych nie jest domyślnie widoczna (a więc wszystkie 
            Show*-flags (ShowValue, ...) własności DefaultDataLabelFormat mają wartość false).
            Tylko do odczytu **bool**.


### Uwagi

Jeśli etykieta danych jest domyślnie widoczna, możesz ukryć ją domyślnie przy użyciu metody Hide().
            Jednak jeśli etykieta danych nie jest domyślnie widoczna (IsVisible jest false), możesz sprawić, że etykieta danych będzie "widoczna 
            domyślnie" ustawiając Show*-flags (ShowValue, ...) własności DefaultDataLabelFormat na stan true.
