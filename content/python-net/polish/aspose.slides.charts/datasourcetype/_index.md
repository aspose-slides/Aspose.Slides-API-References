## DataSourceType enumeracja

Typy źródeł danych.

Typ DataSourceType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| WORKSHEET | Użyj obiektów CellXls do przechowywania XValue, YValue, Value lub BubbleSize punktu danych w arkuszu. |
| STRING_LITERALS | Użyj szybkiego dostępu zmiennej typu string do przechowywania XValue, YValue, Value lub BubbleSize <br/>            punktu danych. Arkusz nie jest używany do przechowywania wartości. |
| DOUBLE_LITERALS | Użyj szybkiego dostępu zmiennej typu double do przechowywania XValue, YValue, Value lub BubbleSize <br/>            punktu danych. Arkusz nie jest używany do przechowywania wartości. |
