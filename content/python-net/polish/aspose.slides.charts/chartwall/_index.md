## ChartWall klasa

Reprezentuje ściany w wykresach 3D.

Typ ChartWall udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`thickness`](/slides/python-net/pl/aspose.slides.charts/chartwall/thickness/) | Zwraca lub ustawia grubość ścian jako procent największego wymiaru objętości wykresu.<br/>            Odczyt/zapis **int**. |
| [`format`](/slides/python-net/pl/aspose.slides.charts/chartwall/format/) | Zwraca wypełnienie ściany, linię, efekt, style 3D.<br/>            Tylko do odczytu [`IFormat`](/slides/python-net/pl/aspose.slides.charts/iformat). |
| [`picture_type`](/slides/python-net/pl/aspose.slides.charts/chartwall/picture_type/) | Zwraca lub ustawia typ obrazu.<br/>            Odczyt/zapis [`PictureType`](/slides/python-net/pl/aspose.slides.charts/picturetype). |
