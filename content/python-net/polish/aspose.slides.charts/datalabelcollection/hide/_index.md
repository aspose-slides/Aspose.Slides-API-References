## hide(self) {#}
Sprawia, że etykieta danych jest domyślnie ukryta, ustawiając wszystkie flagi Show*- (ShowValue, ...) własności DefaultDataLabelFormat na stan false. IsVisible będzie false po tej operacji.

```python
def hide(self):
    ...
```

### Uwagi
Jeśli etykieta danych nie jest domyślnie widoczna (IsVisible jest false), możesz uczynić etykietę danych „widoczną domyślnie”, ustawiając flagi Show*- (ShowValue, ...) własności DefaultDataLabelFormat na stan true.
