## IChartDataCell klasa

Reprezentuje komórkę dla danych wykresu.

Typ IChartDataCell udostępnia następujące członki:

## Właściwości

| Property | Description |
| :- | :- |
| [`row`](/slides/python-net/pl/aspose.slides.charts/ichartdatacell/row/) | Zwraca indeks wiersza worksheet, w którym znajduje się komórka.<br/>            Tylko do odczytu **int**. |
| [`column`](/slides/python-net/pl/aspose.slides.charts/ichartdatacell/column/) | Zwraca indeks kolumny worksheet, w której znajduje się komórka.<br/>            Tylko do odczytu **int**. |
| [`value`](/slides/python-net/pl/aspose.slides.charts/ichartdatacell/value/) | Pobiera lub ustawia wartość komórki.<br/>            Odczyt/zapis **any**. |
| [`formula`](/slides/python-net/pl/aspose.slides.charts/ichartdatacell/formula/) | Pobiera lub ustawia formułę w stylu A1. |
| [`r1c1_formula`](/slides/python-net/pl/aspose.slides.charts/ichartdatacell/r1c1_formula/) | Pobiera lub ustawia formułę w stylu R1C1. |
| [`chart_data_worksheet`](/slides/python-net/pl/aspose.slides.charts/ichartdatacell/chart_data_worksheet/) | Pobiera worksheet.<br/>            Tylko do odczytu [`IChartDataWorksheet`](/slides/python-net/pl/aspose.slides.charts/ichartdataworksheet). |
| [`is_hidden`](/slides/python-net/pl/aspose.slides.charts/ichartdatacell/is_hidden/) | Określa, czy komórka jest ukryta.<br/>            Tylko do odczytu **bool**. |
| [`custom_number_format`](/slides/python-net/pl/aspose.slides.charts/ichartdatacell/custom_number_format/) | Pobiera lub ustawia niestandardowy format wyświetlania liczb i dat. <br/>            Jeśli wartość jest pusta, zostanie użyta wartość PresetNumberFormat.<br/>            Odczyt/zapis **str**. |
| [`preset_number_format`](/slides/python-net/pl/aspose.slides.charts/ichartdatacell/preset_number_format/) | Pobiera lub ustawia wbudowany format wyświetlania liczb i dat. Numer predefiniowany musi być w przedziale [0..22] lub [37..49].<br/>             Odczyt/zapis **int**. |
