## IChartParagraphFormat klasa

Reprezentuje właściwości formatowania akapitu wykresu.

Typ IChartParagraphFormat udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`alignment`](/slides/python-net/pl/aspose.slides.charts/ichartparagraphformat/alignment/) | Zwraca lub ustawia wyrównanie tekstu w akapicie.<br/>            Odczyt/zapis [`TextAlignment`](/slides/python-net/pl/aspose.slides/textalignment). |
| [`space_within`](/slides/python-net/pl/aspose.slides.charts/ichartparagraphformat/space_within/) | Zwraca lub ustawia ilość odstępu pomiędzy bazowymi liniami w akapicie.<br/>            Odczyt/zapis **float**. |
| [`space_before`](/slides/python-net/pl/aspose.slides.charts/ichartparagraphformat/space_before/) | Zwraca lub ustawia ilość odstępu przed pierwszą linią w akapicie.<br/>            Odczyt/zapis **float**. |
| [`space_after`](/slides/python-net/pl/aspose.slides.charts/ichartparagraphformat/space_after/) | Zwraca lub ustawia ilość odstępu po ostatniej linii w akapicie.<br/>            Odczyt/zapis **float**. |
| [`east_asian_line_break`](/slides/python-net/pl/aspose.slides.charts/ichartparagraphformat/east_asian_line_break/) | Określa, czy w akapicie używany jest podział linii wschodnioazjatycki.<br/>            Odczyt/zapis [`NullableBool`](/slides/python-net/pl/aspose.slides/nullablebool). |
| [`right_to_left`](/slides/python-net/pl/aspose.slides.charts/ichartparagraphformat/right_to_left/) | Określa, czy w akapicie używany jest zapis od prawej do lewej.<br/>            Odczyt/zapis [`NullableBool`](/slides/python-net/pl/aspose.slides/nullablebool). |
| [`latin_line_break`](/slides/python-net/pl/aspose.slides.charts/ichartparagraphformat/latin_line_break/) | Określa, czy w akapicie używany jest podział linii łacińskiej.<br/>            Odczyt/zapis [`NullableBool`](/slides/python-net/pl/aspose.slides/nullablebool). |
| [`hanging_punctuation`](/slides/python-net/pl/aspose.slides.charts/ichartparagraphformat/hanging_punctuation/) | Określa, czy w akapicie używana jest zwisająca interpunkcja.<br/>            Odczyt/zapis [`NullableBool`](/slides/python-net/pl/aspose.slides/nullablebool). |
| [`margin_left`](/slides/python-net/pl/aspose.slides.charts/ichartparagraphformat/margin_left/) | Zwraca lub ustawia lewy margines w akapicie.<br/>            Odczyt/zapis **float**. |
| [`margin_right`](/slides/python-net/pl/aspose.slides.charts/ichartparagraphformat/margin_right/) | Zwraca lub ustawia prawy margines w akapicie.<br/>            Odczyt/zapis **float**. |
| [`indent`](/slides/python-net/pl/aspose.slides.charts/ichartparagraphformat/indent/) | Zwraca lub ustawia wcięcie pierwszej linii/zwisające wcięcie akapitu. Zwisające wcięcie może być określone wartościami ujemnymi.<br/>            Odczyt/zapis **float**. |
| [`default_tab_size`](/slides/python-net/pl/aspose.slides.charts/ichartparagraphformat/default_tab_size/) | Zwraca lub ustawia domyślny rozmiar tabulacji.<br/>            Odczyt/zapis **float**. |
| [`tabs`](/slides/python-net/pl/aspose.slides.charts/ichartparagraphformat/tabs/) | Zwraca tabulacje akapitu.<br/>            Tylko do odczytu [`ITabCollection`](/slides/python-net/pl/aspose.slides/itabcollection). |
| [`font_alignment`](/slides/python-net/pl/aspose.slides.charts/ichartparagraphformat/font_alignment/) | Zwraca lub ustawia wyrównanie czcionki w akapicie.<br/>            Odczyt/zapis [`FontAlignment`](/slides/python-net/pl/aspose.slides/fontalignment). |
