## AxisAggregationType enumeracja

Reprezentuje typ agregacji osi kategorii. Używany tylko z seriami Histogram lub HistogramPareto.

Typ AxisAggregationType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| BY_CATEGORY | Agreguj według kategorii |
| AUTOMATIC | Agreguj kategorie automatycznie. |
| BY_BIN_WIDTH | Agreguj kategorie według szerokości przedziału. Property IAxis.BinWidth must be setted. |
| BY_NUMBER_OF_BINS | Agreguj kategorie według liczby przedziałów. Property IAxis.NumberOfBins must be setted. |
