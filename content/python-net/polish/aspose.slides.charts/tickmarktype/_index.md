## TickMarkType enumeracja

Reprezentuje typ znaczników podziałki dla określonej osi.

Typ TickMarkType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| CROSS | Określa, że znaczniki podziałki będą przecinać oś. |
| INSIDE | Określa, że znaczniki podziałki będą wewnątrz obszaru wykresu. |
| NONE | Określa, że nie będzie znaczników podziałki. |
| OUTSIDE | Określa, że znaczniki podziałki będą poza obszarem wykresu. |
