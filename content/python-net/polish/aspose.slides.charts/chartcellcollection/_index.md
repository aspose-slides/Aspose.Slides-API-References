## ChartCellCollection klasa

Reprezentuje kolekcję komórek z danymi.

Typ ChartCellCollection udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`count`](/slides/python-net/pl/aspose.slides.charts/chartcellcollection/count/) | Zwraca liczbę komórek w kolekcji.<br/>            Tylko do odczytu **int**. |

Zwraca komórkę (IChartDataCell) według indeksu.

## Indeksator

| Nazwa | Opis |
| :- | :- |
| [`[index]`](/slides/python-net/pl/aspose.slides.charts/chartcellcollection/__getitem__/) | Indeks komórki. |

| Metoda | Opis |
| :- | :- |
| [`add(self, cell)`](/slides/python-net/pl/aspose.slides.charts/chartcellcollection/add/#ichartdatacell) | Dodaje nową komórkę do kolekcji. |
