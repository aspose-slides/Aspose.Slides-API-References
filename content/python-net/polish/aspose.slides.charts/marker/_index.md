## Marker klasa

Reprezentuje znacznik cherty.

Typ Marker udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`symbol`](/slides/python-net/pl/aspose.slides.charts/marker/symbol/) | Reprezentuje styl znacznika w wykresie liniowym, wykresie punktowym lub wykresie radarowym.<br/>            Odczyt/zapis [`MarkerStyleType`](/slides/python-net/pl/aspose.slides.charts/markerstyletype). |
| [`format`](/slides/python-net/pl/aspose.slides.charts/marker/format/) | Otrzymuje lub ustawia wypełnienie znacznika.<br/>            Tylko do odczytu [`IFormat`](/slides/python-net/pl/aspose.slides.charts/iformat). |
| [`size`](/slides/python-net/pl/aspose.slides.charts/marker/size/) | Reprezentuje rozmiar znacznika w wykresie liniowym, wykresie punktowym lub wykresie radarowym.<br/>            Odczyt/zapis **int**. |
