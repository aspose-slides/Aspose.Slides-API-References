## ParentLabelLayoutType wyliczenie

Reprezentuje układ etykiet danych kategorii. Używany wyłącznie w serii Treemap.

Typ ParentLabelLayoutType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| BANNER | Określa, że etykiety nadrzędnych kategorii są wyświetlane jako baner |
| NONE | Określa, że etykiety nadrzędnych kategorii nie są rysowane |
| OVERLAPPING | Określa, że etykiety nadrzędnych kategorii są wyświetlane jako nakładające się |
