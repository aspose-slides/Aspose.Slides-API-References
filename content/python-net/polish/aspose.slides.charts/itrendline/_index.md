## ITrendline klasa

Klasa reprezentuje linię trendu serii wykresu

Typ ITrendline udostępnia następujące elementy:

## Właściwości

| Property | Description |
| :- | :- |
| [`trendline_name`](/slides/python-net/pl/aspose.slides.charts/itrendline/trendline_name/) | Pobiera lub ustawia nazwę linii trendu.<br/>            Odczyt/zapis **str**. |
| [`trendline_type`](/slides/python-net/pl/aspose.slides.charts/itrendline/trendline_type/) | Pobiera lub ustawia typ linii trendu. <br/>            Odczyt/zapis [`ITrendline.trendline_type`](/slides/python-net/pl/aspose.slides.charts/itrendline/trendline_type). |
| [`format`](/slides/python-net/pl/aspose.slides.charts/itrendline/format/) | Reprezentuje format linii trendu.<br/>            Odczyt/zapis [`IFormat`](/slides/python-net/pl/aspose.slides.charts/iformat). |
| [`backward`](/slides/python-net/pl/aspose.slides.charts/itrendline/backward/) | Określa liczbę kategorii (lub jednostek na wykresie punktowym), które linia trendu rozciąga przed<br/>            danymi serii, które są trendowane. Na wykresach punktowych i niepunktowych wartość może być dowolną nieujemną<br/>            wartością.<br/>            Odczyt/zapis **float**. |
| [`forward`](/slides/python-net/pl/aspose.slides.charts/itrendline/forward/) | Określa liczbę kategorii (lub jednostek na wykresie punktowym), które linia trendu rozciąga po<br/>            danych serii, które są trendowane. Na wykresach punktowych i niepunktowych wartość może być dowolną nieujemną<br/>            wartością.<br/>            Odczyt/zapis **float**. |
| [`intercept`](/slides/python-net/pl/aspose.slides.charts/itrendline/intercept/) | Określa wartość, w której linia trendu przecięta zostanie z osią y. Ta właściwość jest obsługiwana tylko<br/>            gdy typ linii trendu to exp, linear lub poly.<br/>            Odczyt/zapis **float**. |
| [`display_equation`](/slides/python-net/pl/aspose.slides.charts/itrendline/display_equation/) | Określa, że równanie linii trendu jest wyświetlane na wykresie (w tej samej etykiecie co wartość R-kwadrat).<br/>            Odczyt/zapis **bool**. |
| [`order`](/slides/python-net/pl/aspose.slides.charts/itrendline/order/) | Określa stopień wielomianu linii trendu. Jest ignorowane dla innych typów linii trendu. Wartość musi mieścić się w przedziale od 2 do 6.<br/>            Odczyt/zapis **int**. |
| [`period`](/slides/python-net/pl/aspose.slides.charts/itrendline/period/) | Określa okres linii trendu dla linii trendu średniej kroczącej. Jest ignorowane dla innych wariantów linii trendu.<br/>            Wartość musi mieścić się w przedziale od 2 do 255.<br/>            Odczyt/zapis **int**. |
| [`display_r_squared_value`](/slides/python-net/pl/aspose.slides.charts/itrendline/display_r_squared_value/) | Określa, że wartość R-kwadrat linii trendu jest wyświetlana na wykresie (w tej samej etykiecie co równanie).<br/>            Odczyt/zapis **bool**. |
| [`related_legend_entry`](/slides/python-net/pl/aspose.slides.charts/itrendline/related_legend_entry/) | Reprezentuje pozycję legendy związaną z tą linią trendu<br/>            Tylko do odczytu [`ILegendEntryProperties`](/slides/python-net/pl/aspose.slides.charts/ilegendentryproperties). |
| [`text_frame_for_overriding`](/slides/python-net/pl/aspose.slides.charts/itrendline/text_frame_for_overriding/) |  |
| [`text_format`](/slides/python-net/pl/aspose.slides.charts/itrendline/text_format/) |  |
