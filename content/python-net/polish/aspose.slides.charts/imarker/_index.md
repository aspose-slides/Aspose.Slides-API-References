## IMarker klasa

Reprezentuje znacznik wykresu.

Typ IMarker udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`symbol`](/slides/python-net/pl/aspose.slides.charts/imarker/symbol/) | Reprezentuje styl znacznika w wykresie liniowym, wykresie punktowym lub wykresie radarowym.<br/>            Odczyt/zapis [`MarkerStyleType`](/slides/python-net/pl/aspose.slides.charts/markerstyletype). |
| [`format`](/slides/python-net/pl/aspose.slides.charts/imarker/format/) | Pobiera wypełnienie znacznika.<br/>            Tylko do odczytu [`IFormat`](/slides/python-net/pl/aspose.slides.charts/iformat). |
| [`size`](/slides/python-net/pl/aspose.slides.charts/imarker/size/) | Reprezentuje rozmiar znacznika w wykresie liniowym, wykresie punktowym lub wykresie radarowym.<br/>            Odczyt/zapis **int**. |
