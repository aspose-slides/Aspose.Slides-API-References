## Klasa DataTable

Reprezentuje właściwości tabeli danych.

Typ DataTable udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`format`](/slides/python-net/pl/aspose.slides.charts/datatable/format/) | Zwraca style linii, wypełnienia i efektu obiektu.<br/> Tylko do odczytu [`IFormat`](/slides/python-net/pl/aspose.slides.charts/iformat). |
| [`has_border_horizontal`](/slides/python-net/pl/aspose.slides.charts/datatable/has_border_horizontal/) | Prawda, jeśli tabela danych wykresu ma poziome obramowania komórek.<br/> Odczyt/zapis **bool**. |
| [`has_border_outline`](/slides/python-net/pl/aspose.slides.charts/datatable/has_border_outline/) | Prawda, jeśli tabela danych wykresu ma obramowanie zewnętrzne.<br/> Odczyt/zapis **bool**. |
| [`has_border_vertical`](/slides/python-net/pl/aspose.slides.charts/datatable/has_border_vertical/) | Prawda, jeśli tabela danych wykresu ma pionowe obramowania komórek.<br/> Odczyt/zapis **bool**. |
| [`show_legend_key`](/slides/python-net/pl/aspose.slides.charts/datatable/show_legend_key/) | Prawda, jeśli klucz legendy etykiety danych jest widoczny.<br/> Odczyt/zapis **bool**. |
| [`chart`](/slides/python-net/pl/aspose.slides.charts/datatable/chart/) | Zwraca wykres.<br/> Tylko do odczytu [`IChart`](/slides/python-net/pl/aspose.slides.charts/ichart). |
| [`text_format`](/slides/python-net/pl/aspose.slides.charts/datatable/text_format/) | Zwraca format tekstu.<br/> Tylko do odczytu [`IChartTextFormat`](/slides/python-net/pl/aspose.slides.charts/icharttextformat). |
| [`slide`](/slides/python-net/pl/aspose.slides.charts/datatable/slide/) |  |
| [`presentation`](/slides/python-net/pl/aspose.slides.charts/datatable/presentation/) |  |
