## ChartType wyliczenie

Reprezentuje typ wykresu.

Typ ChartType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| CLUSTERED_COLUMN | Reprezentuje wykres kolumnowy grupowany. |
| STACKED_COLUMN | Reprezentuje wykres kolumnowy skumulowany. |
| PERCENTS_STACKED_COLUMN | Reprezentuje wykres kolumnowy skumulowany 100%. |
| CLUSTERED_COLUMN_3D | Reprezentuje trójwymiarowy wykres kolumnowy grupowany. |
| STACKED_COLUMN_3D | Reprezentuje trójwymiarowy wykres kolumnowy skumulowany. |
| PERCENTS_STACKED_COLUMN_3D | Reprezentuje trójwymiarowy wykres kolumnowy skumulowany 100%. |
| COLUMN_3D | Reprezentuje trójwymiarowy wykres kolumnowy. |
| CLUSTERED_CYLINDER | Reprezentuje wykres walcowy grupowany. |
| STACKED_CYLINDER | Reprezentuje wykres walcowy skumulowany. |
| PERCENTS_STACKED_CYLINDER | Reprezentuje wykres walcowy skumulowany 100%. |
| CYLINDER_3D | Reprezentuje trójwymiarowy wykres walcowy. |
| CLUSTERED_CONE | Reprezentuje wykres stożkowy grupowany. |
| STACKED_CONE | Reprezentuje wykres stożkowy skumulowany. |
| PERCENTS_STACKED_CONE | Reprezentuje wykres stożkowy skumulowany 100%. |
| CONE_3D | Reprezentuje trójwymiarowy wykres stożkowy. |
| CLUSTERED_PYRAMID | Reprezentuje wykres piramidalny grupowany. |
| STACKED_PYRAMID | Reprezentuje wykres piramidalny skumulowany. |
| PERCENTS_STACKED_PYRAMID | Reprezentuje wykres piramidalny skumulowany 100%. |
| PYRAMID_3D | Reprezentuje trójwymiarowy wykres piramidalny. |
| LINE | Reprezentuje wykres liniowy. |
| STACKED_LINE | Reprezentuje wykres liniowy skumulowany. |
| PERCENTS_STACKED_LINE | Reprezentuje wykres liniowy skumulowany 100%. |
| LINE_WITH_MARKERS | Reprezentuje wykres liniowy z znacznikami danych. |
| STACKED_LINE_WITH_MARKERS | Reprezentuje wykres liniowy skumulowany z znacznikami danych. |
| PERCENTS_STACKED_LINE_WITH_MARKERS | Reprezentuje wykres liniowy skumulowany 100% z znacznikami danych. |
| LINE_3D | Reprezentuje trójwymiarowy wykres liniowy. |
| PIE | Reprezentuje wykres kołowy. |
| PIE_3D | Reprezentuje trójwymiarowy wykres kołowy. |
| PIE_OF_PIE | Reprezentuje wykres kołowy z podziałem kołowym. |
| EXPLODED_PIE | Reprezentuje wykres kołowy rozwinięty. |
| EXPLODED_PIE_3D | Reprezentuje trójwymiarowy wykres kołowy rozwinięty. |
| BAR_OF_PIE | Reprezentuje wykres słupkowy z wykresem kołowym. |
| PERCENTS_STACKED_BAR | Reprezentuje wykres słupkowy skumulowany 100%. |
| CLUSTERED_BAR_3D | Reprezentuje trójwymiarowy wykres słupkowy grupowany. |
| CLUSTERED_BAR | Reprezentuje wykres słupkowy grupowany. |
| STACKED_BAR | Reprezentuje wykres słupkowy skumulowany. |
| STACKED_BAR_3D | Reprezentuje trójwymiarowy wykres słupkowy skumulowany. |
| PERCENTS_STACKED_BAR_3D | Reprezentuje trójwymiarowy wykres słupkowy skumulowany 100%. |
| CLUSTERED_HORIZONTAL_CYLINDER | Reprezentuje poziomy wykres walcowy grupowany. |
| STACKED_HORIZONTAL_CYLINDER | Reprezentuje poziomy wykres walcowy skumulowany. |
| PERCENTS_STACKED_HORIZONTAL_CYLINDER | Reprezentuje poziomy wykres walcowy skumulowany 100%. |
| CLUSTERED_HORIZONTAL_CONE | Reprezentuje poziomy wykres stożkowy grupowany. |
| STACKED_HORIZONTAL_CONE | Reprezentuje poziomy wykres stożkowy skumulowany. |
| PERCENTS_STACKED_HORIZONTAL_CONE | Reprezentuje poziomy wykres stożkowy skumulowany 100%. |
| CLUSTERED_HORIZONTAL_PYRAMID | Reprezentuje poziomy wykres piramidalny grupowany. |
| STACKED_HORIZONTAL_PYRAMID | Reprezentuje poziomy wykres piramidalny skumulowany. |
| PERCENTS_STACKED_HORIZONTAL_PYRAMID | Reprezentuje poziomy wykres piramidalny skumulowany 100%. |
| AREA | Reprezentuje wykres obszarowy. |
| STACKED_AREA | Reprezentuje wykres obszarowy skumulowany. |
| PERCENTS_STACKED_AREA | Reprezentuje wykres obszarowy skumulowany 100%. |
| AREA_3D | Reprezentuje trójwymiarowy wykres obszarowy. |
| STACKED_AREA_3D | Reprezentuje trójwymiarowy wykres obszarowy skumulowany. |
| PERCENTS_STACKED_AREA_3D | Reprezentuje trójwymiarowy wykres obszarowy skumulowany 100%. |
| SCATTER_WITH_MARKERS | Reprezentuje wykres punktowy z znacznikami danych. |
| SCATTER_WITH_SMOOTH_LINES_AND_MARKERS | Reprezentuje wykres punktowy połączony krzywymi, z znacznikami danych. |
| SCATTER_WITH_SMOOTH_LINES | Reprezentuje wykres punktowy połączony krzywymi, bez znaczników danych. |
| SCATTER_WITH_STRAIGHT_LINES_AND_MARKERS | Reprezentuje wykres punktowy połączony liniami, z znacznikami danych. |
| SCATTER_WITH_STRAIGHT_LINES | Reprezentuje wykres punktowy połączony liniami, bez znaczników danych. |
| HIGH_LOW_CLOSE | Reprezentuje wykres giełdowy High-Low-Close. |
| OPEN_HIGH_LOW_CLOSE | Reprezentuje wykres giełdowy Open-High-Low-Close. |
| VOLUME_HIGH_LOW_CLOSE | Reprezentuje wykres wolumenu High-Low-Close. |
| VOLUME_OPEN_HIGH_LOW_CLOSE | Reprezentuje wykres wolumenu Open-High-Low-Close. |
| SURFACE_3D | Reprezentuje trójwymiarowy wykres powierzchniowy. |
| WIREFRAME_SURFACE_3D | Reprezentuje trójwymiarowy wykres powierzchniowy siatki. |
| CONTOUR | Reprezentuje wykres konturowy. |
| WIREFRAME_CONTOUR | Reprezentuje wykres konturowy siatki. |
| DOUGHNUT | Reprezentuje wykres pierścieniowy. |
| EXPLODED_DOUGHNUT | Reprezentuje wykres pierścieniowy rozwinięty. |
| BUBBLE | Reprezentuje wykres bąbelkowy. |
| BUBBLE_WITH_3D | Reprezentuje trójwymiarowy wykres bąbelkowy. |
| RADAR | Reprezentuje wykres radarowy. |
| RADAR_WITH_MARKERS | Reprezentuje wykres radarowy z znacznikami danych. |
| FILLED_RADAR | Reprezentuje wypełniony wykres radarowy. |
| SERIES_OF_MIXED_TYPES | Ta wartość może być zwrócona wyłącznie przez własność ChartEx.Type. <br/>            Oznacza to, że wykres ma serie o mieszanych typach. |
| TREEMAP | Reprezentuje wykres mapy drzewa. |
| SUNBURST | Reprezentuje wykres promieniowy. |
| HISTOGRAM | Reprezentuje wykres histogramu. |
| PARETO_LINE | Reprezentuje serię linii Pareto (wykres histogramu Pareto). |
| BOX_AND_WHISKER | Reprezentuje wykres BoxAndWhisker. |
| WATERFALL | Reprezentuje wykres wodospadowy. |
| FUNNEL | Reprezentuje wykres lejkowy. |
| MAP | Reprezentuje wykres mapowy. |
