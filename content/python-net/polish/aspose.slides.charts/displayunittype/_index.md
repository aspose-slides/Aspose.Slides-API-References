## DisplayUnitType enumeracja

Określa wielokrotność wyświetlanych danych.

Typ DisplayUnitType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| NONE | Wartości będą wyświetlane bez zmian. |
| HUNDREDS | Określa, że wartości na wykresie będą dzielone przez 100. |
| THOUSANDS | Określa, że wartości na wykresie będą dzielone przez 1,000. |
| TEN_THOUSANDS | Określa, że wartości na wykresie będą dzielone przez 10,000. |
| HUNDRED_THOUSANDS | Określa, że wartości na wykresie będą dzielone przez 100,000. |
| MILLIONS | Określa, że wartości na wykresie będą dzielone przez 1,000,000. |
| TEN_MILLIONS | Określa, że wartości na wykresie będą dzielone przez 10,000,000. |
| HUNDRED_MILLIONS | Określa, że wartości na wykresie będą dzielone przez 100,000,000. |
| BILLIONS | Określa, że wartości na wykresie będą dzielone przez 1,000,000,000. |
| TRILLIONS | Określa, że wartości na wykresie będą dzielone przez 1,000,000,000,000. |
| CUSTOM_VALUE | Określa, że wartości na wykresie będą dzielone przez wartość niestandardową. |
