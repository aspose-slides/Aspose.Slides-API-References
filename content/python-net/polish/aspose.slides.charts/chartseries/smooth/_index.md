## smooth właściwość
Reprezentuje wygładzanie krzywej. True jeśli wygładzanie krzywej jest włączone dla wykresu liniowego lub wykresu punktowego.
            Obowiązuje wyłącznie dla wykresów liniowych oraz wykresów punktowych połączonych liniami.
            Odczyt/zapis **bool**.
