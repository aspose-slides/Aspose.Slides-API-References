## bubble_size_scale właściwość
Określa współczynnik skalowania wykresu bąbelkowego (może wynosić 
            od 0 do 300 procent domyślnego rozmiaru).
            Jest to właściwość nie tylko tej serii, ale wszystkich serii grupy serii nadrzędnej – jest to projekcja odpowiedniej właściwości grupy. Dlatego ta właściwość jest tylko do odczytu.
            Użyj właściwości ParentSeriesGroup, aby uzyskać dostęp do grupy serii nadrzędnej.
            Użyj właściwości ParentSeriesGroup.BubbleSizeScale z dostępem odczyt/zapis, aby zmienić wartość.


### Uwagi

Jest to projekcja właściwości ParentSeriesGroup.BubbleSizeScale.
