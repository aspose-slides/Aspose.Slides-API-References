## data_source_type_for_x_plus_values właściwość
Specifies whether AsCell or AsLiteralString or AsLiteralDouble property 
            jest aktualna w obiekcie właściwości XPlus punktów danych dla niestandardowych wartości słupków błędów. In other words it specifies 
            typu wartości właściwości ChartDataPoint.ErrorBarsCustomValues.XPlus.Data. 
            Odczyt/zapis [`DataSourceType`](/slides/python-net/pl/aspose.slides.charts/datasourcetype).
