## AxesManager class

Zapewnia dostęp do osi wykresu.

Typ AxesManager udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`horizontal_axis`](/slides/python-net/pl/aspose.slides.charts/axesmanager/horizontal_axis/) | Pobiera poziomą oś wykresu.<br/>             Tylko do odczytu [`IAxis`](/slides/python-net/pl/aspose.slides.charts/iaxis). |
| [`secondary_horizontal_axis`](/slides/python-net/pl/aspose.slides.charts/axesmanager/secondary_horizontal_axis/) | Pobiera drugą poziomą oś wykresu.<br/>             Tylko do odczytu [`IAxis`](/slides/python-net/pl/aspose.slides.charts/iaxis). |
| [`vertical_axis`](/slides/python-net/pl/aspose.slides.charts/axesmanager/vertical_axis/) | Pobiera pionową oś wykresu.<br/>             Tylko do odczytu [`IAxis`](/slides/python-net/pl/aspose.slides.charts/iaxis). |
| [`secondary_vertical_axis`](/slides/python-net/pl/aspose.slides.charts/axesmanager/secondary_vertical_axis/) | Pobiera drugą pionową oś wykresu.<br/>             Tylko do odczytu [`IAxis`](/slides/python-net/pl/aspose.slides.charts/iaxis). |
| [`series_axis`](/slides/python-net/pl/aspose.slides.charts/axesmanager/series_axis/) | Pobiera oś serii wykresu.<br/>             Tylko do odczytu [`IAxis`](/slides/python-net/pl/aspose.slides.charts/iaxis). |
