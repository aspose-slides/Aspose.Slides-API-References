## IChartDataPointCollection klasa

Reprezentuje kolekcję punktów danych serii.

Typ IChartDataPointCollection udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`data_source_type_for_x_values`](/slides/python-net/pl/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_x_values/) | Określa, czy właściwość AsCell lub AsLiteralString lub AsLiteralDouble jest aktualna w obiekcie właściwości XValue punktów danych.<br/>            Innymi słowy określa typ wartości właściwości ChartDataPointEx.XValue.Data.<br/>            Odczyt/zapis [`DataSourceType`](/slides/python-net/pl/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_y_values`](/slides/python-net/pl/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_y_values/) | Określa, czy właściwość AsCell lub AsLiteralString lub AsLiteralDouble jest aktualna w obiekcie właściwości YValue punktów danych.<br/>            Innymi słowy określa typ wartości właściwości ChartDataPointEx.YValue.Data.<br/>            Odczyt/zapis [`DataSourceType`](/slides/python-net/pl/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_bubble_sizes`](/slides/python-net/pl/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_bubble_sizes/) | Określa, czy właściwość AsCell lub AsLiteralString lub AsLiteralDouble jest aktualna w obiekcie właściwości BubbleSize punktów danych.<br/>            Innymi słowy określa typ wartości właściwości ChartDataPointEx.BubbleSize.Data.<br/>            Odczyt/zapis [`DataSourceType`](/slides/python-net/pl/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_values`](/slides/python-net/pl/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_values/) | Określa, czy właściwość AsCell lub AsLiteralString lub AsLiteralDouble jest aktualna w obiekcie właściwości Value punktów danych.<br/>            Innymi słowy określa typ wartości właściwości ChartDataPoint.Value.Data.<br/>            Odczyt/zapis [`DataSourceType`](/slides/python-net/pl/aspose.slides.charts/datasourcetype). |
