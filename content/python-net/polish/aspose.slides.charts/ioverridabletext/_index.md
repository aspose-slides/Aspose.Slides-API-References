## IOverridableText klasa

Reprezentuje tekst, który można nadpisać w wykresie.

Typ IOverridableText udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`text_frame_for_overriding`](/slides/python-net/pl/aspose.slides.charts/ioverridabletext/text_frame_for_overriding/) | Może zawierać bogato sformatowany tekst. Jeśli ta właściwość nie jest None, to ta <br/>            sformatowana wartość tekstu nadpisuje automatycznie generowany tekst.<br/>            Automatycznie generowany tekst jest właściwością domyślną etykiety danych, wyświetlanej <br/>            etykiety jednostki osi wartości, tytułu osi, tytułu wykresu, etykiety linii trendu.<br/>            Automatycznie generowany tekst jest formatowany przy użyciu właściwości IFormattedTextContainer.TextFormat.<br/>            Tylko do odczytu [`ITextFrame`](/slides/python-net/pl/aspose.slides/itextframe). |
| [`text_format`](/slides/python-net/pl/aspose.slides.charts/ioverridabletext/text_format/) |  |
