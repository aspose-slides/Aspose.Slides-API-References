## TimeUnitType enumeracja

Reprezentuje jednostkę bazową dla osi kategorii

Typ TimeUnitType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| NONE | Wartości będą wyświetlane tak, jak są. |
| DAYS | Określa, że dane wykresu będą wyświetlane w dniach. |
| MONTHS | Określa, że dane wykresu będą wyświetlane w miesiącach. |
| YEARS | Określa, że dane wykresu będą wyświetlane w latach. |
