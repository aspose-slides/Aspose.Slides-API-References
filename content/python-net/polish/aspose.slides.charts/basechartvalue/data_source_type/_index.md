## data_source_type property
Określa, czy AsCell, AsCells, AsLiteralString lub AsLiteralDouble 
            właściwość jest aktualna w klasach pochodnych. Innymi słowy określa typ 
            wartości właściwości Data.
            Odczyt/zapis [`DataSourceType`](/slides/python-net/pl/aspose.slides.charts/datasourcetype).

### Remarks

Dla punktów w ChartDataPointCollection ta właściwość jest tylko do odczytu. 
            W takim przypadku, aby zmienić wartość tej właściwości, możesz użyć jednej z 
            ChartDataPointCollection.DataSourceTypeFor<...> właściwości.
