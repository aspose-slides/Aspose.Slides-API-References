## Legend klasa

Reprezentuje właściwości legendy wykresu.

Typ Legend udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`x`](/slides/python-net/pl/aspose.slides.charts/legend/x/) | Zwraca lub ustawia współrzędną x legendy jako ułamek szerokości wykresu.<br/>            Read/write **float**. |
| [`y`](/slides/python-net/pl/aspose.slides.charts/legend/y/) | Zwraca lub ustawia współrzędną y legendy jako ułamek wysokości wykresu.<br/>            Read/write **float**. |
| [`width`](/slides/python-net/pl/aspose.slides.charts/legend/width/) | Zwraca lub ustawia szerokość legendy jako ułamek szerokości wykresu.<br/>            Read/write **float**. |
| [`height`](/slides/python-net/pl/aspose.slides.charts/legend/height/) | Zwraca lub ustawia wysokość legendy jako ułamek wysokości wykresu.<br/>            Read/write **float**. |
| [`right`](/slides/python-net/pl/aspose.slides.charts/legend/right/) | Prawa.<br/>            Read-only **float**. |
| [`bottom`](/slides/python-net/pl/aspose.slides.charts/legend/bottom/) | Dolna.<br/>            Read-only **float**. |
| [`overlay`](/slides/python-net/pl/aspose.slides.charts/legend/overlay/) | Określa, czy inne elementy wykresu mogą zachodzić na legendę.<br/>            Read/write **bool**. |
| [`text_format`](/slides/python-net/pl/aspose.slides.charts/legend/text_format/) | Format tekstu.<br/>            Read-only [`IChartTextFormat`](/slides/python-net/pl/aspose.slides.charts/icharttextformat). |
| [`position`](/slides/python-net/pl/aspose.slides.charts/legend/position/) | Określa pozycję legendy na wykresie.<br/>            Nie-NaN wartości właściwości X, Y, Width, Heigt nadpisują działanie tej właściwości.<br/>            Read/write [`LegendPositionType`](/slides/python-net/pl/aspose.slides.charts/legendpositiontype). |
| [`format`](/slides/python-net/pl/aspose.slides.charts/legend/format/) | Zwraca format legendy.<br/>            Read-only [`IFormat`](/slides/python-net/pl/aspose.slides.charts/iformat). |
| [`chart`](/slides/python-net/pl/aspose.slides.charts/legend/chart/) | Zwraca wykres.<br/>            Read-only [`IChart`](/slides/python-net/pl/aspose.slides.charts/ichart). |
| [`entries`](/slides/python-net/pl/aspose.slides.charts/legend/entries/) | Pobiera wpisy legendy.<br/>            Read-only [`ILegendEntryCollection`](/slides/python-net/pl/aspose.slides.charts/ilegendentrycollection). |
| [`actual_x`](/slides/python-net/pl/aspose.slides.charts/legend/actual_x/) | Określa rzeczywistą pozycję x (lewy) elementu wykresu względem lewego górnego rogu wykresu.<br/>            Wywołaj metodę IChart.ValidateChartLayout() przed uzyskaniem rzeczywistych wartości. <br/>            Read **float**. |
| [`actual_y`](/slides/python-net/pl/aspose.slides.charts/legend/actual_y/) | Określa rzeczywistą górną pozycję elementu wykresu względem lewego górnego rogu wykresu.<br/>            Wywołaj metodę IChart.ValidateChartLayout() przed uzyskaniem rzeczywistych wartości. <br/>            Read **float**. |
| [`actual_width`](/slides/python-net/pl/aspose.slides.charts/legend/actual_width/) | Określa rzeczywistą szerokość elementu wykresu. Wywołaj metodę IChart.ValidateChartLayout() przed uzyskaniem rzeczywistych wartości. <br/>            Read **float**. |
| [`actual_height`](/slides/python-net/pl/aspose.slides.charts/legend/actual_height/) | Określa rzeczywistą wysokość elementu wykresu. Wywołaj metodę IChart.ValidateChartLayout() przed uzyskaniem rzeczywistych wartości. <br/>            Read **float**. |
