## is_chart_type_line(chart_type) {#charttype}
Zwraca true, jeśli chartType jest jednym z podtypów typu Line.
            Zestaw podtypów odpowiada odpowiedniemu zestawowi w PowerPoint (zobacz "Change Chart Type" dialog in PowerPoint):

            [`ChartType.PERCENTS_STACKED_LINE_WITH_MARKERS`](/slides/python-net/pl/aspose.slides.charts/charttype/PERCENTS_STACKED_LINE_WITH_MARKERS),

            [`ChartType.STACKED_LINE_WITH_MARKERS`](/slides/python-net/pl/aspose.slides.charts/charttype/STACKED_LINE_WITH_MARKERS),
