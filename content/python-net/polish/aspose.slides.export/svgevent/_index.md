## Wyliczenie SvgEvent

Reprezentuje opcje dla kształtu SVG.

Typ SvgEvent udostępnia następujące człony:

## Pola

| Pole | Opis |
| :- | :- |
| ON_FOCUS_IN | Występuje, gdy element otrzymuje fokus, np. gdy tekst zostaje zaznaczony. |
| ON_FOCUS_OUT | Występuje, gdy element traci fokus, np. gdy tekst zostaje odznaczony. |
| ON_ACTIVATE | Występuje, gdy element jest aktywowany, np. poprzez kliknięcie myszą lub naciśnięcie klawisza. |
| ON_CLICK | Występuje, gdy przycisk urządzenia wskazującego jest kliknięty na elemencie. |
| ON_MOUSE_DOWN | Występuje, gdy przycisk urządzenia wskazującego jest przyciśnięty na elemencie. |
| ON_MOUSE_UP | Występuje, gdy przycisk urządzenia wskazującego jest zwolniony na elemencie. |
| ON_MOUSE_OVER | Występuje, gdy urządzenie wskazujące zostaje przesunięte na element. |
| ON_MOUSE_MOVE | Występuje, gdy urządzenie wskazujące jest przesuwane, będąc nad elementem. |
| ON_MOUSE_OUT | Występuje, gdy urządzenie wskazujące zostaje przesunięte z elementu. |
| ON_LOAD | Występuje, gdy agent użytkownika w pełni przetworzy element oraz jego potomki i wszystkie odwołane zasoby niezbędne do jego renderowania. |
| ON_UNLOAD | Występuje, gdy implementacja DOM usuwa dokument z okna lub ramki. Dotyczy tylko najbardziej zewnętrznych elementów svg. |
| ON_ABORT | Występuje, gdy ładowanie strony zostaje przerwane przed pełnym załadowaniem elementu. |
| ON_ERROR | Występuje, gdy element nie ładuje się prawidłowo lub gdy wystąpi błąd podczas wykonywania skryptu. |
| ON_RESIZE | Występuje, gdy widok dokumentu jest zmieniany rozmiarowo. Dotyczy tylko najbardziej zewnętrznych elementów svg. |
| ON_SCROLL | Występuje, gdy widok dokumentu jest przesuwany wzdłuż osi X, Y lub obu. Dotyczy tylko najbardziej zewnętrznych elementów svg. |
| ON_ZOOM | Występuje, gdy poziom powiększenia widoku dokumentu jest zmieniany. Dotyczy tylko najbardziej zewnętrznych elementów svg. |
| ON_BEGIN | Występuje, gdy element animacji zaczyna się. |
| ON_END | Występuje, gdy element animacji kończy się. |
| ON_REPEAT | Występuje, gdy element animacji powtarza się. |
