## IGifOptions klasa

Reprezentuje opcje eksportu GIF.

Typ IGifOptions udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`frame_size`](/slides/python-net/pl/aspose.slides.export/igifoptions/frame_size/) | Pobiera lub ustawia rozmiar klatki. |
| [`export_hidden_slides`](/slides/python-net/pl/aspose.slides.export/igifoptions/export_hidden_slides/) | Określa, czy ukryte slajdy będą eksportowane.<br/>            Domyślna wartość to false. |
| [`transition_fps`](/slides/python-net/pl/aspose.slides.export/igifoptions/transition_fps/) | Pobiera lub ustawia FPS przejścia [frames/sec]<br/>            Domyślna wartość to 25. |
| [`default_delay`](/slides/python-net/pl/aspose.slides.export/igifoptions/default_delay/) | Pobiera lub ustawia domyślny czas opóźnienia [ms]. Ta wartość zostanie użyta, jeśli [`ISlideShowTransition.advance_after_time`](/slides/python-net/pl/aspose.slides/islideshowtransition/advance_after_time) nie jest ustawione.<br/>            Domyślna wartość to 1000. |
