## skip_java_script_links właściwość
Określa, czy pomijać hiperlinki z wywołaniami JavaScript podczas zapisywania prezentacji. 
            Odczyt/zapis **bool**. Domyślna wartość to **false** .


### Uwagi

Gdy ta właściwość jest ustawiona na **true**, hiperlinki z wywołaniami JavaScript będą ignorowane podczas zapisywania.


Gdy ta właściwość jest ustawiona na **false**, wszystkie hiperlinki zostaną zapisane.
