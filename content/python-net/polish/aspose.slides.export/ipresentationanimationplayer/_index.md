## IPresentationAnimationPlayer klasa

Reprezentuje odtwarzacz animacji.

Animacje generowane przez [`PresentationAnimationsGenerator`](/slides/python-net/pl/aspose.slides.export/presentationanimationsgenerator) za pośrednictwem zdarzenia **NewAnimation**.

Typ IPresentationAnimationPlayer udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`duration`](/slides/python-net/pl/aspose.slides.export/ipresentationanimationplayer/duration/) | Pobierz czas trwania animacji [ms] |

## Metody

| Metoda | Opis |
| :- | :- |
| [`set_time_position(self, time)`](/slides/python-net/pl/aspose.slides.export/ipresentationanimationplayer/set_time_position/#float) | Ustaw pozycję czasu animacji w ramach [`IPresentationAnimationPlayer.duration`](/slides/python-net/pl/aspose.slides.export/ipresentationanimationplayer/duration). |
| [`get_frame(self)`](/slides/python-net/pl/aspose.slides.export/ipresentationanimationplayer/get_frame/#) | Pobierz klatkę dla bieżącej pozycji czasu wcześniej ustawionej metodą **Aspose.Slides.Export.IPresentationAnimationPlayer.SetTimePosition(Syste**. |
