## IHtmlGenerator klasa

Generator HTML.

Typ IHtmlGenerator udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`slide_image_size`](/slides/python-net/pl/aspose.slides.export/ihtmlgenerator/slide_image_size/) | Zwraca rozmiar obrazu slajdu.<br/>            Tylko do odczytu **aspose.slides.SizeF**. |
| [`slide_image_size_unit`](/slides/python-net/pl/aspose.slides.export/ihtmlgenerator/slide_image_size_unit/) | Zwraca jednostkę, w której określono rozmiar obrazu slajdu.<br/>            Tylko do odczytu [`SvgCoordinateUnit`](/slides/python-net/pl/aspose.slides.export/svgcoordinateunit). |
| [`slide_image_size_unit_code`](/slides/python-net/pl/aspose.slides.export/ihtmlgenerator/slide_image_size_unit_code/) | Zwraca kod CSS jednostki, w której określono rozmiar obrazu slajdu.<br/>            Tylko do odczytu **str**. |
| [`previous_slide_index`](/slides/python-net/pl/aspose.slides.export/ihtmlgenerator/previous_slide_index/) | Zwraca indeks poprzednio renderowanego slajdu lub -1, jeśli renderowany jest pierwszy slajd.<br/>            Tylko do odczytu **int**. |
| [`slide_index`](/slides/python-net/pl/aspose.slides.export/ihtmlgenerator/slide_index/) | Zwraca indeks aktualnie renderowanego slajdu.<br/>            Tylko do odczytu **int**. |
| [`next_slide_index`](/slides/python-net/pl/aspose.slides.export/ihtmlgenerator/next_slide_index/) | Zwraca indeks slajdu, który zostanie wyrenderowany po bieżącym slajdzie lub -1, jeśli aktualnie renderowany jest ostatni slajd.<br/>            Tylko do odczytu **int**. |
