## skip_java_script_links właściwość
Określa, czy pomijać hiperłącza wywołujące JavaScript podczas zapisywania prezentacji. 
            Odczyt/zapis **bool**. Domyślna wartość to **false** .


### Uwagi

Gdy ta właściwość ma wartość **true** , hiperłącza wywołujące JavaScript będą ignorowane podczas zapisywania.


Gdy ta właściwość ma wartość **false** , wszystkie hiperłącza zostaną zapisane.
