## ITextToHtmlConversionOptions klasa

Opcje wyodrębniania HTML z tekstu Pptx.

Typ ITextToHtmlConversionOptions udostępnia następujące członki:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`add_clipboard_fragment_header`](/slides/python-net/pl/aspose.slides.export/itexttohtmlconversionoptions/add_clipboard_fragment_header/) | Zwraca lub ustawia wartość, wskazując, czy nagłówki schowka powinny być dodane.<br/>            Odczyt/zapis **bool**. |
| [`text_inheritance_limit`](/slides/python-net/pl/aspose.slides.export/itexttohtmlconversionoptions/text_inheritance_limit/) | Zwraca lub ustawia dziedziczącą głębokość dla właściwości tekstu.<br/>            Odczyt/zapis [`ITextToHtmlConversionOptions.text_inheritance_limit`](/slides/python-net/pl/aspose.slides.export/itexttohtmlconversionoptions/text_inheritance_limit). |
| [`link_embed_controller`](/slides/python-net/pl/aspose.slides.export/itexttohtmlconversionoptions/link_embed_controller/) | Zwraca lub ustawia obiekt zwrotny, który kontroluje, w jaki sposób obiekt zewnętrzny będzie przechowywany.<br/>            Odczyt/zapis [`ILinkEmbedController`](/slides/python-net/pl/aspose.slides.export/ilinkembedcontroller). |
| [`encoding_name`](/slides/python-net/pl/aspose.slides.export/itexttohtmlconversionoptions/encoding_name/) | Zwraca lub ustawia nazwę kodowania html.<br/>            Ta wartość zostanie zapisana do wygenerowanego pliku HTML, ale to od wywołującego zależy, aby plik został zapisany w tym kodowaniu.<br/>            Odczyt/zapis **str**. |
