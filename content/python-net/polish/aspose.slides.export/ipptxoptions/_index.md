## IPptxOptions klasa

Reprezentuje opcje zapisywania prezentacji OpenXml (PPTX, PPSX, POTX, PPTM, PPSM, POTM).

Typ IPptxOptions udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`conformance`](/slides/python-net/pl/aspose.slides.export/ipptxoptions/conformance/) | Określa klasę zgodności, do której dokument prezentacji jest zgodny.<br/>            Domyślna wartość to [`Conformance.ECMA_376_2006`](/slides/python-net/pl/aspose.slides.export/conformance/ECMA_376_2006) |
| [`zip_64_mode`](/slides/python-net/pl/aspose.slides.export/ipptxoptions/zip_64_mode/) | Określa, czy format ZIP64 jest używany w dokumencie prezentacji.<br/>            Domyślna wartość to [`Zip64Mode.IF_NECESSARY`](/slides/python-net/pl/aspose.slides.export/zip64mode/IF_NECESSARY) |
| [`refresh_thumbnail`](/slides/python-net/pl/aspose.slides.export/ipptxoptions/refresh_thumbnail/) | Określa, czy miniatura prezentacji zostanie odświeżona.<br/>            Odczyt/zapis **bool**.<br/>            Domyślna wartość to **true** . |
| [`compression_level`](/slides/python-net/pl/aspose.slides.export/ipptxoptions/compression_level/) | Określa poziom kompresji używany podczas zapisywania dokumentu prezentacji.<br/>            Domyślna wartość to [`CompressionLevel.LEVEL6`](/slides/python-net/pl/aspose.slides.export/compressionlevel/LEVEL6). |
| [`warning_callback`](/slides/python-net/pl/aspose.slides.export/ipptxoptions/warning_callback/) |  |
