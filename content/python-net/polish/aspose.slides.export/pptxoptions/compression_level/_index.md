## właściwość compression_level
Specifies the compression level used when saving the presentation document.
            Domyślna wartość to [`CompressionLevel.LEVEL6`](/slides/python-net/pl/aspose.slides.export/compressionlevel/LEVEL6).


### Uwagi

Higher compression levels produce smaller files but require more processing time.
            Rzeczywisty współczynnik kompresji zależy od zawartości prezentacji.
