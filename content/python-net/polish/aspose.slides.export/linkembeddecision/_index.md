## LinkEmbedDecision wyliczenie

Określa, w jaki sposób obiekt będzie przetwarzany podczas zapisywania.

Typ LinkEmbedDecision udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| LINK | Obiekt zostanie przechowany zewnętrznie, odwoływany przez URL |
| EMBED | Obiekt powinien być osadzony w wygenerowanym pliku, jeśli to możliwe. Jeśli osadzanie jest niemożliwe, wywołana zostanie metoda GetUrl i w zależności od wyniku, obiekt będzie odwoływany przez URL lub zostanie zignorowany. |
| IGNORE | Obiekt zostanie zignorowany. |
