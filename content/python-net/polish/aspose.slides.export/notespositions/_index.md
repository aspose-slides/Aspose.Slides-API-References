## Wyliczenie NotesPositions

Reprezentuje regułę renderowania notatek w wyeksportowanym dokumencie

Typ NotesPositions udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| NONE | Określa, że notatki nie powinny być w ogóle wyświetlane. |
| BOTTOM_FULL | Określa, że notatki powinny być wyświetlane w całości, używając dodatkowych stron w razie potrzeby. |
| BOTTOM_TRUNCATED | Określa, że notatki powinny być wyświetlane na jednej stronie. |
