## MarkdownExportType enumeracja

Typ renderowania dokumentu.

Typ MarkdownExportType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| SEQUENTIAL | Renderuje wszystkie elementy osobno. Jeden po drugim. |
| TEXT_ONLY | Renderuje tylko tekst. |
| VISUAL | Renderuje wszystkie elementy, elementy, które są grupowane - renderuje razem. |
