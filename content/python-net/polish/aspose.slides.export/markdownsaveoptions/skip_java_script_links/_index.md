## skip_java_script_links właściwość
Określa, czy pomijać hiperłącza z wywołaniami JavaScript podczas zapisywania prezentacji. 
            Odczyt/zapis **bool**. Domyślna wartość to **false** .


### Uwagi

Gdy ta właściwość ma ustawioną wartość **true** , hiperłącza z wywołaniami JavaScript będą ignorowane podczas zapisywania.


Gdy ta właściwość ma ustawioną wartość **false** , wszystkie hiperłącza zostaną zapisane.
