## SvgCoordinateUnit enumeracja

Reprezentuje jednostki współrzędnych CSS2 używane do definiowania współrzędnych SVG.

Typ SvgCoordinateUnit udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| INCH | Cal |
| CENTIMETER | Centymetr. |
| MILLIMETER | Milimetr. |
| POINT | Punkt (1/72 cala), |
| PICA | Pica (1/6 cala). |
| EM | Rozmiar em czcionki elementu nadrzędnego. |
| EX | Rozmiar ex (rozmiar małej litery, zwykle „x”) czcionki elementu nadrzędnego. |
| PIXEL | Rozmiar piksela. |
| PERCENT | Procent. |
