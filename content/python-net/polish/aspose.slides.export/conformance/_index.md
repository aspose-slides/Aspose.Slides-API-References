## Wyliczenie zgodności

Określa klasę zgodności, do której dokument PresentationML jest zgodny.

Typ Conformance udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| ECMA_376_2006 | Określa, że dokument jest zgodny z ECMA376:2006. |
| ISO_29500_2008_TRANSITIONAL | Określa, że dokument jest zgodny z klasą zgodności ISO/IEC 29500:2008 Transitional. |
| ISO_29500_2008_STRICT | Określa, że dokument jest zgodny z klasą zgodności ISO/IEC 29500:2008 Strict. |
