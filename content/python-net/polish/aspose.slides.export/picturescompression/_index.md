## PicturesCompression enumeracja

Reprezentuje poziom kompresji obrazów

Typ PicturesCompression udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| DPI330 | Dobra jakość dla wyświetlaczy wysokiej rozdzielczości (HD) |
| DPI220 | Doskonała jakość na większości drukarek i ekranów |
| DPI150 | Dobra jakość dla stron internetowych i projektorów |
| DPI96 | Minimalizuje rozmiar dokumentu przy udostępnianiu |
| DPI72 | Domyślny poziom kompresji |
| DOCUMENT_RESOLUTION | Użyj rozdzielczości dokumentu - obraz nie będzie kompresowany i zostanie użyty w dokumencie w niezmienionej postaci |
