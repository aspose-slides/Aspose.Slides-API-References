## Wyliczenie PdfTextCompression

Stałe definiujące typ kompresji stosowanej do całej zawartości pliku PDF z wyjątkiem obrazów.

Typ PdfTextCompression udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| NONE | Brak kompresji. |
| FLATE | Kompresja Flate (ZIP). |
