## BlackWhiteConversionMode wyliczenie

Udostępnia opcje kontrolujące sposób konwersji obrazów slajdów do obrazów dwuwartościowych.

Typ BlackWhiteConversionMode udostępnia następujące członków:

## Pola

| Pole | Opis |
| :- | :- |
| DEFAULT | Określa brak algorytmu konwersji. Używany będzie algorytm zaimplementowany w kodeku TIFF. (Domyślnie) |
| DITHERING | Określa algorytm ditheringu (Floyd-Steinberg). |
| DITHERING_FLOYD_STEINBERG | Określa algorytm ditheringu Floyd-Steinberg. |
| AUTO | Określa automatycznie obliczany algorytm progowy (Otsu). |
| AUTO_OTSU | Określa automatycznie obliczany algorytm progu Otsu. |
| THRESHOLD25 | Określa statyczny algorytm progowy (25%). |
| THRESHOLD50 | Określa statyczny algorytm progowy (50%). |
| THRESHOLD75 | Określa statyczny algorytm progowy (75%). |
