## SaveFormat enumeracja

Stałe określające format zapisanego prezentacji.

Typ SaveFormat udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| PPT | Zapisz prezentację w formacie PPT. |
| PDF | Zapisz prezentację w formacie PDF. |
| XPS | Zapisz prezentację w formacie XPS. |
| PPTX | Zapisz prezentację w formacie PPTX. |
| PPSX | Zapisz prezentację w formacie PPSX (pokaz slajdów). |
| TIFF | Zapisz prezentację jako wielostronicowy obraz TIFF. |
| ODP | Zapisz prezentację w formacie ODP. |
| PPTM | Zapisz prezentację w formacie PPTM (prezentacja z obsługą makr). |
| PPSM | Zapisz prezentację w formacie PPSM (pokaz slajdów z obsługą makr). |
| POTX | Zapisz prezentację w formacie POTX (szablon). |
| POTM | Zapisz prezentację w formacie POTM (szablon z obsługą makr). |
| HTML | Zapisz prezentację w formacie HTML. |
| SWF | Zapisz prezentację w formacie SWF. |
| OTP | Zapisz prezentację w formacie OTP (szablon prezentacji). |
| PPS | Zapisz prezentację w formacie PPS. |
| POT | Zapisz prezentację w formacie POT. |
| FODP | Zapisz prezentację w formacie FODP. |
| GIF | Zapisz prezentację w formacie GIF. |
| HTML5 | Zapisz prezentację w formacie HTML przy użyciu nowego systemu szablonów HTML5. |
| MD | Zapisz prezentację w formacie Markdown |
| XML | Zapisz prezentację w formacie PowerPoint XML Presentation. |
