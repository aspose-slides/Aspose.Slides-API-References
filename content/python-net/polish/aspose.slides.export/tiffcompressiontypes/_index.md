## TiffCompressionTypes enumeracja

Udostępnia opcje kontrolujące, jak prezentacja jest kompresowana w formacie TIFF.

Typ TiffCompressionTypes udostępnia następujące członki:

## Pola

| Pole | Opis |
| :- | :- |
| DEFAULT | Określa domyślny schemat kompresji (LZW). |
| NONE | Określa brak kompresji. |
| CCITT3 | Określa schemat kompresji CCITT3. |
| CCITT4 | Określa schemat kompresji CCITT4. |
| LZW | Określa schemat kompresji LZW (Domyślny). |
| RLE | Określa schemat kompresji RLE. |
