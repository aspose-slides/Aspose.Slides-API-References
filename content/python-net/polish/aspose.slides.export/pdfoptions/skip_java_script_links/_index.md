## skip_java_script_links właściwość
Określa, czy pomijać hiperłącza z wywołaniami JavaScript podczas zapisywania prezentacji. 
            Odczyt/zapis **bool**. Domyślna wartość to **false** .


### Uwagi

Kiedy ta właściwość jest ustawiona na **true** , hiperłącza z wywołaniami JavaScript będą ignorowane podczas zapisywania.


Kiedy ta właściwość jest ustawiona na **false** , wszystkie hiperłącza zostaną zapisane.
