## embed_true_type_fonts_for_ascii właściwość
Determines if Aspose.Slides will embed common fonts for ASCII (33..127 code range) text.
            Czcionki dla kodów znaków większych niż 127 są zawsze osadzane.
            Lista wspólnych czcionek zawiera 14 podstawowych czcionek PDF oraz dodatkowe czcionki określone przez użytkownika.
            odczyt/zapis **bool**.


### Uwagi

Default is **true** .
