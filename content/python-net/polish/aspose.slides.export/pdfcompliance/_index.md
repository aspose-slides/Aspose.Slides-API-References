## Wyliczenie PdfCompliance

Stałe definiujące poziom zgodności z standardami PDF.

Typ PdfCompliance udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| PDF15 | Plik wyjściowy będzie zgodny ze standardem PDF 1.5. |
| PDF16 | Plik wyjściowy będzie zgodny ze standardem PDF 1.6. |
| PDF17 | Plik wyjściowy będzie zgodny ze standardem PDF 1.7. |
| PDF_A1B | Plik wyjściowy będzie zgodny ze standardem PDF/A-1b. |
| PDF_A1A | Plik wyjściowy będzie zgodny ze standardem PDF/A-1a. |
| PDF_A2B | Plik wyjściowy będzie zgodny ze standardem PDF/A-2b. |
| PDF_A2A | Plik wyjściowy będzie zgodny ze standardem PDF/A-2a. |
| PDF_A3B | Plik wyjściowy będzie zgodny ze standardem PDF/A-3b. |
| PDF_A3A | Plik wyjściowy będzie zgodny ze standardem PDF/A-3a. |
| PDF_UA | Plik wyjściowy będzie zgodny ze standardem PDF/UA. |
| PDF_A2U | Plik wyjściowy będzie zgodny ze standardem PDF/A-2u. |
