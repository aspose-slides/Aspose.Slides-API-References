## TextInheritanceLimit enumeracja

Kontroluje głębokość dziedziczenia właściwości tekstu.

Typ TextInheritanceLimit udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| ALL | Dziedziczy wszystkie właściwości tekstu. |
| TEXT_BOX | Dziedziczy tylko ze stylu TextFrame. |
| PARAGRAPH_ONLY | Używa tylko właściwości zdefiniowanych dla akapitu. |
