## skip_java_script_links właściwość
Określa, czy pomijać hiperłącza wywołujące JavaScript podczas zapisywania prezentacji. 
            Odczyt/zapis **bool**. Wartość domyślna to **false** .


### Uwagi

Gdy ta właściwość jest ustawiona na **true**, hiperłącza wywołujące JavaScript będą ignorowane podczas zapisywania.


Gdy ta właściwość jest ustawiona na **false**, wszystkie hiperłącza zostaną zapisane.
