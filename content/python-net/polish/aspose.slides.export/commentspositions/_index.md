## Enumeracja CommentsPositions

Reprezentuje regułę renderowania komentarzy w wyeksportowanym dokumencie

Typ CommentsPositions udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| NONE | Określa, że komentarze nie powinny być wyświetlane wcale. |
| BOTTOM | Określa, że komentarze powinny być wyświetlane na dole strony. |
| RIGHT | Określa, że komentarze powinny być wyświetlane po prawej stronie. |
