## ISwfOptions klasa

Udostępnia opcje, które kontrolują, jak prezentacja jest zapisywana w formacie SWF.

Typ ISwfOptions udostępnia następujące członki:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`compressed`](/slides/python-net/pl/aspose.slides.export/iswfoptions/compressed/) | Określa, czy wygenerowany dokument SWF powinien być kompresowany, czy nie.<br/>            Domyślnie jest `true`. |
| [`viewer_included`](/slides/python-net/pl/aspose.slides.export/iswfoptions/viewer_included/) | Określa, czy wygenerowany dokument SWF powinien zawierać zintegrowany podgląd dokumentu, czy nie.<br/>            Domyślnie jest `true`. |
| [`show_page_border`](/slides/python-net/pl/aspose.slides.export/iswfoptions/show_page_border/) | Określa, czy granica wokół stron ma być wyświetlana. Domyślnie jest true. |
| [`show_hidden_slides`](/slides/python-net/pl/aspose.slides.export/iswfoptions/show_hidden_slides/) | Określa, czy wygenerowany dokument powinien zawierać ukryte slajdy, czy nie.<br/>            Domyślnie jest `false`. |
| [`show_full_screen`](/slides/python-net/pl/aspose.slides.export/iswfoptions/show_full_screen/) | Pokaż/ukryj przycisk pełnego ekranu. Może być nadpisane w flashvars. Domyślnie jest true. |
| [`show_page_stepper`](/slides/python-net/pl/aspose.slides.export/iswfoptions/show_page_stepper/) | Pokaż/ukryj przełącznik stron. Może być nadpisane w flashvars. Domyślnie jest true. |
| [`show_search`](/slides/python-net/pl/aspose.slides.export/iswfoptions/show_search/) | Pokaż/ukryj sekcję wyszukiwania. Może być nadpisane w flashvars. Domyślnie jest true. |
| [`show_top_pane`](/slides/python-net/pl/aspose.slides.export/iswfoptions/show_top_pane/) | Pokaż/ukryj cały górny panel. Może być nadpisane w flashvars. Domyślnie jest true. |
| [`show_bottom_pane`](/slides/python-net/pl/aspose.slides.export/iswfoptions/show_bottom_pane/) | Pokaż/ukryj dolny panel. Może być nadpisane w flashvars. Domyślnie jest true. |
| [`show_left_pane`](/slides/python-net/pl/aspose.slides.export/iswfoptions/show_left_pane/) | Pokaż/ukryj lewy panel. Może być nadpisane w flashvars. Domyślnie jest true. |
| [`start_open_left_pane`](/slides/python-net/pl/aspose.slides.export/iswfoptions/start_open_left_pane/) | Rozpocznij z otwartym lewym panelem. Może być nadpisane w flashvars. Domyślnie jest false. |
| [`enable_context_menu`](/slides/python-net/pl/aspose.slides.export/iswfoptions/enable_context_menu/) | Włącz/wyłącz menu kontekstowe. Domyślnie jest true. |
| [`logo_image_bytes`](/slides/python-net/pl/aspose.slides.export/iswfoptions/logo_image_bytes/) | Obraz, który będzie wyświetlany jako logo w prawym górnym rogu przeglądarki.             <br/>            Obraz powinien mieć 32x64 piksele w formacie PNG, w przeciwnym razie logo może być wyświetlane niepoprawnie. |
| [`logo_link`](/slides/python-net/pl/aspose.slides.export/iswfoptions/logo_link/) | Pobiera lub ustawia pełny adres hiperłącza dla logo.<br/>            Ma efekt tylko wtedy, gdy określono [`ISwfOptions.logo_image_bytes`](/slides/python-net/pl/aspose.slides.export/iswfoptions/logo_image_bytes). |
| [`jpeg_quality`](/slides/python-net/pl/aspose.slides.export/iswfoptions/jpeg_quality/) | Określa jakość obrazów JPEG.             <br/>            Domyślnie jest 95. |
| [`slides_layout_options`](/slides/python-net/pl/aspose.slides.export/iswfoptions/slides_layout_options/) | Pobiera lub ustawia tryb, w którym slajdy są rozmieszczane na stronie podczas eksportu prezentacji [`ISlidesLayoutOptions`](/slides/python-net/pl/aspose.slides.export/islideslayoutoptions).<br/>            Ta właściwość nie obsługuje przypisywania obiektów typu `Aspose.Slides.Export.HandoutLayoutingOptions` |
| [`warning_callback`](/slides/python-net/pl/aspose.slides.export/iswfoptions/warning_callback/) |  |
| [`progress_callback`](/slides/python-net/pl/aspose.slides.export/iswfoptions/progress_callback/) |  |
| [`default_regular_font`](/slides/python-net/pl/aspose.slides.export/iswfoptions/default_regular_font/) |  |
| [`gradient_style`](/slides/python-net/pl/aspose.slides.export/iswfoptions/gradient_style/) |  |
