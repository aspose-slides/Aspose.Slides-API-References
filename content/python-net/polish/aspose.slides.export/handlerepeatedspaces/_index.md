## HandleRepeatedSpaces enumeration

Określa, jak należy obsługiwać powtarzające się zwykłe znaki spacji podczas eksportu do Markdown.

Typ HandleRepeatedSpaces udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| NONE | Wszystkie spacje są zachowywane jako zwykłe znaki spacji bez żadnych zmian.<br/> Nie stosuje się żadnej transformacji, a wiele kolejnych spacji jest eksportowane w niezmienionej formie. |
| ALTERNATE_SPACES_TO_NBSP |  |
| MULTIPLE_SPACES_TO_NBSP |  |
