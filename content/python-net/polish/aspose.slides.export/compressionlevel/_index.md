## CompressionLevel enumeracja

Określa poziomy kompresji ZIP dla pliku OpenXML.  
Wyższe poziomy zapewniają lepszą kompresję kosztem wolniejszego przetwarzania.

Typ CompressionLevel udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| NONE | Nie stosuje się kompresji. Pliki są przechowywane bez zmian. |
| LEVEL1 | Najszybsza kompresja przy najniższym współczynniku kompresji. |
| LEVEL2 | Szybsza kompresja przy nieco lepszym współczynniku kompresji niż [`CompressionLevel.LEVEL1`](/slides/python-net/pl/aspose.slides.export/compressionlevel/LEVEL1). |
| LEVEL3 | Zapewnia lepszą kompresję niż [`CompressionLevel.LEVEL2`](/slides/python-net/pl/aspose.slides.export/compressionlevel/LEVEL2) przy umiarkowanym wpływie na wydajność. |
| LEVEL4 | Zapewnia lepszą kompresję niż [`CompressionLevel.LEVEL3`](/slides/python-net/pl/aspose.slides.export/compressionlevel/LEVEL3). |
| LEVEL5 | Zapewnia lepszą kompresję niż [`CompressionLevel.LEVEL4`](/slides/python-net/pl/aspose.slides.export/compressionlevel/LEVEL4) przy dodatkowym czasie przetwarzania. |
| LEVEL6 | Standardowa kompresja, zapewniająca dobrą równowagę między szybkością kompresji a rozmiarem pliku.<br/>            Domyślny poziom kompresji. |
| LEVEL7 | Zapewnia wyższą kompresję niż [`CompressionLevel.LEVEL6`](/slides/python-net/pl/aspose.slides.export/compressionlevel/LEVEL6) przy wolniejszym przetwarzaniu. |
| LEVEL8 | Zapewnia wyższą kompresję niż [`CompressionLevel.LEVEL7`](/slides/python-net/pl/aspose.slides.export/compressionlevel/LEVEL7). |
| LEVEL9 | Maksymalna kompresja. Produkuje najmniejszy rozmiar pliku przy najwolniejszej prędkości przetwarzania. |
