## SaveOptions klasa

Abstrakcyjna klasa z opcjami kontrolującymi sposób zapisu prezentacji.

Typ SaveOptions udostępnia następujące elementy:

## Właściwości

| Property | Description |
| :- | :- |
| [`warning_callback`](/slides/python-net/pl/aspose.slides.export/saveoptions/warning_callback/) | Zwraca lub ustawia obiekt, który odbiera ostrzeżenia i decyduje, czy proces ładowania będzie kontynuowany, czy zostanie przerwany.<br/>            Odczyt/zapis [`IWarningCallback`](/slides/python-net/pl/aspose.slides.warnings/iwarningcallback). |
| [`progress_callback`](/slides/python-net/pl/aspose.slides.export/saveoptions/progress_callback/) | Reprezentuje obiekt wywołania zwrotnego do aktualizacji postępu zapisu w procentach.<br/>            Zobacz [`IProgressCallback`](/slides/python-net/pl/aspose.slides/iprogresscallback). |
| [`default_regular_font`](/slides/python-net/pl/aspose.slides.export/saveoptions/default_regular_font/) | Zwraca lub ustawia czcionkę używaną, gdy nie znaleziono czcionki źródłowej.<br/>            Odczyt/zapis **str**. |
| [`gradient_style`](/slides/python-net/pl/aspose.slides.export/saveoptions/gradient_style/) | Zwraca lub ustawia styl wizualny gradientu.<br/>            Odczyt/zapis [`GradientStyle`](/slides/python-net/pl/aspose.slides/gradientstyle). |
| [`skip_java_script_links`](/slides/python-net/pl/aspose.slides.export/saveoptions/skip_java_script_links/) | Określa, czy pomijać hiperłącza z wywołaniami JavaScript podczas zapisywania prezentacji.<br/>            Odczyt/zapis **bool**. Domyślna wartość to **false** . |
