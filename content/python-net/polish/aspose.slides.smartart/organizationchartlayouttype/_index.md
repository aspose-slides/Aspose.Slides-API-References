## OrganizationChartLayoutType wyliczenie

Reprezentuje typ formatowania węzłów potomnych w diagramie organizacyjnym

Typ OrganizationChartLayoutType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| INITIAL | Początkowy typ układu |
| STANDART | Umieszcza węzły potomne poziomo pod węzłem nadrzędnym. |
| BOTH_HANGING | Umieszcza węzły potomne pionowo pod węzłem nadrzędnym po obu stronach: lewej i prawej. |
| LEFT_HANGING | Umieszcza węzły potomne pionowo pod węzłem nadrzędnym po lewej stronie. |
| RIGHT_HANGING | Umieszcza węzły potomne pionowo pod węzłem nadrzędnym po prawej stronie. |
