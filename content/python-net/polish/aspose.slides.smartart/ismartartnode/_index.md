## ISmartArtNode klasa

Reprezentuje węzeł diagramu SmartArt.

Typ ISmartArtNode udostępnia następujące elementy:

## Właściwości

| Property | Description |
| :- | :- |
| [`child_nodes`](/slides/python-net/pl/aspose.slides.smartart/ismartartnode/child_nodes/) | Zwraca kolekcje wszystkich węzłów potomnych bieżącego węzła.<br/>            Tylko do odczytu [`ISmartArtNodeCollection`](/slides/python-net/pl/aspose.slides.smartart/ismartartnodecollection). |
| [`shapes`](/slides/python-net/pl/aspose.slides.smartart/ismartartnode/shapes/) | Zwraca kolekcje wszystkich kształtów powiązanych z węzłem.<br/>            Tylko do odczytu [`ISmartArtShapeCollection`](/slides/python-net/pl/aspose.slides.smartart/ismartartshapecollection). |
| [`text_frame`](/slides/python-net/pl/aspose.slides.smartart/ismartartnode/text_frame/) | Zwraca lub ustawia tekst węzła.<br/>            Tylko do odczytu [`ITextFrame`](/slides/python-net/pl/aspose.slides/itextframe). |
| [`is_assistant`](/slides/python-net/pl/aspose.slides.smartart/ismartartnode/is_assistant/) | Zwraca lub ustawia węzeł jako asystenta.<br/>            Odczyt/zapis **bool**. |
| [`level`](/slides/python-net/pl/aspose.slides.smartart/ismartartnode/level/) | Zwraca poziom zagnieżdżenia węzła.<br/>            Tylko do odczytu **int**. |
| [`bullet_fill_format`](/slides/python-net/pl/aspose.slides.smartart/ismartartnode/bullet_fill_format/) | Zwraca obiekt FillFormat, który zawiera właściwości formatowania wypełnienia dla wypunktowania węzła.<br/>            Uwaga: może zwrócić None dla niektórych typów układu SmartArt, które nie zapewniają wypunktowań dla węzłów.<br/>            Tylko do odczytu [`IFillFormat`](/slides/python-net/pl/aspose.slides/ifillformat). |
| [`position`](/slides/python-net/pl/aspose.slides.smartart/ismartartnode/position/) | Zwraca lub ustawia pozycję zerową węzła wśród węzłów rodzeństwa.<br/>            Odczyt/zapis **int**. |
| [`is_hidden`](/slides/python-net/pl/aspose.slides.smartart/ismartartnode/is_hidden/) | Zwraca true, jeśli ten węzeł jest ukrytym węzłem w modelu danych.<br/>            Tylko do odczytu **bool**. |
| [`organization_chart_layout`](/slides/python-net/pl/aspose.slides.smartart/ismartartnode/organization_chart_layout/) | Zwraca lub ustawia typ układu wykresu organizacyjnego powiązany z bieżącym węzłem.<br/>            Odczyt/zapis [`OrganizationChartLayoutType`](/slides/python-net/pl/aspose.slides.smartart/organizationchartlayouttype). |
