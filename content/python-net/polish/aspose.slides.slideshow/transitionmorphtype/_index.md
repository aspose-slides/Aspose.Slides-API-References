## TransitionMorphType enumeracja

Reprezentuje typ przejścia morph.

Typ TransitionMorphType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| BY_OBJECT | Przejście Morph będzie wykonywane z uwzględnieniem kształtów jako niepodzielnych obiektów. |
| BY_WORD | Przejście Morph będzie wykonywane poprzez przenoszenie tekstu słowo po słowie, gdzie to możliwe. |
| BY_CHAR | Przejście Morph będzie wykonywane poprzez przenoszenie tekstu znak po znaku, gdzie to możliwe. |
