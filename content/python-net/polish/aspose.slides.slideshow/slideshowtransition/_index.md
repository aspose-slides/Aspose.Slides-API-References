## SlideShowTransition klasa

Reprezentuje przejście pokazu slajdów.

Typ SlideShowTransition udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`sound`](/slides/python-net/pl/aspose.slides.slideshow/slideshowtransition/sound/) | Zwraca lub ustawia osadzone dane audio.<br/>            Odczyt/zapis [`IAudio`](/slides/python-net/pl/aspose.slides/iaudio). |
| [`sound_mode`](/slides/python-net/pl/aspose.slides.slideshow/slideshowtransition/sound_mode/) | Ustawia lub zwraca tryb dźwięku dla przejścia slajdu.<br/>            Odczyt/zapis [`TransitionSoundMode`](/slides/python-net/pl/aspose.slides.slideshow/transitionsoundmode). |
| [`sound_loop`](/slides/python-net/pl/aspose.slides.slideshow/slideshowtransition/sound_loop/) | Ten atrybut określa, czy dźwięk będzie powtarzany, aż do wystąpienia następnego zdarzenia dźwiękowego w<br/>            pokazie slajdów.<br/>            Odczyt/zapis **bool**. |
| [`advance_on_click`](/slides/python-net/pl/aspose.slides.slideshow/slideshowtransition/advance_on_click/) | Określa, czy kliknięcie myszy przejdzie do następnego slajdu, czy nie. Jeśli ten atrybut nie jest<br/>            określony, przyjmuje się wartość true.<br/>            Odczyt/zapis **bool**. |
| [`advance_after`](/slides/python-net/pl/aspose.slides.slideshow/slideshowtransition/advance_after/) | Ten atrybut określa, czy pokaz slajdów przejdzie do następnego slajdu po określonym czasie.<br/>            Odczyt/zapis **bool**. |
| [`advance_after_time`](/slides/python-net/pl/aspose.slides.slideshow/slideshowtransition/advance_after_time/) | Określa czas w milisekundach, po którym przejście powinno się rozpocząć. To ustawienie<br/>            może być użyte w połączeniu z atrybutem advClick. Jeśli ten atrybut nie jest określony<br/>            przyjmuje się, że nie nastąpi automatyczne przejście.<br/>            Odczyt/zapis **int**. |
| [`speed`](/slides/python-net/pl/aspose.slides.slideshow/slideshowtransition/speed/) | Określa prędkość przejścia, która ma być użyta przy przejściu z bieżącego slajdu<br/>            do następnego.<br/>            Odczyt/zapis [`TransitionSpeed`](/slides/python-net/pl/aspose.slides.slideshow/transitionspeed). |
| [`value`](/slides/python-net/pl/aspose.slides.slideshow/slideshowtransition/value/) | Wartość przejścia pokazu slajdów.<br/>            Tylko odczyt [`ITransitionValueBase`](/slides/python-net/pl/aspose.slides.slideshow/itransitionvaluebase). |
| [`type`](/slides/python-net/pl/aspose.slides.slideshow/slideshowtransition/type/) | Typ przejścia.<br/>            Odczyt/zapis [`TransitionType`](/slides/python-net/pl/aspose.slides.slideshow/transitiontype). |
| [`sound_is_built_in`](/slides/python-net/pl/aspose.slides.slideshow/slideshowtransition/sound_is_built_in/) | Określa, czy dźwięk jest wbudowany. Jeśli ten atrybut ma wartość true, wtedy aplikacja generująca zostaje powiadomiona, aby sprawdzić atrybut name określony dla tego dźwięku<br/>            na swojej liście wbudowanych dźwięków i może wtedy wyświetlić niestandardową nazwę lub interfejs użytkownika w razie potrzeby.<br/>            Odczyt/zapis **bool**. |
| [`sound_name`](/slides/python-net/pl/aspose.slides.slideshow/slideshowtransition/sound_name/) | Określa czytelną dla człowieka nazwę dźwięku przejścia. Właściwość [`SlideShowTransition.sound`](/slides/python-net/pl/aspose.slides.slideshow/slideshowtransition/sound) musi być przypisana, aby pobrać lub ustawić nazwę dźwięku.<br/>            Odczyt/zapis **str**. |
| [`duration`](/slides/python-net/pl/aspose.slides.slideshow/slideshowtransition/duration/) | Pobiera lub ustawia czas trwania efektu przejścia slajdu w milisekundach.<br/>            Odczyt/zapis **int**. |
