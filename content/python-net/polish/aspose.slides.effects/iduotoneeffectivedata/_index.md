## IDuotoneEffectiveData klasa

Niezmienny obiekt reprezentujący efekt Duotone.  
Dla każdego piksela łączy clr1 i clr2 poprzez liniową interpolację, aby określić nowy kolor tego piksela.

Typ IDuotoneEffectiveData udostępnia następujące członków:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`color1`](/slides/python-net/pl/aspose.slides.effects/iduotoneeffectivedata/color1/) | Zwraca format koloru docelowego dla ciemnych pikseli.<br/>            Tylko do odczytu **aspose.slides.Color**. |
| [`color2`](/slides/python-net/pl/aspose.slides.effects/iduotoneeffectivedata/color2/) | Zwraca format koloru docelowego dla jasnych pikseli.<br/>            Tylko do odczytu **aspose.slides.Color**. |
