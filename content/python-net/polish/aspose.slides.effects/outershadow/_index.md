## Klasa OuterShadow

Reprezentuje efekt cienia zewnętrznego.

Typ OuterShadow udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`blur_radius`](/slides/python-net/pl/aspose.slides.effects/outershadow/blur_radius/) | Promień rozmycia w punktach.<br/>Domyślna wartość – 0 pt.<br/>Odczyt/zapis **float**. |
| [`direction`](/slides/python-net/pl/aspose.slides.effects/outershadow/direction/) | Kierunek cienia w stopniach.<br/>Domyślna wartość – 0 ° (od lewego do prawego).<br/>Odczyt/zapis **float**. |
| [`distance`](/slides/python-net/pl/aspose.slides.effects/outershadow/distance/) | Odległość cienia od obiektu w punktach.<br/>Domyślna wartość – 0 pt.<br/>Odczyt/zapis **float**. |
| [`shadow_color`](/slides/python-net/pl/aspose.slides.effects/outershadow/shadow_color/) | Kolor cienia.<br/>Domyślna wartość – automatyczna czerń (zależna od motywu).<br/>Tylko do odczytu [`IColorFormat`](/slides/python-net/pl/aspose.slides/icolorformat). |
| [`rectangle_align`](/slides/python-net/pl/aspose.slides.effects/outershadow/rectangle_align/) | Wyrównanie prostokąta.<br/>Domyślna wartość – [`RectangleAlignment.BOTTOM`](/slides/python-net/pl/aspose.slides/rectanglealignment/BOTTOM).<br/>Odczyt/zapis [`RectangleAlignment`](/slides/python-net/pl/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/pl/aspose.slides.effects/outershadow/skew_horizontal/) | Kąt pochylenia poziomego w stopniach.<br/>Domyślna wartość – 0 °.<br/>Odczyt/zapis **float**. |
| [`skew_vertical`](/slides/python-net/pl/aspose.slides.effects/outershadow/skew_vertical/) | Kąt pochylenia pionowego w stopniach.<br/>Domyślna wartość – 0 °.<br/>Odczyt/zapis **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/pl/aspose.slides.effects/outershadow/rotate_shadow_with_shape/) | Określa, czy cień obraca się razem z kształtem.<br/>Domyślna wartość – true.<br/>Odczyt/zapis **bool**. |
| [`scale_horizontal`](/slides/python-net/pl/aspose.slides.effects/outershadow/scale_horizontal/) | Czynnik skalowania poziomego w procentach pierwotnego rozmiaru.<br/>Ujemne skalowanie powoduje odbicie.<br/>Domyślna wartość – 100 %.<br/>Odczyt/zapis **float**. |
| [`scale_vertical`](/slides/python-net/pl/aspose.slides.effects/outershadow/scale_vertical/) | Czynnik skalowania pionowego w procentach pierwotnego rozmiaru.<br/>Ujemne skalowanie powoduje odbicie.<br/>Domyślna wartość – 100 %.<br/>Odczyt/zapis **float**. |
