## IBlurEffectiveData klasa

Niezmienny obiekt, który reprezentuje efekt rozmycia stosowany do całego kształtu, włączając w to wypełnienie.
            Wszystkie kanały kolorów, w tym alfa, są poddane efektowi.

Typ IBlurEffectiveData udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`radius`](/slides/python-net/pl/aspose.slides.effects/iblureffectivedata/radius/) | Zwraca lub ustawia promień rozmycia.<br/>            Tylko do odczytu **float**. |
| [`grow`](/slides/python-net/pl/aspose.slides.effects/iblureffectivedata/grow/) | Określa, czy granice obiektu powinny być powiększane w wyniku rozmycia.<br/>            True wskazuje, że granice są powiększane, natomiast false wskazuje, że nie są.<br/>            Tylko do odczytu **bool**. |
