## IReflectionEffectiveData klasa

Niezmienny obiekt reprezentujący efekt odbicia.

Typ IReflectionEffectiveData udostępnia następujące członki:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/pl/aspose.slides.effects/ireflectioneffectivedata/start_pos_alpha/) | Określa pozycję początkową (wzdłuż gradientu alfa) wartości początkowej alfa (procenty).<br/>            Tylko do odczytu **float**. |
| [`end_pos_alpha`](/slides/python-net/pl/aspose.slides.effects/ireflectioneffectivedata/end_pos_alpha/) | Określa pozycję końcową (wzdłuż gradientu alfa) wartości końcowej alfa (procenty).<br/>            Tylko do odczytu **float**. |
| [`fade_direction`](/slides/python-net/pl/aspose.slides.effects/ireflectioneffectivedata/fade_direction/) | Określa kierunek przesunięcia odbicia. (kąt).<br/>            Tylko do odczytu **float**. |
| [`start_reflection_opacity`](/slides/python-net/pl/aspose.slides.effects/ireflectioneffectivedata/start_reflection_opacity/) | Początkowa nieprzezroczystość odbicia. (procenty).<br/>            Tylko do odczytu **float**. |
| [`end_reflection_opacity`](/slides/python-net/pl/aspose.slides.effects/ireflectioneffectivedata/end_reflection_opacity/) | Końcowa nieprzezroczystość odbicia. (procenty).<br/>            Tylko do odczytu **float**. |

| [`rectangle_align`](/slides/python-net/pl/aspose.slides.effects/ireflectioneffectivedata/rectangle_align/) | Wyrównanie prostokąta.<br/>            Tylko do odczytu [`RectangleAlignment`](/slides/python-net/pl/aspose.slides/rectanglealignment). |

| [`scale_horizontal`](/slides/python-net/pl/aspose.slides.effects/ireflectioneffectivedata/scale_horizontal/) | Określa poziomy współczynnik skalowania, ujemne skalowanie powoduje odbicie. (procenty)<br/>            Tylko do odczytu **float**. |
