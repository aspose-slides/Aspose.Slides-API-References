## Klasa Reflection

Reprezentuje efekt Reflection.

Typ Reflection udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/pl/aspose.slides.effects/reflection/start_pos_alpha/) | Określa pozycję początkową (wzdłuż gradientu alfa) wartości alfa początkowej (procenty).<br/>            Odczyt/zapis **float**. |
| [`end_pos_alpha`](/slides/python-net/pl/aspose.slides.effects/reflection/end_pos_alpha/) | Określa pozycję końcową (wzdłuż gradientu alfa) wartości alfa końcowej (procenty).<br/>            Odczyt/zapis **float**. |
| [`fade_direction`](/slides/python-net/pl/aspose.slides.effects/reflection/fade_direction/) | Określa kierunek przesunięcia odbicia. (kąt).<br/>            Odczyt/zapis **float**. |

| [`end_reflection_opacity`](/slides/python-net/pl/aspose.slides.effects/reflection/end_reflection_opacity/) | Końcowa nieprzezroczystość odbicia. (procenty).<br/>            Odczyt/zapis **float**. |
| [`blur_radius`](/slides/python-net/pl/aspose.slides.effects/reflection/blur_radius/) | Promień rozmycia.<br/>            Odczyt/zapis **float**. |

| [`rectangle_align`](/slides/python-net/pl/aspose.slides.effects/reflection/rectangle_align/) | Wyrównanie prostokąta.<br/>            Odczyt/zapis [`RectangleAlignment`](/slides/python-net/pl/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/pl/aspose.slides.effects/reflection/skew_horizontal/) | Określa poziomy kąt pochylenia.<br/>            Odczyt/zapis **float**. |

| [`scale_vertical`](/slides/python-net/pl/aspose.slides.effects/reflection/scale_vertical/) | Określa pionowy współczynnik skalowania, ujemne skalowanie powoduje odbicie. (procenty)<br/>            Odczyt/zapis **float**. |
