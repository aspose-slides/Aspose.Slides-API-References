## IColorChangeEffectiveData klasa

Niezmienny obiekt, który reprezentuje efekt zmiany koloru.
Instancje FromColor są zastępowane instancjami ToColor.

Typ IColorChangeEffectiveData udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`from_color`](/slides/python-net/pl/aspose.slides.effects/icolorchangeeffectivedata/from_color/) | Kolor, który zostanie zastąpiony.<br/>            Tylko do odczytu [`Color`](/slides/python-net/pl/aspose.slides/color). |
| [`to_color`](/slides/python-net/pl/aspose.slides.effects/icolorchangeeffectivedata/to_color/) | Kolor, który zastąpi.<br/>            Tylko do odczytu [`Color`](/slides/python-net/pl/aspose.slides/color). |
| [`use_alpha`](/slides/python-net/pl/aspose.slides.effects/icolorchangeeffectivedata/use_alpha/) | Zwraca wartość logiczną określającą, czy komponent alfa powinien być używany.<br/>            Tylko do odczytu **bool**. |
