## IColorChangeEffectiveData klasa

Niezmienny obiekt reprezentujący efekt zmiany koloru.  
Instancje FromColor są zastępowane instancjami ToColor.

Typ IColorChangeEffectiveData udostępnia następujące elementy:

## Właściwości

| Property | Description |
| :- | :- |
| [`from_color`](/slides/python-net/pl/aspose.slides.effects/icolorchangeeffectivedata/from_color/) | Kolor, który zostanie zastąpiony.<br/>            Tylko do odczytu **aspose.slides.Color**. |
| [`to_color`](/slides/python-net/pl/aspose.slides.effects/icolorchangeeffectivedata/to_color/) | Kolor, który zastąpi.<br/>            Tylko do odczytu **aspose.slides.Color**. |
| [`use_alpha`](/slides/python-net/pl/aspose.slides.effects/icolorchangeeffectivedata/use_alpha/) | Zwraca wartość boolowską określającą, czy należy użyć składowej alfa.<br/>            Tylko do odczytu **bool**. |
