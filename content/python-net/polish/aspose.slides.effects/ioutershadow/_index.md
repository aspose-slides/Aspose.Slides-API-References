## IOuterShadow klasa

Reprezentuje efekt zewnętrznego cienia.

Typ IOuterShadow udostępnia następujące elementy:

## Właściwości

| Property | Description |
| :- | :- |
| [`blur_radius`](/slides/python-net/pl/aspose.slides.effects/ioutershadow/blur_radius/) | Promień rozmycia, w punktach.<br/>            Domyślna wartość – 0 pt.<br/>            Odczyt/zapis **float**. |
| [`direction`](/slides/python-net/pl/aspose.slides.effects/ioutershadow/direction/) | Kierunek cienia, w stopniach.<br/>            Domyślna wartość – 0 ° (od lewej do prawej).<br/>            Odczyt/zapis **float**. |
| [`distance`](/slides/python-net/pl/aspose.slides.effects/ioutershadow/distance/) | Odległość cienia od obiektu, w punktach.<br/>            Domyślna wartość – 0 pt.<br/>            Odczyt/zapis **float**. |
| [`shadow_color`](/slides/python-net/pl/aspose.slides.effects/ioutershadow/shadow_color/) | Kolor cienia.<br/>            Domyślna wartość – automatyczna czerń (zależna od motywu).<br/>            Tylko odczyt [`IColorFormat`](/slides/python-net/pl/aspose.slides/icolorformat). |
| [`rectangle_align`](/slides/python-net/pl/aspose.slides.effects/ioutershadow/rectangle_align/) | Wyrównanie prostokąta.<br/>            Domyślna wartość – [`RectangleAlignment.BOTTOM`](/slides/python-net/pl/aspose.slides/rectanglealignment/BOTTOM). <br/>            Odczyt/zapis [`RectangleAlignment`](/slides/python-net/pl/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/pl/aspose.slides.effects/ioutershadow/skew_horizontal/) | Kąt pochylenia w poziomie, w stopniach.<br/>            Domyślna wartość – 0 °.<br/>            Odczyt/zapis **float**. |
| [`skew_vertical`](/slides/python-net/pl/aspose.slides.effects/ioutershadow/skew_vertical/) | Kąt pochylenia w pionie, w stopniach.<br/>            Domyślna wartość – 0 °.<br/>            Odczyt/zapis **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/pl/aspose.slides.effects/ioutershadow/rotate_shadow_with_shape/) | Wskazuje, czy cień obraca się razem z kształtem.<br/>            Domyślna wartość – true.<br/>            Odczyt/zapis **bool**. |
| [`scale_horizontal`](/slides/python-net/pl/aspose.slides.effects/ioutershadow/scale_horizontal/) | Poziomy współczynnik skalowania, w procentach oryginalnego rozmiaru.<br/>            Ujemne skalowanie powoduje odbicie.<br/>            Domyślna wartość – 100 %.<br/>            Odczyt/zapis **float**. |
| [`scale_vertical`](/slides/python-net/pl/aspose.slides.effects/ioutershadow/scale_vertical/) | Pionowy współczynnik skalowania, w procentach oryginalnego rozmiaru.<br/>            Ujemne skalowanie powoduje odbicie.<br/>            Domyślna wartość – 100 %.<br/>            Odczyt/zapis **float**. |
