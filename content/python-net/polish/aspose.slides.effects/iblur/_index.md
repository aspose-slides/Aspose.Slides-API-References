## IBlur klasa

Reprezentuje efekt rozmycia, który jest stosowany do całego kształtu, w tym jego wypełnienia.  
            Wszystkie kanały kolorów, w tym alfa, są dotknięte.

Typ IBlur udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`radius`](/slides/python-net/pl/aspose.slides.effects/iblur/radius/) | Zwraca lub ustawia promień rozmycia.<br/>            Odczyt/zapis **float**. |
| [`grow`](/slides/python-net/pl/aspose.slides.effects/iblur/grow/) | Określa, czy granice obiektu powinny być powiększone w wyniku rozmycia.<br/>            True wskazuje, że granice są powiększane, natomiast false wskazuje, że nie są.<br/>            Odczyt/zapis **bool**. |
