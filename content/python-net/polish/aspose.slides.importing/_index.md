## Klasy

| Klasa | Opis |
| :- | :- |
| [`ExcelWorkbookImporter`](/slides/python-net/pl/aspose.slides.importing/excelworkbookimporter/) | Zapewnia funkcjonalność importowania treści z arkusza Excel do prezentacji. |
| [`ExternalResourceResolver`](/slides/python-net/pl/aspose.slides.importing/externalresourceresolver/) | Klasa zwrotna używana do rozwiązywania zewnętrznych zasobów podczas importu dokumentów Html, Svg.<br/>            Użycie tego resolvera może stworzyć lukę bezpieczeństwa, gdy dostarczony przez klienta plik HTML lub SVG spowoduje, że oprogramowanie serwera pobierze lokalny lub sieciowy plik. Należy zachować ostrożność. Zaleca się nie określać ExternalResourceResolver wcale (odczytywane będą tylko osadzone obiekty) lub utworzyć podklasę, która sprawdza, czy podany uri jest prawidłowy. |
| [`HtmlExternalResolver`](/slides/python-net/pl/aspose.slides.importing/htmlexternalresolver/) | Obiekt zwrotny używany przez procedurę importu HTML do uzyskiwania odwoływanych obiektów, takich jak obrazy.<br/>            Użycie tego resolvera może stworzyć lukę bezpieczeństwa, gdy dostarczony przez klienta plik HTML spowoduje, że oprogramowanie serwera pobierze lokalny lub sieciowy plik. Należy zachować ostrożność. Zaleca się nie określać HtmlExternalResolver wcale (odczytywane będą tylko osadzone obiekty) lub utworzyć podklasę, która sprawdza, czy podany uri jest prawidłowy. |
| [`IExternalResourceResolver`](/slides/python-net/pl/aspose.slides.importing/iexternalresourceresolver/) | Interfejs zwrotny używany do rozwiązywania zewnętrznych zasobów podczas importu dokumentów Html, Svg. |
| [`IHtmlExternalResolver`](/slides/python-net/pl/aspose.slides.importing/ihtmlexternalresolver/) | Interfejs zwrotny używany przez procedurę importu HTML do uzyskiwania odwoływanych obiektów, takich jak obrazy. |
| [`PdfImportOptions`](/slides/python-net/pl/aspose.slides.importing/pdfimportoptions/) | Reprezentuje opcje importu PDF. |
