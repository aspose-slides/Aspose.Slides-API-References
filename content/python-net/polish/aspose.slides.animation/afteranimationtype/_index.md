## enumeracja AfterAnimationType

Reprezentuje typ po animacji efektu animacji.

Typ AfterAnimationType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| DO_NOT_DIM | Nie przygasa po animacji. |
| COLOR | Kolor po animacji. |
| HIDE_AFTER_ANIMATION | Ukryj po animacji |
| HIDE_ON_NEXT_MOUSE_CLICK | Ukryj po następnym kliknięciu myszy po animacji. |
