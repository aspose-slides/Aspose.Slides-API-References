## IBehavior klasa

Reprezentuje zachowanie klasy bazowej efektu.

Typ IBehavior udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`accumulate`](/slides/python-net/pl/aspose.slides.animation/ibehavior/accumulate/) | Reprezentuje, czy zachowania animacji są kumulowane.<br/>            Odczyt/zapis [`NullableBool`](/slides/python-net/pl/aspose.slides/nullablebool). |
| [`additive`](/slides/python-net/pl/aspose.slides.animation/ibehavior/additive/) | Reprezentuje, czy bieżące zachowanie animacji jest łączone z innymi działającymi animacjami.<br/>            Odczyt/zapis [`BehaviorAdditiveType`](/slides/python-net/pl/aspose.slides.animation/behavioradditivetype). |
| [`properties`](/slides/python-net/pl/aspose.slides.animation/ibehavior/properties/) | Reprezentuje właściwości zachowania.<br/>            Tylko do odczytu [`IBehaviorPropertyCollection`](/slides/python-net/pl/aspose.slides.animation/ibehaviorpropertycollection). |
| [`timing`](/slides/python-net/pl/aspose.slides.animation/ibehavior/timing/) | Reprezentuje właściwości czasu dla zachowania efektu.<br/>            Odczyt/zapis [`ITiming`](/slides/python-net/pl/aspose.slides.animation/itiming). |
