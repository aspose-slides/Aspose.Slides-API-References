## AnimateTextType enumeracja

Reprezentuje typ animowanego tekstu efektu animacji.

Typ AnimateTextType udostępnia następujące członków:

## Pola

| Pole | Opis |
| :- | :- |
| ALL_AT_ONCE | Animuj cały tekst jednocześnie. |
| BY_WORD | Animuj tekst słowo po słowie. |
| BY_LETTER | Animuj tekst znak po znaku. |
