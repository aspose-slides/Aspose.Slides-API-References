## AnimationTimeLine klasa

Reprezentuje oś czasu animacji.

Typ AnimationTimeLine udostępnia następujące członków:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`interactive_sequences`](/slides/python-net/pl/aspose.slides.animation/animationtimeline/interactive_sequences/) | Zwraca kolekcję interaktywnych sekwencji.<br/>            Ta sekwencja może zawierać tylko efekty wywoływane kliknięciem kształtu z określonym docelowym kształtem.<br/>            Tylko do odczytu [`ISequenceCollection`](/slides/python-net/pl/aspose.slides.animation/isequencecollection). |
| [`main_sequence`](/slides/python-net/pl/aspose.slides.animation/animationtimeline/main_sequence/) | Zwraca główną sekwencję, która może zawierać tylko główną kolekcję efektów.<br/>            Tylko do odczytu [`ISequence`](/slides/python-net/pl/aspose.slides.animation/isequence). |
| [`text_animation_collection`](/slides/python-net/pl/aspose.slides.animation/animationtimeline/text_animation_collection/) | Zwraca kolekcję animacji tekstu.<br/>            Tylko do odczytu [`ITextAnimationCollection`](/slides/python-net/pl/aspose.slides.animation/itextanimationcollection). |
