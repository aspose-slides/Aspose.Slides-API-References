## ITextAnimation klasa

Reprezentuje animację tekstu.

Typ ITextAnimation udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`build_type`](/slides/python-net/pl/aspose.slides.animation/itextanimation/build_type/) | Lista typów budowy (np. Paragraph 1,2,3, All at Once) animacji tekstu.<br/>            Odczyt/zapis [`ITextAnimation.build_type`](/slides/python-net/pl/aspose.slides.animation/itextanimation/build_type). |
| [`effect_animate_background_shape`](/slides/python-net/pl/aspose.slides.animation/itextanimation/effect_animate_background_shape/) | Powiązany efekt kształtu z grupą lub bez (None)<br/>            Odczyt/zapis [`IEffect`](/slides/python-net/pl/aspose.slides.animation/ieffect). |

## Metody

| Metoda | Opis |
| :- | :- |
| [`add_effect(self, effect_type, subtype, trigger_type)`](/slides/python-net/pl/aspose.slides.animation/itextanimation/add_effect/#effecttype-effectsubtype-effecttriggertype) | Dodaj nowy efekt na koniec bieżącej sekwencji do końca grupowych animacji tekstu.<br/>            Ważne tylko wtedy, gdy liczba akapitów tekstu jest równa lub większa od liczby efektów w tej grupie! |
