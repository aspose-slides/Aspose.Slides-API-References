## Klasa Timing

Reprezentuje synchronizację animacji.

Typ Timing udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`accelerate`](/slides/python-net/pl/aspose.slides.animation/timing/accelerate/) | Opisuje procent trwania efektu przyspieszającego.<br/>            Odczyt/zapis **float**. |
| [`decelerate`](/slides/python-net/pl/aspose.slides.animation/timing/decelerate/) | Opisuje procent trwania efektu zwalniającego.<br/>            Odczyt/zapis **float**. |
| [`auto_reverse`](/slides/python-net/pl/aspose.slides.animation/timing/auto_reverse/) | Opisuje, czy animacja ma być automatycznie odtwarzana w odwrotnym kierunku po<br/>            odtworzeniu jej w kierunku do przodu.<br/>            Odczyt/zapis **bool**. |
| [`duration`](/slides/python-net/pl/aspose.slides.animation/timing/duration/) | Opisuje czas trwania efektu animacji.<br/>            Odczyt/zapis **float**. |
| [`repeat_count`](/slides/python-net/pl/aspose.slides.animation/timing/repeat_count/) | Opisuje liczbę powtórzeń efektu.<br/>            Odczyt/zapis **float**. |
| [`repeat_until_end_slide`](/slides/python-net/pl/aspose.slides.animation/timing/repeat_until_end_slide/) | Ten atrybut określa, czy efekt będzie powtarzany aż do końca slajdu.<br/>             Odczyt/zapis **bool**. |
| [`repeat_until_next_click`](/slides/python-net/pl/aspose.slides.animation/timing/repeat_until_next_click/) | Ten atrybut określa, czy efekt będzie powtarzany do następnego kliknięcia.<br/>             Odczyt/zapis **bool**. |
| [`repeat_duration`](/slides/python-net/pl/aspose.slides.animation/timing/repeat_duration/) | Opisuje liczbę powtórzeń efektu.<br/>            Odczyt/zapis **float**. |
| [`restart`](/slides/python-net/pl/aspose.slides.animation/timing/restart/) | Określa, czy efekt ma się zrestartować po zakończeniu.<br/>            Odczyt/zapis [`EffectRestartType`](/slides/python-net/pl/aspose.slides.animation/effectrestarttype). |
| [`rewind`](/slides/python-net/pl/aspose.slides.animation/timing/rewind/) | Ten atrybut określa, czy efekt zostanie przewinięty po zakończeniu odtwarzania.<br/>             Odczyt/zapis **bool**. |
| [`speed`](/slides/python-net/pl/aspose.slides.animation/timing/speed/) | Określa procent przyspieszenia (lub spowolnienia) czasu.<br/>            Odczyt/zapis **float**. |
| [`trigger_delay_time`](/slides/python-net/pl/aspose.slides.animation/timing/trigger_delay_time/) | Opisuje czas opóźnienia po uruchomieniu.<br/>            Odczyt/zapis **float**. |
| [`trigger_type`](/slides/python-net/pl/aspose.slides.animation/timing/trigger_type/) | Opisuje typ wyzwalacza.<br/>            Odczyt/zapis [`EffectTriggerType`](/slides/python-net/pl/aspose.slides.animation/effecttriggertype). |
