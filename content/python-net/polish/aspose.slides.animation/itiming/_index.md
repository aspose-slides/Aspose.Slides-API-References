## ITiming klasa

Reprezentuje synchronizację animacji.

Typ ITiming udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`accelerate`](/slides/python-net/pl/aspose.slides.animation/itiming/accelerate/) | Opisuje procent przyspieszania efektu w czasie.<br/>            Odczyt/zapis **float**. |
| [`decelerate`](/slides/python-net/pl/aspose.slides.animation/itiming/decelerate/) | Opisuje procent zwalniania efektu w czasie.<br/>            Odczyt/zapis **float**. |
| [`auto_reverse`](/slides/python-net/pl/aspose.slides.animation/itiming/auto_reverse/) | Opisuje, czy automatycznie odtwarzać animację w odwrotnej kolejności po<br/>            odtworzeniu w kierunku do przodu.<br/>            Odczyt/zapis **bool**. |
| [`duration`](/slides/python-net/pl/aspose.slides.animation/itiming/duration/) | Opisuje czas trwania efektu animacji.<br/>            Odczyt/zapis **float**. |
| [`repeat_count`](/slides/python-net/pl/aspose.slides.animation/itiming/repeat_count/) | Opisuje liczbę powtórzeń efektu.<br/>            Odczyt/zapis **float**. |
| [`repeat_until_end_slide`](/slides/python-net/pl/aspose.slides.animation/itiming/repeat_until_end_slide/) | Ten atrybut określa, czy efekt będzie powtarzany do końca slajdu.<br/>             Odczyt/zapis **bool**. |
| [`repeat_until_next_click`](/slides/python-net/pl/aspose.slides.animation/itiming/repeat_until_next_click/) | Ten atrybut określa, czy efekt będzie powtarzany do następnego kliknięcia.<br/>             Odczyt/zapis **bool**. |
| [`repeat_duration`](/slides/python-net/pl/aspose.slides.animation/itiming/repeat_duration/) | Opisuje liczbę powtórzeń efektu.<br/>            Odczyt/zapis **float**. |
| [`restart`](/slides/python-net/pl/aspose.slides.animation/itiming/restart/) | Określa, czy efekt ma zostać ponownie uruchomiony po zakończeniu.<br/>            Odczyt/zapis [`EffectRestartType`](/slides/python-net/pl/aspose.slides.animation/effectrestarttype). |
| [`speed`](/slides/python-net/pl/aspose.slides.animation/itiming/speed/) | Określa procent, o który przyspieszyć (lub spowolnić) synchronizację.<br/>            Odczyt/zapis **float**. |
| [`trigger_delay_time`](/slides/python-net/pl/aspose.slides.animation/itiming/trigger_delay_time/) | Opisuje czas opóźnienia po wyzwalaczu.<br/>            Odczyt/zapis **float**. |
| [`trigger_type`](/slides/python-net/pl/aspose.slides.animation/itiming/trigger_type/) | Opisuje typ wyzwalacza.<br/>            Odczyt/zapis [`EffectTriggerType`](/slides/python-net/pl/aspose.slides.animation/effecttriggertype). |
| [`rewind`](/slides/python-net/pl/aspose.slides.animation/itiming/rewind/) | Ten atrybut określa, czy efekt zostanie cofnięty po zakończeniu odtwarzania.<br/>             Odczyt/zapis **bool**. |
