## IEffect klasa

Reprezentuje efekt animacji.

Typ IEffect udostępnia następujące elementy:

## Właściwości

| Property | Description |
| :- | :- |
| [`sequence`](/slides/python-net/pl/aspose.slides.animation/ieffect/sequence/) | Zwraca sekwencję dla efektu.<br/>            Tylko do odczytu [`ISequence`](/slides/python-net/pl/aspose.slides.animation/isequence). |
| [`text_animation`](/slides/python-net/pl/aspose.slides.animation/ieffect/text_animation/) | Zwraca animację tekstu.<br/>            Tylko do odczytu [`ITextAnimation`](/slides/python-net/pl/aspose.slides.animation/itextanimation). |
| [`preset_class_type`](/slides/python-net/pl/aspose.slides.animation/ieffect/preset_class_type/) | Definiuje klasę efektu.<br/>            Odczyt/zapis [`EffectPresetClassType`](/slides/python-net/pl/aspose.slides.animation/effectpresetclasstype). |
| [`type`](/slides/python-net/pl/aspose.slides.animation/ieffect/type/) | Definiuje typ efektu.<br/>            Odczyt/zapis [`EffectType`](/slides/python-net/pl/aspose.slides.animation/effecttype). |
| [`subtype`](/slides/python-net/pl/aspose.slides.animation/ieffect/subtype/) | Definiuje podtyp efektu.<br/>            Odczyt/zapis [`EffectSubtype`](/slides/python-net/pl/aspose.slides.animation/effectsubtype). |
| [`behaviors`](/slides/python-net/pl/aspose.slides.animation/ieffect/behaviors/) | Zwraca kolekcję zachowań dla efektu.<br/>            Odczyt/zapis [`IBehaviorCollection`](/slides/python-net/pl/aspose.slides.animation/ibehaviorcollection). |
| [`timing`](/slides/python-net/pl/aspose.slides.animation/ieffect/timing/) | Definiuje wartość czasu dla efektu.<br/>            Odczyt/zapis [`ITiming`](/slides/python-net/pl/aspose.slides.animation/itiming). |
| [`target_shape`](/slides/python-net/pl/aspose.slides.animation/ieffect/target_shape/) | Zwraca docelowy kształt dla efektu.<br/>            Tylko do odczytu [`IShape`](/slides/python-net/pl/aspose.slides/ishape). |
| [`sound`](/slides/python-net/pl/aspose.slides.animation/ieffect/sound/) | Definiuje wbudowane dźwięki dla efektu.<br/>            Odczyt/zapis [`IAudio`](/slides/python-net/pl/aspose.slides/iaudio). |
| [`stop_previous_sound`](/slides/python-net/pl/aspose.slides.animation/ieffect/stop_previous_sound/) | Ten atrybut określa, czy efekt animacji zatrzymuje poprzedni dźwięk.<br/>            Odczyt/zapis **bool**. |
| [`after_animation_type`](/slides/python-net/pl/aspose.slides.animation/ieffect/after_animation_type/) | Definiuje typ poanimacji dla efektu.<br/>            Odczyt/zapis [`IEffect.after_animation_type`](/slides/python-net/pl/aspose.slides.animation/ieffect/after_animation_type). |
| [`after_animation_color`](/slides/python-net/pl/aspose.slides.animation/ieffect/after_animation_color/) | Definiuje kolor poanimacji dla efektu.<br/>            Odczyt/zapis [`IColorFormat`](/slides/python-net/pl/aspose.slides/icolorformat). |
| [`animate_text_type`](/slides/python-net/pl/aspose.slides.animation/ieffect/animate_text_type/) | Definiuje typ animacji tekstu dla efektu.<br/>            Tekst obiektu może być animowany literą, słowem lub całością jednocześnie.<br/>            Odczyt/zapis [`IEffect.animate_text_type`](/slides/python-net/pl/aspose.slides.animation/ieffect/animate_text_type). |
| [`delay_between_text_parts`](/slides/python-net/pl/aspose.slides.animation/ieffect/delay_between_text_parts/) | Definiuje opóźnienie między częściami animowanego tekstu (słowa lub litery).<br/>            Dodatnia wartość określa procent czasu trwania efektu.<br/>            Ujemna wartość określa opóźnienie w sekundach.<br/>            Odczyt/zapis **float**. |
