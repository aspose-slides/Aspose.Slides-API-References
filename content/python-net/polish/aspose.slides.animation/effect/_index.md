## Klasa Effect

Reprezentuje efekt animacji.

Typ Effect udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`sequence`](/slides/python-net/pl/aspose.slides.animation/effect/sequence/) | Zwraca sekwencję dla efektu.<br/>            Tylko odczyt [`ISequence`](/slides/python-net/pl/aspose.slides.animation/isequence). |
| [`text_animation`](/slides/python-net/pl/aspose.slides.animation/effect/text_animation/) | TextAnimation<br/>            Tylko odczyt [`ITextAnimation`](/slides/python-net/pl/aspose.slides.animation/itextanimation). |
| [`preset_class_type`](/slides/python-net/pl/aspose.slides.animation/effect/preset_class_type/) | Definiuje klasę efektu.<br/>            Odczyt/zapis [`EffectPresetClassType`](/slides/python-net/pl/aspose.slides.animation/effectpresetclasstype). |
| [`type`](/slides/python-net/pl/aspose.slides.animation/effect/type/) | Definiuje typ efektu.<br/>            Odczyt/zapis [`EffectType`](/slides/python-net/pl/aspose.slides.animation/effecttype). |
| [`subtype`](/slides/python-net/pl/aspose.slides.animation/effect/subtype/) | Definiuje podtyp efektu.<br/>            Odczyt/zapis [`EffectSubtype`](/slides/python-net/pl/aspose.slides.animation/effectsubtype). |
| [`behaviors`](/slides/python-net/pl/aspose.slides.animation/effect/behaviors/) | Zwraca kolekcję zachowań dla efektu.<br/>            Odczyt/zapis [`IBehaviorCollection`](/slides/python-net/pl/aspose.slides.animation/ibehaviorcollection). |
| [`timing`](/slides/python-net/pl/aspose.slides.animation/effect/timing/) | Definiuje wartość czasu dla efektu.<br/>            Odczyt/zapis [`ITiming`](/slides/python-net/pl/aspose.slides.animation/itiming). |
| [`target_shape`](/slides/python-net/pl/aspose.slides.animation/effect/target_shape/) | Zwraca docelowy kształt dla efektu.<br/>            Tylko odczyt [`IShape`](/slides/python-net/pl/aspose.slides/ishape). |
| [`sound`](/slides/python-net/pl/aspose.slides.animation/effect/sound/) | Definiuje wbudowane dźwięki dla efektu.<br/>            Odczyt/zapis [`IAudio`](/slides/python-net/pl/aspose.slides/iaudio). |
| [`stop_previous_sound`](/slides/python-net/pl/aspose.slides.animation/effect/stop_previous_sound/) | Ten atrybut określa, czy efekt animacji zatrzymuje poprzedni dźwięk.<br/>            Odczyt/zapis **bool**. |
| [`after_animation_type`](/slides/python-net/pl/aspose.slides.animation/effect/after_animation_type/) | Definiuje typ animacji po zakończeniu efektu.<br/>            Odczyt/zapis [`Effect.after_animation_type`](/slides/python-net/pl/aspose.slides.animation/effect/after_animation_type). |
| [`after_animation_color`](/slides/python-net/pl/aspose.slides.animation/effect/after_animation_color/) | Definiuje kolor animacji po zakończeniu efektu.<br/>            Odczyt/zapis [`IColorFormat`](/slides/python-net/pl/aspose.slides/icolorformat). |
| [`animate_text_type`](/slides/python-net/pl/aspose.slides.animation/effect/animate_text_type/) | Definiuje typ animacji tekstu dla efektu. <br/>            Tekst kształtu może być animowany literą, słowem lub całościowo.<br/>            Odczyt/zapis [`Effect.animate_text_type`](/slides/python-net/pl/aspose.slides.animation/effect/animate_text_type). |
| [`delay_between_text_parts`](/slides/python-net/pl/aspose.slides.animation/effect/delay_between_text_parts/) | Definiuje opóźnienie pomiędzy częściami animowanego tekstu (słowa lub litery).<br/>            Wartość dodatnia określa procent czasu trwania efektu.<br/>            Wartość ujemna określa opóźnienie w sekundach.<br/>            Odczyt/zapis **float**. |
