## IMotionEffect klasa

Reprezentuje zachowanie efektu ruchu.

Typ IMotionEffect udostępnia następujące członki:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`from_address`](/slides/python-net/pl/aspose.slides.animation/imotioneffect/from_address/) | Określa współrzędną x/y, od której zaczyna się animacja (w procentach). <br/>            Odczyt/zapis **aspose.slides.PointF**. |
| [`to`](/slides/python-net/pl/aspose.slides.animation/imotioneffect/to/) | Określa docelową lokalizację dla efektu ruchu animacji (w procentach).<br/>            Odczyt/zapis **aspose.slides.PointF**. |
| [`by`](/slides/python-net/pl/aspose.slides.animation/imotioneffect/by/) | Opisuje względną wartość offsetu dla animacji (w procentach).<br/>            Odczyt/zapis **aspose.slides.PointF**. |
| [`rotation_center`](/slides/python-net/pl/aspose.slides.animation/imotioneffect/rotation_center/) | Opisuje środek obrotu używany do obrotu ścieżki ruchu o kąt X.<br/>            Odczyt/zapis **aspose.slides.PointF**. |
| [`origin`](/slides/python-net/pl/aspose.slides.animation/imotioneffect/origin/) | Określa, względem czego znajduje się początek ścieżki ruchu, np. układu slajdu,<br/>            lub elementu nadrzędnego.<br/>            Odczyt/zapis [`MotionOriginType`](/slides/python-net/pl/aspose.slides.animation/motionorigintype). |
| [`path`](/slides/python-net/pl/aspose.slides.animation/imotioneffect/path/) | Określa prymityw ścieżki, po którym następują współrzędne ruchu animacji.<br/>            Odczyt/zapis [`IMotionPath`](/slides/python-net/pl/aspose.slides.animation/imotionpath). |
| [`path_edit_mode`](/slides/python-net/pl/aspose.slides.animation/imotioneffect/path_edit_mode/) | Określa, jak ścieżka ruchu przemieszcza się, gdy kształt jest przesuwany.<br/>            Odczyt/zapis [`MotionPathEditMode`](/slides/python-net/pl/aspose.slides.animation/motionpatheditmode). |
| [`angle`](/slides/python-net/pl/aspose.slides.animation/imotioneffect/angle/) | Opisuje względny kąt ścieżki ruchu.<br/>            Odczyt/zapis **float**. |
