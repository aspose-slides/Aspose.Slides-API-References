## BuildType enumeracja

Określa, jak tekst będzie wyświetlany na kształcie podczas animacji.

Typ BuildType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| AS_ONE_OBJECT | Z zawierającym kształtem. |
| ALL_PARAGRAPHS_AT_ONCE | Wszystkie akapity. |
| BY_LEVEL_PARAGRAPHS1 | Według grup akapitów o głębokości 1. |
| BY_LEVEL_PARAGRAPHS2 | Według grup akapitów o głębokości 2. |
| BY_LEVEL_PARAGRAPHS3 | Według grup akapitów o głębokości 3. |
| BY_LEVEL_PARAGRAPHS4 | Według grup akapitów o głębokości 4. |
| BY_LEVEL_PARAGRAPHS5 | Według grup akapitów o głębokości 5. |
