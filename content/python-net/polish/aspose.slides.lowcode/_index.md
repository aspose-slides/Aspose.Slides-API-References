Zawiera klasy i metody służące do obsługi złożonych operacji ogólnych w sposób low code.
## Klasy

| Klasa | Opis |
| :- | :- |
| [`Collect`](/slides/python-net/pl/aspose.slides.lowcode/collect/) | Reprezentuje grupę metod przeznaczonych do zbierania obiektów modelu różnych typów z [`Presentation`](/slides/python-net/pl/aspose.slides/presentation). |
| [`Compress`](/slides/python-net/pl/aspose.slides.lowcode/compress/) | Reprezentuje grupę metod przeznaczonych do kompresowania [`Presentation`](/slides/python-net/pl/aspose.slides/presentation). |
| [`Convert`](/slides/python-net/pl/aspose.slides.lowcode/convert/) | Reprezentuje grupę metod przeznaczonych do konwertowania [`Presentation`](/slides/python-net/pl/aspose.slides/presentation). |
| [`ForEach`](/slides/python-net/pl/aspose.slides.lowcode/foreach/) | Reprezentuje grupę metod przeznaczonych do iteracji po różnych obiektach modelu [`Presentation`](/slides/python-net/pl/aspose.slides/presentation).<br/>            Metody te mogą być przydatne, jeśli musisz iterować i zmieniać formatowanie lub zawartość niektórych elementów Presentation,<br/>             np. zmienić formatowanie każdego fragmentu. |
| [`Merger`](/slides/python-net/pl/aspose.slides.lowcode/merger/) | Reprezentuje grupę metod służących do scalania prezentacji PowerPoint o tym samym formacie w jeden plik. |
