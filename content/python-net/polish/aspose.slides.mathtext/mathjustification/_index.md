## Wyliczenie MathJustification

Określa justowanie paragrafu matematycznego (serii sąsiadujących wystąpień tekstu matematycznego w tym samym paragrafie)

Typ MathJustification udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| LEFT_JUSTIFIED | Wyrównaj tekst matematyczny do lewej |
| RIGHT_JUSTIFIED | Wyrównaj tekst matematyczny do prawej |
| CENTERED | Wyrównaj tekst matematyczny do środka |
| CENTERED_AS_GROUP | Wyśrodkuj na stronie całą grupę bloków matematycznych jako jedną jednostkę.<br/>            Oznacza to, że wystąpienia tekstu matematycznego mogą być wyrównane względem siebie, <br/>            ale cała grupa tekstu matematycznego jest wyśrodkowana jako całość. |
