## MathRowSpacingRule wyliczenie

Typ pionowego odstępu pomiędzy kolumnami w macierzy lub tablicy

Typ MathRowSpacingRule udostępnia następujące członkowie:

## Pola

| Pole | Opis |
| :- | :- |
| SINGLE_LINE_GAP | pojedynczy odstęp linii |
| ONE_AND_A_HALF_LINE_GAP | jedna i pół linii |
| TWO_LINE_GAP | dwa odstępy linii |
| EXACTLY | dokładnie (opiera się na wartości właściwości RowSpacing, mierzonej w punktach) |
| MULTIPLE | wielokrotnie (opiera się na wartości właściwości RowSpacing, mierzonej w liniach) |
