## Wyliczenie MathLimitLocations

Położenie limitów (indeks dolny/górny) w operatorach n-arnych.

Typ MathLimitLocations udostępnia następujące elementy:

## Pola

| Field | Description |
| :- | :- |
| NOT_DEFINED | Nie określono |
| UNDER_OVER | Limity rysowane są u góry i u dołu symbolu operatora |
| SUBSCRIPT_SUPERSCRIPT | Limity rysowane są jako indeks dolny i górny |
