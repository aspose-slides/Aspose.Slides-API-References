## IMathBorderBox klasa

Rysuje prostokątną lub inną ramkę wokół elementu IMathElement.

Typ IMathBorderBox udostępnia następujące członków:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`base`](/slides/python-net/pl/aspose.slides.mathtext/imathborderbox/base/) | Argument bazowy |
| [`hide_top`](/slides/python-net/pl/aspose.slides.mathtext/imathborderbox/hide_top/) | Ukryj górną krawędź (wartość domyślna to false) - określa, czy górna krawędź ramki jest ukryta lub widoczna. |
| [`hide_bottom`](/slides/python-net/pl/aspose.slides.mathtext/imathborderbox/hide_bottom/) | Ukryj dolną krawędź (wartość domyślna to false) - określa, czy dolna krawędź ramki jest ukryta lub widoczna. |
| [`hide_left`](/slides/python-net/pl/aspose.slides.mathtext/imathborderbox/hide_left/) | Ukryj lewą krawędź (wartość domyślna to false) - określa, czy lewa krawędź ramki jest ukryta lub widoczna. |
| [`hide_right`](/slides/python-net/pl/aspose.slides.mathtext/imathborderbox/hide_right/) | Ukryj prawą krawędź (wartość domyślna to false) - określa, czy prawa krawędź ramki jest ukryta lub widoczna. |
| [`strikethrough_horizontal`](/slides/python-net/pl/aspose.slides.mathtext/imathborderbox/strikethrough_horizontal/) | Przekreślenie poziome (wartość domyślna to false) - określa, czy pozioma linia przekreślająca jest ukryta lub widoczna. |
| [`strikethrough_vertical`](/slides/python-net/pl/aspose.slides.mathtext/imathborderbox/strikethrough_vertical/) | Przekreślenie pionowe (wartość domyślna to false) - określa, czy pionowa linia przekreślająca jest ukryta lub widoczna. |
| [`strikethrough_bottom_left_to_top_right`](/slides/python-net/pl/aspose.slides.mathtext/imathborderbox/strikethrough_bottom_left_to_top_right/) | Przekreślenie od lewego dolnego do prawego górnego (wartość domyślna to false).<br/> Określa, czy przekątną linię przekreślającą od lewego dolnego rogu do prawego górnego rogu ramki jest ukryta lub widoczna. |
| [`strikethrough_top_left_to_bottom_right`](/slides/python-net/pl/aspose.slides.mathtext/imathborderbox/strikethrough_top_left_to_bottom_right/) | Przekreślenie od lewego górnego do prawego dolnego (wartość domyślna to false).<br/> Określa, czy przekątną linię przekreślającą od lewego górnego rogu do prawego dolnego rogu ramki jest ukryta lub widoczna. |
