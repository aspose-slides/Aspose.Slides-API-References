## IMathGroupingCharacter klasa

Określa znak grupujący nad lub pod wyrażeniem, zazwyczaj w celu podkreślenia zależności pomiędzy elementami

Typ IMathGroupingCharacter udostępnia następujące elementy:

## Właściwości

| Property | Description |
| :- | :- |
| [`base`](/slides/python-net/pl/aspose.slides.mathtext/imathgroupingcharacter/base/) | Argument bazowy |
| [`character`](/slides/python-net/pl/aspose.slides.mathtext/imathgroupingcharacter/character/) | Znak grupujący<br/>            Domyślna wartość: U+23DF (BOTTOM CURLY BRACKET) |
| [`position`](/slides/python-net/pl/aspose.slides.mathtext/imathgroupingcharacter/position/) | Pozycja znaku grupującego.<br/>            Domyślnie: Bottom |
| [`vertical_justification`](/slides/python-net/pl/aspose.slides.mathtext/imathgroupingcharacter/vertical_justification/) | Wyrównanie pionowe znaku grupującego.<br/>            Określa wyrównanie obiektu względem linii bazowej.<br/>            Na przykład, gdy znak grupujący znajduje się nad obiektem, <br/>            VerticalJustification of Top signifies that the top of the object falls on the baseline;<br/>            gdy VerticalJustification jest ustawione na Bottom, dolna krawędź obiektu znajduje się na linii bazowej<br/>            Domyślnie: Bottom dla Position=Top, oraz Top dla Position=Bottom |
