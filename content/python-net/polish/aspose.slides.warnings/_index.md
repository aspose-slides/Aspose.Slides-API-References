Zawiera klasy, które reprezentują różne rodzaje ostrzeżeń
## Klasy

| Klasa | Opis |
| :- | :- |
| [`IKnownIssueWarningInfo`](/slides/python-net/pl/aspose.slides.warnings/iknownissuewarninginfo/) | Reprezentuje ostrzeżenie o znanym problemie, który nie zostanie w najbliższej przyszłości naprawiony. |
| [`INotImplementedWarningInfo`](/slides/python-net/pl/aspose.slides.warnings/inotimplementedwarninginfo/) | Reprezentuje ostrzeżenie o znanej niezaimplementowanej funkcji, która nie zostanie w najbliższej przyszłości zaimplementowana. |
| [`IObsoletePresLockingBehaviorWarningInfo`](/slides/python-net/pl/aspose.slides.warnings/iobsoletepreslockingbehaviorwarninginfo/) | To ostrzeżenie wskazuje, że używane jest przestarzałe zachowanie blokowania prezentacji. |
| [`IPresentationSignedWarningInfo`](/slides/python-net/pl/aspose.slides.warnings/ipresentationsignedwarninginfo/) | To ostrzeżenie wskazuje, że odczytywana prezentacja ma sygnaturę <br/>            i ta sygnatura zostanie usunięta podczas przetwarzania. |
| [`IWarningCallback`](/slides/python-net/pl/aspose.slides.warnings/iwarningcallback/) | Interfejs dla klas, które otrzymują ostrzeżenie |
| [`IWarningInfo`](/slides/python-net/pl/aspose.slides.warnings/iwarninginfo/) | Reprezentuje bazowy interfejs dla wszystkich ostrzeżeń. |

## Enumeracje

| Wyliczenie | Opis |
| :- | :- |
| [`ReturnAction`](/slides/python-net/pl/aspose.slides.warnings/returnaction/) | Reprezentuje opcje decyzji wywołania zwrotnego ostrzeżenia. |
| [`WarningType`](/slides/python-net/pl/aspose.slides.warnings/warningtype/) | Reprezentuje typ ostrzeżenia. |
