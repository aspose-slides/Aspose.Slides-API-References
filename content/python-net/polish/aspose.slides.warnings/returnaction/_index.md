## enumeracja ReturnAction

Reprezentuje opcje decyzji wywołania ostrzeżenia.

Typ ReturnAction udostępnia następujące członki:

## Pola

| Pole | Opis |
| :- | :- |
| CONTINUE | Operacja powinna być kontynuowana. |
| ABORT | Operacja powinna zostać przerwana. |
