## WarningType enumeracja

Reprezentuje typ ostrzeżenia.

Typ WarningType udostępnia następujące elementy:

## Pola

| Pole | Opis |
| :- | :- |
| SOURCE_FILE_CORRUPTION | Wykryto problem w dokumencie źródłowym, co sprawia, że prawdopodobnie dokument nie będzie można otworzyć, jeśli zostanie zapisany w jego pierwotnym formacie. |
| DATA_LOSS | Tekst/wykres/obraz lub inne dane będą całkowicie brakować albo w drzewie dokumentu po załadowaniu, albo w utworzonym dokumencie po zapisaniu. |
| MAJOR_FORMATTING_LOSS | Znaczna utrata formatowania. |
| MINOR_FORMATTING_LOSS | Mała utrata formatowania. |
| COMPATIBILITY_ISSUE | Jest to znany problem, który uniemożliwi otworzenie dokumentu przez niektóre przeglądarki lub wcześniejsze wersje przeglądarek. |
| UNEXPECTED_CONTENT | Niektóre treści w dokumencie źródłowym nie mogły zostać rozpoznane (tj. nie są obsługiwane), co może powodować problemy lub nie, oraz może skutkować utratą danych lub formatowania. |
