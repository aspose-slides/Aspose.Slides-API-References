## IWarningInfo klasa

Reprezentuje podstawowy interfejs dla wszystkich ostrzeżeń.

Typ IWarningInfo udostępnia następujące elementy:

## Właściwości

| Właściwość | Opis |
| :- | :- |
| [`warning_type`](/slides/python-net/pl/aspose.slides.warnings/iwarninginfo/warning_type/) | Zwraca typ ostrzeżenia.<br/>            Tylko do odczytu [`IWarningInfo.warning_type`](/slides/python-net/pl/aspose.slides.warnings/iwarninginfo/warning_type). |
| [`description`](/slides/python-net/pl/aspose.slides.warnings/iwarninginfo/description/) | Zwraca opis ostrzeżenia w formie czytelnej dla człowieka.<br/>            Tylko do odczytu **str**. |

## Metody

| Metoda | Opis |
| :- | :- |
| [`send_warning(self, receiver)`](/slides/python-net/pl/aspose.slides.warnings/iwarninginfo/send_warning/#iwarningcallback) | Jeśli odbiorca nie jest None, kończy ostrzeżenie do wskazanego odbiorcy i zgłasza <br/>            AbortRequestedException, jeśli odbiorca zdecydował przerwać operację. |
