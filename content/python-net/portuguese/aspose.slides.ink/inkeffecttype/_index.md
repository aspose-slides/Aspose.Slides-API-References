## InkEffectType enumeração

Especifica um conjunto de efeitos visuais predefinidos para a renderização de tinta.  
Cada efeito corresponde a uma textura ou imagem que simula uma aparência estilizada de tinta.  
Esses valores podem ser usados para personalizar o estilo visual dos traços digitais de tinta durante a renderização.

O tipo InkEffectType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| NOT_DEFINED | O efeito não está definido ou é desconhecido. Este valor pode ser usado como padrão ou reserva. |
| BRONZE | Uma textura metálica quente, acastanhada, que se assemelha a tinta de bronze. |
| GALAXY | Uma textura colorida e cintilante que se assemelha a uma galáxia, com tons cósmicos. |
| GOLD | Uma textura metálica dourada e brilhante que confere aos traços de tinta uma aparência luxuosa. |
| LAVA | Uma textura ígnea que se assemelha a lava fundida, com tons vermelhos e laranjas. |
| OCEAN | Uma textura profunda azul, semelhante a fluido, que imita ondas oceânicas ou tinta à base de água. |
| RAINBOW_GLITTER | Um efeito de glitter arco-íris colorido e cintilante usado para traços de tinta festivos ou vibrantes. |
| ROSE_GOLD | Uma combinação suave de rosa e dourado, semelhante ao rose gold, para traços de tinta elegantes. |
| SILVER | Uma textura metálica prata fria que simula tinta prata clássica. |
