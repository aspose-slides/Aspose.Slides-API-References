## InkTrace classe

Representa um objeto Trace.
            Um elemento Trace é usado para registrar os dados capturados pelo digitalizador. 
            Ele contém uma sequência de pontos codificados de acordo com a especificação fornecida pelo objeto InkTraceFormat.

O tipo InkTrace expõe os seguintes membros:

## Propriedades

| :- | :- |
| [`brush`](/slides/python-net/pt/aspose.slides.ink/inktrace/brush/) | Obtém Brush para o IInkLine [`IInkBrush`](/slides/python-net/pt/aspose.slides.ink/iinkbrush)<br/>            Somente leitura. |
