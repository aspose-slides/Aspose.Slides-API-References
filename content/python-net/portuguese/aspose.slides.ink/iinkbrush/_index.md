## IInkBrush classe

Representa o pincel de traço.

O tipo IInkBrush expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`color`](/slides/python-net/pt/aspose.slides.ink/iinkbrush/color/) | Obtém ou define a cor do pincel para uma linha. |
| [`size`](/slides/python-net/pt/aspose.slides.ink/iinkbrush/size/) | Obtém ou define o tamanho do pincel para uma linha em pontos. |
| [`ink_effect`](/slides/python-net/pt/aspose.slides.ink/iinkbrush/ink_effect/) | Obtém o tipo de efeito de tinta (por exemplo, Galaxy, Gold, Silver) que define o estilo visual do traço de tinta.<br/>            O valor é analisado a partir da propriedade do pincel "inkEffects". Se nenhum efeito reconhecido for especificado,<br/>            [`InkEffectType.NOT_DEFINED`](/slides/python-net/pt/aspose.slides.ink/inkeffecttype/NOT_DEFINED) é retornado. |
