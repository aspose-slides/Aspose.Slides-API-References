## ChartThemeManager classe

Fornece acesso ao tema de gráfico substituído.

**Herança:**[`ChartThemeManager`](/slides/python-net/pt/aspose.slides.theme/chartthememanager) → [`BaseOverrideThemeManager`](/slides/python-net/pt/aspose.slides.theme/baseoverridethememanager) → [`BaseThemeManager`](/slides/python-net/pt/aspose.slides.theme/basethememanager)

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`override_theme`](/slides/python-net/pt/aspose.slides.theme/chartthememanager/override_theme/) | Retorna o objeto de tema substituto.<br/>            Leitura/gravação [`IOverrideTheme`](/slides/python-net/pt/aspose.slides.theme/ioverridetheme). |
