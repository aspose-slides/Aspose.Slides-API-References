## IOverrideThemeManager classe

Fornece acesso a diferentes tipos de temas sobrescritos.

O tipo IOverrideThemeManager expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`is_override_theme_enabled`](/slides/python-net/pt/aspose.slides.theme/ioverridethememanager/is_override_theme_enabled/) | Determina se OverrideTheme substitui o tema efetivo herdado ou não.<br/>            Para habilitar OverrideTheme para sobrescrita, use os métodos OverrideTheme.Init*().<br/>            Para desabilitar OverrideTheme de sobrescrever, use o método OverrideTheme.Clear().<br/>            Somente leitura **bool**. |
| [`override_theme`](/slides/python-net/pt/aspose.slides.theme/ioverridethememanager/override_theme/) | Retorna o objeto de tema sobrescrito.<br/>            Leitura/gravação [`IOverrideTheme`](/slides/python-net/pt/aspose.slides.theme/ioverridetheme). |
