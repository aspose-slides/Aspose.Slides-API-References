## IFontSchemeEffectiveData classe

Objeto imutável que contém propriedades efetivas do esquema de fontes.

O tipo IFontSchemeEffectiveData expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`minor`](/slides/python-net/pt/aspose.slides.theme/ifontschemeeffectivedata/minor/) | Retorna a coleção de fontes para a parte "body" do slide.<br/>            Somente leitura [`IFontsEffectiveData`](/slides/python-net/pt/aspose.slides/ifontseffectivedata). |
| [`major`](/slides/python-net/pt/aspose.slides.theme/ifontschemeeffectivedata/major/) | Retorna a coleção de fontes para a parte "heading" do slide.<br/>            Somente leitura [`IFontsEffectiveData`](/slides/python-net/pt/aspose.slides/ifontseffectivedata). |
| [`name`](/slides/python-net/pt/aspose.slides.theme/ifontschemeeffectivedata/name/) | Retorna o nome do esquema de fontes.<br/>            Somente leitura **str**. |


### Observações

Esta interface é usada como parte de [`IThemeEffectiveData`](/slides/python-net/pt/aspose.slides.theme/ithemeeffectivedata).
