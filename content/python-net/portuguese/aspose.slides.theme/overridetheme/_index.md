## OverrideTheme classe

Representa um tema de substituição.

**Herança:**[`OverrideTheme`](/slides/python-net/pt/aspose.slides.theme/overridetheme) → [`Theme`](/slides/python-net/pt/aspose.slides.theme/theme)

O tipo OverrideTheme expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`color_scheme`](/slides/python-net/pt/aspose.slides.theme/overridetheme/color_scheme/) | Retorna o esquema de cores.<br/>            Somente leitura [`IColorScheme`](/slides/python-net/pt/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/pt/aspose.slides.theme/overridetheme/font_scheme/) | Retorna o esquema de fontes.<br/>            Somente leitura [`IFontScheme`](/slides/python-net/pt/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/pt/aspose.slides.theme/overridetheme/format_scheme/) | Retorna o esquema de formato de forma.<br/>            Somente leitura [`IFormatScheme`](/slides/python-net/pt/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/pt/aspose.slides.theme/overridetheme/presentation/) | Retorna a apresentação principal.<br/>            Somente leitura [`IPresentation`](/slides/python-net/pt/aspose.slides/ipresentation). |
| [`is_empty`](/slides/python-net/pt/aspose.slides.theme/overridetheme/is_empty/) | Um valor verdadeiro significa que ColorScheme, FontScheme, FormatScheme são None e qualquer substituição com este objeto de tema está desativada.<br/>            Somente leitura **bool**. |
