## MasterTheme classe

Representa um tema mestre.

**Herança:**[`MasterTheme`](/slides/python-net/pt/aspose.slides.theme/mastertheme) → [`Theme`](/slides/python-net/pt/aspose.slides.theme/theme)

O tipo MasterTheme expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`color_scheme`](/slides/python-net/pt/aspose.slides.theme/mastertheme/color_scheme/) | Retorna o esquema de cores.<br/>            Somente leitura [`IColorScheme`](/slides/python-net/pt/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/pt/aspose.slides.theme/mastertheme/font_scheme/) | Retorna o esquema de fontes.<br/>            Somente leitura [`IFontScheme`](/slides/python-net/pt/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/pt/aspose.slides.theme/mastertheme/format_scheme/) | Retorna o esquema de formato de forma.<br/>            Somente leitura [`IFormatScheme`](/slides/python-net/pt/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/pt/aspose.slides.theme/mastertheme/presentation/) | Retorna a apresentação pai.<br/>            Somente leitura [`IPresentation`](/slides/python-net/pt/aspose.slides/ipresentation). |
| [`extra_color_schemes`](/slides/python-net/pt/aspose.slides.theme/mastertheme/extra_color_schemes/) | Retorna a coleção de esquemas de cores adicionais.<br/>            Esses esquemas não afetam a aparência da apresentação, podem ser selecionados como esquema de cores principal para um slide.<br/>            Somente leitura [`IExtraColorSchemeCollection`](/slides/python-net/pt/aspose.slides.theme/iextracolorschemecollection). |
| [`name`](/slides/python-net/pt/aspose.slides.theme/mastertheme/name/) | Retorna o nome de um tema.<br/>            Leitura/gravação **str**. |
