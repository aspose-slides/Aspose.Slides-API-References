| [`ExternalResourceResolver`](/slides/python-net/pt/aspose.slides.importing/externalresourceresolver/) | Classe de retorno de chamada usada para resolver recursos externos durante a importação de documentos Html e Svg.<br/>            Usar este resolvedor pode criar uma vulnerabilidade quando um arquivo HTML ou Svg fornecido pelo cliente faz o software do servidor obter um arquivo local ou de rede. Use com cautela. Recomenda-se não especificar ExternalResourceResolver (apenas objetos incorporados serão lidos) ou criar alguma subclasse que verifique se o uri especificado é válido. |

Use com cautela. Recomenda-se não especificar HtmlExternalResolver (apenas objetos incorporados serão lidos) ou criar alguma subclasse que verifique se o uri especificado é válido. |
