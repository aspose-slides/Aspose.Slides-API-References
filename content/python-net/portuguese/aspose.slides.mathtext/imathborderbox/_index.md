## IMathBorderBox classe

Desenha um retângulo ou outra borda ao redor do IMathElement.

O tipo IMathBorderBox expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`base`](/slides/python-net/pt/aspose.slides.mathtext/imathborderbox/base/) | Argumento base |
| [`hide_top`](/slides/python-net/pt/aspose.slides.mathtext/imathborderbox/hide_top/) | Ocultar borda superior (default is false) - especifica o estado oculto ou exibido da borda superior da caixa de borda. |
| [`hide_bottom`](/slides/python-net/pt/aspose.slides.mathtext/imathborderbox/hide_bottom/) | Ocultar borda inferior (default is false) - especifica o estado oculto ou exibido da borda inferior da caixa de borda. |
| [`hide_left`](/slides/python-net/pt/aspose.slides.mathtext/imathborderbox/hide_left/) | Ocultar borda esquerda (default is false) - especifica o estado oculto ou exibido da borda esquerda da caixa de borda. |
| [`hide_right`](/slides/python-net/pt/aspose.slides.mathtext/imathborderbox/hide_right/) | Ocultar borda direita (default is false) - especifica o estado oculto ou exibido da borda direita da caixa de borda. |
| [`strikethrough_horizontal`](/slides/python-net/pt/aspose.slides.mathtext/imathborderbox/strikethrough_horizontal/) | Risco horizontal (default is false) - especifica o estado oculto ou exibido de uma linha horizontal riscada. |
| [`strikethrough_vertical`](/slides/python-net/pt/aspose.slides.mathtext/imathborderbox/strikethrough_vertical/) | Risco vertical (default is false) - especifica o estado oculto ou exibido de uma linha vertical riscada. |
| [`strikethrough_bottom_left_to_top_right`](/slides/python-net/pt/aspose.slides.mathtext/imathborderbox/strikethrough_bottom_left_to_top_right/) | Risco da diagonal inferior-esquerda para superior-direita (default is false).<br/>            Especifica o estado oculto ou exibido de uma linha diagonal riscada do canto inferior esquerdo ao canto superior direito da caixa de borda. |
| [`strikethrough_top_left_to_bottom_right`](/slides/python-net/pt/aspose.slides.mathtext/imathborderbox/strikethrough_top_left_to_bottom_right/) | Risco da diagonal superior-esquerda para inferior-direita (default is false).<br/>            Especifica o estado oculto ou exibido de uma linha diagonal riscada do canto superior esquerdo ao canto inferior direito da caixa de borda. |
