## row_spacing propriedade
Spacing between rows of an array
            É usado apenas quando RowSpacingRule está definido como 3 Exactly, caso em que a unidade de medida é points 
            ou Multiple, caso em que a unidade de medida é half-lines.
            Padrão: 0
