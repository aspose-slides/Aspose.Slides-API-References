## MathJustification enumeração

Especifica a justificação do parágrafo de matemática (uma série de instâncias adjacentes de texto matemático dentro do mesmo parágrafo)

O tipo MathJustification expõe os seguintes membros:

## Campos

| Field | Description |
| :- | :- |
| LEFT_JUSTIFIED | Alinha o texto matemático à esquerda |
| RIGHT_JUSTIFIED | Alinha o texto matemático à direita |
| CENTERED | Alinha o texto matemático ao centro |
| CENTERED_AS_GROUP | Centraliza na página todo o grupo de blocos de matemática como uma única unidade.<br/>            Isso significa que as instâncias de texto matemático podem ser alinhadas entre si, <br/>            mas todo o grupo de texto matemático é centralizado como um todo. |
