## MathSpacingRules enumeração

Tipos de espaço (espaçamento horizontal) entre colunas de uma matriz

O tipo MathSpacingRules expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| SINGLE_SPACING_GAP | Único (1 em para colunas ou 1 linha para linhas) |
| ONE_AND_HALF_SPACING_GAP | Um e meio (1,5 em para colunas ou 1,5 linhas para linhas) |
| DOUBLE_SPACING_GAP | Espaçamento duplo (2 em para colunas ou 2 linhas para linhas) |
| EXACTLY | Valor exato<br/>            Para colunas, baseia-se no valor de ColumnGap, medido em twips<br/>            Para linhas, baseia-se no valor de RowGap, medido em twips |
| MULTIPLE | Múltiplo<br/>            Para colunas, baseia-se no valor de ColumnGap, medido em incrementos de 0,5 em<br/>            Para linhas, baseia-se no valor de RowGap, medido em linhas |
