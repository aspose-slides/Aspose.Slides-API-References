## MathRowSpacingRule enumeração

O tipo de espaçamento vertical entre colunas em uma matriz ou array

O tipo MathRowSpacingRule expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| SINGLE_LINE_GAP | espaço de linha única |
| ONE_AND_A_HALF_LINE_GAP | espaço de linha e meia |
| TWO_LINE_GAP | espaço de duas linhas |
| EXACTLY | Exatamente (dependendo do valor da propriedade RowSpacing, medido em pontos) |
| MULTIPLE | Múltiplo (dependendo do valor da propriedade RowSpacing, medido em linhas) |
