## IMathElementCollection classe

Representa uma coleção de elementos matemáticos (MathElement).

O tipo IMathElementCollection expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`count`](/slides/python-net/pt/aspose.slides.mathtext/imathelementcollection/count/) | Obtém o número de elementos realmente contidos na coleção.<br/>            Somente leitura **int**. |

Obtém o elemento no índice especificado.
            Somente leitura [`IMathElement`](/slides/python-net/pt/aspose.slides.mathtext/imathelement).
