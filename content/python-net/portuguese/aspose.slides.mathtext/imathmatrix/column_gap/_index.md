## column_gap propriedade
O valor do espaçamento horizontal entre colunas de uma matriz;
            Se o ColumnGapRule for definido como 3 ("Exactly"), então a unidade é interpretada como twips (1/20 de ponto)
            Se o ColumnGapRule for definido como 4 ("Multiple"), então a unidade é interpretada como número de incrementos de 0.5 em.
            Em outros casos, ignorado.
            Padrão: 0
