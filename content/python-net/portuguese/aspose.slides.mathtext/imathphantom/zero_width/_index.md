## zero_width propriedade
Obtém ou define um valor que indica se a largura do elemento base 
            deve ser tratada como zero.


### Observações

Quando `true`, o phantom não reserva espaço horizontal 
            para sua base. Corresponde ao atributo OMML `m:zeroWid`.
