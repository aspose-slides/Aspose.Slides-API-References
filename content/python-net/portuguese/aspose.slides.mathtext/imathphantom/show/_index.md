## mostrar propriedade
Obtém ou define um valor que indica se o elemento base é exibido.

### Observações

Quando `false`, o elemento base está oculto, mas ainda pode ocupar espaço dependendo de outras configurações fantasma. Corresponde ao atributo OMML `m:show`.
