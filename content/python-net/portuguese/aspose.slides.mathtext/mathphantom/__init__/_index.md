## __init__(self, element) {#imathelement}
Inicializa uma nova instância da classe [`MathPhantom`](/slides/python-net/pt/aspose.slides.mathtext/mathphantom) usando o elemento matemático base especificado.

```python
def __init__(self, element):
    ...
```

| Parâmetro | Tipo | Descrição |
| :- | :- | :- |
| element | [`IMathElement`](/slides/python-net/pt/aspose.slides.mathtext/imathelement) | O [`IMathElement`](/slides/python-net/pt/aspose.slides.mathtext/imathelement) base cuja visibilidade e layout serão controlados <br/><br/>            pelo fantasma. Este elemento define o conteúdo que pode ser ocultado ou mostrado, <br/><br/>            enquanto ainda afeta o alinhamento geométrico da matemática circundante. |

### Observações

O elemento fantasma é usado para reservar ou suprimir o espaço visual de sua expressão base sem necessariamente exibí-lo. Ele corresponde ao elemento OMML `<m:phant>`.
