## SvgExternalFontsHandling enumeração

Representa uma forma de lidar com fontes externas usadas para desenho de texto.

O tipo SvgExternalFontsHandling expõe os membros a seguir:

## Campos

| Campo | Descrição |
| :- | :- |
| ADD_LINKS_TO_FONT_FILES | Adiciona links para arquivos de fontes separados na seção de estilo do arquivo SVG. |
| EMBED | Salva os dados das fontes diretamente no arquivo SVG. Por favor, verifique todos os acordos de licença das fontes externas antes de usar esta opção. |
| VECTORIZE | Salva todo o texto que usa fontes externas como gráficos. |
