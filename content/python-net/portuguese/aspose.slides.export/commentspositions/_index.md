## CommentsPositions enumeração

Representa a regra para renderizar comentários no documento exportado

O tipo CommentsPositions expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| NONE | Especifica que os comentários não devem ser exibidos de forma alguma. |
| BOTTOM | Especifica que os comentários devem ser exibidos na parte inferior da página. |
| RIGHT | Especifica que os comentários devem ser exibidos à direita da página. |
