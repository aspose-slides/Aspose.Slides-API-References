## disable_line_end_cropping propriedade
O SVG 1.1 não possui capacidade de definir recuos para marcadores.
            Aspose.Slides SVG writing engine tem uma solução alternativa para esse problema:
            ele corta a extremidade da linha com a seta, portanto, a linha não sobrepõe os marcadores.
            Esta opção desativa esse comportamento.
Leitura/gravação **bool**.
