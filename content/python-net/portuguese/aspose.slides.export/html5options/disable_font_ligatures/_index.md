## disable_font_ligatures propriedade
Obtém ou define um valor que indica se o texto é renderizado sem usar ligaduras.
            Quando definido como `true`, as ligaduras serão desativadas na saída renderizada. Por padrão, esta propriedade é definida como `false`.
