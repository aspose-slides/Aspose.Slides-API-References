## skip_java_script_links propriedade
Especifica se deve pular hyperlinks com chamadas JavaScript ao salvar a apresentação. 
            Leitura/gravação **bool**. O valor padrão é **false** .


### Observações

Quando esta propriedade está definida como **true** , os hyperlinks com chamadas JavaScript serão ignorados ao salvar.


Quando esta propriedade está definida como **false** , todos os hyperlinks serão salvos.
