## CompressionLevel enumeração

Especifica os níveis de compressão ZIP para arquivos OpenXML.
Níveis mais altos fornecem melhor compressão ao custo de processamento mais lento.

O tipo CompressionLevel expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| NONE | Nenhuma compressão é aplicada. Os arquivos são armazenados como estão. |
| LEVEL1 | Compressão mais rápida com a menor taxa de compressão. |
| LEVEL2 | Compressão mais rápida com uma taxa de compressão ligeiramente melhor que [`CompressionLevel.LEVEL1`](/slides/python-net/pt/aspose.slides.export/compressionlevel/LEVEL1). |
| LEVEL3 | Fornece melhor compressão que [`CompressionLevel.LEVEL2`](/slides/python-net/pt/aspose.slides.export/compressionlevel/LEVEL2) com impacto de desempenho moderado. |
| LEVEL4 | Fornece melhor compressão que [`CompressionLevel.LEVEL3`](/slides/python-net/pt/aspose.slides.export/compressionlevel/LEVEL3). |
| LEVEL5 | Fornece compressão aprimorada em relação a [`CompressionLevel.LEVEL4`](/slides/python-net/pt/aspose.slides.export/compressionlevel/LEVEL4) com tempo de processamento adicional. |
| LEVEL6 | Compressão padrão, oferecendo um bom equilíbrio entre velocidade de compressão e tamanho do arquivo.<br/>            O nível de compressão padrão. |
| LEVEL7 | Fornece compressão maior que [`CompressionLevel.LEVEL6`](/slides/python-net/pt/aspose.slides.export/compressionlevel/LEVEL6) com processamento mais lento. |
| LEVEL8 | Fornece compressão maior que [`CompressionLevel.LEVEL7`](/slides/python-net/pt/aspose.slides.export/compressionlevel/LEVEL7). |
| LEVEL9 | Compressão máxima. Produz o menor tamanho de arquivo com a velocidade de processamento mais lenta. |
