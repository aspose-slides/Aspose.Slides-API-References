## bw_conversion_mode propriedade
Especifica o algoritmo para converter uma imagem colorida em uma imagem preto e branco.
            Esta opção será aplicada somente se [`TiffOptions.compression_type`](/slides/python-net/pt/aspose.slides.export/tiffoptions/compression_type) 
            está definido como [`TiffCompressionTypes.CCITT4`](/slides/python-net/pt/aspose.slides.export/tiffcompressiontypes/CCITT4) ou [`TiffCompressionTypes.CCITT3`](/slides/python-net/pt/aspose.slides.export/tiffcompressiontypes/CCITT3)
            Leitura/gravação [`BlackWhiteConversionMode`](/slides/python-net/pt/aspose.slides.export/blackwhiteconversionmode).
            Padrão é [`BlackWhiteConversionMode.DEFAULT`](/slides/python-net/pt/aspose.slides.export/blackwhiteconversionmode/DEFAULT).
