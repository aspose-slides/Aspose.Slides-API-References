## image_size propriedade
Especifica o tamanho de uma imagem TIFF gerada.
            O valor padrão é 0x0, o que significa que os tamanhos das imagens geradas serão calculados com base no valor do tamanho do slide da apresentação.
            Leitura/gravação **aspose.slides.Size**.
