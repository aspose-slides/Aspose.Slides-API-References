## TiffCompressionTypes enumeração

Fornece opções que controlam como uma apresentação é comprimida no formato TIFF.

O tipo TiffCompressionTypes expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| DEFAULT | Especifica o esquema de compressão padrão (LZW). |
| NONE | Especifica nenhuma compressão. |
| CCITT3 | Especifica o esquema de compressão CCITT3. |
| CCITT4 | Especifica o esquema de compressão CCITT4. |
| LZW | Especifica o esquema de compressão LZW (Padrão). |
| RLE | Especifica o esquema de compressão RLE. |
