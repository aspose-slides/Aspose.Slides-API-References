## SaveFormat enumeração

Constantes que definem o formato de uma apresentação salva.

O tipo SaveFormat expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| PPT | Salvar apresentação no formato PPT. |
| PDF | Salvar apresentação no formato PDF. |
| XPS | Salvar apresentação no formato XPS. |
| PPTX | Salvar apresentação no formato PPTX. |
| PPSX | Salvar apresentação no formato PPSX (apresentação de slides). |
| TIFF | Salvar apresentação como imagem TIFF multi-páginas. |
| ODP | Salvar apresentação no formato ODP. |
| PPTM | Salvar apresentação no formato PPTM (apresentação com macros). |
| PPSM | Salvar apresentação no formato PPSM (apresentação de slides com macros). |
| POTX | Salvar apresentação no formato POTX (modelo). |
| POTM | Salvar apresentação no formato POTM (modelo com macros). |
| HTML | Salvar apresentação no formato HTML. |
| SWF | Salvar apresentação no formato SWF. |
| OTP | Salvar apresentação no formato OTP (modelo de apresentação). |
| PPS | Salvar apresentação no formato PPS. |
| POT | Salvar apresentação no formato POT. |
| FODP | Salvar apresentação no formato FODP. |
| GIF | Salvar apresentação no formato GIF. |
| HTML5 | Salvar apresentação no formato HTML usando o novo sistema de templates HTML5. |
| MD | Salvar apresentação no formato Markdown |
| XML | Salvar apresentação no formato PowerPoint XML Presentation. |
