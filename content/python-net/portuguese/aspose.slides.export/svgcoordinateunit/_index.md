## SvgCoordinateUnit enumeração

Representa unidades de coordenada CSS2 usadas para definir coordenadas SVG.

O tipo SvgCoordinateUnit expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| INCH | Polegada |
| CENTIMETER | Centímetro. |
| MILLIMETER | Milímetro. |
| POINT | Ponto (1/72 de polegada), |
| PICA | Pica (1/6 de polegada). |
| EM | Tamanho Em da fonte do elemento contêiner. |
| EX | Tamanho Ex (tamanho da letra minúscula, normalmente "x") da fonte do elemento contêiner. |
| PIXEL | Tamanho do pixel. |
| PERCENT | Porcentagem. |
