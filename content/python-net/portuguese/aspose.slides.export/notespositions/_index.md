## NotesPositions enumeração

Representa a regra para renderizar notas no documento exportado

O tipo NotesPositions expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| NONE | Especifica que as notas não devem ser exibidas de forma alguma. |
| BOTTOM_FULL | Especifica que as notas devem ser exibidas completamente usando páginas adicionais conforme necessário. |
| BOTTOM_TRUNCATED | Especifica que as notas devem ser exibidas em apenas uma página. |
