## Enumeração EmbedFontCharacters

Representa a regra a ser usada para adicionar nova fonte incorporada ao [`IPresentation`](/slides/python-net/pt/aspose.slides/ipresentation)

O tipo EmbedFontCharacters expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| ONLY_USED | Incorporar apenas os caracteres usados na apresentação (melhor para reduzir o tamanho do arquivo). |
| ALL | Incorporar todos os caracteres (melhor para edição por outras pessoas). |
