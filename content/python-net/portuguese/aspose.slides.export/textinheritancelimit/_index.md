## TextInheritanceLimit enumeração

Controla a profundidade da herança das propriedades de texto.

O tipo TextInheritanceLimit expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| ALL | Herda todas as propriedades de texto. |
| TEXT_BOX | Herda apenas do estilo do TextFrame. |
| PARAGRAPH_ONLY | Use apenas propriedades definidas para parágrafo. |
