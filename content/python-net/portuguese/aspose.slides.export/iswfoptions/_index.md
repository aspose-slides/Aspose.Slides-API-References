## ISwfOptions classe

Fornece opções que controlam como uma apresentação é salva no formato SWF.

O tipo ISwfOptions expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`compressed`](/slides/python-net/pt/aspose.slides.export/iswfoptions/compressed/) | Especifica se o documento SWF gerado deve ser compactado ou não.<br/>            Padrão é `true`. |
| [`viewer_included`](/slides/python-net/pt/aspose.slides.export/iswfoptions/viewer_included/) | Especifica se o documento SWF gerado deve incluir o visualizador de documentos integrado ou não.<br/>            Padrão é `true`. |
| [`show_page_border`](/slides/python-net/pt/aspose.slides.export/iswfoptions/show_page_border/) | Especifica se a borda ao redor das páginas deve ser exibida. Padrão é true. |
| [`show_hidden_slides`](/slides/python-net/pt/aspose.slides.export/iswfoptions/show_hidden_slides/) | Especifica se o documento gerado deve incluir slides ocultos ou não.<br/>            Padrão é `false`. |
| [`show_full_screen`](/slides/python-net/pt/aspose.slides.export/iswfoptions/show_full_screen/) | Mostrar/ocultar botão de tela cheia. Pode ser sobrescrito em flashvars. Padrão é true. |
| [`show_page_stepper`](/slides/python-net/pt/aspose.slides.export/iswfoptions/show_page_stepper/) | Mostrar/ocultar avançador de página. Pode ser sobrescrito em flashvars. Padrão é true. |
| [`show_search`](/slides/python-net/pt/aspose.slides.export/iswfoptions/show_search/) | Mostrar/ocultar seção de pesquisa. Pode ser sobrescrito em flashvars. Padrão é true. |
| [`show_top_pane`](/slides/python-net/pt/aspose.slides.export/iswfoptions/show_top_pane/) | Mostrar/ocultar todo o painel superior. Pode ser sobrescrito em flashvars. Padrão é true. |
| [`show_bottom_pane`](/slides/python-net/pt/aspose.slides.export/iswfoptions/show_bottom_pane/) | Mostrar/ocultar painel inferior. Pode ser sobrescrito em flashvars. Padrão é true. |
| [`show_left_pane`](/slides/python-net/pt/aspose.slides.export/iswfoptions/show_left_pane/) | Mostrar/ocultar painel esquerdo. Pode ser sobrescrito em flashvars. Padrão é true. |
| [`start_open_left_pane`](/slides/python-net/pt/aspose.slides.export/iswfoptions/start_open_left_pane/) | Iniciar com o painel esquerdo aberto. Pode ser sobrescrito em flashvars. Padrão é false. |
| [`enable_context_menu`](/slides/python-net/pt/aspose.slides.export/iswfoptions/enable_context_menu/) | Habilitar/desabilitar menu de contexto. Padrão é true. |
| [`logo_image_bytes`](/slides/python-net/pt/aspose.slides.export/iswfoptions/logo_image_bytes/) | Imagem que será exibida como logotipo no canto superior direito do visualizador.<br/>            A imagem deve ser PNG de 32x64 pixels, caso contrário o logotipo pode ser exibido incorretamente. |
| [`logo_link`](/slides/python-net/pt/aspose.slides.export/iswfoptions/logo_link/) | Obtém ou define o endereço de hiperlink completo para um logotipo.<br/>            Tem efeito somente se um [`ISwfOptions.logo_image_bytes`](/slides/python-net/pt/aspose.slides.export/iswfoptions/logo_image_bytes) for especificado. |
| [`jpeg_quality`](/slides/python-net/pt/aspose.slides.export/iswfoptions/jpeg_quality/) | Especifica a qualidade das imagens JPEG.<br/>            Padrão é 95. |
| [`slides_layout_options`](/slides/python-net/pt/aspose.slides.export/iswfoptions/slides_layout_options/) | Obtém ou define o modo como os slides são posicionados na página ao exportar uma apresentação [`ISlidesLayoutOptions`](/slides/python-net/pt/aspose.slides.export/islideslayoutoptions).<br/>            Esta propriedade não oferece suporte à atribuição de objetos do tipo `Aspose.Slides.Export.HandoutLayoutingOptions` |
| [`warning_callback`](/slides/python-net/pt/aspose.slides.export/iswfoptions/warning_callback/) |  |
| [`progress_callback`](/slides/python-net/pt/aspose.slides.export/iswfoptions/progress_callback/) |  |
| [`default_regular_font`](/slides/python-net/pt/aspose.slides.export/iswfoptions/default_regular_font/) |  |
| [`gradient_style`](/slides/python-net/pt/aspose.slides.export/iswfoptions/gradient_style/) |  |
| [`skip_java_script_links`](/slides/python-net/pt/aspose.slides.export/iswfoptions/skip_java_script_links/) |  |
