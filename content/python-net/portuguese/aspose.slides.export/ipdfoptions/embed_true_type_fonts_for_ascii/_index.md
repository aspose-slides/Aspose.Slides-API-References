## embed_true_type_fonts_for_ascii propriedade
True para incorporar fontes TrueType para caracteres ASCII 32-127.
            Fontes para códigos de caracteres maiores que 127 são sempre incorporadas.
            Leitura/gravação **bool**.


### Observações

O padrão é **true** .
