## Enumeração SvgEvent

Representa opções para forma SVG.

O tipo SvgEvent expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| ON_FOCUS_IN | Ocorre quando um elemento recebe foco, como quando um texto se torna selecionado. |
| ON_FOCUS_OUT | Ocorre quando um elemento perde o foco, como quando um texto deixa de estar selecionado. |
| ON_ACTIVATE | Ocorre quando um elemento é ativado, por exemplo, através de um clique do mouse ou de uma tecla. |
| ON_CLICK | Ocorre quando o botão do dispositivo apontador é clicado sobre um elemento. |
| ON_MOUSE_DOWN | Ocorre quando o botão do dispositivo apontador é pressionado sobre um elemento. |
| ON_MOUSE_UP | Ocorre quando o botão do dispositivo apontador é liberado sobre um elemento. |
| ON_MOUSE_OVER | Ocorre quando o dispositivo apontador é movido para um elemento. |
| ON_MOUSE_MOVE | Ocorre quando o dispositivo apontador é movido enquanto está sobre um elemento. |
| ON_MOUSE_OUT | Ocorre quando o dispositivo apontador se afasta de um elemento. |
| ON_LOAD | Ocorre quando o agente de usuário analisou completamente o elemento e seus descendentes e todos os recursos referenciados, necessários para renderizá-lo. |
| ON_UNLOAD | Ocorre quando a implementação DOM remove um documento de uma janela ou quadro. Aplicável apenas a elementos svg mais externos. |
| ON_ABORT | Ocorre quando o carregamento da página é interrompido antes que um elemento tenha sido completamente carregado. |
| ON_ERROR | Ocorre quando um elemento não é carregado corretamente ou quando ocorre um erro durante a execução de script. |
| ON_RESIZE | Ocorre quando a visualização de um documento está sendo redimensionada. Aplicável apenas a elementos svg mais externos. |
| ON_SCROLL | Ocorre quando a visualização de um documento está sendo deslocada ao longo do eixo X ou Y ou ambos. Aplicável apenas a elementos svg mais externos. |
| ON_ZOOM | Ocorre quando o nível de zoom de uma visualização de documento está sendo alterado. Aplicável apenas a elementos svg mais externos. |
| ON_BEGIN | Ocorre quando um elemento de animação começa. |
| ON_END | Ocorre quando um elemento de animação termina. |
| ON_REPEAT | Ocorre quando um elemento de animação se repete. |
