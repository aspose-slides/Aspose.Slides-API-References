## LinkEmbedDecision enumeração

Determina como o objeto será processado durante a gravação.

O tipo LinkEmbedDecision expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| LINK | O objeto será armazenado externamente, referenciado por URL |
| EMBED | O objeto deve ser incorporado a um arquivo gerado, se possível. Se a incorporação for impossível, GetUrl será chamada e, dependendo do resultado, o objeto será referenciado por URL ou ignorado. |
| IGNORE | O objeto será ignorado. |
