## HandoutType enumeração

Especifica quantos slides e em que sequência serão colocados na página.

O tipo HandoutType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| HANDOUTS1 | Um slide por página. |
| HANDOUTS2 | Dois slides por página. |
| HANDOUTS3 | Três slides por página. |
| HANDOUTS_4_HORIZONTAL | Quatro slides por página em sequência horizontal. |
| HANDOUTS_4_VERTICAL | Quatro slides por página em sequência vertical. |
| HANDOUTS_6_HORIZONTAL | Seis slides por página em sequência horizontal. |
| HANDOUTS_6_VERTICAL | Seis slides por página em sequência vertical. |
| HANDOUTS_9_HORIZONTAL | Nove slides por página em sequência horizontal. |
| HANDOUTS_9_VERTICAL | Nove slides por página em sequência vertical. |
