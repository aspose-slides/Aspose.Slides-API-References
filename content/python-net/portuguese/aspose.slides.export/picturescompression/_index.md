## PicturesCompression enumeração

Representa o nível de compressão das imagens

O tipo PicturesCompression expõe os seguintes membros:

## Fields

| Campo | Descrição |
| :- | :- |
| DPI330 | Boa qualidade para monitores de alta definição (HD) |
| DPI220 | Qualidade excelente na maioria das impressoras e telas |
| DPI150 | Boa para páginas web e projetores |
| DPI96 | Minimiza o tamanho do documento para compartilhamento |
| DPI72 | Nível de compressão padrão |
| DOCUMENT_RESOLUTION | Usa a resolução do documento - a imagem não será comprimida e será usada no documento como está |
