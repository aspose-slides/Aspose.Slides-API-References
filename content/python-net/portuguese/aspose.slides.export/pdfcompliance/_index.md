## enumeração PdfCompliance

Constantes que definem o nível de conformidade com os padrões PDF.

O tipo PdfCompliance expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| PDF15 | O arquivo de saída estará em conformidade com o padrão PDF 1.5. |
| PDF16 | O arquivo de saída estará em conformidade com o padrão PDF 1.6. |
| PDF17 | O arquivo de saída estará em conformidade com o padrão PDF 1.7. |
| PDF_A1B | O arquivo de saída estará em conformidade com o padrão PDF/A-1b. |
| PDF_A1A | O arquivo de saída estará em conformidade com o padrão PDF/A-1a. |
| PDF_A2B | O arquivo de saída estará em conformidade com o padrão PDF/A-2b. |
| PDF_A2A | O arquivo de saída estará em conformidade com o padrão PDF/A-2a. |
| PDF_A3B | O arquivo de saída estará em conformidade com o padrão PDF/A-3b. |
| PDF_A3A | O arquivo de saída estará em conformidade com o padrão PDF/A-3a. |
| PDF_UA | O arquivo de saída estará em conformidade com o padrão PDF/UA. |
| PDF_A2U | O arquivo de saída estará em conformidade com o padrão PDF/A-2u. |
