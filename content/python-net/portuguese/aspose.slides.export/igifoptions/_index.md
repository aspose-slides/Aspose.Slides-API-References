## IGifOptions class

Representa opções de exportação de GIF.

O tipo IGifOptions expõe os seguintes membros:

| :- | :- |
| [`frame_size`](/slides/python-net/pt/aspose.slides.export/igifoptions/frame_size/) | Obtém ou define o tamanho do quadro. |
| [`export_hidden_slides`](/slides/python-net/pt/aspose.slides.export/igifoptions/export_hidden_slides/) | Determina se slides ocultos serão exportados.<br/>            O valor padrão é false. |
