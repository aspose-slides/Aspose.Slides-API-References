## BlackWhiteConversionMode enumeração

Fornece opções que controlam como as imagens dos slides serão convertidas em imagens bitonais.

O tipo BlackWhiteConversionMode expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| DEFAULT | Especifica nenhum algoritmo de conversão. O algoritmo implementado no codec TIFF será usado. (Padrão) |
| DITHERING | Especifica o algoritmo de dithering (Floyd-Steinberg). |
| DITHERING_FLOYD_STEINBERG | Especifica o algoritmo de dithering Floyd-Steinberg. |
| AUTO | Especifica o algoritmo de limiar calculado automaticamente (Otsu). |
| AUTO_OTSU | Especifica o algoritmo de limiar Otsu calculado automaticamente. |
| THRESHOLD25 | Especifica o algoritmo de limiar estático (25%). |
| THRESHOLD50 | Especifica o algoritmo de limiar estático (50%). |
| THRESHOLD75 | Especifica o algoritmo de limiar estático (75%). |
