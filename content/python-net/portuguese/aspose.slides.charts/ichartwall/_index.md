## IChartWall classe

Representa paredes em gráficos 3D.

O tipo IChartWall expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`thickness`](/slides/python-net/pt/aspose.slides.charts/ichartwall/thickness/) | Retorna ou define a espessura das paredes como uma porcentagem da maior dimensão do volume do gráfico.<br/>            Leitura/gravação **int**. |
| [`format`](/slides/python-net/pt/aspose.slides.charts/ichartwall/format/) | Retorna o preenchimento da parede, linha, efeito, estilos 3D.<br/>            Somente leitura [`IFormat`](/slides/python-net/pt/aspose.slides.charts/iformat). |
| [`picture_type`](/slides/python-net/pt/aspose.slides.charts/ichartwall/picture_type/) | Retorna ou define o tipo de imagem.<br/>            Leitura/gravação [`IChartWall.picture_type`](/slides/python-net/pt/aspose.slides.charts/ichartwall/picture_type). |
