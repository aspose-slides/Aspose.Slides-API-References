## ChartCellCollection classe

Representa a coleção de células com dados.

O tipo ChartCellCollection expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`count`](/slides/python-net/pt/aspose.slides.charts/chartcellcollection/count/) | Obtém a contagem de células na coleção.<br/>            Somente leitura **int**. |

Retorna uma célula (IChartDataCell) por índice.

## Indexador

| Nome | Descrição |
| :- | :- |
| [`[index]`](/slides/python-net/pt/aspose.slides.charts/chartcellcollection/__getitem__/) | Índice de uma célula. |

## Métodos

| Método | Descrição |
| :- | :- |
| [`add(self, cell)`](/slides/python-net/pt/aspose.slides.charts/chartcellcollection/add/#ichartdatacell) | Adiciona nova célula à coleção. |
| [`add(self, value)`](/slides/python-net/pt/aspose.slides.charts/chartcellcollection/add/#any) | Cria [`ChartDataCell`](/slides/python-net/pt/aspose.slides.charts/chartdatacell) a partir do valor especificado e o adiciona à coleção. |
| [`get_cells_address(self)`](/slides/python-net/pt/aspose.slides.charts/chartcellcollection/get_cells_address/#) | Retorna o endereço do conjunto de células na pasta de trabalho. |
| [`get_concatenated_values_from_cells(self)`](/slides/python-net/pt/aspose.slides.charts/chartcellcollection/get_concatenated_values_from_cells/#) | Concatena string de todos os valores de string das células. |
| [`remove_at(self, index)`](/slides/python-net/pt/aspose.slides.charts/chartcellcollection/remove_at/#int) | Remove uma célula da coleção por índice. |
