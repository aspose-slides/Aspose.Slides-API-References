## PieSplitCustomPointCollection classe

Representa uma coleção de pontos para dividir o ponto em um gráfico bar-of-pie ou pie-of-pie com uma divisão personalizada.

O tipo PieSplitCustomPointCollection expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`is_synchronized`](/slides/python-net/pt/aspose.slides.charts/piesplitcustompointcollection/is_synchronized/) | Retorna um valor que indica se o acesso à coleção está sincronizado (thread-safe).<br/>            Somente leitura **bool**. |
| [`sync_root`](/slides/python-net/pt/aspose.slides.charts/piesplitcustompointcollection/sync_root/) | Retorna a raiz de sincronização.<br/>            Somente leitura **any**. |

Retorna o ponto de dados do gráfico para o índice especificado.
