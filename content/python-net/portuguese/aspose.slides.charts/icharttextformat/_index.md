## IChartTextFormat classe

Chart opera com um conjunto restrito de propriedades de formato de texto.
            IChartTextFormat, IChartTextBlockFormat, IChartParagraphFormat, IChartPortionFormat
            interfaces descrevem esse conjunto restrito.

O tipo IChartTextFormat expõe os seguintes membros:

## Propriedades

| Property | Description |
| :- | :- |
| [`text_block_format`](/slides/python-net/pt/aspose.slides.charts/icharttextformat/text_block_format/) | Retorna o formato para os elementos de texto do gráfico.<br/>            Somente leitura [`IChartTextBlockFormat`](/slides/python-net/pt/aspose.slides.charts/icharttextblockformat). |
| [`paragraph_format`](/slides/python-net/pt/aspose.slides.charts/icharttextformat/paragraph_format/) | Retorna o formato de parágrafo.<br/>            Somente leitura [`IChartParagraphFormat`](/slides/python-net/pt/aspose.slides.charts/ichartparagraphformat). |
| [`portion_format`](/slides/python-net/pt/aspose.slides.charts/icharttextformat/portion_format/) | Retorna o formato de porção.<br/>            Somente leitura [`IChartPortionFormat`](/slides/python-net/pt/aspose.slides.charts/ichartportionformat). |
