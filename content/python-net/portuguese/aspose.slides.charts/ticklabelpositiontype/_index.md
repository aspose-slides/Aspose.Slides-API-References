## TickLabelPositionType enumeração

Representa o tipo de posição dos rótulos de marca-marca no eixo especificado.

O tipo TickLabelPositionType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| HIGH | Especifica que os rótulos do eixo devem estar no extremo superior do eixo perpendicular. |
| LOW | Especifica que os rótulos do eixo devem estar no extremo inferior do eixo perpendicular. |
| NEXT_TO | Especifica que os rótulos do eixo devem estar ao lado do eixo. |
| NONE | Especifica que os rótulos do eixo não são desenhados. |
