## ParentLabelLayoutType enumeração

Representa o layout dos rótulos de dados da categoria. Usado apenas com séries Treemap.

O tipo ParentLabelLayoutType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| BANNER | Especifica que os rótulos de categoria pai são exibidos como banner |
| NONE | Especifica que os rótulos de categoria pai não são desenhados |
| OVERLAPPING | Especifica que os rótulos de categoria pai são exibidos sobrepostos |
