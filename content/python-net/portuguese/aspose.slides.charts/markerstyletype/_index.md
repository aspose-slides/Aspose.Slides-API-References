## MarkerStyleType enumeração

Determina o formato do marcador no ponto de dados do gráfico.

O tipo MarkerStyleType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| NOT_DEFINED |  |
| CIRCLE | Especifica que um círculo deve ser desenhado em cada ponto de dados. |
| DASH | Especifica que um traço deve ser desenhado em cada ponto de dados. |
| DIAMOND | Especifica que um diamante deve ser desenhado em cada ponto de dados. |
| DOT | Especifica que um ponto deve ser desenhado em cada ponto de dados. |
| NONE | Especifica que nada deve ser desenhado em cada ponto de dados. |
| PICTURE | Especifica que uma imagem deve ser desenhada em cada ponto de dados. |
| PLUS | Especifica que um sinal de mais deve ser desenhado em cada ponto de dados. |
| SQUARE | Especifica que um quadrado deve ser desenhado em cada ponto de dados. |
| STAR | Especifica que uma estrela deve ser desenhada em cada ponto de dados. |
| TRIANGLE | Especifica que um triângulo deve ser desenhado em cada ponto de dados. |
| X | Especifica que um X deve ser desenhado em cada ponto de dados. |
