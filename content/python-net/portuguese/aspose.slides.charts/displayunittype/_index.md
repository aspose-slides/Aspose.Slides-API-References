## Enumeração DisplayUnitType

Determina a multiplicidade dos dados exibidos.

O tipo DisplayUnitType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| NONE | Valores serão exibidos como estão. |
| HUNDREDS | Especifica que os valores no gráfico serão divididos por 100. |
| THOUSANDS | Especifica que os valores no gráfico serão divididos por 1,000. |
| TEN_THOUSANDS | Especifica que os valores no gráfico serão divididos por 10,000. |
| HUNDRED_THOUSANDS | Especifica que os valores no gráfico serão divididos por 100,000. |
| MILLIONS | Especifica que os valores no gráfico serão divididos por 1,000,000. |
| TEN_MILLIONS | Especifica que os valores no gráfico serão divididos por 10,000,000. |
| HUNDRED_MILLIONS | Especifica que os valores no gráfico serão divididos por 100,000,000. |
| BILLIONS | Especifica que os valores no gráfico serão divididos por 1,000,000,000. |
| TRILLIONS | Especifica que os valores no gráfico serão divididos por 1,000,000,000,000. |
| CUSTOM_VALUE | Especifica que os valores no gráfico serão divididos por um valor personalizado. |
