## DisplayBlanksAsType enumeração

Determina como os dados ausentes serão exibidos.

O tipo DisplayBlanksAsType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| GAP | Especifica que valores em branco devem ser deixados como um espaço. |
| SPAN | Especifica que valores em branco devem ser estendidos com uma linha. |
| ZERO | Especifica que valores em branco devem ser tratados como zero. |
