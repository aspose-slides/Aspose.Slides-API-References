## ILayoutable classe

Especifica a posição exata de um elemento do gráfico.

O tipo ILayoutable expõe os seguintes membros:

## Propriedades

| Property | Description |
| :- | :- |
| [`x`](/slides/python-net/pt/aspose.slides.charts/ilayoutable/x/) | Especifica a localização x (esquerda) do elemento do gráfico como uma fração da largura do gráfico.<br/>            Leitura/gravação **float**. |
| [`y`](/slides/python-net/pt/aspose.slides.charts/ilayoutable/y/) | Especifica a parte superior do elemento do gráfico como uma fração da altura do gráfico.<br/>            Leitura/gravação **float**. |
| [`width`](/slides/python-net/pt/aspose.slides.charts/ilayoutable/width/) | Especifica a largura do elemento do gráfico como uma fração da largura do gráfico.<br/>            Leitura/gravação **float**. |
| [`height`](/slides/python-net/pt/aspose.slides.charts/ilayoutable/height/) | Especifica a altura do elemento do gráfico como uma fração da altura do gráfico.<br/>            Leitura/gravação **float**. |
| [`right`](/slides/python-net/pt/aspose.slides.charts/ilayoutable/right/) | Obtém a parte direita do elemento do gráfico como uma fração da largura do gráfico.<br/>            Somente leitura **float**. |
| [`bottom`](/slides/python-net/pt/aspose.slides.charts/ilayoutable/bottom/) | Obtém a parte superior do elemento do gráfico como uma fração da altura do gráfico.<br/>            Somente leitura **float**. |
