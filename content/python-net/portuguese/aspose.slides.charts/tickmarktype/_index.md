## TickMarkType enumeration

Representa o tipo de marca de gradução para o eixo especificado.

O tipo TickMarkType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| CROSS | Especifica que as marcas de gradução devem cruzar o eixo. |
| INSIDE | Especifica que as marcas de gradução devem estar dentro da área do gráfico. |
| NONE | Especifica que não deve haver marcas de gradução. |
| OUTSIDE | Especifica que as marcas de gradução devem estar fora da área do gráfico. |
