## TimeUnitType enumeração

Representa a unidade base para o eixo de categorias

O tipo TimeUnitType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| NONE | Os valores serão exibidos como estão. |
| DAYS | Especifica que os dados do gráfico devem ser mostrados em dias. |
| MONTHS | Especifica que os dados do gráfico devem ser mostrados em meses. |
| YEARS | Especifica que os dados do gráfico devem ser mostrados em anos. |
