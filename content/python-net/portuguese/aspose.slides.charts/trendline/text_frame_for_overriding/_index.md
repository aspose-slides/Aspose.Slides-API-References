## text_frame_for_overriding propriedade
Pode conter um texto formatado rico. Se esta propriedade não for None, então este valor de texto formatado substitui o texto gerado automaticamente do rótulo de dados. Texto gerado automaticamente do rótulo de dados significa o texto que é gerenciado pelas propriedades ShowSeriesName, ShowValue, ... e é formatado com a propriedade TextFormatManager.TextFormat. Somente leitura [`ITextFrame`](/slides/python-net/pt/aspose.slides/itextframe).
