## IErrorBarsFormat classe

Representa barras de erro de séries de gráfico. Os valores personalizados de ErrorBars estão em IChartDataPointCollection (na propriedade [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/pt/aspose.slides.charts/ichartdatapoint/error_bars_custom_values)).

O tipo IErrorBarsFormat expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`type`](/slides/python-net/pt/aspose.slides.charts/ierrorbarsformat/type/) | Obtém ou define o tipo das barras de erro.<br/>            Leitura/gravação [`ErrorBarType`](/slides/python-net/pt/aspose.slides.charts/errorbartype). |
| [`value_type`](/slides/python-net/pt/aspose.slides.charts/ierrorbarsformat/value_type/) | Representa as possíveis maneiras de determinar o comprimento das barras de erro.<br/>            Caso o tipo de valor personalizado seja usado, especifique o valor usando a propriedade [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/pt/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) do ponto de dados específico na coleção DataPoints da série.<br/>            Leitura/gravação [`ErrorBarValueType`](/slides/python-net/pt/aspose.slides.charts/errorbarvaluetype). |
| [`has_end_cap`](/slides/python-net/pt/aspose.slides.charts/ierrorbarsformat/has_end_cap/) | Especifica que um capô final não é desenhado nas barras de erro.<br/>            Leitura/gravação **bool**. |
| [`value`](/slides/python-net/pt/aspose.slides.charts/ierrorbarsformat/value/) | Obtém ou define o valor que é usado com os tipos Fixed, Percentage e StandardDeviation para determinar o comprimento das barras de erro.<br/>            Leitura/gravação **float**. |
| [`format`](/slides/python-net/pt/aspose.slides.charts/ierrorbarsformat/format/) | Representa o formato das barras de erro.<br/>            Leitura/gravação [`IFormat`](/slides/python-net/pt/aspose.slides.charts/iformat). |
| [`is_visible`](/slides/python-net/pt/aspose.slides.charts/ierrorbarsformat/is_visible/) | Obtém ou define a visibilidade das barras de erro.<br/>            Leitura/gravação **bool**. |
