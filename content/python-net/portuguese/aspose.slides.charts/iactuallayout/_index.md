## IActualLayout classe

Especifica a posição real de um elemento de gráfico.

O tipo IActualLayout expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`actual_x`](/slides/python-net/pt/aspose.slides.charts/iactuallayout/actual_x/) | Especifica a localização real x (esquerda) do elemento de gráfico em relação ao canto superior esquerdo do gráfico.<br/>            Chame o método IChart.ValidateChartLayout() antes para obter valores reais. <br/>            Leitura **float**. |
| [`actual_y`](/slides/python-net/pt/aspose.slides.charts/iactuallayout/actual_y/) | Especifica a parte superior real do elemento de gráfico em relação ao canto superior esquerdo do gráfico.<br/>            Chame o método IChart.ValidateChartLayout() antes para obter valores reais. <br/>            Leitura **float**. |
| [`actual_width`](/slides/python-net/pt/aspose.slides.charts/iactuallayout/actual_width/) | Especifica a largura real do elemento de gráfico. Chame o método IChart.ValidateChartLayout() antes para obter valores reais. <br/>            Leitura **float**. |
| [`actual_height`](/slides/python-net/pt/aspose.slides.charts/iactuallayout/actual_height/) | Especifica a altura real do elemento de gráfico. Chame o método IChart.ValidateChartLayout() antes para obter valores reais. <br/>            Leitura **float**. |
