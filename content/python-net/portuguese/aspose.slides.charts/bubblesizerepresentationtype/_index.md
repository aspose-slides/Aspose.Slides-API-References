## Enumeração BubbleSizeRepresentationType

Especifica as possíveis formas de representar dados como tamanhos de gráfico de bolhas.

O tipo BubbleSizeRepresentationType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| AREA | Especifica que a área das bolhas deve ser proporcional ao valor do tamanho da bolha. |
| WIDTH | Especifica que o raio das bolhas deve ser proporcional ao valor do tamanho da bolha. |
