## value_type propriedade
Representa as possíveis formas de determinar o comprimento das barras de erro. 
            No caso de tipo de valor personalizado, para especificar o valor, use a propriedade [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/pt/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) do ponto de dados específico na coleção DataPoints da série.
            No caso de Fixed, Percentage ou StandardDeviation, use a propriedade Value para especificar o valor.  
            Leitura/Gravação [`ErrorBarValueType`](/slides/python-net/pt/aspose.slides.charts/errorbarvaluetype).
