## ChartPlotArea classe

Representa o retângulo onde o gráfico deve ser plotado.

O tipo ChartPlotArea expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`format`](/slides/python-net/pt/aspose.slides.charts/chartplotarea/format/) | Retorna o formato de uma área de plotagem.<br/>            Somente leitura [`IFormat`](/slides/python-net/pt/aspose.slides.charts/iformat). |
| [`x`](/slides/python-net/pt/aspose.slides.charts/chartplotarea/x/) | Retorna ou define a coordenada x do canto superior esquerdo da caixa delimitadora da área de plotagem como uma fração da largura do gráfico (de 0 a 1).<br/>            Leitura/gravação **float**. |
| [`y`](/slides/python-net/pt/aspose.slides.charts/chartplotarea/y/) | Retorna ou define a coordenada y do canto superior esquerdo da caixa delimitadora da área de plotagem como uma fração da altura do gráfico (de 0 a 1).<br/>            Leitura/gravação **float**. |
| [`width`](/slides/python-net/pt/aspose.slides.charts/chartplotarea/width/) | Retorna ou define a largura da caixa delimitadora da área de plotagem como uma fração da largura do gráfico (de 0 a 1).<br/>            Leitura/gravação **float**. |
| [`height`](/slides/python-net/pt/aspose.slides.charts/chartplotarea/height/) | Retorna ou define a altura da caixa delimitadora da área de plotagem como uma fração da altura do gráfico (de 0 a 1).<br/>            Leitura/gravação **float**. |
| [`right`](/slides/python-net/pt/aspose.slides.charts/chartplotarea/right/) | Direita.<br/>            Somente leitura **float**. |
| [`bottom`](/slides/python-net/pt/aspose.slides.charts/chartplotarea/bottom/) | Inferior.<br/>            Somente leitura **float**. |
| [`chart`](/slides/python-net/pt/aspose.slides.charts/chartplotarea/chart/) | Gráfico.<br/>            Somente leitura [`IChart`](/slides/python-net/pt/aspose.slides.charts/ichart). |
| [`is_location_autocalculated`](/slides/python-net/pt/aspose.slides.charts/chartplotarea/is_location_autocalculated/) | Define como a localização deve ser calculada: true – calculado automaticamente; definido pelas propriedades X, Y, Width, Height.<br/>            Somente leitura **bool**. |
| [`layout_target_type`](/slides/python-net/pt/aspose.slides.charts/chartplotarea/layout_target_type/) | Se o layout da área de plotagem for definido manualmente, esta propriedade especifica se <br/>             o layout da área de plotagem deve ser feito por dentro (não incluindo eixo e rótulos dos eixos) ou por fora<br/>             (incluindo eixo e rótulos dos eixos).<br/>             Leitura/gravação [`ChartPlotArea.layout_target_type`](/slides/python-net/pt/aspose.slides.charts/chartplotarea/layout_target_type). |
| [`actual_x`](/slides/python-net/pt/aspose.slides.charts/chartplotarea/actual_x/) | Especifica a localização x real (esquerda) do elemento do gráfico em relação ao canto superior esquerdo do gráfico.<br/>            Chame o método IChart.ValidateChartLayout() antes para obter valores reais. <br/>            Leitura **float**. |
| [`actual_y`](/slides/python-net/pt/aspose.slides.charts/chartplotarea/actual_y/) | Especifica a parte superior real do elemento do gráfico em relação ao canto superior esquerdo do gráfico.<br/>            Chame o método IChart.ValidateChartLayout() antes para obter valores reais. <br/>            Leitura **float**. |
| [`actual_width`](/slides/python-net/pt/aspose.slides.charts/chartplotarea/actual_width/) | Especifica a largura real do elemento do gráfico. Chame o método IChart.ValidateChartLayout() antes para obter valores reais. <br/>            Leitura **float**. |
| [`actual_height`](/slides/python-net/pt/aspose.slides.charts/chartplotarea/actual_height/) | Especifica a altura real do elemento do gráfico. Chame o método IChart.ValidateChartLayout() antes para obter valores reais. <br/>            Leitura **float**. |
