## ErrorBarType enumeração

Representa o tipo de barra de erro

O tipo ErrorBarType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| BOTH | Especifica que as barras de erro devem ser mostradas nas direções positiva e negativa. |
| MINUS | Especifica que as barras de erro devem ser mostradas apenas na direção negativa. |
| PLUS | Especifica que as barras de erro devem ser mostradas apenas na direção positiva. |
