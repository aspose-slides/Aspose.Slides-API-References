## WorkbookType enumeração

Especifica o tipo de arquivo de planilha Open XML.

O tipo WorkbookType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| NOT_DEFINED | O tipo de planilha não está definido. |
| WORKBOOK | Planilha Excel (*.xlsx). |
| WORKBOOK_MACRO | Planilha Excel com macro (*.xlsm). |
| TEMPLATE | Modelo Excel (*.xltx). |
| TEMPLATE_MACRO | Modelo Excel com macro (*.xltm). |
| WORKBOOK_BINARY_MACRO | Planilha Excel binária com macro (*.xlsb). |
