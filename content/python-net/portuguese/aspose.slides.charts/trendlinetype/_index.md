## TrendlineType enumeração

Representa o tipo de linha de tendência

O tipo TrendlineType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| EXPONENTIAL | Especifica que a linha de tendência deve ser uma curva exponencial na forma. |
| LINEAR | Especifica que a linha de tendência deve ser uma linha na forma. |
| LOGARITHMIC | Especifica que a linha de tendência deve ser uma curva logarítmica na forma , onde log é o logaritmo natural. |
| MOVING_AVERAGE | Especifica que a linha de tendência deve ser uma média móvel do período Period. |
| POLYNOMIAL | Especifica que a linha de tendência deve ser uma curva polinomial de ordem Order na forma. |
| POWER | Especifica que a linha de tendência deve ser uma curva de potência na forma. |
