## hide(self) {#}
Torne o rótulo de dados oculto definindo todas as bandeiras Show*-flags (ShowValue, ...) para o estado false.
            IsVisible será false após isso.


```python

    ...
```


### Observações

Se o rótulo de dados não estiver visível (IsVisible é false) você pode tornar o rótulo de dados visível definindo as bandeiras Show*-flags (ShowValue, ...) para o estado true.
