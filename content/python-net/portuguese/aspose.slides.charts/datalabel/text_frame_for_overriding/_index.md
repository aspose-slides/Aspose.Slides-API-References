## text_frame_for_overriding propriedade
Pode conter um texto rico formatado. Se esta propriedade não for None então este 
            o valor de texto formatado sobrescreve o texto auto-gerado do rótulo de dados.
            Texto auto-gerado do rótulo de dados significa o texto que é gerenciado pelas propriedades ShowSeriesName, 
            ShowValue, ... propriedades e é formatado com a propriedade TextFormatManager.TextFormat.
            Somente leitura [`ITextFrame`](/slides/python-net/pt/aspose.slides/itextframe).
