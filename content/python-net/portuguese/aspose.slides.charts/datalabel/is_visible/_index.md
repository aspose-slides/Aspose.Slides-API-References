## is_visible propriedade
False significa que o rótulo de dados não está visível (e assim todas as Show*-flags (ShowValue, ...) são false).
            Somente leitura **bool**.


### Observações

Se o rótulo de dados estiver visível, você pode ocultá-lo com o método Hide().
            Mas se o rótulo de dados não estiver visível (IsVisible é false) você pode tornar o rótulo de dados visível configurando as Show*-flags (ShowValue, ...) para o estado true.
