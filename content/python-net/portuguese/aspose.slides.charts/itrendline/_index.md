## ITrendline classe

Classe que representa a linha de tendência da série de gráfico

O tipo ITrendline expõe os seguintes membros:

## Propriedades

| Property | Description |
| :- | :- |
| [`trendline_name`](/slides/python-net/pt/aspose.slides.charts/itrendline/trendline_name/) | Obtém ou define o nome da linha de tendência.<br/>            Leitura/gravação **str**. |
| [`trendline_type`](/slides/python-net/pt/aspose.slides.charts/itrendline/trendline_type/) | Obtém ou define o tipo da linha de tendência. <br/>            Leitura/gravação [`ITrendline.trendline_type`](/slides/python-net/pt/aspose.slides.charts/itrendline/trendline_type). |
| [`format`](/slides/python-net/pt/aspose.slides.charts/itrendline/format/) | Representa o formato da linha de tendência.<br/>            Leitura/gravação [`IFormat`](/slides/python-net/pt/aspose.slides.charts/iformat). |
| [`backward`](/slides/python-net/pt/aspose.slides.charts/itrendline/backward/) | Especifica o número de categorias (ou unidades em um gráfico de dispersão) que a linha de tendência se estende antes<br/>            dos dados da série que está sendo analisada. Em gráficos de dispersão e não-dispersão, o valor deve ser qualquer número não-negativo<br/>            .<br/>            Leitura/gravação **float**. |
| [`forward`](/slides/python-net/pt/aspose.slides.charts/itrendline/forward/) | Especifica o número de categorias (ou unidades em um gráfico de dispersão) que a linha de tendência se estende após o<br/>            dados da série que está sendo analisada. Em gráficos de dispersão e não-dispersão, o valor deve ser qualquer número não-negativo<br/>            .<br/>            Leitura/gravação **float**. |
| [`intercept`](/slides/python-net/pt/aspose.slides.charts/itrendline/intercept/) | Especifica o valor onde a linha de tendência cruza o eixo y. Esta propriedade só deve ser suportada<br/>            quando o tipo de linha de tendência for exp, linear ou poly.<br/>            Leitura/gravação **float**. |
| [`display_equation`](/slides/python-net/pt/aspose.slides.charts/itrendline/display_equation/) | Especifica que a equação da linha de tendência é exibida no gráfico (no mesmo rótulo que o valor Rsquaredvalue).<br/>            Leitura/gravação **bool**. |
| [`order`](/slides/python-net/pt/aspose.slides.charts/itrendline/order/) | Especifica a ordem da linha de tendência polinomial. É ignorado para outros tipos de linha de tendência. O valor deve estar entre 2 e 6.<br/>            Leitura/gravação **int**. |
| [`period`](/slides/python-net/pt/aspose.slides.charts/itrendline/period/) | Especifica o período da linha de tendência para uma linha de tendência de média móvel. É ignorado para outras variantes de linha de tendência<br/>            . O valor deve estar entre 2 e 255.<br/>            Leitura/gravação **int**. |
| [`display_r_squared_value`](/slides/python-net/pt/aspose.slides.charts/itrendline/display_r_squared_value/) | Especifica que o valor R-squared da linha de tendência é exibido no gráfico (no mesmo rótulo que a equação).<br/>            Leitura/gravação **bool**. |
| [`related_legend_entry`](/slides/python-net/pt/aspose.slides.charts/itrendline/related_legend_entry/) | Representa a entrada da legenda relacionada a esta linha de tendência<br/>            Somente leitura [`ILegendEntryProperties`](/slides/python-net/pt/aspose.slides.charts/ilegendentryproperties). |
| [`text_frame_for_overriding`](/slides/python-net/pt/aspose.slides.charts/itrendline/text_frame_for_overriding/) |  |
