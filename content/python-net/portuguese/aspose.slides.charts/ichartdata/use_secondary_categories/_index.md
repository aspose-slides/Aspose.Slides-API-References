## use_secondary_categories propriedade
Se false então a propriedade [`IChartData.secondary_categories`](/slides/python-net/pt/aspose.slides.charts/ichartdata/secondary_categories) retorna None e os dados na propriedade [`IChartData.categories`](/slides/python-net/pt/aspose.slides.charts/ichartdata/categories) são usados tanto para séries primárias quanto secundárias.
Se true então os dados na propriedade [`IChartData.secondary_categories`](/slides/python-net/pt/aspose.slides.charts/ichartdata/secondary_categories) são usados para séries secundárias e os dados na propriedade [`IChartData.categories`](/slides/python-net/pt/aspose.slides.charts/ichartdata/categories) são usados para séries primárias.
Leitura/Gravação **bool**.
