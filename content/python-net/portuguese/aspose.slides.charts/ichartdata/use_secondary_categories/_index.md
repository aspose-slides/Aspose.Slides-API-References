## use_secondary_categories propriedade
Se for falso, então [`IChartData.secondary_categories`](/slides/python-net/pt/aspose.slides.charts/ichartdata/secondary_categories) propriedade retorna None e os dados 
            em [`IChartData.categories`](/slides/python-net/pt/aspose.slides.charts/ichartdata/categories) propriedade são usados tanto para séries primárias quanto para séries secundárias.
            Se for verdadeiro, os dados em [`IChartData.secondary_categories`](/slides/python-net/pt/aspose.slides.charts/ichartdata/secondary_categories) propriedade são usados para as séries secundárias e os dados 
            em [`IChartData.categories`](/slides/python-net/pt/aspose.slides.charts/ichartdata/categories) propriedade são usados para as séries primárias.
            Leitura/Gravação **bool**.
