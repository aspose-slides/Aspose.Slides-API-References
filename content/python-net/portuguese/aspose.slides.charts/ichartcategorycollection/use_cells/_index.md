## use_cells propriedade
Se true então worksheet é usada para armazenar categorias (este caso oferece suporte a categorias de vários níveis).
            Se false então worksheet NÃO é usada para armazenar valores (e este caso não oferece suporte a 
            categorias de vários níveis).
            Leitura/gravação **bool**.
