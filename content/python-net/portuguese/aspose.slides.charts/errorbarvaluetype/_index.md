## ErrorBarValueType enumeração

Representa o tipo de valor de barra de erro

O tipo ErrorBarValueType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| CUSTOM | Especifica que o comprimento das barras de erro deve ser determinado pelos elementos Plus e Minus. |
| FIXED | Especifica que o comprimento das barras de erro deve ser o valor fixo determinado por Error Bar Value. |
| PERCENTAGE | Especifica que o comprimento das barras de erro deve ser a percentagem Error Bar Value dos dados. |
| STANDARD_DEVIATION | Especifica que o comprimento das barras de erro deve ser Error Bar Value desvios padrão dos dados. |
| STANDARD_ERROR | Especifica que o comprimento das barras de erro deve ser Error Bar Value erros padrão dos dados. |
