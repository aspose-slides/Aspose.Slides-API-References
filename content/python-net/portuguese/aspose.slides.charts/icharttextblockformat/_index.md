## IChartTextBlockFormat classe

Representa propriedades de formatação para elementos de texto de gráfico.

O tipo IChartTextBlockFormat expõe os seguintes membros:

## Propriedades

| Property | Description |
| :- | :- |
| [`anchoring_type`](/slides/python-net/pt/aspose.slides.charts/icharttextblockformat/anchoring_type/) | Retorna ou define o texto de âncora vertical em um TextFrame.<br/>            Leitura/Gravação [`TextAnchorType`](/slides/python-net/pt/aspose.slides/textanchortype). |
| [`center_text`](/slides/python-net/pt/aspose.slides.charts/icharttextblockformat/center_text/) | Se NullableBool.True, então o texto deve estar centralizado horizontalmente na caixa.<br/>            Leitura/Gravação [`NullableBool`](/slides/python-net/pt/aspose.slides/nullablebool). |
| [`text_vertical_type`](/slides/python-net/pt/aspose.slides.charts/icharttextblockformat/text_vertical_type/) | Determina a orientação do texto.<br/>            O valor resultante da rotação visual do texto resumido a partir desta propriedade e do ângulo personalizado<br/>            na propriedade RotationAngle.<br/>            Leitura/Gravação [`TextVerticalType`](/slides/python-net/pt/aspose.slides/textverticaltype). |
| [`margin_left`](/slides/python-net/pt/aspose.slides.charts/icharttextblockformat/margin_left/) | Retorna ou define a margem esquerda (pontos) em um TextFrame.<br/>            Alterar esta propriedade pode produzir certa influência apenas para estas partes do gráfico: <br/>            DataLabel e DataLabelFormat (suporte total no PowerPoint 2013; no PowerPoint 2007 não há efeito na renderização).<br/>            Leitura/Gravação **float**. |
| [`margin_right`](/slides/python-net/pt/aspose.slides.charts/icharttextblockformat/margin_right/) | Retorna ou define a margem direita (pontos) em um TextFrame.<br/>            Alterar esta propriedade pode produzir certa influência apenas para estas partes do gráfico: <br/>            DataLabel e DataLabelFormat (suporte total no PowerPoint 2013; no PowerPoint 2007 não há efeito na renderização).<br/>            Leitura/Gravação **float**. |
| [`margin_top`](/slides/python-net/pt/aspose.slides.charts/icharttextblockformat/margin_top/) | Retorna ou define a margem superior (pontos) em um TextFrame.<br/>            Alterar esta propriedade pode produzir certa influência apenas para estas partes do gráfico: <br/>            DataLabel e DataLabelFormat (suporte total no PowerPoint 2013; no PowerPoint 2007 não há efeito na renderização).<br/>            Leitura/Gravação **float**. |
| [`margin_bottom`](/slides/python-net/pt/aspose.slides.charts/icharttextblockformat/margin_bottom/) | Retorna ou define a margem inferior (pontos) em um TextFrame.<br/>            Alterar esta propriedade pode produzir certa influência apenas para estas partes do gráfico: <br/>            DataLabel e DataLabelFormat (suporte total no PowerPoint 2013; no PowerPoint 2007 não há efeito na renderização).<br/>            Leitura/Gravação **float**. |
| [`wrap_text`](/slides/python-net/pt/aspose.slides.charts/icharttextblockformat/wrap_text/) | **True** se o texto for ajustado nas margens do TextFrame.<br/>            Alterar esta propriedade pode produzir certa influência apenas para estas partes do gráfico: <br/>            DataLabel e DataLabelFormat (suporte total no PowerPoint 2007/2013).<br/>            Leitura/Gravação [`NullableBool`](/slides/python-net/pt/aspose.slides/nullablebool). |
| [`autofit_type`](/slides/python-net/pt/aspose.slides.charts/icharttextblockformat/autofit_type/) | Retorna ou define o modo de ajuste automático do texto.<br/>            Alterar esta propriedade pode produzir certa influência apenas para estas partes do gráfico: <br/>            DataLabel e DataLabelFormat (suporte total no PowerPoint 2013; no PowerPoint 2007 não há efeito na renderização).<br/>            Leitura/Gravação [`TextAutofitType`](/slides/python-net/pt/aspose.slides/textautofittype). |
| [`rotation_angle`](/slides/python-net/pt/aspose.slides.charts/icharttextblockformat/rotation_angle/) | Especifica a rotação personalizada que está sendo aplicada ao texto dentro da caixa delimitadora. Se não for<br/>            especificada, a rotação da forma associada é usada. Se for especificada, então esta é<br/>            aplicada independentemente da forma. Ou seja, a forma pode ter uma rotação aplicada além da própria rotação do texto.<br/>            O valor resultante da rotação visual do texto resumido a partir desta propriedade e do tipo vertical pré-definido na propriedade TextVerticalType.<br/>            Leitura/Gravação **float**. |
