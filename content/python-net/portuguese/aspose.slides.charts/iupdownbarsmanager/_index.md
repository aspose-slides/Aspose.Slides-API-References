## IUpDownBarsManager classe

Fornece acesso às barras de alta/baixa de gráfico de linha ou de ações.

O tipo IUpDownBarsManager expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`up_bars_format`](/slides/python-net/pt/aspose.slides.charts/iupdownbarsmanager/up_bars_format/) | Retorna o formato das barras de alta.<br/>            Somente leitura [`IFormat`](/slides/python-net/pt/aspose.slides.charts/iformat). |
| [`down_bars_format`](/slides/python-net/pt/aspose.slides.charts/iupdownbarsmanager/down_bars_format/) | Retorna o formato das barras de baixa.<br/>            Somente leitura [`IFormat`](/slides/python-net/pt/aspose.slides.charts/iformat). |
| [`has_up_down_bars`](/slides/python-net/pt/aspose.slides.charts/iupdownbarsmanager/has_up_down_bars/) | Determina se o gráfico tem barras de alta/baixa.<br/>            Leitura/gravação **bool**. |
| [`gap_width`](/slides/python-net/pt/aspose.slides.charts/iupdownbarsmanager/gap_width/) | Retorna ou define a largura do espaço.<br/>            Leitura/gravação **int**. |
