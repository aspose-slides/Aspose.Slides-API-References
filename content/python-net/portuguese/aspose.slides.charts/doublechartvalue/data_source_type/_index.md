## data_source_type propriedade
Especifica se AsCell, AsCells, AsLiteralString ou AsLiteralDouble 
            propriedade está atual nos descendentes. Em outras palavras, especifica o tipo 
            de valor da propriedade Data.
            Leitura/gravação [`DataSourceType`](/slides/python-net/pt/aspose.slides.charts/datasourcetype).


### Observações

Para pontos em ChartDataPointCollection, esta propriedade é somente leitura. 
            Neste caso, para alterar o valor desta propriedade, você pode usar uma das 
            ChartDataPointCollection.DataSourceTypeFor<...> propriedades.
