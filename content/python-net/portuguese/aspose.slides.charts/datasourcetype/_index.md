## DataSourceType enumeração

Tipos de fonte de dados.

O tipo DataSourceType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| WORKSHEET | Use objetos CellXls para armazenar XValue, YValue, Value ou BubbleSize do ponto de dados na planilha. |
| STRING_LITERALS | Use variável de string de acesso rápido para armazenar XValue, YValue, Value ou BubbleSize do <br/>            ponto de dados. Worksheet NÃO é usado para armazenar valores. |
| DOUBLE_LITERALS | Use variável de double de acesso rápido para armazenar XValue, YValue, Value ou BubbleSize do <br/>            ponto de dados. Worksheet NÃO é usado para armazenar valores. |
