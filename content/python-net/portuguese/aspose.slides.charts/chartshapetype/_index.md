## enumeração ChartShapeType

Representa uma forma de gráfico.

O tipo ChartShapeType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| NOT_DEFINED | A forma do gráfico não está definida. |
| BOX | Especifica que o gráfico deve ser desenhado com uma forma de caixa. |
| CONE | Especifica que o gráfico deve ser desenhado como um cone, com a base do cone no chão e o ponto do cone no topo do marcador de dados. |
| CONE_TO_MAX | Especifica que o gráfico deve ser desenhado com cones truncados de forma que o ponto do cone seja o valor máximo de dados. |
| CYLINDER | Especifica que o gráfico deve ser desenhado como um cilindro. |
| PYRAMID | Especifica que o gráfico deve ser desenhado como uma pirâmide retangular, com a base da pirâmide no chão e o ponto da pirâmide no topo do marcador de dados. |
| PYRAMID_TO_MAXIMUM | Especifica que o gráfico deve ser desenhado com cones truncados de forma que o ponto do cone seja o valor máximo de dados. |
