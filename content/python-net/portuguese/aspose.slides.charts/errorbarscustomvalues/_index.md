## ErrorBarsCustomValues classe

Especifica os valores das barras de erro. Deve ser usado somente quando o tipo de valor das barras de erro é Custom.

O tipo ErrorBarsCustomValues expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`x_minus`](/slides/python-net/pt/aspose.slides.charts/errorbarscustomvalues/x_minus/) | Especifica o valor da barra de erro na direção negativa. <br/>            Disponível se o tipo de valor das barras de erro for Custom e ErrorBarsXFormat for permitido.<br/>            Em qualquer outro caso, esta propriedade retorna None.<br/>            Somente leitura [`IDoubleChartValue`](/slides/python-net/pt/aspose.slides.charts/idoublechartvalue). |
| [`y_minus`](/slides/python-net/pt/aspose.slides.charts/errorbarscustomvalues/y_minus/) | Especifica o valor da barra de erro na direção negativa. <br/>            Disponível se o tipo de valor das barras de erro for Custom e ErrorBarsYFormat for permitido. <br/>            Em qualquer outro caso, esta propriedade retorna None. <br/>            Somente leitura [`IDoubleChartValue`](/slides/python-net/pt/aspose.slides.charts/idoublechartvalue). |
| [`x_plus`](/slides/python-net/pt/aspose.slides.charts/errorbarscustomvalues/x_plus/) | Especifica o valor da barra de erro na direção positiva. <br/>            Disponível se o tipo de valor das barras de erro for Custom e ErrorBarsXFormat for permitido. <br/>            Em qualquer outro caso, esta propriedade retorna None. <br/>            Somente leitura [`IDoubleChartValue`](/slides/python-net/pt/aspose.slides.charts/idoublechartvalue). |
