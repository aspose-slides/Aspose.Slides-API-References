## get_automatic_data_point_color(self) {#}
Retorna uma cor automática do ponto de dados com base no índice da série, índice do ponto de dados, na propriedade ParentSeriesGroup.IsColorVaried e no estilo do gráfico. 
            Esta cor é usada por padrão se FillType for igual a NotDefined.

### Retorno

Cor automática do ponto de dados **aspose.slides.Color**
