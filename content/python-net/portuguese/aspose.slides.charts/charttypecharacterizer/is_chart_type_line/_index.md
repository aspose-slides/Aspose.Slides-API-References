## is_chart_type_line(chart_type) {#charttype}
Retorna true se chartType for um dos subtipos de Linha.
            O conjunto de subtipos corresponde ao conjunto apropriado no PowerPoint (veja a caixa de diálogo "Change Chart Type" no PowerPoint):

            [`ChartType.PERCENTS_STACKED_LINE_WITH_MARKERS`](/slides/python-net/pt/aspose.slides.charts/charttype/PERCENTS_STACKED_LINE_WITH_MARKERS),
            [`ChartType.STACKED_LINE`](/slides/python-net/pt/aspose.slides.charts/charttype/STACKED_LINE),
            [`ChartType.STACKED_LINE_WITH_MARKERS`](/slides/python-net/pt/aspose.slides.charts/charttype/STACKED_LINE_WITH_MARKERS),
