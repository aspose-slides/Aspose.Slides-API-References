## is_visible propriedade
False significa que o rótulo de dados não está visível (e, portanto, todas as bandeiras Show*-flags (ShowValue, ...) são falsas).
            Somente leitura **bool**.

### Observações

Se o rótulo de dados está visível, você pode torná-lo oculto com o método Hide().
            Mas se o rótulo de dados não está visível (IsVisible é false) você pode tornar o rótulo de dados visível definindo as bandeiras Show*-flags (ShowValue, ...) para o estado true.
