## IChartCellCollection classe

Representa uma coleção de células com dados.

O tipo IChartCellCollection expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`count`](/slides/python-net/pt/aspose.slides.charts/ichartcellcollection/count/) | Obtém a contagem de células na coleção.<br/>            Somente leitura **int**. |

Retorna uma célula (IChartDataCell) por índice.

## Indexador

| Nome | Descrição |
| :- | :- |
| [`[index]`](/slides/python-net/pt/aspose.slides.charts/ichartcellcollection/__getitem__/) | Índice de uma célula. |

## Métodos

| Método | Descrição |
| :- | :- |
| [`add(self, chart_data_cell)`](/slides/python-net/pt/aspose.slides.charts/ichartcellcollection/add/#ichartdatacell) | Adiciona nova célula à coleção. |
| [`add(self, value)`](/slides/python-net/pt/aspose.slides.charts/ichartcellcollection/add/#any) | Cria [`IChartDataCell`](/slides/python-net/pt/aspose.slides.charts/ichartdatacell) a partir do valor especificado e o adiciona à coleção. |
| [`get_cells_address(self)`](/slides/python-net/pt/aspose.slides.charts/ichartcellcollection/get_cells_address/#) | Retorna o endereço do conjunto de células na planilha. |
| [`get_concatenated_values_from_cells(self)`](/slides/python-net/pt/aspose.slides.charts/ichartcellcollection/get_concatenated_values_from_cells/#) | String de concatenação dos valores de string de todas as células. |
| [`remove_at(self, index)`](/slides/python-net/pt/aspose.slides.charts/ichartcellcollection/remove_at/#int) | Remove uma célula da coleção por índice. |
