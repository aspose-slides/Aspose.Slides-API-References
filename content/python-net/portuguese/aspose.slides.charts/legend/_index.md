## Classe Legend

Representa as propriedades da legenda do gráfico.

O tipo Legend expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`x`](/slides/python-net/pt/aspose.slides.charts/legend/x/) | Retorna ou define a coordenada x de uma legenda como fração da largura do gráfico.<br/>            Leitura/Gravação **float**. |
| [`y`](/slides/python-net/pt/aspose.slides.charts/legend/y/) | Retorna ou define a coordenada y de uma legenda como fração da altura do gráfico.<br/>            Leitura/Gravação **float**. |
| [`width`](/slides/python-net/pt/aspose.slides.charts/legend/width/) | Retorna ou define a largura de uma legenda como fração da largura do gráfico.<br/>            Leitura/Gravação **float**. |
| [`height`](/slides/python-net/pt/aspose.slides.charts/legend/height/) | Retorna ou define a altura de uma legenda como fração da altura do gráfico.<br/>            Leitura/Gravação **float**. |
| [`right`](/slides/python-net/pt/aspose.slides.charts/legend/right/) | Direita.<br/>            Somente leitura **float**. |
| [`bottom`](/slides/python-net/pt/aspose.slides.charts/legend/bottom/) | Inferior.<br/>            Somente leitura **float**. |
| [`overlay`](/slides/python-net/pt/aspose.slides.charts/legend/overlay/) | Determina se outros elementos do gráfico podem sobrepor a legenda.<br/>            Leitura/Gravação **bool**. |
| [`text_format`](/slides/python-net/pt/aspose.slides.charts/legend/text_format/) | Formato de texto.<br/>            Somente leitura [`IChartTextFormat`](/slides/python-net/pt/aspose.slides.charts/icharttextformat). |
| [`position`](/slides/python-net/pt/aspose.slides.charts/legend/position/) | Especifica a posição da legenda em um gráfico.<br/>            Valores não-NaN das propriedades X, Y, Width, Heigt substituem o efeito desta propriedade.<br/>            Leitura/Gravação [`LegendPositionType`](/slides/python-net/pt/aspose.slides.charts/legendpositiontype). |
| [`format`](/slides/python-net/pt/aspose.slides.charts/legend/format/) | Retorna o formato de uma legenda.<br/>            Somente leitura [`IFormat`](/slides/python-net/pt/aspose.slides.charts/iformat). |
| [`chart`](/slides/python-net/pt/aspose.slides.charts/legend/chart/) | Retorna o gráfico.<br/>            Somente leitura [`IChart`](/slides/python-net/pt/aspose.slides.charts/ichart). |
| [`entries`](/slides/python-net/pt/aspose.slides.charts/legend/entries/) | Obtém as entradas da legenda.<br/>            Somente leitura [`ILegendEntryCollection`](/slides/python-net/pt/aspose.slides.charts/ilegendentrycollection). |
| [`actual_x`](/slides/python-net/pt/aspose.slides.charts/legend/actual_x/) | Especifica a localização real x (esquerda) do elemento do gráfico em relação ao canto superior esquerdo do gráfico.<br/>            Chame o método IChart.ValidateChartLayout() antes para obter valores reais. <br/>            Leitura **float**. |
| [`actual_y`](/slides/python-net/pt/aspose.slides.charts/legend/actual_y/) | Especifica o topo real do elemento do gráfico em relação ao canto superior esquerdo do gráfico.<br/>            Chame o método IChart.ValidateChartLayout() antes para obter valores reais. <br/>            Leitura **float**. |
| [`actual_width`](/slides/python-net/pt/aspose.slides.charts/legend/actual_width/) | Especifica a largura real do elemento do gráfico. Chame o método IChart.ValidateChartLayout() antes para obter valores reais. <br/>            Leitura **float**. |
| [`actual_height`](/slides/python-net/pt/aspose.slides.charts/legend/actual_height/) | Especifica a altura real do elemento do gráfico. Chame o método IChart.ValidateChartLayout() antes para obter valores reais. <br/>            Leitura **float**. |
