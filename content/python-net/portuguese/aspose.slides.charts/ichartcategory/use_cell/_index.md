## use_cell propriedade
If true then AsCell property is actual. Em outras palavras, worksheet é usado para armazenar a categoria (este caso suporta uma categoria de múltiplos níveis).
If false then AsLiteral property is actual. Em outras palavras, worksheet NÃO é usado para armazenar a categoria (e este caso não suporta categorias de múltiplos níveis).
Somente leitura **bool**.

### Observações

Para alterar o valor desta propriedade (para todas as categorias na coleção) defina o novo valor na propriedade ChartCategoryCollection.UseCells.
