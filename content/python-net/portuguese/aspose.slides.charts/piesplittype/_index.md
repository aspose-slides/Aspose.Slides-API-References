## PieSplitType enumeração

Representa um tipo de pontos de divisão no segundo pedaço ou barra 
            em um gráfico de pizza-em-pizza ou barra-em-pizza.

O tipo PieSplitType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| DEFAULT | Especifica que os pontos de dados devem ser divididos usando o mecanismo padrão <br/>            para este tipo de gráfico. |
| CUSTOM | Especifica que os pontos de dados devem ser divididos entre a <br/>            pizza e o segundo gráfico de acordo com os valores Custom Split. |
| BY_PERCENTAGE | Especifica que os pontos de dados devem ser divididos entre a pizza e o <br/>            segundo gráfico colocando os pontos com porcentagem menor que <br/>            Split Position percent no segundo gráfico. |
| BY_POS | Especifica que os pontos de dados devem ser divididos entre a pizza e o <br/>            segundo gráfico colocando a última Split Position dos pontos de dados <br/>            no segundo gráfico. |
| BY_VALUE | Especifica que os pontos de dados devem ser divididos entre a pizza e o <br/>            segundo gráfico colocando os pontos de dados com valor menor que <br/>            Split Position no segundo gráfico. |
