## IChartDataPointLevel classe

Representa o nível do ponto de dados. Aplica-se a gráficos Treemap e Sunburst.

O tipo IChartDataPointLevel expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`format`](/slides/python-net/pt/aspose.slides.charts/ichartdatapointlevel/format/) | Representa as propriedades de formatação do nível do ponto de dados.<br/>            Leitura/gravação [`IFormat`](/slides/python-net/pt/aspose.slides.charts/iformat). |
| [`label`](/slides/python-net/pt/aspose.slides.charts/ichartdatapointlevel/label/) | Representa o rótulo de dados do nível do ponto de dados. Aplicado aos tipos de séries Treemap e Sunburst.<br/>             Somente leitura [`IDataLabel`](/slides/python-net/pt/aspose.slides.charts/idatalabel). |
