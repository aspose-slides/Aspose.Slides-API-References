## Enumeração LegendDataLabelPosition

Determina a posição dos rótulos de dados.

O tipo LegendDataLabelPosition expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| NOT_DEFINED | Posição não definida. |
| BOTTOM | Especifica que os rótulos de dados devem ser exibidos abaixo do marcador de dados. |
| BEST_FIT | Especifica que os rótulos de dados devem ser exibidos na melhor posição. |
| CENTER | Especifica que os rótulos de dados devem ser exibidos centralizados no marcador de dados. |
| INSIDE_BASE | Especifica que os rótulos de dados devem ser exibidos dentro da base do marcador de dados. |
| INSIDE_END | Especifica que os rótulos de dados devem ser exibidos dentro do final do marcador de dados. |
| LEFT | Especifica que os rótulos de dados devem ser exibidos à esquerda do marcador de dados. |
| OUTSIDE_END | Especifica que os rótulos de dados devem ser exibidos fora do final do marcador de dados. |
| RIGHT | Especifica que os rótulos de dados devem ser exibidos à direita do marcador de dados. |
| TOP | Especifica que os rótulos de dados devem ser exibidos acima do marcador de dados. |
