## data_source_type propriedade
Especifica se a propriedade AsCell ou AsLiteralString ou AsLiteralDouble 
            está atual. Em outras palavras, especifica o tipo de valor da propriedade Data.
            Esta propriedade é somente leitura. Para alterar o valor desta propriedade, você pode usar
            uma das propriedades ChartDataPointCollection.DataSourceTypeFor<...>.
