## ChartDataCell classe

Representa uma célula para dados de gráfico.

O tipo ChartDataCell expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`row`](/slides/python-net/pt/aspose.slides.charts/chartdatacell/row/) | Retorna o índice da linha da planilha na qual a célula está localizada.<br/>            Somente leitura **int**. |
| [`column`](/slides/python-net/pt/aspose.slides.charts/chartdatacell/column/) | Retorna o índice da coluna da planilha na qual a célula está localizada.<br/>            Somente leitura **int**. |
| [`value`](/slides/python-net/pt/aspose.slides.charts/chartdatacell/value/) | Obtém ou define o valor de uma célula.<br/>            Leitura/gravação **any**. |
| [`formula`](/slides/python-net/pt/aspose.slides.charts/chartdatacell/formula/) | Obtém ou define a fórmula no estilo A1. |
| [`r1c1_formula`](/slides/python-net/pt/aspose.slides.charts/chartdatacell/r1c1_formula/) | Obtém ou define a fórmula no estilo R1C1. |
| [`chart_data_worksheet`](/slides/python-net/pt/aspose.slides.charts/chartdatacell/chart_data_worksheet/) | Obtém a planilha.<br/>            Somente leitura [`IChartDataWorksheet`](/slides/python-net/pt/aspose.slides.charts/ichartdataworksheet). |
| [`is_hidden`](/slides/python-net/pt/aspose.slides.charts/chartdatacell/is_hidden/) | Determina se a célula está oculta.<br/>            Somente leitura **bool**. |
| [`custom_number_format`](/slides/python-net/pt/aspose.slides.charts/chartdatacell/custom_number_format/) | Obtém ou define o formato de exibição personalizado de números e datas. <br/>            Se o valor estiver vazio, será usado o valor PresetNumberFormat.<br/>            Leitura/gravação **str**. |
| [`preset_number_format`](/slides/python-net/pt/aspose.slides.charts/chartdatacell/preset_number_format/) | Obtém ou define o formato de exibição interno de números e datas. O número predefinido deve estar em [0..22] ou [37..49].<br/>             Leitura/gravação **int**. |

## Métodos

| Método | Descrição |
| :- | :- |
| [`calculate(self, update_values)`](/slides/python-net/pt/aspose.slides.charts/chartdatacell/calculate/#bool) | Se a célula contiver uma fórmula, o valor será atualizado com base nessa fórmula. |
