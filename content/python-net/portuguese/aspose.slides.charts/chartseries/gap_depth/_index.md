## gap_depth propriedade
Retorna ou define a distância, como porcentagem da largura do marcador, entre as séries de dados em um gráfico 3D.
            Esta é a propriedade não apenas desta série, mas de todas as séries do grupo de séries pai – esta é a projeção da propriedade de grupo apropriada. E assim esta propriedade é somente leitura.
            Use ParentSeriesGroup propriedade para acessar o grupo de séries pai.
            Use ParentSeriesGroup.GapDepth propriedade de leitura/gravação para alterar o valor.
            Somente leitura **int**.


### Observações

Esta é a projeção da propriedade ParentSeriesGroup.GapDepth.
