## has_series_points propriedade
Determina se existem linhas de série para esta série e séries relacionadas.
            Esta é a propriedade não apenas desta série, mas de todas as séries do grupo de séries pai 
            grupo – esta é a projeção da propriedade de grupo apropriada. Portanto, esta propriedade 
            é somente leitura.
            Use a propriedade ParentSeriesGroup para acessar o grupo de séries pai.
            Use a propriedade leitura/escrita ParentSeriesGroup.HasSeriesLines para alterar o valor.
            Use a propriedade ParentSeriesGroup.SeriesLinesFormat para formatar linhas de série.
            Somente leitura **bool**.


### Observações

Esta é a projeção da propriedade ParentSeriesGroup.HasSeriesLines.
