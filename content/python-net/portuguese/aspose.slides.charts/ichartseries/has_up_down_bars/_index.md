## has_up_down_bars propriedade
Determina se o gráfico de Linha ou de Ações possui barras de alta/baixa.
            Esta propriedade não é apenas desta série, mas de todas as séries do grupo de séries pai 
            - isto é a projeção da propriedade apropriada do grupo. E assim esta propriedade 
            é somente leitura.
            Use a propriedade ParentSeriesGroup para acessar o grupo de séries pai.
            Use a propriedade ParentSeriesGroup.UpDownBars.HasUpDownBars de leitura/gravação para mudar o valor.
            Use a propriedade ParentSeriesGroup.UpDownBars para formatar as barras de alta/baixa.
            Somente leitura **bool**.

### Observações

Esta é a projeção da propriedade ParentSeriesGroup.UpDownBars.HasUpDownBars.
