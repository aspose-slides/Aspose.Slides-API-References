## IChartSeries classe

Representa uma série de gráfico.

O tipo IChartSeries expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`explosion`](/slides/python-net/pt/aspose.slides.charts/ichartseries/explosion/) | A distância de uma fatia de pizza aberta do centro do gráfico de pizza é expressa como uma porcentagem do diâmetro da pizza.<br/>             Leitura/gravação **int**. |
| [`smooth`](/slides/python-net/pt/aspose.slides.charts/ichartseries/smooth/) | Representa a suavização da curva. Verdadeiro se a suavização da curva estiver ativada para o gráfico de linhas ou de dispersão. Aplica-se apenas a gráficos de linhas e dispersão conectados por linhas.<br/>            Leitura/gravação **bool**. |
| [`marker`](/slides/python-net/pt/aspose.slides.charts/ichartseries/marker/) | Retorna o marcador da série.<br/>            Somente leitura [`IMarker`](/slides/python-net/pt/aspose.slides.charts/imarker). |
| [`bar_3d_shape`](/slides/python-net/pt/aspose.slides.charts/ichartseries/bar_3d_shape/) | Especifica a forma de uma série de um gráfico de barras 3-D.<br/>            Alterar o valor desta propriedade pode provocar a mudança automática do Tipo da série.<br/>            Leitura/gravação [`ChartShapeType`](/slides/python-net/pt/aspose.slides.charts/chartshapetype). |
| [`name`](/slides/python-net/pt/aspose.slides.charts/ichartseries/name/) | Retorna o nome da série.<br/>            Somente leitura [`IStringChartValue`](/slides/python-net/pt/aspose.slides.charts/istringchartvalue). |
| [`data_points`](/slides/python-net/pt/aspose.slides.charts/ichartseries/data_points/) | Retorna a coleção de pontos de dados desta série.<br/>            Somente leitura [`IChartDataPointCollection`](/slides/python-net/pt/aspose.slides.charts/ichartdatapointcollection). |
| [`type`](/slides/python-net/pt/aspose.slides.charts/ichartseries/type/) | Retorna o tipo desta série.<br/>            Leitura/gravação [`ChartType`](/slides/python-net/pt/aspose.slides.charts/charttype). |
| [`parent_series_group`](/slides/python-net/pt/aspose.slides.charts/ichartseries/parent_series_group/) | Retorna o grupo de séries pai.<br/>            Somente leitura [`IChartSeriesGroup`](/slides/python-net/pt/aspose.slides.charts/ichartseriesgroup). |

| [`trend_lines`](/slides/python-net/pt/aspose.slides.charts/ichartseries/trend_lines/) | Coleção de linhas de tendência da série<br/>            Somente leitura [`ITrendlineCollection`](/slides/python-net/pt/aspose.slides.charts/itrendlinecollection). |

| [`error_bars_y_format`](/slides/python-net/pt/aspose.slides.charts/ichartseries/error_bars_y_format/) | Representa as barras de erro da série com direção Y.<br/>            <br/>            Barras de erro com direção Y estão disponíveis para séries dos tipos área, barra, linha, dispersão e bolha. <br/>            Para quaisquer outros tipos de gráfico esta propriedade retorna None (incluindo gráficos 3D). <br/>            No caso de valores personalizados, use a coleção DataPoints para especificar o valor<br/>            (com a propriedade [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/pt/aspose.slides.charts/ichartdatapoint/error_bars_custom_values)).<br/>            <br/>            Somente leitura [`IErrorBarsFormat`](/slides/python-net/pt/aspose.slides.charts/ierrorbarsformat). |

| [`number_format_of_x_values`](/slides/python-net/pt/aspose.slides.charts/ichartseries/number_format_of_x_values/) | Retorna ou define o formato numérico para os valores x da série.<br/>            Leitura/gravação **str**. |
