## gap_depth propriedade
Retorna ou define a distância, como uma porcentagem da largura do marcador, entre as séries de dados em um gráfico 3D.
            Esta é a propriedade não apenas desta série, mas de todas as séries do grupo de séries pai 
            – isso é a projeção da propriedade de grupo apropriada. Portanto, esta propriedade 
            é somente leitura.
            Use a propriedade ParentSeriesGroup para acessar o grupo de séries pai.
            Use a propriedade ParentSeriesGroup.GapDepth de leitura/gravação para alterar o valor.
            Somente leitura **int**.


### Observações

Esta é a projeção da propriedade ParentSeriesGroup.GapDepth.
