## default_label_shape_type propriedade
Obtém ou define o tipo de forma padrão para rótulos de dados.
             Retorna [`ShapeType.NOT_DEFINED`](/slides/python-net/pt/aspose.slides/shapetype/NOT_DEFINED) se nenhuma forma estiver definida.


### Observações

Definir esta propriedade também define a propriedade [`IDataLabel.label_shape_type`](/slides/python-net/pt/aspose.slides.charts/idatalabel/label_shape_type) para todos os rótulos de dados na coleção com o mesmo valor.
