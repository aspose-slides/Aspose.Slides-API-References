## propriedade is_visible
False significa que o rótulo de dados não está visível por padrão (e, portanto, todas as bandeiras Show*-flags (ShowValue, ...) da propriedade DefaultDataLabelFormat são falsas). Somente leitura **bool**.

### Observações

Se o rótulo de dados estiver visível por padrão, você pode torná-lo oculto por padrão com o método Hide(). Mas, se o rótulo de dados não estiver visível por padrão (IsVisible é false), você pode tornar o rótulo de dados "visível por padrão" configurando as bandeiras Show*-flags (ShowValue, ...) da propriedade DefaultDataLabelFormat para o estado verdadeiro.
