## AxisAggregationType enumeração

Representa o tipo de agregação do eixo de categorias. Usado apenas com séries Histogram ou HistogramPareto.

O tipo AxisAggregationType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| BY_CATEGORY | Agrega por categorias |
| AUTOMATIC | Agrega categorias automaticamente. |
| BY_BIN_WIDTH | Agrega categorias por largura do intervalo. Property IAxis.BinWidth must be setted. |
| BY_NUMBER_OF_BINS | Agrega categorias por número de intervalos. Property IAxis.NumberOfBins must be setted. |
