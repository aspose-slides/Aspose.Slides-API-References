## AxesManager classe

Fornece acesso aos eixos do gráfico.

O tipo AxesManager expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`horizontal_axis`](/slides/python-net/pt/aspose.slides.charts/axesmanager/horizontal_axis/) | Obtém o eixo horizontal do gráfico.<br/>             Somente leitura [`IAxis`](/slides/python-net/pt/aspose.slides.charts/iaxis). |
| [`secondary_horizontal_axis`](/slides/python-net/pt/aspose.slides.charts/axesmanager/secondary_horizontal_axis/) | Obtém o eixo horizontal secundário do gráfico.<br/>             Somente leitura [`IAxis`](/slides/python-net/pt/aspose.slides.charts/iaxis). |
| [`vertical_axis`](/slides/python-net/pt/aspose.slides.charts/axesmanager/vertical_axis/) | Obtém o eixo vertical do gráfico.<br/>             Somente leitura [`IAxis`](/slides/python-net/pt/aspose.slides.charts/iaxis). |
| [`secondary_vertical_axis`](/slides/python-net/pt/aspose.slides.charts/axesmanager/secondary_vertical_axis/) | Obtém o eixo vertical secundário do gráfico.<br/>             Somente leitura [`IAxis`](/slides/python-net/pt/aspose.slides.charts/iaxis). |
| [`series_axis`](/slides/python-net/pt/aspose.slides.charts/axesmanager/series_axis/) | Obtém o eixo de séries do gráfico.<br/>             Somente leitura [`IAxis`](/slides/python-net/pt/aspose.slides.charts/iaxis). |
