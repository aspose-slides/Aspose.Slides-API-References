## propriedade format
Representa o formato do rótulo de dados.
            Somente leitura [`IFormat`](/slides/python-net/pt/aspose.slides.charts/iformat).

### Observações

Se o pai deste objeto DataLabelFormat for uma coleção DataLabelCollection de rótulos de dados, então esta propriedade
            representa o formato padrão para os novos rótulos de dados na coleção DataLabelCollection.
