## show_label_as_data_callout propriedade
Determina se o rótulo de dados do gráfico especificado será exibido como chamada de dados ou como rótulo de dados.
            
            Se o pai deste objeto DataLabelFormat for uma coleção DataLabelCollection de rótulos de dados, então esta propriedade obtém ou define o valor padrão da propriedade ShowLabelAsDataCallout para os novos rótulos de dados na coleção DataLabelCollection.
            Definir esta propriedade com um valor também define esse valor na propriedade ShowLabelAsDataCallout para todos os rótulos de dados na coleção DataLabelCollection
            (por exemplo, "DataLabels.DefaultDataLabelFormat.ShowLabelAsDataCallout = val;" faz com que todos DataLabels[i].ShowLabelAsDataCallout sejam iguais a val).
