## Enumeração ChartType

Representa um tipo de gráfico.

O tipo ChartType expõe os seguintes membros:

| Campo | Descrição |
| :- | :- |
| CLUSTERED_COLUMN | Representa um Gráfico de Colunas Agrupadas. |
| STACKED_COLUMN | Representa um Gráfico de Colunas Empilhadas. |
| PERCENTS_STACKED_COLUMN | Representa um Gráfico de Colunas Empilhadas em 100%. |
| CLUSTERED_COLUMN_3D | Representa um Gráfico de Colunas Agrupadas 3D. |
| STACKED_COLUMN_3D | Representa um Gráfico de Colunas Empilhadas 3D. |

| PERCENTS_STACKED_CYLINDER | Representa um Gráfico de Cilindro Empilhado 100%. |
| CYLINDER_3D | Representa um Gráfico de Cilindro 3D. |
| CLUSTERED_CONE | Representa um Gráfico de Cone. |
| STACKED_CONE | Representa um Gráfico de Cone Empilhado. |
