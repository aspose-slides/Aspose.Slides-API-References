Contains classes and methods to handle complex general operations in a low code way.
## Classes

| Classe | Descrição |
| :- | :- |
| [`Collect`](/slides/python-net/pt/aspose.slides.lowcode/collect/) | Representa um grupo de métodos destinados a coletar objetos de modelo de diferentes tipos de [`Presentation`](/slides/python-net/pt/aspose.slides/presentation). |
| [`Compress`](/slides/python-net/pt/aspose.slides.lowcode/compress/) | Representa um grupo de métodos destinados a compactar [`Presentation`](/slides/python-net/pt/aspose.slides/presentation). |
| [`Convert`](/slides/python-net/pt/aspose.slides.lowcode/convert/) | Representa um grupo de métodos destinados a converter [`Presentation`](/slides/python-net/pt/aspose.slides/presentation). |
| [`ForEach`](/slides/python-net/pt/aspose.slides.lowcode/foreach/) | Representa um grupo de métodos destinados a iterar sobre diferentes objetos de modelo [`Presentation`](/slides/python-net/pt/aspose.slides/presentation).<br/>            Esses métodos podem ser úteis se você precisar iterar e alterar a formatação ou o conteúdo de alguns elementos da Presentation,<br/>             por exemplo, alterar a formatação de cada porção. |
| [`Merger`](/slides/python-net/pt/aspose.slides.lowcode/merger/) | Representa um grupo de métodos para mesclar apresentações PowerPoint do mesmo formato em um único arquivo. |
