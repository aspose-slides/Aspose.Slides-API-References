## IBlur classe

Representa um efeito de desfoque que é aplicado a toda a forma, incluindo seu preenchimento.
Todos os canais de cor, incluindo o alfa, são afetados.

O tipo IBlur expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`radius`](/slides/python-net/pt/aspose.slides.effects/iblur/radius/) | Retorna ou define o raio do desfoque.<br/>            Leitura/gravação **float**. |
| [`grow`](/slides/python-net/pt/aspose.slides.effects/iblur/grow/) | Determina se os limites do objeto devem ser ampliados como resultado do desfoque.<br/>            True indica que os limites são ampliados enquanto false indica que não são.<br/>            Leitura/gravação **bool**. |
