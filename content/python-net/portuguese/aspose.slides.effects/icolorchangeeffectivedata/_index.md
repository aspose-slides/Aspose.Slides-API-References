## IColorChangeEffectiveData classe

Objeto imutável que representa um efeito de mudança de cor.  
Instâncias de FromColor são substituídas por instâncias de ToColor.

O tipo IColorChangeEffectiveData expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`from_color`](/slides/python-net/pt/aspose.slides.effects/icolorchangeeffectivedata/from_color/) | Cor que será substituída.<br/>            Somente leitura **aspose.slides.Color**. |
| [`to_color`](/slides/python-net/pt/aspose.slides.effects/icolorchangeeffectivedata/to_color/) | Cor que substituirá.<br/>            Somente leitura **aspose.slides.Color**. |
| [`use_alpha`](/slides/python-net/pt/aspose.slides.effects/icolorchangeeffectivedata/use_alpha/) | Retorna um valor booleano que determina se o componente alfa deve ser usado.<br/>            Somente leitura **bool**. |
