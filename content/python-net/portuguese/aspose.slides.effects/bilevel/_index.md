## BiLevel classe

Represents a Bi-Level (black/white) effect.
            Cores de entrada cuja luminância é menor que o valor de limiar especificado são alteradas para preto.
            Cores de entrada cuja luminância é maior ou igual ao valor especificado são definidas como branco.
            Os valores de efeito alfa não são afetados por este efeito.
