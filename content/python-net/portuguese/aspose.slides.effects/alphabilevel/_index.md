## AlphaBiLevel classe

Representa um efeito Alpha Bi-Level.
            Valores Alpha (Opacidade) menores que o limiar são alterados para 0 (totalmente transparente) e
            valores alpha maiores ou iguais ao limiar são alterados para 100% (totalmente opaco).
