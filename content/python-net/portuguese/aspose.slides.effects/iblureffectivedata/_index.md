## IBlurEffectiveData classe

Objeto imutável que representa um efeito de desfoque aplicado a toda a forma, incluindo seu preenchimento.
            Todos os canais de cor, incluindo alfa, são afetados.

O tipo IBlurEffectiveData expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`radius`](/slides/python-net/pt/aspose.slides.effects/iblureffectivedata/radius/) | Retorna ou define o raio do desfoque.<br/>            Somente leitura **float**. |
| [`grow`](/slides/python-net/pt/aspose.slides.effects/iblureffectivedata/grow/) | Determina se os limites do objeto devem ser ampliados como resultado do desfoque.<br/>            True indica que os limites são ampliados enquanto false indica que não são.<br/>            Somente leitura **bool**. |
