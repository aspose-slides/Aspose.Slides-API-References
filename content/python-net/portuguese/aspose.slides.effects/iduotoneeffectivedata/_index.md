## IDuotoneEffectiveData classe

Objeto imutável que representa um efeito Duotone.
            Para cada pixel, combina clr1 e clr2 por meio de uma interpolação linear
            para determinar a nova cor desse pixel.

O tipo IDuotoneEffectiveData expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`color1`](/slides/python-net/pt/aspose.slides.effects/iduotoneeffectivedata/color1/) | Retorna o formato de cor de destino para pixels escuros.<br/>            Somente leitura [`Color`](/slides/python-net/pt/aspose.slides/color). |
| [`color2`](/slides/python-net/pt/aspose.slides.effects/iduotoneeffectivedata/color2/) | Retorna o formato de cor de destino para pixels claros.<br/>            Somente leitura [`Color`](/slides/python-net/pt/aspose.slides/color). |
