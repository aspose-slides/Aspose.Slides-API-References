Contém classes para trabalhar com vários efeitos em apresentações do Microsoft PowerPoint.
## Classes

| Classe | Descrição |
| :- | :- |
| [`AlphaBiLevel`](/slides/python-net/pt/aspose.slides.effects/alphabilevel/) | Representa um efeito Alpha Bi-Level.<br/>            Valores Alpha (Opacidade) menores que o limiar são alterados para 0 (totalmente transparente) e<br/>            valores alpha maiores ou iguais ao limiar são alterados para 100% (totalmente opaco). |
| [`AlphaCeiling`](/slides/python-net/pt/aspose.slides.effects/alphaceiling/) | Representa um efeito Alpha Ceiling.<br/>            Valores Alpha (opacidade) maiores que zero são alterados para 100%.<br/>            Em outras palavras, qualquer coisa parcialmente opaca se torna totalmente opaca. |
