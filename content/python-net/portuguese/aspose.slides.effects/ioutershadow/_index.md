## IOuterShadow classe

Representa um efeito de sombra externa.

O tipo IOuterShadow expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`blur_radius`](/slides/python-net/pt/aspose.slides.effects/ioutershadow/blur_radius/) | Raio de desfoque, em pontos.<br/>            Valor padrão – 0 pt.<br/>            Leitura/gravação **float**. |
| [`direction`](/slides/python-net/pt/aspose.slides.effects/ioutershadow/direction/) | Direção da sombra, em graus.<br/>            Valor padrão – 0 ° (da esquerda para a direita).<br/>            Leitura/gravação **float**. |
| [`distance`](/slides/python-net/pt/aspose.slides.effects/ioutershadow/distance/) | Distância da sombra ao objeto, em pontos.<br/>            Valor padrão – 0 pt.<br/>            Leitura/gravação **float**. |
| [`shadow_color`](/slides/python-net/pt/aspose.slides.effects/ioutershadow/shadow_color/) | Cor da sombra.<br/>            Valor padrão – preto automático (dependente do tema).<br/>            Somente leitura [`IColorFormat`](/slides/python-net/pt/aspose.slides/icolorformat). |
| [`rectangle_align`](/slides/python-net/pt/aspose.slides.effects/ioutershadow/rectangle_align/) | Alinhamento do retângulo.<br/>            Valor padrão – [`RectangleAlignment.BOTTOM`](/slides/python-net/pt/aspose.slides/rectanglealignment/BOTTOM). <br/>            Leitura/gravação [`RectangleAlignment`](/slides/python-net/pt/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/pt/aspose.slides.effects/ioutershadow/skew_horizontal/) | Ângulo de inclinação horizontal, em graus.<br/>            Valor padrão – 0 °.<br/>            Leitura/gravação **float**. |
| [`skew_vertical`](/slides/python-net/pt/aspose.slides.effects/ioutershadow/skew_vertical/) | Ângulo de inclinação vertical, em graus.<br/>            Valor padrão – 0 °.<br/>            Leitura/gravação **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/pt/aspose.slides.effects/ioutershadow/rotate_shadow_with_shape/) | Indica se a sombra gira juntamente com a forma.<br/>            Valor padrão – true.<br/>            Leitura/gravação **bool**. |
| [`scale_horizontal`](/slides/python-net/pt/aspose.slides.effects/ioutershadow/scale_horizontal/) | Fator de escala horizontal, em porcentagem do tamanho original.<br/>            Escala negativa causa uma inversão.<br/>            Valor padrão – 100 %.<br/>            Leitura/gravação **float**. |
| [`scale_vertical`](/slides/python-net/pt/aspose.slides.effects/ioutershadow/scale_vertical/) | Fator de escala vertical, em porcentagem do tamanho original.<br/>            Escala negativa causa uma inversão.<br/>            Valor padrão – 100 %.<br/>            Leitura/gravação **float**. |
