## IReflection classe

Representa um efeito de reflexão.

O tipo IReflection expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/pt/aspose.slides.effects/ireflection/start_pos_alpha/) | Especifica a posição inicial (ao longo da rampa de gradiente alfa) do valor alfa inicial (porcentagens).<br/>            Leitura/escrita **float**. |
| [`end_pos_alpha`](/slides/python-net/pt/aspose.slides.effects/ireflection/end_pos_alpha/) | Especifica a posição final (ao longo da rampa de gradiente alfa) do valor alfa final (porcentagens).<br/>            Leitura/escrita **float**. |
| [`fade_direction`](/slides/python-net/pt/aspose.slides.effects/ireflection/fade_direction/) | Especifica a direção para deslocar a reflexão. (ângulo).<br/>            Leitura/escrita **float**. |
| [`start_reflection_opacity`](/slides/python-net/pt/aspose.slides.effects/ireflection/start_reflection_opacity/) | Opacidade inicial da reflexão. (porcentagens).<br/>            Leitura/escrita **float**. |
| [`end_reflection_opacity`](/slides/python-net/pt/aspose.slides.effects/ireflection/end_reflection_opacity/) | Opacidade final da reflexão. (porcentagens).<br/>            Leitura/escrita **float**. |
| [`blur_radius`](/slides/python-net/pt/aspose.slides.effects/ireflection/blur_radius/) | Raio do desfoque.<br/>            Leitura/escrita **float**. |
| [`direction`](/slides/python-net/pt/aspose.slides.effects/ireflection/direction/) | Direção da reflexão.<br/>            Leitura/escrita **float**. |
| [`distance`](/slides/python-net/pt/aspose.slides.effects/ireflection/distance/) | Distância da reflexão.<br/>            Leitura/escrita **float**. |
| [`rectangle_align`](/slides/python-net/pt/aspose.slides.effects/ireflection/rectangle_align/) | Alinhamento do retângulo.<br/>            Leitura/escrita [`RectangleAlignment`](/slides/python-net/pt/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/pt/aspose.slides.effects/ireflection/skew_horizontal/) | Especifica o ângulo de inclinação horizontal.<br/>            Leitura/escrita **float**. |
| [`skew_vertical`](/slides/python-net/pt/aspose.slides.effects/ireflection/skew_vertical/) | Especifica o ângulo de inclinação vertical.<br/>            Leitura/escrita **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/pt/aspose.slides.effects/ireflection/rotate_shadow_with_shape/) | Especifica se a reflexão deve girar com a forma caso a forma seja girada.<br/>            Leitura/escrita **bool**. |
| [`scale_horizontal`](/slides/python-net/pt/aspose.slides.effects/ireflection/scale_horizontal/) | Especifica o fator de escala horizontal, escalonamento negativo provoca uma inversão. (porcentagens)<br/>            Leitura/escrita **float**. |
| [`scale_vertical`](/slides/python-net/pt/aspose.slides.effects/ireflection/scale_vertical/) | Especifica o fator de escala vertical, escalonamento negativo provoca uma inversão. (porcentagens)<br/>            Leitura/escrita **float**. |
