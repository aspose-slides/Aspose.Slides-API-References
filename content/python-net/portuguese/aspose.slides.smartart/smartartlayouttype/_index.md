## Enumeração SmartArtLayoutType

Representa o tipo de layout de um diagrama SmartArt.

O tipo SmartArtLayoutType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| ACCENT_PROCESS | Use para mostrar uma progressão, uma linha do tempo ou etapas sequenciais em uma tarefa, processo ou fluxo de trabalho. Funciona bem para ilustrar textos de Nível 1 e Nível 2. |
| ACCENTED_PICTURE | Use para mostrar uma ideia fotográfica central com ideias relacionadas ao lado. O texto de Nível 1 superior aparece sobre a imagem central. O texto correspondente para outras formas de Nível 1 aparece ao lado das pequenas imagens circulares. Esse layout também funciona bem sem texto. |
| ALTERNATING_FLOW | Use para mostrar grupos de informações ou etapas sequenciais em uma tarefa, processo ou fluxo de trabalho. Enfatiza a interação ou os relacionamentos entre os grupos de informações. |
| ALTERNATING_HEXAGONS | Use para representar uma série de ideias interconectadas. O texto de Nível 1 aparece dentro dos hexágonos. O texto de Nível 2 aparece fora das formas. |
| ALTERNATING_PICTURE_BLOCKS | Use para mostrar uma série de imagens de cima para baixo. O texto aparece alternadamente à direita ou à esquerda da imagem. |
| ALTERNATING_PICTURE_CIRCLES | Use para mostrar um conjunto de imagens com texto. O texto correspondente aparece nos círculos centrais, com as imagens alternando da esquerda para a direita. |
| ARROW_RIBBON | Use para mostrar conceitos relacionados ou contrastantes com alguma conexão, como forças opostas. As duas primeiras linhas do texto de Nível 1 são usadas como texto nas setas. Texto não utilizado não aparece, mas permanece disponível se você mudar o layout. |
| ASCENDING_PICTURE_ACCENT_PROCESS | Use para mostrar uma série ascendente de imagens com texto descritivo. Funciona melhor com uma pequena quantidade de texto. |
| BALANCE | Use para comparar ou mostrar a relação entre duas ideias. Cada uma das duas primeiras linhas do texto de Nível 1 corresponde a texto na parte superior de um lado do ponto central. Enfatiza o texto de Nível 2, que é limitado a quatro formas em cada lado do ponto central. O equilíbrio inclina-se para o lado com mais formas contendo texto de Nível 2. Texto não utilizado não aparece, mas permanece disponível se você mudar o layout. |
| BASIC_BENDING_PROCESS | Use para mostrar uma progressão ou etapas sequenciais em uma tarefa, processo ou fluxo de trabalho. Maximiza tanto o espaço de exibição horizontal quanto o vertical para as formas. |
| BASIC_BLOCK_LIST | Use para mostrar blocos de informação não sequenciais ou agrupados. Maximiza tanto o espaço de exibição horizontal quanto o vertical para as formas. |
| BASIC_CHEVRON_PROCESS | Use para mostrar uma progressão; uma linha do tempo; etapas sequenciais em uma tarefa, processo ou fluxo de trabalho; ou para enfatizar movimento ou direção. O texto de Nível 1 aparece dentro de uma forma de seta enquanto o texto de Nível 2 aparece abaixo das formas de seta. |
| BASIC_CYCLE | Use para representar uma sequência contínua de estágios, tarefas ou eventos em um fluxo circular. Enfatiza os estágios ou etapas ao invés das setas ou fluxo de conexão. Funciona melhor somente com texto de Nível 1. |
| BASIC_MATRIX | Use para mostrar a relação dos componentes com um todo em quadrantes. As quatro primeiras linhas do texto de Nível 1 aparecem nos quadrantes. Texto não utilizado não aparece, mas permanece disponível se você mudar o layout. |
| BASIC_PIE | Use para mostrar como partes individuais formam um todo. As sete primeiras linhas do texto de Nível 1 correspondem às formas de fatia ou pizza distribuídas uniformemente. A forma de texto de Nível 1 superior aparece fora do restante da pizza para ênfase. Texto não utilizado não aparece, mas permanece disponível se você mudar o layout. |
| BASIC_PROCESS | Use para mostrar uma progressão ou etapas sequenciais em uma tarefa, processo ou fluxo de trabalho. |
| BASIC_PYRAMID | Use para mostrar relações proporcionais, interconectadas ou hierárquicas com o maior componente na parte inferior e estreitando para cima. O texto de Nível 1 aparece nos segmentos da pirâmide e o texto de Nível 2 aparece nas formas ao lado de cada segmento. |
| BASIC_RADIAL | Use para mostrar a relação a uma ideia central em um ciclo. A primeira linha do texto de Nível 1 corresponde à forma central, e seu texto de Nível 2 corresponde às formas circulares ao redor. Texto não utilizado não aparece, mas permanece disponível se você mudar o layout. |
| BASIC_TARGET | Use para mostrar contenção, gradações ou relações hierárquicas. As cinco primeiras linhas do texto de Nível 1 estão associadas a um círculo. Texto não utilizado não aparece, mas permanece disponível se você mudar o layout. |
| BASIC_TIMELINE | Use para mostrar etapas sequenciais em uma tarefa, processo ou fluxo de trabalho, ou para mostrar informações de linha do tempo. Funciona bem com textos de Nível 1 e Nível 2. |
| BASIC_VENN | Use para mostrar relações sobrepostas ou interconectadas. As sete primeiras linhas do texto de Nível 1 correspondem a um círculo. Se houver quatro ou menos linhas de texto de Nível 1, o texto fica dentro dos círculos. Se houver mais de quatro linhas de texto de Nível 1, o texto fica fora dos círculos. Texto não utilizado não aparece, mas permanece disponível se você mudar o layout. |
| BENDING_PICTURE_ACCENT_LIST | Use para mostrar blocos de informação não sequenciais ou agrupados. As pequenas formas circulares são projetadas para conter imagens. Funciona bem para ilustrar textos de Nível 1 e Nível 2. Maximiza tanto o espaço de exibição horizontal quanto o vertical para as formas. |
| BENDING_PICTURE_BLOCKS | Use para mostrar uma série de imagens. A caixa que cobre o canto inferior pode conter pequenas quantidades de texto. |
| BENDING_PICTURE_CAPTION | Use para mostrar uma série sequencial de imagens. A caixa que cobre o canto inferior pode conter pequenas quantidades de texto. |
| BENDING_PICTURE_CAPTION_LIST | Use para mostrar uma série de imagens. O título e a descrição aparecem em uma forma de chamada sob cada imagem. |
| BENDING_PICTURE_SEMI_TRANSPARENT_TEXT | Use para mostrar uma série de imagens. Uma caixa semitransparente cobre a parte inferior da imagem e contém todos os níveis de texto. |
| BLOCK_CYCLE | Use para representar uma sequência contínua de estágios, tarefas ou eventos em um fluxo circular. Enfatiza os estágios ou etapas ao invés das setas ou fluxo de conexão. |
| BUBBLE_PICTURE_LIST | Use para mostrar uma série de imagens. Pode conter até oito imagens de Nível 1. Texto e imagens não utilizados não aparecem, mas permanecem disponíveis se você mudar o layout. Funciona melhor com pequenas quantidades de texto. |
| CAPTIONED_PICTURES | Use para mostrar imagens com múltiplos níveis de texto. Funciona melhor com uma pequena quantidade de texto de Nível 1 e uma quantidade média de texto de Nível 2. |
| CHEVRON_LIST | Use para mostrar uma progressão através de vários processos que compõem um fluxo de trabalho geral. Também funciona para ilustrar processos contrastantes. O texto de Nível 1 corresponde à primeira forma de seta à esquerda, enquanto o texto de Nível 2 corresponde a subetapas horizontais para cada forma que contém texto de Nível 1. |
| CIRCLE_ACCENT_TIMELINE | Use para mostrar uma série de eventos ou informações de linha do tempo. O texto de Nível 1 aparece ao lado de formas circulares maiores. O texto de Nível 2 aparece ao lado de formas circulares menores. |
| CIRCLE_ARROW_PROCESS | Use para mostrar itens sequenciais com texto de apoio para cada item. Este diagrama funciona melhor com pequenas quantidades de texto de Nível 1. |
| CIRCLE_PICTURE_HIERARCHY | Use para mostrar informações hierárquicas ou relações de reporte em uma organização. As imagens aparecem em círculos e o texto correspondente aparece ao lado das imagens. |
| CIRCLE_RELATIONSHIP | Use para mostrar a relação com ou a partir de uma ideia central. O texto de Nível 2 é adicionado de forma não sequencial e é limitado a cinco itens. Pode haver apenas um item de Nível 1. |
| CIRCULAR_BENDING_PROCESS | Use para mostrar uma sequência longa ou não linear de passos em uma tarefa, processo ou fluxo de trabalho. Funciona melhor apenas com texto de Nível 1. Maximiza tanto o espaço de exibição horizontal quanto o vertical para as formas. |
| CIRCULAR_PICTURE_CALLOUT | Use para mostrar uma ideia central e sub-ideias ou itens relacionados. O texto da primeira imagem cobre a parte inferior da imagem. O texto correspondente para outras formas de Nível 1 aparece ao lado das pequenas imagens circulares. Este diagrama também funciona bem sem texto. |
| CLOSED_CHEVRON_PROCESS | Use para mostrar uma progressão, uma linha do tempo ou etapas sequenciais em uma tarefa, processo ou fluxo de trabalho, ou para enfatizar movimento ou direção. Pode ser usado para enfatizar informações na forma inicial. Funciona melhor apenas com texto de Nível 1. |
| CONTINUOUS_ARROW_PROCESS | Use para mostrar uma linha do tempo ou etapas sequenciais em uma tarefa, processo ou fluxo de trabalho. Funciona melhor com texto de Nível 1 porque cada linha de texto de Nível 1 aparece dentro da forma de seta. O texto de Nível 2 aparece fora da forma de seta. |
| CONTINUOUS_BLOCK_PROCESS | Use para mostrar uma progressão ou etapas sequenciais em uma tarefa, processo ou fluxo de trabalho. Funciona melhor com textos de Nível 1 e Nível 2 mínimos. |
| CONTINUOUS_CYCLE | Use para representar uma sequência contínua de estágios, tarefas ou eventos em um fluxo circular. Enfatiza a conexão entre todos os componentes. Funciona melhor apenas com texto de Nível 1. |
| CONTINUOUS_PICTURE_LIST | Use para mostrar grupos de informações interconectadas. As formas circulares são projetadas para conter imagens. |
| CONVERGING_ARROWS | Use para mostrar ideias ou conceitos que convergem para um ponto central. Funciona melhor apenas com texto de Nível 1. |
| CONVERGING_RADIAL | Use para mostrar relações de conceitos ou componentes a uma ideia central em um ciclo. A primeira linha do texto de Nível 1 corresponde à forma circular central e as linhas de texto de Nível 2 correspondem às formas retangulares ao redor. Texto não utilizado não aparece, mas permanece disponível se você mudar o layout. |
| COUNTERBALANCE_ARROWS | Use para mostrar duas ideias ou conceitos opostos. Cada uma das duas primeiras linhas do texto de Nível 1 corresponde a uma seta e funciona bem com texto de Nível 2. Texto não utilizado não aparece, mas permanece disponível se você mudar o layout. |
| CYCLE_MATRIX | Use para mostrar a relação a uma ideia central em uma progressão cíclica. Cada uma das quatro primeiras linhas do texto de Nível 1 corresponde a uma fatia ou forma de pizza, e o texto de Nível 2 aparece em uma forma retangular ao lado da fatia ou forma de pizza. Texto não utilizado não aparece, mas permanece disponível se você mudar o layout. |
| DESCENDING_BLOCK_LIST | Use para mostrar grupos de ideias relacionadas ou listas de informações. As formas de texto diminuem de altura sequencialmente, e o texto de Nível 1 é exibido verticalmente. |
| DESCENDING_PROCESS | Use para mostrar uma série descendente de eventos. O primeiro texto de Nível 1 está no topo da seta, e o último texto de Nível 1 é exibido na parte inferior da seta. Apenas os primeiros sete itens de Nível 1 aparecem. Funciona melhor com pequenas a médias quantidades de texto. |
| DETAILED_PROCESS | Use com grandes quantidades de texto de Nível 2 para mostrar uma progressão através de estágios. |
| DIVERGING_ARROWS | Use para mostrar ideias ou conceitos que progridem para fora a partir de uma fonte central. Funciona melhor apenas com texto de Nível 1. |
| DIVERGING_RADIAL | Use para mostrar relações a uma ideia central em um ciclo. A primeira linha de texto de Nível 1 corresponde à forma circular central. Enfatiza os círculos ao redor ao invés da ideia central. Texto não utilizado não aparece, mas permanece disponível se você mudar o layout. |
| EQUATION | Use para mostrar etapas ou tarefas sequenciais que descrevem um plano ou resultado. A última linha de texto de Nível 1 aparece após o sinal de igual (=). Funciona melhor apenas com texto de Nível 1. |
| FRAMED_TEXT_PICTURE | Use para mostrar imagens com texto de Nível 1 correspondente exibido em uma moldura. |
| FUNNEL | Use para mostrar a filtragem de informações ou como partes se juntam em um todo. Enfatiza o resultado final. Pode conter até quatro linhas de texto de Nível 1; a última dessas quatro linhas de texto de Nível 1 aparece abaixo do funil e as outras linhas correspondem a uma forma circular. Texto não utilizado não aparece, mas permanece disponível se você mudar o layout. |
| GEAR | Use para mostrar ideias interligadas. Cada uma das três primeiras linhas do texto de Nível 1 corresponde a uma forma de engrenagem, e o texto de Nível 2 correspondente aparece em retângulos ao lado da forma de engrenagem. Texto não utilizado não aparece, mas permanece disponível se você mudar o layout. |
| GRID_MATRIX | Use para mostrar a colocação de conceitos ao longo de dois eixos. Enfatiza os componentes individuais em vez do todo. As quatro primeiras linhas do texto do Nível 1 aparecem nos quadrantes. O texto não usado não aparece, mas permanece disponível se você mudar os layouts. |
| GROUPED_LIST | Use para mostrar grupos e subgrupos de informação, ou etapas e subetapas em uma tarefa, processo ou fluxo de trabalho. O texto do Nível 1 corresponde às formas horizontais de nível superior, e o texto do Nível 2 corresponde às subetapas verticais sob cada forma de nível superior relacionada. Funciona bem para enfatizar subgrupos ou subetapas, informação hierárquica ou múltiplas listas de informação. |
| HALF_CIRCLE_ORGANIZATION_CHART | Use para mostrar informação hierárquica ou relações de reporte em uma organização. As formas assistentes e os layouts suspensos de Org Chart estão disponíveis com este layout. |
| HEXAGON_CLUSTER | Use para mostrar imagens com texto descritivo associado. Hexágonos pequenos indicam o par imagem-texto. Funciona melhor com pequenas quantidades de texto. |
| HIERARCHY | Use para mostrar relações hierárquicas que progridem de cima para baixo. |
| HIERARCHY_LIST | Use para mostrar relações hierárquicas que progridem entre grupos. Também pode ser usado para agrupar ou listar informações. |
| HORIZONTAL_BULLET_LIST | Use para mostrar listas de informação não sequenciais ou agrupadas. Funciona bem com grandes quantidades de texto. Todo o texto tem o mesmo nível de ênfase e a direção não é implícita. |
| HORIZONTAL_HIERARCHY | Use para mostrar relações hierárquicas que progridem horizontalmente. Funciona bem para árvores de decisão. |
| HORIZONTAL_LABELED_HIERARCHY | Use para mostrar relações hierárquicas que progridem horizontalmente e são agrupadas hierarquicamente. Enfatiza o título ou o texto do Nível 1. A primeira linha do texto do Nível 1 aparece na forma no início da hierarquia, e a segunda e todas as demais linhas do texto do Nível 1 aparecem no topo dos retângulos altos. |
| HORIZONTAL_MULTI_LEVEL_HIERARCHY | Use para mostrar grandes quantidades de informação hierárquica que progridem horizontalmente. A parte superior da hierarquia é exibida verticalmente. Este layout suporta muitos níveis na hierarquia. |
| HORIZONTAL_ORGANIZATION_CHART | Use para mostrar informação hierárquica horizontalmente ou relações de reporte em uma organização. A forma assistente e os layouts suspensos de Org Chart estão disponíveis com este layout. |
| HORIZONTAL_PICTURE_LIST | Use para mostrar informação não sequencial ou agrupada com ênfase em imagens relacionadas. As formas superiores são projetadas para conter imagens. |
| INCREASING_ARROWS_PROCESS | Use para mostrar etapas sequenciais e sobrepostas em um processo. Limitado a cinco itens do Nível 1. O Nível 2 pode conter grandes quantidades de texto. |
| INCREASING_CIRCLE_PROCESS | Use para mostrar uma série de etapas, com o interior do círculo aumentando a cada etapa. Limitado a sete etapas do Nível 1, mas itens ilimitados do Nível 2. Funciona bem com grandes quantidades de texto do Nível 2. |
| INVERTED_PYRAMID | Use para mostrar relações proporcionais, interconectadas ou hierárquicas, com o maior componente no topo e afinando para baixo. O texto do Nível 1 aparece nos segmentos da pirâmide e o texto do Nível 2 aparece nas formas ao lado de cada segmento. |
| LABELED_HIERARCHY | Use para mostrar relações hierárquicas que progridem de cima para baixo e são agrupadas hierarquicamente. Enfatiza o título ou o texto do Nível 1. A primeira linha do texto do Nível 1 aparece na forma no início da hierarquia, e todas as demais linhas do texto do Nível 1 aparecem à esquerda dos retângulos longos. |
| LINEAR_VENN | Use para mostrar relações sobrepostas em uma sequência. Funciona melhor apenas com texto do Nível 1. |
| LINED_LIST | Use para mostrar grandes quantidades de texto divididas em categorias e subcategorias. Funciona bem com múltiplos níveis de texto. Texto no mesmo nível é separado por linhas. |
| MULTIDIRECTIONAL_CYCLE | Use para representar uma sequência contínua de estágios, tarefas ou eventos que podem ocorrer em qualquer direção. |
| NAMEAND_TITLE_ORGANIZATION_CHART | Use para mostrar informação hierárquica ou relações de reporte em uma organização. Para inserir texto na caixa de título, digite diretamente na forma retangular menor. A forma assistente e os layouts suspensos de Org Chart estão disponíveis com este layout. |
| NESTED_TARGET | Use para mostrar relações de contenção. Cada uma das três primeiras linhas do texto do Nível 1 corresponde ao texto superior esquerdo nas formas, e o texto do Nível 2 corresponde às formas menores. Funciona melhor com poucas linhas de texto do Nível 2. O texto não usado não aparece, mas permanece disponível se você mudar os layouts. |
| NONDIRECTIONAL_CYCLE | Use para representar uma sequência contínua de estágios, tarefas ou eventos em fluxo circular. Cada forma tem o mesmo nível de importância. Funciona bem quando a direção não precisa ser indicada. |
| OPPOSING_ARROWS | Use para mostrar duas ideias opostas, ou ideias que divergêm de um ponto central. Cada uma das duas primeiras linhas do texto do Nível 1 corresponde a uma seta. O texto não usado não aparece, mas permanece disponível se você mudar os layouts. |
| OPPOSING_IDEAS | Use para mostrar duas ideias opostas ou contrastantes. Pode ter um ou dois itens do Nível 1. Cada texto do Nível 1 pode conter múltiplos subníveis. Funciona bem com grandes quantidades de texto. |
| ORGANIZATION_CHART | Use para mostrar informação hierárquica ou relações de reporte em uma organização. A forma assistente e os layouts suspensos de Org Chart estão disponíveis com este layout. |
| PHASED_PROCESS | Use para mostrar três fases de um processo. Limitado a três itens do Nível 1. As duas primeiras itens do Nível 1 podem conter cada quatro itens do Nível 2, e o terceiro item do Nível 1 pode conter número ilimitado de itens do Nível 2. Funciona melhor com pequenas quantidades de texto. |
| PICTURE_ACCENT_BLOCKS | Use para mostrar um grupo de imagens em blocos a partir do canto. O texto correspondente é exibido verticalmente. Funciona bem como destaque em slides de título ou subtítulo ou para quebras de seção de um documento. |
| PICTURE_ACCENT_LIST | Use para mostrar informação agrupada ou relacionada. As formas pequenas nos cantos superiores são projetadas para conter imagens. Enfatiza o texto do Nível 2 sobre o texto do Nível 1, sendo uma boa escolha para grandes quantidades de texto do Nível 2. |
| PICTURE_ACCENT_PROCESS | Use para mostrar etapas sequenciais em uma tarefa, processo ou fluxo de trabalho. As formas retangulares ao fundo são projetadas para conter imagens. |
| PICTURE_CAPTION_LIST | Use para mostrar blocos de informação não sequenciais ou agrupados. As formas superiores são projetadas para conter imagens e as imagens são enfatizadas em relação ao texto. Funciona bem para imagens com legendas curtas. |
| PICTURE_GRID | Use para mostrar imagens dispostas em uma grade quadrada. Melhor com pequena quantidade de texto do Nível 1, que aparece acima da imagem. |
| PICTURE_LINEUP | Use para mostrar uma série de imagens lado a lado. O texto do Nível 1 cobre a parte superior da imagem. O texto do Nível 2 aparece abaixo da imagem. |
| PICTURE_STRIPS | Use para mostrar uma série de imagens de cima para baixo com texto do Nível 1 ao lado de cada uma. |
| PIE_PROCESS | Use para mostrar etapas em um processo com cada fatia de torta aumentando de tamanho até sete formas. O texto do Nível 1 é exibido verticalmente. |
| PLUSAND_MINUS | Use para mostrar os prós e contras de duas ideias. Cada texto do Nível 1 pode conter múltiplos subníveis. Funciona bem com grandes quantidades de texto. Limitado a dois itens do Nível 1. |
| PROCESS_ARROWS | Use para mostrar informação que ilustra um processo ou fluxo de trabalho. O texto do Nível 1 aparece nas formas circulares e o texto do Nível 2 aparece nas formas de seta. Funciona melhor com texto mínimo e para enfatizar movimento ou direção. |
| PROCESS_LIST | Use para mostrar múltiplos grupos de informação ou etapas e subetapas em uma tarefa, processo ou fluxo de trabalho. O texto do Nível 1 corresponde às formas horizontais superiores, e o texto do Nível 2 corresponde às subetapas verticais sob cada forma de nível superior relacionada. |
| PYRAMID_LIST | Use para mostrar relações proporcionais, interconectadas ou hierárquicas. O texto aparece nas formas retangulares sobre o fundo da pirâmide. |
| RADIAL_CLUSTER | Use para mostrar dados que se relacionam a uma ideia ou tema central. O texto superior do Nível 1 aparece no centro. O texto do Nível 2 aparece nas formas ao redor. Pode conter até sete formas do Nível 2. O texto não usado não aparece, mas permanece disponível se você mudar os layouts. Funciona melhor com pequenas quantidades de texto. |
| RADIAL_CYCLE | Use para mostrar a relação a uma ideia central. Enfatiza tanto a informação no círculo central quanto como a informação no anel externo de círculos contribui para a ideia central. A primeira linha de texto do Nível 1 corresponde ao círculo central, e seu texto do Nível 2 corresponde ao anel externo de círculos. O texto não usado não aparece, mas permanece disponível se você mudar os layouts. |
| RADIAL_LIST | Use para mostrar relações a uma ideia central em um ciclo. A forma central pode conter uma imagem. O texto do Nível 1 aparece nos círculos menores e qualquer texto relacionado do Nível 2 aparece ao lado dos círculos menores. |
| RADIAL_VENN | Use para mostrar tanto relações sobrepostas quanto a relação a uma ideia central em um ciclo. A primeira linha de texto do Nível 1 corresponde à forma central e as linhas de texto do Nível 2 correspondem às formas circulares ao redor. O texto não usado não aparece, mas permanece disponível se você mudar os layouts. |
| RANDOM_TO_RESULT_PROCESS | Use para mostrar, através de uma série de etapas, como várias ideias caóticas podem resultar em um objetivo ou ideia unificada. Suporta múltiplos itens de texto do Nível 1, porém as formas correspondentes do primeiro e do último Nível 1 são fixas. Funciona melhor com pequenas quantidades de texto do Nível 1 e quantidades médias de texto do Nível 2. |
| REPEATING_BENDING_PROCESS | Use para mostrar uma progressão ou etapas sequenciais em uma tarefa, processo ou fluxo de trabalho. Maximiza tanto o espaço de exibição horizontal quanto vertical para as formas. |
| REVERSE_LIST | Use para alternar entre dois itens. Apenas as duas primeiras linhas de texto são exibidas, e cada item pode conter grande quantidade de texto. Funciona bem para mostrar uma mudança entre dois itens ou alteração de ordem. |
| SEGMENTED_CYCLE | Use para mostrar uma progressão ou sequência de estágios, tarefas ou eventos em fluxo circular. Enfatiza as peças interconectadas. Cada uma das sete primeiras linhas do texto do Nível 1 corresponde a uma fatia ou forma de torta. O texto não usado não aparece, mas permanece disponível se você mudar os layouts. |
| SEGMENTED_PROCESS | Use para mostrar uma progressão ou etapas sequenciais em uma tarefa, processo ou fluxo de trabalho. Enfatiza o texto do Nível 2, já que cada linha aparece em uma forma separada. |
| SEGMENTED_PYRAMID | Use para mostrar relações de contenção, proporcionais ou interconectadas. As nove primeiras linhas do texto do Nível 1 aparecem nas formas triangulares. O texto não usado não aparece, mas permanece disponível se você mudar os layouts. Funciona melhor apenas com texto do Nível 1. |
| SNAPSHOT_PICTURE_LIST | Use para mostrar imagens com texto explicativo. O texto do Nível 2 pode exibir listas de informação. Funciona bem com grande quantidade de texto. |
