## line_format propriedade
Retorna o objeto LineFormat que contém as propriedades de formatação de linha para uma forma.
            Nota: pode retornar None para certos tipos de formas que não possuem propriedades de linha.
            Somente leitura [`ILineFormat`](/slides/python-net/pt/aspose.slides/ilineformat).
