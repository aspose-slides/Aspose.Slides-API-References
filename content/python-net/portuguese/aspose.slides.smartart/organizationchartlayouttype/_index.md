## OrganizationChartLayoutType enumeração

Representa o tipo de formatação dos nós filhos em um organograma

O tipo OrganizationChartLayoutType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| INITIAL | Tipo de layout inicial |
| STANDART | Posiciona os nós filhos horizontalmente abaixo do nó pai. |
| BOTH_HANGING | Posiciona os nós filhos verticalmente abaixo do nó pai dos dois lados esquerdo e direito. |
| LEFT_HANGING | Posiciona os nós filhos verticalmente abaixo do nó pai do lado esquerdo. |
| RIGHT_HANGING | Posiciona os nós filhos verticalmente abaixo do nó pai do lado direito. |
