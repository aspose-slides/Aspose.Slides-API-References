## SmartArtNode classe

Representa um nó de um objeto SmartArt

O tipo SmartArtNode expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`child_nodes`](/slides/python-net/pt/aspose.slides.smartart/smartartnode/child_nodes/) | Retorna coleções de todos os nós filhos do nó atual.<br/>            Somente leitura [`ISmartArtNodeCollection`](/slides/python-net/pt/aspose.slides.smartart/ismartartnodecollection). |
| [`shapes`](/slides/python-net/pt/aspose.slides.smartart/smartartnode/shapes/) | Retorna coleções de todas as formas associadas ao nó.<br/>            Somente leitura [`ISmartArtShapeCollection`](/slides/python-net/pt/aspose.slides.smartart/ismartartshapecollection). |
| [`text_frame`](/slides/python-net/pt/aspose.slides.smartart/smartartnode/text_frame/) | Retorna o quadro de texto do nó.<br/>            Somente leitura [`ITextFrame`](/slides/python-net/pt/aspose.slides/itextframe). |
| [`is_assistant`](/slides/python-net/pt/aspose.slides.smartart/smartartnode/is_assistant/) | Retorna ou define o nó como assistente.<br/>            Leitura/gravação **bool**. |
| [`level`](/slides/python-net/pt/aspose.slides.smartart/smartartnode/level/) | Retorna o nível de aninhamento do nó.<br/>            Somente leitura **int**. |
| [`bullet_fill_format`](/slides/python-net/pt/aspose.slides.smartart/smartartnode/bullet_fill_format/) | Retorna o objeto FillFormat que contém propriedades de formatação de preenchimento para a marca de lista de um nó.<br/>            Observação: pode retornar None para certos tipos de layout SmartArt que não fornecem marcadores para nós.<br/>            Somente leitura [`IFillFormat`](/slides/python-net/pt/aspose.slides/ifillformat). |
| [`position`](/slides/python-net/pt/aspose.slides.smartart/smartartnode/position/) | Retorna ou define a posição baseada em zero do nó entre os nós irmãos.<br/>            Leitura/gravação **int**. |
| [`is_hidden`](/slides/python-net/pt/aspose.slides.smartart/smartartnode/is_hidden/) | Retorna true se este nó está oculto no modelo de dados.<br/>            Somente leitura **bool**. |
| [`organization_chart_layout`](/slides/python-net/pt/aspose.slides.smartart/smartartnode/organization_chart_layout/) | Retorna ou define o tipo de layout do organograma associado ao nó atual.<br/>            Leitura/gravação [`OrganizationChartLayoutType`](/slides/python-net/pt/aspose.slides.smartart/organizationchartlayouttype). |

## Métodos

| Método | Descrição |
| :- | :- |
| [`remove(self)`](/slides/python-net/pt/aspose.slides.smartart/smartartnode/remove/#) | Remove o nó atual. |
