Contém classes para trabalhar com objetos de planilha em apresentações do Microsoft PowerPoint.
## Classes

| Classe | Descrição |
| :- | :- |
| [`CellCircularReferenceException`](/slides/python-net/pt/aspose.slides.spreadsheet/cellcircularreferenceexception/) | A exceção que é lançada quando uma ou mais referências circulares são detectadas onde uma fórmula faz referência ao seu<br/>            própria célula, direta ou indiretamente. |
| [`CellInvalidFormulaException`](/slides/python-net/pt/aspose.slides.spreadsheet/cellinvalidformulaexception/) | A exceção que é lançada quando uma fórmula calculada não está correta ou não foi analisada. |
| [`CellInvalidReferenceException`](/slides/python-net/pt/aspose.slides.spreadsheet/cellinvalidreferenceexception/) | A exceção que é lançada quando uma referência de célula inválida é encontrada. |
| [`CellUnsupportedDataException`](/slides/python-net/pt/aspose.slides.spreadsheet/cellunsupporteddataexception/) | A exceção que é lançada quando um dado não suportado é encontrado em uma célula de planilha. |
