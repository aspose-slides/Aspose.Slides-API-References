## WarningType enumeração

Representa um tipo de aviso.

O tipo WarningType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| SOURCE_FILE_CORRUPTION | Um problema foi detectado no documento fonte que torna muito provável que o documento não possa ser aberto se for salvo em seu formato original. |
| DATA_LOSS | Texto/gráfico/imagem ou outros dados estarão completamente ausentes da árvore de documentos após o carregamento, ou do documento criado após a gravação. |
| MAJOR_FORMATTING_LOSS | Perda de formatação significativa. |
| MINOR_FORMATTING_LOSS | Pequena perda de formatação. |
| COMPATIBILITY_ISSUE | Este é um problema conhecido que impedirá a abertura do documento por certos agentes de usuário, ou versões anteriores dos agentes de usuário. |
| UNEXPECTED_CONTENT | Algum conteúdo no documento fonte não pôde ser reconhecido (ou seja, não é suportado); isso pode ou não causar problemas ou resultar em perda de dados/formatação. |
