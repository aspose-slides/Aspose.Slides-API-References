Contém classes que representam vários tipos de avisos
## Classes

| Classe | Descrição |
| :- | :- |
| [`IKnownIssueWarningInfo`](/slides/python-net/pt/aspose.slides.warnings/iknownissuewarninginfo/) | Representa um aviso sobre um problema conhecido que não será corrigido em breve. |
| [`INotImplementedWarningInfo`](/slides/python-net/pt/aspose.slides.warnings/inotimplementedwarninginfo/) | Representa um aviso sobre um recurso conhecido não implementado que não será implementado em breve. |
| [`IObsoletePresLockingBehaviorWarningInfo`](/slides/python-net/pt/aspose.slides.warnings/iobsoletepreslockingbehaviorwarninginfo/) | Este aviso indica que um comportamento obsoleto de bloqueio de apresentação está sendo usado. |
| [`IPresentationSignedWarningInfo`](/slides/python-net/pt/aspose.slides.warnings/ipresentationsignedwarninginfo/) | Este aviso indica que a apresentação lida possui a assinatura <br/>            e que esta assinatura será removida durante o processamento. |
| [`IWarningCallback`](/slides/python-net/pt/aspose.slides.warnings/iwarningcallback/) | Interface para classes que recebem avisos |
| [`IWarningInfo`](/slides/python-net/pt/aspose.slides.warnings/iwarninginfo/) | Representa uma interface base para todos os avisos. |

## Enumerações

| Enumeração | Descrição |
| :- | :- |
| [`ReturnAction`](/slides/python-net/pt/aspose.slides.warnings/returnaction/) | Representa opções de decisão de retorno de chamada de aviso. |
| [`WarningType`](/slides/python-net/pt/aspose.slides.warnings/warningtype/) | Representa um tipo de aviso. |
