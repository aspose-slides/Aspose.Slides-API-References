## ShapesAlignmentType enumeração

Define uma maneira de alterar a posição das formas selecionadas no slide.

O tipo ShapesAlignmentType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| ALIGN_LEFT | Alinhar à esquerda |
| ALIGN_RIGHT | Alinhar à direita |
| ALIGN_CENTER | Alinhar ao centro |
| ALIGN_TOP | Alinhar ao topo |
| ALIGN_MIDDLE | Alinhar ao meio |
| ALIGN_BOTTOM | Alinhar à parte inferior |
| DISTRIBUTE_HORIZONTALLY | Distribuir horizontalmente |
| DISTRIBUTE_VERTICALLY | Distribuir verticalmente |
