## binary_data propriedade
Retorna a cópia dos dados de um áudio. No caso de grande quantidade de dados, considere
            usar o método [`IAudio.get_stream`](/slides/python-net/pt/aspose.slides/iaudio/get_stream) para impedir o carregamento desnecessário dos dados do áudio
            na memória ou até mesmo uma OutOfMemoryException.
            Somente leitura **int**[].
