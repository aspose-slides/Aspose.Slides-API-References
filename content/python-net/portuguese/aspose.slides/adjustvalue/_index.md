## classe AdjustValue

Representa o valor de ajuste de uma forma geométrica.  
            Esses valores afetam a forma da forma.

O tipo AdjustValue expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`raw_value`](/slides/python-net/pt/aspose.slides/adjustvalue/raw_value/) | Retorna ou define o valor de ajuste “como está”.<br/>            Leitura/gravação **int**. |
| [`angle_value`](/slides/python-net/pt/aspose.slides/adjustvalue/angle_value/) | Retorna ou define o valor, interpretando-o como ângulo em graus.<br/>            Leitura/gravação **float**. |
| [`name`](/slides/python-net/pt/aspose.slides/adjustvalue/name/) | Retorna um nome deste valor de ajuste.<br/>            Somente leitura **str**. |
| [`type`](/slides/python-net/pt/aspose.slides/adjustvalue/type/) | Retorna o tipo do ajuste da forma.<br/>            Somente leitura [`ShapeAdjustmentType`](/slides/python-net/pt/aspose.slides/shapeadjustmenttype). |
