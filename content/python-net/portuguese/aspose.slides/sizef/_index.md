## SizeF classe

Armazena um par ordenado de números de ponto flutuante, tipicamente a largura e a altura de um retângulo. Compatível com .NET `System.Drawing.SizeF`.

O tipo SizeF expõe os seguintes membros:

## Construtores

| :- | :- |
| [`__init__(self, width=0.0, height=0.0)`](/slides/python-net/pt/aspose.slides/sizef/__init__/#float-float) | Cria um tamanho com a largura e a altura especificadas. |

## Propriedades

| Property | Description |
| :- | :- |
| [`width`](/slides/python-net/pt/aspose.slides/sizef/width/) | Obtém o componente horizontal deste tamanho.<br/>            Somente leitura **float**. |
| [`height`](/slides/python-net/pt/aspose.slides/sizef/height/) | Obtém o componente vertical deste tamanho.<br/>            Somente leitura **float**. |
