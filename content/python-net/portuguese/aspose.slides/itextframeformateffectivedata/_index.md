## ITextFrameFormatEffectiveData classe

Objeto imutável que contém as propriedades de formatação efetiva da moldura de texto.

O tipo ITextFrameFormatEffectiveData expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`text_style`](/slides/python-net/pt/aspose.slides/itextframeformateffectivedata/text_style/) | Retorna o estilo do texto efetivo.<br/>            Somente leitura [`ITextStyleEffectiveData`](/slides/python-net/pt/aspose.slides/itextstyleeffectivedata). |
| [`margin_left`](/slides/python-net/pt/aspose.slides/itextframeformateffectivedata/margin_left/) | Retorna a margem esquerda (pontos) em um TextFrame.<br/>            Somente leitura **float**. |
| [`margin_right`](/slides/python-net/pt/aspose.slides/itextframeformateffectivedata/margin_right/) | Retorna a margem direita (pontos) em um TextFrame.<br/>            Somente leitura **float**. |
| [`margin_top`](/slides/python-net/pt/aspose.slides/itextframeformateffectivedata/margin_top/) | Retorna a margem superior (pontos) em um TextFrame.<br/>            Somente leitura **float**. |
| [`margin_bottom`](/slides/python-net/pt/aspose.slides/itextframeformateffectivedata/margin_bottom/) | Retorna a margem inferior (pontos) em um TextFrame.<br/>            Somente leitura **float**. |
| [`wrap_text`](/slides/python-net/pt/aspose.slides/itextframeformateffectivedata/wrap_text/) | Retorna se o texto está envolvido nas margens do TextFrame.<br/>            Somente leitura **bool**. |
| [`anchoring_type`](/slides/python-net/pt/aspose.slides/itextframeformateffectivedata/anchoring_type/) | Retorna o ancoramento vertical do texto em um TextFrame.<br/>            Somente leitura [`TextAnchorType`](/slides/python-net/pt/aspose.slides/textanchortype). |
| [`center_text`](/slides/python-net/pt/aspose.slides/itextframeformateffectivedata/center_text/) | Retorna se o texto deve ser centralizado horizontalmente na caixa.<br/>            Somente leitura **bool**. |
| [`text_vertical_type`](/slides/python-net/pt/aspose.slides/itextframeformateffectivedata/text_vertical_type/) | Retorna a orientação do texto.<br/>            Somente leitura [`TextVerticalType`](/slides/python-net/pt/aspose.slides/textverticaltype). |
| [`autofit_type`](/slides/python-net/pt/aspose.slides/itextframeformateffectivedata/autofit_type/) | Retorna o modo de ajuste automático do texto.<br/>            Somente leitura [`TextAutofitType`](/slides/python-net/pt/aspose.slides/textautofittype). |
| [`column_count`](/slides/python-net/pt/aspose.slides/itextframeformateffectivedata/column_count/) | Especifica o número de colunas de texto no retângulo delimitador.<br/>            Somente leitura **int**. |
| [`column_spacing`](/slides/python-net/pt/aspose.slides/itextframeformateffectivedata/column_spacing/) | Especifica o espaço entre colunas de texto na área de texto (em pontos).<br/>            Somente leitura **float**. |


### Observações

Esta interface é usada juntamente com a [`ITextFrameFormat`](/slides/python-net/pt/aspose.slides/itextframeformat) interface para retornar valores de formatação efetiva com herança aplicada.
