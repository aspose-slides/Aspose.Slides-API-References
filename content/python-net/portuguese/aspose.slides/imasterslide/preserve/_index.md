## preservar propriedade
Determina se o mestre correspondente é excluído quando todos 
            os slides que seguem esse mestre são excluídos.
            Observação: Aspose.Slides nunca removerá nenhum mestre não utilizado por conta própria, 
            para realmente remover mestres não utilizados chame **Aspose.Slides.IMasterSlideCollection.RemoveUnused(Syste**
            Leitura/Escrita **bool**.
