## set_header_and_child_headers_visibility(self, is_visible) {#bool}
Altera a visibilidade do placeholder de cabeçalho do slide de notas mestre e de todos os placeholders de cabeçalho filhos.
Placeholders filhos significam que os placeholders estão contidos em slides de notas dependentes.
Slides de notas dependentes usam e dependem do slide de notas mestre.

```python
def set_header_and_child_headers_visibility(self, is_visible):
    ...
```

| Parâmetro | Tipo | Descrição |
| :- | :- | :- |
| is_visible | **bool** | true - torna os placeholders de cabeçalho visíveis, caso contrário - os oculta. |
