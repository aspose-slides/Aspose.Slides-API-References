## IEffectFormat classe

Representa as propriedades de efeito da forma.

O tipo IEffectFormat expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`is_no_effects`](/slides/python-net/pt/aspose.slides/ieffectformat/is_no_effects/) | Retorna true se todos os efeitos estiverem desativados (como recém-criado, objeto EffectFormat padrão).<br/>            Somente leitura **bool**. |
| [`blur_effect`](/slides/python-net/pt/aspose.slides/ieffectformat/blur_effect/) | Efeito de desfoque.<br/>            Leitura/Gravação [`IBlur`](/slides/python-net/pt/aspose.slides.effects/iblur). |
| [`fill_overlay_effect`](/slides/python-net/pt/aspose.slides/ieffectformat/fill_overlay_effect/) | Efeito de sobreposição de preenchimento.<br/>            Leitura/Gravação [`IFillOverlay`](/slides/python-net/pt/aspose.slides.effects/ifilloverlay). |
| [`glow_effect`](/slides/python-net/pt/aspose.slides/ieffectformat/glow_effect/) | Efeito de brilho.<br/>            Leitura/Gravação [`IGlow`](/slides/python-net/pt/aspose.slides.effects/iglow). |
| [`inner_shadow_effect`](/slides/python-net/pt/aspose.slides/ieffectformat/inner_shadow_effect/) | Sombra interna.<br/>            Leitura/Gravação [`IInnerShadow`](/slides/python-net/pt/aspose.slides.effects/iinnershadow). |
| [`outer_shadow_effect`](/slides/python-net/pt/aspose.slides/ieffectformat/outer_shadow_effect/) | Sombra externa.<br/>            Leitura/Gravação [`IOuterShadow`](/slides/python-net/pt/aspose.slides.effects/ioutershadow). |
| [`preset_shadow_effect`](/slides/python-net/pt/aspose.slides/ieffectformat/preset_shadow_effect/) | Sombra predefinida.<br/>            Leitura/Gravação [`IPresetShadow`](/slides/python-net/pt/aspose.slides.effects/ipresetshadow). |
| [`reflection_effect`](/slides/python-net/pt/aspose.slides/ieffectformat/reflection_effect/) | Reflexo.<br/>            Leitura/Gravação [`IReflection`](/slides/python-net/pt/aspose.slides.effects/ireflection). |
| [`soft_edge_effect`](/slides/python-net/pt/aspose.slides/ieffectformat/soft_edge_effect/) | Borda suave.<br/>            Leitura/Gravação [`ISoftEdge`](/slides/python-net/pt/aspose.slides.effects/isoftedge). |
