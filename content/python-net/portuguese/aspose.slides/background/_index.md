## Background classe

Representa o plano de fundo de um slide.

**Herança:**[`Background`](/slides/python-net/pt/aspose.slides/background) → [`PVIObject`](/slides/python-net/pt/aspose.slides/pviobject)

O tipo Background expõe os seguintes membros:

## Propriedades

| Property | Description |
| :- | :- |
| [`type`](/slides/python-net/pt/aspose.slides/background/type/) | Retorna um tipo de preenchimento de fundo.<br/>            Leitura/gravação [`BackgroundType`](/slides/python-net/pt/aspose.slides/backgroundtype). |
| [`fill_format`](/slides/python-net/pt/aspose.slides/background/fill_format/) | Retorna um FillFormat para o preenchimento BackgroundType.OwnBackground.<br/>            Somente leitura [`IFillFormat`](/slides/python-net/pt/aspose.slides/ifillformat). |
| [`effect_format`](/slides/python-net/pt/aspose.slides/background/effect_format/) | Retorna um EffectFormat para o preenchimento BackgroundType.OwnBackground.<br/>            Somente leitura [`IEffectFormat`](/slides/python-net/pt/aspose.slides/ieffectformat). |
| [`style_color`](/slides/python-net/pt/aspose.slides/background/style_color/) | Retorna um ColorFormat para um preenchimento BackgroundType.Themed.<br/>            Somente leitura [`IColorFormat`](/slides/python-net/pt/aspose.slides/icolorformat). |
| [`style_index`](/slides/python-net/pt/aspose.slides/background/style_index/) | Retorna um índice de preenchimento BackgroundType.Themed na coleção de temas de fundo.<br/>            0 significa nenhum preenchimento.<br/>            1..999 - índice.<br/>            Leitura/gravação **int**. |
| [`slide`](/slides/python-net/pt/aspose.slides/background/slide/) | Retorna o slide pai de uma forma.<br/>            Somente leitura [`IBaseSlide`](/slides/python-net/pt/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/pt/aspose.slides/background/presentation/) | Retorna a apresentação pai de um slide.<br/>            Somente leitura [`IPresentation`](/slides/python-net/pt/aspose.slides/ipresentation). |
