## ISvgImage classe

Representa uma imagem SVG.

O tipo ISvgImage expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`svg_content`](/slides/python-net/pt/aspose.slides/isvgimage/svg_content/) | Retorna o conteúdo SVG.<br/>Somente leitura **str**. |
| [`svg_data`](/slides/python-net/pt/aspose.slides/isvgimage/svg_data/) | Retorna os dados SVG.<br/>Somente leitura **int**[]. |
| [`external_resource_resolver`](/slides/python-net/pt/aspose.slides/isvgimage/external_resource_resolver/) | Retorna a interface de callback usada para resolver recursos externos durante a importação de documentos SVG.<br/>Somente leitura **IExternalResourceResolver**. |
| [`base_uri`](/slides/python-net/pt/aspose.slides/isvgimage/base_uri/) | Retorna a URI base do SVG especificado. Usada para resolver links relativos.<br/>Somente leitura **str**. |
