## Enumeração ShapeElementFillSource

Representa como o elemento de forma deve ser preenchido.

O tipo ShapeElementFillSource expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| NO_FILL | Não preencher o primitivo. |
| SHAPE | Usar o preenchimento da forma. |
| LIGHTEN | Usar o preenchimento clareado da forma. |
| LIGHTEN_LESS | Usar o preenchimento da forma menos clareado. |
| DARKEN | Usar o preenchimento escurecido da forma. |
| DARKEN_LESS | Usar o preenchimento da forma menos escurecido. |
