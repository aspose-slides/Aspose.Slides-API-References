## ITextStyleEffectiveData classe

Objeto imutável que contém propriedades de estilo de texto efetivas.

O tipo ITextStyleEffectiveData expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`default_paragraph_format`](/slides/python-net/pt/aspose.slides/itextstyleeffectivedata/default_paragraph_format/) | Retorna as propriedades padrão de parágrafo efetivas.<br/>            Somente leitura [`IParagraphFormatEffectiveData`](/slides/python-net/pt/aspose.slides/iparagraphformateffectivedata). |

## Métodos

| Método | Descrição |
| :- | :- |
| [`get_level(self, index)`](/slides/python-net/pt/aspose.slides/itextstyleeffectivedata/get_level/#int) | Retorna o nível do estilo efetivo. |

### Observações

Esta interface é usada juntamente com a interface [`ITextStyle`](/slides/python-net/pt/aspose.slides/itextstyle) para retornar valores de formatação efetivos com herança aplicada.
