## CommonSlideViewProperties classe

Representa propriedades comuns de visualização de slides.

O tipo CommonSlideViewProperties expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`scale`](/slides/python-net/pt/aspose.slides/commonslideviewproperties/scale/) | Define a proporção de escala da visualização em porcentagens.<br/>            Leitura/Escrita **int**. |
| [`variable_scale`](/slides/python-net/pt/aspose.slides/commonslideviewproperties/variable_scale/) | Define que o conteúdo da visualização deve ser escalado automaticamente para se ajustar melhor ao tamanho da janela atual.<br/>            Leitura/Escrita **bool**. |
| [`drawing_guides`](/slides/python-net/pt/aspose.slides/commonslideviewproperties/drawing_guides/) | Retorna a coleção de guias de desenho.<br/>            Somente leitura [`IDrawingGuidesCollection`](/slides/python-net/pt/aspose.slides/idrawingguidescollection) |
