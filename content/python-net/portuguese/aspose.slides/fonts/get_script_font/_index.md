## get_script_font(self, script) {#str}
Obtém o nome da fonte associado a uma tag de script específica do tema da apresentação.

### Retorna

O nome da fonte usada para o script especificado, ou `None` se o script não estiver definido.



```python
def get_script_font(self, script):
    ...
```


| Parâmetro | Tipo | Descrição |
| :- | :- | :- |
| script | **str** | O código de script BCP-47 (por exemplo, "Latn", "Cyrl", "Jpan") usado para identificar um sistema de escrita. |
