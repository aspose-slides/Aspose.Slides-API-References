## ISlideText classe

Representa o texto extraído do slide

O tipo ISlideText expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`text`](/slides/python-net/pt/aspose.slides/islidetext/text/) | O texto nas formas do slide |
| [`master_text`](/slides/python-net/pt/aspose.slides/islidetext/master_text/) | O texto nas formas da página mestre para este slide |
| [`layout_text`](/slides/python-net/pt/aspose.slides/islidetext/layout_text/) | O texto nas formas da página de layout para este slide |
| [`notes_text`](/slides/python-net/pt/aspose.slides/islidetext/notes_text/) | O texto nas formas da página de notas para este slide |
| [`comments_text`](/slides/python-net/pt/aspose.slides/islidetext/comments_text/) | O texto dos comentários do slide |
