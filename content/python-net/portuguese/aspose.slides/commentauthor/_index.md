## CommentAuthor classe

Representa um autor de comentários.

O tipo CommentAuthor expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`name`](/slides/python-net/pt/aspose.slides/commentauthor/name/) | Retorna ou define o nome do autor.<br/>            Leitura/Gravação **str**. |
| [`initials`](/slides/python-net/pt/aspose.slides/commentauthor/initials/) | Retorna ou define as iniciais do autor.<br/>            Leitura/Gravação **str**. |
| [`comments`](/slides/python-net/pt/aspose.slides/commentauthor/comments/) | Retorna a coleção de comentários feitos por este autor.<br/>            Somente leitura [`ICommentCollection`](/slides/python-net/pt/aspose.slides/icommentcollection). |

## Métodos

| Método | Descrição |
| :- | :- |
| [`remove(self)`](/slides/python-net/pt/aspose.slides/commentauthor/remove/#) | Remove o autor da coleção pai. |
