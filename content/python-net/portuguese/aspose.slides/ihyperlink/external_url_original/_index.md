## external_url_original propriedade
Representa um hiperlink que é definido para esta parte sem considerar o conteúdo real da parte.
            
            O PowerPoint se comporta de forma específica para links e seus textos correspondentes em uma parte. Ele permite criar texto para o hiperlink na forma de um URL válido, diferente do endereço real do link. Neste caso, ao visualizar o link na janela de edição, ele será alterado para corresponder à parte de texto. Esta propriedade representa o valor original do hiperlink.
