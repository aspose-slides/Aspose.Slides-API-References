## ICellFormat classe

Representa o formato de uma célula de tabela.

O tipo ICellFormat expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`fill_format`](/slides/python-net/pt/aspose.slides/icellformat/fill_format/) | Retorna um objeto de propriedades de preenchimento da célula.<br/>            Somente leitura [`IFillFormat`](/slides/python-net/pt/aspose.slides/ifillformat). |
| [`border_left`](/slides/python-net/pt/aspose.slides/icellformat/border_left/) | Retorna um objeto de propriedades da linha da borda esquerda.<br/>            Somente leitura [`ILineFormat`](/slides/python-net/pt/aspose.slides/ilineformat). |
| [`border_top`](/slides/python-net/pt/aspose.slides/icellformat/border_top/) | Retorna um objeto de propriedades da linha da borda superior.<br/>            Somente leitura [`ILineFormat`](/slides/python-net/pt/aspose.slides/ilineformat). |
| [`border_right`](/slides/python-net/pt/aspose.slides/icellformat/border_right/) | Retorna um objeto de propriedades da linha da borda direita.<br/>            Somente leitura [`ILineFormat`](/slides/python-net/pt/aspose.slides/ilineformat). |
| [`border_bottom`](/slides/python-net/pt/aspose.slides/icellformat/border_bottom/) | Retorna um objeto de propriedades da linha da borda inferior.<br/>            Somente leitura [`ILineFormat`](/slides/python-net/pt/aspose.slides/ilineformat). |
| [`border_diagonal_down`](/slides/python-net/pt/aspose.slides/icellformat/border_diagonal_down/) | Retorna um objeto de propriedades da linha diagonal de canto superior esquerdo para canto inferior direito.<br/>            Somente leitura [`ILineFormat`](/slides/python-net/pt/aspose.slides/ilineformat). |
| [`border_diagonal_up`](/slides/python-net/pt/aspose.slides/icellformat/border_diagonal_up/) | Retorna um objeto de propriedades da linha diagonal de canto inferior esquerdo para canto superior direito.<br/>            Somente leitura [`ILineFormat`](/slides/python-net/pt/aspose.slides/ilineformat). |
| [`transparency`](/slides/python-net/pt/aspose.slides/icellformat/transparency/) | Obtém ou define a transparência da cor de preenchimento.<br/>            Leitura/Gravação **float**. |

## Métodos
