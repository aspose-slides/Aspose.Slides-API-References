## BlackWhiteMode enumeração

Determina como a forma colorida deve ser transformada em preto e branco.

O tipo BlackWhiteMode expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| NOT_DEFINED | A propriedade não está definida |
| COLOR | O objeto é renderizado com coloração normal |
| AUTOMATIC | O objeto é renderizado com coloração automática |
| GRAY | O objeto é renderizado com coloração cinza |
| LIGHT_GRAY | O objeto é renderizado com coloração cinza claro |
| INVERSE_GRAY | O objeto é renderizado com coloração cinza inversa |
| GRAY_WHITE | O objeto é renderizado com coloração cinza e branca |
| BLACK_GRAY | O objeto é renderizado com coloração preto e cinza |
| BLACK_WHITE | O objeto é renderizado com coloração preto e branca |
| BLACK | O objeto é renderizado apenas com coloração preta |
| WHITE | O objeto é renderizado com coloração branca |
| HIDDEN | O objeto não é renderizado |
