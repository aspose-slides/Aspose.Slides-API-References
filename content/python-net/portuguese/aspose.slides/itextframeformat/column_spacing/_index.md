## column_spacing propriedade
Retorna ou define o espaço entre as colunas de texto na área de texto (em pontos). Isso deve ser aplicado 
            quando há mais de 1 coluna presente.
            Esse valor deve ser um número positivo. Caso contrário, o valor será definido como zero. 
            Leitura/gravação **float**.
