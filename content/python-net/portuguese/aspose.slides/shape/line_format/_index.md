## line_format propriedade
Retorna o objeto LineFormat que contém as propriedades de formatação de linha para um shape.
            Observação: pode retornar None para certos tipos de shapes que não possuem propriedades de linha.
            Somente leitura [`ILineFormat`](/slides/python-net/pt/aspose.slides/ilineformat).
