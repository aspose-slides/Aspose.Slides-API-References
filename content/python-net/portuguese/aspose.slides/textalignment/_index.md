## Enumeração TextAlignment

Representa diferentes estilos de alinhamento de texto.

O tipo TextAlignment expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| NOT_DEFINED | Alinhamento padrão. |
| LEFT | Alinhamento à esquerda. |
| CENTER | Alinhamento centralizado. |
| RIGHT | Alinhamento à direita. |
| JUSTIFY | Alinhamento justificado. |
| JUSTIFY_LOW | Justificação Kashida baixa. |
| DISTRIBUTED | Alinhamento distribuído. |
