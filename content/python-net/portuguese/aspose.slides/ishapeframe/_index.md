## IShapeFrame classe

Representa as propriedades da moldura de forma.

O tipo IShapeFrame expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`x`](/slides/python-net/pt/aspose.slides/ishapeframe/x/) | Retorna a coordenada X do canto superior esquerdo de um quadro.<br/>            Somente leitura **float**. |
| [`y`](/slides/python-net/pt/aspose.slides/ishapeframe/y/) | Retorna a coordenada Y do canto superior esquerdo de um quadro.<br/>            Somente leitura **float**. |
| [`width`](/slides/python-net/pt/aspose.slides/ishapeframe/width/) | Retorna a largura de um quadro.<br/>            Somente leitura **float**. |
| [`height`](/slides/python-net/pt/aspose.slides/ishapeframe/height/) | Retorna a altura de um quadro.<br/>            Somente leitura **float**. |
| [`rotation`](/slides/python-net/pt/aspose.slides/ishapeframe/rotation/) | Retorna o número de graus que um quadro está girado ao redor do eixo z.<br/>            Um valor positivo indica rotação horário; um valor negativo indica rotação anti-horário.<br/>            Somente leitura **float**. |
| [`center_x`](/slides/python-net/pt/aspose.slides/ishapeframe/center_x/) | Retorna a coordenada X do centro de um quadro.<br/>            Somente leitura **float**. |
| [`center_y`](/slides/python-net/pt/aspose.slides/ishapeframe/center_y/) | Retorna a coordenada Y do centro de um quadro.<br/>            Somente leitura **float**. |
| [`flip_h`](/slides/python-net/pt/aspose.slides/ishapeframe/flip_h/) | Determina se um quadro está espelhado horizontalmente.<br/>            Somente leitura [`NullableBool`](/slides/python-net/pt/aspose.slides/nullablebool). |
| [`flip_v`](/slides/python-net/pt/aspose.slides/ishapeframe/flip_v/) | Determina se um quadro está espelhado verticalmente.<br/>            Somente leitura [`NullableBool`](/slides/python-net/pt/aspose.slides/nullablebool). |
| [`rectangle`](/slides/python-net/pt/aspose.slides/ishapeframe/rectangle/) | Retorna as coordenadas de um quadro.<br/>            Somente leitura **aspose.slides.RectangleF**. |
