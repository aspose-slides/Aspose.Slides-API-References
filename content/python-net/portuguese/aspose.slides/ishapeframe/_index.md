## IShapeFrame classe

Representa as propriedades da moldura de forma.

O tipo IShapeFrame expõe os seguintes membros:

## Propriedades

| Property | Description |
| :- | :- |
| [`x`](/slides/python-net/pt/aspose.slides/ishapeframe/x/) | Retorna a coordenada X do canto superior esquerdo de uma moldura.<br/>            Somente leitura **float**. |
| [`y`](/slides/python-net/pt/aspose.slides/ishapeframe/y/) | Retorna a coordenada Y do canto superior esquerdo de uma moldura.<br/>            Somente leitura **float**. |
| [`width`](/slides/python-net/pt/aspose.slides/ishapeframe/width/) | Retorna a largura de uma moldura.<br/>            Somente leitura **float**. |
| [`height`](/slides/python-net/pt/aspose.slides/ishapeframe/height/) | Retorna a altura de uma moldura.<br/>            Somente leitura **float**. |
| [`rotation`](/slides/python-net/pt/aspose.slides/ishapeframe/rotation/) | Retorna o número de graus que uma moldura está rotacionada em torno do eixo z.<br/>            Um valor positivo indica rotação no sentido horário; um valor negativo<br/>            indica rotação no sentido anti-horário.<br/>            Somente leitura **float**. |
| [`center_x`](/slides/python-net/pt/aspose.slides/ishapeframe/center_x/) | Retorna a coordenada X do centro de uma moldura.<br/>            Somente leitura **float**. |
| [`center_y`](/slides/python-net/pt/aspose.slides/ishapeframe/center_y/) | Retorna a coordenada Y do centro de uma moldura.<br/>            Somente leitura **float**. |
| [`flip_h`](/slides/python-net/pt/aspose.slides/ishapeframe/flip_h/) | Determina se uma moldura está invertida horizontalmente.<br/>            Somente leitura [`NullableBool`](/slides/python-net/pt/aspose.slides/nullablebool). |
| [`flip_v`](/slides/python-net/pt/aspose.slides/ishapeframe/flip_v/) | Determina se uma moldura está invertida verticalmente.<br/>            Somente leitura [`NullableBool`](/slides/python-net/pt/aspose.slides/nullablebool). |
| [`rectangle`](/slides/python-net/pt/aspose.slides/ishapeframe/rectangle/) | Retorna as coordenadas de uma moldura.<br/>            Somente leitura [`RectangleF`](/slides/python-net/pt/aspose.slides/rectanglef). |
