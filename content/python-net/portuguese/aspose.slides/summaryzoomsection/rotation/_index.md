## rotation propriedade
Returns or sets the number of degrees the specified shape is rotated around
            the z-axis. A positive value indicates clockwise rotation; a negative value
            indicates counterclockwise rotation.
            Leitura/gravação **float**.

### Observações

O valor retornado está sempre definido (não é float.NaN).
            O valor atribuído deve ser definido (não é float.NaN). Você pode definir valores indefinidos para as propriedades da instância RawFrame.
