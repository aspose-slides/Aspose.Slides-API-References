## from_rgb(r, g, b) {#int-int-int}
Cria uma cor opaca (alpha é 255) a partir dos valores de vermelho, verde e azul especificados.

### Retorno

A cor criada a partir dos valores especificados.

```python
@staticmethod
def from_rgb(r, g, b):
    ...
```

| Parâmetro | Tipo | Descrição |
| :- | :- | :- |
| r | **int** | O valor do componente vermelho. Valores válidos são de 0 a 255. |
| g | **int** | O valor do componente verde. Valores válidos são de 0 a 255. |
| b | **int** | O valor do componente azul. Valores válidos são de 0 a 255. |

### Exceções

| Exceção | Descrição |
| :- | :- |
| **ValueError** | Um valor de componente é menor que 0 ou maior que 255. |
