## is_system_color propriedade
Especifica se esta cor é uma cor do sistema: uma cor usada para um elemento de exibição do Windows, como `Control` ou `ActiveBorder`.<br/>            Cores do sistema não são expostas como atributos `Color` e só podem ser obtidas com [`from_known_color`](/slides/python-net/pt/aspose.slides/color/from_known_color/) ou retornadas pela biblioteca.
            Somente leitura **bool**.
