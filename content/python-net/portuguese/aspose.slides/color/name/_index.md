## propriedade name
Obtém o nome desta cor.<br/>            Para uma cor nomeada (uma constante nomeada como `Color.red`, ou uma cor criada com [`from_name`](/slides/python-net/pt/aspose.slides/color/from_name/)) o nome .NET é retornado, por exemplo `"Red"` ou `"LightBlue"`.<br/>            Para qualquer outra cor o valor ARGB é retornado como hexadecimal em letras minúsculas sem preenchimento de zeros, por exemplo `"ffff0000"`. `Color.empty.name` é `"0"`.
            Somente leitura **str**.
