## IColorFormat classe

Representa uma cor usada em uma apresentação.

O tipo IColorFormat expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`color_type`](/slides/python-net/pt/aspose.slides/icolorformat/color_type/) | Retorna ou define o método de definição de cor.<br/>            Leitura/gravação [`ColorType`](/slides/python-net/pt/aspose.slides/colortype). |
| [`color`](/slides/python-net/pt/aspose.slides/icolorformat/color/) | Retorna a cor resultante (com todas as transformações de cor aplicadas).<br/>            Define cores RGB e limpa todas as transformações de cor.<br/>            Leitura/gravação [`Color`](/slides/python-net/pt/aspose.slides/color). |
| [`preset_color`](/slides/python-net/pt/aspose.slides/icolorformat/preset_color/) | Retorna ou define a predefinição de cor.<br/>            Leitura/gravação [`PresetColor`](/slides/python-net/pt/aspose.slides/presetcolor). |
| [`system_color`](/slides/python-net/pt/aspose.slides/icolorformat/system_color/) | Retorna ou define a cor identificada pela tabela de cores do sistema.<br/>            Leitura/gravação [`SystemColor`](/slides/python-net/pt/aspose.slides/systemcolor). |
| [`scheme_color`](/slides/python-net/pt/aspose.slides/icolorformat/scheme_color/) | Retorna ou define a cor identificada por um esquema de cores.<br/>            Leitura/gravação [`SchemeColor`](/slides/python-net/pt/aspose.slides/schemecolor). |
| [`r`](/slides/python-net/pt/aspose.slides/icolorformat/r/) | Retorna ou define o componente vermelho de uma cor. Todas as transformações de cor são ignoradas.<br/>            Leitura/gravação **int**. |
| [`g`](/slides/python-net/pt/aspose.slides/icolorformat/g/) | Retorna ou define o componente verde de uma cor. Todas as transformações de cor são ignoradas.<br/>            Leitura/gravação **int**. |
| [`b`](/slides/python-net/pt/aspose.slides/icolorformat/b/) | Retorna ou define o componente azul de uma cor. Todas as transformações de cor são ignoradas.<br/>            Leitura/gravação **int**. |
| [`float_r`](/slides/python-net/pt/aspose.slides/icolorformat/float_r/) | Retorna ou define o componente vermelho de uma cor. Todas as transformações de cor são ignoradas.<br/>            Leitura/gravação **float**. |
| [`float_g`](/slides/python-net/pt/aspose.slides/icolorformat/float_g/) | Retorna ou define o componente verde de uma cor. Todas as transformações de cor são ignoradas.<br/>            Leitura/gravação **float**. |
| [`float_b`](/slides/python-net/pt/aspose.slides/icolorformat/float_b/) | Retorna ou define o componente azul de uma cor. Todas as transformações de cor são ignoradas.<br/>            Leitura/gravação **float**. |
| [`hue`](/slides/python-net/pt/aspose.slides/icolorformat/hue/) | Retorna ou define o componente matiz de uma cor em representação HSL.<br/>            Todas as transformações de cor são ignoradas.<br/>            Leitura/gravação **float**. |
| [`saturation`](/slides/python-net/pt/aspose.slides/icolorformat/saturation/) | Retorna ou define o componente saturação de uma cor em representação HSL.<br/>            Todas as transformações de cor são ignoradas.<br/>            Leitura/gravação **float**. |
| [`luminance`](/slides/python-net/pt/aspose.slides/icolorformat/luminance/) | Retorna ou define o componente luminância de uma cor em representação HSL.<br/>            Todas as transformações de cor são ignoradas.<br/>            Leitura/gravação **float**. |
| [`color_transform`](/slides/python-net/pt/aspose.slides/icolorformat/color_transform/) | Retorna a coleção de transformações de cor aplicadas a uma cor.<br/>            Somente leitura [`IColorOperationCollection`](/slides/python-net/pt/aspose.slides/icoloroperationcollection). |
