## Enumeração ColorType

Representa diferentes modos de cor.

O tipo ColorType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| NOT_DEFINED | A cor não está definida. |
| RGB | Cor RGB padrão de 24 bits. |
| RGB_PERCENTAGE | Cor RGB de alta definição. |
| HSL | Cor HSL de alta definição. |
| SCHEME | Cor de esquema. |
| SYSTEM | Cor do sistema. |
| PRESET | Cor predefinida. |
