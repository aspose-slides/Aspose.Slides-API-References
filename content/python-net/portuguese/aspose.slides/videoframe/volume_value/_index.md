## volume_value propriedade
Retorna ou define o volume exato do vídeo como uma porcentagem.
             O valor é expresso como uma porcentagem de 0 a 100. Use esta propriedade
             para ler ou definir valores de volume que são mais precisos do que os níveis predefinidos
             disponíveis através da propriedade [`VideoFrame.volume`](/slides/python-net/pt/aspose.slides/videoframe/volume).
             Leitura/gravação **float**.
