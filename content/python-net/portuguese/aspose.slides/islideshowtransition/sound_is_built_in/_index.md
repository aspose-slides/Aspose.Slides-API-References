## sound_is_built_in propriedade
Especifica se este som é ou não um som embutido. Se este atributo for definido como true então
            a aplicação geradora é notificada para verificar o atributo name especificado para este som
            em sua lista de sons embutidos e pode então apresentar um nome personalizado ou UI conforme necessário.
            Leitura e escrita **bool**.
