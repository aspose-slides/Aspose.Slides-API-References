## sound_name propriedade
Especifica um nome legível para o som da transição. A propriedade [`ISlideShowTransition.sound`](/slides/python-net/pt/aspose.slides/islideshowtransition/sound) deve ser atribuída para obter ou definir o nome do som.
            Leitura-gravação **str**.


### Observações

Este nome aparece na interface do usuário do PowerPoint ao configurar o som da transição manualmente.
