## ILayoutPlaceholderManager classe

Representa o gerenciador que permite adicionar marcadores ao slide de layout.

O tipo ILayoutPlaceholderManager expõe os seguintes membros:

## Métodos

| Método | Descrição |
| :- | :- |
| [`add_content_placeholder(self, x, y, width, height)`](/slides/python-net/pt/aspose.slides/ilayoutplaceholdermanager/add_content_placeholder/#float-float-float-float) | Adiciona uma nova forma de marcador ao slide de layout para conter conteúdo, como uma imagem, tabela, mídia ou texto. |
| [`add_vertical_content_placeholder(self, x, y, width, height)`](/slides/python-net/pt/aspose.slides/ilayoutplaceholdermanager/add_vertical_content_placeholder/#float-float-float-float) | Adiciona uma nova forma de marcador ao slide de layout para conter conteúdo, como uma imagem, tabela, mídia <br/>            ou texto na vertical. |
| [`add_text_placeholder(self, x, y, width, height)`](/slides/python-net/pt/aspose.slides/ilayoutplaceholdermanager/add_text_placeholder/#float-float-float-float) | Adiciona uma nova forma de marcador ao slide de layout para conter conteúdo de texto. |
| [`add_vertical_text_placeholder(self, x, y, width, height)`](/slides/python-net/pt/aspose.slides/ilayoutplaceholdermanager/add_vertical_text_placeholder/#float-float-float-float) | Adiciona uma nova forma de marcador ao slide de layout para conter conteúdo de texto na vertical. |
| [`add_picture_placeholder(self, x, y, width, height)`](/slides/python-net/pt/aspose.slides/ilayoutplaceholdermanager/add_picture_placeholder/#float-float-float-float) | Adiciona uma nova forma de marcador ao slide de layout para conter uma imagem. |
