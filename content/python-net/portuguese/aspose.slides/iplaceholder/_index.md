## IPlaceholder classe

Representa um espaço reservado em um slide.

O tipo IPlaceholder expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`orientation`](/slides/python-net/pt/aspose.slides/iplaceholder/orientation/) | Obtém a orientação de um espaço reservado.<br/>            Somente leitura [`Orientation`](/slides/python-net/pt/aspose.slides/orientation). |
| [`size`](/slides/python-net/pt/aspose.slides/iplaceholder/size/) | Obtém o tamanho de um espaço reservado.<br/>            Somente leitura [`PlaceholderSize`](/slides/python-net/pt/aspose.slides/placeholdersize). |
| [`type`](/slides/python-net/pt/aspose.slides/iplaceholder/type/) | Obtém o tipo de um espaço reservado.<br/>            Somente leitura [`PlaceholderType`](/slides/python-net/pt/aspose.slides/placeholdertype). |
| [`index`](/slides/python-net/pt/aspose.slides/iplaceholder/index/) | Obtém o índice de um espaço reservado.<br/>            Somente leitura **int**. |
