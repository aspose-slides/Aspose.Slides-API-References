## IImage classe

Representa uma imagem raster ou vetor.

O tipo IImage expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`size`](/slides/python-net/pt/aspose.slides/iimage/size/) | Obtém o tamanho da imagem. |
| [`width`](/slides/python-net/pt/aspose.slides/iimage/width/) | Obtém a largura da imagem em pixels. |
| [`height`](/slides/python-net/pt/aspose.slides/iimage/height/) | Obtém a altura da imagem em pixels. |

## Métodos

| Método | Descrição |
| :- | :- |
| [`save(self, filename)`](/slides/python-net/pt/aspose.slides/iimage/save/#str) | Salva a imagem em um arquivo. |
| [`save(self, filename, format)`](/slides/python-net/pt/aspose.slides/iimage/save/#str-imageformat) | Salva a imagem em um arquivo no formato especificado. |
| [`save(self, stream, format)`](/slides/python-net/pt/aspose.slides/iimage/save/#iorawiobase-imageformat) | Salva a imagem em um fluxo no formato especificado. |
| [`save(self, filename, format, quality)`](/slides/python-net/pt/aspose.slides/iimage/save/#str-imageformat-int) | Salva a imagem em um arquivo no formato e qualidade especificados. |
| [`save(self, stream, format, quality)`](/slides/python-net/pt/aspose.slides/iimage/save/#iorawiobase-imageformat-int) | Salva a imagem em um fluxo no formato e qualidade especificados. |


### Observações

Esta interface fornece uma abstração comum para manipular imagens raster e vetoriais.  
Implementações podem variar dependendo do tipo subjacente da imagem.
