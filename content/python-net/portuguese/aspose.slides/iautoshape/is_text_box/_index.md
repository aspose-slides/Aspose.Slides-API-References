## is_text_box propriedade
Especifica se a forma é uma caixa de texto.


### Observações

Se a forma não for especificada como uma caixa de texto, isso não significa que ela não possa ter texto anexado a ela. A caixa de texto
            é apenas uma forma especializada com propriedades específicas.
