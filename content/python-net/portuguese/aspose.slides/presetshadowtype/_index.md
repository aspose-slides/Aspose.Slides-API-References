## PresetShadowType enumeração

Representa uma pré-definição para um efeito de sombra.

O tipo PresetShadowType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| TOP_LEFT_DROP_SHADOW | Representa a sombra projetada superior esquerda. |
| TOP_LEFT_LARGE_DROP_SHADOW | Representa a sombra projetada grande superior esquerda. |
| BACK_LEFT_LONG_PERSPECTIVE_SHADOW | Representa a sombra de perspectiva longa traseira esquerda. |
| BACK_RIGHT_LONG_PERSPECTIVE_SHADOW | Representa a sombra de perspectiva longa traseira direita. |
| TOP_LEFT_DOUBLE_DROP_SHADOW | Representa a sombra projetada dupla superior esquerda. |
| BOTTOM_RIGHT_SMALL_DROP_SHADOW | Representa a sombra projetada pequena inferior direita. |
| FRONT_LEFT_LONG_PERSPECTIVE_SHADOW | Representa a sombra de perspectiva longa frontal esquerda. |
| FRONT_RIGHT_LONG_PERSPECTIVE_SHADOW | Representa a sombra de perspectiva longa frontal direita. |
| OUTER_BOX_SHADOW_3D | Representa a sombra de caixa externa 3D. |
| INNER_BOX_SHADOW_3D | Representa a sombra de caixa interna 3D. |
| BACK_CENTER_PERSPECTIVE_SHADOW | Representa a sombra de perspectiva central traseira. |
| TOP_RIGHT_DROP_SHADOW | Representa a sombra projetada superior direita. |
| FRONT_BOTTOM_SHADOW | Representa a sombra inferior frontal. |
| BACK_LEFT_PERSPECTIVE_SHADOW | Representa a sombra de perspectiva traseira esquerda. |
| BACK_RIGHT_PERSPECTIVE_SHADOW | Representa a sombra de perspectiva traseira direita. |
| BOTTOM_LEFT_DROP_SHADOW | Representa a sombra projetada inferior esquerda. |
| BOTTOM_RIGHT_DROP_SHADOW | Representa a sombra projetada inferior direita. |
| FRONT_LEFT_PERSPECTIVE_SHADOW | Representa a sombra de perspectiva frontal esquerda. |
| FRONT_RIGHT_PERSPECTIVE_SHADOW | Representa a sombra de perspectiva frontal direita. |
| TOP_LEFT_SMALL_DROP_SHADOW | Representa a sombra projetada pequena superior esquerda. |
