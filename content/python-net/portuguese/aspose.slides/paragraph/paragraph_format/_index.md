## paragraph_format propriedade
Returns the formatting object for this paragraph.
            Somente leitura [`IParagraphFormat`](/slides/python-net/pt/aspose.slides/iparagraphformat).

### Observações

The formatting object contains the formatting parameters defined for the current paragraph only, inherited data is not applied.

In order to get the effective values including inherited ones use the [`ParagraphFormat.get_effective`](/slides/python-net/pt/aspose.slides/paragraphformat/get_effective) method.
