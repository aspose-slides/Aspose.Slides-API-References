## LineSketchType enumeração

Representa qual tipo de esboço ou efeito foi atribuído a uma forma.

O tipo LineSketchType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| NOT_DEFINED | Especifica que o efeito Sketch de uma forma está indefinido. |
| NONE | Especifica que uma forma não tem efeito Sketch. Isso é equivalente a esta propriedade estar vazia. |
| CURVED | Especifica que uma forma tem o efeito Curved, que transforma cada borda da forma em uma grande curva suave. |
| FREEHAND | Especifica que uma forma tem o efeito Freehand, que mais se assemelha a uma linha desenhada de forma imperfeita. |
| SCRIBBLE | Especifica que uma forma tem o efeito Scribble, que apresenta oscilações exageradas como se fosse desenhada propositalmente bagunçada. |
