## remove(self, item) {#icustomxmlpart}
Remove a primeira ocorrência de um objeto específico da coleção.

### Retorna

`true` se o item for removido com sucesso; caso contrário, `false`.



```python
def remove(self, item):
    ...
```


| Parâmetro | Tipo | Descrição |
| :- | :- | :- |
| item | [`ICustomXmlPart`](/slides/python-net/pt/aspose.slides/icustomxmlpart) | A parte xml personalizada a ser removida. |

### Exceções

| Exceção | Descrição |
| :- | :- |
| **RuntimeError(Proxy error(ArgumentNullException))** | item é `None`. |
