## TagCollection classe

Representa a coleção de tags (pares de strings definidos pelo usuário)

O tipo TagCollection expõe os seguintes membros:

## Métodos

| Método | Descrição |
| :- | :- |
| [`add(self, name, value)`](/slides/python-net/pt/aspose.slides/tagcollection/add/#str-str) | Adiciona uma nova tag à coleção. |
| [`remove(self, name)`](/slides/python-net/pt/aspose.slides/tagcollection/remove/#str) | Remove a tag com um nome especificado da coleção. |
| [`index_of_name(self, name)`](/slides/python-net/pt/aspose.slides/tagcollection/index_of_name/#str) | Retorna o índice base zero da chave especificada na coleção. |
| [`remove_at(self, index)`](/slides/python-net/pt/aspose.slides/tagcollection/remove_at/#int) | Remove a tag no índice especificado. |
| [`clear(self)`](/slides/python-net/pt/aspose.slides/tagcollection/clear/#) | Remove todas as tags da coleção. |
| [`get_value_by_index(self, index)`](/slides/python-net/pt/aspose.slides/tagcollection/get_value_by_index/#int) | Retorna o valor de uma tag no índice especificado. |
| [`get_name_by_index(self, index)`](/slides/python-net/pt/aspose.slides/tagcollection/get_name_by_index/#int) | Retorna a chave de uma tag no índice especificado. |
| [`get_names_of_tags(self)`](/slides/python-net/pt/aspose.slides/tagcollection/get_names_of_tags/#) | Retorna os nomes das tags. |
