## SensitivityLabelAssignmentType enumeração

Representa o método de atribuição para o rótulo de sensibilidade.

O tipo SensitivityLabelAssignmentType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| STANDARD | Use para qualquer rótulo de sensibilidade que não foi aplicado diretamente pelo usuário. <br/>            Isso inclui quaisquer rótulos padrão, rótulos aplicados automaticamente. |
| PRIVILEGED | Use para qualquer rótulo de sensibilidade que foi aplicado diretamente pelo usuário. <br/>            Isso inclui quaisquer rótulos de sensibilidade aplicados manualmente, bem como rotulagem recomendada<br/>            ou obrigatória ou qualquer recurso onde o usuário decide qual rótulo de sensibilidade aplicar. |
