## Row classe

Representa uma linha em uma tabela.

**Herança:**[`Row`](/slides/python-net/pt/aspose.slides/row) → [`CellCollection`](/slides/python-net/pt/aspose.slides/cellcollection)

O tipo Row expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`slide`](/slides/python-net/pt/aspose.slides/row/slide/) | Retorna o slide pai de um CellCollection.<br/>            Somente leitura [`IBaseSlide`](/slides/python-net/pt/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/pt/aspose.slides/row/presentation/) | Retorna a apresentação pai de um CellCollection.<br/>            Somente leitura [`IPresentation`](/slides/python-net/pt/aspose.slides/ipresentation). |
| [`height`](/slides/python-net/pt/aspose.slides/row/height/) | Retorna a altura de uma linha.<br/>            Somente leitura **float**. |
| [`minimal_height`](/slides/python-net/pt/aspose.slides/row/minimal_height/) | Retorna ou define a altura mínima possível de uma linha.<br/>            Leitura/gravação **float**. |
| [`row_format`](/slides/python-net/pt/aspose.slides/row/row_format/) | Retorna o objeto RowFormat que contém propriedades de formatação para esta linha.<br/>            Somente leitura [`IRowFormat`](/slides/python-net/pt/aspose.slides/irowformat). |
