## ITabEffectiveData classe

Objeto imutável que contém as propriedades de parada de tabulação do texto efetivo.

O tipo ITabEffectiveData expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`position`](/slides/python-net/pt/aspose.slides/itabeffectivedata/position/) | Retorna a posição de uma tabulação.<br/>            Atribuir esta propriedade pode mudar o índice da tabulação na coleção e invalidar o Enumerator.<br/>            Somente leitura **float**. |
| [`alignment`](/slides/python-net/pt/aspose.slides/itabeffectivedata/alignment/) | Retorna o estilo de alinhamento de uma tabulação.<br/>            Somente leitura [`TabAlignment`](/slides/python-net/pt/aspose.slides/tabalignment). |


### Observações

Esta interface é usada como parte de [`IParagraphFormatEffectiveData`](/slides/python-net/pt/aspose.slides/iparagraphformateffectivedata).
