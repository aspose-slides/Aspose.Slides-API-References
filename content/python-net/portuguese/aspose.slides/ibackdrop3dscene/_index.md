## IBackdrop3DScene classe

Define um plano no qual efeitos, como brilho e sombra, são aplicados em relação à forma à qual são aplicados.

O tipo IBackdrop3DScene expõe os seguintes membros:

## Propriedades

| Property | Description |
| :- | :- |
| [`normal_vector`](/slides/python-net/pt/aspose.slides/ibackdrop3dscene/normal_vector/) | Retorna ou define um vetor normal. Para ser mais preciso, este atributo define um vetor<br/>            normal à face do plano de fundo. Vetor representado por um array de 3 valores float<br/>            que definem as coordenadas X, Y e Z.<br/>            Leitura/Gravação **float**[]. |
| [`anchor_point`](/slides/python-net/pt/aspose.slides/ibackdrop3dscene/anchor_point/) | Retorna ou define um ponto em espaço 3D. Este ponto é o ponto no espaço que fixa o plano de fundo.<br/>            Ponto 3D representado por um array de 3 valores float que definem as coordenadas X, Y e Z.<br/>            Leitura/Gravação **float**[]. |
| [`up_vector`](/slides/python-net/pt/aspose.slides/ibackdrop3dscene/up_vector/) | Retorna ou define um vetor que representa a direção para cima. Para ser mais preciso, este atributo define um vetor<br/>            que representa a direção para cima em relação à face do plano de fundo. Vetor representado por um array<br/>            de 3 valores float que definem as coordenadas X, Y e Z.<br/>            Leitura/Gravação **float**[]. |
