## Point classe

Representa um par ordenado de coordenadas inteiras x e y que define um ponto em um plano bidimensional. Compatível com .NET `System.Drawing.Point`.

O tipo Point expõe os seguintes membros:

## Construtores

| Construtor | Descrição |
| :- | :- |
| [`__init__(self, x=0, y=0)`](/slides/python-net/pt/aspose.slides/point/__init__/#int-int) | Cria um ponto com as coordenadas especificadas. Valores de ponto flutuante são truncados para inteiros. |

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`x`](/slides/python-net/pt/aspose.slides/point/x/) | Obtém ou define a coordenada x deste ponto.<br/>            Read/write **int**. |
| [`y`](/slides/python-net/pt/aspose.slides/point/y/) | Obtém ou define a coordenada y deste ponto.<br/>            Read/write **int**. |


### Observações

Pontos são comparados por suas coordenadas com `==` e podem ser usados como chaves de dicionário ou membros de conjunto.
