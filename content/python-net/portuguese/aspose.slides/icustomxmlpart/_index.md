## ICustomXmlPart classe

Representa uma parte XML personalizada.

O tipo ICustomXmlPart expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`xml_as_string`](/slides/python-net/pt/aspose.slides/icustomxmlpart/xml_as_string/) | Retorna ou define os dados xml como string UTF-8.<br/>            Read/write **str**.<br/>            o valor é `None`. o valor está vazio ou os dados xml são inválidos. |
| [`xml_data`](/slides/python-net/pt/aspose.slides/icustomxmlpart/xml_data/) | Retorna ou define os dados xml.<br/>            Read/write **int**[].<br/>            o valor é `None`. o valor está vazio ou os dados xml são inválidos. |
| [`item_id`](/slides/python-net/pt/aspose.slides/icustomxmlpart/item_id/) | Especifica um identificador globalmente único (GUID) que identifica de forma exclusiva uma única parte XML personalizada <br/>            dentro de um documento Office Open XML.<br/>            Read-only **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/pt/aspose.slides/icustomxmlpart/namespace_schemas/) | Retorna a coleção de esquemas XML que estão associados à parte XML personalizada.<br/>            Read-only **str**[]. |

## Métodos

| Método | Descrição |
| :- | :- |
| [`remove(self)`](/slides/python-net/pt/aspose.slides/icustomxmlpart/remove/#) | Remove a parte XML personalizada da apresentação. |
