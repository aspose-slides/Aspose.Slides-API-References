## FontsLoader classe

Classe para carregar fontes personalizadas definidas pelo usuário.
            Deve ser usado antes de criar quaisquer objetos de apresentação.

O tipo FontsLoader expõe os seguintes membros:

## Métodos

| Método | Descrição |
| :- | :- |
| [`load_external_fonts(directories)`](/slides/python-net/pt/aspose.slides/fontsloader/load_external_fonts/#liststr) | Adiciona pastas adicionais para buscar fontes. |
| [`load_external_font(data)`](/slides/python-net/pt/aspose.slides/fontsloader/load_external_font/#bytes) | Adiciona fonte a partir dos dados binários. |
| [`get_font_folders()`](/slides/python-net/pt/aspose.slides/fontsloader/get_font_folders/#) | Obtém pastas de fontes. Retorna pastas que foram adicionadas com o método LoadExternalFonts, bem como pastas de fontes do sistema. |
| [`clear_cache()`](/slides/python-net/pt/aspose.slides/fontsloader/clear_cache/#) | Libera todas as fontes personalizadas definidas pelo usuário. |
