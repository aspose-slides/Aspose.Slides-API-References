## Enumeração SourceFormat

Representa o formato do arquivo de origem.

O tipo SourceFormat expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| PPT | Apresentação Microsoft PowerPoint 97-2003 (*.ppt). |
| PPTX | Apresentação Microsoft Office Open XML (*.pptx). |
| ODP | Apresentação OpenDocument (*.odp). |
| PPTM | Apresentação Microsoft Office Open XML com macro (*.pptm). |
| PPSX | Apresentação de Slides Microsoft Office Open XML (*.ppsx). |
| PPSM | Apresentação de Slides Microsoft Office Open XML com macro (*.ppsm). |
| POTX | Modelo Microsoft Office Open XML (*.potx). |
| POTM | Modelo Microsoft Office Open XML com macro (*.potm). |
| PPS | Apresentação de Slides Microsoft PowerPoint 97-2003 (*.pps). |
| POT | Modelo Microsoft PowerPoint 97-2003 (*.pot). |
| OTP | Modelo de Apresentação OpenDocument (*.otp). |
| FODP | Apresentação ODF Flat XML (*.fodp). |
| XML | Apresentação PowerPoint XML (*.xml). |
