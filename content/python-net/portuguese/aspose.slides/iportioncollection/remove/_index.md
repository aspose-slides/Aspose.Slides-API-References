## remove(self, item) {#iportion}
Remove a primeira ocorrência de um objeto específico da **System.Collections.Generic.ICollection`1**.

### Retorna

true se `item` foi removido com sucesso da **System.Collections.Generic.ICollection`1**; caso contrário, false. Este método também retorna false se `item` não for encontrado na **System.Collections.Generic.ICollection`1** original.



```python
def remove(self, item):
    ...
```


| Parâmetro | Tipo | Descrição |
| :- | :- | :- |
| item | [`IPortion`](/slides/python-net/pt/aspose.slides/iportion) | O objeto a ser removido da **System.Collections.Generic.ICollection`1**. |

### Exceções

| Exceção | Descrição |
| :- | :- |
| **RuntimeError(Proxy error(NotSupportedException))** | A **System.Collections.Generic.ICollection`1** é somente leitura. |
