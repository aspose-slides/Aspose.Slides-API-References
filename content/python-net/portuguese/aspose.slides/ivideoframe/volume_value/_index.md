## volume_value propriedade
Retorna ou define o volume exato do vídeo como uma porcentagem.
             O valor é expresso como uma porcentagem de 0 a 100. Use esta propriedade
             para ler ou definir valores de volume que são mais precisos do que os pré-definidos
             níveis disponíveis através da propriedade [`IVideoFrame.volume`](/slides/python-net/pt/aspose.slides/ivideoframe/volume).
             Leitura/gravação **float**.
