## ICaptions classe

Representa as legendas fechadas WebVTT.

O tipo ICaptions expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`caption_id`](/slides/python-net/pt/aspose.slides/icaptions/caption_id/) | Retorna o identificador globalmente único (GUID) das legendas fechadas.<br/>            Somente leitura **System.Guid**. |
| [`label`](/slides/python-net/pt/aspose.slides/icaptions/label/) | Retorna ou define o rótulo das legendas fechadas.<br/>            Leitura/gravação **str**. |
| [`binary_data`](/slides/python-net/pt/aspose.slides/icaptions/binary_data/) | Retorna os dados binários das legendas fechadas.<br/>            Somente leitura **int**[]. |
| [`data_as_string`](/slides/python-net/pt/aspose.slides/icaptions/data_as_string/) | Retorna os dados das legendas fechadas como string codificada em UTF-8<br/>            Somente leitura **str**. |
