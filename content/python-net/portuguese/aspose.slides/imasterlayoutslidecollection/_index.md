## IMasterLayoutSlideCollection classe

Representa uma coleção de todos os slides de layout do slide mestre definido.
Estende a interface ILayoutSlideCollection com métodos para adicionar/inserir/remover/clonar slides de layout no contexto das coleções individuais de slides de layout do mestre.
