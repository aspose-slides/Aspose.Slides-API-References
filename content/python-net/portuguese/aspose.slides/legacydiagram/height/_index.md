## height propriedade
Gets or sets the height of the shape, measured in points.
            Leitura/gravação **float**.


### Observações

O valor retornado está sempre definido e nunca **float**.
            O valor atribuído também deve estar definido; atribua **float** apenas a propriedades de uma `RawFrame` instância.
