## enumeração PPImageFormat

Formatos de imagem. Esta enumeração substitui a classe `System.Drawing.Imaging.ImageFormat`. É necessária para compatibilidade COM.

O tipo PPImageFormat expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| BMP | Obtém o formato de imagem bitmap (BMP). |
| EMF | Obtém o formato de imagem metafile aprimorado (EMF). |
| EXIF | Obtém o formato Exchangeable Image File (Exif). |
| GIF | Obtém o formato Graphics Interchange Format (GIF). |
| ICON | Obtém o formato de imagem de ícone do Windows. |
| JPEG | Obtém o formato Joint Photographic Experts Group (JPEG). |
| MEMORY_BMP | Obtém o formato de um bitmap na memória. |
| PNG | Obtém o formato de imagem Portable Network Graphics (PNG) da W3C. |
| TIFF | Obtém o formato de imagem Tagged Image File Format (TIFF). |
| WMF | Obtém o formato de imagem metafile do Windows (WMF). |
