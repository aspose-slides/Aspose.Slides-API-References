## height propriedade
Retorna ou define a height da marcação de um parágrafo sem herança.
            O valor float.NaN determina que a marcação herda height da primeira porção no parágrafo.
            Leitura/gravação **float**.

### Observações

Um valor negativo para height significa que a height é dada em pontos e
            um valor positivo significa que a height é uma porcentagem do texto circundante.
