## Enumeração ImageFormat

Representa o formato de arquivo da imagem.

O tipo ImageFormat expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| MEMORY_BMP | Representa o formato de um bitmap na memória. |
| BMP | Representa o formato de imagem bitmap (BMP). |
| EMF | Representa o formato de imagem metafile aprimorado (EMF). |
| WMF | Representa o formato de imagem metafile do Windows (WMF). |
| GIF | Representa o formato de imagem Graphics Interchange Format (GIF). |
| JPEG | Representa o formato de imagem Joint Photographic Experts Group (JPEG). |
| PNG | Representa o formato de imagem W3C Portable Network Graphics (PNG). |
| TIFF | Representa o formato de imagem Tagged Image File Format (TIFF). |
| EXIF | Representa o formato Exchangeable Image File (Exif). |
| ICON | Representa o formato de imagem de ícone do Windows. |
