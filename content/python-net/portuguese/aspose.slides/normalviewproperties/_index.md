## NormalViewProperties classe

Representa as propriedades da visualização normal. A visualização normal consiste em três regiões de conteúdo: o próprio slide, uma região de conteúdo lateral e uma região de conteúdo inferior.

O tipo NormalViewProperties expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`show_outline_icons`](/slides/python-net/pt/aspose.slides/normalviewproperties/show_outline_icons/) | Especifica se o aplicativo deve mostrar ícones ao exibir conteúdo de contorno em qualquer<br/>            das regiões de conteúdo do modo de visualização normal.<br/>            Leitura/gravação **bool**. |
| [`snap_vertical_splitter`](/slides/python-net/pt/aspose.slides/normalviewproperties/snap_vertical_splitter/) | Especifica se o divisor vertical deve encaixar em um estado minimizado quando a região lateral<br/>            é suficientemente pequena.<br/>            Leitura/gravação **bool**. |
| [`vertical_bar_state`](/slides/python-net/pt/aspose.slides/normalviewproperties/vertical_bar_state/) | Especifica o estado em que a barra de divisor vertical deve ser exibida. <br/>            Uma barra de divisor vertical separa o slide da região de conteúdo lateral. |
| [`horizontal_bar_state`](/slides/python-net/pt/aspose.slides/normalviewproperties/horizontal_bar_state/) | Especifica o estado em que a barra de divisor horizontal deve ser exibida.<br/>            Uma barra de divisor horizontal separa o slide da região de conteúdo abaixo do slide. |
| [`prefer_single_view`](/slides/python-net/pt/aspose.slides/normalviewproperties/prefer_single_view/) | Especifica se o usuário prefere ver uma única região de conteúdo em janela completa em vez da<br/>            visualização normal padrão com três regiões de conteúdo. Se habilitado, o aplicativo pode escolher<br/>            exibir uma das regiões de conteúdo em toda a janela.<br/>            Leitura/gravação **bool**. |
| [`restored_left`](/slides/python-net/pt/aspose.slides/normalviewproperties/restored_left/) | Este elemento especifica o dimensionamento da região de conteúdo lateral da visualização normal, quando a região tem um tamanho restaurado variável (nem minimizado nem maximizado).<br/>            Somente leitura [`INormalViewRestoredProperties`](/slides/python-net/pt/aspose.slides/inormalviewrestoredproperties). |
| [`restored_top`](/slides/python-net/pt/aspose.slides/normalviewproperties/restored_top/) | Este elemento especifica o dimensionamento da região superior do slide da visualização normal, quando a região tem um tamanho restaurado variável (nem minimizado nem maximizado).<br/>            Somente leitura [`INormalViewRestoredProperties`](/slides/python-net/pt/aspose.slides/inormalviewrestoredproperties). |
