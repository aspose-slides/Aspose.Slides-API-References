## SensitivityLabelContentType enumeração

Representa os tipos de marcação de conteúdo que devem ser aplicados a um documento.

O tipo SensitivityLabelContentType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| NONE | Indica que a rotulagem é aplicada por padrão ou automaticamente. |
| HEADER | Indica que a rotulagem foi aplicada manualmente.<br/>            Use para qualquer rótulo de sensibilidade que tenha sido aplicado diretamente pelo usuário. |
| FOOTER | Indica que a rotulagem foi aplicada manualmente.<br/>            Use para qualquer rótulo de sensibilidade que tenha sido aplicado diretamente pelo usuário. |
| WATERMARK | Indica que a rotulagem foi aplicada manualmente.<br/>            Use para qualquer rótulo de sensibilidade que tenha sido aplicado diretamente pelo usuário. |
| ENCRYPTION | Indica que a rotulagem foi aplicada manualmente.<br/>            Use para qualquer rótulo de sensibilidade que tenha sido aplicado diretamente pelo usuário. |
