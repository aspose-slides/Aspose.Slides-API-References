## SlideLayoutType enumeração

Representa o tipo de layout de slide.

O tipo SlideLayoutType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| CUSTOM | Personalizado |
| TITLE | Título |
| TEXT | Texto |
| TWO_COLUMN_TEXT | Texto de duas colunas |
| TABLE | Tabela |
| TEXT_AND_CHART | Texto e Gráfico |
| CHART_AND_TEXT | Gráfico e Texto |
| DIAGRAM | Diagrama |
| CHART | Gráfico |
| TEXT_AND_CLIP_ART | Texto e Clip Art |
| CLIP_ART_AND_TEXT | Clip Art e Texto |
| TITLE_ONLY | Apenas Título |
| BLANK | Em branco |
| TEXT_AND_OBJECT | Texto e Objeto |
| OBJECT_AND_TEXT | Objeto e Texto |
| OBJECT | Objeto |
| TITLE_AND_OBJECT | Título e Objeto |
| TEXT_AND_MEDIA | Texto e Mídia |
| MEDIA_AND_TEXT | Mídia e Texto |
| OBJECT_OVER_TEXT | Objeto sobre Texto |
| TEXT_OVER_OBJECT | Texto sobre Objeto |
| TEXT_AND_TWO_OBJECTS | Texto e Dois Objetos |
| TWO_OBJECTS_AND_TEXT | Dois Objetos e Texto |
| TWO_OBJECTS_OVER_TEXT | Dois Objetos sobre Texto |
| FOUR_OBJECTS | Quatro Objetos |
| VERTICAL_TEXT | Texto Vertical |
| CLIP_ART_AND_VERTICAL_TEXT | Clip Art e Texto Vertical |
| VERTICAL_TITLE_AND_TEXT | Título Vertical e Texto |
| VERTICAL_TITLE_AND_TEXT_OVER_CHART | Título Vertical e Texto sobre Gráfico |
| TWO_OBJECTS | Dois Objetos |
| OBJECT_AND_TWO_OBJECT | Objeto e Dois Objetos |
| TWO_OBJECTS_AND_OBJECT | Dois Objetos e Objeto |
| SECTION_HEADER | Cabeçalho de Seção |
| TWO_TEXT_AND_TWO_OBJECTS | Dois Textos e Dois Objetos |
| TITLE_OBJECT_AND_CAPTION | Título, Objeto e Legenda |
| PICTURE_AND_CAPTION | Imagem e Legenda |
