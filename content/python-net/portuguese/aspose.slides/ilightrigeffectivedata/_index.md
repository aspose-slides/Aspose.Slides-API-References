## ILightRigEffectiveData classe

Objeto imutável que contém propriedades eficazes de rig de luz.

O tipo ILightRigEffectiveData expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`direction`](/slides/python-net/pt/aspose.slides/ilightrigeffectivedata/direction/) | Direção da luz.<br/>            Somente leitura [`LightingDirection`](/slides/python-net/pt/aspose.slides/lightingdirection). |
| [`light_type`](/slides/python-net/pt/aspose.slides/ilightrigeffectivedata/light_type/) | Representa uma luz pré-definida que pode ser aplicada a uma forma. <br/>            O rig de luz representa um grupo de luzes orientadas de maneira específica em relação a uma cena 3D.<br/>            Somente leitura [`LightRigPresetType`](/slides/python-net/pt/aspose.slides/lightrigpresettype). |

## Métodos

| Método | Descrição |
| :- | :- |
| [`get_rotation(self)`](/slides/python-net/pt/aspose.slides/ilightrigeffectivedata/get_rotation/#) | Uma rotação é definida pelo uso de uma coordenada de latitude, uma coordenada de longitude e uma revolução ao redor do eixo como coordenadas de latitude e longitude.<br/>            Primeiro elemento no array de retorno - latitude, segundo - longitude, terceiro - revolução. |


### Observações

Esta interface é usada como parte de [`IThreeDFormatEffectiveData`](/slides/python-net/pt/aspose.slides/ithreedformateffectivedata).
