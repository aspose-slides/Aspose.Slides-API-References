## TextVerticalType enumeração

Determina o modo de escrita vertical para um texto.

O tipo TextVerticalType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| NOT_DEFINED | Não definido. |
| HORIZONTAL | Texto horizontal. |
| VERTICAL | Texto vertical. |
| VERTICAL270 | Texto vertical de 270 graus. |
| WORD_ART_VERTICAL | Texto vertical WordArt. |
| EAST_ASIAN_VERTICAL | Texto vertical do Leste Asiático. |
| MONGOLIAN_VERTICAL | Texto vertical mongol. |
| WORD_ART_VERTICAL_RIGHT_TO_LEFT | Texto vertical WordArt da direita para a esquerda. |
