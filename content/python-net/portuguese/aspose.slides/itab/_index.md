## ITab classe

Representa uma tabulação para um texto.

O tipo ITab expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`position`](/slides/python-net/pt/aspose.slides/itab/position/) | Retorna ou define a posição de uma tabulação.<br/>            Atribuir esta propriedade pode mudar o índice da tabulação na coleção e invalidar o Enumerator.<br/>            Leitura/gravação **float**. |
| [`alignment`](/slides/python-net/pt/aspose.slides/itab/alignment/) | Retorna ou define o estilo de alinhamento de uma tabulação.<br/>            Leitura/gravação [`TabAlignment`](/slides/python-net/pt/aspose.slides/tabalignment). |
