## CustomXmlPart classe

Representa uma parte XML personalizada.

O tipo CustomXmlPart expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`xml_data`](/slides/python-net/pt/aspose.slides/customxmlpart/xml_data/) | Retorna ou define os dados xml.<br/>            Leitura/gravação **int**[].<br/>            o valor é `None`.o valor está vazio ou os dados xml são inválidos. |
| [`xml_as_string`](/slides/python-net/pt/aspose.slides/customxmlpart/xml_as_string/) | Retorna ou define os dados xml como string UTF-8.<br/>            Leitura/gravação **str**.<br/>            o valor é `None`.o valor está vazio ou os dados xml são inválidos. |
| [`item_id`](/slides/python-net/pt/aspose.slides/customxmlpart/item_id/) | Especifica um identificador globalmente único (GUID) que identifica de forma única uma única parte XML personalizada <br/>            dentro de um documento Office Open XML.<br/>            Somente leitura **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/pt/aspose.slides/customxmlpart/namespace_schemas/) | Retorna a coleção de esquemas XML associados à parte XML personalizada.<br/>            Somente leitura **str**[]. |

## Métodos

| Método | Descrição |
| :- | :- |
| [`remove(self)`](/slides/python-net/pt/aspose.slides/customxmlpart/remove/#) | Remove a parte XML personalizada da apresentação. |
