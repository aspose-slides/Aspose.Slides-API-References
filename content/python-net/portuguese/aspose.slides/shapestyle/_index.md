## ShapeStyle classe

Representa a referência de estilo da forma.

O tipo ShapeStyle expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`line_color`](/slides/python-net/pt/aspose.slides/shapestyle/line_color/) | Retorna a cor de contorno de uma forma.<br/>            Somente leitura [`IColorFormat`](/slides/python-net/pt/aspose.slides/icolorformat). |
| [`line_style_index`](/slides/python-net/pt/aspose.slides/shapestyle/line_style_index/) | Retorna ou define o índice da coluna da linha em uma matriz de estilo.<br/>            Leitura/gravação **int**. |
| [`fill_color`](/slides/python-net/pt/aspose.slides/shapestyle/fill_color/) | Retorna a cor de preenchimento de uma forma.<br/>            Somente leitura [`IColorFormat`](/slides/python-net/pt/aspose.slides/icolorformat). |
| [`fill_style_index`](/slides/python-net/pt/aspose.slides/shapestyle/fill_style_index/) | Retorna ou define o índice da coluna de preenchimento da forma em matrizes de estilo.<br/>            0 significa sem preenchimento,<br/>            valor positivo - índice nos estilos de preenchimento do tema,<br/>            valor negativo - índice nos estilos de plano de fundo do tema.<br/>            Leitura/gravação **int**. |
| [`effect_color`](/slides/python-net/pt/aspose.slides/shapestyle/effect_color/) | Retorna a cor de efeito de uma forma.<br/>            Somente leitura [`IColorFormat`](/slides/python-net/pt/aspose.slides/icolorformat). |
| [`effect_style_index`](/slides/python-net/pt/aspose.slides/shapestyle/effect_style_index/) | Retorna ou define o índice da coluna de efeito da forma em uma matriz de estilo.<br/>            Leitura/gravação **int**. |
| [`font_color`](/slides/python-net/pt/aspose.slides/shapestyle/font_color/) | Retorna a cor da fonte de uma forma.<br/>            Somente leitura [`IColorFormat`](/slides/python-net/pt/aspose.slides/icolorformat). |
| [`font_collection_index`](/slides/python-net/pt/aspose.slides/shapestyle/font_collection_index/) | Retorna ou define o índice da fonte da forma em uma coleção de fontes.<br/>            Leitura/gravação [`FontCollectionIndex`](/slides/python-net/pt/aspose.slides/fontcollectionindex). |
