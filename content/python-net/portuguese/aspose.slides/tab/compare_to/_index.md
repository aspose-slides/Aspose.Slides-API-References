## compare_to(self, obj) {#any}
Compara a instância atual com outro objeto do mesmo tipo.

### Retorno

Um inteiro de 32 bits que indica a ordem relativa dos comparandos.  
O valor retornado tem os seguintes significados:
            
*  < 0 - Esta instância é menor que obj. = 0 - Esta instância é igual a obj. > 0 - Esta instância é maior que obj.

*  < 0 - Esta instância é menor que obj. = 0 - Esta instância é igual a obj. > 0 - Esta instância é maior que obj.

*  < 0 - Esta instância é menor que obj. = 0 - Esta instância é igual a obj. > 0 - Esta instância é maior que obj.
