## tile_alignment propriedade
Returns or sets how the texture is aligned within the shape. This setting controls the starting point of the texture pattern and how it repeats across the shape.
             Leitura/gravação [`RectangleAlignment`](/slides/python-net/pt/aspose.slides/rectanglealignment).

### Observações

O valor padrão é [`RectangleAlignment.TOP_LEFT`](/slides/python-net/pt/aspose.slides/rectanglealignment/TOP_LEFT).
