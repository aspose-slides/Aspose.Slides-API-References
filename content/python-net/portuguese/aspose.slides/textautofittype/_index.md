## TextAutofitType enumeração

Representa o modo de ajuste automático de texto.

O tipo TextAutofitType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| NOT_DEFINED | Não definido. |
| NONE | Sem ajuste automático. |
| NORMAL | Ajuste automático normal. O tamanho da fonte e o espaçamento entre linhas serão reduzidos para caber na forma. |
| SHAPE | Ajuste automático de forma. O tamanho da forma será alterado para caber o texto. |
