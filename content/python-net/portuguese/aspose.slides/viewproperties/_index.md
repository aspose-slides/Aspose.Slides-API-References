## ViewProperties classe

Propriedades de visualização de toda a apresentação.

O tipo ViewProperties expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`last_view`](/slides/python-net/pt/aspose.slides/viewproperties/last_view/) | Especifica o modo de visualização que foi usado quando o documento da apresentação foi salvo pela última vez.<br/>            Leitura/Gravação [`ViewType`](/slides/python-net/pt/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/pt/aspose.slides/viewproperties/show_comments/) | Especifica se os comentários do slide devem ser mostrados.<br/>            Leitura/Gravação [`NullableBool`](/slides/python-net/pt/aspose.slides/nullablebool). |
| [`normal_view_properties`](/slides/python-net/pt/aspose.slides/viewproperties/normal_view_properties/) | Representa as propriedades da visualização normal. A visualização normal consiste em<br/>            três regiões de conteúdo: o próprio slide, uma região de conteúdo lateral e uma região de conteúdo inferior.<br/>            Somente leitura [`INormalViewProperties`](/slides/python-net/pt/aspose.slides/inormalviewproperties). |
| [`slide_view_properties`](/slides/python-net/pt/aspose.slides/viewproperties/slide_view_properties/) | Especifica as propriedades de visualização comuns associadas ao modo de visualização de slide.<br/>            Somente leitura [`ICommonSlideViewProperties`](/slides/python-net/pt/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/pt/aspose.slides/viewproperties/notes_view_properties/) | Especifica as propriedades de visualização comuns associadas ao modo de visualização de notas.<br/>            Somente leitura [`ICommonSlideViewProperties`](/slides/python-net/pt/aspose.slides/icommonslideviewproperties). |
| [`grid_spacing`](/slides/python-net/pt/aspose.slides/viewproperties/grid_spacing/) | Retorna ou define o espaçamento da grade que deve ser usado para a grade subjacente ao documento da apresentação, em pontos.<br/>            Leitura/Gravação **float**. |
