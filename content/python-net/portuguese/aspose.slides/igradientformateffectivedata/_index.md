## classe IGradientFormatEffectiveData

Objeto imutável que contém propriedades de preenchimento de gradiente efetivas.

O tipo IGradientFormatEffectiveData expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`tile_flip`](/slides/python-net/pt/aspose.slides/igradientformateffectivedata/tile_flip/) | Retorna o modo de inversão para um gradiente.<br/>            Somente leitura [`TileFlip`](/slides/python-net/pt/aspose.slides/tileflip). |
| [`gradient_direction`](/slides/python-net/pt/aspose.slides/igradientformateffectivedata/gradient_direction/) | Retorna o estilo de um gradiente.<br/>            Somente leitura [`GradientDirection`](/slides/python-net/pt/aspose.slides/gradientdirection). |
| [`linear_gradient_angle`](/slides/python-net/pt/aspose.slides/igradientformateffectivedata/linear_gradient_angle/) | Retorna o ângulo de um gradiente.<br/>            Somente leitura **float**. |
| [`linear_gradient_scaled`](/slides/python-net/pt/aspose.slides/igradientformateffectivedata/linear_gradient_scaled/) | Determina se um gradiente é dimensionado.<br/>            Somente leitura **bool**. |
| [`gradient_shape`](/slides/python-net/pt/aspose.slides/igradientformateffectivedata/gradient_shape/) | Retorna a forma de um gradiente.<br/>            Somente leitura [`GradientShape`](/slides/python-net/pt/aspose.slides/gradientshape). |
| [`gradient_stops`](/slides/python-net/pt/aspose.slides/igradientformateffectivedata/gradient_stops/) | Retorna a coleção de pontos de parada do gradiente.<br/>            Somente leitura [`IGradientStopCollectionEffectiveData`](/slides/python-net/pt/aspose.slides/igradientstopcollectioneffectivedata). |


### Observações

Esta interface é usada como parte de [`IFillFormatEffectiveData`](/slides/python-net/pt/aspose.slides/ifillformateffectivedata) e [`ILineFillFormatEffectiveData`](/slides/python-net/pt/aspose.slides/ilinefillformateffectivedata).
