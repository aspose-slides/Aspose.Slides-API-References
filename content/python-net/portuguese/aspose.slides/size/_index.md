## classe Size

Armazena um par ordenado de inteiros, que especificam uma largura e uma altura. Compatível com .NET `System.Drawing.Size`.

O tipo Size expõe os seguintes membros:

## Construtores

| Construtor | Descrição |
| :- | :- |
| [`__init__(self, width=0, height=0)`](/slides/python-net/pt/aspose.slides/size/__init__/#int-int) | Cria um tamanho com a largura e altura especificadas. Valores de ponto flutuante são truncados para inteiros. |

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`width`](/slides/python-net/pt/aspose.slides/size/width/) | Obtém o componente horizontal deste tamanho.<br/>            Somente leitura **int**. |
| [`height`](/slides/python-net/pt/aspose.slides/size/height/) | Obtém o componente vertical deste tamanho.<br/>            Somente leitura **int**. |


### Observações

Os tamanhos são comparados pelos seus componentes com `==` e podem ser usados como chaves de dicionário ou membros de conjunto.
