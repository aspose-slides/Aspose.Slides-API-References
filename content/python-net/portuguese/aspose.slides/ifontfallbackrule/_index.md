## IFontFallBackRule classe

Representa a regra de fallback de fonte

O tipo IFontFallBackRule expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`range_start_index`](/slides/python-net/pt/aspose.slides/ifontfallbackrule/range_start_index/) | Obtém o primeiro índice do intervalo unicode contínuo. |
| [`range_end_index`](/slides/python-net/pt/aspose.slides/ifontfallbackrule/range_end_index/) | Obtém o último índice do intervalo unicode contínuo. |
| [`count`](/slides/python-net/pt/aspose.slides/ifontfallbackrule/count/) | Obtém o número de fontes realmente definidas para o intervalo. |

Obtém o nome da fonte no índice especificado.
