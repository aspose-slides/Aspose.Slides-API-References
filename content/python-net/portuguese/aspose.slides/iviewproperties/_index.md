## classe IViewProperties

Propriedades de visualização de toda a apresentação.

O tipo IViewProperties expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`last_view`](/slides/python-net/pt/aspose.slides/iviewproperties/last_view/) | Especifica o modo de visualização que foi usado quando o documento de apresentação foi salvo pela última vez.<br/>            Leitura/Gravação [`ViewType`](/slides/python-net/pt/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/pt/aspose.slides/iviewproperties/show_comments/) | Especifica se os comentários do slide devem ser exibidos.<br/>            Leitura/Gravação [`NullableBool`](/slides/python-net/pt/aspose.slides/nullablebool). |
| [`slide_view_properties`](/slides/python-net/pt/aspose.slides/iviewproperties/slide_view_properties/) | Especifica propriedades de visualização comuns associadas ao modo de visualização de slide.<br/>            Somente leitura [`ICommonSlideViewProperties`](/slides/python-net/pt/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/pt/aspose.slides/iviewproperties/notes_view_properties/) | Especifica propriedades de visualização comuns associadas ao modo de visualização de anotações.<br/>            Somente leitura [`ICommonSlideViewProperties`](/slides/python-net/pt/aspose.slides/icommonslideviewproperties). |
| [`normal_view_properties`](/slides/python-net/pt/aspose.slides/iviewproperties/normal_view_properties/) | Representa propriedades de visualização normal. A visualização normal consiste de<br/>            três regiões de conteúdo: o próprio slide, uma região de conteúdo lateral e uma região de conteúdo inferior.<br/>            Somente leitura [`INormalViewProperties`](/slides/python-net/pt/aspose.slides/inormalviewproperties). |
| [`grid_spacing`](/slides/python-net/pt/aspose.slides/iviewproperties/grid_spacing/) | Retorna ou define o espaçamento da grade que deve ser usado para a grade subjacente ao documento de apresentação, em pontos. <br/>            Leitura/Gravação **float**. |
