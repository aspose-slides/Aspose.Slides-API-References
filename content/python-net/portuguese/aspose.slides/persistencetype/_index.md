## PersistenceType enumeração

Especifica o método usado para armazenar as propriedades do controle ActiveX.

O tipo PersistenceType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| NOT_DEFINED | ID de persistência não especificado. |
| PERSIST_PROPERTY_BAG | Especifica que o controle ActiveX é persistido usando persistência baseada em bolsa de propriedades. <br/>             A persistência baseada em bolsa de propriedades armazena um controle ActiveX por meio de uma coleção de pares de nome <br/>             e valor que especificam os dados persistidos pelo controle ActiveX. |
| PERSIST_STREAM | Especifica que o controle ActiveX é persistido usando uma persistência baseada em fluxo <br/>             que não suporta a inicialização do controle ActiveX para um estado padrão. |
| PERSIST_STREAM_INIT | Especifica que o controle ActiveX é persistido usando uma persistência baseada em fluxo <br/>             que suporta a inicialização do controle ActiveX para um estado padrão. |
| PERSIST_STORAGE | Especifica que o controle ActiveX é persistido usando persistência baseada em armazenamento. |
