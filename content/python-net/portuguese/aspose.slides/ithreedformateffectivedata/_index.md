## IThreeDFormatEffectiveData class

Objeto imutável que representa as propriedades de formatação 3-D efetivas.

O tipo IThreeDFormatEffectiveData expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`contour_width`](/slides/python-net/pt/aspose.slides/ithreedformateffectivedata/contour_width/) | Returns the width of a 3D contour.<br/>            Somente leitura **float**. |
| [`extrusion_height`](/slides/python-net/pt/aspose.slides/ithreedformateffectivedata/extrusion_height/) | Returns the height of an extrusion effect.<br/>            Somente leitura **float**. |
| [`depth`](/slides/python-net/pt/aspose.slides/ithreedformateffectivedata/depth/) | Returns the depth of a 3D shape.<br/>            Somente leitura **float**. |
| [`bevel_top`](/slides/python-net/pt/aspose.slides/ithreedformateffectivedata/bevel_top/) | Returns the type of a top 3D bevel.<br/>            Somente leitura [`IShapeBevelEffectiveData`](/slides/python-net/pt/aspose.slides/ishapebeveleffectivedata). |
| [`bevel_bottom`](/slides/python-net/pt/aspose.slides/ithreedformateffectivedata/bevel_bottom/) | Returns the type of a bottom 3D bevel.<br/>            Somente leitura [`IShapeBevelEffectiveData`](/slides/python-net/pt/aspose.slides/ishapebeveleffectivedata). |
| [`contour_color`](/slides/python-net/pt/aspose.slides/ithreedformateffectivedata/contour_color/) | Returns the color of a contour.<br/>            Somente leitura [`Color`](/slides/python-net/pt/aspose.slides/color). |
| [`extrusion_color`](/slides/python-net/pt/aspose.slides/ithreedformateffectivedata/extrusion_color/) | Returns the color of an extrusion.<br/>            Somente leitura [`Color`](/slides/python-net/pt/aspose.slides/color). |
| [`camera`](/slides/python-net/pt/aspose.slides/ithreedformateffectivedata/camera/) | Returns the settings of a camera.<br/>            Somente leitura [`ICameraEffectiveData`](/slides/python-net/pt/aspose.slides/icameraeffectivedata). |
| [`light_rig`](/slides/python-net/pt/aspose.slides/ithreedformateffectivedata/light_rig/) | Returns the type of a light.<br/>            Somente leitura [`ILightRigEffectiveData`](/slides/python-net/pt/aspose.slides/ilightrigeffectivedata). |
| [`material`](/slides/python-net/pt/aspose.slides/ithreedformateffectivedata/material/) | Returns the type of a material.<br/>            Somente leitura [`MaterialPresetType`](/slides/python-net/pt/aspose.slides/materialpresettype). |


### Observações

Esta interface é usada junto com a interface [`IThreeDFormat`](/slides/python-net/pt/aspose.slides/ithreedformat) para retornar valores de formatação efetiva com herança aplicada.
