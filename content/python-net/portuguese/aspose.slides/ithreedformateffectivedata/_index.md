## classe IThreeDFormatEffectiveData

Objeto imutável que representa propriedades de formatação 3D efetivas.

O tipo IThreeDFormatEffectiveData expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`contour_width`](/slides/python-net/pt/aspose.slides/ithreedformateffectivedata/contour_width/) | Retorna a largura de um contorno 3D.<br/>            Somente leitura **float**. |
| [`extrusion_height`](/slides/python-net/pt/aspose.slides/ithreedformateffectivedata/extrusion_height/) | Retorna a altura de um efeito de extrusão.<br/>            Somente leitura **float**. |
| [`depth`](/slides/python-net/pt/aspose.slides/ithreedformateffectivedata/depth/) | Retorna a profundidade de uma forma 3D.<br/>            Somente leitura **float**. |
| [`bevel_top`](/slides/python-net/pt/aspose.slides/ithreedformateffectivedata/bevel_top/) | Retorna o tipo de um chanfrado superior 3D.<br/>            Somente leitura [`IShapeBevelEffectiveData`](/slides/python-net/pt/aspose.slides/ishapebeveleffectivedata). |
| [`bevel_bottom`](/slides/python-net/pt/aspose.slides/ithreedformateffectivedata/bevel_bottom/) | Retorna o tipo de um chanfrado inferior 3D.<br/>            Somente leitura [`IShapeBevelEffectiveData`](/slides/python-net/pt/aspose.slides/ishapebeveleffectivedata). |
| [`contour_color`](/slides/python-net/pt/aspose.slides/ithreedformateffectivedata/contour_color/) | Retorna a cor de um contorno.<br/>            Somente leitura **aspose.slides.Color**. |
| [`extrusion_color`](/slides/python-net/pt/aspose.slides/ithreedformateffectivedata/extrusion_color/) | Retorna a cor de uma extrusão.<br/>            Somente leitura **aspose.slides.Color**. |
| [`camera`](/slides/python-net/pt/aspose.slides/ithreedformateffectivedata/camera/) | Retorna as configurações de uma câmera.<br/>            Somente leitura [`ICameraEffectiveData`](/slides/python-net/pt/aspose.slides/icameraeffectivedata). |
| [`light_rig`](/slides/python-net/pt/aspose.slides/ithreedformateffectivedata/light_rig/) | Retorna o tipo de uma luz.<br/>            Somente leitura [`ILightRigEffectiveData`](/slides/python-net/pt/aspose.slides/ilightrigeffectivedata). |
| [`material`](/slides/python-net/pt/aspose.slides/ithreedformateffectivedata/material/) | Retorna o tipo de um material.<br/>            Somente leitura [`MaterialPresetType`](/slides/python-net/pt/aspose.slides/materialpresettype). |


### Observações

Esta interface é usada junto com a interface [`IThreeDFormat`](/slides/python-net/pt/aspose.slides/ithreedformat) para retornar valores de formatação efetivos com herança aplicada.
