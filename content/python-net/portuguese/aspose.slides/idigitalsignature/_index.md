## IDigitalSignature classe

Assinatura digital em arquivo assinado.

O tipo IDigitalSignature expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`certificate`](/slides/python-net/pt/aspose.slides/idigitalsignature/certificate/) | Objeto de certificado que foi usado para assinar o documento.<br/>            Read-only **System.Security.Cryptography.X509Certificates.X509Certificate2**. |
| [`is_valid`](/slides/python-net/pt/aspose.slides/idigitalsignature/is_valid/) | Se esta assinatura digital for válida e o documento não tiver sido adulterado, este valor será true.<br/>            Read-only **bool**. |
| [`sign_time`](/slides/python-net/pt/aspose.slides/idigitalsignature/sign_time/) | A hora em que o documento foi assinado.<br/>            Read-only **System.DateTime**. |
| [`comments`](/slides/python-net/pt/aspose.slides/idigitalsignature/comments/) | O propósito da assinatura.<br/>            Read/write **str**. |
