## classe Control

Representa um controle ActiveX.

O tipo Control expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`persistence`](/slides/python-net/pt/aspose.slides/control/persistence/) | Obtém o método usado para armazenar propriedades do controle ActiveX.<br/>            Somente leitura [`PersistenceType`](/slides/python-net/pt/aspose.slides/persistencetype). |
| [`name`](/slides/python-net/pt/aspose.slides/control/name/) | Obtém ou define o nome deste controle.<br/>            Leitura/gravação **str**. |
| [`class_id`](/slides/python-net/pt/aspose.slides/control/class_id/) | Obtém o id de classe deste controle.<br/>            Somente leitura **System.Guid**. |
| [`substitute_picture_format`](/slides/python-net/pt/aspose.slides/control/substitute_picture_format/) | Retorna o objeto de propriedades de preenchimento de imagem do Control.<br/>            Somente leitura [`IPictureFillFormat`](/slides/python-net/pt/aspose.slides/ipicturefillformat). |
| [`frame`](/slides/python-net/pt/aspose.slides/control/frame/) | Obtém ou define a moldura do controle.<br/>            Leitura/gravação [`IShapeFrame`](/slides/python-net/pt/aspose.slides/ishapeframe). |
| [`properties`](/slides/python-net/pt/aspose.slides/control/properties/) | Retorna uma coleção de propriedades ActiveX.<br/>            Nota: Aspose.Slides suporta somente propriedades ActiveX baseadas em XML. Se as propriedades forem armazenadas em formato binário, esta propriedade retornará None.<br/>            Somente leitura [`IControlPropertiesCollection`](/slides/python-net/pt/aspose.slides/icontrolpropertiescollection). |
| [`active_x_control_binary`](/slides/python-net/pt/aspose.slides/control/active_x_control_binary/) | Especifica a persistência de um controle ActiveX quando o método usado para persistir é PersistStream, PersistStreamInit ou PersistStorage. |
