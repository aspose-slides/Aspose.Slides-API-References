## Enumeração ShapeAdjustmentType

Especifica diferentes tipos de valores de ajuste de forma.

O tipo ShapeAdjustmentType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| CUSTOM | Tipo personalizado (ajuste desconhecido) |
| CORNER_SIZE | Controla o tamanho dos cantos. |
| LEFT_UP_CORNER | Controla o canto superior esquerdo. |
| RIGHT_UP_CORNER | Controla o canto superior direito. |
| UP_CORNERS | Controla os cantos superiores. |
| DOWN_CORNERS | Controla os cantos inferiores. |
| THICKNESS | Controla a espessura da figura. |
| ARROW_TAIL_THICKNESS | Controla a espessura da cauda da seta. |
| ARROWHEAD_LENGTH | Controla o comprimento da cabeça da seta. |
| ARROWHEAD_WIDTH | Controla a largura da cabeça da seta. |
| RADIUS | Controla o tamanho do raio da forma ou de sua parte. |
| DEPTH | Controla a profundidade dos dentes da engrenagem ou o efeito de chanfro. |
| SHAPE_PART_OFFSET | Controla o deslocamento de uma parte da figura em relação a outra. |
| ANGLE | Controla o ângulo da figura ou de sua parte. |
| START_ANGLE | Ângulo inicial para formas de pizza e arco. |
| END_ANGLE | Ângulo final para formas de pizza e arco. |
| START_POINT_X | Controla a posição X do ponto inicial do balão. |
| START_POINT_Y | Controla a posição Y do ponto inicial do balão. |
| CONNECTOR_POINT_1X | Controla a posição horizontal do ponto de ajuste do ângulo do balão. |
| CONNECTOR_POINT_1Y | Controla a posição vertical do ponto de ajuste do ângulo do balão. |
| CONNECTOR_POINT_2X | Controla a posição horizontal do ponto de ajuste do ângulo do balão. |
| CONNECTOR_POINT_2Y | Controla a posição vertical do ponto de ajuste do ângulo do balão. |
| CONNECTOR_BEND_POSITION_X | Controla a posição horizontal da curvatura no conector. |
| CONNECTOR_BEND_POSITION_Y | Controla a posição vertical da curvatura no conector. |
| ATTACH_Y | Controla o ponto de fixação vertical da figura. |
| ATTACH_X | Controla o ponto de fixação horizontal da figura. |
| CALLOUT_HEIGHT | Controla o tamanho vertical do balão. |
| CALLOUT_WIDTH | Controla o tamanho horizontal do balão. |
| CALLOUT_SIZE | Controla o tamanho do balão. |
| CURVATURE | Curvatura de uma dobra, colchete, seta curva ou forma. |
| HORIZONTAL_THICKNESS | Controla a espessura horizontal da forma de canto. |
| VERTICAL_THICKNESS | Controla a espessura vertical da forma de canto. |
| VERTICAL_SIZE | Controla o tamanho vertical da forma. |
| HORIZONTAL_SIZE | Controla o tamanho horizontal da forma. |
| TOP | Controla o lado superior de uma forma. |
