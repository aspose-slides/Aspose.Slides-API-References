## binary_data propriedade
Retorna a cópia dos dados de um áudio. No caso de grande quantidade de dados, considere usar o método [`IVideo.get_stream`](/slides/python-net/pt/aspose.slides/ivideo/get_stream) para evitar o carregamento desnecessário dos dados do vídeo na memória ou até mesmo OutOfMemoryException.
