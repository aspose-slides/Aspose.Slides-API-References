## IComment classe

Representa um comentário em um slide.

O tipo IComment expõe os seguintes membros:

## Propriedades

| Property | Description |
| :- | :- |
| [`text`](/slides/python-net/pt/aspose.slides/icomment/text/) | Retorna ou define o texto simples de um comentário de slide.<br/>            Leitura/gravação **str**. |
| [`created_time`](/slides/python-net/pt/aspose.slides/icomment/created_time/) | Retorna ou define o horário de criação de um comentário.<br/>            Definir esta propriedade como **System.DateTime** significa que nenhum horário de comentário está definido.<br/>            Leitura/gravação **System.DateTime**. |
| [`slide`](/slides/python-net/pt/aspose.slides/icomment/slide/) | Retorna ou define o slide pai de um comentário.<br/>            Somente leitura [`ISlide`](/slides/python-net/pt/aspose.slides/islide). |
| [`author`](/slides/python-net/pt/aspose.slides/icomment/author/) | Retorna o autor de um comentário.<br/>            Somente leitura [`ICommentAuthor`](/slides/python-net/pt/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/pt/aspose.slides/icomment/position/) | Retorna ou define a posição de um comentário em um slide.<br/>            Leitura/gravação **aspose.slides.PointF**. |
| [`parent_comment`](/slides/python-net/pt/aspose.slides/icomment/parent_comment/) | Retorna ou define o comentário pai.<br/>            Leitura/gravação [`IComment`](/slides/python-net/pt/aspose.slides/icomment). |

## Métodos

| Method | Description |
| :- | :- |
| [`remove(self)`](/slides/python-net/pt/aspose.slides/icomment/remove/#) | Remove o comentário e todas as suas respostas da coleção pai. |
