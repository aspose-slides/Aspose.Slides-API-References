## unique_id propriedade
Returns an internal, presentation-scoped identifier intended for use by add-ins or other code.
            Como esse valor pode ser reatribuído pelo usuário ou programaticamente, ele não deve ser tratado
            como uma chave única persistente.
            Somente leitura **int**.
