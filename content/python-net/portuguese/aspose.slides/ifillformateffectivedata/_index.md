## IFillFormatEffectiveData classe

Objeto imutável que contém propriedades efetivas de formatação de preenchimento.

O tipo IFillFormatEffectiveData expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`fill_type`](/slides/python-net/pt/aspose.slides/ifillformateffectivedata/fill_type/) | Retorna o tipo de preenchimento.<br/>            Somente leitura [`FillType`](/slides/python-net/pt/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/pt/aspose.slides/ifillformateffectivedata/solid_fill_color/) | Retorna a cor de preenchimento.<br/>            Somente leitura [`Color`](/slides/python-net/pt/aspose.slides/color). |
| [`solid_fill_scheme_color`](/slides/python-net/pt/aspose.slides/ifillformateffectivedata/solid_fill_scheme_color/) | Obtém a cor de preenchimento definida por um esquema de cores.<br/>            O valor [`SchemeColor.NOT_DEFINED`](/slides/python-net/pt/aspose.slides/schemecolor/NOT_DEFINED) indica que o [`IFillFormatEffectiveData.solid_fill_color`](/slides/python-net/pt/aspose.slides/ifillformateffectivedata/solid_fill_color) <br/>            não é uma cor de esquema.<br/>            Somente leitura [`SchemeColor`](/slides/python-net/pt/aspose.slides/schemecolor). |
| [`gradient_format`](/slides/python-net/pt/aspose.slides/ifillformateffectivedata/gradient_format/) | Retorna o formato de preenchimento gradiente.<br/>            Somente leitura [`IGradientFormatEffectiveData`](/slides/python-net/pt/aspose.slides/igradientformateffectivedata). |
| [`pattern_format`](/slides/python-net/pt/aspose.slides/ifillformateffectivedata/pattern_format/) | Retorna o formato de preenchimento de padrão.<br/>            Somente leitura [`IPatternFormatEffectiveData`](/slides/python-net/pt/aspose.slides/ipatternformateffectivedata). |
| [`picture_fill_format`](/slides/python-net/pt/aspose.slides/ifillformateffectivedata/picture_fill_format/) | Retorna o formato de preenchimento de imagem.<br/>            Somente leitura [`IPictureFillFormatEffectiveData`](/slides/python-net/pt/aspose.slides/ipicturefillformateffectivedata). |
| [`rotate_with_shape`](/slides/python-net/pt/aspose.slides/ifillformateffectivedata/rotate_with_shape/) | Determina se o preenchimento deve ser rotacionado com a forma.<br/>            Somente leitura **bool**. |


### Observações

Esta interface é usada juntamente com a interface [`IFillFormat`](/slides/python-net/pt/aspose.slides/ifillformat) para retornar valores efetivos de formatação com herança aplicada.
