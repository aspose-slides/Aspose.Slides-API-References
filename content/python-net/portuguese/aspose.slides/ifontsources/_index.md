## IFontSources classe

Fornece fontes de arquivo e de memória para fontes externas.

O tipo IFontSources expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`font_folders`](/slides/python-net/pt/aspose.slides/ifontsources/font_folders/) | Pastas contendo arquivos de fontes.<br/>            Todos os arquivos de fontes localizados nessas pastas são incluídos na coleção. Pastas pesquisadas recursivamente. |
| [`memory_fonts`](/slides/python-net/pt/aspose.slides/ifontsources/memory_fonts/) | Uma coleção de fontes representadas como arrays de bytes. |
