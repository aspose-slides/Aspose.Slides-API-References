## ITextHighlightingOptions classe

Representa opções que podem ser usadas para destacar texto em um quadro de texto.

O tipo ITextHighlightingOptions expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`case_sensitive`](/slides/python-net/pt/aspose.slides/itexthighlightingoptions/case_sensitive/) | Defina true para usar busca sensível a maiúsculas e minúsculas, false - caso contrário.<br/>            Leitura/escrita **bool**. |
| [`whole_words_only`](/slides/python-net/pt/aspose.slides/itexthighlightingoptions/whole_words_only/) | Defina true para corresponder apenas a palavras inteiras, false - caso contrário.<br/>            Leitura/escrita **bool**. |
