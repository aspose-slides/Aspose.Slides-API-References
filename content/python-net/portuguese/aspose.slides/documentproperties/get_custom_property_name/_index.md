## get_custom_property_name(self, index) {#int}
Retorna o nome de uma propriedade personalizada no índice especificado.

### Retorna

Nome da propriedade personalizada no índice especificado.



```python
def get_custom_property_name(self, index):
    ...
```


| Parâmetro | Tipo | Descrição |
| :- | :- | :- |
| index | **int** | O índice baseado em zero de uma propriedade personalizada a ser obtido. |

### Exceções

| Exceção | Descrição |
| :- | :- |
| **RuntimeError(Proxy error(ArgumentOutOfRangeException))** | O índice é menor que zero. O índice é igual ou maior que Count. |
