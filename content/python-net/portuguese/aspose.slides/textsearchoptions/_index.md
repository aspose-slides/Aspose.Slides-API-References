## TextSearchOptions classe

Representa opções que podem ser usadas para pesquisar texto em uma Presentation, Slide ou TextFrame.

O tipo TextSearchOptions expõe os seguintes membros:

## Construtores

| Construtor | Descrição |
| :- | :- |
| [`__init__(self)`](/slides/python-net/pt/aspose.slides/textsearchoptions/__init__/#) | Cria novas opções padrão de pesquisa de texto. |

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`case_sensitive`](/slides/python-net/pt/aspose.slides/textsearchoptions/case_sensitive/) | Defina true para usar pesquisa sensível a maiúsculas e minúsculas, false caso contrário.<br/>            Leitura/gravação **bool**. |
| [`whole_words_only`](/slides/python-net/pt/aspose.slides/textsearchoptions/whole_words_only/) | Defina true para corresponder apenas a palavras inteiras, false caso contrário.<br/>            Leitura/gravação **bool**. |
| [`include_notes`](/slides/python-net/pt/aspose.slides/textsearchoptions/include_notes/) | Defina `true` para incluir texto contido em notas de slide ([`NotesSlide`](/slides/python-net/pt/aspose.slides/notesslide)) <br/>            ao realizar operações de pesquisa de texto, substituição ou realce.<br/>            O valor padrão é `false`. |
