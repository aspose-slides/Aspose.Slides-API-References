## NumberedBulletStyle enumeração

Representa o estilo das marcas numeradas.

O tipo NumberedBulletStyle expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| NOT_DEFINED | Não definido. |
| BULLET_ALPHA_LC_PERIOD | Caracteres alfabéticos minúsculos com ponto. Exemplo: a., b., c., ... |
| BULLET_ALPHA_UC_PERIOD | Caracteres alfabéticos maiúsculos com ponto. Exemplo: A., B., C., ... |
| BULLET_ARABIC_PAREN_RIGHT | Numerais arábicos com parêntese de fechamento. Exemplo: 1), 2), 3), ... |
| BULLET_ARABIC_PERIOD | Numerais arábicos com ponto. Exemplo: 1., 2., 3., ... |
| BULLET_ROMAN_LC_PAREN_BOTH | Numerais romanos minúsculos com ambos os parênteses. Exemplo: (i), (ii), (iii), ... |
| BULLET_ROMAN_LC_PAREN_RIGHT | Numerais romanos minúsculos com parêntese de fechamento. Exemplo: i), ii), iii), ... |
| BULLET_ROMAN_LC_PERIOD | Numerais romanos minúsculos com ponto. Exemplo: i., ii., iii., ... |
| BULLET_ROMAN_UC_PERIOD | Numerais romanos maiúsculos com ponto. Exemplo: I., II., III., ... |
| BULLET_ALPHA_LC_PAREN_BOTH | Caracteres alfabéticos minúsculos com ambos os parênteses. Exemplo: (a), (b), (c), ... |
| BULLET_ALPHA_LC_PAREN_RIGHT | Caracteres alfabéticos minúsculos com parêntese de fechamento. Exemplo: a), b), c), ... |
| BULLET_ALPHA_UC_PAREN_BOTH | Caracteres alfabéticos maiúsculos com ambos os parênteses. Exemplo: (A), (B), (C), ... |
| BULLET_ALPHA_UC_PAREN_RIGHT | Caracteres alfabéticos maiúsculos com parêntese de fechamento. Exemplo: A), B), C), ... |
| BULLET_ARABIC_PAREN_BOTH | Numerais arábicos com ambos os parênteses. Exemplo: (1), (2), (3), ... |
| BULLET_ARABIC_PLAIN | Numerais arábicos. Exemplo: 1, 2, 3, ... |
| BULLET_ROMAN_UC_PAREN_BOTH | Numerais romanos maiúsculos com ambos os parênteses. Exemplo: (I), (II), (III), ... |
| BULLET_ROMAN_UC_PAREN_RIGHT | Numerais romanos maiúsculos com parêntese de fechamento. Exemplo: I), II), III), ... |
| BULLET_SIMP_CHIN_PLAIN | Chinês simplificado sem ponto. |
| BULLET_SIMP_CHIN_PERIOD | Chinês simplificado com ponto. |
| BULLET_CIRCLE_NUM_DB_PLAIN | Número circundado de duplo byte para valores até 10, a partir de 11 - numerais arábicos. |
| BULLET_CIRCLE_NUM_WD_WHITE_PLAIN | Número colorido de texto com círculo da mesma cor ao redor (números de círculo branco Wingdings). A partir de 11 - numerais arábicos. |
| BULLET_CIRCLE_NUM_WD_BLACK_PLAIN | Número de cor sombra com fundo circular da cor de texto normal (números de círculo preto Wingdings). |
| BULLET_TRAD_CHIN_PLAIN | Chinês tradicional sem ponto. |
| BULLET_TRAD_CHIN_PERIOD | Chinês tradicional com ponto. |
| BULLET_ARABIC_ALPHA_DASH | Caracteres alfabéticos da língua árabe com hífen. |
| BULLET_ARABIC_ABJAD_DASH | Alfabetos Abjad árabes com hífen. |
| BULLET_HEBREW_ALPHA_DASH | Caracteres alfabéticos da língua hebraica com hífen. |
| BULLET_KANJI_KOREAN_PLAIN | Números japonês/coreano sem ponto. |
| BULLET_KANJI_KOREAN_PERIOD | Números japonês/coreano com ponto. |
| BULLET_ARABIC_DB_PLAIN | Esquema de numeração árabe de duplo byte (sem pontuação). |
| BULLET_ARABIC_DB_PERIOD | Esquema de numeração árabe de duplo byte com ponto de duplo byte. |
| BULLET_THAI_ALPHA_PERIOD | Alfabeto tailandês com ponto. |
| BULLET_THAI_ALPHA_PAREN_RIGHT | Parênteses do alfabeto tailandês - direito. |
| BULLET_THAI_ALPHA_PAREN_BOTH | Parênteses do alfabeto tailandês - ambos. |
| BULLET_THAI_NUM_PERIOD | Período numérico tailandês. |
| BULLET_THAI_NUM_PAREN_RIGHT | Parênteses numéricos tailandeses - direito. |
| BULLET_THAI_NUM_PAREN_BOTH | Parênteses numéricos tailandeses - ambos. |
| BULLET_HINDI_ALPHA_PERIOD | Alfabeto hindi com ponto - vogais. |
| BULLET_HINDI_NUM_PERIOD | Período numérico hindi. |
| BULLET_KANJI_SIMP_CHIN_DB_PERIOD | Kanji chinês simplificado DBPeriod. |
| BULLET_HINDI_NUM_PAREN_RIGHT | Parênteses numéricos hindi - direito. |
| BULLET_HINDI_ALPHA_1_PERIOD | Alfabeto hindi com ponto - consoantes. |
