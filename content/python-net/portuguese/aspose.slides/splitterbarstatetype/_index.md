## SplitterBarStateType enumeração

Especifica o estado em que a barra divisória deve ser exibida. A barra divisória separa uma região primária e uma região secundária dentro de uma área de visualização.

O tipo SplitterBarStateType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| MINIMIZED | A região primária ocupa a menor quantidade da área de visualização permitida pela aplicação. |
| RESTORED | A região primária tem um tamanho intermediário específico. |
| MAXIMIZED | A região primária ocupa a maior quantidade da área de visualização permitida pela aplicação. |
