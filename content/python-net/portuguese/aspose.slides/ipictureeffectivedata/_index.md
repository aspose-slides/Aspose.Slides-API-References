## IPictureEffectiveData classe

Objeto imutável que contém propriedades efetivas da imagem.

O tipo IPictureEffectiveData expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`image`](/slides/python-net/pt/aspose.slides/ipictureeffectivedata/image/) | Retorna a imagem incorporada.<br/>            Somente leitura [`IPPImage`](/slides/python-net/pt/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/pt/aspose.slides/ipictureeffectivedata/link_path_long/) | Retorna o URL da imagem vinculada.<br/>            Somente leitura **str**. |
| [`image_transform`](/slides/python-net/pt/aspose.slides/ipictureeffectivedata/image_transform/) | Retorna a coleção de efeitos de transformação da imagem.<br/>            Somente leitura [`IImageTransformOCollectionEffectiveData`](/slides/python-net/pt/aspose.slides.effects/iimagetransformocollectioneffectivedata). |


### Observações

Esta interface é usada como parte de [`IPictureFillFormatEffectiveData`](/slides/python-net/pt/aspose.slides/ipicturefillformateffectivedata) e [`IBulletFormatEffectiveData`](/slides/python-net/pt/aspose.slides/ibulletformateffectivedata).
