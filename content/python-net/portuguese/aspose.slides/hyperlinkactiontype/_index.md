## HyperlinkActionType enumeração

Representa um tipo de ação de hyperlink.

O tipo HyperlinkActionType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| UNKNOWN | Tipo de ação não reconhecido. |
| NO_ACTION | Nenhuma ação. |
| HYPERLINK | Hyperlink usual. |
| JUMP_FIRST_SLIDE | Ir para o primeiro slide da apresentação. |
| JUMP_PREVIOUS_SLIDE | Ir para o slide anterior. |
| JUMP_NEXT_SLIDE | Ir para o próximo slide. |
| JUMP_LAST_SLIDE | Ir para o último slide da apresentação. |
| JUMP_END_SHOW | Ir para o final da apresentação de slides. |
| JUMP_LAST_VIEWED_SLIDE | Ir para o último slide visualizado. |
| JUMP_SPECIFIC_SLIDE | Ir para o slide específico, referenciado pela propriedade [`IHyperlink.target_slide`](/slides/python-net/pt/aspose.slides/ihyperlink/target_slide). |
| START_CUSTOM_SLIDE_SHOW | Iniciar apresentação de slides personalizada. |
| OPEN_FILE | Abrir arquivo referenciado. |
| OPEN_PRESENTATION | Abrir apresentação referenciada. |
| START_STOP_MEDIA | Iniciar/parar reprodução de arquivo de mídia. |
| START_MACRO | Iniciar execução de script de macro. |
| START_PROGRAM | Iniciar programa. |
