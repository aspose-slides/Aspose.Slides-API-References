## FillType enumeração

Especifica o tipo de preenchimento interno de vários objetos visuais.

O tipo FillType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| NOT_DEFINED | O tipo de preenchimento não está definido. |
| NO_FILL | Nenhum preenchimento aplicado. |
| SOLID | Preenchido com uma cor sólida. |
| GRADIENT | O preenchimento é gradiente. |
| PATTERN | Um padrão repetido é usado para preencher o objeto. |
| PICTURE | Uma única imagem é usada para preencher o objeto. |
| GROUP | O objeto visual herda as propriedades de preenchimento do grupo. |
