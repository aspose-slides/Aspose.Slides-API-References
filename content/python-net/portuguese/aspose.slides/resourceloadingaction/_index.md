## Enumeração ResourceLoadingAction

Especifica o modo de carregamento de recursos externos.

O tipo ResourceLoadingAction expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| DEFAULT | Aspose.Slides carregará recurso externo como de costume. |
| SKIP | Aspose.Slides ignorará o carregamento de recurso externo. Apenas o link sem dados será armazenado para uma imagem. |
| USER_PROVIDED | Aspose.Slides usará o array de bytes fornecido pelo usuário em **Aspose.Slides.IResourceLoadingArgs.SetData(Syste** como dados de imagem. |
