## Column classe

Representa uma coluna em uma tabela.

**Herança:**[`Column`](/slides/python-net/pt/aspose.slides/column) → [`CellCollection`](/slides/python-net/pt/aspose.slides/cellcollection)

O tipo Column expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`slide`](/slides/python-net/pt/aspose.slides/column/slide/) | Retorna o slide pai de um CellCollection.<br/>            Somente leitura [`IBaseSlide`](/slides/python-net/pt/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/pt/aspose.slides/column/presentation/) | Retorna a apresentação pai de um CellCollection.<br/>            Somente leitura [`IPresentation`](/slides/python-net/pt/aspose.slides/ipresentation). |
| [`width`](/slides/python-net/pt/aspose.slides/column/width/) | Retorna ou define a largura de uma coluna.<br/>            Leitura/escrita **float**. |
| [`column_format`](/slides/python-net/pt/aspose.slides/column/column_format/) | Retorna o objeto ColumnFormat que contém propriedades de formatação para esta coluna.<br/>            Somente leitura [`IColumnFormat`](/slides/python-net/pt/aspose.slides/icolumnformat). |
