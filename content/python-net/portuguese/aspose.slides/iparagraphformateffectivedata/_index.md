## IParagraphFormatEffectiveData classe

Objeto imutável que contém propriedades efetivas de formatação de parágrafo.

O tipo IParagraphFormatEffectiveData expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`bullet`](/slides/python-net/pt/aspose.slides/iparagraphformateffectivedata/bullet/) | Retorna um formato de marcador de um parágrafo.<br/>            Somente leitura [`IBulletFormatEffectiveData`](/slides/python-net/pt/aspose.slides/ibulletformateffectivedata). |
| [`depth`](/slides/python-net/pt/aspose.slides/iparagraphformateffectivedata/depth/) | Retorna a profundidade de um parágrafo.<br/>            Somente leitura **int**. |
| [`alignment`](/slides/python-net/pt/aspose.slides/iparagraphformateffectivedata/alignment/) | Retorna o alinhamento de texto em um parágrafo.<br/>            Somente leitura [`TextAlignment`](/slides/python-net/pt/aspose.slides/textalignment). |
| [`space_within`](/slides/python-net/pt/aspose.slides/iparagraphformateffectivedata/space_within/) | Retorna a quantidade de espaço entre linhas base em um parágrafo.<br/>            Somente leitura **float**. |
| [`space_before`](/slides/python-net/pt/aspose.slides/iparagraphformateffectivedata/space_before/) | Retorna a quantidade de espaço antes da primeira linha em um parágrafo.<br/>            Somente leitura **float**. |
| [`space_after`](/slides/python-net/pt/aspose.slides/iparagraphformateffectivedata/space_after/) | Retorna a quantidade de espaço após a última linha em um parágrafo.<br/>            Somente leitura **float**. |
| [`east_asian_line_break`](/slides/python-net/pt/aspose.slides/iparagraphformateffectivedata/east_asian_line_break/) | Determina se a quebra de linha da Ásia Oriental é usada em um parágrafo.<br/>            Somente leitura **bool**. |
| [`right_to_left`](/slides/python-net/pt/aspose.slides/iparagraphformateffectivedata/right_to_left/) | Determina se a escrita da direita para a esquerda é usada em um parágrafo.<br/>            Somente leitura **bool**. |
| [`latin_line_break`](/slides/python-net/pt/aspose.slides/iparagraphformateffectivedata/latin_line_break/) | Determina se a quebra de linha latina é usada em um parágrafo.<br/>            Somente leitura **bool**. |
| [`hanging_punctuation`](/slides/python-net/pt/aspose.slides/iparagraphformateffectivedata/hanging_punctuation/) | Determina se a pontuação suspensa é usada em um parágrafo.<br/>            Somente leitura **bool**. |
| [`margin_left`](/slides/python-net/pt/aspose.slides/iparagraphformateffectivedata/margin_left/) | Retorna a margem esquerda em um parágrafo.<br/>            Somente leitura **float**. |
| [`margin_right`](/slides/python-net/pt/aspose.slides/iparagraphformateffectivedata/margin_right/) | Retorna a margem direita em um parágrafo.<br/>            Somente leitura **float**. |
| [`indent`](/slides/python-net/pt/aspose.slides/iparagraphformateffectivedata/indent/) | Retorna o recuo da primeira linha/recuo suspenso do parágrafo. O recuo suspenso pode ser definido com valores negativos.<br/>            Somente leitura **float**. |
| [`default_tab_size`](/slides/python-net/pt/aspose.slides/iparagraphformateffectivedata/default_tab_size/) | Retorna o tamanho de tabulação padrão.<br/>            Somente leitura **float**. |
| [`tabs`](/slides/python-net/pt/aspose.slides/iparagraphformateffectivedata/tabs/) | Retorna as tabulações de um parágrafo.<br/>            Somente leitura [`ITabEffectiveData`](/slides/python-net/pt/aspose.slides/itabeffectivedata)[]. |
| [`font_alignment`](/slides/python-net/pt/aspose.slides/iparagraphformateffectivedata/font_alignment/) | Retorna o alinhamento da fonte em um parágrafo.<br/>            Somente leitura [`FontAlignment`](/slides/python-net/pt/aspose.slides/fontalignment). |
| [`default_portion_format`](/slides/python-net/pt/aspose.slides/iparagraphformateffectivedata/default_portion_format/) | Retorna o formato de porção padrão de um parágrafo.<br/>            Somente leitura [`IPortionFormatEffectiveData`](/slides/python-net/pt/aspose.slides/iportionformateffectivedata). |

### Observações

Esta interface é usada juntamente com a interface [`IParagraphFormat`](/slides/python-net/pt/aspose.slides/iparagraphformat) para retornar valores efetivos de formatação com herança aplicada.
