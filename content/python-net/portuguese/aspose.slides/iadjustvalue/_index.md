## IAdjustValue classe

Representa o valor de ajuste de uma forma geométrica.  
            Esses valores afetam a forma da forma.

O tipo IAdjustValue expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`raw_value`](/slides/python-net/pt/aspose.slides/iadjustvalue/raw_value/) | Retorna ou define o valor de ajuste "as is".<br/>Leitura/gravação **int**. |
| [`angle_value`](/slides/python-net/pt/aspose.slides/iadjustvalue/angle_value/) | Retorna ou define o valor, interpretando-o como ângulo em graus.<br/>Leitura/gravação **float**. |
| [`name`](/slides/python-net/pt/aspose.slides/iadjustvalue/name/) | Retorna um nome deste valor de ajuste.<br/>Somente-leitura **str**. |
| [`type`](/slides/python-net/pt/aspose.slides/iadjustvalue/type/) | Retorna o tipo do ajuste da forma.<br/>Somente-leitura [`ShapeAdjustmentType`](/slides/python-net/pt/aspose.slides/shapeadjustmenttype). |
