## Backdrop3DScene classe

Define um plano no qual efeitos, como brilho e sombra, são aplicados em relação à forma à qual eles são aplicados.

**Herança:**[`Backdrop3DScene`](/slides/python-net/pt/aspose.slides/backdrop3dscene) → [`PVIObject`](/slides/python-net/pt/aspose.slides/pviobject)

O tipo Backdrop3DScene expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`normal_vector`](/slides/python-net/pt/aspose.slides/backdrop3dscene/normal_vector/) | Retorna ou define um vetor normal. Para ser mais preciso, este atributo define um vetor<br/>            normal à face do plano de fundo. Vetor representado por um array de 3 valores float<br/>            que definem as coordenadas X, Y e Z.<br/>            Leitura/gravação **float**[]. |
| [`anchor_point`](/slides/python-net/pt/aspose.slides/backdrop3dscene/anchor_point/) | Retorna ou define um ponto no espaço 3D. Este ponto é o ponto no espaço que ancora o plano de fundo.<br/>            Ponto 3D representado por um array de 3 valores float que definem as coordenadas X, Y e Z.<br/>            Leitura/gravação **float**[]. |
| [`up_vector`](/slides/python-net/pt/aspose.slides/backdrop3dscene/up_vector/) | Retorna ou define um vetor que representa a direção up.
