## portion_format propriedade
Retorna um objeto de formatação que contém propriedades de formatação definidas explicitamente da porção de texto sem herança aplicada.
            Somente leitura [`IPortionFormat`](/slides/python-net/pt/aspose.slides/iportionformat).

### Observações

O objeto de formatação contém os parâmetros de formatação definidos apenas para a porção atual; dados herdados não são aplicados.

Para obter os valores efetivos incluindo os herdados, use o método [`PortionFormat.get_effective`](/slides/python-net/pt/aspose.slides/portionformat/get_effective).
