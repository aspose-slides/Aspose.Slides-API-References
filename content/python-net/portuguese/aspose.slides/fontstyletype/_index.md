## FontStyleType enumeração

Define estilos de formatação que podem ser aplicados ao texto.

O tipo FontStyleType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| REGULAR | Texto padrão. |
| BOLD | Texto em negrito. |
| ITALIC | Texto em itálico. |
| UNDERLINE | Texto sublinhado. |
| STRIKEOUT | Texto riscado com uma linha horizontal. |
