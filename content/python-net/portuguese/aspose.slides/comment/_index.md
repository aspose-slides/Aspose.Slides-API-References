## Comment classe

Representa um comentário em um slide.

O tipo Comment expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`text`](/slides/python-net/pt/aspose.slides/comment/text/) | Retorna ou define o texto simples de um comentário de slide.<br/>            Leitura/escrita **str**. |
| [`created_time`](/slides/python-net/pt/aspose.slides/comment/created_time/) | Retorna ou define o horário de criação de um comentário.<br/>            Definir esta propriedade como **System.DateTime** significa que nenhum horário de comentário está definido.<br/>            Leitura/escrita **System.DateTime**. |
| [`slide`](/slides/python-net/pt/aspose.slides/comment/slide/) | Retorna ou define o slide pai de um comentário.<br/>            Somente leitura [`ISlide`](/slides/python-net/pt/aspose.slides/islide). |
| [`author`](/slides/python-net/pt/aspose.slides/comment/author/) | Retorna o autor de um comentário.<br/>            Somente leitura [`ICommentAuthor`](/slides/python-net/pt/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/pt/aspose.slides/comment/position/) | Retorna ou define a posição de um comentário em um slide.<br/>            Leitura/escrita [`PointF`](/slides/python-net/pt/aspose.slides/pointf). |
| [`parent_comment`](/slides/python-net/pt/aspose.slides/comment/parent_comment/) | Retorna ou define o comentário pai.<br/>            Leitura/escrita [`IComment`](/slides/python-net/pt/aspose.slides/icomment). |

## Métodos

| Método | Descrição |
| :- | :- |
| [`remove(self)`](/slides/python-net/pt/aspose.slides/comment/remove/#) | Remove o comentário e todas as suas respostas da coleção pai. |
