## created_time propriedade
Retorna ou define o horário de criação de um comentário.
            Definir esta propriedade para **System.DateTime** significa que nenhum horário de comentário está definido.
            Leitura/gravação **System.DateTime**.


### Observações

O horário do comentário é um parâmetro opcional.
