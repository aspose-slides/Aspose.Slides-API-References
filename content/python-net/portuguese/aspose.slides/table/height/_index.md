## height propriedade
Gets or sets the height of the shape, measured in points.
            Leitura/Gravação **float**.

### Observações

O valor retornado está sempre definido e nunca **float**.
            O valor atribuído também deve ser definido; atribua **float** apenas às propriedades de uma instância `RawFrame`.
