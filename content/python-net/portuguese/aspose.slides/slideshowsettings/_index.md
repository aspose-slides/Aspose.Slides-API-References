## SlideShowSettings classe

Representa as configurações de exibição de slides da apresentação.

O tipo SlideShowSettings expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`slide_show_type`](/slides/python-net/pt/aspose.slides/slideshowsettings/slide_show_type/) | Obtém ou define o tipo de exibição de slides. Representado pelos seguintes [`SlideShowSettings.slide_show_type`](/slides/python-net/pt/aspose.slides/slideshowsettings/slide_show_type) ancestrais: [`BrowsedAtKiosk`](/slides/python-net/pt/aspose.slides/browsedatkiosk), [`PresentedBySpeaker`](/slides/python-net/pt/aspose.slides/presentedbyspeaker) e [`BrowsedByIndividual`](/slides/python-net/pt/aspose.slides/browsedbyindividual) |
| [`loop`](/slides/python-net/pt/aspose.slides/slideshowsettings/loop/) | Loop da exibição de slides |
| [`show_narration`](/slides/python-net/pt/aspose.slides/slideshowsettings/show_narration/) | Mostrar narração na exibição de slides |
| [`show_animation`](/slides/python-net/pt/aspose.slides/slideshowsettings/show_animation/) | Mostrar animação na exibição de slides |
| [`pen_color`](/slides/python-net/pt/aspose.slides/slideshowsettings/pen_color/) | Cor da caneta para a exibição de slides |
| [`slides`](/slides/python-net/pt/aspose.slides/slideshowsettings/slides/) | Intervalo de slides |
| [`use_timings`](/pt/slides/python-net/aspose.slides/slideshowsettings/use_timings/) | Usar temporizações na exibição de slides |
| [`show_media_controls`](/slides/python-net/pt/aspose.slides/slideshowsettings/show_media_controls/) | Mostrar controles de mídia |
