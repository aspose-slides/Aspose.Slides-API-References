## binary_data propriedade
Retorna a cópia dos dados de um áudio. Caso haja uma grande quantidade de dados, considere 
            usar o método [`Audio.get_stream`](/slides/python-net/pt/aspose.slides/audio/get_stream) para evitar o carregamento desnecessário  dos dados do áudio
            na memória ou até mesmo OutOfMemoryException.
            Somente leitura **int**[].
