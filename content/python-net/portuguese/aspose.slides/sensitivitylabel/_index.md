## SensitivityLabel classe

Representa o rótulo de sensibilidade do Microsoft Purview Information Protection.

O tipo SensitivityLabel expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`id`](/slides/python-net/pt/aspose.slides/sensitivitylabel/id/) | Retorna ou define o id do rótulo de sensibilidade.<br/>            Leitura/gravação **str**. |
| [`site_id`](/slides/python-net/pt/aspose.slides/sensitivitylabel/site_id/) | Retorna ou define o identificador do site do Azure Active Directory (Azure AD) <br/>            correspondente à política de rótulo de sensibilidade que descreve o rótulo de sensibilidade.<br/>            Leitura/gravação **System.Guid**. |
| [`is_enabled`](/slides/python-net/pt/aspose.slides/sensitivitylabel/is_enabled/) | Indica se o rótulo de sensibilidade está habilitado. |
| [`is_removed`](/slides/python-net/pt/aspose.slides/sensitivitylabel/is_removed/) | Indica se o rótulo de sensibilidade foi removido. |
| [`assignment_method_type`](/slides/python-net/pt/aspose.slides/sensitivitylabel/assignment_method_type/) | Retorna ou define o método de atribuição para o rótulo de sensibilidade.<br/>            Leitura/gravação [`SensitivityLabelAssignmentType`](/slides/python-net/pt/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/pt/aspose.slides/sensitivitylabel/content_mark_types/) | Retorna a lista de tipos de marcação de conteúdo que devem ser aplicados a um arquivo. |
