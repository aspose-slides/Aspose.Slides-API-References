## IBulletFormatEffectiveData classe

Objeto imutável que contém propriedades efetivas de formatação de marcadores de parágrafo.

O tipo IBulletFormatEffectiveData expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`type`](/slides/python-net/pt/aspose.slides/ibulletformateffectivedata/type/) | Retorna o tipo de marcador de um parágrafo.<br/>            Somente leitura [`BulletType`](/slides/python-net/pt/aspose.slides/bullettype). |
| [`char`](/slides/python-net/pt/aspose.slides/ibulletformateffectivedata/char/) | Retorna o caractere de marcador de um parágrafo.<br/>            Somente leitura **System.Char**. |
| [`actual_bullet_value`](/slides/python-net/pt/aspose.slides/ibulletformateffectivedata/actual_bullet_value/) | Retorna o valor real do marcador para o parágrafo pai.<br/>            Somente leitura **str**. |
| [`font`](/slides/python-net/pt/aspose.slides/ibulletformateffectivedata/font/) | Retorna a fonte do marcador de um parágrafo.<br/>            Somente leitura [`IFontData`](/slides/python-net/pt/aspose.slides/ifontdata). |
| [`height`](/slides/python-net/pt/aspose.slides/ibulletformateffectivedata/height/) | Retorna a altura do marcador de um parágrafo.<br/>            Somente leitura **float**. |
| [`numbered_bullet_start_with`](/slides/python-net/pt/aspose.slides/ibulletformateffectivedata/numbered_bullet_start_with/) | Retorna o primeiro número usado para o grupo de marcadores numerados.<br/>            Somente leitura **int**. |
| [`numbered_bullet_style`](/slides/python-net/pt/aspose.slides/ibulletformateffectivedata/numbered_bullet_style/) | Retorna o estilo de um marcador numerado.<br/>            Somente leitura [`NumberedBulletStyle`](/slides/python-net/pt/aspose.slides/numberedbulletstyle). |
| [`is_bullet_hard_color`](/slides/python-net/pt/aspose.slides/ibulletformateffectivedata/is_bullet_hard_color/) | Determina se o marcador tem cor própria ou herda da primeira parte do parágrafo.<br/>            Retorna **true**  se o marcador tem cor própria e **false**  se o marcador herda a cor da primeira parte do parágrafo.<br/>            Somente leitura **bool**. |
| [`is_bullet_hard_font`](/slides/python-net/pt/aspose.slides/ibulletformateffectivedata/is_bullet_hard_font/) | Determina se o marcador tem fonte própria ou herda da primeira parte do parágrafo.<br/>            Retorna **true**  se o marcador tem fonte própria e **true**  se o marcador herda a fonte da primeira parte do parágrafo.<br/>            Somente leitura **bool**. |
| [`picture`](/slides/python-net/pt/aspose.slides/ibulletformateffectivedata/picture/) | Retorna a imagem usada como marcador no parágrafo.<br/>            Somente leitura [`IPictureEffectiveData`](/slides/python-net/pt/aspose.slides/ipictureeffectivedata). |
| [`fill_format`](/slides/python-net/pt/aspose.slides/ibulletformateffectivedata/fill_format/) | Retorna o formato de preenchimento do marcador de um parágrafo.<br/>            Somente leitura [`IFillFormatEffectiveData`](/slides/python-net/pt/aspose.slides/ifillformateffectivedata). |

### Observações

Esta interface é usada como parte de [`IParagraphFormatEffectiveData`](/slides/python-net/pt/aspose.slides/iparagraphformateffectivedata).
