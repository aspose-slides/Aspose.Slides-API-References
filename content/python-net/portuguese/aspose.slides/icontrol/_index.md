## IControl classe

Representa um controle ActiveX.

O tipo IControl expõe os seguintes membros:

## Propriedades

| Property | Description |
| :- | :- |
| [`name`](/slides/python-net/pt/aspose.slides/icontrol/name/) | Retorna o nome deste controle.<br/>            Read/write **str**. |
| [`class_id`](/slides/python-net/pt/aspose.slides/icontrol/class_id/) | Obtém o id da classe deste controle.<br/>            Read-only **System.Guid**. |
| [`substitute_picture_format`](/slides/python-net/pt/aspose.slides/icontrol/substitute_picture_format/) | Retorna o objeto de propriedades de preenchimento de imagem do ControlEx.<br/>            Read-only [`IPictureFillFormat`](/slides/python-net/pt/aspose.slides/ipicturefillformat). |
| [`frame`](/slides/python-net/pt/aspose.slides/icontrol/frame/) | Retorna ou define a moldura do controle.<br/>            Read/write [`IShapeFrame`](/slides/python-net/pt/aspose.slides/ishapeframe). |
| [`properties`](/slides/python-net/pt/aspose.slides/icontrol/properties/) | Retorna uma coleção de propriedades ActiveX.<br/>            Read-only [`IControlPropertiesCollection`](/slides/python-net/pt/aspose.slides/icontrolpropertiescollection). |
| [`persistence`](/slides/python-net/pt/aspose.slides/icontrol/persistence/) | Obtém o método usado para armazenar propriedades do controle ActiveX.<br/>            Read only [`PersistenceType`](/slides/python-net/pt/aspose.slides/persistencetype). |
| [`active_x_control_binary`](/slides/python-net/pt/aspose.slides/icontrol/active_x_control_binary/) | Especifica a persistência de um controle ActiveX quando o método usado para persistir é PersistStream, PersistStreamInit ou PersistStorage. |
