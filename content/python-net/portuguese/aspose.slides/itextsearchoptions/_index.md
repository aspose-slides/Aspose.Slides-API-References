## ITextSearchOptions classe

Representa opções que podem ser usadas para pesquisar texto em uma Presentation, Slide ou TextFrame.

O tipo ITextSearchOptions expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`case_sensitive`](/slides/python-net/pt/aspose.slides/itextsearchoptions/case_sensitive/) | Defina true para usar pesquisa sensível a maiúsculas e minúsculas, false caso contrário.<br/>            Leitura/gravação **bool**. |
| [`whole_words_only`](/slides/python-net/pt/aspose.slides/itextsearchoptions/whole_words_only/) | Defina true para corresponder apenas palavras inteiras, false caso contrário.<br/>            Leitura/gravação **bool**. |
| [`include_notes`](/slides/python-net/pt/aspose.slides/itextsearchoptions/include_notes/) | Defina `true` para incluir texto contido nas notas de slides <br/>            ao realizar operações de pesquisa de texto, substituição ou realce.<br/>            O valor padrão é `false`. |
