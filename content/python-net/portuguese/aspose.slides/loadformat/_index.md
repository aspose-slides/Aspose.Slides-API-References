## Enumeração LoadFormat

Indica o formato do documento que será carregado.

O tipo LoadFormat expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| AUTO | Instrui o Aspose.Slides a reconhecer o formato automaticamente. |
| PPT | Apresentação Microsoft PowerPoint 97-2003. |
| PPS | Apresentação de Slides Microsoft PowerPoint 97-2003. |
| PPTX | Documento Microsoft Office Open XML PresentationML. |
| PPSX | Apresentação de Slides Microsoft Office Open XML PresentationML. |
| ODP | Apresentação OpenOffice ODF. |
| POTX | Modelo Microsoft Office Open XML PresentationML. |
| PPTM | Documento Microsoft Office Open XML PresentationML com macro. |
| PPSM | Apresentação de Slides Microsoft Office Open XML PresentationML com macro. |
| POTM | Modelo Microsoft Office Open XML PresentationML com macro. |
| OTP | Modelo de apresentação OpenOffice OTP. |
| PPT95 | Apresentação Microsoft PowerPoint 95. |
| POT | Modelo de apresentação Microsoft PowerPoint 97-2003. |
| FODP | Apresentação Flat XML ODF. |
| UNKNOWN | Formato de arquivo desconhecido |
