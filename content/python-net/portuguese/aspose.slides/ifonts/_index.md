## IFonts classe

Representa a coleção de fontes.

O tipo IFonts expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`latin_font`](/slides/python-net/pt/aspose.slides/ifonts/latin_font/) | Retorna ou define a fonte latina.<br/>            Leitura/gravação [`IFontData`](/slides/python-net/pt/aspose.slides/ifontdata). |
| [`east_asian_font`](/slides/python-net/pt/aspose.slides/ifonts/east_asian_font/) | Retorna ou define a fonte do Leste Asiático.<br/>            Leitura/gravação [`IFontData`](/slides/python-net/pt/aspose.slides/ifontdata). |
| [`complex_script_font`](/slides/python-net/pt/aspose.slides/ifonts/complex_script_font/) | Retorna ou define a fonte de script complexo.<br/>            Leitura/gravação [`IFontData`](/slides/python-net/pt/aspose.slides/ifontdata). |

## Métodos

| Método | Descrição |
| :- | :- |
| [`get_script_font_map(self)`](/slides/python-net/pt/aspose.slides/ifonts/get_script_font_map/#) | Retorna uma lista de todas as definições de fontes de script de pares string-string na apresentação. |
| [`get_script_font(self, script)`](/slides/python-net/pt/aspose.slides/ifonts/get_script_font/#str) | Obtém o nome da fonte associado a uma tag de script específica do tema da apresentação. |
| [`set_script_font(self, script, font_name)`](/slides/python-net/pt/aspose.slides/ifonts/set_script_font/#str-str) | Atribui um nome de fonte a uma tag de script específica, que define como o texto desse script será renderizado na apresentação. |
| [`remove_script_font(self, script)`](/slides/python-net/pt/aspose.slides/ifonts/remove_script_font/#str) | Remove a configuração de fonte associada a uma tag de script específica da coleção de fontes do tema. |
