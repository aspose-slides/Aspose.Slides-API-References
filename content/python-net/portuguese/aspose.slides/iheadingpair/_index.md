## IHeadingPair classe

Representa a propriedade 'Heading pair' do documento. 
            Indica o nome do grupo de partes do documento e o número de partes no grupo.

O tipo IHeadingPair expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`name`](/slides/python-net/pt/aspose.slides/iheadingpair/name/) | Retorna o nome do grupo de partes do documento.<br/>            Somente leitura **str**. |
| [`count`](/slides/python-net/pt/aspose.slides/iheadingpair/count/) | Retorna o número de partes no grupo.<br/>            Somente leitura **int**. |
