## fill_format propriedade
Retorna o objeto FillFormat que contém as propriedades de formatação de preenchimento para uma shape.
            Note: pode retornar None para certos tipos de shapes que não possuem propriedades de preenchimento.
            Somente leitura [`IFillFormat`](/slides/python-net/pt/aspose.slides/ifillformat).
