## insert_group_shape(self, index) {#int}
Cria um novo grupo de formas vazio e o insere na coleção de formas no índice especificado.
O quadro do grupo será ajustado automaticamente para acomodar quaisquer formas adicionadas a ele.

### Retorno

O [`IGroupShape`](/slides/python-net/pt/aspose.slides/igroupshape) recém-criado.

```python

    ...
```

| Parâmetro | Tipo | Descrição |
| :- | :- | :- |
| index | **int** | O índice baseado em zero no qual inserir o grupo de formas. |
