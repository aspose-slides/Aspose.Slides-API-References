## get_text_rect(self) {#}
Obtém o retângulo de texto definido pela geometria da forma pai.

### Retorna
Um [`RectangleF`](/slides/python-net/pt/aspose.slides/rectanglef) que define a área de texto.

```python
def get_text_rect(self):
    ...
```

### Observações
As coordenadas do retângulo são relativas ao canto superior esquerdo da forma pai.

### Exceções

| Exceção | Descrição |
| :- | :- |
| **RuntimeError(Proxy error(InvalidOperationException))** | A moldura de texto não está associada a uma forma geométrica. |
