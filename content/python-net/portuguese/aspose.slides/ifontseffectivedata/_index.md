## IFontsEffectiveData classe

Objeto imutável que contém o conjunto de fontes efetivas.

O tipo IFontsEffectiveData expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`latin_font`](/slides/python-net/pt/aspose.slides/ifontseffectivedata/latin_font/) | Retorna a fonte latina.<br/>            Somente leitura [`IFontData`](/slides/python-net/pt/aspose.slides/ifontdata). |
| [`east_asian_font`](/slides/python-net/pt/aspose.slides/ifontseffectivedata/east_asian_font/) | Retorna a fonte do Leste Asiático.<br/>            Somente leitura [`IFontData`](/slides/python-net/pt/aspose.slides/ifontdata). |
| [`complex_script_font`](/slides/python-net/pt/aspose.slides/ifontseffectivedata/complex_script_font/) | Retorna a fonte de script complexo.<br/>            Somente leitura [`IFontData`](/slides/python-net/pt/aspose.slides/ifontdata). |


### Observações

Esta interface é usada como parte das interfaces [`IBasePortionFormatEffectiveData`](/slides/python-net/pt/aspose.slides/ibaseportionformateffectivedata) e [`IFontSchemeEffectiveData`](/slides/python-net/pt/aspose.slides.theme/ifontschemeeffectivedata).
