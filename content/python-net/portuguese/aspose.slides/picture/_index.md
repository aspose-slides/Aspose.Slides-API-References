## Picture classe

Representa uma imagem em uma apresentação.

O tipo Picture expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`image`](/slides/python-net/pt/aspose.slides/picture/image/) | Retorna ou define a imagem incorporada.<br/>            Leitura/Gravação [`IPPImage`](/slides/python-net/pt/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/pt/aspose.slides/picture/link_path_long/) | Retorna ou define a URL da imagem vinculada.<br/>            Leitura/Gravação **str**. |
| [`image_transform`](/slides/python-net/pt/aspose.slides/picture/image_transform/) | Retorna a coleção de efeitos de transformação de imagem.<br/>            Somente leitura [`IImageTransformOperationCollection`](/slides/python-net/pt/aspose.slides.effects/iimagetransformoperationcollection). |
| [`presentation`](/slides/python-net/pt/aspose.slides/picture/presentation/) | Retorna a apresentação.<br/>            Somente leitura [`IPresentation`](/slides/python-net/pt/aspose.slides/ipresentation). |
| [`slide`](/slides/python-net/pt/aspose.slides/picture/slide/) | Retorna o slide pai de uma imagem.<br/>            Somente leitura [`IBaseSlide`](/slides/python-net/pt/aspose.slides/ibaseslide). |
