## IThreeDFormat classe

Representa propriedades 3-D.

O tipo IThreeDFormat expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`contour_width`](/slides/python-net/pt/aspose.slides/ithreedformat/contour_width/) | Retorna ou define a largura de um contorno 3D.<br/>            Leitura/Gravação **float**. |
| [`extrusion_height`](/slides/python-net/pt/aspose.slides/ithreedformat/extrusion_height/) | Retorna ou define a altura de um efeito de extrusão.<br/>            Leitura/Gravação **float**. |
| [`depth`](/slides/python-net/pt/aspose.slides/ithreedformat/depth/) | Retorna ou define a profundidade de uma forma 3D.<br/>            Leitura/Gravação **float**. |
| [`bevel_top`](/slides/python-net/pt/aspose.slides/ithreedformat/bevel_top/) | Retorna ou define o tipo de um chanfrado superior 3D.<br/>            Somente leitura [`IShapeBevel`](/slides/python-net/pt/aspose.slides/ishapebevel). |
| [`bevel_bottom`](/slides/python-net/pt/aspose.slides/ithreedformat/bevel_bottom/) | Retorna ou define o tipo de um chanfrado inferior 3D.<br/>            Somente leitura [`IShapeBevel`](/slides/python-net/pt/aspose.slides/ishapebevel). |
| [`contour_color`](/slides/python-net/pt/aspose.slides/ithreedformat/contour_color/) | Retorna ou define a cor de um contorno.<br/>            Somente leitura [`IColorFormat`](/slides/python-net/pt/aspose.slides/icolorformat). |
| [`extrusion_color`](/slides/python-net/pt/aspose.slides/ithreedformat/extrusion_color/) | Retorna ou define a cor de uma extrusão.<br/>            Somente leitura [`IColorFormat`](/slides/python-net/pt/aspose.slides/icolorformat). |
| [`camera`](/slides/python-net/pt/aspose.slides/ithreedformat/camera/) | Retorna ou define as configurações de uma câmera.<br/>            Somente leitura [`ICamera`](/slides/python-net/pt/aspose.slides/icamera). |
| [`light_rig`](/slides/python-net/pt/aspose.slides/ithreedformat/light_rig/) | Retorna ou define o tipo de uma luz.<br/>            Somente leitura [`ILightRig`](/slides/python-net/pt/aspose.slides/ilightrig). |
| [`material`](/slides/python-net/pt/aspose.slides/ithreedformat/material/) | Retorna ou define o tipo de um material.<br/>            Leitura/Gravação [`MaterialPresetType`](/slides/python-net/pt/aspose.slides/materialpresettype). |
