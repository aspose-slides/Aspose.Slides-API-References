## get_cells(self, formula, skip_hidden_cells) {#str-bool}
Recupera uma coleção de células da pasta de trabalho que correspondem à fórmula especificada.

### Retorna

Uma lista somente leitura de células que correspondem à fórmula especificada.



```python
def get_cells(self, formula, skip_hidden_cells):
    ...
```


| Parâmetro | Tipo | Descrição |
| :- | :- | :- |
| formula | **str** | Uma expressão de fórmula ou intervalo (por exemplo, "Sheet1!A1:B3") usada para identificar as células alvo. |
| skip_hidden_cells | **bool** | Se `true`, células ocultas (por exemplo, em linhas ou colunas ocultas) serão excluídas do resultado. |
