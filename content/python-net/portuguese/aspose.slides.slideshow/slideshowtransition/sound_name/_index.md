## sound_name propriedade
Especifica um nome legível por humanos para o som da transição. A [`SlideShowTransition.sound`](/slides/python-net/pt/aspose.slides.slideshow/slideshowtransition/sound) propriedade deve ser atribuída para obter ou definir o nome do som.
            Leitura-gravação **str**.


### Observações

Este nome aparece na interface do usuário do PowerPoint ao configurar o som da transição manualmente.
