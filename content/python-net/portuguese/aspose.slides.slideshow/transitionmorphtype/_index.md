## TransitionMorphType enumeração

Representa um tipo de transição morph.

O tipo TransitionMorphType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| BY_OBJECT | A transição morph será realizada considerando formas como objetos indivisíveis. |
| BY_WORD | A transição morph será realizada transferindo texto por palavras, quando possível. |
| BY_CHAR | A transição morph será realizada transferindo texto por caracteres, quando possível. |
