## IBehaviorCollection classe

Representa uma coleção de efeitos de comportamento.

O tipo IBehaviorCollection expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`count`](/slides/python-net/pt/aspose.slides.animation/ibehaviorcollection/count/) | Retorna o número de comportamentos em uma coleção.<br/>            Somente leitura **int**. |

Retorna um comportamento no índice especificado.
