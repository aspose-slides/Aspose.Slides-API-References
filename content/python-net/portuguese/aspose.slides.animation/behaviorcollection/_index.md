## BehaviorCollection classe

Representa a coleção de efeitos de comportamento.

O tipo BehaviorCollection expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`count`](/slides/python-net/pt/aspose.slides.animation/behaviorcollection/count/) | Retorna o número de comportamentos em uma coleção.<br/>            Somente leitura **int**. |
| [`is_read_only`](/slides/python-net/pt/aspose.slides.animation/behaviorcollection/is_read_only/) | Obtém um valor que indica se o **System.Collections.Generic.ICollection`1** é somente leitura.<br/>            Somente leitura **bool**. |

Retorna um comportamento no índice especificado.

## Indexador

| Nome | Descrição |
| :- | :- |
| [`[index]`](/slides/python-net/pt/aspose.slides.animation/behaviorcollection/__getitem__/) | Índice de um comportamento a ser retornado. |
