## Enumeração BuildType

Determina como o texto aparecerá em uma forma durante a animação.

O tipo BuildType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| AS_ONE_OBJECT | Com a forma contenedora. |
| ALL_PARAGRAPHS_AT_ONCE | Todos os parágrafos. |
| BY_LEVEL_PARAGRAPHS1 | Por grupos de parágrafos de profundidade 1. |
| BY_LEVEL_PARAGRAPHS2 | Por grupos de parágrafos de profundidade 2. |
| BY_LEVEL_PARAGRAPHS3 | Por grupos de parágrafos de profundidade 3. |
| BY_LEVEL_PARAGRAPHS4 | Por grupos de parágrafos de profundidade 4. |
| BY_LEVEL_PARAGRAPHS5 | Por grupos de parágrafos de profundidade 5. |
