## AnimateTextType enumeração

Representa o tipo de animação de texto de um efeito de animação.

O tipo AnimateTextType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |

| BY_WORD | Animar texto por palavra. |
| BY_LETTER | Animar texto por letra. |
