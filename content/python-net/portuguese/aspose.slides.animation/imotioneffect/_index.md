## IMotionEffect classe

Representa o comportamento do efeito de movimento.

O tipo IMotionEffect expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`from_address`](/slides/python-net/pt/aspose.slides.animation/imotioneffect/from_address/) | Especifica uma coordenada x/y para iniciar a animação (em porcentagem). <br/>            Leitura/gravação [`PointF`](/slides/python-net/pt/aspose.slides/pointf). |
| [`to`](/slides/python-net/pt/aspose.slides.animation/imotioneffect/to/) | Especifica o local de destino para um efeito de movimento de animação (em porcentagem).<br/>            Leitura/gravação [`PointF`](/slides/python-net/pt/aspose.slides/pointf). |
| [`by`](/slides/python-net/pt/aspose.slides.animation/imotioneffect/by/) | Descreve o valor de deslocamento relativo para a animação (em porcentagem).<br/>            Leitura/gravação [`PointF`](/slides/python-net/pt/aspose.slides/pointf). |
| [`rotation_center`](/slides/python-net/pt/aspose.slides.animation/imotioneffect/rotation_center/) | Descreve o centro da rotação usado para girar um caminho de movimento por ângulo X.<br/>            Leitura/gravação [`PointF`](/slides/python-net/pt/aspose.slides/pointf). |
| [`origin`](/slides/python-net/pt/aspose.slides.animation/imotioneffect/origin/) | Especifica a origem do caminho de movimento em relação a algo, como o layout do slide,<br/>            ou ao pai.<br/>            Leitura/gravação [`MotionOriginType`](/slides/python-net/pt/aspose.slides.animation/motionorigintype). |
| [`path`](/slides/python-net/pt/aspose.slides.animation/imotioneffect/path/) | Especifica a primitiva do caminho seguida por coordenadas para o movimento da animação.<br/>            Leitura/gravação [`IMotionPath`](/slides/python-net/pt/aspose.slides.animation/imotionpath). |
| [`path_edit_mode`](/slides/python-net/pt/aspose.slides.animation/imotioneffect/path_edit_mode/) | Especifica como o caminho de movimento se desloca quando a forma é movida.<br/>            Leitura/gravação [`MotionPathEditMode`](/slides/python-net/pt/aspose.slides.animation/motionpatheditmode). |
| [`angle`](/slides/python-net/pt/aspose.slides.animation/imotioneffect/angle/) | Descreve o ângulo relativo do caminho de movimento.<br/>            Leitura/gravação **float**. |
