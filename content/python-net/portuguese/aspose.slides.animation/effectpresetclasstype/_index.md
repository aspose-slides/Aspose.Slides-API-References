## EffectPresetClassType enumeração

Representa tipos de classes de efeito.

O tipo EffectPresetClassType expõe os seguintes membros:

| :- | :- |
| ENTRANCE | Classe de efeitos de entrada.<br/><br/><br/>Tipos de forma de destino: Todos |
| EXIT | Classe de efeitos de saída.<br/><br/><br/>Tipos de forma de destino: Todos |
| EMPHASIS | Classe de efeitos de ênfase.<br/><br/><br/>Tipos de forma de destino: Todos |
| PATH | Classe de caminhos de movimento.<br/><br/><br/>Tipos de forma de destino: Todos |
| MEDIA_CALL | Classe de efeitos de mídia.<br/><br/><br/>Tipos de forma de destino: [`IVideoFrame`](/slides/python-net/pt/aspose.slides/ivideoframe), [`IAudioFrame`](/slides/python-net/pt/aspose.slides/iaudioframe) |
