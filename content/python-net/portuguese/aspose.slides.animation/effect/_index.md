## classe Effect

Representa o efeito de animação.

O tipo Effect expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`sequence`](/slides/python-net/pt/aspose.slides.animation/effect/sequence/) | Retorna uma sequência para um efeito.<br/>            Somente leitura [`ISequence`](/slides/python-net/pt/aspose.slides.animation/isequence). |
| [`text_animation`](/slides/python-net/pt/aspose.slides.animation/effect/text_animation/) | TextAnimation<br/>            Somente leitura [`ITextAnimation`](/slides/python-net/pt/aspose.slides.animation/itextanimation). |
| [`preset_class_type`](/slides/python-net/pt/aspose.slides.animation/effect/preset_class_type/) | Define a classe do efeito.<br/>            Leitura/gravação [`EffectPresetClassType`](/slides/python-net/pt/aspose.slides.animation/effectpresetclasstype). |
| [`type`](/slides/python-net/pt/aspose.slides.animation/effect/type/) | Define o tipo do efeito.<br/>            Leitura/gravação [`EffectType`](/slides/python-net/pt/aspose.slides.animation/effecttype). |
| [`subtype`](/slides/python-net/pt/aspose.slides.animation/effect/subtype/) | Define o subtipo do efeito.<br/>            Leitura/gravação [`EffectSubtype`](/slides/python-net/pt/aspose.slides.animation/effectsubtype). |
| [`behaviors`](/slides/python-net/pt/aspose.slides.animation/effect/behaviors/) | Retorna a coleção de comportamentos para o efeito.<br/>            Leitura/gravação [`IBehaviorCollection`](/slides/python-net/pt/aspose.slides.animation/ibehaviorcollection). |
| [`timing`](/slides/python-net/pt/aspose.slides.animation/effect/timing/) | Define o valor de tempo para o efeito.<br/>            Leitura/gravação [`ITiming`](/slides/python-net/pt/aspose.slides.animation/itiming). |
| [`target_shape`](/slides/python-net/pt/aspose.slides.animation/effect/target_shape/) | Retorna a forma alvo para o efeito.<br/>            Somente leitura [`IShape`](/slides/python-net/pt/aspose.slides/ishape). |
| [`sound`](/slides/python-net/pt/aspose.slides.animation/effect/sound/) | Define som incorporado para o efeito.<br/>            Leitura/gravação [`IAudio`](/slides/python-net/pt/aspose.slides/iaudio). |
| [`stop_previous_sound`](/slides/python-net/pt/aspose.slides.animation/effect/stop_previous_sound/) | Este atributo especifica se o efeito de animação interrompe o som anterior.<br/>            Leitura/gravação **bool**. |
| [`after_animation_type`](/slides/python-net/pt/aspose.slides.animation/effect/after_animation_type/) | Define um tipo de animação posterior para o efeito.<br/>            Leitura/gravação [`Effect.after_animation_type`](/slides/python-net/pt/aspose.slides.animation/effect/after_animation_type). |
| [`after_animation_color`](/slides/python-net/pt/aspose.slides.animation/effect/after_animation_color/) | Define uma cor de animação posterior para o efeito.<br/>            Leitura/gravação [`IColorFormat`](/slides/python-net/pt/aspose.slides/icolorformat). |
| [`animate_text_type`](/slides/python-net/pt/aspose.slides.animation/effect/animate_text_type/) | Define um tipo de texto animado para o efeito. <br/>            O texto da forma pode ser animado por letra, por palavra ou tudo de uma vez.<br/>            Leitura/gravação [`Effect.animate_text_type`](/slides/python-net/pt/aspose.slides.animation/effect/animate_text_type). |
| [`delay_between_text_parts`](/slides/python-net/pt/aspose.slides.animation/effect/delay_between_text_parts/) | Define um atraso entre partes de texto animado (palavras ou letras).<br/>            Um valor positivo especifica a porcentagem da duração do efeito.<br/>            Um valor negativo especifica o atraso em segundos.<br/>            Leitura/gravação **float**. |
