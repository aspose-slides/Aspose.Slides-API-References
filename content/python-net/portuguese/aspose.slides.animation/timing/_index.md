## classe Timing

Representa o tempo da animação.

O tipo Timing expõe os seguintes membros:

## Propriedades

| Property | Description |
| :- | :- |
| [`accelerate`](/slides/python-net/pt/aspose.slides.animation/timing/accelerate/) | Descreve a porcentagem do efeito de aceleração da duração.<br/>            Leitura/gravação **float**. |
| [`decelerate`](/slides/python-net/pt/aspose.slides.animation/timing/decelerate/) | Descreve a porcentagem do efeito de desaceleração da duração.<br/>            Leitura/gravação **float**. |
| [`auto_reverse`](/slides/python-net/pt/aspose.slides.animation/timing/auto_reverse/) | Descreve se a animação deve ser reproduzida automaticamente em reverso após<br/>            reproduzi-la na direção normal.<br/>            Leitura/gravação **bool**. |
| [`duration`](/slides/python-net/pt/aspose.slides.animation/timing/duration/) | Descreve a duração do efeito de animação.<br/>            Leitura/gravação **float**. |
| [`repeat_count`](/slides/python-net/pt/aspose.slides.animation/timing/repeat_count/) | Descreve o número de vezes que o efeito deve ser repetido.<br/>            Leitura/gravação **float**. |
| [`repeat_until_end_slide`](/slides/python-net/pt/aspose.slides.animation/timing/repeat_until_end_slide/) | Este atributo especifica se o efeito será repetido até o final do slide.<br/>             Leitura/gravação **bool**. |
| [`repeat_until_next_click`](/slides/python-net/pt/aspose.slides.animation/timing/repeat_until_next_click/) | Este atributo especifica se o efeito será repetido até o próximo clique.<br/>             Leitura/gravação **bool**. |
| [`repeat_duration`](/slides/python-net/pt/aspose.slides.animation/timing/repeat_duration/) | Descreve o número de vezes que o efeito deve ser repetido.<br/>            Leitura/gravação **float**. |
| [`restart`](/slides/python-net/pt/aspose.slides.animation/timing/restart/) | Especifica se um efeito deve reiniciar após a conclusão.<br/>            Leitura/gravação [`EffectRestartType`](/slides/python-net/pt/aspose.slides.animation/effectrestarttype). |
| [`rewind`](/slides/python-net/pt/aspose.slides.animation/timing/rewind/) | Este atributo especifica se o efeito será rebobinado ao terminar a reprodução.<br/>             Leitura/gravação **bool**. |
| [`speed`](/slides/python-net/pt/aspose.slides.animation/timing/speed/) | Especifica a porcentagem pela qual acelerar (ou desacelerar) o tempo.<br/>            Leitura/gravação **float**. |
| [`trigger_delay_time`](/slides/python-net/pt/aspose.slides.animation/timing/trigger_delay_time/) | Descreve o tempo de atraso após o acionamento.<br/>            Leitura/gravação **float**. |
| [`trigger_type`](/slides/python-net/pt/aspose.slides.animation/timing/trigger_type/) | Descreve o tipo de acionamento.<br/>            Leitura/gravação [`EffectTriggerType`](/slides/python-net/pt/aspose.slides.animation/effecttriggertype). |
