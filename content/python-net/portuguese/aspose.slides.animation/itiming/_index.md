## ITiming classe

Representa o tempo da animação.

O tipo ITiming expõe os seguintes membros:

## Propriedades

| Propriedade | Descrição |
| :- | :- |
| [`accelerate`](/slides/python-net/pt/aspose.slides.animation/itiming/accelerate/) | Descreve a porcentagem do efeito de aceleração da duração.<br/>Leitura/gravação **float**. |
| [`decelerate`](/slides/python-net/pt/aspose.slides.animation/itiming/decelerate/) | Descreve a porcentagem do efeito de desaceleração da duração.<br/>Leitura/gravação **float**. |
| [`auto_reverse`](/slides/python-net/pt/aspose.slides.animation/itiming/auto_reverse/) | Descreve se a animação deve ser reproduzida automaticamente em reverso após<br/>ser reproduzida na direção normal.<br/>Leitura/gravação **bool**. |
| [`duration`](/slides/python-net/pt/aspose.slides.animation/itiming/duration/) | Descreve a duração do efeito de animação.<br/>Leitura/gravação **float**. |
| [`repeat_count`](/slides/python-net/pt/aspose.slides.animation/itiming/repeat_count/) | Descreve o número de vezes que o efeito deve se repetir.<br/>Leitura/gravação **float**. |
| [`repeat_until_end_slide`](/slides/python-net/pt/aspose.slides.animation/itiming/repeat_until_end_slide/) | Este atributo especifica se o efeito será repetido até o final do slide.<br/>Leitura/gravação **bool**. |
| [`repeat_until_next_click`](/slides/python-net/pt/aspose.slides.animation/itiming/repeat_until_next_click/) | Este atributo especifica se o efeito será repetido até o próximo clique.<br/>Leitura/gravação **bool**. |
| [`repeat_duration`](/slides/python-net/pt/aspose.slides.animation/itiming/repeat_duration/) | Descreve o número de vezes que o efeito deve se repetir.<br/>Leitura/gravação **float**. |
| [`restart`](/slides/python-net/pt/aspose.slides.animation/itiming/restart/) | Especifica se um efeito deve reiniciar após a conclusão.<br/>Leitura/gravação [`EffectRestartType`](/slides/python-net/pt/aspose.slides.animation/effectrestarttype). |
| [`speed`](/slides/python-net/pt/aspose.slides.animation/itiming/speed/) | Especifica a porcentagem pela qual acelerar (ou desacelerar) o tempo.<br/>Leitura/gravação **float**. |
| [`trigger_delay_time`](/slides/python-net/pt/aspose.slides.animation/itiming/trigger_delay_time/) | Descreve o tempo de atraso após o gatilho.<br/>Leitura/gravação **float**. |
| [`trigger_type`](/slides/python-net/pt/aspose.slides.animation/itiming/trigger_type/) | Descreve o tipo de gatilho.<br/>Leitura/gravação [`EffectTriggerType`](/slides/python-net/pt/aspose.slides.animation/effecttriggertype). |
| [`rewind`](/slides/python-net/pt/aspose.slides.animation/itiming/rewind/) | Este atributo especifica se o efeito será rebobinado ao terminar a reprodução.<br/>Leitura/gravação **bool**. |
