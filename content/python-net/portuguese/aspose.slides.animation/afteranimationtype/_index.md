## AfterAnimationType enumeração

Representa o tipo de animação posterior de um efeito de animação.

O tipo AfterAnimationType expõe os seguintes membros:

## Campos

| Campo | Descrição |
| :- | :- |
| DO_NOT_DIM | Não escurecer após o tipo de animação. |
| COLOR | Cor após o tipo de animação. |
| HIDE_AFTER_ANIMATION | Ocultar após o tipo de animação |
| HIDE_ON_NEXT_MOUSE_CLICK | Ocultar ao próximo clique do mouse após o tipo de animação. |
