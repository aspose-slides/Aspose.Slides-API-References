## IVbaProject classe

Representa um projeto VBA com macros de apresentação.

O tipo IVbaProject expõe os seguintes membros:

## Propriedades

| Property | Description |
| :- | :- |
| [`name`](/slides/python-net/pt/aspose.slides.vba/ivbaproject/name/) | Retorna o nome do projeto VBA.<br/>            Somente leitura **str**. |
| [`modules`](/slides/python-net/pt/aspose.slides.vba/ivbaproject/modules/) | Retorna a lista de todos os módulos que estão contidos no projeto VBA.<br/>            Somente leitura [`IVbaModuleCollection`](/slides/python-net/pt/aspose.slides.vba/ivbamodulecollection). |
| [`references`](/slides/python-net/pt/aspose.slides.vba/ivbaproject/references/) | Retorna a lista de todas as referências que estão contidas no projeto VBA.<br/>            Somente leitura [`IVbaReferenceCollection`](/slides/python-net/pt/aspose.slides.vba/ivbareferencecollection). |
| [`is_password_protected`](/slides/python-net/pt/aspose.slides.vba/ivbaproject/is_password_protected/) | Indica se o VBAProject está protegido por senha para visualizar as propriedades do projeto.<br/>            Somente leitura **bool**. |
