## IChartTextFormat Klasse

Diagramme arbeiten mit einem eingeschränkten Satz von Textformat-Eigenschaften.
            IChartTextFormat, IChartTextBlockFormat, IChartParagraphFormat, IChartPortionFormat
            Schnittstellen beschreiben dieses eingeschränkte Set.

Der Typ IChartTextFormat stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Property | Description |
| :- | :- |
| [`text_block_format`](/slides/python-net/de/aspose.slides.charts/icharttextformat/text_block_format/) | Gibt das Format für die Diagramm-Text-Elemente zurück.<br/>Schreibgeschützt [`IChartTextBlockFormat`](/slides/python-net/de/aspose.slides.charts/icharttextblockformat). |
| [`paragraph_format`](/slides/python-net/de/aspose.slides.charts/icharttextformat/paragraph_format/) | Gibt das Absatzformat zurück.<br/>Schreibgeschützt [`IChartParagraphFormat`](/slides/python-net/de/aspose.slides.charts/ichartparagraphformat). |
| [`portion_format`](/slides/python-net/de/aspose.slides.charts/icharttextformat/portion_format/) | Gibt das Portionformat zurück.<br/>Schreibgeschützt [`IChartPortionFormat`](/slides/python-net/de/aspose.slides.charts/ichartportionformat). |
