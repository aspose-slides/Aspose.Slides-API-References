## is_number_format_linked_to_source Eigenschaft
Lesen/Schreiben **bool**.

### Hinweise

Wenn das übergeordnete Element dieses DataLabelFormat-Objekts eine DataLabelCollection-Sammlung von Datenbeschriftungen ist, dann ruft diese Eigenschaft den Standardwert der IsNumberFormatLinkedToSource-Eigenschaft für die neuen Datenbeschriftungen in der DataLabelCollection-Sammlung ab oder legt ihn fest. Das Setzen dieser Eigenschaft mit einem Wert setzt diesen Wert auch für die IsNumberFormatLinkedToSource-Eigenschaft aller Datenbeschriftungen in der DataLabelCollection-Sammlung (z. B. "DataLabels.DefaultDataLabelFormat.IsNumberFormatLinkedToSource = val;" bewirkt, dass alle DataLabels[i].IsNumberFormatLinkedToSource gleich val sind).
