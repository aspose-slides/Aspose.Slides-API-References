## Format-Eigenschaft
Stellt das Format der Datenbeschriftung dar.
Nur lesbar [`IFormat`](/slides/python-net/de/aspose.slides.charts/iformat).

### Anmerkungen

Wenn das übergeordnete Objekt dieses DataLabelFormat-Objekts eine DataLabelCollection-Sammlung von Datenbeschriftungen ist, dann repräsentiert diese Eigenschaft das Standardformat für die neuen Datenbeschriftungen in der DataLabelCollection-Sammlung.
