## IChartParagraphFormat Klasse

Stellt die Absatzformatierungseigenschaften eines Diagramms dar.

Der IChartParagraphFormat Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`alignment`](/slides/python-net/de/aspose.slides.charts/ichartparagraphformat/alignment/) | Gibt die Textausrichtung in einem Absatz zurück oder legt sie fest.<br/>            Lesen/Schreiben [`TextAlignment`](/slides/python-net/de/aspose.slides/textalignment). |
| [`space_within`](/slides/python-net/de/aspose.slides.charts/ichartparagraphformat/space_within/) | Gibt den Abstand zwischen Grundlinien in einem Absatz zurück oder legt ihn fest.<br/>            Lesen/Schreiben **float**. |
| [`space_before`](/slides/python-net/de/aspose.slides.charts/ichartparagraphformat/space_before/) | Gibt den Abstand vor der ersten Zeile in einem Absatz zurück oder legt ihn fest.<br/>            Lesen/Schreiben **float**. |
| [`space_after`](/slides/python-net/de/aspose.slides.charts/ichartparagraphformat/space_after/) | Gibt den Abstand nach der letzten Zeile in einem Absatz zurück oder legt ihn fest.<br/>            Lesen/Schreiben **float**. |
| [`east_asian_line_break`](/slides/python-net/de/aspose.slides.charts/ichartparagraphformat/east_asian_line_break/) | Bestimmt, ob der ostasiatische Zeilenumbruch in einem Absatz verwendet wird.<br/>            Lesen/Schreiben [`NullableBool`](/slides/python-net/de/aspose.slides/nullablebool). |
| [`right_to_left`](/slides/python-net/de/aspose.slides.charts/ichartparagraphformat/right_to_left/) | Bestimmt, ob das Schreiben von rechts nach links in einem Absatz verwendet wird.<br/>            Lesen/Schreiben [`NullableBool`](/slides/python-net/de/aspose.slides/nullablebool). |
| [`latin_line_break`](/slides/python-net/de/aspose.slides.charts/ichartparagraphformat/latin_line_break/) | Bestimmt, ob der lateinische Zeilenumbruch in einem Absatz verwendet wird.<br/>            Lesen/Schreiben [`NullableBool`](/slides/python-net/de/aspose.slides/nullablebool). |
| [`hanging_punctuation`](/slides/python-net/de/aspose.slides.charts/ichartparagraphformat/hanging_punctuation/) | Bestimmt, ob hängende Interpunktion in einem Absatz verwendet wird.<br/>            Lesen/Schreiben [`NullableBool`](/slides/python-net/de/aspose.slides/nullablebool). |
| [`margin_left`](/slides/python-net/de/aspose.slides.charts/ichartparagraphformat/margin_left/) | Gibt den linken Rand in einem Absatz zurück oder legt ihn fest.<br/>            Lesen/Schreiben **float**. |
| [`margin_right`](/slides/python-net/de/aspose.slides.charts/ichartparagraphformat/margin_right/) | Gibt den rechten Rand in einem Absatz zurück oder legt ihn fest.<br/>            Lesen/Schreiben **float**. |
| [`indent`](/slides/python-net/de/aspose.slides.charts/ichartparagraphformat/indent/) | Gibt den ersten Zeileneinzug/Hängenden Einzug des Absatzes zurück oder legt ihn fest. Der hängende Einzug kann mit negativen Werten definiert werden.<br/>            Lesen/Schreiben **float**. |
| [`default_tab_size`](/slides/python-net/de/aspose.slides.charts/ichartparagraphformat/default_tab_size/) | Gibt die Standardtabulationsgröße zurück oder legt sie fest.<br/>            Lesen/Schreiben **float**. |
| [`tabs`](/slides/python-net/de/aspose.slides.charts/ichartparagraphformat/tabs/) | Gibt die Tabulatoren eines Absatzes zurück.<br/>            Nur-Lesen [`ITabCollection`](/slides/python-net/de/aspose.slides/itabcollection). |
| [`font_alignment`](/slides/python-net/de/aspose.slides.charts/ichartparagraphformat/font_alignment/) | Gibt die Schriftausrichtung in einem Absatz zurück oder legt sie fest.<br/>            Lesen/Schreiben [`FontAlignment`](/slides/python-net/de/aspose.slides/fontalignment). |
