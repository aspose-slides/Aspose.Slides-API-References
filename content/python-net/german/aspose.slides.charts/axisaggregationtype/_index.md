## AxisAggregationType Aufzählung

Stellt den Aggregationstyp der Kategorienachse dar. Wird nur mit Histogramm- oder HistogramPareto-Serien verwendet.

Der AxisAggregationType-Typ stellt die folgenden Member bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| BY_CATEGORY | Nach Kategorien aggregieren |
| AUTOMATIC | Kategorien automatisch aggregieren. |
| BY_BIN_WIDTH | Kategorien nach Bin-Breite aggregieren. Property IAxis.BinWidth muss gesetzt werden. |
| BY_NUMBER_OF_BINS | Kategorien nach Anzahl der Bins aggregieren. Property IAxis.NumberOfBins muss gesetzt werden. |
