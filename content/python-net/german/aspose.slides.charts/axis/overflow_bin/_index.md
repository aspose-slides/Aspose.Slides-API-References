## overflow_bin Eigenschaft
Gibt an, dass ein benutzerdefinierter Wert für das Overflow Bin verwendet wird. Wird angewendet, wenn die Eigenschaft IsAutomaticOverflowBin auf false gesetzt ist und die Eigenschaft IsOverflowBin den Wert true hat.
