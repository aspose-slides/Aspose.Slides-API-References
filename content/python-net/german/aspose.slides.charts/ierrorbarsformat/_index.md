## IErrorBarsFormat Klasse

Stellt Fehlermarken einer Diagrammreihe dar. ErrorBars benutzerdefinierte Werte befinden sich in IChartDataPointCollection (in [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/de/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) Eigenschaft).

Der Typ IErrorBarsFormat stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`type`](/slides/python-net/de/aspose.slides.charts/ierrorbarsformat/type/) | Liest oder setzt den Typ von Fehlermarken. <br/>            Lesen/Schreiben [`ErrorBarType`](/slides/python-net/de/aspose.slides.charts/errorbartype). |
| [`value_type`](/slides/python-net/de/aspose.slides.charts/ierrorbarsformat/value_type/) | Stellt mögliche Wege zur Bestimmung der Länge der Fehlermarken dar. <br/>            Im Falle eines benutzerdefinierten Wertetyps, um den Wert anzugeben, verwenden Sie die [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/de/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) Eigenschaft des spezifischen Datenpunkts in der DataPoints Sammlung der Reihe.  <br/>            Lesen/Schreiben [`ErrorBarValueType`](/slides/python-net/de/aspose.slides.charts/errorbarvaluetype). |
| [`has_end_cap`](/slides/python-net/de/aspose.slides.charts/ierrorbarsformat/has_end_cap/) | Gibt an, dass kein Endkap auf den Fehlermarken gezeichnet wird.<br/>            Lesen/Schreiben **bool**. |
| [`value`](/slides/python-net/de/aspose.slides.charts/ierrorbarsformat/value/) | Liest oder setzt den Wert, der mit den Wertetypen Fixed, Percentage und StandardDeviation verwendet wird, um die Länge der Fehlermarken zu bestimmen. <br/>            Lesen/Schreiben **float**. |
| [`format`](/slides/python-net/de/aspose.slides.charts/ierrorbarsformat/format/) | Stellt das Format der Fehlermarken dar.<br/>            Lesen/Schreiben [`IFormat`](/slides/python-net/de/aspose.slides.charts/iformat). |
| [`is_visible`](/slides/python-net/de/aspose.slides.charts/ierrorbarsformat/is_visible/) | Liest oder setzt die Sichtbarkeit der Fehlermarken.<br/>            Lesen/Schreiben **bool**. |
