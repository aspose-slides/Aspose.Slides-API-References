## ErrorBarType Aufzählung

Stellt den Typ des Fehlerbalkens dar

Der Typ ErrorBarType stellt die folgenden Mitglieder bereit:

## Felder

| Field | Description |
| :- | :- |
| BOTH | Gibt an, dass Fehlerbalken sowohl in der positiven als auch in der negativen Richtung angezeigt werden. |
| MINUS | Gibt an, dass Fehlerbalken nur in der negativen Richtung angezeigt werden. |
| PLUS | Gibt an, dass Fehlerbalken nur in der positiven Richtung angezeigt werden. |
