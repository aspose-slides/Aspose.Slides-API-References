## default_label_shape_type Eigenschaft
Liest oder setzt den Standard-Shape-Typ für Datenbeschriftungen.
             Gibt [`ShapeType.NOT_DEFINED`](/slides/python-net/de/aspose.slides/shapetype/NOT_DEFINED) zurück, wenn keine Form definiert ist.

### Hinweise
Das Festlegen dieser Eigenschaft setzt auch die [`IDataLabel.label_shape_type`](/slides/python-net/de/aspose.slides.charts/idatalabel/label_shape_type) Eigenschaft
             für alle Datenbeschriftungen in der Sammlung auf denselben Wert.
