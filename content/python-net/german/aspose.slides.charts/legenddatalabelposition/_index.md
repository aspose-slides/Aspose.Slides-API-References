## LegendDataLabelPosition Aufzählung

Bestimmt die Position der Datenbeschriftungen.

Der Typ LegendDataLabelPosition stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| NOT_DEFINED | Position ist nicht definiert. |
| BOTTOM | Gibt an, dass Datenbeschriftungen unter dem Datenmarker angezeigt werden sollen. |
| BEST_FIT | Gibt an, dass Datenbeschriftungen in der besten Position angezeigt werden sollen. |
| CENTER | Gibt an, dass Datenbeschriftungen zentriert am Datenmarker angezeigt werden sollen. |
| INSIDE_BASE | Gibt an, dass Datenbeschriftungen innerhalb der Basis des Datenmarkers angezeigt werden sollen. |
| INSIDE_END | Gibt an, dass Datenbeschriftungen innerhalb des Endes des Datenmarkers angezeigt werden sollen. |
| LEFT | Gibt an, dass Datenbeschriftungen links vom Datenmarker angezeigt werden sollen. |
| OUTSIDE_END | Gibt an, dass Datenbeschriftungen außerhalb des Endes des Datenmarkers angezeigt werden sollen. |
| RIGHT | Gibt an, dass Datenbeschriftungen rechts vom Datenmarker angezeigt werden sollen. |
| TOP | Gibt an, dass Datenbeschriftungen über dem Datenmarker angezeigt werden sollen. |
