## is_chart_type_line(chart_type) {#charttype}
Gibt true zurück, wenn chartType einer der Line-Untertypen ist.
            Die Menge der Untertypen entspricht der entsprechenden Menge in PowerPoint (siehe den Dialog „Change Chart Type“ in PowerPoint):
            [`ChartType.LINE`](/slides/python-net/de/aspose.slides.charts/charttype/LINE),
            [`ChartType.LINE_WITH_MARKERS`](/slides/python-net/de/aspose.slides.charts/charttype/LINE_WITH_MARKERS),
            [`ChartType.PERCENTS_STACKED_LINE`](/slides/python-net/de/aspose.slides.charts/charttype/PERCENTS_STACKED_LINE),
            [`ChartType.PERCENTS_STACKED_LINE_WITH_MARKERS`](/slides/python-net/de/aspose.slides.charts/charttype/PERCENTS_STACKED_LINE_WITH_MARKERS),
            [`ChartType.STACKED_LINE`](/slides/python-net/de/aspose.slides.charts/charttype/STACKED_LINE),
            [`ChartType.STACKED_LINE_WITH_MARKERS`](/slides/python-net/de/aspose.slides.charts/charttype/STACKED_LINE_WITH_MARKERS),
            [`ChartType.LINE_3D`](/slides/python-net/de/aspose.slides.charts/charttype/LINE_3D).
