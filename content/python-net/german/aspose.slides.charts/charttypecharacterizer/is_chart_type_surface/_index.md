## is_chart_type_surface(chart_type) {#charttype}
Gibt true zurück, wenn chartType einer der Surface-Untersorten ist.
            Die Menge der Untersorten entspricht der entsprechenden Menge in PowerPoint (siehe "Change Chart Type" dialog in PowerPoint):
            [`ChartType.SURFACE_3D`](/slides/python-net/de/aspose.slides.charts/charttype/SURFACE_3D),
            [`ChartType.WIREFRAME_SURFACE_3D`](/slides/python-net/de/aspose.slides.charts/charttype/WIREFRAME_SURFACE_3D),
            [`ChartType.CONTOUR`](/slides/python-net/de/aspose.slides.charts/charttype/CONTOUR),
            [`ChartType.WIREFRAME_CONTOUR`](/slides/python-net/de/aspose.slides.charts/charttype/WIREFRAME_CONTOUR).
