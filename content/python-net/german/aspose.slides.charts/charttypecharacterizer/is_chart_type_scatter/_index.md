## is_chart_type_scatter(chart_type) {#charttype}
Gibt true zurück, wenn chartType einer der Scatter Untertypen ist.
            Die Menge der Untertypen entspricht der entsprechenden Menge in PowerPoint (siehe "Change Chart Type" dialog in PowerPoint):
            [`ChartType.SCATTER_WITH_MARKERS`](/slides/python-net/de/aspose.slides.charts/charttype/SCATTER_WITH_MARKERS),
            [`ChartType.SCATTER_WITH_SMOOTH_LINES`](/slides/python-net/de/aspose.slides.charts/charttype/SCATTER_WITH_SMOOTH_LINES),
            [`ChartType.SCATTER_WITH_SMOOTH_LINES_AND_MARKERS`](/slides/python-net/de/aspose.slides.charts/charttype/SCATTER_WITH_SMOOTH_LINES_AND_MARKERS),
            [`ChartType.SCATTER_WITH_STRAIGHT_LINES`](/slides/python-net/de/aspose.slides.charts/charttype/SCATTER_WITH_STRAIGHT_LINES),
            [`ChartType.SCATTER_WITH_STRAIGHT_LINES_AND_MARKERS`](/slides/python-net/de/aspose.slides.charts/charttype/SCATTER_WITH_STRAIGHT_LINES_AND_MARKERS).
