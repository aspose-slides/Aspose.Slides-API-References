## TimeUnitType-Aufzählung

Stellt die Basiseinheit für die Kategorieachse dar

Der Typ TimeUnitType stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| NONE | Werte werden unverändert angezeigt. |
| DAYS | Gibt an, dass die Diagrammdaten in Tagen angezeigt werden. |
| MONTHS | Gibt an, dass die Diagrammdaten in Monaten angezeigt werden. |
| YEARS | Gibt an, dass die Diagrammdaten in Jahren angezeigt werden. |
