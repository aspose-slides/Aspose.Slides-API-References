## WorkbookType Aufzählung

Gibt den Typ einer Open XML-Arbeitsmappendatei an.

Der WorkbookType-Typ stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| NOT_DEFINED | Der Arbeitsmappertyp ist nicht definiert. |
| WORKBOOK | Excel-Arbeitsmappe (*.xlsx). |
| WORKBOOK_MACRO | Excel-Makro-unterstützte Arbeitsmappe (*.xlsm). |
| TEMPLATE | Excel-Vorlage (*.xltx). |
| TEMPLATE_MACRO | Excel-Makro-unterstützte Vorlage (*.xltm). |
| WORKBOOK_BINARY_MACRO | Excel-Binär-Arbeitsmappe mit Makros (*.xlsb). |
