## number_of_bins Eigenschaft
Gibt die Anzahl der Behälter an, wenn der Wert der AggregationType-Eigenschaft auf AxisAggregationType.ByNumberOfBins gesetzt ist.
            Wird auf Kategorienachsen angewendet. Wird nur mit Histogram oder HistogramPareto-Serien verwendet.
