## PieSplitType Aufzählung

Stellt einen Typ von Trennpunkten im zweiten Kuchen oder Balken in einem Kuchen-aus-Kuchen- oder Balken-aus-Kuchen-Diagramm dar.

Der PieSplitType-Typ stellt die folgenden Member bereit:

## Felder

| Field | Beschreibung |
| :- | :- |
| DEFAULT | Gibt an, dass die Datenpunkte mit dem Standard <br/> Mechanismus für diesen Diagrammtyp aufgeteilt werden sollen. |
| CUSTOM | Gibt an, dass die Datenpunkte zwischen dem <br/> Kuchen und dem zweiten Diagramm gemäß den benutzerdefinierten Split-Werten aufgeteilt werden sollen. |
| BY_PERCENTAGE | Gibt an, dass die Datenpunkte zwischen dem Kuchen und dem <br/> zweiten Diagramm aufgeteilt werden, indem Punkte mit einem Prozentsatz kleiner als <br/> den Split-Position-Prozentwert im zweiten Diagramm platziert werden. |
| BY_POS | Gibt an, dass die Datenpunkte zwischen dem Kuchen und dem <br/> zweiten Diagramm aufgeteilt werden, indem die letzte Split-Position der Datenpunkte <br/> im zweiten Diagramm platziert wird. |
| BY_VALUE | Gibt an, dass die Datenpunkte zwischen dem Kuchen und dem <br/> zweiten Diagramm aufgeteilt werden, indem Datenpunkte mit einem Wert kleiner als <br/> die Split-Position im zweiten Diagramm platziert werden. |
