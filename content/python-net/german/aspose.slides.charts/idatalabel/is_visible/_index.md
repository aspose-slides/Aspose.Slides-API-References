## is_visible Eigenschaft
False means that data label is not visible (and so all Show*-flags (ShowValue, ...) are false).
            Nur lesbar **bool**.

### Hinweise

Wenn das Datenlabel sichtbar ist, können Sie es mit der Methode Hide() ausblenden.
            Aber wenn das Datenlabel nicht sichtbar ist (IsVisible ist false), können Sie das Datenlabel sichtbar machen 
            mit dem Setzen der Show*-flags (ShowValue, ...) auf true.
