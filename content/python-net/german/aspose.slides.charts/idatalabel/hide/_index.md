## hide(self) {#}
Macht das Datenbeschriftungs-Label unsichtbar, indem alle Show*-Flags (ShowValue, ...) auf false gesetzt werden.
            IsVisible wird danach false sein.


```python
def hide(self):
    ...
```


### Hinweise

Wenn das Datenbeschriftungs-Label nicht sichtbar ist (IsVisible ist false), können Sie das Label sichtbar machen, indem Sie die
            Show*-Flags (ShowValue, ...) auf true setzen.
