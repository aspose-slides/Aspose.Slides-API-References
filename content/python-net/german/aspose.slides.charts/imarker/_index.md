## IMarker Klasse

Stellt einen Marker eines Diagramms dar.

Der Typ IMarker stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Property | Description |
| :- | :- |
| [`symbol`](/slides/python-net/de/aspose.slides.charts/imarker/symbol/) | Stellt den Marker-Stil in einem Liniendiagramm, Punktdiagramm oder Radar-Diagramm dar.<br/>            Lesen/Schreiben [`MarkerStyleType`](/slides/python-net/de/aspose.slides.charts/markerstyletype). |
| [`format`](/slides/python-net/de/aspose.slides.charts/imarker/format/) | Ruft die Füllung des Markers ab.<br/>            Nur-Lesen [`IFormat`](/slides/python-net/de/aspose.slides.charts/iformat). |
| [`size`](/slides/python-net/de/aspose.slides.charts/imarker/size/) | Stellt die Marker-Größe in einem Liniendiagramm, Punktdiagramm oder Radar-Diagramm dar.<br/>            Lesen/Schreiben **int**. |
