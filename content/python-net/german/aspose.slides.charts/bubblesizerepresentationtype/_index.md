## BubbleSizeRepresentationType Aufzählung

Gibt die möglichen Wege an, Daten als Bubble-Diagrammgrößen darzustellen.

Der Typ BubbleSizeRepresentationType stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| AREA | Gibt an, dass die Fläche der Blasen proportional zum Bubble-Größenwert ist. |
| WIDTH | Gibt an, dass der Radius der Blasen proportional zum Bubble-Größenwert ist. |
