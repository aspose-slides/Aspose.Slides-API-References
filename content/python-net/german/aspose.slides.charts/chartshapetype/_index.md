## ChartShapeType Aufzählung

Stellt eine Diagrammform dar.

Der Typ ChartShapeType stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| NOT_DEFINED | Diagrammform ist nicht definiert. |
| BOX | Gibt an, dass das Diagramm mit einer Boxform gezeichnet wird. |
| CONE | Gibt an, dass das Diagramm als Kegel gezeichnet wird, wobei die Basis des Kegels auf dem Boden liegt und die Spitze des Kegels am oberen Datenpunkt ist. |
| CONE_TO_MAX | Gibt an, dass das Diagramm mit abgeschnittenen Kegeln gezeichnet wird, sodass die Spitze des Kegels dem maximalen Datenwert entspricht. |
| CYLINDER | Gibt an, dass das Diagramm als Zylinder gezeichnet wird. |
| PYRAMID | Gibt an, dass das Diagramm als rechteckige Pyramide gezeichnet wird, wobei die Basis der Pyramide auf dem Boden liegt und die Spitze der Pyramide am oberen Datenpunkt ist. |
| PYRAMID_TO_MAXIMUM | Gibt an, dass das Diagramm mit abgeschnittenen Kegeln gezeichnet wird, sodass die Spitze des Kegels dem maximalen Datenwert entspricht. |
