## is_visible Eigenschaft
False means that data label is not visible (and so all Show*-flags (ShowValue, ...) are false).
            Nur lesbar **bool**.


### Anmerkungen

Wenn das Datenbeschriftungsfeld sichtbar ist, können Sie es mit der Hide()-Methode ausblenden.
            Aber wenn das Datenbeschriftungsfeld nicht sichtbar ist (IsVisible ist false), können Sie das Datenbeschriftungsfeld sichtbar machen, indem Sie die Show*-Flags (ShowValue, ...) auf den wahren Zustand setzen.
