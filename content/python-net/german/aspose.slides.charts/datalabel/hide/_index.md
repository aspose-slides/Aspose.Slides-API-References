## hide(self) {#}
Mache die Datenbeschriftung unsichtbar, indem du alle Show*-Flags (ShowValue, ...) auf den falschen Zustand setzt.
            IsVisible wird danach false sein.

```python
def hide(self):
    ...
```

### Hinweise

Wenn die Datenbeschriftung nicht sichtbar ist (IsVisible ist false), kannst du die Datenbeschriftung sichtbar machen, indem du die Show*-Flags (ShowValue, ...) auf den wahren Zustand setzt.
