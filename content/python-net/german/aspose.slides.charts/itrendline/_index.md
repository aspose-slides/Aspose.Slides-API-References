## ITrendline Klasse

Klasse stellt die Trendlinie einer Diagrammserie dar

Der ITrendline-Typ stellt die folgenden Member bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`trendline_name`](/slides/python-net/de/aspose.slides.charts/itrendline/trendline_name/) | Liest oder setzt den Namen der Trendlinie.<br/>            Lesen/Schreiben **str**. |
| [`trendline_type`](/slides/python-net/de/aspose.slides.charts/itrendline/trendline_type/) | Liest oder setzt den Typ der Trendlinie.<br/>            Lesen/Schreiben [`ITrendline.trendline_type`](/slides/python-net/de/aspose.slides.charts/itrendline/trendline_type). |
| [`format`](/slides/python-net/de/aspose.slides.charts/itrendline/format/) | Stellt das Format der Trendlinie dar.<br/>            Lesen/Schreiben [`IFormat`](/slides/python-net/de/aspose.slides.charts/iformat). |
| [`backward`](/slides/python-net/de/aspose.slides.charts/itrendline/backward/) | Gibt die Anzahl der Kategorien (oder Einheiten in einem Streudiagramm) an, um die die Trendlinie vor<br/>            den Daten der Serie, die getrendet wird, erweitert wird. In Streu- und Nicht-Streu-Diagrammen darf der Wert beliebig nicht-negativ sein.<br/>            Lesen/Schreiben **float**. |
| [`forward`](/slides/python-net/de/aspose.slides.charts/itrendline/forward/) | Gibt die Anzahl der Kategorien (oder Einheiten in einem Streudiagramm) an, um die die Trendlinie nach<br/>            den Daten der Serie, die getrendet wird, erweitert wird. In Streu- und Nicht-Streu-Diagrammen darf der Wert beliebig nicht-negativ sein.<br/>            Lesen/Schreiben **float**. |
| [`intercept`](/slides/python-net/de/aspose.slides.charts/itrendline/intercept/) | Gibt den Wert an, an dem die Trendlinie die y-Achse schneidet. Diese Eigenschaft wird nur unterstützt,<br/>            wenn der Trendlinientyp exp, linear oder poly ist.<br/>            Lesen/Schreiben **float**. |
| [`display_equation`](/slides/python-net/de/aspose.slides.charts/itrendline/display_equation/) | Gibt an, dass die Gleichung der Trendlinie im Diagramm angezeigt wird (im selben Beschriftungsfeld wie der Rsquaredvalue).<br/>            Lesen/Schreiben **bool**. |
| [`order`](/slides/python-net/de/aspose.slides.charts/itrendline/order/) | Gibt die Ordnung der Polynomialtrendlinie an. Sie wird für andere Trendlinientypen ignoriert. Der Wert muss zwischen 2 und 6 liegen.<br/>            Lesen/Schreiben **int**. |
| [`period`](/slides/python-net/de/aspose.slides.charts/itrendline/period/) | Gibt den Zeitraum der Trendlinie für eine gleitende Durchschnittrtrendlinie an. Sie wird für andere Trend-<br/>            linienvarianten ignoriert. Der Wert muss zwischen 2 und 255 liegen.<br/>            Lesen/Schreiben **int**. |
| [`display_r_squared_value`](/slides/python-net/de/aspose.slides.charts/itrendline/display_r_squared_value/) | Gibt an, dass der R-quadratische Wert der Trendlinie im Diagramm angezeigt wird (im selben Beschriftungsfeld wie die Gleichung).<br/>            Lesen/Schreiben **bool**. |
| [`related_legend_entry`](/slides/python-net/de/aspose.slides.charts/itrendline/related_legend_entry/) | Stellt den Legendeeintrag dar, der mit dieser Trendlinie verbunden ist<br/>            Nur-Lesen [`ILegendEntryProperties`](/slides/python-net/de/aspose.slides.charts/ilegendentryproperties). |
