## ErrorBarValueType Aufzählung

Stellt den Typ des Fehlerbalkenwerts dar

Der Typ ErrorBarValueType stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| CUSTOM | Gibt an, dass die Länge der Fehlerbalken durch die Plus- und Minus-Elemente bestimmt wird. |
| FIXED | Gibt an, dass die Länge der Fehlerbalken der feste Wert ist, der durch Error Bar Value bestimmt wird. |
| PERCENTAGE | Gibt an, dass die Länge der Fehlerbalken Error Bar Value Prozent der Daten beträgt. |
| STANDARD_DEVIATION | Gibt an, dass die Länge der Fehlerbalken Error Bar Value Standardabweichungen der Daten beträgt. |
| STANDARD_ERROR | Gibt an, dass die Länge der Fehlerbalken Error Bar Value Standardfehler der Daten beträgt. |
