## IFormat Klasse

Stellt Eigenschaften des Diagrammformats dar.

Der IFormat-Typ stellt die folgenden Member bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`fill`](/slides/python-net/de/aspose.slides.charts/iformat/fill/) | Gibt die Füllstil-Eigenschaften eines Diagramms zurück.<br/>            Nur lesbar [`IFillFormat`](/slides/python-net/de/aspose.slides/ifillformat). |
| [`line`](/slides/python-net/de/aspose.slides.charts/iformat/line/) | Gibt die Linienstil-Eigenschaften eines Diagramms zurück.<br/>            Nur lesbar [`ILineFormat`](/slides/python-net/de/aspose.slides/ilineformat). |
| [`effect`](/slides/python-net/de/aspose.slides.charts/iformat/effect/) | Gibt die für ein Diagramm verwendeten Effekte zurück.<br/>            Nur lesbar [`IEffectFormat`](/slides/python-net/de/aspose.slides/ieffectformat). |
| [`effect_3d`](/slides/python-net/de/aspose.slides.charts/iformat/effect_3d/) | Gibt das 3D-Format eines Diagramms zurück.<br/>            Nur lesbar [`IThreeDFormat`](/slides/python-net/de/aspose.slides/ithreedformat). |
