## IActualLayout Klasse

Gibt die tatsächliche Position eines Diagrammelements an.

Der IActualLayout-Typ enthält die folgenden Mitglieder:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`actual_x`](/slides/python-net/de/aspose.slides.charts/iactuallayout/actual_x/) | Gibt die tatsächliche x-Position (links) des Diagrammelements relativ zur linken oberen Ecke des Diagramms an.<br/>            Rufen Sie die Methode IChart.ValidateChartLayout() auf, bevor Sie die tatsächlichen Werte erhalten. <br/>            Lesen **float**. |
| [`actual_y`](/slides/python-net/de/aspose.slides.charts/iactuallayout/actual_y/) | Gibt den tatsächlichen oberen Rand des Diagrammelements relativ zur linken oberen Ecke des Diagramms an.<br/>            Rufen Sie die Methode IChart.ValidateChartLayout() auf, bevor Sie die tatsächlichen Werte erhalten. <br/>            Lesen **float**. |
| [`actual_width`](/slides/python-net/de/aspose.slides.charts/iactuallayout/actual_width/) | Gibt die tatsächliche Breite des Diagrammelements an. Rufen Sie die Methode IChart.ValidateChartLayout() auf, bevor Sie die tatsächlichen Werte erhalten. <br/>            Lesen **float**. |
| [`actual_height`](/slides/python-net/de/aspose.slides.charts/iactuallayout/actual_height/) | Gibt die tatsächliche Höhe des Diagrammelements an. Rufen Sie die Methode IChart.ValidateChartLayout() auf, bevor Sie die tatsächlichen Werte erhalten. <br/>            Lesen **float**. |
