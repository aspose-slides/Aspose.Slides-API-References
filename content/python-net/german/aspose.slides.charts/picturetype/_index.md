## PictureType Aufzählung

Bestimmt den Modus der Bildfüllung für Balken.

Der Typ PictureType stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| NOT_DEFINED | Nicht definiert. |
| STACK | Das Bild wird so skaliert, dass es maximal 15-mal im längsten gestapelten Balken wiederholt wird. |
| STACK_SCALE | Das Bild wird auf eine angegebene Anzahl von Einheiten skaliert und über die Länge des Balkens wiederholt. |
| STRETCH | Das Bild wird über die gesamte Länge des gestapelten Balkens gestreckt. |
