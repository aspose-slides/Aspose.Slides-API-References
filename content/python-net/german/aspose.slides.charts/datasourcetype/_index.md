## DataSourceType Aufzählung

Datenquellentypen.

Der Typ DataSourceType stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| WORKSHEET | Verwenden Sie CellXls-Objekte zum Speichern von XValue, YValue, Value oder BubbleSize des Datenpunkts im Arbeitsblatt. |
| STRING_LITERALS | Verwenden Sie eine schnellzugreifbare Zeichenkettenvariable zum Speichern von XValue, YValue, Value oder BubbleSize des <br/>            Datenpunkts. Arbeitsblatt wird NICHT zum Speichern von Werten verwendet. |
| DOUBLE_LITERALS | Verwenden Sie eine schnellzugreifbare double-Variable zum Speichern von XValue, YValue, Value oder BubbleSize des <br/>            Datenpunkts. Arbeitsblatt wird NICHT zum Speichern von Werten verwendet. |
