## Marker Klasse

Stellt den Marker eines Kieselsteins dar.

Der Typ Marker stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`symbol`](/slides/python-net/de/aspose.slides.charts/marker/symbol/) | Stellt den Marker-Stil in einem Liniendiagramm, Punktdiagramm oder Radardiagramm dar.<br/>            Lese/Schreiben [`MarkerStyleType`](/slides/python-net/de/aspose.slides.charts/markerstyletype). |
| [`format`](/slides/python-net/de/aspose.slides.charts/marker/format/) | Liest oder setzt die Marker-Füllung.<br/>            Nur lesbar [`IFormat`](/slides/python-net/de/aspose.slides.charts/iformat). |
| [`size`](/slides/python-net/de/aspose.slides.charts/marker/size/) | Stellt die Marker-Größe in einem Liniendiagramm, Punktdiagramm oder Radardiagramm dar.<br/>            Lese/Schreiben **int**. |
