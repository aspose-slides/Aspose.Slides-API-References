## LegendPositionType Aufzählung

Bestimmt die Position der Legende in einem Diagramm.

Der Typ LegendPositionType stellt die folgenden Member bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| BOTTOM | Gibt an, dass die Legende unten im Diagramm gezeichnet wird. |
| LEFT | Gibt an, dass die Legende links im Diagramm gezeichnet wird. |
| RIGHT | Gibt an, dass die Legende rechts im Diagramm gezeichnet wird. |
| TOP | Gibt an, dass die Legende oben im Diagramm gezeichnet wird. |
| TOP_RIGHT | Gibt an, dass die Legende oben rechts im Diagramm gezeichnet wird. |
