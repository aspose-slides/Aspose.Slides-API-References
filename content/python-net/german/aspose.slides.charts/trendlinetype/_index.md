## TrendlineType Aufzählung

Stellt den Typ einer Trendlinie dar

Der Typ TrendlineType stellt die folgenden Member bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| EXPONENTIAL | Gibt an, dass die Trendlinie eine exponentielle Kurve in der Form sein soll. |
| LINEAR | Gibt an, dass die Trendlinie eine Linie in der Form sein soll. |
| LOGARITHMIC | Gibt an, dass die Trendlinie eine logarithmische Kurve in der Form ist, wobei log der natürliche Logarithmus ist. |
| MOVING_AVERAGE | Gibt an, dass die Trendlinie ein gleitender Durchschnitt der Periode Period ist. |
| POLYNOMIAL | Gibt an, dass die Trendlinie eine Polynomkurve der Ordnung Order in der Form ist. |
| POWER | Gibt an, dass die Trendlinie eine Potenzkurve in der Form sein soll. |
