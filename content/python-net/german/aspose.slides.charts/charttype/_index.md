## ChartType Aufzählung

Stellt einen Diagrammtyp dar.

Der Typ ChartType stellt die folgenden Member bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| CLUSTERED_COLUMN | Stellt ein gruppiertes Säulendiagramm dar. |
| STACKED_COLUMN | Stellt ein gestapeltes Säulendiagramm dar. |
| PERCENTS_STACKED_COLUMN | Stellt ein 100-% gestapeltes Säulendiagramm dar. |
| CLUSTERED_COLUMN_3D | Stellt ein 3D gruppiertes Säulendiagramm dar. |
| STACKED_COLUMN_3D | Stellt ein 3D gestapeltes Säulendiagramm dar. |
| PERCENTS_STACKED_COLUMN_3D | Stellt ein 3D 100-% gestapeltes Säulendiagramm dar. |
| COLUMN_3D | Stellt ein 3D Säulendiagramm dar. |
| CLUSTERED_CYLINDER | Stellt ein Zylinderdiagramm dar. |
| STACKED_CYLINDER | Stellt ein gestapeltes Zylinderdiagramm dar. |
| PERCENTS_STACKED_CYLINDER | Stellt ein 100-% gestapeltes Zylinderdiagramm dar. |
| CYLINDER_3D | Stellt ein 3D zylindrisches Säulendiagramm dar. |
| CLUSTERED_CONE | Stellt ein Kegeldiagramm dar. |
| STACKED_CONE | Stellt ein gestapeltes Kegeldiagramm dar. |
| PERCENTS_STACKED_CONE | Stellt ein 100-% gestapeltes Kegeldiagramm dar. |
| CONE_3D | Stellt ein 3D konisches Säulendiagramm dar. |
| CLUSTERED_PYRAMID | Stellt ein Pyramidendiagramm dar. |
| STACKED_PYRAMID | Stellt ein gestapeltes Pyramidendiagramm dar. |
| PERCENTS_STACKED_PYRAMID | Stellt ein 100-% gestapeltes Pyramidendiagramm dar. |
| PYRAMID_3D | Stellt ein 3D Pyramiden-Säulendiagramm dar. |
| LINE | Stellt ein Liniendiagramm dar. |
| STACKED_LINE | Stellt ein gestapeltes Liniendiagramm dar. |
| PERCENTS_STACKED_LINE | Stellt ein 100-% gestapeltes Liniendiagramm dar. |
| LINE_WITH_MARKERS | Stellt ein Liniendiagramm mit Datenmarkierungen dar. |
| STACKED_LINE_WITH_MARKERS | Stellt ein gestapeltes Liniendiagramm mit Datenmarkierungen dar. |
| PERCENTS_STACKED_LINE_WITH_MARKERS | Stellt ein 100-% gestapeltes Liniendiagramm mit Datenmarkierungen dar. |
| LINE_3D | Stellt ein 3D Liniendiagramm dar. |
| PIE | Stellt ein Kreisdiagramm dar. |
| PIE_3D | Stellt ein 3D Kreisdiagramm dar. |

| EXPLODED_PIE | Stellt ein aufgespaltenes Kreisdiagramm dar. |
| EXPLODED_PIE_3D | Stellt ein 3D aufgespaltenes Kreisdiagramm dar. |
| BAR_OF_PIE | Stellt ein Balken-im-Kreis-Diagramm dar. |
| PERCENTS_STACKED_BAR | Stellt ein 100-% gestapeltes Balkendiagramm dar. |
| CLUSTERED_BAR_3D | Stellt ein 3D gruppiertes Balkendiagramm dar. |
| CLUSTERED_BAR | Stellt ein gruppiertes Balkendiagramm dar. |
| STACKED_BAR | Stellt ein gestapeltes Balkendiagramm dar. |
| STACKED_BAR_3D | Stellt ein 3D gestapeltes Balkendiagramm dar. |
| PERCENTS_STACKED_BAR_3D | Stellt ein 3D 100-% gestapeltes Balkendiagramm dar. |
| CLUSTERED_HORIZONTAL_CYLINDER | Stellt ein zylindrisches Balkendiagramm dar. |
| STACKED_HORIZONTAL_CYLINDER | Stellt ein gestapeltes zylindrisches Balkendiagramm dar. |
| PERCENTS_STACKED_HORIZONTAL_CYLINDER | Stellt ein 100-% gestapeltes zylindrisches Balkendiagramm dar. |
| CLUSTERED_HORIZONTAL_CONE | Stellt ein konisches Balkendiagramm dar. |
| STACKED_HORIZONTAL_CONE | Stellt ein gestapeltes konisches Balkendiagramm dar. |

| CLUSTERED_HORIZONTAL_PYRAMID | Stellt ein pyramidenförmiges Balkendiagramm dar. |
| STACKED_HORIZONTAL_PYRAMID | Stellt ein gestapeltes pyramidenförmiges Balkendiagramm dar. |
| PERCENTS_STACKED_HORIZONTAL_PYRAMID | Stellt ein 100-% gestapeltes pyramidenförmiges Balkendiagramm dar. |
| AREA | Stellt ein Flächendiagramm dar. |

| PERCENTS_STACKED_AREA | Stellt ein 100-% gestapeltes Flächendiagramm dar. |

| STACKED_AREA_3D | Stellt ein 3D gestapeltes Flächendiagramm dar. |

| SCATTER_WITH_STRAIGHT_LINES_AND_MARKERS | Stellt ein Streudiagramm mit geraden Linien und Datenmarkierungen dar. |

| VOLUME_HIGH_LOW_CLOSE | Stellt ein Volumen-Hoch-Tief-Schluss-Aktienchart dar. |
| VOLUME_OPEN_HIGH_LOW_CLOSE | Stellt ein Volumen-Öffnen-Hoch-Tief-Schluss-Aktienchart dar. |
| SURFACE_3D | Stellt ein 3D Oberflächendiagramm dar. |
| WIREFRAME_SURFACE_3D | Stellt ein 3D Drahtgitter-Oberflächendiagramm dar. |
| CONTOUR | Stellt ein Konturdiagramm dar. |
| WIREFRAME_CONTOUR | Stellt ein Drahtgitter-Konturdiagramm dar. |
| DOUGHNUT | Stellt ein Donut-Diagramm dar. |
| EXPLODED_DOUGHNUT | Stellt ein aufgespaltenes Donut-Diagramm dar. |
| BUBBLE | Stellt ein Blasendiagramm dar. |

| RADAR | Stellt ein Radar-Diagramm dar. |

| TREEMAP | Stellt ein Treemap-Diagramm dar. |
| SUNBURST | Stellt ein Sunburst-Diagramm dar. |
| HISTOGRAM | Stellt ein Histogramm-Diagramm dar. |
