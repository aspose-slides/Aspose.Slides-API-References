## format Eigenschaft
Stellt das Format der Datenbeschriftung dar.
            Nur lesbar [`IFormat`](/slides/python-net/de/aspose.slides.charts/iformat).

### Anmerkungen

Wenn der übergeordnete Knoten dieses DataLabelFormat-Objekts eine DataLabelCollection-Sammlung von Datenbeschriftungen ist, dann diese
            Eigenschaft das Standardformat für die neuen Datenbeschriftungen in der DataLabelCollection-Sammlung darstellt.
