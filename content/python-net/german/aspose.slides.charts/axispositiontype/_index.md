## AxisPositionType Aufzählung

Bestimmt eine Position der Achse.

Der Typ AxisPositionType stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| BOTTOM | Gibt an, dass die Achse am unteren Rand des Zeichenbereichs angezeigt werden soll. |
| LEFT | Gibt an, dass die Achse am linken Rand des Zeichenbereichs angezeigt werden soll. |
| RIGHT | Gibt an, dass die Achse am rechten Rand des Zeichenbereichs angezeigt werden soll. |
| TOP | Gibt an, dass die Achse am oberen Rand des Zeichenbereichs angezeigt werden soll. |
