## TickMarkType Aufzählung

Stellt den TickMarkType-Typ für die angegebene Achse dar.

Der Typ TickMarkType stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| CROSS | Legt fest, dass die Tick-Markierungen die Achse kreuzen. |
| INSIDE | Legt fest, dass die Tick-Markierungen innerhalb des Diagrammbereichs liegen. |
| NONE | Legt fest, dass keine Tick-Markierungen vorhanden sind. |
| OUTSIDE | Legt fest, dass die Tick-Markierungen außerhalb des Diagrammbereichs liegen. |
