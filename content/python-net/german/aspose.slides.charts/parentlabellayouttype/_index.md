## ParentLabelLayoutType Aufzählung

Stellt das Layout von Kategoriedatenbeschriftungen dar. Wird nur mit Treemap-Serien verwendet.

Der Typ ParentLabelLayoutType stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| BANNER | Gibt an, dass übergeordnete Kategoriebeschriftungen als Banner angezeigt werden |
| NONE | Gibt an, dass übergeordnete Kategoriebeschriftungen nicht gezeichnet werden |
| OVERLAPPING | Gibt an, dass übergeordnete Kategoriebeschriftungen überlappend angezeigt werden |
