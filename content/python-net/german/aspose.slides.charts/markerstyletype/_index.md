## MarkerStyleType Aufzählung

Bestimmt die Form des Markers am Datenpunkt des Diagramms.

Der Typ MarkerStyleType stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| NOT_DEFINED |  |
| CIRCLE | Gibt an, dass an jedem Datenpunkt ein Kreis gezeichnet wird. |
| DASH | Gibt an, dass an jedem Datenpunkt ein Strich gezeichnet wird. |
| DIAMOND | Gibt an, dass an jedem Datenpunkt ein Diamant gezeichnet wird. |
| DOT | Gibt an, dass an jedem Datenpunkt ein Punkt gezeichnet wird. |
| NONE | Gibt an, dass an jedem Datenpunkt nichts gezeichnet wird. |
| PICTURE | Gibt an, dass an jedem Datenpunkt ein Bild gezeichnet wird. |
| PLUS | Gibt an, dass an jedem Datenpunkt ein Pluszeichen gezeichnet wird. |
| SQUARE | Gibt an, dass an jedem Datenpunkt ein Quadrat gezeichnet wird. |
| STAR | Gibt an, dass an jedem Datenpunkt ein Stern gezeichnet wird. |
| TRIANGLE | Gibt an, dass an jedem Datenpunkt ein Dreieck gezeichnet wird. |
| X | Gibt an, dass an jedem Datenpunkt ein X gezeichnet wird. |
