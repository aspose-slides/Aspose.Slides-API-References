## hide(self) {#}
Machen Sie die Datenbeschriftung standardmäßig unsichtbar, indem Sie alle Show*-Flags (ShowValue, ...) der 
            DefaultDataLabelFormat Eigenschaft auf den Zustand false setzen.
IsVisible wird nach diesem Vorgang false sein.

```python
def hide(self):
    ...
```

### Bemerkungen

Wenn die Datenbeschriftung standardmäßig nicht sichtbar ist (IsVisible ist false), können Sie die Datenbeschriftung "standardmäßig sichtbar" 
            mit dem Setzen der Show*-Flags (ShowValue, ...) der 
            DefaultDataLabelFormat Eigenschaft auf den Zustand true machen.
