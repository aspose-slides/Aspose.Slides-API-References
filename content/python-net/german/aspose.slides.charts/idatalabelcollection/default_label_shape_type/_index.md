## default_label_shape_type Eigenschaft
Ruft den Standardformtyp für Datenbeschriftungen ab oder legt ihn fest.
             Gibt [`ShapeType.NOT_DEFINED`](/slides/python-net/de/aspose.slides/shapetype/NOT_DEFINED) zurück, wenn keine Form definiert ist.


### Hinweise

Durch das Festlegen dieser Eigenschaft wird auch die [`IDataLabel.label_shape_type`](/slides/python-net/de/aspose.slides.charts/idatalabel/label_shape_type)-Eigenschaft
             für alle Datenbeschriftungen in der Sammlung auf denselben Wert gesetzt.
