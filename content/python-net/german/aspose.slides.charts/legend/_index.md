## Legend-Klasse

Stellt die Eigenschaften der Legende eines Diagramms dar.

Der Typ Legend stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`x`](/slides/python-net/de/aspose.slides.charts/legend/x/) | Gibt die x-Koordinate einer Legende zurück oder setzt sie als Bruchteil der Breite des Diagramms.<br/>            Lesen/Schreiben **float**. |
| [`y`](/slides/python-net/de/aspose.slides.charts/legend/y/) | Gibt die y-Koordinate einer Legende zurück oder setzt sie als Bruchteil der Höhe des Diagramms.<br/>            Lesen/Schreiben **float**. |
| [`width`](/slides/python-net/de/aspose.slides.charts/legend/width/) | Gibt die Breite einer Legende zurück oder setzt sie als Bruchteil der Breite des Diagramms.<br/>            Lesen/Schreiben **float**. |
| [`height`](/slides/python-net/de/aspose.slides.charts/legend/height/) | Gibt die Höhe einer Legende zurück oder setzt sie als Bruchteil der Höhe des Diagramms.<br/>            Lesen/Schreiben **float**. |
| [`right`](/slides/python-net/de/aspose.slides.charts/legend/right/) | Rechts.<br/>            Nur-Lesen **float**. |
| [`bottom`](/slides/python-net/de/aspose.slides.charts/legend/bottom/) | Unten.<br/>            Nur-Lesen **float**. |
| [`overlay`](/slides/python-net/de/aspose.slides.charts/legend/overlay/) | Bestimmt, ob andere Diagrammelemente die Legende überlappen dürfen.<br/>            Lesen/Schreiben **bool**. |
| [`text_format`](/slides/python-net/de/aspose.slides.charts/legend/text_format/) | Textformat.<br/>            Nur-Lesen [`IChartTextFormat`](/slides/python-net/de/aspose.slides.charts/icharttextformat). |
| [`position`](/slides/python-net/de/aspose.slides.charts/legend/position/) | Gibt die Position der Legende in einem Diagramm an.<br/>            Nicht-NaN-Werte von X, Y, Width, Heigt-Eigenschaften überschreiben die Wirkung dieser Eigenschaft.<br/>            Lesen/Schreiben [`LegendPositionType`](/slides/python-net/de/aspose.slides.charts/legendpositiontype). |
| [`format`](/slides/python-net/de/aspose.slides.charts/legend/format/) | Gibt das Format einer Legende zurück.<br/>            Nur-Lesen [`IFormat`](/slides/python-net/de/aspose.slides.charts/iformat). |
| [`chart`](/slides/python-net/de/aspose.slides.charts/legend/chart/) | Gibt das Diagramm zurück.<br/>            Nur-Lesen [`IChart`](/slides/python-net/de/aspose.slides.charts/ichart). |
| [`entries`](/slides/python-net/de/aspose.slides.charts/legend/entries/) | Liefert Legendeinträge.<br/>            Nur-Lesen [`ILegendEntryCollection`](/slides/python-net/de/aspose.slides.charts/ilegendentrycollection). |
| [`actual_x`](/slides/python-net/de/aspose.slides.charts/legend/actual_x/) | Gibt die tatsächliche x-Position (links) des Diagrammelements relativ zur linken oberen Ecke des Diagramms an.<br/>            Rufen Sie die Methode IChart.ValidateChartLayout() auf, bevor Sie die tatsächlichen Werte erhalten. <br/>            Lesen **float**. |
| [`actual_y`](/slides/python-net/de/aspose.slides.charts/legend/actual_y/) | Gibt die tatsächliche obere Position des Diagrammelements relativ zur linken oberen Ecke des Diagramms an.<br/>            Rufen Sie die Methode IChart.ValidateChartLayout() auf, bevor Sie die tatsächlichen Werte erhalten. <br/>            Lesen **float**. |
| [`actual_width`](/slides/python-net/de/aspose.slides.charts/legend/actual_width/) | Gibt die tatsächliche Breite des Diagrammelements an. Rufen Sie die Methode IChart.ValidateChartLayout() auf, bevor Sie die tatsächlichen Werte erhalten. <br/>            Lesen **float**. |
| [`actual_height`](/slides/python-net/de/aspose.slides.charts/legend/actual_height/) | Gibt die tatsächliche Höhe des Diagrammelements an. Rufen Sie die Methode IChart.ValidateChartLayout() auf, bevor Sie die tatsächlichen Werte erhalten. <br/>            Lesen **float**. |
