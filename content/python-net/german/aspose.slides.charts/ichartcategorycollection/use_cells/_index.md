## use_cells Eigenschaft
Wenn true dann wird das Arbeitsblatt zur Ablage von Kategorien verwendet (dieser Fall unterstützt mehrstufige Kategorien).
            Wenn false dann Arbeitsblatt NICHT zur Ablage von Werten verwendet wird (und dieser Fall unterstützt keine 
            mehrstufigen Kategorien).
            Lesen/Schreiben **bool**.
