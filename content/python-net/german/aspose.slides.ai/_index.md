Enthält Klassen, die KI-basierte Funktionen zum Analysieren und Verarbeiten von PowerPoint-Präsentationen bereitstellen.
## Klassen

| Klasse | Beschreibung |
| :- | :- |
| [`AsposeAIWebClient`](/slides/python-net/de/aspose.slides.ai/asposeaiwebclient/) | Eine eingebaute [`IAIWebClient`](/slides/python-net/de/aspose.slides.ai/iaiwebclient)-Implementierung, die sich mit Asposes eigenem LLM verbindet.<br/>            Dies ist der Standardclient, der vom parameterlosen **SlidesAIAgent.#ctor**-Konstruktor verwendet wird. |
| [`IAIConversation`](/slides/python-net/de/aspose.slides.ai/iaiconversation/) | Stellt eine Gesprächsinstanz dar. Im Gegensatz zu regulären KI-Aufrufen behalten Unterhaltungen den gesamten Kontext bei. |
| [`IAIWebClient`](/slides/python-net/de/aspose.slides.ai/iaiwebclient/) | AI-Web-Client-Schnittstelle. Diese Schnittstelle ermöglicht den Austausch verschiedener KI-Sprachmodelle.<br/>            Klassen, die diese Schnittstelle implementieren, sollten zusammen mit `SlidesAIAgent` verwendet werden. |
| [`OpenAICompatibleWebClient`](/slides/python-net/de/aspose.slides.ai/openaicompatiblewebclient/) | Eine eingebaute [`IAIWebClient`](/slides/python-net/de/aspose.slides.ai/iaiwebclient)-Implementierung, die sich mit einem OpenAI-kompatiblen LLM-Anbieter<br/>            an einer angegebenen Basis-URL verbindet. |
| [`OpenAIWebClient`](/slides/python-net/de/aspose.slides.ai/openaiwebclient/) | Eine eingebaute [`IAIWebClient`](/slides/python-net/de/aspose.slides.ai/iaiwebclient)-Implementierung, die sich mit der OpenAI-API verbindet. |
| [`SlidesAIAgent`](/slides/python-net/de/aspose.slides.ai/slidesaiagent/) | Bietet KI-gestützte Funktionen zum Verarbeiten von Präsentationen. |
| [`SlidesAIAgentException`](/slides/python-net/de/aspose.slides.ai/slidesaiagentexception/) | Stellt Ausnahmen im Zusammenhang mit Slides AI Agent dar. |

## Aufzählungen

| Aufzählung | Beschreibung |
| :- | :- |
| [`PresentationContentAmountType`](/slides/python-net/de/aspose.slides.ai/presentationcontentamounttype/) | Gibt die Menge des im erzeugten Dokument enthaltenen Inhalts an und beeinflusst sowohl die Anzahl der Folien als auch den Detaillierungsgrad pro Folie. |
