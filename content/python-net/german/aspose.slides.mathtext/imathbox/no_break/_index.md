## no_break Eigenschaft
Kein Umbruch.
            Diese Eigenschaft legt die "unbreakable"-Eigenschaft des Objektkastens fest. Wenn true, können innerhalb des Kastens keine Zeilenumbrüche auftreten.
            Dies kann wichtig sein für Operator-Emulatoren, die aus mehr als einem binären Operator bestehen.
            Wenn dieses Element nicht angegeben ist, können innerhalb des Kastens Umbrüche auftreten.
            Default: true
