## to_box(self) {#}
Platziert dieses Element in einem nicht-visuellen Kasten (logische Gruppierung) 
            der verwendet wird, um Komponenten einer Gleichung oder einer anderen Instanz mathematischen Textes zu gruppieren.
            Ein gekapseltes Objekt kann (zum Beispiel) als Operator-Emulator mit oder ohne Ausrichtungspunkt dienen, 
            als Zeilenumbruchstelle fungieren oder so gruppiert werden, dass innerhalb keine Zeilenumbrüche erlaubt sind.
