## to_box(self) {#}
Platziert dieses Element in einer nicht-sichtbaren Box (logische Gruppierung) 
            die verwendet wird, um Komponenten einer Gleichung oder einer anderen Instanz von mathematischem Text zu gruppieren.
            Ein in einer Box befindliches Objekt kann (zum Beispiel) als Operator-Emulator mit oder ohne Ausrichtungspunkt dienen, 
            als Zeilenumbruch-Punkt dienen oder so gruppiert werden, dass innerhalb keine Zeilenumbrüche erlaubt sind.

### Rückgabewert

Logische Box, in der dieses Element platziert ist
