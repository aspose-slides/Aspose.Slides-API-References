## row_spacing Eigenschaft
Abstand zwischen Zeilen eines Arrays
            Sie wird nur verwendet, wenn RowSpacingRule auf 3 Exact eingestellt ist, wobei die Maßeinheit Punkte ist,
            oder auf Multiple, wobei die Maßeinheit Halbzeilen ist.
            Standard: 0
