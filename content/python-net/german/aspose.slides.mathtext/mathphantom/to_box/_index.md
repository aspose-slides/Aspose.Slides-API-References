## to_box(self) {#}
Platziert dieses Element in einer nicht-visualen Box (logische Gruppierung) 
            die verwendet wird, um Komponenten einer Gleichung oder eines anderen mathematischen Textes zu gruppieren.
            Ein in einer Box gekapseltes Objekt kann (zum Beispiel) als Operator-Emulator mit oder ohne Ausrichtungspunkt dienen, 
            als Zeilenumbruchpunkt dienen oder so gruppiert werden, dass innerhalb keine Zeilenumbrüche erlaubt sind.
