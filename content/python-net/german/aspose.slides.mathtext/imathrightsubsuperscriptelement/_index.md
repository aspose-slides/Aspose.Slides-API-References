## IMathRightSubSuperscriptElement Klasse

Gibt das Sub-Superscript-Objekt an, das aus einer Basis und einer Tief- bzw. Hochstellung besteht, die rechts von der Basis positioniert werden.

Der Typ IMathRightSubSuperscriptElement stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`base`](/slides/python-net/de/aspose.slides.mathtext/imathrightsubsuperscriptelement/base/) | Basisargument |
| [`subscript`](/slides/python-net/de/aspose.slides.mathtext/imathrightsubsuperscriptelement/subscript/) | Tiefstellenargument |
| [`superscript`](/slides/python-net/de/aspose.slides.mathtext/imathrightsubsuperscriptelement/superscript/) | Hochstellenargument |
| [`align_scripts`](/slides/python-net/de/aspose.slides.mathtext/imathrightsubsuperscriptelement/align_scripts/) | Gibt die Ausrichtung von Tiefstellung/Hochstellung an. <br/>            Wenn true, sind Tiefstellung und Hochstellung horizontal zueinander ausgerichtet.<br/>            Wenn false, werden sie an die Form der Basis angepasst.<br/>            Der Standardwert ist false. |
