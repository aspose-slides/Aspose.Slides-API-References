## IMathElementCollection Klasse

Stellt eine Sammlung mathematischer Elemente (MathElement) dar.

Der Typ IMathElementCollection stellt die folgenden Mitglieder bereit:

## Eigenschaften

| :- | :- |
| [`count`](/slides/python-net/de/aspose.slides.mathtext/imathelementcollection/count/) | Ermittelt die tatsächlich in der Sammlung enthaltene Anzahl von Elementen.<br/>Nur lesend **int**. |

Ermittelt das Element am angegebenen Index.
