## row_gap Eigenschaft
Der Wert des vertikalen Abstands zwischen den Zeilen einer Matrix;
            Wenn die RowGapRule auf 3 ("Exactly") gesetzt ist, wird die Einheit als twips (1/20th of a point) interpretiert
            Wenn die RowGapRule auf 4 ("Multiple") gesetzt ist, wird die Einheit als halbe Zeilen interpretiert.
            Standard: 0
