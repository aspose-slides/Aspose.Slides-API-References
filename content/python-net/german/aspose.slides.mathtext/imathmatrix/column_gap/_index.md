## column_gap Eigenschaft
Der Wert des horizontalen Abstands zwischen den Spalten einer Matrix;
            Wenn die ColumnGapRule auf 3 ("Exactly") gesetzt ist, wird die Einheit als Twips (1/20 eines Punktes) interpretiert
            Wenn die ColumnGapRule auf 4 ("Multiple") gesetzt ist, wird die Einheit als Anzahl von 0.5 em Inkrementen interpretiert.
            In anderen Fällen wird ignoriert.
            Standard: 0
