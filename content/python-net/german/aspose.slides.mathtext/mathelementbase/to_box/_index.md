## to_box(self) {#}
Platziert dieses Element in einer nicht-visuellen Box (logische Gruppierung) 
            die zum Gruppieren von Komponenten einer Gleichung oder einer anderen Instanz mathematischen Textes verwendet wird.
            Ein in einer Box befindliches Objekt kann (zum Beispiel) als Operator-Emulator mit oder ohne Ausrichtungspunkt dienen, 
            als Zeilenumbruchpunkt fungieren oder so gruppiert werden, dass Zeilenumbrüche innerhalb nicht erlaubt sind.

### Rückgabewert

Logische Box mit diesem Element platziert
