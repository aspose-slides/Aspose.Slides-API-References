## no_break Eigenschaft
Kein Umbruch
            Diese Eigenschaft gibt die "unbreakable"-Eigenschaft am Objektbox an. Wenn true, können innerhalb des Kastens keine Zeilenumbrüche auftreten.
            Dies kann für Operator-Emulatoren wichtig sein, die aus mehr als einem binären Operator bestehen.
            Wenn dieses Element nicht angegeben ist, können innerhalb des Kastens Umbrüche auftreten.
            Standard: true
