## MathSpacingRules Aufzählung

Arten von Lücken (horizontaler Abstand) zwischen den Spalten einer Matrix

Der Typ MathSpacingRules stellt die folgenden Member bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| SINGLE_SPACING_GAP | Einfach (1 em für Spalten oder 1 Zeile für Reihen) |
| ONE_AND_HALF_SPACING_GAP | Eineinhalb (1,5 ems für Spalten oder 1,5 Zeilen für Reihen) |
| DOUBLE_SPACING_GAP | Doppelter Abstand (2 ems für Spalten oder 2 Zeilen für Reihen) |
| EXACTLY | Genau Wert<br/>            Für Spalten, verweise auf den Wert von ColumnGap, gemessen in Twips<br/>            Für Reihen, verweise auf den Wert von RowGap, gemessen in Twips |
| MULTIPLE | Mehrere<br/>            Für Spalten, verweise auf den Wert von ColumnGap, gemessen in 0,5-em-Schritten<br/>            Für Reihen, verweise auf den Wert von RowGap, gemessen in Zeilen |
