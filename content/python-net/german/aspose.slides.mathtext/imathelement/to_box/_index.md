## to_box(self) {#}
Platzieren Sie dieses Element in einem nicht-visuellen Kasten (logische Gruppierung) 
            der verwendet wird, um Komponenten einer Gleichung oder eines anderen mathematischen Textes zu gruppieren.

            als Zeilenumbruchpunkt fungieren oder so gruppiert werden, dass innerhalb kein Zeilenumbruch zulässig ist.
