## MathRowSpacingRule Aufzählung

Der Typ des vertikalen Abstands zwischen Spalten in einer Matrix oder einem Array

Der Typ MathRowSpacingRule enthält die folgenden Mitglieder:

## Felder

| Feld | Beschreibung |
| :- | :- |
| SINGLE_LINE_GAP | Einzeiliger Abstand |
| ONE_AND_A_HALF_LINE_GAP | Eineinhalbzeiliger Abstand |
| TWO_LINE_GAP | Zweizeiliger Abstand |
| EXACTLY | Genau (abhängig vom Wert der RowSpacing-Eigenschaft, gemessen in Punkten) |
| MULTIPLE | Mehrfach (abhängig vom Wert der RowSpacing-Eigenschaft, gemessen in Zeilen) |
