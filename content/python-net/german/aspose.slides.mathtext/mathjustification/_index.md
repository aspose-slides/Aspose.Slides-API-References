## MathJustification-Aufzählung

Legt die Ausrichtung des mathematischen Absatzes fest (eine Reihe benachbarter Instanzen mathematischen Textes innerhalb desselben Absatzes)

Der Typ MathJustification stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| LEFT_JUSTIFIED | Mathematischen Text nach links ausrichten |
| RIGHT_JUSTIFIED | Mathematischen Text nach rechts ausrichten |
| CENTERED | Mathematischen Text zentrieren |
| CENTERED_AS_GROUP | Zentriert die gesamte Gruppe von mathematischen Blöcken auf der Seite als eine Einheit.<br/>            Das bedeutet, dass die Instanzen des mathematischen Textes zueinander ausgerichtet werden können, <br/>            aber die gesamte Gruppe des mathematischen Textes als Ganzes zentriert ist. |
