## column_gap Eigenschaft
Der Wert des horizontalen Abstands zwischen den Spalten einer Matrix;
            Wenn der ColumnGapRule auf 3 ("Exactly") gesetzt ist, wird die Einheit als Twips (1/20 eines Punktes) interpretiert
            Wenn der ColumnGapRule auf 4 ("Multiple") gesetzt ist, wird die Einheit als Anzahl von 0.5 em-Schritten interpretiert.
            In anderen Fällen ignoriert.
            Standard: 0
