## row_gap Eigenschaft
Der Wert des vertikalen Abstands zwischen Zeilen einer Matrix;
            Wenn die RowGapRule auf 3 ("Exactly") gesetzt ist, wird die Einheit als Twips (1/20 eines Punktes) interpretiert
            Wenn die RowGapRule auf 4 ("Multiple") gesetzt ist, wird die Einheit als Halblinien interpretiert.
            Standard: 0
