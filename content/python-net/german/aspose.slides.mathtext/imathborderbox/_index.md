## IMathBorderBox Klasse

Zeichnet einen rechteckigen oder anderen Rand um das IMathElement.

Der IMathBorderBox-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`base`](/slides/python-net/de/aspose.slides.mathtext/imathborderbox/base/) | Basisargument |
| [`hide_top`](/slides/python-net/de/aspose.slides.mathtext/imathborderbox/hide_top/) | Versteckt obere Kante (default is false) – gibt den versteckten oder angezeigten Zustand der oberen Kante des Randkastens an. |
| [`hide_bottom`](/slides/python-net/de/aspose.slides.mathtext/imathborderbox/hide_bottom/) | Versteckt untere Kante (default is false) – gibt den versteckten oder angezeigten Zustand der unteren Kante des Randkastens an. |
| [`hide_left`](/slides/python-net/de/aspose.slides.mathtext/imathborderbox/hide_left/) | Versteckt linke Kante (default is false) – gibt den versteckten oder angezeigten Zustand der linken Kante des Randkastens an. |
| [`hide_right`](/slides/python-net/de/aspose.slides.mathtext/imathborderbox/hide_right/) | Versteckt rechte Kante (default is false) – gibt den versteckten oder angezeigten Zustand der rechten Kante des Randkastens an. |
| [`strikethrough_horizontal`](/slides/python-net/de/aspose.slides.mathtext/imathborderbox/strikethrough_horizontal/) | Durchgestrichen horizontal (default is false) – gibt den versteckten oder angezeigten Zustand einer horizontalen Durchstreichlinie an. |
| [`strikethrough_vertical`](/slides/python-net/de/aspose.slides.mathtext/imathborderbox/strikethrough_vertical/) | Durchgestrichen vertikal (default is false) – gibt den versteckten oder angezeigten Zustand einer vertikalen Durchstreichlinie an. |
| [`strikethrough_bottom_left_to_top_right`](/slides/python-net/de/aspose.slides.mathtext/imathborderbox/strikethrough_bottom_left_to_top_right/) | Durchgestrichen von unten-links nach oben-rechts (default is false).<br/>            Gibt den versteckten oder angezeigten Zustand einer diagonalen Durchstreichlinie von der unteren linken Ecke zur oberen rechten Ecke des Randkastens an. |
| [`strikethrough_top_left_to_bottom_right`](/slides/python-net/de/aspose.slides.mathtext/imathborderbox/strikethrough_top_left_to_bottom_right/) | Durchgestrichen von oben-links nach unten-rechts (default is false).<br/>            Gibt den versteckten oder angezeigten Zustand einer diagonalen Durchstreichlinie von der oberen linken Ecke zur unteren rechten Ecke des Randkastens an. |
