## IFontScheme Klasse

Speichert die vom Design definierten Schriftarten.

Der IFontScheme-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`minor`](/slides/python-net/de/aspose.slides.theme/ifontscheme/minor/) | Gibt die Schriftartsammlung für den "body"-Teil der Folie zurück.<br/>            Schreibgeschützt [`IFonts`](/slides/python-net/de/aspose.slides/ifonts). |
| [`major`](/slides/python-net/de/aspose.slides.theme/ifontscheme/major/) | Gibt die Schriftartsammlung für den "heading"-Teil der Folie zurück.<br/>            Schreibgeschützt [`IFonts`](/slides/python-net/de/aspose.slides/ifonts). |
| [`name`](/slides/python-net/de/aspose.slides.theme/ifontscheme/name/) | Gibt den Namen des Schriftschemas zurück.<br/>            Lesen/Schreiben **str**. |
