## MasterTheme Klasse

Stellt ein Master-Theme dar.

**Vererbung:**[`MasterTheme`](/slides/python-net/de/aspose.slides.theme/mastertheme) → [`Theme`](/slides/python-net/de/aspose.slides.theme/theme)

Der MasterTheme-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`color_scheme`](/slides/python-net/de/aspose.slides.theme/mastertheme/color_scheme/) | Gibt das Farbschema zurück.<br/>            Nur lesbar [`IColorScheme`](/slides/python-net/de/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/de/aspose.slides.theme/mastertheme/font_scheme/) | Gibt das Schriftschema zurück.<br/>            Nur lesbar [`IFontScheme`](/slides/python-net/de/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/de/aspose.slides.theme/mastertheme/format_scheme/) | Gibt das Formformat-Schema zurück.<br/>            Nur lesbar [`IFormatScheme`](/slides/python-net/de/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/de/aspose.slides.theme/mastertheme/presentation/) | Gibt die übergeordnete Präsentation zurück.<br/>            Nur lesbar [`IPresentation`](/slides/python-net/de/aspose.slides/ipresentation). |
| [`extra_color_schemes`](/slides/python-net/de/aspose.slides.theme/mastertheme/extra_color_schemes/) | Gibt die Sammlung zusätzlicher Farbschemas zurück.<br/>            Diese Schemata beeinflussen das Aussehen der Präsentation nicht, sie können als Hauptfarbschema für eine Folie ausgewählt werden.<br/>            Nur lesbar [`IExtraColorSchemeCollection`](/slides/python-net/de/aspose.slides.theme/iextracolorschemecollection). |
| [`name`](/slides/python-net/de/aspose.slides.theme/mastertheme/name/) | Gibt den Namen eines Themes zurück.<br/>            Lesen/Schreiben **str**. |
