## FontScheme Klasse

Speichert themendefinierte Schriftarten.

Der FontScheme-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`minor`](/slides/python-net/de/aspose.slides.theme/fontscheme/minor/) | Gibt die Schriftarten-Sammlung für einen "body"-Teil der Folie zurück.<br/>            Nur lesbar [`IFonts`](/slides/python-net/de/aspose.slides/ifonts). |
| [`major`](/slides/python-net/de/aspose.slides.theme/fontscheme/major/) | Gibt die Schriftarten-Sammlung für einen "heading"-Teil der Folie zurück.<br/>            Nur lesbar [`IFonts`](/slides/python-net/de/aspose.slides/ifonts). |
| [`name`](/slides/python-net/de/aspose.slides.theme/fontscheme/name/) | Gibt den Namen des Schriftartschemas zurück.<br/>            Lesen/Schreiben **str**. |
