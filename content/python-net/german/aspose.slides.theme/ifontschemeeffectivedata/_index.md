## IFontSchemeEffectiveData Klasse

Unveränderliches Objekt, das effektive Schriftart-Schema-Eigenschaften enthält.

Der Typ IFontSchemeEffectiveData stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`minor`](/slides/python-net/de/aspose.slides.theme/ifontschemeeffectivedata/minor/) | Gibt die Schriften-Sammlung für den "body"-Teil der Folie zurück.<br/>            Nur lesbar [`IFontsEffectiveData`](/slides/python-net/de/aspose.slides/ifontseffectivedata). |
| [`major`](/slides/python-net/de/aspose.slides.theme/ifontschemeeffectivedata/major/) | Gibt die Schriften-Sammlung für den "heading"-Teil der Folie zurück.<br/>            Nur lesbar [`IFontsEffectiveData`](/slides/python-net/de/aspose.slides/ifontseffectivedata). |
| [`name`](/slides/python-net/de/aspose.slides.theme/ifontschemeeffectivedata/name/) | Gibt den Namen des Schriftartschemas zurück.<br/>            Nur lesbar **str**. |

### Hinweise
