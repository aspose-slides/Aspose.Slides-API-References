## OverrideTheme Klasse

Stellt ein überschreibendes Theme dar.

**Vererbung:**[`OverrideTheme`](/slides/python-net/de/aspose.slides.theme/overridetheme) → [`Theme`](/slides/python-net/de/aspose.slides.theme/theme)

Der OverrideTheme-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`color_scheme`](/slides/python-net/de/aspose.slides.theme/overridetheme/color_scheme/) | Gibt das Farbschema zurück.<br/>            Nur lesend [`IColorScheme`](/slides/python-net/de/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/de/aspose.slides.theme/overridetheme/font_scheme/) | Gibt das Schriftartschema zurück.<br/>            Nur lesend [`IFontScheme`](/slides/python-net/de/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/de/aspose.slides.theme/overridetheme/format_scheme/) | Gibt das Shape-Format-Schema zurück.<br/>            Nur lesend [`IFormatScheme`](/slides/python-net/de/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/de/aspose.slides.theme/overridetheme/presentation/) | Gibt die übergeordnete Präsentation zurück.<br/>            Nur lesend [`IPresentation`](/slides/python-net/de/aspose.slides/ipresentation). |
| [`is_empty`](/slides/python-net/de/aspose.slides.theme/overridetheme/is_empty/) | Ein wahrer Wert bedeutet, dass ColorScheme, FontScheme, FormatScheme None sind und jede Überschreibung mit diesem Theme-Objekt deaktiviert ist.<br/>            Nur lesend **bool**. |
