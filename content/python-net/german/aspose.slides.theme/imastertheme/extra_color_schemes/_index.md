## extra_color_schemes Eigenschaft
Gibt die Sammlung zusätzlicher Farbschemata zurück.
            Diese Schemata beeinflussen das Aussehen der Präsentation nicht, sie können als Hauptfarbschema für eine Folie ausgewählt werden.
