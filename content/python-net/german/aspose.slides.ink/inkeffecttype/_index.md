## InkEffectType Aufzählung

Gibt einen Satz vordefinierter visueller Effekte für die Tinten-Darstellung an.  
Jeder Effekt entspricht einer Textur oder einem Bild, das ein stilisiertes Tinten-aussehen simuliert.  
Diese Werte können verwendet werden, um den visuellen Stil digitaler Tintenstriche beim Rendern anzupassen.

Der Typ InkEffectType stellt die folgenden Member bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| NOT_DEFINED | Der Effekt ist nicht definiert oder unbekannt. Dieser Wert kann als Standard- oder Rückfallwert verwendet werden. |
| BRONZE | Eine warme, bräunliche Metalltextur, die bronzene Tinte nachahmt. |
| GALAXY | Eine farbenfrohe, schimmernde Textur, die einer Galaxie ähnelt, mit kosmischen Tönen. |
| GOLD | Eine helle, metallische Goldtextur, die Tintenstrichen ein luxuriöses Aussehen verleiht. |
| LAVA | Eine feurige Textur, die geschmolzene Lava nachahmt, mit roten und orangefarbenen Tönen. |
| OCEAN | Eine tiefblaue, flüssigkeitsähnliche Textur, die Ozeanwellen oder wasserbasierte Tinte nachahmt. |
| RAINBOW_GLITTER | Ein farbenfroher, funkelnder Regenbogen-Glitzereffekt, der für festliche oder lebendige Tintenstriche verwendet wird. |
| ROSE_GOLD | Eine weiche pink-goldene Mischung, ähnlich wie Roségold, für elegante Tintenstriche. |
| SILVER | Eine kühle, metallische Silbertextur, die klassische silberne Tinte simuliert. |
