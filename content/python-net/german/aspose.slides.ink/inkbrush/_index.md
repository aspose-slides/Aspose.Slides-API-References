## InkBrush Klasse

Stellt ein inkBrush-Objekt dar.

Der InkBrush-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`color`](/slides/python-net/de/aspose.slides.ink/inkbrush/color/) | Liest oder setzt die Pinselfarbe für eine Linie. |
| [`size`](/slides/python-net/de/aspose.slides.ink/inkbrush/size/) | Liest oder setzt die Pinselgröße für eine Linie in Punkten. |
| [`ink_effect`](/slides/python-net/de/aspose.slides.ink/inkbrush/ink_effect/) | Liest den Tinten-Effekt-Typ (z. B., Galaxy, Gold, Silver), der den visuellen Stil des Tintenstrichs definiert.<br/>            Der Wert wird aus der Pinsel-Eigenschaft "inkEffects" geparst. Wenn kein erkannter Effekt angegeben ist,<br/>            [`InkEffectType.NOT_DEFINED`](/slides/python-net/de/aspose.slides.ink/inkeffecttype/NOT_DEFINED) wird zurückgegeben. |
