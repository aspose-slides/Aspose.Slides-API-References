## IInkBrush Klasse

Repräsentiert einen Zeichenpinsel.

Der IInkBrush-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`color`](/slides/python-net/de/aspose.slides.ink/iinkbrush/color/) | Liest oder setzt die Pinsel-Farbe für eine Linie. |
| [`size`](/slides/python-net/de/aspose.slides.ink/iinkbrush/size/) | Liest oder setzt die Pinselgröße für eine Linie in Punkten. |
| [`ink_effect`](/slides/python-net/de/aspose.slides.ink/iinkbrush/ink_effect/) | Liest den Tinteneffekt-Typ (z. B. Galaxy, Gold, Silver), der den visuellen Stil des Tintenschlages definiert.<br/>            Der Wert wird aus der Pinsel-Eigenschaft "inkEffects" geparst. Wenn kein erkannter Effekt angegeben ist,<br/>            [`InkEffectType.NOT_DEFINED`](/slides/python-net/de/aspose.slides.ink/inkeffecttype/NOT_DEFINED) wird zurückgegeben. |
