## BlackWhiteConversionMode Aufzählung

Stellt Optionen bereit, die steuern, wie die Folienbilder in binäre Bilder konvertiert werden.

Der Typ BlackWhiteConversionMode stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| DEFAULT | Gibt keinen Konvertierungsalgorithmus an. Der im TIFF-Codec implementierte Algorithmus wird verwendet. (Standard) |
| DITHERING | Gibt den Dithering-Algorithmus (Floyd-Steinberg) an. |
| DITHERING_FLOYD_STEINBERG | Gibt den Floyd-Steinberg-Dithering-Algorithmus an. |
| AUTO | Gibt den automatisch berechneten Schwellwert-Algorithmus (Otsu) an. |
| AUTO_OTSU | Gibt den automatisch berechneten Otsu-Schwellwert-Algorithmus an. |
| THRESHOLD25 | Gibt den statischen Schwellwert-Algorithmus (25 %) an. |
| THRESHOLD50 | Gibt den statischen Schwellwert-Algorithmus (50 %) an. |
| THRESHOLD75 | Gibt den statischen Schwellwert-Algorithmus (75 %) an. |
