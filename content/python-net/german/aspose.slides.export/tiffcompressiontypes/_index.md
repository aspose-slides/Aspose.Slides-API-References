## TiffCompressionTypes Aufzählung

Stellt Optionen bereit, die steuern, wie eine Präsentation im TIFF-Format komprimiert wird.

Der Typ TiffCompressionTypes stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| DEFAULT | Gibt das Standardskomprimierungsschema an (LZW). |
| NONE | Gibt an, dass keine Komprimierung verwendet wird. |
| CCITT3 | Gibt das CCITT3-Komprimierungsschema an. |
| CCITT4 | Gibt das CCITT4-Komprimierungsschema an. |
| LZW | Gibt das LZW-Komprimierungsschema an (Standard). |
| RLE | Gibt das RLE-Komprimierungsschema an. |
