## SvgCoordinateUnit Aufzählung

Stellt CSS2-Koordinateneinheiten dar, die zur Definition von SVG-Koordinaten verwendet werden.

Der Typ SvgCoordinateUnit stellt die folgenden Mitglieder bereit:

## Felder

| Field | Description |
| :- | :- |
| INCH | Zoll |
| CENTIMETER | Zentimeter. |
| MILLIMETER | Millimeter. |
| POINT | Punkt (1/72 Zoll), |
| PICA | Pica (1/6 Zoll). |
| EM | Em-Größe einer Schrift des enthaltenden Elements. |
| EX | Ex-Größe (Größe des Kleinbuchstabens, normalerweise "x") einer Schrift des enthaltenden Elements. |
| PIXEL | Pixelgröße. |
| PERCENT | Prozent. |
