## delete_pictures_cropped_areas Eigenschaft
Ein boolesches Flag gibt an, ob die zugeschnittenen Teile Teil des Dokuments bleiben. If true die zugeschnittenen 
            Teile werden entfernt, wenn false werden sie im Dokument serialisiert (was möglicherweise zu einer 
            größeren Datei führen kann)
