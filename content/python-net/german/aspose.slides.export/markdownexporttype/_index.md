## MarkdownExportType Aufzählung

Typ des renderten Dokuments.

Der Typ MarkdownExportType stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| SEQUENTIAL | Alle Elemente einzeln rendern. Eins nach dem anderen. |
| TEXT_ONLY | Nur Text rendern. |
| VISUAL | Alle Elemente rendern, gruppierte Elemente zusammen rendern. |
