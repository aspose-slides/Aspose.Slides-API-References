## Konformitätsaufzählung

Gibt die Konformitätsklasse an, der das PresentationML-Dokument entspricht.

Der Conformance-Typ stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| ECMA_376_2006 | Gibt an, dass das Dokument der ECMA376:2006 entspricht. |
| ISO_29500_2008_TRANSITIONAL | Gibt an, dass das Dokument der ISO/IEC 29500:2008 Transitional-Konformitätsklasse entspricht. |
| ISO_29500_2008_STRICT | Gibt an, dass das Dokument der ISO/IEC 29500:2008 Strict-Konformitätsklasse entspricht. |
