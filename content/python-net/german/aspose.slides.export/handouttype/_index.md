## HandoutType Aufzählung

Gibt an, wie viele Folien und in welcher Reihenfolge auf der Seite platziert werden.

Der Typ HandoutType stellt die folgenden Member bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| HANDOUTS1 | Eine Folie pro Seite. |
| HANDOUTS2 | Zwei Folien pro Seite. |
| HANDOUTS3 | Drei Folien pro Seite. |
| HANDOUTS_4_HORIZONTAL | Vier Folien pro Seite in einer horizontalen Reihenfolge. |
| HANDOUTS_4_VERTICAL | Vier Folien pro Seite in einer vertikalen Reihenfolge. |
| HANDOUTS_6_HORIZONTAL | Sechs Folien pro Seite in einer horizontalen Reihenfolge. |
| HANDOUTS_6_VERTICAL | Sechs Folien pro Seite in einer vertikalen Reihenfolge. |
| HANDOUTS_9_HORIZONTAL | Neun Folien pro Seite in einer horizontalen Reihenfolge. |
| HANDOUTS_9_VERTICAL | Neun Folien pro Seite in einer vertikalen Reihenfolge. |
