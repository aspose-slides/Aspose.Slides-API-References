## SvgExternalFontsHandling Aufzählung

Stellt eine Methode dar, wie externe Schriften für die Textdarstellung behandelt werden.

Der Typ SvgExternalFontsHandling stellt die folgenden Member bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| ADD_LINKS_TO_FONT_FILES | Fügt Links zu separaten Schriftdateien zum Style-Abschnitt der SVG-Datei hinzu. |
| EMBED | Speichert Schriftartdaten direkt in die SVG-Datei. Bitte prüfen Sie alle Lizenzvereinbarungen für externe Schriften, bevor Sie diese Option verwenden. |
| VECTORIZE | Speichert gesamten Text, der externe Schriften verwendet, als Grafiken. |
