## Zip64Mode Aufzählung

Gibt an, wann ZIP64-Format-Erweiterungen für OpenXML-Dateien verwendet werden sollen.

Der Typ Zip64Mode stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| NEVER | Verwenden Sie keine ZIP64-Format-Erweiterungen. |
| IF_NECESSARY | Verwenden Sie ZIP64-Format-Erweiterungen, falls erforderlich. |
| ALWAYS | Verwenden Sie immer ZIP64-Format-Erweiterungen. |


### Bemerkungen

Eine OpenXML-Datei ist ein ZIP-Archiv, das eine Grenze von 4 GB (2^32 Byte) für die unkomprimierte Dateigröße, die komprimierte Dateigröße und die Gesamtgröße des Archivs hat, sowie eine Beschränkung von 65.535 (2^16-1) Dateien im Archiv. ZIP64-Format-Erweiterungen erhöhen die Grenzen auf 2^64.
