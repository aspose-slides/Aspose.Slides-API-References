## PdfTextCompression Aufzählung

Konstanten, die den Typ einer Kompression definieren, die auf alle Inhalte in der PDF-Datei außer Bildern angewendet wird.

Der Typ PdfTextCompression stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| NONE | Keine Kompression. |
| FLATE | Flate (ZIP) Kompression. |
