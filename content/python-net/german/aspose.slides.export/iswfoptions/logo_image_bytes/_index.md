## logo_image_bytes Eigenschaft
Bild, das im rechten oberen Eck des Betrachters als Logo angezeigt wird.
            Das Bild sollte ein 32x64 Pixel PNG-Bild sein, sonst kann das Logo fehlerhaft angezeigt werden.
