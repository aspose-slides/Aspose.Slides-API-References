## ISwfOptions Klasse

Stellt Optionen bereit, die steuern, wie eine Präsentation im SWF-Format gespeichert wird.

Der ISwfOptions-Typ stellt die folgenden Elemente bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`compressed`](/slides/python-net/de/aspose.slides.export/iswfoptions/compressed/) | Gibt an, ob das erzeugte SWF-Dokument komprimiert werden soll oder nicht.<br/>            Standardwert ist `true`. |
| [`viewer_included`](/slides/python-net/de/aspose.slides.export/iswfoptions/viewer_included/) | Gibt an, ob das erzeugte SWF-Dokument den integrierten Dokumentbetrachter enthalten soll oder nicht.<br/>            Standardwert ist `true`. |
| [`show_page_border`](/slides/python-net/de/aspose.slides.export/iswfoptions/show_page_border/) | Gibt an, ob ein Rahmen um die Seiten angezeigt werden soll. Standardwert ist true. |
| [`show_hidden_slides`](/slides/python-net/de/aspose.slides.export/iswfoptions/show_hidden_slides/) | Gibt an, ob das erzeugte Dokument versteckte Folien enthalten soll oder nicht.<br/>            Standardwert ist `false`. |
| [`show_full_screen`](/slides/python-net/de/aspose.slides.export/iswfoptions/show_full_screen/) | Anzeige/Verbergen des Vollbild-Buttons. Kann in flashvars überschrieben werden. Standardwert ist true. |
| [`show_page_stepper`](/slides/python-net/de/aspose.slides.export/iswfoptions/show_page_stepper/) | Anzeige/Verbergen des Seitenschrittes. Kann in flashvars überschrieben werden. Standardwert ist true. |
| [`show_search`](/slides/python-net/de/aspose.slides.export/iswfoptions/show_search/) | Anzeige/Verbergen des Suchbereichs. Kann in flashvars überschrieben werden. Standardwert ist true. |
| [`show_top_pane`](/slides/python-net/de/aspose.slides.export/iswfoptions/show_top_pane/) | Anzeige/Verbergen des gesamten oberen Bereichs. Kann in flashvars überschrieben werden. Standardwert ist true. |
| [`show_bottom_pane`](/slides/python-net/de/aspose.slides.export/iswfoptions/show_bottom_pane/) | Anzeige/Verbergen des unteren Bereichs. Kann in flashvars überschrieben werden. Standardwert ist true. |
| [`show_left_pane`](/slides/python-net/de/aspose.slides.export/iswfoptions/show_left_pane/) | Anzeige/Verbergen des linken Bereichs. Kann in flashvars überschrieben werden. Standardwert ist true. |
| [`start_open_left_pane`](/slides/python-net/de/aspose.slides.export/iswfoptions/start_open_left_pane/) | Starten mit geöffnetem linkem Bereich. Kann in flashvars überschrieben werden. Standardwert ist false. |
| [`enable_context_menu`](/slides/python-net/de/aspose.slides.export/iswfoptions/enable_context_menu/) | Aktivieren/Deaktivieren des Kontextmenüs. Standardwert ist true. |
| [`logo_image_bytes`](/slides/python-net/de/aspose.slides.export/iswfoptions/logo_image_bytes/) | Bild, das als Logo in der oberen rechten Ecke des Betrachters angezeigt wird.             <br/>            Das Bild sollte eine PNG-Datei mit 32 × 64 Pixel sein, sonst kann das Logo fehlerhaft dargestellt werden. |
| [`logo_link`](/slides/python-net/de/aspose.slides.export/iswfoptions/logo_link/) | Ruft die vollständige Hyperlink-Adresse für ein Logo ab oder setzt sie.<br/>            Hat nur Wirkung, wenn ein [`ISwfOptions.logo_image_bytes`](/slides/python-net/de/aspose.slides.export/iswfoptions/logo_image_bytes) angegeben ist. |
| [`jpeg_quality`](/slides/python-net/de/aspose.slides.export/iswfoptions/jpeg_quality/) | Gibt die Qualität von JPEG-Bildern an.             <br/>            Standardwert ist 95. |
| [`slides_layout_options`](/slides/python-net/de/aspose.slides.export/iswfoptions/slides_layout_options/) | Ruft den Modus ab, in dem Folien beim Export einer Präsentation [`ISlidesLayoutOptions`](/slides/python-net/de/aspose.slides.export/islideslayoutoptions) auf der Seite angeordnet werden, oder setzt ihn.<br/>            Diese Eigenschaft unterstützt das Zuweisen von Objekten des Typs `Aspose.Slides.Export.HandoutLayoutingOptions` nicht. |
| [`warning_callback`](/slides/python-net/de/aspose.slides.export/iswfoptions/warning_callback/) |  |
