## IPresentationAnimationPlayer Klasse

Stellt einen Player der Animation dar.

Animationen, die von [`PresentationAnimationsGenerator`](/slides/python-net/de/aspose.slides.export/presentationanimationsgenerator) über sein **NewAnimation** Ereignis erzeugt werden.

Der IPresentationAnimationPlayer-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`duration`](/slides/python-net/de/aspose.slides.export/ipresentationanimationplayer/duration/) | Liefert die Animationsdauer [ms] |

## Methoden

| Methode | Beschreibung |
| :- | :- |
| [`set_time_position(self, time)`](/slides/python-net/de/aspose.slides.export/ipresentationanimationplayer/set_time_position/#float) | Setzt die Animationszeitposition innerhalb des [`IPresentationAnimationPlayer.duration`](/slides/python-net/de/aspose.slides.export/ipresentationanimationplayer/duration). |
| [`get_frame(self)`](/slides/python-net/de/aspose.slides.export/ipresentationanimationplayer/get_frame/#) | Liefert das Bild für die aktuelle Zeitposition, die zuvor mit der **Aspose.Slides.Export.IPresentationAnimationPlayer.SetTimePosition(Syste**-Methode festgelegt wurde. |
