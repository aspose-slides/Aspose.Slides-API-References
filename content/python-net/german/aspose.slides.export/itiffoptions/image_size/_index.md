## image_size Eigenschaft
Gibt die Größe eines erzeugten TIFF-Bildes an.
            Der Standardwert ist 0x0, was bedeutet, dass die erzeugten Bildgrößen basierend auf dem Wert der Präsentationsfoliengröße berechnet werden.
            Lesen/Schreiben **aspose.slides.Size**.
