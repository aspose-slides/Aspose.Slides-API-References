## skip_java_script_links Eigenschaft
Specifies whether to skip hyperlinks with JavaScript calls when saving the presentation. 
            Lesen/Schreiben **bool**. Der Standardwert ist **false** .


### Hinweise

Wenn diese Eigenschaft auf **true** , Hyperlinks mit JavaScript-Aufrufen werden beim Speichern ignoriert.


Wenn diese Eigenschaft auf **false** , alle Hyperlinks werden gespeichert.
