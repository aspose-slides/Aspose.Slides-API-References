## CommentsPositions Aufzählung

Beschreibt die Regel, Kommentare in das exportierte Dokument zu rendern

Der Typ CommentsPositions stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| NONE | Gibt an, dass Kommentare überhaupt nicht angezeigt werden sollen. |
| BOTTOM | Gibt an, dass Kommentare am unteren Rand der Seite angezeigt werden sollen. |
| RIGHT | Gibt an, dass Kommentare rechts von der Seite angezeigt werden sollen. |
