## NotesPositions Aufzählung

Stellt die Regel dar, Notizen in ein exportiertes Dokument zu rendern.

Der Typ NotesPositions stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| NONE | Gibt an, dass Notizen überhaupt nicht angezeigt werden sollen. |
| BOTTOM_FULL | Gibt an, dass Notizen vollständig angezeigt werden, indem bei Bedarf zusätzliche Seiten verwendet werden. |
| BOTTOM_TRUNCATED | Gibt an, dass Notizen nur auf einer Seite angezeigt werden sollen. |
