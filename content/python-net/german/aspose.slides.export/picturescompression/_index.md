## PicturesCompression Aufzählung

Stellt das Bilderkomprimierungslevel dar

Der Typ PicturesCompression stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| DPI330 | Gute Qualität für hochauflösende (HD) Displays |
| DPI220 | Ausgezeichnete Qualität auf den meisten Druckern und Bildschirmen |
| DPI150 | Geeignet für Webseiten und Projektoren |
| DPI96 | Minimiert die Dokumentgröße zum Teilen |
| DPI72 | Standard-Komprimierungsstufe |
| DOCUMENT_RESOLUTION | Verwende die Dokumentauflösung – das Bild wird nicht komprimiert und im Dokument unverändert verwendet |
