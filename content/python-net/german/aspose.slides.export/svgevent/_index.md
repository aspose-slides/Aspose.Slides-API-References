## SvgEvent Aufzählung

Stellt Optionen für SVG-Formen dar.

Der Typ SvgEvent stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| ON_FOCUS_IN | Tritt auf, wenn ein Element den Fokus erhält, zum Beispiel wenn ein Text ausgewählt wird. |
| ON_FOCUS_OUT | Tritt auf, wenn ein Element den Fokus verliert, zum Beispiel wenn ein Text deselektiert wird. |
| ON_ACTIVATE | Tritt auf, wenn ein Element aktiviert wird, zum Beispiel durch einen Mausklick oder einen Tastendruck. |
| ON_CLICK | Tritt auf, wenn die Maustaste über einem Element geklickt wird. |
| ON_MOUSE_DOWN | Tritt auf, wenn die Maustaste über einem Element gedrückt wird. |
| ON_MOUSE_UP | Tritt auf, wenn die Maustaste über einem Element losgelassen wird. |
| ON_MOUSE_OVER | Tritt auf, wenn die Maus über ein Element bewegt wird. |
| ON_MOUSE_MOVE | Tritt auf, wenn die Maus bewegt wird, während sie sich über einem Element befindet. |
| ON_MOUSE_OUT | Tritt auf, wenn die Maus von einem Element wegbewegt wird. |
| ON_LOAD | Tritt auf, wenn der User-Agent das Element und seine Nachkommen sowie alle referenzierten Ressourcen vollständig geparst hat, die für die Darstellung erforderlich sind. |
| ON_UNLOAD | Tritt auf, wenn die DOM-Implementierung ein Dokument aus einem Fenster oder Frame entfernt. Nur anwendbar auf äußerste SVG-Elemente. |
| ON_ABORT | Tritt auf, wenn das Laden der Seite gestoppt wird, bevor ein Element vollständig geladen werden konnte. |
| ON_ERROR | Tritt auf, wenn ein Element nicht korrekt geladen wird oder ein Fehler während der Skriptausführung auftritt. |
| ON_RESIZE | Tritt auf, wenn die Ansicht eines Dokuments skaliert wird. Nur anwendbar auf äußerste SVG-Elemente. |
| ON_SCROLL | Tritt auf, wenn die Ansicht eines Dokuments entlang der X- oder Y-Achse bzw. beider Achsen verschoben wird. Nur anwendbar auf äußerste SVG-Elemente. |
| ON_ZOOM | Tritt auf, wenn die Zoomstufe einer Dokumentenansicht geändert wird. Nur anwendbar auf äußerste SVG-Elemente. |
| ON_BEGIN | Tritt auf, wenn ein Animationselement beginnt. |
| ON_END | Tritt auf, wenn ein Animationselement endet. |
| ON_REPEAT | Tritt auf, wenn ein Animationselement wiederholt wird. |
