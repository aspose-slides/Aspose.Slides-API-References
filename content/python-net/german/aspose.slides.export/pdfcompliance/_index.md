## PdfCompliance Aufzählung

Konstanten, die das PDF-Standard-Konformitätsniveau definieren.

Der Typ PdfCompliance stellt die folgenden Member bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| PDF15 | Die Ausgabedatei entspricht dem PDF 1.5 Standard. |
| PDF16 | Die Ausgabedatei entspricht dem PDF 1.6 Standard. |
| PDF17 | Die Ausgabedatei entspricht dem PDF 1.7 Standard. |
| PDF_A1B | Die Ausgabedatei entspricht dem PDF/A-1b Standard. |
| PDF_A1A | Die Ausgabedatei entspricht dem PDF/A-1a Standard. |
| PDF_A2B | Die Ausgabedatei entspricht dem PDF/A-2b Standard. |
| PDF_A2A | Die Ausgabedatei entspricht dem PDF/A-2a Standard. |
| PDF_A3B | Die Ausgabedatei entspricht dem PDF/A-3b Standard. |
| PDF_A3A | Die Ausgabedatei entspricht dem PDF/A-3a Standard. |
| PDF_UA | Die Ausgabedatei entspricht dem PDF/UA Standard. |
| PDF_A2U | Die Ausgabedatei entspricht dem PDF/A-2u Standard. |
