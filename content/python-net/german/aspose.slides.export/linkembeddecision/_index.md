## LinkEmbedDecision Aufzählung

Bestimmt, wie das Objekt beim Speichern verarbeitet wird.

Der Typ LinkEmbedDecision stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| LINK | Das Objekt wird extern gespeichert und per URL referenziert. |
| EMBED | Das Objekt sollte, wenn möglich, in eine erzeugte Datei eingebettet werden. Wenn das Einbetten nicht möglich ist, wird GetUrl aufgerufen und je nach Ergebnis wird das Objekt per URL referenziert oder ignoriert. |
| IGNORE | Das Objekt wird ignoriert. |
