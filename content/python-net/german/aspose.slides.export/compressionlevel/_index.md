## CompressionLevel Aufzählung

Gibt die ZIP-Komprimierungsstufen für OpenXML-Dateien an.
Höhere Stufen bieten eine bessere Komprimierung, allerdings auf Kosten einer langsameren Verarbeitung.

Der Typ CompressionLevel stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| NONE | Keine Komprimierung wird angewendet. Dateien werden unverändert gespeichert. |
| LEVEL1 | Schnellste Komprimierung mit dem niedrigsten Kompressionsverhältnis. |
| LEVEL2 | Schnellere Komprimierung mit leicht besserem Kompressionsverhältnis als [`CompressionLevel.LEVEL1`](/slides/python-net/de/aspose.slides.export/compressionlevel/LEVEL1). |
| LEVEL3 | Bietet eine bessere Komprimierung als [`CompressionLevel.LEVEL2`](/slides/python-net/de/aspose.slides.export/compressionlevel/LEVEL2) mit moderatem Leistungseinfluss. |
| LEVEL4 | Bietet eine bessere Komprimierung als [`CompressionLevel.LEVEL3`](/slides/python-net/de/aspose.slides.export/compressionlevel/LEVEL3). |
| LEVEL5 | Bietet eine verbesserte Komprimierung gegenüber [`CompressionLevel.LEVEL4`](/slides/python-net/de/aspose.slides.export/compressionlevel/LEVEL4) mit zusätzlicher Verarbeitungszeit. |
| LEVEL6 | Standardkomprimierung, die ein gutes Gleichgewicht zwischen Komprimierungsgeschwindigkeit und Dateigröße bietet.<br/>            Die Standardkomprimierungsstufe. |
| LEVEL7 | Bietet eine höhere Komprimierung als [`CompressionLevel.LEVEL6`](/slides/python-net/de/aspose.slides.export/compressionlevel/LEVEL6) bei langsamerer Verarbeitung. |
| LEVEL8 | Bietet eine höhere Komprimierung als [`CompressionLevel.LEVEL7`](/slides/python-net/de/aspose.slides.export/compressionlevel/LEVEL7). |
| LEVEL9 | Maximale Komprimierung. Erzeugt die kleinste Dateigröße bei der langsamsten Verarbeitungsgeschwindigkeit. |
