## IInkOptions Klasse

Stellt Optionen bereit, die das Aussehen von Ink-Objekten im exportierten Dokument steuern.

Der Typ IInkOptions stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`hide_ink`](/slides/python-net/de/aspose.slides.export/iinkoptions/hide_ink/) | Zeigt Ink-Elemente im exportierten Dokument an oder blendet sie aus. |
| [`interpret_mask_op_as_opacity`](/slides/python-net/de/aspose.slides.export/iinkoptions/interpret_mask_op_as_opacity/) | Verwendet ROP-Operation oder Opazität zum Rendern des Pinsels. |
