## root_directory_clsid Eigenschaft
Stellt die Objektklassen-GUID (CLSID) dar, die im Root-Verzeichnis-Eintrag gespeichert ist. Kann für die COM-Aktivierung der Anwendungsdatei des Dokuments verwendet werden. Der Standardwert ist '64818D11-4F9B-11CF-86EA-00AA00B929E8', der 'Microsoft Powerpoint.Slide.8' entspricht.
