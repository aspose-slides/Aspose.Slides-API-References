## HandleRepeatedSpaces Aufzählung

Gibt an, wie wiederholte reguläre Leerzeichen behandelt werden sollen während des Markdown-Exports.

Der Typ HandleRepeatedSpaces stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| NONE | Alle Leerzeichen werden als reguläre Leerzeichen ohne Änderungen beibehalten.<br/>            Es wird keine Transformation angewendet, und mehrere aufeinanderfolgende Leerzeichen werden unverändert exportiert. |
| ALTERNATE_SPACES_TO_NBSP |  |
| MULTIPLE_SPACES_TO_NBSP |  |
