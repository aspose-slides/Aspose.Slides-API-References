## Eigenschaften

| Property | Description |
| :- | :- |
| [`warning_callback`](/slides/python-net/de/aspose.slides.export/html5options/warning_callback/) | Gibt ein Objekt zurück, das Warnungen empfängt und entscheidet, ob der Ladevorgang fortgesetzt oder abgebrochen wird.<br/>            Lesen/Schreiben [`IWarningCallback`](/slides/python-net/de/aspose.slides.warnings/iwarningcallback). |

| [`default_regular_font`](/slides/python-net/de/aspose.slides.export/html5options/default_regular_font/) | Gibt die Schriftart zurück oder setzt sie, falls die Quellschriftart nicht gefunden wird.<br/>            Lesen/Schreiben **str**. |
| [`gradient_style`](/slides/python-net/de/aspose.slides.export/html5options/gradient_style/) | Gibt den visuellen Stil des Farbverlaufs zurück oder setzt ihn.<br/>            Lesen/Schreiben [`GradientStyle`](/slides/python-net/de/aspose.slides/gradientstyle). |

| [`animate_shapes`](/slides/python-net/de/aspose.slides.export/html5options/animate_shapes/) | Gibt die Formenanimationsoption zurück oder setzt sie.<br/>            Lesen/Schreiben **bool**. |
| [`embed_images`](/slides/python-net/de/aspose.slides.export/html5options/embed_images/) | Gibt die Bild-Einbettungsoption zurück oder setzt sie.<br/>            Lesen/Schreiben **bool**. |
| [`output_path`](/slides/python-net/de/aspose.slides.export/html5options/output_path/) | Bestimmt, wo externe Ressourcen gespeichert werden sollen.<br/>            Lesen/Schreiben **str**. |
| [`pictures_compression`](/slides/python-net/de/aspose.slides.export/html5options/pictures_compression/) | Stellt den Kompressionsgrad für Bilder dar |
| [`disable_font_ligatures`](/slides/python-net/de/aspose.slides.export/html5options/disable_font_ligatures/) | Gibt einen Wert zurück oder setzt ihn, der angibt, ob Text ohne Ligaturen gerendert wird.<br/>            Wenn auf `true` gesetzt, werden Ligaturen im gerenderten Ausgabebild deaktiviert. Standardmäßig ist diese Eigenschaft auf `false` gesetzt. |
