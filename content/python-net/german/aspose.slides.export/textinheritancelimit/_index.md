## TextInheritanceLimit Aufzählung

Steuert die Tiefe der Vererbung von Texteigenschaften.

Der Typ TextInheritanceLimit stellt die folgenden Elemente bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| ALL | Vererbt alle Texteigenschaften. |
| TEXT_BOX | Vererbt nur vom Stil von TextFrame. |
| PARAGRAPH_ONLY | Verwendet nur für Absatz definierte Eigenschaften. |
