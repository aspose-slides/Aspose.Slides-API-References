## embed_true_type_fonts_for_ascii Eigenschaft
Bestimmt, ob Aspose.Slides gängige Schriftarten für ASCII (33..127 Codebereich) Text einbetten wird.
Schriftarten für Zeichenkodierungen größer als 127 werden immer eingebettet.
Die Liste der gängigen Schriftarten enthält die 14 Basis-Schriftarten von PDF und zusätzliche benutzerdefinierte Schriftarten.
Lesen/Schreiben **bool**.

### Anmerkungen
Standard ist **true**.
