## IAlphaCeiling Klasse

Stellt einen Alpha-Ceiling-Effekt dar.
            Alpha (opacity)-Werte, die größer als Null sind, werden auf 100% geändert.
            Mit anderen Worten wird alles, das teilweise undurchsichtig ist, vollständig undurchsichtig.
