## IColorChangeEffectiveData Klasse

Unveränderliches Objekt, das einen Color Change-Effekt darstellt.  
Instanzen von FromColor werden durch Instanzen von ToColor ersetzt.

Der Typ IColorChangeEffectiveData stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`from_color`](/slides/python-net/de/aspose.slides.effects/icolorchangeeffectivedata/from_color/) | Farbe, die ersetzt wird.<br/>            Nur-Lesen **aspose.slides.Color**. |
| [`to_color`](/slides/python-net/de/aspose.slides.effects/icolorchangeeffectivedata/to_color/) | Farbe, die ersetzt wird.<br/>            Nur-Lesen **aspose.slides.Color**. |
| [`use_alpha`](/slides/python-net/de/aspose.slides.effects/icolorchangeeffectivedata/use_alpha/) | Gibt einen booleschen Wert zurück, der bestimmt, ob die Alpha-Komponente verwendet werden soll.<br/>            Nur-Lesen **bool**. |
