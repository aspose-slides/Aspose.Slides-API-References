## IHSLEffectiveData Klasse

Stellt einen Hue/Saturation/Luminance-Effekt dar.  
Der Hue, die Saturation und die Luminanz können jeweils relativ zu ihrem aktuellen Wert angepasst werden.

Der Typ IHSLEffectiveData stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`hue`](/slides/python-net/de/aspose.slides.effects/ihsleffectivedata/hue/) | Gibt den Hue-Prozentsatz zurück.<br/>            Nur lesbar **float**. |
| [`saturation`](/slides/python-net/de/aspose.slides.effects/ihsleffectivedata/saturation/) | Gibt den Saturation-Prozentsatz zurück.<br/>            Nur lesbar **float**. |
| [`luminance`](/slides/python-net/de/aspose.slides.effects/ihsleffectivedata/luminance/) | Gibt den Luminance-Prozentsatz zurück.<br/>            Nur lesbar **float**. |
