## AlphaCeiling class

Stellt einen Alpha-Ceiling-Effekt dar.
Alpha-Werte (Deckkraft) größer als Null werden auf 100 % geändert.
Mit anderen Worten wird alles teilweise undurchsichtig vollständig undurchsichtig.
