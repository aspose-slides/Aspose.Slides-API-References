## IAlphaCeilingEffectiveData Klasse

Unveränderliches Objekt, das einen Alpha-Ceiling-Effekt darstellt.
            Alpha (Deckkraft) Werte größer als Null werden auf 100 % geändert.
            Andererseits wird alles, das teilweise undurchsichtig ist, vollständig undurchsichtig.
