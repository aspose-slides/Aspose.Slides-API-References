## IReflectionEffectiveData Klasse

Unveränderliches Objekt, das einen Reflexionseffekt darstellt.

Der IReflectionEffectiveData-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/de/aspose.slides.effects/ireflectioneffectivedata/start_pos_alpha/) | Gibt die Startposition (entlang der Alpha-Verlaufsrampe) des Start-Alpha-Werts (Prozent) an.<br/>            Nur lesbar **float**. |
| [`end_pos_alpha`](/slides/python-net/de/aspose.slides.effects/ireflectioneffectivedata/end_pos_alpha/) | Gibt die Endposition (entlang der Alpha-Verlaufsrampe) des End-Alpha-Werts (Prozent) an.<br/>            Nur lesbar **float**. |
| [`fade_direction`](/slides/python-net/de/aspose.slides.effects/ireflectioneffectivedata/fade_direction/) | Gibt die Richtung an, in die die Reflexion verschoben wird (Winkel).<br/>            Nur lesbar **float**. |
| [`start_reflection_opacity`](/slides/python-net/de/aspose.slides.effects/ireflectioneffectivedata/start_reflection_opacity/) | Anfangs-Reflexions-Deckkraft (Prozent).<br/>            Nur lesbar **float**. |
| [`end_reflection_opacity`](/slides/python-net/de/aspose.slides.effects/ireflectioneffectivedata/end_reflection_opacity/) | End-Reflexions-Deckkraft (Prozent).<br/>            Nur lesbar **float**. |
| [`blur_radius`](/slides/python-net/de/aspose.slides.effects/ireflectioneffectivedata/blur_radius/) | Unschärferadius.<br/>            Nur lesbar **float**. |
