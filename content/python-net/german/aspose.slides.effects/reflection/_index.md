## Reflexions-Klasse

Stellt einen Reflexionseffekt dar.

Der Reflexionstyp stellt die folgenden Member bereit:

## Eigenschaften

| Property | Description |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/de/aspose.slides.effects/reflection/start_pos_alpha/) | Gibt die Startposition (entlang der Alpha-Verlaufsrampe) des Start-Alpha-Werts (Prozent) an.<br/>            Lesen/Schreiben **float**. |
| [`end_pos_alpha`](/slides/python-net/de/aspose.slides.effects/reflection/end_pos_alpha/) | Gibt die Endposition (entlang der Alpha-Verlaufsrampe) des End-Alpha-Werts (Prozent) an.<br/>            Lesen/Schreiben **float**. |
| [`fade_direction`](/slides/python-net/de/aspose.slides.effects/reflection/fade_direction/) | Gibt die Richtung an, um die die Reflexion verschoben wird. (Winkel).<br/>            Lesen/Schreiben **float**. |
| [`start_reflection_opacity`](/slides/python-net/de/aspose.slides.effects/reflection/start_reflection_opacity/) | Anfangs-Transparenz der Reflexion. (Prozent).<br/>            Lesen/Schreiben **float**. |
| [`end_reflection_opacity`](/slides/python-net/de/aspose.slides.effects/reflection/end_reflection_opacity/) | End-Transparenz der Reflexion. (Prozent).<br/>            Lesen/Schreiben **float**. |
| [`blur_radius`](/slides/python-net/de/aspose.slides.effects/reflection/blur_radius/) | Unschärferadius.<br/>            Lesen/Schreiben **float**. |
| [`direction`](/slides/python-net/de/aspose.slides.effects/reflection/direction/) | Richtung der Reflexion.<br/>            Lesen/Schreiben **float**. |
| [`distance`](/slides/python-net/de/aspose.slides.effects/reflection/distance/) | Abstand der Reflexion.<br/>            Lesen/Schreiben **float**. |
| [`rectangle_align`](/slides/python-net/de/aspose.slides.effects/reflection/rectangle_align/) | Rechteckausrichtung.<br/>            Lesen/Schreiben [`RectangleAlignment`](/slides/python-net/de/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/de/aspose.slides.effects/reflection/skew_horizontal/) | Gibt den horizontalen Schrägstellungswinkel an.<br/>            Lesen/Schreiben **float**. |
| [`skew_vertical`](/slides/python-net/de/aspose.slides.effects/reflection/skew_vertical/) | Gibt den vertikalen Schrägstellungswinkel an.<br/>            Lesen/Schreiben **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/de/aspose.slides.effects/reflection/rotate_shadow_with_shape/) | Gibt an, ob die Reflexion mit der Form rotiert werden soll, wenn die Form rotiert wird.<br/>            Lesen/Schreiben **bool**. |
| [`scale_horizontal`](/slides/python-net/de/aspose.slides.effects/reflection/scale_horizontal/) | Gibt den horizontalen Skalierungsfaktor an, negative Skalierung bewirkt ein Spiegeln. (Prozent)<br/>            Lesen/Schreiben **float**. |
| [`scale_vertical`](/slides/python-net/de/aspose.slides.effects/reflection/scale_vertical/) | Gibt den vertikalen Skalierungsfaktor an, negative Skalierung bewirkt ein Spiegeln. (Prozent)<br/>            Lesen/Schreiben **float**. |
