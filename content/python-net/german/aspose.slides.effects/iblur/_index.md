## IBlur Klasse

Stellt einen Blur-Effekt dar, der auf die gesamte Form, einschließlich ihrer Füllung, angewendet wird.
            Alle Farbkanäle, einschließlich Alpha, sind betroffen.

Der IBlur-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Property | Description |
| :- | :- |
| [`radius`](/slides/python-net/de/aspose.slides.effects/iblur/radius/) | Liefert oder setzt den Blur-Radius.<br/>            Read/write **float**. |
| [`grow`](/slides/python-net/de/aspose.slides.effects/iblur/grow/) | Bestimmt, ob die Begrenzungen des Objekts als Ergebnis des Blur-Effekts vergrößert werden sollen.<br/>            True gibt an, dass die Begrenzungen vergrößert werden, während false angibt, dass dies nicht der Fall ist.<br/>            Read/write **bool**. |
