## IOuterShadow Klasse

Stellt einen Outer Shadow-Effekt dar.

Der IOuterShadow Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Property | Description |
| :- | :- |
| [`blur_radius`](/slides/python-net/de/aspose.slides.effects/ioutershadow/blur_radius/) | Unschärferadius, in Punkten.<br/>            Standardwert – 0 pt.<br/>            Lese/Schreib **float**. |
| [`direction`](/slides/python-net/de/aspose.slides.effects/ioutershadow/direction/) | Richtung des Schattens, in Grad.<br/>            Standardwert – 0 ° (links nach rechts).<br/>            Lese/Schreib **float**. |
| [`distance`](/slides/python-net/de/aspose.slides.effects/ioutershadow/distance/) | Abstand des Schattens vom Objekt, in Punkten.<br/>            Standardwert – 0 pt.<br/>            Lese/Schreib **float**. |
| [`shadow_color`](/slides/python-net/de/aspose.slides.effects/ioutershadow/shadow_color/) | Farbe des Schattens.<br/>            Standardwert – automatisches Schwarz (themenabhängig).<br/>            Nur lesbar [`IColorFormat`](/slides/python-net/de/aspose.slides/icolorformat). |
| [`rectangle_align`](/slides/python-net/de/aspose.slides.effects/ioutershadow/rectangle_align/) | Rechteckausrichtung.<br/>            Standardwert – [`RectangleAlignment.BOTTOM`](/slides/python-net/de/aspose.slides/rectanglealignment/BOTTOM). <br/>            Lese/Schreib [`RectangleAlignment`](/slides/python-net/de/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/de/aspose.slides.effects/ioutershadow/skew_horizontal/) | Horizontaler Schrägwinkel, in Grad.<br/>            Standardwert – 0 °.<br/>            Lese/Schreib **float**. |
| [`skew_vertical`](/slides/python-net/de/aspose.slides.effects/ioutershadow/skew_vertical/) | Vertikaler Schrägwinkel, in Grad.<br/>            Standardwert – 0 °.<br/>            Lese/Schreib **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/de/aspose.slides.effects/ioutershadow/rotate_shadow_with_shape/) | Gibt an, ob der Schatten zusammen mit der Form rotiert.<br/>            Standardwert – true.<br/>            Lese/Schreib **bool**. |
| [`scale_horizontal`](/slides/python-net/de/aspose.slides.effects/ioutershadow/scale_horizontal/) | Horizontaler Skalierungsfaktor, in Prozent der Originalgröße.<br/>            Negative Skalierung bewirkt eine Spiegelung.<br/>            Standardwert – 100 %.<br/>            Lese/Schreib **float**. |
| [`scale_vertical`](/slides/python-net/de/aspose.slides.effects/ioutershadow/scale_vertical/) | Vertikaler Skalierungsfaktor, in Prozent der Originalgröße.<br/>            Negative Skalierung bewirkt eine Spiegelung.<br/>            Standardwert – 100 %.<br/>            Lese/Schreib **float**. |
