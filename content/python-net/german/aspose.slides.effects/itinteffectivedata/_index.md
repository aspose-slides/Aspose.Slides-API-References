## ITintEffectiveData Klasse

Unveränderliches Objekt, das einen Tint-Effekt darstellt.  
Verschiebt die Farbwerte des Effekts zum oder vom Farbton um den angegebenen Betrag.

Der Typ ITintEffectiveData stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`hue`](/slides/python-net/de/aspose.slides.effects/itinteffectivedata/hue/) | Gibt den Farbton zurück.<br/>            Nur lesbar **float**. |
| [`amount`](/slides/python-net/de/aspose.slides.effects/itinteffectivedata/amount/) | Gibt die Effektmenge zurück.<br/>            Nur lesbar **float**. |
