Enthält Klassen zur Arbeit mit verschiedenen Effekten in Microsoft PowerPoint-Präsentationen.

| [`AlphaBiLevel`](/slides/python-net/de/aspose.slides.effects/alphabilevel/) | Stellt einen Alpha Bi-Level Effekt dar.<br/>            Alpha (Opacity)-Werte, die unter dem Schwellenwert liegen, werden zu 0 (vollständig transparent) und<br/>            Alpha-Werte, die größer oder gleich dem Schwellenwert sind, werden zu 100% (vollständig undurchsichtig) geändert. |
| [`AlphaCeiling`](/slides/python-net/de/aspose.slides.effects/alphaceiling/) | Stellt einen Alpha Ceiling-Effekt dar.<br/>            Alpha (opacity)-Werte, die größer als null sind, werden zu 100% geändert.<br/>            Mit anderen Worten wird alles, das teilweise undurchsichtig ist, vollständig undurchsichtig. |
