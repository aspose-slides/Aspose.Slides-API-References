## IDuotoneEffectiveData Klasse

Unveränderliches Objekt, das einen Duotone-Effekt darstellt.
            Für jedes Pixel kombiniert es clr1 und clr2 mittels linearer Interpolation,
            um die neue Farbe für dieses Pixel zu bestimmen.

Der Typ IDuotoneEffectiveData stellt die folgenden Mitglieder bereit:

## Eigenschaften

| :- | :- |
| [`color1`](/slides/python-net/de/aspose.slides.effects/iduotoneeffectivedata/color1/) | Gibt das Zielfarbformat für dunkle Pixel zurück.<br/>            Nur lesend [`Color`](/slides/python-net/de/aspose.slides/color). |
| [`color2`](/slides/python-net/de/aspose.slides.effects/iduotoneeffectivedata/color2/) | Gibt das Zielfarbformat für helle Pixel zurück.<br/>            Nur lesend [`Color`](/slides/python-net/de/aspose.slides/color). |
