## IAlphaBiLevelEffectiveData Klasse

Unveränderliches Objekt, das einen Alpha-Bi-Level-Effekt darstellt.
            Alpha (Opacity) Werte, die kleiner als der Schwellenwert sind, werden auf 0 (vollständig transparent) gesetzt und
            alpha Werte, die größer oder gleich dem Schwellenwert sind, werden auf 100 % (vollständig undurchsichtig) gesetzt.
