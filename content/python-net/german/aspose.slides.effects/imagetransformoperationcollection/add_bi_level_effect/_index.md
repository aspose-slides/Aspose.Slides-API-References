## add_bi_level_effect(self, threshold) {#float}
Fügt den neuen Bi-Level- (Schwarz/Weiß-) Effekt am Ende einer Sammlung hinzu.

### Rückgabewert

Index des neuen Bildeffekts in einer Sammlung.



```python
def add_bi_level_effect(self, threshold):
    ...
```


| Parameter | Typ | Beschreibung |
| :- | :- | :- |
| threshold | **float** | der Luminanz-Schwellenwert für den Bi-Level-Effekt.<br/><br/>            Werte, die größer oder gleich dem Schwellenwert sind, werden auf Weiß gesetzt.<br/><br/>            Werte, die kleiner als der Schwellenwert sind, werden auf Schwarz gesetzt. |
