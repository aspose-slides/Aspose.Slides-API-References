## IExcelDataCell Klasse

Stellt eine einzelne Zelle in einer Excel-Arbeitsmappe dar.

Der Typ IExcelDataCell stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`value`](/slides/python-net/de/aspose.slides.excel/iexceldatacell/value/) | Ermittelt den in der Excel-Zelle enthaltenen Wert.<br/>            Nur lesend **any**. |
| [`name`](/slides/python-net/de/aspose.slides.excel/iexceldatacell/name/) | Ermittelt den Namen der Diagrammdatenzelle.<br/>            Nur lesend **str**. |
| [`row`](/slides/python-net/de/aspose.slides.excel/iexceldatacell/row/) | Ermittelt den nullbasierten Index der Zeile im Arbeitsblatt, in dem sich die Zelle befindet.<br/>            Nur lesend **int**. |
| [`column`](/slides/python-net/de/aspose.slides.excel/iexceldatacell/column/) | Ermittelt den nullbasierten Index der Spalte im Arbeitsblatt, in dem sich die Zelle befindet.<br/>            Nur lesend **int**. |
