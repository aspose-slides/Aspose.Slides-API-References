## IExcelDataWorkbook Klasse

Represents a workbook that provides access to Excel data for general use.

Der Typ IExcelDataWorkbook stellt die folgenden Mitglieder bereit:

| Methode | Beschreibung |

| [`get_cell(self, worksheet_name, row, column)`](/slides/python-net/de/aspose.slides.excel/iexceldataworkbook/get_cell/#str-int-int) | Ruft eine Zelle aus dem angegebenen Arbeitsblatt anhand ihres Namens und der Zellenkoordinaten ab. |
