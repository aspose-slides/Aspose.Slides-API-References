## ExcelDataCell Klasse

Stellt eine einzelne Zelle in einer Excel-Arbeitsmappe dar.

Der Typ ExcelDataCell stellt die folgenden Member bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`value`](/slides/python-net/de/aspose.slides.excel/exceldatacell/value/) | Liefert den in der Excel-Zelle enthaltenen Wert. |
| [`name`](/slides/python-net/de/aspose.slides.excel/exceldatacell/name/) | Liefert den Namen der Diagrammdatenzelle. |
| [`row`](/slides/python-net/de/aspose.slides.excel/exceldatacell/row/) | Liefert den nullbasierten Index der Zeile im Arbeitsblatt, in dem sich die Zelle befindet.<br/>            Nur lesbar **int**. |
| [`column`](/slides/python-net/de/aspose.slides.excel/exceldatacell/column/) | Liefert den nullbasierten Index der Spalte im Arbeitsblatt, in dem sich die Zelle befindet.<br/>            Nur lesbar **int**. |
