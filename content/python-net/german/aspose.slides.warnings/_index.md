## Klassen

| Klasse | Beschreibung |
| :- | :- |
| [`IKnownIssueWarningInfo`](/slides/python-net/de/aspose.slides.warnings/iknownissuewarninginfo/) | Stellt eine Warnung über ein bekanntes Problem dar, das in naher Zukunft nicht behoben wird. |
| [`INotImplementedWarningInfo`](/slides/python-net/de/aspose.slides.warnings/inotimplementedwarninginfo/) | Stellt eine Warnung über ein bekanntes, nicht implementiertes Feature dar, das in naher Zukunft nicht implementiert wird. |
| [`IObsoletePresLockingBehaviorWarningInfo`](/slides/python-net/de/aspose.slides.warnings/iobsoletepreslockingbehaviorwarninginfo/) | Diese Warnung weist darauf hin, dass ein veraltetes Präsentations-Sperrverhalten verwendet wird. |
| [`IPresentationSignedWarningInfo`](/slides/python-net/de/aspose.slides.warnings/ipresentationsignedwarninginfo/) | Diese Warnung weist darauf hin, dass die eingelesene Präsentation die Signatur hat <br/>            und diese Signatur während der Verarbeitung entfernt wird. |
| [`IWarningCallback`](/slides/python-net/de/aspose.slides.warnings/iwarningcallback/) | Schnittstelle für Klassen, die Warnungen empfangen |
| [`IWarningInfo`](/slides/python-net/de/aspose.slides.warnings/iwarninginfo/) | Stellt eine Basisschnittstelle für alle Warnungen dar. |
