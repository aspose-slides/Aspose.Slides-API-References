## WarningType Aufzählung

Stellt einen Warnungstyp dar.

Der Typ WarningType stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| SOURCE_FILE_CORRUPTION | Ein Problem wurde im Quell-Dokument festgestellt, das die Wahrscheinlichkeit sehr hoch macht, dass das Dokument nicht geöffnet werden kann, wenn es im ursprünglichen Format gespeichert wird. |
| DATA_LOSS | Text/Diagramm/Bild oder andere Daten gehen nach dem Laden vollständig im Dokumentenbaum verloren oder fehlen im erstellten Dokument nach dem Speichern. |
| MAJOR_FORMATTING_LOSS | Großer Formatierungsverlust. |
| MINOR_FORMATTING_LOSS | Geringer Formatierungsverlust. |
| COMPATIBILITY_ISSUE | Dies ist ein bekanntes Problem, das verhindert, dass das Dokument von bestimmten User-Agents oder älteren Versionen von User-Agents geöffnet wird. |
| UNEXPECTED_CONTENT | Einige Inhalte im Quell-Dokument konnten nicht erkannt werden (d. h. werden nicht unterstützt); dies kann zu Problemen führen oder Daten-/Formatierungsverlust verursachen. |
