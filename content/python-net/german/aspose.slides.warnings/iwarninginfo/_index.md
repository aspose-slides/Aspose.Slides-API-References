## IWarningInfo Klasse

Stellt eine Basisschnittstelle für alle Warnungen dar.

Der Typ IWarningInfo stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`warning_type`](/slides/python-net/de/aspose.slides.warnings/iwarninginfo/warning_type/) | Gibt einen Typ der Warnung zurück.<br/>            Nur lesbar [`IWarningInfo.warning_type`](/slides/python-net/de/aspose.slides.warnings/iwarninginfo/warning_type). |
| [`description`](/slides/python-net/de/aspose.slides.warnings/iwarninginfo/description/) | Gibt eine menschenlesbare Beschreibung dieser Warnung zurück.<br/>            Nur lesbar **str**. |

## Methoden

| Methode | Beschreibung |
| :- | :- |
| [`send_warning(self, receiver)`](/slides/python-net/de/aspose.slides.warnings/iwarninginfo/send_warning/#iwarningcallback) | Wenn receiver nicht None ist, beendet die Warnung für einen angegebenen Empfänger und wirft die <br/>            AbortRequestedException, wenn der Empfänger beschlossen hat, einen Vorgang abzubrechen. |
