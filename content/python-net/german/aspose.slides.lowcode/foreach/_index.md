## ForEach Klasse

Stellt eine Gruppe von Methoden dar, die dazu bestimmt sind, über verschiedene [`Presentation`](/slides/python-net/de/aspose.slides/presentation) Modellobjekte zu iterieren.  
Diese Methoden können nützlich sein, wenn Sie über einige Elemente von Presentation iterieren und deren Formatierung oder Inhalt ändern müssen, z. B. die Formatierung jeder Portion ändern.
