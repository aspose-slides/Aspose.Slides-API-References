Enthält Klassen und Methoden zur Handhabung komplexer allgemeiner Operationen auf Low-Code-Weise.
## Klassen

| Klasse | Beschreibung |
| :- | :- |
| [`Collect`](/slides/python-net/de/aspose.slides.lowcode/collect/) | Stellt eine Gruppe von Methoden dar, die dazu bestimmt sind, Modellobjekte verschiedener Typen von [`Presentation`](/slides/python-net/de/aspose.slides/presentation) zu sammeln. |
| [`Compress`](/slides/python-net/de/aspose.slides.lowcode/compress/) | Stellt eine Gruppe von Methoden dar, die dazu bestimmt sind, [`Presentation`](/slides/python-net/de/aspose.slides/presentation) zu komprimieren. |
| [`Convert`](/slides/python-net/de/aspose.slides.lowcode/convert/) | Stellt eine Gruppe von Methoden dar, die dazu bestimmt sind, [`Presentation`](/slides/python-net/de/aspose.slides/presentation) zu konvertieren. |
| [`ForEach`](/slides/python-net/de/aspose.slides.lowcode/foreach/) | Stellt eine Gruppe von Methoden dar, die dazu bestimmt sind, über verschiedene [`Presentation`](/slides/python-net/de/aspose.slides/presentation) Modellobjekte zu iterieren.<br/>            Diese Methoden können nützlich sein, wenn Sie über einige Presentation' Elemente iterieren und deren Formatierung oder Inhalt ändern müssen,<br/>             z. B. die Formatierung jedes Abschnitts ändern. |
| [`Merger`](/slides/python-net/de/aspose.slides.lowcode/merger/) | Stellt eine Gruppe von Methoden für das Zusammenführen von PowerPoint-Präsentationen desselben Formats in einer Datei dar. |
