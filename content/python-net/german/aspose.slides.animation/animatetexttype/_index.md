## AnimateTextType Aufzählung

Stellt den animierten Texttyp eines Animationseffekts dar.

Der Typ AnimateTextType enthält die folgenden Mitglieder:

## Felder

| Feld | Beschreibung |
| :- | :- |
| ALL_AT_ONCE | Animiert den gesamten Text auf einmal. |
| BY_WORD | Animiert Text nach Wort. |
| BY_LETTER | Animiert Text nach Buchstaben. |
