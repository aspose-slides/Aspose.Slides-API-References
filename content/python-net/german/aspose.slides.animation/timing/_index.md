## Timing-Klasse

Stellt die Animationszeit dar.

Der Timing-Typ stellt die folgenden Member bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`accelerate`](/slides/python-net/de/aspose.slides.animation/timing/accelerate/) | Beschreibt den Prozentsatz des Beschleunigungsverhaltens über die Dauer.<br/>            Lesen/Schreiben **float**. |
| [`decelerate`](/slides/python-net/de/aspose.slides.animation/timing/decelerate/) | Beschreibt den Prozentsatz des Verzögerungsverhaltens über die Dauer.<br/>            Lesen/Schreiben **float**. |
| [`auto_reverse`](/slides/python-net/de/aspose.slides.animation/timing/auto_reverse/) | Beschreibt, ob die Animation nach dem Abspielen in Vorwärtsrichtung automatisch rückwärts abgespielt wird.<br/>            Lesen/Schreiben **bool**. |
| [`duration`](/slides/python-net/de/aspose.slides.animation/timing/duration/) | Beschreibt die Dauer des Animationseffekts.<br/>            Lesen/Schreiben **float**. |
| [`repeat_count`](/slides/python-net/de/aspose.slides.animation/timing/repeat_count/) | Beschreibt, wie oft der Effekt wiederholt werden soll.<br/>            Lesen/Schreiben **float**. |
| [`repeat_until_end_slide`](/slides/python-net/de/aspose.slides.animation/timing/repeat_until_end_slide/) | Dieses Attribut gibt an, ob der Effekt bis zum Ende der Folie wiederholt wird.<br/>             Lesen/Schreiben **bool**. |
| [`repeat_until_next_click`](/slides/python-net/de/aspose.slides.animation/timing/repeat_until_next_click/) | Dieses Attribut gibt an, ob der Effekt bis zum nächsten Klick wiederholt wird.<br/>             Lesen/Schreiben **bool**. |
| [`repeat_duration`](/slides/python-net/de/aspose.slides.animation/timing/repeat_duration/) | Beschreibt, wie oft der Effekt wiederholt werden soll.<br/>            Lesen/Schreiben **float**. |
| [`restart`](/slides/python-net/de/aspose.slides.animation/timing/restart/) | Gibt an, ob ein Effekt nach dem Abschluss neu gestartet werden soll.<br/>            Lesen/Schreiben [`EffectRestartType`](/slides/python-net/de/aspose.slides.animation/effectrestarttype). |
| [`rewind`](/slides/python-net/de/aspose.slides.animation/timing/rewind/) | Dieses Attribut gibt an, ob der Effekt nach dem Abspielen zurückgespult wird.<br/>             Lesen/Schreiben **bool**. |
| [`speed`](/slides/python-net/de/aspose.slides.animation/timing/speed/) | Gibt den Prozentsatz an, um den die Zeitbeschleunigung (oder -verlangsamung) erhöht wird.<br/>            Lesen/Schreiben **float**. |
| [`trigger_delay_time`](/slides/python-net/de/aspose.slides.animation/timing/trigger_delay_time/) | Beschreibt die Verzögerungszeit nach dem Auslöser.<br/>            Lesen/Schreiben **float**. |
| [`trigger_type`](/slides/python-net/de/aspose.slides.animation/timing/trigger_type/) | Beschreibt den Auslösertyp.<br/>            Lesen/Schreiben [`EffectTriggerType`](/slides/python-net/de/aspose.slides.animation/effecttriggertype). |
