## BuildType-Aufzählung

Bestimmt, wie Text während einer Animation auf einer Form angezeigt wird.

Der Typ BuildType stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| AS_ONE_OBJECT | Mit enthaltender Form. |
| ALL_PARAGRAPHS_AT_ONCE | Alle Absätze. |
| BY_LEVEL_PARAGRAPHS1 | Nach Gruppen von Absätzen der Tiefe 1. |
| BY_LEVEL_PARAGRAPHS2 | Nach Gruppen von Absätzen der Tiefe 2. |
| BY_LEVEL_PARAGRAPHS3 | Nach Gruppen von Absätzen der Tiefe 3. |
| BY_LEVEL_PARAGRAPHS4 | Nach Gruppen von Absätzen der Tiefe 4. |
| BY_LEVEL_PARAGRAPHS5 | Nach Gruppen von Absätzen der Tiefe 5. |
