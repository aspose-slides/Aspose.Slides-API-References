## EffectChartMinorGroupingType Aufzählung

Stellt den Typ eines Animationseffekts für das Diagrammelement in einer Serie oder Kategorie dar.

Der Typ EffectChartMinorGroupingType stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| BY_ELEMENT_IN_SERIES | Diagramm nach Element in Serie animieren |
| BY_ELEMENT_IN_CATEGORY | Diagramm nach Element in Kategorie animieren |
