## AnimationTimeLine Klasse

Stellt die Zeitleiste der Animation dar.

Der Typ AnimationTimeLine stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`interactive_sequences`](/slides/python-net/de/aspose.slides.animation/animationtimeline/interactive_sequences/) | Gibt die Sammlung interaktiver Sequenzen zurück.<br/>            Diese Sequenzen können nur Effekte durch "click on shape" mit spezifizierter Ziel-Form enthalten.<br/>            Nur lesbar [`ISequenceCollection`](/slides/python-net/de/aspose.slides.animation/isequencecollection). |
| [`main_sequence`](/slides/python-net/de/aspose.slides.animation/animationtimeline/main_sequence/) | Gibt die Hauptsequenz zurück, die nur die Haupt-Effekt-Sammlung enthalten kann.<br/>            Nur lesbar [`ISequence`](/slides/python-net/de/aspose.slides.animation/isequence). |
| [`text_animation_collection`](/slides/python-net/de/aspose.slides.animation/animationtimeline/text_animation_collection/) | Gibt die Sammlung von Textanimationen zurück.<br/>            Nur lesbar [`ITextAnimationCollection`](/slides/python-net/de/aspose.slides.animation/itextanimationcollection). |
