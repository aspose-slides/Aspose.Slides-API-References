## BehaviorCollection Klasse

Stellt eine Sammlung von Verhaltens-Effekten dar.

Der Typ BehaviorCollection stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`count`](/slides/python-net/de/aspose.slides.animation/behaviorcollection/count/) | Gibt die Anzahl der Verhaltensweisen in einer Sammlung zurück.<br/>            Nur-Lesen **int**. |
| [`is_read_only`](/slides/python-net/de/aspose.slides.animation/behaviorcollection/is_read_only/) | Ermittelt einen Wert, der anzeigt, ob die **System.Collections.Generic.ICollection`1** schreibgeschützt ist.<br/>            Nur-Lesen **bool**. |

Gibt ein Verhalten am angegebenen Index zurück.
