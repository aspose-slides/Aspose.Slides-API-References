## ITiming Klasse

Stellt die Animationszeit dar.

Der ITiming-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`accelerate`](/slides/python-net/de/aspose.slides.animation/itiming/accelerate/) | Beschreibt den Prozentsatz der Beschleunigungswirkung der Dauer.<br/>            Lesen/Schreiben **float**. |
| [`decelerate`](/slides/python-net/de/aspose.slides.animation/itiming/decelerate/) | Beschreibt den Prozentsatz der Verzögerungswirkung der Dauer.<br/>            Lesen/Schreiben **float**. |
| [`auto_reverse`](/slides/python-net/de/aspose.slides.animation/itiming/auto_reverse/) | Beschreibt, ob die Animation nach dem Abspielen in Vorwärtsrichtung automatisch rückwärts abgespielt werden soll.<br/>            Lesen/Schreiben **bool**. |
| [`duration`](/slides/python-net/de/aspose.slides.animation/itiming/duration/) | Beschreibt die Dauer des Animationseffekts.<br/>            Lesen/Schreiben **float**. |
| [`repeat_count`](/slides/python-net/de/aspose.slides.animation/itiming/repeat_count/) | Beschreibt die Anzahl der Wiederholungen des Effekts.<br/>            Lesen/Schreiben **float**. |
| [`repeat_until_end_slide`](/slides/python-net/de/aspose.slides.animation/itiming/repeat_until_end_slide/) | Dieses Attribut legt fest, ob der Effekt bis zum Ende der Folie wiederholt wird.<br/>            Lesen/Schreiben **bool**. |
| [`repeat_until_next_click`](/slides/python-net/de/aspose.slides.animation/itiming/repeat_until_next_click/) | Dieses Attribut legt fest, ob der Effekt bis zum nächsten Klick wiederholt wird.<br/>            Lesen/Schreiben **bool**. |
| [`repeat_duration`](/slides/python-net/de/aspose.slides.animation/itiming/repeat_duration/) | Beschreibt die Anzahl der Wiederholungen des Effekts.<br/>            Lesen/Schreiben **float**. |
| [`restart`](/slides/python-net/de/aspose.slides.animation/itiming/restart/) | Gibt an, ob ein Effekt nach Abschluss neu gestartet werden soll.<br/>            Lesen/Schreiben [`EffectRestartType`](/slides/python-net/de/aspose.slides.animation/effectrestarttype). |
| [`speed`](/slides/python-net/de/aspose.slides.animation/itiming/speed/) | Gibt den Prozentsatz an, um den die Timing-Geschwindigkeit beschleunigt (oder verlangsamt) wird.<br/>            Lesen/Schreiben **float**. |
| [`trigger_delay_time`](/slides/python-net/de/aspose.slides.animation/itiming/trigger_delay_time/) | Beschreibt die Verzögerungszeit nach dem Auslösen.<br/>            Lesen/Schreiben **float**. |
| [`trigger_type`](/slides/python-net/de/aspose.slides.animation/itiming/trigger_type/) | Beschreibt den Auslösertyp.<br/>            Lesen/Schreiben [`EffectTriggerType`](/slides/python-net/de/aspose.slides.animation/effecttriggertype). |
| [`rewind`](/slides/python-net/de/aspose.slides.animation/itiming/rewind/) | Dieses Attribut legt fest, ob der Effekt nach dem Abspielen zurückgespult wird.<br/>            Lesen/Schreiben **bool**. |
