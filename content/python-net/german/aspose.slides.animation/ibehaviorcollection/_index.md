## IBehaviorCollection Klasse

Stellt eine Sammlung von Verhaltenseffekten dar.

Der IBehaviorCollection-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Property | Beschreibung |
| :- | :- |
| [`count`](/slides/python-net/de/aspose.slides.animation/ibehaviorcollection/count/) | Gibt die Anzahl der Verhaltensweisen in einer Sammlung zurück.<br/>            Nur-Lesen **int**. |

Gibt ein Verhalten am angegebenen Index zurück.
