## SlideShowTransition Klasse

Stellt den Folienübergang dar.

Der SlideShowTransition-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`sound`](/slides/python-net/de/aspose.slides.slideshow/slideshowtransition/sound/) | Gibt die eingebetteten Audiodaten zurück oder legt sie fest.<br/>            Lesen/Schreiben [`IAudio`](/slides/python-net/de/aspose.slides/iaudio). |
| [`sound_mode`](/slides/python-net/de/aspose.slides.slideshow/slideshowtransition/sound_mode/) | Setzt oder gibt den Soundmodus für den Folienübergang zurück.<br/>            Lesen/Schreiben [`TransitionSoundMode`](/slides/python-net/de/aspose.slides.slideshow/transitionsoundmode). |
| [`sound_loop`](/slides/python-net/de/aspose.slides.slideshow/slideshowtransition/sound_loop/) | Dieses Attribut gibt an, ob der Sound in<br/>            der Diashow wiederholt wird, bis das nächste Soundereignis eintritt.<br/>            Lesen/Schreiben **bool**. |
| [`advance_on_click`](/slides/python-net/de/aspose.slides.slideshow/slideshowtransition/advance_on_click/) | Gibt an, ob ein Mausklick die Folie weiterbewegt oder nicht. Wenn dieses Attribut nicht<br/>            angegeben ist, wird ein Wert von true angenommen.<br/>            Lesen/Schreiben **bool**. |
| [`advance_after`](/slides/python-net/de/aspose.slides.slideshow/slideshowtransition/advance_after/) | Dieses Attribut gibt an, ob die Diashow nach einer bestimmten Zeit zur nächsten Folie wechselt.<br/>            Lesen/Schreiben **bool**. |
| [`advance_after_time`](/slides/python-net/de/aspose.slides.slideshow/slideshowtransition/advance_after_time/) | Gibt die Zeit in Millisekunden an, nach der der Übergang beginnen soll. Diese Einstellung<br/>            kann in Verbindung mit dem advClick-Attribut verwendet werden. Wenn dieses Attribut nicht angegeben<br/>            wird, wird angenommen, dass kein automatischer Fortschritt erfolgt.<br/>            Lesen/Schreiben **int**. |
| [`speed`](/slides/python-net/de/aspose.slides.slideshow/slideshowtransition/speed/) | Gibt die Übergangsgeschwindigkeit an, die beim Übergang von der aktuellen Folie<br/>            zur nächsten verwendet werden soll.<br/>            Lesen/Schreiben [`TransitionSpeed`](/slides/python-net/de/aspose.slides.slideshow/transitionspeed). |
| [`value`](/slides/python-net/de/aspose.slides.slideshow/slideshowtransition/value/) | Wert des Folienübergangs.<br/>            Nur-Lesen [`ITransitionValueBase`](/slides/python-net/de/aspose.slides.slideshow/itransitionvaluebase). |
| [`type`](/slides/python-net/de/aspose.slides.slideshow/slideshowtransition/type/) | Typ des Übergangs.<br/>            Lesen/Schreiben [`TransitionType`](/slides/python-net/de/aspose.slides.slideshow/transitiontype). |
| [`sound_is_built_in`](/slides/python-net/de/aspose.slides.slideshow/slideshowtransition/sound_is_built_in/) | Gibt an, ob dieser Sound ein integrierter Sound ist oder nicht. Wenn dieses Attribut auf true gesetzt ist, dann<br/>            wird die erzeugende Anwendung darauf hingewiesen, das Namensattribut, das für diesen Sound angegeben wurde,<br/>            in ihrer Liste integrierter Sounds zu prüfen und kann dann bei Bedarf einen benutzerdefinierten Namen oder eine UI bereitstellen.<br/>            Lesen/Schreiben **bool**. |
| [`sound_name`](/slides/python-net/de/aspose.slides.slideshow/slideshowtransition/sound_name/) | Gibt einen menschenlesbaren Namen für den Sound des Übergangs an. Die [`SlideShowTransition.sound`](/slides/python-net/de/aspose.slides.slideshow/slideshowtransition/sound)-Eigenschaft muss zugewiesen werden, um den Soundnamen zu erhalten oder festzulegen.<br/>            Lesen/Schreiben **str**. |
| [`duration`](/slides/python-net/de/aspose.slides.slideshow/slideshowtransition/duration/) | Gibt die Dauer des Folienübergangseffekts in Millisekunden zurück oder legt sie fest.<br/>            Lesen/Schreiben **int**. |
