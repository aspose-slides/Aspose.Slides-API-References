## TransitionMorphType Aufzählung

Repräsentiert einen Typ eines Morph-Übergangs.

Der Typ TransitionMorphType stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| BY_OBJECT | Der Morph-Übergang wird durchgeführt, indem Formen als unteilbare Objekte betrachtet werden. |
| BY_WORD | Der Morph-Übergang wird durchgeführt, indem nach Möglichkeit Text Wort für Wort übertragen wird. |
| BY_CHAR | Der Morph-Übergang wird durchgeführt, indem nach Möglichkeit Text Zeichen für Zeichen übertragen wird. |
