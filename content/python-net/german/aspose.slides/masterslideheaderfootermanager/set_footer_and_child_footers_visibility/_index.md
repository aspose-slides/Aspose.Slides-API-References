## set_footer_and_child_footers_visibility(self, is_visible) {#bool}
Ändert die Sichtbarkeit des Fußzeilen-Platzhalters der Masterfolie und aller untergeordneten Fußzeilen-Platzhalter.
            Untergeordnete Platzhalter bedeuten, dass Platzhalter auf abhängigen Layout-Folien und abhängigen Folien enthalten sind.
            Abhängige Layout-Folien und Folien verwenden und hängen von der Masterfolie ab.

```python
    ...
```


| Parameter | Typ | Beschreibung |
| :- | :- | :- |
| is_visible | **bool** | true - macht die Fußzeilen-Platzhalter sichtbar, andernfalls - blendet sie aus. |
