## ImageFormat Aufzählung

Stellt das Dateiformat des Bildes dar.

Der Typ ImageFormat stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| MEMORY_BMP | Stellt das Format eines Bitmaps im Speicher dar. |
| BMP | Stellt das Bildformat Bitmap (BMP) dar. |
| EMF | Stellt das erweiterte Metadatei (EMF) Bildformat dar. |
| WMF | Stellt das Windows-Metadatei (WMF) Bildformat dar. |
| GIF | Stellt das Graphics Interchange Format (GIF) Bildformat dar. |
| JPEG | Stellt das Joint Photographic Experts Group (JPEG) Bildformat dar. |
| PNG | Stellt das W3C Portable Network Graphics (PNG) Bildformat dar. |
| TIFF | Stellt das Tagged Image File Format (TIFF) Bildformat dar. |
| EXIF | Stellt das Exchangeable Image File (Exif) Format dar. |
| ICON | Stellt das Windows-Icon Bildformat dar. |
