## position Eigenschaft
Gibt die Position der Zeichenhilfe zurück oder legt sie fest, angegeben in Punkten vom oberen linken Rand der Folie.
            Lesen/Schreiben **float**.


### Hinweise

Der typische Wertebereich reicht von 0 bis zur Folienhöhe für einen horizontalen Leitfaden und von 0 bis zur Folienbreite für einen vertikalen Leitfaden.
