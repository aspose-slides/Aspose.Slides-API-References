## SensitivityLabelAssignmentType Aufzählung

Stellt die Zuweisungsmethode für das Sensitivitätslabel dar.

Der Typ SensitivityLabelAssignmentType stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| STANDARD | Verwendung für jedes Sensitivitätslabel, das nicht direkt vom Benutzer angewendet wurde. <br/>            Dies umfasst alle Standard-Labels und automatisch angewendete Labels. |
| PRIVILEGED | Verwendung für jedes Sensitivitätslabel, das direkt vom Benutzer angewendet wurde. <br/>            Dies umfasst alle manuell angewendeten Sensitivitätslabels sowie empfohlene<br/>            oder verpflichtende Kennzeichnungen oder jede Funktion, bei der der Benutzer entscheidet, welches Sensitivitätslabel angewendet werden soll. |
