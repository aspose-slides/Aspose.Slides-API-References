## IColorFormat Klasse

Stellt eine in einer Präsentation verwendete Farbe dar.

Der IColorFormat-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`color_type`](/slides/python-net/de/aspose.slides/icolorformat/color_type/) | Liefert oder setzt die Farbbestimmungsmethode.<br/>            Lesen/Schreiben [`ColorType`](/slides/python-net/de/aspose.slides/colortype). |
| [`color`](/slides/python-net/de/aspose.slides/icolorformat/color/) | Liefert die resultierende Farbe (mit allen angewendeten Farbtransformationen).<br/>            Setzt RGB-Farben und löscht alle Farbtransformationen.<br/>            Lesen/Schreiben **aspose.slides.Color**. |
| [`preset_color`](/slides/python-net/de/aspose.slides/icolorformat/preset_color/) | Liefert oder setzt die Farb-Voreinstellung.<br/>            Lesen/Schreiben [`PresetColor`](/slides/python-net/de/aspose.slides/presetcolor). |
| [`system_color`](/slides/python-net/de/aspose.slides/icolorformat/system_color/) | Liefert oder setzt die durch die Systemfarbtabelle identifizierte Farbe.<br/>            Lesen/Schreiben [`SystemColor`](/slides/python-net/de/aspose.slides/systemcolor). |
| [`scheme_color`](/slides/python-net/de/aspose.slides/icolorformat/scheme_color/) | Liefert oder setzt die durch ein Farbschema identifizierte Farbe.<br/>            Lesen/Schreiben [`SchemeColor`](/slides/python-net/de/aspose.slides/schemecolor). |
| [`r`](/slides/python-net/de/aspose.slides/icolorformat/r/) | Liefert oder setzt die rote Komponente einer Farbe. Alle Farbtransformationen werden ignoriert.<br/>            Lesen/Schreiben **int**. |
| [`g`](/slides/python-net/de/aspose.slides/icolorformat/g/) | Liefert oder setzt die grüne Komponente einer Farbe. Alle Farbtransformationen werden ignoriert.<br/>            Lesen/Schreiben **int**. |
| [`b`](/slides/python-net/de/aspose.slides/icolorformat/b/) | Liefert oder setzt die blaue Komponente einer Farbe. Alle Farbtransformationen werden ignoriert.<br/>            Lesen/Schreiben **int**. |
| [`float_r`](/slides/python-net/de/aspose.slides/icolorformat/float_r/) | Liefert oder setzt die rote Komponente einer Farbe. Alle Farbtransformationen werden ignoriert.<br/>            Lesen/Schreiben **float**. |
| [`float_g`](/slides/python-net/de/aspose.slides/icolorformat/float_g/) | Liefert oder setzt die grüne Komponente einer Farbe. Alle Farbtransformationen werden ignoriert.<br/>            Lesen/Schreiben **float**. |
| [`float_b`](/slides/python-net/de/aspose.slides/icolorformat/float_b/) | Liefert oder setzt die blaue Komponente einer Farbe. Alle Farbtransformationen werden ignoriert.<br/>            Lesen/Schreiben **float**. |
| [`hue`](/slides/python-net/de/aspose.slides/icolorformat/hue/) | Liefert oder setzt die Farbton-Komponente einer Farbe in HSL-Darstellung.<br/>            Alle Farbtransformationen werden ignoriert.<br/>            Lesen/Schreiben **float**. |
| [`saturation`](/slides/python-net/de/aspose.slides/icolorformat/saturation/) | Liefert oder setzt die Sättigungs-Komponente einer Farbe in HSL-Darstellung.<br/>            Alle Farbtransformationen werden ignoriert.<br/>            Lesen/Schreiben **float**. |
| [`luminance`](/slides/python-net/de/aspose.slides/icolorformat/luminance/) | Liefert oder setzt die Luminanz-Komponente einer Farbe in HSL-Darstellung.<br/>            Alle Farbtransformationen werden ignoriert.<br/>            Lesen/Schreiben **float**. |
| [`color_transform`](/slides/python-net/de/aspose.slides/icolorformat/color_transform/) | Liefert die Sammlung der auf eine Farbe angewendeten Farbtransformationen.<br/>            Nur-Lesen [`IColorOperationCollection`](/slides/python-net/de/aspose.slides/icoloroperationcollection). |
