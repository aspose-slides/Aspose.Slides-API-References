## IShapeFrame Klasse

Stellt die Eigenschaften des Shape-Frames dar.

Der IShapeFrame-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`x`](/slides/python-net/de/aspose.slides/ishapeframe/x/) | Gibt die X-Koordinate der oberen linken Ecke eines Rahmens zurück.<br/>            Nur-Lesen **float**. |
| [`y`](/slides/python-net/de/aspose.slides/ishapeframe/y/) | Gibt die Y-Koordinate der oberen linken Ecke eines Rahmens zurück.<br/>            Nur-Lesen **float**. |
| [`width`](/slides/python-net/de/aspose.slides/ishapeframe/width/) | Gibt die Breite eines Rahmens zurück.<br/>            Nur-Lesen **float**. |
| [`height`](/slides/python-net/de/aspose.slides/ishapeframe/height/) | Gibt die Höhe eines Rahmens zurück.<br/>            Nur-Lesen **float**. |
| [`rotation`](/slides/python-net/de/aspose.slides/ishapeframe/rotation/) | Gibt die Anzahl der Grad zurück, um die ein Rahmen um die Z-Achse gedreht ist. Ein positiver Wert bedeutet eine Drehung im Uhrzeigersinn; ein negativer Wert bedeutet eine Drehung gegen den Uhrzeigersinn.<br/>            Nur-Lesen **float**. |
| [`center_x`](/slides/python-net/de/aspose.slides/ishapeframe/center_x/) | Gibt die X-Koordinate des Zentrums eines Rahmens zurück.<br/>            Nur-Lesen **float**. |
| [`center_y`](/slides/python-net/de/aspose.slides/ishapeframe/center_y/) | Gibt die Y-Koordinate des Zentrums eines Rahmens zurück.<br/>            Nur-Lesen **float**. |
| [`flip_h`](/slides/python-net/de/aspose.slides/ishapeframe/flip_h/) | Ermittelt, ob ein Rahmen horizontal gespiegelt ist.<br/>            Nur-Lesen [`NullableBool`](/slides/python-net/de/aspose.slides/nullablebool). |
| [`flip_v`](/slides/python-net/de/aspose.slides/ishapeframe/flip_v/) | Ermittelt, ob ein Rahmen vertikal gespiegelt ist.<br/>            Nur-Lesen [`NullableBool`](/slides/python-net/de/aspose.slides/nullablebool). |
| [`rectangle`](/slides/python-net/de/aspose.slides/ishapeframe/rectangle/) | Gibt die Koordinaten eines Rahmens zurück.<br/>            Nur-Lesen [`RectangleF`](/slides/python-net/de/aspose.slides/rectanglef). |
