## Captions Klasse

Stellt die WebVTT-Untertitel dar.

Der Captions-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`caption_id`](/slides/python-net/de/aspose.slides/captions/caption_id/) | Gibt die global eindeutige Kennung (GUID) der Untertitel zurück.<br/>            Nur lesend **System.Guid**. |
| [`label`](/slides/python-net/de/aspose.slides/captions/label/) | Gibt die Bezeichnung der Untertitel zurück oder setzt sie.<br/>            Lesen/Schreiben **str**. |
| [`binary_data`](/slides/python-net/de/aspose.slides/captions/binary_data/) | Gibt die Binärdaten der Untertitel zurück.<br/>            Nur lesend **int**[]. |
| [`data_as_string`](/slides/python-net/de/aspose.slides/captions/data_as_string/) | Gibt die Untertitel-Daten als UTF-8 kodierten String zurück<br/>            Nur lesend **str**. |
