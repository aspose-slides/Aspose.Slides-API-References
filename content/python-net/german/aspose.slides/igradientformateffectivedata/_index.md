## IGradientFormatEffectiveData Klasse

Unveränderliches Objekt, das effektive Gradient-Füllungseigenschaften enthält.

Der Typ IGradientFormatEffectiveData stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`tile_flip`](/slides/python-net/de/aspose.slides/igradientformateffectivedata/tile_flip/) | Gibt den Spiegelungsmodus für einen Gradient zurück.<br/>            Nur-Lesen [`TileFlip`](/slides/python-net/de/aspose.slides/tileflip). |
| [`gradient_direction`](/slides/python-net/de/aspose.slides/igradientformateffectivedata/gradient_direction/) | Gibt den Stil eines Gradienten zurück.<br/>            Nur-Lesen [`GradientDirection`](/slides/python-net/de/aspose.slides/gradientdirection). |
| [`linear_gradient_angle`](/slides/python-net/de/aspose.slides/igradientformateffectivedata/linear_gradient_angle/) | Gibt den Winkel eines Gradienten zurück.<br/>            Nur-Lesen **float**. |
| [`linear_gradient_scaled`](/slides/python-net/de/aspose.slides/igradientformateffectivedata/linear_gradient_scaled/) | Bestimmt, ob ein Gradient skaliert wird.<br/>            Nur-Lesen **bool**. |
| [`gradient_shape`](/slides/python-net/de/aspose.slides/igradientformateffectivedata/gradient_shape/) | Gibt die Form eines Gradienten zurück.<br/>            Nur-Lesen [`GradientShape`](/slides/python-net/de/aspose.slides/gradientshape). |
| [`gradient_stops`](/slides/python-net/de/aspose.slides/igradientformateffectivedata/gradient_stops/) | Gibt die Sammlung von Gradientstopps zurück.<br/>            Nur-Lesen [`IGradientStopCollectionEffectiveData`](/slides/python-net/de/aspose.slides/igradientstopcollectioneffectivedata). |

### Anmerkungen

Diese Schnittstelle wird als Teil von [`IFillFormatEffectiveData`](/slides/python-net/de/aspose.slides/ifillformateffectivedata) und [`ILineFillFormatEffectiveData`](/slides/python-net/de/aspose.slides/ilinefillformateffectivedata) verwendet.
