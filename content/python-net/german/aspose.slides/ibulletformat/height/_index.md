## height Eigenschaft
Gibt die Aufzählungszeichenhöhe eines Absatzes ohne Vererbung zurück oder legt sie fest.
            Der Wert float.NaN bestimmt, dass das Aufzählungszeichen die Höhe vom ersten Teil im Absatz erbt.
            Lesen/Schreiben **float**.
