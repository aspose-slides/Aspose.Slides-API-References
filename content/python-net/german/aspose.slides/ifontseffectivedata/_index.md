## IFontsEffectiveData Klasse

Unveränderliches Objekt, das den effektiven Satz von Schriftarten enthält.

Der Typ IFontsEffectiveData stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Property | Description |
| :- | :- |
| [`latin_font`](/slides/python-net/de/aspose.slides/ifontseffectivedata/latin_font/) | Gibt die lateinische Schriftart zurück.<br/>Schreibgeschützt [`IFontData`](/slides/python-net/de/aspose.slides/ifontdata). |
| [`east_asian_font`](/slides/python-net/de/aspose.slides/ifontseffectivedata/east_asian_font/) | Gibt die ostasiatische Schriftart zurück.<br/>Schreibgeschützt [`IFontData`](/slides/python-net/de/aspose.slides/ifontdata). |
| [`complex_script_font`](/slides/python-net/de/aspose.slides/ifontseffectivedata/complex_script_font/) | Gibt die komplexe Skript-Schriftart zurück.<br/>Schreibgeschützt [`IFontData`](/slides/python-net/de/aspose.slides/ifontdata). |


### Hinweise

Dieses Interface wird als Teil der [`IBasePortionFormatEffectiveData`](/slides/python-net/de/aspose.slides/ibaseportionformateffectivedata) und [`IFontSchemeEffectiveData`](/slides/python-net/de/aspose.slides.theme/ifontschemeeffectivedata) Schnittstellen verwendet.
