## ISlideSize Klasse

Stellt die Größe und Ausrichtung einer Folie dar.

Der ISlideSize-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`size`](/slides/python-net/de/aspose.slides/islidesize/size/) | Liefert die Folienabmessungen in Punkten. |
| [`type`](/slides/python-net/de/aspose.slides/islidesize/type/) | Liefert den Foliengrößentyp. |
| [`orientation`](/slides/python-net/de/aspose.slides/islidesize/orientation/) | Liefert oder setzt die Folienausrichtung. |

| Methode | Beschreibung |
