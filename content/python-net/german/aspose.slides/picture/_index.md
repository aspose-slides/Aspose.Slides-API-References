## Picture Klasse

Stellt ein Bild in einer Präsentation dar.

Der Picture-Typ stellt die folgenden Member bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`image`](/slides/python-net/de/aspose.slides/picture/image/) | Gibt das eingebettete Bild zurück oder setzt es.<br/>            Lesen/Schreiben [`IPPImage`](/slides/python-net/de/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/de/aspose.slides/picture/link_path_long/) | Gibt die URL des verknüpften Bildes zurück oder setzt sie.<br/>            Lesen/Schreiben **str**. |
| [`image_transform`](/slides/python-net/de/aspose.slides/picture/image_transform/) | Gibt die Sammlung von Bildtransformations-Effekten zurück.<br/>            Nur-Lesen [`IImageTransformOperationCollection`](/slides/python-net/de/aspose.slides.effects/iimagetransformoperationcollection). |
| [`presentation`](/slides/python-net/de/aspose.slides/picture/presentation/) | Gibt die Präsentation zurück.<br/>            Nur-Lesen [`IPresentation`](/slides/python-net/de/aspose.slides/ipresentation). |
| [`slide`](/slides/python-net/de/aspose.slides/picture/slide/) | Gibt die übergeordnete Folie eines Bildes zurück.<br/>            Nur-Lesen [`IBaseSlide`](/slides/python-net/de/aspose.slides/ibaseslide). |
