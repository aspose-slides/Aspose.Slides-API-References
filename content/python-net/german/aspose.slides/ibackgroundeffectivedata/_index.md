## IBackgroundEffectiveData Klasse

Unveränderliches Objekt, das die effektiven Hintergrund-Eigenschaften enthält.

Der Typ IBackgroundEffectiveData stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`fill_format`](/slides/python-net/de/aspose.slides/ibackgroundeffectivedata/fill_format/) | Gibt das effektive Füllformat zurück.<br/>            Nur lesbar [`IFillFormatEffectiveData`](/slides/python-net/de/aspose.slides/ifillformateffectivedata). |
| [`effect_format`](/slides/python-net/de/aspose.slides/ibackgroundeffectivedata/effect_format/) | Gibt das effektive Effektformat zurück.<br/>            Nur lesbar [`IEffectFormatEffectiveData`](/slides/python-net/de/aspose.slides/ieffectformateffectivedata). |


### Anmerkungen

Dieses Interface wird zusammen mit dem Interface [`IBackground`](/slides/python-net/de/aspose.slides/ibackground) verwendet, um effektive Formatierungswerte mit angewandter Vererbung zurückzugeben.
