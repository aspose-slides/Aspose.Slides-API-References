## get_rotation(self) {#}
Eine Rotation wird durch die Verwendung einer Breitenkoordinate, einer Längenkoordinate und einer Umdrehung um die Achse definiert, wobei die Breiten- und Längenkoordinate als Achse verwendet werden.
Erstes Element im Rückgabearray - Breite, zweites - Länge, drittes - Umdrehung.
Gibt None zurück, wenn keine Rotation definiert ist.
