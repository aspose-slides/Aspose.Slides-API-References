## Row Klasse

Stellt eine Zeile in einer Tabelle dar.

**Vererbung:**[`Row`](/slides/python-net/de/aspose.slides/row) → [`CellCollection`](/slides/python-net/de/aspose.slides/cellcollection)

Der Row-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`slide`](/slides/python-net/de/aspose.slides/row/slide/) | Gibt die übergeordnete Folie einer CellCollection zurück.<br/>            Nur lesbar [`IBaseSlide`](/slides/python-net/de/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/de/aspose.slides/row/presentation/) | Gibt die übergeordnete Präsentation einer CellCollection zurück.<br/>            Nur lesbar [`IPresentation`](/slides/python-net/de/aspose.slides/ipresentation). |
| [`height`](/slides/python-net/de/aspose.slides/row/height/) | Gibt die Höhe einer Zeile zurück.<br/>            Nur lesbar **float**. |
| [`minimal_height`](/slides/python-net/de/aspose.slides/row/minimal_height/) | Gibt die minimale mögliche Höhe einer Zeile zurück oder setzt sie.<br/>            Lese-/Schreib **float**. |
| [`row_format`](/slides/python-net/de/aspose.slides/row/row_format/) | Gibt das RowFormat-Objekt zurück, das Formatierungseigenschaften für diese Zeile enthält.<br/>            Nur lesbar [`IRowFormat`](/slides/python-net/de/aspose.slides/irowformat). |
