## get_script_font(self, script) {#str}
Ermittelt den Schriftartnamen, der mit einem bestimmten Skript-Tag aus dem Präsentationsthema verknüpft ist.

### Rückgabewert

Der Name der für das angegebene Skript verwendeten Schriftart oder `None`, wenn das Skript nicht definiert ist.



```python
def get_script_font(self, script):
    ...
```


| Parameter | Typ | Beschreibung |
| :- | :- | :- |
| script | **str** | Der BCP-47-Skriptcode (z.B. "Latn", "Cyrl", "Jpan"), der zur Identifizierung eines Schriftsystems verwendet wird. |
