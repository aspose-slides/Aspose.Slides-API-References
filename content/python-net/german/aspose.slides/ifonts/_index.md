## IFonts Klasse

Stellt die Schriftenkollektion dar.

Der Typ IFonts stellt die folgenden Member bereit:

## Eigenschaften

| Property | Description |
| :- | :- |
| [`latin_font`](/slides/python-net/de/aspose.slides/ifonts/latin_font/) | Gibt die lateinische Schriftart zurück oder setzt sie.<br/>            Lesen/Schreiben [`IFontData`](/slides/python-net/de/aspose.slides/ifontdata). |
| [`east_asian_font`](/slides/python-net/de/aspose.slides/ifonts/east_asian_font/) | Gibt die ostasiatische Schriftart zurück oder setzt sie.<br/>            Lesen/Schreiben [`IFontData`](/slides/python-net/de/aspose.slides/ifontdata). |
| [`complex_script_font`](/slides/python-net/de/aspose.slides/ifonts/complex_script_font/) | Gibt die komplexe Skript-Schriftart zurück oder setzt sie.<br/>            Lesen/Schreiben [`IFontData`](/slides/python-net/de/aspose.slides/ifontdata). |

## Methoden

| Method | Description |
| :- | :- |
| [`get_script_font_map(self)`](/slides/python-net/de/aspose.slides/ifonts/get_script_font_map/#) | Gibt eine Liste aller string-string-Paar-Skript-Schriftdefinitionen in der Präsentation zurück. |
