## SizeF Klasse

Speichert ein geordnetes Paar von Gleitkommazahlen, typischerweise die Breite und Höhe eines Rechtecks. Kompatibel mit .NET `System.Drawing.SizeF`.

Der Typ SizeF stellt die folgenden Mitglieder bereit:

## Konstruktoren

| Konstruktor | Beschreibung |
| :- | :- |
| [`__init__(self, width=0.0, height=0.0)`](/slides/python-net/de/aspose.slides/sizef/__init__/#float-float) | Erstellt eine Größe mit der angegebenen Breite und Höhe. |

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`width`](/slides/python-net/de/aspose.slides/sizef/width/) | Gibt die horizontale Komponente dieser Größe zurück.<br/>            Nur lesbar **float**. |
| [`height`](/slides/python-net/de/aspose.slides/sizef/height/) | Gibt die vertikale Komponente dieser Größe zurück.<br/>            Nur lesbar **float**. |


### Anmerkungen

Größen werden über ihre Komponenten mit `==` verglichen und können als Dictionary-Schlüssel oder Mengenelemente verwendet werden.
