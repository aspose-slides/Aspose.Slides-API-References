## ColorType Aufzählung

Stellt verschiedene Farbmodi dar.

Der Typ ColorType stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| NOT_DEFINED | Farbe ist überhaupt nicht definiert. |
| RGB | Standard-24bit RGB-Farbe. |
| RGB_PERCENTAGE | Hochauflösende RGB-Farbe. |
| HSL | Hochauflösende HSL-Farbe. |
| SCHEME | Schema-Farbe. |
| SYSTEM | Systemfarbe. |
| PRESET | Voreingestellte Farbe. |
