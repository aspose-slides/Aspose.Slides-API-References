## apply_external_theme_to_depending_slides(self, fname) {#str}
Erstellt eine neue MasterSlide basierend auf der aktuellen, wendet ein externes Theme darauf an und wendet die erstellte MasterSlide auf alle abhängigen Folien an.

### Rückgabewert
