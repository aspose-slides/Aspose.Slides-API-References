## PathCommandType-Aufzählung

Stellt Grafik-Pfadbefehle dar

Der Typ PathCommandType stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| CLOSE | Schließt den Geometriepfad |
| MOVE_TO | Setzt die nächste Punktposition des Geometriepfads |
| LINE_TO | Fügt eine Linie zum Geometriepfad hinzu |
| ARC_TO | Fügt den angegebenen Bogen zum Geometriepfad hinzu. |
| QUAD_BEZIER_TO | Fügt eine quadratische Bézierkurve zum Geometriepfad hinzu |
| CUBIC_BEZIER_TO | Fügt eine kubische Bézierkurve zum Geometriepfad hinzu |
