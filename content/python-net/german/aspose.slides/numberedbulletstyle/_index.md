## NumberedBulletStyle Aufzählung

Stellt den Stil der nummerierten Aufzählungszeichen dar.

Der Typ NumberedBulletStyle stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| NOT_DEFINED | Nicht definiert. |
| BULLET_ALPHA_LC_PERIOD | Kleinbuchstaben des Alphabets mit einem Punkt. Beispiel: a., b., c., ... |
| BULLET_ALPHA_UC_PERIOD | Großbuchstaben des Alphabets mit einem Punkt. Beispiel: A., B., C., ... |
| BULLET_ARABIC_PAREN_RIGHT | Arabische Ziffern mit schließender Klammer. Beispiel: 1), 2), 3), ... |
| BULLET_ARABIC_PERIOD | Arabische Ziffern mit einem Punkt. Beispiel: 1., 2., 3., ... |
| BULLET_ROMAN_LC_PAREN_BOTH | Kleinbuchstabige römische Zahlen mit beiden Klammern. Beispiel: (i), (ii), (iii), ... |
| BULLET_ROMAN_LC_PAREN_RIGHT | Kleinbuchstabige römische Zahlen mit schließender Klammer. Beispiel: i), ii), iii), ... |
| BULLET_ROMAN_LC_PERIOD | Kleinbuchstabige römische Zahlen mit Punkt. Beispiel: i., ii., iii., ... |
| BULLET_ROMAN_UC_PERIOD | Großbuchstabige römische Zahlen mit Punkt. Beispiel: I., II., III., ... |
| BULLET_ALPHA_LC_PAREN_BOTH | Kleinbuchstaben des Alphabets mit beiden Klammern. Beispiel: (a), (b), (c), ... |
| BULLET_ALPHA_LC_PAREN_RIGHT | Kleinbuchstaben des Alphabets mit schließender Klammer. Beispiel: a), b), c), ... |
| BULLET_ALPHA_UC_PAREN_BOTH | Großbuchstaben des Alphabets mit beiden Klammern. Beispiel: (A), (B), (C), ... |
| BULLET_ALPHA_UC_PAREN_RIGHT | Großbuchstaben des Alphabets mit schließender Klammer. Beispiel: A), B), C), ... |
| BULLET_ARABIC_PAREN_BOTH | Arabische Ziffern mit beiden Klammern. Beispiel: (1), (2), (3), ... |
| BULLET_ARABIC_PLAIN | Arabische Ziffern. Beispiel: 1, 2, 3, ... |
| BULLET_ROMAN_UC_PAREN_BOTH | Großbuchstabige römische Zahlen mit beiden Klammern. Beispiel: (I), (II), (III), ... |
| BULLET_ROMAN_UC_PAREN_RIGHT | Großbuchstabige römische Zahlen mit schließender Klammer. Beispiel: I), II), III), ... |
| BULLET_SIMP_CHIN_PLAIN | Vereinfachtes Chinesisch ohne Punkt. |
| BULLET_SIMP_CHIN_PERIOD | Vereinfachtes Chinesisch mit Punkt. |
| BULLET_CIRCLE_NUM_DB_PLAIN | Doppelbyte-umrundte Nummer für Werte bis 10, ab 11 - arabische Zahlen. |
| BULLET_CIRCLE_NUM_WD_WHITE_PLAIN | Textfarbige Nummer mit gleichfarbigem Kreis darum (Wingdings weiße Kreiszahlen). Ab 11 - arabische Zahlen. |
| BULLET_CIRCLE_NUM_WD_BLACK_PLAIN | Schattenfarbene Nummer mit kreisförmigem Hintergrund in normaler Textfarbe (Wingdings schwarze Kreiszahlen). |
| BULLET_TRAD_CHIN_PLAIN | Traditionelles Chinesisch ohne Punkt. |
| BULLET_TRAD_CHIN_PERIOD | Traditionelles Chinesisch mit Punkt. |
| BULLET_ARABIC_ALPHA_DASH | Arabische alphabetische Zeichen mit Bindestrich. |
| BULLET_ARABIC_ABJAD_DASH | Arabische Abjad-Alphabete mit Bindestrich. |
| BULLET_HEBREW_ALPHA_DASH | Hebräische alphabetische Zeichen mit Bindestrich. |
| BULLET_KANJI_KOREAN_PLAIN | Japanisch/Koreanische Zahlen ohne Punkt. |
| BULLET_KANJI_KOREAN_PERIOD | Japanisch/Koreanische Zahlen mit Punkt. |
| BULLET_ARABIC_DB_PLAIN | Doppelbyte-Arabisches Nummerierungsschema (ohne Satzzeichen). |
| BULLET_ARABIC_DB_PERIOD | Doppelbyte-Arabisches Nummerierungsschema mit Doppelbyte-Punkt. |
| BULLET_THAI_ALPHA_PERIOD | Thailändisches Alphabet mit Punkt. |
| BULLET_THAI_ALPHA_PAREN_RIGHT | Thailändisches Alphabet Klammern – rechts. |
| BULLET_THAI_ALPHA_PAREN_BOTH | Thailändisches Alphabet Klammern – beide. |
| BULLET_THAI_NUM_PERIOD | Thailändische Ziffern mit Punkt. |
| BULLET_THAI_NUM_PAREN_RIGHT | Thailändische Ziffern Klammern – rechts. |
| BULLET_THAI_NUM_PAREN_BOTH | Thailändische Ziffern Klammern – beide. |
| BULLET_HINDI_ALPHA_PERIOD | Hindi-Alphabet mit Punkt – Vokale. |
| BULLET_HINDI_NUM_PERIOD | Hindi-Ziffern mit Punkt. |
| BULLET_KANJI_SIMP_CHIN_DB_PERIOD | Kanji einfaches Chinesisch DBPeriod. |
| BULLET_HINDI_NUM_PAREN_RIGHT | Hindi-Ziffern Klammern – rechts. |
| BULLET_HINDI_ALPHA_1_PERIOD | Hindi-Alphabet mit Punkt – Konsonanten. |
