## ZoomImageType Aufzählung

Definiert, ob das Zoom-Objekt die Folienvorschau oder ein Titelbild verwendet.

Der ZoomImageType-Typ stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| PREVIEW | Verwendet das Bild der Folie oder des Abschnitts. |
| COVER | Verwendet ein benutzerdefiniertes Bild. |
