## get_rotation(self) {#}
Eine Drehung wird definiert durch die Verwendung einer Breitengrad-
            Koordinate, einer Längengradkoordinate und einer Umdrehung um die Achse 
            als die Breitengrad- und Längengradkoordinaten.
            erstes Element im Rückgabe-Array - Breitengrad, zweites - Längengrad, drittes - Umdrehung.
            Gibt None zurück, wenn keine Drehung definiert ist.

### Rückgabe

Array von Drehungswerten als **float**[].
