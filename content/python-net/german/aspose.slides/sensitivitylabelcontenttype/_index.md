## SensitivityLabelContentType Aufzählung

Stellt die Arten der Inhaltskennzeichnung dar, die auf ein Dokument angewendet werden sollen.

Der Typ SensitivityLabelContentType stellt die folgenden Member bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| NONE | Bedeutet, dass das Label standardmäßig oder automatisch angewendet wird. |
| HEADER | Bedeutet, dass das Label manuell angewendet wurde.<br/>            Verwenden Sie dieses Label für jede Sensitivitätskennzeichnung, die vom Benutzer direkt angewendet wurde. |
| FOOTER | Bedeutet, dass das Label manuell angewendet wurde.<br/>            Verwenden Sie dieses Label für jede Sensitivitätskennzeichnung, die vom Benutzer direkt angewendet wurde. |
| WATERMARK | Bedeutet, dass das Label manuell angewendet wurde.<br/>            Verwenden Sie dieses Label für jede Sensitivitätskennzeichnung, die vom Benutzer direkt angewendet wurde. |
| ENCRYPTION | Bedeutet, dass das Label manuell angewendet wurde.<br/>            Verwenden Sie dieses Label für jede Sensitivitätskennzeichnung, die vom Benutzer direkt angewendet wurde. |
