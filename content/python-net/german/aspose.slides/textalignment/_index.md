## TextAlignment Aufzählung

Stellt verschiedene Textausrichtungsstile dar.

Der Typ TextAlignment stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| NOT_DEFINED | Standardausrichtung. |
| LEFT | Linksbündig. |
| CENTER | Zentrierte Ausrichtung. |
| RIGHT | Rechtsbündig. |
| JUSTIFY | Blocksatz. |
| JUSTIFY_LOW | Kashida-Blocksatz niedrig. |
| DISTRIBUTED | Verteilte Ausrichtung. |
