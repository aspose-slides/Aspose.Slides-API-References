## ICameraEffectiveData Klasse

Unveränderliches Objekt, das effektive Kameraeigenschaften enthält.

Der Typ ICameraEffectiveData stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`camera_type`](/slides/python-net/de/aspose.slides/icameraeffectivedata/camera_type/) | Kameratyp.<br/>            Nur lesbar [`CameraPresetType`](/slides/python-net/de/aspose.slides/camerapresettype). |
| [`field_of_view_angle`](/slides/python-net/de/aspose.slides/icameraeffectivedata/field_of_view_angle/) | Kamera-FOV (0-180 Grad, Sichtfeld).<br/>            Nur lesbar **float**. |
| [`zoom`](/slides/python-net/de/aspose.slides/icameraeffectivedata/zoom/) | Kamera-Zoom (positiver Wert in Prozent).<br/>            Nur lesbar **float**. |

## Methoden

| Methode | Beschreibung |
| :- | :- |
| [`get_rotation(self)`](/slides/python-net/de/aspose.slides/icameraeffectivedata/get_rotation/#) | Eine Drehung wird definiert durch die Verwendung einer Breitengradkoordinate<br/>            einer Längengradkoordinate und einer Umdrehung um die Achse <br/>            als die Breitengrad- und Längengradkoordinaten.<br/>            Erstes Element im Rückgabe-Array – Breitengrad, zweites – Längengrad, drittes – Umdrehung.<br/>            Gibt None zurück, wenn keine Drehung definiert ist. |
