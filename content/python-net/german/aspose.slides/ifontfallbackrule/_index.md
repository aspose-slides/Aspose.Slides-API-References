## IFontFallBackRule Klasse

Stellt die Font-Fallback-Regel dar

Der Typ IFontFallBackRule stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`range_start_index`](/slides/python-net/de/aspose.slides/ifontfallbackrule/range_start_index/) | Gibt den ersten Index eines kontinuierlichen Unicode-Bereichs zurück. |
| [`range_end_index`](/slides/python-net/de/aspose.slides/ifontfallbackrule/range_end_index/) | Gibt den letzten Index eines kontinuierlichen Unicode-Bereichs zurück. |
| [`count`](/slides/python-net/de/aspose.slides/ifontfallbackrule/count/) | Gibt die Anzahl der tatsächlich für den Bereich definierten Schriften zurück. |
