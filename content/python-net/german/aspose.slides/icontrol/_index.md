## IControl Klasse

Stellt ein ActiveX-Steuerelement dar.

Der IControl-Typ stellt die folgenden Member bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`name`](/slides/python-net/de/aspose.slides/icontrol/name/) | Gibt den Namen dieses Steuerelements zurück.<br/>            Lesen/Schreiben **str**. |
| [`class_id`](/slides/python-net/de/aspose.slides/icontrol/class_id/) | Ruft die Klassen-ID dieses Steuerelements ab.<br/>            Nur lesen **System.Guid**. |
| [`substitute_picture_format`](/slides/python-net/de/aspose.slides/icontrol/substitute_picture_format/) | Gibt das ControlEx-Bildfüllungs-Eigenschaften-Objekt zurück.<br/>            Nur lesen [`IPictureFillFormat`](/slides/python-net/de/aspose.slides/ipicturefillformat). |
| [`frame`](/slides/python-net/de/aspose.slides/icontrol/frame/) | Gibt den Rahmen des Steuerelements zurück oder setzt ihn.<br/>            Lesen/Schreiben [`IShapeFrame`](/slides/python-net/de/aspose.slides/ishapeframe). |
| [`properties`](/slides/python-net/de/aspose.slides/icontrol/properties/) | Gibt eine Sammlung von ActiveX-Eigenschaften zurück.<br/>            Nur lesen [`IControlPropertiesCollection`](/slides/python-net/de/aspose.slides/icontrolpropertiescollection). |
| [`persistence`](/slides/python-net/de/aspose.slides/icontrol/persistence/) | Ruft die zum Speichern der Eigenschaften des ActiveX-Steuerelements verwendete Methode ab.<br/>            Nur lesen [`PersistenceType`](/slides/python-net/de/aspose.slides/persistencetype). |
| [`active_x_control_binary`](/slides/python-net/de/aspose.slides/icontrol/active_x_control_binary/) | Gibt die Persistenz eines ActiveX-Steuerelements an, wenn die zum Persistieren verwendete Methode entweder PersistStream, PersistStreamInit oder PersistStorage ist. |
