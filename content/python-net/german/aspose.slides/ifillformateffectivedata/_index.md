## IFillFormatEffectiveData Klasse

Unveränderliches Objekt, das die wirksamen Füllformatierungseigenschaften enthält.

Der Typ IFillFormatEffectiveData stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`fill_type`](/slides/python-net/de/aspose.slides/ifillformateffectivedata/fill_type/) | Gibt den Fülltyp zurück.<br/>            Nur-Lesen [`FillType`](/slides/python-net/de/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/de/aspose.slides/ifillformateffectivedata/solid_fill_color/) | Gibt die Füllfarbe zurück.<br/>            Nur-Lesen [`Color`](/slides/python-net/de/aspose.slides/color). |
| [`solid_fill_scheme_color`](/slides/python-net/de/aspose.slides/ifillformateffectivedata/solid_fill_scheme_color/) | Ermittelt die durch ein Farbschema definierte Füllfarbe.<br/>            Der Wert [`SchemeColor.NOT_DEFINED`](/slides/python-net/de/aspose.slides/schemecolor/NOT_DEFINED) zeigt an, dass die [`IFillFormatEffectiveData.solid_fill_color`](/slides/python-net/de/aspose.slides/ifillformateffectivedata/solid_fill_color) <br/>            keine Schemafarbe ist.<br/>            Nur-Lesen [`SchemeColor`](/slides/python-net/de/aspose.slides/schemecolor). |
| [`gradient_format`](/slides/python-net/de/aspose.slides/ifillformateffectivedata/gradient_format/) | Gibt das Verlaufsfüllformat zurück.<br/>            Nur-Lesen [`IGradientFormatEffectiveData`](/slides/python-net/de/aspose.slides/igradientformateffectivedata). |
| [`pattern_format`](/slides/python-net/de/aspose.slides/ifillformateffectivedata/pattern_format/) | Gibt das Musterfüllformat zurück.<br/>            Nur-Lesen [`IPatternFormatEffectiveData`](/slides/python-net/de/aspose.slides/ipatternformateffectivedata). |
| [`picture_fill_format`](/slides/python-net/de/aspose.slides/ifillformateffectivedata/picture_fill_format/) | Gibt das Bildfüllformat zurück.<br/>            Nur-Lesen [`IPictureFillFormatEffectiveData`](/slides/python-net/de/aspose.slides/ipicturefillformateffectivedata). |
| [`rotate_with_shape`](/slides/python-net/de/aspose.slides/ifillformateffectivedata/rotate_with_shape/) | Bestimmt, ob die Füllung mit der Form rotiert werden soll.<br/>            Nur-Lesen **bool**. |

### Anmerkungen

Dieses Interface wird zusammen mit dem Interface [`IFillFormat`](/slides/python-net/de/aspose.slides/ifillformat) verwendet, um wirksame Formatierungswerte mit angewandter Vererbung zurückzugeben.
