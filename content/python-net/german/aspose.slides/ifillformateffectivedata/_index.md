## IFillFormatEffectiveData Klasse

Unveränderliches Objekt, das effektive Füllformatierungseigenschaften enthält.

Der Typ IFillFormatEffectiveData stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`fill_type`](/slides/python-net/de/aspose.slides/ifillformateffectivedata/fill_type/) | Gibt den Typ der Füllung zurück.<br/>            Nur-Lesen [`FillType`](/slides/python-net/de/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/de/aspose.slides/ifillformateffectivedata/solid_fill_color/) | Gibt die Füllfarbe zurück.<br/>            Nur-Lesen **aspose.slides.Color**. |
| [`solid_fill_scheme_color`](/slides/python-net/de/aspose.slides/ifillformateffectivedata/solid_fill_scheme_color/) | Liefert die durch ein Farbschema definierte Füllfarbe.<br/>            Der [`SchemeColor.NOT_DEFINED`](/slides/python-net/de/aspose.slides/schemecolor/NOT_DEFINED) Wert zeigt an, dass das [`IFillFormatEffectiveData.solid_fill_color`](/slides/python-net/de/aspose.slides/ifillformateffectivedata/solid_fill_color) <br/>            keine Schematafarbe ist.<br/>            Nur-Lesen [`SchemeColor`](/slides/python-net/de/aspose.slides/schemecolor). |
| [`gradient_format`](/slides/python-net/de/aspose.slides/ifillformateffectivedata/gradient_format/) | Gibt das Gradient-Füllformat zurück.<br/>            Nur-Lesen [`IGradientFormatEffectiveData`](/slides/python-net/de/aspose.slides/igradientformateffectivedata). |
| [`pattern_format`](/slides/python-net/de/aspose.slides/ifillformateffectivedata/pattern_format/) | Gibt das Muster-Füllformat zurück.<br/>            Nur-Lesen [`IPatternFormatEffectiveData`](/slides/python-net/de/aspose.slides/ipatternformateffectivedata). |
| [`picture_fill_format`](/slides/python-net/de/aspose.slides/ifillformateffectivedata/picture_fill_format/) | Gibt das Bild-Füllformat zurück.<br/>            Nur-Lesen [`IPictureFillFormatEffectiveData`](/slides/python-net/de/aspose.slides/ipicturefillformateffectivedata). |
| [`rotate_with_shape`](/slides/python-net/de/aspose.slides/ifillformateffectivedata/rotate_with_shape/) | Bestimmt, ob die Füllung mit der Form rotiert werden soll.<br/>            Nur-Lesen **bool**. |

### Bemerkungen

Dieses Interface wird zusammen mit dem [`IFillFormat`](/slides/python-net/de/aspose.slides/ifillformat) Interface verwendet, um effektive Formatierungswerte mit angewandter Vererbung zurückzugeben.
