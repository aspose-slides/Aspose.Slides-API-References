## ILightRigEffectiveData Klasse

Unveränderliches Objekt, das wirksame Lichtrig-Eigenschaften enthält.

Der ILightRigEffectiveData-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`direction`](/slides/python-net/de/aspose.slides/ilightrigeffectivedata/direction/) | Lichtrichtung.<br/>            Nur lesbar [`LightingDirection`](/slides/python-net/de/aspose.slides/lightingdirection). |
| [`light_type`](/slides/python-net/de/aspose.slides/ilightrigeffectivedata/light_type/) | Stellt ein vordefiniertes Licht dar, das auf eine Form angewendet werden kann.<br/>            Das Lichtrig stellt eine Gruppe von Lichtern dar, die in einer bestimmten Weise relativ zu einer 3D-Szene ausgerichtet sind.<br/>            Nur lesbar [`LightRigPresetType`](/slides/python-net/de/aspose.slides/lightrigpresettype). |

## Methoden

| Methode | Beschreibung |
| :- | :- |
| [`get_rotation(self)`](/slides/python-net/de/aspose.slides/ilightrigeffectivedata/get_rotation/#) | Eine Rotation wird definiert durch die Verwendung einer Breitengradkoordinate, einer Längengradkoordinate und einer Drehung um die Achse entsprechend den Breitengrad- und Längengradkoordinaten.<br/>            Erstes Element im Rückgabe-Array – Breitengrad, zweites – Längengrad, drittes – Drehung. |

### Anmerkungen

Dieses Interface wird als Teil von [`IThreeDFormatEffectiveData`](/slides/python-net/de/aspose.slides/ithreedformateffectivedata) verwendet.
