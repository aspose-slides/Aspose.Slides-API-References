## IImage Klasse

Stellt ein Raster- oder Vektorbild dar.

Der IImage-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`size`](/slides/python-net/de/aspose.slides/iimage/size/) | Gibt die Größe des Bildes zurück. |
| [`width`](/slides/python-net/de/aspose.slides/iimage/width/) | Gibt die Breite des Bildes in Pixeln zurück. |
| [`height`](/slides/python-net/de/aspose.slides/iimage/height/) | Gibt die Höhe des Bildes in Pixeln zurück. |

## Methoden

| Methode | Beschreibung |
| :- | :- |
| [`save(self, filename)`](/slides/python-net/de/aspose.slides/iimage/save/#str) | Speichert das Bild in einer Datei. |
| [`save(self, filename, format)`](/slides/python-net/de/aspose.slides/iimage/save/#str-imageformat) | Speichert das Bild in einer Datei im angegebenen Format. |
| [`save(self, stream, format)`](/slides/python-net/de/aspose.slides/iimage/save/#iorawiobase-imageformat) | Speichert das Bild in einen Stream im angegebenen Format. |
| [`save(self, filename, format, quality)`](/slides/python-net/de/aspose.slides/iimage/save/#str-imageformat-int) | Speichert das Bild in einer Datei im angegebenen Format und in der angegebenen Qualität. |
| [`save(self, stream, format, quality)`](/slides/python-net/de/aspose.slides/iimage/save/#iorawiobase-imageformat-int) | Speichert das Bild in einen Stream im angegebenen Format und in der angegebenen Qualität. |

### Anmerkungen

Dieses Interface bietet eine gemeinsame Abstraktion für die Verarbeitung von Raster- und Vektorbildern.  
Implementierungen können je nach zugrunde liegendem Bildtyp variieren.
