## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`x`](/slides/python-net/de/aspose.slides/shapeframe/x/) | Gibt die X-Koordinate der oberen linken Ecke eines Rahmens zurück.<br/>            Nur lesend **float**. |
| [`y`](/slides/python-net/de/aspose.slides/shapeframe/y/) | Gibt die Y-Koordinate der oberen linken Ecke eines Rahmens zurück.<br/>            Nur lesend **float**. |
| [`width`](/slides/python-net/de/aspose.slides/shapeframe/width/) | Gibt die Breite eines Rahmens zurück.<br/>            Nur lesend **float**. |
| [`height`](/slides/python-net/de/aspose.slides/shapeframe/height/) | Gibt die Höhe eines Rahmens zurück.<br/>            Nur lesend **float**. |
| [`rotation`](/slides/python-net/de/aspose.slides/shapeframe/rotation/) | Gibt die Anzahl der Grad zurück, um die ein Rahmen um die Z-Achse gedreht ist.<br/>            Ein positiver Wert bedeutet Drehung im Uhrzeigersinn; ein negativer Wert<br/>            bedeutet Drehung gegen den Uhrzeigersinn.<br/>            Nur lesend **float**. |
| [`center_x`](/slides/python-net/de/aspose.slides/shapeframe/center_x/) | Gibt die X-Koordinate des Mittelpunkts eines Rahmens zurück.<br/>            Nur lesend **float**. |
| [`center_y`](/slides/python-net/de/aspose.slides/shapeframe/center_y/) | Gibt die Y-Koordinate des Mittelpunkts eines Rahmens zurück.<br/>            Nur lesend **float**. |
| [`flip_h`](/slides/python-net/de/aspose.slides/shapeframe/flip_h/) | Gibt an, ob ein Rahmen horizontal gespiegelt ist.<br/>            Nur lesend [`NullableBool`](/slides/python-net/de/aspose.slides/nullablebool). |
| [`flip_v`](/slides/python-net/de/aspose.slides/shapeframe/flip_v/) | Gibt an, ob ein Rahmen vertikal gespiegelt ist.<br/>            Nur lesend [`NullableBool`](/slides/python-net/de/aspose.slides/nullablebool). |
| [`rectangle`](/slides/python-net/de/aspose.slides/shapeframe/rectangle/) | Gibt die Koordinaten eines Rahmens zurück.<br/>            Nur lesend [`RectangleF`](/slides/python-net/de/aspose.slides/rectanglef). |
