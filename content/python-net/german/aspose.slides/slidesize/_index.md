## SlideSize Klasse

Stellt die Größe und Orientierung einer Folie dar.

Der SlideSize-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`size`](/slides/python-net/de/aspose.slides/slidesize/size/) | Ermittelt die Folienabmessungen in Punkten. |
| [`type`](/slides/python-net/de/aspose.slides/slidesize/type/) | Ermittelt den Foliengrößentyp. |
| [`orientation`](/slides/python-net/de/aspose.slides/slidesize/orientation/) | Ermittelt oder setzt die Folienorientierung. |
