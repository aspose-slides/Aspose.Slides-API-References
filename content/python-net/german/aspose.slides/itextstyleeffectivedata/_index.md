## ITextStyleEffectiveData Klasse

Unveränderliches Objekt, das effektive Texteigenschaften enthält.

Der Typ ITextStyleEffectiveData stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`default_paragraph_format`](/slides/python-net/de/aspose.slides/itextstyleeffectivedata/default_paragraph_format/) | Gibt effektive Standard-Absatzeigenschaften zurück.<br/>            Nur lesbar [`IParagraphFormatEffectiveData`](/slides/python-net/de/aspose.slides/iparagraphformateffectivedata). |

## Methoden

| Methode | Beschreibung |
| :- | :- |
| [`get_level(self, index)`](/slides/python-net/de/aspose.slides/itextstyleeffectivedata/get_level/#int) | Gibt die Ebene des effektiven Stils zurück. |


### Hinweise

Dieses Interface wird zusammen mit dem Interface [`ITextStyle`](/slides/python-net/de/aspose.slides/itextstyle) verwendet, um effektive Formatierungswerte mit angewandter Vererbung zurückzugeben.
