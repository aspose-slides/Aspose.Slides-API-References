## width Eigenschaft
Liest oder setzt die width der Form, gemessen in Punkten.
            Lese-/Schreib **float**.


### Hinweise

Der zurückgegebene Wert ist immer definiert und niemals **float**.
            Der zugewiesene Wert muss ebenfalls definiert sein; **float** nur Eigenschaften einer `RawFrame`-Instanz zuweisen.
