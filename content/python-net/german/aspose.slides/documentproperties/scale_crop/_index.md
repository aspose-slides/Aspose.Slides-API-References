## scale_crop Eigenschaft
Gibt den Anzeigemodus der Dokumentvorschau an. 
            Setzen Sie dieses Element auf **true**, um die Skalierung der Dokumentvorschau an die Anzeige zu ermöglichen. 
            Setzen Sie dieses Element auf **false**, um das Zuschneiden der Dokumentvorschau zu aktivieren, sodass nur Abschnitte angezeigt werden, die zur Anzeige passen.
            Lesen/Schreiben **bool**.
