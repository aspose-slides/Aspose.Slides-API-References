## IBackdrop3DScene Klasse

Definiert eine Ebene, in der Effekte wie Glühen und Schatten in Relation zur Form, auf die sie angewendet werden, angewendet werden.

Der IBackdrop3DScene-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Property | Description |
| :- | :- |
| [`normal_vector`](/slides/python-net/de/aspose.slides/ibackdrop3dscene/normal_vector/) | Gibt einen Normalvektor zurück oder setzt ihn. <br/>            genauer gesagt definiert dieses Attribut einen Vektor, der senkrecht zur Fläche der Hintergrundebene steht. Vector represented by array of 3 float values<br/>            die X, Y und Z Koordinaten definieren.<br/>            Lesen/Schreiben **float**[]. |
| [`anchor_point`](/slides/python-net/de/aspose.slides/ibackdrop3dscene/anchor_point/) | Gibt einen Punkt im 3D-Raum zurück oder setzt ihn. Dieser Punkt ist der Punkt im Raum, der die Hintergrundebene verankert.<br/>            3D-Punkt wird durch ein Array von 3 Float-Werten dargestellt, die die X, Y und Z Koordinaten definieren.<br/>            Lesen/Schreiben **float**[]. |
| [`up_vector`](/slides/python-net/de/aspose.slides/ibackdrop3dscene/up_vector/) | Gibt einen Vektor zurück, der nach oben zeigt, oder setzt ihn. Genauer gesagt definiert dieses Attribut einen Vektor,<br/>            der nach oben gerichtet ist in Relation zur Fläche der Hintergrundebene. Vector represented by array<br/>            von 3 Float-Werten, die die X, Y und Z Koordinaten definieren.<br/>            Lesen/Schreiben **float**[]. |
