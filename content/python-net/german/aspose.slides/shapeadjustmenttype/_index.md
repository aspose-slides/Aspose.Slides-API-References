## ShapeAdjustmentType Aufzählung

Specifies different types of shape adjustment values.

The ShapeAdjustmentType type exposes the following members:

## Felder

| Field | Description |
| :- | :- |
| CUSTOM | Custom type (unbekannte Anpassung) |
| CORNER_SIZE | Steuert die Größe der Ecken. |
| LEFT_UP_CORNER | Steuert die obere linke Ecke. |
| RIGHT_UP_CORNER | Steuert die obere rechte Ecke. |
| UP_CORNERS | Steuert die oberen Ecken. |
| DOWN_CORNERS | Steuert die unteren Ecken. |
| THICKNESS | Steuert die Dicke der Figur. |
| ARROW_TAIL_THICKNESS | Steuert die Dicke des Pfeilschafts. |
| ARROWHEAD_LENGTH | Steuert die Länge des Pfeilkopfes. |
| ARROWHEAD_WIDTH | Steuert die Breite des Pfeilkopfes. |
| RADIUS | Steuert die Größe des Radius der Form oder ihres Teils. |
| DEPTH | Steuert die Tiefe der Zahnräder oder des Fasen-Effekts. |
| SHAPE_PART_OFFSET | Steuert den Versatz eines Teils der Figur relativ zu einem anderen. |
| ANGLE | Steuert den Winkel für die Figur oder ihr Teil. |
| START_ANGLE | Startwinkel für Kuchen- und Bogenformen. |
| END_ANGLE | Endwinkel für Kuchen- und Bogenformen. |
| START_POINT_X | Steuert die X-Position des Startpunkts des Callouts. |
| START_POINT_Y | Steuert die Y-Position des Startpunkts des Callouts. |
| CONNECTOR_POINT_1X | Steuert die horizontale Position des Winkelanpassungspunkts des Callouts. |
| CONNECTOR_POINT_1Y | Steuert die vertikale Position des Winkelanpassungspunkts des Callouts. |
| CONNECTOR_POINT_2X | Steuert die horizontale Position des Winkelanpassungspunkts des Callouts. |
| CONNECTOR_POINT_2Y | Steuert die vertikale Position des Winkelanpassungspunkts des Callouts. |
| CONNECTOR_BEND_POSITION_X | Steuert die horizontale Position der Biegung im Verbinder. |
| CONNECTOR_BEND_POSITION_Y | Steuert die vertikale Position der Biegung im Verbinder. |
| ATTACH_Y | Steuert den vertikalen Ansatzpunkt der Figur. |
| ATTACH_X | Steuert den horizontalen Ansatzpunkt der Figur. |
| CALLOUT_HEIGHT | Steuert die vertikale Größe des Callouts. |
| CALLOUT_WIDTH | Steuert die horizontale Größe des Callouts. |
| CALLOUT_SIZE | Steuert die Größe des Callouts. |
| CURVATURE | Krümmung einer gebogenen Klammer, eines gebogenen Pfeils oder einer Form. |
| HORIZONTAL_THICKNESS | Steuert die horizontale Dicke der Eckform. |
| VERTICAL_THICKNESS | Steuert die vertikale Dicke der Eckform. |
| VERTICAL_SIZE | Steuert die vertikale Größe der Form. |
| HORIZONTAL_SIZE | Steuert die horizontale Größe der Form. |
| TOP | Steuert die Oberseite einer Form. |
