## TagCollection Klasse

Stellt die Sammlung von Tags dar (vom Nutzer definierte Zeichenkettenpaare)

Der Typ TagCollection stellt die folgenden Mitglieder bereit:

## Methoden

| Methode | Beschreibung |
| :- | :- |
| [`add(self, name, value)`](/slides/python-net/de/aspose.slides/tagcollection/add/#str-str) | Fügt der Sammlung ein neues Tag hinzu. |
| [`remove(self, name)`](/slides/python-net/de/aspose.slides/tagcollection/remove/#str) | Entfernt das Tag mit einem angegebenen Namen aus der Sammlung. |
| [`index_of_name(self, name)`](/slides/python-net/de/aspose.slides/tagcollection/index_of_name/#str) | Gibt den nullbasierten Index des angegebenen Schlüssels in der Sammlung zurück. |
| [`remove_at(self, index)`](/slides/python-net/de/aspose.slides/tagcollection/remove_at/#int) | Entfernt das Tag am angegebenen Index. |
| [`clear(self)`](/slides/python-net/de/aspose.slides/tagcollection/clear/#) | Entfernt alle Tags aus der Sammlung. |
| [`get_value_by_index(self, index)`](/slides/python-net/de/aspose.slides/tagcollection/get_value_by_index/#int) | Gibt den Wert eines Tags am angegebenen Index zurück. |
| [`get_name_by_index(self, index)`](/slides/python-net/de/aspose.slides/tagcollection/get_name_by_index/#int) | Gibt den Schlüssel eines Tags am angegebenen Index zurück. |
| [`get_names_of_tags(self)`](/slides/python-net/de/aspose.slides/tagcollection/get_names_of_tags/#) | Gibt die Namen der Tags zurück. |
