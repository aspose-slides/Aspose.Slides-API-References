## SensitivityLabel Klasse

Stellt das Sensitivitätslabel von Microsoft Purview Information Protection dar.

Der Typ SensitivityLabel stellt die folgenden Member bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`id`](/slides/python-net/de/aspose.slides/sensitivitylabel/id/) | Gibt die ID des Sensitivitätslabels zurück oder setzt sie.<br/>            Lesen/Schreiben **str**. |
| [`site_id`](/slides/python-net/de/aspose.slides/sensitivitylabel/site_id/) | Gibt den Azure Active Directory (Azure AD)-Site-Bezeichner zurück oder setzt ihn <br/>            entsprechend der Sensitivitätslabel-Richtlinie, die das Sensitivitätslabel beschreibt.<br/>            Lesen/Schreiben **System.Guid**. |
| [`is_enabled`](/slides/python-net/de/aspose.slides/sensitivitylabel/is_enabled/) | Gibt an, ob das Sensitivitätslabel aktiviert ist. |
| [`is_removed`](/slides/python-net/de/aspose.slides/sensitivitylabel/is_removed/) | Gibt an, ob das Sensitivitätslabel entfernt wurde. |
| [`assignment_method_type`](/slides/python-net/de/aspose.slides/sensitivitylabel/assignment_method_type/) | Gibt die Zuweisungsmethode für das Sensitivitätslabel zurück oder setzt sie.<br/>            Lesen/Schreiben [`SensitivityLabelAssignmentType`](/slides/python-net/de/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/de/aspose.slides/sensitivitylabel/content_mark_types/) | Gibt die Liste der Inhaltkennzeichnungs-Typen zurück, die auf eine Datei angewendet werden sollten. |
