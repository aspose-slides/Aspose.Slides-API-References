## AudioPlayModePreset Aufzählung

Konstanten, die festlegen, wie ein Ton abgespielt wird.

Der Typ AudioPlayModePreset stellt die folgenden Member bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| MIXED |  |
| AUTO | Wird automatisch abgespielt. |
| ON_CLICK | Wird nur abgespielt, wenn das Symbol angeklickt wird. |
| ALL_SLIDES | Wird auf allen Folien abgespielt.<br/>Bitte verwenden Sie stattdessen die Eigenschaft [`IAudioFrame.play_across_slides`](/slides/python-net/de/aspose.slides/iaudioframe/play_across_slides).<br/>Dieses Element ist seit PowerPoint 2013 veraltet. |
| IN_CLICK_SEQUENCE | Wird automatisch mit einem Klick abgespielt. |
