## insert_clone(self, index, source_master) {#int-imasterslide}
Fügt eine Kopie einer angegebenen Masterfolie an der angegebenen Position der Sammlung ein. Zugehörige Layout-Folien werden ebenfalls kopiert.

### Rückgabe

Eingefügte Masterfolie.

    ...
