## SlideSizeType Aufzählung

Stellt die voreingestellte Foliengröße dar.

Der Typ SlideSizeType enthält die folgenden Mitglieder:

## Felder

| Feld | Beschreibung |
| :- | :- |
| ON_SCREEN | Auf Bildschirm 4x3 |
| LETTER_PAPER | Letter |
| A4_PAPER | A4 |
| SLIDE_35MM | Folienformat 35mm |
| OVERHEAD | Overhead |
| BANNER | Banner |
| CUSTOM | Benutzerdefinierte Größe |
| LEDGER | Ledger |
| A3_PAPER | A3 |
| B4_ISO_PAPER | B4 ISO |
| B5_ISO_PAPER | B5 ISO |
| B4_JIS_PAPER | B4 JIS |
| B5_JIS_PAPER | B5 JIS |
| HAGAKI_CARD | Hagaki-Karte |
| ON_SCREEN_16X9 | Auf Bildschirm 16x9 |
| ON_SCREEN_16X10 | Auf Bildschirm 16x10 |
| WIDESCREEN | Widescreen |
