## SlideLayoutType Aufzählung

Repräsentiert den Folienlayouttyp.

Der SlideLayoutType-Typ stellt die folgenden Member bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| CUSTOM | Benutzerdefiniert |
| TITLE | Titel |
| TEXT | Text |
| TWO_COLUMN_TEXT | Zweispaltiger Text |
| TABLE | Tabelle |
| TEXT_AND_CHART | Text und Diagramm |
| CHART_AND_TEXT | Diagramm und Text |
| DIAGRAM | Diagramm |
| CHART | Diagramm |
| TEXT_AND_CLIP_ART | Text und ClipArt |
| CLIP_ART_AND_TEXT | ClipArt und Text |
| TITLE_ONLY | Nur Titel |
| BLANK | Leer |
| TEXT_AND_OBJECT | Text und Objekt |
| OBJECT_AND_TEXT | Objekt und Text |
| OBJECT | Objekt |
| TITLE_AND_OBJECT | Titel und Objekt |
| TEXT_AND_MEDIA | Text und Medien |
| MEDIA_AND_TEXT | Medien und Text |
| OBJECT_OVER_TEXT | Objekt über Text |
| TEXT_OVER_OBJECT | Text über Objekt |
| TEXT_AND_TWO_OBJECTS | Text und zwei Objekte |
| TWO_OBJECTS_AND_TEXT | Zwei Objekte und Text |
| TWO_OBJECTS_OVER_TEXT | Zwei Objekte über Text |
| FOUR_OBJECTS | Vier Objekte |
| VERTICAL_TEXT | Vertikaler Text |
| CLIP_ART_AND_VERTICAL_TEXT | ClipArt und vertikaler Text |
| VERTICAL_TITLE_AND_TEXT | Vertikaler Titel und Text |
| VERTICAL_TITLE_AND_TEXT_OVER_CHART | Vertikaler Titel und Text über Diagramm |
| TWO_OBJECTS | Zwei Objekte |
| OBJECT_AND_TWO_OBJECT | Objekt und zwei Objekte |
| TWO_OBJECTS_AND_OBJECT | Zwei Objekte und Objekt |
| SECTION_HEADER | Abschnittsüberschrift |
| TWO_TEXT_AND_TWO_OBJECTS | Zwei Texte und zwei Objekte |
| TITLE_OBJECT_AND_CAPTION | Titel, Objekt und Beschriftung |
| PICTURE_AND_CAPTION | Bild und Beschriftung |
