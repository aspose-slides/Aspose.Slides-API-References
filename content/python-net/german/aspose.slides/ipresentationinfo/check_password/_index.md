## check_password(self, password) {#str}
Überprüft, ob ein Passwort für eine mit offenem Passwort geschützte Präsentation korrekt ist.

### Rückgabewert

True, wenn die Präsentation mit offenem Passwort geschützt ist und das Passwort korrekt ist, sonst false.



```python
def check_password(self, password):
    ...
```


| Parameter | Typ | Beschreibung |
| :- | :- | :- |
| password | **str** | Das zu prüfende Passwort. |

### Bemerkungen

Wenn das Passwort None oder leer ist, gibt diese Methode false zurück.
