## Control Klasse

Stellt ein ActiveX-Steuerelement dar.

Der Control Typ stellt die folgenden Member bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`persistence`](/slides/python-net/de/aspose.slides/control/persistence/) | Gibt die Methode zurück, die zum Speichern von Eigenschaften des ActiveX-Steuerelements verwendet wird.<br/>            Nur lesbar [`PersistenceType`](/slides/python-net/de/aspose.slides/persistencetype). |
| [`name`](/slides/python-net/de/aspose.slides/control/name/) | Gibt den Namen dieses Steuerelements zurück oder legt ihn fest.<br/>            Lese/Schreib **str**. |
| [`class_id`](/slides/python-net/de/aspose.slides/control/class_id/) | Gibt die Klassen-ID dieses Steuerelements zurück.<br/>            Nur lesbar **System.Guid**. |
| [`substitute_picture_format`](/slides/python-net/de/aspose.slides/control/substitute_picture_format/) | Gibt das Bildfüllungs-Eigenschaften-Objekt von Control zurück.<br/>            Nur lesbar [`IPictureFillFormat`](/slides/python-net/de/aspose.slides/ipicturefillformat). |
| [`frame`](/slides/python-net/de/aspose.slides/control/frame/) | Gibt den Rahmen des Steuerelements zurück oder legt ihn fest.<br/>            Lese/Schreib [`IShapeFrame`](/slides/python-net/de/aspose.slides/ishapeframe). |
| [`properties`](/slides/python-net/de/aspose.slides/control/properties/) | Gibt eine Sammlung von ActiveX-Eigenschaften zurück.<br/>            Hinweis: Aspose.Slides unterstützt nur XML-basierte ActiveX-Eigenschaften. Wenn Eigenschaften im Binärformat gespeichert werden, gibt diese Eigenschaft None zurück.<br/>            Nur lesbar [`IControlPropertiesCollection`](/slides/python-net/de/aspose.slides/icontrolpropertiescollection). |
| [`active_x_control_binary`](/slides/python-net/de/aspose.slides/control/active_x_control_binary/) | Gibt die Persistenz eines ActiveX-Steuerelements an, wenn die zum Persistieren verwendete Methode entweder PersistStream, PersistStreamInit oder PersistStorage ist. |
