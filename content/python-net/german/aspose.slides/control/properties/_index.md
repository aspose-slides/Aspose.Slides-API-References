## properties property
Gibt eine Sammlung von ActiveX-Eigenschaften zurück.
            Hinweis: Aspose.Slides unterstützt nur XML-basierte ActiveX-Eigenschaften. Wenn Eigenschaften im Binärformat gespeichert werden, gibt diese Eigenschaft None zurück.
            Nur-Lesen [`IControlPropertiesCollection`](/slides/python-net/de/aspose.slides/icontrolpropertiescollection).
