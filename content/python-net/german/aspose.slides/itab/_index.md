## ITab Klasse

Stellt eine Tabulation für einen Text dar.

Der ITab-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`position`](/slides/python-net/de/aspose.slides/itab/position/) | Gibt die Position eines Tabulators zurück oder legt sie fest.<br/>            Das Zuweisen dieser Eigenschaft kann den Index des Tabulators in der Sammlung ändern und den Enumerator ungültig machen.<br/>            Lesen/Schreiben **float**. |
| [`alignment`](/slides/python-net/de/aspose.slides/itab/alignment/) | Gibt den Ausrichtungsstil eines Tabulators zurück oder legt ihn fest.<br/>            Lesen/Schreiben [`TabAlignment`](/slides/python-net/de/aspose.slides/tabalignment). |
