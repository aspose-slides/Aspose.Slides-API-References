## ICustomXmlPart Klasse

Stellt ein benutzerdefiniertes xml-Teil dar.

Der ICustomXmlPart-Typ stellt die folgenden Member bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`xml_as_string`](/slides/python-net/de/aspose.slides/icustomxmlpart/xml_as_string/) | Gibt xml-Daten als UTF-8-Zeichenfolge zurück oder legt sie fest.<br/>            Lesen/Schreiben **str**.<br/>            Der Wert ist `None`.Der Wert ist leer oder xml-Daten sind ungültig. |
| [`xml_data`](/slides/python-net/de/aspose.slides/icustomxmlpart/xml_data/) | Gibt xml-Daten zurück oder legt sie fest.<br/>            Lesen/Schreiben **int**[].<br/>            Der Wert ist `None`.Der Wert ist leer oder xml-Daten sind ungültig. |
| [`item_id`](/slides/python-net/de/aspose.slides/icustomxmlpart/item_id/) | Gibt einen global eindeutigen Bezeichner (GUID) an, der ein einzelnes benutzerdefiniertes XML-Teil innerhalb eines Office Open XML-Dokuments eindeutig identifiziert.<br/>            Nur lesbar **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/de/aspose.slides/icustomxmlpart/namespace_schemas/) | Gibt die Sammlung von XML-Schemas zurück, die dem benutzerdefinierten XML-Teil zugeordnet sind.<br/>            Nur lesbar **str**[]. |

## Methoden

| Methode | Beschreibung |
| :- | :- |
| [`remove(self)`](/slides/python-net/de/aspose.slides/icustomxmlpart/remove/#) | Entfernt das benutzerdefinierte xml-Teil aus der Präsentation. |
