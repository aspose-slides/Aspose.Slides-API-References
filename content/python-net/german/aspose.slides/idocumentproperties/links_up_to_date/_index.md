## links_up_to_date Eigenschaft
Gibt an, ob Hyperlinks in einem Dokument aktuell sind.
Setzen Sie dieses Element auf **true**, um anzugeben, dass Hyperlinks aktualisiert sind.
Setzen Sie dieses Element auf **false**, um anzugeben, dass Hyperlinks veraltet sind.
Lesen/Schreiben **bool**.
