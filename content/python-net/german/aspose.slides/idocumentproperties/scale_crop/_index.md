## scale_crop Eigenschaft
Gibt den Anzeigemodus der Dokumentenminiatur an. 
            Setzen Sie dieses Element auf **true**  um die Skalierung der Dokumentenminiatur für die Anzeige zu aktivieren. 
            Setzen Sie dieses Element auf **false**  um das Zuschneiden der Dokumentenminiatur zu aktivieren, sodass nur Abschnitte angezeigt werden, die in die Anzeige passen.
            Lese-/Schreib **bool**.
