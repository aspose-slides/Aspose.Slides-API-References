## remove_custom_property(self, name) {#str}
Entfernt eine benutzerdefinierte Eigenschaft, die mit einem angegebenen Namen verknüpft ist.

### Rückgabewert

Gibt true zurück, wenn eine Eigenschaft entfernt wurde, andernfalls false.



```python
def remove_custom_property(self, name):
    ...
```


| Parameter | Typ | Beschreibung |
| :- | :- | :- |
| name | **str** | Name einer benutzerdefinierten Eigenschaft, die entfernt werden soll. |
