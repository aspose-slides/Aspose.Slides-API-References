## app_version Eigenschaft
Gibt die App-Version zurück.
            Nur-Lesen **str**.


### Bemerkungen

Der Inhalt dieses Elements muss das Format XX.YYYY haben, wobei X und Y numerische Werte darstellen; andernfalls wird das Dokument als nicht konform angesehen.
            Aspose.Slides stellt seine Version im Format XX.YYZZ dar, wobei:
            XX - Hauptversion
            YY - Nebenversion
            ZZ - Patch-Version
            Zum Beispiel bedeutet der Wert 23.0105 die Aspose.Slides-Version 23.1.5.
