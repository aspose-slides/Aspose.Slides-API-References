## IParagraph Klasse

Stellt einen Absatz eines Textes dar.

Der IParagraph-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`portions`](/slides/python-net/de/aspose.slides/iparagraph/portions/) | Gibt die Sammlung von Textabschnitten zurück.<br/>            Nur lesend [`IPortionCollection`](/slides/python-net/de/aspose.slides/iportioncollection). |
| [`paragraph_format`](/slides/python-net/de/aspose.slides/iparagraph/paragraph_format/) | Gibt das Formatierungsobjekt für diesen Absatz zurück.<br/>            Nur lesend [`IParagraphFormat`](/slides/python-net/de/aspose.slides/iparagraphformat). |
| [`text`](/slides/python-net/de/aspose.slides/iparagraph/text/) | Ruft den Klartext eines Absatzes ab oder legt ihn fest.<br/>            Lesen/Schreiben **str**. |
| [`end_paragraph_portion_format`](/slides/python-net/de/aspose.slides/iparagraph/end_paragraph_portion_format/) | Gibt die Abschnitteigenschaften an, die verwendet werden sollen, wenn ein weiterer Abschnitt nach dem letzten eingefügt wird. |
| [`slide`](/slides/python-net/de/aspose.slides/iparagraph/slide/) |  |
| [`presentation`](/slides/python-net/de/aspose.slides/iparagraph/presentation/) |  |

## Methoden

| Methode | Beschreibung |
| :- | :- |
| [`get_image`](/slides/python-net/de/aspose.slides/iparagraph/get_image/#) | Gibt ein Bild des Absatzes zurück. |
| [`get_image`](/slides/python-net/de/aspose.slides/iparagraph/get_image/#float-float) | Gibt ein Bild des Absatzes mit dem angegebenen Maßstab zurück. |
| [`join_portions_with_same_formatting`](/slides/python-net/de/aspose.slides/iparagraph/join_portions_with_same_formatting/#) | Verbindet Läufe mit derselben Formatierung. |
| [`get_rect`](/slides/python-net/de/aspose.slides/iparagraph/get_rect/#) | Ermittelt die Koordinaten des Rechtecks, das den Absatz begrenzt. Das Rechteck enthält alle Zeilen von<br/>            Text im Absatz, einschließlich leerer. |
| [`get_lines_count`](/slides/python-net/de/aspose.slides/iparagraph/get_lines_count/#) | Ermittelt die Anzahl der Zeilen in einem Absatz. |
