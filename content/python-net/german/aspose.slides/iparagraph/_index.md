## IParagraph class

Stellt einen Absatz eines Textes dar.

Der IParagraph-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`portions`](/slides/python-net/de/aspose.slides/iparagraph/portions/) | Gibt die Sammlung von Textabschnitten zurück.<br/>            Nur lesbar [`IPortionCollection`](/slides/python-net/de/aspose.slides/iportioncollection). |
| [`paragraph_format`](/slides/python-net/de/aspose.slides/iparagraph/paragraph_format/) | Gibt das Formatierungsobjekt für diesen Absatz zurück.<br/>            Nur lesbar [`IParagraphFormat`](/slides/python-net/de/aspose.slides/iparagraphformat). |
| [`text`](/slides/python-net/de/aspose.slides/iparagraph/text/) | Liest oder setzt den reinen Text eines Absatzes.<br/>            Lesen/Schreiben **str**. |
| [`end_paragraph_portion_format`](/slides/python-net/de/aspose.slides/iparagraph/end_paragraph_portion_format/) | Gibt die Abschnittseigenschaften an, die verwendet werden sollen, wenn ein weiterer Abschnitt nach <br/>            dem letzten eingefügt wird. |
| [`slide`](/slides/python-net/de/aspose.slides/iparagraph/slide/) |  |
| [`presentation`](/slides/python-net/de/aspose.slides/iparagraph/presentation/) |  |

## Methoden

| Methode | Beschreibung |
| :- | :- |
| [`get_image(self)`](/slides/python-net/de/aspose.slides/iparagraph/get_image/#) | Gibt ein Bild des Absatzes zurück. |
| [`get_image(self, scale_x, scale_y)`](/slides/python-net/de/aspose.slides/iparagraph/get_image/#float-float) | Gibt ein Bild des Absatzes mit dem angegebenen Maßstab zurück. |
| [`join_portions_with_same_formatting(self)`](/slides/python-net/de/aspose.slides/iparagraph/join_portions_with_same_formatting/#) | Verbindet Läufe mit gleicher Formatierung. |
| [`get_rect(self)`](/slides/python-net/de/aspose.slides/iparagraph/get_rect/#) | Ermittelt die Koordinaten des Rechtecks, das den Absatz begrenzt. Das Rechteck umfasst alle Zeilen von<br/>            Text im Absatz, einschließlich leerer Zeilen. |
| [`get_lines_count(self)`](/slides/python-net/de/aspose.slides/iparagraph/get_lines_count/#) | Ermittelt die Anzahl der Zeilen in einem Absatz. |
