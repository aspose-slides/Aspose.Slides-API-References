## get_font_bytes(self, font_data, font_style) {#ifontdata-fontstyletype}
Ruft das Byte-Array ab, das die Font-Daten für den angegebenen Font-Stil und Font-Daten darstellt.

### Rückgabe
Ein Byte-Array, das die Font-Daten für den angegebenen Font-Stil enthält. Wenn die Font-Daten oder der Stil nicht gefunden werden, wird None zurückgegeben.

```python
def get_font_bytes(self, font_data, font_style):
    ...
```

| :- | :- | :- |
| font_data | [`IFontData`](/slides/python-net/de/aspose.slides/ifontdata) | Das Font-Datenobjekt, das die Informationen über die Schrift [`IFontData`](/slides/python-net/de/aspose.slides/ifontdata) enthält. |
| font_style | [`FontStyleType`](/slides/python-net/de/aspose.slides/fontstyletype) | Der Stil der Schrift, für die die Daten abgerufen werden sollen [`FontStyleType`](/slides/python-net/de/aspose.slides/fontstyletype). |
