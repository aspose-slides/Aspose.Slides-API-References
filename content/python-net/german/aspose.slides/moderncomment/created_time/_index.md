## created_time Eigenschaft
Gibt die Zeit der Erstellung eines Kommentars zurück oder legt sie fest.
            Das Festlegen dieser Eigenschaft auf **System.DateTime** bedeutet, dass keine Kommentarzeit festgelegt ist.
            Lesen/Schreiben **System.DateTime**.


### Anmerkungen

Die Kommentarzeit ist ein optionaler Parameter.
