## IAnimationTimeLine Klasse

Stellt die Zeitleiste der Animation dar.

Der Typ IAnimationTimeLine stellt die folgenden Member bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`interactive_sequences`](/slides/python-net/de/aspose.slides/ianimationtimeline/interactive_sequences/) | Gibt eine Sammlung interaktiver Sequenzen zurück.<br/>            Diese Sequenzen können nur Effekte durch "Klick auf Form" mit angegebenem Zielobjekt enthalten.<br/>            Schreibgeschützt [`ISequenceCollection`](/slides/python-net/de/aspose.slides.animation/isequencecollection). |
| [`main_sequence`](/slides/python-net/de/aspose.slides/ianimationtimeline/main_sequence/) | Gibt die Hauptsequenz zurück, die möglicherweise nur die Haupt-Effektsammlungen enthält.<br/>            Schreibgeschützt [`ISequence`](/slides/python-net/de/aspose.slides.animation/isequence). |
| [`text_animation_collection`](/slides/python-net/de/aspose.slides/ianimationtimeline/text_animation_collection/) | Gibt eine Sammlung von Textanimationen zurück.<br/>            Schreibgeschützt [`ITextAnimationCollection`](/slides/python-net/de/aspose.slides.animation/itextanimationcollection). |
