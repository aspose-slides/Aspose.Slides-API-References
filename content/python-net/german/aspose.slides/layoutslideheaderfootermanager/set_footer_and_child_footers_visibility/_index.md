## set_footer_and_child_footers_visibility(self, is_visible) {#bool}
Ändert die Sichtbarkeit des Folienfußzeilenplatzhalters im Layout und aller untergeordneten Fußzeilenplatzhalter.
            Untergeordnete Platzhalter bedeuten, dass Platzhalter auf abhängigen Folien enthalten sind.
            Abhängige Folien verwenden und basieren auf der Masterfolie.

```python
    ...
```


| Parameter | Typ | Beschreibung |
| :- | :- | :- |
| is_visible | **bool** | true - macht die Fußzeilenplatzhalter sichtbar, sonst - blendet sie aus. |
