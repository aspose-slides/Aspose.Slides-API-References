## set_date_time_and_child_date_times_visibility(self, is_visible) {#bool}
Ändert die Sichtbarkeit des Datums-Uhrzeit-Platzhalters der Layout-Folie und aller untergeordneten Datums-Uhrzeit-Platzhalter.
Kind-Platzhalter bedeuten, dass Platzhalter auf abhängigen Folien enthalten sind.
Abhängige Folien verwenden und hängen vom Layout-Folie ab.

```python
def set_date_time_and_child_date_times_visibility(self, is_visible):
    ...
```

| Parameter | Typ | Beschreibung |
| :- | :- | :- |
| is_visible | **bool** | true - macht Datums-Uhrzeit-Platzhalter sichtbar, andernfalls - blendet sie aus. |
