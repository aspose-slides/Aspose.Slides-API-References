## INormalViewRestoredProperties Klasse

Gibt die Größe des Folienbereichs an ((Breite, wenn ein Kind von restoredTop, Höhe, wenn ein Kind von restoredLeft) der Normalansicht, wenn der Bereich eine variable wiederhergestellte Größe hat (weder minimiert noch maximiert).

Der Typ INormalViewRestoredProperties stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`dimension_size`](/slides/python-net/de/aspose.slides/inormalviewrestoredproperties/dimension_size/) | Gibt die Größe des Folienbereichs an (Breite, wenn ein Kind von RestoredTop, Höhe, wenn ein Kind von RestoredLeft).<br/>            Read/write **float**.<br/>            Wirft, wenn der Wert kleiner als 0 oder größer als 100 ist. |
| [`auto_adjust`](/slides/python-net/de/aspose.slides/inormalviewrestoredproperties/auto_adjust/) | Gibt an, ob die Größe des Seiteninhaltsbereichs die neue Größe kompensieren soll, wenn das Fenster, das die Ansicht innerhalb der Anwendung enthält, geändert wird.<br/>            Read/write **bool**. |
