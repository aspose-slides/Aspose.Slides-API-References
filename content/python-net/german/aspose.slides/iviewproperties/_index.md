## IViewProperties Klasse

Anzeigeeigenschaften für die gesamte Präsentation.

Der Typ IViewProperties stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`last_view`](/slides/python-net/de/aspose.slides/iviewproperties/last_view/) | Gibt den Ansichtmodus an, der verwendet wurde, als das Präsentationsdokument zuletzt gespeichert wurde.<br/>            Lesen/Schreiben [`ViewType`](/slides/python-net/de/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/de/aspose.slides/iviewproperties/show_comments/) | Gibt an, ob die Folienkommentare angezeigt werden sollen.<br/>            Lesen/Schreiben [`NullableBool`](/slides/python-net/de/aspose.slides/nullablebool). |
| [`slide_view_properties`](/slides/python-net/de/aspose.slides/iviewproperties/slide_view_properties/) | Gibt die allgemeinen Ansichtseigenschaften an, die mit dem Folienansichtsmodus verbunden sind.<br/>            Schreibgeschützt [`ICommonSlideViewProperties`](/slides/python-net/de/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/de/aspose.slides/iviewproperties/notes_view_properties/) | Gibt die allgemeinen Ansichtseigenschaften an, die mit dem Notizansichtsmodus verbunden sind.<br/>            Schreibgeschützt [`ICommonSlideViewProperties`](/slides/python-net/de/aspose.slides/icommonslideviewproperties). |
| [`normal_view_properties`](/slides/python-net/de/aspose.slides/iviewproperties/normal_view_properties/) | Stellt die normalen Ansichtseigenschaften dar. Die normale Ansicht besteht aus<br/>            drei Inhaltsbereichen: der Folie selbst, einem seitlichen Inhaltsbereich und einem unteren Inhaltsbereich.<br/>            Schreibgeschützt [`INormalViewProperties`](/slides/python-net/de/aspose.slides/inormalviewproperties). |
| [`grid_spacing`](/slides/python-net/de/aspose.slides/iviewproperties/grid_spacing/) | Gibt den Rasterabstand zurück oder legt ihn fest, der für das dem Präsentationsdokument zugrunde liegende Raster in Punkten verwendet werden soll. <br/>            Lesen/Schreiben **float**. |
