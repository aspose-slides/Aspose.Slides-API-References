## ResourceLoadingAction Aufzählung

Gibt den Modus des Ladens externer Ressourcen an.

Der Typ ResourceLoadingAction stellt die folgenden Member bereit:

## Felder

| Field | Description |
| :- | :- |
| DEFAULT | Aspose.Slides lädt externe Ressourcen wie üblich. |
| SKIP | Aspose.Slides überspringt das Laden externer Ressourcen. Es wird nur ein Link ohne Daten für ein Bild gespeichert. |
| USER_PROVIDED | Aspose.Slides verwendet das vom Benutzer bereitgestellte Byte-Array in **Aspose.Slides.IResourceLoadingArgs.SetData(Syste** als Bilddaten. |
