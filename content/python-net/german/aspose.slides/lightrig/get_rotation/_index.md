## get_rotation(self) {#}
Eine Drehung wird definiert durch die Verwendung eines Breitengrads
            Koordinate, eine Längengrad-Koordinate und eine Umdrehung um die Achse 
            als die Breitengrad- und Längengrad-Koordinaten.
            erstes Element im Rückgabe-Array - Breitengrad, zweites - Längengrad, drittes - Umdrehung.
            Gibt None zurück, wenn keine Drehung definiert ist.
