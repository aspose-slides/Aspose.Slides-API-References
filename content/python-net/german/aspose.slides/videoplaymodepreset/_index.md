## VideoPlayModePreset Aufzählung

Konstanten, die definieren, wie ein Video wiedergegeben wird.

Der Typ VideoPlayModePreset stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| MIXED |  |
| AUTO | Wird automatisch wiedergegeben. |
| ON_CLICK | Wird nur abgespielt, wenn das Video-Frame angeklickt wird. |
| ALL_SLIDES | Wird auf allen Folien wiedergegeben. |
| IN_CLICK_SEQUENCE | Wird automatisch mit einem Klick wiedergegeben. |
