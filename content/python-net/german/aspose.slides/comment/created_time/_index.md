## created_time Eigenschaft
Gibt die Zeit einer Kommentarerstellung zurück oder legt sie fest.
            Das Setzen dieser Eigenschaft auf **System.DateTime** bedeutet, dass keine Kommentarzeit festgelegt ist.
            Lesen/Schreiben **System.DateTime**.


### Anmerkungen

Die Kommentarzeit ist ein optionaler Parameter.
