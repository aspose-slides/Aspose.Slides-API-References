## TextVerticalType Aufzählung

Bestimmt den vertikalen Schreibmodus für einen Text.

Der Typ TextVerticalType enthält die folgenden Member:

## Felder

| Feld | Beschreibung |
| :- | :- |
| NOT_DEFINED | Nicht definiert. |
| HORIZONTAL | Horizontaler Text. |
| VERTICAL | Vertikaler Text. |
| VERTICAL270 | Vertikaler Text mit 270 Grad. |
| WORD_ART_VERTICAL | Vertikaler WordArt-Text. |
| EAST_ASIAN_VERTICAL | Ostasianischer vertikaler Text. |
| MONGOLIAN_VERTICAL | Mongolischer vertikaler Text. |
| WORD_ART_VERTICAL_RIGHT_TO_LEFT | Vertikaler WordArt-Text von rechts nach links. |
