## to_string(self) {#}
Konvertiert diese Farbe in einen lesbaren String. Der gleiche Text wird von `str()` und `repr()` zurückgegeben.

### Rückgabe

`Color [Red]` für eine benannte Farbe, `Color [Empty]` für `Color.empty` oder `Color [A=255, R=1, G=2, B=3]` für eine aus Komponenten erstellte Farbe.
