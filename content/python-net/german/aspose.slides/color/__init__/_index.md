## __init__(self, r=0, g=0, b=0, a=255) {#int-int-int-int}
Erstellt eine Farbe aus den angegebenen Rot-, Grün-, Blau- und Alpha-Komponentenwerten.


```python
def __init__(self, r=0, g=0, b=0, a=255):
    ...
```


| Parameter | Typ | Beschreibung |
| :- | :- | :- |
| r | **int** | Der Rot-Komponentenwert. Gültige Werte liegen zwischen 0 und 255. |
| g | **int** | Der Grün-Komponentenwert. Gültige Werte liegen zwischen 0 und 255. |
| b | **int** | Der Blau-Komponentenwert. Gültige Werte liegen zwischen 0 und 255. |
| a | **int** | Der Alpha-Komponentenwert. Gültige Werte liegen zwischen 0 und 255. |

### Ausnahmen

| Ausnahme | Beschreibung |
| :- | :- |
| **ValueError** | Ein Komponentenwert ist kleiner als 0 oder größer als 255. |
| **TypeError** | Ein Komponentenwert ist keine Zahl. |
