## is_system_color Eigenschaft
Gibt an, ob diese Farbe eine Systemfarbe ist: eine Farbe, die für ein Windows-Anzeigeelement verwendet wird, wie z. B. `Control` oder `ActiveBorder`.<br/>            Systemfarben werden nicht als `Color`-Attribute bereitgestellt und können nur mit [`from_known_color`](/slides/python-net/de/aspose.slides/color/from_known_color/) abgerufen oder von der Bibliothek zurückgegeben werden.
            Nur lesbar **bool**.
