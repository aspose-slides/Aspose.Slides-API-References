## is_bullet_hard_font Eigenschaft
Bestimmt, ob das Aufzählungszeichen eine eigene Schriftart hat oder sie vom ersten Abschnitt im Absatz erbt.
            Gibt **true**  zurück, wenn das Aufzählungszeichen eine eigene Schriftart hat und **true**  zurück, wenn das Aufzählungszeichen die Schriftart vom ersten Abschnitt im Absatz erbt.
            Nur-Lesen **bool**.
