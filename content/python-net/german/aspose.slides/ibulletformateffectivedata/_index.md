## IBulletFormatEffectiveData Klasse

Unveränderliches Objekt, das die wirksamen Aufzählungsformatierungseigenschaften eines Absatzes enthält.

Der IBulletFormatEffectiveData-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Property | Description |
| :- | :- |
| [`type`](/slides/python-net/de/aspose.slides/ibulletformateffectivedata/type/) | Returns the bullet type of a paragraph.<br/>            Nur lesbar [`BulletType`](/slides/python-net/de/aspose.slides/bullettype). |
| [`char`](/slides/python-net/de/aspose.slides/ibulletformateffectivedata/char/) | Returns the bullet char of a paragraph.<br/>            Nur lesbar **System.Char**. |
| [`actual_bullet_value`](/slides/python-net/de/aspose.slides/ibulletformateffectivedata/actual_bullet_value/) | Returns actual bullet value for parent paragraph.<br/>            Nur lesbar **str**. |
| [`font`](/slides/python-net/de/aspose.slides/ibulletformateffectivedata/font/) | Returns the bullet font of a paragraph.<br/>            Nur lesbar [`IFontData`](/slides/python-net/de/aspose.slides/ifontdata). |
| [`height`](/slides/python-net/de/aspose.slides/ibulletformateffectivedata/height/) | Returns the bullet height of a paragraph.<br/>            Nur lesbar **float**. |
| [`numbered_bullet_start_with`](/slides/python-net/de/aspose.slides/ibulletformateffectivedata/numbered_bullet_start_with/) | Returns the first number which is used for group of numbered bullets.<br/>            Nur lesbar **int**. |
| [`numbered_bullet_style`](/slides/python-net/de/aspose.slides/ibulletformateffectivedata/numbered_bullet_style/) | Returns the style of a numbered bullet.<br/>            Nur lesbar [`NumberedBulletStyle`](/slides/python-net/de/aspose.slides/numberedbulletstyle). |
| [`is_bullet_hard_color`](/slides/python-net/de/aspose.slides/ibulletformateffectivedata/is_bullet_hard_color/) | Determines whether the bullet has own color or inherits it from the first portion in the paragraph.<br/>            Gibt **true** zurück, wenn die Aufzählung eine eigene Farbe hat und **false** zurück, wenn die Aufzählung die Farbe vom ersten Abschnitt im Absatz erbt.<br/>            Nur lesbar **bool**. |
| [`is_bullet_hard_font`](/slides/python-net/de/aspose.slides/ibulletformateffectivedata/is_bullet_hard_font/) | Determines whether the bullet has own font or inherits it from the first portion in the paragraph.<br/>            Gibt **true** zurück, wenn die Aufzählung eine eigene Schriftart hat und **true** zurück, wenn die Aufzählung die Schriftart vom ersten Abschnitt im Absatz erbt.<br/>            Nur lesbar **bool**. |
| [`picture`](/slides/python-net/de/aspose.slides/ibulletformateffectivedata/picture/) | Returns the picture used as a bullet in the paragraph.<br/>            Nur lesbar [`IPictureEffectiveData`](/slides/python-net/de/aspose.slides/ipictureeffectivedata). |
