## CommentAuthor Klasse

Stellt einen Autor von Kommentaren dar.

Der Typ CommentAuthor stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`name`](/slides/python-net/de/aspose.slides/commentauthor/name/) | Gibt den Namen des Autors zurück oder setzt ihn.<br/>            Lesen/Schreiben **str**. |
| [`initials`](/slides/python-net/de/aspose.slides/commentauthor/initials/) | Gibt die Initialen des Autors zurück oder setzt sie.<br/>            Lesen/Schreiben **str**. |
| [`comments`](/slides/python-net/de/aspose.slides/commentauthor/comments/) | Gibt die Sammlung der von diesem Autor erstellten Kommentare zurück.<br/>            Nur-Lesen [`ICommentCollection`](/slides/python-net/de/aspose.slides/icommentcollection). |

## Methoden

| Methode | Beschreibung |
| :- | :- |
| [`remove(self)`](/slides/python-net/de/aspose.slides/commentauthor/remove/#) | Entfernt den Autor aus der übergeordneten Sammlung. |
