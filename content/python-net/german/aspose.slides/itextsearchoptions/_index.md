## ITextSearchOptions Klasse

Stellt Optionen bereit, die zum Suchen von Text in einer Presentation, einem Slide oder einem TextFrame verwendet werden können.

Der Typ ITextSearchOptions stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Property | Description |
| :- | :- |
| [`case_sensitive`](/slides/python-net/de/aspose.slides/itextsearchoptions/case_sensitive/) | Set true, um eine case-sensitive Suche zu verwenden, false – sonst.<br/>            Lesen/Schreiben **bool**. |
| [`whole_words_only`](/slides/python-net/de/aspose.slides/itextsearchoptions/whole_words_only/) | Set true, um nur ganze Wörter zu matchen, false – sonst.<br/>            Lesen/Schreiben **bool**. |
| [`include_notes`](/slides/python-net/de/aspose.slides/itextsearchoptions/include_notes/) | Set `true`, um Text, der in Foliennotizen enthalten ist, <br/>            bei der Durchführung von Textsuche, Ersetzung oder Hervorhebungs-Operationen einzuschließen.<br/>            Der Standardwert ist `false`. |
