## ViewType Aufzählung

Der ViewType-Typ stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| NOT_DEFINED | Wert ist nicht definiert |
| SLIDE_VIEW | Normale Folienansicht |
| SLIDE_MASTER_VIEW | Folienmaster-Ansicht |
| NOTES_VIEW | Notizenansicht |
| HANDOUT_VIEW | Handzettelansicht |
| NOTES_MASTER_VIEW | Notizenmaster-Ansicht |
| OUTLINE_VIEW | Gliederungsansicht |
| SLIDE_SORTER_VIEW | Foliensortieransicht |
| SLIDE_THUMBNAIL_VIEW | Folienminiaturansicht |
