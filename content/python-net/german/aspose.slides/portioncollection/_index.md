## PortionCollection Klasse

Stellt eine Sammlung von Portionen dar.

Der Typ PortionCollection stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`count`](/slides/python-net/de/aspose.slides/portioncollection/count/) | Gibt die tatsächlich in der Sammlung enthaltene Anzahl von Elementen zurück.<br/>            Nur lesbar **int**. |
| [`is_read_only`](/slides/python-net/de/aspose.slides/portioncollection/is_read_only/) | Gibt einen Wert zurück, der anzeigt, ob die **System.Collections.Generic.ICollection`1** schreibgeschützt ist.<br/>            Nur lesbar **bool**. |
