## insert_clone(self, index, source_master) {#int-imasterslide}
Fügt eine Kopie einer angegebenen Master-Folie an einer angegebenen Position der Sammlung ein.  
Verknüpfte Layout-Folien werden ebenfalls kopiert.

### Rückgabe

Eingefügte Master-Folie.

```python
def insert_clone(self, index, source_master):
    ...
```

| :- | :- | :- |
| index | **int** | Index der neuen Folie. |
| source_master | [`IMasterSlide`](/slides/python-net/de/aspose.slides/imasterslide) | Folie zum Klonen. |
