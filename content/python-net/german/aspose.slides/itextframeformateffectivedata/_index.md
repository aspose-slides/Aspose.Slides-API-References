## ITextFrameFormatEffectiveData Klasse

Unveränderliches Objekt, das die effektiven Textrahmen-Formatierungseigenschaften enthält.

Der Typ ITextFrameFormatEffectiveData stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Property | Description |
| :- | :- |
| [`text_style`](/slides/python-net/de/aspose.slides/itextframeformateffectivedata/text_style/) | Gibt den effektiven Textstil zurück.<br/>            Nur lesbar [`ITextStyleEffectiveData`](/slides/python-net/de/aspose.slides/itextstyleeffectivedata). |
| [`margin_left`](/slides/python-net/de/aspose.slides/itextframeformateffectivedata/margin_left/) | Gibt den linken Rand (Punkte) in einem TextFrame zurück.<br/>            Nur lesbar **float**. |
| [`margin_right`](/slides/python-net/de/aspose.slides/itextframeformateffectivedata/margin_right/) | Gibt den rechten Rand (Punkte) in einem TextFrame zurück.<br/>            Nur lesbar **float**. |
| [`margin_top`](/slides/python-net/de/aspose.slides/itextframeformateffectivedata/margin_top/) | Gibt den oberen Rand (Punkte) in einem TextFrame zurück.<br/>            Nur lesbar **float**. |
| [`margin_bottom`](/slides/python-net/de/aspose.slides/itextframeformateffectivedata/margin_bottom/) | Gibt den unteren Rand (Punkte) in einem TextFrame zurück.<br/>            Nur lesbar **float**. |
| [`wrap_text`](/slides/python-net/de/aspose.slides/itextframeformateffectivedata/wrap_text/) | Gibt zurück, ob Text an den Rändern des TextFrames umbrochen wird.<br/>            Nur lesbar **bool**. |
| [`anchoring_type`](/slides/python-net/de/aspose.slides/itextframeformateffectivedata/anchoring_type/) | Gibt den vertikalen Ankertext in einem TextFrame zurück.<br/>            Nur lesbar [`TextAnchorType`](/slides/python-net/de/aspose.slides/textanchortype). |
| [`center_text`](/slides/python-net/de/aspose.slides/itextframeformateffectivedata/center_text/) | Gibt zurück, ob Text horizontal im Feld zentriert werden soll.<br/>            Nur lesbar **bool**. |
| [`text_vertical_type`](/slides/python-net/de/aspose.slides/itextframeformateffectivedata/text_vertical_type/) | Gibt die Textausrichtung zurück.<br/>            Nur lesbar [`TextVerticalType`](/slides/python-net/de/aspose.slides/textverticaltype). |
| [`autofit_type`](/slides/python-net/de/aspose.slides/itextframeformateffectivedata/autofit_type/) | Gibt den Text-Autofit-Modus zurück.<br/>            Nur lesbar [`TextAutofitType`](/slides/python-net/de/aspose.slides/textautofittype). |
| [`column_count`](/slides/python-net/de/aspose.slides/itextframeformateffectivedata/column_count/) | Gibt die Anzahl der Textspalten im Begrenzungsrechteck an.<br/>            Nur lesbar **int**. |
| [`column_spacing`](/slides/python-net/de/aspose.slides/itextframeformateffectivedata/column_spacing/) | Gibt den Abstand zwischen Textspalten im Textbereich (in Punkten) an.<br/>            Nur lesbar **float**. |

### Anmerkungen

Dieses Interface wird zusammen mit dem Interface [`ITextFrameFormat`](/slides/python-net/de/aspose.slides/itextframeformat) verwendet, um effektive Formatierungswerte mit angewandter Vererbung zurückzugeben.
