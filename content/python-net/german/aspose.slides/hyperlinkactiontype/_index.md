## HyperlinkActionType Aufzählung

Stellt einen Typ einer Hyperlink-Aktion dar.

Der Typ HyperlinkActionType stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| UNKNOWN | Nicht erkannter Aktionstyp. |
| NO_ACTION | Keine Aktion. |
| HYPERLINK | Üblicher Hyperlink. |
| JUMP_FIRST_SLIDE | Springt zur ersten Folie der Präsentation. |
| JUMP_PREVIOUS_SLIDE | Springt zur vorherigen Folie. |
| JUMP_NEXT_SLIDE | Springt zur nächsten Folie. |
| JUMP_LAST_SLIDE | Springt zur letzten Folie der Präsentation. |
| JUMP_END_SHOW | Springt zum Ende der Diashow. |
| JUMP_LAST_VIEWED_SLIDE | Springt zur zuletzt angezeigten Folie. |
| JUMP_SPECIFIC_SLIDE | Springt zur spezifischen Folie, die durch die [`IHyperlink.target_slide`](/slides/python-net/de/aspose.slides/ihyperlink/target_slide)-Eigenschaft referenziert wird. |
| START_CUSTOM_SLIDE_SHOW | Startet benutzerdefinierte Diashow. |
| OPEN_FILE | Öffnet referenzierte Datei. |
| OPEN_PRESENTATION | Öffnet referenzierte Präsentation. |
| START_STOP_MEDIA | Startet/stoppt das Abspielen einer Mediendatei. |
| START_MACRO | Startet die Ausführung eines Makro-Skripts. |
| START_PROGRAM | Startet das Programm. |
