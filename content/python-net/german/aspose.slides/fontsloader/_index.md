## FontsLoader Klasse

Klasse zum Laden benutzerdefinierter Schriften, die vom Benutzer definiert wurden.  
Sollte verwendet werden, bevor irgendwelche Präsentationsobjekte erstellt werden.

Der FontsLoader-Typ stellt die folgenden Mitglieder bereit:

## Methoden

| Method | Description |
| :- | :- |
| [`load_external_fonts(directories)`](/slides/python-net/de/aspose.slides/fontsloader/load_external_fonts/#liststr) | Fügt zusätzliche Ordner hinzu, um nach Schriften zu suchen. |
| [`load_external_font(data)`](/slides/python-net/de/aspose.slides/fontsloader/load_external_font/#bytes) | Fügt eine Schrift aus den Binärdaten hinzu. |
| [`get_font_folders()`](/slides/python-net/de/aspose.slides/fontsloader/get_font_folders/#) | Ermittelt Schriftordner. Gibt Ordner zurück, die mit der Methode LoadExternalFonts hinzugefügt wurden, sowie Systemschriftordner. |
| [`clear_cache()`](/slides/python-net/de/aspose.slides/fontsloader/clear_cache/#) | Gibt alle vom Benutzer definierten benutzerdefinierten Schriften frei. |
