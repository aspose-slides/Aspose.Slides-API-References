## insert_audio_frame_linked(self, index, x, y, width, height, fname) {#int-float-float-float-float-str}
Erstellt einen neuen Audio-Frame, der mit einer externen Audiodatei verknüpft ist, und fügt ihn in die Shape-Sammlung am angegebenen Index ein.

### Rückgabewert

Der neu erstellte [`IAudioFrame`](/slides/python-net/de/aspose.slides/iaudioframe).

```python
def insert_audio_frame_linked(self, index, x, y, width, height, fname):
    ...
```


| Parameter | Typ | Beschreibung |
| :- | :- | :- |
| index | **int** | Der nullbasierte Index, an dem der Audio-Frame eingefügt werden soll. |
| x | **float** | Die x-Koordinate des neuen Audio-Frames, in Punkten. |
| y | **float** | Die y-Koordinate des neuen Audio-Frames, in Punkten. |
| width | **float** | Die Breite des neuen Audio-Frames, in Punkten. |
| height | **float** | Die Höhe des neuen Audio-Frames, in Punkten. |
| fname | **str** | Der Pfad oder Name der externen Audiodatei, die verknüpft werden soll. |
