Gibt einen internen, präsentationsbezogenen Bezeichner zurück, der von Add-Ins oder anderem Code verwendet werden soll.
            Because this value can be reassigned by the user or programmatically, it must not be treated
            as a persistent unique key.
            Read-only **int**.
