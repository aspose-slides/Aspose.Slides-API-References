## get_base_placeholder(self) {#}
Gibt eine grundlegende Platzhalterform zurück (Form aus dem Layout und/oder der Master-Folie, von der die aktuelle Form geerbt wird).
Es wird ein None zurückgegeben, wenn die aktuelle Form nicht geerbt wird.
