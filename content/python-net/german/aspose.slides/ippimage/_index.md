## IPPImage Klasse

Stellt ein Bild in einer Präsentation dar.

Der IPPImage-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`binary_data`](/slides/python-net/de/aspose.slides/ippimage/binary_data/) | Gibt eine Kopie der Bilddaten zurück.<br/>            Nur lesbar **int**[]. |
| [`image`](/slides/python-net/de/aspose.slides/ippimage/image/) | Gibt eine Kopie des Bildes zurück.<br/>            Nur lesbar [`IPPImage.image`](/slides/python-net/de/aspose.slides/ippimage/image). |
| [`svg_image`](/slides/python-net/de/aspose.slides/ippimage/svg_image/) | Gibt das ISvgImage-Objekt [`ISvgImage`](/slides/python-net/de/aspose.slides/isvgimage) zurück oder setzt es |
| [`content_type`](/slides/python-net/de/aspose.slides/ippimage/content_type/) | Gibt den MIME-Typ eines Bildes zurück, codiert in [`IPPImage.binary_data`](/slides/python-net/de/aspose.slides/ippimage/binary_data).<br/>            Nur lesbar **str**. |
| [`width`](/slides/python-net/de/aspose.slides/ippimage/width/) | Gibt die Breite eines Bildes zurück.<br/>            Nur lesbar **int**. |
| [`height`](/slides/python-net/de/aspose.slides/ippimage/height/) | Gibt die Höhe eines Bildes zurück.<br/>            Nur lesbar **int**. |
| [`x`](/slides/python-net/de/aspose.slides/ippimage/x/) | Gibt den X-Versatz eines Bildes zurück.<br/>            Nur lesbar **int**. |
| [`y`](/slides/python-net/de/aspose.slides/ippimage/y/) | Gibt den Y-Versatz eines Bildes zurück.<br/>            Nur lesbar **int**. |
