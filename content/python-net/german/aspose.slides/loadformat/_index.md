## LoadFormat-Aufzählung

Gibt das Format des zu ladenden Dokuments an.

Der Typ LoadFormat stellt die folgenden Mitglieder bereit:

## Fields

| Field | Description |
| :- | :- |
| AUTO | Weist Aspose.Slides an, das Format automatisch zu erkennen. |
| PPT | Microsoft PowerPoint 97-2003 Präsentation. |
| PPS | Microsoft PowerPoint 97-2003 Diashow. |
| PPTX | Microsoft Office Open XML PresentationML Dokument. |
| PPSX | Microsoft Office Open XML PresentationML Diashow. |
| ODP | OpenOffice ODF Präsentation. |
| POTX | Microsoft Office Open XML PresentationML Vorlage. |
| PPTM | Microsoft Office Open XML PresentationML Makro-unterstütztes Dokument. |
| PPSM | Microsoft Office Open XML PresentationML Makro-unterstützte Diashow. |
| POTM | Microsoft Office Open XML PresentationML Makro-unterstützte Vorlage. |
| OTP | OpenOffice OTP Präsentationsvorlage. |
| PPT95 | Microsoft PowerPoint 95 Präsentation. |
| POT | Microsoft PowerPoint 97-2003 Präsentationsvorlage. |
| FODP | Flat XML ODF Präsentation. |
| UNKNOWN | Unbekanntes Dateiformat |
