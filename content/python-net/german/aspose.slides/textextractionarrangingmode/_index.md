## TextExtractionArrangingMode Aufzählung

Stellt den Modus dar, der bei der Textextraktion verwendet wird

Der Typ TextExtractionArrangingMode stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| UNARRANGED | Der Rohtext, ohne Berücksichtigung der Position auf der Folie |
| ARRANGED | Der Text ist in derselben Reihenfolge wie auf der Folie positioniert |
