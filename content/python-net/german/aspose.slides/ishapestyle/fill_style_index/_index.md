## fill_style_index Eigenschaft
Returns or sets shape's fill column index in style matrices.
            0 bedeutet keine Füllung,
            positiver Wert - Index in theme's fill styles,
            negativer Wert - Index in theme's background styles.
            Lese/Schreib **int**.
