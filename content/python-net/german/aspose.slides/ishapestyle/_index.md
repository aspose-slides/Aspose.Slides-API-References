## IShapeStyle Klasse

Stellt die Stilreferenz einer Form dar.

Der Typ IShapeStyle stellt die folgenden Mitglieder bereit:

| Eigenschaft | Beschreibung |
| :- | :- |
| [`line_color`](/slides/python-net/de/aspose.slides/ishapestyle/line_color/) | Gibt die Umrissfarbe einer Form zurück.<br/>            Nur lesend [`IColorFormat`](/slides/python-net/de/aspose.slides/icolorformat). |

| [`fill_color`](/slides/python-net/de/aspose.slides/ishapestyle/fill_color/) | Gibt die Füllfarbe einer Form zurück.<br/>            Nur lesend [`IColorFormat`](/slides/python-net/de/aspose.slides/icolorformat). |
