## INormalViewProperties Klasse

Stellt Eigenschaften der Normalansicht dar. Die Normalansicht besteht aus drei Inhaltsbereichen: der Folie selbst, einem seitlichen Inhaltsbereich und einem unteren Inhaltsbereich.

Der INormalViewProperties-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Property | Description |
| :- | :- |
| [`show_outline_icons`](/slides/python-net/de/aspose.slides/inormalviewproperties/show_outline_icons/) | Gibt an, ob die Anwendung Symbole anzeigen soll, wenn Gliederungsinhalt in einem der Inhaltsbereiche des Normalansichtsmodus angezeigt wird.<br/>            Lesen/Schreiben **bool**. |
| [`snap_vertical_splitter`](/slides/python-net/de/aspose.slides/inormalviewproperties/snap_vertical_splitter/) | Gibt an, ob der vertikale Trenner in einen minimierten Zustand einrasten soll, wenn der seitliche Bereich ausreichend klein ist.<br/>            Lesen/Schreiben **bool**. |
| [`vertical_bar_state`](/slides/python-net/de/aspose.slides/inormalviewproperties/vertical_bar_state/) | Gibt den Zustand an, in dem die vertikale Trennleiste angezeigt werden soll. <br/>            Eine vertikale Trennleiste trennt die Folie vom seitlichen Inhaltsbereich. |
| [`horizontal_bar_state`](/slides/python-net/de/aspose.slides/inormalviewproperties/horizontal_bar_state/) | Gibt den Zustand an, in dem die horizontale Trennleiste angezeigt werden soll.<br/>            Eine horizontale Trennleiste trennt die Folie vom Inhaltsbereich unterhalb der Folie. |
| [`prefer_single_view`](/slides/python-net/de/aspose.slides/inormalviewproperties/prefer_single_view/) | Gibt an, ob der Benutzer es vorzieht, eine vollfensterige Ein-Inhaltsbereich-Ansicht anstelle der standardmäßigen Normalansicht mit drei Inhaltsbereichen zu sehen. Wenn aktiviert, kann die Anwendung wählen, einen der Inhaltsbereiche im gesamten Fenster anzuzeigen.<br/>            Lesen/Schreiben **bool**. |
| [`restored_left`](/slides/python-net/de/aspose.slides/inormalviewproperties/restored_left/) | Dieses Element gibt die Größe des seitlichen Inhaltsbereichs der Normalansicht an, wenn der Bereich eine variable wiederhergestellte Größe hat (weder minimiert noch maximiert).<br/>            Nur lesen [`INormalViewRestoredProperties`](/slides/python-net/de/aspose.slides/inormalviewrestoredproperties). |
| [`restored_top`](/slides/python-net/de/aspose.slides/inormalviewproperties/restored_top/) | Dieses Element gibt die Größe des oberen Folienbereichs der Normalansicht an, wenn der Bereich eine variable wiederhergestellte Größe hat (weder minimiert noch maximiert).<br/>            Nur lesen [`INormalViewRestoredProperties`](/slides/python-net/de/aspose.slides/inormalviewrestoredproperties). |
