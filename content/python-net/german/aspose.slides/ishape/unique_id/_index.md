## unique_id Eigenschaft
Gibt einen internen, präsentationsbezogenen Bezeichner zurück, der für die Verwendung durch Add-Ins oder anderen Code vorgesehen ist.
            Da dieser Wert vom Benutzer oder programmgesteuert neu zugewiesen werden kann, darf er nicht behandelt werden
            als persistenter eindeutiger Schlüssel.
            Nur lesbar **int**.
            Siehe auch [`IShape.office_interop_shape_id`](/slides/python-net/de/aspose.slides/ishape/office_interop_shape_id).
