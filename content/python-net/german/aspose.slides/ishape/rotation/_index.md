## Rotations-Eigenschaft
Gibt die Anzahl der Grad zurück, um die das angegebene Shape um die
            Z-Achse gedreht ist, oder legt sie fest. Ein positiver Wert bedeutet eine Drehung im Uhrzeigersinn; ein negativer Wert bedeutet eine Drehung gegen den Uhrzeigersinn.
            Lesen/Schreiben **float**.


### Anmerkungen

Der zurückgegebene Wert ist immer definiert (ist nicht float.NaN). Zugewiesener Wert muss definiert sein (nicht float.NaN). Sie können undefinierte Werte für Eigenschaften von RawFrame-Instanzen festlegen.
