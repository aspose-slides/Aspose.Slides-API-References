## Point Klasse

Stellt ein geordnetes Paar von ganzzahligen x- und y-Koordinaten dar, das einen Punkt in einer zweidimensionalen Ebene definiert. Kompatibel mit .NET `System.Drawing.Point`.

Der Typ Point stellt die folgenden Member bereit:

## Konstruktoren

| Konstruktor | Beschreibung |
| :- | :- |
| [`__init__(self, x=0, y=0)`](/slides/python-net/de/aspose.slides/point/__init__/#int-int) | Erstellt einen Punkt mit den angegebenen Koordinaten. Fließkommawerte werden zu Ganzzahlen abgeschnitten. |

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`x`](/slides/python-net/de/aspose.slides/point/x/) | Liest oder legt die x-Koordinate dieses Punktes fest.<br/>            Lesen/Schreiben **int**. |
| [`y`](/slides/python-net/de/aspose.slides/point/y/) | Liest oder legt die y-Koordinate dieses Punktes fest.<br/>            Lesen/Schreiben **int**. |

### Bemerkungen

Punkte werden anhand ihrer Koordinaten mit `==` verglichen und können als Schlüssel in Dictionaries oder als Elemente in Sets verwendet werden.
