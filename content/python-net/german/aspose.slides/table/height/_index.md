## height Eigenschaft
Liest oder setzt die height der Form, gemessen in Punkten.
            Lesen/Schreiben **float**.


### Bemerkungen

Der zurückgegebene Wert ist immer definiert und nie **float**.
            Der zugewiesene Wert muss ebenfalls definiert sein; weise **float** nur Eigenschaften einer `RawFrame`-Instanz zu.
