## SlideShowSettings Klasse

Stellt die Diashow-Einstellungen für die Präsentation dar.

Der Typ SlideShowSettings gibt die folgenden Mitglieder frei:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`slide_show_type`](/slides/python-net/de/aspose.slides/slideshowsettings/slide_show_type/) | Liest oder setzt den Diashow-Typ. Repräsentiert durch die folgenden [`SlideShowSettings.slide_show_type`](/slides/python-net/de/aspose.slides/slideshowsettings/slide_show_type) Vorfahren: [`BrowsedAtKiosk`](/slides/python-net/de/aspose.slides/browsedatkiosk), [`PresentedBySpeaker`](/slides/python-net/de/aspose.slides/presentedbyspeaker) und [`BrowsedByIndividual`](/slides/python-net/de/aspose.slides/browsedbyindividual) |
| [`loop`](/slides/python-net/de/aspose.slides/slideshowsettings/loop/) | Diashow-Schleife |
| [`show_narration`](/slides/python-net/de/aspose.slides/slideshowsettings/show_narration/) | Narration in Diashow anzeigen |
| [`show_animation`](/slides/python-net/de/aspose.slides/slideshowsettings/show_animation/) | Animation in Diashow anzeigen |
| [`pen_color`](/slides/python-net/de/aspose.slides/slideshowsettings/pen_color/) | Stiftfarbe für Diashow |
| [`slides`](/slides/python-net/de/aspose.slides/slideshowsettings/slides/) | Folienbereich |
| [`use_timings`](/de/slides/python-net/aspose.slides/slideshowsettings/use_timings/) | Zeitsteuerungen in Diashow verwenden |
| [`show_media_controls`](/slides/python-net/de/aspose.slides/slideshowsettings/show_media_controls/) | Mediensteuerelemente anzeigen |
