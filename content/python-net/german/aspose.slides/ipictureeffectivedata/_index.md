## IPictureEffectiveData Klasse

Unveränderliches Objekt, das effektive Bildeigenschaften enthält.

Der IPictureEffectiveData-Typ stellt die folgenden Member bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`image`](/slides/python-net/de/aspose.slides/ipictureeffectivedata/image/) | Gibt das eingebettete Bild zurück.<br/>            Nur lesbar [`IPPImage`](/slides/python-net/de/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/de/aspose.slides/ipictureeffectivedata/link_path_long/) | Gibt die URL des verknüpften Bildes zurück.<br/>            Nur lesbar **str**. |
| [`image_transform`](/slides/python-net/de/aspose.slides/ipictureeffectivedata/image_transform/) | Gibt die Sammlung der Bildtransformations-Effekte zurück.<br/>            Nur lesbar [`IImageTransformOCollectionEffectiveData`](/slides/python-net/de/aspose.slides.effects/iimagetransformocollectioneffectivedata). |


### Hinweise

Diese Schnittstelle wird als Teil von [`IPictureFillFormatEffectiveData`](/slides/python-net/de/aspose.slides/ipicturefillformateffectivedata) und [`IBulletFormatEffectiveData`](/slides/python-net/de/aspose.slides/ibulletformateffectivedata) verwendet.
