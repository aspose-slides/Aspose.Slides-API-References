## IDigitalSignature Klasse

Digitale Signatur in einer signierten Datei.

Der IDigitalSignature-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`certificate`](/slides/python-net/de/aspose.slides/idigitalsignature/certificate/) | Zertifikatobjekt, das zum Signieren des Dokuments verwendet wurde.<br/>            Nur lesbar **System.Security.Cryptography.X509Certificates.X509Certificate2**. |
| [`is_valid`](/slides/python-net/de/aspose.slides/idigitalsignature/is_valid/) | Wenn diese digitale Signatur gültig ist und das Dokument nicht manipuliert wurde, ist dieser Wert wahr.<br/>            Nur lesbar **bool**. |
| [`sign_time`](/slides/python-net/de/aspose.slides/idigitalsignature/sign_time/) | Der Zeitpunkt, zu dem das Dokument signiert wurde.<br/>            Nur lesbar **System.DateTime**. |
| [`comments`](/slides/python-net/de/aspose.slides/idigitalsignature/comments/) | Der Zweck der Signatur.<br/>            Lesen/Schreiben **str**. |
