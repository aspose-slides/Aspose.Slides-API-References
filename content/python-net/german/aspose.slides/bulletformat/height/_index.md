## height Eigenschaft
Returns or sets the bullet height of a paragraph with no inheritance.
            Value float.NaN determines that bullet inherits height from the first portion in the paragraph.
            Read/write **float**.


### Remarks

Ein negativer Höhenwert bedeutet, dass die Höhe in Punkten angegeben ist, und ein positiver Wert bedeutet, dass die Höhe ein Prozentsatz des umgebenden Textes ist.
