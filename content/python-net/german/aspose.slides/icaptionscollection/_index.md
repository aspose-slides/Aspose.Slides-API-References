## ICaptionsCollection Klasse

Stellt eine Sammlung der geschlossenen Untertitel dar.

Der ICaptionsCollection-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Property | Beschreibung |
| :- | :- |
| [`count`](/slides/python-net/de/aspose.slides/icaptionscollection/count/) | Gibt die Anzahl der Elemente in der Sammlung zurück.<br/>            Nur lesend **int**. |

Gibt die geschlossenen Untertitel am angegebenen Index zurück.
            Nur lesend [`ICaptions`](/slides/python-net/de/aspose.slides/icaptions).
