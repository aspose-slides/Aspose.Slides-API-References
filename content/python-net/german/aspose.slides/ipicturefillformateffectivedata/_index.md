## IPictureFillFormatEffectiveData Klasse

Unveränderliches Objekt, das die Eigenschaften der Bildfüllung enthält.

Der IPictureFillFormatEffectiveData-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`dpi`](/slides/python-net/de/aspose.slides/ipicturefillformateffectivedata/dpi/) | Gibt die DPI zurück, die zum Füllen eines Bildes verwendet wird.<br/>            Nur lesbar **int**. |
| [`picture_fill_mode`](/slides/python-net/de/aspose.slides/ipicturefillformateffectivedata/picture_fill_mode/) | Gibt den Bildfüllmodus zurück.<br/>            Nur lesbar [`PictureFillMode`](/slides/python-net/de/aspose.slides/picturefillmode). |
| [`picture`](/slides/python-net/de/aspose.slides/ipicturefillformateffectivedata/picture/) | Gibt das Bild zurück.<br/>            Nur lesbar [`IPictureEffectiveData`](/slides/python-net/de/aspose.slides/ipictureeffectivedata). |
| [`crop_left`](/slides/python-net/de/aspose.slides/ipicturefillformateffectivedata/crop_left/) | Gibt den Prozentsatz der tatsächlichen Bildbreite zurück, der abgeschnitten wird<br/>            links vom Bild. <br/>            Nur lesbar **float**. |
| [`crop_top`](/slides/python-net/de/aspose.slides/ipicturefillformateffectivedata/crop_top/) | Gibt den Prozentsatz der tatsächlichen Bildhöhe zurück, der abgeschnitten wird<br/>            oben vom Bild. <br/>            Nur lesbar **float**. |
| [`crop_right`](/slides/python-net/de/aspose.slides/ipicturefillformateffectivedata/crop_right/) | Gibt den Prozentsatz der tatsächlichen Bildbreite zurück, der abgeschnitten wird<br/>            rechts vom Bild. <br/>            Nur lesbar **float**. |
| [`crop_bottom`](/slides/python-net/de/aspose.slides/ipicturefillformateffectivedata/crop_bottom/) | Gibt den Prozentsatz der tatsächlichen Bildhöhe zurück, der abgeschnitten wird<br/>            unten vom Bild. <br/>            Nur lesbar **float**. |


### Anmerkungen

Diese Schnittstelle wird als Teil von [`IFillFormatEffectiveData`](/slides/python-net/de/aspose.slides/ifillformateffectivedata) verwendet.
