## Position Eigenschaft
Gibt die Position des Zeichenleitfadens in Punkten vom oberen linken Eck der Folie zurück oder legt sie fest.
            Lesen/Schreiben **float**.


### Bemerkungen

Der typische Wertebereich reicht von Null bis zur Folienhöhe für einen horizontalen Führer und von Null bis zur Folienbreite für einen vertikalen Führer.
