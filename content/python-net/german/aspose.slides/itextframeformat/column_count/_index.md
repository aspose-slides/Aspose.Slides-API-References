## column_count Eigenschaft
Gibt die Anzahl der Spalten im Textbereich zurück oder legt sie fest.
            Dieser Wert muss eine positive Zahl sein. Andernfalls wird der Wert auf null gesetzt. 
            Der Wert 0 bedeutet einen undefinierten Wert.
            Lesen/Schreiben **int**.
