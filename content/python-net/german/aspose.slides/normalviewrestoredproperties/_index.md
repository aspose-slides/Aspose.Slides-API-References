## NormalViewRestoredProperties Klasse

Gibt die Größe des Folienbereichs an ((Breite, wenn ein Kind von restoredTop, Höhe, wenn ein Kind von restoredLeft) der Normalansicht, wenn der Bereich eine variable wiederhergestellte Größe hat (weder minimiert noch maximiert)).

Der Typ NormalViewRestoredProperties stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`dimension_size`](/slides/python-net/de/aspose.slides/normalviewrestoredproperties/dimension_size/) | Gibt die Größe des Folienbereichs an (Breite, wenn ein Kind von RestoredTop, Höhe, wenn ein<br/>            Kind von RestoredLeft).<br/>            Lesen/Schreiben **float**. |
| [`auto_adjust`](/slides/python-net/de/aspose.slides/normalviewrestoredproperties/auto_adjust/) | Gibt an, ob die Größe des Seiteninhaltsbereichs die neue Größe<br/>            beim Ändern der Größe des Fensters, das die Ansicht innerhalb der Anwendung enthält,<br/>            ausgleichen soll.<br/>            Lesen/Schreiben **bool**. |
