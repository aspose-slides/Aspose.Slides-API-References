## split_text_by_columns(self) {#}
Teilt den Textinhalt des [`ITextFrame`](/slides/python-net/de/aspose.slides/itextframe) in ein Array von Zeichenketten,  
            wobei jedes Element einer separaten Textspalte innerhalb des Rahmens entspricht.

### Rückgabe

Ein Array von Zeichenketten, wobei jede Zeichenkette den Textinhalt einer bestimmten Spalte  
            im [`ITextFrame`](/slides/python-net/de/aspose.slides/itextframe) darstellt.



```python
def split_text_by_columns(self):
    ...
```


### Bemerkungen

Wenn der Textrahmen nicht mehrere Spalten enthält, wird das zurückgegebene Array ein einzelnes Element  
            enthalten, das den gesamten Text umfasst.  
            Leere Spalten werden im Array als leere Zeichenketten dargestellt.
