## remove(self, item) {#iparagraph}
Entfernt das erste Vorkommen eines bestimmten Objekts aus der **System.Collections.Generic.ICollection`1**.

### Rückgabewert
true, wenn `item` erfolgreich aus der **System.Collections.Generic.ICollection`1** entfernt wurde; andernfalls false. Diese Methode gibt ebenfalls false zurück, wenn `item` im ursprünglichen **System.Collections.Generic.ICollection`1** nicht gefunden wird.



```python
def remove(self, item):
    ...
```


| Parameter | Typ | Beschreibung |
| :- | :- | :- |
| item | [`IParagraph`](/slides/python-net/de/aspose.slides/iparagraph) | Das Objekt, das aus der **System.Collections.Generic.ICollection`1** entfernt werden soll. |

### Ausnahmen

| Ausnahme | Beschreibung |
| :- | :- |
| **RuntimeError(Proxy error(NotSupportedException))** | Die **System.Collections.Generic.ICollection`1** ist schreibgeschützt. |
