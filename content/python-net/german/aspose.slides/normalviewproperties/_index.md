## NormalViewProperties Klasse

Stellt die Eigenschaften der Normalansicht dar. Die Normalansicht besteht aus
            drei Inhaltsbereichen: der Folie selbst, einem seitlichen Inhaltsbereich und einem unteren Inhaltsbereich.

Der Typ NormalViewProperties enthält die folgenden Mitglieder:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`show_outline_icons`](/slides/python-net/de/aspose.slides/normalviewproperties/show_outline_icons/) | Gibt an, ob die Anwendung Symbole anzeigen soll, wenn in einem der Inhaltsbereiche der Normalansichts-Modus Gliederungsinhalte angezeigt werden.<br/>            Lesen/Schreiben **bool**. |
| [`snap_vertical_splitter`](/slides/python-net/de/aspose.slides/normalviewproperties/snap_vertical_splitter/) | Gibt an, ob die vertikale Trennlinie in den minimierten Zustand wechseln soll, wenn der seitliche<br/>            Bereich ausreichend klein ist.<br/>            Lesen/Schreiben **bool**. |
| [`vertical_bar_state`](/slides/python-net/de/aspose.slides/normalviewproperties/vertical_bar_state/) | Gibt an, in welchem Zustand die vertikale Trennleiste angezeigt werden soll. <br/>            Eine vertikale Trennleiste trennt die Folie vom seitlichen Inhaltsbereich. |
| [`horizontal_bar_state`](/slides/python-net/de/aspose.slides/normalviewproperties/horizontal_bar_state/) | Gibt an, in welchem Zustand die horizontale Trennleiste angezeigt werden soll.<br/>            Eine horizontale Trennleiste trennt die Folie vom Inhaltsbereich unterhalb der Folie. |
| [`prefer_single_view`](/slides/python-net/de/aspose.slides/normalviewproperties/prefer_single_view/) | Gibt an, ob der Benutzer lieber einen einzelnen Inhaltsbereich im Vollfenster sehen möchte statt der<br/>            Standard-Normalansicht mit drei Inhaltsbereichen. Wenn aktiviert, kann die Anwendung<br/>            wählen, einen der Inhaltsbereiche im gesamten Fenster anzuzeigen.<br/>            Lesen/Schreiben **bool**. |
| [`restored_left`](/slides/python-net/de/aspose.slides/normalviewproperties/restored_left/) | Dieses Element gibt die Größe des seitlichen Inhaltsbereichs der Normalansicht an, wenn der Bereich eine variable<br/>            wiederhergestellte Größe (weder minimiert noch maximiert) hat.<br/>            Nur Lesen [`INormalViewRestoredProperties`](/slides/python-net/de/aspose.slides/inormalviewrestoredproperties). |
| [`restored_top`](/slides/python-net/de/aspose.slides/normalviewproperties/restored_top/) | Dieses Element gibt die Größe des oberen Folienbereichs der Normalansicht an, wenn der Bereich eine variable<br/>            wiederhergestellte Größe (weder minimiert noch maximiert) hat.<br/>            Nur Lesen [`INormalViewRestoredProperties`](/slides/python-net/de/aspose.slides/inormalviewrestoredproperties). |
