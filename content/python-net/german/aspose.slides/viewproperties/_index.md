## ViewProperties Klasse

Präsentationsweite Ansichtseigenschaften.

Der ViewProperties-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`last_view`](/slides/python-net/de/aspose.slides/viewproperties/last_view/) | Gibt den Ansichtsmodus an, der verwendet wurde, als das Präsentationsdokument zuletzt gespeichert wurde.<br/>            Lesen/Schreiben [`ViewType`](/slides/python-net/de/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/de/aspose.slides/viewproperties/show_comments/) | Gibt an, ob die Folienkommentare angezeigt werden sollen.<br/>            Lesen/Schreiben [`NullableBool`](/slides/python-net/de/aspose.slides/nullablebool). |
| [`normal_view_properties`](/slides/python-net/de/aspose.slides/viewproperties/normal_view_properties/) | Stellt Eigenschaften der Normalansicht dar. Die Normalansicht besteht aus<br/>            drei Inhaltsbereichen: der Folie selbst, einem seitlichen Inhaltsbereich und einem unteren Inhaltsbereich.<br/>            Nur lesen [`INormalViewProperties`](/slides/python-net/de/aspose.slides/inormalviewproperties). |
| [`slide_view_properties`](/slides/python-net/de/aspose.slides/viewproperties/slide_view_properties/) | Gibt gemeinsame Ansichtseigenschaften an, die dem Folienansichtsmodus zugeordnet sind.<br/>            Nur lesen [`ICommonSlideViewProperties`](/slides/python-net/de/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/de/aspose.slides/viewproperties/notes_view_properties/) | Gibt gemeinsame Ansichtseigenschaften an, die dem Notizansichtsmodus zugeordnet sind.<br/>            Nur lesen [`ICommonSlideViewProperties`](/slides/python-net/de/aspose.slides/icommonslideviewproperties). |
| [`grid_spacing`](/slides/python-net/de/aspose.slides/viewproperties/grid_spacing/) | Gibt den Rasterabstand zurück oder legt ihn fest, der für das dem Präsentationsdokument zugrunde liegende Raster in Punkten verwendet werden soll. <br/>            Lesen/Schreiben **float**. |
