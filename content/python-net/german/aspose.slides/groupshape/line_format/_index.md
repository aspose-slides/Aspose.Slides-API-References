## line_format Eigenschaft
Gibt das LineFormat-Objekt zurück, das die Linienformatierungseigenschaften für eine Form enthält.
            Hinweis: Gibt None zurück für GroupShape-Objekte, weil sie keine Linieneigenschaften haben.
            Nur-Lesen [`ILineFormat`](/slides/python-net/de/aspose.slides/ilineformat).
