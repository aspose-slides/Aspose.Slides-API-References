## get_base_placeholder(self) {#}
Gibt eine grundlegende Platzhalterform zurück (Form aus dem Layout und/oder der Master-Folie, von der die aktuelle Form ererbt wurde).
Ein None wird zurückgegeben, wenn die aktuelle Form nicht ererbt wird.
