## IThreeDFormatEffectiveData Klasse

Unveränderliches Objekt, das effektive 3D-Formatierungseigenschaften darstellt.

Der Typ IThreeDFormatEffectiveData stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`contour_width`](/slides/python-net/de/aspose.slides/ithreedformateffectivedata/contour_width/) | Gibt die Breite einer 3D-Kontur zurück.<br/>            Nur lesbar **float**. |
| [`extrusion_height`](/slides/python-net/de/aspose.slides/ithreedformateffectivedata/extrusion_height/) | Gibt die Höhe eines Extrusions-Effekts zurück.<br/>            Nur lesbar **float**. |
| [`depth`](/slides/python-net/de/aspose.slides/ithreedformateffectivedata/depth/) | Gibt die Tiefe einer 3D-Form zurück.<br/>            Nur lesbar **float**. |
| [`bevel_top`](/slides/python-net/de/aspose.slides/ithreedformateffectivedata/bevel_top/) | Gibt den Typ einer oberen 3D-Fase zurück.<br/>            Nur lesbar [`IShapeBevelEffectiveData`](/slides/python-net/de/aspose.slides/ishapebeveleffectivedata). |
| [`bevel_bottom`](/slides/python-net/de/aspose.slides/ithreedformateffectivedata/bevel_bottom/) | Gibt den Typ einer unteren 3D-Fase zurück.<br/>            Nur lesbar [`IShapeBevelEffectiveData`](/slides/python-net/de/aspose.slides/ishapebeveleffectivedata). |
| [`contour_color`](/slides/python-net/de/aspose.slides/ithreedformateffectivedata/contour_color/) | Gibt die Farbe einer Kontur zurück.<br/>            Nur lesbar [`Color`](/slides/python-net/de/aspose.slides/color). |

### Bemerkungen

Diese Schnittstelle wird zusammen mit der Schnittstelle [`IThreeDFormat`](/slides/python-net/de/aspose.slides/ithreedformat) verwendet, um effektive Formatierungswerte mit angewandter Vererbung zurückzugeben.
