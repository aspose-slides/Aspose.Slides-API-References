## compare_to(self, obj) {#any}
Vergleicht die aktuelle Instanz mit einem anderen Objekt desselben Typs.

### Rückgabewert

Ein 32-Bit-Integer, der die relative Reihenfolge der Vergleichsobjekte angibt.
Der Rückgabewert hat folgende Bedeutungen:
*  < 0 - Dieses Objekt ist kleiner als obj. = 0 - Dieses Objekt ist gleich obj. > 0 - Dieses Objekt ist größer als obj.
*  < 0 - Dieses Objekt ist kleiner als obj. = 0 - Dieses Objekt ist gleich obj. > 0 - Dieses Objekt ist größer als obj.
*  < 0 - Dieses Objekt ist kleiner als obj. = 0 - Dieses Objekt ist gleich obj. > 0 - Dieses Objekt ist größer als obj.
