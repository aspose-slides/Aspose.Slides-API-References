## Size Klasse

Speichert ein geordnetes Paar von Ganzzahlen, das eine Breite und eine Höhe angibt. Kompatibel mit .NET `System.Drawing.Size`.

Der Typ Size stellt die folgenden Mitglieder bereit:

## Konstruktoren

| Konstruktor | Beschreibung |
| :- | :- |
| [`__init__(self, width=0, height=0)`](/slides/python-net/de/aspose.slides/size/__init__/#int-int) | Erstellt eine Size mit der angegebenen Breite und Höhe. Float-Werte werden zu Ganzzahlen gekürzt. |

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`width`](/slides/python-net/de/aspose.slides/size/width/) | Gibt die horizontale Komponente dieser Size zurück.<br/>            Nur lesbar **int**. |
| [`height`](/slides/python-net/de/aspose.slides/size/height/) | Gibt die vertikale Komponente dieser Size zurück.<br/>            Nur lesbar **int**. |


### Hinweise

Sizes werden anhand ihrer Komponenten mit `==` verglichen und können als Wörterbuchschlüssel oder Mengenelemente verwendet werden.
