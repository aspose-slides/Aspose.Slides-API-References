## Column Klasse

Stellt eine Spalte in einer Tabelle dar.

**Vererbung:**[`Column`](/slides/python-net/de/aspose.slides/column) → [`CellCollection`](/slides/python-net/de/aspose.slides/cellcollection)

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`slide`](/slides/python-net/de/aspose.slides/column/slide/) | Gibt die übergeordnete Folie einer CellCollection zurück.<br/>            Nur lesend [`IBaseSlide`](/slides/python-net/de/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/de/aspose.slides/column/presentation/) | Gibt die übergeordnete Präsentation einer CellCollection zurück.<br/>            Nur lesend [`IPresentation`](/slides/python-net/de/aspose.slides/ipresentation). |
| [`width`](/slides/python-net/de/aspose.slides/column/width/) | Gibt die Breite einer Spalte zurück oder setzt sie.<br/>            Lese/Schreib **float**. |
| [`column_format`](/slides/python-net/de/aspose.slides/column/column_format/) | Gibt das ColumnFormat-Objekt zurück, das Formatierungseigenschaften für diese Spalte enthält.<br/>            Nur lesend [`IColumnFormat`](/slides/python-net/de/aspose.slides/icolumnformat). |
