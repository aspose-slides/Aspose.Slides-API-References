## PlaceholderType Aufzählung

Stellt den Typ eines Platzhalters dar.

Der Typ PlaceholderType stellt die folgenden Mitglieder bereit:

| BODY | Text. |

| SUBTITLE | Untertitel. |
| DATE_AND_TIME | Datum und Uhrzeit. |
| SLIDE_NUMBER | Foliennummer. |
| FOOTER | Fußzeile. |
| HEADER | Kopfzeile. |
| OBJECT | Objekt. |
| CHART | Diagramm. |
| TABLE | Tabelle. |
