## get_text_rect(self) {#}
Ruft das Textrechteck ab, das durch die Geometrie der übergeordneten Form definiert ist.

### Rückgabewert

Ein [`RectangleF`](/slides/python-net/de/aspose.slides/rectanglef), das den Textbereich definiert.



```python
def get_text_rect(self):
    ...
```


### Bemerkungen

Die Rechteckkoordinaten sind relativ zur oberen linken Ecke der übergeordneten Form.

### Ausnahmen

| Ausnahme | Beschreibung |
| :- | :- |
| **RuntimeError(Proxy error(InvalidOperationException))** | Der Textrahmen ist keiner geometrischen Form zugeordnet. |
