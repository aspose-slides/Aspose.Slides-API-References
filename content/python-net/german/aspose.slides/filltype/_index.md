## FillType Enumeration

Gibt den inneren Fülltyp verschiedener visueller Objekte an.

Der Typ FillType stellt die folgenden Mitglieder bereit:

## Felder

| Field | Description |
| :- | :- |
| NOT_DEFINED | Der Fülltyp ist nicht definiert. |
| NO_FILL | Keine Füllung angewendet. |
| SOLID | Mit einer Vollfarbe gefüllt. |
| GRADIENT | Die Füllung ist ein Farbverlauf. |
| PATTERN | Ein wiederholendes Muster wird verwendet, um das Objekt zu füllen. |
| PICTURE | Ein einzelnes Bild wird verwendet, um das Objekt zu füllen. |
| GROUP | Das visuelle Objekt erbt die Fülleigenschaften von der Gruppe. |
