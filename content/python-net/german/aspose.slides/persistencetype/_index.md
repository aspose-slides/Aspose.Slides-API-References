## PersistenceType-Aufzählung

Gibt die Methode an, die zum Speichern von Eigenschaften des ActiveX-Steuerelements verwendet wird.

Der Typ PersistenceType stellt die folgenden Member bereit:

## Felder

| Field | Description |
| :- | :- |
| NOT_DEFINED | Persistenz-ID nicht angegeben. |
| PERSIST_PROPERTY_BAG | Gibt an, dass das ActiveX-Steuerelement mithilfe einer property-bag-basierten Persistenz gespeichert wird.<br/>             Eine property-bag-basierte Persistenz speichert ein ActiveX-Steuerelement mittels einer Sammlung von Namens- und Wertpaaren, die die vom ActiveX-Steuerelement gespeicherten Daten angeben. |
| PERSIST_STREAM | Gibt an, dass das ActiveX-Steuerelement mithilfe einer stream-basierten Persistenz gespeichert wird,<br/>             die keine Initialisierung des ActiveX-Steuerelements in einen Standardzustand unterstützt. |
| PERSIST_STREAM_INIT | Gibt an, dass das ActiveX-Steuerelement mithilfe einer stream-basierten Persistenz gespeichert wird,<br/>             die die Initialisierung des ActiveX-Steuerelements in einen Standardzustand unterstützt. |
| PERSIST_STORAGE | Gibt an, dass das ActiveX-Steuerelement mithilfe einer speicher-basierten Persistenz gespeichert wird. |
