## PathFillModeType Enumeration

Gibt an, wie ein Pfad gefüllt werden soll

Der Typ PathFillModeType stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| NONE | Keine Pfadfüllung<br/>            Dies gibt an, dass der entsprechende Pfad keine Füllung haben soll. |
| NORMAL | Normale Pfadfüllung<br/>            Dies gibt an, dass der entsprechende Pfad eine normal schattierte Farbe auf seine Füllung angewendet bekommt. |
| LIGHTEN | Aufhellende Pfadfüllung<br/>            Dies gibt an, dass der entsprechende Pfad  eine leicht schattierte Farbe auf seine Füllung angewendet bekommt. |
| LIGHTEN_LESS | Weniger aufhellende Pfadfüllung<br/>            Dies gibt an, dass der entsprechende Pfad eine leicht hellere schattierte Farbe auf seine Füllung angewendet bekommt. |
| DARKEN | Abgedunkelte Pfadfüllung<br/>            Dies gibt an, dass der entsprechende Pfad eine dunklere schattierte Farbe auf seine Füllung angewendet bekommt. |
| DARKEN_LESS | Weniger abgedunkelte Pfadfüllung<br/>            Dies gibt an, dass der entsprechende Pfad eine etwas dunklere schattierte Farbe auf seine Füllung angewendet bekommt. |
