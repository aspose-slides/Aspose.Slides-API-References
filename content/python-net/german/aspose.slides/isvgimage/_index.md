## ISvgImage Klasse

Stellt ein SVG-Bild dar.

Der Typ ISvgImage stellt die folgenden Member bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`svg_content`](/slides/python-net/de/aspose.slides/isvgimage/svg_content/) | Gibt den SVG-Inhalt zurück.<br/>            Nur lesbar **str**. |
| [`svg_data`](/slides/python-net/de/aspose.slides/isvgimage/svg_data/) | Gibt SVG-Daten zurück.<br/>            Nur lesbar **int**[]. |
| [`external_resource_resolver`](/slides/python-net/de/aspose.slides/isvgimage/external_resource_resolver/) | Gibt das Callback-Interface zurück, das zum Auflösen externer Ressourcen während des SVG-Dokumentenimports verwendet wird.<br/>            Nur lesbar **IExternalResourceResolver**. |
| [`base_uri`](/slides/python-net/de/aspose.slides/isvgimage/base_uri/) | Gibt die Basis-URI des angegebenen SVG zurück. Wird zum Auflösen relativer Links verwendet.<br/>            Nur lesbar **str**. |
