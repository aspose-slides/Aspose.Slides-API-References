## HyperlinkQueries Klasse

Bietet einfachen Zugriff auf enthaltene Hyperlinks.

Der HyperlinkQueries Typ stellt die folgenden Mitglieder bereit:

## Methoden

| Methode | Beschreibung |
| :- | :- |
| [`get_hyperlink_clicks(self)`](/slides/python-net/de/aspose.slides/hyperlinkqueries/get_hyperlink_clicks/#) | Ruft alle IHyperlinkContainer Unterobjekte ab, die nicht None HyperlinkClick enthalten.<br/>            Mit dem angegebenen IHyperlinkContainer-Objekt können Sie dessen Hyperlink verwalten (lesen, aktualisieren oder entfernen). Siehe IHyperlinkContainer Schnittstelle. |
| [`get_hyperlink_mouse_overs(self)`](/slides/python-net/de/aspose.slides/hyperlinkqueries/get_hyperlink_mouse_overs/#) | Ruft alle IHyperlinkContainer Unterobjekte ab, die nicht None HyperlinkMouseOver enthalten.<br/>            Mit dem angegebenen IHyperlinkContainer-Objekt können Sie dessen Hyperlink verwalten (lesen, aktualisieren oder entfernen). Siehe IHyperlinkContainer Schnittstelle. |
| [`get_any_hyperlinks(self)`](/slides/python-net/de/aspose.slides/hyperlinkqueries/get_any_hyperlinks/#) | Ruft alle IHyperlinkContainer Unterobjekte ab, die nicht None HyperlinkMouseOver enthalten.<br/>            Mit dem angegebenen IHyperlinkContainer-Objekt können Sie dessen Hyperlink verwalten (lesen, aktualisieren oder entfernen). Siehe IHyperlinkContainer Schnittstelle. |
| [`remove_all_hyperlinks(self)`](/slides/python-net/de/aspose.slides/hyperlinkqueries/remove_all_hyperlinks/#) | Entfernt alle enthaltenen HyperlinkClick- und HyperlinkMouseOver-Hyperlinks (in allen IHyperlinkContainer Unterobjekten). |
