## ControlPropertiesCollection Klasse

Eine Sammlung von AcitveX-Eigenschaften.

Der Typ ControlPropertiesCollection stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`names_of_properties`](/slides/python-net/de/aspose.slides/controlpropertiescollection/names_of_properties/) | Gibt die Sammlung von Eigenschaftsnamen zurück.<br/>            schreibgeschützt **list**. |
| [`count`](/slides/python-net/de/aspose.slides/controlpropertiescollection/count/) | Gibt die Anzahl der Eigenschaften in der Sammlung zurück.<br/>            schreibgeschützt **int**. |

## Methoden

| Methode | Beschreibung |
| :- | :- |
| [`add(self, name, value)`](/slides/python-net/de/aspose.slides/controlpropertiescollection/add/#str-str) | Fügt der Sammlung eine Eigenschaft hinzu. |
| [`remove(self, name)`](/slides/python-net/de/aspose.slides/controlpropertiescollection/remove/#str) | Entfernt eine Eigenschaft mit dem angegebenen Namen. |
| [`clear(self)`](/slides/python-net/de/aspose.slides/controlpropertiescollection/clear/#) | Entfernt alle Eigenschaften. |
