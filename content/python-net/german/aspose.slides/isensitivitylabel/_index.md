## ISensitivityLabel Klasse

Stellt das Sensitivitätslabel von Microsoft Purview Information Protection dar.

Der Typ ISensitivityLabel stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Property | Description |
| :- | :- |
| [`id`](/slides/python-net/de/aspose.slides/isensitivitylabel/id/) | Gibt die ID des Sensitivitätslabels zurück oder setzt sie.<br/>            Lese/Schreib **str**. |
| [`site_id`](/slides/python-net/de/aspose.slides/isensitivitylabel/site_id/) | Gibt den Azure Active Directory (Azure AD) Site-Identifikator zurück oder setzt ihn<br/>            entsprechend der Richtlinie für Sensitivitätslabels, die das Sensitivitätslabel beschreibt.<br/>            Lese/Schreib **System.Guid**. |
| [`is_enabled`](/slides/python-net/de/aspose.slides/isensitivitylabel/is_enabled/) | Gibt an, ob das Sensitivitätslabel aktiviert ist. |
| [`is_removed`](/slides/python-net/de/aspose.slides/isensitivitylabel/is_removed/) | Gibt an, ob das Sensitivitätslabel entfernt wurde. |
| [`assignment_method_type`](/slides/python-net/de/aspose.slides/isensitivitylabel/assignment_method_type/) | Gibt die Zuweisungsmethode für das Sensitivitätslabel zurück oder setzt sie.<br/>            Lese/Schreib [`SensitivityLabelAssignmentType`](/slides/python-net/de/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/de/aspose.slides/isensitivitylabel/content_mark_types/) | Gibt die Liste der Arten von Inhaltskennzeichnungen zurück, die auf eine Datei angewendet werden sollen. |
