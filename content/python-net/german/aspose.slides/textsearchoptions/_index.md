## TextSearchOptions Klasse

Stellt Optionen dar, die verwendet werden können, um Text in einer Presentation, einem Slide oder einem TextFrame zu suchen.

Der Typ TextSearchOptions stellt die folgenden Mitglieder bereit:

## Konstruktoren

| Konstruktor | Beschreibung |
| :- | :- |
| [`__init__(self)`](/slides/python-net/de/aspose.slides/textsearchoptions/__init__/#) | Erstellt neue Standard-Textsuchoptionen. |

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`case_sensitive`](/slides/python-net/de/aspose.slides/textsearchoptions/case_sensitive/) | Set true, um eine Groß-/Kleinschreibung-sensible Suche zu verwenden, false - sonst.<br/>            Lesen/Schreiben **bool**. |
| [`whole_words_only`](/slides/python-net/de/aspose.slides/textsearchoptions/whole_words_only/) | Set true, um nur ganze Wörter zu finden, false - sonst.<br/>            Lesen/Schreiben **bool**. |
| [`include_notes`](/slides/python-net/de/aspose.slides/textsearchoptions/include_notes/) | Set `true`, um Text, der in Foliennotizen ([`NotesSlide`](/slides/python-net/de/aspose.slides/notesslide)) enthalten ist, einzuschließen <br/>            bei Textsuche-, Ersetzungs- oder Hervorhebungsoperationen.<br/>            Der Standardwert ist `false`. |
