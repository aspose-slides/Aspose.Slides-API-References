## LineSketchType enumeration

Gibt an, welcher Skizzentyp oder Effekt einer Form zugewiesen wurde.

Der Typ LineSketchType enthält die folgenden Member:

## Fields

| Feld | Beschreibung |
| :- | :- |
| NOT_DEFINED | Gibt an, dass ein Sketch-Effekt einer Form undefiniert ist. |
| NONE | Gibt an, dass eine Form keinen Sketch-Effekt hat. Dies entspricht einem leeren Wert dieser Eigenschaft. |
| CURVED | Gibt an, dass eine Form den Curved-Effekt hat, der jede Kante der Form in eine große, sanfte Kurve umwandelt. |
| FREEHAND | Gibt an, dass eine Form den Freehand-Effekt hat, der am ehesten einer unvollkommen gezeichneten Linie ähnelt. |
| SCRIBBLE | Gibt an, dass eine Form den Scribble-Effekt hat, der eine übertriebene Schwingung aufweist, als wäre er absichtlich unordentlich gezeichnet. |
