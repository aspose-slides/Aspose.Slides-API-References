## line_format Eigenschaft
Gibt das LineFormat-Objekt zurück, das die Linienformatierungseigenschaften für ein shape enthält.
            Hinweis: kann None zurückgeben für bestimmte Arten von shapes, die keine Linieneigenschaften haben.
