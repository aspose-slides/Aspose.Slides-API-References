## ITabEffectiveData Klasse

Unveränderliches Objekt, das die Tabulator-Stop-Eigenschaften des effektiven Textes enthält.

Der Typ ITabEffectiveData stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`position`](/slides/python-net/de/aspose.slides/itabeffectivedata/position/) | Gibt die Position eines Tabs zurück.<br/>            Das Zuweisen dieser Eigenschaft kann den Index des Tabs in der Sammlung ändern und den Enumerator ungültig machen.<br/>            Nur lesbar **float**. |
| [`alignment`](/slides/python-net/de/aspose.slides/itabeffectivedata/alignment/) | Gibt den Ausrichtungsstil eines Tabs zurück.<br/>            Nur lesbar [`TabAlignment`](/slides/python-net/de/aspose.slides/tabalignment). |


### Hinweise

Diese Schnittstelle wird als Teil von [`IParagraphFormatEffectiveData`](/slides/python-net/de/aspose.slides/iparagraphformateffectivedata) verwendet.
