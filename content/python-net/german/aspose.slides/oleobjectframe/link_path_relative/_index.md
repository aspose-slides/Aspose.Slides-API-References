## link_path_relative Eigenschaft
Gibt den relativen Pfad zu einer verknüpften Datei zurück, falls vorhanden, andernfalls wird ein leerer String zurückgegeben.
             Nur lesbar **str**.

### Anmerkungen

In den PPT-Präsentationen können einige Ole-Objektverknüpfungen eine relative Darstellung haben.
