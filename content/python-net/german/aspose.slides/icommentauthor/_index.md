## ICommentAuthor Klasse

Stellt einen Autor von Kommentaren dar.

Der Typ ICommentAuthor stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`name`](/slides/python-net/de/aspose.slides/icommentauthor/name/) | Liefert oder setzt den Namen des Autors.<br/>            Lese/Schreib **str**. |
| [`initials`](/slides/python-net/de/aspose.slides/icommentauthor/initials/) | Liefert oder setzt die Initialen des Autors.<br/>            Lese/Schreib **str**. |
| [`comments`](/slides/python-net/de/aspose.slides/icommentauthor/comments/) | Liefert die Sammlung der von diesem Autor erstellten Kommentare.<br/>            Nur lesbar [`ICommentCollection`](/slides/python-net/de/aspose.slides/icommentcollection). |
