## ICaptions class

Stellt die WebVTT-Untertitel dar.

Der ICaptions-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`caption_id`](/slides/python-net/de/aspose.slides/icaptions/caption_id/) | Gibt die global eindeutige Kennung (GUID) der Untertitel zurück.<br/>            Nur lesbar **System.Guid**. |
| [`label`](/slides/python-net/de/aspose.slides/icaptions/label/) | Gibt die Beschriftung der Untertitel zurück oder setzt sie.<br/>            Lesen/Schreiben **str**. |
| [`binary_data`](/slides/python-net/de/aspose.slides/icaptions/binary_data/) | Gibt die Binärdaten der Untertitel zurück.<br/>            Nur lesbar **int**[]. |
| [`data_as_string`](/slides/python-net/de/aspose.slides/icaptions/data_as_string/) | Gibt die Untertitel-Daten als UTF-8-kodierten String zurück<br/>            Nur lesbar **str**. |
