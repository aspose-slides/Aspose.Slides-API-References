## TextAutofitType Aufzählung

Stellt den Text-Autofit-Modus dar.

Der Typ TextAutofitType stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| NOT_DEFINED | Nicht definiert. |
| NONE | Kein Autofit. |
| NORMAL | Normaler Autofit. Schriftgröße und Zeilenabstand werden reduziert, um in die Form zu passen. |
| SHAPE | Form-Autofit. Die Formgröße wird geändert, um den Text zu passen. |
