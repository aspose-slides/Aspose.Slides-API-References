## ShapeStyle Klasse

Stellt die Stilreferenz einer Form dar.

Der ShapeStyle-Typ stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`line_color`](/slides/python-net/de/aspose.slides/shapestyle/line_color/) | Gibt die Konturfarbe einer Form zurück.<br/>            Nur lesbar [`IColorFormat`](/slides/python-net/de/aspose.slides/icolorformat). |
| [`line_style_index`](/slides/python-net/de/aspose.slides/shapestyle/line_style_index/) | Gibt den Spaltenindex einer Linie in einer Stilmatrix zurück oder setzt ihn.<br/>            Lesen/Schreiben **int**. |
| [`fill_color`](/slides/python-net/de/aspose.slides/shapestyle/fill_color/) | Gibt die Füllfarbe einer Form zurück.<br/>            Nur lesbar [`IColorFormat`](/slides/python-net/de/aspose.slides/icolorformat). |
| [`fill_style_index`](/slides/python-net/de/aspose.slides/shapestyle/fill_style_index/) | Gibt den Füllspaltenindex einer Form in Stilmatrizen zurück oder setzt ihn.<br/>            0 bedeutet keine Füllung,<br/>            positiver Wert - Index in den Füllstilen des Themes,<br/>            negativer Wert - Index in den Hintergrundstilen des Themes.<br/>            Lesen/Schreiben **int**. |
| [`effect_color`](/slides/python-net/de/aspose.slides/shapestyle/effect_color/) | Gibt die Effektfarbe einer Form zurück.<br/>            Nur lesbar [`IColorFormat`](/slides/python-net/de/aspose.slides/icolorformat). |
| [`effect_style_index`](/slides/python-net/de/aspose.slides/shapestyle/effect_style_index/) | Gibt den Effektspaltenindex einer Form in einer Stilmatrix zurück oder setzt ihn.<br/>            Lesen/Schreiben **int**. |
| [`font_color`](/slides/python-net/de/aspose.slides/shapestyle/font_color/) | Gibt die Schriftfarbe einer Form zurück.<br/>            Nur lesbar [`IColorFormat`](/slides/python-net/de/aspose.slides/icolorformat). |
| [`font_collection_index`](/slides/python-net/de/aspose.slides/shapestyle/font_collection_index/) | Gibt den Schriftindex einer Form in einer Schriftartsammlung zurück oder setzt ihn.<br/>            Lesen/Schreiben [`FontCollectionIndex`](/slides/python-net/de/aspose.slides/fontcollectionindex). |
