## SourceFormat Aufzählung

Stellt das Quelldateiformat dar.

Der Typ SourceFormat stellt die folgenden Member bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| PPT | Microsoft PowerPoint 97-2003 Präsentation (*.ppt). |
| PPTX | Microsoft Office Open XML Präsentation (*.pptx). |
| ODP | OpenDocument Präsentation (*.odp). |
| PPTM | Microsoft Office Open XML Makroaktivierte Präsentation (*.pptm). |
| PPSX | Microsoft Office Open XML Diashow (*.ppsx). |
| PPSM | Microsoft Office Open XML Makroaktivierte Diashow (*.ppsm). |
| POTX | Microsoft Office Open XML Vorlage (*.potx). |
| POTM | Microsoft Office Open XML Makroaktivierte Vorlage (*.potm). |
| PPS | Microsoft PowerPoint 97-2003 Diashow (*.pps). |
| POT | Microsoft PowerPoint 97-2003 Vorlage (*.pot). |
| OTP | OpenDocument Präsentationsvorlage (*.otp). |
| FODP | Flat XML ODF Präsentation (*.fodp). |
| XML | PowerPoint XML Präsentation (*.xml). |
