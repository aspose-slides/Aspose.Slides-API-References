## BlackWhiteMode Aufzählung

Bestimmt, wie farbige Formen in Schwarz-Weiß umgewandelt werden sollen.

Der Typ BlackWhiteMode stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| NOT_DEFINED | Die Eigenschaft ist nicht gesetzt |
| COLOR | Das Objekt wird mit normaler Farbdarstellung gerendert |
| AUTOMATIC | Das Objekt wird mit automatischer Farbdarstellung gerendert |
| GRAY | Das Objekt wird mit grauer Farbdarstellung gerendert |
| LIGHT_GRAY | Das Objekt wird mit hellgrauer Farbdarstellung gerendert |
| INVERSE_GRAY | Das Objekt wird mit invertierter grauer Farbdarstellung gerendert |
| GRAY_WHITE | Das Objekt wird mit grauer und weißer Farbdarstellung gerendert |
| BLACK_GRAY | Das Objekt wird mit schwarzer und grauer Farbdarstellung gerendert |
| BLACK_WHITE | Das Objekt wird mit schwarzer und weißer Farbdarstellung gerendert |
| BLACK | Das Objekt wird nur mit schwarzer Farbdarstellung gerendert |
| WHITE | Das Objekt wird mit weißer Farbdarstellung gerendert |
| HIDDEN | Das Objekt wird nicht gerendert |
