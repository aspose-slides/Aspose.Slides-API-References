## remove(self, item) {#icustomxmlpart}
Entfernt das erste Vorkommen eines bestimmten Objekts aus der Sammlung.

### Rückgabe

`true` wenn item erfolgreich entfernt wurde; andernfalls `false`.



```python
def remove(self, item):
    ...
```


| Parameter | Typ | Beschreibung |
| :- | :- | :- |
| item | [`ICustomXmlPart`](/slides/python-net/de/aspose.slides/icustomxmlpart) | Das benutzerdefinierte XML-Teil, das entfernt werden soll. |

### Ausnahmen

| Ausnahme | Beschreibung |
| :- | :- |
| **RuntimeError(Proxy error(ArgumentNullException))** | item ist `None`. |
