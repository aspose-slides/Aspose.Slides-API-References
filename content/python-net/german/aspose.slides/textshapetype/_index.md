## TextShapeType Aufzählung

Stellt eine Textumbruchform dar.

Der TextShapeType-Typ stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| NOT_DEFINED | Nicht definiert |
| NONE | Keine Form |
| PLAIN | Einfach |
| STOP | Stoppschild |
| TRIANGLE | Dreieck |
| TRIANGLE_INVERTED | Umgekehrtes Dreieck |
| CHEVRON | Keil |
| CHEVRON_INVERTED | Umgekehrter Keil |
| RING_INSIDE | Innerer Ring |
| RING_OUTSIDE | Äußerer Ring |
| ARCH_UP | Aufwärts-Bogen |
| ARCH_DOWN | Abwärts-Bogen |
| CIRCLE | Kreis |
| BUTTON | Schaltfläche |
| ARCH_UP_POUR | Aufwärtsüberlauf-Bogen |
| ARCH_DOWN_POUR | Abwärtsüberlauf-Bogen |
| CIRCLE_POUR | Kreisseinlauf |
| BUTTON_POUR | Schaltflächen-Einlauf |
| CURVE_UP | Aufwärtskurve |
| CURVE_DOWN | Abwärtskurve |
| CAN_UP | Aufwärtsdose |
| CAN_DOWN | Abwärtsdose |
| WAVE1 | Welle 1 |
| WAVE2 | Welle 2 |
| DOUBLE_WAVE1 | Doppelte Welle 1 |
| WAVE4 | Welle 4 |
| INFLATE | Aufblasen |
| DEFLATE | Entleeren |
| INFLATE_BOTTOM | Unterseite Aufblasen |
| DEFLATE_BOTTOM | Unterseite Entleeren |
| INFLATE_TOP | Oberseite Aufblasen |
| DEFLATE_TOP | Oberseite Entleeren |
| DEFLATE_INFLATE | Entleeren-Aufblasen |
| DEFLATE_INFLATE_DEFLATE | Entleeren-Aufblasen-Entleeren |
| FADE_RIGHT | Rechtsausblendung |
| FADE_LEFT | Linksausblendung |
| FADE_UP | Aufwärtsausblendung |
| FADE_DOWN | Abwärtsausblendung |
| SLANT_UP | Aufwärtsneigung |
| SLANT_DOWN | Abwärtsneigung |
| CASCADE_UP | Aufwärtskaskade |
| CASCADE_DOWN | Abwärtskaskade |
| CUSTOM | Benutzerdefiniert |
