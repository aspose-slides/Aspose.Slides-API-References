## SectionCollection Klasse

Stellt eine Sammlung von Abschnitten dar.

Der Typ SectionCollection stellt die folgenden Mitglieder bereit:

Liest das Element am angegebenen Index. Nur lesbar [`ISection`](/slides/python-net/de/aspose.slides/isection).
