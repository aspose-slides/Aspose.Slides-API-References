## IHeadingPair Klasse

Stellt eine 'Heading pair'-Eigenschaft des Dokuments dar. 
            Sie gibt den Gruppennamen der Dokumentteile und die Anzahl der Teile in der Gruppe an.

Der Typ IHeadingPair stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`name`](/slides/python-net/de/aspose.slides/iheadingpair/name/) | Gibt den Gruppennamen der Dokumentteile zurück.<br/>            Nur lesbar **str**. |
| [`count`](/slides/python-net/de/aspose.slides/iheadingpair/count/) | Gibt die Anzahl der Teile in der Gruppe zurück.<br/>            Nur lesbar **int**. |
