## OrganizationChartLayoutType Aufzählung

Stellt den Formatierungstyp der Kindknoten in einem Organisationsdiagramm dar.

Der Typ OrganizationChartLayoutType stellt die folgenden Member bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| INITIAL | Initialer Layouttyp |
| STANDART | Platziert Kindknoten horizontal unter dem übergeordneten Knoten. |
| BOTH_HANGING | Platziert Kindknoten vertikal unter dem übergeordneten Knoten sowohl auf der linken als auch auf der rechten Seite. |
| LEFT_HANGING | Platziert Kindknoten vertikal unter dem übergeordneten Knoten auf der linken Seite. |
| RIGHT_HANGING | Platziert Kindknoten vertikal unter dem übergeordneten Knoten auf der rechten Seite. |
