## get_base_placeholder(self) {#}
Gibt eine grundlegende Platzhalterform zurück (Form aus dem Layout und/oder der Masterfolie, von der die aktuelle Form ererbt wird).
Es wird None zurückgegeben, wenn die aktuelle Form nicht geerbt wird.
