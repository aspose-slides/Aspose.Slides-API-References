## bullet_fill_format Eigenschaft
Gibt das FillFormat-Objekt zurück, das Füllformatierungs-Eigenschaften für einen Knoten-Aufzählungspunkt enthält.
            Hinweis: kann None zurückgeben für bestimmte Arten von SmartArt-Layout, die keine Aufzählungspunkte für Knoten bereitstellen.
