## SmartArtLayoutType enumeration

Stellt den Layouttyp eines SmartArt-Diagramms dar.

Der Typ SmartArtLayoutType stellt die folgenden Mitglieder bereit:

## Felder

| Feld | Beschreibung |
| :- | :- |
| ACCENT_PROCESS | Verwenden, um einen Verlauf, eine Zeitleiste oder sequenzielle Schritte in einer Aufgabe, einem Prozess oder einem Workflow darzustellen. Geeignet zur Visualisierung von Level-1- und Level-2-Text. |
| ACCENTED_PICTURE | Verwenden, um eine zentrale fotografische Idee mit seitlich angeordneten verwandten Ideen darzustellen. Der obere Level-1-Text erscheint über dem zentralen Bild. Der zugehörige Text für andere Level-1-Formen erscheint neben den kleinen runden Bildern. Dieses Layout funktioniert auch gut ohne Text. |
| ALTERNATING_FLOW | Verwenden, um Informationsgruppen oder sequenzielle Schritte in einer Aufgabe, einem Prozess oder einem Workflow darzustellen. Betont die Interaktion bzw. Beziehungen zwischen den Informationsgruppen. |
| ALTERNATING_HEXAGONS | Verwenden, um eine Reihe miteinander verbundener Ideen darzustellen. Level-1-Text erscheint in den Sechsecken. Level-2-Text erscheint außerhalb der Formen. |
| ALTERNATING_PICTURE_BLOCKS | Verwenden, um eine Reihe von Bildern von oben nach unten darzustellen. Der Text erscheint abwechselnd rechts oder links vom Bild. |
| ALTERNATING_PICTURE_CIRCLES | Verwenden, um ein Set von Bildern mit Text darzustellen. Der zugehörige Text erscheint in den zentralen Kreisen, wobei die Bilder von links nach rechts abwechseln. |
| ARROW_RIBBON | Verwenden, um verwandte oder gegensätzliche Konzepte mit einer gewissen Verbindung, z. B. gegensätzliche Kräfte, darzustellen. Die ersten beiden Zeilen des Level-1-Texts werden für den Text in den Pfeilen verwendet. Unbenutzter Text wird nicht angezeigt, bleibt jedoch verfügbar, wenn Sie das Layout wechseln. |
| ASCENDING_PICTURE_ACCENT_PROCESS | Verwenden, um eine aufsteigende Reihe von Bildern mit beschreibendem Text darzustellen. Am besten geeignet für eine geringe Textmenge. |
| BALANCE | Verwenden, um zwei Ideen zu vergleichen oder ihre Beziehung darzustellen. Jede der ersten beiden Zeilen des Level-1-Texts entspricht dem Text oben auf einer Seite des Mittelpunktes. Betont Level-2-Text, der auf jeweils vier Formen pro Seite des Mittelpunktes beschränkt ist. Das Gleichgewicht kippt zur Seite mit den meisten Formen, die Level-2-Text enthalten. Unbenutzter Text wird nicht angezeigt, bleibt jedoch verfügbar, wenn Sie das Layout wechseln. |
| BASIC_BENDING_PROCESS | Verwenden, um einen Verlauf oder sequenzielle Schritte in einer Aufgabe, einem Prozess oder einem Workflow darzustellen. Nutzt sowohl den horizontalen als auch den vertikalen Anzeigeraum für Formen maximal aus. |
| BASIC_BLOCK_LIST | Verwenden, um nicht-sequenzielle oder gruppierte Informationsblöcke darzustellen. Nutzt sowohl den horizontalen als auch den vertikalen Anzeigeraum für Formen maximal aus. |
| BASIC_CHEVRON_PROCESS | Verwenden, um einen Verlauf; eine Zeitleiste; sequenzielle Schritte in einer Aufgabe, einem Prozess oder einem Workflow darzustellen oder Bewegung bzw. Richtung zu betonen. Level-1-Text erscheint innerhalb einer Pfeilform, während Level-2-Text unter den Pfeilformen erscheint. |
| BASIC_CYCLE | Verwenden, um eine fortlaufende Sequenz von Phasen, Aufgaben oder Ereignissen in einem kreisförmigen Ablauf darzustellen. Betont die Phasen oder Schritte mehr als die verbindenden Pfeile oder den Fluss. Am besten geeignet für ausschließlich Level-1-Text. |
| BASIC_MATRIX | Verwenden, um die Beziehung von Komponenten zu einem Ganzen in Quadranten darzustellen. Die ersten vier Zeilen des Level-1-Texts erscheinen in den Quadranten. Unbenutzter Text wird nicht angezeigt, bleibt jedoch verfügbar, wenn Sie das Layout wechseln. |
| BASIC_PIE | Verwenden, um zu zeigen, wie einzelne Teile ein Ganzes bilden. Die ersten sieben Zeilen des Level-1-Texts entsprechen den gleichmäßig verteilten Keil- oder Kreisformen. Die obere Level-1-Textform erscheint außerhalb des restlichen Kreises zur Hervorhebung. Unbenutzter Text wird nicht angezeigt, bleibt jedoch verfügbar, wenn Sie das Layout wechseln. |
| BASIC_PROCESS | Verwenden, um einen Verlauf oder sequenzielle Schritte in einer Aufgabe, einem Prozess oder einem Workflow darzustellen. |
| BASIC_PYRAMID | Verwenden, um proportionale, miteinander verbundene oder hierarchische Beziehungen darzustellen, wobei die größte Komponente unten liegt und nach oben hin verjüngt. Level-1-Text erscheint in den Pyramidensegmenten und Level-2-Text erscheint in Formen neben jedem Segment. |
| BASIC_RADIAL | Verwenden, um die Beziehung zu einer zentralen Idee in einem Zyklus darzustellen. Die erste Zeile des Level-1-Texts entspricht der zentralen Form, und ihr Level-2-Text entspricht den umgebenden runden Formen. Unbenutzter Text wird nicht angezeigt, bleibt jedoch verfügbar, wenn Sie das Layout wechseln. |
| BASIC_TARGET | Verwenden, um Einschluss, Abstufungen oder hierarchische Beziehungen darzustellen. Die ersten fünf Zeilen des Level-1-Texts sind mit einem Kreis verknüpft. Unbenutzter Text wird nicht angezeigt, bleibt jedoch verfügbar, wenn Sie das Layout wechseln. |
| BASIC_TIMELINE | Verwenden, um sequenzielle Schritte in einer Aufgabe, einem Prozess oder einem Workflow darzustellen oder Zeitleisteninformationen zu zeigen. Funktioniert gut mit sowohl Level-1- als auch Level-2-Text. |
| BASIC_VENN | Verwenden, um überlappende oder miteinander verbundene Beziehungen darzustellen. Die ersten sieben Zeilen des Level-1-Texts entsprechen einem Kreis. Bei vier oder weniger Zeilen Level-1-Text befindet sich der Text innerhalb der Kreise. Bei mehr als vier Zeilen Level-1-Text befindet sich der Text außerhalb der Kreise. Unbenutzter Text wird nicht angezeigt, bleibt jedoch verfügbar, wenn Sie das Layout wechseln. |
| BENDING_PICTURE_ACCENT_LIST | Verwenden, um nicht-sequenzielle oder gruppierte Informationsblöcke darzustellen. Die kleinen runden Formen sind dafür ausgelegt, Bilder zu enthalten. Geeignet zur Visualisierung von sowohl Level-1- als auch Level-2-Text. Nutzt sowohl den horizontalen als auch den vertikalen Anzeigeraum für Formen maximal aus. |
| BENDING_PICTURE_BLOCKS | Verwenden, um eine Reihe von Bildern darzustellen. Das Feld, das die untere Ecke abdeckt, kann kleine Textmengen enthalten. |
| BENDING_PICTURE_CAPTION | Verwenden, um eine sequenzielle Reihe von Bildern darzustellen. Das Feld, das die untere Ecke abdeckt, kann kleine Textmengen enthalten. |
| BENDING_PICTURE_CAPTION_LIST | Verwenden, um eine Reihe von Bildern darzustellen. Titel und Beschreibung erscheinen in einer Hinweisform unter jedem Bild. |
| BENDING_PICTURE_SEMI_TRANSPARENT_TEXT | Verwenden, um eine Reihe von Bildern darzustellen. Ein halbtransparentes Feld bedeckt den unteren Bildbereich und enthält alle Textebenen. |
| BLOCK_CYCLE | Verwenden, um eine fortlaufende Sequenz von Phasen, Aufgaben oder Ereignissen in einem kreisförmigen Ablauf darzustellen. Betont die Phasen oder Schritte mehr als die verbindenden Pfeile oder den Fluss. |
| BUBBLE_PICTURE_LIST | Verwenden, um eine Reihe von Bildern darzustellen. Kann bis zu acht Level-1-Bilder enthalten. Unbenutzter Text und Bilder werden nicht angezeigt, bleiben jedoch verfügbar, wenn Sie das Layout wechseln. Am besten geeignet für kleine Textmengen. |
| CAPTIONED_PICTURES | Verwenden, um Bilder mit mehreren Textebenen darzustellen. Am besten geeignet für eine geringe Menge an Level-1-Text und eine mittlere Menge an Level-2-Text. |
| CHEVRON_LIST | Verwenden, um einen Fortschritt durch mehrere Prozesse zu zeigen, die einen Gesamtablauf bilden. Auch geeignet, um kontrastierende Prozesse zu visualisieren. Der Level-1-Text entspricht der ersten Pfeilform links, während der Level-2-Text den horizontalen Zwischenschritten jeder Form, die Level-1-Text enthält, zugeordnet ist. |
| CIRCLE_ACCENT_TIMELINE | Verwenden, um eine Reihe von Ereignissen oder Zeitleisteninformationen darzustellen. Level-1-Text erscheint neben größeren runden Formen. Level-2-Text erscheint neben kleineren runden Formen. |
| CIRCLE_ARROW_PROCESS | Verwenden, um sequenzielle Elemente mit unterstützendem Text für jedes Element darzustellen. Dieses Diagramm eignet sich am besten für kleine Mengen an Level-1-Text. |
| CIRCLE_PICTURE_HIERARCHY | Verwenden, um hierarchische Informationen oder Berichtsprache in einer Organisation darzustellen. Bilder erscheinen in Kreisen und entsprechender Text erscheint neben den Bildern. |
| CIRCLE_RELATIONSHIP | Verwenden, um die Beziehung zu oder von einer zentralen Idee darzustellen. Level-2-Text wird nicht sequenziell hinzugefügt und ist auf fünf Elemente beschränkt. Es kann nur ein Level-1-Element geben. |
| CIRCULAR_BENDING_PROCESS | Verwenden, um eine lange oder nichtlineare Sequenz bzw. Schritte in einer Aufgabe, einem Prozess oder einem Workflow darzustellen. Am besten geeignet für ausschließlich Level-1-Text. Nutzt sowohl den horizontalen als auch den vertikalen Anzeigeraum für Formen maximal aus. |
| CIRCULAR_PICTURE_CALLOUT | Verwenden, um eine zentrale Idee und Unterideen oder verwandte Elemente darzustellen. Der Text für das erste Bild deckt den unteren Bildbereich ab. Der zugehörige Text für andere Level-1-Formen erscheint neben den kleinen runden Bildern. Dieses Diagramm funktioniert auch gut ohne Text. |
| CLOSED_CHEVRON_PROCESS | Verwenden, um einen Verlauf, eine Zeitleiste oder sequenzielle Schritte in einer Aufgabe, einem Prozess oder einem Workflow darzustellen bzw. Bewegung oder Richtung zu betonen. Kann verwendet werden, um Informationen in der Ausgangsform zu betonen. Am besten geeignet für ausschließlich Level-1-Text. |
| CONTINUOUS_ARROW_PROCESS | Verwenden, um eine Zeitleiste oder sequenzielle Schritte in einer Aufgabe, einem Prozess oder einem Workflow darzustellen. Am besten geeignet für Level-1-Text, da jede Zeile des Level-1-Texts innerhalb der Pfeilform erscheint. Level-2-Text erscheint außerhalb der Pfeilform. |
| CONTINUOUS_BLOCK_PROCESS | Verwenden, um einen Verlauf oder sequenzielle Schritte in einer Aufgabe, einem Prozess oder einem Workflow darzustellen. Am besten geeignet für minimale Level-1- und Level-2-Texte. |
| CONTINUOUS_CYCLE | Verwenden, um eine fortlaufende Sequenz von Phasen, Aufgaben oder Ereignissen in einem kreisförmigen Ablauf darzustellen. Betont die Verbindung aller Komponenten. Am besten geeignet für ausschließlich Level-1-Text. |
| CONTINUOUS_PICTURE_LIST | Verwenden, um Gruppen von miteinander verbundenen Informationen darzustellen. Die runden Formen sind dafür ausgelegt, Bilder zu enthalten. |
| CONVERGING_ARROWS | Verwenden, um Ideen oder Konzepte darzustellen, die zu einem zentralen Punkt konvergieren. Am besten geeignet für ausschließlich Level-1-Text. |
| CONVERGING_RADIAL | Verwenden, um Beziehungen von Konzepten oder Komponenten zu einer zentralen Idee in einem Zyklus darzustellen. Die erste Zeile des Level-1-Texts entspricht der zentralen runden Form und die Zeilen des Level-2-Texts entsprechen den umliegenden rechteckigen Formen. Unbenutzter Text wird nicht angezeigt, bleibt jedoch verfügbar, wenn Sie das Layout wechseln. |
| COUNTERBALANCE_ARROWS | Verwenden, um zwei gegensätzliche Ideen oder Konzepte darzustellen. Jede der ersten beiden Zeilen des Level-1-Texts entspricht einem Pfeil und funktioniert gut mit Level-2-Text. Unbenutzter Text wird nicht angezeigt, bleibt jedoch verfügbar, wenn Sie das Layout wechseln. |
| CYCLE_MATRIX | Verwenden, um die Beziehung zu einer zentralen Idee in einer zyklischen Progression darzustellen. Jede der ersten vier Zeilen des Level-1-Texts entspricht einem Keil- oder Kreissegment, und Level-2-Text erscheint in einer rechteckigen Form neben dem Keil- oder Kreissegment. Unbenutzter Text wird nicht angezeigt, bleibt jedoch verfügbar, wenn Sie das Layout wechseln. |
| DESCENDING_BLOCK_LIST | Verwenden, um Gruppen von verwandten Ideen oder Informationslisten darzustellen. Die Textformen verkleinern sich sequenziell in der Höhe, und der Level-1-Text wird vertikal angezeigt. |
| DESCENDING_PROCESS | Verwenden, um eine absteigende Reihe von Ereignissen darzustellen. Der erste Level-1-Text befindet sich oben am Pfeil, und der letzte Level-1-Text wird unten am Pfeil angezeigt. Nur die ersten sieben Level-1-Elemente werden angezeigt. Am besten geeignet für kleine bis mittlere Textmengen. |
| DETAILED_PROCESS | Verwenden Sie große Mengen an Level-2-Text, um einen Verlauf durch Phasen darzustellen. |
| DIVERGING_ARROWS | Verwenden, um Ideen oder Konzepte darzustellen, die von einer zentralen Quelle nach außen verlaufen. Am besten geeignet für ausschließlich Level-1-Text. |
| DIVERGING_RADIAL | Verwenden, um Beziehungen zu einer zentralen Idee in einem Zyklus darzustellen. Die erste Level-1-Zeile entspricht der zentralen runden Form. Betont die umgebenden Kreise mehr als die zentrale Idee. Unbenutzter Text wird nicht angezeigt, bleibt jedoch verfügbar, wenn Sie das Layout wechseln. |
| EQUATION | Verwenden, um sequenzielle Schritte oder Aufgaben darzustellen, die einen Plan oder ein Ergebnis zeigen. Die letzte Level-1-Zeile erscheint nach dem Gleichheitszeichen (=). Am besten geeignet für ausschließlich Level-1-Text. |
| FRAMED_TEXT_PICTURE | Verwenden, um Bilder mit zugehörigem Level-1-Text, der in einem Rahmen angezeigt wird, darzustellen. |
| FUNNEL | Verwenden, um die Filterung von Informationen oder das Zusammenführen von Teilen zu einem Ganzen darzustellen. Betont das Endergebnis. Kann bis zu vier Zeilen Level-1-Text enthalten; die letzte dieser vier Zeilen erscheint unter dem Trichter und die anderen Zeilen entsprechen einer runden Form. Unbenutzter Text wird nicht angezeigt, bleibt jedoch verfügbar, wenn Sie das Layout wechseln. |
| GEAR | Verwenden, um ineinandergreifende Ideen darzustellen. Jede der ersten drei Zeilen des Level-1-Texts entspricht einer Zahnradform, und der zugehörige Level-2-Text erscheint in Rechtecken neben der Zahnradform. Unbenutzter Text wird nicht angezeigt, bleibt jedoch verfügbar, wenn Sie das Layout wechseln. |
| GRID_MATRIX | Verwenden, um die Platzierung von Konzepten entlang zweier Achsen zu zeigen. Betont die einzelnen Komponenten statt des Ganzen. Die ersten vier Zeilen des Level 1-Textes erscheinen in den Quadranten. Unbenutzter Text wird nicht angezeigt, bleibt jedoch verfügbar, wenn Sie das Layout wechseln. |
| GROUPED_LIST | Verwenden, um Gruppen und Untergruppen von Informationen oder Schritte und Unter-Schritte in einer Aufgabe, einem Prozess oder Workflow darzustellen. Level 1-Text entspricht den horizontalen Formen der obersten Ebene, und Level 2-Text entspricht den vertikalen Unter-Schritten unter jeder zugehörigen Form der obersten Ebene. Eignet sich gut, um Unter-gruppen oder Unter-schritte, hierarchische Informationen oder mehrere Informationslisten hervorzuheben. |
| HALF_CIRCLE_ORGANIZATION_CHART | Verwenden, um hierarchische Informationen oder Berichtsbeziehungen in einer Organisation darzustellen. Die Assistenten-Formen und Org Chart-hängenden Layouts sind mit diesem Layout verfügbar. |
| HEXAGON_CLUSTER | Verwenden, um Bilder mit zugehörigem Beschreibungstext darzustellen. Kleine Hexagone zeigen das Bild-Text-Paar an. Am besten geeignet für kleine Textmengen. |
| HIERARCHY | Verwenden, um hierarchische Beziehungen von oben nach unten darzustellen. |
| HIERARCHY_LIST | Verwenden, um hierarchische Beziehungen über Gruppen hinweg darzustellen. Kann auch zum Gruppieren oder Auflisten von Informationen verwendet werden. |
| HORIZONTAL_BULLET_LIST | Verwenden, um nicht-sequenzielle oder gruppierte Informationslisten darzustellen. Geeignet für große Textmengen. Der gesamte Text hat die gleiche Betonung, und keine Richtung wird impliziert. |
| HORIZONTAL_HIERARCHY | Verwenden, um hierarchische Beziehungen horizontal darzustellen. Geeignet für Entscheidungsbäume. |
| HORIZONTAL_LABELED_HIERARCHY | Verwenden, um hierarchische Beziehungen horizontal und hierarchisch gruppiert darzustellen. Betont Überschriften oder Level 1-Text. Die erste Zeile des Level 1-Textes erscheint in der Form am Anfang der Hierarchie, und die zweite und alle folgenden Zeilen des Level 1-Textes erscheinen an der Oberseite der hohen Rechtecke. |
| HORIZONTAL_MULTI_LEVEL_HIERARCHY | Verwenden, um große Mengen hierarchischer Informationen horizontal darzustellen. Der obere Teil der Hierarchie wird vertikal angezeigt. Dieses Layout unterstützt viele Ebenen in der Hierarchie. |
| HORIZONTAL_ORGANIZATION_CHART | Verwenden, um hierarchische Informationen horizontal oder Berichtsbeziehungen in einer Organisation darzustellen. Die Assistenten-Form und die Org Chart-hängenden Layouts sind mit diesem Layout verfügbar. |
| HORIZONTAL_PICTURE_LIST | Verwenden, um nicht-sequenzielle oder gruppierte Informationen mit Schwerpunkt auf zugehörigen Bildern darzustellen. Die oberen Formen sind für das Einfügen von Bildern vorgesehen. |
| INCREASING_ARROWS_PROCESS | Verwenden, um sequenzielle und überlappende Schritte in einem Prozess darzustellen. Auf fünf Level 1-Elemente beschränkt. Level 2 kann große Textmengen enthalten. |
| INCREASING_CIRCLE_PROCESS | Verwenden, um eine Reihe von Schritten darzustellen, wobei das Innere des Kreises mit jedem Schritt zunimmt. Auf sieben Level 1-Schritte beschränkt, aber unbegrenzte Level 2-Elemente. Geeignet für große Mengen an Level 2-Text. |
| INVERTED_PYRAMID | Verwenden, um proportionale, miteinander verbundene oder hierarchische Beziehungen mit der größten Komponente oben und einer Verengung nach unten darzustellen. Level 1-Text erscheint in den Pyramidensegmenten und Level 2-Text in Formen neben jedem Segment. |
| LABELED_HIERARCHY | Verwenden, um hierarchische Beziehungen von oben nach unten und hierarchisch gruppiert darzustellen. Betont Überschriften oder Level 1-Text. Die erste Zeile des Level 1-Textes erscheint in der Form am Beginn der Hierarchie, und alle folgenden Zeilen des Level 1-Textes erscheinen links der langen Rechtecke. |
| LINEAR_VENN | Verwenden, um überlappende Beziehungen in einer Sequenz darzustellen. Am besten geeignet für ausschließlich Level 1-Text. |
| LINED_LIST | Verwenden, um große Textmengen in Kategorien und Unterkategorien zu unterteilen. Geeignet für mehrere Textebenen. Text auf derselben Ebene wird durch Linien getrennt. |
| MULTIDIRECTIONAL_CYCLE | Verwenden, um eine fortlaufende Sequenz von Phasen, Aufgaben oder Ereignissen darzustellen, die in jede Richtung erfolgen kann. |
| NAMEAND_TITLE_ORGANIZATION_CHART | Verwenden, um hierarchische Informationen oder Berichtsbeziehungen in einer Organisation darzustellen. Um Text im Titelfeld einzugeben, tippen Sie direkt in die kleinere rechteckige Form. Die Assistenten-Form und die Org Chart-hängenden Layouts sind mit diesem Layout verfügbar. |
| NESTED_TARGET | Verwenden, um Containment-Beziehungen darzustellen. Jede der ersten drei Zeilen des Level 1-Textes entspricht dem oberen linken Text in den Formen, und Level 2-Text entspricht den kleineren Formen. Am besten geeignet für minimale Level 2-Textzeilen. Unbenutzter Text wird nicht angezeigt, bleibt aber verfügbar, wenn Sie das Layout wechseln. |
| NONDIRECTIONAL_CYCLE | Verwenden, um eine fortlaufende Sequenz von Phasen, Aufgaben oder Ereignissen in einem kreisförmigen Fluss darzustellen. Jede Form hat die gleiche Wichtigkeit. Geeignet, wenn keine Richtung angegeben werden muss. |
| OPPOSING_ARROWS | Verwenden, um zwei gegensätzliche Ideen oder von einem zentralen Punkt aus divergierende Ideen darzustellen. Jede der ersten beiden Zeilen des Level 1-Textes entspricht einem Pfeil. Unbenutzter Text wird nicht angezeigt, bleibt aber verfügbar, wenn Sie das Layout wechseln. |
| OPPOSING_IDEAS | Verwenden, um zwei gegensätzliche oder kontrastierende Ideen darzustellen. Kann ein oder zwei Level 1-Elemente enthalten. Jeder Level 1-Text kann mehrere Unterebenen enthalten. Geeignet für große Textmengen. |
| ORGANIZATION_CHART | Verwenden, um hierarchische Informationen oder Berichtsbeziehungen in einer Organisation darzustellen. Die Assistenten-Form und die Org Chart-hängenden Layouts sind mit diesem Layout verfügbar. |
| PHASED_PROCESS | Verwenden, um drei Phasen eines Prozesses darzustellen. Auf drei Level 1-Elemente beschränkt. Die ersten beiden Level 1-Elemente können jeweils vier Level 2-Elemente enthalten, und das dritte Level 1-Element kann eine unbegrenzte Anzahl an Level 2-Elementen enthalten. Am besten geeignet für kleine Textmengen. |
| PICTURE_ACCENT_BLOCKS | Verwenden, um eine Gruppe von Bildern in Blöcken von der Ecke aus anzuzeigen. Der zugehörige Text wird vertikal angezeigt. Geeignet als Akzent auf Titel- oder Untertitel-Folien oder für Abschnitts-trennungen eines Dokuments. |
| PICTURE_ACCENT_LIST | Verwenden, um gruppierte oder verwandte Informationen darzustellen. Die kleinen Formen in den oberen Ecken sind für das Einfügen von Bildern vorgesehen. Betont Level 2-Text über Level 1-Text und ist eine gute Wahl für große Mengen an Level 2-Text. |
| PICTURE_ACCENT_PROCESS | Verwenden, um sequenzielle Schritte in einer Aufgabe, einem Prozess oder Workflow darzustellen. Die rechteckigen Formen im Hintergrund sind für das Einfügen von Bildern vorgesehen. |
| PICTURE_CAPTION_LIST | Verwenden, um nicht-sequenzielle oder gruppierte Informationsblöcke darzustellen. Die oberen Formen sind für das Einfügen von Bildern vorgesehen und Bilder werden gegenüber Text betont. Geeignet für Bilder mit kurzen Textunterschriften. |
| PICTURE_GRID | Verwenden, um Bilder in einem quadratischen Raster anzuzeigen. Am besten mit einer kleinen Menge an Level 1-Text, der über dem Bild erscheint. |
| PICTURE_LINEUP | Verwenden, um eine Reihe von Bildern nebeneinander anzuzeigen. Level 1-Text befindet sich oben über dem Bild. Level 2-Text erscheint unter dem Bild. |
| PICTURE_STRIPS | Verwenden, um eine Reihe von Bildern von oben nach unten mit Level 1-Text neben jedem anzuzeigen. |
| PIE_PROCESS | Verwenden, um Schritte in einem Prozess darzustellen, wobei jedes Kuchenscheibensegment bis zu sieben Formen vergrößert. Level 1-Text wird vertikal angezeigt. |
| PLUSAND_MINUS | Verwenden, um die Vor- und Nachteile von zwei Ideen zu zeigen. Jeder Level 1-Text kann mehrere Unterebenen enthalten. Geeignet für große Textmengen. Auf zwei Level 1-Elemente beschränkt. |
| PROCESS_ARROWS | Verwenden, um Informationen zu veranschaulichen, die einen Prozess oder Workflow darstellen. Level 1-Text erscheint in den kreisförmigen Formen und Level 2-Text in den Pfeilformen. Am besten geeignet für minimalen Text und zur Betonung von Bewegung oder Richtung. |
| PROCESS_LIST | Verwenden, um mehrere Gruppen von Informationen oder Schritte und Unter-schritte in einer Aufgabe, einem Prozess oder Workflow darzustellen. Level 1-Text entspricht den horizontalen Formen der obersten Ebene, und Level 2-Text den vertikalen Unter-schritten unter jeder zugehörigen Form der obersten Ebene. |
| PYRAMID_LIST | Verwenden, um proportionale, miteinander verbundene oder hierarchische Beziehungen darzustellen. Text erscheint in den rechteckigen Formen über dem Pyramiden-Hintergrund. |
| RADIAL_CLUSTER | Verwenden, um Daten zu zeigen, die sich auf eine zentrale Idee oder ein zentrales Thema beziehen. Der obere Level 1-Text erscheint in der Mitte. Level 2-Text erscheint in den umgebenden Formen. Kann bis zu sieben Level 2-Formen enthalten. Unbenutzter Text wird nicht angezeigt, bleibt aber verfügbar, wenn Sie das Layout wechseln. Am besten geeignet für kleine Textmengen. |
