## SmartArtNode Klasse

Stellt einen Knoten eines SmartArt-Objekts dar

Der Typ SmartArtNode stellt die folgenden Mitglieder bereit:

## Eigenschaften

| Eigenschaft | Beschreibung |
| :- | :- |
| [`child_nodes`](/slides/python-net/de/aspose.slides.smartart/smartartnode/child_nodes/) | Gibt Sammlungen aller untergeordneten Knoten des aktuellen Knotens zurück.<br/>            Nur-Lesen [`ISmartArtNodeCollection`](/slides/python-net/de/aspose.slides.smartart/ismartartnodecollection). |
| [`shapes`](/slides/python-net/de/aspose.slides.smartart/smartartnode/shapes/) | Gibt Sammlungen aller dem Knoten zugehörigen Formen zurück.<br/>            Nur-Lesen [`ISmartArtShapeCollection`](/slides/python-net/de/aspose.slides.smartart/ismartartshapecollection). |
| [`text_frame`](/slides/python-net/de/aspose.slides.smartart/smartartnode/text_frame/) | Gibt den Textbereich des Knotens zurück.<br/>            Nur-Lesen [`ITextFrame`](/slides/python-net/de/aspose.slides/itextframe). |
| [`is_assistant`](/slides/python-net/de/aspose.slides.smartart/smartartnode/is_assistant/) | Gibt den Knoten als Assistent zurück oder legt ihn fest.<br/>            Lesen/Schreiben **bool**. |
| [`level`](/slides/python-net/de/aspose.slides.smartart/smartartnode/level/) | Gibt die Verschachtelungsebene des Knotens zurück.<br/>            Nur-Lesen **int**. |
| [`bullet_fill_format`](/slides/python-net/de/aspose.slides.smartart/smartartnode/bullet_fill_format/) | Gibt das FillFormat-Objekt zurück, das Füllformatierungs-Eigenschaften für ein Aufzählungszeichen eines Knotens enthält.<br/>            Hinweis: kann None zurückgeben für bestimmte Arten von SmartArt-Layout, die keine Aufzählungszeichen für Knoten bereitstellen.<br/>            Nur-Lesen [`IFillFormat`](/slides/python-net/de/aspose.slides/ifillformat). |
| [`position`](/slides/python-net/de/aspose.slides.smartart/smartartnode/position/) | Gibt die nullbasierte Position des Knotens unter den Geschwisterknoten zurück oder legt sie fest.<br/>            Lesen/Schreiben **int**. |
| [`is_hidden`](/slides/python-net/de/aspose.slides.smartart/smartartnode/is_hidden/) | Gibt true zurück, wenn dieser Knoten ein versteckter Knoten im Datenmodell ist.<br/>            Nur-Lesen **bool**. |
| [`organization_chart_layout`](/slides/python-net/de/aspose.slides.smartart/smartartnode/organization_chart_layout/) | Gibt den mit dem aktuellen Knoten verbundenen Organisation-Diagrammlayouttyp zurück oder legt ihn fest.<br/>            Lesen/Schreiben [`OrganizationChartLayoutType`](/slides/python-net/de/aspose.slides.smartart/organizationchartlayouttype). |
