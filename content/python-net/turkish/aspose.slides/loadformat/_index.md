## LoadFormat sayımı

Yüklenecek belgenin formatını belirtir.

LoadFormat türü aşağıdaki üyeleri sunar:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| AUTO | Aspose.Slides'a formatı otomatik olarak tanımasını söyler. |
| PPT | Microsoft PowerPoint 97-2003 Sunumu. |
| PPS | Microsoft PowerPoint 97-2003 Slayt Gösterisi. |
| PPTX | Microsoft Office Open XML PresentationML Belgesi. |
| PPSX | Microsoft Office Open XML PresentationML Slayt Gösterisi. |
| ODP | OpenOffice ODF Sunumu. |
| POTX | Microsoft Office Open XML PresentationML Şablonu. |
| PPTM | Microsoft Office Open XML PresentationML Makro Destekli Belge. |
| PPSM | Microsoft Office Open XML PresentationML Makro Destekli Slayt Gösterisi. |
| POTM | Microsoft Office Open XML PresentationML Makro Destekli Şablon. |
| OTP | OpenOffice OTP Sunum Şablonu. |
| PPT95 | Microsoft PowerPoint 95 Sunumu. |
| POT | Microsoft PowerPoint 97-2003 Sunum Şablonu. |
| FODP | Düz XML ODF Sunumu. |
| UNKNOWN | Bilinmeyen dosya formatı |
