## ModernComment sınıfı

Bir slayt üzerindeki yorumu temsil eder.

**Kalıtım:**[`ModernComment`](/slides/python-net/tr/aspose.slides/moderncomment) → [`Comment`](/slides/python-net/tr/aspose.slides/comment)

ModernComment türü aşağıdaki üyeleri sunar:

## Özellikler

| Özellik | Açıklama |
| :- | :- |
| [`text`](/slides/python-net/tr/aspose.slides/moderncomment/text/) | Bir slayt yorumunun düz metnini getirir veya ayarlar.<br/>            Okuma/yazma **str**. |
| [`created_time`](/slides/python-net/tr/aspose.slides/moderncomment/created_time/) | Bir yorumun oluşturulma zamanını getirir veya ayarlar.<br/>            Bu özelliği **System.DateTime** olarak ayarlamak, yorum zamanının ayarlanmadığı anlamına gelir.<br/>            Okuma/yazma **System.DateTime**. |
| [`slide`](/slides/python-net/tr/aspose.slides/moderncomment/slide/) | Bir yorumun üst slaydını getirir veya ayarlar.<br/>            Sadece okuma [`ISlide`](/slides/python-net/tr/aspose.slides/islide). |
| [`author`](/slides/python-net/tr/aspose.slides/moderncomment/author/) | Bir yorumun yazarını getirir.<br/>            Sadece okuma [`ICommentAuthor`](/slides/python-net/tr/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/tr/aspose.slides/moderncomment/position/) | Bir slayt üzerindeki yorumun konumunu getirir veya ayarlar.<br/>            Okuma/yazma **aspose.slides.PointF**. |
| [`parent_comment`](/slides/python-net/tr/aspose.slides/moderncomment/parent_comment/) | Üst yorumu getirir veya ayarlar.<br/>            Okuma/yazma [`IComment`](/slides/python-net/tr/aspose.slides/icomment). |
| [`shape`](/slides/python-net/tr/aspose.slides/moderncomment/shape/) | Yorumla ilişkili bir şekli getirir.<br/>            Sadece okuma [`IShape`](/slides/python-net/tr/aspose.slides/ishape). |
| [`text_selection_start`](/slides/python-net/tr/aspose.slides/moderncomment/text_selection_start/) | Yorum AutoShape ile ilişkili ise, metin çerçevesindeki metin seçiminin başlangıç konumunu getirir veya ayarlar.<br/>            Okuma/yazma **int**. |
| [`text_selection_length`](/slides/python-net/tr/aspose.slides/moderncomment/text_selection_length/) | Yorum AutoShape ile ilişkili ise, metin çerçevesindeki metin seçiminin uzunluğunu getirir veya ayarlar.<br/>            Okuma/yazma **int**. |
| [`status`](/slides/python-net/tr/aspose.slides/moderncomment/status/) | Yorumun durumunu getirir veya ayarlar.<br/>            Okuma/yazma [`ModernCommentStatus`](/slides/python-net/tr/aspose.slides/moderncommentstatus). |
