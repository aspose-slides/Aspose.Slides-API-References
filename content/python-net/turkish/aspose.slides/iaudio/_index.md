## IAudio sınıfı

Gömülü bir ses dosyasını temsil eder.

IAudio türü aşağıdaki üyelere sahiptir:

## Özellikler

| Property | Description |
| :- | :- |
| [`content_type`](/slides/python-net/tr/aspose.slides/iaudio/content_type/) | Bir sesin MIME tipini döndürür, [`IAudio.binary_data`](/slides/python-net/tr/aspose.slides/iaudio/binary_data) içinde kodlanmış.<br/>            Sadece okunur **str**. |
| [`binary_data`](/slides/python-net/tr/aspose.slides/iaudio/binary_data/) | Bir sesin verisinin bir kopyasını döndürür. Büyük miktarda veri durumunda, gereksiz ses verisinin bellek içine yüklenmesini veya OutOfMemoryException oluşmasını önlemek için <br/>            [`IAudio.get_stream`](/slides/python-net/tr/aspose.slides/iaudio/get_stream) yönteminin kullanılmasını düşünün.<br/>            Sadece okunur **int**[]. |
