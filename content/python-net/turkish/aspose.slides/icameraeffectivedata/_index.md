## ICameraEffectiveData sınıf

Etkili kamera özelliklerini içeren değişmez nesne.

ICameraEffectiveData türü aşağıdaki üyeleri sunar:

## Özellikler

| Özellik | Açıklama |
| :- | :- |
| [`camera_type`](/slides/python-net/tr/aspose.slides/icameraeffectivedata/camera_type/) | Kamera türü.<br/>            Yalnızca okuma [`CameraPresetType`](/slides/python-net/tr/aspose.slides/camerapresettype). |
| [`field_of_view_angle`](/slides/python-net/tr/aspose.slides/icameraeffectivedata/field_of_view_angle/) | Kamera FOV (0-180 derece, görüş alanı).<br/>            Yalnızca okuma **float**. |
| [`zoom`](/slides/python-net/tr/aspose.slides/icameraeffectivedata/zoom/) | Kamera yakınlaştırması (yüzde cinsinden pozitif değer).<br/>            Yalnızca okuma **float**. |

## Yöntemler

| Yöntem | Açıklama |
| :- | :- |
| [`get_rotation(self)`](/slides/python-net/tr/aspose.slides/icameraeffectivedata/get_rotation/#) | Bir dönüş, enlem<br/>            koordinatı, boylam koordinatı ve eksen etrafında bir devrim kullanılarak tanımlanır <br/>            enlem ve boylam koordinatları gibi.<br/>            dönüşüm dizisinin ilk elemanı - enlem, ikincisi - boylam, üçüncüsü - devrim.<br/>            Döndürme tanımlı değilse None döner. |
