## TextSearchOptions sınıfı

Presentation, Slide veya TextFrame içinde metin aramak için kullanılabilecek seçenekleri temsil eder.

TextSearchOptions türü aşağıdaki üyeleri sunar:

## Yapıcılar

| Yapıcı | Açıklama |
| :- | :- |
| [`__init__(self)`](/slides/python-net/tr/aspose.slides/textsearchoptions/__init__/#) | Yeni varsayılan metin arama seçenekleri oluşturur. |

## Özellikler

| Özellik | Açıklama |
| :- | :- |
| [`case_sensitive`](/slides/python-net/tr/aspose.slides/textsearchoptions/case_sensitive/) | Büyük/küçük harfe duyarlı arama kullanmak için true, aksi takdirde false ayarlayın.<br/>            Read/write **bool**. |
| [`whole_words_only`](/slides/python-net/tr/aspose.slides/textsearchoptions/whole_words_only/) | Yalnızca tam kelimelerle eşleşmesi için true, aksi takdirde false ayarlayın.<br/>            Read/write **bool**. |
| [`include_notes`](/slides/python-net/tr/aspose.slides/textsearchoptions/include_notes/) | `true` ayarlayarak slayt notlarında bulunan metni ([`NotesSlide`](/slides/python-net/tr/aspose.slides/notesslide)) <br/>            metin arama, değiştirme veya vurgulama işlemleri sırasında dahil edin.<br/>            Varsayılan değer `false`. |
