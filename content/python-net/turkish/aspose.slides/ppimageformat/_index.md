## PPImageFormat enum

Görüntü formatları. Bu enum, `System.Drawing.Imaging.ImageFormat` sınıfının yerine geçer. COM uyumluluğu için gereklidir.

PPImageFormat türü aşağıdaki üyeleri sunar:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| BMP | Bitmap (BMP) görüntü formatını alır. |
| EMF | Gelişmiş metafile (EMF) görüntü formatını alır. |
| EXIF | Değiştirilebilir Görüntü Dosyası (Exif) formatını alır. |
| GIF | Grafik Değişim Formatı (GIF) görüntü formatını alır. |
| ICON | Windows simge görüntü formatını alır. |
| JPEG | Joint Photographic Experts Group (JPEG) görüntü formatını alır. |
| MEMORY_BMP | Bellekteki bitmap formatını alır. |
| PNG | W3C Portable Network Graphics (PNG) görüntü formatını alır. |
| TIFF | Tagged Image File Format (TIFF) görüntü formatını alır. |
| WMF | Windows metafile (WMF) görüntü formatını alır. |
