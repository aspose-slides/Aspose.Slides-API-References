## CustomXmlPart sınıfı

Özel xml bölümünü temsil eder.

CustomXmlPart türü aşağıdaki üyeleri sunar:

## Özellikler

| Özellik | Açıklama |
| :- | :- |
| [`xml_data`](/slides/python-net/tr/aspose.slides/customxmlpart/xml_data/) | XML verisini döndürür veya ayarlar.<br/>            Okuma/yazma **int**[].<br/>            değer `None`'dır. değer boş veya xml-data geçersizdir. |
| [`xml_as_string`](/slides/python-net/tr/aspose.slides/customxmlpart/xml_as_string/) | XML verisini UTF-8 dizesi olarak döndürür veya ayarlar.<br/>            Okuma/yazma **str**.<br/>            değer `None`'dır. değer boş veya xml-data geçersizdir. |
| [`item_id`](/slides/python-net/tr/aspose.slides/customxmlpart/item_id/) | Tek bir özel XML <br/>            parçayı bir Office Open XML belgesi içinde benzersiz şekilde tanımlayan küresel benzersiz tanımlayıcıyı (GUID) belirtir.<br/>            Sadece okuma **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/tr/aspose.slides/customxmlpart/namespace_schemas/) | Özel XML parçasıyla ilişkili XML şema koleksiyonunu döndürür.<br/>            Sadece okuma **str**[]. |
