## HyperlinkActionType enum

Represents a type of hyperlink action.

The HyperlinkActionType type exposes the following members:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| UNKNOWN | Tanımlanamayan eylem tipi. |
| NO_ACTION | Eylem yok. |
| HYPERLINK | Normal hiperlink. |
| JUMP_FIRST_SLIDE | Sunumun ilk slaytına atla. |
| JUMP_PREVIOUS_SLIDE | Önceki slayta atla. |
| JUMP_NEXT_SLIDE | Sonraki slayta atla. |
| JUMP_LAST_SLIDE | Sunumun son slaytına atla. |
| JUMP_END_SHOW | Slayt gösterisinin sonuna atla. |
| JUMP_LAST_VIEWED_SLIDE | Son görüntülenen slayta atla. |
| JUMP_SPECIFIC_SLIDE | Belirli slayta atla, [`IHyperlink.target_slide`](/slides/python-net/tr/aspose.slides/ihyperlink/target_slide) özelliğiyle belirtilen. |
| START_CUSTOM_SLIDE_SHOW | Özel slayt gösterisini başlat. |
| OPEN_FILE | Referans verilen dosyayı aç. |
| OPEN_PRESENTATION | Referans verilen sunumu aç. |
| START_STOP_MEDIA | Medya dosyasını oynatmayı başlat/durdur. |
| START_MACRO | Makro betiğini çalıştırmaya başla. |
| START_PROGRAM | Programı başlat. |
