## portion_format özelliği
Returns formatting object which contains explicitly set formatting properties of the text portion with no inheritance applied.
            Yalnızca okunabilir [`IPortionFormat`](/slides/python-net/tr/aspose.slides/iportionformat).


### Açıklamalar

Biçimlendirme nesnesi yalnızca geçerli bölüme tanımlanan biçimlendirme parametrelerini içerir, kalıtılan veriler uygulanmaz.
