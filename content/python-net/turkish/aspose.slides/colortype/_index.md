## ColorType enumeration

Farklı renk modlarını temsil eder.

ColorType türü aşağıdaki üyelere sahiptir:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| NOT_DEFINED | Renk hiç tanımlanmamış. |
| RGB | Standart 24bit RGB renk. |
| RGB_PERCENTAGE | Yüksek tanımlı RGB renk. |
| HSL | Yüksek tanımlı HSL renk. |
| SCHEME | Şema rengi. |
| SYSTEM | Sistem rengi. |
| PRESET | Ön ayar Renk. |
