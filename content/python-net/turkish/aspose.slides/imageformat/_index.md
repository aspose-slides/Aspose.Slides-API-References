## ImageFormat enumerasyonu

Görüntünün dosya formatını temsil eder.

ImageFormat türü aşağıdaki üyeleri sunar:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| MEMORY_BMP | Bellekteki bir bitmap formatını temsil eder. |
| BMP | Bitmap (BMP) görüntü formatını temsil eder. |
| EMF | Gelişmiş metafile (EMF) görüntü formatını temsil eder. |
| WMF | Windows metafile (WMF) görüntü formatını temsil eder. |
| GIF | Graphics Interchange Format (GIF) görüntü formatını temsil eder. |
| JPEG | Joint Photographic Experts Group (JPEG) görüntü formatını temsil eder. |
| PNG | W3C Portable Network Graphics (PNG) görüntü formatını temsil eder. |
| TIFF | Tagged Image File Format (TIFF) görüntü formatını temsil eder. |
| EXIF | Exchangeable Image File (Exif) formatını temsil eder. |
| ICON | Windows simge görüntü formatını temsil eder. |
