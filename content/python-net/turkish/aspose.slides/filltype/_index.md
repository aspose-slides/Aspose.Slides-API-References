## FillType enum

Çeşitli görsel nesnelerin iç dolgu tipini belirtir.

FillType türü aşağıdaki üyeleri sunar:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| NOT_DEFINED | Dolgu tipi tanımlanmamıştır. |
| NO_FILL | Dolgu uygulanmaz. |
| SOLID | Katı bir renkle doldurulur. |
| GRADIENT | Dolgu gradyan tipindedir. |
| PATTERN | Nesneyi doldurmak için yinelenen desen kullanılır. |
| PICTURE | Nesneyi doldurmak için tek bir resim kullanılır. |
| GROUP | Görsel nesne, doldurma özelliklerini gruptan devralır. |
