## IEffectFormatEffectiveData sınıfı

Etkili efekt biçimlendirme özelliklerini içeren değiştirilemez nesne.

IEffectFormatEffectiveData türü aşağıdaki üyeleri ortaya çıkar.

## Özellikler

| Özellik | Açıklama |
| :- | :- |
| [`is_no_effects`](/slides/python-net/tr/aspose.slides/ieffectformateffectivedata/is_no_effects/) | Tüm efektler devre dışı bırakılmışsa (az önce oluşturulmuş, varsayılan EffectFormat nesnesi gibi) true döndürür.<br/>            Yalnızca okunabilir **bool**. |
| [`blur_effect`](/slides/python-net/tr/aspose.slides/ieffectformateffectivedata/blur_effect/) | Bulanıklaştırma efekti.<br/>            Yalnızca okunabilir [`IBlurEffectiveData`](/slides/python-net/tr/aspose.slides.effects/iblureffectivedata). |
| [`fill_overlay_effect`](/slides/python-net/tr/aspose.slides/ieffectformateffectivedata/fill_overlay_effect/) | Dolgu bindirme efekti.<br/>            Yalnızca okunabilir [`IFillOverlayEffectiveData`](/slides/python-net/tr/aspose.slides.effects/ifilloverlayeffectivedata). |
| [`glow_effect`](/slides/python-net/tr/aspose.slides/ieffectformateffectivedata/glow_effect/) | Parıltı efekti.<br/>            Yalnızca okunabilir [`IGlowEffectiveData`](/slides/python-net/tr/aspose.slides.effects/igloweffectivedata). |
| [`inner_shadow_effect`](/slides/python-net/tr/aspose.slides/ieffectformateffectivedata/inner_shadow_effect/) | İç gölge.<br/>            Yalnızca okunabilir [`IInnerShadowEffectiveData`](/slides/python-net/tr/aspose.slides.effects/iinnershadoweffectivedata). |
| [`outer_shadow_effect`](/slides/python-net/tr/aspose.slides/ieffectformateffectivedata/outer_shadow_effect/) | Dış gölge.<br/>            Yalnızca okunabilir [`IOuterShadowEffectiveData`](/slides/python-net/tr/aspose.slides.effects/ioutershadoweffectivedata). |
| [`preset_shadow_effect`](/slides/python-net/tr/aspose.slides/ieffectformateffectivedata/preset_shadow_effect/) | Ön ayarlı gölge.<br/>            Yalnızca okunabilir [`IPresetShadowEffectiveData`](/slides/python-net/tr/aspose.slides.effects/ipresetshadoweffectivedata). |
| [`reflection_effect`](/slides/python-net/tr/aspose.slides/ieffectformateffectivedata/reflection_effect/) | Yansıma.<br/>            Yalnızca okunabilir [`IReflectionEffectiveData`](/slides/python-net/tr/aspose.slides.effects/ireflectioneffectivedata). |
| [`soft_edge_effect`](/slides/python-net/tr/aspose.slides/ieffectformateffectivedata/soft_edge_effect/) | Yumuşak kenar.<br/>            Yalnızca okunabilir [`ISoftEdgeEffectiveData`](/slides/python-net/tr/aspose.slides.effects/isoftedgeeffectivedata). |
