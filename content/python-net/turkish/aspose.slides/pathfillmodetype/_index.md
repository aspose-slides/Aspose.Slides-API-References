## PathFillModeType enum

Bir yolun nasıl doldurulması gerektiğini belirtir

PathFillModeType türü aşağıdaki üyelere sahiptir:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| NONE | No Path Fill<br/>            Bu, ilgili yolun doldurulmayacağını belirtir. |
| NORMAL | Normal Path Fill<br/>            Bu, ilgili yolun normal gölgeli bir renkle doldurulacağını belirtir. |
| LIGHTEN | Lighten Path Fill<br/>            Bu, ilgili yolun hafif gölgeli bir renkle doldurulacağını belirtir. |
| LIGHTEN_LESS | Lighten Path Fill Less<br/>            Bu, ilgili yolun biraz daha açık gölgeli bir renkle doldurulacağını belirtir. |
| DARKEN | Darken Path Fill<br/>            Bu, ilgili yolun daha koyu gölgeli bir renkle doldurulacağını belirtir. |
| DARKEN_LESS | Darken Path Fill Less<br/>            Bu, ilgili yolun biraz daha koyu gölgeli bir renkle doldurulacağını belirtir. |
