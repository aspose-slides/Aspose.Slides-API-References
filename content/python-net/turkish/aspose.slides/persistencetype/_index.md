## PersistenceType sayımı

ActiveX denetiminin özelliklerini depolamak için kullanılan yöntemi belirtir.

PersistenceType türü aşağıdaki üyeleri ortaya koyar:

## Fields

| Alan | Açıklama |
| :- | :- |
| NOT_DEFINED | Persistans kimliği belirtilmemiş. |
| PERSIST_PROPERTY_BAG | ActiveX denetiminin property-bag tabanlı kalıcılık kullanılarak kalıcılaştırıldığını belirtir. <br/>             Property-bag tabanlı kalıcılık, bir isim ve değer çifti koleksiyonu aracılığıyla ActiveX denetimini, denetim tarafından kalıcılaştırılan verileri belirten şekilde depolar. |
| PERSIST_STREAM | ActiveX denetiminin stream tabanlı kalıcılık kullanılarak kalıcılaştırıldığını belirtir <br/>             bu kalıcılık, ActiveX denetiminin varsayılan duruma başlatılmasını desteklemez. |
| PERSIST_STREAM_INIT | ActiveX denetiminin stream tabanlı kalıcılık kullanılarak kalıcılaştırıldığını belirtir <br/>             bu kalıcılık, ActiveX denetiminin varsayılan duruma başlatılmasını destekler. |
| PERSIST_STORAGE | ActiveX denetiminin storage tabanlı kalıcılık kullanılarak kalıcılaştırıldığını belirtir. |
