## IEffectFormat sınıfı

Şeklin efekt özelliklerini temsil eder.

IEffectFormat türü aşağıdaki üyeleri sunar:

## Özellikler

| Özellik | Açıklama |
| :- | :- |
| [`is_no_effects`](/slides/python-net/tr/aspose.slides/ieffectformat/is_no_effects/) | Tüm efektler devre dışı bırakılmışsa (yeni oluşturulmuş, varsayılan EffectFormat nesnesi gibi) true döndürür.<br/>            Salt okunur **bool**. |
| [`blur_effect`](/slides/python-net/tr/aspose.slides/ieffectformat/blur_effect/) | Bulanıklaştırma efekti.<br/>            Okunur/yazılabilir [`IBlur`](/slides/python-net/tr/aspose.slides.effects/iblur). |
| [`fill_overlay_effect`](/slides/python-net/tr/aspose.slides/ieffectformat/fill_overlay_effect/) | Doldurma bindirme efekti.<br/>            Okunur/yazılabilir [`IFillOverlay`](/slides/python-net/tr/aspose.slides.effects/ifilloverlay). |
| [`glow_effect`](/slides/python-net/tr/aspose.slides/ieffectformat/glow_effect/) | Parlama efekti.<br/>            Okunur/yazılabilir [`IGlow`](/slides/python-net/tr/aspose.slides.effects/iglow). |
| [`inner_shadow_effect`](/slides/python-net/tr/aspose.slides/ieffectformat/inner_shadow_effect/) | İç gölge.<br/>            Okunur/yazılabilir [`IInnerShadow`](/slides/python-net/tr/aspose.slides.effects/iinnershadow). |
| [`outer_shadow_effect`](/slides/python-net/tr/aspose.slides/ieffectformat/outer_shadow_effect/) | Dış gölge.<br/>            Okunur/yazılabilir [`IOuterShadow`](/slides/python-net/tr/aspose.slides.effects/ioutershadow). |
| [`preset_shadow_effect`](/slides/python-net/tr/aspose.slides/ieffectformat/preset_shadow_effect/) | Ön tanımlı gölge.<br/>            Okunur/yazılabilir [`IPresetShadow`](/slides/python-net/tr/aspose.slides.effects/ipresetshadow). |
| [`reflection_effect`](/slides/python-net/tr/aspose.slides/ieffectformat/reflection_effect/) | Yansıma.<br/>            Okunur/yazılabilir [`IReflection`](/slides/python-net/tr/aspose.slides.effects/ireflection). |
| [`soft_edge_effect`](/slides/python-net/tr/aspose.slides/ieffectformat/soft_edge_effect/) | Yumuşak kenar.<br/>            Okunur/yazılabilir [`ISoftEdge`](/slides/python-net/tr/aspose.slides.effects/isoftedge). |
