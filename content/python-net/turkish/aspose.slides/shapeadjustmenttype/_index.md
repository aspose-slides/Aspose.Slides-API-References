## ShapeAdjustmentType sayımı

Şekil ayar değerlerinin farklı türlerini belirtir.

ShapeAdjustmentType türü aşağıdaki üyeleri gösterir:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| CUSTOM | Özel tür (bilinmeyen ayar) |
| CORNER_SIZE | Köşelerin boyutunu kontrol eder. |
| LEFT_UP_CORNER | Sol üst köşeyi kontrol eder. |
| RIGHT_UP_CORNER | Sağ üst köşeyi kontrol eder. |
| UP_CORNERS | Üst köşeleri kontrol eder. |
| DOWN_CORNERS | Alt köşeleri kontrol eder. |
| THICKNESS | Şeklin kalınlığını kontrol eder. |
| ARROW_TAIL_THICKNESS | Ok kuyruğunun kalınlığını kontrol eder. |
| ARROWHEAD_LENGTH | Ok başının uzunluğunu kontrol eder. |
| ARROWHEAD_WIDTH | Ok başının genişliğini kontrol eder. |
| RADIUS | Şeklin veya parçasının yarıçapının boyutunu kontrol eder. |
| DEPTH | Dişli dişlerinin veya eğim etkisinin derinliğini kontrol eder. |
| SHAPE_PART_OFFSET | Şeklin bir parçasının diğerine göre ofsetini kontrol eder. |
| ANGLE | Şeklin veya parçasının açısını kontrol eder. |
| START_ANGLE | Pasta ve yay şekilleri için başlangıç açısı. |
| END_ANGLE | Pasta ve yay şekilleri için bitiş açısı. |
| START_POINT_X | Çağrı kutusunun başlangıç noktası X konumunu kontrol eder. |
| START_POINT_Y | Çağrı kutusunun başlangıç noktası Y konumunu kontrol eder. |
| CONNECTOR_POINT_1X | Çağrı kutusunun açı ayar noktasının yatay konumunu kontrol eder. |
| CONNECTOR_POINT_1Y | Çağrı kutusunun açı ayar noktasının dikey konumunu kontrol eder. |
| CONNECTOR_POINT_2X | Çağrı kutusunun açı ayar noktasının yatay konumunu kontrol eder. |
| CONNECTOR_POINT_2Y | Çağrı kutusunun açı ayar noktasının dikey konumunu kontrol eder. |
| CONNECTOR_BEND_POSITION_X | Bağlayıcıdaki kıvrımın yatay konumunu kontrol eder. |
| CONNECTOR_BEND_POSITION_Y | Bağlayıcıdaki kıvrımın dikey konumunu kontrol eder. |
| ATTACH_Y | Şeklin dikey bağlantı noktasını kontrol eder. |
| ATTACH_X | Şeklin yatay bağlantı noktasını kontrol eder. |
| CALLOUT_HEIGHT | Çağrı kutusunun dikey boyutunu kontrol eder. |
| CALLOUT_WIDTH | Çağrı kutusunun yatay boyutunu kontrol eder. |
| CALLOUT_SIZE | Çağrı kutusunun boyutunu kontrol eder. |
| CURVATURE | Bükülmüş, parantez, eğimli ok veya şeklin eğriliği. |
| HORIZONTAL_THICKNESS | Köşe şeklinin yatay kalınlığını kontrol eder. |
| VERTICAL_THICKNESS | Köşe şeklinin dikey kalınlığını kontrol eder. |
| VERTICAL_SIZE | Şeklin dikey boyutunu kontrol eder. |
| HORIZONTAL_SIZE | Şeklin yatay boyutunu kontrol eder. |
| TOP | Bir şeklin üst tarafını kontrol eder. |
