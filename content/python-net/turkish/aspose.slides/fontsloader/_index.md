## FontsLoader class

Kullanıcı tarafından tanımlanan özel yazı tiplerini yüklemek için sınıf.
                Herhangi bir sunum nesnesi oluşturulmadan önce kullanılmalıdır.

FontsLoader türü aşağıdaki üyeleri ortaya çıkarır:

## Yöntemler

| Yöntem | Açıklama |
| :- | :- |
| [`load_external_fonts(directories)`](/slides/python-net/tr/aspose.slides/fontsloader/load_external_fonts/#liststr) | Yazı tiplerini aramak için ek klasörler ekler. |
| [`load_external_font(data)`](/slides/python-net/tr/aspose.slides/fontsloader/load_external_font/#bytes) | İkili veriden yazı tipi ekler |
| [`get_font_folders()`](/slides/python-net/tr/aspose.slides/fontsloader/get_font_folders/#) | Yazı tipi klasörlerini alır. LoadExternalFonts yöntemiyle eklenmiş klasörlerin yanı sıra sistem yazı tipi klasörlerini döndürür |
| [`clear_cache()`](/slides/python-net/tr/aspose.slides/fontsloader/clear_cache/#) | Kullanıcı tarafından tanımlanan tüm özel yazı tiplerini serbest bırakır |
