## SlideShowSettings sınıf

Sunumun slayt gösterisi ayarlarını temsil eder.

SlideShowSettings türü aşağıdaki üyeleri sunar:

## Özellikler

| Özellik | Açıklama |
| :- | :- |
| [`slide_show_type`](/slides/python-net/tr/aspose.slides/slideshowsettings/slide_show_type/) | Slayt gösterisi türünü alır veya ayarlar. Aşağıdaki [`SlideShowSettings.slide_show_type`](/slides/python-net/tr/aspose.slides/slideshowsettings/slide_show_type) ataları tarafından temsil edilir: [`BrowsedAtKiosk`](/slides/python-net/tr/aspose.slides/browsedatkiosk), [`PresentedBySpeaker`](/slides/python-net/tr/aspose.slides/presentedbyspeaker) ve [`BrowsedByIndividual`](/slides/python-net/tr/aspose.slides/browsedbyindividual) |
| [`loop`](/slides/python-net/tr/aspose.slides/slideshowsettings/loop/) | Slayt Gösterisini Döngüle |
| [`show_narration`](/slides/python-net/tr/aspose.slides/slideshowsettings/show_narration/) | Slayt Gösterisinde Anlatımı Göster |
| [`show_animation`](/slides/python-net/tr/aspose.slides/slideshowsettings/show_animation/) | Slayt Gösterisinde Animasyonu Göster |
| [`pen_color`](/slides/python-net/tr/aspose.slides/slideshowsettings/pen_color/) | Slayt Gösterisi için Kalem Rengi |
| [`slides`](/slides/python-net/tr/aspose.slides/slideshowsettings/slides/) | Slayt aralığı |
| [`use_timings`](/tr/slides/python-net/aspose.slides/slideshowsettings/use_timings/) | Slayt Gösterisinde Zamanlamaları Kullan |
| [`show_media_controls`](/slides/python-net/tr/aspose.slides/slideshowsettings/show_media_controls/) | Medya Kontrollerini Göster |
