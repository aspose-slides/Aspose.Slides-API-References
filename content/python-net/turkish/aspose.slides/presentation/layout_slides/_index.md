## layout_slides özelliği
Returns a list of all layout slides that are defined in the presentation.
            Yalnızca okunabilir [`IGlobalLayoutSlideCollection`](/slides/python-net/tr/aspose.slides/igloballayoutslidecollection).


### Açıklamalar

You can access to alternative API for adding/inserting/removing/cloning layout slides 
            by using IMasterSlide.LayoutSlides özelliği.
