## NumberedBulletStyle enum

Numaralı madde işaretlerinin stilini temsil eder.

NumberedBulletStyle türü aşağıdaki üyeleri sunar:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| NOT_DEFINED | Tanımlanmamış. |
| BULLET_ALPHA_LC_PERIOD | Noktalı küçük harf alfabetik karakterler. Sample: a., b., c., ... |
| BULLET_ALPHA_UC_PERIOD | Noktalı büyük harf alfabetik karakterler. Sample: A., B., C., ... |
| BULLET_ARABIC_PAREN_RIGHT | Kapanış parantezli Arap rakamları. Sample: 1), 2), 3), ... |
| BULLET_ARABIC_PERIOD | Noktalı Arap rakamları. Sample: 1., 2., 3., ... |
| BULLET_ROMAN_LC_PAREN_BOTH | Her iki parantezli küçük harf Roma rakamları. Sample: (i), (ii), (iii), ... |
| BULLET_ROMAN_LC_PAREN_RIGHT | Kapanış parantezli küçük harf Roma rakamları. Sample: i), ii), iii), ... |
| BULLET_ROMAN_LC_PERIOD | Noktalı küçük harf Roma rakamları. Sample: i., ii., iii., ... |
| BULLET_ROMAN_UC_PERIOD | Noktalı büyük harf Roma rakamları. Sample: I., II., III., ... |
| BULLET_ALPHA_LC_PAREN_BOTH | Her iki parantezli küçük harf alfabetik karakterler. Sample: (a), (b), (c), ... |
| BULLET_ALPHA_LC_PAREN_RIGHT | Kapanış parantezli küçük harf alfabetik karakterler. Sample: a), b), c), ... |
| BULLET_ALPHA_UC_PAREN_BOTH | Her iki parantezli büyük harf alfabetik karakterler. Sample: (A), (B), (C), ... |
| BULLET_ALPHA_UC_PAREN_RIGHT | Kapanış parantezli büyük harf alfabetik karakterler. Sample: A), B), C), ... |
| BULLET_ARABIC_PAREN_BOTH | Her iki parantezli Arap rakamları. Sample: (1), (2), (3), ... |
| BULLET_ARABIC_PLAIN | Arap rakamları. Sample: 1, 2, 3, ... |
| BULLET_ROMAN_UC_PAREN_BOTH | Her iki parantezli büyük harf Roma rakamları. Sample: (I), (II), (III), ... |
| BULLET_ROMAN_UC_PAREN_RIGHT | Kapanış parantezli büyük harf Roma rakamları. Sample: I), II), III), ... |
| BULLET_SIMP_CHIN_PLAIN | Noktasız Basitleştirilmiş Çince. |
| BULLET_SIMP_CHIN_PERIOD | Noktalı Basitleştirilmiş Çince. |
| BULLET_CIRCLE_NUM_DB_PLAIN | 10'a kadar değerler için çift bayt çevrelenmiş sayı, 11'den itibaren Arap rakamları. |
| BULLET_CIRCLE_NUM_WD_WHITE_PLAIN | Metin rengiyle aynı renkte daire içinde çizilen renkli sayı (Wingdings beyaz daire numaraları). 11'den itibaren Arap rakamları. |
| BULLET_CIRCLE_NUM_WD_BLACK_PLAIN | Normal metin rengiyle dairesel arka planlı gölge renkli sayı (Wingdings siyah daire numaraları). |
| BULLET_TRAD_CHIN_PLAIN | Noktasız Geleneksel Çince. |
| BULLET_TRAD_CHIN_PERIOD | Noktalı Geleneksel Çince. |
| BULLET_ARABIC_ALPHA_DASH | Tireli Arapça alfabetik karakterler. |
| BULLET_ARABIC_ABJAD_DASH | Tireli Arapça Abjad alfabeleri. |
| BULLET_HEBREW_ALPHA_DASH | Tireli İbranice alfabetik karakterler. |
| BULLET_KANJI_KOREAN_PLAIN | Noktasız Japon/Kore sayıları. |
| BULLET_KANJI_KOREAN_PERIOD | Noktalı Japon/Kore sayıları. |
| BULLET_ARABIC_DB_PLAIN | Noktasız çift bayt Arap numaralandırma şeması. |
| BULLET_ARABIC_DB_PERIOD | Çift bayt nokta ile çift bayt Arap numaralandırma şeması. |
| BULLET_THAI_ALPHA_PERIOD | Tay alfabe noktası. |
| BULLET_THAI_ALPHA_PAREN_RIGHT | Sağ parantezli Tay alfabesi. |
| BULLET_THAI_ALPHA_PAREN_BOTH | Her iki parantezli Tay alfabesi. |
| BULLET_THAI_NUM_PERIOD | Tay sayısal nokta. |
| BULLET_THAI_NUM_PAREN_RIGHT | Sağ parantezli Tay sayısal. |
| BULLET_THAI_NUM_PAREN_BOTH | Her iki parantezli Tay sayısal. |
| BULLET_HINDI_ALPHA_PERIOD | Sesli harfler için Hint alfabesi noktası. |
| BULLET_HINDI_NUM_PERIOD | Hint sayısal nokta. |
| BULLET_KANJI_SIMP_CHIN_DB_PERIOD | Kanji Basit Çince DBPeriod. |
