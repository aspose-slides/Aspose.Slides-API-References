## SensitivityLabel sınıfı

Microsoft Purview Information Protection'tan duyarlılık etiketini temsil eder.

SensitivityLabel türü aşağıdaki üyeleri ortaya çıkarır:

## Özellikler

| Özellik | Açıklama |
| :- | :- |
| [`id`](/slides/python-net/tr/aspose.slides/sensitivitylabel/id/) | Duyarlılık etiketinin kimliğini getirir veya ayarlar.<br/>            Okuma/Yazma **str**. |
| [`site_id`](/slides/python-net/tr/aspose.slides/sensitivitylabel/site_id/) | Duyarlılık etiketini tanımlayan duyarlılık etiketi politikasına karşılık gelen Azure Active Directory (Azure AD) site tanımlayıcısını getirir veya ayarlar.<br/>            Okuma/Yazma **System.Guid**. |
| [`is_enabled`](/slides/python-net/tr/aspose.slides/sensitivitylabel/is_enabled/) | Duyarlılık etiketinin etkin olup olmadığını gösterir. |
| [`is_removed`](/slides/python-net/tr/aspose.slides/sensitivitylabel/is_removed/) | Duyarlılık etiketinin kaldırılıp kaldırılmadığını gösterir. |
| [`assignment_method_type`](/slides/python-net/tr/aspose.slides/sensitivitylabel/assignment_method_type/) | Duyarlılık etiketi için atama yöntemini getirir veya ayarlar.<br/>            Okuma/Yazma [`SensitivityLabelAssignmentType`](/slides/python-net/tr/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/tr/aspose.slides/sensitivitylabel/content_mark_types/) | Bir dosyaya uygulanması gereken içerik işaretleme türlerinin listesini getirir. |
