## TextAlignment sayımı

Farklı metin hizalama stillerini temsil eder.

TextAlignment türü aşağıdaki üyeleri ortaya çıkar:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| NOT_DEFINED | Varsayılan hizalama. |
| LEFT | Sol hizalama. |
| CENTER | Orta hizalama. |
| RIGHT | Sağ hizalama. |
| JUSTIFY | İki yana hizalama. |
| JUSTIFY_LOW | Kashida düşük hizalama. |
| DISTRIBUTED | Dağıtılmış hizalama. |
