## MathRowSpacingRule enumerasyon

Bir matris ya da dizi içinde sütunlar arasındaki dikey boşluk tipidir

MathRowSpacingRule tipi aşağıdaki üyeleri sunar:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| SINGLE_LINE_GAP | tek satır boşluğu |
| ONE_AND_A_HALF_LINE_GAP | bir buçuk satır boşluğu |
| TWO_LINE_GAP | iki satır boşluğu |
| EXACTLY | Tam olarak (RowSpacing özelliğinin değerine dayanır, puan cinsinden ölçülür) |
| MULTIPLE | Çoklu (RowSpacing özelliğinin değerine dayanır, satır cinsinden ölçülür) |
