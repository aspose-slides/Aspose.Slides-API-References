## zero_width özelliği
Gets or sets a value indicating whether the width of the base element 
            should be treated as zero.


### Açıklamalar

`true` olduğunda, hayalet temel öğesi için yatay alan ayırmaz. OMML özniteliği `m:zeroWid` ile eşleşir.
