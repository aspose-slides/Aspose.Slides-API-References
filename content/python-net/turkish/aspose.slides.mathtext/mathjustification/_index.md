## MathJustification sayım

Matematik paragrafının hizalamasını (aynı paragrafta yan yana gelen matematik metni örneklerinin serisi) belirtir.

MathJustification türü aşağıdaki üyeleri ortaya çıkarır:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| LEFT_JUSTIFIED | Matematik metnini sola hizala |
| RIGHT_JUSTIFIED | Matematik metnini sağa hizala |
| CENTERED | Matematik metnini ortaya hizala |
| CENTERED_AS_GROUP | Sayfa üzerinde tüm matematik blokları grubunu tek bir birim olarak ortala.<br/>            Bu, matematik metni örneklerinin birbirine göre hizalanabileceği anlamına gelir, <br/>            ancak tüm matematik metni grubu bütün olarak ortalanır. |
