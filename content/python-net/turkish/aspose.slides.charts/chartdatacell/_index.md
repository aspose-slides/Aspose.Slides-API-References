## ChartDataCell sınıfı

Grafik verileri için hücreyi temsil eder.

ChartDataCell türü aşağıdaki üyeleri sunar:

## Özellikler

| Özellik | Açıklama |
| :- | :- |
| [`row`](/slides/python-net/tr/aspose.slides.charts/chartdatacell/row/) | Hücrenin bulunduğu çalışma sayfasının satır indeksini döndürür.<br/>            Salt okunur **int**. |
| [`column`](/slides/python-net/tr/aspose.slides.charts/chartdatacell/column/) | Hücrenin bulunduğu çalışma sayfasının sütun indeksini döndürür.<br/>            Salt okunur **int**. |
| [`value`](/slides/python-net/tr/aspose.slides.charts/chartdatacell/value/) | Hücrenin değerini alır veya ayarlar.<br/>            Okunur/yazılabilir **any**. |
| [`formula`](/slides/python-net/tr/aspose.slides.charts/chartdatacell/formula/) | A1 stilinde formülü alır veya ayarlar. |
| [`r1c1_formula`](/slides/python-net/tr/aspose.slides.charts/chartdatacell/r1c1_formula/) | R1C1 stilinde formülü alır veya ayarlar. |
| [`chart_data_worksheet`](/slides/python-net/tr/aspose.slides.charts/chartdatacell/chart_data_worksheet/) | Çalışma sayfasını alır.<br/>            Salt okunur [`IChartDataWorksheet`](/slides/python-net/tr/aspose.slides.charts/ichartdataworksheet). |
| [`is_hidden`](/slides/python-net/tr/aspose.slides.charts/chartdatacell/is_hidden/) | Hücrenin gizli olup olmadığını belirler.<br/>            Salt okunur **bool**. |
| [`custom_number_format`](/slides/python-net/tr/aspose.slides.charts/chartdatacell/custom_number_format/) | Sayıların ve tarihlerin özel görüntü biçimini alır veya ayarlar.<br/>            Değer boş ise PresetNumberFormat değeri kullanılacak.<br/>            Okunur/yazılabilir **str**. |
| [`preset_number_format`](/slides/python-net/tr/aspose.slides.charts/chartdatacell/preset_number_format/) | Sayıların ve tarihlerin yerleşik görüntü biçimini alır veya ayarlar. Ön ayar numarası [0..22] veya [37..49] aralığında olmalıdır.<br/>             Okunur/yazılabilir **int**. |
