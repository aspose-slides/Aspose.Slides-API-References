## ChartPlotArea sınıf

Grafiğin çizilmesi gereken dikdörtgeni temsil eder.

ChartPlotArea türü aşağıdaki üyeleri sunar:

## Özellikler

| Özellik | Açıklama |
| :- | :- |
| [`format`](/slides/python-net/tr/aspose.slides.charts/chartplotarea/format/) | Bir grafik alanının biçimini döndürür.<br/>            Yalnızca okunur [`IFormat`](/slides/python-net/tr/aspose.slides.charts/iformat). |
| [`x`](/slides/python-net/tr/aspose.slides.charts/chartplotarea/x/) | Grafik alanı sınırlama kutusunun sol üst köşesinin x koordinatını, grafiğin genişliğinin bir kesri olarak (0 ile 1 arasında) döndürür veya ayarlar.<br/>            Okunur/yazılabilir **float**. |
| [`y`](/slides/python-net/tr/aspose.slides.charts/chartplotarea/y/) | Grafik alanı sınırlama kutusunun sol üst köşesinin y koordinatını, grafiğin yüksekliğinin bir kesri olarak (0 ile 1 arasında) döndürür veya ayarlar.<br/>            Okunur/yazılabilir **float**. |
| [`width`](/slides/python-net/tr/aspose.slides.charts/chartplotarea/width/) | Grafik alanı sınırlama kutusunun genişliğini, grafiğin genişliğinin bir kesri olarak (0 ile 1 arasında) döndürür veya ayarlar.<br/>            Okunur/yazılabilir **float**. |
| [`height`](/slides/python-net/tr/aspose.slides.charts/chartplotarea/height/) | Grafik alanı sınırlama kutusunun yüksekliğini, grafiğin yüksekliğinin bir kesri olarak (0 ile 1 arasında) döndürür veya ayarlar.<br/>            Okunur/yazılabilir **float**. |
| [`right`](/slides/python-net/tr/aspose.slides.charts/chartplotarea/right/) | Sağ.<br/>            Yalnızca okunur **float**. |
| [`bottom`](/slides/python-net/tr/aspose.slides.charts/chartplotarea/bottom/) | Alt.<br/>            Yalnızca okunur **float**. |
| [`chart`](/slides/python-net/tr/aspose.slides.charts/chartplotarea/chart/) | Grafik.<br/>            Yalnızca okunur [`IChart`](/slides/python-net/tr/aspose.slides.charts/ichart). |
| [`is_location_autocalculated`](/slides/python-net/tr/aspose.slides.charts/chartplotarea/is_location_autocalculated/) | Konumun nasıl hesaplanacağını tanımlar: true – otomatik olarak hesaplanır; X, Y, Width, Height özellikleriyle tanımlanır.<br/>            Yalnızca okunur **bool**. |
| [`layout_target_type`](/slides/python-net/tr/aspose.slides.charts/chartplotarea/layout_target_type/) | Grafik alanının düzeni manuel olarak tanımlandıysa bu özellik, grafik alanını iç kısmına (ekseni ve eksen etiketlerini içermeyen) <br/>             dış kısmına (ekseni ve eksen etiketlerini içeren) <br/>             yerleştirileceğini belirtir.<br/>            Okunur/yazılabilir [`ChartPlotArea.layout_target_type`](/slides/python-net/tr/aspose.slides.charts/chartplotarea/layout_target_type). |
| [`actual_x`](/slides/python-net/tr/aspose.slides.charts/chartplotarea/actual_x/) | Grafik elemanının sol üst köşesine göre gerçek x konumunu (sol) belirtir.<br/>            Gerçek değerleri almak için önce IChart.ValidateChartLayout() metodunu çağırın.<br/>            Okunur **float**. |
| [`actual_y`](/slides/python-net/tr/aspose.slides.charts/chartplotarea/actual_y/) | Grafik elemanının sol üst köşesine göre gerçek üst konumunu belirtir.<br/>            Gerçek değerleri almak için önce IChart.ValidateChartLayout() metodunu çağırın.<br/>            Okunur **float**. |
| [`actual_width`](/slides/python-net/tr/aspose.slides.charts/chartplotarea/actual_width/) | Grafik elemanının gerçek genişliğini belirtir. Gerçek değerleri almak için önce IChart.ValidateChartLayout() metodunu çağırın.<br/>            Okunur **float**. |
| [`actual_height`](/slides/python-net/tr/aspose.slides.charts/chartplotarea/actual_height/) | Grafik elemanının gerçek yüksekliğini belirtir. Gerçek değerleri almak için önce IChart.ValidateChartLayout() metodunu çağırın.<br/>            Okunur **float**. |
