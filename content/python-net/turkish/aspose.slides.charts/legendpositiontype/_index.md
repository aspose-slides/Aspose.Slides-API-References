## LegendPositionType enum

Bir grafikteki lejantın konumunu belirler.

LegendPositionType türü aşağıdaki üyeleri sağlar:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| BOTTOM | Lejantın grafiğin alt kısmına çizileceğini belirtir. |
| LEFT | Lejantın grafiğin sol tarafına çizileceğini belirtir. |
| RIGHT | Lejantın grafiğin sağ tarafına çizileceğini belirtir. |
| TOP | Lejantın grafiğin üst kısmına çizileceğini belirtir. |
| TOP_RIGHT | Lejantın grafiğin sağ üst köşesine çizileceğini belirtir. |
