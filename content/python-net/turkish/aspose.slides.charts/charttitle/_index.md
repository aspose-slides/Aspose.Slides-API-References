## ChartTitle sınıfı

Grafik başlığı özelliklerini temsil eder.

ChartTitle türü aşağıdaki üyeleri sunar:

## Özellikler

| Özellik | Açıklama |
| :- | :- |
| [`x`](/slides/python-net/tr/aspose.slides.charts/charttitle/x/) | Başlığın x koordinatını, grafiğin genişliğinin bir kesri olarak döndürür veya ayarlar.<br/>            Okuma/Yazma **float**. |
| [`y`](/slides/python-net/tr/aspose.slides.charts/charttitle/y/) | Başlığın y koordinatını, grafiğin yüksekliğinin bir kesri olarak döndürür veya ayarlar.<br/>            Okuma/Yazma **float**. |
| [`width`](/slides/python-net/tr/aspose.slides.charts/charttitle/width/) | Başlığın genişliğini, grafiğin genişliğinin bir kesri olarak döndürür veya ayarlar.<br/>            Okuma/Yazma **float**. |
| [`height`](/slides/python-net/tr/aspose.slides.charts/charttitle/height/) | Başlığın yüksekliğini, grafiğin yüksekliğinin bir kesri olarak döndürür veya ayarlar.<br/>            Okuma/Yazma **float**. |
| [`right`](/slides/python-net/tr/aspose.slides.charts/charttitle/right/) | Sağ.<br/>            Yalnızca okuma **float**. |
| [`bottom`](/slides/python-net/tr/aspose.slides.charts/charttitle/bottom/) | Alt.<br/>            Yalnızca okuma **float**. |
| [`overlay`](/slides/python-net/tr/aspose.slides.charts/charttitle/overlay/) | Diğer grafik öğelerinin başlığın üzerine çakışmasına izin verilip verilmeyeceğini belirler.<br/>            Okuma/Yazma **bool**. |
| [`format`](/slides/python-net/tr/aspose.slides.charts/charttitle/format/) | Bir başlığın dolgu, çizgi, efekt stillerini döndürür.<br/>            Yalnızca okuma [`IFormat`](/slides/python-net/tr/aspose.slides.charts/iformat). |
| [`text_frame_for_overriding`](/slides/python-net/tr/aspose.slides.charts/charttitle/text_frame_for_overriding/) | Zengin biçimlendirilmiş metin içerebilir. Bu özellik None değilse, bu <br/>            biçimlendirilmiş metin değeri otomatik oluşturulan metni geçersiz kılar.<br/>            Otomatik oluşturulan metin, veri etiketi, değer ekseninin birim etiketi, eksen başlığı, grafik başlığı, trend çizgisi etiketi gibi öğelerin örtük bir özelliğidir.<br/>            Otomatik oluşturulan metin, IFormattedTextContainer.TextFormat özelliği ile biçimlendirilir.<br/>            Yalnızca okuma [`ITextFrame`](/slides/python-net/tr/aspose.slides/itextframe). |
| [`text_format`](/slides/python-net/tr/aspose.slides.charts/charttitle/text_format/) | Metin biçimini döndürür.<br/>            Yalnızca okuma [`IChartTextFormat`](/slides/python-net/tr/aspose.slides.charts/icharttextformat). |
| [`actual_x`](/slides/python-net/tr/aspose.slides.charts/charttitle/actual_x/) | Grafik öğesinin sol üst köşeye göre gerçek x konumunu (sol) belirtir.<br/>            Gerçek değerleri elde etmek için önce IChart.ValidateChartLayout() metodunu çağırın. <br/>            Okuma **float**. |
| [`actual_y`](/slides/python-net/tr/aspose.slides.charts/charttitle/actual_y/) | Grafik öğesinin sol üst köşeye göre gerçek üst konumunu belirtir.<br/>            Gerçek değerleri elde etmek için önce IChart.ValidateChartLayout() metodunu çağırın. <br/>            Okuma **float**. |
| [`actual_width`](/slides/python-net/tr/aspose.slides.charts/charttitle/actual_width/) | Grafik öğesinin gerçek genişliğini belirtir. Gerçek değerleri elde etmek için önce IChart.ValidateChartLayout() metodunu çağırın. <br/>            Okuma **float**. |
| [`actual_height`](/slides/python-net/tr/aspose.slides.charts/charttitle/actual_height/) | Grafik öğesinin gerçek yüksekliğini belirtir. Gerçek değerleri elde etmek için önce IChart.ValidateChartLayout() metodunu çağırın. <br/>            Okuma **float**. |
| [`chart`](/slides/python-net/tr/aspose.slides.charts/charttitle/chart/) | Üst grafiği döndürür.<br/>            Yalnızca okuma [`IChart`](/slides/python-net/tr/aspose.slides.charts/ichart). |
