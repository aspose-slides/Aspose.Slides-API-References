## ParentLabelLayoutType enumerasyonu

Kategori veri etiketlerinin düzenini temsil eder. Yalnızca Treemap serileriyle kullanılır.

ParentLabelLayoutType türü aşağıdaki üyeleri ortaya çıkarır:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| BANNER | Üst kategori etiketlerinin banner olarak gösterileceğini belirtir |
| NONE | Üst kategori etiketlerinin çizilmediğini belirtir |
| OVERLAPPING | Üst kategori etiketlerinin üst üste bindirilmiş olarak gösterileceğini belirtir |
