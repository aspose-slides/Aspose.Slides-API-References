## LegendDataLabelPosition enum

Veri etiketlerinin konumunu belirler.

LegendDataLabelPosition türü aşağıdaki üyeleri gösterir:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| NOT_DEFINED | Pozisyon tanımlanmamış. |
| BOTTOM | Veri etiketlerinin veri işaretçisinin altında görüntüleneceğini belirtir. |
| BEST_FIT | Veri etiketlerinin en uygun konumda görüntüleneceğini belirtir. |
| CENTER | Veri etiketlerinin veri işaretçisinin ortasında görüntüleneceğini belirtir. |
| INSIDE_BASE | Veri etiketlerinin veri işaretçisinin tabanında görüntüleneceğini belirtir. |
| INSIDE_END | Veri etiketlerinin veri işaretçisinin ucunda görüntüleneceğini belirtir. |
| LEFT | Veri etiketlerinin veri işaretçisinin solunda görüntüleneceğini belirtir. |
| OUTSIDE_END | Veri etiketlerinin veri işaretçisinin ucunun dışında görüntüleneceğini belirtir. |
| RIGHT | Veri etiketlerinin veri işaretçisinin sağında görüntüleneceğini belirtir. |
| TOP | Veri etiketlerinin veri işaretçisinin üzerinde görüntüleneceğini belirtir. |
