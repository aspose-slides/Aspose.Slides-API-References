## value_type özelliği
Represents possible ways to determine the length of the error bars. 
            Özel değer tipi durumunda değeri belirtmek için serinin DataPoints koleksiyonundaki belirli veri noktasının [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/tr/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) özelliğini kullanın.
            Fixed, Percentage veya StandardDeviation değer tipi durumunda değeri belirtmek için Value özelliğini kullanın.  
            Okuma/yazma [`ErrorBarValueType`](/slides/python-net/tr/aspose.slides.charts/errorbarvaluetype).
