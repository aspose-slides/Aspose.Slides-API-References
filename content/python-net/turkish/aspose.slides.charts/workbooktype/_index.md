## WorkbookType sayımı

Open XML çalışma kitabı dosyasının türünü belirtir.

WorkbookType türü aşağıdaki üyeleri sunar:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| NOT_DEFINED | Çalışma kitabı türü tanımlanmamış. |
| WORKBOOK | Excel çalışma kitabı (*.xlsx). |
| WORKBOOK_MACRO | Excel makro etkin çalışma kitabı (*.xlsm). |
| TEMPLATE | Excel şablonu (*.xltx). |
| TEMPLATE_MACRO | Excel makro etkin şablon (*.xltm). |
| WORKBOOK_BINARY_MACRO | Excel ikili makro etkin çalışma kitabı (*.xlsb). |
