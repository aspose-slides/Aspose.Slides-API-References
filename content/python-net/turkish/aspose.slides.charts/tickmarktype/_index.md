## TickMarkType enum

Belirtilen eksen için işaret çizgisi tipini temsil eder.

TickMarkType tipi aşağıdaki üyeleri sunar:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| CROSS | İşaret çizgilerinin ekseni kesmesi gerektiğini belirtir. |
| INSIDE | İşaret çizgilerinin çizim alanının içinde olması gerektiğini belirtir. |
| NONE | İşaret çizgilerinin olmayacağını belirtir. |
| OUTSIDE | İşaret çizgilerinin çizim alanının dışında olması gerektiğini belirtir. |
