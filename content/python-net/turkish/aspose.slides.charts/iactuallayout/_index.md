## IActualLayout sınıfı

Bir grafik öğesinin gerçek konumunu belirtir.

IActualLayout tipi aşağıdaki üyeleri ortaya çıkarır:

## Özellikler

| Özellik | Açıklama |
| :- | :- |
| [`actual_x`](/slides/python-net/tr/aspose.slides.charts/iactuallayout/actual_x/) | Grafik öğesinin sol üst köşeye göre gerçek x konumunu (sol) belirtir.<br/>            Gerçek değerleri almak için önce IChart.ValidateChartLayout() yöntemini çağırın. <br/>            Okunur **float**. |
| [`actual_y`](/slides/python-net/tr/aspose.slides.charts/iactuallayout/actual_y/) | Grafik öğesinin sol üst köşeye göre gerçek üst konumunu belirtir.<br/>            Gerçek değerleri almak için önce IChart.ValidateChartLayout() yöntemini çağırın. <br/>            Okunur **float**. |
| [`actual_width`](/slides/python-net/tr/aspose.slides.charts/iactuallayout/actual_width/) | Grafik öğesinin gerçek genişliğini belirtir. Gerçek değerleri almak için önce IChart.ValidateChartLayout() yöntemini çağırın. <br/>            Okunur **float**. |
| [`actual_height`](/slides/python-net/tr/aspose.slides.charts/iactuallayout/actual_height/) | Grafik öğesinin gerçek yüksekliğini belirtir. Gerçek değerleri almak için önce IChart.ValidateChartLayout() yöntemini çağırın. <br/>            Okunur **float**. |
