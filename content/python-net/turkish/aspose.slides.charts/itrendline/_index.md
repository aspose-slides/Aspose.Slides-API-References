## ITrendline sınıfı

Sınıf, grafik serisinin trend çizgisini temsil eder.

ITrendline türü aşağıdaki üyelere erişim sağlar:

## Özellikler

| Özellik | Açıklama |
| :- | :- |
| [`trendline_name`](/slides/python-net/tr/aspose.slides.charts/itrendline/trendline_name/) | Trend çizgisinin adını alır veya ayarlar.<br/>            Okuma/Yazma **str**. |
| [`trendline_type`](/slides/python-net/tr/aspose.slides.charts/itrendline/trendline_type/) | Trend çizgisinin tipini alır veya ayarlar.<br/>            Okuma/Yazma [`ITrendline.trendline_type`](/slides/python-net/tr/aspose.slides.charts/itrendline/trendline_type). |
| [`format`](/slides/python-net/tr/aspose.slides.charts/itrendline/format/) | Trend çizgisinin biçimini temsil eder.<br/>            Okuma/Yazma [`IFormat`](/slides/python-net/tr/aspose.slides.charts/iformat). |
| [`backward`](/slides/python-net/tr/aspose.slides.charts/itrendline/backward/) | Trend çizgisinin, eğilim yapılan serinin verilerinden önce uzadığı kategori (veya dağılım grafiğinde birimler) sayısını belirtir.<br/>            Dağılım ve dağılım olmayan grafiklerde değer negatif olmayan herhangi bir değer olmalıdır.<br/>            Okuma/Yazma **float**. |
| [`forward`](/slides/python-net/tr/aspose.slides.charts/itrendline/forward/) | Trend çizgisinin, eğilim yapılan serinin verilerinden sonra uzadığı kategori (veya dağılım grafiğinde birimler) sayısını belirtir.<br/>            Dağılım ve dağılım olmayan grafiklerde değer negatif olmayan herhangi bir değer olmalıdır.<br/>            Okuma/Yazma **float**. |
| [`intercept`](/slides/python-net/tr/aspose.slides.charts/itrendline/intercept/) | Trend çizgisinin y eksenini kestiği değeri belirtir. Bu özellik yalnızca trend çizgisi türü exp, linear veya poly olduğunda desteklenir.<br/>            Okuma/Yazma **float**. |
| [`display_equation`](/slides/python-net/tr/aspose.slides.charts/itrendline/display_equation/) | Trend çizgisinin denkleminin grafikte (R-squared değeri ile aynı etiket içinde) görüntüleneceğini belirtir.<br/>            Okuma/Yazma **bool**. |
| [`order`](/slides/python-net/tr/aspose.slides.charts/itrendline/order/) | Polinomsal trend çizgisinin derecesini belirtir. Diğer trend çizgi türleri için yok sayılır. Değer 2 ile 6 arasında olmalıdır.<br/>            Okuma/Yazma **int**. |
| [`period`](/slides/python-net/tr/aspose.slides.charts/itrendline/period/) | Hareketli ortalama trend çizgisi için trend çizgisinin periyodunu belirtir. Diğer trend çizgi varyantları için yok sayılır. Değer 2 ile 255 arasında olmalıdır.<br/>            Okuma/Yazma **int**. |
| [`display_r_squared_value`](/slides/python-net/tr/aspose.slides.charts/itrendline/display_r_squared_value/) | Trend çizgisinin R-kare değerinin grafikte (denklemin aynı etiketi içinde) görüntüleneceğini belirtir.<br/>            Okuma/Yazma **bool**. |
| [`related_legend_entry`](/slides/python-net/tr/aspose.slides.charts/itrendline/related_legend_entry/) | Bu trend çizgisiyle ilişkili lejand girişini temsil eder<br/>            Sadece okuma [`ILegendEntryProperties`](/slides/python-net/tr/aspose.slides.charts/ilegendentryproperties). |
| [`text_frame_for_overriding`](/slides/python-net/tr/aspose.slides.charts/itrendline/text_frame_for_overriding/) |  |
| [`text_format`](/slides/python-net/tr/aspose.slides.charts/itrendline/text_format/) |  |
| [`chart`](/slides/python-net/tr/aspose.slides.charts/itrendline/chart/) |  |
