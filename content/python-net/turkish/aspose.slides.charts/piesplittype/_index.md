## PieSplitType enumerasyonu

İkinci pasta veya çubuk üzerindeki bölme noktalarının bir türünü temsil eder, bir pasta-pasta veya çubuk-pasta grafiğinde.

PieSplitType tipi aşağıdaki üyeleri sunar:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| DEFAULT | Veri noktalarının bu grafik türü için varsayılan <br/>            mekanizma kullanılarak bölüneceğini belirtir. |
| CUSTOM | Veri noktalarının pasta ile <br/>            ikinci grafik arasında, Özel Bölme değerlerine göre bölüneceğini belirtir. |
| BY_PERCENTAGE | Veri noktalarının pasta ile <br/>            ikinci grafik arasında, yüzde değeri Split Position yüzdesinden düşük olan noktalar <br/>            ikinci grafiğe yerleştirilerek bölüneceğini belirtir. |
| BY_POS | Veri noktalarının pasta ile <br/>            ikinci grafik arasında, veri noktalarının son Split Position'ı <br/>            ikinci grafiğe yerleştirerek bölüneceğini belirtir. |
| BY_VALUE | Veri noktalarının pasta ile <br/>            ikinci grafik arasında, değeri Split Position'dan düşük olan veri noktaları <br/>            ikinci grafiğe yerleştirilerek bölüneceğini belirtir. |
