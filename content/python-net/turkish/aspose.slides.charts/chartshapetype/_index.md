## ChartShapeType enumerasyonu

Bir grafik şekli temsil eder.

ChartShapeType türü aşağıdaki üyeleri ortaya çıkar:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| NOT_DEFINED | Grafik şekli tanımlanmamıştır. |
| BOX | Grafiğin kutu şekliyle çizileceğini belirtir. |
| CONE | Grafiğin bir koni olarak çizileceğini, koninin tabanının zeminde ve koninin ucunun veri işaretinin üst kısmında olacağını belirtir. |
| CONE_TO_MAX | Grafiğin, koninin ucunun maksimum veri değeri olacağı şekilde kesik konilerle çizileceğini belirtir. |
| CYLINDER | Grafiğin bir silindir olarak çizileceğini belirtir. |
| PYRAMID | Grafiğin dikdörtgen piramit olarak çizileceğini, piramidin tabanının zeminde ve piramidin ucunun veri işaretinin üst kısmında olacağını belirtir. |
| PYRAMID_TO_MAXIMUM | Grafiğin, koninin ucunun maksimum veri değeri olacağı şekilde kesik konilerle çizileceğini belirtir. |
