## TickLabelPositionType enumerasyonu

Belirtilen eksende tik işareti etiketlerinin konum tipini temsil eder.

TickLabelPositionType türü aşağıdaki üyeleri sunar:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| HIGH | Eksen etiketlerinin dik eksenin yüksek ucunda olacağını belirtir. |
| LOW | Eksen etiketlerinin dik eksenin düşük ucunda olacağını belirtir. |
| NEXT_TO | Eksen etiketlerinin eksene yakın olacağını belirtir. |
| NONE | Eksen etiketlerinin çizilmeyeceğini belirtir. |
