## Rotation3D sınıfı

Bir grafiğin 3B dönüşümünü temsil eder.

Rotation3D türü aşağıdaki üyeleri sunar:

## Özellikler

| Property | Description |
| :- | :- |
| [`rotation_x`](/slides/python-net/tr/aspose.slides.charts/rotation3d/rotation_x/) | X ekseni etrafındaki döndürme derecesini döndürür veya ayarlar, yani 3B grafikler için Y yönünde (-90 ile 90 derece arasında).<br/>            Özellik, ECMA-376'deki 21.2.2.157 rotX (X Rotation) öğesi ve PowerPoint 2007+’deki "Y Rotation" seçeneği ile eşleşir.<br/>            Okunur/yazılır **int**. |
| [`rotation_y`](/slides/python-net/tr/aspose.slides.charts/rotation3d/rotation_y/) | Y ekseni etrafındaki döndürme derecesini döndürür veya ayarlar, yani 3B grafikler için X yönünde (0 ile 360 derece arasında).<br/>            Özellik, ECMA-376'deki 21.2.158 rotY (Y Rotation) öğesi ve PowerPoint 2007+’deki "X Rotation" seçeneği ile eşleşir.<br/>            Okunur/yazılır **int**. |
| [`perspective`](/slides/python-net/tr/aspose.slides.charts/rotation3d/perspective/) | 3B grafikler için perspektif değeri (görüş alanı açısı) döndürür veya ayarlar (0 ile 240 arasında).<br/>            RightAngleAxes özelliği true ise yok sayılır.<br/>            Okunur/yazılır **int**. |
| [`right_angle_axes`](/slides/python-net/tr/aspose.slides.charts/rotation3d/right_angle_axes/) | Grafik eksenlerinin perspektif yerine dik açıyla olup olmadığını belirler.<br/>            Başka bir deyişle, eksen açıları grafik <br/>            döndürmesi veya eğiminden bağımsız olup olmadığını belirler.<br/>            Okunur/yazılır **bool**. |
| [`depth_percents`](/slides/python-net/tr/aspose.slides.charts/rotation3d/depth_percents/) | 3B bir grafiğin derinliğini, grafik genişliğinin yüzdesi olarak döndürür veya ayarlar (20 ile 2000 yüzde arasında).<br/>            Okunur/yazılır **int**. |
| [`height_percents`](/slides/python-net/tr/aspose.slides.charts/rotation3d/height_percents/) | 3-D bir grafiğin yüksekliğini, grafik genişliğinin yüzdesi olarak belirler (5 ile 500 yüzde arasında).<br/>            Okunur/yazılır **int**. |
