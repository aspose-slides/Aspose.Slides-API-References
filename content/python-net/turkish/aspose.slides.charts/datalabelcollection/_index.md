## DataLabelCollection sınıfı

Bir seri etiketlerini temsil eder.

DataLabelCollection tipi aşağıdaki üyeleri sunar:

## Özellikler

| Özellik | Açıklama |
| :- | :- |
| [`chart`](/slides/python-net/tr/aspose.slides.charts/datalabelcollection/chart/) | Üst grafiği döndürür.<br/>            Salt okunur [`IChart`](/slides/python-net/tr/aspose.slides.charts/ichart). |
| [`is_visible`](/slides/python-net/tr/aspose.slides.charts/datalabelcollection/is_visible/) | False, veri etiketinin varsayılan olarak görünür olmadığını ifade eder (ve bu nedenle DefaultDataLabelFormat özelliğinin tüm Show*-bayrakları (ShowValue, ...) false olur).<br/>            Salt okunur **bool**. |
| [`count_of_visible_data_labels`](/slides/python-net/tr/aspose.slides.charts/datalabelcollection/count_of_visible_data_labels/) | Koleksiyondaki görünür veri etiketlerinin sayısını alır.<br/>            Salt okunur **int**. |
| [`count`](/slides/python-net/tr/aspose.slides.charts/datalabelcollection/count/) | Koleksiyondaki tüm veri etiketlerinin sayısını alır.<br/>            Salt okunur **int**. |
| [`default_data_label_format`](/slides/python-net/tr/aspose.slides.charts/datalabelcollection/default_data_label_format/) | Varsayılan veri etiketi biçimini alır.<br/>            Salt okunur [`IDataLabelFormat`](/slides/python-net/tr/aspose.slides.charts/idatalabelformat). |
| [`leader_lines_format`](/slides/python-net/tr/aspose.slides.charts/datalabelcollection/leader_lines_format/) | Veri etiketleri lider çizgi biçimini temsil eder.<br/>             Salt okunur [`IChartLinesFormat`](/slides/python-net/tr/aspose.slides.charts/ichartlinesformat). |
| [`parent_series`](/slides/python-net/tr/aspose.slides.charts/datalabelcollection/parent_series/) | Üst seriyi alır.<br/>            Salt okunur [`IChartSeries`](/slides/python-net/tr/aspose.slides.charts/ichartseries). |
| [`default_label_shape_type`](/slides/python-net/tr/aspose.slides.charts/datalabelcollection/default_label_shape_type/) | Veri etiketleri için varsayılan şekil tipini alır veya ayarlar.<br/>             Şekil tanımlı değilse [`ShapeType.NOT_DEFINED`](/slides/python-net/tr/aspose.slides/shapetype/NOT_DEFINED) döndürür. |
| [`slide`](/slides/python-net/tr/aspose.slides.charts/datalabelcollection/slide/) |  |
| [`presentation`](/slides/python-net/tr/aspose.slides.charts/datalabelcollection/presentation/) |  |
