## DataLabelCollection sınıfı

Bir seri etiketlerini temsil eder.

DataLabelCollection türü aşağıdaki üyeleri sunar:

## Özellikler

| Özellik | Açıklama |
| :- | :- |
| [`chart`](/slides/python-net/tr/aspose.slides.charts/datalabelcollection/chart/) | Üst grafiği döndürür.<br/>            Yalnızca okunur [`IChart`](/slides/python-net/tr/aspose.slides.charts/ichart). |
| [`is_visible`](/slides/python-net/tr/aspose.slides.charts/datalabelcollection/is_visible/) | False, veri etiketinin varsayılan olarak görünür olmadığını (ve bu nedenle DefaultDataLabelFormat özelliğinin tüm Show*-bayraklarının (ShowValue, ...) false olduğunu) belirtir.<br/>            Yalnızca okunur **bool**. |
| [`count_of_visible_data_labels`](/slides/python-net/tr/aspose.slides.charts/datalabelcollection/count_of_visible_data_labels/) | Koleksiyondaki görünür veri etiketlerinin sayısını alır.<br/>            Yalnızca okunur **int**. |
| [`count`](/slides/python-net/tr/aspose.slides.charts/datalabelcollection/count/) | Koleksiyondaki tüm veri etiketlerinin sayısını alır.<br/>            Yalnızca okunur **int**. |
| [`default_data_label_format`](/slides/python-net/tr/aspose.slides.charts/datalabelcollection/default_data_label_format/) | Varsayılan veri etiketi biçimini alır.<br/>            Yalnızca okunur [`IDataLabelFormat`](/slides/python-net/tr/aspose.slides.charts/idatalabelformat). |
| [`leader_lines_format`](/slides/python-net/tr/aspose.slides.charts/datalabelcollection/leader_lines_format/) | Veri etiketlerinin kılavuz çizgi biçimini temsil eder.<br/>            Yalnızca okunur [`IChartLinesFormat`](/slides/python-net/tr/aspose.slides.charts/ichartlinesformat). |
| [`parent_series`](/slides/python-net/tr/aspose.slides.charts/datalabelcollection/parent_series/) | Üst seriyi alır.<br/>            Yalnızca okunur [`IChartSeries`](/slides/python-net/tr/aspose.slides.charts/ichartseries). |
| [`slide`](/slides/python-net/tr/aspose.slides.charts/datalabelcollection/slide/) |  |
| [`presentation`](/slides/python-net/tr/aspose.slides.charts/datalabelcollection/presentation/) |  |
