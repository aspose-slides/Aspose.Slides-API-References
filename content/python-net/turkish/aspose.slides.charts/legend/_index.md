## Legend sınıfı

Grafiğin lejand özelliklerini temsil eder.

Legend türü aşağıdaki üyeleri sunar:

## Özellikler

| Özellik | Açıklama |
| :- | :- |
| [`x`](/slides/python-net/tr/aspose.slides.charts/legend/x/) | Lejandın x koordinatını grafiğin genişliğinin bir kesri olarak döndürür veya ayarlar.<br/> Okunur/yazılır **float**. |
| [`y`](/slides/python-net/tr/aspose.slides.charts/legend/y/) | Lejandın y koordinatını grafiğin yüksekliğinin bir kesri olarak döndürür veya ayarlar.<br/> Okunur/yazılır **float**. |
| [`width`](/slides/python-net/tr/aspose.slides.charts/legend/width/) | Lejandın genişliğini grafiğin genişliğinin bir kesri olarak döndürür veya ayarlar.<br/> Okunur/yazılır **float**. |
| [`height`](/slides/python-net/tr/aspose.slides.charts/legend/height/) | Lejandın yüksekliğini grafiğin yüksekliğinin bir kesri olarak döndürür veya ayarlar.<br/> Okunur/yazılır **float**. |
| [`right`](/slides/python-net/tr/aspose.slides.charts/legend/right/) | Sağ.<br/> Sadece okunur **float**. |
| [`bottom`](/slides/python-net/tr/aspose.slides.charts/legend/bottom/) | Alt.<br/> Sadece okunur **float**. |
| [`overlay`](/slides/python-net/tr/aspose.slides.charts/legend/overlay/) | Diğer grafik öğelerinin lejandın üzerine çakışmasına izin verilip verilmeyeceğini belirler.<br/> Okunur/yazılır **bool**. |
| [`text_format`](/slides/python-net/tr/aspose.slides.charts/legend/text_format/) | Metin formatı.<br/> Sadece okunur [`IChartTextFormat`](/slides/python-net/tr/aspose.slides.charts/icharttextformat). |
| [`position`](/slides/python-net/tr/aspose.slides.charts/legend/position/) | Lejandın bir grafikteki konumunu belirler.<br/> X, Y, Width, Heigt özelliklerinin NaN olmayan değerleri bu özelliğin etkisini geçersiz kılar.<br/> Okunur/yazılır [`LegendPositionType`](/slides/python-net/tr/aspose.slides.charts/legendpositiontype). |
| [`format`](/slides/python-net/tr/aspose.slides.charts/legend/format/) | Lejandın formatını döndürür.<br/> Sadece okunur [`IFormat`](/slides/python-net/tr/aspose.slides.charts/iformat). |
| [`chart`](/slides/python-net/tr/aspose.slides.charts/legend/chart/) | Grafiği döndürür.<br/> Sadece okunur [`IChart`](/slides/python-net/tr/aspose.slides.charts/ichart). |
| [`entries`](/slides/python-net/tr/aspose.slides.charts/legend/entries/) | Lejand girişlerini alır.<br/> Sadece okunur [`ILegendEntryCollection`](/slides/python-net/tr/aspose.slides.charts/ilegendentrycollection). |
| [`actual_x`](/slides/python-net/tr/aspose.slides.charts/legend/actual_x/) | Grafik öğesinin sol üst köşesine göre gerçek x konumunu (sol) belirler.<br/> Gerçek değerleri almak için IChart.ValidateChartLayout() yöntemini önce çağırın.<br/> Okunur **float**. |
| [`actual_y`](/slides/python-net/tr/aspose.slides.charts/legend/actual_y/) | Grafik öğesinin sol üst köşesine göre gerçek üst konumunu belirler.<br/> Gerçek değerleri almak için IChart.ValidateChartLayout() yöntemini önce çağırın.<br/> Okunur **float**. |
| [`actual_width`](/slides/python-net/tr/aspose.slides.charts/legend/actual_width/) | Grafik öğesinin gerçek genişliğini belirler. Gerçek değerleri almak için IChart.ValidateChartLayout() yöntemini önce çağırın.<br/> Okunur **float**. |
| [`actual_height`](/slides/python-net/tr/aspose.slides.charts/legend/actual_height/) | Grafik öğesinin gerçek yüksekliğini belirler. Gerçek değerleri almak için IChart.ValidateChartLayout() yöntemini önce çağırın.<br/> Okunur **float**. |
