## IChartDataCell sınıfı

IChartDataCell türü aşağıdaki üyeleri sunar:

| Özellik | Açıklama |
| :- | :- |
| [`row`](/slides/python-net/tr/aspose.slides.charts/ichartdatacell/row/) | Hücrenin bulunduğu çalışma sayfasındaki satırın dizinini döndürür.<br/>            Yalnızca okunur **int**. |
| [`column`](/slides/python-net/tr/aspose.slides.charts/ichartdatacell/column/) | Hücrenin bulunduğu çalışma sayfasındaki sütunun dizinini döndürür.<br/>            Yalnızca okunur **int**. |
| [`value`](/slides/python-net/tr/aspose.slides.charts/ichartdatacell/value/) | Bir hücrenin değerini alır veya ayarlar.<br/>            Okunur/Yazılır **any**. |
| [`formula`](/slides/python-net/tr/aspose.slides.charts/ichartdatacell/formula/) | A1 stilindeki formülü alır veya ayarlar. |
| [`r1c1_formula`](/slides/python-net/tr/aspose.slides.charts/ichartdatacell/r1c1_formula/) | R1C1 stilindeki formülü alır veya ayarlar. |
| [`chart_data_worksheet`](/slides/python-net/tr/aspose.slides.charts/ichartdatacell/chart_data_worksheet/) | Çalışma sayfasını alır.<br/>            Yalnızca okunur [`IChartDataWorksheet`](/slides/python-net/tr/aspose.slides.charts/ichartdataworksheet). |
