## DataSourceType enum'ı

Veri kaynağı türleri.

DataSourceType türü aşağıdaki üyeleri gösterir:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| WORKSHEET | Veri noktasının XValue, YValue, Value veya BubbleSize değerini çalışma sayfasında saklamak için CellXls nesnelerini kullanın. |
| STRING_LITERALS | XValue, YValue, Value veya BubbleSize değerini <br/>            veri noktasında saklamak için hızlı erişimli string değişkeni kullanın. Worksheet, değerleri saklamak için kullanılmaz. |
| DOUBLE_LITERALS | XValue, YValue, Value veya BubbleSize değerini <br/>            veri noktasında saklamak için hızlı erişimli double değişkeni kullanın. Worksheet, değerleri saklamak için kullanılmaz. |
