## AxisAggregationType enum

Kategori ekseninin toplama türünü temsil eder. Yalnızca Histogram veya HistogramPareto serileriyle kullanılır.

AxisAggregationType türü aşağıdaki üyeleri sunar:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| BY_CATEGORY | Kategorilere göre toplar |
| AUTOMATIC | Kategorileri otomatik olarak toplar. |
| BY_BIN_WIDTH | Bin genişliğine göre kategorileri toplar. IAxis.BinWidth özelliği ayarlanmalıdır. |
| BY_NUMBER_OF_BINS | Bin sayısına göre kategorileri toplar. IAxis.NumberOfBins özelliği ayarlanmalıdır. |
