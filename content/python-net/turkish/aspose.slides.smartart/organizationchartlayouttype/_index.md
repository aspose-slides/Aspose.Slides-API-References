## OrganizationChartLayoutType enum

Bir organizasyon şemasındaki alt düğümlerin biçimlendirme türünü temsil eder

OrganizationChartLayoutType türü aşağıdaki üyeleri sunar:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| INITIAL | İlk düzen türü |
| STANDART | Alt düğümleri ebeveyn düğümün altında yatay olarak konumlandırır. |
| BOTH_HANGING | Alt düğümleri ebeveyn düğümün altında hem sol hem sağ tarafta dikey olarak konumlandırır. |
| LEFT_HANGING | Alt düğümleri ebeveyn düğümün altında sol tarafta dikey olarak konumlandırır. |
| RIGHT_HANGING | Alt düğümleri ebeveyn düğümün altında sağ tarafta dikey olarak konumlandırır. |
