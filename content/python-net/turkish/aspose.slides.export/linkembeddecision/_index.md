## LinkEmbedDecision enum

Nesnenin kaydedilirken nasıl işleneceğini belirler.

LinkEmbedDecision türü aşağıdaki üyeleri ortaya koyar:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| LINK | Nesne dışarıda depolanacak, URL ile referanslandırılacak |
| EMBED | Nesne mümkünse oluşturulan bir dosyaya gömülmelidir. Gömme mümkün değilse, GetUrl çağrılacak ve sonuca bağlı olarak nesne URL ile referanslandırılacak ya da yok sayılacak. |
| IGNORE | Nesne yok sayılacak. |
