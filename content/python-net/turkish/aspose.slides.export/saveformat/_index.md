## SaveFormat enumu

SaveFormat türü aşağıdaki üyeleri sunar:

| Alan | Açıklama |
| :- | :- |

| POTX | Sunumu POTX (şablon) biçiminde kaydet. |

| HTML | Sunumu HTML biçiminde kaydet. |
| SWF | Sunumu SWF biçiminde kaydet. |
