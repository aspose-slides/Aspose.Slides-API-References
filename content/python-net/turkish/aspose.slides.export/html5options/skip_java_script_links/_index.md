## skip_java_script_links property
Sunumu kaydederken JavaScript çağrıları içeren köprülerin atlanıp atlanmayacağını belirtir. 
            Okunur/Yazılabilir **bool**. Varsayılan değer **false** .


### Açıklamalar

**true** olarak ayarlandığında, JavaScript çağrıları içeren köprüler kaydedilirken yok sayılır.


**false** olarak ayarlandığında, tüm köprüler kaydedilir.
