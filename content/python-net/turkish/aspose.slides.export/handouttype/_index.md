## HandoutType enum

Sayfada kaç slayt bulunacağını ve hangi sırayla yerleştirileceğini belirler.

HandoutType türü aşağıdaki üyeleri sunar:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| HANDOUTS1 | Sayfa başına bir slayt. |
| HANDOUTS2 | Sayfa başına iki slayt. |
| HANDOUTS3 | Sayfa başına üç slayt. |
| HANDOUTS_4_HORIZONTAL | Sayfa başına dört slayt, yatay sırada. |
| HANDOUTS_4_VERTICAL | Sayfa başına dört slayt, dikey sırada. |
| HANDOUTS_6_HORIZONTAL | Sayfa başına altı slayt, yatay sırada. |
| HANDOUTS_6_VERTICAL | Sayfa başına altı slayt, dikey sırada. |
| HANDOUTS_9_HORIZONTAL | Sayfa başına dokuz slayt, yatay sırada. |
| HANDOUTS_9_VERTICAL | Sayfa başına dokuz slayt, dikey sırada. |
