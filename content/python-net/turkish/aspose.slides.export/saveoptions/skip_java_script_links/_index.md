## skip_java_script_links özelliği
Sunumu kaydederken JavaScript çağrıları içeren bağlantıların atlanıp atlanmayacağını belirtir. 
            Okunabilir/yazılabilir **bool**. Varsayılan değer **false** .


### Açıklamalar

Bu özellik **true** olarak ayarlandığında, JavaScript çağrıları içeren bağlantılar kaydetme sırasında yok sayılır.


Bu özellik **false** olarak ayarlandığında, tüm bağlantılar kaydedilir.
