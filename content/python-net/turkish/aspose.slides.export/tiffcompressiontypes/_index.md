## TiffCompressionTypes enum

TIFF formatında bir sunumun nasıl sıkıştırılacağını kontrol eden seçenekler sağlar.

TiffCompressionTypes türü aşağıdaki üyeleri sunar:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| DEFAULT | Varsayılan sıkıştırma şemasını (LZW) belirtir. |
| NONE | Sıkıştırma olmadığını belirtir. |
| CCITT3 | CCITT3 sıkıştırma şemasını belirtir. |
| CCITT4 | CCITT4 sıkıştırma şemasını belirtir. |
| LZW | LZW sıkıştırma şemasını (Varsayılan) belirtir. |
| RLE | RLE sıkıştırma şemasını belirtir. |
