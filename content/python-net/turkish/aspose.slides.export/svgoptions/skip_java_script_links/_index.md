## skip_java_script_links property
Sunum kaydedilirken JavaScript çağrıları içeren köprülerin atlanıp atlanmayacağını belirtir. 
Okuma/Yazma **bool**. Varsayılan değer **false** .


### Remarks

Bu özellik **true** olarak ayarlandığında, JavaScript çağrıları içeren köprüler kaydedilirken yok sayılır.


Bu özellik **false** olarak ayarlandığında, tüm köprüler kaydedilir.
