## embed_true_type_fonts_for_ascii özellik
True to embed true type fonts for ASCII characters 32-127.
Fonts for character codes greater than 127 are always embedded.
Okunur/Yazılabilir **bool**.

### Açıklamalar

Varsayılan **true**.
