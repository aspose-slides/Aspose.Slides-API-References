## SvgExternalFontsHandling enumerasyon

Metin çizimi için kullanılan harici yazı tiplerini işleme şekli temsil eder.

SvgExternalFontsHandling türü aşağıdaki üyeleri sunar:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| ADD_LINKS_TO_FONT_FILES | SVG dosyasının stil bölümüne ayrı yazı tipi dosyalarına bağlantılar ekle. |
| EMBED | Yazı tipi verilerini doğrudan SVG dosyasına kaydet. Bu seçeneği kullanmadan önce tüm harici yazı tipi lisans anlaşmalarını kontrol edin. |
| VECTORIZE | Harici yazı tiplerini kullanan tüm metni grafik olarak kaydet. |
