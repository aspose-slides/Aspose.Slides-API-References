## skip_java_script_links özelliği
Sunumu kaydederken JavaScript çağrıları içeren köprüleri atlayıp atlamayacağını belirtir. 
            Okuma/yazma **bool**. Varsayılan değer **false** .


### Remarks

Bu özellik **true** olarak ayarlandığında, JavaScript çağrıları içeren köprüler kaydederken yok sayılacaktır.


Bu özellik **false** olarak ayarlandığında, tüm köprüler kaydedilecektir.
