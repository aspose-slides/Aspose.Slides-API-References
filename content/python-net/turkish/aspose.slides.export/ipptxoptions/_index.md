## IPptxOptions sınıfı

OpenXml sunumlarını (PPTX, PPSX, POTX, PPTM, PPSM, POTM) kaydetmek için seçenekleri temsil eder.

IPptxOptions türü aşağıdaki üyeleri ortaya çıkar:

## Özellikler

| Özellik | Açıklama |
| :- | :- |
| [`conformance`](/slides/python-net/tr/aspose.slides.export/ipptxoptions/conformance/) | Sunum belgesinin uyduğu uygunluk sınıfını belirtir.<br/>            Varsayılan değer [`Conformance.ECMA_376_2006`](/slides/python-net/tr/aspose.slides.export/conformance/ECMA_376_2006) |
| [`zip_64_mode`](/slides/python-net/tr/aspose.slides.export/ipptxoptions/zip_64_mode/) | Sunum belgesinde ZIP64 formatının kullanılıp kullanılmadığını belirtir.<br/>            Varsayılan değer [`Zip64Mode.IF_NECESSARY`](/slides/python-net/tr/aspose.slides.export/zip64mode/IF_NECESSARY) |
| [`refresh_thumbnail`](/slides/python-net/tr/aspose.slides.export/ipptxoptions/refresh_thumbnail/) | Sunum küçük resminin yenilenip yenilenmeyeceğini belirtir. <br/>            Okunur/yazılır **bool**.<br/>            Varsayılan değer **true** . |
| [`compression_level`](/slides/python-net/tr/aspose.slides.export/ipptxoptions/compression_level/) | Sunum belgesi kaydedilirken kullanılan sıkıştırma seviyesini belirtir.<br/>            Varsayılan değer [`CompressionLevel.LEVEL6`](/slides/python-net/tr/aspose.slides.export/compressionlevel/LEVEL6). |
