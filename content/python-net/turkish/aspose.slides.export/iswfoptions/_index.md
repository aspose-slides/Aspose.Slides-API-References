## ISwfOptions sınıfı

Sunumun SWF biçiminde kaydedilmesini kontrol eden seçenekleri sağlar.

ISwfOptions türü aşağıdaki üyeleri sunar:

## Özellikler

| Özellik | Açıklama |
| :- | :- |
| [`compressed`](/slides/python-net/tr/aspose.slides.export/iswfoptions/compressed/) | Oluşturulan SWF belgesinin sıkıştırılıp sıkıştırılmayacağını belirtir.<br/>            Varsayılan değer `true`. |
| [`viewer_included`](/slides/python-net/tr/aspose.slides.export/iswfoptions/viewer_included/) | Oluşturulan SWF belgesinin bütünleşik belge görüntüleyiciyi içerip içermeyeceğini belirtir.<br/>            Varsayılan değer `true`. |
| [`show_page_border`](/slides/python-net/tr/aspose.slides.export/iswfoptions/show_page_border/) | Sayfalar etrafındaki kenarlığın gösterilip gösterilmeyeceğini belirtir. Varsayılan değer true. |
| [`show_hidden_slides`](/slides/python-net/tr/aspose.slides.export/iswfoptions/show_hidden_slides/) | Oluşturulan belgenin gizli slaytları içerip içermeyeceğini belirtir.<br/>            Varsayılan değer `false`. |
| [`show_full_screen`](/slides/python-net/tr/aspose.slides.export/iswfoptions/show_full_screen/) | Tam ekran düğmesini göster/gizle. flashvars içinde geçersiz kılınabilir. Varsayılan değer true. |
| [`show_page_stepper`](/slides/python-net/tr/aspose.slides.export/iswfoptions/show_page_stepper/) | Sayfa adım düğmesini göster/gizle. flashvars içinde geçersiz kılınabilir. Varsayılan değer true. |
| [`show_search`](/slides/python-net/tr/aspose.slides.export/iswfoptions/show_search/) | Arama bölümünü göster/gizle. flashvars içinde geçersiz kılınabilir. Varsayılan değer true. |
| [`show_top_pane`](/slides/python-net/tr/aspose.slides.export/iswfoptions/show_top_pane/) | Tüm üst paneli göster/gizle. flashvars içinde geçersiz kılınabilir. Varsayılan değer true. |
| [`show_bottom_pane`](/slides/python-net/tr/aspose.slides.export/iswfoptions/show_bottom_pane/) | Alt paneli göster/gizle. flashvars içinde geçersiz kılınabilir. Varsayılan değer true. |
| [`show_left_pane`](/slides/python-net/tr/aspose.slides.export/iswfoptions/show_left_pane/) | Sol paneli göster/gizle. flashvars içinde geçersiz kılınabilir. Varsayılan değer true. |
| [`start_open_left_pane`](/slides/python-net/tr/aspose.slides.export/iswfoptions/start_open_left_pane/) | Açık sol panel ile başlat. flashvars içinde geçersiz kılınabilir. Varsayılan değer false. |
| [`enable_context_menu`](/slides/python-net/tr/aspose.slides.export/iswfoptions/enable_context_menu/) | Bağlam menüsünü etkinleştir/devre dışı bırak. Varsayılan değer true. |
| [`logo_image_bytes`](/slides/python-net/tr/aspose.slides.export/iswfoptions/logo_image_bytes/) | Görüntüleyicinin sağ üst köşesinde logo olarak gösterilecek resim.<br/>            Resim 32x64 piksel PNG olmalıdır, aksi takdirde logo düzgün görüntülenmeyebilir. |
| [`logo_link`](/slides/python-net/tr/aspose.slides.export/iswfoptions/logo_link/) | Logonun tam hiperbağ adresini alır veya ayarlar.<br/>            Yalnızca bir [`ISwfOptions.logo_image_bytes`](/slides/python-net/tr/aspose.slides.export/iswfoptions/logo_image_bytes) belirtilmişse etkili olur. |
| [`jpeg_quality`](/slides/python-net/tr/aspose.slides.export/iswfoptions/jpeg_quality/) | JPEG resimlerin kalitesini belirtir.<br/>            Varsayılan değer 95. |
| [`slides_layout_options`](/slides/python-net/tr/aspose.slides.export/iswfoptions/slides_layout_options/) | Sunumu [`ISlidesLayoutOptions`](/slides/python-net/tr/aspose.slides.export/islideslayoutoptions) dışa aktarırken slaytların sayfaya yerleştirileceği modu alır veya ayarlar.<br/>            Bu özellik `Aspose.Slides.Export.HandoutLayoutingOptions` türündeki nesnelerin atanmasını desteklemez |
