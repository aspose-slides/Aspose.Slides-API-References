## skip_java_script_links özelliği
Sunumu kaydederken JavaScript çağrıları içeren köprülerin atlanıp atlanmayacağını belirtir. 
            Okunur/Yazılır **bool**. Varsayılan değer **false** .


### Açıklama

Bu özellik **true** olarak ayarlandığında, JavaScript çağrıları içeren köprüler kaydetme sırasında yoksayılacaktır.


Bu özellik **false** olarak ayarlandığında, tüm köprüler kaydedilecektir.
