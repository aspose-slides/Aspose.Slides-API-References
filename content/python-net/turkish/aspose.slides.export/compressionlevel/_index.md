## CompressionLevel enum

OpenXML dosyası için ZIP sıkıştırma seviyelerini belirtir. Daha yüksek seviyeler, daha yavaş işlem maliyetine karşı daha iyi sıkıştırma sağlar.

CompressionLevel türü aşağıdaki üyeleri sunar:

## Alanlar

| Field | Description |
| :- | :- |
| NONE | Sıkıştırma uygulanmaz. Dosyalar olduğu gibi depolanır. |
| LEVEL1 | En düşük sıkıştırma oranına sahip en hızlı sıkıştırma. |
| LEVEL2 | [`CompressionLevel.LEVEL1`](/slides/python-net/tr/aspose.slides.export/compressionlevel/LEVEL1)'a göre biraz daha iyi sıkıştırma oranı ve daha hızlı sıkıştırma. |
| LEVEL3 | [`CompressionLevel.LEVEL2`](/slides/python-net/tr/aspose.slides.export/compressionlevel/LEVEL2)'a göre daha iyi sıkıştırma sağlar, performans etkisi orta seviyededir. |
| LEVEL4 | [`CompressionLevel.LEVEL3`](/slides/python-net/tr/aspose.slides.export/compressionlevel/LEVEL3)'a göre daha iyi sıkıştırma sağlar. |
| LEVEL5 | [`CompressionLevel.LEVEL4`](/slides/python-net/tr/aspose.slides.export/compressionlevel/LEVEL4)'a göre geliştirilmiş sıkıştırma sağlar, ek işlem süresi gerektirir. |
| LEVEL6 | Standart sıkıştırma, sıkıştırma hızı ve dosya boyutu arasında iyi bir denge sunar.<br/>Varsayılan sıkıştırma seviyesi. |
| LEVEL7 | [`CompressionLevel.LEVEL6`](/slides/python-net/tr/aspose.slides.export/compressionlevel/LEVEL6)'a göre daha yüksek sıkıştırma sağlar, ancak işlem daha yavaştır. |
| LEVEL8 | [`CompressionLevel.LEVEL7`](/slides/python-net/tr/aspose.slides.export/compressionlevel/LEVEL7)'a göre daha yüksek sıkıştırma sağlar. |
| LEVEL9 | Maksimum sıkıştırma. En küçük dosya boyutunu, en yavaş işlem hızıyla üretir. |
