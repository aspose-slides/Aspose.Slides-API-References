## skip_java_script_links özelliği
Sunumu kaydederken JavaScript çağrıları içeren köprülerin atlanıp atlanmayacağını belirtir. 
            Okuma/Yazma **bool**. Varsayılan değer **false** .


### Açıklamalar

Bu özellik **true** olarak ayarlandığında, JavaScript çağrıları içeren köprüler kaydederken görmezlenir.


Bu özellik **false** olarak ayarlandığında, tüm köprüler kaydedilir.
