## SvgCoordinateUnit numaralandırma

SVG koordinatlarını tanımlamak için kullanılan CSS2 koordinat birimlerini temsil eder.

SvgCoordinateUnit türü aşağıdaki üyeleri sunar:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| INCH | İnç |
| CENTIMETER | Santimetre. |
| MILLIMETER | Milimetre. |
| POINT | Nokta (inç'in 1/72'si), |
| PICA | Pika (inç'in 1/6'sı). |
| EM | İçeren öğenin yazı tipinin em boyutu. |
| EX | İçeren öğenin yazı tipinin ex boyutu (küçük harf boyutu, genellikle "x"). |
| PIXEL | Piksel boyutu. |
| PERCENT | Yüzde. |
