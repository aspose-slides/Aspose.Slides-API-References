## BlackWhiteConversionMode numaralandırması

Slaytların görüntülerinin iki tonlu görüntülere nasıl dönüştürüleceğini kontrol eden seçenekler sağlar.

BlackWhiteConversionMode türü aşağıdaki üyeleri ortaya koyar:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| DEFAULT | Herhangi bir dönüşüm algoritması belirtmez. TIFF kodekinde uygulanan algoritma kullanılacaktır. (Varsayılan) |
| DITHERING | Dithering algoritmasını (Floyd-Steinberg) belirtir. |
| DITHERING_FLOYD_STEINBERG | Floyd-Steinberg dithering algoritmasını belirtir. |
| AUTO | Otomatik olarak hesaplanan eşik algoritmasını (Otsu) belirtir. |
| AUTO_OTSU | Otomatik olarak hesaplanan Otsu eşik algoritmasını belirtir. |
| THRESHOLD25 | Statik eşik algoritmasını (25%) belirtir. |
| THRESHOLD50 | Statik eşik algoritmasını (50%) belirtir. |
| THRESHOLD75 | Statik eşik algoritmasını (75%) belirtir. |
