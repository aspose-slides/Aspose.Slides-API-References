## BuildType enumeration

Metnin bir şekil üzerindeki animasyon sırasında nasıl görüneceğini belirler.

BuildType türü aşağıdaki üyeleri ortaya çıkar:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| AS_ONE_OBJECT | İçeren şekille. |
| ALL_PARAGRAPHS_AT_ONCE | Tüm paragraflar. |
| BY_LEVEL_PARAGRAPHS1 | Derinliği 1 olan paragraf gruplarıyla. |
| BY_LEVEL_PARAGRAPHS2 | Derinliği 2 olan paragraf gruplarıyla. |
| BY_LEVEL_PARAGRAPHS3 | Derinliği 3 olan paragraf gruplarıyla. |
| BY_LEVEL_PARAGRAPHS4 | Derinliği 4 olan paragraf gruplarıyla. |
| BY_LEVEL_PARAGRAPHS5 | Derinliği 5 olan paragraf gruplarıyla. |
