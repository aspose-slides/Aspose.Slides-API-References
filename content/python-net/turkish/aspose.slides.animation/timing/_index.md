## Timing sınıfı

Animasyon zamanlamasını temsil eder.

Timing türü aşağıdaki üyeleri ortaya çıkar:

## Özellikler

| Özellik | Açıklama |
| :- | :- |
| [`accelerate`](/slides/python-net/tr/aspose.slides.animation/timing/accelerate/) | Süre içinde hızlanma davranışı etkisinin yüzdesini tanımlar.<br/>            Okuma/yazma **float**. |
| [`decelerate`](/slides/python-net/tr/aspose.slides.animation/timing/decelerate/) | Süre içinde yavaşlatma davranışı etkisinin yüzdesini tanımlar.<br/>            Okuma/yazma **float**. |
| [`auto_reverse`](/slides/python-net/tr/aspose.slides.animation/timing/auto_reverse/) | İleri yönde oynatıldıktan sonra animasyonun ters yönde otomatik olarak oynatılıp oynatılmayacağını tanımlar.<br/>            Okuma/yazma **bool**. |
| [`duration`](/slides/python-net/tr/aspose.slides.animation/timing/duration/) | Animasyon etkisinin süresini tanımlar.<br/>            Okuma/yazma **float**. |
| [`repeat_count`](/slides/python-net/tr/aspose.slides.animation/timing/repeat_count/) | Etkinin kaç kez tekrarlanması gerektiğini tanımlar.<br/>            Okuma/yazma **float**. |
| [`repeat_until_end_slide`](/slides/python-net/tr/aspose.slides.animation/timing/repeat_until_end_slide/) | Bu nitelik, etkinin slayt sonuna kadar tekrar edip etmeyeceğini belirler.<br/>             Okuma/yazma **bool**. |
| [`repeat_until_next_click`](/slides/python-net/tr/aspose.slides.animation/timing/repeat_until_next_click/) | Bu nitelik, etkinin bir sonraki tıklamaya kadar tekrar edip etmeyeceğini belirler.<br/>             Okuma/yazma **bool**. |
| [`repeat_duration`](/slides/python-net/tr/aspose.slides.animation/timing/repeat_duration/) | Etkinin kaç kez tekrarlanması gerektiğini tanımlar.<br/>            Okuma/yazma **float**. |
| [`restart`](/slides/python-net/tr/aspose.slides.animation/timing/restart/) | Tamamlandıktan sonra etkinin yeniden başlatılıp başlatılmayacağını belirler.<br/>            Okuma/yazma [`EffectRestartType`](/slides/python-net/tr/aspose.slides.animation/effectrestarttype). |
| [`rewind`](/slides/python-net/tr/aspose.slides.animation/timing/rewind/) | Bu nitelik, etkinin çalma tamamlandığında geri sarılıp sarılmayacağını belirler.<br/>             Okuma/yazma **bool**. |
| [`speed`](/slides/python-net/tr/aspose.slides.animation/timing/speed/) | Zamanlamayı hızlandırma (veya yavaşlatma) yüzdesini belirler.<br/>            Okuma/yazma **float**. |
| [`trigger_delay_time`](/slides/python-net/tr/aspose.slides.animation/timing/trigger_delay_time/) | Tetikleyiciden sonraki gecikme süresini tanımlar.<br/>            Okuma/yazma **float**. |
| [`trigger_type`](/slides/python-net/tr/aspose.slides.animation/timing/trigger_type/) | Tetikleyici tipini tanımlar.<br/>            Okuma/yazma [`EffectTriggerType`](/slides/python-net/tr/aspose.slides.animation/effecttriggertype). |
