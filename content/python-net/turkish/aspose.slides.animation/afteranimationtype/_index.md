## AfterAnimationType enum

Bir animasyon etkisinin animasyon sonrası tipini temsil eder.

AfterAnimationType tipi aşağıdaki üyeleri sunar:

## Alanlar

| Alan | Açıklama |
| :- | :- |
| DO_NOT_DIM | Animasyon sonrası karartma yapılmasın. |
| COLOR | Animasyon sonrası renk. |
| HIDE_AFTER_ANIMATION | Animasyon sonrası gizle. |
| HIDE_ON_NEXT_MOUSE_CLICK | Animasyon sonrası sonraki fare tıklamasında gizle. |
