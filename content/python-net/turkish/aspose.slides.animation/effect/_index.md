## Effect sınıfı

Animasyon efektini temsil eder.

Effect tipi aşağıdaki üyeleri gösterir:

## Özellikler

| Özellik | Açıklama |
| :- | :- |
| [`sequence`](/slides/python-net/tr/aspose.slides.animation/effect/sequence/) | Bir efekt için bir dizi döndürür.<br/>            Yalnızca okuma [`ISequence`](/slides/python-net/tr/aspose.slides.animation/isequence). |
| [`text_animation`](/slides/python-net/tr/aspose.slides.animation/effect/text_animation/) | TextAnimation<br/>            Yalnızca okuma [`ITextAnimation`](/slides/python-net/tr/aspose.slides.animation/itextanimation). |
| [`preset_class_type`](/slides/python-net/tr/aspose.slides.animation/effect/preset_class_type/) | Efektin sınıfını tanımlar.<br/>            Okuma/yazma [`EffectPresetClassType`](/slides/python-net/tr/aspose.slides.animation/effectpresetclasstype). |
| [`type`](/slides/python-net/tr/aspose.slides.animation/effect/type/) | Efektin tipini tanımlar.<br/>            Okuma/yazma [`EffectType`](/slides/python-net/tr/aspose.slides.animation/effecttype). |
| [`subtype`](/slides/python-net/tr/aspose.slides.animation/effect/subtype/) | Efektin alt tipini tanımlar.<br/>            Okuma/yazma [`EffectSubtype`](/slides/python-net/tr/aspose.slides.animation/effectsubtype). |
| [`behaviors`](/slides/python-net/tr/aspose.slides.animation/effect/behaviors/) | Efekt için davranış koleksiyonunu döndürür.<br/>            Okuma/yazma [`IBehaviorCollection`](/slides/python-net/tr/aspose.slides.animation/ibehaviorcollection). |
| [`timing`](/slides/python-net/tr/aspose.slides.animation/effect/timing/) | Efekt için zamanlama değerini tanımlar.<br/>            Okuma/yazma [`ITiming`](/slides/python-net/tr/aspose.slides.animation/itiming). |
| [`target_shape`](/slides/python-net/tr/aspose.slides.animation/effect/target_shape/) | Efekt için hedef şekli döndürür.<br/>            Yalnızca okuma [`IShape`](/slides/python-net/tr/aspose.slides/ishape). |
| [`sound`](/slides/python-net/tr/aspose.slides.animation/effect/sound/) | Efekt için gömülü ses tanımlanır.<br/>            Okuma/yazma [`IAudio`](/slides/python-net/tr/aspose.slides/iaudio). |
| [`stop_previous_sound`](/slides/python-net/tr/aspose.slides.animation/effect/stop_previous_sound/) | Bu öznitelik, animasyon efektinin önceki sesi durdurup durdurmadığını belirtir.<br/>            Okuma/yazma **bool**. |
| [`after_animation_type`](/slides/python-net/tr/aspose.slides.animation/effect/after_animation_type/) | Efekt için bir sonraki animasyon tipini tanımlar.<br/>            Okuma/yazma [`Effect.after_animation_type`](/slides/python-net/tr/aspose.slides.animation/effect/after_animation_type). |
| [`after_animation_color`](/slides/python-net/tr/aspose.slides.animation/effect/after_animation_color/) | Efekt için bir sonraki animasyon rengini tanımlar.<br/>            Okuma/yazma [`IColorFormat`](/slides/python-net/tr/aspose.slides/icolorformat). |
| [`animate_text_type`](/slides/python-net/tr/aspose.slides.animation/effect/animate_text_type/) | Efekt için bir metin animasyonu tipini tanımlar.<br/>            Şekil metni harf, kelime bazında veya tümü bir anda animasyonlandırılabilir.<br/>            Okuma/yazma [`Effect.animate_text_type`](/slides/python-net/tr/aspose.slides.animation/effect/animate_text_type). |
| [`delay_between_text_parts`](/slides/python-net/tr/aspose.slides.animation/effect/delay_between_text_parts/) | Animasyonlu metin parçaları (kelimeler veya harfler) arasındaki gecikmeyi tanımlar.<br/>            Pozitif bir değer, efekt süresinin yüzdesini belirtir.<br/>            Negatif bir değer, saniye cinsinden gecikmeyi belirtir.<br/>            Okuma/yazma **float**. |
