## ITiming sınıf

Animasyon zamanlamasını temsil eder.

ITTiming türü aşağıdaki üyeleri sunar:

## Özellikler

| Özellik | Açıklama |
| :- | :- |
| [`accelerate`](/slides/python-net/tr/aspose.slides.animation/itiming/accelerate/) | Süre hızlandırma davranışı etkisinin yüzdesini tanımlar.<br/>            Okunur/Yazılır **float**. |
| [`decelerate`](/slides/python-net/tr/aspose.slides.animation/itiming/decelerate/) | Süre yavaşlatma davranışı etkisinin yüzdesini tanımlar.<br/>            Okunur/Yazılır **float**. |
| [`auto_reverse`](/slides/python-net/tr/aspose.slides.animation/itiming/auto_reverse/) | İleri yönde oynatıldıktan sonra<br/>            animasyonun ters yönde otomatik olarak oynatılıp oynatılmayacağını tanımlar.<br/>            Okunur/Yazılır **bool**. |
| [`duration`](/slides/python-net/tr/aspose.slides.animation/itiming/duration/) | Animasyon etkisinin süresini tanımlar.<br/>            Okunur/Yazılır **float**. |
| [`repeat_count`](/slides/python-net/tr/aspose.slides.animation/itiming/repeat_count/) | Etkinin kaç kez tekrarlanması gerektiğini tanımlar.<br/>            Okunur/Yazılır **float**. |
| [`repeat_until_end_slide`](/slides/python-net/tr/aspose.slides.animation/itiming/repeat_until_end_slide/) | Bu nitelik, etkinin slayt sonuna kadar tekrarlanıp tekrarlanmayacağını belirler.<br/>            Okunur/Yazılır **bool**. |

| [`repeat_duration`](/slides/python-net/tr/aspose.slides.animation/itiming/repeat_duration/) | Etkinin kaç kez tekrarlanması gerektiğini tanımlar.<br/>            Okunur/Yazılır **float**. |

| [`trigger_delay_time`](/slides/python-net/tr/aspose.slides.animation/itiming/trigger_delay_time/) | Tetikleyiciden sonra gecikme süresini tanımlar.<br/>            Okunur/Yazılır **float**. |
| [`trigger_type`](/slides/python-net/tr/aspose.slides.animation/itiming/trigger_type/) | Tetikleyici türünü tanımlar.<br/>            Okunur/Yazılır [`EffectTriggerType`](/slides/python-net/tr/aspose.slides.animation/effecttriggertype). |
| [`rewind`](/slides/python-net/tr/aspose.slides.animation/itiming/rewind/) | Bu nitelik, etkinin çalma tamamlandığında geri sarılıp sarılmayacağını belirler.<br/>            Okunur/Yazılır **bool**. |
