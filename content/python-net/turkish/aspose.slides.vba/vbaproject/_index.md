## VbaProject sınıf

Sunum makroları içeren VBA projesini temsil eder.

VbaProject türü aşağıdaki üyelere sahiptir:

## Yapıcılar

| Yapıcı | Açıklama |
| :- | :- |
| [`__init__(self)`](/slides/python-net/tr/aspose.slides.vba/vbaproject/__init__/#) | Bu yapıcı, baştan yeni bir VBA projesi oluşturur.<br/>            Proje 1252 Windows Latin 1 (ANSI) kod sayfasında oluşturulacaktır |
| [`__init__(self, data)`](/slides/python-net/tr/aspose.slides.vba/vbaproject/__init__/#bytes) | Bu yapıcı, OLE konteynerinin ikili temsili üzerinden VBA projesini yükler. |

## Özellikler

| Özellik | Açıklama |
| :- | :- |
| [`name`](/slides/python-net/tr/aspose.slides.vba/vbaproject/name/) | VBA projesinin adını döndürür.<br/>            Salt-okunur **str**. |
| [`modules`](/slides/python-net/tr/aspose.slides.vba/vbaproject/modules/) | VBA projesinde bulunan tüm modüllerin listesini döndürür.<br/>            Salt-okunur [`IVbaModuleCollection`](/slides/python-net/tr/aspose.slides.vba/ivbamodulecollection). |
| [`references`](/slides/python-net/tr/aspose.slides.vba/vbaproject/references/) | VBA projesinde bulunan tüm referansların listesini döndürür.<br/>            Salt-okunur [`IVbaReferenceCollection`](/slides/python-net/tr/aspose.slides.vba/ivbareferencecollection). |
| [`is_password_protected`](/slides/python-net/tr/aspose.slides.vba/vbaproject/is_password_protected/) | VBAProject'in proje özelliklerini görüntülemek için bir şifreyle korunduğunu gösterir.<br/>            Salt-okunur **bool**. |
