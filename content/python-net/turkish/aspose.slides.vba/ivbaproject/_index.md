## IVbaProject sınıf

Sunum makroları içeren VBA projesini temsil eder.

IVbaProject türü aşağıdaki üyeleri sunar:

## Özellikler

| Özellik | Açıklama |
| :- | :- |
| [`name`](/slides/python-net/tr/aspose.slides.vba/ivbaproject/name/) | VBA projesinin adını döndürür.<br/>            Sadece okunur **str**. |
| [`modules`](/slides/python-net/tr/aspose.slides.vba/ivbaproject/modules/) | VBA projesinde bulunan tüm modüllerin listesini döndürür.<br/>            Sadece okunur [`IVbaModuleCollection`](/slides/python-net/tr/aspose.slides.vba/ivbamodulecollection). |
| [`references`](/slides/python-net/tr/aspose.slides.vba/ivbaproject/references/) | VBA projesinde bulunan tüm referansların listesini döndürür.<br/>            Sadece okunur [`IVbaReferenceCollection`](/slides/python-net/tr/aspose.slides.vba/ivbareferencecollection). |
| [`is_password_protected`](/slides/python-net/tr/aspose.slides.vba/ivbaproject/is_password_protected/) | VBAProject'in proje özelliklerini görüntülemek için bir şifreyle korunup korunmadığını gösterir.<br/>            Sadece okunur **bool**. |
