## get_cells(self, formula, skip_hidden_cells) {#str-bool}
Recupera una colección de celdas del libro de trabajo que coinciden con la fórmula especificada.

### Devuelve

Una lista de solo lectura de celdas que coinciden con la fórmula especificada.

```python
def get_cells(self, formula, skip_hidden_cells):
    ...
```


| Parámetro | Tipo | Descripción |
| :- | :- | :- |

| skip_hidden_cells | **bool** | Si `true`, las celdas ocultas (p. ej., en filas o columnas ocultas) se excluirán del resultado. |
