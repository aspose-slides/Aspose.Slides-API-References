## TransitionMorphType enumeración

Representa un tipo de transición morph.

El tipo TransitionMorphType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| BY_OBJECT | La transición morph se realizará considerando las formas como objetos indivisibles. |
| BY_WORD | La transición morph se realizará transfiriendo el texto por palabras cuando sea posible. |
| BY_CHAR | La transición morph se realizará transfiriendo el texto por caracteres cuando sea posible. |
