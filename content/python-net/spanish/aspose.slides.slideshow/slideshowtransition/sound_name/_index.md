## propiedad sound_name
Especifica un nombre legible para el sonido de la transición. La propiedad [`SlideShowTransition.sound`](/slides/python-net/es/aspose.slides.slideshow/slideshowtransition/sound) debe asignarse para obtener o establecer el nombre del sonido.
            Lectura-escritura **str**.


### Observaciones

Este nombre aparece en la interfaz de usuario de PowerPoint al configurar manualmente el sonido de la transición.
