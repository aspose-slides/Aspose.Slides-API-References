## sound_is_built_in propiedad
Especifica si este sonido es un sonido incorporado o no. Si este atributo se establece en true entonces
            la aplicación generadora se notifica para comprobar el atributo name especificado para este sonido
            en su lista de sonidos incorporados y luego puede presentar un nombre personalizado o UI según sea necesario.
            Lectura-escritura **bool**.
