## EffectPresetClassType enumeración

Representa los tipos de clase de efecto.

El tipo EffectPresetClassType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| ENTRANCE | Clase de efectos de entrada.<br/><br/><br/>Tipos de forma objetivo: Todos |
| EXIT | Clase de efectos de salida.<br/><br/><br/>Tipos de forma objetivo: Todos |
| EMPHASIS | Clase de efectos de énfasis.<br/><br/><br/>Tipos de forma objetivo: Todos |
| PATH | Clase de rutas de movimiento.<br/><br/><br/>Tipos de forma objetivo: Todos |
| MEDIA_CALL | Clase de efectos de medios.<br/><br/><br/>Tipos de forma objetivo: [`IVideoFrame`](/slides/python-net/es/aspose.slides/ivideoframe), [`IAudioFrame`](/slides/python-net/es/aspose.slides/iaudioframe) |
| OLE_ACTION_VERBS | Clase de verbos de acción OLE.<br/><br/><br/>Tipos de forma objetivo: [`IOleObjectFrame`](/slides/python-net/es/aspose.slides/ioleobjectframe) |
