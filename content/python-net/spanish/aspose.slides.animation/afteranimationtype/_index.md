## AfterAnimationType enumeración

Representa el tipo de animación posterior de un efecto de animación.

El tipo AfterAnimationType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| DO_NOT_DIM | No atenuar después del tipo de animación. |
| COLOR | Color después del tipo de animación. |
| HIDE_AFTER_ANIMATION | Ocultar tipo de animación posterior |
| HIDE_ON_NEXT_MOUSE_CLICK | Ocultar al hacer clic del ratón siguiente después del tipo de animación. |
