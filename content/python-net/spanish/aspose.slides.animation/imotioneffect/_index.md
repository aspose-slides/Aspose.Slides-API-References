## IMotionEffect clase

Representa el comportamiento del efecto de movimiento del efecto.

El tipo IMotionEffect expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`from_address`](/slides/python-net/es/aspose.slides.animation/imotioneffect/from_address/) | Especifica una coordenada x/y desde la cual iniciar la animación (en porcentajes). <br/>            Lectura/escritura [`PointF`](/slides/python-net/es/aspose.slides/pointf). |
| [`to`](/slides/python-net/es/aspose.slides.animation/imotioneffect/to/) | Especifica la ubicación objetivo para un efecto de movimiento de animación (en porcentajes).<br/>            Lectura/escritura [`PointF`](/slides/python-net/es/aspose.slides/pointf). |
| [`by`](/slides/python-net/es/aspose.slides.animation/imotioneffect/by/) | Describe el valor de desplazamiento relativo para la animación (en porcentajes).<br/>            Lectura/escritura [`PointF`](/slides/python-net/es/aspose.slides/pointf). |
| [`rotation_center`](/slides/python-net/es/aspose.slides.animation/imotioneffect/rotation_center/) | Describe el centro de rotación utilizado para girar una trayectoria de movimiento en un ángulo X.<br/>            Lectura/escritura [`PointF`](/slides/python-net/es/aspose.slides/pointf). |
| [`origin`](/slides/python-net/es/aspose.slides.animation/imotioneffect/origin/) | Especifica a qué se refiere el origen de la trayectoria de movimiento, como el diseño de la diapositiva,<br/>            o el elemento padre.<br/>            Lectura/escritura [`MotionOriginType`](/slides/python-net/es/aspose.slides.animation/motionorigintype). |
| [`path`](/slides/python-net/es/aspose.slides.animation/imotioneffect/path/) | Especifica la primitiva de trayectoria seguida de coordenadas para el movimiento de animación.<br/>            Lectura/escritura [`IMotionPath`](/slides/python-net/es/aspose.slides.animation/imotionpath). |
| [`path_edit_mode`](/slides/python-net/es/aspose.slides.animation/imotioneffect/path_edit_mode/) | Especifica cómo se mueve la trayectoria de movimiento cuando se desplaza la forma.<br/>            Lectura/escritura [`MotionPathEditMode`](/slides/python-net/es/aspose.slides.animation/motionpatheditmode). |
