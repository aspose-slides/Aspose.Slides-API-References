## Timing clase
Representa la temporización de la animación.

El tipo Timing expone los siguientes miembros:
## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`accelerate`](/slides/python-net/es/aspose.slides.animation/timing/accelerate/) | Describe el porcentaje del efecto de aceleración de la duración.<br/> Lectura/escritura **float**. |
| [`decelerate`](/slides/python-net/es/aspose.slides.animation/timing/decelerate/) | Describe el porcentaje del efecto de desaceleración de la duración.<br/> Lectura/escritura **float**. |
| [`auto_reverse`](/slides/python-net/es/aspose.slides.animation/timing/auto_reverse/) | Describe si se reproduce automáticamente la animación en reversa después de<br/> reproducirla en la dirección hacia adelante.<br/> Lectura/escritura **bool**. |
| [`duration`](/slides/python-net/es/aspose.slides.animation/timing/duration/) | Describe la duración del efecto de animación.<br/> Lectura/escritura **float**. |
| [`repeat_count`](/slides/python-net/es/aspose.slides.animation/timing/repeat_count/) | Describe el número de veces que el efecto debe repetirse.<br/>            Lectura/escritura **float**. |
| [`repeat_until_end_slide`](/slides/python-net/es/aspose.slides.animation/timing/repeat_until_end_slide/) | Este atributo especifica si el efecto se repetirá hasta el final de la diapositiva.<br/>             Lectura/escritura **bool**. |
| [`repeat_until_next_click`](/slides/python-net/es/aspose.slides.animation/timing/repeat_until_next_click/) | Este atributo especifica si el efecto se repetirá hasta el siguiente clic.<br/>             Lectura/escritura **bool**. |
| [`repeat_duration`](/slides/python-net/es/aspose.slides.animation/timing/repeat_duration/) | Describe el número de veces que el efecto debe repetirse.<br/>            Lectura/escritura **float**. |
| [`restart`](/slides/python-net/es/aspose.slides.animation/timing/restart/) | Especifica si un efecto debe reiniciarse después de completarse.<br/>            Lectura/escritura [`EffectRestartType`](/slides/python-net/es/aspose.slides.animation/effectrestarttype). |
| [`rewind`](/slides/python-net/es/aspose.slides.animation/timing/rewind/) | Este atributo especifica si el efecto retrocederá cuando termine de reproducirse.<br/>             Lectura/escritura **bool**. |
| [`speed`](/slides/python-net/es/aspose.slides.animation/timing/speed/) | Especifica el porcentaje en el que se acelerará (o ralentizará) la sincronización.<br/>            Lectura/escritura **float**. |
| [`trigger_delay_time`](/slides/python-net/es/aspose.slides.animation/timing/trigger_delay_time/) | Describe el tiempo de retardo después del disparador.<br/>            Lectura/escritura **float**. |
| [`trigger_type`](/slides/python-net/es/aspose.slides.animation/timing/trigger_type/) | Describe el tipo de disparador.<br/>            Lectura/escritura [`EffectTriggerType`](/slides/python-net/es/aspose.slides.animation/effecttriggertype). |
