## Clase ITextAnimation

Representa la animación de texto.

El tipo ITextAnimation expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`build_type`](/slides/python-net/es/aspose.slides.animation/itextanimation/build_type/) | Lista de tipos de compilación (por ejemplo Paragraph 1,2,3, All at Once) de animación de texto.<br/>            Lectura/escritura [`ITextAnimation.build_type`](/slides/python-net/es/aspose.slides.animation/itextanimation/build_type). |
| [`effect_animate_background_shape`](/slides/python-net/es/aspose.slides.animation/itextanimation/effect_animate_background_shape/) | Efecto de forma vinculado con grupo o no (None)<br/>            Lectura/escritura [`IEffect`](/slides/python-net/es/aspose.slides.animation/ieffect). |

## Métodos

| Método | Descripción |
| :- | :- |
| [`add_effect(self, effect_type, subtype, trigger_type)`](/slides/python-net/es/aspose.slides.animation/itextanimation/add_effect/#effecttype-effectsubtype-effecttriggertype) | Agregar nuevo efecto al final de la secuencia actual al final de las animaciones de texto del grupo.<br/>            ¡Solo válido si la cantidad de párrafos de texto es igual o mayor que la cantidad de efectos de este grupo! |
