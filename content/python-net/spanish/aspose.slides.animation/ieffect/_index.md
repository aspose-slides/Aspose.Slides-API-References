## IEffect clase

Representa un efecto de animación.

El tipo IEffect expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`sequence`](/slides/python-net/es/aspose.slides.animation/ieffect/sequence/) | Devuelve una secuencia para un efecto.<br/>            Solo lectura [`ISequence`](/slides/python-net/es/aspose.slides.animation/isequence). |
| [`text_animation`](/slides/python-net/es/aspose.slides.animation/ieffect/text_animation/) | Devuelve la animación de texto.<br/>            Solo lectura [`ITextAnimation`](/slides/python-net/es/aspose.slides.animation/itextanimation). |
| [`preset_class_type`](/slides/python-net/es/aspose.slides.animation/ieffect/preset_class_type/) | Define la clase del efecto.<br/>            Lectura/escritura [`EffectPresetClassType`](/slides/python-net/es/aspose.slides.animation/effectpresetclasstype). |
| [`type`](/slides/python-net/es/aspose.slides.animation/ieffect/type/) | Define el tipo del efecto.<br/>            Lectura/escritura [`EffectType`](/slides/python-net/es/aspose.slides.animation/effecttype). |
| [`subtype`](/slides/python-net/es/aspose.slides.animation/ieffect/subtype/) | Define el subtipo del efecto.<br/>            Lectura/escritura [`EffectSubtype`](/slides/python-net/es/aspose.slides.animation/effectsubtype). |
| [`behaviors`](/slides/python-net/es/aspose.slides.animation/ieffect/behaviors/) | Devuelve la colección de comportamientos para el efecto.<br/>            Lectura/escritura [`IBehaviorCollection`](/slides/python-net/es/aspose.slides.animation/ibehaviorcollection). |
| [`timing`](/slides/python-net/es/aspose.slides.animation/ieffect/timing/) | Define el valor de temporización para el efecto.<br/>            Lectura/escritura [`ITiming`](/slides/python-net/es/aspose.slides.animation/itiming). |
| [`target_shape`](/slides/python-net/es/aspose.slides.animation/ieffect/target_shape/) | Devuelve la forma objetivo del efecto.<br/>            Solo lectura [`IShape`](/slides/python-net/es/aspose.slides/ishape). |
| [`sound`](/slides/python-net/es/aspose.slides.animation/ieffect/sound/) | Define el sonido incrustado para el efecto.<br/>            Lectura/escritura [`IAudio`](/slides/python-net/es/aspose.slides/iaudio). |
| [`stop_previous_sound`](/slides/python-net/es/aspose.slides.animation/ieffect/stop_previous_sound/) | Este atributo especifica si el efecto de animación detiene el sonido anterior.<br/>            Lectura/escritura **bool**. |
| [`after_animation_type`](/slides/python-net/es/aspose.slides.animation/ieffect/after_animation_type/) | Define un tipo de animación posterior para el efecto.<br/>            Lectura/escritura [`IEffect.after_animation_type`](/slides/python-net/es/aspose.slides.animation/ieffect/after_animation_type). |
| [`after_animation_color`](/slides/python-net/es/aspose.slides.animation/ieffect/after_animation_color/) | Define un color de animación posterior para el efecto.<br/>            Lectura/escritura [`IColorFormat`](/slides/python-net/es/aspose.slides/icolorformat). |
| [`animate_text_type`](/slides/python-net/es/aspose.slides.animation/ieffect/animate_text_type/) | Define un tipo de animación de texto para el efecto.<br/>            El texto de la forma puede animarse por letra, por palabra o todo a la vez.<br/>            Lectura/escritura [`IEffect.animate_text_type`](/slides/python-net/es/aspose.slides.animation/ieffect/animate_text_type). |
| [`delay_between_text_parts`](/slides/python-net/es/aspose.slides.animation/ieffect/delay_between_text_parts/) | Define un retardo entre partes de texto animado (palabras o letras).<br/>            Un valor positivo especifica el porcentaje de la duración del efecto.<br/>            Un valor negativo especifica el retardo en segundos.<br/>            Lectura/escritura **float**. |
