## AnimateTextType enumeración

Representa el tipo de texto animado de un efecto de animación.

El tipo AnimateTextType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| ALL_AT_ONCE | Animar todo el texto a la vez. |
| BY_WORD | Animar texto por palabra. |
| BY_LETTER | Animar texto por letra. |
