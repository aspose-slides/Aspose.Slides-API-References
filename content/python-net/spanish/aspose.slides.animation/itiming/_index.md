## ITiming clase

Representa la temporización de animación.

El tipo ITiming expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`accelerate`](/slides/python-net/es/aspose.slides.animation/itiming/accelerate/) | Describe el porcentaje de la duración del efecto de comportamiento de aceleración.<br/>            Read/write **float**. |
| [`decelerate`](/slides/python-net/es/aspose.slides.animation/itiming/decelerate/) | Describe el porcentaje de la duración del efecto de comportamiento de desaceleración.<br/>            Read/write **float**. |
| [`auto_reverse`](/slides/python-net/es/aspose.slides.animation/itiming/auto_reverse/) | Describe si la animación se reproduce automáticamente en reversa después de reproducirla en dirección directa.<br/>            Read/write **bool**. |
| [`duration`](/slides/python-net/es/aspose.slides.animation/itiming/duration/) | Describe la duración del efecto de animación.<br/>            Read/write **float**. |
| [`repeat_count`](/slides/python-net/es/aspose.slides.animation/itiming/repeat_count/) | Describe el número de veces que el efecto debe repetirse.<br/>            Read/write **float**. |
| [`repeat_until_end_slide`](/slides/python-net/es/aspose.slides.animation/itiming/repeat_until_end_slide/) | Este atributo especifica si el efecto se repetirá hasta el final de la diapositiva.<br/>             Read/write **bool**. |
| [`repeat_until_next_click`](/slides/python-net/es/aspose.slides.animation/itiming/repeat_until_next_click/) | Este atributo especifica si el efecto se repetirá hasta el siguiente clic.<br/>             Read/write **bool**. |
| [`repeat_duration`](/slides/python-net/es/aspose.slides.animation/itiming/repeat_duration/) | Describe el número de veces que el efecto debe repetirse.<br/>            Read/write **float**. |
| [`restart`](/slides/python-net/es/aspose.slides.animation/itiming/restart/) | Especifica si un efecto debe reiniciarse después de completarse.<br/>            Read/write [`EffectRestartType`](/slides/python-net/es/aspose.slides.animation/effectrestarttype). |
| [`speed`](/slides/python-net/es/aspose.slides.animation/itiming/speed/) | Especifica el porcentaje en que se acelera (o desacelera) la temporización.<br/>            Read/write **float**. |
| [`trigger_delay_time`](/slides/python-net/es/aspose.slides.animation/itiming/trigger_delay_time/) | Describe el tiempo de retraso después del disparador.<br/>            Read/write **float**. |
| [`trigger_type`](/slides/python-net/es/aspose.slides.animation/itiming/trigger_type/) | Describe el tipo de disparador.<br/>            Read/write [`EffectTriggerType`](/slides/python-net/es/aspose.slides.animation/effecttriggertype). |
| [`rewind`](/slides/python-net/es/aspose.slides.animation/itiming/rewind/) | Este atributo especifica si el efecto retrocederá cuando termine de reproducirse.<br/>             Read/write **bool**. |
