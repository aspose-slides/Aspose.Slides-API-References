## BehaviorCollection clase

Representa una colección de efectos de comportamiento.

El tipo BehaviorCollection expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`count`](/slides/python-net/es/aspose.slides.animation/behaviorcollection/count/) | Devuelve el número de comportamientos en una colección.<br/>            Sólo lectura **int**. |
| [`is_read_only`](/slides/python-net/es/aspose.slides.animation/behaviorcollection/is_read_only/) | Obtiene un valor que indica si la **System.Collections.Generic.ICollection`1** es de solo lectura.<br/>            Sólo lectura **bool**. |

Devuelve un comportamiento en el índice especificado.

## Indexador

| Nombre | Descripción |
| :- | :- |
| [`[index]`](/slides/python-net/es/aspose.slides.animation/behaviorcollection/__getitem__/) | Índice de un comportamiento a devolver. |
