## enumeración BuildType

Determina cómo aparecerá el texto en una forma durante la animación.

El tipo BuildType expone los siguientes miembros:

## Campos

| Field | Description |
| :- | :- |
| AS_ONE_OBJECT | Con la forma contenedora. |
| ALL_PARAGRAPHS_AT_ONCE | Todo el párrafo. |
| BY_LEVEL_PARAGRAPHS1 | Por grupos de párrafos de profundidad 1. |
| BY_LEVEL_PARAGRAPHS2 | Por grupos de párrafos de profundidad 2. |
| BY_LEVEL_PARAGRAPHS3 | Por grupos de párrafos de profundidad 3. |
| BY_LEVEL_PARAGRAPHS4 | Por grupos de párrafos de profundidad 4. |
| BY_LEVEL_PARAGRAPHS5 | Por grupos de párrafos de profundidad 5. |
