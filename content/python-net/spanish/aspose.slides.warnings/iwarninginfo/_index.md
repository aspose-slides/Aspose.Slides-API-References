## IWarningInfo clase

Representa una interfaz base para todas las advertencias.

El tipo IWarningInfo expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`warning_type`](/slides/python-net/es/aspose.slides.warnings/iwarninginfo/warning_type/) | Devuelve un tipo de advertencia.<br/>            Solo lectura [`IWarningInfo.warning_type`](/slides/python-net/es/aspose.slides.warnings/iwarninginfo/warning_type). |
| [`description`](/slides/python-net/es/aspose.slides.warnings/iwarninginfo/description/) | Devuelve una descripción legible por humanos de esta advertencia.<br/>            Solo lectura **str**. |

## Métodos

| Método | Descripción |
| :- | :- |
| [`send_warning(self, receiver)`](/slides/python-net/es/aspose.slides.warnings/iwarninginfo/send_warning/#iwarningcallback) | Si receiver no es None finaliza la advertencia a un receiver especificado y lanza la <br/>            AbortRequestedException si receiver decidió abortar una operación. |
