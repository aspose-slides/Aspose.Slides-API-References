Contiene clases que representan varios tipos de advertencias
## Clases

| Clase | Descripción |
| :- | :- |
| [`IKnownIssueWarningInfo`](/slides/python-net/es/aspose.slides.warnings/iknownissuewarninginfo/) | Representa una advertencia sobre un problema conocido que no se solucionará en un futuro cercano. |
| [`INotImplementedWarningInfo`](/slides/python-net/es/aspose.slides.warnings/inotimplementedwarninginfo/) | Representa una advertencia sobre una característica conocida no implementada que no se implementará en un futuro cercano. |
| [`IObsoletePresLockingBehaviorWarningInfo`](/slides/python-net/es/aspose.slides.warnings/iobsoletepreslockingbehaviorwarninginfo/) | Esta advertencia indica que se está utilizando un comportamiento de bloqueo de presentación obsoleto. |
| [`IPresentationSignedWarningInfo`](/slides/python-net/es/aspose.slides.warnings/ipresentationsignedwarninginfo/) | Esta advertencia indica que la presentación que se está leyendo tiene la firma <br/>            y que esta firma será eliminada durante el procesamiento. |
| [`IWarningCallback`](/slides/python-net/es/aspose.slides.warnings/iwarningcallback/) | Interfaz para clases que reciben advertencias |
| [`IWarningInfo`](/slides/python-net/es/aspose.slides.warnings/iwarninginfo/) | Representa una interfaz base para todas las advertencias. |

## Enumeraciones

| Enumeración | Descripción |
| :- | :- |
| [`ReturnAction`](/slides/python-net/es/aspose.slides.warnings/returnaction/) | Representa opciones de decisión de devolución de llamada de advertencia. |
| [`WarningType`](/slides/python-net/es/aspose.slides.warnings/warningtype/) | Representa un tipo de advertencia. |
