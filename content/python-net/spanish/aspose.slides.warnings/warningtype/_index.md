## WarningType enumeración

Representa un tipo de advertencia.

El tipo WarningType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| SOURCE_FILE_CORRUPTION | Se ha detectado un problema en el documento fuente que hace muy probable que el documento no pueda abrirse si se guarda en su formato original. |
| DATA_LOSS | El texto/gráfico/imagen u otros datos estarán completamente ausentes ya sea del árbol del documento después de la carga, o del documento creado después de guardar. |
| MAJOR_FORMATTING_LOSS | Pérdida importante de formato. |
| MINOR_FORMATTING_LOSS | Pérdida menor de formato. |
| COMPATIBILITY_ISSUE | Este es un problema conocido que impedirá que el documento sea abierto por ciertos agentes de usuario, o versiones anteriores de agentes de usuario. |
| UNEXPECTED_CONTENT | Algún contenido del documento fuente no pudo ser reconocido (es decir, no está soportado), lo que puede o no causar problemas o resultar en pérdida de datos/formato. |
