Contiene clases y métodos para manejar operaciones generales complejas de forma low code.
## Clases

| Clase | Descripción |
| :- | :- |
| [`Collect`](/slides/python-net/es/aspose.slides.lowcode/collect/) | Representa un grupo de métodos destinados a recopilar objetos de modelo de diferentes tipos de [`Presentation`](/slides/python-net/es/aspose.slides/presentation). |
| [`Compress`](/slides/python-net/es/aspose.slides.lowcode/compress/) | Representa un grupo de métodos destinados a comprimir [`Presentation`](/slides/python-net/es/aspose.slides/presentation). |
| [`Convert`](/slides/python-net/es/aspose.slides.lowcode/convert/) | Representa un grupo de métodos destinados a convertir [`Presentation`](/slides/python-net/es/aspose.slides/presentation). |
| [`ForEach`](/slides/python-net/es/aspose.slides.lowcode/foreach/) | Representa un grupo de métodos destinados a iterar sobre diferentes objetos de modelo [`Presentation`](/slides/python-net/es/aspose.slides/presentation).<br/>            Estos métodos pueden ser útiles si necesita iterar y cambiar el formato o el contenido de algunos elementos de Presentation,<br/>             p. ej. cambiar el formato de cada sección. |
| [`Merger`](/slides/python-net/es/aspose.slides.lowcode/merger/) | Representa un grupo de métodos para combinar presentaciones de PowerPoint del mismo formato en un solo archivo. |
