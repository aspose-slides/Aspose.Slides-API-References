## IVbaProject clase

Representa un proyecto VBA con macros de presentación.

El tipo IVbaProject expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`name`](/slides/python-net/es/aspose.slides.vba/ivbaproject/name/) | Devuelve el nombre del proyecto VBA.<br/>            Solo lectura **str**. |
| [`modules`](/slides/python-net/es/aspose.slides.vba/ivbaproject/modules/) | Devuelve la lista de todos los módulos que están contenidos en el proyecto VBA.<br/>            Solo lectura [`IVbaModuleCollection`](/slides/python-net/es/aspose.slides.vba/ivbamodulecollection). |
| [`references`](/slides/python-net/es/aspose.slides.vba/ivbaproject/references/) | Devuelve la lista de todas las referencias que están contenidas en el proyecto VBA.<br/>            Solo lectura [`IVbaReferenceCollection`](/slides/python-net/es/aspose.slides.vba/ivbareferencecollection). |
| [`is_password_protected`](/slides/python-net/es/aspose.slides.vba/ivbaproject/is_password_protected/) | Indica si el VBAProject está protegido por una contraseña para ver las propiedades del proyecto.<br/>            Solo lectura **bool**. |

## Métodos

| Método | Descripción |
| :- | :- |
| [`to_binary(self)`](/slides/python-net/es/aspose.slides.vba/ivbaproject/to_binary/#) | Devuelve la representación binaria del proyecto VBA como contenedor OLE.<br/>            Solo lectura **int**[]. |
