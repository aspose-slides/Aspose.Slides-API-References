## is_override_theme_enabled propiedad
Determina si OverrideTheme sobrescribe el tema efectivo heredado o no.
            Para habilitar OverrideTheme para la sobrescritura use los métodos OverrideTheme.Init*().
            Para deshabilitar OverrideTheme de la sobrescritura use el método OverrideTheme.Clear().
            Solo lectura **bool**.
