## IOverrideThemeManager clase

Proporciona acceso a diferentes tipos de temas sobrescritos.

El tipo IOverrideThemeManager expone los siguientes miembros:

## Propiedades

| Property | Description |
| :- | :- |
| [`is_override_theme_enabled`](/slides/python-net/es/aspose.slides.theme/ioverridethememanager/is_override_theme_enabled/) | Determina si OverrideTheme sobrescribe el tema efectivo heredado o no.<br/>            Para habilitar OverrideTheme para sobrescritura use los métodos OverrideTheme.Init*().<br/>            Para deshabilitar OverrideTheme de sobrescribir use el método OverrideTheme.Clear().<br/>            Solo lectura **bool**. |
| [`override_theme`](/slides/python-net/es/aspose.slides.theme/ioverridethememanager/override_theme/) | Devuelve el objeto del tema sobrescrito.<br/>            Lectura/escritura [`IOverrideTheme`](/slides/python-net/es/aspose.slides.theme/ioverridetheme). |
