## MasterTheme clase

Representa un tema maestro.

**Herencia:**[`MasterTheme`](/slides/python-net/es/aspose.slides.theme/mastertheme) → [`Theme`](/slides/python-net/es/aspose.slides.theme/theme)

El tipo MasterTheme expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`color_scheme`](/slides/python-net/es/aspose.slides.theme/mastertheme/color_scheme/) | Devuelve el esquema de colores.<br/>            Solo lectura [`IColorScheme`](/slides/python-net/es/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/es/aspose.slides.theme/mastertheme/font_scheme/) | Devuelve el esquema de fuentes.<br/>            Solo lectura [`IFontScheme`](/slides/python-net/es/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/es/aspose.slides.theme/mastertheme/format_scheme/) | Devuelve el esquema de formato de forma.<br/>            Solo lectura [`IFormatScheme`](/slides/python-net/es/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/es/aspose.slides.theme/mastertheme/presentation/) | Devuelve la presentación principal.<br/>            Solo lectura [`IPresentation`](/slides/python-net/es/aspose.slides/ipresentation). |
| [`extra_color_schemes`](/slides/python-net/es/aspose.slides.theme/mastertheme/extra_color_schemes/) | Devuelve la colección de esquemas de colores adicionales.<br/>            Estos esquemas no afectan el aspecto de la presentación, pueden seleccionarse como esquema de color principal para una diapositiva.<br/>            Solo lectura [`IExtraColorSchemeCollection`](/slides/python-net/es/aspose.slides.theme/iextracolorschemecollection). |
| [`name`](/slides/python-net/es/aspose.slides.theme/mastertheme/name/) | Devuelve el nombre de un tema.<br/>            Lectura/escritura **str**. |
