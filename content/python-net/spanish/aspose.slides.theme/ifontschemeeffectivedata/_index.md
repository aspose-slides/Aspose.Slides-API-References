## IFontSchemeEffectiveData clase

Objeto inmutable que contiene las propiedades del esquema de fuentes efectivo.

El tipo IFontSchemeEffectiveData expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`minor`](/slides/python-net/es/aspose.slides.theme/ifontschemeeffectivedata/minor/) | Devuelve la colección de fuentes para la parte "cuerpo" de la diapositiva.<br/>            Sólo lectura [`IFontsEffectiveData`](/slides/python-net/es/aspose.slides/ifontseffectivedata). |
| [`major`](/slides/python-net/es/aspose.slides.theme/ifontschemeeffectivedata/major/) | Devuelve la colección de fuentes para la parte "encabezado" de la diapositiva.<br/>            Sólo lectura [`IFontsEffectiveData`](/slides/python-net/es/aspose.slides/ifontseffectivedata). |
| [`name`](/slides/python-net/es/aspose.slides.theme/ifontschemeeffectivedata/name/) | Devuelve el nombre del esquema de fuentes.<br/>            Sólo lectura **str**. |
