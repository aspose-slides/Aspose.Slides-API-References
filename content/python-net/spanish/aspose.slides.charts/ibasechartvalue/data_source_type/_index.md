## data_source_type propiedad
Especifica si la propiedad AsCell o AsLiteralString o AsLiteralDouble es actual. En otras palabras, especifica el tipo de valor de la propiedad Data. Esta propiedad es de solo lectura. Para cambiar el valor de esta propiedad puede usar una de las propiedades ChartDataPointCollection.DataSourceTypeFor<...>.
