## Enumeración ChartType

Representa un tipo de gráfico.

El tipo ChartType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| CLUSTERED_COLUMN | Representa un gráfico de columnas agrupadas. |
| STACKED_COLUMN | Representa un gráfico de columnas apiladas. |
| PERCENTS_STACKED_COLUMN | Representa un gráfico de columnas apiladas al 100 %. |
| CLUSTERED_COLUMN_3D | Representa un gráfico de columnas agrupadas 3D. |
| STACKED_COLUMN_3D | Representa un gráfico de columnas apiladas 3D. |
| PERCENTS_STACKED_COLUMN_3D | Representa un gráfico de columnas apiladas al 100 % 3D. |
| COLUMN_3D | Representa un gráfico de columnas 3D. |
| CLUSTERED_CYLINDER | Representa un gráfico de cilindro. |
| STACKED_CYLINDER | Representa un gráfico de cilindro apilado. |
| PERCENTS_STACKED_CYLINDER | Representa un gráfico de cilindro apilado al 100 %. |
| CYLINDER_3D | Representa un gráfico de cilindro 3D. |
| CLUSTERED_CONE | Representa un gráfico de cono. |
| STACKED_CONE | Representa un gráfico de cono apilado. |
| PERCENTS_STACKED_CONE | Representa un gráfico de cono apilado al 100 %. |
| CONE_3D | Representa un gráfico de cono 3D. |
| CLUSTERED_PYRAMID | Representa un gráfico de pirámide. |
| STACKED_PYRAMID | Representa un gráfico de pirámide apilado. |
| PERCENTS_STACKED_PYRAMID | Representa un gráfico de pirámide apilado al 100 %. |
| PYRAMID_3D | Representa un gráfico de pirámide 3D. |
| LINE | Representa un gráfico de líneas. |
| STACKED_LINE | Representa un gráfico de líneas apilado. |
| PERCENTS_STACKED_LINE | Representa un gráfico de líneas apilado al 100 %. |
| LINE_WITH_MARKERS | Representa un gráfico de líneas con marcadores de datos. |
| STACKED_LINE_WITH_MARKERS | Representa un gráfico de líneas apilado con marcadores de datos. |
| PERCENTS_STACKED_LINE_WITH_MARKERS | Representa un gráfico de líneas apilado al 100 % con marcadores de datos. |
| LINE_3D | Representa un gráfico de líneas 3D. |
| PIE | Representa un gráfico circular. |
| PIE_3D | Representa un gráfico circular 3D. |
| PIE_OF_PIE | Representa un gráfico de pastel dentro de otro pastel. |
| EXPLODED_PIE | Representa un gráfico circular explotado. |
| EXPLODED_PIE_3D | Representa un gráfico circular 3D explotado. |
| BAR_OF_PIE | Representa un gráfico de barra dentro de pastel. |
| PERCENTS_STACKED_BAR | Representa un gráfico de barras apilado al 100 %. |
| CLUSTERED_BAR_3D | Representa un gráfico de barras agrupadas 3D. |
| CLUSTERED_BAR | Representa un gráfico de barras agrupadas. |
| STACKED_BAR | Representa un gráfico de barras apilado. |
| STACKED_BAR_3D | Representa un gráfico de barras apilado 3D. |
| PERCENTS_STACKED_BAR_3D | Representa un gráfico de barras apilado al 100 % 3D. |
| CLUSTERED_HORIZONTAL_CYLINDER | Representa un gráfico de barra cilíndrica. |
| STACKED_HORIZONTAL_CYLINDER | Representa un gráfico de barra cilíndrica apilada. |
| PERCENTS_STACKED_HORIZONTAL_CYLINDER | Representa un gráfico de barra cilíndrica apilada al 100 %. |
| CLUSTERED_HORIZONTAL_CONE | Representa un gráfico de barra cónica. |
| STACKED_HORIZONTAL_CONE | Representa un gráfico de barra cónica apilada. |
| PERCENTS_STACKED_HORIZONTAL_CONE | Representa un gráfico de barra cónica apilada al 100 %. |
| CLUSTERED_HORIZONTAL_PYRAMID | Representa un gráfico de barra piramidal. |
| STACKED_HORIZONTAL_PYRAMID | Representa un gráfico de barra piramidal apilada. |
| PERCENTS_STACKED_HORIZONTAL_PYRAMID | Representa un gráfico de barra piramidal apilada al 100 %. |
| AREA | Representa un gráfico de áreas. |
| STACKED_AREA | Representa un gráfico de áreas apilado. |
| PERCENTS_STACKED_AREA | Representa un gráfico de áreas apilado al 100 %. |
| AREA_3D | Representa un gráfico de áreas 3D. |
| STACKED_AREA_3D | Representa un gráfico de áreas apilado 3D. |
| PERCENTS_STACKED_AREA_3D | Representa un gráfico de áreas apilado al 100 % 3D. |
| SCATTER_WITH_MARKERS | Representa un gráfico de dispersión con marcadores de datos. |
| SCATTER_WITH_SMOOTH_LINES_AND_MARKERS | Representa un gráfico de dispersión conectado por curvas, con marcadores de datos. |
| SCATTER_WITH_SMOOTH_LINES | Representa un gráfico de dispersión conectado por curvas, sin marcadores de datos. |
| SCATTER_WITH_STRAIGHT_LINES_AND_MARKERS | Representa un gráfico de dispersión conectado por líneas rectas, con marcadores de datos. |
| SCATTER_WITH_STRAIGHT_LINES | Representa un gráfico de dispersión conectado por líneas rectas, sin marcadores de datos. |
| HIGH_LOW_CLOSE | Representa un gráfico de acciones Alto-Bajo-Cierre. |
| OPEN_HIGH_LOW_CLOSE | Representa un gráfico de acciones Apertura-Alto-Bajo-Cierre. |
| VOLUME_HIGH_LOW_CLOSE | Representa un gráfico de volumen Alto-Bajo-Cierre. |
| VOLUME_OPEN_HIGH_LOW_CLOSE | Representa un gráfico de volumen Apertura-Alto-Bajo-Cierre. |
| SURFACE_3D | Representa un gráfico de superficie 3D. |
| WIREFRAME_SURFACE_3D | Representa un gráfico de superficie 3D alámbrico. |
| CONTOUR | Representa un gráfico de contorno. |
| WIREFRAME_CONTOUR | Representa un gráfico de contorno alámbrico. |
| DOUGHNUT | Representa un gráfico de dona. |
| EXPLODED_DOUGHNUT | Representa un gráfico de dona explotado. |
| BUBBLE | Representa un gráfico de burbujas. |
| BUBBLE_WITH_3D | Representa un gráfico de burbujas 3D. |
| RADAR | Representa un gráfico de radar. |
| RADAR_WITH_MARKERS | Representa un gráfico de radar con marcadores de datos. |
| FILLED_RADAR | Representa un gráfico de radar relleno. |
| SERIES_OF_MIXED_TYPES | Este valor solo puede ser devuelto por la propiedad ChartEx.Type.<br/>            Significa que el gráfico tiene series de tipos mixtos. |
| TREEMAP | Representa un gráfico de treemap. |
| SUNBURST | Representa un gráfico Sunburst. |
| HISTOGRAM | Representa un gráfico de histograma. |
| PARETO_LINE | Representa una serie de línea Pareto (gráfico de histograma Pareto). |
| BOX_AND_WHISKER | Representa un gráfico de caja y bigotes. |
| WATERFALL | Representa un gráfico de cascada. |
| FUNNEL | Representa un gráfico de embudo. |
| MAP | Representa un gráfico de mapa. |
