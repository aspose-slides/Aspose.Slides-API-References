## AxisAggregationType enumeración

Representa el tipo de agregación del eje de categoría. Se usa solo con series Histogram o HistogramPareto.

El tipo AxisAggregationType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| BY_CATEGORY | Agregar por categorías |
| AUTOMATIC | Agregar categorías automáticamente. |
| BY_BIN_WIDTH | Agregar categorías por ancho de intervalo. La propiedad IAxis.BinWidth debe establecerse. |
| BY_NUMBER_OF_BINS | Agregar categorías por número de intervalos. La propiedad IAxis.NumberOfBins debe establecerse. |
