## PieSplitCustomPointCollection clase

Representa una colección de puntos para dividir un punto en un gráfico de barra-de-tarta o tarta-de-tarta con una división personalizada.

El tipo PieSplitCustomPointCollection expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`is_synchronized`](/slides/python-net/es/aspose.slides.charts/piesplitcustompointcollection/is_synchronized/) | Devuelve un valor que indica si el acceso a la colección está sincronizado (seguro para subprocesos).<br/>            Solo lectura **bool**. |
| [`sync_root`](/slides/python-net/es/aspose.slides.charts/piesplitcustompointcollection/sync_root/) | Devuelve la raíz de sincronización.<br/>            Solo lectura **any**. |

Devuelve el punto de datos del gráfico para el índice especificado.
