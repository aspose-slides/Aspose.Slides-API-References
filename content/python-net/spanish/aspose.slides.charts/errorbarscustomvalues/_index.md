## ErrorBarsCustomValues clase

Especifica los valores de la barra de errores. Sólo debe usarse cuando el tipo de valor de las barras de error es Custom.

El tipo ErrorBarsCustomValues expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`x_minus`](/slides/python-net/es/aspose.slides.charts/errorbarscustomvalues/x_minus/) | Especifica el valor de la barra de error en la dirección negativa. <br/>            Disponible si el tipo de valor de las barras de error es Custom y ErrorBarsXFormat está permitido.<br/>            En cualquier otro caso esta propiedad devuelve None.<br/>            Solo lectura [`IDoubleChartValue`](/slides/python-net/es/aspose.slides.charts/idoublechartvalue). |
| [`y_minus`](/slides/python-net/es/aspose.slides.charts/errorbarscustomvalues/y_minus/) | Especifica el valor de la barra de error en la dirección negativa. <br/>            Disponible si el tipo de valor de las barras de error es Custom y ErrorBarsYFormat está permitido. <br/>            En cualquier otro caso esta propiedad devuelve None. <br/>            Solo lectura [`IDoubleChartValue`](/slides/python-net/es/aspose.slides.charts/idoublechartvalue). |
