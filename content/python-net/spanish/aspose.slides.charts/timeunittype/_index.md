## TimeUnitType enumeración

Representa la unidad base para el eje de categorías

El tipo TimeUnitType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| NONE | Los valores se mostrarán tal cual. |
| DAYS | Especifica que los datos del gráfico se mostrarán en días. |
| MONTHS | Especifica que los datos del gráfico se mostrarán en meses. |
| YEARS | Especifica que los datos del gráfico se mostrarán en años. |
