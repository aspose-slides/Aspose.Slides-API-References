## ErrorBarValueType enumeración

Representa el tipo de valor de barra de error

El tipo ErrorBarValueType expone los siguientes miembros:

## Fields

| Campo | Descripción |
| :- | :- |
| CUSTOM | Especifica que la longitud de las barras de error se determinará por los elementos Plus y Minus. |
| FIXED | Especifica que la longitud de las barras de error será el valor fijo determinado por Error Bar Value. |
| PERCENTAGE | Especifica que la longitud de las barras de error será el porcentaje de Error Bar Value de los datos. |
| STANDARD_DEVIATION | Especifica que la longitud de las barras de error será las desviaciones estándar de Error Bar Value de los datos. |
| STANDARD_ERROR | Especifica que la longitud de las barras de error será los errores estándar de Error Bar Value de los datos. |
