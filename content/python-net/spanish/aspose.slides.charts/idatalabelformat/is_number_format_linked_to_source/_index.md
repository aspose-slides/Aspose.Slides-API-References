## is_number_format_linked_to_source propiedad
Lectura/escritura **bool**.

### Comentarios

Si el padre de este objeto DataLabelFormat es una colección DataLabelCollection de etiquetas de datos, entonces esta propiedad obtiene o establece el valor predeterminado de la propiedad IsNumberFormatLinkedToSource para las nuevas etiquetas de datos en la colección DataLabelCollection.  
Establecer esta propiedad con valor también asigna ese valor a la propiedad IsNumberFormatLinkedToSource para todas las etiquetas de datos en la colección DataLabelCollection (i.e. "DataLabels.DefaultDataLabelFormat.IsNumberFormatLinkedToSource = val;" cause to all DataLabels[i].IsNumberFormatLinkedToSource is equal to val).
