## TickLabelPositionType enumeración

Representa el tipo de posición de las etiquetas de marcas de graduación en el eje especificado.

El tipo TickLabelPositionType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| HIGH | Especifica que las etiquetas del eje estarán en el extremo alto del eje perpendicular. |
| LOW | Especifica que las etiquetas del eje estarán en el extremo bajo del eje perpendicular. |
| NEXT_TO | Especifica que las etiquetas del eje estarán junto al eje. |
| NONE | Especifica que las etiquetas del eje no se dibujan. |
