## ChartCellCollection clase

Representa una colección de celdas con datos.

El tipo ChartCellCollection expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`count`](/slides/python-net/es/aspose.slides.charts/chartcellcollection/count/) | Obtiene el recuento de celdas en la colección.<br/>            Solo lectura **int**. |

Devuelve una celda (IChartDataCell) por índice.

## Indexador

| Nombre | Descripción |
| :- | :- |
| [`[index]`](/slides/python-net/es/aspose.slides.charts/chartcellcollection/__getitem__/) | Índice de una celda. |

## Métodos

| Método | Descripción |
| :- | :- |
| [`add(self, cell)`](/slides/python-net/es/aspose.slides.charts/chartcellcollection/add/#ichartdatacell) | Añade una nueva celda a la colección. |
| [`add(self, value)`](/slides/python-net/es/aspose.slides.charts/chartcellcollection/add/#any) | Crea [`ChartDataCell`](/slides/python-net/es/aspose.slides.charts/chartdatacell) a partir del valor especificado y lo añade a la colección. |
| [`get_cells_address(self)`](/slides/python-net/es/aspose.slides.charts/chartcellcollection/get_cells_address/#) | Devuelve la dirección del conjunto de celdas en el libro de trabajo. |
| [`get_concatenated_values_from_cells(self)`](/slides/python-net/es/aspose.slides.charts/chartcellcollection/get_concatenated_values_from_cells/#) | Cadena de concatenación de los valores de cadena de todas las celdas. |
| [`remove_at(self, index)`](/slides/python-net/es/aspose.slides.charts/chartcellcollection/remove_at/#int) | Elimina una celda de la colección por índice. |
