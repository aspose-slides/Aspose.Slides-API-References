## IMarker clase

Representa el marcador de un chert.

El tipo IMarker expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`symbol`](/slides/python-net/es/aspose.slides.charts/imarker/symbol/) | Representa el estilo del marcador en un gráfico de líneas, gráfico de dispersión o gráfico de radar.<br/>            Lectura/escritura [`MarkerStyleType`](/slides/python-net/es/aspose.slides.charts/markerstyletype). |
| [`format`](/slides/python-net/es/aspose.slides.charts/imarker/format/) | Obtiene el relleno del marcador.<br/>            Solo lectura [`IFormat`](/slides/python-net/es/aspose.slides.charts/iformat). |
| [`size`](/slides/python-net/es/aspose.slides.charts/imarker/size/) | Representa el tamaño del marcador en un gráfico de líneas, gráfico de dispersión o gráfico de radar.<br/>            Lectura/escritura **int**. |
