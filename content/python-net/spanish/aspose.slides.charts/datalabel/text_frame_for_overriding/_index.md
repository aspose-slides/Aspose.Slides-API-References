## text_frame_for_overriding propiedad
Puede contener un texto con formato enriquecido. Si esta propiedad no es None entonces este 
            el valor de texto formateado sobrescribe el texto autogenerado de la etiqueta de datos.
            El texto autogenerado de la etiqueta de datos significa el texto que es manejado por las propiedades ShowSeriesName, 
            ShowValue, ... y que está formateado con la propiedad TextFormatManager.TextFormat.
            Solo lectura [`ITextFrame`](/slides/python-net/es/aspose.slides/itextframe).
