## is_visible propiedad
False means that data label is not visible (and so all Show*-flags (ShowValue, ...) are false).
            Solo lectura **bool**.


### Observaciones

            Si la etiqueta de datos es visible, puede ocultarla con el método Hide().
            Pero si la etiqueta de datos no es visible (IsVisible es false) puede hacerla visible estableciendo las banderas Show*-flags (ShowValue, ...) en estado true.
