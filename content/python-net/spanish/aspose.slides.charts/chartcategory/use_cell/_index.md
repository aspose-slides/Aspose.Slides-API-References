## propiedad use_cell
Si es true entonces la propiedad AsCell es actual. En otras palabras, la hoja de cálculo se utiliza para almacenar la categoría (este caso admite una categoría de varios niveles).
Si es false entonces la propiedad AsLiteral es actual. En otras palabras, la hoja de cálculo NO se utiliza para almacenar la categoría (y este caso no admite categorías de varios niveles).
Solo lectura **bool**.


### Observaciones

Para cambiar el valor de esta propiedad (para todas las categorías en la colección) establezca el nuevo valor en la propiedad ChartCategoryCollection.UseCells.
