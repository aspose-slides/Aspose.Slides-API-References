## enumeración ErrorBarType

Representa el tipo de barra de error

El tipo ErrorBarType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| BOTH | Especifica que las barras de error se deben mostrar en las direcciones positiva y negativa. |
| MINUS | Especifica que las barras de error se deben mostrar solo en la dirección negativa. |
| PLUS | Especifica que las barras de error se deben mostrar solo en la dirección positiva. |
