## DataSourceType enumeración

Tipos de origen de datos.

El tipo DataSourceType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| WORKSHEET | Utilice objetos CellXls para almacenar XValue, YValue, Value o BubbleSize del punto de datos en la hoja de cálculo. |
| STRING_LITERALS | Utilice una variable de cadena de acceso rápido para almacenar XValue, YValue, Value o BubbleSize del <br/>            punto de datos. La hoja de cálculo NO se utiliza para almacenar valores. |
| DOUBLE_LITERALS | Utilice una variable double de acceso rápido para almacenar XValue, YValue, Value o BubbleSize del <br/>            punto de datos. La hoja de cálculo NO se utiliza para almacenar valores. |
