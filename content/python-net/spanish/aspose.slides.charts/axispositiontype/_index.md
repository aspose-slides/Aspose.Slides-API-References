## AxisPositionType enumeración

Determina una posición del eje.

El tipo AxisPositionType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| BOTTOM | Especifica que el eje se mostrará en la parte inferior del área de trazado. |
| LEFT | Especifica que el eje se mostrará en el lado izquierdo del área de trazado. |
| RIGHT | Especifica que el eje se mostrará en el lado derecho del área de trazado. |
| TOP | Especifica que el eje se mostrará en la parte superior del área de trazado. |
