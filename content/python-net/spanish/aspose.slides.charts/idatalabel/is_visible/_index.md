## is_visible propiedad
False indica que la etiqueta de datos no es visible (y por lo tanto todas las banderas Show*-flags (ShowValue, ...) son falsas).
            Solo lectura **bool**.

### Comentarios

Si la etiqueta de datos es visible, puedes ocultarla con el método Hide().
            Pero si la etiqueta de datos no es visible (IsVisible es false), puedes hacerla visible estableciendo las banderas Show*-flags (ShowValue, ...) en estado true.
