## hide(self) {#}
Oculta la etiqueta de datos estableciendo todas las banderas Show*- (ShowValue, ...) al estado false.
            IsVisible será false después de esto.

```python
def hide(self):
    ...
```

### Observaciones

Si la etiqueta de datos no es visible (IsVisible es false) puedes hacer la etiqueta de datos visible con 
            estableciendo las banderas Show*- (ShowValue, ...) al estado true.
