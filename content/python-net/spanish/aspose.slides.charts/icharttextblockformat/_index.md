## IChartTextBlockFormat clase

Representa las propiedades de formato para los elementos de texto del gráfico.

El tipo IChartTextBlockFormat expone los siguientes miembros:

## Propiedades

| Property | Description |
| :- | :- |
| [`anchoring_type`](/slides/python-net/es/aspose.slides.charts/icharttextblockformat/anchoring_type/) | Devuelve o establece el texto de anclaje vertical en un TextFrame.<br/>            Lectura/escritura [`TextAnchorType`](/slides/python-net/es/aspose.slides/textanchortype). |
| [`center_text`](/slides/python-net/es/aspose.slides.charts/icharttextblockformat/center_text/) | Si NullableBool.True, el texto debe centrarse horizontalmente en el recuadro.<br/>            Lectura/escritura [`NullableBool`](/slides/python-net/es/aspose.slides/nullablebool). |
| [`text_vertical_type`](/slides/python-net/es/aspose.slides.charts/icharttextblockformat/text_vertical_type/) | Determina la orientación del texto.<br/>            El valor resultante de la rotación visual del texto resumido a partir de esta propiedad y del ángulo personalizado<br/>            en la propiedad RotationAngle.<br/>            Lectura/escritura [`TextVerticalType`](/slides/python-net/es/aspose.slides/textverticaltype). |
| [`margin_left`](/slides/python-net/es/aspose.slides.charts/icharttextblockformat/margin_left/) | Devuelve o establece el margen izquierdo (puntos) en un TextFrame.<br/>            Cambiar esta propiedad puede producir cierta influencia solo para estas partes del gráfico: <br/>            DataLabel y DataLabelFormat (soporte completo en PowerPoint 2013; en PowerPoint 2007 no hay efecto en la renderización).<br/>            Lectura/escritura **float**. |
| [`margin_right`](/slides/python-net/es/aspose.slides.charts/icharttextblockformat/margin_right/) | Devuelve o establece el margen derecho (puntos) en un TextFrame.<br/>            Cambiar esta propiedad puede producir cierta influencia solo para estas partes del gráfico: <br/>            DataLabel y DataLabelFormat (soporte completo en PowerPoint 2013; en PowerPoint 2007 no hay efecto en la renderización).<br/>            Lectura/escritura **float**. |
| [`margin_top`](/slides/python-net/es/aspose.slides.charts/icharttextblockformat/margin_top/) | Devuelve o establece el margen superior (puntos) en un TextFrame.<br/>            Cambiar esta propiedad puede producir cierta influencia solo para estas partes del gráfico: <br/>            DataLabel y DataLabelFormat (soporte completo en PowerPoint 2013; en PowerPoint 2007 no hay efecto en la renderización).<br/>            Lectura/escritura **float**. |
| [`margin_bottom`](/slides/python-net/es/aspose.slides.charts/icharttextblockformat/margin_bottom/) | Devuelve o establece el margen inferior (puntos) en un TextFrame.<br/>            Cambiar esta propiedad puede producir cierta influencia solo para estas partes del gráfico: <br/>            DataLabel y DataLabelFormat (soporte completo en PowerPoint 2013; en PowerPoint 2007 no hay efecto en la renderización).<br/>            Lectura/escritura **float**. |
| [`wrap_text`](/slides/python-net/es/aspose.slides.charts/icharttextblockformat/wrap_text/) | **True**  si el texto se ajusta a los márgenes del TextFrame.<br/>            Cambiar esta propiedad puede producir cierta influencia solo para estas partes del gráfico: <br/>            DataLabel y DataLabelFormat (soporte completo en PowerPoint 2007/2013).<br/>            Lectura/escritura [`NullableBool`](/slides/python-net/es/aspose.slides/nullablebool). |
| [`autofit_type`](/slides/python-net/es/aspose.slides.charts/icharttextblockformat/autofit_type/) | Devuelve o establece el modo de ajuste automático del texto.<br/>            Cambiar esta propiedad puede producir cierta influencia solo para estas partes del gráfico: <br/>            DataLabel y DataLabelFormat (soporte completo en PowerPoint 2013; en PowerPoint 2007 no hay efecto en la renderización).<br/>            Lectura/escritura [`TextAutofitType`](/slides/python-net/es/aspose.slides/textautofittype). |
| [`rotation_angle`](/slides/python-net/es/aspose.slides.charts/icharttextblockformat/rotation_angle/) | Especifica la rotación personalizada que se aplica al texto dentro del cuadro delimitador. Si no se<br/>            especifica, se usa la rotación de la forma asociada. Si se especifica, esto se<br/>            aplica independientemente de la forma. Es decir, la forma puede tener una rotación aplicada y<br/>            además el texto mismo tener una rotación aplicada.<br/>            El valor resultante de la rotación visual del texto resumido a partir de esta propiedad y del tipo<br/>            vertical predefinido en la propiedad TextVerticalType.<br/>            Lectura/escritura **float**. |
