## error_bars_y_format propiedad
Representa ErrorBars de series con dirección Y.

            ErrorBars con dirección Y están disponibles para series de tipo area, bar, line, scatter y bubble. 
            Para cualquier otro tipo de gráfico esta propiedad devuelve None (incluidos los gráficos 3D). 
            En caso de valores personalizados use la colección DataPoints para especificar el valor
            (con la propiedad [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/es/aspose.slides.charts/ichartdatapoint/error_bars_custom_values)).

            Solo lectura [`IErrorBarsFormat`](/slides/python-net/es/aspose.slides.charts/ierrorbarsformat).
