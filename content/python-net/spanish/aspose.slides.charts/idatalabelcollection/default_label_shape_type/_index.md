## default_label_shape_type propiedad
Obtiene o establece el tipo de forma predeterminado para las etiquetas de datos.
             Devuelve [`ShapeType.NOT_DEFINED`](/slides/python-net/es/aspose.slides/shapetype/NOT_DEFINED) si no se define una forma.


### Observaciones

Establecer esta propiedad también establece la propiedad [`IDataLabel.label_shape_type`](/slides/python-net/es/aspose.slides.charts/idatalabel/label_shape_type) para todas las etiquetas de datos en la colección al mismo valor.
