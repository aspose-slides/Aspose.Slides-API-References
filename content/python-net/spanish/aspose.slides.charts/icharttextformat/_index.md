## IChartTextFormat clase

El gráfico opera con un conjunto restringido de propiedades de formato de texto.
            IChartTextFormat, IChartTextBlockFormat, IChartParagraphFormat, IChartPortionFormat describen este conjunto restringido.

El tipo IChartTextFormat expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`text_block_format`](/slides/python-net/es/aspose.slides.charts/icharttextformat/text_block_format/) | Devuelve el formato para los elementos de texto del gráfico.<br/>            Solo lectura [`IChartTextBlockFormat`](/slides/python-net/es/aspose.slides.charts/icharttextblockformat). |
| [`paragraph_format`](/slides/python-net/es/aspose.slides.charts/icharttextformat/paragraph_format/) | Devuelve el formato de párrafo.<br/>            Solo lectura [`IChartParagraphFormat`](/slides/python-net/es/aspose.slides.charts/ichartparagraphformat). |
| [`portion_format`](/slides/python-net/es/aspose.slides.charts/icharttextformat/portion_format/) | Devuelve el formato de porción.<br/>            Solo lectura [`IChartPortionFormat`](/slides/python-net/es/aspose.slides.charts/ichartportionformat). |
