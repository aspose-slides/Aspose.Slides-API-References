## smooth propiedad
Representa el suavizado de curvas. True si el suavizado de curvas está activado para el gráfico de líneas o el gráfico de dispersión. Se aplica solo a los gráficos de líneas y de dispersión conectados por líneas.
            Lectura/escritura **bool**.
