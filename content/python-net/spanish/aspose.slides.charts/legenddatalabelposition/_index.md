## Enumeración LegendDataLabelPosition

Determina la posición de las etiquetas de datos.

El tipo LegendDataLabelPosition expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| NOT_DEFINED | La posición no está definida. |
| BOTTOM | Especifica que las etiquetas de datos se mostrarán debajo del marcador de datos. |
| BEST_FIT | Especifica que las etiquetas de datos se mostrarán en la mejor posición. |
| CENTER | Especifica que las etiquetas de datos se mostrarán centradas en el marcador de datos. |
| INSIDE_BASE | Especifica que las etiquetas de datos se mostrarán dentro de la base del marcador de datos. |
| INSIDE_END | Especifica que las etiquetas de datos se mostrarán dentro del extremo del marcador de datos. |
| LEFT | Especifica que las etiquetas de datos se mostrarán a la izquierda del marcador de datos. |
| OUTSIDE_END | Especifica que las etiquetas de datos se mostrarán fuera del extremo del marcador de datos. |
| RIGHT | Especifica que las etiquetas de datos se mostrarán a la derecha del marcador de datos. |
| TOP | Especifica que las etiquetas de datos se mostrarán encima del marcador de datos. |
