## is_visible propiedad
False significa que la etiqueta de datos no es visible por defecto (y por lo tanto todos 
            Show*-flags (ShowValue, ...) de la DefaultDataLabelFormat propiedad son false).
            Solo lectura **bool**.

### Observaciones

Si la etiqueta de datos es visible por defecto, puedes hacerla oculta por defecto con el método Hide().
            Pero si la etiqueta de datos no es visible por defecto (IsVisible es false), puedes hacer que la etiqueta de datos "visible por defecto" configurando los Show*-flags (ShowValue, ...) de la DefaultDataLabelFormat propiedad a estado true.
