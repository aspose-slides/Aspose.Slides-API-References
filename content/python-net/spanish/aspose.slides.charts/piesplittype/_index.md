## PieSplitType enumeración

Representa un tipo de puntos de división en el segundo pastel o barra en un gráfico de pie-of-pie o bar-of-pie.

El tipo PieSplitType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| DEFAULT | Especifica que los puntos de datos deben dividirse usando el mecanismo predeterminado <br/>            para este tipo de gráfico. |
| CUSTOM | Especifica que los puntos de datos deben dividirse entre el <br/>            pastel y el segundo gráfico según los valores de división personalizados. |
| BY_PERCENTAGE | Especifica que los puntos de datos deben dividirse entre el pastel y el <br/>            segundo gráfico colocando los puntos con porcentaje menor al Split Position percent en el segundo gráfico. |
| BY_POS | Especifica que los puntos de datos deben dividirse entre el pastel y el <br/>            segundo gráfico colocando la última Split Position de los puntos de datos <br/>            en el segundo gráfico. |
| BY_VALUE | Especifica que los puntos de datos deben dividirse entre el pastel y el <br/>            segundo gráfico colocando los puntos de datos con valor inferior a Split Position en el segundo gráfico. |
