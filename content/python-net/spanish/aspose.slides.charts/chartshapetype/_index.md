## ChartShapeType enumeración

Representa una forma de gráfico.

El tipo ChartShapeType expone los siguientes miembros:

## Campos

| Field | Description |
| :- | :- |
| NOT_DEFINED | La forma del gráfico no está definida. |
| BOX | Especifica que el gráfico se dibujará con una forma de caja. |
| CONE | Especifica que el gráfico se dibujará como un cono, con la base del cono en el suelo y el punto del cono en la parte superior del marcador de datos. |
| CONE_TO_MAX | Especifica que el gráfico se dibujará con conos truncados de modo que el punto del cono corresponderá al valor máximo de los datos. |
| CYLINDER | Especifica que el gráfico se dibujará como un cilindro. |
| PYRAMID | Especifica que el gráfico se dibujará como una pirámide rectangular, con la base de la pirámide en el suelo y el punto de la pirámide en la parte superior del marcador de datos. |
| PYRAMID_TO_MAXIMUM | Especifica que el gráfico se dibujará con conos truncados de modo que el punto del cono corresponda al valor máximo de los datos. |
