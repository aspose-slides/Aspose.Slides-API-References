## IChartDataPointLevel clase

Representa el nivel del punto de datos. Se aplica a los gráficos Treemap y Sunburst.

El tipo IChartDataPointLevel expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`format`](/slides/python-net/es/aspose.slides.charts/ichartdatapointlevel/format/) | Representa las propiedades de formato del nivel del punto de datos.<br/>            Read/write [`IFormat`](/slides/python-net/es/aspose.slides.charts/iformat). |
| [`label`](/slides/python-net/es/aspose.slides.charts/ichartdatapointlevel/label/) | Representa la etiqueta de datos del nivel del punto de datos. Aplicado a los tipos de serie Treemap y Sunburst.<br/>             Read-only [`IDataLabel`](/slides/python-net/es/aspose.slides.charts/idatalabel). |
