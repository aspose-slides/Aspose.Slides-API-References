## IChartCellCollection clase

Representa una colección de celdas con datos.

El tipo IChartCellCollection expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`count`](/slides/python-net/es/aspose.slides.charts/ichartcellcollection/count/) | Obtiene la cantidad de celdas en la colección.<br/>            Sólo lectura **int**. |

Devuelve una celda (IChartDataCell) por índice.

## Indexador

| Nombre | Descripción |
| :- | :- |
| [`[index]`](/slides/python-net/es/aspose.slides.charts/ichartcellcollection/__getitem__/) | Índice de una celda. |

## Métodos

| Método | Descripción |
| :- | :- |
| [`add(self, chart_data_cell)`](/slides/python-net/es/aspose.slides.charts/ichartcellcollection/add/#ichartdatacell) | Añade una nueva celda a la colección. |
| [`add(self, value)`](/slides/python-net/es/aspose.slides.charts/ichartcellcollection/add/#any) | Crea [`IChartDataCell`](/slides/python-net/es/aspose.slides.charts/ichartdatacell) a partir del valor especificado y lo añade a la colección. |
| [`get_cells_address(self)`](/slides/python-net/es/aspose.slides.charts/ichartcellcollection/get_cells_address/#) | Devuelve la dirección del conjunto de celdas en el libro de trabajo. |
| [`get_concatenated_values_from_cells(self)`](/slides/python-net/es/aspose.slides.charts/ichartcellcollection/get_concatenated_values_from_cells/#) | Cadena de concatenación de los valores de cadena de todas las celdas. |
| [`remove_at(self, index)`](/slides/python-net/es/aspose.slides.charts/ichartcellcollection/remove_at/#int) | Elimina una celda de la colección por índice. |
