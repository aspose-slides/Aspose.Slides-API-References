## IActualLayout clase

Especifica la posición real de un elemento de gráfico.

El tipo IActualLayout expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`actual_x`](/slides/python-net/es/aspose.slides.charts/iactuallayout/actual_x/) | Especifica la ubicación x real (izquierda) del elemento de gráfico relativa a la esquina superior izquierda del gráfico.<br/>            Llame al método IChart.ValidateChartLayout() antes para obtener los valores reales. <br/>            Leer **float**. |
| [`actual_y`](/slides/python-net/es/aspose.slides.charts/iactuallayout/actual_y/) | Especifica la parte superior real del elemento de gráfico relativa a la esquina superior izquierda del gráfico.<br/>            Llame al método IChart.ValidateChartLayout() antes para obtener los valores reales. <br/>            Leer **float**. |
| [`actual_width`](/slides/python-net/es/aspose.slides.charts/iactuallayout/actual_width/) | Especifica el ancho real del elemento de gráfico. Llame al método IChart.ValidateChartLayout() antes para obtener los valores reales. <br/>            Leer **float**. |
| [`actual_height`](/slides/python-net/es/aspose.slides.charts/iactuallayout/actual_height/) | Especifica la altura real del elemento de gráfico. Llame al método IChart.ValidateChartLayout() antes para obtener los valores reales. <br/>            Leer **float**. |
