## IErrorBarsCustomValues clase

Especifica los valores de las barras de error. Sólo se debe usar cuando el tipo de valor de las barras de error es Custom.

El tipo IErrorBarsCustomValues expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`x_minus`](/slides/python-net/es/aspose.slides.charts/ierrorbarscustomvalues/x_minus/) | Especifica el valor de la barra de error en la dirección negativa. <br/>            Disponible si el tipo de valor de las barras de error es Custom y se permite ErrorBarsXFormat.<br/>            En cualquier otro caso esta propiedad devuelve None.  <br/>            Solo lectura [`IDoubleChartValue`](/slides/python-net/es/aspose.slides.charts/idoublechartvalue). |
| [`y_minus`](/slides/python-net/es/aspose.slides.charts/ierrorbarscustomvalues/y_minus/) | Especifica el valor de la barra de error en la dirección negativa. <br/>            Disponible si el tipo de valor de las barras de error es Custom y se permite ErrorBarsYFormat.<br/>            En cualquier otro caso esta propiedad devuelve None. <br/>            Solo lectura [`IDoubleChartValue`](/slides/python-net/es/aspose.slides.charts/idoublechartvalue). |
| [`x_plus`](/slides/python-net/es/aspose.slides.charts/ierrorbarscustomvalues/x_plus/) | Especifica el valor de la barra de error en la dirección positiva. <br/>            Disponible si el tipo de valor de las barras de error es Custom y se permite ErrorBarsXFormat.<br/>            En cualquier otro caso esta propiedad devuelve None. <br/>            Solo lectura [`IDoubleChartValue`](/slides/python-net/es/aspose.slides.charts/idoublechartvalue). |
| [`y_plus`](/slides/python-net/es/aspose.slides.charts/ierrorbarscustomvalues/y_plus/) | Especifica el valor de la barra de error en la dirección positiva. <br/>            Disponible si el tipo de valor de las barras de error es Custom y se permite ErrorBarsYFormat.<br/>            En cualquier otro caso esta propiedad devuelve None. <br/>            Solo lectura [`IDoubleChartValue`](/slides/python-net/es/aspose.slides.charts/idoublechartvalue). |
