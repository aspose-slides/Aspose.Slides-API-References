## use_secondary_categories propiedad
Si es falso, entonces la propiedad [`ChartData.secondary_categories`](/slides/python-net/es/aspose.slides.charts/chartdata/secondary_categories) devuelve None y los datos
            en la propiedad [`ChartData.categories`](/slides/python-net/es/aspose.slides.charts/chartdata/categories) se usan tanto para la serie primaria como para la serie secundaria.
            Si es verdadero, entonces los datos en la propiedad [`ChartData.secondary_categories`](/slides/python-net/es/aspose.slides.charts/chartdata/secondary_categories) se usan para la serie secundaria y los datos
            en la propiedad [`ChartData.categories`](/slides/python-net/es/aspose.slides.charts/chartdata/categories) se usan para la serie primaria.
            Lectura/escritura **bool**.
