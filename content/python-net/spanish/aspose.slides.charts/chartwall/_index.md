## ChartWall clase

Representa paredes en gráficos 3d.

El tipo ChartWall expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`thickness`](/slides/python-net/es/aspose.slides.charts/chartwall/thickness/) | Devuelve o establece el grosor de las paredes como un porcentaje de la mayor <br/>            dimensión del volumen del trazado.<br/>            Lectura/escritura **int**. |
| [`format`](/slides/python-net/es/aspose.slides.charts/chartwall/format/) | Devuelve el relleno, línea, efecto y estilos 3d de la pared.<br/>            Solo lectura [`IFormat`](/slides/python-net/es/aspose.slides.charts/iformat). |
| [`picture_type`](/slides/python-net/es/aspose.slides.charts/chartwall/picture_type/) | Devuelve o establece el tipo de imagen.<br/>            Lectura/escritura [`PictureType`](/slides/python-net/es/aspose.slides.charts/picturetype). |
