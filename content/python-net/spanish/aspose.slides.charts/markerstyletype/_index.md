## MarkerStyleType enumeración

Determina la forma del marcador en el punto de datos del gráfico.

El tipo MarkerStyleType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| NOT_DEFINED |  |
| CIRCLE | Especifica que se debe dibujar un círculo en cada punto de datos. |
| DASH | Especifica que se debe dibujar un guion en cada punto de datos. |
| DIAMOND | Especifica que se debe dibujar un rombo en cada punto de datos. |
| DOT | Especifica que se debe dibujar un punto en cada punto de datos. |
| NONE | Especifica que no se debe dibujar nada en cada punto de datos. |
| PICTURE | Especifica que se debe dibujar una imagen en cada punto de datos. |
| PLUS | Especifica que se debe dibujar un signo más en cada punto de datos. |
| SQUARE | Especifica que se debe dibujar un cuadrado en cada punto de datos. |
| STAR | Especifica que se debe dibujar una estrella en cada punto de datos. |
| TRIANGLE | Especifica que se debe dibujar un triángulo en cada punto de datos. |
| X | Especifica que se debe dibujar una X en cada punto de datos. |
