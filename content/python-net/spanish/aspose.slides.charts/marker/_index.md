## Clase Marker

Representa el marcador de una pizarra.

El tipo Marker expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`symbol`](/slides/python-net/es/aspose.slides.charts/marker/symbol/) | Representa el estilo del marcador en un gráfico de líneas, gráfico de dispersión o gráfico de radar.<br/>            Lectura/escritura [`MarkerStyleType`](/slides/python-net/es/aspose.slides.charts/markerstyletype). |
| [`format`](/slides/python-net/es/aspose.slides.charts/marker/format/) | Obtiene o establece el relleno del marcador.<br/>            Solo lectura [`IFormat`](/slides/python-net/es/aspose.slides.charts/iformat). |
| [`size`](/slides/python-net/es/aspose.slides.charts/marker/size/) | Representa el tamaño del marcador en un gráfico de líneas, gráfico de dispersión o gráfico de radar.<br/>            Lectura/escritura **int**. |
