## WorkbookType enumeración

Especifica el tipo de archivo de libro de trabajo Open XML.

El tipo WorkbookType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| NOT_DEFINED | El tipo de libro de trabajo no está definido. |
| WORKBOOK | Libro de Excel (*.xlsx). |
| WORKBOOK_MACRO | Libro de Excel con macros (*.xlsm). |
| TEMPLATE | Plantilla de Excel (*.xltx). |
| TEMPLATE_MACRO | Plantilla de Excel con macros (*.xltm). |
| WORKBOOK_BINARY_MACRO | Libro de Excel binario con macros (*.xlsb). |
