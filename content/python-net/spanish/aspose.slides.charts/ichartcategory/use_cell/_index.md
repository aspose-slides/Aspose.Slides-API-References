## use_cell propiedad
Si es verdadero, entonces la propiedad AsCell es real. En otras palabras, la hoja de cálculo se usa para almacenar la categoría (este caso admite una categoría de varios niveles).
Si es falso, entonces la propiedad AsLiteral es real. En otras palabras, la hoja de cálculo NO se usa para almacenar la categoría (y este caso no admite categorías de varios niveles).
Solo lectura **bool**.

### Observaciones

Para cambiar el valor de esta propiedad (para todas las categorías en la colección) establezca el nuevo valor en la propiedad ChartCategoryCollection.UseCells.
