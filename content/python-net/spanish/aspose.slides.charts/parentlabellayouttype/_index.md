## enumeración ParentLabelLayoutType

Representa la distribución de las etiquetas de datos de categoría. Se usa solo con series Treemap.

El tipo ParentLabelLayoutType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| BANNER | Especifica que las etiquetas de categoría principal se muestran como banner |
| NONE | Especifica que las etiquetas de categoría principal no se dibujan |
| OVERLAPPING | Especifica que las etiquetas de categoría principal se muestran superpuestas |
