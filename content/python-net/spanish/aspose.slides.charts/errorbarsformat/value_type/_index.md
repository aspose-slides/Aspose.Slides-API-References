## value_type propiedad
Representa las posibles formas de determinar la longitud de las barras de error. 
            En el caso de un tipo de valor personalizado, para especificar el valor use la propiedad [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/es/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) del punto de datos específico en la colección DataPoints de la serie.
            En el caso de los tipos de valor Fixed, Percentage o StandardDeviation, use la propiedad Value para especificar el valor.  
            Lectura/escritura [`ErrorBarValueType`](/slides/python-net/es/aspose.slides.charts/errorbarvaluetype).
