## Clase Legend

Representa las propiedades de la leyenda del gráfico.

El tipo Legend expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`x`](/slides/python-net/es/aspose.slides.charts/legend/x/) | Devuelve o establece la coordenada x de una leyenda como una fracción del ancho del gráfico.<br/>            Lectura/escritura **float**. |
| [`y`](/slides/python-net/es/aspose.slides.charts/legend/y/) | Devuelve o establece la coordenada y de una leyenda como una fracción de la altura del gráfico.<br/>            Lectura/escritura **float**. |
| [`width`](/slides/python-net/es/aspose.slides.charts/legend/width/) | Devuelve o establece el ancho de una leyenda como una fracción del ancho del gráfico.<br/>            Lectura/escritura **float**. |
| [`height`](/slides/python-net/es/aspose.slides.charts/legend/height/) | Devuelve o establece la altura de una leyenda como una fracción de la altura del gráfico.<br/>            Lectura/escritura **float**. |
| [`right`](/slides/python-net/es/aspose.slides.charts/legend/right/) | Derecha.<br/>            Solo lectura **float**. |
| [`bottom`](/slides/python-net/es/aspose.slides.charts/legend/bottom/) | Inferior.<br/>            Solo lectura **float**. |
| [`overlay`](/slides/python-net/es/aspose.slides.charts/legend/overlay/) | Determina si otros elementos del gráfico pueden superponerse a la leyenda.<br/>            Lectura/escritura **bool**. |
| [`text_format`](/slides/python-net/es/aspose.slides.charts/legend/text_format/) | Formato de texto.<br/>            Solo lectura [`IChartTextFormat`](/slides/python-net/es/aspose.slides.charts/icharttextformat). |
| [`position`](/slides/python-net/es/aspose.slides.charts/legend/position/) | Especifica la posición de la leyenda en un gráfico.<br/>            Los valores no NaN de las propiedades X, Y, Width, Heigt sobrescriben el efecto de esta propiedad.<br/>            Lectura/escritura [`LegendPositionType`](/slides/python-net/es/aspose.slides.charts/legendpositiontype). |
| [`format`](/slides/python-net/es/aspose.slides.charts/legend/format/) | Devuelve el formato de una leyenda.<br/>            Solo lectura [`IFormat`](/slides/python-net/es/aspose.slides.charts/iformat). |
| [`chart`](/slides/python-net/es/aspose.slides.charts/legend/chart/) | Devuelve el gráfico.<br/>            Solo lectura [`IChart`](/slides/python-net/es/aspose.slides.charts/ichart). |
| [`entries`](/slides/python-net/es/aspose.slides.charts/legend/entries/) | Obtiene las entradas de la leyenda.<br/>            Solo lectura [`ILegendEntryCollection`](/slides/python-net/es/aspose.slides.charts/ilegendentrycollection). |
| [`actual_x`](/slides/python-net/es/aspose.slides.charts/legend/actual_x/) | Especifica la ubicación real x (izquierda) del elemento del gráfico relativo a la esquina superior izquierda del gráfico.<br/>            Llama al método IChart.ValidateChartLayout() antes para obtener los valores reales. <br/>            Lectura **float**. |
| [`actual_y`](/slides/python-net/es/aspose.slides.charts/legend/actual_y/) | Especifica la parte superior real del elemento del gráfico relativo a la esquina superior izquierda del gráfico.<br/>            Llama al método IChart.ValidateChartLayout() antes para obtener los valores reales. <br/>            Lectura **float**. |
| [`actual_width`](/slides/python-net/es/aspose.slides.charts/legend/actual_width/) | Especifica el ancho real del elemento del gráfico. Llama al método IChart.ValidateChartLayout() antes para obtener los valores reales. <br/>            Lectura **float**. |
| [`actual_height`](/slides/python-net/es/aspose.slides.charts/legend/actual_height/) | Especifica la altura real del elemento del gráfico. Llama al método IChart.ValidateChartLayout() antes para obtener los valores reales. <br/>            Lectura **float**. |
