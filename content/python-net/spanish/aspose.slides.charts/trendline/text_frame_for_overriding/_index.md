## text_frame_for_overriding propiedad
Puede contener un texto con formato enriquecido. Si esta propiedad no es None entonces este 
            el valor del texto formateado sobrescribe el texto autogenerado de la etiqueta de datos.
            El texto autogenerado de la etiqueta de datos significa el texto que es gestionado por ShowSeriesName, 
            ShowValue, ... propiedades y está formateado con la propiedad TextFormatManager.TextFormat.
            Solo lectura [`ITextFrame`](/slides/python-net/es/aspose.slides/itextframe).
