## TickMarkType enumeración

Representa el tipo de marca de graduación para el eje especificado.

El tipo TickMarkType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| CROSS | Especifica que las marcas de graduación deben cruzar el eje. |
| INSIDE | Especifica que las marcas de graduación deben estar dentro del área de trazado. |
| NONE | Especifica que no habrá marcas de graduación. |
| OUTSIDE | Especifica que las marcas de graduación deben estar fuera del área de trazado. |
