## data_source_type propiedad
Especifica si la propiedad AsCell, AsCells, AsLiteralString o AsLiteralDouble está activa en los descendientes. En otras palabras, especifica el tipo de valor de la propiedad Data.
Lectura/escritura [`DataSourceType`](/slides/python-net/es/aspose.slides.charts/datasourcetype).

### Observaciones
Para los puntos en ChartDataPointCollection esta propiedad es de solo lectura. 
            En este caso, para cambiar el valor de esta propiedad puede utilizar una de las 
            propiedades ChartDataPointCollection.DataSourceTypeFor<...>.
