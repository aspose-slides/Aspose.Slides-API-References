## layout_target_type propiedad
Si el diseño del área del gráfico se define manualmente, esta propiedad especifica si 
            diseñar el área del gráfico por su interior (sin incluir ejes y etiquetas de ejes) o por el exterior (incluyendo ejes y etiquetas de ejes).
