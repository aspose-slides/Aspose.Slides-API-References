## ChartPlotArea clase

Representa el rectángulo donde se debe trazar el gráfico.

El tipo ChartPlotArea expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`format`](/slides/python-net/es/aspose.slides.charts/chartplotarea/format/) | Devuelve el formato de un área de trazado.<br/>            Solo lectura [`IFormat`](/slides/python-net/es/aspose.slides.charts/iformat). |
| [`x`](/slides/python-net/es/aspose.slides.charts/chartplotarea/x/) | Devuelve o establece la coordenada x de la esquina superior izquierda del cuadro delimitador del área de trazado como una fracción del ancho del gráfico (de 0 a 1).<br/>            Lectura/escritura **float**. |
| [`y`](/slides/python-net/es/aspose.slides.charts/chartplotarea/y/) | Devuelve o establece la coordenada y de la esquina superior izquierda del cuadro delimitador del área de trazado como una fracción de la altura del gráfico (de 0 a 1).<br/>            Lectura/escritura **float**. |
| [`width`](/slides/python-net/es/aspose.slides.charts/chartplotarea/width/) | Devuelve o establece el ancho del cuadro delimitador del área de trazado como una fracción del ancho del gráfico (de 0 a 1).<br/>            Lectura/escritura **float**. |
| [`height`](/slides/python-net/es/aspose.slides.charts/chartplotarea/height/) | Devuelve o establece la altura del cuadro delimitador del área de trazado como una fracción de la altura del gráfico (de 0 a 1).<br/>            Lectura/escritura **float**. |
| [`right`](/slides/python-net/es/aspose.slides.charts/chartplotarea/right/) | Derecha.<br/>            Solo lectura **float**. |
| [`bottom`](/slides/python-net/es/aspose.slides.charts/chartplotarea/bottom/) | Inferior.<br/>            Solo lectura **float**. |
| [`chart`](/slides/python-net/es/aspose.slides.charts/chartplotarea/chart/) | Gráfico.<br/>            Solo lectura [`IChart`](/slides/python-net/es/aspose.slides.charts/ichart). |
| [`is_location_autocalculated`](/slides/python-net/es/aspose.slides.charts/chartplotarea/is_location_autocalculated/) | Define cómo se debe calcular la ubicación: true – calculado automáticamente; definido por las propiedades X, Y, Width, Height.<br/>            Solo lectura **bool**. |
| [`layout_target_type`](/slides/python-net/es/aspose.slides.charts/chartplotarea/layout_target_type/) | Si el diseño del área de trazado se define manualmente, esta propiedad especifica si <br/>             diseñar el área de trazado por su interior (sin incluir ejes y etiquetas de ejes) o por el exterior<br/>             (incluyendo ejes y etiquetas de ejes).<br/>             Lectura/escritura [`ChartPlotArea.layout_target_type`](/slides/python-net/es/aspose.slides.charts/chartplotarea/layout_target_type). |
| [`actual_x`](/slides/python-net/es/aspose.slides.charts/chartplotarea/actual_x/) | Especifica la ubicación x real (izquierda) del elemento del gráfico relativa a la esquina superior izquierda del gráfico.<br/>            Llama al método IChart.ValidateChartLayout() antes para obtener los valores reales. <br/>            Lectura **float**. |
| [`actual_y`](/slides/python-net/es/aspose.slides.charts/chartplotarea/actual_y/) | Especifica la parte superior real del elemento del gráfico relativa a la esquina superior izquierda del gráfico.<br/>            Llama al método IChart.ValidateChartLayout() antes para obtener los valores reales. <br/>            Lectura **float**. |
| [`actual_width`](/slides/python-net/es/aspose.slides.charts/chartplotarea/actual_width/) | Especifica el ancho real del elemento del gráfico. Llama al método IChart.ValidateChartLayout() antes para obtener los valores reales. <br/>            Lectura **float**. |
| [`actual_height`](/slides/python-net/es/aspose.slides.charts/chartplotarea/actual_height/) | Especifica la altura real del elemento del gráfico. Llama al método IChart.ValidateChartLayout() antes para obtener los valores reales. <br/>            Lectura **float**. |
