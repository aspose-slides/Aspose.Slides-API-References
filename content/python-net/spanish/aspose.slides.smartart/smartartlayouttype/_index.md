## SmartArtLayoutType enumeración

Representa el tipo de diseño de un diagrama SmartArt.

El tipo SmartArtLayoutType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| ACCENT_PROCESS | Úselo para mostrar una progresión, una línea de tiempo o pasos secuenciales en una tarea, proceso o flujo de trabajo. Funciona bien para ilustrar tanto texto de Nivel 1 como de Nivel 2. |
| ACCENTED_PICTURE | Úselo para mostrar una idea fotográfica central con ideas relacionadas a los lados. El texto superior de Nivel 1 aparece sobre la imagen central. El texto correspondiente para otras formas de Nivel 1 aparece junto a las pequeñas imágenes circulares. Este diseño también funciona bien sin texto. |
| ALTERNATING_FLOW | Úselo para mostrar grupos de información o pasos secuenciales en una tarea, proceso o flujo de trabajo. Destaca la interacción o las relaciones entre los grupos de información. |
| ALTERNATING_HEXAGONS | Úselo para representar una serie de ideas interconectadas. El texto de Nivel 1 aparece dentro de los hexágonos. El texto de Nivel 2 aparece fuera de las formas. |
| ALTERNATING_PICTURE_BLOCKS | Úselo para mostrar una serie de imágenes de arriba a abajo. El texto aparece alternadamente a la derecha o a la izquierda de la imagen. |
| ALTERNATING_PICTURE_CIRCLES | Úselo para mostrar un conjunto de imágenes con texto. El texto correspondiente aparece en los círculos centrales con las imágenes alternando de izquierda a derecha. |
| ARROW_RIBBON | Úselo para mostrar conceptos relacionados o contrastantes con alguna conexión, como fuerzas opuestas. Las dos primeras líneas del texto de Nivel 1 se usan para el texto en las flechas. El texto no utilizado no aparece, pero sigue disponible si cambia de diseño. |
| ASCENDING_PICTURE_ACCENT_PROCESS | Úselo para mostrar una serie ascendente de imágenes con texto descriptivo. Funciona mejor con una pequeña cantidad de texto. |
| BALANCE | Úselo para comparar o mostrar la relación entre dos ideas. Cada una de las dos primeras líneas del texto de Nivel 1 corresponde a texto en la parte superior de un lado del punto central. Destaca el texto de Nivel 2, que se limita a cuatro formas en cada lado del punto central. La balanza se inclina hacia el lado con más formas que contienen texto de Nivel 2. El texto no utilizado no aparece, pero sigue disponible si cambia de diseño. |
| BASIC_BENDING_PROCESS | Úselo para mostrar una progresión o pasos secuenciales en una tarea, proceso o flujo de trabajo. Maximiza tanto el espacio horizontal como vertical de visualización para las formas. |
| BASIC_BLOCK_LIST | Úselo para mostrar bloques de información no secuenciales o agrupados. Maximiza tanto el espacio horizontal como vertical de visualización para las formas. |
| BASIC_CHEVRON_PROCESS | Úselo para mostrar una progresión; una línea de tiempo; pasos secuenciales en una tarea, proceso o flujo de trabajo; o para enfatizar movimiento o dirección. El texto de Nivel 1 aparece dentro de una forma de flecha mientras que el texto de Nivel 2 aparece bajo las formas de flecha. |
| BASIC_CYCLE | Úselo para representar una secuencia continua de etapas, tareas o eventos en un flujo circular. Destaca las etapas o pasos más que las flechas o el flujo conectante. Funciona mejor solo con texto de Nivel 1. |
| BASIC_MATRIX | Úselo para mostrar la relación de componentes a un todo en cuadrantes. Las primeras cuatro líneas del texto de Nivel 1 aparecen en los cuadrantes. El texto no utilizado no aparece, pero sigue disponible si cambia de diseño. |
| BASIC_PIE | Úselo para mostrar cómo las partes individuales forman un todo. Las primeras siete líneas del texto de Nivel 1 corresponden a las formas de cuña o sector distribuidas uniformemente. La forma de texto superior de Nivel 1 aparece fuera del resto del gráfico de sectores para enfatizar. El texto no utilizado no aparece, pero sigue disponible si cambia de diseño. |
| BASIC_PROCESS | Úselo para mostrar una progresión o pasos secuenciales en una tarea, proceso o flujo de trabajo. |
| BASIC_PYRAMID | Úselo para mostrar relaciones proporcionales, interconectadas o jerárquicas con el componente más grande en la parte inferior y estrechándose hacia arriba. El texto de Nivel 1 aparece en los segmentos de la pirámide y el texto de Nivel 2 aparece en formas junto a cada segmento. |
| BASIC_RADIAL | Úselo para mostrar la relación con una idea central en un ciclo. La primera línea del texto de Nivel 1 corresponde a la forma central, y su texto de Nivel 2 corresponde a las formas circulares circundantes. El texto no utilizado no aparece, pero sigue disponible si cambia de diseño. |
| BASIC_TARGET | Úselo para mostrar contención, gradaciones o relaciones jerárquicas. Las primeras cinco líneas del texto de Nivel 1 están asociadas a un círculo. El texto no utilizado no aparece, pero sigue disponible si cambia de diseño. |
| BASIC_TIMELINE | Úselo para mostrar pasos secuenciales en una tarea, proceso o flujo de trabajo, o para mostrar información de línea de tiempo. Funciona bien con texto de Nivel 1 y Nivel 2. |
| BASIC_VENN | Úselo para mostrar relaciones superpuestas o interconectadas. Las primeras siete líneas del texto de Nivel 1 corresponden a un círculo. Si hay cuatro o menos líneas de texto de Nivel 1, el texto está dentro de los círculos. Si hay más de cuatro líneas de texto de Nivel 1, el texto está fuera de los círculos. El texto no utilizado no aparece, pero sigue disponible si cambia de diseño. |
| BENDING_PICTURE_ACCENT_LIST | Úselo para mostrar bloques de información no secuenciales o agrupados. Las pequeñas formas circulares están diseñadas para contener imágenes. Funciona bien para ilustrar tanto texto de Nivel 1 como de Nivel 2. Maximiza tanto el espacio horizontal como vertical de visualización para las formas. |
| BENDING_PICTURE_BLOCKS | Úselo para mostrar una serie de imágenes. La caja que cubre la esquina inferior puede contener pequeñas cantidades de texto. |
| BENDING_PICTURE_CAPTION | Úselo para mostrar una serie secuencial de imágenes. La caja que cubre la esquina inferior puede contener pequeñas cantidades de texto. |
| BENDING_PICTURE_CAPTION_LIST | Úselo para mostrar una serie de imágenes. El título y la descripción aparecen en una forma de llamada bajo cada imagen. |
| BENDING_PICTURE_SEMI_TRANSPARENT_TEXT | Úselo para mostrar una serie de imágenes. Una caja semitransparente cubre la porción inferior de la imagen y contiene todos los niveles de texto. |
| BLOCK_CYCLE | Úselo para representar una secuencia continua de etapas, tareas o eventos en un flujo circular. Destaca las etapas o pasos más que las flechas o el flujo conectante. |
| BUBBLE_PICTURE_LIST | Úselo para mostrar una serie de imágenes. Puede contener hasta ocho imágenes de Nivel 1. El texto y las imágenes no utilizadas no aparecen, pero siguen disponibles si cambia de diseño. Funciona mejor con pequeñas cantidades de texto. |
| CAPTIONED_PICTURES | Úselo para mostrar imágenes con varios niveles de texto. Funciona mejor con una pequeña cantidad de texto de Nivel 1 y una cantidad media de texto de Nivel 2. |
| CHEVRON_LIST | Úselo para mostrar una progresión a través de varios procesos que conforman un flujo de trabajo general. También funciona para ilustrar procesos contrastantes. El texto de Nivel 1 corresponde a la primera forma de flecha a la izquierda, mientras que el texto de Nivel 2 corresponde a sub-pasos horizontales para cada forma que contiene texto de Nivel 1. |
| CIRCLE_ACCENT_TIMELINE | Úselo para mostrar una serie de eventos o información de línea de tiempo. El texto de Nivel 1 aparece junto a formas circulares más grandes. El texto de Nivel 2 aparece junto a formas circulares más pequeñas. |
| CIRCLE_ARROW_PROCESS | Úselo para mostrar elementos secuenciales con texto de apoyo para cada elemento. Este diagrama funciona mejor con pequeñas cantidades de texto de Nivel 1. |
| CIRCLE_PICTURE_HIERARCHY | Úselo para mostrar información jerárquica o relaciones de reporte en una organización. Las imágenes aparecen en círculos y el texto correspondiente aparece junto a las imágenes. |
| CIRCLE_RELATIONSHIP | Úselo para mostrar la relación con o desde una idea central. El texto de Nivel 2 se agrega de forma no secuencial y se limita a cinco elementos. Solo puede haber un elemento de Nivel 1. |
| CIRCULAR_BENDING_PROCESS | Úselo para mostrar una secuencia larga o no lineal de pasos en una tarea, proceso o flujo de trabajo. Funciona mejor solo con texto de Nivel 1. Maximiza tanto el espacio horizontal como vertical de visualización para las formas. |
| CIRCULAR_PICTURE_CALLOUT | Úselo para mostrar una idea central y subideas o elementos relacionados. El texto de la primera imagen cubre la parte inferior de la imagen. El texto correspondiente para otras formas de Nivel 1 aparece junto a las pequeñas imágenes circulares. Este diagrama también funciona bien sin texto. |
| CLOSED_CHEVRON_PROCESS | Úselo para mostrar una progresión, una línea de tiempo o pasos secuenciales en una tarea, proceso o flujo de trabajo, o para enfatizar movimiento o dirección. Puede usarse para enfatizar información en la forma inicial. Funciona mejor solo con texto de Nivel 1. |
| CONTINUOUS_ARROW_PROCESS | Úselo para mostrar una línea de tiempo o pasos secuenciales en una tarea, proceso o flujo de trabajo. Funciona mejor con texto de Nivel 1 porque cada línea del texto de Nivel 1 aparece dentro de la forma de flecha. El texto de Nivel 2 aparece fuera de la forma de flecha. |
| CONTINUOUS_BLOCK_PROCESS | Úselo para mostrar una progresión o pasos secuenciales en una tarea, proceso o flujo de trabajo. Funciona mejor con texto mínimo de Nivel 1 y Nivel 2. |
| CONTINUOUS_CYCLE | Úselo para representar una secuencia continua de etapas, tareas o eventos en un flujo circular. Destaca la conexión entre todos los componentes. Funciona mejor solo con texto de Nivel 1. |
| CONTINUOUS_PICTURE_LIST | Úselo para mostrar grupos de información interconectada. Las formas circulares están diseñadas para contener imágenes. |
| CONVERGING_ARROWS | Úselo para mostrar ideas o conceptos que convergen a un punto central. Funciona mejor solo con texto de Nivel 1. |
| CONVERGING_RADIAL | Úselo para mostrar relaciones de conceptos o componentes con una idea central en un ciclo. La primera línea del texto de Nivel 1 corresponde a la forma circular central y las líneas del texto de Nivel 2 corresponden a las formas rectangulares circundantes. El texto no utilizado no aparece, pero sigue disponible si cambia de diseño. |
| COUNTERBALANCE_ARROWS | Úselo para mostrar dos ideas o conceptos opuestos. Cada una de las dos primeras líneas del texto de Nivel 1 corresponde a una flecha y funciona bien con texto de Nivel 2. El texto no utilizado no aparece, pero sigue disponible si cambia de diseño. |
| CYCLE_MATRIX | Úselo para mostrar la relación con una idea central en una progresión cíclica. Cada una de las primeras cuatro líneas del texto de Nivel 1 corresponde a una cuña o forma de sector, y el texto de Nivel 2 aparece en una forma rectangular al lado de la cuña o sector. El texto no utilizado no aparece, pero sigue disponible si cambia de diseño. |
| DESCENDING_BLOCK_LIST | Úselo para mostrar grupos de ideas relacionadas o listas de información. Las formas de texto disminuyen en altura de forma secuencial, y el texto de Nivel 1 se muestra verticalmente. |
| DESCENDING_PROCESS | Úselo para mostrar una serie descendente de eventos. El primer texto de Nivel 1 está en la parte superior de la flecha, y el último texto de Nivel 1 se muestra en la parte inferior de la flecha. Solo aparecen los primeros siete elementos de Nivel 1. Funciona mejor con cantidades pequeñas a medianas de texto. |
| DETAILED_PROCESS | Úselo con grandes cantidades de texto de Nivel 2 para mostrar una progresión a través de etapas. |
| DIVERGING_ARROWS | Úselo para mostrar ideas o conceptos que se expanden desde una fuente central. Funciona mejor solo con texto de Nivel 1. |
| DIVERGING_RADIAL | Úselo para mostrar relaciones con una idea central en un ciclo. La primera línea del texto de Nivel 1 corresponde a la forma circular central. Destaca los círculos circundantes más que la idea central. El texto no utilizado no aparece, pero sigue disponible si cambia de diseño. |
| EQUATION | Úselo para mostrar pasos secuenciales o tareas que representan un plan o resultado. La última línea del texto de Nivel 1 aparece después del signo igual (=).Funciona mejor solo con texto de Nivel 1. |
| FRAMED_TEXT_PICTURE | Úselo para mostrar imágenes con texto de Nivel 1 correspondiente mostrado en un marco. |
| FUNNEL | Úselo para mostrar el filtrado de información o cómo las partes se unen en un todo. Destaca el resultado final. Puede contener hasta cuatro líneas de texto de Nivel 1; la última de esas cuatro líneas de texto de Nivel 1 aparece bajo el embudo y las demás líneas corresponden a una forma circular. El texto no utilizado no aparece, pero sigue disponible si cambia de diseño. |
| GEAR | Úselo para mostrar ideas interconectadas. Cada una de las tres primeras líneas del texto de Nivel 1 corresponde a una forma de engranaje, y su texto de Nivel 2 correspondiente aparece en rectángulos junto a la forma de engranaje. El texto no utilizado no aparece, pero sigue disponible si cambia de diseño. |
| GRID_MATRIX | Úselo para mostrar la ubicación de conceptos a lo largo de dos ejes. Resalta los componentes individuales en lugar del conjunto. Las primeras cuatro líneas de texto de Nivel 1 aparecen en los cuadrantes. El texto no utilizado no aparece, pero sigue disponible si cambia los diseños. |
| GROUPED_LIST | Úselo para mostrar grupos y subgrupos de información, o pasos y subpasos en una tarea, proceso o flujo de trabajo. El texto de Nivel 1 corresponde a las formas horizontales de nivel superior, y el texto de Nivel 2 corresponde a los subpasos verticales bajo cada forma de nivel superior relacionada. Funciona bien para resaltar subgrupos o subpasos, información jerárquica o múltiples listas de información. |
| HALF_CIRCLE_ORGANIZATION_CHART | Úselo para mostrar información jerárquica o relaciones de reporte en una organización. Las formas asistente y los diseños colgantes de Org Chart están disponibles con este diseño. |
| HEXAGON_CLUSTER | Úselo para mostrar imágenes con texto descriptivo asociado. Los hexágonos pequeños indican el par imagen y texto. Funciona mejor con pequeñas cantidades de texto. |
| HIERARCHY | Úselo para mostrar relaciones jerárquicas que avanzan de arriba hacia abajo. |
| HIERARCHY_LIST | Úselo para mostrar relaciones jerárquicas que progresan a través de grupos. También puede usarse para agrupar o listar información. |
| HORIZONTAL_BULLET_LIST | Úselo para mostrar listas de información no secuenciales o agrupadas. Funciona bien con grandes cantidades de texto. Todo el texto tiene el mismo nivel de énfasis y no se implica dirección. |
| HORIZONTAL_HIERARCHY | Úselo para mostrar relaciones jerárquicas que se desarrollan horizontalmente. Funciona bien para árboles de decisión. |
| HORIZONTAL_LABELED_HIERARCHY | Úselo para mostrar relaciones jerárquicas que avanzan horizontalmente y se agrupan jerárquicamente. Resalta el encabezado o el texto de Nivel 1. | HORIZONTAL_MULTI_LEVEL_HIERARCHY | Úselo para mostrar grandes cantidades de información jerárquica que avanza horizontalmente. La parte superior de la jerarquía se muestra de forma vertical. Este diseño admite muchos niveles en la jerarquía. |
| HORIZONTAL_ORGANIZATION_CHART | Úselo para mostrar información jerárquica horizontalmente o relaciones de reporte en una organización. La forma asistente y los diseños colgantes de Org Chart están disponibles con este diseño. |
| HORIZONTAL_PICTURE_LIST | Úselo para mostrar información no secuencial o agrupada con énfasis en imágenes relacionadas. Las formas superiores están diseñadas para contener imágenes. |

| INCREASING_CIRCLE_PROCESS | Úselo para mostrar una serie de pasos, con el interior del círculo aumentando en cada paso. Limitado a siete pasos de Nivel 1 pero con elementos de Nivel 2 ilimitados. Funciona bien con grandes cantidades de texto de Nivel 2. |
| INVERTED_PYRAMID | Úselo para mostrar relaciones proporcionales, interconectadas o jerárquicas con el componente más grande en la parte superior y estrechándose hacia abajo. | LINEAR_VENN | Úselo para mostrar relaciones superpuestas en una secuencia. Funciona mejor solo con texto de Nivel 1. |

| NAMEAND_TITLE_ORGANIZATION_CHART | Úselo para mostrar información jerárquica o relaciones de reporte en una organización. | NESTED_TARGET | Úselo para mostrar relaciones de contención. Cada una de las tres primeras líneas de texto de Nivel 1 corresponde al texto superior izquierdo en las formas, y el texto de Nivel 2 corresponde a las formas más pequeñas. Funciona mejor con líneas mínimas de texto de Nivel 2. El texto no utilizado no aparece, pero sigue disponible si cambia los diseños. |
| NONDIRECTIONAL_CYCLE | Úselo para representar una secuencia continua de etapas, tareas o eventos en un flujo circular. Cada forma tiene el mismo nivel de importancia. Funciona bien cuando no es necesario indicar dirección. |

| PICTURE_ACCENT_PROCESS | Úselo para mostrar pasos secuenciales en una tarea, proceso o flujo de trabajo. Las formas rectangulares en el fondo están diseñadas para contener imágenes. |
| PICTURE_CAPTION_LIST | Úselo para mostrar bloques de información no secuenciales o agrupados. Las formas superiores están diseñadas para contener imágenes y se da mayor énfasis a las imágenes que al texto. Funciona bien para imágenes con breves pies de foto. |
