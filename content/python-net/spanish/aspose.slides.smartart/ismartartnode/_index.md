## ISmartArtNode clase

Representa un nodo de un diagrama SmartArt.

El tipo ISmartArtNode expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`child_nodes`](/slides/python-net/es/aspose.slides.smartart/ismartartnode/child_nodes/) | Devuelve colecciones de todos los nodos hijos del nodo actual.<br/>            Solo lectura [`ISmartArtNodeCollection`](/slides/python-net/es/aspose.slides.smartart/ismartartnodecollection). |
| [`shapes`](/slides/python-net/es/aspose.slides.smartart/ismartartnode/shapes/) | Devuelve colecciones de todas las formas asociadas al nodo.<br/>            Solo lectura [`ISmartArtShapeCollection`](/slides/python-net/es/aspose.slides.smartart/ismartartshapecollection). |
| [`text_frame`](/slides/python-net/es/aspose.slides.smartart/ismartartnode/text_frame/) | Devuelve o establece el texto del nodo.<br/>            Solo lectura [`ITextFrame`](/slides/python-net/es/aspose.slides/itextframe). |
| [`is_assistant`](/slides/python-net/es/aspose.slides.smartart/ismartartnode/is_assistant/) | Devuelve o establece el nodo como asistente.<br/>            Lectura/escritura **bool**. |
| [`level`](/slides/python-net/es/aspose.slides.smartart/ismartartnode/level/) | Devuelve el nivel de anidamiento del nodo.<br/>            Solo lectura **int**. |
| [`bullet_fill_format`](/slides/python-net/es/aspose.slides.smartart/ismartartnode/bullet_fill_format/) | Devuelve el objeto FillFormat que contiene las propiedades de formato de relleno para una viñeta de nodo.<br/>            Nota: puede devolver None para ciertos tipos de diseño SmartArt que no proporcionan viñetas para los nodos.<br/>            Solo lectura [`IFillFormat`](/slides/python-net/es/aspose.slides/ifillformat). |
| [`position`](/slides/python-net/es/aspose.slides.smartart/ismartartnode/position/) | Devuelve o establece la posición basada en cero del nodo entre los nodos hermanos.<br/>            Lectura/escritura **int**. |
| [`is_hidden`](/slides/python-net/es/aspose.slides.smartart/ismartartnode/is_hidden/) | Devuelve true si este nodo es un nodo oculto en el modelo de datos.<br/>            Solo lectura **bool**. |
| [`organization_chart_layout`](/slides/python-net/es/aspose.slides.smartart/ismartartnode/organization_chart_layout/) | Devuelve o establece el tipo de diseño del organigrama asociado con el nodo actual.<br/>            Lectura/escritura [`OrganizationChartLayoutType`](/slides/python-net/es/aspose.slides.smartart/organizationchartlayouttype). |

## Métodos

| Método | Descripción |
| :- | :- |
| [`remove(self)`](/slides/python-net/es/aspose.slides.smartart/ismartartnode/remove/#) | Elimina el nodo actual. |
