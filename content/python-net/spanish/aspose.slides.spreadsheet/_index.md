Contiene clases para trabajar con objetos de hoja de cálculo en presentaciones de Microsoft PowerPoint.
## Clases

| Clase | Descripción |
| :- | :- |
| [`CellCircularReferenceException`](/slides/python-net/es/aspose.slides.spreadsheet/cellcircularreferenceexception/) | La excepción que se lanza cuando se detecta una o más referencias circulares donde una fórmula se refiere a su<br/>            propia celda, ya sea directa o indirectamente. |
| [`CellInvalidFormulaException`](/slides/python-net/es/aspose.slides.spreadsheet/cellinvalidformulaexception/) | La excepción que se lanza cuando una fórmula calculada no es correcta o no se ha analizado. |
| [`CellInvalidReferenceException`](/slides/python-net/es/aspose.slides.spreadsheet/cellinvalidreferenceexception/) | La excepción que se lanza cuando se encuentra una referencia de celda no válida. |
| [`CellUnsupportedDataException`](/slides/python-net/es/aspose.slides.spreadsheet/cellunsupporteddataexception/) | La excepción que se lanza cuando se encuentra un dato no compatible en una celda de hoja de cálculo. |
