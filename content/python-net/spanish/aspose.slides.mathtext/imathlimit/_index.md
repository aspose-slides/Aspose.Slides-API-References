## clase IMathLimit

Especifica el objeto Limit, que consiste en texto en la línea base y texto de tamaño reducido inmediatamente encima o debajo de ella.

El tipo IMathLimit expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`base`](/slides/python-net/es/aspose.slides.mathtext/imathlimit/base/) | Argumento base |
| [`limit`](/slides/python-net/es/aspose.slides.mathtext/imathlimit/limit/) | Argumento límite |
| [`upper_limit`](/slides/python-net/es/aspose.slides.mathtext/imathlimit/upper_limit/) | Especifica límite superior o inferior |
