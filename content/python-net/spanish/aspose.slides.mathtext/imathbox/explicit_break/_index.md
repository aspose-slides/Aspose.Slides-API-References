## explicit_break propiedad
El salto explícito indica si hay un salto de línea al inicio del objeto Box, de modo que la línea se envuelva al comienzo del objeto box.
Especifica el número del operador en la línea anterior del texto matemático que se debe usar como punto de alineación para la línea actual del texto matemático
valores posibles: 1..255
Predeterminado: 0 (sin salto explícito)
