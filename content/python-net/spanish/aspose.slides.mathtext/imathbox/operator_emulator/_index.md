## operator_emulator propiedad
Emulador de Operador.
            Cuando es true, el cuadro y su contenido se comportan como un solo operador y heredan las propiedades de un operador. 
            Esto significa, por ejemplo, que el carácter puede servir como punto para un salto de línea y puede alinearse a otros operadores.
            Los Emuladores de Operador se usan a menudo cuando uno o más glifos se combinan para formar un operador, como '=='.
            Valor predeterminado: false
