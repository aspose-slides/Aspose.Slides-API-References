## no_break propiedad
Sin salto
            Esta propiedad especifica la propiedad "unbreakable" en el cuadro de objeto. Cuando es true, no pueden producirse saltos de línea dentro del cuadro.
            Esto puede ser importante para emuladores de operadores que constan de más de un operador binario. 
            Cuando este elemento no se especifica, pueden ocurrir saltos dentro del cuadro.
            Default: true
