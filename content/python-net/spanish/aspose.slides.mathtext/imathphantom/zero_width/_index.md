## zero_width propiedad
Obtiene o establece un valor que indica si el ancho del elemento base 
            debe tratarse como cero.

### Observaciones

Cuando `true`, el fantasma no reserva espacio horizontal para su base. Corresponde al atributo OMML `m:zeroWid`.
