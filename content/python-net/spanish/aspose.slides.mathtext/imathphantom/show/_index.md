## show propiedad
Obtiene o establece un valor que indica si el elemento base se muestra.

### Observaciones

Cuando `false`, el elemento base está oculto pero aún puede ocupar espacio dependiendo de otras configuraciones fantasma. Corresponde al atributo OMML `m:show`.
