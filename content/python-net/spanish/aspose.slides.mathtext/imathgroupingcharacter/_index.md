## IMathGroupingCharacter clase

Especifica un símbolo de agrupación sobre o bajo una expresión, generalmente para resaltar la relación entre los elementos

El tipo IMathGroupingCharacter expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`base`](/slides/python-net/es/aspose.slides.mathtext/imathgroupingcharacter/base/) | Argumento base |
| [`character`](/slides/python-net/es/aspose.slides.mathtext/imathgroupingcharacter/character/) | Carácter de agrupación<br/>            Valor predeterminado: U+23DF (BOTTOM CURLY BRACKET) |
| [`position`](/slides/python-net/es/aspose.slides.mathtext/imathgroupingcharacter/position/) | Posición del carácter de agrupación.<br/>            Predeterminado: Bottom |
| [`vertical_justification`](/slides/python-net/es/aspose.slides.mathtext/imathgroupingcharacter/vertical_justification/) | Justificación vertical del carácter de grupo.<br/>            Especifica la alineación del objeto con respecto a la línea base.<br/>            Por ejemplo, cuando el carácter de grupo está encima del objeto, <br/>            VerticalJustification de Top significa que la parte superior del objeto cae en la línea base;<br/>            cuando VerticalJustification se establece en Bottom, la parte inferior del objeto está en la línea base<br/>            Predeterminado: Bottom para Position=Top, y Top para Position=Bottom |
