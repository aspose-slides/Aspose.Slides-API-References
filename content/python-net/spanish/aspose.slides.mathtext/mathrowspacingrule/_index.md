## MathRowSpacingRule enumeración

El tipo de espaciado vertical entre columnas en una matriz o arreglo

El tipo MathRowSpacingRule expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| SINGLE_LINE_GAP | espacio de una línea |
| ONE_AND_A_HALF_LINE_GAP | espacio de una línea y media |
| TWO_LINE_GAP | espacio de dos líneas |
| EXACTLY | Exactamente (depende del valor de la propiedad RowSpacing, medido en puntos) |
| MULTIPLE | Múltiple (depende del valor de la propiedad RowSpacing, medido en líneas) |
