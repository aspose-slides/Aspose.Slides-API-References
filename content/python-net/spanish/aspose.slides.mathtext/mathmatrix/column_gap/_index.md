## column_gap propiedad
El valor del espacio horizontal entre columnas de una matriz;
            Si el ColumnGapRule está configurado a 3 ("Exactly"), entonces la unidad se interpreta como twips (1/20 de punto)
            Si el ColumnGapRule está configurado a 4 ("Multiple"), entonces la unidad se interpreta como número de incrementos de 0.5 em.
            En otros casos se ignora.
            Predeterminado: 0
