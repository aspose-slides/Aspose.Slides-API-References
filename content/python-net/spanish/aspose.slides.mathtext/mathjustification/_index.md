## MathJustification enumeración

Especifica la justificación del párrafo matemático (una serie de instancias adyacentes de texto matemático dentro del mismo párrafo)

El tipo MathJustification expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| LEFT_JUSTIFIED | Alinear el texto matemático a la izquierda |
| RIGHT_JUSTIFIED | Alinear el texto matemático a la derecha |
| CENTERED | Alinear el texto matemático al centro |
| CENTERED_AS_GROUP | Centrar en la página todo el grupo de bloques matemáticos como una única unidad.<br/>            Esto significa que las instancias de texto matemático pueden alinearse entre sí, <br/>            pero todo el grupo de texto matemático se centra como un todo. |
