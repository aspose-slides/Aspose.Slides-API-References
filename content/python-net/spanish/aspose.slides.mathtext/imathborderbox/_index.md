## IMathBorderBox clase

Dibuja un borde rectangular u otro tipo alrededor del IMathElement.

El tipo IMathBorderBox expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`base`](/slides/python-net/es/aspose.slides.mathtext/imathborderbox/base/) | Argumento base |
| [`hide_top`](/slides/python-net/es/aspose.slides.mathtext/imathborderbox/hide_top/) | Ocultar borde superior (el valor predeterminado es false) - especifica el estado oculto o visible del borde superior del cuadro de borde. |
| [`hide_bottom`](/slides/python-net/es/aspose.slides.mathtext/imathborderbox/hide_bottom/) | Ocultar borde inferior (el valor predeterminado es false) - especifica el estado oculto o visible del borde inferior del cuadro de borde. |
| [`hide_left`](/slides/python-net/es/aspose.slides.mathtext/imathborderbox/hide_left/) | Ocultar borde izquierdo (el valor predeterminado es false) - especifica el estado oculto o visible del borde izquierdo del cuadro de borde. |
| [`hide_right`](/slides/python-net/es/aspose.slides.mathtext/imathborderbox/hide_right/) | Ocultar borde derecho (el valor predeterminado es false) - especifica el estado oculto o visible del borde derecho del cuadro de borde. |
| [`strikethrough_horizontal`](/slides/python-net/es/aspose.slides.mathtext/imathborderbox/strikethrough_horizontal/) | Tachado horizontal (el valor predeterminado es false) - especifica el estado oculto o visible de una línea horizontal tachada. |
| [`strikethrough_vertical`](/slides/python-net/es/aspose.slides.mathtext/imathborderbox/strikethrough_vertical/) | Tachado vertical (el valor predeterminado es false) - especifica el estado oculto o visible de una línea vertical tachada. |
| [`strikethrough_bottom_left_to_top_right`](/slides/python-net/es/aspose.slides.mathtext/imathborderbox/strikethrough_bottom_left_to_top_right/) | Tachado de abajo a la izquierda a arriba a la derecha (el valor predeterminado es false).<br/>            Especifica el estado oculto o visible de una línea diagonal tachada desde la esquina inferior izquierda hasta la esquina superior derecha del cuadro de borde. |
| [`strikethrough_top_left_to_bottom_right`](/slides/python-net/es/aspose.slides.mathtext/imathborderbox/strikethrough_top_left_to_bottom_right/) | Tachado de arriba a la izquierda a abajo a la derecha (el valor predeterminado es false).<br/>            Especifica el estado oculto o visible de una línea diagonal tachada desde la esquina superior izquierda hasta la esquina inferior derecha del cuadro de borde. |
