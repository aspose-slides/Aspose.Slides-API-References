## MathSpacingRules enumeración

Tipos de separación (espaciado horizontal) entre columnas de una matriz

El tipo MathSpacingRules expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| SINGLE_SPACING_GAP | Simple (1 em para columnas o 1 línea para filas) |
| ONE_AND_HALF_SPACING_GAP | Una y media (1,5 ems para columnas o 1,5 líneas para filas) |
| DOUBLE_SPACING_GAP | Doble espaciado (2 ems para columnas o 2 líneas para filas) |
| EXACTLY | Valor exacto<br/>            Para columnas, depende del valor de ColumnGap, medido en twips<br/>            Para filas, depende del valor de RowGap, medido en twips |
| MULTIPLE | Múltiple<br/>            Para columnas, depende del valor de ColumnGap, medido en incrementos de 0,5 em<br/>            Para filas, depende del valor de RowGap, medido en líneas |
