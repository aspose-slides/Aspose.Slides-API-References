## IMathElementCollection clase

Representa una colección de elementos matemáticos (MathElement).

El tipo IMathElementCollection expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`count`](/slides/python-net/es/aspose.slides.mathtext/imathelementcollection/count/) | Obtiene el número de elementos realmente contenidos en la colección.<br/>            Solo lectura **int**. |

Obtiene el elemento en el índice especificado.
            Solo lectura [`IMathElement`](/slides/python-net/es/aspose.slides.mathtext/imathelement).

## Indexador

| Nombre | Descripción |
| :- | :- |
| [`[index]`](/slides/python-net/es/aspose.slides.mathtext/imathelementcollection/__getitem__/) | El índice basado en cero del elemento a obtener |

| :- | :- |
