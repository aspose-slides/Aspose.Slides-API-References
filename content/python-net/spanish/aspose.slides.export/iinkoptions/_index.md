## IInkOptions clase

Proporciona opciones que controlan la apariencia de los objetos Ink en el documento exportado.

El tipo IInkOptions expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`hide_ink`](/slides/python-net/es/aspose.slides.export/iinkoptions/hide_ink/) | Muestra u oculta los elementos Ink en el documento exportado. |
| [`interpret_mask_op_as_opacity`](/slides/python-net/es/aspose.slides.export/iinkoptions/interpret_mask_op_as_opacity/) | Utiliza la operación ROP o la Opacidad para renderizar la brocha. |
