## skip_java_script_links propiedad
Especifica si se omiten los hipervínculos con llamadas a JavaScript al guardar la presentación. 
            Lectura/escritura **bool**. El valor predeterminado es **false** .


### Observaciones

Cuando esta propiedad se establece en **true**, los hipervínculos con llamadas a JavaScript serán ignorados al guardar.


Cuando esta propiedad se establece en **false**, se guardarán todos los hipervínculos.
