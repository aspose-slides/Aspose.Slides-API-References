## Enumeración CompressionLevel

Especifica los niveles de compresión ZIP para archivos OpenXML.  
Los niveles más altos proporcionan una mejor compresión a costa de un procesamiento más lento.

El tipo CompressionLevel expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| NONE | No se aplica compresión. Los archivos se almacenan tal cual. |
| LEVEL1 | Compresión más rápida con la relación de compresión más baja. |
| LEVEL2 | Compresión más rápida con una relación de compresión ligeramente mejor que [`CompressionLevel.LEVEL1`](/slides/python-net/es/aspose.slides.export/compressionlevel/LEVEL1). |
| LEVEL3 | Proporciona una mejor compresión que [`CompressionLevel.LEVEL2`](/slides/python-net/es/aspose.slides.export/compressionlevel/LEVEL2) con un impacto de rendimiento moderado. |
| LEVEL4 | Proporciona una mejor compresión que [`CompressionLevel.LEVEL3`](/slides/python-net/es/aspose.slides.export/compressionlevel/LEVEL3). |
| LEVEL5 | Proporciona una compresión mejorada respecto a [`CompressionLevel.LEVEL4`](/slides/python-net/es/aspose.slides.export/compressionlevel/LEVEL4) con tiempo de procesamiento adicional. |
| LEVEL6 | Compresión estándar, que ofrece un buen equilibrio entre la velocidad de compresión y el tamaño del archivo.<br/>            El nivel de compresión predeterminado. |
| LEVEL7 | Proporciona una compresión mayor que [`CompressionLevel.LEVEL6`](/slides/python-net/es/aspose.slides.export/compressionlevel/LEVEL6) con un procesamiento más lento. |
| LEVEL8 | Proporciona una compresión mayor que [`CompressionLevel.LEVEL7`](/slides/python-net/es/aspose.slides.export/compressionlevel/LEVEL7). |
| LEVEL9 | Compresión máxima. Produce el tamaño de archivo más pequeño con la velocidad de procesamiento más lenta. |
