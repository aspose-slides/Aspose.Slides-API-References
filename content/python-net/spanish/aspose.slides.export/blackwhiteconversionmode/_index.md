## BlackWhiteConversionMode enumeración

Proporciona opciones que controlan cómo se convertirán las imágenes de las diapositivas a imágenes bitonales.

El tipo BlackWhiteConversionMode expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| DEFAULT | Especifica que no se aplica algoritmo de conversión. Se usará el algoritmo implementado en el códec TIFF. (Predeterminado) |
| DITHERING | Especifica el algoritmo de dithering (Floyd-Steinberg). |
| DITHERING_FLOYD_STEINBERG | Especifica el algoritmo de dithering Floyd-Steinberg. |
| AUTO | Especifica el algoritmo de umbral calculado automáticamente (Otsu). |
| AUTO_OTSU | Especifica el algoritmo de umbral de Otsu calculado automáticamente. |
| THRESHOLD25 | Especifica el algoritmo de umbral estático (25%). |
| THRESHOLD50 | Especifica el algoritmo de umbral estático (50%). |
| THRESHOLD75 | Especifica el algoritmo de umbral estático (75%). |
