## MarkdownExportType enumeración

Tipo de documento de renderizado.

El tipo MarkdownExportType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| SEQUENTIAL | Renderiza todos los elementos por separado. Uno a uno. |
| TEXT_ONLY | Renderiza solo texto. |
| VISUAL | Renderiza todos los elementos, los elementos que están agrupados - renderizar juntos. |
