## LinkEmbedDecision enumeración

Determina cómo se procesará el objeto durante el guardado.

El tipo LinkEmbedDecision expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| LINK | El objeto se almacenará externamente, referenciado por URL |
| EMBED | El objeto debe incrustarse en un archivo generado si es posible. Si la incrustación es imposible, se llamará a GetUrl y, dependiendo del resultado, el objeto será referenciado por URL o se ignorará. |
| IGNORE | El objeto será ignorado. |
