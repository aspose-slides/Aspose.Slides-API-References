## NotesPositions enumeración

Representa la regla para renderizar notas en el documento exportado

El tipo NotesPositions expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| NONE | Especifica que las notas no deben mostrarse en absoluto. |
| BOTTOM_FULL | Especifica que las notas deben mostrarse en su totalidad utilizando páginas adicionales según sea necesario. |
| BOTTOM_TRUNCATED | Especifica que las notas deben mostrarse en una sola página. |
