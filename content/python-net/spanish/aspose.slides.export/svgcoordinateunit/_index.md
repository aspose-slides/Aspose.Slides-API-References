## Enumeración SvgCoordinateUnit

Representa unidades de coordenadas CSS2 usadas para definir coordenadas SVG.

El tipo SvgCoordinateUnit expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| INCH | Pulgada |
| CENTIMETER | Centímetro. |
| MILLIMETER | Milímetro. |
| POINT | Punto (1/72 de pulgada), |
| PICA | Pica (1/6 de pulgada). |
| EM | Tamaño EM de la fuente del elemento contenedor. |
| EX | Tamaño EX (tamaño de letra minúscula, normalmente "x") de la fuente del elemento contenedor. |
| PIXEL | Tamaño de píxel. |
| PERCENT | Porcentaje. |
