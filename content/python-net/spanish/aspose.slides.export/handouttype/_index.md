## Enumeración HandoutType

Especifica cuántas diapositivas y en qué secuencia se colocarán en la página.

El tipo HandoutType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| HANDOUTS1 | Una diapositiva por página. |
| HANDOUTS2 | Dos diapositivas por página. |
| HANDOUTS3 | Tres diapositivas por página. |
| HANDOUTS_4_HORIZONTAL | Cuatro diapositivas por página en una secuencia horizontal. |
| HANDOUTS_4_VERTICAL | Cuatro diapositivas por página en una secuencia vertical. |
| HANDOUTS_6_HORIZONTAL | Seis diapositivas por página en una secuencia horizontal. |
| HANDOUTS_6_VERTICAL | Seis diapositivas por página en una secuencia vertical. |
| HANDOUTS_9_HORIZONTAL | Nueve diapositivas por página en una secuencia horizontal. |
| HANDOUTS_9_VERTICAL | Nueve diapositivas por página en una secuencia vertical. |
