## SvgExternalFontsHandling enumeración

Representa una forma de manejar fuentes externas usadas para dibujar texto.

El tipo SvgExternalFontsHandling expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| ADD_LINKS_TO_FONT_FILES | Agregar enlaces a archivos de fuentes separados en la sección de estilo del archivo SVG. |
| EMBED | Guardar los datos de las fuentes directamente en el archivo SVG. Por favor, revise todos los acuerdos de licencia de fuentes externas antes de usar esta opción. |
| VECTORIZE | Guardar todo el texto que usa fuentes externas como gráficos. |
