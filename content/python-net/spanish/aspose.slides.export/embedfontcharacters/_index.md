## EmbedFontCharacters enumeración

Representa la regla a usar para agregar nuevas fuentes incrustadas en [`IPresentation`](/slides/python-net/es/aspose.slides/ipresentation)

El tipo EmbedFontCharacters expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| ONLY_USED | Incrusta solo los caracteres usados en la presentación (lo mejor para reducir el tamaño del archivo). |
| ALL | Incrusta todos los caracteres (lo mejor para la edición por otras personas). |
