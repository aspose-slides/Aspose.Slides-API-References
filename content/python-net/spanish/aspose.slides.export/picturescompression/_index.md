## Enumeración PicturesCompression

Representa el nivel de compresión de imágenes

El tipo PicturesCompression expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| DPI330 | Buena calidad para pantallas de alta definición (HD) |
| DPI220 | Calidad excelente en la mayoría de impresoras y pantallas |
| DPI150 | Adecuada para páginas web y proyectores |
| DPI96 | Minimiza el tamaño del documento para compartir |
| DPI72 | Nivel de compresión predeterminado |
| DOCUMENT_RESOLUTION | Usa la resolución del documento - la imagen no se comprimirá y se usará en el documento tal cual |
