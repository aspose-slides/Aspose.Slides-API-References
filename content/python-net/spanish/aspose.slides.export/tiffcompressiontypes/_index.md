## TiffCompressionTypes enumeración

Proporciona opciones que controlan cómo se comprime una presentación en formato TIFF.

El tipo TiffCompressionTypes expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| DEFAULT | Especifica el esquema de compresión predeterminado (LZW). |
| NONE | Especifica sin compresión. |
| CCITT3 | Especifica el esquema de compresión CCITT3. |
| CCITT4 | Especifica el esquema de compresión CCITT4. |
| LZW | Especifica el esquema de compresión LZW (Predeterminado). |
| RLE | Especifica el esquema de compresión RLE. |
