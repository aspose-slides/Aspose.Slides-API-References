## PdfCompliance enumeración

Constantes que definen el nivel de cumplimiento de los estándares PDF.

El tipo PdfCompliance expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| PDF15 | El archivo de salida cumplirá con el estándar PDF 1.5. |
| PDF16 | El archivo de salida cumplirá con el estándar PDF 1.6. |
| PDF17 | El archivo de salida cumplirá con el estándar PDF 1.7. |
| PDF_A1B | El archivo de salida cumplirá con el estándar PDF/A-1b. |
| PDF_A1A | El archivo de salida cumplirá con el estándar PDF/A-1a. |
| PDF_A2B | El archivo de salida cumplirá con el estándar PDF/A-2b. |
| PDF_A2A | El archivo de salida cumplirá con el estándar PDF/A-2a. |
| PDF_A3B | El archivo de salida cumplirá con el estándar PDF/A-3b. |
| PDF_A3A | El archivo de salida cumplirá con el estándar PDF/A-3a. |
| PDF_UA | El archivo de salida cumplirá con el estándar PDF/UA. |
| PDF_A2U | El archivo de salida cumplirá con el estándar PDF/A-2u. |
