## skip_java_script_links propiedad
Specifica si se deben omitir los hipervínculos con llamadas JavaScript al guardar la presentación. 
            Lectura/escritura **bool**. El valor predeterminado es **false** .


### Observaciones

Cuando esta propiedad se establece en **true**, los hipervínculos con llamadas JavaScript serán ignorados al guardar.


Cuando esta propiedad se establece en **false**, todos los hipervínculos se guardarán.
