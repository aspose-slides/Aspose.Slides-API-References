## SvgEvent enumeración

Representa opciones para la forma SVG.

El tipo SvgEvent expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| ON_FOCUS_IN | Ocurre cuando un elemento recibe foco, como cuando un texto se selecciona. |
| ON_FOCUS_OUT | Ocurre cuando un elemento pierde foco, como cuando un texto deja de estar seleccionado. |
| ON_ACTIVATE | Ocurre cuando un elemento se activa, por ejemplo, mediante un clic del ratón o una pulsación de tecla. |
| ON_CLICK | Ocurre cuando se pulsa el botón del dispositivo de apuntado sobre un elemento. |
| ON_MOUSE_DOWN | Ocurre cuando se presiona el botón del dispositivo de apuntado sobre un elemento. |
| ON_MOUSE_UP | Ocurre cuando se suelta el botón del dispositivo de apuntado sobre un elemento. |
| ON_MOUSE_OVER | Ocurre cuando el dispositivo de apuntado se mueve sobre un elemento. |
| ON_MOUSE_MOVE | Ocurre cuando el dispositivo de apuntado se mueve mientras está sobre un elemento. |
| ON_MOUSE_OUT | Ocurre cuando el dispositivo de apuntado se aleja de un elemento. |
| ON_LOAD | Ocurre cuando el agente de usuario ha analizado completamente el elemento y sus descendientes y todos los recursos referenciados, necesarios para renderizarlo. |
| ON_UNLOAD | Ocurre cuando la implementación del DOM elimina un documento de una ventana o marco. Solo aplicable a los elementos svg más externos. |
| ON_ABORT | Ocurre cuando la carga de la página se detiene antes de que un elemento haya podido cargarse completamente. |
| ON_ERROR | Ocurre cuando un elemento no se carga correctamente o cuando ocurre un error durante la ejecución del script. |
| ON_RESIZE | Ocurre cuando la vista de un documento se está redimensionando. Solo aplicable a los elementos svg más externos. |
| ON_SCROLL | Ocurre cuando la vista de un documento se desplaza a lo largo del eje X o Y o ambos. Solo aplicable a los elementos svg más externos. |
| ON_ZOOM | Ocurre cuando se cambia el nivel de zoom de la vista de un documento. Solo aplicable a los elementos svg más externos. |
| ON_BEGIN | Ocurre cuando un elemento de animación comienza. |
| ON_END | Ocurre cuando un elemento de animación termina. |
| ON_REPEAT | Ocurre cuando un elemento de animación se repite. |
