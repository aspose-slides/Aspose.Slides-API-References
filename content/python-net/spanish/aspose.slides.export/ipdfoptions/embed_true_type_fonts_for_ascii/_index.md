## embed_true_type_fonts_for_ascii propiedad
True para incrustar fuentes TrueType para caracteres ASCII 32-127.
            Las fuentes para códigos de carácter mayores que 127 siempre se incrustan.
            Lectura/escritura **bool**.


### Observaciones

El valor predeterminado es **true** .
