## text_compression propiedad
Especifica el tipo de compresión que se utilizará para todo el contenido textual del documento.
            Lectura/escritura [`PdfTextCompression`](/slides/python-net/es/aspose.slides.export/pdftextcompression).


### Observaciones

El valor predeterminado es [`PdfTextCompression.FLATE`](/slides/python-net/es/aspose.slides.export/pdftextcompression/FLATE).
