## Enumeración SaveFormat

Constantes que definen el formato de una presentación guardada.

El tipo SaveFormat expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| PPT | Guardar presentación en formato PPT. |
| PDF | Guardar presentación en formato PDF. |
| XPS | Guardar presentación en formato XPS. |
| PPTX | Guardar presentación en formato PPTX. |
| PPSX | Guardar presentación en formato PPSX (presentación de diapositivas). |
| TIFF | Guardar presentación como imagen TIFF multipágina. |
| ODP | Guardar presentación en formato ODP. |
| PPTM | Guardar presentación en formato PPTM (presentación con macros). |
| PPSM | Guardar presentación en formato PPSM (presentación de diapositivas con macros). |
| POTX | Guardar presentación en formato POTX (plantilla). |
| POTM | Guardar presentación en formato POTM (plantilla con macros). |
| HTML | Guardar presentación en formato HTML. |
| SWF | Guardar presentación en formato SWF. |
| OTP | Guardar presentación en formato OTP (plantilla de presentación). |
| PPS | Guardar presentación en formato PPS. |
| POT | Guardar presentación en formato POT. |
| FODP | Guardar presentación en formato FODP. |
| GIF | Guardar presentación en formato GIF. |
| HTML5 | Guardar presentación en formato HTML usando el nuevo sistema de plantillas HTML5. |
| MD | Guardar presentación en formato Markdown |
| XML | Guardar presentación en formato PowerPoint XML Presentation. |
