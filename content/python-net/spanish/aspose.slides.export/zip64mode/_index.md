## Enumeración Zip64Mode

Especifica cuándo usar extensiones de formato ZIP64 para el archivo OpenXML.

El tipo Zip64Mode expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| NEVER | No usar extensiones de formato ZIP64. |
| IF_NECESSARY | Usar extensiones de formato ZIP64 si es necesario. |
| ALWAYS | Siempre usar extensiones de formato ZIP64. |


### Observaciones

El archivo OpenXML es un archivo ZIP que tiene un límite de 4 GB (2^32 bytes) en el tamaño sin comprimir de un archivo, el tamaño comprimido de un archivo y el tamaño total del archivo, así como un límite de 65 535 (2^16-1) archivos en el archivo. Las extensiones del formato ZIP64 aumentan los límites a 2^64.
