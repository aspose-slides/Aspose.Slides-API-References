## TextInheritanceLimit enumeración

Controla la profundidad de la herencia de las propiedades de texto.

El tipo TextInheritanceLimit expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| ALL | Hereda todas las propiedades de texto. |
| TEXT_BOX | Hereda solo del estilo de TextFrame. |
| PARAGRAPH_ONLY | Utiliza solo las propiedades definidas para el párrafo. |
