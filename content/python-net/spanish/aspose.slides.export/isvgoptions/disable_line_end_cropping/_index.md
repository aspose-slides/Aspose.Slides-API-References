## disable_line_end_cropping propiedad
SVG 1.1 carece de la capacidad de definir inserciones para los marcadores.
            El motor de escritura SVG de Aspose.Slides tiene una solución alternativa para ese problema:
            Recorta el extremo de la línea con una flecha, por lo que la línea no se superpone a los marcadores.
            Esta opción desactiva ese comportamiento.
            Lectura/escritura **bool**.
