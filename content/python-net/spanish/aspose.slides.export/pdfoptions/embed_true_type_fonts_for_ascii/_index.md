## embed_true_type_fonts_for_ascii propiedad
Determina si Aspose.Slides incrustará fuentes comunes para texto ASCII (33..127 code range).
            Las fuentes para códigos de caracteres mayores que 127 siempre se incrustan.
            La lista de fuentes comunes incluye las 14 fuentes base de PDF y fuentes adicionales especificadas por el usuario.
            Lectura/escritura **bool**.

### Observaciones

El valor predeterminado es **true** .
