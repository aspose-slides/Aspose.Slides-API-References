## PdfTextCompression enumeración

Constantes que definen el tipo de compresión aplicada a todo el contenido del archivo PDF, excepto a las imágenes.

El tipo PdfTextCompression expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| NONE | Sin compresión. |
| FLATE | Compresión Flate (ZIP). |
