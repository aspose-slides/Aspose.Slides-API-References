## IPresentationAnimationPlayer clase

Representa un reproductor de la animación.

Animaciones generadas por [`PresentationAnimationsGenerator`](/slides/python-net/es/aspose.slides.export/presentationanimationsgenerator) a través de su evento **NewAnimation**.

El tipo IPresentationAnimationPlayer expone los siguientes miembros:

## Propiedades

| Property | Description |
| :- | :- |
| [`duration`](/slides/python-net/es/aspose.slides.export/ipresentationanimationplayer/duration/) | Obtiene la duración de la animación [ms] |

## Métodos

| Method | Description |
| :- | :- |
| [`set_time_position(self, time)`](/slides/python-net/es/aspose.slides.export/ipresentationanimationplayer/set_time_position/#float) | Establece la posición de tiempo de la animación dentro del [`IPresentationAnimationPlayer.duration`](/slides/python-net/es/aspose.slides.export/ipresentationanimationplayer/duration). |
| [`get_frame(self)`](/slides/python-net/es/aspose.slides.export/ipresentationanimationplayer/get_frame/#) | Obtiene el fotograma para la posición de tiempo actual previamente establecida con el método **Aspose.Slides.Export.IPresentationAnimationPlayer.SetTimePosition(Syste**. |
