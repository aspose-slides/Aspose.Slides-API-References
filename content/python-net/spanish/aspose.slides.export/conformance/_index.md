## Enumeración de conformidad

Especifica la clase de conformidad a la que se ajusta el documento PresentationML.

El tipo Conformance expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| ECMA_376_2006 | Especifica que el documento se ajusta a la ECMA376:2006. |
| ISO_29500_2008_TRANSITIONAL | Especifica que el documento se ajusta a la clase de conformidad ISO/IEC 29500:2008 Transitional. |
| ISO_29500_2008_STRICT | Especifica que el documento se ajusta a la clase de conformidad ISO/IEC 29500:2008 Strict. |
