## Reflection clase

Representa un efecto Reflection.

El tipo Reflection expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/es/aspose.slides.effects/reflection/start_pos_alpha/) | Especifica la posición inicial (a lo largo de la rampa de degradado alfa) del valor alfa inicial (porcientos).<br/>            Lectura/escritura **float**. |
| [`end_pos_alpha`](/slides/python-net/es/aspose.slides.effects/reflection/end_pos_alpha/) | Especifica la posición final (a lo largo de la rampa de degradado alfa) del valor alfa final (porcientos).<br/>            Lectura/escritura **float**. |
| [`fade_direction`](/slides/python-net/es/aspose.slides.effects/reflection/fade_direction/) | Especifica la dirección para desplazar la reflexión. (ángulo).<br/>            Lectura/escritura **float**. |
| [`start_reflection_opacity`](/slides/python-net/es/aspose.slides.effects/reflection/start_reflection_opacity/) | Opacidad inicial de la reflexión. (porcientos).<br/>            Lectura/escritura **float**. |
| [`end_reflection_opacity`](/slides/python-net/es/aspose.slides.effects/reflection/end_reflection_opacity/) | Opacidad final de la reflexión. (porcientos).<br/>            Lectura/escritura **float**. |
| [`blur_radius`](/slides/python-net/es/aspose.slides.effects/reflection/blur_radius/) | Radio de desenfoque.<br/>            Lectura/escritura **float**. |
| [`direction`](/slides/python-net/es/aspose.slides.effects/reflection/direction/) | Dirección de la reflexión.<br/>            Lectura/escritura **float**. |
| [`distance`](/slides/python-net/es/aspose.slides.effects/reflection/distance/) | Distancia de la reflexión.<br/>            Lectura/escritura **float**. |
| [`rectangle_align`](/slides/python-net/es/aspose.slides.effects/reflection/rectangle_align/) | Alineación del rectángulo.<br/>            Lectura/escritura [`RectangleAlignment`](/slides/python-net/es/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/es/aspose.slides.effects/reflection/skew_horizontal/) | Especifica el ángulo de sesgo horizontal.<br/>            Lectura/escritura **float**. |
| [`skew_vertical`](/slides/python-net/es/aspose.slides.effects/reflection/skew_vertical/) | Especifica el ángulo de sesgo vertical.<br/>            Lectura/escritura **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/es/aspose.slides.effects/reflection/rotate_shadow_with_shape/) | Especifica si la reflexión debe rotar con la forma cuando la forma está rotada.<br/>            Lectura/escritura **bool**. |
| [`scale_horizontal`](/slides/python-net/es/aspose.slides.effects/reflection/scale_horizontal/) | Especifica el factor de escala horizontal, una escala negativa provoca una inversión. (porcientos)<br/>            Lectura/escritura **float**. |
| [`scale_vertical`](/slides/python-net/es/aspose.slides.effects/reflection/scale_vertical/) | Especifica el factor de escala vertical, una escala negativa provoca una inversión. (porcientos)<br/>            Lectura/escritura **float**. |
