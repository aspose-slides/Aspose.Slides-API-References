## ZoomLayout enumeración

Especifica el diseño de zoom del resumen.

El tipo ZoomLayout expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| GRID_LAYOUT | Especifica el diseño como un diseño de cuadrícula para una lista de objetos. |
| FIXED_LAYOUT | Especifica el diseño con posicionamiento Zoom definido por el usuario. |
