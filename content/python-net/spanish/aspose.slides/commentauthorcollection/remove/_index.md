## remove(self, author) {#icommentauthor}
Elimina la primera aparición del autor especificado en una colección.

```python
def remove(self, author):
    ...
```

| Parámetro | Tipo | Descripción |
| :- | :- | :- |
| author | [`ICommentAuthor`](/slides/python-net/es/aspose.slides/icommentauthor) | El autor a eliminar de una colección. |

### Excepciones

| Excepción | Descripción |
| :- | :- |
| **RuntimeError(Proxy error(ArgumentNullException))** | El autor es `None` |
| [`PptxEditException`](/slides/python-net/es/aspose.slides/pptxeditexception) | Se lanza si el autor ya ha sido eliminado. |
