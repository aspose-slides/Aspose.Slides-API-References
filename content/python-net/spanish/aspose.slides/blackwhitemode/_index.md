## BlackWhiteMode enumeración

Determina cómo debe transformarse una forma coloreada a blanco y negro.

El tipo BlackWhiteMode expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| NOT_DEFINED | La propiedad no está establecida |
| COLOR | El objeto se renderiza con coloración normal |
| AUTOMATIC | El objeto se renderiza con coloración automática |
| GRAY | El objeto se renderiza con coloración gris |
| LIGHT_GRAY | El objeto se renderiza con coloración gris claro |
| INVERSE_GRAY | El objeto se renderiza con coloración gris inversa |
| GRAY_WHITE | El objeto se renderiza con coloración gris y blanco |
| BLACK_GRAY | El objeto se renderiza con coloración negro y gris |
| BLACK_WHITE | El objeto se renderiza con coloración negro y blanco |
| BLACK | El objeto se renderiza solo con coloración negra |
| WHITE | El objeto se renderiza con coloración blanca |
| HIDDEN | El objeto no se renderiza |
