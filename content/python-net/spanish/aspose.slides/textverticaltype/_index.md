## Enumeración TextVerticalType

Determina el modo de escritura vertical para un texto.

El tipo TextVerticalType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| NOT_DEFINED | No definido. |
| HORIZONTAL | Texto horizontal. |
| VERTICAL | Texto vertical. |
| VERTICAL270 | Texto vertical a 270 grados. |
| WORD_ART_VERTICAL | Texto vertical de WordArt. |
| EAST_ASIAN_VERTICAL | Texto vertical este asiático. |
| MONGOLIAN_VERTICAL | Texto vertical mongol. |
| WORD_ART_VERTICAL_RIGHT_TO_LEFT | Texto vertical de WordArt de derecha a izquierda. |
