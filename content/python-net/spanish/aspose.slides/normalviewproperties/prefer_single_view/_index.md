## prefer_single_view propiedad
Especifica si el usuario prefiere ver una región de contenido único a pantalla completa sobre la
            vista normal estándar con tres regiones de contenido. Si está habilitado, la aplicación puede elegir
            mostrar una de las regiones de contenido en toda la ventana.
            Lectura/escritura **bool**.
