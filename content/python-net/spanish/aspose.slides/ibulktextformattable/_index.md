## IBulkTextFormattable clase

Representa un objeto con la posibilidad de establecer en bloque los formatos de los elementos de texto secundarios.

El tipo IBulkTextFormattable expone los siguientes miembros:

## Métodos

| Método | Descripción |
| :- | :- |
| [`set_text_format(self, source)`](/slides/python-net/es/aspose.slides/ibulktextformattable/set_text_format/#iportionformat) | Establece las propiedades de formato de porción definidas a todas las porciones del elemento. |
| [`set_text_format(self, source)`](/slides/python-net/es/aspose.slides/ibulktextformattable/set_text_format/#iparagraphformat) | Establece las propiedades de formato de párrafo definidas a todos los párrafos del elemento. |
| [`set_text_format(self, source)`](/slides/python-net/es/aspose.slides/ibulktextformattable/set_text_format/#itextframeformat) | Establece las propiedades de formato de marco de texto definidas a todos los marcos de texto del elemento. |
