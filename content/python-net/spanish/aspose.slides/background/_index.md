## Background clase

Representa el fondo de una diapositiva.

**Herencia:**[`Background`](/slides/python-net/es/aspose.slides/background) → [`PVIObject`](/slides/python-net/es/aspose.slides/pviobject)

El tipo Background expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`type`](/slides/python-net/es/aspose.slides/background/type/) | Devuelve un tipo de relleno de fondo.<br/>            Lectura/Escritura [`BackgroundType`](/slides/python-net/es/aspose.slides/backgroundtype). |
| [`fill_format`](/slides/python-net/es/aspose.slides/background/fill_format/) | Devuelve un FillFormat para el relleno BackgroundType.OwnBackground.<br/>            Solo lectura [`IFillFormat`](/slides/python-net/es/aspose.slides/ifillformat). |
| [`effect_format`](/slides/python-net/es/aspose.slides/background/effect_format/) | Devuelve un EffectFormat para el relleno BackgroundType.OwnBackground.<br/>            Solo lectura [`IEffectFormat`](/slides/python-net/es/aspose.slides/ieffectformat). |
| [`style_color`](/slides/python-net/es/aspose.slides/background/style_color/) | Devuelve un ColorFormat para un relleno BackgroundType.Themed.<br/>            Solo lectura [`IColorFormat`](/slides/python-net/es/aspose.slides/icolorformat). |
| [`style_index`](/slides/python-net/es/aspose.slides/background/style_index/) | Devuelve un índice del relleno BackgroundType.Themed en la colección de temas de fondo.<br/>            0 significa sin relleno.<br/>            1..999 - índice.<br/>            Lectura/Escritura **int**. |
| [`slide`](/slides/python-net/es/aspose.slides/background/slide/) | Devuelve la diapositiva principal de una forma.<br/>            Solo lectura [`IBaseSlide`](/slides/python-net/es/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/es/aspose.slides/background/presentation/) | Devuelve la presentación principal de una diapositiva.<br/>            Solo lectura [`IPresentation`](/slides/python-net/es/aspose.slides/ipresentation). |
