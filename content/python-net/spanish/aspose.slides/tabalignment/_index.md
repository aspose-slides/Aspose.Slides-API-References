## TabAlignment enumeración

Representa la alineación de tabulación.

El tipo TabAlignment expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| LEFT | Alineación a la izquierda |
| CENTER | Alineación centrada |
| RIGHT | Alineación a la derecha |
| DECIMAL | Alineación decimal |
