## height propiedad
Obtiene o establece la height del shape, medido en puntos.
            Lectura/escritura **float**.

### Observaciones

El valor devuelto siempre está definido y nunca **float**.
            El valor asignado también debe estar definido; asigne **float** solo a las propiedades de una instancia `RawFrame`.
