## get_font_bytes(self, font_data, font_style) {#ifontdata-fontstyletype}
Recupera el array de bytes que representa los datos de la fuente para un estilo de fuente y datos de fuente especificados.

### Devuelve

Un array de bytes que contiene los datos de la fuente para el estilo de fuente especificado. Si los datos de la fuente o el estilo no se encuentran, devuelve None.
