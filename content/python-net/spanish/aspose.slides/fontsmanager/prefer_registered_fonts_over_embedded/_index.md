## prefer_registered_fonts_over_embedded propiedad
Especifica si se deben preferir las fuentes registradas sobre las fuentes incrustadas con el mismo nombre y estilo de fuente.
            Cuando está habilitado, las fuentes incrustadas coincidentes se sustituyen temporalmente por las fuentes registradas correspondientes durante la exportación.


### Observaciones

El valor predeterminado es **false**.
