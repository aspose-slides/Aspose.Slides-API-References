## remove(self, item) {#iparagraph}
Elimina la primera aparición de un objeto específico de la **System.Collections.Generic.ICollection`1**.

### Devuelve

true si `item` se eliminó correctamente de la **System.Collections.Generic.ICollection`1**; de lo contrario, false. Este método también devuelve false si `item` no se encuentra en la **System.Collections.Generic.ICollection`1** original.



```python
def remove(self, item):
    ...
```


| Parámetro | Tipo | Descripción |
| :- | :- | :- |
| item | [`IParagraph`](/slides/python-net/es/aspose.slides/iparagraph) | El objeto que se eliminará de la **System.Collections.Generic.ICollection`1**. |

### Excepciones

| Excepción | Descripción |
| :- | :- |
| **RuntimeError(Proxy error(NotSupportedException))** | La **System.Collections.Generic.ICollection`1** es de solo lectura. |
