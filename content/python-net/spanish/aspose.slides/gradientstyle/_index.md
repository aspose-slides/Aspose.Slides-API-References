## GradientStyle enumeración

Representa los estilos de degradado disponibles.

El tipo GradientStyle expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| DEFAULT | El estilo de degradado predeterminado. |
| POWER_POINT_UI | El estilo de degradado tal como aparece en la interfaz de usuario de PowerPoint. |
