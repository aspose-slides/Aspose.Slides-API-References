## link_path_relative propiedad
Devuelve la ruta relativa a un archivo vinculado si está presente, de lo contrario devuelve una cadena vacía.
             Solo lectura **str**.


### Observaciones

En las presentaciones Ppt, algunos enlaces a objetos Ole pueden tener una representación relativa.
