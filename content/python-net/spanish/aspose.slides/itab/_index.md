## ITab clase

Representa una tabulación para un texto.

El tipo ITab expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`position`](/slides/python-net/es/aspose.slides/itab/position/) | Devuelve o establece la posición de una tabulación.<br/>            Asignar esta propiedad puede cambiar el índice de la tabulación en la colección e invalidar el Enumerator.<br/>            Lectura/escritura **float**. |
| [`alignment`](/slides/python-net/es/aspose.slides/itab/alignment/) | Devuelve o establece el estilo de alineación de una tabulación.<br/>            Lectura/escritura [`TabAlignment`](/slides/python-net/es/aspose.slides/tabalignment). |
