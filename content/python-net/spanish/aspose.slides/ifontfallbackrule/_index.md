## IFontFallBackRule clase

Representa la regla de sustitución de fuentes

El tipo IFontFallBackRule expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`range_start_index`](/slides/python-net/es/aspose.slides/ifontfallbackrule/range_start_index/) | Obtiene el primer índice del rango unicode continuo. |
| [`range_end_index`](/slides/python-net/es/aspose.slides/ifontfallbackrule/range_end_index/) | Obtiene el último índice del rango unicode continuo. |
| [`count`](/slides/python-net/es/aspose.slides/ifontfallbackrule/count/) | Obtiene la cantidad de fuentes realmente definidas para el rango. |

Obtiene el nombre de la fuente en el índice especificado.
