## ICameraEffectiveData clase

Objeto inmutable que contiene las propiedades efectivas de la cámara.

El tipo ICameraEffectiveData expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`camera_type`](/slides/python-net/es/aspose.slides/icameraeffectivedata/camera_type/) | Tipo de cámara.<br/>            Solo lectura [`CameraPresetType`](/slides/python-net/es/aspose.slides/camerapresettype). |
| [`field_of_view_angle`](/slides/python-net/es/aspose.slides/icameraeffectivedata/field_of_view_angle/) | FOV de la cámara (0-180 deg, campo de visión).<br/>            Solo lectura **float**. |
| [`zoom`](/slides/python-net/es/aspose.slides/icameraeffectivedata/zoom/) | Zoom de la cámara (valor positivo en porcentaje).<br/>            Solo lectura **float**. |

## Métodos

| Método | Descripción |
| :- | :- |
| [`get_rotation(self)`](/slides/python-net/es/aspose.slides/icameraeffectivedata/get_rotation/#) | Una rotación se define mediante el uso de una latitud<br/>            coordenada, una coordenada de longitud y una revolución alrededor del eje <br/>            como las coordenadas de latitud y longitud.<br/>            primer elemento en el arreglo de retorno - latitud, segundo - longitud, tercero - revolución.<br/>            Devuelve None si no se ha definido una rotación. |
