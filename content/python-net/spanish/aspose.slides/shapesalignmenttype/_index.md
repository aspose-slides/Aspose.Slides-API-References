## Enumeración ShapesAlignmentType

Define una forma de cambiar la ubicación de las formas seleccionadas en la diapositiva.

El tipo ShapesAlignmentType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| ALIGN_LEFT | Alinear a la izquierda |
| ALIGN_RIGHT | Alinear a la derecha |
| ALIGN_CENTER | Alinear al centro |
| ALIGN_TOP | Alinear arriba |
| ALIGN_MIDDLE | Alinear al medio |
| ALIGN_BOTTOM | Alinear abajo |
| DISTRIBUTE_HORIZONTALLY | Distribuir horizontalmente |
| DISTRIBUTE_VERTICALLY | Distribuir verticalmente |
