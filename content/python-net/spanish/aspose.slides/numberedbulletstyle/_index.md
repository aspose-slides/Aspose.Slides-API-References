## NumberedBulletStyle enumeración

Representa el estilo de las viñetas numeradas.

El tipo NumberedBulletStyle expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| NOT_DEFINED | No definido. |
| BULLET_ALPHA_LC_PERIOD | Caracteres alfabéticos en minúsculas con un punto. Ejemplo: a., b., c., ... |
| BULLET_ALPHA_UC_PERIOD | Caracteres alfabéticos en mayúsculas con un punto. Ejemplo: A., B., C., ... |
| BULLET_ARABIC_PAREN_RIGHT | Números arábigos con paréntesis de cierre. Ejemplo: 1), 2), 3), ... |
| BULLET_ARABIC_PERIOD | Números arábigos con un punto. Ejemplo: 1., 2., 3., ... |
| BULLET_ROMAN_LC_PAREN_BOTH | Números romanos en minúsculas con ambos paréntesis. Ejemplo: (i), (ii), (iii), ... |
| BULLET_ROMAN_LC_PAREN_RIGHT | Números romanos en minúsculas con paréntesis de cierre. Ejemplo: i), ii), iii), ... |
| BULLET_ROMAN_LC_PERIOD | Números romanos en minúsculas con punto. Ejemplo: i., ii., iii., ... |
| BULLET_ROMAN_UC_PERIOD | Números romanos en mayúsculas con punto. Ejemplo: I., II., III., ... |
| BULLET_ALPHA_LC_PAREN_BOTH | Caracteres alfabéticos en minúsculas con ambos paréntesis. Ejemplo: (a), (b), (c), ... |
| BULLET_ALPHA_LC_PAREN_RIGHT | Caracteres alfabéticos en minúsculas con paréntesis de cierre. Ejemplo: a), b), c), ... |
| BULLET_ALPHA_UC_PAREN_BOTH | Caracteres alfabéticos en mayúsculas con ambos paréntesis. Ejemplo: (A), (B), (C), ... |
| BULLET_ALPHA_UC_PAREN_RIGHT | Caracteres alfabéticos en mayúsculas con paréntesis de cierre. Ejemplo: A), B), C), ... |
| BULLET_ARABIC_PAREN_BOTH | Números arábigos con ambos paréntesis. Ejemplo: (1), (2), (3), ... |
| BULLET_ARABIC_PLAIN | Números arábigos. Ejemplo: 1, 2, 3, ... |
| BULLET_ROMAN_UC_PAREN_BOTH | Números romanos en mayúsculas con ambos paréntesis. Ejemplo: (I), (II), (III), ... |
| BULLET_ROMAN_UC_PAREN_RIGHT | Números romanos en mayúsculas con paréntesis de cierre. Ejemplo: I), II), III), ... |
| BULLET_SIMP_CHIN_PLAIN | Chino simplificado sin punto. |
| BULLET_SIMP_CHIN_PERIOD | Chino simplificado con punto. |
| BULLET_CIRCLE_NUM_DB_PLAIN | Número circundado de doble byte para valores hasta 10, a partir de 11 - números arábigos. |
| BULLET_CIRCLE_NUM_WD_WHITE_PLAIN | Número de texto coloreado con círculo del mismo color dibujado a su alrededor (números de círculo blanco Wingdings). A partir de 11 - números arábigos. |
| BULLET_CIRCLE_NUM_WD_BLACK_PLAIN | Número de color sombra con fondo circular del color de texto normal (números de círculo negro Wingdings). |
| BULLET_TRAD_CHIN_PLAIN | Chino tradicional sin punto. |
| BULLET_TRAD_CHIN_PERIOD | Chino tradicional con punto. |
| BULLET_ARABIC_ALPHA_DASH | Caracteres alfabéticos del idioma árabe con guion. |
| BULLET_ARABIC_ABJAD_DASH | Alfabetos Abjad árabes con guion. |
| BULLET_HEBREW_ALPHA_DASH | Caracteres alfabéticos del idioma hebreo con guion. |
| BULLET_KANJI_KOREAN_PLAIN | Números japoneses/coreanos sin punto. |
| BULLET_KANJI_KOREAN_PERIOD | Números japoneses/coreanos con punto. |
| BULLET_ARABIC_DB_PLAIN | Esquema de numeración árabe de doble byte (sin puntuación). |
| BULLET_ARABIC_DB_PERIOD | Esquema de numeración árabe de doble byte con punto de doble byte. |
| BULLET_THAI_ALPHA_PERIOD | Alfabeto tailandés con punto. |
| BULLET_THAI_ALPHA_PAREN_RIGHT | Paréntesis del alfabeto tailandés - derecho. |
| BULLET_THAI_ALPHA_PAREN_BOTH | Paréntesis del alfabeto tailandés - ambos. |
| BULLET_THAI_NUM_PERIOD | Período numérico tailandés. |
| BULLET_THAI_NUM_PAREN_RIGHT | Paréntesis numéricos tailandeses - derecho. |
| BULLET_THAI_NUM_PAREN_BOTH | Paréntesis numéricos tailandeses - ambos. |
| BULLET_HINDI_ALPHA_PERIOD | Alfabeto hindi con punto - vocales. |
| BULLET_HINDI_NUM_PERIOD | Período numérico hindi. |
| BULLET_KANJI_SIMP_CHIN_DB_PERIOD | Kanji chino simplificado DBPeriod. |
| BULLET_HINDI_NUM_PAREN_RIGHT | Paréntesis numéricos hindi - derecho. |
| BULLET_HINDI_ALPHA_1_PERIOD | Alfabeto hindi con punto - consonantes. |
