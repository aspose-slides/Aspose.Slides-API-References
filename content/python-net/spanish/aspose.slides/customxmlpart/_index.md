## CustomXmlPart clase

Representa una parte xml personalizada.

El tipo CustomXmlPart expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`xml_data`](/slides/python-net/es/aspose.slides/customxmlpart/xml_data/) | Devuelve o establece datos xml.<br/>            Lectura/escritura **int**[].<br/>            el valor es `None`. el valor está vacío o los datos xml son inválidos. |
| [`xml_as_string`](/slides/python-net/es/aspose.slides/customxmlpart/xml_as_string/) | Devuelve o establece los datos xml como cadena UTF-8.<br/>            Lectura/escritura **str**.<br/>            el valor es `None`. el valor está vacío o los datos xml son inválidos. |
| [`item_id`](/slides/python-net/es/aspose.slides/customxmlpart/item_id/) | Especifica un identificador globalmente único (GUID) que identifica de forma única una única parte xml personalizada <br/>            dentro de un documento Office Open XML.<br/>            Solo lectura **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/es/aspose.slides/customxmlpart/namespace_schemas/) | Devuelve la colección de esquemas XML que están asociados con la parte xml personalizada.<br/>            Solo lectura **str**[]. |

## Métodos

| Método | Descripción |
| :- | :- |
| [`remove(self)`](/slides/python-net/es/aspose.slides/customxmlpart/remove/#) | Elimina la parte xml personalizada de la presentación. |
