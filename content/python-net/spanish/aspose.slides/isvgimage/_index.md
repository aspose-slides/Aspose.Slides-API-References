## ISvgImage clase

Representa una imagen SVG.

El tipo ISvgImage expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`svg_content`](/slides/python-net/es/aspose.slides/isvgimage/svg_content/) | Devuelve el contenido SVG.<br/>            Solo lectura **str**. |
| [`svg_data`](/slides/python-net/es/aspose.slides/isvgimage/svg_data/) | Devuelve los datos SVG.<br/>            Solo lectura **int**[]. |
| [`external_resource_resolver`](/slides/python-net/es/aspose.slides/isvgimage/external_resource_resolver/) | Devuelve la interfaz de devolución de llamada utilizada para resolver recursos externos durante la importación de documentos SVG.<br/>            Solo lectura **IExternalResourceResolver**. |
| [`base_uri`](/slides/python-net/es/aspose.slides/isvgimage/base_uri/) | Devuelve la URI base del SVG especificado. Se usa para resolver enlaces relativos.<br/>            Solo lectura **str**. |

## Métodos

| Método | Descripción |
| :- | :- |
| [`write_as_emf(self, stream)`](/slides/python-net/es/aspose.slides/isvgimage/write_as_emf/#iorawiobase) | Guarda la imagen SVG como un archivo EMF. |
