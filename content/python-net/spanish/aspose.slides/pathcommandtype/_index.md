## PathCommandType enumeración

Representa comandos de ruta gráfica

El tipo PathCommandType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| CLOSE | Cierra la ruta geométrica |
| MOVE_TO | Establece la posición del siguiente punto de la ruta geométrica |
| LINE_TO | Añade una línea a la ruta geométrica |
| ARC_TO | Añade el arco especificado a la ruta geométrica. |
| QUAD_BEZIER_TO | Añade una curva Bézier cuadrática a la ruta geométrica |
| CUBIC_BEZIER_TO | Añade una curva Bézier cúbica a la ruta geométrica |
