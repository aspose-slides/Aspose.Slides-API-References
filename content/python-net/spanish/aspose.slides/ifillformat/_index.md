## IFillFormat clase

Representa opciones de formato de relleno.

El tipo IFillFormat expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`fill_type`](/slides/python-net/es/aspose.slides/ifillformat/fill_type/) | Devuelve o establece el tipo de relleno.<br/>            Lectura/escritura [`FillType`](/slides/python-net/es/aspose.slides/filltype). |

| [`gradient_format`](/slides/python-net/es/aspose.slides/ifillformat/gradient_format/) | Devuelve el formato de relleno degradado.<br/>            Solo lectura [`IGradientFormat`](/slides/python-net/es/aspose.slides/igradientformat). |
| [`pattern_format`](/slides/python-net/es/aspose.slides/ifillformat/pattern_format/) | Devuelve el formato de relleno de patrón.<br/>            Solo lectura [`IPatternFormat`](/slides/python-net/es/aspose.slides/ipatternformat). |
| [`picture_fill_format`](/slides/python-net/es/aspose.slides/ifillformat/picture_fill_format/) | Devuelve el formato de relleno de imagen.<br/>            Solo lectura [`IPictureFillFormat`](/slides/python-net/es/aspose.slides/ipicturefillformat). |
