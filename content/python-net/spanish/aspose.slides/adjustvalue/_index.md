## AdjustValue clase

Representa el valor de ajuste de una forma geométrica.
            Estos valores afectan la forma de la figura.

El tipo AdjustValue expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`raw_value`](/slides/python-net/es/aspose.slides/adjustvalue/raw_value/) | Devuelve o establece el valor de ajuste "tal cual".<br/>            Lectura/escritura **int**. |
| [`angle_value`](/slides/python-net/es/aspose.slides/adjustvalue/angle_value/) | Devuelve o establece el valor, interpretándolo como ángulo en grados.<br/>            Lectura/escritura **float**. |
| [`name`](/slides/python-net/es/aspose.slides/adjustvalue/name/) | Devuelve un nombre de este valor de ajuste.<br/>            Solo lectura **str**. |
| [`type`](/slides/python-net/es/aspose.slides/adjustvalue/type/) | Devuelve el tipo de ajuste de la forma.<br/>            Solo lectura [`ShapeAdjustmentType`](/slides/python-net/es/aspose.slides/shapeadjustmenttype). |
