## ICellFormat clase

Representa el formato de una celda de tabla.

El tipo ICellFormat expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`fill_format`](/slides/python-net/es/aspose.slides/icellformat/fill_format/) | Devuelve un objeto de propiedades de relleno de celda.<br/>            Solo lectura [`IFillFormat`](/slides/python-net/es/aspose.slides/ifillformat). |
| [`border_left`](/slides/python-net/es/aspose.slides/icellformat/border_left/) | Devuelve un objeto de propiedades de línea del borde izquierdo.<br/>            Solo lectura [`ILineFormat`](/slides/python-net/es/aspose.slides/ilineformat). |
| [`border_top`](/slides/python-net/es/aspose.slides/icellformat/border_top/) | Devuelve un objeto de propiedades de línea del borde superior.<br/>            Solo lectura [`ILineFormat`](/slides/python-net/es/aspose.slides/ilineformat). |
| [`border_right`](/slides/python-net/es/aspose.slides/icellformat/border_right/) | Devuelve un objeto de propiedades de línea del borde derecho.<br/>            Solo lectura [`ILineFormat`](/slides/python-net/es/aspose.slides/ilineformat). |
| [`border_bottom`](/slides/python-net/es/aspose.slides/icellformat/border_bottom/) | Devuelve un objeto de propiedades de línea del borde inferior.<br/>            Solo lectura [`ILineFormat`](/slides/python-net/es/aspose.slides/ilineformat). |
| [`border_diagonal_down`](/slides/python-net/es/aspose.slides/icellformat/border_diagonal_down/) | Devuelve un objeto de propiedades de línea diagonal de arriba-izquierda a abajo-derecha.<br/>            Solo lectura [`ILineFormat`](/slides/python-net/es/aspose.slides/ilineformat). |
| [`border_diagonal_up`](/slides/python-net/es/aspose.slides/icellformat/border_diagonal_up/) | Devuelve un objeto de propiedades de línea diagonal de abajo-izquierda a arriba-derecha.<br/>            Solo lectura [`ILineFormat`](/slides/python-net/es/aspose.slides/ilineformat). |
| [`transparency`](/slides/python-net/es/aspose.slides/icellformat/transparency/) | Obtiene o establece la transparencia del color de relleno.<br/>            Lectura/escritura **float**. |
