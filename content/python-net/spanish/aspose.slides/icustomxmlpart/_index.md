## ICustomXmlPart clase

Representa una parte XML personalizada.

El tipo ICustomXmlPart expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`xml_as_string`](/slides/python-net/es/aspose.slides/icustomxmlpart/xml_as_string/) | Devuelve o establece datos xml como cadena UTF-8.<br/>            Lectura/escritura **str**.<br/>            el valor es `None`.el valor está vacío o xml-data es inválido. |
| [`xml_data`](/slides/python-net/es/aspose.slides/icustomxmlpart/xml_data/) | Devuelve o establece datos xml.<br/>            Lectura/escritura **int**[].<br/>            el valor es `None`.el valor está vacío o xml-data es inválido. |
| [`item_id`](/slides/python-net/es/aspose.slides/icustomxmlpart/item_id/) | Especifica un identificador único global (GUID) que identifica de forma única una única parte XML personalizada <br/>            dentro de un documento Office Open XML.<br/>            Solo lectura **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/es/aspose.slides/icustomxmlpart/namespace_schemas/) | Devuelve la colección de esquemas XML que están asociados con la parte XML personalizada.<br/>            Solo lectura **str**[]. |

## Métodos

| Método | Descripción |
| :- | :- |
| [`remove(self)`](/slides/python-net/es/aspose.slides/icustomxmlpart/remove/#) | Elimina la parte XML personalizada de la presentación. |
