## SlideLayoutType enumeración

Representa el tipo de diseño de diapositiva.

El tipo SlideLayoutType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| CUSTOM | Personalizado |
| TITLE | Título |
| TEXT | Texto |
| TWO_COLUMN_TEXT | Texto de dos columnas |
| TABLE | Tabla |
| TEXT_AND_CHART | Texto y gráfico |
| CHART_AND_TEXT | Gráfico y texto |
| DIAGRAM | Diagrama |
| CHART | Gráfico |
| TEXT_AND_CLIP_ART | Texto y Clip Art |
| CLIP_ART_AND_TEXT | Clip Art y texto |
| TITLE_ONLY | Solo título |
| BLANK | En blanco |
| TEXT_AND_OBJECT | Texto y objeto |
| OBJECT_AND_TEXT | Objeto y texto |
| OBJECT | Objeto |
| TITLE_AND_OBJECT | Título y objeto |
| TEXT_AND_MEDIA | Texto y medios |
| MEDIA_AND_TEXT | Medios y texto |
| OBJECT_OVER_TEXT | Objeto sobre texto |
| TEXT_OVER_OBJECT | Texto sobre objeto |
| TEXT_AND_TWO_OBJECTS | Texto y dos objetos |
| TWO_OBJECTS_AND_TEXT | Dos objetos y texto |
| TWO_OBJECTS_OVER_TEXT | Dos objetos sobre texto |
| FOUR_OBJECTS | Cuatro objetos |
| VERTICAL_TEXT | Texto vertical |
| CLIP_ART_AND_VERTICAL_TEXT | Clip Art y texto vertical |
| VERTICAL_TITLE_AND_TEXT | Título vertical y texto |
| VERTICAL_TITLE_AND_TEXT_OVER_CHART | Título vertical y texto sobre gráfico |
| TWO_OBJECTS | Dos objetos |
| OBJECT_AND_TWO_OBJECT | Objeto y dos objetos |
| TWO_OBJECTS_AND_OBJECT | Dos objetos y objeto |
| SECTION_HEADER | Encabezado de sección |
| TWO_TEXT_AND_TWO_OBJECTS | Dos textos y dos objetos |
| TITLE_OBJECT_AND_CAPTION | Título, objeto y leyenda |
| PICTURE_AND_CAPTION | Imagen y leyenda |
