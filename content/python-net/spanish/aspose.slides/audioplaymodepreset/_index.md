## AudioPlayModePreset enumeración

Constantes que definen cómo se reproduce un sonido.

El tipo AudioPlayModePreset expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| MIXED |  |
| AUTO | Reproduce automáticamente. |
| ON_CLICK | Reproduce solo cuando se hace clic en el ícono. |
| ALL_SLIDES | Reproduce en todas las diapositivas.<br/>Por favor use la propiedad [`IAudioFrame.play_across_slides`](/slides/python-net/es/aspose.slides/iaudioframe/play_across_slides) en su lugar.<br/>Este elemento está desactualizado desde PowerPoint 2013. |
