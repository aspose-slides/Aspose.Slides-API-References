## portion_format propiedad
Devuelve un objeto de formato que contiene las propiedades de formato establecidas explícitamente de la porción de texto sin aplicar herencia.
            Solo lectura [`IPortionFormat`](/slides/python-net/es/aspose.slides/iportionformat).

### Observaciones

El objeto de formato contiene los parámetros de formato definidos solo para la porción actual; los datos heredados no se aplican.

Para obtener los valores efectivos, incluidos los heredados, use el método [`PortionFormat.get_effective`](/slides/python-net/es/aspose.slides/portionformat/get_effective).
