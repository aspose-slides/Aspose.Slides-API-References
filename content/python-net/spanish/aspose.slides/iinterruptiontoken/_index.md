## IInterruptionToken clase

Esta clase representa el token que se usa para indicar a tareas de larga duración si se solicitó la interrupción.

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`is_interruption_requested`](/slides/python-net/es/aspose.slides/iinterruptiontoken/is_interruption_requested/) | Devuelve **bool**.true si se solicitó la interrupción. |

## Métodos

| Método | Descripción |
| :- | :- |
| [`throw_if_interruption_requested(self)`](/slides/python-net/es/aspose.slides/iinterruptiontoken/throw_if_interruption_requested/#) | Lanza una OperationCanceledException si<br/>            se solicitó la interrupción.<br/>            Lanzado cuando se solicitó la interrupción. |
