## Comment clase

Representa un comentario en una diapositiva.

El tipo Comment expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`text`](/slides/python-net/es/aspose.slides/comment/text/) | Devuelve o establece el texto sin formato de un comentario de diapositiva.<br/>            Lectura/escritura **str**. |
| [`created_time`](/slides/python-net/es/aspose.slides/comment/created_time/) | Devuelve o establece la hora de creación de un comentario.<br/>            Establecer esta propiedad a **System.DateTime** significa que no se ha establecido la hora del comentario.<br/>            Lectura/escritura **System.DateTime**. |
| [`slide`](/slides/python-net/es/aspose.slides/comment/slide/) | Devuelve o establece la diapositiva padre de un comentario.<br/>            Solo lectura [`ISlide`](/slides/python-net/es/aspose.slides/islide). |
| [`author`](/slides/python-net/es/aspose.slides/comment/author/) | Devuelve el autor de un comentario.<br/>            Solo lectura [`ICommentAuthor`](/slides/python-net/es/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/es/aspose.slides/comment/position/) | Devuelve o establece la posición de un comentario en una diapositiva.<br/>            Lectura/escritura **aspose.slides.PointF**. |
| [`parent_comment`](/slides/python-net/es/aspose.slides/comment/parent_comment/) | Obtiene o establece el comentario padre.<br/>            Lectura/escritura [`IComment`](/slides/python-net/es/aspose.slides/icomment). |

## Métodos

| Método | Descripción |
| :- | :- |
| [`remove(self)`](/slides/python-net/es/aspose.slides/comment/remove/#) | Elimina el comentario y todas sus respuestas de la colección padre. |
