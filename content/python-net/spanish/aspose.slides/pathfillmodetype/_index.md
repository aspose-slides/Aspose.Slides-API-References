## PathFillModeType enumeración

Especifica la forma en que debe rellenarse una ruta

El tipo PathFillModeType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| NONE | Sin relleno de ruta<br/>            Esto indica que la ruta correspondiente no debe tener relleno. |
| NORMAL | Relleno de ruta normal<br/>            Esto indica que la ruta correspondiente debe tener un color sombreado normalmente aplicado a su relleno. |
| LIGHTEN | Relleno de ruta aclarado<br/>            Esto indica que la ruta correspondiente debe tener  un color suavemente sombreado aplicado a su relleno. |
| LIGHTEN_LESS | Relleno de ruta aclarado menos<br/>            Esto indica que la ruta correspondiente debe tener un color ligeramente más claro sombreado aplicado a su relleno. |
| DARKEN | Relleno de ruta oscurecido<br/>            Esto indica que la ruta correspondiente debe tener un color más oscuro sombreado aplicado a su relleno. |
| DARKEN_LESS | Relleno de ruta oscurecido menos<br/>            Esto indica que la ruta correspondiente debe tener un color ligeramente más oscuro sombreado aplicado a su relleno. |
