## IBackground clase

Representa el fondo de una diapositiva.

El tipo IBackground expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`type`](/slides/python-net/es/aspose.slides/ibackground/type/) | Devuelve un tipo de relleno de fondo.<br/>            Lectura/escritura [`BackgroundType`](/slides/python-net/es/aspose.slides/backgroundtype). |
| [`fill_format`](/slides/python-net/es/aspose.slides/ibackground/fill_format/) | Devuelve un FillFormat para el relleno BackgroundType.OwnBackground.<br/>            Solo lectura [`IFillFormat`](/slides/python-net/es/aspose.slides/ifillformat). |
| [`effect_format`](/slides/python-net/es/aspose.slides/ibackground/effect_format/) | Devuelve un EffectFormat para el relleno BackgroundType.OwnBackground.<br/>            Solo lectura [`IEffectFormat`](/slides/python-net/es/aspose.slides/ieffectformat). |
| [`style_color`](/slides/python-net/es/aspose.slides/ibackground/style_color/) | Devuelve un ColorFormat para un relleno BackgroundType.Themed.<br/>            Solo lectura [`IColorFormat`](/slides/python-net/es/aspose.slides/icolorformat). |
| [`style_index`](/slides/python-net/es/aspose.slides/ibackground/style_index/) | Devuelve un índice del relleno BackgroundType.Themed en la colección de temas de fondo.<br/>            0 significa sin relleno.<br/>            1..999 - índice.<br/>            Lectura/escritura **int**. |
| [`slide`](/slides/python-net/es/aspose.slides/ibackground/slide/) |  |
