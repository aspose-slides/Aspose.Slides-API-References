## ITextSearchOptions clase

Representa opciones que pueden usarse para buscar texto en una Presentation, Slide o TextFrame.

El tipo ITextSearchOptions expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`case_sensitive`](/slides/python-net/es/aspose.slides/itextsearchoptions/case_sensitive/) | Establezca true para usar búsqueda sensible a mayúsculas y minúsculas, false - en caso contrario.<br/>            Lectura/escritura **bool**. |
| [`whole_words_only`](/slides/python-net/es/aspose.slides/itextsearchoptions/whole_words_only/) | Establezca true para coincidir solo con palabras completas, false - en caso contrario.<br/>            Lectura/escritura **bool**. |
| [`include_notes`](/slides/python-net/es/aspose.slides/itextsearchoptions/include_notes/) | Establezca `true` para incluir texto contenido en notas de diapositiva <br/>            al realizar búsquedas de texto, reemplazos o operaciones de resaltado.<br/>            El valor predeterminado es `false`. |
