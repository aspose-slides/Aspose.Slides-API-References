## ImageFormat enumeración

Representa el formato de archivo de la imagen.

El tipo ImageFormat expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| MEMORY_BMP | Representa el formato de un mapa de bits en memoria. |
| BMP | Representa el formato de imagen BMP (bitmap). |
| EMF | Representa el formato de imagen EMF (metarchivo mejorado). |
| WMF | Representa el formato de imagen WMF (metarchivo de Windows). |
| GIF | Representa el formato de imagen GIF (Graphics Interchange Format). |
| JPEG | Representa el formato de imagen JPEG (Joint Photographic Experts Group). |
| PNG | Representa el formato de imagen PNG (Portable Network Graphics de W3C). |
| TIFF | Representa el formato de imagen TIFF (Tagged Image File Format). |
| EXIF | Representa el formato EXIF (Exchangeable Image File). |
| ICON | Representa el formato de imagen de icono de Windows. |
