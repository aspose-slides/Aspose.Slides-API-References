## IFontSources clase

Proporciona fuentes de archivo y de memoria para fuentes externas.

El tipo IFontSources expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`font_folders`](/slides/python-net/es/aspose.slides/ifontsources/font_folders/) | Carpetas que contienen archivos de fuente.<br/>            Todos los archivos de fuente ubicados en estas carpetas están incluidos en la colección. Carpetas que se buscan recursivamente. |
| [`memory_fonts`](/slides/python-net/es/aspose.slides/ifontsources/memory_fonts/) | Una colección de fuentes representadas como matrices de bytes. |
