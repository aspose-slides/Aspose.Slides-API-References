## ShapeAdjustmentType enumeración

Especifica diferentes tipos de valores de ajuste de forma.

El tipo ShapeAdjustmentType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| CUSTOM | Tipo personalizado (ajuste desconocido) |
| CORNER_SIZE | Controla el tamaño de las esquinas. |
| LEFT_UP_CORNER | Controla la esquina superior izquierda. |
| RIGHT_UP_CORNER | Controla la esquina superior derecha. |
| UP_CORNERS | Controla las esquinas superiores. |
| DOWN_CORNERS | Controla las esquinas inferiores. |
| THICKNESS | Controla el grosor de la figura. |
| ARROW_TAIL_THICKNESS | Controla el grosor de la cola de la flecha. |
| ARROWHEAD_LENGTH | Controla la longitud de la punta de la flecha. |
| ARROWHEAD_WIDTH | Controla el ancho de la punta de la flecha. |
| RADIUS | Controla el tamaño del radio de la forma o de su parte. |
| DEPTH | Controla la profundidad de los dientes del engranaje o el efecto de bisel. |
| SHAPE_PART_OFFSET | Controla el desplazamiento de una parte de la figura respecto a otra. |
| ANGLE | Controla el ángulo de la figura o de su parte. |
| START_ANGLE | Ángulo de inicio para formas de pastel y arco. |
| END_ANGLE | Ángulo final para formas de pastel y arco. |
| START_POINT_X | Controla la posición X del punto de inicio de la anotación. |
| START_POINT_Y | Controla la posición Y del punto de inicio de la anotación. |
| CONNECTOR_POINT_1X | Controla la posición horizontal del punto de ajuste del ángulo de la anotación. |
| CONNECTOR_POINT_1Y | Controla la posición vertical del punto de ajuste del ángulo de la anotación. |
| CONNECTOR_POINT_2X | Controla la posición horizontal del punto de ajuste del ángulo de la anotación. |
| CONNECTOR_POINT_2Y | Controla la posición vertical del punto de ajuste del ángulo de la anotación. |
| CONNECTOR_BEND_POSITION_X | Controla la posición horizontal de la curvatura del conector. |
| CONNECTOR_BEND_POSITION_Y | Controla la posición vertical de la curvatura del conector. |
| ATTACH_Y | Controla el punto de unión vertical de la figura. |
| ATTACH_X | Controla el punto de unión horizontal de la figura. |
| CALLOUT_HEIGHT | Controla el tamaño vertical de la anotación. |
| CALLOUT_WIDTH | Controla el tamaño horizontal de la anotación. |
| CALLOUT_SIZE | Controla el tamaño de la anotación. |
| CURVATURE | Curvatura de una barra doblada, llaves, flecha curvada o forma. |
| HORIZONTAL_THICKNESS | Controla el grosor horizontal de la forma de la esquina. |
| VERTICAL_THICKNESS | Controla el grosor vertical de la forma de la esquina. |
| VERTICAL_SIZE | Controla el tamaño vertical de la forma. |
| HORIZONTAL_SIZE | Controla el tamaño horizontal de la forma. |
| TOP | Controla el lado superior de una forma. |
