## clase ILightRigEffectiveData

Objeto inmutable que contiene las propiedades efectivas del rig de luz.

El tipo ILightRigEffectiveData expone los siguientes miembros:

## Propiedades

| Property | Description |
| :- | :- |
| [`direction`](/slides/python-net/es/aspose.slides/ilightrigeffectivedata/direction/) | Dirección de la luz.<br/>            Solo lectura [`LightingDirection`](/slides/python-net/es/aspose.slides/lightingdirection). |
| [`light_type`](/slides/python-net/es/aspose.slides/ilightrigeffectivedata/light_type/) | Representa una luz preestablecida que puede aplicarse a una forma. <br/>            El rig de luz representa un grupo de luces orientadas de una manera específica en relación con una escena 3D.<br/>            Solo lectura [`LightRigPresetType`](/slides/python-net/es/aspose.slides/lightrigpresettype). |

## Métodos

| Method | Description |
| :- | :- |
| [`get_rotation(self)`](/slides/python-net/es/aspose.slides/ilightrigeffectivedata/get_rotation/#) | Una rotación se define mediante el uso de una coordenada de latitud, una coordenada de longitud y una revolución alrededor del eje según las coordenadas de latitud y longitud.<br/>            Primer elemento en la matriz devuelta - latitud, segundo - longitud, tercero - revolución. |


### Observaciones

Esta interfaz se usa como parte de [`IThreeDFormatEffectiveData`](/slides/python-net/es/aspose.slides/ithreedformateffectivedata).
