## Clase Point

Representa un par ordenado de coordenadas enteras x e y que define un punto en un plano bidimensional. Compatible con .NET `System.Drawing.Point`.

El tipo Point expone los siguientes miembros:

## Constructores

| Constructor | Descripción |
| :- | :- |
| [`__init__(self, x=0, y=0)`](/slides/python-net/es/aspose.slides/point/__init__/#int-int) | Crea un punto con las coordenadas especificadas. Los valores flotantes se truncan a enteros. |

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`x`](/slides/python-net/es/aspose.slides/point/x/) | Obtiene o establece la coordenada x de este punto.<br/>            Lectura/escritura **int**. |
| [`y`](/slides/python-net/es/aspose.slides/point/y/) | Obtiene o establece la coordenada y de este punto.<br/>            Lectura/escritura **int**. |

### Observaciones

Los puntos se comparan por sus coordenadas con `==` y pueden usarse como claves de diccionario o como miembros de conjunto.
