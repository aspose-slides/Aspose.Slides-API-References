## IPPImage clase

Representa una imagen en una presentación.

El tipo IPPImage expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`binary_data`](/slides/python-net/es/aspose.slides/ippimage/binary_data/) | Devuelve una copia de los datos de una imagen.<br/>            Solo lectura **int**[] |
| [`image`](/slides/python-net/es/aspose.slides/ippimage/image/) | Devuelve una copia de una imagen.<br/>            Solo lectura [`IPPImage.image`](/slides/python-net/es/aspose.slides/ippimage/image). |
| [`svg_image`](/slides/python-net/es/aspose.slides/ippimage/svg_image/) | Devuelve o establece el objeto ISvgImage [`ISvgImage`](/slides/python-net/es/aspose.slides/isvgimage) |
| [`content_type`](/slides/python-net/es/aspose.slides/ippimage/content_type/) | Devuelve un tipo MIME de una imagen, codificado en [`IPPImage.binary_data`](/slides/python-net/es/aspose.slides/ippimage/binary_data).<br/>            Solo lectura **str**. |
| [`width`](/slides/python-net/es/aspose.slides/ippimage/width/) | Devuelve el ancho de una imagen.<br/>            Solo lectura **int**. |
| [`height`](/slides/python-net/es/aspose.slides/ippimage/height/) | Devuelve la altura de una imagen.<br/>            Solo lectura **int**. |
| [`x`](/slides/python-net/es/aspose.slides/ippimage/x/) | Devuelve el desplazamiento X de una imagen.<br/>            Solo lectura **int**. |
| [`y`](/slides/python-net/es/aspose.slides/ippimage/y/) | Devuelve el desplazamiento Y de una imagen.<br/>            Solo lectura **int**. |
