## clase IControl

Representa un control ActiveX.

El tipo IControl expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`name`](/slides/python-net/es/aspose.slides/icontrol/name/) | Devuelve el nombre de este control.<br/>            Lectura/escritura **str**. |
| [`class_id`](/slides/python-net/es/aspose.slides/icontrol/class_id/) | Obtiene el id de clase de este control.<br/>            Solo lectura **System.Guid**. |
| [`substitute_picture_format`](/slides/python-net/es/aspose.slides/icontrol/substitute_picture_format/) | Devuelve el objeto de propiedades de relleno de imagen de ControlEx.<br/>            Solo lectura [`IPictureFillFormat`](/slides/python-net/es/aspose.slides/ipicturefillformat). |
| [`frame`](/slides/python-net/es/aspose.slides/icontrol/frame/) | Devuelve o establece el marco del control.<br/>            Lectura/escritura [`IShapeFrame`](/slides/python-net/es/aspose.slides/ishapeframe). |
| [`properties`](/slides/python-net/es/aspose.slides/icontrol/properties/) | Devuelve una colección de propiedades ActiveX.<br/>            Solo lectura [`IControlPropertiesCollection`](/slides/python-net/es/aspose.slides/icontrolpropertiescollection). |
| [`persistence`](/slides/python-net/es/aspose.slides/icontrol/persistence/) | Obtiene el método utilizado para almacenar las propiedades del control ActiveX.<br/>            Solo lectura [`PersistenceType`](/slides/python-net/es/aspose.slides/persistencetype). |
| [`active_x_control_binary`](/slides/python-net/es/aspose.slides/icontrol/active_x_control_binary/) | Especifica la persistencia de un control ActiveX cuando el método utilizado para persistir es PersistStream, PersistStreamInit o PersistStorage. |
