## INotesSlideManager clase

Administrador de diapositivas de notas.

El tipo INotesSlideManager expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`notes_slide`](/slides/python-net/es/aspose.slides/inotesslidemanager/notes_slide/) | Devuelve la diapositiva de notas para la diapositiva actual. Devuelve None si la diapositiva no tiene diapositiva de notas.<br/>Solo lectura [`INotesSlide`](/slides/python-net/es/aspose.slides/inotesslide). |

## Métodos

| Método | Descripción |
| :- | :- |
| [`add_notes_slide(self)`](/slides/python-net/es/aspose.slides/inotesslidemanager/add_notes_slide/#) | Devuelve la diapositiva de notas para la diapositiva actual, creando una si no existe. |
| [`remove_notes_slide(self)`](/slides/python-net/es/aspose.slides/inotesslidemanager/remove_notes_slide/#) | Elimina la diapositiva de notas de la diapositiva actual. |
