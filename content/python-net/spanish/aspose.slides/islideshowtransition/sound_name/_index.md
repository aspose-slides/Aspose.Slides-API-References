## sound_name propiedad
Especifica un nombre legible para el sonido de la transición. La propiedad [`ISlideShowTransition.sound`](/slides/python-net/es/aspose.slides/islideshowtransition/sound) debe asignarse para obtener o establecer el nombre del sonido.
            Lectura-escritura **str**.

### Observaciones

Este nombre aparece en la interfaz de usuario de PowerPoint al configurar el sonido de la transición manualmente.
