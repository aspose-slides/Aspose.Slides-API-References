## sound_is_built_in propiedad
Especifica si este sonido es o no un sonido incorporado. Si este atributo se establece en true entonces
            la aplicación generadora es alertada para comprobar el atributo name especificado para este sonido
            en su lista de sonidos incorporados y puede entonces mostrar un nombre personalizado o una interfaz de usuario según sea necesario.
            Lectura-escritura **bool**.
