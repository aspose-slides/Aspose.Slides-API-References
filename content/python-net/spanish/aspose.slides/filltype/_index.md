## FillType enumeración

Especifica el tipo de relleno interior de varios objetos visuales.

El tipo FillType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| NOT_DEFINED | El tipo de relleno no está definido. |
| NO_FILL | No se aplica relleno. |
| SOLID | Relleno con un color sólido. |
| GRADIENT | El relleno es un degradado. |
| PATTERN | Se usa un patrón repetido para rellenar el objeto. |
| PICTURE | Se usa una sola imagen para rellenar el objeto. |
| GROUP | El objeto visual hereda las propiedades de relleno del grupo. |
