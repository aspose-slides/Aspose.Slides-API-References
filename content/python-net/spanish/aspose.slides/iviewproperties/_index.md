## IViewProperties clase

Propiedades de vista a nivel de presentación.

El tipo IViewProperties expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`last_view`](/slides/python-net/es/aspose.slides/iviewproperties/last_view/) | Especifica el modo de vista que se utilizó cuando el documento de presentación se guardó por última vez.<br/>            Lectura/escritura [`ViewType`](/slides/python-net/es/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/es/aspose.slides/iviewproperties/show_comments/) | Especifica si los comentarios de diapositiva deben mostrarse.<br/>            Lectura/escritura [`NullableBool`](/slides/python-net/es/aspose.slides/nullablebool). |
| [`slide_view_properties`](/slides/python-net/es/aspose.slides/iviewproperties/slide_view_properties/) | Especifica las propiedades de vista comunes asociadas con el modo de vista de diapositiva.<br/>            Solo lectura [`ICommonSlideViewProperties`](/slides/python-net/es/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/es/aspose.slides/iviewproperties/notes_view_properties/) | Especifica las propiedades de vista comunes asociadas con el modo de vista de notas.<br/>            Solo lectura [`ICommonSlideViewProperties`](/slides/python-net/es/aspose.slides/icommonslideviewproperties). |
| [`normal_view_properties`](/slides/python-net/es/aspose.slides/iviewproperties/normal_view_properties/) | Representa las propiedades de vista normal. La vista normal consta de<br/>            tres regiones de contenido: la propia diapositiva, una región de contenido lateral y una región de contenido inferior.<br/>            Solo lectura [`INormalViewProperties`](/slides/python-net/es/aspose.slides/inormalviewproperties). |
| [`grid_spacing`](/slides/python-net/es/aspose.slides/iviewproperties/grid_spacing/) | Devuelve o establece el espaciado de la cuadrícula que debe usarse para la cuadrícula subyacente al documento de presentación, en puntos. <br/>            Lectura/escritura **float**. |
