## compare_to(self, obj) {#any}
Compara la instancia actual con otro objeto del mismo tipo.

### Devuelve
Un entero de 32 bits que indica el orden relativo de los comparandos.
            El valor devuelto tiene estos significados:
            
*  < 0 - Esta instancia es menor que obj. = 0 - Esta instancia es igual a obj. > 0 - Esta instancia es mayor que obj.

*  < 0 - Esta instancia es menor que obj. = 0 - Esta instancia es igual a obj. > 0 - Esta instancia es mayor que obj.

*  < 0 - Esta instancia es menor que obj. = 0 - Esta instancia es igual a obj. > 0 - Esta instancia es mayor que obj.
