## PlaceholderType enumeración

Representa el tipo de un marcador de posición.

El tipo PlaceholderType expone los siguientes miembros:

| SLIDE_NUMBER | Número de diapositiva. |
| FOOTER | Pie de página. |

| OBJECT | Objeto. |
| CHART | Gráfica. |
