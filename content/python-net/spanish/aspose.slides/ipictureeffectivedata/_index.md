## IPictureEffectiveData clase

Objeto inmutable que contiene las propiedades efectivas de la imagen.

El tipo IPictureEffectiveData expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`image`](/slides/python-net/es/aspose.slides/ipictureeffectivedata/image/) | Devuelve la imagen incrustada.<br/>            Solo lectura [`IPPImage`](/slides/python-net/es/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/es/aspose.slides/ipictureeffectivedata/link_path_long/) | Devuelve la URL de la imagen vinculada.<br/>            Solo lectura **str**. |
| [`image_transform`](/slides/python-net/es/aspose.slides/ipictureeffectivedata/image_transform/) | Devuelve la colección de efectos de transformación de la imagen.<br/>            Solo lectura [`IImageTransformOCollectionEffectiveData`](/slides/python-net/es/aspose.slides.effects/iimagetransformocollectioneffectivedata). |


### Observaciones

Esta interfaz se usa como parte de [`IPictureFillFormatEffectiveData`](/slides/python-net/es/aspose.slides/ipicturefillformateffectivedata) y [`IBulletFormatEffectiveData`](/slides/python-net/es/aspose.slides/ibulletformateffectivedata).
