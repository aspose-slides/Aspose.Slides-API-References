## TextAutofitType enumeración

Representa el modo de autoajuste de texto.

El tipo TextAutofitType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| NOT_DEFINED | No definido. |
| NONE | Sin autoajuste. |
| NORMAL | Autoajuste normal. El tamaño de fuente y el interlineado se reducirán para ajustarse a la forma. |
| SHAPE | Autoajuste de forma. El tamaño de la forma se cambiará para ajustarse al texto. |
