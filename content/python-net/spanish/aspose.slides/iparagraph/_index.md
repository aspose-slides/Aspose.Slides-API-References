## IParagraph clase

Representa un párrafo de un texto.

El tipo IParagraph expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`portions`](/slides/python-net/es/aspose.slides/iparagraph/portions/) | Devuelve la colección de porciones de texto.<br/>            Solo lectura [`IPortionCollection`](/slides/python-net/es/aspose.slides/iportioncollection). |
| [`paragraph_format`](/slides/python-net/es/aspose.slides/iparagraph/paragraph_format/) | Devuelve el objeto de formato para este párrafo.<br/>            Solo lectura [`IParagraphFormat`](/slides/python-net/es/aspose.slides/iparagraphformat). |
| [`text`](/slides/python-net/es/aspose.slides/iparagraph/text/) | Obtiene o establece el texto sin formato de un párrafo.<br/>            Lectura/escritura **str**. |
| [`end_paragraph_portion_format`](/slides/python-net/es/aspose.slides/iparagraph/end_paragraph_portion_format/) | Especifica las propiedades de la porción que se usarán si se inserta otra porción después <br/>            de la última. |
| [`slide`](/slides/python-net/es/aspose.slides/iparagraph/slide/) |  |
| [`presentation`](/slides/python-net/es/aspose.slides/iparagraph/presentation/) |  |

## Métodos

| Método | Descripción |
| :- | :- |
| [`get_image`](/slides/python-net/es/aspose.slides/iparagraph/get_image/#) | Devuelve una imagen del párrafo. |
| [`get_image`](/slides/python-net/es/aspose.slides/iparagraph/get_image/#float-float) | Devuelve una imagen del párrafo con la escala especificada. |
| [`join_portions_with_same_formatting`](/slides/python-net/es/aspose.slides/iparagraph/join_portions_with_same_formatting/#) | Une ejecuciones con el mismo formato. |
| [`get_rect`](/slides/python-net/es/aspose.slides/iparagraph/get_rect/#) | Obtiene las coordenadas del rectángulo que delimita el párrafo. El rectángulo incluye todas las líneas de<br/>            texto en el párrafo, incluidas las vacías. |
| [`get_lines_count`](/slides/python-net/es/aspose.slides/iparagraph/get_lines_count/#) | Obtiene el número de líneas en un párrafo. |
