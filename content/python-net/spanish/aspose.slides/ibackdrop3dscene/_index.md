## Clase IBackdrop3DScene

Define un plano en el que los efectos, como el resplandor y la sombra, se aplican en relación con la forma a la que se aplican.

El tipo IBackdrop3DScene expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`normal_vector`](/slides/python-net/es/aspose.slides/ibackdrop3dscene/normal_vector/) | Devuelve o establece un vector normal. Para ser más preciso, este atributo define un vector<br/>            normal a la cara del plano de fondo. Vector representado por una matriz de 3 valores **float**<br/>            que definen las coordenadas X, Y y Z.<br/>            Lectura/escritura **float**[]. |
| [`anchor_point`](/slides/python-net/es/aspose.slides/ibackdrop3dscene/anchor_point/) | Devuelve o establece un punto en el espacio 3D. Este punto es el punto en el espacio que ancla el plano de fondo.<br/>            Punto 3D representado por una matriz de 3 valores **float** que definen las coordenadas X, Y y Z.<br/>            Lectura/escritura **float**[]. |
| [`up_vector`](/slides/python-net/es/aspose.slides/ibackdrop3dscene/up_vector/) | Devuelve o establece un vector que representa la dirección hacia arriba. Para ser más preciso, este atributo define un vector<br/>            que representa la dirección hacia arriba en relación con la cara del plano de fondo. Vector representado por una matriz<br/>            de 3 valores **float** que definen las coordenadas X, Y y Z.<br/>            Lectura/escritura **float**[]. |
