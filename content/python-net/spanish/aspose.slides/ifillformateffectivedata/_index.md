## IFillFormatEffectiveData clase

Objeto inmutable que contiene propiedades de formato de relleno efectivas.

El tipo IFillFormatEffectiveData expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`fill_type`](/slides/python-net/es/aspose.slides/ifillformateffectivedata/fill_type/) | Devuelve el tipo de relleno.<br/>            Solo lectura [`FillType`](/slides/python-net/es/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/es/aspose.slides/ifillformateffectivedata/solid_fill_color/) | Devuelve el color de relleno.<br/>            Solo lectura **aspose.slides.Color**. |
| [`solid_fill_scheme_color`](/slides/python-net/es/aspose.slides/ifillformateffectivedata/solid_fill_scheme_color/) | Obtiene el color de relleno definido por un esquema de colores.<br/>            El valor [`SchemeColor.NOT_DEFINED`](/slides/python-net/es/aspose.slides/schemecolor/NOT_DEFINED) indica que el [`IFillFormatEffectiveData.solid_fill_color`](/slides/python-net/es/aspose.slides/ifillformateffectivedata/solid_fill_color) <br/>            no es un color de esquema.<br/>            Solo lectura [`SchemeColor`](/slides/python-net/es/aspose.slides/schemecolor). |
| [`gradient_format`](/slides/python-net/es/aspose.slides/ifillformateffectivedata/gradient_format/) | Devuelve el formato de relleno degradado.<br/>            Solo lectura [`IGradientFormatEffectiveData`](/slides/python-net/es/aspose.slides/igradientformateffectivedata). |
| [`pattern_format`](/slides/python-net/es/aspose.slides/ifillformateffectivedata/pattern_format/) | Devuelve el formato de relleno de patrón.<br/>            Solo lectura [`IPatternFormatEffectiveData`](/slides/python-net/es/aspose.slides/ipatternformateffectivedata). |
| [`picture_fill_format`](/slides/python-net/es/aspose.slides/ifillformateffectivedata/picture_fill_format/) | Devuelve el formato de relleno de imagen.<br/>            Solo lectura [`IPictureFillFormatEffectiveData`](/slides/python-net/es/aspose.slides/ipicturefillformateffectivedata). |
| [`rotate_with_shape`](/slides/python-net/es/aspose.slides/ifillformateffectivedata/rotate_with_shape/) | Determina si el relleno debe rotarse con la forma.<br/>            Solo lectura **bool**. |


### Observaciones

Esta interfaz se usa junto con la interfaz [`IFillFormat`](/slides/python-net/es/aspose.slides/ifillformat) para devolver valores de formato efectivos con herencia aplicada.
