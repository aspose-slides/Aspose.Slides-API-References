## Enumeración ResourceLoadingAction

Especifica el modo de carga de recursos externos.

El tipo ResourceLoadingAction expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| DEFAULT | Aspose.Slides cargará el recurso externo como de costumbre. |
| SKIP | Aspose.Slides omitirá la carga del recurso externo. Solo se almacenará el enlace sin datos para una imagen. |
| USER_PROVIDED | Aspose.Slides usará el arreglo de bytes proporcionado por el usuario en **Aspose.Slides.IResourceLoadingArgs.SetData(Syste** como datos de imagen. |
