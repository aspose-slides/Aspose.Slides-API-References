## Enumeración SlideSizeType

Representa la configuración predefinida del tamaño de diapositiva.

El tipo SlideSizeType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| ON_SCREEN | En pantalla 4x3 |
| LETTER_PAPER | Carta |
| A4_PAPER | A4 |
| SLIDE_35MM | Diapositiva 35mm |
| OVERHEAD | Proyección |
| BANNER | Banner |
| CUSTOM | Tamaño personalizado |
| LEDGER | Ledger |
| A3_PAPER | A3 |
| B4_ISO_PAPER | B4 ISO |
| B5_ISO_PAPER | B5 ISO |
| B4_JIS_PAPER | B4 JIS |
| B5_JIS_PAPER | B5 JIS |
| HAGAKI_CARD | Tarjeta Hagaki |
| ON_SCREEN_16X9 | En pantalla 16x9 |
| ON_SCREEN_16X10 | En pantalla 16x10 |
| WIDESCREEN | Pantalla ancha |
