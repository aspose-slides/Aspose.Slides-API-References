## SourceFormat enumeración

Representa el formato de archivo fuente.

El tipo SourceFormat expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| PPT | Microsoft PowerPoint 97-2003 Presentación (*.ppt). |
| PPTX | Microsoft Office Open XML Presentación (*.pptx). |
| ODP | OpenDocument Presentación (*.odp). |
| PPTM | Microsoft Office Open XML Presentación con macros (*.pptm). |
| PPSX | Microsoft Office Open XML Presentación de diapositivas (*.ppsx). |
| PPSM | Microsoft Office Open XML Presentación de diapositivas con macros (*.ppsm). |
| POTX | Microsoft Office Open XML Plantilla (*.potx). |
| POTM | Microsoft Office Open XML Plantilla con macros (*.potm). |
| PPS | Microsoft PowerPoint 97-2003 Presentación de diapositivas (*.pps). |
| POT | Microsoft PowerPoint 97-2003 Plantilla (*.pot). |
| OTP | OpenDocument Plantilla de presentación (*.otp). |
| FODP | Flat XML ODF Presentación (*.fodp). |
| XML | PowerPoint XML Presentación (*.xml). |
