## add_summary_zoom_section(self, section) {#isection}
Crea un nuevo objeto Summary Zoom Section y lo añade a la colección

Elemento [`ISummaryZoomFrame`](/slides/python-net/es/aspose.slides/isummaryzoomframe) añadido



```python
def add_summary_zoom_section(self, section):
    ...
```


| Parámetro | Tipo | Descripción |
| :- | :- | :- |
| section | [`ISection`](/slides/python-net/es/aspose.slides/isection) | Sección para un nuevo elemento Summary Zoom Section [`ISection`](/slides/python-net/es/aspose.slides/isection) |

| Excepción | Descripción |
