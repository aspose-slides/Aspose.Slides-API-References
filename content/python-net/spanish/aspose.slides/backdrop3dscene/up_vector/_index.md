## up_vector propiedad
Devuelve o establece un vector que representa la dirección ascendente. Para ser más preciso, este atributo define un vector
            que representa la dirección ascendente en relación con la cara del plano de fondo. Vector representado por una matriz
            de 3 valores float que definen las coordenadas X, Y y Z.
