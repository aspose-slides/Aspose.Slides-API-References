## HyperlinkQueries clase

Proporciona fácil acceso a los hipervínculos contenidos.

El tipo HyperlinkQueries expone los siguientes miembros:

## Métodos

| Método | Descripción |
| :- | :- |
| [`get_hyperlink_clicks(self)`](/slides/python-net/es/aspose.slides/hyperlinkqueries/get_hyperlink_clicks/#) | Obtiene todos los subobjetos IHyperlinkContainer que no son None HyperlinkClick.<br/>            Con el objeto IHyperlinkContainer dado puedes gestionar su hipervínculo (leer, actualizar o eliminar). Ver la interfaz IHyperlinkContainer. |
| [`get_hyperlink_mouse_overs(self)`](/slides/python-net/es/aspose.slides/hyperlinkqueries/get_hyperlink_mouse_overs/#) | Obtiene todos los subobjetos IHyperlinkContainer que no son None HyperlinkMouseOver.<br/>            Con el objeto IHyperlinkContainer dado puedes gestionar su hipervínculo (leer, actualizar o eliminar). Ver la interfaz IHyperlinkContainer. |
| [`get_any_hyperlinks(self)`](/slides/python-net/es/aspose.slides/hyperlinkqueries/get_any_hyperlinks/#) | Obtiene todos los subobjetos IHyperlinkContainer que no son None HyperlinkMouseOver.<br/>            Con el objeto IHyperlinkContainer dado puedes gestionar su hipervínculo (leer, actualizar o eliminar). Ver la interfaz IHyperlinkContainer. |
| [`remove_all_hyperlinks(self)`](/slides/python-net/es/aspose.slides/hyperlinkqueries/remove_all_hyperlinks/#) | Elimina todos los hipervínculos HyperlinkClick y HyperlinkMouseOver contenidos (en todos los subobjetos IHyperlinkContainer). |
