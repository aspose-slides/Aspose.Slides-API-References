## is_text_box propiedad
Especifica si la forma es un cuadro de texto.


### Observaciones

Si la forma no se especifica como un cuadro de texto, no significa que no pueda tener texto adjunto. Un cuadro de texto
            es simplemente una forma especializada con propiedades específicas.
