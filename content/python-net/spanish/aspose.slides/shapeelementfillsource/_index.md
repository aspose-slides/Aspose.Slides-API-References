## ShapeElementFillSource enumeración

Representa cómo debe rellenarse el elemento de forma.

El tipo ShapeElementFillSource expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| NO_FILL | No rellenar el primitivo. |
| SHAPE | Usar el relleno de la forma. |
| LIGHTEN | Usar el relleno aclarado de la forma. |
| LIGHTEN_LESS | Usar el relleno menos aclarado de la forma. |
| DARKEN | Usar el relleno oscurecido de la forma. |
| DARKEN_LESS | Usar el relleno menos oscurecido de la forma. |
