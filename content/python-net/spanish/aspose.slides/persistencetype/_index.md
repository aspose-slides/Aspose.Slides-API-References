## enumeración PersistenceType

Especifica el método usado para almacenar las propiedades del control ActiveX.

El tipo PersistenceType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| NOT_DEFINED | ID de persistencia no especificado. |
| PERSIST_PROPERTY_BAG | Especifica que el control ActiveX se persiste usando persistencia basada en bolsa de propiedades. <br/>             La persistencia basada en bolsa de propiedades almacena un control ActiveX mediante una colección de pares nombre <br/>             y valor que especifican los datos persistidos por el control ActiveX. |
| PERSIST_STREAM | Especifica que el control ActiveX se persiste usando una persistencia basada en flujo <br/>             que no soporta la inicialización del control ActiveX a un estado predeterminado. |
| PERSIST_STREAM_INIT | Especifica que el control ActiveX se persiste usando una persistencia basada en flujo <br/>             que soporta la inicialización del control ActiveX a un estado predeterminado. |
| PERSIST_STORAGE | Especifica que el control ActiveX se persiste usando una persistencia basada en almacenamiento. |
