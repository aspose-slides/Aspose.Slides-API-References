## get_rotation(self) {#}
Una rotación se define mediante el uso de una coordenada de latitud,
una coordenada de longitud y una revolución alrededor del eje
según las coordenadas de latitud y longitud.
primer elemento en la matriz de retorno – latitud, segundo – longitud, tercero – revolución.
Devuelve None si no hay una rotación definida.
