## ViewProperties clase

Propiedades de vista a nivel de presentación.

El tipo ViewProperties expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`last_view`](/slides/python-net/es/aspose.slides/viewproperties/last_view/) | Especifica el modo de vista que se utilizó cuando el documento de presentación se guardó por última vez.<br/>            Lectura/escritura [`ViewType`](/slides/python-net/es/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/es/aspose.slides/viewproperties/show_comments/) | Especifica si se deben mostrar los comentarios de la diapositiva.<br/>            Lectura/escritura [`NullableBool`](/slides/python-net/es/aspose.slides/nullablebool). |
| [`normal_view_properties`](/slides/python-net/es/aspose.slides/viewproperties/normal_view_properties/) | Representa las propiedades de vista normal. La vista normal consta de<br/>            tres regiones de contenido: la propia diapositiva, una región de contenido lateral y una región de contenido inferior.<br/>            Solo lectura [`INormalViewProperties`](/slides/python-net/es/aspose.slides/inormalviewproperties). |
| [`slide_view_properties`](/slides/python-net/es/aspose.slides/viewproperties/slide_view_properties/) | Especifica las propiedades de vista comunes asociadas al modo de vista de diapositiva.<br/>            Solo lectura [`ICommonSlideViewProperties`](/slides/python-net/es/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/es/aspose.slides/viewproperties/notes_view_properties/) | Especifica las propiedades de vista comunes asociadas al modo de vista de notas.<br/>            Solo lectura [`ICommonSlideViewProperties`](/slides/python-net/es/aspose.slides/icommonslideviewproperties). |
| [`grid_spacing`](/slides/python-net/es/aspose.slides/viewproperties/grid_spacing/) | Devuelve o establece el espaciado de la cuadrícula que debe usarse para la cuadrícula subyacente al documento de presentación, en puntos.<br/>            Lectura/escritura **float**. |
