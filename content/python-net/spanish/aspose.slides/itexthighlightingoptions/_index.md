## ITextHighlightingOptions clase

Representa opciones que pueden usarse para resaltar texto en un marco de texto.

El tipo ITextHighlightingOptions expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`case_sensitive`](/slides/python-net/es/aspose.slides/itexthighlightingoptions/case_sensitive/) | Establezca true para usar búsqueda sensible a mayúsculas y minúsculas, false - de lo contrario.<br/>            Lectura/escritura **bool**. |
| [`whole_words_only`](/slides/python-net/es/aspose.slides/itexthighlightingoptions/whole_words_only/) | Establezca true para coincidir solo palabras completas, false - de lo contrario.<br/>            Lectura/escritura **bool**. |
