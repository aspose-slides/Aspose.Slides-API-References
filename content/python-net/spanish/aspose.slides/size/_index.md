## Clase Size

Almacena un par ordenado de enteros, que especifican un ancho y una altura. Compatible con .NET `System.Drawing.Size`.

El tipo Size expone los siguientes miembros:

## Constructores

| Constructor | Description |
| :- | :- |
| [`__init__(self, width=0, height=0)`](/slides/python-net/es/aspose.slides/size/__init__/#int-int) | Crea un tamaño con el ancho y la altura especificados. Los valores flotantes se truncan a enteros. |

## Propiedades

| Property | Description |
| :- | :- |
| [`width`](/slides/python-net/es/aspose.slides/size/width/) | Obtiene el componente horizontal de este tamaño.<br/>            Solo lectura **int**. |
| [`height`](/slides/python-net/es/aspose.slides/size/height/) | Obtiene el componente vertical de este tamaño.<br/>            Solo lectura **int**. |


### Observaciones

Los tamaños se comparan por sus componentes con `==` y pueden usarse como claves de diccionario o miembros de conjunto.
