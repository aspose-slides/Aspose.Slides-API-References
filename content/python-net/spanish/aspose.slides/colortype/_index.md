## enumeración ColorType

Representa diferentes modos de color.

El tipo ColorType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| NOT_DEFINED | Color no está definido en absoluto. |
| RGB | Color RGB estándar de 24 bits. |
| RGB_PERCENTAGE | Color RGB de alta definición. |
| HSL | Color HSL de alta definición. |
| SCHEME | Color de esquema. |
| SYSTEM | Color del sistema. |
| PRESET | Color predefinido. |
