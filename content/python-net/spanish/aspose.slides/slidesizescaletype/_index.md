## Enumeración SlideSizeScaleType

Representa el tipo de escala del contenido de la diapositiva.

El tipo SlideSizeScaleType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| DO_NOT_SCALE | No escalar. |
| ENSURE_FIT | Escalar para asegurar ajuste. |
| MAXIMIZE | Maximizar el tamaño del contenido. |
