## __init__(self, r=0, g=0, b=0, a=255) {#int-int-int-int}
Crea un color a partir de los valores de los componentes rojo, verde, azul y alfa especificados.

```python
def __init__(self, r=0, g=0, b=0, a=255):
    ...
```

| Parameter | Type | Description |
| :- | :- | :- |
| r | **int** | El valor del componente rojo. Los valores válidos son de 0 a 255. |
| g | **int** | El valor del componente verde. Los valores válidos son de 0 a 255. |
| b | **int** | El valor del componente azul. Los valores válidos son de 0 a 255. |
| a | **int** | El valor del componente alfa. Los valores válidos son de 0 a 255. |

### Excepciones

| Excepción | Description |
| :- | :- |
| **ValueError** | Un valor de componente es menor que 0 o mayor que 255. |
| **TypeError** | Un valor de componente no es un número. |
