## is_system_color propiedad
Especifica si este color es un color del sistema: un color usado para un elemento de pantalla de Windows, como `Control` o `ActiveBorder`.<br/>            Los colores del sistema no se exponen como atributos de `Color` y solo pueden obtenerse con [`from_known_color`](/slides/python-net/es/aspose.slides/color/from_known_color/) o devolverse desde la biblioteca.
            Solo lectura **bool**.
