## width propiedad
Gets or sets the width of the shape, measured in points.
            Lectura/escritura **float**.


### Observaciones

            El valor devuelto siempre está definido y nunca es **float**.
            El valor asignado también debe estar definido; asigne **float** solo a propiedades de una instancia de `RawFrame`.
