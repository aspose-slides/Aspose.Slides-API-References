## clase IShapeFrame

Representa las propiedades del marco de forma.

El tipo IShapeFrame expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`x`](/slides/python-net/es/aspose.slides/ishapeframe/x/) | Devuelve la coordenada X de la esquina superior izquierda de un marco.<br/>            Solo lectura **float**. |
| [`y`](/slides/python-net/es/aspose.slides/ishapeframe/y/) | Devuelve la coordenada Y de la esquina superior izquierda de un marco.<br/>            Solo lectura **float**. |
| [`width`](/slides/python-net/es/aspose.slides/ishapeframe/width/) | Devuelve el ancho de un marco.<br/>            Solo lectura **float**. |
| [`height`](/slides/python-net/es/aspose.slides/ishapeframe/height/) | Devuelve la altura de un marco.<br/>            Solo lectura **float**. |
| [`rotation`](/slides/python-net/es/aspose.slides/ishapeframe/rotation/) | Devuelve el número de grados que un marco está rotado alrededor del eje z.<br/>            Un valor positivo indica rotación en sentido horario; un valor negativo<br/>            indica rotación en sentido antihorario.<br/>            Solo lectura **float**. |
| [`center_x`](/slides/python-net/es/aspose.slides/ishapeframe/center_x/) | Devuelve la coordenada X del centro de un marco.<br/>            Solo lectura **float**. |
| [`center_y`](/slides/python-net/es/aspose.slides/ishapeframe/center_y/) | Devuelve la coordenada Y del centro de un marco.<br/>            Solo lectura **float**. |
| [`flip_h`](/slides/python-net/es/aspose.slides/ishapeframe/flip_h/) | Determina si un marco está volteado horizontalmente.<br/>            Solo lectura [`NullableBool`](/slides/python-net/es/aspose.slides/nullablebool). |
| [`flip_v`](/slides/python-net/es/aspose.slides/ishapeframe/flip_v/) | Determina si un marco está volteado verticalmente.<br/>            Solo lectura [`NullableBool`](/slides/python-net/es/aspose.slides/nullablebool). |
| [`rectangle`](/slides/python-net/es/aspose.slides/ishapeframe/rectangle/) | Devuelve las coordenadas de un marco.<br/>            Solo lectura [`RectangleF`](/slides/python-net/es/aspose.slides/rectanglef). |
