## VideoPlayModePreset enumeración

Constantes que definen cómo se reproduce un video.

El tipo VideoPlayModePreset expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| MIXED |  |
| AUTO | Reproduce automáticamente. |
| ON_CLICK | Reproduce solo cuando se hace clic en el fotograma del video. |
| ALL_SLIDES | Reproduce en todas las diapositivas. |
| IN_CLICK_SEQUENCE | Reproduce automáticamente con un clic. |
