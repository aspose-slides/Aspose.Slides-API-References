## Clase Column

Representa una columna en una tabla.

**Herencia:**[`Column`](/slides/python-net/es/aspose.slides/column) → [`CellCollection`](/slides/python-net/es/aspose.slides/cellcollection)

| Propiedad | Descripción |
| :- | :- |
| [`slide`](/slides/python-net/es/aspose.slides/column/slide/) | Devuelve la diapositiva principal de una CellCollection.<br/>            Solo lectura [`IBaseSlide`](/slides/python-net/es/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/es/aspose.slides/column/presentation/) | Devuelve la presentación principal de una CellCollection.<br/>            Solo lectura [`IPresentation`](/slides/python-net/es/aspose.slides/ipresentation). |

| [`column_format`](/slides/python-net/es/aspose.slides/column/column_format/) | Devuelve el objeto ColumnFormat que contiene las propiedades de formato para esta columna.<br/>            Solo lectura [`IColumnFormat`](/slides/python-net/es/aspose.slides/icolumnformat). |
