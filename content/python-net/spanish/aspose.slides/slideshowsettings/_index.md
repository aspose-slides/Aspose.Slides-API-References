## Clase SlideShowSettings

Representa la configuración de la presentación de diapositivas.

El tipo SlideShowSettings expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`slide_show_type`](/slides/python-net/es/aspose.slides/slideshowsettings/slide_show_type/) | Obtiene o establece el tipo de presentación de diapositivas. Representado por los siguientes ancestros [`SlideShowSettings.slide_show_type`](/slides/python-net/es/aspose.slides/slideshowsettings/slide_show_type): [`BrowsedAtKiosk`](/slides/python-net/es/aspose.slides/browsedatkiosk), [`PresentedBySpeaker`](/slides/python-net/es/aspose.slides/presentedbyspeaker) y [`BrowsedByIndividual`](/slides/python-net/es/aspose.slides/browsedbyindividual) |
| [`loop`](/slides/python-net/es/aspose.slides/slideshowsettings/loop/) | Repetir presentación |
| [`show_narration`](/slides/python-net/es/aspose.slides/slideshowsettings/show_narration/) | Mostrar narración en la presentación |
| [`show_animation`](/slides/python-net/es/aspose.slides/slideshowsettings/show_animation/) | Mostrar animación en la presentación |
| [`pen_color`](/slides/python-net/es/aspose.slides/slideshowsettings/pen_color/) | Color del lápiz para la presentación |
| [`slides`](/slides/python-net/es/aspose.slides/slideshowsettings/slides/) | Rango de diapositivas |
| [`use_timings`](/es/slides/python-net/aspose.slides/slideshowsettings/use_timings/) | Usar tiempos en la presentación |
| [`show_media_controls`](/slides/python-net/es/aspose.slides/slideshowsettings/show_media_controls/) | Mostrar controles de medios |
