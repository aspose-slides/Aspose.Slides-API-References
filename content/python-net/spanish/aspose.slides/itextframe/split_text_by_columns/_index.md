## split_text_by_columns(self) {#}
Divide el contenido de texto del [`ITextFrame`](/slides/python-net/es/aspose.slides/itextframe) en una matriz de cadenas,
            donde cada elemento corresponde a una columna de texto separada dentro del marco.

### Devuelve

Una matriz de cadenas, donde cada cadena representa el contenido de texto de una columna específica
            en el [`ITextFrame`](/slides/python-net/es/aspose.slides/itextframe).



```python
def split_text_by_columns(self):
    ...
```


### Comentarios

Si el marco de texto no contiene varias columnas, la matriz devuelta tendrá un único elemento
            que contiene el texto completo.
            Las columnas vacías se representarán como cadenas vacías en la matriz.
