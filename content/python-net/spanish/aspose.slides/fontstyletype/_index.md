## FontStyleType enumeración

Define estilos de formato que pueden aplicarse al texto.

El tipo FontStyleType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| REGULAR | Texto estándar. |
| BOLD | Texto en negrita. |
| ITALIC | Texto en cursiva. |
| UNDERLINE | Texto subrayado. |
| STRIKEOUT | Texto tachado con una línea horizontal. |
