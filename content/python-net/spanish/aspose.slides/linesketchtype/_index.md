## Enumeración LineSketchType

Representa qué tipo de boceto o efecto se ha asignado a una forma.

El tipo LineSketchType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| NOT_DEFINED | Especifica que el efecto Sketch de una forma es indefinido. |
| NONE | Especifica que una forma no tiene efecto Sketch. Esto equivale a que esta propiedad esté vacía. |
| CURVED | Especifica que una forma tiene el efecto Curved, que convierte cada borde de la forma en una gran curva suave. |
| FREEHAND | Especifica que una forma tiene el efecto Freehand, que se asemeja lo más posible a una línea dibujada imperfectamente. |
| SCRIBBLE | Especifica que una forma tiene el efecto Scribble, que tiene una oscilación exagerada como si se dibujara intencionalmente desordenado. |
