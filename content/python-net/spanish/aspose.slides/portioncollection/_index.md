## PortionCollection clase

Representa una colección de porciones.

El tipo PortionCollection expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`count`](/slides/python-net/es/aspose.slides/portioncollection/count/) | Obtiene el número de elementos realmente contenidos en la colección.<br/>            Read-only **int**. |
| [`is_read_only`](/slides/python-net/es/aspose.slides/portioncollection/is_read_only/) | Obtiene un valor que indica si la **System.Collections.Generic.ICollection`1** es de solo lectura.<br/>            Read-only **bool**. |

Obtiene el elemento en el índice especificado.
