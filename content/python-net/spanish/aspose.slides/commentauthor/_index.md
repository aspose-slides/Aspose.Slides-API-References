## CommentAuthor clase

Representa a un autor de comentarios.

El tipo CommentAuthor expone los siguientes miembros:

## Propiedades

| Property | Description |
| :- | :- |
| [`name`](/slides/python-net/es/aspose.slides/commentauthor/name/) | Devuelve o establece el nombre del autor.<br/>            Lectura/escritura **str**. |
| [`initials`](/slides/python-net/es/aspose.slides/commentauthor/initials/) | Devuelve o establece las iniciales del autor.<br/>            Lectura/escritura **str**. |
| [`comments`](/slides/python-net/es/aspose.slides/commentauthor/comments/) | Devuelve la colección de comentarios realizados por este autor.<br/>            Solo lectura [`ICommentCollection`](/slides/python-net/es/aspose.slides/icommentcollection). |
