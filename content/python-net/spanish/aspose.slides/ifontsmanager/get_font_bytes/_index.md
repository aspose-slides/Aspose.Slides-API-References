## get_font_bytes(self, font_data, font_style) {#ifontdata-fontstyletype}
Recupera la matriz de bytes que representa los datos de fuente para un estilo de fuente especificado y los datos de fuente.

Una matriz de bytes que contiene los datos de fuente para el estilo de fuente especificado. Si los datos de fuente o el estilo no se encuentran, devuelve None.
