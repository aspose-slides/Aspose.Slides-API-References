## IBackgroundEffectiveData clase

Objeto inmutable que contiene propiedades de fondo efectivas.

El tipo IBackgroundEffectiveData expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`fill_format`](/slides/python-net/es/aspose.slides/ibackgroundeffectivedata/fill_format/) | Devuelve el formato de relleno efectivo.<br/>            Sólo lectura [`IFillFormatEffectiveData`](/slides/python-net/es/aspose.slides/ifillformateffectivedata). |

Esta interfaz se usa junto con la [`IBackground`](/slides/python-net/es/aspose.slides/ibackground) interfaz para devolver valores de formato efectivos con la herencia aplicada.
