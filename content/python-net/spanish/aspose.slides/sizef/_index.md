## SizeF clase

Almacena un par ordenado de números de punto flotante, típicamente el ancho y la altura de un rectángulo. Compatible con .NET `System.Drawing.SizeF`.

El tipo SizeF expone los siguientes miembros:

## Constructores

| Constructor | Descripción |
| :- | :- |
| [`__init__(self, width=0.0, height=0.0)`](/slides/python-net/es/aspose.slides/sizef/__init__/#float-float) | Crea un tamaño con el ancho y la altura especificados. |

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`width`](/slides/python-net/es/aspose.slides/sizef/width/) | Obtiene el componente horizontal de este tamaño.<br/>            Solo lectura **float**. |
| [`height`](/slides/python-net/es/aspose.slides/sizef/height/) | Obtiene el componente vertical de este tamaño.<br/>            Solo lectura **float**. |


### Observaciones

Los tamaños se comparan por sus componentes con `==` y pueden usarse como claves de diccionario o como miembros de conjuntos.
