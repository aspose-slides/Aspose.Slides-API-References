## IFonts clase

Representa la colección de fuentes.

El tipo IFonts expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`latin_font`](/slides/python-net/es/aspose.slides/ifonts/latin_font/) | Devuelve o establece la fuente latina.<br/>            Lectura/escritura [`IFontData`](/slides/python-net/es/aspose.slides/ifontdata). |
| [`east_asian_font`](/slides/python-net/es/aspose.slides/ifonts/east_asian_font/) | Devuelve o establece la fuente de Asia Oriental.<br/>            Lectura/escritura [`IFontData`](/slides/python-net/es/aspose.slides/ifontdata). |
| [`complex_script_font`](/slides/python-net/es/aspose.slides/ifonts/complex_script_font/) | Devuelve o establece la fuente de escritura compleja.<br/>            Lectura/escritura [`IFontData`](/slides/python-net/es/aspose.slides/ifontdata). |

## Métodos

| Método | Descripción |
| :- | :- |
| [`get_script_font_map(self)`](/slides/python-net/es/aspose.slides/ifonts/get_script_font_map/#) | Devuelve una lista de todas las definiciones de fuentes de script de pares cadena-cadena en la presentación. |
| [`get_script_font(self, script)`](/slides/python-net/es/aspose.slides/ifonts/get_script_font/#str) | Obtiene el nombre de fuente asociado a una etiqueta de script específica del tema de la presentación. |
| [`set_script_font(self, script, font_name)`](/slides/python-net/es/aspose.slides/ifonts/set_script_font/#str-str) | Asigna un nombre de fuente a una etiqueta de script específica, lo que define cómo se renderizará el texto de ese script en la presentación. |
| [`remove_script_font(self, script)`](/slides/python-net/es/aspose.slides/ifonts/remove_script_font/#str) | Elimina la configuración de fuente asociada a una etiqueta de script específica de la colección de fuentes del tema. |
