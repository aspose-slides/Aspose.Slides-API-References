## get_script_font(self, script) {#str}
Obtiene el nombre de la fuente asociado a una etiqueta de script específica del tema de la presentación.

### Devuelve

El nombre de la fuente usada para el script especificado, o `None` si el script no está definido.

    ...

| Parámetro | Tipo | Descripción |
| :- | :- | :- |
| script | **str** | El código de script BCP-47 (p. ej., "Latn", "Cyrl", "Jpan") usado para identificar un sistema de escritura. |
