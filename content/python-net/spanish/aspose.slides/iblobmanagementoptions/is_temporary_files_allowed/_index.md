## is_temporary_files_allowed propiedad
Esta propiedad define si se pueden crear archivos temporales al trabajar con BLOBs, lo que disminuye considerablemente el consumo de memoria pero requiere permisos para crear archivos. Todos los archivos se eliminarán una vez que el trabajo con la presentación haya finalizado.
