## encrypt_document_properties propiedad
Esta propiedad tiene sentido si la presentación está protegida con contraseña.
            Si true entonces las propiedades del documento están encriptadas en el archivo de la presentación.
            Si false entonces las propiedades del documento son públicas mientras la presentación está encriptada.
            Lectura/escritura **bool**.
