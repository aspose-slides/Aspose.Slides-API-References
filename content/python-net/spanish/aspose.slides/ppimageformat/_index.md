## PPImageFormat enumeración

Formatos de imagen. Esta enumeración reemplaza a la clase `System.Drawing.Imaging.ImageFormat`. Es necesaria para la compatibilidad COM.

El tipo PPImageFormat expone los siguientes miembros:

## Campos

| Field | Description |
| :- | :- |
| BMP | Obtiene el formato de imagen bitmap (BMP). |
| EMF | Obtiene el formato de imagen metafile mejorado (EMF). |
| EXIF | Obtiene el formato Exchangeable Image File (Exif). |
| GIF | Obtiene el formato Graphics Interchange Format (GIF). |
| ICON | Obtiene el formato de imagen de icono de Windows. |
| JPEG | Obtiene el formato Joint Photographic Experts Group (JPEG). |
| MEMORY_BMP | Obtiene el formato de un bitmap en memoria. |
| PNG | Obtiene el formato W3C Portable Network Graphics (PNG). |
| TIFF | Obtiene el formato Tagged Image File Format (TIFF). |
| WMF | Obtiene el formato Windows metafile (WMF). |
