## width propiedad
Obtiene o establece el width de la forma, medido en puntos.
            Lectura/escritura **float**.


### Remarks

El valor devuelto está siempre definido y nunca **float**.
            El valor asignado también debe estar definido; asigne **float** solo a propiedades de una instancia `RawFrame`.
