## propiedad de rotación
Returns or sets the number of degrees the specified shape is rotated around
            the z-axis. A positive value indicates clockwise rotation; a negative value
            indicates counterclockwise rotation.
            Lectura/escritura **float**.


### Observaciones

El valor devuelto siempre está definido (no es float.NaN).
            El valor asignado debe estar definido (no es float.NaN). Puede establecer valores no definidos para las propiedades de instancia RawFrame.
