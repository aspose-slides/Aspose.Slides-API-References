## FontsLoader clase

Clase para cargar fuentes personalizadas definidas por el usuario.
Debe usarse antes de crear cualquier objeto de presentación.

El tipo FontsLoader expone los siguientes miembros:

## Métodos

| Método | Descripción |
| :- | :- |
| [`load_external_fonts(directories)`](/slides/python-net/es/aspose.slides/fontsloader/load_external_fonts/#liststr) | Agrega carpetas adicionales para buscar fuentes. |
| [`load_external_font(data)`](/slides/python-net/es/aspose.slides/fontsloader/load_external_font/#bytes) | Agrega una fuente a partir de los datos binarios |
| [`get_font_folders()`](/slides/python-net/es/aspose.slides/fontsloader/get_font_folders/#) | Obtiene carpetas de fuentes. Devuelve las carpetas que se han añadido con el método LoadExternalFonts, así como las carpetas de fuentes del sistema |
| [`clear_cache()`](/slides/python-net/es/aspose.slides/fontsloader/clear_cache/#) | Libera todas las fuentes personalizadas definidas por el usuario |
