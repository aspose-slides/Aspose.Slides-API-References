## IImage clase

Representa una imagen raster o vectorial.

El tipo IImage expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`size`](/slides/python-net/es/aspose.slides/iimage/size/) | Obtiene el tamaño de la imagen. |
| [`width`](/slides/python-net/es/aspose.slides/iimage/width/) | Obtiene el ancho de la imagen en píxeles. |
| [`height`](/slides/python-net/es/aspose.slides/iimage/height/) | Obtiene la altura de la imagen en píxeles. |

## Métodos

| Método | Descripción |
| :- | :- |
| [`save(self, filename)`](/slides/python-net/es/aspose.slides/iimage/save/#str) | Guarda la imagen en un archivo. |
| [`save(self, filename, format)`](/slides/python-net/es/aspose.slides/iimage/save/#str-imageformat) | Guarda la imagen en un archivo en el formato especificado. |
| [`save(self, stream, format)`](/slides/python-net/es/aspose.slides/iimage/save/#iorawiobase-imageformat) | Guarda la imagen en un flujo en el formato especificado. |
| [`save(self, filename, format, quality)`](/slides/python-net/es/aspose.slides/iimage/save/#str-imageformat-int) | Guarda la imagen en un archivo en el formato y calidad especificados. |
| [`save(self, stream, format, quality)`](/slides/python-net/es/aspose.slides/iimage/save/#iorawiobase-imageformat-int) | Guarda la imagen en un flujo en el formato y calidad especificados. |


### Observaciones

Esta interfaz proporciona una abstracción común para manejar tanto imágenes raster como vectoriales.  
Implementaciones pueden variar según el tipo subyacente de la imagen.
