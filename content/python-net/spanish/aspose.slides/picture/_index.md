## Picture clase

Representa una imagen en una presentación.

El tipo Picture expone los siguientes miembros:

## Propiedades

| Property | Description |
| :- | :- |
| [`image`](/slides/python-net/es/aspose.slides/picture/image/) | Devuelve o establece la imagen incrustada.<br/>            Lectura/escritura [`IPPImage`](/slides/python-net/es/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/es/aspose.slides/picture/link_path_long/) | Devuelve o establece la URL de la imagen vinculada.<br/>            Lectura/escritura **str**. |
| [`image_transform`](/slides/python-net/es/aspose.slides/picture/image_transform/) | Devuelve la colección de efectos de transformación de imagen.<br/>            Solo lectura [`IImageTransformOperationCollection`](/slides/python-net/es/aspose.slides.effects/iimagetransformoperationcollection). |
| [`presentation`](/slides/python-net/es/aspose.slides/picture/presentation/) | Devuelve la presentación.<br/>            Solo lectura [`IPresentation`](/slides/python-net/es/aspose.slides/ipresentation). |
| [`slide`](/slides/python-net/es/aspose.slides/picture/slide/) | Devuelve la diapositiva padre de una imagen.<br/>            Solo lectura [`IBaseSlide`](/slides/python-net/es/aspose.slides/ibaseslide). |
