## SensitivityLabelContentType enumeración

Representa los tipos de marcado de contenido que deben aplicarse a un documento.

El tipo SensitivityLabelContentType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| NONE | Implica que la etiqueta se aplica por defecto o automáticamente. |
| HEADER | Implica que la etiqueta se aplicó manualmente.<br/>            Úselo para cualquier etiqueta de sensibilidad que haya sido aplicada directamente por el usuario. |
| FOOTER | Implica que la etiqueta se aplicó manualmente.<br/>            Úselo para cualquier etiqueta de sensibilidad que haya sido aplicada directamente por el usuario. |
| WATERMARK | Implica que la etiqueta se aplicó manualmente.<br/>            Úselo para cualquier etiqueta de sensibilidad que haya sido aplicada directamente por el usuario. |
| ENCRYPTION | Implica que la etiqueta se aplicó manualmente.<br/>            Úselo para cualquier etiqueta de sensibilidad que haya sido aplicada directamente por el usuario. |
