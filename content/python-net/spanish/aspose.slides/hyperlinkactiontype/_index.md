## enumeración HyperlinkActionType

Representa un tipo de acción de hipervínculo.

El tipo HyperlinkActionType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| UNKNOWN | Tipo de acción no reconocido. |
| NO_ACTION | Sin acción. |
| HYPERLINK | Hipervínculo habitual. |
| JUMP_FIRST_SLIDE | Ir a la primera diapositiva de la presentación. |
| JUMP_PREVIOUS_SLIDE | Ir a la diapositiva anterior. |
| JUMP_NEXT_SLIDE | Ir a la diapositiva siguiente. |
| JUMP_LAST_SLIDE | Ir a la última diapositiva de la presentación. |
| JUMP_END_SHOW | Ir al final de la presentación de diapositivas. |
| JUMP_LAST_VIEWED_SLIDE | Ir a la última diapositiva vista. |
| JUMP_SPECIFIC_SLIDE | Ir a la diapositiva específica, referida por la propiedad [`IHyperlink.target_slide`](/slides/python-net/es/aspose.slides/ihyperlink/target_slide). |
| START_CUSTOM_SLIDE_SHOW | Iniciar presentación de diapositivas personalizada. |
| OPEN_FILE | Abrir archivo referenciado. |
| OPEN_PRESENTATION | Abrir presentación referenciada. |
| START_STOP_MEDIA | Iniciar/detener reproducción de archivo multimedia. |
| START_MACRO | Iniciar ejecución de script de macro. |
| START_PROGRAM | Iniciar programa. |
