## IColorFormat clase

Representa un color utilizado en una presentación.

El tipo IColorFormat expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`color_type`](/slides/python-net/es/aspose.slides/icolorformat/color_type/) | Devuelve o establece el método de definición de color.<br/>            Lectura/escritura [`ColorType`](/slides/python-net/es/aspose.slides/colortype). |
| [`color`](/slides/python-net/es/aspose.slides/icolorformat/color/) | Devuelve el color resultante (con todas las transformaciones de color aplicadas).<br/>            Establece colores RGB y borra todas las transformaciones de color.<br/>            Lectura/escritura [`Color`](/slides/python-net/es/aspose.slides/color). |
| [`preset_color`](/slides/python-net/es/aspose.slides/icolorformat/preset_color/) | Devuelve o establece el color predefinido.<br/>            Lectura/escritura [`PresetColor`](/slides/python-net/es/aspose.slides/presetcolor). |
| [`system_color`](/slides/python-net/es/aspose.slides/icolorformat/system_color/) | Devuelve o establece el color identificado por la tabla de colores del sistema.<br/>            Lectura/escritura [`SystemColor`](/slides/python-net/es/aspose.slides/systemcolor). |
| [`scheme_color`](/slides/python-net/es/aspose.slides/icolorformat/scheme_color/) | Devuelve o establece el color identificado por un esquema de color.<br/>            Lectura/escritura [`SchemeColor`](/slides/python-net/es/aspose.slides/schemecolor). |
| [`r`](/slides/python-net/es/aspose.slides/icolorformat/r/) | Devuelve o establece el componente rojo de un color. Todas las transformaciones de color se ignoran.<br/>            Lectura/escritura **int**. |
| [`g`](/slides/python-net/es/aspose.slides/icolorformat/g/) | Devuelve o establece el componente verde de un color. Todas las transformaciones de color se ignoran.<br/>            Lectura/escritura **int**. |
| [`b`](/slides/python-net/es/aspose.slides/icolorformat/b/) | Devuelve o establece el componente azul de un color. Todas las transformaciones de color se ignoran.<br/>            Lectura/escritura **int**. |
| [`float_r`](/slides/python-net/es/aspose.slides/icolorformat/float_r/) | Devuelve o establece el componente rojo de un color. Todas las transformaciones de color se ignoran.<br/>            Lectura/escritura **float**. |
| [`float_g`](/slides/python-net/es/aspose.slides/icolorformat/float_g/) | Devuelve o establece el componente verde de un color. Todas las transformaciones de color se ignoran.<br/>            Lectura/escritura **float**. |
| [`float_b`](/slides/python-net/es/aspose.slides/icolorformat/float_b/) | Devuelve o establece el componente azul de un color. Todas las transformaciones de color se ignoran.<br/>            Lectura/escritura **float**. |
| [`hue`](/slides/python-net/es/aspose.slides/icolorformat/hue/) | Devuelve o establece el componente matiz de un color en representación HSL.<br/>            Todas las transformaciones de color se ignoran.<br/>            Lectura/escritura **float**. |
| [`saturation`](/slides/python-net/es/aspose.slides/icolorformat/saturation/) | Devuelve o establece el componente saturación de un color en representación HSL.<br/>            Todas las transformaciones de color se ignoran.<br/>            Lectura/escritura **float**. |
| [`luminance`](/slides/python-net/es/aspose.slides/icolorformat/luminance/) | Devuelve o establece el componente luminancia de un color en representación HSL.<br/>            Todas las transformaciones de color se ignoran.<br/>            Lectura/escritura **float**. |
| [`color_transform`](/slides/python-net/es/aspose.slides/icolorformat/color_transform/) | Devuelve la colección de transformaciones de color aplicadas a un color.<br/>            Solo lectura [`IColorOperationCollection`](/slides/python-net/es/aspose.slides/icoloroperationcollection). |
