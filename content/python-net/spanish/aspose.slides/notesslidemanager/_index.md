## NotesSlideManager clase

Gestor de notas de diapositivas.

El tipo NotesSlideManager expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`notes_slide`](/slides/python-net/es/aspose.slides/notesslidemanager/notes_slide/) | Devuelve la diapositiva de notas para la diapositiva actual. Devuelve None si la diapositiva no tiene diapositiva de notas.<br/>            Sólo lectura [`INotesSlide`](/slides/python-net/es/aspose.slides/inotesslide). |
