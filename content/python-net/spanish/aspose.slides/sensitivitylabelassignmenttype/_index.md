## SensitivityLabelAssignmentType enumeración

Representa el método de asignación para la etiqueta de sensibilidad.

El tipo SensitivityLabelAssignmentType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| STANDARD | Uso para cualquier etiqueta de sensibilidad que no fue aplicada directamente por el usuario. <br/>            Esto incluye cualquier etiqueta predeterminada, etiquetas aplicadas automáticamente. |
| PRIVILEGED | Uso para cualquier etiqueta de sensibilidad que fue aplicada directamente por el usuario. <br/>            Esto incluye cualquier etiqueta de sensibilidad aplicada manualmente así como las etiquetas recomendadas<br/>            o obligatorias o cualquier característica donde el usuario decide qué etiqueta de sensibilidad aplicar. |
