## ITagCollection clase

Representa la colección de etiquetas (pares de cadenas definidos por el usuario)

El tipo ITagCollection expone los siguientes miembros:

## Métodos

| Method | Descripción |
| :- | :- |
| [`add(self, name, value)`](/slides/python-net/es/aspose.slides/itagcollection/add/#str-str) | Agrega una etiqueta nueva a la colección. |
| [`remove(self, name)`](/slides/python-net/es/aspose.slides/itagcollection/remove/#str) | Elimina la etiqueta con un nombre especificado de la colección. |
| [`index_of_name(self, name)`](/slides/python-net/es/aspose.slides/itagcollection/index_of_name/#str) | Devuelve el índice basado en cero de la clave especificada en la colección. |
| [`remove_at(self, index)`](/slides/python-net/es/aspose.slides/itagcollection/remove_at/#int) | Elimina la etiqueta en el índice especificado. |
| [`clear(self)`](/slides/python-net/es/aspose.slides/itagcollection/clear/#) | Elimina todas las etiquetas de la colección. |
| [`get_value_by_index(self, index)`](/slides/python-net/es/aspose.slides/itagcollection/get_value_by_index/#int) | Devuelve el valor de una etiqueta en el índice especificado. |
| [`get_name_by_index(self, index)`](/slides/python-net/es/aspose.slides/itagcollection/get_name_by_index/#int) | Devuelve la clave de una etiqueta en el índice especificado. |
| [`get_names_of_tags(self)`](/slides/python-net/es/aspose.slides/itagcollection/get_names_of_tags/#) | Devuelve los nombres de las etiquetas. |
