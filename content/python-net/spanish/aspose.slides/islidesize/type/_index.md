## propiedad de tipo
Obtiene el tipo de tamaño de diapositiva.


### Observaciones

Asignar cualquier valor distinto de [`SlideSizeType.CUSTOM`](/slides/python-net/es/aspose.slides/slidesizetype/CUSTOM) ajusta el [`ISlideSize.size`](/slides/python-net/es/aspose.slides/islidesize/size)
            según las dimensiones predefinidas, manteniendo el [`ISlideSize.orientation`](/slides/python-net/es/aspose.slides/islidesize/orientation) actual.
