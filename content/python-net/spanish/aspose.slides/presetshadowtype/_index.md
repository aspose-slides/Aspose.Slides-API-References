## PresetShadowType enumeración

Representa una preconfiguración para un efecto de sombra.

El tipo PresetShadowType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| TOP_LEFT_DROP_SHADOW | Representa la sombra proyectada superior izquierda. |
| TOP_LEFT_LARGE_DROP_SHADOW | Representa la sombra proyectada grande superior izquierda. |
| BACK_LEFT_LONG_PERSPECTIVE_SHADOW | Representa la sombra de perspectiva larga trasera izquierda. |
| BACK_RIGHT_LONG_PERSPECTIVE_SHADOW | Representa la sombra de perspectiva larga trasera derecha. |
| TOP_LEFT_DOUBLE_DROP_SHADOW | Representa la sombra proyectada doble superior izquierda. |
| BOTTOM_RIGHT_SMALL_DROP_SHADOW | Representa la sombra proyectada pequeña inferior derecha. |
| FRONT_LEFT_LONG_PERSPECTIVE_SHADOW | Representa la sombra de perspectiva larga frontal izquierda. |
| FRONT_RIGHT_LONG_PERSPECTIVE_SHADOW | Representa la sombra de perspectiva larga frontal derecha. |
| OUTER_BOX_SHADOW_3D | Representa la sombra de caja externa 3D. |
| INNER_BOX_SHADOW_3D | Representa la sombra de caja interna 3D. |
| BACK_CENTER_PERSPECTIVE_SHADOW | Representa la sombra de perspectiva central trasera. |
| TOP_RIGHT_DROP_SHADOW | Representa la sombra proyectada superior derecha. |
| FRONT_BOTTOM_SHADOW | Representa la sombra frontal inferior. |
| BACK_LEFT_PERSPECTIVE_SHADOW | Representa la sombra de perspectiva trasera izquierda. |
| BACK_RIGHT_PERSPECTIVE_SHADOW | Representa la sombra de perspectiva trasera derecha. |
| BOTTOM_LEFT_DROP_SHADOW | Representa la sombra proyectada inferior izquierda. |
| BOTTOM_RIGHT_DROP_SHADOW | Representa la sombra proyectada inferior derecha. |
| FRONT_LEFT_PERSPECTIVE_SHADOW | Representa la sombra de perspectiva frontal izquierda. |
| FRONT_RIGHT_PERSPECTIVE_SHADOW | Representa la sombra de perspectiva frontal derecha. |
| TOP_LEFT_SMALL_DROP_SHADOW | Representa la sombra proyectada pequeña superior izquierda. |
