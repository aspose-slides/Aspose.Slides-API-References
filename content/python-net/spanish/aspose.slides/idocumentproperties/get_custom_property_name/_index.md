## get_custom_property_name(self, index) {#int}
Devuelve el nombre de una propiedad personalizada en el índice especificado.

### Devuelve

Nombre de propiedad personalizada en el índice especificado.



```python
def get_custom_property_name(self, index):
    ...
```


| Parámetro | Tipo | Descripción |
| :- | :- | :- |
| index | **int** | El índice basado en cero de una propiedad personalizada a obtener. |

### Excepciones

| Excepción | Descripción |
| :- | :- |
| **RuntimeError(Proxy error(ArgumentOutOfRangeException))** | El índice es menor que cero. El índice es igual o mayor que Count. |
