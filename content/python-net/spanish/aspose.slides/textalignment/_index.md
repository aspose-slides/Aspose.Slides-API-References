## TextAlignment enumeración

Representa diferentes estilos de alineación de texto.

El tipo TextAlignment expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| NOT_DEFINED | Alineación predeterminada. |
| LEFT | Alineación a la izquierda. |
| CENTER | Alineación centrada. |
| RIGHT | Alineación a la derecha. |
| JUSTIFY | Alineación justificada. |
| JUSTIFY_LOW | Justificación Kashida baja. |
| DISTRIBUTED | Alineación distribuida. |
