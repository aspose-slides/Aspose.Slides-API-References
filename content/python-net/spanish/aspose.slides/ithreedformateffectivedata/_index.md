## IThreeDFormatEffectiveData clase

Objeto inmutable que representa las propiedades de formato 3-D efectivas.

El tipo IThreeDFormatEffectiveData expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`contour_width`](/slides/python-net/es/aspose.slides/ithreedformateffectivedata/contour_width/) | Devuelve el ancho de un contorno 3D.<br/>            Solo lectura **float**. |
| [`extrusion_height`](/slides/python-net/es/aspose.slides/ithreedformateffectivedata/extrusion_height/) | Devuelve la altura de un efecto de extrusión.<br/>            Solo lectura **float**. |
| [`depth`](/slides/python-net/es/aspose.slides/ithreedformateffectivedata/depth/) | Devuelve la profundidad de una forma 3D.<br/>            Solo lectura **float**. |
| [`bevel_top`](/slides/python-net/es/aspose.slides/ithreedformateffectivedata/bevel_top/) | Devuelve el tipo de bisel superior 3D.<br/>            Solo lectura [`IShapeBevelEffectiveData`](/slides/python-net/es/aspose.slides/ishapebeveleffectivedata). |
| [`bevel_bottom`](/slides/python-net/es/aspose.slides/ithreedformateffectivedata/bevel_bottom/) | Devuelve el tipo de bisel inferior 3D.<br/>            Solo lectura [`IShapeBevelEffectiveData`](/slides/python-net/es/aspose.slides/ishapebeveleffectivedata). |
| [`contour_color`](/slides/python-net/es/aspose.slides/ithreedformateffectivedata/contour_color/) | Devuelve el color de un contorno.<br/>            Solo lectura [`Color`](/slides/python-net/es/aspose.slides/color). |
| [`extrusion_color`](/slides/python-net/es/aspose.slides/ithreedformateffectivedata/extrusion_color/) | Devuelve el color de una extrusión.<br/>            Solo lectura [`Color`](/slides/python-net/es/aspose.slides/color). |
| [`camera`](/slides/python-net/es/aspose.slides/ithreedformateffectivedata/camera/) | Devuelve la configuración de una cámara.<br/>            Solo lectura [`ICameraEffectiveData`](/slides/python-net/es/aspose.slides/icameraeffectivedata). |
| [`light_rig`](/slides/python-net/es/aspose.slides/ithreedformateffectivedata/light_rig/) | Devuelve el tipo de una luz.<br/>            Solo lectura [`ILightRigEffectiveData`](/slides/python-net/es/aspose.slides/ilightrigeffectivedata). |

### Observaciones

Esta interfaz se usa junto con la interfaz [`IThreeDFormat`](/slides/python-net/es/aspose.slides/ithreedformat) para devolver valores de formato efectivos con herencia aplicada.
