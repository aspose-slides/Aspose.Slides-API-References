## remove(self, comment) {#icomment}
Elimina la primera aparición del comentario especificado en una colección.

```python
def remove(self, comment):
    ...
```

| Parámetro | Tipo | Descripción |
| :- | :- | :- |
| comment | [`IComment`](/slides/python-net/es/aspose.slides/icomment) | El comentario a eliminar de una colección. |

### Excepciones

| Excepción | Descripción |
| :- | :- |
| **RuntimeError(Proxy error(ArgumentNullException))** | Si el comentario es `None` |
| [`PptxEditException`](/slides/python-net/es/aspose.slides/pptxeditexception) | Lanzada si el comentario ya ha sido eliminado. |
