## IAdjustValue clase

Representa el valor de ajuste de una forma geométrica.
            Estos valores afectan la forma de la figura.

El tipo IAdjustValue expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`raw_value`](/slides/python-net/es/aspose.slides/iadjustvalue/raw_value/) | Devuelve o establece el valor de ajuste "as is".<br/>            Lectura/escritura **int**. |
| [`angle_value`](/slides/python-net/es/aspose.slides/iadjustvalue/angle_value/) | Devuelve o establece el valor, interpretándolo como ángulo en grados.<br/>            Lectura/escritura **float**. |
| [`name`](/slides/python-net/es/aspose.slides/iadjustvalue/name/) | Devuelve el nombre de este valor de ajuste.<br/>            Solo lectura **str**. |
| [`type`](/slides/python-net/es/aspose.slides/iadjustvalue/type/) | Devuelve el tipo del ajuste de la forma.<br/>            Solo lectura [`ShapeAdjustmentType`](/slides/python-net/es/aspose.slides/shapeadjustmenttype). |
