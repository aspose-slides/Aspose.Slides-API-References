## ISensitivityLabel clase

Representa la etiqueta de sensibilidad de Microsoft Purview Information Protection.

El tipo ISensitivityLabel expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`id`](/slides/python-net/es/aspose.slides/isensitivitylabel/id/) | Devuelve o establece el id de la etiqueta de sensibilidad.<br/>            Lectura/escritura **str**. |
| [`site_id`](/slides/python-net/es/aspose.slides/isensitivitylabel/site_id/) | Devuelve o establece el identificador del sitio de Azure Active Directory (Azure AD) <br/>            correspondiente a la política de etiqueta de sensibilidad que describe la etiqueta de sensibilidad.<br/>            Lectura/escritura **System.Guid**. |
| [`is_enabled`](/slides/python-net/es/aspose.slides/isensitivitylabel/is_enabled/) | Indica si la etiqueta de sensibilidad está habilitada. |
| [`is_removed`](/slides/python-net/es/aspose.slides/isensitivitylabel/is_removed/) | Indica si la etiqueta de sensibilidad fue eliminada. |
| [`assignment_method_type`](/slides/python-net/es/aspose.slides/isensitivitylabel/assignment_method_type/) | Devuelve o establece el método de asignación para la etiqueta de sensibilidad.<br/>            Lectura/escritura [`SensitivityLabelAssignmentType`](/slides/python-net/es/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/es/aspose.slides/isensitivitylabel/content_mark_types/) | Devuelve la lista de tipos de marcado de contenido que deben aplicarse a un archivo. |
