## TextSearchOptions clase

Representa opciones que pueden usarse para buscar texto en una Presentation, Slide o TextFrame.

El tipo TextSearchOptions expone los siguientes miembros:

## Constructores

| Constructor | Descripción |
| :- | :- |
| [`__init__(self)`](/slides/python-net/es/aspose.slides/textsearchoptions/__init__/#) | Crea nuevas opciones de búsqueda de texto predeterminadas. |

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`case_sensitive`](/slides/python-net/es/aspose.slides/textsearchoptions/case_sensitive/) | Establezca true para usar búsqueda sensible a mayúsculas y minúsculas, false en caso contrario.<br/>            Lectura/escritura **bool**. |
| [`whole_words_only`](/slides/python-net/es/aspose.slides/textsearchoptions/whole_words_only/) | Establezca true para coincidir solo palabras completas, false en caso contrario.<br/>            Lectura/escritura **bool**. |
| [`include_notes`](/slides/python-net/es/aspose.slides/textsearchoptions/include_notes/) | Establezca `true` para incluir texto contenido en notas de diapositiva ([`NotesSlide`](/slides/python-net/es/aspose.slides/notesslide)) <br/>            al realizar operaciones de búsqueda de texto, reemplazo o resaltado.<br/>            El valor predeterminado es `false`. |
