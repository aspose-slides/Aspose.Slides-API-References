## LoadFormat enumeración

Indica el formato del documento que se va a cargar.

El tipo LoadFormat expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| AUTO | Indica a Aspose.Slides que reconozca el formato automáticamente. |
| PPT | Presentación Microsoft PowerPoint 97-2003. |
| PPS | Presentación de diapositivas Microsoft PowerPoint 97-2003. |
| PPTX | Documento Microsoft Office Open XML PresentationML. |
| PPSX | Presentación de diapositivas Microsoft Office Open XML PresentationML. |
| ODP | Presentación OpenOffice ODF. |
| POTX | Plantilla Microsoft Office Open XML PresentationML. |
| PPTM | Documento Microsoft Office Open XML PresentationML con macros. |
| PPSM | Presentación de diapositivas Microsoft Office Open XML PresentationML con macros. |
| POTM | Plantilla Microsoft Office Open XML PresentationML con macros. |
| OTP | Plantilla de presentación OpenOffice OTP. |
| PPT95 | Presentación Microsoft PowerPoint 95. |
| POT | Plantilla de presentación Microsoft PowerPoint 97-2003. |
| FODP | Presentación Flat XML ODF. |
| UNKNOWN | Formato de archivo desconocido |
