## IInterruptionTokenSource clase

Representa la fuente de [`IInterruptionToken`](/slides/python-net/es/aspose.slides/iinterruptiontoken).

El tipo IInterruptionTokenSource expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`token`](/slides/python-net/es/aspose.slides/iinterruptiontokensource/token/) | Devuelve un nuevo token vinculado a este [`IInterruptionTokenSource`](/slides/python-net/es/aspose.slides/iinterruptiontokensource). |
| [`is_interruption_requested`](/slides/python-net/es/aspose.slides/iinterruptiontokensource/is_interruption_requested/) | Devuelve true si se solicitó interrupción, false de lo contrario. |
