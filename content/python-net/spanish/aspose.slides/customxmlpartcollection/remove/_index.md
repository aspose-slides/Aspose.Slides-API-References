## remove(self, item) {#icustomxmlpart}
Elimina la primera ocurrencia de un objeto específico de la colección.

### Devuelve

`true` si item se elimina correctamente; de lo contrario, `false`.



```python
def remove(self, item):
    ...
```


| Parámetro | Tipo | Descripción |
| :- | :- | :- |
| item | [`ICustomXmlPart`](/slides/python-net/es/aspose.slides/icustomxmlpart) | La parte xml personalizada para eliminar. |

### Excepciones

| Excepción | Descripción |
| :- | :- |
| **RuntimeError(Proxy error(ArgumentNullException))** | item es `None`. |
