## InkEffectType enumeración

Especifica un conjunto de efectos visuales predefinidos para la renderización de tinta.  
Cada efecto corresponde a una textura o imagen que simula una apariencia de tinta estilizada.  
Estos valores pueden usarse para personalizar el estilo visual de los trazos de tinta digital durante la renderización.

El tipo InkEffectType expone los siguientes miembros:

## Campos

| Campo | Descripción |
| :- | :- |
| NOT_DEFINED | El efecto no está definido o es desconocido. Este valor puede usarse como predeterminado o reserva. |
| BRONZE | Una textura metálica cálida y parduzca que se asemeja a tinta de bronce. |
| GALAXY | Una textura colorida y brillante que se asemeja a una galaxia, con tonos cósmicos. |
| GOLD | Una textura metálica dorada brillante que brinda a los trazos de tinta una apariencia lujosa. |
| LAVA | Una textura ígnea que se asemeja a lava fundida, con tonos rojos y naranjas. |
| OCEAN | Una textura de tono azul profundo, similar a un fluido, que imita las olas del océano o tinta a base de agua. |
| RAINBOW_GLITTER | Un efecto de brillo arcoíris colorido y chispeante utilizado para trazos de tinta festivos o vibrantes. |
| ROSE_GOLD | Una mezcla suave de rosa y oro, similar al oro rosado, para trazos de tinta elegantes. |
| SILVER | Una textura plateada metálica fría que simula tinta plateada clásica. |
