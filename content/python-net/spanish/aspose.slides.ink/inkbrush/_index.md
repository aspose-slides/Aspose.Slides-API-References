## Clase InkBrush

Representa un objeto inkBrush.

El tipo InkBrush expone los siguientes miembros:

## Propiedades

| Propiedad | Descripción |
| :- | :- |
| [`color`](/slides/python-net/es/aspose.slides.ink/inkbrush/color/) | Obtiene o establece el color del pincel para una línea. |
| [`size`](/slides/python-net/es/aspose.slides.ink/inkbrush/size/) | Obtiene o establece el tamaño del pincel para una línea en puntos. |
| [`ink_effect`](/slides/python-net/es/aspose.slides.ink/inkbrush/ink_effect/) | Obtiene el tipo de efecto de tinta (p. ej., Galaxy, Gold, Silver) que define el estilo visual del trazo de tinta.<br/>            El valor se analiza a partir de la propiedad brush "inkEffects". Si no se especifica un efecto reconocido,<br/>            [`InkEffectType.NOT_DEFINED`](/slides/python-net/es/aspose.slides.ink/inkeffecttype/NOT_DEFINED) se devuelve. |
