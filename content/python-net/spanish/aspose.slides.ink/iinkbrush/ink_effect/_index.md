## ink_effect propiedad
Obtiene el tipo de efecto de tinta (p. ej., Galaxy, Gold, Silver) que define el estilo visual del trazo de tinta.
El valor se analiza a partir de la propiedad brush "inkEffects". Si no se especifica un efecto reconocido,
[`InkEffectType.NOT_DEFINED`](/slides/python-net/es/aspose.slides.ink/inkeffecttype/NOT_DEFINED) se devuelve.
