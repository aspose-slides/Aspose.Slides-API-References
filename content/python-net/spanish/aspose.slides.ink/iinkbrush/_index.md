## IInkBrush clase

Representa la brocha de trazo.

El tipo IInkBrush expone los siguientes miembros:

## Propiedades

| Property | Description |
| :- | :- |
| [`color`](/slides/python-net/es/aspose.slides.ink/iinkbrush/color/) | Obtiene o establece el color de la brocha para una línea. |
| [`size`](/slides/python-net/es/aspose.slides.ink/iinkbrush/size/) | Obtiene o establece el tamaño de la brocha para una línea en puntos. |
| [`ink_effect`](/slides/python-net/es/aspose.slides.ink/iinkbrush/ink_effect/) | Obtiene el tipo de efecto de tinta (p. ej., Galaxy, Gold, Silver) que define el estilo visual del trazo de tinta.<br/>            El valor se analiza a partir de la propiedad de brocha \"inkEffects\". Si no se especifica un efecto reconocido,<br/>            [`InkEffectType.NOT_DEFINED`](/slides/python-net/es/aspose.slides.ink/inkeffecttype/NOT_DEFINED) se devuelve. |
