## WarningType 枚举

表示一种警告类型。

WarningType 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| SOURCE_FILE_CORRUPTION | 检测到源文档中存在问题，这使得如果以原始格式保存，文档很可能无法打开。 |
| DATA_LOSS | 文本/图表/图像或其他数据将在加载后的文档树或保存后的生成文档中完全缺失。 |
| MAJOR_FORMATTING_LOSS | 重大格式丢失。 |
| MINOR_FORMATTING_LOSS | 次要格式丢失。 |
| COMPATIBILITY_ISSUE | 这是已知问题，会导致文档无法被某些用户代理或旧版本的用户代理打开。 |
| UNEXPECTED_CONTENT | 源文档中的某些内容无法识别（即不受支持），这可能会导致问题，也可能导致数据/格式丢失。 |
