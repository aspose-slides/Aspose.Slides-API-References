## IMotionEffect 类

表示效果的运动效果行为。

IMotionEffect 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`from_address`](/slides/python-net/zh/aspose.slides.animation/imotioneffect/from_address/) | 指定动画开始的 x/y 坐标（以百分比表示）。<br/>            读取/写入 **aspose.slides.PointF**。 |
| [`to`](/slides/python-net/zh/aspose.slides.animation/imotioneffect/to/) | 指定动画运动效果的目标位置（以百分比表示）。<br/>            读取/写入 **aspose.slides.PointF**。 |
| [`by`](/slides/python-net/zh/aspose.slides.animation/imotioneffect/by/) | 描述动画的相对偏移值（以百分比表示）。<br/>            读取/写入 **aspose.slides.PointF**。 |
| [`rotation_center`](/slides/python-net/zh/aspose.slides.animation/imotioneffect/rotation_center/) | 描述用于将运动路径按 X 角度旋转的中心点。<br/>            读取/写入 **aspose.slides.PointF**。 |
| [`origin`](/slides/python-net/zh/aspose.slides.animation/imotioneffect/origin/) | 指定运动路径的起点相对于什么，例如幻灯片布局，<br/>            或父级。<br/>            读取/写入 [`MotionOriginType`](/slides/python-net/zh/aspose.slides.animation/motionorigintype)。 |
| [`path`](/slides/python-net/zh/aspose.slides.animation/imotioneffect/path/) | 指定动画运动路径的基元以及随后坐标。<br/>            读取/写入 [`IMotionPath`](/slides/python-net/zh/aspose.slides.animation/imotionpath)。 |
| [`path_edit_mode`](/slides/python-net/zh/aspose.slides.animation/imotioneffect/path_edit_mode/) | 指定当形状移动时运动路径的移动方式。<br/>            读取/写入 [`MotionPathEditMode`](/slides/python-net/zh/aspose.slides.animation/motionpatheditmode)。 |
| [`angle`](/slides/python-net/zh/aspose.slides.animation/imotioneffect/angle/) | 描述运动路径的相对角度。<br/>            读取/写入 **float**。 |
