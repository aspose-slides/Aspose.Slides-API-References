## IMotionEffect 类

表示效果的运动效果行为。

IMotionEffect 类型公开以下成员：

## 属性

| Property | Description |
| :- | :- |
| [`from_address`](/slides/python-net/zh/aspose.slides.animation/imotioneffect/from_address/) | 指定动画开始的 x/y 坐标（以百分比为单位）。 <br/>            可读写 [`PointF`](/slides/python-net/zh/aspose.slides/pointf). |
| [`to`](/slides/python-net/zh/aspose.slides.animation/imotioneffect/to/) | 指定动画运动效果的目标位置（以百分比为单位）。<br/>            可读写 [`PointF`](/slides/python-net/zh/aspose.slides/pointf). |
| [`by`](/slides/python-net/zh/aspose.slides.animation/imotioneffect/by/) | 描述动画的相对偏移值（以百分比为单位）。<br/>            可读写 [`PointF`](/slides/python-net/zh/aspose.slides/pointf). |
| [`rotation_center`](/slides/python-net/zh/aspose.slides.animation/imotioneffect/rotation_center/) | 描述用于将运动路径旋转 X 角度的旋转中心。<br/>            可读写 [`PointF`](/slides/python-net/zh/aspose.slides/pointf). |
| [`origin`](/slides/python-net/zh/aspose.slides.animation/imotioneffect/origin/) | 指定运动路径的原点相对于什么，例如幻灯片布局，<br/>            或父对象。<br/>            可读写 [`MotionOriginType`](/slides/python-net/zh/aspose.slides.animation/motionorigintype). |
| [`path`](/slides/python-net/zh/aspose.slides.animation/imotioneffect/path/) | 指定动画运动的路径原语以及随后坐标。<br/>            可读写 [`IMotionPath`](/slides/python-net/zh/aspose.slides.animation/imotionpath). |
| [`path_edit_mode`](/slides/python-net/zh/aspose.slides.animation/imotioneffect/path_edit_mode/) | 指定当形状移动时运动路径的移动方式。<br/>            可读写 [`MotionPathEditMode`](/slides/python-net/zh/aspose.slides.animation/motionpatheditmode). |
| [`angle`](/slides/python-net/zh/aspose.slides.animation/imotioneffect/angle/) | 描述运动路径的相对角度。<br/>            可读写 **float**. |
