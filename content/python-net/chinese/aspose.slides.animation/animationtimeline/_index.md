## AnimationTimeLine 类

表示动画的时间轴。

AnimationTimeLine 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`interactive_sequences`](/slides/python-net/zh/aspose.slides.animation/animationtimeline/interactive_sequences/) | 返回交互式序列的集合。<br/>            这些序列可能仅包含通过“单击形状”指定目标形状的效果。<br/>            只读 [`ISequenceCollection`](/slides/python-net/zh/aspose.slides.animation/isequencecollection). |
| [`main_sequence`](/slides/python-net/zh/aspose.slides.animation/animationtimeline/main_sequence/) | 返回主序列，该序列可能只包含主效果集合。<br/>            只读 [`ISequence`](/slides/python-net/zh/aspose.slides.animation/isequence). |
| [`text_animation_collection`](/slides/python-net/zh/aspose.slides.animation/animationtimeline/text_animation_collection/) | 返回文本动画的集合。<br/>            只读 [`ITextAnimationCollection`](/slides/python-net/zh/aspose.slides.animation/itextanimationcollection). |
