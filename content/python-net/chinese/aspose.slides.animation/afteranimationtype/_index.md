## AfterAnimationType 枚举

表示动画效果的后置动画类型。

AfterAnimationType 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| DO_NOT_DIM | 动画完成后不变暗。 |
| COLOR | 动画完成后的颜色。 |
| HIDE_AFTER_ANIMATION | 动画完成后隐藏类型 |
| HIDE_ON_NEXT_MOUSE_CLICK | 动画完成后在下一次鼠标点击时隐藏。 |
