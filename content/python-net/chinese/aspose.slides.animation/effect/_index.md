## Effect 类

表示动画效果。

Effect 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`sequence`](/slides/python-net/zh/aspose.slides.animation/effect/sequence/) | 返回效果的序列。<br/>            只读 [`ISequence`](/slides/python-net/zh/aspose.slides.animation/isequence)。 |
| [`text_animation`](/slides/python-net/zh/aspose.slides.animation/effect/text_animation/) | TextAnimation<br/>            只读 [`ITextAnimation`](/slides/python-net/zh/aspose.slides.animation/itextanimation)。 |
| [`preset_class_type`](/slides/python-net/zh/aspose.slides.animation/effect/preset_class_type/) | 定义效果的类。<br/>            可读写 [`EffectPresetClassType`](/slides/python-net/zh/aspose.slides.animation/effectpresetclasstype)。 |
| [`type`](/slides/python-net/zh/aspose.slides.animation/effect/type/) | 定义效果的类型。<br/>            可读写 [`EffectType`](/slides/python-net/zh/aspose.slides.animation/effecttype)。 |
| [`subtype`](/slides/python-net/zh/aspose.slides.animation/effect/subtype/) | 定义效果的子类型。<br/>            可读写 [`EffectSubtype`](/slides/python-net/zh/aspose.slides.animation/effectsubtype)。 |
| [`behaviors`](/slides/python-net/zh/aspose.slides.animation/effect/behaviors/) | 返回效果的行为集合。<br/>            可读写 [`IBehaviorCollection`](/slides/python-net/zh/aspose.slides.animation/ibehaviorcollection)。 |
| [`timing`](/slides/python-net/zh/aspose.slides.animation/effect/timing/) | 定义效果的时间值。<br/>            可读写 [`ITiming`](/slides/python-net/zh/aspose.slides.animation/itiming)。 |
| [`target_shape`](/slides/python-net/zh/aspose.slides.animation/effect/target_shape/) | 返回效果的目标形状。<br/>            只读 [`IShape`](/slides/python-net/zh/aspose.slides/ishape)。 |
| [`sound`](/slides/python-net/zh/aspose.slides.animation/effect/sound/) | 定义效果的嵌入式声音。<br/>            可读写 [`IAudio`](/slides/python-net/zh/aspose.slides/iaudio)。 |
| [`stop_previous_sound`](/slides/python-net/zh/aspose.slides.animation/effect/stop_previous_sound/) | 此属性指定动画效果是否停止先前的声音。<br/>            可读写 **bool**。 |
| [`after_animation_type`](/slides/python-net/zh/aspose.slides.animation/effect/after_animation_type/) | 定义效果的后置动画类型。<br/>            可读写 [`Effect.after_animation_type`](/slides/python-net/zh/aspose.slides.animation/effect/after_animation_type)。 |
| [`after_animation_color`](/slides/python-net/zh/aspose.slides.animation/effect/after_animation_color/) | 定义效果的后置动画颜色。<br/>            可读写 [`IColorFormat`](/slides/python-net/zh/aspose.slides/icolorformat)。 |
| [`animate_text_type`](/slides/python-net/zh/aspose.slides.animation/effect/animate_text_type/) | 定义效果的文字动画类型。<br/>            形状文字可以按字母、按单词或一次性全部动画。<br/>            可读写 [`Effect.animate_text_type`](/slides/python-net/zh/aspose.slides.animation/effect/animate_text_type)。 |
| [`delay_between_text_parts`](/slides/python-net/zh/aspose.slides.animation/effect/delay_between_text_parts/) | 定义动画文字部分（单词或字母）之间的延迟。<br/>            正值指定效果持续时间的百分比。<br/>            负值指定以秒为单位的延迟。<br/>            可读写 **float**。 |
