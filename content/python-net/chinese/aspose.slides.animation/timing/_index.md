## Timing 类

表示动画计时。

Timing 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`accelerate`](/slides/python-net/zh/aspose.slides.animation/timing/accelerate/) | 描述持续时间加速行为效果的百分比。<br/>            读/写 **float**. |
| [`decelerate`](/slides/python-net/zh/aspose.slides.animation/timing/decelerate/) | 描述持续时间减速行为效果的百分比。<br/>            读/写 **float**. |
| [`auto_reverse`](/slides/python-net/zh/aspose.slides.animation/timing/auto_reverse/) | 描述在正向播放后是否自动逆向播放动画。<br/>            读/写 **bool**. |
| [`duration`](/slides/python-net/zh/aspose.slides.animation/timing/duration/) | 描述动画效果的持续时间。<br/>            读/写 **float**. |
| [`repeat_count`](/slides/python-net/zh/aspose.slides.animation/timing/repeat_count/) | 描述效果应重复的次数。<br/>            读/写 **float**. |
| [`repeat_until_end_slide`](/slides/python-net/zh/aspose.slides.animation/timing/repeat_until_end_slide/) | 此属性指定效果是否会重复直至幻灯片结束。<br/>            读/写 **bool**. |
| [`repeat_until_next_click`](/slides/python-net/zh/aspose.slides.animation/timing/repeat_until_next_click/) | 此属性指定效果是否会重复直至下一次点击。<br/>            读/写 **bool**. |
| [`repeat_duration`](/slides/python-net/zh/aspose.slides.animation/timing/repeat_duration/) | 描述效果应重复的次数。<br/>            读/写 **float**. |
| [`restart`](/slides/python-net/zh/aspose.slides.animation/timing/restart/) | 指定效果在完成后是否重新启动。<br/>            读/写 [`EffectRestartType`](/slides/python-net/zh/aspose.slides.animation/effectrestarttype). |
| [`rewind`](/slides/python-net/zh/aspose.slides.animation/timing/rewind/) | 此属性指定在播放完毕后是否会倒回效果。<br/>            读/写 **bool**. |
| [`speed`](/slides/python-net/zh/aspose.slides.animation/timing/speed/) | 指定计时加速（或减速）的百分比。<br/>            读/写 **float**. |
| [`trigger_delay_time`](/slides/python-net/zh/aspose.slides.animation/timing/trigger_delay_time/) | 描述触发后的延迟时间。<br/>            读/写 **float**. |
| [`trigger_type`](/slides/python-net/zh/aspose.slides.animation/timing/trigger_type/) | 描述触发类型。<br/>            读/写 [`EffectTriggerType`](/slides/python-net/zh/aspose.slides.animation/effecttriggertype). |
