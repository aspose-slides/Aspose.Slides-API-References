## ITiming 类

表示动画计时。

ITiming 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`accelerate`](/slides/python-net/zh/aspose.slides.animation/itiming/accelerate/) | 描述持续时间加速行为效果的百分比。<br/>            读/写 **float**。 |
| [`decelerate`](/slides/python-net/zh/aspose.slides.animation/itiming/decelerate/) | 描述持续时间减速行为效果的百分比。<br/>            读/写 **float**。 |
| [`auto_reverse`](/slides/python-net/zh/aspose.slides.animation/itiming/auto_reverse/) | 描述是否在正向播放后自动反向播放动画。<br/>            在正向方向播放后。<br/>            读/写 **bool**。 |
| [`duration`](/slides/python-net/zh/aspose.slides.animation/itiming/duration/) | 描述动画效果的持续时间。<br/>            读/写 **float**。 |
| [`repeat_count`](/slides/python-net/zh/aspose.slides.animation/itiming/repeat_count/) | 描述效果应重复的次数。<br/>            读/写 **float**。 |
| [`repeat_until_end_slide`](/slides/python-net/zh/aspose.slides.animation/itiming/repeat_until_end_slide/) | 此属性指定效果是否会重复直至幻灯片结束。<br/>             读/写 **bool**。 |
| [`repeat_until_next_click`](/slides/python-net/zh/aspose.slides.animation/itiming/repeat_until_next_click/) | 此属性指定效果是否会重复直至下一次点击。<br/>             读/写 **bool**。 |
| [`repeat_duration`](/slides/python-net/zh/aspose.slides.animation/itiming/repeat_duration/) | 描述效果应重复的次数。<br/>            读/写 **float**。 |
| [`restart`](/slides/python-net/zh/aspose.slides.animation/itiming/restart/) | 指定效果是否在完成后重新启动。<br/>            读/写 [`EffectRestartType`](/slides/python-net/zh/aspose.slides.animation/effectrestarttype)。 |
| [`speed`](/slides/python-net/zh/aspose.slides.animation/itiming/speed/) | 指定加速（或减速）时间的百分比。<br/>            读/写 **float**。 |
| [`trigger_delay_time`](/slides/python-net/zh/aspose.slides.animation/itiming/trigger_delay_time/) | 描述触发后的延迟时间。<br/>            读/写 **float**。 |
| [`trigger_type`](/slides/python-net/zh/aspose.slides.animation/itiming/trigger_type/) | 描述触发类型。<br/>            读/写 [`EffectTriggerType`](/slides/python-net/zh/aspose.slides.animation/effecttriggertype)。 |
| [`rewind`](/slides/python-net/zh/aspose.slides.animation/itiming/rewind/) | 此属性指定在播放完成后效果是否会倒回。<br/>             读/写 **bool**。 |
