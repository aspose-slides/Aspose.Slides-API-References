## ITextAnimation 类

表示文本动画。

ITextAnimation 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`build_type`](/slides/python-net/zh/aspose.slides.animation/itextanimation/build_type/) | 文本动画的构建类型列表（例如 Paragraph 1,2,3, All at Once）。<br/>            读/写 [`ITextAnimation.build_type`](/slides/python-net/zh/aspose.slides.animation/itextanimation/build_type)。 |
| [`effect_animate_background_shape`](/slides/python-net/zh/aspose.slides.animation/itextanimation/effect_animate_background_shape/) | 是否与组链接的形状效果（None）。<br/>            读/写 [`IEffect`](/slides/python-net/zh/aspose.slides.animation/ieffect)。 |

## 方法

| 方法 | 描述 |
| :- | :- |
| [`add_effect(self, effect_type, subtype, trigger_type)`](/slides/python-net/zh/aspose.slides.animation/itextanimation/add_effect/#effecttype-effectsubtype-effecttriggertype) | 将新效果添加到当前序列的末尾，以结束组文本动画。<br/>            仅当文本段落的数量大于或等于该组效果的数量时有效！ |
