## IImage 类

表示光栅图像或矢量图像。

IImage 类型公开以下成员：

## 属性

| Property | Description |
| :- | :- |
| [`size`](/slides/python-net/zh/aspose.slides/iimage/size/) | 获取图像的大小。 |
| [`width`](/slides/python-net/zh/aspose.slides/iimage/width/) | 获取图像的宽度（像素）。 |
| [`height`](/slides/python-net/zh/aspose.slides/iimage/height/) | 获取图像的高度（像素）。 |

## 方法

| Method | Description |
| :- | :- |
| [`save(self, filename)`](/slides/python-net/zh/aspose.slides/iimage/save/#str) | 将图像保存到文件。 |
| [`save(self, filename, format)`](/slides/python-net/zh/aspose.slides/iimage/save/#str-imageformat) | 将图像以指定格式保存到文件。 |
| [`save(self, stream, format)`](/slides/python-net/zh/aspose.slides/iimage/save/#iorawiobase-imageformat) | 将图像以指定格式保存到流。 |
| [`save(self, filename, format, quality)`](/slides/python-net/zh/aspose.slides/iimage/save/#str-imageformat-int) | 将图像以指定的格式和质量保存到文件。 |
| [`save(self, stream, format, quality)`](/slides/python-net/zh/aspose.slides/iimage/save/#iorawiobase-imageformat-int) | 将图像以指定的格式和质量保存到流。 |


### 备注

此接口提供了处理光栅图像和矢量图像的通用抽象。  
实现可能会因底层图像类型而异。
