## IFonts 类

表示字体集合。

IFonts 类型公开以下成员：

## 属性

| Property | Description |
| :- | :- |
| [`latin_font`](/slides/python-net/zh/aspose.slides/ifonts/latin_font/) | 返回或设置拉丁字体。<br/>            读取/写入 [`IFontData`](/slides/python-net/zh/aspose.slides/ifontdata). |
| [`east_asian_font`](/slides/python-net/zh/aspose.slides/ifonts/east_asian_font/) | 返回或设置东亚字体。<br/>            读取/写入 [`IFontData`](/slides/python-net/zh/aspose.slides/ifontdata). |
| [`complex_script_font`](/slides/python-net/zh/aspose.slides/ifonts/complex_script_font/) | 返回或设置复杂脚本字体。<br/>            读取/写入 [`IFontData`](/slides/python-net/zh/aspose.slides/ifontdata). |

## 方法

| Method | Description |
| :- | :- |
| [`get_script_font_map(self)`](/slides/python-net/zh/aspose.slides/ifonts/get_script_font_map/#) | 返回演示文稿中所有字符串-字符串对脚本字体定义的列表。 |
| [`get_script_font(self, script)`](/slides/python-net/zh/aspose.slides/ifonts/get_script_font/#str) | 获取演示文稿主题中与特定脚本标签关联的字体名称。 |
| [`set_script_font(self, script, font_name)`](/slides/python-net/zh/aspose.slides/ifonts/set_script_font/#str-str) | 为特定脚本标签分配字体名称，以定义该脚本的文本在演示文稿中的渲染方式。 |
| [`remove_script_font(self, script)`](/slides/python-net/zh/aspose.slides/ifonts/remove_script_font/#str) | 从主题的字体集合中移除与特定脚本标签关联的字体设置。 |
