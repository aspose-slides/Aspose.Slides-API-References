## get_script_font(self, script) {#str}
获取与演示文稿主题中特定 script 标记关联的字体名称。

### 返回值

指定脚本使用的字体名称；如果未定义该脚本，则返回 `None`。

```python
def get_script_font(self, script):
    ...
```

| 参数 | 类型 | 描述 |
| :- | :- | :- |
| script | **str** | 用于标识书写系统的 BCP-47 脚本代码（例如 "Latn", "Cyrl", "Jpan"）。 |
