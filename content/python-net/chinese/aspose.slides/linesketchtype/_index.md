## LineSketchType 枚举

表示已分配给形状的草图类型或效果。

LineSketchType 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| NOT_DEFINED | 指定形状的 Sketch 效果未定义。 |
| NONE | 指定形状没有 Sketch 效果。这相当于该属性为空。 |
| CURVED | 指定形状具有 Curved 效果，该效果将形状的每条边转换为一个大的柔和曲线。 |
| FREEHAND | 指定形状具有 Freehand 效果，该效果最接近不完美绘制的线条。 |
| SCRIBBLE | 指定形状具有 Scribble 效果，该效果具有夸张的振荡，仿佛是故意绘制得凌乱。 |
