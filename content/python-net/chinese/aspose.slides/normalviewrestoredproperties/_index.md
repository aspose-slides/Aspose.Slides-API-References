## NormalViewRestoredProperties 类

指定正常视图中幻灯片区域的大小（当作为 restoredTop 的子项时为宽度，<br/>            当作为 restoredLeft 的子项时为高度），当该区域具有可变还原大小（既未最小化也未最大化）时。

NormalViewRestoredProperties 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`dimension_size`](/slides/python-net/zh/aspose.slides/normalviewrestoredproperties/dimension_size/) | 指定幻灯片区域的大小（当作为 RestoredTop 的子项时为宽度，<br/>            当作为 RestoredLeft 的子项时为高度）。<br/>            读/写 **float**. |
| [`auto_adjust`](/slides/python-net/zh/aspose.slides/normalviewrestoredproperties/auto_adjust/) | 指定侧内容区域的大小是否应补偿新的尺寸<br/>            当在应用程序中调整包含视图的窗口大小时<br/>            读/写 **bool**. |
