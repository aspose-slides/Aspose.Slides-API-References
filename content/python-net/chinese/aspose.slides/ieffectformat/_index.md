## IEffectFormat 类

表示形状的效果属性。

IEffectFormat 类型公开以下成员：

## 属性

| Property | Description |
| :- | :- |
| [`is_no_effects`](/slides/python-net/zh/aspose.slides/ieffectformat/is_no_effects/) | 如果所有效果都被禁用则返回 true（如刚创建的默认 EffectFormat 对象）。<br/>            只读 **bool**。 |
| [`blur_effect`](/slides/python-net/zh/aspose.slides/ieffectformat/blur_effect/) | 模糊效果。<br/>            可读写 [`IBlur`](/slides/python-net/zh/aspose.slides.effects/iblur)。 |
| [`fill_overlay_effect`](/slides/python-net/zh/aspose.slides/ieffectformat/fill_overlay_effect/) | 填充覆盖效果。<br/>            可读写 [`IFillOverlay`](/slides/python-net/zh/aspose.slides.effects/ifilloverlay)。 |
| [`glow_effect`](/slides/python-net/zh/aspose.slides/ieffectformat/glow_effect/) | 发光效果。<br/>            可读写 [`IGlow`](/slides/python-net/zh/aspose.slides.effects/iglow)。 |
| [`inner_shadow_effect`](/slides/python-net/zh/aspose.slides/ieffectformat/inner_shadow_effect/) | 内部阴影。<br/>            可读写 [`IInnerShadow`](/slides/python-net/zh/aspose.slides.effects/iinnershadow)。 |
| [`outer_shadow_effect`](/slides/python-net/zh/aspose.slides/ieffectformat/outer_shadow_effect/) | 外部阴影。<br/>            可读写 [`IOuterShadow`](/slides/python-net/zh/aspose.slides.effects/ioutershadow)。 |
| [`preset_shadow_effect`](/slides/python-net/zh/aspose.slides/ieffectformat/preset_shadow_effect/) | 预设阴影。<br/>            可读写 [`IPresetShadow`](/slides/python-net/zh/aspose.slides.effects/ipresetshadow)。 |
| [`reflection_effect`](/slides/python-net/zh/aspose.slides/ieffectformat/reflection_effect/) | 反射。<br/>            可读写 [`IReflection`](/slides/python-net/zh/aspose.slides.effects/ireflection)。 |
| [`soft_edge_effect`](/slides/python-net/zh/aspose.slides/ieffectformat/soft_edge_effect/) | 柔和边缘。<br/>            可读写 [`ISoftEdge`](/slides/python-net/zh/aspose.slides.effects/isoftedge)。 |
