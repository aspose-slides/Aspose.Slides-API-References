## SplitterBarStateType 枚举

指定应显示的拆分条状态。拆分条将视图区域内的主要区域和次要区域分开。

SplitterBarStateType 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| MINIMIZED | 主要区域占据应用允许的视图区域的最小部分。 |
| RESTORED | 主要区域具有特定的中等大小。 |
| MAXIMIZED | 主要区域占据应用允许的视图区域的最大部分。 |
