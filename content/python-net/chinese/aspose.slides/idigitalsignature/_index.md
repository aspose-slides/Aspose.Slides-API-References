## IDigitalSignature 类

已签名文件中的数字签名。

IDigitalSignature 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`certificate`](/slides/python-net/zh/aspose.slides/idigitalsignature/certificate/) | 用于签署文档的证书对象。<br/>            只读 **System.Security.Cryptography.X509Certificates.X509Certificate2**. |
| [`is_valid`](/slides/python-net/zh/aspose.slides/idigitalsignature/is_valid/) | 如果此数字签名有效且文档未被篡改，则此值为 true。<br/>            只读 **bool**. |
| [`sign_time`](/slides/python-net/zh/aspose.slides/idigitalsignature/sign_time/) | 文档签署的时间。<br/>            只读 **System.DateTime**. |
| [`comments`](/slides/python-net/zh/aspose.slides/idigitalsignature/comments/) | 签名的目的。<br/>            读写 **str**. |
