## ICustomXmlPart 类

表示自定义 XML 部分。

ICustomXmlPart 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`xml_as_string`](/slides/python-net/zh/aspose.slides/icustomxmlpart/xml_as_string/) | 返回或设置 XML 数据为 UTF-8 字符串。<br/>            读/写 **str**。<br/>            value 为 `None`。value 为空或 xml-data 无效。 |
| [`xml_data`](/slides/python-net/zh/aspose.slides/icustomxmlpart/xml_data/) | 返回或设置 XML 数据。<br/>            读/写 **int**[]。<br/>            value 为 `None`。value 为空或 xml-data 无效。 |
| [`item_id`](/slides/python-net/zh/aspose.slides/icustomxmlpart/item_id/) | 指定全局唯一标识符 (GUID)，该标识符唯一标识 Office Open XML 文档中的单个自定义 XML <br/>            部分。<br/>            只读 **System.Guid**。 |
| [`namespace_schemas`](/slides/python-net/zh/aspose.slides/icustomxmlpart/namespace_schemas/) | 返回与自定义 XML 部分关联的集合 XML 模式。<br/>            只读 **str**[]。 |

| :- | :- |
