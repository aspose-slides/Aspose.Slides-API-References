## TextAlignment 枚举

表示不同的文本对齐样式。

TextAlignment 类型公开以下成员：

## 字段

| Field | Description |
| :- | :- |
| NOT_DEFINED | 默认对齐。 |
| LEFT | 左对齐。 |
| CENTER | 居中对齐。 |
| RIGHT | 右对齐。 |
| JUSTIFY | 两端对齐。 |
| JUSTIFY_LOW | Kashida 低水平对齐。 |
| DISTRIBUTED | 分散对齐。 |
