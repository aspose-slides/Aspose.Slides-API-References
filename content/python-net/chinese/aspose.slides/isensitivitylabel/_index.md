## ISensitivityLabel 类

表示来自 Microsoft Purview 信息保护的敏感度标签。

ISensitivityLabel 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`id`](/slides/python-net/zh/aspose.slides/isensitivitylabel/id/) | 返回或设置敏感度标签的 ID。<br/>            读/写 **str**. |
| [`site_id`](/slides/python-net/zh/aspose.slides/isensitivitylabel/site_id/) | 返回或设置 Azure Active Directory (Azure AD) 站点标识符 <br/>            对应于描述该敏感度标签的敏感度标签策略。<br/>            读/写 **System.Guid**. |
| [`is_enabled`](/slides/python-net/zh/aspose.slides/isensitivitylabel/is_enabled/) | 指示敏感度标签是否已启用。 |
| [`is_removed`](/slides/python-net/zh/aspose.slides/isensitivitylabel/is_removed/) | 指示敏感度标签是否已被移除。 |
| [`assignment_method_type`](/slides/python-net/zh/aspose.slides/isensitivitylabel/assignment_method_type/) | 返回或设置敏感度标签的分配方法。<br/>            读/写 [`SensitivityLabelAssignmentType`](/slides/python-net/zh/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/zh/aspose.slides/isensitivitylabel/content_mark_types/) | 返回应应用于文件的内容标记类型列表。 |
