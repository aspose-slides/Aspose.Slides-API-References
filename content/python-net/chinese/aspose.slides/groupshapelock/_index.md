## GroupShapeLock 类

确定在父 GroupShape 上禁用哪些操作。

**继承:**[`GroupShapeLock`](/slides/python-net/zh/aspose.slides/groupshapelock) → [`BaseShapeLock`](/slides/python-net/zh/aspose.slides/baseshapelock)

GroupShapeLock 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`no_locks`](/slides/python-net/zh/aspose.slides/groupshapelock/no_locks/) | 如果所有锁标志均已禁用则返回 true。<br/>            只读 **bool**. |
| [`grouping_locked`](/slides/python-net/zh/aspose.slides/groupshapelock/grouping_locked/) | 确定是否禁止将此形状添加到组中。<br/>            读/写 **bool**. |
| [`ungrouping_locked`](/slides/python-net/zh/aspose.slides/groupshapelock/ungrouping_locked/) | 确定是否禁止拆分此组形状。<br/>            读/写 **bool**. |
| [`select_locked`](/slides/python-net/zh/aspose.slides/groupshapelock/select_locked/) | 确定是否禁止选择此形状。<br/>            读/写 **bool**. |
| [`rotation_locked`](/slides/python-net/zh/aspose.slides/groupshapelock/rotation_locked/) | 确定是否禁止更改此形状的旋转角度。<br/>            读/写 **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/zh/aspose.slides/groupshapelock/aspect_ratio_locked/) | 确定在调整大小时是否必须保持形状的宽高比。<br/>            读/写 **bool**. |
| [`position_locked`](/slides/python-net/zh/aspose.slides/groupshapelock/position_locked/) | 确定是否禁止移动此形状。<br/>            读/写 **bool**. |
| [`size_locked`](/slides/python-net/zh/aspose.slides/groupshapelock/size_locked/) | 确定是否禁止调整此形状的大小。<br/>            读/写 **bool**. |
