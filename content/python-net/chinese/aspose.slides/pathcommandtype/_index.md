## PathCommandType 枚举

表示图形路径命令

PathCommandType 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| CLOSE | 关闭几何路径 |
| MOVE_TO | 设置几何路径的下一个点位置 |
| LINE_TO | 向几何路径追加直线 |
| ARC_TO | 向几何路径追加指定的弧 |
| QUAD_BEZIER_TO | 向几何路径追加二次贝塞尔曲线 |
| CUBIC_BEZIER_TO | 向几何路径追加三次贝塞尔曲线 |
