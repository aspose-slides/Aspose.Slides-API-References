表示颜色方案中的索引。

| LIGHT1 | 亮色 1。 |

| LIGHT2 | 亮色 2。 |
| ACCENT1 | 强调色 1。 |
| ACCENT2 | 强调色 2。 |
| ACCENT3 | 强调色 3。 |
| ACCENT4 | 强调色 4。 |
