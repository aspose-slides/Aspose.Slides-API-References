## PathFillModeType 枚举

指定路径应如何填充

PathFillModeType 类型公开以下成员：

## 字段

| Field | Description |
| :- | :- |
| NONE | No Path Fill<br/>            这表示相应的路径不应有填充。 |
| NORMAL | Normal Path Fill<br/>            这表示相应的路径应使用正常阴影颜色填充。 |
| LIGHTEN | Lighten Path Fill<br/>            这表示相应的路径应使用轻度阴影颜色填充。 |
| LIGHTEN_LESS | Lighten Path Fill Less<br/>            这表示相应的路径应使用略微浅色阴影颜色填充。 |
| DARKEN | Darken Path Fill<br/>            这表示相应的路径应使用深色阴影颜色填充。 |
| DARKEN_LESS | Darken Path Fill Less<br/>            这表示相应的路径应使用略微深色阴影颜色填充。 |
