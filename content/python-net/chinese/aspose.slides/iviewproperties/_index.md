## IViewProperties 类

演示文稿范围的视图属性。

IViewProperties 类型公开以下成员：

## 属性

| Property | Description |
| :- | :- |
| [`last_view`](/slides/python-net/zh/aspose.slides/iviewproperties/last_view/) | 指定上次保存演示文稿时使用的视图模式。<br/>            读/写 [`ViewType`](/slides/python-net/zh/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/zh/aspose.slides/iviewproperties/show_comments/) | 指定是否应显示幻灯片注释。<br/>            读/写 [`NullableBool`](/slides/python-net/zh/aspose.slides/nullablebool). |
| [`slide_view_properties`](/slides/python-net/zh/aspose.slides/iviewproperties/slide_view_properties/) | 指定与幻灯片视图模式关联的通用视图属性。<br/>            只读 [`ICommonSlideViewProperties`](/slides/python-net/zh/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/zh/aspose.slides/iviewproperties/notes_view_properties/) | 指定与备注视图模式关联的通用视图属性。<br/>            只读 [`ICommonSlideViewProperties`](/slides/python-net/zh/aspose.slides/icommonslideviewproperties). |
| [`normal_view_properties`](/slides/python-net/zh/aspose.slides/iviewproperties/normal_view_properties/) | 表示普通视图属性。普通视图包括<br/>            三个内容区域：幻灯片本身、侧边内容区域和底部内容区域。<br/>            只读 [`INormalViewProperties`](/slides/python-net/zh/aspose.slides/inormalviewproperties). |
| [`grid_spacing`](/slides/python-net/zh/aspose.slides/iviewproperties/grid_spacing/) | 返回或设置用于演示文稿底层网格的网格间距（单位为点）。 <br/>            读/写 **float**. |
