## NumberedBulletStyle 枚举

表示编号项目符号的样式。

NumberedBulletStyle 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| NOT_DEFINED | 未定义。 |
| BULLET_ALPHA_LC_PERIOD | 小写字母后跟句点。例如：a., b., c., ... |
| BULLET_ALPHA_UC_PERIOD | 大写字母后跟句点。例如：A., B., C., ... |
| BULLET_ARABIC_PAREN_RIGHT | 阿拉伯数字后跟右括号。例如：1), 2), 3), ... |
| BULLET_ARABIC_PERIOD | 阿拉伯数字后跟句点。例如：1., 2., 3., ... |
| BULLET_ROMAN_LC_PAREN_BOTH | 小写罗马数字两侧都有括号。例如：(i), (ii), (iii), ... |
| BULLET_ROMAN_LC_PAREN_RIGHT | 小写罗马数字后跟右括号。例如：i), ii), iii), ... |
| BULLET_ROMAN_LC_PERIOD | 小写罗马数字后跟句点。例如：i., ii., iii., ... |
| BULLET_ROMAN_UC_PERIOD | 大写罗马数字后跟句点。例如：I., II., III., ... |
| BULLET_ALPHA_LC_PAREN_BOTH | 小写字母两侧都有括号。例如：(a), (b), (c), ... |
| BULLET_ALPHA_LC_PAREN_RIGHT | 小写字母后跟右括号。例如：a), b), c), ... |
| BULLET_ALPHA_UC_PAREN_BOTH | 大写字母两侧都有括号。例如：(A), (B), (C), ... |
| BULLET_ALPHA_UC_PAREN_RIGHT | 大写字母后跟右括号。例如：A), B), C), ... |
| BULLET_ARABIC_PAREN_BOTH | 阿拉伯数字两侧都有括号。例如：(1), (2), (3), ... |
| BULLET_ARABIC_PLAIN | 阿拉伯数字。例如：1, 2, 3, ... |
| BULLET_ROMAN_UC_PAREN_BOTH | 大写罗马数字两侧都有括号。例如：(I), (II), (III), ... |
| BULLET_ROMAN_UC_PAREN_RIGHT | 大写罗马数字后跟右括号。例如：I), II), III), ... |
| BULLET_SIMP_CHIN_PLAIN | 简体中文无句点。 |
| BULLET_SIMP_CHIN_PERIOD | 简体中文有句点。 |
| BULLET_CIRCLE_NUM_DB_PLAIN | 双字节圆形数字，适用于 10 以内的值，11 以后使用阿拉伯数字。 |
| BULLET_CIRCLE_NUM_WD_WHITE_PLAIN | 文本颜色数字，周围绘制相同颜色的圆圈（Wingdings 白色圆圈数字），11 以后使用阿拉伯数字。 |
| BULLET_CIRCLE_NUM_WD_BLACK_PLAIN | 阴影颜色数字，圆形背景为普通文本颜色（Wingdings 黑色圆圈数字）。 |
| BULLET_TRAD_CHIN_PLAIN | 繁体中文无句点。 |
| BULLET_TRAD_CHIN_PERIOD | 繁体中文有句点。 |
| BULLET_ARABIC_ALPHA_DASH | 阿拉伯语言字母字符带破折号。 |
| BULLET_ARABIC_ABJAD_DASH | 阿拉伯字母表（Abjad）字符带破折号。 |
| BULLET_HEBREW_ALPHA_DASH | 希伯来语言字母字符带破折号。 |
| BULLET_KANJI_KOREAN_PLAIN | 日语/韩语数字无句点。 |
| BULLET_KANJI_KOREAN_PERIOD | 日语/韩语数字有句点。 |
| BULLET_ARABIC_DB_PLAIN | 双字节阿拉伯数字方案（无标点）。 |
| BULLET_ARABIC_DB_PERIOD | 双字节阿拉伯数字方案，带双字节句点。 |
| BULLET_THAI_ALPHA_PERIOD | 泰文字母句点。 |
| BULLET_THAI_ALPHA_PAREN_RIGHT | 泰文字母右侧括号。 |
| BULLET_THAI_ALPHA_PAREN_BOTH | 泰文字母两侧括号。 |
| BULLET_THAI_NUM_PERIOD | 泰文数字句点。 |
| BULLET_THAI_NUM_PAREN_RIGHT | 泰文数字右侧括号。 |
| BULLET_THAI_NUM_PAREN_BOTH | 泰文数字两侧括号。 |
| BULLET_HINDI_ALPHA_PERIOD | 印地语字母句点 - 元音。 |
| BULLET_HINDI_NUM_PERIOD | 印地语数字句点。 |
| BULLET_KANJI_SIMP_CHIN_DB_PERIOD | 汉字简体中文双字节句点。 |
| BULLET_HINDI_NUM_PAREN_RIGHT | 印地语数字右侧括号。 |
| BULLET_HINDI_ALPHA_1_PERIOD | 印地语字母句点 - 辅音。 |
