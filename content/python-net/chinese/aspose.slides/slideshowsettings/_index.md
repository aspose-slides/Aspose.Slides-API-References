## SlideShowSettings 类

表示演示文稿的幻灯片放映设置。

SlideShowSettings 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`slide_show_type`](/slides/python-net/zh/aspose.slides/slideshowsettings/slide_show_type/) | 获取或设置幻灯片放映类型。由以下 [`SlideShowSettings.slide_show_type`](/slides/python-net/zh/aspose.slides/slideshowsettings/slide_show_type) 祖先表示：[`BrowsedAtKiosk`](/slides/python-net/zh/aspose.slides/browsedatkiosk)、[`PresentedBySpeaker`](/slides/python-net/zh/aspose.slides/presentedbyspeaker)和[`BrowsedByIndividual`](/slides/python-net/zh/aspose.slides/browsedbyindividual) |
| [`loop`](/slides/python-net/zh/aspose.slides/slideshowsettings/loop/) | 循环幻灯片放映 |
| [`show_narration`](/slides/python-net/zh/aspose.slides/slideshowsettings/show_narration/) | 在幻灯片放映中显示旁白 |
| [`show_animation`](/slides/python-net/zh/aspose.slides/slideshowsettings/show_animation/) | 在幻灯片放映中显示动画 |
| [`pen_color`](/slides/python-net/zh/aspose.slides/slideshowsettings/pen_color/) | 幻灯片放映的笔颜色 |
| [`slides`](/slides/python-net/zh/aspose.slides/slideshowsettings/slides/) | 幻灯片范围 |
| [`use_timings`](/zh/slides/python-net/aspose.slides/slideshowsettings/use_timings/) | 在幻灯片放映中使用计时 |
| [`show_media_controls`](/slides/python-net/zh/aspose.slides/slideshowsettings/show_media_controls/) | 显示媒体控制 |
