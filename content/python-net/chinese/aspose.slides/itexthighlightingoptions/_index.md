## ITextHighlightingOptions 类

表示可用于在文本框中突出显示文本的选项。

ITextHighlightingOptions 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`case_sensitive`](/slides/python-net/zh/aspose.slides/itexthighlightingoptions/case_sensitive/) | 设置为 true 以使用区分大小写的搜索，false - 否则。<br/>            读/写 **bool**. |
| [`whole_words_only`](/slides/python-net/zh/aspose.slides/itexthighlightingoptions/whole_words_only/) | 设置为 true 仅匹配整个单词，false - 否则。<br/>            读/写 **bool**. |
