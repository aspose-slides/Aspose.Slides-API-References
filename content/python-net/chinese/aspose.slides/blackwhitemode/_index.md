## BlackWhiteMode 枚举

确定有色形状应如何转换为黑白。

BlackWhiteMode 类型公开以下成员：

## 字段

| Field | Description |
| :- | :- |
| NOT_DEFINED | 属性未设置 |
| COLOR | 对象使用正常着色渲染 |
| AUTOMATIC | 对象使用自动着色渲染 |
| GRAY | 对象使用灰色着色渲染 |
| LIGHT_GRAY | 对象使用浅灰色着色渲染 |
| INVERSE_GRAY | 对象使用反向灰色着色渲染 |
| GRAY_WHITE | 对象使用灰白色着色渲染 |
| BLACK_GRAY | 对象使用黑灰色着色渲染 |
| BLACK_WHITE | 对象使用黑白色着色渲染 |
| BLACK | 对象仅使用黑色着色渲染 |
| WHITE | 对象使用白色着色渲染 |
| HIDDEN | 对象未渲染 |
