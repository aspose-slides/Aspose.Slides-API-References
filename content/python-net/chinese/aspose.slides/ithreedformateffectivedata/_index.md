## IThreeDFormatEffectiveData 类

不可变对象，表示有效的 3-D 格式属性。

IThreeDFormatEffectiveData 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`contour_width`](/slides/python-net/zh/aspose.slides/ithreedformateffectivedata/contour_width/) | 返回 3D 轮廓的宽度。<br/>            只读 **float**. |
| [`extrusion_height`](/slides/python-net/zh/aspose.slides/ithreedformateffectivedata/extrusion_height/) | 返回 拉伸效果的高度。<br/>            只读 **float**. |
| [`depth`](/slides/python-net/zh/aspose.slides/ithreedformateffectivedata/depth/) | 返回 3D 形状的深度。<br/>            只读 **float**. |
| [`bevel_top`](/slides/python-net/zh/aspose.slides/ithreedformateffectivedata/bevel_top/) | 返回 顶部 3D 倾斜的类型。<br/>            只读 [`IShapeBevelEffectiveData`](/slides/python-net/zh/aspose.slides/ishapebeveleffectivedata). |
| [`bevel_bottom`](/slides/python-net/zh/aspose.slides/ithreedformateffectivedata/bevel_bottom/) | 返回 底部 3D 倾斜的类型。<br/>            只读 [`IShapeBevelEffectiveData`](/slides/python-net/zh/aspose.slides/ishapebeveleffectivedata). |
| [`contour_color`](/slides/python-net/zh/aspose.slides/ithreedformateffectivedata/contour_color/) | 返回 轮廓的颜色。<br/>            只读 [`Color`](/slides/python-net/zh/aspose.slides/color). |
| [`extrusion_color`](/slides/python-net/zh/aspose.slides/ithreedformateffectivedata/extrusion_color/) | 返回 拉伸的颜色。<br/>            只读 [`Color`](/slides/python-net/zh/aspose.slides/color). |
| [`camera`](/slides/python-net/zh/aspose.slides/ithreedformateffectivedata/camera/) | 返回 相机的设置。<br/>            只读 [`ICameraEffectiveData`](/slides/python-net/zh/aspose.slides/icameraeffectivedata). |
| [`light_rig`](/slides/python-net/zh/aspose.slides/ithreedformateffectivedata/light_rig/) | 返回 光源的类型。<br/>            只读 [`ILightRigEffectiveData`](/slides/python-net/zh/aspose.slides/ilightrigeffectivedata). |
| [`material`](/slides/python-net/zh/aspose.slides/ithreedformateffectivedata/material/) | 返回 材料的类型。<br/>            只读 [`MaterialPresetType`](/slides/python-net/zh/aspose.slides/materialpresettype). |

### 备注

此接口与 [`IThreeDFormat`](/slides/python-net/zh/aspose.slides/ithreedformat) 接口一起使用，以返回已应用继承的有效格式化值。
