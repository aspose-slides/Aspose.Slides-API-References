## CustomXmlPart 类

表示自定义 XML 部分。

CustomXmlPart 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`xml_data`](/slides/python-net/zh/aspose.slides/customxmlpart/xml_data/) | 返回或设置 xml 数据。<br/>            读/写 **int**[].<br/>            值为 `None`。值为空或 xml 数据无效。 |
| [`xml_as_string`](/slides/python-net/zh/aspose.slides/customxmlpart/xml_as_string/) | 返回或设置 xml 数据为 UTF-8 字符串。<br/>            读/写 **str**。<br/>            值为 `None`。值为空或 xml 数据无效。 |
| [`item_id`](/slides/python-net/zh/aspose.slides/customxmlpart/item_id/) | 指定全局唯一标识符 (GUID)，该标识符唯一标识 Office Open XML 文档中的单个自定义 XML <br/>            部分。<br/>            只读 **System.Guid**。 |
| [`namespace_schemas`](/slides/python-net/zh/aspose.slides/customxmlpart/namespace_schemas/) | 返回与自定义 XML 部分关联的 XML 架构集合。<br/>            只读 **str**[]. |
