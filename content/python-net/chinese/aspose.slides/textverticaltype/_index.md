## TextVerticalType 枚举

确定文本的垂直书写模式。

TextVerticalType 类型公开以下成员：

## 字段

| Field | Description |
| :- | :- |
| NOT_DEFINED | 未定义。 |
| HORIZONTAL | 水平文本。 |
| VERTICAL | 垂直文本。 |
| VERTICAL270 | 垂直 270 度文本。 |
| WORD_ART_VERTICAL | WordArt 垂直文本。 |
| EAST_ASIAN_VERTICAL | 东亚垂直文本。 |
| MONGOLIAN_VERTICAL | 蒙古垂直文本。 |
| WORD_ART_VERTICAL_RIGHT_TO_LEFT | WordArt 垂直从右到左文本。 |
