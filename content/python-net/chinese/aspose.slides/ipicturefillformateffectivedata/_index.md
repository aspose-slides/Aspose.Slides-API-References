## IPictureFillFormatEffectiveData 类

不可变对象，包含图片填充的属性。

| 属性 | 描述 |

| [`dpi`](/slides/python-net/zh/aspose.slides/ipicturefillformateffectivedata/dpi/) | 返回用于填充图片的 dpi。<br/>            只读 **int**。 |
| [`picture_fill_mode`](/slides/python-net/zh/aspose.slides/ipicturefillformateffectivedata/picture_fill_mode/) | 返回图片填充模式。<br/>            只读 [`PictureFillMode`](/slides/python-net/zh/aspose.slides/picturefillmode)。 |
