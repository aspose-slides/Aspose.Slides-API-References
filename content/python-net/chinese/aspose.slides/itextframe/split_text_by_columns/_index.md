## split_text_by_columns(self) {#}
将 [`ITextFrame`](/slides/python-net/zh/aspose.slides/itextframe) 的文本内容拆分为字符串数组，  
            每个元素对应框架内的单独文本列。

### 返回值

字符串数组，其中每个字符串表示 [`ITextFrame`](/slides/python-net/zh/aspose.slides/itextframe) 中特定列的文本内容。

```python
def split_text_by_columns(self):
    ...
```

### 备注

如果文本框不包含多个列，则返回的数组将只有一个元素，包含完整文本。  
            空列将在数组中表示为空字符串。
