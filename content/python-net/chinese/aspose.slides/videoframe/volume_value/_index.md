## volume_value 属性
返回或设置精确的视频音量，以百分比表示。
             该值以 0 到 100 的百分比表示。使用此属性
             读取或设置比预定义的更精确的音量值
             通过 [`VideoFrame.volume`](/slides/python-net/zh/aspose.slides/videoframe/volume) 属性可用的级别。
             读取/写入 **float**.
