## AdjustValue 类

表示几何形状的调整值。  
这些值会影响形状的形式。

AdjustValue 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`raw_value`](/slides/python-net/zh/aspose.slides/adjustvalue/raw_value/) | 返回或设置“原样”的调整值。<br/>            读写 **int**。 |
| [`angle_value`](/slides/python-net/zh/aspose.slides/adjustvalue/angle_value/) | 返回或设置值，将其解释为角度（度）。<br/>            读写 **float**。 |
| [`name`](/slides/python-net/zh/aspose.slides/adjustvalue/name/) | 返回此调整值的名称。<br/>            只读 **str**。 |
| [`type`](/slides/python-net/zh/aspose.slides/adjustvalue/type/) | 返回形状调整的类型。<br/>            只读 [`ShapeAdjustmentType`](/slides/python-net/zh/aspose.slides/shapeadjustmenttype)。 |
