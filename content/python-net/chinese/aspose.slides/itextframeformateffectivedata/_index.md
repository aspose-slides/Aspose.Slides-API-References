## ITextFrameFormatEffectiveData 类

不可变对象，包含有效文本框的格式属性。

ITextFrameFormatEffectiveData 类型公开以下成员：

## 属性

| Property | Description |
| :- | :- |
| [`text_style`](/slides/python-net/zh/aspose.slides/itextframeformateffectivedata/text_style/) | 返回有效文本的样式。<br/>            只读 [`ITextStyleEffectiveData`](/slides/python-net/zh/aspose.slides/itextstyleeffectivedata). |
| [`margin_left`](/slides/python-net/zh/aspose.slides/itextframeformateffectivedata/margin_left/) | 返回 TextFrame 中的左边距（点）。<br/>            只读 **float**. |
| [`margin_right`](/slides/python-net/zh/aspose.slides/itextframeformateffectivedata/margin_right/) | 返回 TextFrame 中的右边距（点）。<br/>            只读 **float**. |
| [`margin_top`](/slides/python-net/zh/aspose.slides/itextframeformateffectivedata/margin_top/) | 返回 TextFrame 中的上边距（点）。<br/>            只读 **float**. |
| [`margin_bottom`](/slides/python-net/zh/aspose.slides/itextframeformateffectivedata/margin_bottom/) | 返回 TextFrame 中的下边距（点）。<br/>            只读 **float**. |
| [`wrap_text`](/slides/python-net/zh/aspose.slides/itextframeformateffectivedata/wrap_text/) | 返回文本是否在 TextFrame 的边距换行。<br/>            只读 **bool**. |
| [`anchoring_type`](/slides/python-net/zh/aspose.slides/itextframeformateffectivedata/anchoring_type/) | 返回 TextFrame 中的垂直锚点文本。<br/>            只读 [`TextAnchorType`](/slides/python-net/zh/aspose.slides/textanchortype). |
| [`center_text`](/slides/python-net/zh/aspose.slides/itextframeformateffectivedata/center_text/) | 返回文本是否应水平居中于框中。<br/>            只读 **bool**. |
| [`text_vertical_type`](/slides/python-net/zh/aspose.slides/itextframeformateffectivedata/text_vertical_type/) | 返回文本方向。<br/>            只读 [`TextVerticalType`](/slides/python-net/zh/aspose.slides/textverticaltype). |
| [`autofit_type`](/slides/python-net/zh/aspose.slides/itextframeformateffectivedata/autofit_type/) | 返回文本自动适配模式。<br/>            只读 [`TextAutofitType`](/slides/python-net/zh/aspose.slides/textautofittype). |
| [`column_count`](/slides/python-net/zh/aspose.slides/itextframeformateffectivedata/column_count/) | 指定边界矩形中文本的列数。<br/>            只读 **int**. |
| [`column_spacing`](/slides/python-net/zh/aspose.slides/itextframeformateffectivedata/column_spacing/) | 指定文本区域中文本列之间的间距（点）。<br/>            只读 **float**. |

### 备注

此接口与 [`ITextFrameFormat`](/slides/python-net/zh/aspose.slides/itextframeformat) 接口一起使用，以返回应用继承后的有效格式值。
