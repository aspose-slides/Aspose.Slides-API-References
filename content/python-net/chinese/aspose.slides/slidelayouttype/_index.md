## SlideLayoutType 枚举

表示幻灯片布局类型。

SlideLayoutType 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| CUSTOM | 自定义 |
| TITLE | 标题 |
| TEXT | 文本 |
| TWO_COLUMN_TEXT | 两列文本 |
| TABLE | 表格 |
| TEXT_AND_CHART | 文本和图表 |
| CHART_AND_TEXT | 图表和文本 |
| DIAGRAM | 图形 |
| CHART | 图表 |
| TEXT_AND_CLIP_ART | 文本和剪贴画 |
| CLIP_ART_AND_TEXT | 剪贴画和文本 |
| TITLE_ONLY | 仅标题 |
| BLANK | 空白 |
| TEXT_AND_OBJECT | 文本和对象 |
| OBJECT_AND_TEXT | 对象和文本 |
| OBJECT | 对象 |
| TITLE_AND_OBJECT | 标题和对象 |
| TEXT_AND_MEDIA | 文本和媒体 |
| MEDIA_AND_TEXT | 媒体和文本 |
| OBJECT_OVER_TEXT | 对象在文本上 |
| TEXT_OVER_OBJECT | 文本在对象上 |
| TEXT_AND_TWO_OBJECTS | 文本和两个对象 |
| TWO_OBJECTS_AND_TEXT | 两个对象和文本 |
| TWO_OBJECTS_OVER_TEXT | 两个对象在文本上 |
| FOUR_OBJECTS | 四个对象 |
| VERTICAL_TEXT | 垂直文本 |
| CLIP_ART_AND_VERTICAL_TEXT | 剪贴画和垂直文本 |
| VERTICAL_TITLE_AND_TEXT | 垂直标题和文本 |
| VERTICAL_TITLE_AND_TEXT_OVER_CHART | 垂直标题和文本在图表上 |
| TWO_OBJECTS | 两个对象 |
| OBJECT_AND_TWO_OBJECT | 对象和两个对象 |
| TWO_OBJECTS_AND_OBJECT | 两个对象和对象 |
| SECTION_HEADER | 章节标题 |
| TWO_TEXT_AND_TWO_OBJECTS | 两个文本和两个对象 |
| TITLE_OBJECT_AND_CAPTION | 标题、对象和说明 |
| PICTURE_AND_CAPTION | 图片和说明 |
