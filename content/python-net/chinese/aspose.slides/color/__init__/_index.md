## __init__(self, r=0, g=0, b=0, a=255) {#int-int-int-int}
从指定的红色、绿色、蓝色和 Alpha 组件值创建颜色。


```python
def __init__(self, r=0, g=0, b=0, a=255):
    ...
```


| 参数 | 类型 | 描述 |
| :- | :- | :- |
| r | **int** | 红色组件值。有效值范围为 0 到 255。 |
| g | **int** | 绿色组件值。有效值范围为 0 到 255。 |
| b | **int** | 蓝色组件值。有效值范围为 0 到 255。 |
| a | **int** | Alpha 组件值。有效值范围为 0 到 255。 |

### 异常

| 异常 | 描述 |
| :- | :- |
| **ValueError** | 组件值小于 0 或大于 255。 |
| **TypeError** | 组件值不是数字。 |
