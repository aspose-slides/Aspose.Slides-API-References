## is_system_color 属性
指定此颜色是否为系统颜色：系统颜色是用于 Windows 显示元素的颜色，例如 `Control` 或 `ActiveBorder`。<br/>            系统颜色未以 `Color` 属性的形式公开，只能通过 [`from_known_color`](/slides/python-net/zh/aspose.slides/color/from_known_color/) 获取或从库中返回。            只读 **bool**。
