## Size 类

存储一对整数，指定宽度和高度。兼容 .NET `System.Drawing.Size`。

Size 类型公开以下成员：

## 构造函数

| 构造函数 | 描述 |
| :- | :- |
| [`__init__(self, width=0, height=0)`](/slides/python-net/zh/aspose.slides/size/__init__/#int-int) | 创建具有指定宽度和高度的尺寸。浮点值会被截断为整数。 |

## 属性

| 属性 | 描述 |
| :- | :- |
| [`width`](/slides/python-net/zh/aspose.slides/size/width/) | 获取此尺寸的水平分量。<br/>            只读 **int**. |
| [`height`](/slides/python-net/zh/aspose.slides/size/height/) | 获取此尺寸的垂直分量。<br/>            只读 **int**. |


### 备注

尺寸通过 `==` 比较其分量，可用作字典键或集合成员。
