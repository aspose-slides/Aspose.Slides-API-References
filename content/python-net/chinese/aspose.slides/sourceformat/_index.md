## SourceFormat 枚举

表示源文件格式。

SourceFormat 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| PPT | Microsoft PowerPoint 97-2003 演示文稿 (*.ppt)。 |
| PPTX | Microsoft Office Open XML 演示文稿 (*.pptx)。 |
| ODP | OpenDocument 演示文稿 (*.odp)。 |
| PPTM | Microsoft Office Open XML 宏启用的演示文稿 (*.pptm)。 |
| PPSX | Microsoft Office Open XML 幻灯片放映 (*.ppsx)。 |
| PPSM | Microsoft Office Open XML 宏启用的幻灯片放映 (*.ppsm)。 |
| POTX | Microsoft Office Open XML 模板 (*.potx)。 |
| POTM | Microsoft Office Open XML 宏启用的模板 (*.potm)。 |
| PPS | Microsoft PowerPoint 97-2003 幻灯片放映 (*.pps)。 |
| POT | Microsoft PowerPoint 97-2003 模板 (*.pot)。 |
| OTP | OpenDocument 演示文稿模板 (*.otp)。 |
| FODP | Flat XML ODF 演示文稿 (*.fodp)。 |
| XML | PowerPoint XML 演示文稿 (*.xml)。 |
