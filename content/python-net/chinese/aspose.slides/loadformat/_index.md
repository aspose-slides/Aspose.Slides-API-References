## LoadFormat 枚举

指示要加载的文档的格式。

LoadFormat 类型公开以下成员：

## 字段

| Field | Description |
| :- | :- |
| AUTO | 指示 Aspose.Slides 自动识别格式。 |
| PPT | Microsoft PowerPoint 97-2003 演示文稿。 |
| PPS | Microsoft PowerPoint 97-2003 幻灯片放映。 |
| PPTX | Microsoft Office Open XML PresentationML 文档。 |
| PPSX | Microsoft Office Open XML PresentationML 幻灯片放映。 |
| ODP | OpenOffice ODF 演示文稿。 |
| POTX | Microsoft Office Open XML PresentationML 模板。 |
| PPTM | Microsoft Office Open XML PresentationML 含宏文档。 |
| PPSM | Microsoft Office Open XML PresentationML 含宏幻灯片放映。 |
| POTM | Microsoft Office Open XML PresentationML 含宏模板。 |
| OTP | OpenOffice OTP 演示文稿模板。 |
| PPT95 | Microsoft PowerPoint 95 演示文稿。 |
| POT | Microsoft PowerPoint 97-2003 演示文稿模板。 |
| FODP | Flat XML ODF 演示文稿。 |
| UNKNOWN | 未知文件格式 |
