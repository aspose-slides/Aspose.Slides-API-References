## Point 类

表示在二维平面上定义点的整数 x 和 y 坐标的有序对。兼容 .NET `System.Drawing.Point`。

Point 类型公开以下成员：

| 构造函数 | 描述 |
| :- | :- |
| [`__init__(self, x=0, y=0)`](/slides/python-net/zh/aspose.slides/point/__init__/#int-int) | 使用指定的坐标创建一个点。浮点值会被截断为整数。 |

## 属性

| 属性 | 描述 |
| :- | :- |
| [`x`](/slides/python-net/zh/aspose.slides/point/x/) | 获取或设置此点的 x 坐标。<br/>            读/写 **int**。 |
| [`y`](/slides/python-net/zh/aspose.slides/point/y/) | 获取或设置此点的 y 坐标。<br/>            读/写 **int**。 |
