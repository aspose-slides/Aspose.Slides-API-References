## PictureFrameLock 类

确定在父 PictureFrame 上禁用哪些操作。

**继承:**[`PictureFrameLock`](/slides/python-net/zh/aspose.slides/pictureframelock) → [`BaseShapeLock`](/slides/python-net/zh/aspose.slides/baseshapelock)

| 属性 | 描述 |
| :- | :- |
| [`no_locks`](/slides/python-net/zh/aspose.slides/pictureframelock/no_locks/) | 如果所有锁标志都已禁用，则返回 true。<br/>            只读 **bool**。 |
| [`grouping_locked`](/slides/python-net/zh/aspose.slides/pictureframelock/grouping_locked/) | 确定是否禁止将此形状添加到组中。<br/>            读写 **bool**。 |
