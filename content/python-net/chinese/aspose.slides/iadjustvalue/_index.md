## IAdjustValue 类

表示几何形状的调整值。  
这些值会影响形状的形式。

IAdjustValue 类型提供以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`raw_value`](/slides/python-net/zh/aspose.slides/iadjustvalue/raw_value/) | 返回或设置调整值“原样”。<br/>只读/可写 **int**. |
| [`angle_value`](/slides/python-net/zh/aspose.slides/iadjustvalue/angle_value/) | 返回或设置值，按角度（度）解释。<br/>只读/可写 **float**. |
| [`name`](/slides/python-net/zh/aspose.slides/iadjustvalue/name/) | 返回此调整值的名称。<br/>只读 **str**. |
| [`type`](/slides/python-net/zh/aspose.slides/iadjustvalue/type/) | 返回形状调整的类型。<br/>只读 [`ShapeAdjustmentType`](/slides/python-net/zh/aspose.slides/shapeadjustmenttype). |
