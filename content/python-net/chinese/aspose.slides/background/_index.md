## Background 类

表示幻灯片的背景。

**继承:**[`Background`](/slides/python-net/zh/aspose.slides/background) → [`PVIObject`](/slides/python-net/zh/aspose.slides/pviobject)

Background 类型公开以下成员：

## 属性

| Property | Description |
| :- | :- |
| [`type`](/slides/python-net/zh/aspose.slides/background/type/) | 返回背景填充的类型。<br/>            可读写 [`BackgroundType`](/slides/python-net/zh/aspose.slides/backgroundtype)。 |
| [`fill_format`](/slides/python-net/zh/aspose.slides/background/fill_format/) | 返回 BackgroundType.OwnBackground 填充的 FillFormat。<br/>            只读 [`IFillFormat`](/slides/python-net/zh/aspose.slides/ifillformat)。 |
| [`effect_format`](/slides/python-net/zh/aspose.slides/background/effect_format/) | 返回 BackgroundType.OwnBackground 填充的 EffectFormat。<br/>            只读 [`IEffectFormat`](/slides/python-net/zh/aspose.slides/ieffectformat)。 |
| [`style_color`](/slides/python-net/zh/aspose.slides/background/style_color/) | 返回 BackgroundType.Themed 填充的 ColorFormat。<br/>            只读 [`IColorFormat`](/slides/python-net/zh/aspose.slides/icolorformat)。 |
| [`style_index`](/slides/python-net/zh/aspose.slides/background/style_index/) | 返回背景主题集合中 BackgroundType.Themed 填充的索引。<br/>            0 表示无填充。<br/>            1..999 - 索引。<br/>            可读写 **int**。 |
| [`slide`](/slides/python-net/zh/aspose.slides/background/slide/) | 返回形状的父幻灯片。<br/>            只读 [`IBaseSlide`](/slides/python-net/zh/aspose.slides/ibaseslide)。 |
| [`presentation`](/slides/python-net/zh/aspose.slides/background/presentation/) | 返回幻灯片的父演示文稿。<br/>            只读 [`IPresentation`](/slides/python-net/zh/aspose.slides/ipresentation)。 |
