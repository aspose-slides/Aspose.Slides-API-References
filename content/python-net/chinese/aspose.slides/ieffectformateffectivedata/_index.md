## IEffectFormatEffectiveData 类

不可变对象，包含有效的效果格式属性。

IEffectFormatEffectiveData 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`is_no_effects`](/slides/python-net/zh/aspose.slides/ieffectformateffectivedata/is_no_effects/) | 如果所有效果已禁用（刚创建时，默认 EffectFormat 对象），返回 true。<br/>            只读 **bool**. |
| [`blur_effect`](/slides/python-net/zh/aspose.slides/ieffectformateffectivedata/blur_effect/) | 模糊效果。<br/>            只读 [`IBlurEffectiveData`](/slides/python-net/zh/aspose.slides.effects/iblureffectivedata). |
| [`fill_overlay_effect`](/slides/python-net/zh/aspose.slides/ieffectformateffectivedata/fill_overlay_effect/) | 填充覆盖效果。<br/>            只读 [`IFillOverlayEffectiveData`](/slides/python-net/zh/aspose.slides.effects/ifilloverlayeffectivedata). |
| [`glow_effect`](/slides/python-net/zh/aspose.slides/ieffectformateffectivedata/glow_effect/) | 发光效果。<br/>            只读 [`IGlowEffectiveData`](/slides/python-net/zh/aspose.slides.effects/igloweffectivedata). |
| [`inner_shadow_effect`](/slides/python-net/zh/aspose.slides/ieffectformateffectivedata/inner_shadow_effect/) | 内阴影。<br/>            只读 [`IInnerShadowEffectiveData`](/slides/python-net/zh/aspose.slides.effects/iinnershadoweffectivedata). |
| [`outer_shadow_effect`](/slides/python-net/zh/aspose.slides/ieffectformateffectivedata/outer_shadow_effect/) | 外阴影。<br/>            只读 [`IOuterShadowEffectiveData`](/slides/python-net/zh/aspose.slides.effects/ioutershadoweffectivedata). |
| [`preset_shadow_effect`](/slides/python-net/zh/aspose.slides/ieffectformateffectivedata/preset_shadow_effect/) | 预设阴影。<br/>            只读 [`IPresetShadowEffectiveData`](/slides/python-net/zh/aspose.slides.effects/ipresetshadoweffectivedata). |
| [`reflection_effect`](/slides/python-net/zh/aspose.slides/ieffectformateffectivedata/reflection_effect/) | 反射。 <br/>            只读 [`IReflectionEffectiveData`](/slides/python-net/zh/aspose.slides.effects/ireflectioneffectivedata). |
| [`soft_edge_effect`](/slides/python-net/zh/aspose.slides/ieffectformateffectivedata/soft_edge_effect/) | 柔和边缘。<br/>            只读 [`ISoftEdgeEffectiveData`](/slides/python-net/zh/aspose.slides.effects/isoftedgeeffectivedata). |

### 备注

此接口与 [`IEffectFormat`](/slides/python-net/zh/aspose.slides/ieffectformat) 接口一起使用，以返回应用继承后的有效格式值。
