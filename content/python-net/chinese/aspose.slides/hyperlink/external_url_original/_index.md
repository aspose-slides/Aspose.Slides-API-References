## external_url_original 属性
Represents a hyperlink that is set for this portion without regard to the actual content of the portion.

            PowerPoint 对片段中的链接及其对应的文本有特殊的处理方式。它允许以有效的 URL 形式为超链接创建文本
            与链接的真实地址不同。在这种情况下，当您在编辑窗口中查看链接时，它将被更改为匹配文本片段。
            此属性表示超链接的原始值。
