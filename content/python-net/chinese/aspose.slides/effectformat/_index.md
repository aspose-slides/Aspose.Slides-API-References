## EffectFormat 类

表示形状的效果属性。

## 属性

| 属性 | 描述 |
| :- | :- |
| [`is_no_effects`](/slides/python-net/zh/aspose.slides/effectformat/is_no_effects/) | 如果所有效果均已禁用，则返回 true（如刚创建的默认 EffectFormat 对象）。<br/>            只读 **bool**. |
| [`blur_effect`](/slides/python-net/zh/aspose.slides/effectformat/blur_effect/) | 模糊效果。<br/>            读取/写入 [`IBlur`](/slides/python-net/zh/aspose.slides.effects/iblur). |

| [`glow_effect`](/slides/python-net/zh/aspose.slides/effectformat/glow_effect/) | 辉光效果。<br/>            读取/写入 [`IGlow`](/slides/python-net/zh/aspose.slides.effects/iglow). |
| [`inner_shadow_effect`](/slides/python-net/zh/aspose.slides/effectformat/inner_shadow_effect/) | 内部阴影。<br/>            读取/写入 [`IInnerShadow`](/slides/python-net/zh/aspose.slides.effects/iinnershadow). |
| [`outer_shadow_effect`](/slides/python-net/zh/aspose.slides/effectformat/outer_shadow_effect/) | 外部阴影。<br/>            读取/写入 [`IOuterShadow`](/slides/python-net/zh/aspose.slides.effects/ioutershadow). |
| [`preset_shadow_effect`](/slides/python-net/zh/aspose.slides/effectformat/preset_shadow_effect/) | 预设阴影。<br/>            读取/写入 [`IPresetShadow`](/slides/python-net/zh/aspose.slides.effects/ipresetshadow). |
| [`reflection_effect`](/slides/python-net/zh/aspose.slides/effectformat/reflection_effect/) | 反射。<br/>            读取/写入 [`IReflection`](/slides/python-net/zh/aspose.slides.effects/ireflection). |
| [`soft_edge_effect`](/slides/python-net/zh/aspose.slides/effectformat/soft_edge_effect/) | 柔和边缘。<br/>            读取/写入 [`ISoftEdge`](/slides/python-net/zh/aspose.slides.effects/isoftedge). |
