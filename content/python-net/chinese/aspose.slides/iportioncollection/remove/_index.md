## remove(self, item) {#iportion}
从 **System.Collections.Generic.ICollection`1** 中移除特定对象的首次出现。

### 返回

如果成功从 **System.Collections.Generic.ICollection`1** 中移除 `item`，则返回 true；否则返回 false。如果在原始 **System.Collections.Generic.ICollection`1** 中未找到 `item`，该方法也会返回 false。



```python
def remove(self, item):
    ...
```

| :- | :- | :- |
| item | [`IPortion`](/slides/python-net/zh/aspose.slides/iportion) | 要从 **System.Collections.Generic.ICollection`1** 中移除的对象。 |
