## ShapeAdjustmentType 枚举

指定形状调整值的不同类型。

ShapeAdjustmentType 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| CUSTOM | 自定义类型（未知调整） |
| CORNER_SIZE | 控制角的大小。 |
| LEFT_UP_CORNER | 控制左上角。 |
| RIGHT_UP_CORNER | 控制右上角。 |
| UP_CORNERS | 控制上部角。 |
| DOWN_CORNERS | 控制下角。 |
| THICKNESS | 控制图形的粗细。 |
| ARROW_TAIL_THICKNESS | 控制箭尾的粗细。 |
| ARROWHEAD_LENGTH | 控制箭头的长度。 |
| ARROWHEAD_WIDTH | 控制箭头的宽度。 |
| RADIUS | 控制形状或其部件的半径大小。 |
| DEPTH | 控制齿轮齿的深度或斜角效果。 |
| SHAPE_PART_OFFSET | 控制图形一部分相对于另一部分的偏移。 |
| ANGLE | 控制图形或其部件的角度。 |
| START_ANGLE | 饼图和弧形的起始角度。 |
| END_ANGLE | 饼图和弧形的结束角度。 |
| START_POINT_X | 控制标注起始点的 X 位置。 |
| START_POINT_Y | 控制标注起始点的 Y 位置。 |
| CONNECTOR_POINT_1X | 控制标注角度调整点的水平位置。 |
| CONNECTOR_POINT_1Y | 控制标注角度调整点的垂直位置。 |
| CONNECTOR_POINT_2X | 控制标注角度调整点的水平位置。 |
| CONNECTOR_POINT_2Y | 控制标注角度调整点的垂直位置。 |
| CONNECTOR_BEND_POSITION_X | 控制连接器弯曲处的水平位置。 |
| CONNECTOR_BEND_POSITION_Y | 控制连接器弯曲处的垂直位置。 |
| ATTACH_Y | 控制图形的垂直附着点。 |
| ATTACH_X | 控制图形的水平附着点。 |
| CALLOUT_HEIGHT | 控制标注的垂直大小。 |
| CALLOUT_WIDTH | 控制标注的水平大小。 |
| CALLOUT_SIZE | 控制标注的大小。 |
| CURVATURE | 弯曲、支架、弧形箭头或形状的曲率。 |
| HORIZONTAL_THICKNESS | 控制角形的水平厚度。 |
| VERTICAL_THICKNESS | 控制角形的垂直厚度。 |
| VERTICAL_SIZE | 控制形状的垂直大小。 |
| HORIZONTAL_SIZE | 控制形状的水平大小。 |
| TOP | 控制形状的顶部。 |
