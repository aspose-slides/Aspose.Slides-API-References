## INormalViewRestoredProperties 类

指定普通视图中幻灯片区域的尺寸（当为 restoredTop 的子项时为宽度，当为 restoredLeft 的子项时为高度），当区域大小为可变的恢复大小（既不最小化也不最大化）时。

INormalViewRestoredProperties 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`dimension_size`](/slides/python-net/zh/aspose.slides/inormalviewrestoredproperties/dimension_size/) | 指定幻灯片区域的大小（当为 RestoredTop 的子项时为宽度，当为 RestoredLeft 的子项时为高度）。<br/>            读/写 **float**。<br/>            当值小于 0 或大于 100 时抛出异常。 |
| [`auto_adjust`](/slides/python-net/zh/aspose.slides/inormalviewrestoredproperties/auto_adjust/) | 指定在调整包含视图的窗口大小时，是否应让侧边内容区域的大小补偿新的尺寸。<br/>            读/写 **bool**。 |
