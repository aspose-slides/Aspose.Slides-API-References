## ITextSearchOptions 类

表示可用于在 Presentation、Slide 或 TextFrame 中搜索文本的选项。

ITextSearchOptions 类型公开以下成员：

## 属性

| Property | Description |
| :- | :- |
| [`case_sensitive`](/slides/python-net/zh/aspose.slides/itextsearchoptions/case_sensitive/) | 将 true 设置为使用区分大小写的搜索，false 为否则。<br/>            可读写 **bool**. |
| [`whole_words_only`](/slides/python-net/zh/aspose.slides/itextsearchoptions/whole_words_only/) | 将 true 设置为仅匹配完整单词，false 为否则。<br/>            可读写 **bool**. |
| [`include_notes`](/slides/python-net/zh/aspose.slides/itextsearchoptions/include_notes/) | 将 `true` 设置为在执行文本搜索、替换或高亮操作时包含幻灯片备注中的文本。<br/>            默认值为 `false`. |
