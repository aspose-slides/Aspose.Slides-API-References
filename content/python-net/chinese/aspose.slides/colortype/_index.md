## ColorType 枚举

表示不同的颜色模式。

ColorType 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| NOT_DEFINED | 颜色根本未定义。 |
| RGB | 标准 24 位 RGB 颜色。 |
| RGB_PERCENTAGE | 高精度 RGB 颜色。 |
| HSL | 高精度 HSL 颜色。 |
| SCHEME | 方案颜色。 |
| SYSTEM | 系统颜色。 |
| PRESET | 预设颜色。 |
