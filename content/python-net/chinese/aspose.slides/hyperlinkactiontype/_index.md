## HyperlinkActionType 枚举

表示超链接操作的类型。

HyperlinkActionType 类型公开以下成员：

## 字段

| Field | Description |
| :- | :- |
| UNKNOWN | 未识别的操作类型。 |
| NO_ACTION | 无操作。 |
| HYPERLINK | 普通超链接。 |
| JUMP_FIRST_SLIDE | 跳转到演示文稿的第一张幻灯片。 |
| JUMP_PREVIOUS_SLIDE | 跳转到上一张幻灯片。 |
| JUMP_NEXT_SLIDE | 跳转到下一张幻灯片。 |
| JUMP_LAST_SLIDE | 跳转到演示文稿的最后一张幻灯片。 |
| JUMP_END_SHOW | 跳转到幻灯片放映的结尾。 |
| JUMP_LAST_VIEWED_SLIDE | 跳转到上一次查看的幻灯片。 |
| JUMP_SPECIFIC_SLIDE | 跳转到特定幻灯片，由 [`IHyperlink.target_slide`](/slides/python-net/zh/aspose.slides/ihyperlink/target_slide) 属性引用。 |
| START_CUSTOM_SLIDE_SHOW | 开始自定义幻灯片放映。 |
| OPEN_FILE | 打开引用的文件。 |
| OPEN_PRESENTATION | 打开引用的演示文稿。 |
| START_STOP_MEDIA | 启动/停止播放媒体文件。 |
| START_MACRO | 开始执行宏脚本。 |
| START_PROGRAM | 启动程序。 |
