## CommonSlideViewProperties 类

表示通用幻灯片视图属性。

CommonSlideViewProperties 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`scale`](/slides/python-net/zh/aspose.slides/commonslideviewproperties/scale/) | 指定视图缩放比例（百分比）。<br/>            可读写 **int**. |
| [`variable_scale`](/slides/python-net/zh/aspose.slides/commonslideviewproperties/variable_scale/) | 指定视图内容应自动缩放以最佳适应当前窗口大小。<br/>            可读写 **bool**. |
| [`drawing_guides`](/slides/python-net/zh/aspose.slides/commonslideviewproperties/drawing_guides/) | 返回绘图指南的集合。<br/>            只读 [`IDrawingGuidesCollection`](/slides/python-net/zh/aspose.slides/idrawingguidescollection) |
