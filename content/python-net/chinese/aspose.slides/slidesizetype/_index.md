## SlideSizeType 枚举

表示幻灯片尺寸预设。

SlideSizeType 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| ON_SCREEN | 屏幕 4x3 |
| LETTER_PAPER | 信纸 |
| A4_PAPER | A4 |
| SLIDE_35MM | 幻灯片 35mm |
| OVERHEAD | 投影 |
| BANNER | 横幅 |
| CUSTOM | 自定义大小 |
| LEDGER | Ledger |
| A3_PAPER | A3 |
| B4_ISO_PAPER | B4 ISO |
| B5_ISO_PAPER | B5 ISO |
| B4_JIS_PAPER | B4 JIS |
| B5_JIS_PAPER | B5 JIS |
| HAGAKI_CARD | 明信片 |
| ON_SCREEN_16X9 | 屏幕 16x9 |
| ON_SCREEN_16X10 | 屏幕 16x10 |
| WIDESCREEN | 宽屏 |
