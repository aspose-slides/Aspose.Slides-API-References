## 属性

| Property | Description |
| :- | :- |
| [`name`](/slides/python-net/zh/aspose.slides/icontrol/name/) | 返回此控件的名称。<br/>            读/写 **str**. |
| [`class_id`](/slides/python-net/zh/aspose.slides/icontrol/class_id/) | 获取此控件的类 ID。<br/>            只读 **System.Guid**. |
