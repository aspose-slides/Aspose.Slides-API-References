## IPictureEffectiveData 类

不可变对象，包含有效图片属性。

IPictureEffectiveData 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`image`](/slides/python-net/zh/aspose.slides/ipictureeffectivedata/image/) | 返回嵌入的图像。<br/>            只读 [`IPPImage`](/slides/python-net/zh/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/zh/aspose.slides/ipictureeffectivedata/link_path_long/) | 返回链接图像的 URL。<br/>            只读 **str**. |
| [`image_transform`](/slides/python-net/zh/aspose.slides/ipictureeffectivedata/image_transform/) | 返回图像变换效果的集合。<br/>            只读 [`IImageTransformOCollectionEffectiveData`](/slides/python-net/zh/aspose.slides.effects/iimagetransformocollectioneffectivedata). |


### 备注

此接口用作 [`IPictureFillFormatEffectiveData`](/slides/python-net/zh/aspose.slides/ipicturefillformateffectivedata) 和 [`IBulletFormatEffectiveData`](/slides/python-net/zh/aspose.slides/ibulletformateffectivedata)。
