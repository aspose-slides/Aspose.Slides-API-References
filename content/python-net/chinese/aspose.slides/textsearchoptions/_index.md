## TextSearchOptions 类

表示可用于在 Presentation、Slide 或 TextFrame 中搜索文本的选项。

TextSearchOptions 类型公开以下成员：

## 构造函数

| Constructor | Description |
| :- | :- |
| [`__init__(self)`](/slides/python-net/zh/aspose.slides/textsearchoptions/__init__/#) | 创建新的默认文本搜索选项。 |

## 属性

| Property | Description |
| :- | :- |
| [`case_sensitive`](/slides/python-net/zh/aspose.slides/textsearchoptions/case_sensitive/) | 设为 true 以使用区分大小写的搜索，设为 false 则不区分大小写。<br/>            读/写 **bool**. |
| [`whole_words_only`](/slides/python-net/zh/aspose.slides/textsearchoptions/whole_words_only/) | 设为 true 以仅匹配完整单词，设为 false 则不匹配。<br/>            读/写 **bool**. |
| [`include_notes`](/slides/python-net/zh/aspose.slides/textsearchoptions/include_notes/) | 将 `true` 设置为在执行文本搜索、替换或高亮操作时包含幻灯片备注中的文本 ([`NotesSlide`](/slides/python-net/zh/aspose.slides/notesslide)) <br/>            默认值为 `false`. |
