## ITabEffectiveData 类

不可变对象，包含有效文本的制表符停止属性。

ITabEffectiveData 类型公开以下成员：

## 属性

| Property | Description |
| :- | :- |
| [`position`](/slides/python-net/zh/aspose.slides/itabeffectivedata/position/) | 返回制表符的位置。<br/>            为此属性赋值可以更改集合中制表符的索引并使 Enumerator 失效。<br/>            只读 **float**. |
| [`alignment`](/slides/python-net/zh/aspose.slides/itabeffectivedata/alignment/) | 返回制表符的对齐样式。<br/>            只读 [`TabAlignment`](/slides/python-net/zh/aspose.slides/tabalignment). |


### 备注

此接口用作 [`IParagraphFormatEffectiveData`](/slides/python-net/zh/aspose.slides/iparagraphformateffectivedata) 的一部分。
