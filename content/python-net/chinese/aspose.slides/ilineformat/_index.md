## ILineFormat 类

表示线的格式。

ILineFormat 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`is_format_not_defined`](/slides/python-net/zh/aspose.slides/ilineformat/is_format_not_defined/) | 如果线格式未定义（刚创建时为默认），返回 true。<br/>            只读 **bool**. |
| [`fill_format`](/slides/python-net/zh/aspose.slides/ilineformat/fill_format/) | 返回线的填充格式。<br/>            只读 [`ILineFillFormat`](/slides/python-net/zh/aspose.slides/ilinefillformat). |

| [`width`](/slides/python-net/zh/aspose.slides/ilineformat/width/) | 返回或设置线的宽度。<br/>            可读写 **float**. |
| [`dash_style`](/slides/python-net/zh/aspose.slides/ilineformat/dash_style/) | 返回或设置线的虚线样式。<br/>            可读写 [`LineDashStyle`](/slides/python-net/zh/aspose.slides/linedashstyle). |
| [`custom_dash_pattern`](/slides/python-net/zh/aspose.slides/ilineformat/custom_dash_pattern/) | 返回或设置自定义虚线模式。<br/>            可读写 **float**[]. |
| [`cap_style`](/slides/python-net/zh/aspose.slides/ilineformat/cap_style/) | 返回或设置线端帽样式。<br/>            可读写 [`LineCapStyle`](/slides/python-net/zh/aspose.slides/linecapstyle). |
| [`style`](/slides/python-net/zh/aspose.slides/ilineformat/style/) | 返回或设置线样式。<br/>            可读写 [`LineStyle`](/slides/python-net/zh/aspose.slides/linestyle). |
| [`alignment`](/slides/python-net/zh/aspose.slides/ilineformat/alignment/) | 返回或设置线对齐方式。<br/>            可读写 [`LineAlignment`](/slides/python-net/zh/aspose.slides/linealignment). |
| [`join_style`](/slides/python-net/zh/aspose.slides/ilineformat/join_style/) | 返回或设置线段连接样式。<br/>            可读写 [`LineJoinStyle`](/slides/python-net/zh/aspose.slides/linejoinstyle). |

| [`begin_arrowhead_style`](/slides/python-net/zh/aspose.slides/ilineformat/begin_arrowhead_style/) | 返回或设置线起点的箭头样式。<br/>            可读写 [`LineArrowheadStyle`](/slides/python-net/zh/aspose.slides/linearrowheadstyle). |
| [`end_arrowhead_style`](/slides/python-net/zh/aspose.slides/ilineformat/end_arrowhead_style/) | 返回或设置线终点的箭头样式。<br/>            可读写 [`LineArrowheadStyle`](/slides/python-net/zh/aspose.slides/linearrowheadstyle). |
| [`begin_arrowhead_width`](/slides/python-net/zh/aspose.slides/ilineformat/begin_arrowhead_width/) | 返回或设置线起点的箭头宽度。<br/>            可读写 [`LineArrowheadWidth`](/slides/python-net/zh/aspose.slides/linearrowheadwidth). |
| [`end_arrowhead_width`](/slides/python-net/zh/aspose.slides/ilineformat/end_arrowhead_width/) | 返回或设置线终点的箭头宽度。<br/>            可读写 [`LineArrowheadWidth`](/slides/python-net/zh/aspose.slides/linearrowheadwidth). |
