## ConnectorLock 类

确定在父 Connector 上哪些操作被禁用。

**继承:**[`ConnectorLock`](/slides/python-net/zh/aspose.slides/connectorlock) → [`BaseShapeLock`](/slides/python-net/zh/aspose.slides/baseshapelock)

ConnectorLock 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`no_locks`](/slides/python-net/zh/aspose.slides/connectorlock/no_locks/) | 如果所有 lock-flags 都已禁用则返回 true。<br/>            只读 **bool**. |
| [`grouping_locked`](/slides/python-net/zh/aspose.slides/connectorlock/grouping_locked/) | 确定是否禁止将此形状添加到组中。<br/>            读/写 **bool**. |
| [`select_locked`](/slides/python-net/zh/aspose.slides/connectorlock/select_locked/) | 确定是否禁止选择此形状。<br/>            读/写 **bool**. |
| [`rotate_locked`](/slides/python-net/zh/aspose.slides/connectorlock/rotate_locked/) | 确定是否禁止更改此形状的旋转角度。<br/>            读/写 **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/zh/aspose.slides/connectorlock/aspect_ratio_locked/) | 确定在调整大小时形状是否必须保持宽高比。<br/>            读/写 **bool**. |
| [`position_move`](/slides/python-net/zh/aspose.slides/connectorlock/position_move/) | 确定是否禁止移动此形状。<br/>            读/写 **bool**. |
| [`size_locked`](/slides/python-net/zh/aspose.slides/connectorlock/size_locked/) | 确定是否禁止调整此形状的大小。<br/>            读/写 **bool**. |
| [`edit_points_locked`](/slides/python-net/zh/aspose.slides/connectorlock/edit_points_locked/) | 确定是否禁止直接更改此形状的轮廓。<br/>            读/写 **bool**. |
| [`adjust_handles_locked`](/slides/python-net/zh/aspose.slides/connectorlock/adjust_handles_locked/) | 确定是否禁止更改调整值。<br/>            读/写 **bool**. |
| [`arrowheads_locked`](/slides/python-net/zh/aspose.slides/connectorlock/arrowheads_locked/) | 确定是否禁止更改箭头。<br/>            读/写 **bool**. |
| [`shape_type_locked`](/slides/python-net/zh/aspose.slides/connectorlock/shape_type_locked/) | 确定是否禁止更改形状类型。<br/>            读/写 **bool**. |
