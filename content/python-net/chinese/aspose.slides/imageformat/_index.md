## ImageFormat 枚举

表示图像的文件格式。

ImageFormat 类型公开以下成员：

## 字段

| Field | Description |
| :- | :- |
| MEMORY_BMP | 表示内存中位图的格式。 |
| BMP | 表示位图 (BMP) 图像格式。 |
| EMF | 表示增强型图元文件 (EMF) 图像格式。 |
| WMF | 表示 Windows 图元文件 (WMF) 图像格式。 |
| GIF | 表示图形交换格式 (GIF) 图像格式。 |
| JPEG | 表示联合摄影专家组 (JPEG) 图像格式。 |
| PNG | 表示 W3C 可移植网络图形 (PNG) 图像格式。 |
| TIFF | 表示标记图像文件格式 (TIFF) 图像格式。 |
| EXIF | 表示可交换图像文件 (Exif) 格式。 |
| ICON | 表示 Windows 图标图像格式。 |
