## IColorFormat 类

表示演示文稿中使用的颜色。

IColorFormat 类型公开以下成员：

## 属性

| Property | Description |
| :- | :- |
| [`color_type`](/slides/python-net/zh/aspose.slides/icolorformat/color_type/) | 返回或设置颜色定义方法。<br/>            读/写 [`ColorType`](/slides/python-net/zh/aspose.slides/colortype)。 |
| [`color`](/slides/python-net/zh/aspose.slides/icolorformat/color/) | 返回应用所有颜色转换后的结果颜色。<br/>            设置 RGB 颜色并清除所有颜色转换。<br/>            读/写 **aspose.slides.Color**。 |
| [`preset_color`](/slides/python-net/zh/aspose.slides/icolorformat/preset_color/) | 返回或设置颜色预设。<br/>            读/写 [`PresetColor`](/slides/python-net/zh/aspose.slides/presetcolor)。 |
| [`system_color`](/slides/python-net/zh/aspose.slides/icolorformat/system_color/) | 返回或设置由系统颜色表标识的颜色。<br/>            读/写 [`SystemColor`](/slides/python-net/zh/aspose.slides/systemcolor)。 |
| [`scheme_color`](/slides/python-net/zh/aspose.slides/icolorformat/scheme_color/) | 返回或设置由配色方案标识的颜色。<br/>            读/写 [`SchemeColor`](/slides/python-net/zh/aspose.slides/schemecolor)。 |
| [`r`](/slides/python-net/zh/aspose.slides/icolorformat/r/) | 返回或设置颜色的红色分量。所有颜色转换均被忽略。<br/>            读/写 **int**。 |
| [`g`](/slides/python-net/zh/aspose.slides/icolorformat/g/) | 返回或设置颜色的绿色分量。所有颜色转换均被忽略。<br/>            读/写 **int**。 |
| [`b`](/slides/python-net/zh/aspose.slides/icolorformat/b/) | 返回或设置颜色的蓝色分量。所有颜色转换均被忽略。<br/>            读/写 **int**。 |
| [`float_r`](/slides/python-net/zh/aspose.slides/icolorformat/float_r/) | 返回或设置颜色的红色分量。所有颜色转换均被忽略。<br/>            读/写 **float**。 |
| [`float_g`](/slides/python-net/zh/aspose.slides/icolorformat/float_g/) | 返回或设置颜色的绿色分量。所有颜色转换均被忽略。<br/>            读/写 **float**。 |
| [`float_b`](/slides/python-net/zh/aspose.slides/icolorformat/float_b/) | 返回或设置颜色的蓝色分量。所有颜色转换均被忽略。<br/>            读/写 **float**。 |
| [`hue`](/slides/python-net/zh/aspose.slides/icolorformat/hue/) | 返回或设置 HSL 表示中颜色的色相分量。<br/>            所有颜色转换均被忽略。<br/>            读/写 **float**。 |
| [`saturation`](/slides/python-net/zh/aspose.slides/icolorformat/saturation/) | 返回或设置 HSL 表示中颜色的饱和度分量。<br/>            所有颜色转换均被忽略。<br/>            读/写 **float**。 |
| [`luminance`](/slides/python-net/zh/aspose.slides/icolorformat/luminance/) | 返回或设置 HSL 表示中颜色的亮度分量。<br/>            所有颜色转换均被忽略。<br/>            读/写 **float**。 |
| [`color_transform`](/slides/python-net/zh/aspose.slides/icolorformat/color_transform/) | 返回对颜色应用的颜色转换集合。<br/>            只读 [`IColorOperationCollection`](/slides/python-net/zh/aspose.slides/icoloroperationcollection)。 |
