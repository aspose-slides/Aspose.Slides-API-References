## ShapeThumbnailBounds 枚举

形状缩略图边界类型的枚举。

ShapeThumbnailBounds 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| SLIDE | 形状缩略图的大小将等于幻灯片大小。<br/>            形状位置将被保存。 |
| SHAPE | 形状缩略图的大小将等于形状边界矩形<br/>            并考虑形状轮廓设置。 |
| APPEARANCE | 形状缩略图的大小将等于形状外观（在幻灯片范围内）。 <br/>            可能出现形状外观无法适配形状边界的情况。例如：<br/>            旋转、锐角斜接、3D 效果等。 |
