## ITab 类

表示文本的制表符。

ITab 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`position`](/slides/python-net/zh/aspose.slides/itab/position/) | 返回或设置制表符的位置。<br/>            为此属性赋值可能会更改集合中制表符的索引并使 Enumerator 失效。<br/>            读/写 **float**. |
| [`alignment`](/slides/python-net/zh/aspose.slides/itab/alignment/) | 返回或设置制表符的对齐样式。<br/>            读/写 [`TabAlignment`](/slides/python-net/zh/aspose.slides/tabalignment). |
