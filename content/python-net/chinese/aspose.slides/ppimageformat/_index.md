## PPImageFormat 枚举

图像格式。此枚举是 `System.Drawing.Imaging.ImageFormat` 类的替代，用于 COM 兼容性。

PPImageFormat 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| BMP | 获取位图 (BMP) 图像格式。 |
| EMF | 获取增强型元文件 (EMF) 图像格式。 |
| EXIF | 获取可交换图像文件 (Exif) 格式。 |
| GIF | 获取图形交换格式 (GIF) 图像格式。 |
| ICON | 获取 Windows 图标图像格式。 |
| JPEG | 获取联合摄影专家组 (JPEG) 图像格式。 |
| MEMORY_BMP | 获取内存中位图的格式。 |
| PNG | 获取 W3C 可移植网络图形 (PNG) 图像格式。 |
| TIFF | 获取标签图像文件格式 (TIFF) 图像格式。 |
| WMF | 获取 Windows 元文件 (WMF) 图像格式。 |
