## NormalViewProperties 类

表示普通视图属性。普通视图由三个内容区域组成：幻灯片本身、侧边内容区域和底部内容区域。

NormalViewProperties 类型公开以下成员：

## 属性

| Property | Description |
| :- | :- |
| [`show_outline_icons`](/slides/python-net/zh/aspose.slides/normalviewproperties/show_outline_icons/) | 指定在普通视图模式的任何<br/>            内容区域显示大纲内容时，应用程序是否应显示图标。<br/>            读写 **bool**. |
| [`snap_vertical_splitter`](/slides/python-net/zh/aspose.slides/normalviewproperties/snap_vertical_splitter/) | 指定当侧边<br/>            区域足够小时时，垂直分割条是否应自动捕捉到最小化状态。<br/>            读写 **bool**. |
| [`vertical_bar_state`](/slides/python-net/zh/aspose.slides/normalviewproperties/vertical_bar_state/) | 指定垂直分割条应显示的状态。<br/>            垂直分割条将幻灯片与侧边内容区域分隔开. |
| [`horizontal_bar_state`](/slides/python-net/zh/aspose.slides/normalviewproperties/horizontal_bar_state/) | 指定水平分割条应显示的状态。<br/>            水平分割条将幻灯片与幻灯片下方的内容区域分隔开. |
| [`prefer_single_view`](/slides/python-net/zh/aspose.slides/normalviewproperties/prefer_single_view/) | 指定用户是否倾向于在全窗口单内容区域上查看，而不是<br/>            具有三个内容区域的标准普通视图。启用后，应用程序可能会选择<br/>            在整个窗口中显示其中一个内容区域。<br/>            读写 **bool**. |
| [`restored_left`](/slides/python-net/zh/aspose.slides/normalviewproperties/restored_left/) | 此元素指定普通视图侧边内容区域的大小，当该区域处于可变<br/>            恢复大小（既未最小化也未最大化）时。<br/>            只读 [`INormalViewRestoredProperties`](/slides/python-net/zh/aspose.slides/inormalviewrestoredproperties). |
| [`restored_top`](/slides/python-net/zh/aspose.slides/normalviewproperties/restored_top/) | 此元素指定普通视图顶部幻灯片区域的大小，当该区域处于可变<br/>            恢复大小（既未最小化也未最大化）时。<br/>            只读 [`INormalViewRestoredProperties`](/slides/python-net/zh/aspose.slides/inormalviewrestoredproperties). |
