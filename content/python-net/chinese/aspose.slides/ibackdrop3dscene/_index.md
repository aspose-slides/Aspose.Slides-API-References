## IBackdrop3DScene 类

定义一个平面，在该平面上相对于所应用的形状，应用诸如辉光和阴影等效果。

IBackdrop3DScene 类型公开以下成员：

## 属性

| Property | Description |
| :- | :- |
| [`normal_vector`](/slides/python-net/zh/aspose.slides/ibackdrop3dscene/normal_vector/) | 返回或设置法向量。更精确地说，此属性定义一个垂直于背景平面面的向量<br/>            向量由包含 X、Y 和 Z 坐标的 3 个 float 值的数组表示<br/>            读取/写入 **float**[]. |
| [`anchor_point`](/slides/python-net/zh/aspose.slides/ibackdrop3dscene/anchor_point/) | 返回或设置 3D 空间中的一点。该点是锚定背景平面的空间点。<br/>            3D 点由包含 X、Y 和 Z 坐标的 3 个 float 值的数组表示<br/>            读取/写入 **float**[]. |
| [`up_vector`](/slides/python-net/zh/aspose.slides/ibackdrop3dscene/up_vector/) | 返回或设置表示上方向的向量。更精确地说，此属性定义一个相对于背景平面面的上方向向量<br/>            向量由包含 X、Y 和 Z 坐标的 3 个 float 值的数组表示<br/>            读取/写入 **float**[]. |
