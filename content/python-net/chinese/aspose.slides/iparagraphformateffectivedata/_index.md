## IParagraphFormatEffectiveData 类

不可变对象，包含有效的段落格式属性。

IParagraphFormatEffectiveData 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`bullet`](/slides/python-net/zh/aspose.slides/iparagraphformateffectivedata/bullet/) | 返回段落的项目符号格式。<br/> 只读 [`IBulletFormatEffectiveData`](/slides/python-net/zh/aspose.slides/ibulletformateffectivedata). |
| [`depth`](/slides/python-net/zh/aspose.slides/iparagraphformateffectivedata/depth/) | 返回段落的深度。<br/> 只读 **int**. |
| [`alignment`](/slides/python-net/zh/aspose.slides/iparagraphformateffectivedata/alignment/) | 返回段落中的文本对齐方式。<br/> 只读 [`TextAlignment`](/slides/python-net/zh/aspose.slides/textalignment). |
| [`space_within`](/slides/python-net/zh/aspose.slides/iparagraphformateffectivedata/space_within/) | 返回段落基线之间的间距。<br/> 只读 **float**. |
| [`space_before`](/slides/python-net/zh/aspose.slides/iparagraphformateffectivedata/space_before/) | 返回段落第一行之前的间距。<br/> 只读 **float**. |
| [`space_after`](/slides/python-net/zh/aspose.slides/iparagraphformateffectivedata/space_after/) | 返回段落最后一行之后的间距。<br/> 只读 **float**. |
| [`east_asian_line_break`](/slides/python-net/zh/aspose.slides/iparagraphformateffectivedata/east_asian_line_break/) | 确定段落中是否使用东亚换行。<br/> 只读 **bool**. |
| [`right_to_left`](/slides/python-net/zh/aspose.slides/iparagraphformateffectivedata/right_to_left/) | 确定段落中是否使用从右到左的书写。<br/> 只读 **bool**. |
| [`latin_line_break`](/slides/python-net/zh/aspose.slides/iparagraphformateffectivedata/latin_line_break/) | 确定段落中是否使用拉丁换行。<br/> 只读 **bool**. |
| [`hanging_punctuation`](/slides/python-net/zh/aspose.slides/iparagraphformateffectivedata/hanging_punctuation/) | 确定段落中是否使用悬挂标点。<br/> 只读 **bool**. |
| [`margin_left`](/slides/python-net/zh/aspose.slides/iparagraphformateffectivedata/margin_left/) | 返回段落的左侧边距。<br/> 只读 **float**. |
| [`margin_right`](/slides/python-net/zh/aspose.slides/iparagraphformateffectivedata/margin_right/) | 返回段落的右侧边距。<br/> 只读 **float**. |
| [`indent`](/slides/python-net/zh/aspose.slides/iparagraphformateffectivedata/indent/) | 返回段落的首行缩进/悬挂缩进。悬挂缩进可以使用负值定义。<br/> 只读 **float**. |
| [`default_tab_size`](/slides/python-net/zh/aspose.slides/iparagraphformateffectivedata/default_tab_size/) | 返回默认制表符大小。<br/> 只读 **float**. |
| [`tabs`](/slides/python-net/zh/aspose.slides/iparagraphformateffectivedata/tabs/) | 返回段落的制表符。<br/> 只读 [`ITabEffectiveData`](/slides/python-net/zh/aspose.slides/itabeffectivedata)[]. |
| [`font_alignment`](/slides/python-net/zh/aspose.slides/iparagraphformateffectivedata/font_alignment/) | 返回段落中的字体对齐方式。<br/> 只读 [`FontAlignment`](/slides/python-net/zh/aspose.slides/fontalignment). |
| [`default_portion_format`](/slides/python-net/zh/aspose.slides/iparagraphformateffectivedata/default_portion_format/) | 返回段落的默认部分格式。<br/> 只读 [`IPortionFormatEffectiveData`](/slides/python-net/zh/aspose.slides/iportionformateffectivedata). |


### 备注

此接口与 [`IParagraphFormat`](/slides/python-net/zh/aspose.slides/iparagraphformat) 接口一起使用，以返回应用继承后的有效格式化值。
