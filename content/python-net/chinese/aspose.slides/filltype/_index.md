## FillType 枚举

指定各种可视对象的内部填充类型。

FillType 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| NOT_DEFINED | 填充类型未定义。 |
| NO_FILL | 未应用填充。 |
| SOLID | 使用纯色填充。 |
| GRADIENT | 填充为渐变。 |
| PATTERN | 使用重复图案填充对象。 |
| PICTURE | 使用单张图片填充对象。 |
| GROUP | 视觉对象从组继承填充属性。 |
