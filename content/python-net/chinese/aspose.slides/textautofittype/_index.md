## TextAutofitType 枚举

表示文本自动适应模式。

TextAutofitType 类型公开以下成员：

## 字段

| Field | Description |
| :- | :- |
| NOT_DEFINED | 未定义。 |
| NONE | 无自动适应。 |
| NORMAL | 正常自动适应。字体大小和行间距将被缩小以适应形状。 |
| SHAPE | 形状自动适应。形状大小将被更改以适应文本。 |
