## IPPImage 类

表示演示文稿中的图像。

IPPImage 类型公开以下成员：

## 属性

| Property | Description |
| :- | :- |
| [`binary_data`](/slides/python-net/zh/aspose.slides/ippimage/binary_data/) | 返回图像数据的副本。<br/>            只读 **int**[]。 |
| [`image`](/slides/python-net/zh/aspose.slides/ippimage/image/) | 返回图像的副本。<br/>            只读 [`IPPImage.image`](/slides/python-net/zh/aspose.slides/ippimage/image)。 |
| [`svg_image`](/slides/python-net/zh/aspose.slides/ippimage/svg_image/) | 返回或设置 ISvgImage 对象 [`ISvgImage`](/slides/python-net/zh/aspose.slides/isvgimage) |
| [`content_type`](/slides/python-net/zh/aspose.slides/ippimage/content_type/) | 返回图像的 MIME 类型，使用 [`IPPImage.binary_data`](/slides/python-net/zh/aspose.slides/ippimage/binary_data) 编码。<br/>            只读 **str**。 |
| [`width`](/slides/python-net/zh/aspose.slides/ippimage/width/) | 返回图像的宽度。<br/>            只读 **int**。 |
| [`height`](/slides/python-net/zh/aspose.slides/ippimage/height/) | 返回图像的高度。<br/>            只读 **int**。 |
| [`x`](/slides/python-net/zh/aspose.slides/ippimage/x/) | 返回图像的 X 偏移量。<br/>            只读 **int**。 |
| [`y`](/slides/python-net/zh/aspose.slides/ippimage/y/) | 返回图像的 Y 偏移量。<br/>            只读 **int**。 |
