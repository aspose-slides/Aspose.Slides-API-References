## IShapeStyle 类

表示形状的样式引用。

IShapeStyle 类型公开以下成员：

## 属性

| Property | Description |
| :- | :- |
| [`line_color`](/slides/python-net/zh/aspose.slides/ishapestyle/line_color/) | 返回形状的轮廓颜色。<br/>            只读 [`IColorFormat`](/slides/python-net/zh/aspose.slides/icolorformat)。 |
| [`line_style_index`](/slides/python-net/zh/aspose.slides/ishapestyle/line_style_index/) | 返回或设置线条在样式矩阵中的列索引。<br/>            读写 **int**。 |
| [`fill_color`](/slides/python-net/zh/aspose.slides/ishapestyle/fill_color/) | 返回形状的填充颜色。<br/>            只读 [`IColorFormat`](/slides/python-net/zh/aspose.slides/icolorformat)。 |
| [`fill_style_index`](/slides/python-net/zh/aspose.slides/ishapestyle/fill_style_index/) | 返回或设置形状在样式矩阵中的填充列索引。<br/>            0 表示无填充，<br/>            正值 - 主题填充样式的索引，<br/>            负值 - 主题背景样式的索引。<br/>            读写 **int**。 |
| [`effect_color`](/slides/python-net/zh/aspose.slides/ishapestyle/effect_color/) | 返回形状的效果颜色。<br/>            只读 [`IColorFormat`](/slides/python-net/zh/aspose.slides/icolorformat)。 |
| [`effect_style_index`](/slides/python-net/zh/aspose.slides/ishapestyle/effect_style_index/) | 返回或设置形状在样式矩阵中的效果列索引。<br/>            读写 **int**。 |
| [`font_color`](/slides/python-net/zh/aspose.slides/ishapestyle/font_color/) | 返回形状的字体颜色。<br/>            只读 [`IColorFormat`](/slides/python-net/zh/aspose.slides/icolorformat)。 |
| [`font_collection_index`](/slides/python-net/zh/aspose.slides/ishapestyle/font_collection_index/) | 返回或设置形状在字体集合中的字体索引。<br/>            读写 [`FontCollectionIndex`](/slides/python-net/zh/aspose.slides/fontcollectionindex)。 |
