## IGradientFormat 类

表示渐变格式。

IGradientFormat 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`tile_flip`](/slides/python-net/zh/aspose.slides/igradientformat/tile_flip/) | 返回或设置渐变的翻转模式。<br/>            可读写 [`TileFlip`](/slides/python-net/zh/aspose.slides/tileflip)。 |
| [`gradient_direction`](/slides/python-net/zh/aspose.slides/igradientformat/gradient_direction/) | 返回或设置渐变的样式。<br/>            可读写 [`GradientDirection`](/slides/python-net/zh/aspose.slides/gradientdirection)。 |
| [`linear_gradient_angle`](/slides/python-net/zh/aspose.slides/igradientformat/linear_gradient_angle/) | 返回或设置渐变的角度。<br/>            可读写 **float**。 |
| [`linear_gradient_scaled`](/slides/python-net/zh/aspose.slides/igradientformat/linear_gradient_scaled/) | 确定渐变是否被缩放。<br/>            可读写 [`NullableBool`](/slides/python-net/zh/aspose.slides/nullablebool)。 |
| [`gradient_shape`](/slides/python-net/zh/aspose.slides/igradientformat/gradient_shape/) | 返回或设置渐变的形状。<br/>            可读写 [`GradientShape`](/slides/python-net/zh/aspose.slides/gradientshape)。 |
| [`gradient_stops`](/slides/python-net/zh/aspose.slides/igradientformat/gradient_stops/) | 返回渐变停止点的集合。<br/>            只读 [`IGradientStopCollection`](/slides/python-net/zh/aspose.slides/igradientstopcollection)。 |
