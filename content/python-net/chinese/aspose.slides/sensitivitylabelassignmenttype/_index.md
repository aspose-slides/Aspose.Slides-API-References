## SensitivityLabelAssignmentType 枚举

表示敏感度标签的分配方法。

SensitivityLabelAssignmentType 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| STANDARD | 用于任何未由用户直接应用的敏感度标签。<br/>            这包括任何默认标签，自动应用的标签。 |
| PRIVILEGED | 用于任何由用户直接应用的敏感度标签。<br/>            这包括任何手动应用的敏感度标签，以及推荐<br/>            或强制标记或任何用户决定应用哪个敏感度标签的功能。 |
