## IHeadingPair 类

表示文档的“Heading pair”属性。 
            它指示文档部件组的组名以及组中部件的数量。

IHeadingPair 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`name`](/slides/python-net/zh/aspose.slides/iheadingpair/name/) | 返回文档部件的组名。<br/>            只读 **str**。 |
| [`count`](/slides/python-net/zh/aspose.slides/iheadingpair/count/) | 返回组中部件的数量。<br/>            只读 **int**。 |
