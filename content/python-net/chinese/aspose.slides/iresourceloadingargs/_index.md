## IResourceLoadingArgs 类

用于外部资源加载参数的接口。

IResourceLoadingArgs 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`original_uri`](/slides/python-net/zh/aspose.slides/iresourceloadingargs/original_uri/) | 在导入的演示文稿中指定的资源的原始 URI。 |
| [`uri`](/slides/python-net/zh/aspose.slides/iresourceloadingargs/uri/) | 如果 **Aspose.Slides.IResourceLoadingCallback.ResourceLoading(Aspose.Slide** <br/>            返回 [`ResourceLoadingAction.DEFAULT`](/slides/python-net/zh/aspose.slides/resourceloadingaction/DEFAULT). <br/>            最初它被设置为资源的原始 URI，但可以重新定义为任意值。 |

## 方法

| 方法 | 描述 |
| :- | :- |
| [`set_data(self, data)`](/slides/python-net/zh/aspose.slides/iresourceloadingargs/set_data/#bytes) | 如果 **Aspose.Slides.IResourceLoadingCallback.ResourceLoading(Aspose.Slide** <br/>            返回 [`ResourceLoadingAction.USER_PROVIDED`](/slides/python-net/zh/aspose.slides/resourceloadingaction/USER_PROVIDED)，则设置资源的用户提供数据。 |
