## Picture 类

表示演示文稿中的图片。

Picture 类型公开以下成员：

## 属性

| Property | Description |
| :- | :- |
| [`image`](/slides/python-net/zh/aspose.slides/picture/image/) | 返回或设置嵌入的图像。<br/>            读写 [`IPPImage`](/slides/python-net/zh/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/zh/aspose.slides/picture/link_path_long/) | 返回或设置链接图片的 URL。<br/>            读写 **str**. |
| [`image_transform`](/slides/python-net/zh/aspose.slides/picture/image_transform/) | 返回图像变换效果的集合。<br/>            只读 [`IImageTransformOperationCollection`](/slides/python-net/zh/aspose.slides.effects/iimagetransformoperationcollection). |
| [`presentation`](/slides/python-net/zh/aspose.slides/picture/presentation/) | 返回演示文稿。 <br/>            只读 [`IPresentation`](/slides/python-net/zh/aspose.slides/ipresentation). |
| [`slide`](/slides/python-net/zh/aspose.slides/picture/slide/) | 返回图片的父幻灯片。<br/>            只读 [`IBaseSlide`](/slides/python-net/zh/aspose.slides/ibaseslide). |
