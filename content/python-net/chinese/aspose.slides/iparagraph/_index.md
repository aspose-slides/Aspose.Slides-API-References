## IParagraph 类

表示文本中的段落。

IParagraph 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`portions`](/slides/python-net/zh/aspose.slides/iparagraph/portions/) | 返回文本片段的集合。<br/>            只读 [`IPortionCollection`](/slides/python-net/zh/aspose.slides/iportioncollection)。 |
| [`paragraph_format`](/slides/python-net/zh/aspose.slides/iparagraph/paragraph_format/) | 返回此段落的格式化对象。<br/>            只读 [`IParagraphFormat`](/slides/python-net/zh/aspose.slides/iparagraphformat)。 |
| [`text`](/slides/python-net/zh/aspose.slides/iparagraph/text/) | 获取或设置段落的纯文本。<br/>            读/写 **str**。 |
| [`end_paragraph_portion_format`](/slides/python-net/zh/aspose.slides/iparagraph/end_paragraph_portion_format/) | 指定如果在最后一个片段后插入另一个片段时要使用的片段属性。 |
| [`slide`](/slides/python-net/zh/aspose.slides/iparagraph/slide/) |  |
| [`presentation`](/slides/python-net/zh/aspose.slides/iparagraph/presentation/) |  |

## 方法

| 方法 | 描述 |
| :- | :- |
| [`get_image`](/slides/python-net/zh/aspose.slides/iparagraph/get_image/#) | 返回段落的图像。 |
| [`get_image`](/slides/python-net/zh/aspose.slides/iparagraph/get_image/#float-float) | 返回指定缩放比例的段落图像。 |

| [`get_rect`](/slides/python-net/zh/aspose.slides/iparagraph/get_rect/#) | 获取段落边界矩形的坐标。<br/>            包括段落中的文本，包括空行。 |
| [`get_lines_count`](/slides/python-net/zh/aspose.slides/iparagraph/get_lines_count/#) | 获取段落中的行数。 |
