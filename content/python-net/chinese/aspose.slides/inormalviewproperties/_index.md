## INormalViewProperties 类

表示普通视图属性。普通视图由三个内容区域组成：幻灯片本身、侧边内容区域以及底部内容区域。

INormalViewProperties 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`show_outline_icons`](/slides/python-net/zh/aspose.slides/inormalviewproperties/show_outline_icons/) | 指定在普通视图模式的任意内容区域显示大纲内容时，应用程序是否应显示图标。<br/>            可读写 **bool**. |
| [`snap_vertical_splitter`](/slides/python-net/zh/aspose.slides/inormalviewproperties/snap_vertical_splitter/) | 指定当侧边区域足够小时时，垂直分割条是否应自动折叠到最小化状态。<br/>            可读写 **bool**. |
| [`vertical_bar_state`](/slides/python-net/zh/aspose.slides/inormalviewproperties/vertical_bar_state/) | 指定垂直分割条应显示的状态。<br/>            垂直分割条将幻灯片与侧边内容区域分开。 |
| [`horizontal_bar_state`](/slides/python-net/zh/aspose.slides/inormalviewproperties/horizontal_bar_state/) | 指定水平分割条应显示的状态。<br/>            水平分割条将幻灯片与幻灯片下方的内容区域分开。 |
| [`prefer_single_view`](/slides/python-net/zh/aspose.slides/inormalviewproperties/prefer_single_view/) | 指定用户是否更倾向于在全窗口单内容区域中查看，而不是具有三个内容区域的标准普通视图。如果启用，应用程序可能会选择在整个窗口显示其中一个内容区域。<br/>            可读写 **bool**. |
| [`restored_left`](/slides/python-net/zh/aspose.slides/inormalviewproperties/restored_left/) | 当侧边内容区域处于可变恢复大小（既未最小化也未最大化）时，此元素指定该区域的大小。<br/>            只读 [`INormalViewRestoredProperties`](/slides/python-net/zh/aspose.slides/inormalviewrestoredproperties). |
| [`restored_top`](/slides/python-net/zh/aspose.slides/inormalviewproperties/restored_top/) | 当顶部幻灯片区域处于可变恢复大小（既未最小化也未最大化）时，此元素指定该区域的大小。<br/>            只读 [`INormalViewRestoredProperties`](/slides/python-net/zh/aspose.slides/inormalviewrestoredproperties). |
