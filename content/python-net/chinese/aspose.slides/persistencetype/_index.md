## PersistenceType 枚举

指定用于存储 ActiveX 控件属性的方法。

PersistenceType 类型公开以下成员：

## 字段

| Field | Description |
| :- | :- |
| NOT_DEFINED | 未指定持久性 ID。 |
| PERSIST_PROPERTY_BAG | 指定 ActiveX 控件使用基于属性包的持久化。 <br/>             基于属性包的持久化通过一组名称和值对来存储 ActiveX 控件，这些名称和值对指定了由 ActiveX 控件持久化的数据。 |
| PERSIST_STREAM | 指定 ActiveX 控件使用基于流的持久化 <br/>             该持久化不支持将 ActiveX 控件初始化为默认状态。 |
| PERSIST_STREAM_INIT | 指定 ActiveX 控件使用基于流的持久化 <br/>             该持久化支持将 ActiveX 控件初始化为默认状态。 |
| PERSIST_STORAGE | 指定 ActiveX 控件使用基于存储的持久化。 |
