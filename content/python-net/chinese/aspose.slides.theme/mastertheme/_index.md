## MasterTheme 类

表示一个母版主题。

**继承:**[`MasterTheme`](/slides/python-net/zh/aspose.slides.theme/mastertheme) → [`Theme`](/slides/python-net/zh/aspose.slides.theme/theme)

MasterTheme 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`color_scheme`](/slides/python-net/zh/aspose.slides.theme/mastertheme/color_scheme/) | 返回颜色方案。<br/>            只读 [`IColorScheme`](/slides/python-net/zh/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/zh/aspose.slides.theme/mastertheme/font_scheme/) | 返回字体方案。<br/>            只读 [`IFontScheme`](/slides/python-net/zh/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/zh/aspose.slides.theme/mastertheme/format_scheme/) | 返回形状格式方案。<br/>            只读 [`IFormatScheme`](/slides/python-net/zh/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/zh/aspose.slides.theme/mastertheme/presentation/) | 返回父演示文稿。<br/>            只读 [`IPresentation`](/slides/python-net/zh/aspose.slides/ipresentation). |
| [`extra_color_schemes`](/slides/python-net/zh/aspose.slides.theme/mastertheme/extra_color_schemes/) | 返回附加颜色方案的集合。<br/>            这些方案不会影响演示文稿的外观，它们可以被选为幻灯片的主颜色方案。<br/>            只读 [`IExtraColorSchemeCollection`](/slides/python-net/zh/aspose.slides.theme/iextracolorschemecollection). |
| [`name`](/slides/python-net/zh/aspose.slides.theme/mastertheme/name/) | 返回主题的名称。<br/>            读/写 **str**. |
