包含用于以低代码方式处理复杂通用操作的类和方法。

## 类

| 类 | 描述 |
| :- | :- |
| [`Collect`](/slides/python-net/zh/aspose.slides.lowcode/collect/) | 表示一组旨在从[`Presentation`](/slides/python-net/zh/aspose.slides/presentation)收集不同类型模型对象的方法。 |
| [`Compress`](/slides/python-net/zh/aspose.slides.lowcode/compress/) | 表示一组旨在压缩[`Presentation`](/slides/python-net/zh/aspose.slides/presentation)的方法。 |
| [`Convert`](/slides/python-net/zh/aspose.slides.lowcode/convert/) | 表示一组旨在转换[`Presentation`](/slides/python-net/zh/aspose.slides/presentation)的方法。 |
| [`ForEach`](/slides/python-net/zh/aspose.slides.lowcode/foreach/) | 表示一组旨在遍历不同[`Presentation`](/slides/python-net/zh/aspose.slides/presentation)模型对象的方法。<br/>这些方法在需要遍历并更改某些Presentation元素的格式或内容时非常有用，<br/>例如更改每个部分的格式。 |
| [`Merger`](/slides/python-net/zh/aspose.slides.lowcode/merger/) | 表示一组用于将相同格式的PowerPoint演示文稿合并为一个文件的方法。 |
