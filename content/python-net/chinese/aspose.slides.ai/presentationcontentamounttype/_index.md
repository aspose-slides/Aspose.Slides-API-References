## PresentationContentAmountType 枚举

指定生成的演示文稿中包含的内容量，影响幻灯片数量以及每张幻灯片的细节程度。

PresentationContentAmountType 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| BRIEF | 简短且基本的内容。 |
| MEDIUM | 适中的内容量。 |
| DETAILED | 最详细的选项，包含大量文字。 |
