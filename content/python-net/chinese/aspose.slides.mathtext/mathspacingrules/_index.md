## MathSpacingRules 枚举

矩阵列之间的间隙（水平间距）的类型

MathSpacingRules 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| SINGLE_SPACING_GAP | 单一（列使用 1 em，行使用 1 line） |
| ONE_AND_HALF_SPACING_GAP | 一个半（列使用 1.5 ems，行使用 1.5 行） |
| DOUBLE_SPACING_GAP | 双倍间距（列使用 2 ems，行使用 2 行） |
| EXACTLY | 精确值<br/>            对于列，依赖 ColumnGap 的值，以 twips 为单位<br/>            对于行，依赖 RowGap 的值，以 twips 为单位 |
| MULTIPLE | 多重<br/>            对于列，依赖 ColumnGap 的值，以 0.5 em 为增量<br/>            对于行，依赖 RowGap 的值，以 行 为单位 |
