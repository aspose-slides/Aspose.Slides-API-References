## MathJustification 枚举

指定数学段落的对齐方式（同一段落中相邻的数学文本实例系列）

MathJustification 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| LEFT_JUSTIFIED | 将数学文本左对齐 |
| RIGHT_JUSTIFIED | 将数学文本右对齐 |
| CENTERED | 将数学文本居中 |
| CENTERED_AS_GROUP | 在页面上将整个数学块组作为单个单元居中。<br/>            这意味着数学文本的实例可以相互对齐，<br/>            但整个数学文本组整体居中。 |
