## no_break 属性
不换行
            此属性指定对象框的“不可换行”属性。为 true 时，框内不能出现换行。
            对于由多个二元运算符组成的运算符仿真器，这一点可能很重要。 
            如果未指定此元素，则框内可能出现换行。
            默认值： true
