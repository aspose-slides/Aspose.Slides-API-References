## MathRowSpacingRule 枚举

矩阵或数组中列之间的垂直间距类型

MathRowSpacingRule 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| SINGLE_LINE_GAP | 单行间距 |
| ONE_AND_A_HALF_LINE_GAP | 一行半间距 |
| TWO_LINE_GAP | 双行间距 |
| EXACTLY | 精确（依赖 RowSpacing 属性的值，以点为单位测量） |
| MULTIPLE | 多行（依赖 RowSpacing 属性的值，以行数为单位测量） |
