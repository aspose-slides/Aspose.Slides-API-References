## no_break 属性
无换行。
            此属性指定对象框的“unbreakable”属性。设置为 true 时，框内不能出现换行符。
            对于由多个二元运算符组成的运算符仿真器，这一点可能很重要。
            如果未指定此元素，框内可以出现换行。
            默认值： true
