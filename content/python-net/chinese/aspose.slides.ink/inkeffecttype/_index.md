## InkEffectType 枚举

指定一组预定义的墨水渲染视觉效果。
            每个效果对应一种纹理或图像，用于模拟风格化的墨水外观。
            这些值可用于在渲染过程中自定义数字墨水笔画的视觉样式。

InkEffectType 类型公开以下成员：

## 字段

| Field | Description |
| :- | :- |
| NOT_DEFINED | 该效果未定义或未知。此值可用作默认或后备。 |
| BRONZE | 一种温暖的棕色金属纹理，类似青铜墨水。 |
| GALAXY | 一种多彩且闪耀的纹理，类似星系，带有宇宙色调。 |
| GOLD | 一种明亮的金属金色纹理，使墨水笔画呈现奢华外观。 |
| LAVA | 一种火热的纹理，类似熔岩，带有红色和橙色色调。 |
| OCEAN | 一种深蓝色、类似流体的纹理，模仿海浪或水性墨水。 |
| RAINBOW_GLITTER | 一种多彩、闪亮的彩虹闪光效果，用于节日或活泼的墨水笔画。 |
| ROSE_GOLD | 一种柔和的粉金色混合，类似玫瑰金，用于优雅的墨水笔画。 |
| SILVER | 一种凉爽的金属银色纹理，模拟经典银色墨水。 |
