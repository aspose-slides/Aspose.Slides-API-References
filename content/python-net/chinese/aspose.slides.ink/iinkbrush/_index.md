## IInkBrush 类

表示踪迹画笔。

IInkBrush 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`color`](/slides/python-net/zh/aspose.slides.ink/iinkbrush/color/) | 获取或设置线条的画笔颜色。 |
| [`size`](/slides/python-net/zh/aspose.slides.ink/iinkbrush/size/) | 获取或设置线条的画笔大小（单位为点）。 |
| [`ink_effect`](/slides/python-net/zh/aspose.slides.ink/iinkbrush/ink_effect/) | 获取墨迹效果类型（例如，Galaxy、Gold、Silver），该类型定义墨笔笔触的视觉样式。<br/>            该值从画笔属性 "inkEffects" 中解析。如果未指定已识别的效果，<br/>            [`InkEffectType.NOT_DEFINED`](/slides/python-net/zh/aspose.slides.ink/inkeffecttype/NOT_DEFINED) 将被返回。 |
