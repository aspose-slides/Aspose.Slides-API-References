## PdfCompliance 枚举

定义 PDF 标准合规级别的常量。

PdfCompliance 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| PDF15 | 输出文件将符合 PDF 1.5 标准。 |
| PDF16 | 输出文件将符合 PDF 1.6 标准。 |
| PDF17 | 输出文件将符合 PDF 1.7 标准。 |
| PDF_A1B | 输出文件将符合 PDF/A-1b 标准。 |
| PDF_A1A | 输出文件将符合 PDF/A-1a 标准。 |
| PDF_A2B | 输出文件将符合 PDF/A-2b 标准。 |
| PDF_A2A | 输出文件将符合 PDF/A-2a 标准。 |
| PDF_A3B | 输出文件将符合 PDF/A-3b 标准。 |
| PDF_A3A | 输出文件将符合 PDF/A-3a 标准。 |
| PDF_UA | 输出文件将符合 PDF/UA 标准。 |
| PDF_A2U | 输出文件将符合 PDF/A-2u 标准。 |
