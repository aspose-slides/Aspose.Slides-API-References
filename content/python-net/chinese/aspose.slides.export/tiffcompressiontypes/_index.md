## TiffCompressionTypes 枚举

提供控制演示文稿在 TIFF 格式中压缩方式的选项。

TiffCompressionTypes 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| DEFAULT | 指定默认压缩方案 (LZW)。 |
| NONE | 指定无压缩。 |
| CCITT3 | 指定 CCITT3 压缩方案。 |
| CCITT4 | 指定 CCITT4 压缩方案。 |
| LZW | 指定 LZW 压缩方案 (默认)。 |
| RLE | 指定 RLE 压缩方案。 |
