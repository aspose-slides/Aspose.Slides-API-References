## PicturesCompression 枚举

表示图片压缩级别

PicturesCompression 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| DPI330 | 适用于高清 (HD) 显示器的高质量 |
| DPI220 | 在大多数打印机和屏幕上提供卓越质量 |
| DPI150 | 适用于网页和投影仪的良好质量 |
| DPI96 | 最小化文档大小以便共享 |
| DPI72 | 默认压缩级别 |
| DOCUMENT_RESOLUTION | 使用文档分辨率 - 图片将不被压缩并原样使用在文档中 |
