## ITextToHtmlConversionOptions 类

从 Pptx 文本中提取 HTML 的选项。

ITextToHtmlConversionOptions 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`add_clipboard_fragment_header`](/slides/python-net/zh/aspose.slides.export/itexttohtmlconversionoptions/add_clipboard_fragment_header/) | 返回或设置值，指示是否应添加剪贴板标题。<br/>            读/写 **bool**. |
| [`text_inheritance_limit`](/slides/python-net/zh/aspose.slides.export/itexttohtmlconversionoptions/text_inheritance_limit/) | 返回或设置文本属性的继承深度。<br/>            读/写 [`ITextToHtmlConversionOptions.text_inheritance_limit`](/slides/python-net/zh/aspose.slides.export/itexttohtmlconversionoptions/text_inheritance_limit). |

| [`encoding_name`](/slides/python-net/zh/aspose.slides.export/itexttohtmlconversionoptions/encoding_name/) | 返回或设置 HTML 编码名称。<br/>            此值将保存到生成的 HTML 文件中，但由调用方确保文件以此编码保存。<br/>            读/写 **str**. |
