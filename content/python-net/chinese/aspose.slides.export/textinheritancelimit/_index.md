## TextInheritanceLimit 枚举

控制文本属性继承的深度。

TextInheritanceLimit 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| ALL | 继承所有文本属性。 |
| TEXT_BOX | 仅继承自 TextFrame 的样式。 |
| PARAGRAPH_ONLY | 仅使用为段落定义的属性。 |
