## BlackWhiteConversionMode 枚举

提供控制幻灯片图像如何转换为二值图像的选项。

BlackWhiteConversionMode 类型公开以下成员：

## 字段

| 字段 | 说明 |
| :- | :- |
| DEFAULT | 指定不进行转换算法。将使用 TIFF 编码器实现的算法。（默认） |
| DITHERING | 指定抖动算法（Floyd-Steinberg）。 |
| DITHERING_FLOYD_STEINBERG | 指定 Floyd-Steinberg 抖动算法。 |
| AUTO | 指定自动计算的阈值算法（Otsu）。 |
| AUTO_OTSU | 指定自动计算的 Otsu 阈值算法。 |
| THRESHOLD25 | 指定静态阈值算法（25%）。 |
| THRESHOLD50 | 指定静态阈值算法（50%）。 |
| THRESHOLD75 | 指定静态阈值算法（75%）。 |
