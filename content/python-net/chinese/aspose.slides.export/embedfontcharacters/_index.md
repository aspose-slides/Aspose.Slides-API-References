EmbedFontCharacters 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| ONLY_USED | 仅嵌入演示文稿中使用的字符（最有助于减小文件大小）。 |
| ALL | 嵌入所有字符（最适合其他人编辑）。 |
