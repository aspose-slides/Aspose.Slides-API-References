## IPptxOptions 类

表示用于保存 OpenXml 演示文稿 (PPTX, PPSX, POTX, PPTM, PPSM, POTM) 的选项。

IPptxOptions 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`conformance`](/slides/python-net/zh/aspose.slides.export/ipptxoptions/conformance/) | 指定演示文稿文档符合的兼容类。<br/>默认值为 [`Conformance.ECMA_376_2006`](/slides/python-net/zh/aspose.slides.export/conformance/ECMA_376_2006) |
| [`zip_64_mode`](/slides/python-net/zh/aspose.slides.export/ipptxoptions/zip_64_mode/) | 指定是否对 Presentation 文档使用 ZIP64 格式。<br/>默认值为 [`Zip64Mode.IF_NECESSARY`](/slides/python-net/zh/aspose.slides.export/zip64mode/IF_NECESSARY) |
| [`refresh_thumbnail`](/slides/python-net/zh/aspose.slides.export/ipptxoptions/refresh_thumbnail/) | 指定是否刷新演示文稿缩略图。<br/>可读写 **bool**。<br/>默认值为 **true** 。 |
| [`compression_level`](/slides/python-net/zh/aspose.slides.export/ipptxoptions/compression_level/) | 指定保存演示文稿文档时使用的压缩级别。<br/>默认值为 [`CompressionLevel.LEVEL6`](/slides/python-net/zh/aspose.slides.export/compressionlevel/LEVEL6)。 |
| [`warning_callback`](/slides/python-net/zh/aspose.slides.export/ipptxoptions/warning_callback/) |  |
| [`progress_callback`](/slides/python-net/zh/aspose.slides.export/ipptxoptions/progress_callback/) |  |
| [`default_regular_font`](/slides/python-net/zh/aspose.slides.export/ipptxoptions/default_regular_font/) |  |
| [`gradient_style`](/slides/python-net/zh/aspose.slides.export/ipptxoptions/gradient_style/) |  |
| [`skip_java_script_links`](/slides/python-net/zh/aspose.slides.export/ipptxoptions/skip_java_script_links/) |  |
