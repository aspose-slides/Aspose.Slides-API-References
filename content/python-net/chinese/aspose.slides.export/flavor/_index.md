## Flavor 枚举

程序中使用的所有 markdown 规范。

Flavor 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| GITHUB | Github 风格。 |
| GRUBER | Gruber 风格。 |
| MULTI_MARKDOWN | Multi markdown 风格。 |
| COMMON_MARK | Common mark 风格。 |
| MARKDOWN_EXTRA | Markdown extra 风格。 |
| PANDOC | Pandoc 风格。 |
| KRAMDOWN | Kramdown 风格。 |
| MARKUA | Markua 风格。 |
| MARUKU | Maruku 风格。 |
| MARKDOWN2 | Markdown2 风格。 |
| REMARKABLE | Remarkable 风格 |
| SHOWDOWN | Showdown 风格。 |
| GHOST | Ghost 风格。 |
| GIT_LAB | Gitlab 风格。 |
| HAROOPAD | Haroopad 风格。 |
| IA_WRITER | IAWriter 风格。 |
| REDCARPET | Redcarpet 风格。 |
| SCHOLARLY_MARKDOWN | Scholarly markdown 风格。 |
| TAIGA | Taiga 风格。 |
| TRELLO | Trello 风格。 |
| S9E_TEXT_FORMATTER | S9E text formatter 风格。 |
| X_WIKI | XWiki 风格。 |
| STACK_OVERFLOW | Stack overflow 风格。 |
| DEFAULT | 默认 markdown 风格。 |
