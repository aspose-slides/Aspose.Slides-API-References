## SaveFormat 枚举

定义已保存演示文稿格式的常量。

SaveFormat 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| PPT | 以 PPT 格式保存演示文稿。 |
| PDF | 以 PDF 格式保存演示文稿。 |
| XPS | 以 XPS 格式保存演示文稿。 |
| PPTX | 以 PPTX 格式保存演示文稿。 |
| PPSX | 以 PPSX (slideshow) 格式保存演示文稿。 |
| TIFF | 将演示文稿保存为多页 TIFF 图像。 |
| ODP | 以 ODP 格式保存演示文稿。 |
| PPTM | 以 PPTM (macro-enabled presentation) 格式保存演示文稿。 |
| PPSM | 以 PPSM (macro-enabled slideshow) 格式保存演示文稿。 |
| POTX | 以 POTX (template) 格式保存演示文稿。 |
| POTM | 以 POTM (macro-enabled template) 格式保存演示文稿。 |
| HTML | 以 HTML 格式保存演示文稿。 |
| SWF | 以 SWF 格式保存演示文稿。 |
| OTP | 以 OTP (presentation template) 格式保存演示文稿。 |
| PPS | 以 PPS 格式保存演示文稿。 |
| POT | 以 POT 格式保存演示文稿。 |
| FODP | 以 FODP 格式保存演示文稿。 |
| GIF | 以 GIF 格式保存演示文稿。 |
| HTML5 | 使用新的 HTML5 模板系统以 HTML 格式保存演示文稿。 |
| MD | 以 Markdown 格式保存演示文稿 |
| XML | 以 PowerPoint XML 演示文稿格式保存演示文稿。 |
