## NotesPositions 枚举

表示在导出文档中渲染备注的规则

NotesPositions 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| NONE | 指定不应显示任何备注。 |
| BOTTOM_FULL | 指定应使用额外页面完整显示备注，视需要而定。 |
| BOTTOM_TRUNCATED | 指定应仅在一页中显示备注。 |
