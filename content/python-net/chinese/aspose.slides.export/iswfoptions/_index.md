## ISwfOptions 类

提供选项以控制演示文稿以 SWF 格式保存的方式。

ISwfOptions 类型公开以下成员：

## 属性

| Property | Description |
| :- | :- |
| [`compressed`](/slides/python-net/zh/aspose.slides.export/iswfoptions/compressed/) | 指定生成的 SWF 文档是否应压缩。<br/>默认值为 `true`。 |
| [`viewer_included`](/slides/python-net/zh/aspose.slides.export/iswfoptions/viewer_included/) | 指定生成的 SWF 文档是否应包含集成的文档查看器。<br/>默认值为 `true`。 |
| [`show_page_border`](/slides/python-net/zh/aspose.slides.export/iswfoptions/show_page_border/) | 指定是否应显示页面周围的边框。默认值为 true。 |
| [`show_hidden_slides`](/slides/python-net/zh/aspose.slides.export/iswfoptions/show_hidden_slides/) | 指定生成的文档是否应包括隐藏的幻灯片。<br/>默认值为 `false`。 |
| [`show_full_screen`](/slides/python-net/zh/aspose.slides.export/iswfoptions/show_full_screen/) | 显示/隐藏全屏按钮。可以在 flashvars 中覆盖。默认值为 true。 |
| [`show_page_stepper`](/slides/python-net/zh/aspose.slides.export/iswfoptions/show_page_stepper/) | 显示/隐藏页面步进器。可以在 flashvars 中覆盖。默认值为 true。 |
| [`show_search`](/slides/python-net/zh/aspose.slides.export/iswfoptions/show_search/) | 显示/隐藏搜索区域。可以在 flashvars 中覆盖。默认值为 true。 |
| [`show_top_pane`](/slides/python-net/zh/aspose.slides.export/iswfoptions/show_top_pane/) | 显示/隐藏整个顶部面板。可以在 flashvars 中覆盖。默认值为 true。 |
| [`show_bottom_pane`](/slides/python-net/zh/aspose.slides.export/iswfoptions/show_bottom_pane/) | 显示/隐藏底部面板。可以在 flashvars 中覆盖。默认值为 true。 |
| [`show_left_pane`](/slides/python-net/zh/aspose.slides.export/iswfoptions/show_left_pane/) | 显示/隐藏左侧面板。可以在 flashvars 中覆盖。默认值为 true。 |
| [`start_open_left_pane`](/slides/python-net/zh/aspose.slides.export/iswfoptions/start_open_left_pane/) | 启动时左侧面板已打开。可以在 flashvars 中覆盖。默认值为 false。 |
| [`enable_context_menu`](/slides/python-net/zh/aspose.slides.export/iswfoptions/enable_context_menu/) | 启用/禁用上下文菜单。默认值为 true。 |
| [`logo_image_bytes`](/slides/python-net/zh/aspose.slides.export/iswfoptions/logo_image_bytes/) | 将在查看器右上角显示为徽标的图像。<br/>图像应为 32x64 像素的 PNG 图像，否则徽标可能显示不正确。 |
| [`logo_link`](/slides/python-net/zh/aspose.slides.export/iswfoptions/logo_link/) | 获取或设置徽标的完整超链接地址。<br/>仅在指定了 [`ISwfOptions.logo_image_bytes`](/slides/python-net/zh/aspose.slides.export/iswfoptions/logo_image_bytes) 时生效。 |
| [`jpeg_quality`](/slides/python-net/zh/aspose.slides.export/iswfoptions/jpeg_quality/) | 指定 JPEG 图像的质量。<br/>默认值为 95。 |
| [`slides_layout_options`](/slides/python-net/zh/aspose.slides.export/iswfoptions/slides_layout_options/) | 获取或设置在导出演示文稿 [`ISlidesLayoutOptions`](/slides/python-net/zh/aspose.slides.export/islideslayoutoptions) 时幻灯片在页面上的放置模式。<br/>此属性不支持分配类型为 `Aspose.Slides.Export.HandoutLayoutingOptions` 的对象 |
| [`warning_callback`](/slides/python-net/zh/aspose.slides.export/iswfoptions/warning_callback/) |  |
| [`progress_callback`](/slides/python-net/zh/aspose.slides.export/iswfoptions/progress_callback/) |  |
| [`default_regular_font`](/slides/python-net/zh/aspose.slides.export/iswfoptions/default_regular_font/) |  |
