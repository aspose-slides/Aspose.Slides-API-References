## embed_true_type_fonts_for_ascii 属性
确定 Aspose.Slides 是否会为 ASCII (33..127 代码范围) 文本嵌入常用字体。
            字符代码大于 127 的字体始终嵌入。
            常用字体列表包括 PDF 的基本 14 种字体以及用户指定的其他字体。
            读/写 **bool**。


### 备注

默认是 **true** 。
