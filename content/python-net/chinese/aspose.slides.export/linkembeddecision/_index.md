## LinkEmbedDecision 枚举

确定在保存过程中对象将如何处理。

LinkEmbedDecision 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| LINK | 对象将被外部存储，并通过 URL 引用 |
| EMBED | 如果可能，应该将对象嵌入生成的文件中。如果嵌入不可行，将调用 GetUrl，并根据结果将对象通过 URL 引用或忽略。 |
| IGNORE | 对象将被忽略。 |
