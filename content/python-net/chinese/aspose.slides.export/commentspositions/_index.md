## CommentsPositions 枚举

表示将批注渲染到导出文档的规则

CommentsPositions 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| NONE | 指定不应显示任何批注。 |
| BOTTOM | 指定批注应显示在页面底部。 |
| RIGHT | 指定批注应显示在页面右侧。 |
