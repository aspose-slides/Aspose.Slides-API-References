## HandoutType 枚举

指定每页放置多少张幻灯片以及顺序。

HandoutType 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| HANDOUTS1 | 每页一张幻灯片。 |
| HANDOUTS2 | 每页两张幻灯片。 |
| HANDOUTS3 | 每页三张幻灯片。 |
| HANDOUTS_4_HORIZONTAL | 每页四张幻灯片，水平排列。 |
| HANDOUTS_4_VERTICAL | 每页四张幻灯片，垂直排列。 |
| HANDOUTS_6_HORIZONTAL | 每页六张幻灯片，水平排列。 |
| HANDOUTS_6_VERTICAL | 每页六张幻灯片，垂直排列。 |
| HANDOUTS_9_HORIZONTAL | 每页九张幻灯片，水平排列。 |
| HANDOUTS_9_VERTICAL | 每页九张幻灯片，垂直排列。 |
