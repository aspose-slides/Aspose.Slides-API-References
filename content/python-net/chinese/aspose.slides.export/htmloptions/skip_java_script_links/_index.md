## skip_java_script_links 属性
指定在保存演示文稿时是否跳过带有 JavaScript 调用的超链接。

读/写 **bool**。默认值为 **false** .


### 备注

当此属性设置为 **true** 时，保存时将忽略带有 JavaScript 调用的超链接。

当此属性设置为 **false** 时，所有超链接都将被保存。
