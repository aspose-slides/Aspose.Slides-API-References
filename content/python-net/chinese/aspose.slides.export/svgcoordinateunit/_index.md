## SvgCoordinateUnit 枚举

表示用于定义 SVG 坐标的 CSS2 坐标单位。

SvgCoordinateUnit 类型公开以下成员：

## 字段

| Field | Description |
| :- | :- |
| INCH | 英寸 |
| CENTIMETER | 厘米。 |
| MILLIMETER | 毫米。 |
| POINT | 点 (1/72 英寸)， |
| PICA | 派卡 (1/6 英寸)。 |
| EM | 包含元素的字体的 Em 大小。 |
| EX | 包含元素的字体的 Ex 大小（小写字母的大小，通常为 "x"）。 |
| PIXEL | 像素大小。 |
| PERCENT | 百分比。 |
