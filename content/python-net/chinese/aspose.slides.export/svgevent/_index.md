## SvgEvent 枚举

表示 SVG 形状的选项。

SvgEvent 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| ON_FOCUS_IN | 当元素获得焦点时触发，例如文本被选中时。 |
| ON_FOCUS_OUT | 当元素失去焦点时触发，例如文本被取消选中时。 |
| ON_ACTIVATE | 当元素被激活时触发，例如通过鼠标点击或按键。 |
| ON_CLICK | 当指针设备按钮在元素上被点击时触发。 |
| ON_MOUSE_DOWN | 当指针设备按钮在元素上被按下时触发。 |
| ON_MOUSE_UP | 当指针设备按钮在元素上被释放时触发。 |
| ON_MOUSE_OVER | 当指针设备移动到元素上时触发。 |
| ON_MOUSE_MOVE | 当指针设备在元素上移动时触发。 |
| ON_MOUSE_OUT | 当指针设备移出元素时触发。 |
| ON_LOAD | 当用户代理已完全解析该元素及其子元素以及渲染所需的所有引用资源时触发。 |
| ON_UNLOAD | 当 DOM 实现从窗口或框架中移除文档时触发。仅适用于最外层的 svg 元素。 |
| ON_ABORT | 当页面加载在元素完全加载之前被停止时触发。 |
| ON_ERROR | 当元素未能正确加载或脚本执行期间出现错误时触发。 |
| ON_RESIZE | 当文档视图被调整大小时触发。仅适用于最外层的 svg 元素。 |
| ON_SCROLL | 当文档视图沿 X、Y 或两轴移动时触发。仅适用于最外层的 svg 元素。 |
| ON_ZOOM | 当文档视图的缩放级别改变时触发。仅适用于最外层的 svg 元素。 |
| ON_BEGIN | 当动画元素开始时触发。 |
| ON_END | 当动画元素结束时触发。 |
| ON_REPEAT | 当动画元素重复时触发。 |
