## 合规性枚举

指定 PresentationML 文档符合的合规类。

Conformance 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| ECMA_376_2006 | 指定文档符合 ECMA376:2006。 |
| ISO_29500_2008_TRANSITIONAL | 指定文档符合 ISO/IEC 29500:2008 过渡合规类。 |
| ISO_29500_2008_STRICT | 指定文档符合 ISO/IEC 29500:2008 严格合规类。 |
