## embed_true_type_fonts_for_ascii 属性
设为 True 可为 ASCII 字符 32-127 嵌入 TrueType 字体。
字符代码大于 127 的字体始终会被嵌入。
读/写 **bool**.

### 备注

默认是 **true**。
