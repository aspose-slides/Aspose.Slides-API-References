## SvgExternalFontsHandling 枚举

表示处理用于文本绘制的外部字体的方式。

SvgExternalFontsHandling 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| ADD_LINKS_TO_FONT_FILES | 将指向单独字体文件的链接添加到 SVG 文件的 style 部分。 |
| EMBED | 将字体数据直接保存到 SVG 文件中。使用此选项前请检查所有外部字体的许可协议。 |
| VECTORIZE | 将使用外部字体的所有文本保存为图形。 |
