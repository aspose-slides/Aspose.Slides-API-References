## gap_width 属性
指定条形图或柱形图簇之间的空间，作为条形图或柱形图宽度的百分比。  
该属性不仅适用于此序列，而且适用于父系列组的所有序列——这是相应组属性的投影。因此该属性是只读的。  
使用 ParentSeriesGroup 属性访问父系列组。  
使用 ParentSeriesGroup.GapWidth 可读写属性来更改值。  
只读 **int**。

### 备注

这是属性 ParentSeriesGroup.GapWidth 的投影。
