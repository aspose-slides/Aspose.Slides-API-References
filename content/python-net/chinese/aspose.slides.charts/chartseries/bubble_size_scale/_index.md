## bubble_size_scale 属性
指定气泡图的缩放因子 (可在默认大小的 0% 到 300% 之间)。
            此属性不仅适用于此序列，还适用于父序列组的所有序列
            group - 这是相应组属性的投射。并且此属性
            为只读。
            使用 ParentSeriesGroup 属性来访问父序列组。
            使用 ParentSeriesGroup.BubbleSizeScale 读/写 属性来更改值。


### 备注

这是属性 ParentSeriesGroup.BubbleSizeScale 的投射。
