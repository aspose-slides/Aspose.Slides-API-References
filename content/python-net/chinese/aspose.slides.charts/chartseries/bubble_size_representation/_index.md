## bubble_size_representation 属性
指定气泡图上气泡大小值的表示方式。
            该属性不仅适用于此系列，还适用于父系列组的所有系列——它是相应组属性的投影。因此该属性为只读。
            使用 ParentSeriesGroup 属性访问父系列组。
            使用 ParentSeriesGroup.BubbleSizeRepresentation 读/写属性来更改值。

### 备注

这是属性 ParentSeriesGroup.BubbleSizeRepresentation 的投影。
