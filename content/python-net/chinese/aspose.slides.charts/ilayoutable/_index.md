## ILayoutable 类

指定图表元素的精确位置。

ILayoutable 类型公开以下成员：

## 属性

| Property | Description |
| :- | :- |
| [`x`](/slides/python-net/zh/aspose.slides.charts/ilayoutable/x/) | 指定图表元素的 x 位置（左侧），该位置是图表宽度的比例。<br/>            可读写 **float**. |
| [`y`](/slides/python-net/zh/aspose.slides.charts/ilayoutable/y/) | 指定图表元素的顶部位置，该位置是图表高度的比例。<br/>            可读写 **float**. |
| [`width`](/slides/python-net/zh/aspose.slides.charts/ilayoutable/width/) | 指定图表元素的宽度，该宽度是图表宽度的比例。<br/>            可读写 **float**. |
| [`height`](/slides/python-net/zh/aspose.slides.charts/ilayoutable/height/) | 指定图表元素的高度，该高度是图表高度的比例。<br/>            可读写 **float**. |
| [`right`](/slides/python-net/zh/aspose.slides.charts/ilayoutable/right/) | 获取图表元素的右侧位置，该位置是图表宽度的比例。<br/>            只读 **float**. |
| [`bottom`](/slides/python-net/zh/aspose.slides.charts/ilayoutable/bottom/) | 获取图表元素的顶部位置，该位置是图表高度的比例。<br/>            只读 **float**. |
