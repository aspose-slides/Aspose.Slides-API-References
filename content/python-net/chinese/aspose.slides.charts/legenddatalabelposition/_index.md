## LegendDataLabelPosition 枚举

确定数据标签的位置。

LegendDataLabelPosition 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| NOT_DEFINED | 未定义位置。 |
| BOTTOM | 指定数据标签应显示在数据标记的下方。 |
| BEST_FIT | 指定数据标签应显示在最佳位置。 |
| CENTER | 指定数据标签应居中显示在数据标记上。 |
| INSIDE_BASE | 指定数据标签应显示在数据标记的基部内部。 |
| INSIDE_END | 指定数据标签应显示在数据标记的末端内部。 |
| LEFT | 指定数据标签应显示在数据标记的左侧。 |
| OUTSIDE_END | 指定数据标签应显示在数据标记的末端外部。 |
| RIGHT | 指定数据标签应显示在数据标记的右侧。 |
| TOP | 指定数据标签应显示在数据标记的上方。 |
