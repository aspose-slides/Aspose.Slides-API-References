## LegendEntryCollection 类

表示图例集合。

LegendEntryCollection 类型公开以下成员：

## 属性

| Property | Description |
| :- | :- |
| [`count`](/slides/python-net/zh/aspose.slides.charts/legendentrycollection/count/) | 获取图例条目的数量。<br/>            只读 **int**。 |

获取对应于 Chart.ChartData.Series[0].DataPoints[index] 的图例条目的属性，适用于以下图表类型：
              ChartType.BarOfPie,
              ChartType.ExplodedPie,
              ChartType.ExplodedPie3D,
              ChartType.Pie,
              ChartType.Pie3D,
              ChartType.PieOfPie;
            或对应于 Chart.ChartData.Series[index] 的其他图表类型。
