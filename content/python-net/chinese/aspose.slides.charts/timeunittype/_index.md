## TimeUnitType 枚举

表示分类轴的基本单位

TimeUnitType 类型公开以下成员：

## 字段

| Field | Description |
| :- | :- |
| NONE | 值将按原样显示。 |
| DAYS | 指定图表数据应以天为单位显示。 |
| MONTHS | 指定图表数据应以月为单位显示。 |
| YEARS | 指定图表数据应以年为单位显示。 |
