## TickMarkType 枚举

表示指定坐标轴的刻度线类型。

TickMarkType 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| CROSS | 指定刻度线应跨越坐标轴。 |
| INSIDE | 指定刻度线应位于绘图区域内部。 |
| NONE | 指定不应有刻度线。 |
| OUTSIDE | 指定刻度线应位于绘图区域外部。 |
