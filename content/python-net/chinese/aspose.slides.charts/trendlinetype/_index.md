## TrendlineType 枚举

表示趋势线的类型

TrendlineType 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| EXPONENTIAL | 指定趋势线应为指数曲线的形式。 |
| LINEAR | 指定趋势线应为直线的形式。 |
| LOGARITHMIC | 指定趋势线应为对数曲线的形式，其中 log 为自然对数。 |
| MOVING_AVERAGE | 指定趋势线应为周期为 Period 的移动平均。 |
| POLYNOMIAL | 指定趋势线应为阶数为 Order 的多项式曲线的形式。 |
| POWER | 指定趋势线应为幂曲线的形式。 |
