## TickLabelPositionType 枚举

表示指定坐标轴上刻度标签的位置类型。

TickLabelPositionType 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| HIGH | 指定坐标轴标签应位于垂直轴的高端。 |
| LOW | 指定坐标轴标签应位于垂直轴的低端。 |
| NEXT_TO | 指定坐标轴标签应紧邻坐标轴。 |
| NONE | 指定坐标轴标签不绘制。 |
