## ParentLabelLayoutType 枚举

表示类目数据标签的布局。仅在 Treemap 系列中使用。

ParentLabelLayoutType 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| BANNER | 指定父类别标签显示为横幅 |
| NONE | 指定不绘制父类别标签 |
| OVERLAPPING | 指定父类别标签显示为重叠 |
