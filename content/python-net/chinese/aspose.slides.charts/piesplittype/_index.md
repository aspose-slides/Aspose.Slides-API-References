## PieSplitType 枚举

表示在饼中饼或柱中柱图表上的第二饼或柱的拆分点类型。

PieSplitType 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| DEFAULT | 指定数据点应使用此图表类型的默认 <br/> 机制进行拆分。 |
| CUSTOM | 指定数据点应根据自定义拆分值在 <br/> 饼图和第二图表之间进行拆分。 |
| BY_PERCENTAGE | 指定数据点应在饼图和 <br/> 第二图表之间拆分，通过将百分比小于 <br/> 拆分位置百分比的点放入第二图表。 |
| BY_POS | 指定数据点应在饼图和 <br/> 第二图表之间拆分，通过将数据点的最后拆分位置 <br/> 放入第二图表。 |
| BY_VALUE | 指定数据点应在饼图和 <br/> 第二图表之间拆分，通过将值小于 <br/> 拆分位置的数据点放入第二图表。 |
