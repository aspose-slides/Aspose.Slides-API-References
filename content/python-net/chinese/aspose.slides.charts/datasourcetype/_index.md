## DataSourceType 枚举

数据源类型。

DataSourceType 类型公开以下成员：

## 字段

| 字段 | 说明 |
| :- | :- |
| WORKSHEET | 使用 CellXls 对象在工作表中存储数据点的 XValue、YValue、Value 或 BubbleSize。 |
| STRING_LITERALS | 使用快速访问的字符串变量存储 XValue、YValue、Value 或 BubbleSize 的 <br/>            数据点。工作表未用于存储值。 |
| DOUBLE_LITERALS | 使用快速访问的 double 变量存储 XValue、YValue、Value 或 BubbleSize 的 <br/>            数据点。工作表未用于存储值。 |
