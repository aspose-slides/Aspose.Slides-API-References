## layout_target_type 属性
If layout of the plot area defined manually this property specifies whether 
             按其内部布局绘图区域（不包括坐标轴和坐标轴标签）或按外部布局（包括坐标轴和坐标轴标签）。
             读/写 [`ChartPlotArea.layout_target_type`](/slides/python-net/zh/aspose.slides.charts/chartplotarea/layout_target_type).
