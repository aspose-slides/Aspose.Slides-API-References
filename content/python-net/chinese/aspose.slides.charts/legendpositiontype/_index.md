## LegendPositionType 枚举

确定图表中图例的位置。

LegendPositionType 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| BOTTOM | 指定图例应绘制在图表的底部。 |
| LEFT | 指定图例应绘制在图表的左侧。 |
| RIGHT | 指定图例应绘制在图表的右侧。 |
| TOP | 指定图例应绘制在图表的顶部。 |
| TOP_RIGHT | 指定图例应绘制在图表的右上角。 |
