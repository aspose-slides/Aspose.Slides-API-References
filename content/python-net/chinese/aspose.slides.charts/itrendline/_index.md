## ITrendline 类

类表示图表系列的趋势线

ITrendline 类型公开以下成员：

## 属性

| Property | Description |
| :- | :- |
| [`trendline_name`](/slides/python-net/zh/aspose.slides.charts/itrendline/trendline_name/) | 获取或设置趋势线的名称。<br/>            读/写 **str**. |
| [`trendline_type`](/slides/python-net/zh/aspose.slides.charts/itrendline/trendline_type/) | 获取或设置趋势线类型。<br/>            读/写 [`ITrendline.trendline_type`](/slides/python-net/zh/aspose.slides.charts/itrendline/trendline_type). |
| [`format`](/slides/python-net/zh/aspose.slides.charts/itrendline/format/) | 表示趋势线的格式。<br/>            读/写 [`IFormat`](/slides/python-net/zh/aspose.slides.charts/iformat). |
| [`backward`](/slides/python-net/zh/aspose.slides.charts/itrendline/backward/) | 指定趋势线在系列数据之前延伸的类别（或散点图上的单位）数量。对于散点图和非散点图，值必须为非负值。<br/>            读/写 **float**. |
| [`forward`](/slides/python-net/zh/aspose.slides.charts/itrendline/forward/) | 指定趋势线在系列数据之后延伸的类别（或散点图上的单位）数量。对于散点图和非散点图，值必须为非负值。<br/>            读/写 **float**. |
| [`intercept`](/slides/python-net/zh/aspose.slides.charts/itrendline/intercept/) | 指定趋势线交叉 y 轴的值。仅在趋势线类型为 exp、linear 或 poly 时支持此属性。<br/>            读/写 **float**. |
| [`display_equation`](/slides/python-net/zh/aspose.slides.charts/itrendline/display_equation/) | 指定是否在图表上显示趋势线方程（与 Rsquaredvalue 位于同一标签）。<br/>            读/写 **bool**. |
| [`order`](/slides/python-net/zh/aspose.slides.charts/itrendline/order/) | 指定多项式趋势线的阶数。对其他趋势线类型忽略此设置。值必须介于 2 到 6 之间。<br/>            读/写 **int**. |
| [`period`](/slides/python-net/zh/aspose.slides.charts/itrendline/period/) | 指定移动平均趋势线的周期。对其他趋势线变体忽略此设置。值必须介于 2 到 255 之间。<br/>            读/写 **int**. |
| [`display_r_squared_value`](/slides/python-net/zh/aspose.slides.charts/itrendline/display_r_squared_value/) | 指定是否在图表上显示趋势线的 R 平方值（与方程位于同一标签）。<br/>            读/写 **bool**. |
| [`related_legend_entry`](/slides/python-net/zh/aspose.slides.charts/itrendline/related_legend_entry/) | 表示与此趋势线相关的图例项<br/>            只读 [`ILegendEntryProperties`](/slides/python-net/zh/aspose.slides.charts/ilegendentryproperties). |
| [`text_frame_for_overriding`](/slides/python-net/zh/aspose.slides.charts/itrendline/text_frame_for_overriding/) |  |
