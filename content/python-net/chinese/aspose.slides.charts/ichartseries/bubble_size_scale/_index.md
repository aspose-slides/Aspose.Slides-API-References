## bubble_size_scale 属性
指定气泡图的比例因子（可以在默认尺寸的0%到300%之间）。
此属性不仅属于此序列，还属于父序列组的所有序列——这是相应组属性的投影。
因此此属性为只读。
使用 ParentSeriesGroup 属性访问父序列组。
使用 ParentSeriesGroup.BubbleSizeScale 可读写属性来更改值。


### 备注

这是属性 ParentSeriesGroup.BubbleSizeScale 的投影。
