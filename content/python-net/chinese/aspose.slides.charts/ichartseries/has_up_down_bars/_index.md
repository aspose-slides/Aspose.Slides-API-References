## has_up_down_bars 属性
确定折线图或股票图是否具有上下条形。
            该属性不仅适用于此序列，还适用于父序列组的所有序列
            ——这是相应组属性的投影。因此此属性为只读。
            使用 ParentSeriesGroup 属性访问父序列组。
            使用 ParentSeriesGroup.UpDownBars.HasUpDownBars 读写属性来更改值。
            使用 ParentSeriesGroup.UpDownBars 属性来设置上下条形的格式。
            只读 **bool**。


### 备注

这是属性 ParentSeriesGroup.UpDownBars.HasUpDownBars 的投影。
