## bubble_size_representation 属性
指定气泡图中气泡大小值的表示方式。
            此属性不仅适用于此序列，还适用于父序列组的所有序列——这是相应组属性的投影。因此此属性为只读。
            使用 ParentSeriesGroup 属性访问父系列组。
            使用 ParentSeriesGroup.BubbleSizeRepresentation 可读写属性来更改值。

### 备注

这是属性 ParentSeriesGroup.BubbleSizeRepresentation 的投影。
