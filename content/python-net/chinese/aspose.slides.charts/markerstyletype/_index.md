## MarkerStyleType 枚举

确定图表数据点上标记的形状。

MarkerStyleType 类型公开以下成员：

## 字段

| Field | Description |
| :- | :- |
| NOT_DEFINED |  |
| CIRCLE | 指定在每个数据点上绘制一个圆形。 |
| DASH | 指定在每个数据点上绘制一条短划线。 |
| DIAMOND | 指定在每个数据点上绘制一个菱形。 |
| DOT | 指定在每个数据点上绘制一个点。 |
| NONE | 指定在每个数据点上不绘制任何内容。 |
| PICTURE | 指定在每个数据点上绘制一幅图片。 |
| PLUS | 指定在每个数据点上绘制一个加号。 |
| SQUARE | 指定在每个数据点上绘制一个正方形。 |
| STAR | 指定在每个数据点上绘制一个星形。 |
| TRIANGLE | 指定在每个数据点上绘制一个三角形。 |
| X | 指定在每个数据点上绘制一个 X。 |
