## hide(self) {#}
通过将所有 Show*-flags（ShowValue，...）设置为 false 状态，使
            DefaultDataLabelFormat 属性的数据标签默认隐藏。
            IsVisible 将为 false。


```python
def hide(self):
    ...
```


### 备注

如果数据标签默认不可见（IsVisible 为 false），您可以使数据标签“可见 
            默认”通过设置 DefaultDataLabelFormat 属性的 Show*-flags（ShowValue，...）
            为 true 状态。
