## default_label_shape_type 属性
获取或设置数据标签的默认形状类型。
如果未定义形状，则返回 [`ShapeType.NOT_DEFINED`](/slides/python-net/zh/aspose.slides/shapetype/NOT_DEFINED)。


### 备注

设置此属性还会将集合中所有数据标签的 [`IDataLabel.label_shape_type`](/slides/python-net/zh/aspose.slides.charts/idatalabel/label_shape_type) 属性设置为相同的值。
