## IChartCellCollection 类

表示包含数据的单元格集合。

IChartCellCollection 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`count`](/slides/python-net/zh/aspose.slides.charts/ichartcellcollection/count/) | 获取集合中单元格的数量。<br/>            只读 **int**. |

通过索引返回一个单元格 (IChartDataCell)。

## 索引器

| 名称 | 描述 |
| :- | :- |
| [`[index]`](/slides/python-net/zh/aspose.slides.charts/ichartcellcollection/__getitem__/) | Index of a cell. |
