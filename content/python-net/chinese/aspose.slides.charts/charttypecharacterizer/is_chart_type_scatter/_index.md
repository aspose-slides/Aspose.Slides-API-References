## is_chart_type_scatter(chart_type) {#charttype}
如果 chartType 是 Scatter 子类型之一，则返回 true。
            子类型集合对应 PowerPoint 中的相应集合（参见 PowerPoint 中的 “Change Chart Type” 对话框）：
            [`ChartType.SCATTER_WITH_MARKERS`](/slides/python-net/zh/aspose.slides.charts/charttype/SCATTER_WITH_MARKERS),
            [`ChartType.SCATTER_WITH_SMOOTH_LINES`](/slides/python-net/zh/aspose.slides.charts/charttype/SCATTER_WITH_SMOOTH_LINES),
            [`ChartType.SCATTER_WITH_SMOOTH_LINES_AND_MARKERS`](/slides/python-net/zh/aspose.slides.charts/charttype/SCATTER_WITH_SMOOTH_LINES_AND_MARKERS),
            [`ChartType.SCATTER_WITH_STRAIGHT_LINES`](/slides/python-net/zh/aspose.slides.charts/charttype/SCATTER_WITH_STRAIGHT_LINES),
            [`ChartType.SCATTER_WITH_STRAIGHT_LINES_AND_MARKERS`](/slides/python-net/zh/aspose.slides.charts/charttype/SCATTER_WITH_STRAIGHT_LINES_AND_MARKERS)。
