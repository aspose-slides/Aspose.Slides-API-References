## PictureType 枚举

确定条形图片填充的模式。

PictureType 类型公开以下成员：

## 字段

| Field | Description |
| :- | :- |
| NOT_DEFINED | 未定义。 |
| STACK | 图片的大小设置为在最长的堆叠条形中最多重复 15 次。 |
| STACK_SCALE | 图片的大小设置为指定的单位数，并沿条形的长度重复。 |
| STRETCH | 图片在堆叠条形的整个长度上被拉伸。 |
