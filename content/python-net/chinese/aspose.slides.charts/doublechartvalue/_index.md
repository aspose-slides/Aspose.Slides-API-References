## DoubleChartValue 类

表示可以在pptx演示文稿中存储的双精度值，有两种方式：
1) 在与图表相关的工作簿的单元格中；
2) 作为文字值。

**继承:**[`DoubleChartValue`](/slides/python-net/zh/aspose.slides.charts/doublechartvalue) → [`BaseChartValue`](/slides/python-net/zh/aspose.slides.charts/basechartvalue)

## 属性

| Property | Description |
| :- | :- |
| [`data_source_type`](/slides/python-net/zh/aspose.slides.charts/doublechartvalue/data_source_type/) | 指定在派生类中实际使用的是 AsCell、AsCells、AsLiteralString 还是 AsLiteralDouble <br/>            属性。换句话说，它指定 Data 属性的值类型。<br/>            读取/写入 [`DataSourceType`](/slides/python-net/zh/aspose.slides.charts/datasourcetype)。 |
| [`data`](/slides/python-net/zh/aspose.slides.charts/doublechartvalue/data/) | 返回或设置 Data 对象。<br/>            读取/写入 **any**。 |
| [`as_cell`](/slides/python-net/zh/aspose.slides.charts/doublechartvalue/as_cell/) | 返回或设置图表数据单元格。<br/>            读取/写入 [`IChartDataCell`](/slides/python-net/zh/aspose.slides.charts/ichartdatacell)。 |
| [`as_literal_double`](/slides/python-net/zh/aspose.slides.charts/doublechartvalue/as_literal_double/) | 返回或设置作为文字双精度的值。<br/>            读取/写入 **float**。 |
