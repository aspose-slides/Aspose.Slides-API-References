## ChartDataPointCollection 类

表示系列数据点的集合。

ChartDataPointCollection 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`data_source_type_for_x_values`](/slides/python-net/zh/aspose.slides.charts/chartdatapointcollection/data_source_type_for_x_values/) | 指定 AsCell、AsLiteralString 或 AsLiteralDouble 属性在数据点 XValue 属性对象中是否实际存在。换句话说，它指定 ChartDataPoint.XValue.Data 属性的值类型。<br/>            读/写 [`DataSourceType`](/slides/python-net/zh/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_y_values`](/slides/python-net/zh/aspose.slides.charts/chartdatapointcollection/data_source_type_for_y_values/) | 指定 AsCell、AsLiteralString 或 AsLiteralDouble 属性在数据点 YValue 属性对象中是否实际存在。换句话说，它指定 ChartDataPoint.YValue.Data 属性的值类型。<br/>            读/写 [`DataSourceType`](/slides/python-net/zh/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_bubble_sizes`](/slides/python-net/zh/aspose.slides.charts/chartdatapointcollection/data_source_type_for_bubble_sizes/) | 指定 AsCell、AsLiteralString 或 AsLiteralDouble 属性在数据点 BubbleSize 属性对象中是否实际存在。换句话说，它指定 ChartDataPoint.BubbleSize.Data 属性的值类型。<br/>            读/写 [`DataSourceType`](/slides/python-net/zh/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_values`](/slides/python-net/zh/aspose.slides.charts/chartdatapointcollection/data_source_type_for_values/) | 指定 AsCell、AsLiteralString 或 AsLiteralDouble 属性在数据点 Value 属性对象中是否实际存在。换句话说，它指定 ChartDataPoint.Value.Data 属性的值类型。<br/>            读/写 [`DataSourceType`](/slides/python-net/zh/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_error_bars_custom_values`](/slides/python-net/zh/aspose.slides.charts/chartdatapointcollection/data_source_type_for_error_bars_custom_values/) | 指定 ChartDataPoint.ErrorBarsCustomValues 属性列表中值的类型。<br/>            只读 [`IDataSourceTypeForErrorBarsCustomValues`](/slides/python-net/zh/aspose.slides.charts/idatasourcetypeforerrorbarscustomvalues). |
