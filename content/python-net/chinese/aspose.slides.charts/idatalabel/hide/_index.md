## hide(self) {#}
通过将所有 Show*-标志 (ShowValue, ...) 设置为 false 状态，使数据标签隐藏。
            执行此操作后 IsVisible 将为 false。

```python
def hide(self):
    ...
```

### 备注

如果数据标签不可见 (IsVisible 为 false)，可以
            通过将 Show*-标志 (ShowValue, ...) 设置为 true 状态，使数据标签可见。
