## ChartCellCollection 类

表示一个包含数据的单元格集合。

ChartCellCollection 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`count`](/slides/python-net/zh/aspose.slides.charts/chartcellcollection/count/) | 获取集合中单元格的计数。<br/>            只读 **int**。 |

通过索引返回一个单元格 (IChartDataCell)。

## 索引器

| 名称 | 描述 |
| :- | :- |
| [`[index]`](/slides/python-net/zh/aspose.slides.charts/chartcellcollection/__getitem__/) | 单元格的索引。 |

| 方法 | 描述 |
