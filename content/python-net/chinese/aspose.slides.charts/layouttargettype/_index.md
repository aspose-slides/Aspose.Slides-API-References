## LayoutTargetType 枚举

如果手动定义绘图区域的布局，此属性指定是按内部布局绘图区域（不包括轴和轴标签）还是外部布局（包括轴和轴标签）。

LayoutTargetType 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| INNER | 指定绘图区域的大小应决定绘图区域的大小，<br/>不包括刻度线和<br/>轴标签。 |
| OUTER | 指定绘图区域的大小应决定绘图区域的大小，<br/>刻度线和<br/>轴标签。 |
