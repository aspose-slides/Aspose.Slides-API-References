## ChartShapeType 枚举

表示图表的形状。

ChartShapeType 类型公开以下成员：

## 字段

| Field | Description |
| :- | :- |
| NOT_DEFINED | 图表形状未定义。 |
| BOX | 指定图表应使用盒形绘制。 |
| CONE | 指定图表应绘制为圆锥形，圆锥的底部位于地面，圆锥的尖端位于数据标记的顶部。 |
| CONE_TO_MAX | 指定图表应绘制为截断的圆锥，使圆锥的尖端对应最大数据值。 |
| CYLINDER | 指定图表应绘制为圆柱体。 |
| PYRAMID | 指定图表应绘制为矩形金字塔，金字塔的底部位于地面，金字塔的尖端位于数据标记的顶部。 |
| PYRAMID_TO_MAXIMUM | 指定图表应绘制为截断的圆锥，使圆锥的尖端对应最大数据值。 |
