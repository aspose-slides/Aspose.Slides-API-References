## Legend 类

表示图表图例属性。

Legend 类型公开以下成员：

## 属性

| Property | Description |
| :- | :- |
| [`x`](/slides/python-net/zh/aspose.slides.charts/legend/x/) | 返回或设置图例的 x 坐标，以图表宽度的比例表示。<br/>读写 **float**. |
| [`y`](/slides/python-net/zh/aspose.slides.charts/legend/y/) | 返回或设置图例的 y 坐标，以图表高度的比例表示。<br/>读写 **float**. |
| [`width`](/slides/python-net/zh/aspose.slides.charts/legend/width/) | 返回或设置图例的宽度，以图表宽度的比例表示。<br/>读写 **float**. |
| [`height`](/slides/python-net/zh/aspose.slides.charts/legend/height/) | 返回或设置图例的高度，以图表高度的比例表示。<br/>读写 **float**. |
| [`right`](/slides/python-net/zh/aspose.slides.charts/legend/right/) | 右。<br/>只读 **float**. |
| [`bottom`](/slides/python-net/zh/aspose.slides.charts/legend/bottom/) | 底部。<br/>只读 **float**. |
| [`overlay`](/slides/python-net/zh/aspose.slides.charts/legend/overlay/) | 确定是否允许其他图表元素覆盖图例。<br/>读写 **bool**. |
| [`text_format`](/slides/python-net/zh/aspose.slides.charts/legend/text_format/) | 文本格式。<br/>只读 [`IChartTextFormat`](/slides/python-net/zh/aspose.slides.charts/icharttextformat). |
| [`position`](/slides/python-net/zh/aspose.slides.charts/legend/position/) | 指定图例在图表上的位置。<br/>X、Y、Width、Heigt 属性的非 NaN 值会覆盖此属性的效果。<br/>读写 [`LegendPositionType`](/slides/python-net/zh/aspose.slides.charts/legendpositiontype). |
| [`format`](/slides/python-net/zh/aspose.slides.charts/legend/format/) | 返回图例的格式。<br/>只读 [`IFormat`](/slides/python-net/zh/aspose.slides.charts/iformat). |
| [`chart`](/slides/python-net/zh/aspose.slides.charts/legend/chart/) | 返回图表。<br/>只读 [`IChart`](/slides/python-net/zh/aspose.slides.charts/ichart). |
| [`entries`](/slides/python-net/zh/aspose.slides.charts/legend/entries/) | 获取图例条目。<br/>只读 [`ILegendEntryCollection`](/slides/python-net/zh/aspose.slides.charts/ilegendentrycollection). |
| [`actual_x`](/slides/python-net/zh/aspose.slides.charts/legend/actual_x/) | 指定图表元素相对于图表左上角的实际 x 位置（左）。<br/>在获取实际值之前请调用方法 IChart.ValidateChartLayout()。<br/>读取 **float**. |
| [`actual_y`](/slides/python-net/zh/aspose.slides.charts/legend/actual_y/) | 指定图表元素相对于图表左上角的实际顶部位置。<br/>在获取实际值之前请调用方法 IChart.ValidateChartLayout()。<br/>读取 **float**. |
| [`actual_width`](/slides/python-net/zh/aspose.slides.charts/legend/actual_width/) | 指定图表元素的实际宽度。调用方法 IChart.ValidateChartLayout() 之后获取实际值。<br/>读取 **float**. |
| [`actual_height`](/slides/python-net/zh/aspose.slides.charts/legend/actual_height/) | 指定图表元素的实际高度。调用方法 IChart.ValidateChartLayout() 之后获取实际值。<br/>读取 **float**. |
