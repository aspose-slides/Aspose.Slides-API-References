## ChartType 枚举

表示一种图表类型。

ChartType 类型公开以下成员：

## 字段

| Field | Description |
| :- | :- |
| CLUSTERED_COLUMN | 表示簇状柱形图。 |
| STACKED_COLUMN | 表示堆积柱形图。 |
| PERCENTS_STACKED_COLUMN | 表示 100% 堆积柱形图。 |
| CLUSTERED_COLUMN_3D | 表示 3D 簇状柱形图。 |
| STACKED_COLUMN_3D | 表示 3D 堆积柱形图。 |
| PERCENTS_STACKED_COLUMN_3D | 表示 3D 100% 堆积柱形图。 |
| COLUMN_3D | 表示 3D 柱形图。 |
| CLUSTERED_CYLINDER | 表示圆柱图。 |
| STACKED_CYLINDER | 表示堆积圆柱图。 |
| PERCENTS_STACKED_CYLINDER | 表示 100% 堆积圆柱图。 |
| CYLINDER_3D | 表示 3D 圆柱图。 |
| CLUSTERED_CONE | 表示圆锥图。 |
| STACKED_CONE | 表示堆积圆锥图。 |
| PERCENTS_STACKED_CONE | 表示 100% 堆积圆锥图。 |
| CONE_3D | 表示 3D 圆锥图。 |
| CLUSTERED_PYRAMID | 表示金字塔图。 |
| STACKED_PYRAMID | 表示堆积金字塔图。 |
| PERCENTS_STACKED_PYRAMID | 表示 100% 堆积金字塔图。 |
| PYRAMID_3D | 表示 3D 金字塔图。 |
| LINE | 表示折线图。 |
| STACKED_LINE | 表示堆积折线图。 |
| PERCENTS_STACKED_LINE | 表示 100% 堆积折线图。 |
| LINE_WITH_MARKERS | 表示带数据标记的折线图。 |
| STACKED_LINE_WITH_MARKERS | 表示带数据标记的堆积折线图。 |
| PERCENTS_STACKED_LINE_WITH_MARKERS | 表示带数据标记的 100% 堆积折线图。 |
| LINE_3D | 表示 3D 折线图。 |
| PIE | 表示饼图。 |
| PIE_3D | 表示 3D 饼图。 |
| PIE_OF_PIE | 表示嵌套饼图。 |
| EXPLODED_PIE | 表示炸裂饼图。 |
| EXPLODED_PIE_3D | 表示 3D 炸裂饼图。 |
| BAR_OF_PIE | 表示条形饼图。 |
| PERCENTS_STACKED_BAR | 表示 100% 堆积条形图。 |
| CLUSTERED_BAR_3D | 表示 3D 簇状条形图。 |
| CLUSTERED_BAR | 表示簇状条形图。 |
| STACKED_BAR | 表示堆积条形图。 |
| STACKED_BAR_3D | 表示 3D 堆积条形图。 |
| PERCENTS_STACKED_BAR_3D | 表示 3D 100% 堆积条形图。 |
| CLUSTERED_HORIZONTAL_CYLINDER | 表示圆柱条形图。 |
| STACKED_HORIZONTAL_CYLINDER | 表示堆积圆柱条形图。 |
| PERCENTS_STACKED_HORIZONTAL_CYLINDER | 表示 100% 堆积圆柱条形图。 |
| CLUSTERED_HORIZONTAL_CONE | 表示圆锥条形图。 |
| STACKED_HORIZONTAL_CONE | 表示堆积圆锥条形图。 |
| PERCENTS_STACKED_HORIZONTAL_CONE | 表示 100% 堆积圆锥条形图。 |
| CLUSTERED_HORIZONTAL_PYRAMID | 表示金字塔条形图。 |
| STACKED_HORIZONTAL_PYRAMID | 表示堆积金字塔条形图。 |
| PERCENTS_STACKED_HORIZONTAL_PYRAMID | 表示 100% 堆积金字塔条形图。 |
| AREA | 表示面积图。 |
| STACKED_AREA | 表示堆积面积图。 |
| PERCENTS_STACKED_AREA | 表示 100% 堆积面积图。 |
| AREA_3D | 表示 3D 面积图。 |
| STACKED_AREA_3D | 表示 3D 堆积面积图。 |
| PERCENTS_STACKED_AREA_3D | 表示 3D 100% 堆积面积图。 |
| SCATTER_WITH_MARKERS | 表示带数据标记的散点图。 |
| SCATTER_WITH_SMOOTH_LINES_AND_MARKERS | 表示带平滑线和数据标记的散点图。 |
| SCATTER_WITH_SMOOTH_LINES | 表示带平滑线的散点图。 |
| SCATTER_WITH_STRAIGHT_LINES_AND_MARKERS | 表示带直线和数据标记的散点图。 |
| SCATTER_WITH_STRAIGHT_LINES | 表示带直线的散点图。 |
| HIGH_LOW_CLOSE | 表示高低收盘股票图。 |
| OPEN_HIGH_LOW_CLOSE | 表示开盘-高-低-收盘股票图。 |
| VOLUME_HIGH_LOW_CLOSE | 表示成交量-高-低-收盘股票图。 |
| VOLUME_OPEN_HIGH_LOW_CLOSE | 表示成交量-开盘-高-低-收盘股票图。 |
| SURFACE_3D | 表示 3D 曲面图。 |
| WIREFRAME_SURFACE_3D | 表示 3D 线框曲面图。 |
| CONTOUR | 表示等高线图。 |
| WIREFRAME_CONTOUR | 表示线框等高线图。 |
| DOUGHNUT | 表示环形图。 |
| EXPLODED_DOUGHNUT | 表示炸裂环形图。 |
| BUBBLE | 表示气泡图。 |
| BUBBLE_WITH_3D | 表示 3D 气泡图。 |
| RADAR | 表示雷达图。 |
| RADAR_WITH_MARKERS | 表示带数据标记的雷达图。 |
| FILLED_RADAR | 表示填充雷达图。 |
| SERIES_OF_MIXED_TYPES | 此值仅能由 ChartEx.Type 属性返回。<br/>            这意味着图表具有混合类型的系列。 |
| TREEMAP | 表示树图。 |
| SUNBURST | 表示旭日图。 |
| HISTOGRAM | 表示直方图。 |
| PARETO_LINE | 表示帕累托线系列类型（直方图帕累托图）。 |
| BOX_AND_WHISKER | 表示箱线图。 |
| WATERFALL | 表示瀑布图。 |
| FUNNEL | 表示漏斗图。 |
| MAP | 表示地图图。 |
