## WorkbookType 枚举

指定 Open XML 工作簿文件的类型。

WorkbookType 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| NOT_DEFINED | 工作簿类型未定义。 |
| WORKBOOK | Excel 工作簿 (*.xlsx)。 |
| WORKBOOK_MACRO | Excel 启用宏的工作簿 (*.xlsm)。 |
| TEMPLATE | Excel 模板 (*.xltx)。 |
| TEMPLATE_MACRO | Excel 启用宏的模板 (*.xltm)。 |
| WORKBOOK_BINARY_MACRO | Excel 二进制启用宏的工作簿 (*.xlsb)。 |
