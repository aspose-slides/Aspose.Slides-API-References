## IChartTextFormat 类

图表操作使用受限的一组文本格式属性。  
IChartTextFormat、IChartTextBlockFormat、IChartParagraphFormat、IChartPortionFormat 接口描述了此受限集合。

IChartTextFormat 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`text_block_format`](/slides/python-net/zh/aspose.slides.charts/icharttextformat/text_block_format/) | 返回图表文本元素的格式。<br/>            只读 [`IChartTextBlockFormat`](/slides/python-net/zh/aspose.slides.charts/icharttextblockformat)。 |
| [`paragraph_format`](/slides/python-net/zh/aspose.slides.charts/icharttextformat/paragraph_format/) | 返回段落格式。<br/>            只读 [`IChartParagraphFormat`](/slides/python-net/zh/aspose.slides.charts/ichartparagraphformat)。 |
| [`portion_format`](/slides/python-net/zh/aspose.slides.charts/icharttextformat/portion_format/) | 返回部分格式。<br/>            只读 [`IChartPortionFormat`](/slides/python-net/zh/aspose.slides.charts/ichartportionformat)。 |
