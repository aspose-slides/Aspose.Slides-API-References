## x_minus 属性
指定负方向的误差线值。 
如果 error bars value type 为 Custom 且允许 ErrorBarsXFormat，则可用。 
在任何其他情况下，此属性返回 None。 
只读 [`IDoubleChartValue`](/slides/python-net/zh/aspose.slides.charts/idoublechartvalue).
