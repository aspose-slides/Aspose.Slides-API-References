## DisplayUnitType 枚举

确定显示数据的倍数。

DisplayUnitType 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| NONE | 值将按原样显示。 |
| HUNDREDS | 指定图表上的值将除以 100。 |
| THOUSANDS | 指定图表上的值将除以 1,000。 |
| TEN_THOUSANDS | 指定图表上的值将除以 10,000。 |
| HUNDRED_THOUSANDS | 指定图表上的值将除以 100,000。 |
| MILLIONS | 指定图表上的值将除以 1,000,000。 |
| TEN_MILLIONS | 指定图表上的值将除以 10,000,000。 |
| HUNDRED_MILLIONS | 指定图表上的值将除以 100,000,000。 |
| BILLIONS | 指定图表上的值将除以 1,000,000,000。 |
| TRILLIONS | 指定图表上的值将除以 1,000,000,000,000。 |
| CUSTOM_VALUE | 指定图表上的值将除以自定义值。 |
