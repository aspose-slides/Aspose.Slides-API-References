## ErrorBarValueType 枚举

表示误差线值的类型

The ErrorBarValueType type exposes the following members:

## 字段

| 字段 | 描述 |
| :- | :- |
| CUSTOM | 指定误差线的长度应由 Plus 和 Minus 元素决定。 |
| FIXED | 指定误差线的长度应为由 Error Bar Value 决定的固定值。 |
| PERCENTAGE | 指定误差线的长度应为数据的 Error Bar Value 百分比。 |
| STANDARD_DEVIATION | 指定误差线的长度应为数据的 Error Bar Value 标准偏差。 |
| STANDARD_ERROR | 指定误差线的长度应为数据的 Error Bar Value 标准误差。 |
