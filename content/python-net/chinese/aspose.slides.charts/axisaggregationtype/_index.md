## AxisAggregationType 枚举

表示类别轴的聚合类型。仅用于 Histogram 或 HistogramPareto 系列。

AxisAggregationType 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| BY_CATEGORY | 按类别聚合 |
| AUTOMATIC | 自动聚合类别 |
| BY_BIN_WIDTH | 按箱宽度聚合类别。属性 IAxis.BinWidth 必须设置。 |
| BY_NUMBER_OF_BINS | 按箱数量聚合类别。属性 IAxis.NumberOfBins 必须设置。 |
