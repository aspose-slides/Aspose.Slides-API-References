## embedded_workbook_type 属性
获取嵌入工作簿的类型。
如果 [`IChartData.data_source_type`](/slides/python-net/zh/aspose.slides.charts/ichartdata/data_source_type) 是 [`ChartDataSourceType.EXTERNAL_WORKBOOK`](/slides/python-net/zh/aspose.slides.charts/chartdatasourcetype/EXTERNAL_WORKBOOK)，则返回 [`WorkbookType.NOT_DEFINED`](/slides/python-net/zh/aspose.slides.charts/workbooktype/NOT_DEFINED)。
只读 [`WorkbookType`](/slides/python-net/zh/aspose.slides.charts/workbooktype)。
