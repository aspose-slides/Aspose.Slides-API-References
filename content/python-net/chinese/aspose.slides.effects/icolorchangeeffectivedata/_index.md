## IColorChangeEffectiveData 类

不可变对象，表示颜色更改效果。  
FromColor 的实例被替换为 ToColor 的实例。

IColorChangeEffectiveData 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`from_color`](/slides/python-net/zh/aspose.slides.effects/icolorchangeeffectivedata/from_color/) | 将被替换的颜色。<br/>            只读 **aspose.slides.Color**. |
| [`to_color`](/slides/python-net/zh/aspose.slides.effects/icolorchangeeffectivedata/to_color/) | 将用于替换的颜色。<br/>            只读 **aspose.slides.Color**. |
| [`use_alpha`](/slides/python-net/zh/aspose.slides.effects/icolorchangeeffectivedata/use_alpha/) | 返回一个布尔值，用于确定是否应使用 alpha 组件。<br/>            只读 **bool**. |
