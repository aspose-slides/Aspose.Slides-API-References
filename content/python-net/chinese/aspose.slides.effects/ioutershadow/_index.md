## IOuterShadow 类

表示外部阴影效果。

IOuterShadow 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`blur_radius`](/slides/python-net/zh/aspose.slides.effects/ioutershadow/blur_radius/) | 模糊半径，单位为点。<br/>            默认值 – 0 pt。<br/>            读写 **float**。 |
| [`direction`](/slides/python-net/zh/aspose.slides.effects/ioutershadow/direction/) | 阴影方向，单位为度。<br/>            默认值 – 0 ° (从左到右)。<br/>            读写 **float**。 |
| [`distance`](/slides/python-net/zh/aspose.slides.effects/ioutershadow/distance/) | 阴影与对象的距离，单位为点。<br/>            默认值 – 0 pt。<br/>            读写 **float**。 |
| [`shadow_color`](/slides/python-net/zh/aspose.slides.effects/ioutershadow/shadow_color/) | 阴影的颜色。<br/>            默认值 – 自动黑色（主题相关）。<br/>            只读 [`IColorFormat`](/slides/python-net/zh/aspose.slides/icolorformat)。 |
| [`rectangle_align`](/slides/python-net/zh/aspose.slides.effects/ioutershadow/rectangle_align/) | 矩形对齐方式。<br/>            默认值 – [`RectangleAlignment.BOTTOM`](/slides/python-net/zh/aspose.slides/rectanglealignment/BOTTOM)。 <br/>            读写 [`RectangleAlignment`](/slides/python-net/zh/aspose.slides/rectanglealignment)。 |
| [`skew_horizontal`](/slides/python-net/zh/aspose.slides.effects/ioutershadow/skew_horizontal/) | 水平倾斜角度，单位为度。<br/>            默认值 – 0 °。<br/>            读写 **float**。 |
| [`skew_vertical`](/slides/python-net/zh/aspose.slides.effects/ioutershadow/skew_vertical/) | 垂直倾斜角度，单位为度。<br/>            默认值 – 0 °。<br/>            读写 **float**。 |
| [`rotate_shadow_with_shape`](/slides/python-net/zh/aspose.slides.effects/ioutershadow/rotate_shadow_with_shape/) | 指示阴影是否随形状一起旋转。<br/>            默认值 – true。<br/>            读写 **bool**。 |
| [`scale_horizontal`](/slides/python-net/zh/aspose.slides.effects/ioutershadow/scale_horizontal/) | 水平缩放因子，以原始大小的百分比表示。<br/>            负缩放会导致翻转。<br/>            默认值 – 100 %。<br/>            读写 **float**。 |
| [`scale_vertical`](/slides/python-net/zh/aspose.slides.effects/ioutershadow/scale_vertical/) | 垂直缩放因子，以原始大小的百分比表示。<br/>            负缩放会导致翻转。<br/>            默认值 – 100 %。<br/>            读写 **float**。 |
