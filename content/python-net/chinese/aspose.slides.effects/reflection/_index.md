## Reflection 类

表示一种 Reflection 效果。

Reflection 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/zh/aspose.slides.effects/reflection/start_pos_alpha/) | 指定起始 alpha 值（沿 alpha 梯度坡道）的起始位置（百分比）。<br/>            读/写 **float**. |
| [`end_pos_alpha`](/slides/python-net/zh/aspose.slides.effects/reflection/end_pos_alpha/) | 指定结束 alpha 值（沿 alpha 梯度坡道）的结束位置（百分比）。<br/>            读/写 **float**. |
| [`fade_direction`](/slides/python-net/zh/aspose.slides.effects/reflection/fade_direction/) | 指定反射的偏移方向。（角度）<br/>            读/写 **float**. |
| [`start_reflection_opacity`](/slides/python-net/zh/aspose.slides.effects/reflection/start_reflection_opacity/) | 起始反射不透明度。（百分比）<br/>            读/写 **float**. |
| [`end_reflection_opacity`](/slides/python-net/zh/aspose.slides.effects/reflection/end_reflection_opacity/) | 结束反射不透明度。（百分比）<br/>            读/写 **float**. |
| [`blur_radius`](/slides/python-net/zh/aspose.slides.effects/reflection/blur_radius/) | 模糊半径。<br/>            读/写 **float**. |
| [`direction`](/slides/python-net/zh/aspose.slides.effects/reflection/direction/) | 反射方向。<br/>            读/写 **float**. |
| [`distance`](/slides/python-net/zh/aspose.slides.effects/reflection/distance/) | 反射距离。<br/>            读/写 **float**. |
| [`rectangle_align`](/slides/python-net/zh/aspose.slides.effects/reflection/rectangle_align/) | 矩形对齐方式。<br/>            读/写 [`RectangleAlignment`](/slides/python-net/zh/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/zh/aspose.slides.effects/reflection/skew_horizontal/) | 指定水平倾斜角度。<br/>            读/写 **float**. |
| [`skew_vertical`](/slides/python-net/zh/aspose.slides.effects/reflection/skew_vertical/) | 指定垂直倾斜角度。<br/>            读/写 **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/zh/aspose.slides.effects/reflection/rotate_shadow_with_shape/) | 指定当形状旋转时，反射是否随形状一起旋转。<br/>            读/写 **bool**. |
| [`scale_horizontal`](/slides/python-net/zh/aspose.slides.effects/reflection/scale_horizontal/) | 指定水平缩放因子，负值缩放会导致翻转。（百分比）<br/>            读/写 **float**. |
| [`scale_vertical`](/slides/python-net/zh/aspose.slides.effects/reflection/scale_vertical/) | 指定垂直缩放因子，负值缩放会导致翻转。（百分比）<br/>            读/写 **float**. |
