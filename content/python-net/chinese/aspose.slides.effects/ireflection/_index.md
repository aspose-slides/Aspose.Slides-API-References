## IReflection 类

表示反射效果。

IReflection 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/zh/aspose.slides.effects/ireflection/start_pos_alpha/) | 指定起始位置（沿 alpha 渐变坡道）对应的起始 alpha 值（百分比）。<br/>            读/写 **float**. |
| [`end_pos_alpha`](/slides/python-net/zh/aspose.slides.effects/ireflection/end_pos_alpha/) | 指定结束位置（沿 alpha 渐变坡道）对应的结束 alpha 值（百分比）。<br/>            读/写 **float**. |
| [`fade_direction`](/slides/python-net/zh/aspose.slides.effects/ireflection/fade_direction/) | 指定用于偏移反射的方向。（角度）<br/>            读/写 **float**. |
| [`start_reflection_opacity`](/slides/python-net/zh/aspose.slides.effects/ireflection/start_reflection_opacity/) | 起始反射不透明度。（百分比）<br/>            读/写 **float**. |
| [`end_reflection_opacity`](/slides/python-net/zh/aspose.slides.effects/ireflection/end_reflection_opacity/) | 结束反射不透明度。（百分比）<br/>            读/写 **float**. |
| [`blur_radius`](/slides/python-net/zh/aspose.slides.effects/ireflection/blur_radius/) | 模糊半径。<br/>            读/写 **float**. |
| [`direction`](/slides/python-net/zh/aspose.slides.effects/ireflection/direction/) | 反射方向。<br/>            读/写 **float**. |
| [`distance`](/slides/python-net/zh/aspose.slides.effects/ireflection/distance/) | 反射距离。<br/>            读/写 **float**. |
| [`rectangle_align`](/slides/python-net/zh/aspose.slides.effects/ireflection/rectangle_align/) | 矩形对齐方式。<br/>            读/写 [`RectangleAlignment`](/slides/python-net/zh/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/zh/aspose.slides.effects/ireflection/skew_horizontal/) | 指定水平倾斜角度。<br/>            读/写 **float**. |
| [`skew_vertical`](/slides/python-net/zh/aspose.slides.effects/ireflection/skew_vertical/) | 指定垂直倾斜角度。<br/>            读/写 **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/zh/aspose.slides.effects/ireflection/rotate_shadow_with_shape/) | 指定当形状旋转时，反射是否随形状一起旋转。<br/>            读/写 **bool**. |
| [`scale_horizontal`](/slides/python-net/zh/aspose.slides.effects/ireflection/scale_horizontal/) | 指定水平缩放因子，负数缩放会导致翻转。（百分比）<br/>            读/写 **float**. |
| [`scale_vertical`](/slides/python-net/zh/aspose.slides.effects/ireflection/scale_vertical/) | 指定垂直缩放因子，负数缩放会导致翻转。（百分比）<br/>            读/写 **float**. |
