## IReflectionEffectiveData 类

表示反射效果的不可变对象。

IReflectionEffectiveData 类型公开以下成员：

## 属性

| Property | Description |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/zh/aspose.slides.effects/ireflectioneffectivedata/start_pos_alpha/) | 指定起始 alpha 值（沿 alpha 渐变斜坡）的起始位置（百分比）。<br/>            只读 **float**. |
| [`end_pos_alpha`](/slides/python-net/zh/aspose.slides.effects/ireflectioneffectivedata/end_pos_alpha/) | 指定结束 alpha 值（沿 alpha 渐变斜坡）的结束位置（百分比）。<br/>            只读 **float**. |
| [`fade_direction`](/slides/python-net/zh/aspose.slides.effects/ireflectioneffectivedata/fade_direction/) | 指定偏移反射的方向。（角度）<br/>            只读 **float**. |
| [`start_reflection_opacity`](/slides/python-net/zh/aspose.slides.effects/ireflectioneffectivedata/start_reflection_opacity/) | 起始反射不透明度。（百分比）<br/>            只读 **float**. |
| [`end_reflection_opacity`](/slides/python-net/zh/aspose.slides.effects/ireflectioneffectivedata/end_reflection_opacity/) | 结束反射不透明度。（百分比）<br/>            只读 **float**. |
| [`blur_radius`](/slides/python-net/zh/aspose.slides.effects/ireflectioneffectivedata/blur_radius/) | 模糊半径。<br/>            只读 **float**. |
| [`direction`](/slides/python-net/zh/aspose.slides.effects/ireflectioneffectivedata/direction/) | 反射方向。<br/>            只读 **float**. |
| [`distance`](/slides/python-net/zh/aspose.slides.effects/ireflectioneffectivedata/distance/) | 反射距离。<br/>            只读 **float**. |
| [`rectangle_align`](/slides/python-net/zh/aspose.slides.effects/ireflectioneffectivedata/rectangle_align/) | 矩形对齐方式。<br/>            只读 [`RectangleAlignment`](/slides/python-net/zh/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/zh/aspose.slides.effects/ireflectioneffectivedata/skew_horizontal/) | 指定水平倾斜角度。<br/>            只读 **float**. |
| [`skew_vertical`](/slides/python-net/zh/aspose.slides.effects/ireflectioneffectivedata/skew_vertical/) | 指定垂直倾斜角度。<br/>            只读 **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/zh/aspose.slides.effects/ireflectioneffectivedata/rotate_shadow_with_shape/) | 指定在形状旋转时反射是否随形状一起旋转。<br/>            只读 **bool**. |
| [`scale_horizontal`](/slides/python-net/zh/aspose.slides.effects/ireflectioneffectivedata/scale_horizontal/) | 指定水平缩放因子，负值缩放会导致翻转。（百分比）<br/>            只读 **float**. |
| [`scale_vertical`](/slides/python-net/zh/aspose.slides.effects/ireflectioneffectivedata/scale_vertical/) | 指定垂直缩放因子，负值缩放会导致翻转。（百分比）<br/>            只读 **float**. |
