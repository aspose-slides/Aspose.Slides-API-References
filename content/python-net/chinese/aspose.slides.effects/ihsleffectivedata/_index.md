## IHSLEffectiveData 类

表示一种色相/饱和度/亮度效果。
            色相、饱和度和亮度都可以相对于其当前值进行调整。

IHSLEffectiveData 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`hue`](/slides/python-net/zh/aspose.slides.effects/ihsleffectivedata/hue/) | 返回色相百分比。<br/>            只读 **float**. |
| [`saturation`](/slides/python-net/zh/aspose.slides.effects/ihsleffectivedata/saturation/) | 返回饱和度百分比。<br/>            只读 **float**. |
| [`luminance`](/slides/python-net/zh/aspose.slides.effects/ihsleffectivedata/luminance/) | 返回亮度百分比。<br/>            只读 **float**. |
