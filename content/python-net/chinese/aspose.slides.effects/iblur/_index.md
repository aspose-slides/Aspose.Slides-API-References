## IBlur 类

表示应用于整个形状（包括其填充）的模糊效果。  
所有颜色通道，包括 alpha，均受影响。

IBlur 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`radius`](/slides/python-net/zh/aspose.slides.effects/iblur/radius/) | 返回或设置模糊半径。<br/>            读/写 **float**. |
| [`grow`](/slides/python-net/zh/aspose.slides.effects/iblur/grow/) | 确定对象的边界是否应因模糊而增大。<br/>            True 表示边界会增大，而 false 表示不会增大。<br/>            读/写 **bool**. |
