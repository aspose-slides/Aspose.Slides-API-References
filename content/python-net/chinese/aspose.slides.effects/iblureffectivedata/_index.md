## IBlurEffectiveData 类

不可变对象，表示应用于整个形状（包括填充）的模糊效果。  
所有颜色通道，包括 alpha，均受到影响。

IBlurEffectiveData 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`radius`](/slides/python-net/zh/aspose.slides.effects/iblureffectivedata/radius/) | 返回或设置模糊半径。<br/>            只读 **float**. |
| [`grow`](/slides/python-net/zh/aspose.slides.effects/iblureffectivedata/grow/) | 确定在模糊后对象的边界是否应扩大。<br/>            True 表示边界会扩大，而 false 表示不会。<br/>            只读 **bool**. |
