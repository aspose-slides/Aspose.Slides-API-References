## SmartArtLayoutType 枚举

表示 SmartArt 图表的布局类型。

SmartArtLayoutType 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| ACCENT_PROCESS | 用于显示任务、流程或工作流中的进展、时间线或顺序步骤。非常适合展示 Level 1 和 Level 2 文本。 |
| ACCENTED_PICTURE | 用于展示中心的摄影构想以及侧面的相关构想。顶部的 Level 1 文本显示在中心图片之上。其他 Level 1 形状对应的文本显示在小圆形图片旁边。该布局在没有文本时也能良好使用。 |
| ALTERNATING_FLOW | 用于显示任务、流程或工作流中的信息组或顺序步骤。强调信息组之间的交互或关系。 |
| ALTERNATING_HEXAGONS | 用于表示一系列相互关联的想法。Level 1 文本显示在六边形内部。Level 2 文本显示在形状外部。 |
| ALTERNATING_PICTURE_BLOCKS | 用于从上到下展示一系列图片。文本交替显示在图片的右侧或左侧。 |
| ALTERNATING_PICTURE_CIRCLES | 用于展示一组带文本的图片。相应的文本显示在中心圆形中，图像从左到右交替排列。 |
| ARROW_RIBBON | 用于展示具有某种关联的相关或对比概念，例如相对的力量。前两行 Level 1 文本用于箭头中的文字。未使用的文本不显示，但在切换布局时仍可使用。 |
| ASCENDING_PICTURE_ACCENT_PROCESS | 用于显示一系列带描述性文本的上升图片。最适合少量文本。 |
| BALANCE | 用于比较或展示两个想法之间的关系。前两行 Level 1 文本分别对应中心点两侧顶部的文字。强调 Level 2 文本，且每侧最多四个形状包含 Level 2 文本。平衡会倾向于包含更多 Level 2 文本形状的一侧。未使用的文本不显示，但在切换布局时仍可使用。 |
| BASIC_BENDING_PROCESS | 用于展示任务、流程或工作流中的进展或顺序步骤。最大化形状的水平和垂直显示空间。 |
| BASIC_BLOCK_LIST | 用于展示非顺序或分组的信息块。最大化形状的水平和垂直显示空间。 |
| BASIC_CHEVRON_PROCESS | 用于展示进展、时间线、任务、流程或工作流中的顺序步骤，或强调移动或方向。Level 1 文本显示在箭头形状内部，Level 2 文本显示在箭头形状下方。 |
| BASIC_CYCLE | 用于在循环流程中表示持续的阶段、任务或事件序列。强调阶段或步骤，而非连接的箭头或流向。仅使用 Level 1 文本时效果最佳。 |
| BASIC_MATRIX | 用于以象限方式展示组件与整体的关系。前四行 Level 1 文本显示在各象限中。未使用的文本不显示，但在切换布局时仍可使用。 |
| BASIC_PIE | 用于展示各部分如何组成整体。前七行 Level 1 文本对应均匀分布的楔形或饼形。顶部的 Level 1 文本形状位于饼图其余部分之外以示强调。未使用的文本不显示，但在切换布局时仍可使用。 |
| BASIC_PROCESS | 用于展示任务、流程或工作流中的进展或顺序步骤。 |
| BASIC_PYRAMID | 用于展示比例、相互关联或层级关系，最大组件位于底部并逐渐向上收窄。Level 1 文本显示在金字塔的各段中，Level 2 文本显示在每段旁边的形状中。 |
| BASIC_RADIAL | 用于在循环中展示与中心理念的关系。第一行 Level 1 文本对应中心形状，其 Level 2 文本对应周围的圆形。未使用的文本不显示，但在切换布局时仍可使用。 |
| BASIC_TARGET | 用于展示包含、层次或层级关系。前五行 Level 1 文本与一个圆形关联。未使用的文本不显示，但在切换布局时仍可使用。 |
| BASIC_TIMELINE | 用于展示任务、流程或工作流中的顺序步骤，或显示时间线信息。对 Level 1 和 Level 2 文本均表现良好。 |
| BASIC_VENN | 用于展示重叠或相互关联的关系。前七行 Level 1 文本对应一个圆形。若 Level 1 文本行数不超过四行，则文本位于圆形内部；若超过四行，则文本位于圆形外部。未使用的文本不显示，但在切换布局时仍可使用。 |
| BENDING_PICTURE_ACCENT_LIST | 用于展示非顺序或分组的信息块。小圆形设计用于容纳图片。对展示 Level 1 和 Level 2 文本均表现良好。最大化形状的水平和垂直显示空间。 |
| BENDING_PICTURE_BLOCKS | 用于展示一系列图片。覆盖底部角落的框可容纳少量文本。 |
| BENDING_PICTURE_CAPTION | 用于展示一系列顺序图片。覆盖底部角落的框可容纳少量文本。 |
| BENDING_PICTURE_CAPTION_LIST | 用于展示一系列图片。标题和描述显示在每张图片下方的标注形状中。 |
| BENDING_PICTURE_SEMI_TRANSPARENT_TEXT | 用于展示一系列图片。半透明框覆盖图片下部并容纳所有层级的文本。 |
| BLOCK_CYCLE | 用于在循环流中表示持续的阶段、任务或事件序列。强调阶段或步骤，而非连接的箭头或流向。 |
| BUBBLE_PICTURE_LIST | 用于展示一系列图片。可容纳最多八个 Level 1 图片。未使用的文本和图片不显示，但在切换布局时仍可使用。对少量文本效果最佳。 |
| CAPTIONED_PICTURES | 用于展示带有多层文本的图片。对少量 Level 1 文本和中等量 Level 2 文本效果最佳。 |
| CHEVRON_LIST | 用于展示组成整体工作流的多个过程的进展。也可用于说明对比过程。Level 1 文本对应左侧的第一个箭头形状，而 Level 2 文本对应每个包含 Level 1 文本的形状的水平子步骤。 |
| CIRCLE_ACCENT_TIMELINE | 用于展示一系列事件或时间线信息。Level 1 文本显示在较大圆形旁边，Level 2 文本显示在较小圆形旁边。 |
| CIRCLE_ARROW_PROCESS | 用于展示带有每项支持文本的顺序项目。该图在少量 Level 1 文本时效果最佳。 |
| CIRCLE_PICTURE_HIERARCHY | 用于展示组织中的层级信息或汇报关系。图片显示在圆形中，相应的文本显示在图片旁边。 |
| CIRCLE_RELATIONSHIP | 用于展示与中心理念的关系（向内或向外）。Level 2 文本以非顺序方式添加，最多五项。只能有一个 Level 1 项目。 |
| CIRCULAR_BENDING_PROCESS | 用于展示任务、流程或工作流中较长或非线性的序列或步骤。仅使用 Level 1 文本时效果最佳。最大化形状的水平和垂直显示空间。 |
| CIRCULAR_PICTURE_CALLOUT | 用于展示中心理念及其子理念或相关项目。第一张图片的文本覆盖图片的下部。其他 Level 1 形状的相应文本显示在小圆形图片旁边。该图在没有文本时亦表现良好。 |
| CLOSED_CHEVRON_PROCESS | 用于展示进展、时间线或任务、流程、工作流中的顺序步骤，或强调移动或方向。可用于强调起始形状中的信息。仅使用 Level 1 文本时效果最佳。 |
| CONTINUOUS_ARROW_PROCESS | 用于展示任务、流程或工作流中的时间线或顺序步骤。由于每行 Level 1 文本显示在箭头形状内部，仅使用 Level 1 文本时效果最佳。Level 2 文本显示在箭头形状外部。 |
| CONTINUOUS_BLOCK_PROCESS | 用于展示任务、流程或工作流中的进展或顺序步骤。对最少量的 Level 1 和 Level 2 文本效果最佳。 |
| CONTINUOUS_CYCLE | 用于在循环流中表示持续的阶段、任务或事件序列。强调所有组件之间的连接。仅使用 Level 1 文本时效果最佳。 |
| CONTINUOUS_PICTURE_LIST | 用于展示相互关联的信息组。圆形设计用于容纳图片。 |
| CONVERGING_ARROWS | 用于展示汇聚到中心点的想法或概念。仅使用 Level 1 文本时效果最佳。 |
| CONVERGING_RADIAL | 用于在循环中展示概念或组件与中心理念的关系。第一行 Level 1 文本对应中心圆形，Level 2 文本对应周围的矩形形状。未使用的文本不显示，但在切换布局时仍可使用。 |
| COUNTERBALANCE_ARROWS | 用于展示两个相对的想法或概念。前两行 Level 1 文本各对应一个箭头，并能很好地配合 Level 2 文本。未使用的文本不显示，但在切换布局时仍可使用。 |
| CYCLE_MATRIX | 用于在循环进程中展示与中心理念的关系。前四行 Level 1 文本各对应一个楔形或饼形，Level 2 文本显示在该楔形或饼形旁边的矩形中。未使用的文本不显示，但在切换布局时仍可使用。 |
| DESCENDING_BLOCK_LIST | 用于展示相关想法或信息列表的分组。文本形状按顺序逐渐降低高度，Level 1 文本垂直显示。 |
| DESCENDING_PROCESS | 用于展示递降的事件序列。第一行 Level 1 文本位于箭头顶部，最后一行位于箭头底部。仅显示前七个 Level 1 项目。对少量至中等量文本效果最佳。 |
| DETAILED_PROCESS | 与大量 Level 2 文本一起使用，以展示跨阶段的进展。 |
| DIVERGING_ARROWS | 用于展示从中心源向外扩展的想法或概念。仅使用 Level 1 文本时效果最佳。 |
| DIVERGING_RADIAL | 用于在循环中展示与中心理念的关系。第一行 Level 1 文本对应中心圆形。强调周围的圆形而非中心理念。未使用的文本不显示，但在切换布局时仍可使用。 |
| EQUATION | 用于展示描绘计划或结果的顺序步骤或任务。最后一行 Level 1 文本出现在等号 (=) 之后。仅使用 Level 1 文本时效果最佳。 |
| FRAMED_TEXT_PICTURE | 用于展示图片，并在框中显示相应的 Level 1 文本。 |
| FUNNEL | 用于展示信息过滤或各部分合并为整体的过程。强调最终结果。可包含最多四行 Level 1 文本；其中最后一行显示在漏斗下方，其他行对应圆形。未使用的文本不显示，但在切换布局时仍可使用。 |
| GEAR | 用于展示相互联动的想法。前三行 Level 1 文本各对应一个齿轮形状，其相应的 Level 2 文本显示在齿轮形状旁的矩形中。未使用的文本不显示，但在切换布局时仍可使用。
| GRID_MATRIX | 用于展示概念在两个轴上的布局。强调各个组件而不是整体。Level 1 文本的前四行显示在象限中。未使用的文本不显示，但在切换布局时仍可用。 |
| GROUPED_LIST | 用于显示信息的组和子组，或任务、流程、工作流中的步骤和子步骤。Level 1 文本对应顶层水平形状，Level 2 文本对应每个相关顶层形状下的垂直子步骤。适合强调子组或子步骤、层级信息或多个信息列表。 |
| HALF_CIRCLE_ORGANIZATION_CHART | 用于展示组织中的层级信息或汇报关系。此布局提供辅助形状和组织结构图悬挂布局。 |
| HEXAGON_CLUSTER | 用于显示带有说明文字的图片。小六边形表示图片与文字的配对。适合文字量较少的情况。 |
| HIERARCHY | 用于展示自上而下的层级关系。 |
| HIERARCHY_LIST | 用于展示跨组的层级关系。也可用于分组或列出信息。 |
| HORIZONTAL_BULLET_LIST | 用于显示非顺序或分组的信息列表。适用于大量文字。所有文字的强调程度相同，且不暗示方向。 |
| HORIZONTAL_HIERARCHY | 用于展示水平进展的层级关系。适合决策树。 |
| HORIZONTAL_LABELED_HIERARCHY | 用于展示水平且层级分组的层级关系。强调标题或 Level 1 文本。第一行 Level 1 文本出现在层级起始的形状中，第二行及后续所有 Level 1 文本出现在高矩形的顶部。 |
| HORIZONTAL_MULTI_LEVEL_HIERARCHY | 用于水平展示大量层级信息。层级顶部以垂直方式显示。此布局支持层级中的多层级。 |
| HORIZONTAL_ORGANIZATION_CHART | 用于水平展示组织中的层级信息或汇报关系。此布局提供辅助形状和组织结构图悬挂布局。 |
| HORIZONTAL_PICTURE_LIST | 用于显示非顺序或分组的信息，并强调相关图片。顶部形状设计用于容纳图片。 |
| INCREASING_ARROWS_PROCESS | 用于展示流程中的顺序和重叠步骤。最多五个 Level 1 项目。Level 2 可包含大量文字。 |
| INCREASING_CIRCLE_PROCESS | 用于展示一系列步骤，圆形内部随每一步递增。最多七个 Level 1 步骤，Level 2 项目数量不限。适合大量 Level 2 文字。 |
| INVERTED_PYRAMID | 用于展示比例、互联或层级关系，顶部为最大组件并逐渐收窄。Level 1 文本显示在金字塔分段中，Level 2 文本显示在每个分段旁的形状中。 |
| LABELED_HIERARCHY | 用于自上而下并层级分组的层级关系。强调标题或 Level 1 文本。第一行 Level 1 文本出现在层级起始的形状中，后续所有 Level 1 文本显示在长矩形的左侧。 |
| LINEAR_VENN | 用于顺序展示重叠关系。最适合仅使用 Level 1 文本。 |
| LINED_LIST | 用于将大量文字划分为类别和子类别。适合多层级文字。相同层级的文字之间以线条分隔。 |
| MULTIDIRECTIONAL_CYCLE | 用于表示可以在任意方向发生的连续阶段、任务或事件序列。 |
| NAMEAND_TITLE_ORGANIZATION_CHART | 用于展示组织中的层级信息或汇报关系。要在标题框中输入文字，请直接在较小的矩形形状中键入。此布局提供辅助形状和组织结构图悬挂布局。 |
| NESTED_TARGET | 用于展示包含关系。Level 1 文本的前三行对应形状左上方的文字，Level 2 文本对应较小的形状。最适合少量 Level 2 行文字。未使用的文本不显示，但在切换布局时仍可用。 |
| NONDIRECTIONAL_CYCLE | 用于以循环方式表示持续的阶段、任务或事件序列。每个形状的重要性相同。适用于不需要指示方向的情况。 |
| OPPOSING_ARROWS | 用于显示两个相对的想法或从中心点分出的想法。Level 1 文本的前两行对应一支箭头。未使用的文本不显示，但在切换布局时仍可用。 |
| OPPOSING_IDEAS | 用于展示两个相对或对比的想法。可包含一或两个 Level 1 项目。每个 Level 1 文本可以包含多个子层级。适合大量文字。 |
| ORGANIZATION_CHART | 用于展示组织中的层级信息或汇报关系。此布局提供辅助形状和组织结构图悬挂布局。 |
| PHASED_PROCESS | 用于展示流程的三个阶段。限制为三个 Level 1 项目。前两个 Level 1 项目各可包含四个 Level 2 项目，第三个 Level 1 项目可包含无限数量的 Level 2 项目。最适合少量文字。 |
| PICTURE_ACCENT_BLOCKS | 用于从角落开始以块状显示一组图片。对应文字垂直显示。适合作为标题或副标题幻灯片的强调，或文档的章节分隔。 |
| PICTURE_ACCENT_LIST | 用于显示分组或相关信息。上角的小形状设计用于容纳图片。强调 Level 2 文本而非 Level 1 文本，适合大量 Level 2 文字。 |
| PICTURE_ACCENT_PROCESS | 用于展示任务、流程或工作流中的顺序步骤。背景中的矩形形状设计用于容纳图片。 |
| PICTURE_CAPTION_LIST | 用于显示非顺序或分组的信息块。顶部形状设计用于容纳图片，且图片相对于文字更受强调。适合带短文字说明的图片。 |
| PICTURE_GRID | 用于在方形网格上布局图片。最好配少量的 Level 1 文本，文本显示在图片上方。 |
| PICTURE_LINEUP | 用于并排显示一系列图片。Level 1 文本位于图片顶部。Level 2 文本显示在图片下方。 |
| PICTURE_STRIPS | 用于从上到下展示一系列图片，旁边配有 Level 1 文本。 |
| PIE_PROCESS | 用于展示流程步骤，每个饼形片段逐渐增大，最多七个形状。Level 1 文本垂直显示。 |
| PLUSAND_MINUS | 用于展示两个想法的利弊。每个 Level 1 文本可以包含多个子层级。适合大量文字。限制为两个 Level 1 项目。 |
| PROCESS_ARROWS | 用于展示说明流程或工作流的信息。Level 1 文本显示在圆形形状中，Level 2 文本显示在箭头形状中。最适合文字简少且强调移动或方向的情况。 |
| PROCESS_LIST | 用于显示多组信息或任务、流程、工作流中的步骤和子步骤。Level 1 文本对应顶部水平形状，Level 2 文本对应每个相关顶部形状下的垂直子步骤。 |
| PYRAMID_LIST | 用于展示比例、互联或层级关系。文字显示在金字塔背景顶部的矩形形状中。 |
| RADIAL_CLUSTER | 用于展示与中心理念或主题相关的数据。顶部的 Level 1 文本显示在中心。Level 2 文本显示在周围形状中。可包含最多七个 Level 2 形状。未使用的文本不显示，但在切换布局时仍可用。最适合少量文字。 |
| RADIAL_CYCLE | 用于展示与中心理念的关系。强调中心圆圈中的信息以及外环圆圈信息对中心理念的贡献。第一行 Level 1 文本对应中心圆，其 Level 2 文本对应外环圆圈。未使用的文本不显示，但在切换布局时仍可用。 |
| RADIAL_LIST | 用于在循环中展示与中心理念的关系。中心形状可容纳图片。Level 1 文本显示在较小的圆圈中，相关的 Level 2 文本显示在这些圆圈旁边。 |
| RADIAL_VENN | 用于在循环中同时展示重叠关系和与中心理念的关系。第一行 Level 1 文本对应中心形状，Level 2 文本对应周围的圆形形状。未使用的文本不显示，但在切换布局时仍可用。 |
| RANDOM_TO_RESULT_PROCESS | 用于通过一系列步骤展示多个混乱想法如何汇聚为统一目标或想法。支持多个 Level 1 文本项，但首尾对应的形状固定。最适合少量 Level 1 文本和中等量的 Level 2 文本。 |
| REPEATING_BENDING_PROCESS | 用于展示任务、流程或工作流中的进程或顺序步骤。最大化形状的水平和垂直显示空间。 |
| REVERSE_LIST | 用于在两个项目之间切换。仅显示前两个文本项目，每个项目可包含大量文字。适合展示两项之间的变化或顺序的转变。 |
| SEGMENTED_CYCLE | 用于在循环流中展示进程或阶段、任务、事件的序列。强调相互关联的部分。Level 1 文本的前七行对应一个楔形或饼形。未使用的文本不显示，但在切换布局时仍可用。 |
| SEGMENTED_PROCESS | 用于展示任务、流程或工作流中的进程或顺序步骤。强调 Level 2 文本，因为每行文字出现在独立的形状中。 |
| SEGMENTED_PYRAMID | 用于展示包含、比例或互联关系。前九行 Level 1 文本显示在三角形形状中。未使用的文本不显示，但在切换布局时仍可用。最适合仅使用 Level 1 文本。 |
| SNAPSHOT_PICTURE_LIST | 用于显示带说明文字的图片。Level 2 文本可呈现信息列表。适合大量文字。 |
