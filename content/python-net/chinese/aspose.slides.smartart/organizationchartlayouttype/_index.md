## OrganizationChartLayoutType 枚举

表示组织结构图中子节点的格式类型

OrganizationChartLayoutType 类型公开以下成员：

## 字段

| 字段 | 描述 |
| :- | :- |
| INITIAL | 初始布局类型 |
| STANDART | 将子节点水平放置在父节点下方。 |
| BOTH_HANGING | 将子节点垂直放置在父节点下方的左右两侧。 |
| LEFT_HANGING | 将子节点垂直放置在父节点下方的左侧。 |
| RIGHT_HANGING | 将子节点垂直放置在父节点下方的右侧。 |
