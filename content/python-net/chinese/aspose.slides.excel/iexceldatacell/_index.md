## IExcelDataCell 类

表示 Excel 工作簿中的单个单元格。

IExcelDataCell 类型公开以下成员：

## 属性

| 属性 | 描述 |
| :- | :- |
| [`value`](/slides/python-net/zh/aspose.slides.excel/iexceldatacell/value/) | 获取 Excel 单元格中包含的值。<br/>            只读 **any**. |
| [`name`](/slides/python-net/zh/aspose.slides.excel/iexceldatacell/name/) | 获取图表数据单元格的名称。<br/>            只读 **str**. |
| [`row`](/slides/python-net/zh/aspose.slides.excel/iexceldatacell/row/) | 获取单元格所在工作表中行的零基索引。<br/>            只读 **int**. |
| [`column`](/slides/python-net/zh/aspose.slides.excel/iexceldatacell/column/) | 获取单元格所在工作表中列的零基索引。<br/>            只读 **int**. |
