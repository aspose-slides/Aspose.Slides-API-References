มีคลาสที่ให้คุณลักษณะ AI สำหรับการวิเคราะห์และประมวลผลงานนำเสนอ PowerPoint.

## คลาส

| คลาส | คำอธิบาย |
| :- | :- |
| [`AsposeAIWebClient`](/slides/python-net/th/aspose.slides.ai/asposeaiwebclient/) | การใช้งาน [`IAIWebClient`](/slides/python-net/th/aspose.slides.ai/iaiwebclient) แบบในตัวที่เชื่อมต่อกับ LLM ของ Aspose.<br/>            นี่คือไคลเอนต์เริ่มต้นที่ใช้โดยคอนสตรัคเตอร์ **SlidesAIAgent.#ctor** ที่ไม่มีพารามิเตอร์ |
| [`IAIConversation`](/slides/python-net/th/aspose.slides.ai/iaiconversation/) | แทนอินสแตนซ์ของการสนทนา. แตกต่างจากการเรียก AI ปกติ การสนทนาจะเก็บบริบททั้งหมด |
| [`IAIWebClient`](/slides/python-net/th/aspose.slides.ai/iaiwebclient/) | อินเทอร์เฟซไคลเอนต์ AI บนเว็บ. อินเทอร์เฟซนี้ทำให้สามารถแทนที่โมเดลภาษา AI ต่าง ๆ ได้<br/>            คลาสที่ทำตามอินเทอร์เฟซนี้ควรใช้งานร่วมกับ `SlidesAIAgent`. |
| [`OpenAICompatibleWebClient`](/slides/python-net/th/aspose.slides.ai/openaicompatiblewebclient/) | การใช้งาน [`IAIWebClient`](/slides/python-net/th/aspose.slides.ai/iaiwebclient) แบบในตัวที่เชื่อมต่อกับผู้ให้บริการ LLM ที่เข้ากันได้กับ OpenAI<br/>            ที่ URL ฐานที่กำหนด. |
| [`OpenAIWebClient`](/slides/python-net/th/aspose.slides.ai/openaiwebclient/) | การใช้งาน [`IAIWebClient`](/slides/python-net/th/aspose.slides.ai/iaiwebclient) แบบในตัวที่เชื่อมต่อกับ API ของ OpenAI. |
| [`SlidesAIAgent`](/slides/python-net/th/aspose.slides.ai/slidesaiagent/) | ให้คุณลักษณะที่ใช้ AI เพื่อประมวลผลงานนำเสนอ. |
| [`SlidesAIAgentException`](/slides/python-net/th/aspose.slides.ai/slidesaiagentexception/) | แทนข้อยกเว้นที่เกี่ยวข้องกับ Slides AI Agent. |
