## ExcelDataCell คลาส

แทนความหมายของเซลล์เดียวในเวิร์กบุ๊ก Excel.

ประเภท ExcelDataCell เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`value`](/slides/python-net/th/aspose.slides.excel/exceldatacell/value/) | รับค่าที่อยู่ในเซลล์ Excel. |
| [`name`](/slides/python-net/th/aspose.slides.excel/exceldatacell/name/) | รับชื่อของเซลล์ข้อมูลแผนภูมิ. |
| [`row`](/slides/python-net/th/aspose.slides.excel/exceldatacell/row/) | รับดัชนีของแถวในเวิร์กชีตที่เซลล์ตั้งอยู่โดยเริ่มจากศูนย์.<br/>            อ่านอย่างเดียว **int**. |
| [`column`](/slides/python-net/th/aspose.slides.excel/exceldatacell/column/) | รับดัชนีของคอลัมน์ในเวิร์กชีตที่เซลล์ตั้งอยู่โดยเริ่มจากศูนย์.<br/>            อ่านอย่างเดียว **int**. |
