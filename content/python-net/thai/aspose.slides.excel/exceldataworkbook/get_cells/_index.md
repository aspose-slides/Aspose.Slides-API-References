## get_cells(self, formula, skip_hidden_cells) {#str-bool}
ดึงคอลเลกชันของเซลล์จากเวิร์กบุ๊กที่ตรงกับสูตรที่ระบุ

### คืนค่า

รายการเซลล์แบบอ่านอย่างเดียวที่ตรงกับสูตรที่ระบุ



```python
def get_cells(self, formula, skip_hidden_cells):
    ...
```


| พารามิเตอร์ | ประเภท | คำอธิบาย |
| :- | :- | :- |
| formula | **str** | สูตรหรือการแสดงช่วง (เช่น "Sheet1!A1:B3") ที่ใช้เพื่อระบุเซลล์เป้าหมาย |
| skip_hidden_cells | **bool** | หาก `true` เซลล์ที่ซ่อนอยู่ (เช่น ในแถวหรือคอลัมน์ที่ซ่อน) จะถูกตัดออกจากผลลัพธ์ |
