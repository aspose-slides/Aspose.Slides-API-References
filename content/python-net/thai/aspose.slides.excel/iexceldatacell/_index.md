## IExcelDataCell class

แสดงถึงเซลล์เดียวในเวิร์กบุ๊ก Excel

ประเภท IExcelDataCell เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`value`](/slides/python-net/th/aspose.slides.excel/iexceldatacell/value/) | รับค่าที่บรรจุอยู่ในเซลล์ Excel.<br/>            อ่านอย่างเดียว **any**. |
| [`name`](/slides/python-net/th/aspose.slides.excel/iexceldatacell/name/) | รับชื่อของเซลล์ข้อมูลแผนภูมิ.<br/>            อ่านอย่างเดียว **str**. |
| [`row`](/slides/python-net/th/aspose.slides.excel/iexceldatacell/row/) | รับดัชนีเริ่มจากศูนย์ของแถวในเวิร์กชีตที่เซลล์ตั้งอยู่.<br/>            อ่านอย่างเดียว **int**. |
| [`column`](/slides/python-net/th/aspose.slides.excel/iexceldatacell/column/) | รับดัชนีเริ่มจากศูนย์ของคอลัมน์ในเวิร์กชีตที่เซลล์ตั้งอยู่.<br/>            อ่านอย่างเดียว **int**. |
