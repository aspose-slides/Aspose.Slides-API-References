## การนับรวม AxisAggregationType (enumeration)

แทนประเภทการนับรวมของแกนประเภท ใช้ร่วมกับชุดข้อมูล Histogram หรือ HistogramPareto เท่านั้น

ประเภท AxisAggregationType เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| BY_CATEGORY | นับรวมตามประเภท |
| AUTOMATIC | นับรวมประเภทโดยอัตโนมัติ |
| BY_BIN_WIDTH | นับรวมประเภทโดยใช้ความกว้างของบิ้น ค่าคุณสมบัติ IAxis.BinWidth ต้องถูกตั้งค่า |
| BY_NUMBER_OF_BINS | นับรวมประเภทโดยใช้จำนวนบิ้น ค่าคุณสมบัติ IAxis.NumberOfBins ต้องถูกตั้งค่า |
