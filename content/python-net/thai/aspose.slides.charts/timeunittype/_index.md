## TimeUnitType enumeration

แทนหน่วยพื้นฐานสำหรับแกนประเภท

ประเภท TimeUnitType เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| NONE | ค่าจะถูกแสดงตามที่เป็นอยู่ |
| DAYS | ระบุว่าข้อมูลแผนภูมิจะแสดงเป็นวัน |
| MONTHS | ระบุว่าข้อมูลแผนภูมิจะแสดงเป็นเดือน |
| YEARS | ระบุว่าข้อมูลแผนภูมิจะแสดงเป็นปี |
