## error_bars_x_format คุณสมบัติ
แสดง ErrorBars ของ series ที่มีทิศทาง X.

            ErrorBars ที่มีทิศทาง X มีให้ใช้สำหรับ series ประเภท area, bar, scatter และ bubble. 
            สำหรับประเภทแผนภูมิอื่นใด คุณสมบัตินี้จะคืนค่า None (รวมถึงแผนภูมิ 3D). 
            ในกรณีค่าที่กำหนดเอง ใช้คอลเลกชัน DataPoints เพื่อระบุค่า (ด้วย [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/th/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) คุณสมบัติ). 
            
            อ่านอย่างเดียว [`IErrorBarsFormat`](/slides/python-net/th/aspose.slides.charts/ierrorbarsformat).
