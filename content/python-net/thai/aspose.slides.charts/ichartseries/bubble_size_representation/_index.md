## bubble_size_representation คุณสมบัติ
Specifies how the bubble size values are represented on the bubble chart.
            นี้เป็นคุณสมบัติไม่เพียงของซีรีส์นี้ แต่ของทุกซีรีส์ในซีรีส์แม่ 
            group - นี้เป็นการฉายของคุณสมบัติกลุ่มที่เหมาะสม และดังนั้นคุณสมบัติ 
            เป็นแบบอ่านอย่างเดียว.
            ใช้คุณสมบัติ ParentSeriesGroup เพื่อเข้าถึงกลุ่มซีรีส์แม่.
            ใช้คุณสมบัติ ParentSeriesGroup.BubbleSizeRepresentation แบบอ่าน/เขียน เพื่อเปลี่ยนค่า.
