## bubble_size_scale คุณสมบัติ
ระบุปัจจัยสเกลสำหรับแผนภูมิบับเบิล (สามารถอยู่ระหว่าง 0 ถึง 300 เปอร์เซ็นต์ของขนาดเริ่มต้น).
นี่คือคุณสมบัติไม่เพียงของชุดข้อมูลนี้เท่านั้น แต่ของชุดข้อมูลทั้งหมดของกลุ่มชุดข้อมูลพARENT - นี่คือการฉายของคุณสมบัติกลุ่มที่เหมาะสม. ดังนั้นคุณสมบัตินี้เป็นแบบอ่านอย่างเดียว.
ใช้คุณสมบัติ ParentSeriesGroup เพื่อเข้าถึงกลุ่มชุดข้อมูลพARENT.
ใช้คุณสมบัติอ่าน/เขียน ParentSeriesGroup.BubbleSizeScale เพื่อเปลี่ยนค่า.

### หมายเหตุ
