## show_percentage คุณสมบัติ
Represents a specified chart's data label percentage value display behavior. 
            True แสดงค่าร้อยละ. False เพื่อซ่อน.
            อ่าน/เขียน **bool**.

### หมายเหตุ

If parent of this DataLabelFormat object is a DataLabelCollection collection of data labels then this คุณสมบัติ gets or sets the default value of the ShowPercentage คุณสมบัติ for the new data labels in the DataLabelCollection collection. 
            Set this คุณสมบัติ with value also sets this value to the ShowPercentage คุณสมบัติ for all data labels in the DataLabelCollection collection
            (i.e. "DataLabels.DefaultDataLabelFormat.ShowPercentage = val;" cause to 
            all DataLabels[i].ShowPercentage is equal to val).
