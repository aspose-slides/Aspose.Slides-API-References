## position คุณสมบัติ
แสดงตำแหน่งของป้ายข้อมูล.
อ่าน/เขียน [`LegendDataLabelPosition`](/slides/python-net/th/aspose.slides.charts/legenddatalabelposition).

### หมายเหตุ
If parent of this DataLabelFormat object is a DataLabelCollection collection of data labels then this
            คุณสมบัติรับหรือกำหนดค่ากำหนดเริ่มต้นของคุณสมบัติ Position สำหรับข้อมูลใหม่ 
            ป้ายในคอลเลกชัน DataLabelCollection.
            แสดงตำแหน่งสำหรับวัตถุ DataLabel.
            กำหนดคุณสมบัตินี้ด้วยค่า จะทำให้ค่านี้ถูกกำหนดให้กับคุณสมบัติ Position 
            สำหรับป้ายข้อมูลทั้งหมดในคอลเลกชัน DataLabelCollection
            (เช่น "DataLabels.DefaultDataLabelFormat.Position = val;" ทำให้ 
            ตำแหน่ง DataLabels[i].Position ทั้งหมดเท่ากับ val).
