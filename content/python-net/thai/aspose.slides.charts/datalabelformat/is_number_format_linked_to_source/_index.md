## is_number_format_linked_to_source คุณสมบัติ
อ่าน/เขียน **bool**.

### หมายเหตุ

ถ้า parent ของวัตถุ DataLabelFormat นี้เป็นคอลเลกชัน DataLabelCollection ของป้ายข้อมูลแล้ว
            property นี้จะรับหรือกำหนดค่าเริ่มต้นของ property IsNumberFormatLinkedToSource สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน DataLabelCollection
            การตั้งค่า property นี้ด้วยค่าจะกำหนดค่าที่เดียวกันให้กับ property IsNumberFormatLinkedToSource สำหรับป้ายข้อมูลทั้งหมดในคอลเลกชัน DataLabelCollection
            (i.e. "DataLabels.DefaultDataLabelFormat.IsNumberFormatLinkedToSource = val;" ทำให้
            ทั้งหมด DataLabels[i].IsNumberFormatLinkedToSource มีค่าเท่ากับ val).
