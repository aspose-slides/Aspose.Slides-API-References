## show_label_value_from_cell คุณสมบัติ
แสดงถึงพฤติกรรมการแสดงค่าของเซลล์ป้ายข้อมูลในแผนภูมิที่ระบุ. 
True แสดงค่าของเซลล์. False เพื่อซ่อน.
อ่าน/เขียน **bool**.

### หมายเหตุ

หากพาเรนต์ของอ็อบเจกต์ DataLabelFormat นี้เป็นคอลเลกชัน DataLabelCollection ของป้ายข้อมูลแล้ว คุณสมบัตินี้รับหรือกำหนดค่าเริ่มต้นของคุณสมบัติ ShowLabelValueFromCell สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน DataLabelCollection.
การตั้งค่าคุณสมบัตินี้ด้วยค่าเดียวกันยังกำหนดค่านี้ให้กับคุณสมบัติ ShowLabelValueFromCell สำหรับป้ายข้อมูลทั้งหมดในคอลเลกชัน DataLabelCollection
(เช่น "DataLabels.DefaultDataLabelFormat.ShowLabelValueFromCell = val;" ทำให้ทุก DataLabels[i].ShowLabelValueFromCell มีค่าเท่ากับ val).
