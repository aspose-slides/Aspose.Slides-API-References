## show_bubble_size คุณสมบัติ
เป็นการแสดงพฤติกรรมการแสดงค่าขนาดฟองของป้ายข้อมูลในแผนภูมิที่ระบุ  
True แสดงค่าขนาดฟอง. False เพื่อซ่อน.  
อ่าน/เขียน **bool**.


### หมายเหตุ

หากพาเรนต์ของอ็อบเจ็กต์ DataLabelFormat นี้เป็นคอลเลกชัน DataLabelCollection ของป้ายข้อมูล จะทำให้คุณสมบัตินี้ได้รับหรือกำหนดค่าปริยายของ ShowBubbleSize คุณสมบัติสำหรับป้ายข้อมูลใหม่ในคอลเลกชัน DataLabelCollection  
การตั้งค่าคุณสมบัตินี้ด้วยค่าใดค่าหนึ่งจะกำหนดค่านั้นให้กับ ShowBubbleSize คุณสมบัติสำหรับป้ายข้อมูลทั้งหมดในคอลเลกชัน DataLabelCollection  
(i.e. "DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;" ทำให้ DataLabels[i].ShowBubbleSize ทั้งหมดมีค่าเท่ากับ val).
