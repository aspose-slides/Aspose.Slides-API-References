## Legend คลาส

เป็นตัวแทนของคุณสมบัติ legend ของแผนภูมิ

ประเภท Legend แสดงสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`x`](/slides/python-net/th/aspose.slides.charts/legend/x/) | คืนหรือกำหนดค่าพิกัด x ของ legend เป็นส่วนของความกว้างของแผนภูมิ.<br/>            อ่าน/เขียน **float**. |
| [`y`](/slides/python-net/th/aspose.slides.charts/legend/y/) | คืนหรือกำหนดค่าพิกัด y ของ legend เป็นส่วนของความสูงของแผนภูมิ.<br/>            อ่าน/เขียน **float**. |
| [`width`](/slides/python-net/th/aspose.slides.charts/legend/width/) | คืนหรือกำหนดค่าความกว้างของ legend เป็นส่วนของความกว้างของแผนภูมิ.<br/>            อ่าน/เขียน **float**. |
| [`height`](/slides/python-net/th/aspose.slides.charts/legend/height/) | คืนหรือกำหนดค่าความสูงของ legend เป็นส่วนของความสูงของแผนภูมิ.<br/>            อ่าน/เขียน **float**. |
| [`right`](/slides/python-net/th/aspose.slides.charts/legend/right/) | ด้านขวา.<br/>            อ่านอย่างเดียว **float**. |
| [`bottom`](/slides/python-net/th/aspose.slides.charts/legend/bottom/) | ด้านล่าง.<br/>            อ่านอย่างเดียว **float**. |
| [`overlay`](/slides/python-net/th/aspose.slides.charts/legend/overlay/) | กำหนดว่ารายการแผนภูมิอื่น ๆ จะได้รับอนุญาตให้ทับเหนือ legend หรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`text_format`](/slides/python-net/th/aspose.slides.charts/legend/text_format/) | รูปแบบข้อความ.<br/>            อ่านอย่างเดียว [`IChartTextFormat`](/slides/python-net/th/aspose.slides.charts/icharttextformat). |
| [`position`](/slides/python-net/th/aspose.slides.charts/legend/position/) | ระบุตำแหน่งของ legend บนแผนภูมิ.<br/>            ค่าที่ไม่เป็น NaN ของคุณสมบัติ X, Y, Width, Heigt จะเหนือผลของคุณสมบัตินี้.<br/>            อ่าน/เขียน [`LegendPositionType`](/slides/python-net/th/aspose.slides.charts/legendpositiontype). |
| [`format`](/slides/python-net/th/aspose.slides.charts/legend/format/) | ส่งคืนรูปแบบของ legend.<br/>            อ่านอย่างเดียว [`IFormat`](/slides/python-net/th/aspose.slides.charts/iformat). |
| [`chart`](/slides/python-net/th/aspose.slides.charts/legend/chart/) | ส่งคืนแผนภูมิ.<br/>            อ่านอย่างเดียว [`IChart`](/slides/python-net/th/aspose.slides.charts/ichart). |
| [`entries`](/slides/python-net/th/aspose.slides.charts/legend/entries/) | รับรายการ legend.<br/>            อ่านอย่างเดียว [`ILegendEntryCollection`](/slides/python-net/th/aspose.slides.charts/ilegendentrycollection). |
| [`actual_x`](/slides/python-net/th/aspose.slides.charts/legend/actual_x/) | ระบุตำแหน่ง x จริง (ด้านซ้าย) ขององค์ประกอบแผนภูมิเกี่ยวข้องกับมุมซ้ายบนของแผนภูมิ.<br/>            เรียกเมธ็อด IChart.ValidateChartLayout() ก่อนเพื่อรับค่าจริง. <br/>            อ่าน **float**. |
| [`actual_y`](/slides/python-net/th/aspose.slides.charts/legend/actual_y/) | ระบุตำแหน่งบนจริงขององค์ประกอบแผนภูมิเกี่ยวข้องกับมุมซ้ายบนของแผนภูมิ.<br/>            เรียกเมธ็อด IChart.ValidateChartLayout() ก่อนเพื่อรับค่าจริง. <br/>            อ่าน **float**. |
| [`actual_width`](/slides/python-net/th/aspose.slides.charts/legend/actual_width/) | ระบุความกว้างจริงขององค์ประกอบแผนภูมิ. เรียกเมธ็อด IChart.ValidateChartLayout() ก่อนเพื่อรับค่าจริง. <br/>            อ่าน **float**. |
| [`actual_height`](/slides/python-net/th/aspose.slides.charts/legend/actual_height/) | ระบุความสูงจริงขององค์ประกอบแผนภูมิ. เรียกเมธ็อด IChart.ValidateChartLayout() ก่อนเพื่อรับค่าจริง. <br/>            อ่าน **float**. |
| [`slide`](/slides/python-net/th/aspose.slides.charts/legend/slide/) |  |
| [`presentation`](/slides/python-net/th/aspose.slides.charts/legend/presentation/) |  |
