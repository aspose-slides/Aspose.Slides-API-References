## IChartWall คลาส

แสดงผนังบนกราฟ 3 มิติ.

ประเภท IChartWall เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`thickness`](/slides/python-net/th/aspose.slides.charts/ichartwall/thickness/) | คืนค่า หรือ ตั้งค่าความหนาของผนังเป็นเปอร์เซ็นต์ของมิติที่ใหญ่ที่สุดของปริมาณกราฟ.<br/>            อ่าน/เขียน **int**. |
| [`format`](/slides/python-net/th/aspose.slides.charts/ichartwall/format/) | คืนค่าการเติมสีของผนัง, เส้น, เอฟเฟกต์, สไตล์ 3 มิติ.<br/>            อ่านอย่างเดียว [`IFormat`](/slides/python-net/th/aspose.slides.charts/iformat). |
| [`picture_type`](/slides/python-net/th/aspose.slides.charts/ichartwall/picture_type/) | คืนค่า หรือ ตั้งค่าชนิดของรูปภาพ.<br/>            อ่าน/เขียน [`IChartWall.picture_type`](/slides/python-net/th/aspose.slides.charts/ichartwall/picture_type). |
