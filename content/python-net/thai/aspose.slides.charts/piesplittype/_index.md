## การกำหนดค่า PieSplitType

แสดงประเภทของจุดแบ่งในพายหรือแถบที่สองบนแผนภูมิแบบ pie-of-pie หรือ bar-of-pie.

ชนิด PieSplitType มีสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | รายละเอียด |
| :- | :- |
| DEFAULT | ระบุว่าจุดข้อมูลจะถูกแบ่งโดยใช้กลไกเริ่มต้น <br/>            สำหรับประเภทแผนภูมินี้. |
| CUSTOM | ระบุว่าจุดข้อมูลจะถูกแบ่งระหว่าง <br/>            พายและแผนภูมที่สองตามค่าการแยกแบบกำหนดเอง. |
| BY_PERCENTAGE | ระบุว่าจุดข้อมูลจะถูกแบ่งระหว่างพายและ <br/>            แผนภูมที่สองโดยวางจุดที่มีเปอร์เซ็นต์น้อยกว่า <br/>            เปอร์เซ็นต์ตำแหน่งการแยกในแผนภูมที่สอง. |
| BY_POS | ระบุว่าจุดข้อมูลจะถูกแบ่งระหว่างพายและ <br/>            แผนภูมที่สองโดยวางตำแหน่งการแยกสุดท้ายของจุดข้อมูล <br/>            ในแผนภูมที่สอง. |
| BY_VALUE | ระบุว่จุดข้อมูลจะถูกแบ่งระหว่างพายและ <br/>           แผนภูมที่สองโดยวางจุดข้อมูลที่มีค่าน้อยกว่า <br/>           ตำแหน่งการแยกในแผนภูมที่สอง. |
