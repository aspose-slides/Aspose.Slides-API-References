## Rotation3D คลาส

Represents 3D rotation of a chart.

The Rotation3D type exposes the following members:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`rotation_x`](/slides/python-net/th/aspose.slides.charts/rotation3d/rotation_x/) | คืนค่า หรือกำหนดมุมการหมุนรอบแกน X ซึ่งหมายถึงทิศทาง Y สำหรับแผนภูมิ 3 มิติ (ระหว่าง -90 ถึง 90 องศา).<br/>            คุณสมบัตินี้สอดคล้องกับรายการ 21.2.2.157 rotX (X Rotation) ใน ECMA-376 และกับตัวเลือก "Y Rotation" ใน PowerPoint 2007+.<br/>            อ่าน/เขียน **int**. |
| [`rotation_y`](/slides/python-net/th/aspose.slides.charts/rotation3d/rotation_y/) | คืนค่า หรือกำหนดมุมการหมุนรอบแกน Y ซึ่งหมายถึงทิศทาง X สำหรับแผนภูมิ 3 มิติ (ระหว่าง 0 ถึง 360 องศา).<br/>            คุณสมบัตินี้สอดคล้องกับรายการ 21.2.2.158 rotY (Y Rotation) ใน ECMA-376 และกับตัวเลือก "X Rotation" ใน PowerPoint 2007+.<br/>            อ่าน/เขียน **int**. |
| [`perspective`](/slides/python-net/th/aspose.slides.charts/rotation3d/perspective/) | คืนค่า หรือกำหนดค่ามุมมอง (มุมมองฟิลด์) สำหรับแผนภูมิ 3 มิติ (ระหว่าง 0 ถึง 240).<br/>            จะถูกละเว้นหากค่าคุณสมบัติ RightAngleAxes เป็น true.<br/>            อ่าน/เขียน **int**. |
| [`right_angle_axes`](/slides/python-net/th/aspose.slides.charts/rotation3d/right_angle_axes/) | กำหนดว่าแกนของแผนภูมิจะเป็นมุมฉากหรือไม่ แทนที่จะวาดในมุมมองเชิงพิเศษ.<br/>            กล่าวคือ จะกำหนดว่ามุมแกนของแผนภูมิเป็นอิสระจากการหมุน<br/>            หรือการยกของแผนภูมิหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`depth_percents`](/slides/python-net/th/aspose.slides.charts/rotation3d/depth_percents/) | คืนค่า หรือกำหนดความลึกของแผนภูมิ 3 มิติเป็นเปอร์เซ็นต์ของความกว้างแผนภูมิ (ระหว่าง 20 ถึง 2000 เปอร์เซ็นต์).<br/>            อ่าน/เขียน **int**. |
| [`height_percents`](/slides/python-net/th/aspose.slides.charts/rotation3d/height_percents/) | ระบุความสูงของแผนภูมิ 3-D เป็นเปอร์เซ็นต์ของความกว้างแผนภูมิ (ระหว่าง 5 ถึง 500 เปอร์เซ็นต์).<br/>            อ่าน/เขียน **int**. |
