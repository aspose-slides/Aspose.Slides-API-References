## is_chart_type_scatter(chart_type) {#charttype}
คืนค่า true หาก chartType เป็นหนึ่งในประเภทย่อย Scatter.
            ชุดประเภทย่อยสอดคล้องกับชุดที่เหมาะสมใน PowerPoint (ดู "เปลี่ยนประเภทแผนภูมิ" ใน PowerPoint):

            [`ChartType.SCATTER_WITH_SMOOTH_LINES`](/slides/python-net/th/aspose.slides.charts/charttype/SCATTER_WITH_SMOOTH_LINES),
            [`ChartType.SCATTER_WITH_SMOOTH_LINES_AND_MARKERS`](/slides/python-net/th/aspose.slides.charts/charttype/SCATTER_WITH_SMOOTH_LINES_AND_MARKERS),
            [`ChartType.SCATTER_WITH_STRAIGHT_LINES`](/slides/python-net/th/aspose.slides.charts/charttype/SCATTER_WITH_STRAIGHT_LINES),
            [`ChartType.SCATTER_WITH_STRAIGHT_LINES_AND_MARKERS`](/slides/python-net/th/aspose.slides.charts/charttype/SCATTER_WITH_STRAIGHT_LINES_AND_MARKERS).
