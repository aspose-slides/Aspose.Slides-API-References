## data_source_type คุณสมบัติ
ระบุว่า AsCell, AsCells, AsLiteralString หรือ AsLiteralDouble คุณสมบัติเป็นของจริงในคลาสลูก หรือไม่ ในคำอื่นหมายถึงระบุประเภทของค่าของ Data คุณสมบัติ
อ่าน/เขียน [`DataSourceType`](/slides/python-net/th/aspose.slides.charts/datasourcetype).

### หมายเหตุ

สำหรับจุดใน ChartDataPointCollection คุณสมบัตินี้เป็นแบบอ่านอย่างเดียว
ในกรณีนี้เพื่อเปลี่ยนค่าของคุณสมบัตินี้ คุณสามารถใช้หนึ่งใน ChartDataPointCollection.DataSourceTypeFor<...> คุณสมบัติ
