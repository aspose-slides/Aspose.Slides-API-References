## IErrorBarsFormat คลาส

แทนแท่งข้อผิดพลาดของชุดข้อมูลแผนภูมิ. ค่ากำหนดเองของ ErrorBars อยู่ใน IChartDataPointCollection (ในคุณสมบัติ [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/th/aspose.slides.charts/ichartdatapoint/error_bars_custom_values)).

ประเภท IErrorBarsFormat แสดงสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`type`](/slides/python-net/th/aspose.slides.charts/ierrorbarsformat/type/) | รับหรือกำหนดประเภทของแท่งข้อผิดพลาด.<br/>            อ่าน/เขียน [`ErrorBarType`](/slides/python-net/th/aspose.slides.charts/errorbartype). |
| [`value_type`](/slides/python-net/th/aspose.slides.charts/ierrorbarsformat/value_type/) | แสดงวิธีที่เป็นไปได้ในการกำหนดความยาวของแท่งข้อผิดพลาด.<br/>            ในกรณีที่เป็นประเภทค่ากำหนดเองเพื่อระบุค่าใช้คุณสมบัติ [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/th/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) ของจุดข้อมูลเฉพาะในคอลเลกชัน DataPoints ของชุดข้อมูล.<br/>            อ่าน/เขียน [`ErrorBarValueType`](/slides/python-net/th/aspose.slides.charts/errorbarvaluetype). |
| [`has_end_cap`](/slides/python-net/th/aspose.slides.charts/ierrorbarsformat/has_end_cap/) | ระบุว่าปลายหัวไม่ถูกวาดบนแท่งข้อผิดพลาด.<br/>            อ่าน/เขียน **bool**. |
| [`value`](/slides/python-net/th/aspose.slides.charts/ierrorbarsformat/value/) | รับหรือกำหนดค่าที่ใช้ร่วมกับประเภทค่าที่ Fixed, Percentage และ StandardDeviation เพื่อกำหนดความยาวของแท่งข้อผิดพลาด.<br/>            อ่าน/เขียน **float**. |
| [`format`](/slides/python-net/th/aspose.slides.charts/ierrorbarsformat/format/) | แสดงรูปแบบของแท่งข้อผิดพลาด.<br/>            อ่าน/เขียน [`IFormat`](/slides/python-net/th/aspose.slides.charts/iformat). |
| [`is_visible`](/slides/python-net/th/aspose.slides.charts/ierrorbarsformat/is_visible/) | รับหรือกำหนดการมองเห็นของ Error Bars.<br/>            อ่าน/เขียน **bool**. |
