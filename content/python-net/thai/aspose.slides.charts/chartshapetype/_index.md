## ChartShapeType enum

แทนรูปร่างของแผนภูมิ

ประเภท ChartShapeType เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| NOT_DEFINED | รูปร่างของแผนภูมิไม่ได้กำหนด. |
| BOX | ระบุว่าแผนภูมิจะถูกวาดด้วยรูปทรงกล่อง. |
| CONE | ระบุว่าแผนภูมิจะถูกวาดเป็นรูปกรวย โดยฐานของกรวยวางบนพื้นและปลายของกรวยอยู่ที่ด้านบนของเครื่องหมายข้อมูล. |
| CONE_TO_MAX | ระบุว่าแผนภูมิจะถูกวาดด้วยกรวยตัดส่วนที่ทำให้ปลายกรวยเป็นค่าสูงสุดของข้อมูล. |
| CYLINDER | ระบุว่าแผนภูมิจะถูกวาดเป็นรูปทรงกระบอก. |
| PYRAMID | ระบุว่าแผนภูมิจะถูกวาดเป็นรูปพีระมิดสี่เหลี่ยม โดยฐานของพีระมิดวางบนพื้นและยอดของพีระมิดอยู่ที่ด้านบนของเครื่องหมายข้อมูล. |
| PYRAMID_TO_MAXIMUM | ระบุว่าแผนภูมิจะถูกวาดด้วยพีระมิดตัดส่วนที่ทำให้ยอดของพีระมิดเป็นค่าสูงสุดของข้อมูล. |
