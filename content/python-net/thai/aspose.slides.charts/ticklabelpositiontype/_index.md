## TickLabelPositionType enumeration

แสดงถึงประเภทตำแหน่งของป้ายกำกับ tick-mark บนแกนที่ระบุ

ประเภท TickLabelPositionType มีสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| HIGH | ระบุว่าป้ายกำกับแกนจะอยู่ที่ด้านบนของแกนตั้งฉาก |
| LOW | ระบุว่าป้ายกำกับแกนจะอยู่ที่ด้านล่างของแกนตั้งฉาก |
| NEXT_TO | ระบุว่าป้ายกำกับแกนจะอยู่ถัดจากแกน |
| NONE | ระบุว่าป้ายกำกับแกนจะไม่ถูกวาด |
