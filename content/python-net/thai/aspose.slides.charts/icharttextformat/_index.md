## IChartTextFormat คลาส

แผนภูมิทำงานด้วยชุดจำกัดของคุณสมบัติการจัดรูปแบบข้อความ.
IChartTextFormat, IChartTextBlockFormat, IChartParagraphFormat, IChartPortionFormat อินเทอร์เฟซอธิบายชุดจำกัดนี้.

ชนิด IChartTextFormat เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`text_block_format`](/slides/python-net/th/aspose.slides.charts/icharttextformat/text_block_format/) | ส่งคืนฟอร์แมตสำหรับองค์ประกอบข้อความของแผนภูมิ.<br/>            อ่านอย่างเดียว [`IChartTextBlockFormat`](/slides/python-net/th/aspose.slides.charts/icharttextblockformat). |
| [`paragraph_format`](/slides/python-net/th/aspose.slides.charts/icharttextformat/paragraph_format/) | ส่งคืนฟอร์แมตย่อหน้า.<br/>            อ่านอย่างเดียว [`IChartParagraphFormat`](/slides/python-net/th/aspose.slides.charts/ichartparagraphformat). |
| [`portion_format`](/slides/python-net/th/aspose.slides.charts/icharttextformat/portion_format/) | ส่งคืนฟอร์แมตส่วนที่.<br/>            อ่านอย่างเดียว [`IChartPortionFormat`](/slides/python-net/th/aspose.slides.charts/ichartportionformat). |
