## gap_width คุณลักษณะ
รับหรือกำหนดช่องว่างระหว่างกลุ่มแท่งหรือคอลัมน์ เป็นเปอร์เซ็นต์ของความกว้างของแท่งหรือคอลัมน์
            ค่าต้องอยู่ระหว่าง 0 ถึง 500.
            อ่าน/เขียน **int**.

### หมายเหตุ

            Column subtypes (ดูเพิ่มเติมที่ **Aspose.Slides.Charts.ChartTypeCharacterizer.IsChartTypeColumn(Aspose.Slides.Chart** method),

            [`ChartType.PIE_OF_PIE`](/slides/python-net/th/aspose.slides.charts/charttype/PIE_OF_PIE),
            [`ChartType.BOX_AND_WHISKER`](/slides/python-net/th/aspose.slides.charts/charttype/BOX_AND_WHISKER),
            [`ChartType.FUNNEL`](/slides/python-net/th/aspose.slides.charts/charttype/FUNNEL),
            [`ChartType.HISTOGRAM`](/slides/python-net/th/aspose.slides.charts/charttype/HISTOGRAM),
