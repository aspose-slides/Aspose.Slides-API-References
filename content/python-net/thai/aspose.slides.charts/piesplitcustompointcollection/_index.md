## PieSplitCustomPointCollection คลาส

แสดงถึงคอลเลกชันของจุดสำหรับการแยกจุดในแผนภูมิแบบ bar-of-pie หรือ pie-of-pie ด้วยการแยกแบบกำหนดเอง。

ประเภท PieSplitCustomPointCollection เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`is_synchronized`](/slides/python-net/th/aspose.slides.charts/piesplitcustompointcollection/is_synchronized/) | ส่งคืนค่าแสดงว่าการเข้าถึงคอลเลกชันนี้มีการประสาน (ทำให้เป็นเธรด-เซฟ).<br/>            อ่านอย่างเดียว **bool**. |
| [`sync_root`](/slides/python-net/th/aspose.slides.charts/piesplitcustompointcollection/sync_root/) | ส่งคืนรากของการประสานงาน.<br/>            อ่านอย่างเดียว **any**. |

ส่งคืนจุดข้อมูลแผนภูมิสำหรับดัชนีที่ระบุ。
