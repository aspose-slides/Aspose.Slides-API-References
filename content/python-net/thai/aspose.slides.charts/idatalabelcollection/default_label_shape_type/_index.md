## default_label_shape_type คุณสมบัติ

             คืนค่า [`ShapeType.NOT_DEFINED`](/slides/python-net/th/aspose.slides/shapetype/NOT_DEFINED) หากไม่มีรูปแบบที่กำหนด.

             สำหรับป้ายข้อมูลทั้งหมดในคอลเลกชันให้เป็นค่าเดียวกัน.
