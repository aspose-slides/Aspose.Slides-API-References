## hide(self) {#}
ทำให้ป้ายข้อมูลถูกซ่อนเป็นค่าเริ่มต้นโดยตั้งค่าทุก Show*-flags (ShowValue, ...) ของ
            DefaultDataLabelFormat คุณสมบัติเป็นสถานะ false.
            IsVisible จะเป็น false หลังจากนี้.

```python
def hide(self):
    ...
```

### หมายเหตุ
หากป้ายข้อมูลไม่แสดงเป็นค่าเริ่มต้น (IsVisible เป็น false) คุณสามารถทำให้ป้ายข้อมูล "visible
            by default" ด้วยการตั้งค่า Show*-flags (ShowValue, ...) ของ DefaultDataLabelFormat คุณสมบัติ
            เป็นสถานะ true.
