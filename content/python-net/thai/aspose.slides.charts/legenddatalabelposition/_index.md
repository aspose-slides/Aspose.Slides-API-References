## LegendDataLabelPosition enumeration

กำหนดตำแหน่งของป้ายข้อมูล.

ประเภท LegendDataLabelPosition เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| NOT_DEFINED | ตำแหน่งไม่ได้กำหนด. |
| BOTTOM | ระบุว่าป้ายข้อมูลจะแสดงอยู่ด้านล่างของเครื่องหมายข้อมูล. |
| BEST_FIT | ระบุว่าป้ายข้อมูลจะแสดงในตำแหน่งที่ดีที่สุด. |
| CENTER | ระบุว่าป้ายข้อมูลจะแสดงตรงกลางของเครื่องหมายข้อมูล. |
| INSIDE_BASE | ระบุว่าป้ายข้อมูลจะแสดงภายในฐานของเครื่องหมายข้อมูล. |
| INSIDE_END | ระบุว่าป้ายข้อมูลจะแสดงภายในส่วนปลายของเครื่องหมายข้อมูล. |
| LEFT | ระบุว่าป้ายข้อมูลจะแสดงทางด้านซ้ายของเครื่องหมายข้อมูล. |
| OUTSIDE_END | ระบุว่าป้ายข้อมูลจะแสดงอยู่นอกส่วนปลายของเครื่องหมายข้อมูล. |
| RIGHT | ระบุว่าป้ายข้อมูลจะแสดงทางด้านขวาของเครื่องหมายข้อมูล. |
| TOP | ระบุว่าป้ายข้อมูลจะแสดงอยู่เหนือเครื่องหมายข้อมูล. |
