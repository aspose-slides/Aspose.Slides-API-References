## IOverridableText class

เป็นข้อความที่สามารถทำการแทนที่ได้สำหรับแผนภูมิ.

ประเภท IOverridableText แสดงสมาชิกต่อไปนี้:

## Properties

| คุณสมบัติ | คำอธิบาย |

| [`text_frame_for_overriding`](/slides/python-net/th/aspose.slides.charts/ioverridabletext/text_frame_for_overriding/) | สามารถบรรจุข้อความที่จัดรูปแบบอย่างสมบูรณ์ได้. หากคุณสมบัตินี้ไม่เท่ากับ None แล้วค่าข้อความที่จัดรูปแบบนี้ <br/>            จะทับข้อความที่สร้างโดยอัตโนมัติ.<br/>            ข้อความที่สร้างโดยอัตโนมัติเป็นคุณสมบัติโดยนัยของป้ายกำกับข้อมูล, ป้ายกำกับหน่วยการแสดงผลของแกนค่า, ชื่อแกน, ชื่อแผนภูมิ, ป้ายกำกับของเส้นแนวโน้ม.<br/>            ข้อความที่สร้างโดยอัตโนมัติได้รับการจัดรูปแบบด้วยคุณสมบัติ IFormattedTextContainer.TextFormat.<br/>            อ่านอย่างเดียว [`ITextFrame`](/slides/python-net/th/aspose.slides/itextframe). |
