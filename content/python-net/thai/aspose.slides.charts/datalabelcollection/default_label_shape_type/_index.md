## default_label_shape_type คุณสมบัติ
รับหรือกำหนดประเภทรูปแบบเริ่มต้นสำหรับป้ายข้อมูล.
             ส่งคืน [`ShapeType.NOT_DEFINED`](/slides/python-net/th/aspose.slides/shapetype/NOT_DEFINED) หากไม่มีรูปที่กำหนด.

### หมายเหตุ

การตั้งค่าคุณสมบัตินี้ยังตั้งค่า [`IDataLabel.label_shape_type`](/slides/python-net/th/aspose.slides.charts/idatalabel/label_shape_type) คุณสมบัติ
             สำหรับป้ายข้อมูลทั้งหมดในชุดเป็นค่าเดียวกัน.
