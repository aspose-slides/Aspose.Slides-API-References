## hide(self) {#}
ทำให้ป้ายข้อมูลซ่อนโดยค่าเริ่มต้นโดยตั้งค่าแฟล็ก Show*-ทั้งหมด (ShowValue, ...) ของคุณสมบัติ DefaultDataLabelFormat ให้เป็นสถานะ false.
            IsVisible จะเป็น false หลังจากนี้.


```python
def hide(self):
    ...
```


### หมายเหตุ
หากป้ายข้อมูลไม่แสดงโดยค่าเริ่มต้น (IsVisible เป็น false) คุณสามารถทำให้ป้ายข้อมูล "visible 
            by default" ด้วยการตั้งค่าแฟล็ก Show*-ทั้งหมด (ShowValue, ...) ของคุณสมบัติ DefaultDataLabelFormat
            ให้เป็นสถานะ true.
