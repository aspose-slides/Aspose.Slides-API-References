## คุณสมบัติ is_visible
False หมายถึง data label ไม่แสดงโดยค่าเริ่มต้น (และดังนั้นทั้งหมด Show*-flags (ShowValue, ...) ของคุณสมบัติ DefaultDataLabelFormat จะเป็น false). อ่านอย่างเดียว **bool**.

### หมายเหตุ
If data label is visible by default you can make it hidden by default with Hide() วิธี.  
But if data label is not visible by default (IsVisible is false) you can make data label "visible by default" with setting Show*-flags (ShowValue, ...) of the DefaultDataLabelFormat property to true state.
