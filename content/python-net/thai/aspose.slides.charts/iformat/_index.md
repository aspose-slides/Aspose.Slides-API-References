## IFormat คลาส

แสดงคุณสมบัติรูปแบบของแผนภูมิ

ประเภท IFormat เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`fill`](/slides/python-net/th/aspose.slides.charts/iformat/fill/) | คืนค่าคุณสมบัติสไตล์การเติมของแผนภูมิ.<br/>            อ่านอย่างเดียว [`IFillFormat`](/slides/python-net/th/aspose.slides/ifillformat). |
| [`line`](/slides/python-net/th/aspose.slides.charts/iformat/line/) | คืนค่าคุณสมบัติสไตล์เส้นของแผนภูมิ.<br/>            อ่านอย่างเดียว [`ILineFormat`](/slides/python-net/th/aspose.slides/ilineformat). |
| [`effect`](/slides/python-net/th/aspose.slides.charts/iformat/effect/) | คืนค่าเอฟเฟ็กต์ที่ใช้สำหรับแผนภูมิ.<br/>            อ่านอย่างเดียว [`IEffectFormat`](/slides/python-net/th/aspose.slides/ieffectformat). |
| [`effect_3d`](/slides/python-net/th/aspose.slides.charts/iformat/effect_3d/) | คืนค่ารูปแบบ 3 มิติของแผนภูมิ.<br/>            อ่านอย่างเดียว [`IThreeDFormat`](/slides/python-net/th/aspose.slides/ithreedformat). |
