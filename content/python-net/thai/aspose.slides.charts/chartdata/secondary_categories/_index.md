## secondary_categories คุณสมบัติ
รับค่าหมวดหมู่รองถ้า [`ChartData.use_secondary_categories`](/slides/python-net/th/aspose.slides.charts/chartdata/use_secondary_categories) คุณสมบัติเป็น true.
            อ่านอย่างเดียว [`IChartCategoryCollection`](/slides/python-net/th/aspose.slides.charts/ichartcategorycollection).


### หมายเหตุ

If [`ChartData.use_secondary_categories`](/slides/python-net/th/aspose.slides.charts/chartdata/use_secondary_categories) คุณสมบัติเป็น false then this [`ChartData.secondary_categories`](/slides/python-net/th/aspose.slides.charts/chartdata/secondary_categories) 
            property return None and data in [`ChartData.categories`](/slides/python-net/th/aspose.slides.charts/chartdata/categories) คุณสมบัติ is used both for primary 
            and secondary series.
            If [`ChartData.use_secondary_categories`](/slides/python-net/th/aspose.slides.charts/chartdata/use_secondary_categories) คุณสมบัติเป็น true then data in 
            this [`ChartData.secondary_categories`](/slides/python-net/th/aspose.slides.charts/chartdata/secondary_categories) คุณสมบัติ is used for secondary series and data 
            in [`ChartData.categories`](/slides/python-net/th/aspose.slides.charts/chartdata/categories) คุณสมบัติ is used for primary series.
