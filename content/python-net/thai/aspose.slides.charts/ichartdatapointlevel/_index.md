## IChartDataPointLevel คลาส

แสดงระดับจุดข้อมูล ใช้กับแผนภูมิ Treemap และ Sunburst.

ประเภท IChartDataPointLevel เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`format`](/slides/python-net/th/aspose.slides.charts/ichartdatapointlevel/format/) | แสดงคุณสมบัติการจัดรูปแบบของระดับจุดข้อมูล.<br/>            อ่าน/เขียน [`IFormat`](/slides/python-net/th/aspose.slides.charts/iformat). |
| [`label`](/slides/python-net/th/aspose.slides.charts/ichartdatapointlevel/label/) | แสดงป้ายข้อมูลของระดับจุดข้อมูล ใช้สำหรับประเภท Treemap และ Sunburst sereis.<br/>             อ่านอย่างเดียว [`IDataLabel`](/slides/python-net/th/aspose.slides.charts/idatalabel). |
