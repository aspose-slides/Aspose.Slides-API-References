## ITrendline คลาส

คลาสแทนเส้นแนวโน้มของชุดข้อมูลแผนภูมิ

ประเภท ITrendline เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`trendline_name`](/slides/python-net/th/aspose.slides.charts/itrendline/trendline_name/) | รับหรือกำหนดชื่อของเส้นแนวโน้ม.<br/>            อ่าน/เขียน **str**. |
| [`trendline_type`](/slides/python-net/th/aspose.slides.charts/itrendline/trendline_type/) | รับหรือกำหนดประเภทของเส้นแนวโน้ม. <br/>            อ่าน/เขียน [`ITrendline.trendline_type`](/slides/python-net/th/aspose.slides.charts/itrendline/trendline_type). |
| [`format`](/slides/python-net/th/aspose.slides.charts/itrendline/format/) | แสดงรูปแบบของเส้นแนวโน้ม.<br/>            อ่าน/เขียน [`IFormat`](/slides/python-net/th/aspose.slides.charts/iformat). |
| [`backward`](/slides/python-net/th/aspose.slides.charts/itrendline/backward/) | ระบุจำนวนของหมวดหมู่ (หรือหน่วยในแผนภูมิแบบกระจาย) ที่เส้นแนวโน้มขยายออกไปก่อน<br/>            ข้อมูลของชุดข้อมูลที่กำลังวิเคราะห์. ในแผนภูมิแบบกระจายและไม่ใช่แบบกระจาย, ค่าต้องเป็นค่าไม่เป็นลบใด ๆ<br/>            ค่า.<br/>            อ่าน/เขียน **float**. |
| [`forward`](/slides/python-net/th/aspose.slides.charts/itrendline/forward/) | ระบุจำนวนของหมวดหมู่ (หรือหน่วยในแผนภูมิแบบกระจาย) ที่เส้นแนวโน้มขยายออกไปหลังจาก<br/>            ข้อมูลของชุดข้อมูลที่กำลังวิเคราะห์. ในแผนภูมิแบบกระจายและไม่ใช่แบบกระจาย, ค่าต้องเป็นค่าไม่เป็นลบใด ๆ<br/>            ค่า.<br/>            อ่าน/เขียน **float**. |
| [`intercept`](/slides/python-net/th/aspose.slides.charts/itrendline/intercept/) | ระบุค่าที่เส้นแนวโน้มจะตัดแกน y. คุณสมบัตินี้จะสนับสนุนเฉพาะเมื่อประเภทของเส้นแนวโน้มเป็น exp, linear, หรือ poly.<br/>            อ่าน/เขียน **float**. |
| [`display_equation`](/slides/python-net/th/aspose.slides.charts/itrendline/display_equation/) | ระบุว่าสมการของเส้นแนวโน้มจะแสดงบนแผนภูมิ (ในป้ายเดียวกับค่า Rsquaredvalue).<br/>            อ่าน/เขียน **bool**. |
| [`order`](/slides/python-net/th/aspose.slides.charts/itrendline/order/) | ระบุลำดับของเส้นแนวโน้มแบบพหูพจน์. จะถูกละเว้นสำหรับประเภทเส้นแนวโน้มอื่น. ค่าต้องอยู่ระหว่าง 2 ถึง 6.<br/>            อ่าน/เขียน **int**. |
| [`period`](/slides/python-net/th/aspose.slides.charts/itrendline/period/) | ระบุช่วงเวลาของเส้นแนวโน้มสำหรับเส้นแนวโน้มค่าเฉลี่ยเคลื่อนที่. จะถูกละเว้นสำหรับรูปแบบเส้นแนวโน้มอื่น.<br/>            ค่าต้องอยู่ระหว่าง 2 ถึง 255.<br/>            อ่าน/เขียน **int**. |
| [`display_r_squared_value`](/slides/python-net/th/aspose.slides.charts/itrendline/display_r_squared_value/) | ระบุว่าค่า R-squared ของเส้นแนวโน้มจะแสดงบนแผนภูมิ (ในป้ายเดียวกับสมการ).<br/>            อ่าน/เขียน **bool**. |
| [`related_legend_entry`](/slides/python-net/th/aspose.slides.charts/itrendline/related_legend_entry/) | แสดงรายการคำอธิบายที่เกี่ยวข้องกับเส้นแนวโน้มนี้<br/>            อ่านอย่างเดียว [`ILegendEntryProperties`](/slides/python-net/th/aspose.slides.charts/ilegendentryproperties). |
| [`text_frame_for_overriding`](/slides/python-net/th/aspose.slides.charts/itrendline/text_frame_for_overriding/) |  |
| [`text_format`](/slides/python-net/th/aspose.slides.charts/itrendline/text_format/) |  |
| [`chart`](/slides/python-net/th/aspose.slides.charts/itrendline/chart/) |  |
