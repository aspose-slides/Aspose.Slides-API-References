## DataSourceType enumeration

ประเภทแหล่งข้อมูล

ชนิด DataSourceType มีสมาชิกต่อไปนี้:

## Fields

| Field | Description |
| :- | :- |
| WORKSHEET | ใช้วัตถุ CellXls สำหรับจัดเก็บ XValue, YValue, Value หรือ BubbleSize ของจุดข้อมูลใน worksheet. |
| STRING_LITERALS | ใช้ตัวแปรชนิดสตริงที่เข้าถึงได้เร็วสำหรับจัดเก็บ XValue, YValue, Value หรือ BubbleSize ของ <br/>            จุดข้อมูล. Worksheet ไม่ได้ใช้สำหรับจัดเก็บค่า. |
| DOUBLE_LITERALS | ใช้ตัวแปรชนิด double ที่เข้าถึงได้เร็วสำหรับจัดเก็บ XValue, YValue, Value หรือ BubbleSize ของ <br/>            จุดข้อมูล. Worksheet ไม่ได้ใช้สำหรับจัดเก็บค่า. |
