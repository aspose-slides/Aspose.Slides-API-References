## DoubleChartValue คลาส

แทนค่าตัวเลขทศนิยมแบบ double ที่สามารถจัดเก็บในเอกสารพรีเซนเทชัน pptx ได้สองวิธี:
1) ใน cell/cells ของ workbook ที่เกี่ยวข้องกับ chart;
2) เป็น literal value.

**การสืบทอด:**[`DoubleChartValue`](/slides/python-net/th/aspose.slides.charts/doublechartvalue) → [`BaseChartValue`](/slides/python-net/th/aspose.slides.charts/basechartvalue)

ประเภท DoubleChartValue เปิดเผยสมาชิกต่อไปนี้:

| คุณสมบัติ | รายละเอียด |
| :- | :- |
| [`data_source_type`](/slides/python-net/th/aspose.slides.charts/doublechartvalue/data_source_type/) | ระบุว่า AsCell, AsCells, AsLiteralString หรือ AsLiteralDouble <br/>            property มีอยู่จริงในคลาสลูกหรือไม่ บรรทัดอื่นคือระบุประเภท <br/>            ของค่าของ Data property.<br/>            อ่าน/เขียน [`DataSourceType`](/slides/python-net/th/aspose.slides.charts/datasourcetype). |
