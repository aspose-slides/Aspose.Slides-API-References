## use_cell property
ถ้าเป็น true แล้วคุณสมบัติ AsCell จะเป็นค่าใช้งานจริง. กล่าวคือ worksheet ถูกใช้เพื่อ 
            จัดเก็บหมวดหมู่ (กรณีนี้รองรับหมวดหมู่ระดับหลายระดับ).
            ถ้าเป็น false แล้วคุณสมบัติ AsLiteral จะเป็นค่าใช้งานจริง. กล่าวคือ worksheet ไม่ได้ถูกใช้ 
            เพื่อจัดเก็บหมวดหมู่ (และกรณีนี้ไม่รองรับหมวดหมู่หลายระดับ).
            อ่านได้เท่านั้น **bool**.


### หมายเหตุ

เพื่อเปลี่ยนค่าของคุณสมบัตินี้ (สำหรับทุกหมวดหมู่ในคอลเลกชัน) ให้ตั้งค่าใหม่ 
            ให้กับคุณสมบัติ ChartCategoryCollection.UseCells property.
