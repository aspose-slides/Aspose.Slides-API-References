## use_secondary_categories คุณสมบัติ
หากเป็น false แล้ว [`IChartData.secondary_categories`](/slides/python-net/th/aspose.slides.charts/ichartdata/secondary_categories) property จะคืนค่า None และข้อมูล 
            ใน [`IChartData.categories`](/slides/python-net/th/aspose.slides.charts/ichartdata/categories) property จะถูกใช้ทั้งสำหรับซีรีส์หลักและซีรีส์รอง.
หากเป็น true แล้วข้อมูลใน [`IChartData.secondary_categories`](/slides/python-net/th/aspose.slides.charts/ichartdata/secondary_categories) property จะถูกใช้สำหรับซีรีส์รองและข้อมูล 
            ใน [`IChartData.categories`](/slides/python-net/th/aspose.slides.charts/ichartdata/categories) property จะถูกใช้สำหรับซีรีส์หลัก.
