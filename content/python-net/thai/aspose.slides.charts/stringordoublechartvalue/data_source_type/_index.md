## data_source_type คุณสมบัติ
ระบุว่า AsCell, AsCells, AsLiteralString หรือ AsLiteralDouble เป็นคุณสมบัติที่ใช้งานได้ในคลาสลูก ในทางอื่นหมายความว่ามันระบุประเภทของค่าในคุณสมบัติ Data. อ่าน/เขียน [`DataSourceType`](/slides/python-net/th/aspose.slides.charts/datasourcetype).

### หมายเหตุ

สำหรับจุดใน ChartDataPointCollection คุณสมบัตินี้เป็นอ่านอย่างเดียว ในกรณีนี้เพื่อเปลี่ยนค่าของคุณสมบัตินี้คุณสามารถใช้หนึ่งในคุณสมบัติ ChartDataPointCollection.DataSourceTypeFor<...>.
