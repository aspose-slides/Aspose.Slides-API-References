## data_source_type คุณสมบัติ
ระบุว่า AsCell, AsCells, AsLiteralString หรือ AsLiteralDouble 
            คุณสมบัติมีอยู่จริงในคลาสลูกหรือไม่ ในคำอื่นหมายความว่าระบุประเภท 
            ของค่าของคุณสมบัติ Data
            อ่าน/เขียน [`DataSourceType`](/slides/python-net/th/aspose.slides.charts/datasourcetype).

### หมายเหตุ

สำหรับจุดใน ChartDataPointCollection คุณสมบัตินี้เป็นแบบอ่านอย่างเดียว 
            ในกรณีนี้เพื่อเปลี่ยนค่าของคุณสมบัตินี้คุณสามารถใช้หนึ่งใน 
            คุณสมบัติ ChartDataPointCollection.DataSourceTypeFor<...>.
