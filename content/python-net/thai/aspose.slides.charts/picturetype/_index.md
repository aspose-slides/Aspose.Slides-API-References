## PictureType enum

กำหนดโหมดการเติมรูปภาพของแถบ

ประเภท PictureType เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| NOT_DEFINED | ไม่ได้กำหนด. |
| STACK | ภาพจะถูกปรับขนาดให้ทำซ้ำได้สูงสุด 15 ครั้งในแถบที่ซ้อนกันยาวที่สุด. |
| STACK_SCALE | ภาพจะถูกปรับขนาดให้เป็นจำนวนหน่วยที่ระบุและทำซ้ำตามความยาวของแถบ. |
| STRETCH | ภาพจะถูกขยายเต็มความยาวของแถบที่ซ้อนกัน. |
