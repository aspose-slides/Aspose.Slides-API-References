## ChartDataCell คลาส

แสดงเซลล์สำหรับข้อมูลแผนภูมิ.

ชนิด ChartDataCell เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`row`](/slides/python-net/th/aspose.slides.charts/chartdatacell/row/) | ส่งคืนดัชนีของแถวในแผ่นงานที่เซลล์ตั้งอยู่.<br/>            อ่านอย่างเดียว **int**. |
| [`column`](/slides/python-net/th/aspose.slides.charts/chartdatacell/column/) | ส่งคืนดัชนีของคอลัมน์ในแผ่นงานที่เซลล์ตั้งอยู่.<br/>            อ่านอย่างเดียว **int**. |
| [`value`](/slides/python-net/th/aspose.slides.charts/chartdatacell/value/) | รับหรือกำหนดค่าของเซลล์.<br/>            อ่าน/เขียน **any**. |
| [`formula`](/slides/python-net/th/aspose.slides.charts/chartdatacell/formula/) | รับหรือกำหนดสูตรในรูปแบบ A1. |
| [`r1c1_formula`](/slides/python-net/th/aspose.slides.charts/chartdatacell/r1c1_formula/) | รับหรือกำหนดสูตรในรูปแบบ R1C1. |
| [`chart_data_worksheet`](/slides/python-net/th/aspose.slides.charts/chartdatacell/chart_data_worksheet/) | รับแผ่นงาน.<br/>            อ่านอย่างเดียว [`IChartDataWorksheet`](/slides/python-net/th/aspose.slides.charts/ichartdataworksheet). |
| [`is_hidden`](/slides/python-net/th/aspose.slides.charts/chartdatacell/is_hidden/) | กำหนดว่าเซลล์ถูกซ่อนหรือไม่.<br/>            อ่านอย่างเดียว **bool**. |
| [`custom_number_format`](/slides/python-net/th/aspose.slides.charts/chartdatacell/custom_number_format/) | รับหรือกำหนดรูปแบบการแสดงผลแบบกำหนดเองของตัวเลขและวันที่.<br/>            หากค่าเป็นค่าว่างจะใช้ค่าของ PresetNumberFormat.<br/>            อ่าน/เขียน **str**. |
| [`preset_number_format`](/slides/python-net/th/aspose.slides.charts/chartdatacell/preset_number_format/) | รับหรือกำหนดรูปแบบการแสดงผลที่สร้างขึ้นของตัวเลขและวันที่. ตัวเลขที่กำหนดต้องอยู่ในช่วง [0..22] หรือ [37..49].<br/>            อ่าน/เขียน **int**. |
