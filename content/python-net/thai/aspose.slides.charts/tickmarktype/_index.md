## TickMarkType enumeration

แสดงประเภทเครื่องหมายติ๊กสำหรับแกนที่ระบุ

ประเภท TickMarkType มีสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| CROSS | ระบุว่าตำแหน่งเครื่องหมายติ๊กจะข้ามแกน |
| INSIDE | ระบุว่าตำแหน่งเครื่องหมายติ๊กจะอยู่ภายในพื้นที่พล็อต |
| NONE | ระบุว่าไม่มีเครื่องหมายติ๊ก |
| OUTSIDE | ระบุว่าตำแหน่งเครื่องหมายติ๊กจะอยู่ภายนอกพื้นที่พล็อต |
