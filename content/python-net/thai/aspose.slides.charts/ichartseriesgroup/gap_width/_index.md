## คุณสมบัติ gap_width
Gets or sets the space between bar or column clusters, as a percentage of the bar or column width.
            The value must be between 0 and 500.
            Read/write **int**.

### หมายเหตุ

This property applies to series of the following types:
            All bar and column subtypes, 
            [`ChartType.BAR_OF_PIE`](/slides/python-net/th/aspose.slides.charts/charttype/BAR_OF_PIE),
            [`ChartType.PIE_OF_PIE`](/slides/python-net/th/aspose.slides.charts/charttype/PIE_OF_PIE),
            [`ChartType.BOX_AND_WHISKER`](/slides/python-net/th/aspose.slides.charts/charttype/BOX_AND_WHISKER),
            [`ChartType.FUNNEL`](/slides/python-net/th/aspose.slides.charts/charttype/FUNNEL),
            [`ChartType.HISTOGRAM`](/slides/python-net/th/aspose.slides.charts/charttype/HISTOGRAM),
            [`ChartType.WATERFALL`](/slides/python-net/th/aspose.slides.charts/charttype/WATERFALL).
