## คุณสมบัติ text_frame_for_overriding
สามารถบรรจุตัวอักษรที่จัดรูปแบบอย่างสมบูรณ์ได้ หากคุณสมบัตินี้ไม่เป็น None แล้วค่าตัวอักษรที่จัดรูปแบบนี้จะทับข้อความที่สร้างโดยอัตโนมัติของป้ายข้อมูล
            ข้อความที่สร้างโดยอัตโนมัติของป้ายข้อมูลหมายถึงข้อความที่จัดการโดยคุณสมบัติ ShowSeriesName, ShowValue, ... และจัดรูปแบบด้วยคุณสมบัติ TextFormatManager.TextFormat
            อ่านอย่างเดียว [`ITextFrame`](/slides/python-net/th/aspose.slides/itextframe).
