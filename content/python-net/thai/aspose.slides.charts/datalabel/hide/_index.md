## hide(self) {#}
ทำให้ป้ายข้อมูลถูกซ่อนโดยการตั้งค่า Show*-flags ทั้งหมด (ShowValue, ...) เป็นสถานะ false.
IsVisible จะเป็น false หลังจากนี้.


```python
def hide(self):
    ...
```


### หมายเหตุ

หากป้ายข้อมูลไม่แสดง (IsVisible เป็น false) คุณสามารถทำให้ป้ายข้อมูลแสดงได้โดย
ตั้งค่า Show*-flags (ShowValue, ...) เป็นสถานะ true.
