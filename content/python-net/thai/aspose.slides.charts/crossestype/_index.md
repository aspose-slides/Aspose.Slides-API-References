## CrossesType การนับ

Determines where axis will cross.

The CrossesType type exposes the following members:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| AXIS_CROSSES_AT_ZERO | แกนประเภทจะข้ามที่จุดศูนย์ของแกนค่าตามที่เป็นไปได้ หรือค่าต่ำสุด (ถ้าค่าต่ำสุดมากกว่าศูนย์) หรือค่าสูงสุด (ถ้าค่าสูงสุดน้อยกว่าศูนย์) |
| MAXIMUM | แกนจะข้ามที่ค่าสูงสุด |
| CUSTOM | ค่าที่กำหนดเองจากคุณสมบัติ CrossAt |
