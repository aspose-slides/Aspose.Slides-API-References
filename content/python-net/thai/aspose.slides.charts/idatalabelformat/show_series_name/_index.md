## show_series_name คุณสมบัติ
ส่งคืนหรือกำหนดค่า Boolean เพื่อระบุพฤติกรรมการแสดงชื่อชุดข้อมูลสำหรับป้ายข้อมูลบนแผนภูมิ. 
True เพื่อแสดงชื่อชุดข้อมูล. False เพื่อซ่อน.
อ่าน/เขียน **bool**.

### หมายเหตุ

หากพาเรนต์ของวัตถุ DataLabelFormat นี้เป็นคอลเล็กชัน DataLabelCollection ของป้ายข้อมูลแล้วคุณสมบัตินี้จะรับหรือกำหนดค่าดีฟอลต์ของคุณสมบัติ ShowSeriesName สำหรับป้ายข้อมูลใหม่ในคอลเล็กชัน DataLabelCollection.
การกำหนดคุณสมบัตินี้ด้วยค่าใดค่าหนึ่งยังทำให้ค่านี้ถูกกำหนดให้กับคุณสมบัติ ShowSeriesName สำหรับป้ายข้อมูลทั้งหมดในคอลเล็กชัน DataLabelCollection
(เช่น "DataLabels.DefaultDataLabelFormat.ShowSeriesName = val;" ทำให้ DataLabels[i].ShowSeriesName มีค่าเท่ากับ val).
