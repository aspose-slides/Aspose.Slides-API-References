## show_label_as_data_callout คุณสมบัติ
กำหนดว่าป้ายข้อมูลของแผนภูมิที่ระบุจะถูกแสดงเป็น data callout หรือเป็น data label.
            
            หากพาเรนท์ของวัตถุ DataLabelFormat นี้เป็นคอลเลกชัน DataLabelCollection ของป้ายข้อมูลแล้วนี้
            คุณสมบัติจะรับหรือกำหนดค่าปริยายของคุณสมบัติ ShowLabelAsDataCallout สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน DataLabelCollection
            ตั้งค่าคุณสมบัตินี้ด้วยค่าใดค่าหนึ่งจะกำหนดค่าดังกล่าวให้กับคุณสมบัติ ShowLabelAsDataCallout สำหรับป้ายข้อมูลทั้งหมดในคอลเลกชัน DataLabelCollection
            (เช่น "DataLabels.DefaultDataLabelFormat.ShowLabelAsDataCallout = val;" ทำให้
            all DataLabels[i].ShowLabelAsDataCallout มีค่าเท่ากับ val).
