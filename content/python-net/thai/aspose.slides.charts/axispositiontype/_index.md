## AxisPositionType การนับ

กำหนดตำแหน่งของแกน.

ประเภท AxisPositionType เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| BOTTOM | ระบุว่าแกนจะถูกแสดงที่ด้านล่างของพื้นที่พล็อต. |
| LEFT | ระบุว่าแกนจะถูกแสดงที่ด้านซ้ายของพื้นที่พล็อต. |
| RIGHT | ระบุว่าแกนจะถูกแสดงที่ด้านขวาของพื้นที่พล็อต. |
| TOP | ระบุว่าแกนจะถูกแสดงที่ด้านบนของพื้นที่พล็อต. |
