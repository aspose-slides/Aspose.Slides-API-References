## IAxisFormat คลาส

แสดงคุณสมบัติการจัดรูปแบบแผนภูมิ.

ประเภท IAxisFormat เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | คำอธิบาย |
| :- | :- |
| [`fill`](/slides/python-net/th/aspose.slides.charts/iaxisformat/fill/) | คืนคุณสมบัติสไตล์การเติมของแกน.<br/>            อ่านอย่างเดียว [`IFillFormat`](/slides/python-net/th/aspose.slides/ifillformat). |
| [`line`](/slides/python-net/th/aspose.slides.charts/iaxisformat/line/) | คืนคุณสมบัติสไตล์เส้นของแกน.<br/>            อ่านอย่างเดียว [`ILineFormat`](/slides/python-net/th/aspose.slides/ilineformat). |
| [`effect`](/slides/python-net/th/aspose.slides.charts/iaxisformat/effect/) | คืนเอฟเฟกต์ที่ใช้สำหรับแกน.<br/>            อ่านอย่างเดียว [`IEffectFormat`](/slides/python-net/th/aspose.slides/ieffectformat). |
