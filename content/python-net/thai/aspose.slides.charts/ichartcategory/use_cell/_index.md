## use_cell คุณสมบัติ
หากเป็น true แล้ว AsCell property จะเป็นค่าจริง. โดยความหมายอื่น worksheet จะถูกใช้เพื่อ 
            เก็บหมวดหมู่ (กรณีนี้สนับสนุนหมวดหมู่หลายระดับ).
            หากเป็น false แล้ว AsLiteral property จะเป็นค่าจริง. โดยความหมายอื่น worksheet **ไม่** ถูกใช้ 
            เพื่อเก็บหมวดหมู่ (และกรณีนี้ไม่สนับสนุนหมวดหมู่หลายระดับ).
            อ่านอย่างเดียว **bool**.

### หมายเหตุ
เพื่อเปลี่ยนค่าาของคุณสมบัตินี้ (สำหรับหมวดหมู่ทั้งหมดในคอลเลกชัน) ให้ตั้งค่าใหม่ให้กับ ChartCategoryCollection.UseCells property.
