## IUpDownBarsManager คลาส

ให้การเข้าถึงแถบขึ้น/ลงของแผนภูมิแบบเส้นหรือแบบหุ้น.

ชนิด IUpDownBarsManager เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`up_bars_format`](/slides/python-net/th/aspose.slides.charts/iupdownbarsmanager/up_bars_format/) | คืนรูปแบบของแถบขึ้น.<br/>            อ่านอย่างเดียว [`IFormat`](/slides/python-net/th/aspose.slides.charts/iformat). |
| [`down_bars_format`](/slides/python-net/th/aspose.slides.charts/iupdownbarsmanager/down_bars_format/) | คืนรูปแบบของแถบลง.<br/>            อ่านอย่างเดียว [`IFormat`](/slides/python-net/th/aspose.slides.charts/iformat). |
| [`has_up_down_bars`](/slides/python-net/th/aspose.slides.charts/iupdownbarsmanager/has_up_down_bars/) | กำหนดว่าแผนภูมิมีแถบขึ้น/ลงหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`gap_width`](/slides/python-net/th/aspose.slides.charts/iupdownbarsmanager/gap_width/) | คืนหรือกำหนดความกว้างของช่องว่าง.<br/>            อ่าน/เขียน **int**. |
