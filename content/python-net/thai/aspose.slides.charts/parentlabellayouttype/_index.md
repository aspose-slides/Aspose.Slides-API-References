## ParentLabelLayoutType enumeration

แสดงการจัดวางของป้ายข้อมูลหมวดหมู่ ใช้กับชุดข้อมูล Treemap เท่านั้น

ชนิด ParentLabelLayoutType มีสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| BANNER | ระบุว่าป้ายหมวดหมู่พาเรนต์จะแสดงเป็นแบนเนอร์ |
| NONE | ระบุว่าป้ายหมวดหมู่พาเรนต์จะไม่ถูกวาด |
| OVERLAPPING | ระบุว่าป้ายหมวดหมู่พาเรนต์จะแสดงเป็นการทับซ้อน |
