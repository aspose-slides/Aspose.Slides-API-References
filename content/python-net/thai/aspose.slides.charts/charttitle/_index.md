## ChartTitle คลาส

แสดงคุณสมบัติของหัวข้อแผนภูมิ.

ประเภท ChartTitle เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`x`](/slides/python-net/th/aspose.slides.charts/charttitle/x/) | คืนค่าหรือกำหนดพิกัด x ของหัวข้อเป็นส่วนของความกว้างของแผนภูมิ.<br/>            อ่าน/เขียน **float**. |
| [`y`](/slides/python-net/th/aspose.slides.charts/charttitle/y/) | คืนค่าหรือกำหนดพิกัด y ของหัวข้อเป็นส่วนของความสูงของแผนภูมิ.<br/>            อ่าน/เขียน **float**. |
| [`width`](/slides/python-net/th/aspose.slides.charts/charttitle/width/) | คืนค่าหรือกำหนดความกว้างของหัวข้อเป็นส่วนของความกว้างของแผนภูมิ.<br/>            อ่าน/เขียน **float**. |
| [`height`](/slides/python-net/th/aspose.slides.charts/charttitle/height/) | คืนค่าหรือกำหนดความสูงของหัวข้อเป็นส่วนของความสูงของแผนภูมิ.<br/>            อ่าน/เขียน **float**. |
| [`right`](/slides/python-net/th/aspose.slides.charts/charttitle/right/) | ด้านขวา.<br/>            อ่านอย่างเดียว **float**. |
| [`bottom`](/slides/python-net/th/aspose.slides.charts/charttitle/bottom/) | ด้านล่าง.<br/>            อ่านอย่างเดียว **float**. |
| [`overlay`](/slides/python-net/th/aspose.slides.charts/charttitle/overlay/) | กำหนดว่าตัวองค์ประกอบแผนภูมิอื่น ๆ จะอนุญาตให้ทับหัวข้อหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`format`](/slides/python-net/th/aspose.slides.charts/charttitle/format/) | คืนค่าสไตล์การเติม, เส้น, และเอฟเฟกต์ของหัวข้อ.<br/>            อ่านอย่างเดียว [`IFormat`](/slides/python-net/th/aspose.slides.charts/iformat). |
| [`text_frame_for_overriding`](/slides/python-net/th/aspose.slides.charts/charttitle/text_frame_for_overriding/) | สามารถมีข้อความที่จัดรูปแบบอย่างหลากหลายได้ หากคุณสมบัตินี้ไม่ใช่ None แล้วค่าข้อความที่จัดรูปแบบนี้จะทับข้อความที่สร้างโดยอัตโนมัติ.<br/>            ข้อความที่สร้างโดยอัตโนมัติเป็นคุณสมบัติแฝงของป้ายข้อมูล, ป้ายหน่วยแสดงของแกนค่า, ชื่อแกน, ชื่อแผนภูมิ, ป้ายของเส้นแนวโน้ม.<br/>            ข้อความที่สร้างโดยอัตโนมัติถูกจัดรูปแบบด้วยคุณสมบัติ IFormattedTextContainer.TextFormat.<br/>            อ่านอย่างเดียว [`ITextFrame`](/slides/python-net/th/aspose.slides/itextframe). |
| [`text_format`](/slides/python-net/th/aspose.slides.charts/charttitle/text_format/) | คืนรูปแบบข้อความ.<br/>            อ่านอย่างเดียว [`IChartTextFormat`](/slides/python-net/th/aspose.slides.charts/icharttextformat). |
| [`actual_x`](/slides/python-net/th/aspose.slides.charts/charttitle/actual_x/) | ระบุตำแหน่ง x จริง (ซ้าย) ขององค์ประกอบแผนภูมิสัมพันธ์กับมุมซ้ายบนของแผนภูมิ.<br/>            เรียกเมธอด IChart.ValidateChartLayout() ก่อนเพื่อรับค่าแท้จริง. <br/>            อ่าน **float**. |
| [`actual_y`](/slides/python-net/th/aspose.slides.charts/charttitle/actual_y/) | ระบุตำแหน่งด้านบนจริงขององค์ประกอบแผนภูมิสัมพันธ์กับมุมซ้ายบนของแผนภูมิ.<br/>            เรียกเมธอด IChart.ValidateChartLayout() ก่อนเพื่อรับค่าแท้จริง. <br/>            อ่าน **float**. |
| [`actual_width`](/slides/python-net/th/aspose.slides.charts/charttitle/actual_width/) | ระบุความกว้างจริงขององค์ประกอบแผนภูมิ. เรียกเมธอด IChart.ValidateChartLayout() ก่อนเพื่อรับค่าแท้จริง. <br/>            อ่าน **float**. |
| [`actual_height`](/slides/python-net/th/aspose.slides.charts/charttitle/actual_height/) | ระบุความสูงจริงขององค์ประกอบแผนภูมิ. เรียกเมธอด IChart.ValidateChartLayout() ก่อนเพื่อรับค่าแท้จริง. <br/>            อ่าน **float**. |
| [`chart`](/slides/python-net/th/aspose.slides.charts/charttitle/chart/) | คืนค่าแผนภูมิแม่.<br/>            อ่านอย่างเดียว [`IChart`](/slides/python-net/th/aspose.slides.charts/ichart). |
| [`slide`](/slides/python-net/th/aspose.slides.charts/charttitle/slide/) |  |
| [`presentation`](/slides/python-net/th/aspose.slides.charts/charttitle/presentation/) |  |
