## การกำหนดค่า TrendlineType

แสดงประเภทของเส้นแนวโน้ม

ประเภท TrendlineType เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| EXPONENTIAL | ระบุว่าเส้นแนวโน้มจะเป็นเส้นโค้งเชิงเอ็กซ์โพเนนเชียลในรูปแบบนี้. |
| LINEAR | ระบุว่าเส้นแนวโน้มจะเป็นเส้นตรงในรูปแบบนี้. |
| LOGARITHMIC | ระบุว่าเส้นแนวโน้มจะเป็นเส้นโค้งลอการิทึมในรูปแบบนี้, โดยที่ log คือลอการิทึมธรรมชาติ. |
| MOVING_AVERAGE | ระบุว่าเส้นแนวโน้มจะเป็นค่าเฉลี่ยเคลื่อนที่ของช่วง Period. |
| POLYNOMIAL | ระบุว่าเส้นแนวโน้มจะเป็นเส้นโค้งพหุนามของลำดับ Order ในรูปแบบนี้. |
| POWER | ระบุว่าเส้นแนวโน้มจะเป็นเส้นโค้งพาวเวอร์ในรูปแบบนี้. |
