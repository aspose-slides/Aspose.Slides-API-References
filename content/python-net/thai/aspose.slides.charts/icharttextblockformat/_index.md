## IChartTextBlockFormat คลาส

แสดงคุณสมบัติการจัดรูปแบบสำหรับองค์ประกอบข้อความแผนภูมิ.

ประเภท IChartTextBlockFormat เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`anchoring_type`](/slides/python-net/th/aspose.slides.charts/icharttextblockformat/anchoring_type/) | คืนค่า หรือ ตั้งข้อความ anchor แนวตั้งใน TextFrame.<br/>            อ่าน/เขียน [`TextAnchorType`](/slides/python-net/th/aspose.slides/textanchortype). |
| [`center_text`](/slides/python-net/th/aspose.slides.charts/icharttextblockformat/center_text/) | ถ้า NullableBool.True แล้วข้อความควรอยู่กึ่งกลางในกล่องแนวนอน.<br/>            อ่าน/เขียน [`NullableBool`](/slides/python-net/th/aspose.slides/nullablebool). |
| [`text_vertical_type`](/slides/python-net/th/aspose.slides.charts/icharttextblockformat/text_vertical_type/) | กำหนดทิศทางของข้อความ.<br/>            ค่าที่ได้ของการหมุนข้อความเชิงภาพสรุปจากคุณสมบัตินี้และมุมที่กำหนดเอง<br/>            ในคุณสมบัติ RotationAngle.<br/>            อ่าน/เขียน [`TextVerticalType`](/slides/python-net/th/aspose.slides/textverticaltype). |
| [`margin_left`](/slides/python-net/th/aspose.slides.charts/icharttextblockformat/margin_left/) | คืนค่า หรือ ตั้งค่าขอบซ้าย (points) ใน TextFrame.<br/>            การเปลี่ยนแปลงของคุณสมบัตินี้อาจมีผลเฉพาะกับส่วนของแผนภูมิดังต่อไปนี้: <br/>            DataLabel และ DataLabelFormat (รองรับเต็มรูปแบบใน PowerPoint 2013; ใน PowerPoint 2007 ไม่มีผลต่อการแสดงผล).<br/>            อ่าน/เขียน **float**. |
| [`margin_right`](/slides/python-net/th/aspose.slides.charts/icharttextblockformat/margin_right/) | คืนค่า หรือ ตั้งค่าขอบขวา (points) ใน TextFrame.<br/>            การเปลี่ยนแปลงของคุณสมบัตินี้อาจมีผลเฉพาะกับส่วนของแผนภูมิดังต่อไปนี้: <br/>            DataLabel และ DataLabelFormat (รองรับเต็มรูปแบบใน PowerPoint 2013; ใน PowerPoint 2007 ไม่มีผลต่อการแสดงผล).<br/>            อ่าน/เขียน **float**. |
| [`margin_top`](/slides/python-net/th/aspose.slides.charts/icharttextblockformat/margin_top/) | คืนค่า หรือ ตั้งค่าขอบบน (points) ใน TextFrame.<br/>            การเปลี่ยนแปลงของคุณสมบัตินี้อาจมีผลเฉพาะกับส่วนของแผนภูมิดังต่อไปนี้: <br/>            DataLabel และ DataLabelFormat (รองรับเต็มรูปแบบใน PowerPoint 2013; ใน PowerPoint 2007 ไม่มีผลต่อการแสดงผล).<br/>            อ่าน/เขียน **float**. |
| [`margin_bottom`](/slides/python-net/th/aspose.slides.charts/icharttextblockformat/margin_bottom/) | คืนค่า หรือ ตั้งค่าขอบล่าง (points) ใน TextFrame.<br/>            การเปลี่ยนแปลงของคุณสมบัตินี้อาจมีผลเฉพาะกับส่วนของแผนภูมิดังต่อไปนี้: <br/>            DataLabel และ DataLabelFormat (รองรับเต็มรูปแบบใน PowerPoint 2013; ใน PowerPoint 2007 ไม่มีผลต่อการแสดงผล).<br/>            อ่าน/เขียน **float**. |
| [`wrap_text`](/slides/python-net/th/aspose.slides.charts/icharttextblockformat/wrap_text/) | **True**  ถ้าข้อความถูกตัดบรรทัดที่ขอบของ TextFrame.<br/>            การเปลี่ยนแปลงของคุณสมบัตินี้อาจมีผลเฉพาะกับส่วนของแผนภูมิดังต่อไปนี้: <br/>            DataLabel และ DataLabelFormat (รองรับเต็มรูปแบบใน PowerPoint 2007/2013).<br/>            อ่าน/เขียน [`NullableBool`](/slides/python-net/th/aspose.slides/nullablebool). |
| [`autofit_type`](/slides/python-net/th/aspose.slides.charts/icharttextblockformat/autofit_type/) | คืนค่า หรือ ตั้งค่าโหมดปรับขนาดอัตโนมัติของข้อความ.<br/>            การเปลี่ยนแปลงของคุณสมบัตินี้อาจมีผลเฉพาะกับส่วนของแผนภูมิดังต่อไปนี้: <br/>            DataLabel และ DataLabelFormat (รองรับเต็มรูปแบบใน PowerPoint 2013; ใน PowerPoint 2007 ไม่มีผลต่อการแสดงผล).<br/>            อ่าน/เขียน [`TextAutofitType`](/slides/python-net/th/aspose.slides/textautofittype). |
| [`rotation_angle`](/slides/python-net/th/aspose.slides.charts/icharttextblockformat/rotation_angle/) | ระบุการหมุนแบบกำหนดเองที่นำไปใช้กับข้อความภายในกล่องกรอบ. หากไม่ได้ระบุ, การหมุนของรูปร่างที่เกี่ยวข้องจะถูกใช้. หากระบุ, การหมุนนี้จะถูกนำไปใช้แยกจากรูปร่าง. กล่าวคือรูปร่างอาจมีการหมุนเพิ่มเติมนอกเหนือจากข้อความที่มีการหมุนของมันเอง.<br/>            ค่าที่ได้ของการหมุนข้อความเชิงภาพสรุปจากคุณสมบัตินี้และประเภทแนวตั้งที่กำหนดไว้ล่วงหน้าในคุณสมบัติ TextVerticalType.<br/>            อ่าน/เขียน **float**. |
