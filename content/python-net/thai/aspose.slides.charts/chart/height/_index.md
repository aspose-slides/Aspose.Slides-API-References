## height คุณสมบัติ
ดึงหรือกำหนด height ของ shape, วัดเป็นจุด.
            อ่าน/เขียน **float**.

### หมายเหตุ

ค่าที่ส่งคืนจะถูกกำหนดเสมอและจะไม่เป็น **float**.
            ค่าที่กำหนดต้องถูกกำหนดเช่นกัน; ให้กำหนด **float** เฉพาะกับคุณสมบัติของอินสแตนซ์ `RawFrame` เท่านั้น.
