## คุณสมบัติ x
รับหรือกำหนดค่าพิกัด x ของมุมซ้ายบนของรูปร่าง, วัดเป็นจุด.
            อ่าน/เขียน **float**.

### หมายเหตุ

ค่าที่ส่งกลับจะถูกกำหนดเสมอและไม่เคยเป็น **float**.
            ค่าที่กำหนดต้องถูกกำหนดเช่นกัน; กำหนด **float** เท่านั้นให้กับคุณสมบัติของอินสแตนซ์ `RawFrame` instance.

@property
def x(self):
    ...

    ...
