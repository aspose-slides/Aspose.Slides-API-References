## ErrorBarValueType การกำหนดค่า

แสดงชนิดของค่า error bar

ชนิด ErrorBarValueType จะเปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| CUSTOM | ระบุว่าความยาวของเส้นผิดพลาดจะถูกกำหนดโดยองค์ประกอบ Plus และ Minus. |
| FIXED | ระบุว่าความยาวของเส้นผิดพลาดจะเป็นค่าคงที่ที่กำหนดโดย Error Bar Value. |
| PERCENTAGE | ระบุว่าความยาวของเส้นผิดพลาดจะเป็นเปอร์เซ็นต์ของ Error Bar Value ของข้อมูล. |
| STANDARD_DEVIATION | ระบุว่าความยาวของเส้นผิดพลาดจะเป็นส่วนเบี่ยงเบนมาตรฐานของ Error Bar Value ของข้อมูล. |
| STANDARD_ERROR | ระบุว่าความยาวของเส้นผิดพลาดจะเป็นค่าความคลาดเคลื่อนมาตรฐานของ Error Bar Value ของข้อมูล. |
