## text_frame_for_overriding คุณสมบัติ
สามารถบรรจุข้อความที่จัดรูปแบบอย่างหลากหลายได้. หากคุณสมบัตินี้ไม่เป็น None แล้วค่าข้อความที่จัดรูปแบบนี้จะทับข้อความที่สร้างโดยอัตโนมัติของป้ายข้อมูล. ข้อความที่สร้างโดยอัตโนมัติของป้ายข้อมูลหมายถึงข้อความที่จัดการโดย ShowSeriesName, ShowValue, ... คุณสมบัติและถูกจัดรูปแบบด้วย TextFormatManager.TextFormat คุณสมบัติ. อ่านอย่างเดียว [`ITextFrame`](/slides/python-net/th/aspose.slides/itextframe).
