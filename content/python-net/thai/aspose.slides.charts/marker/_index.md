## Marker คลาส

แสดงถึงมาร์คเกอร์ของแผนภูมิ

ชนิด Marker เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`symbol`](/slides/python-net/th/aspose.slides.charts/marker/symbol/) | แสดงถึงสไตล์มาร์คเกอร์ในแผนภูมิเส้น, แผนภูมิกระจาย, หรือแผนภูมิโรเทเตอร์.<br/>            อ่าน/เขียน [`MarkerStyleType`](/slides/python-net/th/aspose.slides.charts/markerstyletype). |
| [`format`](/slides/python-net/th/aspose.slides.charts/marker/format/) | รับหรือกำหนดการเติมมาร์คเกอร์.<br/>            อ่านอย่างเดียว [`IFormat`](/slides/python-net/th/aspose.slides.charts/iformat). |
| [`size`](/slides/python-net/th/aspose.slides.charts/marker/size/) | แสดงถึงขนาดมาร์คเกอร์ในแผนภูมิเส้น, แผนภูมิกระจาย, หรือแผนภูมิโรเทเตอร์.<br/>            อ่าน/เขียน **int**. |
