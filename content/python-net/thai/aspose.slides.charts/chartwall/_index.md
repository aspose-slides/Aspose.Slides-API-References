## ChartWall คลาส

แสดงผนังบนแผนภูมิ 3 มิติ.

ประเภท ChartWall เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`thickness`](/slides/python-net/th/aspose.slides.charts/chartwall/thickness/) | คืนค่า หรือ ตั้งค่าความหนาของผนังเป็นเปอร์เซ็นต์ของมิติที่ใหญ่ที่สุดของปริมาณการพล็อต.<br/>            อ่าน/เขียน **int**. |
| [`format`](/slides/python-net/th/aspose.slides.charts/chartwall/format/) | คืนค่าเติมผนัง, เส้น, เอฟเฟ็กต์, สไตล์ 3 มิติ.<br/>            อ่านอย่างเดียว [`IFormat`](/slides/python-net/th/aspose.slides.charts/iformat). |
| [`picture_type`](/slides/python-net/th/aspose.slides.charts/chartwall/picture_type/) | คืนค่า หรือ ตั้งค่าประเภทภาพ.<br/>            อ่าน/เขียน [`PictureType`](/slides/python-net/th/aspose.slides.charts/picturetype). |
