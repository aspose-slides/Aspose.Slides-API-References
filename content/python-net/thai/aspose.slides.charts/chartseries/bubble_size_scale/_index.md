## bubble_size_scale คุณสมบัติ
ระบุค่าตัวคูณสเกลสำหรับแผนภูมิกระจุ (สามารถอยู่ระหว่าง 0 ถึง 300 เปอร์เซ็นต์ของขนาดเริ่มต้น)  
นี่เป็นคุณสมบัติไม่เพียงของซีรีส์นี้แต่ของทุกซีรีส์ในกลุ่มซีรีส์แม่ - นี่คือการสอดแทรกของคุณสมบัติกลุ่มที่เหมาะสม และคุณสมบัตินี้เป็นอ่านอย่างเดียว  
ใช้คุณสมบัติ ParentSeriesGroup เพื่อเข้าถึงกลุ่มซีรีส์แม่  
ใช้คุณสมบัติอ่าน/เขียน ParentSeriesGroup.BubbleSizeScale เพื่อเปลี่ยนค่า

### หมายเหตุ
