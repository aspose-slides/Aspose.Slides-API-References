## BubbleSizeRepresentationType ชนิด enumeration

ระบุวิธีที่เป็นไปได้ในการแสดงข้อมูลเป็นขนาดของแผนภูมิบับเบิล

ชนิด BubbleSizeRepresentationType เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| AREA | ระบุว่าพื้นที่ของฟองจะสัดส่วนกับค่าขนาดของฟอง |
| WIDTH | ระบุว่ารัศมีของฟองจะสัดส่วนกับค่าขนาดของฟอง |
