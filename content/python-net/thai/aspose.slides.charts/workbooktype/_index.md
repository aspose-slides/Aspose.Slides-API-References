## WorkbookType enumeration

ระบุประเภทของไฟล์เวิร์กบุ๊ก Open XML.

ประเภท WorkbookType มีสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| NOT_DEFINED | ประเภทของเวิร์กบุ๊กไม่ได้กำหนด. |
| WORKBOOK | เวิร์กบุ๊ก Excel (*.xlsx). |
| WORKBOOK_MACRO | เวิร์กบุ๊ก Excel ที่เปิดใช้งานแมโคร (*.xlsm). |
| TEMPLATE | เทมเพลต Excel (*.xltx). |
| TEMPLATE_MACRO | เทมเพลต Excel ที่เปิดใช้งานแมโคร (*.xltm). |
| WORKBOOK_BINARY_MACRO | เวิร์กบุ๊ก Excel ไบนารี่ที่เปิดใช้งานแมโคร (*.xlsb). |
