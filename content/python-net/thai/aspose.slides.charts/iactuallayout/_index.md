## IActualLayout คลาส

ระบุตำแหน่งที่แท้จริงขององค์ประกอบแผนภูมิ

ประเภท IActualLayout เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`actual_x`](/slides/python-net/th/aspose.slides.charts/iactuallayout/actual_x/) | ระบุตำแหน่ง x (ซ้าย) ที่แท้จริงขององค์ประกอบแผนภูมิสัมพันธ์กับมุมซ้ายบนของแผนภูมิ.<br/>            เรียกเมธอด IChart.ValidateChartLayout() ก่อนเพื่อรับค่าจริง. <br/>            อ่าน **float**. |
| [`actual_y`](/slides/python-net/th/aspose.slides.charts/iactuallayout/actual_y/) | ระบุตำแหน่งบนที่แท้จริงขององค์ประกอบแผนภูมิสัมพันธ์กับมุมซ้ายบนของแผนภูมิ.<br/>            เรียกเมธอด IChart.ValidateChartLayout() ก่อนเพื่อรับค่าจริง. <br/>            อ่าน **float**. |
| [`actual_width`](/slides/python-net/th/aspose.slides.charts/iactuallayout/actual_width/) | ระบุความกว้างที่แท้จริงขององค์ประกอบแผนภูมิ. เรียกเมธอด IChart.ValidateChartLayout() ก่อนเพื่อรับค่าจริง. <br/>            อ่าน **float**. |
| [`actual_height`](/slides/python-net/th/aspose.slides.charts/iactuallayout/actual_height/) | ระบุความสูงที่แท้จริงขององค์ประกอบแผนภูมิ. เรียกเมธอด IChart.ValidateChartLayout() ก่อนเพื่อรับค่าจริง. <br/>            อ่าน **float**. |
