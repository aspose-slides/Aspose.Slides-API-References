## LegendPositionType enumeration

กำหนดตำแหน่งของ legend บนแผนภูมิ

ประเภท LegendPositionType เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| Field | Description |
| :- | :- |
| BOTTOM | ระบุว่า legend จะถูกวาดที่ด้านล่างของแผนภูมิ |
| LEFT | ระบุว่า legend จะถูกวาดที่ด้านซ้ายของแผนภูมิ |
| RIGHT | ระบุว่า legend จะถูกวาดที่ด้านขวาของแผนภูมิ |
| TOP | ระบุว่า legend จะถูกวาดที่ด้านบนของแผนภูมิ |
| TOP_RIGHT | ระบุว่า legend จะถูกวาดที่ด้านบนขวาของแผนภูมิ |
