## LegendEntryCollection คลาส

เป็นตัวแทนของคอลเลกชันของคติ.

ประเภท LegendEntryCollection เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`count`](/slides/python-net/th/aspose.slides.charts/legendentrycollection/count/) | รับจำนวนของรายการคติ.<br/>            อ่านอย่างเดียว **int**. |

รับคุณสมบัติของรายการคติที่สอดคล้องกับ Chart.ChartData.Series[0].DataPoints[index] ในกรณีที่ประเภทแผนภูมิอยู่ในรายการต่อไปนี้:
  ChartType.BarOfPie,
  ChartType.ExplodedPie,
  ChartType.ExplodedPie3D,
  ChartType.Pie,
  ChartType.Pie3D,
  ChartType.PieOfPie;
หรือสอดคล้องกับ Chart.ChartData.Series[index] สำหรับประเภทแผนภูมิอื่น ๆ.
