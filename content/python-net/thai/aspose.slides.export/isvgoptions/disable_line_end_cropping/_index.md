## disable_line_end_cropping คุณสมบัติ
SVG 1.1 ขาดความสามารถในการกำหนดช่องว่างสำหรับตัวบ่งชี้.
            Aspose.Slides เครื่องมือเขียน SVG มีวิธีแก้ปัญหานั้น:
            มันตัดส่วนท้ายของเส้นที่มีลูกศร, ดังนั้นเส้นจะไม่ทับซ้อนกับตัวบ่งชี้.
            ตัวเลือกนี้จะปิดการทำงานดังกล่าว.
            อ่าน/เขียน **bool**.
