## SvgExternalFontsHandling การกำหนดค่า

แสดงวิธีการจัดการแบบอักษรภายนอกที่ใช้สำหรับการวาดข้อความ

ประเภท SvgExternalFontsHandling เปิดให้เข้าถึงสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| ADD_LINKS_TO_FONT_FILES | เพิ่มลิงก์ไปยังไฟล์แบบอักษรแยกต่างหากในส่วนสไตล์ของไฟล์ SVG. |
| EMBED | บันทึกข้อมูลแบบอักษรโดยตรงลงในไฟล์ SVG. โปรดตรวจสอบข้อตกลงลิขสิทธิ์ของแบบอักษรภายนอกทั้งหมดก่อนใช้ตัวเลือกนี้. |
| VECTORIZE | บันทึกข้อความทั้งหมดที่ใช้แบบอักษรภายนอกเป็นกราฟิก. |
