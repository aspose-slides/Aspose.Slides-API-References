## enumeration SaveFormat

ค่าคงที่ที่กำหนดรูปแบบของงานนำเสนอที่บันทึกไว้.

ประเภท SaveFormat เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| PPT | บันทึกงานนำเสนอในรูปแบบ PPT. |
| PDF | บันทึกงานนำเสนอในรูปแบบ PDF. |
| XPS | บันทึกงานนำเสนอในรูปแบบ XPS. |
| PPTX | บันทึกงานนำเสนอในรูปแบบ PPTX. |
| PPSX | บันทึกงานนำเสนอในรูปแบบ PPSX (การแสดงสไลด์). |
| TIFF | บันทึกงานนำเสนอเป็นภาพ TIFF แบบหลายหน้า. |
| ODP | บันทึกงานนำเสนอในรูปแบบ ODP. |
| PPTM | บันทึกงานนำเสนอในรูปแบบ PPTM (งานนำเสนอที่เปิดใช้งานมาโคร). |
| PPSM | บันทึกงานนำเสนอในรูปแบบ PPSM (การแสดงสไลด์ที่เปิดใช้งานมาโคร). |
| POTX | บันทึกงานนำเสนอในรูปแบบ POTX (แม่แบบ). |
| POTM | บันทึกงานนำเสนอในรูปแบบ POTM (แม่แบบที่เปิดใช้งานมาโคร). |
| HTML | บันทึกงานนำเสนอในรูปแบบ HTML. |
| SWF | บันทึกงานนำเสนอในรูปแบบ SWF. |
| OTP | บันทึกงานนำเสนอในรูปแบบ OTP (แม่แบบงานนำเสนอ). |
| PPS | บันทึกงานนำเสนอในรูปแบบ PPS. |
| POT | บันทึกงานนำเสนอในรูปแบบ POT. |
| FODP | บันทึกงานนำเสนอในรูปแบบ FODP. |
| GIF | บันทึกงานนำเสนอในรูปแบบ GIF. |
| HTML5 | บันทึกงานนำเสนอในรูปแบบ HTML โดยใช้ระบบเทมเพลต HTML5 ใหม่. |
| MD | บันทึกงานนำเสนอในรูปแบบ Markdown |
| XML | บันทึกงานนำเสนอในรูปแบบ PowerPoint XML Presentation. |
