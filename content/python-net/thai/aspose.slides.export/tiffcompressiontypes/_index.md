## TiffCompressionTypes enumeration

ให้ตัวเลือกที่ควบคุมวิธีการบีบอัดการนำเสนอในรูปแบบ TIFF.

ประเภท TiffCompressionTypes แสดงสมาชิกต่อไปนี้:

## Fields

| Field | Description |
| :- | :- |
| DEFAULT | ระบุโครงการบีบอัดเริ่มต้น (LZW). |
| NONE | ระบุว่าไม่มีการบีบอัด. |
| CCITT3 | ระบุโครงการบีบอัด CCITT3. |
| CCITT4 | ระบุโครงการบีบอัด CCITT4. |
| LZW | ระบุโครงการบีบอัด LZW (ค่าเริ่มต้น). |
| RLE | ระบุโครงการบีบอัด RLE. |
