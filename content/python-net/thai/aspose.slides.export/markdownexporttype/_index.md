## MarkdownExportType enumeration

ประเภทของการแสดงผลเอกสาร

ประเภท MarkdownExportType มีสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| SEQUENTIAL | แสดงผลทุกรายการแยกกัน ทีละรายการ |
| TEXT_ONLY | แสดงผลเฉพาะข้อความ |
| VISUAL | แสดงผลทุกรายการ, รายการที่จัดกลุ่ม - แสดงร่วมกัน |
