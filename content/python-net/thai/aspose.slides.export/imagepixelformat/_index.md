## ImagePixelFormat การระบุค่า

ระบุรูปแบบพิกเซลสำหรับภาพที่สร้างขึ้น

ประเภท ImagePixelFormat เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| FORMAT_1BPP_INDEXED | 1 บิตต่อพิกเซล, จัดทำดรรชนี |
| FORMAT_4BPP_INDEXED | 4 บิตต่อพิกเซล, จัดทำดรรชนี |
| FORMAT_8BPP_INDEXED | 8 บิตต่อพิกเซล, จัดทำดรรชนี |
| FORMAT_24BPP_RGB | 24 บิตต่อพิกเซล, RGB |
| FORMAT_32BPP_ARGB | 32 บิตต่อพิกเซล, ARGB |
