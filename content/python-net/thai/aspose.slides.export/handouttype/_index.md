## HandoutType การระบุค่า

ระบุจำนวนสไลด์และลำดับที่จะแสดงบนหน้า

ประเภท HandoutType เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| HANDOUTS1 | หนึ่งสไลด์ต่อหน้า |
| HANDOUTS2 | สองสไลด์ต่อหน้า |
| HANDOUTS3 | สามสไลด์ต่อหน้า |
| HANDOUTS_4_HORIZONTAL | สี่สไลด์ต่อหน้าในลำดับแนวนอน |
| HANDOUTS_4_VERTICAL | สี่สไลด์ต่อหน้าในลำดับแนวตั้ง |
| HANDOUTS_6_HORIZONTAL | หกสไลด์ต่อหน้าในลำดับแนวนอน |
| HANDOUTS_6_VERTICAL | หกสไลด์ต่อหน้าในลำดับแนวตั้ง |
| HANDOUTS_9_HORIZONTAL | เก้าสไลด์ต่อหน้าในลำดับแนวนอน |
| HANDOUTS_9_VERTICAL | เก้าสไลด์ต่อหน้าในลำดับแนวตั้ง |
