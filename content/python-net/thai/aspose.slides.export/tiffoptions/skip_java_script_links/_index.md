## คุณสมบัติ skip_java_script_links
ระบุว่าจะข้ามไฮเปอร์ลิงก์ที่มีการเรียก JavaScript หรือไม่เมื่อบันทึกการนำเสนอ. 
            อ่าน/เขียน **bool**. ค่าเริ่มต้นคือ **false** .


### หมายเหตุ

เมื่อกำหนดคุณสมบัตินี้เป็น **true** , ไฮเปอร์ลิงก์ที่มีการเรียก JavaScript จะถูกละเว้นขณะบันทึก.


เมื่อกำหนดคุณสมบัตินี้เป็น **false** , ไฮเปอร์ลิงก์ทั้งหมดจะถูกบันทึก.
