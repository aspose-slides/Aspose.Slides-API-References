## PdfCompliance การนับค่า

ค่าคงที่ที่กำหนดระดับการปฏิบัติตามมาตรฐาน PDF

ประเภท PdfCompliance เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| PDF15 | ไฟล์ผลลัพธ์จะสอดคล้องกับมาตรฐาน PDF 1.5 |
| PDF16 | ไฟล์ผลลัพธ์จะสอดคล้องกับมาตรฐาน PDF 1.6 |

| PDF_A1B | ไฟล์ผลลัพธ์จะสอดคล้องกับมาตรฐาน PDF/A-1b |
| PDF_A1A | ไฟล์ผลลัพธ์จะสอดคล้องกับมาตรฐาน PDF/A-1a |
| PDF_A2B | ไฟล์ผลลัพธ์จะสอดคล้องกับมาตรฐาน PDF/A-2b |
| PDF_A2A | ไฟล์ผลลัพธ์จะสอดคล้องกับมาตรฐาน PDF/A-2a |
| PDF_A3B | ไฟล์ผลลัพธ์จะสอดคล้องกับมาตรฐาน PDF/A-3b |
| PDF_A3A | ไฟล์ผลลัพธ์จะสอดคล้องกับมาตรฐาน PDF/A-3a |
| PDF_UA | ไฟล์ผลลัพธ์จะสอดคล้องกับมาตรฐาน PDF/UA |
