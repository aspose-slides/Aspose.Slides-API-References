## SvgCoordinateUnit enumeration

แทนหน่วยพิกัด CSS2 ที่ใช้กำหนดพิกัด SVG.

ประเภท SvgCoordinateUnit เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| INCH | นิ้ว |
| CENTIMETER | เซนติเมตร. |
| MILLIMETER | มิลลิเมตร. |
| POINT | พอยต์ (1/72 ของนิ้ว), |
| PICA | พิก้า (1/6 ของนิ้ว). |
| EM | ขนาด Em ของฟอนต์ขององค์ประกอบที่กำหนด. |
| EX | ขนาด Ex (ขนาดของอักษรตัวพิมพ์เล็ก, โดยทั่วไปคือ "x") ของฟอนต์ขององค์ประกอบที่กำหนด. |
| PIXEL | ขนาดพิกเซล. |
| PERCENT | เปอร์เซ็นต์. |
