## การจำแนก Conformance

ระบุคลาสการปฏิบัติตามที่เอกสาร PresentationML ปฏิบัติตาม

ประเภท Conformance เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| ECMA_376_2006 | ระบุว่าเอกสารสอดคล้องกับ ECMA376:2006. |
| ISO_29500_2008_TRANSITIONAL | ระบุว่าเอกสารสอดคล้องกับคลาสการปฏิบัติตามแบบ Transitional ของ ISO/IEC 29500:2008. |
| ISO_29500_2008_STRICT | ระบุว่าเอกสารสอดคล้องกับคลาสการปฏิบัติตามแบบ Strict ของ ISO/IEC 29500:2008. |
