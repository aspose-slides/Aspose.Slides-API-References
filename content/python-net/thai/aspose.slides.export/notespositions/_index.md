## NotesPositions การนับ

เป็นตัวแทนของกฎเพื่อเรนเดอร์โน้ตในเอกสารที่ส่งออก

ประเภท NotesPositions เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| NONE | ระบุว่าโน้ตไม่ควรแสดงเลย |
| BOTTOM_FULL | ระบุว่าโน้ตควรแสดงเต็มโดยใช้หน้าพิเศษตามที่ต้องการ |
| BOTTOM_TRUNCATED | ระบุว่าโน้ตควรแสดงในหน้าเดียวเท่านั้น |
