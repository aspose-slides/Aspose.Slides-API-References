## CommentsPositions enumeration

เป็นกฎที่กำหนดการแสดงความเห็นในเอกสารที่ส่งออก

ประเภท CommentsPositions เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| NONE | ระบุว่าความคิดเห็นไม่ควรแสดงเลย |
| BOTTOM | ระบุว่าความคิดเห็นควรแสดงที่ส่วนล่างของหน้า |
| RIGHT | ระบุว่าความคิดเห็นควรแสดงทางด้านขวาของหน้า |
