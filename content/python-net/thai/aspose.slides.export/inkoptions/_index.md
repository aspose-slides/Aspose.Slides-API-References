## InkOptions คลาส

ประเภท InkOptions มีสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`hide_ink`](/slides/python-net/th/aspose.slides.export/inkoptions/hide_ink/) | แสดงหรือซ่อนองค์ประกอบ Ink ในเอกสารที่ส่งออก. |
| [`interpret_mask_op_as_opacity`](/slides/python-net/th/aspose.slides.export/inkoptions/interpret_mask_op_as_opacity/) | ใช้การดำเนินการ ROP หรือความทึบแสงสำหรับการวาดแปรง. |
