## skip_java_script_links คุณสมบัติ
ระบุว่าควรข้ามไฮเปอร์ลิงก์ที่มีการเรียกใช้ JavaScript หรือไม่เมื่อบันทึกการนำเสนอ. 
            อ่าน/เขียน **bool**. ค่าเริ่มต้นคือ **false** .


### หมายเหตุ

เมื่อคุณสมบัตินี้ตั้งค่าเป็น **true** , ไฮเปอร์ลิงก์ที่มีการเรียกใช้ JavaScript จะถูกละเว้นขณะบันทึก.


เมื่อคุณสมบัตินี้ตั้งค่าเป็น **false** , ไฮเปอร์ลิงก์ทั้งหมดจะถูกบันทึก.
