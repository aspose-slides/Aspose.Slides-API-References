## ITextToHtmlConversionOptions คลาส

ตัวเลือกสำหรับการสกัด HTML จากข้อความ Pptx.

ประเภท ITextToHtmlConversionOptions เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`add_clipboard_fragment_header`](/slides/python-net/th/aspose.slides.export/itexttohtmlconversionoptions/add_clipboard_fragment_header/) | ส่งคืนหรือกำหนดค่า, แสดงว่า ควรเพิ่มส่วนหัว Clipboard หรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`text_inheritance_limit`](/slides/python-net/th/aspose.slides.export/itexttohtmlconversionoptions/text_inheritance_limit/) | ส่งคืนหรือกำหนดค่าความลึกที่สืบทอดสำหรับคุณสมบัติข้อความ.<br/>            อ่าน/เขียน [`ITextToHtmlConversionOptions.text_inheritance_limit`](/slides/python-net/th/aspose.slides.export/itexttohtmlconversionoptions/text_inheritance_limit). |
| [`link_embed_controller`](/slides/python-net/th/aspose.slides.export/itexttohtmlconversionoptions/link_embed_controller/) | ส่งคืนหรือกำหนดอ็อบเจกต์ callback ที่ควบคุมวิธีการจัดเก็บอ็อบเจกต์ภายนอก.<br/>            อ่าน/เขียน [`ILinkEmbedController`](/slides/python-net/th/aspose.slides.export/ilinkembedcontroller). |
| [`encoding_name`](/slides/python-net/th/aspose.slides.export/itexttohtmlconversionoptions/encoding_name/) | ส่งคืนหรือกำหนดชื่อการเข้ารหัส html.<br/>            ค่านี้จะถูกบันทึกลงในไฟล์ HTML ที่สร้างขึ้น, แต่ขึ้นกับผู้เรียกเพื่อให้แน่ใจว่าไฟล์จะถูกบันทึกด้วยการเข้ารหัสนี้.<br/>            อ่าน/เขียน **str**. |
