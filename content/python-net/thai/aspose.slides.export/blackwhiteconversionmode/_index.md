## BlackWhiteConversionMode enum

ให้ตัวเลือกที่ควบคุมวิธีการแปลงภาพของสไลด์เป็นภาพสองระดับสี

ประเภท BlackWhiteConversionMode มีสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| DEFAULT | ระบุว่าไม่มีอัลกอริธึมการแปลง อัลกอริธึมที่ดำเนินการในตัวแปลง TIFF จะถูกใช้ (ค่าเริ่มต้น) |
| DITHERING | ระบุอัลกอริธึม dithering (Floyd-Steinberg) |
| DITHERING_FLOYD_STEINBERG | ระบุอัลกอริธึม Floyd-Steinberg dithering |
| AUTO | ระบุอัลกอริธึมการกำหนดค่า threshold ที่คำนวณอัตโนมัติ (Otsu) |
| AUTO_OTSU | ระบุอัลกอริธึม threshold ของ Otsu ที่คำนวณอัตโนมัติ |
| THRESHOLD25 | ระบุอัลกอริธึม threshold แบบคงที่ (25%) |
| THRESHOLD50 | ระบุอัลกอริธึม threshold แบบคงที่ (50%) |
| THRESHOLD75 | ระบุอัลกอริธึม threshold แบบคงที่ (75%) |
