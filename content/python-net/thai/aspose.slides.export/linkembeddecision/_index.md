## LinkEmbedDecision enumeration

กำหนดวิธีการประมวลผลวัตถุขณะบันทึก

`LinkEmbedDecision` type จะเปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| LINK | อ็อบเจ็กต์จะถูกจัดเก็บภายนอกและอ้างอิงโดย URL |
| EMBED | ควรฝังอ็อบเจ็กต์ลงในไฟล์ที่สร้างขึ้นหากเป็นไปได้ หากการฝังเป็นไปไม่ได้ `GetUrl` จะถูกเรียก และขึ้นอยู่กับผลลัพธ์ อ็อบเจ็กต์จะถูกอ้างอิงโดย URL หรือถูกละเว้น |
| IGNORE | อ็อบเจ็กต์จะถูกละเว้น |
