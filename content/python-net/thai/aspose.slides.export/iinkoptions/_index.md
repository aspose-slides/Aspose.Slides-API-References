## IInkOptions คลาส

ให้ตัวเลือกที่ควบคุมลักษณะของวัตถุ Ink ในเอกสารที่ส่งออก

IInkOptions ประเภท เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`hide_ink`](/slides/python-net/th/aspose.slides.export/iinkoptions/hide_ink/) | แสดงหรือซ่อนองค์ประกอบ Ink ในเอกสารที่ส่งออก |
| [`interpret_mask_op_as_opacity`](/slides/python-net/th/aspose.slides.export/iinkoptions/interpret_mask_op_as_opacity/) | ใช้การดำเนินการ ROP หรือ Opacity สำหรับการเรนเดอร์แปรง |
