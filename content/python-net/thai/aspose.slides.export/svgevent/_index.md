## SvgEvent enumeration

แทนตัวเลือกสำหรับรูปแบบ SVG.

ประเภท SvgEvent เปิดเผยสมาชิกต่อไปนี้:

## Fields

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| ON_FOCUS_IN | เกิดขึ้นเมื่อองค์ประกอบได้รับโฟกัส เช่น เมื่อข้อความถูกเลือก. |
| ON_FOCUS_OUT | เกิดขึ้นเมื่อองค์ประกอบสูญเสียโฟกัส เช่น เมื่อข้อความไม่ได้เลือกแล้ว. |
| ON_ACTIVATE | เกิดขึ้นเมื่อองค์ประกอบถูกทำงาน เช่น ผ่านการคลิกเมาส์หรือการกดแป้น. |
| ON_CLICK | เกิดขึ้นเมื่อปุ่มอุปกรณ์ชี้ถูกคลิกบนองค์ประกอบ. |
| ON_MOUSE_DOWN | เกิดขึ้นเมื่อปุ่มอุปกรณ์ชี้ถูกกดบนองค์ประกอบ. |
| ON_MOUSE_UP | เกิดขึ้นเมื่อปุ่มอุปกรณ์ชี้ถูกปล่อยบนองค์ประกอบ. |
| ON_MOUSE_OVER | เกิดขึ้นเมื่ออุปกรณ์ชี้เคลื่อนที่เข้าสู่องค์ประกอบ. |
| ON_MOUSE_MOVE | เกิดขึ้นเมื่ออุปกรณ์ชี้เคลื่อนที่ในขณะที่อยู่บนองค์ประกอบ. |
| ON_MOUSE_OUT | เกิดขึ้นเมื่ออุปกรณ์ชี้เคลื่อนที่ออกจากองค์ประกอบ. |
| ON_LOAD | เกิดขึ้นเมื่อเอเจนต์ผู้ใช้ได้ทำการแยกวิเคราะห์องค์ประกอบและลูกของมันและทรัพยากรทั้งหมดที่อ้างอิงอย่างเต็มที่ เพื่อแสดงผล. |
| ON_UNLOAD | เกิดขึ้นเมื่อการทำงานของ DOM ลบเอกสารออกจากหน้าต่างหรือเฟรม ใช้ได้เฉพาะกับองค์ประกอบ svg ที่เป็นชั้นนอกสุดเท่านั้น. |
| ON_ABORT | เกิดขึ้นเมื่อการโหลดหน้าเว็บหยุดก่อนที่องค์ประกอบจะโหลดเสร็จสมบูรณ์. |
| ON_ERROR | เกิดขึ้นเมื่อองค์ประกอบไม่สามารถโหลดได้อย่างถูกต้องหรือเมื่อเกิดข้อผิดพลาดระหว่างการทำงานของสคริปต์. |
| ON_RESIZE | เกิดขึ้นเมื่อมุมมองเอกสารมีการปรับขนาด ใช้ได้เฉพาะกับองค์ประกอบ svg ที่เป็นชั้นนอกสุดเท่านั้น. |
| ON_SCROLL | เกิดขึ้นเมื่อมุมมองเอกสารถูกเลื่อนตามแกน X หรือ Y หรือทั้งสองแกน ใช้ได้เฉพาะกับองค์ประกอบ svg ที่เป็นชั้นนอกสุดเท่านั้น. |
| ON_ZOOM | เกิดขึ้นเมื่อระดับการขยายของมุมมองเอกสารถูกเปลี่ยน ใช้ได้เฉพาะกับองค์ประกอบ svg ที่เป็นชั้นนอกสุดเท่านั้น. |
| ON_BEGIN | เกิดขึ้นเมื่อองค์ประกอบการเคลื่อนไหวเริ่มต้น. |
| ON_END | เกิดขึ้นเมื่อองค์ประกอบการเคลื่อนไหวสิ้นสุด. |
| ON_REPEAT | เกิดขึ้นเมื่อองค์ประกอบการเคลื่อนไหวทำซ้ำ. |
