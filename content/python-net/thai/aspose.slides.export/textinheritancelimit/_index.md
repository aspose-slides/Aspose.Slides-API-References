## การกำหนดค่า TextInheritanceLimit

ควบคุมความลึกของการสืบทอดคุณสมบัติข้อความ

ชนิด TextInheritanceLimit แสดงสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| ALL | สืบทอดคุณสมบัติข้อความทั้งหมด |
| TEXT_BOX | สืบทอดเฉพาะจากสไตล์ของ TextFrame |
| PARAGRAPH_ONLY | ใช้คุณสมบัติที่กำหนดไว้เฉพาะสำหรับย่อหน้า |
