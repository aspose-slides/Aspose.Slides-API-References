## embed_true_type_fonts_for_ascii คุณสมบัติ
Determines if Aspose.Slides will embed common fonts for ASCII (33..127 code range) text.
            ฟอนต์สำหรับรหัสอักขระที่มากกว่า 127 จะถูกฝังเสมอ.
            รายการฟอนต์ทั่วไปรวมถึงฟอนต์ฐาน 14 ของ PDF และฟอนต์เพิ่มเติมที่ผู้ใช้ระบุ.
            อ่าน/เขียน **bool**.

### หมายเหตุ

ค่าเริ่มต้นคือ **true** .
