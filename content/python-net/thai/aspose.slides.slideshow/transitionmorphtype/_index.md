## การนับค่า TransitionMorphType

แสดงประเภทของการเปลี่ยนแปลงแบบ morph.

ประเภท TransitionMorphType แสดงสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| BY_OBJECT | การเปลี่ยนแปลงแบบ morph จะดำเนินการโดยพิจารณารูปร่างเป็นวัตถุที่ไม่แยกย่อย |
| BY_WORD | การเปลี่ยนแปลงแบบ morph จะดำเนินการโดยการถ่ายทอดข้อความตามคำเมื่อเป็นไปได้ |
| BY_CHAR | การเปลี่ยนแปลงแบบ morph จะดำเนินการโดยการถ่ายทอดข้อความตามอักขระเมื่อเป็นไปได้ |
