## WarningType การจัดรายการ

เป็นประเภทของคำเตือน.

ประเภท WarningType มีสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| SOURCE_FILE_CORRUPTION | พบปัญหาในเอกสารต้นฉบับซึ่งทำให้มีความเป็นไปได้สูงว่าเอกสารจะไม่สามารถเปิดได้หากบันทึกในรูปแบบเดิมของมัน. |
| DATA_LOSS | ข้อความ/แผนภูมิ/รูปภาพ หรือข้อมูลอื่นจะหายไปอย่างสมบูรณ์จากต้นไม้ของเอกสารหลังจากโหลด หรือจากเอกสารที่สร้างขึ้นหลังจากบันทึก. |
| MAJOR_FORMATTING_LOSS | การสูญเสียการจัดรูปแบบอย่างมาก. |
| MINOR_FORMATTING_LOSS | การสูญเสียการจัดรูปแบบเล็กน้อย. |
| COMPATIBILITY_ISSUE | นี่เป็นปัญหาที่ทราบแล้วซึ่งจะทำให้เอกสารไม่สามารถเปิดได้โดยเอเจนต์ผู้ใช้บางตัว หรือเวอร์ชันก่อนของเอเจนต์ผู้ใช้. |
| UNEXPECTED_CONTENT | บางเนื้อหาในเอกสารต้นฉบับไม่สามารถระบุได้ (เช่น ไม่รองรับ) ซึ่งอาจทำให้เกิดปัญหา หรืออาจทำให้ข้อมูล/การจัดรูปแบบสูญเสียได้. |
