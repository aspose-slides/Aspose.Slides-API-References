## คลาส

| คลาส | คำอธิบาย |
| :- | :- |
| [`IKnownIssueWarningInfo`](/slides/python-net/th/aspose.slides.warnings/iknownissuewarninginfo/) | แสดงคำเตือนเกี่ยวกับปัญหาที่ทราบซึ่งจะไม่ถูกแก้ไขในอนาคตอันใกล้. |
| [`INotImplementedWarningInfo`](/slides/python-net/th/aspose.slides.warnings/inotimplementedwarninginfo/) | แสดงคำเตือนเกี่ยวกับฟีเจอร์ที่ยังไม่ได้ทำซึ่งจะไม่ถูกดำเนินการในอนาคตอันใกล้. |
| [`IObsoletePresLockingBehaviorWarningInfo`](/slides/python-net/th/aspose.slides.warnings/iobsoletepreslockingbehaviorwarninginfo/) | คำเตือนนี้บ่งชี้ว่ามีการใช้พฤติกรรมการล็อกการนำเสนอที่ล้าสมัย. |
| [`IPresentationSignedWarningInfo`](/slides/python-net/th/aspose.slides.warnings/ipresentationsignedwarninginfo/) | คำเตือนนี้บ่งชี้ว่าการนำเสนอที่กำลังอ่านมีลายเซ็น <br/>            และลายเซ็นนี้จะถูกลบออกระหว่างการประมวลผล. |
| [`IWarningCallback`](/slides/python-net/th/aspose.slides.warnings/iwarningcallback/) | อินเทอร์เฟซสำหรับคลาสที่รับคำเตือน |
| [`IWarningInfo`](/slides/python-net/th/aspose.slides.warnings/iwarninginfo/) | แสดงอินเทอร์เฟซพื้นฐานสำหรับคำเตือนทั้งหมด. |
