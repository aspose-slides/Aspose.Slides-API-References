## InkBrush คลาส

แสดงถึงอ็อบเจกต์ inkBrush.

ประเภท InkBrush แสดงสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`color`](/slides/python-net/th/aspose.slides.ink/inkbrush/color/) | รับหรือกำหนดสีแปรงสำหรับเส้น. |
| [`size`](/slides/python-net/th/aspose.slides.ink/inkbrush/size/) | รับหรือกำหนดขนาดแปรงสำหรับเส้นเป็นหน่วยจุด. |
| [`ink_effect`](/slides/python-net/th/aspose.slides.ink/inkbrush/ink_effect/) | รับประเภทเอฟเฟกต์หมึก (เช่น Galaxy, Gold, Silver) ที่กำหนดรูปแบบการแสดงผลของการวาดด้วยหมึก.<br/>            ค่าได้มาจากคุณสมบัติแปรง "inkEffects". หากไม่มีเอฟเฟกต์ที่รู้จักระบุไว้,<br/>            [`InkEffectType.NOT_DEFINED`](/slides/python-net/th/aspose.slides.ink/inkeffecttype/NOT_DEFINED) จะถูกคืนค่า. |
