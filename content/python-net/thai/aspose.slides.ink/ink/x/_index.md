## x คุณสมบัติ
รับหรือกำหนดค่าพิกัด x ของมุมซ้ายบนของรูปทรง โดยวัดเป็นจุด.
อ่าน/เขียน **float**.


### หมายเหตุ

ค่าที่ส่งกลับจะถูกกำหนดเสมอและจะไม่เป็น **float**.
ค่าที่กำหนดต้องถูกกำหนดเช่นกัน; ให้กำหนด **float** เฉพาะกับคุณสมบัติของอินสแตนซ์ `RawFrame` เท่านั้น.

### คำจำกัดความ:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
