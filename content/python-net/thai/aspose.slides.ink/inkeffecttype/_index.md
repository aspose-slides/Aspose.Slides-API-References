## InkEffectType การกำหนดค่า

ระบุชุดของเอฟเฟกต์ภาพที่กำหนดล่วงหน้าสำหรับการเรนเดอร์หมึก.  
แต่ละเอฟเฟกต์สอดคล้องกับพื้นผิวหรือภาพที่จำลองลักษณะหมึกสไตล์.  
ค่าสเหล่านี้สามารถใช้เพื่อปรับแต่งสไตล์ภาพของเส้นหมึกดิจิทัลระหว่างการเรนเดอร์.

ประเภท InkEffectType เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| NOT_DEFINED | เอฟเฟกต์ไม่ได้กำหนดหรือไม่ทราบค่า ค่านี้สามารถใช้เป็นค่าเริ่มต้นหรือสำรองได้. |
| BRONZE | พื้นผิวโลหะสีอุ่นสีน้ำตาลที่คล้ายหมึกบรอนซ์. |
| GALAXY | พื้นผิวสีสันสดใสและแวววาวที่คล้ายกาแล็กซี่ พร้อมโทนสีจักรวาล. |
| GOLD | พื้นผิวโลหะสีทองสว่างที่ทำให้เส้นหมึกดูหรูหรา. |
| LAVA | พื้นผิวไฟแรงที่คล้ายลาวาไหล มีเฉดสีแดงและส้ม. |
| OCEAN | พื้นผิวสีฟ้าเข้มคล้ายของเหลวที่จำลองคลื่นทะเลหรือหมึกแบบน้ำ. |
| RAINBOW_GLITTER | เอฟเฟกต์แววระยิบสีรุ้งสีสันที่ใช้กับเส้นหมึกเทศกาลหรือสว่างสดใส. |
| ROSE_GOLD | การผสมสีชมพูทองอ่อนคล้ายโรสโกลด์ เพื่อเส้นหมึกที่สง่างาม. |
| SILVER | พื้นผิวโลหะสีเงินเย็นที่จำลองหมึกสีเงินคลาสสิก. |
