## x คุณสมบัติ
รับหรือกำหนดค่าพิกัด x ของมุมบนซ้ายของรูปทรง, หน่วยเป็นจุด.
            อ่าน/เขียน **float**.


### หมายเหตุ

            ค่าที่ส่งกลับจะถูกกำหนดเสมอและไม่เป็น **float**.
            ค่าที่กำหนดต้องถูกกำหนดเช่นกัน; ให้กำหนด **float** เฉพาะกับคุณสมบัติของอินสแตนซ์ `RawFrame` เท่านั้น.

### คำนิยาม:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
