## IVbaProject คลาส

แสดงถึงโครงการ VBA พร้อมแมโครการนำเสนอ

ประเภท IVbaProject เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`name`](/slides/python-net/th/aspose.slides.vba/ivbaproject/name/) | คืนค่าชื่อของโครงการ VBA.<br/>            อ่านอย่างเดียว **str**. |
| [`modules`](/slides/python-net/th/aspose.slides.vba/ivbaproject/modules/) | คืนรายการของโมดูลทั้งหมดที่อยู่ในโครงการ VBA.<br/>            อ่านอย่างเดียว [`IVbaModuleCollection`](/slides/python-net/th/aspose.slides.vba/ivbamodulecollection). |
| [`references`](/slides/python-net/th/aspose.slides.vba/ivbaproject/references/) | คืนรายการของการอ้างอิงทั้งหมดที่อยู่ในโครงการ VBA.<br/>            อ่านอย่างเดียว [`IVbaReferenceCollection`](/slides/python-net/th/aspose.slides.vba/ivbareferencecollection). |
| [`is_password_protected`](/slides/python-net/th/aspose.slides.vba/ivbaproject/is_password_protected/) | ระบุว่า VBAProject ถูกปกป้องด้วยรหัสผ่านเพื่อดูคุณสมบัติของโครงการหรือไม่.<br/>            อ่านอย่างเดียว **bool**. |

## เมธอด

| เมธอด | คำอธิบาย |
| :- | :- |
| [`to_binary(self)`](/slides/python-net/th/aspose.slides.vba/ivbaproject/to_binary/#) | คืนตัวแทนไบนารีของโครงการ VBA ในรูปแบบคอนเทนเนอร์ OLE.<br/>            อ่านอย่างเดียว **int**[]. |
