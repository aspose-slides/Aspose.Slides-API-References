## VbaProject คลาส

แสดงโครงการ VBA ที่มีแมโครการนำเสนอ

ประเภท VbaProject เปิดเผยสมาชิกต่อไปนี้:

## Constructors

| Constructor | Description |
| :- | :- |
| [`__init__(self)`](/slides/python-net/th/aspose.slides.vba/vbaproject/__init__/#) | คอนสตรัคเตอร์นี้สร้างโครงการ VBA ใหม่ตั้งแต่เริ่มต้น.<br/>            Project will be created in 1252 Windows Latin 1 (ANSI) codepage |
| [`__init__(self, data)`](/slides/python-net/th/aspose.slides.vba/vbaproject/__init__/#bytes) | คอนสตรัคเตอร์นี้โหลดโครงการ VBA จากการแทนแบบไบนารีของคอนเทนเนอร์ OLE. |

## Properties

| Property | Description |
| :- | :- |
| [`name`](/slides/python-net/th/aspose.slides.vba/vbaproject/name/) | คืนค่าชื่อของโครงการ VBA.<br/>            Read-only **str**. |
| [`modules`](/slides/python-net/th/aspose.slides.vba/vbaproject/modules/) | คืนค่ารายการของโมดูลทั้งหมดที่อยู่ในโครงการ VBA.<br/>            Read-only [`IVbaModuleCollection`](/slides/python-net/th/aspose.slides.vba/ivbamodulecollection). |
| [`references`](/slides/python-net/th/aspose.slides.vba/vbaproject/references/) | คืนค่ารายการของการอ้างอิงทั้งหมดที่อยู่ในโครงการ VBA.<br/>            Read-only [`IVbaReferenceCollection`](/slides/python-net/th/aspose.slides.vba/ivbareferencecollection). |
| [`is_password_protected`](/slides/python-net/th/aspose.slides.vba/vbaproject/is_password_protected/) | บ่งชี้ว่า VBAProject ถูกป้องกันด้วยรหัสผ่านเพื่อดูคุณสมบัติของโครงการหรือไม่.<br/>            Read-only **bool**. |
