## MasterTheme คลาส

แสดงถึงธีมหลัก

**การสืบทอด:**[`MasterTheme`](/slides/python-net/th/aspose.slides.theme/mastertheme) → [`Theme`](/slides/python-net/th/aspose.slides.theme/theme)

ประเภท MasterTheme เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`color_scheme`](/slides/python-net/th/aspose.slides.theme/mastertheme/color_scheme/) | ส่งคืนโครงร่างสี.<br/>            อ่านอย่างเดียว [`IColorScheme`](/slides/python-net/th/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/th/aspose.slides.theme/mastertheme/font_scheme/) | ส่งคืนโครงร่างแบบอักษร.<br/>            อ่านอย่างเดียว [`IFontScheme`](/slides/python-net/th/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/th/aspose.slides.theme/mastertheme/format_scheme/) | ส่งคืนโครงร่างรูปแบบรูปร่าง.<br/>            อ่านอย่างเดียว [`IFormatScheme`](/slides/python-net/th/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/th/aspose.slides.theme/mastertheme/presentation/) | ส่งคืนการนำเสนอแม่.<br/>            อ่านอย่างเดียว [`IPresentation`](/slides/python-net/th/aspose.slides/ipresentation). |
| [`extra_color_schemes`](/slides/python-net/th/aspose.slides.theme/mastertheme/extra_color_schemes/) | ส่งคืนคอลเลกชันของโครงร่างสีเพิ่มเติม.<br/>            โครงร่างเหล่านี้ไม่ได้ส่งผลต่อรูปลักษณ์ของการนำเสนอ สามารถเลือกเป็นโครงร่างสีหลักสำหรับสไลด์ได้.<br/>            อ่านอย่างเดียว [`IExtraColorSchemeCollection`](/slides/python-net/th/aspose.slides.theme/iextracolorschemecollection). |
| [`name`](/slides/python-net/th/aspose.slides.theme/mastertheme/name/) | ส่งคืนชื่อของธีม.<br/>            อ่าน/เขียน **str**. |
