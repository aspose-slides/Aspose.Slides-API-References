## คลาส

| คลาส | คำอธิบาย |
| :- | :- |
| [`CellCircularReferenceException`](/slides/python-net/th/aspose.slides.spreadsheet/cellcircularreferenceexception/) | ข้อยกเว้นที่เกิดขึ้นเมื่อพบการอ้างอิงแบบวงกลมหนึ่งหรือหลายรายการที่สูตรอ้างอิงถึงเซลของตนเอง<br/>            โดยตรงหรือโดยอ้อม. |
| [`CellInvalidFormulaException`](/slides/python-net/th/aspose.slides.spreadsheet/cellinvalidformulaexception/) | ข้อยกเว้นที่เกิดขึ้นเมื่อสูตรที่คำนวณไม่ถูกต้องหรือไม่สามารถแยกวิเคราะห์ได้. |
| [`CellInvalidReferenceException`](/slides/python-net/th/aspose.slides.spreadsheet/cellinvalidreferenceexception/) | ข้อยกเว้นที่เกิดขึ้นเมื่อพบการอ้างอิงเซลที่ไม่ถูกต้อง. |
