## OrganizationChartLayoutType การนับค่า

แทนประเภทการจัดรูปแบบของโหนดลูกในแผนผังองค์กร

ชนิด OrganizationChartLayoutType เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| INITIAL | รูปแบบการจัดวางเริ่มต้น |
| STANDART | วางโหนดลูกแนวนอนใต้โหนดพาเรนท์ |
| BOTH_HANGING | วางโหนดลูกแนวตั้งใต้โหนดพาเรนท์ทั้งด้านซ้ายและด้านขวา |
| LEFT_HANGING | วางโหนดลูกแนวตั้งใต้โหนดพาเรนท์ทางด้านซ้าย |
| RIGHT_HANGING | วางโหนดลูกแนวตั้งใต้โหนดพาเรนท์ทางด้านขวา |
