## การนับค่าของ SmartArtLayoutType

แสดงประเภทการจัดวางของแผนภูมิ SmartArt

ประเภท SmartArtLayoutType มีสมาชิกต่อไปนี้:

## ฟิลด์

| Field | คำอธิบาย |
| :- | :- |
| ACCENT_PROCESS | ใช้เพื่อแสดงความก้าวหน้า ไทม์ไลน์ หรือขั้นตอนต่อเนื่องในงาน กระบวนการ หรือเวิร์กโฟลว์ ทำได้ดีในการอธิบายข้อความระดับ 1 และระดับ 2 |
| ACCENTED_PICTURE | ใช้เพื่อแสดงแนวคิดภาพถ่ายศูนย์กลางพร้อมแนวคิดที่เกี่ยวข้องอยู่ด้านข้าง ข้อความระดับ 1 ที่อยู่บนสุดจะแสดงเหนือรูปภาพศูนย์กลาง ข้อความที่สอดคล้องกับรูปทรงระดับ 1 อื่น ๆ จะอยู่ถัดจากรูปภาพวงกลมเล็ก ๆ การจัดวางนี้ยังทำงานได้ดีเมื่อไม่มีข้อความ |
| ALTERNATING_FLOW | ใช้เพื่อแสดงกลุ่มข้อมูลหรือขั้นตอนต่อเนื่องในงาน กระบวนการ หรือเวิร์กโฟลว์ เน้นการโต้ตอบหรือความสัมพันธ์ระหว่างกลุ่มข้อมูล |
| ALTERNATING_HEXAGONS | ใช้เพื่อแสดงชุดแนวคิดที่เชื่อมต่อกัน ข้อความระดับ 1 ปรากฏภายในรูปหกเหลี่ยม ข้อความระดับ 2 ปรากฏนอกรูปทรง |
| ALTERNATING_PICTURE_BLOCKS | ใช้เพื่อแสดงชุดรูปภาพจากบนลงล่าง ข้อความสลับกันอยู่ด้านขวาหรือด้านซ้ายของรูปภาพ |
| ALTERNATING_PICTURE_CIRCLES | ใช้เพื่อแสดงชุดรูปภาพพร้อมข้อความ ข้อความที่สอดคล้องจะแสดงในวงกลมศูนย์กลางโดยภาพสลับจากซ้ายไปขวา |
| ARROW_RIBBON | ใช้เพื่อแสดงแนวคิดที่เกี่ยวข้องหรือขัดแย้งพร้อมการเชื่อมต่อ เช่น แรงที่ต้านกัน ข้อความระดับ 1 สองบรรทัดแรกใช้เป็นข้อความในลูกศร ข้อความที่ไม่ได้ใช้จะไม่ปรากฏ แต่ยังคงพร้อมใช้งานหากสลับการจัดวาง |
| ASCENDING_PICTURE_ACCENT_PROCESS | ใช้เพื่อแสดงชุดรูปภาพที่เพิ่มขึ้นพร้อมข้อความอธิบาย ทำได้ดีที่สุดกับข้อความจำนวนเล็กน้อย |
| BALANCE | ใช้เพื่อเปรียบเทียบหรือแสดงความสัมพันธ์ระหว่างสองแนวคิด แต่ละบรรทัดแรกสองบรรทัดของข้อความระดับ 1 จะสอดคล้องกับข้อความที่ด้านบนของแต่ละด้านของจุดศูนย์กลาง เน้นข้อความระดับ 2 ซึ่งจำกัดอยู่ที่สี่รูปทรงต่อด้านของจุดศูนย์กลาง ความสมดุลจะเอียงไปทางด้านที่มีรูปทรงระดับ 2 มากที่สุด ข้อความที่ไม่ได้ใช้จะไม่ปรากฏ แต่ยังคงพร้อมใช้งานหากสลับการจัดวาง |
| BASIC_BENDING_PROCESS | ใช้เพื่อแสดงความก้าวหน้าหรือขั้นตอนต่อเนื่องในงาน กระบวนการ หรือเวิร์กโฟลว์ เพิ่มพื้นที่แสดงแนวนอนและแนวตั้งสำหรับรูปทรงให้สูงสุด |
| BASIC_BLOCK_LIST | ใช้เพื่อแสดงบล็อกข้อมูลที่ไม่ต่อเนื่องหรือเป็นกลุ่ม เพิ่มพื้นที่แสดงแนวนอนและแนวตั้งสำหรับรูปทรงให้สูงสุด |
| BASIC_CHEVRON_PROCESS | ใช้เพื่อแสดงความก้าวหน้า; ไทม์ไลน์; ขั้นตอนต่อเนื่องในงาน กระบวนการ หรือเวิร์กโฟลว์; หรือเน้นการเคลื่อนที่หรือทิศทาง ข้อความระดับ 1 ปรากฏภายในรูปทรงลูกศร ส่วนข้อความระดับ 2 ปรากฏใต้รูปทรงลูกศร |
| BASIC_CYCLE | ใช้เพื่อแสดงลำดับต่อเนื่องของขั้นตอน งาน หรือเหตุการณ์ในรูปแบบวงกลม เน้นขั้นตอนหรือขั้นตอนมากกว่าลูกศรหรือการไหลที่เชื่อมต่อ ทำได้ดีที่สุดกับข้อความระดับ 1 เท่านั้น |
| BASIC_MATRIX | ใช้เพื่อแสดงความสัมพันธ์ของส่วนประกอบต่อทั้งหมดในสี่ส่วนแรกของข้อความระดับ 1 ปรากฏในสี่ส่วนแรก ข้อความที่ไม่ได้ใช้จะไม่ปรากฏ แต่ยังคงพร้อมใช้งานหากสลับการจัดวาง |
| BASIC_PIE | ใช้เพื่อแสดงว่าชิ้นส่วน individuales สร้างเป็นภาพรวมได้อย่างไร บรรทัดแรกเจ็ดบรรทัดของข้อความระดับ 1 สอดคล้องกับรูปแผ่นพายหรือแผ่นกากบาทที่กระจายอย่างเท่าเทียม รูปข้อความระดับ 1 ด้านบนปรากฏนอกส่วนพายเพื่อเน้น ข้อความที่ไม่ได้ใช้จะไม่ปรากฏ แต่ยังคงพร้อมใช้งานหากสลับการจัดวาง |
| BASIC_PROCESS | ใช้เพื่อแสดงความก้าวหน้าหรือขั้นตอนต่อเนื่องในงาน กระบวนการ หรือเวิร์กโฟลว์ |
| BASIC_PYRAMID | ใช้เพื่อแสดงความสัมพันธ์เชิงสัดส่วน เชื่อมต่อกัน หรือเชิงลำดับชั้น โดยส่วนที่ใหญ่ที่สุดอยู่ด้านล่างและค่อยแคบขึ้นไปขึ้นข้างบน ข้อความระดับ 1 ปรากฏในส่วนของพีระมิดและข้อความระดับ 2 ปรากฏในรูปทรงข้างเคียงแต่ละส่วน |
| BASIC_RADIAL | ใช้เพื่อแสดงความสัมพันธ์ต่อแนวคิดศูนย์กลางในวงจร บรรทัดแรกของข้อความระดับ 1 สอดคล้องกับรูปทรงศูนย์กลาง และข้อความระดับ 2 ของมันสอดคล้องกับรูปทรงวงกลมรอบ ๆ ข้อความที่ไม่ได้ใช้จะไม่ปรากฏ แต่ยังคงพร้อมใช้งานหากสลับการจัดวาง |
| BASIC_TARGET | ใช้เพื่อแสดงการบรรจุ การเกรเดชัน หรือความสัมพันธ์เชิงลำดับชั้น บรรทัดแรกห้าบรรทัดของข้อความระดับ 1 เชื่อมโยงกับวงกลม ข้อความที่ไม่ได้ใช้จะไม่ปรากฏ แต่ยังคงพร้อมใช้งานหากสลับการจัดวาง |
| BASIC_TIMELINE | ใช้เพื่อแสดงขั้นตอนต่อเนื่องในงาน กระบวนการ หรือเวิร์กโฟลว์ หรือเพื่อแสดงข้อมูลไทม์ไลน์ ทำได้ดีทั้งกับข้อความระดับ 1 และระดับ 2 |
| BASIC_VENN | ใช้เพื่อแสดงความสัมพันธ์ที่ทับซ้อนหรือเชื่อมต่อกัน บรรทัดแรกเจ็ดบรรทัดของข้อความระดับ 1 สอดคล้องกับวงกลม หากมีข้อความระดับ 1 สี่บรรทัดหรือน้อยกว่านั้น ข้อความจะอยู่ภายในวงกลม หากมีมากกว่าสี่บรรทัด ข้อความจะอยู่ภายนอกวงกลม ข้อความที่ไม่ได้ใช้จะไม่ปรากฏ แต่ยังคงพร้อมใช้งานหากสลับการจัดวาง |
| BENDING_PICTURE_ACCENT_LIST | ใช้เพื่อแสดงบล็อกข้อมูลที่ไม่ต่อเนื่องหรือเป็นกลุ่ม รูปวงกลมเล็ก ๆ ถูกออกแบบให้บรรจุรูปภาพ ทำได้ดีในการอธิบายข้อความระดับ 1 และระดับ 2 เพิ่มพื้นที่แสดงแนวนอนและแนวตั้งสำหรับรูปทรงให้สูงสุด |
| BENDING_PICTURE_BLOCKS | ใช้เพื่อแสดงชุดรูปภาพ กล่องที่คลุมมุมล่างสามารถบรรจุข้อความจำนวนเล็กน้อย |
| BENDING_PICTURE_CAPTION | ใช้เพื่อแสดงชุดรูปภาพต่อเนื่อง กล่องที่คลุมมุมล่างสามารถบรรจุข้อความจำนวนเล็กน้อย |
| BENDING_PICTURE_CAPTION_LIST | ใช้เพื่อแสดงชุดรูปภาพ ชื่อและคำอธิบายปรากฏในรูปทรงคอลเอาต์ใต้แต่ละรูปภาพ |
| BENDING_PICTURE_SEMI_TRANSPARENT_TEXT | ใช้เพื่อแสดงชุดรูปภาพ กล่องกึ่งโปร่งใสคลุมส่วนล่างของรูปภาพและบรรจุข้อความทุกระดับ |
| BLOCK_CYCLE | ใช้เพื่อแสดงลำดับต่อเนื่องของขั้นตอน งาน หรือเหตุการณ์ในรูปแบบวงกลม เน้นขั้นตอนหรือขั้นตอนมากกว่าลูกศรหรือการไหลที่เชื่อมต่อ |
| BUBBLE_PICTURE_LIST | ใช้เพื่อแสดงชุดรูปภาพ สามารถบรรจุรูปภาพระดับ 1 ได้สูงสุดแปดภาพ ข้อความและรูปภาพที่ไม่ได้ใช้จะไม่ปรากฏ แต่ยังคงพร้อมใช้งานหากสลับการจัดวาง ทำได้ดีที่สุดกับข้อความจำนวนเล็กน้อย |
| CAPTIONED_PICTURES | ใช้เพื่อแสดงรูปภาพพร้อมข้อความหลายระดับ ทำได้ดีที่สุดกับข้อความระดับ 1 ปริมาณเล็กน้อยและข้อความระดับ 2 ปริมาณปานกลาง |
| CHEVRON_LIST | ใช้เพื่อแสดงความก้าวหน้าผ่านหลายกระบวนการที่ประกอบเป็นเวิร์กโฟลว์โดยรวม อีกทั้งทำงานได้ดีในการอธิบายกระบวนการที่ขัดแย้งกัน ข้อความระดับ 1 สอดคล้องกับรูปทรงลูกศรแรกทางด้านซ้าย ส่วนข้อความระดับ 2 สอดคล้องกับขั้นตอนย่อยแนวนอนของแต่ละรูปทรงที่มีข้อความระดับ 1 |
| CIRCLE_ACCENT_TIMELINE | ใช้เพื่อแสดงชุดเหตุการณ์หรือข้อมูลไทม์ไลน์ ข้อความระดับ 1 ปรากฏข้างรูปทรงวงกลมขนาดใหญ่ ข้อความระดับ 2 ปรากฏข้างรูปทรงวงกลมขนาดเล็ก |
| CIRCLE_ARROW_PROCESS | ใช้เพื่อแสดงรายการต่อเนื่องพร้อมข้อความสนับสนุนสำหรับแต่ละรายการ ไดอะแกรมนี้ทำได้ดีที่สุดกับข้อความระดับ 1 จำนวนเล็กน้อย |
| CIRCLE_PICTURE_HIERARCHY | ใช้เพื่อแสดงข้อมูลเชิงลำดับชั้นหรือความสัมพันธ์การรายงานในองค์กร รูปภาพปรากฏในวงกลมและข้อความที่สอดคล้องอยู่ข้างรูปภาพ |

| CIRCULAR_BENDING_PROCESS | ใช้เพื่อแสดงลำดับหรือขั้นตอนที่ยาวหรือไม่เป็นเชิงเส้นในงาน กระบวนการ หรือเวิร์กโฟลว์ ทำได้ดีที่สุดกับข้อความระดับ 1 เท่านั้น เพิ่มพื้นที่แสดงแนวนอนและแนวตั้งสำหรับรูปทรงให้สูงสุด |

| CLOSED_CHEVRON_PROCESS | ใช้เพื่อแสดงความก้าวหน้า ไทม์ไลน์ หรือขั้นตอนต่อเนื่องในงาน กระบวนการ หรือเวิร์กโฟลว์ หรือเพื่อเน้นการเคลื่อนที่หรือทิศทาง สามารถใช้เพื่อเน้นข้อมูลในรูปทรงเริ่มต้น ทำได้ดีที่สุดกับข้อความระดับ 1 เท่านั้น |
