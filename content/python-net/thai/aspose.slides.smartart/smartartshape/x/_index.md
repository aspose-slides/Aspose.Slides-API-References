## x คุณสมบัติ
รับหรือกำหนดพิกัด x ของมุมบนซ้ายของรูปร่าง, วัดเป็นหน่วยจุด.
            อ่าน/เขียน **float**.


### หมายเหตุ

ค่าที่ส่งกลับจะถูกกำหนดเสมอและไม่เคยเป็น **float**.
            ค่าที่กำหนดต้องถูกกำหนดเช่นกัน; ให้กำหนด **float** เฉพาะกับคุณสมบัติของอินสแตนซ์ `RawFrame` เท่านั้น.

### คำนิยาม:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
