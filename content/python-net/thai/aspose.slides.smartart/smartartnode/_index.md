## SmartArtNode คลาส

แสดงโหนดของอ็อบเจกต์ SmartArt

ประเภท SmartArtNode เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`child_nodes`](/slides/python-net/th/aspose.slides.smartart/smartartnode/child_nodes/) | คืนคอลเลกชันของโหนดลูกทั้งหมดของโหนดปัจจุบัน.<br/>            อ่านอย่างเดียว [`ISmartArtNodeCollection`](/slides/python-net/th/aspose.slides.smartart/ismartartnodecollection). |
| [`shapes`](/slides/python-net/th/aspose.slides.smartart/smartartnode/shapes/) | คืนคอลเลกชันของรูปร่างทั้งหมดที่เชื่อมโยงกับโหนด.<br/>            อ่านอย่างเดียว [`ISmartArtShapeCollection`](/slides/python-net/th/aspose.slides.smartart/ismartartshapecollection). |
| [`text_frame`](/slides/python-net/th/aspose.slides.smartart/smartartnode/text_frame/) | คืนกรอบข้อความของโหนด.<br/>            อ่านอย่างเดียว [`ITextFrame`](/slides/python-net/th/aspose.slides/itextframe). |
| [`is_assistant`](/slides/python-net/th/aspose.slides.smartart/smartartnode/is_assistant/) | คืนหรือกำหนดโหนดเป็นผู้ช่วย.<br/>            อ่าน/เขียน **bool**. |
| [`level`](/slides/python-net/th/aspose.slides.smartart/smartartnode/level/) | คืนระดับการซ้อนของโหนด.<br/>            อ่านอย่างเดียว **int**. |
| [`bullet_fill_format`](/slides/python-net/th/aspose.slides.smartart/smartartnode/bullet_fill_format/) | คืนอ็อบเจกต์ FillFormat ที่มีคุณสมบัติการจัดรูปแบบการเติมสำหรับจุดหัวข้อของโหนด.<br/>            หมายเหตุ: สามารถคืนค่า None สำหรับประเภทของเค้าโครง SmartArt บางอย่างที่ไม่ได้ให้จุดหัวข้อสำหรับโหนด.<br/>            อ่านอย่างเดียว [`IFillFormat`](/slides/python-net/th/aspose.slides/ifillformat). |
| [`position`](/slides/python-net/th/aspose.slides.smartart/smartartnode/position/) | คืนหรือกำหนดตำแหน่งที่เริ่มจากศูนย์ของโหนดในบรรดาโหนดพี่น้อง.<br/>            อ่าน/เขียน **int**. |
| [`is_hidden`](/slides/python-net/th/aspose.slides.smartart/smartartnode/is_hidden/) | คืนค่า true หากโหนดนี้เป็นโหนดที่ซ่อนอยู่ในโมเดลข้อมูล.<br/>            อ่านอย่างเดียว **bool**. |
| [`organization_chart_layout`](/slides/python-net/th/aspose.slides.smartart/smartartnode/organization_chart_layout/) | คืนหรือกำหนดประเภทเค้าโครงแผนภูมิองค์กรที่เชื่อมโยงกับโหนดปัจจุบัน.<br/>            อ่าน/เขียน [`OrganizationChartLayoutType`](/slides/python-net/th/aspose.slides.smartart/organizationchartlayouttype). |
