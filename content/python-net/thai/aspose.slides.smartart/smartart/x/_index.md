## x คุณสมบัติ
รับหรือกำหนดพิกัด x ของมุมซ้ายบนของรูปร่าง ตามหน่วยจุด.
            อ่าน/เขียน **float**.

### หมายเหตุ

ค่าที่ส่งคืนจะถูกกำหนดเสมอและจะไม่มี **float**.
            ค่าที่กำหนดต้องถูกกำหนดเช่นกัน; กำหนด **float** เฉพาะให้กับคุณสมบัติของออบเจกต์ `RawFrame` เท่านั้น.

### การกำหนด:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
