## คุณสมบัติการหมุน
Returns or sets the number of degrees the specified shape is rotated around
            the z-axis. A positive value indicates clockwise rotation; a negative value
            indicates counterclockwise rotation.
            อ่าน/เขียน **float**.

### หมายเหตุ

ค่าที่ส่งคืนจะกำหนดเสมอ (is not float.NaN).
            ค่าที่กำหนดต้องมีการกำหนด (not float.NaN). คุณสามารถตั้งค่าที่ไม่ได้กำหนดสำหรับคุณสมบัติของอินสแตนซ์ RawFrame ได้.
