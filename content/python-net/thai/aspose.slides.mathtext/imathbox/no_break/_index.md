## no_break คุณสมบัติ
ไม่มีการตัดบรรทัด.
            คุณสมบัตินี้ระบุคุณสมบัติ "unbreakable" บน object box. When true, no line breaks can occur within the box.
            สิ่งนี้อาจมีความสำคัญสำหรับ operator emulators ที่ประกอบด้วย binary operator มากกว่าหนึ่งตัว. 
            When this element is not specified, breaks can occur inside box.
            Default: true

```python
@property
def no_break(self):
    ...

@no_break.setter
def no_break(self, value):
    ...
```
