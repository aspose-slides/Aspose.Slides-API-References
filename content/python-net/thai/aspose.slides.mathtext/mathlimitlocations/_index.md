## enumeration MathLimitLocations

ตำแหน่งของขีดจำกัด (ตัวห้อย/ตัวยก) ในตัวดำเนินการแบบ n-ary

ชนิด MathLimitLocations เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| NOT_DEFINED | ไม่ได้กำหนด |
| UNDER_OVER | ขีดจำกัดแสดงที่ด้านบนและด้านล่างของสัญลักษณ์ตัวดำเนินการ |
| SUBSCRIPT_SUPERSCRIPT | ขีดจำกัดแสดงเป็นตัวห้อยและตัวยก |
