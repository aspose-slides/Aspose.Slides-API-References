## MathRowSpacingRule การนับ

ประเภทของช่องว่างแนวตั้งระหว่างคอลัมน์ในเมทริกซ์หรืออาเรย์

ประเภท MathRowSpacingRule มีสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| SINGLE_LINE_GAP | ช่องว่างบรรทัดเดียว |
| ONE_AND_A_HALF_LINE_GAP | ช่องว่างบรรทัดหนึ่งและครึ่ง |
| TWO_LINE_GAP | ช่องว่างบรรทัดสอง |
| EXACTLY | โดยตรง (อ้างอิงค่าของคุณสมบัติ RowSpacing วัดเป็นจุด) |
| MULTIPLE | หลายค่า (อ้างอิงค่าของคุณสมบัติ RowSpacing วัดเป็นบรรทัด) |
