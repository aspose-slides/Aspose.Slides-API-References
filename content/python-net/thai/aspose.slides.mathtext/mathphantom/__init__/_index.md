## __init__(self, element) {#imathelement}
เริ่มต้นอินสแตนซ์ใหม่ของคลาส [`MathPhantom`](/slides/python-net/th/aspose.slides.mathtext/mathphantom) โดยใช้อิลเมนต์คณิตศาสตร์ฐานที่ระบุ.

```python
def __init__(self, element):
    ...
```

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| :- | :- | :- |
| element | [`IMathElement`](/slides/python-net/th/aspose.slides.mathtext/imathelement) | [`IMathElement`](/slides/python-net/th/aspose.slides.mathtext/imathelement) พื้นฐานที่การมองเห็นและการจัดวางจะถูกควบคุม <br/><br/>            โดย phantom. อิลเมนต์นี้กำหนดเนื้อหาที่อาจถูกซ่อนหรือแสดง <br/><br/>            ในขณะที่ยังส่งผลต่อการจัดตำแหน่งเชิงเรขาคณิตของคณิตศาสตร์รอบข้าง. |

### หมายเหตุ

อิลเมนต์ phantom ใช้เพื่อสำรองหรือกดขนาดพื้นที่การมองเห็นของนิพจน์ฐานโดยไม่จำเป็นต้องแสดงออก มันสอดคล้องกับอิลเมนต์ OMML `<m:phant>`.
