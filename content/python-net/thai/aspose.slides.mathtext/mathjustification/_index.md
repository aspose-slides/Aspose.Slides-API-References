## MathJustification enumeration

กำหนดการจัดแนวของย่อหน้าคณิตศาสตร์ (ชุดของข้อความคณิตศาสตร์ที่ต่อเนื่องกันภายในย่อหน้าเดียวกัน)

ประเภท MathJustification แสดงสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| LEFT_JUSTIFIED | จัดตำแหน่งข้อความคณิตศาสตร์ทางซ้าย |
| RIGHT_JUSTIFIED | จัดตำแหน่งข้อความคณิตศาสตร์ทางขวา |
| CENTERED | จัดตำแหน่งข้อความคณิตศาสตร์กึ่งกลาง |
| CENTERED_AS_GROUP | จัดศูนย์บนหน้าให้กลุ่มบล็อกคณิตศาสตร์ทั้งหมดเป็นหน่วยเดียว.<br/>            ซึ่งหมายความว่าตัวอย่างของข้อความคณิตศาสตร์สามารถจัดแนวสัมพันธ์กันได้, <br/>            แต่กลุ่มข้อความคณิตศาสตร์ทั้งหมดจะถูกจัดศูนย์เป็นหนึ่งทั้งหมด. |
