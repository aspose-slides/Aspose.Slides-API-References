## explicit_break คุณสมบัติ
Explicit break ระบุว่ามีการตัดบรรทัดที่จุดเริ่มต้นของวัตถุ Box หรือไม่,
            โดยที่บรรทัดจะห่อหุ้มที่จุดเริ่มต้นของวัตถุ Box.
            ระบุจำนวนของตัวดำเนินการในบรรทัดก่อนหน้าของข้อความคณิตศาสตร์ที่
            ใช้เป็นจุดจัดแนวสำหรับบรรทัดปัจจุบันของข้อความคณิตศาสตร์
            ค่าที่เป็นไปได้: 1..255
            ค่าเริ่มต้น: 0 (ไม่มีการตัดบรรทัดอย่างชัดเจน)
