## การนับ MathNaryOperatorTypes enumeration

ตัวดำเนินการ Nary IMathNaryOperator types (ยกเว้น integrals)  
สำหรับการบูรณาการ [`MathIntegralTypes`](/slides/python-net/th/aspose.slides.mathtext/mathintegraltypes)

ประเภท MathNaryOperatorTypes เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| SUMMATION | การบวกผลรวม: '∑' |
| PRODUCT | ผลคูณ: '∏' |
| CO_PRODUCT | คูโพรดักต์: '∐' |
| INTERSECTION | การตัดกัน: '∩' |
| UNION | การรวม: '∪' |
| LOGICAL_AND | และตรรกะ: '∧' |
| LOGICAL_OR | หรือตรรกะ: '∨' |
