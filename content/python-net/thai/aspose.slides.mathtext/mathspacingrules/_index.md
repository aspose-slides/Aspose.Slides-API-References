## MathSpacingRules enum

ประเภทของช่องว่าง (การเว้นระยะแนวนอน) ระหว่างคอลัมน์ของเมทริกซ์

ประเภท MathSpacingRules เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| SINGLE_SPACING_GAP | แบบเดี่ยว (1 em สำหรับคอลัมน์หรือ 1 บรรทัดสำหรับแถว) |
| ONE_AND_HALF_SPACING_GAP | หนึ่งและครึ่ง (1.5 ems สำหรับคอลัมน์หรือ 1.5 บรรทัดสำหรับแถว) |
| DOUBLE_SPACING_GAP | ระยะห่างคู่ (2 ems สำหรับคอลัมน์หรือ 2 บรรทัดสำหรับแถว) |
| EXACTLY | ค่าที่แน่นอน<br/>            สำหรับคอลัมน์ ให้อิงค่าของ ColumnGap ที่วัดเป็น twips<br/>            สำหรับแถว ให้อิงค่าของ RowGap ที่วัดเป็น twips |
| MULTIPLE | หลายค่า<br/>            สำหรับคอลัมน์ ให้อิงค่ของ ColumnGap ที่วัดเป็นการเพิ่ม 0.5 em<br/>            สำหรับแถว ให้อิงค่าของ RowGap ที่วัดเป็นบรรทัด |
