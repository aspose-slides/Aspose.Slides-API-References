## IMathRightSubSuperscriptElement คลาส

ระบุอ็อบเจกต์ Sub-Superscript ซึ่งประกอบด้วยฐานและตัวห้อยและตัวยกที่วางทางด้านขวาของฐาน

ประเภท IMathRightSubSuperscriptElement แสดงสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`base`](/slides/python-net/th/aspose.slides.mathtext/imathrightsubsuperscriptelement/base/) | อาร์กิวเมนต์ฐาน |
| [`subscript`](/slides/python-net/th/aspose.slides.mathtext/imathrightsubsuperscriptelement/subscript/) | อาร์กิวเมนต์ตัวห้อย |
| [`superscript`](/slides/python-net/th/aspose.slides.mathtext/imathrightsubsuperscriptelement/superscript/) | อาร์กิวเมนต์ตัวยก |
| [`align_scripts`](/slides/python-net/th/aspose.slides.mathtext/imathrightsubsuperscriptelement/align_scripts/) | ระบุการจัดแนวของตัวห้อย/ตัวยก.<br/>            เมื่อเป็น true, ตัวห้อยและตัวยกจะจัดแนวในแนวนอนต่อกัน.<br/>            เมื่อเป็น false, จะปรับตำแหน่งตามรูปร่างของฐาน.<br/>            ค่าเริ่มต้นคือ false. |
