## IColorChangeEffectiveData คลาส

อ็อบเจ็กต์ที่ไม่เปลี่ยนแปลงซึ่งเป็นตัวแทนของเอฟเฟกต์การเปลี่ยนสี  
อินสแตนซ์ของ FromColor จะถูกแทนที่ด้วยอินสแตนซ์ของ ToColor

ประเภท IColorChangeEffectiveData เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`from_color`](/slides/python-net/th/aspose.slides.effects/icolorchangeeffectivedata/from_color/) | สีที่จะแทนที่<br/>            อ่านอย่างเดียว [`Color`](/slides/python-net/th/aspose.slides/color). |
| [`to_color`](/slides/python-net/th/aspose.slides.effects/icolorchangeeffectivedata/to_color/) | สีที่จะมาแทนที่<br/>            อ่านอย่างเดียว [`Color`](/slides/python-net/th/aspose.slides/color). |
| [`use_alpha`](/slides/python-net/th/aspose.slides.effects/icolorchangeeffectivedata/use_alpha/) | ส่งคืนค่า boolean ที่กำหนดว่าควรใช้ส่วนประกอบ alpha หรือไม่<br/>            อ่านอย่างเดียว **bool**. |
