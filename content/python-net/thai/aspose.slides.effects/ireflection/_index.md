## IReflection คลาส

เป็นการแสดงถึงเอฟเฟกต์การสะท้อน.

ชนิด IReflection ให้การเข้าถึงสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/th/aspose.slides.effects/ireflection/start_pos_alpha/) | ระบุตำแหน่งเริ่มต้น (ตามระดับสีกราดิเอนท์อัลฟ่า) ของค่าอัลฟ่าเริ่มต้น (เปอร์เซ็นต์).<br/>            อ่าน/เขียน **float**. |
| [`end_pos_alpha`](/slides/python-net/th/aspose.slides.effects/ireflection/end_pos_alpha/) | ระบุตำแหน่งสิ้นสุด (ตามระดับสีกราดิเอนท์อัลฟ่า) ของค่าอัลฟ่าสิ้นสุด (เปอร์เซ็นต์).<br/>            อ่าน/เขียน **float**. |
| [`fade_direction`](/slides/python-net/th/aspose.slides.effects/ireflection/fade_direction/) | ระบุทิศทางเพื่อเลื่อนการสะท้อน (องศา).<br/>            อ่าน/เขียน **float**. |
| [`start_reflection_opacity`](/slides/python-net/th/aspose.slides.effects/ireflection/start_reflection_opacity/) | ความทึบเริ่มต้นของการสะท้อน (เปอร์เซ็นต์).<br/>            อ่าน/เขียน **float**. |
| [`end_reflection_opacity`](/slides/python-net/th/aspose.slides.effects/ireflection/end_reflection_opacity/) | ความทึบสุดท้ายของการสะท้อน (เปอร์เซ็นต์).<br/>            อ่าน/เขียน **float**. |
| [`blur_radius`](/slides/python-net/th/aspose.slides.effects/ireflection/blur_radius/) | รัศมีการเบลอ.<br/>            อ่าน/เขียน **float**. |
| [`direction`](/slides/python-net/th/aspose.slides.effects/ireflection/direction/) | ทิศทางของการสะท้อน.<br/>            อ่าน/เขียน **float**. |
| [`distance`](/slides/python-net/th/aspose.slides.effects/ireflection/distance/) | ระยะของการสะท้อน.<br/>            อ่าน/เขียน **float**. |
| [`rectangle_align`](/slides/python-net/th/aspose.slides.effects/ireflection/rectangle_align/) | การจัดตำแหน่งสี่เหลี่ยม.<br/>            อ่าน/เขียน [`RectangleAlignment`](/slides/python-net/th/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/th/aspose.slides.effects/ireflection/skew_horizontal/) | ระบุมุมบิดแนวนอน.<br/>            อ่าน/เขียน **float**. |
| [`skew_vertical`](/slides/python-net/th/aspose.slides.effects/ireflection/skew_vertical/) | ระบุมุมบิดแนวตั้ง.<br/>            อ่าน/เขียน **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/th/aspose.slides.effects/ireflection/rotate_shadow_with_shape/) | ระบุว่าการสะท้อนควรหมุนพร้อมกับรูปทรงหรือไม่ หากรูปทรงถูกหมุน.<br/>            อ่าน/เขียน **bool**. |
| [`scale_horizontal`](/slides/python-net/th/aspose.slides.effects/ireflection/scale_horizontal/) | ระบุปัจจัยการสเกลแนวนอน, การสเกลเชิงลบทำให้พลิก (เปอร์เซ็นต์)<br/>            อ่าน/เขียน **float**. |
| [`scale_vertical`](/slides/python-net/th/aspose.slides.effects/ireflection/scale_vertical/) | ระบุปัจจัยการสเกลแนวตั้ง, การสเกลเชิงลบทำให้พลิก (เปอร์เซ็นต์)<br/>            อ่าน/เขียน **float**. |
