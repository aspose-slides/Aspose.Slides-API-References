## OuterShadow คลาส

แสดงถึงเอฟเฟกต์เงานอก

ประเภท OuterShadow ทำให้สามารถเข้าถึงสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`blur_radius`](/slides/python-net/th/aspose.slides.effects/outershadow/blur_radius/) | รัศมีเบลอร์, หน่วยเป็นจุด.<br/>            ค่าเริ่มต้น – 0 pt.<br/>            อ่าน/เขียน **float**. |
| [`direction`](/slides/python-net/th/aspose.slides.effects/outershadow/direction/) | ทิศทางของเงา, หน่วยเป็นองศ.<br/>            ค่าเริ่มต้น – 0 ° (ซ้ายไปขวา).<br/>            อ่าน/เขียน **float**. |
| [`distance`](/slides/python-net/th/aspose.slides.effects/outershadow/distance/) | ระยะห่างของเงาจากวัตถุ, หน่วยเป็นจุด.<br/>            ค่าเริ่มต้น – 0 pt.<br/>            อ่าน/เขียน **float**. |
| [`shadow_color`](/slides/python-net/th/aspose.slides.effects/outershadow/shadow_color/) | สีของเงา.<br/>            ค่าเริ่มต้น – สีดำอัตโนมัติ (ขึ้นกับธีม).<br/>            อ่านอย่างเดียว [`IColorFormat`](/slides/python-net/th/aspose.slides/icolorformat). |
| [`rectangle_align`](/slides/python-net/th/aspose.slides.effects/outershadow/rectangle_align/) | การจัดแนวสี่เหลี่ยม.<br/>            ค่าเริ่มต้น – [`RectangleAlignment.BOTTOM`](/slides/python-net/th/aspose.slides/rectanglealignment/BOTTOM). <br/>            อ่าน/เขียน [`RectangleAlignment`](/slides/python-net/th/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/th/aspose.slides.effects/outershadow/skew_horizontal/) | มุมเอียงแนวนอน, หน่วยเป็นองศ.<br/>            ค่าเริ่มต้น – 0 °.<br/>            อ่าน/เขียน **float**. |
| [`skew_vertical`](/slides/python-net/th/aspose.slides.effects/outershadow/skew_vertical/) | มุมเอียงแนวตั้ง, หน่วยเป็นองศ.<br/>            ค่าเริ่มต้น – 0 °.<br/>            อ่าน/เขียน **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/th/aspose.slides.effects/outershadow/rotate_shadow_with_shape/) | ระบุว่าเงาจะหมุนพร้อมกับรูปร่างหรือไม่.<br/>            ค่าเริ่มต้น – true.<br/>            อ่าน/เขียน **bool**. |
| [`scale_horizontal`](/slides/python-net/th/aspose.slides.effects/outershadow/scale_horizontal/) | ปัจจัยการสเกลแนวนอน, เป็นเปอร์เซ็นต์ของขนาดเดิม.<br/>            การสเกลเชิงลบทำให้พลิกกลับ.<br/>            ค่าเริ่มต้น – 100 %.<br/>            อ่าน/เขียน **float**. |
| [`scale_vertical`](/slides/python-net/th/aspose.slides.effects/outershadow/scale_vertical/) | ปัจจัยการสเกลแนวตั้ง, เป็นเปอร์เซ็นต์ของขนาดเดิม.<br/>            การสเกลเชิงลบทำให้พลิกกลับ.<br/>           ค่าเริ่มต้น – 100 %.<br/>            อ่าน/เขียน **float**. |
