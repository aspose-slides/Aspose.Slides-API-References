## Reflection คลาส

แสดงถึงเอฟเฟกต์ Reflection.

ประเภท Reflection เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/th/aspose.slides.effects/reflection/start_pos_alpha/) | ระบุตำแหน่งเริ่มต้น (ตามแนวลาดของเกรเดียนท์อัลฟา) ของค่าอัลฟาเริ่มต้น (เปอร์เซ็นต์).<br/>            อ่าน/เขียน **float**. |
| [`end_pos_alpha`](/slides/python-net/th/aspose.slides.effects/reflection/end_pos_alpha/) | ระบุตำแหน่งสุดท้าย (ตามแนวลาดของเกรเดียนท์อัลฟา) ของค่าอัลฟาสุดท้าย (เปอร์เซ็นต์).<br/>            อ่าน/เขียน **float**. |
| [`fade_direction`](/slides/python-net/th/aspose.slides.effects/reflection/fade_direction/) | ระบุทิศทางในการเยื้องการสะท้อน (มุม).<br/>            อ่าน/เขียน **float**. |
| [`start_reflection_opacity`](/slides/python-net/th/aspose.slides.effects/reflection/start_reflection_opacity/) | ความทึบของการสะท้อนเริ่มต้น (เปอร์เซ็นต์).<br/>            อ่าน/เขียน **float**. |
| [`end_reflection_opacity`](/slides/python-net/th/aspose.slides.effects/reflection/end_reflection_opacity/) | ความทึบของการสะท้อนสุดท้าย (เปอร์เซ็นต์).<br/>            อ่าน/เขียน **float**. |
| [`blur_radius`](/slides/python-net/th/aspose.slides.effects/reflection/blur_radius/) | รัศมีการเบลอ.<br/>            อ่าน/เขียน **float**. |
| [`direction`](/slides/python-net/th/aspose.slides.effects/reflection/direction/) | ทิศทางของการสะท้อน.<br/>            อ่าน/เขียน **float**. |
| [`distance`](/slides/python-net/th/aspose.slides.effects/reflection/distance/) | ระยะของการสะท้อน.<br/>            อ่าน/เขียน **float**. |
| [`rectangle_align`](/slides/python-net/th/aspose.slides.effects/reflection/rectangle_align/) | การจัดแนวสี่เหลี่ยม.<br/>            อ่าน/เขียน [`RectangleAlignment`](/slides/python-net/th/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/th/aspose.slides.effects/reflection/skew_horizontal/) | ระบุมุมบิดตามแนวนอน.<br/>            อ่าน/เขียน **float**. |
| [`skew_vertical`](/slides/python-net/th/aspose.slides.effects/reflection/skew_vertical/) | ระบุมุมบิดตามแนวตั้ง.<br/>            อ่าน/เขียน **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/th/aspose.slides.effects/reflection/rotate_shadow_with_shape/) | ระบุว่าการสะท้อนควรหมุนพร้อมกับรูปทรงหรือไม่ หากรูปทรงถูกหมุน.<br/>            อ่าน/เขียน **bool**. |
| [`scale_horizontal`](/slides/python-net/th/aspose.slides.effects/reflection/scale_horizontal/) | ระบุปัจจัยการสเกลตามแนวนอน, การสเกลเป็นค่าลบจะทำให้พลิก (เปอร์เซ็นต์)<br/>            อ่าน/เขียน **float**. |
| [`scale_vertical`](/slides/python-net/th/aspose.slides.effects/reflection/scale_vertical/) | ระบุปัจจัยการสเกลตามแนวตั้ง, การสเกลเป็นค่าลบจะทำให้พลิก (เปอร์เซ็นต์)<br/>            อ่าน/เขียน **float**. |
