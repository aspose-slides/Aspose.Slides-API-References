## IOuterShadow คลาส

เป็นตัวแทนของเอฟเฟกต์เงานอก

ประเภท IOuterShadow เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`blur_radius`](/slides/python-net/th/aspose.slides.effects/ioutershadow/blur_radius/) | รัศมีการเบลอ, หน่วยเป็นจุด.<br/>            ค่าเริ่มต้น – 0 pt.<br/>            อ่าน/เขียน **float**. |
| [`direction`](/slides/python-net/th/aspose.slides.effects/ioutershadow/direction/) | ทิศทางของเงา, หน่วยเป็นองศา.<br/>            ค่าเริ่มต้น – 0 ° (จากซ้ายไปขวา).<br/>            อ่าน/เขียน **float**. |
| [`distance`](/slides/python-net/th/aspose.slides.effects/ioutershadow/distance/) | ระยะของเงาจากวัตถุ, หน่วยเป็นจุด.<br/>            ค่าเริ่มต้น – 0 pt.<br/>            อ่าน/เขียน **float**. |
| [`shadow_color`](/slides/python-net/th/aspose.slides.effects/ioutershadow/shadow_color/) | สีของเงา.<br/>            ค่าเริ่มต้น – สีดำอัตโนมัติ (ขึ้นอยู่กับธีม).<br/>            อ่านเท่านั้น [`IColorFormat`](/slides/python-net/th/aspose.slides/icolorformat). |
| [`rectangle_align`](/slides/python-net/th/aspose.slides.effects/ioutershadow/rectangle_align/) | การจัดตำแหน่งสี่เหลี่ยม.<br/>            ค่าเริ่มต้น – [`RectangleAlignment.BOTTOM`](/slides/python-net/th/aspose.slides/rectanglealignment/BOTTOM). <br/>            อ่าน/เขียน [`RectangleAlignment`](/slides/python-net/th/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/th/aspose.slides.effects/ioutershadow/skew_horizontal/) | มุมเอียงแนวนอน, หน่วยเป็นองศา.<br/>            ค่าเริ่มต้น – 0 °.<br/>            อ่าน/เขียน **float**. |
| [`skew_vertical`](/slides/python-net/th/aspose.slides.effects/ioutershadow/skew_vertical/) | มุมเอียงแนวตั้ง, หน่วยเป็นองศา.<br/>            ค่าเริ่มต้น – 0 °.<br/>            อ่าน/เขียน **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/th/aspose.slides.effects/ioutershadow/rotate_shadow_with_shape/) | ระบุว่าเงาจะหมุนพร้อมกับรูปร่างหรือไม่.<br/>            ค่าเริ่มต้น – true.<br/>            อ่าน/เขียน **bool**. |
| [`scale_horizontal`](/slides/python-net/th/aspose.slides.effects/ioutershadow/scale_horizontal/) | ตัวคูณการย่อขยายแนวนอน, เป็นเปอร์เซ็นต์ของขนาดต้นฉบับ.<br/>            การสเกลเป็นค่าติดลบทำให้เกิดการพลิก.<br/>            ค่าเริ่มต้น – 100 %.<br/>            อ่าน/เขียน **float**. |
| [`scale_vertical`](/slides/python-net/th/aspose.slides.effects/ioutershadow/scale_vertical/) | ตัวคูณการย่อขยายแนวตั้ง, เป็นเปอร์เซ็นต์ของขนาดต้นฉบับ.<br/>            การสเกลเป็นค่าติดลบทำให้เกิดการพลิก.<br/>            ค่าเริ่มต้น – 100 %.<br/>            อ่าน/เขียน **float**. |
