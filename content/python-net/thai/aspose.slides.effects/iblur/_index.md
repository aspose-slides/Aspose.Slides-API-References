## IBlur คลาส

แสดงถึงเอฟเฟ็กต์ Blur ที่ถูกใช้กับรูปทรงทั้งหมด รวมถึงการเติมสีของมัน ทั้งช่องสีทั้งหมดรวมถึงอัลฟ่าได้รับผลกระทบ

ประเภท IBlur มีสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`radius`](/slides/python-net/th/aspose.slides.effects/iblur/radius/) | คืนค่า หรือ ตั้งค่ารัศมีเบลอ.<br/>            อ่าน/เขียน **float**. |
| [`grow`](/slides/python-net/th/aspose.slides.effects/iblur/grow/) | กำหนดว่าขอบเขตของวัตถุควรขยายเป็นผลมาจากการเบลอหรือไม่.<br/>            True แสดงว่าขอบเขตขยายในขณะที่ false แสดงว่าไม่ขยาย.<br/>            อ่าน/เขียน **bool**. |
