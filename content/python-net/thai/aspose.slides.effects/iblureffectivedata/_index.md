## IBlurEffectiveData คลาส

วัตถุไม่เปลี่ยนแปลงซึ่งแสดงถึงเอฟเฟ็กต์ Blur ที่ถูกนำไปใช้กับรูปทรงทั้งหมดรวมถึงการเติมสีของมัน
            ทุกช่องสีรวมถึงอัลฟ่าถูกส่งผลกระทบ

I BlurEffectiveData type เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`radius`](/slides/python-net/th/aspose.slides.effects/iblureffectivedata/radius/) | Returns or sets blur radius.<br/>            อ่านอย่างเดียว **float**. |
| [`grow`](/slides/python-net/th/aspose.slides.effects/iblureffectivedata/grow/) | Determines whether the bounds of the object should be grown as a result of the blurring.<br/>            True indicates the bounds are grown while false indicates that they are not.<br/>            อ่านอย่างเดียว **bool**. |
