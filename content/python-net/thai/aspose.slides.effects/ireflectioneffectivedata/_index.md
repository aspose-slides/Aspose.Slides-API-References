## IReflectionEffectiveData คลาส

อ็อบเจ็กต์ที่ไม่สามารถแก้ไขได้ซึ่งเป็นตัวแทนของเอฟเฟกต์ Reflection.

ประเภท IReflectionEffectiveData เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/th/aspose.slides.effects/ireflectioneffectivedata/start_pos_alpha/) | ระบุตำแหน่งเริ่มต้น (ตามระดับความลาดสี alpha) ของค่าอัลฟาเริ่มต้น (เปอร์เซ็นต์).<br/>            Read-only **float**. |
| [`end_pos_alpha`](/slides/python-net/th/aspose.slides.effects/ireflectioneffectivedata/end_pos_alpha/) | ระบุตำแหน่งสุดท้าย (ตามระดับความลาดสี alpha) ของค่าอัลฟาสุดท้าย (เปอร์เซ็นต์).<br/>            Read-only **float**. |
| [`fade_direction`](/slides/python-net/th/aspose.slides.effects/ireflectioneffectivedata/fade_direction/) | ระบุทิศทางเพื่อชดเชยการสะท้อน (มุม).<br/>            Read-only **float**. |
