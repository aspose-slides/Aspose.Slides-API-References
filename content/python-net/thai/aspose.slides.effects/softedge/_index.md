## SoftEdge คลาส

แสดงถึงเอฟเฟกต์ขอบแบบนุ่ม. 
            ขอบของรูปทรงจะเบลอขณะที่การเติมสีไม่ได้รับผลกระทบ.

ประเภท SoftEdge เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`radius`](/slides/python-net/th/aspose.slides.effects/softedge/radius/) | ระบุรัศมีของการเบลอที่จะใช้กับขอบ.<br/>            อ่าน/เขียน **float**. |

## เมธอด

| Method | Description |
| :- | :- |
| [`get_effective(self)`](/slides/python-net/th/aspose.slides.effects/softedge/get_effective/#) | ดึงข้อมูลเอฟเฟกต์ Soft Edge ที่มีผลกับการสืบทอดที่ถูกนำไปใช้. |
