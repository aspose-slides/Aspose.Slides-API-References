## GradientDirection การกำหนดค่า

ชนิด GradientDirection เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| NOT_DEFINED | ไม่ได้กำหนด |
| FROM_CORNER1 | จากมุมบนซ้าย |
| FROM_CORNER2 | จากมุมบนขวา |
| FROM_CORNER3 | จากมุมล่างซ้าย |
| FROM_CORNER4 | จากมุมล่างขวา |
| FROM_CENTER | จากศูนย์กลาง |
