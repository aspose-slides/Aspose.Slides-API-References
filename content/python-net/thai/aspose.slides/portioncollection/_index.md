## PortionCollection คลาส

แทนที่คอลเลกชันของ portion

PortionCollection type เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`count`](/slides/python-net/th/aspose.slides/portioncollection/count/) | ดึงจำนวนขององค์ประกอบที่อยู่จริงในคอลเลกชัน<br/>            อ่านอย่างเดียว **int**. |
| [`is_read_only`](/slides/python-net/th/aspose.slides/portioncollection/is_read_only/) | ดึงค่าแสดงว่าหรือไม่ที่ **System.Collections.Generic.ICollection`1** เป็นแบบอ่านอย่างเดียว<br/>            อ่านอย่างเดียว **bool**. |
