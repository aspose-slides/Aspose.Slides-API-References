## add_clone(self, source_layout) {#ilayoutslide}

### คืนค่า

```python
def add_clone(self, source_layout):
    ...
```

### หมายเหตุ

1) รูปแบบใหม่จะเชื่อมโยงกับสไลด์มาสเตอร์หลักสำหรับคอลเลกชันสไลด์รูปแบบนี้. ดังนั้นจึงเป็นการทำงานคล้ายการคัดลอก/วางพร้อมตัวเลือก "Use Destination Theme" ใน PowerPoint.
2) คล้ายกับเมธอดนี้คือเมธอด **Aspose.Slides.IGlobalLayoutSlideCollection.AddClone(Aspose.Slides.ILayoutSlide,Aspose.Slide** ที่เข้าถึงได้ด้วย [`IPresentation.layout_slides`](/slides/python-net/th/aspose.slides/ipresentation/layout_slides) คุณสมบัติ
