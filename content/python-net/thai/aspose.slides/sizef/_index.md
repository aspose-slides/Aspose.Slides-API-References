## SizeF คลาส

เก็บคู่ค่าตัวเลขจุดลอยเรียงลำดับ, ซึ่งโดยทั่วไปเป็นความกว้างและความสูงของสี่เหลี่ยม. รองรับ .NET `System.Drawing.SizeF`.

ประเภท SizeF เปิดเผยสมาชิกต่อไปนี้:

| :- | :- |
| [`__init__(self, width=0.0, height=0.0)`](/slides/python-net/th/aspose.slides/sizef/__init__/#float-float) | สร้างขนาดด้วยความกว้างและความสูงที่ระบุ. |

## คุณสมบัติ

| Property | คำอธิบาย |
| :- | :- |
| [`width`](/slides/python-net/th/aspose.slides/sizef/width/) | รับส่วนประกอบแนวนอนของขนาดนี้.<br/>            อ่านอย่างเดียว **float**. |
| [`height`](/slides/python-net/th/aspose.slides/sizef/height/) | รับส่วนประกอบแนวตั้งของขนาดนี้.<br/>            อ่านอย่างเดียว **float**. |
