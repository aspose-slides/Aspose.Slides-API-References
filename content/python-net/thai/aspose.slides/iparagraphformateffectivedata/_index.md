## IParagraphFormatEffectiveData คลาส

อ็อบเจ็กต์ที่ไม่เปลี่ยนแปลงซึ่งประกอบด้วยคุณสมบัติการจัดรูปแบบย่อหน้าที่มีผล

ประเภท IParagraphFormatEffectiveData เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`bullet`](/slides/python-net/th/aspose.slides/iparagraphformateffectivedata/bullet/) | ส่งคืนรูปแบบสัญลักษณ์หัวข้อของย่อหน้า.<br/>อ่านอย่างเดียว [`IBulletFormatEffectiveData`](/slides/python-net/th/aspose.slides/ibulletformateffectivedata). |
| [`depth`](/slides/python-net/th/aspose.slides/iparagraphformateffectivedata/depth/) | ส่งคืนความลึกของย่อหน้า.<br/>อ่านอย่างเดียว **int**. |
| [`alignment`](/slides/python-net/th/aspose.slides/iparagraphformateffectivedata/alignment/) | ส่งคืนการจัดตำแหน่งข้อความในย่อหน้า.<br/>อ่านอย่างเดียว [`TextAlignment`](/slides/python-net/th/aspose.slides/textalignment). |
| [`space_within`](/slides/python-net/th/aspose.slides/iparagraphformateffectivedata/space_within/) | ส่งคืนปริมาณการเว้นระยะระหว่างบรรทัดฐานในย่อหน้า.<br/>อ่านอย่างเดียว **float**. |

| [`latin_line_break`](/slides/python-net/th/aspose.slides/iparagraphformateffectivedata/latin_line_break/) | กำหนดว่าจะใช้การขึ้นบรรทัดแบบละตินในย่อหน้าหรือไม่.<br/>อ่านอย่างเดียว **bool**. |
| [`hanging_punctuation`](/slides/python-net/th/aspose.slides/iparagraphformateffectivedata/hanging_punctuation/) | กำหนดว่าจะใช้เครื่องหมายวรรคตอนห้อยในย่อหน้าหรือไม่.<br/>อ่านอย่างเดียว **bool**. |
| [`margin_left`](/slides/python-net/th/aspose.slides/iparagraphformateffectivedata/margin_left/) | ส่งคืนระยะขอบซ้ายในย่อหน้า.<br/>อ่านอย่างเดียว **float**. |
| [`margin_right`](/slides/python-net/th/aspose.slides/iparagraphformateffectivedata/margin_right/) | ส่งคืนระยะขอบขวาในย่อหน้า.<br/>อ่านอย่างเดียว **float**. |
