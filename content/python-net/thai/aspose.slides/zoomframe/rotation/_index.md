## rotation property
Returns or sets the number of degrees the specified shape is rotated around
            แกน z. ค่าบวกบ่งชี้การหมุนตามเข็มนาฬิกา; ค่าลบบ่งชี้การหมุนทวนเข็มนาฬิกา
            บ่งชี้การหมุนทวนเข็มนาฬิกา
            อ่าน/เขียน **float**.


### หมายเหตุ

ค่าที่ส่งกลับจะถูกกำหนดเสมอ (is not float.NaN).
            ค่าที่กำหนดต้องถูกกำหนด (not float.NaN). You can set undefined values for RawFrame instance properties.
