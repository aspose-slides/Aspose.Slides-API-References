## equals(self, slide) {#ibaseslide}
กำหนดว่าตัวอย่างสองอ็อบเจกต์ของ IBaseSlide เท่ากันหรือไม่  
ค่าที่ส่งคืนคำนวณจากโครงสร้างของสไลด์และเนื้อหาคงที่  
สไลด์สองชิ้นเท่ากันหากรูปทรง, สไตล์, ข้อความ, แอนิเมชัน และการตั้งค่าอื่น ๆ ฯลฯ ทั้งหมดเท่ากัน การเปรียบเทียบไม่พิจารณาค่าตัวระบุที่เป็นเอกลักษณ์ เช่น SlideId และเนื้อหาแบบไดนามิก เช่น ค่ารูปแบบวันที่ปัจจุบันใน Date Placeholder

### ค่าที่ส่งคืน

**true** หาก IBaseSlide ที่ระบุเท่ากับ IBaseSlide ปัจจุบัน; มิฉะนั้น **false** .

```python
def equals(self, slide):
    ...
```
