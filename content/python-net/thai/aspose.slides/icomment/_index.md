## IComment คลาส

เป็นตัวแทนของความคิดเห็นบนสไลด์

ประเภท IComment เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | คำอธิบาย |
| :- | :- |
| [`text`](/slides/python-net/th/aspose.slides/icomment/text/) | คืนค่า หรือกำหนดข้อความธรรมดาของความคิดเห็นบนสไลด์.<br/>            อ่าน/เขียน **str**. |
| [`created_time`](/slides/python-net/th/aspose.slides/icomment/created_time/) | คืนค่า หรือกำหนดเวลาการสร้างความคิดเห็น.<br/>            การตั้งค่าสมบัตินี้เป็น **System.DateTime** หมายความว่าไม่มีการตั้งค่าเวลาให้กับความคิดเห็น.<br/>            อ่าน/เขียน **System.DateTime**. |
| [`slide`](/slides/python-net/th/aspose.slides/icomment/slide/) | คืนค่า หรือกำหนดสไลด์พาเรนท์ของความคิดเห็น.<br/>            อ่านอย่างเดียว [`ISlide`](/slides/python-net/th/aspose.slides/islide). |
| [`author`](/slides/python-net/th/aspose.slides/icomment/author/) | คืนค่าผู้เขียนของความคิดเห็น.<br/>            อ่านอย่างเดียว [`ICommentAuthor`](/slides/python-net/th/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/th/aspose.slides/icomment/position/) | คืนค่า หรือกำหนดตำแหน่งของความคิดเห็นบนสไลด์.<br/>            อ่าน/เขียน [`PointF`](/slides/python-net/th/aspose.slides/pointf). |
| [`parent_comment`](/slides/python-net/th/aspose.slides/icomment/parent_comment/) | รับหรือกำหนดความคิดเห็นพาเรนท์.<br/>            อ่าน/เขียน [`IComment`](/slides/python-net/th/aspose.slides/icomment). |
