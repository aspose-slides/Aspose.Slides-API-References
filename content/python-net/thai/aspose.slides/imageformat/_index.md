## ImageFormat enumeration

แสดงถึงรูปแบบไฟล์ของรูปภาพ

ประเภท ImageFormat แสดงสมาชิกต่อไปนี้:

## ฟิลด์

| Field | Description |
| :- | :- |
| MEMORY_BMP | แสดงรูปแบบของบิตแมพในหน่วยความจำ |
| BMP | แสดงรูปแบบภาพบิตแมพ (BMP) |
| EMF | แสดงรูปแบบภาพเมทะไฟล์ขั้นสูง (EMF) |
| WMF | แสดงรูปแบบภาพเมทะไฟล์ของ Windows (WMF) |
| GIF | แสดงรูปแบบภาพ Graphics Interchange Format (GIF) |
| JPEG | แสดงรูปแบบภาพ Joint Photographic Experts Group (JPEG) |
| PNG | แสดงรูปแบบภาพ W3C Portable Network Graphics (PNG) |
| TIFF | แสดงรูปแบบภาพ Tagged Image File Format (TIFF) |
| EXIF | แสดงรูปแบบ Exchangeable Image File (Exif) |
| ICON | แสดงรูปแบบภาพไอคอนของ Windows |
