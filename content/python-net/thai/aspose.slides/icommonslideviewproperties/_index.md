## ICommonSlideViewProperties คลาส

แสดงคุณสมบัติมุมมองสไลด์ที่ใช้ร่วมกัน.

ประเภท ICommonSlideViewProperties เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`scale`](/slides/python-net/th/aspose.slides/icommonslideviewproperties/scale/) | ระบุอัตราการขยายมุมมองเป็นเปอร์เซ็นต์.<br/>            อ่าน/เขียน **int**. |
| [`variable_scale`](/slides/python-net/th/aspose.slides/icommonslideviewproperties/variable_scale/) | ระบุว่าข้อมูลมุมมองควรปรับขนาดอัตโนมัติเพื่อให้พอดีกับขนาดหน้าต่างปัจจุบันที่สุด.<br/>            อ่าน/เขียน **bool**. |
| [`drawing_guides`](/slides/python-net/th/aspose.slides/icommonslideviewproperties/drawing_guides/) | คืนค่าชุดของแนวทางการวาด.<br/>            อ่านอย่างเดียว [`IDrawingGuidesCollection`](/slides/python-net/th/aspose.slides/idrawingguidescollection) |
