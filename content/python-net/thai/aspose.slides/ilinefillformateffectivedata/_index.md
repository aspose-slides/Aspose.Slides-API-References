## ILineFillFormatEffectiveData คลาส

อ็อบเจ็กต์ที่ไม่สามารถแก้ไขได้ซึ่งบรรจุคุณสมบัติการเติมเส้นที่มีผล

ประเภท ILineFillFormatEffectiveData เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`fill_type`](/slides/python-net/th/aspose.slides/ilinefillformateffectivedata/fill_type/) | ส่งคืนประเภทการเติม.<br/>            อ่านได้อย่างเดียว [`FillType`](/slides/python-net/th/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/th/aspose.slides/ilinefillformateffectivedata/solid_fill_color/) | ส่งคืนสีของการเติมแบบทึบ.<br/>            อ่านได้อย่างเดียว **aspose.slides.Color**. |
| [`gradient_format`](/slides/python-net/th/aspose.slides/ilinefillformateffectivedata/gradient_format/) | ส่งคืนฟอร์แมตการเติมแบบไล่สี.<br/>            อ่านได้อย่างเดียว [`IGradientFormatEffectiveData`](/slides/python-net/th/aspose.slides/igradientformateffectivedata). |
| [`pattern_format`](/slides/python-net/th/aspose.slides/ilinefillformateffectivedata/pattern_format/) | ส่งคืนฟอร์แมตการเติมแบบลวดลาย.<br/>            อ่านได้อย่างเดียว [`IPatternFormatEffectiveData`](/slides/python-net/th/aspose.slides/ipatternformateffectivedata). |
| [`rotate_with_shape`](/slides/python-net/th/aspose.slides/ilinefillformateffectivedata/rotate_with_shape/) | กำหนดว่าการเติมควรหมุนตามรูปร่างหรือไม่.<br/>            อ่านได้อย่างเดียว **bool**. |
