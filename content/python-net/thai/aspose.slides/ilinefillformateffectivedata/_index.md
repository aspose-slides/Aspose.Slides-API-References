## ILineFillFormatEffectiveData คลาส

อ็อบเจกต์แบบคงที่ซึ่งมีคุณสมบัติการเติมเส้นที่มีผล

The ILineFillFormatEffectiveData type เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`fill_type`](/slides/python-net/th/aspose.slides/ilinefillformateffectivedata/fill_type/) | คืนค่าประเภทการเติม.<br/>            อ่านอย่างเดียว [`FillType`](/slides/python-net/th/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/th/aspose.slides/ilinefillformateffectivedata/solid_fill_color/) | คืนค่าสีของการเติมแบบทึบ.<br/>            อ่านอย่างเดียว [`Color`](/slides/python-net/th/aspose.slides/color). |
| [`gradient_format`](/slides/python-net/th/aspose.slides/ilinefillformateffectivedata/gradient_format/) | คืนค่าแบบการเติมแบบไล่เฉดสี.<br/>            อ่านอย่างเดียว [`IGradientFormatEffectiveData`](/slides/python-net/th/aspose.slides/igradientformateffectivedata). |
| [`pattern_format`](/slides/python-net/th/aspose.slides/ilinefillformateffectivedata/pattern_format/) | คืนค่าแบบการเติมแบบลาย.<br/>            อ่านอย่างเดียว [`IPatternFormatEffectiveData`](/slides/python-net/th/aspose.slides/ipatternformateffectivedata). |
| [`rotate_with_shape`](/slides/python-net/th/aspose.slides/ilinefillformateffectivedata/rotate_with_shape/) | กำหนดว่าการเติมควรหมุนตามรูปร่างหรือไม่.<br/>            อ่านอย่างเดียว **bool**. |
