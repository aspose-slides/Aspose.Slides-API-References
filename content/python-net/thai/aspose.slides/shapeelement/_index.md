## ShapeElement คลาส

เป็นการแทนส่วนของรูปร่างที่มีคุณสมบัติเขียนขอบและเติมสีเดียวกัน

The ShapeElement type เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`parent_shape`](/slides/python-net/th/aspose.slides/shapeelement/parent_shape/) | ส่งคืน Shape_PPT ที่สร้างองค์ประกอบนี้ขึ้น.<br/>            อ่านอย่างเดียว [`Shape`](/slides/python-net/th/aspose.slides/shape). |
| [`path_points`](/slides/python-net/th/aspose.slides/shapeelement/path_points/) | รับอาร์เรย์ของจุดที่กำหนดรูปทรงเรขาคณิตของเส้นทางขององค์ประกอบ. |
| [`path_types`](/slides/python-net/th/aspose.slides/shapeelement/path_types/) | รับอาร์เรย์ของค่าไบต์ที่ระบุประเภทของแต่ละจุดในเส้นทางขององค์ประกอบ. <br/>            <br/>**0**  ระบุว่าจุดนี้เป็นจุดเริ่มต้นของรูป.<br/><br/><br/>**1**  ระบุว่าจุดนี้เป็นหนึ่งในสองจุดสิ้นสุดของเส้น.<br/><br/><br/>**3**  ระบุว่าจุดนี้เป็นจุดสิ้นสุดหรือจุดควบคุมของ cubic Bezier spline.<br/><br/><br/>**7**  ปิดบังทุกบิตยกเว้นบิตสามบิตต่ำสุดที่ระบุประเภทของจุด.<br/><br/><br/>**16**  ระบุว่าเซกเมนต์ที่สอดคล้องเป็นแบบเส้นประ.<br/><br/><br/>**32**  ระบุว่าจุดนี้เป็นเครื่องหมาย.<br/><br/><br/>**128**  ระบุว่าจุดนี้เป็นจุดสุดท้ายในเส้นทางย่อยที่ปิด (รูป).<br/><br/><br/>**129**  ระบุว่าจุดข้อมูลนี้เป็นทั้งจุดสิ้นสุดของเซกเมนต์เส้นและจุดสุดท้ายของเส้นทางย่อยที่ปิด. |
| [`fill_source`](/slides/python-net/th/aspose.slides/shapeelement/fill_source/) | ส่งคืนข้อมูลเกี่ยวกับวิธีการเติมสีให้กับองค์ประกอบ.<br/>            อ่านอย่างเดียว [`ShapeElementFillSource`](/slides/python-net/th/aspose.slides/shapeelementfillsource). |
| [`stroke_source`](/slides/python-net/th/aspose.slides/shapeelement/stroke_source/) | ส่งคืนข้อมูลเกี่ยวกับวิธีการวาดเส้นขอบให้กับองค์ประกอบ.<br/>            อ่านอย่างเดียว [`ShapeElementStrokeSource`](/slides/python-net/th/aspose.slides/shapeelementstrokesource). |
