## ITextFrameFormatEffectiveData คลาส

อ็อบเจ็กต์แบบไม่เปลี่ยนแปลงซึ่งมีคุณสมบัติการจัดรูปแบบกรอบข้อความที่มีผล

ประเภท ITextFrameFormatEffectiveData เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`text_style`](/slides/python-net/th/aspose.slides/itextframeformateffectivedata/text_style/) | ส่งคืนสไตล์ของข้อความที่มีผล.<br/>            อ่านอย่างเดียว [`ITextStyleEffectiveData`](/slides/python-net/th/aspose.slides/itextstyleeffectivedata). |
| [`margin_left`](/slides/python-net/th/aspose.slides/itextframeformateffectivedata/margin_left/) | ส่งคืนระยะขอบซ้าย (หน่วยจุด) ใน TextFrame.<br/>            อ่านอย่างเดียว **float**. |
| [`margin_right`](/slides/python-net/th/aspose.slides/itextframeformateffectivedata/margin_right/) | ส่งคืนระยะขอบขวา (หน่วยจุด) ใน TextFrame.<br/>            อ่านอย่างเดียว **float**. |
| [`margin_top`](/slides/python-net/th/aspose.slides/itextframeformateffectivedata/margin_top/) | ส่งคืนระยะขอบบน (หน่วยจุด) ใน TextFrame.<br/>            อ่านอย่างเดียว **float**. |
| [`margin_bottom`](/slides/python-net/th/aspose.slides/itextframeformateffectivedata/margin_bottom/) | ส่งคืนระยะขอบล่าง (หน่วยจุด) ใน TextFrame.<br/>            อ่านอย่างเดียว **float**. |
| [`wrap_text`](/slides/python-net/th/aspose.slides/itextframeformateffectivedata/wrap_text/) | ส่งคืนว่าข้อความถูกตัดคำที่ขอบของ TextFrame หรือไม่.<br/>            อ่านอย่างเดียว **bool**. |
| [`anchoring_type`](/slides/python-net/th/aspose.slides/itextframeformateffectivedata/anchoring_type/) | ส่งคืนการยึดแนวตั้งของข้อความใน TextFrame.<br/>            อ่านอย่างเดียว [`TextAnchorType`](/slides/python-net/th/aspose.slides/textanchortype). |
| [`center_text`](/slides/python-net/th/aspose.slides/itextframeformateffectivedata/center_text/) | ส่งคืนว่าข้อความควรอยู่กึ่งกลางในกล่องแนวนอนหรือไม่.<br/>            อ่านอย่างเดียว **bool**. |
| [`text_vertical_type`](/slides/python-net/th/aspose.slides/itextframeformateffectivedata/text_vertical_type/) | ส่งคืนการวางแนวของข้อความ.<br/>            อ่านอย่างเดียว [`TextVerticalType`](/slides/python-net/th/aspose.slides/textverticaltype). |
| [`autofit_type`](/slides/python-net/th/aspose.slides/itextframeformateffectivedata/autofit_type/) | ส่งคืนโหมดปรับขนาดอัตโนมัติของข้อความ.<br/>            อ่านอย่างเดียว [`TextAutofitType`](/slides/python-net/th/aspose.slides/textautofittype). |
| [`column_count`](/slides/python-net/th/aspose.slides/itextframeformateffectivedata/column_count/) | ระบุจำนวนคอลัมน์ของข้อความในสี่เหลี่ยมขอบ.<br/>            อ่านอย่างเดียว **int**. |
| [`column_spacing`](/slides/python-net/th/aspose.slides/itextframeformateffectivedata/column_spacing/) | ระยะห่างระหว่างคอลัมน์ของข้อความในพื้นที่ข้อความ (หน่วยจุด).<br/>            อ่านอย่างเดียว **float**. |
