## height คุณสมบัติ
ดึงหรือกำหนด height ของรูปร่าง, วัดเป็นจุด.
            อ่าน/เขียน **float**.

### หมายเหตุ

ค่าที่คืนกลับมาจะถูกกำหนดเสมอและไม่เคยเป็น **float**.
            ค่าที่กำหนดต้องถูกกำหนดเช่นกัน; กำหนด **float** เฉพาะกับคุณสมบัติของอินสแตนซ์ `RawFrame` เท่านั้น.
