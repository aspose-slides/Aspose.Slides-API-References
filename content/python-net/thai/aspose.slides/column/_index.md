## Column class

แสดงถึงคอลัมน์ในตาราง.

**การสืบทอด:**[`Column`](/slides/python-net/th/aspose.slides/column) → [`CellCollection`](/slides/python-net/th/aspose.slides/cellcollection)

ประเภท Column มีสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`slide`](/slides/python-net/th/aspose.slides/column/slide/) | คืนค่า slide แม่ของ CellCollection.<br/>            อ่านอย่างเดียว [`IBaseSlide`](/slides/python-net/th/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/th/aspose.slides/column/presentation/) | คืนค่า presentation แแม่ของ CellCollection.<br/>            อ่านอย่างเดียว [`IPresentation`](/slides/python-net/th/aspose.slides/ipresentation). |
| [`width`](/slides/python-net/th/aspose.slides/column/width/) | คืนค่า หรือ ตั้งค่าความกว้างของคอลัมน์.<br/>            อ่าน/เขียน **float**. |
| [`column_format`](/slides/python-net/th/aspose.slides/column/column_format/) | คืนค่าอ็อบเจกต์ ColumnFormat ที่มีคุณสมบัติการฟอร์แมตสำหรับคอลัมน์นี้.<br/>            อ่านอย่างเดียว [`IColumnFormat`](/slides/python-net/th/aspose.slides/icolumnformat). |
