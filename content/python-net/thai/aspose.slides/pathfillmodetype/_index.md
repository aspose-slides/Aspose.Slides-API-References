## PathFillModeType enumeration

ระบุวิธีการที่ควรเติมพาธ

ประเภท PathFillModeType แสดงสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| NONE | ไม่มีการเติมเส้นทาง<br/>            นี้ระบุว่าพาธที่สอดคล้องควรไม่มีการเติม |
| NORMAL | การเติมเส้นทางแบบปกติ<br/>            นี้ระบุว่าพาธที่สอดคล้องควรมีสีที่มีการเงาแบบปกติถูกนำมาใช้กับการเติมของมัน |
| LIGHTEN | การเติมเส้นทางให้สว่างขึ้น<br/>            นี้ระบุว่าพาธที่สอดคล้องควรมีสีที่มีการเงาเบาบางถูกนำมาใช้กับการเติมของมัน |
| LIGHTEN_LESS | การเติมเส้นทางให้สว่างขึ้นน้อยลง<br/>            นี้ระบุว่าพาธที่สอดคล้องควรมีสีที่มีการเงาอ่อนกว่าปกติถูกนำมาใช้กับการเติมของมัน |
| DARKEN | การเติมเส้นทางทำให้มืดลง<br/>            นี้ระบุว่าพาธที่สอดคล้องควรมีสีที่มีการเงาเข้มกว่าปกติถูกนำมาใช้กับการเติมของมัน |
| DARKEN_LESS | การเติมเส้นทางทำให้มืดลงน้อยลง<br/>            นี้ระบุว่าพาธที่สอดคล้องควรมีสีที่มีการเงาเข้มกว่าปกติเล็กน้อยถูกนำมาใช้กับการเติมของมัน |
