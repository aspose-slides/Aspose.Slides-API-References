## IBackground คลาส

เป็นตัวแทนพื้นหลังของสไลด์

The IBackground type เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`type`](/slides/python-net/th/aspose.slides/ibackground/type/) | ส่งคืนประเภทของการเติมพื้นหลัง.<br/>            อ่าน/เขียน [`BackgroundType`](/slides/python-net/th/aspose.slides/backgroundtype). |
| [`fill_format`](/slides/python-net/th/aspose.slides/ibackground/fill_format/) | ส่งคืน FillFormat สำหรับการเติม BackgroundType.OwnBackground.<br/>            อ่านอย่างเดียว [`IFillFormat`](/slides/python-net/th/aspose.slides/ifillformat). |
| [`effect_format`](/slides/python-net/th/aspose.slides/ibackground/effect_format/) | ส่งคืน EffectFormat สำหรับการเติม BackgroundType.OwnBackground.<br/>            อ่านอย่างเดียว [`IEffectFormat`](/slides/python-net/th/aspose.slides/ieffectformat). |
| [`style_color`](/slides/python-net/th/aspose.slides/ibackground/style_color/) | ส่งคืน ColorFormat สำหรับการเติม BackgroundType.Themed.<br/>            อ่านอย่างเดียว [`IColorFormat`](/slides/python-net/th/aspose.slides/icolorformat). |
| [`style_index`](/slides/python-net/th/aspose.slides/ibackground/style_index/) | ส่งคืนดัชนีของการเติม BackgroundType.Themed ในชุดรูปแบบพื้นหลัง.<br/>            0 หมายถึงไม่มีการเติม.<br/>            1..999 - ดัชนี.<br/>            อ่าน/เขียน **int**. |
| [`slide`](/slides/python-net/th/aspose.slides/ibackground/slide/) |  |
| [`presentation`](/slides/python-net/th/aspose.slides/ibackground/presentation/) |  |
