## ICustomData คลาส

เป็นตัวแทนของคอนเทนเนอร์สำหรับข้อมูลที่กำหนดเอง.

ชนิด ICustomData เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`tags`](/slides/python-net/th/aspose.slides/icustomdata/tags/) | ส่งคืนคอลเลกชันของแท็กข้อมูลลูกค้า.<br/>            อ่านอย่างเดียว [`ITagCollection`](/slides/python-net/th/aspose.slides/itagcollection). |
| [`custom_xml_parts`](/slides/python-net/th/aspose.slides/icustomdata/custom_xml_parts/) | ส่งคืนคอลเลกชันของส่วน xml ที่กำหนดเอง.<br/>            อ่านอย่างเดียว [`ICustomXmlPartCollection`](/slides/python-net/th/aspose.slides/icustomxmlpartcollection). |
