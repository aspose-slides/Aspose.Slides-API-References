## INormalViewProperties คลาส

แสดงคุณสมบัติของมุมมองปกติ. มุมมองปกติประกอบด้วยเขตเนื้อหา สามส่วน: สไลด์เอง, เขตเนื้อหาข้างด้าน, และเขตเนื้อหาด้านล่าง.

ประเภท INormalViewProperties เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`show_outline_icons`](/slides/python-net/th/aspose.slides/inormalviewproperties/show_outline_icons/) | ระบุว่าแอปพลิเคชันควรแสดงไอคอนหรือไม่หากแสดงเนื้อหาโครงร่างในส่วนใดของเขตเนื้อหาในโหมดมุมมองปกติ.<br/>            อ่าน/เขียน **bool**. |
| [`snap_vertical_splitter`](/slides/python-net/th/aspose.slides/inormalviewproperties/snap_vertical_splitter/) | ระบุว่าตัวแบ่งแนวตั้งควรสแน็ปไปยังสถานะย่อเมื่อเขตข้างด้านมีขนาดเล็กพอ.<br/>            อ่าน/เขียน **bool**. |
| [`vertical_bar_state`](/slides/python-net/th/aspose.slides/inormalviewproperties/vertical_bar_state/) | ระบุสถานะที่แถบแบ่งแนวตั้งควรแสดงอยู่. <br/>            แถบแบ่งแนวตั้งจะแยกสไลด์ออกจากเขตเนื้อหาข้างด้าน. |
| [`horizontal_bar_state`](/slides/python-net/th/aspose.slides/inormalviewproperties/horizontal_bar_state/) | ระบุสถานะที่แถบแบ่งแนวนอนควรแสดงอยู่.<br/>            แถบแบ่งแนวนอนจะแยกสไลด์ออกจากเขตเนื้อหาที่อยู่ด้านล่างสไลด์. |
| [`prefer_single_view`](/slides/python-net/th/aspose.slides/inormalviewproperties/prefer_single_view/) | ระบุว่าผู้ใช้ต้องการดูเขตเนื้อหาเดี่ยวเต็มหน้าต่างแทนมุมมองปกติมาตรฐานที่มีสามเขตเนื้อหาหรือไม่. หากเปิดใช้งาน แอปพลิเคชันอาจเลือกแสดงหนึ่งในเขตเนื้อหาในหน้าต่างทั้งหมด.<br/>            อ่าน/เขียน **bool**. |
| [`restored_left`](/slides/python-net/th/aspose.slides/inormalviewproperties/restored_left/) | องค์ประกอบนี้ระบุขนาดของเขตเนื้อหาข้างด้านของมุมมองปกติเมื่อเขตนั้นอยู่ในขนาดที่กู้คืนได้แบบเปลี่ยนแปลง (ไม่ได้ย่อหรือขยาย).<br/>            อ่านอย่างเดียว [`INormalViewRestoredProperties`](/slides/python-net/th/aspose.slides/inormalviewrestoredproperties). |
| [`restored_top`](/slides/python-net/th/aspose.slides/inormalviewproperties/restored_top/) | องค์ประกอบนี้ระบุขนาดของเขตสไลด์ด้านบนของมุมมองปกติเมื่อเขตนั้นอยู่ในขนาดที่กู้คืนได้แบบเปลี่ยนแปลง (ไม่ได้ย่อหรือขยาย).<br/>            อ่านอย่างเดียว [`INormalViewRestoredProperties`](/slides/python-net/th/aspose.slides/inormalviewrestoredproperties). |
