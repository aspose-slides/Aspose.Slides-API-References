## IAnimationTimeLine คลาส

แสดงถึงเส้นเวลาของการเคลื่อนไหว.

ประเภท IAnimationTimeLine เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`interactive_sequences`](/slides/python-net/th/aspose.slides/ianimationtimeline/interactive_sequences/) | ส่งคืนคอลเลกชันของลำดับการโต้ตอบ.<br/>            ลำดับนี้อาจมีเฉพาะเอฟเฟ็กต์โดย "คลิกบนรูปร่าง" กับรูปร่างเป้าหมายที่ระบุ.<br/>            อ่านอย่างเดียว [`ISequenceCollection`](/slides/python-net/th/aspose.slides.animation/isequencecollection). |
| [`main_sequence`](/slides/python-net/th/aspose.slides/ianimationtimeline/main_sequence/) | ส่งคืนลำดับหลักซึ่งอาจมีเพียงคอลเลกชันของเอฟเฟ็กต์หลักเท่านั้น.<br/>            อ่านอย่างเดียว [`ISequence`](/slides/python-net/th/aspose.slides.animation/isequence). |
| [`text_animation_collection`](/slides/python-net/th/aspose.slides/ianimationtimeline/text_animation_collection/) | ส่งคืนคอลเลกชันของการเคลื่อนไหวข้อความ.<br/>            อ่านอย่างเดียว [`ITextAnimationCollection`](/slides/python-net/th/aspose.slides.animation/itextanimationcollection). |
