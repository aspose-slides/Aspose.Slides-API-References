## IViewProperties คลาส

คุณสมบัติวิวทั่วทั้งการนำเสนอ.

ประเภท IViewProperties เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`last_view`](/slides/python-net/th/aspose.slides/iviewproperties/last_view/) | ระบุโหมดมุมมองที่ใช้เมื่อบันทึกเอกสารการนำเสนอเป็นครั้งสุดท้าย.<br/>            อ่าน/เขียน [`ViewType`](/slides/python-net/th/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/th/aspose.slides/iviewproperties/show_comments/) | ระบุว่าความคิดเห็นสไลด์ควรแสดงหรือไม่.<br/>            อ่าน/เขียน [`NullableBool`](/slides/python-net/th/aspose.slides/nullablebool). |
| [`slide_view_properties`](/slides/python-net/th/aspose.slides/iviewproperties/slide_view_properties/) | ระบุคุณสมบัติวิวทั่วไปที่เชื่อมโยงกับโหมดมุมมองสไลด์.<br/>            อ่านได้เท่านั้น [`ICommonSlideViewProperties`](/slides/python-net/th/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/th/aspose.slides/iviewproperties/notes_view_properties/) | ระบุคุณสมบัติวิวทั่วไปที่เชื่อมโยงกับโหมดมุมมองบันทึกหมายเหตุ.<br/>            อ่านได้เท่านั้น [`ICommonSlideViewProperties`](/slides/python-net/th/aspose.slides/icommonslideviewproperties). |
| [`normal_view_properties`](/slides/python-net/th/aspose.slides/iviewproperties/normal_view_properties/) | เป็นตัวแทนของคุณสมบัติวิวปกติ. วิวปกติประกอบด้วย<br/>            สามส่วนของเนื้อหา: สไลด์เอง, ส่วนเนื้อหาด้านข้าง, และส่วนเนื้อหาที่ด้านล่าง.<br/>            อ่านได้เท่านั้น [`INormalViewProperties`](/slides/python-net/th/aspose.slides/inormalviewproperties). |
| [`grid_spacing`](/slides/python-net/th/aspose.slides/iviewproperties/grid_spacing/) | คืนค่าหรือกำหนดระยะห่างของกริดที่ควรใช้สำหรับกริดที่อยู่ใต้เอกสารการนำเสนอ, หน่วยเป็นจุด.<br/>            อ่าน/เขียน **float**. |
