## คลาส Size

จัดเก็บคู่จำนวนเต็มที่เรียงลำดับ ซึ่งระบุความกว้างและความสูง เข้ากันได้กับ .NET `System.Drawing.Size`.

ประเภท Size เปิดเผยสมาชิกต่อไปนี้:

## คอนสตรัคเตอร์

| คอนสตรัคเตอร์ | คำอธิบาย |
| :- | :- |
| [`__init__(self, width=0, height=0)`](/slides/python-net/th/aspose.slides/size/__init__/#int-int) | สร้างขนาดด้วยความกว้างและความสูงที่ระบุ ค่าจุดทศนิยมจะถูกตัดเป็นจำนวนเต็ม. |

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`width`](/slides/python-net/th/aspose.slides/size/width/) | รับส่วนประกอบแนวนอนของขนาดนี้.<br/>            อ่านได้อย่างเดียว **int**. |
| [`height`](/slides/python-net/th/aspose.slides/size/height/) | รับส่วนประกอบแนวตั้งของขนาดนี้.<br/>            อ่านได้อย่างเดียว **int**. |


### หมายเหตุ

ขนาดจะถูกเปรียบเทียบตามส่วนประกอบด้วย `==` และสามารถใช้เป็นคีย์ของดิกชันนารีหรือสมาชิกของเซ็ตได้.
