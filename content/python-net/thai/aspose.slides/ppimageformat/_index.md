## PPImageFormat การนับประเภท

รูปแบบภาพต่าง ๆ enum นี้เป็นการแทนที่คลาส `System.Drawing.Imaging.ImageFormat`  
จำเป็นสำหรับความเข้ากันได้กับ COM

ประเภท PPImageFormat เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| BMP | รับรูปแบบภาพบิทแมพ (BMP). |
| EMF | รับรูปแบบเมตะไฟล์ที่ปรับปรุงแล้ว (EMF). |
| EXIF | รับรูปแบบไฟล์ภาพที่แลกเปลี่ยนได้ (Exif). |
| GIF | รับรูปแบบภาพกราฟิกอินเทอร์เชนจ (GIF). |
| ICON | รับรูปแบบภาพไอคอนของ Windows. |
| JPEG | รับรูปแบบภาพ Joint Photographic Experts Group (JPEG). |
| MEMORY_BMP | รับรูปแบบบิทแมพในหน่วยความจำ. |
| PNG | รับรูปแบบภาพ Portable Network Graphics (PNG) ของ W3C. |
| TIFF | รับรูปแบบภาพ Tagged Image File Format (TIFF). |
| WMF | รับรูปแบบเมตะไฟล์ของ Windows (WMF). |
