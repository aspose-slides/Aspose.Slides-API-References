## IShapeStyle คลาส

แสดงอ้างอิงสไตล์ของรูปร่าง.

ประเภท IShapeStyle เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`line_color`](/slides/python-net/th/aspose.slides/ishapestyle/line_color/) | ส่งคืนสีโครงของรูปร่าง.<br/>            อ่านอย่างเดียว [`IColorFormat`](/slides/python-net/th/aspose.slides/icolorformat). |
| [`line_style_index`](/slides/python-net/th/aspose.slides/ishapestyle/line_style_index/) | ส่งคืนหรือกำหนดดัชนีคอลัมน์ของเส้นในเมทริกซ์สไตล์.<br/>            อ่าน/เขียน **int**. |
| [`fill_color`](/slides/python-net/th/aspose.slides/ishapestyle/fill_color/) | ส่งคืนสีเติมของรูปร่าง.<br/>            อ่านอย่างเดียว [`IColorFormat`](/slides/python-net/th/aspose.slides/icolorformat). |
| [`fill_style_index`](/slides/python-net/th/aspose.slides/ishapestyle/fill_style_index/) | ส่งคืนหรือกำหนดดัชนีคอลัมน์การเติมของรูปร่างในเมทริกซ์สไตล์.<br/>            0 หมายถึงไม่มีการเติม,<br/>            ค่าบวก - ดัชนีในสไตล์การเติมของธีม,<br/>            ค่าเชิงลบ - ดัชนีในสไตล์พื้นหลังของธีม.<br/>            อ่าน/เขียน **int**. |
| [`effect_color`](/slides/python-net/th/aspose.slides/ishapestyle/effect_color/) | ส่งคืนสีเอฟเฟกต์ของรูปร่าง.<br/>            อ่านอย่างเดียว [`IColorFormat`](/slides/python-net/th/aspose.slides/icolorformat). |
| [`effect_style_index`](/slides/python-net/th/aspose.slides/ishapestyle/effect_style_index/) | ส่งคืนหรือกำหนดดัชนีคอลัมน์เอฟเฟกต์ของรูปร่างในเมทริกซ์สไตล์.<br/>            อ่าน/เขียน **int**. |
| [`font_color`](/slides/python-net/th/aspose.slides/ishapestyle/font_color/) | ส่งคืนสีฟอนต์ของรูปร่าง.<br/>            อ่านอย่างเดียว [`IColorFormat`](/slides/python-net/th/aspose.slides/icolorformat). |
| [`font_collection_index`](/slides/python-net/th/aspose.slides/ishapestyle/font_collection_index/) | ส่งคืนหรือกำหนดดัชนีฟอนต์ของรูปร่างในคอลเลกชันฟอนต์.<br/>            อ่าน/เขียน [`FontCollectionIndex`](/slides/python-net/th/aspose.slides/fontcollectionindex). |
