## width คุณสมบัติ
รับหรือกำหนดความกว้างของ shape, วัดเป็นจุด.
            อ่าน/เขียน **float**.

### หมายเหตุ

ค่าที่ส่งกลับจะถูกกำหนดเสมอและไม่เคย **float**.
            ค่าที่กำหนดต้องถูกกำหนดเช่นกัน; กำหนด **float** เฉพาะให้กับคุณสมบัติของอินสแตนซ์ `RawFrame` เท่านั้น.
