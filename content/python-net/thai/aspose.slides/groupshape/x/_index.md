## x คุณสมบัติ
รับหรือกำหนดค่า x-coordinate ของมุมบนซ้ายของรูปร่าง, วัดเป็นจุด.
            อ่าน/เขียน **float**.


### หมายเหตุ

ค่าที่ส่งกลับมาจะถูกกำหนดเสมอและไม่ใช่ **float**.
            ค่าที่กำหนดต้องถูกกำหนดเช่นกัน; ให้กำหนด **float** เฉพาะให้กับคุณสมบัติของอ็อบเจ็กต์ `RawFrame` เท่านั้น.

### คำนิยาม:

```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
