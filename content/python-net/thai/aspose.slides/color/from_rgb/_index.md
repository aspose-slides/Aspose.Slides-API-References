## from_rgb(r, g, b) {#int-int-int}
สร้างสีทึบ (alpha คือ 255) จากค่าที่ระบุของสีแดง, สีเขียวและสีน้ำเงิน

### คืนค่า

สีที่สร้างจากค่าที่ระบุ



```python
@staticmethod
def from_rgb(r, g, b):
    ...
```


| พารามิเตอร์ | ประเภท | คำอธิบาย |
| :- | :- | :- |
| r | **int** | ค่าคอมโพเนนต์สีแดง. ค่าใช้ได้ตั้งแต่ 0 ถึง 255. |
| g | **int** | ค่าคอมโพเนนต์สีเขียว. ค่าใช้ได้ตั้งแต่ 0 ถึง 255. |
| b | **int** | ค่าคอมโพเนนต์สีน้ำเงิน. ค่าใช้ได้ตั้งแต่ 0 ถึง 255. |

| :- | :- |
