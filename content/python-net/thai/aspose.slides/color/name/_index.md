## name คุณสมบัติ
รับชื่อของสีนี้.<br/>            สำหรับสีที่มีชื่อ (ค่าคงที่ที่ตั้งชื่อ เช่น `Color.red`, หรือสีที่สร้างด้วย [`from_name`](/slides/python-net/th/aspose.slides/color/from_name/)) จะคืนชื่อของ .NET เช่น `"Red"` หรือ `"LightBlue"`.<br/>            สำหรับสีอื่นใดค่า ARGB จะถูกคืนในรูปแบบฐานสิบหกตัวพิมพ์เล็กโดยไม่มีการเติมศูนย์หน้า เช่น `"ffff0000"`. `Color.empty.name` คือ `"0"`.
            อ่านอย่างเดียว **str**.
