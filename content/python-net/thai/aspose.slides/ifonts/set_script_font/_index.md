```python
def set_script_font(self, script, font_name):
    ...
```

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| :- | :- | :- |
| script | **str** | รหัสสคริปต์ BCP-47 (เช่น "Arab", "Hebr", "Hans") ซึ่งระบุระบบการเขียน |
| font_name | **str** | ชื่อฟอนต์ที่จะกำหนดให้กับสคริปต์ที่ระบุ |
