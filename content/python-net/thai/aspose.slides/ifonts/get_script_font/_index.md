## get_script_font(self, script) {#str}

ชื่อแบบอักษรที่ใช้สำหรับสคริปต์ที่ระบุ, หรือ `None` หากสคริปต์ไม่มีการกำหนด



```python
def get_script_font(self, script):
    ...
```


| พารามิเตอร์ | ประเภท | รายละเอียด |
| :- | :- | :- |
