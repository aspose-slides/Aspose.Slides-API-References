## IFonts คลาส

เป็นตัวแทนของชุดแบบอักษร

ประเภท IFonts เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`latin_font`](/slides/python-net/th/aspose.slides/ifonts/latin_font/) | คืนค่า หรือ ตั้งค่าแบบอักษร Latin.<br/>            อ่าน/เขียน [`IFontData`](/slides/python-net/th/aspose.slides/ifontdata). |
| [`east_asian_font`](/slides/python-net/th/aspose.slides/ifonts/east_asian_font/) | คืนค่า หรือ ตั้งค่าแบบอักษร East Asian.<br/>            อ่าน/เขียน [`IFontData`](/slides/python-net/th/aspose.slides/ifontdata). |
| [`complex_script_font`](/slides/python-net/th/aspose.slides/ifonts/complex_script_font/) | คืนค่า หรือ ตั้งค่าแบบอักษร complex script.<br/>            อ่าน/เขียน [`IFontData`](/slides/python-net/th/aspose.slides/ifontdata). |
