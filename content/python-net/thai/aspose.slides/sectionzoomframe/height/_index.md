## height คุณสมบัติ
รับหรือกำหนดค่า height ของ shape ที่วัดเป็นจุด.
อ่าน/เขียน **float**.

### หมายเหตุ

ค่าที่ส่งกลับมักจะถูกกำหนดเสมอและไม่เคยเป็น **float**.
ค่าที่กำหนดต้องถูกกำหนดเช่นกัน; กำหนด **float** ให้กับคุณสมบัติของอ็อบเจกต์ `RawFrame` เท่านั้น.
