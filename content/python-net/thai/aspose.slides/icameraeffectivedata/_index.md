## ICameraEffectiveData คลาส

อ็อบเจกต์ที่ไม่สามารถเปลี่ยนแปลงได้ซึ่งบรรจุคุณสมบัติของกล้องที่มีผล

ประเภท ICameraEffectiveData เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`camera_type`](/slides/python-net/th/aspose.slides/icameraeffectivedata/camera_type/) | ประเภทกล้อง.<br/>อ่านอย่างเดียว [`CameraPresetType`](/slides/python-net/th/aspose.slides/camerapresettype). |
| [`field_of_view_angle`](/slides/python-net/th/aspose.slides/icameraeffectivedata/field_of_view_angle/) | มุมมองกล้อง (0-180 deg, field of View).<br/>อ่านอย่างเดียว **float**. |
| [`zoom`](/slides/python-net/th/aspose.slides/icameraeffectivedata/zoom/) | การซูมของกล้อง (ค่าบวกเป็นเปอร์เซ็นต์).<br/>อ่านอย่างเดียว **float**. |

## เมธอด

| Method | Description |
| :- | :- |
| [`get_rotation(self)`](/slides/python-net/th/aspose.slides/icameraeffectivedata/get_rotation/#) | การหมุนถูกกำหนดโดยการใช้พิกัดละติจูด<br/>พิกัดลองจิจูดและการหมุนรอบแกน<br/>ตามพิกัดละติจูดและลองจิจูด.<br/>องค์ประกอบตัวแรกในอาร์เรย์ที่คืนค่า - ละติจูด, ตัวที่สอง - ลองจิจูด, ตัวที่สาม - การหมุน.<br/>คืนค่า None หากไม่มีการหมุนกำหนด. |
