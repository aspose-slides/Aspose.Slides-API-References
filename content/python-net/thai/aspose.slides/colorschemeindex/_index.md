## ColorSchemeIndex enumeration

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| DARK1 | สีเข้ม 1. |
| LIGHT1 | สีอ่อน 1. |
| DARK2 | สีเข้ม 2. |
| LIGHT2 | สีอ่อน 2. |
| ACCENT1 | สีเน้น 1. |
| ACCENT2 | สีเน้น 2. |
| ACCENT3 | สีเน้น 3. |
| ACCENT4 | สีเน้น 4. |
| ACCENT5 | สีเน้น 5. |
| ACCENT6 | สีเน้น 6. |
| HYPERLINK | ไฮเปอร์ลิงก์. |
| FOLLOWED_HYPERLINK | ไฮเปอร์ลิงก์ที่ตามแล้ว. |
