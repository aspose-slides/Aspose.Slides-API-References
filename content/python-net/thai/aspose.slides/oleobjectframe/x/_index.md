## x คุณสมบัติ
รับหรือกำหนดค่าพิกัด x ของมุมบนซ้ายของรูปร่าง, วัดเป็นจุด.
            อ่าน/เขียน **float**.

### หมายเหตุ

ค่าที่ส่งกลับจะถูกกำหนดเสมอและไม่เป็น **float**.
            ค่าที่กำหนดต้องถูกกำหนดเช่นกัน; ให้กำหนด **float** เฉพาะกับคุณสมบัติของออบเจกต์ `RawFrame` เท่านั้น.

### การกำหนด:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
