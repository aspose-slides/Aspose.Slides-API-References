## height คุณสมบัติ
ดึงหรือกำหนดค่า height ของ shape วัดเป็นจุด.
            อ่าน/เขียน **float**.

### หมายเหตุ

ค่าที่ส่งกลับจะถูกกำหนดไว้เสมอและไม่ใช่ **float**.
            ค่าที่กำหนดต้องถูกกำหนดไว้เช่นกัน; ให้กำหนด **float** เฉพาะกับคุณสมบัติของอินสแตนซ์ `RawFrame` เท่านั้น.
