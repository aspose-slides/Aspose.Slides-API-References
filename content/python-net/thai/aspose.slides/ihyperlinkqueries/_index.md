## IHyperlinkQueries คลาส

ให้การเข้าถึงไฮเปอร์ลิงก์ที่บรรจุอยู่ได้อย่างง่ายดาย.

ประเภท IHyperlinkQueries เปิดเผยสมาชิกต่อไปนี้:

## เมธอด

| เมธอด | คำอธิบาย |
| :- | :- |
| [`get_hyperlink_clicks(self)`](/slides/python-net/th/aspose.slides/ihyperlinkqueries/get_hyperlink_clicks/#) | รับ IHyperlinkContainer ย่อยทั้งหมดที่มี HyperlinkClick ที่ไม่เป็นค่า None.<br/>            ด้วยวัตถุ IHyperlinkContainer ที่กำหนด คุณสามารถจัดการไฮเปอร์ลิงก์ของมัน (อ่าน, ปรับข้อมูลหรือเอาออก). ดู IHyperlinkContainer interface. |
| [`get_hyperlink_mouse_overs(self)`](/slides/python-net/th/aspose.slides/ihyperlinkqueries/get_hyperlink_mouse_overs/#) | รับ IHyperlinkContainer ย่อยทั้งหมดที่มี HyperlinkMouseOver ที่ไม่เป็นค่า None.<br/>            ด้วยวัตถุ IHyperlinkContainer ที่กำหนด คุณสามารถจัดการไฮเปอร์ลิงก์ของมัน (อ่าน, ปรับข้อมูลหรือเอาออก). ดู IHyperlinkContainer interface. |
| [`get_any_hyperlinks(self)`](/slides/python-net/th/aspose.slides/ihyperlinkqueries/get_any_hyperlinks/#) | รับ IHyperlinkContainer ย่อยทั้งหมดที่มี HyperlinkMouseOver ที่ไม่เป็นค่า None.<br/>            ด้วยวัตถุ IHyperlinkContainer ที่กำหนด คุณสามารถจัดการไฮเปอร์ลิงก์ของมัน (อ่าน, ปรับข้อมูลหรือเอาออก). ดู IHyperlinkContainer interface. |
| [`remove_all_hyperlinks(self)`](/slides/python-net/th/aspose.slides/ihyperlinkqueries/remove_all_hyperlinks/#) | ลบไฮเปอร์ลิงก์ HyperlinkClick และ HyperlinkMouseOver ทั้งหมดที่บรรจุอยู่ (ใน IHyperlinkContainer ย่อยทั้งหมด). |
