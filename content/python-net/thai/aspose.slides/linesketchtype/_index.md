## LineSketchType enumeration

ระบุประเภทสเก็ตช์หรือเอฟเฟกต์ที่กำหนดให้กับรูปทรง

ประเภท LineSketchType แสดงสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| NOT_DEFINED | ระบุว่าเอฟเฟกต์ Sketch ของรูปทรงไม่ได้กำหนด |
| NONE | ระบุว่ารูปทรงไม่มีเอฟเฟกต์ Sketch. ซึ่งเท่ากับว่าคุณสมบัตินี้ว่างเปล่า |
| CURVED | ระบุว่ารูปทรงมีเอฟเฟกต์ Curved ซึ่งทำให้ขอบของรูปทรงแต่ละด้านกลายเป็นโค้งอ่อนสบายเดียว |
| FREEHAND | ระบุว่ารูปทรงมีเอฟเฟกต์ Freehand ซึ่งคล้ายกับเส้นที่วาดโดยไม่สมบูรณ์ที่สุด |
| SCRIBBLE | ระบุว่ารูปทรงมีเอฟเฟกต์ Scribble ซึ่งมีการสั่นไหลเกินจริงเหมือนถูกวาดอย่างเจตนาให้รก |
