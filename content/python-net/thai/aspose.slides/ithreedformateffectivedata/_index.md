## IThreeDFormatEffectiveData คลาส

วัตถุที่ไม่เปลี่ยนแปลงซึ่งเป็นตัวแทนของคุณสมบัติการจัดรูปแบบ 3-D ที่มีประสิทธิภาพ

ประเภท IThreeDFormatEffectiveData เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`contour_width`](/slides/python-net/th/aspose.slides/ithreedformateffectivedata/contour_width/) | ส่งกลับความกว้างของโครงร่าง 3D.<br/>            อ่านอย่างเดียว **float**. |
| [`extrusion_height`](/slides/python-net/th/aspose.slides/ithreedformateffectivedata/extrusion_height/) | ส่งกลับความสูงของเอฟเฟกต์การดึงออก.<br/>            อ่านอย่างเดียว **float**. |
| [`depth`](/slides/python-net/th/aspose.slides/ithreedformateffectivedata/depth/) | ส่งกลับความลึกของรูป 3D.<br/>            อ่านอย่างเดียว **float**. |
| [`bevel_top`](/slides/python-net/th/aspose.slides/ithreedformateffectivedata/bevel_top/) | ส่งกลับประเภทของบีเวลด้านบน 3D.<br/>            อ่านอย่างเดียว [`IShapeBevelEffectiveData`](/slides/python-net/th/aspose.slides/ishapebeveleffectivedata). |
| [`bevel_bottom`](/slides/python-net/th/aspose.slides/ithreedformateffectivedata/bevel_bottom/) | ส่งกลับประเภทของบีเวลด้านล่าง 3D.<br/>            อ่านอย่างเดียว [`IShapeBevelEffectiveData`](/slides/python-net/th/aspose.slides/ishapebeveleffectivedata). |
| [`contour_color`](/slides/python-net/th/aspose.slides/ithreedformateffectivedata/contour_color/) | ส่งกลับสีของโครงร่าง.<br/>            อ่านอย่างเดียว **aspose.slides.Color**. |
| [`extrusion_color`](/slides/python-net/th/aspose.slides/ithreedformateffectivedata/extrusion_color/) | ส่งกลับสีของการดึงออก.<br/>            อ่านอย่างเดียว **aspose.slides.Color**. |
| [`camera`](/slides/python-net/th/aspose.slides/ithreedformateffectivedata/camera/) | ส่งกลับการตั้งค่าของกล้อง.<br/>            อ่านอย่างเดียว [`ICameraEffectiveData`](/slides/python-net/th/aspose.slides/icameraeffectivedata). |
| [`light_rig`](/slides/python-net/th/aspose.slides/ithreedformateffectivedata/light_rig/) | ส่งกลับประเภทของแสง.<br/>            อ่านอย่างเดียว [`ILightRigEffectiveData`](/slides/python-net/th/aspose.slides/ilightrigeffectivedata). |
| [`material`](/slides/python-net/th/aspose.slides/ithreedformateffectivedata/material/) | ส่งกลับประเภทของวัสดุ.<br/>            อ่านอย่างเดียว [`MaterialPresetType`](/slides/python-net/th/aspose.slides/materialpresettype). |
