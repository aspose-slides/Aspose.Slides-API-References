## IThreeDFormatEffectiveData คลาส

อ็อบเจกต์ที่ไม่สามารถแก้ไขได้ซึ่งแสดงถึงคุณสมบัติการจัดรูปแบบ 3-D ที่มีผล

ประเภท IThreeDFormatEffectiveData เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`contour_width`](/slides/python-net/th/aspose.slides/ithreedformateffectivedata/contour_width/) | คืนค่าความกว้างของคอนทัวร์ 3D.<br/>            อ่านอย่างเดียว **float**. |
| [`extrusion_height`](/slides/python-net/th/aspose.slides/ithreedformateffectivedata/extrusion_height/) | คืนค่าความสูงของเอฟเฟกต์การดึงออก.<br/>            อ่านอย่างเดียว **float**. |
| [`depth`](/slides/python-net/th/aspose.slides/ithreedformateffectivedata/depth/) | คืนค่าความลึกของรูปทรง 3D.<br/>            อ่านอย่างเดียว **float**. |
| [`bevel_top`](/slides/python-net/th/aspose.slides/ithreedformateffectivedata/bevel_top/) | คืนค่าประเภทของบีเวลด้านบน 3D.<br/>            อ่านอย่างเดียว [`IShapeBevelEffectiveData`](/slides/python-net/th/aspose.slides/ishapebeveleffectivedata). |
| [`bevel_bottom`](/slides/python-net/th/aspose.slides/ithreedformateffectivedata/bevel_bottom/) | คืนค่าประเภทของบีเวลด้านล่าง 3D.<br/>            อ่านอย่างเดียว [`IShapeBevelEffectiveData`](/slides/python-net/th/aspose.slides/ishapebeveleffectivedata). |
| [`contour_color`](/slides/python-net/th/aspose.slides/ithreedformateffectivedata/contour_color/) | คืนค่าสีของคอนทัวร์.<br/>            อ่านอย่างเดียว [`Color`](/slides/python-net/th/aspose.slides/color). |
| [`extrusion_color`](/slides/python-net/th/aspose.slides/ithreedformateffectivedata/extrusion_color/) | คืนค่าสีของการดึงออก.<br/>            อ่านอย่างเดียว [`Color`](/slides/python-net/th/aspose.slides/color). |
| [`camera`](/slides/python-net/th/aspose.slides/ithreedformateffectivedata/camera/) | คืนค่าการตั้งค่าของกล้อง.<br/>            อ่านอย่างเดียว [`ICameraEffectiveData`](/slides/python-net/th/aspose.slides/icameraeffectivedata). |
| [`light_rig`](/slides/python-net/th/aspose.slides/ithreedformateffectivedata/light_rig/) | คืนค่าประเภทของแสง.<br/>            อ่านอย่างเดียว [`ILightRigEffectiveData`](/slides/python-net/th/aspose.slides/ilightrigeffectivedata). |
| [`material`](/slides/python-net/th/aspose.slides/ithreedformateffectivedata/material/) | คืนค่าประเภทของวัสดุ.<br/>            อ่านอย่างเดียว [`MaterialPresetType`](/slides/python-net/th/aspose.slides/materialpresettype). |
