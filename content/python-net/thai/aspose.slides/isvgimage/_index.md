## ISvgImage คลาส

แสดงถึงภาพ SVG.

ประเภท ISvgImage เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`svg_content`](/slides/python-net/th/aspose.slides/isvgimage/svg_content/) | ส่งคืนเนื้อหา SVG.<br/>            อ่านอย่างเดียว **str**. |
| [`svg_data`](/slides/python-net/th/aspose.slides/isvgimage/svg_data/) | ส่งคืนข้อมูล SVG.<br/>            อ่านอย่างเดียว **int**[]. |
| [`external_resource_resolver`](/slides/python-net/th/aspose.slides/isvgimage/external_resource_resolver/) | คืนอินเทอร์เฟซการเรียกกลับที่ใช้เพื่อแก้ไขทรัพยากรภายนอกระหว่างการนำเข้าเอกสาร SVG.<br/>            อ่านอย่างเดียว **IExternalResourceResolver**. |
| [`base_uri`](/slides/python-net/th/aspose.slides/isvgimage/base_uri/) | ส่งคืน URI พื้นฐานของ SVG ที่ระบุ ใช้ในการแก้ไขลิงก์สัมพันธ์.<br/>            อ่านอย่างเดียว **str**. |

## เมธอด

| เมธอด | คำอธิบาย |
| :- | :- |
