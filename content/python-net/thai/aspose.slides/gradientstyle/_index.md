## GradientStyle การนับค่า

แสดงถึงสไตล์ gradient ที่มีอยู่

ประเภท GradientStyle เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | รายละเอียด |
| :- | :- |
| DEFAULT | สไตล์ gradient เริ่มต้น |
| POWER_POINT_UI | สไตล์ gradient ตามที่แสดงในส่วนต่อประสานผู้ใช้ของ PowerPoint |
