## HyperlinkActionType ประเภท

แทนประเภทของการกระทำไฮเปอร์ลิงก์

ประเภท HyperlinkActionType เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| Field | Description |
| :- | :- |
| UNKNOWN | ประเภทการกระทำที่ไม่รู้จัก. |
| NO_ACTION | ไม่มีการกระทำ. |
| HYPERLINK | ไฮเปอร์ลิงก์ทั่วไป. |
| JUMP_FIRST_SLIDE | กระโดดไปยังสไลด์แรกของงานนำเสนอ. |
| JUMP_PREVIOUS_SLIDE | กระโดดไปยังสไลด์ก่อนหน้า. |
| JUMP_NEXT_SLIDE | กระโดดไปยังสไลด์ต่อไป. |
| JUMP_LAST_SLIDE | กระโดดไปยังสไลด์สุดท้ายของงานนำเสนอ. |
| JUMP_END_SHOW | กระโดดไปยังจุดสิ้นสุดของการสไลด์โชว์. |
| JUMP_LAST_VIEWED_SLIDE | กระโดดไปยังสไลด์ที่ดูล่าสุด. |
| JUMP_SPECIFIC_SLIDE | กระโดดไปยังสไลด์เฉพาะที่อ้างอิงโดยคุณสมบัติ [`IHyperlink.target_slide`](/slides/python-net/th/aspose.slides/ihyperlink/target_slide). |
| START_CUSTOM_SLIDE_SHOW | เริ่มการสไลด์โชว์แบบกำหนดเอง. |
| OPEN_FILE | เปิดไฟล์ที่อ้างอิง. |
| OPEN_PRESENTATION | เปิดงานนำเสนอที่อ้างอิง. |
| START_STOP_MEDIA | เริ่ม/หยุดเล่นไฟล์สื่อ. |
| START_MACRO | เริ่มการดำเนินการสคริปต์มาโคร. |
| START_PROGRAM | เริ่มโปรแกรม. |
