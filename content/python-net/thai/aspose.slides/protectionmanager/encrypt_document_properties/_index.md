## encrypt_document_properties คุณสมบัติ
คุณสมบัตินี้มีความหมาย หากการนำเสนอได้รับการป้องกันด้วยรหัสผ่าน.
หากเป็น true แล้วคุณสมบัติของเอกสารจะถูกเข้ารหัสในไฟล์การนำเสนอ.
หากเป็น false แล้วคุณสมบัติของเอกสารจะเป็นสาธารณะขณะที่การนำเสนอถูกเข้ารหัส.
อ่าน/เขียน **bool**.
