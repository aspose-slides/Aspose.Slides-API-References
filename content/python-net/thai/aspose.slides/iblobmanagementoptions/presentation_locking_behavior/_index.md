## presentation_locking_behavior คุณสมบัติ
This property defines if an instance of the Presentation class can be an owner of the แหล่งที่มา - ไฟล์ 
            หรือสตรีมระหว่างอายุการทำงานของตัวอย่าง หากตัวอย่างเป็นเจ้าของ จะล็อกแหล่งที่มา สิ่งนี้ช่วย 
            ปรับปรุงการใช้หน่วยความจำและประสิทธิภาพขณะทำงานกับ BLOBs แต่แหล่งที่มา (สตรีมหรือไฟล์) 
            ไม่สามารถเปลี่ยนแปลงได้ในช่วงอายุการทำงานของ Presentation นี้เป็นตัวอย่าง:
