```python
def insert_table(self, index, x, y, column_widths, row_heights):
    ...
```

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| :- | :- | :- |
| index | **int** | ดัชนีที่เริ่มต้นจากศูนย์ซึ่งจะใช้แทรกตาราง |
| x | **float** | พิกัด x ของตาราง หน่วยเป็นพอยท์ |
| y | **float** | พิกัด y ของตาราง หน่วยเป็นพอยท์ |
| column_widths | **List[float]** | อาร์เรย์ของตัวเลขทศนิยมที่แสดงความกว้างของคอลัมน์ของตาราง<br/><br/>            หน่วยเป็นพอยท์ |
| row_heights | **List[float]** | อาร์เรย์ของตัวเลขทศนิยมที่แสดงความสูงของแถวของตาราง<br/><br/>            หน่วยเป็นพอยท์ |
