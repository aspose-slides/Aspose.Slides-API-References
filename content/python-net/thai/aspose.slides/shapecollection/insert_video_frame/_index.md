## insert_video_frame(self, index, x, y, width, height, fname) {#int-float-float-float-float-str}
สร้าง video frame ใหม่และแทรกลงในคอลเลกชันของ shape ที่ตำแหน่ง index ที่ระบุ

### ผลลัพธ์

อ็อบเจ็กต์ที่สร้างใหม่ [`IVideoFrame`](/slides/python-net/th/aspose.slides/ivideoframe).

```python
def insert_video_frame(self, index, x, y, width, height, fname):
    ...
```

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| :- | :- | :- |
| index | **int** | ดัชนีเริ่มจากศูนย์ที่ใช้แทรก video frame |
| x | **float** | พิกัด x ของ video frame ใหม่ หน่วยเป็น points |
| y | **float** | พิกัด y ของ video frame ใหม่ หน่วยเป็น points |
| width | **float** | ความกว้างของ video frame ใหม่ หน่วยเป็น points |
| height | **float** | ความสูงของ video frame ใหม่ หน่วยเป็น points |
| fname | **str** | เส้นทางหรือชื่อไฟล์วิดีโอที่จะฝัง |
