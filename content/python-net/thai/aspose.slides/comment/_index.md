## คลาส Comment

แสดงถึงความคิดเห็นบนสไลด์.

ประเภท Comment เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`text`](/slides/python-net/th/aspose.slides/comment/text/) | คืนค่า หรือ กำหนดข้อความธรรมดาของความคิดเห็นบนสไลด์.<br/>            อ่าน/เขียน **str**. |
| [`created_time`](/slides/python-net/th/aspose.slides/comment/created_time/) | คืนค่า หรือ กำหนดเวลาการสร้างความคิดเห็น.<br/>            การตั้งค่าคุณสมบัตินี้เป็น **System.DateTime** หมายความว่าไม่ได้ตั้งค่าเวลาให้ความคิดเห็น.<br/>            อ่าน/เขียน **System.DateTime**. |
| [`slide`](/slides/python-net/th/aspose.slides/comment/slide/) | คืนค่า หรือ กำหนดสไลด์แม่ของความคิดเห็น.<br/>            อ่านอย่างเดียว [`ISlide`](/slides/python-net/th/aspose.slides/islide). |
| [`author`](/slides/python-net/th/aspose.slides/comment/author/) | คืนค่าผู้เขียนของความคิดเห็น.<br/>            อ่านอย่างเดียว [`ICommentAuthor`](/slides/python-net/th/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/th/aspose.slides/comment/position/) | คืนค่า หรือ กำหนดตำแหน่งของความคิดเห็นบนสไลด์.<br/>            อ่าน/เขียน **aspose.slides.PointF**. |
| [`parent_comment`](/slides/python-net/th/aspose.slides/comment/parent_comment/) | รับหรือกำหนดความคิดเห็นแม่.<br/>            อ่าน/เขียน [`IComment`](/slides/python-net/th/aspose.slides/icomment). |
