## IGroupShapeLock คลาส

กำหนดว่าการดำเนินการใดบ้างที่ถูกปิดการใช้งานบน GroupShape พาเรนต์

IGroupShapeLock ประเภท แสดงสมาชิกต่อไปนี้:

| คุณสมบัติ | คำอธิบาย |

| [`grouping_locked`](/slides/python-net/th/aspose.slides/igroupshapelock/grouping_locked/) | กำหนดว่าการเพิ่มรูปร่างนี้ไปยังกลุ่มถูกห้ามหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`ungrouping_locked`](/slides/python-net/th/aspose.slides/igroupshapelock/ungrouping_locked/) | กำหนดว่าการแยก groupshape นี้ถูกห้ามหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`select_locked`](/slides/python-net/th/aspose.slides/igroupshapelock/select_locked/) | กำหนดว่าการเลือกรูปร่างนี้ถูกห้ามหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`rotation_locked`](/slides/python-net/th/aspose.slides/igroupshapelock/rotation_locked/) | กำหนดว่าการเปลี่ยนมุมการหมุนของรูปร่างนี้ถูกห้ามหรือไม่.<br/>            อ่าน/เขียน **bool**. |
