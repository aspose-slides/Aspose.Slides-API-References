## PersistenceType การกำหนดค่า

ระบุวิธีที่ใช้ในการเก็บคุณสมบัติของ ActiveX คอนโทรล

ประเภท PersistenceType มีสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| NOT_DEFINED | ไม่ได้ระบุ Persistance id |
| PERSIST_PROPERTY_BAG | ระบุว่า ActiveX คอนโทรลถูกเก็บโดยใช้การเก็บข้อมูลแบบ property-bag < br/> การเก็บข้อมูลแบบ property-bag จะเก็บ ActiveX คอนโทรลโดยใช้คอลเลกชันของคู่ชื่อ < br/> และค่าที่ระบุข้อมูลที่ถูกเก็บโดย ActiveX คอนโทรล |
| PERSIST_STREAM | ระบุว่า ActiveX คอนโทรลถูกเก็บโดยใช้การเก็บข้อมูลแบบสตรีมที่ไม่รองรับการเริ่มต้น ActiveX คอนโทรลให้เป็นสถานะเริ่มต้น |
| PERSIST_STREAM_INIT | ระบุว่า ActiveX คอนโทรลถูกเก็บโดยใช้การเก็บข้อมูลแบบสตรีมที่รองรับการเริ่มต้น ActiveX คอนโทรลให้เป็นสถานะเริ่มต้น |
| PERSIST_STORAGE | ระบุว่า ActiveX คอนโทรลถูกเก็บโดยใช้การเก็บข้อมูลแบบ storage |
