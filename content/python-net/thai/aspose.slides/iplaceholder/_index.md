## IPlaceholder คลาส

เป็นตัวแทนของ placeholder บนสไลด์.

ประเภท IPlaceholder แสดงสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`orientation`](/slides/python-net/th/aspose.slides/iplaceholder/orientation/) | รับค่า orientation ของ placeholder.<br/>            อ่านอย่างเดียว [`Orientation`](/slides/python-net/th/aspose.slides/orientation). |
| [`size`](/slides/python-net/th/aspose.slides/iplaceholder/size/) | รับขนาดของ placeholder.<br/>            อ่านอย่างเดียว [`PlaceholderSize`](/slides/python-net/th/aspose.slides/placeholdersize). |
| [`type`](/slides/python-net/th/aspose.slides/iplaceholder/type/) | รับประเภทของ placeholder.<br/>            อ่านอย่างเดียว [`PlaceholderType`](/slides/python-net/th/aspose.slides/placeholdertype). |
| [`index`](/slides/python-net/th/aspose.slides/iplaceholder/index/) | รับดัชนีของ placeholder.<br/>            อ่านอย่างเดียว **int**. |
