## IEffectFormatEffectiveData คลาส

อ็อบเจ็กต์ที่ไม่สามารถแก้ไขได้ซึ่งบรรจุคุณสมบัติการจัดรูปแบบเอฟเฟกต์ที่มีผล

ประเภท IEffectFormatEffectiveData เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`is_no_effects`](/slides/python-net/th/aspose.slides/ieffectformateffectivedata/is_no_effects/) | คืนค่า true หากเอฟเฟ็กต์ทั้งหมดถูกปิดใช้งาน (เช่น เพิ่งสร้าง, วัตถุ EffectFormat เริ่มต้น).<br/>            อ่านอย่างเดียว **bool**. |
| [`blur_effect`](/slides/python-net/th/aspose.slides/ieffectformateffectivedata/blur_effect/) | เอฟเฟ็กต์เบลอ.<br/>            อ่านอย่างเดียว [`IBlurEffectiveData`](/slides/python-net/th/aspose.slides.effects/iblureffectivedata). |
| [`fill_overlay_effect`](/slides/python-net/th/aspose.slides/ieffectformateffectivedata/fill_overlay_effect/) | เอฟเฟ็กต์เติมซ้อนทับ.<br/>            อ่านอย่างเดียว [`IFillOverlayEffectiveData`](/slides/python-net/th/aspose.slides.effects/ifilloverlayeffectivedata). |
| [`glow_effect`](/slides/python-net/th/aspose.slides/ieffectformateffectivedata/glow_effect/) | เอฟเฟ็กต์เรืองแสง.<br/>            อ่านอย่างเดียว [`IGlowEffectiveData`](/slides/python-net/th/aspose.slides.effects/igloweffectivedata). |
| [`inner_shadow_effect`](/slides/python-net/th/aspose.slides/ieffectformateffectivedata/inner_shadow_effect/) | เงาภายใน.<br/>            อ่านอย่างเดียว [`IInnerShadowEffectiveData`](/slides/python-net/th/aspose.slides.effects/iinnershadoweffectivedata). |
| [`outer_shadow_effect`](/slides/python-net/th/aspose.slides/ieffectformateffectivedata/outer_shadow_effect/) | เงาภายนอก.<br/>            อ่านอย่างเดียว [`IOuterShadowEffectiveData`](/slides/python-net/th/aspose.slides.effects/ioutershadoweffectivedata). |
| [`preset_shadow_effect`](/slides/python-net/th/aspose.slides/ieffectformateffectivedata/preset_shadow_effect/) | เงาตั้งล่วงหน้า.<br/>            อ่านอย่างเดียว [`IPresetShadowEffectiveData`](/slides/python-net/th/aspose.slides.effects/ipresetshadoweffectivedata). |
| [`reflection_effect`](/slides/python-net/th/aspose.slides/ieffectformateffectivedata/reflection_effect/) | การสะท้อน.<br/>            อ่านอย่างเดียว [`IReflectionEffectiveData`](/slides/python-net/th/aspose.slides.effects/ireflectioneffectivedata). |
| [`soft_edge_effect`](/slides/python-net/th/aspose.slides/ieffectformateffectivedata/soft_edge_effect/) | ขอบนุ่มนวล.<br/>            อ่านอย่างเดียว [`ISoftEdgeEffectiveData`](/slides/python-net/th/aspose.slides.effects/isoftedgeeffectivedata). |

### หมายเหตุ

ส่วนต่อประสานนี้ใช้ร่วมกับส่วนต่อประสาน [`IEffectFormat`](/slides/python-net/th/aspose.slides/ieffectformat) เพื่อคืนค่า การจัดรูปแบบที่มีผลโดยใช้การสืบทอด.
