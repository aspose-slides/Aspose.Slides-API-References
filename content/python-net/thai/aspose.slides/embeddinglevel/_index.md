## EmbeddingLevel enumeration
แสดงสิทธิ์การให้สิทธิ์การใช้ลิขสิทธิ์สำหรับการฝังแบบอักษร.

ประเภท EmbeddingLevel เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| INSTALLABLE | แบบอักษรที่มีการตั้งค่านี้ระบุว่าสามารถฝังและติดตั้งอย่างถาวรบนระบบระยะไกลโดยแอปพลิเคชัน <br/>            ผู้ใช้ระบบระยะไกลจะได้รับสิทธิ์ หน้าที่ และลิขสิทธิ์เดียวกันสำหรับแบบอักษรนั้นเช่นเดียวกับผู้ซื้อแบบอักษรต้นฉบับ <br/>            และต้องปฏิบัติตามข้อตกลงการใช้งานสำหรับผู้ใช้ปลายสุด ลิขสิทธิ์ สิทธิบัตรการออกแบบ และ/หรือเครื่องหมายการค้าที่เหมือนกับผู้ซื้อแรก. |
| RESTRICTED | แบบอักษรที่มีบิตนี้ตั้งค่าเท่านั้นต้องไม่ถูกแก้ไข ฝัง หรือตอบโอนในรูปแบบใด ๆ หากไม่ได้รับอนุญาตจากเจ้าของลิขสิทธิ์ก่อน. |
| PREVIEW_PRINT | เมื่อบิตนี้ถูกตั้งค่า แบบอักษรสามารถฝังได้และโหลดชั่วคราวบนระบบระยะไกล เอกสารที่มีแบบอักษร Preview & <br/>            Print ต้องเปิดในโหมด "read-only;" ไม่สามารถแก้ไขเอกสารได้. |
| EDITABLE | เมื่อบิตนี้ถูกตั้งค่า แบบอักษรสามารถฝังได้แต่ต้องติดตั้งชั่วคราวบนระบบอื่นเท่านั้น ในการเปรียบเทียบกับแบบอักษร Preview & <br/>            Print เอกสารที่มีแบบอักษร Editable สามารถเปิดเพื่ออ่านได้ การแก้ไขได้รับอนุญาตและการเปลี่ยนแปลงสามารถบันทึกได้. |
| NO_SUBSETTING | เมื่อบิตนี้ถูกตั้งค่า แบบอักษรไม่สามารถทำ subset ก่อนการฝังได้ การจำกัดการฝังอื่น ๆ ที่ระบุในบิต 0-3 และ 9 ยังใช้เช่นกัน. |
| BITMAP_ONLY | เมื่อบิตนี้ถูกตั้งค่า จะฝังเฉพาะบิตแมพที่อยู่ในแบบอักษรเท่านั้น ไม่สามารถฝังข้อมูลโครงร่างได้ หากไม่มีบิตแมพในแบบอักษร <br/>            แบบอักษรจะถือว่าไม่สามารถฝังได้และบริการการฝังจะล้มเหลว. |
