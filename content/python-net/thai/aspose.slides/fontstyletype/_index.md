## FontStyleType enum

กำหนดรูปแบบการจัดรูปแบบที่สามารถนำไปใช้กับข้อความได้

ประเภท FontStyleType เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| REGULAR | ข้อความทั่วไป |
| BOLD | ข้อความหนา |
| ITALIC | ข้อความเอียง |
| UNDERLINE | ข้อความที่มีขีดเส้นใต้ |
| STRIKEOUT | ข้อความที่ขีดผ่านด้วยเส้นแนวนอน |
