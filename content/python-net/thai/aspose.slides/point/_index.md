## Point คลาส

แทนค่าคู่ลำดับของพิกัดจำนวนเต็ม x-และ y-ที่กำหนดจุดในระนาบสองมิติ เข้ากันได้กับ .NET `System.Drawing.Point`.

ประเภท Point มีสมาชิกต่อไปนี้:

## ตัวสร้าง

| คอนสตรัคเตอร์ | คำอธิบาย |
| :- | :- |
| [`__init__(self, x=0, y=0)`](/slides/python-net/th/aspose.slides/point/__init__/#int-int) | สร้างจุดด้วยพิกัดที่ระบุ ค่า Float จะถูกตัดลงเป็นจำนวนเต็ม. |

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`x`](/slides/python-net/th/aspose.slides/point/x/) | รับหรือกำหนดค่า x-coordinate ของจุดนี้.<br/>            อ่าน/เขียน **int**. |
| [`y`](/slides/python-net/th/aspose.slides/point/y/) | รับหรือกำหนดค่า y-coordinate ของจุดนี้.<br/>            อ่าน/เขียน **int**. |

### หมายเหตุ

จุดจะถูกเปรียบเทียบโดยพิกัดของพวกมันด้วย `==` และสามารถใช้เป็นคีย์ของพจนานุกรมหรือเป็นสมาชิกของเซ็ตได้.
