## IResourceLoadingArgs คลาส

อินเทอร์เฟซสำหรับอาร์กิวเมนต์การโหลดทรัพยากรภายนอก

ประเภท IResourceLoadingArgs เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`original_uri`](/slides/python-net/th/aspose.slides/iresourceloadingargs/original_uri/) | URI ดั้งเดิมของทรัพยากรตามที่ระบุในงานนำเสนอที่นำเข้า. |
| [`uri`](/slides/python-net/th/aspose.slides/iresourceloadingargs/uri/) | URI ของทรัพยากรที่ใช้สำหรับการดาวน์โหลดหาก **Aspose.Slides.IResourceLoadingCallback.ResourceLoading(Aspose.Slide** <br/>            returns [`ResourceLoadingAction.DEFAULT`](/slides/python-net/th/aspose.slides/resourceloadingaction/DEFAULT). <br/>            โดยเริ่มต้นจะถูกตั้งค่าเป็น URI ดั้งเดิมของทรัพยากร แต่สามารถกำหนดค่าใหม่เป็นค่าใดก็ได้. |

## เมธอด

| เมธอด | คำอธิบาย |
| :- | :- |
| [`set_data(self, data)`](/slides/python-net/th/aspose.slides/iresourceloadingargs/set_data/#bytes) | ตั้งค่าข้อมูลที่ผู้ใช้ให้ของทรัพยากรซึ่งใช้หาก **Aspose.Slides.IResourceLoadingCallback.ResourceLoading(Aspose.Slide** <br/>            returns [`ResourceLoadingAction.USER_PROVIDED`](/slides/python-net/th/aspose.slides/resourceloadingaction/USER_PROVIDED). |
