## IGradientFormatEffectiveData คลาส

อ็อบเจ็กต์ที่ไม่สามารถเปลี่ยนแปลงได้ซึ่งมีคุณสมบัติการเติมสีไล่ระดับที่มีผล

ประเภท IGradientFormatEffectiveData เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`tile_flip`](/slides/python-net/th/aspose.slides/igradientformateffectivedata/tile_flip/) | ส่งกลับโหมดการพลิกของการไล่สี.<br/>            อ่านอย่างเดียว [`TileFlip`](/slides/python-net/th/aspose.slides/tileflip). |
| [`gradient_direction`](/slides/python-net/th/aspose.slides/igradientformateffectivedata/gradient_direction/) | ส่งกลับสไตล์ของการไล่สี.<br/>            อ่านอย่างเดียว [`GradientDirection`](/slides/python-net/th/aspose.slides/gradientdirection). |
| [`linear_gradient_angle`](/slides/python-net/th/aspose.slides/igradientformateffectivedata/linear_gradient_angle/) | ส่งกลับมุมของการไล่สี.<br/>            อ่านอย่างเดียว **float**. |
| [`linear_gradient_scaled`](/slides/python-net/th/aspose.slides/igradientformateffectivedata/linear_gradient_scaled/) | กำหนดว่าการไล่สีถูกสเกลหรือไม่.<br/>            อ่านอย่างเดียว **bool**. |
| [`gradient_shape`](/slides/python-net/th/aspose.slides/igradientformateffectivedata/gradient_shape/) | ส่งกลับรูปร่างของการไล่สี.<br/>            อ่านอย่างเดียว [`GradientShape`](/slides/python-net/th/aspose.slides/gradientshape). |
| [`gradient_stops`](/slides/python-net/th/aspose.slides/igradientformateffectivedata/gradient_stops/) | ส่งกลับคอลเลกชันของจุดหยุดการไล่สี.<br/>            อ่านอย่างเดียว [`IGradientStopCollectionEffectiveData`](/slides/python-net/th/aspose.slides/igradientstopcollectioneffectivedata). |


### หมายเหตุ

อินเทอร์เฟซนี้ใช้เป็นส่วนหนึ่งของ [`IFillFormatEffectiveData`](/slides/python-net/th/aspose.slides/ifillformateffectivedata) และ [`ILineFillFormatEffectiveData`](/slides/python-net/th/aspose.slides/ilinefillformateffectivedata).
