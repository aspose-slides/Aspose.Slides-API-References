## ViewType การนับ

ประเภทมุมมองการนำเสนอ

ประเภท ViewType มีสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| NOT_DEFINED | ค่าไม่ได้กำหนด |
| SLIDE_VIEW | มุมมองสไลด์ปกติ |
| SLIDE_MASTER_VIEW | มุมมองสไลด์มาสเตอร์ |
| NOTES_VIEW | มุมมองบันทึกย่อ |
| HANDOUT_VIEW | มุมมองแจกจ่าย |
| NOTES_MASTER_VIEW | มุมมองบันทึกย่อมาสเตอร์ |
| OUTLINE_VIEW | มุมมองโครงร่าง |
| SLIDE_SORTER_VIEW | มุมมองจัดเรียงสไลด์ |
| SLIDE_THUMBNAIL_VIEW | มุมมองภาพย่อสไลด์ |
