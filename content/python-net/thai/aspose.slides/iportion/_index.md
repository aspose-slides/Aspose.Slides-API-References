## คลาส IPortion

แสดงส่วนของข้อความภายในย่อหน้าข้อความ

ประเภท IPortion เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`portion_format`](/slides/python-net/th/aspose.slides/iportion/portion_format/) | คืนค่าออบเจกต์การจัดรูปแบบที่มีคุณสมบัติการจัดรูปแบบที่กำหนดอย่างชัดเจนของส่วนข้อความโดยไม่มีการสืบทอดถูกใช้<br/>            อ่านอย่างเดียว [`IPortionFormat`](/slides/python-net/th/aspose.slides/iportionformat). |
| [`text`](/slides/python-net/th/aspose.slides/iportion/text/) | รับหรือกำหนดข้อความธรรมดาของส่วน<br/>            อ่าน/เขียน **str**. |
| [`field`](/slides/python-net/th/aspose.slides/iportion/field/) | คืนค่าเขตข้อมูลของส่วนนี้<br/>            อ่านอย่างเดียว [`IField`](/slides/python-net/th/aspose.slides/ifield). |
| [`slide`](/slides/python-net/th/aspose.slides/iportion/slide/) |  |
| [`presentation`](/slides/python-net/th/aspose.slides/iportion/presentation/) |  |
