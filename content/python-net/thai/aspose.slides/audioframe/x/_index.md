## x คุณสมบัติ
รับหรือกำหนดพิกัด x ของมุมซ้ายบนของรูปร่าง, วัดเป็นจุด.
            อ่าน/เขียน **float**.


### หมายเหตุ

ค่าที่ส่งคืนจะถูกกำหนดเสมอและไม่เคยเป็น **float**.
            ค่าที่กำหนดต้องได้รับการกำหนดเช่นกัน; กำหนด **float** เพียงคุณสมบัติของอินสแตนซ์ `RawFrame` เท่านั้น.

### คำนิยาม:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
