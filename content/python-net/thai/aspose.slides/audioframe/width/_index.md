## width คุณสมบัติ
รับหรือกำหนดค่า width ของรูปร่าง, วัดเป็นจุด.
อ่าน/เขียน **float**.

### หมายเหตุ

ค่าที่ส่งคืนจะเป็นค่าที่กำหนดเสมอและไม่เป็น **float**.
ค่าที่กำหนดต้องเป็นค่าที่กำหนดเช่นกัน; กำหนด **float** เฉพาะให้กับคุณสมบัติของอินสแตนซ์ `RawFrame` เท่านั้น.
