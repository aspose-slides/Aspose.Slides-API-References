## การกำหนดค่า LoadFormat

บ่งบอกรูปแบบของเอกสารที่ต้องการโหลด

ประเภท LoadFormat มีสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| AUTO | สั่งให้ Aspose.Slides จำแนกรูปแบบโดยอัตโนมัติ. |
| PPT | Microsoft PowerPoint 97-2003 การนำเสนอ. |
| PPS | Microsoft PowerPoint 97-2003 การแสดงสไลด์. |
| PPTX | Microsoft Office Open XML PresentationML เอกสาร. |
| PPSX | Microsoft Office Open XML PresentationML การแสดงสไลด์. |
| ODP | OpenOffice ODF การนำเสนอ. |
| POTX | Microsoft Office Open XML PresentationML แม่แบบ. |
| PPTM | Microsoft Office Open XML PresentationML เอกสารที่รองรับมาโคร. |
| PPSM | Microsoft Office Open XML PresentationML การแสดงสไลด์ที่รองรับมาโคร. |
| POTM | Microsoft Office Open XML PresentationML แม่แบบที่รองรับมาโคร. |
| OTP | OpenOffice OTP แม่แบบการนำเสนอ. |
| PPT95 | Microsoft PowerPoint 95 การนำเสนอ. |
| POT | Microsoft PowerPoint 97-2003 แม่แบบการนำเสนอ. |
| FODP | Flat XML ODF การนำเสนอ. |
| UNKNOWN | ประเภทรูปแบบไฟล์ที่ไม่รู้จัก |
