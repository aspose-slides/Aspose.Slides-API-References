## ShapeThumbnailBounds การนับ

การนับประเภทของขอบเขตภาพย่อของรูปร่าง.

ประเภท ShapeThumbnailBounds เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| SLIDE | ภาพย่อของรูปร่างจะมีขนาดเท่ากับขนาดสไลด์.<br/>            ตำแหน่งของรูปร่างจะถูกบันทึกไว้. |
| SHAPE | ภาพย่อของรูปร่างจะมีขนาดเท่ากับสี่เหลี่ยมขอบเขตของรูปร่าง<br/>            โดยคำนึงถึงการตั้งค่าขอบเส้นของรูปร่าง. |
| APPEARANCE | ภาพย่อของรูปร่างจะมีขนาดเท่ากับการแสดงผลของรูปร่าง (ภายในขอบเขตของสไลด์). <br/>            อาจมีกรณีที่การแสดงผลของรูปร่างไม่พอดีกับขอบเขตของรูปร่าง เช่น<br/>            การหมุน, มุมมิตเตอร์ของมุมคม, เอฟเฟกต์ 3 มิติ, ฯลฯ. |
