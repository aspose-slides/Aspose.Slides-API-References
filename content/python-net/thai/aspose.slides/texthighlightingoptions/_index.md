## คลาส TextHighlightingOptions

แสดงตัวเลือกที่สามารถใช้เพื่อไฮไลต์ข้อความในกรอบข้อความ。

ประเภท TextHighlightingOptions เปิดเผยสมาชิกต่อไปนี้：

## ตัวสร้าง

| ตัวสร้าง | คำอธิบาย |
| :- | :- |
| [`__init__(self)`](/slides/python-net/th/aspose.slides/texthighlightingoptions/__init__/#) | สร้างตัวเลือกการไฮไลต์ข้อความค่าเริ่มต้นใหม่ |

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`case_sensitive`](/slides/python-net/th/aspose.slides/texthighlightingoptions/case_sensitive/) | กำหนดเป็น true เพื่อใช้การค้นหาแยกแยะตัวพิมพ์ใหญ่-เล็ก, false - ในอื่น ๆ.<br/>            อ่าน/เขียน **bool**. |
| [`whole_words_only`](/slides/python-net/th/aspose.slides/texthighlightingoptions/whole_words_only/) | กำหนดเป็น true เพื่อจับคู่เฉพาะคำเต็ม, false - ในอื่น ๆ.<br/>            อ่าน/เขียน **bool**. |
