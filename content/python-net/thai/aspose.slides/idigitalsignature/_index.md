## IDigitalSignature คลาส

ลายเซ็นดิจิทัลในไฟล์ที่ลงชื่อ

ประเภท IDigitalSignature เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`certificate`](/slides/python-net/th/aspose.slides/idigitalsignature/certificate/) | วัตถุใบรับรองที่ใช้ในการลงนามเอกสาร.<br/>            อ่านอย่างเดียว **System.Security.Cryptography.X509Certificates.X509Certificate2**. |
| [`is_valid`](/slides/python-net/th/aspose.slides/idigitalsignature/is_valid/) | หากลายเซ็นดิจิทัลนี้ถูกต้องและเอกสารถูกเปลี่ยนแปลงไม่ได้ ค่าดังกล่าวจะเป็น true.<br/>            อ่านอย่างเดียว **bool**. |
| [`sign_time`](/slides/python-net/th/aspose.slides/idigitalsignature/sign_time/) | เวลาที่เอกสารถูกลงนาม.<br/>            อ่านอย่างเดียว **System.DateTime**. |
| [`comments`](/slides/python-net/th/aspose.slides/idigitalsignature/comments/) | วัตถุประสงค์ของลายเซ็น.<br/>            อ่าน/เขียน **str**. |
