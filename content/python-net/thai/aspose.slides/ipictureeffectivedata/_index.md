## IPictureEffectiveData คลาส

อ็อบเจ็กต์ที่ไม่เปลี่ยนแปลงซึ่งประกอบด้วยคุณสมบัติรูปภาพที่มีประสิทธิภาพ

ประเภท IPictureEffectiveData เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`image`](/slides/python-net/th/aspose.slides/ipictureeffectivedata/image/) | ส่งคืนรูปภาพที่ฝังอยู่.<br/>อ่านอย่างเดียว [`IPPImage`](/slides/python-net/th/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/th/aspose.slides/ipictureeffectivedata/link_path_long/) | ส่งคืน URL ของรูปภาพที่เชื่อมโยง.<br/>อ่านอย่างเดียว **str**. |
| [`image_transform`](/slides/python-net/th/aspose.slides/ipictureeffectivedata/image_transform/) | ส่งคืนคอลเลกชันของเอฟเฟกต์การแปลงรูปภาพ.<br/>อ่านอย่างเดียว [`IImageTransformOCollectionEffectiveData`](/slides/python-net/th/aspose.slides.effects/iimagetransformocollectioneffectivedata). |

### หมายเหตุ

อินเทอร์เฟซนี้ใช้เป็นส่วนหนึ่งของ [`IPictureFillFormatEffectiveData`](/slides/python-net/th/aspose.slides/ipicturefillformateffectivedata) และ [`IBulletFormatEffectiveData`](/slides/python-net/th/aspose.slides/ibulletformateffectivedata).
