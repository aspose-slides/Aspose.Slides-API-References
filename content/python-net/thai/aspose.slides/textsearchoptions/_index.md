## TextSearchOptions คลาส

แทนตัวเลือกที่สามารถใช้เพื่อค้นหาขข้อความใน Presentation, Slide หรือ TextFrame.

ประเภท TextSearchOptions มีสมาชิกต่อไปนี้:

## ตัวสร้าง

| ตัวสร้าง | คำอธิบาย |
| :- | :- |
| [`__init__(self)`](/slides/python-net/th/aspose.slides/textsearchoptions/__init__/#) | สร้างตัวเลือกการค้นหาขข้อความเริ่มต้นใหม่ |

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`case_sensitive`](/slides/python-net/th/aspose.slides/textsearchoptions/case_sensitive/) | ตั้งค่า true เพื่อใช้การค้นหาที่แยกแยะตัวพิมพ์ใหญ่-เล็ก, false - หากไม่ใช่.<br/>            อ่าน/เขียน **bool**. |
| [`whole_words_only`](/slides/python-net/th/aspose.slides/textsearchoptions/whole_words_only/) | ตั้งค่า true เพื่อให้ตรงกับคำเต็มเท่านั้น, false - หากไม่ใช่.<br/>            อ่าน/เขียน **bool**. |
| [`include_notes`](/slides/python-net/th/aspose.slides/textsearchoptions/include_notes/) | ตั้งค่า `true` เพื่อรวมข้อความที่อยู่ในบันทึกสไลด์ ([`NotesSlide`](/slides/python-net/th/aspose.slides/notesslide)) <br/>            เมื่อทำการค้นหาขข้อความ, การแทนที่, หรือการเน้นข้อความ.<br/>            ค่าเริ่มต้นคือ `false`. |
