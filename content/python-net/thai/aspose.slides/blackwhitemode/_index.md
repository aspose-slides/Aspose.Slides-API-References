## BlackWhiteMode การกำหนดค่า

กำหนดว่ารูปร่างที่มีสีจะถูกแปลงเป็นสีขาวและดำอย่างไร

ประเภท BlackWhiteMode มีสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| NOT_DEFINED | คุณสมบัตินี้ไม่ได้ตั้งค่า |
| COLOR | วัตถุแสดงผลด้วยสีปกติ |
| AUTOMATIC | วัตถุแสดงผลด้วยสีอัตโนมัติ |
| GRAY | วัตถุแสดงผลด้วยสีเทา |
| LIGHT_GRAY | วัตถุแสดงผลด้วยสีเทาอ่อน |
| INVERSE_GRAY | วัตถุแสดงผลด้วยสีเทาแบบกลับด้าน |
| GRAY_WHITE | วัตถุแสดงผลด้วยสีเทาและสีขาว |
| BLACK_GRAY | วัตถุแสดงผลด้วยสีดำและสีเทา |
| BLACK_WHITE | วัตถุแสดงผลด้วยสีดำและสีขาว |
| BLACK | วัตถุแสดงผลด้วยสีดำอย่างเดียว |
| WHITE | วัตถุแสดงผลด้วยสีขาว |
| HIDDEN | วัตถุไม่ได้แสดงผล |
