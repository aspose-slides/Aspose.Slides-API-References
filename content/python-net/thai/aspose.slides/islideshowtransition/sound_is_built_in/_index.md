## sound_is_built_in คุณสมบัติ
ระบุว่าเสียงนี้เป็นเสียงในตัวหรือไม่ หากแอตทริบิวต์นี้ตั้งค่าเป็น true แล้ว
            แอปพลิเคชันที่สร้างขึ้นจะได้รับการแจ้งให้ตรวจสอบแอตทริบิวต์ name ที่ระบุสำหรับเสียงนี้
            ในรายการเสียงในตัวของมันและจากนั้นสามารถแสดงชื่อหรือ UI แบบกำหนดเองตามความจำเป็น
            อ่าน-เขียน **bool**.
