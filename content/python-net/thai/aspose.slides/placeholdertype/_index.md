## PlaceholderType enumeration

แสดงประเภทของ placeholder.

ประเภท PlaceholderType เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| TITLE | ชื่อเรื่อง. |
| BODY | เนื้อหา. |
| CENTERED_TITLE | ชื่อเรื่องตรงกลาง. |
| SUBTITLE | คำบรรยายย่อย. |
| DATE_AND_TIME | วันที่และเวลา. |
| SLIDE_NUMBER | หมายเลขสไลด์. |
| FOOTER | ส่วนท้าย. |
| HEADER | ส่วนหัว. |
| OBJECT | วัตถุ. |
| CHART | แผนภูมิ. |
| TABLE | ตาราง. |
| CLIP_ART | คลิปอาร์ต. |
| DIAGRAM | แผนภาพ. |
| MEDIA | สื่อ. |
| SLIDE_IMAGE | ภาพสไลด์. |
| PICTURE | รูปภาพ. |
