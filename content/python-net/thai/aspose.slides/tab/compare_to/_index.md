## compare_to(self, obj) {#any}

### คืนค่า

* < 0 - อินสแตนซ์นี้น้อยกว่า obj. = 0 - อินสแตนซ์นี้เท่ากับ obj. > 0 - อินสแตนซ์นี้มากกว่า obj.
* < 0 - อินสแตนซ์นี้น้อยกว่า obj. = 0 - อินสแตนซ์นี้เท่ากับ obj. > 0 - อินสแตนซ์นี้มากกว่า obj.
