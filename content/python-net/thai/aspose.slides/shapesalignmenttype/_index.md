## ShapesAlignmentType การจำแนก

กำหนดวิธีการเปลี่ยนตำแหน่งของรูปร่างที่เลือกบนสไลด์

ประเภท ShapesAlignmentType มีสมาชิกดังต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| ALIGN_LEFT | จัดชิดซ้าย |
| ALIGN_RIGHT | จัดชิดขวา |
| ALIGN_CENTER | จัดกึ่งกลาง |
| ALIGN_TOP | จัดบน |
| ALIGN_MIDDLE | จัดกลางแนวตั้ง |
| ALIGN_BOTTOM | จัดล่าง |
| DISTRIBUTE_HORIZONTALLY | กระจายแนวนอน |
| DISTRIBUTE_VERTICALLY | กระจายแนวตั้ง |
