## AudioPlayModePreset การระบุค่า

ค่าคงที่ที่กำหนดวิธีการเล่นเสียง

ประเภท AudioPlayModePreset แสดงสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| MIXED |  |
| AUTO | เล่นโดยอัตโนมัติ. |
| ON_CLICK | เล่นเฉพาะเมื่อคลิกที่ไอคอน |
| ALL_SLIDES | เล่นบนทุกสไลด์. <br/> กรุณาใช้ [`IAudioFrame.play_across_slides`](/slides/python-net/th/aspose.slides/iaudioframe/play_across_slides) property แทน.<br/> องค์ประกอบนี้ล้าสมัยตั้งแต่ PowerPoint 2013. |
| IN_CLICK_SEQUENCE | เล่นโดยอัตโนมัติพร้อมกับการคลิก. |
