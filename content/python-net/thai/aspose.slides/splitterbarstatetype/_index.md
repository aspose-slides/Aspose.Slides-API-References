## SplitterBarStateType การจำแนกประเภท

ระบุสถานะที่แถบแบ่งควรแสดง แถบแบ่งจะแยกพื้นที่หลักและพื้นที่รองภายในพื้นที่การแสดงผล

ประเภท SplitterBarStateType เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| MINIMIZED | พื้นที่หลักใช้พื้นที่การแสดงผลน้อยที่สุดที่แอปพลิเคชันอนุญาต |
| RESTORED | พื้นที่หลักมีขนาดกลางที่ระบุเฉพาะ |
| MAXIMIZED | พื้นที่หลักใช้พื้นที่การแสดงผลมากที่สุดที่แอปพลิเคชันอนุญาต |
