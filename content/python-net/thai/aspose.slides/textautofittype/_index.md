## TextAutofitType การนับ

แสดงโหมดการปรับอัตโนมัติของข้อความ

ประเภท TextAutofitType มีสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| NOT_DEFINED | ไม่ได้กำหนด |
| NONE | ไม่มีการปรับอัตโนมัติ |
| NORMAL | AutoFit ปกติ. ขนาดฟอนต์และระยะห่างบรรทัดจะถูกลดลงเพื่อให้พอดีกับรูปร่าง |
| SHAPE | AutoFit รูปร่าง. ขนาดรูปร่างจะถูกเปลี่ยนเพื่อให้พอดีกับข้อความ |
