## ICustomXmlPart คลาส

แสดงส่วน XML แบบกำหนดเอง

ประเภท ICustomXmlPart เปิดให้เข้าถึงสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`xml_as_string`](/slides/python-net/th/aspose.slides/icustomxmlpart/xml_as_string/) | ส่งคืนหรือกำหนดข้อมูล xml เป็นสตริง UTF-8.<br/>อ่าน/เขียน **str**.<br/>ค่าเป็น `None`.ค่าเป็นค่าว่างหรือข้อมูล xml ไม่ถูกต้อง. |
| [`xml_data`](/slides/python-net/th/aspose.slides/icustomxmlpart/xml_data/) | ส่งคืนหรือกำหนดข้อมูล xml.<br/>อ่าน/เขียน **int**[].<br/>ค่าเป็น `None`.ค่าเป็นค่าว่างหรือข้อมูล xml ไม่ถูกต้อง. |
| [`item_id`](/slides/python-net/th/aspose.slides/icustomxmlpart/item_id/) | ระบุตัวระบุตัวอักษรที่ไม่ซ้ำกันทั่วโลก (GUID) ที่ระบุส่วน custom XML เดียวภายในเอกสาร Office Open XML.<br/>อ่านอย่างเดียว **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/th/aspose.slides/icustomxmlpart/namespace_schemas/) | คืนคอลเลกชันของสคีม่า XML ที่เชื่อมโยงกับส่วน custom XML.<br/>อ่านอย่างเดียว **str**[]. |

## เมธอด

| เมธอด | คำอธิบาย |
| :- | :- |
| [`remove(self)`](/slides/python-net/th/aspose.slides/icustomxmlpart/remove/#) | ลบส่วน custom xml จากการนำเสนอ. |
