## IPictureFillFormatEffectiveData คลาส

อ็อบเจ็กต์ที่ไม่เปลี่ยนแปลงซึ่งบรรจุคุณสมบัติของการเติมรูปภาพ

The IPictureFillFormatEffectiveData type มีสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | รายละเอียด |
| :- | :- |
| [`dpi`](/slides/python-net/th/aspose.slides/ipicturefillformateffectivedata/dpi/) | ส่งคืน dpi ที่ใช้ในการเติมรูปภาพ.<br/>            อ่านอย่างเดียว **int**. |
| [`picture_fill_mode`](/slides/python-net/th/aspose.slides/ipicturefillformateffectivedata/picture_fill_mode/) | ส่งคืนโหมดการเติมรูปภาพ.<br/>            อ่านอย่างเดียว [`PictureFillMode`](/slides/python-net/th/aspose.slides/picturefillmode). |
| [`picture`](/slides/python-net/th/aspose.slides/ipicturefillformateffectivedata/picture/) | ส่งคืนรูปภาพ.<br/>            อ่านอย่างเดียว [`IPictureEffectiveData`](/slides/python-net/th/aspose.slides/ipictureeffectivedata). |
| [`crop_left`](/slides/python-net/th/aspose.slides/ipicturefillformateffectivedata/crop_left/) | ส่งคืนจำนวนเปอร์เซ็นต์ของความกว้างภาพจริงที่ถูกตัดออก<br/>            ด้านซ้ายของรูปภาพ. <br/>            อ่านอย่างเดียว **float**. |
| [`crop_top`](/slides/python-net/th/aspose.slides/ipicturefillformateffectivedata/crop_top/) | ส่งคืนจำนวนเปอร์เซ็นต์ของความสูงภาพจริงที่ถูกตัดออก<br/>            ด้านบนของรูปภาพ. <br/>            อ่านอย่างเดียว **float**. |
| [`crop_right`](/slides/python-net/th/aspose.slides/ipicturefillformateffectivedata/crop_right/) | ส่งคืนจำนวนเปอร์เซ็นต์ของความกว้างภาพจริงที่ถูกตัดออก<br/>            ด้านขวาของรูปภาพ. <br/>            อ่านอย่างเดียว **float**. |
| [`crop_bottom`](/slides/python-net/th/aspose.slides/ipicturefillformateffectivedata/crop_bottom/) | ส่งคืนจำนวนเปอร์เซ็นต์ของความสูงภาพจริงที่ถูกตัดออก<br/>            ด้านล่างของรูปภาพ. <br/>            อ่านอย่างเดียว **float**. |
