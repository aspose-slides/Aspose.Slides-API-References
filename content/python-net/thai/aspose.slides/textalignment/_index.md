## TextAlignment enumeration

แสดงถึงรูปแบบการจัดแนวข้อความที่แตกต่างกัน

ประเภท TextAlignment เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| NOT_DEFINED | ค่าเริ่มต้นของการจัดแนว |
| LEFT | การจัดแนวซ้าย |
| CENTER | การจัดแนวศูนย์กลาง |
| RIGHT | การจัดแนวขวา |
| JUSTIFY | การจัดแนวแบบเต็ม |
| JUSTIFY_LOW | การจัดแนว Kashida ต่ำ |
| DISTRIBUTED | การจัดแนวแบบกระจาย |
