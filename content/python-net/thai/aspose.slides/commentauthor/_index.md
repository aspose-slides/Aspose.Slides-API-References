## CommentAuthor คลาส

แสดงถึงผู้เขียนความคิดเห็น

ประเภท CommentAuthor เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`name`](/slides/python-net/th/aspose.slides/commentauthor/name/) | คืนค่า หรือกำหนดชื่อของผู้เขียน.<br/>            Read/write **str**. |
| [`initials`](/slides/python-net/th/aspose.slides/commentauthor/initials/) | คืนค่า หรือกำหนดชื่อย่อของผู้เขียน.<br/>            Read/write **str**. |
| [`comments`](/slides/python-net/th/aspose.slides/commentauthor/comments/) | คืนค่าคอลเลกชันของความคิดเห็นที่สร้างโดยผู้เขียนนี้.<br/>            Read-only [`ICommentCollection`](/slides/python-net/th/aspose.slides/icommentcollection). |
