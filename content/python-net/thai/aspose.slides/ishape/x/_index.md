## x คุณสมบัติ
รับหรือกำหนดค่าพิกัด x ของมุมซ้ายบนของรูปร่าง, วัดเป็นจุด.
            อ่าน/เขียน **float**.


### หมายเหตุ

ค่าที่คืนกลับมาจะถูกกำหนดเสมอและไม่เคยเป็น **float**.
            ค่าที่กำหนดต้องถูกกำหนดเช่นกัน; กำหนด **float** เฉพาะให้กับคุณสมบัติของอินสแตนซ์ `RawFrame` เท่านั้น.

### คำนิยาม:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
