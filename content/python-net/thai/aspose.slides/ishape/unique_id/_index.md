## unique_id คุณสมบัติ
Returns an internal, presentation-scoped identifier intended for use by add-ins or other code.
            เนื่องจากค่าตัวนี้อาจถูกกำหนดค่าใหม่โดยผู้ใช้หรือโดยโปรแกรม จึงไม่ควรถือว่าเป็นคีย์ที่ไม่ซ้ำกันแบบถาวร.
            อ่านอย่างเดียว **int**.
