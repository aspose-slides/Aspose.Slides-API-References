## ResourceLoadingAction การนับจำนวน

ระบุโหมดของการโหลดทรัพยากรภายนอก

ประเภท ResourceLoadingAction เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| DEFAULT | Aspose.Slides จะโหลดทรัพยากรภายนอกตามปกติ. |
| SKIP | Aspose.Slides จะข้ามการโหลดทรัพยากรภายนอก. จะเก็บเฉพาะลิงก์ที่ไม่มีข้อมูลสำหรับภาพ. |
| USER_PROVIDED | Aspose.Slides จะใช้ byte array ที่ผู้ใช้ให้ไว้ใน **Aspose.Slides.IResourceLoadingArgs.SetData(Syste** เป็นข้อมูลรูปภาพ. |
