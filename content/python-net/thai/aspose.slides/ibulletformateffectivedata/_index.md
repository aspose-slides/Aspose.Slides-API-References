## IBulletFormatEffectiveData คลาส

อ็อบเจ็กต์ที่ไม่มีการเปลี่ยนแปลงซึ่งบรรจุคุณสมบัติการจัดรูปแบบหัวข้อของย่อหน้าที่มีผล

ประเภท IBulletFormatEffectiveData จะเปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`type`](/slides/python-net/th/aspose.slides/ibulletformateffectivedata/type/) | คืนค่าชนิดหัวข้อของย่อหน้า.<br/>อ่านอย่างเดียว [`BulletType`](/slides/python-net/th/aspose.slides/bullettype). |
| [`char`](/slides/python-net/th/aspose.slides/ibulletformateffectivedata/char/) | คืนค่าตัวอักษรหัวข้อของย่อหน้า.<br/>อ่านอย่างเดียว **System.Char**. |
| [`actual_bullet_value`](/slides/python-net/th/aspose.slides/ibulletformateffectivedata/actual_bullet_value/) | คืนค่าจริงของหัวข้อสำหรับย่อหน้าหลัก.<br/>อ่านอย่างเดียว **str**. |
| [`font`](/slides/python-net/th/aspose.slides/ibulletformateffectivedata/font/) | คืนค่าแบบอักษรหัวข้อของย่อหน้า.<br/>อ่านอย่างเดียว [`IFontData`](/slides/python-net/th/aspose.slides/ifontdata). |
| [`height`](/slides/python-net/th/aspose.slides/ibulletformateffectivedata/height/) | คืนค่าความสูงของหัวข้อในย่อหน้า.<br/>อ่านอย่างเดียว **float**. |
| [`numbered_bullet_start_with`](/slides/python-net/th/aspose.slides/ibulletformateffectivedata/numbered_bullet_start_with/) | คืนตัวเลขแรกที่ใช้สำหรับกลุ่มหัวข้อเป็นลำดับเลข.<br/>อ่านอย่างเดียว **int**. |
| [`numbered_bullet_style`](/slides/python-net/th/aspose.slides/ibulletformateffectivedata/numbered_bullet_style/) | คืนรูปแบบของหัวข้อแบบลำดับเลข.<br/>อ่านอย่างเดียว [`NumberedBulletStyle`](/slides/python-net/th/aspose.slides/numberedbulletstyle). |
| [`is_bullet_hard_color`](/slides/python-net/th/aspose.slides/ibulletformateffectivedata/is_bullet_hard_color/) | กำหนดว่าหัวข้อมีสีของตนเองหรือสืบทอดมาจากส่วนแรกในย่อหน้า.<br/>คืนค่า **true** หากหัวข้อมีสีของตนเองและ **false** หากหัวข้อสืบทอดสีมาจากส่วนแรกในย่อหน้า.<br/>อ่านอย่างเดียว **bool**. |
| [`is_bullet_hard_font`](/slides/python-net/th/aspose.slides/ibulletformateffectivedata/is_bullet_hard_font/) | กำหนดว่าหัวข้อมีแบบอักษรของตนเองหรือสืบทอดมาจากส่วนแรกในย่อหน้า.<br/>คืนค่า **true** หากหัวข้อมีแบบอักษรของตนเองและ **true** หากหัวข้อสืบทอดแบบอักษรจากส่วนแรกในย่อหน้า.<br/>อ่านอย่างเดียว **bool**. |
| [`picture`](/slides/python-net/th/aspose.slides/ibulletformateffectivedata/picture/) | คืนรูปภาพที่ใช้เป็นหัวข้อในย่อหน้า.<br/>อ่านอย่างเดียว [`IPictureEffectiveData`](/slides/python-net/th/aspose.slides/ipictureeffectivedata). |
| [`fill_format`](/slides/python-net/th/aspose.slides/ibulletformateffectivedata/fill_format/) | คืนรูปแบบการเติมสีหัวข้อของย่อหน้า.<br/>อ่านอย่างเดียว [`IFillFormatEffectiveData`](/slides/python-net/th/aspose.slides/ifillformateffectivedata). |
