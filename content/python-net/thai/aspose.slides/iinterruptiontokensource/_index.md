## IInterruptionTokenSource คลาส

เป็นตัวแทนของแหล่งที่มาของ [`IInterruptionToken`](/slides/python-net/th/aspose.slides/iinterruptiontoken).

ประเภท IInterruptionTokenSource เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`token`](/slides/python-net/th/aspose.slides/iinterruptiontokensource/token/) | ส่งคืนโทเคนใหม่ที่ผูกกับ [`IInterruptionTokenSource`](/slides/python-net/th/aspose.slides/iinterruptiontokensource) นี้. |
| [`is_interruption_requested`](/slides/python-net/th/aspose.slides/iinterruptiontokensource/is_interruption_requested/) | ส่งคืน true หากมีการขอการขัดจังหวะ, false ในกรณีอื่น. |

## เมธอด

| เมธอด | คำอธิบาย |
| :- | :- |
| [`interrupt(self)`](/slides/python-net/th/aspose.slides/iinterruptiontokensource/interrupt/#) | เริ่มต้นคำขอการขัดจังหวะ. |
