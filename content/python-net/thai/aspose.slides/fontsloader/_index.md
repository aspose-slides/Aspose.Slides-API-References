## FontsLoader คลาส

คลาสสำหรับโหลดแบบอักษรที่กำหนดโดยผู้ใช้.            
ควรใช้ก่อนสร้างวัตถุการนำเสนอใดๆ.

ประเภท FontsLoader เปิดเผยสมาชิกต่อไปนี้:

## เมธอด

| เมธอด | คำอธิบาย |
| :- | :- |
| [`load_external_fonts(directories)`](/slides/python-net/th/aspose.slides/fontsloader/load_external_fonts/#liststr) | เพิ่มโฟลเดอร์เพิ่มเติมเพื่อค้นหาแบบอักษร. |
| [`load_external_font(data)`](/slides/python-net/th/aspose.slides/fontsloader/load_external_font/#bytes) | เพิ่มแบบอักษรจากข้อมูลไบนารี |
| [`get_font_folders()`](/slides/python-net/th/aspose.slides/fontsloader/get_font_folders/#) | รับโฟลเดอร์แบบอักษร. รายการโฟลเดอร์ที่ถูกเพิ่มด้วยเมธอด LoadExternalFonts รวมถึงโฟลเดอร์แบบอักษรของระบบ |
| [`clear_cache()`](/slides/python-net/th/aspose.slides/fontsloader/clear_cache/#) | ปล่อยแบบอักษรกำหนดเองทั้งหมดที่ผู้ใช้กำหนด |
