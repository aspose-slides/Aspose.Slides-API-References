## PictureFrameLock คลาส

กำหนดว่าปฏิบัติการใดถูกปิดใช้งานบน PictureFrame พาเรนท์.

**การสืบทอด:**[`PictureFrameLock`](/slides/python-net/th/aspose.slides/pictureframelock) → [`BaseShapeLock`](/slides/python-net/th/aspose.slides/baseshapelock)

ประเภท PictureFrameLock เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`no_locks`](/slides/python-net/th/aspose.slides/pictureframelock/no_locks/) | ส่งค่า true หาก lock-flags ทั้งหมดถูกปิดใช้งาน.<br/>            อ่านอย่างเดียว **bool**. |
| [`grouping_locked`](/slides/python-net/th/aspose.slides/pictureframelock/grouping_locked/) | กำหนดว่าการเพิ่มรูปร่างนี้เข้าไปในกลุ่มถูกห้ามหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`select_locked`](/slides/python-net/th/aspose.slides/pictureframelock/select_locked/) | กำหนดว่าการเลือกรูปร่างนี้ถูกห้ามหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`rotation_locked`](/slides/python-net/th/aspose.slides/pictureframelock/rotation_locked/) | กำหนดว่าการเปลี่ยนมุมการหมุนของรูปร่างนี้ถูกห้ามหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/th/aspose.slides/pictureframelock/aspect_ratio_locked/) | กำหนดว่ารูปร่างต้องรักษาอัตราส่วนภาพเมื่อตัวขนาดถูกเปลี่ยนหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`position_locked`](/slides/python-net/th/aspose.slides/pictureframelock/position_locked/) | กำหนดว่าการย้ายรูปร่างนี้ถูกห้ามหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`size_locked`](/slides/python-net/th/aspose.slides/pictureframelock/size_locked/) | กำหนดว่าการปรับขนาดรูปร่างนี้ถูกห้ามหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`edit_points_locked`](/slides/python-net/th/aspose.slides/pictureframelock/edit_points_locked/) | กำหนดว่าการเปลี่ยนเส้นขอบโดยตรงของรูปร่างนี้ถูกห้ามหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`adjust_handles_locked`](/slides/python-net/th/aspose.slides/pictureframelock/adjust_handles_locked/) | กำหนดว่าการปรับค่า adjust ถูกห้ามหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`arrowheads_locked`](/slides/python-net/th/aspose.slides/pictureframelock/arrowheads_locked/) | กำหนดว่าการเปลี่ยนหัวลูกศรถูกห้ามหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`shape_type_locked`](/slides/python-net/th/aspose.slides/pictureframelock/shape_type_locked/) | กำหนดว่าการเปลี่ยนประเภทของรูปร่างถูกห้ามหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`crop_locked`](/slides/python-net/th/aspose.slides/pictureframelock/crop_locked/) | กำหนดว่าการตัดภาพถูกห้ามหรือไม่.<br/>            อ่าน/เขียน **bool**. |
