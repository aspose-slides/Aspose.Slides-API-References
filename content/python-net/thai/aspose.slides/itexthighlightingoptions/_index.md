## ITextHighlightingOptions คลาส

แสดงตัวเลือกที่ใช้สำหรับการเน้นข้อความในกรอบข้อความ.

ประเภท ITextHighlightingOptions เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`case_sensitive`](/slides/python-net/th/aspose.slides/itexthighlightingoptions/case_sensitive/) | ตั้งค่า true เพื่อใช้การค้นหาแยกแยะตัวพิมพ์ใหญ่เล็ก, false - หากไม่ต้องการ.<br/> อ่าน/เขียน **bool**. |
| [`whole_words_only`](/slides/python-net/th/aspose.slides/itexthighlightingoptions/whole_words_only/) | ตั้งค่า true เพื่อให้ตรงกับคำเต็มเท่านั้น, false - หากไม่ต้องการ.<br/> อ่าน/เขียน **bool**. |
