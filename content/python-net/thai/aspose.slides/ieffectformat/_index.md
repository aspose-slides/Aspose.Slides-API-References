## IEffectFormat คลาส

แสดงคุณสมบัติของเอฟเฟ็กต์ของรูปร่าง.

ประเภท IEffectFormat เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`is_no_effects`](/slides/python-net/th/aspose.slides/ieffectformat/is_no_effects/) | คืนค่า true หากเอฟเฟ็กต์ทั้งหมดถูกปิดการใช้งาน (เช่น เพิ่งสร้าง ค่าเริ่มต้น EffectFormat object).<br/>            อ่านอย่างเดียว **bool**. |
| [`blur_effect`](/slides/python-net/th/aspose.slides/ieffectformat/blur_effect/) | เอฟเฟ็กต์เบลอ.<br/>            อ่าน/เขียน [`IBlur`](/slides/python-net/th/aspose.slides.effects/iblur). |
| [`fill_overlay_effect`](/slides/python-net/th/aspose.slides/ieffectformat/fill_overlay_effect/) | เอฟเฟ็กต์การเติมซ้อนทับ.<br/>            อ่าน/เขียน [`IFillOverlay`](/slides/python-net/th/aspose.slides.effects/ifilloverlay). |
| [`glow_effect`](/slides/python-net/th/aspose.slides/ieffectformat/glow_effect/) | เอฟเฟ็กต์เรืองแสง.<br/>            อ่าน/เขียน [`IGlow`](/slides/python-net/th/aspose.slides.effects/iglow). |
| [`inner_shadow_effect`](/slides/python-net/th/aspose.slides/ieffectformat/inner_shadow_effect/) | เงาภายใน.<br/>            อ่าน/เขียน [`IInnerShadow`](/slides/python-net/th/aspose.slides.effects/iinnershadow). |
| [`outer_shadow_effect`](/slides/python-net/th/aspose.slides/ieffectformat/outer_shadow_effect/) | เงาภายนอก.<br/>            อ่าน/เขียน [`IOuterShadow`](/slides/python-net/th/aspose.slides.effects/ioutershadow). |
| [`preset_shadow_effect`](/slides/python-net/th/aspose.slides/ieffectformat/preset_shadow_effect/) | เงาที่ตั้งล่วงหน้า.<br/>            อ่าน/เขียน [`IPresetShadow`](/slides/python-net/th/aspose.slides.effects/ipresetshadow). |
| [`reflection_effect`](/slides/python-net/th/aspose.slides/ieffectformat/reflection_effect/) | การสะท้อน.<br/>            อ่าน/เขียน [`IReflection`](/slides/python-net/th/aspose.slides.effects/ireflection). |
| [`soft_edge_effect`](/slides/python-net/th/aspose.slides/ieffectformat/soft_edge_effect/) | ขอบนุ่ม.<br/>            อ่าน/เขียน [`ISoftEdge`](/slides/python-net/th/aspose.slides.effects/isoftedge). |
