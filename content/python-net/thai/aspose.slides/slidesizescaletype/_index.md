## SlideSizeScaleType enumeration

แสดงถึงประเภทการปรับสเกลของเนื้อหาสไลด์.

ประเภท SlideSizeScaleType เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| DO_NOT_SCALE | ไม่ปรับสเกล. |
| ENSURE_FIT | ปรับสเกลเพื่อให้พอดี. |
| MAXIMIZE | เพิ่มขนาดของเนื้อหาให้มากที่สุด. |
