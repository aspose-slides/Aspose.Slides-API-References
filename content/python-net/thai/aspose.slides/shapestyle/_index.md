## คลาส ShapeStyle

ระบุการอ้างอิงสไตล์ของรูปร่าง.

ประเภท ShapeStyle เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`line_color`](/slides/python-net/th/aspose.slides/shapestyle/line_color/) | ส่งคืนสีโครงร่างของรูปร่าง.<br/>            อ่านอย่างเดียว [`IColorFormat`](/slides/python-net/th/aspose.slides/icolorformat). |
| [`line_style_index`](/slides/python-net/th/aspose.slides/shapestyle/line_style_index/) | ส่งคืนหรือกำหนดดัชนีคอลัมน์ของเส้นในเมทริกซ์สไตล์.<br/>            อ่าน/เขียน **int**. |
| [`fill_color`](/slides/python-net/th/aspose.slides/shapestyle/fill_color/) | ส่งคืนสีเติมของรูปร่าง.<br/>            อ่านอย่างเดียว [`IColorFormat`](/slides/python-net/th/aspose.slides/icolorformat). |
| [`fill_style_index`](/slides/python-net/th/aspose.slides/shapestyle/fill_style_index/) | ส่งคืนหรือกำหนดดัชนีคอลัมน์การเติมของรูปร่างในเมทริกซ์สไตล์.<br/>            0 หมายถึงไม่มีการเติม,<br/>            ค่าบวก - ดัชนีในสไตล์เติมของธีม,<br/>            ค่าลบ - ดัชนีในสไตล์พื้นหลังของธีม.<br/>            อ่าน/เขียน **int**. |
| [`effect_color`](/slides/python-net/th/aspose.slides/shapestyle/effect_color/) | ส่งคืนสีเอฟเฟ็กต์ของรูปร่าง.<br/>            อ่านอย่างเดียว [`IColorFormat`](/slides/python-net/th/aspose.slides/icolorformat). |
| [`effect_style_index`](/slides/python-net/th/aspose.slides/shapestyle/effect_style_index/) | ส่งคืนหรือกำหนดดัชนีคอลัมน์เอฟเฟ็กต์ของรูปร่างในเมทริกซ์สไตล์.<br/>            อ่าน/เขียน **int**. |
| [`font_color`](/slides/python-net/th/aspose.slides/shapestyle/font_color/) | ส่งคืนสีฟอนต์ของรูปร่าง.<br/>            อ่านอย่างเดียว [`IColorFormat`](/slides/python-net/th/aspose.slides/icolorformat). |
| [`font_collection_index`](/slides/python-net/th/aspose.slides/shapestyle/font_collection_index/) | ส่งคืนหรือกำหนดดัชนีฟอนต์ของรูปร่างในคอลเลกชันฟอนต์.<br/>            อ่าน/เขียน [`FontCollectionIndex`](/slides/python-net/th/aspose.slides/fontcollectionindex). |
