## SourceFormat การนับค่า

แทนรูปแบบไฟล์ต้นฉบับ

ประเภท SourceFormat มีสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| PPT | Microsoft PowerPoint 97-2003 งานนำเสนอ (*.ppt). |
| PPTX | Microsoft Office Open XML งานนำเสนอ (*.pptx). |
| ODP | OpenDocument งานนำเสนอ (*.odp). |
| PPTM | Microsoft Office Open XML งานนำเสนอที่มีแมโคร (*.pptm). |
| PPSX | Microsoft Office Open XML สไลด์โชว์ (*.ppsx). |
| PPSM | Microsoft Office Open XML สไลด์โชว์ที่มีแมโคร (*.ppsm). |
| POTX | Microsoft Office Open XML แม่แบบ (*.potx). |
| POTM | Microsoft Office Open XML แม่แบบที่มีแมโคร (*.potm). |
| PPS | Microsoft PowerPoint 97-2003 สไลด์โชว์ (*.pps). |
| POT | Microsoft PowerPoint 97-2003 แม่แบบ (*.pot). |
| OTP | OpenDocument แม่แบบงานนำเสนอ (*.otp). |
| FODP | Flat XML ODF งานนำเสนอ (*.fodp). |
| XML | PowerPoint XML งานนำเสนอ (*.xml). |
