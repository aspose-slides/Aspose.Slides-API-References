## IShapeFrame คลาส

แสดงคุณสมบัติของเฟรมรูปทรง.

IShapeFrame type เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`x`](/slides/python-net/th/aspose.slides/ishapeframe/x/) | ส่งคืนพิกัด X ของมุมบนซ้ายของเฟรม.<br/>            อ่านอย่างเดียว **float**. |
| [`y`](/slides/python-net/th/aspose.slides/ishapeframe/y/) | ส่งคืนพิกัด Y ของมุมบนซ้ายของเฟรม.<br/>            อ่านอย่างเดียว **float**. |
| [`width`](/slides/python-net/th/aspose.slides/ishapeframe/width/) | ส่งคืนความกว้างของเฟรม.<br/>            อ่านอย่างเดียว **float**. |
| [`height`](/slides/python-net/th/aspose.slides/ishapeframe/height/) | ส่งคืนความสูงของเฟรม.<br/>            อ่านอย่างเดียว **float**. |
| [`rotation`](/slides/python-net/th/aspose.slides/ishapeframe/rotation/) | ส่งคืนจำนวนองศาที่เฟรมหมุนรอบแกน Z.<br/>            ค่าบวกแสดงการหมุนตามเข็มนาฬิกา; ค่าลบ<br/>            แสดงการหมุนทวนเข็มนาฬิกา.<br/>            อ่านอย่างเดียว **float**. |
| [`center_x`](/slides/python-net/th/aspose.slides/ishapeframe/center_x/) | ส่งคืนพิกัด X ของจุดศูนย์กลางของเฟรม.<br/>            อ่านอย่างเดียว **float**. |
| [`center_y`](/slides/python-net/th/aspose.slides/ishapeframe/center_y/) | ส่งคืนพิกัด Y ของจุดศูนย์กลางของเฟรม.<br/>            อ่านอย่างเดียว **float**. |
| [`flip_h`](/slides/python-net/th/aspose.slides/ishapeframe/flip_h/) | กำหนดว่าเฟรมถูกพลิกในแนวนอนหรือไม่.<br/>            อ่านอย่างเดียว [`NullableBool`](/slides/python-net/th/aspose.slides/nullablebool). |
| [`flip_v`](/slides/python-net/th/aspose.slides/ishapeframe/flip_v/) | กำหนดว่าเฟรมถูกพลิกในแนวตั้งหรือไม่.<br/>            อ่านอย่างเดียว [`NullableBool`](/slides/python-net/th/aspose.slides/nullablebool). |
| [`rectangle`](/slides/python-net/th/aspose.slides/ishapeframe/rectangle/) | ส่งคืนพิกัดของเฟรม.<br/>            อ่านอย่างเดียว **aspose.slides.RectangleF**. |
