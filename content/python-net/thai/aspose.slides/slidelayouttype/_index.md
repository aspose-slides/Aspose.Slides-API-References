## SlideLayoutType การนับ

แสดงถึงประเภทเลเอาท์สไลด์

ประเภท SlideLayoutType มีสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| CUSTOM | กำหนดเอง |
| TITLE | หัวเรื่อง |
| TEXT | ข้อความ |
| TWO_COLUMN_TEXT | ข้อความแบบสองคอลัมน์ |
| TABLE | ตาราง |
| TEXT_AND_CHART | ข้อความและแผนภูมิ |
| CHART_AND_TEXT | แผนภูมิและข้อความ |
| DIAGRAM | ไดอะแกรม |
| CHART | แผนภูมิ |
| TEXT_AND_CLIP_ART | ข้อความและคลิปอาร์ต |
| CLIP_ART_AND_TEXT | คลิปอาร์ตและข้อความ |
| TITLE_ONLY | หัวเรื่องเท่านั้น |
| BLANK | ว่าง |
| TEXT_AND_OBJECT | ข้อความและอ็อบเจ็กต์ |
| OBJECT_AND_TEXT | อ็อบเจ็กต์และข้อความ |
| OBJECT | อ็อบเจ็กต์ |
| TITLE_AND_OBJECT | หัวเรื่องและอ็อบเจ็กต์ |
| TEXT_AND_MEDIA | ข้อความและสื่อ |
| MEDIA_AND_TEXT | สื่อและข้อความ |
| OBJECT_OVER_TEXT | อ็อบเจ็กต์เหนือข้อความ |
| TEXT_OVER_OBJECT | ข้อความเหนืออ็อบเจ็กต์ |
| TEXT_AND_TWO_OBJECTS | ข้อความและอ็อบเจ็กต์สองรายการ |
| TWO_OBJECTS_AND_TEXT | อ็อบเจ็กต์สองรายการและข้อความ |
| TWO_OBJECTS_OVER_TEXT | อ็อบเจ็กต์สองรายการเหนือข้อความ |
| FOUR_OBJECTS | อ็อบเจ็กต์สี่รายการ |
| VERTICAL_TEXT | ข้อความแนวตั้ง |
| CLIP_ART_AND_VERTICAL_TEXT | คลิปอาร์ตและข้อความแนวตั้ง |
| VERTICAL_TITLE_AND_TEXT | หัวเรื่องแนวตั้งและข้อความ |
| VERTICAL_TITLE_AND_TEXT_OVER_CHART | หัวเรื่องแนวตั้งและข้อความเหนือแผนภูมิ |
| TWO_OBJECTS | อ็อบเจ็กต์สองรายการ |
| OBJECT_AND_TWO_OBJECT | อ็อบเจ็กต์และอ็อบเจ็กต์สองรายการ |
| TWO_OBJECTS_AND_OBJECT | อ็อบเจ็กต์สองรายการและอ็อบเจ็กต์ |
| SECTION_HEADER | หัวข้อส่วน |
| TWO_TEXT_AND_TWO_OBJECTS | ข้อความสองรายการและอ็อบเจ็กต์สองรายการ |
| TITLE_OBJECT_AND_CAPTION | หัวเรื่อง, อ็อบเจ็กต์, และคำอธิบาย |
| PICTURE_AND_CAPTION | รูปภาพและคำอธิบาย |
