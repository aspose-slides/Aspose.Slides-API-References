## ISensitivityLabel คลาส

เป็นตัวแทนของป้ายระดับความละเอียดอ่อนจาก Microsoft Purview Information Protection.

ประเภท ISensitivityLabel เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`id`](/slides/python-net/th/aspose.slides/isensitivitylabel/id/) | คืนหรือกำหนดค่า ID ของป้ายระดับความละเอียดอ่อน.<br/>            อ่าน/เขียน **str**. |
| [`site_id`](/slides/python-net/th/aspose.slides/isensitivitylabel/site_id/) | คืนหรือกำหนดค่า ตัวระบุไซต์ของ Azure Active Directory (Azure AD) <br/>            ที่สอดคล้องกับนโยบายป้ายระดับความละเอียดอ่อนที่อธิบายป้ายระดับความละเอียดอ่อน.<br/>            อ่าน/เขียน **System.Guid**. |
| [`is_enabled`](/slides/python-net/th/aspose.slides/isensitivitylabel/is_enabled/) | ระบุว่าป้ายระดับความละเอียดอ่อนถูกเปิดใช้งานหรือไม่. |
| [`is_removed`](/slides/python-net/th/aspose.slides/isensitivitylabel/is_removed/) | ระบุว่าป้ายระดับความละเอียดอ่อนถูกลบหรือไม่. |
| [`assignment_method_type`](/slides/python-net/th/aspose.slides/isensitivitylabel/assignment_method_type/) | คืนหรือกำหนดวิธีการมอบหมายสำหรับป้ายระดับความละเอียดอ่อน.<br/>            อ่าน/เขียน [`SensitivityLabelAssignmentType`](/slides/python-net/th/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/th/aspose.slides/isensitivitylabel/content_mark_types/) | คืนรายการประเภทของการทำเครื่องหมายเนื้อหาที่ควรนำไปใช้กับไฟล์. |
