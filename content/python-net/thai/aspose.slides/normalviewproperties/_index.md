## NormalViewProperties คลาส

แทนคุณสมบัติของมุมมองปกติ. มุมมองปกติมีสามพื้นที่เนื้อหา: สไลด์เอง, พื้นที่เนื้อหาด้านข้าง, และพื้นที่เนื้อหาด้านล่าง.

ประเภท NormalViewProperties เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`show_outline_icons`](/slides/python-net/th/aspose.slides/normalviewproperties/show_outline_icons/) | ระบุว่าแอปพลิเคชันควรแสดงไอคอนไหมหากแสดงเนื้อหาโครงร่างในใด<br/>            ของพื้นที่เนื้อหาในโหมดมุมมองปกติ.<br/>            อ่าน/เขียน **bool**. |
| [`snap_vertical_splitter`](/slides/python-net/th/aspose.slides/normalviewproperties/snap_vertical_splitter/) | ระบุว่าตัวแบ่งแนวตั้งควรสแนปไปยังสถานะย่อเมื่อด้าน<br/>            มีขนาดเล็กพอหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`vertical_bar_state`](/slides/python-net/th/aspose.slides/normalviewproperties/vertical_bar_state/) | ระบุสถานะที่แถบแบ่งแนวตั้งควรแสดงใน. <br/>            แถบแบ่งแนวตั้งแยกสไลด์ออกจากพื้นที่เนื้อหาด้านข้าง. |
| [`horizontal_bar_state`](/slides/python-net/th/aspose.slides/normalviewproperties/horizontal_bar_state/) | ระบุสถานะที่แถบแบ่งแนวนอนควรแสดงใน.<br/>            แถบแบ่งแนวนอนแยกสไลด์ออกจากพื้นที่เนื้อหาที่อยู่ด้านล่างสไลด์. |
| [`prefer_single_view`](/slides/python-net/th/aspose.slides/normalviewproperties/prefer_single_view/) | ระบุว่าผู้ใช้ต้องการดูพื้นที่เนื้อหาเดี่ยวเต็มหน้าต่างแทน<br/>            มุมมองปกติมาตรฐานที่มีสามพื้นที่เนื้อหรือไม่. หากเปิดใช้งาน แอปพลิเคชันอาจเลือก<br/>            แสดงหนึ่งในพื้นที่เนื้อหาเต็มหน้าต่าง.<br/>            อ่าน/เขียน **bool**. |
| [`restored_left`](/slides/python-net/th/aspose.slides/normalviewproperties/restored_left/) | องค์ประกอบนี้ระบุขนาดของพื้นที่เนื้อหาด้านข้างของมุมมองปกติเมื่อพื้นที่อยู่ในขนาดที่เปลี่ยนแปลงได้ (ไม่ย่อไม่ขยาย).<br/>            อ่านอย่างเดียว [`INormalViewRestoredProperties`](/slides/python-net/th/aspose.slides/inormalviewrestoredproperties). |
| [`restored_top`](/slides/python-net/th/aspose.slides/normalviewproperties/restored_top/) | องค์ประกอบนี้ระบุขนาดของพื้นที่สไลด์ด้านบนของมุมมองปกติเมื่อพื้นที่อยู่ในขนาดที่เปลี่ยนแปลงได้ (ไม่ย่อไม่ขยาย).<br/>            อ่านอย่างเดียว [`INormalViewRestoredProperties`](/slides/python-net/th/aspose.slides/inormalviewrestoredproperties). |
