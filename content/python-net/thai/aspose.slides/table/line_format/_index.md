## line_format คุณสมบัติ
คืนค่าอ็อบเจ็กต์ LineFormat ที่มีคุณสมบัติการจัดรูปแบบเส้นสำหรับ shape.
            หมายเหตุ: สามารถคืนค่า None สำหรับประเภทบางอย่างของ shapes ที่ไม่มีคุณสมบัติเส้น.
            อ่านอย่างเดียว [`ILineFormat`](/slides/python-net/th/aspose.slides/ilineformat).
