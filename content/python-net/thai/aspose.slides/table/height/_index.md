## height คุณสมบัติ
รับหรือกำหนดค่า height ของรูปร่าง, วัดเป็นจุด.
อ่านเขียน **float**.

### หมายเหตุ

ค่าที่ส่งคืนจะถูกกำหนดเสมอและไม่เคยเป็น **float**.
ค่าที่กำหนดต้องถูกกำหนดเช่นกัน; ให้กำหนด **float** เฉพาะกับคุณสมบัติของออบเจ็กต์ `RawFrame` เท่านั้น.
