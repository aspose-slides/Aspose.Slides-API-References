## InterruptionToken คลาส

ประเภท InterruptionToken เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`none`](/slides/python-net/th/aspose.slides/interruptiontoken/none/) | แสดงถึงโทเค็นการขัดจังหวะที่ว่างเปล่า.<br/>            การทำงานที่ใช้เวลานานจะไม่มีการขัดจังหวะผ่าน [`InterruptionTokenSource.interrupt`](/slides/python-net/th/aspose.slides/interruptiontokensource/interrupt)<br/>            เมื่อใช้โทเค็นนี้. |
| [`is_interruption_requested`](/slides/python-net/th/aspose.slides/interruptiontoken/is_interruption_requested/) | คืนค่า **bool**.true ถ้าการขัดจังหวะถูกร้องขอ. |

## เมธอด

| เมธอด | คำอธิบาย |
| :- | :- |
| [`throw_if_interruption_requested(self)`](/slides/python-net/th/aspose.slides/interruptiontoken/throw_if_interruption_requested/#) | โยน OperationCanceledException ถ้าการขัดจังหวะถูกร้องขอ. |
