## IAdjustValue คลาส

แสดงค่าการปรับของรูปทรงเรขาคณิต
            ค่าเหล่านี้มีผลต่อรูปทรง

ประเภท IAdjustValue เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`raw_value`](/slides/python-net/th/aspose.slides/iadjustvalue/raw_value/) | คืนหรือกำหนดค่าการปรับ "as is".<br/>            อ่าน/เขียน **int**. |
| [`angle_value`](/slides/python-net/th/aspose.slides/iadjustvalue/angle_value/) | คืนหรือกำหนดค่า โดยตีความเป็นมุมเป็นองศา.<br/>            อ่าน/เขียน **float**. |
| [`name`](/slides/python-net/th/aspose.slides/iadjustvalue/name/) | คืนชื่อของค่าการปรับนี้.<br/>            อ่านอย่างเดียว **str**. |
| [`type`](/slides/python-net/th/aspose.slides/iadjustvalue/type/) | คืนประเภทของการปรับรูปทรง.<br/>            อ่านอย่างเดียว [`ShapeAdjustmentType`](/slides/python-net/th/aspose.slides/shapeadjustmenttype). |
