## ICaptions คลาส

แสดงถึงคำบรรยายปิดของ WebVTT.

ประเภท ICaptions เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`caption_id`](/slides/python-net/th/aspose.slides/icaptions/caption_id/) | คืนค่า GUID ที่เป็นตัวระบุเฉพาะทั่วโลกของคำบรรยายปิด.<br/>            อ่านอย่างเดียว **System.Guid**. |
| [`label`](/slides/python-net/th/aspose.slides/icaptions/label/) | คืนค่า หรือกำหนดป้ายกำกับของคำบรรยายปิด.<br/>            อ่าน/เขียน **str**. |
| [`binary_data`](/slides/python-net/th/aspose.slides/icaptions/binary_data/) | คืนค่าข้อมูลไบนารีของคำบรรยายปิด.<br/>            อ่านอย่างเดียว **int**[]. |
| [`data_as_string`](/slides/python-net/th/aspose.slides/icaptions/data_as_string/) | คืนค่าข้อมูลคำบรรยายปิดเป็นสตริงที่เข้ารหัส UTF-8<br/>            อ่านอย่างเดียว **str**. |
