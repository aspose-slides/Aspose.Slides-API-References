## TabAlignment enumeration

แสดงการจัดแนวแท็บ

ประเภท TabAlignment เผยให้เห็นสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| LEFT | การจัดแนวซ้าย |
| CENTER | การจัดแนวศูนย์กลาง |
| RIGHT | การจัดแนวขวา |
| DECIMAL | การจัดแนวทศนิยม |
