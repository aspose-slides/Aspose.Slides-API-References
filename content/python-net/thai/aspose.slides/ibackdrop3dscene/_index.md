## IBackdrop3DScene คลาส

กำหนดระนาบที่เอฟเฟกต์ เช่น แสงเรืองแสงและเงา ถูกนำไปใช้สัมพันธ์กับรูปทรงที่นำไปใช้กับมัน

ประเภท IBackdrop3DScene เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`normal_vector`](/slides/python-net/th/aspose.slides/ibackdrop3dscene/normal_vector/) | คืนหรือกำหนดเวกเตอร์ปกติ เพื่อให้ชัดเจนยิ่งขึ้น คุณลักษณะนี้กำหนดเวกเตอร์<br/>            ที่ตั้งฉากต่อพื้นผิวของระนาบพื้นหลัง เวกเตอร์แสดงโดยอาร์เรย์ของค่า float 3 ตัว<br/>            ซึ่งกำหนดพิกัด X, Y และ Z<br/>            อ่าน/เขียน **float**[]. |
| [`anchor_point`](/slides/python-net/th/aspose.slides/ibackdrop3dscene/anchor_point/) | คืนหรือกำหนดจุดในพื้นที่ 3D จุดนี้เป็นจุดในอวกาศที่เป็นจุดยึดของระนาบพื้นหลัง<br/>            จุด 3D แสดงโดยอาร์เรย์ของค่า float 3 ตัวซึ่งกำหนดพิกัด X, Y และ Z<br/>            อ่าน/เขียน **float**[]. |
| [`up_vector`](/slides/python-net/th/aspose.slides/ibackdrop3dscene/up_vector/) | คืนหรือกำหนดเวกเตอร์ที่แสดงทิศทางขึ้น เพื่อให้ชัดเจนยิ่งขึ้น คุณลักษณะนี้กำหนดเวกเตอร์<br/>            ที่แสดงทิศทางขึ้นสัมพันธ์กับพื้นผิวของระนาบพื้นหลัง เวกเตอร์แสดงโดยอาร์เรย์<br/>            ของค่า float 3 ตัวซึ่งกำหนดพิกัด X, Y และ Z<br/>            อ่าน/เขียน **float**[]. |
