## คลาส Picture

แสดงถึงรูปภาพในงานนำเสนอหนึ่ง

ประเภท Picture เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`image`](/slides/python-net/th/aspose.slides/picture/image/) | คืนค่า หรือกำหนดภาพที่ฝังไว้.<br/>            อ่าน/เขียน [`IPPImage`](/slides/python-net/th/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/th/aspose.slides/picture/link_path_long/) | คืนค่า หรือกำหนด URL ของภาพที่เชื่อมโยง.<br/>            อ่าน/เขียน **str**. |
| [`image_transform`](/slides/python-net/th/aspose.slides/picture/image_transform/) | คืนค่าคอลเลกชันของเอฟเฟกต์การแปลงภาพ.<br/>            อ่านอย่างเดียว [`IImageTransformOperationCollection`](/slides/python-net/th/aspose.slides.effects/iimagetransformoperationcollection). |
| [`presentation`](/slides/python-net/th/aspose.slides/picture/presentation/) | คืนค่างานนำเสนอ.<br/>            อ่านอย่างเดียว [`IPresentation`](/slides/python-net/th/aspose.slides/ipresentation). |
| [`slide`](/slides/python-net/th/aspose.slides/picture/slide/) | คืนค่าสไลด์แม่ของรูปภาพ.<br/>            อ่านอย่างเดียว [`IBaseSlide`](/slides/python-net/th/aspose.slides/ibaseslide). |
