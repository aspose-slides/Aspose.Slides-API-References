## IFillFormatEffectiveData คลาส

อ็อบเจ็กต์ที่ไม่สามารถเปลี่ยนแปลงได้ซึ่งบรรจุคุณสมบัติการจัดรูปแบบการเติมที่มีผล

ประเภท IFillFormatEffectiveData เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`fill_type`](/slides/python-net/th/aspose.slides/ifillformateffectivedata/fill_type/) | คืนค่าชนิดของการเติม.<br/>            อ่านอย่างเดียว [`FillType`](/slides/python-net/th/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/th/aspose.slides/ifillformateffectivedata/solid_fill_color/) | คืนค่าสีเติม.<br/>            อ่านอย่างเดียว [`Color`](/slides/python-net/th/aspose.slides/color). |
| [`solid_fill_scheme_color`](/slides/python-net/th/aspose.slides/ifillformateffectivedata/solid_fill_scheme_color/) | รับค่าสีเติมที่กำหนดโดยโครงสร้างสี.<br/>            ค่าของ [`SchemeColor.NOT_DEFINED`](/slides/python-net/th/aspose.slides/schemecolor/NOT_DEFINED) แสดงให้เห็นว่า [`IFillFormatEffectiveData.solid_fill_color`](/slides/python-net/th/aspose.slides/ifillformateffectivedata/solid_fill_color) <br/>            ไม่ใช่สีตามสเค็ม.<br/>            อ่านอย่างเดียว [`SchemeColor`](/slides/python-net/th/aspose.slides/schemecolor). |
| [`gradient_format`](/slides/python-net/th/aspose.slides/ifillformateffectivedata/gradient_format/) | คืนรูปแบบการเติมแบบไล่ระดับ.<br/>            อ่านอย่างเดียว [`IGradientFormatEffectiveData`](/slides/python-net/th/aspose.slides/igradientformateffectivedata). |
| [`pattern_format`](/slides/python-net/th/aspose.slides/ifillformateffectivedata/pattern_format/) | คืนรูปแบบการเติมแบบลาย.<br/>            อ่านอย่างเดียว [`IPatternFormatEffectiveData`](/slides/python-net/th/aspose.slides/ipatternformateffectivedata). |
| [`picture_fill_format`](/slides/python-net/th/aspose.slides/ifillformateffectivedata/picture_fill_format/) | คืนรูปแบบการเติมแบบรูปภาพ.<br/>            อ่านอย่างเดียว [`IPictureFillFormatEffectiveData`](/slides/python-net/th/aspose.slides/ipicturefillformateffectivedata). |
| [`rotate_with_shape`](/slides/python-net/th/aspose.slides/ifillformateffectivedata/rotate_with_shape/) | กำหนดว่าการเติมควรหมุนตามรูปทรงหรือไม่.<br/>            อ่านอย่างเดียว **bool**. |

### หมายเหตุ

อินเทอร์เฟซนี้ใช้ร่วมกับอินเทอร์เฟซ [`IFillFormat`](/slides/python-net/th/aspose.slides/ifillformat) เพื่อส่งคืนค่าการจัดรูปแบบที่มีผลโดยมีการใช้การสืบทอด
