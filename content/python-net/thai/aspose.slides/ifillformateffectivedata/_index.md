## IFillFormatEffectiveData คลาส

วัตถุที่ไม่เปลี่ยนแปลงซึ่งบรรจุคุณลักษณะการจัดรูปแบบการเติมที่มีผล

ประเภท IFillFormatEffectiveData เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`fill_type`](/slides/python-net/th/aspose.slides/ifillformateffectivedata/fill_type/) | คืนค่าประเภทของการเติม<br/>            อ่านอย่างเดียว [`FillType`](/slides/python-net/th/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/th/aspose.slides/ifillformateffectivedata/solid_fill_color/) | คืนค่าสีการเติม<br/>            อ่านอย่างเดียว **aspose.slides.Color**. |
| [`solid_fill_scheme_color`](/slides/python-net/th/aspose.slides/ifillformateffectivedata/solid_fill_scheme_color/) | รับค่าสีการเติมที่กำหนดโดยโครงการสี<br/>            ค่าที่ [`SchemeColor.NOT_DEFINED`](/slides/python-net/th/aspose.slides/schemecolor/NOT_DEFINED) ระบุว่า [`IFillFormatEffectiveData.solid_fill_color`](/slides/python-net/th/aspose.slides/ifillformateffectivedata/solid_fill_color) <br/>            ไม่ใช่สีจากโครงการ<br/>            อ่านอย่างเดียว [`SchemeColor`](/slides/python-net/th/aspose.slides/schemecolor). |
