## CustomXmlPart คลาส

แสดงถึงส่วน xml ที่กำหนดเอง.

ประเภท CustomXmlPart เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`xml_data`](/slides/python-net/th/aspose.slides/customxmlpart/xml_data/) | คืนค่า หรือ ตั้งค่า ข้อมูล xml.<br/>            อ่าน/เขียน **int**[].<br/>            ค่าเป็น `None`.ค่าเป็นค่าว่างหรือ xml-data ไม่ถูกต้อง. |
| [`xml_as_string`](/slides/python-net/th/aspose.slides/customxmlpart/xml_as_string/) | คืนค่า หรือ ตั้งค่า ข้อมูล xml เป็นสตริง UTF-8.<br/>            อ่าน/เขียน **str**.<br/>            ค่าเป็น `None`.ค่าเป็นค่าว่างหรือ xml-data ไม่ถูกต้อง. |
| [`item_id`](/slides/python-net/th/aspose.slides/customxmlpart/item_id/) | ระบุตัวระบุที่เป็นเอกลักษณ์ทั่วโลก (GUID) ที่ระบุส่วน custom XML <br/>            part ภายในเอกสาร Office Open XML.<br/>            อ่านอย่างเดียว **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/th/aspose.slides/customxmlpart/namespace_schemas/) | คืนค่าชุดสคีม่า XML ที่เชื่อมโยงกับส่วน custom XML.<br/>            อ่านอย่างเดียว **str**[]. |
