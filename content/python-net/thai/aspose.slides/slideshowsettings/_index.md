## SlideShowSettings คลาส

แทนค่าการตั้งค่าการแสดงสไลด์สำหรับงานนำเสนอ

ประเภท SlideShowSettings เปิดให้เข้าถึงสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`slide_show_type`](/slides/python-net/th/aspose.slides/slideshowsettings/slide_show_type/) | รับหรือกำหนดประเภทการแสดงสไลด์ แสดงโดยบรรพบุรุษ [`SlideShowSettings.slide_show_type`](/slides/python-net/th/aspose.slides/slideshowsettings/slide_show_type) ต่อไปนี้: [`BrowsedAtKiosk`](/slides/python-net/th/aspose.slides/browsedatkiosk), [`PresentedBySpeaker`](/slides/python-net/th/aspose.slides/presentedbyspeaker) และ [`BrowsedByIndividual`](/slides/python-net/th/aspose.slides/browsedbyindividual) |
| [`loop`](/slides/python-net/th/aspose.slides/slideshowsettings/loop/) | วนลูปการแสดงสไลด์ |
| [`show_narration`](/slides/python-net/th/aspose.slides/slideshowsettings/show_narration/) | แสดงคำบรรยายในการแสดงสไลด์ |
| [`show_animation`](/slides/python-net/th/aspose.slides/slideshowsettings/show_animation/) | แสดงการเคลื่อนไหวในการแสดงสไลด์ |
| [`pen_color`](/slides/python-net/th/aspose.slides/slideshowsettings/pen_color/) | สีปากกาสำหรับการแสดงสไลด์ |
| [`slides`](/slides/python-net/th/aspose.slides/slideshowsettings/slides/) | ช่วงสไลด์ |
| [`use_timings`](/th/slides/python-net/aspose.slides/slideshowsettings/use_timings/) | ใช้การกำหนดเวลาในการแสดงสไลด์ |
| [`show_media_controls`](/slides/python-net/th/aspose.slides/slideshowsettings/show_media_controls/) | แสดงการควบคุมสื่อ |
