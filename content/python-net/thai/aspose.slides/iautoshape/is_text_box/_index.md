## is_text_box คุณสมบัติ
ระบุว่า shape เป็น text box หรือไม่.

### หมายเหตุ
หาก shape ไม่ได้ระบุว่าเป็น text box ไม่ได้หมายความว่าไม่สามารถมีข้อความแนบอยู่ได้. กล่องข้อความเป็นเพียง shape พิเศษที่มีคุณสมบัติเฉพาะ.
