## insert_chart(self, type, x, y, width, height, index, init_with_sample) {#asposeslideschartscharttype-float-float-float-float-int-bool}
สร้างแผนภูมิใหม่, เริ่มต้นด้วยข้อมูลซีรีส์ตัวอย่างและการตั้งค่า,
            แล้วแทรกลงในคอลเลกชันรูปทรัพย์ที่ตำแหน่งที่ระบุ.

### ผลลัพธ์

วัตถุที่สร้างใหม่ [`IChart`](/slides/python-net/th/aspose.slides.charts/ichart).



```python
def insert_chart(self, type, x, y, width, height, index, init_with_sample):
    ...
```


| พารามิเตอร์ | ชนิด | คำอธิบาย |
| :- | :- | :- |
| type | [`ChartType`](/slides/python-net/th/aspose.slides.charts/charttype) | ประเภทของแผนภูมิที่จะสร้าง |
| x | **float** | พิกัด x ของแผนภูมิใหม่, หน่วยเป็นจุด |
| y | **float** | พิกัด y ของแผนภูมิใหม่, หน่วยเป็นจุด |
| width | **float** | ความกว้างของแผนภูมิใหม่, หน่วยเป็นจุด |
| height | **float** | ความสูงของแผนภูมิใหม่, หน่วยเป็นจุด |
| index | **int** | ดัชนีเริ่มต้นจากศูนย์ที่จะแทรกแผนภูมิใหม่ลงในคอลเลกชันรูปทรัพย์ |
| init_with_sample | **bool** | True เพื่อเริ่มต้นแผนภูมิใหม่ด้วยข้อมูลซีรีส์ตัวอย่างและการตั้งค่า; <br/><br/>            false เพื่อสร้างแผนภูมิโดยไม่มีซีรีส์และมีการตั้งค่าอย่างน้อยที่สุดซึ่งทำให้การสร้างเร็วขึ้น. |
