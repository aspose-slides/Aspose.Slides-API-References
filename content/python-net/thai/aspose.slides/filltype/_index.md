## FillType การกำหนดค่า

กำหนดประเภทการเติมภายในของวัตถุภาพต่างๆ.

ประเภท FillType มีสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| NOT_DEFINED | ประเภทการเติมไม่ได้กำหนด. |
| NO_FILL | ไม่มีการเติม. |
| SOLID | เติมด้วยสีทึบ. |
| GRADIENT | การเติมเป็นแบบไล่ระดับสี. |
| PATTERN | ใช้ลายแบบทำซ้ำเพื่อเติมวัตถุ. |
| PICTURE | ใช้รูปภาพเดียวเพื่อเติมวัตถุ. |
| GROUP | วัตถุภาพสืบทอดคุณสมบัติการเติมจากกลุ่ม. |
