## NormalViewRestoredProperties คลาส

ระบุขนาดของพื้นที่สไลด์ ((width เมื่อเป็น child ของ restoredTop, height เมื่อเป็น\n            child ของ restoredLeft) ของมุมมองปกติ, เมื่อพื้นที่เป็นขนาด restored ที่เปลี่ยนแปลงได้ (ไม่ย่อหรือขยายเต็ม).

ประเภท NormalViewRestoredProperties เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`dimension_size`](/slides/python-net/th/aspose.slides/normalviewrestoredproperties/dimension_size/) | ระบุขนาดของพื้นที่สไลด์ (width เมื่อเป็น child ของ RestoredTop, height เมื่อเป็น<br/>            child ของ RestoredLeft).<br/>            อ่าน/เขียน **float**. |
| [`auto_adjust`](/slides/python-net/th/aspose.slides/normalviewrestoredproperties/auto_adjust/) | ระบุว่าขนาดของพื้นที่เนื้อหาด้านข้างควรชดเชยขนาดใหม่<br/>            เมื่อปรับขนาดหน้าต่างที่มีมุมมองอยู่ในแอปพลิเคชัน<br/>            อ่าน/เขียน **bool**. |
