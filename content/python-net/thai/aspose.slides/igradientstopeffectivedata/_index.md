## IGradientStopEffectiveData คลาส

The IGradientStopEffectiveData type เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`position`](/slides/python-net/th/aspose.slides/igradientstopeffectivedata/position/) | ส่งคืนตำแหน่ง (0..1) ของจุดไล่ระดับสี.<br/>            อ่านอย่างเดียว **float**. |
| [`color`](/slides/python-net/th/aspose.slides/igradientstopeffectivedata/color/) | ส่งคืนสีของจุดไล่ระดับสี.<br/>            อ่านอย่างเดียว [`Color`](/slides/python-net/th/aspose.slides/color). |
