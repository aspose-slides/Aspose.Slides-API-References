## x คุณสมบัติ
รับหรือกำหนดพิกัด x ของมุมซ้ายบนของรูปร่าง, วัดเป็นจุด.
            อ่าน/เขียน **float**.

### หมายเหตุ

ค่าที่คืนมาจะกำหนดเสมอและไม่เคยเป็น **float**.
            ค่าที่กำหนดต้องถูกกำหนดเช่นกัน; กำหนด **float** เฉพาะให้คุณสมบัติของอินสแตนซ์ `RawFrame` เท่านั้น.

### คำนิยาม:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
