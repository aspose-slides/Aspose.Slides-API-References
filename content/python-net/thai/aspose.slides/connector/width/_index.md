## width คุณสมบัติ
รับหรือกำหนด width ของ shape, วัดเป็น points.
อ่าน/เขียน **float**.

### หมายเหตุ

ค่าที่ส่งกลับจะได้รับการกำหนดเสมอและไม่เคยเป็น **float**.
ค่าที่กำหนดต้องได้กำหนดเช่นกัน; กำหนด **float** เฉพาะคุณสมบัติของอินสแตนซ์ `RawFrame` เท่านั้น.
