## height คุณสมบัติ
รับหรือกำหนดค่า height ของรูปร่างที่วัดเป็นจุด.
อ่าน/เขียน **float**.

### หมายเหตุ

ค่าที่ส่งกลับจะถูกกำหนดเสมอและไม่เป็น **float**.
ค่าที่กำหนดต้องถูกกำหนดเช่นกัน; กำหนด **float** เฉพาะให้กับคุณสมบัติของอินสแตนซ์ `RawFrame` เท่านั้น.
