## คุณสมบัติ x
รับหรือกำหนดค่าพิกัด x ของมุมซ้าย-บนของรูปร่าง หน่วยเป็นจุด.
            อ่าน/เขียน **float**.

### หมายเหตุ

ค่าที่ส่งกลับมาจะถูกกำหนดเสมอและจะไม่มี **float**.
            ค่าที่กำหนดต้องถูกกำหนดเช่นกัน; ให้กำหนด **float** เฉพาะกับคุณสมบัติของอินสแตนซ์ `RawFrame`.

### คำนิยาม:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
