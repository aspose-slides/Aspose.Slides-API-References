## x คุณสมบัติ
รับหรือกำหนดพิกัด X ของมุมบนซ้ายของรูปร่าง, มีหน่วยเป็นจุด.
            อ่าน/เขียน **float**.


### หมายเหตุ

ค่าที่ส่งกลับมักจะถูกกำหนดเสมอและไม่เคยเป็น **float**.
            ค่าที่กำหนดต้องถูกกำหนดเช่นกัน; ให้กำหนด **float** เฉพาะกับคุณสมบัติของออบเจกต์ `RawFrame` เท่านั้น.

### นิยาม:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
