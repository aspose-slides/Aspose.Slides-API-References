## คลาส ViewProperties

คุณสมบัติมุมมองทั่วทั้งการนำเสนอ.

ประเภท ViewProperties เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`last_view`](/slides/python-net/th/aspose.slides/viewproperties/last_view/) | ระบุโหมดมุมมองที่ใช้เมื่อบันทึกเอกสารการนำเสนอเป็นครั้งสุดท้าย.<br/>            อ่าน/เขียน [`ViewType`](/slides/python-net/th/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/th/aspose.slides/viewproperties/show_comments/) | ระบุว่าจะต้องแสดงความคิดเห็นสไลด์หรือไม่.<br/>            อ่าน/เขียน [`NullableBool`](/slides/python-net/th/aspose.slides/nullablebool). |
| [`normal_view_properties`](/slides/python-net/th/aspose.slides/viewproperties/normal_view_properties/) | แสดงคุณสมบัติมุมมองปกติ. มุมมองปกติประกอบด้วย<br/>            สามส่วนเนื้อหา: สไลด์เอง, พื้นที่เนื้อหาด้านข้าง, และพื้นที่เนื้อหาด้านล่าง.<br/>            อ่านอย่างเดียว [`INormalViewProperties`](/slides/python-net/th/aspose.slides/inormalviewproperties). |
| [`slide_view_properties`](/slides/python-net/th/aspose.slides/viewproperties/slide_view_properties/) | ระบุคุณสมบัติมุมมองทั่วไปที่เชื่อมโยงกับโหมดมุมมองสไลด์.<br/>            อ่านอย่างเดียว [`ICommonSlideViewProperties`](/slides/python-net/th/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/th/aspose.slides/viewproperties/notes_view_properties/) | ระบุคุณสมบัติมุมมองทั่วไปที่เชื่อมโยงกับโหมดมุมมองบันทึกโน้ต.<br/>            อ่านอย่างเดียว [`ICommonSlideViewProperties`](/slides/python-net/th/aspose.slides/icommonslideviewproperties). |
| [`grid_spacing`](/slides/python-net/th/aspose.slides/viewproperties/grid_spacing/) | คืนค่าหรือกำหนดระยะห่างของกริดที่ควรใช้สำหรับกริดพื้นฐานของเอกสารการนำเสนอ, หน่วยเป็นพ้อยท์. <br/>            อ่าน/เขียน **float**. |
