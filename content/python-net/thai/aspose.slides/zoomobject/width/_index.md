## width คุณสมบัติ
รับหรือกำหนดค่า width ของ shape ที่วัดเป็นจุด.
            อ่าน/เขียน **float**.


### หมายเหตุ

ค่าที่ส่งกลับจะถูกกำหนดเสมอและไม่เป็น **float**.
            ค่าที่กำหนดต้องถูกกำหนดเช่นกัน; ให้กำหนด **float** เฉพาะกับคุณสมบัติของอินสแตนซ์ `RawFrame` เท่านั้น.
