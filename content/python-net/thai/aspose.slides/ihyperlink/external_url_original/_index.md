## external_url_original คุณสมบัติ
Represents a hyperlink that is set for this portion without regard to the actual content of the portion.

            PowerPoint ทำงานโดยเฉพาะสำหรับลิงก์และข้อความที่สอดคล้องกันในส่วนหนึ่ง มันอนุญาตให้สร้างข้อความสำหรับลิงก์ไฮเปอร์ใน
            รูปแบบของ URL ที่ถูกต้อง ซึ่งแตกต่างจากที่อยู่จริงของลิงก์ ในกรณีนี้ เมื่อคุณดูลิงก์ในหน้าต่างแก้ไข มันจะถูกเปลี่ยนให้ตรงกับส่วนข้อความ คุณสมบัตินี้แสดงค่าต้นฉบับของลิงก์ไฮเปอร์.
