## ShapeElementFillSource enum

แสดงถึงวิธีที่ shape element ควรถูกเติม.

ประเภท ShapeElementFillSource เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| NO_FILL | ไม่เติม primitive. |
| SHAPE | ใช้การเติมของ shape. |
| LIGHTEN | ใช้การทำให้ shape สว่าง. |
| LIGHTEN_LESS | ใช้การทำให้ shape สว่างน้อยลง. |
| DARKEN | ใช้การทำให้ shape มืด. |
| DARKEN_LESS | ใช้การทำให้ shape มืดน้อยลง. |
