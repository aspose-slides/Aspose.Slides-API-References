## ITextSearchOptions คลาส

แสดงตัวเลือกที่สามารถใช้เพื่อค้นหาข้อความใน Presentation, Slide หรือ TextFrame.

ITextSearchOptions ประเภท แสดงสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`case_sensitive`](/slides/python-net/th/aspose.slides/itextsearchoptions/case_sensitive/) | ตั้งค่า true เพื่อใช้การค้นหาแบบแยกตัวพิมพ์ใหญ่-เล็ก, false - หากไม่ต้องการ.<br/>            อ่าน/เขียน **bool**. |
| [`whole_words_only`](/slides/python-net/th/aspose.slides/itextsearchoptions/whole_words_only/) | ตั้งค่า true เพื่อจับคู่เฉพาะคำเต็ม, false - หากไม่ต้องการ.<br/>            อ่าน/เขียน **bool**. |
| [`include_notes`](/slides/python-net/th/aspose.slides/itextsearchoptions/include_notes/) | ตั้งค่า `true` เพื่อรวมข้อความที่อยู่ในโน้ตสไลด์ <br/>            เมื่อทำการค้นหาข้อความ, การแทนที่, หรือการเน้นข้อความ.<br/>            ค่าปริยายคือ `false`. |
