## IThreeDFormat คลาส

แทนคุณสมบัติเชิง 3-D

IThreeDFormat type เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`contour_width`](/slides/python-net/th/aspose.slides/ithreedformat/contour_width/) | คืนค่า หรือ กำหนด ความกว้างของคอนทัวร์ 3D<br/>Read/write **float**. |
| [`extrusion_height`](/slides/python-net/th/aspose.slides/ithreedformat/extrusion_height/) | คืนค่า หรือ กำหนด ความสูงของเอฟเฟกต์ extrusion<br/>Read/write **float**. |
| [`depth`](/slides/python-net/th/aspose.slides/ithreedformat/depth/) | คืนค่า หรือ กำหนด ความลึกของรูปร่าง 3D<br/>Read/write **float**. |
| [`bevel_top`](/slides/python-net/th/aspose.slides/ithreedformat/bevel_top/) | คืนค่า หรือ กำหนด ประเภทของ bevel ด้านบน 3D<br/>Read-only [`IShapeBevel`](/slides/python-net/th/aspose.slides/ishapebevel). |
| [`bevel_bottom`](/slides/python-net/th/aspose.slides/ithreedformat/bevel_bottom/) | คืนค่า หรือ กำหนด ประเภทของ bevel ด้านล่าง 3D<br/>Read-only [`IShapeBevel`](/slides/python-net/th/aspose.slides/ishapebevel). |
| [`contour_color`](/slides/python-net/th/aspose.slides/ithreedformat/contour_color/) | คืนค่า หรือ กำหนด สีของคอนทัวร์<br/>Read-only [`IColorFormat`](/slides/python-net/th/aspose.slides/icolorformat). |
| [`extrusion_color`](/slides/python-net/th/aspose.slides/ithreedformat/extrusion_color/) | คืนค่า หรือ กำหนด สีของ extrusion<br/>Read-only [`IColorFormat`](/slides/python-net/th/aspose.slides/icolorformat). |
| [`camera`](/slides/python-net/th/aspose.slides/ithreedformat/camera/) | คืนค่า หรือ กำหนด การตั้งค่ากล้อง<br/>Read-only [`ICamera`](/slides/python-net/th/aspose.slides/icamera). |
| [`light_rig`](/slides/python-net/th/aspose.slides/ithreedformat/light_rig/) | คืนค่า หรือ กำหนด ประเภทของแสง<br/>Read-only [`ILightRig`](/slides/python-net/th/aspose.slides/ilightrig). |
| [`material`](/slides/python-net/th/aspose.slides/ithreedformat/material/) | คืนค่า หรือ กำหนด ประเภทของวัสดุ<br/>Read/write [`MaterialPresetType`](/slides/python-net/th/aspose.slides/materialpresettype). |
