## การกำหนดค่า ColorType

แสดงถึงโหมดสีที่แตกต่างกัน

ประเภท ColorType เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| NOT_DEFINED | สีไม่ได้กำหนดเลย |
| RGB | สี RGB มาตรฐาน 24 บิต |
| RGB_PERCENTAGE | สี RGB ความละเอียดสูง |
| HSL | สี HSL ความละเอียดสูง |
| SCHEME | สีตามสคีม |
| SYSTEM | สีของระบบ |
| PRESET | สีที่กำหนดล่วงหน้า |
