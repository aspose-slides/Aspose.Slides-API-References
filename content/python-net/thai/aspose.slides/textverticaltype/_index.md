## การนับประเภท TextVerticalType

กำหนดโหมดการเขียนแนวตั้งสำหรับข้อความ.

ประเภท TextVerticalType มีสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| NOT_DEFINED | ไม่ได้กำหนด. |
| HORIZONTAL | ข้อความแนวนอน. |
| VERTICAL | ข้อความแนวตั้ง. |
| VERTICAL270 | ข้อความแนวตั้ง 270 องศา. |
| WORD_ART_VERTICAL | ข้อความแนวตั้ง WordArt. |
| EAST_ASIAN_VERTICAL | ข้อความแนวตั้งเอเชียตะวันออก. |
| MONGOLIAN_VERTICAL | ข้อความแนวตั้งมองโกเลีย. |
| WORD_ART_VERTICAL_RIGHT_TO_LEFT | ข้อความแนวตั้ง WordArt จากขวาไปซ้าย. |
