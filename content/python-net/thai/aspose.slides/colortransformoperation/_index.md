## ColorTransformOperation การกำหนดค่าแบบนับ

กำหนดการดำเนินการแปลงสี.

ประเภท ColorTransformOperation เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| TINT | ทำให้สีอ่อนขึ้น. พารามิเตอร์อยู่ในช่วงระหว่าง 0 (สีต้นฉบับ) และ 1 (สีขาว). |
| SHADE | ทำให้สีเข้มขึ้น. พารามิเตอร์อยู่ในช่วงระหว่าง 0 (สีต้นฉบับ) และ 1 (สีดำ). |
| COMPLEMENT | เปลี่ยนสีเป็นสี RGB ที่ตรงกันข้าม.<br/>            m = Max(r, g, b);<br/>            r = m - r;<br/>            g = m - g;<br/>            b = m - b; |
| INVERSE | เปลี่ยนสีเป็นสีที่กลับด้าน.<br/>            r = 1 - r;<br/>            g = 1 - g;<br/>            b = 1 - b; |
| GRAYSCALE | เปลี่ยนสีเป็นสีเทาที่มีความสว่างเท่ากัน. พารามิเตอร์ถูกละเลย. |
| SET_ALPHA | กำหนดส่วนประกอบแอลฟาของสี. พารามิเตอร์อยู่ในช่วงระหว่าง 0 (โปร่งแสง) และ 1 (ทึบแสง). |
| ADD_ALPHA | เพิ่มค่าพารามิเตอร์ไปยังส่วนประกอบแอลฟาของสี. พารามิเตอร์อยู่ในช่วงระหว่าง -1 และ 1. |
| MULTIPLY_ALPHA | คูณส่วนประกอบแอลฟากับค่าพารามิเตอร์. |
| SET_HUE | เปลี่ยนส่วนประกอบสีฮิวของสีให้เป็นค่าพารามิเตอร์. พารามิเตอร์อยู่ในช่วงระหว่าง 0 ถึง 360. |
| ADD_HUE | เพิ่มค่าพารามิเตอร์ไปยังส่วนประกอบสีฮิวของสี. พารามิเตอร์อยู่ในช่วงระหว่าง -360 ถึง 360. |
| MULTIPLY_HUE | คูณส่วนประกอบสีฮิวกับค่าพารามิเตอร์. |
| SET_SATURATION | เปลี่ยนส่วนประกอบความอิ่มของสีให้เป็นค่าพารามิเตอร์. พารามิเตอร์อยู่ในช่วงระหว่าง 0 ถึง 1. |
| ADD_SATURATION | เพิ่มค่าพารามิเตอร์ไปยังส่วนประกอบความอิ่มของสี. พารามิเตอร์อยู่ในช่วงระหว่าง -1 ถึง 1. |
| MULTIPLY_SATURATION | คูณส่วนประกอบความอิ่มกับค่าพารามิเตอร์. |
| SET_LUMINANCE | เปลี่ยนส่วนประกอบความสว่างของสีให้เป็นค่าพารามิเตอร์. พารามิเตอร์อยู่ในช่วงระหว่าง 0 ถึง 1. |
| ADD_LUMINANCE | เพิ่มค่าพารามิเตอร์ไปยังส่วนประกอบความสว่างของสี. พารามิเตอร์อยู่ในช่วงระหว่าง -1 ถึง 1. |
| MULTIPLY_LUMINANCE | คูณส่วนประกอบความสว่างกับค่าพารามิเตอร์. |
| SET_RED | เปลี่ยนส่วนประกอบสีแดงของสีให้เป็นค่าพารามิเตอร์. พารามิเตอร์อยู่ในช่วงระหว่าง 0 ถึง 1. |
| ADD_RED | เพิ่มค่าพารามิเตอร์ไปยังส่วนประกอบสีแดงของสี. พารามิเตอร์อยู่ในช่วงระหว่าง -1 ถึง 1. |
| MULTIPLY_RED | คูณส่วนประกอบสีแดงกับพารามิเตอร์. |
| SET_GREEN | เปลี่ยนส่วนประกอบสีเขียวของสีให้เป็นค่าพารามิเตอร์. พารามิเตอร์อยู่ในช่วงระหว่าง 0 ถึง 1. |
| ADD_GREEN | เพิ่มพารามิเตอร์ไปยังส่วนประกอบสีเขียวของสี. พารามิเตอร์อยู่ในช่วงระหว่าง -1 ถึง 1. |
| MULTIPLY_GREEN | คูณส่วนประกอบสีเขียวกับค่าพารามิเตอร์. |
| SET_BLUE | เปลี่ยนส่วนประกอบสีฟ้าของสีให้เป็นค่าพารามิเตอร์. พารามิเตอร์อยู่ในช่วงระหว่าง 0 ถึง 360. |
| ADD_BLUE | เพิ่มค่าพารามิเตอร์ไปยังส่วนประกอบสีฟ้าของสี. พารามิเตอร์อยู่ในช่วงระหว่าง -1 ถึง 1. |
| MULTIPLY_BLUE | คูณส่วนประกอบสีฟ้ากับค่าพารามิเตอร์. |
| GAMMA | การแก้ไขแกมมา. พารามิเตอร์ถูกละเลย. |
| INVERSE_GAMMA | การแก้ไขแกมมาผกผัน. พารามิเตอร์ถูกละเลย. |
