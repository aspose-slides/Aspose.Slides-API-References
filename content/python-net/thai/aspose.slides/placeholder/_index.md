## Placeholder คลาส

แสดงถึง placeholder บนสไลด์หนึ่ง.

ประเภท Placeholder เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`orientation`](/slides/python-net/th/aspose.slides/placeholder/orientation/) | ดึงหรือกำหนดทิศทางของ placeholder.<br/>            อ่านอย่างเดียว [`Orientation`](/slides/python-net/th/aspose.slides/orientation). |
| [`size`](/slides/python-net/th/aspose.slides/placeholder/size/) | ดึงหรือกำหนดขนาดของ placeholder.<br/>            อ่านอย่างเดียว [`PlaceholderSize`](/slides/python-net/th/aspose.slides/placeholdersize). |
| [`type`](/slides/python-net/th/aspose.slides/placeholder/type/) | ดึงหรือกำหนดประเภทของ placeholder.<br/>            อ่านอย่างเดียว [`PlaceholderType`](/slides/python-net/th/aspose.slides/placeholdertype). |
| [`index`](/slides/python-net/th/aspose.slides/placeholder/index/) | ดึงหรือกำหนดดัชนีของ placeholder.<br/>            อ่านอย่างเดียว **int**. |
