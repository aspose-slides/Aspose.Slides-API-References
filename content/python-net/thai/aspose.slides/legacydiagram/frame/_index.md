## คุณสมบัติของ frame
คืนค่า หรือกำหนดคุณสมบัติของ shape frame.
            อ่าน/เขียน [`IShapeFrame`](/slides/python-net/th/aspose.slides/ishapeframe).

### หมายเหตุ

ค่าของแต่ละ property ของอินสแตนซ์ IShapeFrame ที่คืนมาไม่ได้เป็น undefined (ไม่ใช่ NaN หรือ NotDefined).
            ค่าของแต่ละ property ของอินสแตนซ์ IShapeFrame ที่กำหนดไว้ต้องไม่เป็น undefined (ต้องไม่เป็น NaN หรือ NotDefined).
            คุณสามารถกำหนดค่า undefined สำหรับ property ของอินสแตนซ์ RawFrame
