## x คุณสมบัติ
รับหรือกำหนดค่าพิกัด x ของมุมซ้ายบนของรูปร่าง ซึ่งวัดเป็นพ้อยท์
            อ่าน/เขียน **float**.


### หมายเหตุ

ค่าที่คืนกลับมาจะถูกกำหนดเสมอและไม่เป็น **float**.
            ค่าที่กำหนดต้องถูกกำหนดเช่นกัน; ให้กำหนด **float** เพียงกับคุณสมบัติของอ็อบเจกต์ `RawFrame` เท่านั้น.

### คำนิยาม:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
