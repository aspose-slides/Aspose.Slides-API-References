## ConnectorLock คลาส

กำหนดว่าการดำเนินการใดถูกปิดใช้งานบน Connector ผู้ปกครอง

**การสืบทอด:**[`ConnectorLock`](/slides/python-net/th/aspose.slides/connectorlock) → [`BaseShapeLock`](/slides/python-net/th/aspose.slides/baseshapelock)

ชนิด ConnectorLock แสดงสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`no_locks`](/slides/python-net/th/aspose.slides/connectorlock/no_locks/) | คืนค่า true หาก lock-flags ทั้งหมดถูกปิดใช้งาน.<br/>            อ่านอย่างเดียว **bool**. |
| [`grouping_locked`](/slides/python-net/th/aspose.slides/connectorlock/grouping_locked/) | กำหนดว่าการเพิ่ม shape นี้เข้าไปในกลุ่มถูกห้ามหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`select_locked`](/slides/python-net/th/aspose.slides/connectorlock/select_locked/) | กำหนดว่าการเลือก shape นี้ถูกห้ามหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`rotate_locked`](/slides/python-net/th/aspose.slides/connectorlock/rotate_locked/) | กำหนดว่าการเปลี่ยนมุมการหมุนของ shape นี้ถูกห้ามหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/th/aspose.slides/connectorlock/aspect_ratio_locked/) | กำหนดว่า shape ต้องรักษาอัตราส่วนภาพเมื่อปรับขนาดหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`position_move`](/slides/python-net/th/aspose.slides/connectorlock/position_move/) | กำหนดว่าการย้าย shape นี้ถูกห้ามหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`size_locked`](/slides/python-net/th/aspose.slides/connectorlock/size_locked/) | กำหนดว่าการปรับขนาด shape นี้ถูกห้ามหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`edit_points_locked`](/slides/python-net/th/aspose.slides/connectorlock/edit_points_locked/) | กำหนดว่าการเปลี่ยนรูปทรงโดยตรงของ shape นี้ถูกห้ามหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`adjust_handles_locked`](/slides/python-net/th/aspose.slides/connectorlock/adjust_handles_locked/) | กำหนดว่าการเปลี่ยนค่าการปรับถูกห้ามหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`arrowheads_locked`](/slides/python-net/th/aspose.slides/connectorlock/arrowheads_locked/) | กำหนดว่าการเปลี่ยนหัวลูกศรถูกห้ามหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`shape_type_locked`](/slides/python-net/th/aspose.slides/connectorlock/shape_type_locked/) | กำหนดว่าการเปลี่ยนประเภทของ shape ถูกห้ามหรือไม่.<br/>            อ่าน/เขียน **bool**. |
