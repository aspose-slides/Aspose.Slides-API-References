## คลาส Control

เป็นตัวแทนของคอนโทรล ActiveX.

ประเภท Control เปิดเผยสมาชิกต่อไปนี้:

## Properties

| Property | Description |
| :- | :- |
| [`persistence`](/slides/python-net/th/aspose.slides/control/persistence/) | รับวิธีที่ใช้เก็บคุณสมบัติของคอนโทรล ActiveX.<br/>            อ่านอย่างเดียว [`PersistenceType`](/slides/python-net/th/aspose.slides/persistencetype). |
| [`name`](/slides/python-net/th/aspose.slides/control/name/) | รับหรือกำหนดชื่อของคอนโทรลนี้.<br/>            อ่าน/เขียน **str**. |
| [`class_id`](/slides/python-net/th/aspose.slides/control/class_id/) | รับ class id ของคอนโทรลนี้.<br/>            อ่านเท่านั้น **System.Guid**. |
| [`substitute_picture_format`](/slides/python-net/th/aspose.slides/control/substitute_picture_format/) | คืนค่าอ็อบเจกต์คุณสมบัติการเติมภาพของ Control.<br/>            อ่านเท่านั้น [`IPictureFillFormat`](/slides/python-net/th/aspose.slides/ipicturefillformat). |
| [`frame`](/slides/python-net/th/aspose.slides/control/frame/) | รับหรือกำหนดเฟรมของคอนโทรล.<br/>            อ่าน/เขียน [`IShapeFrame`](/slides/python-net/th/aspose.slides/ishapeframe). |
| [`properties`](/slides/python-net/th/aspose.slides/control/properties/) | คืนค่าคอลเลคชันของคุณสมบัติ ActiveX.<br/>            หมายเหตุ: Aspose.Slides รองรับเฉพาะคุณสมบัติ ActiveX ที่เป็น XML เท่านั้น. หากคุณสมบัติเก็บในรูปแบบไบนารี, คุณสมบัตินี้จะคืนค่า None.<br/>            อ่านเท่านั้น [`IControlPropertiesCollection`](/slides/python-net/th/aspose.slides/icontrolpropertiescollection). |
| [`active_x_control_binary`](/slides/python-net/th/aspose.slides/control/active_x_control_binary/) | ระบุการคงอยู่ของคอนโทรล ActiveX เมื่อวิธีที่ใช้ในการคงอยู่คือ PersistStream, PersistStreamInit หรือ PersistStorage. |
