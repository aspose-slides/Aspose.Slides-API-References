## IPoint คลาส

แสดงจุดการเคลื่อนไหว.

ประเภท IPoint เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`time`](/slides/python-net/th/aspose.slides.animation/ipoint/time/) | แสดงค่าระยะเวลา.<br/>            อ่าน/เขียน **float**. |
| [`value`](/slides/python-net/th/aspose.slides.animation/ipoint/value/) | แสดงค่าจุด.<br/>            มีเฉพาะ: bool, ColorFormat, float, int, string.<br/>            อ่าน/เขียน **any**. |
| [`formula`](/slides/python-net/th/aspose.slides.animation/ipoint/formula/) | สูตรภายในค่า, แอตทริบิวต์ from, to, by สามารถประกอบด้วยสิ่งต่อไปนี้:<br/>            ตัวดำเนินการคณิตศาสตร์พื้นฐาน: ‘+’, ‘-‘, ‘*’, ‘/’, ‘^’, ‘%’ (mod)<br/>            ค่าคงที่: ‘pi’ ‘e’<br/>            ตัวดำเนินการเงื่อนไข: ‘abs’, ‘min’, ‘max’, ‘?’ (if)<br/>            ตัวดำเนินการเปรียบเทียบ: '==' , '>=', '', '!=', '!'<br/>            ตัวดำเนินการตรีโกณมิติ: ‘sin()’, ‘cos()’, ‘tan()’, ‘asin()’, ‘acos()’, ‘atan()’<br/>            ลอการิทึมธรรมชาติ ‘ln()’<br/>            การอ้างอิงคุณสมบัติ (คุณสมบัติที่โฮสต์รองรับ)<br/>            <br/>            ตัวอย่าง: "#ppt_x+(cos(-2*pi*(1-$))*-#ppt_x-sin(-2*pi*(1-$))*(1-#ppt_y))*(1-$)"<br/>            อ่าน/เขียน **str**. |
