## EffectChartMajorGroupingType การกำหนดค่า

ระบุประเภทของเอฟเฟกต์การเคลื่อนไหวสำหรับองค์ประกอบของแผนภูมิ

EffectChartMajorGroupingType type เผยให้เห็นสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| BY_SERIES | ทำให้แผนภูมิเคลื่อนไหวตามซีรีส์ |
| BY_CATEGORY | ทำให้แผนภูมิเคลื่อนไหวตามหมวดหมู่ |
