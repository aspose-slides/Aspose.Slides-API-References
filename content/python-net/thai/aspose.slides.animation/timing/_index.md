## คลาส Timing

แสดงถึงการกำหนดเวลาแอนิเมชัน

ประเภท Timing เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`accelerate`](/slides/python-net/th/aspose.slides.animation/timing/accelerate/) | อธิบายเปอร์เซ็นต์ของผลพฤติกรรมเร่งความเร็วของระยะเวลา.<br/>            **อ่าน/เขียน** **float**. |
| [`decelerate`](/slides/python-net/th/aspose.slides.animation/timing/decelerate/) | อธิบายเปอร์เซ็นต์ของผลพฤติกรรมชะลอความเร็วของระยะเวลา.<br/>            **อ่าน/เขียน** **float**. |
| [`auto_reverse`](/slides/python-net/th/aspose.slides.animation/timing/auto_reverse/) | อธิบายว่าจะเล่นแอนิเมชันโดยอัตโนมัติในทิศทางย้อนหลังจาก<br/>            เล่นในทิศทางไปข้างหน้า.<br/>            **อ่าน/เขียน** **bool**. |
| [`duration`](/slides/python-net/th/aspose.slides.animation/timing/duration/) | อธิบายระยะเวลาของผลแอนิเมชัน.<br/>            **อ่าน/เขียน** **float**. |
| [`repeat_count`](/slides/python-net/th/aspose.slides.animation/timing/repeat_count/) | อธิบายจำนวนครั้งที่ผลควรทำซ้ำ.<br/>            **อ่าน/เขียน** **float**. |
| [`repeat_until_end_slide`](/slides/python-net/th/aspose.slides.animation/timing/repeat_until_end_slide/) | คุณลักษณะนี้ระบุว่าผลจะทำซ้ำจนจบสไลด์หรือไม่.<br/>            **อ่าน/เขียน** **bool**. |
| [`repeat_until_next_click`](/slides/python-net/th/aspose.slides.animation/timing/repeat_until_next_click/) | คุณลักษณะนี้ระบุว่าผลจะทำซ้ำจนคลิกถัดไปหรือไม่.<br/>            **อ่าน/เขียน** **bool**. |
| [`repeat_duration`](/slides/python-net/th/aspose.slides.animation/timing/repeat_duration/) | อธิบายจำนวนครั้งที่ผลควรทำซ้ำ.<br/>            **อ่าน/เขียน** **float**. |
| [`restart`](/slides/python-net/th/aspose.slides.animation/timing/restart/) | ระบุว่าผลจะรีสตาร์ทหลังจากเสร็จสิ้นหรือไม่.<br/>            อ่าน/เขียน [`EffectRestartType`](/slides/python-net/th/aspose.slides.animation/effectrestarttype). |
| [`rewind`](/slides/python-net/th/aspose.slides.animation/timing/rewind/) | คุณลักษณะนี้ระบุว่าผลจะทำการย้อนกลับเมื่อเล่นเสร็จหรือไม่.<br/>            **อ่าน/เขียน** **bool**. |
| [`speed`](/slides/python-net/th/aspose.slides.animation/timing/speed/) | ระบุเปอร์เซ็นต์ที่ต้องการเร่ง (หรือลด) เวลา.<br/>            **อ่าน/เขียน** **float**. |
| [`trigger_delay_time`](/slides/python-net/th/aspose.slides.animation/timing/trigger_delay_time/) | อธิบายเวลาหน่วงหลังจากการทริกเกอร์.<br/>            **อ่าน/เขียน** **float**. |
| [`trigger_type`](/slides/python-net/th/aspose.slides.animation/timing/trigger_type/) | อธิบายประเภทของทริกเกอร์.<br/>            **อ่าน/เขียน** [`EffectTriggerType`](/slides/python-net/th/aspose.slides.animation/effecttriggertype). |
