## คลาส IMotionEffect

แสดงพฤติกรรมของเอฟเฟ็กต์การเคลื่อนที่ของเอฟเฟ็กต์

ประเภท IMotionEffect เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`from_address`](/slides/python-net/th/aspose.slides.animation/imotioneffect/from_address/) | ระบุพิกัด x/y ที่เริ่มการเคลื่อนไหวจาก (เป็นเปอร์เซ็นต์). <br/>            อ่าน/เขียน [`PointF`](/slides/python-net/th/aspose.slides/pointf). |
| [`to`](/slides/python-net/th/aspose.slides.animation/imotioneffect/to/) | ระบุตำแหน่งเป้าหมายสำหรับเอฟเฟ็กต์การเคลื่อนไหวของการแอนิเมชัน (เป็นเปอร์เซ็นต์)<br/>            อ่าน/เขียน [`PointF`](/slides/python-net/th/aspose.slides/pointf). |
| [`by`](/slides/python-net/th/aspose.slides.animation/imotioneffect/by/) | อธิบายค่าการชดเชยเชิงสัมพันธ์สำหรับการแอนิเมชัน (เป็นเปอร์เซ็นต์)<br/>            อ่าน/เขียน [`PointF`](/slides/python-net/th/aspose.slides/pointf). |
| [`rotation_center`](/slides/python-net/th/aspose.slides.animation/imotioneffect/rotation_center/) | อธิบายศูนย์กลางการหมุนที่ใช้ในการหมุนเส้นทางการเคลื่อนไหวด้วยมุม X<br/>            อ่าน/เขียน [`PointF`](/slides/python-net/th/aspose.slides/pointf). |

| [`path_edit_mode`](/slides/python-net/th/aspose.slides.animation/imotioneffect/path_edit_mode/) | ระบุว่าเส้นทางการเคลื่อนไหวเคลื่อนที่อย่างไรเมื่อรูปร่างถูกย้าย<br/>            อ่าน/เขียน [`MotionPathEditMode`](/slides/python-net/th/aspose.slides.animation/motionpatheditmode). |
