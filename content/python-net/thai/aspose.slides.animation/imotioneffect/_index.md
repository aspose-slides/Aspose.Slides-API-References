## IMotionEffect คลาส

แสดงพฤติกรรมของเอฟเฟกต์การเคลื่อนที่ของเอฟเฟ็กต์

ประเภท IMotionEffect มีสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`from_`](/slides/python-net/th/aspose.slides.animation/imotioneffect/from_/) | ระบุพิกัด x/y เพื่อเริ่มแอนิเมชันจาก (เป็นเปอร์เซ็นต์). <br/>            อ่าน/เขียน [`PointF`](/slides/python-net/th/aspose.slides/pointf). |
| [`to`](/slides/python-net/th/aspose.slides.animation/imotioneffect/to/) | ระบุตำแหน่งเป้าหมายสำหรับเอฟเฟ็กต์การเคลื่อนไหวของแอนิเมชัน (เป็นเปอร์เซ็นต์).<br/>            อ่าน/เขียน [`PointF`](/slides/python-net/th/aspose.slides/pointf). |
| [`by`](/slides/python-net/th/aspose.slides.animation/imotioneffect/by/) | อธิบายค่าการออฟเซตเชิงสัมพัทธ์สำหรับแอนิเมชัน (เป็นเปอร์เซ็นต์).<br/>            อ่าน/เขียน [`PointF`](/slides/python-net/th/aspose.slides/pointf). |
| [`rotation_center`](/slides/python-net/th/aspose.slides.animation/imotioneffect/rotation_center/) | อธิบายศูนย์กลางของการหมุนที่ใช้ในการหมุนเส้นทางการเคลื่อนที่ด้วยมุม X.<br/>            อ่าน/เขียน [`PointF`](/slides/python-net/th/aspose.slides/pointf). |
| [`origin`](/slides/python-net/th/aspose.slides.animation/imotioneffect/origin/) | ระบุว่าต้นกำเนิดของเส้นทางการเคลื่อนที่สัมพันธ์กับอะไร เช่น การจัดวางของสไลด์,<br/>            หรือพาเรนต์.<br/>            อ่าน/เขียน [`MotionOriginType`](/slides/python-net/th/aspose.slides.animation/motionorigintype). |

| [`path_edit_mode`](/slides/python-net/th/aspose.slides.animation/imotioneffect/path_edit_mode/) | ระบุว่าทางเคลื่อนที่เคลื่อนที่อย่างไรเมื่อรูปร่างถูกย้าย.<br/>            อ่าน/เขียน [`MotionPathEditMode`](/slides/python-net/th/aspose.slides.animation/motionpatheditmode). |
| [`angle`](/slides/python-net/th/aspose.slides.animation/imotioneffect/angle/) | อธิบายมุมเชิงสัมพันธ์ของเส้นทางการเคลื่อนที่.<br/>            อ่าน/เขียน **float**. |
