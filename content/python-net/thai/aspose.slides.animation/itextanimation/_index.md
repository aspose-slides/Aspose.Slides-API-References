## ITextAnimation คลาส

แสดงการเคลื่อนไหวของข้อความ.

ประเภท ITextAnimation เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`build_type`](/slides/python-net/th/aspose.slides.animation/itextanimation/build_type/) | รายการประเภทการสร้าง (เช่น ย่อหน้า 1,2,3, ทั้งหมดพร้อมกัน) ของการเคลื่อนไหวของข้อความ.<br/>            อ่าน/เขียน [`ITextAnimation.build_type`](/slides/python-net/th/aspose.slides.animation/itextanimation/build_type). |
| [`effect_animate_background_shape`](/slides/python-net/th/aspose.slides.animation/itextanimation/effect_animate_background_shape/) | เอฟเฟกต์รูปทรงที่เชื่อมโยงกับกลุ่มหรือไม่ (ไม่มี)<br/>            อ่าน/เขียน [`IEffect`](/slides/python-net/th/aspose.slides.animation/ieffect). |

## เมธอด

| เมธอด | คำอธิบาย |
| :- | :- |
| [`add_effect(self, effect_type, subtype, trigger_type)`](/slides/python-net/th/aspose.slides.animation/itextanimation/add_effect/#effecttype-effectsubtype-effecttriggertype) | เพิ่มเอฟเฟกต์ใหม่ไปที่ส่วนท้ายของลำดับปัจจุบันไปยังส่วนท้ายของการเคลื่อนไหวของข้อความในกลุ่ม.<br/>            ใช้ได้เฉพาะเมื่อจำนวนย่อหน้าของข้อความเท่าหรือมากกว่าจำนวนเอฟเฟกต์ของกลุ่มนี้! |
