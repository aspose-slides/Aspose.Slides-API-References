## ITiming คลาส

แสดงถึงการจัดเวลาแอนิเมชัน.

ประเภท ITiming เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`accelerate`](/slides/python-net/th/aspose.slides.animation/itiming/accelerate/) | อธิบายเปอร์เซ็นต์ของผลการเร่งพฤติกรรมตามระยะเวลา.<br/>            อ่าน/เขียน **float**. |
| [`decelerate`](/slides/python-net/th/aspose.slides.animation/itiming/decelerate/) | อธิบายเปอร์เซ็นต์ของผลการชะลอพฤติกรรมตามระยะเวลา.<br/>            อ่าน/เขียน **float**. |
| [`auto_reverse`](/slides/python-net/th/aspose.slides.animation/itiming/auto_reverse/) | อธิบายว่าการแอนิเมชันควรทำการเล่นแบบย้อนหลังจากเล่นในทิศทางข้างหน้าโดยอัตโนมัติหรือไม่.<br/>            อ่าน/เขียน **bool**. |
| [`duration`](/slides/python-net/th/aspose.slides.animation/itiming/duration/) | อธิบายระยะเวลาของเอฟเฟกต์แอนิเมชัน.<br/>            อ่าน/เขียน **float**. |
| [`repeat_count`](/slides/python-net/th/aspose.slides.animation/itiming/repeat_count/) | อธิบายจำนวนครั้งที่เอฟเฟกต์ควรทำซ้ำ.<br/>            อ่าน/เขียน **float**. |
| [`repeat_until_end_slide`](/slides/python-net/th/aspose.slides.animation/itiming/repeat_until_end_slide/) | คุณลักษณะนี้ระบุว่าเอฟเฟกต์จะทำซ้ำจนถึงจบสไลด์หรือไม่.<br/>             อ่าน/เขียน **bool**. |
| [`repeat_until_next_click`](/slides/python-net/th/aspose.slides.animation/itiming/repeat_until_next_click/) | คุณลักษณะนี้ระบุว่าเอฟเฟกต์จะทำซ้ำจนถึงคลิกถัดไปหรือไม่.<br/>             อ่าน/เขียน **bool**. |
| [`repeat_duration`](/slides/python-net/th/aspose.slides.animation/itiming/repeat_duration/) | อธิบายจำนวนครั้งที่เอฟเฟกต์ควรทำซ้ำ.<br/>            อ่าน/เขียน **float**. |
| [`restart`](/slides/python-net/th/aspose.slides.animation/itiming/restart/) | ระบุว่าเอฟเฟกต์จะรีสตาร์ตหลังจากเสร็จสมบูรณ์หรือไม่.<br/>            อ่าน/เขียน [`EffectRestartType`](/slides/python-net/th/aspose.slides.animation/effectrestarttype). |
| [`speed`](/slides/python-net/th/aspose.slides.animation/itiming/speed/) | ระบุเปอร์เซ็นต์ที่ต้องการเร่ง (หรือชะลอ) เวลา.<br/>            อ่าน/เขียน **float**. |
| [`trigger_delay_time`](/slides/python-net/th/aspose.slides.animation/itiming/trigger_delay_time/) | อธิบายเวลาหน่วงหลังจากทริกเกอร์.<br/>            อ่าน/เขียน **float**. |
| [`trigger_type`](/slides/python-net/th/aspose.slides.animation/itiming/trigger_type/) | อธิบายประเภทของทริกเกอร์.<br/>            อ่าน/เขียน [`EffectTriggerType`](/slides/python-net/th/aspose.slides.animation/effecttriggertype). |
| [`rewind`](/slides/python-net/th/aspose.slides.animation/itiming/rewind/) | คุณลักษณะนี้ระบุว่าเอฟเฟกต์จะย้อนกลับเมื่อเล่นเสร็จหรือไม่.<br/>             อ่าน/เขียน **bool**. |
