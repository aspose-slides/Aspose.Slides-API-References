## PropertyEffect คลาส

แสดงพฤติกรรมของเอฟเฟกต์คุณสมบัติ.

**การสืบทอด:**[`PropertyEffect`](/slides/python-net/th/aspose.slides.animation/propertyeffect) → [`Behavior`](/slides/python-net/th/aspose.slides.animation/behavior)

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
| :- | :- |
| [`accumulate`](/slides/python-net/th/aspose.slides.animation/propertyeffect/accumulate/) | แสดงว่าพฤติกรรมการเคลื่อนไหวถูกรวบรวมกันหรือไม่.<br/>            อ่าน/เขียน [`NullableBool`](/slides/python-net/th/aspose.slides/nullablebool). |
| [`additive`](/slides/python-net/th/aspose.slides.animation/propertyeffect/additive/) | แสดงว่าพฤติกรรมการเคลื่อนไหวปัจจุบันถูกรวมกับการเคลื่อนไหวอื่นที่กำลังทำงานอยู่หรือไม่.<br/>            อ่าน/เขียน [`BehaviorAdditiveType`](/slides/python-net/th/aspose.slides.animation/behavioradditivetype). |
| [`properties`](/slides/python-net/th/aspose.slides.animation/propertyeffect/properties/) | แสดงคุณสมบัติของพฤติกรรม.<br/>            อ่านอย่างเดียว [`IBehaviorPropertyCollection`](/slides/python-net/th/aspose.slides.animation/ibehaviorpropertycollection). |
| [`timing`](/slides/python-net/th/aspose.slides.animation/propertyeffect/timing/) | แสดงคุณสมบัติการกำหนดเวลา สำหรับพฤติกรรมเอฟเฟกต์.<br/>            อ่าน/เขียน [`ITiming`](/slides/python-net/th/aspose.slides.animation/itiming). |
| [`from_`](/slides/python-net/th/aspose.slides.animation/propertyeffect/from_/) | ระบุค่าตั้งต้นของการเคลื่อนไหว.<br/>            อ่าน/เขียน **str**. |
| [`to`](/slides/python-net/th/aspose.slides.animation/propertyeffect/to/) | ระบุค่าปลายของการเคลื่อนไหว.<br/>            อ่าน/เขียน **str**. |
| [`by`](/slides/python-net/th/aspose.slides.animation/propertyeffect/by/) | ระบุค่าชดเชยเชิงสัมพันธ์สำหรับการเคลื่อนไหวเมื่อเทียบกับตำแหน่งของมัน<br/>            ก่อนเริ่มการเคลื่อนไหว.<br/>            อ่าน/เขียน **str**. |
| [`value_type`](/slides/python-net/th/aspose.slides.animation/propertyeffect/value_type/) | ระบุประเภทของค่าคุณสมบัติ.<br/>            อ่าน/เขียน [`PropertyValueType`](/slides/python-net/th/aspose.slides.animation/propertyvaluetype). |
| [`calc_mode`](/slides/python-net/th/aspose.slides.animation/propertyeffect/calc_mode/) | ระบุโหมดการแทรกค่า (interpolation) สำหรับการเคลื่อนไหว<br/>            อ่าน/เขียน [`PropertyCalcModeType`](/slides/python-net/th/aspose.slides.animation/propertycalcmodetype). |
| [`points`](/slides/python-net/th/aspose.slides.animation/propertyeffect/points/) | ระบุจุดของการเคลื่อนไหว.<br/>            อ่าน/เขียน [`IPointCollection`](/slides/python-net/th/aspose.slides.animation/ipointcollection). |
