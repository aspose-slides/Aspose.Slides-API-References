## IBehavior คลาส

ประเภท IBehavior เปิดเผยสมาชิกต่อไปนี้:

## คุณสมบัติ

| Property | Description |
| :- | :- |
| [`accumulate`](/slides/python-net/th/aspose.slides.animation/ibehavior/accumulate/) | แทนว่าพฤติกรรมแอนิเมชันจะถูกรวบรวมหรือไม่<br/>            อ่าน/เขียน [`NullableBool`](/slides/python-net/th/aspose.slides/nullablebool). |
| [`additive`](/slides/python-net/th/aspose.slides.animation/ibehavior/additive/) | แทนว่าพฤติกรรมแอนิเมชันปัจจุบันจะถูกรวมกับแอนิเมชันอื่นที่กำลังทำงานหรือไม่<br/>            อ่าน/เขียน [`BehaviorAdditiveType`](/slides/python-net/th/aspose.slides.animation/behavioradditivetype). |
