## BuildType enumeration

กำหนดวิธีการที่ข้อความจะปรากฏบนรูปร่างขณะทำแอนิเมชัน

BuildType type เปิดเผยสมาชิกต่อไปนี้:

## ฟิลด์

| Field | คำอธิบาย |
| :- | :- |
| AS_ONE_OBJECT | กับรูปร่างที่บรรจุ |
| ALL_PARAGRAPHS_AT_ONCE | ทุกย่อหน้า |
| BY_LEVEL_PARAGRAPHS1 | ตามกลุ่มของย่อหน้าในระดับ 1 |
| BY_LEVEL_PARAGRAPHS2 | ตามกลุ่มของย่อหน้าในระดับ 2 |
| BY_LEVEL_PARAGRAPHS3 | ตามกลุ่มของย่อหน้าในระดับ 3 |
| BY_LEVEL_PARAGRAPHS4 | ตามกลุ่มของย่อหน้าในระดับ 4 |
| BY_LEVEL_PARAGRAPHS5 | ตามกลุ่มของย่อหน้าในระดับ 5 |
