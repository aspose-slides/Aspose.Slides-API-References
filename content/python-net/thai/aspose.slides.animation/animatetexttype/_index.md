## การเรียงลำดับ AnimateTextType

แสดงถึงประเภทข้อความที่ทำการเคลื่อนไหวของเอฟเฟกต์การเคลื่อนไหว

ประเภท AnimateTextType มีสมาชิกต่อไปนี้:

## ฟิลด์

| ฟิลด์ | คำอธิบาย |
| :- | :- |
| ALL_AT_ONCE | ทำให้ข้อความทั้งหมดเคลื่อนที่พร้อมกัน |
| BY_WORD | ทำให้ข้อความเคลื่อนที่ตามคำ |
| BY_LETTER | ทำให้ข้อความเคลื่อนที่ตามตัวอักษร |
