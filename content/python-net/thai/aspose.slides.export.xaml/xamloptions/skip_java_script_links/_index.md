## skip_java_script_links คุณสมบัติ
กำหนดว่าควรข้ามไฮเพอร์ลิงก์ที่มีการเรียกใช้ JavaScript หรือไม่เมื่อต้องบันทึกงานนำเสนอ. 
            อ่าน/เขียน **bool**. ค่าเริ่มต้นคือ **false** .


### หมายเหตุ

เมื่อคุณสมบัตินี้ตั้งค่าเป็น **true** , ไฮเพอร์ลิงก์ที่มีการเรียกใช้ JavaScript จะถูกละเว้นขณะบันทึก.


เมื่อคุณสมบัตินี้ตั้งค่าเป็น **false** , ไฮเพอร์ลิงก์ทั้งหมดจะถูกบันทึก.
