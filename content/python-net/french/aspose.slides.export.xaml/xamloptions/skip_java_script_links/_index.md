## skip_java_script_links propriété
Spécifie si les hyperliens contenant des appels JavaScript doivent être ignorés lors de l'enregistrement de la présentation. 
            Lecture/écriture **bool**. La valeur par défaut est **false** .


### Remarques

Lorsque cette propriété est définie sur **true**, les hyperliens contenant des appels JavaScript seront ignorés lors de l'enregistrement.

Lorsque cette propriété est définie sur **false**, tous les hyperliens seront enregistrés.
