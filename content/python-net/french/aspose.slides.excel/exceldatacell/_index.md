## ExcelDataCell classe

Représente une seule cellule dans un classeur Excel.

Le type ExcelDataCell expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`value`](/slides/python-net/fr/aspose.slides.excel/exceldatacell/value/) | Obtient la valeur contenue dans la cellule Excel. |
| [`name`](/slides/python-net/fr/aspose.slides.excel/exceldatacell/name/) | Obtient le nom de la cellule de données du graphique. |
| [`row`](/slides/python-net/fr/aspose.slides.excel/exceldatacell/row/) | Obtient l'indice basé zéro de la ligne dans la feuille de calcul où la cellule est située.<br/>            Lecture seule **int**. |
| [`column`](/slides/python-net/fr/aspose.slides.excel/exceldatacell/column/) | Obtient l'indice basé zéro de la colonne dans la feuille de calcul où la cellule est située.<br/>            Lecture seule **int**. |
