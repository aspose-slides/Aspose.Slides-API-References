## get_cells(self, formula, skip_hidden_cells) {#str-bool}
Récupère une collection de cellules du classeur qui correspondent à la formule spécifiée.

### Retour

Une liste en lecture seule de cellules qui correspondent à la formule spécifiée.



```python
def get_cells(self, formula, skip_hidden_cells):
    ...
```


| Paramètre | Type | Description |
| :- | :- | :- |
| formula | **str** | Une formule ou expression de plage (par exemple, "Sheet1!A1:B3") utilisée pour identifier les cellules ciblées. |
| skip_hidden_cells | **bool** | Si `true`, les cellules masquées (par exemple, dans des lignes ou colonnes masquées) seront exclues du résultat. |
