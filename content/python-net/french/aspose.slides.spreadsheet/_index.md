Contient des classes pour travailler avec des objets de feuille de calcul dans les présentations Microsoft PowerPoint.
## Classes

| Classe | Description |
| :- | :- |
| [`CellCircularReferenceException`](/slides/python-net/fr/aspose.slides.spreadsheet/cellcircularreferenceexception/) | L'exception qui est levée lorsqu'une ou plusieurs références circulaires sont détectées où une formule fait référence à sa<br/>            propre cellule directement ou indirectement. |
| [`CellInvalidFormulaException`](/slides/python-net/fr/aspose.slides.spreadsheet/cellinvalidformulaexception/) | L'exception qui est levée lorsqu'une formule calculée n'est pas correcte ou n'a pas pu être analysée. |
| [`CellInvalidReferenceException`](/slides/python-net/fr/aspose.slides.spreadsheet/cellinvalidreferenceexception/) | L'exception qui est levée lorsqu'une référence de cellule invalide est rencontrée. |
| [`CellUnsupportedDataException`](/slides/python-net/fr/aspose.slides.spreadsheet/cellunsupporteddataexception/) | L'exception qui est levée lorsqu'une donnée non prise en charge est rencontrée dans une cellule de feuille de calcul. |
