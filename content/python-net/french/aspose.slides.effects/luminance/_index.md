## Classe Luminance

Représente un effet de Luminance.  
La luminosité décale linéairement toutes les couleurs vers le blanc ou le noir.  
Le contraste ajuste toutes les couleurs pour qu'elles soient plus proches ou plus éloignées les unes des autres.
