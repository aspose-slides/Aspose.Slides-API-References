## IReflection classe

Représente un effet de réflexion.

Le type IReflection expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/fr/aspose.slides.effects/ireflection/start_pos_alpha/) | Spécifie la position de départ (le long du dégradé alpha) de la valeur alpha de départ (pourcentages).<br/>            Lecture/écriture **float**. |
| [`end_pos_alpha`](/slides/python-net/fr/aspose.slides.effects/ireflection/end_pos_alpha/) | Spécifie la position de fin (le long du dégradé alpha) de la valeur alpha de fin (pourcentages).<br/>            Lecture/écriture **float**. |
| [`fade_direction`](/slides/python-net/fr/aspose.slides.effects/ireflection/fade_direction/) | Spécifie la direction du décalage de la réflexion (angle).<br/>            Lecture/écriture **float**. |
| [`start_reflection_opacity`](/slides/python-net/fr/aspose.slides.effects/ireflection/start_reflection_opacity/) | Opacité de la réflexion de départ (pourcentages).<br/>            Lecture/écriture **float**. |
| [`end_reflection_opacity`](/slides/python-net/fr/aspose.slides.effects/ireflection/end_reflection_opacity/) | Opacité de la réflexion de fin (pourcentages).<br/>            Lecture/écriture **float**. |
| [`blur_radius`](/slides/python-net/fr/aspose.slides.effects/ireflection/blur_radius/) | Rayon de flou.<br/>            Lecture/écriture **float**. |

| [`rectangle_align`](/slides/python-net/fr/aspose.slides.effects/ireflection/rectangle_align/) | Alignement du rectangle.<br/>            Lecture/écriture [`RectangleAlignment`](/slides/python-net/fr/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/fr/aspose.slides.effects/ireflection/skew_horizontal/) | Spécifie l'angle d'inclinaison horizontal.<br/>            Lecture/écriture **float**. |
