## IBlur classe

Représente un effet de flou appliqué à l'ensemble de la forme, y compris son remplissage. Tous les canaux de couleur, y compris l'alpha, sont affectés.

Le type IBlur expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`radius`](/slides/python-net/fr/aspose.slides.effects/iblur/radius/) | Renvoie ou définit le rayon du flou.<br/>            Lecture/écriture **float**. |
| [`grow`](/slides/python-net/fr/aspose.slides.effects/iblur/grow/) | Détermine si les limites de l'objet doivent être agrandies suite au flou.<br/>            True indique que les limites sont agrandies tandis que false indique le contraire.<br/>            Lecture/écriture **bool**. |
