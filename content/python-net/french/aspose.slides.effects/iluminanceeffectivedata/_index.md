## ILuminanceEffectiveData classe

Représente un effet de luminance.
            La luminosité décale linéairement toutes les couleurs vers le blanc ou le noir.
            Le contraste ajuste toutes les couleurs pour qu'elles soient soit plus proches, soit plus éloignées les unes des autres.
