## IBlurEffectiveData classe

Objet immuable qui représente un effet de flou appliqué à l’ensemble de la forme, y compris son remplissage.<br/>Tous les canaux de couleur, y compris l’alpha, sont affectés.

Le type IBlurEffectiveData expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`radius`](/slides/python-net/fr/aspose.slides.effects/iblureffectivedata/radius/) | Renvoie ou définit le rayon du flou.<br/>            Lecture seule **float**. |
| [`grow`](/slides/python-net/fr/aspose.slides.effects/iblureffectivedata/grow/) | Détermine si les limites de l'objet doivent être agrandies suite au flou.<br/>            True indique que les limites sont agrandies tandis que false indique qu'elles ne le sont pas.<br/>            Lecture seule **bool**. |
