## disable_font_ligatures propriété
Obtient ou définit une valeur indiquant si le texte est rendu sans utiliser de ligatures.
            Lorsque elle est définie sur `true`, les ligatures seront désactivées dans la sortie rendue. Par défaut, cette propriété est définie sur `false`.
