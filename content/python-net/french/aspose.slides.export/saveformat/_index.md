## Énumération SaveFormat

Constantes qui définissent le format d’une présentation enregistrée.

Le type SaveFormat expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| PPT | Enregistre la présentation au format PPT. |
| PDF | Enregistre la présentation au format PDF. |
| XPS | Enregistre la présentation au format XPS. |
| PPTX | Enregistre la présentation au format PPTX. |
| PPSX | Enregistre la présentation au format PPSX (diaporama). |
| TIFF | Enregistre la présentation en tant qu’image TIFF multi-pages. |
| ODP | Enregistre la présentation au format ODP. |
| PPTM | Enregistre la présentation au format PPTM (présentation avec macros). |
| PPSM | Enregistre la présentation au format PPSM (diaporama avec macros). |
| POTX | Enregistre la présentation au format POTX (modèle). |
| POTM | Enregistre la présentation au format POTM (modèle avec macros). |
| HTML | Enregistre la présentation au format HTML. |
| SWF | Enregistre la présentation au format SWF. |
| OTP | Enregistre la présentation au format OTP (modèle de présentation). |
| PPS | Enregistre la présentation au format PPS. |

| FODP | Enregistre la présentation au format FODP. |
| GIF | Enregistre la présentation au format GIF. |
| HTML5 | Enregistre la présentation au format HTML en utilisant le nouveau système de modèles HTML5. |
| MD | Enregistre la présentation au format Markdown |
