## CompressionLevel énumération

Spécifie les niveaux de compression ZIP pour le fichier OpenXML.  
Les niveaux supérieurs offrent une meilleure compression au prix d'un traitement plus lent.

Le type CompressionLevel expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| NONE | Aucune compression n'est appliquée. Les fichiers sont stockés tels quels. |
| LEVEL1 | Compression la plus rapide avec le taux de compression le plus bas. |
| LEVEL2 | Compression plus rapide avec un taux de compression légèrement meilleur que [`CompressionLevel.LEVEL1`](/slides/python-net/fr/aspose.slides.export/compressionlevel/LEVEL1). |
| LEVEL3 | Offre une meilleure compression que [`CompressionLevel.LEVEL2`](/slides/python-net/fr/aspose.slides.export/compressionlevel/LEVEL2) avec un impact de performance modéré. |
| LEVEL4 | Offre une meilleure compression que [`CompressionLevel.LEVEL3`](/slides/python-net/fr/aspose.slides.export/compressionlevel/LEVEL3). |
| LEVEL5 | Fournit une compression améliorée par rapport à [`CompressionLevel.LEVEL4`](/slides/python-net/fr/aspose.slides.export/compressionlevel/LEVEL4) avec un temps de traitement supplémentaire. |
| LEVEL6 | Compression standard, offrant un bon équilibre entre la vitesse de compression et la taille du fichier.<br/>            Niveau de compression par défaut. |
| LEVEL7 | Fournit une compression supérieure à [`CompressionLevel.LEVEL6`](/slides/python-net/fr/aspose.slides.export/compressionlevel/LEVEL6) avec un traitement plus lent. |
| LEVEL8 | Fournit une compression supérieure à [`CompressionLevel.LEVEL7`](/slides/python-net/fr/aspose.slides.export/compressionlevel/LEVEL7). |
| LEVEL9 | Compression maximale. Produit la plus petite taille de fichier avec la vitesse de traitement la plus lente. |
