## SvgEvent énumération

Représente les options pour la forme SVG.

Le type SvgEvent expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| ON_FOCUS_IN | Se produit lorsqu'un élément reçoit le focus, par exemple lorsqu'un texte devient sélectionné. |
| ON_FOCUS_OUT | Se produit lorsqu'un élément perd le focus, par exemple lorsqu'un texte devient désélectionné. |
| ON_ACTIVATE | Se produit lorsqu'un élément est activé, par exemple par un clic de souris ou une pression de touche. |
| ON_CLICK | Se produit lorsque le bouton du dispositif de pointage est cliqué sur un élément. |
| ON_MOUSE_DOWN | Se produit lorsque le bouton du dispositif de pointage est enfoncé sur un élément. |
| ON_MOUSE_UP | Se produit lorsque le bouton du dispositif de pointage est relâché sur un élément. |
| ON_MOUSE_OVER | Se produit lorsque le dispositif de pointage est déplacé sur un élément. |
| ON_MOUSE_MOVE | Se produit lorsque le dispositif de pointage est déplacé alors qu'il est sur un élément. |
| ON_MOUSE_OUT | Se produit lorsque le dispositif de pointage s'éloigne d'un élément. |
| ON_LOAD | Se produit lorsque l'agent utilisateur a entièrement analysé l'élément, ses descendants et toutes les ressources référencées nécessaires à son rendu. |
| ON_UNLOAD | Se produit lorsque l'implémentation DOM supprime un document d'une fenêtre ou d'un cadre. Applicable uniquement aux éléments svg les plus externes. |
| ON_ABORT | Se produit lorsque le chargement de la page est interrompu avant qu'un élément ne soit entièrement chargé. |
| ON_ERROR | Se produit lorsqu'un élément ne se charge pas correctement ou lorsqu'une erreur survient lors de l'exécution d'un script. |
| ON_RESIZE | Se produit lorsqu'une vue de document est redimensionnée. Applicable uniquement aux éléments svg les plus externes. |
| ON_SCROLL | Se produit lorsqu'une vue de document est déplacée le long de l'axe X ou Y ou des deux. Applicable uniquement aux éléments svg les plus externes. |
| ON_ZOOM | Se produit lorsque le niveau de zoom d'une vue de document est modifié. Applicable uniquement aux éléments svg les plus externes. |
| ON_BEGIN | Se produit lorsqu'un élément d'animation commence. |
| ON_END | Se produit lorsqu'un élément d'animation se termine. |
| ON_REPEAT | Se produit lorsqu'un élément d'animation se répète. |
