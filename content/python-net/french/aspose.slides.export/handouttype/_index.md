## Énumération HandoutType

Spécifie le nombre de diapositives et la séquence dans laquelle elles seront placées sur la page.

Le type HandoutType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| HANDOUTS1 | Une diapositive par page. |
| HANDOUTS2 | Deux diapositives par page. |
| HANDOUTS3 | Trois diapositives par page. |
| HANDOUTS_4_HORIZONTAL | Quatre diapositives par page dans une séquence horizontale. |
| HANDOUTS_4_VERTICAL | Quatre diapositives par page dans une séquence verticale. |
| HANDOUTS_6_HORIZONTAL | Six diapositives par page dans une séquence horizontale. |
| HANDOUTS_6_VERTICAL | Six diapositives par page dans une séquence verticale. |
| HANDOUTS_9_HORIZONTAL | Neuf diapositives par page dans une séquence horizontale. |
| HANDOUTS_9_VERTICAL | Neuf diapositives par page dans une séquence verticale. |
