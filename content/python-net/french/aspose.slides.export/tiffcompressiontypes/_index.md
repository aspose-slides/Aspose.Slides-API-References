## TiffCompressionTypes énumération

Fournit des options qui contrôlent la façon dont une présentation est compressée au format TIFF.

Le type TiffCompressionTypes expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| DEFAULT | Spécifie le schéma de compression par défaut (LZW). |
| NONE | Spécifie aucune compression. |
| CCITT3 | Spécifie le schéma de compression CCITT3. |
| CCITT4 | Spécifie le schéma de compression CCITT4. |
| LZW | Spécifie le schéma de compression LZW (Par défaut). |
| RLE | Spécifie le schéma de compression RLE. |
