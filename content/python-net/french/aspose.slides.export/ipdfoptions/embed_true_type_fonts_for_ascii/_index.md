## embed_true_type_fonts_for_ascii propriété
True to embed true type fonts for ASCII characters 32-127.
            Les polices pour les codes de caractères supérieurs à 127 sont toujours incorporées.
            Lecture/écriture **bool**.

### Remarques

Par défaut, **true**.
