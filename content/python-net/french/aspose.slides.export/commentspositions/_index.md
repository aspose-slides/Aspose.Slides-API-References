Représente la règle de rendu des commentaires dans le document exporté

Le type CommentsPositions expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| NONE | Spécifie que les commentaires ne doivent pas être affichés du tout. |
| BOTTOM | Spécifie que les commentaires doivent être affichés en bas de la page. |
| RIGHT | Spécifie que les commentaires doivent être affichés à droite de la page. |
