## disable_font_ligatures propriété
Obtient ou définit une valeur indiquant si le texte est rendu sans utiliser les ligatures.
            Lorsqu'il est défini sur `true`, les ligatures seront désactivées dans le rendu. Par défaut, cette propriété est définie sur `false`.
