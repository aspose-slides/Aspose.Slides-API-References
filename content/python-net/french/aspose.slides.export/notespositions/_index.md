## NotesPositions énumération

Représente la règle de rendu des notes dans le document exporté

Le type NotesPositions expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| NONE | Spécifie que les notes ne doivent pas être affichées du tout. |
| BOTTOM_FULL | Spécifie que les notes doivent être affichées complètement en utilisant des pages supplémentaires au besoin. |
| BOTTOM_TRUNCATED | Spécifie que les notes doivent être affichées sur une seule page. |
