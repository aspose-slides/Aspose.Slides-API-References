## disable_font_ligatures propriété
Obtient ou définit une valeur indiquant si le texte est rendu sans utiliser les ligatures.
            Lorsque la valeur est `true`, les ligatures seront désactivées dans la sortie rendue. Par défaut, cette propriété est définie sur `false`.
