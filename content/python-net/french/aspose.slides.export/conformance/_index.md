## Énumération de conformité

Spécifie la classe de conformité à laquelle le document PresentationML se conforme.

Le type Conformance expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| ECMA_376_2006 | Spécifie que le document se conforme à ECMA376:2006. |
| ISO_29500_2008_TRANSITIONAL | Spécifie que le document se conforme à la classe de conformité Transitoire ISO/IEC 29500:2008. |
| ISO_29500_2008_STRICT | Spécifie que le document se conforme à la classe de conformité Strict ISO/IEC 29500:2008. |
