## PicturesCompression énumération

Représente le niveau de compression des images

Le type PicturesCompression expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| DPI330 | Bonne qualité pour les écrans haute définition (HD) |
| DPI220 | Qualité excellente sur la plupart des imprimantes et écrans |
| DPI150 | Bon pour les pages web et les projecteurs |
| DPI96 | Réduit la taille du document pour le partage |
| DPI72 | Niveau de compression par défaut |
| DOCUMENT_RESOLUTION | Utilise la résolution du document - l'image ne sera pas compressée et sera utilisée telle quelle dans le document |
