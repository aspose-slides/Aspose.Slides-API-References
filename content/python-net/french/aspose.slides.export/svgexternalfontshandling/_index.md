## SvgExternalFontsHandling énumération

Représente une façon de gérer les polices externes utilisées pour le rendu du texte.

Le type SvgExternalFontsHandling expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| ADD_LINKS_TO_FONT_FILES | Ajouter des liens vers des fichiers de polices séparés à la section style du fichier SVG. |
| EMBED | Enregistrer les données des polices directement dans le fichier SVG. Veuillez vérifier les accords de licence de toutes les polices externes avant d’utiliser cette option. |
| VECTORIZE | Enregistrer tout le texte utilisant des polices externes sous forme de graphiques. |
