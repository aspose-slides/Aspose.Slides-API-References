## BlackWhiteConversionMode énumération

Fournit des options qui contrôlent la façon dont les images des diapositives seront converties en images bitales.

Le type BlackWhiteConversionMode expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| DEFAULT | Spécifie aucune algorithme de conversion. L'algorithme implémenté dans le codec TIFF sera utilisé. (Par défaut) |
| DITHERING | Spécifie l'algorithme de tramage (Floyd-Steinberg). |
| DITHERING_FLOYD_STEINBERG | Spécifie l'algorithme de tramage Floyd-Steinberg. |
| AUTO | Spécifie l'algorithme de seuil calculé automatiquement (Otsu). |
| AUTO_OTSU | Spécifie l'algorithme de seuil d'Otsu calculé automatiquement. |
| THRESHOLD25 | Spécifie l'algorithme de seuil statique (25 %). |
| THRESHOLD50 | Spécifie l'algorithme de seuil statique (50 %). |
| THRESHOLD75 | Spécifie l'algorithme de seuil statique (75 %). |
