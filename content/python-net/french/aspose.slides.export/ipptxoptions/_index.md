## IPptxOptions classe

Représente les options pour enregistrer les présentations OpenXml (PPTX, PPSX, POTX, PPTM, PPSM, POTM).

Le type IPptxOptions expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`conformance`](/slides/python-net/fr/aspose.slides.export/ipptxoptions/conformance/) | Spécifie la classe de conformité à laquelle le document Presentation se conforme.<br/>            Valeur par défaut est [`Conformance.ECMA_376_2006`](/slides/python-net/fr/aspose.slides.export/conformance/ECMA_376_2006) |
| [`zip_64_mode`](/slides/python-net/fr/aspose.slides.export/ipptxoptions/zip_64_mode/) | Spécifie si le format ZIP64 est utilisé pour le document Presentation.<br/>            Valeur par défaut est [`Zip64Mode.IF_NECESSARY`](/slides/python-net/fr/aspose.slides.export/zip64mode/IF_NECESSARY) |
| [`refresh_thumbnail`](/slides/python-net/fr/aspose.slides.export/ipptxoptions/refresh_thumbnail/) | Spécifie si la miniature de la présentation sera actualisée.<br/>            Lecture/écriture **bool**.<br/>            Valeur par défaut est **true**. |
| [`compression_level`](/slides/python-net/fr/aspose.slides.export/ipptxoptions/compression_level/) | Spécifie le niveau de compression utilisé lors de l'enregistrement du document de présentation.<br/>            Valeur par défaut est [`CompressionLevel.LEVEL6`](/slides/python-net/fr/aspose.slides.export/compressionlevel/LEVEL6). |
| [`warning_callback`](/slides/python-net/fr/aspose.slides.export/ipptxoptions/warning_callback/) |  |
