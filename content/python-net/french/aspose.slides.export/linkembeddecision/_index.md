## LinkEmbedDecision énumération

Détermine comment l'objet sera traité lors de l'enregistrement.

Le type LinkEmbedDecision expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| LINK | L'objet sera stocké à l'extérieur, référencé par URL |
| EMBED | L'objet doit être intégré à un fichier généré si possible. Si l'intégration est impossible, GetUrl sera appelé et, selon le résultat, l'objet sera référencé par URL ou ignoré. |
| IGNORE | L'objet sera ignoré. |
