## to_box(self) {#}
Place cet element dans une boite non visuelle (groupement logique) qui est utilisee pour regrouper les composants d'une equation ou d'une autre instance de texte mathematique. Un objet encadre peut (par exemple) servir d'emulateur d'operateur avec ou sans point d'alignement, servir de point de rupture de ligne, ou etre groupe de maniere a ne pas autoriser les retours a la ligne a l'interieur.

### Retour

Boite logique contenant cet element
