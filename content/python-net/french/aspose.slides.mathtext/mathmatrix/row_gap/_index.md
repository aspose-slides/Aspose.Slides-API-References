## propriété row_gap
La valeur de l'espacement vertical entre les lignes d'une matrice;
            Si le RowGapRule est défini sur 3 ("Exactement"), l'unité est interprétée en twips (1/20e de point)
            Si le RowGapRule est défini sur 4 ("Multiple"), l'unité est interprétée en demi-lignes.
            Par défaut: 0
