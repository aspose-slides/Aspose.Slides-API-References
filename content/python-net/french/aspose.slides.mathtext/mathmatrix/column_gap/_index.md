## column_gap propriété
La valeur de l'espacement horizontal entre les colonnes d'une matrice;
            Si le ColumnGapRule est défini sur 3 ("Exactly"), alors l'unité est interprétée comme des twips (1/20e d'un point)
            Si le ColumnGapRule est défini sur 4 ("Multiple"), alors l'unité est interprétée comme un nombre d'incréments de 0,5 em.
            Dans les autres cas, ignoré.
            Valeur par défaut : 0
