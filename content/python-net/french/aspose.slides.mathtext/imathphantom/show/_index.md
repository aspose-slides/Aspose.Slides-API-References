## show propriété
Obtient ou définit une valeur indiquant si l'élément de base est affiché.

### Remarques

Lorsque `false`, l'élément de base est masqué mais peut encore occuper de l'espace selon d'autres paramètres fantômes. Correspond à l'attribut OMML `m:show`.
