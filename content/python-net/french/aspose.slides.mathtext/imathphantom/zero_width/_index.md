## zero_width propriété
Obtient ou définit une valeur indiquant si la largeur de l'élément de base 
            doit être considérée comme zéro.

### Remarques

Lorsque `true`, le fantôme ne réserve pas d'espace horizontal 
            pour son élément de base. Correspond à l'attribut OMML `m:zeroWid`.
