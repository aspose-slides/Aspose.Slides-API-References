## beginning_character propriété
Le caractère de délimiteur de début spécifie le caractère de délimiteur d'ouverture. 
            Les délimiteurs mathématiques sont des caractères d'encadrement tels que les parenthèses, les crochets et les accolades.
            Par défaut : '('.
