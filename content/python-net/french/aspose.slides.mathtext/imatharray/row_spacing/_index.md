## row_spacing propriété
Espacement entre les lignes d'un tableau
Il est utilisé uniquement lorsque RowSpacingRule est défini sur 3 Exactly, auquel cas l'unité de mesure est les points
ou Multiple, auquel cas l'unité de mesure est les demi-lignes.
Par défaut: 0
