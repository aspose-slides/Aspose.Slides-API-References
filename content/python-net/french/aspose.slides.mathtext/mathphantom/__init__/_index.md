| Paramètre | Type | Description |
| :- | :- | :- |
| element | [`IMathElement`](/slides/python-net/fr/aspose.slides.mathtext/imathelement) | Le [`IMathElement`](/slides/python-net/fr/aspose.slides.mathtext/imathelement) de base dont la visibilité et la disposition seront contrôlées <br/><br/>            par le fantôme. ### Remarques

L'élément fantôme est utilisé pour réserver ou supprimer l'espace visuel de son expression 
            de base sans nécessairement l'afficher. Il correspond à l'élément OMML 
            `<m:phant>`.
