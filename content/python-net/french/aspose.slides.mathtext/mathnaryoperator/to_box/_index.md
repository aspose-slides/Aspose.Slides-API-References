## to_box(self) {#}
Place cet élément dans une boîte non visuelle (groupement logique) 
            qui est utilisée pour regrouper les composants d'une équation ou d'une autre instance de texte mathématique.
            Un objet encadré peut (par exemple) servir d'emulateur d'opérateur avec ou sans point d'alignement, 
            servir de point de saut de ligne, ou être groupé de manière à ne pas autoriser les sauts de ligne à l'intérieur.
