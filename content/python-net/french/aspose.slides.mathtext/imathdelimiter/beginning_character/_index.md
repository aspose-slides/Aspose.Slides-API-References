## beginning_character propriété
Le caractère de délimiteur de début indique le caractère de délimiteur initial, ou d'ouverture. 
    Les délimiteurs mathématiques sont des caractères d'encapsulation tels que les parenthèses, les crochets et les accolades.
    Valeur par défaut : '('.
