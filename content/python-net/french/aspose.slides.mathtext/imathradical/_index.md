## classe IMathRadical

Spécifie la fonction radicale, composée d'une base et d'un degré optionnel.
            Exemple d'objet radical : √𝑥.

Le type IMathRadical expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`base`](/slides/python-net/fr/aspose.slides.mathtext/imathradical/base/) | Argument de base |
| [`degree`](/slides/python-net/fr/aspose.slides.mathtext/imathradical/degree/) | Argument du degré |
| [`hide_degree`](/slides/python-net/fr/aspose.slides.mathtext/imathradical/hide_degree/) | Masquer le degré<br/>            Lorsque true, le degré n'est pas affiché, comme dans √𝑥 |
