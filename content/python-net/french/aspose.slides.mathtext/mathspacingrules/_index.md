## MathSpacingRules énumération

Types d'écart (espacement horizontal) entre les colonnes d'une matrice

Le type MathSpacingRules expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| SINGLE_SPACING_GAP | Simple (1 em pour les colonnes ou 1 ligne pour les rangées) |
| ONE_AND_HALF_SPACING_GAP | Un et demi (1,5 em pour les colonnes ou 1,5 lignes pour les rangées) |
| DOUBLE_SPACING_GAP | Double espacement (2 em pour les colonnes ou 2 lignes pour les rangées) |
| EXACTLY | Valeur exacte<br/>            Pour les colonnes, utilise la valeur de ColumnGap, mesurée en twips<br/>            Pour les rangées, utilise la valeur de RowGap, mesurée en twips |
| MULTIPLE | Multiple<br/>            Pour les colonnes, utilise la valeur de ColumnGap, mesurée par incréments de 0,5 em<br/>            Pour les rangées, utilise la valeur de RowGap, mesurée en lignes |
