## Énumération MathJustification

Spécifie l'alignement du paragraphe mathématique (une série d'instances adjacentes de texte mathématique au sein du même paragraphe)

Le type MathJustification expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| LEFT_JUSTIFIED | Aligner le texte mathématique à gauche |
| RIGHT_JUSTIFIED | Aligner le texte mathématique à droite |
| CENTERED | Aligner le texte mathématique au centre |
| CENTERED_AS_GROUP | Centrer sur la page l'ensemble complet des blocs mathématiques en tant qu'unité unique.<br/>            Cela signifie que les instances de texte mathématique peuvent être alignées les unes par rapport aux autres, <br/>            mais l'ensemble complet du texte mathématique est centré dans son ensemble. |
