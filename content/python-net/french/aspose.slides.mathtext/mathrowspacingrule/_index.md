## MathRowSpacingRule énumération

Le type d'espacement vertical entre les colonnes d'une matrice ou d'un tableau

Le type MathRowSpacingRule expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| SINGLE_LINE_GAP | écart d'une ligne |
| ONE_AND_A_HALF_LINE_GAP | Écart d'une ligne et demie |
| TWO_LINE_GAP | Écart de deux lignes |
| EXACTLY | Exactement (se base sur la valeur de la propriété RowSpacing, mesurée en points) |
| MULTIPLE | Multiple (se base sur la valeur de la propriété RowSpacing, mesurée en lignes) |
