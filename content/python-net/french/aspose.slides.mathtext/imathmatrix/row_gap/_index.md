## row_gap propriété
Valeur de l'espacement vertical entre les lignes d'une matrice;
            Si le RowGapRule est défini sur 3 ("Exactly"), alors l'unité est interprétée comme des twips (1/20e d'un point)
            Si le RowGapRule est défini sur 4 ("Multiple"), alors l'unité est interprétée comme des demi-lignes.
            Par défaut : 0
