## ISensitivityLabel classe

Représente le libellé de sensibilité de Microsoft Purview Information Protection.

Le type ISensitivityLabel expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`id`](/slides/python-net/fr/aspose.slides/isensitivitylabel/id/) | Renvoie ou définit l'ID du libellé de sensibilité.<br/>            Lecture/écriture **str**. |
| [`site_id`](/slides/python-net/fr/aspose.slides/isensitivitylabel/site_id/) | Renvoie ou définit l'identifiant du site Azure Active Directory (Azure AD) <br/>            correspondant à la stratégie du libellé de sensibilité qui décrit le libellé de sensibilité.<br/>            Lecture/écriture **System.Guid**. |
| [`is_enabled`](/slides/python-net/fr/aspose.slides/isensitivitylabel/is_enabled/) | Indique si le libellé de sensibilité est activé. |
| [`is_removed`](/slides/python-net/fr/aspose.slides/isensitivitylabel/is_removed/) | Indique si le libellé de sensibilité a été supprimé. |
| [`assignment_method_type`](/slides/python-net/fr/aspose.slides/isensitivitylabel/assignment_method_type/) | Renvoie ou définit la méthode d'attribution du libellé de sensibilité.<br/>            Lecture/écriture [`SensitivityLabelAssignmentType`](/slides/python-net/fr/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/fr/aspose.slides/isensitivitylabel/content_mark_types/) | Renvoie la liste des types de marquage de contenu qui doivent être appliqués à un fichier. |
