## IColorFormat classe

Représente une couleur utilisée dans une présentation.

Le type IColorFormat expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`color_type`](/slides/python-net/fr/aspose.slides/icolorformat/color_type/) | Renvoie ou définit la méthode de définition de la couleur.<br/>            Lecture/écriture [`ColorType`](/slides/python-net/fr/aspose.slides/colortype). |
| [`color`](/slides/python-net/fr/aspose.slides/icolorformat/color/) | Renvoie la couleur résultante (avec toutes les transformations de couleur appliquées).<br/>            Définit les couleurs RVB et supprime toutes les transformations de couleur.<br/>            Lecture/écriture [`Color`](/slides/python-net/fr/aspose.slides/color). |
| [`preset_color`](/slides/python-net/fr/aspose.slides/icolorformat/preset_color/) | Renvoie ou définit le préréglage de couleur.<br/>            Lecture/écriture [`PresetColor`](/slides/python-net/fr/aspose.slides/presetcolor). |
| [`system_color`](/slides/python-net/fr/aspose.slides/icolorformat/system_color/) | Renvoie ou définit la couleur identifiée par la table des couleurs du système.<br/>            Lecture/écriture [`SystemColor`](/slides/python-net/fr/aspose.slides/systemcolor). |
| [`scheme_color`](/slides/python-net/fr/aspose.slides/icolorformat/scheme_color/) | Renvoie ou définit la couleur identifiée par un schéma de couleurs.<br/>            Lecture/écriture [`SchemeColor`](/slides/python-net/fr/aspose.slides/schemecolor). |
| [`r`](/slides/python-net/fr/aspose.slides/icolorformat/r/) | Renvoie ou définit le composant rouge d'une couleur. Toutes les transformations de couleur sont ignorées.<br/>            Lecture/écriture **int**. |
| [`g`](/slides/python-net/fr/aspose.slides/icolorformat/g/) | Renvoie ou définit le composant vert d'une couleur. Toutes les transformations de couleur sont ignorées.<br/>            Lecture/écriture **int**. |
| [`b`](/slides/python-net/fr/aspose.slides/icolorformat/b/) | Renvoie ou définit le composant bleu d'une couleur. Toutes les transformations de couleur sont ignorées.<br/>            Lecture/écriture **int**. |
| [`float_r`](/slides/python-net/fr/aspose.slides/icolorformat/float_r/) | Renvoie ou définit le composant rouge d'une couleur. Toutes les transformations de couleur sont ignorées.<br/>            Lecture/écriture **float**. |
| [`float_g`](/slides/python-net/fr/aspose.slides/icolorformat/float_g/) | Renvoie ou définit le composant vert d'une couleur. Toutes les transformations de couleur sont ignorées.<br/>            Lecture/écriture **float**. |
| [`float_b`](/slides/python-net/fr/aspose.slides/icolorformat/float_b/) | Renvoie ou définit le composant bleu d'une couleur. Toutes les transformations de couleur sont ignorées.<br/>            Lecture/écriture **float**. |
| [`hue`](/slides/python-net/fr/aspose.slides/icolorformat/hue/) | Renvoie ou définit le composant teinte d'une couleur en représentation HSL.<br/>            Toutes les transformations de couleur sont ignorées.<br/>            Lecture/écriture **float**. |
| [`saturation`](/slides/python-net/fr/aspose.slides/icolorformat/saturation/) | Renvoie ou définit le composant saturation d'une couleur en représentation HSL.<br/>            Toutes les transformations de couleur sont ignorées.<br/>            Lecture/écriture **float**. |
| [`luminance`](/slides/python-net/fr/aspose.slides/icolorformat/luminance/) | Renvoie ou définit le composant luminance d'une couleur en représentation HSL.<br/>            Toutes les transformations de couleur sont ignorées.<br/>            Lecture/écriture **float**. |
| [`color_transform`](/slides/python-net/fr/aspose.slides/icolorformat/color_transform/) | Renvoie la collection des transformations de couleur appliquées à une couleur.<br/>            Lecture seule [`IColorOperationCollection`](/slides/python-net/fr/aspose.slides/icoloroperationcollection). |
