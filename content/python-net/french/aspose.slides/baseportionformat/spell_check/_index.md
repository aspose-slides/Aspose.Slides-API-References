## spell_check propriété
Obtient ou définit une valeur indiquant si la vérification orthographique est activée pour la partie texte.
            Lorsque cette propriété est définie sur false, les vérifications d'orthographe pour les éléments texte sont supprimées.
            Lorsqu'elle est définie sur true, la vérification orthographique est autorisée.
            La valeur par défaut est `false`.
