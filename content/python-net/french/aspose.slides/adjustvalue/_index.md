## AdjustValue classe

Représente la valeur d'ajustement d'une forme géométrique.
            Ces valeurs affectent la forme de la forme.

Le type AdjustValue expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`raw_value`](/slides/python-net/fr/aspose.slides/adjustvalue/raw_value/) | Renvoie ou définit la valeur d'ajustement « tel quel ».<br/>            Lecture/écriture **int**. |
| [`angle_value`](/slides/python-net/fr/aspose.slides/adjustvalue/angle_value/) | Renvoie ou définit la valeur, en l'interprétant comme un angle en degrés.<br/>            Lecture/écriture **float**. |
| [`name`](/slides/python-net/fr/aspose.slides/adjustvalue/name/) | Renvoie le nom de cette valeur d'ajustement.<br/>            Lecture seule **str**. |
| [`type`](/slides/python-net/fr/aspose.slides/adjustvalue/type/) | Renvoie le type de l'ajustement de forme.<br/>            Lecture seule [`ShapeAdjustmentType`](/slides/python-net/fr/aspose.slides/shapeadjustmenttype). |
