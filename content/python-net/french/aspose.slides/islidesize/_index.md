## ISlideSize classe

Représente la taille et l'orientation d'une diapositive.

Le type ISlideSize expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`size`](/slides/python-net/fr/aspose.slides/islidesize/size/) | Obtient les dimensions de la diapositive en points. |
| [`type`](/slides/python-net/fr/aspose.slides/islidesize/type/) | Obtient le type de taille de la diapositive. |
| [`orientation`](/slides/python-net/fr/aspose.slides/islidesize/orientation/) | Obtient ou définit l'orientation de la diapositive. |
