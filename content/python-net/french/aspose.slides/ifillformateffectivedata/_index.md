## IFillFormatEffectiveData classe

Objet immuable qui contient les propriétés de formatage de remplissage effectif.

Le type IFillFormatEffectiveData expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`fill_type`](/slides/python-net/fr/aspose.slides/ifillformateffectivedata/fill_type/) | Renvoie le type de remplissage.<br/>            Lecture seule [`FillType`](/slides/python-net/fr/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/fr/aspose.slides/ifillformateffectivedata/solid_fill_color/) | Renvoie la couleur de remplissage.<br/>            Lecture seule [`Color`](/slides/python-net/fr/aspose.slides/color). |
| [`solid_fill_scheme_color`](/slides/python-net/fr/aspose.slides/ifillformateffectivedata/solid_fill_scheme_color/) | Obtient la couleur de remplissage définie par un jeu de couleurs.<br/>            La valeur [`SchemeColor.NOT_DEFINED`](/slides/python-net/fr/aspose.slides/schemecolor/NOT_DEFINED) indique que le [`IFillFormatEffectiveData.solid_fill_color`](/slides/python-net/fr/aspose.slides/ifillformateffectivedata/solid_fill_color) <br/>            n'est pas une couleur de jeu.<br/>            Lecture seule [`SchemeColor`](/slides/python-net/fr/aspose.slides/schemecolor). |
| [`gradient_format`](/slides/python-net/fr/aspose.slides/ifillformateffectivedata/gradient_format/) | Renvoie le format de remplissage en dégradé.<br/>            Lecture seule [`IGradientFormatEffectiveData`](/slides/python-net/fr/aspose.slides/igradientformateffectivedata). |
| [`pattern_format`](/slides/python-net/fr/aspose.slides/ifillformateffectivedata/pattern_format/) | Renvoie le format de remplissage en motif.<br/>            Lecture seule [`IPatternFormatEffectiveData`](/slides/python-net/fr/aspose.slides/ipatternformateffectivedata). |
| [`picture_fill_format`](/slides/python-net/fr/aspose.slides/ifillformateffectivedata/picture_fill_format/) | Renvoie le format de remplissage d'image.<br/>            Lecture seule [`IPictureFillFormatEffectiveData`](/slides/python-net/fr/aspose.slides/ipicturefillformateffectivedata). |
| [`rotate_with_shape`](/slides/python-net/fr/aspose.slides/ifillformateffectivedata/rotate_with_shape/) | Détermine si le remplissage doit être pivoté avec la forme.<br/>            Lecture seule **bool**. |


### Remarques

Cette interface est utilisée conjointement avec l'interface [`IFillFormat`](/slides/python-net/fr/aspose.slides/ifillformat) pour renvoyer les valeurs de formatage effectif avec héritage appliqué.
