## ILightRigEffectiveData classe

Objet immuable contenant les propriétés effectives du dispositif d’éclairage.

Le type ILightRigEffectiveData expose les membres suivants :

## Propriété

| Propriété | Description |
| :- | :- |
| [`direction`](/slides/python-net/fr/aspose.slides/ilightrigeffectivedata/direction/) | Direction de la lumière.<br/>            Lecture seule [`LightingDirection`](/slides/python-net/fr/aspose.slides/lightingdirection). |
| [`light_type`](/slides/python-net/fr/aspose.slides/ilightrigeffectivedata/light_type/) | Représente un réglage prédéfini de la lumière qui peut être appliqué à une forme. <br/>            Le dispositif d’éclairage représente un groupe de lumières orientées d’une manière spécifique par rapport à une scène 3D.<br/>            Lecture seule [`LightRigPresetType`](/slides/python-net/fr/aspose.slides/lightrigpresettype). |

## Méthode

| Méthode | Description |
| :- | :- |
| [`get_rotation(self)`](/slides/python-net/fr/aspose.slides/ilightrigeffectivedata/get_rotation/#) | Une rotation est définie à l’aide d’une coordonnée de latitude, d’une coordonnée de longitude et d’une révolution autour de l’axe selon les coordonnées de latitude et de longitude.<br/>            Premier élément du tableau de retour - latitude, deuxième - longitude, troisième - révolution. |

### Remarques

Cette interface est utilisée comme partie de [`IThreeDFormatEffectiveData`](/slides/python-net/fr/aspose.slides/ithreedformateffectivedata).
