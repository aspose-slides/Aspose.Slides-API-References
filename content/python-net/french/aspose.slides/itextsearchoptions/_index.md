## ITextSearchOptions classe

Représente les options qui peuvent être utilisées pour rechercher du texte dans une Presentation, un Slide ou un TextFrame.

Le type ITextSearchOptions expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`case_sensitive`](/slides/python-net/fr/aspose.slides/itextsearchoptions/case_sensitive/) | Définir true pour utiliser une recherche sensible à la casse, false sinon.<br/>            Lecture/écriture **bool**. |
| [`whole_words_only`](/slides/python-net/fr/aspose.slides/itextsearchoptions/whole_words_only/) | Définir true pour ne correspondre qu'aux mots entiers, false sinon.<br/>            Lecture/écriture **bool**. |
| [`include_notes`](/slides/python-net/fr/aspose.slides/itextsearchoptions/include_notes/) | Définir `true` pour inclure le texte présent dans les notes de diapositive <br/>            lors de la recherche de texte, du remplacement ou des opérations de mise en surbrillance.<br/>            La valeur par défaut est `false`. |
