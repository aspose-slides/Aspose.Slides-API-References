## LoadFormat énumération

Indique le format du document à charger.

Le type LoadFormat expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| AUTO | Indique à Aspose.Slides de reconnaître le format automatiquement. |
| PPT | Présentation Microsoft PowerPoint 97-2003. |
| PPS | Diaporama Microsoft PowerPoint 97-2003. |
| PPTX | Document Microsoft Office Open XML PresentationML. |
| PPSX | Diaporama Microsoft Office Open XML PresentationML. |
| ODP | Présentation OpenOffice ODF. |
| POTX | Modèle Microsoft Office Open XML PresentationML. |
| PPTM | Document Microsoft Office Open XML PresentationML avec macros. |
| PPSM | Diaporama Microsoft Office Open XML PresentationML avec macros. |
| POTM | Modèle Microsoft Office Open XML PresentationML avec macros. |
| OTP | Modèle de présentation OpenOffice OTP. |
| PPT95 | Présentation Microsoft PowerPoint 95. |
| POT | Modèle de présentation Microsoft PowerPoint 97-2003. |
| FODP | Présentation ODF XML plat. |
| UNKNOWN | Format de fichier inconnu |
