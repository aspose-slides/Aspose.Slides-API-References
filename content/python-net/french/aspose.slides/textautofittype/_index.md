## Énumération TextAutofitType

Représente le mode d'ajustement automatique du texte.

Le type TextAutofitType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| NOT_DEFINED | Non défini. |
| NONE | Pas d'ajustement automatique. |
| NORMAL | Ajustement automatique normal. La taille de la police et l'espacement des lignes seront réduits pour s'adapter à la forme. |
| SHAPE | Ajustement automatique de la forme. La taille de la forme sera modifiée pour s'adapter au texte. |
