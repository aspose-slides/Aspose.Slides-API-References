## ITextFrameFormatEffectiveData classe

Objet immuable qui contient les propriétés de formatage effectif du cadre de texte.

Le type ITextFrameFormatEffectiveData expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`text_style`](/slides/python-net/fr/aspose.slides/itextframeformateffectivedata/text_style/) | Renvoie le style du texte effectif.<br/>            Lecture seule [`ITextStyleEffectiveData`](/slides/python-net/fr/aspose.slides/itextstyleeffectivedata). |
| [`margin_left`](/slides/python-net/fr/aspose.slides/itextframeformateffectivedata/margin_left/) | Renvoie la marge gauche (points) dans un TextFrame.<br/>            Lecture seule **float**. |
| [`margin_right`](/slides/python-net/fr/aspose.slides/itextframeformateffectivedata/margin_right/) | Renvoie la marge droite (points) dans un TextFrame.<br/>            Lecture seule **float**. |
| [`margin_top`](/slides/python-net/fr/aspose.slides/itextframeformateffectivedata/margin_top/) | Renvoie la marge supérieure (points) dans un TextFrame.<br/>            Lecture seule **float**. |
| [`margin_bottom`](/slides/python-net/fr/aspose.slides/itextframeformateffectivedata/margin_bottom/) | Renvoie la marge inférieure (points) dans un TextFrame.<br/>            Lecture seule **float**. |
| [`wrap_text`](/slides/python-net/fr/aspose.slides/itextframeformateffectivedata/wrap_text/) | Renvoie si le texte est renvoyé aux marges du TextFrame.<br/>            Lecture seule **bool**. |
| [`anchoring_type`](/slides/python-net/fr/aspose.slides/itextframeformateffectivedata/anchoring_type/) | Renvoie l'ancrage vertical du texte dans un TextFrame.<br/>            Lecture seule [`TextAnchorType`](/slides/python-net/fr/aspose.slides/textanchortype). |
| [`center_text`](/slides/python-net/fr/aspose.slides/itextframeformateffectivedata/center_text/) | Renvoie si le texte doit être centré horizontalement dans la boîte.<br/>            Lecture seule **bool**. |
| [`text_vertical_type`](/slides/python-net/fr/aspose.slides/itextframeformateffectivedata/text_vertical_type/) | Renvoie l'orientation du texte.<br/>            Lecture seule [`TextVerticalType`](/slides/python-net/fr/aspose.slides/textverticaltype). |
| [`autofit_type`](/slides/python-net/fr/aspose.slides/itextframeformateffectivedata/autofit_type/) | Renvoie le mode d'ajustement automatique du texte.<br/>            Lecture seule [`TextAutofitType`](/slides/python-net/fr/aspose.slides/textautofittype). |
| [`column_count`](/slides/python-net/fr/aspose.slides/itextframeformateffectivedata/column_count/) | Spécifie le nombre de colonnes de texte dans le rectangle englobant.<br/>            Lecture seule **int**. |
| [`column_spacing`](/slides/python-net/fr/aspose.slides/itextframeformateffectivedata/column_spacing/) | Spécifie l'espace entre les colonnes de texte dans la zone de texte (en points).<br/>            Lecture seule **float**. |


### Remarques

Cette interface est utilisée avec l'interface [`ITextFrameFormat`](/slides/python-net/fr/aspose.slides/itextframeformat) pour renvoyer les valeurs de formatage effectif avec l'héritage appliqué.
