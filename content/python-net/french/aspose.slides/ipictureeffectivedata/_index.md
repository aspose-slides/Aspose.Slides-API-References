## IPictureEffectiveData classe

Objet immuable qui contient les propriétés effectives de l'image.

Le type IPictureEffectiveData expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`image`](/slides/python-net/fr/aspose.slides/ipictureeffectivedata/image/) | Renvoie l'image intégrée.<br/>            Lecture seule [`IPPImage`](/slides/python-net/fr/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/fr/aspose.slides/ipictureeffectivedata/link_path_long/) | Renvoie l'URL de l'image liée.<br/>            Lecture seule **str**. |
| [`image_transform`](/slides/python-net/fr/aspose.slides/ipictureeffectivedata/image_transform/) | Renvoie la collection des effets de transformation d'image.<br/>            Lecture seule [`IImageTransformOCollectionEffectiveData`](/slides/python-net/fr/aspose.slides.effects/iimagetransformocollectioneffectivedata). |


### Remarques

Cette interface est utilisée dans le cadre de [`IPictureFillFormatEffectiveData`](/slides/python-net/fr/aspose.slides/ipicturefillformateffectivedata) et [`IBulletFormatEffectiveData`](/slides/python-net/fr/aspose.slides/ibulletformateffectivedata).
