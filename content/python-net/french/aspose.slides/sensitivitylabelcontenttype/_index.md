## SensitivityLabelContentType enumération

Représente les types de marquage de contenu qui doivent être appliqués à un document.

Le type SensitivityLabelContentType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| NONE | Implique que l’étiquette est appliquée par défaut ou automatiquement. |
| HEADER | Implique que l’étiquette a été appliquée manuellement.<br/>            Utilisez pour toute étiquette de sensibilité qui a été appliquée directement par l’utilisateur. |
| FOOTER | Implique que l’étiquette a été appliquée manuellement.<br/>            Utilisez pour toute étiquette de sensibilité qui a été appliquée directement par l’utilisateur. |
| WATERMARK | Implique que l’étiquette a été appliquée manuellement.<br/>            Utilisez pour toute étiquette de sensibilité qui a été appliquée directement par l’utilisateur. |
