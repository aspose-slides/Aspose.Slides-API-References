## classe Point

Représente une paire ordonnée de coordonnées entières x et y qui définit un point dans un plan à deux dimensions. Compatible avec .NET `System.Drawing.Point`.

Le type Point expose les membres suivants :

## Constructeurs

| Constructeur | Description |
| :- | :- |
| [`__init__(self, x=0, y=0)`](/slides/python-net/fr/aspose.slides/point/__init__/#int-int) | Crée un point avec les coordonnées spécifiées. Les valeurs flottantes sont tronquées en entiers. |

## Propriétés

| Propriété | Description |
| :- | :- |
| [`x`](/slides/python-net/fr/aspose.slides/point/x/) | Obtient ou définit la coordonnée x de ce point.<br/>            Lecture/écriture **int**. |
| [`y`](/slides/python-net/fr/aspose.slides/point/y/) | Obtient ou définit la coordonnée y de ce point.<br/>            Lecture/écriture **int**. |

### Remarques

Les points sont comparés par leurs coordonnées avec `==` et peuvent être utilisés comme clés de dictionnaire ou membres d’ensemble.
