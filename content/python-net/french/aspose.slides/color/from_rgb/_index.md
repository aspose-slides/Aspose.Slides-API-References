## from_rgb(r, g, b) {#int-int-int}
Crée une couleur opaque (alpha vaut 255) à partir des valeurs de rouge, vert et bleu spécifiées.

### Retour

La couleur créée à partir des valeurs spécifiées.

```python
@staticmethod
def from_rgb(r, g, b):
    ...
```

| Paramètre | Type | Description |
| :- | :- | :- |
| r | **int** | La valeur du composant rouge. Les valeurs valides sont de 0 à 255. |
| g | **int** | La valeur du composant vert. Les valeurs valides sont de 0 à 255. |
| b | **int** | La valeur du composant bleu. Les valeurs valides sont de 0 à 255. |

### Exceptions

| Exception | Description |
| :- | :- |
| **ValueError** | Une valeur de composant est inférieure à 0 ou supérieure à 255. |
