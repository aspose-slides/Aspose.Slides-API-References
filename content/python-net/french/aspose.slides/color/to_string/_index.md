## to_string(self) {#}
Convertit cette couleur en une chaîne lisible par l'homme. Le même texte est renvoyé par `str()` et `repr()`.

### Renvoie

`Color [Red]` pour une couleur nommée, `Color [Empty]` pour `Color.empty`, ou `Color [A=255, R=1, G=2, B=3]` pour une couleur créée à partir de composants.
