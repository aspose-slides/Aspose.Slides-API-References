## __init__(self, r=0, g=0, b=0, a=255) {#int-int-int-int}
Crée une couleur à partir des valeurs des composants rouge, vert, bleu et alpha spécifiées.

```python
def __init__(self, r=0, g=0, b=0, a=255):
    ...
```

| Paramètre | Type | Description |
| :- | :- | :- |
| r | **int** | La valeur du composant rouge. Les valeurs valides sont de 0 à 255. |
| g | **int** | La valeur du composant vert. Les valeurs valides sont de 0 à 255. |
| b | **int** | La valeur du composant bleu. Les valeurs valides sont de 0 à 255. |
| a | **int** | La valeur du composant alpha. Les valeurs valides sont de 0 à 255. |

### Exceptions

| Exception | Description |
| :- | :- |
| **ValueError** | Une valeur de composant est inférieure à 0 ou supérieure à 255. |
| **TypeError** | Une valeur de composant n'est pas un nombre. |
