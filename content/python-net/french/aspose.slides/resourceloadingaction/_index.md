## ResourceLoadingAction énumération

Spécifie le mode de chargement des ressources externes.

Le type ResourceLoadingAction expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| DEFAULT | Aspose.Slides chargera la ressource externe comme d'habitude. |
| SKIP | Aspose.Slides ignorera le chargement de la ressource externe. Seul le lien sans données sera conservé pour une image. |
| USER_PROVIDED | Aspose.Slides utilisera le tableau d’octets fourni par l’utilisateur dans **Aspose.Slides.IResourceLoadingArgs.SetData(Syste** comme données d’image. |
