## Picture classe

Représente une image dans une présentation.

Le type Picture expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`image`](/slides/python-net/fr/aspose.slides/picture/image/) | Renvoie ou définit l'image intégrée.<br/>            Lecture/écriture [`IPPImage`](/slides/python-net/fr/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/fr/aspose.slides/picture/link_path_long/) | Renvoie ou définit l'URL de l'image liée.<br/>            Lecture/écriture **str**. |
| [`image_transform`](/slides/python-net/fr/aspose.slides/picture/image_transform/) | Renvoie la collection d'effets de transformation d'image.<br/>            Lecture seule [`IImageTransformOperationCollection`](/slides/python-net/fr/aspose.slides.effects/iimagetransformoperationcollection). |
| [`presentation`](/slides/python-net/fr/aspose.slides/picture/presentation/) | Renvoie la présentation. <br/>            Lecture seule [`IPresentation`](/slides/python-net/fr/aspose.slides/ipresentation). |
| [`slide`](/slides/python-net/fr/aspose.slides/picture/slide/) | Renvoie la diapositive parente d'une image.<br/>            Lecture seule [`IBaseSlide`](/slides/python-net/fr/aspose.slides/ibaseslide). |
