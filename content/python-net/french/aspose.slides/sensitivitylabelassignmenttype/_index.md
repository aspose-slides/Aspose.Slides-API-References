## SensitivityLabelAssignmentType énumération

Représente la méthode d'affectation du label de sensibilité.

Le type SensitivityLabelAssignmentType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| STANDARD | Utilisé pour tout label de sensibilité qui n'a pas été appliqué directement par l'utilisateur.<br/>            Cela inclut les labels par défaut, les labels appliqués automatiquement. |
| PRIVILEGED | Utilisé pour tout label de sensibilité qui a été appliqué directement par l'utilisateur.<br/>            Cela inclut les labels de sensibilité appliqués manuellement ainsi que les labels recommandés<br/>            ou obligatoires ou toute fonctionnalité où l'utilisateur décide quel label de sensibilité appliquer. |
