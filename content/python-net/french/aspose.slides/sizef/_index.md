## SizeF classe

Stocke une paire ordonnée de nombres à virgule flottante, généralement la largeur et la hauteur d'un rectangle. Compatible avec .NET `System.Drawing.SizeF`.

Le type SizeF expose les membres suivants :

## Constructeurs

| Constructeur | Description |
| :- | :- |
| [`__init__(self, width=0.0, height=0.0)`](/slides/python-net/fr/aspose.slides/sizef/__init__/#float-float) | Crée une taille avec la largeur et la hauteur spécifiées. |

## Propriétés

| Propriété | Description |
| :- | :- |
| [`width`](/slides/python-net/fr/aspose.slides/sizef/width/) | Obtient le composant horizontal de cette taille.<br/>            Lecture seule **float**. |
| [`height`](/slides/python-net/fr/aspose.slides/sizef/height/) | Obtient le composant vertical de cette taille.<br/>            Lecture seule **float**. |

### Remarques

Les tailles sont comparées par leurs composants avec `==` et peuvent être utilisées comme clés de dictionnaire ou comme éléments d'ensemble.
