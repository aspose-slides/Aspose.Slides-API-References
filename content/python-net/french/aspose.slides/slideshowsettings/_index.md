## SlideShowSettings classe

Représente les paramètres du diaporama pour la présentation.

Le type SlideShowSettings expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`slide_show_type`](/slides/python-net/fr/aspose.slides/slideshowsettings/slide_show_type/) | Obtient ou définit le type de diaporama. Représenté par les ancêtres [`SlideShowSettings.slide_show_type`](/slides/python-net/fr/aspose.slides/slideshowsettings/slide_show_type) suivants : [`BrowsedAtKiosk`](/slides/python-net/fr/aspose.slides/browsedatkiosk), [`PresentedBySpeaker`](/slides/python-net/fr/aspose.slides/presentedbyspeaker) et [`BrowsedByIndividual`](/slides/python-net/fr/aspose.slides/browsedbyindividual) |
| [`loop`](/slides/python-net/fr/aspose.slides/slideshowsettings/loop/) | Diaporama en boucle |
| [`show_narration`](/slides/python-net/fr/aspose.slides/slideshowsettings/show_narration/) | Afficher la narration dans le diaporama |
| [`show_animation`](/slides/python-net/fr/aspose.slides/slideshowsettings/show_animation/) | Afficher l'animation dans le diaporama |
| [`pen_color`](/slides/python-net/fr/aspose.slides/slideshowsettings/pen_color/) | Couleur du stylo pour le diaporama |
| [`slides`](/slides/python-net/fr/aspose.slides/slideshowsettings/slides/) | Plage de diapositives |
| [`use_timings`](/fr/slides/python-net/aspose.slides/slideshowsettings/use_timings/) | Utiliser les minuteries dans le diaporama |
| [`show_media_controls`](/slides/python-net/fr/aspose.slides/slideshowsettings/show_media_controls/) | Afficher les contrôles multimédia |
