## ColorType énumération

Représente différents modes de couleur.

Le type ColorType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| NOT_DEFINED | La couleur n'est pas définie du tout. |
| RGB | Couleur RGB standard 24 bits. |
| RGB_PERCENTAGE | Couleur RGB haute définition. |
| HSL | Couleur HSL haute définition. |
| SCHEME | Couleur de schéma. |
| SYSTEM | Couleur système. |
| PRESET | Couleur prédéfinie. |
