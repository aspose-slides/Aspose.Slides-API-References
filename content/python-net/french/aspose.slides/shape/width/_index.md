## width propriété
Obtient ou définit le width de la forme, mesuré en points.
            Lecture/écriture **float**.

### Remarques

La valeur renvoyée est toujours définie et jamais **float**.
            La valeur assignée doit également être définie ; attribuez **float** uniquement aux propriétés d'une instance `RawFrame`.
