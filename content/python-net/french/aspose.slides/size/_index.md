## Size classe

Stocke une paire ordonnée d'entiers, qui spécifient une largeur et une hauteur. Compatible avec .NET `System.Drawing.Size`.

Le type Size expose les membres suivants :

## Constructeurs

| Constructeur | Description |
| :- | :- |
| [`__init__(self, width=0, height=0)`](/slides/python-net/fr/aspose.slides/size/__init__/#int-int) | Crée une taille avec la largeur et la hauteur spécifiées. Les valeurs à virgule flottante sont tronquées en entiers. |

## Propriétés

| Propriété | Description |
| :- | :- |
| [`width`](/slides/python-net/fr/aspose.slides/size/width/) | Obtient la composante horizontale de cette taille.<br/>            Lecture seule **int**. |
| [`height`](/slides/python-net/fr/aspose.slides/size/height/) | Obtient la composante verticale de cette taille.<br/>            Lecture seule **int**. |

### Remarques

Les tailles sont comparées par leurs composantes avec `==` et peuvent être utilisées comme clés de dictionnaire ou membres d'ensemble.
