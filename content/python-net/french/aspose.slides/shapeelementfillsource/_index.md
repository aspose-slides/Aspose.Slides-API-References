## ShapeElementFillSource énumération

Représente la façon dont l'élément de forme doit être rempli.

Le type ShapeElementFillSource expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| NO_FILL | Ne pas remplir le primitive. |
| SHAPE | Utilise le remplissage de la forme. |
| LIGHTEN | Utilise le remplissage éclairci de la forme. |
| LIGHTEN_LESS | Utilise le remplissage moins éclairci de la forme. |
| DARKEN | Utilise le remplissage assombri de la forme. |
| DARKEN_LESS | Utilise le remplissage moins assombri de la forme. |
