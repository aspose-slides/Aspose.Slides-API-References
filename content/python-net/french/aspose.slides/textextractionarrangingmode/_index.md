## TextExtractionArrangingMode énumération

Représente le mode à utiliser lors de l'extraction de texte

Le type TextExtractionArrangingMode expose les membres suivants:

## Champs

| Champ | Description |
| :- | :- |
| UNARRANGED | Le texte brut sans tenir compte de la position sur la diapositive |
| ARRANGED | Le texte est positionné dans le même ordre que sur la diapositive |
