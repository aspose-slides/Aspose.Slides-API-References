Représente un contrôle ActiveX.

Le type IControl expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`name`](/slides/python-net/fr/aspose.slides/icontrol/name/) | Renvoie le nom de ce contrôle.<br/>            Lecture/écriture **str**. |
| [`class_id`](/slides/python-net/fr/aspose.slides/icontrol/class_id/) | Obtient l'identifiant de classe de ce contrôle.<br/>            Lecture seule **System.Guid**. |

| [`properties`](/slides/python-net/fr/aspose.slides/icontrol/properties/) | Renvoie une collection de propriétés ActiveX.<br/>            Lecture seule [`IControlPropertiesCollection`](/slides/python-net/fr/aspose.slides/icontrolpropertiescollection). |

| [`active_x_control_binary`](/slides/python-net/fr/aspose.slides/icontrol/active_x_control_binary/) | Spécifie la persistance d'un contrôle ActiveX lorsque la méthode utilisée pour persister est soit PersistStream, PersistStreamInit ou PersistStorage. |
