## hyperlinks_changed propriété
Spécifie qu'un ou plusieurs hyperliens dans cette partie ont été mis à jour exclusivement dans cette partie par un producteur. 
            Le producteur suivant qui ouvrira ce document devra mettre à jour les relations d'hyperliens avec les nouveaux hyperliens spécifiés dans cette partie.
            Lecture/écriture **bool**.
