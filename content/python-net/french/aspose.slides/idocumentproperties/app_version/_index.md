## app_version propriété
Retourne la version de l'application.
            Lecture seule **str**.

### Remarques

Le contenu de cet élément doit être au format XX.YYYY, où X et Y représentent des valeurs numériques;
            autrement, le document sera considéré non conforme.
            Aspose.Slides représente sa version au format XX.YYZZ, où :
            XX - version majeure
            YY - version mineure
            ZZ - version de correctif
            Par exemple, la valeur 23.0105 signifie la version Aspose.Slides 23.1.5.
