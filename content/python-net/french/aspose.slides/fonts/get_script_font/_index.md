## get_script_font(self, script) {#str}
Récupère le nom de la police associé à une balise de script spécifique du thème de la présentation.

### Renvoie

Le nom de la police utilisé pour le script spécifié, ou `None` si le script n'est pas défini.



```python
def get_script_font(self, script):
    ...
```


| Paramètre | Type | Description |
| :- | :- | :- |
| script | **str** | Le code de script BCP-47 (par ex., "Latn", "Cyrl", "Jpan") utilisé pour identifier un système d'écriture. |
