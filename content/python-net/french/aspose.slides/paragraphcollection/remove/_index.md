## remove(self, item) {#iparagraph}
Supprime la première occurrence d'un objet spécifique de la **System.Collections.Generic.ICollection`1**.

### Retour

true si `item` a été supprimé avec succès de la **System.Collections.Generic.ICollection`1** ; sinon, false. Cette méthode renvoie également false si `item` n'est pas trouvé dans la **System.Collections.Generic.ICollection`1** d'origine.



```python
def remove(self, item):
    ...
```


| Paramètre | Type | Description |
| :- | :- | :- |
| item | [`IParagraph`](/slides/python-net/fr/aspose.slides/iparagraph) | L'objet à supprimer de la **System.Collections.Generic.ICollection`1**. |

### Exceptions

| Exception | Description |
| :- | :- |
| **RuntimeError(Proxy error(NotSupportedException))** | La **System.Collections.Generic.ICollection`1** est en lecture seule. |
