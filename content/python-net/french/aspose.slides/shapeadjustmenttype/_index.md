## ShapeAdjustmentType énumération

Spécifie différents types de valeurs d'ajustement de forme.

Le type ShapeAdjustmentType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| CUSTOM | Type personnalisé (ajustement inconnu) |
| CORNER_SIZE | Contrôle la taille des coins. |
| LEFT_UP_CORNER | Contrôle le coin en haut à gauche. |
| RIGHT_UP_CORNER | Contrôle le coin en haut à droite. |
| UP_CORNERS | Contrôle les coins supérieurs. |
| DOWN_CORNERS | Contrôle les coins inférieurs. |
| THICKNESS | Contrôle l'épaisseur de la figure. |
| ARROW_TAIL_THICKNESS | Contrôle l'épaisseur de la queue de la flèche. |
| ARROWHEAD_LENGTH | Contrôle la longueur de la pointe de la flèche. |
| ARROWHEAD_WIDTH | Contrôle la largeur de la pointe de la flèche. |
| RADIUS | Contrôle la taille du rayon de la forme ou de sa partie. |
| DEPTH | Contrôle la profondeur des dents d'engrenage ou de l'effet biseau. |
| SHAPE_PART_OFFSET | Contrôle le décalage d'une partie de la figure par rapport à une autre. |
| ANGLE | Contrôle l'angle de la figure ou de sa partie. |
| START_ANGLE | Angle de départ pour les formes de secteur et d'arc. |
| END_ANGLE | Angle de fin pour les formes de secteur et d'arc. |
| START_POINT_X | Contrôle la position X du point de départ de l'annotation. |
| START_POINT_Y | Contrôle la position Y du point de départ de l'annotation. |
| CONNECTOR_POINT_1X | Contrôle la position horizontale du point d'ajustement d'angle de l'annotation. |
| CONNECTOR_POINT_1Y | Contrôle la position verticale du point d'ajustement d'angle de l'annotation. |
| CONNECTOR_POINT_2X | Contrôle la position horizontale du point d'ajustement d'angle de l'annotation. |
| CONNECTOR_POINT_2Y | Contrôle la position verticale du point d'ajustement d'angle de l'annotation. |
| CONNECTOR_BEND_POSITION_X | Contrôle la position horizontale du pli du connecteur. |
| CONNECTOR_BEND_POSITION_Y | Contrôle la position verticale du pli du connecteur. |
| ATTACH_Y | Contrôle le point d'attache vertical de la figure. |
| ATTACH_X | Contrôle le point d'attache horizontal de la figure. |
| CALLOUT_HEIGHT | Contrôle la taille verticale de l'annotation. |
| CALLOUT_WIDTH | Contrôle la taille horizontale de l'annotation. |
| CALLOUT_SIZE | Contrôle la taille de l'annotation. |
| CURVATURE | Courbure d'un pli, d'accolades, d'une flèche courbée ou d'une forme. |
| HORIZONTAL_THICKNESS | Contrôle l'épaisseur horizontale de la forme d'angle. |
| VERTICAL_THICKNESS | Contrôle l'épaisseur verticale de la forme d'angle. |
| VERTICAL_SIZE | Contrôle la taille verticale de la forme. |
| HORIZONTAL_SIZE | Contrôle la taille horizontale de la forme. |
| TOP | Contrôle le côté supérieur d'une forme. |
