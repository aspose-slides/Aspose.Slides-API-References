## LineSketchType énumération

Représente le type de croquis ou l'effet qui a été attribué à une forme.

Le type LineSketchType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| NOT_DEFINED | Spécifie qu'un effet Sketch d'une forme est indéfini. |
| NONE | Spécifie qu'une forme n'a aucun effet Sketch. Cela équivaut à ce que cette propriété soit vide. |
| CURVED | Spécifie qu'une forme possède l'effet Curved, qui transforme chaque bord de la forme en une grande courbe douce. |
| FREEHAND | Spécifie qu'une forme possède l'effet Freehand, qui ressemble le plus à une ligne dessinée de façon imparfaite. |
| SCRIBBLE | Spécifie qu'une forme possède l'effet Scribble, qui présente une oscillation exagérée comme si elle était dessinée délibérément brouillonne. |
