## IFontSources classe

Fournit des sources de fichiers et de mémoire pour les polices externes.

Le type IFontSources expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`font_folders`](/slides/python-net/fr/aspose.slides/ifontsources/font_folders/) | Dossiers contenant des fichiers de police.<br/>Tous les fichiers de police situés dans ces dossiers sont inclus dans la collection. Dossiers recherchés de manière récursive. |
| [`memory_fonts`](/slides/python-net/fr/aspose.slides/ifontsources/memory_fonts/) | Une collection de polices représentées sous forme de tableaux d'octets. |
