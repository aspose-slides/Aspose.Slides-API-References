## ZoomImageType enumeration

Définit si l'objet Zoom utilise l'aperçu de la diapositive ou une image de couverture.

Le type ZoomImageType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| PREVIEW | Utilise l'image de la diapositive ou de la section. |
| COVER | Utilise une image personnalisée. |
