## HyperlinkActionType énumération

Représente un type d'action de lien hypertexte.

Le type HyperlinkActionType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| UNKNOWN | Type d'action non reconnu. |
| NO_ACTION | Aucune action. |
| HYPERLINK | Lien hypertexte habituel. |
| JUMP_FIRST_SLIDE | Passer à la première diapositive de la présentation. |
| JUMP_PREVIOUS_SLIDE | Passer à la diapositive précédente. |
| JUMP_NEXT_SLIDE | Passer à la diapositive suivante. |
| JUMP_LAST_SLIDE | Passer à la dernière diapositive de la présentation. |
| JUMP_END_SHOW | Passer à la fin du diaporama. |
| JUMP_LAST_VIEWED_SLIDE | Passer à la dernière diapositive affichée. |
| JUMP_SPECIFIC_SLIDE | Passer à la diapositive spécifique, référencée par la propriété [`IHyperlink.target_slide`](/slides/python-net/fr/aspose.slides/ihyperlink/target_slide). |
| START_CUSTOM_SLIDE_SHOW | Démarrer un diaporama personnalisé. |
| OPEN_FILE | Ouvrir le fichier référencé. |
| OPEN_PRESENTATION | Ouvrir la présentation référencée. |
| START_STOP_MEDIA | Démarrer/arrêter la lecture du fichier multimédia. |
| START_MACRO | Démarrer l'exécution du script macro. |
| START_PROGRAM | Démarrer le programme. |
