## ImageFormat énumération

Représente le format de fichier de l'image.

Le type ImageFormat expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| MEMORY_BMP | Représente le format d'un bitmap en mémoire. |
| BMP | Représente le format d'image bitmap (BMP). |
| EMF | Représente le format d'image metafile amélioré (EMF). |
| WMF | Représente le format d'image metafile Windows (WMF). |
| GIF | Représente le format d'image Graphics Interchange Format (GIF). |
| JPEG | Représente le format d'image Joint Photographic Experts Group (JPEG). |
| PNG | Représente le format d'image Portable Network Graphics (PNG) du W3C. |
| TIFF | Représente le format d'image Tagged Image File Format (TIFF). |
| EXIF | Représente le format Exchangeable Image File (Exif). |
| ICON | Représente le format d'image icône Windows. |
