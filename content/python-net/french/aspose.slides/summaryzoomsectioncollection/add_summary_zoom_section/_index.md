## add_summary_zoom_section(self, section) {#isection}
Crée un nouvel objet Summary Zoom Section et l'ajoute à la collection

### Retour
Ajouté [`ISummaryZoomFrame`](/slides/python-net/fr/aspose.slides/isummaryzoomframe) element

```python
def add_summary_zoom_section(self, section):
    ...
```

| Paramètre | Type | Description |
| :- | :- | :- |
| section | [`ISection`](/slides/python-net/fr/aspose.slides/isection) | Section pour un nouvel élément Summary Zoom Section [`ISection`](/slides/python-net/fr/aspose.slides/isection) |

### Remarques
Si un élément pour cette section existe déjà dans la collection, l'élément existant est renvoyé.

### Exceptions
| Exception | Description |
| :- | :- |
| **RuntimeError(Proxy error(ArgumentException))** | La section référencée n'appartient pas à la présentation actuelle ou ne contient aucune diapositive. |
