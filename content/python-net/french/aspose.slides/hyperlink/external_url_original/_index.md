## external_url_original propriété
Represents a hyperlink that is set for this portion without regard to the actual content of the portion.
            
            PowerPoint se comporte spécifiquement pour les liens et le texte correspondant dans une partie. Il permet de créer du texte pour l'hyperlien sous forme d'une URL valide
            différente de l'adresse réelle du lien. Dans ce cas, lorsque vous visualisez le lien dans la fenêtre d'édition, il sera
            modifié pour correspondre à la partie de texte. Cette propriété représente la valeur originale de l'hyperlien.
