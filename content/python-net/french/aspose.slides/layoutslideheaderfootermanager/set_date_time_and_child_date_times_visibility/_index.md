## set_date_time_and_child_date_times_visibility(self, is_visible) {#bool}
Modifie la visibilité de l’espace réservé date-heure de la diapositive de mise en page et de tous les espaces réservés date-heure enfants.  
Les espaces réservés enfants signifient que les espaces réservés sont contenus sur les diapositives dépendantes.  
Les diapositives dépendantes utilisent et dépendent de la diapositive de mise en page.

```python
def set_date_time_and_child_date_times_visibility(self, is_visible):
    ...
```

| Paramètre | Type | Description |
| :- | :- | :- |
| is_visible | **bool** | true - rend les espaces réservés date-heure visibles, sinon - les masque. |
