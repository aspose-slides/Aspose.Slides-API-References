## set_footer_and_child_footers_visibility(self, is_visible) {#bool}
Modifie la visibilité de l’espace réservé au pied de page de la diapositive de mise en page et de tous les espaces réservés aux pieds de page enfants.
Les espaces réservés enfants désignent les espaces réservés contenus dans les diapositives dépendantes.
Les diapositives dépendantes utilisent et dépendent de la diapositive maître.

```python
    ...
```

| Paramètre | Type | Description |
| :- | :- | :- |
| is_visible | **bool** | true - rend les espaces réservés au pied de page visibles, sinon les masque. |
