## FontsLoader classe

Classe pour charger les polices personnalisées définies par l'utilisateur. Doit être utilisée avant de créer tout objet de présentation.

Le type FontsLoader expose les membres suivants :

## Méthodes

| Méthode | Description |
| :- | :- |
| [`load_external_fonts(directories)`](/slides/python-net/fr/aspose.slides/fontsloader/load_external_fonts/#liststr) | Ajoute des dossiers supplémentaires pour rechercher les polices. |
| [`load_external_font(data)`](/slides/python-net/fr/aspose.slides/fontsloader/load_external_font/#bytes) | Ajoute une police à partir des données binaires |
| [`get_font_folders()`](/slides/python-net/fr/aspose.slides/fontsloader/get_font_folders/#) | Obtient les dossiers de polices. Retourne les dossiers qui ont été ajoutés avec la méthode LoadExternalFonts ainsi que les dossiers de polices système |
| [`clear_cache()`](/slides/python-net/fr/aspose.slides/fontsloader/clear_cache/#) | Libère toutes les polices personnalisées définies par l'utilisateur |
