## IShapeFrame classe

Représente les propriétés du cadre de forme.

Le type IShapeFrame expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`x`](/slides/python-net/fr/aspose.slides/ishapeframe/x/) | Renvoie la coordonnée X du coin supérieur gauche d'un cadre.<br/>            Lecture seule **float**. |
| [`y`](/slides/python-net/fr/aspose.slides/ishapeframe/y/) | Renvoie la coordonnée Y du coin supérieur gauche d'un cadre.<br/>            Lecture seule **float**. |
| [`width`](/slides/python-net/fr/aspose.slides/ishapeframe/width/) | Renvoie la largeur d'un cadre.<br/>            Lecture seule **float**. |
| [`height`](/slides/python-net/fr/aspose.slides/ishapeframe/height/) | Renvoie la hauteur d'un cadre.<br/>            Lecture seule **float**. |
| [`rotation`](/slides/python-net/fr/aspose.slides/ishapeframe/rotation/) | Renvoie le nombre de degrés de rotation d'un cadre autour de l'axe z.<br/>            Une valeur positive indique une rotation dans le sens horaire ; une valeur négative<br/>            indique une rotation dans le sens antihoraire.<br/>            Lecture seule **float**. |
| [`center_x`](/slides/python-net/fr/aspose.slides/ishapeframe/center_x/) | Renvoie la coordonnée X du centre d'un cadre.<br/>            Lecture seule **float**. |
| [`center_y`](/slides/python-net/fr/aspose.slides/ishapeframe/center_y/) | Renvoie la coordonnée Y du centre d'un cadre.<br/>            Lecture seule **float**. |
| [`flip_h`](/slides/python-net/fr/aspose.slides/ishapeframe/flip_h/) | Détermine si un cadre est retourné horizontalement.<br/>            Lecture seule [`NullableBool`](/slides/python-net/fr/aspose.slides/nullablebool). |
| [`flip_v`](/slides/python-net/fr/aspose.slides/ishapeframe/flip_v/) | Détermine si un cadre est retourné verticalement.<br/>            Lecture seule [`NullableBool`](/slides/python-net/fr/aspose.slides/nullablebool). |
| [`rectangle`](/slides/python-net/fr/aspose.slides/ishapeframe/rectangle/) | Renvoie les coordonnées d'un cadre.<br/>            Lecture seule **aspose.slides.RectangleF**. |
