## SensitivityLabel classe

Représente le label de sensibilité de Microsoft Purview Information Protection.

Le type SensitivityLabel expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`id`](/slides/python-net/fr/aspose.slides/sensitivitylabel/id/) | Renvoie ou définit l'identifiant du label de sensibilité.<br/>            Lecture/écriture **str**. |
| [`site_id`](/slides/python-net/fr/aspose.slides/sensitivitylabel/site_id/) | Renvoie ou définit l'identifiant du site Azure Active Directory (Azure AD) <br/>            correspondant à la stratégie de label de sensibilité qui décrit le label de sensibilité.<br/>            Lecture/écriture **System.Guid**. |
| [`is_enabled`](/slides/python-net/fr/aspose.slides/sensitivitylabel/is_enabled/) | Indique si le label de sensibilité est activé. |
| [`is_removed`](/slides/python-net/fr/aspose.slides/sensitivitylabel/is_removed/) | Indique si le label de sensibilité a été supprimé. |
| [`assignment_method_type`](/slides/python-net/fr/aspose.slides/sensitivitylabel/assignment_method_type/) | Renvoie ou définit la méthode d'attribution du label de sensibilité.<br/>            Lecture/écriture [`SensitivityLabelAssignmentType`](/slides/python-net/fr/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/fr/aspose.slides/sensitivitylabel/content_mark_types/) | Renvoie la liste des types de marquage de contenu qui doivent être appliqués à un fichier. |
