## propriété de rotation
Renvoie ou définit le nombre de degrés selon lequel la forme spécifiée est pivotée autour de l'axe z. Une valeur positive indique une rotation dans le sens des aiguilles d'une montre ; une valeur négative indique une rotation dans le sens inverse des aiguilles d'une montre.
Lecture/écriture **float**.


### Remarques

La valeur renvoyée est toujours définie (n'est pas float.NaN). La valeur assignée doit être définie (pas float.NaN). Vous pouvez définir des valeurs indéfinies pour les propriétés d'instance de RawFrame.
