## set_date_time_and_child_date_times_visibility(self, is_visible) {#bool}
Modifie la visibilité de l’espace réservé de date-heure de la diapositive maîtresse des notes et de tous les espaces réservés de date-heure enfants.  
Les espaces réservés enfants signifient que les espaces réservés sont contenus sur les diapositives de notes dépendantes.  
Les diapositives de notes dépendantes utilisent et dépendent de la diapositive maîtresse des notes.

```python
def set_date_time_and_child_date_times_visibility(self, is_visible):
    ...
```


| Parameter | Type | Description |
| :- | :- | :- |
| is_visible | **bool** | true - rend les espaces réservés de date-heure visibles, sinon - les masque. |
