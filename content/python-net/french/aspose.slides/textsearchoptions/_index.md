## TextSearchOptions classe

Représente les options qui peuvent être utilisées pour rechercher du texte dans une Presentation, Slide ou TextFrame.

Le type TextSearchOptions expose les membres suivants :

## Constructeurs

| Constructeur | Description |
| :- | :- |
| [`__init__(self)`](/slides/python-net/fr/aspose.slides/textsearchoptions/__init__/#) | Crée de nouvelles options de recherche de texte par défaut. |

## Propriétés

| Propriété | Description |
| :- | :- |
| [`case_sensitive`](/slides/python-net/fr/aspose.slides/textsearchoptions/case_sensitive/) | Définir true pour utiliser une recherche sensible à la casse, false sinon.<br/>            Read/write **bool**. |
| [`whole_words_only`](/slides/python-net/fr/aspose.slides/textsearchoptions/whole_words_only/) | Définir true pour ne correspondre qu'aux mots entiers, false sinon.<br/>            Read/write **bool**. |
| [`include_notes`](/slides/python-net/fr/aspose.slides/textsearchoptions/include_notes/) | Définir `true` pour inclure le texte contenu dans les notes de diapositive ([`NotesSlide`](/slides/python-net/fr/aspose.slides/notesslide)) <br/>            lors des opérations de recherche de texte, de remplacement ou de mise en surbrillance.<br/>            La valeur par défaut est `false`. |
