## CustomXmlPart classe

Représente une partie XML personnalisée.

Le type CustomXmlPart expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`xml_data`](/slides/python-net/fr/aspose.slides/customxmlpart/xml_data/) | Renvoie ou définit les données xml.<br/>Lecture/écriture **int**[].<br/>la valeur est `None`.la valeur est vide ou les données xml sont invalides. |
| [`xml_as_string`](/slides/python-net/fr/aspose.slides/customxmlpart/xml_as_string/) | Renvoie ou définit les données xml sous forme de chaîne UTF-8.<br/>Lecture/écriture **str**.<br/>la valeur est `None`.la valeur est vide ou les données xml sont invalides. |
| [`item_id`](/slides/python-net/fr/aspose.slides/customxmlpart/item_id/) | Spécifie un identifiant globalement unique (GUID) qui identifie de manière unique une seule partie XML personnalisée <br/>au sein d'un document Office Open XML.<br/>Lecture seule **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/fr/aspose.slides/customxmlpart/namespace_schemas/) | Renvoie la collection des schémas XML associés à la partie XML personnalisée.<br/>Lecture seule **str**[]. |
