## IViewProperties classe

Propriétés de vue à l'échelle de la présentation.

Le type IViewProperties expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`last_view`](/slides/python-net/fr/aspose.slides/iviewproperties/last_view/) | Spécifie le mode d'affichage qui était utilisé lorsque le document de présentation a été enregistré pour la dernière fois.<br/>            Lecture/écriture [`ViewType`](/slides/python-net/fr/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/fr/aspose.slides/iviewproperties/show_comments/) | Spécifie si les commentaires de diapositive doivent être affichés.<br/>            Lecture/écriture [`NullableBool`](/slides/python-net/fr/aspose.slides/nullablebool). |
| [`slide_view_properties`](/slides/python-net/fr/aspose.slides/iviewproperties/slide_view_properties/) | Spécifie les propriétés de vue communes associées au mode d'affichage des diapositives.<br/>            Lecture seule [`ICommonSlideViewProperties`](/slides/python-net/fr/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/fr/aspose.slides/iviewproperties/notes_view_properties/) | Spécifie les propriétés de vue communes associées au mode d'affichage des notes.<br/>            Lecture seule [`ICommonSlideViewProperties`](/slides/python-net/fr/aspose.slides/icommonslideviewproperties). |
| [`normal_view_properties`](/slides/python-net/fr/aspose.slides/iviewproperties/normal_view_properties/) | Représente les propriétés de vue normales. La vue normale se compose de<br/>            trois régions de contenu : la diapositive elle-même, une région de contenu latérale et une région de contenu inférieure.<br/>            Lecture seule [`INormalViewProperties`](/slides/python-net/fr/aspose.slides/inormalviewproperties). |
| [`grid_spacing`](/slides/python-net/fr/aspose.slides/iviewproperties/grid_spacing/) | Renvoie ou définit l'espacement de la grille qui doit être utilisé pour la grille sous-jacent le document de présentation, en points.<br/>            Lecture/écriture **float**. |
