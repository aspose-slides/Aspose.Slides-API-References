## remove(self, item) {#icustomxmlpart}
Supprime la première occurrence d'un objet spécifique de la collection.

### Retour

`true` si l'élément est supprimé avec succès ; sinon, `false`.



```python
def remove(self, item):
    ...
```


| Paramètre | Type | Description |
| :- | :- | :- |
| item | [`ICustomXmlPart`](/slides/python-net/fr/aspose.slides/icustomxmlpart) | La partie xml personnalisée à supprimer. |

### Exceptions

| Exception | Description |
| :- | :- |
| **RuntimeError(Proxy error(ArgumentNullException))** | l'élément est `None`. |
