## PathCommandType énumération

Représente les commandes de chemin graphique

Le type PathCommandType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| CLOSE | Ferme le chemin géométrique |
| MOVE_TO | Définit la position du point suivant du chemin géométrique |
| LINE_TO | Ajoute une ligne au chemin géométrique |
| ARC_TO | Ajoute l'arc spécifié au chemin géométrique. |
| QUAD_BEZIER_TO | Ajoute une courbe de Bézier quadratique au chemin géométrique |
| CUBIC_BEZIER_TO | Ajoute une courbe de Bézier cubique au chemin géométrique |
