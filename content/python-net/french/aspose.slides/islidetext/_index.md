## ISlideText classe

Représente le texte extrait de la diapositive

Le type ISlideText expose les membres suivants:

## Propriétés

| Propriété | Description |
| :- | :- |
| [`text`](/slides/python-net/fr/aspose.slides/islidetext/text/) | Le texte sur les formes de la diapositive |
| [`master_text`](/slides/python-net/fr/aspose.slides/islidetext/master_text/) | Le texte sur les formes de la page maître pour cette diapositive |
| [`layout_text`](/slides/python-net/fr/aspose.slides/islidetext/layout_text/) | Le texte sur les formes de la page de mise en page pour cette diapositive |
| [`notes_text`](/slides/python-net/fr/aspose.slides/islidetext/notes_text/) | Le texte sur les formes de la page de notes pour cette diapositive |
| [`comments_text`](/slides/python-net/fr/aspose.slides/islidetext/comments_text/) | Le texte des commentaires de la diapositive |
