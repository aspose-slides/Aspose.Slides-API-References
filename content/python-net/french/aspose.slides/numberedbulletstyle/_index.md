## énumération NumberedBulletStyle

Représente le style des puces numérotées.

Le type NumberedBulletStyle expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| NOT_DEFINED | Non défini. |
| BULLET_ALPHA_LC_PERIOD | Caractères alphabétiques minuscules avec un point. Sample: a., b., c., ... |
| BULLET_ALPHA_UC_PERIOD | Caractères alphabétiques majuscules avec un point. Sample: A., B., C., ... |
| BULLET_ARABIC_PAREN_RIGHT | Nombres arabes avec une parenthèse fermante. Sample: 1), 2), 3), ... |
| BULLET_ARABIC_PERIOD | Nombres arabes avec un point. Sample: 1., 2., 3., ... |
| BULLET_ROMAN_LC_PAREN_BOTH | Nombres romains minuscules avec les deux parenthèses. Sample: (i), (ii), (iii), ... |
| BULLET_ROMAN_LC_PAREN_RIGHT | Nombres romains minuscules avec une parenthèse fermante. Sample: i), ii), iii), ... |
| BULLET_ROMAN_LC_PERIOD | Nombres romains minuscules avec un point. Sample: i., ii., iii., ... |
| BULLET_ROMAN_UC_PERIOD | Nombres romains majuscules avec un point. Sample: I., II., III., ... |
| BULLET_ALPHA_LC_PAREN_BOTH | Caractères alphabétiques minuscules avec les deux parenthèses. Sample: (a), (b), (c), ... |
| BULLET_ALPHA_LC_PAREN_RIGHT | Caractères alphabétiques minuscules avec une parenthèse fermante. Sample: a), b), c), ... |
