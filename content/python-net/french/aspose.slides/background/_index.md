## Background classe

Représente l'arrière-plan d'une diapositive.

**Héritage:**[`Background`](/slides/python-net/fr/aspose.slides/background) → [`PVIObject`](/slides/python-net/fr/aspose.slides/pviobject)

Le type Background expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`type`](/slides/python-net/fr/aspose.slides/background/type/) | Renvoie un type de remplissage d'arrière-plan.<br/>            Lecture/écriture [`BackgroundType`](/slides/python-net/fr/aspose.slides/backgroundtype). |
| [`fill_format`](/slides/python-net/fr/aspose.slides/background/fill_format/) | Renvoie un FillFormat pour le remplissage BackgroundType.OwnBackground.<br/>            Lecture seule [`IFillFormat`](/slides/python-net/fr/aspose.slides/ifillformat). |
| [`effect_format`](/slides/python-net/fr/aspose.slides/background/effect_format/) | Renvoie un EffectFormat pour le remplissage BackgroundType.OwnBackground.<br/>            Lecture seule [`IEffectFormat`](/slides/python-net/fr/aspose.slides/ieffectformat). |
| [`style_color`](/slides/python-net/fr/aspose.slides/background/style_color/) | Renvoie un ColorFormat pour un remplissage BackgroundType.Themed.<br/>            Lecture seule [`IColorFormat`](/slides/python-net/fr/aspose.slides/icolorformat). |
| [`style_index`](/slides/python-net/fr/aspose.slides/background/style_index/) | Renvoie un indice du remplissage BackgroundType.Themed dans la collection du thème d'arrière-plan.<br/>            0 signifie aucun remplissage.<br/>            1..999 - indice.<br/>            Lecture/écriture **int**. |
| [`slide`](/slides/python-net/fr/aspose.slides/background/slide/) | Renvoie la diapositive parente d'une forme.<br/>            Lecture seule [`IBaseSlide`](/slides/python-net/fr/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/fr/aspose.slides/background/presentation/) | Renvoie la présentation parente d'une diapositive.<br/>            Lecture seule [`IPresentation`](/slides/python-net/fr/aspose.slides/ipresentation). |
