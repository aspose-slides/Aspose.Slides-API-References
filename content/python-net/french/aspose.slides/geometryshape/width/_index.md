## width propriété
Obtient ou définit le width de la forme, mesurés en points.
            Lecture/écriture **float**.


### Remarques

La valeur retournée est toujours définie et n'est jamais **float**.
            La valeur assignée doit également être définie ; attribuez **float** uniquement aux propriétés d'une instance de `RawFrame`.
