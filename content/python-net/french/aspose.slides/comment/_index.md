## Comment classe

Représente un commentaire sur une diapositive.

Le type Comment expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`text`](/slides/python-net/fr/aspose.slides/comment/text/) | Renvoie ou définit le texte brut d'un commentaire de diapositive.<br/>            Lecture/écriture **str**. |
| [`created_time`](/slides/python-net/fr/aspose.slides/comment/created_time/) | Renvoie ou définit l'heure de création d'un commentaire.<br/>            Définir cette propriété à **System.DateTime** signifie qu'aucune heure de commentaire n'est définie.<br/>            Lecture/écriture **System.DateTime**. |
| [`slide`](/slides/python-net/fr/aspose.slides/comment/slide/) | Renvoie ou définit la diapositive parent d'un commentaire.<br/>            Lecture seule [`ISlide`](/slides/python-net/fr/aspose.slides/islide). |
| [`author`](/slides/python-net/fr/aspose.slides/comment/author/) | Renvoie l'auteur d'un commentaire.<br/>            Lecture seule [`ICommentAuthor`](/slides/python-net/fr/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/fr/aspose.slides/comment/position/) | Renvoie ou définit la position d'un commentaire sur une diapositive.<br/>            Lecture/écriture **aspose.slides.PointF**. |
| [`parent_comment`](/slides/python-net/fr/aspose.slides/comment/parent_comment/) | Renvoie ou définit le commentaire parent.<br/>            Lecture/écriture [`IComment`](/slides/python-net/fr/aspose.slides/icomment). |

## Méthodes

| Méthode | Description |
| :- | :- |
| [`remove(self)`](/slides/python-net/fr/aspose.slides/comment/remove/#) | Supprime le commentaire et toutes ses réponses de la collection parent. |
