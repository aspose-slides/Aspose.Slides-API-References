## IGradientFormatEffectiveData classe

Objet immuable qui contient les propriétés effectives de remplissage en dégradé.

Le type IGradientFormatEffectiveData expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`tile_flip`](/slides/python-net/fr/aspose.slides/igradientformateffectivedata/tile_flip/) | Renvoie le mode de retournement d'un dégradé.<br/>            Lecture seule [`TileFlip`](/slides/python-net/fr/aspose.slides/tileflip). |
| [`gradient_direction`](/slides/python-net/fr/aspose.slides/igradientformateffectivedata/gradient_direction/) | Renvoie le style d'un dégradé.<br/>            Lecture seule [`GradientDirection`](/slides/python-net/fr/aspose.slides/gradientdirection). |
| [`linear_gradient_angle`](/slides/python-net/fr/aspose.slides/igradientformateffectivedata/linear_gradient_angle/) | Renvoie l'angle d'un dégradé.<br/>            Lecture seule **float**. |
| [`linear_gradient_scaled`](/slides/python-net/fr/aspose.slides/igradientformateffectivedata/linear_gradient_scaled/) | Détermine si un dégradé est mis à l'échelle.<br/>            Lecture seule **bool**. |
| [`gradient_shape`](/slides/python-net/fr/aspose.slides/igradientformateffectivedata/gradient_shape/) | Renvoie la forme d'un dégradé.<br/>            Lecture seule [`GradientShape`](/slides/python-net/fr/aspose.slides/gradientshape). |
| [`gradient_stops`](/slides/python-net/fr/aspose.slides/igradientformateffectivedata/gradient_stops/) | Renvoie la collection d'arrêts de dégradé.<br/>            Lecture seule [`IGradientStopCollectionEffectiveData`](/slides/python-net/fr/aspose.slides/igradientstopcollectioneffectivedata). |
