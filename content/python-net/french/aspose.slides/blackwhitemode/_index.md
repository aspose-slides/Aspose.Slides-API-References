## BlackWhiteMode énumération

Détermine comment une forme colorée doit être transformée en noir et blanc.

Le type BlackWhiteMode expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| NOT_DEFINED | La propriété n'est pas définie |
| COLOR | L'objet est rendu avec une coloration normale |
| AUTOMATIC | L'objet est rendu avec une coloration automatique |
| GRAY | L'objet est rendu avec une coloration grise |
| LIGHT_GRAY | L'objet est rendu avec une coloration gris clair |
| INVERSE_GRAY | L'objet est rendu avec une coloration gris inversé |
| GRAY_WHITE | L'objet est rendu avec une coloration gris et blanc |
| BLACK_GRAY | L'objet est rendu avec une coloration noir et gris |
| BLACK_WHITE | L'objet est rendu avec une coloration noir et blanc |
| BLACK | L'objet est rendu uniquement avec une coloration noire |
| WHITE | L'objet est rendu avec une coloration blanche |
| HIDDEN | L'objet n'est pas rendu |
