## énumération FillType

Spécifie le type de remplissage intérieur de divers objets visuels.

Le type FillType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| NOT_DEFINED | Le type de remplissage n'est pas défini. |
| NO_FILL | Aucun remplissage appliqué. |
| SOLID | Rempli avec une couleur unie. |
| GRADIENT | Le remplissage est en dégradé. |
| PATTERN | Un motif répétitif est utilisé pour remplir l'objet. |
| PICTURE | Une seule image est utilisée pour remplir l'objet. |
| GROUP | L'objet visuel hérite des propriétés de remplissage du groupe. |
