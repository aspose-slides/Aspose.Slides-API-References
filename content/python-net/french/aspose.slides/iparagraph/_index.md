## IParagraph classe

Représente un paragraphe d'un texte.

Le type IParagraph expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`portions`](/slides/python-net/fr/aspose.slides/iparagraph/portions/) | Renvoie la collection des portions de texte.<br/>            Lecture seule [`IPortionCollection`](/slides/python-net/fr/aspose.slides/iportioncollection). |
| [`paragraph_format`](/slides/python-net/fr/aspose.slides/iparagraph/paragraph_format/) | Renvoie l'objet de mise en forme de ce paragraphe.<br/>            Lecture seule [`IParagraphFormat`](/slides/python-net/fr/aspose.slides/iparagraphformat). |
| [`text`](/slides/python-net/fr/aspose.slides/iparagraph/text/) | Obtient ou définit le texte brut d'un paragraphe.<br/>            Lecture/écriture **str**. |
| [`end_paragraph_portion_format`](/slides/python-net/fr/aspose.slides/iparagraph/end_paragraph_portion_format/) | Spécifie les propriétés de la portion à utiliser si une autre portion est insérée après <br/>            la dernière. |
| [`slide`](/slides/python-net/fr/aspose.slides/iparagraph/slide/) |  |
| [`presentation`](/slides/python-net/fr/aspose.slides/iparagraph/presentation/) |  |

| Méthode | Description |
| :- | :- |
| [`get_image`](/slides/python-net/fr/aspose.slides/iparagraph/get_image/#) | Renvoie une image du paragraphe. |
