## CommentAuthor classe

Représente un auteur de commentaires.

Le type CommentAuthor expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`name`](/slides/python-net/fr/aspose.slides/commentauthor/name/) | Renvoie ou définit le nom de l'auteur.<br/> Lecture/écriture **str**. |
| [`initials`](/slides/python-net/fr/aspose.slides/commentauthor/initials/) | Renvoie ou définit les initiales de l'auteur.<br/> Lecture/écriture **str**. |
| [`comments`](/slides/python-net/fr/aspose.slides/commentauthor/comments/) | Renvoie la collection des commentaires faits par cet auteur.<br/> Lecture seule [`ICommentCollection`](/slides/python-net/fr/aspose.slides/icommentcollection). |

## Méthodes

| Méthode | Description |
| :- | :- |
| [`remove(self)`](/slides/python-net/fr/aspose.slides/commentauthor/remove/#) | Supprime l'auteur de la collection parente. |
