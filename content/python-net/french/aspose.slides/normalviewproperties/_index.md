## NormalViewProperties classe

Représente les propriétés de la vue normale. La vue normale se compose de trois régions de contenu : la diapositive elle-même, une région de contenu latérale et une région de contenu inférieure.

Le type NormalViewProperties expose les membres suivants :

## Propriétés

| Property | Description |
| :- | :- |
| [`show_outline_icons`](/slides/python-net/fr/aspose.slides/normalviewproperties/show_outline_icons/) | Indique si l'application doit afficher des icônes lors de l'affichage du contenu du plan dans l'une des régions de contenu du mode de vue normale.<br/>            Lecture/écriture **bool**. |
| [`snap_vertical_splitter`](/slides/python-net/fr/aspose.slides/normalviewproperties/snap_vertical_splitter/) | Indique si le séparateur vertical doit se verrouiller à un état réduit lorsque la région latérale est suffisamment petite.<br/>            Lecture/écriture **bool**. |
| [`vertical_bar_state`](/slides/python-net/fr/aspose.slides/normalviewproperties/vertical_bar_state/) | Indique l'état dans lequel la barre de séparation verticale doit être affichée. <br/>            Une barre de séparation verticale sépare la diapositive de la région de contenu latérale. |
| [`horizontal_bar_state`](/slides/python-net/fr/aspose.slides/normalviewproperties/horizontal_bar_state/) | Indique l'état dans lequel la barre de séparation horizontale doit être affichée.<br/>            Une barre de séparation horizontale sépare la diapositive de la région de contenu située sous la diapositive. |
| [`prefer_single_view`](/slides/python-net/fr/aspose.slides/normalviewproperties/prefer_single_view/) | Indique si l'utilisateur préfère voir une région de contenu unique en plein écran plutôt que la vue normale standard avec trois régions de contenu. Si activé, l'application peut choisir d'afficher l'une des régions de contenu dans toute la fenêtre.<br/>            Lecture/écriture **bool**. |
| [`restored_left`](/slides/python-net/fr/aspose.slides/normalviewproperties/restored_left/) | Cet élément spécifie la taille de la région de contenu latérale de la vue normale, lorsque la région a une taille restaurée variable (ni réduite ni agrandie).<br/>            Lecture seule [`INormalViewRestoredProperties`](/slides/python-net/fr/aspose.slides/inormalviewrestoredproperties). |
| [`restored_top`](/slides/python-net/fr/aspose.slides/normalviewproperties/restored_top/) | Cet élément spécifie la taille de la région supérieure de la diapositive de la vue normale, lorsque la région a une taille restaurée variable (ni réduite ni agrandie).<br/>            Lecture seule [`INormalViewRestoredProperties`](/slides/python-net/fr/aspose.slides/inormalviewrestoredproperties). |
