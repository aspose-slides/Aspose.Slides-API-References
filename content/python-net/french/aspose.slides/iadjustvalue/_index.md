## IAdjustValue classe

Représente la valeur d'ajustement d'une forme géométrique.
            Ces valeurs affectent la forme de la forme.

Le type IAdjustValue expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`raw_value`](/slides/python-net/fr/aspose.slides/iadjustvalue/raw_value/) | Renvoie ou définit la valeur d'ajustement « tel quel ».<br/>            Lecture/écriture **int**. |
| [`angle_value`](/slides/python-net/fr/aspose.slides/iadjustvalue/angle_value/) | Renvoie ou définit la valeur, en l'interprétant comme un angle en degrés.<br/>            Lecture/écriture **float**. |
| [`name`](/slides/python-net/fr/aspose.slides/iadjustvalue/name/) | Renvoie le nom de cette valeur d'ajustement.<br/>            Lecture seule **str**. |
| [`type`](/slides/python-net/fr/aspose.slides/iadjustvalue/type/) | Renvoie le type de l'ajustement de forme.<br/>            Lecture seule [`ShapeAdjustmentType`](/slides/python-net/fr/aspose.slides/shapeadjustmenttype). |
