## fill_style_index propriété
Renvoie ou définit l'indice de colonne de remplissage de shape dans les matrices de style.
            0 signifie aucun remplissage,
            valeur positive - indice dans les styles de remplissage du thème,
            valeur négative - indice dans les styles d'arrière-plan du thème.
            Lecture/écriture **int**.
