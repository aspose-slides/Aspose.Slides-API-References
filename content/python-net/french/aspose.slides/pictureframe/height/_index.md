## height propriété
Gets or sets the height of the shape, measured in points.
            Lecture/écriture **float**.


### Remarques

La valeur renvoyée est toujours définie et jamais **float**.
            La valeur assignée doit également être définie ; assigner **float** uniquement aux propriétés d'une instance `RawFrame`.
