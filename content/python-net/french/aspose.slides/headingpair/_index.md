## HeadingPair classe

Représente la propriété 'Heading pair' du document. 
            Elle indique le nom du groupe des parties du document et le nombre de parties dans le groupe.

Le type HeadingPair expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`name`](/slides/python-net/fr/aspose.slides/headingpair/name/) | Renvoie le nom du groupe des parties du document.<br/>            Lecture seule **str**. |
| [`count`](/slides/python-net/fr/aspose.slides/headingpair/count/) | Renvoie le nombre de parties dans le groupe.<br/>            Lecture seule **int**. |
