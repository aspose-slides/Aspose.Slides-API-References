## paragraph_format propriété
Renvoie l'objet de mise en forme pour ce paragraphe.
Lecture seule [`IParagraphFormat`](/slides/python-net/fr/aspose.slides/iparagraphformat).

### Remarques

L'objet de mise en forme contient les paramètres de mise en forme définis uniquement pour le paragraphe actuel, les données héritées ne sont pas appliquées.

Afin d'obtenir les valeurs effectives incluant celles héritées, utilisez la méthode [`ParagraphFormat.get_effective`](/slides/python-net/fr/aspose.slides/paragraphformat/get_effective).
