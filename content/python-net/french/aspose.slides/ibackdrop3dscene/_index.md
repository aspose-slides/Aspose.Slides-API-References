## IBackdrop3DScene classe

Définit un plan dans lequel les effets, tels que la lueur et l'ombre, sont appliqués par rapport à la forme à laquelle ils sont appliqués.

Le type IBackdrop3DScene expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`normal_vector`](/slides/python-net/fr/aspose.slides/ibackdrop3dscene/normal_vector/) | Renvoie ou définit un vecteur normal. Pour être plus précis, cet attribut définit un vecteur normal à la surface du plan de toile de fond. Vecteur représenté par un tableau de 3 valeurs float qui définissent les coordonnées X, Y et Z.<br/>            Lecture/écriture **float**[]. |
| [`anchor_point`](/slides/python-net/fr/aspose.slides/ibackdrop3dscene/anchor_point/) | Renvoie ou définit un point dans l'espace 3D. Ce point est le point dans l'espace qui ancre le plan de toile de fond.<br/>            Point 3D représenté par un tableau de 3 valeurs float qui définissent les coordonnées X, Y et Z.<br/>            Lecture/écriture **float**[]. |
| [`up_vector`](/slides/python-net/fr/aspose.slides/ibackdrop3dscene/up_vector/) | Renvoie ou définit un vecteur représentant le haut. Pour être plus précis, cet attribut définit un vecteur représentant le haut par rapport à la surface du plan de toile de fond. Vecteur représenté par un tableau de 3 valeurs float qui définissent les coordonnées X, Y et Z.<br/>            Lecture/écriture **float**[]. |
