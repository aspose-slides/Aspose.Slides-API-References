## external_url_original propriété
Représente un hyperlien qui est défini pour cette partie sans tenir compte du contenu réel de la partie.
            
            PowerPoint se comporte de manière spécifique pour les liens et le texte qui leur correspond dans une partie. Il permet de créer un texte pour l'hyperlien sous la forme d'une URL valide, différente de l'adresse réelle du lien. Dans ce cas, lorsque vous affichez le lien dans la fenêtre d'édition, il sera modifié pour correspondre à la portion de texte. Cette propriété représente la valeur originale de l'hyperlien.
