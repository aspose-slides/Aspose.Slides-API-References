## TextAlignment énumération

Représente différents styles d'alignement de texte.

Le type TextAlignment expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| NOT_DEFINED | Alignement par défaut. |
| LEFT | Alignement à gauche. |
| CENTER | Alignement centré. |
| RIGHT | Alignement à droite. |
| JUSTIFY | Alignement justifié. |
| JUSTIFY_LOW | Justification Kashida basse. |
| DISTRIBUTED | Alignement distribué. |
