## Énumération PersistenceType

Spécifie la méthode utilisée pour stocker les propriétés du contrôle ActiveX.

Le type PersistenceType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| NOT_DEFINED | Identifiant de persistance non spécifié. |
| PERSIST_PROPERTY_BAG | Spécifie que le contrôle ActiveX est persistant en utilisant une persistance basée sur un sac de propriétés.<br/>             La persistance basée sur un sac de propriétés stocke un contrôle ActiveX au moyen d’une collection de paires nom et valeur qui spécifient les données persistes par le contrôle ActiveX. |
| PERSIST_STREAM | Spécifie que le contrôle ActiveX est persistant en utilisant une persistance basée sur un flux qui ne prend pas en charge l'initialisation du contrôle ActiveX à un état par défaut. |
| PERSIST_STREAM_INIT | Spécifie que le contrôle ActiveX est persistant en utilisant une persistance basée sur un flux qui prend en charge l'initialisation du contrôle ActiveX à un état par défaut. |
| PERSIST_STORAGE | Spécifie que le contrôle ActiveX est persistant en utilisant une persistance basée sur le stockage. |
