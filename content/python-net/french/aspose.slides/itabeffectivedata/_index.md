## ITabEffectiveData classe

Objet immuable qui contient les propriétés d'arrêt de tabulation du texte effectif.

Le type ITabEffectiveData expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`position`](/slides/python-net/fr/aspose.slides/itabeffectivedata/position/) | Renvoie la position d'une tabulation.<br/>            L'affectation de cette propriété peut changer l'index de la tabulation dans la collection et invalider l'énumérateur.<br/>            Lecture-seule **float**. |
| [`alignment`](/slides/python-net/fr/aspose.slides/itabeffectivedata/alignment/) | Renvoie le style d'alignement d'une tabulation.<br/>            Lecture-seule [`TabAlignment`](/slides/python-net/fr/aspose.slides/tabalignment). |


### Remarques

Cette interface est utilisée comme partie de [`IParagraphFormatEffectiveData`](/slides/python-net/fr/aspose.slides/iparagraphformateffectivedata).
