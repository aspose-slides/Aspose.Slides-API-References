## PPImageFormat énumération

Formats d'image. Cette énumération remplace la classe `System.Drawing.Imaging.ImageFormat`. Elle est nécessaire pour la compatibilité COM.

Le type PPImageFormat expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| BMP | Obtient le format d'image bitmap (BMP). |
| EMF | Obtient le format d'image métafile amélioré (EMF). |
| EXIF | Obtient le format Exchangeable Image File (Exif). |
| GIF | Obtient le format d'image Graphics Interchange Format (GIF). |
| ICON | Obtient le format d'image icône Windows. |
| JPEG | Obtient le format d'image Joint Photographic Experts Group (JPEG). |
| MEMORY_BMP | Obtient le format d'un bitmap en mémoire. |
| PNG | Obtient le format d'image W3C Portable Network Graphics (PNG). |
| TIFF | Obtient le format d'image Tagged Image File Format (TIFF). |
| WMF | Obtient le format d'image métafile Windows (WMF). |
