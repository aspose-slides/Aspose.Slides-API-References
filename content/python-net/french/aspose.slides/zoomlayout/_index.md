## ZoomLayout énumération

Spécifie la mise en page de zoom du résumé.

Le type ZoomLayout expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| GRID_LAYOUT | Spécifie la disposition comme une mise en page en grille pour une liste d'objets. |
| FIXED_LAYOUT | Spécifie la disposition avec un positionnement Zoom défini par l'utilisateur. |
