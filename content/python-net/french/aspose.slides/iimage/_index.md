## IImage classe

Représente une image raster ou vectorielle.

Le type IImage expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`size`](/slides/python-net/fr/aspose.slides/iimage/size/) | Obtient la taille de l'image. |
| [`width`](/slides/python-net/fr/aspose.slides/iimage/width/) | Obtient la largeur de l'image en pixels. |
| [`height`](/slides/python-net/fr/aspose.slides/iimage/height/) | Obtient la hauteur de l'image en pixels. |

## Méthodes

| Méthode | Description |
| :- | :- |
| [`save(self, filename)`](/slides/python-net/fr/aspose.slides/iimage/save/#str) | Enregistre l'image dans un fichier. |
| [`save(self, filename, format)`](/slides/python-net/fr/aspose.slides/iimage/save/#str-imageformat) | Enregistre l'image dans un fichier au format spécifié. |
| [`save(self, stream, format)`](/slides/python-net/fr/aspose.slides/iimage/save/#iorawiobase-imageformat) | Enregistre l'image dans un flux au format spécifié. |
| [`save(self, filename, format, quality)`](/slides/python-net/fr/aspose.slides/iimage/save/#str-imageformat-int) | Enregistre l'image dans un fichier au format spécifié et avec la qualité spécifiée. |
| [`save(self, stream, format, quality)`](/slides/python-net/fr/aspose.slides/iimage/save/#iorawiobase-imageformat-int) | Enregistre l'image dans un flux au format spécifié et avec la qualité spécifiée. |


### Remarques

Cette interface fournit une abstraction commune pour gérer les images raster et vectorielles.
            Les implémentations peuvent varier en fonction du type d'image sous-jacent.
