## Column classe

Représente une colonne dans un tableau.

**Héritage:**[`Column`](/slides/python-net/fr/aspose.slides/column) → [`CellCollection`](/slides/python-net/fr/aspose.slides/cellcollection)

## Propriétés

| Propriété | Description |
| :- | :- |
| [`slide`](/slides/python-net/fr/aspose.slides/column/slide/) | Renvoie la diapositive parent d’une CellCollection.<br/>            Lecture seule [`IBaseSlide`](/slides/python-net/fr/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/fr/aspose.slides/column/presentation/) | Renvoie la présentation parent d’une CellCollection.<br/>            Lecture seule [`IPresentation`](/slides/python-net/fr/aspose.slides/ipresentation). |
