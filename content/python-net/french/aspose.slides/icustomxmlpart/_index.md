## ICustomXmlPart classe

Représente une partie xml personnalisée.

Le type ICustomXmlPart expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`xml_as_string`](/slides/python-net/fr/aspose.slides/icustomxmlpart/xml_as_string/) | Renvoie ou définit les données xml sous forme de chaîne UTF-8.<br/>            Lecture/écriture **str**.<br/>            la valeur est `None`.la valeur est vide ou les données xml sont invalides. |
| [`xml_data`](/slides/python-net/fr/aspose.slides/icustomxmlpart/xml_data/) | Renvoie ou définit les données xml.<br/>            Lecture/écriture **int**[].<br/>            la valeur est `None`.la valeur est vide ou les données xml sont invalides. |
| [`item_id`](/slides/python-net/fr/aspose.slides/icustomxmlpart/item_id/) | Spécifie un identifiant unique global (GUID) qui identifie de façon unique une seule partie XML personnalisée <br/>            dans un document Office Open XML.<br/>            Lecture seule **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/fr/aspose.slides/icustomxmlpart/namespace_schemas/) | Renvoie la collection de schémas XML associés à la partie XML personnalisée.<br/>            Lecture seule **str**[]. |

| :- | :- |
