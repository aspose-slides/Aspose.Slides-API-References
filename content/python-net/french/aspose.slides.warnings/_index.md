Contient des classes qui représentent différents types d'avertissements
## Classes

| Classe | Description |
| :- | :- |
| [`IKnownIssueWarningInfo`](/slides/python-net/fr/aspose.slides.warnings/iknownissuewarninginfo/) | Représente un avertissement concernant un problème connu qui ne sera pas résolu dans un avenir proche. |
| [`INotImplementedWarningInfo`](/slides/python-net/fr/aspose.slides.warnings/inotimplementedwarninginfo/) | Représente un avertissement concernant une fonctionnalité connue non implémentée qui ne sera pas implémentée dans un avenir proche. |
| [`IObsoletePresLockingBehaviorWarningInfo`](/slides/python-net/fr/aspose.slides.warnings/iobsoletepreslockingbehaviorwarninginfo/) | Cet avertissement indique qu'un comportement d'enregistrement de présentation obsolète est utilisé. |
| [`IPresentationSignedWarningInfo`](/slides/python-net/fr/aspose.slides.warnings/ipresentationsignedwarninginfo/) | Cet avertissement indique que la présentation lue possède la signature <br/>            et que cette signature sera supprimée lors du traitement. |
| [`IWarningCallback`](/slides/python-net/fr/aspose.slides.warnings/iwarningcallback/) | Interface pour les classes qui reçoivent des avertissements. |
| [`IWarningInfo`](/slides/python-net/fr/aspose.slides.warnings/iwarninginfo/) | Représente une interface de base pour tous les avertissements. |
