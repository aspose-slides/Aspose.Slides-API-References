## IInkBrush classe

Représente le pinceau de trace.

Le type IInkBrush expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`color`](/slides/python-net/fr/aspose.slides.ink/iinkbrush/color/) | Obtient ou définit la couleur du pinceau pour une ligne. |
| [`size`](/slides/python-net/fr/aspose.slides.ink/iinkbrush/size/) | Obtient ou définit la taille du pinceau pour une ligne en points. |
| [`ink_effect`](/slides/python-net/fr/aspose.slides.ink/iinkbrush/ink_effect/) | Obtient le type d'effet d'encre (par ex., Galaxy, Gold, Silver) qui définit le style visuel du trait d'encre.<br/>            La valeur est analysée à partir de la propriété de pinceau "inkEffects". Si aucun effet reconnu n'est spécifié,<br/>            [`InkEffectType.NOT_DEFINED`](/slides/python-net/fr/aspose.slides.ink/inkeffecttype/NOT_DEFINED) est retourné. |
