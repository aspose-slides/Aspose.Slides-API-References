## ink_effect propriété
Obtient le type d'effet d'encre (e.g., Galaxy, Gold, Silver) qui définit le style visuel du trait d'encre.
            La valeur est analysée à partir de la brush propriété "inkEffects". Si aucun effet reconnu n'est spécifié,
            [`InkEffectType.NOT_DEFINED`](/slides/python-net/fr/aspose.slides.ink/inkeffecttype/NOT_DEFINED) est retourné.
