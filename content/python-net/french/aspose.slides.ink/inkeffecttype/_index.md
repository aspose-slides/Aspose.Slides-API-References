## InkEffectType énumération

Spécifie un ensemble d'effets visuels prédéfinis pour le rendu de l'encre.  
Chaque effet correspond à une texture ou une image qui simule une apparence d'encre stylisée.  
Ces valeurs peuvent être utilisées pour personnaliser le style visuel des traits d'encre numérique lors du rendu.

Le type InkEffectType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| NOT_DEFINED | L'effet n'est pas défini ou est inconnu. Cette valeur peut être utilisée comme valeur par défaut ou de secours. |
| BRONZE | Une texture métallique chaude, brunâtre, ressemblant à de l'encre bronze. |
| GALAXY | Une texture colorée et scintillante rappelant une galaxie, avec des tons cosmiques. |
| GOLD | Une texture métallique dorée brillante qui donne aux traits d'encre une apparence luxueuse. |
| LAVA | Une texture ardente rappelant de la lave en fusion, avec des teintes rouges et oranges. |
| OCEAN | Une texture bleue profonde, fluide, qui imite les vagues de l'océan ou l'encre à base d'eau. |
| RAINBOW_GLITTER | Un effet d'éclat arc-en-ciel coloré et scintillant utilisé pour des traits d'encre festifs ou vibrants. |
| ROSE_GOLD | Un mélange doux de rose et d'or, similaire à l'or rose, pour des traits d'encre élégants. |
| SILVER | Une texture métallique argentée froide qui simule l'encre argent classique. |
