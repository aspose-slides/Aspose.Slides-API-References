## ink_effect propriété
Obtient le type d'effet d'encre (par ex., Galaxy, Gold, Silver) qui définit le style visuel du trait d'encre.
            La valeur est analysée à partir de la propriété brush "inkEffects". Si aucun effet reconnu n'est spécifié,
            [`InkEffectType.NOT_DEFINED`](/slides/python-net/fr/aspose.slides.ink/inkeffecttype/NOT_DEFINED) est retourné.
