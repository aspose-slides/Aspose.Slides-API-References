## Classe Timing

Représente le timing d'animation.

Le type Timing expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`accelerate`](/slides/python-net/fr/aspose.slides.animation/timing/accelerate/) | Décrit le pourcentage de l'effet d'accélération de durée.<br/>            Lecture/écriture **float**. |
| [`decelerate`](/slides/python-net/fr/aspose.slides.animation/timing/decelerate/) | Décrit le pourcentage de l'effet de décélération de durée.<br/>            Lecture/écriture **float**. |
| [`auto_reverse`](/slides/python-net/fr/aspose.slides.animation/timing/auto_reverse/) | Décrit si l'animation doit être jouée automatiquement en sens inverse après l'avoir lue en avant.<br/>            Lecture/écriture **bool**. |

| [`repeat_count`](/slides/python-net/fr/aspose.slides.animation/timing/repeat_count/) | Décrit le nombre de fois que l'effet doit se répéter.<br/>            Lecture/écriture **float**. |
| [`repeat_until_end_slide`](/slides/python-net/fr/aspose.slides.animation/timing/repeat_until_end_slide/) | Cet attribut indique si l'effet se répétera jusqu'à la fin de la diapositive.<br/>            Lecture/écriture **bool**. |

| [`rewind`](/slides/python-net/fr/aspose.slides.animation/timing/rewind/) | Cet attribut indique si l'effet reviendra en arrière lorsqu'il aura fini de jouer.<br/>            Lecture/écriture **bool**. |
| [`speed`](/slides/python-net/fr/aspose.slides.animation/timing/speed/) | Spécifie le pourcentage d'accélération (ou de ralentissement) du timing.<br/>            Lecture/écriture **float**. |
| [`trigger_delay_time`](/slides/python-net/fr/aspose.slides.animation/timing/trigger_delay_time/) | Décrit le temps de retard après le déclencheur.<br/>            Lecture/écriture **float**. |
| [`trigger_type`](/slides/python-net/fr/aspose.slides.animation/timing/trigger_type/) | Décrit le type de déclencheur.<br/>            Lecture/écriture [`EffectTriggerType`](/slides/python-net/fr/aspose.slides.animation/effecttriggertype). |
