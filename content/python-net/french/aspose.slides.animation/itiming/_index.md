## ITTiming classe

Représente le minutage de l'animation.

Le type ITTiming expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`accelerate`](/slides/python-net/fr/aspose.slides.animation/itiming/accelerate/) | Décrit le pourcentage de l'effet d'accélération de la durée.<br/>            Lecture/écriture **float**. |
| [`decelerate`](/slides/python-net/fr/aspose.slides.animation/itiming/decelerate/) | Décrit le pourcentage de l'effet de décélération de la durée.<br/>            Lecture/écriture **float**. |
| [`auto_reverse`](/slides/python-net/fr/aspose.slides.animation/itiming/auto_reverse/) | Décrit s'il faut lire automatiquement l'animation en sens inverse après<br/>            l'avoir lue dans le sens avant.<br/>            Lecture/écriture **bool**. |
| [`duration`](/slides/python-net/fr/aspose.slides.animation/itiming/duration/) | Décrit la durée de l'effet d'animation.<br/>            Lecture/écriture **float**. |
| [`repeat_count`](/slides/python-net/fr/aspose.slides.animation/itiming/repeat_count/) | Décrit le nombre de fois que l'effet doit être répété.<br/>            Lecture/écriture **float**. |
| [`repeat_until_end_slide`](/slides/python-net/fr/aspose.slides.animation/itiming/repeat_until_end_slide/) | Cet attribut indique si l'effet se répétera jusqu'à la fin de la diapositive.<br/>             Lecture/écriture **bool**. |
| [`repeat_until_next_click`](/slides/python-net/fr/aspose.slides.animation/itiming/repeat_until_next_click/) | Cet attribut indique si l'effet se répétera jusqu'au prochain clic.<br/>             Lecture/écriture **bool**. |
| [`repeat_duration`](/slides/python-net/fr/aspose.slides.animation/itiming/repeat_duration/) | Décrit le nombre de fois que l'effet doit être répété.<br/>            Lecture/écriture **float**. |
| [`restart`](/slides/python-net/fr/aspose.slides.animation/itiming/restart/) | Spécifie si un effet doit redémarrer après son achèvement.<br/>            Lecture/écriture [`EffectRestartType`](/slides/python-net/fr/aspose.slides.animation/effectrestarttype). |
| [`speed`](/slides/python-net/fr/aspose.slides.animation/itiming/speed/) | Spécifie le pourcentage d'accélération (ou de ralentissement) du minutage.<br/>            Lecture/écriture **float**. |
| [`trigger_delay_time`](/slides/python-net/fr/aspose.slides.animation/itiming/trigger_delay_time/) | Décrit le temps de retard après le déclencheur.<br/>            Lecture/écriture **float**. |
| [`trigger_type`](/slides/python-net/fr/aspose.slides.animation/itiming/trigger_type/) | Décrit le type de déclencheur.<br/>            Lecture/écriture [`EffectTriggerType`](/slides/python-net/fr/aspose.slides.animation/effecttriggertype). |
| [`rewind`](/slides/python-net/fr/aspose.slides.animation/itiming/rewind/) | Cet attribut indique si l'effet sera réenroulé une fois la lecture terminée.<br/>             Lecture/écriture **bool**. |
