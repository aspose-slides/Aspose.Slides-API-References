## EffectChartMinorGroupingType énumération

Représente le type d'un effet d'animation pour l'élément d'un graphique dans une série ou une catégorie.

Le type EffectChartMinorGroupingType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| BY_ELEMENT_IN_SERIES | Anime le graphique par élément dans la série |
| BY_ELEMENT_IN_CATEGORY | Anime le graphique par élément dans la catégorie |
