## BuildType énumération

Détermine comment le texte apparaît sur une forme pendant l'animation.

Le type BuildType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| AS_ONE_OBJECT | Avec la forme contenant. |
| ALL_PARAGRAPHS_AT_ONCE | Tous les paragraphes. |
| BY_LEVEL_PARAGRAPHS1 | Par groupes de paragraphes de profondeur 1. |
| BY_LEVEL_PARAGRAPHS2 | Par groupes de paragraphes de profondeur 2. |
| BY_LEVEL_PARAGRAPHS3 | Par groupes de paragraphes de profondeur 3. |
