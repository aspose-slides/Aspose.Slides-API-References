## PresentationContentAmountType énumération

Spécifie la quantité de contenu incluse dans la présentation générée, influençant à la fois le nombre de diapositives et le niveau de détail par diapositive.

## Champs

| Champ | Description |
| :- | :- |
| BRIEF | Contenu court et basique. |
| MEDIUM | Une quantité modérée de contenu. |
| DETAILED | L'option la plus détaillée avec un texte extensif. |
