## OrganizationChartLayoutType énumération

Représente le type de formatage des nœuds enfants dans un organigramme

Le type OrganizationChartLayoutType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| INITIAL | Type de mise en page initial |
| STANDART | Place les nœuds enfants horizontalement sous le nœud parent. |
| BOTH_HANGING | Place les nœuds enfants verticalement sous le nœud parent des deux côtés gauche et droit. |
| LEFT_HANGING | Place les nœuds enfants verticalement sous le nœud parent du côté gauche. |
| RIGHT_HANGING | Place les nœuds enfants verticalement sous le nœud parent du côté droit. |
