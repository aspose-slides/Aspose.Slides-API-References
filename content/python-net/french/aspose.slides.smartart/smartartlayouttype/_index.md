## Énumération SmartArtLayoutType

Représente le type de mise en page d'un diagramme SmartArt.

Le type SmartArtLayoutType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| ACCENT_PROCESS | À utiliser pour afficher une progression, une chronologie ou des étapes séquentielles dans une tâche, un processus ou un flux de travail. Fonctionne bien pour illustrer à la fois le texte de Niveau 1 et le texte de Niveau 2. |
| ACCENTED_PICTURE | À utiliser pour afficher une idée centrale, photographique, avec des idées connexes sur le côté. Le texte de Niveau 1 supérieur apparaît au-dessus de l'image centrale. Le texte correspondant pour les autres formes de Niveau 1 apparaît à côté des petites images circulaires. Cette mise en page fonctionne également bien sans texte. |
| ALTERNATING_FLOW | À utiliser pour afficher des groupes d'informations ou des étapes séquentielles dans une tâche, un processus ou un flux de travail. Met l'accent sur l'interaction ou les relations entre les groupes d'informations. |
| ALTERNATING_HEXAGONS | À utiliser pour représenter une série d'idées interconnectées. Le texte de Niveau 1 apparaît à l'intérieur des hexagones. Le texte de Niveau 2 apparaît à l'extérieur des formes. |
| ALTERNATING_PICTURE_BLOCKS | À utiliser pour afficher une série d'images de haut en bas. Le texte apparaît alternativement à droite ou à gauche de l'image. |
| ALTERNATING_PICTURE_CIRCLES | À utiliser pour afficher un ensemble d'images avec du texte. Le texte correspondant apparaît dans les cercles centraux avec les images qui alternent de gauche à droite. |
| ARROW_RIBBON | À utiliser pour afficher des concepts liés ou contrastés avec une certaine connexion, comme des forces opposées. Les deux premières lignes du texte de Niveau 1 sont utilisées pour le texte dans les flèches. Le texte non utilisé n'apparaît pas, mais reste disponible si vous changez de mise en page. |
| ASCENDING_PICTURE_ACCENT_PROCESS | À utiliser pour afficher une série ascendante d'images avec un texte descriptif. Fonctionne mieux avec une petite quantité de texte. |
| BALANCE | À utiliser pour comparer ou montrer la relation entre deux idées. Chacune des deux premières lignes du texte de Niveau 1 correspond à du texte en haut d'un côté du point central. Met l'accent sur le texte de Niveau 2, limité à quatre formes de chaque côté du point central. L'équilibre penche du côté contenant le plus de formes avec du texte de Niveau 2. Le texte non utilisé n'apparaît pas, mais reste disponible si vous changez de mise en page. |
| BASIC_BENDING_PROCESS | À utiliser pour afficher une progression ou des étapes séquentielles dans une tâche, un processus ou un flux de travail. Optimise l'espace d'affichage horizontal et vertical des formes. |
| BASIC_BLOCK_LIST | À utiliser pour afficher des blocs d'informations non séquentiels ou groupés. Optimise l'espace d'affichage horizontal et vertical des formes. |
| BASIC_CHEVRON_PROCESS | À utiliser pour afficher une progression ; une chronologie ; des étapes séquentielles dans une tâche, un processus ou un flux de travail ; ou pour souligner un mouvement ou une direction. Le texte de Niveau 1 apparaît à l'intérieur d'une forme de flèche tandis que le texte de Niveau 2 apparaît sous les formes de flèche. |
| BASIC_CYCLE | À utiliser pour représenter une séquence continue d'étapes, de tâches ou d'événements dans un flux circulaire. Met l'accent sur les étapes ou les phases plutôt que sur les flèches ou le flux de connexion. Fonctionne mieux avec uniquement le texte de Niveau 1. |
| BASIC_MATRIX | À utiliser pour montrer la relation des composants à un tout dans des quadrants. Les quatre premières lignes du texte de Niveau 1 apparaissent dans les quadrants. Le texte non utilisé n'apparaît pas, mais reste disponible si vous changez de mise en page. |
| BASIC_PIE | À utiliser pour montrer comment des parties individuelles forment un tout. Les sept premières lignes du texte de Niveau 1 correspondent aux parts ou tranches de tarte uniformément réparties. La forme du texte de Niveau 1 supérieure apparaît à l'extérieur du reste de la tarte pour souligner. Le texte non utilisé n'apparaît pas, mais reste disponible si vous changez de mise en page. |
| BASIC_PROCESS | À utiliser pour afficher une progression ou des étapes séquentielles dans une tâche, un processus ou un flux de travail. |
| BASIC_PYRAMID | À utiliser pour afficher des relations proportionnelles, interconnectées ou hiérarchiques avec le composant le plus grand en bas et qui rétrécit vers le haut. Le texte de Niveau 1 apparaît dans les segments de la pyramide et le texte de Niveau 2 apparaît dans des formes à côté de chaque segment. |
| BASIC_RADIAL | À utiliser pour montrer la relation à une idée centrale dans un cycle. La première ligne du texte de Niveau 1 correspond à la forme centrale, et son texte de Niveau 2 correspond aux formes circulaires environnantes. Le texte non utilisé n'apparaît pas, mais reste disponible si vous changez de mise en page. |
| BASIC_TARGET | À utiliser pour afficher le contenu, les gradations ou les relations hiérarchiques. Les cinq premières lignes du texte de Niveau 1 sont associées à un cercle. Le texte non utilisé n'apparaît pas, mais reste disponible si vous changez de mise en page. |
| BASIC_TIMELINE | À utiliser pour afficher des étapes séquentielles dans une tâche, un processus ou un flux de travail, ou pour afficher des informations chronologiques. Fonctionne bien avec le texte de Niveau 1 et de Niveau 2. |
| BASIC_VENN | À utiliser pour afficher des relations qui se chevauchent ou sont interconnectées. Les sept premières lignes du texte de Niveau 1 correspondent à un cercle. Si le texte de Niveau 1 comporte quatre lignes ou moins, le texte se trouve à l'intérieur des cercles. S'il comporte plus de quatre lignes, le texte se trouve à l'extérieur des cercles. Le texte non utilisé n'apparaît pas, mais reste disponible si vous changez de mise en page. |
| BENDING_PICTURE_ACCENT_LIST | À utiliser pour afficher des blocs d'informations non séquentiels ou groupés. Les petites formes circulaires sont conçues pour contenir des images. Fonctionne bien pour illustrer le texte de Niveau 1 et de Niveau 2. Optimise l'espace d'affichage horizontal et vertical des formes. |
| BENDING_PICTURE_BLOCKS | À utiliser pour afficher une série d'images. Le cadre couvrant le coin inférieur peut contenir de petites quantités de texte. |
| BENDING_PICTURE_CAPTION | À utiliser pour afficher une série séquentielle d'images. Le cadre couvrant le coin inférieur peut contenir de petites quantités de texte. |
| BENDING_PICTURE_CAPTION_LIST | À utiliser pour afficher une série d'images. Le titre et la description apparaissent dans une forme d'appel sous chaque image. |
| BENDING_PICTURE_SEMI_TRANSPARENT_TEXT | À utiliser pour afficher une série d'images. Un cadre semi-transparent couvre la partie inférieure de l'image et contient tous les niveaux de texte. |
| BLOCK_CYCLE | À utiliser pour représenter une séquence continue d'étapes, de tâches ou d'événements dans un flux circulaire. Met l'accent sur les étapes ou les phases plutôt que sur les flèches ou le flux de connexion. |
| BUBBLE_PICTURE_LIST | À utiliser pour afficher une série d'images. Peut contenir jusqu'à huit images de Niveau 1. Le texte et les images non utilisés n'apparaissent pas, mais restent disponibles si vous changez de mise en page. Fonctionne mieux avec de petites quantités de texte. |
| CAPTIONED_PICTURES | À utiliser pour afficher des images avec plusieurs niveaux de texte. Fonctionne mieux avec une petite quantité de texte de Niveau 1 et une quantité moyenne de texte de Niveau 2. |
| CHEVRON_LIST | À utiliser pour afficher une progression à travers plusieurs processus constituant un flux de travail global. Fonctionne également pour illustrer des processus contrastés. Le texte de Niveau 1 correspond à la première forme de flèche à gauche, tandis que le texte de Niveau 2 correspond aux sous-étapes horizontales pour chaque forme contenant du texte de Niveau 1. |
| CIRCLE_ACCENT_TIMELINE | À utiliser pour afficher une série d'événements ou des informations chronologiques. Le texte de Niveau 1 apparaît à côté de formes circulaires plus grandes. Le texte de Niveau 2 apparaît à côté de formes circulaires plus petites. |
| CIRCLE_ARROW_PROCESS | À utiliser pour afficher des éléments séquentiels avec du texte d'accompagnement pour chaque élément. Ce diagramme fonctionne mieux avec de petites quantités de texte de Niveau 1. |
| CIRCLE_PICTURE_HIERARCHY | À utiliser pour afficher des informations hiérarchiques ou des relations de reporting dans une organisation. Les images apparaissent dans des cercles et le texte correspondant apparaît à côté des images. |
| CIRCLE_RELATIONSHIP | À utiliser pour montrer la relation à ou depuis une idée centrale. Le texte de Niveau 2 est ajouté de façon non séquentielle et est limité à cinq éléments. Il ne peut y avoir qu'un seul élément de Niveau 1. |
| CIRCULAR_BENDING_PROCESS | À utiliser pour afficher une séquence ou des étapes longues ou non linéaires dans une tâche, un processus ou un flux de travail. Fonctionne mieux avec uniquement le texte de Niveau 1. Optimise l'espace d'affichage horizontal et vertical des formes. |
| CIRCULAR_PICTURE_CALLOUT | À utiliser pour afficher une idée centrale et des sous-idées ou éléments associés. Le texte de la première image couvre la partie inférieure de l'image. Le texte correspondant pour les autres formes de Niveau 1 apparaît à côté des petites images circulaires. Ce diagramme fonctionne également bien sans texte. |
| CLOSED_CHEVRON_PROCESS | À utiliser pour afficher une progression, une chronologie ou des étapes séquentielles dans une tâche, un processus ou un flux de travail, ou pour souligner un mouvement ou une direction. Peut être utilisé pour mettre en avant les informations dans la forme de départ. Fonctionne mieux avec uniquement le texte de Niveau 1. |
| CONTINUOUS_ARROW_PROCESS | À utiliser pour afficher une chronologie ou des étapes séquentielles dans une tâche, un processus ou un flux de travail. Fonctionne mieux avec le texte de Niveau 1 car chaque ligne du texte de Niveau 1 apparaît à l'intérieur de la forme de flèche. Le texte de Niveau 2 apparaît à l'extérieur de la forme de flèche. |
| CONTINUOUS_BLOCK_PROCESS | À utiliser pour afficher une progression ou des étapes séquentielles dans une tâche, un processus ou un flux de travail. Fonctionne mieux avec un texte minimal de Niveau 1 et Niveau 2. |
| CONTINUOUS_CYCLE | À utiliser pour représenter une séquence continue d'étapes, de tâches ou d'événements dans un flux circulaire. Met l'accent sur la connexion entre tous les composants. Fonctionne mieux avec uniquement le texte de Niveau 1. |
| CONTINUOUS_PICTURE_LIST | À utiliser pour afficher des groupes d'informations interconnectées. Les formes circulaires sont conçues pour contenir des images. |
| CONVERGING_ARROWS | À utiliser pour afficher des idées ou concepts qui convergent vers un point central. Fonctionne mieux avec uniquement le texte de Niveau 1. |
| CONVERGING_RADIAL | À utiliser pour afficher les relations de concepts ou de composants à une idée centrale dans un cycle. La première ligne du texte de Niveau 1 correspond à la forme circulaire centrale et les lignes du texte de Niveau 2 correspondent aux formes rectangulaires environnantes. Le texte non utilisé n'apparaît pas, mais reste disponible si vous changez de mise en page. |
| COUNTERBALANCE_ARROWS | À utiliser pour afficher deux idées ou concepts opposés. Chacune des deux premières lignes du texte de Niveau 1 correspond à une flèche et fonctionne bien avec le texte de Niveau 2. Le texte non utilisé n'apparaît pas, mais reste disponible si vous changez de mise en page. |
| CYCLE_MATRIX | À utiliser pour afficher la relation à une idée centrale dans une progression cyclique. Chacune des quatre premières lignes du texte de Niveau 1 correspond à une part ou tranche de tarte, et le texte de Niveau 2 apparaît dans une forme rectangulaire à côté de la part ou tranche. Le texte non utilisé n'apparaît pas, mais reste disponible si vous changez de mise en page. |
| DESCENDING_BLOCK_LIST | À utiliser pour afficher des groupes d'idées liées ou des listes d'informations. Les formes de texte diminuent en hauteur de façon séquentielle, et le texte de Niveau 1 s'affiche verticalement. |
| DESCENDING_PROCESS | À utiliser pour afficher une série descendante d'événements. Le premier texte de Niveau 1 se trouve en haut de la flèche, et le dernier texte de Niveau 1 s'affiche en bas de la flèche. Seuls les sept premiers éléments de Niveau 1 apparaissent. Fonctionne mieux avec de petites à moyennes quantités de texte. |
| DETAILED_PROCESS | À utiliser avec de grandes quantités de texte de Niveau 2 pour afficher une progression à travers les étapes. |
| DIVERGING_ARROWS | À utiliser pour afficher des idées ou concepts qui progressent vers l'extérieur depuis une source centrale. Fonctionne mieux avec uniquement le texte de Niveau 1. |
| DIVERGING_RADIAL | À utiliser pour afficher les relations à une idée centrale dans un cycle. La première ligne du texte de Niveau 1 correspond à la forme circulaire centrale. Met l'accent sur les cercles environnants plutôt que sur l'idée centrale. Le texte non utilisé n'apparaît pas, mais reste disponible si vous changez de mise en page. |
| EQUATION | À utiliser pour afficher des étapes ou tâches séquentielles illustrant un plan ou un résultat. La dernière ligne du texte de Niveau 1 apparaît après le signe égal (=). Fonctionne mieux avec uniquement le texte de Niveau 1. |
| FRAMED_TEXT_PICTURE | À utiliser pour afficher des images avec le texte de Niveau 1 correspondant affiché dans un cadre. |
| FUNNEL | À utiliser pour montrer le filtrage d'informations ou comment des parties se combinent en un tout. Met l'accent sur le résultat final. Peut contenir jusqu'à quatre lignes de texte de Niveau 1 ; la dernière de ces quatre lignes de texte de Niveau 1 apparaît sous l'entonnoir et les autres lignes correspondent à une forme circulaire. Le texte non utilisé n'apparaît pas, mais reste disponible si vous changez de mise en page. |
| GEAR | À utiliser pour afficher des idées emboîtées. Chacune des trois premières lignes du texte de Niveau 1 correspond à une forme d'engrenage, et le texte de Niveau 2 correspondant apparaît dans des rectangles à côté de la forme d'engrenage. Le texte non utilisé n'apparaît pas, mais reste disponible si vous changez de mise en page.
| GRID_MATRIX | Utilisez-le pour montrer le placement des concepts le long de deux axes. Met l’accent sur les composants individuels plutôt que sur l’ensemble. Les quatre premières lignes du texte de Niveau 1 apparaissent dans les quadrants. Le texte inutilisé n’apparaît pas, mais reste disponible si vous changez de mise en page. |
| GROUPED_LIST | Utilisez-le pour montrer des groupes et sous-groupes d’informations, ou des étapes et sous-étapes dans une tâche, un processus ou un flux de travail. Le texte de Niveau 1 correspond aux formes horizontales de niveau supérieur, et le texte de Niveau 2 correspond aux sous-étapes verticales sous chaque forme de niveau supérieur associée. Convient bien pour mettre en avant les sous-groupes ou sous-étapes, les informations hiérarchiques ou plusieurs listes d’informations. |
| HALF_CIRCLE_ORGANIZATION_CHART | Utilisez-le pour afficher des informations hiérarchiques ou des relations de reporting dans une organisation. Les formes d’assistant et les mises en page suspendues d’organigramme sont disponibles avec cette disposition. |
| HEXAGON_CLUSTER | Utilisez-le pour montrer des images avec du texte descriptif associé. De petits hexagones indiquent la paire image-texte. Fonctionne mieux avec de petites quantités de texte. |
| HIERARCHY | Utilisez-le pour afficher des relations hiérarchiques du haut vers le bas. |
| HIERARCHY_LIST | Utilisez-le pour afficher des relations hiérarchiques à travers des groupes. Peut également être utilisé pour regrouper ou lister des informations. |
| HORIZONTAL_BULLET_LIST | Utilisez-le pour afficher des listes d’informations non séquentielles ou groupées. Fonctionne bien avec de grandes quantités de texte. Tout le texte a le même niveau d’accentuation et aucune direction n’est implicite. |
| HORIZONTAL_HIERARCHY | Utilisez-le pour afficher des relations hiérarchiques évoluant horizontalement. Convient bien aux arbres de décision. |
| HORIZONTAL_LABELED_HIERARCHY | Utilisez-le pour afficher des relations hiérarchiques évoluant horizontalement et groupées hiérarchiquement. Met l’accent sur le titre ou le texte de Niveau 1. La première ligne du texte de Niveau 1 apparaît dans la forme au début de la hiérarchie, et la deuxième ainsi que toutes les lignes suivantes du texte de Niveau 1 apparaissent en haut des grands rectangles. |
| HORIZONTAL_MULTI_LEVEL_HIERARCHY | Utilisez-le pour afficher de grandes quantités d’informations hiérarchiques évoluant horizontalement. Le sommet de la hiérarchie est affiché verticalement. Cette disposition prend en charge de nombreux niveaux dans la hiérarchie. |
| HORIZONTAL_ORGANIZATION_CHART | Utilisez-le pour afficher des informations hiérarchiques horizontalement ou des relations de reporting dans une organisation. La forme d’assistant et les mises en page suspendues d’organigramme sont disponibles avec cette disposition. |
| HORIZONTAL_PICTURE_LIST | Utilisez-le pour afficher des informations non séquentielles ou groupées en mettant l’accent sur des images associées. Les formes supérieures sont conçues pour contenir des images. |
| INCREASING_ARROWS_PROCESS | Utilisez-le pour montrer des étapes séquentielles et qui se chevauchent dans un processus. Limité à cinq éléments de Niveau 1. Le Niveau 2 peut contenir de grandes quantités de texte. |
| INCREASING_CIRCLE_PROCESS | Utilisez-le pour afficher une série d’étapes, le centre du cercle augmentant à chaque étape. Limité à sept étapes de Niveau 1 mais un nombre illimité d’éléments de Niveau 2. Fonctionne bien avec de grandes quantités de texte de Niveau 2. |
| INVERTED_PYRAMID | Utilisez-le pour afficher des relations proportionnelles, interconnectées ou hiérarchiques avec le composant le plus grand en haut et qui se rétrécit. Le texte de Niveau 1 apparaît dans les segments de la pyramide et le texte de Niveau 2 apparaît dans les formes à côté de chaque segment. |
| LABELED_HIERARCHY | Utilisez-le pour afficher des relations hiérarchiques du haut vers le bas et groupées hiérarchiquement. Met l’accent sur le titre ou le texte de Niveau 1. La première ligne du texte de Niveau 1 apparaît dans la forme au début de la hiérarchie, et toutes les lignes suivantes du texte de Niveau 1 apparaissent à gauche des longs rectangles. |
| LINEAR_VENN | Utilisez-le pour montrer des relations qui se chevauchent dans une séquence. Fonctionne mieux avec uniquement du texte de Niveau 1. |
| LINED_LIST | Utilisez-le pour afficher de grandes quantités de texte divisées en catégories et sous-catégories. Convient bien à plusieurs niveaux de texte. Le texte au même niveau est séparé par des lignes. |
| MULTIDIRECTIONAL_CYCLE | Utilisez-le pour représenter une séquence continue d’étapes, de tâches ou d’événements pouvant se dérouler dans n’importe quelle direction. |
| NAMEAND_TITLE_ORGANIZATION_CHART | Utilisez-le pour afficher des informations hiérarchiques ou des relations de reporting dans une organisation. Pour saisir du texte dans la zone de titre, tapez directement dans la petite forme rectangulaire. La forme d’assistant et les mises en page suspendues d’organigramme sont disponibles avec cette disposition. |
| NESTED_TARGET | Utilisez-le pour afficher des relations de contenance. Chacune des trois premières lignes du texte de Niveau 1 correspond au texte en haut à gauche des formes, et le texte de Niveau 2 correspond aux petites formes. Fonctionne mieux avec un nombre minimal de lignes de Niveau 2. Le texte inutilisé n’apparaît pas, mais reste disponible si vous changez de mise en page. |
| NONDIRECTIONAL_CYCLE | Utilisez-le pour représenter une séquence continue d’étapes, de tâches ou d’événements dans un flux circulaire. Chaque forme a le même niveau d’importance. Convient bien lorsque la direction n’a pas besoin d’être indiquée. |
| OPPOSING_ARROWS | Utilisez-le pour montrer deux idées opposées, ou des idées qui divergent d’un point central. Chacune des deux premières lignes du texte de Niveau 1 correspond à une flèche. Le texte inutilisé n’apparaît pas, mais reste disponible si vous changez de mise en page. |
| OPPOSING_IDEAS | Utilisez-le pour montrer deux idées opposées ou contrastées. Peut contenir un ou deux éléments de Niveau 1. Chaque texte de Niveau 1 peut contenir plusieurs sous-niveaux. Fonctionne bien avec de grandes quantités de texte. |
| ORGANIZATION_CHART | Utilisez-le pour afficher des informations hiérarchiques ou des relations de reporting dans une organisation. La forme d’assistant et les mises en page suspendues d’organigramme sont disponibles avec cette disposition. |
| PHASED_PROCESS | Utilisez-le pour afficher trois phases d’un processus. Limité à trois éléments de Niveau 1. Fonctionne mieux avec de petites quantités de texte. |
| PICTURE_ACCENT_BLOCKS | Utilisez-le pour afficher un groupe d’images en blocs à partir du coin. Le texte correspondant s’affiche verticalement. Convient bien comme accent sur les diapositives de titre ou de sous-titre ou pour les séparations de sections d’un document. |
| PICTURE_ACCENT_LIST | Utilisez-le pour afficher des informations groupées ou liées. Les petites formes dans les coins supérieurs sont conçues pour contenir des images. | PICTURE_ACCENT_PROCESS | Utilisez-le pour afficher des étapes séquentielles dans une tâche, un processus ou un flux de travail. Les formes rectangulaires en arrière-plan sont conçues pour contenir des images. |
| PICTURE_CAPTION_LIST | Utilisez-le pour afficher des blocs d’informations non séquentiels ou groupés. Les formes supérieures sont conçues pour contenir des images et les images sont mises en avant par rapport au texte. Convient bien aux images avec de courtes légendes textuelles. |
| PICTURE_GRID | Utilisez-le pour afficher des images disposées sur une grille carrée. Idéal avec une petite quantité de texte de Niveau 1, qui apparaît au-dessus de l’image. |
| PICTURE_LINEUP | Utilisez-le pour afficher une série d’images côte à côte. Le texte de Niveau 1 couvre le haut de l’image. Le texte de Niveau 2 apparaît sous l’image. |

| PROCESS_ARROWS | Utilisez-le pour montrer des informations illustrant un processus ou un flux de travail. | PROCESS_LIST | Utilisez-le pour afficher plusieurs groupes d’informations ou d’étapes et sous-étapes dans une tâche, un processus ou un flux de travail. | PYRAMID_LIST | Utilisez-le pour afficher des relations proportionnelles, interconnectées ou hiérarchiques. Le texte apparaît dans les formes rectangulaires au-dessus de l’arrière-plan pyramidal. |
| RADIAL_CLUSTER | Utilisez-le pour afficher des données liées à une idée ou un thème central. Le texte de Niveau 1 principal apparaît au centre. Fonctionne mieux avec de petites quantités de texte. |
| RADIAL_CYCLE | Utilisez-le pour montrer la relation à une idée centrale. Met l’accent à la fois sur les informations du cercle central et sur la façon dont les informations du cercle extérieur contribuent à l’idée centrale. La première ligne du texte de Niveau 1 correspond au cercle central, et son texte de Niveau 2 correspond à l’anneau extérieur de cercles.
