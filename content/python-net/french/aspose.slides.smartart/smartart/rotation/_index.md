## propriété de rotation
Renvoie ou définit le nombre de degrés selon lesquels la forme spécifiée est pivotée autour de l'axe z. Une valeur positive indique une rotation horaire ; une valeur négative indique une rotation antihoraire.
Lecture/écriture **float**.

### Remarques

La valeur renvoyée est toujours définie (n'est pas float.NaN).
La valeur affectée doit être définie (pas float.NaN). Vous pouvez définir des valeurs indéfinies pour les propriétés d'instance de RawFrame.
