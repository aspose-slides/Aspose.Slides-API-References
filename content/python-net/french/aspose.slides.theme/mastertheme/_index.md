## MasterTheme classe

Représente un thème principal.

**Héritage:**[`MasterTheme`](/slides/python-net/fr/aspose.slides.theme/mastertheme) → [`Theme`](/slides/python-net/fr/aspose.slides.theme/theme)

Le type MasterTheme expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`color_scheme`](/slides/python-net/fr/aspose.slides.theme/mastertheme/color_scheme/) | Renvoie le jeu de couleurs.<br/>            Lecture seule [`IColorScheme`](/slides/python-net/fr/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/fr/aspose.slides.theme/mastertheme/font_scheme/) | Renvoie le jeu de polices.<br/>            Lecture seule [`IFontScheme`](/slides/python-net/fr/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/fr/aspose.slides.theme/mastertheme/format_scheme/) | Renvoie le jeu de formats de formes.<br/>            Lecture seule [`IFormatScheme`](/slides/python-net/fr/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/fr/aspose.slides.theme/mastertheme/presentation/) | Renvoie la présentation parente.<br/>            Lecture seule [`IPresentation`](/slides/python-net/fr/aspose.slides/ipresentation). |
| [`extra_color_schemes`](/slides/python-net/fr/aspose.slides.theme/mastertheme/extra_color_schemes/) | Renvoie la collection de jeux de couleurs supplémentaires.<br/>            Ces jeux n'affectent pas l'apparence de la présentation, ils peuvent être sélectionnés comme jeu de couleurs principal pour une diapositive.<br/>            Lecture seule [`IExtraColorSchemeCollection`](/slides/python-net/fr/aspose.slides.theme/iextracolorschemecollection). |
| [`name`](/slides/python-net/fr/aspose.slides.theme/mastertheme/name/) | Renvoie le nom d'un thème.<br/>            Lecture/écriture **str**. |
