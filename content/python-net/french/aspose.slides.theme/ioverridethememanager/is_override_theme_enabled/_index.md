## is_override_theme_enabled propriété
Détermine si OverrideTheme remplace le thème effectif hérité ou non.
            Pour activer OverrideTheme pour le remplacement, utilisez les méthodes OverrideTheme.Init*().
            Pour désactiver le remplacement par OverrideTheme, utilisez la méthode OverrideTheme.Clear().
            Lecture seule **bool**.
