Contient des classes et des méthodes pour gérer des opérations générales complexes de manière low code.
## Classes

| Classe | Description |
| :- | :- |
| [`Collect`](/slides/python-net/fr/aspose.slides.lowcode/collect/) | Représente un groupe de méthodes destiné à collecter des objets modèle de différents types depuis [`Presentation`](/slides/python-net/fr/aspose.slides/presentation). |
| [`Compress`](/slides/python-net/fr/aspose.slides.lowcode/compress/) | Représente un groupe de méthodes destiné à compresser [`Presentation`](/slides/python-net/fr/aspose.slides/presentation). |
| [`Convert`](/slides/python-net/fr/aspose.slides.lowcode/convert/) | Représente un groupe de méthodes destiné à convertir [`Presentation`](/slides/python-net/fr/aspose.slides/presentation). |
| [`ForEach`](/slides/python-net/fr/aspose.slides.lowcode/foreach/) | Représente un groupe de méthodes destiné à itérer sur différents objets modèle [`Presentation`](/slides/python-net/fr/aspose.slides/presentation).<br/>            Ces méthodes peuvent être utiles si vous devez itérer et modifier le formatage ou le contenu de certains éléments de Presentation,<br/>             par exemple modifier le formatage de chaque portion. |
| [`Merger`](/slides/python-net/fr/aspose.slides.lowcode/merger/) | Représente un groupe de méthodes pour fusionner des présentations PowerPoint du même format en un seul fichier. |
