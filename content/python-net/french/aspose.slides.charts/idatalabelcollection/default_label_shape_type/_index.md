## default_label_shape_type propriété
Obtient ou définit le type de forme par défaut pour les étiquettes de données.
             Renvoie [`ShapeType.NOT_DEFINED`](/slides/python-net/fr/aspose.slides/shapetype/NOT_DEFINED) si aucune forme n'est définie.


### Remarques

Définir cette propriété définit également la [`IDataLabel.label_shape_type`](/slides/python-net/fr/aspose.slides.charts/idatalabel/label_shape_type) propriété
             pour toutes les étiquettes de données de la collection à la même valeur.
