## value_type propriété
Représente les manières possibles de déterminer la longueur des barres d'erreur. 
            Dans le cas d'un type de valeur personnalisé, pour spécifier la valeur, utilisez la propriété [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/fr/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) du point de données spécifique dans la collection DataPoints de la série.
            Dans le cas des types de valeur Fixed, Percentage ou StandardDeviation, utilisez la propriété Value pour spécifier la valeur.  
            Lecture/écriture [`ErrorBarValueType`](/slides/python-net/fr/aspose.slides.charts/errorbarvaluetype).
