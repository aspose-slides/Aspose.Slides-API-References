## value propriété
Obtient ou définit value qui est utilisé avec les types de valeur Fixed, Percentage et StandardDeviation pour déterminer la longueur des barres d'erreur. 
Dans tout autre cas, renverra NaN. 
Lecture/écriture **float**.
