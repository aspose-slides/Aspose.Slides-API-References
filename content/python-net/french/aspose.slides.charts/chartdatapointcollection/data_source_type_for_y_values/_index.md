## data_source_type_for_y_values propriété
Spécifie si la propriété AsCell ou AsLiteralString ou AsLiteralDouble est réellement utilisée dans l’objet de propriété YValue des points de données. En d’autres termes, elle spécifie le type de valeur de la propriété Data de ChartDataPoint.YValue. Lecture/écriture [`DataSourceType`](/slides/python-net/fr/aspose.slides.charts/datasourcetype).
