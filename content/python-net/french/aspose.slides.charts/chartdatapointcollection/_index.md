## ChartDataPointCollection classe

Représente une collection d’un point de données de série.

Le type ChartDataPointCollection expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`data_source_type_for_x_values`](/slides/python-net/fr/aspose.slides.charts/chartdatapointcollection/data_source_type_for_x_values/) | Indique si la propriété AsCell ou AsLiteralString ou AsLiteralDouble <br/> est effectivement utilisée dans l’objet propriété XValue des points de données.
