## PieSplitType énumération

Représente un type de points de fractionnement dans le deuxième secteur ou barre sur un graphique secteur-dans-secteur ou barre-dans-secteur.

Le type PieSplitType expose les membres suivants :

## Fields

| Champ | Description |
| :- | :- |
| DEFAULT | Spécifie que les points de données doivent être divisés en utilisant le mécanisme par défaut <br/>            pour ce type de graphique. |
| CUSTOM | Spécifie que les points de données doivent être divisés entre le <br/>            secteur et le deuxième graphique selon les valeurs de division personnalisées. |
| BY_PERCENTAGE | Spécifie que les points de données doivent être divisés entre le secteur et le <br/>            deuxième graphique en plaçant les points dont le pourcentage est inférieur à <br/>            le pourcentage de position de division dans le deuxième graphique. |
| BY_POS | Spécifie que les points de données doivent être divisés entre le secteur et le <br/>            deuxième graphique en plaçant la dernière position de division des points de données <br/>            dans le deuxième graphique. |
| BY_VALUE | Spécifie que les points de données doivent être divisés entre le secteur et le <br/>            deuxième graphique en plaçant les points de données dont la valeur est inférieure à <br/>            la position de division dans le deuxième graphique. |
