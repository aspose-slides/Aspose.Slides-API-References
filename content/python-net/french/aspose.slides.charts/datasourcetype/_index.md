## DataSourceType énumération

Types de source de données.

Le type DataSourceType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| WORKSHEET | Utilisez les objets CellXls pour stocker XValue, YValue, Value ou BubbleSize du point de données dans la feuille de calcul. |
| STRING_LITERALS | Utilisez une variable de chaîne à accès rapide pour stocker XValue, YValue, Value ou BubbleSize du <br/>            point de données. La feuille de calcul N'EST PAS utilisée pour stocker les valeurs. |
| DOUBLE_LITERALS | Utilisez une variable double à accès rapide pour stocker XValue, YValue, Value ou BubbleSize du <br/>            point de données. La feuille de calcul N'EST PAS utilisée pour stocker les valeurs. |
