## DisplayUnitType énumération

Détermine la multiplicité des données affichées.

Le type DisplayUnitType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| NONE | Les valeurs seront affichées telles quelles. |
| HUNDREDS | Spécifie que les valeurs du graphique seront divisées par 100. |
| THOUSANDS | Spécifie que les valeurs du graphique seront divisées par 1,000. |
| TEN_THOUSANDS | Spécifie que les valeurs du graphique seront divisées par 10,000. |
| HUNDRED_THOUSANDS | Spécifie que les valeurs du graphique seront divisées par 100,000. |
| MILLIONS | Spécifie que les valeurs du graphique seront divisées par 1,000,000. |
| TEN_MILLIONS | Spécifie que les valeurs du graphique seront divisées par 10,000,000. |
| HUNDRED_MILLIONS | Spécifie que les valeurs du graphique seront divisées par 100,000,000. |
| BILLIONS | Spécifie que les valeurs du graphique seront divisées par 1,000,000,000. |
| TRILLIONS | Spécifie que les valeurs du graphique seront divisées par 1,000,000,000,000. |
| CUSTOM_VALUE | Spécifie que les valeurs du graphique seront divisées par une valeur personnalisée. |
