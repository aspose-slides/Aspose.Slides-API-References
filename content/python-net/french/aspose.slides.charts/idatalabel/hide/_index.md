## hide(self) {#}
Masquez l'étiquette de données en définissant tous les indicateurs Show*-flags (ShowValue, ...) à l'état false.
            IsVisible sera false après cela.


```python
def hide(self):
    ...
```


### Remarks

Si l'étiquette de données n'est pas visible (IsVisible est false) vous pouvez rendre l'étiquette de données visible avec 
            en définissant les indicateurs Show*-flags (ShowValue, ...) à l'état true.
