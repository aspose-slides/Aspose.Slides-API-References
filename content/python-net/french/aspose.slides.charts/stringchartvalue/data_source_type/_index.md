## data_source_type propriété
Specifie si AsCell, AsCells, AsLiteralString ou AsLiteralDouble 
            propriété est réellement présente dans les descendants. En d'autres termes, il spécifie le type 
            de valeur de la propriété Data.
            Lecture/écriture [`DataSourceType`](/slides/python-net/fr/aspose.slides.charts/datasourcetype).

### Remarques

Pour les points dans ChartDataPointCollection, cette propriété est en lecture seule. 
            Dans ce cas, pour modifier la valeur de cette propriété, vous pouvez utiliser l'une des 
            propriétés ChartDataPointCollection.DataSourceTypeFor<...>.
