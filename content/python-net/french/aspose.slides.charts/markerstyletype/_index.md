## MarkerStyleType énumération

Détermine la forme du marqueur sur le point de données du graphique.

Le type MarkerStyleType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| NOT_DEFINED |  |
| CIRCLE | Spécifie qu'un cercle doit être dessiné à chaque point de données. |
| DASH | Spécifie qu'un tiret doit être dessiné à chaque point de données. |
| DIAMOND | Spécifie qu'un diamant doit être dessiné à chaque point de données. |
| DOT | Spécifie qu'un point doit être dessiné à chaque point de données. |
| NONE | Spécifie qu'aucun élément ne doit être dessiné à chaque point de données. |
| PICTURE | Spécifie qu'une image doit être dessinée à chaque point de données. |
| PLUS | Spécifie qu'un signe plus doit être dessiné à chaque point de données. |
| SQUARE | Spécifie qu'un carré doit être dessiné à chaque point de données. |
| STAR | Spécifie qu'une étoile doit être dessinée à chaque point de données. |
| TRIANGLE | Spécifie qu'un triangle doit être dessiné à chaque point de données. |
| X | Spécifie qu'un X doit être dessiné à chaque point de données. |
