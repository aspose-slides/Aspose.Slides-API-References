## Énumération ChartShapeType

Représente une forme de graphique.

Le type ChartShapeType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| NOT_DEFINED | La forme du graphique n'est pas définie. |
| BOX | Spécifie que le graphique doit être dessiné avec une forme de boîte. |
| CONE | Spécifie que le graphique doit être dessiné sous forme de cône, avec la base du cône au sol et le sommet du cône en haut du marqueur de données. |
| CONE_TO_MAX | Spécifie que le graphique doit être dessiné avec des cônes tronqués de façon que le sommet du cône corresponde à la valeur maximale des données. |
| CYLINDER | Spécifie que le graphique doit être dessiné sous forme de cylindre. |
| PYRAMID | Spécifie que le graphique doit être dessiné sous forme de pyramide rectangulaire, avec la base de la pyramide au sol et le sommet de la pyramide en haut du marqueur de données. |
| PYRAMID_TO_MAXIMUM | Spécifie que le graphique doit être dessiné avec des cônes tronqués de façon que le sommet du cône corresponde à la valeur maximale des données. |
