## hide(self) {#}
Masquez l'étiquette de données par défaut en définissant tous les indicateurs Show*-flags (ShowValue, ...) de la 
            propriété DefaultDataLabelFormat sur l'état false.
            IsVisible sera false après cela.


```python
def hide(self):
    ...
```


### Remarques

Si l'étiquette de données n'est pas visible par défaut (IsVisible est false) vous pouvez rendre l'étiquette de données "visible 
            par défaut" en définissant les indicateurs Show*-flags (ShowValue, ...) de la propriété DefaultDataLabelFormat
            sur l'état true.
