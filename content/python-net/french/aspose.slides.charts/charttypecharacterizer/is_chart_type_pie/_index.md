## is_chart_type_pie(chart_type) {#charttype}
Renvoie true si chartType est l'un des sous-types de Pie.
            L'ensemble des sous-types correspond à l'ensemble approprié dans PowerPoint (voir la boîte de dialogue \"Change Chart Type\" dans PowerPoint) :
            [`ChartType.BAR_OF_PIE`](/slides/python-net/fr/aspose.slides.charts/charttype/BAR_OF_PIE),
            [`ChartType.EXPLODED_PIE`](/slides/python-net/fr/aspose.slides.charts/charttype/EXPLODED_PIE),
            [`ChartType.EXPLODED_PIE_3D`](/slides/python-net/fr/aspose.slides.charts/charttype/EXPLODED_PIE_3D),
            [`ChartType.PIE`](/slides/python-net/fr/aspose.slides.charts/charttype/PIE),
            [`ChartType.PIE_3D`](/slides/python-net/fr/aspose.slides.charts/charttype/PIE_3D),
            [`ChartType.PIE_OF_PIE`](/slides/python-net/fr/aspose.slides.charts/charttype/PIE_OF_PIE).
