## IErrorBarsCustomValues class

Spécifie les valeurs des barres d'erreur. Elle ne doit être utilisée que lorsque le Error bars value type est Custom.

Le type IErrorBarsCustomValues expose les membres suivants :

## Properties

| :- | :- |
