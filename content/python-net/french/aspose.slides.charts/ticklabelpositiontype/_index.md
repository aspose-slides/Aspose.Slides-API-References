## TickLabelPositionType énumération

Représente le type de position des libellés des graduations sur l'axe spécifié.

Le type TickLabelPositionType expose les membres suivants:

## Champs

| Champ | Description |
| :- | :- |
| HIGH | Spécifie que les libellés de l'axe doivent être à l'extrémité haute de l'axe perpendiculaire. |
| LOW | Spécifie que les libellés de l'axe doivent être à l'extrémité basse de l'axe perpendiculaire. |
| NEXT_TO | Spécifie que les libellés de l'axe doivent être à côté de l'axe. |
| NONE | Spécifie que les libellés de l'axe ne sont pas dessinés. |
