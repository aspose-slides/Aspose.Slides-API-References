## ErrorBarsCustomValues classe

Spécifie les valeurs des barres d'erreur. Elle doit être utilisée uniquement lorsque le type de valeur des barres d'erreur est Custom.

Le type ErrorBarsCustomValues expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`x_minus`](/slides/python-net/fr/aspose.slides.charts/errorbarscustomvalues/x_minus/) | Spécifie la valeur de la barre d'erreur dans la direction négative. <br/>            Disponible si le type de valeur des barres d'erreur est Custom et que ErrorBarsXFormat est autorisé.<br/>            Dans tout autre cas, cette propriété renvoie None.<br/>            Lecture seule [`IDoubleChartValue`](/slides/python-net/fr/aspose.slides.charts/idoublechartvalue). |
| [`y_minus`](/slides/python-net/fr/aspose.slides.charts/errorbarscustomvalues/y_minus/) | Spécifie la valeur de la barre d'erreur dans la direction négative. <br/>            Disponible si le type de valeur des barres d'erreur est Custom et que ErrorBarsYFormat est autorisé.<br/>            Dans tout autre cas, cette propriété renvoie None.<br/>            Lecture seule [`IDoubleChartValue`](/slides/python-net/fr/aspose.slides.charts/idoublechartvalue). |
| [`x_plus`](/slides/python-net/fr/aspose.slides.charts/errorbarscustomvalues/x_plus/) | Spécifie la valeur de la barre d'erreur dans la direction positive. <br/>            Disponible si le type de valeur des barres d'erreur est Custom et que ErrorBarsXFormat est autorisé.<br/>            Dans tout autre cas, cette propriété renvoie None.<br/>            Lecture seule [`IDoubleChartValue`](/slides/python-net/fr/aspose.slides.charts/idoublechartvalue). |
| [`y_plus`](/slides/python-net/fr/aspose.slides.charts/errorbarscustomvalues/y_plus/) | Spécifie la valeur de la barre d'erreur dans la direction positive. <br/>            Disponible si le type de valeur des barres d'erreur est Custom et que ErrorBarsYFormat est autorisé.<br/>            Dans tout autre cas, cette propriété renvoie None.<br/>            Lecture seule [`IDoubleChartValue`](/slides/python-net/fr/aspose.slides.charts/idoublechartvalue). |
