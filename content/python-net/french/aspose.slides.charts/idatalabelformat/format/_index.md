## propriété format
Représente le format de l'étiquette de données.
            Lecture seule [`IFormat`](/slides/python-net/fr/aspose.slides.charts/iformat).

### Remarques

Si le parent de cet objet DataLabelFormat est une collection DataLabelCollection d'étiquettes de données alors cet
            propriété représente le format par défaut pour les nouvelles étiquettes de données dans la collection DataLabelCollection.
