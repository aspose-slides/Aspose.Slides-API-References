## IChartDataPointCollection classe

Représente une collection de points de données d’une série.

Le type IChartDataPointCollection expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`data_source_type_for_x_values`](/slides/python-net/fr/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_x_values/) | Spécifie si la propriété AsCell ou AsLiteralString ou AsLiteralDouble est réellement utilisée dans l’objet de propriété XValue des points de données. En d’autres termes, elle spécifie le type de valeur de la propriété ChartDataPointEx.XValue.Data.<br/>            Lecture/écriture [`DataSourceType`](/slides/python-net/fr/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_y_values`](/slides/python-net/fr/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_y_values/) | Spécifie si la propriété AsCell ou AsLiteralString ou AsLiteralDouble est réellement utilisée dans l’objet de propriété YValue des points de données. En d’autres termes, elle spécifie le type de valeur de la propriété ChartDataPointEx.YValue.Data.<br/>            Lecture/écriture [`DataSourceType`](/slides/python-net/fr/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_bubble_sizes`](/slides/python-net/fr/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_bubble_sizes/) | Spécifie si la propriété AsCell ou AsLiteralString ou AsLiteralDouble est réellement utilisée dans l’objet de propriété BubbleSize des points de données. En d’autres termes, elle spécifie le type de valeur de la propriété ChartDataPointEx.BubbleSize.Data.<br/>            Lecture/écriture [`DataSourceType`](/slides/python-net/fr/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_values`](/slides/python-net/fr/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_values/) | Spécifie si la propriété AsCell ou AsLiteralString ou AsLiteralDouble est réellement utilisée dans l’objet de propriété Value des points de données. En d’autres termes, elle spécifie le type de valeur de la propriété ChartDataPoint.Value.Data.<br/>            Lecture/écriture [`DataSourceType`](/slides/python-net/fr/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_error_bars_custom_values`](/slides/python-net/fr/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_error_bars_custom_values/) | Spécifie le type de valeurs dans la liste de propriétés ChartDataPoint.ErrorBarsCustomValues.<br/>            Lecture-seule [`IDataSourceTypeForErrorBarsCustomValues`](/slides/python-net/fr/aspose.slides.charts/idatasourcetypeforerrorbarscustomvalues). |

Renvoie le point de données de la série par index (son numéro de série dans cette collection).
