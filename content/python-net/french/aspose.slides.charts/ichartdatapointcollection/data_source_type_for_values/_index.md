## data_source_type_for_values propriété

En d’autres termes, elle spécifie le type de valeur de la propriété ChartDataPoint.Value.Data. Lecture/écriture [`DataSourceType`](/slides/python-net/fr/aspose.slides.charts/datasourcetype).
