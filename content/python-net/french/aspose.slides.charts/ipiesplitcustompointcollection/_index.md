## IPieSplitCustomPointCollection classe

Représente une collection de points qui seront dessinés dans le deuxième camembert ou barre d'un graphique en camembert-sur-barre ou camembert-sur-camembert avec une division personnalisée.

Le type IPieSplitCustomPointCollection expose les membres suivants:

Renvoie le point de données du graphique par indice.
