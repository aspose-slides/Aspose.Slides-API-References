## ITrendline classe

La classe représente la ligne de tendance d'une série de graphique

Le type ITrendline expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`trendline_name`](/slides/python-net/fr/aspose.slides.charts/itrendline/trendline_name/) | Obtient ou définit le nom de la ligne de tendance.<br/>            Lecture/écriture **str**. |
| [`trendline_type`](/slides/python-net/fr/aspose.slides.charts/itrendline/trendline_type/) | Obtient ou définit le type de ligne de tendance.<br/>            Lecture/écriture [`ITrendline.trendline_type`](/slides/python-net/fr/aspose.slides.charts/itrendline/trendline_type). |
| [`format`](/slides/python-net/fr/aspose.slides.charts/itrendline/format/) | Représente le format de la ligne de tendance.<br/>            Lecture/écriture [`IFormat`](/slides/python-net/fr/aspose.slides.charts/iformat). |
| [`backward`](/slides/python-net/fr/aspose.slides.charts/itrendline/backward/) | Spécifie le nombre de catégories (ou d'unités sur un graphique de dispersion) que la ligne de tendance étend avant<br/>            les données de la série en cours de tendance. Sur les graphiques de dispersion et non-dispersion, la valeur doit être non négative.<br/>            Lecture/écriture **float**. |
| [`forward`](/slides/python-net/fr/aspose.slides.charts/itrendline/forward/) | Spécifie le nombre de catégories (ou d'unités sur un graphique de dispersion) que la ligne de tendance étend après le<br/>            les données de la série en cours de tendance. Sur les graphiques de dispersion et non-dispersion, la valeur doit être non négative.<br/>            Lecture/écriture **float**. |
| [`intercept`](/slides/python-net/fr/aspose.slides.charts/itrendline/intercept/) | Spécifie la valeur où la ligne de tendance doit croiser l'axe y. Cette propriété n'est prise en charge que<br/>            lorsque le type de ligne de tendance est exp, linear ou poly.<br/>            Lecture/écriture **float**. |
| [`display_equation`](/slides/python-net/fr/aspose.slides.charts/itrendline/display_equation/) | Spécifie que l'équation de la ligne de tendance est affichée sur le graphique (dans le même libellé que la valeur Rsquaredvalue).<br/>            Lecture/écriture **bool**. |
| [`order`](/slides/python-net/fr/aspose.slides.charts/itrendline/order/) | Spécifie l'ordre de la ligne de tendance polynomial. Il est ignoré pour les autres types de ligne de tendance. La valeur doit être comprise entre 2 et 6.<br/>            Lecture/écriture **int**. |
| [`period`](/slides/python-net/fr/aspose.slides.charts/itrendline/period/) | Spécifie la période de la ligne de tendance pour une ligne de tendance à moyenne mobile. Elle est ignorée pour les autres variantes de ligne de tendance.<br/>            La valeur doit être comprise entre 2 et 255.<br/>            Lecture/écriture **int**. |
| [`display_r_squared_value`](/slides/python-net/fr/aspose.slides.charts/itrendline/display_r_squared_value/) | Spécifie que la valeur R-carré de la ligne de tendance est affichée sur le graphique (dans le même libellé que l'équation).<br/>            Lecture/écriture **bool**. |
| [`related_legend_entry`](/slides/python-net/fr/aspose.slides.charts/itrendline/related_legend_entry/) | Représente l'entrée de légende liée à cette ligne de tendance<br/>            Lecture seule [`ILegendEntryProperties`](/slides/python-net/fr/aspose.slides.charts/ilegendentryproperties). |
