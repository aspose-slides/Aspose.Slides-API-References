## Énumération PictureType

Détermine le mode de remplissage de l'image de barre.

Le type PictureType expose les membres suivants :

## Champs

| Field | Description |
| :- | :- |
| NOT_DEFINED | Non défini. |
| STACK | L'image est redimensionnée pour se répéter au maximum 15 fois dans la barre empilée la plus longue. |
| STACK_SCALE | L'image est redimensionnée à un nombre spécifié d'unités et répétée sur la longueur de la barre. |
| STRETCH | L'image est étirée sur toute la longueur de la barre empilée. |
