## ErrorBarType énumération

Représente le type de barre d'erreur

Le type ErrorBarType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| BOTH | Spécifie que les barres d'erreur doivent être affichées dans les directions positive et négative. |
| MINUS | Spécifie que les barres d'erreur doivent être affichées uniquement dans la direction négative. |
| PLUS | Spécifie que les barres d'erreur doivent être affichées uniquement dans la direction positive. |
