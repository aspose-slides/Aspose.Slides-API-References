## TickMarkType énumération

Représente le type de repère de graduation pour l'axe spécifié.

Le type TickMarkType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| CROSS | Spécifie que les repères de graduation doivent traverser l'axe. |
| INSIDE | Spécifie que les repères de graduation doivent être à l'intérieur de la zone du tracé. |
| NONE | Spécifie qu'il ne doit y avoir aucun repère de graduation. |
| OUTSIDE | Spécifie que les repères de graduation doivent être à l'extérieur de la zone du tracé. |
