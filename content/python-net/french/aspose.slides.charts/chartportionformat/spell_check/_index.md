## spell_check propriété
Obtient ou définit une valeur indiquant si la vérification orthographique est activée pour la partie texte.
            Lorsque cette propriété est définie sur false, les vérifications orthographiques des éléments de texte sont supprimées.
            Lorsque définie sur true, la vérification orthographique est autorisée.
            La valeur par défaut est `false`.
