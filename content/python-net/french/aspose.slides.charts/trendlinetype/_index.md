## Énumération TrendlineType

Représente le type de ligne de tendance

Le type TrendlineType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| EXPONENTIAL | Spécifie que la ligne de tendance doit être une courbe exponentielle sous la forme. |
| LINEAR | Spécifie que la ligne de tendance doit être une ligne sous la forme. |
| LOGARITHMIC | Spécifie que la ligne de tendance doit être une courbe logarithmique sous la forme, où log est le logarithme naturel. |
| MOVING_AVERAGE | Spécifie que la ligne de tendance doit être une moyenne mobile de période Period. |
| POLYNOMIAL | Spécifie que la ligne de tendance doit être une courbe polynomiale d'ordre Order sous la forme. |
| POWER | Spécifie que la ligne de tendance doit être une courbe de puissance sous la forme. |
