## autofit_type propriété
Renvoie ou définit le mode d'ajustement automatique du texte.
            La modification de cette propriété peut avoir une certaine influence uniquement sur ces parties du graphique : 
            DataLabel and DataLabelFormat (prise en charge complète dans PowerPoint 2013 ; dans PowerPoint 2007 il n'y a aucun effet lors du rendu).
