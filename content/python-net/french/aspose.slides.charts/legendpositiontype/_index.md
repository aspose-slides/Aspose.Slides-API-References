## Énumération LegendPositionType

Détermine une position de légende sur un graphique.

Le type LegendPositionType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| BOTTOM | Spécifie que la légende doit être dessinée en bas du graphique. |
| LEFT | Spécifie que la légende doit être dessinée à gauche du graphique. |
| RIGHT | Spécifie que la légende doit être dessinée à droite du graphique. |
| TOP | Spécifie que la légende doit être dessinée en haut du graphique. |
| TOP_RIGHT | Spécifie que la légende doit être dessinée en haut à droite du graphique. |
