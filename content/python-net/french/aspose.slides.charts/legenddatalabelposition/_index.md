## LegendDataLabelPosition énumération

Détermine la position des étiquettes de données.

Le type LegendDataLabelPosition expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| NOT_DEFINED | Position non définie. |
| BOTTOM | Spécifie que les étiquettes de données doivent être affichées sous le repère de données. |
| BEST_FIT | Spécifie que les étiquettes de données doivent être affichées dans la meilleure position. |
| CENTER | Spécifie que les étiquettes de données doivent être affichées centrées sur le repère de données. |
| INSIDE_BASE | Spécifie que les étiquettes de données doivent être affichées à l'intérieur de la base du repère de données. |
| INSIDE_END | Spécifie que les étiquettes de données doivent être affichées à l'intérieur de l'extrémité du repère de données. |
| LEFT | Spécifie que les étiquettes de données doivent être affichées à gauche du repère de données. |
| OUTSIDE_END | Spécifie que les étiquettes de données doivent être affichées à l'extérieur de l'extrémité du repère de données. |
| RIGHT | Spécifie que les étiquettes de données doivent être affichées à droite du repère de données. |
| TOP | Spécifie que les étiquettes de données doivent être affichées au-dessus du repère de données. |
