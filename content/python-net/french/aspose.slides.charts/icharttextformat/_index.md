## IChartTextFormat classe

Les graphiques fonctionnent avec un ensemble restreint de propriétés de format de texte.  
IChartTextFormat, IChartTextBlockFormat, IChartParagraphFormat, IChartPortionFormat interfaces décrivent cet ensemble restreint.

Le type IChartTextFormat expose les membres suivants :
