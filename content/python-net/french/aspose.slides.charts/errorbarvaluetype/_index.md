## ErrorBarValueType énumération

Représente le type de valeur de barre d'erreur

Le type ErrorBarValueType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| CUSTOM | Spécifie que la longueur des barres d'erreur doit être déterminée par les éléments Plus et Minus. |
| FIXED | Spécifie que la longueur des barres d'erreur doit être la valeur fixe déterminée par Error Bar Value. |
| PERCENTAGE | Spécifie que la longueur des barres d'erreur doit être le pourcentage Error Bar Value des données. |
| STANDARD_DEVIATION | Spécifie que la longueur des barres d'erreur doit être les écarts-types Error Bar Value des données. |
| STANDARD_ERROR | Spécifie que la longueur des barres d'erreur doit être les erreurs standards Error Bar Value des données. |
