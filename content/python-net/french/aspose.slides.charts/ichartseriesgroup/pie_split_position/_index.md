## pie_split_position propriété
Specifie une valeur qui doit être utilisée pour déterminer quels points de données 
            sont dans le deuxième secteur ou barre d’un graphique à secteurs imbriqués ou à barres imbriquées. 
            Est utilisée avec la propriété PieSplitBy.
            Lecture/écriture **float**.
