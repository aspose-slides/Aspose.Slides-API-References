## TimeUnitType énumération

Représente l'unité de base pour l'axe des catégories

Le type TimeUnitType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| NONE | Les valeurs seront affichées telles quelles. |
| DAYS | Spécifie que les données du graphique seront affichées en jours. |
| MONTHS | Spécifie que les données du graphique seront affichées en mois. |
| YEARS | Spécifie que les données du graphique seront affichées en années. |
