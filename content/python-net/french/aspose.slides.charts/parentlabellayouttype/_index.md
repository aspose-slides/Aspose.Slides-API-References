## ParentLabelLayoutType énumération

Représente la disposition des étiquettes de données de catégorie. Utilisé uniquement avec les séries Treemap.

Le type ParentLabelLayoutType expose les membres suivants:

## Champs

| Champ | Description |
| :- | :- |
| BANNER | Indique que les étiquettes de catégorie parent sont affichées sous forme de bannière |
| NONE | Indique que les étiquettes de catégorie parent ne sont pas dessinées |
| OVERLAPPING | Indique que les étiquettes de catégorie parent sont affichées en chevauchement |
