## trend_lines propriété
Collection de lignes de tendance de séries.
            Lecture seule [`ITrendlineCollection`](/slides/python-net/fr/aspose.slides.charts/itrendlinecollection).

### Remarques

Les TrendLines sont disponibles (pas None) pour les séries de données dans les graphiques 2-D non empilés de type aire, barres, colonnes, lignes, actions, xy (scatter) et bulles. Une TrendLine n’est pas disponible pour les séries de données dans tout type de graphique qui est empilé ou 3-D. Les TrendLines ne sont également pas disponibles pour les graphiques radar, secteur, surface ou beignet.
