## bin_width propriété
Spécifie la largeur du groupe lorsque la valeur de AggregationType property est définie sur AxisAggregationType.ByBinWidth.
            Appliqué aux axes de catégorie. Utilisé uniquement avec les séries Histogram ou HistogramPareto.
