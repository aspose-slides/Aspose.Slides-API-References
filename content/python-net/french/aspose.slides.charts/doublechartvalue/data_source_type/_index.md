## data_source_type propriété
Indique si la propriété AsCell, AsCells, AsLiteralString ou AsLiteralDouble est active dans les descendants. En d'autres termes, il précise le type de valeur de la propriété Data.
Lecture/écriture [`DataSourceType`](/slides/python-net/fr/aspose.slides.charts/datasourcetype).

### Remarques

Pour les points de ChartDataPointCollection, cette propriété est en lecture seule.
            Dans ce cas, pour changer la valeur de cette propriété, vous pouvez utiliser l'une des propriétés ChartDataPointCollection.DataSourceTypeFor<...>.
