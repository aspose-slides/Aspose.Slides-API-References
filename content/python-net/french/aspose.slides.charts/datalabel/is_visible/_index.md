## is_visible propriété
False signifie que l'étiquette de données n'est pas visible (et donc tous les drapeaux Show*-flags (ShowValue, ...) sont false).
            Lecture seule **bool**.


### Remarques

Si l'étiquette de données est visible, vous pouvez la masquer avec la méthode Hide().
            Mais si l'étiquette de données n'est pas visible (IsVisible est false), vous pouvez rendre l'étiquette de données visible en réglant les drapeaux Show*-flags (ShowValue, ...) à l'état true.
