## AxisAggregationType énumération

Représente le type d'agrégation de l'axe des catégories. Utilisé uniquement avec les séries Histogram ou HistogramPareto.

Le type AxisAggregationType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| BY_CATEGORY | Regrouper par catégories |
| AUTOMATIC | Regrouper les catégories automatiquement. |
| BY_BIN_WIDTH | Regrouper les catégories par largeur de bin. La propriété IAxis.BinWidth doit être définie. |
| BY_NUMBER_OF_BINS | Regrouper les catégories par nombre de bins. La propriété IAxis.NumberOfBins doit être définie. |
