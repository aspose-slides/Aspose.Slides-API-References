## BubbleSizeRepresentationType énumération

Spécifie les façons possibles de représenter les données sous forme de tailles de diagramme à bulles.

Le type BubbleSizeRepresentationType expose les membres suivants :

## Champs

| Champ | Description |
| :- | :- |
| AREA | Spécifie que l'aire des bulles doit être proportionnelle à la valeur de taille de la bulle. |
| WIDTH | Spécifie que le rayon des bulles doit être proportionnel à la valeur de taille de la bulle. |
