## data_source_type propriété
Spécifie si la propriété AsCell, AsCells, AsLiteralString ou AsLiteralDouble 
            est effective chez les descendants. En d'autres termes, il spécifie le type 
            de valeur de la propriété Data.
            Lecture/écriture [`DataSourceType`](/slides/python-net/fr/aspose.slides.charts/datasourcetype).

### Remarques

Pour les points dans ChartDataPointCollection, cette propriété est en lecture seule. 
            Dans ce cas, pour changer la valeur de cette propriété, vous pouvez utiliser l'une des 
            ChartDataPointCollection.DataSourceTypeFor<...> propriétés.
