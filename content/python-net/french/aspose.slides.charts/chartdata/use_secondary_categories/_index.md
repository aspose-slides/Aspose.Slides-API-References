## use_secondary_categories propriété
Si false alors [`ChartData.secondary_categories`](/slides/python-net/fr/aspose.slides.charts/chartdata/secondary_categories) propriété renvoie None et les données 
            dans [`ChartData.categories`](/slides/python-net/fr/aspose.slides.charts/chartdata/categories) propriété est utilisée à la fois pour les séries primaires et secondaires.
            Si true alors les données dans [`ChartData.secondary_categories`](/slides/python-net/fr/aspose.slides.charts/chartdata/secondary_categories) propriété sont utilisées pour les séries secondaires et les données 
            dans [`ChartData.categories`](/slides/python-net/fr/aspose.slides.charts/chartdata/categories) propriété sont utilisées pour les séries primaires.
            Lecture/écriture **bool**.
