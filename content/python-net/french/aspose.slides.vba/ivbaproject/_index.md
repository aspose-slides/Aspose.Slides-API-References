## IVbaProject classe

Représente un projet VBA contenant des macros de présentation.

Le type IVbaProject expose les membres suivants :

## Propriétés

| Propriété | Description |
| :- | :- |
| [`name`](/slides/python-net/fr/aspose.slides.vba/ivbaproject/name/) | Renvoie le nom du projet VBA.<br/>            Lecture seule **str**. |
| [`modules`](/slides/python-net/fr/aspose.slides.vba/ivbaproject/modules/) | Renvoie la liste de tous les modules contenus dans le projet VBA.<br/>            Lecture seule [`IVbaModuleCollection`](/slides/python-net/fr/aspose.slides.vba/ivbamodulecollection). |
| [`references`](/slides/python-net/fr/aspose.slides.vba/ivbaproject/references/) | Renvoie la liste de toutes les références contenues dans le projet VBA.<br/>            Lecture seule [`IVbaReferenceCollection`](/slides/python-net/fr/aspose.slides.vba/ivbareferencecollection). |
| [`is_password_protected`](/slides/python-net/fr/aspose.slides.vba/ivbaproject/is_password_protected/) | Indique si le VBAProject est protégé par un mot de passe pour afficher les propriétés du projet.<br/>            Lecture seule **bool**. |
