## ویژگی use_cell
اگر مقدار true باشد، ویژگی AsCell فعال است. به عبارت دیگر، worksheet برای 
            ذخیره‌سازی دسته‌بندی استفاده می‌شود (این حالت از دسته‌بندی چندسطحی پشتیبانی می‌کند).
اگر مقدار false باشد، ویژگی AsLiteral فعال است. به عبارت دیگر، worksheet برای 
            ذخیره‌سازی دسته‌بندی استفاده نمی‌شود (و این حالت از دسته‌بندی‌های چندسطحی پشتیبانی نمی‌کند).
فقط-خواندنی **bool**.

### توضیحات

برای تغییر مقدار این ویژگی (برای تمام دسته‌ها در مجموعه) مقدار جدید را به ویژگی ChartCategoryCollection.UseCells اختصاص دهید.
