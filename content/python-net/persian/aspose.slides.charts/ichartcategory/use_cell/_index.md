## use_cell ویژگی
اگر true باشد، AsCell ویژگی فعال است. به عبارت دیگر، worksheet برای 
            ذخیره‌سازی دسته استفاده می‌شود (این حالت از دسته‌بندی چندسطحی پشتیبانی می‌کند).
اگر false باشد، AsLiteral ویژگی فعال است. به عبارت دیگر، worksheet برای 
            ذخیره‌سازی دسته استفاده نمی‌شود (و این حالت از دسته‌بندی چندسطحی پشتیبانی نمی‌کند).
فقط-خواندنی **bool**.

### توضیحات

برای تغییر مقدار این ویژگی (برای همه دسته‌ها در مجموعه) مقدار جدید را به ویژگی ChartCategoryCollection.UseCells تنظیم کنید.
