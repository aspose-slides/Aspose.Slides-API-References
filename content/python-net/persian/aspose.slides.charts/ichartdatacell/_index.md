## IChartDataCell کلاس

سلولی که برای داده‌های نمودار استفاده می‌شود را نشان می‌دهد.

نوع IChartDataCell اعضای زیر را ارائه می‌دهد:

## ویژگی‌ها

| Property | Description |
| :- | :- |
| [`row`](/slides/python-net/fa/aspose.slides.charts/ichartdatacell/row/) | شاخص ردیف برگ کاری که سلول در آن قرار دارد را برمی‌گرداند.<br/>            فقط-خواندنی **int**. |
| [`column`](/slides/python-net/fa/aspose.slides.charts/ichartdatacell/column/) | شاخص ستون برگ کاری که سلول در آن قرار دارد را برمی‌گرداند.<br/>            فقط-خواندنی **int**. |
| [`value`](/slides/python-net/fa/aspose.slides.charts/ichartdatacell/value/) | مقدار یک سلول را می‌خواند یا تنظیم می‌کند.<br/>            خواندن/نوشتن **any**. |
| [`formula`](/slides/python-net/fa/aspose.slides.charts/ichartdatacell/formula/) | فرمول را به سبک A1 می‌خواند یا تنظیم می‌کند. |
| [`r1c1_formula`](/slides/python-net/fa/aspose.slides.charts/ichartdatacell/r1c1_formula/) | فرمول را به سبک R1C1 می‌خواند یا تنظیم می‌کند. |
| [`chart_data_worksheet`](/slides/python-net/fa/aspose.slides.charts/ichartdatacell/chart_data_worksheet/) | برگ کاری را می‌خواند.<br/>            فقط-خواندنی [`IChartDataWorksheet`](/slides/python-net/fa/aspose.slides.charts/ichartdataworksheet). |
| [`is_hidden`](/slides/python-net/fa/aspose.slides.charts/ichartdatacell/is_hidden/) | تعیین می‌کند آیا سلول مخفی است یا نه.<br/>            فقط-خواندنی **bool**. |
| [`custom_number_format`](/slides/python-net/fa/aspose.slides.charts/ichartdatacell/custom_number_format/) | قالب نمایش سفارشی اعداد و تاریخ‌ها را می‌خواند یا تنظیم می‌کند. <br/>            اگر مقدار خالی باشد، مقدار PresetNumberFormat استفاده می‌شود.<br/>            خواندن/نوشتن **str**. |
| [`preset_number_format`](/slides/python-net/fa/aspose.slides.charts/ichartdatacell/preset_number_format/) | قالب نمایش پیش‌فرض اعداد و تاریخ‌ها را می‌خواند یا تنظیم می‌کند. عدد پیش‌فرض باید در بازه‌های [0..22] یا [37..49] باشد.<br/>             خواندن/نوشتن **int**. |
