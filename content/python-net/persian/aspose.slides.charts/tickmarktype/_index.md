## TickMarkType enum

نوع علامت‌چین را برای محور مشخص‌شده نشان می‌دهد.

نوع TickMarkType اعضای زیر را نشان می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| CROSS | مشخص می‌کند که علامت‌چین‌ها محور را قطع می‌کنند. |
| INSIDE | مشخص می‌کند که علامت‌چین‌ها داخل ناحیه نمودار قرار می‌گیرند. |
| NONE | مشخص می‌کند که هیچ علامت‌چینی وجود نخواهد داشت. |
| OUTSIDE | مشخص می‌کند که علامت‌چین‌ها خارج از ناحیه نمودار قرار می‌گیرند. |
