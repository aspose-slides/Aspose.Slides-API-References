## ParentLabelLayoutType شمارش

نمایش چیدمان برچسب‌های دادهٔ دسته. فقط برای سری‌های Treemap استفاده می‌شود.

نوع ParentLabelLayoutType اعضای زیر را نمایش می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| BANNER | مشخص می‌کند که برچسب‌های دستهٔ والد به عنوان بنر نشان داده می‌شوند |
| NONE | مشخص می‌کند که برچسب‌های دستهٔ والد رسم نمی‌شوند |
| OVERLAPPING | مشخص می‌کند که برچسب‌های دستهٔ والد به صورت هم‌پوشانی نشان داده می‌شوند |
