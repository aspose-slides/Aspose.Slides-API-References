## ErrorBarValueType شمارش

نوع مقدار نوار خطا را نشان می‌دهد

نوع ErrorBarValueType اعضای زیر را عرضه می‌کند:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| CUSTOM | مشخص می‌کند که طول نوارهای خطا باید توسط عناصری Plus و Minus تعیین شود. |
| FIXED | مشخص می‌کند که طول نوارهای خطا باید مقدار ثابت تعیین‌شده توسط Error Bar Value باشد. |
| PERCENTAGE | مشخص می‌کند که طول نوارهای خطا باید درصد Error Bar Value از داده باشد. |
| STANDARD_DEVIATION | مشخص می‌کند که طول نوارهای خطا باید انحراف معیارهای Error Bar Value از داده باشد. |
| STANDARD_ERROR | مشخص می‌کند که طول نوارهای خطا باید خطاهای استاندارد Error Bar Value از داده باشد. |
