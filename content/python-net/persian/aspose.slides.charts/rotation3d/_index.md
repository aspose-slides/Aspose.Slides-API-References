## کلاس Rotation3D

نمایش‌دهندهٔ چرخش سه‌بعدی یک نمودار.

نوع Rotation3D اعضای زیر را نمایش می‌دهد:

## ویژگی‌ها

| ویژگی | توضیح |
| :- | :- |
| [`rotation_x`](/slides/python-net/fa/aspose.slides.charts/rotation3d/rotation_x/) | مقدار یا تنظیم درجهٔ چرخش حول محور X، یعنی در جهت Y برای نمودارهای سه‌بعدی (بین -90 تا 90 درجه).<br/>            این ویژگی با مورد 21.2.2.157 rotX (X Rotation) در ECMA-376 و گزینهٔ "Y Rotation" در PowerPoint 2007+ مطابقت دارد.<br/>            خواندن/نوشتن **int**. |
| [`rotation_y`](/slides/python-net/fa/aspose.slides.charts/rotation3d/rotation_y/) | مقدار یا تنظیم درجهٔ چرخش حول محور Y، یعنی در جهت X برای نمودارهای سه‌بعدی (بین 0 تا 360 درجه).<br/>            این ویژگی با مورد 21.2.2.158 rotY (Y Rotation) در ECMA-376 و گزینهٔ "X Rotation" در PowerPoint 2007+ مطابقت دارد.<br/>            خواندن/نوشتن **int**. |
| [`perspective`](/slides/python-net/fa/aspose.slides.charts/rotation3d/perspective/) | مقدار یا تنظیم مقدار پرسپکتیو (زاویهٔ میدان دید) برای نمودارهای سه‌بعدی (بین 0 تا 240).<br/>            در صورتی که مقدار ویژگی RightAngleAxes برابر true باشد، نادیده گرفته می‌شود.<br/>            خواندن/نوشتن **int**. |
| [`right_angle_axes`](/slides/python-net/fa/aspose.slides.charts/rotation3d/right_angle_axes/) | تعیین می‌کند آیا محورهاى نمودار تحت زاویه‌های راست‌اند، نه به صورت پرسپکتیو رسم شوند.<br/>            به عبارت دیگر تعیین می‌کند آیا زوایای محورهاى نمودار مستقل از چرخش یا ارتفاع نمودار هستند.<br/>            خواندن/نوشتن **bool**. |
| [`depth_percents`](/slides/python-net/fa/aspose.slides.charts/rotation3d/depth_percents/) | مقدار یا تنظیم عمق یک نمودار سه‌بعدی به‌عنوان درصدی از عرض نمودار (بین 20 تا 2000 درصد).<br/>            خواندن/نوشتن **int**. |
| [`height_percents`](/slides/python-net/fa/aspose.slides.charts/rotation3d/height_percents/) | ارتفاع یک نمودار سه‌بعدی را به‌عنوان درصدی از عرض نمودار مشخص می‌کند (بین 5 تا 500 درصد).<br/>            خواندن/نوشتن **int**. |
