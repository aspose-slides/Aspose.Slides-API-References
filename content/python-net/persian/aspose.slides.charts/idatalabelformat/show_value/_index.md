## show_value ویژگی
نمایانگر رفتار نمایش مقدار درصد برچسب دادهٔ نمودار مشخص شده است. 
True مقدار درصد را نمایش می‌دهد. False برای مخفی کردن.
خواندنی/نوشتنی **bool**.

### توضیحات

اگر والد این شیء DataLabelFormat یک مجموعه DataLabelCollection از برچسب‌های داده باشد، این ویژگی مقدار پیش‌فرض ویژگی ShowValue را برای برچسب‌های داده جدید در مجموعه DataLabelCollection دریافت یا تنظیم می‌کند. تنظیم این ویژگی با مقدار، همچنین این مقدار را به ویژگی ShowValue برای تمام برچسب‌های داده در مجموعه DataLabelCollection تنظیم می‌کند (به عنوان مثال "DataLabels.DefaultDataLabelFormat.ShowValue = val;" باعث می‌شود تمام DataLabels[i].ShowValue برابر با val باشد).
