## text_frame_for_overriding ویژگی
Can contain a rich formatted text. If this ویژگی is not None then this 
            formatted text value overrides auto-generated text of data label.
            Auto-generated text of data label means text that is managed by ShowSeriesName, 
            ShowValue, ... ویژگی‌ها and is formatted with the TextFormatManager.TextFormat ویژگی.
            فقط خواندنی [`ITextFrame`](/slides/python-net/fa/aspose.slides/itextframe).
