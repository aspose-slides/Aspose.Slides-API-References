### نکات

این کلاس برای برگرداندن و دستکاری ویژگی‌های قالب‌بندی بخش متن تعریف‌شده برای بخش خاص استفاده می‌شود. این به این معنی است که هنگام دریافت مقادیر، ارث‌برداری اعمال نمی‌شود، بنابراین برای اکثر موارد مقدار «تعریف‌نشده» دریافت می‌کنید.

برای دریافت مقادیر مؤثر پارامترهای قالب‌بندی شامل ارث‌برداری، باید از روش [`PortionFormat.get_effective`](/slides/python-net/fa/aspose.slides/portionformat/get_effective) استفاده کنید که یک نمونهٔ [`IPortionFormatEffectiveData`](/slides/python-net/fa/aspose.slides/iportionformateffectivedata) را برمی‌گرداند.
