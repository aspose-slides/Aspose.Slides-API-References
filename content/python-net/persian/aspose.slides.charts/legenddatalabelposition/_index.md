## شمارش LegendDataLabelPosition

موقعیت برچسب‌های داده را تعیین می‌کند.

نوع LegendDataLabelPosition اعضای زیر را ارائه می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| NOT_DEFINED | موقعیت تعریف نشده است. |
| BOTTOM | مشخص می‌کند که برچسب‌های داده باید زیر مارکر داده نمایش داده شوند. |
| BEST_FIT | مشخص می‌کند که برچسب‌های داده باید در بهترین موقعیت نمایش داده شوند. |
| CENTER | مشخص می‌کند که برچسب‌های داده باید به صورت مرکز بر روی مارکر داده نمایش داده شوند. |
| INSIDE_BASE | مشخص می‌کند که برچسب‌های داده باید داخل پایه مارکر داده نمایش داده شوند. |
| INSIDE_END | مشخص می‌کند که برچسب‌های داده باید داخل انتهای مارکر داده نمایش داده شوند. |
| LEFT | مشخص می‌کند که برچسب‌های داده باید در سمت چپ مارکر داده نمایش داده شوند. |
| OUTSIDE_END | مشخص می‌کند که برچسب‌های داده باید خارج از انتهای مارکر داده نمایش داده شوند. |
| RIGHT | مشخص می‌کند که برچسب‌های داده باید در سمت راست مارکر داده نمایش داده شوند. |
| TOP | مشخص می‌کند که برچسب‌های داده باید بالای مارکر داده نمایش داده شوند. |
