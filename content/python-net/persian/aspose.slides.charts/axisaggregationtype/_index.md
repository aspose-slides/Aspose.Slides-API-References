## AxisAggregationType شمارش

نمایش می‌دهد نوع تجمیع محور دسته‌بندی. فقط با سری‌های Histogram یا HistogramPareto استفاده می‌شود.

نوع AxisAggregationType اعضای زیر را نشان می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| BY_CATEGORY | تجمیع بر اساس دسته‌ها |
| AUTOMATIC | دسته‌ها را به‌صورت خودکار تجمیع می‌کند. |
| BY_BIN_WIDTH | دسته‌ها را بر اساس عرض بِن تجمیع می‌کند. ویژگی IAxis.BinWidth باید تنظیم شود. |
| BY_NUMBER_OF_BINS | دسته‌ها را بر اساس تعداد بِن‌ها تجمیع می‌کند. ویژگی IAxis.NumberOfBins باید تنظیم شود. |
