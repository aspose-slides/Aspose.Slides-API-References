## IActualLayout کلاس

موقعیت واقعی یک عنصر نمودار را مشخص می‌کند.

نوع IActualLayout اعضای زیر را در اختیار می‌گذارد:

## ویژگی‌ها

| Property | Description |
| :- | :- |
| [`actual_x`](/slides/python-net/fa/aspose.slides.charts/iactuallayout/actual_x/) | موقعیت واقعی x (چپ) عنصر نمودار نسبت به گوشهٔ بالا-چپ نمودار را مشخص می‌کند.<br/>            برای دریافت مقادیر واقعی قبل از آن متد IChart.ValidateChartLayout() را فراخوانی کنید. <br/>            خواندنی **float**. |
| [`actual_y`](/slides/python-net/fa/aspose.slides.charts/iactuallayout/actual_y/) | موقعیت واقعی بالای عنصر نمودار نسبت به گوشهٔ بالا-چپ نمودار را مشخص می‌کند.<br/>            برای دریافت مقادیر واقعی قبل از آن متد IChart.ValidateChartLayout() را فراخوانی کنید. <br/>            خواندنی **float**. |
| [`actual_width`](/slides/python-net/fa/aspose.slides.charts/iactuallayout/actual_width/) | عرض واقعی عنصر نمودار را مشخص می‌کند. برای دریافت مقادیر واقعی قبل از آن متد IChart.ValidateChartLayout() را فراخوانی کنید. <br/>            خواندنی **float**. |
| [`actual_height`](/slides/python-net/fa/aspose.slides.charts/iactuallayout/actual_height/) | ارتفاع واقعی عنصر نمودار را مشخص می‌کند. برای دریافت مقادیر واقعی قبل از آن متد IChart.ValidateChartLayout() را فراخوانی کنید. <br/>            خواندنی **float**. |
