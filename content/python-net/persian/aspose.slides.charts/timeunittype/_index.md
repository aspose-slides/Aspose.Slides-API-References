## TimeUnitType enum

نمایش پایه برای محور دسته‌بندی را نشان می‌دهد

نوع TimeUnitType اعضای زیر را در دسترس قرار می‌دهد:

## Fields

| Field | Description |
| :- | :- |
| NONE | مقادیر همان‌طور که هستند نمایش داده می‌شوند. |
| DAYS | مشخص می‌کند که داده‌های نمودار به روز نمایش داده شوند. |
| MONTHS | مشخص می‌کند که داده‌های نمودار به ماه نمایش داده شوند. |
| YEARS | مشخص می‌کند که داده‌های نمودار به سال نمایش داده شوند. |
