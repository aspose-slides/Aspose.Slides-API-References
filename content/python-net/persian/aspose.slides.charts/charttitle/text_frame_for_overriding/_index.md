## text_frame_for_overriding ویژگی
می‌تواند شامل متن قالب‌بندی‌شده غنی باشد. اگر این ویژگی None نباشد، سپس این
            مقدار متن قالب‌بندی‌شده متن تولید خودکار را بازنویسی می‌کند.
متن تولید خودکار یک ویژگی ضمنی برچسب داده، برچسب واحد نمایش
            برچسب واحد از محور مقدار، عنوان محور، عنوان نمودار، برچسب خط روند.
متن تولید خودکار با ویژگی IFormattedTextContainer.TextFormat قالب‌بندی می‌شود.
فقط خواندنی [`ITextFrame`](/slides/python-net/fa/aspose.slides/itextframe).
