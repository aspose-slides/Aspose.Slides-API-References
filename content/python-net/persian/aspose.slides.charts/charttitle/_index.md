## کلاس ChartTitle

خواص عنوان نمودار را نشان می‌دهد.

نوع ChartTitle اعضای زیر را در دسترس قرار می‌دهد:

## خواص

| ویژگی | توضیح |
| :- | :- |
| [`x`](/slides/python-net/fa/aspose.slides.charts/charttitle/x/) | مقدار یا تنظیم مختصات x یک عنوان به صورت کسری از عرض نمودار.<br/>            Read/write **float**. |
| [`y`](/slides/python-net/fa/aspose.slides.charts/charttitle/y/) | مقدار یا تنظیم مختصات y یک عنوان به صورت کسری از ارتفاع نمودار.<br/>            Read/write **float**. |
| [`width`](/slides/python-net/fa/aspose.slides.charts/charttitle/width/) | مقدار یا تنظیم عرض یک عنوان به صورت کسری از عرض نمودار.<br/>            Read/write **float**. |
| [`height`](/slides/python-net/fa/aspose.slides.charts/charttitle/height/) | مقدار یا تنظیم ارتفاع یک عنوان به صورت کسری از ارتفاع نمودار.<br/>            Read/write **float**. |
| [`right`](/slides/python-net/fa/aspose.slides.charts/charttitle/right/) | راست.<br/>            Read-only **float**. |
| [`bottom`](/slides/python-net/fa/aspose.slides.charts/charttitle/bottom/) | پایین.<br/>            Read-only **float**. |
| [`overlay`](/slides/python-net/fa/aspose.slides.charts/charttitle/overlay/) | مشخص می‌کند آیا عناصر دیگر نمودار می‌توانند بر روی عنوان همپوشانی داشته باشند یا نه.<br/>            Read/write **bool**. |
| [`format`](/slides/python-net/fa/aspose.slides.charts/charttitle/format/) | استایل‌های پر, خط و افکت یک عنوان را برمی‌گرداند.<br/>            Read-only [`IFormat`](/slides/python-net/fa/aspose.slides.charts/iformat). |
| [`text_frame_for_overriding`](/slides/python-net/fa/aspose.slides.charts/charttitle/text_frame_for_overriding/) | می‌تواند متن غنی قالب‌بندی شده را شامل شود. اگر این ویژگی None نباشد، مقدار متن قالب‌بندی شده آن، متن تولید خودکار را بازنویسی می‌کند.<br/>            متن تولید خودکار یک ویژگی ضمنی برچسب داده، برچسب واحد نمایش محور مقدار، عنوان محور، عنوان نمودار، برچسب خط روند است.<br/>            متن تولید خودکار با ویژگی IFormattedTextContainer.TextFormat قالب‌بندی می‌شود.<br/>            Read-only [`ITextFrame`](/slides/python-net/fa/aspose.slides/itextframe). |
| [`text_format`](/slides/python-net/fa/aspose.slides.charts/charttitle/text_format/) | قالب متن را برمی‌گرداند.<br/>            Read-only [`IChartTextFormat`](/slides/python-net/fa/aspose.slides.charts/icharttextformat). |
| [`actual_x`](/slides/python-net/fa/aspose.slides.charts/charttitle/actual_x/) | موقعیت واقعی x (چپ) عنصر نمودار نسبت به گوشه بالای چپ نمودار را مشخص می‌کند.<br/>            قبل از دریافت مقادیر واقعی، متد IChart.ValidateChartLayout() را فراخوانی کنید. <br/>            Read **float**. |
| [`actual_y`](/slides/python-net/fa/aspose.slides.charts/charttitle/actual_y/) | موقعیت واقعی بالای عنصر نمودار نسبت به گوشه بالای چپ نمودار را مشخص می‌کند.<br/>            قبل از دریافت مقادیر واقعی، متد IChart.ValidateChartLayout() را فراخوانی کنید. <br/>            Read **float**. |
| [`actual_width`](/slides/python-net/fa/aspose.slides.charts/charttitle/actual_width/) | عرض واقعی عنصر نمودار را مشخص می‌کند. قبل از دریافت مقادیر واقعی، متد IChart.ValidateChartLayout() را فراخوانی کنید. <br/>            Read **float**. |
| [`actual_height`](/slides/python-net/fa/aspose.slides.charts/charttitle/actual_height/) | ارتفاع واقعی عنصر نمودار را مشخص می‌کند. قبل از دریافت مقادیر واقعی، متد IChart.ValidateChartLayout() را فراخوانی کنید. <br/>            Read **float**. |
