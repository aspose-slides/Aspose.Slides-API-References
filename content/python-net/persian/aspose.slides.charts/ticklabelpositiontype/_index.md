## TickLabelPositionType enum

نوع موقعیت برچسب‌های تیک‌مارک روی محور مشخص شده را نشان می‌دهد.

نوع TickLabelPositionType اعضای زیر را ارائه می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| HIGH | مشخص می‌کند که برچسب‌های محور در انتهای بالای محور عمود قرار می‌گیرند. |
| LOW | مشخص می‌کند که برچسب‌های محور در انتهای پایین محور عمود قرار می‌گیرند. |
| NEXT_TO | مشخص می‌کند که برچسب‌های محور در کنار محور قرار می‌گیرند. |
| NONE | مشخص می‌کند که برچسب‌های محور رسم نمی‌شوند. |
