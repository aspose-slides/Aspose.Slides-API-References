## default_label_shape_type خاصیت
دریافت یا تنظیم نوع شکل پیش‌فرض برای برچسب‌های داده.
باز می‌گرداند [`ShapeType.NOT_DEFINED`](/slides/python-net/fa/aspose.slides/shapetype/NOT_DEFINED) اگر هیچ شکل تعریف نشده باشد.
