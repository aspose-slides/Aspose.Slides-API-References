## ویژگی use_cell
اگر مقدار true باشد، ویژگی AsCell فعال است. به عبارت دیگر، کاربرگ برای ذخیره‌سازی دسته (این حالت از دسته چندسطحی پشتیبانی می‌کند). اگر مقدار false باشد، ویژگی AsLiteral فعال است. به عبارت دیگر، کاربرگ برای ذخیره‌سازی دسته استفاده نمی‌شود (و این حالت از دسته‌های چندسطحی پشتیبانی نمی‌کند). فقط‌خواندنی **bool**.

### توضیحات

برای تغییر مقدار این ویژگی (برای تمام دسته‌ها در مجموعه) مقدار جدید را به ویژگی ChartCategoryCollection.UseCells تنظیم کنید.
