## BubbleSizeRepresentationType شمارشی

روش‌های ممکن برای نمایش داده‌ها به‌عنوان اندازه‌های نمودار حبابی را مشخص می‌کند.

نوع BubbleSizeRepresentationType اعضای زیر را نمایان می‌سازد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| AREA | مشخص می‌کند مساحت حباب‌ها باید متناسب با مقدار اندازه حباب باشد. |
| WIDTH | مشخص می‌کند شعاع حباب‌ها باید متناسب با مقدار اندازه حباب باشد. |
