## secondary_categories ویژگی
دسته‌های ثانویه را دریافت می‌کند اگر ویژگی [`ChartData.use_secondary_categories`](/slides/python-net/fa/aspose.slides.charts/chartdata/use_secondary_categories) برابر true باشد.
            فقط‌خواندنی [`IChartCategoryCollection`](/slides/python-net/fa/aspose.slides.charts/ichartcategorycollection).

### توضیحات

اگر ویژگی [`ChartData.use_secondary_categories`](/slides/python-net/fa/aspose.slides.charts/chartdata/use_secondary_categories) برابر false باشد، این ویژگی [`ChartData.secondary_categories`](/slides/python-net/fa/aspose.slides.charts/chartdata/secondary_categories) 
            مقدار None را برمی‌گرداند و داده‌های موجود در ویژگی [`ChartData.categories`](/slides/python-net/fa/aspose.slides.charts/chartdata/categories) هم برای سری اصلی و هم برای سری ثانویه استفاده می‌شوند.
            اگر ویژگی [`ChartData.use_secondary_categories`](/slides/python-net/fa/aspose.slides.charts/chartdata/use_secondary_categories) برابر true باشد، داده‌های موجود در 
            این ویژگی [`ChartData.secondary_categories`](/slides/python-net/fa/aspose.slides.charts/chartdata/secondary_categories) برای سری ثانویه استفاده می‌شوند و داده‌های 
            موجود در ویژگی [`ChartData.categories`](/slides/python-net/fa/aspose.slides.charts/chartdata/categories) برای سری اصلی استفاده می‌شوند.
