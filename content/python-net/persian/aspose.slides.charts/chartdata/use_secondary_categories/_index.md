## use_secondary_categories ویژگی
اگر مقدار false باشد، ویژگی [`ChartData.secondary_categories`](/slides/python-net/fa/aspose.slides.charts/chartdata/secondary_categories) None را برمی‌گرداند و داده‌ها 
            در ویژگی [`ChartData.categories`](/slides/python-net/fa/aspose.slides.charts/chartdata/categories) هم برای سری اولیه و هم برای سری ثانویه استفاده می‌شود.
            اگر مقدار true باشد، داده‌ها در ویژگی [`ChartData.secondary_categories`](/slides/python-net/fa/aspose.slides.charts/chartdata/secondary_categories) برای سری ثانویه استفاده می‌شود و داده‌ها 
            در ویژگی [`ChartData.categories`](/slides/python-net/fa/aspose.slides.charts/chartdata/categories) برای سری اولیه استفاده می‌شود.
            خواندنی/نوشتنی **bool**.
