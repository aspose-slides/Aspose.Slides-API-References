## use_secondary_categories ویژگی
اگر false باشد، ویژگی [`ChartData.secondary_categories`](/slides/python-net/fa/aspose.slides.charts/chartdata/secondary_categories) مقدار None را برمی‌گرداند و داده‌ها در ویژگی [`ChartData.categories`](/slides/python-net/fa/aspose.slides.charts/chartdata/categories) برای هر دو سری اولیه و ثانویه استفاده می‌شوند.
اگر true باشد، داده‌ها در ویژگی [`ChartData.secondary_categories`](/slides/python-net/fa/aspose.slides.charts/chartdata/secondary_categories) برای سری ثانویه استفاده می‌شود و داده‌ها در ویژگی [`ChartData.categories`](/slides/python-net/fa/aspose.slides.charts/chartdata/categories) برای سری اولیه استفاده می‌شود.
قابل خواندن/نوشتن **bool**.
