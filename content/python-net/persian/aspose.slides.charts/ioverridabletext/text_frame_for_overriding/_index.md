## text_frame_for_overriding ویژگی
می‌تواند شامل متن قالب‌بندی‌شده غنی باشد. اگر این ویژگی None نباشد، این مقدار متن قالب‌بندی‌شده متن تولید خودکار را بازنویسی می‌کند. متن تولید خودکار یک ویژگی ضمنی برچسب داده، برچسب واحد نمایش محور مقدار، عنوان محور، عنوان نمودار، برچسب خط روند است. متن تولید خودکار با ویژگی IFormattedTextContainer.TextFormat قالب‌بندی می‌شود. فقط‌خواندنی [`ITextFrame`](/slides/python-net/fa/aspose.slides/itextframe).
