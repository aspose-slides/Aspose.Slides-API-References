## is_visible ویژگی
False means that data label is not visible (and so all Show*-flags (ShowValue, ...) are false).
            فقط‌خواندنی **bool**.

### توضیحات

If data label is visible you can make it hidden with Hide() method.
            اما اگر برچسب داده قابل مشاهده نیست (IsVisible is false) می‌توانید برچسب داده را با تنظیم Show*-flags (ShowValue, ...) به حالت true قابل مشاهده کنید.
