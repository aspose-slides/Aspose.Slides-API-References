## enum ChartShapeType

نمایانگر یک شکل از نمودار است.

نوع ChartShapeType اعضای زیر را در اختیار می‌گذارد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| NOT_DEFINED | شکل نمودار تعریف نشده است. |
| BOX | مشخص می‌کند که نمودار باید با شکل جعبه‌ای رسم شود. |
| CONE | مشخص می‌کند که نمودار باید به صورت یک مخروط رسم شود، به‌طوری که پایه مخروط روی کف باشد و نوک مخروط در بالای نشانگر داده قرار گیرد. |
| CONE_TO_MAX | مشخص می‌کند که نمودار باید با مخروط‌های مقطوع رسم شود به‌گونه‌ای که نوک مخروط برابر با بیشینه مقدار داده باشد. |
| CYLINDER | مشخص می‌کند که نمودار باید به صورت یک استوانه رسم شود. |
| PYRAMID | مشخص می‌کند که نمودار باید به صورت یک هرم مستطیلی رسم شود، به‌طوری که پایه هرم روی کف باشد و نوک هرم در بالای نشانگر داده قرار گیرد. |
| PYRAMID_TO_MAXIMUM | مشخص می‌کند که نمودار باید با مخروط‌های مقطوع رسم شود به‌گونه‌ای که نوک مخروط برابر با بیشینه مقدار داده باشد. |
