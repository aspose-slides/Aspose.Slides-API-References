## use_cells property
اگر true باشد، worksheet برای ذخیره‌سازی دسته‌ها استفاده می‌شود (این حالت از دسته‌بندی چند‌سطحی پشتیبانی می‌کند).
            اگر false باشد، worksheet برای ذخیره‌سازی مقادیر استفاده نمی‌شود (و این حالت از دسته‌بندی چند‌سطحی پشتیبانی نمی‌کند).
            خواندن/نوشتن **bool**.
