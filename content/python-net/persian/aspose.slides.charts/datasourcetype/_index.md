## شمارش DataSourceType

نوع‌های منبع داده.

نوع DataSourceType اعضای زیر را در اختیار می‌گذارد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| WORKSHEET | از اشیای CellXls برای ذخیره XValue، YValue، Value یا BubbleSize نقطه داده در کاربرگ استفاده کنید. |
| STRING_LITERALS | از متغیر رشته‌ای دسترسی سریع برای ذخیره XValue، YValue، Value یا BubbleSize از <br/>            نقطه داده استفاده کنید. کاربرگ برای ذخیره مقادیر استفاده نمی‌شود. |
| DOUBLE_LITERALS | از متغیر double دسترسی سریع برای ذخیره XValue، YValue، Value یا BubbleSize از <br/>            نقطه داده استفاده کنید. کاربرگ برای ذخیره مقادیر استفاده نمی‌شود. |
