## شمارش PictureType

حالت پرکردن تصویر نوار را تعیین می‌کند.

نوع PictureType اعضای زیر را عرضه می‌کند:

## فیلدها

| Field | Description |
| :- | :- |
| NOT_DEFINED | تعریف نشده. |
| STACK | تصویر به‌گونه‌ای اندازه‌گیری می‌شود که حداکثر ۱۵ بار در بلندترین نوار پشته‌ای تکرار شود. |
| STACK_SCALE | تصویر به تعداد واحدهای مشخص اندازه‌گیری می‌شود و در طول نوار تکرار می‌شود. |
| STRETCH | تصویر تا طول کامل نوار پشته‌ای کشیده می‌شود. |
