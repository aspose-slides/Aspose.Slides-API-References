## شمارش MarkerStyleType

شکل علامت روی نقطه دادهٔ نمودار را تعیین می‌کند.

نوع MarkerStyleType اعضای زیر را نشان می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| NOT_DEFINED |  |
| CIRCLE | مشخص می‌کند که یک دایره در هر نقطه داده رسم شود. |
| DASH | مشخص می‌کند که یک خط تیره در هر نقطه داده رسم شود. |
| DIAMOND | مشخص می‌کند که یک الماس در هر نقطه داده رسم شود. |
| DOT | مشخص می‌کند که یک نقطه در هر نقطه داده رسم شود. |
| NONE | مشخص می‌کند که هیچ چیزی در هر نقطه داده رسم نشود. |
| PICTURE | مشخص می‌کند که یک تصویر در هر نقطه داده رسم شود. |
| PLUS | مشخص می‌کند که یک علامت جمع در هر نقطه داده رسم شود. |
| SQUARE | مشخص می‌کند که یک مربع در هر نقطه داده رسم شود. |
| STAR | مشخص می‌کند که یک ستاره در هر نقطه داده رسم شود. |
| TRIANGLE | مشخص می‌کند که یک مثلث در هر نقطه داده رسم شود. |
| X | مشخص می‌کند که یک X در هر نقطه داده رسم شود. |
