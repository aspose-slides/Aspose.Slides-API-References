## ChartDataCell کلاس

نمایان‌گر سلول برای داده‌های نمودار است.

نوع ChartDataCell اعضای زیر را در اختیار می‌گذارد:

## ویژگی‌ها

| ویژگی | توضیح |
| :- | :- |
| [`row`](/slides/python-net/fa/aspose.slides.charts/chartdatacell/row/) | شمارهٔ سطر شیت کاری که سلول در آن قرار دارد را برمی‌گرداند.<br/>            فقط خواندنی **int**. |
| [`column`](/slides/python-net/fa/aspose.slides.charts/chartdatacell/column/) | شمارهٔ ستون شیت کاری که سلول در آن قرار دارد را برمی‌گرداند.<br/>            فقط خواندنی **int**. |
| [`value`](/slides/python-net/fa/aspose.slides.charts/chartdatacell/value/) | مقدار یک سلول را می‌گیرد یا تنظیم می‌کند.<br/>            خواندنی/نوشتنی **any**. |
| [`formula`](/slides/python-net/fa/aspose.slides.charts/chartdatacell/formula/) | فرمول را به سبک A1 دریافت یا تنظیم می‌کند. |
| [`r1c1_formula`](/slides/python-net/fa/aspose.slides.charts/chartdatacell/r1c1_formula/) | فرمول را به سبک R1C1 دریافت یا تنظیم می‌کند. |
| [`chart_data_worksheet`](/slides/python-net/fa/aspose.slides.charts/chartdatacell/chart_data_worksheet/) | شیت کاری را دریافت می‌کند.<br/>            فقط خواندنی [`IChartDataWorksheet`](/slides/python-net/fa/aspose.slides.charts/ichartdataworksheet). |
| [`is_hidden`](/slides/python-net/fa/aspose.slides.charts/chartdatacell/is_hidden/) | تعیین می‌کند که آیا سلول مخفی است یا خیر.<br/>            فقط خواندنی **bool**. |
| [`custom_number_format`](/slides/python-net/fa/aspose.slides.charts/chartdatacell/custom_number_format/) | فرمت نمایش سفارشی اعداد و تاریخ‌ها را می‌گیرد یا تنظیم می‌کند. <br/>            اگر مقدار خالی باشد، مقدار PresetNumberFormat استفاده خواهد شد.<br/>            خواندنی/نوشتنی **str**. |
| [`preset_number_format`](/slides/python-net/fa/aspose.slides.charts/chartdatacell/preset_number_format/) | فرمت نمایش توکار اعداد و تاریخ‌ها را می‌گیرد یا تنظیم می‌کند. شمارهٔ پیش‌تنظیم باید در بازهٔ [0..22] یا [37..49] باشد.<br/>            خواندنی/نوشتنی **int**. |
