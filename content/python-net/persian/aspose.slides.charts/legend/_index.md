## کلاس Legend

خواص legend نمودار را نمایش می‌دهد.

نوع Legend اعضای زیر را در دسترس قرار می‌دهد:

## ویژگی‌ها

| ویژگی | توضیح |
| :- | :- |
| [`x`](/slides/python-net/fa/aspose.slides.charts/legend/x/) | مختصات x یک legend را به‌صورت کسر از عرض نمودار برمی‌گرداند یا تنظیم می‌کند.<br/>            قابل خواندن/نوشتن **float**. |
| [`y`](/slides/python-net/fa/aspose.slides.charts/legend/y/) | مختصات y یک legend را به‌صورت کسر از ارتفاع نمودار برمی‌گرداند یا تنظیم می‌کند.<br/>            قابل خواندن/نوشتن **float**. |
| [`width`](/slides/python-net/fa/aspose.slides.charts/legend/width/) | عرض یک legend را به‌صورت کسر از عرض نمودار برمی‌گرداند یا تنظیم می‌کند.<br/>            قابل خواندن/نوشتن **float**. |
| [`height`](/slides/python-net/fa/aspose.slides.charts/legend/height/) | ارتفاع یک legend را به‌صورت کسر از ارتفاع نمودار برمی‌گرداند یا تنظیم می‌کند.<br/>            قابل خواندن/نوشتن **float**. |
| [`right`](/slides/python-net/fa/aspose.slides.charts/legend/right/) | مقدار راست.<br/>            فقط‌خواندنی **float**. |
| [`bottom`](/slides/python-net/fa/aspose.slides.charts/legend/bottom/) | مقدار پایین.<br/>            فقط‌خواندنی **float**. |
| [`overlay`](/slides/python-net/fa/aspose.slides.charts/legend/overlay/) | تعیین می‌کند که آیا سایر عناصر نمودار می‌توانند بر legend پوشش داده شوند یا نه.<br/>            قابل خواندن/نوشتن **bool**. |
| [`text_format`](/slides/python-net/fa/aspose.slides.charts/legend/text_format/) | قالب متن.<br/>            فقط‌خواندنی [`IChartTextFormat`](/slides/python-net/fa/aspose.slides.charts/icharttextformat). |
| [`position`](/slides/python-net/fa/aspose.slides.charts/legend/position/) | موقعیت legend را روی نمودار مشخص می‌کند.<br/>            مقادیر غیر-NaN ویژگی‌های X, Y, Width, Height اثر این ویژگی را نادیده می‌گیرند.<br/>            قابل خواندن/نوشتن [`LegendPositionType`](/slides/python-net/fa/aspose.slides.charts/legendpositiontype). |
| [`format`](/slides/python-net/fa/aspose.slides.charts/legend/format/) | قالب یک legend را برمی‌گرداند.<br/>            فقط‌خواندنی [`IFormat`](/slides/python-net/fa/aspose.slides.charts/iformat). |
| [`chart`](/slides/python-net/fa/aspose.slides.charts/legend/chart/) | نمودار را برمی‌گرداند.<br/>            فقط‌خواندنی [`IChart`](/slides/python-net/fa/aspose.slides.charts/ichart). |
| [`entries`](/slides/python-net/fa/aspose.slides.charts/legend/entries/) | ورودی‌های legend را دریافت می‌کند.<br/>            فقط‌خواندنی [`ILegendEntryCollection`](/slides/python-net/fa/aspose.slides.charts/ilegendentrycollection). |
| [`actual_x`](/slides/python-net/fa/aspose.slides.charts/legend/actual_x/) | موقعیت واقعی x (چپ) عنصر نمودار را نسبت به گوشهٔ بالا-چپ نمودار مشخص می‌کند.<br/>            قبل از دریافت مقادیر واقعی، متد IChart.ValidateChartLayout() را فراخوانی کنید. <br/>            قابل خواندن **float**. |
| [`actual_y`](/slides/python-net/fa/aspose.slides.charts/legend/actual_y/) | موقعیت واقعی بالای عنصر نمودار نسبت به گوشهٔ بالا-چپ نمودار مشخص می‌کند.<br/>            قبل از دریافت مقادیر واقعی، متد IChart.ValidateChartLayout() را فراخوانی کنید. <br/>            قابل خواندن **float**. |
| [`actual_width`](/slides/python-net/fa/aspose.slides.charts/legend/actual_width/) | عرض واقعی عنصر نمودار را مشخص می‌کند. قبل از دریافت مقادیر واقعی، متد IChart.ValidateChartLayout() را فراخوانی کنید. <br/>            قابل خواندن **float**. |
| [`actual_height`](/slides/python-net/fa/aspose.slides.charts/legend/actual_height/) | ارتفاع واقعی عنصر نمودار را مشخص می‌کند. قبل از دریافت مقادیر واقعی، متد IChart.ValidateChartLayout() را فراخوانی کنید. <br/>            قابل خواندن **float**. |
