## text_frame_for_overriding ویژگی
می‌تواند یک متن قالب‌بندی‌شده غنی را شامل شود. اگر این ویژگی None نباشد، این
            مقدار متن قالب‌بندی‌شده متن تولید خودکار برچسب داده را بازنویسی می‌کند.
            متن تولید خودکار برچسب داده به معنای متنی است که توسط ShowSeriesName،
            ShowValue، ... ویژگی‌ها مدیریت می‌شود و با ویژگی TextFormatManager.TextFormat قالب‌بندی می‌شود.
            فقط-خواندنی [`ITextFrame`](/slides/python-net/fa/aspose.slides/itextframe).
