## value_type ویژگی
نمایانگر روش‌های ممکن برای تعیین طول نوارهای خطا است.
            در صورت استفاده از نوع مقدار سفارشی برای تعیین مقدار، از ویژگی [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/fa/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) نقطه داده خاص در مجموعه DataPoints از سری استفاده کنید.
            در صورت استفاده از نوع مقدار Fixed، Percentage یا StandardDeviation، از ویژگی Value برای تعیین مقدار استفاده کنید.  
            خواند/نوشت [`ErrorBarValueType`](/slides/python-net/fa/aspose.slides.charts/errorbarvaluetype).
