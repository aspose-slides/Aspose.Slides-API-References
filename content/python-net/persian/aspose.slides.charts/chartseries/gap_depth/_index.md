## gap_depth ویژگی
Returns or sets the distance, as a percentage of the marker width, between the data series in a 3D chart.
            این ویژگی نه تنها برای این سری بلکه برای تمام سری‌های گروه سری والد است - این بازتاب ویژگی مناسب گروه است. بنابراین این ویژگی فقط-خواندنی است.
            از ویژگی ParentSeriesGroup برای دسترسی به گروه سری والد استفاده کنید.
            از ویژگی ParentSeriesGroup.GapDepth خواندنی/نوشتنی برای تغییر مقدار استفاده کنید.
            فقط-خواندنی **int**.
