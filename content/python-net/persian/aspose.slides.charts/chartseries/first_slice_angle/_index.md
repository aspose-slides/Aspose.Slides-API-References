## first_slice_angle ویژگی
زاویهٔ اولین برش نمودار پای یا دونات را مشخص می‌کند، بر حسب درجه (ساعتی از بالا، از 0 تا 360 درجه). این ویژگی نه تنها برای این سری بلکه برای تمامی سری‌های گروه سری والد است - این نمایش ویژگی مناسب گروه است. بنابراین این ویژگی فقط خواندنی است. از ویژگی ParentSeriesGroup برای دسترسی به گروه سری والد استفاده کنید. از ویژگی خواندنی/نوشتنی ParentSeriesGroup.FirstSliceAngle برای تغییر مقدار استفاده کنید. فقط خواندنی **int**.
