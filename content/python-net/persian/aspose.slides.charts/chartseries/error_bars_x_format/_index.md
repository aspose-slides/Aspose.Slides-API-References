## error_bars_x_format ویژگی
نمایش ErrorBars سری با جهت X.

            ErrorBars با جهت X برای سری‌های نوع area، bar، scatter و bubble در دسترس هستند.
            برای هر نوع دیگری از چارت، این ویژگی مقدار None را برمی‌گرداند (شامل چارت‌های 3D).
            در صورت نیاز به مقادیر سفارشی، از مجموعه DataPoints برای تعیین مقدار استفاده کنید
            (با [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/fa/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) ویژگی).

            فقط-خواندنی [`IErrorBarsFormat`](/slides/python-net/fa/aspose.slides.charts/ierrorbarsformat).
