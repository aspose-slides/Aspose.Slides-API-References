## has_series_lines ویژگی
تعیین می‌کند که آیا خطوط سری برای این سری و سری‌های هم‌خانواده وجود دارد یا خیر.
            این ویژگی نه تنها برای این سری بلکه برای تمام سری‌های گروه سری والد است 
            گروه - این یک نمایش از ویژگی مناسب گروه است. بنابراین این ویژگی 
            فقط-خواندنی است.
            از ویژگی ParentSeriesGroup برای دسترسی به گروه سری والد استفاده کنید.
            از ویژگی ParentSeriesGroup.HasSeriesLines که خواندن/نوشتن است برای تغییر مقدار استفاده کنید.
            از ویژگی ParentSeriesGroup.SeriesLinesFormat برای قالب‌بندی خطوط سری استفاده کنید.
            فقط-خواندنی **bool**.
