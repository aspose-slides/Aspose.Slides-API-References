## second_pie_size property
اندازهٔ دومین دایره یا میلهٔ یک نمودار pie-of-pie یا 
            یک نمودار bar-of-pie را به عنوان درصدی از اندازهٔ دایرهٔ اول مشخص می‌کند (می‌تواند بین ۵ تا ۲۰۰ درصد باشد).
            این ویژگی نه فقط برای این سری بلکه برای تمام سری‌های گروه سری والد است - این نمایش ویژگی مناسب گروه است. بنابراین این ویژگی فقط-خواندنی است.
            برای دسترسی به گروه سری والد از ویژگی ParentSeriesGroup استفاده کنید.
            برای تغییر مقدار از ویژگی ParentSeriesGroup.SecondPieSize خواندن/نوشتن استفاده کنید.
            فقط-خواندنی **int**.
