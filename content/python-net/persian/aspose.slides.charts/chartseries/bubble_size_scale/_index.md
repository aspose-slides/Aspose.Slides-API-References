## ویژگی bubble_size_scale
فاکتور مقیاس برای نمودار حبابی را مشخص می‌کند (می‌تواند 
            بین ۰ و ۳۰۰ درصد از اندازه پیش‌فرض باشد).
            این ویژگی نه تنها برای این سری بلکه برای تمام سری‌های گروه سری والد است - این نمایانگر ویژگی مناسب گروه می‌باشد. و بنابراین این ویژگی فقط-خواندنی است.
            از ویژگی ParentSeriesGroup برای دسترسی به گروه سری والد استفاده کنید.
            از ویژگی ParentSeriesGroup.BubbleSizeScale خواندن/نوشتن برای تغییر مقدار استفاده کنید.
