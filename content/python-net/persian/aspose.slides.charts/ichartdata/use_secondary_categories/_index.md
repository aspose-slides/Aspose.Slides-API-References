## use_secondary_categories ویژگی
اگر مقدار false باشد، ویژگی [`IChartData.secondary_categories`](/slides/python-net/fa/aspose.slides.charts/ichartdata/secondary_categories) مقدار None برمی‌گرداند و داده در ویژگی [`IChartData.categories`](/slides/python-net/fa/aspose.slides.charts/ichartdata/categories) برای هر دو سری اصلی و ثانویه استفاده می‌شود.
اگر مقدار true باشد، داده در ویژگی [`IChartData.secondary_categories`](/slides/python-net/fa/aspose.slides.charts/ichartdata/secondary_categories) برای سری ثانویه و داده در ویژگی [`IChartData.categories`](/slides/python-net/fa/aspose.slides.charts/ichartdata/categories) برای سری اصلی استفاده می‌شود.
خواندنی/نوشتنی **bool**.
