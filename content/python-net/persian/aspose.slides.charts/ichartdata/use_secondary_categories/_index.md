## use_secondary_categories ویژگی
اگر false باشد، [`IChartData.secondary_categories`](/slides/python-net/fa/aspose.slides.charts/ichartdata/secondary_categories) ویژگی مقدار None را برمی‌گرداند و داده در [`IChartData.categories`](/slides/python-net/fa/aspose.slides.charts/ichartdata/categories) ویژگی هم برای سری اصلی و هم برای سری ثانویه استفاده می‌شود.
اگر true باشد، داده‌های موجود در [`IChartData.secondary_categories`](/slides/python-net/fa/aspose.slides.charts/ichartdata/secondary_categories) ویژگی برای سری ثانویه استفاده می‌شوند و داده‌های موجود در [`IChartData.categories`](/slides/python-net/fa/aspose.slides.charts/ichartdata/categories) ویژگی برای سری اصلی استفاده می‌شوند.
خواندنی/نوشتنی **bool**.
