## ویژگی secondary_categories
دسته‌های ثانویه را دریافت می‌کند اگر ویژگی [`IChartData.use_secondary_categories`](/slides/python-net/fa/aspose.slides.charts/ichartdata/use_secondary_categories) برابر true باشد.
            فقط-خواندنی [`IChartCategoryCollection`](/slides/python-net/fa/aspose.slides.charts/ichartcategorycollection).


### توضیحات

اگر ویژگی [`IChartData.use_secondary_categories`](/slides/python-net/fa/aspose.slides.charts/ichartdata/use_secondary_categories) برابر false باشد، این ویژگی [`IChartData.secondary_categories`](/slides/python-net/fa/aspose.slides.charts/ichartdata/secondary_categories) 
            مقدار None را برمی‌گرداند و داده‌های موجود در ویژگی [`IChartData.categories`](/slides/python-net/fa/aspose.slides.charts/ichartdata/categories) هم برای سری اولیه 
            و هم برای سری ثانویه استفاده می‌شوند.
            اگر ویژگی [`IChartData.use_secondary_categories`](/slides/python-net/fa/aspose.slides.charts/ichartdata/use_secondary_categories) برابر true باشد، داده‌های موجود در این ویژگی [`IChartData.secondary_categories`](/slides/python-net/fa/aspose.slides.charts/ichartdata/secondary_categories) 
            برای سری ثانویه استفاده می‌شوند و داده‌های موجود در ویژگی [`IChartData.categories`](/slides/python-net/fa/aspose.slides.charts/ichartdata/categories) برای سری اولیه استفاده می‌شوند.
