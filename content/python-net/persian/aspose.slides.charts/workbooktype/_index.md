## WorkbookType شمارش

نوع فایل دفتر کار Open XML را مشخص می‌کند.

نوع WorkbookType اعضای زیر را ارائه می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| NOT_DEFINED | نوع دفتر کار تعریف نشده است. |
| WORKBOOK | دفتر کار Excel (*.xlsx). |
| WORKBOOK_MACRO | دفتر کار Excel با قابلیت ماکرو (*.xlsm). |
| TEMPLATE | قالب Excel (*.xltx). |
| TEMPLATE_MACRO | قالب Excel با قابلیت ماکرو (*.xltm). |
| WORKBOOK_BINARY_MACRO | دفتر کار باینری Excel با قابلیت ماکرو (*.xlsb). |
