## PieSplitType enumeration

نوعی از نقاط تقسیم در پای یا نوار دوم در نمودار آب‌میوه-در-آب‌میوه یا نوار-در-نمودار آب‌میوه را نشان می‌دهد.

نوع PieSplitType اعضای زیر را در اختیار می‌گذارد:

## Fields

| فیلد | توضیح |
| :- | :- |
| DEFAULT | مشخص می‌کند که نقاط داده باید با استفاده از مکانیزم پیش‌فرض <br/> برای این نوع نمودار تقسیم شوند. |
| CUSTOM | مشخص می‌کند که نقاط داده باید بین <br/> پای اصلی و نمودار دوم بر اساس مقادیر تقسیم سفارشی تقسیم شوند. |
| BY_PERCENTAGE | مشخص می‌کند که نقاط داده باید بین پای اصلی و <br/> نمودار دوم تقسیم شوند به‌طوری‌که نقاطی که درصدشان کمتر از <br/> درصد موقعیت تقسیم (Split Position) است، در نمودار دوم قرار گیرند. |
| BY_POS | مشخص می‌کند که نقاط داده باید بین پای اصلی و <br/> نمودار دوم تقسیم شوند با قرار دادن آخرین موقعیت تقسیم (Split Position) نقاط داده <br/> در نمودار دوم. |
| BY_VALUE | مشخص می‌کند که نقاط داده باید بین پای اصلی و <br/> نمودار دوم تقسیم شوند با قرار دادن نقاط داده‌ای که مقدارشان کمتر از <br/> موقعیت تقسیم (Split Position) است، در نمودار دوم. |
