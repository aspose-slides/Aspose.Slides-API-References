## ویژگی‌ها

| Property | Description |
| :- | :- |
| [`use_cells`](/slides/python-net/fa/aspose.slides.charts/chartcategorycollection/use_cells/) | اگر مقدار true باشد، برگه کاری برای ذخیرهٔ دسته‌ها استفاده می‌شود (این حالت از دسته‌های چندسطحی پشتیبانی می‌کند).<br/>            اگر مقدار false باشد، برگه کاری برای ذخیرهٔ مقادیر استفاده نمی‌شود (و این حالت از <br/>            دسته‌های چندسطحی پشتیبانی نمی‌کند).<br/>            خواندن/نوشتن **bool**. |
| [`grouping_level_count`](/slides/python-net/fa/aspose.slides.charts/chartcategorycollection/grouping_level_count/) | تعداد سطوح گروه‌بندی دسته‌های استفاده‌شده را برمی‌گرداند.<br/>            برای دسته‌های چندسطحی بیشتر از یک است.<br/>            فقط-خواندنی **int**. |
