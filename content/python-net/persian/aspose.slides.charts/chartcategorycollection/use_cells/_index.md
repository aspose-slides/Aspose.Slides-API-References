## ویژگی use_cells
اگر مقدار true باشد، worksheet برای ذخیره‌سازی دسته‌ها استفاده می‌شود (این حالت از دسته‌های چندسطحی پشتیبانی می‌کند).
اگر مقدار false باشد، worksheet برای ذخیره‌سازی مقادیر استفاده نمی‌شود (و این حالت از دسته‌های چندسطحی پشتیبانی نمی‌کند).
خواندن/نوشتن **bool**.
