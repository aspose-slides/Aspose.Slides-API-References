## IFormat کلاس

نمایانگر ویژگی‌های قالب نمودار است.

نوع IFormat اعضای زیر را در اختیار می‌گذارد:

## ویژگی‌ها

| ویژگی | توضیح |
| :- | :- |
| [`fill`](/slides/python-net/fa/aspose.slides.charts/iformat/fill/) | ویژگی‌های سبک پرکردن یک نمودار را برمی‌گرداند.<br/>            فقط خواندنی [`IFillFormat`](/slides/python-net/fa/aspose.slides/ifillformat). |
| [`line`](/slides/python-net/fa/aspose.slides.charts/iformat/line/) | ویژگی‌های سبک خط یک نمودار را برمی‌گرداند.<br/>            فقط خواندنی [`ILineFormat`](/slides/python-net/fa/aspose.slides/ilineformat). |
| [`effect`](/slides/python-net/fa/aspose.slides.charts/iformat/effect/) | اثرهای استفاده شده برای یک نمودار را برمی‌گرداند.<br/>            فقط خواندنی [`IEffectFormat`](/slides/python-net/fa/aspose.slides/ieffectformat). |
