## has_up_down_bars ویژگی
تعیین می‌کند که آیا نمودار خطی یا نمودار سهام دارای نوارهای بالا/پایین است.
            این ویژگی نه تنها برای این سری بلکه برای تمام سری‌های سری والد 
            گروه - این یک پروژکشن از ویژگی مناسب گروه است. و بنابراین این ویژگی 
            فقط-خواندنی است.
            از ویژگی ParentSeriesGroup برای دسترسی به گروه سری والد استفاده کنید.
            از ویژگی خواندنی/قابل‌نوشتن ParentSeriesGroup.UpDownBars.HasUpDownBars برای تغییر مقدار استفاده کنید.
            برای قالب‌بندی نوارهای بالا/پایین از ویژگی ParentSeriesGroup.UpDownBars استفاده کنید.
            فقط-خواندنی **bool**.
