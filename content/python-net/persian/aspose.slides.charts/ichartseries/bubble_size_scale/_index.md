## bubble_size_scale ویژگی
مقیاس مقیاس برای نمودار حباب (می‌تواند 
            بین ۰ تا ۳۰۰ درصد اندازه پیش‌فرض باشد).
این ویژگی نه تنها برای این سری بلکه برای تمام سری‌های گروه سری‌های والد است - این یک بازتاب ویژگی مناسب گروه است. به همین دلیل این ویژگی فقط-قابل خواندن است.
از ویژگی ParentSeriesGroup برای دسترسی به گروه سری‌های والد استفاده کنید.
از ویژگی ParentSeriesGroup.BubbleSizeScale که قابل خواندن/نوشتن است برای تغییر مقدار استفاده کنید.
