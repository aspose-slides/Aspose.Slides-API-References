## ویژگی error_bars_x_format
نمایش ErrorBars از سری‌ها با جهت X. 
            
            ErrorBars با جهت X برای سری‌های از نوع area، bar، scatter و bubble در دسترس هستند. 
            برای هر نوع دیگر نمودار، این ویژگی مقدار None را برمی‌گرداند (از جمله نمودارهای 3D).
            در صورت استفاده از مقادیر سفارشی، از مجموعه DataPoints برای مشخص کردن مقدار استفاده کنید
            (با ویژگی [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/fa/aspose.slides.charts/ichartdatapoint/error_bars_custom_values)).
            
            فقط-خواندنی [`IErrorBarsFormat`](/slides/python-net/fa/aspose.slides.charts/ierrorbarsformat).
