## ویژگی bubble_size_representation
مشخص می‌کند که مقادیر اندازهٔ حباب‌ها چگونه در نمودار حبابی نمایش داده می‌شوند.
            این ویژگی نه تنها برای این سری بلکه برای تمام سری‌های گروه سری والد است - این یک پیش‌نمایش از ویژگی مناسب گروه است. بنابراین این ویژگی فقط خواندنی است.
            از ویژگی ParentSeriesGroup برای دسترسی به گروه سری والد استفاده کنید.
            از ویژگی ParentSeriesGroup.BubbleSizeRepresentation که قابلیت خواندن/نوشتن دارد برای تغییر مقدار استفاده کنید.
