## ویژگی gap_depth
فاصله را که به‌عنوان درصدی از عرض مارکر بین سری‌های داده‌ای در یک نمودار 3 بعدی است، بازمی‌گرداند یا تنظیم می‌کند.
این ویژگی نه تنها برای این سری بلکه برای تمام سری‌های گروه سری‌های والد است - این نمایش ویژگی مناسب گروه می‌باشد.
بنابراین این ویژگی فقط خواندنی است.
از ویژگی ParentSeriesGroup برای دسترسی به گروه سری‌های والد استفاده کنید.
از ویژگی ParentSeriesGroup.GapDepth برای خواندن/نوشتن به منظور تغییر مقدار استفاده کنید.
فقط خواندنی **int**.
