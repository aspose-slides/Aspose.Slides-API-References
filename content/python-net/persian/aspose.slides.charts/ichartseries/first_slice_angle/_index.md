## first_slice_angle خصوصیت
زاویه اولین برش نمودار دایره‌ای یا دونات را مشخص می‌کند، بر حسب درجه (ساعت‌گرد از بالا، از 0 تا 360 درجه).  
این خصوصیت نه تنها برای این سری بلکه برای تمام سری‌های گروه سری والد است – این بازتاب خصوصیت مناسب گروه می‌باشد. بنابراین این خصوصیت فقط-خواندنی است.  
برای دسترسی به گروه سری والد از خصوصیت ParentSeriesGroup استفاده کنید.  
برای تغییر مقدار، از خصوصیت خواندن/نوشتن ParentSeriesGroup.FirstSliceAngle استفاده کنید.  
فقط-خواندنی **int**.
