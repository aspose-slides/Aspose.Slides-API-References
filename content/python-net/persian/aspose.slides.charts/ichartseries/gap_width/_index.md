## خاصیت gap_width
Specifies the space between bar or column clusters, as a percentage of the bar or column width.
            این خاصیت نه تنها برای این سری، بلکه برای تمام سری‌های گروه سری‌های والد است - این انعکاس خاصیت مناسب گروه می‌باشد. به همین دلیل این خاصیت 
            فقط خواندنی است.
            برای دسترسی به گروه سری‌های والد، از خاصیت ParentSeriesGroup استفاده کنید.
            برای تغییر مقدار، از خاصیت خواندنی/نوشتنی ParentSeriesGroup.GapWidth استفاده کنید.
            فقط خواندنی **int**.
