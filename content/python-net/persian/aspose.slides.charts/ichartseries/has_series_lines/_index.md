## ویژگی has_series_lines
تعیین می‌کند که آیا خطوط سری برای این سری و سری‌های مرتبط وجود دارد.
این ویژگی نه تنها برای این سری بلکه برای تمام سری‌های گروه سری والد است - این بازتابی از ویژگی مناسب گروه است. بنابراین این ویژگی فقط خواندنی است.
از ویژگی ParentSeriesGroup برای دسترسی به گروه سری والد استفاده کنید.
از ویژگی خواندنی/نوشتنی ParentSeriesGroup.HasSeriesLines برای تغییر مقدار استفاده کنید.
از ویژگی ParentSeriesGroup.SeriesLinesFormat برای قالب‌بندی خطوط سری استفاده کنید.
فقط خواندنی **bool**.
