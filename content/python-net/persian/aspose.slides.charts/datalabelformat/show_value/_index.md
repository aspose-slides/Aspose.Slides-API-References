## show_value ویژگی
Represents a specified chart's data label percentage value display behavior. 
            True displays the percentage value. False to hide.
            خواندنی/نوشتنی **bool**.

### توضیحات

If parent of this DataLabelFormat object is a DataLabelCollection collection of data labels then this ویژگی gets or sets the default value of the ShowValue ویژگی for the new data labels in the DataLabelCollection collection.
            Set this ویژگی with value also sets this value to the ShowValue ویژگی for all data labels in the DataLabelCollection collection
            (i.e. "DataLabels.DefaultDataLabelFormat.ShowValue = val;" cause to 
            all DataLabels[i].ShowValue is equal to val).
