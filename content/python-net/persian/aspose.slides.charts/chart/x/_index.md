## ویژگی x
مختصات x گوشهٔ بالا-چپ شکل را دریافت یا تنظیم می‌کند، بر حسب نقاط.
            قابل خواندن/نوشتن **float**.

### ملاحظات

مقدار بازگردانده شده همیشه تعریف شده است و هرگز **float** نیست.
            مقدار تخصیص داده شده نیز باید تعریف شده باشد؛ **float** فقط به ویژگی‌های یک نمونهٔ `RawFrame` اختصاص داده شود.

### تعریف:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
