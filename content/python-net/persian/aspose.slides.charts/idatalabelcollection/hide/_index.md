## hide(self) {#}
با تنظیم همه پرچم‌های Show*- (ShowValue, ...) از ویژگی DefaultDataLabelFormat به حالت false، برچسب داده به‌صورت پیش‌فرض مخفی می‌شود.  
IsVisible پس از این مقدار false خواهد بود.


```python
def hide(self):
    ...
```


### توضیحات

اگر برچسب داده به‌صورت پیش‌فرض قابل مشاهده نیست (IsVisible برابر false است) می‌توانید برچسب داده را «به‌صورت پیش‌فرض قابل مشاهده» کنید با تنظیم پرچم‌های Show*- (ShowValue, ...) از ویژگی DefaultDataLabelFormat به حالت true.
