## IDataLabelCollection کلاس

نوع IDataLabelCollection اعضای زیر را در دسترس قرار می‌دهد:

## ویژگی‌ها

| ویژگی | توضیح |
| :- | :- |
| [`default_data_label_format`](/slides/python-net/fa/aspose.slides.charts/idatalabelcollection/default_data_label_format/) | قالب پیش‌فرض تمام برچسب‌های داده در مجموعه را برمی‌گرداند.<br/>            فقط‌خواندنی [`IDataLabelFormat`](/slides/python-net/fa/aspose.slides.charts/idatalabelformat). |

| [`is_visible`](/slides/python-net/fa/aspose.slides.charts/idatalabelcollection/is_visible/) | مقدار False به این معنی است که برچسب داده به طور پیش‌فرض قابل مشاهده نیست (و بنابراین تمام <br/>            پرچم‌های Show* (ShowValue, ...) ویژگی DefaultDataLabelFormat برابر false هستند).<br/>            فقط‌خواندنی **bool**. |
| [`count_of_visible_data_labels`](/slides/python-net/fa/aspose.slides.charts/idatalabelcollection/count_of_visible_data_labels/) | تعداد برچسب‌های داده قابل مشاهده در مجموعه را برمی‌گیرد.<br/>            فقط‌خواندنی **int**. |
| [`count`](/slides/python-net/fa/aspose.slides.charts/idatalabelcollection/count/) | تعداد تمام برچسب‌های داده در مجموعه را برمی‌گیرد.<br/>            فقط‌خواندنی **int**. |
| [`parent_series`](/slides/python-net/fa/aspose.slides.charts/idatalabelcollection/parent_series/) | سری نمودار والد را برمی‌گرداند.<br/>            فقط‌خواندنی [`IChartSeries`](/slides/python-net/fa/aspose.slides.charts/ichartseries). |
