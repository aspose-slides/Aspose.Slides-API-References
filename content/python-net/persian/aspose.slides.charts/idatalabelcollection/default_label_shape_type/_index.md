## خاصیت default_label_shape_type
دریافت یا تنظیم نوع پیش‌فرض شکل برای برچسب‌های داده.
             اگر هیچ شکلی تعریف نشده باشد، [`ShapeType.NOT_DEFINED`](/slides/python-net/fa/aspose.slides/shapetype/NOT_DEFINED) را برمی‌گرداند.


### توضیحات

تنظیم این خاصیت همچنین خاصیت [`IDataLabel.label_shape_type`](/slides/python-net/fa/aspose.slides.charts/idatalabel/label_shape_type) را
             برای همه برچسب‌های داده در مجموعه به همان مقدار تنظیم می‌کند.
