## SlideShowTransition کلاس

نمایانگر انتقال اسلایدشو است.

نوع SlideShowTransition اعضای زیر را ارائه می‌دهد:

## ویژگی‌ها

| Property | Description |
| :- | :- |
| [`sound`](/slides/python-net/fa/aspose.slides.slideshow/slideshowtransition/sound/) | داده‌های صوتی جاسازی‌شده را برمی‌گرداند یا تنظیم می‌کند.<br/>            خواندنی/نوشتنی [`IAudio`](/slides/python-net/fa/aspose.slides/iaudio). |
| [`sound_mode`](/slides/python-net/fa/aspose.slides.slideshow/slideshowtransition/sound_mode/) | حالت صدا برای انتقال اسلاید را تنظیم یا برمی‌گرداند.<br/>            خواندنی/نوشتنی [`TransitionSoundMode`](/slides/python-net/fa/aspose.slides.slideshow/transitionsoundmode). |
| [`sound_loop`](/slides/python-net/fa/aspose.slides.slideshow/slideshowtransition/sound_loop/) | این ویژگی مشخص می‌کند که صدا تا وقوع رویداد صوتی بعدی در اسلایدشو حلقه بزند.<br/>            خواندنی/نوشتنی **bool**. |
| [`advance_on_click`](/slides/python-net/fa/aspose.slides.slideshow/slideshowtransition/advance_on_click/) | مشخص می‌کند که آیا کلیک موس اسلاید را پیش‌روی می‌کند یا خیر. اگر این ویژگی مشخص نشود، مقدار true فرض می‌شود.<br/>            خواندنی/نوشتنی **bool**. |
| [`advance_after`](/slides/python-net/fa/aspose.slides.slideshow/slideshowtransition/advance_after/) | این ویژگی مشخص می‌کند که آیا اسلایدشو پس از زمان معینی به اسلاید بعدی می‌رود یا خیر.<br/>            خواندنی/نوشتنی **bool**. |
| [`advance_after_time`](/slides/python-net/fa/aspose.slides.slideshow/slideshowtransition/advance_after_time/) | زمان را بر حسب میلی‌ثانیه مشخص می‌کند که پس از آن انتقال باید شروع شود. این تنظیم می‌تواند همراه با ویژگی advClick استفاده شود. اگر این ویژگی مشخص نشود، فرض می‌شود که خودکار پیش‌روی‌ای رخ ندهد.<br/>            خواندنی/نوشتنی **int**. |
| [`speed`](/slides/python-net/fa/aspose.slides.slideshow/slideshowtransition/speed/) | سرعت انتقالی که هنگام انتقال از اسلاید فعلی به اسلاید بعدی استفاده می‌شود را مشخص می‌کند.<br/>            خواندنی/نوشتنی [`TransitionSpeed`](/slides/python-net/fa/aspose.slides.slideshow/transitionspeed). |
| [`value`](/slides/python-net/fa/aspose.slides.slideshow/slideshowtransition/value/) | مقدار انتقال اسلایدشو.<br/>            فقط-خواندنی [`ITransitionValueBase`](/slides/python-net/fa/aspose.slides.slideshow/itransitionvaluebase). |
| [`type`](/slides/python-net/fa/aspose.slides.slideshow/slideshowtransition/type/) | نوع انتقال.<br/>            خواندنی/نوشتنی [`TransitionType`](/slides/python-net/fa/aspose.slides.slideshow/transitiontype). |
| [`sound_is_built_in`](/slides/python-net/fa/aspose.slides.slideshow/slideshowtransition/sound_is_built_in/) | مشخص می‌کند که آیا این صدا یک صدای داخلی است یا خیر. اگر این ویژگی به true تنظیم شود<br/>            برنامهٔ تولیدکننده مطلع می‌شود تا ویژگی name مشخص‌شده برای این صدا را در لیست صداهای داخلی بررسی کند<br/>            و سپس می‌تواند نام یا رابط کاربری سفارشی را در صورت نیاز نمایش دهد.<br/>            قابل خواندن/نوشتن **bool**. |
| [`sound_name`](/slides/python-net/fa/aspose.slides.slideshow/slideshowtransition/sound_name/) | نامی قابل خواندن برای صداهای انتقال را مشخص می‌کند. برای دریافت یا تنظیم نام صدا باید ویژگی [`SlideShowTransition.sound`](/slides/python-net/fa/aspose.slides.slideshow/slideshowtransition/sound) اختصاص داده شود.<br/>            قابل خواندن/نوشتن **str**. |
| [`duration`](/slides/python-net/fa/aspose.slides.slideshow/slideshowtransition/duration/) | مدت اثر انتقال اسلاید را بر حسب میلی‌ثانیه دریافت یا تنظیم می‌کند.<br/>            خواندنی/نوشتنی **int**. |
