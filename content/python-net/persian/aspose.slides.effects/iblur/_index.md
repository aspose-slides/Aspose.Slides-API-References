## IBlur کلاس

نمایانگر یک اثر Blur است که بر تمام شکل، از جمله پرکننده‌اش اعمال می‌شود. تمام کانال‌های رنگی، از جمله آلفا، تحت تأثیر قرار می‌گیرند.

نوع IBlur اعضای زیر را فراهم می‌کند:

## ویژگی‌ها

| ویژگی | توضیح |
| :- | :- |
| [`radius`](/slides/python-net/fa/aspose.slides.effects/iblur/radius/) | مقدار شعاع تاری را برمی‌گرداند یا تنظیم می‌کند.<br/>            خواندنی/قابل نوشتن **float**. |
| [`grow`](/slides/python-net/fa/aspose.slides.effects/iblur/grow/) | تعیین می‌کند که آیا مرزهای شی به دلیل تاری بزرگ شوند یا خیر.<br/>            مقدار true نشان می‌دهد مرزها بزرگ می‌شوند و مقدار false نشان می‌دهد که بزرگ نمی‌شوند.<br/>            خواندنی/قابل نوشتن **bool**. |
