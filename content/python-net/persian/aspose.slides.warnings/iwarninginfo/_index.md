## IWarningInfo کلاس

یک رابط پایه برای تمام هشدارها را نشان می‌دهد.

نوع IWarningInfo اعضای زیر را نمایان می‌کند:

## ویژگی‌ها

| ویژگی | شرح |
| :- | :- |
| [`warning_type`](/slides/python-net/fa/aspose.slides.warnings/iwarninginfo/warning_type/) | یک نوع هشدار را برمی‌گرداند.<br/>            فقط خواندنی [`IWarningInfo.warning_type`](/slides/python-net/fa/aspose.slides.warnings/iwarninginfo/warning_type). |
| [`description`](/slides/python-net/fa/aspose.slides.warnings/iwarninginfo/description/) | یک توصیف قابل خواندن برای انسان از این هشدار را برمی‌گرداند.<br/>            فقط خواندنی **str**. |

## متدها

| متد | شرح |
| :- | :- |
| [`send_warning(self, receiver)`](/slides/python-net/fa/aspose.slides.warnings/iwarninginfo/send_warning/#iwarningcallback) | اگر receiver برابر None نباشد، هشدار را به receiver مشخص شده پایان می‌دهد و در صورتی که receiver تصمیم به قطع عملیات گرفت، <br/>            AbortRequestedException را پرتاب می‌کند. |
