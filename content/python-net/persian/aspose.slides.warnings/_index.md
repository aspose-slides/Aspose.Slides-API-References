شامل کلاس‌هایی است که انواع مختلفی از هشدارها را نشان می‌دهند
## کلاس‌ها

| کلاس | توضیح |
| :- | :- |
| [`IKnownIssueWarningInfo`](/slides/python-net/fa/aspose.slides.warnings/iknownissuewarninginfo/) | هشدار درباره مشکلی شناخته‌شده که در آینده نزدیک برطرف نخواهد شد. |
| [`INotImplementedWarningInfo`](/slides/python-net/fa/aspose.slides.warnings/inotimplementedwarninginfo/) | هشدار درباره ویژگی‌ای شناخته‌شده که پیاده‌سازی نشده و در آینده نزدیک پیاده‌سازی نخواهد شد. |
| [`IObsoletePresLockingBehaviorWarningInfo`](/slides/python-net/fa/aspose.slides.warnings/iobsoletepreslockingbehaviorwarninginfo/) | این هشدار نشان می‌دهد که رفتار قفل‌گذاری ارائه منسوخ شده‌ای استفاده شده است. |
| [`IPresentationSignedWarningInfo`](/slides/python-net/fa/aspose.slides.warnings/ipresentationsignedwarninginfo/) | این هشدار نشان می‌دهد که ارائه خوانده شده دارای امضای <br/>            است و این امضا در طول پردازش حذف خواهد شد. |
| [`IWarningCallback`](/slides/python-net/fa/aspose.slides.warnings/iwarningcallback/) | رابط برای کلاس‌هایی که هشدار دریافت می‌کنند |
| [`IWarningInfo`](/slides/python-net/fa/aspose.slides.warnings/iwarninginfo/) | یک رابط پایه برای تمام هشدارها را نشان می‌دهد. |

| :- | :- |

| [`WarningType`](/slides/python-net/fa/aspose.slides.warnings/warningtype/) | یک نوع هشدار را نشان می‌دهد. |
