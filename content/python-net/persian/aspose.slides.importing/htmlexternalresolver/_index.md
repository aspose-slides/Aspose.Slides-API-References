## HtmlExternalResolver کلاس

شیء فراخوانی که توسط روتین وارد کردن HTML برای دریافت اشیائی مانند تصاویر استفاده می‌شود. استفاده از این حل‌کننده می‌تواند در صورتی که فایل HTML فراهم‌شده توسط کاربر باعث دسترسی به فایل‌های محلی یا شبکه‌ای شود، باعث بروز آسیب‌پذیری شود. با احتیاط استفاده کنید. توصیه می‌شود که HtmlExternalResolver را به‌طور کامل مشخص نکنید (تنها اشیاء توکار خوانده می‌شوند) یا یک زیرکلاس ایجاد کنید که بررسی کند آیا URI مشخص‌شده معتبر است یا خیر.
