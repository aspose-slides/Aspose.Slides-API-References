## get_cells(self, formula, skip_hidden_cells) {#str-bool}
یک مجموعه از سلول‌ها را از کتاب‌کار بازیابی می‌کند که با فرمول مشخص شده مطابقت دارند.

### خروجی

یک لیست فقط-خواندنی از سلول‌ها که با فرمول مشخص شده مطابقت دارند.



```python
def get_cells(self, formula, skip_hidden_cells):
    ...
```


| Parameter | Type | Description |
| :- | :- | :- |
| formula | **str** | یک فرمول یا عبارت بازه (مثلاً "Sheet1!A1:B3") برای شناسایی سلول‌های هدف استفاده می‌شود. |
| skip_hidden_cells | **bool** | اگر `true` باشد، سلول‌های مخفی (مثلاً در ردیف‌ها یا ستون‌های مخفی) از نتایج حذف می‌شوند. |
