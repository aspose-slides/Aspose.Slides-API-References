## get_cells(self, formula, skip_hidden_cells) {#str-bool}
یک مجموعه از سلول‌ها را از دفتر کار بازیابی می‌کند که با فرمول مشخص شده مطابقت دارند.

### بازگرداندن

یک لیست فقط-خواندنی از سلول‌هایی که با فرمول مشخص شده مطابقت دارند.



```python
def get_cells(self, formula, skip_hidden_cells):
    ...
```


| پارامتر | نوع | توضیح |
| :- | :- | :- |
| formula | **str** | یک فرمول یا عبارت بازه (مثال: "Sheet1!A1:B3") که برای شناسایی سلول‌های هدف استفاده می‌شود. |
| skip_hidden_cells | **bool** | اگر `true`، سلول‌های مخفی (مثال: در ردیف‌ها یا ستون‌های مخفی) از نتیجه حذف خواهند شد. |
