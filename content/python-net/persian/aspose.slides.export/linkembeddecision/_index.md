## LinkEmbedDecision شمارش

تعیین می‌کند که شی در هنگام ذخیره‌سازی چگونه پردازش شود.

نوع LinkEmbedDecision اعضای زیر را در دسترس قرار می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| LINK | شی به صورت خارجی ذخیره می‌شود و توسط URL ارجاع داده می‌شود |
| EMBED | در صورت امکان، شی باید در فایلی که تولید می‌شود جاسازی شود. اگر جاسازی ممکن نباشد، GetUrl فراخوانی می‌شود و بسته به نتیجه، شی توسط URL ارجاع داده می‌شود یا نادیده گرفته می‌شود. |
| IGNORE | شی نادیده گرفته می‌شود. |
