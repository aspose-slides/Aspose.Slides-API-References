## شمارش Zip64Mode

مشخص می‌کند که چه زمانی باید از افزونه‌های قالب ZIP64 برای فایل OpenXML استفاده شود.

نوع Zip64Mode اعضای زیر را نمایش می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| NEVER | از افزونه‌های قالب ZIP64 استفاده نکنید. |
| IF_NECESSARY | در صورت لزوم از افزونه‌های قالب ZIP64 استفاده کنید. |
| ALWAYS | همیشه از افزونه‌های قالب ZIP64 استفاده کنید. |


### توضیحات

فایل OpenXML یک بایگانی ZIP است که محدودیت ۴ GB (۲^۳۲ بایت) برای اندازهٔ غیرقابلمهٔ یک فایل، اندازهٔ فشردهٔ یک فایل، و اندازهٔ کل بایگانی دارد، همچنین محدودیت ۶۵٬۵۳۵ (۲^۱۶-۱) فایل در بایگانی. افزونه‌های قالب ZIP64 محدودیت‌ها را به ۲^۶۴ افزایش می‌دهند.
