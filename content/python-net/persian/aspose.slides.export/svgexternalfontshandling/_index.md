## شمارش SvgExternalFontsHandling

نماهنگامی یک روش برای ادارهٔ قلم‌های خارجی استفاده شده در رسم متن را ارائه می‌دهد.

نوع SvgExternalFontsHandling اعضای زیر را نمایان می‌کند:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| ADD_LINKS_TO_FONT_FILES | افزودن پیوندهایی به فایل‌های قلم جداگانه در بخش style فایل SVG. |
| EMBED | ذخیرهٔ داده‌های قلم‌ها به‌صورت مستقیم در فایل SVG. لطفاً قبل از استفاده از این گزینه، تمام توافق‌نامه‌های مجوز قلم‌های خارجی را بررسی کنید. |
| VECTORIZE | ذخیرهٔ تمام متن با استفاده از قلم‌های خارجی به‌صورت گرافیک. |
