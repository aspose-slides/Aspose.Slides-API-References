## شمارش SaveFormat

ثوابت که فرمت یک ارائه ذخیره‌شده را تعریف می‌کنند.

نوع SaveFormat اعضای زیر را ارائه می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| PPT | ارائه را در فرمت PPT ذخیره می‌کند. |
| PDF | ارائه را در فرمت PDF ذخیره می‌کند. |
| XPS | ارائه را در فرمت XPS ذخیره می‌کند. |
| PPTX | ارائه را در فرمت PPTX ذخیره می‌کند. |
| PPSX | ارائه را در فرمت PPSX (اسلایدشو) ذخیره می‌کند. |
| TIFF | ارائه را به عنوان تصویر چند صفحه‌ای TIFF ذخیره می‌کند. |
| ODP | ارائه را در فرمت ODP ذخیره می‌کند. |
| PPTM | ارائه را در فرمت PPTM (ارائه‌ با ماکرو) ذخیره می‌کند. |
| PPSM | ارائه را در فرمت PPSM (اسلایدشو با ماکرو) ذخیره می‌کند. |
| POTX | ارائه را در فرمت POTX (قالب) ذخیره می‌کند. |
| POTM | ارائه را در فرمت POTM (قالب با ماکرو) ذخیره می‌کند. |
| HTML | ارائه را در فرمت HTML ذخیره می‌کند. |
| SWF | ارائه را در فرمت SWF ذخیره می‌کند. |
| OTP | ارائه را در فرمت OTP (قالب ارائه) ذخیره می‌کند. |
| PPS | ارائه را در فرمت PPS ذخیره می‌کند. |
| POT | ارائه را در فرمت POT ذخیره می‌کند. |
| FODP | ارائه را در فرمت FODP ذخیره می‌کند. |
| GIF | ارائه را در فرمت GIF ذخیره می‌کند. |
| HTML5 | ارائه را در فرمت HTML با استفاده از سیستم قالب‌بندی جدید HTML5 ذخیره می‌کند. |
| MD | ارائه را در فرمت مارک‌داون ذخیره می‌کند |
| XML | ارائه را در فرمت PowerPoint XML Presentation ذخیره می‌کند. |
