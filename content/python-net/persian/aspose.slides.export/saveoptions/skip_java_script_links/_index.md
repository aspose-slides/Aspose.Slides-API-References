## skip_java_script_links ویژگی
مشخص می‌کند که آیا هنگام ذخیره ارائه، پیوندهای حاوی فراخوانی JavaScript نادیده گرفته شوند یا نه. 
            Read/write **bool**. مقدار پیش‌فرض **false** .


### توضیحات

هنگامی که این ویژگی به **true** تنظیم شود، پیوندهای حاوی فراخوانی JavaScript هنگام ذخیره‌سازی نادیده گرفته می‌شوند.

هنگامی که این ویژگی به **false** تنظیم شود، تمام پیوندها ذخیره می‌شوند.
