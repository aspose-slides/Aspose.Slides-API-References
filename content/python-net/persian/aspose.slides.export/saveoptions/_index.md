## SaveOptions کلاس

کلاس انتزاعی با گزینه‌هایی که نحوه ذخیره‌سازى ارائه را کنترل می‌کند.

نوع SaveOptions اعضای زیر را ارائه می‌دهد:

## ویژگی‌ها

| خصوصیت | توضیح |
| :- | :- |
| [`warning_callback`](/slides/python-net/fa/aspose.slides.export/saveoptions/warning_callback/) | برمی‌گرداند یا تنظیم می‌کند یک شیء که هشدارها را دریافت می‌کند و تصمیم می‌گیرد آیا فرایند بارگذاری ادامه یابد یا متوقف شود.<br/>            خواندن/نوشتن [`IWarningCallback`](/slides/python-net/fa/aspose.slides.warnings/iwarningcallback). |
| [`progress_callback`](/slides/python-net/fa/aspose.slides.export/saveoptions/progress_callback/) | یک شیء callback را برای به‌روزرسانی پیشرفت ذخیره‌سازی بر حسب درصد نشان می‌دهد.<br/>            مشاهده [`IProgressCallback`](/slides/python-net/fa/aspose.slides/iprogresscallback). |
