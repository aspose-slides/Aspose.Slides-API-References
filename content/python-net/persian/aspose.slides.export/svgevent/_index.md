## شمارش SvgEvent

نمایانگر گزینه‌های شکل SVG.

نوع SvgEvent اعضای زیر را در دسترس قرار می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| ON_FOCUS_IN | وقوع می‌یابد زمانی که یک عنصر تمرکز دریافت می‌کند، مانند زمانی که متنی انتخاب می‌شود. |
| ON_FOCUS_OUT | وقوع می‌یابد زمانی که یک عنصر تمرکز خود را از دست می‌دهد، مانند زمانی که متنی انتخاب نشده می‌ماند. |
| ON_ACTIVATE | وقوع می‌یابد زمانی که یک عنصر فعال می‌شود، برای مثال، از طریق کلیک ماوس یا فشار کلید. |
| ON_CLICK | وقوع می‌یابد زمانی که دکمه دستگاه اشاره‌کننده بر روی یک عنصر کلیک می‌شود. |
| ON_MOUSE_DOWN | وقوع می‌یابد زمانی که دکمه دستگاه اشاره‌کننده بر روی یک عنصر فشار داده می‌شود. |
| ON_MOUSE_UP | وقوع می‌یابد زمانی که دکمه دستگاه اشاره‌کننده بر روی یک عنصر رها می‌شود. |
| ON_MOUSE_OVER | وقوع می‌یابد زمانی که دستگاه اشاره‌کننده به یک عنصر حرکت می‌کند. |
| ON_MOUSE_MOVE | وقوع می‌یابد زمانی که دستگاه اشاره‌کننده در حالی که بر روی یک عنصر است، حرکت می‌کند. |
| ON_MOUSE_OUT | وقوع می‌یابد زمانی که دستگاه اشاره‌کننده از یک عنصر دور می‌شود. |
| ON_LOAD | وقوع می‌یابد زمانی که عامل کاربری عنصر و فرزندان آن و تمام منابع ارجاع‌شده مورد نیاز برای رندر کردن آن را به‌طور کامل تجزیه کرده است. |
| ON_UNLOAD | وقوع می‌یابد زمانی که پیاده‌سازی DOM سندی را از یک پنجره یا فریم حذف می‌کند. فقط برای عناصر svg بیرونی قابل اعمال است. |
| ON_ABORT | وقوع می‌یابد زمانی که بارگذاری صفحه قبل از اینکه اجازه بارگذاری کامل یک عنصر داده شود، متوقف می‌شود. |
| ON_ERROR | وقوع می‌یابد زمانی که یک عنصر به‌درستی بارگذاری نمی‌شود یا هنگام اجرای اسکریپت خطایی رخ می‌دهد. |
| ON_RESIZE | وقوع می‌یابد زمانی که نمای سند در حال تغییر اندازه است. فقط برای عناصر svg بیرونی قابل اعمال است. |
| ON_SCROLL | وقوع می‌یابد زمانی که نمای سند به‌طور افقی یا عمودی (یا هر دو) جابه‌جا می‌شود. فقط برای عناصر svg بیرونی قابل اعمال است. |
| ON_ZOOM | وقوع می‌یابد زمانی که سطح زوم نمای سند تغییر می‌کند. فقط برای عناصر svg بیرونی قابل اعمال است. |
| ON_BEGIN | وقوع می‌یابد زمانی که عنصر انیمیشن آغاز می‌شود. |
| ON_END | وقوع می‌یابد زمانی که عنصر انیمیشن پایان می‌یابد. |
| ON_REPEAT | وقوع می‌یابد زمانی که عنصر انیمیشن تکرار می‌شود. |
