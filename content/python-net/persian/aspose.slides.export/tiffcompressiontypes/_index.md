## TiffCompressionTypes enumeration

گزینه‌هایی را فراهم می‌کند که نحوه فشرده‌سازی یک ارائه در قالب TIFF را کنترل می‌کنند.

نوع TiffCompressionTypes اعضای زیر را افشا می‌کند:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| DEFAULT | طرح فشرده‌سازی پیش‌فرض (LZW) را مشخص می‌کند. |
| NONE | بدون فشرده‌سازی را مشخص می‌کند. |
| CCITT3 | طرح فشرده‌سازی CCITT3 را مشخص می‌کند. |
| CCITT4 | طرح فشرده‌سازی CCITT4 را مشخص می‌کند. |
| LZW | طرح فشرده‌سازی LZW (پیش‌فرض) را مشخص می‌کند. |
| RLE | طرح فشرده‌سازی RLE را مشخص می‌کند. |
