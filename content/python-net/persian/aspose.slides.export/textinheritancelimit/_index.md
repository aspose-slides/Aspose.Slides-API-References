## شمارش TextInheritanceLimit

عمق ارث‌بری ویژگی‌های متن را کنترل می‌کند.

نوع TextInheritanceLimit اعضای زیر را ارائه می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| ALL | تمام ویژگی‌های متن را به ارث می‌برد. |
| TEXT_BOX | فقط از استایل TextFrame به ارث می‌برد. |
| PARAGRAPH_ONLY | فقط از ویژگی‌های تعریف‌شده برای پاراگراف استفاده می‌کند. |
