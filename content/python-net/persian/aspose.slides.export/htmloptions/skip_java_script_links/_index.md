## ویژگی skip_java_script_links
مشخص می‌کند که آیا هنگام ذخیره‌سازی ارائه، لینک‌های فراخوانی JavaScript را حذف کند یا نه. 
            خواندنی/قابل نوشتن **bool**. مقدار پیش‌فرض **false** .


### توضیحات

هنگامی که این ویژگی به **true** , لینک‌های فراخوانی JavaScript هنگام ذخیره‌سازی نادیده گرفته می‌شوند.

هنگامی که این ویژگی به **false** , تمام لینک‌ها ذخیره می‌شوند.

    ...
