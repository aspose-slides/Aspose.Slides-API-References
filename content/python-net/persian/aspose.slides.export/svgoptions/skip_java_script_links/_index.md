## skip_java_script_links ویژگی
مشخص می‌کند که آیا هنگام ذخیرهٔ ارائه، پیوندهای ابرمتنی با فراخوانی‌های JavaScript را نادیده بگیرد یا خیر. 
            قابل خواندن/نوشتن **bool**. مقدار پیش‌فرض **false** است.

### توضیحات

زمانی که این ویژگی روی **true** تنظیم شود، پیوندهای ابرمتنی با فراخوانی‌های JavaScript در هنگام ذخیره نادیده گرفته می‌شوند.

زمانی که این ویژگی روی **false** تنظیم شود، تمام پیوندهای ابرمتنی ذخیره خواهند شد.
