## CompressionLevel شمارش

سطوح فشرده‌سازی ZIP را برای فایل OpenXML مشخص می‌کند.
سطوح بالاتر فشرده‌سازی بهتری را به قیمت پردازش کندتر ارائه می‌دهند.

نوع CompressionLevel اعضای زیر را در اختیار می‌گذارد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| NONE | هیچ فشرده‌سازی‌ای اعمال نمی‌شود. فایل‌ها به همان حالت ذخیره می‌شوند. |
| LEVEL1 | سریع‌ترین فشرده‌سازی با کم‌ترین نسبت فشرده‌سازی. |
| LEVEL2 | فشرده‌سازی سریع‌تر با نسبت فشرده‌سازی کمی بهتر نسبت به [`CompressionLevel.LEVEL1`](/slides/python-net/fa/aspose.slides.export/compressionlevel/LEVEL1). |
| LEVEL3 | فشرده‌سازی بهتری نسبت به [`CompressionLevel.LEVEL2`](/slides/python-net/fa/aspose.slides.export/compressionlevel/LEVEL2) با تأثیر متوسط بر عملکرد ارائه می‌دهد. |
| LEVEL4 | فشرده‌سازی بهتری نسبت به [`CompressionLevel.LEVEL3`](/slides/python-net/fa/aspose.slides.export/compressionlevel/LEVEL3) ارائه می‌دهد. |
| LEVEL5 | فشرده‌سازی بهبود یافته نسبت به [`CompressionLevel.LEVEL4`](/slides/python-net/fa/aspose.slides.export/compressionlevel/LEVEL4) با زمان پردازش اضافی فراهم می‌کند. |
| LEVEL6 | فشرده‌سازی استاندارد، تعادلی خوب بین سرعت فشرده‌سازی و حجم فایل ارائه می‌دهد.<br/>            سطح فشرده‌سازی پیش‌فرض. |
| LEVEL7 | فشرده‌سازی بالاتر نسبت به [`CompressionLevel.LEVEL6`](/slides/python-net/fa/aspose.slides.export/compressionlevel/LEVEL6) با پردازش کندتر فراهم می‌کند. |
| LEVEL8 | فشرده‌سازی بالاتر نسبت به [`CompressionLevel.LEVEL7`](/slides/python-net/fa/aspose.slides.export/compressionlevel/LEVEL7) فراهم می‌کند. |
| LEVEL9 | فشرده‌سازی حداکثری. کوچک‌ترین حجم فایل را با کندترین سرعت پردازش تولید می‌کند. |
