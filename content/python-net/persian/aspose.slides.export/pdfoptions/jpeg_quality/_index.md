## jpeg_quality ویژگی
مقداری را برمی‌گرداند یا تنظیم می‌کند که کیفیت تصاویر JPEG داخل سند PDF را تعیین می‌کند.
            خواندن/نوشتن **int**.


### ملاحظات

فقط زمانی اثر دارد که یک سند شامل تصاویر JPEG باشد.


از این ویژگی برای دریافت یا تنظیم کیفیت تصاویر داخل یک سند هنگام ذخیره به فرمت PDF استفاده کنید.
            مقدار می‌تواند از 0 تا 100 باشد که 0 به معنای پایین‌ترین کیفیت اما بیشترین فشرده‌سازی و 100 به معنای بهترین کیفیت اما کمترین فشرده‌سازی است.


مقدار پیش‌فرض **100** است.
