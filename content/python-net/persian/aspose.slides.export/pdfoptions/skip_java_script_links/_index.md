## skip_java_script_links property
مشخص می‌کند آیا پیوندهای فراگیر با فراخوانی‌های جاوااسکریپت هنگام ذخیره‌سازی ارائه‌نامه نادیده گرفته شوند یا نه. 
            خواندنی/نوشتنی **bool**. مقدار پیش‌فرض **false** .


### توضیحات

زمانی که این خصوصیت به **true** تنظیم شود، پیوندهای فراگیر با فراخوانی‌های جاوااسکریپت هنگام ذخیره‌سازی نادیده گرفته می‌شوند.


زمانی که این خصوصیت به **false** تنظیم شود، تمام پیوندهای فراگیر ذخیره خواهند شد.
