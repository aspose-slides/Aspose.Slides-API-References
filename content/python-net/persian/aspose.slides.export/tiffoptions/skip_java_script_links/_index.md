## skip_java_script_links ویژگی
مشخص می‌کند آیا هنگام ذخیره‌سازی ارائه، پیوندهای فراسرایی با فراخوانی‌های جاوااسکریپت نادیده گرفته شوند. 
            خواندنی/نوشتنی **bool**. مقدار پیش‌فرض **false** .


### توضیحات

زمانی که این ویژگی به **true** تنظیم شود، پیوندهای فراسرایی با فراخوانی‌های جاوااسکریپت هنگام ذخیره‌سازی نادیده گرفته می‌شوند.


زمانی که این ویژگی به **false** تنظیم شود، تمام پیوندهای فراسرایی ذخیره می‌شوند.
