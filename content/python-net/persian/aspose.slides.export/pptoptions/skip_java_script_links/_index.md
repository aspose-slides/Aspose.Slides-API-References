## skip_java_script_links ویژگی
Specifies whether to skip hyperlinks with JavaScript calls when saving the presentation. 
            Read/write **bool**. The default value is **false** .


### توضیحات

When this feature is set to **true** , hyperlinks with JavaScript calls will be ignored while saving.
هنگامی که این ویژگی روی **false** , تمام پیوندهای ابرمتنی ذخیره می‌شوند.
