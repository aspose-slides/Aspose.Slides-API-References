## skip_java_script_links property
مشخص می‌کند که آیا هنگام ذخیره‌سازی ارائه، پیوندهای هیپرمتنی با فراخوانی‌های جاوااسکریپت را نادیده بگیرد یا نه. 
            خواندن/نوشتن **bool**. مقدار پیش‌فرض **false** است.


### توضیحات

وقتی این ویژگی به **true** تنظیم شود، پیوندهای هیپرمتنی با فراخوانی‌های جاوااسکریپت در حین ذخیره‌سازی نادیده گرفته می‌شوند.


وقتی این ویژگی به **false** تنظیم شود، تمام پیوندهای هیپرمتنی ذخیره می‌شوند.
