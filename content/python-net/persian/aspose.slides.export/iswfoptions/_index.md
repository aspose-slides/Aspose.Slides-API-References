## ISwfOptions کلاس

گزینه‌هایی را فراهم می‌کند که نحوه ذخیره‌سازی ارائه در قالب SWF را کنترل می‌کند.

نوع ISwfOptions اعضای زیر را نمایش می‌دهد:

## ویژگی‌ها

| ویژگی | توضیح |
| :- | :- |
| [`compressed`](/slides/python-net/fa/aspose.slides.export/iswfoptions/compressed/) | مشخص می‌کند که سند SWF تولید شده باید فشرده شود یا نه.<br/> پیش‌فرض `true` است. |
| [`viewer_included`](/slides/python-net/fa/aspose.slides.export/iswfoptions/viewer_included/) | مشخص می‌کند که سند SWF تولید شده باید مرورگر سند یکپارچه را شامل شود یا نه.<br/> پیش‌فرض `true` است. |
| [`show_page_border`](/slides/python-net/fa/aspose.slides.export/iswfoptions/show_page_border/) | مشخص می‌کند که حاشیهٔ اطراف صفحات نمایش داده شود یا نه. پیش‌فرض true است. |
| [`show_hidden_slides`](/slides/python-net/fa/aspose.slides.export/iswfoptions/show_hidden_slides/) | مشخص می‌کند که سند تولید شده اسلایدهای مخفی را شامل شود یا نه.<br/> پیش‌فرض `false` است. |
| [`show_full_screen`](/slides/python-net/fa/aspose.slides.export/iswfoptions/show_full_screen/) | دکمهٔ تمام‌صفحه را نشان/پنهان می‌کند. می‌توان آن را در flashvars بازنویسی کرد. پیش‌فرض true است. |
| [`show_page_stepper`](/slides/python-net/fa/aspose.slides.export/iswfoptions/show_page_stepper/) | دستگیرهٔ صفحه را نشان/پنهان می‌کند. می‌توان آن را در flashvars بازنویسی کرد. پیش‌فرض true است. |
| [`show_search`](/slides/python-net/fa/aspose.slides.export/iswfoptions/show_search/) | بخش جستجو را نشان/پنهان می‌کند. می‌توان آن را در flashvars بازنویسی کرد. پیش‌فرض true است. |
| [`show_top_pane`](/slides/python-net/fa/aspose.slides.export/iswfoptions/show_top_pane/) | کل پنل بالا را نشان/پنهان می‌کند. می‌توان آن را در flashvars بازنویسی کرد. پیش‌فرض true است. |
| [`show_bottom_pane`](/slides/python-net/fa/aspose.slides.export/iswfoptions/show_bottom_pane/) | پنل پایین را نشان/پنهان می‌کند. می‌توان آن را در flashvars بازنویسی کرد. پیش‌فرض true است. |
| [`show_left_pane`](/slides/python-net/fa/aspose.slides.export/iswfoptions/show_left_pane/) | پنل چپ را نشان/پنهان می‌کند. می‌توان آن را در flashvars بازنویسی کرد. پیش‌فرض true است. |
| [`start_open_left_pane`](/slides/python-net/fa/aspose.slides.export/iswfoptions/start_open_left_pane/) | با پنل چپ باز شروع می‌شود. می‌توان آن را در flashvars بازنویسی کرد. پیش‌فرض false است. |
| [`enable_context_menu`](/slides/python-net/fa/aspose.slides.export/iswfoptions/enable_context_menu/) | منوی زمینه را فعال/غیرفعال می‌کند. پیش‌فرض true است. |
| [`logo_image_bytes`](/slides/python-net/fa/aspose.slides.export/iswfoptions/logo_image_bytes/) | تصویری که به‌عنوان لوگو در گوشهٔ بالا-راست نمایش‌دهنده نمایش داده می‌شود.<br/> تصویر باید به صورت PNG با ابعاد 32x64 پیکسل باشد، در غیر این صورت ممکن است لوگو به‌درستی نمایش داده نشود. |
| [`logo_link`](/slides/python-net/fa/aspose.slides.export/iswfoptions/logo_link/) | آدرس کامل ابرلینک لوگو را می‌گیرد یا تنظیم می‌کند.<br/> فقط در صورتی که یک [`ISwfOptions.logo_image_bytes`](/slides/python-net/fa/aspose.slides.export/iswfoptions/logo_image_bytes) مشخص شده باشد مؤثر است. |
| [`jpeg_quality`](/slides/python-net/fa/aspose.slides.export/iswfoptions/jpeg_quality/) | کیفیت تصاویر JPEG را مشخص می‌کند.<br/> پیش‌فرض 95 است. |
| [`slides_layout_options`](/slides/python-net/fa/aspose.slides.export/iswfoptions/slides_layout_options/) | حالت قرارگیری اسلایدها روی صفحه هنگام استخراج یک ارائه [`ISlidesLayoutOptions`](/slides/python-net/fa/aspose.slides.export/islideslayoutoptions) را می‌گیرد یا تنظیم می‌کند.<br/> این ویژگی از اختصاص اشیائی از نوع `Aspose.Slides.Export.HandoutLayoutingOptions` پشتیبانی نمی‌کند. |
