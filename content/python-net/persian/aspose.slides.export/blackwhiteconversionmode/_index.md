## BlackWhiteConversionMode شمارش

گزینه‌هایی را ارائه می‌دهد که نحوه تبدیل تصاویر اسلایدها به تصاویر دو رنگی را کنترل می‌کند.

نوع BlackWhiteConversionMode اعضای زیر را ارائه می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| DEFAULT | الگوریتم تبدیلی را مشخص نمی‌کند. الگوریتم پیاده‌سازی‌شده در کدک TIFF استفاده خواهد شد. (پیش‌فرض) |
| DITHERING | الگوریتم دی‌درینگ (Floyd-Steinberg) را مشخص می‌کند. |
| DITHERING_FLOYD_STEINBERG | الگوریتم دی‌درینگ Floyd-Steinberg را مشخص می‌کند. |
| AUTO | الگوریتم آستانه‌گذاری به‌صورت خودکار محاسبه‌شده (Otsu) را مشخص می‌کند. |
| AUTO_OTSU | الگوریتم آستانه‌گذاری Otsu به‌صورت خودکار محاسبه‌شده را مشخص می‌کند. |
| THRESHOLD25 | الگوریتم آستانه‌گذاری ثابت (۲۵٪) را مشخص می‌کند. |
| THRESHOLD50 | الگوریتم آستانه‌گذاری ثابت (۵۰٪) را مشخص می‌کند. |
| THRESHOLD75 | الگوریتم آستانه‌گذاری ثابت (۷۵٪) را مشخص می‌کند. |
