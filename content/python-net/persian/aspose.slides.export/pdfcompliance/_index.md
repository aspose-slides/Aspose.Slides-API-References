## PdfCompliance شمارش

ثابت‌هایی که سطح انطباق با استانداردهای PDF را تعریف می‌کنند.

نوع PdfCompliance اعضای زیر را ارائه می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| PDF15 | فایل خروجی با استاندارد PDF 1.5 سازگار خواهد بود. |
| PDF16 | فایل خروجی با استاندارد PDF 1.6 سازگار خواهد بود. |
| PDF17 | فایل خروجی با استاندارد PDF 1.7 سازگار خواهد بود. |
| PDF_A1B | فایل خروجی با استاندارد PDF/A-1b سازگار خواهد بود. |
| PDF_A1A | فایل خروجی با استاندارد PDF/A-1a سازگار خواهد بود. |
| PDF_A2B | فایل خروجی با استاندارد PDF/A-2b سازگار خواهد بود. |
| PDF_A2A | فایل خروجی با استاندارد PDF/A-2a سازگار خواهد بود. |
| PDF_A3B | فایل خروجی با استاندارد PDF/A-3b سازگار خواهد بود. |
| PDF_A3A | فایل خروجی با استاندارد PDF/A-3a سازگار خواهد بود. |
| PDF_UA | فایل خروجی با استاندارد PDF/UA سازگار خواهد بود. |
| PDF_A2U | فایل خروجی با استاندارد PDF/A-2u سازگار خواهد بود. |
