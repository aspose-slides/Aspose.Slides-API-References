## ویژگی skip_java_script_links
مشخص می‌کند که آیا هنگام ذخیره‌سازی ارائه، لینک‌های هیپرمتنی با فراخوانی‌های JavaScript رد شوند یا خیر. 
            خواندن/نوشتن **bool**. مقدار پیش‌فرض **false** .


### توضیحات

When this property is set to **true** , لینک‌های هیپرمتنی با فراخوانی‌های JavaScript هنگام ذخیره‌سازی نادیده گرفته می‌شوند.

When this property is set to **false** , تمام لینک‌های هیپرمتنی ذخیره خواهند شد.
