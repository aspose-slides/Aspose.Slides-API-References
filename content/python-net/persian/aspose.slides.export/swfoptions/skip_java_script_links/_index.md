## skip_java_script_links خاصیت
مشخص می‌کند که آیا هنگام ذخیره‌سازی ارائه، لینک‌های حاوی فراخوانی‌های JavaScript نادیده گرفته شوند یا نه.  
قابل خواندن/قابل نوشتن **bool**. مقدار پیش‌فرض **false** است.

### Remarks

زمانی که این خاصیت روی **true** تنظیم شود، لینک‌های حاوی فراخوانی‌های JavaScript در هنگام ذخیره‌سازی نادیده گرفته می‌شوند.

زمانی که این خاصیت روی **false** تنظیم شود، تمام لینک‌ها ذخیره می‌شوند.
