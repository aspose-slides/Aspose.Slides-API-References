## jpeg_quality ویژگی
Returns or sets a value determining the quality of the JPEG images inside PDF document.
            خواندنی/نوشتنی **int**.

### توضیحات

فقط زمانی مؤثر است که سند شامل تصاویر JPEG باشد.

از این ویژگی برای دریافت یا تنظیم کیفیت تصاویر داخل سند هنگام ذخیره در قالب PDF استفاده کنید.
            مقدار می‌تواند بین 0 تا 100 باشد که در آن 0 به معنای بدترین کیفیت اما بیشترین فشرده‌سازی و 100 به معنای بهترین کیفیت اما کمترین فشرده‌سازی است.

مقدار پیش‌فرض **100** است.
