## embed_true_type_fonts_for_ascii ویژگی
درست برای تعبیهٔ قلم‌های TrueType برای کاراکترهای ASCII 32-127.
            قلم‌ها برای کدهای کاراکتری بیش از 127 همیشه تعبیه می‌شوند.
            خواندن/نوشتن **bool**.

### توضیحات

پیش‌فرض **true** است.
