## skip_java_script_links ویژگی
مشخص می‌کند که آیا هنگام ذخیره‌سازی ارائه، پیوندهای حاوی فراخوانی‌های JavaScript نادیده گرفته شوند یا نه. 
            خواندن/نوشتن **bool**. مقدار پیش‌فرض **false** است.

### توضیحات

زمانی که این ویژگی به **true** , تنظیم شود، پیوندهای فراخوانی JavaScript هنگام ذخیره‌سازی نادیده گرفته می‌شوند.

زمانی که این ویژگی به **false** , تنظیم شود، تمام پیوندها ذخیره می‌شوند.

    ...
