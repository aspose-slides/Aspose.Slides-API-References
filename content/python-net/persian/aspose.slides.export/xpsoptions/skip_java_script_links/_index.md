## skip_java_script_links ویژگی
مشخص می‌کند که آیا هنگام ذخیرهٔ ارائه، پیوندهای ابرمتنی با فراخوانی‌های JavaScript را نادیده بگیرد. 
            قابل خواندن/نوشتن **bool**. مقدار پیش‌فرض **false** .


### تذکرات

هنگامی که این ویژگی روی **true** , پیوندهای ابرمتنی با فراخوانی‌های JavaScript هنگام ذخیره نادیده گرفته می‌شوند.


هنگامی که این ویژگی روی **false** , تمام پیوندهای ابرمتنی ذخیره می‌شوند.

    ...
