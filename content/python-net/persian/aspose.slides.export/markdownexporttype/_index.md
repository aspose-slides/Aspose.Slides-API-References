## نوع شمارشی MarkdownExportType

نوع رندر سند.

نوع MarkdownExportType اعضای زیر را نمایان می‌کند:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| SEQUENTIAL | تمام آیتم‌ها را به‌صورت جداگانه رندر می‌کند. یکی پس از دیگری. |
| TEXT_ONLY | فقط متن را رندر می‌کند. |
| VISUAL | تمام آیتم‌ها را رندر می‌کند، آیتم‌های گروه‌بندی‌شده را به‌صورت یکجا رندر می‌کند. |
