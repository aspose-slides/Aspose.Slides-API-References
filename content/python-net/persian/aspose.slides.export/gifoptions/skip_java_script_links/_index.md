## skip_java_script_links ویژگی
مشخص می‌کند که آیا هنگام ذخیره‌سازی ارائه، پیوندهای دارای فراخوانی‌های JavaScript را نادیده بگیرد یا خیر.  
خواندن/نوشتن **bool**. مقدار پیش‌فرض **false** است.

### توضیحات

زمانی که این ویژگی روی **true** تنظیم شود، پیوندهای دارای فراخوانی‌های JavaScript در حین ذخیره‌سازی نادیده گرفته می‌شوند.

زمانی که این ویژگی روی **false** تنظیم شود، تمام پیوندها ذخیره می‌شوند.

def skip_java_script_links(self):
    ...

    ...
