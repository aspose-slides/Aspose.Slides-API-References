## PicturesCompression نماد

نمایانگر سطح فشرده‌سازی تصاویر

نوع PicturesCompression موارد زیر را در اختیار می‌گذارد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| DPI330 | کیفیت خوبی برای نمایشگرهای با وضوح بالا (HD) |
| DPI220 | کیفیت عالی در اکثر پرینترها و صفحه‌نمایش‌ها |
| DPI150 | مناسب برای صفحات وب و پروژکتورها |
| DPI96 | حداقل‌سازی حجم سند برای به‌اشتراک‌گذاری |
| DPI72 | سطح فشرده‌سازی پیش‌فرض |
| DOCUMENT_RESOLUTION | از وضوح سند استفاده کنید - تصویر فشرده نمی‌شود و به همان صورت در سند استفاده می‌شود |
