## ویژگی skip_java_script_links
مشخص می‌کند که آیا هنگام ذخیره‌سازی ارائه، لینک‌های فراخوانی جاوااسکریپت را نادیده بگیرد یا نه. 
            خواندنی/نوشتنی **bool**. مقدار پیش‌فرض **false** .

### توضیحات

زمانی که این ویژگی روی **true** تنظیم شود، لینک‌های دارای فراخوانی جاوااسکریپت هنگام ذخیره‌سازی نادیده گرفته می‌شوند.

زمانی که این ویژگی روی **false** تنظیم شود، تمام لینک‌ها ذخیره می‌شوند.
