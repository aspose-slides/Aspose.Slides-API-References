## ویژگی y
دریافت یا تنظیم مختصات y گوشه بالایی-چپ شکل، به واحد نقطه.
            خواند/نوشت **float**.


### توضیحات

مقدار برگردانده‌شده همیشه تعریف شده است و هرگز **float** نیست.
            مقدار اختصاص داده‌شده نیز باید تعریف شده باشد؛ فقط **float** را به ویژگی‌های یک نمونه `RawFrame` اختصاص دهید.

### تعریف:
```python
@property
def y(self):
    ...

@y.setter
def y(self, value):
    ...
```
