## ویژگی width
دریافت یا تنظیم width شکل، بر حسب نقطه.
خواندن/نوشتن **float**.

### توضیحات

مقدار اختصاص داده شده نیز باید تعریف شده باشد؛ **float** را فقط به ویژگی‌های یک نمونه `RawFrame` اختصاص دهید.
