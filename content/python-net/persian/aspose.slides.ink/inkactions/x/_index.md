## x ویژگی
مختصات x گوشه بالا-چپ شکل را که بر حسب نقاط اندازه‌گیری می‌شود، دریافت یا تنظیم می‌کند.
خواندن/نوشتن **float**.

### توضیحات

مقداری که برگردانده می‌شود همیشه تعریف‌شده است و هرگز **float** نیست.
مقداری که اختصاص داده می‌شود نیز باید تعریف‌شده باشد؛ **float** را فقط به ویژگی‌های یک نمونه `RawFrame` اختصاص دهید.

### تعریف:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
