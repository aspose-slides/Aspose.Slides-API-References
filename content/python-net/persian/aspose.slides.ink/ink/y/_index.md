## ویژگی y
مختصات y گوشه بالای سمت چپ شکل را که بر حسب نقاط اندازه‌گیری می‌شود، دریافت یا تنظیم می‌کند.
            خواندنی/نوشتنی **float**.

### ملاحظات

مقداری که برگردانده می‌شود همیشه تعریف‌شده است و هرگز **float** نیست.
            مقداری که اختصاص داده می‌شود نیز باید تعریف‌شده باشد؛ فقط **float** را به ویژگی‌های یک شیء `RawFrame` اختصاص دهید.

### تعریف:
```python
@property
def y(self):
    ...

@y.setter
def y(self, value):
    ...
```
