## InkEffectType شمارش

مجموعه‌ای از افکت‌های تصویری پیش‌تعریف‌شده برای رندر جوهر را مشخص می‌کند.  
هر افکت متناظر با یک بافت یا تصویر است که ظاهر جوهر سبک‌شده را شبیه‌سازی می‌کند.  
این مقادیر می‌توانند برای سفارشی‌سازی سبک بصری خطوط دیجیتالی جوهر در زمان رندر استفاده شوند.

The InkEffectType type exposes the following members:

| BRONZE | بافت فلزی گرم و قهوه‌ای‌رنگ که شبیه جوهر برنزی است. |
