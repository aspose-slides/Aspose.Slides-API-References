## InkTrace کلاس

یک شیء Trace را نشان می‌دهد.
            یک عنصر Trace برای ضبط داده‌های ضبط شده توسط دیجیتایزر استفاده می‌شود. 
            این شامل یک توالی از نقاط است که بر اساس مشخصات داده شده توسط شیء InkTraceFormat رمزگذاری شده است.
