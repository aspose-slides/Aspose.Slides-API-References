## ویژگی x
مختصات x گوشه بالا-چپ شکل را می‌گیرد یا تنظیم می‌کند و به پوینت اندازه‌گیری می‌شود.
خواندن/نوشتن **float**.

### توضیحات

مقدار برگشتی همیشه تعریف‌شده است و هرگز **float** نیست.
مقدار اختصاص داده‌شده نیز باید تعریف‌شده باشد؛ **float** را فقط به ویژگی‌های یک نمونه `RawFrame` اختصاص دهید.

### تعریف:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
