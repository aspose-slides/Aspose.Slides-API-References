## y ویژگی
مقدار y-مختصات گوشهٔ بالا-چپ شکل را دریافت یا تنظیم می‌کند، که بر حسب نقطه اندازه‌گیری می‌شود.
خواندن/نوشتن **float**.

### یادداشت‌ها

مقدار بازگردانده‌شده همیشه تعریف‌شده است و هرگز **float** نیست.
مقدار اختصاص‌یافته نیز باید تعریف‌شده باشد؛ **float** را فقط به ویژگی‌های یک نمونهٔ `RawFrame` اختصاص دهید.

### تعریف:
```python
@property
def y(self):
    ...

@y.setter
def y(self, value):
    ...
```
