## width ویژگی
دریافت یا تنظیم width شکل، که بر حسب نقطه اندازه‌گیری می‌شود.
            خواندنی/نوشتنی **float**.


### توضیحات

مقدار بازگشت‌شده همیشه تعریف‌شده است و هیچ‌وقت **float** نیست.
            مقدار تخصیص‌داده‌شده نیز باید تعریف‌شده باشد؛ **float** را فقط به ویژگی‌های یک نمونه `RawFrame` اختصاص دهید.
