## x خاصیت
مختصات x گوشه‌ی بالا-چپ شکل را می‌گیرد یا تنظیم می‌کند، که بر حسب نقاط اندازه‌گیری می‌شود.
            خواندنی/نوشتنی **float**.


### توضیحات

مقدار بازگشتی همواره تعریف‌شده است و هرگز **float** نیست.
            مقدار اختصاص داده‌شده نیز باید تعریف‌شده باشد؛ فقط **float** را به خصوصیات یک نمونه‌ی `RawFrame` اختصاص دهید.

### تعریف:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
