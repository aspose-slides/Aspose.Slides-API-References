## IVbaProject کلاس

نمایانگر پروژه VBA با ماکروهای ارائه است.

نوع IVbaProject اعضای زیر را ارائه می‌دهد:

## خواص

| ویژگی | شرح |
| :- | :- |
| [`name`](/slides/python-net/fa/aspose.slides.vba/ivbaproject/name/) | نام پروژه VBA را برمی‌گرداند.<br/>            فقط-خواندنی **str**. |
| [`modules`](/slides/python-net/fa/aspose.slides.vba/ivbaproject/modules/) | فهرست تمام ماژول‌هایی که در پروژه VBA گنجانده شده‌اند را برمی‌گرداند.<br/>            فقط-خواندنی [`IVbaModuleCollection`](/slides/python-net/fa/aspose.slides.vba/ivbamodulecollection). |
| [`references`](/slides/python-net/fa/aspose.slides.vba/ivbaproject/references/) | فهرست تمام مراجع که در پروژه VBA گنجانده شده‌اند را برمی‌گرداند.<br/>            فقط-خواندنی [`IVbaReferenceCollection`](/slides/python-net/fa/aspose.slides.vba/ivbareferencecollection). |
| [`is_password_protected`](/slides/python-net/fa/aspose.slides.vba/ivbaproject/is_password_protected/) | نشان می‌دهد آیا VBAProject توسط رمز عبور برای مشاهده ویژگی‌های پروژه محافظت شده است یا خیر.<br/>            فقط-خواندنی **bool**. |
