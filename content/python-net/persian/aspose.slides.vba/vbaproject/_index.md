## VbaProject کلاس

نمایانگر پروژه VBA با ماکروهای ارائه.

نوع VbaProject اعضای زیر را در اختیار می‌گذارد:

## سازنده‌ها

| سازنده | توضیح |
| :- | :- |
| [`__init__(self)`](/slides/python-net/fa/aspose.slides.vba/vbaproject/__init__/#) | این سازنده یک پروژه VBA جدید را از ابتدا ایجاد می‌کند.<br/>            پروژه در صفحه کد 1252 Windows Latin 1 (ANSI) ایجاد خواهد شد |
| [`__init__(self, data)`](/slides/python-net/fa/aspose.slides.vba/vbaproject/__init__/#bytes) | این سازنده پروژه VBA را از نمایش باینری محفظه OLE بارگذاری می‌کند. |
