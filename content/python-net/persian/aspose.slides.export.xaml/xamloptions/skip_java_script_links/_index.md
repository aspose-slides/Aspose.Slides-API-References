## ویژگی skip_java_script_links
مشخص می‌کند آیا هنگام ذخیره‌سازی ارائه، پیوندهای حاوی فراخوانی‌های JavaScript نادیده گرفته شوند یا خیر.
            خواندن/نوشتن **bool**. مقدار پیش‌فرض **false** است.

### توضیحات

زمانی که این ویژگی روی **true** تنظیم شود، پیوندهای حاوی فراخوانی‌های JavaScript هنگام ذخیره‌سازی نادیده گرفته می‌شوند.

زمانی که این ویژگی روی **false** تنظیم شود، تمام پیوندها ذخیره می‌شوند.
