## MasterTheme کلاس

نمایانگر یک تم اصلی.

**Inheritance:**[`MasterTheme`](/slides/python-net/fa/aspose.slides.theme/mastertheme) → [`Theme`](/slides/python-net/fa/aspose.slides.theme/theme)

نوع MasterTheme اعضای زیر را نمایش می‌دهد:

## ویژگی‌ها

| ویژگی | توضیح |
| :- | :- |
| [`color_scheme`](/slides/python-net/fa/aspose.slides.theme/mastertheme/color_scheme/) | طرح رنگ را برمی‌گرداند.<br/>            فقط خواندنی [`IColorScheme`](/slides/python-net/fa/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/fa/aspose.slides.theme/mastertheme/font_scheme/) | طرح قلم را برمی‌گرداند.<br/>            فقط خواندنی [`IFontScheme`](/slides/python-net/fa/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/fa/aspose.slides.theme/mastertheme/format_scheme/) | طرح قالب شکل را برمی‌گرداند.<br/>            فقط خواندنی [`IFormatScheme`](/slides/python-net/fa/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/fa/aspose.slides.theme/mastertheme/presentation/) | ارائه والد را برمی‌گرداند.<br/>            فقط خواندنی [`IPresentation`](/slides/python-net/fa/aspose.slides/ipresentation). |
| [`extra_color_schemes`](/slides/python-net/fa/aspose.slides.theme/mastertheme/extra_color_schemes/) | مجموعه‌ای از طرح‌های رنگی اضافه را برمی‌گرداند.<br/>            این طرح‌ها بر ظاهر ارائه تأثیری ندارند، می‌توان آنها را به‌عنوان طرح رنگ اصلی برای یک اسلاید انتخاب کرد.<br/>            فقط خواندنی [`IExtraColorSchemeCollection`](/slides/python-net/fa/aspose.slides.theme/iextracolorschemecollection). |
| [`name`](/slides/python-net/fa/aspose.slides.theme/mastertheme/name/) | نام یک تم را برمی‌گرداند.<br/>            قابل خواندن/نوشتن **str**. |
