## FontScheme کلاس

فونت‌های تعریف‌شده توسط تم را ذخیره می‌کند.

نوع FontScheme اعضای زیر را در اختیار می‌گذارد:

## ویژگی‌ها

| ویژگی | توضیح |
| :- | :- |
| [`minor`](/slides/python-net/fa/aspose.slides.theme/fontscheme/minor/) | مجموعهٔ فونت‌ها را برای بخش "body" اسلاید برمی‌گرداند.<br/>            فقط خواندنی [`IFonts`](/slides/python-net/fa/aspose.slides/ifonts). |
| [`major`](/slides/python-net/fa/aspose.slides.theme/fontscheme/major/) | مجموعهٔ فونت‌ها را برای بخش "heading" اسلاید برمی‌گرداند.<br/>            فقط خواندنی [`IFonts`](/slides/python-net/fa/aspose.slides/ifonts). |
| [`name`](/slides/python-net/fa/aspose.slides.theme/fontscheme/name/) | نام طرح فونت را برمی‌گرداند.<br/>            خواندنی/نوشتنی **str**. |
