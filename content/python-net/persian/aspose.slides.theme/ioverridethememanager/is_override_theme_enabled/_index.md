## is_override_theme_enabled ویژگی
تعیین می‌کند که آیا OverrideTheme تم مؤثر به ارث‌برده را بازنویسی می‌کند یا خیر.
برای فعال‌سازی OverrideTheme برای بازنویسی از روش‌های OverrideTheme.Init*() استفاده کنید.
برای غیرفعال کردن OverrideTheme از بازنویسی از روش OverrideTheme.Clear() استفاده کنید.
فقط-خواندنی **bool**.
