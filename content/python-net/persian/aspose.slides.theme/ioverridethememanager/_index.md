## IOverrideThemeManager کلاس

دسترسی به انواع مختلف تم‌های بازنویسی‌شده را فراهم می‌کند.

نوع IOverrideThemeManager اعضای زیر را در معرض نمایش می‌گذارد:

## خواص

| ویژگی | توضیح |
| :- | :- |
| [`is_override_theme_enabled`](/slides/python-net/fa/aspose.slides.theme/ioverridethememanager/is_override_theme_enabled/) | تعیین می‌کند که آیا OverrideTheme تم مؤثر ارث‌براده را بازنویسی می‌کند یا خیر.<br/>            برای فعال‌سازی OverrideTheme برای بازنویسی، از متدهای OverrideTheme.Init*() استفاده کنید.<br/>            برای غیرفعال‌سازی OverrideTheme از بازنویسی، از متد OverrideTheme.Clear() استفاده کنید.<br/>            فقط خواندنی **bool**. |
| [`override_theme`](/slides/python-net/fa/aspose.slides.theme/ioverridethememanager/override_theme/) | شیء تم بازنویسی‌شده را برمی‌گرداند.<br/>            قابلیت خواندن/نوشتن [`IOverrideTheme`](/slides/python-net/fa/aspose.slides.theme/ioverridetheme). |
