## is_override_theme_enabled ویژگی
مشخص می‌کند آیا OverrideTheme تم مؤثر وراثت‌پذیر را بازنویسی می‌کند یا نه.
            برای فعال کردن OverrideTheme برای بازنویسی از متدهای OverrideTheme.Init*() استفاده کنید.
            برای غیرفعال کردن OverrideTheme از بازنویسی، از متد OverrideTheme.Clear() استفاده کنید.
            فقط-خواندنی **bool**.
