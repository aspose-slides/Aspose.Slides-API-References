## is_override_theme_enabled ویژگی
تعیین می‌کند که آیا OverrideTheme تم مؤثر به‌ارث‌برنده را بازنویسی می‌کند یا نه.
            برای فعال‌سازی OverrideTheme برای بازنویسی از متدهای OverrideTheme.Init*() استفاده کنید.
            برای غیرفعال‌سازی OverrideTheme از بازنویسی، از متد OverrideTheme.Clear() استفاده کنید.
            فقط‌خواندنی **bool**.
