## init_format_scheme_from(self, format_scheme) {#iformatscheme}
FormatScheme را با شیء جدیدی برای بازنویسی FormatScheme تم ارث‌برده (InheritedTheme) مقداردهی اولیه می‌کند.

```python
def init_format_scheme_from(self, format_scheme):
    ...
```

| پارامتر | نوع | توضیح |
| :- | :- | :- |
| format_scheme | [`IFormatScheme`](/slides/python-net/fa/aspose.slides.theme/iformatscheme) | داده‌ای که برای مقداردهی اولیه استفاده می‌شود. |

### استثناها

| استثنا | توضیح |
| :- | :- |
| **RuntimeError(Proxy error(InvalidOperationException))** | اگر FormatScheme قبلاً مقداردهی اولیه شده باشد (نه None) پرتاب می‌شود. |
| **RuntimeError(Proxy error(ArgumentNullException))** | اگر پارامتر formatScheme مقدار None داشته باشد پرتاب می‌شود. |
