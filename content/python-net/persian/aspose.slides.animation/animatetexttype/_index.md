## AnimateTextType شمارش

نمایانگر نوع متن انیمیشن برای یک اثر انیمیشن است.

نوع AnimateTextType اعضای زیر را در اختیار دارد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| ALL_AT_ONCE | همه متن را یک‌باره انیمیت می‌کند. |
| BY_WORD | متن را بر حسب کلمه انیمیت می‌کند. |
| BY_LETTER | متن را بر حسب حرف انیمیت می‌کند. |
