## شمارش BuildType

نحوه نمایش متن بر روی یک شکل هنگام انیمیشن را تعیین می‌کند.

نوع BuildType اعضای زیر را ارائه می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| AS_ONE_OBJECT | با شکل حاوی. |
| ALL_PARAGRAPHS_AT_ONCE | تمام پاراگراف‌ها. |
| BY_LEVEL_PARAGRAPHS1 | بر اساس گروه‌های پاراگراف با عمق 1. |
| BY_LEVEL_PARAGRAPHS2 | بر اساس گروه‌های پاراگراف با عمق 2. |
| BY_LEVEL_PARAGRAPHS3 | بر اساس گروه‌های پاراگراف با عمق 3. |
| BY_LEVEL_PARAGRAPHS4 | بر اساس گروه‌های پاراگراف با عمق 4. |
| BY_LEVEL_PARAGRAPHS5 | بر اساس گروه‌های پاراگراف با عمق 5. |
