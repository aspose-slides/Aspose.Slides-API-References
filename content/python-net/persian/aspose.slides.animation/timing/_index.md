## کلاس Timing

نمایانگر زمان‌بندی انیمیشن.

نوع Timing موارد زیر را ارائه می‌دهد:

## ویژگی‌ها

| ویژگی | توضیح |
| :- | :- |
| [`accelerate`](/slides/python-net/fa/aspose.slides.animation/timing/accelerate/) | توصیف می‌کند درصد تأثیر رفتار تسریع در طول زمان را.<br/>            خواندن/نوشتن **float**. |
| [`decelerate`](/slides/python-net/fa/aspose.slides.animation/timing/decelerate/) | توصیف می‌کند درصد تأثیر رفتار کاهشی در طول زمان را.<br/>            خواندن/نوشتن **float**. |
| [`auto_reverse`](/slides/python-net/fa/aspose.slides.animation/timing/auto_reverse/) | توصیف می‌کند که آیا انیمیشن به‌صورت خودکار پس از<br/>            پخش آن در جهت جلو<br/>            خواندن/نوشتن **bool**. |
| [`duration`](/slides/python-net/fa/aspose.slides.animation/timing/duration/) | توصیف می‌کند مدت زمان اثر انیمیشن را.<br/>            خواندن/نوشتن **float**. |
| [`repeat_count`](/slides/python-net/fa/aspose.slides.animation/timing/repeat_count/) | توصیف می‌کند تعداد دفعاتی که اثر باید تکرار شود را.<br/>            خواندن/نوشتن **float**. |
| [`repeat_until_end_slide`](/slides/python-net/fa/aspose.slides.animation/timing/repeat_until_end_slide/) | این ویژگی مشخص می‌کند که آیا اثر تا انتهای اسلاید تکرار می‌شود یا خیر.<br/>            خواندن/نوشتن **bool**. |
| [`repeat_until_next_click`](/slides/python-net/fa/aspose.slides.animation/timing/repeat_until_next_click/) | این ویژگی مشخص می‌کند که آیا اثر تا کلیک بعدی تکرار می‌شود یا خیر.<br/>            خواندن/نوشتن **bool**. |
| [`repeat_duration`](/slides/python-net/fa/aspose.slides.animation/timing/repeat_duration/) | توصیف می‌کند تعداد دفعاتی که اثر باید تکرار شود را.<br/>            خواندن/نوشتن **float**. |
| [`restart`](/slides/python-net/fa/aspose.slides.animation/timing/restart/) | مشخص می‌کند که آیا اثر پس از کامل شدن باید دوباره راه‌اندازی شود یا نه.<br/>            خواندن/نوشتن [`EffectRestartType`](/slides/python-net/fa/aspose.slides.animation/effectrestarttype). |
| [`rewind`](/slides/python-net/fa/aspose.slides.animation/timing/rewind/) | این ویژگی مشخص می‌کند که آیا اثر پس از پخش کامل به عقب باز می‌گردد یا خیر.<br/>            خواندن/نوشتن **bool**. |
| [`speed`](/slides/python-net/fa/aspose.slides.animation/timing/speed/) | مشخص می‌کند درصدی که زمان‌بندی باید تسریع (یا کندی) شود را.<br/>            خواندن/نوشتن **float**. |
| [`trigger_delay_time`](/slides/python-net/fa/aspose.slides.animation/timing/trigger_delay_time/) | توصیف می‌کند زمان تأخیر پس از فعال‌ساز را.<br/>            خواندن/نوشتن **float**. |
