## AfterAnimationType شمارشی

نمایانگر نوع AfterAnimationType یک افکت انیمیشن است.

نوع AfterAnimationType اعضای زیر را ارائه می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| DO_NOT_DIM | پس از انیمیشن تار نشود. |
| COLOR | رنگ پس از انیمیشن. |
| HIDE_AFTER_ANIMATION | پس از انیمیشن مخفی شود |
| HIDE_ON_NEXT_MOUSE_CLICK | در کلیک ماوس بعدی پس از انیمیشن مخفی شود. |
