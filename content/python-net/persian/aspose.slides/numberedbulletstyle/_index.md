## NumberedBulletStyle شمارش

سبک بولت‌های شماره‌دار را نشان می‌دهد.

نوع NumberedBulletStyle اعضای زیر را در اختیار می‌گذارد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| NOT_DEFINED | تعریف نشده. |
| BULLET_ALPHA_LC_PERIOD | حروف الفبای کوچک با نقطه. مثال: a., b., c., ... |
| BULLET_ALPHA_UC_PERIOD | حروف الفبای بزرگ با نقطه. مثال: A., B., C., ... |
| BULLET_ARABIC_PAREN_RIGHT | اعداد عربی با پرانتز بسته. مثال: 1), 2), 3), ... |
| BULLET_ARABIC_PERIOD | اعداد عربی با نقطه. مثال: 1., 2., 3., ... |
| BULLET_ROMAN_LC_PAREN_BOTH | اعداد رومی کوچک با هر دو پرانتز. مثال: (i), (ii), (iii), ... |
| BULLET_ROMAN_LC_PAREN_RIGHT | اعداد رومی کوچک با پرانتز بسته. مثال: i), ii), iii), ... |
| BULLET_ROMAN_LC_PERIOD | اعداد رومی کوچک با نقطه. مثال: i., ii., iii., ... |
| BULLET_ROMAN_UC_PERIOD | اعداد رومی بزرگ با نقطه. مثال: I., II., III., ... |
| BULLET_ALPHA_LC_PAREN_BOTH | حروف الفبای کوچک با هر دو پرانتز. مثال: (a), (b), (c), ... |
| BULLET_ALPHA_LC_PAREN_RIGHT | حروف الفبای کوچک با پرانتز بسته. مثال: a), b), c), ... |
| BULLET_ALPHA_UC_PAREN_BOTH | حروف الفبای بزرگ با هر دو پرانتز. مثال: (A), (B), (C), ... |
| BULLET_ALPHA_UC_PAREN_RIGHT | حروف الفبای بزرگ با پرانتز بسته. مثال: A), B), C), ... |
| BULLET_ARABIC_PAREN_BOTH | اعداد عربی با هر دو پرانتز. مثال: (1), (2), (3), ... |
| BULLET_ARABIC_PLAIN | اعداد عربی. مثال: 1, 2, 3, ... |
| BULLET_ROMAN_UC_PAREN_BOTH | اعداد رومی بزرگ با هر دو پرانتز. مثال: (I), (II), (III), ... |
| BULLET_ROMAN_UC_PAREN_RIGHT | اعداد رومی بزرگ با پرانتز بسته. مثال: I), II), III), ... |
| BULLET_SIMP_CHIN_PLAIN | چینی ساده بدون نقطه. |
| BULLET_SIMP_CHIN_PERIOD | چینی ساده با نقطه. |
| BULLET_CIRCLE_NUM_DB_PLAIN | عدد دایره‌ای دو بایتی برای مقادیر تا 10، از 11 به بعد - اعداد عربی. |
| BULLET_CIRCLE_NUM_WD_WHITE_PLAIN | عدد رنگی متن با دایره‌ای هم‌رنگ اطراف آن (شماره‌های دایره‌ای سفید Wingdings). از 11 - اعداد عربی. |
| BULLET_CIRCLE_NUM_WD_BLACK_PLAIN | عدد رنگ سایه با پس‌زمینهٔ دایره‌ای رنگ متن معمولی (شماره‌های دایره‌ای سیاه Wingdings). |
| BULLET_TRAD_CHIN_PLAIN | چینی سنتی بدون نقطه. |
| BULLET_TRAD_CHIN_PERIOD | چینی سنتی با نقطه. |
| BULLET_ARABIC_ALPHA_DASH | حروف الفبای عربی با خط تیره. |
| BULLET_ARABIC_ABJAD_DASH | الفبای عربی عجم (Abjad) با خط تیره. |
| BULLET_HEBREW_ALPHA_DASH | حروف الفبای عبری با خط تیره. |
| BULLET_KANJI_KOREAN_PLAIN | اعداد ژاپنی/کره‌ای بدون نقطه. |
| BULLET_KANJI_KOREAN_PERIOD | اعداد ژاپنی/کره‌ای با نقطه. |
| BULLET_ARABIC_DB_PLAIN | طرح شماره‌گذاری عربی دو بایتی (بدون نقطه‌گذاری). |
| BULLET_ARABIC_DB_PERIOD | طرح شماره‌گذاری عربی دو بایتی با نقطه دو بایتی. |
| BULLET_THAI_ALPHA_PERIOD | نقطه الفبای تایلندی. |
| BULLET_THAI_ALPHA_PAREN_RIGHT | پرانتزهای الفبای تایلندی - راست. |
| BULLET_THAI_ALPHA_PAREN_BOTH | پرانتزهای الفبای تایلندی - هر دو. |
| BULLET_THAI_NUM_PERIOD | نقطه عددی تایلندی. |
| BULLET_THAI_NUM_PAREN_RIGHT | پرانتزهای عددی تایلندی - راست. |
| BULLET_THAI_NUM_PAREN_BOTH | پرانتزهای عددی تایلندی - هر دو. |
| BULLET_HINDI_ALPHA_PERIOD | نقطه الفبای هندی - حروف صدادار. |
| BULLET_HINDI_NUM_PERIOD | نقطه عددی هندی. |
| BULLET_KANJI_SIMP_CHIN_DB_PERIOD | کانجی چینی ساده با دوره دو بایتی. |
| BULLET_HINDI_NUM_PAREN_RIGHT | پرانتزهای عددی هندی - راست. |
| BULLET_HINDI_ALPHA_1_PERIOD | نقطه الفبای هندی - حروف بی‌صدا. |
