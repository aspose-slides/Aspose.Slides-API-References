## ShapeElementFillSource شمارش

نشان می‌دهد که عنصر شکل چگونه باید پر شود.

نوع ShapeElementFillSource اعضای زیر را ارائه می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| NO_FILL | پر کردن اولیه انجام نشود. |
| SHAPE | از پر کردن شکل استفاده کنید. |
| LIGHTEN | از پر کردن روشن‌شده شکل استفاده کنید. |
| LIGHTEN_LESS | از پر کردن کم‌تر روشن‌شده شکل استفاده کنید. |
| DARKEN | از پر کردن تاریک‌شده شکل استفاده کنید. |
| DARKEN_LESS | از پر کردن کم‌تر تاریک‌شده شکل استفاده کنید. |
