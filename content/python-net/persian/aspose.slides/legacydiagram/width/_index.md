## width ویژگی
دریافت یا تنظیم width شکل، که بر حسب نقطه‌ها اندازه‌گیری می‌شود.
خواندنی/نوشتنی **float**.


### توضیحات

مقدار بازگردانده‌شده همیشه تعریف‌شده است و هرگز **float** نیست.
مقدار اختصاص داده‌شده نیز باید تعریف‌شده باشد؛ **float** را فقط به ویژگی‌های یک نمونه `RawFrame` اختصاص دهید.
