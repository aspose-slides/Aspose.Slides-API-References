## ویژگی y
مختصات y-نقطهٔ گوشهٔ بالا-چپ شکل را می‌گیرد یا تنظیم می‌کند، بر حسب نقطه‌ها.
            خواندنی/نوشتنی **float**.

### ملاحظات

مقداری که برگردانده می‌شود همیشه تعریف شده است و هرگز **float** نیست.
            مقداری که اختصاص داده می‌شود نیز باید تعریف شده باشد؛ **float** را فقط به ویژگی‌های یک نمونهٔ `RawFrame` اختصاص دهید.

### تعریف:
```python
@property
def y(self):
    ...

@y.setter
def y(self, value):
    ...
```
