## x ویژگی
مختصات x گوشهٔ بالا-چپ شکل را دریافت یا تنظیم می‌کند، که بر حسب نقطه اندازه‌گیری می‌شود.
            خواندن/نوشتن **float**.


### توضیحات

مقداری که بازگردانده می‌شود همیشه تعریف‌شده است و هرگز **float** نیست.
            مقداری که اختصاص داده می‌شود نیز باید تعریف‌شده باشد؛ فقط **float** را به ویژگی‌های یک نمونهٔ `RawFrame` اختصاص دهید.

### تعریف:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
