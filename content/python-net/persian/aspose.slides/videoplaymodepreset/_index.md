## VideoPlayModePreset شمارش

ثابت‌هایی که نحوه پخش یک ویدیو را تعریف می‌کنند.

نوع VideoPlayModePreset اعضای زیر را ارائه می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| MIXED | |
| AUTO | به‌صورت خودکار پخش می‌شود. |
| ON_CLICK | فقط زمانی پخش می‌شود که فریم ویدیو کلیک شود. |
| ALL_SLIDES | در تمام اسلایدها پخش می‌شود. |
| IN_CLICK_SEQUENCE | به‌صورت خودکار با یک کلیک پخش می‌شود. |
