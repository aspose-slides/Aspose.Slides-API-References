## PathFillModeType شمارش

مشخص می‌کند که مسیر باید چگونه پر شود

نوع PathFillModeType اعضای زیر را در اختیار می‌گذارد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| NONE | بدون پر کردن مسیر<br/>            این مشخص می‌کند که مسیر مربوطه نباید پر شود. |
| NORMAL | پر کردن مسیر به‌صورت عادی<br/>            این مشخص می‌کند که مسیر مربوطه باید رنگی با سایه معمولی بر روی پرکردگی‌اش اعمال شود. |
| LIGHTEN | روشن‌کردن پر کردن مسیر<br/>            این مشخص می‌کند که مسیر مربوطه باید رنگی با سایه کم‌روشن بر روی پرکردگی‌اش اعمال شود. |
| LIGHTEN_LESS | روشن‌کردن کمتر پر کردن مسیر<br/>            این مشخص می‌کند که مسیر مربوطه باید رنگی با سایه کمی روشن‌تر بر روی پرکردگی‌اش اعمال شود. |
| DARKEN | تیره‌کردن پر کردن مسیر<br/>            این مشخص می‌کند که مسیر مربوطه باید رنگی با سایه تیره‌تر بر روی پرکردگی‌اش اعمال شود. |
| DARKEN_LESS | تیره‌کردن کمتر پر کردن مسیر<br/>            این مشخص می‌کند که مسیر مربوطه باید رنگی با سایه کمی تیره‌تر بر روی پرکردگی‌اش اعمال شود. |
