## IInterruptionToken کلاس

این کلاس نمایانگر توکنی است که برای سیگنال‌دادن به کارهای طولانی‌مدت استفاده می‌شود تا تعیین شود آیا قطع درخواست شده است یا خیر.

نوع IInterruptionToken اعضای زیر را در اختیار می‌گذارد:

## ویژگی‌ها

| ویژگی | توضیح |
| :- | :- |
| [`is_interruption_requested`](/slides/python-net/fa/aspose.slides/iinterruptiontoken/is_interruption_requested/) | بازمی‌گرداند **bool**.true اگر قطع درخواست شده باشد. |

## متدها

| متد | توضیح |
| :- | :- |
| [`throw_if_interruption_requested(self)`](/slides/python-net/fa/aspose.slides/iinterruptiontoken/throw_if_interruption_requested/#) | یک OperationCanceledException پرتاب می‌کند اگر<br/>            قطع درخواست شده باشد.<br/>            زمانی که قطع درخواست شده باشد پرتاب می‌شود. |
