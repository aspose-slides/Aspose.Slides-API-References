## SensitivityLabelContentType شمارش

نوع محتواهای علامت‌گذاری که باید بر روی یک سند اعمال شوند را نشان می‌دهد.

نوع SensitivityLabelContentType اعضای زیر را در اختیار می‌گذارد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| NONE | به این معناست که برچسب به طور پیش‌فرض یا به‌صورت خودکار اعمال می‌شود. |
| HEADER | به این معناست که برچسب به‌صورت دستی اعمال شده است.<br/>            برای هر برچسب حساسیتی که مستقیماً توسط کاربر اعمال شده باشد استفاده شود. |
| FOOTER | به این معناست که برچسب به‌صورت دستی اعمال شده است.<br/>            برای هر برچسب حساسیتی که مستقیماً توسط کاربر اعمال شده باشد استفاده شود. |
| WATERMARK | به این معناست که برچسب به‌صورت دستی اعمال شده است.<br/>            برای هر برچسب حساسیتی که مستقیماً توسط کاربر اعمال شده باشد استفاده شود. |
| ENCRYPTION | به این معناست که برچسب به‌صورت دستی اعمال شده است.<br/>            برای هر برچسب حساسیتی که مستقیماً توسط کاربر اعمال شده باشد استفاده شود. |
