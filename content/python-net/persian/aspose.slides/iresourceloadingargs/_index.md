## IResourceLoadingArgs کلاس

رابط برای آرگومان‌های بارگذاری منابع خارجی.

نوع IResourceLoadingArgs اعضای زیر را افشا می‌کند:

## ویژگی‌ها

| ویژگی | توضیح |
| :- | :- |
| [`original_uri`](/slides/python-net/fa/aspose.slides/iresourceloadingargs/original_uri/) | URI اصلی منبع همان‌طور که در ارائه وارد شده مشخص شده است. |
| [`uri`](/slides/python-net/fa/aspose.slides/iresourceloadingargs/uri/) | URI منبع که برای بارگیری استفاده می‌شود اگر **Aspose.Slides.IResourceLoadingCallback.ResourceLoading(Aspose.Slide** <br/>            returns [`ResourceLoadingAction.DEFAULT`](/slides/python-net/fa/aspose.slides/resourceloadingaction/DEFAULT). <br/>            در ابتدا به URI اصلی منبع تنظیم می‌شود، اما می‌تواند به هر مقدار دیگری بازتعریف شود. |

## متدها

| متد | توضیح |
| :- | :- |
