## شمارش PPImageFormat

قالب‌های تصویر. این شمارش جایگزین کلاس `System.Drawing.Imaging.ImageFormat` است.
            برای سازگاری با COM لازم است.

نوع PPImageFormat اعضای زیر را ارائه می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| BMP | قالب تصویر bitmap (BMP) را دریافت می‌کند. |
| EMF | قالب تصویر متافایل پیشرفته (EMF) را دریافت می‌کند. |
| EXIF | قالب فایل تصویری قابل تبادل (Exif) را دریافت می‌کند. |
| GIF | قالب تصویر Graphics Interchange Format (GIF) را دریافت می‌کند. |
| ICON | قالب تصویر نماد ویندوز (ICON) را دریافت می‌کند. |
| JPEG | قالب تصویر Joint Photographic Experts Group (JPEG) را دریافت می‌کند. |
| MEMORY_BMP | قالب bitmap در حافظه را دریافت می‌کند. |
| PNG | قالب تصویر W3C Portable Network Graphics (PNG) را دریافت می‌کند. |
| TIFF | قالب تصویر Tagged Image File Format (TIFF) را دریافت می‌کند. |
| WMF | قالب تصویر Windows metafile (WMF) را دریافت می‌کند. |
