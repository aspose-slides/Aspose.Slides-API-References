## from_name(name) {#str}
یک رنگ را از نام مشخص‌شده یک رنگ پیش‌تعریف‌شده ایجاد می‌کند.<br/>جستجو بدون در نظر گرفتن حروف بزرگ و کوچک است و زیرخط‌ها و فاصله‌ها را نادیده می‌گیرد: "LightBlue", "lightblue" and "light_blue" همگی به `Color.light_blue` تبدیل می‌شوند. صفحهٔ کلاس [`Color`](/slides/python-net/fa/aspose.slides/color) را برای فهرست رنگ‌های پیش‌تعریف‌شده ببینید.

### Returns
رنگ نام‌گذاری‌شده.

```python
@staticmethod
def from_name(name):
    ...
```

| پارامتر | نوع | توضیح |
| :- | :- | :- |
| name | **str** | یک رشته که نام یک رنگ پیش‌تعریف‌شده است. |

### Exceptions
| Exception | Description |
| :- | :- |
| **ValueError** | نام، نام یک رنگ پیش‌تعریف‌شده نیست. |
| **TypeError** | نام، یک رشته نیست. |
