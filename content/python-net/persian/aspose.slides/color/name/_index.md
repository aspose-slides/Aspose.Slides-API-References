## ویژگی name
نام این رنگ را بر می‌گرداند.<br/>            برای یک رنگ نام‌دار (یک ثابت نام‌دار مانند `Color.red`، یا رنگی که با [`from_name`](/slides/python-net/fa/aspose.slides/color/from_name/) ساخته شده است) نام .NET برگردانده می‌شود، مثلاً `"Red"` یا `"LightBlue"`.<br/>            برای هر رنگ دیگر مقدار ARGB به صورت هگزادسیمال کوچک بدون صفر پیشوند بر می‌گردد، مثلاً `"ffff0000"`. `Color.empty.name` برابر با `"0"` است.
            فقط خواندنی **str**.
