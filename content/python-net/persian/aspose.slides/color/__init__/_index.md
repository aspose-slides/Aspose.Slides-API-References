## __init__(self, r=0, g=0, b=0, a=255) {#int-int-int-int}
یک رنگ را از مقادیر مشخص‌شدهٔ مؤلفه‌های قرمز، سبز، آبی و آلفا ایجاد می‌کند.

```python
def __init__(self, r=0, g=0, b=0, a=255):
    ...
```

| پارامتر | نوع | توضیح |
| :- | :- | :- |
| r | **int** | مقدار مؤلفهٔ قرمز. مقادیر معتبر ۰ تا ۲۵۵ هستند. |
| g | **int** | مقدار مؤلفهٔ سبز. مقادیر معتبر ۰ تا ۲۵۵ هستند. |
| b | **int** | مقدار مؤلفهٔ آبی. مقادیر معتبر ۰ تا ۲۵۵ هستند. |
| a | **int** | مقدار مؤلفهٔ آلفا. مقادیر معتبر ۰ تا ۲۵۵ هستند. |

### استثناها

| استثنا | توضیح |
| :- | :- |
| **ValueError** | مقدار یک مؤلفه کمتر از ۰ یا بزرگ‌تر از ۲۵۵ است. |
| **TypeError** | مقدار یک مؤلفه عددی نیست. |
