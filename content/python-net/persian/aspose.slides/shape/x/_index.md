## خاصیت x
مختصات x گوشهٔ بالا-چپ شکل را به‌دست می‌آورد یا تنظیم می‌کند، که بر حسب نقطه اندازه‌گیری می‌شود.
خواندنی/نوشتنی **float**.


### توضیحات

مقداری که برگردانده می‌شود همیشه تعریف شده است و هرگز **float** نیست.
مقداری که اختصاص داده می‌شود نیز باید تعریف شده باشد؛ **float** را فقط به خاصیت‌های یک نمونهٔ `RawFrame` اختصاص دهید.

### تعریف:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
