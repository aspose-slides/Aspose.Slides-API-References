## width ویژگی
مقدار width شکل را دریافت یا تنظیم می‌کند که بر حسب نقطه اندازه‌گیری می‌شود.
            خواندنی/نوشتنی **float**.

### توضیحات

مقدار بازگردانده شده همیشه تعریف‌شده است و هرگز **float** نیست.
            مقدار اختصاص داده شده نیز باید تعریف‌شده باشد؛ **float** را فقط به ویژگی‌های یک نمونه `RawFrame` اختصاص دهید.
