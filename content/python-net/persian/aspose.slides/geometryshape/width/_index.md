## width ویژگی
دریافت یا تنظیم width شکل، بر حسب نقطه.
            خواندن/نوشتن **float**.


### توضیحات

مقدار بازگردانده شده همیشه تعریف‌شده است و هرگز **float** نیست.
            مقدار اختصاص داده‌شده نیز باید تعریف‌شده باشد؛ **float** را فقط به ویژگی‌های یک نمونه `RawFrame` اختصاص دهید.
