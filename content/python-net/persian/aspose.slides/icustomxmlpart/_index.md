## ICustomXmlPart کلاس

قسمت xml سفارشی را نشان می‌دهد.

نوع ICustomXmlPart اعضای زیر را در دسترس می‌گذارد:

## ویژگی‌ها

| ویژگی | توضیح |
| :- | :- |
| [`xml_as_string`](/slides/python-net/fa/aspose.slides/icustomxmlpart/xml_as_string/) | داده‌های xml را به‌صورت رشته UTF-8 برمی‌گرداند یا تنظیم می‌کند.<br/>            خواندن/نوشتن **str**.<br/>            مقدار `None` است. مقدار خالی یا داده‌های xml نامعتبر هستند. |
| [`xml_data`](/slides/python-net/fa/aspose.slides/icustomxmlpart/xml_data/) | داده‌های xml را برمی‌گرداند یا تنظیم می‌کند.<br/>            خواندن/نوشتن **int**[].<br/>            مقدار `None` است. مقدار خالی یا داده‌های xml نامعتبر هستند. |
| [`item_id`](/slides/python-net/fa/aspose.slides/icustomxmlpart/item_id/) | یک شناسه یکتا جهانی (GUID) را مشخص می‌کند که یک بخش xml سفارشی را به‌طور یکتای در یک سند Office Open XML شناسایی می‌کند.<br/>            فقط‌خواندنی **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/fa/aspose.slides/icustomxmlpart/namespace_schemas/) | مجموعهٔ طرح‌واره‌های XML که با بخش xml سفارشی مرتبط هستند را برمی‌گرداند.<br/>            فقط‌خواندنی **str**[]. |

## متدها

| :- | :- |
