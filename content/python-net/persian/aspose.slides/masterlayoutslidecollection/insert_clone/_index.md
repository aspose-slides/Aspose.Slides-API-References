## insert_clone(self, index, source_layout) {#int-ilayoutslide}
یک کپی از یک اسلاید طرح مشخص شده را در موقعیت مشخصی از مجموعه درج می‌کند.

### بازگشت
اسلاید درج‌شده.

```python
def insert_clone(self, index, source_layout):
    ...
```

| پارامتر | نوع | توضیح |
| :- | :- | :- |
| index | **int** | نمایه اسلاید جدید. |
| source_layout | [`ILayoutSlide`](/slides/python-net/fa/aspose.slides/ilayoutslide) | اسلاید برای تکثیر. |

### ملاحظات
طرح جدید با اسلاید مستر والد برای این مجموعه اسلایدهای طرح مرتبط خواهد شد. بنابراین این مشابه کپی/چسباندن با گزینه "Use Destination Theme" در PowerPoint است.
