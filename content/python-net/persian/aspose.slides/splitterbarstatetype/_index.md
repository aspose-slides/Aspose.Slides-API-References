## SplitterBarStateType شمارش

وضعیتی را که نوار تقسیم‌کننده باید نمایش داده شود، مشخص می‌کند. نوار تقسیم‌کننده یک منطقهٔ اصلی و یک منطقهٔ ثانویه را درون یک ناحیهٔ مشاهده جدا می‌کند.

نوع SplitterBarStateType اعضای زیر را نمایش می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| MINIMIZED | منطقهٔ اصلی کمترین حجم از ناحیهٔ مشاهده را که توسط برنامه مجاز است، اشغال می‌کند. |
| RESTORED | منطقهٔ اصلی دارای اندازهٔ متوسط خاصی است. |
| MAXIMIZED | منطقهٔ اصلی بیشترین حجم از ناحیهٔ مشاهده را که توسط برنامه مجاز است، اشغال می‌کند. |
