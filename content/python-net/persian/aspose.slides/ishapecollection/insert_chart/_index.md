```python
def insert_chart(self, type, x, y, width, height, index):
    ...
```


| پارامتر | نوع | توضیح |
| :- | :- | :- |
| type | [`ChartType`](/slides/python-net/fa/aspose.slides.charts/charttype) | نوع نمودار برای ایجاد. |
| x | **float** | مختصات x نمودار جدید، بر حسب نقطه. |
| y | **float** | مختصات y نمودار جدید، بر حسب نقطه. |
| width | **float** | عرض نمودار جدید، بر حسب نقطه. |
| height | **float** | ارتفاع نمودار جدید، بر حسب نقطه. |
| index | **int** | اندیس مبتنی بر صفر که در آن نمودار جدید در مجموعهٔ اشکال وارد می‌شود. |

    ...

| :- | :- | :- |
| type | [`ChartType`](/slides/python-net/fa/aspose.slides.charts/charttype) | نوع نمودار برای ایجاد. |
| x | **float** | مختصات x نمودار جدید، بر حسب نقطه. |
