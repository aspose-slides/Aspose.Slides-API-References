The newly created [`IConnector`](/slides/python-net/fa/aspose.slides/iconnector).

```python
def add_connector(self, shape_type, x, y, width, height):
    ...
```


| پارامتر | نوع | توضیح |
| :- | :- | :- |
| shape_type | [`ShapeType`](/slides/python-net/fa/aspose.slides/shapetype) | [`ShapeType`](/slides/python-net/fa/aspose.slides/shapetype) شکل اتصال برای افزودن. |
| x | **float** | مختصات x قاب اتصال، به پوینت. |
| y | **float** | مختصات y قاب اتصال، به پوینت. |
| width | **float** | عرض قاب اتصال، به پوینت. |

## add_connector(self, shape_type, x, y, width, height, create_from_template) {#shapetype-float-float-float-float-bool}
یک شکل اتصال جدید ایجاد می‌کند و آن را به انتهای مجموعه شکل‌ها اضافه می‌دارد، به‌طور اختیاری با اعمال سبک قالب پیش‌فرض.

### مقدار بازگشتی

The newly created [`IConnector`](/slides/python-net/fa/aspose.slides/iconnector).



```python
def add_connector(self, shape_type, x, y, width, height, create_from_template):
    ...
```


| پارامتر | نوع | توضیح |
| :- | :- | :- |
| shape_type | [`ShapeType`](/slides/python-net/fa/aspose.slides/shapetype) | [`ShapeType`](/slides/python-net/fa/aspose.slides/shapetype) شکل اتصال برای ایجاد. |
| x | **float** | مختصات x قاب اتصال، به پوینت. |
| y | **float** | مختصات y قاب اتصال، به پوینت. |
| width | **float** | عرض قاب اتصال، به پوینت. |
| height | **float** | ارتفاع قاب اتصال، به پوینت. |
| create_from_template | **bool** | True برای اعمال سبک قالب پیش‌فرض (نام غیر خالی، سبک ساده)؛ <br/><br/> false برای ایجاد اتصال با مقادیر پیش‌فرض ویژگی‌ها. |
