## reorder(self, index, shape) {#int-ishape}
شکل مشخص شده را به موقعیت جدیدی در مجموعهٔ اشکال منتقل می‌کند.


```python
def reorder(self, index, shape):
    ...
```


| پارامتر | نوع | توضیح |
| :- | :- | :- |
| index | **int** | اندیس هدف مبتنی بر صفر که شکل در آن قرار خواهد گرفت. |
| shape | [`IShape`](/slides/python-net/fa/aspose.slides/ishape) | [`IShape`](/slides/python-net/fa/aspose.slides/ishape) برای جابجایی در مجموعه. |


## reorder(self, index, shapes) {#int-listishape}
اشکال مشخص شده را در مجموعهٔ اشکال جابجا می‌کند و آنها را از اندیس داده شده شروع می‌دهد.


```python
def reorder(self, index, shapes):
    ...
```


| پارامتر | نوع | توضیح |
| :- | :- | :- |
| index | **int** | اندیس هدف مبتنی بر صفر که اولین شکل مشخص شده در آن قرار خواهد گرفت؛ <br/><br/> اشکال بعدی به ترتیب ارائه شده دنبال می‌شوند. |
| shapes | **List[IShape]** | یک یا چند نمونه از [`IShape`](/slides/python-net/fa/aspose.slides/ishape) برای جابجایی در مجموعه. |
