## خاصیت x
مختصات x نقطهٔ گوشهٔ بالایی سمت چپ شکل را دریافت یا تنظیم می‌کند، بر حسب نقطه.
            خواندنی/نوشتنی **float**.


### توضیحات

مقدار بازگشتی همیشه تعریف‌شده است و هرگز **float** نیست.
            مقدار انتسابی نیز باید تعریف‌شده باشد؛ فقط **float** را به ویژگی‌های یک نمونهٔ `RawFrame` اختصاص دهید.

### تعریف:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
