## rotation ویژگی
تعداد درجاتی که شکل مشخص شده حول محور z چرخانده می‌شود را برمی‌گرداند یا تنظیم می‌کند.  
مقدار مثبت نشان‌دهنده چرخش ساعت‌گرد است؛ مقدار منفی نشان‌دهنده چرخش پاد ساعت‌گرد است.  
قابل خواندن/نوشتن **float**.

### توضیحات
مقدار برگشتی همیشه تعریف شده است (float.NaN نیست). مقدار انتسابی باید تعریف شده باشد (float.NaN نیست). می‌توانید مقادیر نام‌تعریف‌شده را برای ویژگی‌های نمونه RawFrame تنظیم کنید.

@property
def rotation(self):
    ...

@rotation.setter
def rotation(self, value):
    ...
