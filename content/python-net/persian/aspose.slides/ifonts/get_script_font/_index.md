## get_script_font(self, script) {#str}
فونت نام مرتبط با یک برچسب اسکریپت خاص را از تم ارائه می‌کند.

### بازگشت
نام فونت استفاده‌شده برای اسکریپت مشخص‌شده، یا `None` اگر اسکریپت تعریف نشده باشد.



```python
def get_script_font(self, script):
    ...
```


| پارامتر | نوع | توضیح |
| :- | :- | :- |
| script | **str** | کد اسکریپت BCP-47 (به عنوان مثال "Latn"، "Cyrl"، "Jpan") که برای شناسایی یک سیستم نوشتاری استفاده می‌شود. |
