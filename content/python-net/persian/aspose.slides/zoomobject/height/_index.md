## height ویژگی
دریافت یا تنظیم height شکل، بر حسب نقطه.
            خواندنی/قابل نوشتن **float**.

### توضیحات

مقدار بازگردانده همیشه تعریف شده است و هرگز **float** نیست.
            مقدار اختصاص داده‌شده نیز باید تعریف شده باشد؛ فقط **float** را به ویژگی‌های یک نمونه `RawFrame` اختصاص دهید.
