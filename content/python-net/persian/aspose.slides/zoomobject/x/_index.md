## x ویژگی
دریافت یا تنظیم مختصات x گوشه بالا-چپ شکل، که بر حسب نقاط اندازه‌گیری می‌شود.
            خواندنی/نوشتنی **float**.

### توضیحات

مقدار برگردانده شده همیشه تعریف شده است و هرگز **float** نیست.
            مقدار اختصاص داده شده نیز باید تعریف شده باشد؛ فقط **float** را به ویژگی‌های یک نمونهٔ `RawFrame` اختصاص دهید.

### تعریف:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
