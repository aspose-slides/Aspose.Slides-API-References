## IAdjustValue کلاس

نمایش‌دهنده مقدار تنظیم شکل هندسی است.
این مقادیر بر فرم شکل تأثیر می‌گذارد.

نوع IAdjustValue اعضای زیر را ارائه می‌دهد:

## ویژگی‌ها

| ویژگی | توضیح |
| :- | :- |
| [`raw_value`](/slides/python-net/fa/aspose.slides/iadjustvalue/raw_value/) | مقدار تنظیم را همان‌گونه برمی‌گرداند یا تنظیم می‌کند.<br/>            خواندن/نوشتن **int**. |
| [`angle_value`](/slides/python-net/fa/aspose.slides/iadjustvalue/angle_value/) | مقدار را برمی‌گرداند یا تنظیم می‌کند، به عنوان زاویه بر حسب درجه تفسیر می‌کند.<br/>            خواندن/نوشتن **float**. |
| [`name`](/slides/python-net/fa/aspose.slides/iadjustvalue/name/) | نام این مقدار تنظیم را برمی‌گرداند.<br/>            فقط قابل خواندن **str**. |
