## شمارش ColorTransformOperation

عملیات تبدیل رنگ را تعریف می‌کند.

نوع ColorTransformOperation اعضای زیر را در اختیار می‌گذارد:

## فیلدها

| Field | Description |
| :- | :- |
| TINT | رنگ را روشن می‌کند. پارامتر در بازه بین 0 (رنگ اصلی) و 1 (سفید) است. |
| SHADE | رنگ را تیره می‌کند. پارامتر در بازه بین 0 (رنگ اصلی) و 1 (سیاه) است. |
| COMPLEMENT | رنگ را به یک رنگ مکمل RGB تبدیل می‌کند.<br/>            m = Max(r, g, b);<br/>            r = m - r;<br/>            g = m - g;<br/>            b = m - b; |
| INVERSE | رنگ را به یک رنگ معکوس تبدیل می‌کند.<br/>            r = 1 - r;<br/>            g = 1 - g;<br/>            b = 1 - b; |
| GRAYSCALE | رنگ را به یک رنگ خاکستری با همان روشنایی تبدیل می‌کند. پارامتر نادیده گرفته می‌شود. |
| SET_ALPHA | جزء آلفای رنگ را تعریف می‌کند. پارامتر در بازه بین 0 (شفاف) و 1 (مات) قرار دارد. |
| ADD_ALPHA | مقدار پارامتر را به جزء آلفای رنگ اضافه می‌کند. پارامتر در بازه بین -1 و 1 است. |
| MULTIPLY_ALPHA | جزء آلفا را در مقدار پارامتر ضرب می‌کند. |
| SET_HUE | جزء هیو رنگ را به مقدار پارامتر تغییر می‌دهد. پارامتر در بازه بین 0 و 360 است. |
| ADD_HUE | مقدار پارامتر را به جزء هیو رنگ اضافه می‌کند. پارامتر در بازه بین -360 و 360 است. |
| MULTIPLY_HUE | جزء هیو را در مقدار پارامتر ضرب می‌کند. |
| SET_SATURATION | جزء اشباع رنگ را به مقدار پارامتر تغییر می‌دهد. پارامتر در بازه بین 0 و 1 است. |
| ADD_SATURATION | مقدار پارامتر را به جزء اشباع رنگ اضافه می‌کند. پارامتر در بازه بین -1 و 1 است. |
| MULTIPLY_SATURATION | جزء اشباع رنگ را در مقدار پارامتر ضرب می‌کند. |
| SET_LUMINANCE | جزء روشنایی رنگ را به مقدار پارامتر تغییر می‌دهد. پارامتر در بازه بین 0 و 1 است. |
| ADD_LUMINANCE | مقدار پارامتر را به جزء روشنایی رنگ اضافه می‌کند. پارامتر در بازه بین -1 و 1 است. |
| MULTIPLY_LUMINANCE | جزء روشنایی رنگ را در مقدار پارامتر ضرب می‌کند. |
| SET_RED | جزء قرمز رنگ را به مقدار پارامتر تغییر می‌دهد. پارامتر در بازه بین 0 و 1 است. |
| ADD_RED | مقدار پارامتر را به جزء قرمز رنگ اضافه می‌کند. پارامتر در بازه بین -1 و 1 است. |
| MULTIPLY_RED | جزء قرمز را در پارامتر ضرب می‌کند. |
| SET_GREEN | جزء سبز رنگ را به مقدار پارامتر تغییر می‌دهد. پارامتر در بازه بین 0 و 1 است. |
| ADD_GREEN | پارامتر را به جزء سبز رنگ اضافه می‌کند. پارامتر در بازه بین -1 و 1 است. |
| MULTIPLY_GREEN | جزء سبز رنگ را در مقدار پارامتر ضرب می‌کند. |
| SET_BLUE | جزء آبی رنگ را به مقدار پارامتر تغییر می‌دهد. پارامتر در بازه بین 0 و 360 است. |
| ADD_BLUE | مقدار پارامتر را به جزء آبی رنگ اضافه می‌کند. پارامتر در بازه بین -1 و 1 است. |
| MULTIPLY_BLUE | جزء آبی رنگ را در مقدار پارامتر ضرب می‌کند. |
| GAMMA | تصحیح گاما. پارامتر نادیده گرفته می‌شود. |
| INVERSE_GAMMA | تصحیح گاما معکوس. پارامتر نادیده گرفته می‌شود. |
