## خاصیت چرخش
Returns or sets the number of degrees the specified shape is rotated around
            the z-axis. A positive value indicates clockwise rotation; a negative value
            indicates counterclockwise rotation.
            خواندنی/نوشتنی **float**.


### توضیحات

مقدار بازگردانده شده همیشه تعریف‌شده است (is not float.NaN).
            مقدار اختصاص داده شده باید تعریف‌شده باشد (not float.NaN). می‌توانید مقادیر تعریف‌نشده را برای ویژگی‌های نمونه RawFrame تنظیم کنید.
