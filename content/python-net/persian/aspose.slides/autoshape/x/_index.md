## ویژگی x
مختصات x گوشهٔ بالا-چپ شکل را دریافت یا تنظیم می‌کند، که بر حسب نقطه اندازه‌گیری می‌شود.
            خواندنی/قابلیت نوشتن **float**.


### توضیحات

مقدار بازگردانده‌شده همیشه تعریف‌شده است و هرگز **float** نیست.
            مقدار اختصاص داده‌شده نیز باید تعریف‌شده باشد؛ فقط **float** را به ویژگی‌های یک نمونهٔ `RawFrame` اختصاص دهید.

### تعریف:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
