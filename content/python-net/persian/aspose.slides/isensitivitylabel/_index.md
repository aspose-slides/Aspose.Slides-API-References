## ISensitivityLabel کلاس

نمایش‌گر برچسب حساسیت از Microsoft Purview Information Protection است.

نوع ISensitivityLabel اعضای زیر را در اختیار می‌گذارد:

## ویژگی‌ها

| ویژگی | توضیح |
| :- | :- |
| [`id`](/slides/python-net/fa/aspose.slides/isensitivitylabel/id/) | مقدار دهی یا دریافت شناسه برچسب حساسیت.<br/>            خواندن/نوشتن **str**. |
| [`site_id`](/slides/python-net/fa/aspose.slides/isensitivitylabel/site_id/) | مقدار دهی یا دریافت شناسه سایت Azure Active Directory (Azure AD) <br/>            که به سیاست برچسب حساسیتی که برچسب حساسیت را توصیف می‌کند مربوط می‌شود.<br/>            خواندن/نوشتن **System.Guid**. |
| [`is_enabled`](/slides/python-net/fa/aspose.slides/isensitivitylabel/is_enabled/) | نشان می‌دهد که آیا برچسب حساسیت فعال است یا نه. |
| [`is_removed`](/slides/python-net/fa/aspose.slides/isensitivitylabel/is_removed/) | نشان می‌دهد که آیا برچسب حساسیت حذف شده است یا نه. |
| [`assignment_method_type`](/slides/python-net/fa/aspose.slides/isensitivitylabel/assignment_method_type/) | مقدار دهی یا دریافت روش تخصیص برای برچسب حساسیت.<br/>            خواندن/نوشتن [`SensitivityLabelAssignmentType`](/slides/python-net/fa/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/fa/aspose.slides/isensitivitylabel/content_mark_types/) | لیست انواع علامت‌گذاری محتوا را که باید بر یک فایل اعمال شود بر می‌گرداند. |
