## GradientStyle شمارش

نمایانگر سبک‌های گرادیان در دسترس است.

نوع GradientStyle موارد زیر را ارائه می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| DEFAULT | سبک گرادیان پیش‌فرض. |
| POWER_POINT_UI | سبک گرادیان همان‌طور که در رابط کاربری PowerPoint ظاهر می‌شود. |
