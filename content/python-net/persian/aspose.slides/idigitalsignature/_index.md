## IDigitalSignature کلاس

امضای دیجیتال در فایل امضاشده.

نوع IDigitalSignature اعضای زیر را در اختیار می‌گذارد:

## ویژگی‌ها

| ویژگی | توضیح |
| :- | :- |
| [`certificate`](/slides/python-net/fa/aspose.slides/idigitalsignature/certificate/) | شیء گواهی که برای امضای سند استفاده شد.<br/>            فقط خواندنی **System.Security.Cryptography.X509Certificates.X509Certificate2**. |
| [`is_valid`](/slides/python-net/fa/aspose.slides/idigitalsignature/is_valid/) | اگر این امضای دیجیتال معتبر باشد و سند دستکاری نشده باشد، این مقدار true خواهد بود.<br/>            فقط خواندنی **bool**. |
| [`sign_time`](/slides/python-net/fa/aspose.slides/idigitalsignature/sign_time/) | زمانی که سند امضا شد.<br/>            فقط خواندنی **System.DateTime**. |
| [`comments`](/slides/python-net/fa/aspose.slides/idigitalsignature/comments/) | هدف امضا.<br/>            قابل خواندن و نوشتن **str**. |
