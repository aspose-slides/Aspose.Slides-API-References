## ویژگی y
دریافت یا تنظیم مختصات y گوشهٔ بالا-چپ شکل، که بر حسب نقطه اندازه‌گیری می‌شود.
            خواندنی/نوشتنی **float**.

### توضیحات
مقدار بازگردانده‌شده همیشه تعریف شده است و هرگز **float** نیست.
            مقدار اختصاص داده شده نیز باید تعریف شده باشد؛ **float** را فقط به ویژگی‌های یک نمونهٔ `RawFrame` اختصاص دهید.

### تعریف:
```python
@property
def y(self):
    ...

@y.setter
def y(self, value):
    ...
```
