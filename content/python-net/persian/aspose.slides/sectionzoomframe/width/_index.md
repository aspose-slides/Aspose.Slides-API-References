## width خاصیت
دریافت یا تنظیم width شکل، بر حسب نقطه اندازه‌گیری می‌شود.
            خواندنی/نوشتنی **float**.


### توضیحات

مقدار برگشت داده شده همیشه تعریف شده است و هرگز **float** نیست.
            مقدار اختصاص داده شده نیز باید تعریف شده باشد؛ فقط **float** را به خصوصیات یک نمونه `RawFrame` اختصاص دهید.
