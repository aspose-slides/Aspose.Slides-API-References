## ImageFormat شمارش

قالب فایل تصویر را نشان می‌دهد.

نوع ImageFormat اعضای زیر را افشا می‌کند:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| MEMORY_BMP | قالب یک bitmap در حافظه را نشان می‌دهد. |
| BMP | قالب تصویر bitmap (BMP) را نشان می‌دهد. |
| EMF | قالب تصویر metafile پیشرفته (EMF) را نشان می‌دهد. |
| WMF | قالب تصویر metafile ویندوز (WMF) را نشان می‌دهد. |
| GIF | قالب تصویر Graphics Interchange Format (GIF) را نشان می‌دهد. |
| JPEG | قالب تصویر Joint Photographic Experts Group (JPEG) را نشان می‌دهد. |
| PNG | قالب تصویر W3C Portable Network Graphics (PNG) را نشان می‌دهد. |
| TIFF | قالب تصویر Tagged Image File Format (TIFF) را نشان می‌دهد. |
| EXIF | قالب Exchangeable Image File (Exif) را نشان می‌دهد. |
| ICON | قالب تصویر آیکون ویندوز را نشان می‌دهد. |
