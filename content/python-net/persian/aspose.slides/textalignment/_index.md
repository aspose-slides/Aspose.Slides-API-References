## TextAlignment enum

نمایشگر انواع سبک‌های تراز متن.

نوع TextAlignment اعضای زیر را در اختیار می‌گذارد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| NOT_DEFINED | تراز پیش‌فرض. |
| LEFT | تراز چپ. |
| CENTER | تراز مرکز. |
| RIGHT | تراز راست. |
| JUSTIFY | تراز توجیه. |
| JUSTIFY_LOW | تراز کشیده پایین. |
| DISTRIBUTED | تراز توزیعی. |
