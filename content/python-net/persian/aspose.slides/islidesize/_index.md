## ISlideSize کلاس

اندازه و جهت‌گیری یک اسلاید را نمایندگی می‌کند.

ISlideSize نوع اعضای زیر را ارائه می‌دهد:

## ویژگی‌ها

| ویژگی | توضیح |
| :- | :- |
| [`size`](/slides/python-net/fa/aspose.slides/islidesize/size/) | ابعاد اسلاید را بر حسب پوینت دریافت می‌کند. |
| [`type`](/slides/python-net/fa/aspose.slides/islidesize/type/) | نوع اندازه اسلاید را دریافت می‌کند. |
| [`orientation`](/slides/python-net/fa/aspose.slides/islidesize/orientation/) | جهت اسلاید را دریافت یا تنظیم می‌کند. |

## متدها

| متد | توضیح |
| :- | :- |
| [`set_size(self, type, scale_type)`](/slides/python-net/fa/aspose.slides/islidesize/set_size/#slidesizetype-slidesizescaletype) | اندازه اسلاید را بر اساس نوع تنظیم می‌کند و محتوای موجود را مقیاس می‌دهد. |
| [`set_size(self, width, height, scale_type)`](/slides/python-net/fa/aspose.slides/islidesize/set_size/#float-float-slidesizescaletype) | ابعاد اسلاید را به‌صورت صریح تنظیم می‌کند و محتوای موجود را مقیاس می‌دهد. |
