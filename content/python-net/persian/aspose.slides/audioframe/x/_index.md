## ویژگی x
مختصات x گوشه‌ی بالا-چپ شکل را دریافت یا تنظیم می‌کند، که بر حسب نقاط اندازه‌گیری می‌شود.
            قابل خواندن/نوشتن **float**.

### توضیحات

مقدار بازگردانده شده همیشه تعریف‌شده است و هرگز **float** نیست.
            مقدار اختصاص داده شده نیز باید تعریف‌شده باشد؛ فقط **float** را به ویژگی‌های یک نمونه `RawFrame` اختصاص دهید.

### تعریف:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
