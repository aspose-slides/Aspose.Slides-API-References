## ITextFrameFormatEffectiveData کلاس

شیء ثابت که شامل ویژگی‌های قالب‌بندی مؤثر قاب متن است.

نوع ITextFrameFormatEffectiveData اعضای زیر را در دسترس قرار می‌دهد:

## ویژگی‌ها

| ویژگی | توضیح |
| :- | :- |
| [`text_style`](/slides/python-net/fa/aspose.slides/itextframeformateffectivedata/text_style/) | استایل متن مؤثر را برمی‌گرداند.<br/> فقط‌خواندنی [`ITextStyleEffectiveData`](/slides/python-net/fa/aspose.slides/itextstyleeffectivedata). |
| [`margin_left`](/slides/python-net/fa/aspose.slides/itextframeformateffectivedata/margin_left/) | حاشیه چپ (نقطه) را در یک TextFrame برمی‌گرداند.<br/> فقط‌خواندنی **float**. |
| [`margin_right`](/slides/python-net/fa/aspose.slides/itextframeformateffectivedata/margin_right/) | حاشیه راست (نقطه) را در یک TextFrame برمی‌گرداند.<br/> فقط‌خواندنی **float**. |
| [`margin_top`](/slides/python-net/fa/aspose.slides/itextframeformateffectivedata/margin_top/) | حاشیه بالایی (نقطه) را در یک TextFrame برمی‌گرداند.<br/> فقط‌خواندنی **float**. |
| [`margin_bottom`](/slides/python-net/fa/aspose.slides/itextframeformateffectivedata/margin_bottom/) | حاشیه پایین (نقطه) را در یک TextFrame برمی‌گرداند.<br/> فقط‌خواندنی **float**. |
| [`wrap_text`](/slides/python-net/fa/aspose.slides/itextframeformateffectivedata/wrap_text/) | برمی‌گرداند که آیا متن در حاشیه‌های TextFrame بسته می‌شود.<br/> فقط‌خواندنی **bool**. |
| [`anchoring_type`](/slides/python-net/fa/aspose.slides/itextframeformateffectivedata/anchoring_type/) | متن لنگر عمودی را در یک TextFrame برمی‌گرداند.<br/> فقط‌خواندنی [`TextAnchorType`](/slides/python-net/fa/aspose.slides/textanchortype). |
| [`center_text`](/slides/python-net/fa/aspose.slides/itextframeformateffectivedata/center_text/) | برمی‌گرداند که آیا متن باید به صورت افقی در جعبه مرکز شود.<br/> فقط‌خواندنی **bool**. |
| [`text_vertical_type`](/slides/python-net/fa/aspose.slides/itextframeformateffectivedata/text_vertical_type/) | جهت متن را برمی‌گرداند.<br/> فقط‌خواندنی [`TextVerticalType`](/slides/python-net/fa/aspose.slides/textverticaltype). |
| [`autofit_type`](/slides/python-net/fa/aspose.slides/itextframeformateffectivedata/autofit_type/) | حالت خودکار تنظیم متن را برمی‌گرداند.<br/> فقط‌خواندنی [`TextAutofitType`](/slides/python-net/fa/aspose.slides/textautofittype). |
| [`column_count`](/slides/python-net/fa/aspose.slides/itextframeformateffectivedata/column_count/) | تعداد ستون‌های متن در مستطیل مرزی را مشخص می‌کند.<br/> فقط‌خواندنی **int**. |
| [`column_spacing`](/slides/python-net/fa/aspose.slides/itextframeformateffectivedata/column_spacing/) | فاصله بین ستون‌های متن در ناحیه متن (به نقطه) را مشخص می‌کند.<br/> فقط‌خواندنی **float**. |
