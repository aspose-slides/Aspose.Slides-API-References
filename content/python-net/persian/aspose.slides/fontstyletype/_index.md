## FontStyleType شمارش

قالب‌های فرمت‌بندی که می‌توانند بر روی متن اعمال شوند را تعریف می‌کند.

نوع FontStyleType اعضای زیر را در اختیار می‌گذارد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| REGULAR | متن استاندارد. |
| BOLD | متن پررنگ. |
| ITALIC | متن ایتالیک. |
| UNDERLINE | متن زیرخط‌دار. |
| STRIKEOUT | متنی که با خط افقی عبور داده شده است. |
