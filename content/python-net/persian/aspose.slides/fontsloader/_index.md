## FontsLoader کلاس

کلاسی برای بارگذاری قلم‌های سفارشی تعریف‌شده توسط کاربر.
            باید قبل از ایجاد هر شی‌ء ارائه‌ای استفاده شود.

نوع FontsLoader اعضای زیر را در دسترس می‌گذارد:

## متدها

| متد | توضیح |
| :- | :- |
| [`load_external_fonts(directories)`](/slides/python-net/fa/aspose.slides/fontsloader/load_external_fonts/#liststr) | پوشه‌های اضافی برای جستجوی قلم‌ها اضافه می‌کند. |
| [`load_external_font(data)`](/slides/python-net/fa/aspose.slides/fontsloader/load_external_font/#bytes) | قلم را از داده‌های باینری اضافه می‌کند. |
| [`get_font_folders()`](/slides/python-net/fa/aspose.slides/fontsloader/get_font_folders/#) | پوشه‌های قلم را دریافت می‌کند. پوشه‌هایی را که با متد LoadExternalFonts اضافه شده‌اند و همچنین پوشه‌های قلم سیستم را برمی‌گرداند. |
| [`clear_cache()`](/slides/python-net/fa/aspose.slides/fontsloader/clear_cache/#) | تمام قلم‌های سفارشی تعریف‌شده توسط کاربر را آزاد می‌کند. |
