## width ویژگی
دریافت یا تنظیم width شکل، بر حسب نقطه.
            خواندن/نوشتن **float**.


### توضیحات

مقداری که بازگردانده می‌شود همیشه تعریف شده است و هرگز **float** نیست.
            مقدار اختصاص داده شده نیز باید تعریف شده باشد؛ فقط **float** را به ویژگی‌های یک نمونه `RawFrame` اختصاص دهید.
