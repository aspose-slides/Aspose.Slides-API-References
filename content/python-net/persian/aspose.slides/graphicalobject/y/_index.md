## y ویژگی
مختصات y گوشهٔ بالا-چپ شکل را دریافت یا تنظیم می‌کند، به نقطه اندازه‌گیری می‌شود.
            قابل خواندن/نوشتن **float**.


### توضیحات

مقدار بازگردانده‌شده همیشه تعریف‌شده است و هرگز **float** نیست.
            مقدار اختصاص‌یافته نیز باید تعریف‌شده باشد؛ **float** فقط به ویژگی‌های یک نمونهٔ `RawFrame` اختصاص داده شود.

### تعریف:
```python
@property
def y(self):
    ...

@y.setter
def y(self, value):
    ...
```
