## ویژگی portion_format
یک شیء قالب‌بندی را برمی‌گرداند که شامل ویژگی‌های قالب‌بندی به‌طور صریح تنظیم‌شده‌ی بخش متن است بدون اعمال ارث‌بری.
            فقط-خواندنی [`IPortionFormat`](/slides/python-net/fa/aspose.slides/iportionformat).

### توضیحات

شیء قالب‌بندی شامل پارامترهای قالب‌بندی تعریف‌شده فقط برای بخش جاری است، داده‌های ارث‌بری اعمال نمی‌شوند.

برای دریافت مقادیر مؤثر شامل مقادیر ارث‌بری، از روش [`IPortionFormat.get_effective`](/slides/python-net/fa/aspose.slides/iportionformat/get_effective) استفاده کنید.
