## remove(self, item) {#iparagraph}
شیء مورد نظر را برای اولین بار از **System.Collections.Generic.ICollection`1** حذف می‌کند.

### بازگرداندن
true اگر `item` با موفقیت از **System.Collections.Generic.ICollection`1** حذف شده باشد؛ در غیر این صورت false. این روش همچنین در صورتی که `item` در **System.Collections.Generic.ICollection`1** اصلی یافت نشود، false برمی‌گرداند.

```python
def remove(self, item):
    ...
```

| item | [`IParagraph`](/slides/python-net/fa/aspose.slides/iparagraph) | شیئی که باید از **System.Collections.Generic.ICollection`1** حذف شود. |
