## portion_format خاصیت
یک شیء قالب‌بندی را برمی‌گرداند که شامل ویژگی‌های قالب‌بندی به‌صورت صریح تنظیم‌شده‌ی بخش متن است که هیچ وراثتی اعمال نمی‌شود.
فقط-خواندنی [`IPortionFormat`](/slides/python-net/fa/aspose.slides/iportionformat).

### توضیحات

شیء قالب‌بندی فقط شامل پارامترهای قالب‌بندی تعریف‌شده برای بخش فعلی است و داده‌های ارث‌بری اعمال نمی‌شوند.

برای دریافت مقادیر مؤثر شامل مقادیر ارث‌بری، از روش [`PortionFormat.get_effective`](/slides/python-net/fa/aspose.slides/portionformat/get_effective) استفاده کنید.
