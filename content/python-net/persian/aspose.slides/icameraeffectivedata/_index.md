## ICameraEffectiveData کلاس

شیء غیرقابل تغییر که ویژگی‌های مؤثر دوربین را در بر می‌گیرد.

نوع ICameraEffectiveData اعضای زیر را ارائه می‌دهد:

## ویژگی‌ها

| ویژگی | توضیح |
| :- | :- |
| [`camera_type`](/slides/python-net/fa/aspose.slides/icameraeffectivedata/camera_type/) | نوع دوربین.<br/>            فقط‌خواندنی [`CameraPresetType`](/slides/python-net/fa/aspose.slides/camerapresettype). |
| [`field_of_view_angle`](/slides/python-net/fa/aspose.slides/icameraeffectivedata/field_of_view_angle/) | FOV دوربین (0-180 درجه، میدان دید).<br/>            فقط‌خواندنی **float**. |
| [`zoom`](/slides/python-net/fa/aspose.slides/icameraeffectivedata/zoom/) | زوم دوربین (مقدار مثبت به درصد).<br/>            فقط‌خواندنی **float**. |

## متدها

| متد | توضیح |
| :- | :- |
| [`get_rotation(self)`](/slides/python-net/fa/aspose.slides/icameraeffectivedata/get_rotation/#) | یک چرخش از طریق استفاده از مختصات عرض جغرافیایی، مختصات طول جغرافیایی و یک دور حول محور به عنوان مختصات عرض و طول تعریف می‌شود.
            اولین عنصر در آرایهٔ بازگشت - عرض، دوم - طول، سوم - دور.
            اگر چرخشی تعریف نشده باشد، None برگردانده می‌شود. |
