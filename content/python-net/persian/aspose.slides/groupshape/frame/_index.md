## ویژگی فریم
ویژگی‌های فریم شکل را برمی‌گرداند یا تنظیم می‌کند.
            خواندنی/نوشتنی [`IShapeFrame`](/slides/python-net/fa/aspose.slides/ishapeframe).


### توضیحاتی


مقدار هر ویژگی از نمونه IShapeFrame بازگشتی تعریف نشده نیست (NaN یا NotDefined نیست).
            مقدار هر ویژگی از نمونه IShapeFrame اختصاص داده شده باید تعریف نشده نباشد (باید NaN یا NotDefined نباشد).
            شما می‌توانید مقادیر تعریف نشده را برای ویژگی‌های نمونه RawFrame تنظیم کنید.

### تعریف:

```python
@property
def frame(self):
    ...

@frame.setter
def frame(self, value):
    ...
```
