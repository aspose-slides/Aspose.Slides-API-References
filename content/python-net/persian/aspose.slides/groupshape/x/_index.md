## ویژگی x
مختصات x گوشه بالا-چپ شکل را دریافت یا تنظیم می‌کند، که بر حسب نقاط سنجش می‌شود.
            خواندنی/نوشتنی **float**.


### توضیحات

مقدار برگردانده شده همیشه تعریف شده است و هرگز **float** نیست.
            مقدار اختصاص داده‌شده نیز باید تعریف شده باشد؛ **float** را فقط به ویژگی‌های یک نمونه `RawFrame` اختصاص دهید.

### تعریف:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
