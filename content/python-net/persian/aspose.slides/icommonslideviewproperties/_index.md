## ICommonSlideViewProperties کلاس

نمایش ویژگی‌های مشترک اسلاید را نشان می‌دهد.

نوع ICommonSlideViewProperties اعضای زیر را ارائه می‌دهد:

## ویژگی‌ها

| ویژگی | توضیح |
| :- | :- |
| [`scale`](/slides/python-net/fa/aspose.slides/icommonslideviewproperties/scale/) | نسبت مقیاس‌گذاری نمای را بر حسب درصد مشخص می‌کند.<br/>            Read/write **int**. |
| [`variable_scale`](/slides/python-net/fa/aspose.slides/icommonslideviewproperties/variable_scale/) | مشخص می‌کند که محتوای نمای باید به‌صورت خودکار برای بهترین تناسب با اندازه پنجره فعلی مقیاس شود.<br/>            Read/write **bool**. |
| [`drawing_guides`](/slides/python-net/fa/aspose.slides/icommonslideviewproperties/drawing_guides/) | مجموعه راهنمای‌های رسم را برمی‌گرداند.<br/>            Read-only [`IDrawingGuidesCollection`](/slides/python-net/fa/aspose.slides/idrawingguidescollection) |
