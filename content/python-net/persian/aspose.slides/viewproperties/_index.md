## کلاس ViewProperties

ویژگی‌های نمای سراسری ارائه.

نوع ViewProperties اعضای زیر را در دسترس قرار می‌دهد:

## ویژگی‌ها

| ویژگی | توضیح |
| :- | :- |
| [`last_view`](/slides/python-net/fa/aspose.slides/viewproperties/last_view/) | حالت نمایی که هنگام ذخیرهٔ آخرین بار سند ارائه استفاده شد را مشخص می‌کند.<br/>            قابل خواندن/نوشتن [`ViewType`](/slides/python-net/fa/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/fa/aspose.slides/viewproperties/show_comments/) | مشخص می‌کند که نظرات اسلاید نشان داده شوند یا نه.<br/>            قابل خواندن/نوشتن [`NullableBool`](/slides/python-net/fa/aspose.slides/nullablebool). |
| [`normal_view_properties`](/slides/python-net/fa/aspose.slides/viewproperties/normal_view_properties/) | ویژگی‌های نمای عادی را نشان می‌دهد. نمای عادی شامل<br/>            سه ناحیه محتواست: خود اسلاید، یک ناحیه محتوا کناری، و یک ناحیه محتوا پایین.<br/>            فقط قابل خواندن [`INormalViewProperties`](/slides/python-net/fa/aspose.slides/inormalviewproperties). |
| [`slide_view_properties`](/slides/python-net/fa/aspose.slides/viewproperties/slide_view_properties/) | ویژگی‌های نمای مشترک مرتبط با حالت نمای اسلاید را مشخص می‌کند.<br/>            فقط قابل خواندن [`ICommonSlideViewProperties`](/slides/python-net/fa/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/fa/aspose.slides/viewproperties/notes_view_properties/) | ویژگی‌های نمای مشترک مرتبط با حالت نمای یادداشت‌ها را مشخص می‌کند.<br/>            فقط قابل خواندن [`ICommonSlideViewProperties`](/slides/python-net/fa/aspose.slides/icommonslideviewproperties). |
| [`grid_spacing`](/slides/python-net/fa/aspose.slides/viewproperties/grid_spacing/) | فاصلهٔ شبکه‌ای که باید برای شبکهٔ زیرین سند ارائه استفاده شود را بر می‌گرداند یا تنظیم می‌کند، بر حسب نقطه. <br/>            قابل خواندن/نوشتن **float**. |
