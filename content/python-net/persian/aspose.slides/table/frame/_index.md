## ویژگی فریم
مقادیر ویژگی‌های فریم شکل را بر می‌گردانَد یا تنظیم می‌کند.
خواندنی/نوشتنی [`IShapeFrame`](/slides/python-net/fa/aspose.slides/ishapeframe).

### توضیحات

مقدار هر ویژگی از شیء IShapeFrame بازگشتی مقدار undefined ندارد (مقدار NaN یا NotDefined نیست).
مقدار هر ویژگی از شیء IShapeFrame اختصاص داده شده نباید undefined باشد (بیاید NaN یا NotDefined نباشد).
شما می‌توانید مقادیر undefined را برای ویژگی‌های شیء RawFrame تنظیم کنید.
