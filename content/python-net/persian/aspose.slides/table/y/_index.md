## y ویژگی
مختصات y شکل را در گوشهٔ بالایی-چپ می‌گیرد یا تنظیم می‌کند، که بر حسب نقاط اندازه‌گیری می‌شود.
            خواندنی/نوشتنی **float**.


### توضیحات

مقدار بازگردانده شده همیشه تعریف شده است و هرگز **float** نیست.
            مقدار اختصاص دهده شده نیز باید تعریف شده باشد؛ فقط **float** را به ویژگی‌های یک نمونهٔ `RawFrame` اختصاص دهید.

### تعریف:
```python
@property
def y(self):
    ...

@y.setter

    ...
```
