## ویژگی x
مقدار x-مختصات گوشه بالا-چپ شکل را دریافت یا تنظیم می‌کند، به نقطه اندازه‌گیری می‌شود.
            خواندنی/نوشتنی **float**.


### توضیحات

مقدار برگشتی همیشه تعریف شده است و هرگز **float** نیست.
            مقدار اختصاص داده‌شده نیز باید تعریف شده باشد؛ **float** را فقط به ویژگی‌های یک نمونه `RawFrame` اختصاص دهید.

### تعریف:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
