## ویژگی width
دریافت یا تنظیم عرض شکل، که بر حسب نقاط اندازه‌گیری می‌شود.
خواندن/نوشتن **float**.

### توضیحات

مقدار بازگردانده همیشه تعریف شده است و هرگز **float** نیست.
مقدار اختصاص داده شده نیز باید تعریف شده باشد؛ فقط **float** را به ویژگی‌های یک نمونه `RawFrame` اختصاص دهید.
