## کلاس CustomXmlPart

نمایانگر بخش XML سفارشی است.

نوع CustomXmlPart اعضای زیر را ارائه می‌دهد:

## خصوصیات

| Property | Description |
| :- | :- |
| [`xml_data`](/slides/python-net/fa/aspose.slides/customxmlpart/xml_data/) | دریافت یا تنظیم داده‌های xml.<br/>            خواند/نوشت **int**[].<br/>            مقدار `None`. مقدار خالی است یا داده‌های xml نامعتبرند. |
| [`xml_as_string`](/slides/python-net/fa/aspose.slides/customxmlpart/xml_as_string/) | دریافت یا تنظیم داده‌های xml به صورت رشته UTF-8.<br/>            خواند/نوشت **str**.<br/>            مقدار `None`. مقدار خالی است یا داده‌های xml نامعتبرند. |
| [`item_id`](/slides/python-net/fa/aspose.slides/customxmlpart/item_id/) | شناسهٔ globally unique identifier (GUID) را مشخص می‌کند که یک بخش XML سفارشی را به طور یکتا در یک سند Office Open XML شناسایی می‌کند.<br/>            فقط-خواندنی **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/fa/aspose.slides/customxmlpart/namespace_schemas/) | مجموعهٔ طرح‌واره‌های XML مرتبط با بخش XML سفارشی را برمی‌گرداند.<br/>            فقط-خواندنی **str**[]. |
