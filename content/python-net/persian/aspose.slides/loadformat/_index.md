## شمارش LoadFormat

قالب سندی را که باید بارگذاری شود نشان می‌دهد.

نوع LoadFormat اعضای زیر را در اختیار می‌گذارد:

## فیلدها

| Field | Description |
| :- | :- |
| AUTO | به Aspose.Slides می‌گوید که قالب را به‌صورت خودکار تشخیص دهد. |
| PPT | ارائهٔ Microsoft PowerPoint 97-2003. |
| PPS | نمایش اسلاید Microsoft PowerPoint 97-2003. |
| PPTX | سند Microsoft Office Open XML PresentationML. |
| PPSX | نمایش اسلاید Microsoft Office Open XML PresentationML. |
| ODP | ارائهٔ OpenOffice ODF. |
| POTX | قالب Microsoft Office Open XML PresentationML. |
| PPTM | سند Microsoft Office Open XML PresentationML با ماکرو. |
| PPSM | نمایش اسلاید Microsoft Office Open XML PresentationML با ماکرو. |
| POTM | قالب Microsoft Office Open XML PresentationML با ماکرو. |
| OTP | قالب ارائهٔ OpenOffice OTP. |
| PPT95 | ارائهٔ Microsoft PowerPoint 95. |
| POT | قالب ارائهٔ Microsoft PowerPoint 97-2003. |
| FODP | ارائهٔ Flat XML ODF. |
| UNKNOWN | قالب فایل نامعلوم |
