## ShapeAdjustmentType شمارش

انواع مختلف مقادیر تنظیم شکل را مشخص می‌کند.

نوع ShapeAdjustmentType اعضای زیر را نشان می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| CUSTOM | نوع سفارشی (تنظیم ناشناخته) |
| CORNER_SIZE | اندازه گوشه‌ها را کنترل می‌کند. |
| LEFT_UP_CORNER | گوشهٔ بالا سمت چپ را کنترل می‌کند. |
| RIGHT_UP_CORNER | گوشهٔ بالا سمت راست را کنترل می‌کند. |
| UP_CORNERS | گوشه‌های بالایی را کنترل می‌کند. |
| DOWN_CORNERS | گوشه‌های پایین را کنترل می‌کند. |
| THICKNESS | ضخامت شکل را کنترل می‌کند. |
| ARROW_TAIL_THICKNESS | ضخامت دم پیکان را کنترل می‌کند. |
| ARROWHEAD_LENGTH | طول سر پیکان را کنترل می‌کند. |
| ARROWHEAD_WIDTH | عرض سر پیکان را کنترل می‌کند. |
| RADIUS | اندازهٔ شعاع شکل یا بخشی از آن را کنترل می‌کند. |
| DEPTH | عمق دندانه‌های چرخ‌دنده یا اثر زاویه‌دار را کنترل می‌کند. |
| SHAPE_PART_OFFSET | جابه‌جایی یک بخش از شکل نسبت به بخش دیگر را کنترل می‌کند. |
| ANGLE | زاویهٔ شکل یا بخشی از آن را کنترل می‌کند. |
| START_ANGLE | زاویهٔ شروع برای اشکال دایره‌ای و قوس‌دار. |
| END_ANGLE | زاویهٔ پایان برای اشکال دایره‌ای و قوس‌دار. |
| START_POINT_X | موقعیت X نقطه شروع Callout را کنترل می‌کند. |
| START_POINT_Y | موقعیت Y نقطه شروع Callout را کنترل می‌کند. |
| CONNECTOR_POINT_1X | موقعیت افقی نقطه تنظیم زاویه Callout را کنترل می‌کند. |
| CONNECTOR_POINT_1Y | موقعیت عمودی نقطه تنظیم زاویه Callout را کنترل می‌کند. |
| CONNECTOR_POINT_2X | موقعیت افقی نقطه تنظیم زاویه Callout را کنترل می‌کند. |
| CONNECTOR_POINT_2Y | موقعیت عمودی نقطه تنظیم زاویه Callout را کنترل می‌کند. |
| CONNECTOR_BEND_POSITION_X | موقعیت افقی خم در متصل‌کننده را کنترل می‌کند. |
| CONNECTOR_BEND_POSITION_Y | موقعیت عمودی خم در متصل‌کننده را کنترل می‌کند. |
| ATTACH_Y | نقطه اتصال عمودی شکل را کنترل می‌کند. |
| ATTACH_X | نقطه اتصال افقی شکل را کنترل می‌کند. |
| CALLOUT_HEIGHT | اندازۀ عمودی Callout را کنترل می‌کند. |
| CALLOUT_WIDTH | اندازۀ افقی Callout را کنترل می‌کند. |
| CALLOUT_SIZE | اندازۀ Callout را کنترل می‌کند. |
| CURVATURE | قوس یک خم، براکت، پیکان منحنی یا شکل. |
| HORIZONTAL_THICKNESS | ضخامت افقی شکل گوشه را کنترل می‌کند. |
| VERTICAL_THICKNESS | ضخامت عمودی شکل گوشه را کنترل می‌کند. |
| VERTICAL_SIZE | اندازۀ عمودی شکل را کنترل می‌کند. |
| HORIZONTAL_SIZE | اندازۀ افقی شکل را کنترل می‌کند. |
| TOP | طرف بالایی یک شکل را کنترل می‌کند. |
