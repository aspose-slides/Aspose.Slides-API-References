## ILightRigEffectiveData کلاس

شیء غیرقابل تغییر که شامل ویژگی‌های مؤثر رگ نور است.

نوع ILightRigEffectiveData اعضای زیر را نمایان می‌کند:

## ویژگی‌ها

| Property | Description |
| :- | :- |
| [`direction`](/slides/python-net/fa/aspose.slides/ilightrigeffectivedata/direction/) | جهت نور.<br/>            فقط‌خواندنی [`LightingDirection`](/slides/python-net/fa/aspose.slides/lightingdirection). |
| [`light_type`](/slides/python-net/fa/aspose.slides/ilightrigeffectivedata/light_type/) | نمایش می‌دهد یک نور پیش‌تنظیم راست که می‌تواند به شکلی اعمال شود. <br/>            رگ نور یک گروه از نورها را نشان می‌دهد که به‌صورت خاصی نسبت به یک صحنهٔ سه‌بعدی جهت‌دار هستند.<br/>            فقط‌خواندنی [`LightRigPresetType`](/slides/python-net/fa/aspose.slides/lightrigpresettype). |

## متدها

| Method | Description |
| :- | :- |
| [`get_rotation(self)`](/slides/python-net/fa/aspose.slides/ilightrigeffectivedata/get_rotation/#) | یک چرخش از طریق استفاده از مختصات عرض، مختصات طول و یک دور حول محور به عنوان مختصات عرض و طول تعریف می‌شود.<br/>            اولین عنصر در آرایهٔ بازگشتی - عرض، دوم - طول، سوم - دور. |
