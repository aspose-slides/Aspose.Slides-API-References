## کلاس Size

یک جفت مرتب از اعداد صحیح را ذخیره می‌کند که عرض و ارتفاع را مشخص می‌کنند. سازگار با .NET `System.Drawing.Size`.

نوع Size اعضای زیر را در اختیار می‌گذارد:

## سازنده‌ها

| سازنده | توضیح |
| :- | :- |
| [`__init__(self, width=0, height=0)`](/slides/python-net/fa/aspose.slides/size/__init__/#int-int) | یک سایز با عرض و ارتفاع مشخص ایجاد می‌کند. مقادیر شناور به اعداد صحیح برش می‌شوند. |
