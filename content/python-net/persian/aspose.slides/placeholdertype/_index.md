## PlaceholderType لیست مقادیر

نمایانگر نوع یک متغیر نگهدارنده است.

نوع PlaceholderType اعضای زیر را در اختیار می‌گذارد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| TITLE | عنوان. |
| BODY | بدنه. |
| CENTERED_TITLE | عنوان مرکز‌گذاری‌شده. |
| SUBTITLE | زیرعنوان. |
| DATE_AND_TIME | تاریخ و زمان. |
| SLIDE_NUMBER | شماره اسلاید. |
| FOOTER | پایین‌صفحه. |
| HEADER | سرصفحه. |
| OBJECT | شیء. |
| CHART | نمودار. |
| TABLE | جدول. |
| CLIP_ART | گرافیک کلیپ. |
| DIAGRAM | پیکره. |
| MEDIA | رسانه. |
| SLIDE_IMAGE | تصویر اسلاید. |
| PICTURE | تصویر. |
