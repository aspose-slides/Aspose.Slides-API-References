## IVideo کلاس

یک ویدئو که در یک ارائه جاسازی شده است را نشان می‌دهد.

نوع IVideo اعضای زیر را نمایش می‌دهد:

## ویژگی‌ها

| ویژگی | توضیح |
| :- | :- |
| [`content_type`](/slides/python-net/fa/aspose.slides/ivideo/content_type/) | یک نوع MIME برای ویدئو را برمی‌گرداند که در [`IVideo.binary_data`](/slides/python-net/fa/aspose.slides/ivideo/binary_data) کدگذاری شده است.<br/>            فقط‌خواندنی **str**. |
| [`binary_data`](/slides/python-net/fa/aspose.slides/ivideo/binary_data/) | یک کپی از داده‌های صوتی را برمی‌گرداند. در صورت حجم بزرگ داده‌ها استفاده از <br/>            [`IVideo.get_stream`](/slides/python-net/fa/aspose.slides/ivideo/get_stream) متد برای جلوگیری از بارگذاری غیرضروری داده‌های ویدئو در حافظه <br/>            یا حتی OutOfMemoryException.<br/>            فقط‌خواندنی **int**[]. |

## متدها

| متد | توضیح |
| :- | :- |
| [`get_stream(self)`](/slides/python-net/fa/aspose.slides/ivideo/get_stream/#) | یک Stream برای خواندن برمی‌گرداند.<br/>            'using' را استفاده کنید یا پس از استفاده Stream را ببندید. |
