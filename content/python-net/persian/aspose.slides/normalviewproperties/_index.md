## کلاس NormalViewProperties

نمایش عادی را توصیف می‌کند. نمایش عادی شامل
سه منطقه محتوا است: خود اسلاید، یک منطقه محتوا جانبی، و یک منطقه محتوا پایین.

نوع NormalViewProperties اعضای زیر را نشان می‌دهد:

## ویژگی‌ها

| Property | Description |
| :- | :- |
| [`show_outline_icons`](/slides/python-net/fa/aspose.slides/normalviewproperties/show_outline_icons/) | مشخص می‌کند که آیا برنامه باید آیکون‌ها را در صورت نمایش محتوای طرح کلی در هر یک از مناطق محتوا در حالت نمایش عادی نشان دهد.<br/>خواندن/نوشتن **bool**. |
| [`snap_vertical_splitter`](/slides/python-net/fa/aspose.slides/normalviewproperties/snap_vertical_splitter/) | مشخص می‌کند که آیا تقسیم‌کننده عمودی هنگام کوچک شدن کافی منطقه کناری به حالت کوچک شده بچسبد.<br/>خواندن/نوشتن **bool**. |
| [`vertical_bar_state`](/slides/python-net/fa/aspose.slides/normalviewproperties/vertical_bar_state/) | وضعیتی که نوار تقسیم‌کننده عمودی باید در آن نمایش داده شود را مشخص می‌کند.<br/>نوار تقسیم‌کننده عمودی اسلاید را از منطقه محتوا کناری جدا می‌کند. |
| [`horizontal_bar_state`](/slides/python-net/fa/aspose.slides/normalviewproperties/horizontal_bar_state/) | وضعیتی که نوار تقسیم‌کننده افقی باید در آن نمایش داده شود را مشخص می‌کند.<br/>نوار تقسیم‌کننده افقی اسلاید را از منطقه محتوا زیر اسلاید جدا می‌کند. |
| [`prefer_single_view`](/slides/python-net/fa/aspose.slides/normalviewproperties/prefer_single_view/) | مشخص می‌کند که آیا کاربر ترجیح می‌دهد یک منطقه محتوا تک-پنجره‌ای تمام-صفحه به‌جای نمایش عادی استاندارد با سه منطقه محتوا ببیند. در صورت فعال باشد، برنامه ممکن است یکی از مناطق محتوا را در تمام پنجره نمایش دهد.<br/>خواندن/نوشتن **bool**. |
| [`restored_left`](/slides/python-net/fa/aspose.slides/normalviewproperties/restored_left/) | این عنصر اندازه‌گیری منطقه محتوا کناری نمایش عادی را زمانی که منطقه دارای اندازه بازگردانده متغیر باشد (نه کوچک شده نه بزرگ شده) مشخص می‌کند.<br/>فقط خواندنی [`INormalViewRestoredProperties`](/slides/python-net/fa/aspose.slides/inormalviewrestoredproperties). |
| [`restored_top`](/slides/python-net/fa/aspose.slides/normalviewproperties/restored_top/) | این عنصر اندازه‌گیری منطقه اسلاید بالایی نمایش عادی را زمانی که منطقه دارای اندازه بازگردانده متغیر باشد (نه کوچک شده نه بزرگ شده) مشخص می‌کند.<br/>فقط خواندنی [`INormalViewRestoredProperties`](/slides/python-net/fa/aspose.slides/inormalviewrestoredproperties). |
