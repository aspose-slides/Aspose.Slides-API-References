## ویژگی y
مختصات y گوشه بالا-چپ شکل را می‌گیرد یا تنظیم می‌کند، که بر حسب نقطه اندازه‌گیری می‌شود.
            خواندنی/نوشتنی **float**.


### ملاحظات

مقداری که برگردانده می‌شود همیشه تعریف‌شده است و هرگز **float** نیست.
            مقداری که اختصاص می‌یابد نیز باید تعریف‌شده باشد؛ **float** را فقط به خصوصیات یک نمونه `RawFrame` اختصاص دهید.

### تعریف:
```python
@property
def y(self):
    ...

@y.setter
def y(self, value):
    ...
```
