## کلاس GroupShapeLock

تشخیص می‌دهد که کدام عملیات‌ها روی GroupShape والد غیرفعال هستند.

**ارث‌بری:**[`GroupShapeLock`](/slides/python-net/fa/aspose.slides/groupshapelock) → [`BaseShapeLock`](/slides/python-net/fa/aspose.slides/baseshapelock)

نوع GroupShapeLock اعضای زیر را در اختیار می‌گذارد:

## ویژگی‌ها

| ویژگی | توضیح |
| :- | :- |
| [`no_locks`](/slides/python-net/fa/aspose.slides/groupshapelock/no_locks/) | مقدار true را برمی‌گرداند اگر تمام پرچم‌های قفل غیرفعال باشند.<br/>            Read-only **bool**. |
| [`grouping_locked`](/slides/python-net/fa/aspose.slides/groupshapelock/grouping_locked/) | تعیین می‌کند آیا افزودن این شکل به یک گروه ممنوع است یا نه.<br/>            Read/write **bool**. |
| [`ungrouping_locked`](/slides/python-net/fa/aspose.slides/groupshapelock/ungrouping_locked/) | تعیین می‌کند آیا تقسیم این گروه‌شکل ممنوع است یا نه.<br/>            Read/write **bool**. |
| [`select_locked`](/slides/python-net/fa/aspose.slides/groupshapelock/select_locked/) | تعیین می‌کند آیا انتخاب این شکل ممنوع است یا نه.<br/>            Read/write **bool**. |
| [`rotation_locked`](/slides/python-net/fa/aspose.slides/groupshapelock/rotation_locked/) | تعیین می‌کند آیا تغییر زاویه چرخش این شکل ممنوع است یا نه.<br/>            Read/write **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/fa/aspose.slides/groupshapelock/aspect_ratio_locked/) | تعیین می‌کند آیا شکل باید نسبت ابعاد را هنگام تغییر اندازه حفظ کند یا نه.<br/>            Read/write **bool**. |
| [`position_locked`](/slides/python-net/fa/aspose.slides/groupshapelock/position_locked/) | تعیین می‌کند آیا جابه‌جایی این شکل ممنوع است یا نه.<br/>            Read/write **bool**. |
| [`size_locked`](/slides/python-net/fa/aspose.slides/groupshapelock/size_locked/) | تعیین می‌کند آیا تغییر اندازه این شکل ممنوع است یا نه.<br/>            Read/write **bool**. |
