## encrypt_document_properties ویژگی
این ویژگی منطقی است، اگر ارائه با رمز عبور محافظت شده باشد.
اگر true باشد، ویژگی‌های سند در فایل ارائه رمزگذاری می‌شود.
اگر false باشد، ویژگی‌های سند عمومی هستند در حالی که ارائه رمزگذاری شده است.
خواندن/نوشتن **bool**.
