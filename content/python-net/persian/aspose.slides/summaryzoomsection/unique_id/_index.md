## unique_id خاصیت
Returns an internal, presentation-scoped identifier intended for use by add-ins or other code.
            یک شناسهٔ داخلی و مرتبط با ارائه برگردانده می‌شود که برای استفاده توسط افزونه‌ها یا کدهای دیگر منظور شده است.
            از آن‌جایی که این مقدار می‌تواند توسط کاربر یا به‌صورت برنامه‌نویسی مجدداً اختصاص داده شود، نباید به‌عنوان یک کلید یکتا پایدار در نظر گرفته شود.
            فقط-خواندنی **int**.
            همچنین مراجعه کنید به [`Shape.office_interop_shape_id`](/slides/python-net/fa/aspose.slides/shape/office_interop_shape_id).
