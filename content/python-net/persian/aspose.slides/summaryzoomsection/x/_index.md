## خصوصیت x
مختصات x گوشه بالا-چپ شکل را به دست می‌آورد یا تنظیم می‌کند، که بر حسب پوینت اندازه‌گیری می‌شود.
            خواندنی/نوشتنی **float**.


### توضیحات

مقدار بازگشت همیشه تعریف‌شده است و هرگز **float** نیست.
            مقدار اختصاص داده شده نیز باید تعریف‌شده باشد؛ فقط **float** را به ویژگی‌های یک نمونهٔ `RawFrame` اختصاص دهید.

### تعریف:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
