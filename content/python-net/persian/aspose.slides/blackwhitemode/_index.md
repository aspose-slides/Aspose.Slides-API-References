## BlackWhiteMode شمارش

تعیین می‌کند که چگونه شکل رنگی به سیاه و سفید تبدیل شود.

نوع BlackWhiteMode اعضای زیر را ارائه می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| NOT_DEFINED | ویژگی تنظیم نشده است |
| COLOR | شیء با رنگ‌بندی عادی رندر می‌شود |
| AUTOMATIC | شیء با رنگ‌بندی خودکار رندر می‌شود |
| GRAY | شیء با رنگ‌بندی خاکستری رندر می‌شود |
| LIGHT_GRAY | شیء با رنگ‌بندی خاکستری روشن رندر می‌شود |
| INVERSE_GRAY | شیء با رنگ‌بندی خاکستری معکوس رندر می‌شود |
| GRAY_WHITE | شیء با رنگ‌بندی خاکستری و سفید رندر می‌شود |
| BLACK_GRAY | شیء با رنگ‌بندی سیاه و خاکستری رندر می‌شود |
| BLACK_WHITE | شیء با رنگ‌بندی سیاه و سفید رندر می‌شود |
| BLACK | شیء فقط با رنگ سیاه رندر می‌شود |
| WHITE | شیء با رنگ سفید رندر می‌شود |
| HIDDEN | شیء رندر نمی‌شود |
