## کلاس SensitivityLabel

نمایش دهنده برچسب حساسیت از Microsoft Purview Information Protection.

نوع SensitivityLabel اعضای زیر را نمایان می‌کند:

## ویژگی‌ها

| ویژگی | توضیح |
| :- | :- |
| [`id`](/slides/python-net/fa/aspose.slides/sensitivitylabel/id/) | مقدار یا تعیین‌کننده شناسه برچسب حساسیت.<br/>            خواندنی/نوشتنی **str**. |
| [`site_id`](/slides/python-net/fa/aspose.slides/sensitivitylabel/site_id/) | مقدار یا تعیین‌کننده شناسه سایت Azure Active Directory (Azure AD) <br/>            که مربوط به سیاست برچسب حساسیت است که برچسب حساسیت را توصیف می‌کند.<br/>            خواندنی/نوشتنی **System.Guid**. |
| [`is_enabled`](/slides/python-net/fa/aspose.slides/sensitivitylabel/is_enabled/) | نشان می‌دهد آیا برچسب حساسیت فعال است یا خیر. |
| [`is_removed`](/slides/python-net/fa/aspose.slides/sensitivitylabel/is_removed/) | نشان می‌دهد آیا برچسب حساسیت حذف شده است یا خیر. |
| [`assignment_method_type`](/slides/python-net/fa/aspose.slides/sensitivitylabel/assignment_method_type/) | مقدار یا تعیین‌کننده روش انتساب برای برچسب حساسیت.<br/>            خواندنی/نوشتنی [`SensitivityLabelAssignmentType`](/slides/python-net/fa/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/fa/aspose.slides/sensitivitylabel/content_mark_types/) | فهرست انواع علامت‌گذاری محتوا که باید بر روی یک فایل اعمال شود را برمی‌گرداند. |
