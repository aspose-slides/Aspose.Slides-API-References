## SensitivityLabelAssignmentType شمارش

نمایانگر روش تخصیص برای برچسب حساسیت است.

نوع SensitivityLabelAssignmentType اعضای زیر را نمایش می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| STANDARD | برای هر برچسب حساسیتی که به‌طور مستقیم توسط کاربر اعمال نشده است استفاده می‌شود.<br/> این شامل هر برچسب پیش‌فرض و برچسب‌های اعمال‌شده به‌صورت خودکار است. |
| PRIVILEGED | برای هر برچسب حساسیتی که به‌طور مستقیم توسط کاربر اعمال شده است استفاده می‌شود.<br/> این شامل هر برچسب حساسیتی است که به‌صورت دستی اعمال شده باشد، همچنین پیشنهادی<br/> یا برچسب‌گذاری اجباری یا هر ویژگی که در آن کاربر تصمیم می‌گیرد کدام برچسب حساسیت را اعمال کند. |
