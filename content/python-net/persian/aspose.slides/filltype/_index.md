## FillType شمارش

نوع پرکردن داخلی اشیاء تصویری مختلف را تعیین می‌کند.

نوع FillType اعضای زیر را در اختیار می‌گذارد:

## فیلدها

| فیلد | توضیحات |
| :- | :- |
| NOT_DEFINED | نوع پرکردن تعریف نشده است. |
| NO_FILL | بدون پرکردن اعمال شده. |
| SOLID | با یک رنگ ثابت پر می‌شود. |
| GRADIENT | پرکردن به صورت گرادیان است. |
| PATTERN | الگوی تکراری برای پرکردن شیء استفاده می‌شود. |
| PICTURE | یک تصویر واحد برای پرکردن شیء استفاده می‌شود. |
| GROUP | شیء تصویری ویژگی‌های پرکردن را از گروه به ارث می‌برد. |
