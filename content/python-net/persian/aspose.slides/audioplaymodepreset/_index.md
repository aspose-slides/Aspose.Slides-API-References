## شمارش AudioPlayModePreset

ثابت‌هایی که نحوه پخش صدا را تعیین می‌کنند.

نوع AudioPlayModePreset اعضای زیر را نمایش می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| MIXED |  |
| AUTO | به صورت خودکار پخش می‌شود. |
| ON_CLICK | فقط زمانی که نماد کلیک می‌شود، پخش می‌شود. |
| ALL_SLIDES | در تمام اسلایدها پخش می‌شود.<br/>            لطفاً به جای آن از ویژگی [`IAudioFrame.play_across_slides`](/slides/python-net/fa/aspose.slides/iaudioframe/play_across_slides) استفاده کنید.<br/>            این عنصر از PowerPoint 2013 به بعد منسوخ شده است. |
| IN_CLICK_SEQUENCE | به صورت خودکار با یک کلیک پخش می‌شود. |
