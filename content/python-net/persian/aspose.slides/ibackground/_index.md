## IBackground کلاس

پس‌زمینه یک اسلاید را نشان می‌دهد.

نوع IBackground اعضای زیر را در اختیار می‌گذارد:

## ویژگی‌ها

| Property | Description |
| :- | :- |
| [`type`](/slides/python-net/fa/aspose.slides/ibackground/type/) | یک نوع پرکردن پس‌زمینه را برمی‌گرداند.<br/>            قابل خواندن/نوشتن [`BackgroundType`](/slides/python-net/fa/aspose.slides/backgroundtype). |
| [`fill_format`](/slides/python-net/fa/aspose.slides/ibackground/fill_format/) | یک FillFormat برای پرکردن BackgroundType.OwnBackground برمی‌گرداند.<br/>            فقط قابل خواندن [`IFillFormat`](/slides/python-net/fa/aspose.slides/ifillformat). |
| [`effect_format`](/slides/python-net/fa/aspose.slides/ibackground/effect_format/) | یک EffectFormat برای پرکردن BackgroundType.OwnBackground برمی‌گرداند.<br/>            فقط قابل خواندن [`IEffectFormat`](/slides/python-net/fa/aspose.slides/ieffectformat). |
| [`style_color`](/slides/python-net/fa/aspose.slides/ibackground/style_color/) | یک ColorFormat برای پرکردن BackgroundType.Themed برمی‌گرداند.<br/>            فقط قابل خواندن [`IColorFormat`](/slides/python-net/fa/aspose.slides/icolorformat). |
| [`style_index`](/slides/python-net/fa/aspose.slides/ibackground/style_index/) | یک ایندکس از پرکردن BackgroundType.Themed در مجموعه تم پس‌زمینه را برمی‌گرداند.<br/>            0 به معنی بدون پرکردن.<br/>            1..999 - ایندکس.<br/>            قابل خواندن/نوشتن **int**. |
| [`slide`](/slides/python-net/fa/aspose.slides/ibackground/slide/) |  |
