## ISvgImage کلاس

یک تصویر SVG را نمایان می‌کند.

نوع ISvgImage اعضای زیر را در اختیار می‌گذارد:

## خصوصیات

| خصوصیت | توضیح |
| :- | :- |
| [`svg_content`](/slides/python-net/fa/aspose.slides/isvgimage/svg_content/) | محتویات SVG را برمی‌گرداند.<br/>            فقط-خواندنی **str**. |
| [`svg_data`](/slides/python-net/fa/aspose.slides/isvgimage/svg_data/) | داده‌های SVG را برمی‌گرداند.<br/>            فقط-خواندنی **int**[]. |
| [`external_resource_resolver`](/slides/python-net/fa/aspose.slides/isvgimage/external_resource_resolver/) | رابط‌کاربری کال-بک مورد استفاده برای حل منابع خارجی هنگام وارد کردن اسناد SVG را برمی‌گرداند.<br/>            فقط-خواندنی **IExternalResourceResolver**. |
| [`base_uri`](/slides/python-net/fa/aspose.slides/isvgimage/base_uri/) | URI پایهٔ SVG مشخص‌شده را برمی‌گرداند. برای حل لینک‌های نسبی استفاده می‌شود.<br/>            فقط-خواندنی **str**. |
