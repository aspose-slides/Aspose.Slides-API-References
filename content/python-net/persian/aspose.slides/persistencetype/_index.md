## PersistenceType شمارش

روش استفاده‌شده برای ذخیره‌سازی ویژگی‌های کنترل ActiveX را مشخص می‌کند.

نوع PersistenceType اعضای زیر را نمایش می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| NOT_DEFINED | شناسه persistance مشخص نشده است. |
| PERSIST_PROPERTY_BAG | مشخص می‌کند که کنترل ActiveX با استفاده از پایداری مبتنی بر property-bag ذخیره می‌شود. <br/>             پایداری مبتنی بر property-bag، کنترل ActiveX را از طریق مجموعه‌ای از جفت‌های نام و مقدار که داده‌های ذخیره‌شده توسط کنترل ActiveX را مشخص می‌کنند، ذخیره می‌کند. |
| PERSIST_STREAM | مشخص می‌کند که کنترل ActiveX با استفاده از پایداری مبتنی بر جریان ذخیره می‌شود<br/>             که پشتیبانی از مقداردهی اولیه کنترل ActiveX به حالت پیش‌فرض را ندارد. |
| PERSIST_STREAM_INIT | مشخص می‌کند که کنترل ActiveX با استفاده از پایداری مبتنی بر جریان ذخیره می‌شود<br/>             که پشتیبانی از مقداردهی اولیه کنترل ActiveX به حالت پیش‌فرض را دارد. |
| PERSIST_STORAGE | مشخص می‌کند که کنترل ActiveX با استفاده از پایداری مبتنی بر ذخیره‌سازی ذخیره می‌شود. |
