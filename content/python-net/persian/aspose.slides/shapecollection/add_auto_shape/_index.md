## add_auto_shape(self, shape_type, x, y, width, height, create_from_template) {#shapetype-float-float-float-float-bool}
یک شکل خودکار جدید ایجاد می‌کند و آن را به انتهای مجموعه شکل‌ها اضافه می‌کند، به‌طور اختیاری آن را با قالب پیش‌فرض الگو مقداردهی اولیه می‌کند.

### Returns

[`IAutoShape`](/slides/python-net/fa/aspose.slides/iautoshape) جدید ایجاد شده.



```python
def add_auto_shape(self, shape_type, x, y, width, height, create_from_template):
    ...
```


| پارامتر | نوع | توضیح |
| :- | :- | :- |
| shape_type | [`ShapeType`](/slides/python-net/fa/aspose.slides/shapetype) | [`ShapeType`](/slides/python-net/fa/aspose.slides/shapetype) شکل خودکار برای افزودن. |
| x | **float** | مختصات x قاب شکل، به نقطه. |
| y | **float** | مختصات y قاب شکل، به نقطه. |
| width | **float** | عرض قاب شکل، به نقطه. |
| height | **float** | ارتفاع قاب شکل، به نقطه. |
| create_from_template | **bool** | True برای اعمال قالب پیش‌فرض الگو (سبک ساده، متن مرکزچین، و نام غیر خالی)<br/><br/>به شکل جدید؛ false برای ایجاد شکل با تمام ویژگی‌ها به مقادیر پیش‌فرض. |
