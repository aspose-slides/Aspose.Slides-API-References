def insert_connector(self, index, shape_type, x, y, width, height, create_from_template):

| پارامتر | نوع | توضیح |
| :- | :- | :- |
| index | **int** | اندیسی صفر-پایه که شکل وصل‌کننده در آن درج می‌شود. |
| shape_type | [`ShapeType`](/slides/python-net/fa/aspose.slides/shapetype) | [`ShapeType`](/slides/python-net/fa/aspose.slides/shapetype) شکل وصل‌کننده‌ای که قرار است درج شود. |
