## reorder(self, index, shape) {#int-ishape}
شکل مشخص‌شده را به موقعیتی جدید درون مجموعهٔ اشکال منتقل می‌کند.

```python
def reorder(self, index, shape):
    ...
```

| پارامتر | نوع | توضیح |
| :- | :- | :- |
| index | **int** | اندیس هدف صفر-مبنا که شکل در آن قرار می‌گیرد. |
| shape | [`IShape`](/slides/python-net/fa/aspose.slides/ishape) | [`IShape`](/slides/python-net/fa/aspose.slides/ishape) را برای جابه‌جایی درون مجموعه. |

## reorder(self, index, shapes) {#int-listishape}
اشکال مشخص‌شده را درون مجموعهٔ اشکال جابه‌جا می‌کند و آن‌ها را از اندیس داده‌شده قرار می‌دهد.

```python
def reorder(self, index, shapes):
    ...
```

| پارامتر | نوع | توضیح |
| :- | :- | :- |
| index | **int** | اندیس هدف صفر-مبنا که اولین شکل مشخص‌شده در آن قرار می‌گیرد; <br/><br/> شکل‌های بعدی به ترتیب ارائه‌شده پیگیری می‌شوند. |
| shapes | **List[IShape]** | یک یا چند نمونهٔ [`IShape`](/slides/python-net/fa/aspose.slides/ishape) برای جابه‌جایی درون مجموعه. |
