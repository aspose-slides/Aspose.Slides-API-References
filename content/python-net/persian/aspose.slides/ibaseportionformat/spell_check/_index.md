## spell_check ویژگی
Gets or sets a value indicating whether spell checking is enabled for the text portion.
            زمانی که این ویژگی به false تنظیم شود، بررسی‌های املا برای عناصر متن سرکوب می‌شوند.
            زمانی که به true تنظیم شود، بررسی املا مجاز است.
            مقدار پیش‌فرض `false` است.
