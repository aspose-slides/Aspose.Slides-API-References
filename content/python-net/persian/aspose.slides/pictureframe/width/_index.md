## width خاصیت
دریافت یا تنظیم width shape، که به نقطه اندازه‌گیری می‌شود.
            خواندنی/نوشتنی **float**.


### توضیحات

مقدار بازگردانده شده همواره تعریف شده است و هرگز **float** نیست.
            مقدار اختصاص داده شده نیز باید تعریف شده باشد؛ فقط **float** را به ویژگی‌های یک نمونه `RawFrame` اختصاص دهید.
