## x ویژگی
مقدار مختصات x گوشهٔ بالایی-چپ شکل را دریافت یا تنظیم می‌کند، که بر حسب پوینت اندازه‌گیری می‌شود.
            قابل خواندن/نوشتن **float**.

### توضیحات
مقدار برگشتی همیشه تعریف شده است و هرگز **float** نیست.
            مقدار اختصاص داده شده نیز باید تعریف شده باشد؛ فقط **float** را به ویژگی‌های یک نمونهٔ `RawFrame` اختصاص دهید.

### تعریف:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
