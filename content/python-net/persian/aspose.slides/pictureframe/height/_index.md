## height خصوصیت
دریافت یا تنظیم height شکل، بر حسب نقطه.
خواندنی/نوشتنی **float**.

### توضیحات

مقدار بازگردانده شده همیشه تعریف شده است و هرگز **float** نیست.
مقدار اختصاص داده شده نیز باید تعریف شده باشد؛ **float** را فقط به خصوصیات یک نمونه `RawFrame` اختصاص دهید.
