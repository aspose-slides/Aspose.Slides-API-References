## ویژگی x
مختصات x گوشهٔ بالا-چپ شکل را دریافت یا تنظیم می‌کند و بر حسب پوینت اندازه‌گیری می‌شود.
            خواندنی/نوشتنی **float**.


### نکات

مقداری که برگردانده می‌شود همیشه تعریف‌شده است و هرگز **float** نیست.
            مقداری که اختصاص می‌دهد نیز باید تعریف‌شده باشد؛ **float** را فقط به ویژگی‌های یک نمونهٔ `RawFrame` اختصاص دهید.

### تعریف:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
