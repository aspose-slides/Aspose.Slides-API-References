## شمارش PathCommandType

نمایش دهنده دستورات مسیر گرافیکی

نوع PathCommandType اعضای زیر را فراهم می‌کند:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| CLOSE | مسیر هندسی را می‌بندد |
| MOVE_TO | موقعیت نقطه بعدی مسیر هندسی را تنظیم می‌کند |
| LINE_TO | خطی به مسیر هندسی اضافه می‌کند |
| ARC_TO | قوس مشخص شده را به مسیر هندسی اضافه می‌کند. |
| QUAD_BEZIER_TO | منحنی بزیه درجه دوم را به مسیر هندسی اضافه می‌کند |
| CUBIC_BEZIER_TO | منحنی بزیه درجه سه را به مسیر هندسی اضافه می‌کند |
