## only_load_document_properties ویژگی
این ویژگی زمانی معنادار است که فایل ارائه رمزگذاری شده باشد.
            مقدار true به این معنی است که تنها ویژگی‌های سند باید از یک فایل ارائه رمزگذاری شده
            بارگذاری شود و رمز عبور نادیده گرفته شود.
            مقدار false به این معنی است که تمام ارائه رمزگذاری شده باید با استفاده از رمز صحیح
            بارگذاری شود.
            اگر ارائه رمزگذاری نشده باشد، مقدار ویژگی همیشه نادیده گرفته می‌شود.
            اگر ویژگی‌های سند یک فایل رمزگذاری شده عمومی نباشند و مقدار ویژگی true باشد
            قابلیت بارگذاری ویژگی‌های سند وجود نخواهد داشت و استثنایی پرتاب خواهد شد.
            قابل خواندن/نوشتن **bool**.
