## ویژگی x
دریافت یا تنظیم مختصات x گوشهٔ بالایی-چپ شکل، بر حسب نقاط.
Read/write **float**.

### توضیحات

مقدار بازگردانده شده همیشه تعریف شده است و هرگز **float** نیست.
مقدار اختصاص داده شده نیز باید تعریف شده باشد؛ فقط **float** را به ویژگی‌های یک نمونهٔ `RawFrame` اختصاص دهید.

### تعریف:
```python
@property
def x(self):
    ...

@x.setter
def x(self, value):
    ...
```
