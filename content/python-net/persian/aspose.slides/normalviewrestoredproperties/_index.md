## NormalViewRestoredProperties کلاس

اندازه‌گذاری ناحیه اسلاید را مشخص می‌کند ((عرض زمانی که فرزند RestoredTop باشد، ارتفاع زمانی که فرزند RestoredLeft باشد) در نمای عادی، هنگامی که ناحیه دارای اندازه متغیر بازگردانده‌شده باشد (نه حداقل‌سازی‌شده نه بیشینه‌شده)).

### ویژگی‌ها

| Property | Description |
| :- | :- |
| [`dimension_size`](/slides/python-net/fa/aspose.slides/normalviewrestoredproperties/dimension_size/) | اندازۀ ناحیه اسلاید را مشخص می‌کند (عرض زمانی که فرزند RestoredTop باشد، ارتفاع زمانی که <br/>            فرزند RestoredLeft باشد).<br/>            خواندنی/نوشتنی **float**. |
| [`auto_adjust`](/slides/python-net/fa/aspose.slides/normalviewrestoredproperties/auto_adjust/) | مشخص می‌کند آیا اندازهٔ ناحیه محتواهای جانبی باید برای اندازهٔ جدید جبران کند<br/>            هنگام تغییر اندازهٔ پنجرهٔ حاوی نمای داخل برنامه<br/>            خواندنی/نوشتنی **bool**. |
