## TextVerticalType enumeration

حالت نوشتن عمودی متن را تعیین می‌کند.

نوع TextVerticalType اعضای زیر را ارائه می‌دهد:

## فیلدها

| فیلد | توضیحات |
| :- | :- |
| NOT_DEFINED | تعریف نشده. |
| HORIZONTAL | متن افقی. |
| VERTICAL | متن عمودی. |
| VERTICAL270 | متن عمودی 270 درجه. |
| WORD_ART_VERTICAL | متن عمودی WordArt. |
| EAST_ASIAN_VERTICAL | متن عمودی شرق آسیا. |
| MONGOLIAN_VERTICAL | متن عمودی مغولی. |
| WORD_ART_VERTICAL_RIGHT_TO_LEFT | متن عمودی WordArt از راست به چپ. |
