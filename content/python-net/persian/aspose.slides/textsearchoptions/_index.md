## TextSearchOptions کلاس

نمایانگر گزینه‌هایی است که می‌توان از آنها برای جستجوی متن در یک Presentation، Slide یا TextFrame استفاده کرد.

نوع TextSearchOptions اعضای زیر را ارائه می‌دهد:

## سازنده‌ها

| سازنده | توضیح |
| :- | :- |
| [`__init__(self)`](/slides/python-net/fa/aspose.slides/textsearchoptions/__init__/#) | یک گزینه جستجوی متن پیش‌فرض جدید ایجاد می‌کند. |

## خصوصیات

| خصوصیت | توضیح |
| :- | :- |
| [`case_sensitive`](/slides/python-net/fa/aspose.slides/textsearchoptions/case_sensitive/) | برای استفاده از جستجوی حساس به حروف بزرگ، مقدار true را تنظیم کنید، در غیر این صورت false.<br/>            خواندنی/نوشتنی **bool**. |
| [`whole_words_only`](/slides/python-net/fa/aspose.slides/textsearchoptions/whole_words_only/) | برای انطباق فقط با کلمات کامل، مقدار true را تنظیم کنید، در غیر این صورت false.<br/>            خواندنی/نوشتنی **bool**. |
| [`include_notes`](/slides/python-net/fa/aspose.slides/textsearchoptions/include_notes/) | مقدار `true` را تنظیم کنید تا متن موجود در یادداشت‌های اسلاید ([`NotesSlide`](/slides/python-net/fa/aspose.slides/notesslide)) <br/>            هنگام انجام عملیات جستجوی متن، جایگزینی یا هایلایت کردن گنجانده شود.<br/>            مقدار پیش‌فرض `false` است. |
