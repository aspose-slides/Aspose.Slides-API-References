## ویژگی y
مختصات y گوشه بالا-چپ شکل را دریافت یا تعیین می‌کند، که بر حسب نقطه اندازه‌گیری می‌شود.
قابل خواندن/قابل نوشتن **float**.

### توضیحات

مقدار بازگردانده شده همیشه تعریف‌شده است و هرگز **float** نیست.
مقدار اختصاص داده شده نیز باید تعریف‌شده باشد؛ **float** فقط به ویژگی‌های یک نمونه‌ی `RawFrame` اختصاص دهید.

### تعریف:
```python
@property
def y(self):
    ...

@y.setter
def y(self, value):
    ...
```
