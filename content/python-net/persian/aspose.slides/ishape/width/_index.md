## width ویژگی
Gets or sets the width of the shape, measured in points.
            خواندنی/نوشتنی **float**.

### توضیحات
مقدار بازگردانده شده همیشه تعریف شده است و هرگز **float** نیست.
            مقدار اختصاص داده‌شده نیز باید تعریف شده باشد؛ فقط **float** را به ویژگی‌های یک نمونه `RawFrame` اختصاص دهید.
