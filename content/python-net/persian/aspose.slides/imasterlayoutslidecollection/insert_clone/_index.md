## insert_clone(self, index, source_layout) {#int-ilayoutslide}
یک کپی از اسلاید طرح‌بندی مشخص‌شده را در موقعیت تعیین‌شدهٔ مجموعه درج می‌کند.

### بازگشت

اسلاید درج‌شده.

```python
def insert_clone(self, index, source_layout):
    ...
```

| پارامتر | نوع | توضیح |
| :- | :- | :- |
| index | **int** | اندیس اسلاید جدید. |
| source_layout | [`ILayoutSlide`](/slides/python-net/fa/aspose.slides/ilayoutslide) | اسلاید برای کلون. |

### توضیحات

طرح‌بندی جدید با اسلاید مستر والد برای این مجموعهٔ اسلایدهای طرح‌بندی پیوند خواهد شد. بنابراین این مشابه عملیات کپی/چسباندن با گزینه «Use Destination Theme» در PowerPoint است.
