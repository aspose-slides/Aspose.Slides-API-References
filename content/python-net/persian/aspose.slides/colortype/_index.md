## شمارش ColorType

نمایش‌دهندهٔ حالت‌های مختلف رنگ.

نوع ColorType اعضای زیر را در دسترس قرار می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| NOT_DEFINED | رنگ به‌طور کامل تعریف نشده است. |
| RGB | رنگ استاندارد ۲۴ بیتی RGB. |
| RGB_PERCENTAGE | رنگ RGB با وضوح بالا. |
| HSL | رنگ HSL با وضوح بالا. |
| SCHEME | رنگ طرح. |
| SYSTEM | رنگ سیستم. |
| PRESET | رنگ پیش‌تنظیم. |
