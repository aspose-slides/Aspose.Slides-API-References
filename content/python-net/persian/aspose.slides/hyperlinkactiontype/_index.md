## HyperlinkActionType نوع شمارشی

نمایش‌دهنده یک نوع عمل پیوند.

نوع HyperlinkActionType اعضای زیر را در اختیار می‌گذارد:

## Fields

| فیلد | توضیح |
| :- | :- |
| UNKNOWN | نوع عمل تشخیص داده نشده. |
| NO_ACTION | بدون عمل. |
| HYPERLINK | لینک معمولی. |
| JUMP_FIRST_SLIDE | پرش به اولین اسلاید ارائه. |
| JUMP_PREVIOUS_SLIDE | پرش به اسلاید قبلی. |
| JUMP_NEXT_SLIDE | پرش به اسلاید بعدی. |
| JUMP_LAST_SLIDE | پرش به آخرین اسلاید ارائه. |
| JUMP_END_SHOW | پرش به پایان نمایش اسلایدها. |
| JUMP_LAST_VIEWED_SLIDE | پرش به آخرین اسلاید مشاهده شده. |
| JUMP_SPECIFIC_SLIDE | پرش به اسلاید خاصی که توسط ویژگی [`IHyperlink.target_slide`](/slides/python-net/fa/aspose.slides/ihyperlink/target_slide) ارجاع داده می‌شود. |
| START_CUSTOM_SLIDE_SHOW | شروع نمایش اسلاید سفارشی. |
| OPEN_FILE | باز کردن فایل مرجع. |
| OPEN_PRESENTATION | باز کردن ارائه مرجع. |
| START_STOP_MEDIA | شروع/توقف پخش فایل رسانه‌ای. |
| START_MACRO | شروع اجرای اسکریپت ماکرو. |
| START_PROGRAM | شروع برنامه. |
