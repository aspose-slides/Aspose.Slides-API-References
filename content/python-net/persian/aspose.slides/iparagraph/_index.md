## IParagraph کلاس

یک پاراگراف از متن را نشان می‌دهد.

نوع IParagraph اعضای زیر را در اختیار می‌گذارد:

## ویژگی‌ها

| ویژگی | توضیح |
| :- | :- |
| [`portions`](/slides/python-net/fa/aspose.slides/iparagraph/portions/) | مجموعه‌ای از بخش‌های متن را برمی‌گرداند.<br/>            فقط-خواندنی [`IPortionCollection`](/slides/python-net/fa/aspose.slides/iportioncollection). |
| [`paragraph_format`](/slides/python-net/fa/aspose.slides/iparagraph/paragraph_format/) | شیء قالب‌بندی برای این پاراگراف را برمی‌گرداند.<br/>            فقط-خواندنی [`IParagraphFormat`](/slides/python-net/fa/aspose.slides/iparagraphformat). |
| [`text`](/slides/python-net/fa/aspose.slides/iparagraph/text/) | متن ساده یک پاراگراف را می‌گیرد یا تنظیم می‌کند.<br/>            خواندنی/قابل‌نوشتن **str**. |
| [`end_paragraph_portion_format`](/slides/python-net/fa/aspose.slides/iparagraph/end_paragraph_portion_format/) | مشخص می‌کند ویژگی‌های بخش که در صورت افزودن بخش دیگری پس از <br/>            آخرین بخش استفاده می‌شوند. |
| [`slide`](/slides/python-net/fa/aspose.slides/iparagraph/slide/) |  |
