## IParagraph کلاس

نمایش یک پاراگراف از متن.

نوع IParagraph اعضای زیر را افشا می‌کند:

## ویژگی‌ها

| ویژگی | توضیح |
| :- | :- |
| [`portions`](/slides/python-net/fa/aspose.slides/iparagraph/portions/) | مجموعهٔ قسمت‌های متن را برمی‌گرداند.<br/>            فقط خواندنی [`IPortionCollection`](/slides/python-net/fa/aspose.slides/iportioncollection). |
| [`paragraph_format`](/slides/python-net/fa/aspose.slides/iparagraph/paragraph_format/) | شیء قالب‌بندی این پاراگراف را برمی‌گرداند.<br/>            فقط خواندنی [`IParagraphFormat`](/slides/python-net/fa/aspose.slides/iparagraphformat). |
| [`text`](/slides/python-net/fa/aspose.slides/iparagraph/text/) | متن سادهٔ پاراگراف را دریافت یا تنظیم می‌کند.<br/>            قابل خواندن/نوشتن **str**. |
| [`end_paragraph_portion_format`](/slides/python-net/fa/aspose.slides/iparagraph/end_paragraph_portion_format/) | مشخص می‌کند که ویژگی‌های قسمت چه زمانی استفاده شود اگر قسمت دیگری پس از آخرین قسمت درج شود. |
| [`slide`](/slides/python-net/fa/aspose.slides/iparagraph/slide/) |  |
| [`presentation`](/slides/python-net/fa/aspose.slides/iparagraph/presentation/) |  |
