

| پارامتر | نوع | توضیح |
| :- | :- | :- |
| character | **char** | کاراکتر گروه‌بندی مانند BOTTOM CURLY BRACKET (U+23DF) یا هر کاراکتر دیگری |
| position | [`MathTopBotPositions`](/slides/python-net/fa/aspose.slides.mathtext/mathtopbotpositions) | موقعیت کاراکتر گروه‌بندی |
| vertical_justification | [`MathTopBotPositions`](/slides/python-net/fa/aspose.slides.mathtext/mathtopbotpositions) | تراز عمودی کاراکتر گروه.<br/><br/>            ترازبندی شیء نسبت به خط پایه را مشخص می‌کند.<br/><br/>            به عنوان مثال، وقتی کاراکتر گروه بالای شیء قرار دارد، <br/><br/>            VerticalJustification از مقدار Top نشان می‌دهد که بالای شیء بر روی خط پایه قرار می‌گیرد؛<br/><br/>            وقتی VerticalJustification برابر Bottom تنظیم شود، پایین شیء بر روی خط پایه قرار می‌گیرد |
