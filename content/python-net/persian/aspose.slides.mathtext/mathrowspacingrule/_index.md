## شمارشی MathRowSpacingRule

نوع فاصله عمودی بین ستون‌ها در یک ماتریس یا آرایه

نوع MathRowSpacingRule اعضای زیر را ارائه می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| SINGLE_LINE_GAP | فاصله تک خطی |
| ONE_AND_A_HALF_LINE_GAP | فاصله یک و نیم خطی |
| TWO_LINE_GAP | فاصله دو خطی |
| EXACTLY | دقیقاً (به مقدار ویژگی RowSpacing متکی است که بر حسب نقطه اندازه‌گیری می‌شود) |
| MULTIPLE | چندگانه (به مقدار ویژگی RowSpacing متکی است که بر حسب خطوط اندازه‌گیری می‌شود) |
