## ویژگی portion_format
یک شیء قالب‌بندی را برمی‌گرداند که شامل ویژگی‌های قالب‌بندی به‌طور صریح تنظیم‌شدهٔ بخش متن است و هیچ ارث‌بری اعمال نمی‌شود.
            فقط-خواندنی [`IPortionFormat`](/slides/python-net/fa/aspose.slides/iportionformat).

### توضیحات

شیء قالب‌بندی شامل پارامترهای قالب‌بندی تعریف‌شده فقط برای بخش فعلی است و داده‌های ارث‌بری اعمال نمی‌شوند.

برای دریافت مقادیر مؤثر شامل ارث‌برده‌ها از روش [`PortionFormat.get_effective`](/slides/python-net/fa/aspose.slides/portionformat/get_effective) استفاده کنید.
