## MathSpacingRules شمارش

انواع فاصله (فاصله افقی) بین ستون‌های یک ماتریس

نوع MathSpacingRules اعضای زیر را ارائه می‌دهد:

## فیلدها

| فیلد | توضیح |
| :- | :- |
| SINGLE_SPACING_GAP | تک (1 em برای ستون‌ها یا 1 خط برای ردیف‌ها) |
| ONE_AND_HALF_SPACING_GAP | یک و نیم (1.5 em برای ستون‌ها یا 1.5 خط برای ردیف‌ها) |
| DOUBLE_SPACING_GAP | فاصله دو برابر (2 em برای ستون‌ها یا 2 خط برای ردیف‌ها) |
| EXACTLY | مقدار دقیق<br/>            برای ستون‌ها، به مقدار ColumnGap وابسته است، که بر حسب twips اندازه‌گیری می‌شود<br/>            برای ردیف‌ها، به مقدار RowGap وابسته است، که بر حسب twips اندازه‌گیری می‌شود |
| MULTIPLE | چندگانه<br/>            برای ستون‌ها، به مقدار ColumnGap وابسته است، که بر حسب گام‌های 0.5 em اندازه‌گیری می‌شود<br/>            برای ردیف‌ها، به مقدار RowGap وابسته است، که بر حسب خطوط اندازه‌گیری می‌شود |
