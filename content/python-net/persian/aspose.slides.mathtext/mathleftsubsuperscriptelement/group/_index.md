### بازگرداندن

```python

    ...
```


| Parameter | Type | Description |
| :- | :- | :- |
| character | **char** | کاراکتر گروه‌بندی مانند پرانتز منحنی پایین (U+23DF) یا هر کاراکتر دیگری |
| position | [`MathTopBotPositions`](/slides/python-net/fa/aspose.slides.mathtext/mathtopbotpositions) | موقعیت کاراکتر گروه‌بندی |
| vertical_justification | [`MathTopBotPositions`](/slides/python-net/fa/aspose.slides.mathtext/mathtopbotpositions) | توجه عمودی کاراکتر گروه‌بندی.<br/><br/>            ترازبندی شیء نسبت به خط پایه را مشخص می‌کند.<br/><br/>            به عنوان مثال، زمانی که کاراکتر گروه‌بندی بالای شیء باشد، <br/><br/>            VerticalJustification مقدار Top نشان می‌دهد که بالای شیء بر روی خط پایه قرار می‌گیرد؛<br/><br/>            هنگامی که VerticalJustification بر روی Bottom تنظیم شود، پایین شیء بر روی خط پایه قرار می‌گیرد |
