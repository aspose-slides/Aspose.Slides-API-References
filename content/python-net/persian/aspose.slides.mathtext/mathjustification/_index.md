## شمارش MathJustification

توضیح می‌دهد که توجیه متن ریاضی در پاراگراف (یک سری نمونه‌های مجاور متن ریاضی در همان پاراگراف) چگونه باشد

نوع MathJustification اعضای زیر را ارائه می‌دهد:

## فیلدها

| Field | Description |
| :- | :- |
| LEFT_JUSTIFIED | متن ریاضی را به سمت چپ تراز می‌کند |
| RIGHT_JUSTIFIED | متن ریاضی را به سمت راست تراز می‌کند |
| CENTERED | متن ریاضی را در مرکز تراز می‌کند |
| CENTERED_AS_GROUP | کل گروه بلوک‌های ریاضی را به عنوان یک واحد در صفحه مرکز می‌کند.<br/>            این به این معنی است که نمونه‌های متن ریاضی می‌توانند نسبت به یکدیگر تراز شوند، <br/>            اما کل گروه متن ریاضی به عنوان یک کل مرکز می‌شود. |
