## no_break ویژگی
بدون شکست.
            این ویژگی خصوصیت "unbreakable" را در جعبهٔ شیء مشخص می‌کند. زمانی که true باشد، هیچ شکستن خطی درون جعبه رخ نمی‌دهد.
            این می‌تواند برای شبیه‌سازهای عملگر که از بیش از یک عملگر باینری تشکیل شده‌اند، مهم باشد. 
            اگر این عنصر مشخص نشود، امکان شکستن داخل جعبه وجود دارد.
            پیش‌فرض: true
