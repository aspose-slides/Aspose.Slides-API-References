## __init__(self, element) {#imathelement}
یک نمونهٔ جدید از کلاس [`MathPhantom`](/slides/python-net/fa/aspose.slides.mathtext/mathphantom) را 
            با استفاده از عنصر ریاضی پایهٔ مشخص‌شده مقداردهی اولیه می‌کند.

```python
def __init__(self, element):
    ...
```

| پارامتر | نوع | توضیح |
| :- | :- | :- |
| element | [`IMathElement`](/slides/python-net/fa/aspose.slides.mathtext/imathelement) | پایهٔ [`IMathElement`](/slides/python-net/fa/aspose.slides.mathtext/imathelement) که قابلیت مشاهده و چیدمان آن توسط فانتوم کنترل می‌شود <br/><br/>            این عنصر محتوایی را که ممکن است مخفی یا نمایش داده شود تعریف می‌کند، <br/><br/>            در حالی که همچنان بر تراز هندسی ریاضیات اطراف تاثیر می‌گذارد. |

### توضیحات
عنصر فانتوم برای رزرو یا حذف فضای بصری بیان پایهٔ خود استفاده می‌شود بدون اینکه لزوماً نمایش داده شود. این عنصر متناظر با عنصر OMML `<m:phant>` است.
