## show ویژگی
مقداری را که نشان می‌دهد آیا عنصر پایه نمایش داده می‌شود دریافت یا تنظیم می‌کند.


### توضیحات

When `false`, عنصر پایه مخفی می‌شود اما ممکن است بسته به تنظیمات فانتوم دیگر همچنان فضا اشغال کند.
            متناظر با ویژگی OMML `m:show`.

### تعریف:

@property
def show(self):
    ...

@show.setter

    ...
