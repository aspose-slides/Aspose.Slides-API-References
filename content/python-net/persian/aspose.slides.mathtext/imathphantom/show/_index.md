## show ویژگی
یک مقدار را دریافت یا تنظیم می‌کند که نشان می‌دهد آیا عنصر پایه نمایش داده می‌شود یا خیر.

### توضیحات
وقتی `false`، عنصر پایه مخفی است اما ممکن است بسته به تنظیمات فانتوم دیگر همچنان فضا را اشغال کند. متناظر با ویژگی OMML `m:show`.

### تعریف:
```python
@property
def show(self):
    ...

@show.setter
def show(self, value):
    ...
```
