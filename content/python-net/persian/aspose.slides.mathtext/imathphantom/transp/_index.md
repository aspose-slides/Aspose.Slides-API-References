## transp ویژگی
دریافت یا تنظیم مقدار نشان‌دهنده این‌که آیا فانتوم شفاف است 
            برای قوانین فاصله‌گذاری مبتنی بر کلاس.

### توضیحات

زمانی که `true`، عملگرها و نمادهای داخل فانتوم هنوز بر 
            فاصله‌گذاری ریاضی اطراف فانتوم (گویی قابل مشاهده) تأثیر می‌گذارند. زمانی که `false`، 
            فاصله‌گذاری مبتنی بر کلاس نادیده گرفته می‌شود. مطابق با ویژگی OMML `m:transp`.

### تعریف:
```python
@property
def transp(self):
    ...

@transp.setter
def transp(self, value):
    ...
```
