

| Parameter | Type | Description |
| :- | :- | :- |
| character | **char** | کاراکتر گروهی مانند BOTTOM CURLY BRACKET (U+23DF) یا هر کاراکتر دیگری |
| position | [`MathTopBotPositions`](/slides/python-net/fa/aspose.slides.mathtext/mathtopbotpositions) | موقعیت کاراکتر گروهی |
| vertical_justification | [`MathTopBotPositions`](/slides/python-net/fa/aspose.slides.mathtext/mathtopbotpositions) | ترازبندی عمودی کاراکتر گروه.<br/><br/>            مشخص می‌کند که شیء نسبت به خط پایه چگونه تراز شده است.<br/><br/>            به عنوان مثال، وقتی کاراکتر گروه بالای شیء قرار داشته باشد، <br/><br/>            VerticalJustification مقدار Top به این معنی است که بالای شیء بر روی خط پایه قرار می‌گیرد؛<br/><br/>            وقتی VerticalJustification برابر Bottom باشد، پایین شیء بر روی خط پایه قرار می‌گیرد |
