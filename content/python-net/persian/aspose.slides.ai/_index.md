شامل کلاس‌هایی است که ویژگی‌های مبتنی بر هوش مصنوعی برای تجزیه و تحلیل و پردازش ارائه‌های PowerPoint فراهم می‌کنند.
## کلاس‌ها

| کلاس | توضیح |
| :- | :- |
| [`AsposeAIWebClient`](/slides/python-net/fa/aspose.slides.ai/asposeaiwebclient/) | یک پیاده‌سازی [`IAIWebClient`](/slides/python-net/fa/aspose.slides.ai/iaiwebclient) داخلی که به LLM اختصاصی Aspose متصل می‌شود.<br/> این کلاینت پیش‌فرض است که توسط سازنده بدون پارامتر **SlidesAIAgent.#ctor** استفاده می‌شود. |
| [`IAIConversation`](/slides/python-net/fa/aspose.slides.ai/iaiconversation/) | یک نمونه گفت‌وگو را نشان می‌دهد. بر خلاف تماس‌های معمولی هوش مصنوعی، گفتگوها تمام زمینه را حفظ می‌کنند. |
| [`IAIWebClient`](/slides/python-net/fa/aspose.slides.ai/iaiwebclient/) | رابط کاربری کلاینت وب هوش مصنوعی. این رابط امکان جایگزینی مدل‌های مختلف زبان هوش مصنوعی را فراهم می‌کند.<br/> کلاس‌هایی که این رابط را پیاده‌سازی می‌کنند، به همراه `SlidesAIAgent` استفاده شوند. |
| [`OpenAICompatibleWebClient`](/slides/python-net/fa/aspose.slides.ai/openaicompatiblewebclient/) | یک پیاده‌سازی [`IAIWebClient`](/slides/python-net/fa/aspose.slides.ai/iaiwebclient) داخلی که به یک ارائه‌کننده LLM سازگار با OpenAI <br/> در یک URL پایهٔ مشخص متصل می‌شود. |
| [`OpenAIWebClient`](/slides/python-net/fa/aspose.slides.ai/openaiwebclient/) | یک پیاده‌سازی [`IAIWebClient`](/slides/python-net/fa/aspose.slides.ai/iaiwebclient) داخلی که به API OpenAI متصل می‌شود. |
| [`SlidesAIAgent`](/slides/python-net/fa/aspose.slides.ai/slidesaiagent/) | ویژگی‌های مبتنی بر هوش مصنوعی برای پردازش ارائه‌ها را فراهم می‌کند. |
| [`SlidesAIAgentException`](/slides/python-net/fa/aspose.slides.ai/slidesaiagentexception/) | استثناهای مرتبط با Slides AI Agent را نشان می‌دهد. |
