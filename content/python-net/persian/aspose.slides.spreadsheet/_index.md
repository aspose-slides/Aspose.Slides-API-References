شامل کلاس‌هایی برای کار با اشیای صفحه‌گسترده در ارائه‌های Microsoft PowerPoint است.
## کلاس‌ها

| کلاس | توضیح |
| :- | :- |
| [`CellCircularReferenceException`](/slides/python-net/fa/aspose.slides.spreadsheet/cellcircularreferenceexception/) | استثنایی که زمانی پرتاب می‌شود که یک یا چند ارجاع چرخه‌ای شناسایی می‌شود که فرمول به سلول خود<br/>            به‌صورت مستقیم یا غیرمستقیم اشاره می‌کند. |
| [`CellInvalidFormulaException`](/slides/python-net/fa/aspose.slides.spreadsheet/cellinvalidformulaexception/) | استثنایی که زمانی پرتاب می‌شود که یک فرمول محاسبه‌شده صحیح نیست یا تجزیه نشد. |
| [`CellInvalidReferenceException`](/slides/python-net/fa/aspose.slides.spreadsheet/cellinvalidreferenceexception/) | استثنایی که زمانی پرتاب می‌شود که یک مرجع سلول نامعتبر مواجه می‌شود. |
| [`CellUnsupportedDataException`](/slides/python-net/fa/aspose.slides.spreadsheet/cellunsupporteddataexception/) | استثنایی که زمانی پرتاب می‌شود که داده‌ای پشتیبانی‌نشده در یک سلول صفحه‌گسترده مواجه می‌شود. |
