## ImagePixelFormat enumeráció

Megadja a generált képek pixelformátumát.

Az ImagePixelFormat típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| FORMAT_1BPP_INDEXED | 1 bit képpontonként, indexelt. |
| FORMAT_4BPP_INDEXED | 4 bit képpontonként, indexelt. |
| FORMAT_8BPP_INDEXED | 8 bit képpontonként, indexelt. |
| FORMAT_24BPP_RGB | 24 bit képpontonként, RGB. |
| FORMAT_32BPP_ARGB | 32 bit képpontonként, ARGB. |
