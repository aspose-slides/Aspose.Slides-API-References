## HandoutType enumeráció

Megadja, hogy hány dia és milyen sorrendben lesz elhelyezve az oldalon.

A HandoutType típus a következő tagokat tartalmaz:

## Mezők

| Mező | Leírás |
| :- | :- |
| HANDOUTS1 | Egy dia oldalanként. |
| HANDOUTS2 | Két dia oldalanként. |
| HANDOUTS3 | Három dia oldalanként. |
| HANDOUTS_4_HORIZONTAL | Négy dia oldalanként egy vízszintes sorrendben. |
| HANDOUTS_4_VERTICAL | Négy dia oldalanként egy függőleges sorrendben. |
| HANDOUTS_6_HORIZONTAL | Hat dia oldalanként egy vízszintes sorrendben. |
| HANDOUTS_6_VERTICAL | Hat dia oldalanként egy függőleges sorrendben. |
| HANDOUTS_9_HORIZONTAL | Kilenc dia oldalanként egy vízszintes sorrendben. |
| HANDOUTS_9_VERTICAL | Kilenc dia oldalanként egy függőleges sorrendben. |
