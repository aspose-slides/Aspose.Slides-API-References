## skip_java_script_links tulajdonság
Megadja, hogy a prezentáció mentése során kihagyjuk-e a JavaScript hívású hiperhivatkozásokat. 
            Olvasás/írás **bool**. Az alapértelmezett érték **false** .


### Megjegyzés

Ha ez a tulajdonság **true**, a JavaScript hívású hiperhivatkozások a mentés során figyelmen kívül lesznek hagyva.


Ha ez a tulajdonság **false**, az összes hiperhivatkozás mentésre kerül.
