## skip_java_script_links tulajdonság
Megadja, hogy a prezentáció mentésekor kihagyja-e a JavaScript hívásokat tartalmazó hiperhivatkozásokat. 
            Olvasás/írás **bool**. Az alapértelmezett érték **false** .


### Megjegyzés

Ha ez a tulajdonság **true** , a JavaScript hívásokat tartalmazó hiperhivatkozások figyelmen kívül maradnak a mentés során.


Ha ez a tulajdonság **false** , az összes hiperhivatkozás mentésre kerül.
