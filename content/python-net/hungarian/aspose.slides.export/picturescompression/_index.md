## PicturesCompression enumeráció

A képek tömörítési szintjét jelöli

A PicturesCompression típus a következő tagok érhetők el:

## Mezők

| Field | Description |
| :- | :- |
| DPI330 | Jó minőség a nagy felbontású (HD) képernyőkhöz |
| DPI220 | Kiváló minőség a legtöbb nyomtatón és képernyőn |
| DPI150 | Jó weboldalakhoz és projektorokhoz |
| DPI96 | A dokumentum méretének minimalizálása megosztáshoz |
| DPI72 | Alapértelmezett tömörítési szint |
| DOCUMENT_RESOLUTION | Dokumentum felbontás használata - a kép nem lesz tömörítve, és a dokumentumban eredeti állapotában lesz használva |
