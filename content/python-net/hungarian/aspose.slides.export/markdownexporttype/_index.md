## MarkdownExportType felsorolás

A dokumentum renderelésének típusa.

A MarkdownExportType típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| SEQUENTIAL | Minden elemet külön-külön renderel. Egyesével. |
| TEXT_ONLY | Csak a szöveget rendereli. |
| VISUAL | Minden elemet renderel, a csoportosított elemeket együtt rendereli. |
