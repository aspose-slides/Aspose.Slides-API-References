## SaveFormat enumeráció

Állandók, amelyek meghatározzák a mentett bemutató formátumát.

A SaveFormat típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| PPT | A bemutató mentése PPT formátumban. |
| PDF | A bemutató mentése PDF formátumban. |
| XPS | A bemutató mentése XPS formátumban. |
| PPTX | A bemutató mentése PPTX formátumban. |
| PPSX | A bemutató mentése PPSX (diavetítés) formátumban. |
| TIFF | A bemutató mentése többszörös oldalas TIFF képként. |
| ODP | A bemutató mentése ODP formátumban. |
| PPTM | A bemutató mentése PPTM (makrókkal ellátott bemutató) formátumban. |
| PPSM | A bemutató mentése PPSM (makrókkal ellátott diavetítés) formátumban. |
| POTX | A bemutató mentése POTX (sablon) formátumban. |
| POTM | A bemutató mentése POTM (makrókkal ellátott sablon) formátumban. |
| HTML | A bemutató mentése HTML formátumban. |
| SWF | A bemutató mentése SWF formátumban. |
| OTP | A bemutató mentése OTP (bemutató sablon) formátumban. |
| PPS | A bemutató mentése PPS formátumban. |
| POT | A bemutató mentése POT formátumban. |
| FODP | A bemutató mentése FODP formátumban. |
| GIF | A bemutató mentése GIF formátumban. |
| HTML5 | A bemutató mentése HTML formátumban az új HTML5 sablonrendszer használatával. |
| MD | A bemutató mentése Markdown formátumban |
| XML | A bemutató mentése PowerPoint XML prezentáció formátumban. |
