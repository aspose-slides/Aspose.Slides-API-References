## TextInheritanceLimit felsorolás

A szövegtulajdonságok öröklődésének mélységét szabályozza.

A TextInheritanceLimit típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| ALL | Örökli az összes szövegtulajdonságot. |
| TEXT_BOX | Csak a TextFrame stíluséből örökli. |
| PARAGRAPH_ONLY | Csak a bekezdéshez definiált tulajdonságokat használja. |
