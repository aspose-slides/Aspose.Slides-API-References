## skip_java_script_links tulajdonság
Megadja, hogy a prezentáció mentésekor kihagyja-e a JavaScript hívásokat tartalmazó hiperhivatkozásokat. 
            Olvasás/írás **bool**. Az alapértelmezett érték **false** .


### Megjegyzés

Amikor ez a tulajdonság **true** értékre van állítva, a JavaScript hívásokat tartalmazó hiperhivatkozások figyelmen kívül maradnak a mentés során.


Amikor ez a tulajdonság **false** értékre van állítva, minden hiperhivatkozás mentésre kerül.
