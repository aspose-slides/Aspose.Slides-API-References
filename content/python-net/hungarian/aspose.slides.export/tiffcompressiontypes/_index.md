## TiffCompressionTypes enumeráció

Lehetőségeket biztosít, amelyek szabályozzák, hogy egy prezentációt hogyan tömörítenek TIFF formátumban.

A TiffCompressionTypes típus a következő tagokat teszi közzé:

## Mezők

| Mező | Leírás |
| :- | :- |
| DEFAULT | Megadja az alapértelmezett tömörítési séma (LZW). |
| NONE | Megadja, hogy nincs tömörítés. |
| CCITT3 | Megadja a CCITT3 tömörítési sémát. |
| CCITT4 | Megadja a CCITT4 tömörítési sémát. |
| LZW | Megadja az LZW tömörítési sémát (Alapértelmezett). |
| RLE | Megadja az RLE tömörítési sémát. |
