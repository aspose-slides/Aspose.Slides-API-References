## HandleRepeatedSpaces enumeráció

Megadja, hogyan kell kezelni az ismétlődő szabályos szóköz karaktereket a Markdown exportálás során.

A HandleRepeatedSpaces típus a következő tagokat teszi közzé:

## Mezők

| Mező | Leírás |
| :- | :- |
| NONE | Minden szóköz megmarad szabályos szóköz karakterként változtatás nélkül.<br/>            Nem alkalmaznak átalakítást, és a több egymást követő szóköz exportáláskor változatlanul marad. |
| ALTERNATE_SPACES_TO_NBSP |  |
| MULTIPLE_SPACES_TO_NBSP |  |
