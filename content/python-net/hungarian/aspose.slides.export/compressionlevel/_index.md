## CompressionLevel enumeráció

Megadja a ZIP tömörítési szinteket az OpenXML fájlhoz.  
A magasabb szintek jobb tömörítést biztosítanak, de lassabb feldolgozással járnak.

A CompressionLevel típus a következő tagokat biztosítja:

## Mezők

| Mező | Leírás |
| :- | :- |
| NONE | Nem alkalmazott tömörítés. A fájlok változatlanul tárolódnak. |
| LEVEL1 | Leggyorsabb tömörítés a legalacsonyabb tömörítési aránnyal. |
| LEVEL2 | Gyorsabb tömörítés, amely valamivel jobb tömörítési arányt biztosít, mint [`CompressionLevel.LEVEL1`](/slides/python-net/hu/aspose.slides.export/compressionlevel/LEVEL1). |
| LEVEL3 | Jobb tömörítést biztosít, mint [`CompressionLevel.LEVEL2`](/slides/python-net/hu/aspose.slides.export/compressionlevel/LEVEL2), közepes teljesítményhatással. |
| LEVEL4 | Jobb tömörítést biztosít, mint [`CompressionLevel.LEVEL3`](/slides/python-net/hu/aspose.slides.export/compressionlevel/LEVEL3). |
| LEVEL5 | Javított tömörítést nyújt a [`CompressionLevel.LEVEL4`](/slides/python-net/hu/aspose.slides.export/compressionlevel/LEVEL4)-hez képest, plusz feldolgozási idővel. |
| LEVEL6 | Standard tömörítés, amely jó egyensúlyt kínál a tömörítési sebesség és a fájlméret között.<br/>            Alapértelmezett tömörítési szint. |
| LEVEL7 | Magasabb tömörítést biztosít, mint [`CompressionLevel.LEVEL6`](/slides/python-net/hu/aspose.slides.export/compressionlevel/LEVEL6), lassabb feldolgozással. |
| LEVEL8 | Magasabb tömörítést biztosít, mint [`CompressionLevel.LEVEL7`](/slides/python-net/hu/aspose.slides.export/compressionlevel/LEVEL7). |
| LEVEL9 | Maximum tömörítés. A legkisebb fájlméretet állítja elő a leglassabb feldolgozási sebességgel. |
