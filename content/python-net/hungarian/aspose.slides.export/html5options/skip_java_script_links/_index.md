## skip_java_script_links tulajdonság
Megadja, hogy a bemutató mentésekor kihagyja-e a JavaScript hívásokat tartalmazó hiperhivatkozásokat. 
            Olvasás/írás **bool**. Az alapértelmezett érték **false**.


### Megjegyzés

Ha ez a tulajdonság **true** értékre van állítva, a JavaScript hívásokat tartalmazó hiperhivatkozások a mentés során figyelmen kívül lesznek hagyva.


Ha ez a tulajdonság **false** értékre van állítva, minden hiperhivatkozás el lesz mentve.
