## skip_java_script_links tulajdonság
Megadja, hogy a prezentáció mentésekor kihagyja-e a JavaScript hívásokat tartalmazó hiperhivatkozásokat. 
            Olvasás/írás **bool**. Az alapértelmezett érték **false** .


### Megjegyzések

Ha ez a tulajdonság **true** értékre van állítva, a JavaScript hívásokat tartalmazó hiperhivatkozások mentés közben figyelmen kívül lesznek hagyva.


Ha ez a tulajdonság **false** értékre van állítva, minden hiperhivatkozás mentésre kerül.
