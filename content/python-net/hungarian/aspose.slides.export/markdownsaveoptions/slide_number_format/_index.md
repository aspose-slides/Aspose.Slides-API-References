## slide_number_format tulajdonság
Gets or sets the format string used for slide number headers in Markdown output.
            A formátumnak tartalmaznia kell a "{0}" helyőrzőt, amely az exportálás során a dia indexével lesz helyettesítve.
            Példa: "# Slide {0}" a következőket eredményezi: "# Slide 1", "# Slide 2", stb.
