## SvgExternalFontsHandling enumeráció

A szövegrajzoláshoz használt külső betűtípusok kezelésének módját jelöli.

A SvgExternalFontsHandling típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| ADD_LINKS_TO_FONT_FILES | Hivatkozásokat ad a különálló betűtípus fájlokhoz az SVG fájl stílus szekciójához. |
| EMBED | A betűtípus adatokat közvetlenül az SVG fájlba menti. Kérjük, ellenőrizze az összes külső betűtípus licencszerződését, mielőtt ezt a lehetőséget használja. |
| VECTORIZE | Az összes szöveget, amely külső betűtípusokat használ, grafikaként menti. |
