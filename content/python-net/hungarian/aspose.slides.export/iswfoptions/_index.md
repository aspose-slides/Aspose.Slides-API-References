## ISwfOptions osztály

Lehetőséget biztosít beállítások megadására, amelyek szabályozzák, hogyan mentődik a bemutató SWF formátumban.

Az ISwfOptions típus a következő tagokat teszi közzé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`compressed`](/slides/python-net/hu/aspose.slides.export/iswfoptions/compressed/) | Megadja, hogy a generált SWF dokumentumot tömöríteni kell-e vagy sem.<br/>            Alapértelmezett érték `true`. |
| [`viewer_included`](/slides/python-net/hu/aspose.slides.export/iswfoptions/viewer_included/) | Megadja, hogy a generált SWF dokumentum tartalmazza-e a beépített dokumentumnézegetőt vagy sem.<br/>            Alapértelmezett érték `true`. |
| [`show_page_border`](/slides/python-net/hu/aspose.slides.export/iswfoptions/show_page_border/) | Megadja, hogy a lapok körüli keret megjelenjen-e. Alapértelmezett érték `true`. |
| [`show_hidden_slides`](/slides/python-net/hu/aspose.slides.export/iswfoptions/show_hidden_slides/) | Megadja, hogy a generált dokumentum tartalmazza-e a rejtett diákot vagy sem.<br/>            Alapértelmezett érték `false`. |
| [`show_full_screen`](/slides/python-net/hu/aspose.slides.export/iswfoptions/show_full_screen/) | Teljes képernyős gomb megjelenítése/elrejtése. Felülírható a flashvars-ban. Alapértelmezett érték `true`. |
| [`show_page_stepper`](/slides/python-net/hu/aspose.slides.export/iswfoptions/show_page_stepper/) | Oldallépő megjelenítése/elrejtése. Felülírható a flashvars-ban. Alapértelmezett érték `true`. |
| [`show_search`](/slides/python-net/hu/aspose.slides.export/iswfoptions/show_search/) | Kereső rész megjelenítése/elrejtése. Felülírható a flashvars-ban. Alapértelmezett érték `true`. |
| [`show_top_pane`](/slides/python-net/hu/aspose.slides.export/iswfoptions/show_top_pane/) | Az egész felső panel megjelenítése/elrejtése. Felülírható a flashvars-ban. Alapértelmezett érték `true`. |
| [`show_bottom_pane`](/slides/python-net/hu/aspose.slides.export/iswfoptions/show_bottom_pane/) | Az alsó panel megjelenítése/elrejtése. Felülírható a flashvars-ban. Alapértelmezett érték `true`. |
| [`show_left_pane`](/slides/python-net/hu/aspose.slides.export/iswfoptions/show_left_pane/) | A bal panel megjelenítése/elrejtése. Felülírható a flashvars-ban. Alapértelmezett érték `true`. |
| [`start_open_left_pane`](/slides/python-net/hu/aspose.slides.export/iswfoptions/start_open_left_pane/) | Bal panel megnyitott állapotban indítás. Felülírható a flashvars-ban. Alapértelmezett érték `false`. |
| [`enable_context_menu`](/slides/python-net/hu/aspose.slides.export/iswfoptions/enable_context_menu/) | Egyéni menü engedélyezése/letiltása. Alapértelmezett érték `true`. |
| [`logo_image_bytes`](/slides/python-net/hu/aspose.slides.export/iswfoptions/logo_image_bytes/) | Kép, amely a nézegető jobb felső sarkában logóként jelenik meg.<br/>            A képméretnek 32x64 pixel PNG-nek kell lennie, egyébként a logó helytelenül jelenhet meg. |
| [`logo_link`](/slides/python-net/hu/aspose.slides.export/iswfoptions/logo_link/) | Lekéri vagy beállítja a logó teljes hiperlink címét.<br/>            Hatása csak akkor van, ha egy [`ISwfOptions.logo_image_bytes`](/slides/python-net/hu/aspose.slides.export/iswfoptions/logo_image_bytes) meg van adva. |
| [`jpeg_quality`](/slides/python-net/hu/aspose.slides.export/iswfoptions/jpeg_quality/) | Megadja a JPEG képek minőségét.<br/>            Alapértelmezett érték 95. |
| [`slides_layout_options`](/slides/python-net/hu/aspose.slides.export/iswfoptions/slides_layout_options/) | Lekéri vagy beállítja azt a módot, amiben a diák a lapra kerülnek egy [`ISlidesLayoutOptions`](/slides/python-net/hu/aspose.slides.export/islideslayoutoptions) exportálásakor.<br/>            Ez a tulajdonság nem támogatja `Aspose.Slides.Export.HandoutLayoutingOptions` típusú objektumok hozzárendelését |
