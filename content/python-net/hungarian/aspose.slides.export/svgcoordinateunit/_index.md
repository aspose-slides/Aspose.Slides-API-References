## SvgCoordinateUnit enumeráció

A CSS2 koordinátamértékek képviseli, amelyek az SVG koordináták meghatározásához használatosak.

A SvgCoordinateUnit típus a következő tagokat teszi elérhetővé:

## Mezők

| Mező | Leírás |
| :- | :- |
| INCH | hüvelyk |
| CENTIMETER | centiméter. |
| MILLIMETER | milliméter. |
| POINT | Pont (1/72 of inch), |
| PICA | Pika (1/6 of inch). |
| EM | Az elemhez tartozó betűtípus Em mérete. |
| EX | Az elemhez tartozó betűtípus Ex mérete (a kisbetű, általában "x", mérete). |
| PIXEL | Pixel méret. |
| PERCENT | Százalék. |
