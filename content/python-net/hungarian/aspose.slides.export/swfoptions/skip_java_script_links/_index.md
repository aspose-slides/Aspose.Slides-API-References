## skip_java_script_links tulajdonság
Megadja, hogy a prezentáció mentése során kihagyja-e a JavaScript hívásokat tartalmazó hiperhivatkozásokat. 
            Olvasás/írás **bool**. Az alapértelmezett érték **false** .


### Megjegyzés

Ha ez a tulajdonság **true** , a JavaScript hívásokat tartalmazó hiperhivatkozások mentéskor figyelmen kívül lesznek hagyva.


Ha ez a tulajdonság **false** , az összes hiperhivatkozás mentésre kerül.
