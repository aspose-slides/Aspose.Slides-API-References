## PdfTextCompression enumeráció

Állandók, amelyek meghatározzák a tömörítés típusát, amely a PDF fájl összes tartalmára, a képeken kívül, alkalmazott.

A PdfTextCompression típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| NONE | Nincs tömörítés. |
| FLATE | Flate (ZIP) tömörítés. |
