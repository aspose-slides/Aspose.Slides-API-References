## SvgEvent enumeráció

Az SVG alakzat opcióit képviseli.

A SvgEvent típus a következő tagokat biztosítja:

## Mezők

| Field | Leírás |
| :- | :- |
| ON_FOCUS_IN | Akkor fordul elő, amikor egy elem fókuszt kap, például amikor egy szöveg kijelölődik. |
| ON_FOCUS_OUT | Akkor fordul elő, amikor egy elem elveszíti a fókuszt, például amikor egy szöveg kijelölése megszűnik. |
| ON_ACTIVATE | Akkor fordul elő, amikor egy elem aktiválódik, például egérkattintással vagy billentyűleütéssel. |
| ON_CLICK | Akkor fordul elő, amikor a mutatóeszköz gombját egy elemre kattintják. |
| ON_MOUSE_DOWN | Akkor fordul elő, amikor a mutatóeszköz gombját egy elemre lenyomják. |
| ON_MOUSE_UP | Akkor fordul elő, amikor a mutatóeszköz gombját egy elemről felengedik. |
| ON_MOUSE_OVER | Akkor fordul elő, amikor a mutatóeszköz egy elemre mozog. |
| ON_MOUSE_MOVE | Akkor fordul elő, amikor a mutatóeszköz mozog, miközben egy elem felett van. |
| ON_MOUSE_OUT | Akkor fordul elő, amikor a mutatóeszköz elhagy egy elemet. |
| ON_LOAD | Akkor fordul elő, amikor a felhasználói ügynök teljesen beolvasta az elemet és annak leszármazottait, valamint az összes hivatkozott erőforrást, amely a megjelenítéshez szükséges. |
| ON_UNLOAD | Akkor fordul elő, amikor a DOM megvalósítás eltávolít egy dokumentumot egy ablakból vagy keretből. Csak a legkülső svg elemekre vonatkozik. |
| ON_ABORT | Akkor fordul elő, amikor az oldal betöltése leáll, mielőtt egy elem teljesen betöltődhetne. |
| ON_ERROR | Akkor fordul elő, amikor egy elem nem töltődik be megfelelően, vagy amikor hiba lép fel a szkript végrehajtása közben. |
| ON_RESIZE | Akkor fordul elő, amikor egy dokumentumnézet mérete változik. Csak a legkülső svg elemekre vonatkozik. |
| ON_SCROLL | Akkor fordul elő, amikor egy dokumentumnézet eltolódik az X vagy Y vagy mindkét tengely mentén. Csak a legkülső svg elemekre vonatkozik. |
| ON_ZOOM | Akkor fordul elő, amikor egy dokumentumnézet nagyítási szintje megváltozik. Csak a legkülső svg elemekre vonatkozik. |
| ON_BEGIN | Akkor fordul elő, amikor egy animációs elem elkezdődik. |
| ON_END | Akkor fordul elő, amikor egy animációs elem befejeződik. |
| ON_REPEAT | Akkor fordul elő, amikor egy animációs elem ismétlődik. |
