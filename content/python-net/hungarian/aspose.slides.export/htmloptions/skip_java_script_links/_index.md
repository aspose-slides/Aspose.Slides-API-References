## skip_java_script_links tulajdonság
Meghatározza, hogy a prezentáció mentésekor kihagyja-e a JavaScript hívásokat tartalmazó hiperhivatkozásokat. 
            Olvasás/írás **bool**. Az alapérték **false** .


### Megjegyzések

Ha ez a tulajdonság **true** , a JavaScript hívásokat tartalmazó hiperhivatkozások mentéskor figyelmen kívül lesznek hagyva.


Ha ez a tulajdonság **false** , minden hiperhivatkozás el lesz mentve.
