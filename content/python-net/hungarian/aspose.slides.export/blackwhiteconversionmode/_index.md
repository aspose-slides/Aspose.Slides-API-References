## BlackWhiteConversionMode felsorolás

Lehetőségeket biztosít, amelyek szabályozzák, hogyan lesznek a diák képei átalakítva bitonális képekké.

A BlackWhiteConversionMode típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| DEFAULT | Nem ad meg konverziós algoritmust. A TIFF kodekben megvalósított algoritmus lesz használva. (Alapértelmezett) |
| DITHERING | Megadja a dithering algoritmust (Floyd-Steinberg). |
| DITHERING_FLOYD_STEINBERG | Megadja a Floyd-Steinberg dithering algoritmust. |
| AUTO | Megadja az automatikusan számított küszöb algoritmust (Otsu). |
| AUTO_OTSU | Megadja az automatikusan számított Otsu küszöb algoritmust. |
| THRESHOLD25 | Megadja a statikus küszöb algoritmust (25%). |
| THRESHOLD50 | Megadja a statikus küszöb algoritmust (50%). |
| THRESHOLD75 | Megadja a statikus küszöb algoritmust (75%). |
