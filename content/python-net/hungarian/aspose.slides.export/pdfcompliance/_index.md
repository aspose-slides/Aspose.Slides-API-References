## PdfCompliance enumeráció

A PDF szabványok megfelelőségi szintjét meghatározó állandók.

A PdfCompliance típus a következő tagokat biztosítja:

## Mezők

| Mező | Leírás |
| :- | :- |
| PDF15 | A kimeneti fájl megfelel a PDF 1.5 szabványnak. |
| PDF16 | A kimeneti fájl megfelel a PDF 1.6 szabványnak. |
| PDF17 | A kimeneti fájl megfelel a PDF 1.7 szabványnak. |
| PDF_A1B | A kimeneti fájl megfelel a PDF/A-1b szabványnak. |
| PDF_A1A | A kimeneti fájl megfelel a PDF/A-1a szabványnak. |
| PDF_A2B | A kimeneti fájl megfelel a PDF/A-2b szabványnak. |
| PDF_A2A | A kimeneti fájl megfelel a PDF/A-2a szabványnak. |
| PDF_A3B | A kimeneti fájl megfelel a PDF/A-3b szabványnak. |
| PDF_A3A | A kimeneti fájl megfelel a PDF/A-3a szabványnak. |
| PDF_UA | A kimeneti fájl megfelel a PDF/UA szabványnak. |
| PDF_A2U | A kimeneti fájl megfelel a PDF/A-2u szabványnak. |
