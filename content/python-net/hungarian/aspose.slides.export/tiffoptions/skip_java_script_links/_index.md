## skip_java_script_links tulajdonság
Megadja, hogy a prezentáció mentésekor kihagyja-e a JavaScript hívású hiperhivatkozásokat. 
            Olvasás/írás **bool**. Az alapértelmezett érték **false** .


### Megjegyzések

Ha ez a tulajdonság **true** értékre van állítva, a JavaScript hívású hiperhivatkozások mentéskor figyelmen kívül lesznek hagyva.

Ha ez a tulajdonság **false** értékre van állítva, az összes hiperhivatkozás mentésre kerül.
