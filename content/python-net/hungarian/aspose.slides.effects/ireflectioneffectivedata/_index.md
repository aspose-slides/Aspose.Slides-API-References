## IReflectionEffectiveData osztály

Megváltoztathatatlan objektum, amely egy Reflexió hatást képviseli.

Az IReflectionEffectiveData típus a következő tagokat teszi közzé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/hu/aspose.slides.effects/ireflectioneffectivedata/start_pos_alpha/) | Meghatározza a kezdő alfa érték (százalék) kezdő pozícióját (az alfa gradient emelkedő mentén).<br/>            Csak olvasható **float**. |
| [`end_pos_alpha`](/slides/python-net/hu/aspose.slides.effects/ireflectioneffectivedata/end_pos_alpha/) | Meghatározza a vég alfa érték (százalék) végpozícióját (az alfa gradient emelkedő mentén).<br/>            Csak olvasható **float**. |
| [`fade_direction`](/slides/python-net/hu/aspose.slides.effects/ireflectioneffectivedata/fade_direction/) | Meghatározza a reflexió eltolásának irányát. (szög).<br/>            Csak olvasható **float**. |
| [`start_reflection_opacity`](/slides/python-net/hu/aspose.slides.effects/ireflectioneffectivedata/start_reflection_opacity/) | Kezdeti reflexió átlátszatlansága. (százalék).<br/>            Csak olvasható **float**. |
| [`end_reflection_opacity`](/slides/python-net/hu/aspose.slides.effects/ireflectioneffectivedata/end_reflection_opacity/) | Végső reflexió átlátszatlansága. (százalék).<br/>            Csak olvasható **float**. |
