## Reflection osztály

Egy Reflection hatást reprezentál.

A Reflection típus a következő tagokat teszi elérhetővé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`start_pos_alpha`](/slides/python-net/hu/aspose.slides.effects/reflection/start_pos_alpha/) | Megadja a kezdő alfa érték (százalék) a alfa gradient rámpán lévő kezdő pozícióját.<br/>            Olvasás/írás **float**. |
| [`end_pos_alpha`](/slides/python-net/hu/aspose.slides.effects/reflection/end_pos_alpha/) | Megadja a végső alfa érték (százalék) a alfa gradient rámpán lévő végpozícióját.<br/>            Olvasás/írás **float**. |
| [`fade_direction`](/slides/python-net/hu/aspose.slides.effects/reflection/fade_direction/) | Megadja a reflexió eltolásának irányát (szög).<br/>            Olvasás/írás **float**. |
| [`start_reflection_opacity`](/slides/python-net/hu/aspose.slides.effects/reflection/start_reflection_opacity/) | Kezdő reflexió átlátszatlansága. (százalék).<br/>            Olvasás/írás **float**. |
| [`end_reflection_opacity`](/slides/python-net/hu/aspose.slides.effects/reflection/end_reflection_opacity/) | Végső reflexió átlátszatlansága. (százalék).<br/>            Olvasás/írás **float**. |
| [`blur_radius`](/slides/python-net/hu/aspose.slides.effects/reflection/blur_radius/) | Elmosás sugara.<br/>            Olvasás/írás **float**. |
| [`direction`](/slides/python-net/hu/aspose.slides.effects/reflection/direction/) | Reflexió iránya.<br/>            Olvasás/írás **float**. |
| [`distance`](/slides/python-net/hu/aspose.slides.effects/reflection/distance/) | Reflexió távolsága.<br/>            Olvasás/írás **float**. |
| [`rectangle_align`](/slides/python-net/hu/aspose.slides.effects/reflection/rectangle_align/) | Téglalap igazítás.<br/>            Olvasás/írás [`RectangleAlignment`](/slides/python-net/hu/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/hu/aspose.slides.effects/reflection/skew_horizontal/) | Megadja a vízszintes dőlési szöget.<br/>            Olvasás/írás **float**. |
| [`skew_vertical`](/slides/python-net/hu/aspose.slides.effects/reflection/skew_vertical/) | Megadja a függőleges dőlési szöget.<br/>            Olvasás/írás **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/hu/aspose.slides.effects/reflection/rotate_shadow_with_shape/) | Megadja, hogy a reflexió forgatódjon-e a formával, ha a forma el van forgatva.<br/>            Olvasás/írás **bool**. |
| [`scale_horizontal`](/slides/python-net/hu/aspose.slides.effects/reflection/scale_horizontal/) | Megadja a vízszintes méretezési tényezőt, a negatív méretezés tükrözést okoz. (százalék)<br/>            Olvasás/írás **float**. |
| [`scale_vertical`](/slides/python-net/hu/aspose.slides.effects/reflection/scale_vertical/) | Megadja a függőleges méretezési tényezőt, a negatív méretezés tükrözést okoz. (százalék)<br/>            Olvasás/írás **float**. |
