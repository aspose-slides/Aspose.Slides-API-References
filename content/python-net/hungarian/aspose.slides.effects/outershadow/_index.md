## OuterShadow osztály

Képviseli egy külső árnyék hatást.

Az OuterShadow típus a következő tagokat teszi közzé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`blur_radius`](/slides/python-net/hu/aspose.slides.effects/outershadow/blur_radius/) | Elmosódási sugár, pontokban.<br/>            Alapértelmezett érték – 0 pt.<br/>            Olvasás/írás **float**. |
| [`direction`](/slides/python-net/hu/aspose.slides.effects/outershadow/direction/) | Az árnyék iránya fokban.<br/>            Alapértelmezett érték – 0 ° (balról jobbra).<br/>            Olvasás/írás **float**. |
| [`distance`](/slides/python-net/hu/aspose.slides.effects/outershadow/distance/) | Az árnyék távolsága az objektumtól pontokban.<br/>            Alapértelmezett érték – 0 pt.<br/>            Olvasás/írás **float**. |
| [`shadow_color`](/slides/python-net/hu/aspose.slides.effects/outershadow/shadow_color/) | Az árnyék színe.<br/>            Alapértelmezett érték – automatikus fekete (témafüggő).<br/>            Csak olvasható [`IColorFormat`](/slides/python-net/hu/aspose.slides/icolorformat). |
| [`rectangle_align`](/slides/python-net/hu/aspose.slides.effects/outershadow/rectangle_align/) | Téglalap igazítás.<br/>            Alapértelmezett érték – [`RectangleAlignment.BOTTOM`](/slides/python-net/hu/aspose.slides/rectanglealignment/BOTTOM). <br/>            Olvasás/írás [`RectangleAlignment`](/slides/python-net/hu/aspose.slides/rectanglealignment). |
| [`skew_horizontal`](/slides/python-net/hu/aspose.slides.effects/outershadow/skew_horizontal/) | Vízszintes ferdeség szöge fokban.<br/>            Alapértelmezett érték – 0 °.<br/>            Olvasás/írás **float**. |
| [`skew_vertical`](/slides/python-net/hu/aspose.slides.effects/outershadow/skew_vertical/) | Függőleges ferdeség szöge fokban.<br/>            Alapértelmezett érték – 0 °.<br/>            Olvasás/írás **float**. |
| [`rotate_shadow_with_shape`](/slides/python-net/hu/aspose.slides.effects/outershadow/rotate_shadow_with_shape/) | Jelzi, hogy az árnyék a alakzattal együtt forog-e.<br/>            Alapértelmezett érték – true.<br/>            Olvasás/írás **bool**. |
| [`scale_horizontal`](/slides/python-net/hu/aspose.slides.effects/outershadow/scale_horizontal/) | Vízszintes méretezési tényező, az eredeti méret százalékában.<br/>            Negatív méretezés tükrözést okoz.<br/>            Alapértelmezett érték – 100 %.<br/>            Olvasás/írás **float**. |
| [`scale_vertical`](/slides/python-net/hu/aspose.slides.effects/outershadow/scale_vertical/) | Függőleges méretezési tényező, az eredeti méret százalékában.<br/>            Negatív méretezés tükrözést okoz.<br/>            Alapértelmezett érték – 100 %.<br/>            Olvasás/írás **float**. |
