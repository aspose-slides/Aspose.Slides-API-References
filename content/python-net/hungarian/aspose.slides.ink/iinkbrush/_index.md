## IInkBrush osztály

A nyomvonal ecsetet képviseli.

Az IInkBrush típus a következő tagokat teszi elérhetővé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`color`](/slides/python-net/hu/aspose.slides.ink/iinkbrush/color/) | Lekérdezi vagy beállítja egy vonal ecsetszínét. |
| [`size`](/slides/python-net/hu/aspose.slides.ink/iinkbrush/size/) | Lekérdezi vagy beállítja a vonal ecsetméretét pontokban. |
| [`ink_effect`](/slides/python-net/hu/aspose.slides.ink/iinkbrush/ink_effect/) | Lekérdezi az tinta hatás típusát (pl. Galaxy, Gold, Silver), amely meghatározza a tinta vonal vizuális stílusát.<br/>            Az érték a "inkEffects" ecset tulajdonságból kerül beolvasásra. Ha nincs felismerhető hatás megadva,<br/>            [`InkEffectType.NOT_DEFINED`](/slides/python-net/hu/aspose.slides.ink/inkeffecttype/NOT_DEFINED) kerül visszaadásra. |
