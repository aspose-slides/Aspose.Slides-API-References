## InkEffectType enumeráció

Megad egy előre definiált vizuális hatások halmazát a tinta megjelenítéséhez.
            Minden hatás egy olyan textúrához vagy képre felel meg, amely szimulálja a stilizált tinta megjelenését.
            Ezek az értékek felhasználhatók a digitális tintavonalak vizuális stílusának testreszabására a megjelenítés során.

Az InkEffectType típus a következő tagokat teszi elérhetővé:

## Mezők

| Field | Description |
| :- | :- |
| NOT_DEFINED | A hatás nincs definiálva vagy ismeretlen. Ez az érték használható alapértelmezettként vagy tartalékaként. |
| BRONZE | Egy meleg, barnás fémes textúra, amely a bronz tintahez hasonlít. |
| GALAXY | Egy színes, csillogó textúra, amely egy galaxisra emlékeztet, kozmikus színekkel. |
| GOLD | Egy fényes, fémes arany textúra, amely a tintavonalaknak luxus megjelenést kölcsönöz. |
| LAVA | Egy tűzszínű textúra, amely a lávára emlékeztet, piros és narancs árnyalatokkal. |
| OCEAN | Egy mélykék, folyadékszerű textúra, amely az óceáni hullámokat vagy a vízalapú tintát utánozza. |
| RAINBOW_GLITTER | Egy színes, csillogó szivárvány glitter hatás, amely ünnepi vagy élénk tintavonalakhoz használható. |
| ROSE_GOLD | Egy puha rózsaszín-arany keverék, amely a rózsaaranyhoz hasonlít, elegáns tintavonalakhoz. |
| SILVER | Egy hűvös, fémes ezüst textúra, amely a klasszikus ezüst tintát szimulálja. |
