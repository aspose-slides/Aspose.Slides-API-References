## ISmartArtNode osztály

A SmartArt diagram csomópontját képviseli.

Az ISmartArtNode típus a következő tagokat tartalmazza:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`child_nodes`](/slides/python-net/hu/aspose.slides.smartart/ismartartnode/child_nodes/) | Visszaadja az aktuális csomópont összes gyermekcsomópontjának gyűjteményét.<br/>            Csak olvasható [`ISmartArtNodeCollection`](/slides/python-net/hu/aspose.slides.smartart/ismartartnodecollection). |
| [`shapes`](/slides/python-net/hu/aspose.slides.smartart/ismartartnode/shapes/) | Visszaadja a csomóponttal összefüggő összes alakzat gyűjteményét.<br/>            Csak olvasható [`ISmartArtShapeCollection`](/slides/python-net/hu/aspose.slides.smartart/ismartartshapecollection). |
| [`text_frame`](/slides/python-net/hu/aspose.slides.smartart/ismartartnode/text_frame/) | Visszaadja vagy beállítja a csomópont szövegét.<br/>            Csak olvasható [`ITextFrame`](/slides/python-net/hu/aspose.slides/itextframe). |
| [`is_assistant`](/slides/python-net/hu/aspose.slides.smartart/ismartartnode/is_assistant/) | Visszaadja vagy beállítja a csomópontot asszisztensként.<br/>            Olvasás/írás **bool**. |
| [`level`](/slides/python-net/hu/aspose.slides.smartart/ismartartnode/level/) | Visszaadja a csomópont beágyazási szintjét.<br/>            Csak olvasható **int**. |
| [`bullet_fill_format`](/slides/python-net/hu/aspose.slides.smartart/ismartartnode/bullet_fill_format/) | Visszaadja a FillFormat objektumot, amely a csomópont jelölőjének kitöltési formázási tulajdonságait tartalmazza.<br/>            Megjegyzés: bizonyos SmartArt elrendezéstípusoknál, ahol a csomópontok nem kapnak jelölőt, None értéket adhat vissza.<br/>            Csak olvasható [`IFillFormat`](/slides/python-net/hu/aspose.slides/ifillformat). |
| [`position`](/slides/python-net/hu/aspose.slides.smartart/ismartartnode/position/) | Visszaadja vagy beállítja a csomópont testvércsomópontok közötti nullával kezdődő pozícióját.<br/>            Olvasás/írás **int**. |
| [`is_hidden`](/slides/python-net/hu/aspose.slides.smartart/ismartartnode/is_hidden/) | Visszaadja, hogy igaz, ha ez a csomópont rejtett a adatmodellben.<br/>            Csak olvasható **bool**. |
| [`organization_chart_layout`](/slides/python-net/hu/aspose.slides.smartart/ismartartnode/organization_chart_layout/) | Visszaadja vagy beállítja a jelenlegi csomóponttal kapcsolatos szervezeti diagram elrendezés típusát.<br/>            Olvasás/írás [`OrganizationChartLayoutType`](/slides/python-net/hu/aspose.slides.smartart/organizationchartlayouttype). |
