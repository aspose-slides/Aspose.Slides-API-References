## SmartArtNode osztály

A SmartArt objektum csomópontját képviseli

A SmartArtNode típus a következő tagokat tartalmazza:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`child_nodes`](/slides/python-net/hu/aspose.slides.smartart/smartartnode/child_nodes/) | Visszaadja az aktuális csomópont összes gyermek csomópontjának gyűjteményét.<br/>            Csak olvasható [`ISmartArtNodeCollection`](/slides/python-net/hu/aspose.slides.smartart/ismartartnodecollection). |
| [`shapes`](/slides/python-net/hu/aspose.slides.smartart/smartartnode/shapes/) | Visszaadja az adott csomóponthoz kapcsolódó összes alakzat gyűjteményét.<br/>            Csak olvasható [`ISmartArtShapeCollection`](/slides/python-net/hu/aspose.slides.smartart/ismartartshapecollection). |
| [`text_frame`](/slides/python-net/hu/aspose.slides.smartart/smartartnode/text_frame/) | Visszaadja a csomópont szövegkeretét.<br/>            Csak olvasható [`ITextFrame`](/slides/python-net/hu/aspose.slides/itextframe). |
| [`is_assistant`](/slides/python-net/hu/aspose.slides.smartart/smartartnode/is_assistant/) | Visszaadja vagy beállítja a csomópontot segédként.<br/>            Olvasható/írható **bool**. |
| [`level`](/slides/python-net/hu/aspose.slides.smartart/smartartnode/level/) | Visszaadja a csomópont beágyazási szintjét.<br/>            Csak olvasható **int**. |
| [`bullet_fill_format`](/slides/python-net/hu/aspose.slides.smartart/smartartnode/bullet_fill_format/) | Visszaadja a FillFormat objektumot, amely a csomópont jelölőpontjának kitöltési formázási tulajdonságait tartalmazza.<br/>            Megjegyzés: bizonyos SmartArt elrendezéstípusok esetén visszaadhat None értéket, ahol a csomópontok nem kapnak jelölőpontot.<br/>            Csak olvasható [`IFillFormat`](/slides/python-net/hu/aspose.slides/ifillformat). |
| [`position`](/slides/python-net/hu/aspose.slides.smartart/smartartnode/position/) | Visszaadja vagy beállítja a csomópont testvércsomópontok közötti nullázott pozícióját.<br/>            Olvasható/írható **int**. |
| [`is_hidden`](/slides/python-net/hu/aspose.slides.smartart/smartartnode/is_hidden/) | Igaz értéket ad vissza, ha ez a csomópont rejtett a adatelőállítási modellben.<br/>            Csak olvasható **bool**. |
| [`organization_chart_layout`](/slides/python-net/hu/aspose.slides.smartart/smartartnode/organization_chart_layout/) | Visszaadja vagy beállítja a jelenlegi csomóponthoz tartozó szervezeti ábra elrendezés típusát.<br/>            Olvasható/írható [`OrganizationChartLayoutType`](/slides/python-net/hu/aspose.slides.smartart/organizationchartlayouttype). |
