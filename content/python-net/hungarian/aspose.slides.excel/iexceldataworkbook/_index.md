## IExcelDataWorkbook osztály

A munkafüzet, amely általános használatra biztosít hozzáférést az Excel adatokhoz.

Az IExcelDataWorkbook típus a következő tagokkal rendelkezik:

## Metódusok

| Metódus | Leírás |
| :- | :- |
| [`get_cell(self, worksheet_index, row, column)`](/slides/python-net/hu/aspose.slides.excel/iexceldataworkbook/get_cell/#int-int-int) | A megadott munkalapról index és cellakoordináták alapján visszaad egy cellát. |
| [`get_cell(self, worksheet_name, row, column)`](/slides/python-net/hu/aspose.slides.excel/iexceldataworkbook/get_cell/#str-int-int) | A megadott munkalapról név és cellakoordináták alapján visszaad egy cellát. |
| [`get_cell(self, worksheet_index, cell_name)`](/slides/python-net/hu/aspose.slides.excel/iexceldataworkbook/get_cell/#int-str) | A megadott munkalapról index és Excel-stílusú cellanév (például "B2") alapján visszaad egy cellát. |
| [`get_cell(self, worksheet_name, cell_name)`](/slides/python-net/hu/aspose.slides.excel/iexceldataworkbook/get_cell/#str-str) | A megadott munkalapról Excel-stílusú cellanév (például "B2") alapján visszaad egy cellát. |
| [`get_cells(self, formula, skip_hidden_cells)`](/slides/python-net/hu/aspose.slides.excel/iexceldataworkbook/get_cells/#str-bool) | Visszaad egy cellagyűjteményt a munkafüzetből, amely megfelel a megadott képletnek. |
| [`get_charts_from_worksheet(self, worksheet_name)`](/slides/python-net/hu/aspose.slides.excel/iexceldataworkbook/get_charts_from_worksheet/#str) | Visszaad egy szótárat, amely tartalmazza az összes chart indexeit és nevét a megadott Excel munkalapon. |
| [`get_worksheet_names(self)`](/slides/python-net/hu/aspose.slides.excel/iexceldataworkbook/get_worksheet_names/#) | Visszaad az Excel munkafüzetben található összes munkalap nevét. |
