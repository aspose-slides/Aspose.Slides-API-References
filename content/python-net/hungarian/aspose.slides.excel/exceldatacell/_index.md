## ExcelDataCell osztály

Egy egyedi cellát képvisel egy Excel munkafüzetben.

Az ExcelDataCell típus a következő tagokat tartalmazza:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`value`](/slides/python-net/hu/aspose.slides.excel/exceldatacell/value/) | Megkapja az Excel cellában tárolt értéket. |
| [`name`](/slides/python-net/hu/aspose.slides.excel/exceldatacell/name/) | Megkapja a diagram adatcellájának nevét. |
| [`row`](/slides/python-net/hu/aspose.slides.excel/exceldatacell/row/) | Megkapja a cella helyének a munkalapon lévő sor nullával kezdődő indexét.<br/>            Csak olvasható **int**. |
| [`column`](/slides/python-net/hu/aspose.slides.excel/exceldatacell/column/) | Megkapja a cella helyének a munkalapon lévő oszlop nullával kezdődő indexét.<br/>            Csak olvasható **int**. |
