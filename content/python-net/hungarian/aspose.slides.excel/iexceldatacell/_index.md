## IExcelDataCell osztály

Egy Excel munkafüzet egyetlen celláját képviseli.

Az IExcelDataCell típus a következő tagokat teszi közzé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`value`](/slides/python-net/hu/aspose.slides.excel/iexceldatacell/value/) | Lekéri az Excel cellában tárolt értéket.<br/>            Csak olvasható **any**. |
| [`name`](/slides/python-net/hu/aspose.slides.excel/iexceldatacell/name/) | Lekéri a diagram adatcellájának nevét.<br/>            Csak olvasható **str**. |
| [`row`](/slides/python-net/hu/aspose.slides.excel/iexceldatacell/row/) | Lekéri a cella helyét tartalmazó munkalap sorának nullától induló indexét.<br/>            Csak olvasható **int**. |
| [`column`](/slides/python-net/hu/aspose.slides.excel/iexceldatacell/column/) | Lekéri a cella helyét tartalmazó munkalap oszlopának nullától induló indexét.<br/>            Csak olvasható **int**. |
