## EffectChartMinorGroupingType felsorolás

Képviseli a diagram sorozati vagy kategóriaelemen lévő animációs effektus típusát.

Az EffectChartMinorGroupingType típus a következő tagokat teszi elérhetővé:

## Mezők

| Mező | Leírás |
| :- | :- |
| BY_ELEMENT_IN_SERIES | Animate chart by element in series |
| BY_ELEMENT_IN_CATEGORY | Animate chart by element in category |
