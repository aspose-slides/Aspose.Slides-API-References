## IPoint osztály

Animációs pontot ábrázol.

Az IPoint típus a következő tagokat tartalmazza:

## Tulajdonságok

| Property | Description |
| :- | :- |
| [`time`](/slides/python-net/hu/aspose.slides.animation/ipoint/time/) | Az időértéket jelöli.<br/>            Olvasás/írás **float**. |
| [`value`](/slides/python-net/hu/aspose.slides.animation/ipoint/value/) | A pontértéket jelöli.<br/>            Csak: bool, ColorFormat, float, int, string.<br/>            Olvasás/írás **any**. |
| [`formula`](/slides/python-net/hu/aspose.slides.animation/ipoint/formula/) | A values, from, to, by attribútumokban lévő képletek a következő elemekből állhatnak:<br/>            Szabványos aritmetikai operátorok: ‘+’, ‘-‘, ‘*’, ‘/’, ‘^’, ‘%’ (mod)<br/>            Konstansok: ‘pi’ ‘e’<br/>            Feltételes operátorok: ‘abs’, ‘min’, ‘max’, ‘?’ (if)<br/>            Összehasonlító operátorok: '==', '>=', '', '!=', '!'<br/>            Trigonometrikus operátorok: ‘sin()’, ‘cos()’, ‘tan()’, ‘asin()’, ‘acos()’, ‘atan()’<br/>            Természetes logaritmus ‘ln()’<br/>            Tulajdonságreferenciák (a gazda által támogatott tulajdonságok)<br/>            <br/>            for example: "#ppt_x+(cos(-2*pi*(1-$))*-#ppt_x-sin(-2*pi*(1-$))*(1-#ppt_y))*(1-$)"<br/>            Olvasás/írás **str**. |
