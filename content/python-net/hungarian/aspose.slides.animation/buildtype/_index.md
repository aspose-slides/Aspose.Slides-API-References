## BuildType felsorolás

Meghatározza, hogyan jelenik meg a szöveg egy alakzaton az animáció során.

A BuildType típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| AS_ONE_OBJECT | A tartalmazó alakzattal. |
| ALL_PARAGRAPHS_AT_ONCE | Minden bekezdés. |
| BY_LEVEL_PARAGRAPHS1 | Az 1. mélységű bekezdések csoportjai szerint. |
| BY_LEVEL_PARAGRAPHS2 | A 2. mélységű bekezdések csoportjai szerint. |
| BY_LEVEL_PARAGRAPHS3 | A 3. mélységű bekezdések csoportjai szerint. |
| BY_LEVEL_PARAGRAPHS4 | A 4. mélységű bekezdések csoportjai szerint. |
| BY_LEVEL_PARAGRAPHS5 | A 5. mélységű bekezdések csoportjai szerint. |
