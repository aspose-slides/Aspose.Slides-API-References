## Behavior osztály

Az effektus alap osztályának viselkedését reprezentálja.

A Behavior típus a következő tagokat teszi közzé:

## Tulajdonságok

| Property | Description |
| :- | :- |
| [`accumulate`](/slides/python-net/hu/aspose.slides.animation/behavior/accumulate/) | Kijelzi, hogy az animációs viselkedések felhalmozódnak-e.<br/>            Olvasás/írás [`NullableBool`](/slides/python-net/hu/aspose.slides/nullablebool). |
| [`additive`](/slides/python-net/hu/aspose.slides.animation/behavior/additive/) | Kijelzi, hogy a jelenlegi animációs viselkedés más futó animációkkal van-e kombinálva.<br/>            Olvasás/írás [`BehaviorAdditiveType`](/slides/python-net/hu/aspose.slides.animation/behavioradditivetype). |
| [`properties`](/slides/python-net/hu/aspose.slides.animation/behavior/properties/) | Kijelzi a viselkedés tulajdonságait.<br/>            Csak olvasható [`IBehaviorPropertyCollection`](/slides/python-net/hu/aspose.slides.animation/ibehaviorpropertycollection). |
| [`timing`](/slides/python-net/hu/aspose.slides.animation/behavior/timing/) | Kijelzi az effektus viselkedés időzítési tulajdonságait.<br/>            Olvasás/írás [`ITiming`](/slides/python-net/hu/aspose.slides.animation/itiming). |
