## AnimateTextType enumeration

Az animációs hatás szöveganimáció típusát reprezentálja.

Az AnimateTextType típus a következő tagokkal rendelkezik:

## Mezők

| Mező | Leírás |
| :- | :- |
| ALL_AT_ONCE | Az összes szöveget egyszerre animálja. |
| BY_WORD | A szöveget szónként animálja. |
| BY_LETTER | A szöveget betűnként animálja. |
