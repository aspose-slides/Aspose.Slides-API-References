## AfterAnimationType enumeráció

Az animáció hatás után alkalmazott animáció típust képviseli.

Az AfterAnimationType típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| DO_NOT_DIM | Ne halványítsa az animáció után. |
| COLOR | Szín az animáció után. |
| HIDE_AFTER_ANIMATION | Elrejtés az animáció után |
| HIDE_ON_NEXT_MOUSE_CLICK | Elrejtés a következő egérkattintásnál az animáció után. |
