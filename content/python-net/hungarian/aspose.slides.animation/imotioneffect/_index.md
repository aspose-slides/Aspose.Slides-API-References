## IMotionEffect osztály

A mozgási hatás viselkedését reprezentálja.

Az IMotionEffect típus a következő tagokat teszi közzé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`from_address`](/slides/python-net/hu/aspose.slides.animation/imotioneffect/from_address/) | Megadja az animáció kezdőpontjának x/y koordinátáját (százalékban). <br/>            Olvasás/írás **aspose.slides.PointF**. |
| [`to`](/slides/python-net/hu/aspose.slides.animation/imotioneffect/to/) | Megadja az animáció mozgási hatásának célhelyét (százalékban).<br/>            Olvasás/írás **aspose.slides.PointF**. |
| [`by`](/slides/python-net/hu/aspose.slides.animation/imotioneffect/by/) | Leírja az animáció relatív eltolási értékét (százalékban).<br/>            Olvasás/írás **aspose.slides.PointF**. |
| [`rotation_center`](/slides/python-net/hu/aspose.slides.animation/imotioneffect/rotation_center/) | Leírja a forgás középpontját, amelyet egy X szögű mozgási út forgatásához használnak.<br/>            Olvasás/írás **aspose.slides.PointF**. |
| [`origin`](/slides/python-net/hu/aspose.slides.animation/imotioneffect/origin/) | Megadja, hogy a mozgási út kiindulópontja mire vonatkozik, például a diák elrendezésére,<br/>            vagy a szülőre.<br/>            Olvasás/írás [`MotionOriginType`](/slides/python-net/hu/aspose.slides.animation/motionorigintype). |

| [`path_edit_mode`](/slides/python-net/hu/aspose.slides.animation/imotioneffect/path_edit_mode/) | Megadja, hogy a mozgási út hogyan mozog, amikor az alakzatot mozgatják.<br/>            Olvasás/írás [`MotionPathEditMode`](/slides/python-net/hu/aspose.slides.animation/motionpatheditmode). |
