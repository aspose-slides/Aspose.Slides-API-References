## Timing osztály

Képviseli az animáció időzítését.

A Timing típus a következő tagokat teszi közzé:

## Tulajdonságok

| Property | Description |
| :- | :- |
| [`accelerate`](/slides/python-net/hu/aspose.slides.animation/timing/accelerate/) | Leírja a gyorsuló viselkedés hatás időtartamának százalékos arányát.<br/>            Olvasás/írás **float**. |
| [`decelerate`](/slides/python-net/hu/aspose.slides.animation/timing/decelerate/) | Leírja a lassuló viselkedés hatás időtartamának százalékos arányát.<br/>            Olvasás/írás **float**. |
| [`auto_reverse`](/slides/python-net/hu/aspose.slides.animation/timing/auto_reverse/) | Leírja, hogy automatikusan lejátszódjon-e az animáció visszafelé a<br/>            előre irányban történő lejátszás után.<br/>            Olvasás/írás **bool**. |
| [`duration`](/slides/python-net/hu/aspose.slides.animation/timing/duration/) | Leírja az animáció hatásának időtartamát.<br/>            Olvasás/írás **float**. |
| [`repeat_count`](/slides/python-net/hu/aspose.slides.animation/timing/repeat_count/) | Leírja, hogy hányszor ismétlődjön a hatás.<br/>            Olvasás/írás **float**. |
| [`repeat_until_end_slide`](/slides/python-net/hu/aspose.slides.animation/timing/repeat_until_end_slide/) | Ez a tulajdonság meghatározza, hogy a hatás a diára a végéig ismétlődik-e.<br/>             Olvasás/írás **bool**. |
| [`repeat_until_next_click`](/slides/python-net/hu/aspose.slides.animation/timing/repeat_until_next_click/) | Ez a tulajdonság meghatározza, hogy a hatás a következő kattintásig ismétlődik-e.<br/>             Olvasás/írás **bool**. |
| [`repeat_duration`](/slides/python-net/hu/aspose.slides.animation/timing/repeat_duration/) | Leírja, hogy hányszor ismétlődjön a hatás.<br/>            Olvasás/írás **float**. |
| [`restart`](/slides/python-net/hu/aspose.slides.animation/timing/restart/) | Megadja, hogy a hatás a teljes befejezés után újrainduljon-e.<br/>            Olvasás/írás [`EffectRestartType`](/slides/python-net/hu/aspose.slides.animation/effectrestarttype). |
| [`rewind`](/slides/python-net/hu/aspose.slides.animation/timing/rewind/) | Ez a tulajdonság meghatározza, hogy a hatás lejátszás befejezésekor visszatekerődik-e.<br/>             Olvasás/írás **bool**. |
| [`speed`](/slides/python-net/hu/aspose.slides.animation/timing/speed/) | Megadja a százalékos értéket, amellyel a időzítést gyorsítja (vagy lassítja).<br/>            Olvasás/írás **float**. |
| [`trigger_delay_time`](/slides/python-net/hu/aspose.slides.animation/timing/trigger_delay_time/) | Leírja a kiváltó után lévő késleltetési időt.<br/>            Olvasás/írás **float**. |
| [`trigger_type`](/slides/python-net/hu/aspose.slides.animation/timing/trigger_type/) | Leírja a kiváltó típusát.<br/>            Olvasás/írás [`EffectTriggerType`](/slides/python-net/hu/aspose.slides.animation/effecttriggertype). |
