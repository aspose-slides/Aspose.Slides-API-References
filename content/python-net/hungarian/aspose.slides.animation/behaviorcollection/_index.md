## BehaviorCollection osztály

A viselkedés hatásokat tartalmazó gyűjteményt képviseli.

A BehaviorCollection típus a következő tagokat teszi közzé:

## Tulajdonságok

| Property | Description |
| :- | :- |
| [`count`](/slides/python-net/hu/aspose.slides.animation/behaviorcollection/count/) | Visszaadja a viselkedések számát egy gyűjteményben.<br/>            Csak olvasható **int**. |
| [`is_read_only`](/slides/python-net/hu/aspose.slides.animation/behaviorcollection/is_read_only/) | Lekéri azt az értéket, amely azt jelzi, hogy a **System.Collections.Generic.ICollection`1** csak olvasható-e.<br/>            Csak olvasható **bool**. |

Visszaad egy viselkedést a megadott indexnél.

## Indexelő

| Név | Leírás |
| :- | :- |
| [`[index]`](/slides/python-net/hu/aspose.slides.animation/behaviorcollection/__getitem__/) | A visszaadandó viselkedés indexe. |
