## ITiming osztály

Az animáció időzítését reprezentálja.

Az ITiming típus a következő tagokat tartalmazza:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`accelerate`](/slides/python-net/hu/aspose.slides.animation/itiming/accelerate/) | Leírja a gyorsuló viselkedés hatás időtartamának százalékát.<br/>            Olvasás/írás **float**. |
| [`decelerate`](/slides/python-net/hu/aspose.slides.animation/itiming/decelerate/) | Leírja a lassuló viselkedés hatás időtartamának százalékát.<br/>            Olvasás/írás **float**. |
| [`auto_reverse`](/slides/python-net/hu/aspose.slides.animation/itiming/auto_reverse/) | Leírja, hogy a animációt automatikusan visszafelé játssza-e le a<br/>            előre irányban történő lejátszás után.<br/>            Olvasás/írás **bool**. |
| [`duration`](/slides/python-net/hu/aspose.slides.animation/itiming/duration/) | Leírja az animációs hatás időtartamát.<br/>            Olvasás/írás **float**. |
| [`repeat_count`](/slides/python-net/hu/aspose.slides.animation/itiming/repeat_count/) | Leírja, hogy hányszor kell ismételni a hatást.<br/>            Olvasás/írás **float**. |
| [`repeat_until_end_slide`](/slides/python-net/hu/aspose.slides.animation/itiming/repeat_until_end_slide/) | Ez az attribútum meghatározza, hogy a hatás a dia végéig ismétlődik-e.<br/>             Olvasás/írás **bool**. |
| [`repeat_until_next_click`](/slides/python-net/hu/aspose.slides.animation/itiming/repeat_until_next_click/) | Ez az attribútum meghatározza, hogy a hatás a következő kattintásig ismétlődik-e.<br/>             Olvasás/írás **bool**. |
| [`repeat_duration`](/slides/python-net/hu/aspose.slides.animation/itiming/repeat_duration/) | Leírja, hogy hányszor kell ismételni a hatást.<br/>            Olvasás/írás **float**. |
| [`restart`](/slides/python-net/hu/aspose.slides.animation/itiming/restart/) | Megadja, hogy a hatás a befejezés után újrainduljon-e.<br/>            Olvasás/írás [`EffectRestartType`](/slides/python-net/hu/aspose.slides.animation/effectrestarttype). |
| [`speed`](/slides/python-net/hu/aspose.slides.animation/itiming/speed/) | Megadja, hogy a időzítést hány százalékkal kell felgyorsítani (vagy lelassítani).<br/>            Olvasás/írás **float**. |
| [`trigger_delay_time`](/slides/python-net/hu/aspose.slides.animation/itiming/trigger_delay_time/) | Leírja a késleltetési időt a trigger után.<br/>            Olvasás/írás **float**. |
| [`trigger_type`](/slides/python-net/hu/aspose.slides.animation/itiming/trigger_type/) | Leírja a trigger típusát.<br/>            Olvasás/írás [`EffectTriggerType`](/slides/python-net/hu/aspose.slides.animation/effecttriggertype). |
| [`rewind`](/slides/python-net/hu/aspose.slides.animation/itiming/rewind/) | Ez az attribútum meghatározza, hogy a hatás a lejátszás befejezésekor visszatekerődik-e.<br/>             Olvasás/írás **bool**. |
