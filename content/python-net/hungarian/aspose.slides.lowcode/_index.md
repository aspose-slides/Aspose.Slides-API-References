Tartalmaz osztályokat és metódusokat összetett általános műveletek alacsony kódú módon történő kezeléséhez.
## Osztályok

| Osztály | Leírás |
| :- | :- |
| [`Collect`](/slides/python-net/hu/aspose.slides.lowcode/collect/) | Egy metóduscsoportot képvisel, amely különböző típusú modell objektumok gyűjtésére szolgál a [`Presentation`](/slides/python-net/hu/aspose.slides/presentation)-ből. |
| [`Compress`](/slides/python-net/hu/aspose.slides.lowcode/compress/) | Egy metóduscsoportot képvisel, amely a [`Presentation`](/slides/python-net/hu/aspose.slides/presentation) tömörítésére szolgál. |
| [`Convert`](/slides/python-net/hu/aspose.slides.lowcode/convert/) | Egy metóduscsoportot képvisel, amely a [`Presentation`](/slides/python-net/hu/aspose.slides/presentation) átalakítására szolgál. |
| [`ForEach`](/slides/python-net/hu/aspose.slides.lowcode/foreach/) | Egy metóduscsoportot képvisel, amely különböző [`Presentation`](/slides/python-net/hu/aspose.slides/presentation) modell objektumokon való iterálásra szolgál.<br/>            Ezek a metódusok hasznosak lehetnek, ha iterálni és módosítani kell a Presentation elemeinek formázását vagy tartalmát,<br/>            például minden rész formázását. |
| [`Merger`](/slides/python-net/hu/aspose.slides.lowcode/merger/) | Egy metóduscsoportot képvisel, amely az azonos formátumú PowerPoint prezentációk egyetlen fájlba egyesítésére szolgál. |
