## MathJustification felsorolás

Megadja a matematikai bekezdés igazítását (azonos bekezdésen belül egymás mellé helyezett matematikai szöveg példányok sorozata)

A MathJustification típus a következő tagokat teszi elérhetővé:

## Mezők

| Mező | Leírás |
| :- | :- |
| LEFT_JUSTIFIED | A matematikai szöveget balra igazítja |
| RIGHT_JUSTIFIED | A matematikai szöveget jobbra igazítja |
| CENTERED | A matematikai szöveget középre igazítja |
| CENTERED_AS_GROUP | Az oldalon középre helyezi a teljes matematikai blokkok csoportját egy egységként.<br/>            Ez azt jelenti, hogy a matematikai szöveg példányai egymáshoz képest igazíthatók, <br/>            de a teljes matematikai szövegcsoport egészként középre van igazítva. |
