## min_column_width tulajdonság
Minimum column width in twips (1/20th of a point)
            A hézag távolság (más néven “Column Gap” vagy “Gap Width”) hozzáadódik a 
            a MinColumnWidth-hez, hogy meghatározza a teljes Matrix Column Spacing
            (a különböző oszlopok azonos élei közti távolság).
            Alapértelmezett: 0.
