## MathRowSpacingRule enumeráció

A mátrix vagy tömb oszlopai közötti függőleges táv típusa

A MathRowSpacingRule típus a következő tagokat teszi elérhetővé:

## Mezők

| Mező | Leírás |
| :- | :- |
| SINGLE_LINE_GAP | egy soros rés |
| ONE_AND_A_HALF_LINE_GAP | másfél soros rés |
| TWO_LINE_GAP | két soros rés |
| EXACTLY | Pontos (a RowSpacing tulajdonság értékére támaszkodik, pontban mérve) |
| MULTIPLE | Többszörös (a RowSpacing tulajdonság értékére támaszkodik, sorokban mérve) |
