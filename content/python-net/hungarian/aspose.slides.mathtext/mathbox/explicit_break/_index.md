## explicit_break tulajdonság
Explicit break specifies whether there is a line break at the start of the Box object, 
            such that the line wraps at the start of the box object.
            Megadja az előző sorban lévő matematikai szöveg operátorának számát, amelyet a jelenlegi sor matematikai szövegének igazítási pontjaként kell használni.
            lehetséges értékek: 1..255
            Alapértelmezett: 0 (no explicit break)
