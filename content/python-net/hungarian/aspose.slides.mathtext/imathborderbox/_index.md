## IMathBorderBox osztály

Téglalap vagy más típusú keretet rajzol az IMathElement körül.

Az IMathBorderBox típus a következő tagokat teszi közzé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`base`](/slides/python-net/hu/aspose.slides.mathtext/imathborderbox/base/) | Alap argumentum |
| [`hide_top`](/slides/python-net/hu/aspose.slides.mathtext/imathborderbox/hide_top/) | A felső él elrejtése (alapértelmezett false) - meghatározza a border box felső élének rejtett vagy látható állapotát. |
| [`hide_bottom`](/slides/python-net/hu/aspose.slides.mathtext/imathborderbox/hide_bottom/) | Az alsó él elrejtése (alapértelmezett false) - meghatározza a border box alsó élének rejtett vagy látható állapotát. |
| [`hide_left`](/slides/python-net/hu/aspose.slides.mathtext/imathborderbox/hide_left/) | A bal él elrejtése (alapértelmezett false) - meghatározza a border box bal élének rejtett vagy látható állapotát. |
| [`hide_right`](/slides/python-net/hu/aspose.slides.mathtext/imathborderbox/hide_right/) | A jobb él elrejtése (alapértelmezett false) - meghatározza a border box jobb élének rejtett vagy látható állapotát. |
| [`strikethrough_horizontal`](/slides/python-net/hu/aspose.slides.mathtext/imathborderbox/strikethrough_horizontal/) | Vízszintes áthúzás (alapértelmezett false) - meghatározza egy vízszintes áthúzási vonal rejtett vagy látható állapotát. |
| [`strikethrough_vertical`](/slides/python-net/hu/aspose.slides.mathtext/imathborderbox/strikethrough_vertical/) | Függőleges áthúzás (alapértelmezett false) - meghatározza egy függőleges áthúzási vonal rejtett vagy látható állapotát. |
| [`strikethrough_bottom_left_to_top_right`](/slides/python-net/hu/aspose.slides.mathtext/imathborderbox/strikethrough_bottom_left_to_top_right/) | Bal alsó-jobb felső áthúzás (alapértelmezett false).<br/>            Meghatározza a border box bal alsó sarkától jobb felső sarkáig ívelő áthúzási vonal rejtett vagy látható állapotát. |
| [`strikethrough_top_left_to_bottom_right`](/slides/python-net/hu/aspose.slides.mathtext/imathborderbox/strikethrough_top_left_to_bottom_right/) | Felső balról alsó jobb áthúzás (alapértelmezett false).<br/>            Meghatározza a border box felső bal sarkától alsó jobb sarkáig ívelő áthúzási vonal rejtett vagy látható állapotát. |
