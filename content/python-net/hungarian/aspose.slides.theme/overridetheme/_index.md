## OverrideTheme osztály

Egy felülíró témát képvisel.

**Öröklés:**[`OverrideTheme`](/slides/python-net/hu/aspose.slides.theme/overridetheme) → [`Theme`](/slides/python-net/hu/aspose.slides.theme/theme)

Az OverrideTheme típus a következő tagokat biztosít:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`color_scheme`](/slides/python-net/hu/aspose.slides.theme/overridetheme/color_scheme/) | Visszaadja a színsémát.<br/>            Csak olvasható [`IColorScheme`](/slides/python-net/hu/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/hu/aspose.slides.theme/overridetheme/font_scheme/) | Visszaadja a betűtípus sémát.<br/>            Csak olvasható [`IFontScheme`](/slides/python-net/hu/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/hu/aspose.slides.theme/overridetheme/format_scheme/) | Visszaadja az alakzat formátumsémát.<br/>            Csak olvasható [`IFormatScheme`](/slides/python-net/hu/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/hu/aspose.slides.theme/overridetheme/presentation/) | Visszaadja a szülő prezentációt.<br/>            Csak olvasható [`IPresentation`](/slides/python-net/hu/aspose.slides/ipresentation). |
| [`is_empty`](/slides/python-net/hu/aspose.slides.theme/overridetheme/is_empty/) | Az igaz érték azt jelenti, hogy a ColorScheme, FontScheme, FormatScheme nincs megadva, és minden felülírás ezzel a témaobjektummal le van tiltva.<br/>            Csak olvasható **bool**. |
