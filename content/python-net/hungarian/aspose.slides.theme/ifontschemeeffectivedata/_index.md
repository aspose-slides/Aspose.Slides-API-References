## IFontSchemeEffectiveData osztály

Megváltoztathatatlan objektum, amely a tényleges betűkészlet-sémára vonatkozó tulajdonságokat tartalmaz.

Az IFontSchemeEffectiveData típus a következő tagokat tartalmazza:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`minor`](/slides/python-net/hu/aspose.slides.theme/ifontschemeeffectivedata/minor/) | Returns the fonts collection for a "body" part of the slide.<br/>            Csak olvasható [`IFontsEffectiveData`](/slides/python-net/hu/aspose.slides/ifontseffectivedata). |
| [`major`](/slides/python-net/hu/aspose.slides.theme/ifontschemeeffectivedata/major/) | Returns the fonts collection for a "heading" part of the slide.<br/>            Csak olvasható [`IFontsEffectiveData`](/slides/python-net/hu/aspose.slides/ifontseffectivedata). |
| [`name`](/slides/python-net/hu/aspose.slides.theme/ifontschemeeffectivedata/name/) | Returns the font scheme name.<br/>            Csak olvasható **str**. |
