## MasterTheme osztály

Egy master témát reprezentál.

**Öröklődés:**[`MasterTheme`](/slides/python-net/hu/aspose.slides.theme/mastertheme) → [`Theme`](/slides/python-net/hu/aspose.slides.theme/theme)

A MasterTheme típus a következő tagokat teszi közzé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`color_scheme`](/slides/python-net/hu/aspose.slides.theme/mastertheme/color_scheme/) | Visszaadja a színsémát.<br/>            Csak olvasható [`IColorScheme`](/slides/python-net/hu/aspose.slides.theme/icolorscheme). |
| [`font_scheme`](/slides/python-net/hu/aspose.slides.theme/mastertheme/font_scheme/) | Visszaadja a betűtípussémát.<br/>            Csak olvasható [`IFontScheme`](/slides/python-net/hu/aspose.slides.theme/ifontscheme). |
| [`format_scheme`](/slides/python-net/hu/aspose.slides.theme/mastertheme/format_scheme/) | Visszaadja az alakzatformátumsémát.<br/>            Csak olvasható [`IFormatScheme`](/slides/python-net/hu/aspose.slides.theme/iformatscheme). |
| [`presentation`](/slides/python-net/hu/aspose.slides.theme/mastertheme/presentation/) | Visszaadja a szülő prezentációt.<br/>            Csak olvasható [`IPresentation`](/slides/python-net/hu/aspose.slides/ipresentation). |
| [`extra_color_schemes`](/slides/python-net/hu/aspose.slides.theme/mastertheme/extra_color_schemes/) | Visszaadja a további színsémák gyűjteményét.<br/>            Ezek a sémák nem befolyásolják a bemutató megjelenését, egy dián fő színsémaként kiválaszthatók.<br/>            Csak olvasható [`IExtraColorSchemeCollection`](/slides/python-net/hu/aspose.slides.theme/iextracolorschemecollection). |
| [`name`](/slides/python-net/hu/aspose.slides.theme/mastertheme/name/) | Visszaadja egy téma nevét.<br/>            Olvasható/írható **str**. |
