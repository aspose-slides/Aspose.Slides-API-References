## IFontScheme osztály

Témakör által meghatározott betűkészleteket tárol.

Az IFontScheme típus a következő tagokat teszi elérhetővé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`minor`](/slides/python-net/hu/aspose.slides.theme/ifontscheme/minor/) | Visszaadja a betűkészletek gyűjteményét a dián a "body" részhez.<br/>            Csak olvasható [`IFonts`](/slides/python-net/hu/aspose.slides/ifonts). |
| [`major`](/slides/python-net/hu/aspose.slides.theme/ifontscheme/major/) | Visszaadja a betűkészletek gyűjteményét a dián a "heading" részhez.<br/>            Csak olvasható [`IFonts`](/slides/python-net/hu/aspose.slides/ifonts). |
| [`name`](/slides/python-net/hu/aspose.slides.theme/ifontscheme/name/) | Visszaadja a betűkészlet-séma nevét.<br/>            Olvasás/írás **str**. |
