## FontScheme osztály

A témához definiált betűkészleteket tárolja.

A FontScheme típus a következő tagokat teszi elérhetővé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`minor`](/slides/python-net/hu/aspose.slides.theme/fontscheme/minor/) | Visszaadja a betűkészletek gyűjteményét a diák "body" részéhez.<br/>            Csak olvasható [`IFonts`](/slides/python-net/hu/aspose.slides/ifonts). |
| [`major`](/slides/python-net/hu/aspose.slides.theme/fontscheme/major/) | Visszaadja a betűkészletek gyűjteményét a diák "heading" részéhez.<br/>            Csak olvasható [`IFonts`](/slides/python-net/hu/aspose.slides/ifonts). |
| [`name`](/slides/python-net/hu/aspose.slides.theme/fontscheme/name/) | Visszaadja a betűtípus-séma nevét.<br/>            Olvasás/írás **str**. |
