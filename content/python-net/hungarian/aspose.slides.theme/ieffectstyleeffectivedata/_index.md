## IEffectStyleEffectiveData osztály

Az IEffectStyleEffectiveData típus a következő tagokat tartalmazza:

## Tulajdonságok

| Property | Description |
| :- | :- |
| [`effect_format`](/slides/python-net/hu/aspose.slides.theme/ieffectstyleeffectivedata/effect_format/) | Visszaad egy effektus formátumot.<br/>            Csak olvasható [`IEffectFormatEffectiveData`](/slides/python-net/hu/aspose.slides/ieffectformateffectivedata). |
