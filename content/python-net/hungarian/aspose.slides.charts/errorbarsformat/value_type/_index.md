## value_type tulajdonság
Azonosítja a hibasávok hosszának meghatározásának lehetséges módjait. 
            Egyéni értéktípus esetén az érték megadásához használja a [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/hu/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) tulajdonságot a sorozat DataPoints gyűjteményében lévő adott adatponton.
            Fixed, Percentage vagy StandardDeviation értéktípus esetén használja a Value tulajdonságot az érték megadásához.  
            Olvasás/írás [`ErrorBarValueType`](/slides/python-net/hu/aspose.slides.charts/errorbarvaluetype).
