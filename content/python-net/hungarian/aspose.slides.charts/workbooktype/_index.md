## WorkbookType enumeráció

Meghatározza az Open XML munkafüzet fájl típusát.

A WorkbookType típus a következő tagokat teszi elérhetővé:

## Mezők

| Mező | Leírás |
| :- | :- |
| NOT_DEFINED | A munkafüzet típusa nincs definiálva. |
| WORKBOOK | Excel munkafüzet (*.xlsx). |
| WORKBOOK_MACRO | Excel makróval ellátott munkafüzet (*.xlsm). |
| TEMPLATE | Excel sablon (*.xltx). |
| TEMPLATE_MACRO | Excel makróval ellátott sablon (*.xltm). |
| WORKBOOK_BINARY_MACRO | Excel bináris makróval ellátott munkafüzet (*.xlsb). |
