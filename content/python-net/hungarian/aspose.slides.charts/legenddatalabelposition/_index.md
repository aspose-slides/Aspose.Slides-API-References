## LegendDataLabelPosition enumeráció

Meghatározza az adatcímkék helyzetét.

A LegendDataLabelPosition típus a következő tagokat teszi elérhetővé:

## Mezők

| Mező | Leírás |
| :- | :- |
| NOT_DEFINED | A pozíció nincs definiálva. |
| BOTTOM | Azt határozza meg, hogy az adatcímkék a adatjelző alatt jelenjenek meg. |
| BEST_FIT | Azt határozza meg, hogy az adatcímkék a legjobb pozícióban jelenjenek meg. |
| CENTER | Azt határozza meg, hogy az adatcímkék középre legyenek helyezve az adatjelzőn. |
| INSIDE_BASE | Azt határozza meg, hogy az adatcímkék az adatjelző alapján belül jelenjenek meg. |
| INSIDE_END | Azt határozza meg, hogy az adatcímkék az adatjelző végén belül jelenjenek meg. |
| LEFT | Azt határozza meg, hogy az adatcímkék az adatjelző bal oldalán jelenjenek meg. |
| OUTSIDE_END | Azt határozza meg, hogy az adatcímkék az adatjelző végén kívül jelenjenek meg. |
| RIGHT | Azt határozza meg, hogy az adatcímkék az adatjelző jobb oldalán jelenjenek meg. |
| TOP | Azt határozza meg, hogy az adatcímkék az adatjelző felett jelenjenek meg. |
