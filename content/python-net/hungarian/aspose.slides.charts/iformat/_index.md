## IFormat osztály

Képviseli a diagram formátum tulajdonságait.

Az IFormat típus a következő tagokat teszi elérhetővé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`fill`](/slides/python-net/hu/aspose.slides.charts/iformat/fill/) | Visszaad egy diagram kitöltési stílus tulajdonságait.<br/>            Csak olvasható [`IFillFormat`](/slides/python-net/hu/aspose.slides/ifillformat). |
| [`line`](/slides/python-net/hu/aspose.slides.charts/iformat/line/) | Visszaad egy diagram vonalstílus tulajdonságait.<br/>            Csak olvasható [`ILineFormat`](/slides/python-net/hu/aspose.slides/ilineformat). |
| [`effect`](/slides/python-net/hu/aspose.slides.charts/iformat/effect/) | Visszaad egy diagramra alkalmazott effektusokat.<br/>            Csak olvasható [`IEffectFormat`](/slides/python-net/hu/aspose.slides/ieffectformat). |
| [`effect_3d`](/slides/python-net/hu/aspose.slides.charts/iformat/effect_3d/) | Visszaad egy diagram 3D formátumát.<br/>            Csak olvasható [`IThreeDFormat`](/slides/python-net/hu/aspose.slides/ithreedformat). |
