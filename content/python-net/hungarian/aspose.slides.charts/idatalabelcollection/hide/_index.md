## hide(self) {#}
Alapértelmezés szerint rejtetté teszi az adatcímkét, ha a DefaultDataLabelFormat property összes Show*-flags (ShowValue, ...) értékét false állapotra állítja. Az IsVisible false lesz ezt követően.

```python
def hide(self):
    ...
```

### Megjegyzések

Ha az adatcímke nem látható alapértelmezés szerint (IsVisible false), akkor a DefaultDataLabelFormat property Show*-flags (ShowValue, ...) beállításával "látható alapértelmezés szerint" tehető true állapotra.
