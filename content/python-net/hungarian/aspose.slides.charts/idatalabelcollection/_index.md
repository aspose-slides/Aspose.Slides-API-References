## IDataLabelCollection osztály

Sorozat címkéket képvisel.

Az IDataLabelCollection típus a következő tagokat tartalmazza:

## Tulajdonságok

| Property | Leírás |
| :- | :- |
| [`default_data_label_format`](/slides/python-net/hu/aspose.slides.charts/idatalabelcollection/default_data_label_format/) | Visszaadja az összes adatcímke alapértelmezett formátumát a gyűjteményben.<br/>            Csak olvasható [`IDataLabelFormat`](/slides/python-net/hu/aspose.slides.charts/idatalabelformat). |
| [`leader_lines_format`](/slides/python-net/hu/aspose.slides.charts/idatalabelcollection/leader_lines_format/) | Az adatcímkék vezető vonalainak formátumát képviseli.<br/>             Csak olvasható [`IChartLinesFormat`](/slides/python-net/hu/aspose.slides.charts/ichartlinesformat). |
| [`is_visible`](/slides/python-net/hu/aspose.slides.charts/idatalabelcollection/is_visible/) | A False azt jelenti, hogy az adatcímke alapértelmezés szerint nem látható (és ezért az összes Show*-jelző (ShowValue, ...) a DefaultDataLabelFormat tulajdonságban hamis).<br/>            Csak olvasható **bool**. |
| [`count_of_visible_data_labels`](/slides/python-net/hu/aspose.slides.charts/idatalabelcollection/count_of_visible_data_labels/) | Visszaadja a gyűjteményben lévő látható adatcímkék számát.<br/>            Csak olvasható **int**. |
| [`count`](/slides/python-net/hu/aspose.slides.charts/idatalabelcollection/count/) | Visszaadja a gyűjteményben lévő összes adatcímke számát.<br/>            Csak olvasható **int**. |
| [`parent_series`](/slides/python-net/hu/aspose.slides.charts/idatalabelcollection/parent_series/) | Visszaadja a szülő diagram sorozatot.<br/>            Csak olvasható [`IChartSeries`](/slides/python-net/hu/aspose.slides.charts/ichartseries). |
