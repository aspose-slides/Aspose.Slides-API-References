## IChartParagraphFormat osztály

A diagram bekezdésformázási tulajdonságait képviseli.

Az IChartParagraphFormat típus a következő elemeket teszi elérhetővé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`alignment`](/slides/python-net/hu/aspose.slides.charts/ichartparagraphformat/alignment/) | Visszaadja vagy beállítja a szövegigazítást egy bekezdésben.<br/>            Olvasás/írás [`TextAlignment`](/slides/python-net/hu/aspose.slides/textalignment). |
| [`space_within`](/slides/python-net/hu/aspose.slides.charts/ichartparagraphformat/space_within/) | Visszaadja vagy beállítja az alapvonalak közti térközt egy bekezdésben.<br/>            Olvasás/írás **float**. |
| [`space_before`](/slides/python-net/hu/aspose.slides.charts/ichartparagraphformat/space_before/) | Visszaadja vagy beállítja az első sor előtti térközt egy bekezdésben.<br/>            Olvasás/írás **float**. |
| [`space_after`](/slides/python-net/hu/aspose.slides.charts/ichartparagraphformat/space_after/) | Visszaadja vagy beállítja az utolsó sor utáni térközt egy bekezdésben.<br/>            Olvasás/írás **float**. |
| [`east_asian_line_break`](/slides/python-net/hu/aspose.slides.charts/ichartparagraphformat/east_asian_line_break/) | Megállapítja, hogy a kelet-ázsiai sortörés használatban van-e egy bekezdésben.<br/>            Olvasás/írás [`NullableBool`](/slides/python-net/hu/aspose.slides/nullablebool). |
| [`right_to_left`](/slides/python-net/hu/aspose.slides.charts/ichartparagraphformat/right_to_left/) | Megállapítja, hogy jobbról balra írás használatban van-e egy bekezdésben.<br/>            Olvasás/írás [`NullableBool`](/slides/python-net/hu/aspose.slides/nullablebool). |
| [`latin_line_break`](/slides/python-net/hu/aspose.slides.charts/ichartparagraphformat/latin_line_break/) | Megállapítja, hogy a latin sortörés használatban van-e egy bekezdésben.<br/>            Olvasás/írás [`NullableBool`](/slides/python-net/hu/aspose.slides/nullablebool). |
| [`hanging_punctuation`](/slides/python-net/hu/aspose.slides.charts/ichartparagraphformat/hanging_punctuation/) | Megállapítja, hogy függő írásjelek használatban vannak-e egy bekezdésben.<br/>            Olvasás/írás [`NullableBool`](/slides/python-net/hu/aspose.slides/nullablebool). |
| [`margin_left`](/slides/python-net/hu/aspose.slides.charts/ichartparagraphformat/margin_left/) | Visszaadja vagy beállítja a bal margót egy bekezdésben.<br/>            Olvasás/írás **float**. |
| [`margin_right`](/slides/python-net/hu/aspose.slides.charts/ichartparagraphformat/margin_right/) | Visszaadja vagy beállítja a jobb margót egy bekezdésben.<br/>            Olvasás/írás **float**. |
| [`indent`](/slides/python-net/hu/aspose.slides.charts/ichartparagraphformat/indent/) | Visszaadja vagy beállítja a bekezdés első sor behúzását/függő behúzást. A függő behúzás negatív értékkel is definiálható.<br/>            Olvasás/írás **float**. |
| [`default_tab_size`](/slides/python-net/hu/aspose.slides.charts/ichartparagraphformat/default_tab_size/) | Visszaadja vagy beállítja az alapértelmezett tabuláció méretét.<br/>            Olvasás/írás **float**. |
| [`tabs`](/slides/python-net/hu/aspose.slides.charts/ichartparagraphformat/tabs/) | Visszaadja a bekezdés tabulációit.<br/>            Csak olvasható [`ITabCollection`](/slides/python-net/hu/aspose.slides/itabcollection). |
| [`font_alignment`](/slides/python-net/hu/aspose.slides.charts/ichartparagraphformat/font_alignment/) | Visszaadja vagy beállítja a betűtípus igazítását egy bekezdésben.<br/>            Olvasás/írás [`FontAlignment`](/slides/python-net/hu/aspose.slides/fontalignment). |
