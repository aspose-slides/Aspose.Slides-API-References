## PictureType enumeráció

Meghatározza a sáv képi kitöltésének módját.

A PictureType típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| NOT_DEFINED | Nincs meghatározva. |
| STACK | A képet úgy méretezik, hogy a leghosszabb halmozott sávban legfeljebb 15-ször ismétlődjön. |
| STACK_SCALE | A képet egy meghatározott egységszámra méretezik, és a sáv hosszán ismétlődik. |
| STRETCH | A képet a halmozott sáv teljes hosszára nyújtják. |
