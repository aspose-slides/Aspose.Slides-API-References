## ParentLabelLayoutType enumeráció

A kategória adatcímkék elrendezését reprezentálja. Csak Treemap sorozatoknál használható.

A ParentLabelLayoutType típus a következő tagokat teszi elérhetővé:

## Mezők

| Mező | Leírás |
| :- | :- |
| BANNER | Meghatározza, hogy a szülő kategória címkék szalagszerűen jelennek meg |
| NONE | Meghatározza, hogy a szülő kategória címkék nincsenek megrajzolva |
| OVERLAPPING | Meghatározza, hogy a szülő kategória címkék átfedésben jelennek meg |
