## ChartType enumeráció

A diagram egy típusát képviseli.

A ChartType típus a következő tagokat tartalmazza:

| Mező | Leírás |
| :- | :- |
| CLUSTERED_COLUMN | Csoportosított oszlopdiagramot képviseli. |

| PERCENTS_STACKED_COLUMN | 100%-os halmozott oszlopdiagramot képviseli. |
| CLUSTERED_COLUMN_3D | 3D csoportosított oszlopdiagramot képviseli. |
| STACKED_COLUMN_3D | 3D halmozott oszlopdiagramot képviseli. |

| CLUSTERED_CYLINDER | Hengerdiagramot képviseli. |

| PERCENTS_STACKED_CYLINDER | 100%-os halmozott hengerdiagramot képviseli. |
| CYLINDER_3D | 3D henger alakú oszlopdiagramot képviseli. |
| CLUSTERED_CONE | Kúpdiagramot képviseli. |
| STACKED_CONE | Halmozott kúpdiagramot képviseli. |
