## PieSplitType enumeráció

A második kör vagy oszlop szétválasztási pontjainak típusát képviseli egy kör-kör vagy oszlop-kör diagramon.

A PieSplitType típus a következő tagokat teszi elérhetővé:

## Mezők

| Mező | Leírás |
| :- | :- |
| DEFAULT | Megadja, hogy az adatpontok az alapértelmezett <br/>            mechanizmust használva legyenek szétválasztva ennél a diagramtípusnál. |
| CUSTOM | Megadja, hogy az adatpontok a <br/>            kör és a második diagram között legyenek szétválasztva a Custom Split értékek szerint. |
| BY_PERCENTAGE | Megadja, hogy az adatpontok a kör és a <br/>            második diagram között legyenek szétválasztva úgy, hogy a <br/>            százalékuk kisebb, mint a Split Position százalék, a második diagramba kerülnek. |
| BY_POS | Megadja, hogy az adatpontok a kör és a <br/>            második diagram között legyenek szétválasztva úgy, hogy az adatpontok legutolsó Split Position-ét <br/>            a második diagramba helyezzék. |
| BY_VALUE | Megadja, hogy az adatpontok a kör és a <br/>            második diagram között legyenek szétválasztva úgy, hogy az értékük kisebb, mint a Split Position, a második diagramba kerülnek. |
