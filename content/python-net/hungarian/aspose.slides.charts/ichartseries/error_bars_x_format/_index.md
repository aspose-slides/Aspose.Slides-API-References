## error_bars_x_format tulajdonság
Az X irányú sorozat ErrorBars értékét reprezentálja. 
            
            Az X irányú ErrorBars elérhető area, bar, scatter és bubble típusú sorozatoknál. 
            Más típusú diagramoknál ez a tulajdonság None értéket ad vissza (beleértve a 3D diagramokat).
            Egyedi értékek esetén használja a DataPoints gyűjteményt az érték megadásához
            ([`IChartDataPoint.error_bars_custom_values`](/slides/python-net/hu/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) tulajdonsággal).
            
            Csak-olvasású [`IErrorBarsFormat`](/slides/python-net/hu/aspose.slides.charts/ierrorbarsformat).
