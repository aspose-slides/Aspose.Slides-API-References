## TickMarkType enumeráció

A megadott tengelyhez tartozó jelölő vonal típusát reprezentálja.

A TickMarkType típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| CROSS | Megadja, hogy a jelölő vonalak átlójanak a tengelyen. |
| INSIDE | Megadja, hogy a jelölő vonalak a diagramterületen belül legyenek. |
| NONE | Megadja, hogy ne legyenek jelölő vonalak. |
| OUTSIDE | Megadja, hogy a jelölő vonalak a diagramterület kívül legyenek. |
