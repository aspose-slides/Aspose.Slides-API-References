## IChartWall osztály

A 3d diagramok falait képviseli.

Az IChartWall típus a következő tagokat teszi közzé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`thickness`](/slides/python-net/hu/aspose.slides.charts/ichartwall/thickness/) | Visszaadja vagy beállítja a falak vastagságát a diagram térfogatának legnagyobb <br/>            dimenziójának százalékában.<br/>            Olvasás/írás **int**. |
| [`format`](/slides/python-net/hu/aspose.slides.charts/ichartwall/format/) | Visszaadja a fal kitöltését, vonalát, effektusát, 3d stílusait.<br/>            Csak olvasható [`IFormat`](/slides/python-net/hu/aspose.slides.charts/iformat). |
| [`picture_type`](/slides/python-net/hu/aspose.slides.charts/ichartwall/picture_type/) | Visszaadja vagy beállítja a kép típusát.<br/>            Olvasás/írás [`IChartWall.picture_type`](/slides/python-net/hu/aspose.slides.charts/ichartwall/picture_type). |
