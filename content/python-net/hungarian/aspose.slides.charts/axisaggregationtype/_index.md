## AxisAggregationType enumeráció

A kategória tengely aggregációs típusát képviseli. Csak Histogram vagy HistogramPareto sorozatokkal használható.

Az AxisAggregationType típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| BY_CATEGORY | Aggregálás kategóriák szerint |
| AUTOMATIC | Kategóriák automatikus aggregálása. |
| BY_BIN_WIDTH | Aggregálja a kategóriákat a vödör szélessége alapján. Az IAxis.BinWidth tulajdonságot be kell állítani. |
| BY_NUMBER_OF_BINS | Aggregálja a kategóriákat a vödrök száma alapján. Az IAxis.NumberOfBins tulajdonságot be kell állítani. |
