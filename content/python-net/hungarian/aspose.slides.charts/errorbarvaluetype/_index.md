## ErrorBarValueType enumeráció

Az error bar érték típusát jelöli

Az ErrorBarValueType típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| CUSTOM | Azt határozza meg, hogy a hibasávok hossza a Plusz és Minus elemek alapján legyen meghatározva. |
| FIXED | Azt határozza meg, hogy a hibasávok hossza az Error Bar Value által meghatározott rögzített érték legyen. |
| PERCENTAGE | Azt határozza meg, hogy a hibasávok hossza az adatnak az Error Bar Value százaléka legyen. |
| STANDARD_DEVIATION | Azt határozza meg, hogy a hibasávok hossza az adatnak az Error Bar Value standard deviációja legyen. |
| STANDARD_ERROR | Azt határozza meg, hogy a hibasávok hossza az adatnak az Error Bar Value standard hibája legyen. |
