## ChartDataCell osztály

Képviseli a diagram adataihoz tartozó cellát.

A ChartDataCell típus a következő tagokat teszi közzé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`row`](/slides/python-net/hu/aspose.slides.charts/chartdatacell/row/) | Visszaadja a munkalap sorának indexét, amelyben a cella található.<br/>            Csak olvasható **int**. |
| [`column`](/slides/python-net/hu/aspose.slides.charts/chartdatacell/column/) | Visszaadja a munkalap oszlopának indexét, amelyben a cella található.<br/>            Csak olvasható **int**. |
| [`value`](/slides/python-net/hu/aspose.slides.charts/chartdatacell/value/) | Lekérdezi vagy beállítja egy cella értékét.<br/>            Olvasható/írható **any**. |
| [`formula`](/slides/python-net/hu/aspose.slides.charts/chartdatacell/formula/) | Lekérdezi vagy beállítja a képletet A1-stílusban. |
| [`r1c1_formula`](/slides/python-net/hu/aspose.slides.charts/chartdatacell/r1c1_formula/) | Lekérdezi vagy beállítja a képletet R1C1-stílusban. |
| [`chart_data_worksheet`](/slides/python-net/hu/aspose.slides.charts/chartdatacell/chart_data_worksheet/) | Lekérdezi a munkalapot.<br/>            Csak olvasható [`IChartDataWorksheet`](/slides/python-net/hu/aspose.slides.charts/ichartdataworksheet). |
| [`is_hidden`](/slides/python-net/hu/aspose.slides.charts/chartdatacell/is_hidden/) | Megállapítja, hogy a cella rejtett-e.<br/>            Csak olvasható **bool**. |
| [`custom_number_format`](/slides/python-net/hu/aspose.slides.charts/chartdatacell/custom_number_format/) | Lekérdezi vagy beállítja a számok és dátumok egyéni megjelenítési formátumát.<br/>            Ha az érték üres, a PresetNumberFormat érték lesz használva.<br/>            Olvasható/írható **str**. |
| [`preset_number_format`](/slides/python-net/hu/aspose.slides.charts/chartdatacell/preset_number_format/) | Lekérdezi vagy beállítja a számok és dátumok beépített megjelenítési formátumát. Az előre definiált számnak a [0..22] vagy [37..49] tartományban kell lennie.<br/>             Olvasható/írható **int**. |
