## Legend osztály

A diagram legenda tulajdonságait képviseli.

A Legend típus a következő tagokat teszi elérhetővé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`x`](/slides/python-net/hu/aspose.slides.charts/legend/x/) | Visszaadja vagy beállítja a legenda x koordinátáját a diagram szélességének tört részeként.<br/>            Olvasás/írás **float**. |
| [`y`](/slides/python-net/hu/aspose.slides.charts/legend/y/) | Visszaadja vagy beállítja a legenda y koordinátáját a diagram magasságának tört részeként.<br/>            Olvasás/írás **float**. |
| [`width`](/slides/python-net/hu/aspose.slides.charts/legend/width/) | Visszaadja vagy beállítja a legenda szélességét a diagram szélességének tört részeként.<br/>            Olvasás/írás **float**. |
| [`height`](/slides/python-net/hu/aspose.slides.charts/legend/height/) | Visszaadja vagy beállítja a legenda magasságát a diagram magasságának tört részeként.<br/>            Olvasás/írás **float**. |
| [`right`](/slides/python-net/hu/aspose.slides.charts/legend/right/) | Jobb.<br/>            Csak olvasható **float**. |
| [`bottom`](/slides/python-net/hu/aspose.slides.charts/legend/bottom/) | Alsó.<br/>            Csak olvasható **float**. |
| [`overlay`](/slides/python-net/hu/aspose.slides.charts/legend/overlay/) | Meghatározza, hogy a diagram egyéb elemei átfedhetik-e a legendát.<br/>            Olvasás/írás **bool**. |
| [`text_format`](/slides/python-net/hu/aspose.slides.charts/legend/text_format/) | Szövegformátum.<br/>            Csak olvasható [`IChartTextFormat`](/slides/python-net/hu/aspose.slides.charts/icharttextformat). |
| [`position`](/slides/python-net/hu/aspose.slides.charts/legend/position/) | Meghatározza a legenda pozícióját a diagramon.<br/>            A X, Y, Width, Heigt tulajdonságok nem-NaN értékei felülbírálják ennek a tulajdonságnak a hatását.<br/>            Olvasás/írás [`LegendPositionType`](/slides/python-net/hu/aspose.slides.charts/legendpositiontype). |
| [`format`](/slides/python-net/hu/aspose.slides.charts/legend/format/) | Visszaadja a legenda formátumát.<br/>            Csak olvasható [`IFormat`](/slides/python-net/hu/aspose.slides.charts/iformat). |
| [`chart`](/slides/python-net/hu/aspose.slides.charts/legend/chart/) | Visszaadja a diagramot.<br/>            Csak olvasható [`IChart`](/slides/python-net/hu/aspose.slides.charts/ichart). |
| [`entries`](/slides/python-net/hu/aspose.slides.charts/legend/entries/) | Lekéri a legenda bejegyzéseit.<br/>            Csak olvasható [`ILegendEntryCollection`](/slides/python-net/hu/aspose.slides.charts/ilegendentrycollection). |
| [`actual_x`](/slides/python-net/hu/aspose.slides.charts/legend/actual_x/) | Megadja a diagram elem tényleges x helyzetét (left) a diagram bal felső sarkához viszonyítva.<br/>            Hívja meg az IChart.ValidateChartLayout() metódust előbb a tényleges értékek megszerzéséhez. <br/>            Olvas **float**. |
| [`actual_y`](/slides/python-net/hu/aspose.slides.charts/legend/actual_y/) | Megadja a diagram elem tényleges felső pozícióját a diagram bal felső sarkához viszonyítva.<br/>            Hívja meg az IChart.ValidateChartLayout() metódust előbb a tényleges értékek megszerzéséhez. <br/>            Olvas **float**. |
| [`actual_width`](/slides/python-net/hu/aspose.slides.charts/legend/actual_width/) | Megadja a diagram elem tényleges szélességét. Hívja meg az IChart.ValidateChartLayout() metódust előbb a tényleges értékek megszerzéséhez. <br/>            Olvas **float**. |
| [`actual_height`](/slides/python-net/hu/aspose.slides.charts/legend/actual_height/) | Megadja a diagram elem tényleges magasságát. Hívja meg az IChart.ValidateChartLayout() metódust előbb a tényleges értékek megszerzéséhez. <br/>            Olvas **float**. |
