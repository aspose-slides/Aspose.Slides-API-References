## ChartDataPointCollection osztály

A ChartDataPointCollection gyűjteményt képviseli egy sorozat adatpontjához.

A ChartDataPointCollection típus a következő tagokat teszi közzé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`data_source_type_for_x_values`](/slides/python-net/hu/aspose.slides.charts/chartdatapointcollection/data_source_type_for_x_values/) | Megadja, hogy az AsCell vagy az AsLiteralString vagy az AsLiteralDouble tulajdonság <br/>            ténylegesen jelen van az adatpontok XValue tulajdonságobjektumban. Más szóval megadja <br/>            a ChartDataPoint.XValue.Data tulajdonság értékének típusát.<br/>            Olvasás/írás [`DataSourceType`](/slides/python-net/hu/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_y_values`](/slides/python-net/hu/aspose.slides.charts/chartdatapointcollection/data_source_type_for_y_values/) | Megadja, hogy az AsCell vagy az AsLiteralString vagy az AsLiteralDouble tulajdonság <br/>            ténylegesen jelen van az adatpontok YValue tulajdonságobjektumban. Más szóval megadja <br/>            a ChartDataPoint.YValue.Data tulajdonság értékének típusát.<br/>            Olvasás/írás [`DataSourceType`](/slides/python-net/hu/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_bubble_sizes`](/slides/python-net/hu/aspose.slides.charts/chartdatapointcollection/data_source_type_for_bubble_sizes/) | Megadja, hogy az AsCell vagy az AsLiteralString vagy az AsLiteralDouble tulajdonság <br/>            ténylegesen jelen van az adatpontok BubbleSize tulajdonságobjektumban. | [`data_source_type_for_values`](/slides/python-net/hu/aspose.slides.charts/chartdatapointcollection/data_source_type_for_values/) | Megadja, hogy az AsCell vagy az AsLiteralString vagy az AsLiteralDouble tulajdonság <br/>            ténylegesen jelen van az adatpontok Value tulajdonságobjektumban. Visszaadja a sorozat adatpontját az index alapján (a sorozat sorszáma ebben a gyűjteményben).
