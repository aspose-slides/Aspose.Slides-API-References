## IDataLabelFormat osztály

A DataLabel formázási beállításait reprezentálja.

Az IDataLabelFormat típus a következő tagokkal rendelkezik:

| Property | Description |
| :- | :- |

| [`number_format`](/slides/python-net/hu/aspose.slides.charts/idatalabelformat/number_format/) | A DataLabels objektum formátumkarakterláncát reprezentálja.<br/>            Olvasás/írás **str**. |
