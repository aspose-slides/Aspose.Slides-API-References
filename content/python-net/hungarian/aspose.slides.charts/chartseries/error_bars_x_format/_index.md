## error_bars_x_format tulajdonság
Az X irányú ErrorBars-t reprezentálja a sorozatoknál. 
            
            Az X irányú ErrorBars elérhető olyan sorozattípusoknál, mint area, bar, scatter és bubble. 
            Bármely más diagramtípus esetén ez a tulajdonság None értéket ad vissza (beleértve a 3D diagramokat is).
            Egyedi értékek esetén a DataPoints gyűjteményt kell használni az érték megadásához
            ([`IChartDataPoint.error_bars_custom_values`](/slides/python-net/hu/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) tulajdonsággal).
            
            Csak olvasható [`IErrorBarsFormat`](/slides/python-net/hu/aspose.slides.charts/ierrorbarsformat).
