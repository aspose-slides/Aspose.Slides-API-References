## MarkerStyleType enumeráció

Meghatározza a jelző formaját a diagram adatpontján.

A MarkerStyleType típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| NOT_DEFINED |  |
| CIRCLE | A körnek kell megjelenni minden adatpontnál. |
| DASH | A vonalnak kell megjelenni minden adatpontnál. |
| DIAMOND | A rombusznak kell megjelenni minden adatpontnál. |
| DOT | A pontnak kell megjelenni minden adatpontnál. |
| NONE | Semmit sem kell megjeleníteni minden adatpontnál. |
| PICTURE | A képet kell megjeleníteni minden adatpontnál. |
| PLUS | A plusz jelet kell megjeleníteni minden adatpontnál. |
| SQUARE | A négyzetet kell megjeleníteni minden adatpontnál. |
| STAR | A csillagot kell megjeleníteni minden adatpontnál. |
| TRIANGLE | A háromszöget kell megjeleníteni minden adatpontnál. |
| X | Az X-et kell megjeleníteni minden adatpontnál. |
