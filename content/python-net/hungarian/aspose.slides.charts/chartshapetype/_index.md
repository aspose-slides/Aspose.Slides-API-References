## ChartShapeType felsorolás

A diagram alakzatát reprezentálja.

A ChartShapeType típus a következő tagokat biztosítja:

## Mezők

| Mező | Leírás |
| :- | :- |
| NOT_DEFINED | Diagram alakzata nincs meghatározva. |
| BOX | Megadja, hogy a diagram doboz alakzattal legyen megrajzolva. |
| CONE | Megadja, hogy a diagram kúp alakban legyen megrajzolva, a kúp alapja a padlón legyen, a kúp csúcsa az adatjelző tetején. |
| CONE_TO_MAX | Megadja, hogy a diagram csonkított kúpokkal legyen megrajzolva úgy, hogy a kúp csúcsa a legnagyobb adatérték legyen. |
| CYLINDER | Megadja, hogy a diagram hengerként legyen megrajzolva. |
| PYRAMID | Megadja, hogy a diagram téglalap alakú piramisként legyen megrajzolva, a piramis alapja a padlón legyen, a piramis csúcsa az adatjelző tetején. |
| PYRAMID_TO_MAXIMUM | Megadja, hogy a diagram csonkított piramisokkal legyen megrajzolva úgy, hogy a piramis csúcsa a legnagyobb adatérték legyen. |
