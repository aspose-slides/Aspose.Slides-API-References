## ChartPlotArea osztály

A diagramhoz megjelenítendő téglalapot reprezentálja.

A ChartPlotArea típus a következő tagokat teszi elérhetővé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`format`](/slides/python-net/hu/aspose.slides.charts/chartplotarea/format/) | Visszaadja a plot terület formátumát.<br/>            Csak olvasható [`IFormat`](/slides/python-net/hu/aspose.slides.charts/iformat). |
| [`x`](/slides/python-net/hu/aspose.slides.charts/chartplotarea/x/) | Visszaadja vagy beállítja a plot terület körülhatároló négyzetének bal felső sarkának x koordinátáját a diagram szélességének arányában (0 és 1 között).<br/>            Olvasható/írható **float**. |
| [`y`](/slides/python-net/hu/aspose.slides.charts/chartplotarea/y/) | Visszaadja vagy beállítja a plot terület körülhatároló négyzetének bal felső sarkának y koordinátáját a diagram magasságának arányában (0 és 1 között).<br/>            Olvasható/írható **float**. |
| [`width`](/slides/python-net/hu/aspose.slides.charts/chartplotarea/width/) | Visszaadja vagy beállítja a plot terület körülhatároló négyzetének szélességét a diagram szélességének arányában (0 és 1 között).<br/>            Olvasható/írható **float**. |
| [`height`](/slides/python-net/hu/aspose.slides.charts/chartplotarea/height/) | Visszaadja vagy beállítja a plot terület körülhatároló négyzetének magasságát a diagram magasságának arányában (0 és 1 között).<br/>            Olvasható/írható **float**. |
| [`right`](/slides/python-net/hu/aspose.slides.charts/chartplotarea/right/) | Jobb.<br/>            Csak olvasható **float**. |
| [`bottom`](/slides/python-net/hu/aspose.slides.charts/chartplotarea/bottom/) | Alsó.<br/>            Csak olvasható **float**. |
| [`chart`](/slides/python-net/hu/aspose.slides.charts/chartplotarea/chart/) | Diagram.<br/>            Csak olvasható [`IChart`](/slides/python-net/hu/aspose.slides.charts/ichart). |
| [`is_location_autocalculated`](/slides/python-net/hu/aspose.slides.charts/chartplotarea/is_location_autocalculated/) | Meghatározza, hogyan kell kiszámítani a helyzetet: true – automatikusan számítva; az X, Y, Width, Height tulajdonságok által definiálva.<br/>            Csak olvasható **bool**. |
| [`layout_target_type`](/slides/python-net/hu/aspose.slides.charts/chartplotarea/layout_target_type/) | Ha a plot terület elrendezése manuálisan van megadva, ez a tulajdonság határozza meg, hogy a plot területet a belső (tengelyek és tengelycímkék nélkül) vagy a külső (tengelyek és tengelycímkék beleértve) rész alapján rendezzék-e el.<br/>            Olvasható/írható [`ChartPlotArea.layout_target_type`](/slides/python-net/hu/aspose.slides.charts/chartplotarea/layout_target_type). |
| [`actual_x`](/slides/python-net/hu/aspose.slides.charts/chartplotarea/actual_x/) | Megadja a diagram elem tényleges x helyzetét (bal) a diagram bal felső sarkához viszonyítva.<br/>            Hívja meg az IChart.ValidateChartLayout() metódust a tényleges értékek lekéréséhez.<br/>            Olvasható **float**. |
| [`actual_y`](/slides/python-net/hu/aspose.slides.charts/chartplotarea/actual_y/) | Megadja a diagram elem tényleges felső részét a diagram bal felső sarkához viszonyítva.<br/>            Hívja meg az IChart.ValidateChartLayout() metódust a tényleges értékek lekéréséhez.<br/>            Olvasható **float**. |
| [`actual_width`](/slides/python-net/hu/aspose.slides.charts/chartplotarea/actual_width/) | Megadja a diagram elem tényleges szélességét. Hívja meg az IChart.ValidateChartLayout() metódust a tényleges értékek lekéréséhez.<br/>            Olvasható **float**. |
| [`actual_height`](/slides/python-net/hu/aspose.slides.charts/chartplotarea/actual_height/) | Megadja a diagram elem tényleges magasságát. Hívja meg az IChart.ValidateChartLayout() metódust a tényleges értékek lekéréséhez.<br/>            Olvasható **float**. |
