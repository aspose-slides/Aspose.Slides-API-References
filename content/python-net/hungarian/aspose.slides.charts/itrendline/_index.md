## ITrendline osztály

Az osztály a diagram sorozat trendvonalát képviseli

Az ITrendline típus a következő tagokat biztosítja:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`trendline_name`](/slides/python-net/hu/aspose.slides.charts/itrendline/trendline_name/) | A trendvonal nevét adja vissza vagy állítja be.<br/>            Olvasás/írás **str**. |
| [`trendline_type`](/slides/python-net/hu/aspose.slides.charts/itrendline/trendline_type/) | A trendvonal típusát adja vissza vagy állítja be.<br/>            Olvasás/írás [`ITrendline.trendline_type`](/slides/python-net/hu/aspose.slides.charts/itrendline/trendline_type). |
| [`format`](/slides/python-net/hu/aspose.slides.charts/itrendline/format/) | A trendvonal formátumát képviseli.<br/>            Olvasás/írás [`IFormat`](/slides/python-net/hu/aspose.slides.charts/iformat). |
| [`backward`](/slides/python-net/hu/aspose.slides.charts/itrendline/backward/) | Megadja a kategóriák (vagy pontdiagramon a mértékegységek) számát, amelyet a trendvonal a trendelt sorozat adatai előtt kiterjeszt.<br/>            Szórt és nem szórt diagramoknál az érték bármely nemnegatív érték lehet.<br/>            Olvasás/írás **float**. |
| [`forward`](/slides/python-net/hu/aspose.slides.charts/itrendline/forward/) | Megadja a kategóriák (vagy pontdiagramon a mértékegységek) számát, amelyet a trendvonal a trendelt sorozat adatai után kiterjeszt.<br/>            Szórt és nem szórt diagramoknál az érték bármely nem negatív érték lehet.<br/>            Olvasás/írás **float**. |
| [`intercept`](/slides/python-net/hu/aspose.slides.charts/itrendline/intercept/) | Megadja azt az értéket, ahol a trendvonal áthalad az y tengelyen. Ez a tulajdonság csak akkor támogatott, ha a trendvonal típusa exp, lineáris vagy polinomiális.<br/>            Olvasás/írás **float**. |
| [`display_equation`](/slides/python-net/hu/aspose.slides.charts/itrendline/display_equation/) | Megadja, hogy a trendvonal egyenlete megjelenik a diagramon (ugyanabban a feliratban, mint az Rsquaredvalue).<br/>            Olvasás/írás **bool**. |
| [`order`](/slides/python-net/hu/aspose.slides.charts/itrendline/order/) | Megadja a polinomiális trendvonal rendjét. Más trendvonal típusoknál figyelmen kívül marad. Az értéknek 2 és 6 között kell lennie.<br/>            Olvasás/írás **int**. |
| [`period`](/slides/python-net/hu/aspose.slides.charts/itrendline/period/) | Megadja a mozgó átlag trendvonal periódusát. Más trendvonal változatoknál figyelmen kívül marad. Az értéknek 2 és 255 között kell lennie.<br/>            Olvasás/írás **int**. |
| [`display_r_squared_value`](/slides/python-net/hu/aspose.slides.charts/itrendline/display_r_squared_value/) | Megadja, hogy a trendvonal R-négyzet értéke megjelenik a diagramon (ugyanabban a feliratban, mint az egyenlet).<br/>            Olvasás/írás **bool**. |
| [`related_legend_entry`](/slides/python-net/hu/aspose.slides.charts/itrendline/related_legend_entry/) | A legendában megjelenő bejegyzést jelöli, amely ehhez a trendvonalhoz kapcsolódik<br/>            Csak olvasható [`ILegendEntryProperties`](/slides/python-net/hu/aspose.slides.charts/ilegendentryproperties). |
| [`text_frame_for_overriding`](/slides/python-net/hu/aspose.slides.charts/itrendline/text_frame_for_overriding/) |  |
| [`text_format`](/slides/python-net/hu/aspose.slides.charts/itrendline/text_format/) |  |
| [`chart`](/slides/python-net/hu/aspose.slides.charts/itrendline/chart/) |  |
