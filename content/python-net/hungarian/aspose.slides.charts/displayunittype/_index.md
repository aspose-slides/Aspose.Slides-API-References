## DisplayUnitType enumeráció

Meghatározza a megjelenített adatok szorzatosságát.

A DisplayUnitType típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| NONE | Az értékek változatlanul jelennek meg. |
| HUNDREDS | Megadja, hogy a diagram értékei 100-rel legyenek osztva. |
| THOUSANDS | Megadja, hogy a diagram értékei 1000-rel legyenek osztva. |
| TEN_THOUSANDS | Megadja, hogy a diagram értékei 10000-rel legyenek osztva. |
| HUNDRED_THOUSANDS | Megadja, hogy a diagram értékei 100000-rel legyenek osztva. |
| MILLIONS | Megadja, hogy a diagram értékei 1000000-rel legyenek osztva. |
| TEN_MILLIONS | Megadja, hogy a diagram értékei 10000000-rel legyenek osztva. |
| HUNDRED_MILLIONS | Megadja, hogy a diagram értékei 100000000-rel legyenek osztva. |
| BILLIONS | Megadja, hogy a diagram értékei 1000000000-rel legyenek osztva. |
| TRILLIONS | Megadja, hogy a diagram értékei 1000000000000-rel legyenek osztva. |
| CUSTOM_VALUE | Megadja, hogy a diagram értékei egy egyedi értékkel legyenek osztva. |
