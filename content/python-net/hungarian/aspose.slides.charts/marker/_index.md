## Marker osztály

A chert jelölőjét képviseli.

A Marker típus a következő tagokat tartalmazza:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`symbol`](/slides/python-net/hu/aspose.slides.charts/marker/symbol/) | Képviseli a jelzőstílust egy vonaldiagramon, szórásdiagramon vagy radar diagramon.<br/>            Olvasás/írás [`MarkerStyleType`](/slides/python-net/hu/aspose.slides.charts/markerstyletype). |
| [`format`](/slides/python-net/hu/aspose.slides.charts/marker/format/) | Megkapja vagy beállítja a jelző kitöltését.<br/>            Csak olvasás [`IFormat`](/slides/python-net/hu/aspose.slides.charts/iformat). |
| [`size`](/slides/python-net/hu/aspose.slides.charts/marker/size/) | Képviseli a jelző méretét egy vonaldiagramon, szórásdiagramon vagy radar diagramon.<br/>            Olvasás/írás **int**. |
