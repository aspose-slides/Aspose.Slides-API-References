## text_frame_for_overriding tulajdonság
Tartalmazhat gazdag formázott szöveget. If this tulajdonság is not None then this 
            formázott szöveges érték felülírja az adatok címkéjének automatikusan generált szövegét.
            Az adatok címkéjének automatikusan generált szöveg olyan szöveget jelent, amelyet a ShowSeriesName, 
            ShowValue, … tulajdonságok és a TextFormatManager.TextFormat tulajdonság formáz.
            Csak olvasható [`ITextFrame`](/slides/python-net/hu/aspose.slides/itextframe).
