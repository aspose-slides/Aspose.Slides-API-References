## IErrorBarsFormat osztály

A diagram sorozat hibasávjait képviseli. Az ErrorBars egyedi értékei az IChartDataPointCollection-ben találhatók (a [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/hu/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) tulajdonságban).

Az IErrorBarsFormat típus a következő tagokat tartalmazza:

## Tulajdonságok

| Property | Description |
| :- | :- |
| [`type`](/slides/python-net/hu/aspose.slides.charts/ierrorbarsformat/type/) | A hibasáv típusának lekérdezése vagy beállítása. <br/>            Olvasás/írás [`ErrorBarType`](/slides/python-net/hu/aspose.slides.charts/errorbartype). |
| [`value_type`](/slides/python-net/hu/aspose.slides.charts/ierrorbarsformat/value_type/) | A hibasáv hosszanak meghatározásának lehetséges módjait képviseli. <br/>            Egyéni értéktípus esetén az érték megadásához használja a [`IChartDataPoint.error_bars_custom_values`](/slides/python-net/hu/aspose.slides.charts/ichartdatapoint/error_bars_custom_values) tulajdonságot a sorozat DataPoints gyűjteményének adott adatpontjában.  <br/>            Olvasás/írás [`ErrorBarValueType`](/slides/python-net/hu/aspose.slides.charts/errorbarvaluetype). |
| [`has_end_cap`](/slides/python-net/hu/aspose.slides.charts/ierrorbarsformat/has_end_cap/) | Megadja, hogy az end cap nem kerül kirajzolásra a hibasávokon.<br/>            Olvasás/írás **bool**. |
| [`value`](/slides/python-net/hu/aspose.slides.charts/ierrorbarsformat/value/) | Lekérdezi vagy beállítja azt az értéket, amelyet a Fixed, Percentage és StandardDeviation értéktípusokkal használnak a hibasávok hosszának meghatározásához. <br/>            Olvasás/írás **float**. |
| [`format`](/slides/python-net/hu/aspose.slides.charts/ierrorbarsformat/format/) | A hibasávok formátumát képviseli.<br/>            Olvasás/írás [`IFormat`](/slides/python-net/hu/aspose.slides.charts/iformat). |
| [`is_visible`](/slides/python-net/hu/aspose.slides.charts/ierrorbarsformat/is_visible/) | A hibasávok láthatóságának lekérdezése vagy beállítása.<br/>            Olvasás/írás **bool**. |
