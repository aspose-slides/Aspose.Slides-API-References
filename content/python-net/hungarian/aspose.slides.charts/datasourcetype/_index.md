## DataSourceType enumeráció

Adatforrás típusok.

A DataSourceType típus a következő tagokat teszi elérhetővé:

## Mezők

| Mező | Leírás |
| :- | :- |
| WORKSHEET | Használja a CellXls objektumokat az XValue, YValue, Value vagy BubbleSize tárolásához a munkalapon. |
| STRING_LITERALS | Használjon gyors hozzáférésű karakterlánc változót az XValue, YValue, Value vagy BubbleSize tárolására az <br/>            adatpontnál. A munkalap NEM használatos az értékek tárolására. |
| DOUBLE_LITERALS | Használjon gyors hozzáférésű double változót az XValue, YValue, Value vagy BubbleSize tárolására az <br/>            adatpontnál. A munkalap NEM használatos az értékek tárolására. |
