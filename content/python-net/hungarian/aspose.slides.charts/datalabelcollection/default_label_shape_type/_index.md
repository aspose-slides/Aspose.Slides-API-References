## default_label_shape_type tulajdonság
Lekéri vagy beállítja az adatcímkék alapértelmezett alakzat típusát.  
Visszaadja [`ShapeType.NOT_DEFINED`](/slides/python-net/hu/aspose.slides/shapetype/NOT_DEFINED) értéket, ha nincs alakzat definiálva.


### Megjegyzések
