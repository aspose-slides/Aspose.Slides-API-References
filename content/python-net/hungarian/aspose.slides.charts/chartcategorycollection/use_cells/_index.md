## use_cells tulajdonság
If true then worksheet is used for storing categories (this case supports a multi-level categories).
            Ha hamis, akkor a munkalapot NEM használják az értékek tárolására (és ez az eset nem támogatja a 
            több szintű kategóriákat).
            Olvasás/írás **bool**.
