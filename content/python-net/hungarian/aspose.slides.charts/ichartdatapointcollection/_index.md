## IChartDataPointCollection osztály

A sorozat adatpontjainak gyűjteményét képviseli.

Az IChartDataPointCollection típus a következő tagokat teszi közzé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`data_source_type_for_x_values`](/slides/python-net/hu/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_x_values/) | Meghatározza, hogy az AsCell vagy AsLiteralString vagy AsLiteralDouble tulajdonság valóban szerepel-e az adatpontok XValue tulajdonságobjektumában. <br/>            Más szóval meghatározza a ChartDataPointEx.XValue.Data tulajdonság értékének típusát. <br/>            Olvasás/írás [`DataSourceType`](/slides/python-net/hu/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_y_values`](/slides/python-net/hu/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_y_values/) | Meghatározza, hogy az AsCell vagy AsLiteralString vagy AsLiteralDouble tulajdonság valóban szerepel-e az adatpontok YValue tulajdonságobjektumában. <br/>            Más szóval meghatározza a ChartDataPointEx.YValue.Data tulajdonság értékének típusát. <br/>            Olvasás/írás [`DataSourceType`](/slides/python-net/hu/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_bubble_sizes`](/slides/python-net/hu/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_bubble_sizes/) | Meghatározza, hogy az AsCell vagy AsLiteralString vagy AsLiteralDouble tulajdonság valóban szerepel-e az adatpontok BubbleSize tulajdonságobjektumában. <br/>            Más szóval meghatározza a ChartDataPointEx.BubbleSize.Data tulajdonság értékének típusát. <br/>            Olvasás/írás [`DataSourceType`](/slides/python-net/hu/aspose.slides.charts/datasourcetype). |
| [`data_source_type_for_values`](/slides/python-net/hu/aspose.slides.charts/ichartdatapointcollection/data_source_type_for_values/) | Meghatározza, hogy az AsCell vagy AsLiteralString vagy AsLiteralDouble tulajdonság valóban szerepel-e az adatpontok Value tulajdonságobjektumában. <br/>            Más szóval meghatározza a ChartDataPoint.Value.Data tulajdonság értékének típusát. <br/>            Olvasás/írás [`DataSourceType`](/slides/python-net/hu/aspose.slides.charts/datasourcetype). |
