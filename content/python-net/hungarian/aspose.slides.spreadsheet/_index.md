Osztályokat tartalmaz a Microsoft PowerPoint prezentációkban a táblázatobjektumokkal való munkához.

## Osztályok

| Osztály | Leírás |
| :- | :- |
| [`CellCircularReferenceException`](/slides/python-net/hu/aspose.slides.spreadsheet/cellcircularreferenceexception/) | Az a kivétel, amely akkor kerül dobásra, amikor egy vagy több körkörös hivatkozás kerül észlelésre, ahol a képlet a saját cellájára hivatkozik<br/>            közvetlenül vagy közvetve. |
| [`CellInvalidFormulaException`](/slides/python-net/hu/aspose.slides.spreadsheet/cellinvalidformulaexception/) | Az a kivétel, amely akkor kerül dobásra, amikor egy kiszámított képlet helytelen vagy nem lett értelmezve. |
| [`CellInvalidReferenceException`](/slides/python-net/hu/aspose.slides.spreadsheet/cellinvalidreferenceexception/) | Az a kivétel, amely akkor kerül dobásra, amikor egy érvénytelen cellahivatkozás merül fel. |
| [`CellUnsupportedDataException`](/slides/python-net/hu/aspose.slides.spreadsheet/cellunsupporteddataexception/) | Az a kivétel, amely akkor kerül dobásra, amikor egy nem támogatott adatot találnak egy táblázatcellában. |
