## WarningType enumeráció

Egy figyelmeztetéstípus reprezentálása.

A WarningType típus a következő elemeket teszi elérhetővé:

## Mezők

| Mező | Leírás |
| :- | :- |
| SOURCE_FILE_CORRUPTION | A forrásdokumentumban egy probléma lett észlelve, amely miatt nagyon valószínű, hogy a dokumentum nem lesz megnyitható, ha az eredeti formátumban van mentve. |
| DATA_LOSS | A szöveg/grafikon/kép vagy egyéb adatok teljesen hiányozni fognak a dokumentumfa betöltése után, vagy a mentés után a létrehozott dokumentumból. |
| MAJOR_FORMATTING_LOSS | Jelentős formázásveszteség. |
| MINOR_FORMATTING_LOSS | Kisebb formázásveszteség. |
| COMPATIBILITY_ISSUE | Ez egy ismert probléma, amely megakadályozza a dokumentum megnyitását bizonyos felhasználói ügynökök vagy korábbi verziók esetén. |
| UNEXPECTED_CONTENT | A forrásdokumentum egyes tartalmai nem ismerhetők fel (azaz nem támogatottak), ez esetleg problémákat okozhat vagy adat-/formázásveszteséghez vezethet. |
