## z_order_position tulajdonság
Visszaadja az alakzat pozícióját a z-orderben.
            Shapes[0] visszaadja azt az alakzatot, amely a z-order hátulján van,
            és Shapes[Shapes.Count - 1] visszaadja azt az alakzatot, amely a z-order elöl található.
            Csak olvasható **int**.
