## width tulajdonság
A shape width értékét adja vissza vagy állítja be, pontban mérve.
Olvasás/írás **float**.

### Megjegyzések

A visszaadott érték mindig definiált, és soha nem **float**.
A hozzárendelt értéknek is definiáltnak kell lennie; **float** csak a `RawFrame` példány tulajdonságaira rendelhető.
