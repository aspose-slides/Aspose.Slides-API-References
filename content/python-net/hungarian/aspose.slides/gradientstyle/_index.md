## GradientStyle enumeráció

Képviseli a rendelkezésre álló színátmenet stílusokat.

A GradientStyle típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| DEFAULT | Az alapértelmezett színátmenet stílus. |
| POWER_POINT_UI | A színátmenet stílus, ahogy a PowerPoint felhasználói felületén megjelenik. |
