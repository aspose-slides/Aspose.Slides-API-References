## ICustomXmlPart osztály

Egy egyéni XML részt képvisel.

Az ICustomXmlPart típus a következő tagokat teszi elérhetővé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`xml_as_string`](/slides/python-net/hu/aspose.slides/icustomxmlpart/xml_as_string/) | XML adatot ad vissza vagy állít be UTF-8 karakterláncként.<br/>            Olvasás/írás **str**.<br/>            az érték `None`. az érték üres vagy az xml-adat érvénytelen. |
| [`xml_data`](/slides/python-net/hu/aspose.slides/icustomxmlpart/xml_data/) | XML adatot ad vissza vagy állít be.<br/>            Olvasás/írás **int**[].<br/>            az érték `None`. az érték üres vagy az xml-adat érvénytelen. |
| [`item_id`](/slides/python-net/hu/aspose.slides/icustomxmlpart/item_id/) | Megad egy globálisan egyedi azonosítót (GUID), amely egyetlen egyedi XML <br/>            részt azonosít egy Office Open XML dokumentumban.<br/>            Csak olvasható **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/hu/aspose.slides/icustomxmlpart/namespace_schemas/) | Visszaadja a gyűjtemény XML séma(ka)t, amelyek a saját XML részhez kapcsolódnak.<br/>            Csak olvasható **str**[]. |
