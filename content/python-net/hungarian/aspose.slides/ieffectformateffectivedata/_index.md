## IEffectFormatEffectiveData osztály

Megváltoztathatatlan objektum, amely tartalmazza a hatásformázás hatékony tulajdonságait.

Az IEffectFormatEffectiveData típus a következő tagokat tartalmazza:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`is_no_effects`](/slides/python-net/hu/aspose.slides/ieffectformateffectivedata/is_no_effects/) | Igaz értéket ad, ha minden hatás le van tiltva (úgy, ahogy a frissen létrehozott, alapértelmezett EffectFormat objektum).<br/>            Csak olvasható **bool**. |
| [`blur_effect`](/slides/python-net/hu/aspose.slides/ieffectformateffectivedata/blur_effect/) | Elmosódás hatás.<br/>            Csak olvasható [`IBlurEffectiveData`](/slides/python-net/hu/aspose.slides.effects/iblureffectivedata). |
| [`fill_overlay_effect`](/slides/python-net/hu/aspose.slides/ieffectformateffectivedata/fill_overlay_effect/) | Kitöltés felülhelyezési hatás.<br/>            Csak olvasható [`IFillOverlayEffectiveData`](/slides/python-net/hu/aspose.slides.effects/ifilloverlayeffectivedata). |
| [`glow_effect`](/slides/python-net/hu/aspose.slides/ieffectformateffectivedata/glow_effect/) | Ragyogó hatás.<br/>            Csak olvasható [`IGlowEffectiveData`](/slides/python-net/hu/aspose.slides.effects/igloweffectivedata). |
| [`inner_shadow_effect`](/slides/python-net/hu/aspose.slides/ieffectformateffectivedata/inner_shadow_effect/) | Belső árnyék.<br/>            Csak olvasható [`IInnerShadowEffectiveData`](/slides/python-net/hu/aspose.slides.effects/iinnershadoweffectivedata). |
