## ISensitivityLabel osztály

Képviseli a Microsoft Purview Information Protection szenzitivitási címkét.

Az ISensitivityLabel típus a következő tagokat teszi elérhetővé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`id`](/slides/python-net/hu/aspose.slides/isensitivitylabel/id/) | Visszaadja vagy beállítja a szenzitivitási címke azonosítóját.<br/>            Read/write **str**. |
| [`site_id`](/slides/python-net/hu/aspose.slides/isensitivitylabel/site_id/) | Visszaadja vagy beállítja az Azure Active Directory (Azure AD) webhelyazonosítót <br/>            amely a szenzitivitási címkét leíró szenzitivitási címke szabályzathoz tartozik.<br/>            Read/write **System.Guid**. |
| [`is_enabled`](/slides/python-net/hu/aspose.slides/isensitivitylabel/is_enabled/) | Jelzi, hogy a szenzitivitási címke engedélyezve van-e. |
| [`is_removed`](/slides/python-net/hu/aspose.slides/isensitivitylabel/is_removed/) | Jelzi, hogy a szenzitivitási címke el lett-e távolítva. |
| [`assignment_method_type`](/slides/python-net/hu/aspose.slides/isensitivitylabel/assignment_method_type/) | Visszaadja vagy beállítja a szenzitivitási címke hozzárendelési módját.<br/>            Read/write [`SensitivityLabelAssignmentType`](/slides/python-net/hu/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/hu/aspose.slides/isensitivitylabel/content_mark_types/) | Visszaadja azoknak a tartalomjelölési típusoknak a listáját, amelyeket egy fájlra alkalmazni kell. |
