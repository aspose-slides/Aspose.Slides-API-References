## PictureFrameLock osztály

Megállapítja, hogy mely műveletek vannak letiltva a szülő PictureFrame-en.

**Öröklődés:**[`PictureFrameLock`](/slides/python-net/hu/aspose.slides/pictureframelock) → [`BaseShapeLock`](/slides/python-net/hu/aspose.slides/baseshapelock)

A PictureFrameLock típus a következő tagokat teszi elérhetővé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`no_locks`](/slides/python-net/hu/aspose.slides/pictureframelock/no_locks/) | True értéket ad vissza, ha az összes lock-flags le van tiltva.<br/>            Csak olvasható **bool**. |
| [`grouping_locked`](/slides/python-net/hu/aspose.slides/pictureframelock/grouping_locked/) | Megállapítja, hogy a forma csoportba való hozzáadása tiltott-e.<br/>            Olvasás/írás **bool**. |
| [`select_locked`](/slides/python-net/hu/aspose.slides/pictureframelock/select_locked/) | Megállapítja, hogy a forma kiválasztása tiltott-e.<br/>            Olvasás/írás **bool**. |
| [`rotation_locked`](/slides/python-net/hu/aspose.slides/pictureframelock/rotation_locked/) | Megállapítja, hogy a forma forgatási szögének módosítása tiltott-e.<br/>            Olvasás/írás **bool**. |
| [`aspect_ratio_locked`](/slides/python-net/hu/aspose.slides/pictureframelock/aspect_ratio_locked/) | Megállapítja, hogy a formának meg kell őriznie az oldalarányt átméretezéskor.<br/>            Olvasás/írás **bool**. |
| [`position_locked`](/slides/python-net/hu/aspose.slides/pictureframelock/position_locked/) | Megállapítja, hogy a forma mozgatása tiltott-e.<br/>            Olvasás/írás **bool**. |
| [`size_locked`](/slides/python-net/hu/aspose.slides/pictureframelock/size_locked/) | Megállapítja, hogy a forma átméretezése tiltott-e.<br/>            Olvasás/írás **bool**. |
| [`edit_points_locked`](/slides/python-net/hu/aspose.slides/pictureframelock/edit_points_locked/) | Megállapítja, hogy a forma körvonalának közvetlen módosítása tiltott-e.<br/>            Olvasás/írás **bool**. |
| [`adjust_handles_locked`](/slides/python-net/hu/aspose.slides/pictureframelock/adjust_handles_locked/) | Megállapítja, hogy a beállítási értékek módosítása tiltott-e.<br/>            Olvasás/írás **bool**. |
| [`arrowheads_locked`](/slides/python-net/hu/aspose.slides/pictureframelock/arrowheads_locked/) | Megállapítja, hogy a nyílfejek módosítása tiltott-e.<br/>            Olvasás/írás **bool**. |
| [`shape_type_locked`](/slides/python-net/hu/aspose.slides/pictureframelock/shape_type_locked/) | Megállapítja, hogy a forma típusának módosítása tiltott-e.<br/>            Olvasás/írás **bool**. |
| [`crop_locked`](/slides/python-net/hu/aspose.slides/pictureframelock/crop_locked/) | Megállapítja, hogy a kép vágása tiltott-e.<br/>            Olvasás/írás **bool**. |
