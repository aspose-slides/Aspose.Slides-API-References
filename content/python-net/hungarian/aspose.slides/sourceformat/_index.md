## SourceFormat enumeráció

A forrásfájl formátumát reprezentálja.

A SourceFormat típus a következő tagokat teszi közzé:

## Mezők

| Mező | Leírás |
| :- | :- |
| PPT | Microsoft PowerPoint 97-2003 bemutató (*.ppt). |
| PPTX | Microsoft Office Open XML bemutató (*.pptx). |
| ODP | OpenDocument bemutató (*.odp). |
| PPTM | Microsoft Office Open XML makróval ellátott bemutató (*.pptm). |
| PPSX | Microsoft Office Open XML diavetítés (*.ppsx). |
| PPSM | Microsoft Office Open XML makróval ellátott diavetítés (*.ppsm). |
| POTX | Microsoft Office Open XML sablon (*.potx). |
| POTM | Microsoft Office Open XML makróval ellátott sablon (*.potm). |
| PPS | Microsoft PowerPoint 97-2003 diavetítés (*.pps). |
| POT | Microsoft PowerPoint 97-2003 sablon (*.pot). |
| OTP | OpenDocument bemutató sablon (*.otp). |
| FODP | Flat XML ODF bemutató (*.fodp). |
| XML | PowerPoint XML bemutató (*.xml). |
