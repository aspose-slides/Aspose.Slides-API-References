# IShapeStyle osztály

A forma stílusreferenciáját reprezentálja.

Az IShapeStyle típus a következő tagokat teszi közzé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`line_color`](/slides/python-net/hu/aspose.slides/ishapestyle/line_color/) | Visszaadja a forma körvonal színét.<br/>            Csak olvasható [`IColorFormat`](/slides/python-net/hu/aspose.slides/icolorformat). |
| [`line_style_index`](/slides/python-net/hu/aspose.slides/ishapestyle/line_style_index/) | Visszaadja vagy beállítja a vonal oszlopindexét egy stílusmátrixban.<br/>            Olvasás/írás **int**. |
| [`fill_color`](/slides/python-net/hu/aspose.slides/ishapestyle/fill_color/) | Visszaadja a forma kitöltési színét.<br/>            Csak olvasható [`IColorFormat`](/slides/python-net/hu/aspose.slides/icolorformat). |
| [`fill_style_index`](/slides/python-net/hu/aspose.slides/ishapestyle/fill_style_index/) | Visszaadja vagy beállítja a forma kitöltési oszlopindexét a stílusmátrixokban.<br/>            0 jelentése nincs kitöltés,<br/>            pozitív érték – index a téma kitöltési stílusaiban,<br/>            negatív érték – index a téma háttérstílusaiban.<br/>            Olvasás/írás **int**. |
| [`effect_color`](/slides/python-net/hu/aspose.slides/ishapestyle/effect_color/) | Visszaadja a forma effektus színét.<br/>            Csak olvasható [`IColorFormat`](/slides/python-net/hu/aspose.slides/icolorformat). |
| [`effect_style_index`](/slides/python-net/hu/aspose.slides/ishapestyle/effect_style_index/) | Visszaadja vagy beállítja a forma effektus oszlopindexét egy stílusmátrixban.<br/>            Olvasás/írás **int**. |
| [`font_color`](/slides/python-net/hu/aspose.slides/ishapestyle/font_color/) | Visszaadja a forma betűszínét.<br/>            Csak olvasható [`IColorFormat`](/slides/python-net/hu/aspose.slides/icolorformat). |
| [`font_collection_index`](/slides/python-net/hu/aspose.slides/ishapestyle/font_collection_index/) | Visszaadja vagy beállítja a forma betűtípus-indexét egy betűtípus-gyűjteményben.<br/>            Olvasás/írás [`FontCollectionIndex`](/slides/python-net/hu/aspose.slides/fontcollectionindex). |
