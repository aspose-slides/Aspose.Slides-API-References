## ControlPropertiesCollection osztály

Az ActiveX tulajdonságok gyűjteménye.

A ControlPropertiesCollection típus a következő tagokat teszi elérhetővé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`names_of_properties`](/slides/python-net/hu/aspose.slides/controlpropertiescollection/names_of_properties/) | Visszaadja a tulajdonságnevek gyűjteményét.<br/>            Írásvédett **list**. |
| [`count`](/slides/python-net/hu/aspose.slides/controlpropertiescollection/count/) | Visszaadja a gyűjteményben lévő tulajdonságok számát.<br/>            Írásvédett **int**. |

## Módszerek

| Módszer | Leírás |
| :- | :- |
| [`add(self, name, value)`](/slides/python-net/hu/aspose.slides/controlpropertiescollection/add/#str-str) | Hozzáad egy tulajdonságot a gyűjteményhez. |
| [`remove(self, name)`](/slides/python-net/hu/aspose.slides/controlpropertiescollection/remove/#str) | Eltávolít egy megadott névű tulajdonságot. |
