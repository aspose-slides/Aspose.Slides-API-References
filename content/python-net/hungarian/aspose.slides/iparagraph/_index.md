## IParagraph osztály

Egy szövegrész bekezdését reprezentálja.

Az IParagraph típus a következő tagokat teszi közzé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`portions`](/slides/python-net/hu/aspose.slides/iparagraph/portions/) | Visszaadja a szövegrészek gyűjteményét.<br/>            Csak olvasható [`IPortionCollection`](/slides/python-net/hu/aspose.slides/iportioncollection). |
| [`paragraph_format`](/slides/python-net/hu/aspose.slides/iparagraph/paragraph_format/) | Visszaadja a formázási objektumot ehhez a bekezdéshez.<br/>            Csak olvasható [`IParagraphFormat`](/slides/python-net/hu/aspose.slides/iparagraphformat). |
| [`text`](/slides/python-net/hu/aspose.slides/iparagraph/text/) | Lekéri vagy beállítja a bekezdés egyszerű szövegét.<br/>            Olvasás/írás **str**. |
| [`end_paragraph_portion_format`](/slides/python-net/hu/aspose.slides/iparagraph/end_paragraph_portion_format/) | Megadja a résztulajdonságokat, amelyeket akkor kell használni, ha egy újabb rész kerül beszúrásra az utolsó után. |
| [`slide`](/slides/python-net/hu/aspose.slides/iparagraph/slide/) |  |
| [`presentation`](/slides/python-net/hu/aspose.slides/iparagraph/presentation/) |  |

| Módszer | Leírás |
