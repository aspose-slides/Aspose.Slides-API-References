## SensitivityLabel osztály

A Microsoft Purview Information Protection által biztosított érzékenységi címkét képviseli.

A SensitivityLabel típus a következő tagokat teszi elérhetővé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`id`](/slides/python-net/hu/aspose.slides/sensitivitylabel/id/) | Visszaadja vagy beállítja az érzékenységi címke azonosítóját.<br/>            Olvasás/írás **str**. |
| [`site_id`](/slides/python-net/hu/aspose.slides/sensitivitylabel/site_id/) | Visszaadja vagy beállítja az Azure Active Directory (Azure AD) webhely-azonosítót <br/>            amely a érzékenységi címkét leíró érzékenységi címke politika szerint van.<br/>            Olvasás/írás **System.Guid**. |
| [`is_enabled`](/slides/python-net/hu/aspose.slides/sensitivitylabel/is_enabled/) | Megadja, hogy a érzékenységi címke engedélyezett-e. |
| [`is_removed`](/slides/python-net/hu/aspose.slides/sensitivitylabel/is_removed/) | Megadja, hogy a érzékenységi címke eltávolításra került-e. |
| [`assignment_method_type`](/slides/python-net/hu/aspose.slides/sensitivitylabel/assignment_method_type/) | Visszaadja vagy beállítja a érzékenységi címke hozzárendelési módját.<br/>            Olvasás/írás [`SensitivityLabelAssignmentType`](/slides/python-net/hu/aspose.slides/sensitivitylabelassignmenttype). |
| [`content_mark_types`](/slides/python-net/hu/aspose.slides/sensitivitylabel/content_mark_types/) | Visszaadja a fájlra alkalmazandó tartalomjelölés típusainak listáját. |
