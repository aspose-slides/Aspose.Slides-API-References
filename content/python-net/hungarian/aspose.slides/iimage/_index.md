## IImage osztály

Egy raszter vagy vektorképet képvisel.

Az IImage típus a következő tagokat biztosítja:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`size`](/slides/python-net/hu/aspose.slides/iimage/size/) | Visszaadja a kép méretét. |
| [`width`](/slides/python-net/hu/aspose.slides/iimage/width/) | Visszaadja a kép szélességét pixelben. |
| [`height`](/slides/python-net/hu/aspose.slides/iimage/height/) | Visszaadja a kép magasságát pixelben. |

## Metódusok

| Metódus | Leírás |
| :- | :- |
| [`save(self, filename)`](/slides/python-net/hu/aspose.slides/iimage/save/#str) | Elmenti a képet egy fájlba. |
| [`save(self, filename, format)`](/slides/python-net/hu/aspose.slides/iimage/save/#str-imageformat) | Elmenti a képet egy fájlba a megadott formátumban. |
| [`save(self, stream, format)`](/slides/python-net/hu/aspose.slides/iimage/save/#iorawiobase-imageformat) | Elmenti a képet egy adatfolyamra a megadott formátumban. |
| [`save(self, filename, format, quality)`](/slides/python-net/hu/aspose.slides/iimage/save/#str-imageformat-int) | Elmenti a képet egy fájlba a megadott formátumban és minőségben. |
| [`save(self, stream, format, quality)`](/slides/python-net/hu/aspose.slides/iimage/save/#iorawiobase-imageformat-int) | Elmenti a képet egy adatfolyamra a megadott formátumban és minőségben. |


### Megjegyzések

Ez az interfész közös absztrakciót biztosít a raszter és vektorképek kezeléséhez.  
            A megvalósítások különbözhetnek a mögöttes képtípustól függően.
