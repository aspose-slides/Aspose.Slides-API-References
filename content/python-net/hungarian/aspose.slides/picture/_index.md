## Picture osztály

Egy képet képvisel egy prezentációban.

A Picture típus a következő tagokat teszi elérhetővé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`image`](/slides/python-net/hu/aspose.slides/picture/image/) | Visszaadja vagy beállítja a beágyazott képet.<br/>            Olvasás/írás [`IPPImage`](/slides/python-net/hu/aspose.slides/ippimage). |
| [`link_path_long`](/slides/python-net/hu/aspose.slides/picture/link_path_long/) | Visszaadja vagy beállítja a csatolt kép URL-jét.<br/>            Olvasás/írás **str**. |
| [`image_transform`](/slides/python-net/hu/aspose.slides/picture/image_transform/) | Visszaadja a kép transzformációs hatásainak gyűjteményét.<br/>            Csak olvasható [`IImageTransformOperationCollection`](/slides/python-net/hu/aspose.slides.effects/iimagetransformoperationcollection). |
| [`presentation`](/slides/python-net/hu/aspose.slides/picture/presentation/) | Visszaadja a prezentációt.<br/>            Csak olvasható [`IPresentation`](/slides/python-net/hu/aspose.slides/ipresentation). |
| [`slide`](/slides/python-net/hu/aspose.slides/picture/slide/) | Visszaadja a kép szülő diaját.<br/>            Csak olvasható [`IBaseSlide`](/slides/python-net/hu/aspose.slides/ibaseslide). |
