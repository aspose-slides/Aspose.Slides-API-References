## TextAutofitType enumeration

A szöveg automatikus illesztési módot képviseli.

A TextAutofitType típus a következő tagokat teszi elérhetővé:

## Mezők

| Mező | Leírás |
| :- | :- |
| NOT_DEFINED | Nincs meghatározva. |
| NONE | Nincs autofit. |
| NORMAL | Normál autofit. A betűméret és a sortávolság le lesz csökkentve, hogy illeszkedjen a formához. |
| SHAPE | Forma autofit. A forma mérete megváltozik, hogy illeszkedjen a szöveghez. |
