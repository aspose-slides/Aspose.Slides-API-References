## BlackWhiteMode enumeration

Meghatározza, hogyan kell a színes alakzatot fekete-fehérre átalakítani.

A BlackWhiteMode típus a következő tagokat teszi közzé:

## Mezők

| Mező | Leírás |
| :- | :- |
| NOT_DEFINED | A tulajdonság nincs beállítva |
| COLOR | Az objektum normál színezéssel jelenik meg |
| AUTOMATIC | Az objektum automatikus színezéssel jelenik meg |
| GRAY | Az objektum szürke színezéssel jelenik meg |
| LIGHT_GRAY | Az objektum világos szürke színezéssel jelenik meg |
| INVERSE_GRAY | Az objektum fordított szürke színezéssel jelenik meg |
| GRAY_WHITE | Az objektum szürke és fehér színezéssel jelenik meg |
| BLACK_GRAY | Az objektum fekete és szürke színezéssel jelenik meg |
| BLACK_WHITE | Az objektum fekete és fehér színezéssel jelenik meg |
| BLACK | Az objektum csak fekete színnel jelenik meg |
| WHITE | Az objektum fehér színezéssel jelenik meg |
| HIDDEN | Az objektum nem jelenik meg |
