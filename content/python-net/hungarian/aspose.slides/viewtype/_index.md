## ViewType felsorolás

Prezentáció nézet típusok

A ViewType típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| NOT_DEFINED | Az érték nincs definiálva |
| SLIDE_VIEW | Normál dia nézet |
| SLIDE_MASTER_VIEW | Dia minta nézet |
| NOTES_VIEW | Jegyzet nézet |
| HANDOUT_VIEW | Kéziszóró nézet |
| NOTES_MASTER_VIEW | Jegyzet minta nézet |
| OUTLINE_VIEW | Vázlat nézet |
| SLIDE_SORTER_VIEW | Dia rendező nézet |
| SLIDE_THUMBNAIL_VIEW | Dia bélyegkép nézet |
