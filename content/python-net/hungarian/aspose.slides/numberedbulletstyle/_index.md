## NumberedBulletStyle enumeráció

A számozott golyók stílusát reprezentálja.

A NumberedBulletStyle típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| NOT_DEFINED | Nincs definiálva. |
| BULLET_ALPHA_LC_PERIOD | Kisbetűs alfabetikus karakterek ponttal. Sample: a., b., c., ... |
| BULLET_ALPHA_UC_PERIOD | Nagybetűs alfabetikus karakterek ponttal. Sample: A., B., C., ... |
| BULLET_ARABIC_PAREN_RIGHT | Arab számjegyek záró zárójellel. Sample: 1), 2), 3), ... |
| BULLET_ARABIC_PERIOD | Arab számjegyek ponttal. Sample: 1., 2., 3., ... |
| BULLET_ROMAN_LC_PAREN_BOTH | Kis római számjegyek mindkét zárójelben. Sample: (i), (ii), (iii), ... |
| BULLET_ROMAN_LC_PAREN_RIGHT | Kis római számjegyek záró zárójellel. Sample: i), ii), iii), ... |
| BULLET_ROMAN_LC_PERIOD | Kis római számjegyek ponttal. Sample: i., ii., iii., ... |
| BULLET_ROMAN_UC_PERIOD | Nagy római számjegyek ponttal. Sample: I., II., III., ... |
| BULLET_ALPHA_LC_PAREN_BOTH | Kisbetűs alfabetikus karakterek mindkét zárójelben. Sample: (a), (b), (c), ... |
| BULLET_ALPHA_LC_PAREN_RIGHT | Kisbetűs alfabetikus karakterek záró zárójellel. Sample: a), b), c), ... |
| BULLET_ALPHA_UC_PAREN_BOTH | Nagybetűs alfabetikus karakterek mindkét zárójelben. Sample: (A), (B), (C), ... |
| BULLET_ALPHA_UC_PAREN_RIGHT | Nagybetűs alfabetikus karakterek záró zárójellel. Sample: A), B), C), ... |
| BULLET_ARABIC_PAREN_BOTH | Arab számjegyek mindkét zárójelben. Sample: (1), (2), (3), ... |
| BULLET_ARABIC_PLAIN | Arab számjegyek. Sample: 1, 2, 3, ... |
| BULLET_ROMAN_UC_PAREN_BOTH | Nagy római számjegyek mindkét zárójelben. Sample: (I), (II), (III), ... |
| BULLET_ROMAN_UC_PAREN_RIGHT | Nagy római számjegyek záró zárójellel. Sample: I), II), III), ... |
| BULLET_SIMP_CHIN_PLAIN | Egyszerűsített kínai írásjel pont nélkül. |
| BULLET_SIMP_CHIN_PERIOD | Egyszerűsített kínai írásjel ponttal. |
| BULLET_CIRCLE_NUM_DB_PLAIN | Kétszörös bájtú körbehúzott szám 10-ig, 11-től arab számjegyek. |
| BULLET_CIRCLE_NUM_WD_WHITE_PLAIN | Színezett szám, körrel ugyanabban a színben (Wingdings fehér kör számok). 11-től arab számjegyek. |
| BULLET_CIRCLE_NUM_WD_BLACK_PLAIN | Árnyékszínű szám körkörű háttérrel, normál szövegszínben (Wingdings fekete kör számok). |
| BULLET_TRAD_CHIN_PLAIN | Hagyományos kínai írásjel pont nélkül. |
| BULLET_TRAD_CHIN_PERIOD | Hagyományos kínai írásjel ponttal. |
| BULLET_ARABIC_ALPHA_DASH | Arab nyelvű alfabetikus karakterek kötőjellel. |
| BULLET_ARABIC_ABJAD_DASH | Arab Abjad ábécék kötőjellel. |
| BULLET_HEBREW_ALPHA_DASH | Héber nyelvű alfabetikus karakterek kötőjellel. |
| BULLET_KANJI_KOREAN_PLAIN | Japán/koreai számok pont nélkül. |
| BULLET_KANJI_KOREAN_PERIOD | Japán/koreai számok ponttal. |
| BULLET_ARABIC_DB_PLAIN | Kétszörös bájtú arab számozási rendszer (írásjel nélkül). |
| BULLET_ARABIC_DB_PERIOD | Kétszörös bájtú arab számozási rendszer kétszörös bájtú ponttal. |
| BULLET_THAI_ALPHA_PERIOD | Thai ábécé pont. |
| BULLET_THAI_ALPHA_PAREN_RIGHT | Thai ábécé zárójelek - jobb. |
| BULLET_THAI_ALPHA_PAREN_BOTH | Thai ábécé zárójelek - mindkettő. |
| BULLET_THAI_NUM_PERIOD | Thai számjegy pont. |
| BULLET_THAI_NUM_PAREN_RIGHT | Thai számjegy zárójelek - jobb. |
| BULLET_THAI_NUM_PAREN_BOTH | Thai számjegy zárójelek - mindkettő. |
| BULLET_HINDI_ALPHA_PERIOD | Hindi ábécé pont - magánhangzók. |
| BULLET_HINDI_NUM_PERIOD | Hindi számjegy pont. |
| BULLET_KANJI_SIMP_CHIN_DB_PERIOD | Kanji egyszerű kínai DBPeriod. |
| BULLET_HINDI_NUM_PAREN_RIGHT | Hindi számjegy zárójelek - jobb. |
| BULLET_HINDI_ALPHA_1_PERIOD | Hindi ábécé pont - mássalhangzók. |
