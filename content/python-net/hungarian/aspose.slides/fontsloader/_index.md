## FontsLoader osztály

Osztály egyedi, a felhasználó által definiált betűkészletek betöltéséhez.
            Használata a prezentációobjektumok létrehozása előtt szükséges.

A FontsLoader típus a következő tagokat teszi elérhetővé:

## Metódusok

| Metódus | Leírás |
| :- | :- |
| [`load_external_fonts(directories)`](/slides/python-net/hu/aspose.slides/fontsloader/load_external_fonts/#liststr) | További mappákat ad hozzá a betűkészletek kereséséhez. |
| [`load_external_font(data)`](/slides/python-net/hu/aspose.slides/fontsloader/load_external_font/#bytes) | Betűkészletet ad hozzá a bináris adatokból. |
| [`get_font_folders()`](/slides/python-net/hu/aspose.slides/fontsloader/get_font_folders/#) | Betűkészlet-mappákat kér le. Visszaadja a LoadExternalFonts metódussal hozzáadott mappákat, valamint a rendszer betűkészlet-mappákat. |
| [`clear_cache()`](/slides/python-net/hu/aspose.slides/fontsloader/clear_cache/#) | Felszabadítja a felhasználó által definiált összes egyedi betűkészletet. |
