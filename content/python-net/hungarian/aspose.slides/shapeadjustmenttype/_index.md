## ShapeAdjustmentType enumeráció

Különböző típusú alakzatkorrekciós értékeket határoz meg.

A ShapeAdjustmentType típus a következő elemeket tartalmazza:

## Mezők

| Field | Description |
| :- | :- |
| CUSTOM | Egyéni típus (ismeretlen beállítás) |
| CORNER_SIZE | A sarkok méretét szabályozza. |
| LEFT_UP_CORNER | A bal felső sarkot szabályozza. |
| RIGHT_UP_CORNER | A jobb felső sarkot szabályozza. |
| UP_CORNERS | A felső sarkokat szabályozza. |
| DOWN_CORNERS | Az alsó sarkokat szabályozza. |
| THICKNESS | Az alakzat vastagságát szabályozza. |
| ARROW_TAIL_THICKNESS | A nyílfarok vastagságát szabályozza. |
| ARROWHEAD_LENGTH | A nyílléc hosszát szabályozza. |
| ARROWHEAD_WIDTH | A nyílléc szélességét szabályozza. |
| RADIUS | Az alakzat vagy annak részének sugárméretét szabályozza. |
| DEPTH | A fogaskerék fogak vagy a ferde hatás mélységét szabályozza. |
| SHAPE_PART_OFFSET | Az alakzat egy részének eltolását szabályozza a másikhoz képest. |
| ANGLE | Az alakzat vagy annak részének szögét szabályozza. |
| START_ANGLE | Kezdőszög a kördiagram és ív alakzatokhoz. |
| END_ANGLE | Végszög a kördiagram és ív alakzatokhoz. |
| START_POINT_X | A felirat kezdőpontjának X pozícióját szabályozza. |
| START_POINT_Y | A felirat kezdőpontjának Y pozícióját szabályozza. |
| CONNECTOR_POINT_1X | A felirat szögállítási pontjának vízszintes pozícióját szabályozza. |
| CONNECTOR_POINT_1Y | A felirat szögállítási pontjának függőleges pozícióját szabályozza. |
| CONNECTOR_POINT_2X | A felirat szögállítási pontjának vízszintes pozícióját szabályozza. |
| CONNECTOR_POINT_2Y | A felirat szögállítási pontjának függőleges pozícióját szabályozza. |
| CONNECTOR_BEND_POSITION_X | A csatlakozó görbületének vízszintes pozícióját szabályozza. |
| CONNECTOR_BEND_POSITION_Y | A csatlakozó görbületének függőleges pozícióját szabályozza. |
| ATTACH_Y | Az alakzat függőleges csatlakozási pontját szabályozza. |
| ATTACH_X | Az alakzat vízszintes csatlakozási pontját szabályozza. |
| CALLOUT_HEIGHT | A felirat függőleges méretét szabályozza. |
| CALLOUT_WIDTH | A felirat vízszintes méretét szabályozza. |
| CALLOUT_SIZE | A felirat méretét szabályozza. |
| CURVATURE | A hajlított, konzolos, ívelt nyíl vagy alakzat görbülete. |
| HORIZONTAL_THICKNESS | A sark alakzat vízszintes vastagságát szabályozza. |
| VERTICAL_THICKNESS | A sark alakzat függőleges vastagságát szabályozza. |
| VERTICAL_SIZE | Az alakzat függőleges méretét szabályozza. |
| HORIZONTAL_SIZE | Az alakzat vízszintes méretét szabályozza. |
| TOP | Az alakzat felső oldalát szabályozza. |
