## ColorType enumeráció

Különböző színmódokat képvisel.

A ColorType típus a következő tagokat teszi elérhetővé:

## Mezők

| Mező | Leírás |
| :- | :- |
| NOT_DEFINED | A szín egyáltalán nincs definiálva. |
| RGB | Standard 24 bites RGB szín. |
| RGB_PERCENTAGE | Nagy felbontású RGB szín. |
| HSL | Nagy felbontású HSL szín. |
| SCHEME | Séma szín. |
| SYSTEM | Rendszer szín. |
| PRESET | Előre beállított szín. |
