## SensitivityLabelAssignmentType enumeration

A szenzitivitási címke hozzárendelési módját reprezentálja.

A SensitivityLabelAssignmentType típus a következő tagokat tartalmazza:

## Mezők

| Field | Description |
| :- | :- |
| STANDARD | Használja minden olyan szenzitivitási címke esetén, amelyet a felhasználó nem alkalmazott közvetlenül. <br/>            Ez magában foglalja az összes alapértelmezett címkét, valamint az automatikusan alkalmazott címkéket. |
| PRIVILEGED | Használja minden olyan szenzitivitási címke esetén, amelyet a felhasználó közvetlenül alkalmazott. <br/>            Ez magában foglalja a manuálisan alkalmazott szenzitivitási címkéket, valamint az ajánlott<br/>            vagy kötelező címkézést, vagy bármely olyan funkciót, ahol a felhasználó dönt a alkalmazandó szenzitivitási címkéről. |
