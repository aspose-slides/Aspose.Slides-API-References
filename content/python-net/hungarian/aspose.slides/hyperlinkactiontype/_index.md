## HyperlinkActionType felsorolás

Egy hiperhivatkozás művelet típusát képviseli.

A HyperlinkActionType típus a következő tagokat biztosítja:

## Mezők

| Mező | Leírás |
| :- | :- |
| UNKNOWN | Ismeretlen művelettípus. |
| NO_ACTION | Nincs művelet. |
| HYPERLINK | Általános hiperhivatkozás. |
| JUMP_FIRST_SLIDE | Ugrás a prezentáció első diájára. |
| JUMP_PREVIOUS_SLIDE | Ugrás az előző diára. |
| JUMP_NEXT_SLIDE | Ugrás a következő diára. |
| JUMP_LAST_SLIDE | Ugrás a prezentáció utolsó diájára. |
| JUMP_END_SHOW | Ugrás a diavetítés végére. |
| JUMP_LAST_VIEWED_SLIDE | Ugrás az utoljára megtekintett diára. |
| JUMP_SPECIFIC_SLIDE | Ugrás a konkrét diára, amelyet a [`IHyperlink.target_slide`](/slides/python-net/hu/aspose.slides/ihyperlink/target_slide) tulajdonság jelöl. |
| START_CUSTOM_SLIDE_SHOW | Egyéni diavetítés indítása. |
| OPEN_FILE | Hivatkozott fájl megnyitása. |
| OPEN_PRESENTATION | Hivatkozott prezentáció megnyitása. |
| START_STOP_MEDIA | Médiafájl lejátszásának indítása/leállítása. |
| START_MACRO | Makró szkript végrehajtásának indítása. |
| START_PROGRAM | Program indítása. |
