## LineSketchType felsorolás

Azt jelöli, hogy egy alakzat melyik vázlat típus vagy hatás lett hozzárendelve.

The LineSketchType type exposes the following members:

## Mezők

| Mező | Leírás |
| :- | :- |
| NOT_DEFINED | Megadja, hogy egy alakzatra a Sketch effektus nincs definiálva. |
| NONE | Megadja, hogy egy alakzatra nincs Sketch effektus. Ennek megfelelője, hogy ez a tulajdonság üres. |
| CURVED | Megadja, hogy egy alakzatra a Curved effektus van alkalmazva, amely az alakzat minden élét egy nagy, enyhe ívvé alakítja. |
| FREEHAND | Megadja, hogy egy alakzatra a Freehand effektus van alkalmazva, amely a leginkább egy hibásan rajzolt vonalra hasonlít. |
| SCRIBBLE | Megadja, hogy egy alakzatra a Scribble effektus van alkalmazva, amely túlzó rezgést mutat, mintha szándékosan rendezetlenül lenne megrajzolva. |
