## PathFillModeType enumeráció

Meghatározza, hogyan kell kitölteni egy útvonalat

A PathFillModeType típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| NONE | No Path Fill<br/>            Ez azt jelenti, hogy a megfelelő útvonalnak nem lesz kitöltése. |
| NORMAL | Normal Path Fill<br/>            Ez azt jelenti, hogy a megfelelő útvonalra normál árnyalatú szín kerül alkalmazásra a kitöltésén. |
| LIGHTEN | Lighten Path Fill<br/>            Ez azt jelenti, hogy a megfelelő útvonalra enyhén árnyalatú szín kerül alkalmazásra a kitöltésén. |
| LIGHTEN_LESS | Lighten Path Fill Less<br/>            Ez azt jelenti, hogy a megfelelő útvonalra valamivel világosabb árnyalatú szín kerül alkalmazásra a kitöltésén. |
| DARKEN | Darken Path Fill<br/>            Ez azt jelenti, hogy a megfelelő útvonalra sötétebb árnyalatú szín kerül alkalmazásra a kitöltésén. |
| DARKEN_LESS | Darken Path Fill Less<br/>            Ez azt jelenti, hogy a megfelelő útvonalra valamivel sötétebb árnyalatú szín kerül alkalmazásra a kitöltésén. |
