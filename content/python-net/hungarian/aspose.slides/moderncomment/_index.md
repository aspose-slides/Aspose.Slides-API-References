## ModernComment osztály

A diára vonatkozó megjegyzést képviseli.

**Öröklődés:**[`ModernComment`](/slides/python-net/hu/aspose.slides/moderncomment) → [`Comment`](/slides/python-net/hu/aspose.slides/comment)

A ModernComment típus a következő tagokat biztosítja:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`text`](/slides/python-net/hu/aspose.slides/moderncomment/text/) | A diára vonatkozó megjegyzés egyszerű szövegét adja vissza vagy állítja be.<br/>            Olvasás/írás **str**. |
| [`created_time`](/slides/python-net/hu/aspose.slides/moderncomment/created_time/) | A megjegyzés létrehozásának időpontját adja vissza vagy állítja be.<br/>            Ennek a tulajdonságnak **System.DateTime** értékre állítása azt jelenti, hogy nincs megjegyzés időpont beállítva.<br/>            Olvasás/írás **System.DateTime**. |
| [`slide`](/slides/python-net/hu/aspose.slides/moderncomment/slide/) | A megjegyzés szülődiáját adja vissza vagy állítja be.<br/>            Csak olvasható [`ISlide`](/slides/python-net/hu/aspose.slides/islide). |
| [`author`](/slides/python-net/hu/aspose.slides/moderncomment/author/) | A megjegyzés szerzőjét adja vissza.<br/>            Csak olvasható [`ICommentAuthor`](/slides/python-net/hu/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/hu/aspose.slides/moderncomment/position/) | A megjegyzés diára vonatkozó pozícióját adja vissza vagy állítja be.<br/>            Olvasás/írás [`PointF`](/slides/python-net/hu/aspose.slides/pointf). |
| [`parent_comment`](/slides/python-net/hu/aspose.slides/moderncomment/parent_comment/) | A szülő megjegyzést adja vissza vagy állítja be.<br/>            Olvasás/írás [`IComment`](/slides/python-net/hu/aspose.slides/icomment). |
| [`shape`](/slides/python-net/hu/aspose.slides/moderncomment/shape/) | A megjegyzéshez kapcsolódó alakzatot adja vissza.<br/>            Csak olvasható [`IShape`](/slides/python-net/hu/aspose.slides/ishape). |
| [`text_selection_start`](/slides/python-net/hu/aspose.slides/moderncomment/text_selection_start/) | A szövegkeretben lévő szövegkijelölés kezdőpozícióját adja vissza vagy állítja be, ha a megjegyzés egy AutoShape-hez kapcsolódik.<br/>            Olvasás/írás **int**. |
| [`text_selection_length`](/slides/python-net/hu/aspose.slides/moderncomment/text_selection_length/) | A szövegkeretben lévő szövegkijelölés hosszát adja vissza vagy állítja be, ha a megjegyzés egy AutoShape-hez kapcsolódik.<br/>            Olvasás/írás **int**. |
| [`status`](/slides/python-net/hu/aspose.slides/moderncomment/status/) | A megjegyzés állapotát adja vissza vagy állítja be.<br/>            Olvasás/írás [`ModernCommentStatus`](/slides/python-net/hu/aspose.slides/moderncommentstatus). |
