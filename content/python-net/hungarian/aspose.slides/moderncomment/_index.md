## ModernComment osztály

Egy dián lévő megjegyzést képvisel.

**Öröklés:**[`ModernComment`](/slides/python-net/hu/aspose.slides/moderncomment) → [`Comment`](/slides/python-net/hu/aspose.slides/comment)

A ModernComment típus a következő tagokat tartalmazza:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`text`](/slides/python-net/hu/aspose.slides/moderncomment/text/) | Visszaadja vagy beállítja a diamegjegyzés egyszerű szövegét.<br/>            Olvasás/írás **str**. |
| [`created_time`](/slides/python-net/hu/aspose.slides/moderncomment/created_time/) | Visszaadja vagy beállítja a megjegyzés létrehozásának időpontját.<br/>            Ennek a tulajdonságnak **System.DateTime** értékre állítása azt jelenti, hogy nincs megjegyzés időpont beállítva.<br/>            Olvasás/írás **System.DateTime**. |
| [`slide`](/slides/python-net/hu/aspose.slides/moderncomment/slide/) | Visszaadja vagy beállítja a megjegyzés szülődiáját.<br/>            Csak olvasható [`ISlide`](/slides/python-net/hu/aspose.slides/islide). |
| [`author`](/slides/python-net/hu/aspose.slides/moderncomment/author/) | Visszaadja a megjegyzés szerzőjét.<br/>            Csak olvasható [`ICommentAuthor`](/slides/python-net/hu/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/hu/aspose.slides/moderncomment/position/) | Visszaadja vagy beállítja a megjegyzés helyzetét a dián.<br/>            Olvasás/írás **aspose.slides.PointF**. |
| [`parent_comment`](/slides/python-net/hu/aspose.slides/moderncomment/parent_comment/) | Lekéri vagy beállítja a szülő megjegyzést.<br/>            Olvasás/írás [`IComment`](/slides/python-net/hu/aspose.slides/icomment). |
| [`shape`](/slides/python-net/hu/aspose.slides/moderncomment/shape/) | Visszaad egy alakzatot, amely a megjegyzéshez kapcsolódik.<br/>            Csak olvasható [`IShape`](/slides/python-net/hu/aspose.slides/ishape). |
| [`text_selection_start`](/slides/python-net/hu/aspose.slides/moderncomment/text_selection_start/) | Lekéri vagy beállítja a szövegkiválasztás kezdőpozícióját a szövegkeretben, ha a megjegyzés AutoShape-hez kapcsolódik.<br/>            Olvasás/írás **int**. |
| [`text_selection_length`](/slides/python-net/hu/aspose.slides/moderncomment/text_selection_length/) | Lekéri vagy beállítja a szövegkiválasztás hosszát a szövegkeretben, ha a megjegyzés AutoShape-hez kapcsolódik.<br/>            Olvasás/írás **int**. |
| [`status`](/slides/python-net/hu/aspose.slides/moderncomment/status/) | Lekéri vagy beállítja a megjegyzés állapotát.<br/>            Olvasás/írás [`ModernCommentStatus`](/slides/python-net/hu/aspose.slides/moderncommentstatus). |
