## CustomXmlPart osztály

A testreszabott XML részletet képviseli.

A CustomXmlPart típus a következő tagokat teszi elérhetővé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`xml_data`](/slides/python-net/hu/aspose.slides/customxmlpart/xml_data/) | Visszaadja vagy beállítja az xml adatot.<br/>            Olvasás/írás **int**[].<br/>            az érték `None`. az érték üres vagy az xml-adat érvénytelen. |
| [`xml_as_string`](/slides/python-net/hu/aspose.slides/customxmlpart/xml_as_string/) | Visszaadja vagy beállítja az xml adatot UTF-8 karakterláncként.<br/>            Olvasás/írás **str**.<br/>            az érték `None`. az érték üres vagy az xml-adat érvénytelen. |
| [`item_id`](/slides/python-net/hu/aspose.slides/customxmlpart/item_id/) | Megadja a globálisan egyedi azonosítót (GUID), amely egyedileg azonosít egyetlen testreszabott XML <br/>            részt egy Office Open XML dokumentumban.<br/>            Csak olvasható **System.Guid**. |
| [`namespace_schemas`](/slides/python-net/hu/aspose.slides/customxmlpart/namespace_schemas/) | Visszaadja a testreszabott XML részhez kapcsolódó XML séma gyűjteményt.<br/>            Csak olvasható **str**[]. |
