## ITextFrameFormatEffectiveData osztály

Megváltoztathatatlan objektum, amely a hatékony szövegkeret formázási tulajdonságait tartalmazza.

Az ITextFrameFormatEffectiveData típus a következő tagokat teszi közzé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`text_style`](/slides/python-net/hu/aspose.slides/itextframeformateffectivedata/text_style/) | Visszaadja a hatékony szöveg stílusát.<br/>            Csak olvasható [`ITextStyleEffectiveData`](/slides/python-net/hu/aspose.slides/itextstyleeffectivedata). |
| [`margin_left`](/slides/python-net/hu/aspose.slides/itextframeformateffectivedata/margin_left/) | Visszaadja a bal margót (pontokban) egy TextFrame-ben.<br/>            Csak olvasható **float**. |
| [`margin_right`](/slides/python-net/hu/aspose.slides/itextframeformateffectivedata/margin_right/) | Visszaadja a jobb margót (pontokban) egy TextFrame-ben.<br/>            Csak olvasható **float**. |
| [`margin_top`](/slides/python-net/hu/aspose.slides/itextframeformateffectivedata/margin_top/) | Visszaadja a felső margót (pontokban) egy TextFrame-ben.<br/>            Csak olvasható **float**. |
| [`margin_bottom`](/slides/python-net/hu/aspose.slides/itextframeformateffectivedata/margin_bottom/) | Visszaadja az alsó margót (pontokban) egy TextFrame-ben.<br/>            Csak olvasható **float**. |
| [`wrap_text`](/slides/python-net/hu/aspose.slides/itextframeformateffectivedata/wrap_text/) | Visszaadja, hogy a szöveg megtörik-e a TextFrame margóin.<br/>            Csak olvasható **bool**. |
| [`anchoring_type`](/slides/python-net/hu/aspose.slides/itextframeformateffectivedata/anchoring_type/) | Visszaadja a függőleges rögzítési szöveget egy TextFrame-ben.<br/>            Csak olvasható [`TextAnchorType`](/slides/python-net/hu/aspose.slides/textanchortype). |
| [`center_text`](/slides/python-net/hu/aspose.slides/itextframeformateffectivedata/center_text/) | Visszaadja, hogy a szöveget vízszintesen középre kell-e helyezni a dobozban.<br/>            Csak olvasható **bool**. |
| [`text_vertical_type`](/slides/python-net/hu/aspose.slides/itextframeformateffectivedata/text_vertical_type/) | Visszaadja a szöveg tájolását.<br/>            Csak olvasható [`TextVerticalType`](/slides/python-net/hu/aspose.slides/textverticaltype). |
| [`autofit_type`](/slides/python-net/hu/aspose.slides/itextframeformateffectivedata/autofit_type/) | Visszaadja a szöveg automatikus illesztési módját.<br/>            Csak olvasható [`TextAutofitType`](/slides/python-net/hu/aspose.slides/textautofittype). |
| [`column_count`](/slides/python-net/hu/aspose.slides/itextframeformateffectivedata/column_count/) | Meghatározza a szövegoszlopok számát a határoló téglalapban.<br/>            Csak olvasható **int**. |
| [`column_spacing`](/slides/python-net/hu/aspose.slides/itextframeformateffectivedata/column_spacing/) | Meghatározza a szövegoszlopok közötti távolságot a szövegterületen (pontokban).<br/>            Csak olvasható **float**. |
