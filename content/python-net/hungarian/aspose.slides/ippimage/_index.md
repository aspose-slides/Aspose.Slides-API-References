## IPPImage osztály

Egy képet képvisel egy prezentációban.

Az IPPImage típus a következő tagokat teszi közzé:

## Tulajdonságok

| Property | Description |
| :- | :- |
| [`binary_data`](/slides/python-net/hu/aspose.slides/ippimage/binary_data/) | Visszaadja a kép adatainak másolatát.<br/>            Csak olvasható **int**[]. |
| [`image`](/slides/python-net/hu/aspose.slides/ippimage/image/) | Visszaadja a kép másolatát.<br/>            Csak olvasható [`IPPImage.image`](/slides/python-net/hu/aspose.slides/ippimage/image). |
| [`svg_image`](/slides/python-net/hu/aspose.slides/ippimage/svg_image/) | Visszaadja vagy beállítja az ISvgImage objektumot [`ISvgImage`](/slides/python-net/hu/aspose.slides/isvgimage) |
| [`content_type`](/slides/python-net/hu/aspose.slides/ippimage/content_type/) | Visszaadja egy kép MIME típusát, amely [`IPPImage.binary_data`](/slides/python-net/hu/aspose.slides/ippimage/binary_data)-ben van kódolva.<br/>            Csak olvasható **str**. |
| [`width`](/slides/python-net/hu/aspose.slides/ippimage/width/) | Visszaadja egy kép szélességét.<br/>            Csak olvasható **int**. |
| [`height`](/slides/python-net/hu/aspose.slides/ippimage/height/) | Visszaadja egy kép magasságát.<br/>            Csak olvasható **int**. |
| [`x`](/slides/python-net/hu/aspose.slides/ippimage/x/) | Visszaadja egy kép X-eltolását.<br/>            Csak olvasható **int**. |
| [`y`](/slides/python-net/hu/aspose.slides/ippimage/y/) | Visszaadja egy kép Y-eltolását.<br/>            Csak olvasható **int**. |
