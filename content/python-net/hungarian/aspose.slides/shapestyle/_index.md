## ShapeStyle osztály

Az alakzat stílusreferenciáját képviseli.

A ShapeStyle típus a következő tagokat teszi közzé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`line_color`](/slides/python-net/hu/aspose.slides/shapestyle/line_color/) | Visszaad egy alakzat kontúr színét.<br/>            Csak olvasható [`IColorFormat`](/slides/python-net/hu/aspose.slides/icolorformat). |
| [`line_style_index`](/slides/python-net/hu/aspose.slides/shapestyle/line_style_index/) | Visszaadja vagy beállítja a vonal oszlopindexét egy stílusmátrixban.<br/>            Olvasható/írható **int**. |
| [`fill_color`](/slides/python-net/hu/aspose.slides/shapestyle/fill_color/) | Visszaad egy alakzat kitöltő színét.<br/>            Csak olvasható [`IColorFormat`](/slides/python-net/hu/aspose.slides/icolorformat). |
| [`fill_style_index`](/slides/python-net/hu/aspose.slides/shapestyle/fill_style_index/) | Visszaadja vagy beállítja az alakzat kitöltő oszlopindexét a stílusmátrixokban.<br/>            0 azt jelenti, hogy nincs kitöltés,<br/>            pozitív érték - index a téma kitöltési stílusaiban,<br/>            negatív érték - index a téma háttérstílusaiban.<br/>            Olvasható/írható **int**. |
| [`effect_color`](/slides/python-net/hu/aspose.slides/shapestyle/effect_color/) | Visszaad egy alakzat effektus színét.<br/>            Csak olvasható [`IColorFormat`](/slides/python-net/hu/aspose.slides/icolorformat). |
| [`effect_style_index`](/slides/python-net/hu/aspose.slides/shapestyle/effect_style_index/) | Visszaadja vagy beállítja az alakzat effektus oszlopindexét egy stílusmátrixban.<br/>            Olvasható/írható **int**. |
| [`font_color`](/slides/python-net/hu/aspose.slides/shapestyle/font_color/) | Visszaad egy alakzat betűszínét.<br/>            Csak olvasható [`IColorFormat`](/slides/python-net/hu/aspose.slides/icolorformat). |
| [`font_collection_index`](/slides/python-net/hu/aspose.slides/shapestyle/font_collection_index/) | Visszaadja vagy beállítja az alakzat betűtípus indexét egy betűtípus-gyűjteményben.<br/>            Olvasható/írható [`FontCollectionIndex`](/slides/python-net/hu/aspose.slides/fontcollectionindex). |
