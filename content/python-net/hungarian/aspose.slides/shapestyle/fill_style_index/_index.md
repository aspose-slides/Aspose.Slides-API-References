## fill_style_index tulajdonság
Visszaadja vagy beállítja az alakzat kitöltési oszlopindexét a stílusmátrixokban.
            0 azt jelenti, hogy nincs kitöltés,
            pozitív érték - index a téma kitöltési stílusaiban,
            negatív érték - index a téma háttérstílusaiban.
            Olvasás/írás **int**.
