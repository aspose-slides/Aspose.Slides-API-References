## portion_format tulajdonság
Returns formatting object which contains explicitly set formatting properties of the text portion with no inheritance applied.
            Csak olvasható [`IPortionFormat`](/slides/python-net/hu/aspose.slides/iportionformat).

### Megjegyzések

A formázási objektum csak az aktuális részhez definiált formázási paramétereket tartalmazza, az örökölt adatok nem kerülnek alkalmazásra.

Az örökölt értékeket is magában foglaló hatékony értékek lekéréséhez használd a [`PortionFormat.get_effective`](/slides/python-net/hu/aspose.slides/portionformat/get_effective) metódust.
