| BODY | Törzs. |

| SUBTITLE | Alcím. |
| DATE_AND_TIME | Dátum és idő. |

| FOOTER | Lábléc. |
| HEADER | Fejléc. |
| OBJECT | Objektum. |
| CHART | Diagram. |

| PICTURE | Kép. |
