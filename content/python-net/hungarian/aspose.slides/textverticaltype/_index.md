## TextVerticalType enumeráció

Meghatározza a szöveg függőleges írási módját.

A TextVerticalType típus a következő tagokat teszi elérhetővé:

## Mezők

| Mező | Leírás |
| :- | :- |
| NOT_DEFINED | Nincs definiálva. |
| HORIZONTAL | Vízszintes szöveg. |
| VERTICAL | Függőleges szöveg. |
| VERTICAL270 | 270 fokos függőleges szöveg. |
| WORD_ART_VERTICAL | WordArt függőleges szöveg. |
| EAST_ASIAN_VERTICAL | Kelet-ázsiai függőleges szöveg. |
| MONGOLIAN_VERTICAL | Mongol függőleges szöveg. |
| WORD_ART_VERTICAL_RIGHT_TO_LEFT | WordArt függőleges jobbról balra szöveg. |
