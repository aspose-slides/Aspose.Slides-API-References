## SlideSizeType felsorolás

A diavetítés méretének előre definiált beállítását jelöli.

A SlideSizeType típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| ON_SCREEN | Képernyőn 4x3 |
| LETTER_PAPER | Letter |
| A4_PAPER | A4 |
| SLIDE_35MM | Dia 35mm |
| OVERHEAD | Overhead |
| BANNER | Banner |
| CUSTOM | Egyéni méret |
| LEDGER | Ledger |
| A3_PAPER | A3 |
| B4_ISO_PAPER | B4 ISO |
| B5_ISO_PAPER | B5 ISO |
| B4_JIS_PAPER | B4 JIS |
| B5_JIS_PAPER | B5 JIS |
| HAGAKI_CARD | Hagaki kártya |
| ON_SCREEN_16X9 | Képernyőn 16x9 |
| ON_SCREEN_16X10 | Képernyőn 16x10 |
| WIDESCREEN | Szélesvásznú |
