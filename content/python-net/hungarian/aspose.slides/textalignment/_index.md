## TextAlignment enumeráció

Különböző szövegigazítási stílusokat képvisel.

A TextAlignment típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| NOT_DEFINED | Alapértelmezett igazítás. |
| LEFT | Bal igazítás. |
| CENTER | Középre igazítás. |
| RIGHT | Jobb igazítás. |
| JUSTIFY | Sorkizárt igazítás. |
| JUSTIFY_LOW | Kashida alacsony igazítás. |
| DISTRIBUTED | Elosztott igazítás. |
