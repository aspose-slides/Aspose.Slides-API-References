## PPImageFormat felsorolás

Képfájl formátumok. Ez az enumeráció helyettesíti a `System.Drawing.Imaging.ImageFormat` osztályt. COM kompatibilitáshoz szükséges.

A PPImageFormat típus a következő tagokat teszi elérhetővé:

## Mezők

| Mező | Leírás |
| :- | :- |
| BMP | A bitmap (BMP) képformátumot adja vissza. |
| EMF | Az enhanced metafile (EMF) képformátumot adja vissza. |
| EXIF | Az Exchangeable Image File (Exif) formátumot adja vissza. |
| GIF | A Graphics Interchange Format (GIF) képformátumot adja vissza. |
| ICON | A Windows ikon képformátumot adja vissza. |
| JPEG | A Joint Photographic Experts Group (JPEG) képformátumot adja vissza. |
| MEMORY_BMP | A memória bitmap formátumát adja vissza. |
| PNG | A W3C Portable Network Graphics (PNG) képformátumot adja vissza. |
| TIFF | A Tagged Image File Format (TIFF) képformátumot adja vissza. |
| WMF | A Windows metafile (WMF) képformátumot adja vissza. |
