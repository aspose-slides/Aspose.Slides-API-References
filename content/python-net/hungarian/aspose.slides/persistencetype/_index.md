## PersistenceType enumeráció

Megadja a módszert, amelyet a ActiveX vezérlő tulajdonságainak tárolására használnak.

A PersistenceType típus a következő tagokkal rendelkezik:

## Mezők

| Mező | Leírás |
| :- | :- |
| NOT_DEFINED | A perzisztencia-azonosító nincs megadva. |
| PERSIST_PROPERTY_BAG | Megadja, hogy az ActiveX vezérlő a property-bag-alapú perzisztencia használatával van perzisztálva. <br/>             A property-bag-alapú perzisztencia az ActiveX vezérlőt egy név-érték párokból álló gyűjtemény segítségével tárolja, <br/>             amelyek meghatározzák a vezérlő által perzisztált adatokat. |
| PERSIST_STREAM | Megadja, hogy az ActiveX vezérlő stream-alapú perzisztencia használatával van perzisztálva <br/>             ami nem támogatja az ActiveX vezérlő alapértelmezett állapotra történő inicializálását. |
| PERSIST_STREAM_INIT | Megadja, hogy az ActiveX vezérlő stream-alapú perzisztencia használatával van perzisztálva <br/>             amely támogatja az ActiveX vezérlő alapértelmezett állapotra történő inicializálását. |
| PERSIST_STORAGE | Megadja, hogy az ActiveX vezérlő storage-alapú perzisztencia használatával van perzisztálva. |
