## remove(self, item) {#iportion}
Eltávolítja egy adott objektum első előfordulását a **System.Collections.Generic.ICollection`1**-ból.

### Visszatérési érték

true, ha a `item` sikeresen eltávolításra került a **System.Collections.Generic.ICollection`1**-ból; egyébként false. A metódus false értéket ad vissza, ha a `item` nem található az eredeti **System.Collections.Generic.ICollection`1**-ban.



```python
def remove(self, item):
    ...
```


| Paraméter | Típus | Leírás |
| :- | :- | :- |
| item | [`IPortion`](/slides/python-net/hu/aspose.slides/iportion) | Az az objektum, amelyet el kell távolítani a **System.Collections.Generic.ICollection`1**-ból. |

### Kivételek

| Kivétel | Leírás |
| :- | :- |
| **RuntimeError(Proxy error(NotSupportedException))** | A **System.Collections.Generic.ICollection`1** csak olvasható. |
