## Size osztály

Egy egész számokból álló rendezett párost tárol, amely meghatározza a szélességet és a magasságot. Kompatibilis a .NET `System.Drawing.Size`-nal.

A Size típus a következő tagokat teszi elérhetővé:

## Konstruktorok

| Constructor | Description |
| :- | :- |
| [`__init__(self, width=0, height=0)`](/slides/python-net/hu/aspose.slides/size/__init__/#int-int) | Létrehoz egy méretet a megadott szélességgel és magassággal. A lebegőpontos értékeket egész számokra csonkolja. |

## Tulajdonságok

| Property | Description |
| :- | :- |
| [`width`](/slides/python-net/hu/aspose.slides/size/width/) | Visszaadja ennek a méretnek a vízszintes komponensét.<br/>            Csak olvasható **int**. |
| [`height`](/slides/python-net/hu/aspose.slides/size/height/) | Visszaadja ennek a méretnek a függőleges komponensét.<br/>            Csak olvasható **int**. |


### Megjegyzések

A méreteket a komponenseik alapján hasonlítják össze a `==` operátorral, és használhatók szótárkulcsként vagy halmazelemként.
