## IThreeDFormatEffectiveData osztály

Megváltoztathatatlan objektum, amely a hatékony 3-D formázási tulajdonságokat képviseli.

Az IThreeDFormatEffectiveData típus a következő tagokat biztosítja:

## Tulajdonságok

| Property | Description |
| :- | :- |
| [`contour_width`](/slides/python-net/hu/aspose.slides/ithreedformateffectivedata/contour_width/) | Visszaadja egy 3D kontúr szélességét.<br/>            Csak olvasható **float**. |
| [`extrusion_height`](/slides/python-net/hu/aspose.slides/ithreedformateffectivedata/extrusion_height/) | Visszaadja egy kiemelési hatás magasságát.<br/>            Csak olvasható **float**. |
| [`depth`](/slides/python-net/hu/aspose.slides/ithreedformateffectivedata/depth/) | Visszaadja egy 3D alak mélységét.<br/>            Csak olvasható **float**. |
| [`bevel_top`](/slides/python-net/hu/aspose.slides/ithreedformateffectivedata/bevel_top/) | Visszaadja a felső 3D lekerekítés típusát.<br/>            Csak olvasható [`IShapeBevelEffectiveData`](/slides/python-net/hu/aspose.slides/ishapebeveleffectivedata). |
| [`bevel_bottom`](/slides/python-net/hu/aspose.slides/ithreedformateffectivedata/bevel_bottom/) | Visszaadja az alsó 3D lekerekítés típusát.<br/>            Csak olvasható [`IShapeBevelEffectiveData`](/slides/python-net/hu/aspose.slides/ishapebeveleffectivedata). |
| [`contour_color`](/slides/python-net/hu/aspose.slides/ithreedformateffectivedata/contour_color/) | Visszaadja egy kontúr színét.<br/>            Csak olvasható [`Color`](/slides/python-net/hu/aspose.slides/color). |

| [`camera`](/slides/python-net/hu/aspose.slides/ithreedformateffectivedata/camera/) | Visszaadja egy kamera beállításait.<br/>            Csak olvasható [`ICameraEffectiveData`](/slides/python-net/hu/aspose.slides/icameraeffectivedata). |
