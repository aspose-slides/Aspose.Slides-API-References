## IThreeDFormatEffectiveData osztály

Megváltoztathatatlan objektum, amely a hatékony 3-D formázási tulajdonságokat képviseli.

Az IThreeDFormatEffectiveData típus a következő tagokat teszi közzé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`contour_width`](/slides/python-net/hu/aspose.slides/ithreedformateffectivedata/contour_width/) | Visszaadja egy 3D kontúr szélességét.<br/>            Csak olvasható **float**. |
| [`extrusion_height`](/slides/python-net/hu/aspose.slides/ithreedformateffectivedata/extrusion_height/) | Visszaadja a kihúzási hatás magasságát.<br/>            Csak olvasható **float**. |
| [`depth`](/slides/python-net/hu/aspose.slides/ithreedformateffectivedata/depth/) | Visszaadja egy 3D alak mélységét.<br/>            Csak olvasható **float**. |
| [`bevel_top`](/slides/python-net/hu/aspose.slides/ithreedformateffectivedata/bevel_top/) | Visszaadja egy felső 3D levágás típusát.<br/>            Csak olvasható [`IShapeBevelEffectiveData`](/slides/python-net/hu/aspose.slides/ishapebeveleffectivedata). |
| [`bevel_bottom`](/slides/python-net/hu/aspose.slides/ithreedformateffectivedata/bevel_bottom/) | Visszaadja egy alsó 3D levágás típusát.<br/>            Csak olvasható [`IShapeBevelEffectiveData`](/slides/python-net/hu/aspose.slides/ishapebeveleffectivedata). |
| [`contour_color`](/slides/python-net/hu/aspose.slides/ithreedformateffectivedata/contour_color/) | Visszaadja egy kontúr színét.<br/>            Csak olvasható **aspose.slides.Color**. |
| [`extrusion_color`](/slides/python-net/hu/aspose.slides/ithreedformateffectivedata/extrusion_color/) | Visszaadja egy kihúzás színét.<br/>            Csak olvasható **aspose.slides.Color**. |
| [`camera`](/slides/python-net/hu/aspose.slides/ithreedformateffectivedata/camera/) | Visszaadja egy kamera beállításait.<br/>            Csak olvasható [`ICameraEffectiveData`](/slides/python-net/hu/aspose.slides/icameraeffectivedata). |
| [`light_rig`](/slides/python-net/hu/aspose.slides/ithreedformateffectivedata/light_rig/) | Visszaadja egy fény típusát.<br/>            Csak olvasható [`ILightRigEffectiveData`](/slides/python-net/hu/aspose.slides/ilightrigeffectivedata). |
| [`material`](/slides/python-net/hu/aspose.slides/ithreedformateffectivedata/material/) | Visszaadja egy anyag típusát.<br/>            Csak olvasható [`MaterialPresetType`](/slides/python-net/hu/aspose.slides/materialpresettype). |

### Megjegyzés

Ez a felület a [`IThreeDFormat`](/slides/python-net/hu/aspose.slides/ithreedformat) felülettel együtt használható a hatékony formázási értékek visszaadásához, öröklődéssel együtt.
