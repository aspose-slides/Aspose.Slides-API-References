## ICameraEffectiveData osztály

Módosíthatatlan objektum, amely hatékony kamera tulajdonságokat tartalmaz.

Az ICameraEffectiveData típus a következő tagokat teszi elérhetővé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`camera_type`](/slides/python-net/hu/aspose.slides/icameraeffectivedata/camera_type/) | Kamera típusa.<br/>            Csak olvasható [`CameraPresetType`](/slides/python-net/hu/aspose.slides/camerapresettype). |
| [`field_of_view_angle`](/slides/python-net/hu/aspose.slides/icameraeffectivedata/field_of_view_angle/) | Kamera FOV (0-180°, látómező).<br/>            Csak olvasható **float**. |
| [`zoom`](/slides/python-net/hu/aspose.slides/icameraeffectivedata/zoom/) | Kamera nagyítás (pozitív érték százalékban).<br/>            Csak olvasható **float**. |

## Módszerek

| Metódus | Leírás |
| :- | :- |
| [`get_rotation(self)`](/slides/python-net/hu/aspose.slides/icameraeffectivedata/get_rotation/#) | A forgást egy szélességi koordináta használatával definiálják<br/>            koordinátát, egy hosszúsági koordinátát, és egy tengely körüli forgalmat <br/>            mint a szélességi és hosszúsági koordináták.<br/>            első elem a visszatérő tömbben – szélesség, második – hosszúság, harmadik – forgalom.<br/>            None értéket ad vissza, ha nincs forgás definiálva. |
