## last_saved_time tulajdonság
Returns the date a presentation was last modified.
            Values are in UTC.P
            Csak olvasható a Presentation.DocumentProperties esetén (because it will be updated internally while IPresentation object saving process). 
            Módosítható a DocumentProperties instance returning by method [`IPresentationInfo.read_document_properties`](/slides/python-net/hu/aspose.slides/ipresentationinfo/read_document_properties)
            Lásd a példát az **Aspose.Slides.IPresentationInfo.UpdateDocumentProperties(Aspose.Slide** metódus összefoglalójában.
