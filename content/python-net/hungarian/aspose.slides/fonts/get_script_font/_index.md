## get_script_font(self, script) {#str}
Visszaadja a prezentációs sablonhoz kapcsolódó adott script címkéhez társított betűtípus nevét.

### Visszatérési érték

A megadott scripthez használt betűtípus neve, vagy `None`, ha a script nincs definiálva.



```python
def get_script_font(self, script):
    ...
```


| Paraméter | Típus | Leírás |
| :- | :- | :- |
| script | **str** | A BCP-47 script kód (például "Latn", "Cyrl", "Jpan"), amely egy írásrendszert azonosít. |
