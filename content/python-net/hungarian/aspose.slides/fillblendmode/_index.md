## FillBlendMode enumeráció

Meghatározza a keverési módot.

A FillBlendMode típus a következő tagokat teszi közzé:

## Mezők

| Mező | Leírás |
| :- | :- |
| DARKEN | Sötétítő keverési mód. |
| LIGHTEN | Világosító keverési mód. |
| MULTIPLY | Szorzó keverési mód. |
| OVERLAY | Átfedés keverési mód. |
| SCREEN | Képernyő keverési mód. |
