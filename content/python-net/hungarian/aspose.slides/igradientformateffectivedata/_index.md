## IGradientFormatEffectiveData osztály

Immutable objektum, amely a tényleges színátmenetes kitöltési tulajdonságokat tartalmazza.

Az IGradientFormatEffectiveData típus a következő tagokat teszi közzé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`tile_flip`](/slides/python-net/hu/aspose.slides/igradientformateffectivedata/tile_flip/) | Visszaadja egy színátmenet forgatási módját.<br/>            Csak olvasható [`TileFlip`](/slides/python-net/hu/aspose.slides/tileflip). |
| [`gradient_direction`](/slides/python-net/hu/aspose.slides/igradientformateffectivedata/gradient_direction/) | Visszaadja egy színátmenet stílusát.<br/>            Csak olvasható [`GradientDirection`](/slides/python-net/hu/aspose.slides/gradientdirection). |
| [`linear_gradient_angle`](/slides/python-net/hu/aspose.slides/igradientformateffectivedata/linear_gradient_angle/) | Visszaadja egy színátmenet szögét.<br/>            Csak olvasható **float**. |
| [`linear_gradient_scaled`](/slides/python-net/hu/aspose.slides/igradientformateffectivedata/linear_gradient_scaled/) | Megállapítja, hogy egy színátmenet méretezett-e.<br/>            Csak olvasható **bool**. |
| [`gradient_shape`](/slides/python-net/hu/aspose.slides/igradientformateffectivedata/gradient_shape/) | Visszaadja egy színátmenet alakját.<br/>            Csak olvasható [`GradientShape`](/slides/python-net/hu/aspose.slides/gradientshape). |
| [`gradient_stops`](/slides/python-net/hu/aspose.slides/igradientformateffectivedata/gradient_stops/) | Visszaadja a színátmenet állomások gyűjteményét.<br/>            Csak olvasható [`IGradientStopCollectionEffectiveData`](/slides/python-net/hu/aspose.slides/igradientstopcollectioneffectivedata). |


### Megjegyzés

Ez az interfész a [`IFillFormatEffectiveData`](/slides/python-net/hu/aspose.slides/ifillformateffectivedata) és a [`ILineFillFormatEffectiveData`](/slides/python-net/hu/aspose.slides/ilinefillformateffectivedata) részeként használatos.
