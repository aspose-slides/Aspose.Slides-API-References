## EffectFormat osztály

A forma effektus tulajdonságait képviseli.

| Tulajdonság | Leírás |
| :- | :- |
| [`is_no_effects`](/slides/python-net/hu/aspose.slides/effectformat/is_no_effects/) | Igaz értéket ad vissza, ha az összes effektus le van tiltva (újonnan létrehozott, alapértelmezett EffectFormat objektum).<br/>            Csak olvasható **bool**. |
| [`blur_effect`](/slides/python-net/hu/aspose.slides/effectformat/blur_effect/) | Elmosás effektus.<br/>            Olvasás/írás [`IBlur`](/slides/python-net/hu/aspose.slides.effects/iblur). |

| [`inner_shadow_effect`](/slides/python-net/hu/aspose.slides/effectformat/inner_shadow_effect/) | Belső árnyék.<br/>            Olvasás/írás [`IInnerShadow`](/slides/python-net/hu/aspose.slides.effects/iinnershadow). |
| [`outer_shadow_effect`](/slides/python-net/hu/aspose.slides/effectformat/outer_shadow_effect/) | Külső árnyék.<br/>            Olvasás/írás [`IOuterShadow`](/slides/python-net/hu/aspose.slides.effects/ioutershadow). |
| [`preset_shadow_effect`](/slides/python-net/hu/aspose.slides/effectformat/preset_shadow_effect/) | Előre beállított árnyék.<br/>            Olvasás/írás [`IPresetShadow`](/slides/python-net/hu/aspose.slides.effects/ipresetshadow). |
| [`reflection_effect`](/slides/python-net/hu/aspose.slides/effectformat/reflection_effect/) | Tükröződés. <br/>            Olvasás/írás [`IReflection`](/slides/python-net/hu/aspose.slides.effects/ireflection). |
| [`soft_edge_effect`](/slides/python-net/hu/aspose.slides/effectformat/soft_edge_effect/) | Lágy él.<br/>            Olvasás/írás [`ISoftEdge`](/slides/python-net/hu/aspose.slides.effects/isoftedge). |
