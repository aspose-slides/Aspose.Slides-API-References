## IHyperlinkQueries osztály

Egyszerű hozzáférést biztosít a tartalmazott hiperhivatkozásokhoz.

Az IHyperlinkQueries típus a következő tagokat teszi elérhetővé:

## Módszerek

| Módszer | Leírás |
| :- | :- |
| [`get_hyperlink_clicks(self)`](/slides/python-net/hu/aspose.slides/ihyperlinkqueries/get_hyperlink_clicks/#) | Szerezze meg az összes IHyperlinkContainer alobjektumot, amely nem None HyperlinkClick-et tartalmaz.<br/>            A megadott IHyperlinkContainer objektummal kezelheti a hiperhivatkozását (olvasás, frissítés vagy eltávolítás). Lásd az IHyperlinkContainer interfészt. |
| [`get_hyperlink_mouse_overs(self)`](/slides/python-net/hu/aspose.slides/ihyperlinkqueries/get_hyperlink_mouse_overs/#) | Szerezze meg az összes IHyperlinkContainer alobjektumot, amely nem None HyperlinkMouseOver-et tartalmaz.<br/>            A megadott IHyperlinkContainer objektummal kezelheti a hiperhivatkozását (olvasás, frissítés vagy eltávolítás). Lásd az IHyperlinkContainer interfészt. |
| [`get_any_hyperlinks(self)`](/slides/python-net/hu/aspose.slides/ihyperlinkqueries/get_any_hyperlinks/#) | Szerezze meg az összes IHyperlinkContainer alobjektumot, amely nem None HyperlinkMouseOver-et tartalmaz.<br/>            A megadott IHyperlinkContainer objektummal kezelheti a hiperhivatkozását (olvasás, frissítés vagy eltávolítás). Lásd az IHyperlinkContainer interfészt. |
| [`remove_all_hyperlinks(self)`](/slides/python-net/hu/aspose.slides/ihyperlinkqueries/remove_all_hyperlinks/#) | Eltávolítja az összes tartalmazott HyperlinkClick és HyperlinkMouseOver hiperhivatkozást (az összes IHyperlinkContainer alobjektumban). |
