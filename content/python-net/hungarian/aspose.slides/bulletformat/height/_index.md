## height tulajdonság
Visszaadja vagy beállítja egy bekezdés bullet height értékét öröklődés nélkül.
            Value float.NaN determines that bullet inherits height from the first portion in the paragraph.
            Olvasás/írás **float**.


### Megjegyzések

A negatív height érték azt jelenti, hogy a height pontokban van megadva, és
            egy pozitív érték azt jelzi, hogy a height a környező szöveg százalékában van.
