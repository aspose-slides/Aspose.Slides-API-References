## ShapeThumbnailBounds felsorolás

A forma bélyegkép határainak típusainak felsorolása.

A ShapeThumbnailBounds típus a következő tagokat teszi közzé:

## Mezők

| Mező | Leírás |
| :- | :- |
| SLIDE | A forma bélyegkép mérete megegyezik a dia méretével.<br/>            A forma pozíciója mentésre kerül. |
| SHAPE | A forma bélyegkép mérete a forma határ téglalapjával lesz egyenlő<br/>            a forma körvonal beállításainak figyelembevételével. |
| APPEARANCE | A forma bélyegkép mérete a forma megjelenésével lesz egyenlő (a dia határain belül). <br/>            Lehetnek olyan esetek, amikor a forma megjelenése nem fér bele a forma határaiba. Például:<br/>            forgatás, éles szögű csonka illesztés, 3D hatások stb. |
