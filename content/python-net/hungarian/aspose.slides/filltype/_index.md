## FillType enumeráció

Megadja a különféle vizuális objektumok belső kitöltésének típusát.

A FillType típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| NOT_DEFINED | A kitöltés típusa nincs definiálva. |
| NO_FILL | Nincs alkalmazott kitöltés. |
| SOLID | Egyszínű színnel kitöltve. |
| GRADIENT | A kitöltés átmenetes. |
| PATTERN | Ismétlődő mintát alkalmaz a objektum kitöltésére. |
| PICTURE | Egyetlen képet használ az objektum kitöltésére. |
| GROUP | A vizuális objektum a csoport kitöltési tulajdonságait örökli. |
