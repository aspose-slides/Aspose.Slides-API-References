## IAdjustValue osztály

Egy geometriai alakzat beállítási értékét reprezentálja.
            Ezek az értékek befolyásolják az alakzat formáját.

Az IAdjustValue típus a következő elemeket teszi elérhetővé:

## Tulajdonságok

| Property | Description |
| :- | :- |
| [`raw_value`](/slides/python-net/hu/aspose.slides/iadjustvalue/raw_value/) | Visszaadja vagy beállítja a beállítási értéket „as is”.<br/>            Olvasás/írás **int**. |
| [`angle_value`](/slides/python-net/hu/aspose.slides/iadjustvalue/angle_value/) | Visszaadja vagy beállítja az értéket, fokban értelmezve a szöget.<br/>            Olvasás/írás **float**. |
| [`name`](/slides/python-net/hu/aspose.slides/iadjustvalue/name/) | Visszaadja ennek a beállítási értéknek a nevét.<br/>            Csak olvasható **str**. |
| [`type`](/slides/python-net/hu/aspose.slides/iadjustvalue/type/) | Visszaadja az alakzat beállításának típusát.<br/>            Csak olvasható [`ShapeAdjustmentType`](/slides/python-net/hu/aspose.slides/shapeadjustmenttype). |
