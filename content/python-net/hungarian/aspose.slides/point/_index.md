## Point osztály

Két egész x és y koordinátából álló rendezett párt képvisel, amely egy pontot definiál kétdimenziós síkban. Kompatibilis a .NET `System.Drawing.Point`-tal.

## Konstruktorok

| Constructor | Description |
| :- | :- |
| [`__init__(self, x=0, y=0)`](/slides/python-net/hu/aspose.slides/point/__init__/#int-int) | Létrehozza a pontot a megadott koordinátákkal. A lebegőpontos értékek egész számra lesznek csonkítva. |

## Tulajdonságok

| Property | Description |
| :- | :- |
| [`x`](/slides/python-net/hu/aspose.slides/point/x/) | Lekéri vagy beállítja ennek a pontnak az x-koordinátáját.<br/>            Olvasás/írás **int**. |
| [`y`](/slides/python-net/hu/aspose.slides/point/y/) | Lekéri vagy beállítja ennek a pontnak az y-koordinátáját.<br/>            Olvasás/írás **int**. |
