## ICaptions osztály

Képviseli a WebVTT zárt feliratokat.

Az ICaptions típus a következő tagokat teszi közzé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`caption_id`](/slides/python-net/hu/aspose.slides/icaptions/caption_id/) | Visszaadja a feliratok globálisan egyedi azonosítóját (GUID).<br/>            Csak olvasható **System.Guid**. |
| [`label`](/slides/python-net/hu/aspose.slides/icaptions/label/) | Visszaadja vagy beállítja a feliratok címkéjét.<br/>            Olvasás/írás **str**. |
| [`binary_data`](/slides/python-net/hu/aspose.slides/icaptions/binary_data/) | Visszaadja a feliratok bináris adatait.<br/>            Csak olvasható **int**[]. |
| [`data_as_string`](/slides/python-net/hu/aspose.slides/icaptions/data_as_string/) | Visszaadja a feliratok adatait UTF-8 kódolású karakterláncként<br/>            Csak olvasható **str**. |
