## ITextHighlightingOptions osztály

A szövegdobozban lévő szöveg kiemelésére használható beállításokat képviseli.

Az ITextHighlightingOptions típus a következő tagokat teszi közzé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`case_sensitive`](/slides/python-net/hu/aspose.slides/itexthighlightingoptions/case_sensitive/) | Állítsa true értékre a nagybetűérzékeny kereséshez, false – egyébként.<br/>            Read/write **bool**. |
| [`whole_words_only`](/slides/python-net/hu/aspose.slides/itexthighlightingoptions/whole_words_only/) | Állítsa true értékre, ha csak egész szavakra szeretne egyezni, false – egyébként.<br/>            Read/write **bool**. |
