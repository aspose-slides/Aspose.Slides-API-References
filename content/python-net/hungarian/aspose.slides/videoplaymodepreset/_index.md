## VideoPlayModePreset enumeráció

Azok a konstansok, amelyek meghatározzák, hogyan játszódik le egy videó.

A VideoPlayModePreset típus a következő tagokat teszi elérhetővé:

## Mezők

| Mező | Leírás |
| :- | :- |
| MIXED |  |
| AUTO | Automatikus lejátszás. |
| ON_CLICK | Csak akkor játszik le, amikor a videókeretre kattintanak. |
| ALL_SLIDES | Lejátszás minden dián. |
| IN_CLICK_SEQUENCE | Automatikus lejátszás egy kattintással. |
