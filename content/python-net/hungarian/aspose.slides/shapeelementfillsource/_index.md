## ShapeElementFillSource enumeráció

Azt jelenti, hogyan kell kitölteni a shape elemet.

A ShapeElementFillSource típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| NO_FILL | Nem tölti ki a primitívet. |
| SHAPE | A shape kitöltését használja. |
| LIGHTEN | A shape kitöltésének világosítását használja. |
| LIGHTEN_LESS | Kevesebb világosítással használja a shape kitöltését. |
| DARKEN | A shape kitöltésének sötétítését használja. |
| DARKEN_LESS | Kevesebb sötétítéssel használja a shape kitöltését. |
