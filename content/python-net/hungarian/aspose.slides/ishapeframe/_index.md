## IShapeFrame osztály

A shape frame tulajdonságait reprezentálja.

Az IShapeFrame típus a következő tagokat teszi közzé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`x`](/slides/python-net/hu/aspose.slides/ishapeframe/x/) | Visszaadja egy keret bal felső sarkának X koordinátáját.<br/>            Csak olvasható **float**. |
| [`y`](/slides/python-net/hu/aspose.slides/ishapeframe/y/) | Visszaadja egy keret bal felső sarkának Y koordinátáját.<br/>            Csak olvasható **float**. |
| [`width`](/slides/python-net/hu/aspose.slides/ishapeframe/width/) | Visszaadja egy keret szélességét.<br/>            Csak olvasható **float**. |
| [`height`](/slides/python-net/hu/aspose.slides/ishapeframe/height/) | Visszaadja egy keret magasságát.<br/>            Csak olvasható **float**. |
| [`rotation`](/slides/python-net/hu/aspose.slides/ishapeframe/rotation/) | Visszaadja a keret z-tengely körüli forgatásának fokszámát.<br/>            A pozitív érték az óramutató járásával megegyező forgást jelzi; egy negatív érték<br/>            az óramutató járásával ellentétes forgást.<br/>            Csak olvasható **float**. |
| [`center_x`](/slides/python-net/hu/aspose.slides/ishapeframe/center_x/) | Visszaadja egy keret középpontjának X koordinátáját.<br/>            Csak olvasható **float**. |
| [`center_y`](/slides/python-net/hu/aspose.slides/ishapeframe/center_y/) | Visszaadja egy keret középpontjának Y koordinátáját.<br/>            Csak olvasható **float**. |
| [`flip_h`](/slides/python-net/hu/aspose.slides/ishapeframe/flip_h/) | Meghatározza, hogy egy keret vízszintesen van-e tükrözve.<br/>            Csak olvasható [`NullableBool`](/slides/python-net/hu/aspose.slides/nullablebool). |
| [`flip_v`](/slides/python-net/hu/aspose.slides/ishapeframe/flip_v/) | Meghatározza, hogy egy keret függőlegesen van-e tükrözve.<br/>            Csak olvasható [`NullableBool`](/slides/python-net/hu/aspose.slides/nullablebool). |
| [`rectangle`](/slides/python-net/hu/aspose.slides/ishapeframe/rectangle/) | Visszaadja egy keret koordinátáit.<br/>            Csak olvasható **aspose.slides.RectangleF**. |
