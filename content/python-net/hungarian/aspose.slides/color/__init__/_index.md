| Paraméter | Típus | Leírás |
| :- | :- | :- |
| r | **int** | A piros komponens értéke. Érvényes értékek 0 és 255 között. |
| g | **int** | A zöld komponens értéke. Érvényes értékek 0 és 255 között. |
