## from_rgb(r, g, b) {#int-int-int}
Létrehoz egy átlátszatlan színt (az alfa értéke 255) a megadott vörös, zöld és kék értékekből.

### Visszatérési érték

A megadott értékekből létrehozott szín.



```python
@staticmethod
def from_rgb(r, g, b):
    ...
```


| Paraméter | Típus | Leírás |
| :- | :- | :- |
| r | **int** | A vörös komponens értéke. A megengedett értékek 0-tól 255-ig terjednek. |
| g | **int** | A zöld komponens értéke. A megengedett értékek 0-tól 255-ig terjednek. |
| b | **int** | A kék komponens értéke. A megengedett értékek 0-tól 255-ig terjednek. |

### Kivételek

| Kivétel | Leírás |
| :- | :- |
| **ValueError** | Egy komponens értéke kisebb, mint 0 vagy nagyobb, mint 255. |
