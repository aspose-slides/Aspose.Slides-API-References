## ICellFormat osztály

A táblázat cella formátumát képviseli.

Az ICellFormat típus a következő tagokat teszi elérhetővé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`fill_format`](/slides/python-net/hu/aspose.slides/icellformat/fill_format/) | Visszaad egy cella kitöltés tulajdonságok objektumot.<br/>            Csak olvasható [`IFillFormat`](/slides/python-net/hu/aspose.slides/ifillformat). |
| [`border_left`](/slides/python-net/hu/aspose.slides/icellformat/border_left/) | Visszaad egy bal szegély vonal tulajdonságok objektumot.<br/>            Csak olvasható [`ILineFormat`](/slides/python-net/hu/aspose.slides/ilineformat). |
| [`border_top`](/slides/python-net/hu/aspose.slides/icellformat/border_top/) | Visszaad egy felső szegély vonal tulajdonságok objektumot.<br/>            Csak olvasható [`ILineFormat`](/slides/python-net/hu/aspose.slides/ilineformat). |
| [`border_right`](/slides/python-net/hu/aspose.slides/icellformat/border_right/) | Visszaad egy jobb szegély vonal tulajdonságok objektumot.<br/>            Csak olvasható [`ILineFormat`](/slides/python-net/hu/aspose.slides/ilineformat). |
| [`border_bottom`](/slides/python-net/hu/aspose.slides/icellformat/border_bottom/) | Visszaad egy alsó szegély vonal tulajdonságok objektumot.<br/>            Csak olvasható [`ILineFormat`](/slides/python-net/hu/aspose.slides/ilineformat). |
| [`border_diagonal_down`](/slides/python-net/hu/aspose.slides/icellformat/border_diagonal_down/) | Visszaad egy bal felső-jobb alsó átló tulajdonságok objektumot.<br/>            Csak olvasható [`ILineFormat`](/slides/python-net/hu/aspose.slides/ilineformat). |
| [`border_diagonal_up`](/slides/python-net/hu/aspose.slides/icellformat/border_diagonal_up/) | Visszaad egy bal alsó-jobb felső átló tulajdonságok objektumot.<br/>            Csak olvasható [`ILineFormat`](/slides/python-net/hu/aspose.slides/ilineformat). |
| [`transparency`](/slides/python-net/hu/aspose.slides/icellformat/transparency/) | Lekéri vagy beállítja a kitöltési szín átlátszóságát.<br/>            Olvasás/írás **float**. |
