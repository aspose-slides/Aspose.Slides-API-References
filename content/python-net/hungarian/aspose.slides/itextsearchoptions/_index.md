## ITextSearchOptions osztály

Az opciókat képviseli, amelyeket egy Presentation, Slide vagy TextFrame szövegének keresésére lehet használni.

Az ITextSearchOptions típus a következő tagokat teszi elérhetővé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`case_sensitive`](/slides/python-net/hu/aspose.slides/itextsearchoptions/case_sensitive/) | Állítsa true-ra a kis- és nagybetűkre érzékeny kereséshez, false - egyébként.<br/>            Olvasás/írás **bool**. |
| [`whole_words_only`](/slides/python-net/hu/aspose.slides/itextsearchoptions/whole_words_only/) | Állítsa true-ra, hogy csak teljes szavakat egyeztesse, false - egyébként.<br/>            Olvasás/írás **bool**. |
| [`include_notes`](/slides/python-net/hu/aspose.slides/itextsearchoptions/include_notes/) | Állítsa `true`-ra a dia megjegyzéseiben lévő szöveg bevonásához <br/>            szövegkeresés, csere vagy kiemelés műveletek végrehajtásakor.<br/>            Az alapértelmezett érték `false`. |
