## ImageFormat enumeráció

A kép fájlformátumát ábrázolja.

Az ImageFormat típus a következő tagokat teszi közzé:

## Mezők

| Mező | Leírás |
| :- | :- |
| MEMORY_BMP | A memóriában lévő bitmap formátumát ábrázolja. |
| BMP | A bitmap (BMP) képfájltípust ábrázolja. |
| EMF | A bővített metafájl (EMF) képfájltípust ábrázolja. |
| WMF | A Windows metafájl (WMF) képfájltípust ábrázolja. |
| GIF | A Graphics Interchange Format (GIF) képfájltípust ábrázolja. |
| JPEG | A Joint Photographic Experts Group (JPEG) képfájltípust ábrázolja. |
| PNG | A W3C Portable Network Graphics (PNG) képfájltípust ábrázolja. |
| TIFF | A Tagged Image File Format (TIFF) képfájltípust ábrázolja. |
| EXIF | Az Exchangeable Image File (Exif) formátumot ábrázolja. |
| ICON | A Windows ikon képfájltípust ábrázolja. |
