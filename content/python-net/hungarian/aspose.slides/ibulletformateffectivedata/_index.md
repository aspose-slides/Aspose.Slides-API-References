## IBulletFormatEffectiveData osztály

Megváltoztathatatlan objektum, amely a hatékony bekezdés bullet formázási tulajdonságokat tartalmaz.

Az IBulletFormatEffectiveData típus a következő tagokat teszi közzé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`type`](/slides/python-net/hu/aspose.slides/ibulletformateffectivedata/type/) | Visszaadja a bekezdés bullet típusát.<br/>            Csak olvasható [`BulletType`](/slides/python-net/hu/aspose.slides/bullettype). |
| [`char`](/slides/python-net/hu/aspose.slides/ibulletformateffectivedata/char/) | Visszaadja a bekezdés bullet karakterét.<br/>            Csak olvasható **System.Char**. |
| [`actual_bullet_value`](/slides/python-net/hu/aspose.slides/ibulletformateffectivedata/actual_bullet_value/) | Visszaadja a szülő bekezdés tényleges bullet értékét.<br/>            Csak olvasható **str**. |
| [`font`](/slides/python-net/hu/aspose.slides/ibulletformateffectivedata/font/) | Visszaadja a bekezdés bullet betűtípusát.<br/>            Csak olvasható [`IFontData`](/slides/python-net/hu/aspose.slides/ifontdata). |
| [`height`](/slides/python-net/hu/aspose.slides/ibulletformateffectivedata/height/) | Visszaadja a bekezdés bullet magasságát.<br/>            Csak olvasható **float**. |
| [`numbered_bullet_start_with`](/slides/python-net/hu/aspose.slides/ibulletformateffectivedata/numbered_bullet_start_with/) | Visszaadja az első számot, amely a számozott bullet csoportokhoz használatos.<br/>            Csak olvasható **int**. |
| [`numbered_bullet_style`](/slides/python-net/hu/aspose.slides/ibulletformateffectivedata/numbered_bullet_style/) | Visszaadja a számozott bullet stílusát.<br/>            Csak olvasható [`NumberedBulletStyle`](/slides/python-net/hu/aspose.slides/numberedbulletstyle). |
| [`is_bullet_hard_color`](/slides/python-net/hu/aspose.slides/ibulletformateffectivedata/is_bullet_hard_color/) | Megállapítja, hogy a bullet saját színt használ-e, vagy az örökli a bekezdés első résztől.<br/>            Visszaad **true**  ha a bullet saját színt használ, és **false**  ha a bullet a bekezdés első részétől örököl színt.<br/>            Csak olvasható **bool**. |
| [`is_bullet_hard_font`](/slides/python-net/hu/aspose.slides/ibulletformateffectivedata/is_bullet_hard_font/) | Megállapítja, hogy a bullet saját betűtípust használ-e, vagy az örökli a bekezdés első résztől.<br/>            Visszaad **true**  ha a bullet saját betűtípust használ, és **true**  ha a bullet a bekezdés első részétől örököl betűtípust.<br/>            Csak olvasható **bool**. |
| [`picture`](/slides/python-net/hu/aspose.slides/ibulletformateffectivedata/picture/) | Visszaadja a bekezdésben bulletként használt képet.<br/>            Csak olvasható [`IPictureEffectiveData`](/slides/python-net/hu/aspose.slides/ipictureeffectivedata). |
| [`fill_format`](/slides/python-net/hu/aspose.slides/ibulletformateffectivedata/fill_format/) | Visszaadja a bekezdés bullet kitöltési formátumát.<br/>            Csak olvasható [`IFillFormatEffectiveData`](/slides/python-net/hu/aspose.slides/ifillformateffectivedata). |
