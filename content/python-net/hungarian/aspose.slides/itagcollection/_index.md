## ITagCollection osztály

A címkék (felhasználó által definiált karakterlánc párok) gyűjteményét reprezentálja

Az ITagCollection típus a következő tagokat tartalmazza:

## Módszerek

| Módszer | Leírás |
| :- | :- |
| [`add(self, name, value)`](/slides/python-net/hu/aspose.slides/itagcollection/add/#str-str) | Új címkét ad a gyűjteményhez. |
| [`remove(self, name)`](/slides/python-net/hu/aspose.slides/itagcollection/remove/#str) | Eltávolítja a megadott névvel rendelkező címkét a gyűjteményből. |
| [`index_of_name(self, name)`](/slides/python-net/hu/aspose.slides/itagcollection/index_of_name/#str) | Visszaadja a megadott kulcs nullától kezdődő indexét a gyűjteményben. |
| [`remove_at(self, index)`](/slides/python-net/hu/aspose.slides/itagcollection/remove_at/#int) | Eltávolítja a megadott indexen lévő címkét. |
| [`clear(self)`](/slides/python-net/hu/aspose.slides/itagcollection/clear/#) | Eltávolítja az összes címkét a gyűjteményből. |
| [`get_value_by_index(self, index)`](/slides/python-net/hu/aspose.slides/itagcollection/get_value_by_index/#int) | Visszaadja egy címke értékét a megadott indexen. |
| [`get_name_by_index(self, index)`](/slides/python-net/hu/aspose.slides/itagcollection/get_name_by_index/#int) | Visszaadja egy címke kulcsát a megadott indexen. |
| [`get_names_of_tags(self)`](/slides/python-net/hu/aspose.slides/itagcollection/get_names_of_tags/#) | Visszaadja a címkék neveit. |
