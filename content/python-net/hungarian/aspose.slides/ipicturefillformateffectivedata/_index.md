## IPictureFillFormatEffectiveData osztály

Módosíthatatlan objektum, amely a kép kitöltésének tulajdonságait tartalmazza.

Az IPictureFillFormatEffectiveData típus a következő tagokat teszi elérhetővé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`dpi`](/slides/python-net/hu/aspose.slides/ipicturefillformateffectivedata/dpi/) | Visszaadja a képet kitöltéshez használt DPI értéket.<br/>            Csak olvasható **int**. |
| [`picture_fill_mode`](/slides/python-net/hu/aspose.slides/ipicturefillformateffectivedata/picture_fill_mode/) | Visszaadja a kép kitöltési módot.<br/>            Csak olvasható [`PictureFillMode`](/slides/python-net/hu/aspose.slides/picturefillmode). |
| [`picture`](/slides/python-net/hu/aspose.slides/ipicturefillformateffectivedata/picture/) | Visszaadja a képet.<br/>            Csak olvasható [`IPictureEffectiveData`](/slides/python-net/hu/aspose.slides/ipictureeffectivedata). |
| [`crop_left`](/slides/python-net/hu/aspose.slides/ipicturefillformateffectivedata/crop_left/) | Visszaadja a valós kép szélességének százalékos arányát, amely levágásra kerül a kép bal oldalán.<br/>            Csak olvasható **float**. |
| [`crop_top`](/slides/python-net/hu/aspose.slides/ipicturefillformateffectivedata/crop_top/) | Visszaadja a valós kép magasságának százalékos arányát, amely levágásra kerül a kép tetején.<br/>            Csak olvasható **float**. |
| [`crop_right`](/slides/python-net/hu/aspose.slides/ipicturefillformateffectivedata/crop_right/) | Visszaadja a valós kép szélességének százalékos arányát, amely levágásra kerül a kép jobb oldalán.<br/>            Csak olvasható **float**. |
| [`crop_bottom`](/slides/python-net/hu/aspose.slides/ipicturefillformateffectivedata/crop_bottom/) | Visszaadja a valós kép magasságának százalékos arányát, amely levágásra kerül a kép alján.<br/>            Csak olvasható **float**. |
