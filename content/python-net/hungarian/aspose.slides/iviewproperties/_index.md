## IViewProperties osztály

A prezentációra kiterjedő nézet tulajdonságok.

Az IViewProperties típus a következő tagokat teszi közzé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`last_view`](/slides/python-net/hu/aspose.slides/iviewproperties/last_view/) | Megadja a nézetmódot, amelyet a prezentációs dokumentum legutóbbi mentésekor használtak.<br/>            Olvasás/írás [`ViewType`](/slides/python-net/hu/aspose.slides/viewtype). |
| [`show_comments`](/slides/python-net/hu/aspose.slides/iviewproperties/show_comments/) | Megadja, hogy a diákhoz tartozó megjegyzéseket meg kell-e jeleníteni.<br/>            Olvasás/írás [`NullableBool`](/slides/python-net/hu/aspose.slides/nullablebool). |
| [`slide_view_properties`](/slides/python-net/hu/aspose.slides/iviewproperties/slide_view_properties/) | Megadja a dianézet módhoz társított általános nézettulajdonságokat.<br/>            Csak olvasás [`ICommonSlideViewProperties`](/slides/python-net/hu/aspose.slides/icommonslideviewproperties). |
| [`notes_view_properties`](/slides/python-net/hu/aspose.slides/iviewproperties/notes_view_properties/) | Megadja a jegyzetek nézet módhoz társított általános nézettulajdonságokat.<br/>            Csak olvasás [`ICommonSlideViewProperties`](/slides/python-net/hu/aspose.slides/icommonslideviewproperties). |
| [`normal_view_properties`](/slides/python-net/hu/aspose.slides/iviewproperties/normal_view_properties/) | Képviseli a normál nézet tulajdonságait. A normál nézet három tartalmi területből áll:<br/>            a diából, egy oldalsó tartalmi területből és egy alsó tartalmi területből.<br/>            Csak olvasás [`INormalViewProperties`](/slides/python-net/hu/aspose.slides/inormalviewproperties). |
| [`grid_spacing`](/slides/python-net/hu/aspose.slides/iviewproperties/grid_spacing/) | Visszaadja vagy beállítja a rács távolságát, amelyet a prezentációs dokumentum alatti rácshoz kell használni, pontban. <br/>            Olvasás/írás **float**. |
