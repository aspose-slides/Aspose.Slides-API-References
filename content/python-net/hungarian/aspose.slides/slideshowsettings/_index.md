## SlideShowSettings osztály

A prezentáció diavetítésének beállításait reprezentálja.

A SlideShowSettings típus a következő tagokat teszi közzé:

## Tulajdonságok

| Property | Description |
| :- | :- |
| [`slide_show_type`](/slides/python-net/hu/aspose.slides/slideshowsettings/slide_show_type/) | Lekérdezi vagy beállítja a diavetítés típusát. A következő [`SlideShowSettings.slide_show_type`](/slides/python-net/hu/aspose.slides/slideshowsettings/slide_show_type) ősök képviselik: [`BrowsedAtKiosk`](/slides/python-net/hu/aspose.slides/browsedatkiosk), [`PresentedBySpeaker`](/slides/python-net/hu/aspose.slides/presentedbyspeaker) és [`BrowsedByIndividual`](/slides/python-net/hu/aspose.slides/browsedbyindividual) |
| [`loop`](/slides/python-net/hu/aspose.slides/slideshowsettings/loop/) | Diavetítés ismétlése |
| [`show_narration`](/slides/python-net/hu/aspose.slides/slideshowsettings/show_narration/) | Narráció megjelenítése a diavetítésben |
| [`show_animation`](/slides/python-net/hu/aspose.slides/slideshowsettings/show_animation/) | Animáció megjelenítése a diavetítésben |
| [`pen_color`](/slides/python-net/hu/aspose.slides/slideshowsettings/pen_color/) | Tollszín a diavetítéshez |
| [`slides`](/slides/python-net/hu/aspose.slides/slideshowsettings/slides/) | Diák tartománya |
| [`use_timings`](/hu/slides/python-net/aspose.slides/slideshowsettings/use_timings/) | Időzítések használata a diavetítésben |
| [`show_media_controls`](/slides/python-net/hu/aspose.slides/slideshowsettings/show_media_controls/) | Média vezérlők megjelenítése |
