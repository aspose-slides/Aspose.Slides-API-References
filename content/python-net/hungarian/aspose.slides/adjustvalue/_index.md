## AdjustValue osztály

A geometriai alakzat beállítási értékét reprezentálja.
            Ezek az értékek befolyásolják az alakzat formáját.

Az AdjustValue típus a következő tagokat teszi elérhetővé:

## Tulajdonságok

| Property | Description |
| :- | :- |
| [`raw_value`](/slides/python-net/hu/aspose.slides/adjustvalue/raw_value/) | Visszaadja vagy beállítja a beállítási értéket "ahogy van".<br/>            Olvasás/írás **int**. |
| [`angle_value`](/slides/python-net/hu/aspose.slides/adjustvalue/angle_value/) | Visszaadja vagy beállítja az értéket, fokban kifejezett szögeként értelmezve.<br/>            Olvasás/írás **float**. |
| [`name`](/slides/python-net/hu/aspose.slides/adjustvalue/name/) | Visszaadja ennek a beállítási értéknek a nevét.<br/>            Csak olvasható **str**. |
| [`type`](/slides/python-net/hu/aspose.slides/adjustvalue/type/) | Visszaadja a forma beállításának típusát.<br/>            Csak olvasható [`ShapeAdjustmentType`](/slides/python-net/hu/aspose.slides/shapeadjustmenttype). |
