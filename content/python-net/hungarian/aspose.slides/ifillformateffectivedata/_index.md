## IFillFormatEffectiveData osztály

Módosíthatatlan objektum, amely hatékony kitöltési formázási tulajdonságokat tartalmaz.

Az IFillFormatEffectiveData típus a következő tagokat teszi közzé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`fill_type`](/slides/python-net/hu/aspose.slides/ifillformateffectivedata/fill_type/) | Visszaadja a kitöltés típusát.<br/>            Csak olvasható [`FillType`](/slides/python-net/hu/aspose.slides/filltype). |
| [`solid_fill_color`](/slides/python-net/hu/aspose.slides/ifillformateffectivedata/solid_fill_color/) | Visszaadja a kitöltés színét.<br/>            Csak olvasható [`Color`](/slides/python-net/hu/aspose.slides/color). |
| [`solid_fill_scheme_color`](/slides/python-net/hu/aspose.slides/ifillformateffectivedata/solid_fill_scheme_color/) | Megkapja a színséma által meghatározott kitöltési színt.<br/>            A [`SchemeColor.NOT_DEFINED`](/slides/python-net/hu/aspose.slides/schemecolor/NOT_DEFINED) érték jelzi, hogy a [`IFillFormatEffectiveData.solid_fill_color`](/slides/python-net/hu/aspose.slides/ifillformateffectivedata/solid_fill_color) <br/>            nem egy sémaszín.<br/>            Csak olvasható [`SchemeColor`](/slides/python-net/hu/aspose.slides/schemecolor). |
| [`gradient_format`](/slides/python-net/hu/aspose.slides/ifillformateffectivedata/gradient_format/) | Visszaadja a színátmenetes kitöltés formátumát.<br/>            Csak olvasható [`IGradientFormatEffectiveData`](/slides/python-net/hu/aspose.slides/igradientformateffectivedata). |
| [`pattern_format`](/slides/python-net/hu/aspose.slides/ifillformateffectivedata/pattern_format/) | Visszaadja a mintás kitöltés formátumát.<br/>            Csak olvasható [`IPatternFormatEffectiveData`](/slides/python-net/hu/aspose.slides/ipatternformateffectivedata). |
| [`picture_fill_format`](/slides/python-net/hu/aspose.slides/ifillformateffectivedata/picture_fill_format/) | Visszaadja a kép kitöltés formátumát.<br/>            Csak olvasható [`IPictureFillFormatEffectiveData`](/slides/python-net/hu/aspose.slides/ipicturefillformateffectivedata). |
| [`rotate_with_shape`](/slides/python-net/hu/aspose.slides/ifillformateffectivedata/rotate_with_shape/) | Megállapítja, hogy a kitöltést el kell-e forgatni a formával.<br/>            Csak olvasható **bool**. |

### Megjegyzések

Ez az interfész a [`IFillFormat`](/slides/python-net/hu/aspose.slides/ifillformat) interfésszel együtt használható a hatékony formázási értékek visszaadásához öröklődés alkalmazásával.
