## Background osztály

Representálja egy dia háttérét.

**Inheritance:**[`Background`](/slides/python-net/hu/aspose.slides/background) → [`PVIObject`](/slides/python-net/hu/aspose.slides/pviobject)

A Background típus a következő tagokat teszi közzé:

## Tulajdonságok

| Property | Description |
| :- | :- |
| [`type`](/slides/python-net/hu/aspose.slides/background/type/) | Visszaad egy háttérkitöltés típusát.<br/>            Írás/olvasás [`BackgroundType`](/slides/python-net/hu/aspose.slides/backgroundtype). |
| [`fill_format`](/slides/python-net/hu/aspose.slides/background/fill_format/) | Visszaad egy FillFormat-ot a BackgroundType.OwnBackground kitöltéshez.<br/>            Csak olvasható [`IFillFormat`](/slides/python-net/hu/aspose.slides/ifillformat). |
| [`effect_format`](/slides/python-net/hu/aspose.slides/background/effect_format/) | Visszaad egy EffectFormat-ot a BackgroundType.OwnBackground kitöltéshez.<br/>            Csak olvasható [`IEffectFormat`](/slides/python-net/hu/aspose.slides/ieffectformat). |
| [`style_color`](/slides/python-net/hu/aspose.slides/background/style_color/) | Visszaad egy ColorFormat-ot egy BackgroundType.Themed kitöltéshez.<br/>            Csak olvasható [`IColorFormat`](/slides/python-net/hu/aspose.slides/icolorformat). |
| [`style_index`](/slides/python-net/hu/aspose.slides/background/style_index/) | Visszaad egy indexet a BackgroundType.Themed kitöltéshez a háttértéma gyűjteményben.<br/>            A 0 jelentése nincs kitöltés.<br/>            1..999 - index.<br/>            Írás/olvasás **int**. |
| [`slide`](/slides/python-net/hu/aspose.slides/background/slide/) | Visszaad a forma szülő diaját.<br/>            Csak olvasható [`IBaseSlide`](/slides/python-net/hu/aspose.slides/ibaseslide). |
| [`presentation`](/slides/python-net/hu/aspose.slides/background/presentation/) | Visszaad a dia szülő prezentációját.<br/>            Csak olvasható [`IPresentation`](/slides/python-net/hu/aspose.slides/ipresentation). |
