## ShapesAlignmentType enumeráció

Meghatároz egy módot a kijelölt alakzatok elhelyezésének megváltoztatására a dián.

A ShapesAlignmentType típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| ALIGN_LEFT | Balra igazítás |
| ALIGN_RIGHT | Jobbra igazítás |
| ALIGN_CENTER | Középre igazítás |
| ALIGN_TOP | Felülre igazítás |
| ALIGN_MIDDLE | Középre igazítás |
| ALIGN_BOTTOM | Alulra igazítás |
| DISTRIBUTE_HORIZONTALLY | Vízszintesen elosztás |
| DISTRIBUTE_VERTICALLY | Függőlegesen elosztás |
