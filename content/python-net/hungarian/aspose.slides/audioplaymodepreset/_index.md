## AudioPlayModePreset enumeráció

A hang lejátszásának módját meghatározó állandók.

Az AudioPlayModePreset típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| MIXED |  |
| AUTO | Automatikusan lejátszódik. |
| ON_CLICK | Csak akkor játszódik le, ha az ikonra kattintanak. |
| ALL_SLIDES | Minden dián lejátszódik.<br/>            Kérjük, helyette használja a [`IAudioFrame.play_across_slides`](/slides/python-net/hu/aspose.slides/iaudioframe/play_across_slides) tulajdonságot.<br/>            Ez az elem elavult a PowerPoint 2013 óta. |
| IN_CLICK_SEQUENCE | Automatikusan játszódik egy kattintással. |
