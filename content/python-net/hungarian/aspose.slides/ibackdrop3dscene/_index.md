## IBackdrop3DScene osztály

Meghatároz egy síkot, amelyen a fénykibújás és az árnyékhoz hasonló hatások a rájuk alkalmazott alakzathoz viszonyítva kerülnek alkalmazásra.

Az IBackdrop3DScene típus a következő tagokat tartalmazza:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`normal_vector`](/slides/python-net/hu/aspose.slides/ibackdrop3dscene/normal_vector/) | Visszaad vagy beállít egy normál vektort. Pontosabban, ez az attribútum egy a háttér sík felületére merőleges vektort határoz meg. <br/>            Vector represented by array of 3 float values<br/>            which define X, Y and Z coordinates.<br/>            Olvasás/írás **float**[]. |
| [`anchor_point`](/slides/python-net/hu/aspose.slides/ibackdrop3dscene/anchor_point/) | Visszaad vagy beállít egy pontot a 3D térben. Ez a pont a háttér síkot rögzítő pont a térben.<br/>            3D point represented by array of 3 float values which define X, Y and Z coordinates.<br/>            Olvasás/írás **float**[]. |
| [`up_vector`](/slides/python-net/hu/aspose.slides/ibackdrop3dscene/up_vector/) | Visszaad vagy beállít egy felfelé irányt jelző vektort.
