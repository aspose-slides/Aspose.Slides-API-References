## TabAlignment enumeráció

A tabulátor igazítását reprezentálja.

A TabAlignment típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| LEFT | Bal igazítás |
| CENTER | Középre igazítás |
| RIGHT | Jobb igazítás |
| DECIMAL | Tizedes igazítás |
