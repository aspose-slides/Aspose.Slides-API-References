## ResourceLoadingAction enumeráció

Megadja a külső erőforrás betöltésének módját.

A ResourceLoadingAction típus a következő tagokat teszi közzé:

## Mezők

| Field | Description |
| :- | :- |
| DEFAULT | Az Aspose.Slides a külső erőforrást a szokásos módon tölti be. |
| SKIP | Az Aspose.Slides kihagyja a külső erőforrás betöltését. Csak a link adat nélkül lesz tárolva egy képhez. |
| USER_PROVIDED | Az Aspose.Slides a felhasználó által biztosított bájt tömböt fogja használni a **Aspose.Slides.IResourceLoadingArgs.SetData(Syste** képadatként. |
