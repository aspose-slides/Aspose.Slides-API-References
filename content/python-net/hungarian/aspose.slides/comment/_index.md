## Comment osztály

Egy dián lévő megjegyzést reprezentál.

A Comment típus a következő tagokat tartalmazza:

## Tulajdonságok

| Property | Description |
| :- | :- |
| [`text`](/slides/python-net/hu/aspose.slides/comment/text/) | Visszaadja vagy beállítja egy dia megjegyzés egyszerű szövegét.<br/>            Olvasás/írás **str**. |
| [`created_time`](/slides/python-net/hu/aspose.slides/comment/created_time/) | Visszaadja vagy beállítja a megjegyzés létrehozásának időpontját.<br/>            Ennek a tulajdonságnak **System.DateTime** értékre állítása azt jelenti, hogy nincs megjegyzés időpont beállítva.<br/>            Olvasás/írás **System.DateTime**. |
| [`slide`](/slides/python-net/hu/aspose.slides/comment/slide/) | Visszaadja vagy beállítja a megjegyzés szülődiáját.<br/>            Csak olvasható [`ISlide`](/slides/python-net/hu/aspose.slides/islide). |
| [`author`](/slides/python-net/hu/aspose.slides/comment/author/) | Visszaadja a megjegyzés szerzőjét.<br/>            Csak olvasható [`ICommentAuthor`](/slides/python-net/hu/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/hu/aspose.slides/comment/position/) | Visszaadja vagy beállítja a megjegyzés pozícióját egy dián.<br/>            Olvasás/írás **aspose.slides.PointF**. |
| [`parent_comment`](/slides/python-net/hu/aspose.slides/comment/parent_comment/) | Visszaadja vagy beállítja a szülő megjegyzést.<br/>            Olvasás/írás [`IComment`](/slides/python-net/hu/aspose.slides/icomment). |

## Metódusok

| Method | Description |
| :- | :- |
| [`remove(self)`](/slides/python-net/hu/aspose.slides/comment/remove/#) | Eltávolítja a megjegyzést és annak összes válaszát a szülő gyűjteményből. |
