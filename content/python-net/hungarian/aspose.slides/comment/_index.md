## Comment osztály

Egy dia megjegyzését reprezentálja.

A Comment típus a következő tagokat teszi közzé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`text`](/slides/python-net/hu/aspose.slides/comment/text/) | Visszaadja vagy beállítja egy dia megjegyzés egyszerű szövegét.<br/>            Olvasás/írás **str**. |
| [`created_time`](/slides/python-net/hu/aspose.slides/comment/created_time/) | Visszaadja vagy beállítja egy megjegyzés létrehozásának idejét.<br/>            Ennek a tulajdonságnak a **System.DateTime** értékre állítása azt jelenti, hogy nincs megjegyzés idő beállítva.<br/>            Olvasás/írás **System.DateTime**. |
| [`slide`](/slides/python-net/hu/aspose.slides/comment/slide/) | Visszaadja vagy beállítja egy megjegyzés szülődiáját.<br/>            Csak olvasható [`ISlide`](/slides/python-net/hu/aspose.slides/islide). |
| [`author`](/slides/python-net/hu/aspose.slides/comment/author/) | Visszaadja egy megjegyzés szerzőjét.<br/>            Csak olvasható [`ICommentAuthor`](/slides/python-net/hu/aspose.slides/icommentauthor). |
| [`position`](/slides/python-net/hu/aspose.slides/comment/position/) | Visszaadja vagy beállítja egy megjegyzés pozícióját a dián.<br/>            Olvasás/írás [`PointF`](/slides/python-net/hu/aspose.slides/pointf). |
| [`parent_comment`](/slides/python-net/hu/aspose.slides/comment/parent_comment/) | Visszaadja vagy beállítja a szülőmegjegyzést.<br/>            Olvasás/írás [`IComment`](/slides/python-net/hu/aspose.slides/icomment). |

## Metódusok

| Metódus | Leírás |
| :- | :- |
| [`remove(self)`](/slides/python-net/hu/aspose.slides/comment/remove/#) | Eltávolítja a megjegyzést és annak minden válaszát a szülőgyűjteményből. |
