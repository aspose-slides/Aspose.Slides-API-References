## Control osztály

ActiveX vezérlőt képvisel.

A Control típus a következő tagokat teszi közzé:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`persistence`](/slides/python-net/hu/aspose.slides/control/persistence/) | Azt a módszert adja vissza, amelyet az ActiveX vezérlő tulajdonságainak tárolására használnak.<br/>            Csak olvasható [`PersistenceType`](/slides/python-net/hu/aspose.slides/persistencetype). |
| [`name`](/slides/python-net/hu/aspose.slides/control/name/) | A vezérlő nevét adja vissza vagy állítja be.<br/>            Olvasás/írás **str**. |
| [`class_id`](/slides/python-net/hu/aspose.slides/control/class_id/) | A vezérlő osztályazonosítóját adja vissza.<br/>            Csak olvasható **System.Guid**. |
| [`substitute_picture_format`](/slides/python-net/hu/aspose.slides/control/substitute_picture_format/) | A Control kép kitöltésének tulajdonságait tartalmazó objektumot adja vissza.<br/>            Csak olvasható [`IPictureFillFormat`](/slides/python-net/hu/aspose.slides/ipicturefillformat). |
| [`frame`](/slides/python-net/hu/aspose.slides/control/frame/) | Visszaadja vagy beállítja a vezérlő keretét.<br/>            Olvasás/írás [`IShapeFrame`](/slides/python-net/hu/aspose.slides/ishapeframe). |
| [`properties`](/slides/python-net/hu/aspose.slides/control/properties/) | Az ActiveX tulajdonságok gyűjteményét adja vissza.<br/>            Megjegyzés: Az Aspose.Slides csak XML-alapú ActiveX tulajdonságokat támogat. Ha a tulajdonságok bináris formátumban vannak tárolva, ez a tulajdonság None értéket ad vissza.<br/>            Csak olvasható [`IControlPropertiesCollection`](/slides/python-net/hu/aspose.slides/icontrolpropertiescollection). |
| [`active_x_control_binary`](/slides/python-net/hu/aspose.slides/control/active_x_control_binary/) | Meghatározza egy ActiveX vezérlő állandó tárolását, amikor a megőrzéshez használt módszer a PersistStream, PersistStreamInit vagy PersistStorage. |
