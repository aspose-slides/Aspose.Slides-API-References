## LoadFormat enumeráció

Jelzi a betöltendő dokumentum formátumát.

A LoadFormat típus a következő tagokat teszi közzé:

## Mezők

| Field | Leírás |
| :- | :- |
| AUTO | Az Aspose.Slides-t arra utasítja, hogy automatikusan felismerje a formátumot. |
| PPT | Microsoft PowerPoint 97-2003 prezentáció. |
| PPS | Microsoft PowerPoint 97-2003 diavetítés. |
| PPTX | Microsoft Office Open XML PresentationML dokumentum. |
| PPSX | Microsoft Office Open XML PresentationML diavetítés. |
| ODP | OpenOffice ODF prezentáció. |
| POTX | Microsoft Office Open XML PresentationML sablon. |
| PPTM | Microsoft Office Open XML PresentationML makróval ellátott dokumentum. |
| PPSM | Microsoft Office Open XML PresentationML makróval ellátott diavetítés. |
| POTM | Microsoft Office Open XML PresentationML makróval ellátott sablon. |
| OTP | OpenOffice OTP prezentációs sablon. |
| PPT95 | Microsoft PowerPoint 95 prezentáció. |
| POT | Microsoft PowerPoint 97-2003 prezentációs sablon. |
| FODP | Flat XML ODF prezentáció. |
| UNKNOWN | Ismeretlen fájlformátum |
