## HyperlinkQueries osztály

Könnyű hozzáférést biztosít a tartalmazott hiperhivatkozásokhoz.

A HyperlinkQueries típus a következő tagokat tartalmazza:

## Módszerek

| Módszer | Leírás |
| :- | :- |
| [`get_hyperlink_clicks(self)`](/slides/python-net/hu/aspose.slides/hyperlinkqueries/get_hyperlink_clicks/#) | Az összes IHyperlinkContainer alobjektum lekérése, amely nem None HyperlinkClick tartalmaz.<br/>            A megadott IHyperlinkContainer objektummal kezelheti annak hiperhivatkozását (olvasás, frissítés vagy eltávolítás). Lásd az IHyperlinkContainer interfészt. |
| [`get_hyperlink_mouse_overs(self)`](/slides/python-net/hu/aspose.slides/hyperlinkqueries/get_hyperlink_mouse_overs/#) | Az összes IHyperlinkContainer alobjektum lekérése, amely nem None HyperlinkMouseOver tartalmaz.<br/>            A megadott IHyperlinkContainer objektummal kezelheti annak hiperhivatkozását (olvasás, frissítés vagy eltávolítás). Lásd az IHyperlinkContainer interfészt. |
| [`get_any_hyperlinks(self)`](/slides/python-net/hu/aspose.slides/hyperlinkqueries/get_any_hyperlinks/#) | Az összes IHyperlinkContainer alobjektum lekérése, amely nem None HyperlinkMouseOver tartalmaz.<br/>            A megadott IHyperlinkContainer objektummal kezelheti annak hiperhivatkozását (olvasás, frissítés vagy eltávolítás). Lásd az IHyperlinkContainer interfészt. |
| [`remove_all_hyperlinks(self)`](/slides/python-net/hu/aspose.slides/hyperlinkqueries/remove_all_hyperlinks/#) | Eltávolítja az összes tartalmazott HyperlinkClick és HyperlinkMouseOver hiperhivatkozást (az összes IHyperlinkContainer alobjektumban). |
