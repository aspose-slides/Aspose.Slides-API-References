## PathCommandType enumeráció

A grafikus útvonalparancsok képviselője

A PathCommandType típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| CLOSE | Lezárja a geometriai útvonalat |
| MOVE_TO | Beállítja a geometriai útvonal következő pontjának pozícióját |
| LINE_TO | Vonalat ad hozzá a geometriai útvonalhoz |
| ARC_TO | A megadott ívet adja hozzá a geometriai útvonalhoz. |
| QUAD_BEZIER_TO | Kvadratikus Bezier-görbét ad hozzá a geometriai útvonalhoz |
| CUBIC_BEZIER_TO | Kubikus Bezier-görbét ad hozzá a geometriai útvonalhoz |
