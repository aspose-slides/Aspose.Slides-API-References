## ColorSchemeIndex enumeráció

Egy színséma indexét képviseli.

A ColorSchemeIndex típus a következő tagokat tartalmazza:

## Mezők

| Mező | Leírás |
| :- | :- |
| DARK1 | Sötét 1. |
| LIGHT1 | Világos 1. |
| DARK2 | Sötét 2. |
| LIGHT2 | Világos 2. |
| ACCENT1 | Akcentus 1. |
| ACCENT2 | Akcentus 2. |
| ACCENT3 | Akcentus 3. |
| ACCENT4 | Akcentus 4. |
| ACCENT5 | Akcentus 5. |
| ACCENT6 | Akcentus 6. |
| HYPERLINK | Hiperhivatkozás. |
| FOLLOWED_HYPERLINK | Követett hiperhivatkozás. |
