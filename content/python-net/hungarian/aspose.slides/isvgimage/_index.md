## ISvgImage osztály

Egy SVG képet képvisel.

Az ISvgImage típus a következő tagokat tartalmazza:

## Tulajdonságok

| Tulajdonság | Leírás |
| :- | :- |
| [`svg_content`](/slides/python-net/hu/aspose.slides/isvgimage/svg_content/) | SVG tartalmat ad vissza.<br/>            Csak olvasható **str**. |
| [`svg_data`](/slides/python-net/hu/aspose.slides/isvgimage/svg_data/) | SVG adatot ad vissza.<br/>            Csak olvasható **int**[]. |
| [`external_resource_resolver`](/slides/python-net/hu/aspose.slides/isvgimage/external_resource_resolver/) | Visszaadja azt a callback interfészt, amelyet a külső erőforrások feloldásához használnak SVG dokumentumok importálása során.<br/>            Csak olvasható **IExternalResourceResolver**. |
| [`base_uri`](/slides/python-net/hu/aspose.slides/isvgimage/base_uri/) | Visszaadja a megadott SVG alap-URI-ját. Relatív hivatkozások feloldásához használható.<br/>            Csak olvasható **str**. |

## Metódusok

| Metódus | Leírás |
| :- | :- |
