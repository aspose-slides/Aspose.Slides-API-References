## StringCollection::rend() metod

Returnerar en omvänd iterator till elementet som följer det sista elementet i den omvända behållaren. Det motsvarar elementet som föregår det första elementet i den icke-omvända behållaren. Detta element fungerar som en platshållare; ett försök att komma åt det resulterar i odefinierat beteende.

```cpp
reverse_iterator System::Collections::Specialized::StringCollection::rend() noexcept
```

### Returvärde

En iterator som pekar på det teoretiska elementet som föregår det första elementet i behållaren.

## StringCollection::rend() const metod

```cpp
const_reverse_iterator System::Collections::Specialized::StringCollection::rend() const noexcept
```

### Returvärde

En iterator som pekar på det teoretiska elementet som föregår det första elementet i den const-kvalificerade behållaren.
