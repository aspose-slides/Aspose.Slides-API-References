## TraceLevel enum

Anger vilka meddelanden som ska skrivas ut för klasserna [System.Diagnostics.Debug](../debug/), [System.Diagnostics.Trace](../trace/) och System.Diagnostics.TraceSwitch.

```cpp
enum class TraceLevel
```

### Values

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Off | 0 | Ingen spårnings- och felsökningsmeddelanden skrivs ut. |
| Error | 1 | Skriver ut felhanteringsmeddelanden. |
| Warning | 2 | Skriver ut varnings- och felhanteringsmeddelanden. |
| Info | 3 | Skriver ut informationsmeddelanden, varningsmeddelanden och felhanteringsmeddelanden. |
| Verbose | 4 | Skriver ut alla felsöknings- och spårningsmeddelanden. |
