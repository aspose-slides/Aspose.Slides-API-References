## TraceListener klass

Gränssnitt för att reagera på debug och trace infofmation. Objekt av denna klass bör endast allokeras med [System::MakeObject()](../../system/makeobject/) funktion. Skapa aldrig en instans av denna typ på stacken eller med operatorn new, eftersom det kommer att resultera i runtime errors och/eller assertion faults. Wrappa alltid denna klass i en [System::SmartPtr](../../system/smartptr/) pointer och använd den pekaren för att skicka den till funktioner som argument.

```cpp
class TraceListener : public System::Object
```
