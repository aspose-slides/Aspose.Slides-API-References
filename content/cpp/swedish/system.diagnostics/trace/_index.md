## Trace struct

Tillhandahåller ett gränssnitt för att komma åt debuggerns spårning (om någon). Fungerar endast i [Debug](../debug/) läge. Detta är en statisk typ utan instans-tjänster. Du bör aldrig skapa instanser av den på något sätt.

```cpp
class Trace
```
