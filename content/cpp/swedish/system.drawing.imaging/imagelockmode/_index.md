## ImageLockMode enum

Anger egenskaper för den del av en bild som låses.

```cpp
enum class ImageLockMode
```

### Värden

| Name | Value | Description |
| --- | --- | --- |
| ReadOnly | 1 | Regionen är låst endast för läsning. |
| WriteOnly | 2 | Regionen är låst endast för skrivning. |
| ReadWrite | n/a | Regionen är låst både för läsning och skrivning. |
| UserInputBuffer | 4 | Bilden finns i en användarinmatningsbuffert, vars åtkomst kontrolleras av användaren. |
