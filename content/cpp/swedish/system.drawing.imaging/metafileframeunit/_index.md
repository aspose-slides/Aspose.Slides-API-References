## MetafileFrameUnit enum


Anger enheten för mätning av den rektangel som används för att storleksanpassa och positionera en metafil.

```cpp
enum class MetafileFrameUnit
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Pixel | n/a | Anger en pixel som måttenhet. |
| Point | n/a | Anger en printers punkt som måttenhet. |
| Inch | n/a | Anger en tum som måttenhet. |
| Document | n/a | Anger 1/300 av en tum som måttenhet. |
| Millimeter | n/a | Anger en millimeter som måttenhet. |
