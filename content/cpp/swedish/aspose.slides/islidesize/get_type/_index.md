## ISlideSize::get_Type() metod


Hämtar slide-storlekstypen. Att tilldela något värde förutom [SlideSizeType::Custom](../../slidesizetype/) justerar [ISlideSize::get_Size](../get_size/) enligt de fördefinierade dimensionerna, samtidigt som den nuvarande [ISlideSize::get_Orientation](../get_orientation/) behålls.

```cpp
virtual SlideSizeType Aspose::Slides::ISlideSize::get_Type()=0
```

## Anmärkningar


Att tilldela något värde annat än [SlideSizeType::Custom](../../slidesizetype/) justerar [System::Drawing::Size](../../../system.drawing/size/) enligt de fördefinierade dimensionerna, samtidigt som den nuvarande [Orientation](../../orientation/) behålls.
