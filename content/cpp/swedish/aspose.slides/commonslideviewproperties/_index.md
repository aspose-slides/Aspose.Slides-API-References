## Anmärkningar


Följande exempel visar hur man ställer in zoomvärdet för en bild i PowerPoint [Presentation](../presentation/). 
```cpp
// Instansiera ett Presentation-objekt som representerar en presentationsfil
auto presentation = System::MakeObject<Presentation>(u"demo.pptx");

// Ställer in visningsegenskaper för presentationen
presentation->get_ViewProperties()->get_SlideViewProperties()->set_Scale(100);
// Zoomvärde i procent för slide-vyn
presentation->get_ViewProperties()->get_NotesViewProperties()->set_Scale(100);
// Zoomvärde i procent för notervyn
presentation->Save(u"Zoom_out.pptx", SaveFormat::Pptx);
```
