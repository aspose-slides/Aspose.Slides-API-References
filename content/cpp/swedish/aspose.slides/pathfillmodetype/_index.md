## PathFillModeType enum

Anger på vilket sätt en path ska fyllas

```cpp
enum class PathFillModeType : uint8_t
```

### Värden

| Name | Value | Description |
| --- | --- | --- |
| None | 0 | Ingen Path Fill Detta anger att den motsvarande path inte ska ha någon fyllning. |
| Normal | 1 | Normal Path Fill Detta anger att den motsvarande path bör ha en normalt skuggad färg applicerad på dess fyllning. |
| Lighten | 2 | Lighten Path Fill Detta anger att den motsvarande path bör ha en lätt skuggad färg applicerad på dess fyllning. |
| LightenLess | 3 | Lighten Path Fill Less Detta anger att den motsvarande path bör ha en något ljusare skuggad färg applicerad på dess fyllning. |
| Darken | 4 | Darken Path Fill Detta anger att den motsvarande path bör ha en mörkare skuggad färg applicerad på dess fyllning. |
| DarkenLess | 5 | Darken Path Fill Less Detta anger att den motsvarande path bör ha en något mörkare skuggad färg applicerad på dess fyllning. |
