## IVideo::get_BinaryData() metod

Returns the copy of an audio's data. In case of large amount of data consider using of [IVideo::GetStream](../getstream/) metod to prevent unnecessary loading of video's data into memory or even OutOfMemoryException. Skrivskyddad **uint8_t**[].

```cpp
virtual System::ArrayPtr<uint8_t> Aspose::Slides::IVideo::get_BinaryData()=0
```
