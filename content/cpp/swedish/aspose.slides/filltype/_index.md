## FillType enum


Specificerar den inre fyllningstypen för olika visuella objekt.

```cpp
enum class FillType : int8_t
```

### Values

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| NotDefined | -1 | Fylltypen är inte definierad. |
| NoFill | 0 | Ingen fyllning appliceras. |
| Solid | 1 | Fylld med en solid färg. |
| Gradient | 2 | Fyllningen är en gradient. |
| Pattern | 3 | Upprepande mönster används för att fylla objektet. |
| Picture | 4 | En enda bild används för att fylla objektet. |
| Group | 5 | Det visuella objektet ärver fyllningsegenskaperna från gruppen. |
