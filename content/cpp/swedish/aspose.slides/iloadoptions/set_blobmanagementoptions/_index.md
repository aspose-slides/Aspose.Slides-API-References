## ILoadOptions::set_BlobManagementOptions(System::SharedPtr\<IBlobManagementOptions\>) method

Representerar de alternativ som kan användas för att hantera beteendet för Binary Large Objects (BLOBs), såsom användning av temporära filer eller maximalt antal BLOB-bytes i minnet. Dessa alternativ är avsedda att ställa in det bästa förhållandet mellan prestanda och minnesförbrukning för en särskild miljö eller krav.

```cpp
virtual void Aspose::Slides::ILoadOptions::set_BlobManagementOptions(System::SharedPtr<IBlobManagementOptions> value)=0
```

## Anmärkningar

Ett Binary Large Object (BLOB) är binär data lagrad som en enhet – t.ex. kan ett BLOB vara en ljudfil, video eller en presentation.
