## ILoadOptions::get_BlobManagementOptions() metod

Representerar de alternativ som kan användas för att hantera Binary Large Objects (BLOBs) hanteringsbeteende, såsom användning av temporära filer eller maximalt antal BLOB-bytes i minnet. Dessa alternativ är avsedda att konfigurera det bästa förhållandet mellan prestanda och minnesförbrukning för en särskild miljö eller krav.

```cpp
virtual System::SharedPtr<IBlobManagementOptions> Aspose::Slides::ILoadOptions::get_BlobManagementOptions()=0
```

## Anmärkningar

Ett Binary Large Object (BLOB) är binär data lagrad som en enda enhet – dvs. BLOB kan vara ett ljud, en video eller en presentation i sig själv.
