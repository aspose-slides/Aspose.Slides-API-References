## IDocumentProperties::get_AppVersion() metod

Returns the app version. Endast läsning [System::String](../../../system/string/).

```cpp
virtual System::String Aspose::Slides::IDocumentProperties::get_AppVersion()=0
```

## Anmärkningar

Innehållet i detta element ska vara i formatet XX.YYYY, där X och Y representerar numeriska värden; annars ska dokumentet betraktas som icke-standardkompatibelt. [Aspose.Slides](../../) representerar dess version i formatet XX.YYZZ, där: XX - huvudversion YY - underordnad version ZZ - patch-version För exempel betyder värdet 23.0105 [Aspose.Slides](../../) version 23.1.5.
