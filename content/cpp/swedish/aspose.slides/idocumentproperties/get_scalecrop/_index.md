## IDocumentProperties::get_ScaleCrop() metod


Indikerar visningsläget för dokumentets miniatyrbild. Ställ in detta element till **true** för att möjliggöra skalning av dokumentets miniatyrbild till skärmen. Ställ in detta element till **false** för att möjliggöra beskärning av dokumentets miniatyrbild så att endast sektioner som passar skärmen visas. Läs **bool**.

```cpp
virtual bool Aspose::Slides::IDocumentProperties::get_ScaleCrop()=0
```
