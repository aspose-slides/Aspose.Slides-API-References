## IDocumentProperties::set_ScaleCrop(bool) metod

Anger visningsläget för dokumentets miniatyrbild. Ställ in detta element till **true** för att möjliggöra skalning av dokumentets miniatyrbild till skärmen. Ställ in detta element till **false** för att möjliggöra beskärning av dokumentets miniatyrbild så att endast sektioner som passar skärmen visas. Skriv **bool**.

virtual void Aspose::Slides::IDocumentProperties::set_ScaleCrop(bool value)=0
