## IParagraphFormat::set_SpaceBefore(float) metod

Sätter mängden utrymme före den första raden i ett stycke utan arv. Ett positivt värde anger procentandelen av teckenstorleken som det vita utrymmet ska vara. Ett negativt värde anger storleken på det vita utrymmet i punktstorlek. Skriv **float**.

virtual void Aspose::Slides::IParagraphFormat::set_SpaceBefore(float value)=0
