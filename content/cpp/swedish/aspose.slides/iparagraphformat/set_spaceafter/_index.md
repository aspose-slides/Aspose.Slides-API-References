## IParagraphFormat::set_SpaceAfter(float) metod

Sätter mängden utrymme efter den sista raden i ett stycke utan arv. Ett positivt värde anger procentsatsen av teckenstorleken som det vita utrymmet ska vara. Ett negativt värde anger storleken på det vita utrymmet i punktstorlek. Skriv **float**.

virtual void Aspose::Slides::IParagraphFormat::set_SpaceAfter(float value)=0
