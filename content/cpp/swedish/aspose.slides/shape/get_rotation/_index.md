## Shape::get_Rotation() metod

Returnerar antalet grader som den angivna formen är roterad kring z-axeln. Ett positivt värde indikerar medurs rotation; ett negativt värde indikerar moturs rotation. Läs **float**.

```cpp
float Aspose::Slides::Shape::get_Rotation() override
```

## Anmärkningar

Det returnerade värdet är alltid definierat (är inte std::numeric_limits<float>::quiet_NaN()). Tilldelat värde måste vara definierat (inte std::numeric_limits<float>::quiet_NaN()). Du kan sätta odefinierade värden för RawFrame-instansens egenskaper.
