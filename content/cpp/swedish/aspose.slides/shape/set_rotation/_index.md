## Shape::set_Rotation(float) metod


Ställer in antalet grader som den angivna formen roteras kring z-axeln. Ett positivt värde indikerar medursrotation; ett negativt värde indikerar motursrotation. Skriv **float**.

```cpp
void Aspose::Slides::Shape::set_Rotation(float value) override
```

## Anmärkningar


Det returnerade värdet är alltid definierat (är inte std::numeric_limits<float>::quiet_NaN()). Tilldelat värde måste vara definierat (inte std::numeric_limits<float>::quiet_NaN()). Du kan sätta odefinierade värden för RawFrame-instansens egenskaper.
