## IShape::get_Rotation() metod


Returnerar antalet grader som den angivna formen roteras runt z-axeln. Ett positivt värde indikerar medurs rotation; ett negativt värde indikerar moturs rotation. Läs **float**.

```cpp
virtual float Aspose::Slides::IShape::get_Rotation()=0
```

## Anmärkningar


Det returnerade värdet är alltid definierat (är inte std::numeric_limits<float>::quiet_NaN()). Tilldelat värde måste vara definierat (inte std::numeric_limits<float>::quiet_NaN()). Du kan sätta odefinierade värden för RawFrame-instansens egenskaper.
