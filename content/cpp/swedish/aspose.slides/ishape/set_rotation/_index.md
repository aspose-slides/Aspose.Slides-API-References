## IShape::set_Rotation(float) metod


Ställer in antalet grader som den angivna formen roteras omkring z-axeln. Ett positivt värde indikerar medursrotation; ett negativt värde indikerar motursrotation. Skriv **float**.

```cpp
virtual void Aspose::Slides::IShape::set_Rotation(float value)=0
```

## Anmärkningar


Det returnerade värdet är alltid definierat (är inte std::numeric_limits<float>::quiet_NaN()). Tilldelat värde måste vara definierat (inte std::numeric_limits<float>::quiet_NaN()). Du kan ange odefinierade värden för RawFrame-instansens egenskaper.
