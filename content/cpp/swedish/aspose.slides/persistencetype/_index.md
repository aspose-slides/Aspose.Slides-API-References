## PersistenceType enum

Anger metoden som används för att lagra egenskaper för ActiveX control.

```cpp
enum class PersistenceType
```

### Values

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| NotDefined | -1 | Persistens-id ej specificerat. |
| PersistPropertyBag | 0 | Anger att ActiveX control sparas med egenskaps-påse-baserad persistens. Egenskaps-påse-baserad persistens lagrar en ActiveX control genom en samling av namn- och värdepar som specificerar de data som sparas av ActiveX control. |
| PersistStream | 1 | Anger att ActiveX control sparas med ström-baserad persistens som inte stöder initiering av ActiveX control till ett standardtillstånd. |
| PersistStreamInit | 2 | Anger att ActiveX control sparas med ström-baserad persistens som stöder initiering av ActiveX control till ett standardtillstånd. |
| PersistStorage | 3 | Anger att ActiveX control sparas med lagrings-baserad persistens. |
