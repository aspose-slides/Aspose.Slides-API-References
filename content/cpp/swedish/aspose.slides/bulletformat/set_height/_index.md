## BulletFormat::set_Height(float) metod


Ställer in punkthöjden för ett stycke utan arv. Värdet std::numeric_limits<float>::quiet_NaN() bestämmer att punkten ärver höjden från den första delen i stycket. Skriv **float**.

```cpp
void Aspose::Slides::BulletFormat::set_Height(float value) override
```

## Anmärkningar


Ett negativt höjdvärde betyder att höjden anges i punkter och ett positivt värde betyder att höjden är en procentsats av den omgivande texten.
