## LoadOptions::set_BlobManagementOptions(System::SharedPtr\<IBlobManagementOptions\>) metod

Representerar de alternativ som kan användas för att hantera Binary Large Objects (BLOBs) beteende, såsom användning av temporära filer eller maximalt antal BLOB-bytes i minnet. Dessa alternativ är avsedda att konfigurera det bästa förhållandet mellan prestanda och minnesförbrukning för en särskild miljö eller krav.

```cpp
void Aspose::Slides::LoadOptions::set_BlobManagementOptions(System::SharedPtr<IBlobManagementOptions> value) override
```

## Anmärkningar

En Binary Large Object (BLOB) är binär data lagrad som en enda enhet – dvs. BLOB kan vara ett ljud, video eller en presentation i sig själv.
