## DocumentProperties::get_ScaleCrop() metod

Anger visningsläget för dokumentets miniatyrbild. Ställ in detta element till **true** för att aktivera skalning av dokumentets miniatyrbild till skärmen. Ställ in detta element till **false** för att aktivera beskärning av dokumentets miniatyrbild så att endast sektioner som passar skärmen visas. Läs **bool**.
