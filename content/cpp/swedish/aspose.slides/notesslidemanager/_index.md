## Anmärkningar

Följande exempel visar hur man lägger till Noter på en specifik PowerPoint [Presentation](../presentation/) slide.
```cpp
// Instansiera ett Presentation-objekt som representerar en presentationsfil
auto presentation = System::MakeObject<Presentation>(dataDir + u"AccessSlides.pptx");

// Lägg till anteckningar på den första bilden
System::SharedPtr<INotesSlideManager> mgr = presentation->get_Slides()->idx_get(0)->get_NotesSlideManager();
System::SharedPtr<INotesSlide> noteSlide = mgr->AddNotesSlide();
noteSlide->get_NotesTextFrame()->set_Text(u"Your Notes");

// Spara presentationen till disk
presentation->Save(u"RemoveNotesAtSpecificSlide_out.pptx", SaveFormat::Pptx);
```
Följande exempel visar hur man tar bort Noter från en specifik slide i PowerPoint [Presentation](../presentation/).
```cpp
// Instansiera ett Presentation-objekt som representerar en presentationsfil
auto presentation = System::MakeObject<Presentation>(dataDir + u"AccessSlides.pptx");
// Tar bort anteckningar på den första bilden
System::SharedPtr<INotesSlideManager> mgr = presentation->get_Slides()->idx_get(0)->get_NotesSlideManager();
mgr->RemoveNotesSlide();
// Spara presentationen till disk
presentation->Save(u"RemoveNotesAtSpecificSlide_out.pptx", SaveFormat::Pptx);
```
