## XmlOutputMethod enum

Anger metoden som används för att serialisera [XmlWriter](../xmlwriter/)-utdata.

```cpp
enum class XmlOutputMethod
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Xml | 0 | Serialisera enligt XML 1.0-reglerna. |
| Html | 1 | Serialisera enligt HTML-reglerna som specificeras av XSLT. |
| Text | 2 | Serialisera endast textblock. |
| AutoDetect | 3 | Använd XSLT-reglerna för att välja mellan [XmlOutputMethod::Xml](./)- och [XmlOutputMethod::Html](./)-utdata-metoder vid körning. |
