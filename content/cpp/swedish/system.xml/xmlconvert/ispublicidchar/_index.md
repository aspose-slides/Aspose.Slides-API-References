## XmlConvert::IsPublicIdChar(char16_t) metod


Returns the passed-in character instance if the character in the argument is a valid public id character, otherwise **nullptr**.

```cpp
static bool System::Xml::XmlConvert::IsPublicIdChar(char16_t ch)
```


### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| ch | char16_t | [Char](../../../system/char/) objekt att validera. |

### Returvärde

Det medskickade tecknet om tecknet är ett giltigt offentligt id-tecken, annars **nullptr**.
