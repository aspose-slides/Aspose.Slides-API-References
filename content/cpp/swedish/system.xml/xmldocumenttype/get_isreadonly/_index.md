## XmlDocumentType::get_IsReadOnly() metod

Returnerar ett värde som indikerar om noden är skrivskyddad.

```cpp
bool System::Xml::XmlDocumentType::get_IsReadOnly() override
```

### Returvärde

**true** om noden är skrivskyddad; annars **false**. Eftersom DocumentType-noder är skrivskyddade, returnerar denna metod alltid **true**.
