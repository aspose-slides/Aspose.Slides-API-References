## XmlNode::get_Prefix() metod

Returnerar namnrymdspräfixet för den här noden.

```cpp
virtual String System::Xml::XmlNode::get_Prefix()
```

### Returvärde

Namnrymdspräfixet för den här noden. Till exempel är **Prefix** **bk** för elementet **<bk:book>**. Om det inte finns något prefix, returnerar den här metoden [String::Empty](../../../system/string/empty/).
