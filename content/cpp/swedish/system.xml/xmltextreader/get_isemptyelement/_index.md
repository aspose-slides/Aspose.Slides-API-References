## XmlTextReader::get_IsEmptyElement() metod


Returns a value indicating whether the current node is an empty element (for example, **<MyElement/>**).

```cpp
bool System::Xml::XmlTextReader::get_IsEmptyElement() override
```


### Returvärde

**true** om den aktuella noden är ett element ([XmlTextReader::get_NodeType](../get_nodetype/) värde är lika med [XmlNodeType::Element](../../xmlnodetype/)) som avslutas med **/>**; annars **false**.
