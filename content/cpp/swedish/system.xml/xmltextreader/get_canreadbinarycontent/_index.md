## XmlTextReader::get_CanReadBinaryContent() metod


Returnerar ett värde som indikerar om [XmlTextReader](../) implementerar metoderna för läsning av binärt innehåll.

```cpp
bool System::Xml::XmlTextReader::get_CanReadBinaryContent() override
```


### Returvärde

**true** om metoderna för läsning av binärt innehåll är implementerade; annars **false**. Klass [XmlTextReader](../) returnerar alltid **true**.
