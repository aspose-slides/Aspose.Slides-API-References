## XmlTextReader::get_HasValue() metod


Returnerar ett värde som anger om den aktuella noden kan ha en [XmlTextReader::get_Value](../get_value/) annan än [String::Empty](../../../system/string/empty/).

```cpp
bool System::Xml::XmlTextReader::get_HasValue() override
```


### Returvärde
