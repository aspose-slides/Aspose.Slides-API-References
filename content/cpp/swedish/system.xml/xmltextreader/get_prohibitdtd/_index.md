## XmlTextReader::get_ProhibitDtd() metod


Returnerar ett värde som indikerar om DTD-bearbetning ska tillåtas.

```cpp
bool System::Xml::XmlTextReader::get_ProhibitDtd()
```


### Returvärde

**true** to disallow DTD processing; otherwise **false**. The default is **false**.
