## XmlTextReader::ReadString() metod

Läser innehållet i ett element eller en textnod som en sträng.

```cpp
String System::Xml::XmlTextReader::ReadString() override
```

### Returvärde

Innehållet i elementet eller textnoden. Det kan vara en tom sträng om läsaren är positionerad på något annat än ett element eller en textnod, eller om det inte finns mer textinnehåll att returnera i det aktuella sammanhanget. **Obs:** Textnoden kan vara antingen ett element eller ett attributtextnod.
