## NamespaceHandling enum

Anger om dubblettnamnrymdsdeklarationer ska tas bort i [XmlWriter](../xmlwriter/).

```cpp
enum class NamespaceHandling
```

### Values

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Default | 0 | Anger att dubblett namnrymdsdeklarationer inte kommer att tas bort. |
| OmitDuplicates | 1 | Anger att dubblett namnrymdsdeklarationer kommer att tas bort. För att dubblettnamnrymden ska tas bort måste prefixet och namnrymden matcha. |
