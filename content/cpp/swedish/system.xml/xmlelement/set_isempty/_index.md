## XmlElement::set_IsEmpty(bool) metod


Sets the tag format of the element.

```cpp
void System::Xml::XmlElement::set_IsEmpty(bool value)
```


### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| value | **bool** | Värdet att sätta. När detta värde sätts, om det är **true**, tas elementets barn bort och elementet serialiseras i det korta taggformatet. Om det är **false**, ändras värdet (oavsett om elementet har innehåll eller inte); om elementet är tomt, serialiseras det i det långa formatet. |
