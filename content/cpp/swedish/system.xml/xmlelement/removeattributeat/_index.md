## XmlElement::RemoveAttributeAt(int32_t) metod


Tar bort attributnoden med det angivna indexet från elementet. (Om den borttagna attributet har ett standardvärde ersätts det omedelbart).

```cpp
virtual SharedPtr<XmlNode> System::Xml::XmlElement::RemoveAttributeAt(int32_t i)
```


### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| i | **int32_t** | Indexet för noden som ska tas bort. Den första noden har index 0. |

### Returvärde

Den borttagna attributnoden eller **nullptr** om det inte finns någon nod på det angivna indexet.
