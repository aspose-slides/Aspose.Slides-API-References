## XmlElement::get_IsEmpty() metod


Returnerar taggformatet för elementet.

```cpp
bool System::Xml::XmlElement::get_IsEmpty()
```


### Returvärde

**true** om elementet ska serialiseras i korta taggformatet \"<tt><item/></tt>\"; **false** för det långa formatet \"<tt><item></item></tt>\".
