## XmlWriter::get_XmlSpace() metod

När den åsidosätts i en härledd klass hämtar den ett XmlSpace som representerar det aktuella **xml:space**-omfånget.

```cpp
virtual System::Xml::XmlSpace System::Xml::XmlWriter::get_XmlSpace()
```

### Returvärde

Ett XmlSpace som representerar det aktuella **xml:space**-omfånget.



| Värde | Betydelse |
| --- | --- |
| `None`| Detta är standardvärdet om ingen `xml:space`-omfång finns. |
| `Default`| Det aktuella omfånget är `xml:space="default"`. |
| `Preserve`| Det aktuella omfånget är `xml:space="preserve"`. |
