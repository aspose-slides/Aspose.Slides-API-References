## XmlWriterSettings::get_CheckCharacters() metod

Returnerar ett värde som indikerar om XML-skrivaren ska kontrollera för att säkerställa att alla tecken i dokumentet överensstämmer med avsnittet "2.2 Characters" i W3C [XML 1.0 Recommendation](https://www.w3.org/TR/REC-xml/#charsets).

```cpp
bool System::Xml::XmlWriterSettings::get_CheckCharacters()
```

### Returvärde

**true** för att utföra teckenkontroll; annars **false**. Standardvärdet är **true**.
