## XmlWriterSettings::get_NewLineChars() metod


Returnerar teckensträngen som ska användas för radbrytningar.

```cpp
String System::Xml::XmlWriterSettings::get_NewLineChars()
```


### Returvärde

Teckensträngen som ska användas för radbrytningar. Det kan sättas till vilket strängvärde som helst. Men för att säkerställa giltig XML bör du endast ange giltiga blankstegstecken, såsom mellanslag, tabbar, vagnretur eller radmatning. Standardvärdet är **\r\n** (vagnretur, ny rad).
