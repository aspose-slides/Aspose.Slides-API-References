## XmlWriterSettings::get_CloseOutput() metod

Returnerar ett värde som anger om [XmlWriter](../../xmlwriter/) också ska stänga den underliggande strömmen eller TextWriter när [XmlWriter::Close](../../xmlwriter/close/)-metoden anropas.

```cpp
bool System::Xml::XmlWriterSettings::get_CloseOutput()
```

### Returvärde

**true** för att också stänga den underliggande strömmen eller TextWriter; annars **false**. Standardvärdet är **false**.
