## XmlWriterSettings::get_IndentChars() metod


Returnerar teckensträngen som ska användas vid indragning. Denna inställning används när värdet [XmlWriterSettings::set_Indent](../set_indent/) är satt till **true**.

```cpp
String System::Xml::XmlWriterSettings::get_IndentChars()
```


### Returvärde

Teckensträngen som ska användas vid indragning. Den kan sättas till valfritt strängvärde. För att säkerställa giltig XML bör du dock endast ange giltiga blankstegstecken, såsom mellanslag, tabbar, vagnretur eller radmatning. Standardvärdet är två mellanslag.
