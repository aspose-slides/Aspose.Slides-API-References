## XmlWriterSettings::get_NamespaceHandling() metod

Returnerar ett värde som indikerar om [XmlWriter](../../xmlwriter/) ska ta bort dubblettnamnrymdsdeklarationer vid skrivning av XML-innehåll. Standardbeteendet är att skrivaren skriver ut alla namnrymdsdeklarationer som finns i skrivarens namnrymdslösare.

```cpp
System::Xml::NamespaceHandling System::Xml::XmlWriterSettings::get_NamespaceHandling()
```

### Returvärde

NamespaceHandling-enumerationen som används för att ange huruvida dubblettnamnrymdsdeklarationer ska tas bort i [XmlWriter](../../xmlwriter/).
