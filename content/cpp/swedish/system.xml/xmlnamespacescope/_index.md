## XmlNamespaceScope enum

Definierar namnrymdens omfång.

```cpp
enum class XmlNamespaceScope
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| All | 0 | Alla namnrymder som definieras i omfånget för den aktuella noden. Detta inkluderar xmlns:xml-namnrymden som alltid deklareras implicit. Ordningen på de returnerade namnrymderna är inte definierad. |
| ExcludeXml | 1 | Alla namnrymder som definieras i omfånget för den aktuella noden, exklusive xmlns:xml-namnrymden, som alltid deklareras implicit. Ordningen på de returnerade namnrymderna är inte definierad. |
| Local | 2 | Alla namnrymder som definieras lokalt på den aktuella noden. |
