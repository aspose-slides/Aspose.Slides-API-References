## XmlValidatingReader::get_IsEmptyElement() metod


Returnerar ett värde som indikerar om den aktuella noden är ett tomt element (till exempel **<MyElement/>**).

```cpp
bool System::Xml::XmlValidatingReader::get_IsEmptyElement() override
```


### Returvärde

**true** om den aktuella noden är ett element ([XmlValidatingReader::get_NodeType](../get_nodetype/) värde är lika med [XmlNodeType::Element](../../xmlnodetype/)) som avslutas med **/>**; annars, **false**.
