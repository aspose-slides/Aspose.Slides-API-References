## XmlValidatingReader::get_IsDefault() metod

Returnerar ett värde som indikerar om den aktuella noden är ett attribut som genererades från standardvärdet som definierats i dokumenttypdefinitionen (DTD) eller schemat.

```cpp
bool System::Xml::XmlValidatingReader::get_IsDefault() override
```

### Returvärde

**true** om den aktuella noden är ett attribut vars värde genererades från standardvärdet definierat i DTD eller schema; **false** om attributvärdet sattes explicit.
