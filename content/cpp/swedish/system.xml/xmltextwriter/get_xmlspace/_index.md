## XmlTextWriter::get_XmlSpace() metod

Returnerar ett XmlSpace som representerar det aktuella **xml:space**-omfånget.

```cpp
System::Xml::XmlSpace System::Xml::XmlTextWriter::get_XmlSpace() override
```

### Returvärde

Ett XmlSpace som representerar det aktuella **xml:space**-omfånget.

| Värde | Betydelse |
| --- | --- |
| None | Detta är standardvärdet om ingen `xml:space`-omfång finns. |
| Default | Det aktuella omfånget är `xml:space="default"`. |
| Preserve | Det aktuella omfånget är `xml:space="preserve"`. |
