## XmlTextWriter::get_QuoteChar() metod

Returnerar vilket tecken som ska användas för att citera attributvärden.

```cpp
char16_t System::Xml::XmlTextWriter::get_QuoteChar()
```

### Returvärde

Tecknet som ska användas för att citera attributvärden. Detta måste vara ett enkelt citattecken **'** eller ett dubbelt citattecken **\"**. Standardvärdet är ett dubbelt citattecken.
