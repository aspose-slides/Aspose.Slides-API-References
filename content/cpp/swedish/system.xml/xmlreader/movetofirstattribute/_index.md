## XmlReader::MoveToFirstAttribute() metod


När den åsidosätts i en avledd klass, flyttas läsaren till det första attributet.

```cpp
virtual bool System::Xml::XmlReader::MoveToFirstAttribute()=0
```

### Returvärde

**true** om ett attribut finns (läsaren flyttas till det första attributet); annars **false** (läsarens position förändras inte).
