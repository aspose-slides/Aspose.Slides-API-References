## XmlReader::ReadString() metod

När den åsidosätts i en avledd klass läser den innehållet i ett element eller en textnod som en sträng. Det rekommenderas dock att använda [XmlReader::ReadElementContentAsString](../readelementcontentasstring/)-metoden istället, eftersom den ger ett mer direkt sätt att hantera denna operation.

```cpp
virtual String System::Xml::XmlReader::ReadString()
```

### Returvärde

Innehållet i elementet eller en tom sträng.
