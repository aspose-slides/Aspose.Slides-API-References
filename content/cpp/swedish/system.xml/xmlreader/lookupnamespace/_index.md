## XmlReader::LookupNamespace(const String\&) metod


När den åsidosätts i en härledd klass, löser den ett namnrymdsprefix i det aktuella elementets omfång.

```cpp
virtual String System::Xml::XmlReader::LookupNamespace(const String &prefix)=0
```


### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| prefix | const [String](../../../system/string/)\& | Prefixet vars namnrymds-URI du vill lösa. För att matcha standardnamnrymden, skicka en tom sträng. |

### Returvärde

Namnrymdens URI som prefixet mappar till eller **nullptr** om inget matchande prefix hittas.
