## XmlReader::get_IsEmptyElement() metod

När den åsidosätts i en härledd klass får den ett värde som indikerar om den aktuella noden är ett tomt element (till exempel, **<MyElement/>**).

```cpp
virtual bool System::Xml::XmlReader::get_IsEmptyElement()=0
```

### Returvärde

**true** om den aktuella noden är ett element ([XmlReader::get_NodeType](../get_nodetype/) är lika med [XmlNodeType::Element](../../xmlnodetype/)) som slutar med **/>**; annars, **false**.
