## XmlReader::get_HasValue() metod


När den åsidosätts i en avledd klass, hämtar ett värde som indikerar om den aktuella noden kan ha ett [XmlReader::get_Value](../get_value/)-värde.

```cpp
virtual bool System::Xml::XmlReader::get_HasValue()
```


### Returvärde

**true** om noden som läsaren för närvarande är placerad på kan ha ett **Value**; annars **false**. Om **false**, har noden ett värde av [String::Empty](../../../system/string/empty/).
