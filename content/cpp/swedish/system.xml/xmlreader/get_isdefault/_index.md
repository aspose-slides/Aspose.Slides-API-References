## XmlReader::get_IsDefault() metod


När den åsidosätts i en avledd klass returnerar den ett värde som indikerar om den aktuella noden är ett attribut som genererades från standardvärdet som definierats i DTD eller schemat.

```cpp
virtual bool System::Xml::XmlReader::get_IsDefault()
```


### Return Value

**true** om den aktuella noden är ett attribut vars värde genererades från standardvärdet som definierats i DTD eller schemat; **false** om attributvärdet sattes explicit.
