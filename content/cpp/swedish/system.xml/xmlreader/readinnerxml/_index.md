## XmlReader::ReadInnerXml() method


När den överskuggas i en avledd klass läser den allt innehåll, inklusive markup, som en sträng.

```cpp
virtual String System::Xml::XmlReader::ReadInnerXml()
```


### Returvärde

Allt XML-innehåll, inklusive markup, i den aktuella noden. Om den aktuella noden inte har några barn returneras en tom sträng. Om den aktuella noden varken är ett element eller ett attribut returneras en tom sträng.
