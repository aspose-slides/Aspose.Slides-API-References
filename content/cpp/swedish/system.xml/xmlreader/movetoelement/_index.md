## XmlReader::MoveToElement() metod


När den överskuggas i en avärvd klass flyttar den till elementet som innehåller det aktuella attributnoden.

```cpp
virtual bool System::Xml::XmlReader::MoveToElement()=0
```


### Returvärde

**true** om läsaren är placerad på ett attribut (läsaren flyttar till elementet som äger attributet); **false** om läsaren inte är placerad på ett attribut (läsarens position förändras inte).
