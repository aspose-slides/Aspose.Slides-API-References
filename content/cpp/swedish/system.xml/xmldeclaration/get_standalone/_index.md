## XmlDeclaration::get_Standalone() metod

Returnerar värdet på attributet standalone.

```cpp
String System::Xml::XmlDeclaration::get_Standalone()
```

### Returvärde

Giltiga värden är **yes** om alla enhetsdeklarationer som krävs av XML-dokumentet finns i dokumentet, eller **no** om en extern dokumenttypdefinition (DTD) krävs. Om ett standalone-attribut inte finns i XML-deklarationen, returnerar denna metod [String::Empty](../../../system/string/empty/).
