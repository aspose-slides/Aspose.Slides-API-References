## XmlReaderSettings::get_MaxCharactersInDocument() metod


Returnerar ett värde som indikerar det maximalt tillåtna antalet tecken i ett XML-dokument. Ett noll (0) värde betyder att det inte finns några begränsningar för storleken på XML-dokumentet. Ett icke-noll värde specificerar den maximala storleken, i tecken.

```cpp
int64_t System::Xml::XmlReaderSettings::get_MaxCharactersInDocument()
```


### Returvärde

Det maximalt tillåtna antalet tecken i ett XML-dokument. Standardvärdet är 0.
