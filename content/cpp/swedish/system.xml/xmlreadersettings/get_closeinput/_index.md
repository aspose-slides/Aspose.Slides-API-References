## XmlReaderSettings::get_CloseInput() metod

Returnerar ett värde som indikerar om den underliggande strömmen eller TextReader bör stängas när läsaren stängs.

```cpp
bool System::Xml::XmlReaderSettings::get_CloseInput()
```

### Returvärde

**true** för att stänga den underliggande strömmen eller TextReader när läsaren stängs; annars **false**. Standardvärdet är **false**.
