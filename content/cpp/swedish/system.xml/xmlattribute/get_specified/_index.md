## XmlAttribute::get_Specified() metod


Returnerar ett värde som indikerar om attributvärdet sattes uttryckligen.

```cpp
virtual bool System::Xml::XmlAttribute::get_Specified()
```


### Returvärde

**true** om detta attribut explicit tilldelades ett värde i det ursprungliga instansdokumentet; annars **false**. Ett värde av **false** indikerar att attributets värde kom från DTD.
