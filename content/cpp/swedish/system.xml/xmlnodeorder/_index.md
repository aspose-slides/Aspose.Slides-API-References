## XmlNodeOrder enum


Beskriver dokumentordningen för en nod jämfört med en andra nod.

```cpp
enum class XmlNodeOrder
```

### Värden

| Name | Value | Description |
| --- | --- | --- |
| Before | 0 | Den aktuella noden för den här navigatören är före den aktuella noden för den angivna navigatören. |
| After | 1 | Den aktuella noden för den här navigatören är efter den aktuella noden för den angivna navigatören. |
| Same | 2 | De två navigatörerna är placerade på samma nod. |
| Unknown | 3 | Nodepositionerna kan inte bestämmas i dokumentordning i förhållande till varandra. Detta kan uppstå om de två noderna finns i olika träd. |
