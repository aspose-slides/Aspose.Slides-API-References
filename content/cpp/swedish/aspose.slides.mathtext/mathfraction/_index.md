## MathFraction-klass

Specificerar bråkobjektet, bestående av ett täljare och en nämnare separerade av ett bråkstreck. Bråkstrecket kan vara horisontellt eller diagonalt, beroende på bråkegenskaperna. Bråkobjektet används också för att representera stackfunktionen, som placerar ett element ovanpå ett annat, utan bråkstreck.

```cpp
class MathFraction : public Aspose::Slides::MathText::MathElementBase,
                     public Aspose::Slides::MathText::IMathFraction,
                     public Aspose::Slides::MathText::IHasControlCharacterProperties
```
