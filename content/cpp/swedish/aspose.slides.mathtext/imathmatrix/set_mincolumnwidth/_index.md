## IMathMatrix::set_MinColumnWidth(uint32_t) metod


Minsta kolumnbredd i twips (1/20 av en punkt) Gapavståndet (även kallat \\u201CColumn Gap\\u201D eller \\u201CGap Width\\u201D) läggs till MinColumnWidth för att bestämma den totala Matrix [Column](../../../aspose.slides/column/) Spacing (avståndet mellan samma kanter på olika kolumner). Standard: 0.

```cpp
virtual void Aspose::Slides::MathText::IMathMatrix::set_MinColumnWidth(uint32_t value)=0
```

## Anmärkningar


Exempel: 
```cpp
auto matrix = System::MakeObject<MathMatrix>(2, 3);
matrix->set_MinColumnWidth(20);
```
