## IMathMatrix::get_MinColumnWidth() metod

Minsta kolumnbredd i twips (1/20 av en punkt) Mellanrumsavståndet (även kallat \\u201CColumn Gap\\u201D eller \\u201CGap Width\\u201D) läggs till MinColumnWidth för att bestämma den totala Matrix [Column](../../../aspose.slides/column/) Spacing (avståndet mellan samma kanter på olika kolumner). Standardvärde: 0.

```cpp
virtual uint32_t Aspose::Slides::MathText::IMathMatrix::get_MinColumnWidth()=0
```

## Anmärkningar

Exempel: 
```cpp
auto matrix = System::MakeObject<MathMatrix>(2, 3);
matrix->set_MinColumnWidth(20);
```
