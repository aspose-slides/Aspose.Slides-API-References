## IMathPhantom::get_ZeroAsc() metod


Hämtar ett värde som anger om höjden (höjd över baslinjen) för baselementet ska behandlas som noll.

```cpp
virtual bool Aspose::Slides::MathText::IMathPhantom::get_ZeroAsc()=0
```

## Anmärkningar


När **true**, höjer inte fantomen baslinjen för den omgivande matematiska raden. Motsvarar OMML-attributet **m:zeroAsc**.
