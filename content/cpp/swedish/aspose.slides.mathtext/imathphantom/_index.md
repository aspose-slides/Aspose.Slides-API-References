## IMathPhantom klass

Representerar ett phantom-matematiskt objekt (<m:phant>) som påverkar layouten för sitt underordnade element utan att nödvändigtvis visa det. En phantom kan dölja sitt basuttryck men bevara sin bredd, höjd eller djup för att justera formler eller reservera utrymme. Synlighet och geometribeteende styrs av egenskaper som Show, ZeroWid, ZeroAsc, ZeroDesc och Transp.

```cpp
class IMathPhantom : public virtual Aspose::Slides::MathText::IMathElement
```
