## IMathPhantom::set_Transp(bool) metod

Anger ett värde som visar om fantomet är transparent för klassbaserade avståndsregler.

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_Transp(bool value)=0
```

## Anmärkningar

När **true**, operatorer och symboler inuti fantomet fortfarande påverkar matematiskt avstånd runt fantomet (som om det var synligt). När **false**, klassbaserat avstånd ignoreras. Motsvarar OMML-attributet **m:transp**.
