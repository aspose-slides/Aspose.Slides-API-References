## IMathPhantom::get_Show() metod


Hämtar ett värde som indikerar om baselementet visas.

```cpp
virtual bool Aspose::Slides::MathText::IMathPhantom::get_Show()=0
```

## Anmärkningar


När **false**, baselementet är dolt men kan fortfarande uppta utrymme beroende på andra phantom-inställningar. Motsvarar OMML-attributet **m:show**.
