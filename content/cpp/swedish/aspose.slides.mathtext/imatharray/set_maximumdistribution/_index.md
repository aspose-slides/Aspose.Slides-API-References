## IMathArray::set_MaximumDistribution(bool) metod

Maximal fördelning När true, arrayen placeras med jämna intervall så att den fyller den maximala bredden av det omgivande elementet (sida, kolumn, cell, osv.).

```cpp
virtual void Aspose::Slides::MathText::IMathArray::set_MaximumDistribution(bool value)=0
```

## Anmärkningar

Exempel:
```cpp
auto mathArray = System::MakeObject<MathArray>(System::MakeObject<MathematicalText>(u"item1"));
mathArray->set_MaximumDistribution(true);
```
