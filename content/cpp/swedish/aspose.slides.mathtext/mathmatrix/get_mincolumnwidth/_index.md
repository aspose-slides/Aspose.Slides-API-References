## MathMatrix::get_MinColumnWidth() metod


Minimum kolumnbredd i twips (1/20 av en punkt) Avståndet (även kallat \u201CColumn Gap\u201D eller \u201CGap Width\u201D) läggs till MinColumnWidth för att bestämma den totala Matrix [Column](../../../aspose.slides/column/) Avstånd (avståndet mellan samma kanter på olika kolumner). Standard: 0.

```cpp
uint32_t Aspose::Slides::MathText::MathMatrix::get_MinColumnWidth() override
```

## Anmärkningar


Exempel: 
```cpp
auto matrix = System::MakeObject<MathMatrix>(2, 3);
matrix->set_MinColumnWidth(20);
```
