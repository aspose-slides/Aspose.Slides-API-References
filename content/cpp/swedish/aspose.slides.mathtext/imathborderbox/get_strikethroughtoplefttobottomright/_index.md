## IMathBorderBox::get_StrikethroughTopLeftToBottomRight() metod


Genomstruken övre vänster till nedre hög

er (standard är falskt). Anger det dolda eller visade tillståndet för en genomstruken diagonal linje från det övre vänstra hörnet till det nedre högra hörnet av border box.

```cpp
virtual bool Aspose::Slides::MathText::IMathBorderBox::get_StrikethroughTopLeftToBottomRight()=0
```

## Anmärkningar


Exempel: 
```cpp
auto borderBox = System::MakeObject<MathematicalText>(u"x+y+z")->ToBorderBox();
borderBox->set_StrikethroughTopLeftToBottomRight(true);
```
