## IMathBorderBox::set_StrikethroughTopLeftToBottomRight(bool) metod


Genomstrykning övre-vänster till nedre-höger (standard är falskt). Anger det dolda eller visade tillståndet för en genomstruken diagonal linje från det övre vänstra hörnet till det nedre högra hörnet av ramruta.

```cpp
virtual void Aspose::Slides::MathText::IMathBorderBox::set_StrikethroughTopLeftToBottomRight(bool value)=0
```

## Anmärkningar


Exempel: 
```cpp
auto borderBox = System::MakeObject<MathematicalText>(u"x+y+z")->ToBorderBox();
borderBox->set_StrikethroughTopLeftToBottomRight(true);
```
