## IMathBorderBox::set_StrikethroughBottomLeftToTopRight(bool) metod

Genomstrykning nedre vänstra till övre högra (standard är false). Anger det dolda eller visade tillståndet för en genomstruken diagonal linje från det nedre vänstra hörnet till det övre högra hörnet av kantboxen.

```cpp
virtual void Aspose::Slides::MathText::IMathBorderBox::set_StrikethroughBottomLeftToTopRight(bool value)=0
```

## Anmärkningar

Exempel:
```cpp
auto borderBox = System::MakeObject<MathematicalText>(u"x+y+z")->ToBorderBox();
borderBox->set_StrikethroughBottomLeftToTopRight(true);
```
