## MathPhantom::get_ZeroDesc() metod


Hämtar ett värde som indikerar om nedstigningen (djupet under baslinjen) för baselementet ska behandlas som noll.

```cpp
bool Aspose::Slides::MathText::MathPhantom::get_ZeroDesc() override
```

## Anmärkningar


När **true** sänker inte phantom baslinjen för den omgivande matematikraden. Motsvarar OMML-attributet **m:zeroDesc**.
