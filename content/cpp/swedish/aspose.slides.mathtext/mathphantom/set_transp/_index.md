## MathPhantom::set_Transp(bool) metod


Ställer in ett värde som anger om fantomet är genomskinligt för klassbaserade avståndsregler.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_Transp(bool value) override
```

## Anmärkningar


När **true**, operatorer och symboler inuti fantomet fortfarande påverkar det matematiska avståndet runt fantomet (som om det var synligt). När **false**, klassbaserat avstånd ignoreras. Motsvarar OMML-attributet **m:transp**.
