## MathBorderBox::set_StrikethroughTopLeftToBottomRight(bool) metod


Strikethrough Top-Left to Bottom-Right (default är falskt). Anger det dolda eller visade tillståndet för en genomstrykning diagonal linje från det övre vänstra hörnet till det nedre högra hörnet av ramrutan.

```cpp
void Aspose::Slides::MathText::MathBorderBox::set_StrikethroughTopLeftToBottomRight(bool value) override
```

## Anmärkningar


Exempel: 
```cpp
auto borderBox = System::MakeObject<MathBorderBox>(System::MakeObject<MathematicalText>(u"x"));
borderBox->set_StrikethroughTopLeftToBottomRight(true);
```
