## EmptyEnumerator::MoveNext() metod

Flyttar enumerator till nästa element. Om inget element refererades tidigare, sätter referensen till det första tillgängliga elementet. Om slutet av behållaren nås, gör den ingenting.

```cpp
bool System::Linq::Details::EmptyEnumerator<T>::MoveNext() override
```

### Returvärde

True om ett element är tillgängligt efter anropet, false annars.
