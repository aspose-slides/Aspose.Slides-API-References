## Details_CookieException klass

Representerar ett undantag som kastas när storleken på [CookieContainer](../cookiecontainer/) är större än värdet för egenskapen MaxCookieSize. Skapa aldrig instanser av denna klass manuellt. Använd CookieException-klassen istället. Bunta aldrig in CookieException-klassens instanser i [System::SmartPtr](../../system/smartptr/).

```cpp
class Details_CookieException : public System::Details_FormatException
```
