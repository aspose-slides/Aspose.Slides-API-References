
### Värden

| Namn | Värde | Beskrivning |

| Unknown | 0 | Den okända cookie-specifikationen. |
| Plain | 1 | Den enkla cookie-specifikationen. |
| Rfc2109 | 2 | Den 'RFC 2109' cookie-specifikationen. |
| Rfc2965 | 3 | Den 'RFC 2965' cookie-specifikationen. |
