## SystemIOStreamWrappingMode enum

Anger läget för I/O-operationer som omslutare kommer att utföra på [System::IO::Stream](../stream/)-liknande strömmar.

```cpp
enum class SystemIOStreamWrappingMode
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Binary | 0 | Ett läge som tillåter inmatningsoperationer att koda strömbitar till char_type-data och avkoda char_type-data till strömbitar för utmatningsoperationer. |
| Conversion | 1 | Ett läge som tillåter inmatningsoperationer att konvertera strömbitar från **uint8_t**-typ till char_type-typ och vice versa för utmatningsoperationer. |
