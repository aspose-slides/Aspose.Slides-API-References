```cpp
enum class FileAttributes
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Archive | 32 | Filsystemselementet är en kandidat för borttagning eller säkerhetskopiering. |
| Compressed | 2048 | Filsystemselementet är komprimerat. |
| Device | 64 | Ej använd. |
| Directory | 16 | Filsystemselementet är en katalog. |
| Encrypted | 16384 | Filsystemselementet är krypterat. |
| Hidden | 2 | Filsystemselementet är dolt. |

| NotContentIndexed | 8192 | Filsystemselementet kommer inte att indexeras av innehållsindexeringstjänsten. |
| NoScrubData | 131072 | Filsystemselementet ingår inte i dataintegritetsskanningen. |

| ReadOnly | 1 | Filsystemselementet är skrivskyddat. |
| ReparsePoint | 1024 | Filsystemselementet är en fil som innehåller en omparsningspunkt. |
| SparseFile | 512 | Filsystemselementet är en gles fil. |
