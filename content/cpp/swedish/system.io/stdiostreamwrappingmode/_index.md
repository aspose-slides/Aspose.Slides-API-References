## STDIOStreamWrappingMode enum

Anger läget för I/O-operationer som wrappers kommer att utföra på strömmar av typen std::iostreams-liknande.

```cpp
enum class STDIOStreamWrappingMode
```

### Värden

| Name | Value | Description |
| --- | --- | --- |
| Binary | 0 | Ett läge som tillåter indataoperationer att avkoda strömdata av typen char_type till byte, och att koda byte till char_type-data för utdataoperationer. |
| Conversion | 1 | Ett läge som tillåter indataoperationer att konvertera strömdata från typen char_type till **uint8_t**-typen och vice versa för utdataoperationer. |
