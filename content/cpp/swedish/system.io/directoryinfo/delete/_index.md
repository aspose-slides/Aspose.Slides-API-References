## DirectoryInfo::Delete(bool) metod

Tar bort katalogen som refereras till av sökvägen som representeras av det aktuella objektet. En parameter anger om innehållet i katalogen ska tas bort rekursivt om katalogen inte är tom.

```cpp
void System::IO::DirectoryInfo::Delete(bool recursive)
```

### Argument

| Parameter | Type | Beskrivning |
