## BasicSTDIOStreamWrapper::ReadByte() metod


Om omslagsläget är binärt läses en enda byte från den senast avkodade teckenlagringen, annars läses ett enskilt tecken från strömmen och konverteras till **uint8_t**-typen.

```cpp
virtual int System::IO::BasicSTDIOStreamWrapper<T, typename>::ReadByte() override
```


### Returvärde

Ett 32-bitars heltal som motsvarar resultatet av läsningen
