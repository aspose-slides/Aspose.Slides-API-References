## AlphaBiLevel klass

Representerar en Alpha Bi-Level-effekt. Alpha (opacitet)-värden som är mindre än tröskeln ändras till 0 (helt transparent) och alpha-värden som är större än eller lika med tröskeln ändras till 100 % (helt opakt).

```cpp
class AlphaBiLevel : public Aspose::Slides::Effects::ImageTransformOperation,
                     public Aspose::Slides::Effects::IAlphaBiLevel,
                     public Aspose::Slides::Effects::IVisualEffect
```
