## PdfOptions::get_RasterizeUnsupportedFontStyles() metod

Indikerar huruvida text ska rasteriseras som en bitmap och sparas till PDF när typsnittet inte stöder fet stil. Detta tillvägångssätt kan förbättra kvaliteten på text i den resulterande PDF-filen för vissa typsnitt. Läs **bool**.

```cpp
bool Aspose::Slides::Export::PdfOptions::get_RasterizeUnsupportedFontStyles() override
```

## Anmärkningar

Standard är **false**.
