## PdfOptions::set_EmbedTrueTypeFontsForASCII(bool) metod


Bestämmer om [Aspose.Slides](../../../aspose.slides/) kommer att bädda in vanliga teckensnitt för ASCII (33..127 kodintervall) text. [Fonts](../../../aspose.slides/fonts/) för teckenkoder större än 127 är alltid inbäddade. Listan över vanliga teckensnitt inkluderar PDF:s bas 14-teckensnitt och ytterligare användarspecificerade teckensnitt. Skriv **bool**.

```cpp
void Aspose::Slides::Export::PdfOptions::set_EmbedTrueTypeFontsForASCII(bool value) override
```

## Anmärkningar


Standard är **true**.
