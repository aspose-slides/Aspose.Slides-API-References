## PdfOptions::get_JpegQuality() metod

Returnerar ett värde som bestämmer kvaliteten på JPEG-bilderna i PDF-dokumentet. Läs **uint8_t**.

```cpp
uint8_t Aspose::Slides::Export::PdfOptions::get_JpegQuality() override
```

## Anmärkningar

Har effekt endast när ett dokument innehåller JPEG-bilder.

Använd denna egenskap för att hämta eller ange kvaliteten på bilderna i ett dokument när du sparar i PDF-format. Värdet kan variera från 0 till 100 där 0 betyder sämst kvalitet men maximal komprimering och 100 betyder bästa kvalitet men minimal komprimering.

Standardvärdet är **100**.
