## NotesPositions enum

Representerar regeln för att rendera anteckningar i ett exporterat dokument

```cpp
enum class NotesPositions
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| None | 0 | Anger att anteckningar inte ska visas alls. |
| BottomFull | 1 | Anger att anteckningar ska visas fullständigt med extra sidor efter behov. |
| BottomTruncated | 2 | Anger att anteckningar ska visas på endast en sida. |
