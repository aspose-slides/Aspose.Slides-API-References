## HtmlOptions::set_JpegQuality(uint8_t) method


Sätter ett värde som bestämmer kvaliteten på JPEG-bilderna i PDF-dokumentet. Skriv **uint8_t**.

```cpp
void Aspose::Slides::Export::HtmlOptions::set_JpegQuality(uint8_t value) override
```

## Anmärkningar


Har endast effekt när ett dokument innehåller JPEG-bilder.

Använd den här egenskapen för att läsa eller skriva kvaliteten på bilderna i ett dokument när du sparar i PDF-format. Värdet kan variera från 0 till 100 där 0 betyder sämst kvalitet men maximal komprimering och 100 betyder bästa kvalitet men minimal komprimering.

Standardvärdet är **95**.
