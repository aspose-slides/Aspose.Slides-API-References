## EmbedFontCharacters enum

Representerar regeln som ska användas för att lägga till nya inbäddade teckensnitt i [IPresentation](../../aspose.slides/ipresentation/)

```cpp
enum class EmbedFontCharacters
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| OnlyUsed | 0 | Bädda endast in de tecken som används i presentationen (bäst för att minska filstorleken). |
| All | 1 | Bädda in alla tecken (bäst för redigering av andra personer). |
