## SvgEvent enum

Representerar alternativ för SVG-form.

```cpp
enum class SvgEvent
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| OnFocusIn | 0 | Uppstår när ett element får fokus, till exempel när en text blir markerad. |
| OnFocusOut | 1 | Uppstår när ett element förlorar fokus, till exempel när en text avmarkeras. |
| OnActivate | 2 | Uppstår när ett element aktiveras, till exempel genom ett musklick eller ett tangentnedslag. |
| OnClick | 3 | Uppstår när pekdonets knapp klickas över ett element. |
| OnMouseDown | 4 | Uppstår när pekdonets knapp trycks ned över ett element. |
| OnMouseUp | 5 | Uppstår när pekdonets knapp släpps över ett element. |
| OnMouseOver | 6 | Uppstår när pekdonet flyttas på ett element. |
| OnMouseMove | 7 | Uppstår när pekdonet flyttas medan det är över ett element. |
| OnMouseOut | 8 | Uppstår när pekdonet flyttas bort från ett element. |
| OnLoad | 9 | Uppstår när användaragenten har helt analyserat elementet och dess underordnade samt alla refererade resurser som krävs för att rendera det. |
| OnUnload | 10 | Uppstår när [DOM](../../aspose.slides.dom/)-implementeringen tar bort ett dokument från ett fönster eller en ram. Gäller endast för yttersta svg-element. |
| OnAbort | 11 | Uppstår när sidladdning stoppas innan ett element har fått laddas färdigt. |
| OnError | 12 | Uppstår när ett element inte laddas korrekt eller när ett fel inträffar under skriptkörning. |
| OnResize | 13 | Uppstår när en dokumentvy storleksändras. Gäller endast för yttersta svg-element. |
| OnScroll | 14 | Uppstår när en dokumentvy förflyttas längs X- eller Y-axeln eller båda. Gäller endast för yttersta svg-element. |
| OnZoom | 15 | Uppstår när zoomnivån för en dokumentvy ändras. Gäller endast för yttersta svg-element. |
| OnBegin | 16 | Uppstår när ett animationselement startar. |
| OnEnd | 17 | Uppstår när ett animationselement avslutas. |
| OnRepeat | 18 | Uppstår när ett animationselement upprepas. |
