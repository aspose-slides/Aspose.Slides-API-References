## IPdfOptions::set_RasterizeUnsupportedFontStyles(bool) metod


Anger huruvida text ska rasteriseras som en bitmap och sparas till PDF när teckensnittet inte stödjer fet styling. Detta tillvägagångssätt kan förbättra kvaliteten på text i den resulterande PDF-filen för vissa teckensnitt. Skriv **bool**.

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_RasterizeUnsupportedFontStyles(bool value)=0
```

## Anmärkningar


Standard är **false**.
