## IPdfOptions::get_RasterizeUnsupportedFontStyles() metod

Indikerar huruvida text ska rasteriseras som en bitmap och sparas till PDF när teckensnittet inte stöder fet stil. Detta tillvägagångssätt kan förbättra kvaliteten på texten i den resulterande PDF-filen för vissa teckensnitt. Läs **bool**.

```cpp
virtual bool Aspose::Slides::Export::IPdfOptions::get_RasterizeUnsupportedFontStyles()=0
```

## Anmärkningar

Standard är **false**.
