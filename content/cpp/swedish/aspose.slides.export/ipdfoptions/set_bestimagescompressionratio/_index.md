## IPdfOptions::set_BestImagesCompressionRatio(bool) metod

Anger om den mest effektiva komprimeringen (istället för standardkomprimeringen) för varje bild ska väljas automatiskt. Om den sätts till **bool**.true, kommer för varje bild i presentationen den mest lämpliga komprimeringsalgoritmen att väljas, vilket kommer att leda till en mindre storlek på det resulterande PDF-dokumentet.

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_BestImagesCompressionRatio(bool value)=0
```

## Anmärkningar

Val av bästa bildkomprimeringsförhållande är beräkningsintensivt och kräver extra RAM, och detta alternativ är som standard **bool**.false.

Standard är **bool**.false.
