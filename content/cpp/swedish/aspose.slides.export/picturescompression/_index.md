## PicturesCompression enum

Representerar komprimeringsnivån för bilder

```cpp
enum class PicturesCompression
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Dpi330 | 0 | Bra kvalitet för högupplösta (HD) skärmar |
| Dpi220 | 1 | Utmärkt kvalitet på de flesta skrivare och skärmar |
| Dpi150 | 2 | Bra för webbsidor och projektorer |
| Dpi96 | 3 | Minimera dokumentstorlek för delning |
| Dpi72 | 4 | Standard komprimeringsnivå |
| DocumentResolution | 5 | Använd dokumentupplösning - bilden kommer inte att komprimeras och används i dokumentet som den är |
