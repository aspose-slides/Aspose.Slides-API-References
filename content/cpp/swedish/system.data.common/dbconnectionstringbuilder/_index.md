## DbConnectionStringBuilder klass

API för att bygga anslutningssträng med namngivna fält. Objekt av denna klass bör endast allokeras med funktionen [System::MakeObject()](../../system/makeobject/). Skapa aldrig en instans av denna typ på stacken eller med operator new, eftersom det kan leda till körtidsfel och/eller assert-fel. Packa alltid in denna klass i en [System::SmartPtr](../../system/smartptr/)-pekare och använd denna pekare för att skicka den till funktioner som argument.

```cpp
class DbConnectionStringBuilder : public System::Object
```
