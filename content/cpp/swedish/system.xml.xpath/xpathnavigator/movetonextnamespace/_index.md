## XPathNavigator::MoveToNextNamespace(XPathNamespaceScope) metod

När den överskrivs i en avledd klass flyttas [XPathNavigator](../) till nästa namnrymdsnod som matchar den angivna XPathNamespaceScope.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToNextNamespace(XPathNamespaceScope namespaceScope)=0
```

### Argument

| Parameter | Type | Description |
| --- | --- | --- |
| namespaceScope | [XPathNamespaceScope](../../xpathnamespacescope/) | Ett XPathNamespaceScope-värde som beskriver namnrymdens omfattning. |

### Returvärde

**true** om [XPathNavigator](../) lyckas flyttas till nästa namnrymdsnod; annars **false**. Om **false** är positionen för [XPathNavigator](../) oförändrad.
