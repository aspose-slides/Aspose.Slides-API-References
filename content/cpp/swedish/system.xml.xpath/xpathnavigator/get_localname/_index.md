## XPathNavigator::get_LocalName() metod


När den överskuggas i en avledd klass hämtar den [XPathNavigator::get_Name](../get_name/) för den aktuella noden utan någon namnrymdspräfix.

```cpp
virtual String System::Xml::XPath::XPathNavigator::get_LocalName()=0
```


### Returvärde

En [String](../../../system/string/) som innehåller det lokala namnet på den aktuella noden, eller [String::Empty](../../../system/string/empty/) om den aktuella noden inte har ett namn (till exempel text- eller kommentarsnoder).
