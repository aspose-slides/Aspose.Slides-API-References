## XPathNavigator::get_IsEmptyElement() metod


När den åsidosätts i en underklass, hämtas ett värde som indikerar om den aktuella noden är ett tomt element utan en avslutande elementtagg.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::get_IsEmptyElement()=0
```


### Returvärde

**true** om den aktuella noden är ett tomt element; annars **false**.
