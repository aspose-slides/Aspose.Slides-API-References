## XPathNavigator::get_HasAttributes() metod


Returnerar ett värde som indikerar om den aktuella noden har några attribut.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::get_HasAttributes()
```


### Returvärde

**true** om den aktuella noden har attribut; returnerar **false** om den aktuella noden inte har attribut, eller om [XPathNavigator](../) inte är placerad på en elementnod.
