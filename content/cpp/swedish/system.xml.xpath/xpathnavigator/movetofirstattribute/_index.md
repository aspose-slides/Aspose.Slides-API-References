## XPathNavigator::MoveToFirstAttribute() metod


När den överskuggas i en avledd klass, flyttar [XPathNavigator](../) till det första attributet på den aktuella noden.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToFirstAttribute()=0
```


### Returvärde

**true** om [XPathNavigator](../) lyckas flytta till det första attributet på den aktuella noden; annars **false**. Om **false** är positionen för [XPathNavigator](../) oförändrad.
