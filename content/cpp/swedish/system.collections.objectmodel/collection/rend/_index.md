## Collection::rend() metod


Hämtar en omvänd iterator för ett icke-existerande element före samlingens början.

```cpp

```


### Returvärde

En omvänd iterator som pekar på det teoretiska elementet som föregår det första elementet i listan (sista i omvänd ordning).
