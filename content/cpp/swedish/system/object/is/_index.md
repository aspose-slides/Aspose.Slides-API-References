## Object::Is(const TypeInfo\&) const metod


Kontrollera om objektet representerar en instans av den typ som beskrivs av targetType. Analog till C#-operatorn 'is'.

```cpp
virtual bool System::Object::Is(const TypeInfo &targetType) const
```


### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| targetType | const [TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struktur som beskriver den typ som det aktuella objektet testas mot. |

### Returvärde

True om objektet är av den märkta typen eller dess underklass, false annars.
