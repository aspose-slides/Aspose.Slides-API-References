## MathF::Truncate(float) metod


Returnerar ett float-precision floating point value som har heltalsdelen lika med det angivna värdet och alla fraktionella siffror tas bort.

```cpp
static float System::MathF::Truncate(float x)
```


### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| x | **float** | Ett decimaltal |

### Returvärde

Ett float-precision floating point value vars heltalsdel är lika med det angivna värdet och de fraktionella siffrorna är alla 0.
