## Array::crend() const metod

Returnerar en omvänd iterator till elementet som följer det sista elementet i den omvända behållaren. Det motsvarar elementet som föregår det första elementet i den icke-omvända behållaren. Detta element fungerar som en platshållare, och ett försök att komma åt det resulterar i odefinierat beteende.

```cpp
const_reverse_iterator System::Array<T>::crend() const noexcept
```

### Returnvärde

En iterator som pekar på det teoretiska const-kvalificerade elementet som föregår det första elementet i behållaren.
