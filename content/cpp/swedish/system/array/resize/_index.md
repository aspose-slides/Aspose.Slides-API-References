## Array::Resize(ArrayPtr\<Type\>\&, int) metod

Ändrar storleken på den angivna arrayen till det specificerade värdet eller skapar en ny array med angiven storlek.

```cpp
template<typename Type> static void System::Array<T>::Resize(ArrayPtr<Type> &arr, int new_size)
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| arr | [ArrayPtr](../../arrayptr/)\<[Type](../../object/type/)\>\& | [Array](../) för att ändra storlek. Om **arr** är en null-pekare kommer den nya arrayen att skapas |
| new_size | int | Den nya storleken på arrayen, eller storleken på den nya arrayen om **arr** är null |
