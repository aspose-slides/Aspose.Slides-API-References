## Array::rend() metod


Returnerar en bakåtriktad iterator till elementet som följer det sista elementet i den omvända containern. Den motsvarar elementet som föregår det första elementet i den icke-omvända containern. Detta element fungerar som en platshållare; ett försök att komma åt det resulterar i odefinierat beteende.

```cpp
reverse_iterator System::Array<T>::rend() noexcept
```


### Return Value

En iterator som pekar på det teoretiska elementet som föregår det första elementet i containern.

## Array::rend() const metod


Returnerar en bakåtriktad iterator till elementet som följer det sista elementet i den omvända containern. Den motsvarar elementet som föregår det första elementet i den icke-omvända containern. Detta element fungerar som en platshållare; ett försök att komma åt det resulterar i odefinierat beteende.

```cpp
const_reverse_iterator System::Array<T>::rend() const noexcept
```


### Return Value

En iterator som pekar på det teoretiska elementet som föregår det första elementet i den const-kvalificerade containern.
