## Array::cend() const metod


Returnerar en iterator till elementet som följer det sista elementet i behållaren. Detta element fungerar som en platshållare; försök att komma åt det resulterar i odefinierat beteende.

```cpp
const_iterator System::Array<T>::cend() const noexcept
```


### Returvärde

En iterator som pekar på det teoretiska const-kvalificerade elementet som placeras efter det sista elementet i behållaren.
