## Array::end() metod


Returnerar en iterator till elementet som följer det sista elementet i behållaren. Detta element fungerar som en platshållare; ett försök att komma åt det resulterar i odefinierat beteende.

```cpp
iterator System::Array<T>::end() noexcept
```


### Returvärde

En iterator som pekar på det teoretiska elementet placerat efter det sista elementet i behållaren.

## Array::end() const metod


Returnerar en iterator till elementet som följer det sista elementet i den const-kvalificerade behållaren. Detta element fungerar som en platshållare; ett försök att komma åt det resulterar i odefinierat beteende.

```cpp
const_iterator System::Array<T>::end() const noexcept
```


### Returvärde

En iterator som pekar på det teoretiska elementet placerat efter det sista elementet i den const-kvalificerade behållaren.
