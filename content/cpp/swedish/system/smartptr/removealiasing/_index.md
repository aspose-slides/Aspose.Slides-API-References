## SmartPtr::RemoveAliasing() const metod

Tar bort aliasing (skapad av en aliasing-konstruktor) från pekaren, och säkerställer att den hanterar (om delad) eller spårar (om svag) samma objekt som den pekar på.

```cpp
SmartPtr_ System::SmartPtr<T>::RemoveAliasing() const
```

### Returvärde

Pekaren till samma objekt som denna pekare pekar på och som sköter livslängden för samma objekt.
