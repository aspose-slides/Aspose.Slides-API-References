## System::IsTuple(const SharedPtr\<Object\>\&, int32_t) funktion

bool System::IsTuple(const SharedPtr<Object> &object, int32_t length)

### Argument

| Parameter | Typ | Beskrivning |

| object | const [SharedPtr](../sharedptr/)\<[Object](../object/)\>\& | objekt att kontrollera. |
| length | **int32_t** | förväntad tuple-längd |

objektet är en tuple och dess längd är lika med den förväntade
