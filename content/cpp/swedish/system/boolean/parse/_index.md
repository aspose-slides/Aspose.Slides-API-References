## Boolean::Parse(const String\&) metod

Konverterar den angivna strängen till ett värde av bool-typ.

```cpp
static bool System::Boolean::Parse(const String &value)
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| value | const [String](../../string/)\& | Strängen som ska konverteras. |

### Returvärde

Bool-variabeln där resultatet av konverteringen placeras; resultatet är true om den angivna strängen är lika med "True" och false om den angivna strängen är lika med "False".
