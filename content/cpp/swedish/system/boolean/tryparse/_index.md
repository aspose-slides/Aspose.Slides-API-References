## Boolean::TryParse(const String\&, bool\&) metod


Konverterar den angivna strängen till ett värde av bool-typ.

```cpp
static bool System::Boolean::TryParse(const String &value, bool &result)
```


### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| value | const [String](../../string/)\& | Strängen att konvertera. |
| result | **bool**\& | Referensen till en bool-variabel där konverteringsresultatet placeras; resultatet är true om den angivna strängen är lika med "True" och false om den angivna strängen är lika med "False". |

### Returvärde

True om den angivna strängen är lika med antingen "True" eller "False", annars - false.
