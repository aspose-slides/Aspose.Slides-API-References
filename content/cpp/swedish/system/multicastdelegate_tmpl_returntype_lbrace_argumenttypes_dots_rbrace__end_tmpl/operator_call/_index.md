## MulticastDelegate< ReturnType(ArgumentTypes...)>::operator()(ArgumentTypes...) const metod


Invokerar alla delegater som för närvarande finns i delegatkollektionen. Delegater anropas i samma ordning som de lades till i samlingen. Operatorn blockerar medan delegaterna körs.

```cpp
ReturnType System::MulticastDelegate<ReturnType(ArgumentTypes...)>::operator()(ArgumentTypes... args) const
```


### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| args | ArgumentTypes... | Argument till delegaterna som ska anropas |

### Returvärde
