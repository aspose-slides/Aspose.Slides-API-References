## MulticastDelegate< ReturnType(ArgumentTypes...)>::invoke(ArgumentTypes...) const metod

Invokar alla delegater som för närvarande finns i delegatkollektionen. Delegater anropas i samma ordning som de lades till i kollektionen. Metoden blockerar medan delegaterna körs.

```cpp
ReturnType System::MulticastDelegate<ReturnType(ArgumentTypes...)>::invoke(ArgumentTypes... args) const
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| args | ArgumentTypes... | Argument att skicka till delegaterna som ska anropas |

### Returvärde
