## IComparable::CompareTo(T) metod

Jämför det aktuella objektet med det specificerade objektet.

```cpp
virtual int System::IComparable<T>::CompareTo(T other)=0
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| other | T | Objektet som ska jämföras med det aktuella objektet |

### Returvärde

Ett negativt tal om det aktuella objektet föregår det specificerade objektet i sorteringsordningen; 0 om de jämförda objekten är lika; ett positivt tal om det aktuella objektet följer det specificerade objektet i sorteringsordningen
