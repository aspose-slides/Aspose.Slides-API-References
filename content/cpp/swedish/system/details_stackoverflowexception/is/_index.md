## Details_StackOverflowException::Is(const System::TypeInfo\&) const method

```cpp
bool System::Details_StackOverflowException::Is(const System::TypeInfo &target) const override
```

### Arguments

| Parameter | Type | Description |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struktur som beskriver typen som det aktuella objektet ska testas mot. |

### Return Value

Sant om objektet är av den taggade typen eller dess underklass, annars falskt.

## Remarks

Kontrollera om objektet representerar en instans av den typ som beskrivs av targetType. Analog till C#-operatorn 'is'.
