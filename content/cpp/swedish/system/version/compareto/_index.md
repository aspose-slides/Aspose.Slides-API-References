## Version::CompareTo(const Version\&) const metod

Jämför de versioner som representeras av det aktuella objektet och det angivna objektet.

```cpp
int System::Version::CompareTo(const Version &ver) const
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| ver | const [Version](../)\& | Ett [Version](../)-objekt att jämföra med det aktuella objektet |

### Returvärde

- 1 om versionsnumret som representeras av det aktuella objektet är mindre än det som representeras av **ver**; 0 om versionsnumren är lika; 1 om versionsnumret som representeras av det aktuella objektet är större än värdet som representeras av **ver**
