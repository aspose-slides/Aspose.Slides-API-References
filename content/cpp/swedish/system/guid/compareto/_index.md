## Guid::CompareTo(const Guid\&) const metod

Utför aritmetisk jämförelse av GUID:erna som representeras av det aktuella och det angivna objektet.

```cpp
int System::Guid::CompareTo(const Guid &g) const
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| g | const [Guid](../)\& | Jämförelseobjekt |

### Returvärde

- 1 om GUID:en som representeras av det aktuella objektet är mindre än GUID:en som representeras av **g**; 0 om GUID:erna är lika; 1 om GUID:en som representeras av det aktuella objektet är större än GUID:en som representeras av **g**
