## UriParser klass


Används för att tolka ett nytt URI-schema. Objekt av den här klassen bör endast allokeras med [System::MakeObject()](../makeobject/) funktion. Skapa aldrig en instans av denna typ på stacken eller med operator new, eftersom det kommer att resultera i körfel och/eller assertionsfel. Omslut alltid den här klassen i [System::SmartPtr](../smartptr/) pekare och använd denna pekare för att skicka den till funktioner som argument.

```cpp
class UriParser
```
