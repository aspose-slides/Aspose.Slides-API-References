## Char::IsNumber(const char_t *, int) metod

Bestämmer om tecknet på det angivna indexet i den angivna teckenbufferten är klassificerat som ett tal.

```cpp
static bool System::Char::IsNumber(const char_t *str, int idx)
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| str | const char_t * | Pekare till början av teckenbufferten |
| idx | int | Ett nollbaserat index i den angivna bufferten för tecknet som ska testas |

### Returvärde

True om tecknet på det angivna indexet är ett tal, annars - false
