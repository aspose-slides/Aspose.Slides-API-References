## Char::IsLower(const char_t *, int) metod

```cpp
static bool System::Char::IsLower(const char_t *str, int idx)
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| str | const char_t * | Pekare till början av teckenbufferten |
| idx | int | Ett nollbaserat index i den angivna bufferten för tecknet som ska testas |

### Returvärde

Sant om tecknet på det angivna indexet är en gemen bokstav, annars - falskt
