## Char::IsPunctuation(const char_t *, int) metod

Avgör om tecknet på det angivna indexet i den angivna teckenbufferten klassificeras som ett skiljetecken.

```cpp
static bool System::Char::IsPunctuation(const char_t *str, int idx)
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| str | const char_t * | Pekare till början av teckenbufferten |
| idx | int | Nollbaserat index i den angivna bufferten för tecknet som ska testas |

### Returvärde

Sant om tecknet på det angivna indexet är ett skiljetecken, annars - falskt
