## Char::IsLowSurrogate(const char_t *, int) metod


Bestämmer om tecknet på det angivna indexet i den angivna teckenbufferten är en låg surrogat.

```cpp
static bool System::Char::IsLowSurrogate(const char_t *str, int idx)
```


### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| str | const char_t * | Pekare till början av teckenbufferten |
| idx | int | En nollbaserad index i den angivna bufferten för tecknet som ska testas |

### Returvärde

Sant om tecknet på den angivna indexen är en låg surrogat, annars - falskt
