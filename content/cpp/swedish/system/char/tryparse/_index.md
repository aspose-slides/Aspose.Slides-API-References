## Char::TryParse(const System::String\&, char_t\&) metod


Försöker konvertera en sträng bestående av ett enda tecken till ett UTF-16-tecken. Funktionen lyckas endast när indatasträngen inte är null och har en längd på exakt ett tecken.

```cpp
static bool System::Char::TryParse(const System::String &s, char_t &result)
```


### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| s | const [System::String](../../string/)\& | [String](../../string/) att konvertera |
| result | char_t\& | Den utdatavariabel som kommer att innehålla resultatet av konverteringen om konverteringen lyckas |

### Returvärde

True om konverteringen lyckades, annars - false
