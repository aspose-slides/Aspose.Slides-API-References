## Char::IsSurrogate(char_t) metod


Avgör om det angivna tecknet är en UTF-16 surrogate-kod enhet.

```cpp
static bool System::Char::IsSurrogate(char_t c)
```


### Argument

| Parameter | Type | Description |
| --- | --- | --- |
| c | char_t | Ett tecken |

### Returvärde

Sant om det angivna tecknet är en UTF-16 surrogate-kod enhet, annars falskt

## Char::IsSurrogate(const String\&, int) metod


Avgör om tecknet på det angivna indexet i den angivna strängen är en UTF-16 surrogate-kod enhet.

```cpp
static bool System::Char::IsSurrogate(const String &s, int index)
```


### Argument

| Parameter | Type | Description |
| --- | --- | --- |
| s | const [String](../../string/)\& | En sträng |
| index | int | Indexet för tecknet i den angivna strängen |

### Returvärde

Sant om tecknet på det angivna indexet är en UTF-16 surrogate-kod enhet, annars falskt
