## Char::IsControl(const char_t *, int) metod

Bestämmer om tecknet på den angivna indexen i den angivna teckenbufferten klassificeras som ett Unicode-kontrolltecken.

```cpp
static bool System::Char::IsControl(const char_t *str, int idx)
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| str | const char_t * | Pekare till början av teckenbufferten |
| idx | int | Nollbaserat index i den angivna bufferten för tecknet som ska testas |

### Returvärde

Sant om tecknet på den angivna indexen är ett Unicode-kontrolltecken, annars falskt

## Char::IsControl(char_t) metod

Bestämmer om det angivna tecknet klassificeras som ett Unicode-kontrolltecken.

```cpp
static bool System::Char::IsControl(char_t c)
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| c | char_t | Tecknet som ska testas |

### Returvärde

Sant om det angivna tecknet är ett Unicode-kontrolltecken, annars falskt
