## Char::IsSymbol(const char_t *, int) metod

Bestämmer om tecknet på den angivna indexen i den angivna teckenbufferten är klassificerat som ett symboltecken.

```cpp
static bool System::Char::IsSymbol(const char_t *str, int idx)
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| str | const char_t * | Pekare till början av teckenbufferten |
| idx | int | Ett nollbaserat index i den angivna bufferten för tecknet som ska testas |

### Returvärde

Sant om tecknet på den angivna indexen är ett symboltecken, annars - falskt
