## Char::IsWhiteSpace(const char_t *, int) metod


Bestämmer om tecknet på den angivna indexen i den specificerade teckenbufferten klassificeras som ett blankstegstecken.

```cpp
static bool System::Char::IsWhiteSpace(const char_t *str, int idx)
```


### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| str | const char_t * | Pekare till början av teckenbufferten |
| idx | int | Ett nollbaserat index i den specificerade bufferten för tecknet som ska testas |

### Returvärde

Sant om tecknet på den angivna indexen är ett blankstegstecken, annars - falskt
