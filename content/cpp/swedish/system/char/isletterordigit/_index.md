## Char::IsLetterOrDigit(const char_t *, int) metod

Avgör om tecknet på det angivna indexet i den angivna teckenbufferten är klassificerat som en Unicode-bokstav eller ett decimaltecken.

```cpp
static bool System::Char::IsLetterOrDigit(const char_t *str, int idx)
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| str | const char_t * | Pekare till början av teckenbufferten |
| idx | int | Ett nollbaserat index i den angivna bufferten för tecknet som ska testas |

### Returvärde

Sant om tecknet på det angivna indexet är en Unicode-bokstav eller ett decimaltecken, annars - falskt
