## Environment::get_Version() metod


Returnerar [Version](../../version/)-objektet som representerar informationen om versionen av den gemensamma språkruntimen. Versionsnumret som returneras av denna metod är snarare dummy och betyder inte att alla biblioteksklasser beter sig i enlighet med den returnerade versionen.

```cpp
static Version System::Environment::get_Version()
```
