## TypeCode enum

Representerar typen av ett objekt.

```cpp
enum class TypeCode
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Empty | 0 | En null-referens. |
| Object | 1 | En allmän typ som representerar vilken referens- eller värdetyp som helst som inte uttryckligen representeras av en annan TypeCode. |
| DBNull | 2 | Ett databas-null (kolumn)värde. |
| Boolean | 3 | En enkel typ som representerar [Boolean](../boolean/)-värden av true eller false. |
| Char | 4 | En heltalstyp som representerar osignerade 16-bitars heltal med värden mellan 0 och 65535. |
| SByte | 5 | En heltalstyp som representerar signerade 8-bitars heltal med värden mellan -128 och 127. |
| Byte | 6 | En heltalstyp som representerar osignerade 8-bitars heltal med värden mellan 0 och 255. |
| Int16 | 7 | En heltalstyp som representerar signerade 16-bitars heltal med värden mellan -32768 och 32767. |
| UInt16 | 8 | En heltalstyp som representerar osignerade 16-bitars heltal med värden mellan 0 och 65535. |
| Int32 | 9 | En heltalstyp som representerar signerade 32-bitars heltal med värden mellan -2147483648 och 2147483647. |
| UInt32 | 10 | En heltalstyp som representerar osignerade 32-bitars heltal med värden mellan 0 och 4294967295. |
| Int64 | 11 | En heltalstyp som representerar signerade 64-bitars heltal med värden mellan -9223372036854775808 och 9223372036854775807. |
| UInt64 | 12 | En heltalstyp som representerar osignerade 64-bitars heltal med värden mellan 0 och 18446744073709551615. |
| Single | 13 | En flyttalstyp som representerar värden som varierar från ungefär 1.5 x 10 -45 till 3.4 x 10 38 med en precision på 7 siffror. |
| Double | 14 | En flyttalstyp som representerar värden som varierar från ungefär 5.0 x 10 -324 till 1.7 x 10 308 med en precision på 15-16 siffror. |
| Decimal | 15 | En enkel typ som representerar värden som varierar från 1.0 x 10 -28 till ungefär 7.9 x 10 28 med 28-29 signifikanta siffror. |
| DateTime | 16 | En typ som representerar ett datum- och tidsvärde. |
| String | 18 | En förseglad klasstyp som representerar Unicode-teckensnittssträngar. |
