## String::IsNull() const metod

Kontrollerar om string betraktas som null. [String](../) är null och endast om den konstrueras via [String()](../string/) konstruktör, flyttas, kopieras eller tilldelas från en null string eller [reset()](../reset/) metod anropades.

```cpp
bool System::String::IsNull() const
```

### Returvärde

true om string betraktas som null, false annars.
