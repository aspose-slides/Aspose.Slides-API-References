## String::rend() const metod


Returnerar en bakåtriktad iterator till tecknet före det första tecknet (om sådant finns) i den faktiska strängbufferten.

```cpp
reverse_iterator System::String::rend() const
```


### Returvärde

Bakåtriktad iterator till elementet som föregår det första tecknet i den faktiska strängbufferten (om det finns) eller till elementet precis före den allokerade bufferten.
