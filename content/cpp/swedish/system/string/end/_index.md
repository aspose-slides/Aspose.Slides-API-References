## String::end() const metod


Returnerar en pekare till slutet av den faktiska strängbufferten. Allokerar aldrig om något. Garanterar inte att bufferten är null-terminerad.

```cpp
const UChar * System::String::end() const
```


### Returvärde

Pekare till det första elementet efter den faktiska strängbufferten, null-terminerad eller inte.
