## DateTime::FromOADate(double) metod

Returnerar en instans av [DateTime](../)-klassen som representerar datum- och tidsvärdet som motsvarar det angivna OLE Automation Date.

```cpp
static DateTime System::DateTime::FromOADate(double date)
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| date | **double** | OLE Automation Date för att konvertera till [DateTime](../)-objekt |

### Returvärde

En ny instans av [DateTime](../)-klassen som representerar samma datum och tid som **date**
