## DateTime::Compare(DateTime, DateTime) metod

Jämför två värden som representeras av de angivna instanserna av [DateTime](../) klass och returnerar ett värde som anger värdenas relativa position på tidslinjen.

```cpp
static constexpr int System::DateTime::Compare(DateTime t1, DateTime t2)
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| t1 | [DateTime](../) | Den första jämföranden |
| t2 | [DateTime](../) | Den andra jämföranden |

### Returvärde

Ett värde som är mindre än 0 om **t1** är tidigare än **t2**; 0 om **t1** är samma som **t2**; ett värde som är större än 0 om **t1** är senare än **t2**
