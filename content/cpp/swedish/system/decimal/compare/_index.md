## Decimal::Compare(const Decimal\&, const Decimal\&) metod

Bestämmer om värdet som representeras av det första [Decimal](../)-objektet är mindre än, lika med eller större än värdet som representeras av det andra [Decimal](../)-objektet.

```cpp
static int System::Decimal::Compare(const Decimal &d1, const Decimal &d2)
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| d1 | const [Decimal](../)\& | Det första jämförelsetalet |
| d2 | const [Decimal](../)\& | Det andra jämförelsetalet |

### Returvärde

- 1 om värdet som representeras av **d1** är mindre än värdet som representeras av **d2**; 0 om värdena är lika; 1 om värdet som representeras av **d1** är större än värdet som representeras av **d2**
