## System::operator*(const T\&, const Decimal\&) funktion

Returnerar en ny instans av klass [Decimal](../decimal/) som representerar ett värde som är resultatet av multiplikation av det angivna värdet och värdet som representeras av det angivna [Decimal](../decimal/)-objektet.

```cpp
template<typename T,typename _> Decimal System::operator*(const T &x, const Decimal &d)
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| x | const T\& | Den första multiplikatorn |
| d | const [Decimal](../decimal/)\& | Det [Decimal](../decimal/)-objektet som representerar den andra multiplikatorn |

### Returvärde

En ny instans av klass [Decimal](../decimal/) som representerar ett värde som är resultatet av multiplikation av **x** och värdet som representeras av **d**.
