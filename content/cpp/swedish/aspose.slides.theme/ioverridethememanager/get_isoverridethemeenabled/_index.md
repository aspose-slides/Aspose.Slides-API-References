## IOverrideThemeManager::get_IsOverrideThemeEnabled() metod


Avgör om [OverrideTheme](../../overridetheme/) återgör ärvt effektivt tema eller inte. För att aktivera [OverrideTheme](../../overridetheme/) för överskrivning, använd OverrideTheme.Init*() metoder. För att inaktivera [OverrideTheme](../../overridetheme/) från överskrivning, använd [get_OverrideTheme()](../get_overridetheme/)->Clear() metod. Skrivskyddad **bool**.

virtual bool Aspose::Slides::Theme::IOverrideThemeManager::get_IsOverrideThemeEnabled()=0
