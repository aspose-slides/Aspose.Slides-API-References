## BaseOverrideThemeManager::get_IsOverrideThemeEnabled() metod

Bestämmer om [OverrideTheme](../../overridetheme/) åsidosätter ärvt effektivt tema eller inte. För att möjliggöra [OverrideTheme](../../overridetheme/) för åsidosättning, använd OverrideTheme.Init*() metoderna. För att förhindra [OverrideTheme](../../overridetheme/) från att åsidosätta, använd [OverrideTheme::Clear](../../overridetheme/clear/) metoden. Skrivskyddad **bool**.
