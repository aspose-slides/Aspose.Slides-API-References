## X509IssuerSerial klass


Representerar '[X509IssuerSerial](./)' elementet i XML-signaturen. Objekt av denna klass ska endast allokeras med [System::MakeObject()](../../system/makeobject/)-funktionen. Skapa aldrig en instans av denna typ på stacken eller med operator new, eftersom det kan leda till körfel och/eller assertionsfel. Förpacka alltid denna klass i en [System::SmartPtr](../../system/smartptr/)-pekare och använd den pekaren för att skicka den till funktioner som argument.

class X509IssuerSerial : public System::Object
