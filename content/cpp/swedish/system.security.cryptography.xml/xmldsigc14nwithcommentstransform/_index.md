## XmlDsigC14NWithCommentsTransform klass

Representerar C14N XML-kanoniseringstransformen för en digital signatur med kommentarer. Objekt av denna klass bör endast allokeras med [System::MakeObject()](../../system/makeobject/)-funktionen. Skapa aldrig en instans av denna typ på stacken eller med operatorn new, då det kommer att resultera i körfel och/eller påståendesfel. Omslut alltid denna klass i en [System::SmartPtr](../../system/smartptr/)-pekare och använd pekaren för att skicka den till funktioner som argument.

```cpp
class XmlDsigC14NWithCommentsTransform : public System::Security::Cryptography::Xml::XmlDsigC14NTransform
```
