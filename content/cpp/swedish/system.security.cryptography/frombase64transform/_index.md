## FromBase64Transform klass

Konverterar [CryptoStream](../cryptostream/) klassinstans från base 64. Objekt av denna klass bör endast allokeras med hjälp av funktionen [System::MakeObject()](../../system/makeobject/). Skapa aldrig en instans av denna typ på stacken eller med operator new, eftersom det kommer att resultera i körfel och/eller påståendefel. Omslut alltid denna klass i en [System::SmartPtr](../../system/smartptr/)-pekare och använd pekaren för att skicka den till funktioner som argument.

```cpp
class FromBase64Transform : public System::Security::Cryptography::ICryptoTransform
```
