## SHA1CryptoServiceProvider klass

[SHA1](../sha1/) CSP-implementation. Objekt av denna klass ska endast allokeras med hjälp av [System::MakeObject()](../../system/makeobject/)-funktionen. Skapa aldrig en instans av denna typ på stacken eller med operator new, eftersom det kommer att resultera i körningsfel och/eller påståenden fel. Wrappa alltid denna klass i en [System::SmartPtr](../../system/smartptr/)-pekare och använd denna pekare för att skicka den till funktioner som argument.

```cpp
class SHA1CryptoServiceProvider : public System::Security::Cryptography::SHA1
```
