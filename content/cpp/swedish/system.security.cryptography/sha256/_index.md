## SHA256 klass

Beräknar [SHA256](./) hash för indata. I C++ [SHA256](./) är inte en abstrakt klass. Objekt av denna klass bör endast allokeras med hjälp av funktionen [System::MakeObject()](../../system/makeobject/). Skapa aldrig en instans av denna typ på stacken eller med operatorn new, eftersom det kommer att leda till körningsfel och/eller assertionsfel. Omslut alltid denna klass i en [System::SmartPtr](../../system/smartptr/)-pekare och använd denna pekare för att skicka den till funktioner som argument.

```cpp
class SHA256 : public System::Security::Cryptography::HashAlgorithm
```
