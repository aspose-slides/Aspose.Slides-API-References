## HMAC klass


Alla implementationer av Hash-based Message [Authentication](../../system.security.authentication/) Code ([HMAC](./)) måste ärva denna abstrakta klass. Objekt av denna klass bör endast allokeras med hjälp av [System::MakeObject()](../../system/makeobject/) funktion. Skapa aldrig en instans av denna typ på stacken eller med operatorn new, eftersom det kommer att resultera i körfel och/eller assertionsfel. Wrap alltid denna klass i en [System::SmartPtr](../../system/smartptr/)-pekare och använd denna pekare för att skicka den till funktioner som argument.

```cpp
class HMAC : public System::Security::Cryptography::HashAlgorithm
```
