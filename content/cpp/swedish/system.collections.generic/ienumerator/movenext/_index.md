## IEnumerator::MoveNext() metod

Flyttar uppräkningaren till nästa element. Om inget element har refererats tidigare, sätter referensen till det första tillgängliga elementet. Om slutet av behållaren nås, gör den ingenting.

```cpp
virtual bool System::Collections::Generic::IEnumerator<T>::MoveNext()=0
```

### Returvärde

True om ett element är tillgängligt efter anropet, false annars.
