## List::rend() metod

Hämtar en omvänd iterator för ett icke-existerande element före samlingens början.

```cpp
reverse_iterator System::Collections::Generic::List<T>::rend() noexcept
```

### Returvärde

En omvänd iterator som pekar på det teoretiska elementet som föregår det första elementet i listan (sist i omvänd ordning).

## List::rend() const metod

Hämtar en omvänd iterator för ett icke-existerande element före den const-kvalificerade samlingens början.

```cpp
const_reverse_iterator System::Collections::Generic::List<T>::rend() const noexcept
```

### Returvärde

En omvänd iterator som pekar på det teoretiska elementet som föregår det första elementet i den const-kvalificerade listan (sist i omvänd ordning).
