## BaseDictionary::end() const metod

Returnerar en iterator till KVPair-wrapper för nyckel-värde-element som följer det sista elementet i behållaren. Implementerad i C#-stil - iteratorn bör returnera KVPair-objektet med get_Key() och get_Value() gränssnittet. Detta element fungerar som en platshållare; försök att komma åt det leder till odefinierat beteende.

```cpp
const_iterator System::Collections::Generic::BaseDictionary<Map>::end() const noexcept
```

### Returvärde

En iterator som pekar på det teoretiska elementet som placeras efter slut-elementet i samlingen.
