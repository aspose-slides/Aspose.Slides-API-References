## IEnumerable::end() metod


Hämtar en iterator som pekar precis efter det sista elementet (om något) i samlingen. Den här iteratorn kan inte användas för att ändra ett refererat objekt eftersom [GetEnumerator()](../getenumerator/) returnerar ett kopieobjekt av T.

```cpp
iterator System::Collections::Generic::IEnumerable<T>::end()
```


### Returvärde

En iterator som pekar precis efter det sista elementet (om något) i samlingen
