## IEnumerable::LINQ_All(std::function\<bool(T)>) method

Bestämmer om alla element i en sekvens uppfyller ett villkor.

```cpp
bool System::Collections::Generic::IEnumerable<T>::LINQ_All(std::function<bool(T)> predicate)
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| predicate | std::function\<**bool**(T)> | En funktion som testar varje element för ett villkor. |

### Returvärde

true om varje element i källsekvensen klarar testet i det angivna predikatet, eller om sekvensen är tom; annars false.
