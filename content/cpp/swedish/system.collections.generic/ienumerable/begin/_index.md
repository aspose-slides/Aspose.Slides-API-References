## IEnumerable::begin() metod

Hämtar en iterator som pekar på det första elementet (om något) i samlingen. Denna iterator kan inte användas för att ändra ett refererat objekt eftersom [GetEnumerator()](../getenumerator/) returnerar ett kopieringsobjekt av T.

```cpp
iterator System::Collections::Generic::IEnumerable<T>::begin()
```

### Returvärde

En iterator som pekar på det första elementet (om något) i samlingen

## IEnumerable::begin() const metod

Hämtar en iterator som pekar på det första elementet (om något) i den konstantkvalificerade instansen av samlingen.

```cpp
const_iterator System::Collections::Generic::IEnumerable<T>::begin() const
```

### Returvärde

En iterator som pekar på det första elementet (om något) i den konstantkvalificerade instansen av samlingen
