## SoapParameterStyle enum

Enumererar parameterformaten i ett SOAP-meddelande.

```cpp
enum class SoapParameterStyle
```

### Values

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Default | 0 | Om '[SoapDocumentServiceAttribute](../soapdocumentserviceattribute/)' inte tillämpas på klassen, så är standardvärdet 'Wrapped'. |
| Bare | 1 | Parametrarna placeras i XML-element som följer 'Body'-elementet. |
| Wrapped | 2 | Parametrarna kapslas in i ett enda XML-element som följer 'Body'-elementet. |
