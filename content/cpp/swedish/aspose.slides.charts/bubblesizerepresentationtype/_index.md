## BubbleSizeRepresentationType enum

Anger de möjliga sätten att representera data som bubbeldiagramstorlekar.

```cpp
enum class BubbleSizeRepresentationType
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Area | 0 | Anger att arean på bubblorna ska vara proportionell mot bubbelns storleksvärde. |
| Width | 1 | Anger att radien på bubblorna ska vara proportionell mot bubbelns storleksvärde. |
