## TickMarkType enum


Representerar tick-markeringstypen för den angivna axeln.

```cpp
enum class TickMarkType
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Cross | 0 | Anger att tick-markeringarna ska korsa axeln. |
| Inside | 1 | Anger att tick-markeringarna ska vara inom diagramområdet. |
| None | 2 | Anger att det inte ska finnas någon tick-markering. |
| Outside | 3 | Anger att tick-markeringarna ska vara utanför diagramområdet. |
