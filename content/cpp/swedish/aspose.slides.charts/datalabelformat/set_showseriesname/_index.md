## DataLabelFormat::set_ShowSeriesName(bool) metod

Ställer in en Boolean för att ange beteendet för visning av serienamnet för dataetiketterna i ett diagram. True för att visa serienamnet. False för att dölja. Skriv **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowSeriesName(bool value) override
```

## Anmärkningar

Om föräldern till detta [DataLabelFormat](../)-objekt är en [DataLabelCollection](../../datalabelcollection/)-samling av dataetiketter, så hämtar eller anger denna egenskap standardvärdet för egenskapen ShowSeriesName för de nya dataetiketterna i [DataLabelCollection](../../datalabelcollection/)-samlingen. Att ange denna egenskap med ett värde sätter också detta värde för egenskapen ShowSeriesName för alla dataetiketter i [DataLabelCollection](../../datalabelcollection/)-samlingen (t.ex. "DataLabels.DefaultDataLabelFormat.ShowSeriesName = val;" vilket gör att alla DataLabels[i].ShowSeriesName är lika med val).
