## DataLabelFormat::set_ShowLabelValueFromCell(bool) metod

Representerar en angiven diagrammets dataetikettcellvärdesvisningsbeteende. True visar cellvärdet. False för att dölja. Skriv **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLabelValueFromCell(bool value) override
```

## Anmärkningar

Om föräldern till detta [DataLabelFormat](../)-objekt är en [DataLabelCollection](../../datalabelcollection/)-samling av dataetiketter så hämtar eller sätter denna egenskap standardvärdet för egenskapen ShowLabelValueFromCell för de nya dataetiketterna i [DataLabelCollection](../../datalabelcollection/)-samlingen. Att sätta denna egenskap med ett värde sätter också detta värde till egenskapen ShowLabelValueFromCell för alla dataetiketter i [DataLabelCollection](../../datalabelcollection/)-samlingen (d.v.s. "DataLabels.DefaultDataLabelFormat.ShowLabelValueFromCell = val;" vilket gör att alla DataLabels[i].ShowLabelValueFromCell är lika med val).
