## DataLabelFormat::set_Position(LegendDataLabelPosition) metod

Representerar positionen för dataetiketten. Skriv [LegendDataLabelPosition](../../legenddatalabelposition/).

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_Position(LegendDataLabelPosition value) override
```

## Anmärkningar

Om föräldern till detta [DataLabelFormat](../) objekt är en [DataLabelCollection](../../datalabelcollection/) samling av dataetiketter så hämtar eller anger den här egenskapen standardvärdet för egenskapen Position för de nya dataetiketterna i [DataLabelCollection](../../datalabelcollection/) samlingen. Representerar positionen för [DataLabel](../../datalabel/) objekten. Att sätta den här egenskapen med ett värde sätter också detta värde till egenskapen Position för alla dataetiketter i [DataLabelCollection](../../datalabelcollection/) samlingen (i.e. \"DataLabels.DefaultDataLabelFormat.Position = val;\" vilket gör att alla DataLabels[i].Position är lika med val).
