## DataLabelFormat::set_ShowLeaderLines(bool) metod


Representerar beteendet för visning av ledarlinjer för dataetiketter i ett specificerat diagram. True visar ledarlinjerna. False döljer dem. Skriv **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLeaderLines(bool value) override
```

## Anmärkningar


Om föräldern till detta [DataLabelFormat](../)-objekt är en [DataLabelCollection](../../datalabelcollection/)-samling av dataetiketter, så hämtar eller anger denna egenskap standardvärdet för egenskapen ShowLeaderLines för de nya dataetiketterna i [DataLabelCollection](../../datalabelcollection/)-samlingen. Att ange denna egenskap med ett värde sätter också detta värde på egenskapen ShowLeaderLines för alla dataetiketter i [DataLabelCollection](../../datalabelcollection/)-samlingen (dvs. "DataLabels.DefaultDataLabelFormat.ShowLeaderLines = val;" vilket gör att alla DataLabels[i].ShowLeaderLines är lika med val).
