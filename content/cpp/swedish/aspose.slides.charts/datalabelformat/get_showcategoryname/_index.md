## DataLabelFormat::get_ShowCategoryName() metod


Representerar ett specificerat diagramdatapunkts kategorinamnsvisningsbeteende. True för att visa kategorinamnet för datapunkterna i ett diagram. False för att dölja. Läs **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowCategoryName() override
```

## Anmärkningar


Om föräldern till detta [DataLabelFormat](../)-objekt är en [DataLabelCollection](../../datalabelcollection/)-samling av datapunkter så får den här egenskapen eller sätter standardvärdet för egenskapen ShowCategoryName för de nya datapunkterna i [DataLabelCollection](../../datalabelcollection/)-samlingen. Att sätta den här egenskapen med ett värde sätter också detta värde till egenskapen ShowCategoryName för alla datapunkter i [DataLabelCollection](../../datalabelcollection/)-samlingen (dvs. "DataLabels.DefaultDataLabelFormat.ShowCategoryName = val;" orsakar att alla DataLabels[i].ShowCategoryName är lika med val).
