## DataLabelFormat::set_ShowBubbleSize(bool) metod

Representerar ett specifikt diagrams datamärkningars bubbelformats värdevisningsbeteende. True visar bubbelformatsvärdet. False för att dölja. Skriv **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowBubbleSize(bool value) override
```

## Anmärkningar

Om föräldern till detta [DataLabelFormat](../)-objekt är en [DataLabelCollection](../../datalabelcollection/)-samling av datamärkningar, så hämtar eller anger denna egenskap standardvärdet för ShowBubbleSize-egenskapen för de nya datamärkningarna i [DataLabelCollection](../../datalabelcollection/)-samlingen. Att ange denna egenskap med ett värde sätter också detta värde till ShowBubbleSize-egenskapen för alla datamärkningar i [DataLabelCollection](../../datalabelcollection/)-samlingen (t.ex. \"DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;\" vilket gör att alla DataLabels[i].ShowBubbleSize är lika med val).
