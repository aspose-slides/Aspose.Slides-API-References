## DataLabelFormat::set_Separator(System::String) metod


Ställer in eller returnerar en Variant som representerar separatorn som används för dataetiketterna i ett diagram. Skriv [System::String](../../../system/string/).

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_Separator(System::String value) override
```

## Anmärkningar


Om föräldern till detta [DataLabelFormat](../)-objekt är en [DataLabelCollection](../../datalabelcollection/)-samling av dataetiketter så får den här egenskapen eller sätter standardvärdet för Separator-egenskapen för de nya dataetiketterna i [DataLabelCollection](../../datalabelcollection/)-samlingen. Att sätta den här egenskapen med ett värde sätter också detta värde till Separator-egenskapen för alla dataetiketter i [DataLabelCollection](../../datalabelcollection/)-samlingen (dvs. "DataLabels.DefaultDataLabelFormat.Separator = val;" vilket gör att alla DataLabels[i].Separator är lika med val).
