## DataLabelFormat::set_ShowPercentage(bool) metod


Representerar ett specificerat diagrammets datalabels procentvärdes visningsbeteende. True visar procentvärdet. False döljer det. Skriv **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowPercentage(bool value) override
```

## Anmärkningar


Om föräldern till detta [DataLabelFormat](../)-objekt är en [DataLabelCollection](../../datalabelcollection/)-samling av datalabels, så hämtar eller anger den här egenskapen standardvärdet för ShowPercentage-egenskapen för de nya datalabels i [DataLabelCollection](../../datalabelcollection/)-samlingen. Att sätta denna egenskap med ett värde sätter också detta värde till ShowPercentage-egenskapen för alla datalabels i [DataLabelCollection](../../datalabelcollection/)-samlingen (t.ex. "DataLabels.DefaultDataLabelFormat.ShowPercentage = val;" vilket gör att alla DataLabels[i].ShowPercentage är lika med val).
