## DataLabelFormat::set_ShowLegendKey(bool) metod

Representerar ett specificerat diagrams datamärkningslegendnyckelvisningsbeteende. Sant om datamärkningslegendnyckeln är synlig. Skriv **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLegendKey(bool value) override
```

## Anmärkningar

Om föräldern till detta [DataLabelFormat](../)-objekt är en [DataLabelCollection](../../datalabelcollection/)-samling av datamärkningar, så hämtar eller sätter denna egenskap standardvärdet för ShowLegendKey-egenskapen för de nya datamärkningarna i [DataLabelCollection](../../datalabelcollection/)-samlingen. Att sätta denna egenskap med ett värde sätter också detta värde till ShowLegendKey-egenskapen för alla datamärkningar i [DataLabelCollection](../../datalabelcollection/)-samlingen (dvs. "DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;" som gör att alla DataLabels[i].ShowLegendKey är lika med val).
