## DataLabelFormat::set_ShowLabelAsDataCallout(bool) metod


Bestämmer om den angivna diagrammets datamärkning visas som dataanrop eller som datamärkning.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLabelAsDataCallout(bool value) override
```

## Anmärkningar


Om föräldern till detta [DataLabelFormat](../) objekt är en [DataLabelCollection](../../datalabelcollection/) samling av datamärkningar, så får eller sätter denna egenskap standardvärdet för egenskapen ShowLabelAsDataCallout för de nya datamärkningarna i [DataLabelCollection](../../datalabelcollection/) samlingen. Att sätta denna egenskap med ett värde sätter också detta värde i egenskapen ShowLabelAsDataCallout för alla datamärkningar i [DataLabelCollection](../../datalabelcollection/) samlingen (t.ex. "DataLabels.DefaultDataLabelFormat.ShowLabelAsDataCallout = val;" gör att alla DataLabels[i].ShowLabelAsDataCallout blir lika med val).
