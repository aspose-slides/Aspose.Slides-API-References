## ErrorBarValueType enum

Representerar typen av felstapelsvärde

```cpp
enum class ErrorBarValueType
```

### Values

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Custom | 0 | Anger att längden på felstaplarna ska bestämmas av Plus och Minus element. |
| Fixed | 1 | Anger att längden på felstaplarna ska vara det fasta värdet som bestäms av Error Bar Value. |
| Percentage | 2 | Anger att längden på felstaplarna ska vara Error Bar Value procent av data. |
| StandardDeviation | 3 | Anger att längden på felstaplarna ska vara Error Bar Value standardavvikelser av data. |
| StandardError | 4 | Anger att längden på felstaplarna ska vara Error Bar Value standardfel av data. |
