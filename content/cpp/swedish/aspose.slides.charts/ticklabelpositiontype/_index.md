## TickLabelPositionType enum

Representerar positionstypen för tick-mark-etiketter på den angivna axeln.

```cpp
enum class TickLabelPositionType
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| High | 0 | Anger att axellabels ska vara vid den högsta änden av den vinkelräta axeln. |
| Low | 1 | Anger att axellabels ska vara vid den lägsta änden av den vinkelräta axeln. |
| NextTo | 2 | Anger att axellabels ska vara intill axeln. |
| None | 3 | Anger att axellabels inte ritas. |
