## DataSourceType enum


Datakälltyper.

```cpp
enum class DataSourceType
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Worksheet | 0 | Använd CellXls-objekt för att lagra XValue, YValue, Value eller BubbleSize för datapunkten i arbetsblad. |
| StringLiterals | 1 | Använd en snabbåtkomst-strängvariabel för att lagra XValue, YValue, Value eller BubbleSize för datapunkten. Worksheet används INTE för att lagra värden. |
| DoubleLiterals | 2 | Använd en snabbåtkomst-dubbelvariabel för att lagra XValue, YValue, Value eller BubbleSize för datapunkten. Worksheet används INTE för att lagra värden. |
