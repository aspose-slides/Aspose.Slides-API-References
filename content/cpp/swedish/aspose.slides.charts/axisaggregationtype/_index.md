## AxisAggregationType enum

Representerar aggregeringstyp för kategoriaxeln. Används endast med Histogram- eller HistogramPareto-serier.

```cpp
enum class AxisAggregationType
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| ByCategory | 0 | Aggregera efter kategorier |
| Automatic | 1 | Aggregera kategorier automatiskt. |
| ByBinWidth | 2 | Aggregera kategorier efter stapelbredd. Egenskapen IAxis::get(set)_BinWidth måste vara inställd. |
| ByNumberOfBins | 3 | Aggregera kategorier efter antal staplar. Egenskapen IAxis::get(set)_NumberOfBins måste vara inställd. |
