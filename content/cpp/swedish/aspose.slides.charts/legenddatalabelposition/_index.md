## LegendDataLabelPosition enum

Bestämmer positionen för dataetiketter.

```cpp
enum class LegendDataLabelPosition
```

### Värden

| Name | Value | Description |
| --- | --- | --- |
| NotDefined | -1 | Positionen är inte definierad. |
| Bottom | 0 | Anger att dataetiketter ska visas under datamarkören. |
| BestFit | 1 | Anger att dataetiketter ska visas i den bästa positionen. |
| Center | 2 | Anger att dataetiketter ska visas centrerat på datamarkören. |
| InsideBase | 3 | Anger att dataetiketter ska visas i basen av datamarkören. |
| InsideEnd | 4 | Anger att dataetiketter ska visas i änden av datamarkören. |
| Left | 5 | Anger att dataetiketter ska visas till vänster om datamarkören. |
| OutsideEnd | 6 | Anger att dataetiketter ska visas utanför änden av datamarkören. |
| Right | 7 | Anger att dataetiketter ska visas till höger om datamarkören. |
| Top | 8 | Anger att dataetiketter ska visas ovanför datamarkören. |
