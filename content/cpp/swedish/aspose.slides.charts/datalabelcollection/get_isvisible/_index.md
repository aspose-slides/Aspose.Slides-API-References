## DataLabelCollection::get_IsVisible() metod

False betyder att datamärket inte är synligt som standard (och således är alla Show*-flaggor (ShowValue, ...) för egenskapen DefaultDataLabelFormat falska). Skrivskyddad **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelCollection::get_IsVisible() override
```

## Anmärkningar

Om datamärket är synligt som standard kan du göra det dolt som standard med [Hide()](../hide/)-metoden. Men om datamärket inte är synligt som standard (IsVisible är falskt) kan du göra datamärket "synligt som standard" genom att sätta Show*-flaggorna (ShowValue, ...) för egenskapen DefaultDataLabelFormat till sant tillstånd.
