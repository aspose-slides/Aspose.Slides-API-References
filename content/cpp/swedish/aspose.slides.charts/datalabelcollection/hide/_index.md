## DataLabelCollection::Hide() metod

Gör dataetikett dold som standard genom att sätta alla Show*-flags (ShowValue, ...) för egenskapen DefaultDataLabelFormat till falskt läge. IsVisible blir falskt efter detta.

```cpp
void Aspose::Slides::Charts::DataLabelCollection::Hide() override
```

## Anmärkningar

Om dataetikett inte är synlig som standard (IsVisible är falskt) kan du göra dataetikett "synlig som standard" genom att sätta Show*-flags (ShowValue, ...) för egenskapen DefaultDataLabelFormat till sant läge.
