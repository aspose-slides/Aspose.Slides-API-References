## ChartCategory::get_UseCell() method


Om true är då AsCell-egenskapen aktuell. Med andra ord används arbetsbladet för att lagra kategori (detta fall stödjer en flernivåkategori). Om false är då AsLiteral-egenskapen aktuell. Med andra ord används arbetsbladet INTE för att lagra kategori (och detta fall stödjer inte flernivåskategorier). Skrivskyddad **bool**.

```cpp
bool Aspose::Slides::Charts::ChartCategory::get_UseCell() override
```

## Anmärkningar


För att ändra värdet på denna egenskap (för alla kategorier i samlingen) sätt ett nytt värde på ChartCategoryCollection::get(set)_UseCells-egenskapen.
