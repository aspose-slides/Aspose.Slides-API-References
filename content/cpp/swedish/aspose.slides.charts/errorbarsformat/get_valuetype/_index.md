## ErrorBarsFormat::get_ValueType() metod

Representerar möjliga sätt att bestämma längden på felstaplarna. Vid anpassad värdetyp för att ange värde, använd [IChartDataPoint::get_ErrorBarsCustomValues()](../../ichartdatapoint/get_errorbarscustomvalues/) egenskap för en specifik datapunkt i DataPoints samling av serien. Vid Fixed, Percentage eller StandardDeviation värdetyp, använd Value egenskap för att ange värde.
