## IChartCategoryCollection::get_UseCells() metod


Om true så används arbetsblad för att lagra kategorier (detta fall stödjer flernivåkategorier). Om false så är arbetsblad INTE använt för att lagra värden (och detta fall stödjer inte flernivåkategorier). Läs **bool**.

virtual bool Aspose::Slides::Charts::IChartCategoryCollection::get_UseCells()=0
