## IChartCategoryCollection::set_UseCells(bool) metod


Om true är arbetsbladet använt för att lagra kategorier (detta fall stöder flernivåkategorier). Om false är arbetsbladet INTE använt för att lagra värden (och detta fall stöder inte flernivåkategorier). Skriv **bool**.

virtual void Aspose::Slides::Charts::IChartCategoryCollection::set_UseCells(bool value)=0
