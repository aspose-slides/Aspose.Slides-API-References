## IDataLabelCollection::get_IsVisible() metod


False betyder att dataetikett inte är synlig som standard (och så är alla Show*-flags (ShowValue, ...) för egenskapen DefaultDataLabelFormat falska). Skrivskyddad **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelCollection::get_IsVisible()=0
```

## Anmärkningar


Om dataetikett är synlig som standard kan du göra den dold som standard med [Hide()](../hide/)-metoden. Men om dataetikett inte är synlig som standard (IsVisible är falskt) kan du göra dataetikett \"visible 
by default\" genom att sätta Show*-flags (ShowValue, ...) för egenskapen DefaultDataLabelFormat till sant.
