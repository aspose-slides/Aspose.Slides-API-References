## IDataLabelCollection::Hide() metod

Gör dataetiketten dold som standard genom att sätta alla Show*-flags (ShowValue, ...) för egenskapen DefaultDataLabelFormat till falskt tillstånd. IsVisible blir falskt efter detta.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelCollection::Hide()=0
```

## Anmärkningar

Om dataetiketten inte är synlig som standard (IsVisible är falskt) kan du göra dataetiketten \"synlig 
som standard\" genom att sätta Show*-flags (ShowValue, ...) för egenskapen DefaultDataLabelFormat till sant tillstånd.
