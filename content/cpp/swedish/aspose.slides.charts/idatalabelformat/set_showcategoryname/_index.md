## IDataLabelFormat::set_ShowCategoryName(bool) metod

Representerar ett specificerat diagramdatasetiketts kategorinamnvisningsbeteende. True för att visa kategorinamnet för dataetiketterna på ett diagram. False för att dölja. Skriv **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowCategoryName(bool value)=0
```

## Anmärkningar

Om föräldern till detta [DataLabelFormat](../../datalabelformat/)-objekt är en [DataLabelCollection](../../datalabelcollection/)-samling av dataetiketter, så hämtar eller sätter denna egenskap standardvärdet för ShowCategoryName egenskapen för de nya dataetiketterna i [DataLabelCollection](../../datalabelcollection/)-samlingen. Att sätta denna egenskap med ett värde sätter också detta värde till ShowCategoryName egenskapen för alla dataetiketter i [DataLabelCollection](../../datalabelcollection/)-samlingen (t.ex. "DataLabels.DefaultDataLabelFormat.ShowCategoryName = val;" vilket gör att alla DataLabels[i].ShowCategoryName blir lika med val).
