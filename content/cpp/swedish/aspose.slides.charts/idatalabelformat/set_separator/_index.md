## IDataLabelFormat::set_Separator(System::String) metod

Ställer in eller returnerar en Variant som representerar separatorn som används för dataetiketterna i ett diagram. Skriv [System::String](../../../system/string/).

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_Separator(System::String value)=0
```

## Anmärkningar

Om föräldern till detta [DataLabelFormat](../../datalabelformat/)-objekt är en [DataLabelCollection](../../datalabelcollection/)-samling av dataetiketter, så hämtar eller anger den här egenskapen standardvärdet för Separator-egenskapen för de nya dataetiketterna i [DataLabelCollection](../../datalabelcollection/)-samlingen. Att ange den här egenskapen med ett värde sätter även detta värde till Separator-egenskapen för alla dataetiketter i [DataLabelCollection](../../datalabelcollection/)-samlingen (t.ex. \"DataLabels.DefaultDataLabelFormat.Separator = val;\" vilket gör att alla DataLabels[i].Separator är lika med val).
