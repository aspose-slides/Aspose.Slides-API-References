## IDataLabelFormat::set_ShowLabelAsDataCallout(bool) metod


Avgör om den angivna diagrammets datamärkning ska visas som datakallout eller som datamärkning.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowLabelAsDataCallout(bool value)=0
```

## Anmärkningar


Om föräldern till detta [DataLabelFormat](../../datalabelformat/)-objekt är en [DataLabelCollection](../../datalabelcollection/) samling av datamärkningar, får eller anger denna egenskap standardvärdet för ShowLabelAsDataCallout-egenskapen för de nya datamärkningarna i [DataLabelCollection](../../datalabelcollection/)-samlingen. Att sätta denna egenskap till ett värde sätter också detta värde för ShowLabelAsDataCallout-egenskapen för alla datamärkningar i [DataLabelCollection](../../datalabelcollection/)-samlingen (t.ex. "DataLabels.DefaultDataLabelFormat.ShowLabelAsDataCallout = val;" gör att alla DataLabels[i].ShowLabelAsDataCallout är lika med val).
