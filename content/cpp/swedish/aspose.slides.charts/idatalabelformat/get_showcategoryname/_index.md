## IDataLabelFormat::get_ShowCategoryName() metod


Representerar ett specificerat diagram's datataggars kategorinamnsvisningsbeteende. True för att visa kategorinamnet för datataggarnas på ett diagram. False för att dölja. Läs **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowCategoryName()=0
```

## Anmärkningar


Om föräldern till detta [DataLabelFormat](../../datalabelformat/)-objekt är en [DataLabelCollection](../../datalabelcollection/)-samling av datatagglar så får eller sätter den här egenskapen standardvärdet för ShowCategoryName-egenskapen för de nya datatagglarna i [DataLabelCollection](../../datalabelcollection/)-samlingen. Att sätta den här egenskapen med ett värde sätter också detta värde på ShowCategoryName-egenskapen för alla datatagglar i [DataLabelCollection](../../datalabelcollection/)-samlingen (i.e. \"DataLabels.DefaultDataLabelFormat.ShowCategoryName = val;\" vilket gör att alla DataLabels[i].ShowCategoryName är lika med val).
