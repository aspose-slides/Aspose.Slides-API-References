## IDataLabelFormat::get_ShowValue() metod


Representerar ett specifikt diagrammets datalabels procentvärdesvisningsbeteende. True visar procentvärdet. False för att dölja. Läs **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowValue()=0
```

## Anmärkningar


Om föräldern till detta [DataLabelFormat](../../datalabelformat/)-objekt är en [DataLabelCollection](../../datalabelcollection/)-samling av datalabels så får den här egenskapen eller sätter standardvärdet för ShowValue-egenskapen för de nya datalabels i [DataLabelCollection](../../datalabelcollection/)-samlingen. Att sätta den här egenskapen med ett värde sätter också detta värde till ShowValue-egenskapen för alla datalabels i [DataLabelCollection](../../datalabelcollection/)-samlingen (i.e. \"DataLabels.DefaultDataLabelFormat.ShowValue = val;\" vilket gör att alla DataLabels[i].ShowValue är lika med val).
