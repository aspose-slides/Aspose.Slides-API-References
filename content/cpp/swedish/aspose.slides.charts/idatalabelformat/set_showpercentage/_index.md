## IDataLabelFormat::set_ShowPercentage(bool) metod

Representerar hur procentsatsen för dataetiketter i ett specificerat diagram visas. True visar procentsatsen. False döljer den. Skriv **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowPercentage(bool value)=0
```

## Anmärkningar

Om föräldern till detta [DataLabelFormat](../../datalabelformat/)-objekt är en [DataLabelCollection](../../datalabelcollection/)-samling av dataetiketter, får den här egenskapen eller anger standardvärdet för ShowPercentage-egenskapen för de nya dataetiketterna i [DataLabelCollection](../../datalabelcollection/)-samlingen. Att sätta den här egenskapen med ett värde sätter även detta värde till ShowPercentage-egenskapen för alla dataetiketter i [DataLabelCollection](../../datalabelcollection/)-samlingen (t.ex. "DataLabels.DefaultDataLabelFormat.ShowPercentage = val;" gör att alla DataLabels[i].ShowPercentage är lika med val).
