## IDataLabelFormat::set_ShowLabelValueFromCell(bool) metod


Representerar ett specificerat diagrammets datalabel-cellvärdesvisningsbeteende. True visar cellvärdet. False döljer det. Skriv **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowLabelValueFromCell(bool value)=0
```

## Anmärkningar


Om föräldern till detta [DataLabelFormat](../../datalabelformat/)-objekt är en [DataLabelCollection](../../datalabelcollection/)-samling av dataetiketter så hämtar eller anger denna egenskap standardvärdet för ShowLabelValueFromCell-egenskapen för de nya dataetiketterna i [DataLabelCollection](../../datalabelcollection/)-samlingen. Att ange denna egenskap med ett värde sätter också detta värde på ShowLabelValueFromCell-egenskapen för alla dataetiketter i [DataLabelCollection](../../datalabelcollection/)-samlingen (i.e. \"DataLabels.DefaultDataLabelFormat.ShowLabelValueFromCell = val;\" vilket gör att alla DataLabels[i].ShowLabelValueFromCell blir lika med val).
