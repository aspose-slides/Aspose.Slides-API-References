## IDataLabelFormat::get_ShowLeaderLines() metod


Representerar ett specificerat diagrammets datamärkes-ledarlinjers visningsbeteende. True visar ledarlinjerna. False för att dölja. Läs **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowLeaderLines()=0
```

## Anmärkningar


Om föräldern till detta [DataLabelFormat](../../datalabelformat/)-objekt är en [DataLabelCollection](../../datalabelcollection/)-samling av datamärken så hämtar eller ställer denna egenskap in standardvärdet för ShowLeaderLines-egenskapen för de nya datamärkena i [DataLabelCollection](../../datalabelcollection/)-samlingen. Att ange detta egenskap med ett värde sätter också detta värde på ShowLeaderLines-egenskapen för alla datamärken i [DataLabelCollection](../../datalabelcollection/)-samlingen (t.ex. "DataLabels.DefaultDataLabelFormat.ShowLeaderLines = val;" gör att alla DataLabels[i].ShowLeaderLines är lika med val).
