## IDataLabelFormat::get_Position() metod


Representerar positionen för datatetiketten. Läs [LegendDataLabelPosition](../../legenddatalabelposition/).

```cpp
virtual LegendDataLabelPosition Aspose::Slides::Charts::IDataLabelFormat::get_Position()=0
```

## Anmärkningar


Om föräldern till detta [DataLabelFormat](../../datalabelformat/)-objekt är en [DataLabelCollection](../../datalabelcollection/)-samling av datatetiketter, så får eller sätter denna egenskap standardvärdet för Position egenskapen för de nya datatetiketterna i [DataLabelCollection](../../datalabelcollection/)-samlingen. Representerar positionen för [DataLabel](../../datalabel/)-objekten. Att sätta denna egenskap med ett värde sätter också detta värde till Position egenskapen för alla datatetiketter i [DataLabelCollection](../../datalabelcollection/)-samlingen (t.ex. "DataLabels.DefaultDataLabelFormat.Position = val;" vilket gör att alla DataLabels[i].Position är lika med val).
