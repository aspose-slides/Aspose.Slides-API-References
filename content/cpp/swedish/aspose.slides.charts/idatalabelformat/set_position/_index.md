## IDataLabelFormat::set_Position(LegendDataLabelPosition) metod

virtual void Aspose::Slides::Charts::IDataLabelFormat::set_Position(LegendDataLabelPosition value)=0

## Anmärkningar

Om föräldern till detta [DataLabelFormat](../../datalabelformat/)-objekt är en [DataLabelCollection](../../datalabelcollection/) samling av dataetiketter så hämtar eller sätter denna egenskap standardvärdet för Position-egenskapen för de nya dataetiketterna i [DataLabelCollection](../../datalabelcollection/)-samlingen. Representerar positionen för [DataLabel](../../datalabel/)-objekten. Att sätta denna egenskap med ett värde sätter också detta värde till Position-egenskapen för alla dataetiketter i [DataLabelCollection](../../datalabelcollection/)-samlingen (t.ex. \"DataLabels.DefaultDataLabelFormat.Position = val;\" vilket gör att alla DataLabels[i].Position är lika med val).
