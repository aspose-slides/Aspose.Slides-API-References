## IDataLabelFormat::set_ShowLeaderLines(bool) metod


Representerar hur ledarlinjerna för dataetiketter i ett specifikt diagram visas. True visar ledarlinjerna. False för att dölja dem. Skriv **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowLeaderLines(bool value)=0
```

## Anmärkningar


Om föräldern till detta [DataLabelFormat](../../datalabelformat/)-objekt är en [DataLabelCollection](../../datalabelcollection/)-samling av dataetiketter, så hämtar eller anger den här egenskapen standardvärdet för egenskapen ShowLeaderLines för de nya dataetiketterna i [DataLabelCollection](../../datalabelcollection/)-samlingen. Att sätta denna egenskap med ett värde sätter också detta värde på egenskapen ShowLeaderLines för alla dataetiketter i [DataLabelCollection](../../datalabelcollection/)-samlingen (t.ex. \"DataLabels.DefaultDataLabelFormat.ShowLeaderLines = val;\" vilket gör att alla DataLabels[i].ShowLeaderLines är lika med val).
