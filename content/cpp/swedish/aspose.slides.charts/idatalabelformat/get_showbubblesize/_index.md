## IDataLabelFormat::get_ShowBubbleSize() metod


Representerar ett angivet diagrammets dataetiketts bubbelstorleksvärdes visningsbeteende. Sant visar bubbelstorleksvärdet. Falskt döljer det. Läs **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowBubbleSize()=0
```

## Anmärkningar


Om föräldern till detta [DataLabelFormat](../../datalabelformat/)-objekt är en [DataLabelCollection](../../datalabelcollection/)-samling av dataetiketter, så hämtar eller sätter denna egenskap standardvärdet för egenskapen ShowBubbleSize för de nya dataetiketterna i [DataLabelCollection](../../datalabelcollection/)-samlingen. Att sätta denna egenskap med ett värde sätter också detta värde till egenskapen ShowBubbleSize för alla dataetiketter i [DataLabelCollection](../../datalabelcollection/)-samlingen (t.ex. \"DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;\" vilket gör att alla DataLabels[i].ShowBubbleSize är lika med val).
