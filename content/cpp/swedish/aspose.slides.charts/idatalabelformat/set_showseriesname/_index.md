## IDataLabelFormat::set_ShowSeriesName(bool) metod


Ställer in en Boolean för att ange serienamnet visningsbeteende för datamärken på ett diagram. True för att visa serienamnet. False för att dölja. Skriv **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowSeriesName(bool value)=0
```

## Anmärkningar


Om föräldern till detta [DataLabelFormat](../../datalabelformat/)-objekt är en [DataLabelCollection](../../datalabelcollection/)-samling av datamärken så hämtar eller anger denna egenskap standardvärdet för ShowSeriesName-egenskapen för de nya datamärkena i [DataLabelCollection](../../datalabelcollection/)-samlingen. Att ange denna egenskap med ett värde sätter även detta värde på ShowSeriesName-egenskapen för alla datamärken i [DataLabelCollection](../../datalabelcollection/)-samlingen (t.ex. \"DataLabels.DefaultDataLabelFormat.ShowSeriesName = val;\" vilket gör att alla DataLabels[i].ShowSeriesName är lika med val).
