## IDataLabel::Hide() metod

Gör dataetiketten dold genom att sätta alla Show*-flags (ShowValue, ...) till false state. IsVisible blir false efter detta.

```cpp
virtual void Aspose::Slides::Charts::IDataLabel::Hide()=0
```

## Anmärkningar

Om dataetiketten inte är synlig (IsVisible är false) kan du göra dataetiketten synlig genom att sätta Show*-flags (ShowValue, ...) till true state.
