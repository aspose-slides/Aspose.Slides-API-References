## ChartCategoryCollection::set_UseCells(bool) metod

Om true används arbetsbladet för att lagra kategorier (detta fall stöder flernivåkategorier). Om false används arbetsbladet INTE för att lagra värden (och detta fall stöder inte flernivåkategorier). Skriv **bool**.
