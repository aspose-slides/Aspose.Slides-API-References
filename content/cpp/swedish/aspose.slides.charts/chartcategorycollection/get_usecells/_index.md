## ChartCategoryCollection::get_UseCells() metod


Om true så används arbetsblad för att lagra kategorier (detta fall stödjer kategorier med flera nivåer). Om false så används arbetsblad INTE för att lagra värden (och detta fall stödjer inte kategorier med flera nivåer). Läs **bool**.
