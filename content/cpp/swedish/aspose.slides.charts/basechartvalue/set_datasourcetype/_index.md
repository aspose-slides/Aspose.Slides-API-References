## BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType) metod


Anger huruvida AsCell, AsCells, AsLiteralString eller AsLiteralDouble property är aktuell i avledda. Med andra ord specificerar den typen av värde för Data property. Skriv [Charts::DataSourceType](../../datasourcetype/).

```cpp
void Aspose::Slides::Charts::BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType value) override
```

## Anmärkningar


För punkter i [ChartDataPointCollection](../../chartdatapointcollection/) är denna property read-only. I detta fall kan du för att ändra värdet på denna property använda en av egenskaperna i ChartDataPointCollection.DataSourceTypeFor<...> properties.
