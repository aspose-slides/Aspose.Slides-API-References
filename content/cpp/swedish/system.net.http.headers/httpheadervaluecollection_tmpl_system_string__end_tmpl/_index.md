## HttpHeaderValueCollection< System::String > klass


Den partiella specialiseringen av [HttpHeaderValueCollection](../httpheadervaluecollection/)-mallen för [String](../../system/string/)-typen. Objekt av denna klass bör endast allokeras med [System::MakeObject()](../../system/makeobject/)-funktionen. Skapa aldrig en instans av denna typ på stacken eller med operator new, eftersom det kommer att leda till körningstidsfel och/eller assertionfel. Omslut alltid denna klass i en [System::SmartPtr](../../system/smartptr/)-pekare och använd denna pekare för att skicka den till funktioner som argument.

```cpp
class HttpHeaderValueCollection< System::String > : public System::Collections::Generic::ICollection<System::String>
```
