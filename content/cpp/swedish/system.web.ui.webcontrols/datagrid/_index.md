## DataGrid klass

Dummy-klass som gör det möjligt att länka översatt kod med [DataGrid](./)-referenser, men inte köra den. Innehåller inga korrekt implementerade medlemmar. Objekt av denna klass bör endast allokeras med [System::MakeObject()](../../system/makeobject/)-funktionen. Skapa aldrig en instans av denna typ på stacken eller med operator new, eftersom det kommer att resultera i körningsfel och/eller assertion-fel. Omslut alltid denna klass i en [System::SmartPtr](../../system/smartptr/)-pekare och använd denna pekare för att skicka den till funktioner som argument.

```cpp
class DataGrid : public System::Object
```
