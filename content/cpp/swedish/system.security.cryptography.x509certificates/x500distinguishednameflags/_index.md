## X500DistinguishedNameFlags enum

Regler för formatering av X509-certifikatets distinguished name.

```cpp
enum class X500DistinguishedNameFlags
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| None | 0 | Inga speciella egenskaper. |
| Reversed | 1 | Namnet är reserverat. |
| UseSemicolons | 16 | Använd semikolon. |
| DoNotUsePlusSign | 32 | Namnet använder inte plustecken. |
| DoNotUseQuotes | 64 | Inaktiverar citattecken i namnet. |
| UseCommas | 128 | Aktiverar användning av kommatecken. |
| UseNewLines | 256 | Aktiverar användning av nya rader. |
| UseUTF8Encoding | 4096 | Byter från att använda Unicode till att använda UTF-8-kodning. |
| UseT61Encoding | 8192 | Byter till T61-kodning. |
| ForceUTF8Encoding | 16384 | Tvingar användning av UTF-8 vid kodning av specifika X500-nycklar. |
