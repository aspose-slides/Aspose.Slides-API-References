## X509KeyStorageFlags enum

Definierar hur nyckeln lagras.

```cpp
enum class X509KeyStorageFlags : int32_t
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| DefaultKeySet | 0 | Använd standardnyckeluppsättningen. |
| UserKeySet | 1 | Använd lagring som är associerad med användaren istället för maskinlokal. |
| MachineKeySet | 2 | Använd lokalt maskinlager istället för användarens. |
| Exportable | 4 | Markerar importerade nycklar som exportbara. |
| UserProtected | 8 | Meddela användaren att nyckeln används. |
| PersistKeySet | 16 | Nyckeln sparas när certifikat importeras. |
