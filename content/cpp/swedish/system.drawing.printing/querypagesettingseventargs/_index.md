## QueryPageSettingsEventArgs klass

Tillhandahåller data för QueryPageSettings-händelsen. Objekt av denna klass bör endast allokeras med funktionen [System::MakeObject()](../../system/makeobject/). Skapa aldrig en instans av denna typ på stacken eller med operator new, eftersom det kommer att leda till runtime errors och/eller assertion faults. Wrappa alltid denna klass i en [System::SmartPtr](../../system/smartptr/)-pointer och använd denna pointer för att skicka den till funktioner som argument.

```cpp
class QueryPageSettingsEventArgs : private System::Drawing::Printing::PrintEventArgs
```
