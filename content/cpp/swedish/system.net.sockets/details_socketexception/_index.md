## Details_SocketException klass

Representerar undantaget som kastas när ett socket-fel inträffar. Skapa aldrig instanser av den här klassen manuellt. Använd istället SocketException klass. Slå aldrig in SocketException klassens instanser i [System::SmartPtr](../../system/smartptr/).

```cpp
class Details_SocketException : public System::Details_Exception
```
