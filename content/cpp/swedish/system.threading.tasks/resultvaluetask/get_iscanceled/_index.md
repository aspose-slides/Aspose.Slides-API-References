## ResultValueTask::get_IsCanceled() const metod

Hämtar ett värde som indikerar om uppgiften avslutades på grund av att den avbröts.

```cpp
bool System::Threading::Tasks::ResultValueTask<T>::get_IsCanceled() const
```

### Returvärde

bool True om uppgiften avbröts; annars false.
