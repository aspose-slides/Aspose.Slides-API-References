## CancellationToken::get_CanBeCanceled() const metod


Hämtar huruvida detta token kan vara i avbrutet tillstånd.

```cpp
bool System::Threading::CancellationToken::get_CanBeCanceled() const
```


### Returvärde

true om detta token kan vara i avbrutet tillstånd; annars false.
## Anmärkningar



Tokens som skapas från [CancellationTokenSource](../../cancellationtokensource/) returnerar true, medan None token alltid returnerar false.
