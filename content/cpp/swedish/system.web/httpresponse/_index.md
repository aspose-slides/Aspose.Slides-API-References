## HttpResponse klass

Dummy-klass som möjliggör länkning av översatt kod med [HttpResponse](./)-referenser, men som inte körs. Innehåller inga korrekt implementerade medlemmar. Objekt av denna klass bör endast allokeras med hjälp av funktionen [System::MakeObject()](../../system/makeobject/). Skapa aldrig en instans av denna typ på stacken eller med operator new, eftersom det kommer att resultera i körfel och/eller påståendefel. Omslut alltid denna klass i en [System::SmartPtr](../../system/smartptr/)-pekare och använd den pekaren för att skicka den till funktioner som argument.

```cpp
class HttpResponse : public System::Object
```
