## LineCap enum

Indikerar de tillgängliga spetsstilarna som ett [Pen](../../system.drawing/pen/)-objekt kan använda för att avsluta en linje.

```cpp
enum class LineCap
```

### Värden

| Name | Value | Description |
| --- | --- | --- |
| Flat | 0 | Platt linjespets. |
| Square | 1 | Kvadratisk linjespets. |
| Round | 2 | Rund linjespets. |
| Triangle | 3 | Triangulär linjespets. |
| NoAnchor | 16 | Ingen ankare. |
| SquareAnchor | 17 | Kvadratisk ankarlinjespets. |
| RoundAnchor | 18 | Rund ankarlinjespets. |
| DiamondAnchor | 19 | Diamantankarlinjespets. |
| ArrowAnchor | 20 | Pilankarlinjespets. |
| AnchorMask | 240 | En mask som används för att kontrollera om en linjespets är ett ankare. |
| Custom | 255 | Anpassad spets. |
