## SmoothingMode enum

Specificerar vilken typ av utjämning (kantutjämning) som tillämpas på linjer, kurvor och kanter på fyllda områden.

```cpp
enum class SmoothingMode
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Invalid | n/a | Invalid värde. |
| Default | n/a | Default läge, ingen kantutjämning. |
| HighSpeed | n/a | Ingen kantutjämning, hög hastighet. |
| HighQuality | n/a | Kantutjämnad återgivning, låg hastighet. |
| None | n/a | Ingen kantutjämning. |
| AntiAlias | n/a | Kantutjämnad återgivning. |
