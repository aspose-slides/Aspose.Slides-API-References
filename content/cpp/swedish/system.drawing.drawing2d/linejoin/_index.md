## LineJoin enum

Anger hur på varandra följande linjer eller kurvor förenas.

```cpp
enum class LineJoin
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Miter | 0 | Miterad fog som ger ett vasst eller avklippt hörn beroende på om mätningens längd överskrider mitergränsen. |
| Bevel | 1 | Fasettfog som ger ett diagonalt hörn. |
| Round | 2 | Rund fog som producerar en jämn cirkulär båge mellan linjerna. |
| MiterClipped | 3 | Miterad fog som ger ett vasst eller fasettat hörn beroende på om mätningens längd överskrider mitergränsen. |
