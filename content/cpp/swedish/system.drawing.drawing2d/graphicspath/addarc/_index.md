## GraphicsPath::AddArc(float, float, float, float, float, float) metod

Lägger till den angivna elliptiska bågen i den bana som representeras av det aktuella objektet.

```cpp
void System::Drawing::Drawing2D::GraphicsPath::AddArc(float x, float y, float width, float height, float startAngle, float sweepAngle)
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| x | **float** | X-koordinaten för det övre vänstra hörnet av den rektangel som avgränsar ellipsen som bågen ritas från |
| y | **float** | Y-koordinaten för det övre vänstra hörnet av den rektangel som avgränsar ellipsen som bågen ritas från |
| width | **float** | Bredden på den rektangel som avgränsar ellipsen som bågen ritas från |
| height | **float** | Höjden på den rektangel som avgränsar ellipsen som bågen ritas från |
| startAngle | **float** | Anger startvinkeln för bågen i grader, mätt medurs från X-axeln |
| sweepAngle | **float** | Anger vinkeln mellan startvinkeln och slutet av bågen |
