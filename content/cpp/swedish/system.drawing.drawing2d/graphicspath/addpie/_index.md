## GraphicsPath::AddPie(float, float, float, float, float, float) metod

Lägger till den angivna konturen av pajformen till den bana som representeras av det aktuella objektet.

```cpp
void System::Drawing::Drawing2D::GraphicsPath::AddPie(float x, float y, float width, float height, float startAngle, float sweepAngle)
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| x | **float** | X-koordinaten för det övre vänstra hörnet av den rektangel som begränsar ellipsen som pajen ritas från |
| y | **float** | Y-koordinaten för det övre vänstra hörnet av den rektangel som begränsar ellipsen som pajen ritas från |
| width | **float** | Bredden på det övre vänstra hörnet av den rektangel som begränsar ellipsen som pajen ritas från |
| height | **float** | Höjden på det övre vänstra hörnet av den rektangel som begränsar ellipsen som pajen ritas från |
| startAngle | **float** | Anger startvinkeln för pajen i grader, mätt medurs från X-axeln |
| sweepAngle | **float** | Anger vinkeln mellan startvinkeln och slutet av pajen |
