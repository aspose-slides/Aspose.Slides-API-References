## XsltSettings::get_Default() metod


Returnerar ett [XsltSettings](../)-objekt med standardinställningar. Stöd för XSLT **document()**-funktionen och inbäddade skriptblock är inaktiverat.

```cpp
static SharedPtr<XsltSettings> System::Xml::Xsl::XsltSettings::get_Default()
```


### Returvärde

Ett [XsltSettings](../)-objekt med alternativen [XsltSettings::set_EnableDocumentFunction](../set_enabledocumentfunction/) och [XsltSettings::set_EnableScript](../set_enablescript/) satta till **false**.
