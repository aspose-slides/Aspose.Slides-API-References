## has_method_compareto_shared_ptr struct

Kontrollerar om metoden CompareTo(SharedPtr<T>) finns i den angivna typen. Om så är fallet ärver den std::true_type, annars ärver den std::false_type. Kan användas i std::enable_if.

```cpp
template<typename T,typename Sfinae>class has_method_compareto_shared_ptr : public std::false_type
```

### Template parameters

| Parameter | Beskrivning |
| --- | --- |
| T | Typ för att kontrollera om metoden Equals finns. |
| Sfinae | Formellt mallargument för att SFINAE ska fungera. |
