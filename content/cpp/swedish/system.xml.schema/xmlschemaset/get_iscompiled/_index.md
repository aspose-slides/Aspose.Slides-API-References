## XmlSchemaSet::get_IsCompiled() metod

Returnerar ett värde som visar om XML [Schema](../../) definition language (XSD) scheman i [XmlSchemaSet](../) har kompilerats.

```cpp
bool System::Xml::Schema::XmlSchemaSet::get_IsCompiled()
```

### Returnvärde

**true** om scheman i [XmlSchemaSet](../) har kompilerats sedan senaste gången ett schema lades till eller togs bort från [XmlSchemaSet](../); annars, **false**.
