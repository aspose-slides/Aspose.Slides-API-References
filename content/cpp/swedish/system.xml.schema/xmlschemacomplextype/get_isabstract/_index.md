## XmlSchemaComplexType::get_IsAbstract() metod


Returnerar informationen som bestämmer om **complexType**-elementet kan användas i instansdokumentet.

```cpp
bool System::Xml::Schema::XmlSchemaComplexType::get_IsAbstract()
```


### Returvärde

Om **true** kan ett element inte använda detta **complexType**-element direkt och måste använda en komplex typ som är avledd från detta **complexType**-element. Standardvärdet är **false**. Valfritt.
