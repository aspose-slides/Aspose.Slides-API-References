## XmlSchemaComplexType::get_IsMixed() method

Returnerar information som bestämmer om den komplexa typen har en blandad innehållsmodell (markup inom innehållet).

```cpp
bool System::Xml::Schema::XmlSchemaComplexType::get_IsMixed() override
```

### Returvärde

**true**, om teckendata kan förekomma mellan underordnade element i denna komplexa typ; annars, **false**. Standardvärdet är **false**. Valfritt.
