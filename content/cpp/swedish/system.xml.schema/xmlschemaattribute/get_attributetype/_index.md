## XmlSchemaAttribute::get_AttributeType() metod

Returnerar objektet baserat på [XmlSchemaAttribute::get_SchemaType](../get_schematype/) eller [XmlSchemaAttribute::get_SchemaTypeName](../get_schematypename/) värdet för attributet som innehåller tolkningen efter kompilering av **AttributeType**-värdet.

```cpp
SharedPtr<Object> System::Xml::Schema::XmlSchemaAttribute::get_AttributeType()
```

### Returvärde

Objektet som innehåller tolkningen efter kompilering av **AttributeType**-värdet.

Föråldrad
:   Det rekommenderas att använda get_AttributeSchemaType metod istället.
