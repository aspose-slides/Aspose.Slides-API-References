## XmlSchemaSimpleTypeList klass


Representerar **lista**-elementet från XML [Schema](../) som specificerat av World Wide [Web](../../system.web/) Consortium (W3C). Denna klass kan användas för att definiera ett **simpleType**-element som en lista av värden av en angiven datatyp.

```cpp
class XmlSchemaSimpleTypeList : public System::Xml::Schema::XmlSchemaSimpleTypeContent
```
