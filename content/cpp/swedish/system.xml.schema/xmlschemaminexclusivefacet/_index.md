## XmlSchemaMinExclusiveFacet klass


Representerar **minExclusive**-elementet från XML [Schema](../) enligt specifikationen av World Wide [Web](../../system.web/) Consortium (W3C). Denna klass kan användas för att ange en begränsning på minsta värde för ett **simpleType**-element. Elementvärdet måste vara större än värdet i **minExclusive**-elementet.

```cpp
class XmlSchemaMinExclusiveFacet : public System::Xml::Schema::XmlSchemaFacet
```
