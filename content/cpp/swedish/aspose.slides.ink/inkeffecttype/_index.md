## InkEffectType enum

Specificerar en uppsättning fördefinierade visuella effekter för bläckåtergivning. Varje effekt motsvarar en textur eller bild som simulerar ett stiliserat bläckeutseende. Dessa värden kan användas för att anpassa den visuella stilen för digitala bläckstift under rendering.

```cpp
enum class InkEffectType
```

### Values

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| NotDefined | -1 | Effekten är inte definierad eller är okänd. Detta värde kan användas som standard eller reserv. |
| Bronze | 0 | En varm, brunaktig metallisk textur som liknar bronsbläck. |
| Galaxy | 1 | En färgglad, skimrande textur som liknar en galax, med kosmiska toner. |
| Gold | 2 | En ljus, metallisk guldfärgad textur som ger bläckstift ett lyxigt utseende. |
| Lava | 3 | En eldglödande textur som liknar smält lava, med röda och orangea nyanser. |
| Ocean | 4 | En djupblå, vätskeliknande textur som efterliknar havsvågor eller vattenbaserat bläck. |
| RainbowGlitter | 5 | En färgglad, glittrande regnbågsglittereffekt som används för festliga eller livfulla bläckstift. |
| RoseGold | 6 | En mjuk rosa-guldblandning, liknande roséguld, för eleganta bläckstift. |
| Silver | 7 | En kall, metallisk silvertextur som simulerar klassiskt silverbläck. |
