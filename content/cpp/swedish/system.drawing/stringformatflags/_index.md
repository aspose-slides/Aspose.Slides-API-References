## StringFormatFlags enum

Anger visnings- och layoutinformation för textsträngar.

```cpp
enum class StringFormatFlags
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| DirectionRightToLeft | 1 | Höger-till-vänster text riktning. |
| DirectionVertical | 2 | [Text](../../system.drawing.text/) är vertikalt justerad. |
| FitBlackBox | 4 | Delar av tecken kan hänga över layoutrutan. |
| DisplayFormatControl | 32 | Kontrolltecken visas. |
| NoFontFallback | 1024 | [Font](../font/) fallback är inaktiverad. |
| MeasureTrailingSpaces | 2048 | Infogar efterföljande mellanslag i slutet av varje rad. |
| NoWrap | 4096 | [Text](../../system.drawing.text/) radbrytning är inaktiverad. |
| LineLimit | 8192 | Hela rader läggs ut i formateringsrektangeln. |
| NoClip | 16384 | Hängande delar av glyfer får visas. |
