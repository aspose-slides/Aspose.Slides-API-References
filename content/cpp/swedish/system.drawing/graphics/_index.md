## Graphics klass


Representerar en ritningsyta. Objekt av denna klass bör endast allokeras med [System::MakeObject()](../../system/makeobject/) funktion. Skapa aldrig en instans av den här typen på stacken eller med operator new, eftersom det kan leda till körningsfel och/eller assertionsfel. Omslut alltid denna klass med en [System::SmartPtr](../../system/smartptr/) pekare och använd denna pekare för att skicka den till funktioner som argument.

```cpp
class Graphics : public virtual System::Object
```
