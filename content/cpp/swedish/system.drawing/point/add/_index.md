## Point::Add(const Point\&, const Size\&) metod

Lägger till bredd- och höjdvärdena för det angivna [Size](../../size/)-objektet till X- och Y-koordinatvärdena för det angivna [Point](../)-objektet respektive.

```cpp
static Point System::Drawing::Point::Add(const Point &point, const Size &size)
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| point | const [Point](../)\& | point att översätta |
| size | const [Size](../../size/)\& | [Size](../../size/)-objektet som specificerar värdena att lägga till koordinatvärdena för **point** |

### Returvärde

Ett nytt [Point](../)-objekt vars X-koordinatavärde är lika med summan av X-koordinatavärdet för **point** och breddvärdet för **size**, och Y-koordinatavärdet är lika med summan av Y-koordinatavärdet för **point** och höjdvärdet för **size**
