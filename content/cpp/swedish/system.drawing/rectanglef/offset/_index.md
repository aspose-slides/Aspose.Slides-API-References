## RectangleF::Offset(const PointF\&) metod

Förskjuter positionen för den rektangel som representeras av det aktuella objektet med de angivna värdena.

```cpp
void System::Drawing::RectangleF::Offset(const PointF &pos)
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| pos | const [PointF](../../pointf/)\& | Det [PointF](../../pointf/)-objektet som anger mängden som rektangeln ska förskjutas med; punktens X-koordinatavärde anger mängden att lägga till X-koordinaten för rektangelns övre vänstra hörn och punktens Y-koordinat anger mängden att lägga till Y-koordinaten för rektangelns övre vänstra hörn |

## RectangleF::Offset(float, float) metod

Förskjuter positionen för den rektangel som representeras av det aktuella objektet med de angivna värdena.

```cpp
void System::Drawing::RectangleF::Offset(float x, float y)
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| x | **float** | Värdet att lägga till den aktuella X-koordinaten för rektangeln |
| y | **float** | Värdet att lägga till den aktuella Y-koordinaten för rektangeln |
