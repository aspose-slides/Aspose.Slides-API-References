## Color::get_IsNamedColor() const metod

Returnerar ett värde som avgör om [Color](../)-strukturen representerar en namngiven färg eller en medlem av KnownColor-enumerationen.

```cpp
bool System::Drawing::Color::get_IsNamedColor() const
```

### Returvärde

True if [Color](../) was created using either the FromName(String) metod or the [FromKnownColor(KnownColor)](../fromknowncolor/) metod; otherwise, it returns false.
