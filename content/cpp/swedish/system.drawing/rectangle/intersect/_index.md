## Rectangle::Intersect(const Rectangle\&) metod

Ersätter rektangeln som representeras av det aktuella objektet med rektangeln som resultat av dess skärning med rektangeln som representeras av det angivna objektet.

```cpp
void System::Drawing::Rectangle::Intersect(const Rectangle &rect)
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| rect | const [Rectangle](../)\& | Det [Rectangle](../)-objektet som representerar rektangeln som ska skäras mot rektangeln som representeras av det aktuella objektet |

## Rectangle::Intersect(const Rectangle\&, const Rectangle\&) metod

Returnerar en rektangel som är resultatet av skärningen av de angivna rektanglarna.

```cpp
static Rectangle System::Drawing::Rectangle::Intersect(const Rectangle &a, const Rectangle &b)
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| a | const [Rectangle](../)\& | Den första rektangeln att skära |
| b | const [Rectangle](../)\& | Den andra rektangeln att skära |

### Returvärde

Resultatet av skärningen av **a** med **b**
