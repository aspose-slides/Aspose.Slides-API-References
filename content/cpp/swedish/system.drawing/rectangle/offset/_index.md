## Rectangle::Offset(const Point\&) metod

Offsets positionen för den rektangel som representeras av det aktuella objektet med de angivna värdena.

```cpp
void System::Drawing::Rectangle::Offset(const Point &pos)
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| pos | const [Point](../../point/)\& | Det [Point](../../point/)-objekt som specificerar mängden som rektangeln förskjuts; punktens X-koordinatvärde anger hur mycket som ska läggas till X-koordinaten för rektangelns övre vänstra hörn och punktens Y-koordinat anger hur mycket som ska läggas till Y-koordinaten för rektangelns övre vänstra hörn |

## Rectangle::Offset(int, int) metod

Offsets positionen för den rektangel som representeras av det aktuella objektet med de angivna värdena.

```cpp
void System::Drawing::Rectangle::Offset(int x, int y)
```

### Argument

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| x | int | Värdet som ska läggas till den aktuella X-koordinaten för rektangeln |
| y | int | Värdet som ska läggas till den aktuella Y-koordinaten för rektangeln |
