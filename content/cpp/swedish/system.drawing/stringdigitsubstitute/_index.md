## StringDigitSubstitute enum

Anger hur siffror i en sträng ersätts enligt den lokala inställningen eller språket.

```cpp
enum class StringDigitSubstitute
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| User | 0 | Användardefinierad ersättning. |
| None | 1 | Ersättning är inaktiverad. |
| National | 2 | Ersätt siffror som motsvarar det officiella nationella språket för användarens lokala inställning. |
| Traditional | 3 | Ersätt siffror som motsvarar användarens inhemska skriftsystem eller språk, vilket kan skilja sig från det officiella nationella språket för användarens lokala inställning. |
