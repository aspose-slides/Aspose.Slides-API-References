## IEnumeratorImplRefType::MoveNext() metod


Flyttar uppräkning till nästa element. Om inget element refererades tidigare, sätter referensen till det första tillgängliga elementet. Om behållarens slut nås, gör den ingenting.

```cpp
virtual bool System::Collections::IEnumeratorImplRefType<T>::MoveNext() override
```


### Returvärde

True om ett element är tillgängligt efter anropet, false annars.
