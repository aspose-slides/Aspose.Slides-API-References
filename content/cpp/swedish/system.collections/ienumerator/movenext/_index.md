## IEnumerator::MoveNext() metod

Flyttar enumerator till nästa element. Om inget element refererades tidigare, sätter referensen till det första tillgängliga elementet. Om slutet på behållaren nås, gör den ingenting.

```cpp
virtual bool System::Collections::IEnumerator::MoveNext()=0
```

### Returvärde

Sant om ett element är tillgängligt efter anropet, falskt annars.
