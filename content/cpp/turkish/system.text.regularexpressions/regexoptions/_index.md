## RegexOptions enum


[Regex](../regex/) seçenekler.

```cpp
enum class RegexOptions
```

### Değerler

| Ad | Değer | Açıklama |
| --- | --- | --- |
| None | 0 | Varsayılan davranış. |
| Compiled | 1 | Performans için regex derle. Her zaman varsayılan olarak yapılır. |
| CultureInvariant | 2 | Kültür bağımsız eşleşme kullan. Yoksayıldı. |
| ECMAScript | 4 | ECMAScript sözdizimini kullan. Yoksayıldı. |
| ExplicitCapture | 8 | Yalnızca açık yakalama. Yoksayıldı. |
| IgnoreCase | 16 | Eşleşirken harf duyarlılığını yoksay. |
| IgnorePatternWhitespace | 32 | Desimdeki boşlukları yoksay. Desteklenmiyor. |
| Multiline | 64 | '^' ve '$' karakterlerini bütün dize yerine satırın başı ve sonu olarak kabul et. |
| RightToLeft | 128 | Sağdan sola eşleşme. Desteklenmiyor. |
| Singleline | 256 | '.' karakterini istisnasız herhangi bir karakterle eşleştirir (normalde yeni satır karakterleri eşleşmez). |
