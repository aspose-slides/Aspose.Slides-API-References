## IDataLabelCollection::Hide() yöntemi

Varsayılan olarak veri etiketini gizli yapın; DefaultDataLabelFormat özelliğinin tüm Show*-bayraklarını (ShowValue, ...) false durumuna ayarlayarak. Bu işlemden sonra IsVisible false olacaktır.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelCollection::Hide()=0
```

## Açıklamalar

Veri etiketi varsayılan olarak görünür değilse (IsVisible false) Show*-bayraklarını (ShowValue, ...) DefaultDataLabelFormat özelliğinin true durumuna ayarlayarak veri etiketini "görünür \nvarsayılan olarak" yapabilirsiniz.
