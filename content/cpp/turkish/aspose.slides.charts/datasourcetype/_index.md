```cpp
enum class DataSourceType
```

### Değerler

| Ad | Değer | Açıklama |
| --- | --- | --- |
| Worksheet | 0 | Veri noktasının XValue, YValue, Value veya BubbleSize değerlerini worksheet'te depolamak için CellXls nesnelerini kullanın. |
| StringLiterals | 1 | Veri noktasının XValue, YValue, Value veya BubbleSize değerlerini depolamak için hızlı erişimli string değişkeni kullanın. Worksheet, değerleri depolamak için NOT kullanılır. |
| DoubleLiterals | 2 | Veri noktasının XValue, YValue, Value veya BubbleSize değerlerini depolamak için hızlı erişimli double değişkeni kullanın. Worksheet, değerleri depolamak için NOT kullanılır. |
