## AxisAggregationType enum

Kategori ekseninin toplama tipini temsil eder. Yalnızca Histogram veya HistogramPareto serileriyle kullanılır.

```cpp
enum class AxisAggregationType
```

### Değerler

| Name | Value | Description |
| --- | --- | --- |
| ByCategory | 0 | Kategorilere göre toplama |
| Automatic | 1 | Kategorileri otomatik olarak toplar. |
| ByBinWidth | 2 | Kategorileri kutu genişliğine göre toplar. Property IAxis::get(set)_BinWidth must be setted. |
| ByNumberOfBins | 3 | Kategorileri kutu sayısına göre toplar. Property IAxis::get(set)_NumberOfBins must be setted. |
