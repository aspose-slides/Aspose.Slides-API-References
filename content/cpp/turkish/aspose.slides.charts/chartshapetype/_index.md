## ChartShapeType enum

Bir grafik şekli temsil eder.

```cpp
enum class ChartShapeType
```

### Değerler

| Name | Value | Description |
| --- | --- | --- |
| NotDefined | -1 | [Chart](../chart/) şekli tanımlı değildir. |
| Box | 0 | Grafiğin kutu şekliyle çizileceğini belirtir. |
| Cone | 1 | Grafiğin koni olarak çizileceğini, koninin tabanının zemine, koninin ucunun ise veri işaretleyicisinin tepesine yerleştirileceğini belirtir. |
| ConeToMax | 2 | Grafiğin koni biçiminde ancak kesik koni olarak çizileceğini, koni ucunun en büyük veri değerine karşılık geleceğini belirtir. |
| Cylinder | 3 | Grafiğin silindir olarak çizileceğini belirtir. |
| Pyramid | 4 | Grafiğin dikdörtgen piramit olarak çizileceğini, piramidin tabanının zemine, piramidin ucunun veri işaretleyicisinin tepesine yerleştirileceğini belirtir. |
| PyramidToMaximum | 5 | Grafiğin piramit yerine kesik koni olarak çizileceğini, koni ucunun en büyük veri değerine karşılık geleceğini belirtir. |
