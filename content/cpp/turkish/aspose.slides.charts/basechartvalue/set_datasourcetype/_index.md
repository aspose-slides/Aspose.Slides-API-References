## BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType) metodu


AsCell, AsCells, AsLiteralString veya AsLiteralDouble özelliğinin türevlerde geçerli olup olmadığını belirtir. Başka bir deyişle Data özelliğinin değerinin türünü belirtir. Yazın [Charts::DataSourceType](../../datasourcetype/).

```cpp
void Aspose::Slides::Charts::BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType value) override
```

## Açıklamalar


[ChartDataPointCollection](../../chartdatapointcollection/) içindeki noktalar için bu özellik yalnızca okunur. Bu durumda bu özelliğin değerini değiştirmek için ChartDataPointCollection.DataSourceTypeFor<...> özelliklerinden birini kullanabilirsiniz.
