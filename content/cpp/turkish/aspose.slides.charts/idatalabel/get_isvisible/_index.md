## IDataLabel::get_IsVisible() yöntemi


False, veri etiketinin görünür olmadığı anlamına gelir (ve bu yüzden tüm Show*-flags (ShowValue, ...) false olur). Salt okunur **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabel::get_IsVisible()=0
```

## Açıklamalar


Veri etiketi görünürse, onu [Hide()](../hide/) yöntemiyle gizleyebilirsiniz. Ancak veri etiketi görünür değilse (IsVisible false ise) veri etiketini görünür hâle getirmek için Show*-flags (ShowValue, ...) true durumuna ayarlayabilirsiniz.
