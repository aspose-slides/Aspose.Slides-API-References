## ErrorBarsFormat::set_ValueType(ErrorBarValueType) metodu

Hata çubuklarının uzunluğunu belirlemenin olası yollarını temsil eder. Özel değer türü için değeri belirtmek istediğinizde serinin DataPoints koleksiyonundaki belirli veri noktasının [IChartDataPoint::get_ErrorBarsCustomValues()](../../ichartdatapoint/get_errorbarscustomvalues/) özelliğini kullanın. Fixed, Percentage veya StandardDeviation değer türü durumunda değeri belirtmek için Value özelliğini kullanın. 

Yazın [ErrorBarValueType](../../errorbarvaluetype/).
