## IAlphaBiLevelEffectiveData sınıf

Değiştirilemez nesne, bir Alpha Bi-Level etkisini temsil eder. Eşik değerinden düşük Alpha (Opacity) değerleri 0 (tamamen şeffaf) olarak, eşik değerine eşit veya daha büyük Alpha değerleri %100 (tamamen opak) olarak değiştirilir.

```cpp
class IAlphaBiLevelEffectiveData : public virtual Aspose::Slides::Effects::IEffectEffectiveData
```
