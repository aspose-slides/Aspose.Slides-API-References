## IAlphaBiLevel sınıf


Alpha Bi-Level etkisini temsil eder. Eşik değerinden düşük Alpha (Opacity) değerleri 0 (tamamen şeffaf) olarak, eşiğe eşit veya daha yüksek alpha değerleri ise %100 (tamamen opak) olarak değiştirilir.

```cpp
class IAlphaBiLevel : public virtual Aspose::Slides::Effects::IImageTransformOperation,
                      public Aspose::Slides::IAccessiblePVIObject<System::SharedPtr<Aspose::Slides::Effects::IAlphaBiLevelEffectiveData>>
```
