## PixelOffsetMode enum


Piksellerin render edildiği sırada nasıl ofsetlendiğini belirtir.

```cpp
enum class PixelOffsetMode
```

### Values

| Ad | Değer | Açıklama |
| --- | --- | --- |
| Invalid | n/a | Geçersiz değer. |
| Default | n/a | Varsayılan mod. |
| HighSpeed | n/a | Düşük kalite (yüksek performans) modu. |
| HighQuality | n/a | Yüksek kalite (daha düşük performans) modu. |
| None | n/a | Piksel ofseti yok. |
| Half | n/a | Yüksek performanslı kenar yumuşatma için pikseller yatay ve dikey olarak -0.5 birim ofsetlenir. |
