## TextRenderingHint enum

```cpp
enum class TextRenderingHint
```

### Değerler

| İsim | Değer | Açıklama |
| --- | --- | --- |
| SystemDefault | 0 | Sistem varsayılanı renderleme ipucuna sahip Glyph. |
| SingleBitPerPixelGridFit | 1 | İpucu ile Glyph bitmap. |
| SingleBitPerPixel | 2 | İpucu olmadan Glyph bitmap. |
| AntiAliasGridFit | 3 | İpucu ile anti-aliasing. |
| AntiAlias | 4 | İpucu olmadan Glyph anti-alias bitmap. |
| ClearTypeGridFit | 5 | İpucu ile Glyph CT bitmap. |
