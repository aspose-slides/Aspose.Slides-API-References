```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToId(String id)=0
```

### Parametreler

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| id | [String](../../../system/string/) | [String](../../../system/string/), taşınmak istediğiniz düğümün **ID** değerini temsil eder. |
