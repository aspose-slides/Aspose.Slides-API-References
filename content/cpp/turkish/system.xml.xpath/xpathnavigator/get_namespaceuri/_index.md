## XPathNavigator::get_NamespaceURI() yöntemi

When overridden in a derived class, gets the namespace URI of the current node.

```cpp
virtual String System::Xml::XPath::XPathNavigator::get_NamespaceURI()=0
```

### Dönüş Değeri

Geçerli düğümün namespace URI'sini içeren bir [String](../../../system/string/), veya geçerli düğümün namespace URI'si yoksa [String::Empty](../../../system/string/empty/).
