## XPathNavigator::InsertElementBefore(String, String, String, String) metodu


Belirtilen ad alanı öneki, yerel ad ve ad alanı URI'si ile, belirtilen değer kullanılarak geçerli düğümden önce yeni bir kardeş öğe oluşturur.

```cpp
virtual void System::Xml::XPath::XPathNavigator::InsertElementBefore(String prefix, String localName, String namespaceURI, String value)
```


### Argümanlar

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| prefix | [String](../../../system/string/) | Yeni alt öğenin ad alanı öneki (varsa). |
| localName | [String](../../../system/string/) | Yeni alt öğenin yerel adı (varsa). |
| namespaceURI | [String](../../../system/string/) | Yeni alt öğenin ad alanı URI'si (varsa). [String::Empty](../../../system/string/empty/) ve **nullptr** eşdeğerdir. |
| value | [String](../../../system/string/) | Yeni alt öğenin değeri. [String::Empty](../../../system/string/empty/) veya **nullptr** geçirilirse, boş bir öğe oluşturulur. |
