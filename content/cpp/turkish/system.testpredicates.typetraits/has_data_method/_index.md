## has_data_method struct

Bir tipin data() yöntemine sahip olup olmadığını kontrol eder. Eğer sahipse, std::true_type tipinden miras alır, aksi takdirde std::false_type tipinden miras alır.

```cpp
template<typename T,typename Enable>class has_data_method : public std::false_type
```

### Şablon parametreleri

| Parametre | Açıklama |
| --- | --- |
| T | Kontrol edilecek tip. |
| Enable | SFINAE'nin çalışması için formal argüman. |
