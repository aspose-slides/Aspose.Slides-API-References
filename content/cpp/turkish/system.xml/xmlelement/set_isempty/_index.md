## XmlElement::set_IsEmpty(bool) metodu

Elemanın etiket biçimini ayarlar.

```cpp
void System::Xml::XmlElement::set_IsEmpty(bool value)
```

### Argümanlar

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| value | **bool** | Ayarlanacak değer. Bu değeri ayarlarken **true** olarak ayarlanırsa, elemanın çocukları kaldırılır ve eleman kısa etiket biçiminde serileştirilir. **false** olarak ayarlanırsa, değer değiştirilir (elemanın içeriği olup olmadığına bakılmaksızın); eleman boşsa, uzun biçimde serileştirilir. |
