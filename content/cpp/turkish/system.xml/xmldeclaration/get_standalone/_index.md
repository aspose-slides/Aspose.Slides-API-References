## XmlDeclaration::get_Standalone() metod

Bağımsız özniteliğinin değerini döndürür.

```cpp
String System::Xml::XmlDeclaration::get_Standalone()
```

### Dönüş Değeri

Geçerli değerler, XML belgesi tarafından gerektiren tüm varlık bildirimleri belge içinde bulunuyorsa **yes**, aksi takdirde dış bir belge türü tanımı (DTD) gerekiyorsa **no** şeklindedir. Eğer bir standalone özniteliği XML bildiriminde bulunmuyorsa, bu metod [String::Empty](../../../system/string/empty/) döndürür.
