## XmlReader::get_XmlSpace() metodu

When overridden in a derived class, gets the current **xml:space** scope.

```cpp
virtual System::Xml::XmlSpace System::Xml::XmlReader::get_XmlSpace()
```

### Dönüş Değeri

XmlSpace değerlerinden biri. **xml:space** kapsamı mevcut değilse, bu değer varsayılan olarak [XmlSpace::None](../../xmlspace/) olur.
