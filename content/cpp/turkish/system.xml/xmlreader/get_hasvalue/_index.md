## XmlReader::get_HasValue() method

Türetilmiş bir sınıfta geçersiz kılındığında, geçerli düğümün bir [XmlReader::get_Value](../get_value/) değeri olup olmadığını gösteren bir değer alır.

```cpp
virtual bool System::Xml::XmlReader::get_HasValue()
```

### Return Value

**true** eğer okuyucunun şu anda konumlandığı düğüm **Value**'a sahip olabiliyorsa; aksi takdirde **false**. **false** ise, düğümün değeri [String::Empty](../../../system/string/empty/).
