## XmlWriterSettings::get_CheckCharacters() yöntemi


XML yazarının belgede bulunan tüm karakterlerin W3C [XML 1.0 Recommendation](https://www.w3.org/TR/REC-xml/#charsets)'nin \"2.2 Characters\" bölümüne uygun olup olmadığını kontrol edip etmediğini gösteren bir değer döndürür.

```cpp
bool System::Xml::XmlWriterSettings::get_CheckCharacters()
```

### Dönüş Değeri

**true** karakter kontrolü yapmak için; aksi takdirde **false**. Varsayılan **true**'dur.
