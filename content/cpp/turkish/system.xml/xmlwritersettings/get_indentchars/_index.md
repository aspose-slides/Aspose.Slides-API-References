## XmlWriterSettings::get_IndentChars() metodu

Girintileme sırasında kullanılacak karakter dizisini döndürür. Bu ayar, [XmlWriterSettings::set_Indent](../set_indent/) değeri **true** olarak ayarlandığında kullanılır.

```cpp
String System::Xml::XmlWriterSettings::get_IndentChars()
```

### Dönüş Değeri

Girintileme sırasında kullanılacak karakter dizisi. Bu, herhangi bir dizge değerine ayarlanabilir. Ancak, geçerli XML sağlamak için yalnızca boşluk karakterleri, sekme, satır başı veya satır sonu gibi geçerli beyaz boşluk karakterlerini belirtmelisiniz. Varsayılan iki boşluktur.
