## XmlWriterSettings::get_WriteEndDocumentOnClose() yöntemi

[XmlWriter](../../xmlwriter/) nesnesinin [XmlWriter::Close](../../xmlwriter/close/) yöntemi çağrıldığında, kapatılmamış tüm öğe etiketlerine kapanış etiketleri ekleyip eklemeyeceğini gösteren bir değer döndürür.

```cpp
bool System::Xml::XmlWriterSettings::get_WriteEndDocumentOnClose()
```

### Dönüş Değeri

**true** if all unclosed element tags will be closed out; otherwise, **false**. The default value is **true**.
