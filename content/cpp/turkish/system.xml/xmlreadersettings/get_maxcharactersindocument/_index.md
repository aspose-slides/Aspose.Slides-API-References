## XmlReaderSettings::get_MaxCharactersInDocument() metodu

XML belgesindeki izin verilen maksimum karakter sayısını belirten bir değer döndürür. Sıfır (0) değeri, XML belgesinin boyutu için herhangi bir sınırlama olmadığını gösterir. Sıfırdan farklı bir değer, karakter cinsinden maksimum boyutu belirler.

```cpp
int64_t System::Xml::XmlReaderSettings::get_MaxCharactersInDocument()
```

### Dönüş Değeri

XML belgesindeki izin verilen maksimum karakter sayısı. Varsayılan değer 0'dır.
