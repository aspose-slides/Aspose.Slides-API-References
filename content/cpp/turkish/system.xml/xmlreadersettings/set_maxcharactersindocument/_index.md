## XmlReaderSettings::set_MaxCharactersInDocument(int64_t) metot


Belirli bir XML belgesindeki izin verilen maksimum karakter sayısını gösteren bir değeri ayarlar. Sıfır (0) değeri, XML belgesinin boyutu üzerinde limit olmadığını gösterir. Sıfırdan farklı bir değer, maksimum boyutu karakter cinsinden belirtir.
