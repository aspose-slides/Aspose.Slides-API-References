## DecoderFallback sınıfı

Provides fallback API to handle decoding error. Objects of this sınıf should only be allocated using [System::MakeObject()](../../system/makeobject/) fonksiyonu. Never create instance of this type on stack or using operator new, as it will result in runtime errors and/or assertion faults. Always wrap this sınıf into [System::SmartPtr](../../system/smartptr/) pointer and use this pointer to pass it to functions as argument.

```cpp
class DecoderFallback : public System::Object
```
