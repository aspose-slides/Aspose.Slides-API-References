## Açıklamalar

[Dictionary](./) değerleri anahtarlara eşler. Bu sınıfın nesneleri yalnızca [System::MakeObject()](../../system/makeobject/) işlevi kullanılarak ayrılmalıdır. Bu tür bir örneği yığıt üzerinde ya da new operatörüyle oluşturmaya asla çalışmayın; çünkü çalışma zamanı hatalarına ve/veya doğrulama hatalarına yol açar. Bu sınıfı her zaman [System::SmartPtr](../../system/smartptr/) işaretçisiyle sarın ve bu işaretçiyi fonksiyonlara argüman olarak geçirin.

```cpp
#include <system/collections/dictionary.h>
#include <system/smart_ptr.h>

using namespace System;
using namespace System::Collections::Generic;

int main()
{
  // Dictionary sınıfı örneğini oluştur.
  auto dictionary = MakeObject<Dictionary<int, String>>();

  // Sözlüğü doldur.
  dictionary->Add(0, u"Foo");
  dictionary->Add(1, u"Bar");
  dictionary->Add(2, u"Baz");

  // Sözlük öğelerini yazdır.
  for (const auto &pair: dictionary)
  {
    std::cout << pair.get_Key() << " - " << pair.get_Value() << std::endl;
  }

  return 0;
}
/*
Bu kod örneği aşağıdaki çıktıyı üretir:
0 - Foo
1 - Bar
2 - Baz
*/
```
