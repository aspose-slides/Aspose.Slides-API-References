## XmlSchemaRedefine sınıfı

Represents the **redefine** element from XML [Schema](../) as specified by the World Wide [Web](../../system.web/) Consortium (W3C). This sınıf can be used to allow simple and complex types, groups and attribute groups from external schema files to be redefined in the current schema. This sınıf can also be used to provide versioning for the schema elements.

```cpp
class XmlSchemaRedefine : public System::Xml::Schema::XmlSchemaExternal
```

## Açıklamalar

Bu sınıfın nesneleri yalnızca [System::MakeObject()](../../system/makeobject/) işlevi kullanılarak ayrılmalıdır. Bu tipin örneklerini yığıt (stack) üzerine veya new operatörüyle oluşturmak asla yapılmamalıdır; bu, çalışma zamanı hatalarına ve/veya doğrulama hatalarına neden olur. Bu sınıfı her zaman [System::SmartPtr](../../system/smartptr/) işaretçisine sarın ve bu işaretçiyi fonksiyonlara argüman olarak geçirin.
