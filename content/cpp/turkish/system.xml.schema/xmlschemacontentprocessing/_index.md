## XmlSchemaContentProcessing enum

Herhangi **any** ve **anyAttribute** öğe ikamelerinin doğrulama modu hakkında bilgi sağlar.

```cpp
enum class XmlSchemaContentProcessing
```

### Değerler

| Ad | Değer | Açıklama |
| --- | --- | --- |
| None | 0 | Belge öğeleri doğrulanmaz. |
| Skip | 1 | Belge öğeleri geçerli biçimlendirilmiş XML içermeli ve şema tarafından doğrulanmaz. |
| Lax | 2 | İlişkili şema bulunursa, belge öğeleri doğrulanır. Aksi takdirde hata oluşmaz. |
| Strict | 3 | Şema işlemcisi, belge öğelerini doğrulamak için belirtilen ad alanı ile ilişkili bir şema bulmalıdır. |
