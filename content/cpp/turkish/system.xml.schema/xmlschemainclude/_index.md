## XmlSchemaInclude sınıfı

Represents the **include** element from XML [Schema](../) as specified by the World Wide [Web](../../system.web/) Consortium (W3C). This sınıf is used to include declarations and definitions from an external schema. The included declarations and definitions are then available for processing in the containing schema.

```cpp
class XmlSchemaInclude : public System::Xml::Schema::XmlSchemaExternal
```

## Açıklamalar

Bu sınıfın nesneleri yalnızca [System::MakeObject()](../../system/makeobject/) fonksiyonunu kullanarak ayrılmalıdır. Bu tipin örneklerini yığına (stack) veya new operatörüyle oluşturmaktan kaçının; bu, çalışma zamanı hatalarına ve/veya doğrulama hatalarına neden olur. Her zaman bu sınıfı [System::SmartPtr](../../system/smartptr/) işaretçisine sarın ve bu işaretçiyi fonksiyonlara argüman olarak geçirin.
