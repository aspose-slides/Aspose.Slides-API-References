## XmlSchemaEnumerationFacet sınıf

Represents the **enumeration** facet from XML [Schema](../) as specified by the World Wide [Web](../../system.web/) Consortium (W3C). This class specifies a list of valid values for a simpleType element. Declaration is contained within a **restriction** declaration.

```cpp
class XmlSchemaEnumerationFacet : public System::Xml::Schema::XmlSchemaFacet
```

## Açıklamalar

Bu sınıfın nesneleri yalnızca [System::MakeObject()](../../system/makeobject/) işlevi kullanılarak allocate edilmelidir. Bu tipin örneklerini yığına (stack) ya da operator new ile oluşturmayın; bu, çalışma zamanı hatalarına ve/veya doğrulama hatalarına neden olur. Bu sınıfı her zaman [System::SmartPtr](../../system/smartptr/) işaretçisine sarın ve bu işaretçiyi fonksiyonlara argüman olarak geçirin.
