## XmlSchemaSimpleTypeList sınıf

Represents the **list** element from XML [Schema](../) as specified by the World Wide [Web](../../system.web/) Consortium (W3C). This sınıf can be used to define a **simpleType** element as a list of values of a specified data type.

```cpp
class XmlSchemaSimpleTypeList : public System::Xml::Schema::XmlSchemaSimpleTypeContent
```

## Açıklamalar

Objects of this sınıf should only be allocated using [System::MakeObject()](../../system/makeobject/) function. Never create instances of this type on stack or using operator new, as it will result in runtime errors and/or assertion faults. Always wrap this sınıf into [System::SmartPtr](../../system/smartptr/) pointer and use this pointer to pass it to functions as argument.
