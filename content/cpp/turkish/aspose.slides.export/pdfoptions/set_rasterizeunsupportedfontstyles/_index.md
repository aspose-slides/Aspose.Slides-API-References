## PdfOptions::set_RasterizeUnsupportedFontStyles(bool) metodu

Yazı tipi kalın stilini desteklemediğinde, metnin bitmap olarak rasterleştirilip PDF'ye kaydedilip kaydedilmeyeceğini gösterir. Bu yaklaşım, belirli yazı tipleri için oluşturulan PDF'deki metin kalitesini artırabilir. Yazma **bool**.

```cpp
void Aspose::Slides::Export::PdfOptions::set_RasterizeUnsupportedFontStyles(bool value) override
```

## Açıklamalar

Varsayılan **false** değeridir.
