## MarkdownSaveOptions::get_HandleRepeatedSpaces() const metod


Markdown dışa aktarımı sırasında yinelenen düzenli boşluk karakterlerinin nasıl işleneceğini belirtir.

```cpp
Aspose::Slides::Export::HandleRepeatedSpaces Aspose::Slides::Export::MarkdownSaveOptions::get_HandleRepeatedSpaces() const
```

## Açıklamalar


Bu özellik, ardışık boşlukların şu şekilde olup olmayacağını tanımlar:* düzenli boşluk karakterleri olarak korunur,
* düzenli boşluklar ile bölünmez boşluk varlıkları (**&nbsp;**) arasında değiştirilir,
* veya tamamen (ilkinden sonra) **&nbsp;** ile değiştirilir, Markdown çıktısında görsel hizalamayı korumak için.



Varsayılan değer [HandleRepeatedSpaces::AlternateSpacesToNbsp](../../handlerepeatedspaces/).
