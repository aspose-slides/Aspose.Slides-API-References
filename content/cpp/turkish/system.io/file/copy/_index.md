| destFileName | const [String](../../../system/string/)\& | Kopyalanacak dosyanın yeni konumunun yolu |
| overwrite | **bool** | Mevcut hedef dosyasının üzerine yazılması gerekiyorsa true, hedef dosya zaten mevcutsa kopyalama başarısız olmalıysa false |
