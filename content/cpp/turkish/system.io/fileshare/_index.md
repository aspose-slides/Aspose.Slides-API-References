## FileShare enum

Açılan bir dosyaya diğer [FileStream](../filestream/) nesnelerinin sahip olabileceği erişim türünü belirtir.

```cpp
enum class FileShare
```

### Değerler

| Ad | Değer | Açıklama |
| --- | --- | --- |
| None | 0 | Erişim yok. |
| Read | 1 | Yalnızca okuma erişimi. |
| Write | 2 | Yalnızca yazma erişimi. |
| ReadWrite | 3 | Okuma ve yazma erişimi. |
| Delete | 4 | Dosya silinebilir. |
| Inheritable | 16 | Dosya tutamacını alt süreçler tarafından devralınabilir yapar. |
