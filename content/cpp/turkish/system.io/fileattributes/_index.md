## FileAttributes enum

Dosya sistemi varlığının bir dizin veya dosya özelliğini temsil eder.

```cpp
enum class FileAttributes
```

### Değerler

| Ad | Değer | Açıklama |
| --- | --- | --- |
| Archive | 32 | Dosya sistemi varlığı, silme veya yedekleme için bir adaydır. |
| Compressed | 2048 | Dosya sistemi varlığı sıkıştırılmıştır. |
| Device | 64 | Kullanılmaz. |
| Directory | 16 | Dosya sistemi varlığı bir dizindir. |
| Encrypted | 16384 | Dosya sistemi varlığı şifrelenmiştir. |
| Hidden | 2 | Dosya sistemi varlığı gizlidir. |
| IntegrityStream | 32768 | Dosya sistemi varlığı veri bütünlüğü desteği içerir. |
| Normal | 128 | Dosya sistemi varlığı, özel bir özelliği olmayan bir dosyadır. |
| NotContentIndexed | 8192 | Dosya sistemi varlığı, içerik indeksleme hizmeti tarafından indekslenmeyecektir. |
| NoScrubData | 131072 | Dosya sistemi varlığı veri bütünlüğü taramasına dahil edilmemiştir. |
| Offline | 4096 | Dosya sistemi varlığı çevrim dışıdır ve verileri hemen erişilebilir değildir. |
| ReadOnly | 1 | Dosya sistemi varlığı sadece okumaktır. |
| ReparsePoint | 1024 | Dosya sistemi varlığı, bir yeniden ayrıştırma noktası içeren bir dosyadır. |
| SparseFile | 512 | Dosya sistemi varlığı seyrek bir dosyadır. |
| System | 4 | Dosya sistemi varlığı bir sistem dosyasıdır. |
| Temporary | 256 | Dosya sistemi varlığı geçici bir dosyadır. |
| Invalid | 0 | Geçersiz değer. |
