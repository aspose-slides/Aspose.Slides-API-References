## has_method_compareto struct

Belirtilen tipte CompareTo metodunun mevcut olup olmadığını kontrol eder. Eğer mevcutsa std::true_type'dan, aksi takdirde std::false_type'dan türetilir. std::enable_if içinde kullanılabilir.

```cpp
template<typename T,typename Sfinae>class has_method_compareto : public std::false_type
```

| Parameter | Description |
| --- | --- |
| T | Equals metodunun varlığını kontrol etmek için tip. |
| Sfinae | SFINAE’nin çalışması için resmi şablon argümanı. |
