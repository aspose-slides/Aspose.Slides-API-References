## Rectangle::Offset(const Point\&) metodu

Mevcut nesne tarafından temsil edilen dikdörtgenin konumunu belirtilen miktarlarda kaydırır.

```cpp
void System::Drawing::Rectangle::Offset(const Point &pos)
```

### Argümanlar

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| pos | const [Point](../../point/)\& | Dikdörtgenin kaydırılacağı miktarı belirten [Point](../../point/) nesnesi; noktanın X koordinat değeri, dikdörtgenin sol üst köşesinin X koordinatına eklenmesi gereken miktarı belirtirken, noktanın Y koordinatı, sol üst köşenin Y koordinatına eklenmesi gereken miktarı belirtir. |

void System::Drawing::Rectangle::Offset(int x, int y)

### Argümanlar
