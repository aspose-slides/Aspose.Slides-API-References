## Size::Subtract(const Size\&, const Size\&) metodu


Yeni bir [Size](../) nesnesi döndürür; bu nesne **size1**'den **size2**'nin çıkarılması sonucudur, yani genişlik değeri **size1**'in genişlik değerinden **size2**'nin genişlik değerinin çıkarılması ve yükseklik değeri **size1**'in yüksekliğinden **size2**'nin yüksekliğinin çıkarılması sonucudur.

```cpp
static Size System::Drawing::Size::Subtract(const Size &size1, const Size &size2)
```


### Parametreler

| Parametre | Tip | Açıklama |
| --- | --- | --- |
| size1 | const [Size](../)\& | Çıkarma işleminin yapılacağı [Size](../) nesnesi |
| size2 | const [Size](../)\& | Çıkartılacak [Size](../) nesnesi |

### Dönüş Değeri

[Size](../) nesnesi, **size1**'den **size2**'nin çıkarılması sonucu oluşur.
