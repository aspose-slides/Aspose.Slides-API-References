## StringDigitSubstitute enum

Bir dizedeki rakamların yerel ayar veya dile göre nasıl değiştirileceğini belirtir.

```cpp
enum class StringDigitSubstitute
```

### Values

| Ad | Değer | Açıklama |
| --- | --- | --- |
| User | 0 | Kullanıcı tanımlı ikame. |
| None | 1 | İkame devre dışı bırakılmıştır. |
| National | 2 | Kullanıcının yerel ayarına ait resmi ulusal dile karşılık gelen rakamları ikame eder. |
| Traditional | 3 | Kullanıcının yerel betiği veya diline karşılık gelen rakamları ikame eder; bu, kullanıcının yerel ayarına ait resmi ulusal dilden farklı olabilir. |
