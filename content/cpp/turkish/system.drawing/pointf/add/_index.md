## PointF::Add(const PointF\&, const SizeF\&) metodu

Belirtilen [SizeF](../../sizef/) nesnesinin genişlik ve yükseklik değerlerini, belirtilen [PointF](../) nesnesinin X ve Y koordinat değerlerine karşılık gelen şekilde ekler.

```cpp
static PointF System::Drawing::PointF::Add(const PointF &point, const SizeF &size)
```

### Argümanlar

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| point | const [PointF](../)\& | Çevrilecek nokta |
| size | const [SizeF](../../sizef/)\& | [SizeF](../../sizef/) nesnesi, **point** koordinat değerlerine eklenecek değerleri belirtir |

### Dönüş Değeri

X koordinat değeri **point**'in X koordinat değeri ile **size**'ın genişlik değerinin toplamına, Y koordinat değeri ise **point**'in Y koordinat değeri ile **size**'ın yükseklik değerinin toplamına eşit yeni bir [PointF](../) nesnesi.
