## PointF::Subtract(const PointF\&, const SizeF\&) method

Belirtilen [SizeF](../../sizef/) nesnesinin genişlik ve yükseklik değerlerini, belirtilen [PointF](../) nesnesinin X ve Y koordinat değerlerinden sırasıyla çıkarır.

```cpp
static PointF System::Drawing::PointF::Subtract(const PointF &point, const SizeF &size)
```

### Argümanlar

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| point | const [PointF](../)\& | Çevrilecek nokta |
| size | const [SizeF](../../sizef/)\& | Koordinat değerlerinden **point** nesnesinin değerlerini çıkarmak için belirten [SizeF](../../sizef/) nesnesi |

### Dönüş Değeri

X koordinat değeri **point**'in X koordinat değerinden **size**'in genişlik değerinin çıkarılması sonucuna, Y koordinat değeri **point**'in Y koordinat değerinden **size**'in yükseklik değerinin çıkarılması sonucuna eşit olan yeni bir [PointF](../) nesnesi
