## SizeF::Subtract(const SizeF\&, const SizeF\&) yöntemi

Yeni bir [SizeF](../) nesnesi döndürür; bu nesne **size2**'nin **size1**'den çıkarılması sonucudur, yani genişlik değeri **size2's** genişlik değerinin **size1's** genişlik değerinden çıkarılması sonucu ve yükseklik değeri **size2's** yükseklik değerinin **size1's** yükseklik değerinden çıkarılması sonucudur.

```cpp
static SizeF System::Drawing::SizeF::Subtract(const SizeF &size1, const SizeF &size2)
```

### Argümanlar

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| size1 | const [SizeF](../)\& | Çıkarma işlemi yapılacak [SizeF](../) nesnesi |
| size2 | const [SizeF](../)\& | Çıkarılacak [SizeF](../) nesnesi |

### Dönüş Değeri

[SizeF](../) nesnesi, **size1**'den **size2**'nin çıkarılması sonucudur.
