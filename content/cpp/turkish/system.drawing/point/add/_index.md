## Point::Add(const Point\&, const Size\&) method

Belirtilen [Size](../../size/) nesnesinin genişlik ve yükseklik değerlerini, belirtilen [Point](../) nesnesinin X ve Y koordinat değerlerine karşılık gelecek şekilde ekler.

```cpp
static Point System::Drawing::Point::Add(const Point &point, const Size &size)
```

### Argümanlar

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| point | const [Point](../)\& | **point**'ı çevirmek için |
| size | const [Size](../../size/)\& | [Size](../../size/) nesnesi, **point**'in koordinat değerlerine eklenecek değerleri belirtir |

### Dönüş Değeri

X koordinat değeri **point**'in X koordinat değerinin ve **size**'in genişlik değerinin toplamına, Y koordinat değeri ise **point**'in Y koordinat değerinin ve **size**'in yükseklik değerinin toplamına eşit olan yeni bir [Point](../) nesnesi.
