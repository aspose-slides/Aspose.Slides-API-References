## TraceLevel enum

Belirtilen [System.Diagnostics.Debug](../debug/), [System.Diagnostics.Trace](../trace/) ve System.Diagnostics.TraceSwitch sınıfları için hangi mesajların çıktılanacağını belirler.

```cpp
enum class TraceLevel
```

### Değerler

| Name | Value | Description |
| --- | --- | --- |
| Off | 0 | İzleme ve hata ayıklama mesajı çıkmaz. |
| Error | 1 | Hata işleme mesajları üretir. |
| Warning | 2 | Uyarı ve hata işleme mesajları üretir. |
| Info | 3 | Bilgilendirme mesajları, uyarılar ve hata işleme mesajları üretir. |
| Verbose | 4 | Tüm hata ayıklama ve izleme mesajları üretir. |
