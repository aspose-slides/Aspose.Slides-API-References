## SoapParameterStyle enum


SOAP mesajındaki parametre formatlarını listeler.

```cpp
enum class SoapParameterStyle
```

### Değerler

| Ad | Değer | Açıklama |
| --- | --- | --- |
| Default | 0 | Eğer '[SoapDocumentServiceAttribute](../soapdocumentserviceattribute/)' sınıfa uygulanmazsa, varsayılan değer 'Wrapped' olur. |
| Bare | 1 | Parametreler, 'Body' öğesini izleyen XML öğelerinde yer alır. |
| Wrapped | 2 | Parametreler, 'Body' öğesini izleyen tek bir XML öğesi içinde kapsüllenmiş olur. |
