## SmartPtr::RemoveAliasing() const metod

İşaretçiden (aliasing constructor tarafından oluşturulan) aliasing'i kaldırır, işaretçinin işaret ettiği aynı nesneyi (paylaşıldığında) yönetmesini veya (zayıf olduğunda) izlemesini sağlar.

```cpp
SmartPtr_ System::SmartPtr<T>::RemoveAliasing() const
```

### Dönüş Değeri

Bu işaretçinin işaret ettiği aynı nesnenin ömrünü gözeten aynı nesneye işaretçi.
