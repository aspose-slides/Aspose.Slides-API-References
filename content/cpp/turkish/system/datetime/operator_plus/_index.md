## DateTime::operator+(TimeSpan) const metot

```cpp
DateTime System::DateTime::operator+(TimeSpan value) const
```

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| value | [TimeSpan](../../timespan/) | Geçerli nesnenin temsil ettiği değere eklenecek zaman aralığı |
