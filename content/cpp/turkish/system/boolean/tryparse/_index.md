## Boolean::TryParse(const String\&, bool\&) metod

Belirtilen dizeyi bool tipinde bir değere dönüştürür.

```cpp
static bool System::Boolean::TryParse(const String &value, bool &result)
```

### Argümanlar

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| value | const [String](../../string/)\& | Dönüştürülecek dize. |
| result | **bool**\& | Dönüştürmenin sonucunun yerleştirileceği bir bool değişkenine referans; sonuç, belirtilen dize \"True\" değerine eşitse true, belirtilen dize \"False\" değerine eşitse false olur. |

### Dönüş Değeri

Belirtilen dize \"True\" ya da \"False\" değerine eşitse True, aksi takdirde - false.
