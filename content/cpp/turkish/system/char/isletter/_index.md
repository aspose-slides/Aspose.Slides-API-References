## Char::IsLetter(const char_t *, int) metodu

Belirtilen karakter tamponunda belirtilen indisteki karakterin Unicode harfi olup olmadığını belirler.

```cpp
static bool System::Char::IsLetter(const char_t *str, int idx)
```

### Parametreler

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| str | const char_t * | Karakter tamponunun başlangıcına işaretçi |
| idx | int | Test edilecek karakterin bulunduğu belirtilen tampondaki sıfır tabanlı indeks |

### Dönüş Değeri

Belirtilen indisteki karakter Unicode harfi ise true, aksi takdirde false
