## Char::IsWhiteSpace(const char_t *, int) metodu

Belirtilen karakter tamponundaki belirtilen indeksteki karakterin boşluk karakteri olarak sınıflandırılıp sınıflandırılmadığını belirler.

```cpp
static bool System::Char::IsWhiteSpace(const char_t *str, int idx)
```

### Parametreler

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| str | const char_t * | Karakter tamponunun başlangıcına işaretçi |
| idx | int | Belirtilen tampondaki test edilecek karakterin sıfır bazlı indeksi |

### Dönüş Değeri

Belirtilen indeksteki karakter bir boşluk karakteri ise true, aksi takdirde false
