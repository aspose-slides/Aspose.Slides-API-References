## Char::IsNumber(const char_t *, int) yöntemi


Belirtilen karakter tamponunda belirtilen konumdaki karakterin bir sayı olarak sınıflandırılıp sınıflandırılmadığını belirler.

```cpp
static bool System::Char::IsNumber(const char_t *str, int idx)
```


### Argümanlar

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| str | const char_t * | Karakter tamponunun başlangıcına gösteren işaretçi |
| idx | int | Test edilecek karakterin bulunduğu belirtilen tampon içinde sıfır tabanlı bir indeks |

### Dönüş Değeri

Belirtilen dizindeki karakter bir sayı ise true, aksi takdirde false
