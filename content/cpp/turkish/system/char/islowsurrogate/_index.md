## Char::IsLowSurrogate(const char_t *, int) metod

Belirtilen karakter tamponunda belirtilen konumdaki karakterin düşük surrogate olup olmadığını belirler.

```cpp
static bool System::Char::IsLowSurrogate(const char_t *str, int idx)
```

### Argümanlar

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| str | const char_t * | Karakter tamponunun başlangıcına gösteren işaretçi |
| idx | int | Test edilecek karakterin tampon içindeki sıfırdan başlayan dizini |

### Dönüş Değeri

Doğru, eğer belirtilen konumdaki karakter düşük surrogate ise, aksi takdirde - false
