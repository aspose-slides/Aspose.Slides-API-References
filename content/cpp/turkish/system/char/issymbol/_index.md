## Char::IsSymbol(const char_t *, int) metod


Belirtilen karakter tamponundaki belirtilen indeksteki karakterin sembol karakteri olarak sınıflandırılıp sınıflandırılmadığını belirler.

```cpp
static bool System::Char::IsSymbol(const char_t *str, int idx)
```


### Parametreler

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| str | const char_t * | Karakter tamponunun başlangıcına işaretçi |
| idx | int | Belirtilen tamponda test edilecek karakterin sıfır tabanlı indeksi |

### Dönüş Değeri

Belirtilen indeksteki karakter sembol karakteri ise true, aksi takdirde false
