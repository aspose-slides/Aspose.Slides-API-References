## Char::IsPunctuation(const char_t *, int) yöntemi

Belirtilen karakter arabelleğinde belirtilen konumdaki karakterin noktalama işareti olarak sınıflandırılıp sınıflandırılmadığını belirler.

```cpp
static bool System::Char::IsPunctuation(const char_t *str, int idx)
```

### Argümanlar

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| str | const char_t * | Karakter arabelleğinin başlangıcına işaretçi |
| idx | int | Test edilecek karakterin arabellek içindeki sıfır-tabanlı indeksi |

### Dönüş Değeri

Belirtilen konumdaki karakter bir noktalama işareti ise True, aksi takdirde - false
