```cpp
static bool System::Char::IsUpper(const String &str, int idx)
```


### Arguments

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| str | const [String](../../string/)\& | Bir karakter içeren dize. |
| idx | int | Test edilecek belirtilen dizedeki sıfır tabanlı indeks. |

### Return Value

Belirtilen dizindeki karakter büyük harf ise True, aksi takdirde - false
