## Char::TryParse(const System::String\&, char_t\&) metot

```cpp
static bool System::Char::TryParse(const System::String &s, char_t &result)
```


### Parametreler

| Parameter | Type | Description |

| s | const [System::String](../../string/)\& | [String](../../string/) dönüştürmek için |
| result | char_t\& | Dönüşüm başarılı olursa sonucu içerecek çıktı değişkeni |

### Dönüş Değeri

True if conversion succeeded, otherwise - false
