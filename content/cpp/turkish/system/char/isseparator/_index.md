## Char::IsSeparator(const char_t *, int) metodu


Belirtilen karakter arabellekindeki belirtilen indeksteki karakterin ayırıcı bir karakter olarak sınıflandırılıp sınıflandırılmadığını belirler.

```cpp
static bool System::Char::IsSeparator(const char_t *str, int idx)
```


### Argümanlar

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| str | const char_t * | Karakter arabelleğinin başlangıcına işaretçi |
| idx | int | Test edilecek karakterin arabellek içindeki sıfırdan başlayan indeksi |

### Dönüş Değeri

True, eğer belirtilen indeksteki karakter bir ayırıcı karakter ise, aksi takdirde - false
