## Char::IsLetterOrDigit(const char_t *, int) metodu

Belirtilen karakter tamponundaki belirtilen dizindeki karakterin Unicode harfi veya ondalık rakam olarak sınıflandırılıp sınıflandırılmadığını belirler.

```cpp
static bool System::Char::IsLetterOrDigit(const char_t *str, int idx)
```

### Argümanlar

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| str | const char_t * | Karakter tamponunun başlangıcına işaretçi |
| idx | int | Test edilecek karakterin belirtilen tampondaki sıfır tabanlı dizini |

### Dönüş Değeri

True if the character at the specified index is Unicode letter or a decimal digit, otherwise - false
