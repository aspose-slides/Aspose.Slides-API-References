## Details_UnauthorizedAccessException sınıf

UnauthorizedAccessException, işletim sistemi tarafından bir I/O hatası veya güvenlik hatası nedeniyle erişim reddedildiğinde fırlatılır. Bu sınıfın örneklerini manuel olarak oluşturmayın. Bunun yerine UnauthorizedAccessException sınıfını kullanın. UnauthorizedAccessException sınıfı örneklerini [System::SmartPtr](../smartptr/) içine asla sarmalamayın.

```cpp
class Details_UnauthorizedAccessException : public System::Details_SystemException
```
