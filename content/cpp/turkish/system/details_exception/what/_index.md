## Details_Exception::what() const yöntemi

[what()](./) metodunu uygular ve bu metod [ExceptionWrapper](../../exceptionwrapper/) sınıfı tarafından çağrılır. Bu sınıf std::exception'dan türetilmemiş olsa da, türetilen sınıflar korumalı/özel üyeleri kullanarak kendi mantığını uygulayabilir. Bu metodun uygulamasını [ExceptionWrapper](../../exceptionwrapper/)'ye taşımak bu mantığı bozabilir.

```cpp
virtual const char * System::Details_Exception::what() const noexcept
```
