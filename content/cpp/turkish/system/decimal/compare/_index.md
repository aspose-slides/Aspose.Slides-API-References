## Decimal::Compare(const Decimal\&, const Decimal\&) yöntemi

İlk [Decimal](../) nesnesi tarafından temsil edilen değerin ikinci [Decimal](../) nesnesi tarafından temsil edilen değerden daha küçük, eşit veya daha büyük olup olmadığını belirler.

```cpp
static int System::Decimal::Compare(const Decimal &d1, const Decimal &d2)
```

### Parametreler

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| d1 | const [Decimal](../)\& | İlk karşılaştırılan |
| d2 | const [Decimal](../)\& | İkinci karşılaştırılan |

### Dönüş Değeri

- 1, **d1** tarafından temsil edilen değer **d2** tarafından temsil edilen değerden daha küçüktür; 0, değerler eşittir; 1, **d1** tarafından temsil edilen değer **d2** tarafından temsil edilen değerden daha büyüktür.
