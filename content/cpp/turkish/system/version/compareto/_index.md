## Version::CompareTo(const Version\&) const metodu

Mevcut nesne ve belirtilen nesne tarafından temsil edilen sürümleri karşılaştırır.

```cpp
int System::Version::CompareTo(const Version &ver) const
```

### Argümanlar

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| ver | const [Version](../)\& | Mevcut nesneyle karşılaştırmak için bir [Version](../) nesnesi |

### Dönüş Değeri

- 1, mevcut nesne tarafından temsil edilen sürüm numarası **ver** tarafından temsil edileninden küçükse; 0, sürüm numaraları eşitse; 1, mevcut nesne tarafından temsil edilen sürüm numarası **ver** tarafından temsil edilen değerden büyükse
