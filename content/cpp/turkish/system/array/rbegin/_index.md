## Array::rbegin() metodu


Tersine çevrilmiş konteynerin ilk öğesine bir ters yineleyici döndürür. Bu, ters çevrilmemiş konteynerin son öğesine karşılık gelir. Eğer konteyner boşsa, döndürülen yineleyici [rend()](../rend/) değerine eşittir.

```cpp
reverse_iterator System::Array<T>::rbegin() noexcept
```


### Dönüş Değeri

Konteynerin son öğesine işaret eden bir yineleyici.

## Array::rbegin() const metodu

```cpp
const_reverse_iterator System::Array<T>::rbegin() const noexcept
```


### Dönüş Değeri
