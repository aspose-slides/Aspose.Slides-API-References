## String::IsNull() const metodu

Dizgenin null olarak kabul edilip edilmediğini kontrol eder. [String](../) null'dur ve yalnızca [String()](../string/) yapıcı aracılığıyla oluşturulduysa, taşındıysa, kopyalandıysa veya null dizeden atandıysa ya da [reset()](../reset/) metodu çağrıldıysa.

```cpp
bool System::String::IsNull() const
```

### Dönüş Değeri

dizge null kabul ediliyorsa true, aksi takdirde false.
