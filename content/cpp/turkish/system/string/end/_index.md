## String::end() const metodu


Gerçek dize tamponunun sonuna işaretçi döndürür. Hiçbir şeyi yeniden tahsis etmez. Tamponun null ile sonlandırılacağını garanti etmez.

```cpp
const UChar * System::String::end() const
```


### Dönüş Değeri
