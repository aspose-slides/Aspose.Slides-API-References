## Details_InvalidOperationException sınıfı


The exception that is thrown when a method is invoked on an object which is in the state inconsistent with this call. Never create instances of this class manually. Use the InvalidOperationException class instead. Never wrap the InvalidOperationException class instances into [System::SmartPtr](../smartptr/).

```cpp
class Details_InvalidOperationException : public System::Details_Exception
```
