```cpp
bool System::DateTimeOffset::operator<=(const DateTimeOffset &other) const
```


### Argümanlar

| Parameter | Type | Description |
| --- | --- | --- |
| other | const [DateTimeOffset](../)\& | [DateTimeOffset](../) nesnesi, geçerli nesneyle karşılaştırmak için |

### Dönüş Değeri

Geçerli nesne tarafından temsil edilen tarih ve saat değeri, **other** nesnesi tarafından temsil edilen değerden daha erken veya aynı ise true, aksi takdirde false
