## CultureTypes enum

Culture categories bitmask entries.

```cpp
enum class CultureTypes : int32_t
```

### Değerler

| Ad | Değer | Açıklama |
| --- | --- | --- |
| NeutralCultures | 1 | Dil için belirli, ancak ülke veya bölge için belirli olmayan kültür. |
| SpecificCultures | 2 | Ülke/bölge için belirli. |
| InstalledWin32Cultures | 4 | İşletim Sistemine kurulu kültürler. |
| AllCultures | n/a | Tüm kullanılabilir kültürler. |
| UserCustomCulture | 8 | Kullanıcı tanımlı kültürler. |
| ReplacementCultures | 16 | Mevcut kültürler için kullanıcı tanımlı değiştiriciler. |

| FrameworkCultures | 64 | Kullanım dışı. |
