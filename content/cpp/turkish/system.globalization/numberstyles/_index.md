## NumberStyles enum

Number style allowed when parsing.

```cpp
enum class NumberStyles : int32_t
```

### Değerler

| Ad | Değer | Açıklama |
| --- | --- | --- |
| None | 0 | Rakam olmayan semboller yok. |
| AllowLeadingWhite | 1 | Ön boşluklara izin ver. |
| AllowTrailingWhite | 2 | Son boşluklara izin ver. |
| AllowLeadingSign | 4 | Ön işarete izin ver. |
| Integer | n/a | Varsayılan tamsayı biçimlendirmesi. |
| AllowTrailingSign | 8 | Son işarete izin ver. |
| AllowParentheses | 16 | Negatif değerler için parantez kullanımına izin ver. |
| AllowDecimalPoint | 32 | Ondalık ayırıcıya izin ver. |
| AllowThousands | 64 | Grup ayırıcılarına izin ver. |
| Number | n/a | Varsayılan birleşik sayı biçimi. |
| AllowExponent | 128 | Üs işaretine izin ver. |
| Float | n/a | Varsayılan kayan nokta sayı biçimi. |
| AllowCurrencySymbol | 256 | Para birimi simgesine izin ver. |
| Currency | n/a | Varsayılan para birimi biçimi. |
| Any | n/a | Herhangi bir biçim belirtecine izin ver. |
| AllowHexSpecifier | 512 | Hexadecimal sayılara izin ver. |
| HexNumber | n/a | Varsayılan hexadecimal sayı biçimi. |
