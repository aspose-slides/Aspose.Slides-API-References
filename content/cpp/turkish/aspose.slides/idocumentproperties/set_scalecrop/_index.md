## IDocumentProperties::set_ScaleCrop(bool) yöntemi

Belge küçük resminin görüntüleme modunu gösterir. Bu elemanı **true** olarak ayarlarsanız, belge küçük resminin ekrana ölçeklenmesini etkinleştirir. Bu elemanı **false** olarak ayarlarsanız, belge küçük resminin sadece ekrana uyan bölümleri gösterecek şekilde kırpılmasını etkinleştirir. **bool** yazın.

```cpp
virtual void Aspose::Slides::IDocumentProperties::set_ScaleCrop(bool value)=0
```
