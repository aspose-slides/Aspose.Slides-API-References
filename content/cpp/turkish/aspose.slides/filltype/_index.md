## FillType enum

Çeşitli görsel nesnelerin iç dolgu tipini belirtir.

```cpp
enum class FillType : int8_t
```

### Değerler

| Ad | Değer | Açıklama |
| --- | --- | --- |
| NotDefined | -1 | Dolgu tipi tanımlanmamış. |
| NoFill | 0 | Dolgu uygulanmadı. |
| Solid | 1 | Düz renk ile dolduruldu. |
| Gradient | 2 | Dolgu degradedir. |
| Pattern | 3 | Nesneyi doldurmak için yinelenen desen kullanılır. |
| Picture | 4 | Nesneyi doldurmak için tek bir resim kullanılır. |
| Group | 5 | Görsel nesne, grupdan dolgu özelliklerini miras alır. |
