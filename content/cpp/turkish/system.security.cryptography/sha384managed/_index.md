## SHA384Managed sınıf


Managed [SHA384](../sha384/) hasher. Not implemented. Objects of this sınıf should only be allocated using [System::MakeObject()](../../system/makeobject/) function. Never create instance of this type on stack or using operator new, as it will result in runtime errors and/or assertion faults. Always wrap this sınıf into [System::SmartPtr](../../system/smartptr/) pointer and use this pointer to pass it to functions as argument.

```cpp
class SHA384Managed : public System::Security::Cryptography::SHA384
```
