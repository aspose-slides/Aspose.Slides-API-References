## MathBox::set_NoBreak(bool) metodu


No break Bu özellik, nesne kutusundaki \"unbreakable\" özelliğini belirler. true olduğunda, kutu içinde satır sonları oluşmaz. Bu, birden fazla ikili operatörden oluşan operatör öykünücüler için önemli olabilir. Bu öğe belirtilmediğinde, kutu içinde satır sonları oluşabilir. Varsayılan: true

```cpp
void Aspose::Slides::MathText::MathBox::set_NoBreak(bool value) override
```

## Açıklamalar


Örnek: 
```cpp
auto box = System::MakeObject<MathBox>(System::MakeObject<MathematicalText>(u"*****"));
box->set_NoBreak(false);
```
