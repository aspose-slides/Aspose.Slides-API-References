## IMathMatrix::get_MinColumnWidth() yöntemi


Minimum column width in twips (1/20 bir noktanın 1/20'si) Boşluk aralığı (also referred to as \u201CSütun Boşluğu\u201D or \u201CBoşluk Genişliği\u201D) MinColumnWidth'e eklenerek toplam Matrix [Column](../../../aspose.slides/column/) Spacing (farklı sütunların aynı kenarları arasındaki mesafe) belirlenir. Varsayılan: 0.

```cpp
virtual uint32_t Aspose::Slides::MathText::IMathMatrix::get_MinColumnWidth()=0
```

## Açıklamalar


Örnek: 
```cpp
auto matrix = System::MakeObject<MathMatrix>(2, 3);
matrix->set_MinColumnWidth(20);
```
