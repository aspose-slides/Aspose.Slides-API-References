## MathBorderBox::set_StrikethroughTopLeftToBottomRight(bool) metodu

Üst Sol'dan Alt Sağ'a Çapraz Çizgi (varsayılan false'tur). Çerçeve kutusunun üst sol köşesinden alt sağ köşesine çizilen çapraz çizgi'nin gizli veya gösterilen durumunu belirtir.

```cpp
void Aspose::Slides::MathText::MathBorderBox::set_StrikethroughTopLeftToBottomRight(bool value) override
```

## Açıklamalar

Örnek:
```cpp
auto borderBox = System::MakeObject<MathBorderBox>(System::MakeObject<MathematicalText>(u"x"));
borderBox->set_StrikethroughTopLeftToBottomRight(true);
```
