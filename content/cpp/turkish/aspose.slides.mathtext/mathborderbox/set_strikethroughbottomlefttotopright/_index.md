## MathBorderBox::set_StrikethroughBottomLeftToTopRight(bool) metodu

Strikethrough Bottom-Left to Top-Right (varsayılan false). Border kutusunun alt-sol köşesinden üst-sağ köşesine uzanan bir üzeri çizili diyagonal çizginin gizli veya gösterilen durumunu belirler.

```cpp
void Aspose::Slides::MathText::MathBorderBox::set_StrikethroughBottomLeftToTopRight(bool value) override
```

## Açıklamalar

Örnek:
```cpp
auto borderBox = System::MakeObject<MathBorderBox>(System::MakeObject<MathematicalText>(u"x"));
borderBox->set_StrikethroughBottomLeftToTopRight(true);
```
