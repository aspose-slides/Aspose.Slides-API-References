## IMathBorderBox::get_StrikethroughTopLeftToBottomRight() metot


Strikethrough Top-Left to Bottom-Right (varsayılan false). Border kutusunun üst sol köşesinden alt sağ köşesine uzanan bir çapraz çizginin gizli veya gösterilir durumunu belirtir.

```cpp
virtual bool Aspose::Slides::MathText::IMathBorderBox::get_StrikethroughTopLeftToBottomRight()=0
```

## Açıklamalar


Örnek: 
```cpp
auto borderBox = System::MakeObject<MathematicalText>(u"x+y+z")->ToBorderBox();
borderBox->set_StrikethroughTopLeftToBottomRight(true);
```
