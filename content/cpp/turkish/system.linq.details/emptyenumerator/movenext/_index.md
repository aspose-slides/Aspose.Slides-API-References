## EmptyEnumerator::MoveNext() metodu

Enumeratörü bir sonraki öğeye taşır. Daha önce hiçbir öğeye referans verilmemişse, referansı mevcut ilk öğeye ayarlar. Eğer konteyner sonuna ulaşılmışsa, hiçbir şey yapmaz.

```cpp
bool System::Linq::Details::EmptyEnumerator<T>::MoveNext() override
```

### Dönüş Değeri

True if some element is available after call, false otherwise.
