## Catatan



Objek kelas ini sebaiknya hanya dialokasikan menggunakan fungsi [System::MakeObject()](../../system/makeobject/). Jangan pernah membuat instance tipe ini di stack atau menggunakan operator new, karena dapat menyebabkan kesalahan runtime dan/atau kegagalan asersi. Selalu bungkus kelas ini dengan pointer [System::SmartPtr](../../system/smartptr/) dan gunakan pointer tersebut untuk meneruskannya ke fungsi sebagai argument.
