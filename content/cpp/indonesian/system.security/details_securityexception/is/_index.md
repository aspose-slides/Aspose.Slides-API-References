## Details_SecurityException::Is(const System::TypeInfo\&) const method




```cpp
bool System::Security::Details_SecurityException::Is(const System::TypeInfo &target) const override
```


### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| target | const [System::TypeInfo](../../../system/typeinfo/)\& | [TypeInfo](../../../system/typeinfo/) struktur yang menggambarkan tipe untuk menguji objek saat ini terhadap. |

### Nilai Kembali

True jika objek merupakan tipe yang ditandai atau subclass-nya, false sebaliknya.

## Catatan

Periksa apakah objek merupakan instance dari tipe yang dijelaskan oleh targetType. Analog dari operator 'is' C#.
