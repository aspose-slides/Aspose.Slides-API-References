## String::begin() const metode


Mengembalikan penunjuk ke awal buffer string yang sebenarnya. Tidak pernah melakukan alokasi ulang apa pun. Tidak menjamin buffer diakhiri dengan null.

```cpp
const UChar * System::String::begin() const
```


### Nilai Kembali

Penunjuk ke buffer string yang sebenarnya, baik yang diakhiri null maupun tidak.
