## String::IsNull() const metode

Memeriksa apakah string dianggap null. [String](../) adalah null dan hanya jika itu dibangun melalui konstruktor [String()](../string/), dipindahkan, disalin atau ditetapkan dari string null atau metode [reset()](../reset/) dipanggil.

```cpp
bool System::String::IsNull() const
```

### Nilai Kembali

true jika string dianggap null, false sebaliknya.
