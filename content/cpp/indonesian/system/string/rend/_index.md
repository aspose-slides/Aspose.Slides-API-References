## String::rend() const metode

Mengembalikan iterator terbalik ke sebelum karakter pertama (jika ada) dari buffer string aktual.

```cpp
reverse_iterator System::String::rend() const
```

### Nilai Kembali

Iterator terbalik ke elemen yang berada sebelum karakter pertama dari buffer string aktual (jika ada) atau ke elemen tepat sebelum buffer yang dialokasikan.
