## String::IsNullOrWhiteSpace(const String\&) metode

Menunjukkan apakah string yang ditentukan bernilai null, kosong, atau hanya berisi karakter spasi putih.

```cpp
static bool System::String::IsNullOrWhiteSpace(const String &str)
```

### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| str | const [String](../)\& | [String](../) untuk diperiksa. |

### Nilai Kembalian
