## Char::IsSymbol(const char_t *, int) metode

Menentukan apakah karakter pada indeks yang ditentukan dalam buffer karakter yang ditentukan diklasifikasikan sebagai karakter simbol.

```cpp
static bool System::Char::IsSymbol(const char_t *str, int idx)
```

### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| str | const char_t * | Penunjuk ke awal buffer karakter |
| idx | int | Indeks berbasis nol dalam buffer yang ditentukan dari karakter yang diuji |

### Nilai Kembali

True jika karakter pada indeks yang ditentukan adalah karakter simbol, jika tidak - false

## Char::IsSymbol(char_t) metode

Menentukan apakah karakter yang ditentukan diklasifikasikan sebagai karakter simbol.

```cpp
static bool System::Char::IsSymbol(char_t c)
```

### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| c | char_t | Karakter yang akan diuji |

### Nilai Kembali

True jika karakter yang ditentukan adalah karakter simbol, jika tidak - false
