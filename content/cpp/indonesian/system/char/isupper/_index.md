## Char::IsUpper(const String\&, int) metode

Menentukan apakah karakter pada indeks yang ditentukan dalam string yang ditentukan diklasifikasikan sebagai huruf kapital.

```cpp
static bool System::Char::IsUpper(const String &str, int idx)
```

### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| str | const [String](../../string/)\& | String yang berisi char. |
| idx | int | Indeks berbasis nol dalam string yang ditentukan untuk diuji |

### Nilai Kembalian

True jika karakter pada indeks yang ditentukan adalah huruf kapital, jika tidak - false
