## Char::IsSurrogate(char_t) metode

Menentukan apakah karakter yang ditentukan merupakan unit kode surrogate UTF-16.

```cpp
static bool System::Char::IsSurrogate(char_t c)
```

### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| c | char_t | Sebuah karakter |

### Nilai Kembalian

True jika karakter yang ditentukan merupakan unit kode surrogate UTF-16, jika tidak - false
