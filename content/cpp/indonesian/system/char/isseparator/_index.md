## Char::IsSeparator(const char_t *, int) metode

Menentukan apakah karakter pada indeks yang ditentukan dalam buffer karakter yang ditentukan diklasifikasikan sebagai karakter pemisah.

```cpp
static bool System::Char::IsSeparator(const char_t *str, int idx)
```

### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| str | const char_t * | Pointer ke awal buffer karakter |
| idx | int | Indeks berbasis nol dalam buffer yang ditentukan untuk karakter yang akan diuji |

### Nilai Kembalian

True jika karakter pada indeks yang ditentukan adalah karakter pemisah, sebaliknya - false

## Char::IsSeparator(char_t) metode

Menentukan apakah karakter yang ditentukan diklasifikasikan sebagai karakter pemisah.

```cpp
static bool System::Char::IsSeparator(char_t c)
```

### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| c | char_t | Karakter yang akan diuji |

### Nilai Kembalian

True jika karakter yang ditentukan adalah karakter pemisah, sebaliknya - false
