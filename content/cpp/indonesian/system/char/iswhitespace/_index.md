## Char::IsWhiteSpace(const char_t *, int) metode

Menentukan apakah karakter pada indeks yang ditentukan dalam buffer karakter yang ditentukan diklasifikasikan sebagai karakter spasi.

```cpp
static bool System::Char::IsWhiteSpace(const char_t *str, int idx)
```

### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| str | const char_t * | Penunjuk ke awal buffer karakter |
| idx | int | Indeks berbasis nol dalam buffer yang ditentukan untuk karakter yang diuji |

### Nilai Kembali

True jika karakter pada indeks yang ditentukan adalah karakter spasi, lainnya - false
