## Char::IsDigit(const char_t *, int) metode


Menentukan apakah karakter pada indeks yang ditentukan dalam buffer karakter yang diberikan diklasifikasikan sebagai digit desimal.

```cpp
static bool System::Char::IsDigit(const char_t *str, int idx)
```


### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| str | const char_t * | Penunjuk ke awal buffer karakter |
| idx | int | Indeks berbasis nol dalam buffer yang ditentukan untuk karakter yang akan diuji |

### Nilai Kembalian

True jika karakter pada indeks yang ditentukan adalah digit desimal, jika tidak - false
