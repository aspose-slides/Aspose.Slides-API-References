## Char::TryParse(const System::String\&, char_t\&) metode

Mencoba mengkonversi string yang terdiri dari satu karakter menjadi karakter UTF-16. Fungsi berhasil hanya bila string masukan tidak null dan memiliki panjang tepat satu karakter.

```cpp
static bool System::Char::TryParse(const System::String &s, char_t &result)
```

### Argument

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| s | const [System::String](../../string/)\& | [String](../../string/) untuk dikonversi |
| result | char_t\& | Variabel output yang akan berisi hasil konversi jika konversi berhasil |

### Nilai Kembali

True jika konversi berhasil, jika tidak - false
