## Char::IsLower(const char_t *, int) metode

Menentukan apakah karakter pada indeks yang ditentukan dalam buffer karakter yang ditentukan diklasifikasikan sebagai huruf kecil.

```cpp
static bool System::Char::IsLower(const char_t *str, int idx)
```

### Argumen

| Parameter | Type | Deskripsi |
| --- | --- | --- |
| str | const char_t * | Penunjuk ke awal buffer karakter |
| idx | int | Indeks berbasis nol dalam buffer yang ditentukan untuk karakter yang diuji |

### Nilai Kembalian

True jika karakter pada indeks yang ditentukan adalah huruf kecil, jika tidak - false
