## Char::IsNumber(const char_t *, int) metode

Menentukan apakah karakter pada indeks yang ditentukan dalam buffer karakter yang ditentukan diklasifikasikan sebagai angka.

```cpp
static bool System::Char::IsNumber(const char_t *str, int idx)
```

### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| str | const char_t * | Penunjuk ke awal buffer karakter |
| idx | int | Indeks berbasis nol dalam buffer yang ditentukan untuk karakter yang akan diuji |

### Nilai Kembalian

True jika karakter pada indeks yang ditentukan adalah angka, otherwise - false

## Char::IsNumber(char_t) metode

Menentukan apakah karakter yang ditentukan diklasifikasikan sebagai angka.

```cpp
static bool System::Char::IsNumber(char_t c)
```

### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| c | char_t | Karakter yang akan diuji |

### Nilai Kembalian

True jika karakter yang ditentukan adalah angka, otherwise - false
