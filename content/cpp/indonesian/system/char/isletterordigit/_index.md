## Char::IsLetterOrDigit(const char_t *, int) metode

Menentukan apakah karakter pada indeks yang ditentukan dalam buffer karakter yang ditentukan diklasifikasikan sebagai huruf Unicode atau digit desimal.

```cpp
static bool System::Char::IsLetterOrDigit(const char_t *str, int idx)
```

### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| str | const char_t * | Penunjuk ke awal buffer karakter |
| idx | int | Indeks berbasis nol dalam buffer yang ditentukan untuk karakter yang akan diuji |

### Return Value

True jika karakter pada indeks yang ditentukan adalah huruf Unicode atau digit desimal, jika tidak - false
