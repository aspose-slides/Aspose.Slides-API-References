## Details_NotImplementedException::Is(const System::TypeInfo\&) const method

```cpp
bool System::Details_NotImplementedException::Is(const System::TypeInfo &target) const override
```

### Argumen

| Parameter | Type | Description |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struktur yang menjelaskan tipe untuk menguji objek saat ini terhadapnya. |

### Nilai Kembalian

Benar jika objek merupakan tipe yang ditandai atau subclass-nya, salah jika tidak.

## Catatan

Periksa apakah objek mewakili sebuah instance dari tipe yang dijelaskan oleh targetType. Analogi operator 'is' di C#.
