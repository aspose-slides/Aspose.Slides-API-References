```cpp
bool System::Details_ArgumentException::Is(const System::TypeInfo &target) const override
```


### Argumen

| Parameter | Type | Deskripsi |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struktur yang menjelaskan tipe untuk menguji objek saat ini terhadapnya. |

### Nilai Kembali

## Keterangan


Periksa apakah objek mewakili instance dari tipe yang dijelaskan oleh targetType. Analog operator 'is' di C#.
