## TypeInfo::IsDefined(const TypeInfo\&, bool) const metode

NOT IMPLEMENTED. Menunjukkan apakah satu atau lebih atribut dari tipe yang ditentukan atau dari tipe yang diturunkan diterapkan pada anggota ini.

```cpp
bool System::TypeInfo::IsDefined(const TypeInfo &attributeType, bool inherit) const
```

### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| attributeType | const [TypeInfo](../)\& | Tipe atribut khusus yang akan dicari. Pencarian mencakup tipe yang diturunkan. |
| inherit | **bool** | true untuk mencari rantai pewarisan anggota ini guna menemukan atribut; jika tidak, false. Parameter ini diabaikan untuk properti dan event. |

### Nilai Kembali

true jika satu atau lebih instance dari attributeType atau tipe turunannya diterapkan pada anggota ini; jika tidak, false.
