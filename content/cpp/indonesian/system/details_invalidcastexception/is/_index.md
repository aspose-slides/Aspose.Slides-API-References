## Details_InvalidCastException::Is(const System::TypeInfo\&) const method

```cpp
bool System::Details_InvalidCastException::Is(const System::TypeInfo &target) const override
```

### Argumen

| Parameter | Type | Description |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struktur yang menggambarkan tipe untuk menguji objek saat ini. |

### Nilai Kembali

True jika objek berjenis tipe yang ditandai atau subclass-nya, false jika tidak.

## Keterangan

Periksa apakah objek mewakili instance dari tipe yang dijelaskan oleh targetType. Analog dari operator 'is' di C#.
