## System::BuildArray() fungsi


Membuat sebuah array.

```cpp
template<typename T> Details::ObjectBuilder<Details::ArrayStorage<T>> System::BuildArray()
```


### Parameter templat

| Parameter | Deskripsi |
| --- | --- |
| T | Tipe elemen array yang akan dibangun |

### Nilai Kembalian

ObjectBuilder dikonfigurasi untuk konstruksi array
## Keterangan



Membuat sebuah ArrayPtr<T> dan mengembalikan builder untuknya
[Object](../object/) konstruksi harus selesai dengan [Get()](../get/) panggilan
