## Detail_NullReferenceException::Is(const System::TypeInfo\&) const method

```cpp
bool System::Details_NullReferenceException::Is(const System::TypeInfo &target) const override
```

### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struktur yang menggambarkan tipe untuk menguji objek saat ini terhadap. |

### Nilai Kembalian

True jika objek adalah tipe yang ditandai atau subclass-nya, false sebaliknya.

## Catatan

Periksa apakah objek mewakili contoh dari tipe yang dijelaskan oleh targetType. Analogi operator 'is' di C#.
