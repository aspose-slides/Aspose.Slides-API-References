## SmartPtr::get_shared_count() const metode

Mendapatkan jumlah pointer bersama yang ada pada objek yang dirujuk, termasuk yang saat ini. Memastikan pointer saat ini berada dalam mode bersama.

```cpp
int System::SmartPtr<T>::get_shared_count() const
```

### Nilai Kembali

Jumlah pointer bersama yang ada pada objek yang dirujuk, jika ada. Jika pointer null, mengembalikan 0.
