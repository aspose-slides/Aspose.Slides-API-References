## SmartPtrMode enum

[SmartPtr](../smartptr/) tipe pointer: lemah atau berbagi. Menentukan apakah pointer dihitung ketika diputuskan apakah objek akan dihapus atau tidak.

```cpp
enum class SmartPtrMode : char
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Shared | 0 | Shared mode: pointer berpartisipasi dalam penghitung referensi. |
| Weak | 1 | Weak mode: pointer tidak berpartisipasi dalam penghitung referensi. |
