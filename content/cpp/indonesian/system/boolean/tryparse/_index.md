## Boolean::TryParse(const String\&, bool\&) metode

Mengonversi string yang ditentukan menjadi nilai tipe bool.

```cpp
static bool System::Boolean::TryParse(const String &value, bool &result)
```

### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| value | const [String](../../string/)\& | String yang akan dikonversi. |
| result | **bool**\& | Referensi ke variabel bool dimana hasil konversi ditempatkan; hasilnya true jika string yang ditentukan sama dengan \"True\" dan false jika string yang ditentukan sama dengan \"False\". |

### Nilai Kembalian

True jika string yang ditentukan sama dengan \"True\" atau \"False\", lainnya - false.
