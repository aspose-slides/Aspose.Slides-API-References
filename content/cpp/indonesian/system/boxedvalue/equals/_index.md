## BoxedValue::Equals(ptr) metode


Determines the equality of the boxed values represented by the current and specified objects.

```cpp
bool System::BoxedValue<T>::Equals(ptr obj) override
```


### Argumen

| Parameter | Type | Description |
| --- | --- | --- |
| obj | [ptr](../../object/ptr/) | Objek yang mewakili nilai yang dibungkus untuk dibandingkan dengan nilai yang dibungkus yang diwakili oleh objek saat ini |

### Nilai Kembalian

True jika nilai yang dibungkus yang diwakili oleh objek saat ini dan **obj** sama, jika tidak - false
