## DateTime::Compare(DateTime, DateTime) metode

Membandingkan dua nilai yang diwakili oleh instance [DateTime](../) kelas yang ditentukan dan mengembalikan nilai yang menunjukkan posisi relatif nilai pada garis waktu.

```cpp
static constexpr int System::DateTime::Compare(DateTime t1, DateTime t2)
```

### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| t1 | [DateTime](../) | Komparan pertama |
| t2 | [DateTime](../) | Komparan kedua |

### Nilai Kembalian

Nilai yang kurang dari 0 jika **t1** lebih awal dari **t2**; 0 jika **t1** sama dengan **t2**; nilai yang lebih besar dari 0 jika **t1** lebih lambat dari **t2**
