## DateTime::IsDaylightSavingTime() const metode

Menentukan apakah nilai tanggal dan waktu yang diwakili oleh objek saat ini berada dalam rentang waktu siang untuk zona waktu saat ini.

```cpp
bool System::DateTime::IsDaylightSavingTime() const
```

### Nilai Kembalian

True jika nilai tanggal dan waktu yang ditentukan oleh objek saat ini berada dalam rentang waktu siang, sebaliknya - false
