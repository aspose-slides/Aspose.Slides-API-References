## Details_OverflowException::Is(const System::TypeInfo\&) const metode

```cpp
bool System::Details_OverflowException::Is(const System::TypeInfo &target) const override
```

### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struktur yang menggambarkan tipe untuk menguji objek saat ini. |

### Nilai Kembali

True jika objek berjenis tipe yang ditandai atau subclass-nya, false sebaliknya.

## Catatan

Periksa apakah objek merupakan instance dari tipe yang dijelaskan oleh targetType. Analogi operator 'is' di C#.
