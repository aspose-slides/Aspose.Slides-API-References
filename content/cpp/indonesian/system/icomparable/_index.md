## IComparable kelas

Mendefinisikan metode yang membandingkan dua objek. Objek dari kelas ini hanya boleh dialokasikan menggunakan fungsi [System::MakeObject()](../makeobject/). Jangan pernah membuat instance tipe ini di stack atau menggunakan operator new, karena akan mengakibatkan kesalahan runtime dan/atau kegagalan asersi. Selalu bungkus kelas ini ke dalam pointer [System::SmartPtr](../smartptr/) dan gunakan pointer ini untuk melewatkannya ke fungsi sebagai argumen.

```cpp
template<typename T>class IComparable : public virtual System::Object
```

### Parameter templat

| Parameter | Deskripsi |
| --- | --- |
| T | Tipe objek yang dibandingkan dengan objek saat ini |
