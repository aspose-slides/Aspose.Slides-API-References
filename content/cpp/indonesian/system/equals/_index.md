## System::Equals(const TA\&, const TB\&) fungsi

Menentukan kesetaraan dua nilai dengan menerapkan [operator==()](../operator_equal_equal/) pada mereka.

```cpp
template<typename TA,typename TB> bool System::Equals(const TA &a, const TB &b)
```

### Parameter templat

| Parameter | Deskripsi |
| --- | --- |
| TA | Tipe dari operand pertama |
| TB | Tipe dari operand kedua |

### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| a | const TA\& | Operand pertama |
| b | const TB\& | Operand kedua |

### Nilai Kembalian

Nilai boolean yang dikembalikan oleh [operator==()](../operator_equal_equal/) yang diterapkan pada **a** dan **b**
