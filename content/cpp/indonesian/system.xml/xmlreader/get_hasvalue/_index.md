## XmlReader::get_HasValue() metode


Saat dioverride dalam kelas turunan, mengembalikan nilai yang menunjukkan apakah node saat ini dapat memiliki nilai [XmlReader::get_Value](../get_value/).

```cpp
virtual bool System::Xml::XmlReader::get_HasValue()
```


### Nilai Kembali

**true** jika node tempat pembaca saat ini berada dapat memiliki **Value**; sebaliknya, **false**. Jika **false**, node memiliki nilai [String::Empty](../../../system/string/empty/).
