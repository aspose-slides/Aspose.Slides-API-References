## XmlReader::MoveToElement() metode


Ketika ditimpa dalam kelas turunan, berpindah ke elemen yang berisi node atribut saat ini.

```cpp
virtual bool System::Xml::XmlReader::MoveToElement()=0
```


### Nilai Kembali

**true** jika pembaca berada pada atribut (pembaca berpindah ke elemen yang memiliki atribut); **false** jika pembaca tidak berada pada atribut (posisi pembaca tidak berubah).
