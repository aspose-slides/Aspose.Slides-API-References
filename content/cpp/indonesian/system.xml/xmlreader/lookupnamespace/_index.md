## XmlReader::LookupNamespace(const String\&) metode

Saat ditimpa dalam kelas turunan, menyelesaikan prefiks namespace dalam ruang lingkup elemen saat ini.

```cpp
virtual String System::Xml::XmlReader::LookupNamespace(const String &prefix)=0
```

### Argumen

| Parameter | Type | Deskripsi |
| --- | --- | --- |
| prefix | const [String](../../../system/string/)\& | Prefiks yang namespace URI-nya ingin Anda selesaikan. Untuk mencocokkan namespace default, berikan string kosong. |

### Nilai Kembali

Namespace URI yang dipetakan oleh prefiks atau **nullptr** jika tidak ada prefiks yang cocok.
