## XmlReader::get_IsEmptyElement() metode

Saat dioverride dalam kelas turunan, mengembalikan nilai yang menunjukkan apakah node saat ini adalah elemen kosong (misalnya, **<MyElement/>**).

```cpp
virtual bool System::Xml::XmlReader::get_IsEmptyElement()=0
```

### Nilai Kembali

**true** jika node saat ini adalah elemen ([XmlReader::get_NodeType](../get_nodetype/) sama dengan [XmlNodeType::Element](../../xmlnodetype/)) yang berakhir dengan **/>**; sebaliknya, **false**.
