## XmlReader::ReadInnerXml() metode

Saat ditimpa dalam kelas turunan, membaca semua konten, termasuk markup, sebagai string.

```cpp
virtual String System::Xml::XmlReader::ReadInnerXml()
```

### Nilai Kembali

Semua konten XML, termasuk markup, pada node saat ini. Jika node saat ini tidak memiliki anak, string kosong dikembalikan. Jika node saat ini bukan elemen maupun atribut, string kosong dikembalikan.
