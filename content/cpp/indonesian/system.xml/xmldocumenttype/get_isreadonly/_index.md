## XmlDocumentType::get_IsReadOnly() metode


Mengembalikan nilai yang menunjukkan apakah node bersifat hanya-baca.

```cpp
bool System::Xml::XmlDocumentType::get_IsReadOnly() override
```


### Nilai Kembalian

**true** jika node bersifat hanya-baca; lainnya, **false**. Karena node DocumentType bersifat hanya-baca, metode ini selalu mengembalikan **true**.
