## XmlAttribute::get_Specified() method


Mengembalikan nilai yang menunjukkan apakah nilai atribut ditetapkan secara eksplisit.

```cpp
virtual bool System::Xml::XmlAttribute::get_Specified()
```


### Nilai Kembalian

**true** jika atribut ini secara eksplisit diberikan nilai dalam dokumen instance asli; selainnya, **false**. Nilai **false** menunjukkan bahwa nilai atribut berasal dari DTD.
