## XmlWriter::WriteProcessingInstruction(String, String) method

Ketika dioverride dalam kelas turunan, menulis instruksi pemrosesan dengan spasi antara nama dan teks seperti berikut: **<?name text?>**.

```cpp
virtual void System::Xml::XmlWriter::WriteProcessingInstruction(String name, String text)=0
```

### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| name | [String](../../../system/string/) | Nama instruksi pemrosesan. |
| text | [String](../../../system/string/) | Teks yang dimasukkan ke dalam instruksi pemrosesan. |
## Catatan

Metode ini digunakan untuk membuat deklarasi XML setelah [XmlWriter::WriteStartDocument](../writestartdocument/) sudah dipanggil.
