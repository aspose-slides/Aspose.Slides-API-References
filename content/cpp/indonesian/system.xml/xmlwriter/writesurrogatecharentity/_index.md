## XmlWriter::WriteSurrogateCharEntity(char16_t, char16_t) metode

Saat dioverride dalam kelas turunan, menghasilkan dan menulis entitas karakter surrogate untuk pasangan karakter surrogate.

```cpp
virtual void System::Xml::XmlWriter::WriteSurrogateCharEntity(char16_t lowChar, char16_t highChar)=0
```

### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| lowChar | char16_t | Surrogate rendah. Ini harus berupa nilai antara 0xDC00 dan 0xDFFF. |
| highChar | char16_t | Surrogate tinggi. Ini harus berupa nilai antara 0xD800 dan 0xDBFF. |
