## Metode XmlWriter::get_XmlSpace() 

Saat dioverride dalam kelas turunan, mengembalikan XmlSpace yang mewakili ruang **xml:space** saat ini.

```cpp
virtual System::Xml::XmlSpace System::Xml::XmlWriter::get_XmlSpace()
```

### Nilai Kembali

Sebuah XmlSpace yang mewakili ruang **xml:space** saat ini.



| Nilai | Makna |
| --- | --- |
| `None`| Ini adalah default jika tidak ada ruang `xml:space` ada. |
| `Default`| Ruang saat ini adalah `xml:space="default"`. |
| `Preserve`| Ruang saat ini adalah `xml:space="preserve"`. |
