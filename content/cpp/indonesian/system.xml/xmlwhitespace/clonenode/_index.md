### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| deep | **bool** | **true** untuk menyalin secara rekursif subtree di bawah node yang ditentukan; **false** untuk menyalin hanya node itu sendiri. Untuk node spasi putih, node yang disalin selalu menyertakan nilai data, terlepas dari pengaturan parameter. |
