## XmlTextWriter::WriteSurrogateCharEntity(char16_t, char16_t) metode


Menghasilkan dan menulis entitas karakter surrogate untuk pasangan karakter surrogate.

```cpp
void System::Xml::XmlTextWriter::WriteSurrogateCharEntity(char16_t lowChar, char16_t highChar) override
```


### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| lowChar | char16_t | Surrogate rendah. Ini harus berupa nilai antara **0xDC00** dan **0xDFFF**. |
| highChar | char16_t | Surrogate tinggi. Ini harus berupa nilai antara **0xD800** dan **0xDBFF**. |
