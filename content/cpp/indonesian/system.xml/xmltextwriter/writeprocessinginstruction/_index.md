## XmlTextWriter::WriteProcessingInstruction(String, String) metode

```cpp
void System::Xml::XmlTextWriter::WriteProcessingInstruction(String name, String text) override
```


### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
