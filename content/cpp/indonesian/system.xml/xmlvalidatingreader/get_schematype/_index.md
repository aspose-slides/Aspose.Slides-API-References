SharedPtr<Object> System::Xml::XmlValidatingReader::get_SchemaType()

### Nilai Kembalian

XmlSchemaDatatype, XmlSchemaSimpleType, atau XmlSchemaComplexType tergantung apakah nilai node adalah tipe bahasa definisi XML [Schema](../../../system.xml.schema/) bawaan (XSD) atau tipe simpleType atau complexType yang didefinisikan pengguna; **nullptr** jika node saat ini tidak memiliki tipe skema.
