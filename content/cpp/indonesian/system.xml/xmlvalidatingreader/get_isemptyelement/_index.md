## XmlValidatingReader::get_IsEmptyElement() metode


Mengembalikan nilai yang menunjukkan apakah node saat ini merupakan elemen kosong (misalnya, **<MyElement/>**).

```cpp
bool System::Xml::XmlValidatingReader::get_IsEmptyElement() override
```


### Nilai Kembalian

**true** jika node saat ini merupakan elemen ([XmlValidatingReader::get_NodeType](../get_nodetype/) nilai sama dengan [XmlNodeType::Element](../../xmlnodetype/)) yang diakhiri dengan **/>**; selain itu, **false**.
