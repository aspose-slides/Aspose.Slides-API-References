## XmlValidatingReader::get_LocalName() metode

Mengembalikan nama lokal node saat ini.

```cpp
String System::Xml::XmlValidatingReader::get_LocalName() override
```

### Nilai Kembali

Nama node saat ini dengan awalan yang dihapus. Misalnya, **LocalName** adalah **book** untuk elemen **<bk:book>**. Untuk tipe node yang tidak memiliki nama (seperti **[Text](../../../system.text/)**, **Comment**, dan sebagainya), metode ini mengembalikan [String::Empty](../../../system/string/empty/).
