## XmlTextReader::get_LocalName() metode


Mengembalikan nama lokal dari node saat ini.

```cpp
String System::Xml::XmlTextReader::get_LocalName() override
```


### Nilai Kembalian

Nama node saat ini dengan awalan dihapus. Misalnya, **LocalName** adalah **book** untuk elemen **<bk:book>**. Untuk tipe node yang tidak memiliki nama (seperti **[Text](../../../system.text/)**, **Comment**, dan seterusnya), metode ini mengembalikan [String::Empty](../../../system/string/empty/).
