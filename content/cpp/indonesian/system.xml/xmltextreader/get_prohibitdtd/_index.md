## XmlTextReader::get_ProhibitDtd() method


Mengembalikan nilai yang menunjukkan apakah pemrosesan DTD diizinkan.

```cpp
bool System::Xml::XmlTextReader::get_ProhibitDtd()
```


### Nilai Kembali

:   Metode ini sudah usang. Gunakan [XmlTextReader::get_DtdProcessing](../get_dtdprocessing/) sebagai gantinya.
