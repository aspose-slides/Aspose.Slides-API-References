## XmlTextReader::ReadString() metode

Membaca isi sebuah elemen atau node teks sebagai string.

```cpp
String System::Xml::XmlTextReader::ReadString() override
```

### Nilai Kembali

Isi dari elemen atau node teks. Ini dapat berupa string kosong jika pembaca berada pada sesuatu selain elemen atau node teks, atau jika tidak ada lagi konten teks yang dapat dikembalikan dalam konteks saat ini. **Catatan:** Node teks dapat berupa elemen atau node teks atribut.
