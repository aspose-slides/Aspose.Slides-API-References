## XmlElement::RemoveAttribute(String) metode

Removes an attribute by name.

```cpp
virtual void System::Xml::XmlElement::RemoveAttribute(String name)
```

### Argumen

| Parameter | Type | Description |
| --- | --- | --- |
| name | [String](../../../system/string/) | Nama atribut yang akan dihapus. Ini adalah nama yang memenuhi syarat. Itu dicocokkan dengan nilai **get_Name** dari node yang cocok. |

## XmlElement::RemoveAttribute(String, String) metode

Removes an attribute with the specified local name and namespace URI. (If the removed attribute has a default value, it is immediately replaced).

```cpp
virtual void System::Xml::XmlElement::RemoveAttribute(String localName, String namespaceURI)
```

### Argumen

| Parameter | Type | Description |
| --- | --- | --- |
| localName | [String](../../../system/string/) | Nama lokal atribut yang akan dihapus. |
| namespaceURI | [String](../../../system/string/) | URI namespace dari atribut yang akan dihapus. |
