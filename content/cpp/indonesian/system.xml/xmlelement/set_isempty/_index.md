## XmlElement::set_IsEmpty(bool) metode


Mengatur format tag elemen.

```cpp
void System::Xml::XmlElement::set_IsEmpty(bool value)
```


### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| value | **bool** | Nilai yang akan diatur. Saat mengatur nilai ini, jika diatur ke **true**, anak anak elemen dihapus dan elemen diserialisasi dalam format tag pendek. Jika diatur ke **false**, nilai diubah (tanpa memperhatikan apakah elemen memiliki konten atau tidak); jika elemen kosong, ia diserialisasi dalam format panjang. |
