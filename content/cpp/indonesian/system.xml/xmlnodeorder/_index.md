## enum XmlNodeOrder

Describes the document order of a node compared to a second node.

```cpp
enum class XmlNodeOrder
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Before | 0 | Node saat ini pada navigator ini berada sebelum node saat ini pada navigator yang diberikan. |
| After | 1 | Node saat ini pada navigator ini berada setelah node saat ini pada navigator yang diberikan. |
| Same | 2 | Kedua navigator berada pada node yang sama. |
| Unknown | 3 | Posisi node tidak dapat ditentukan dalam urutan dokumen, relatif satu sama lain. Hal ini dapat terjadi jika dua node berada di pohon yang berbeda. |
