## XmlNodeReader::ReadString() method

Membaca isi elemen atau node teks sebagai string.

```cpp
String System::Xml::XmlNodeReader::ReadString() override
```

### Nilai Kembali

Isi dari elemen atau node yang mirip teks (Ini dapat mencakup CDATA, [Text](../../../system.text/) node, dan seterusnya). Ini dapat menjadi string kosong jika pembaca berada pada sesuatu selain elemen atau node teks, atau jika tidak ada lagi konten teks yang dapat dikembalikan dalam konteks saat ini. Catatan: Node teks dapat berupa elemen atau node teks atribut.
