## XmlNodeReader::get_IsEmptyElement() metode

Mengembalikan nilai yang menunjukkan apakah node saat ini adalah elemen kosong (misalnya, **<MyElement/>**).

```cpp
bool System::Xml::XmlNodeReader::get_IsEmptyElement() override
```

### Nilai Kembalian

**true** jika node saat ini adalah elemen ([XmlNodeReader::get_NodeType](../get_nodetype/) sama dengan [XmlNodeType::Element](../../xmlnodetype/)) dan berakhir dengan **/>**; selain itu, **false**.
