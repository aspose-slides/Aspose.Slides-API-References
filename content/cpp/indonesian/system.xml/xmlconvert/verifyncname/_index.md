## XmlConvert::VerifyNCName(const String\&) metode

Memverifikasi bahwa nama tersebut adalah **NCName** yang valid menurut rekomendasi W3C Extended Markup Language. Sebuah **NCName** adalah nama yang tidak dapat mengandung titik dua.

```cpp
static String System::Xml::XmlConvert::VerifyNCName(const String &name)
```

### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| name | const [String](../../../system/string/)\& | Nama yang akan diverifikasi. |

### Nilai Kembalian

Nama tersebut, jika itu merupakan NCName yang valid.
