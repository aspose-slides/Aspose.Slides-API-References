## XmlOutputMethod enum


Menentukan metode yang digunakan untuk menyerialkan output [XmlWriter](../xmlwriter/).

```cpp
enum class XmlOutputMethod
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Xml | 0 | Menyerialkan sesuai dengan aturan XML 1.0. |
| Html | 1 | Menyerialkan sesuai dengan aturan HTML yang ditentukan oleh XSLT. |
| Text | 2 | Menyerialkan hanya blok teks. |
| AutoDetect | 3 | Gunakan aturan XSLT untuk memilih antara metode output [XmlOutputMethod::Xml](./) dan [XmlOutputMethod::Html](./) pada waktu berjalan. |
