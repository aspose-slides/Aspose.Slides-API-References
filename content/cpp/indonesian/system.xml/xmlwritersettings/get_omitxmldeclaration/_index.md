## XmlWriterSettings::get_OmitXmlDeclaration() metode

Mengembalikan nilai yang menunjukkan apakah deklarasi XML harus dihilangkan.

```cpp
bool System::Xml::XmlWriterSettings::get_OmitXmlDeclaration()
```

### Nilai Pengembalian

**true** untuk menghilangkan deklarasi XML; jika tidak, **false**. Nilai default adalah **false**, deklarasi XML ditulis.
