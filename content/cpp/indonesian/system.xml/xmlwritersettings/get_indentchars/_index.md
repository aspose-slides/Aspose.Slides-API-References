## XmlWriterSettings::get_IndentChars() metode


Mengembalikan string karakter yang digunakan saat mengindentasi. Pengaturan ini digunakan ketika nilai [XmlWriterSettings::set_Indent](../set_indent/) disetel ke **true**.

```cpp
String System::Xml::XmlWriterSettings::get_IndentChars()
```


### Nilai Kembali

String karakter yang digunakan saat mengindentasi. Ini dapat disetel ke nilai string apa pun. Namun, untuk memastikan XML yang valid, Anda harus menentukan hanya karakter spasi putih yang valid, seperti karakter spasi, tab, carriage return, atau line feed. Defaultnya adalah dua spasi.
