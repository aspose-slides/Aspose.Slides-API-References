## XmlWriterSettings::get_WriteEndDocumentOnClose() metode

Mengembalikan nilai yang menunjukkan apakah [XmlWriter](../../xmlwriter/) akan menambahkan tag penutup ke semua tag elemen yang belum ditutup ketika [XmlWriter::Close](../../xmlwriter/close/) metode dipanggil.

```cpp
bool System::Xml::XmlWriterSettings::get_WriteEndDocumentOnClose()
```

### Nilai Kembalian

**true** jika semua tag elemen yang belum ditutup akan ditutup; jika tidak, **false**. Nilai default adalah **true**.
