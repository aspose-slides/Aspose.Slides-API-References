## XmlWriterSettings::get_CheckCharacters() metode

Mengembalikan nilai yang menunjukkan apakah penulis XML harus memeriksa untuk memastikan semua karakter dalam dokumen sesuai dengan bagian \"2.2 Characters\" dari W3C [XML 1.0 Recommendation](https://www.w3.org/TR/REC-xml/#charsets).

```cpp
bool System::Xml::XmlWriterSettings::get_CheckCharacters()
```

### Nilai Kembali

**true** untuk melakukan pemeriksaan karakter; lainnya, **false**. Defaultnya adalah **true**.
