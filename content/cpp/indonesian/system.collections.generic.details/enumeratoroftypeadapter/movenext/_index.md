## EnumeratorOfTypeAdapter::MoveNext() metode


Memindahkan enumerator ke elemen berikutnya. Jika tidak ada elemen yang direferensikan sebelumnya, menetapkan referensi ke elemen pertama yang tersedia. Jika akhir wadah tercapai, tidak melakukan apa-pun.

```cpp
bool System::Collections::Generic::Details::EnumeratorOfTypeAdapter<Source, Result>::MoveNext() override
```


### Nilai Kembali

True jika ada elemen yang tersedia setelah pemanggilan, false jika tidak.
