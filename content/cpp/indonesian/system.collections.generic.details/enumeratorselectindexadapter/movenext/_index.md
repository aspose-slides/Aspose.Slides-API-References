## EnumeratorSelectIndexAdapter::MoveNext() metode

Memindahkan enumerator ke elemen berikutnya. Jika tidak ada elemen yang direferensikan sebelumnya, menetapkan referensi ke elemen pertama yang tersedia. Jika akhir kontainer tercapai, tidak melakukan apa-apa.

```cpp
bool System::Collections::Generic::Details::EnumeratorSelectIndexAdapter<Source, Result>::MoveNext() override
```

### Nilai Kembalian

True jika ada elemen yang tersedia setelah pemanggilan, false jika tidak.
