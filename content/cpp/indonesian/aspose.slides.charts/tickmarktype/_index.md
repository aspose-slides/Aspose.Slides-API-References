## TickMarkType enum

Mewakili tipe penanda tick untuk sumbu yang ditentukan.

```cpp
enum class TickMarkType
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Cross | 0 | Menentukan bahwa penanda tick akan melintasi sumbu. |
| Inside | 1 | Menentukan bahwa penanda tick akan berada di dalam area plot. |
| None | 2 | Menentukan tidak ada penanda tick. |
| Outside | 3 | Menentukan bahwa penanda tick akan berada di luar area plot. |
