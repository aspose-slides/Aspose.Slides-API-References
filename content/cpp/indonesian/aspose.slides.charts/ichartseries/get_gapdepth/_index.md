## IChartSeries::get_GapDepth() metode

Mengembalikan jarak, sebagai persentase lebar penanda, antara rangkaian data dalam diagram 3D. Properti ini bukan hanya milik seri ini tetapi juga semua seri dalam grup seri induk - ini merupakan proyeksi properti grup yang sesuai. Dan demikian properti ini bersifat hanya-baca. Gunakan properti ParentSeriesGroup untuk mengakses grup seri induk. Gunakan [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_GapDepth() properti baca/tulis untuk mengubah nilai. Hanya-baca **int32_t**.

```cpp
virtual int32_t Aspose::Slides::Charts::IChartSeries::get_GapDepth()=0
```

## Catatan

Ini adalah proyeksi properti [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_GapDepth().
