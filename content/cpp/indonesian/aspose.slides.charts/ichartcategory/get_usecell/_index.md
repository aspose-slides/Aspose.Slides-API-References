## IChartCategory::get_UseCell() method


Jika true maka properti AsCell aktual. Dengan kata lain, worksheet digunakan untuk menyimpan kategori (kasus ini mendukung kategori multi-level). Jika false maka properti AsLiteral aktual. Dengan kata lain, worksheet TIDAK digunakan untuk menyimpan kategori (dan kasus ini tidak mendukung kategori multi-level). Baca-saja **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IChartCategory::get_UseCell()=0
```

## Keterangan


Untuk mengubah nilai properti ini (untuk semua kategori dalam koleksi) setel nilai baru ke properti ChartCategoryCollection.UseCells.
