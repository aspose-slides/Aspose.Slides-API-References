## LayoutTargetType enum

Jika tata letak area plot ditentukan secara manual, properti ini menentukan apakah tata letak area plot menggunakan bagian dalamnya (tidak termasuk sumbu dan label sumbu) atau bagian luar (termasuk sumbu dan label sumbu).

```cpp
enum class LayoutTargetType
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Inner | 0 | Menentukan bahwa ukuran area plot akan menentukan ukuran area plot, tidak termasuk tanda skala dan label sumbu. |
| Outer | 1 | Menentukan bahwa ukuran area plot akan menentukan ukuran area plot, tanda skala, dan label sumbu. |
