## ParentLabelLayoutType enum

Mewakili tata letak label data kategori. Hanya digunakan dengan seri Treemap.

```cpp
enum class ParentLabelLayoutType
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Banner | 0 | Menentukan bahwa label kategori induk ditampilkan sebagai banner |
| None | 1 | Menentukan bahwa label kategori induk tidak digambar |
| Overlapping | 2 | Menentukan bahwa label kategori induk ditampilkan secara tumpang tindih |
