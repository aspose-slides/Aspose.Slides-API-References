## DataLabelFormat::get_Separator() metode


Mengatur atau mengembalikan Variant yang mewakili pemisah yang digunakan untuk label data pada bagan. Baca [System::String](../../../system/string/).

```cpp
System::String Aspose::Slides::Charts::DataLabelFormat::get_Separator() override
```

## Catatan


Jika induk dari objek [DataLabelFormat](../) ini adalah kumpulan [DataLabelCollection](../../datalabelcollection/) label data, maka properti ini mengambil atau mengatur nilai default properti Separator untuk label data baru dalam kumpulan [DataLabelCollection](../../datalabelcollection/). Mengatur properti ini dengan nilai juga menetapkan nilai ini ke properti Separator untuk semua label data dalam kumpulan [DataLabelCollection](../../datalabelcollection/) (misalnya "DataLabels.DefaultDataLabelFormat.Separator = val;" menyebabkan semua DataLabels[i].Separator sama dengan val).
