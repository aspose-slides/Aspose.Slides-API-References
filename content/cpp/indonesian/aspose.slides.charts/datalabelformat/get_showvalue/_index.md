## DataLabelFormat::get_ShowValue() metode

Mewakili perilaku tampilan nilai persentase label data pada diagram tertentu. True menampilkan nilai persentase. False untuk menyembunyikan. Baca **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowValue() override
```

## Catatan

Jika induk dari objek [DataLabelFormat](../) ini adalah koleksi [DataLabelCollection](../../datalabelcollection/) label data maka properti ini mendapatkan atau mengatur nilai default properti ShowValue untuk label data baru di koleksi [DataLabelCollection](../../datalabelcollection/). Mengatur properti ini dengan nilai juga mengatur nilai ini ke properti ShowValue untuk semua label data di koleksi [DataLabelCollection](../../datalabelcollection/) (misalnya "DataLabels.DefaultDataLabelFormat.ShowValue = val;" menyebabkan semua DataLabels[i].ShowValue menjadi sama dengan val).
