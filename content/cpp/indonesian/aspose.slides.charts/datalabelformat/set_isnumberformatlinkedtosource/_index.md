## DataLabelFormat::set_IsNumberFormatLinkedToSource(bool) metode

Tulis **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_IsNumberFormatLinkedToSource(bool value) override
```

## Keterangan

Jika induk dari objek [DataLabelFormat](../) ini adalah kumpulan [DataLabelCollection](../../datalabelcollection/) label data, maka properti ini mendapatkan atau mengatur nilai default properti IsNumberFormatLinkedToSource untuk label data baru dalam kumpulan [DataLabelCollection](../../datalabelcollection/). Menetapkan properti ini dengan nilai juga mengatur nilai ini ke properti IsNumberFormatLinkedToSource untuk semua label data dalam kumpulan [DataLabelCollection](../../datalabelcollection/) (misalnya "DataLabels.DefaultDataLabelFormat.IsNumberFormatLinkedToSource = val;" menyebabkan semua DataLabels[i].IsNumberFormatLinkedToSource menjadi sama dengan val).
