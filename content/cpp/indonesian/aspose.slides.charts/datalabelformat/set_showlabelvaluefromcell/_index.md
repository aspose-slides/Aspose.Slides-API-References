## DataLabelFormat::set_ShowLabelValueFromCell(bool) metode

Mewakili perilaku tampilan nilai sel label data pada diagram yang ditentukan. True menampilkan nilai sel. False menyembunyikannya. Tulis **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLabelValueFromCell(bool value) override
```

## Catatan

Jika induk dari objek [DataLabelFormat](../) ini adalah kumpulan [DataLabelCollection](../../datalabelcollection/) label data, maka properti ini mendapatkan atau mengatur nilai default properti ShowLabelValueFromCell untuk label data baru dalam kumpulan [DataLabelCollection](../../datalabelcollection/). Menetapkan properti ini dengan nilai juga menetapkan nilai ini ke properti ShowLabelValueFromCell untuk semua label data dalam kumpulan [DataLabelCollection](../../datalabelcollection/) (misalnya \"DataLabels.DefaultDataLabelFormat.ShowLabelValueFromCell = val;\" menyebabkan semua DataLabels[i].ShowLabelValueFromCell menjadi sama dengan val).
