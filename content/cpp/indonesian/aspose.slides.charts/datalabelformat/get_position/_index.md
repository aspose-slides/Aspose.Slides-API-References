## DataLabelFormat::get_Position() metode


Mewakili posisi label data. Baca [LegendDataLabelPosition](../../legenddatalabelposition/).

```cpp
LegendDataLabelPosition Aspose::Slides::Charts::DataLabelFormat::get_Position() override
```

## Catatan


Jika induk dari objek [DataLabelFormat](../) ini merupakan kumpulan [DataLabelCollection](../../datalabelcollection/) label data maka properti ini memperoleh atau menetapkan nilai default properti Position untuk label data baru dalam kumpulan [DataLabelCollection](../../datalabelcollection/). Mewakili posisi untuk objek [DataLabel](../../datalabel/). Menetapkan properti ini dengan nilai juga menetapkan nilai ini ke properti Position untuk semua label data dalam kumpulan [DataLabelCollection](../../datalabelcollection/) (misalnya \"DataLabels.DefaultDataLabelFormat.Position = val;\" menyebabkan semua DataLabels[i].Position menjadi sama dengan val).
