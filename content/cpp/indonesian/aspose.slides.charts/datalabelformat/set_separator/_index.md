## DataLabelFormat::set_Separator(System::String) metode

Mengatur atau mengembalikan Variant yang mewakili pemisah yang digunakan untuk label data pada diagram. Tulis [System::String](../../../system/string/).

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_Separator(System::String value) override
```

## Keterangan

Jika induk dari objek [DataLabelFormat](../) ini adalah koleksi [DataLabelCollection](../../datalabelcollection/) label data, maka properti ini mendapatkan atau mengatur nilai default dari properti Separator untuk label data baru dalam koleksi [DataLabelCollection](../../datalabelcollection/). Mengatur properti ini dengan nilai juga menetapkan nilai ini ke properti Separator untuk semua label data dalam koleksi [DataLabelCollection](../../datalabelcollection/) (misalnya "DataLabels.DefaultDataLabelFormat.Separator = val;" menyebabkan semua DataLabels[i].Separator sama dengan val).
