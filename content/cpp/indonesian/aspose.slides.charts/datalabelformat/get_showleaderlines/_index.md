## DataLabelFormat::get_ShowLeaderLines() metode


Mewakili perilaku tampilan garis pemimpin label data pada bagan tertentu. True menampilkan garis pemimpin. False untuk menyembunyikan. Baca **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowLeaderLines() override
```

## Catatan


Jika induk dari objek [DataLabelFormat](../) ini adalah koleksi [DataLabelCollection](../../datalabelcollection/) label data maka properti ini mendapatkan atau mengatur nilai default dari properti ShowLeaderLines untuk label data baru dalam koleksi [DataLabelCollection](../../datalabelcollection/). Mengatur properti ini dengan nilai juga mengatur nilai ini ke properti ShowLeaderLines untuk semua label data dalam koleksi [DataLabelCollection](../../datalabelcollection/) (mis. \"DataLabels.DefaultDataLabelFormat.ShowLeaderLines = val;\" menyebabkan semua DataLabels[i].ShowLeaderLines sama dengan val).
