## DataLabelFormat::set_ShowLegendKey(bool) metode


Mewakili perilaku tampilan kunci legenda label data pada bagan tertentu. True jika kunci legenda label data terlihat. Tulis **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLegendKey(bool value) override
```

## Catatan


Jika induk dari objek [DataLabelFormat](../) ini adalah kumpulan [DataLabelCollection](../../datalabelcollection/) label data maka properti ini mendapatkan atau mengatur nilai default properti ShowLegendKey untuk label data baru dalam kumpulan [DataLabelCollection](../../datalabelcollection/). Menyetel properti ini dengan nilai juga mengatur nilai ini ke properti ShowLegendKey untuk semua label data dalam kumpulan [DataLabelCollection](../../datalabelcollection/) (yaitu \"DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;\" menyebabkan semua DataLabels[i].ShowLegendKey sama dengan val).
