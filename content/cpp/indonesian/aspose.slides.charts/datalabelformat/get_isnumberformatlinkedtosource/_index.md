## DataLabelFormat::get_IsNumberFormatLinkedToSource() metode


Baca **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_IsNumberFormatLinkedToSource() override
```

## Catatan


Jika induk dari objek [DataLabelFormat](../) ini adalah koleksi [DataLabelCollection](../../datalabelcollection/) label data maka properti ini mendapatkan atau mengatur nilai default dari properti IsNumberFormatLinkedToSource untuk label data baru dalam koleksi [DataLabelCollection](../../datalabelcollection/). Mengatur properti ini dengan nilai juga mengatur nilai ini ke properti IsNumberFormatLinkedToSource untuk semua label data dalam koleksi [DataLabelCollection](../../datalabelcollection/) (misalnya \"DataLabels.DefaultDataLabelFormat.IsNumberFormatLinkedToSource = val;\" menyebabkan semua DataLabels[i].IsNumberFormatLinkedToSource menjadi sama dengan val).
