## DataLabelFormat::get_ShowPercentage() metode


Mewakili perilaku penampilan nilai persentase label data pada diagram yang ditentukan. True menampilkan nilai persentase. False untuk menyembunyikannya. Baca **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowPercentage() override
```

## Catatan


Jika induk dari objek [DataLabelFormat](../) ini adalah koleksi [DataLabelCollection](../../datalabelcollection/) label data, maka properti ini mendapatkan atau mengatur nilai default properti ShowPercentage untuk label data baru dalam koleksi [DataLabelCollection](../../datalabelcollection/). Menetapkan properti ini dengan nilai juga mengatur nilai ini ke properti ShowPercentage untuk semua label data dalam koleksi [DataLabelCollection](../../datalabelcollection/) (misalnya "DataLabels.DefaultDataLabelFormat.ShowPercentage = val;" menyebabkan semua DataLabels[i].ShowPercentage sama dengan val).
