## DataLabelFormat::set_Position(LegendDataLabelPosition) metode

Mewakili posisi label data. Tulis [LegendDataLabelPosition](../../legenddatalabelposition/).

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_Position(LegendDataLabelPosition value) override
```

## Catatan

Jika induk dari objek [DataLabelFormat](../) ini adalah koleksi [DataLabelCollection](../../datalabelcollection/) dari label data maka properti ini mendapatkan atau mengatur nilai default dari properti Position untuk label data baru dalam koleksi [DataLabelCollection](../../datalabelcollection/). Mewakili posisi untuk objek [DataLabel](../../datalabel/). Mengatur properti ini dengan nilai juga mengatur nilai ini ke properti Position untuk semua label data dalam koleksi [DataLabelCollection](../../datalabelcollection/) (misalnya "DataLabels.DefaultDataLabelFormat.Position = val;" menyebabkan semua DataLabels[i].Position menjadi sama dengan val).
