## DataLabelFormat::set_ShowBubbleSize(bool) metode

Mewakili perilaku tampilan nilai ukuran gelembung label data pada diagram yang ditentukan. True menampilkan nilai ukuran gelembung. False untuk menyembunyikannya. Tulis **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowBubbleSize(bool value) override
```

## Catatan

Jika induk dari objek [DataLabelFormat](../) ini adalah koleksi [DataLabelCollection](../../datalabelcollection/) label data, maka properti ini mendapatkan atau mengatur nilai default properti ShowBubbleSize untuk label data baru dalam koleksi [DataLabelCollection](../../datalabelcollection/). Menetapkan properti ini dengan nilai juga mengatur nilai ini ke properti ShowBubbleSize untuk semua label data dalam koleksi [DataLabelCollection](../../datalabelcollection/) (misalnya "DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;" menyebabkan semua DataLabels[i].ShowBubbleSize menjadi sama dengan val).
