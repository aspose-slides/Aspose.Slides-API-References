## DataLabelFormat::get_ShowLabelValueFromCell() metode


Mewakili perilaku tampilan nilai sel label data pada diagram yang ditentukan. True menampilkan nilai sel. False untuk menyembunyikan. Baca **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowLabelValueFromCell() override
```

## Keterangan


Jika induk dari objek [DataLabelFormat](../) ini adalah koleksi [DataLabelCollection](../../datalabelcollection/) label data maka properti ini mendapatkan atau menetapkan nilai default properti ShowLabelValueFromCell untuk label data baru dalam koleksi [DataLabelCollection](../../datalabelcollection/). Menetapkan properti ini dengan nilai juga menetapkan nilai ini ke properti ShowLabelValueFromCell untuk semua label data dalam koleksi [DataLabelCollection](../../datalabelcollection/) (misalnya "DataLabels.DefaultDataLabelFormat.ShowLabelValueFromCell = val;" menyebabkan semua DataLabels[i].ShowLabelValueFromCell menjadi val).
