## ChartTypeCharacterizer::IsChartTypeRadar(ChartType) metode

Mengembalikan true jika chartType adalah salah satu subtipe Radar. Set subtipe sesuai dengan set yang tepat di PowerPoint (lihat \"Change Chart Type\" dialog di PowerPoint): [ChartType::FilledRadar](../../charttype/), [ChartType::Radar](../../charttype/), [ChartType::RadarWithMarkers](../../charttype/).
