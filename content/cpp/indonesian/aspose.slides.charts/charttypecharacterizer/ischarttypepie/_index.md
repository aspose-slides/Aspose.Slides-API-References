## ChartTypeCharacterizer::IsChartTypePie(ChartType) metode

Mengembalikan true jika chartType adalah salah satu subtipe Pie. Set subtipe sesuai dengan set yang tepat di PowerPoint (lihat dialog \"Change Chart Type\" di PowerPoint): [ChartType::BarOfPie](../../charttype/), [ChartType::ExplodedPie](../../charttype/), [ChartType::ExplodedPie3D](../../charttype/), [ChartType::Pie](../../charttype/), [ChartType::Pie3D](../../charttype/), [ChartType::PieOfPie](../../charttype/).
