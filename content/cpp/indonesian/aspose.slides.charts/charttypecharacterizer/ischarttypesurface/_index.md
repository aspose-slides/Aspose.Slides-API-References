## ChartTypeCharacterizer::IsChartTypeSurface(ChartType) method

Kembalikan true jika chartType termasuk salah satu subtipe Surface. Set subtipe sesuai dengan set yang tepat di PowerPoint (lihat dialog "Change Chart Type" di PowerPoint): [ChartType::Surface3D](../../charttype/), [ChartType::WireframeSurface3D](../../charttype/), [ChartType::Contour](../../charttype/), [ChartType::WireframeContour](../../charttype/).
