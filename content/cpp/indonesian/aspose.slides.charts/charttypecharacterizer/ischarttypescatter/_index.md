## ChartTypeCharacterizer::IsChartTypeScatter(ChartType) metode

Kembalikan true jika chartType adalah salah satu subtipe Scatter. Set subtipe sesuai dengan set yang tepat di PowerPoint (lihat dialog "Change Chart Type" di PowerPoint): [ChartType::ScatterWithMarkers](../../charttype/), [ChartType::ScatterWithSmoothLines](../../charttype/), [ChartType::ScatterWithSmoothLinesAndMarkers](../../charttype/), [ChartType::ScatterWithStraightLines](../../charttype/), [ChartType::ScatterWithStraightLinesAndMarkers](../../charttype/).
