## PieSplitType enum

Mewakili jenis titik pembagian pada pie atau bar kedua pada diagram pie-of-pie atau bar-of-pie.

```cpp
enum class PieSplitType
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Default | 0 | Menentukan bahwa titik data akan dibagi menggunakan mekanisme default untuk tipe diagram ini. |
| Custom | 1 | Menentukan bahwa titik data akan dibagi antara pie dan diagram kedua sesuai dengan nilai Custom Split. |
| ByPercentage | 2 | Menentukan bahwa titik data akan dibagi antara pie dan diagram kedua dengan menempatkan titik dengan persentase kurang dari Split Position persen pada diagram kedua. |
| ByPos | 3 | Menentukan bahwa titik data akan dibagi antara pie dan diagram kedua dengan menempatkan Split Position terakhir dari titik data pada diagram kedua. |
| ByValue | 4 | Menentukan bahwa titik data akan dibagi antara pie dan diagram kedua dengan menempatkan titik data dengan nilai kurang dari Split Position pada diagram kedua. |
