## IChartData::SetRange(System::String) metode


Atur rentang data diagram. Serial dan kategori akan diperbarui berdasarkan rentang data baru. Jika jumlah serial dalam rentang data lebih besar daripada jumlah serial dalam data diagram maka serial tambahan dengan tipe yang sama dengan serial terakhir dalam koleksi saat ini akan ditambahkan ke akhir koleksi.

```cpp
virtual void Aspose::Slides::Charts::IChartData::SetRange(System::String formula)=0
```


### Argumen

| Parameter | Type | Description |
| --- | --- | --- |
| formula | [System::String](../../../system/string/) | Formula rentang data sel. Misalnya: \"Sheet1!$A$1:$C$4\" , \"SomeSheetName!A1:B100\", \"Sheet1!$A$1:$B$5;Sheet1!$D$1:$D$5\". |
