## BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType) metode

Menentukan apakah properti AsCell, AsCells, AsLiteralString, atau AsLiteralDouble berlaku pada turunan. Dengan kata lain, ini menentukan jenis nilai dari properti Data. Tulis [Charts::DataSourceType](../../datasourcetype/).

```cpp
void Aspose::Slides::Charts::BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType value) override
```

## Catatan

Untuk poin di [ChartDataPointCollection](../../chartdatapointcollection/) properti ini hanya-baca. Dalam hal ini, untuk mengubah nilai properti ini Anda dapat menggunakan salah satu properti ChartDataPointCollection.DataSourceTypeFor<...>.
