## IRotation3D::get_RotationY() metode


Mengembalikan derajat rotasi di sekitar sumbu Y, yaitu arah X untuk diagram 3D (antara 0 dan 360 derajat). Properti ini sesuai dengan item 21.2.2.158 rotY (Y Rotation) di ECMA-376 dan dengan opsi \"X Rotation\" di PowerPoint 2007+. Baca **uint16_t**.

```cpp
virtual uint16_t Aspose::Slides::Charts::IRotation3D::get_RotationY()=0
```
