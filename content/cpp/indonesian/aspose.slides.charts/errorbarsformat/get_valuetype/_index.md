## ErrorBarsFormat::get_ValueType() metode


Menampilkan cara-cara yang mungkin untuk menentukan panjang batang galat. Jika tipe nilai khusus, untuk menentukan nilai gunakan properti [IChartDataPoint::get_ErrorBarsCustomValues()](../../ichartdatapoint/get_errorbarscustomvalues/) dari titik data tertentu dalam koleksi DataPoints pada seri. Jika tipe nilai Fixed, Percentage atau StandardDeviation, gunakan properti Value untuk menentukan nilai.
