## ErrorBarsFormat::set_ValueType(ErrorBarValueType) metode

Mewakili cara-cara yang mungkin untuk menentukan panjang bar error. Jika tipe nilai khusus, gunakan properti [IChartDataPoint::get_ErrorBarsCustomValues()](../../ichartdatapoint/get_errorbarscustomvalues/) untuk menentukan nilai pada titik data tertentu dalam koleksi DataPoints pada seri. Jika tipe nilai Fixed, Percentage atau StandardDeviation, gunakan properti Value untuk menentukan nilai.

Tuliskan [ErrorBarValueType](../../errorbarvaluetype/).
