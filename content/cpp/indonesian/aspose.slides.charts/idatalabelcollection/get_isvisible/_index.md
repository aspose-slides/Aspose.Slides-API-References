## IDataLabelCollection::get_IsVisible() metode

False berarti label data tidak terlihat secara default (dan sehingga semua flag Show*- (ShowValue, ...) dari properti DefaultDataLabelFormat bernilai false). Baca-saja **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelCollection::get_IsVisible()=0
```

## Catatan

Jika label data terlihat secara default, Anda dapat menyembunyikannya secara default dengan metode [Hide()](../hide/). Tetapi jika label data tidak terlihat secara default (IsVisible false) Anda dapat membuat label data \"visible 
by default\" dengan mengatur flag Show*- (ShowValue, ...) dari properti DefaultDataLabelFormat ke keadaan true.
