## IDataLabelCollection::Hide() metode


Membuat label data tersembunyi secara default dengan mengatur semua Show*-flags (ShowValue, ...) dari properti DefaultDataLabelFormat ke keadaan false. IsVisible akan menjadi false setelah ini.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelCollection::Hide()=0
```

## Catatan


Jika label data tidak terlihat secara default (IsVisible adalah false) Anda dapat membuat label data "visible by default" dengan mengatur Show*-flags (ShowValue, ...) dari properti DefaultDataLabelFormat ke keadaan true.
