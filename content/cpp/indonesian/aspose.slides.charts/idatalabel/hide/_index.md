## IDataLabel::Hide() metode

Membuat label data tersembunyi dengan mengatur semua Show*-flags (ShowValue, ...) ke status false. IsVisible akan menjadi false setelah ini.

```cpp
virtual void Aspose::Slides::Charts::IDataLabel::Hide()=0
```

## Catatan

Jika label data tidak terlihat (IsVisible false) Anda dapat membuat label data terlihat dengan mengatur Show*-flags (ShowValue, ...) ke status true.
