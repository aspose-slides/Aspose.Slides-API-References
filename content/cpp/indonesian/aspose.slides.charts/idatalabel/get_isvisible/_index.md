## IDataLabel::get_IsVisible() metode

False berarti bahwa label data tidak terlihat (dan sehingga semua Show*-flags (ShowValue, ...) adalah false). Hanya-baca **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabel::get_IsVisible()=0
```

## Catatan

Jika label data terlihat, Anda dapat menyembunyikannya dengan [Hide()](../hide/) metode. Namun jika label data tidak terlihat (IsVisible adalah false) Anda dapat membuat label data terlihat dengan mengatur Show*-flags (ShowValue, ...) ke keadaan true.
