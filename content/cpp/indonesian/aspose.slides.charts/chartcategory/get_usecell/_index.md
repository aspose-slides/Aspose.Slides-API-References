## ChartCategory::get_UseCell() method

Jika true maka properti AsCell aktif. Dengan kata lain, worksheet digunakan untuk menyimpan kategori (kasus ini mendukung kategori berlapis). Jika false maka properti AsLiteral aktif. Dengan kata lain, worksheet TIDAK digunakan untuk menyimpan kategori (dan kasus ini tidak mendukung kategori berlapis). Hanya baca **bool**.

```cpp
bool Aspose::Slides::Charts::ChartCategory::get_UseCell() override
```

## Catatan

Untuk mengubah nilai properti ini (untuk semua kategori dalam koleksi) setel nilai baru ke ChartCategoryCollection::get(set)_UseCells properti.
