## TickLabelPositionType enum

Mewakili tipe posisi label tanda pada sumbu yang ditentukan.

```cpp
enum class TickLabelPositionType
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| High | 0 | Menentukan label sumbu berada di ujung atas sumbu tegak lurus. |
| Low | 1 | Menentukan label sumbu berada di ujung bawah sumbu tegak lurus. |
| NextTo | 2 | Menentukan label sumbu berada di samping sumbu. |
| None | 3 | Menentukan label sumbu tidak digambar. |
