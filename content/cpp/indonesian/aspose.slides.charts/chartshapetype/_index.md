## ChartShapeType enum


Mewakili bentuk bagan.

```cpp
enum class ChartShapeType
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| NotDefined | -1 | [Chart](../chart/) shape tidak didefinisikan. |
| Box | 0 | Menentukan bahwa chart akan digambar dengan bentuk kotak. |
| Cone | 1 | Menentukan bahwa chart akan digambar sebagai kerucut, dengan dasar kerucut berada di lantai dan titik kerucut di atas penanda data. |
| ConeToMax | 2 | Menentukan bahwa chart akan digambar dengan kerucut terpotong sehingga titik kerucut akan menjadi nilai data maksimum. |
| Cylinder | 3 | Menentukan bahwa chart akan digambar sebagai silinder. |
| Pyramid | 4 | Menentukan bahwa chart akan digambar sebagai piramida persegi panjang, dengan dasar piramida berada di lantai dan titik piramida di atas penanda data. |
| PyramidToMaximum | 5 | Menentukan bahwa chart akan digambar dengan kerucut terpotong sehingga titik kerucut akan menjadi nilai data maksimum. |
