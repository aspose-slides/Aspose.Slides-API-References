## IDataLabelFormat::get_Separator() metode

Mengatur atau mengembalikan Variant yang mewakili pemisah yang digunakan untuk label data pada diagram. Baca [System::String](../../../system/string/).

```cpp
virtual System::String Aspose::Slides::Charts::IDataLabelFormat::get_Separator()=0
```

## Keterangan

Jika induk dari objek [DataLabelFormat](../../datalabelformat/) ini adalah koleksi [DataLabelCollection](../../datalabelcollection/) dari label data maka properti ini mendapatkan atau mengatur nilai default dari properti Separator untuk label data baru dalam koleksi [DataLabelCollection](../../datalabelcollection/). Mengatur properti ini dengan nilai juga mengatur nilai tersebut ke properti Separator untuk semua label data dalam koleksi [DataLabelCollection](../../datalabelcollection/) (misalnya "DataLabels.DefaultDataLabelFormat.Separator = val;" menyebabkan semua DataLabels[i].Separator menjadi sama dengan val).
