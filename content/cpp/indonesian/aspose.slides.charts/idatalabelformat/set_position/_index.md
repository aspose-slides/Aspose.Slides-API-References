## IDataLabelFormat::set_Position(LegendDataLabelPosition) metode

Mewakili posisi label data. Tulis [LegendDataLabelPosition](../../legenddatalabelposition/).

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_Position(LegendDataLabelPosition value)=0
```

## Keterangan

Jika induk dari objek [DataLabelFormat](../../datalabelformat/) ini adalah kumpulan [DataLabelCollection](../../datalabelcollection/) label data maka properti ini mendapatkan atau mengatur nilai default dari properti Position untuk label data baru dalam kumpulan [DataLabelCollection](../../datalabelcollection/). Mewakili posisi untuk objek [DataLabel](../../datalabel/). Mengatur properti ini dengan nilai juga mengatur nilai ini ke properti Position untuk semua label data dalam kumpulan [DataLabelCollection](../../datalabelcollection/) (misalnya "DataLabels.DefaultDataLabelFormat.Position = val;" menyebabkan semua DataLabels[i].Position menjadi sama dengan val).
