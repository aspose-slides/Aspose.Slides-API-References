## IDataLabelFormat::get_ShowLabelValueFromCell() metode


Mewakili perilaku penampilan nilai sel label data pada diagram yang ditentukan. True menampilkan nilai sel. False menyembunyikannya. Baca **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowLabelValueFromCell()=0
```

## Catatan


Jika induk dari objek [DataLabelFormat](../../datalabelformat/) ini adalah koleksi [DataLabelCollection](../../datalabelcollection/) label data maka properti ini mendapatkan atau menetapkan nilai default dari properti ShowLabelValueFromCell untuk label data baru dalam koleksi [DataLabelCollection](../../datalabelcollection/). Menetapkan properti ini dengan nilai juga menetapkan nilai ini ke properti ShowLabelValueFromCell untuk semua label data dalam koleksi [DataLabelCollection](../../datalabelcollection/) (misalnya \"DataLabels.DefaultDataLabelFormat.ShowLabelValueFromCell = val;\" menyebabkan semua DataLabels[i].ShowLabelValueFromCell menjadi val).
