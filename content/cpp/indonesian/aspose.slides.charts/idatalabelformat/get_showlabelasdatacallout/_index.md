## IDataLabelFormat::get_ShowLabelAsDataCallout() metode

Menentukan apakah label data grafik yang ditentukan akan ditampilkan sebagai data callout atau sebagai label data.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowLabelAsDataCallout()=0
```

## Catatan

Jika induk dari objek [DataLabelFormat](../../datalabelformat/) ini adalah koleksi [DataLabelCollection](../../datalabelcollection/) dari label data maka properti ini mengambil atau menetapkan nilai default dari properti ShowLabelAsDataCallout untuk label data baru dalam koleksi [DataLabelCollection](../../datalabelcollection/). Mengatur properti ini dengan nilai juga menetapkan nilai ini ke properti ShowLabelAsDataCallout untuk semua label data dalam koleksi [DataLabelCollection](../../datalabelcollection/) (misalnya "DataLabels.DefaultDataLabelFormat.ShowLabelAsDataCallout = val;" menyebabkan semua DataLabels[i].ShowLabelAsDataCallout menjadi sama dengan val).
