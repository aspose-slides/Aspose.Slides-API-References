## IDataLabelFormat::set_ShowLabelValueFromCell(bool) metode

Mewakili perilaku tampilan nilai sel label data pada diagram yang ditentukan. True menampilkan nilai sel. False menyembunyikannya. Tulis **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowLabelValueFromCell(bool value)=0
```

## Catatan

Jika induk dari objek [DataLabelFormat](../../datalabelformat/) ini adalah koleksi [DataLabelCollection](../../datalabelcollection/) label data maka properti ini mendapatkan atau mengatur nilai default properti ShowLabelValueFromCell untuk label data baru dalam koleksi [DataLabelCollection](../../datalabelcollection/). Mengatur properti ini dengan nilai juga menetapkan nilai ini ke properti ShowLabelValueFromCell untuk semua label data dalam koleksi [DataLabelCollection](../../datalabelcollection/) (misalnya "DataLabels.DefaultDataLabelFormat.ShowLabelValueFromCell = val;" menyebabkan semua DataLabels[i].ShowLabelValueFromCell menjadi sama dengan val).
