## IDataLabelFormat::set_Separator(System::String) metode


Mengatur atau mengembalikan Variant yang mewakili pemisah yang digunakan untuk label data pada diagram. Tulis [System::String](../../../system/string/).

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_Separator(System::String value)=0
```

## Keterangan


Jika induk dari objek [DataLabelFormat](../../datalabelformat/) ini adalah kumpulan [DataLabelCollection](../../datalabelcollection/) label data, maka properti ini mendapatkan atau mengatur nilai default dari properti Separator untuk label data baru dalam kumpulan [DataLabelCollection](../../datalabelcollection/). Mengatur properti ini dengan nilai juga mengatur nilai ini ke properti Separator untuk semua label data dalam kumpulan [DataLabelCollection](../../datalabelcollection/) (i.e. \"DataLabels.DefaultDataLabelFormat.Separator = val;\" menyebabkan semua DataLabels[i].Separator menjadi sama dengan val).
