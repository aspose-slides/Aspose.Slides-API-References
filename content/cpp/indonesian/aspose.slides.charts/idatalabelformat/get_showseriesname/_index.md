## IDataLabelFormat::get_ShowSeriesName() metode

Mengembalikan Boolean untuk menunjukkan perilaku tampilan nama seri pada label data di sebuah diagram. True untuk menampilkan nama seri. False untuk menyembunyikan. Baca **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowSeriesName()=0
```

## Catatan

Jika orang tua dari objek [DataLabelFormat](../../datalabelformat/) ini adalah koleksi [DataLabelCollection](../../datalabelcollection/) label data maka properti ini mengambil atau mengatur nilai bawaan properti ShowSeriesName untuk label data baru dalam koleksi [DataLabelCollection](../../datalabelcollection/). Mengatur properti ini dengan nilai juga mengatur nilai ini ke properti ShowSeriesName untuk semua label data dalam koleksi [DataLabelCollection](../../datalabelcollection/) (mis. "DataLabels.DefaultDataLabelFormat.ShowSeriesName = val;" menyebabkan semua DataLabels[i].ShowSeriesName menjadi val).
