## IDataLabelFormat::get_ShowLeaderLines() metode

Mewakili perilaku tampilan garis pemimpin label data pada diagram yang ditentukan. True menampilkan garis pemimpin. False untuk menyembunyikan. Baca **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowLeaderLines()=0
```

## Keterangan

Jika induk dari objek [DataLabelFormat](../../datalabelformat/) ini adalah koleksi [DataLabelCollection](../../datalabelcollection/) label data maka properti ini mendapatkan atau mengatur nilai default properti ShowLeaderLines untuk label data baru dalam koleksi [DataLabelCollection](../../datalabelcollection/). Menetapkan properti ini dengan nilai juga mengatur nilai ini ke properti ShowLeaderLines untuk semua label data dalam koleksi [DataLabelCollection](../../datalabelcollection/) (misalnya \"DataLabels.DefaultDataLabelFormat.ShowLeaderLines = val;\" menyebabkan semua DataLabels[i].ShowLeaderLines menjadi sama dengan val).
