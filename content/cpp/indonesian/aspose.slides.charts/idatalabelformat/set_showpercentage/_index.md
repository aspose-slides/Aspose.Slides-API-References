## IDataLabelFormat::set_ShowPercentage(bool) metode

Mewakili perilaku tampilan nilai persentase label data pada diagram yang ditentukan. True menampilkan nilai persentase. False untuk menyembunyikannya. Tulis **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowPercentage(bool value)=0
```

## Keterangan

Jika parent dari objek [DataLabelFormat](../../datalabelformat/) ini adalah koleksi [DataLabelCollection](../../datalabelcollection/) label data maka properti ini mendapatkan atau mengatur nilai default properti ShowPercentage untuk label data baru dalam koleksi [DataLabelCollection](../../datalabelcollection/). Menetapkan properti ini dengan nilai juga mengatur nilai ini ke properti ShowPercentage untuk semua label data dalam koleksi [DataLabelCollection](../../datalabelcollection/) (misalnya "DataLabels.DefaultDataLabelFormat.ShowPercentage = val;" menyebabkan semua DataLabels[i].ShowPercentage menjadi sama dengan val).
