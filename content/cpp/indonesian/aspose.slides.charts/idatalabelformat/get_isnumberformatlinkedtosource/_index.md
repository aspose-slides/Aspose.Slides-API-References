## IDataLabelFormat::get_IsNumberFormatLinkedToSource() metode

Baca **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_IsNumberFormatLinkedToSource()=0
```

## Catatan

Jika induk dari objek [DataLabelFormat](../../datalabelformat/) ini adalah koleksi [DataLabelCollection](../../datalabelcollection/) label data maka properti ini mendapatkan atau mengatur nilai default dari properti IsNumberFormatLinkedToSource untuk label data baru di dalam koleksi [DataLabelCollection](../../datalabelcollection/). Mengatur properti ini dengan nilai juga menetapkan nilai ini ke properti IsNumberFormatLinkedToSource untuk semua label data dalam koleksi [DataLabelCollection](../../datalabelcollection/) (misalnya "DataLabels.DefaultDataLabelFormat.IsNumberFormatLinkedToSource = val;" menyebabkan semua DataLabels[i].IsNumberFormatLinkedToSource menjadi sama dengan val).
