## IDataLabelFormat::set_IsNumberFormatLinkedToSource(bool) metode

Tulis **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_IsNumberFormatLinkedToSource(bool value)=0
```

## Catatan

Jika induk dari objek [DataLabelFormat](../../datalabelformat/) ini adalah kumpulan [DataLabelCollection](../../datalabelcollection/) label data maka properti ini mendapatkan atau menetapkan nilai default properti IsNumberFormatLinkedToSource untuk label data baru dalam kumpulan [DataLabelCollection](../../datalabelcollection/). Menetapkan properti ini dengan nilai juga menetapkan nilai ini ke properti IsNumberFormatLinkedToSource untuk semua label data dalam kumpulan [DataLabelCollection](../../datalabelcollection/) (misalnya \"DataLabels.DefaultDataLabelFormat.IsNumberFormatLinkedToSource = val;\" menyebabkan semua DataLabels[i].IsNumberFormatLinkedToSource menjadi sama dengan val).
