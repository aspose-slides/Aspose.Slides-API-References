## IDataLabelFormat::set_ShowLegendKey(bool) metode

Mewakili perilaku penampilan kunci legenda label data pada diagram yang ditentukan. True jika kunci legenda label data terlihat. Tulis **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowLegendKey(bool value)=0
```

## Keterangan

Jika induk dari objek [DataLabelFormat](../../datalabelformat/) ini adalah koleksi [DataLabelCollection](../../datalabelcollection/) label data, maka properti ini mendapatkan atau mengatur nilai default properti ShowLegendKey untuk label data baru dalam koleksi [DataLabelCollection](../../datalabelcollection/). Menetapkan properti ini dengan nilai juga menetapkan nilai tersebut ke properti ShowLegendKey untuk semua label data dalam koleksi [DataLabelCollection](../../datalabelcollection/) (misalnya "DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;" menyebabkan semua DataLabels[i].ShowLegendKey menjadi sama dengan val).
