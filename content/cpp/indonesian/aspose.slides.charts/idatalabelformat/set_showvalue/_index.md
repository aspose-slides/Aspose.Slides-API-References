## IDataLabelFormat::set_ShowValue(bool) metode

Mewakili perilaku penampilan nilai persentase label data pada diagram yang ditentukan. True menampilkan nilai persentase. False untuk menyembunyikan. Tulis **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowValue(bool value)=0
```

## Keterangan

Jika induk dari objek [DataLabelFormat](../../datalabelformat/) ini adalah koleksi [DataLabelCollection](../../datalabelcollection/) label data maka properti ini mendapatkan atau mengatur nilai default properti ShowValue untuk label data baru dalam koleksi [DataLabelCollection](../../datalabelcollection/). Mengatur properti ini dengan nilai juga mengatur nilai ini ke properti ShowValue untuk semua label data dalam koleksi [DataLabelCollection](../../datalabelcollection/) (misalnya "DataLabels.DefaultDataLabelFormat.ShowValue = val;" menyebabkan semua DataLabels[i].ShowValue menjadi sama dengan val).
