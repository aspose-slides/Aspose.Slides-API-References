## IDataLabelFormat::get_ShowValue() metode

Mewakili perilaku tampilan nilai persentase label data pada diagram yang ditentukan. True menampilkan nilai persentase. False untuk menyembunyikannya. Baca **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowValue()=0
```

## Keterangan

Jika induk dari objek [DataLabelFormat](../../datalabelformat/) ini merupakan koleksi [DataLabelCollection](../../datalabelcollection/) label data maka properti ini mendapatkan atau mengatur nilai default properti ShowValue untuk label data baru dalam koleksi [DataLabelCollection](../../datalabelcollection/). Menetapkan properti ini dengan nilai juga mengatur nilai ini ke properti ShowValue untuk semua label data dalam koleksi [DataLabelCollection](../../datalabelcollection/) (misalnya "DataLabels.DefaultDataLabelFormat.ShowValue = val;" menyebabkan semua DataLabels[i].ShowValue menjadi val).
