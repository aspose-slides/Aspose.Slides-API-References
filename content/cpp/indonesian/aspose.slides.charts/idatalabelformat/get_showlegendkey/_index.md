## IDataLabelFormat::get_ShowLegendKey() metode

Mewakili perilaku tampilan kunci legenda label data pada diagram yang ditentukan. Benar jika kunci legenda label data terlihat. Baca **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowLegendKey()=0
```

## Catatan

Jika induk dari objek [DataLabelFormat](../../datalabelformat/) ini adalah kumpulan [DataLabelCollection](../../datalabelcollection/) label data, maka properti ini mengambil atau menetapkan nilai default properti ShowLegendKey untuk label data baru dalam kumpulan [DataLabelCollection](../../datalabelcollection/). Menetapkan properti ini dengan nilai juga menetapkan nilai ini ke properti ShowLegendKey untuk semua label data dalam kumpulan [DataLabelCollection](../../datalabelcollection/) (misalnya "DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;" menyebabkan semua DataLabels[i].ShowLegendKey sama dengan val).
