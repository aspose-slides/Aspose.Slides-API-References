## IDataLabelFormat::get_Position() metode


Mewakili posisi label data. Baca [LegendDataLabelPosition](../../legenddatalabelposition/).

```cpp
virtual LegendDataLabelPosition Aspose::Slides::Charts::IDataLabelFormat::get_Position()=0
```

## Keterangan


Jika induk dari objek [DataLabelFormat](../../datalabelformat/) ini adalah kumpulan [DataLabelCollection](../../datalabelcollection/) label data maka properti ini mendapatkan atau mengatur nilai default dari properti Position untuk label data baru di kumpulan [DataLabelCollection](../../datalabelcollection/). Mewakili posisi untuk objek [DataLabel](../../datalabel/). Mengatur properti ini dengan nilai juga mengatur nilai ini ke properti Position untuk semua label data di kumpulan [DataLabelCollection](../../datalabelcollection/) (misalnya "DataLabels.DefaultDataLabelFormat.Position = val;" menyebabkan semua DataLabels[i].Position menjadi sama dengan val).
