## IDataLabelFormat::set_ShowSeriesName(bool) metode

Mengatur Boolean untuk menunjukkan perilaku tampilan nama seri pada label data di diagram. True untuk menampilkan nama seri. False untuk menyembunyikan. Tulis **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowSeriesName(bool value)=0
```

## Keterangan

Jika induk dari objek [DataLabelFormat](../../datalabelformat/) ini adalah kumpulan [DataLabelCollection](../../datalabelcollection/) dari label data maka properti ini memperoleh atau mengatur nilai default dari properti ShowSeriesName untuk label data baru dalam kumpulan [DataLabelCollection](../../datalabelcollection/). Menetapkan properti ini dengan nilai juga mengatur nilai ini ke properti ShowSeriesName untuk semua label data dalam kumpulan [DataLabelCollection](../../datalabelcollection/) (misalnya "DataLabels.DefaultDataLabelFormat.ShowSeriesName = val;" menyebabkan semua DataLabels[i].ShowSeriesName menjadi sama dengan val).
