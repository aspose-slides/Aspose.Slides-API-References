## DataLabel::get_IsVisible() metode


False berarti label data tidak terlihat (dan sehingga semua Show*-flags (ShowValue, ...) adalah false). Hanya-baca **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabel::get_IsVisible() override
```

## Catatan


Jika label data terlihat Anda dapat menyembunyikannya dengan metode [Hide()](../hide/). Namun jika label data tidak terlihat (IsVisible is false) Anda dapat membuat label data terlihat dengan mengatur Show*-flags (ShowValue, ...) ke keadaan true.
