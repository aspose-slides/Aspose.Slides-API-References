## AxisAggregationType enum

Mewakili tipe agregasi sumbu kategori. Hanya digunakan dengan seri Histogram atau HistogramPareto.

```cpp
enum class AxisAggregationType
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| ByCategory | 0 | Agregasi berdasarkan kategori |
| Automatic | 1 | Mengagregasi kategori secara otomatis. |
| ByBinWidth | 2 | Agregasi kategori berdasarkan lebar bin. Property IAxis::get(set)_BinWidth must be setted. |
| ByNumberOfBins | 3 | Agregasi kategori berdasarkan jumlah bin. Property IAxis::get(set)_NumberOfBins must be setted. |
