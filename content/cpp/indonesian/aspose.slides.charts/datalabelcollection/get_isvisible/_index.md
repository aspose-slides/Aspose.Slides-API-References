## DataLabelCollection::get_IsVisible() metode


False berarti label data tidak terlihat secara default (dan sehingga semua Show*-flags (ShowValue, ...) dari properti DefaultDataLabelFormat bernilai false). Hanya-baca **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelCollection::get_IsVisible() override
```

## Catatan


Jika label data terlihat secara default, Anda dapat menyembunyikannya secara default dengan metode [Hide()](../hide/). Namun jika label data tidak terlihat secara default (IsVisible false) Anda dapat membuat label data \"visible \nby default\" dengan mengatur Show*-flags (ShowValue, ...) dari properti DefaultDataLabelFormat ke keadaan true.
