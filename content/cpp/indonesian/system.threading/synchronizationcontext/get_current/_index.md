## SynchronizationContext::get_Current() metode

Mendapatkan konteks sinkronisasi untuk thread saat ini.

```cpp
static const SharedPtr<SynchronizationContext> & System::Threading::SynchronizationContext::get_Current()
```

### Nilai Kembali

SharedPtr<SynchronizationContext> Pointer bersama ke konteks sinkronisasi thread saat ini.

## Catatan

Mengembalikan null jika tidak ada konteks sinkronisasi yang telah diatur untuk thread saat ini.
