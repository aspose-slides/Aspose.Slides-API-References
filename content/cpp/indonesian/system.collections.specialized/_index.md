## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [BitVector32](./bitvector32/) | Menyediakan vektor bit ringan sederhana dengan akses integer atau [Boolean](../system/boolean/) yang mudah ke penyimpanan 32 bit. |
| [NameValueCollection](./namevaluecollection/) | Koleksi kunci [String](../system/string/) yang terkait dan nilai [String](../system/string/) yang dapat diakses baik dengan kunci maupun dengan indeks. |
| [StringCollection](./stringcollection/) | Daftar string terindeks. Objek kelas ini hanya boleh dialokasikan menggunakan fungsi [System::MakeObject()](../system/makeobject/). Jangan pernah membuat instance jenis ini di stack atau menggunakan operator new, karena akan menyebabkan kesalahan runtime dan/atau kegagalan asersi. Selalu bungkus kelas ini ke dalam pointer [System::SmartPtr](../system/smartptr/) dan gunakan pointer ini untuk melewatkannya ke fungsi sebagai argumen. |
| [StringCollectionPtr](./stringcollectionptr/) | Pointer koleksi string dengan operator akses. |
| [StringDictionary](./stringdictionary/) | [String](../system/string/) ke kamus string. Objek kelas ini hanya boleh dialokasikan menggunakan fungsi [System::MakeObject()](../system/makeobject/). Jangan pernah membuat instance jenis ini di stack atau menggunakan operator new, karena akan menyebabkan kesalahan runtime dan/atau kegagalan asersi. Selalu bungkus kelas ini ke dalam pointer [System::SmartPtr](../system/smartptr/) dan gunakan pointer ini untuk melewatkannya ke fungsi sebagai argumen. |
