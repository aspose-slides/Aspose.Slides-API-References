## XmlSchemaComplexType::get_BlockResolved() metode


Mengembalikan nilai setelah tipe dikompilasi ke himpunan informasi pasca-validasi skema (infoset). Nilai ini menunjukkan bagaimana tipe ditegakkan ketika **xsi:type** digunakan dalam dokumen instansi.

```cpp
XmlSchemaDerivationMethod System::Xml::Schema::XmlSchemaComplexType::get_BlockResolved()
```


### Nilai Kembalian

Nilai infoset yang telah divalidasi pasca-skema. Nilai default adalah nilai **BlockDefault** pada elemen **schema**.
