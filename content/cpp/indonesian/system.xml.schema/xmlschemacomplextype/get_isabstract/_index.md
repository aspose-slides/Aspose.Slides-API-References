## XmlSchemaComplexType::get_IsAbstract() metode


Mengembalikan informasi yang menentukan apakah elemen **complexType** dapat digunakan dalam dokumen instance.

```cpp
bool System::Xml::Schema::XmlSchemaComplexType::get_IsAbstract()
```


### Nilai Kembalian

Jika **true**, sebuah elemen tidak dapat menggunakan elemen **complexType** ini secara langsung dan harus menggunakan tipe kompleks yang diturunkan dari elemen **complexType** ini. Nilainya default **false**. Opsional.
