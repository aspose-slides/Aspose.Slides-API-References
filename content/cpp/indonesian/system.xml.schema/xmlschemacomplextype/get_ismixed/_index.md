## XmlSchemaComplexType::get_IsMixed() metode


Mengembalikan informasi yang menentukan apakah tipe kompleks memiliki model konten campuran (markup di dalam konten).

```cpp
bool System::Xml::Schema::XmlSchemaComplexType::get_IsMixed() override
```


### Nilai Kembalian

**true**, jika data karakter dapat muncul di antara elemen anak dari tipe kompleks ini; sebaliknya, **false**. Nilai default adalah **false**. Opsional.
