## IXmlSchemaInfo::get_IsDefault() metode


Mengembalikan nilai yang menunjukkan apakah node XML yang telah divalidasi ini diatur sebagai hasil dari nilai default yang diterapkan selama validasi skema XML [Schema](../../) Definition Language (XSD).

```cpp
virtual bool System::Xml::Schema::IXmlSchemaInfo::get_IsDefault()=0
```


### Nilai Kembali

**true** jika node XML yang telah divalidasi ini diatur sebagai hasil dari nilai default yang diterapkan selama validasi skema; bila tidak, **false**.
