## XmlSchemaElement::get_IsNillable() metode

Mengembalikan informasi yang menunjukkan apakah **xsi:nil** dapat terjadi dalam data instansi. Menunjukkan apakah nilai nil eksplisit dapat ditetapkan ke elemen.

```cpp
bool System::Xml::Schema::XmlSchemaElement::get_IsNillable()
```

### Nilai Kembali

Jika nillable bernilai **true**, ini memungkinkan sebuah instansi elemen memiliki atribut **nil** yang disetel ke **true**. Atribut **nil** didefinisikan sebagai bagian dari ruang nama XML [Schema](../../) untuk instansi. Defaultnya adalah **false**. Opsional.
