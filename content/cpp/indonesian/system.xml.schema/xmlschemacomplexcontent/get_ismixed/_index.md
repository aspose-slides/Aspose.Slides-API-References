## XmlSchemaComplexContent::get_IsMixed() metode

Mengembalikan informasi yang menentukan apakah tipe memiliki model konten campuran.

```cpp
bool System::Xml::Schema::XmlSchemaComplexContent::get_IsMixed()
```

### Nilai Kembalian

Jika nilai ini **true**, data karakter diizinkan muncul di antara elemen anak dari tipe kompleks (model konten campuran). Nilai default adalah **false**. Opsional.
