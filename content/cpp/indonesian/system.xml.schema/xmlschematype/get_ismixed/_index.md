## XmlSchemaType::get_IsMixed() metode


Mengembalikan nilai yang menunjukkan apakah tipe ini memiliki model konten campuran. Pemanggilan ini hanya valid pada tipe kompleks.

```cpp
virtual bool System::Xml::Schema::XmlSchemaType::get_IsMixed()
```


### Nilai Kembalian

**true** jika tipe memiliki model konten campuran; bila tidak, **false**. Defaultnya adalah **false**.
