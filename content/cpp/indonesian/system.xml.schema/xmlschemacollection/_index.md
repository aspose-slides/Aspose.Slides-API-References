## Catatan

Usang
:   Kelas [XmlSchemaCollection](./) sudah usang. Gunakan [XmlSchemaSet](../xmlschemaset/) sebagai gantinya.

Objek dari kelas ini seharusnya hanya dialokasikan menggunakan fungsi [System::MakeObject()](../../system/makeobject/). Jangan pernah membuat instance tipe ini di stack atau menggunakan operator new, karena akan menghasilkan kesalahan waktu jalan dan/atau kesalahan asersi. Selalu bungkus kelas ini ke dalam pointer [System::SmartPtr](../../system/smartptr/) dan gunakan pointer ini untuk melewatkannya ke fungsi sebagai argumen.
