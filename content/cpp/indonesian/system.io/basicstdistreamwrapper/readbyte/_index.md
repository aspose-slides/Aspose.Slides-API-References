## BasicSTDIStreamWrapper::ReadByte() metode

Jika mode pembungkus adalah biner, membaca satu byte dari penyimpanan karakter terdekripsi terakhir, sebaliknya membaca satu karakter dari aliran dan mengkonversinya ke tipe **uint8_t**.

```cpp
virtual int System::IO::BasicSTDIStreamWrapper<T, typename>::ReadByte() override
```

### Nilai Kembalian
