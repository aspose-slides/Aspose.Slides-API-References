## BasicSTDIStreamWrapper::WriteByte(uint8_t) metode


Jika mode pembungkus adalah biner, menulis ke aliran nilai bilangan bulat tak bertanda 8-bit yang ditentukan, jika tidak mengonversinya ke tipe char_type dan kemudian menulis hasilnya ke aliran. Tidak didukung!

virtual void System::IO::BasicSTDIStreamWrapper<T, typename>::WriteByte(uint8_t value) override
