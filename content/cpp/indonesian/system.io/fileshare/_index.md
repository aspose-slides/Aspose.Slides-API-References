## FileShare enum

Menentukan jenis akses apa yang dapat dimiliki objek [FileStream](../filestream/) lain ke file yang sedang dibuka.

```cpp
enum class FileShare
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| None | 0 | Tidak ada akses. |
| Read | 1 | Akses hanya-baca. |
| Write | 2 | Akses hanya-tulis. |
| ReadWrite | 3 | Akses Baca dan Tulis. |
| Delete | 4 | File dapat dihapus. |
| Inheritable | 16 | Membuat handle file dapat diwariskan oleh proses anak. |
