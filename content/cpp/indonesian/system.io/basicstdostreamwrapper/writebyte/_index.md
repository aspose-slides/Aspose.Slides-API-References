## BasicSTDOStreamWrapper::WriteByte(uint8_t) metode

Jika mode pembungkusan adalah biner, menulis ke stream nilai bilangan bulat tak bertanda 8-bit yang ditentukan, jika tidak mengonversinya ke tipe char_type dan kemudian menulis hasilnya ke stream.

```cpp
virtual void System::IO::BasicSTDOStreamWrapper<T, typename>::WriteByte(uint8_t value) override
```

### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| value | **uint8_t** | Nilai yang akan ditulis |
