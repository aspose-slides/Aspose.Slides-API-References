## FileMode enum

Menentukan bagaimana file harus dibuka.

```cpp
enum class FileMode
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| CreateNew | 1 | Buat file baru. Jika file sudah ada, sebuah pengecualian dilemparkan. |
| Create | 2 | Buat file baru. Jika file sudah ada, file tersebut ditimpa. |
| Open | 3 | Buka file yang sudah ada. Jika file tidak ada, sebuah pengecualian dilemparkan. |
| OpenOrCreate | 4 | Buka file yang sudah ada atau buat file baru jika tidak ada. |
| Truncate | 5 | Buka file yang sudah ada dan pangkas sehingga kosong. Jika file tidak ada, sebuah pengecualian dilemparkan. |
| Append | 6 | Buka file yang sudah ada dan pindah ke akhir file atau buat file baru jika tidak ada. |
