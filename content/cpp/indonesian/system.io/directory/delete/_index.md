
### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| path | const [String](../../../system/string/)\& | Jalur ke direktori atau file yang akan dihapus |
| recursive | **bool** | Jika **path** menunjukkan direktori yang tidak kosong maka **recursive** menentukan apakah semua isi direktori harus dihapus secara rekursif; jika direktori yang ditunjuk oleh **path** tidak kosong dan **recursive** bernilai 'false' maka operasi gagal |
