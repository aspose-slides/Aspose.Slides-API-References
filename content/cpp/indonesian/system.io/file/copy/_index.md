## File::Copy(const String\&, const String\&, bool) metode

Menyalin file yang ditentukan ke lokasi yang ditentukan. Jika file tujuan sudah ada, sebuah parameter menentukan apakah file tersebut harus ditimpa.

```cpp
static void System::IO::File::Copy(const String &sourceFileName, const String &destFileName, bool overwrite=false)
```

### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| sourceFileName | const [String](../../../system/string/)\& | Jalur file yang akan disalin |
| destFileName | const [String](../../../system/string/)\& | Jalur lokasi baru file yang akan disalin |
| overwrite | **bool** | Benar jika file tujuan yang ada harus ditimpa, salah jika penyalinan harus gagal bila file tujuan sudah ada |
