## FileAttributes enum

Mewakili atribut direktori atau file.

```cpp
enum class FileAttributes
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Archive | 32 | Entitas sistem file adalah kandidat untuk penghapusan atau cadangan. |
| Compressed | 2048 | Entitas sistem file terkompresi. |
| Device | 64 | Tidak digunakan. |
| Directory | 16 | Entitas sistem file adalah direktori. |
| Encrypted | 16384 | Entitas sistem file terenkripsi. |
| Hidden | 2 | Entitas sistem file tersembunyi. |
| IntegrityStream | 32768 | Entitas sistem file mengandung dukungan integritas data. |
| Normal | 128 | Entitas sistem file adalah file yang tidak memiliki atribut khusus. |
| NotContentIndexed | 8192 | Entitas sistem file tidak akan diindeks oleh layanan pengindeksan konten. |
| NoScrubData | 131072 | Entitas sistem file tidak termasuk dalam pemindaian integritas data. |
| Offline | 4096 | Entitas sistem file berada offline dan datanya tidak tersedia secara langsung. |
| ReadOnly | 1 | Entitas sistem file bersifat baca-saja. |
| ReparsePoint | 1024 | Entitas sistem file adalah file yang berisi titik reparse. |
| SparseFile | 512 | Entitas sistem file adalah file sparse. |
| System | 4 | Entitas sistem file adalah file sistem. |
| Temporary | 256 | Entitas sistem file adalah file sementara. |
| Invalid | 0 | Nilai tidak valid. |
