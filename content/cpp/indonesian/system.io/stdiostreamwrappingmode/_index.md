## STDIOStreamWrappingMode enum

Menentukan mode operasi I/O yang akan dilakukan pembungkus pada aliran yang mirip dengan std::iostreams-like streams.

```cpp
enum class STDIOStreamWrappingMode
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Binary | 0 | Mode yang memungkinkan operasi masukan untuk mendekode data aliran bertipe char_type menjadi byte, dan mengkodekan byte menjadi data bertipe char_type untuk operasi keluaran. |
| Conversion | 1 | Mode yang memungkinkan operasi masukan untuk mengkonversi data aliran dari tipe char_type ke tipe **uint8_t** dan sebaliknya untuk operasi keluaran. |
