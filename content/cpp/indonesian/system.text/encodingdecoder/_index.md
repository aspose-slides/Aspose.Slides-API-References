## EncodingDecoder kelas

[Decoder](../decoder/) yang menggunakan objek encoding untuk mendekode. Objek kelas ini harus hanya dialokasikan menggunakan fungsi [System::MakeObject()](../../system/makeobject/). Jangan pernah membuat instance tipe ini di stack atau menggunakan operator new, karena akan menghasilkan error runtime dan/atau kesalahan assert. Selalu balut kelas ini ke dalam pointer [System::SmartPtr](../../system/smartptr/) dan gunakan pointer tersebut untuk meneruskannya ke fungsi sebagai argumen.

```cpp
class EncodingDecoder : public System::Text::Decoder
```
