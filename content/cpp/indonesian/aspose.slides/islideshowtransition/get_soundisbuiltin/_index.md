## ISlideShowTransition::get_SoundIsBuiltIn() metode

Menentukan apakah suara ini merupakan suara bawaan atau tidak. Jika atribut ini diatur ke true maka aplikasi yang menghasilkan akan diperingatkan untuk memeriksa atribut name yang ditentukan untuk suara ini dalam daftar suara bawaan dan kemudian dapat menampilkan nama khusus atau UI sebagaimana diperlukan. Reads **bool**.

```cpp
virtual bool Aspose::Slides::ISlideShowTransition::get_SoundIsBuiltIn()=0
```
