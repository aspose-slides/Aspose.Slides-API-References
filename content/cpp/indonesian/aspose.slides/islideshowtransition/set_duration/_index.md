## ISlideShowTransition::set_Duration(int32_t) metode

Mengatur durasi efek transisi slide dalam milidetik. Tulis **int32_t**.

```cpp
virtual void Aspose::Slides::ISlideShowTransition::set_Duration(int32_t value)=0
```

## Catatan

Berkorespondensi dengan atribut **p14:dur** dari elemen **p:transition** dalam skema PresentationML. Jika tidak diatur, durasi ditentukan secara otomatis berdasarkan properti [Speed](../) dan tipe transisi.
