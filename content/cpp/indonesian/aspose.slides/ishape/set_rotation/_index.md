## IShape::set_Rotation(float) metode

Menetapkan jumlah derajat bentuk yang ditentukan diputar di sekitar sumbu z. Nilai positif menunjukkan rotasi searah jarum jam; nilai negatif menunjukkan rotasi berlawanan arah jarum jam. Tulis **float**.

```cpp
virtual void Aspose::Slides::IShape::set_Rotation(float value)=0
```

## Catatan

Nilai yang dikembalikan selalu terdefinisi (bukan std::numeric_limits<float>::quiet_NaN()). Nilai yang diberikan harus terdefinisi (bukan std::numeric_limits<float>::quiet_NaN()). Anda dapat mengatur nilai yang tidak terdefinisi untuk properti instance RawFrame.
