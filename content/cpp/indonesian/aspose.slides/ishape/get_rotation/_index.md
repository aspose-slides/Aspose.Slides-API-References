## IShape::get_Rotation() metode

Mengembalikan jumlah derajat bentuk yang ditentukan diputar di sekitar sumbu z. Nilai positif menunjukkan rotasi searah jarum jam; nilai negatif menunjukkan rotasi berlawanan arah jarum jam. Baca **float**.

```cpp
virtual float Aspose::Slides::IShape::get_Rotation()=0
```

## Catatan

Nilai yang dikembalikan selalu terdefinisi (bukan std::numeric_limits<float>::quiet_NaN()). Nilai yang diberikan harus terdefinisi (bukan std::numeric_limits<float>::quiet_NaN()). Anda dapat mengatur nilai tak terdefinisi untuk properti instance RawFrame.
