## Catatan

Contoh berikut menunjukkan cara mengatur nilai zoom untuk slide PowerPoint [Presentation](../presentation/).
```cpp
// Membuat objek Presentation yang mewakili file presentasi
auto presentation = System::MakeObject<Presentation>(u"demo.pptx");

// Mengatur Properti Tampilan Presentasi
presentation->get_ViewProperties()->get_SlideViewProperties()->set_Scale(100);
// Nilai zoom dalam persentase untuk tampilan slide
presentation->get_ViewProperties()->get_NotesViewProperties()->set_Scale(100);
// Nilai zoom dalam persentase untuk tampilan catatan
presentation->Save(u"Zoom_out.pptx", SaveFormat::Pptx);
```
