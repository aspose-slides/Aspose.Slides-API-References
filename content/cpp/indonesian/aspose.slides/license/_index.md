## Catatan


Dalam contoh ini, akan dicoba untuk menemukan file lisensi bernama MyLicense.lic di folder yang berisi komponen, di folder yang berisi assembly pemanggil, di folder assembly entri, dan kemudian di sumber daya tertanam dari assembly pemanggil. 
```cpp
auto license = MakeObject<License>();
license->SetLicense(u"MyLicense.lic");
```
