## ResourceLoadingAction enum

Menentukan mode pemuatan sumber daya eksternal.

```cpp
enum class ResourceLoadingAction
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Default | 0 | [Aspose.Slides](../) akan memuat sumber daya eksternal seperti biasa. |
| Skip | 1 | [Aspose.Slides](../) akan melewati pemuatan sumber daya eksternal. Hanya tautan tanpa data yang akan disimpan untuk gambar. |
| UserProvided | 2 | [Aspose.Slides](../) akan menggunakan array byte yang disediakan oleh pengguna di [IResourceLoadingArgs::SetData](../iresourceloadingargs/setdata/) sebagai data gambar. |
