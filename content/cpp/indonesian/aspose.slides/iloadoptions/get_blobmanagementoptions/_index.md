## ILoadOptions::get_BlobManagementOptions() metode


Mewakili opsi yang dapat digunakan untuk mengelola perilaku penanganan Binary Large Objects (BLOBs), seperti penggunaan file sementara atau maksimum byte BLOBs dalam memori. Opsi-opsi ini dimaksudkan untuk mengatur rasio kinerja/konsumsi memori terbaik untuk lingkungan atau persyaratan tertentu.

```cpp
virtual System::SharedPtr<IBlobManagementOptions> Aspose::Slides::ILoadOptions::get_BlobManagementOptions()=0
```

## Catatan


Binary Large Object (BLOB) adalah data biner yang disimpan sebagai satu entitas - yaitu BLOB dapat berupa audio, video, atau presentasi itu sendiri.
