## ProtectionManager::set_EncryptDocumentProperties(bool) metode

Properti ini masuk akal, jika presentasi dilindungi dengan kata sandi. Jika true maka properti dokumen dienkripsi dalam file presentasi. Jika false maka properti dokumen bersifat publik sementara presentasi dienkripsi. Tulis **bool**.
