## IDrawingGuide::get_Position() metode


Mengembalikan posisi panduan gambar dalam poin dari sudut kiri atas slide. Baca **float**.

```cpp
virtual float Aspose::Slides::IDrawingGuide::get_Position()=0
```

## Catatan


Rentang nilai tipikal adalah dari nol hingga tinggi slide untuk panduan horizontal dan dari nol hingga lebar slide untuk panduan vertikal.
