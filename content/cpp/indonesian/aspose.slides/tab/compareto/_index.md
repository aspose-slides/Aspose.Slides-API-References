## Tab::CompareTo(System::SharedPtr\<ITab\>) metode


Membandingkan instance saat ini dengan objek lain dari tipe yang sama.

```cpp
int32_t Aspose::Slides::Tab::CompareTo(System::SharedPtr<ITab> obj) override
```


### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| obj | [System::SharedPtr](../../../system/sharedptr/)\<[ITab](../../itab/)\> | Objek untuk dibandingkan dengan instance ini. |

### Nilai Kembali

Integer 32-bit yang menunjukkan urutan relatif dari kedua objek yang dibandingkan. Nilai kembali memiliki arti berikut:
* < 0 - Instance ini lebih kecil daripada obj.
* = 0 - Instance ini sama dengan obj.
* > 0 - Instance ini lebih besar daripada obj.
