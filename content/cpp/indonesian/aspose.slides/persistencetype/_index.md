## PersistenceType enum

Menentukan metode yang digunakan untuk menyimpan properti kontrol ActiveX.

```cpp
enum class PersistenceType
```

### Values

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| NotDefined | -1 | ID persistance tidak ditentukan. |
| PersistPropertyBag | 0 | Menentukan bahwa kontrol ActiveX dipertahankan menggunakan persistance berbasis property-bag. Persistance berbasis property-bag menyimpan kontrol ActiveX dengan cara kumpulan pasangan nama dan nilai yang menentukan data yang dipertahankan oleh kontrol ActiveX. |
| PersistStream | 1 | Menentukan bahwa kontrol ActiveX dipertahankan menggunakan persistance berbasis stream yang tidak mendukung inisialisasi kontrol ActiveX ke keadaan default. |
| PersistStreamInit | 2 | Menentukan bahwa kontrol ActiveX dipertahankan menggunakan persistance berbasis stream yang mendukung inisialisasi kontrol ActiveX ke keadaan default. |
| PersistStorage | 3 | Menentukan bahwa kontrol ActiveX dipertahankan menggunakan persistance berbasis storage. |
