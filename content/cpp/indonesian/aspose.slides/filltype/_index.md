## FillType enum

Menentukan jenis isian interior dari berbagai objek visual.

```cpp
enum class FillType : int8_t
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| NotDefined | -1 | Jenis isian tidak didefinisikan. |
| NoFill | 0 | Tidak ada isian yang diterapkan. |
| Solid | 1 | Diisi dengan warna solid. |
| Gradient | 2 | Isian bergradien. |
| Pattern | 3 | Pola berulang digunakan untuk mengisi objek. |
| Picture | 4 | Satu gambar tunggal digunakan untuk mengisi objek. |
| Group | 5 | Objek visual mewarisi properti isian dari grup. |
