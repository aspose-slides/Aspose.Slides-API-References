## BulletFormat::set_Height(float) metode

Menetapkan tinggi bullet dari sebuah paragraf tanpa pewarisan. Nilai std::numeric_limits<float>::quiet_NaN() menentukan bahwa bullet mewarisi tinggi dari bagian pertama dalam paragraf. Tuliskan **float**.

```cpp
void Aspose::Slides::BulletFormat::set_Height(float value) override
```

## Catatan

Nilai tinggi negatif berarti tinggi diberikan dalam poin dan nilai positif berarti tinggi merupakan persentase dari teks di sekitarnya.
