## Shape::set_Rotation(float) method

Mengatur jumlah derajat bentuk yang ditentukan diputar di sekitar sumbu z. Nilai positif menunjukkan rotasi searah jarum jam; nilai negatif menunjukkan rotasi berlawanan arah jarum jam. Tulis **float**.

```cpp
void Aspose::Slides::Shape::set_Rotation(float value) override
```

## Catatan

Nilai yang dikembalikan selalu terdefinisi (bukan std::numeric_limits<float>::quiet_NaN()). Nilai yang diberikan harus terdefinisi (bukan std::numeric_limits<float>::quiet_NaN()). Anda dapat mengatur nilai tak terdefinisi untuk properti instance RawFrame.
