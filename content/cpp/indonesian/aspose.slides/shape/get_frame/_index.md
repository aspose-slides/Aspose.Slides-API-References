## Catatan

Nilai setiap properti dari instance [IShapeFrame](../../ishapeframe/) yang ditetapkan harus tidak terdefinisi (harus bukan NaN atau NotDefined). Anda dapat mengatur nilai tidak terdefinisi untuk properti instance RawFrame.
