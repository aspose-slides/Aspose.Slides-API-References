## IShapeFrame::get_Rotation() metode

Mengembalikan jumlah derajat sebuah frame diputar di sekitar sumbu z. Nilai positif menunjukkan putaran searah jarum jam; nilai negatif menunjukkan putaran berlawanan arah jarum jam. Baca-saja **float**.

```cpp
virtual float Aspose::Slides::IShapeFrame::get_Rotation()=0
```
