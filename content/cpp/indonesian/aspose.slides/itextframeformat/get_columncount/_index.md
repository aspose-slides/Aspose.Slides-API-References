## ITextFrameFormat::get_ColumnCount() metode

Mengembalikan jumlah kolom di area teks. Nilai ini harus berupa angka positif. Jika tidak, nilai akan diatur menjadi nol. Nilai 0 berarti nilai tidak terdefinisi. Baca **int32_t**.

```cpp
virtual int32_t Aspose::Slides::ITextFrameFormat::get_ColumnCount()=0
```
