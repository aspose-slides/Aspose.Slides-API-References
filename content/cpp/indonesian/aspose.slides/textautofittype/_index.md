## TextAutofitType enum

Represents text autofit mode.

```cpp
enum class TextAutofitType : int8_t
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| NotDefined | -1 | Tidak didefinisikan. |
| None | 0 | Tidak ada autofit. |
| Normal | 1 | Autofit normal. Ukuran font dan spasi baris akan dikurangi agar sesuai dengan bentuk. |
| Shape | 2 | [Shape](../shape/) autofit. [Shape](../shape/) ukuran akan diubah agar sesuai dengan teks. |
