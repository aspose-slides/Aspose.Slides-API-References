## IDocumentProperties::get_AppVersion() method


Mengembalikan versi aplikasi. Hanya baca [System::String](../../../system/string/).

```cpp
virtual System::String Aspose::Slides::IDocumentProperties::get_AppVersion()=0
```

## Catatan


Konten elemen ini harus dalam format XX.YYYY, di mana X dan Y mewakili nilai numerik; jika tidak, dokumen akan dianggap tidak sesuai. [Aspose.Slides](../../) mewakili versinya dalam format XX.YYZZ, di mana: XX - versi utama YY - versi minor ZZ - versi perbaikan Sebagai contoh, nilai 23.0105 berarti versi [Aspose.Slides](../../) 23.1.5.
