## BlobManagementOptions::get_PresentationLockingBehavior() metode

Properti ini menentukan apakah sebuah instance dari kelas [Presentation](../../presentation/) dapat menjadi pemilik sumber - file atau stream selama masa hidup instance. Jika instance menjadi pemilik, ia mengunci sumber. Ini membantu meningkatkan konsumsi memori dan kinerja saat bekerja dengan BLOB, namun sumber (stream atau file) tidak dapat diubah selama masa hidup [Presentation](../../presentation/)'s instance.
