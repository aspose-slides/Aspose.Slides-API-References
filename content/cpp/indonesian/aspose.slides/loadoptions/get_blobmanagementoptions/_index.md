## LoadOptions::get_BlobManagementOptions() metode

Mewakili opsi yang dapat digunakan untuk mengelola perilaku penanganan Binary Large Objects (BLOBs), seperti penggunaan file sementara atau byte BLOB maksimum di memori. Opsi-opsi ini dimaksudkan untuk menyetel rasio kinerja/konsumsi memori terbaik untuk lingkungan atau persyaratan tertentu.

```cpp
System::SharedPtr<IBlobManagementOptions> Aspose::Slides::LoadOptions::get_BlobManagementOptions() override
```

## Keterangan

Binary Large Object (BLOB) adalah data biner yang disimpan sebagai satu entitas - yaitu BLOB dapat berupa audio, video, atau presentasi itu sendiri.
