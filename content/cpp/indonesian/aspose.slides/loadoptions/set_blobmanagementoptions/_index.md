## LoadOptions::set_BlobManagementOptions(System::SharedPtr\<IBlobManagementOptions\>) metode

Mewakili opsi yang dapat digunakan untuk mengelola perilaku penanganan Binary Large Objects (BLOBs), seperti penggunaan file sementara atau maksimum byte BLOBs di memori. Opsi-opsi ini dimaksudkan untuk menyetel rasio kinerja/konsumsi memori terbaik untuk lingkungan atau kebutuhan tertentu.

```cpp
void Aspose::Slides::LoadOptions::set_BlobManagementOptions(System::SharedPtr<IBlobManagementOptions> value) override
```

## Keterangan

Objek Besar Biner (BLOB) adalah data biner yang disimpan sebagai satu entitas - yaitu BLOB dapat berupa audio, video, atau presentasi itu sendiri.
