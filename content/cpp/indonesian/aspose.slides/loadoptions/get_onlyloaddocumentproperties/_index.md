## LoadOptions::get_OnlyLoadDocumentProperties() metode

Properti ini masuk akal jika file presentasi dilindungi kata sandi. Nilai true berarti hanya properti dokumen yang harus dimuat dari file presentasi yang terenkripsi dan kata sandi harus diabaikan. Nilai false berarti seluruh presentasi yang terenkripsi harus dimuat dengan menggunakan kata sandi yang tepat. Jika presentasi tidak terenkripsi maka nilai properti selalu diabaikan. Jika properti dokumen dari file yang terenkripsi tidak bersifat publik dan nilai properti adalah true maka properti dokumen tidak dapat dimuat dan eksepsi akan dilemparkan. Baca **bool**.

```cpp
bool Aspose::Slides::LoadOptions::get_OnlyLoadDocumentProperties() override
```
