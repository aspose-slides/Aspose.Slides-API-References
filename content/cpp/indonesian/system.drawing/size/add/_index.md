## Size::Add(const Size\&, const Size\&) metode

```cpp
static Size System::Drawing::Size::Add(const Size &size1, const Size &size2)
```

| size2 | const [Size](../)\& | Operand kedua |

### Nilai Kembali

Objek [Size](../) yang merupakan jumlah dari **size1** dan **size2**
