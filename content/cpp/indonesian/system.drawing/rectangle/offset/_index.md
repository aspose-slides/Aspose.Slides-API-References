## Rectangle::Offset(const Point\&) metode


Offsets the position of the rectangle represented by the current object by the specified amounts.

```cpp
void System::Drawing::Rectangle::Offset(const Point &pos)
```


### Argumen

| Parameter | Type | Deskripsi |
| --- | --- | --- |
| pos | const [Point](../../point/)\& | Objek [Point](../../point/) yang menentukan jumlah offset rectangle; nilai koordinat X titik menentukan jumlah yang ditambahkan ke koordinat X sudut kiri atas persegi panjang dan nilai koordinat Y titik menentukan jumlah yang ditambahkan ke koordinat Y sudut kiri atas persegi panjang |
