## ContentAlignment enum

Menentukan perataan konten.

```cpp
enum class ContentAlignment
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| TopLeft | 1 | Ditempatkan secara vertikal di bagian atas, dan secara horizontal di sebelah kiri. |
| TopCenter | 2 | Ditempatkan secara vertikal di bagian atas, dan secara horizontal di tengah. |
| TopRight | 4 | Ditempatkan secara vertikal di bagian atas, dan secara horizontal di sebelah kanan. |
| MiddleLeft | 16 | Ditempatkan secara vertikal di tengah, dan secara horizontal di sebelah kiri. |
| MiddleCenter | 32 | Ditempatkan secara vertikal di tengah, dan secara horizontal di tengah. |
| MiddleRight | 64 | Ditempatkan secara vertikal di tengah, dan secara horizontal di sebelah kanan. |
| BottomLeft | 256 | Ditempatkan secara vertikal di bagian bawah, dan secara horizontal di sebelah kiri. |
| BottomCenter | 512 | Ditempatkan secara vertikal di bagian bawah, dan secara horizontal di tengah. |
| BottomRight | 1024 | Ditempatkan secara vertikal di bagian bawah, dan secara horizontal di sebelah kanan. |
