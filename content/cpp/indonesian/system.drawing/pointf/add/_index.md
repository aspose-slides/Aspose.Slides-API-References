## PointF::Add(const PointF\&, const SizeF\&) metode

Menambahkan nilai lebar dan tinggi dari objek [SizeF](../../sizef/) yang ditentukan ke nilai koordinat X dan Y dari objek [PointF](../) yang ditentukan secara berkorespondensi.

```cpp
static PointF System::Drawing::PointF::Add(const PointF &point, const SizeF &size)
```

### Argument

| Parameter | Type | Description |
| --- | --- | --- |
| point | const [PointF](../)\& | Titik yang akan diterjemahkan |
| size | const [SizeF](../../sizef/)\& | Objek [SizeF](../../sizef/) yang menentukan nilai yang akan ditambahkan ke nilai koordinat **point** |

### Nilai Kembalian

Objek [PointF](../) baru yang nilai koordinat X-nya sama dengan jumlah nilai koordinat X **point** dan nilai lebar **size**, serta nilai koordinat Y-nya sama dengan jumlah nilai koordinat Y **point** dan nilai tinggi **size**.
