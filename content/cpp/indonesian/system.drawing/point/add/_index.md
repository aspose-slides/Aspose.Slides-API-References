## Point::Add(const Point\&, const Size\&) method

Menambahkan nilai lebar dan tinggi dari objek [Size](../../size/) yang ditentukan ke nilai koordinat X dan Y dari objek [Point](../) yang ditentukan secara berkorespondensi.

```cpp
static Point System::Drawing::Point::Add(const Point &point, const Size &size)
```

### Arguments

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| point | const [Point](../)\& | Titik yang akan dipindahkan |
| size | const [Size](../../size/)\& | Objek [Size](../../size/) yang menentukan nilai yang akan ditambahkan ke nilai koordinat **point** |

### Nilai Kembalian

Objek [Point](../) baru yang nilai koordinat X-nya sama dengan jumlah nilai koordinat X **point** dan nilai lebar **size**, serta nilai koordinat Y-nya sama dengan jumlah nilai koordinat Y **point** dan nilai tinggi **size**.
