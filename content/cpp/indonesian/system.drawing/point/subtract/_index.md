## Point::Subtract(const Point\&, const Size\&) metode


Mengurangkan nilai lebar dan tinggi objek [Size](../../size/) yang ditentukan dari nilai koordinat X dan Y objek [Point](../) yang ditentukan secara berurutan.

```cpp
static Point System::Drawing::Point::Subtract(const Point &point, const Size &size)
```


### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| point | const [Point](../)\& | Titik yang akan diterjemahkan |
| size | const [Size](../../size/)\& | Objek [Size](../../size/) yang menentukan nilai yang akan dikurangkan dari nilai koordinat **point** |

## Nilai Kembalian

Sebuah objek [Point](../) baru yang nilai koordinat X-nya sama dengan hasil pengurangan nilai lebar **size** dari nilai koordinat X **point** dan nilai koordinat Y-nya sama dengan hasil pengurangan nilai tinggi **size** dari nilai koordinat Y **point**.
