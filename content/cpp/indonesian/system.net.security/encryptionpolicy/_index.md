## EncryptionPolicy enum

Menumukan kebijakan enkripsi.

```cpp
enum class EncryptionPolicy
```

### Values

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| RequireEncryption | 0 | Mewajibkan enkripsi dan tidak pernah mengizinkan cipher 'Null'. |
| AllowNoEncryption | 1 | Menyukai penggunaan enkripsi penuh tetapi cipher 'Null' dapat digunakan jika server menyetujui. |
| NoEncryption | 2 | Mengizinkan tanpa enkripsi dan meminta agar cipher 'Null' digunakan jika ujung lainnya dapat menangani cipher 'Null'. |
