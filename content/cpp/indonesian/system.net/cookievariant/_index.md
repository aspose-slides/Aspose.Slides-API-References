## CookieVariant enum

Menumerasikan spesifikasi cookie.

```cpp
enum class CookieVariant
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Unknown | 0 | Spesifikasi cookie yang tidak diketahui. |
| Plain | 1 | Spesifikasi cookie biasa. |
| Rfc2109 | 2 | Spesifikasi cookie 'RFC 2109'. |
| Rfc2965 | 3 | Spesifikasi cookie 'RFC 2965'. |
| Default | 2 | Nilai default yang sama dengan 'Rfc2109'. |
