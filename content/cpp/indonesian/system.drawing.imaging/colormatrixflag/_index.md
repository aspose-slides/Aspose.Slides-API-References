## ColorMatrixFlag enum

Menentukan jenis gambar dan warna yang akan dipengaruhi oleh pengaturan penyesuaian warna dan grayscale dari objek [ImageAttributes](../imageattributes/).

```cpp
enum class ColorMatrixFlag
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| Default | 0 | Baik warna maupun nilai grayscale disesuaikan warnanya. |
| SkipGrays | 1 | Nilai grayscale tidak disesuaikan warnanya. |
| AltGrays | 2 | Hanya nilai grayscale yang disesuaikan warnanya. |
