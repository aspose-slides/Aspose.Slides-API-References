## enum ImageLockMode

Menentukan properti wilayah gambar yang sedang dikunci.

```cpp
enum class ImageLockMode
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| ReadOnly | 1 | Wilayah dikunci hanya untuk membaca. |
| WriteOnly | 2 | Wilayah dikunci hanya untuk menulis. |
| ReadWrite | n/a | Wilayah dikunci baik untuk membaca maupun menulis. |
| UserInputBuffer | 4 | Gambar berada di buffer input pengguna, aksesnya dikendalikan oleh pengguna. |
