## MetafileFrameUnit enum

Menentukan satuan ukuran untuk persegi panjang yang digunakan untuk mengatur ukuran dan posisi metafile.

```cpp
enum class MetafileFrameUnit
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Pixel | n/a | Menentukan piksel sebagai satuan ukuran. |
| Point | n/a | Menentukan poin printer sebagai satuan ukuran. |
| Inch | n/a | Menentukan inci sebagai satuan ukuran. |
| Document | n/a | Menentukan 1/300 inci sebagai satuan ukuran. |
| Millimeter | n/a | Menentukan milimeter sebagai satuan ukuran. |
| GdiCompatible | n/a | Menentukan 0,01 milimeter sebagai satuan ukuran. Disediakan untuk kompatibilitas dengan GDI. |
