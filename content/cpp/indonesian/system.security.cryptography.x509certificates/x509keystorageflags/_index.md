## X509KeyStorageFlags enum

Mendefinisikan cara menyimpan kunci.

```cpp
enum class X509KeyStorageFlags : int32_t
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| DefaultKeySet | 0 | Gunakan set kunci default. |
| UserKeySet | 1 | Gunakan penyimpanan yang terkait dengan pengguna alih-alih yang lokal pada mesin. |
| MachineKeySet | 2 | Gunakan penyimpanan mesin lokal alih-alih yang milik pengguna. |
| Exportable | 4 | Menandai kunci yang diimpor sebagai dapat diekspor. |
| UserProtected | 8 | Beritahu pengguna bahwa kunci sedang digunakan. |
| PersistKeySet | 16 | Kunci dipertahankan ketika mengimpor sertifikat. |
