## X500DistinguishedNameFlags enum


Aturan pemformatan nama terdistinguisi sertifikat X509.

```cpp
enum class X500DistinguishedNameFlags
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| None | 0 | Tidak ada karakter khusus. |
| Reversed | 1 | Nama dicadangkan. |
| UseSemicolons | 16 | Gunakan titik koma. |
| DoNotUsePlusSign | 32 | Nama tidak menggunakan tanda plus. |
| DoNotUseQuotes | 64 | Menonaktifkan tanda kutip dalam nama. |
| UseCommas | 128 | Mengaktifkan penggunaan koma. |
| UseNewLines | 256 | Mengaktifkan penggunaan baris baru. |
| UseUTF8Encoding | 4096 | Berpindah dari penggunaan Unicode ke penggunaan enkoding UTF-8. |
| UseT61Encoding | 8192 | Berpindah ke enkoding T61. |
| ForceUTF8Encoding | 16384 | Memaksa penggunaan UTF-8 saat mengenkode kunci X500 tertentu. |
