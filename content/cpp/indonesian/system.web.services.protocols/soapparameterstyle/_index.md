## SoapParameterStyle enum

Mendaftarkan format parameter dalam pesan SOAP.

```cpp
enum class SoapParameterStyle
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Default | 0 | Jika '[SoapDocumentServiceAttribute](../soapdocumentserviceattribute/)' tidak diterapkan pada kelas, maka nilai defaultnya adalah 'Wrapped'. |
| Bare | 1 | Parameter ditempatkan dalam elemen XML yang mengikuti elemen 'Body'. |
| Wrapped | 2 | Parameter dibungkus dalam satu elemen XML yang mengikuti elemen 'Body'. |
