## SoapHeaderAttribute kelas

Menentukan header SOAP yang dapat diproses oleh metode layanan XML [Web](../../system.web/) atau klien layanan XML [Web](../../system.web/). Objek dari kelas ini harus hanya dialokasikan menggunakan fungsi [System::MakeObject()](../../system/makeobject/). Jangan pernah membuat instance tipe ini pada stack atau menggunakan operator new, karena akan menghasilkan kesalahan runtime dan/atau kegagalan asersi. Selalu balut kelas ini ke dalam pointer [System::SmartPtr](../../system/smartptr/) dan gunakan pointer ini untuk meneruskannya ke fungsi sebagai argumen.

```cpp
class SoapHeaderAttribute : public System::Attribute
```
