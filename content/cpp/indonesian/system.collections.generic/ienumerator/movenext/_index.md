## IEnumerator::MoveNext() metode

Memindahkan enumerator ke elemen berikutnya. Jika tidak ada elemen yang dirujuk sebelumnya, menetapkan referensi ke elemen pertama yang tersedia. Jika akhir kontainer tercapai, tidak melakukan apa pun.

```cpp
virtual bool System::Collections::Generic::IEnumerator<T>::MoveNext()=0
```

### Nilai Kembalian

True jika ada elemen yang tersedia setelah pemanggilan, false jika tidak.
