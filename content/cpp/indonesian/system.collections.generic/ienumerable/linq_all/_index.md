## IEnumerable::LINQ_All(std::function\<bool(T)>) metode

Menentukan apakah semua elemen dalam sebuah urutan memenuhi suatu kondisi.

```cpp
bool System::Collections::Generic::IEnumerable<T>::LINQ_All(std::function<bool(T)> predicate)
```

### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| predicate | std::function\<**bool**(T)> | Sebuah fungsi untuk menguji setiap elemen terhadap sebuah kondisi. |

### Nilai Kembali

true jika setiap elemen dari urutan sumber lulus uji pada predikat yang ditentukan, atau jika urutan kosong; jika tidak, false.
