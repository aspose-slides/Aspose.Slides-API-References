## LinkedListNode kelas

Node dari linked list. Menerapkan pembungkus di atas iterator std::list yang dibungkus dalam linked list. Objek dari kelas ini sebaiknya hanya dialokasikan menggunakan fungsi [System::MakeObject()](../../system/makeobject/). Jangan pernah membuat instance tipe ini di stack atau menggunakan operator new, karena akan menghasilkan runtime error dan/atau kegagalan asersi. Selalu bungkus kelas ini ke dalam pointer [System::SmartPtr](../../system/smartptr/) dan gunakan pointer tersebut untuk meneruskannya ke fungsi sebagai argumen.

```cpp
template<typename T>class LinkedListNode : public System::Object
```

### Parameter templat

| Parameter | Deskripsi |
| --- | --- |
| T | Tipe nilai yang disimpan. |
