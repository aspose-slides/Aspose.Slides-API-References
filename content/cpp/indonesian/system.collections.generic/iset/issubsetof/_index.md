## ISet::IsSubsetOf(IEnumerablePtr) metode

Memeriksa apakah set saat ini merupakan subset dari kontainer lain.

```cpp
virtual bool System::Collections::Generic::ISet<T>::IsSubsetOf(IEnumerablePtr other)=0
```

### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| other | [IEnumerablePtr](../ienumerableptr/) | Superset yang akan diperiksa. |

### Nilai Kembali

True jika semua elemen dalam set saat ini terdapat dalam **other**, false sebaliknya.
