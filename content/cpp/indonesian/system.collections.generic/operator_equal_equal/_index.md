## System::Collections::Generic::operator==(const KeyValuePair\<TKey, TValue\>\&, const KeyValuePair\<TKey, TValue\>\&) fungsi


Membandingkan dua pasangan kunci-nilai menggunakan semantik 'equals'. Menggunakan operator == atau metode EqualsTo untuk kedua kunci dan nilai, mana yang didefinisikan.

```cpp
template<typename TKey,typename TValue> bool System::Collections::Generic::operator==(const KeyValuePair<TKey, TValue> &left, const KeyValuePair<TKey, TValue> &right)
```

| TValue | Tipe nilai. |

### Argumen

| Parameter | Tipe | Deskripsi |

| left | const [KeyValuePair](../keyvaluepair/)\<TKey, TValue\>\& | Operand LHS. |
| right | const [KeyValuePair](../keyvaluepair/)\<TKey, TValue\>\& | Operand RHS. |

### Nilai Kembalian

True jika kedua kunci dan nilai cocok, false sebaliknya.
