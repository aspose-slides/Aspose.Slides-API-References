## Details_ReflectionTypeLoadException kelas


ReflectionTypeLoadException dilemparkan oleh metode Module.GetTypes jika ada kelas dalam modul yang gagal dimuat. Jangan pernah membuat instance kelas ini secara manual. Gunakan kelas ReflectionTypeLoadException sebagai gantinya. Jangan pernah membungkus instance kelas ReflectionTypeLoadException ke dalam [System::SmartPtr](../../system/smartptr/).

```cpp
class Details_ReflectionTypeLoadException : public System::Details_Exception
```
