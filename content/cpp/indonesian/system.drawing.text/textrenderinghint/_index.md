## TextRenderingHint enum

Specifies the quality of text rendering.

```cpp
enum class TextRenderingHint
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| SystemDefault | 0 | Glyph dengan petunjuk rendering default sistem. |
| SingleBitPerPixelGridFit | 1 | Glyph bitmap dengan petunjuk. |
| SingleBitPerPixel | 2 | Glyph bitmap tanpa petunjuk. |
| AntiAliasGridFit | 3 | Anti-aliasing dengan petunjuk. |
| AntiAlias | 4 | Glyph bitmap anti-alias tanpa petunjuk. |
| ClearTypeGridFit | 5 | Glyph CT bitmap dengan petunjuk. |
