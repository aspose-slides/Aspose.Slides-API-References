## Enum LineCap

Menunjukkan gaya penutup yang tersedia yang dapat digunakan oleh objek [Pen](../../system.drawing/pen/) untuk mengakhiri sebuah garis.

```cpp
enum class LineCap
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Flat | 0 | Penutup garis datar. |
| Square | 1 | Penutup garis persegi. |
| Round | 2 | Penutup garis bulat. |
| Triangle | 3 | Penutup garis segitiga. |
| NoAnchor | 16 | Tidak ada jangkar. |
| SquareAnchor | 17 | Penutup garis jangkar persegi. |
| RoundAnchor | 18 | Penutup garis jangkar bulat. |
| DiamondAnchor | 19 | Penutup gambar jangkar wajik. |
| ArrowAnchor | 20 | Penutup gambar jangkar panah. |
| AnchorMask | 240 | Masker yang digunakan untuk memeriksa apakah penutup garis adalah penutup jangkar. |
| Custom | 255 | Penutup khusus. |
