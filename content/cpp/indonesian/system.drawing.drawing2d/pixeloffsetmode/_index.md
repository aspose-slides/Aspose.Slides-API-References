## PixelOffsetMode enum

Menentukan bagaimana piksel di-offset saat dirender.

```cpp
enum class PixelOffsetMode
```

### Nilai

| Name | Value | Description |
| --- | --- | --- |
| Invalid | n/a | Nilai tidak valid. |
| Default | n/a | Mode default. |
| HighSpeed | n/a | Mode kualitas rendah (kinerja tinggi). |
| HighQuality | n/a | Mode kualitas tinggi (kinerja lebih rendah). |
| None | n/a | Tidak ada offset piksel. |
| Half | n/a | Piksel di-offset sebesar -0.5 unit secara horizontal dan vertikal untuk anti-aliasing kinerja tinggi. |
