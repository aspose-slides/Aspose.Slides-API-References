## TimeSpanStyles enum

Menentukan opsi pemformatan yang menyesuaikan parsing string untuk metode yang mengonversi representasi string dari interval waktu menjadi objek Timespan.

```cpp
enum class TimeSpanStyles : int32_t
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| None | 0 | Interval waktu yang direpresentasikan oleh string inptut diinterpretasikan sebagai interval waktu negatif hanya jika tanda minus hadir. |
| AssumeNegative | 1 | Interval waktu yang direpresentasikan oleh string inptut diinterpretasikan sebagai interval waktu negatif selalu. |
