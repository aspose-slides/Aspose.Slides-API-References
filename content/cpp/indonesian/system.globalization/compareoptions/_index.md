### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| None | 0 | Tidak ada opsi khusus. |
| IgnoreCase | 1 | Abaikan huruf besar/kecil. |
| IgnoreNonSpace | 2 | Abaikan karakter penggabungan non-spasi, misalnya diakritik. |
| IgnoreSymbols | 4 | Sertakan spasi, tanda baca, dan sebagainya. |
| IgnoreKanaType | 8 | Abaikan jenis kana (Jepang). |
| IgnoreWidth | 16 | Abaikan lebar karakter ketika membandingkan string. |

| StringSort | 536870912 | Gunakan algoritma pengurutan string untuk membandingkan karakter. |
