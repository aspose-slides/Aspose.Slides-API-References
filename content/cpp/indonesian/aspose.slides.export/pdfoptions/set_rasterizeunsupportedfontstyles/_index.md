## PdfOptions::set_RasterizeUnsupportedFontStyles(bool) metode


Menunjukkan apakah teks harus dirasterkan sebagai bitmap dan disimpan ke PDF ketika font tidak mendukung gaya tebal. Pendekatan ini dapat meningkatkan kualitas teks dalam PDF yang dihasilkan untuk beberapa font tertentu. Tulis **bool**.

```cpp
void Aspose::Slides::Export::PdfOptions::set_RasterizeUnsupportedFontStyles(bool value) override
```

## Catatan


Nilai default adalah **false**.
