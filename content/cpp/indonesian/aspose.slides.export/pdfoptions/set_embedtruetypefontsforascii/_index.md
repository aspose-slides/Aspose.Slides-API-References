## PdfOptions::set_EmbedTrueTypeFontsForASCII(bool) metode


Menentukan apakah [Aspose.Slides](../../../aspose.slides/) akan menyematkan font umum untuk teks ASCII (rentang kode 33..127). [Fonts](../../../aspose.slides/fonts/) untuk kode karakter yang lebih besar dari 127 selalu disematkan. Daftar font umum mencakup 14 font dasar PDF dan font tambahan yang ditentukan pengguna. Tulis **bool**.

```cpp
void Aspose::Slides::Export::PdfOptions::set_EmbedTrueTypeFontsForASCII(bool value) override
```

## Catatan


Nilai baku adalah **true**.
