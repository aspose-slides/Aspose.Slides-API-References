## PdfOptions::set_JpegQuality(uint8_t) metode

Menetapkan nilai yang menentukan kualitas gambar JPEG di dalam dokumen PDF. Tulis **uint8_t**.

```cpp
void Aspose::Slides::Export::PdfOptions::set_JpegQuality(uint8_t value) override
```

## Keterangan

Berpengaruh hanya ketika dokumen berisi gambar JPEG.

Gunakan properti ini untuk mendapatkan atau mengatur kualitas gambar di dalam dokumen saat menyimpan dalam format PDF. Nilainya dapat bervariasi dari 0 hingga 100 dimana 0 berarti kualitas terburuk tetapi kompresi maksimum dan 100 berarti kualitas terbaik tetapi kompresi minimum.

Nilai default adalah **100**.
