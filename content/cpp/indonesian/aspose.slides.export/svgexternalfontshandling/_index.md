## SvgExternalFontsHandling enum

Mewakili cara menangani font eksternal yang digunakan untuk menggambar teks.

```cpp
enum class SvgExternalFontsHandling
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| AddLinksToFontFiles | 0 | Tambahkan tautan ke file font terpisah ke bagian style dari file SVG. |
| Embed | 1 | Simpan data font langsung ke file SVG. Harap periksa semua perjanjian lisensi font eksternal sebelum menggunakan opsi ini. |
| Vectorize | 2 | Simpan semua teks yang menggunakan font eksternal sebagai grafik. |
