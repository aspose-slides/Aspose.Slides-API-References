## MarkdownSaveOptions::set_HandleRepeatedSpaces(Aspose::Slides::Export::HandleRepeatedSpaces) metode


Menentukan bagaimana karakter spasi biasa yang berulang harus diproses selama ekspor Markdown.

```cpp
void Aspose::Slides::Export::MarkdownSaveOptions::set_HandleRepeatedSpaces(Aspose::Slides::Export::HandleRepeatedSpaces value)
```

## Catatan


Properti ini menentukan apakah spasi berurutan adalah:* dipertahankan sebagai karakter spasi biasa,
* berganti antara spasi biasa dan entitas spasi tak terputus (**&nbsp;**),
* atau sepenuhnya diganti (setelah yang pertama) dengan **&nbsp;** untuk mempertahankan penyelarasan visual dalam output Markdown.



Nilai default adalah [HandleRepeatedSpaces::AlternateSpacesToNbsp](../../handlerepeatedspaces/).
