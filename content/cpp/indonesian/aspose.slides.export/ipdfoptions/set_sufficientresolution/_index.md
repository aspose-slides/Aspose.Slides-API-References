## IPdfOptions::set_SufficientResolution(float) metode


Menetapkan nilai yang menentukan resolusi gambar di dalam dokumen PDF.

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_SufficientResolution(float value)=0
```

## Catatan


Properti memengaruhi ukuran file, waktu ekspor, dan kualitas gambar.

Nilai default adalah **96**.

Pengaruh parameter ini tergantung pada beberapa faktor. Algoritma berusaha mendapatkan ukuran gambar output terbaik berdasarkan nilai properti, ukuran gambar sumber, dan ukuran bingkai gambar. Penggunaan nilai properti yang serupa dapat menghasilkan hasil yang sama. Disarankan menggunakan langkah 16 atau 32 untuk mendapatkan efek yang terlihat.

Tuliskan **float**.
