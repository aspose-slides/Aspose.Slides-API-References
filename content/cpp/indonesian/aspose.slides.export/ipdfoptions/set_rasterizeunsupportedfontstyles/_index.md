## IPdfOptions::set_RasterizeUnsupportedFontStyles(bool) method


Menunjukkan apakah teks harus di rasterisasi sebagai bitmap dan disimpan ke PDF ketika font tidak mendukung gaya tebal. Pendekatan ini dapat meningkatkan kualitas teks dalam PDF yang dihasilkan untuk font tertentu. Tulis **bool**.

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_RasterizeUnsupportedFontStyles(bool value)=0
```

## Catatan


Nilai default adalah **false**.
