## IPdfOptions::set_BestImagesCompressionRatio(bool) metode

Menunjukkan apakah kompresi paling efektif (alih-alih yang default) untuk setiap gambar harus dipilih secara otomatis. Jika diatur ke **bool**.true, untuk setiap gambar dalam presentasi algoritma kompresi yang paling tepat akan dipilih, yang akan menghasilkan ukuran PDF akhir yang lebih kecil.

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_BestImagesCompressionRatio(bool value)=0
```

## Catatan

Pemilihan rasio kompresi gambar terbaik memerlukan biaya komputasi yang tinggi dan membutuhkan tambahan RAM, dan opsi ini secara default **bool**.false.

Nilai default **bool**.false.
