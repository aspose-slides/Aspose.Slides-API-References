## IPdfOptions::get_JpegQuality() metode


Mengembalikan nilai yang menentukan kualitas gambar JPEG dalam dokumen PDF. Baca **uint8_t**.

```cpp
virtual uint8_t Aspose::Slides::Export::IPdfOptions::get_JpegQuality()=0
```

## Keterangan


Berpengaruh hanya ketika dokumen berisi gambar JPEG.

Gunakan properti ini untuk mendapatkan atau mengatur kualitas gambar dalam dokumen saat menyimpan dalam format PDF. Nilai dapat berkisar dari 0 hingga 100 dimana 0 berarti kualitas terburuk tetapi kompresi maksimum dan 100 berarti kualitas terbaik tetapi kompresi minimum.

Nilai default adalah **100**.
