## IPdfOptions::set_JpegQuality(uint8_t) method

Mengatur nilai yang menentukan kualitas gambar JPEG di dalam dokumen PDF. Tulis **uint8_t**.

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_JpegQuality(uint8_t value)=0
```

## Catatan

Berpengaruh hanya ketika dokumen berisi gambar JPEG.

Gunakan properti ini untuk mendapatkan atau mengatur kualitas gambar di dalam dokumen saat menyimpan dalam format PDF. Nilai dapat bervariasi dari 0 hingga 100 di mana 0 berarti kualitas terburuk tetapi kompresi maksimal dan 100 berarti kualitas terbaik tetapi kompresi minimal.

Nilai default adalah **100**.
