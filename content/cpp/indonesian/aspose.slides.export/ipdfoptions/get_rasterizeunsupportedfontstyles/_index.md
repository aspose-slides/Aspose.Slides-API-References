## IPdfOptions::get_RasterizeUnsupportedFontStyles() metode

Menunjukkan apakah teks harus di rasterkan sebagai bitmap dan disimpan ke PDF ketika font tidak mendukung gaya tebal. Pendekatan ini dapat meningkatkan kualitas teks dalam PDF yang dihasilkan untuk font tertentu. Baca **bool**.

```cpp
virtual bool Aspose::Slides::Export::IPdfOptions::get_RasterizeUnsupportedFontStyles()=0
```

## Catatan

Nilai default adalah **false**.
