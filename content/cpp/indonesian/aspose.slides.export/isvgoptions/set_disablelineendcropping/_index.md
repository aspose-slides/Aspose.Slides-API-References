## ISVGOptions::set_DisableLineEndCropping(bool) metode

SVG 1.1 tidak memiliki kemampuan untuk mendefinisikan inset untuk penanda. [Aspose.Slides](../../../aspose.slides/) mesin penulisan SVG memiliki solusi untuk masalah itu: ia memotong ujung garis dengan panah, sehingga garis tidak tumpang tindih dengan penanda. Opsi ini mematikan perilaku tersebut. Tulis **bool**.

virtual void Aspose::Slides::Export::ISVGOptions::set_DisableLineEndCropping(bool value)=0
