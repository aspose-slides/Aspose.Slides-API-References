## ISVGOptions::get_DisableLineEndCropping() metode

SVG 1.1 tidak memiliki kemampuan untuk mendefinisikan inset untuk penanda. [Aspose.Slides](../../../aspose.slides/) Mesin penulisan SVG memiliki solusi untuk masalah tersebut: ia memotong ujung garis dengan panah, sehingga garis tidak tumpang tindih dengan penanda. Opsi ini mematikan perilaku tersebut. Baca **bool**.

```cpp
virtual bool Aspose::Slides::Export::ISVGOptions::get_DisableLineEndCropping()=0
```
