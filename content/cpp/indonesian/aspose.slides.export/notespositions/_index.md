## NotesPositions enum

Mewakili aturan untuk merender catatan ke dalam dokumen yang diekspor

```cpp
enum class NotesPositions
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| None | 0 | Menentukan bahwa catatan tidak boleh ditampilkan sama sekali. |
| BottomFull | 1 | Menentukan bahwa catatan harus ditampilkan sepenuhnya menggunakan halaman tambahan sesuai kebutuhan. |
| BottomTruncated | 2 | Menentukan bahwa catatan harus ditampilkan hanya pada satu halaman. |
