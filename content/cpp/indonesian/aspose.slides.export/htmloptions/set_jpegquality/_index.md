## HtmlOptions::set_JpegQuality(uint8_t) metode

Mengatur nilai yang menentukan kualitas gambar JPEG di dalam dokumen PDF. Tulis **uint8_t**.

```cpp
void Aspose::Slides::Export::HtmlOptions::set_JpegQuality(uint8_t value) override
```

## Catatan

Berpengaruh hanya ketika dokumen berisi gambar JPEG.

Gunakan properti ini untuk mendapatkan atau menetapkan kualitas gambar di dalam dokumen saat menyimpan dalam format PDF. Nilai dapat berkisar dari 0 hingga 100 dimana 0 berarti kualitas terburuk tetapi kompresi maksimum dan 100 berarti kualitas terbaik tetapi kompresi minimum.

Nilai default adalah **95**.
