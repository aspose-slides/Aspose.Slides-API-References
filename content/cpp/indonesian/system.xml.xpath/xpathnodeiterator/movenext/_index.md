## XPathNodeIterator::MoveNext() metode

Ketika di-override dalam kelas turunan, memindahkan objek [XPathNavigator](../../xpathnavigator/) yang dikembalikan oleh metode [XPathNodeIterator::get_Current](../get_current/) ke node berikutnya dalam set node yang dipilih.

```cpp
virtual bool System::Xml::XPath::XPathNodeIterator::MoveNext()=0
```

### Nilai Kembalian

**true** jika objek [XPathNavigator](../../xpathnavigator/) berpindah ke node berikutnya; **false** jika tidak ada lagi node yang dipilih.
