## XPathNavigator::MoveToParent() metode


Ketika dioverride di kelas turunan, memindahkan [XPathNavigator](../) ke node induk dari node saat ini.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToParent()=0
```


### Nilai Kembali

**true** jika [XPathNavigator](../) berhasil berpindah ke node induk dari node saat ini; jika tidak, **false**. Jika **false**, posisi [XPathNavigator](../) tidak berubah.
