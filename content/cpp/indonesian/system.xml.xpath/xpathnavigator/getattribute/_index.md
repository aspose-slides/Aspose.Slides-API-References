## XPathNavigator::GetAttribute(String, String) method

Mengembalikan nilai atribut dengan nama lokal dan namespace URI yang ditentukan.

```cpp
virtual String System::Xml::XPath::XPathNavigator::GetAttribute(String localName, String namespaceURI)
```

### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| localName | [String](../../../system/string/) | Nama lokal dari atribut. **localName** bersifat case-sensitive. |
| namespaceURI | [String](../../../system/string/) | Namespace URI dari atribut. |

### Nilai Kembalian

Sebuah [String](../../../system/string/) yang berisi nilai atribut yang ditentukan; [String::Empty](../../../system/string/empty/) jika atribut yang cocok tidak ditemukan, atau jika [XPathNavigator](../) tidak diposisikan pada node elemen.
