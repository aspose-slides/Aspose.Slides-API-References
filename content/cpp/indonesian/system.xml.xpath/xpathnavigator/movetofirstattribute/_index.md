## XPathNavigator::MoveToFirstAttribute() metode

Ketika di-override dalam kelas turunan, memindahkan [XPathNavigator](../) ke atribut pertama pada node saat ini.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToFirstAttribute()=0
```

### Nilai Kembalian

**true** jika [XPathNavigator](../) berhasil berpindah ke atribut pertama dari node saat ini; sebaliknya, **false**. Jika **false**, posisi [XPathNavigator](../) tidak berubah.
