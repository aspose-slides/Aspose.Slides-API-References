## XPathNavigator::AppendChildElement(String, String, String, String) metode

Membuat node elemen anak baru di akhir daftar node anak dari node saat ini menggunakan awalan namespace, nama lokal, dan URI namespace yang ditentukan dengan nilai yang diberikan.

```cpp
virtual void System::Xml::XPath::XPathNavigator::AppendChildElement(String prefix, String localName, String namespaceURI, String value)
```

### Arguments

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| prefix | [String](../../../system/string/) | Awalan namespace dari node elemen anak baru (jika ada). |
| localName | [String](../../../system/string/) | Nama lokal dari node elemen anak baru (jika ada). |
| namespaceURI | [String](../../../system/string/) | URI namespace dari node elemen anak baru (jika ada). [String::Empty](../../../system/string/empty/) dan **nullptr** adalah ekuivalen. |
| value | [String](../../../system/string/) | Nilai dari node elemen anak baru. Jika [String::Empty](../../../system/string/empty/) atau **nullptr** diberikan, elemen kosong akan dibuat. |
