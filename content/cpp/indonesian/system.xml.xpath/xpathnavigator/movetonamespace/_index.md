## XPathNavigator::MoveToNamespace(String) metode

Memindahkan [XPathNavigator](../) ke node namespace dengan awalan namespace yang ditentukan.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToNamespace(String name)
```

### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| name | [String](../../../system/string/) | Awalan namespace dari node namespace. |

### Nilai Kembalian

**true** jika [XPathNavigator](../) berhasil dipindahkan ke namespace yang ditentukan; **false** jika node namespace yang cocok tidak ditemukan, atau jika [XPathNavigator](../) tidak diposisikan pada node elemen. Jika **false**, posisi [XPathNavigator](../) tidak berubah.
