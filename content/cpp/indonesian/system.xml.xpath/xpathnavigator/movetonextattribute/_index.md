## XPathNavigator::MoveToNextAttribute() metode


Ketika dioverride dalam kelas turunan, memindahkan [XPathNavigator](../) ke atribut berikutnya.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToNextAttribute()=0
```


### Nilai Kembalian

**true** jika [XPathNavigator](../) berhasil berpindah ke atribut berikutnya; **false** jika tidak ada lagi atribut. Jika **false**, posisi [XPathNavigator](../) tidak berubah.
