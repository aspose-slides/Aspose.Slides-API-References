Memindahkan [XPathNavigator](../) ke atribut dengan nama lokal dan namespace URI yang cocok.


### Argumen

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| localName | [String](../../../system/string/) | Nama lokal atribut. |
| namespaceURI | [String](../../../system/string/) | URI namespace atribut; **nullptr** untuk namespace kosong. |

### Nilai Kembalian
