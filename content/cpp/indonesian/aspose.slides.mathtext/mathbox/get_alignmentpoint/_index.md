## MathBox::get_AlignmentPoint() metode

Ketika bernilai true, emulator operator ini berfungsi sebagai titik penyelarasan; yaitu, titik penyelarasan yang ditentukan dalam persamaan lain dapat diselaraskan dengannya. Bawaan: false

```cpp
bool Aspose::Slides::MathText::MathBox::get_AlignmentPoint() override
```

## Keterangan

Contoh: 
```cpp
auto box = System::MakeObject<MathematicalText>(u"==")->ToBox();
box->set_AlignmentPoint(true);
```
