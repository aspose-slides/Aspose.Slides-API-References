## MathBox::set_NoBreak(bool) metode


Tidak terputus Properti ini menentukan properti \"unbreakable\" pada kotak objek. Ketika true, tidak ada jeda baris yang dapat terjadi dalam kotak. Ini dapat penting untuk emulator operator yang terdiri dari lebih dari satu operator biner. Ketika elemen ini tidak ditentukan, jeda dapat terjadi di dalam kotak. Default: true

```cpp
void Aspose::Slides::MathText::MathBox::set_NoBreak(bool value) override
```

## Catatan


Contoh: 
```cpp
auto box = System::MakeObject<MathBox>(System::MakeObject<MathematicalText>(u"*****"));
box->set_NoBreak(false);
```
