## MathPhantom::set_ZeroAsc(bool) metode

Menetapkan nilai yang menunjukkan apakah ascent (tinggi di atas baseline) elemen dasar harus diperlakukan sebagai nol.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_ZeroAsc(bool value) override
```

## Catatan

Ketika **true**, phantom tidak menaikkan baseline dari baris matematika di sekitarnya. Berkorespondensi dengan atribut OMML **m:zeroAsc**.
