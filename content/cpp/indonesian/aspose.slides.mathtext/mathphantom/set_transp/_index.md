## MathPhantom::set_Transp(bool) metode

Mengatur nilai yang menunjukkan apakah phantom transparan untuk aturan spasi berbasis kelas.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_Transp(bool value) override
```

## Catatan

Ketika **true**, operator dan simbol di dalam phantom masih memengaruhi spasi matematis di sekitar phantom (seolah terlihat). Ketika **false**, spasi berbasis kelas diabaikan. Berkorespondensi dengan atribut OMML **m:transp**.
