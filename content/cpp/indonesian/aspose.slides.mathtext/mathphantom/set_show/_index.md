## MathPhantom::set_Show(bool) method

Mengatur nilai yang menunjukkan apakah elemen dasar ditampilkan.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_Show(bool value) override
```

## Catatan

Ketika **false**, elemen dasar disembunyikan tetapi masih dapat menempati ruang tergantung pada pengaturan phantom lain. Berkorespondensi dengan atribut OMML **m:show**.
