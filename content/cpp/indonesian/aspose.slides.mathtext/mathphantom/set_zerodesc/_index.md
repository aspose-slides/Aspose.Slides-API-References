## MathPhantom::set_ZeroDesc(bool) metode


Menetapkan nilai yang menunjukkan apakah penurunan (kedalaman di bawah garis dasar) elemen dasar harus diperlakukan sebagai nol.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_ZeroDesc(bool value) override
```

## Catatan


Ketika **true**, phantom tidak menurunkan garis dasar dari baris matematika di sekitarnya. Mengacu pada atribut OMML **m:zeroDesc**.
