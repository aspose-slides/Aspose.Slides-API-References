## MathBorderBox::set_StrikethroughBottomLeftToTopRight(bool) metode


Strikethrough Bottom-Left to Top-Right (default adalah false). Menentukan keadaan tersembunyi atau ditampilkan dari garis diagonal coret dari sudut kiri-bawah ke sudut kanan-atas border box.

```cpp
void Aspose::Slides::MathText::MathBorderBox::set_StrikethroughBottomLeftToTopRight(bool value) override
```

## Catatan


Contoh: 
```cpp
auto borderBox = System::MakeObject<MathBorderBox>(System::MakeObject<MathematicalText>(u"x"));
borderBox->set_StrikethroughBottomLeftToTopRight(true);
```
