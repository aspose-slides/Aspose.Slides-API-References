## MathBorderBox::get_StrikethroughTopLeftToBottomRight() metode

Garis coret dari kiri atas ke kanan bawah (default adalah false). Menentukan status tersembunyi atau ditampilkan dari garis diagonal coret dari sudut kiri atas ke sudut kanan bawah kotak batas.

```cpp
bool Aspose::Slides::MathText::MathBorderBox::get_StrikethroughTopLeftToBottomRight() override
```

## Catatan

Contoh:
```cpp
auto borderBox = System::MakeObject<MathBorderBox>(System::MakeObject<MathematicalText>(u"x"));
borderBox->set_StrikethroughTopLeftToBottomRight(true);
```
