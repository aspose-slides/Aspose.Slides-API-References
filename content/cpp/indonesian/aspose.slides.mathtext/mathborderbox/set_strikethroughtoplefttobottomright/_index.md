## MathBorderBox::set_StrikethroughTopLeftToBottomRight(bool) metode


Strikethrough Top-Left to Bottom-Right (default is false). Menentukan keadaan tersembunyi atau ditampilkan dari garis diagonal coret yang menghubungkan sudut kiri atas ke sudut kanan bawah dari kotak border.

```cpp
void Aspose::Slides::MathText::MathBorderBox::set_StrikethroughTopLeftToBottomRight(bool value) override
```

## Catatan


Contoh: 
```cpp
auto borderBox = System::MakeObject<MathBorderBox>(System::MakeObject<MathematicalText>(u"x"));
borderBox->set_StrikethroughTopLeftToBottomRight(true);
```
