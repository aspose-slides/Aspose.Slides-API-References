## IMathBorderBox::set_StrikethroughTopLeftToBottomRight(bool) metode

Garis coret dari kiri atas ke kanan bawah (default adalah false). Menentukan keadaan tersembunyi atau ditampilkan dari garis diagonal coret dari sudut kiri atas ke sudut kanan bawah kotak batas.

```cpp
virtual void Aspose::Slides::MathText::IMathBorderBox::set_StrikethroughTopLeftToBottomRight(bool value)=0
```

## Keterangan

Contoh:
```cpp
auto borderBox = System::MakeObject<MathematicalText>(u"x+y+z")->ToBorderBox();
borderBox->set_StrikethroughTopLeftToBottomRight(true);
```
