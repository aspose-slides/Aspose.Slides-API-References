## IMathBorderBox::set_StrikethroughBottomLeftToTopRight(bool) metode

Strikethrough Bottom-Left to Top-Right (default is false). Menentukan status tersembunyi atau ditampilkan dari garis diagonal strikethrough dari sudut kiri-bawah ke sudut kanan-atas kotak batas.

```cpp
virtual void Aspose::Slides::MathText::IMathBorderBox::set_StrikethroughBottomLeftToTopRight(bool value)=0
```

## Catatan

Contoh:
```cpp
auto borderBox = System::MakeObject<MathematicalText>(u"x+y+z")->ToBorderBox();
borderBox->set_StrikethroughBottomLeftToTopRight(true);
```
