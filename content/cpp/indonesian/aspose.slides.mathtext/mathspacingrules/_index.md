## MathSpacingRules enum

Jenis celah (jarak horizontal) antara kolom matriks

```cpp
enum class MathSpacingRules
```

### Values

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| SingleSpacingGap | 0 | Tunggal (1 em untuk kolom atau 1 baris untuk baris) |
| OneAndHalfSpacingGap | 1 | Satu setengah (1.5 em untuk kolom atau 1.5 baris untuk baris) |
| DoubleSpacingGap | 2 | Spasi ganda (2 em untuk kolom atau 2 baris untuk baris) |
| Exactly | 3 | Nilai tepat Untuk kolom, gunakan nilai ColumnGap, diukur dalam twip. Untuk baris, gunakan nilai RowGap, diukur dalam twip. |
| Multiple | 4 | Banyak Untuk kolom, gunakan nilai ColumnGap, diukur dalam kenaikan 0.5 em. Untuk baris, gunakan nilai RowGap, diukur dalam baris. |
