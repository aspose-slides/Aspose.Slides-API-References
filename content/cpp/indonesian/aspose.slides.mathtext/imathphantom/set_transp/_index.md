## IMathPhantom::set_Transp(bool) metode

Mengatur nilai yang menunjukkan apakah phantom transparan untuk aturan spasi berbasis kelas.

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_Transp(bool value)=0
```

## Catatan

Saat **true**, operator dan simbol di dalam phantom masih memengaruhi spasi matematis di sekitar phantom (seolah terlihat). Saat **false**, spasi berbasis kelas diabaikan. Mengacu pada atribut OMML **m:transp**.
