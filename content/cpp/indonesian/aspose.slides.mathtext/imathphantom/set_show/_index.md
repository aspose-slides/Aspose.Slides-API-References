## IMathPhantom::set_Show(bool) method

Mengatur nilai yang menunjukkan apakah elemen dasar ditampilkan.

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_Show(bool value)=0
```

## Catatan

Saat **false**, elemen dasar disembunyikan tetapi masih dapat menempati ruang tergantung pada pengaturan phantom lainnya. Mengacu pada atribut OMML **m:show**.
