## IMathPhantom::set_ZeroDesc(bool) metode


Mengatur nilai yang menunjukkan apakah penurunan (kedalaman di bawah garis dasar) dari elemen dasar harus diperlakukan sebagai nol.

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_ZeroDesc(bool value)=0
```

## Catatan


Ketika **true**, phantom tidak menurunkan garis dasar dari baris matematika di sekitarnya. Mengacu pada atribut OMML **m:zeroDesc**.
