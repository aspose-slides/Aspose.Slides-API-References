## IEnumeratorImplValueType::MoveNext() method


Memindahkan enumerator ke elemen berikutnya. Jika tidak ada elemen yang pernah direferensikan sebelumnya, menetapkan referensi ke elemen pertama yang tersedia. Jika akhir kontainer tercapai, tidak melakukan apa-apa.

```cpp
virtual bool System::Collections::IEnumeratorImplValueType<T>::MoveNext() override
```


### Nilai Kembali

True jika ada elemen yang tersedia setelah pemanggilan, false jika tidak.
