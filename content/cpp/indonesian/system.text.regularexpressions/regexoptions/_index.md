## RegexOptions enum


[Regex](../regex/) options.

```cpp
enum class RegexOptions
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| None | 0 | Perilaku default. |
| Compiled | 1 | Kompilasi regex untuk kinerja. Selalu dilakukan secara default. |
| CultureInvariant | 2 | Gunakan pencocokan yang tidak tergantung budaya. Diabaikan. |
| ECMAScript | 4 | Gunakan sintaks ECMAScript. Diabaikan. |
| ExplicitCapture | 8 | Hanya penangkapan eksplisit. Diabaikan. |
| IgnoreCase | 16 | Abaikan huruf besar/kecil saat pencocokan. |
| IgnorePatternWhitespace | 32 | Abaikan spasi putih dalam pola. Tidak didukung. |
| Multiline | 64 | Anggap '^' dan '$' sebagai awal dan akhir baris, bukan seluruh string. |
| RightToLeft | 128 | Pencocokan kanan-ke-kiri. Tidak didukung. |
| Singleline | 256 | Membuat '.' cocok dengan karakter apa pun tanpa pengecualian (biasanya, karakter baris baru tidak cocok). |
