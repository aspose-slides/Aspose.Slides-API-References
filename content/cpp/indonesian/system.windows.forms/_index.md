## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [Control](./control/) | Kelas dummy untuk membuat kode terjemahan yang menggunakan kelas [Control](./control/) dapat dikompilasi. Metode tidak diimplementasikan. Objek kelas ini hanya boleh dialokasikan menggunakan fungsi [System::MakeObject()](../system/makeobject/). Jangan pernah membuat instance tipe ini di stack atau menggunakan operator new, karena akan menghasilkan kesalahan runtime dan/atau kesalahan asersi. Selalu bungkus kelas ini ke dalam pointer [System::SmartPtr](../system/smartptr/) dan gunakan pointer ini untuk melewatkannya ke fungsi sebagai argumen. |
