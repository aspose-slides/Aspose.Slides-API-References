## AutoSizeMode enum

Defines how autosize works.


### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| GrowAndShrink | 0 | [Control](../control/) tumbuh dan menyusut sesuai kebutuhan. Tidak dapat diubah ukurannya secara manual. |
