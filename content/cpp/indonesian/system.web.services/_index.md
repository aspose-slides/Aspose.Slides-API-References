## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [Soap](./soap/) | Berisi konstanta string SOAP. |
| [Soap12](./soap12/) | Berisi konstanta string SOAP versi 1.2. |
| [WebServiceAttribute](./webserviceattribute/) | Menambahkan informasi tambahan ke layanan XML [Web](../system.web/). Objek dari kelas ini harus hanya dialokasikan menggunakan fungsi [System::MakeObject()](../system/makeobject/). Jangan pernah membuat instance tipe ini di stack atau menggunakan operator new, karena akan menghasilkan kesalahan runtime dan/atau assertion fault. Selalu bungkus kelas ini ke dalam pointer [System::SmartPtr](../system/smartptr/) dan gunakan pointer ini untuk melewatkannya ke fungsi sebagai argumen. |
| [WebServiceBindingAttribute](./webservicebindingattribute/) | Digunakan untuk mendeklarasikan binding yang mendefinisikan satu atau lebih metode dari layanan XML [Web](../system.web/). Objek dari kelas ini harus hanya dialokasikan menggunakan fungsi [System::MakeObject()](../system/makeobject/). Jangan pernah membuat instance tipe ini di stack atau menggunakan operator new, karena akan menghasilkan kesalahan runtime dan/atau assertion fault. Selalu bungkus kelas ini ke dalam pointer [System::SmartPtr](../system/smartptr/) dan gunakan pointer ini untuk melewatkannya ke fungsi sebagai argumen. |
