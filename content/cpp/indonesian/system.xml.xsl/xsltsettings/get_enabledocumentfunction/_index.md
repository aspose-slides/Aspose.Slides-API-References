## XsltSettings::get_EnableDocumentFunction() metode

Mengembalikan nilai yang menunjukkan apakah dukungan untuk fungsi **document()** XSLT diaktifkan.

```cpp
bool System::Xml::Xsl::XsltSettings::get_EnableDocumentFunction()
```

### Nilai Kembalian

**true** untuk mendukung fungsi **document()** XSLT; jika tidak, **false**. Nilai default adalah **false**.
