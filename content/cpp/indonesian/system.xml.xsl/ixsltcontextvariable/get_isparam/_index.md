## IXsltContextVariable::get_IsParam() metode

Mengembalikan nilai yang menunjukkan apakah variabel adalah parameter Extensible Stylesheet Language Transformations (XSLT). Ini dapat menjadi parameter untuk lembar gaya atau templat.

```cpp
virtual bool System::Xml::Xsl::IXsltContextVariable::get_IsParam()=0
```

### Nilai Kembalian

**true** jika variabel adalah parameter XSLT; sebaliknya, **false**.
