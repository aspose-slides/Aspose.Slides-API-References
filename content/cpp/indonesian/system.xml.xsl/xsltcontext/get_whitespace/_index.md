## XsltContext::get_Whitespace() metode


When overridden in a derived class, gets a value indicating whether to include white space nodes in the output.

```cpp
virtual bool System::Xml::Xsl::XsltContext::get_Whitespace()=0
```


### Nilai Kembalian

**true** untuk memeriksa node spasi putih dalam dokumen sumber untuk disertakan dalam output; **false** untuk tidak mengevaluasi node spasi putih. Default-nya adalah **true**.
