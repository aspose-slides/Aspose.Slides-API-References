## Catatan

Menggunakan resolver ini dapat menimbulkan kerentanan ketika file HTML atau SVG yang disediakan klien menyebabkan perangkat lunak server memperoleh file lokal atau jaringan. Gunakan dengan hati-hati. Disarankan agar tidak menentukan [ExternalResourceResolver](./) sama sekali (hanya objek yang disematkan yang akan dibaca) atau membuat beberapa subclass yang memeriksa apakah uri yang ditentukan valid.
