## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [InstanceDescriptor](./instancedescriptor/) | Kelas dummy untuk kode yang menggunakan [InstanceDescriptor](./instancedescriptor/) untuk dikompilasi. Objek dari kelas ini hanya boleh dialokasikan menggunakan fungsi [System::MakeObject()](../system/makeobject/). Jangan pernah membuat instance tipe ini di stack atau menggunakan operator new, karena akan menyebabkan error runtime dan/atau kesalahan asersi. Selalu bungkus kelas ini ke dalam pointer [System::SmartPtr](../system/smartptr/) dan gunakan pointer ini untuk meneruskannya ke fungsi sebagai argumen. |
