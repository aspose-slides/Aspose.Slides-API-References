### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Critical | 1 | Kesalahan fatal atau crash aplikasi. |
| Error | 2 | Kesalahan yang dapat dipulihkan. |
| Warning | 4 | Masalah non-kritis. |
| Information | 8 | Pesan informatif. |
| Verbose | 16 | Jejak debugging. |
| Start | 256 | Mulai operasi logis. |
| Stop | 512 | Menghentikan operasi logis. |
| Suspend | 1024 | Penangguhan operasi logis. |
| Resume | 2048 | Melanjutkan operasi logis. |
| Transfer | 4096 | Perubahan identitas korelasi. |
