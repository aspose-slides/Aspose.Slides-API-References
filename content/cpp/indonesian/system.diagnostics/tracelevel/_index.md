## TraceLevel enum

Menentukan pesan apa yang akan dikeluarkan untuk kelas [System.Diagnostics.Debug](../debug/), [System.Diagnostics.Trace](../trace/) dan System.Diagnostics.TraceSwitch.

```cpp
enum class TraceLevel
```

### Values

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Off | 0 | Tidak mengeluarkan pesan pelacakan dan debugging. |
| Error | 1 | Mengeluarkan pesan penanganan error. |
| Warning | 2 | Mengeluarkan peringatan dan pesan penanganan error. |
| Info | 3 | Mengeluarkan pesan informasional, peringatan, dan pesan penanganan error. |
| Verbose | 4 | Mengeluarkan semua pesan debugging dan tracing. |
