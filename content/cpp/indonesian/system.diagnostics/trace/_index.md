## Trace struct


Menyediakan antarmuka untuk mengakses jejak debugger (jika ada). Hanya berfungsi dalam mode [Debug](../debug/). Ini adalah tipe statis tanpa layanan instansi. Anda tidak boleh pernah membuat instansi darinya dengan cara apa pun.

```cpp
class Trace
```

## Metode

| Metode | Deskripsi |
| --- | --- |
| static void [Flush](./flush/)() | Mengosongkan buffer output, dan menyebabkan data yang di-buffer ditulis ke pendengar. |
| static void [WriteLine](./writeline/)(const [String](../../system/string/)\&) | Menulis baris ke jejak debugger. |
