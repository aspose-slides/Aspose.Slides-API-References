## Debugger struct

[Debugger](./) antarmuka. Ini adalah tipe statis tanpa layanan instance. Anda tidak boleh membuat instance darinya dengan cara apa pun.

```cpp
class Debugger
```

## Metode

| Metode | Deskripsi |
| --- | --- |
| static void [Break](./break/)() | Memulai jeda debugger (jika terpasang). |
| static **bool** [get_IsAttached](./get_isattached/)() | Memeriksa apakah debugger terpasang pada instansi aplikasi saat ini. |
