## enum PaddingMode

Mendefinisikan bagaimana memperlakukan pesan yang lebih pendek daripada blok yang diperlukan oleh operasi kripto.

```cpp
enum class PaddingMode
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| None | 1 | Tidak ada padding. |
| PKCS7 | 2 | Gunakan string padding PKCS #7. |
| Zeros | 3 | Gunakan byte nol. |
| ANSIX923 | 4 | Gunakan string padding ANSIX923. |
| ISO10126 | 5 | Gunakan string padding ISO10126. |
