## HMACSHA512 kelas


Hash-based Message [Authentication](../../system.security.authentication/) Code yang menggunakan fungsi hash [SHA512](../sha512/). Implementasi parsial. Objek dari kelas ini hanya boleh dialokasikan menggunakan fungsi [System::MakeObject()](../../system/makeobject/). Jangan pernah membuat instance tipe ini di stack atau menggunakan operator new, karena akan menghasilkan runtime error dan/atau assertion fault. Selalu bungkus kelas ini ke dalam pointer [System::SmartPtr](../../system/smartptr/) dan gunakan pointer ini untuk melewatkannya ke fungsi sebagai argumen.

```cpp
class HMACSHA512 : public System::Security::Cryptography::HashAlgorithm
```
