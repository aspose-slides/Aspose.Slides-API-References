## XmlDsigC14NTransform kelas


Mewakili transformasi kanonisasi XML C14N untuk tanda tangan digital tanpa komentar. Objek dari kelas ini hanya boleh dialokasikan menggunakan fungsi [System::MakeObject()](../../system/makeobject/). Jangan pernah membuat instance tipe ini di stack atau menggunakan operator new, karena akan mengakibatkan kesalahan runtime dan/atau kegagalan assert. Selalu bungkus kelas ini ke dalam pointer [System::SmartPtr](../../system/smartptr/) dan gunakan pointer ini untuk meneruskannya ke fungsi sebagai argumen.

```cpp
class XmlDsigC14NTransform : public System::Security::Cryptography::Xml::Transform
```
