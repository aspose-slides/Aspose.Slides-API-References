## LoadOptions::set_BlobManagementOptions(System::SharedPtr\<IBlobManagementOptions\>) विधि

Binary Large Objects (BLOBs) को प्रबंधित करने के लिए उपयोग किए जा सकने वाले विकल्पों का प्रतिनिधित्व करता है, जैसे कि अस्थायी फ़ाइलों का उपयोग या मेमोरी में अधिकतम BLOB बाइट्स। ये विकल्प किसी विशिष्ट वातावरण या आवश्यकताओं के लिए सर्वोत्तम प्रदर्शन/स्मृति खपत अनुपात स्थापित करने के लिए डिज़ाइन किए गए हैं।

```cpp
void Aspose::Slides::LoadOptions::set_BlobManagementOptions(System::SharedPtr<IBlobManagementOptions> value) override
```

## टिप्पणियाँ

एक Binary Large Object (BLOB) एक बाइनरी डेटा है जो एकल इकाई के रूप में संग्रहीत होता है - अर्थात् BLOB एक ऑडियो, वीडियो या प्रस्तुति स्वयं हो सकता है।
