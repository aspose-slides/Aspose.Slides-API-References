## CommentCollection::virtualizeEndConstIterator() const विधि

Gets iterator pointing right after the last element (if any)of the const-qualified instance of the collection.

### Return Value

एक iterator जो const-योग्य संग्रह के उदाहरण के अंतिम तत्व (यदि कोई हो) के ठीक बाद इंगित करता है, कंटेनर के अंत के लिए const iterator कार्यान्वयन प्रदान करता है।
