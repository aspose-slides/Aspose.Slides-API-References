## CommentCollection::virtualizeBeginConstIterator() const विधि


पहले तत्व (यदि कोई हो) की ओर इशारा करने वाला iterator प्राप्त करता है, जो संग्रह की const-योग्य instance का पहला तत्व है।

```cpp
virtualized_iterator * Aspose::Slides::CommentCollection::virtualizeBeginConstIterator() const override
```


### Return Value

एक iterator जो पहले तत्व (यदि कोई हो) की ओर इशारा करता है, जो const-योग्य instance का पहला तत्व है। कंटेनर के पहले तत्व के लिए const iterator कार्यान्वयन प्रदान करता है।

नया बनाया गया iterator ऑब्जेक्ट।
