## ILoadOptions::set_BlobManagementOptions(System::SharedPtr\<IBlobManagementOptions\>) विधि


Binary Large Objects (BLOBs) के हैंडलिंग व्यवहार को प्रबंधित करने के लिए उपयोग किए जा सकने वाले विकल्पों का प्रतिनिधित्व करता है, जैसे अस्थायी फ़ाइलों का उपयोग या मेमोरी में अधिकतम BLOB बाइट्स। ये विकल्प किसी विशिष्ट पर्यावरण या आवश्यकताओं के लिए सर्वोत्तम प्रदर्शन/मेमोरी खपत अनुपात सेट करने के उद्देश्य से हैं।

```cpp
virtual void Aspose::Slides::ILoadOptions::set_BlobManagementOptions(System::SharedPtr<IBlobManagementOptions> value)=0
```

## टिप्पणियाँ


Binary Large Object (BLOB) एक बाइनरी डेटा है जिसे एकल इकाई के रूप में संग्रहित किया जाता है - अर्थात् BLOB एक ऑडियो, वीडियो या प्रस्तुति स्वयं हो सकता है।
