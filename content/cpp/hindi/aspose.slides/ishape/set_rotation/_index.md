## IShape::set_Rotation(float) विधि

निर्दिष्ट आकार को z-अक्ष के चारों ओर घुमाए जाने वाले डिग्री की संख्या निर्धारित करता है। एक सकारात्मक मान घड़ी की सुई की दिशा में घुमाव दर्शाता है; एक नकारात्मक मान विपरीत दिशा में घुमाव दर्शाता है। **float** लिखें।

```cpp
virtual void Aspose::Slides::IShape::set_Rotation(float value)=0
```

## टिप्पणी

वापसी मान हमेशा परिभाषित होता है (std::numeric_limits<float>::quiet_NaN() नहीं है)। असाइन किया गया मान परिभाषित होना चाहिए (std::numeric_limits<float>::quiet_NaN() नहीं)। आप RawFrame instance गुणों के लिए अपरिभाषित मान सेट कर सकते हैं।
