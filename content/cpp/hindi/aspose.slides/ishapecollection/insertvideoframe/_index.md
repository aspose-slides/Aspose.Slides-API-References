## IShapeCollection::InsertVideoFrame(int32_t, float, float, float, float, System::String) मेथड

```cpp
virtual System::SharedPtr<IVideoFrame> Aspose::Slides::IShapeCollection::InsertVideoFrame(int32_t index, float x, float y, float width, float height, System::String fname)=0
```

### Arguments

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| index | **int32_t** | वीडियो फ्रेम सम्मिलित करने के लिए शून्य-आधारित अनुक्रमांक। |
| x | **float** | नए वीडियो फ़्रेम का x-निर्देशांक, पॉइंट्स में। |
| y | **float** | नए वीडियो फ़्रेम का y-निर्देशांक, पॉइंट्स में। |
| width | **float** | नए वीडियो फ़्रेम की चौड़ाई, पॉइंट्स में। |
| height | **float** | नए वीडियो फ़्रेम की ऊँचाई, पॉइंट्स में। |
| fname | [System::String](../../../system/string/) | एम्बेड करने के लिए वीडियो फ़ाइल का पाथ या नाम। |

### Return Value

नया बनाया गया [IVideoFrame](../../ivideoframe/)।
