## FillType enum

विभिन्न दृश्य वस्तुओं के आंतरिक भराव प्रकार को निर्दिष्ट करता है।

```cpp
enum class FillType : int8_t
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| NotDefined | -1 | फ़िल प्रकार परिभाषित नहीं है। |
| NoFill | 0 | कोई भराव लागू नहीं किया गया। |
| Solid | 1 | ठोस रंग से भरा हुआ है। |
| Gradient | 2 | भराव ग्रेडिएंट है। |
| Pattern | 3 | दोहराव वाला पैटर्न उपयोग करके वस्तु को भरा जाता है। |
| Picture | 4 | एकल चित्र का उपयोग करके वस्तु को भरा जाता है। |
| Group | 5 | दृश्य वस्तु समूह से भराव गुण विरासत में प्राप्त करता है। |
