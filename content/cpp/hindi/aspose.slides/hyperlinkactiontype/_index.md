## HyperlinkActionType enum

हाइपरलिंक कार्रवाई का एक प्रकार दर्शाता है।

```cpp
enum class HyperlinkActionType
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| Unknown | -1 | अपरिचित कार्रवाई प्रकार। |
| NoAction | 0 | कोई कार्रवाई नहीं। |
| Hyperlink | 1 | सामान्य हाइपरलिंक। |
| JumpFirstSlide | 2 | प्रस्तुति की पहली स्लाइड पर जाएँ। |
| JumpPreviousSlide | 3 | पिछली स्लाइड पर जाएँ। |
| JumpNextSlide | 4 | अगली स्लाइड पर जाएँ। |
| JumpLastSlide | 5 | प्रस्तुति की अंतिम स्लाइड पर जाएँ। |
| JumpEndShow | 6 | स्लाइडशो के अंत पर जाएँ। |
| JumpLastViewedSlide | 7 | अंतिम देखी गई स्लाइड पर जाएँ। |
| JumpSpecificSlide | 8 | विशिष्ट स्लाइड पर जाएँ, जिसे [IHyperlink::get_TargetSlide](../ihyperlink/get_targetslide/) मान द्वारा संदर्भित किया गया है। |
| StartCustomSlideShow | 9 | कस्टम स्लाइडशो शुरू करें। |
| OpenFile | 10 | संदर्भित फ़ाइल खोलें। |
| OpenPresentation | 11 | संदर्भित प्रस्तुति खोलें। |
| StartStopMedia | 12 | मीडिया फ़ाइल चलाना शुरू/रोकें। |
| StartMacro | 13 | मैक्रो स्क्रिप्ट निष्पादित करना शुरू करें। |
| StartProgram | 14 | प्रोग्राम शुरू करें। |
