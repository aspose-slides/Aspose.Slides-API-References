## RegexOptions enum

[Regex](../regex/) विकल्प।
```cpp
enum class RegexOptions
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| None | 0 | डिफ़ॉल्ट व्यवहार। |
| Compiled | 1 | प्रदर्शन के लिए regex संकलित करें। हमेशा डिफ़ॉल्ट रूप से किया जाता है। |
| CultureInvariant | 2 | culture-invariant मिलान का उपयोग करें। अनदेखा किया गया। |
| ECMAScript | 4 | ECMAScript सिंटैक्स का उपयोग करें। अनदेखा किया गया। |
| ExplicitCapture | 8 | केवल स्पष्ट कैप्चरिंग। अनदेखा किया गया। |
| IgnoreCase | 16 | मिलान के समय केस को अनदेखा करें। |
| IgnorePatternWhitespace | 32 | पैटर्न में व्हाइटस्पेस को अनदेखा करें। असमर्थित। |
| Multiline | 64 | '^' और '$' को पूरी स्ट्रिंग के बजाय पंक्ति की शुरुआत और अंत मानें। |
| RightToLeft | 128 | दाएँ से बाएँ मिलान। असमर्थित। |
| Singleline | 256 | '.' को किसी भी कैरेक्टर को बिना अपवाद के मिलाने के लिए बनाता है (आमतौर पर, न्यूलाइन कैरेक्टर मिलाए नहीं जाते)। |
