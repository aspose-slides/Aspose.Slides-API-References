## HttpMessageInvoker क्लास

ऐप्लिकेशन को HTTP हैंडलर श्रृंखला पर Send मेथड को कॉल करने की अनुमति देता है। इस क्लास की ऑब्जेक्ट्स को केवल [System::MakeObject()](../../system/makeobject/) फ़ंक्शन का उपयोग करके ही आवंटित किया जाना चाहिए। इस प्रकार का इंस्टेंस स्टैक पर या operator new का उपयोग करके कभी न बनाएँ, क्योंकि इससे रनटाइम त्रुटियाँ और/या असर्शन त्रुटियाँ उत्पन्न हो सकती हैं। हमेशा इस क्लास को [System::SmartPtr](../../system/smartptr/) पॉइंटर में लपेटें और इस पॉइंटर को फ़ंक्शनों में आर्ग्यूमेंट के रूप में पास करें।

```cpp
class HttpMessageInvoker : public System::IDisposable
```
