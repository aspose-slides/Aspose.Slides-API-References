## DataGrid क्लास

डमी क्लास जो अनुवादित कोड को [DataGrid](./) रेफ़रेंसेज़ के साथ लिंक करने में संभव बनाती है, लेकिन इसे निष्पादित नहीं करती। इसमें कोई सही ढंग से लागू सदस्य नहीं हैं। इस क्लास के ऑब्जेक्ट्स को केवल [System::MakeObject()](../../system/makeobject/) फ़ंक्शन का उपयोग करके आवंटित किया जाना चाहिए। इस प्रकार का इंस्टेंस स्टैक पर या operator new का उपयोग करके कभी बनाएं नहीं, क्योंकि इससे रनटाइम त्रुटियां और/या असेर्शन फॉल्ट्स हो सकते हैं। हमेशा इस क्लास को [System::SmartPtr](../../system/smartptr/) पॉइंटर में लपेटें और इस पॉइंटर का उपयोग करके इसे फ़ंक्शनों के तर्क के रूप में पास करें।

```cpp
class DataGrid : public System::Object
```
