## X500DistinguishedNameFlags enum

X509 प्रमाणपत्र विशिष्ट नाम स्वरूपण नियम।

```cpp
enum class X500DistinguishedNameFlags
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| None | 0 | कोई विशेष विशेषताएँ नहीं। |
| Reversed | 1 | नाम आरक्षित है। |
| UseSemicolons | 16 | सेमीकोलन का उपयोग करें। |
| DoNotUsePlusSign | 32 | नाम प्लस चिह्न का उपयोग नहीं करता। |
| DoNotUseQuotes | 64 | नाम में उद्धरण अक्षम करता है। |
| UseCommas | 128 | कॉमा के उपयोग को सक्षम करता है। |
| UseNewLines | 256 | नयी पंक्तियों के उपयोग को सक्षम करता है। |
| UseUTF8Encoding | 4096 | यूनिकोड से UTF-8 एन्कोडिंग की ओर स्विच करता है। |
| UseT61Encoding | 8192 | T61 एन्कोडिंग पर स्विच करता है। |
| ForceUTF8Encoding | 16384 | निर्दिष्ट X500 कुंजियों के एन्कोड करते समय UTF-8 के उपयोग को बाध्य करता है। |
