## X509KeyStorageFlags enum

परिभाषित करता है कि कुंजी को कैसे संग्रहीत किया जाए।

```cpp
enum class X509KeyStorageFlags : int32_t
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| DefaultKeySet | 0 | डिफ़ॉल्ट कुंजी सेट का उपयोग करें। |
| UserKeySet | 1 | उपयोगकर्ता-संबंधित स्टोर का उपयोग करें, मशीन-स्थानीय के बजाय। |
| MachineKeySet | 2 | स्थानीय मशीन स्टोर का उपयोग करें, उपयोगकर्ता वाले के बजाय। |
| Exportable | 4 | आयातित कुंजियों को निर्यात योग्य के रूप में चिह्नित करता है। |
| UserProtected | 8 | उपयोगकर्ता को सूचित करें कि कुंजी उपयोग में है। |
| PersistKeySet | 16 | प्रमाणपत्र आयात करते समय कुंजी निरंतर रहती है। |
