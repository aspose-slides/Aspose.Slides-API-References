## Enumerable::Range(int32_t, int32_t) मेथड

```cpp
static SharedPtr<Collections::Generic::IEnumerable<int32_t>> System::Linq::Enumerable::Range(int32_t start, int32_t count)
```


### आर्ग्युमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| start | **int32_t** | क्रम में पहले पूर्णांक का मान। |
| count | **int32_t** | उत्पन्न करने के लिए क्रमिक पूर्णांकों की संख्या। |

### वापसी मान

एक IEnumerable **int32_t**'s जो क्रमिक पूर्णाक संख्याओं की सीमा शामिल करता है।
