## TraceLevel enum

निर्दिष्ट करता है कि [System.Diagnostics.Debug](../debug/), [System.Diagnostics.Trace](../trace/) और System.Diagnostics.TraceSwitch वर्गों के लिए कौन से संदेश आउटपुट किए जाने चाहिए।

```cpp
enum class TraceLevel
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| Off | 0 | कोई ट्रेसिंग और डिबगिंग संदेश नहीं आउटपुट करता। |
| Error | 1 | त्रुटि-हैंडलिंग संदेशों को आउटपुट करता है। |
| Warning | 2 | चेतावनियों और त्रुटि-हैंडलिंग संदेशों को आउटपुट करता है। |
| Info | 3 | सूचनात्मक संदेश, चेतावनियाँ और त्रुटि-हैंडलिंग संदेशों को आउटपुट करता है। |
| Verbose | 4 | सभी डिबगिंग और ट्रेसिंग संदेशों को आउटपुट करता है। |
