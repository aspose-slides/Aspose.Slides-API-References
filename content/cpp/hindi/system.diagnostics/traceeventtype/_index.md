## TraceEventType enum

ट्रेस को उत्पन्न करने वाली घटना के प्रकार की पहचान करता है।

```cpp
enum class TraceEventType
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| Critical | 1 | गंभीर त्रुटि या अनुप्रयोग क्रैश। |
| Error | 2 | पुनर्प्राप्ति योग्य त्रुटि। |
| Warning | 4 | गैर-गंभीर समस्या। |
| Information | 8 | सूचनात्मक संदेश। |
| Verbose | 16 | डिबगिंग ट्रेस। |
| Start | 256 | तार्किक संचालन की शुरुआत। |
| Stop | 512 | तार्किक संचालन को रोकना। |
| Suspend | 1024 | तार्किक संचालन का निलंबन। |
| Resume | 2048 | तार्किक संचालन का पुनः आरंभ। |
| Transfer | 4096 | संबंध पहचान में परिवर्तन। |
