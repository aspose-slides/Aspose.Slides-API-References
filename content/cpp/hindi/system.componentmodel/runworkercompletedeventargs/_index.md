## RunWorkerCompletedEventArgs क्लास


An instance of this क्लास is passed as the argument to the RunWorkerCompletedEventHandler delegate. Objects of this क्लास should only be allocated using [System::MakeObject()](../../system/makeobject/) function. Never create instance of this type on स्टैक or using operator new, as it will result in runtime errors and/or assertion faults. Always wrap this क्लास into [System::SmartPtr](../../system/smartptr/) pointer and use this pointer to pass it to functions as argument.

```cpp
class RunWorkerCompletedEventArgs : public System::ComponentModel::AsyncCompletedEventArgs
```
