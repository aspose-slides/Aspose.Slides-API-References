## AsyncCompletedEventArgs क्लास

An instance of this क्लास is passed as the argument on to the AsyncCompletedEventHandler delegate. Objects of this क्लास should only be allocated using [System::MakeObject()](../../system/makeobject/) फ़ंक्शन. Never create instance of this type on stack or using operator new, as it will result in runtime errors and/or assertion faults. Always wrap this क्लास into [System::SmartPtr](../../system/smartptr/) पॉइंटर and use this pointer to pass it to फ़ंक्शन as argument.

```cpp
class AsyncCompletedEventArgs : public System::EventArgs
```
