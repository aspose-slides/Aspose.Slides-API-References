## SignedXml क्लास

XML साइनिंग और वेरिफिकेशन के लिए उपयोग किया जाता है। इस क्लास की ऑब्जेक्ट्स केवल [System::MakeObject()](../../system/makeobject/) फ़ंक्शन का उपयोग करके आवंटित की जानी चाहिए। कभी भी इस प्रकार की इंस्टेंस को स्टैक पर या operator new का उपयोग करके न बनाएँ, क्योंकि इससे रनटाइम त्रुटियां और/या असर्शन फॉल्ट्स हो सकते हैं। हमेशा इस क्लास को [System::SmartPtr](../../system/smartptr/) पॉइंटर में लपेटें और इस पॉइंटर का उपयोग फ़ंक्शनों को आर्ग्यूमेंट के रूप में पास करने के लिए करें।

```cpp
class SignedXml : public System::Object
```
