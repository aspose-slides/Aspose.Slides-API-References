## DSAKeyValue क्लास

यह [DSA](../../system.security.cryptography/dsa/) निजी कुंजी का प्रतिनिधित्व करता है। इस क्लास के ऑब्जेक्ट्स को केवल [System::MakeObject()](../../system/makeobject/) फ़ंक्शन का प्रयोग करके ही आवंटित किया जाना चाहिए। इस प्रकार की इंस्टेंस को स्टैक पर या operator new का उपयोग करके कभी न बनाएं, क्योंकि इससे रनटाइम त्रुटियाँ और/या असर्शन फ़ॉल्ट्स हो सकते हैं। हमेशा इस क्लास को [System::SmartPtr](../../system/smartptr/) पॉइंटर में लपेटें और इस पॉइंटर को फ़ंक्शन्स को आर्ग्यूमेंट के रूप में पास करें।

```cpp
class DSAKeyValue : public System::Security::Cryptography::Xml::KeyInfoClause
```
