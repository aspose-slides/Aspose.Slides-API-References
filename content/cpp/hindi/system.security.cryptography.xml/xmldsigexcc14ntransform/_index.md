## XmlDsigExcC14NTransform वर्ग

डिजिटल हस्ताक्षर के लिए टिप्पणी-रहित एक्सक्लूसिव C14N XML कैनॉनिकलाइज़ेशन ट्रांसफ़ॉर्म का प्रतिनिधित्व करता है।  
इस वर्ग की वस्तुओं को केवल [System::MakeObject()](../../system/makeobject/) फ़ंक्शन का उपयोग करके ही आवंटित किया जाना चाहिए।  
कभी भी इस प्रकार का उदाहरण स्टैक पर या operator new का उपयोग करके न बनाएँ, क्योंकि इससे रनटाइम त्रुटियों और/या असेर्शन दोष उत्पन्न हो सकते हैं।  
हमेशा इस वर्ग को [System::SmartPtr](../../system/smartptr/) पॉइंटर में लपेटें और इस पॉइंटर का उपयोग करके इसे फ़ंक्शन के तर्क के रूप में पास करें।

```cpp
class XmlDsigExcC14NTransform : public System::Security::Cryptography::Xml::Transform
```
