## KeyInfoClause क्लास

All implementations of [KeyInfo](../keyinfo/) subelements must inherit this abstract क्लास. Objects of this क्लास should only be allocated using [System::MakeObject()](../../system/makeobject/) function. Never create instance of this type on stack or using operator new, as it will result in runtime त्रुटियाँ and/or assertion faults. Always wrap this क्लास into [System::SmartPtr](../../system/smartptr/) pointer and use this pointer to pass it to functions as argument.

```cpp
class KeyInfoClause : public System::Object
```
