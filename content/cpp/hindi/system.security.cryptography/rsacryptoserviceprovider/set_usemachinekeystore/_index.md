## RSACryptoServiceProvider::set_UseMachineKeyStore(bool) मेथड

परिभाषित करता है कि कुंजी उपयोगकर्ता स्टोर के बजाय मशीन स्टोर में बनी रहे या नहीं।

```cpp
static void System::Security::Cryptography::RSACryptoServiceProvider::set_UseMachineKeyStore(bool value)
```

### आर्ग्युमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| value | **bool** | True यदि कुंजी को मशीन स्टोर में स्थायी किया जाना चाहिए, false यदि इसे उपयोगकर्ता स्टोर में स्थायी किया जाना चाहिए। |
