## HMACSHA512 क्लास


हैश-आधारित संदेश [Authentication](../../system.security.authentication/) कोड जो [SHA512](../sha512/) हैश फ़ंक्शन का उपयोग करता है। आंशिक रूप से लागू किया गया है। इस क्लास की वस्तुओं को केवल [System::MakeObject()](../../system/makeobject/) फ़ंक्शन का उपयोग करके ही आवंटित किया जाना चाहिए। इस प्रकार का इंस्टेंस स्टैक पर या operator new का उपयोग करके कभी न बनाएँ, क्योंकि इससे रनटाइम त्रुटियाँ और/या असर्शन त्रुटियाँ हो सकती हैं। हमेशा इस क्लास को [System::SmartPtr](../../system/smartptr/) पॉइंटर में लपेटें और इस पॉइंटर को फ़ंक्शन में तर्क के रूप में पास करें।

```cpp
class HMACSHA512 : public System::Security::Cryptography::HashAlgorithm
```
