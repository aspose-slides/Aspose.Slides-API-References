## AsymmetricAlgorithm क्लास

असममित एन्क्रिप्शन एल्गोरिदम के लिए सारभूत बेस क्लास। इस क्लास की वस्तुओं को केवल [System::MakeObject()](../../system/makeobject/) फ़ंक्शन का उपयोग करके ही आवंटित किया जाना चाहिए। कभी भी इस प्रकार का इंस्टेंस स्टैक पर या operator new का उपयोग करके न बनाएँ, क्योंकि इससे रनटाइम त्रुटियाँ और/या असर्शन फ़ॉल्ट हो सकते हैं। हमेशा इस क्लास को [System::SmartPtr](../../system/smartptr/) पॉइंटर में लपेटें और इस पॉइंटर को फ़ंक्शन के तर्क के रूप में पास करें।

```cpp
class AsymmetricAlgorithm : public virtual System::Object,
                            public System::IDisposable
```
