## HMAC क्लास


Hash-based Message [Authentication](../../system.security.authentication/) Code ([HMAC](./)) की सभी कार्यान्वयन को इस सारगर्भित class को विरासत में लेना चाहिए। इस class की वस्तुओं को केवल [System::MakeObject()](../../system/makeobject/) फ़ंक्शन का उपयोग करके ही आवंटित किया जाना चाहिए। इस प्रकार का उदाहरण स्टैक पर या operator new का उपयोग करके कभी न बनाएँ, क्योंकि इससे रनटाइम त्रुटियाँ और/या असर्शन faults उत्पन्न होंगे। हमेशा इस class को [System::SmartPtr](../../system/smartptr/) पॉइंटर में लपेटें और इस पॉइंटर को तर्क के रूप में फ़ंक्शनों में पास करें।

```cpp
class HMAC : public System::Security::Cryptography::HashAlgorithm
```
