## NewLineHandling enum

लाइन ब्रेक को संभालने का तरीका निर्धारित करता है।

```cpp
enum class NewLineHandling
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| Replace | 0 | नई पंक्ति अक्षर को [XmlWriterSettings::set_NewLineChars](../xmlwritersettings/set_newlinechars/) मान में निर्दिष्ट अक्षर से मेल खाने के लिए बदल दिया जाता है। |
| Entitize | 1 | नई पंक्ति अक्षर को एंटिटीज़ किया जाता है। यह सेटिंग सभी अक्षरों को संरक्षित रखती है जब आउटपुट को एक सामान्यीकरण करने वाले [XmlReader](../xmlreader/) द्वारा पढ़ा जाता है। |
| None | 2 | नई पंक्ति अक्षर अपरिवर्तित रहते हैं। आउटपुट इनपुट के समान है। |
