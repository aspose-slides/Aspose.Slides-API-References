## XmlReader::ReadInnerXml() विधि


जब किसी व्युत्पन्न क्लास में ओवरराइड किया जाता है, तो यह सभी सामग्री, जिसमें मार्कअप शामिल है, को एक स्ट्रिंग के रूप में पढ़ता है।

```cpp
virtual String System::Xml::XmlReader::ReadInnerXml()
```


### रिटर्न मान

वर्तमान नोड में सभी XML सामग्री, जिसमें मार्कअप शामिल है। यदि वर्तमान नोड के कोई बच्चे नहीं हैं, तो एक खाली स्ट्रिंग लौटाई जाती है। यदि वर्तमान नोड न तो तत्व है और न ही गुण, तो एक खाली स्ट्रिंग लौटाई जाती है।
