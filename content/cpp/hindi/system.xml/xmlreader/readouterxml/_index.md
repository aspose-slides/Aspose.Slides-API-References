## XmlReader::ReadOuterXml() मेथड

जब कोई व्युत्पन्न क्लास में ओवरराइड किया जाता है, तो यह इस नोड और इसके सभी चाइल्ड्स का प्रतिनिधित्व करने वाले कंटेंट को, मार्कअप सहित, पढ़ता है।

```cpp
virtual String System::Xml::XmlReader::ReadOuterXml()
```

### वापसी मान

यदि रीडर किसी एलिमेंट या एट्रिब्यूट नोड पर स्थित है, तो यह मेथड वर्तमान नोड और उसके सभी चाइल्ड्स का, मार्कअप सहित, सभी XML कंटेंट लौटाता है; अन्यथा, यह एक खाली स्ट्रिंग लौटाता है।
