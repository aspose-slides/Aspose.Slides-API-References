## XmlReaderSettings::get_MaxCharactersInDocument() मेथड

एक मान लौटाता है जो XML दस्तावेज़ में अनुमत अधिकतम अक्षरों की संख्या दर्शाता है। शून्य (0) मान का मतलब है कि XML दस्तावेज़ के आकार पर कोई सीमा नहीं है। गैर-शून्य मान अक्षरों में अधिकतम आकार निर्दिष्ट करता है।

```cpp
int64_t System::Xml::XmlReaderSettings::get_MaxCharactersInDocument()
```

### रिटर्न वैल्यू

XML दस्तावेज़ में अनुमत अधिकतम अक्षरों की संख्या। डिफ़ॉल्ट 0 है।
