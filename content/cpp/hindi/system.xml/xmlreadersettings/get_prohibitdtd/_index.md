## XmlReaderSettings::get_ProhibitDtd() विधि


एक मान लौटाता है जो यह दर्शाता है कि क्या दस्तावेज़ प्रकार परिभाषा (DTD) प्रसंस्करण को रोकना है।

```cpp
bool System::Xml::XmlReaderSettings::get_ProhibitDtd()
```


### रिटर्न मान

**true** ताकि DTD प्रसंस्करण को रोका जा सके; अन्यथा **false**। डिफ़ॉल्ट **true** है।

अप्रचलित
:   यह मेथड अप्रचलित है। इसके बजाय [XmlTextReader::get_DtdProcessing](../../xmltextreader/get_dtdprocessing/) का उपयोग करें।
