## XmlConvert::ToString(DateTime, const String\&) विधि

```cpp
static String System::Xml::XmlConvert::ToString(DateTime value, const String &format)
```

### तर्क

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| value | [DateTime](../../../system/datetime/) | परिवर्तित करने के लिए मान। |
| format | const [String](../../../system/string/)\& | स्वरूप संरचना जो परिवर्तित स्ट्रिंग को प्रदर्शित करने का तरीका निर्धारित करती है। वैध स्वरूपों में "yyyy-MM-ddTHH:mm:sszzzzzz" और इसके उपसमुच्चय शामिल हैं। |

### वापसी मान

एक स्ट्रिंग प्रतिनिधित्व [DateTime](../../../system/datetime/) का, निर्दिष्ट स्वरूप में।

## XmlConvert::ToString(DateTime, XmlDateTimeSerializationMode) विधि

[DateTime](../../../system/datetime/) को [String](../../../system/string/) में परिवर्तित करता है, निर्दिष्ट XmlDateTimeSerializationMode का उपयोग करते हुए।

```cpp
static String System::Xml::XmlConvert::ToString(DateTime value, XmlDateTimeSerializationMode dateTimeOption)
```

### तर्क

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| value | [DateTime](../../../system/datetime/) | [DateTime](../../../system/datetime/) मान को परिवर्तित करने के लिए। |
| dateTimeOption | [XmlDateTimeSerializationMode](../../xmldatetimeserializationmode/) | XmlDateTimeSerializationMode मानों में से एक जो [DateTime](../../../system/datetime/) मान को कैसे संभालना है, यह निर्दिष्ट करता है। |

### वापसी मान

[DateTime](../../../system/datetime/) का [String](../../../system/string/) समतुल्य।

## XmlConvert::ToString(DateTimeOffset, const String\&) विधि

प्रदान किया गया [DateTimeOffset](../../../system/datetimeoffset/) को निर्दिष्ट स्वरूप में [String](../../../system/string/) में परिवर्तित करता है।

```cpp
static String System::Xml::XmlConvert::ToString(DateTimeOffset value, const String &format)
```

### तर्क

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| value | [DateTimeOffset](../../../system/datetimeoffset/) | परिवर्तित करने के लिए [DateTimeOffset](../../../system/datetimeoffset/)। |
| format | const [String](../../../system/string/)\& | स्वरूप जिसके अनुसार **s** को परिवर्तित किया जाता है। स्वरूप पैरामीटर XML dateTime प्रकार के W3C Recommendation के किसी भी उपसमुच्चय हो सकता है। अधिक जानकारी के लिए XML [Schema](../../../system.xml.schema/) विनिर्देशन के [dateTime](https://www.w3.org/TR/xmlschema-2/#dateTime) अनुभाग देखें। |

### वापसी मान

प्रदान किए गए [DateTimeOffset](../../../system/datetimeoffset/) का निर्दिष्ट स्वरूप में [String](../../../system/string/) प्रतिनिधित्व।
