## XmlConvert::VerifyXmlChars(const String\&) मेथड

वापस पास किया गया स्ट्रिंग यदि सभी अक्षर और स्ट्रिंग आर्गुमेंट में मौजूद सर्वोगेट पेयर अक्षर वैध XML अक्षर हों, अन्यथा एक XmlException पहली अवैध अक्षर पर जानकारी के साथ फेंका जाता है।

```cpp
static String System::Xml::XmlConvert::VerifyXmlChars(const String &content)
```

### आर्ग्यूमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| content | const [String](../../../system/string/)\& | [String](../../../system/string/) जिसमें सत्यापित करने के लिये अक्षर होते हैं। |

### रिटर्न वैल्यू

वापस पास किया गया स्ट्रिंग यदि सभी अक्षर और सर्वोगेट-पेयर अक्षर स्ट्रिंग आर्गुमेंट में वैध XML अक्षर हों, अन्यथा एक XmlException पहली अवैध अक्षर पर जानकारी के साथ फेंका जाता है।
