## XmlConvert::IsXmlSurrogatePair(char16_t, char16_t) मेथड

```cpp
static bool System::Xml::XmlConvert::IsXmlSurrogatePair(char16_t lowChar, char16_t highChar)
```

### आर्ग्यूमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| lowChar | char16_t | सत्यापन करने के लिए सरोगेट अक्षर। |
| highChar | char16_t | सत्यापन करने के लिए सरोगेट अक्षर। |

### वापसी मान

**true** यदि पास किया गया सरोगेट अक्षरों का युग्म मान्य XML अक्षर है; अन्यथा **false**।
