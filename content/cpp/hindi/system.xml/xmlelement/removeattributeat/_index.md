## XmlElement::RemoveAttributeAt(int32_t) विधि

निर्दिष्ट सूचकांक वाले attribute node को तत्व से हटाता है। (यदि हटाए गए attribute का डिफ़ॉल्ट मान है, तो वह तुरंत प्रतिस्थापित हो जाता है)।

```cpp
virtual SharedPtr<XmlNode> System::Xml::XmlElement::RemoveAttributeAt(int32_t i)
```

### Arguments

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| i | **int32_t** | हटाने योग्य नोड का सूचकांक। पहला नोड का सूचकांक 0 है। |

### रिटर्न वैल्यू

हटाया गया attribute node या **nullptr** यदि दिए गए सूचकांक पर कोई नोड नहीं है।
