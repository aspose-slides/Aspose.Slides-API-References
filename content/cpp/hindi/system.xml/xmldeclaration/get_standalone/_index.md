## XmlDeclaration::get_Standalone() मेथड


standalone गुणधर्म का मान लौटाता है।

```cpp
String System::Xml::XmlDeclaration::get_Standalone()
```


### रिटर्न मान

मान्य मान **yes** होते हैं यदि XML दस्तावेज़ द्वारा आवश्यक सभी इकाई घोषणाएँ दस्तावेज़ के भीतर ही शामिल हों, या **no** यदि एक बाहरी दस्तावेज़ प्रकार परिभाषा (DTD) आवश्यक हो। यदि XML घोषणा में standalone गुणधर्म उपस्थित नहीं है, तो यह मेथड [String::Empty](../../../system/string/empty/) लौटाता है।
