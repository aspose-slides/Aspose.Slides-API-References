## DtdProcessing enum

DTD प्रसंस्करण के विकल्प निर्दिष्ट करता है। DtdProcessing enumeration [XmlReaderSettings](../xmlreadersettings/) क्लास द्वारा उपयोग किया जाता है।

```cpp
enum class DtdProcessing
```

### मान

| Name | Value | Description |
| --- | --- | --- |
| Prohibit | 0 | निर्दिष्ट करता है कि जब एक DTD का सामना होता है, तो एक XmlException को एक संदेश के साथ थ्रो किया जाता है जो बताता है कि DTDs प्रतिबंधित हैं। यह डिफ़ॉल्ट व्यवहार है। |
| Ignore | 1 | DOCTYPE तत्व को अनदेखा किया जाता है। कोई DTD प्रसंस्करण नहीं होता, और DTD/DOCTYPE आउटपुट पर खो जाता है। |
| Parse | 2 | DTD को पार्स करने के लिए उपयोग किया जाता है। |
