## XmlTextWriter::get_XmlSpace() विधि

वर्तमान **xml:space** स्कोप का प्रतिनिधित्व करने वाला एक XmlSpace लौटाता है।

```cpp
System::Xml::XmlSpace System::Xml::XmlTextWriter::get_XmlSpace() override
```

### वापसी मान

वर्तमान **xml:space** स्कोप का प्रतिनिधित्व करने वाला एक XmlSpace।

| मूल्य | अर्थ |
| --- | --- |
| None | यदि कोई `xml:space` स्कोप मौजूद नहीं है तो यह डिफ़ॉल्ट है। |
| Default | वर्तमान स्कोप `xml:space="default"` है। |
| Preserve | वर्तमान स्कोप `xml:space="preserve"` है। |
