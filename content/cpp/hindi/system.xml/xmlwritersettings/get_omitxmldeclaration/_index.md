## XmlWriterSettings::get_OmitXmlDeclaration() विधि

एक मान लौटाता है जो यह दर्शाता है कि क्या XML घोषणा को छोड़ना है।

```cpp
bool System::Xml::XmlWriterSettings::get_OmitXmlDeclaration()
```

### वापसी मान

**true** XML घोषणा को छोड़ने के लिये; अन्यथा, **false**. डिफ़ॉल्ट **false** है, एक XML घोषणा लिखी जाती है।
