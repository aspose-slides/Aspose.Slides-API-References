## XmlWriterSettings::get_IndentChars() method

इंडेंट करने के लिए उपयोग की जाने वाली कैरेक्टर स्ट्रिंग को लौटाता है। यह सेटिंग तब उपयोग की जाती है जब [XmlWriterSettings::set_Indent](../set_indent/) मान **true** पर सेट किया जाता है।

```cpp
String System::Xml::XmlWriterSettings::get_IndentChars()
```

### Return Value

इंडेंट करने के लिए उपयोग की जाने वाली कैरेक्टर स्ट्रिंग। इसे किसी भी स्ट्रिंग मूल्य पर सेट किया जा सकता है। हालांकि, वैध XML सुनिश्चित करने के लिए, आपको केवल वैध व्हाइटस्पेस कैरेक्टर, जैसे स्पेस कैरेक्टर, टैब, कैरिज रिटर्न, या लाइन फीड निर्दिष्ट करना चाहिए। डिफ़ॉल्ट दो स्पेस है।
