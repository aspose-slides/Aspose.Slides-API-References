## XmlWriterSettings::get_NewLineChars() मेथड

लाइन ब्रेक के लिए उपयोग की जाने वाली अक्षर स्ट्रिंग लौटाता है।

```cpp
String System::Xml::XmlWriterSettings::get_NewLineChars()
```

### वापसी मान

लाइन ब्रेक के लिए उपयोग की जाने वाली अक्षर स्ट्रिंग। इसे किसी भी स्ट्रिंग मान पर सेट किया जा सकता है। हालांकि, वैध XML सुनिश्चित करने के लिए, आपको केवल मान्य व्हाइटस्पेस अक्षर निर्दिष्ट करने चाहिए, जैसे स्पेस अक्षर, टैब, कैरिज रिटर्न या लाइन फीड। डिफ़ॉल्ट **\r\n** (कैरिज रिटर्न, नई लाइन) है।
