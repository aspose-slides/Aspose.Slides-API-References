## XmlWriterSettings::get_NamespaceHandling() विधि


एक मान लौटाता है जो संकेत देता है कि [XmlWriter](../../xmlwriter/) को XML सामग्री लिखते समय दोहराए जाने वाले नेमस्पेस घोषणाओं को हटाना चाहिए या नहीं। डिफ़ॉल्ट व्यवहार यह है कि लेखक उन सभी नेमस्पेस घोषणाओं को आउटपुट करे जो लेखक के नेमस्पेस रिजॉल्वर में मौजूद हैं।

```cpp
System::Xml::NamespaceHandling System::Xml::XmlWriterSettings::get_NamespaceHandling()
```


### वापसी मान

NamespaceHandling एन्हुमरेशन का उपयोग यह निर्दिष्ट करने के लिए किया जाता है कि [XmlWriter](../../xmlwriter/) में दोहराए जाने वाले नेमस्पेस घोषणाओं को हटाया जाए या नहीं।
