## XmlWriter::get_XmlSpace() विधि

जब व्युत्पन्न वर्ग में ओवरराइड किया जाता है, तो यह वर्तमान **xml:space** स्कोप को दर्शाने वाला एक XmlSpace प्राप्त करता है।

```cpp
virtual System::Xml::XmlSpace System::Xml::XmlWriter::get_XmlSpace()
```

### रिटर्न मान

वर्तमान **xml:space** स्कोप को दर्शाने वाला एक XmlSpace।

| मान | अर्थ |
| --- | --- |
| `None`| यह डिफ़ॉल्ट है यदि कोई `xml:space` स्कोप मौजूद नहीं है। |
| `Default`| वर्तमान स्कोप `xml:space="default"` है। |
| `Preserve`| वर्तमान स्कोप `xml:space="preserve"` है। |
