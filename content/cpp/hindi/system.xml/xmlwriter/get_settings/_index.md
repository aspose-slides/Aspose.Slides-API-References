## XmlWriter::get_Settings() विधि


वापस करता है [XmlWriterSettings](../../xmlwritersettings/) ऑब्जेक्ट जिसे इस [XmlWriter](../) इंस्टेंस को बनाने के लिए उपयोग किया गया था।

```cpp
virtual SharedPtr<XmlWriterSettings> System::Xml::XmlWriter::get_Settings()
```


### रिटर्न वैल्यू

यह [XmlWriterSettings](../../xmlwritersettings/) ऑब्जेक्ट इस राइटर इंस्टेंस को बनाने के लिए उपयोग किया गया है। यदि यह राइटर [XmlWriter::Create](../create/) विधि का उपयोग करके नहीं बनाया गया है, तो यह विधि **nullptr** लौटाती है।
