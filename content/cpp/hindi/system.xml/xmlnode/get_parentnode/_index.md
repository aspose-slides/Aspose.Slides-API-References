## XmlNode::get_ParentNode() मेथड

इस नोड का पैरेंट लौटाता है (उन नोड्स के लिए जिनके पास पैरेंट हो सकता है)।

```cpp
virtual SharedPtr<XmlNode> System::Xml::XmlNode::get_ParentNode() final
```

### वापसी मान

वर्तमान नोड का पैरेंट होने वाला [XmlNode](../)।

## टिप्पणियाँ

यदि कोई नोड अभी-अभी बनाया गया है और अभी तक ट्री में जोड़ा नहीं गया है, या यदि उसे ट्री से हटा दिया गया है, तो पैरेंट **nullptr** होता है। सभी अन्य नोड्स के लिए, लौटाया गया मान नोड के [XmlNode::get_NodeType](../get_nodetype/) पर निर्भर करता है। नीचे दी गई तालिका **get_NodeType** मेथड के संभावित रिटर्न वैल्यूज़ का वर्णन करती है।

| NodeType | Return Value of ParentNode |
| --- | --- |
| [Attribute](../../../system/attribute/), Document, DocumentFragment, Entity, Notation | `nullptr` लौटाता है; इन नोड्स के कोई पैरेंट नहीं होते। |
| CDATA | CDATA सेक्शन को शामिल करने वाला एलिमेंट या एंटिटी रेफ़रेंस लौटाता है। |
| Comment | टिप्पणी को शामिल करने वाला एलिमेंट, एंटिटी रेफ़रेंस, डॉक्यूमेंट टाइप, या डॉक्यूमेंट लौटाता है। |
| DocumentType | डॉक्यूमेंट नोड लौटाता है। |
| Element | एलिमेंट का पैरेंट नोड लौटाता है। यदि एलिमेंट ट्री की रूट नोड है, तो पैरेंट डॉक्यूमेंट नोड होता है। |
| EntityReference | एंटिटी रेफ़रेंस को शामिल करने वाला एलिमेंट, एट्रिब्यूट, या एंटिटी रेफ़रेंस लौटाता है। |
| ProcessingInstruction | प्रोसेसिंग इंस्ट्रक्शन को शामिल करने वाला डॉक्यूमेंट, एलिमेंट, डॉक्यूमेंट टाइप, या एंटिटी रेफ़रेंस लौटाता है। |
| [Text](../../../system.text/)| टेक्स्ट नोड को शामिल करने वाला पैरेंट एलिमेंट, एट्रिब्यूट, या एंटिटी रेफ़रेंस लौटाता है। |
