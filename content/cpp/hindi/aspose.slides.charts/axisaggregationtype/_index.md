## AxisAggregationType एनम

Represents aggregation type of category axis. Used with Histogram or HistogramPareto series only.

```cpp
enum class AxisAggregationType
```

### मान

| Name | Value | Description |
| --- | --- | --- |
| ByCategory | 0 | श्रेणियों द्वारा एकत्रित |
| Automatic | 1 | श्रेणियों को स्वचालित रूप से एकत्रित करें। |
| ByBinWidth | 2 | बिन की चौड़ाई के अनुसार श्रेणियों को एकत्रित करें। Property IAxis::get(set)_BinWidth को सेट किया जाना चाहिए। |
| ByNumberOfBins | 3 | बिन की संख्या के अनुसार श्रेणियों को एकत्रित करें। Property IAxis::get(set)_NumberOfBins को सेट किया जाना चाहिए। |
