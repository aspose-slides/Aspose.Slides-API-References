## DataLabelFormat::set_ShowSeriesName(bool) विधि


एक Boolean सेट करता है जो चार्ट पर डेटा लेबल के लिए श्रृंखला नाम प्रदर्शित करने के व्यवहार को दर्शाता है। True श्रृंखला नाम दिखाने के लिए। False छिपाने के लिए। Write **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowSeriesName(bool value) override
```

## टिप्पणी


यदि इस [DataLabelFormat](../) वस्तु का पैरेंट एक [DataLabelCollection](../../datalabelcollection/) डेटा लेबल का संग्रह है तो यह प्रॉपर्टी [DataLabelCollection](../../datalabelcollection/) संग्रह में नई डेटा लेबल के लिए ShowSeriesName प्रॉपर्टी का डिफ़ॉल्ट मान प्राप्त या सेट करती है। इस प्रॉपर्टी को मान के साथ सेट करने से यह मान सभी डेटा लेबल के लिए [DataLabelCollection](../../datalabelcollection/) संग्रह में ShowSeriesName प्रॉपर्टी पर भी सेट हो जाता है (i.e. \"DataLabels.DefaultDataLabelFormat.ShowSeriesName = val;\" जिससे सभी DataLabels[i].ShowSeriesName बराबर val हो जाता है)।
