## DataLabelFormat::get_ShowPercentage() विधि

Represents a specified chart's data label percentage value display behavior. True displays the percentage value. False to hide. Read **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowPercentage() override
```

## टिप्पणी

यदि इस [DataLabelFormat](../) ऑब्जेक्ट का पैरेंट एक [DataLabelCollection](../../datalabelcollection/) डेटा लेबल संग्रह है तो यह प्रॉपर्टी [DataLabelCollection](../../datalabelcollection/) संग्रह में नए डेटा लेबल्स के लिए ShowPercentage प्रॉपर्टी का डिफ़ॉल्ट मान प्राप्त करती या सेट करती है। इस प्रॉपर्टी को मान के साथ सेट करने से यह मान [DataLabelCollection](../../datalabelcollection/) संग्रह में सभी डेटा लेबल्स की ShowPercentage प्रॉपर्टी पर भी सेट हो जाता है (i.e. "DataLabels.DefaultDataLabelFormat.ShowPercentage = val;" cause to all DataLabels[i].ShowPercentage is equal to val).
