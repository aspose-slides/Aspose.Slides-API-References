## DataLabelFormat::set_ShowValue(bool) मेथड


निर्दिष्ट चार्ट के डेटा लेबल प्रतिशत मान के प्रदर्शन व्यवहार को दर्शाता है। True प्रतिशत मान प्रदर्शित करता है। False छिपाता है। Write **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowValue(bool value) override
```

## टिप्पणी


यदि इस [DataLabelFormat](../) वस्तु का पैरेंट एक [DataLabelCollection](../../datalabelcollection/) डेटा लेबल्स संग्रह है, तो यह प्रॉपर्टी [DataLabelCollection](../../datalabelcollection/) संग्रह में नए डेटा लेबल्स के लिए ShowValue प्रॉपर्टी का डिफ़ॉल्ट मान प्राप्त करती या सेट करती है। इस प्रॉपर्टी को मान के साथ सेट करने से यह मान [DataLabelCollection](../../datalabelcollection/) संग्रह में सभी डेटा लेबल्स की ShowValue प्रॉपर्टी पर भी सेट हो जाता है (उदाहरण के लिए "DataLabels.DefaultDataLabelFormat.ShowValue = val;" जिसके कारण सभी DataLabels[i].ShowValue बराबर val हो जाता है)।
