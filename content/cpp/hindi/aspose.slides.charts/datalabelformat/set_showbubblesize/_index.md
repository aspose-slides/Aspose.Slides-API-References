## DataLabelFormat::set_ShowBubbleSize(bool) मेथड


निर्दिष्ट चार्ट के डेटा लेबल बबल साइज वैल्यू प्रदर्शन व्यवहार को दर्शाता है। True बबल साइज वैल्यू दर्शाता है। False इसे छुपाता है। Write **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowBubbleSize(bool value) override
```

## टिप्पणी


यदि इस [DataLabelFormat](../) वस्तु का पैरेंट एक [DataLabelCollection](../../datalabelcollection/) डेटा लेबल्स का संग्रह है तो यह प्रॉपर्टी [DataLabelCollection](../../datalabelcollection/) संग्रह में नए डेटा लेबल्स के लिए ShowBubbleSize प्रॉपर्टी का डिफ़ॉल्ट मान प्राप्त या सेट करती है। इस प्रॉपर्टी को मान के साथ सेट करने से यह मान [DataLabelCollection](../../datalabelcollection/) संग्रह में सभी डेटा लेबल्स के ShowBubbleSize प्रॉपर्टी पर भी सेट हो जाता है (i.e. \"DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;\" जिससे सभी DataLabels[i].ShowBubbleSize बराबर val हो जाता है)।
