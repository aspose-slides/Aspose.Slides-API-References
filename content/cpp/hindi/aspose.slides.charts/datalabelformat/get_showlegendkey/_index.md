## DataLabelFormat::get_ShowLegendKey() विधि

Represents a specified chart's data label legend key display behavior. True if the data label legend key is visible. पढ़ें **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowLegendKey() override
```

## टिप्पणियाँ

यदि इस [DataLabelFormat](../) वस्तु का पैरेंट एक [DataLabelCollection](../../datalabelcollection/) डेटा लेबल्स का संग्रह है तो यह प्रॉपर्टी [DataLabelCollection](../../datalabelcollection/) संग्रह में नए डेटा लेबल्स के लिए ShowLegendKey प्रॉपर्टी का डिफ़ॉल्ट मान प्राप्त करती है या सेट करती है। इस प्रॉपर्टी को मान के साथ सेट करने से यह मान सभी डेटा लेबल्स के लिए [DataLabelCollection](../../datalabelcollection/) संग्रह में ShowLegendKey प्रॉपर्टी में भी सेट हो जाता है (i.e. "DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;" cause to all DataLabels[i].ShowLegendKey is equal to val).
