## DataLabelFormat::set_ShowLabelValueFromCell(bool) विधि

एक निर्दिष्ट चार्ट के डेटा लेबल सेल मान प्रदर्शित व्यवहार को दर्शाता है। True सेल मान को दिखाता है। False को छुपाता है। लिखें **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLabelValueFromCell(bool value) override
```

## टिप्पणी

यदि इस [DataLabelFormat](../) ऑब्जेक्ट का पैरेंट एक [DataLabelCollection](../../datalabelcollection/) डेटा लेबल संग्रह है तो यह प्रॉपर्टी [DataLabelCollection](../../datalabelcollection/) संग्रह में नए डेटा लेबल के लिए ShowLabelValueFromCell प्रॉपर्टी का डिफ़ॉल्ट मान प्राप्त या सेट करती है। इस प्रॉपर्टी को मान के साथ सेट करने से यह मान सभी डेटा लेबल के ShowLabelValueFromCell प्रॉपर्टी को [DataLabelCollection](../../datalabelcollection/) संग्रह में सेट करता है (उदा. \"DataLabels.DefaultDataLabelFormat.ShowLabelValueFromCell = val;\" कारण सभी DataLabels[i].ShowLabelValueFromCell बराबर val हो जाता है)।
