## DataLabelFormat::set_ShowLeaderLines(bool) विधि


निर्दिष्ट चार्ट के डेटा लेबल लीडर लाइन्स के प्रदर्शन व्यवहार को दर्शाता है। True लीडर लाइन्स को दिखाता है। False छिपाने के लिए। लिखें **bool**।

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLeaderLines(bool value) override
```

## टिप्पणी


यदि इस [DataLabelFormat](../) वस्तु का पैरेंट एक [DataLabelCollection](../../datalabelcollection/) डेटा लेबल संग्रह है तो यह प्रॉपर्टी नए डेटा लेबल्स के लिए [DataLabelCollection](../../datalabelcollection/) संग्रह में ShowLeaderLines प्रॉपर्टी का डिफ़ॉल्ट मान प्राप्त करती है या सेट करती है। इस प्रॉपर्टी को मान के साथ सेट करने से यह मान सभी डेटा लेबल्स के लिए [DataLabelCollection](../../datalabelcollection/) संग्रह में ShowLeaderLines प्रॉपर्टी में भी सेट हो जाता है (i.e. \"DataLabels.DefaultDataLabelFormat.ShowLeaderLines = val;\" जिससे सभी DataLabels[i].ShowLeaderLines बराबर val हो जाता है)।
