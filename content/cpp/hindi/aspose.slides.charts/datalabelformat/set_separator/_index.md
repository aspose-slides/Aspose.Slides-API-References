## DataLabelFormat::set_Separator(System::String) मेथड


एक Variant सेट करता है या लौटाता है जो चार्ट पर डेटा लेबल्स के लिए उपयोग किए जाने वाले विभाजक को दर्शाता है। लिखें [System::String](../../../system/string/).

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_Separator(System::String value) override
```

## टिप्पणियाँ


यदि इस [DataLabelFormat](../) ऑब्जेक्ट का पैरेंट एक [DataLabelCollection](../../datalabelcollection/) डेटा लेबल्स का संग्रह है, तो यह प्रॉपर्टी [DataLabelCollection](../../datalabelcollection/) संग्रह में नई डेटा लेबल्स के लिए Separator प्रॉपर्टी का डिफ़ॉल्ट मान प्राप्त करती है या सेट करती है।
इस प्रॉपर्टी को मान के साथ सेट करने से यह मान [DataLabelCollection](../../datalabelcollection/) संग्रह में सभी डेटा लेबल्स की Separator प्रॉपर्टी पर भी सेट हो जाता है (उदा. "DataLabels.DefaultDataLabelFormat.Separator = val;" जिससे सभी DataLabels[i].Separator बराबर val हो जाता है)।
