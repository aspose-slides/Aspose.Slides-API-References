## IDataLabelFormat::set_ShowValue(bool) विधि

एक निर्दिष्ट चार्ट के डेटा लेबल प्रतिशत मान प्रदर्शन व्यवहार का प्रतिनिधित्व करता है। True प्रतिशत मान प्रदर्शित करता है। False छिपाने के लिए। Write **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowValue(bool value)=0
```

## टिप्पणियाँ

यदि इस [DataLabelFormat](../../datalabelformat/) वस्तु का पैरेंट एक [DataLabelCollection](../../datalabelcollection/) डेटा लेबल्स संग्रह है तो यह प्रॉपर्टी [DataLabelCollection](../../datalabelcollection/) संग्रह में नए डेटा लेबल्स के लिए ShowValue प्रॉपर्टी का डिफ़ॉल्ट मान प्राप्त करती है या सेट करती है। इस प्रॉपर्टी को मान के साथ सेट करने से यह मान [DataLabelCollection](../../datalabelcollection/) संग्रह में सभी डेटा लेबल्स के ShowValue प्रॉपर्टी पर भी सेट हो जाता है (i.e. \"DataLabels.DefaultDataLabelFormat.ShowValue = val;\" cause to all DataLabels[i].ShowValue is equal to val)।
