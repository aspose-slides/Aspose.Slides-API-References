## DataLabelCollection::get_IsVisible() मेथड

False का अर्थ है कि डेटा लेबल डिफ़ॉल्ट रूप से दिखाई नहीं देता (और इसलिए DefaultDataLabelFormat गुण की सभी Show*-flags (ShowValue, ...) false होते हैं). केवल-पढ़ने योग्य **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelCollection::get_IsVisible() override
```

## टिप्पणी

यदि डेटा लेबल डिफ़ॉल्ट रूप से दिखाई देता है तो आप इसे डिफ़ॉल्ट रूप से छुपा सकते हैं [Hide()](../hide/) मेथड के साथ। लेकिन यदि डेटा लेबल डिफ़ॉल्ट रूप से दिखाई नहीं देता (IsVisible false है) तो आप डेटा लेबल को "visible 
by default" बना सकते हैं DefaultDataLabelFormat गुण की Show*-flags (ShowValue, ...) को true स्थिति में सेट करके।
