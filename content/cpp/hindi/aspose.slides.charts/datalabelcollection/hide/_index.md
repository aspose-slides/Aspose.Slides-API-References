## DataLabelCollection::Hide() विधि

डिफ़ॉल्ट रूप से डेटा लेबल को छिपा रखने के लिए DefaultDataLabelFormat प्रॉपर्टी के सभी Show*-फ्लैग्स (ShowValue, ...) को false स्थिति में सेट करें। IsVisible इस के बाद false रहेगा।

```cpp
void Aspose::Slides::Charts::DataLabelCollection::Hide() override
```

## टिप्पणियाँ

यदि डेटा लेबल डिफ़ॉल्ट रूप से दिखाई नहीं देता (IsVisible false है) तो आप Show*-फ्लैग्स (ShowValue, ...) को true स्थिति में सेट करके डेटा लेबल को "डिफ़ॉल्ट रूप से दिखाई देने वाला" बना सकते हैं।
