## DataLabel::get_IsVisible() विधि

False का अर्थ है कि डेटा लेबल दृश्यमान नहीं है (और इसलिए सभी Show*-flags (ShowValue, ...) false होते हैं). केवल-पढ़ने योग्य **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabel::get_IsVisible() override
```

## टिप्पणियाँ

यदि डेटा लेबल दृश्यमान है तो आप इसे [Hide()](../hide/) विधि से छिपा सकते हैं। लेकिन यदि डेटा लेबल दृश्यमान नहीं है (IsVisible false है) तो आप Show*-flags (ShowValue, ...) को true स्थिति पर सेट करके डेटा लेबल को दृश्यमान बना सकते हैं।
