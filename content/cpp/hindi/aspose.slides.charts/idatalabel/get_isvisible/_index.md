## IDataLabel::get_IsVisible() विधि


False का अर्थ है कि डेटा लेबल दृश्यमान नहीं है (और इसलिए सभी Show*-flags (ShowValue, ...) गलत हैं). केवल-पढ़ने योग्य **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabel::get_IsVisible()=0
```

## टिप्पणी


यदि डेटा लेबल दृश्यमान है तो आप इसे [Hide()](../hide/) विधि से छुपा सकते हैं। लेकिन यदि डेटा लेबल दृश्यमान नहीं है (IsVisible false है) तो आप Show*-flags (ShowValue, ...) को true अवस्था में सेट करके डेटा लेबल को दृश्यमान बना सकते हैं।
