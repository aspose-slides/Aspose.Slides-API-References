## IDataLabel::Hide() विधि


सभी Show*-flags (ShowValue, ...) को false स्थिति में सेट करके डेटा लेबल को छिपा दें। IsVisible false रहेगा।

```cpp
virtual void Aspose::Slides::Charts::IDataLabel::Hide()=0
```

## टिप्पणी


यदि डेटा लेबल दृश्यमान नहीं है (IsVisible false) तो आप Show*-flags (ShowValue, ...) को true स्थिति में सेट करके डेटा लेबल को दृश्यमान बना सकते हैं।
