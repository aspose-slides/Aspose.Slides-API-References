## IDataLabelCollection::get_IsVisible() मेथड


False का अर्थ है कि डेटा लेबल डिफ़ॉल्ट रूप से दिखाई नहीं देता (और इसलिए DefaultDataLabelFormat प्रॉपर्टी के सभी Show*-flags (ShowValue, ...) false हैं)। केवल पढ़ने योग्य **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelCollection::get_IsVisible()=0
```

## टिप्पणियाँ


यदि डेटा लेबल डिफ़ॉल्ट रूप से दिखाई देता है तो आप इसे [Hide()](../hide/) मेथड के साथ डिफ़ॉल्ट रूप से छिपा सकता है। लेकिन यदि डेटा लेबल डिफ़ॉल्ट रूप से नहीं दिखता (IsVisible false है) तो आप डेटा लेबल को \"दिखाई देता 
डिफ़ॉल्ट रूप से\" सेट करके Show*-flags (ShowValue, ...) को DefaultDataLabelFormat प्रॉपर्टी में true स्थिति पर सेट कर सकते हैं।
