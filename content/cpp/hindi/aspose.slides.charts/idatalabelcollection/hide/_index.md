## IDataLabelCollection::Hide() विधि


डिफ़ॉल्ट रूप से डेटा लेबल को छिपा हुआ बनाएं सभी Show*-flags (ShowValue, ...) को DefaultDataLabelFormat प्रॉपर्टी की false स्थिति में सेट करके। IsVisible इस के बाद false होगा।

```cpp
virtual void Aspose::Slides::Charts::IDataLabelCollection::Hide()=0
```

## टिप्पणी


यदि डेटा लेबल डिफ़ॉल्ट रूप से दृश्यमान नहीं है (IsVisible false है) तो आप डेटा लेबल को \"visible \nby default\" बना सकते हैं Show*-flags (ShowValue, ...) को DefaultDataLabelFormat प्रॉपर्टी की true स्थिति में सेट करके।
