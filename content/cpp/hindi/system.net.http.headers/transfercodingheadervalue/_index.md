## TransferCodingHeaderValue क्लास


Represents a value of the 'Accept-Encoding' header. Objects of this क्लास should only be allocated using [System::MakeObject()](../../system/makeobject/) फ़ंक्शन. Never create instance of this type on stack or using operator new, as it will result in runtime errors and/or assertion faults. Always wrap this क्लास into [System::SmartPtr](../../system/smartptr/) पॉइंटर and use this pointer to pass it to फ़ंक्शनों as argument.

```cpp
class TransferCodingHeaderValue : public virtual System::ICloneable
```
