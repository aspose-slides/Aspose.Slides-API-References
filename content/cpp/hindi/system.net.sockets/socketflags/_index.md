## SocketFlags enum

सॉकेट संदेशों के लिए स्थिर मान प्रदान करता है।

```cpp
enum class SocketFlags
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| None | 0 | इस कॉल के लिए कोई फ़्लैग उपयोग नहीं किए गए हैं। |
| OutOfBand | 1 | आउट-ऑफ़-बैंड डेटा को संसाधित किया जा रहा है। |
| Peek | 2 | आने वाले संदेश को देखें। |
| DontRoute | 4 | रूटिंग तालिकाओं का उपयोग किए बिना संदेश भेजें। |
| Truncated | 256 | एक संदेश निर्दिष्ट बफ़र में फिट होने के लिये बहुत बड़ा है। इसे काट दिया गया है। |
| ControlDataTruncated | 512 | नियंत्रण डेटा 64 KB से बड़ा है और आंतरिक बफ़र में फिट नहीं होता। इसे काट दिया गया है। |
| Broadcast | 1024 | एक प्रसारण पैकेट। |
| Multicast | 2048 | एक मल्टीकास्ट पैकेट। |
| Partial | 32768 | एक संदेश आंशिक रूप से भेजा या प्राप्त किया गया। |
