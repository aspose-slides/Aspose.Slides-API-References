## ColorChannelFlag एनुम

CMYK रंग स्थान में एक रंग चैनल निर्दिष्ट करता है।

```cpp
enum class ColorChannelFlag
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| ColorChannelC | 0 | सियान रंग चैनल। |
| ColorChannelM | 1 | मैजेंटा रंग चैनल। |
| ColorChannelY | 2 | पीला रंग चैनल। |
| ColorChannelK | 3 | काला रंग चैनल। |
| ColorChannelLast | 4 | आखिरी चयनित चैनल का उपयोग किया जाना चाहिए। |
