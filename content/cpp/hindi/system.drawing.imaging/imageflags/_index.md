## ImageFlags एनम

एक [Image](../../system.drawing/image/) ऑब्जेक्ट द्वारा प्रदर्शित पिक्सेल डेटा के गुणों का प्रतिनिधित्व करता है।

```cpp
enum class ImageFlags
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| None | 0 |  |
| Scalable | 1 | स्केलेबल। |
| HasAlpha | 2 | एल्फा जानकारी शामिल है। |
| HasTranslucent | 4 | ऐसे अल्फा मान हैं जो 0 से बड़े और 255 से छोटे हैं। |
| PartiallyScalable | 8 |  |
| ColorSpaceRgb | 16 | पिक्सेल डेटा RGB कलरस्पेस में दर्शाया गया है। |
| ColorSpaceCmyk | 32 | पिक्सेल डेटा CMYK कलरस्पेस में दर्शाया गया है। |
| ColorSpaceGray | 64 | पिक्सेल डेटा ग्रेस्केल है। |
| ColorSpaceYcbcr | 128 | पिक्सेल डेटा YCBCR कलरस्पेस में दर्शाया गया है। |
| ColorSpaceYcck | 256 | पिक्सेल डेटा YCCK कलरस्पेस में दर्शाया गया है। |
| HasRealDpi | 4096 | छवि में DPI जानकारी संग्रहीत है। |
| HasRealPixelSize | 8192 | छवि में पिक्सेल का आकार संग्रहीत है। |
| ReadOnly | 65536 | पिक्सेल डेटा केवल-पढ़ने योग्य है। |
| Caching | 131072 | तेज़ एक्सेस के लिए कैश किया जा सकता है। |
