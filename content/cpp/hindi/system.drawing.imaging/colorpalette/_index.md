## ColorPalette क्लास

Represents a set of 32-bit ARGB colors that make up a color palette. Objects of this क्लास should only be allocated using [System::MakeObject()](../../system/makeobject/) फ़ंक्शन. Never create instance of this type on stack or using operator new, as it will result in रनटाइम त्रुटियां and/or assertion faults. Always wrap this क्लास into [System::SmartPtr](../../system/smartptr/) पोइंटर and use this पोइंटर to pass it to functions as argument.

```cpp
class ColorPalette : public System::Object
```
