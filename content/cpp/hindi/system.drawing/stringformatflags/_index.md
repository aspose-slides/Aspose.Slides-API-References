## StringFormatFlags enum


पाठ की स्ट्रिंग्स के लिए प्रदर्शन और लेआउट जानकारी निर्दिष्ट करता है।

```cpp
enum class StringFormatFlags
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| DirectionRightToLeft | 1 | दाएँ से बाएँ टेक्स्ट दिशा। |
| DirectionVertical | 2 | [Text](../../system.drawing.text/) ऊर्ध्वरात्मक रूप से संरेखित है। |
| FitBlackBox | 4 | अक्षरों के भाग लेआउट बॉक्स से बाहर निकल सकते हैं। |
| DisplayFormatControl | 32 | नियंत्रण अक्षरों को प्रदर्शित किया जाता है। |
| NoFontFallback | 1024 | [Font](../font/) फॉल्बैक अक्षम किया गया है। |
| MeasureTrailingSpaces | 2048 | प्रत्येक पंति के अंत में ट्रेलिंग स्पेस डालता है। |
| NoWrap | 4096 | [Text](../../system.drawing.text/) रैपिंग अक्षम किया गया है। |
| LineLimit | 8192 | सभी पंक्तियों को फ़ॉर्मेटिंग आयत में व्यवस्थित किया जाता है। |
| NoClip | 16384 | ग्लिफ़ के बाहर निकलने वाले भागों को दिखाने की अनुमति है। |
