## StringTrimming enum

यह निर्दिष्ट करता है कि लेआउट आकार में फिट न होने वाली स्ट्रिंग से अक्षरों को कैसे ट्रिम किया जाना चाहिए।

```cpp
enum class StringTrimming
```

### Values

| नाम | मान | विवरण |
| --- | --- | --- |
| None | 0 | कोई ट्रिमिंग नहीं। |
| Character | 1 | निकटतम अक्षर तक ट्रिम करें। |
| Word | 2 | निकटतम शब्द तक ट्रिम करें। |
| EllipsisCharacter | 3 | निकटतम अक्षर तक ट्रिम करें और स्ट्रिंग के अंत में एलिप्सिस डालें। |
| EllipsisWord | 4 | निकटतम शब्द तक ट्रिम करें और स्ट्रिंग के अंत में एलिप्सिस डालें। |
| EllipsisPath | 5 | ट्रिम की गई लाइनों के मध्य भाग को हटा दिया जाता है और उसे एलिप्सिस से बदल दिया जाता है। लाइन के अंतिम स्लैश-सीमांकित भाग को यथासंभव अधिक रखने का प्रयास करें। |
