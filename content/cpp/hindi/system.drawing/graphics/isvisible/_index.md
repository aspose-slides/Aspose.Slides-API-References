## Graphics::IsVisible(Point) मेथड

निर्धारित करता है कि क्या निर्दिष्ट बिंदु वर्तमान [Graphics](../) ऑब्जेक्ट के दृश्यमान क्लिप क्षेत्र के भीतर सम्मिलित है।

```cpp
bool System::Drawing::Graphics::IsVisible(Point point)
```

### आर्ग्युमेंट्स

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| point | [Point](../../point/) | जाँचने के लिये बिंदु |

### रिटर्न वैल्यू

True if **point** is contained within the visible clip region of the current [Graphics](../) object, otherwise - false
