## Point::Offset(int, int) विधि

वर्तमान वस्तु द्वारा प्रतिनिधित्व किए गए X और Y निर्देशांक मान को निर्दिष्ट मानों द्वारा ऑफसेट करता है।

```cpp
void System::Drawing::Point::Offset(int dx, int dy)
```

### आर्ग्यूमेंट

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| dx | int | X निर्देशांक मान को ऑफसेट करने के लिए मान |
| dy | int | Y निर्देशांक मान को ऑफसेट करने के लिए मान |
