## Point::Subtract(const Point\&, const Size\&) मेथड


निर्दिष्ट [Size](../../size/) ऑब्जेक्ट के चौड़ाई और ऊँचाई मान को क्रमशः निर्दिष्ट [Point](../) ऑब्जेक्ट के X और Y निर्देशांक मानों से घटाता है।

```cpp
static Point System::Drawing::Point::Subtract(const Point &point, const Size &size)
```


### आर्ग्युमेंट्स

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| point | const [Point](../)\& | अनुवाद करने के लिये बिंदु |
| size | const [Size](../../size/)\& | वह [Size](../../size/) ऑब्जेक्ट जो **point** के निर्देशांक मानों से घटाने के लिए मान निर्दिष्ट करता है |

### रिटर्न मान

एक नया [Point](../) ऑब्जेक्ट जिसका X निर्देशांक मान **point** के X निर्देशांक मान से **size** की चौड़ाई मान घटाने के परिणाम के बराबर है और Y निर्देशांक मान **point** के Y निर्देशांक मान से **size** की ऊँचाई मान घटाने के परिणाम के बराबर है।
