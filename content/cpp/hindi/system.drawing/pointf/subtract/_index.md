## PointF::Subtract(const PointF\&, const SizeF\&) विधि

निर्दिष्ट [SizeF](../../sizef/) वस्तु के चौड़ाई और ऊँचाई मानों को निर्धारित [PointF](../) वस्तु के X और Y समन्वय मानों से क्रमशः घटाता है।

```cpp
static PointF System::Drawing::PointF::Subtract(const PointF &point, const SizeF &size)
```

### तर्क

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| point | const [PointF](../)\& | अनुवादित करने के लिए बिंदु |
| size | const [SizeF](../../sizef/)\& | वह [SizeF](../../sizef/) वस्तु जो **point** के समन्वय मानों से घटाने के लिए मान निर्दिष्ट करती है |

### रिटर्न मान

एक नया [PointF](../) वस्तु जिसका X समन्वय मान **size** की चौड़ाई मान को **point** के X समन्वय मान से घटाने के परिणाम के बराबर होता है और Y समन्वय मान **size** की ऊँचाई मान को **point** के Y समन्वय मान से घटाने के परिणाम के बराबर होता है।
