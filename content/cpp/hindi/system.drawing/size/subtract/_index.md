## Size::Subtract(const Size\&, const Size\&) विधि

एक नया [Size](../) ऑब्जेक्ट लौटाता है जो **size2** को **size1** से घटाने का परिणाम है, अर्थात् जिसकी चौड़ाई मान **size1** की चौड़ाई मान से **size2** की चौड़ाई मान घटाने का परिणाम है और ऊँचाई मान **size1** की ऊँचाई मान से **size2** की ऊँचाई मान घटाने का परिणाम है।

```cpp
static Size System::Drawing::Size::Subtract(const Size &size1, const Size &size2)
```

| --- | --- | --- |

| size2 | const [Size](../)\& | [Size](../) ऑब्जेक्ट घटाने के लिए |
