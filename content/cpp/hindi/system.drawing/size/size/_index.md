## Size::Size() कंस्ट्रक्टर

एक नया [Size](../) ऑब्जेक्ट बनाता है और उसकी width और height मान को 0 से प्रारम्भ करता है।

```cpp
System::Drawing::Size::Size()
```

## Size::Size(const Point\&) कंस्ट्रक्टर

एक नया [Size](../) ऑब्जेक्ट बनाता है और उसकी width और height मान को निर्दिष्ट बिंदु के X तथा Y निर्देशांक के मानों के अनुसार प्रारम्भ करता है।

```cpp
System::Drawing::Size::Size(const Point &point)
```

### आर्ग्यूमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| point | const [Point](../../point/)\& | एक [Point](../../point/) ऑब्जेक्ट जिसका X और Y निर्देशांक का उपयोग बन रहे [Size](../) ऑब्जेक्ट की width और height मान को प्रारम्भ करने के लिए किया जाता है |

## Size::Size(int, int) कंस्ट्रक्टर

एक नया [Size](../) ऑब्जेक्ट बनाता है और उसे निर्दिष्ट मान के साथ प्रारम्भ करता है।

```cpp
System::Drawing::Size::Size(int width, int height)
```

### आर्ग्यूमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| width | int | चौड़ाई के लिए मान |
| height | int | height का मान |
