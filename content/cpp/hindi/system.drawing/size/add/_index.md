## Size::Add(const Size\&, const Size\&) विधि

एक नया [Size](../) ऑब्जेक्ट लौटाता है जो निर्दिष्ट [Size](../) ऑब्जेक्ट का योग है, अर्थात् जिसकी width मान निर्दिष्ट ऑब्जेक्ट्स के width मानों के योग के बराबर है और height मान निर्दिष्ट ऑब्जेक्ट्स के height मानों के योग के बराबर है।

```cpp
static Size System::Drawing::Size::Add(const Size &size1, const Size &size2)
```

### आर्ग्युमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| size1 | const [Size](../)\& | पहला ऑपरेण्ड |
| size2 | const [Size](../)\& | दूसरा ऑपरेण्ड |

### वापसी मान

[Size](../) ऑब्जेक्ट जो **size1** और **size2** का योग है।
