## HandleRepeatedSpaces enum

```cpp
enum class HandleRepeatedSpaces
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| None | 0 | सभी स्पेस को बिना किसी परिवर्तन के नियमित स्पेस अक्षरों के रूप में संरक्षित रखा जाता है। कोई रूपांतरण नहीं किया जाता, और कई लगातार स्पेस को जैसा है वैसा ही निर्यात किया जाता है। |
| AlternateSpacesToNbsp | 1 | दो या अधिक लगातार नियमित स्पेस की श्रंखलाओं को नियमित स्पेस अक्षरों और नॉन-ब्रेकिंग स्पेस एंटिटी (**&nbsp;**) के बीच वैकल्पिक रूप से बदलता है। पहला स्पेस हमेशा नियमित स्पेस के रूप में संरक्षित रहता है। |
| MultipleSpacesToNbsp | 2 | दो या अधिक लगातार नियमित स्पेस की श्रंखलाओं को पहले स्पेस को नियमित स्पेस अक्षर के रूप में संरक्षित रखकर और सभी बाद के स्पेस को नॉन-ब्रेकिंग स्पेस एंटिटी (**&nbsp;**) से बदलकर परिवर्तित करता है। |
