## PdfOptions::set_JpegQuality(uint8_t) मेथड

PDF दस्तावेज़ के भीतर JPEG छवियों की गुणवत्ता निर्धारित करने वाला मान सेट करता है। लिखें **uint8_t**।

```cpp
void Aspose::Slides::Export::PdfOptions::set_JpegQuality(uint8_t value) override
```

## टिप्पणियाँ

यह केवल तब प्रभावी होता है जब दस्तावेज़ में JPEG छवियां हों।

जब PDF प्रारूप में सहेजा जाता है, तो दस्तावेज़ के भीतर छवियों की गुणवत्ता को प्राप्त करने या सेट करने के लिए इस गुण का उपयोग करें। मान 0 से 100 के बीच हो सकता है जहाँ 0 सबसे खराब गुणवत्ता लेकिन अधिकतम संपीड़न दर्शाता है और 100 सबसे अच्छी गुणवत्ता लेकिन न्यूनतम संपीड़न दर्शाता है।

डिफ़ॉल्ट मान **100** है।
