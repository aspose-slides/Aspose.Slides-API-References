## PdfOptions::set_BestImagesCompressionRatio(bool) मेथड

यह दर्शाता है कि प्रत्येक छवि के लिए सबसे प्रभावी संपीड़न (डिफ़ॉल्ट के बजाय) स्वचालित रूप से चुना जाना चाहिए या नहीं। यदि इसे **bool**.true पर सेट किया जाता है, तो प्रस्तुतिकरण की प्रत्येक छवि के लिए सबसे उपयुक्त संपीड़न एल्गोरिथ्म चुना जाएगा, जिससे उत्पन्न PDF दस्तावेज़ का आकार छोटा हो जाएगा।

```cpp
void Aspose::Slides::Export::PdfOptions::set_BestImagesCompressionRatio(bool value) override
```

## टिप्पणी

सर्वोत्कृष्ट छवि संपीड़न अनुपात चयन गणनात्मक रूप से महँगा है और अतिरिक्त RAM की आवश्यकता होती है, और यह विकल्प डिफ़ॉल्ट रूप से **bool**.false रहता है।

डिफ़ॉल्ट मान **bool**.false है।
