## TiffCompressionTypes एनम

TIFF फ़ॉर्मेट में एक प्रस्तुति को संपीड़ित करने के तरीकों को नियंत्रित करने वाले विकल्प प्रदान करता है।

```cpp
enum class TiffCompressionTypes
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| Default | 0 | डिफ़ॉल्ट संपीड़न योजना (LZW) को निर्दिष्ट करता है। |
| None | 1 | कोई संपीड़न नहीं निर्दिष्ट करता है। |
| CCITT3 | 2 | CCITT3 संपीड़न योजना को निर्दिष्ट करता है। |
| CCITT4 | 3 | CCITT4 संपीड़न योजना को निर्दिष्ट करता है। |
| LZW | 4 | LZW संपीड़न योजना (Default) को निर्दिष्ट करता है। |
| RLE | 5 | RLE संपीड़न योजना को निर्दिष्ट करता है। |
