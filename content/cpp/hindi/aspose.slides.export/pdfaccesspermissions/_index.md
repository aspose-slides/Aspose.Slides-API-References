## PdfAccessPermissions enum

इसमें फ़्लैग्स का एक सेट शामिल है जो यह निर्दिष्ट करता है कि दस्तावेज़ को उपयोगकर्ता अभिगम के साथ खोलते समय कौन सी अभिगम अनुमतियों को प्रदान किया जाना चाहिए।

```cpp
enum class PdfAccessPermissions
```

### मान

| Name | Value | Description |
| --- | --- | --- |
| None | 0 | निर्दिष्ट करता है कि उपयोगकर्ता के पास कोई अभिगम अनुमति नहीं है। |
| PrintDocument | 4 | निर्दिष्ट करता है कि उपयोगकर्ता दस्तावेज़ को प्रिंट कर सकता है या नहीं (संभवतः उच्चतम गुणवत्ता स्तर पर नहीं, यह इस पर निर्भर करता है कि बिट [PdfAccessPermissions::HighQualityPrint](./) भी सेट है या नहीं)। |
| ModifyContent | 8 | निर्दिष्ट करता है कि उपयोगकर्ता दस्तावेज़ की सामग्री को उन संचालन द्वारा संशोधित कर सकता है जो बिट्स [PdfAccessPermissions::AddOrModifyFields](./), [PdfAccessPermissions::FillExistingFields](./), [PdfAccessPermissions::AssembleDocument](./) द्वारा नियंत्रित नहीं हैं। |
| CopyTextAndGraphics | 16 | निर्दिष्ट करता है कि उपयोगकर्ता दस्तावेज़ से पाठ और ग्राफ़िक्स को कॉपी या अन्यथा निकाल सकता है उन संचालन द्वारा जो बिट [PdfAccessPermissions::ExtractTextAndGraphics](./) द्वारा नियंत्रित नहीं हैं। |
| AddOrModifyFields | 32 | निर्दिष्ट करता है कि उपयोगकर्ता पाठ एनोटेशन जोड़ या संशोधित कर सकता है, इंटरैक्टिव फ़ॉर्म फ़ील्ड भर सकता है, और यदि बिट [PdfAccessPermissions::ModifyContent](./) भी सेट है, तो इंटरैक्टिव फ़ॉर्म फ़ील्ड (हस्ताक्षर फ़ील्ड सहित) बना या संशोधित कर सकता है। |
| FillExistingFields | 256 | निर्दिष्ट करता है कि उपयोगकर्ता मौजूदा इंटरैक्टिव फ़ॉर्म फ़ील्ड (हस्ताक्षर फ़ील्ड सहित) भर सकता है, भले ही बिट [PdfAccessPermissions::AddOrModifyFields](./) साफ़ हो। |
| ExtractTextAndGraphics | 512 | निर्दिष्ट करता है कि उपयोगकर्ता विकलांग उपयोगकर्ताओं की पहुँच के समर्थन में या अन्य उद्देश्यों के लिए पाठ और ग्राफ़िक्स निकाल सकता है। |
| AssembleDocument | 1024 | निर्दिष्ट करता है कि उपयोगकर्ता दस्तावेज़ को व्यवस्थित कर सकता है (पृष्ठ सम्मिलित, घुमा, या हटाना तथा बुकमार्क या थंबनेल छवियां बनाना), भले ही बिट [PdfAccessPermissions::ModifyContent](./) साफ़ हो। |
| HighQualityPrint | 2048 | निर्दिष्ट करता है कि उपयोगकर्ता दस्तावेज़ को ऐसी अभिव्यक्ति में प्रिंट कर सकता है जिससे PDF सामग्री की एक सटीक डिजिटल प्रति बनाई जा सके। जब यह बिट साफ़ हो (और बिट [PdfAccessPermissions::PrintDocument](./) सेट हो), तो प्रिंटिंग को रूप-रंग की निम्न-स्तर अभिव्यक्ति तक सीमित किया जाता है, जो संभवतः घटी हुई गुणवत्ता की हो सकती है। |
