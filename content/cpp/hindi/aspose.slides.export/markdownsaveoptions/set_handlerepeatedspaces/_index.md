## MarkdownSaveOptions::set_HandleRepeatedSpaces(Aspose::Slides::Export::HandleRepeatedSpaces) विधि


निर्दिष्ट करता है कि Markdown निर्यात के दौरान दोहराए गए नियमित स्पेस अक्षरों को कैसे संभाला जाना चाहिए।

```cpp
void Aspose::Slides::Export::MarkdownSaveOptions::set_HandleRepeatedSpaces(Aspose::Slides::Export::HandleRepeatedSpaces value)
```

## टिप्पणियाँ


यह प्रॉपर्टी निर्धारित करती है कि क्रमागत स्पेस * नियमित स्पेस अक्षरों के रूप में संरक्षित रहें,
* नियमित स्पेस और गैर-विभाज्य स्पेस इकाइयों (**&nbsp;**) के बीच बदलते रहें,
* या Markdown आउटपुट में दृश्य संरेखण बनाए रखने के लिए (पहले के बाद) पूरी तरह **&nbsp;** से प्रतिस्थापित हो जाएँ।



डिफ़ॉल्ट मान है [HandleRepeatedSpaces::AlternateSpacesToNbsp](../../handlerepeatedspaces/).
