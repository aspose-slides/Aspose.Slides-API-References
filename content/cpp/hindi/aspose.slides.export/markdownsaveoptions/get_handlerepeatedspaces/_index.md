## MarkdownSaveOptions::get_HandleRepeatedSpaces() const मेथड


निर्दिष्ट करता है कि Markdown निर्यात के दौरान दोहराए गए नियमित स्पेस वर्णों को कैसे संभाला जाना चाहिए।

```cpp
Aspose::Slides::Export::HandleRepeatedSpaces Aspose::Slides::Export::MarkdownSaveOptions::get_HandleRepeatedSpaces() const
```

## टिप्पणियाँ


यह प्रॉपर्टी निर्धारित करती है कि क्रमागत स्पेस:
* नियमित स्पेस वर्णों के रूप में संरक्षित रहें,
* नियमित स्पेस और अपरिवर्तनीय स्पेस इकाइयों (**&nbsp;**) के बीच वैकल्पिक रूप से उपयोग किए जाएँ,
* या पहले के बाद सभी को **&nbsp;** से पूरी तरह प्रतिस्थापित किया जाए ताकि Markdown आउटपुट में दृश्य संरेखण बना रहे।



डिफ़ॉल्ट मान [HandleRepeatedSpaces::AlternateSpacesToNbsp](../../handlerepeatedspaces/) है।
