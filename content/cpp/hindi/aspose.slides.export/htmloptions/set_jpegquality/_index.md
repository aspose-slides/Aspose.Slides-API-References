## HtmlOptions::set_JpegQuality(uint8_t) विधि

PDF दस्तावेज़ के भीतर JPEG छवियों की गुणवत्ता निर्धारित करने वाला मान सेट करता है। लिखें **uint8_t**.

```cpp
void Aspose::Slides::Export::HtmlOptions::set_JpegQuality(uint8_t value) override
```

## टिप्पणियाँ

यह प्रभाव केवल तब पड़ता है जब दस्तावेज़ में JPEG छवियां हों।

जब PDF प्रारूप में सहेजा जाता है, तो एक दस्तावेज़ के भीतर छवियों की गुणवत्ता प्राप्त करने या सेट करने के लिए इस गुण का उपयोग करें। मान 0 से 100 के बीच हो सकता है जहाँ 0 सबसे खराब गुणवत्ता दर्शाता है लेकिन अधिकतम संपीड़न और 100 सबसे अच्छी गुणवत्ता दर्शाता है लेकिन न्यूनतम संपीड़न।

डिफ़ॉल्ट मान **95** है।
