## ISVGOptions::set_DisableLineEndCropping(bool) विधि

SVG 1.1 में मार्करों के लिए इनसेट परिभाषित करने की क्षमता नहीं है। [Aspose.Slides](../../../aspose.slides/) SVG writing engine उस समस्या के लिए समाधान रखता है: यह तीर के साथ लाइन के अंत को काट देता है, इसलिए लाइन मार्करों के साथ ओवरलैप नहीं करती। यह विकल्प इस व्यवहार को बंद कर देता है। लिखें **bool**।

```cpp
virtual void Aspose::Slides::Export::ISVGOptions::set_DisableLineEndCropping(bool value)=0
```
