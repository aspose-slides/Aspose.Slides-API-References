## LinkEmbedDecision enum

वस्तु को सहेजते समय कैसे प्रोसेस किया जाएगा, यह निर्धारित करता है।

```cpp
enum class LinkEmbedDecision
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| Link | 0 | वस्तु को बाहरी रूप से संग्रहीत किया जाएगा, URL द्वारा संदर्भित |
| Embed | 1 | यदि संभव हो तो वस्तु को उत्पन्न फ़ाइल में एम्बेड किया जाना चाहिए। यदि एम्बेड करना असंभव हो, तो GetUrl कॉल किया जाएगा और परिणाम के अनुसार, वस्तु को URL द्वारा संदर्भित या अनदेखा किया जाएगा। |
| Ignore | 2 | वस्तु को अनदेखा किया जाएगा। |
