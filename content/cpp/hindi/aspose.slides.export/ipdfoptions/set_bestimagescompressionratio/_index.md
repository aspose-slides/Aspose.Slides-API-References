## IPdfOptions::set_BestImagesCompressionRatio(bool) विधि

इसे इंगित करता है कि प्रत्येक चित्र के लिए सबसे प्रभावी संकुशन (डिफ़ॉल्ट के बजाय) को स्वचालित रूप से चुना जाना चाहिए। यदि **bool**.true सेट किया जाता है, तो प्रस्तुति में प्रत्येक चित्र के लिए सबसे उपयुक्त संकुशन एल्गोरिद्म चुना जाएगा, जिससे परिणामी PDF दस्तावेज़ का आकार छोटा रहेगा।

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_BestImagesCompressionRatio(bool value)=0
```

## टिप्पणी

सबसे अच्छा चित्र संकुशन अनुपात चयन संगणनात्मक रूप से महंगा है और अतिरिक्त RAM की आवश्यकता होती है, और यह विकल्प डिफ़ॉल्ट रूप से **bool**.false है।
