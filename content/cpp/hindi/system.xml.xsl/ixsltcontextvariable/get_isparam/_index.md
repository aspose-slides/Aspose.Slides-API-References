## IXsltContextVariable::get_IsParam() विधि

एक मान लौटाता है जो यह दर्शाता है कि चर Extensible Stylesheet Language Transformations (XSLT) पैरामीटर है या नहीं। यह एक स्टाइल शीट या टेम्प्लेट का पैरामीटर हो सकता है।

```cpp
virtual bool System::Xml::Xsl::IXsltContextVariable::get_IsParam()=0
```

### Return Value

**true** if the variable is an XSLT parameter; otherwise, **false**.
