## FormBorderStyle enum

ड्रॉ किए जाने पर बॉर्डर कैसे बनता है, इसे निर्धारित करता है।

```cpp
enum class FormBorderStyle
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| None | 0 | बिलकुल कोई बॉर्डर नहीं। |
| FixedSingle | 1 | [Single](../../system/single/) बॉर्डर। |
| Fixed3D | 2 | 3D जैसा बॉर्डर। |
| FixedDialog | 3 | डायलॉग स्टाइल बॉर्डर। |
| Sizable | 4 | रीसाइज़ेबल बॉर्डर। |
| FixedToolWindow | 5 | अपरिवर्तनीय टूल विंडो बॉर्डर। |
| SizableToolWindow | 6 | रीसाइज़ेबल टूल विंडो बॉर्डर। |
