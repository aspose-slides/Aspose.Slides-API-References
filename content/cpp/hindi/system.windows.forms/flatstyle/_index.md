## FlatStyle enum

नियंत्रण को समतल या त्रि-आयामी रूप में चित्रित किया जाता है या नहीं, यह निर्धारित करता है।

```cpp
enum class FlatStyle
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| Flat | 0 | [Control](../control/) समतल रूप में खींचा गया है। |
| Popup | 1 | [Control](../control/) समतल रूप में खींचा जाता है, जब तक कि माउस उसके ऊपर नहीं चलता और वह 3D जैसा खींचा गया हो। |
| Standard | 2 | [Control](../control/) 3D जैसा खींचा गया है। |
| System | 3 | स्टाइल OS द्वारा नियंत्रित है। |
