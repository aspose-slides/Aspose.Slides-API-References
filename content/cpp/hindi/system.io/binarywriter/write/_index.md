## BinaryWriter::Write(const ArrayPtr\<uint8_t\>\&, int, int) मेथड


निर्दिष्ट बाइट ऐरे से निर्दिष्ट बाइट्स के सबरेंज को आउटपुट स्ट्रीम में लिखता है।

```cpp
virtual void System::IO::BinaryWriter::Write(const ArrayPtr<uint8_t> &buffer, int index=0, int count=-1)
```


### आर्ग्युमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| buffer | const [ArrayPtr](../../../system/arrayptr/)\<**uint8_t**\>\& | बाइट्स लिखने वाली ऐरे |
| index | int | एक 0-आधारित इंडेक्स **buffer** में जहाँ से सबरेंज लिखना शुरू होता है |
| count | int | सबरेंज में तत्वों की संख्या; -1 यह दर्शाता है कि सबरेंज **buffer** ऐरे के अंत पर समाप्त होता है |
