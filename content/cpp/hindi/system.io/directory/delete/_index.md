## Directory::Delete(const String&, bool) मेथड

निर्दिष्ट फ़ाइल या निर्देशिका को हटाता है। कोई अपवाद नहीं फेंकता।

```cpp
static void System::IO::Directory::Delete(const String &path, bool recursive=false)
```

### आर्ग्युमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| path | const [String](../../../system/string/)\& | हटाए जाने वाली निर्देशिका या फ़ाइल का पथ |
| recursive | **bool** | यदि path एक गैर-खाली निर्देशिका निर्दिष्ट करता है तो recursive यह निर्धारित करता है कि सभी निर्देशिका की सामग्री को पुनरावर्ती रूप से हटाना है या नहीं; यदि path द्वारा निर्दिष्ट निर्देशिका खाली नहीं है और recursive 'false' है तो संचालन विफल हो जाता है |
