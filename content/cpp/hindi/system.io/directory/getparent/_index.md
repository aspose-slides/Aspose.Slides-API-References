```cpp
static DirectoryInfoPtr System::IO::Directory::GetParent(const String &path)
```

### Arguments

| Parameter | Type | Description |

| path | const [String](../../../system/string/)\& | उस इकाई का पथ जिसकी पैरेंट प्राप्त किया जाना है |

### Return Value

एक साझा पॉइंटर [DirectoryInfo](../../directoryinfo/) ऑब्जेक्ट के लिए जो **path** द्वारा निर्दिष्ट इकाई की पैरेंट डायरेक्टरी का प्रतिनिधित्व करता है।
