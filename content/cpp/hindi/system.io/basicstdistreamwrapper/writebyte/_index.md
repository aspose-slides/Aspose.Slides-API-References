## BasicSTDIStreamWrapper::WriteByte(uint8_t) विधि

यदि wrapping mode बाइनरी है, तो निर्दिष्ट unsigned 8-bit integer मान को stream में लिखता है, अन्यथा इसे char_type प्रकार में परिवर्तित करके परिणाम को stream में लिखता है। समर्थित नहीं!

```cpp
virtual void System::IO::BasicSTDIStreamWrapper<T, typename>::WriteByte(uint8_t value) override
```
