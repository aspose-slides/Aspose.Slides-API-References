## FileMode enum

फ़ाइल को कैसे खोलना चाहिए, यह निर्दिष्ट करता है।

```cpp
enum class FileMode
```

### मान

| Name | Value | Description |
| --- | --- | --- |
| CreateNew | 1 | एक नई फ़ाइल बनाएँ। यदि फ़ाइल पहले से मौजूद है, तो एक अपवाद फेंका जाता है। |
| Create | 2 | एक नई फ़ाइल बनाएँ। यदि फ़ाइल पहले से मौजूद है, तो उसे ओवरराइट कर दिया जाता है। |
| Open | 3 | एक मौजूदा फ़ाइल खोलें। यदि फ़ाइल मौजूद नहीं है, तो एक अपवाद फेंका जाता है। |
| OpenOrCreate | 4 | एक मौजूदा फ़ाइल खोलें या यदि वह मौजूद नहीं है तो नई फ़ाइल बनाएं। |
| Truncate | 5 | एक मौजूदा फ़ाइल खोलें और उसे छोटा करें ताकि वह खाली हो। यदि फ़ाइल मौजूद नहीं है, तो एक अपवाद फेंका जाता है। |
| Append | 6 | एक मौजूदा फ़ाइल खोलें और उसकी अंत तक पहुंचें या यदि वह मौजूद नहीं है तो नई फ़ाइल बनाएं। |
