## FileShare एनम

निर्दिष्ट करता है कि अन्य [FileStream](../filestream/) वस्तुओं को खुल रहे फ़ाइल तक किस प्रकार का अभिगम हो सकता है।

```cpp
enum class FileShare
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| None | 0 | कोई अभिगम नहीं। |
| Read | 1 | केवल पढ़ने का अभिगम। |
| Write | 2 | केवल लिखने का अभिगम। |
| ReadWrite | 3 | पढ़ने और लिखने दोनों का अभिगम। |
| Delete | 4 | फ़ाइल को हटाया जा सकता है। |
| Inheritable | 16 | फ़ाइल हैंडल को चाइल्ड प्रक्रियाओं द्वारा विरासत योग्य बनाता है। |
