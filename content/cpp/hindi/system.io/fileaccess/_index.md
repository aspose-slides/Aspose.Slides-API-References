## FileAccess enum

फ़ाइल खोलते समय अभिगम का प्रकार निर्दिष्ट करता है।

```cpp
enum class FileAccess
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| Read | 1 | केवल पढ़ने का अभिगम। |
| Write | 2 | केवल लिखने का अभिगम। |
| ReadWrite | n/a | पढ़ने और लिखने का अभिगम। |
