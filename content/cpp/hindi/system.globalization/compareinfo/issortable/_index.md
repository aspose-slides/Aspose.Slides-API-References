## CompareInfo::IsSortable(char16_t) विधि

निर्दिष्ट अक्षर क्रमबद्ध है या नहीं, यह जाँचता है।

```cpp
static bool System::Globalization::CompareInfo::IsSortable(char16_t ch)
```

### आर्ग्यूमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| ch | char16_t | यूनिकोड अक्षर। |

### रिटर्न वैल्यू

True if **ch** is sortable; otherwise false.

## CompareInfo::IsSortable(const String\&) विधि

निर्दिष्ट स्ट्रिंग क्रमबद्ध है या नहीं, यह जाँचता है।

```cpp
static bool System::Globalization::CompareInfo::IsSortable(const String &text)
```

### आर्ग्यूमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| text | const [String](../../../system/string/)\& | एक स्ट्रिंग। |

### रिटर्न वैल्यू

True if **text** is not empty and all characters in **text** are sortable; otherwise false.
