## CompareInfo::IsPrefix(const String\&, const String\&, CompareOptions) const method

निर्दिष्ट स्ट्रिंग की शुरुआत निर्दिष्ट प्रीफ़िक्स से होती है या नहीं, निर्दिष्ट तुलना विकल्पों का उपयोग करके जाँचता है।

```cpp
virtual bool System::Globalization::CompareInfo::IsPrefix(const String &source, const String &prefix, CompareOptions options) const
```

### आर्गुमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| source | const [String](../../../system/string/)\& | स्रोत स्ट्रिंग। |
| prefix | const [String](../../../system/string/)\& | प्रीफ़िक्स स्ट्रिंग। |
| options | [CompareOptions](../../compareoptions/) | तुलना विकल्प। |

### रिटर्न मान

True यदि स्ट्रिंग प्रीफ़िक्स से शुरू होती है; अन्यथा false।
