## XPathNavigator::get_Name() विधि

जब एक व्युत्पन्न वर्ग में ओवरराइड किया जाता है, तो वर्तमान नोड का योग्य नाम प्राप्त करता है।

```cpp
virtual String System::Xml::XPath::XPathNavigator::get_Name()=0
```

### वापसी मान

एक [String](../../../system/string/) जिसमें वर्तमान नोड का योग्य [XPathNavigator::get_Name](./) होता है, या [String::Empty](../../../system/string/empty/) यदि वर्तमान नोड का कोई नाम नहीं है (उदाहरण के लिए, टेक्स्ट या टिप्पणी नोड)।
