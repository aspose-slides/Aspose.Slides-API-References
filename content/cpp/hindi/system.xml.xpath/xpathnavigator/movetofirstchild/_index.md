## XPathNavigator::MoveToFirstChild() विधि

When overridden in a derived class, moves the [XPathNavigator](../) to the first child node of the current node.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToFirstChild()=0
```

### रिटर्न मान

**true** यदि [XPathNavigator](../) सफलतापूर्वक वर्तमान नोड के पहले चाइल्ड नोड पर चलने में सफल हो; अन्यथा, **false**। यदि **false**, तो [XPathNavigator](../) की स्थिति अपरिवर्तित रहती है।
