## XPathNavigator::InsertElementAfter(String, String, String, String) विधि

निर्दिष्ट नेमस्पेस उपसर्ग, स्थानीय नाम और नेमस्पेस URI का उपयोग करके वर्तमान नोड के बाद एक नया सहोदर तत्व बनाता है, साथ ही निर्दिष्ट मान के साथ।

```cpp
virtual void System::Xml::XPath::XPathNavigator::InsertElementAfter(String prefix, String localName, String namespaceURI, String value)
```


### तर्क

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| prefix | [String](../../../system/string/) | नए चाइल्ड तत्व का नेमस्पेस उपसर्ग (यदि हो)। |
| localName | [String](../../../system/string/) | नए चाइल्ड तत्व का स्थानीय नाम (यदि हो)। |
| namespaceURI | [String](../../../system/string/) | नए चाइल्ड तत्व का नेमस्पेस URI (यदि हो)। [String::Empty](../../../system/string/empty/) और **nullptr** समान हैं। |
| value | [String](../../../system/string/) | नए चाइल्ड तत्व का मान। यदि [String::Empty](../../../system/string/empty/) या **nullptr** पास किया जाता है, तो एक खाली तत्व बनाया जाता है। |
