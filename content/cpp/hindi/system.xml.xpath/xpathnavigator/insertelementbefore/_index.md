## XPathNavigator::InsertElementBefore(String, String, String, String) विधि

निर्दिष्ट namespace प्रीफ़िक्स, स्थानीय नाम और namespace URI का उपयोग करके, वर्तमान नोड से पहले एक नया सिब्लिंग तत्व बनाता है, जिसमें निर्दिष्ट मान होता है।

```cpp
virtual void System::Xml::XPath::XPathNavigator::InsertElementBefore(String prefix, String localName, String namespaceURI, String value)
```

### Arguments

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| prefix | [String](../../../system/string/) | नए चाइल्ड एलिमेंट का namespace प्रीफ़िक्स (यदि हो)। |
| localName | [String](../../../system/string/) | नए चाइल्ड एलिमेंट का स्थानीय नाम (यदि हो)। |
| namespaceURI | [String](../../../system/string/) | नए चाइल्ड एलिमेंट का namespace URI (यदि हो)। [String::Empty](../../../system/string/empty/) और **nullptr** समान हैं। |
| value | [String](../../../system/string/) | नए चाइल्ड एलिमेंट का मान। यदि [String::Empty](../../../system/string/empty/) या **nullptr** पास किया जाता है, तो एक खाली एलिमेंट बनाया जाता है। |
