## SoapParameterStyle enum


SOAP संदेश में पैरामीटर स्वरूपों को सूचीबद्ध करता है।

```cpp
enum class SoapParameterStyle
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| Default | 0 | यदि '[SoapDocumentServiceAttribute](../soapdocumentserviceattribute/)' वर्ग पर लागू नहीं किया गया है, तो डिफ़ॉल्ट मान 'Wrapped' है। |
| Bare | 1 | पैरामीटर उन XML तत्वों में रखे जाते हैं जो 'Body' तत्व के बाद आते हैं। |
| Wrapped | 2 | पैरामीटर एक एकल XML तत्व के भीतर समाहित होते हैं जो 'Body' तत्व के बाद आता है। |
