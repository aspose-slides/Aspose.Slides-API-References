## MathBorderBox::set_StrikethroughBottomLeftToTopRight(bool) विधि

Strikethrough Bottom-Left to Top-Right (डिफ़ॉल्ट false है)। बॉर्डर बॉक्स के निचले-बाएँ कोने से ऊपरी-दाएँ कोने तक एक Strikethrough विकर्ण रेखा की छिपी या दिखाई देने वाली स्थिति निर्दिष्ट करता है।

```cpp
void Aspose::Slides::MathText::MathBorderBox::set_StrikethroughBottomLeftToTopRight(bool value) override
```

उदाहरण:

```cpp
auto borderBox = System::MakeObject<MathBorderBox>(System::MakeObject<MathematicalText>(u"x"));
```
