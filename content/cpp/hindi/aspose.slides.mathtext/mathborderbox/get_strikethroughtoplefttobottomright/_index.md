## MathBorderBox::get_StrikethroughTopLeftToBottomRight() मेथड

Strikethrough Top-Left to Bottom-Right (डिफ़ॉल्ट false है)। बॉर्डर बॉक्स के ऊपर-बाएँ कोने से नीचे-दाएँ कोने तक एक स्ट्राइकथ्रू तिरछी रेखा की छिपी या प्रदर्शित स्थिति निर्दिष्ट करता है।

```cpp
bool Aspose::Slides::MathText::MathBorderBox::get_StrikethroughTopLeftToBottomRight() override
```

## टिप्पणी

उदाहरण:
```cpp
auto borderBox = System::MakeObject<MathBorderBox>(System::MakeObject<MathematicalText>(u"x"));
borderBox->set_StrikethroughTopLeftToBottomRight(true);
```
