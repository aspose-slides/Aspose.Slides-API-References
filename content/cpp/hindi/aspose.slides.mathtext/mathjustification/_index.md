## MathJustification enum

गणितीय अनुच्छेद (एक ही अनुच्छेद में गणितीय पाठ की क्रमिक निकटस्थ घटनाओं की श्रृंखला) के संरेखण को निर्दिष्ट करता है

```cpp
enum class MathJustification
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| LeftJustified | 1 | गणितीय पाठ को बाएँ संरेखित करें |
| RightJustified | 2 | गणितीय पाठ को दाएँ संरेखित करें |
| Centered | 3 | गणितीय पाठ को केंद्र में संरेखित करें |
| CenteredAsGroup | 4 | पृष्ठ पर पूरे गणितीय ब्लॉकों के समूह को एक इकाई के रूप में केंद्रित करें। इसका अर्थ है कि गणितीय पाठ की घटनाएँ एक-दूसरे के सापेक्ष संरेखित की जा सकती हैं, लेकिन पूरे गणितीय पाठ का समूह पूर्ण रूप से केंद्रित रहता है। |
