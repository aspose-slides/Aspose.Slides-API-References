## IMathPhantom::set_ZeroDesc(bool) विधि

एक मान सेट करता है जो यह इंगित करता है कि बेस तत्व का descent (आधाररेखा से नीचे की गहराई) शून्य माना जाना चाहिए या नहीं।

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_ZeroDesc(bool value)=0
```

## टिप्पणियाँ

जब **true**, तो phantom आसपास की गणित पंक्ति की बेसलाइन को नहीं घटाता है। यह OMML गुण **m:zeroDesc** के अनुरूप है।
