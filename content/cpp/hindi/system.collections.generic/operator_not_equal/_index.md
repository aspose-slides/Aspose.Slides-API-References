## System::Collections::Generic::operator!=(const KeyValuePair\<TKey, TValue\>\&, const KeyValuePair\<TKey, TValue\>\&) फ़ंक्शन

उल्टा 'equals' सेमैन्टिक्स का उपयोग करके दो कुंजी-मान युग्मों की तुलना करता है।

```cpp
template<typename TKey,typename TValue> bool System::Collections::Generic::operator!=(const KeyValuePair<TKey, TValue> &left, const KeyValuePair<TKey, TValue> &right)
```

### टेम्प्लेट पैरामीटर

| पैरामीटर | विवरण |
| --- | --- |
| TKey | कुंजी प्रकार। |
| TValue | मान प्रकार। |

### आर्गुमेंट्स

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| left | const [KeyValuePair](../keyvaluepair/)\<TKey, TValue\>\& | बाएँ पक्ष का ऑपरेण्ड। |
| right | const [KeyValuePair](../keyvaluepair/)\<TKey, TValue\>\& | दाएँ पक्ष का ऑपरेण्ड। |

### रिटर्न मान

True यदि दोनों कुंजियों और मानों का मेल नहीं है, अन्यथा False।
