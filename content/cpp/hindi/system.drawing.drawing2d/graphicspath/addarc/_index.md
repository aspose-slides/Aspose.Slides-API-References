## GraphicsPath::AddArc(float, float, float, float, float, float) मेथड

वर्तमान ऑब्जेक्ट द्वारा प्रतिनिधित्व किए गए पाथ में निर्दिष्ट दीर्घवृत्तीय चाप जोड़ता है।

```cpp
void System::Drawing::Drawing2D::GraphicsPath::AddArc(float x, float y, float width, float height, float startAngle, float sweepAngle)
```

### आर्ग्युमेंट्स

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| x | **float** | आयत जो दीर्घवृत्त को सीमित करता है, उसके ऊपरी बाएँ कोने का X निर्देशांक |
| y | **float** | आयत जो दीर्घवृत्त को सीमित करता है, उसके ऊपरी बाएँ कोने का Y निर्देशांक |
| width | **float** | आयत के ऊपरी बाएँ कोने की चौड़ाई |
| height | **float** | आयत के ऊपरी बाएँ कोने की ऊँचाई |
| startAngle | **float** | आर्क का प्रारंभिक कोण (डिग्री में) निर्दिष्ट करता है, जो X-अक्ष से घड़ी की दिशा में मापा जाता है |
| sweepAngle | **float** | आर्क के प्रारंभिक कोण और अंत के बीच का कोण निर्दिष्ट करता है |
