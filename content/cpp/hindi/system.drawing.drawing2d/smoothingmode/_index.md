## SmoothingMode एनम

निर्दिष्ट करता है कि रेखाओं, वक्रों और भरे हुए क्षेत्रों के किनारों पर किस प्रकार का सुकून (antialiasing) लागू किया जाता है।

```cpp
enum class SmoothingMode
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| Invalid | n/a | Invalid value. |
| Default | n/a | Default मोड, बिना एंटीएलियासिंग। |
| HighSpeed | n/a | HighSpeed कोई एंटीएलियासिंग नहीं, उच्च गति। |
| HighQuality | n/a | HighQuality एंटीएलियास्ड रेंडरिंग, कम गति। |
| None | n/a | None कोई एंटीएलियासिंग नहीं। |
| AntiAlias | n/a | AntiAlias एंटीएलियास्ड रेंडरिंग। |
