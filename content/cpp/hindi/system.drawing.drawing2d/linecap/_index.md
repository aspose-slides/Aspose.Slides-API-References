## LineCap enum

Indicates the available cap styles with which a [Pen](../../system.drawing/pen/) object can end a line.

```cpp
enum class LineCap
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| Flat | 0 | Flat लाइन कैप। |
| Square | 1 | Square लाइन कैप। |
| Round | 2 | Round लाइन कैप। |
| Triangle | 3 | Triangular लाइन कैप। |
| NoAnchor | 16 | No एंकर। |
| SquareAnchor | 17 | Square एंकर लाइन कैप। |
| RoundAnchor | 18 | Round एंकर लाइन कैप। |
| DiamondAnchor | 19 | Diamond एंकर लाइन कैप। |
| ArrowAnchor | 20 | Arrow एंकर लाइन कैप। |
| AnchorMask | 240 | लाइन कैप एंकर है या नहीं, जाँचने के लिए उपयोग किया जाने वाला मास्क। |
| Custom | 255 | Custom कैप। |
