## PixelOffsetMode enum

निर्दिष्ट करता है कि पिक्सेल को रेंडर होने पर कैसे ऑफसेट किया जाता है।

```cpp
enum class PixelOffsetMode
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| Invalid | n/a | अमान्य मान। |
| Default | n/a | डिफ़ॉल्ट मोड। |
| HighSpeed | n/a | कम गुणवत्ता (उच्च प्रदर्शन) मोड। |
| HighQuality | n/a | उच्च गुणवत्ता (कम प्रदर्शन) मोड। |
| None | n/a | कोई पिक्सेल ऑफसेट नहीं। |
| Half | n/a | पिक्सेल को -0.5 इकाइयों से क्षैतिज और लंबवत दोनों दिशा में ऑफसेट किया जाता है उच्च प्रदर्शन एंटी-एलियासिंग के लिए। |
