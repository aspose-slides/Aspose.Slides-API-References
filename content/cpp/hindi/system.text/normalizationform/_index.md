## NormalizationForm enum

```cpp
enum class NormalizationForm
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| FormC | 1 | पूर्ण कैनॉनिकल विघटन का उपयोग करें, फिर अनुक्रमों को उनके प्राथमिक सम्मिश्रणों से बदलें। |
| FormD | 2 | पूर्ण कैनॉनिकल विघटन का उपयोग करें। |
| FormKC | 5 | पूर्ण संगतता विघटन का उपयोग करें, फिर अनुक्रमों को उनके प्राथमिक सम्मिश्रणों से बदलें। |
| FormKD | 6 | पूर्ण संगतता विघटन का उपयोग करें। |
