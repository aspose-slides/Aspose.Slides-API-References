## Boolean::TryParse(const String\&, bool\&) मेथड

Converts the specified string to a value of bool type.

```cpp
static bool System::Boolean::TryParse(const String &value, bool &result)
```

### आर्ग्युमेंट

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| value | const [String](../../string/)\& | परिवर्तित करने के लिए स्ट्रिंग। |
| result | **bool**\& | परिणाम रखे जाने वाले bool वेरिएबल का रेफ़रेंस; यदि निर्दिष्ट स्ट्रिंग "True" के बराबर है तो परिणाम true होगा और यदि निर्दिष्ट स्ट्रिंग "False" के बराबर है तो परिणाम false होगा। |

## वापसी मान

यदि निर्दिष्ट स्ट्रिंग "True" या "False" में से किसी एक के बराबर है तो true, अन्यथा - false।
