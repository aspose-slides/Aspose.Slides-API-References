## Boolean::Parse(const String\&) विधि

निर्दिष्ट स्ट्रिंग को bool प्रकार के मान में परिवर्तित करता है।

```cpp
static bool System::Boolean::Parse(const String &value)
```

### आर्ग्युमेंट

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| value | const [String](../../string/)\& | परिवर्तित करने के लिये स्ट्रिंग। |

### रिटर्न मान

कनवर्ज़न का परिणाम जहाँ रखी जाती है वह bool वेरिएबल; परिणाम true होता है यदि निर्दिष्ट स्ट्रिंग \"True\" के बराबर हो और false यदि स्ट्रिंग \"False\" के बराबर हो।
