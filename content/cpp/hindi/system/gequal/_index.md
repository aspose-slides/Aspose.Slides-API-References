## System::GEqual(const ExpressionT\&, const ConstantT\&) फ़ंक्शन

'>=' सापेक्ष पैटर्न अनुवाद को लागू करता है।

```cpp
template<class ExpressionT,class ConstantT> bool System::GEqual(const ExpressionT &left, const ConstantT &constant)
```

### टेम्पलेट पैरामीटर

| पैरामीटर | विवरण |
| --- | --- |
| ExpressionT | बाएँ अभिव्यक्ति प्रकार। |
| ConstantT | स्थिर अभिव्यक्ति का प्रकार। |

### आर्ग्यूमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| left | const ExpressionT\& | जिस अभिव्यक्ति की जाँच की जाएगी। |
| constant | const ConstantT\& | जिस अभिव्यक्ति की बाएँ के साथ तुलना की जाएगी। |

### रिटर्न मान

यदि प्रकार जाँच सफल होती है तो true, अन्यथा false।
