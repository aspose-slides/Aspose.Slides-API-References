## Guid::Parse(const String\&) विधि

एक GUID की निर्दिष्ट स्ट्रिंग प्रतिनिधित्व को समान [Guid](../) ऑब्जेक्ट में परिवर्तित करता है।

```cpp
static Guid System::Guid::Parse(const String &input)
```

### आर्गुमेंट्स

| परिमाण | प्रकार | विवरण |
| --- | --- | --- |
| input | const [String](../../string/)\& | GUID का स्ट्रिंग प्रतिनिधित्व रखने वाली स्ट्रिंग |

### रिटर्न मान

एक [Guid](../) ऑब्जेक्ट जो **input** द्वारा दर्शाए गए GUID के समान है।
