## Math::Truncate(const Decimal\&) विधि

वापसी करता है [Decimal](../../decimal/) ऑब्जेक्ट जो एक मान को दर्शाता है, जिसका पूर्णांक भाग निर्दिष्ट [Decimal](../../decimal/) ऑब्जेक्ट द्वारा दर्शाए गए मान के समान होता है और सभी दशमलव अंकों को हटाया गया होता है।

```cpp
static Decimal System::Math::Truncate(const Decimal &d)
```

### आर्ग्यूमेंट्स

| परामीटर | प्रकार | विवरण |
| --- | --- | --- |
| d | const [Decimal](../../decimal/)\& | एक दशमलव संख्या |

### रिटर्न वैल्यू

[Decimal](../../decimal/) ऑब्जेक्ट जो एक दशमलव मान को दर्शाता है, जिसका पूर्णांक भाग निर्दिष्ट मान के समान है और दशमलव अंकों को सभी 0 कर दिया गया है।

## Math::Truncate(double) विधि

वापसी करता है एक double-precision फ्लोटिंग पॉइंट मान जो निर्दिष्ट मान के समान पूर्णांक भाग रखता है और सभी दशमलव अंकों को हटा दिया गया है।

```cpp
static double System::Math::Truncate(double d)
```

### आर्ग्यूमेंट्स

| परामीटर | प्रकार | विवरण |
| --- | --- | --- |
| d | **double** | एक दशमलव संख्या |

### रिटर्न वैल्यू

एक double-precision फ्लोटिंग पॉइंट मान जिसका पूर्णांक भाग निर्दिष्ट मान के समान है और दशमलव अंकों को सभी 0 कर दिया गया है।
