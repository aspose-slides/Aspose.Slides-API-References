## Math::DivRem(int, int, int\&) विधि

दो 32-बिट पूर्णांकों का भागफल और शेष की गणना करता है।

```cpp
static int System::Math::DivRem(int a, int b, int &result)
```

### आर्ग्युमेंट्स

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| a | int | डिविडेंड |
| b | int | डिवाइज़र |
| result | int\& | वह आउटपुट पैरामीटर जो **a** को **b** द्वारा विभाजन करने पर प्राप्त शेष रखता है |

### रिटर्न मान

**a** और **b** का उद्धरण
