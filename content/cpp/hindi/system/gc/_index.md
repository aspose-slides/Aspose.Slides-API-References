## GC वर्ग

एक अनुकरणीय गार्बेज कलेक्शन का प्रतिनिधित्व करता है जो प्रभावी रूप से कुछ नहीं करता, अधिकतर एक स्टब की तरह कार्य करता है। यह एक स्थैतिक प्रकार है जिसके पास कोई इंस्टेंस सेवाएँ नहीं हैं। आपको इसे किसी भी तरह से इंस्टेंस नहीं बनाना चाहिए।

```cpp
class GC : public System::Object
```
