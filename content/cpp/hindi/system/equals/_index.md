## System::Equals(const TA\&, const TB\&) फ़ंक्शन


दो मानों की समानता निर्धारित करता है, जिसमें [operator==()](../operator_equal_equal/) लागू किया जाता है।

```cpp
template<typename TA,typename TB> bool System::Equals(const TA &a, const TB &b)
```


### टेम्प्लेट पैरामीटर

| पैरामीटर | विवरण |
| --- | --- |
| TA | पहले तुलना किए जाने वाले का प्रकार |
| TB | दूसरे तुलना किए जाने वाले का प्रकार |

### आर्ग्युमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| a | const TA\& | पहला तुलना किया जाने वाला |
| b | const TB\& | दूसरा तुलना किया जाने वाला |

### रिटर्न वैल्यू

[operator==()](../operator_equal_equal/) द्वारा **a** और **b** पर लागू किया गया बूलियन मान
