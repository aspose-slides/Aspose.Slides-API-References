## Array::Resize(ArrayPtr\<Type\>\&, int) मेथड

निर्दिष्ट Array का आकार निर्दिष्ट मान में बदलता है या निर्दिष्ट आकार के साथ नया Array बनाता है।

```cpp
template<typename Type> static void System::Array<T>::Resize(ArrayPtr<Type> &arr, int new_size)
```


### आर्ग्यूमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| arr | [ArrayPtr](../../arrayptr/)\<[Type](../../object/type/)\>\& | [Array](../) को पुनः आकार देने के लिए। यदि **arr** null-pointer है, तो नया array बनाया जाएगा |
| new_size | int | Array का नया आकार, या यदि **arr** null है तो नए Array का आकार |
