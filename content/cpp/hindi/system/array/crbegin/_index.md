## Array::crbegin() const मेथड

रिवर्स्ड कंटेनर के पहले तत्व के लिए एक रिवर्स इटरैटर लौटाता है। यह नॉन-रिवर्स्ड कंटेनर के अंतिम तत्व के अनुरूप है। यदि कंटेनर खाली है, तो लौटाया गया इटरैटर [crend()](../crend/) के बराबर होगा।

```cpp
const_reverse_iterator System::Array<T>::crbegin() const noexcept
```

### रिटर्न वैल्यू

एक इटरैटर जो कंटेनर के अंतिम const-योग्य तत्व की ओर इंगित करता है।
