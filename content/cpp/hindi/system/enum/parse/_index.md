## Enum::Parse(const String&, bool) विधि

निर्दिष्ट स्ट्रिंग को समकक्ष enum कॉन्स्टैंट में परिवर्तित करता है।

```cpp
static E System::Enum<E, Guard>::Parse(const String &str, bool ignoreCase=false)
```


### आर्ग्युमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| str | const [String](../../string/)\& | [String](../../string/) जिसे enum कॉन्स्टैंट के नाम को शामिल करने वाला माना जाता है |
| ignoreCase | **bool** | निर्दिष्ट करता है कि स्ट्रिंग को व्याख्यायित करते समय केस को अनदेखा किया जाना चाहिए या नहीं |

### वापसी मान

वह enumeration कॉन्स्टैंट जिसका नाम **str** में निर्दिष्ट किया गया है
