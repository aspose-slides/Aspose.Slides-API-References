## System::static_pointer_cast(SmartPtr\<X\> const\&) फ़ंक्शन

static_cast का उपयोग करके स्मार्ट पॉइंटर्स को कास्ट करता है।

```cpp
template<class Y,class X> SmartPtr<Y> System::static_pointer_cast(SmartPtr<X> const &x)
```

### टेम्प्लेट पैरामीटर

| पैरामीटर | विवरण |
| --- | --- |
| X | स्रोत पॉइंटर का पॉइंटीय प्रकार। |
| Y | लक्षित पॉइंटर का पॉइंटीय प्रकार। |

### आर्ग्युमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| x | [SmartPtr](../smartptr/)\<X\> const\& | स्रोत पॉइंटर। |

### रिटर्न वैल्यू
