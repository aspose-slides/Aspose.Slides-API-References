## Char::IsDigit(const char_t *, int) method

निर्धारित करता है कि निर्दिष्ट अक्षर बफ़र में निर्दिष्ट इंडेक्स पर मौजूद अक्षर को दशमलव अंक के रूप में वर्गीकृत किया गया है या नहीं।

```cpp
static bool System::Char::IsDigit(const char_t *str, int idx)
```

### आर्ग्यूमेंट्स

| Parameter | Type | Description |
| --- | --- | --- |
| str | const char_t * | अक्षर बफ़र की शुरुआत की ओर संकेतक |
| idx | int | परीक्षण किए जाने वाले अक्षर के बफ़र में शून्य-आधारित इंडेक्स |

### Return Value

True यदि निर्दिष्ट इंडेक्स पर अक्षर दशमलव अंक है, अन्यथा - false
