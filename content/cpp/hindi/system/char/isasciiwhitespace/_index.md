## Char::IsAsciiWhiteSpace(char_t) विधि


निर्धारित करता है कि निर्दिष्ट अक्षर को ASCII सफेद स्पेस अक्षर के रूप में वर्गीकृत किया गया है या नहीं।

```cpp
static constexpr bool System::Char::IsAsciiWhiteSpace(char_t c)
```


### आर्गुमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| c | char_t | परीक्षण करने के लिए अक्षर |

### वापसी मान

यदि निर्दिष्ट अक्षर ASCII सफेद स्पेस अक्षर है तो True, अन्यथा - false
