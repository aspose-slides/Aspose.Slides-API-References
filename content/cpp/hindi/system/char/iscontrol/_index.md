## Char::IsControl(const char_t *, int) विधि


निर्धारित करता है कि निर्दिष्ट कैरेक्टर बफ़र में निर्दिष्ट सूचकांक पर स्थित अक्षर Unicode नियंत्रण अक्षर के रूप में वर्गीकृत है या नहीं।

```cpp
static bool System::Char::IsControl(const char_t *str, int idx)
```


### आर्ग्युमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| str | const char_t * | कैरेक्टर बफ़र की शुरुआत की ओर संकेतकर्ता |
| idx | int | परीक्षण किए जाने वाले अक्षर के बफ़र में शून्य-आधारित सूचकांक |

### वापसी मान

यदि निर्दिष्ट सूचकांक पर अक्षर Unicode नियंत्रण अक्षर है तो True, अन्यथा - false
