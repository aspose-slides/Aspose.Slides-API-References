## Char::IsSeparator(const char_t *, int) विधि


निर्दिष्ट वर्ण बफ़र में निर्दिष्ट अनुक्रमणिका पर स्थित वर्ण को विभाजक (separator) वर्ण के रूप में वर्गीकृत किया गया है या नहीं, यह निर्धारित करता है।

```cpp
static bool System::Char::IsSeparator(const char_t *str, int idx)
```


### आर्ग्युमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| str | const char_t * | वर्ण बफ़र की शुरुआत की ओर संकेत करने वाला पॉइंटर |
| idx | int | परीक्षण किए जाने वाले वर्ण का निर्दिष्ट बफ़र में शून्य-आधारित अनुक्रमणिका |

### रिटर्न वैल्यू

यदि निर्दिष्ट अनुक्रमणिका पर वर्ण एक विभाजक वर्ण है तो सही, अन्यथा - गलत

```cpp
static bool System::Char::IsSeparator(char_t c)
```
