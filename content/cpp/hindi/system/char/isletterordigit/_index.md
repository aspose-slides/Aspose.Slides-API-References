## Char::IsLetterOrDigit(const char_t *, int) विधि

निर्धारित करता है कि निर्दिष्ट कैरेक्टर बफ़र में निर्दिष्ट इंडेक्स पर स्थित वर्ण को Unicode अक्षर या दशमलव अंक के रूप में वर्गीकृत किया गया है या नहीं।

```cpp
static bool System::Char::IsLetterOrDigit(const char_t *str, int idx)
```

### तर्क

| Parameter | Type | Description |
| --- | --- | --- |
| str | const char_t * | कैरेक्टर बफ़र की शुरुआत का पॉइंटर |
| idx | int | टेस्ट किए जाने वाले वर्ण के लिए निर्दिष्ट बफ़र में शून्य-आधारित इंडेक्स |

### वापसी मान

True यदि निर्दिष्ट इंडेक्स पर स्थित वर्ण Unicode अक्षर या दशमलव अंक है, अन्यथा - false

निर्धारित करता है कि निर्दिष्ट वर्ण को Unicode अक्षर या दशमलव अंक के रूप में वर्गीकृत किया गया है या नहीं।

```cpp
static bool System::Char::IsLetterOrDigit(char_t c)
```

### तर्क

| Parameter | Type | Description |

| c | char_t | टेस्ट करने के लिए वर्ण |

### वापसी मान
