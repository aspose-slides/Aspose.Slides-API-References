## Char::IsSymbol(const char_t *, int) विधि

निर्धारित करता है कि निर्दिष्ट वर्ण बफ़र में निर्दिष्ट सूचकांक पर स्थित वर्ण को प्रतीक वर्ण के रूप में वर्गीकृत किया गया है या नहीं।

```cpp
static bool System::Char::IsSymbol(const char_t *str, int idx)
```

### आर्ग्युमेंट्स

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| str | const char_t * | वर्ण बफ़र की शुरुआत का पॉइंटर |
| idx | int | परीक्षण किए जाने वाले वर्ण के लिए निर्दिष्ट बफ़र में शून्य-आधारित सूचकांक |

### वापसी मान

True यदि निर्दिष्ट सूचकांक पर स्थित वर्ण एक प्रतीक वर्ण है, अन्यथा false

## Char::IsSymbol(char_t) विधि

निर्धारित करता है कि निर्दिष्ट वर्ण को प्रतीक वर्ण के रूप में वर्गीकृत किया गया है या नहीं।

```cpp
static bool System::Char::IsSymbol(char_t c)
```

### आर्ग्युमेंट्स

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| c | char_t | परीक्षण करने के लिए वर्ण |

### वापसी मान

True यदि निर्दिष्ट वर्ण एक प्रतीक वर्ण है, अन्यथा false
