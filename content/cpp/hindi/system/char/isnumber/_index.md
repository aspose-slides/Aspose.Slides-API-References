## Char::IsNumber(const char_t *, int) मेथड


निर्धारित करता है कि निर्दिष्ट अक्षर बफ़र में निर्दिष्ट सूचकांक पर स्थित अक्षर संख्या के रूप में वर्गीकृत है या नहीं।

```cpp
static bool System::Char::IsNumber(const char_t *str, int idx)
```


### आर्ग्युमेंट्स

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| str | const char_t * | अक्षर बफ़र की शुरुआत का पॉइंटर |
| idx | int | परीक्षण के लिए अक्षर के निर्दिष्ट बफ़र में शून्य-आधारित सूचकांक |

### रिटर्न मान

यदि निर्दिष्ट सूचकांक पर अक्षर संख्या है तो true, अन्यथा false

```cpp
static bool System::Char::IsNumber(char_t c)
```


### आर्ग्युमेंट्स

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| c | char_t | परीक्षण करने हेतु अक्षर |

### रिटर्न मान

यदि निर्दिष्ट अक्षर संख्या है तो true, अन्यथा false
