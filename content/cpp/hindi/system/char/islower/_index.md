## Char::IsLower(const char_t *, int) मेथड

निर्धारित करता है कि निर्दिष्ट वर्ण बफ़र में बताए गये अनुक्रमणिका पर स्थित वर्ण को लोअर केस अक्षर के रूप में वर्गीकृत किया गया है या नहीं।

```cpp
static bool System::Char::IsLower(const char_t *str, int idx)
```

### आर्ग्युमेंट्स

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| str | const char_t * | Pointer to the beginning of the character buffer |
| idx | int | A zero-based index in the specified buffer of the character to test |

### रिटर्न वैल्यू

यदि निर्दिष्ट अनुक्रमणिका पर स्थित वर्ण लोअर केस अक्षर है तो true, अन्यथा - false

```cpp
static bool System::Char::IsLower(char_t c)
```

### आर्ग्युमेंट्स

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| c | char_t | परीक्षण करने के लिए वर्ण |

### रिटर्न वैल्यू

यदि निर्दिष्ट वर्ण लोअर केस अक्षर है तो true, अन्यथा - false

## Char::IsLower(const String\&, int) मेथड

निर्धारित करता है कि निर्दिष्ट स्ट्रिंग में बताए गये अनुक्रमणिका पर स्थित वर्ण को लोअर केस अक्षर के रूप में वर्गीकृत किया गया है या नहीं।

```cpp
static bool System::Char::IsLower(const String &str, int idx)
```

### आर्ग्युमेंट्स

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| str | const [String](../../string/)\& | एक स्ट्रिंग |
| idx | int | निर्दिष्ट स्ट्रिंग में परीक्षण करने के लिए शून्य-आधारित अनुक्रमणिका |

### रिटर्न वैल्यू

यदि निर्दिष्ट अनुक्रमणिका पर स्थित वर्ण लोअर केस अक्षर है तो true, अन्यथा - false
