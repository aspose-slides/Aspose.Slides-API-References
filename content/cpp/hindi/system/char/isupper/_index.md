## Char::IsUpper(const String\&, int) मेथड

निर्धारित करता है कि निर्दिष्ट स्ट्रिंग में निर्दिष्ट इंडेक्स पर स्थित अक्षर को अपर केस लेटर के रूप में वर्गीकृत किया गया है या नहीं।

```cpp
static bool System::Char::IsUpper(const String &str, int idx)
```

### आर्ग्युमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| str | const [String](../../string/)\& | वह स्ट्रिंग जिसमें एक अक्षर होता है। |
| idx | int | परीक्षण के लिए निर्दिष्ट स्ट्रिंग में शून्य-आधारित इंडेक्स |

### रिटर्न वैल्यू

True यदि निर्दिष्ट इंडेक्स पर अक्षर एक अपर केस लेटर है, अन्यथा - false

## Char::IsUpper(const char_t *, int) मेथड

निर्धारित करता है कि निर्दिष्ट कैरेक्टर बफ़र में निर्दिष्ट इंडेक्स पर स्थित अक्षर को अपर केस लेटर के रूप में वर्गीकृत किया गया है या नहीं।

```cpp
static bool System::Char::IsUpper(const char_t *str, int idx)
```

### आर्ग्युमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| str | const char_t * | कैरेक्टर बफ़र की शुरुआत की ओर संकेत करने वाला पॉइंटर |
| idx | int | परीक्षण के लिए निर्दिष्ट बफ़र में अक्षर का शून्य-आधारित इंडेक्स |

### रिटर्न वैल्यू

True यदि निर्दिष्ट इंडेक्स पर अक्षर एक अपर केस लेटर है, अन्यथा - false

## Char::IsUpper(char_t) मेथड

निर्धारित करता है कि निर्दिष्ट अक्षर को अपर केस लेटर के रूप में वर्गीकृत किया गया है या नहीं।

```cpp
static bool System::Char::IsUpper(char_t c)
```

### आर्ग्युमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| c | char_t | परीक्षण हेतु अक्षर |

### रिटर्न वैल्यू

True यदि निर्दिष्ट अक्षर एक अपर केस लेटर है, अन्यथा - false
