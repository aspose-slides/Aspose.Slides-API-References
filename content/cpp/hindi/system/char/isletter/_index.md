## Char::IsLetter(const char_t *, int) मेथड

निर्धारित करता है कि निर्दिष्ट वर्ण बफ़र में निर्दिष्ट इंडेक्स पर स्थित वर्ण को यूनिकोड लेटर के रूप में वर्गीकृत किया गया है या नहीं।

```cpp
static bool System::Char::IsLetter(const char_t *str, int idx)
```

### आर्ग्युमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| str | const char_t * | वर्ण बफ़र की शुरुआत की ओर संकेतकर्ता |
| idx | int | परीक्षण किए जाने वाले वर्ण के लिए निर्दिष्ट बफ़र में शून्य-आधारित इंडेक्स |

### रिटर्न वैल्यू

यदि निर्दिष्ट इंडेक्स पर वर्ण यूनिकोड लेटर है तो true, अन्यथा false

static bool System::Char::IsLetter(char_t c)

### आर्ग्युमेंट्स
