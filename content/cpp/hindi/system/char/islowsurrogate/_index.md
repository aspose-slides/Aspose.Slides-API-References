## Char::IsLowSurrogate(const char_t *, int) मेथड

निर्धारित करता है कि निर्दिष्ट वर्ण बफ़र में निर्दिष्ट इंडेक्स पर स्थित वर्ण लो सरोगेट है या नहीं।

```cpp
static bool System::Char::IsLowSurrogate(const char_t *str, int idx)
```

### आर्ग्यूमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| str | const char_t * | वर्ण बफ़र की शुरुआत की ओर संकेत करने वाला पॉइंटर |
| idx | int | परीक्षण किए जाने वाले वर्ण का निर्दिष्ट बफ़र में शून्य-आधारित इंडेक्स |

### रिटर्न वैल्यू

यदि निर्दिष्ट इंडेक्स पर वर्ण लो सरोगेट है तो True, अन्यथा - false
