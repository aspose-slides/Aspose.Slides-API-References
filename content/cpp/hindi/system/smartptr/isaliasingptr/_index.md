## SmartPtr::IsAliasingPtr() const विधि

```cpp
bool System::SmartPtr<T>::IsAliasingPtr() const
```

### रिटर्न वैल्यू

यदि पॉइंटर द्वारा इंगित और स्वाधीन ऑब्जेक्ट अलग हैं तो true, अन्यथा false।
