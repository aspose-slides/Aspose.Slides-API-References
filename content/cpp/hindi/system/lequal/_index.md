## System::LEqual(const ExpressionT\&, const ConstantT\&) फ़ंक्शन


Implements '<=' relative pattern translation. ‘<=’ सापेक्ष पैटर्न अनुवाद को लागू करता है।

```cpp
template<class ExpressionT,class ConstantT> bool System::LEqual(const ExpressionT &left, const ConstantT &constant)
```


### टेम्पलेट पैरामीटर

| पैरामीटर | विवरण |
| --- | --- |
| ExpressionT | बाएँ अभिव्यक्ति प्रकार। |
| ConstantT | स्थिर अभिव्यक्ति का प्रकार। |

### आर्गुमेंट

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| left | const ExpressionT\& | अभिव्यक्ति जिसे जाँचा जाएगा। |
| constant | const ConstantT\& | अभिव्यक्ति जिसे बाएँ के साथ तुलना की जाएगी। |

### रिटर्न वैल्यू

यदि प्रकार जाँच सफल हो तो true, अन्यथा false।
