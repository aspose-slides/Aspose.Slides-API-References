## Convert::ToDateTime(const String\&) विधि

निर्दिष्ट स्ट्रिंग को [DateTime](../../datetime/) क्लास का एक इंस्टेंस में परिवर्तित करता है।

```cpp
static DateTime System::Convert::ToDateTime(const String &value)
```

### आर्ग्युमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| value | const [String](../../string/)\& | परिवर्तित की जाने वाली स्ट्रिंग |

### रिटर्न वैल्यू

[DateTime](../../datetime/) क्लास का एक इंस्टेंस जो निर्दिष्ट स्ट्रिंग द्वारा दर्शाई गई तिथि और समय जानकारी को प्रतिनिधित्व करता है

## Convert::ToDateTime(const String\&, const SharedPtr\<IFormatProvider\>\&) विधि

प्रदान की गई फ़ॉर्मेटिंग जानकारी का उपयोग करके निर्दिष्ट स्ट्रिंग को [DateTime](../../datetime/) क्लास का एक इंस्टेंस में बदलता है।

```cpp
static DateTime System::Convert::ToDateTime(const String &value, const SharedPtr<IFormatProvider> &fp)
```

### आर्ग्युमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| value | const [String](../../string/)\& | परिवर्तित की जाने वाली स्ट्रिंग |
| fp | const [SharedPtr](../../sharedptr/)\<[IFormatProvider](../../iformatprovider/)\>\& | स्ट्रिंग फ़ॉर्मेट जानकारी रखने वाले ऑब्जेक्ट का पॉइंटर |

## Convert::ToDateTime(const SharedPtr\<Object\>\&, const SharedPtr\<IFormatProvider\>\&) विधि

निर्दिष्ट बॉक्स्ड मान को समान [DateTime](../../datetime/) मान में बदलता है।

```cpp
static DateTime System::Convert::ToDateTime(const SharedPtr<Object> &obj, const SharedPtr<IFormatProvider> &provider=nullptr)
```

### आर्ग्युमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| obj | const [SharedPtr](../../sharedptr/)\<[Object](../../object/)\>\& | मान को परिवर्तित करने वाले ऑब्जेक्ट का शेयर्ड पॉइंटर |
| provider | const [SharedPtr](../../sharedptr/)\<[IFormatProvider](../../iformatprovider/)\>\& | यदि बॉक्स्ड मान का प्रकार [String](../../string/) है तो उपयोग की जाने वाली स्ट्रिंग फ़ॉर्मेट |

### रिटर्न वैल्यू

एक [DateTime](../../datetime/) मान जो निर्दिष्ट बॉक्स्ड मान के समान है
