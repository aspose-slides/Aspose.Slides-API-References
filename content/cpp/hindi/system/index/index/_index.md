```cpp
constexpr System::Index::Index() noexcept
```

## Index::Index(int32_t) कंस्ट्रक्टर

एक उदाहरण बनाता है जो संग्रह की शुरुआत से निर्दिष्ट स्थिति का प्रतिनिधित्व करता है।

```cpp
constexpr System::Index::Index(int32_t value) noexcept
```

### आर्ग्युमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| value | **int32_t** | शुरुआत से शून्य-आधारित इंडेक्स। |

## Index::Index(int32_t, bool) कंस्ट्रक्टर

एक उदाहरण बनाता है जो निर्दिष्ट इंडेक्स का प्रतिनिधित्व करता है।

```cpp
constexpr System::Index::Index(int32_t value, bool from_end) noexcept
```

### आर्ग्युमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| value | **int32_t** | इंडेक्स मान। |
| from_end | **bool** | सत्य यदि इंडेक्स संग्रह के अंत के सापेक्ष है। |
