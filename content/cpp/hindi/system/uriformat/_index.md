## UriFormat enum

URI कैसे एस्केप किया गया है, यह निर्दिष्ट करता है।

```cpp
enum class UriFormat
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| UriEscaped | 1 | RFC-2396 के अनुसार एस्केपिंग। |
| Unescaped | 2 | कोई एस्केपिंग नहीं। |
| SafeUnescaped | 3 | केवल वे अक्षर जो URI में आरक्षित अर्थ रखते हैं, एस्केप किए जाते हैं। |
