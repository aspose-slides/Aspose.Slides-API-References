## WeakPtr::get_weak() const विधि


संदर्भित ऑब्जेक्ट प्राप्त करता है। यह सुनिश्चित करता है कि पॉइंटर कमजोर मोड में है।

```cpp
Object * System::WeakPtr<T>::get_weak() const
```


### रिटर्न वैल्यू

यदि असाइन किया गया हो और समाप्त न हुआ हो तो संदर्भित ऑब्जेक्ट का रॉ पॉइंटर (या nullptr)।
