## String::IsNullOrWhiteSpace(const String\&) मेथड

निर्दिष्ट स्ट्रिंग null, खाली, या केवल white-space अक्षरों से बनी है या नहीं, यह दर्शाता है।

```cpp

```

### रिटर्न मान

यदि स्ट्रिंग null या खाली है या केवल white-space अक्षरों से बनी है तो true, अन्यथा false।
