## String::operator!=(const String\&) const मेथड

असमानता तुलना ऑपरेटर।

```cpp
bool System::String::operator!=(const String &str) const
```

### आर्ग्युमेंट्स

| परामित्र | प्रकार | विवरण |
| --- | --- | --- |
| str | const [String](../)\& | [String](../) को वर्तमान से तुलना करने के लिए। |

### वापसी मान

false यदि दोनों स्ट्रिंग्स null हैं या दोनों null नहीं हैं और समान हैं, true अन्यथा।

## String::operator!=(std::nullptr_t) const मेथड

bool System::String::operator!=(std::nullptr_t) const

### वापसी मान
