## Uri::IsHexEncoding(const String\&, int32_t) विधि


निर्धारण करता है कि निर्दिष्ट स्ट्रिंग में निर्दिष्ट स्थिति पर स्थित अक्षर हैक्साडेसिमल एन्कोडेड है या नहीं।

```cpp
static bool System::Uri::IsHexEncoding(const String &pattern, int32_t index)
```


### Arguments

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| pattern | const [String](../../string/)\& | जाँचने के लिए स्ट्रिंग |
| index | **int32_t** | परीक्षण करने वाले अक्षर की शून्य-आधारित स्थिति |

### Return Value

True यदि निर्दिष्ट अक्षर हैक्साडेसिमल एन्कोडेड है, अन्यथा - false
