## System::IsNaN(const T\&) फ़ंक्शन

निर्धारित करता है कि निर्दिष्ट मान Not-A-Number मान है या नहीं।

```cpp
template<typename T> bool System::IsNaN(const T &value)
```

### टेम्प्लेट पैरामीटर

| पैरामीटर | विवरण |
| --- | --- |
| T | फ़ंक्शन द्वारा जाँच किए गए मान का प्रकार |

### आर्ग्युमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| value | const T\& | जाँच करने के लिए मान |

### रिटर्न वैल्यू

यदि **value** NaN मान है तो true, अन्यथा - false
