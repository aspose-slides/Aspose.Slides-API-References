## Attribute::GetCustomAttribute(const TypeInfo\&, const TypeInfo\&) विधि


एक निर्दिष्ट प्रकार पर लागू एक कस्टम एट्रीब्यूट लौटाता है।

```cpp
static Object::ptr System::Attribute::GetCustomAttribute(const TypeInfo &type, const TypeInfo &attributeType)
```


### आर्ग्युमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| type | const [TypeInfo](../../typeinfo/)\& | जिस प्रकार का एट्रीब्यूट प्राप्त किया जाता है |
| attributeType | const [TypeInfo](../../typeinfo/)\& | प्राप्त किए जाने वाले एट्रीब्यूट का प्रकार |

### वापसी मान

यदि निर्दिष्ट प्रकार के पास निर्दिष्ट प्रकार का एट्रीब्यूट नहीं है तो प्राप्त एट्रीब्यूट या null।
