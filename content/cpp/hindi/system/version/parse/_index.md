## Version::Parse(const String\&) विधि

एक संस्करण संख्या के स्ट्रिंग प्रतिनिधित्व को [Version](../) क्लास की समतुल्य उदाहरण में परिवर्तित करता है।

```cpp
static Version System::Version::Parse(const String &input)
```

### आर्ग्यूमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| input | const [String](../../string/)\& | एक स्ट्रिंग जिसमें संस्करण संख्या के स्ट्रिंग प्रतिनिधित्व होता है |

### वापसी मान

[Version](../) क्लास का एक उदाहरण जो संस्करण संख्या को दर्शाता है जो **input** द्वारा प्रस्तुत किया गया है
