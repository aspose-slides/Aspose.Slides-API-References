## WeakReference< T >::operator!=(std::nullptr_t) const विधि

जाँचता है कि संदर्भित वस्तु शून्य नहीं है।

```cpp
bool System::WeakReference<T>::operator!=(std::nullptr_t) const
```

### वापसी मान

यदि संदर्भित वस्तु शून्य नहीं है तो true, अन्यथा false।

## WeakReference< T >::operator!=(const WeakReference\<T\>\&) const विधि

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |

### वापसी मान
