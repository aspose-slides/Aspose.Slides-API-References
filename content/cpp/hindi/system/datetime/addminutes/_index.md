## DateTime::AddMinutes(double) const विधि

एक नया [DateTime](../) क्लास का उदाहरण लौटाता है जो वर्तमान ऑब्जेक्ट द्वारा प्रदर्शित मान और निर्दिष्ट मिनटों की संख्या के योग के रूप में दिनांक और समय मान को दर्शाता है।

```cpp
DateTime System::DateTime::AddMinutes(double value) const
```

### Arguments

| Parameter | Type | Description |
| --- | --- | --- |
| value | **double** | जोड़ने के लिए मिनटों की संख्या; मान सकारात्मक या नकारात्मक हो सकता है |

### Return Value

एक नया [DateTime](../) क्लास का उदाहरण जो वर्तमान ऑब्जेक्ट द्वारा प्रदर्शित मान और **value** मिनटों के योग के रूप में दिनांक और समय मान को दर्शाता है।
