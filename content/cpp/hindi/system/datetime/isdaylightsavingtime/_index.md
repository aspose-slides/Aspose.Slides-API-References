## DateTime::IsDaylightSavingTime() const विधि

निर्धारित करता है कि वर्तमान वस्तु द्वारा प्रतिनिधित्व किया गया तिथि और समय मान वर्तमान समय क्षेत्र के लिए डेलाइट सेविंग टाइम की सीमा में आता है या नहीं।

```cpp
bool System::DateTime::IsDaylightSavingTime() const
```

### रिटर्न वैल्यू

True यदि वर्तमान वस्तु द्वारा निर्दिष्ट तिथि और समय मान डेलाइट सेविंग टाइम की सीमा में आता है, अन्यथा - false
