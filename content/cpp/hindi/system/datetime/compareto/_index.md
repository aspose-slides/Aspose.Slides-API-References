## DateTime::CompareTo(DateTime) const मेथड

वर्तमान ऑब्जेक्ट द्वारा दर्शाए गए दो तिथि और समय मानों की तुलना निर्दिष्ट [DateTime](../) क्लास के उदाहरण के साथ करता है और मान लौटाता है जो समय रेखा पर मानों की सापेक्ष स्थिति दर्शाता है।

```cpp
constexpr int System::DateTime::CompareTo(DateTime value) const
```

### आर्ग्युमेंट

| Parameter | Type | Description |
| --- | --- | --- |
| value | [DateTime](../) | वर्तमान ऑब्जेक्ट की तुलना करने के लिए [DateTime](../) क्लास का एक उदाहरण |

### रिटर्न मान

0 से कम का मान यदि वर्तमान ऑब्जेक्ट द्वारा दर्शाया गया मान उस मान से पहले है जो **value** द्वारा दर्शाया गया है; 0 यदि दोनों ऑब्जेक्ट द्वारा दर्शाए गए मान समान हैं; 0 से अधिक का मान यदि वर्तमान ऑब्जेक्ट द्वारा दर्शाया गया मान उस मान से बाद में है जो **value** द्वारा दर्शाया गया है।
