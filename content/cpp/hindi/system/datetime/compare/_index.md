## DateTime::Compare(DateTime, DateTime) मेथड

दो निर्दिष्ट [DateTime](../) क्लास के उदाहरणों द्वारा प्रतिनिधित्व किए गए दो मानों की तुलना करता है और समय रेखा पर मानों की सापेक्ष स्थिति दिखाने वाला मान लौटाता है।

```cpp
static constexpr int System::DateTime::Compare(DateTime t1, DateTime t2)
```

### आर्गुमेंट्स

| Parameter | Type | Description |
| --- | --- | --- |
| t1 | [DateTime](../) | पहला कंपैरैंड |
| t2 | [DateTime](../) | दूसरा कंपैरैंड |

### रिटर्न वैल्यू

एक मान जो 0 से कम है यदि **t1** **t2** से पहले है; 0 यदि **t1** **t2** के समान है; एक मान जो 0 से अधिक है यदि **t1** **t2** से बाद में है
