## DateTime::operator>(DateTime) const विधि

```cpp
constexpr bool System::DateTime::operator>(DateTime other) const
```

### आर्गुमेंट्स

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| other | [DateTime](../) | वर्तमान ऑब्जेक्ट की तुलना के लिए [DateTime](../) ऑब्जेक्ट |

### रिटर्न वैल्यू

True यदि वर्तमान ऑब्जेक्ट द्वारा दर्शाया गया तिथि और समय मान **other** द्वारा दर्शाए गए मान से बाद में है तो, अन्यथा - false
