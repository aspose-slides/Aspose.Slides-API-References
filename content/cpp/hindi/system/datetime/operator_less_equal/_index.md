```cpp
constexpr bool System::DateTime::operator<=(DateTime other) const
```

### तर्क

| Parameter | Type | Description |
| --- | --- | --- |
| other | [DateTime](../) | [DateTime](../) ऑब्जेक्ट जिसे वर्तमान ऑब्जेक्ट के साथ तुलना किया जाता है |

सही यदि वर्तमान ऑब्जेक्ट द्वारा दर्शाए गए तारीख और समय मान, **other** द्वारा दर्शाए गए मान से पहले या समान है, अन्यथा - गलत
