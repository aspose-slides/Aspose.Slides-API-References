## Object::Is(const TypeInfo\&) const मेथड

जाँचें कि क्या ऑब्जेक्ट targetType द्वारा वर्णित प्रकार का एक इंस्टैंस दर्शाता है। C# 'is' ऑपरेटर का समानांतर।

```cpp
virtual bool System::Object::Is(const TypeInfo &targetType) const
```

### आर्ग्युमेंट्स

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| targetType | const [TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) संरचना जो वर्तमान ऑब्जेक्ट को परीक्षण करने के लिए प्रकार को वर्णित करती है। |

### रिटर्न वैल्यू

यदि ऑब्जेक्ट को टैग किए गए प्रकार या उसकी उपवर्ग से है तो true, अन्यथा false।
