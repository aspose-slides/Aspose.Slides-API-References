```cpp
static float System::MathF::Round(float a)
```

| परिमाण | प्रकार | विवरण |

| a | **float** | राउंड करने के लिए मान |

### रिटर्न वैल्यू

## MathF::Round(float, int) विधि

निर्दिष्ट मान को निर्दिष्ट दशमिक अंकों की संख्या के साथ सबसे निकटतम मान में राउंड करता है।

```cpp
static float System::MathF::Round(float value, int digits)
```

### आर्ग्युमेंट्स

| परिमाण | प्रकार | विवरण |
| --- | --- | --- |
| value | **float** | राउंड करने के लिए मान |
| digits | int | राउंड किए गए मान में दशमिक अंकों की संख्या |

### रिटर्न वैल्यू

निर्दिष्ट अंकों की संख्या के साथ **value** के सबसे निकटतम संख्या

## MathF::Round(float, MidpointRounding) विधि

निर्दिष्ट मान को सबसे निकटतम पूर्णांक संख्या में राउंड करता है। एक पैरामीटर यह निर्दिष्ट करता है कि यदि निर्दिष्ट मान दो सबसे निकटतम संख्याओं के बराबर निकट हो तो फ़ंक्शन का व्यवहार क्या होगा।

```cpp
static float System::MathF::Round(float value, MidpointRounding mode)
```

### आर्ग्युमेंट्स

| परिमाण | प्रकार | विवरण |
| --- | --- | --- |
| value | **float** | राउंड करने के लिए मान |
| mode | [MidpointRounding](../../midpointrounding/) | यदि **value** दो सबसे निकटतम संख्याओं के बराबर निकट हो तो राउंडिंग कैसे करना है, यह निर्दिष्ट करता है। |

### रिटर्न वैल्यू

**value** को सबसे निकटतम पूर्णांक मान में राउंड किया गया
