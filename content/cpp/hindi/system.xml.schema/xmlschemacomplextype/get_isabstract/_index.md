## XmlSchemaComplexType::get_IsAbstract() विधि

यह जानकारी लौटाता है जो निर्धारित करती है कि **complexType** तत्व को इंस्टांस दस्तावेज़ में उपयोग किया जा सकता है या नहीं।

```cpp
bool System::Xml::Schema::XmlSchemaComplexType::get_IsAbstract()
```

### रिटर्न मान

यदि **true**, तो कोई तत्व इस **complexType** तत्व को सीधे उपयोग नहीं कर सकता और उसे इस **complexType** तत्व से व्युत्पन्न जटिल प्रकार का उपयोग करना होगा। डिफ़ॉल्ट **false** है। वैकल्पिक।
