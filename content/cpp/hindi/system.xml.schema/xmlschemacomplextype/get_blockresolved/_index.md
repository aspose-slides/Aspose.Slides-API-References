## XmlSchemaComplexType::get_BlockResolved() विधि

```cpp
XmlSchemaDerivationMethod System::Xml::Schema::XmlSchemaComplexType::get_BlockResolved()
```

### परिणाम मान

पोस्ट-स्कीमा-वैधता प्राप्त किए गए infoset का मान। डिफ़ॉल्ट **BlockDefault** मान **schema** तत्व पर है।
