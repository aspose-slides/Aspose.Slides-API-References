## XmlSchemaDerivationMethod enum

डेरिवेशन को रोकने के विभिन्न तरीकों को प्रदान करता है।

```cpp
enum class XmlSchemaDerivationMethod
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| Empty | 0 | डिफ़ॉल्ट डेरिवेशन विधि को ओवरराइड करके किसी भी डेरिवेशन की अनुमति देता है। |
| Substitution | 1 | डेरिवेशन को **Substitution** द्वारा संदर्भित करता है। |
| Extension | 2 | डेरिवेशन को **Extension** द्वारा संदर्भित करता है। |
| Restriction | 4 | डेरिवेशन को **Restriction** द्वारा संदर्भित करता है। |
| List | 8 | डेरिवेशन को **List** द्वारा संदर्भित करता है। |
| Union | 16 | डेरिवेशन को **Union** द्वारा संदर्भित करता है। |
| All | 255 | **#all**. सभी डेरिवेशन विधियों को संदर्भित करता है। |
| None | 256 | डिफ़ॉल्ट डेरिवेशन विधि को स्वीकार करता है। |
