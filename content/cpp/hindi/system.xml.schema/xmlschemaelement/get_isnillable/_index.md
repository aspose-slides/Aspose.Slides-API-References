## XmlSchemaElement::get_IsNillable() विधि


यह जानकारी लौटाता है जो दर्शाती है कि **xsi:nil** उदाहरण डेटा में हो सकता है। यह दर्शाता है कि क्या तत्व को स्पष्ट nil मान सौंपा जा सकता है।

```cpp
bool System::Xml::Schema::XmlSchemaElement::get_IsNillable()
```


### रिटर्न मान

यदि nillable **true** है, तो यह तत्व की एक उदाहरण को **nil** एट्रिब्यूट को **true** पर सेट करने की अनुमति देता है। **nil** एट्रिब्यूट XML [Schema](../../) नेमस्पेस का हिस्सा है और उदाहरणों के लिए परिभाषित किया गया है। डिफ़ॉल्ट **false** है। वैकल्पिक।
