```cpp
virtual bool System::Xml::Schema::IXmlSchemaInfo::get_IsDefault()=0
```

### रिटर्न मान

**true** यदि यह सत्यापित XML नोड स्कीमा सत्यापन के दौरान डिफ़ॉल्ट लागू होने के परिणामस्वरूप सेट किया गया था; अन्यथा, **false**।
