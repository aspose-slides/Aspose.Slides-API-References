## XmlAtomicValue::get_IsNode() मेथड

एक मान लौटाता है जो यह दर्शाता है कि सत्यापित XML तत्व या विशेषता एक [XPath](../../../system.xml.xpath/) नोड है या एक परम मान है।

```cpp
bool System::Xml::Schema::XmlAtomicValue::get_IsNode() override
```

### रिटर्न वैल्यू

**true** यदि सत्यापित XML तत्व या विशेषता एक [XPath](../../../system.xml.xpath/) नोड है; **false** यदि सत्यापित XML तत्व या विशेषता एक परम मान है।
