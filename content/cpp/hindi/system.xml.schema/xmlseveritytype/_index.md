## XmlSeverityType एनम


मान्यकरण घटना की गंभीरता को दर्शाता है।

```cpp
enum class XmlSeverityType
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| Error | 0 | यह दर्शाता है कि मान्यकरण दस्तावेज़ को मान्य करते समय एक मान्यकरण त्रुटि हुई। यह दस्तावेज़ प्रकार परिभाषाओं (DTDs) और XML [Schema](../) परिभाषा भाषा (XSD) स्कीमा पर लागू होता है। World Wide [Web](../../system.web/) Consortium (W3C) की वैधता प्रतिबंधों को त्रुटियां माना जाता है। यदि कोई मान्यकरण इवेंट हैंडलर नहीं बनाया गया है, तो त्रुटियां एक अपवाद फेंकती हैं। |
| Warning | 1 | यह दर्शाता है कि एक मान्यकरण इवेंट हुआ है जो त्रुटि नहीं है। एक चेतावनी सामान्यतः तब जारी की जाती है जब कोई DTD नहीं होता, या XML [Schema](../) किसी विशेष तत्व या गुण को मान्य करने के लिये नहीं होता। त्रुटियों के विपरीत, चेतावनियों से कोई अपवाद नहीं फेंका जाता यदि कोई मान्यकरण इवेंट हैंडलर नहीं है। |
