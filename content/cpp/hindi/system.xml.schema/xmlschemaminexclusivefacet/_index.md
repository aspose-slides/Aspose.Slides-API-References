## XmlSchemaMinExclusiveFacet क्लास


Represents the **minExclusive** element from XML [Schema](../) as specified by the World Wide [Web](../../system.web/) Consortium (W3C). This क्लास can be used to specify a restriction on the minimum value of a **simpleType** element. The element value must be greater than the value of the **minExclusive** element.

```cpp
class XmlSchemaMinExclusiveFacet : public System::Xml::Schema::XmlSchemaFacet
```
