## XmlSchemaFractionDigitsFacet क्लास

एक साधारण प्रकार (simpleType) तत्व के fraction value के लिए दर्ज किए जा सकने वाले अंकों की संख्या पर प्रतिबंध निर्दिष्ट करता है। fractionDigits का मान एक धनात्मक पूर्णांक होना चाहिए। विश्वव्यापी [Web](../../system.web/) कंसोर्टियम (W3C) **fractionDigits** फेसट को दर्शाता है।

```cpp
class XmlSchemaFractionDigitsFacet : public System::Xml::Schema::XmlSchemaNumericFacet
```

## टिप्पणियाँ
