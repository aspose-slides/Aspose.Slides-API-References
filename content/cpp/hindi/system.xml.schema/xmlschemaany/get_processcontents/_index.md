## XmlSchemaAny::get_ProcessContents() विधि

एक अनुप्रयोग या XML प्रोसेसर को यह बताने के लिए जानकारी लौटाता है कि वह **any** तत्व द्वारा निर्दिष्ट तत्वों के लिए XML दस्तावेज़ों के मान्यकरण को कैसे संभाले।

```cpp
XmlSchemaContentProcessing System::Xml::Schema::XmlSchemaAny::get_ProcessContents()
```

### रिटर्न वैल्यू

XmlSchemaContentProcessing मानों में से एक। अगर कोई **processContents** गुण निर्दिष्ट नहीं किया गया है, तो डिफ़ॉल्ट **Strict** होता है।
