## CookieVariant enum

Enumereert de cookie-specificaties.

```cpp
enum class CookieVariant
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Unknown | 0 | De onbekende cookie-specificatie. |
| Plain | 1 | De eenvoudige cookie-specificatie. |
| Rfc2109 | 2 | De 'RFC 2109' cookie-specificatie. |
| Rfc2965 | 3 | De 'RFC 2965' cookie-specificatie. |
| Default | 2 | De standaardwaarde gelijk aan 'Rfc2109'. |
