## IWebRequestCreate class

Biedt de methoden voor het aanmaken van instanties van de [WebRequest](../webrequest/)-klasse. Objecten van deze klasse mogen alleen worden gealloceerd met de functie [System::MakeObject()](../../system/makeobject/). Maak nooit een instantie van dit type op de stack of met de operator new, omdat dit runtime-fouten en/of assertiefouten oplevert. Wrap deze klasse altijd in een [System::SmartPtr](../../system/smartptr/)-pointer en gebruik deze pointer om het als argument aan functies door te geven.

```cpp
class IWebRequestCreate : public System::Object
```
