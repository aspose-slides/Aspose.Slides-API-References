## XPathNavigator::CreateAttribute(String, String, String, String) methode

Maakt een attribuutknooppunt op het huidige elementknooppunt aan met de opgegeven namespaceprefix, lokale naam en namespace-URI, gespecificeerd met de opgegeven waarde.

```cpp
virtual void System::Xml::XPath::XPathNavigator::CreateAttribute(String prefix, String localName, String namespaceURI, String value)
```


### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| prefix | [String](../../../system/string/) | De namespaceprefix van het nieuwe attribuutknooppunt (indien aanwezig). |
| localName | [String](../../../system/string/) | De lokale naam van het nieuwe attribuutknooppunt die niet [String::Empty](../../../system/string/empty/) of **nullptr** kan zijn. |
| namespaceURI | [String](../../../system/string/) | De namespace-URI voor het nieuwe attribuutknooppunt (indien aanwezig). |
| value | [String](../../../system/string/) | De waarde van het nieuwe attribuutknooppunt. Als [String::Empty](../../../system/string/empty/) of **nullptr** worden doorgegeven, wordt een leeg attribuutknooppunt aangemaakt. |
