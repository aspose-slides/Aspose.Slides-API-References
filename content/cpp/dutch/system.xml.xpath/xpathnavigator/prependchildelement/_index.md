## XPathNavigator::PrependChildElement(String, String, String, String) methode

Maakt een nieuw kindelement aan het begin van de lijst met kindknopen van het huidige knooppunt met het opgegeven naamruimteprefex, de lokale naam en de naamruimte-URI, en de opgegeven waarde.

```cpp
virtual void System::Xml::XPath::XPathNavigator::PrependChildElement(String prefix, String localName, String namespaceURI, String value)
```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| prefix | [String](../../../system/string/) | De naamruimte-prefix van het nieuwe kindelement (indien aanwezig). |
| localName | [String](../../../system/string/) | De lokale naam van het nieuwe kindelement (indien aanwezig). |
| namespaceURI | [String](../../../system/string/) | De naamruimte-URI van het nieuwe kindelement (indien aanwezig). [String::Empty](../../../system/string/empty/) en **nullptr** zijn gelijkwaardig. |
| value | [String](../../../system/string/) | De waarde van het nieuwe kindelement. Als [String::Empty](../../../system/string/empty/) of **nullptr** worden doorgegeven, wordt een leeg element gemaakt. |
