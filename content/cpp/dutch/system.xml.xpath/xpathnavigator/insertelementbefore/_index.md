## XPathNavigator::InsertElementBefore(String, String, String, String) methode

Maakt een nieuw broertje-/zusters element vóór de huidige knoop met behulp van het opgegeven namespace-voorvoegsel, de lokale naam en de opgegeven namespace-URI, met de opgegeven waarde.

```cpp
virtual void System::Xml::XPath::XPathNavigator::InsertElementBefore(String prefix, String localName, String namespaceURI, String value)
```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| prefix | [String](../../../system/string/) | Het namespace-voorvoegsel van het nieuwe kindelement (indien aanwezig). |
| localName | [String](../../../system/string/) | De lokale naam van het nieuwe kindelement (indien aanwezig). |
| namespaceURI | [String](../../../system/string/) | De namespace-URI van het nieuwe kindelement (indien aanwezig). [String::Empty](../../../system/string/empty/) en **nullptr** zijn equivalent. |
| value | [String](../../../system/string/) | De waarde van het nieuwe kindelement. Als [String::Empty](../../../system/string/empty/) of **nullptr** worden doorgegeven, wordt een leeg element aangemaakt. |
