## XPathNavigator::AppendChildElement(String, String, String, String) methode

Maakt een nieuw kind-elementknooppunt aan het einde van de lijst met kindknooppunten van het huidige knooppunt, met behulp van de opgegeven namespace-prefix, lokale naam en namespace-URI, samen met de gespecificeerde waarde.

```cpp
virtual void System::Xml::XPath::XPathNavigator::AppendChildElement(String prefix, String localName, String namespaceURI, String value)
```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| prefix | [String](../../../system/string/) | De namespace-prefix van het nieuwe kind-elementknooppunt (indien aanwezig). |
| localName | [String](../../../system/string/) | De lokale naam van het nieuwe kind-elementknooppunt (indien aanwezig). |
| namespaceURI | [String](../../../system/string/) | De namespace-URI van het nieuwe kind-elementknooppunt (indien aanwezig). [String::Empty](../../../system/string/empty/) en **nullptr** zijn equivalent. |
| value | [String](../../../system/string/) | De waarde van het nieuwe kind-elementknooppunt. Als [String::Empty](../../../system/string/empty/) of **nullptr** worden doorgegeven, wordt een leeg element aangemaakt. |
