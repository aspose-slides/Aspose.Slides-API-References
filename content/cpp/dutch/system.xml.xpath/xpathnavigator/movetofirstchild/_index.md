## XPathNavigator::MoveToFirstChild() methode


When overridden in a derived class, moves the [XPathNavigator](../) to the first child node of the current node.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToFirstChild()=0
```


### Retourwaarde

**true** als de [XPathNavigator](../) succesvol verplaatst naar het eerste kindknooppunt van het huidige knooppunt; anders **false**. Als **false**, is de positie van de [XPathNavigator](../) ongewijzigd.
