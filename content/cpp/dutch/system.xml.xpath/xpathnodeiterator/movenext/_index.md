## XPathNodeIterator::MoveNext() methode


Wanneer overschreven in een afgeleide klasse, verplaatst het [XPathNavigator](../../xpathnavigator/) object dat wordt geretourneerd door de [XPathNodeIterator::get_Current](../get_current/) methode naar de volgende node in de geselecteerde nodeverzameling.

```cpp
virtual bool System::Xml::XPath::XPathNodeIterator::MoveNext()=0
```


### Retourwaarde

**true** als het [XPathNavigator](../../xpathnavigator/) object naar de volgende node is verplaatst; **false** als er geen geselecteerde nodes meer zijn.
