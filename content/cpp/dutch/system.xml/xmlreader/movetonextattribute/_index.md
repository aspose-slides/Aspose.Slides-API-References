## XmlReader::MoveToNextAttribute() methode


When overridden in a derived class, moves to the next attribute.

```cpp
virtual bool System::Xml::XmlReader::MoveToNextAttribute()=0
```


### Retourwaarde

**true** als er een volgend attribuut is; **false** als er geen verdere attributen meer zijn.
