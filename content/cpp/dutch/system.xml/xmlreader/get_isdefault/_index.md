## XmlReader::get_IsDefault() methode

When overridden in a derived class, gets a value indicating whether the current node is an attribute that was generated from the default value defined in the DTD or schema.

```cpp
virtual bool System::Xml::XmlReader::get_IsDefault()
```

### Retourwaarde

**true** als het huidige knooppunt een attribuut is waarvan de waarde is gegenereerd uit de standaardwaarde die is gedefinieerd in de DTD of schema; **false** als de attribuutwaarde expliciet is ingesteld.
