## XmlReader::get_NamespaceURI() methode

Wanneer overschreven in een afgeleide klasse, haalt het de namespace-URI (zoals gedefinieerd in de W3C Namespace-specificatie) van het knooppunt waarop de lezer is gepositioneerd.

```cpp
virtual String System::Xml::XmlReader::get_NamespaceURI()=0
```

### Retourwaarde

De namespace-URI van het huidige knooppunt; anders een lege tekenreeks.
