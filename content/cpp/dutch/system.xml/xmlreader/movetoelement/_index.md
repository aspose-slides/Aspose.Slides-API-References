## XmlReader::MoveToElement() methode


Wanneer overschreven in een afgeleide klasse, verplaatst het zich naar het element dat de huidige attribuutknoop bevat.

```cpp
virtual bool System::Xml::XmlReader::MoveToElement()=0
```


### Retourwaarde

**true** als de lezer is gepositioneerd op een attribuut (de lezer verplaatst zich naar het element dat het attribuut bezit); **false** als de lezer niet is gepositioneerd op een attribuut (de positie van de lezer verandert niet).
