## XmlReader::ReadString() methode

Wanneer het wordt overschreven in een afgeleide klasse, leest het de inhoud van een element of tekstknooppunt als een string. Het wordt echter aanbevolen om de [XmlReader::ReadElementContentAsString](../readelementcontentasstring/) methode te gebruiken, omdat deze een meer directe manier biedt om deze bewerking af te handelen.

```cpp
virtual String System::Xml::XmlReader::ReadString()
```

### Retourwaarde

De inhoud van het element of een lege string.
