## XmlReader::get_HasValue() methode


Wanneer overschreven in een afgeleide klasse, verkrijgt een waarde die aangeeft of het huidige knooppunt een [XmlReader::get_Value](../get_value/) waarde kan hebben.

```cpp
virtual bool System::Xml::XmlReader::get_HasValue()
```


### Retourwaarde

**true** als het knooppunt waarop de lezer zich momenteel bevindt een **Value** kan hebben; anders **false**. Als **false**, heeft het knooppunt een waarde van [String::Empty](../../../system/string/empty/).
