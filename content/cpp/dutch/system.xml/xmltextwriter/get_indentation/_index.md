## XmlTextWriter::get_Indentation() methode


Geeft terug hoeveel IndentChars er moeten worden geschreven voor elk niveau in de hiërarchie wanneer [XmlTextWriter::set_Formatting](../set_formatting/) is ingesteld op [Formatting::Indented](../../formatting/).

```cpp
int32_t System::Xml::XmlTextWriter::get_Indentation()
```


### Retourwaarde

Aantal **IndentChars** per niveau. De standaardwaarde is 2.
