## XmlNodeOrder enum

Beschrijft de documentvolgorde van een knooppunt ten opzichte van een tweede knooppunt.

```cpp
enum class XmlNodeOrder
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Before | 0 | Het huidige knooppunt van deze navigator is vóór het huidige knooppunt van de opgegeven navigator. |
| After | 1 | Het huidige knooppunt van deze navigator is na het huidige knooppunt van de opgegeven navigator. |
| Same | 2 | De twee navigatoren bevinden zich op hetzelfde knooppunt. |
| Unknown | 3 | De knooppositie kan niet worden bepaald in documentvolgorde ten opzichte van elkaar. Dit kan optreden als de twee knooppunten zich in verschillende bomen bevinden. |
