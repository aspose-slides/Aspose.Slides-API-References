## XmlNodeReader::ReadString() methode

Leest de inhoud van een element of tekstknooppunt als een string.

```cpp
String System::Xml::XmlNodeReader::ReadString() override
```

### Retourwaarde

De inhoud van het element of tekstachtige knooppunt (Dit kan CDATA, [Text](../../../system.text/) knooppunten, en zo verder omvatten). Dit kan een lege string zijn als de lezer is gepositioneerd op iets anders dan een element of tekstknooppunt, of als er geen verdere tekstinhoud meer te retourneren is in de huidige context. Opmerking: Het tekstknooppunt kan zowel een element- als een attribuutttekstknooppunt zijn.
