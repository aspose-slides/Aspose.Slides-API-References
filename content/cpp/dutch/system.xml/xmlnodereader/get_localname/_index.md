## XmlNodeReader::get_LocalName() methode

Retourneert de lokale naam van het huidige knooppunt.

```cpp
String System::Xml::XmlNodeReader::get_LocalName() override
```

### Retourwaarde

De naam van het huidige knooppunt zonder het voorvoegsel. Bijvoorbeeld, **LocalName** is **book** voor het element **<bk:book>**. Voor knooptypes die geen naam hebben (zoals **[Text](../../../system.text/)**, **Comment**, enzovoort), retourneert deze methode [String::Empty](../../../system/string/empty/).
