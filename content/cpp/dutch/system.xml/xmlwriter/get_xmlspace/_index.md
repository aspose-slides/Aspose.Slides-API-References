## XmlWriter::get_XmlSpace() methode


Wanneer overschreven in een afgeleide klasse, krijgt een XmlSpace die de huidige **xml:space** scope weergeeft.

```cpp
virtual System::Xml::XmlSpace System::Xml::XmlWriter::get_XmlSpace()
```


### Retourwaarde

Een XmlSpace die de huidige **xml:space** scope weergeeft.



| Waarde | Betekenis |
| --- | --- |
| `None`| Dit is de standaard als er geen `xml:space` scope bestaat. |
| `Default`| De huidige scope is `xml:space="default"`. |
| `Preserve`| De huidige scope is `xml:space="preserve"`. |
