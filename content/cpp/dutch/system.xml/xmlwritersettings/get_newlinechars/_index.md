## XmlWriterSettings::get_NewLineChars() methode

Retourneert de tekenreeks die moet worden gebruikt voor regeleinden.

```cpp
String System::Xml::XmlWriterSettings::get_NewLineChars()
```

### Retourwaarde

De tekenreeks die moet worden gebruikt voor regeleinden. Deze kan worden ingesteld op elke tekenreekswaarde. Om echter geldige XML te garanderen, moet u alleen geldige witruimtetekens opgeven, zoals spaties, tabs, carriage returns of line feeds. De standaard is **\r\n** (carriage return, nieuwe regel).
