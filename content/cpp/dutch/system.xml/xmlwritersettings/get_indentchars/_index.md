## XmlWriterSettings::get_IndentChars() methode

Geeft de tekenreeks terug die gebruikt wordt bij het inspringen. Deze instelling wordt gebruikt wanneer de [XmlWriterSettings::set_Indent](../set_indent/) waarde is ingesteld op **true**.

```cpp
String System::Xml::XmlWriterSettings::get_IndentChars()
```

### Retourwaarde

De tekenreeks die gebruikt wordt bij het inspringen. Deze kan op elke tekenreekswaarde worden ingesteld. Om echter geldige XML te waarborgen, moet u alleen geldige witruimtetekens opgeven, zoals spaties, tabbladen, carriage returns of line feeds. Standaard zijn twee spaties.
