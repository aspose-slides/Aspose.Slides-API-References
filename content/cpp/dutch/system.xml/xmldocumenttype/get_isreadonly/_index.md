## XmlDocumentType::get_IsReadOnly() methode

Retourneert een waarde die aangeeft of de node alleen-lezen is.

```cpp
bool System::Xml::XmlDocumentType::get_IsReadOnly() override
```

### Retourwaarde

**true** als de node alleen-lezen is; anders **false**. Omdat DocumentType-knooppunten alleen-lezen zijn, retourneert deze methode altijd **true**.
