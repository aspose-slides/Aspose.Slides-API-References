## XmlTextReader::get_LocalName() methode


Retourneert de lokale naam van het huidige knooppunt.

```cpp
String System::Xml::XmlTextReader::get_LocalName() override
```


### Retourwaarde

De naam van het huidige knooppunt zonder het voorvoegsel. Bijvoorbeeld, **LocalName** is **book** voor het element **<bk:book>**. Voor knooppunttypen die geen naam hebben (zoals **[Text](../../../system.text/)**, **Comment**, enzovoort), geeft deze methode [String::Empty](../../../system/string/empty/) terug.
