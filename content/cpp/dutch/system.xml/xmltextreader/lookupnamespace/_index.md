## XmlTextReader::LookupNamespace(const String\&) methode

Lost een namespace-prefix op in de scope van het huidige element.

```cpp
String System::Xml::XmlTextReader::LookupNamespace(const String &prefix) override
```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| prefix | const [String](../../../system/string/)\& | De prefix waarvan u de namespace-URI wilt oplossen. Om de standaardnamespace te matchen, geeft u een lege string door. Deze string hoeft niet geatomiseerd te worden. |

### Retourwaarde

De namespace-URI waaraan de prefix verwijst, of **nullptr** als er geen overeenkomende prefix wordt gevonden.
