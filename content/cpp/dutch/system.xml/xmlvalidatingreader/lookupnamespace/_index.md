

### Argumenten

| Parameter | Type | Description |
| --- | --- | --- |
| prefix | const [String](../../../system/string/)\& | Het voorvoegsel waarvan u de Uniform Resource Identifier (URI) van de naamruimte wilt oplossen. Om overeen te komen met de standaardnaamruimte, geeft u een lege tekenreeks door. |

### Retourwaarde

De naamruimte-URI waarnaar het voorvoegsel verwijst of **nullptr** als er geen overeenkomend voorvoegsel wordt gevonden.
