## XmlValidatingReader::get_LocalName() methode

Retourneert de lokale naam van de huidige node.

```cpp
String System::Xml::XmlValidatingReader::get_LocalName() override
```

### Retourwaarde

De naam van de huidige node met het voorvoegsel verwijderd. Bijvoorbeeld, **LocalName** is **book** voor het element **<bk:book>**. Voor knooptypen die geen naam hebben (zoals **[Text](../../../system.text/)**, **Comment**, en zo voort), retourneert deze methode [String::Empty](../../../system/string/empty/).
