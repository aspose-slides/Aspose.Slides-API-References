## XmlValidatingReader::get_SchemaType() methode

Retourneert een schema type object.

```cpp
SharedPtr<Object> System::Xml::XmlValidatingReader::get_SchemaType()
```

### Retourwaarde

XmlSchemaDatatype, XmlSchemaSimpleType, of XmlSchemaComplexType, afhankelijk of de knoopwaarde een ingebouwd XML [Schema](../../../system.xml.schema/) definitieschrijftaal (XSD) type is of een door de gebruiker gedefinieerd simpleType of complexType; **nullptr** als de huidige knoop geen schema type heeft.
