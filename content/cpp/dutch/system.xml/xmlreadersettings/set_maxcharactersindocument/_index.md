## XmlReaderSettings::set_MaxCharactersInDocument(int64_t) methode

Stelt een waarde in die het maximum aantal toegestane tekens in een XML-document aangeeft. Een nul (0) waarde betekent geen limiet op de grootte van het XML-document. Een niet-nul waarde geeft de maximale grootte in tekens aan.

```cpp
void System::Xml::XmlReaderSettings::set_MaxCharactersInDocument(int64_t value)
```
