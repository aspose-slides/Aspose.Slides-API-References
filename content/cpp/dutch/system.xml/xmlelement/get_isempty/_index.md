## XmlElement::get_IsEmpty() methode


Retourneert het tagformaat van het element.

```cpp
bool System::Xml::XmlElement::get_IsEmpty()
```


### Retourwaarde

**true** als het element moet worden geserialiseerd in het korte tagformaat \"<tt><item/></tt>\"; **false** voor het lange formaat \"<tt><item></item></tt>\".
