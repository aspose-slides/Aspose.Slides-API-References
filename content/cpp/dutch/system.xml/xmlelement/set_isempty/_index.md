## XmlElement::set_IsEmpty(bool) methode

Stelt het tagformaat van het element in.

```cpp
void System::Xml::XmlElement::set_IsEmpty(bool value)
```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| value | **bool** | De waarde die moet worden ingesteld. Bij het instellen van deze waarde, wordt, indien ingesteld op **true**, de subelementen van het element verwijderd en wordt het element geserialiseerd in het korte tagformaat. Indien ingesteld op **false**, wordt de waarde gewijzigd (ongeacht of het element inhoud heeft of niet); als het element leeg is, wordt het geserialiseerd in het lange formaat. |
