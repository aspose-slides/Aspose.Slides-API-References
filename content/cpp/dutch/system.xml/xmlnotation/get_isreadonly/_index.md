bool System::Xml::XmlNotation::get_IsReadOnly() override

### Retourwaarde

**true** als het knooppunt alleen-lezen is; anders **false**. Omdat [XmlNotation](../) knooppunten alleen-lezen zijn, retourneert deze methode altijd **true**.
