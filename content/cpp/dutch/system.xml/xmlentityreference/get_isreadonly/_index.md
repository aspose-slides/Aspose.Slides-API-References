```cpp
bool System::Xml::XmlEntityReference::get_IsReadOnly() override
```

### Retourwaarde

**true** als het knooppunt alleen-lezen is; anders **false**. Omdat [XmlEntityReference](../) knooppunten alleen-lezen zijn, retourneert deze methode altijd **true**.
