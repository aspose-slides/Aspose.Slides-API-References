## XmlAttributeCollection::RemoveAt(int32_t) methode

Verwijdert het attribuut dat overeenkomt met de opgegeven index uit de collectie.

```cpp
SharedPtr<XmlAttribute> System::Xml::XmlAttributeCollection::RemoveAt(int32_t i)
```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| i | **int32_t** | De index van het knooppunt dat verwijderd moet worden. Het eerste knooppunt heeft index 0. |

### Returnwaarde

Retourneert **nullptr** als er geen attribuut is op de opgegeven index.
