## HttpContext klasse

Dummy-klasse die het mogelijk maakt vertaalde code te koppelen aan [HttpContext](./)-referenties, maar deze niet uit te voeren. Bevat geen correct geïmplementeerde leden. Objecten van deze klasse mogen alleen worden gealloceerd met de [System::MakeObject()](../../system/makeobject/)-functie. Maak nooit een exemplaar van dit type op de stack of met operator new, omdat dit runtime-fouten en/of assertiefouten oplevert. Verpak altijd deze klasse in een [System::SmartPtr](../../system/smartptr/)-pointer en gebruik deze pointer om deze als argument aan functies door te geven.

```cpp
class HttpContext : public System::Object
```
