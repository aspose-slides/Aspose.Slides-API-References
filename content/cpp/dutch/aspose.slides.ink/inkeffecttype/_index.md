## InkEffectType enum

Specifies a set of predefined visual effects for ink rendering. Each effect corresponds to a texture or image that simulates a stylized ink appearance. These values can be used to customize the visual style of digital ink strokes during rendering.

```cpp
enum class InkEffectType
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| NotDefined | -1 | Het effect is niet gedefinieerd of onbekend. Deze waarde kan worden gebruikt als standaard of fallback. |
| Bronze | 0 | Een warme, bruinachtige metalen textuur die lijkt op bronzen inkt. |
| Galaxy | 1 | Een kleurrijke, glinsterende textuur die lijkt op een galaxie, met kosmische tinten. |
| Gold | 2 | Een heldere, metalen gouden textuur die inktstrepen een luxueus uiterlijk geeft. |
| Lava | 3 | Een vurige textuur die lijkt op gesmolten lava, met rode en oranje tinten. |
| Ocean | 4 | Een diepblauwe, vloeistofachtige textuur die oceaangolven of watergebaseerde inkt nabootst. |
| RainbowGlitter | 5 | Een kleurrijk, sprankelend regenboogglittereffect dat wordt gebruikt voor feestelijke of levendige inktstrepen. |
| RoseGold | 6 | Een zachte roze-gouden mix, vergelijkbaar met rozen goud, voor elegante inktstrepen. |
| Silver | 7 | Een koele, metalen zilveren textuur die klassieke zilveren inkt simuleert. |
