## Thread::get_ManagedThreadId() const methode


Haalt de identifier van de thread op. Kan worden verkregen van het besturingssysteem, maar als de thread-identifier van het besturingssysteem de int-limieten overschrijdt, kunnen thread-ID's elkaar overlappen.

```cpp
int System::Threading::Thread::get_ManagedThreadId() const
```
