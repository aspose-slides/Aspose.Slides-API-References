## CancellationToken::get_CanBeCanceled() const methode


Geeft aan of dit token zich in de geannuleerde toestand kan bevinden.

```cpp
bool System::Threading::CancellationToken::get_CanBeCanceled() const
```


### Retourwaarde

true als dit token in de geannuleerde toestand kan verkeren; anders false.
## Opmerkingen



Tokens die zijn gemaakt vanuit [CancellationTokenSource](../../cancellationtokensource/) geven true terug, terwijl het None token altijd false geeft.
