## CancellationTokenRegistration::Dispose() methode

Verwijdert de registratie en verwijdert de callback van de gekoppelde [CancellationTokenSource](../../cancellationtokensource/). Na het aanroepen van deze methode wordt de geregistreerde callback niet meer uitgevoerd wanneer de gekoppelde [CancellationTokenSource](../../cancellationtokensource/) wordt geannuleerd.

```cpp
void System::Threading::CancellationTokenRegistration::Dispose()
```

## Opmerkingen

Het is veilig om deze methode meerdere keren aan te roepen - latere aanroepen hebben geen effect.
