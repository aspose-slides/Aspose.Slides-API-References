## StringTrimming enum

Specificeert hoe tekens moeten worden bijgesneden van een tekenreeks die niet in de lay-outvorm past.

```cpp
enum class StringTrimming
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| None | 0 | Geen bijsnijden. |
| Character | 1 | Snij bij tot het dichtstbijzijnde teken. |
| Word | 2 | Snij bij tot het dichtstbijzijnde woord. |
| EllipsisCharacter | 3 | Snij bij tot het dichtstbijzijnde teken en voeg een ellipsis toe aan het einde van de tekenreeks. |
| EllipsisWord | 4 | Snij bij tot het dichtstbijzijnde woord en voeg een ellipsis toe aan het einde van de tekenreeks. |
| EllipsisPath | 5 | Het midden wordt verwijderd uit de bijgesneden regels en vervangen door een ellipsis. Houd zoveel mogelijk van het laatste door schuine strepen gescheiden segment van de regel. |
