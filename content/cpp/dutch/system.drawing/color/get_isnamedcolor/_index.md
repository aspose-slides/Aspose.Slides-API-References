## Color::get_IsNamedColor() const methode


Returns a value that determines whether the [Color](../) structure represents a named color or a member of the KnownColor enumeration.

```cpp
bool System::Drawing::Color::get_IsNamedColor() const
```


### Retourwaarde

True if the [Color](../) was created using either the FromName(String) methode or the [FromKnownColor(KnownColor)](../fromknowncolor/) methode; otherwise, it returns false.
