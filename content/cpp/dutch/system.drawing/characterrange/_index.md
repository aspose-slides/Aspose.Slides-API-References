## CharacterRange klasse

Stelt een bereik van tekenposities in een string voor. Dit type moet op de stack worden toegewezen en doorgegeven aan functies per waarde of per referentie. Gebruik nooit de [System::SmartPtr](../../system/smartptr/) klasse om objecten van dit type te beheren.

```cpp
class CharacterRange
```
