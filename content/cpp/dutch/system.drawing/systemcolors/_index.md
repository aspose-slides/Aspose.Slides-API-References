## SystemColors klasse


Klasse die een reeks vooraf aangemaakte [Color](../color/) objecten biedt die de kleuren van [Windows](../../system.windows/) weergave-elementen vertegenwoordigen. Dit is een statisch type zonder instantie-services. Je mag nooit instanties ervan maken op welke manier dan ook.

```cpp
class SystemColors
```
