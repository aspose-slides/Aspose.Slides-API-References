## Rectangle::Intersect(const Rectangle\&) methode

Vervangt de rechthoek die wordt vertegenwoordigd door het huidige object door de rechthoek die het resultaat is van de intersectie ervan met de rechthoek die wordt vertegenwoordigd door het opgegeven object.

```cpp
void System::Drawing::Rectangle::Intersect(const Rectangle &rect)
```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| rect | const [Rectangle](../)\& | Het [Rectangle](../)-object dat de rechthoek vertegenwoordigt waarmee de rechthoek die door het huidige object wordt vertegenwoordigd, moet worden geïntersecteerd |

## Rectangle::Intersect(const Rectangle\&, const Rectangle\&) methode

Retourneert een rechthoek die het resultaat is van de intersectie van de opgegeven rechthoeken.

```cpp
static Rectangle System::Drawing::Rectangle::Intersect(const Rectangle &a, const Rectangle &b)
```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| a | const [Rectangle](../)\& | De eerste rechthoek om te intersecteren |
| b | const [Rectangle](../)\& | De tweede rechthoek om te intersecteren |

### Retourwaarde

Het resultaat van de intersectie van **a** met **b**
