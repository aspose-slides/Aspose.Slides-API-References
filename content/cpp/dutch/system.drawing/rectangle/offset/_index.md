## Rectangle::Offset(const Point\&) methode

Verschuift de positie van de rechthoek die wordt weergegeven door het huidige object met de opgegeven hoeveelheden.

```cpp
void System::Drawing::Rectangle::Offset(const Point &pos)
```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| pos | const [Point](../../point/)\& | Het [Point](../../point/) object dat de hoeveelheid specificeert waarmee de rechthoek wordt verschoven; de X-coördinaatwaarde van het punt geeft de hoeveelheid aan die moet worden toegevoegd aan de X-coördinaat van de linkerbovenhoek van de rechthoek en de Y-coördinaat van het punt geeft de hoeveelheid aan die moet worden toegevoegd aan de Y-coördinaat van de linkerbovenhoek van de rechthoek |

## Rectangle::Offset(int, int) methode

void System::Drawing::Rectangle::Offset(int x, int y)

| Parameter | Type | Beschrijving |
