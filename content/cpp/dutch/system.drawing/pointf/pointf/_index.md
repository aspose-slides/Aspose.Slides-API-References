Construeert een nieuw [PointF](../) object en initialiseert het met de opgegeven waarden.


| Parameter | Type | Beschrijving |

## PointF::PointF(const SizeF\&) constructor

Construeert een nieuw [PointF](../) object en initialiseert de X- en Y-coördinaatwaarden met de breedte- en hoogtewaarden van het gespecificeerde [SizeF](../../sizef/) object overeenkomstig.

```cpp

```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| size | const [SizeF](../../sizef/)\& | Een [SizeF](../../sizef/) object waarvan de breedte- en hoogtewaarden worden gebruikt om de X- en Y-coördinaatwaarden van het [PointF](../) object dat wordt aangemaakt te initialiseren |
