## PointF::Add(const PointF\&, const SizeF\&) method

Voegt de breedte- en hoogtewaarden van het opgegeven [SizeF](../../sizef/) object toe aan de X- en Y-coördinaatwaarden van het opgegeven [PointF](../) object.

```cpp
static PointF System::Drawing::PointF::Add(const PointF &point, const SizeF &size)
```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| point | const [PointF](../)\& | Het punt om te vertalen |
| size | const [SizeF](../../sizef/)\& | Het [SizeF](../../sizef/) object dat de waarden specificeert die moeten worden toegevoegd aan de coördinaatwaarden van **point** |

### Retourwaarde

Een nieuw [PointF](../) object waarvan de X-coördinaatwaarde gelijk is aan de som van de X-coördinaatwaarde van **point** en de breedtewaarde van **size**, en de Y-coördinaatwaarde gelijk is aan de som van de Y-coördinaatwaarde van **point** en de hoogtewaarde van **size**.
