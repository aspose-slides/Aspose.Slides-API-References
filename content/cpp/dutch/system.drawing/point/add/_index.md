## Point::Add(const Point\&, const Size\&) methode


Voegt de breedte- en hoogtewaarden van het gespecificeerde [Size](../../size/) object toe aan de X- en Y-coördinaatwaarden van het gespecificeerde [Point](../) object overeenkomstig.

```cpp
static Point System::Drawing::Point::Add(const Point &point, const Size &size)
```


### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| point | const [Point](../)\& | Het punt om te vertalen |
| size | const [Size](../../size/)\& | Het [Size](../../size/) object dat de waarden specificeert die aan de coördinaatwaarden van het **point** moeten worden toegevoegd |

### Retourwaarde

Een nieuw [Point](../) object waarvan de X-coördinaatwaarde gelijk is aan de som van de X-coördinaatwaarde van **point** en de breedtewaarde van **size** en de Y-coördinaatwaarde gelijk is aan de som van de Y-coördinaatwaarde van **point** en de hoogtewaarde van **size**
