## Point::Offset(int, int) methode


Verschuift de X- en Y-coördinaatwaarde die door het huidige object wordt vertegenwoordigd met de opgegeven waarden.

```cpp
void System::Drawing::Point::Offset(int dx, int dy)
```


### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| dx | int | De waarde waarmee de X-coördinaatwaarde wordt verschoven |
| dy | int | De waarde waarmee de Y-coördinaatwaarde wordt verschoven |

## Point::Offset(Point) methode


Verschuift de X- en Y-coördinaten die door het huidige object worden vertegenwoordigd met de waarden van de X- en Y-coördinaten die door het opgegeven [Point](../)-object worden vertegenwoordigd.

```cpp
void System::Drawing::Point::Offset(Point point)
```


### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| point | [Point](../) | Het [Point](../)-object dat de waarden opgeeft waarmee de X- en Y-coördinaten worden verschoven |
