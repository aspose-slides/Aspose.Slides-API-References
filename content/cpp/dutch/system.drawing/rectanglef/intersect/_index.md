

### Argumenten

| Parameter | Type | Description |
| --- | --- | --- |

## RectangleF::Intersect(const RectangleF\&, const RectangleF\&) methode


Retourneert een rechthoek die het resultaat is van de intersectie van de opgegeven rechthoeken.

```cpp
static RectangleF System::Drawing::RectangleF::Intersect(const RectangleF &a, const RectangleF &b)
```


### Argumenten

| Parameter | Type | Description |
| --- | --- | --- |
| a | const [RectangleF](../)\& | De eerste rechthoek om te kruisen |
| b | const [RectangleF](../)\& | De tweede rechthoek om te kruisen |

### Retourwaarde

Het resultaat van de intersectie van **a** met **b**
