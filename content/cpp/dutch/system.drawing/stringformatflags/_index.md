## StringFormatFlags enum


Specificeert de weergave- en lay-outinformatie voor de tekenreeksen van tekst.

```cpp
enum class StringFormatFlags
```

### Waarden

| Name | Value | Description |
| --- | --- | --- |
| DirectionRightToLeft | 1 | Rechts-naar-links tekstrichting. |
| DirectionVertical | 2 | [Text](../../system.drawing.text/) is verticaal uitgelijnd. |
| FitBlackBox | 4 | Delen van karakters kunnen over de lay-outbox uitsteken. |
| DisplayFormatControl | 32 | Controletekens worden weergegeven. |
| NoFontFallback | 1024 | [Font](../font/) fallback is uitgeschakeld. |
| MeasureTrailingSpaces | 2048 | Voegt de spatie aan het einde van elke regel in. |
| NoWrap | 4096 | [Text](../../system.drawing.text/) wrapping is uitgeschakeld. |
| LineLimit | 8192 | Volledige regels worden in het formatteringsrechthoek opgesteld. |
| NoClip | 16384 | Uitrekkende delen van glyphs mogen worden weergegeven. |
