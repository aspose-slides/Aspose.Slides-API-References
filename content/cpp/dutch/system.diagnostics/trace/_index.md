## Trace-struct

Biedt een interface om de debuggertrace (indien aanwezig) te benaderen. Werkt alleen in [Debug](../debug/)-modus. Dit is een statisch type zonder instantiediensten. U mag nooit op enigerlei wijze instanties ervan maken.

```cpp
class Trace
```

| Method | Beschrijving |

| static void [WriteLine](./writeline/)(const [String](../../system/string/)\&) | Schrijft een regel naar de debuggertrace. |
