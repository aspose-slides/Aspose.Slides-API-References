## System::MemoryExtensions::IndexOfAny(const ReadOnlySpan\<T\>\&, const T\&, const T\&) functie


Zoekt de index van de eerste voorkoming van een van de twee gespecificeerde waarden in een ReadOnlySpan<T>

```cpp
template<typename T> int32_t System::MemoryExtensions::IndexOfAny(const ReadOnlySpan<T> &span, const T &value0, const T &value1)
```


### Sjabloonparameters

| Parameter | Beschrijving |
| --- | --- |
| T | Het type elementen in de span |

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| span | const [ReadOnlySpan](../../system/readonlyspan/)\<T\>\& | De span waarin gezocht wordt |
| value0 | const T\& | De eerste te zoeken waarde |
| value1 | const T\& | De tweede te zoeken waarde |

### Retourwaarde

De nulgebaseerde index van de eerste voorkoming, of -1 indien niet gevonden
