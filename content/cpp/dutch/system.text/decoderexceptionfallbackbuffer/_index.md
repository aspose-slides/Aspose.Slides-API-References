## DecoderExceptionFallbackBuffer klasse


[Buffer](../../system/buffer/) voor een uitzonderings-werpend decodering fallbackstrategie. Slaat eigenlijk niets op, maar gooit in plaats daarvan een uitzondering. Objecten van deze klasse mogen alleen worden gealloceerd met behulp van de [System::MakeObject()](../../system/makeobject/) functie. Maak nooit een instantie van dit type aan op de stack of met operator new, omdat dit runtime-fouten en/of assertiefouten kan veroorzaken. Plaats altijd deze klasse in een [System::SmartPtr](../../system/smartptr/) pointer en gebruik die pointer om deze door te geven aan functies als argument.

```cpp
class DecoderExceptionFallbackBuffer : public System::Text::DecoderFallbackBuffer
```
