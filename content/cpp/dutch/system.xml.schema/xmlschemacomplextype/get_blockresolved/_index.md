## XmlSchemaComplexType::get_BlockResolved() methode


Retourneert de waarde nadat het type is gecompileerd naar de post-schema-validatie informatieset (infoset). Deze waarde geeft aan hoe het type wordt afgedwongen wanneer **xsi:type** wordt gebruikt in het instantie-document.

```cpp
XmlSchemaDerivationMethod System::Xml::Schema::XmlSchemaComplexType::get_BlockResolved()
```


### Retourwaarde

De post-schema-geverifieerde infoset-waarde. De standaard is de **BlockDefault**-waarde op het **schema**-element.
