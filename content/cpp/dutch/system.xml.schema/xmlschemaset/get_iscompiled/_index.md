## XmlSchemaSet::get_IsCompiled() methode


Retourneert een waarde die aangeeft of de XML [Schema](../../) definitietaal (XSD) schemas in de [XmlSchemaSet](../) zijn gecompileerd.

```cpp
bool System::Xml::Schema::XmlSchemaSet::get_IsCompiled()
```


### Retourwaarde

**true** als de schemas in de [XmlSchemaSet](../) zijn gecompileerd sinds de laatste keer dat een schema werd toegevoegd of verwijderd uit de [XmlSchemaSet](../); anders, **false**.
