## XmlSchemaSimpleTypeUnion::get_MemberTypes() methode


Retourneert de array van gekwalificeerde membernamen van ingebouwde gegevenstypen of **simpleType** elementen die zijn gedefinieerd in dit schema (of een ander schema dat wordt aangeduid door de opgegeven naamruimte).

```cpp
ArrayPtr<SharedPtr<XmlQualifiedName>> System::Xml::Schema::XmlSchemaSimpleTypeUnion::get_MemberTypes()
```


### Retourwaarde

Een array die bestaat uit een lijst van leden van ingebouwde gegevenstypen of eenvoudige typen.
