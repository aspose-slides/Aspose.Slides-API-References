## XmlSchemaSimpleTypeUnion klasse

Geeft het **union**-element voor eenvoudige types uit XML [Schema](../) weer, zoals gespecificeerd door het World Wide [Web](../../system.web/) Consortium (W3C). Een **union**-datatype kan worden gebruikt om de inhoud van een **simpleType** te specificeren. De waarde van het **simpleType**-element moet één van een set alternatieve datatypes zijn die in de union zijn gespecificeerd. Union-types zijn altijd afgeleide types en moeten uit ten minste twee alternatieve datatypes bestaan.

```cpp
class XmlSchemaSimpleTypeUnion : public System::Xml::Schema::XmlSchemaSimpleTypeContent
```

## Opmerkingen

Objecten van deze klasse mogen alleen worden gealloceerd met de [System::MakeObject()](../../system/makeobject/)-functie. Maak nooit instanties van dit type op de stapel of met operator new, omdat dit zal leiden tot runtime-fouten en/of assertiefouten. Wikkel deze klasse altijd in een [System::SmartPtr](../../system/smartptr/)-pointer en gebruik deze pointer om deze door te geven aan functies als argument.
