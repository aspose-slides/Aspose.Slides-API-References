## XmlSchemaComplexContent::get_IsMixed() methode


Retourneert informatie die bepaalt of het type een gemengd contentmodel heeft.

```cpp
bool System::Xml::Schema::XmlSchemaComplexContent::get_IsMixed()
```


### Retourwaarde

Als deze waarde **true** is, is het toegestaan dat tekengegevens verschijnen tussen de onderliggende elementen van het complexe type (gemengd contentmodel). Standaard is **false**. Optioneel.
