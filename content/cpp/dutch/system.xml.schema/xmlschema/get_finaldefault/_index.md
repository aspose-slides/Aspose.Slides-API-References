## XmlSchema::get_FinalDefault() methode

Retourneert het **finalDefault**-attribuut dat de standaardwaarde van het **final**-attribuut voor elementen en complexe types in de doel-namespace van het schema instelt.

```cpp
XmlSchemaDerivationMethod System::Xml::Schema::XmlSchema::get_FinalDefault()
```

### Retourwaarde

Een XmlSchemaDerivationMethod-waarde die de verschillende methoden voor het voorkomen van afleiding weergeeft. De standaardwaarde is [XmlSchemaDerivationMethod::None](../../xmlschemaderivationmethod/).
