## XmlSchemaContentProcessing enum

Biedt informatie over de validatiemodus van **any** en **anyAttribute** elementvervangingen.

```cpp
enum class XmlSchemaContentProcessing
```

### Values

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| None | 0 | Documentitems worden niet gevalideerd. |
| Skip | 1 | Documentitems moeten uit goed gevormde XML bestaan en worden niet gevalideerd door het schema. |
| Lax | 2 | Als het bijbehorende schema wordt gevonden, worden de documentitems gevalideerd. Anders worden er geen fouten gegenereerd. |
| Strict | 3 | De schemaprocessor moet een schema vinden dat is gekoppeld aan de aangegeven namespace om de documentitems te valideren. |
