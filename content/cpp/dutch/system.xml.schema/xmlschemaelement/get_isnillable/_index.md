## XmlSchemaElement::get_IsNillable() methode


Retourneert informatie die aangeeft of **xsi:nil** kan voorkomen in de instantiedata. Geeft aan of een expliciete nil-waarde aan het element kan worden toegewezen.

```cpp
bool System::Xml::Schema::XmlSchemaElement::get_IsNillable()
```


### Retourwaarde

Als nillable **true** is, maakt dit het mogelijk dat een instantie van het element het **nil**-attribuut op **true** heeft staan. Het **nil**-attribuut is gedefinieerd als onderdeel van de XML [Schema](../../)-namespace voor instanties. De standaard is **false**. Optioneel.
