## XmlSchemaElement::get_IsAbstract() methode


Retourneert informatie die aangeeft of het element kan worden gebruikt in een instantie-document.

```cpp
bool System::Xml::Schema::XmlSchemaElement::get_IsAbstract()
```


### Retourwaarde

Als **true**, mag het element niet verschijnen in het instantie-document. De standaard is **false**. Optioneel.
