## DataLabelCollection::get_IsVisible() methode

False betekent dat het gegevenslabel standaard niet zichtbaar is (en dus zijn alle Show*-flags (ShowValue, ...) van de eigenschap DefaultDataLabelFormat onwaar). Alleen-lezen **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelCollection::get_IsVisible() override
```

## Opmerkingen

Als het gegevenslabel standaard zichtbaar is, kun je het standaard verborgen maken met methode [Hide()](../hide/). Maar als het gegevenslabel standaard niet zichtbaar is (IsVisible is false) kun je het gegevenslabel "visible 
by default" maken door de Show*-flags (ShowValue, ...) van de eigenschap DefaultDataLabelFormat op true te zetten.
