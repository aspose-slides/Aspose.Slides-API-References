## DataLabelFormat::get_ShowLabelValueFromCell() methode

Stelt het weergavegedrag van de celwaarde van een data-label van een opgegeven diagram voor. True toont de celwaarde. False verbergt deze. Lees **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowLabelValueFromCell() override
```

## Opmerkingen

Als de ouder van dit [DataLabelFormat](../) object een [DataLabelCollection](../../datalabelcollection/) verzameling van data-labels is, dan krijgt of stelt deze eigenschap de standaardwaarde van de ShowLabelValueFromCell eigenschap voor de nieuwe data-labels in de [DataLabelCollection](../../datalabelcollection/) verzameling. Het instellen van deze eigenschap met een waarde stelt deze waarde ook in voor de ShowLabelValueFromCell eigenschap van alle data-labels in de [DataLabelCollection](../../datalabelcollection/) verzameling (bijv. \"DataLabels.DefaultDataLabelFormat.ShowLabelValueFromCell = val;\" waardoor alle DataLabels[i].ShowLabelValueFromCell gelijk is aan val).
