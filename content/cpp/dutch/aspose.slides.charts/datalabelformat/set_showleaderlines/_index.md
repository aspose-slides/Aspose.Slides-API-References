## DataLabelFormat::set_ShowLeaderLines(bool) methode


Geeft het weergavegedrag van de leader lines van gegevenslabels van een opgegeven diagram weer. True toont de leader lines. False verbergt ze. Schrijf **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLeaderLines(bool value) override
```

## Opmerkingen


Als de ouder van dit [DataLabelFormat](../) object een [DataLabelCollection](../../datalabelcollection/) collectie van gegevenslabels is, dan krijgt deze eigenschap of stelt deze de standaardwaarde van de ShowLeaderLines eigenschap in voor de nieuwe gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) collectie. Het instellen van deze eigenschap met een waarde stelt deze waarde ook in voor de ShowLeaderLines eigenschap van alle gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) collectie (i.e. \"DataLabels.DefaultDataLabelFormat.ShowLeaderLines = val;\" zorgt ervoor dat alle DataLabels[i].ShowLeaderLines gelijk is aan val).
