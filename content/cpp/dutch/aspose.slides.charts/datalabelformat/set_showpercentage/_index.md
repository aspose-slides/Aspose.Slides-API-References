## DataLabelFormat::set_ShowPercentage(bool) methode


Stelt het weergavegedrag van het percentage van het gegevenslabel van een specifiek diagram voor. True toont de percentagewaarde. False verbergt deze. Schrijf **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowPercentage(bool value) override
```

## Opmerkingen


Als de bovenliggende van dit [DataLabelFormat](../) object een [DataLabelCollection](../../datalabelcollection/) verzameling gegevenslabels is, dan krijgt deze eigenschap of stelt hij de standaardwaarde van de ShowPercentage eigenschap in voor de nieuwe gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) verzameling. Het instellen van deze eigenschap met een waarde zet deze waarde ook voor de ShowPercentage eigenschap van alle gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) verzameling (d.w.z. "DataLabels.DefaultDataLabelFormat.ShowPercentage = val;" veroorzaakt dat alle DataLabels[i].ShowPercentage gelijk is aan val).
