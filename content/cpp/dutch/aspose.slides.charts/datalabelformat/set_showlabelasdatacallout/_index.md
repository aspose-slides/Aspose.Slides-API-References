## DataLabelFormat::set_ShowLabelAsDataCallout(bool) methode

Bepaalt of het gegevenslabel van het opgegeven diagram wordt weergegeven als een gegevensaanroep of als een gegevenslabel.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLabelAsDataCallout(bool value) override
```

## Opmerkingen

Als de ouder van dit [DataLabelFormat](../) object een [DataLabelCollection](../../datalabelcollection/) collectie van gegevenslabels is, dan krijgt deze eigenschap of stelt deze de standaardwaarde van de ShowLabelAsDataCallout eigenschap in voor de nieuwe gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) collectie. Het instellen van deze eigenschap met een waarde stelt deze waarde ook in voor de ShowLabelAsDataCallout eigenschap van alle gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) collectie (bijv. "DataLabels.DefaultDataLabelFormat.ShowLabelAsDataCallout = val;" zorgt ervoor dat alle DataLabels[i].ShowLabelAsDataCallout gelijk is aan val).
