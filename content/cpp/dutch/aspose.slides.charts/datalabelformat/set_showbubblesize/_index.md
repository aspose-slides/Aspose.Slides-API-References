## DataLabelFormat::set_ShowBubbleSize(bool) methode


Stelt het weergavegedrag van de bubbela groottewaarde van een gegevenslabel van een opgegeven diagram voor. True geeft de bubbela groottewaarde weer. False verbergt deze. Schrijf **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowBubbleSize(bool value) override
```

## Opmerkingen


Als de ouder van dit [DataLabelFormat](../) object een [DataLabelCollection](../../datalabelcollection/) collectie van gegevenslabels is, dan krijgt deze eigenschap of stelt de standaardwaarde van de ShowBubbleSize eigenschap in voor de nieuwe gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) collectie. Het instellen van deze eigenschap met een waarde stelt deze waarde ook in voor de ShowBubbleSize eigenschap van alle gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) collectie (bijv. \"DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;\" veroorzaakt dat alle DataLabels[i].ShowBubbleSize gelijk is aan val).
