## DataLabelFormat::set_ShowValue(bool) methode

Stelt het weergavegedrag van de percentagewaarde van een gegevenslabel van een opgegeven diagram voor. True geeft de percentagewaarde weer. False verbergt deze. Schrijf **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowValue(bool value) override
```

## Opmerkingen

Als de bovenliggende [DataLabelFormat](../)-object een [DataLabelCollection](../../datalabelcollection/)-verzameling van gegevenslabels is, dan krijgt deze eigenschap of stelt de standaardwaarde van de ShowValue-eigenschap in voor de nieuwe gegevenslabels in de [DataLabelCollection](../../datalabelcollection/)-verzameling. Het instellen van deze eigenschap met een waarde stelt deze waarde ook in op de ShowValue-eigenschap voor alle gegevenslabels in de [DataLabelCollection](../../datalabelcollection/)-verzameling (i.e. "DataLabels.DefaultDataLabelFormat.ShowValue = val;" waardoor alle DataLabels[i].ShowValue gelijk is aan val).
