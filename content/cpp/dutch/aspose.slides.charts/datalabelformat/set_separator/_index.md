## DataLabelFormat::set_Separator(System::String) methode


Stelt een Variant in of retourneert een Variant die het scheidingsteken vertegenwoordigt dat wordt gebruikt voor de gegevenslabels op een grafiek. Schrijf [System::String](../../../system/string/).

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_Separator(System::String value) override
```

## Opmerkingen


Als de ouder van dit [DataLabelFormat](../) object een [DataLabelCollection](../../datalabelcollection/) verzameling van gegevenslabels is, dan krijgt deze eigenschap of stelt deze de standaardwaarde van de Separator eigenschap in voor de nieuwe gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) verzameling. Het instellen van deze eigenschap met een waarde stelt deze waarde ook in voor de Separator eigenschap van alle gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) verzameling (bijv. "DataLabels.DefaultDataLabelFormat.Separator = val;" veroorzaakt dat alle DataLabels[i].Separator gelijk is aan val).
