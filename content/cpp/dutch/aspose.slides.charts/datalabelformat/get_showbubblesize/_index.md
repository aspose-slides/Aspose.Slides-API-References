## DataLabelFormat::get_ShowBubbleSize() methode

Geeft het weergeven van de bolgroottewaarde van gegevenslabels voor een opgegeven diagram weer. True geeft de bolgroottewaarde weer. False verbergt deze. Lezen **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowBubbleSize() override
```

## Opmerkingen

Als de ouder van dit [DataLabelFormat](../) object een [DataLabelCollection](../../datalabelcollection/) verzameling van gegevenslabels is, dan krijgt deze eigenschap of stelt hij de standaardwaarde van de ShowBubbleSize-eigenschap in voor de nieuwe gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) verzameling. Het instellen van deze eigenschap met een waarde stelt deze waarde ook in voor de ShowBubbleSize-eigenschap van alle gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) verzameling (bijv. "DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;" zorgt ervoor dat alle DataLabels[i].ShowBubbleSize gelijk is aan val).
