## DataLabelFormat::set_ShowLegendKey(bool) methode


Geeft het weergavegedrag van de legende-sleutel van een opgegeven diagram weer. True als de legende-sleutel van het datalabel zichtbaar is. Schrijf **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLegendKey(bool value) override
```

## Opmerkingen


Als de bovenliggende [DataLabelFormat](../)-object een [DataLabelCollection](../../datalabelcollection/)-collectie van datalabels is, dan krijgt deze eigenschap of stelt deze de standaardwaarde van de ShowLegendKey-eigenschap in voor de nieuwe datalabels in de [DataLabelCollection](../../datalabelcollection/)-collectie. Het instellen van deze eigenschap met een waarde stelt ook deze waarde in voor de ShowLegendKey-eigenschap van alle datalabels in de [DataLabelCollection](../../datalabelcollection/)-collectie (bijv. \"DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;\" waardoor alle DataLabels[i].ShowLegendKey gelijk is aan val).
