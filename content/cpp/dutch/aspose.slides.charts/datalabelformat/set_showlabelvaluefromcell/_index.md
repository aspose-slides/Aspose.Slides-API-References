## DataLabelFormat::set_ShowLabelValueFromCell(bool) methode


Geeft het weergavegedrag van de celwaarde van een opgegeven diagram weer. True toont de celwaarde. False verbergt deze. Schrijf **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLabelValueFromCell(bool value) override
```

## Opmerkingen


Als de ouder van dit [DataLabelFormat](../) object een [DataLabelCollection](../../datalabelcollection/) collectie van gegevenslabels is, dan haalt deze eigenschap de standaardwaarde van de ShowLabelValueFromCell-eigenschap op of stelt deze in voor de nieuwe gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) collectie. Het instellen van deze eigenschap met een waarde stelt deze waarde ook in voor de ShowLabelValueFromCell-eigenschap van alle gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) collectie (bijv. \"DataLabels.DefaultDataLabelFormat.ShowLabelValueFromCell = val;\" waardoor alle DataLabels[i].ShowLabelValueFromCell gelijk aan val wordt).
