## DataLabelFormat::set_Position(LegendDataLabelPosition) methode


Geeft de positie van het gegevenslabel weer. Schrijf [LegendDataLabelPosition](../../legenddatalabelposition/).

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_Position(LegendDataLabelPosition value) override
```

## Opmerkingen


Als de bovenliggende [DataLabelFormat](../)-object een [DataLabelCollection](../../datalabelcollection/)-verzameling van gegevenslabels is, dan krijgt deze eigenschap of stelt hij de standaardwaarde van de Position-eigenschap in voor de nieuwe gegevenslabels in de [DataLabelCollection](../../datalabelcollection/)-verzameling. Geeft de positie weer voor de [DataLabel](../../datalabel/)-objecten. Doezetten van deze eigenschap met een waarde stelt ook deze waarde in voor de Position-eigenschap van alle gegevenslabels in de [DataLabelCollection](../../datalabelcollection/)-verzameling (bijv. "DataLabels.DefaultDataLabelFormat.Position = val;" waardoor alle DataLabels[i].Position gelijk is aan val).
