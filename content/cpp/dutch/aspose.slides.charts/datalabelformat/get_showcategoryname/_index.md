## DataLabelFormat::get_ShowCategoryName() methode

Vertegenwoordigt het weergavegedrag van de categorienaam van de datalabels van een opgegeven diagram. True om de categorienaam voor de datalabels op een diagram weer te geven. False om te verbergen. Lees **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowCategoryName() override
```

## Opmerkingen

Als de ouder van dit [DataLabelFormat](../)-object een [DataLabelCollection](../../datalabelcollection/)-collectie van datalabels is, krijgt deze eigenschap of stelt deze de standaardwaarde van de ShowCategoryName-eigenschap in voor de nieuwe datalabels in de [DataLabelCollection](../../datalabelcollection/)-collectie. Het instellen van deze eigenschap met een waarde stelt deze waarde ook in voor de ShowCategoryName-eigenschap van alle datalabels in de [DataLabelCollection](../../datalabelcollection/)-collectie (d.w.z. "DataLabels.DefaultDataLabelFormat.ShowCategoryName = val;" veroorzaakt dat alle DataLabels[i].ShowCategoryName gelijk is aan val).
