## BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType) methode

Specificeert of de AsCell-, AsCells-, AsLiteralString- of AsLiteralDouble-eigenschap daadwerkelijk aanwezig is in afstammelingen. Met andere woorden specificeert het het type waarde van de Data-eigenschap. Schrijf [Charts::DataSourceType](../../datasourcetype/).

```cpp
void Aspose::Slides::Charts::BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType value) override
```

## Opmerkingen

Voor punten in [ChartDataPointCollection](../../chartdatapointcollection/) is deze eigenschap alleen-lezen. In dit geval kun je voor het wijzigen van de waarde van deze eigenschap een van de ChartDataPointCollection.DataSourceTypeFor<...> eigenschappen gebruiken.
