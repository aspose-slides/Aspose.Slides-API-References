## TickLabelPositionType enum

Geeft het type positie van tick-markeringlabels op de opgegeven axis weer.

```cpp
enum class TickLabelPositionType
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| High | 0 | Specificeert dat de axis labels zich aan het hoge uiteinde van de perpendicular axis bevinden. |
| Low | 1 | Specificeert dat de axis labels zich aan het lage uiteinde van de perpendicular axis bevinden. |
| NextTo | 2 | Specificeert dat de axis labels zich naast de axis bevinden. |
| None | 3 | Specificeert dat de axis labels niet worden getekend. |
