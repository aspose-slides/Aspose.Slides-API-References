## IDataLabelFormat::set_Separator(System::String) methode

Stelt een Variant in of retourneert een Variant die de Separator vertegenwoordigt die wordt gebruikt voor de gegevenslabels op een diagram. Schrijf [System::String](../../../system/string/).

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_Separator(System::String value)=0
```

## Opmerkingen

Als de bovenliggende van dit [DataLabelFormat](../../datalabelformat/) object een [DataLabelCollection](../../datalabelcollection/) collectie van gegevenslabels is, dan haalt deze eigenschap de standaardwaarde van de Separator-eigenschap op of stelt deze in voor de nieuwe gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) collectie. Het instellen van deze eigenschap met een waarde stelt deze waarde ook in voor de Separator-eigenschap van alle gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) collectie (bijv. "DataLabels.DefaultDataLabelFormat.Separator = val;" waardoor alle DataLabels[i].Separator gelijk is aan val).
