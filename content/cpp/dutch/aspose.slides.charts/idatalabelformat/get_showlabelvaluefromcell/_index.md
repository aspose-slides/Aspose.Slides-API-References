## IDataLabelFormat::get_ShowLabelValueFromCell() methode


Stelt het weergavegedrag van de celwaarde van een opgegeven diagramgegevenslabel in. True toont de celwaarde. False verbergt deze. Lezen **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowLabelValueFromCell()=0
```

## Opmerkingen


Als de bovenliggende van dit [DataLabelFormat](../../datalabelformat/) object een [DataLabelCollection](../../datalabelcollection/) collectie van gegevenslabels is, dan krijgt of stelt deze eigenschap de standaardwaarde van de ShowLabelValueFromCell eigenschap in voor de nieuwe gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) collectie. Het instellen van deze eigenschap met een waarde stelt deze waarde ook in voor de ShowLabelValueFromCell eigenschap van alle gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) collectie (i.e. "DataLabels.DefaultDataLabelFormat.ShowLabelValueFromCell = val;" wat ervoor zorgt dat alle DataLabels[i].ShowLabelValueFromCell gelijk is aan val).
