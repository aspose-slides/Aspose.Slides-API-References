## IDataLabelFormat::set_ShowLabelValueFromCell(bool) methode

Stelt het weergavegedrag van de celwaarde van een gegevenslabel in een opgegeven diagram voor. True toont de celwaarde. False verbergt deze. Schrijf **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowLabelValueFromCell(bool value)=0
```

## Opmerkingen

Als de bovenliggende van dit [DataLabelFormat](../../datalabelformat/) object een [DataLabelCollection](../../datalabelcollection/) verzameling van gegevenslabels is, dan krijgt deze eigenschap of stelt deze de standaardwaarde van de ShowLabelValueFromCell eigenschap in voor de nieuwe gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) verzameling. Het instellen van deze eigenschap met een waarde stelt deze waarde ook in voor de ShowLabelValueFromCell eigenschap van alle gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) verzameling (i.e. "DataLabels.DefaultDataLabelFormat.ShowLabelValueFromCell = val;" zorgt ervoor dat alle DataLabels[i].ShowLabelValueFromCell gelijk is aan val).
