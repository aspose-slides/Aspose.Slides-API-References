## IDataLabelFormat::set_IsNumberFormatLinkedToSource(bool) methode

Schrijf **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_IsNumberFormatLinkedToSource(bool value)=0
```

## Opmerkingen

Als de parent van dit [DataLabelFormat](../../datalabelformat/) object een [DataLabelCollection](../../datalabelcollection/) collectie van gegevenslabels is, dan krijgt of stelt deze eigenschap de standaardwaarde van de IsNumberFormatLinkedToSource eigenschap in voor de nieuwe gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) collectie. Het instellen van deze eigenschap met een waarde stelt deze waarde ook in voor de IsNumberFormatLinkedToSource eigenschap van alle gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) collectie (i.e. \"DataLabels.DefaultDataLabelFormat.IsNumberFormatLinkedToSource = val;\" waardoor alle DataLabels[i].IsNumberFormatLinkedToSource gelijk is aan val).
