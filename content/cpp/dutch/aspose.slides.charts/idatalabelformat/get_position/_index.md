## IDataLabelFormat::get_Position() methode


Geeft de positie van het gegevenslabel weer. Lees [LegendDataLabelPosition](../../legenddatalabelposition/).

```cpp
virtual LegendDataLabelPosition Aspose::Slides::Charts::IDataLabelFormat::get_Position()=0
```

## Opmerkingen


Als de ouder van dit [DataLabelFormat](../../datalabelformat/) object een [DataLabelCollection](../../datalabelcollection/) collectie gegevenslabels is, dan haalt deze eigenschap de standaardwaarde van de Position-eigenschap op of stelt deze in voor de nieuwe gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) collectie. Geeft de positie weer voor de [DataLabel](../../datalabel/) objecten. Het instellen van deze eigenschap met een waarde stelt deze waarde ook in voor de Position-eigenschap van alle gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) collectie (bijv. "DataLabels.DefaultDataLabelFormat.Position = val;" waardoor alle DataLabels[i].Position gelijk is aan val).
