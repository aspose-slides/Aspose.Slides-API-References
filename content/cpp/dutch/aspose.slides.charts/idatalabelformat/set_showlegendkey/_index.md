## IDataLabelFormat::set_ShowLegendKey(bool) methode


Geeft het weergavegedrag van de legende-sleutel van het gegevenslabel van een opgegeven diagram weer. True als de legende-sleutel van het gegevenslabel zichtbaar is. Schrijf **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowLegendKey(bool value)=0
```

## Opmerkingen


Als de bovenliggende van dit [DataLabelFormat](../../datalabelformat/) object een [DataLabelCollection](../../datalabelcollection/) collectie van gegevenslabels is, dan krijgt deze eigenschap of stelt deze de standaardwaarde van de ShowLegendKey eigenschap in voor de nieuwe gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) collectie. Stel deze eigenschap in met een waarde, dan stelt dit ook deze waarde in op de ShowLegendKey eigenschap voor alle gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) collectie (bijv. "DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;" zorgt ervoor dat alle DataLabels[i].ShowLegendKey gelijk is aan val).
