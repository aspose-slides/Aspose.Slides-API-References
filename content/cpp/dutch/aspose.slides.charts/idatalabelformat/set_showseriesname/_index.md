## IDataLabelFormat::set_ShowSeriesName(bool) methode

Stelt een Boolean in om het weergavegedrag van de serienaam voor de gegevenslabels in een diagram aan te geven. True om de serienaam weer te geven. False om te verbergen. Schrijf **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowSeriesName(bool value)=0
```

## Opmerkingen

Als de ouder van dit [DataLabelFormat](../../datalabelformat/) object een [DataLabelCollection](../../datalabelcollection/) verzameling van gegevenslabels is, dan krijgt deze eigenschap of stelt de standaardwaarde van de ShowSeriesName eigenschap in voor de nieuwe gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) verzameling. Deze eigenschap instellen met een waarde stelt deze waarde ook in op de ShowSeriesName eigenschap voor alle gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) verzameling (bijv. \"DataLabels.DefaultDataLabelFormat.ShowSeriesName = val;\" waardoor alle DataLabels[i].ShowSeriesName gelijk is aan val).
