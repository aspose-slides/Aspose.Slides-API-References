## IDataLabelFormat::get_ShowBubbleSize() methode


Geeft het weergavegedrag van de bubbelformaatwaarde van een opgegeven diagram weer. True toont de bubbelformaatwaarde. False om te verbergen. Lezen **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowBubbleSize()=0
```

## Opmerkingen


Als de ouder van dit [DataLabelFormat](../../datalabelformat/) object een [DataLabelCollection](../../datalabelcollection/) verzameling van gegevenslabels is, dan verkrijgt of stelt deze eigenschap de standaardwaarde van de ShowBubbleSize eigenschap in voor de nieuwe gegevenslabels in de [DataLabelCollection](../../datalabelcollection/)-verzameling. Het instellen van deze eigenschap met een waarde stelt deze waarde ook in voor de ShowBubbleSize eigenschap van alle gegevenslabels in de [DataLabelCollection](../../datalabelcollection/)-verzameling (bijv. "DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;" veroorzaakt dat alle DataLabels[i].ShowBubbleSize gelijk is aan val).
