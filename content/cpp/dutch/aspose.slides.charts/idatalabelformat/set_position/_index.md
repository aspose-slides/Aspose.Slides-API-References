## IDataLabelFormat::set_Position(LegendDataLabelPosition) methode


Geeft de positie van het gegevenslabel weer. Schrijf [LegendDataLabelPosition](../../legenddatalabelposition/).

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_Position(LegendDataLabelPosition value)=0
```

## Opmerkingen


Als de ouder van dit [DataLabelFormat](../../datalabelformat/) object een [DataLabelCollection](../../datalabelcollection/) verzameling van gegevenslabels is, dan krijgt deze eigenschap of stelt deze de standaardwaarde van de eigenschap Position in voor de nieuwe gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) verzameling. Geeft de positie weer voor de [DataLabel](../../datalabel/) objecten. Het instellen van deze eigenschap met een waarde stelt deze waarde ook in voor de eigenschap Position van alle gegevenslabels in de [DataLabelCollection](../../datalabelcollection/) verzameling (bijv. "DataLabels.DefaultDataLabelFormat.Position = val;" waardoor alle DataLabels[i].Position gelijk aan val is).
