## DataLabel::Hide() methode


Verberg het data label door alle Show*-flags (ShowValue, ...) op de false-status te zetten. IsVisible zal daarna false zijn.

```cpp
void Aspose::Slides::Charts::DataLabel::Hide() override
```

## Opmerkingen


Als het data label niet zichtbaar is (IsVisible is false) kun je het data label zichtbaar maken door de Show*-flags (ShowValue, ...) op de true-status te zetten.
