## IChartCategoryCollection::set_UseCells(bool) methode


Als true wordt het werkblad gebruikt voor het opslaan van categorieën (dit geval ondersteunt meerlagige categorieën). Als false wordt het werkblad NIET gebruikt voor het opslaan van waarden (en dit geval ondersteunt geen meerlagige categorieën). Schrijf **bool**.

virtual void Aspose::Slides::Charts::IChartCategoryCollection::set_UseCells(bool value)=0
