## PictureType enum

Bepaalt de modus van het vullen van de balkafbeelding.

```cpp
enum class PictureType
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| NotDefined | -1 | Niet gedefinieerd. |
| Stack | 0 | De afbeelding wordt zo groot gemaakt dat hij maximaal 15 keer wordt herhaald in de langste gestapelde balk. |
| StackScale | 1 | De afbeelding wordt zo groot gemaakt op een gespecificeerd aantal eenheden en herhaald over de lengte van de balk. |
| Stretch | 2 | De afbeelding wordt uitgerekt over de volledige lengte van de gestapelde balk. |
