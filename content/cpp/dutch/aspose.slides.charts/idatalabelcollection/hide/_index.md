## IDataLabelCollection::Hide() methode


Maak het gegevenslabel standaard verborgen door alle Show*-flags (ShowValue, ...) van de eigenschap DefaultDataLabelFormat op false te zetten. IsVisible zal daarna false zijn.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelCollection::Hide()=0
```

## Opmerkingen


Als het gegevenslabel standaard niet zichtbaar is (IsVisible is false) kun je het gegevenslabel \"zichtbaar \nstandaard\" maken door de Show*-flags (ShowValue, ...) van de eigenschap DefaultDataLabelFormat op true te zetten.
