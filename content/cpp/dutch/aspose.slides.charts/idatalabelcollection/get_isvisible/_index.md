## IDataLabelCollection::get_IsVisible() methode


False betekent dat het gegevenslabel standaard niet zichtbaar is (en dus alle Show*-flags (ShowValue, ...) van de DefaultDataLabelFormat eigenschap false zijn). Alleen-lezen **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelCollection::get_IsVisible()=0
```

## Opmerkingen


Als het gegevenslabel standaard zichtbaar is, kun je het standaard verborgen maken met [Hide()](../hide/) methode. Maar als het gegevenslabel niet standaard zichtbaar is (IsVisible is false) kun je het gegevenslabel "visible 
by default" zichtbaar maken door de Show*-flags (ShowValue, ...) van de DefaultDataLabelFormat eigenschap op true te zetten.
