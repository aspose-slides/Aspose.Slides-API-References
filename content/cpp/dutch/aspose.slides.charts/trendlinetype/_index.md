## TrendlineType enum

Geeft het type van de trendlijn weer

```cpp
enum class TrendlineType
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Exponential | 0 | Specificeert dat de trendlijn een exponentiële curve moet zijn in de vorm. |
| Linear | 1 | Specificeert dat de trendlijn een lijn moet zijn in de vorm. |
| Logarithmic | 2 | Specificeert dat de trendlijn een logaritmische curve moet zijn in de vorm, waarbij log de natuurlijke logaritme is. |
| MovingAverage | 3 | Specificeert dat de trendlijn een voortschrijdend gemiddelde is van periode Period. |
| Polynomial | 4 | Specificeert dat de trendlijn een polynomiale curve van orde Order moet zijn in de vorm. |
| Power | 5 | Specificeert dat de trendlijn een vermogenscurve moet zijn in de vorm. |
