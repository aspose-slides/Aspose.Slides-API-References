## ChartTypeCharacterizer::IsChartTypeSurface(ChartType) methode

Retourneert true als chartType een van de Surface-subtypen is. De set subtypen komt overeen met de overeenkomstige set in PowerPoint (zie \"Change Chart Type\" dialoog in PowerPoint): [ChartType::Surface3D](../../charttype/), [ChartType::WireframeSurface3D](../../charttype/), [ChartType::Contour](../../charttype/), [ChartType::WireframeContour](../../charttype/).
