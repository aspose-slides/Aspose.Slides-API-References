## IDataLabel::get_IsVisible() methode

False betekent dat gegevenslabel niet zichtbaar is (en dus alle Show*-flags (ShowValue, ...) onwaar zijn). Alleen-lezen **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabel::get_IsVisible()=0
```

## Opmerkingen

Als gegevenslabel zichtbaar is, kun je het verbergen met de [Hide()](../hide/) methode. Maar als gegevenslabel niet zichtbaar is (IsVisible is false) kun je het gegevenslabel zichtbaar maken door Show*-flags (ShowValue, ...) op true te zetten.
