## IDataLabel::Hide() methode


Maak de datalabel verborgen door alle Show*-flags (ShowValue, ...) op false te zetten. IsVisible zal daarna false zijn.

```cpp
virtual void Aspose::Slides::Charts::IDataLabel::Hide()=0
```

## Opmerkingen


Als het datalabel niet zichtbaar is (IsVisible is false) kun je het datalabel zichtbaar maken door de Show*-flags (ShowValue, ...) op true te zetten.
