## Enumerable::Range(int32_t, int32_t) methode

Genereert een reeks gehele getallen binnen een opgegeven bereik.

```cpp
static SharedPtr<Collections::Generic::IEnumerable<int32_t>> System::Linq::Enumerable::Range(int32_t start, int32_t count)
```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| start | **int32_t** | De waarde van het eerste gehele getal in de reeks. |
| count | **int32_t** | Het aantal opeenvolgende gehele getallen om te genereren. |

### Retourwaarde

Een IEnumerable van **int32_t**'s die een reeks opeenvolgende gehele getallen bevat.
