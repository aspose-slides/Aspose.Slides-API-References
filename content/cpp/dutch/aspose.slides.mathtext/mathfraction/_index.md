## MathFraction klasse

Specificeert het breukobject, bestaande uit een teller en een noemer gescheiden door een breukstreep. De breukstreep kan horizontaal of diagonaal zijn, afhankelijk van de breukeigenschappen. Het breukobject wordt ook gebruikt om de stack-functie weer te geven, die één element boven een ander plaatst, zonder breukstreep.

```cpp
class MathFraction : public Aspose::Slides::MathText::MathElementBase,
                     public Aspose::Slides::MathText::IMathFraction,
                     public Aspose::Slides::MathText::IHasControlCharacterProperties
```
