## MathBox klasse

Specificeert de logische boxing (verpakking) van een wiskundig element. Bijvoorbeeld, een boxed object kan dienen als een operatoremulator met of zonder een uitlijningspunt, kan dienen als een regeleinde-punt, of kan gegroepeerd worden zodat er geen regeleinden binnen voorkomen. Bijvoorbeeld, de \"==\" operator moet worden geboxed om regeleinden te voorkomen.

```cpp
class MathBox : public Aspose::Slides::MathText::MathElementBase,
                public Aspose::Slides::MathText::IMathBox,
                public Aspose::Slides::MathText::IHasControlCharacterProperties
```
