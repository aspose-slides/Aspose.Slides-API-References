## MathBox::set_AlignmentPoint(bool) methode

When true, this operator emulator serves as an alignment point; that is, designated alignment points in other equations can be aligned with it. Standaard: false

```cpp
void Aspose::Slides::MathText::MathBox::set_AlignmentPoint(bool value) override
```

## Opmerkingen

Example: 
```cpp
auto box = System::MakeObject<MathematicalText>(u"==")->ToBox();
box->set_AlignmentPoint(true);
```
