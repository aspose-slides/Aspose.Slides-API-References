## IMathPhantom::get_Show() methode

Geeft een waarde die aangeeft of het basiselement wordt weergegeven.

```cpp
virtual bool Aspose::Slides::MathText::IMathPhantom::get_Show()=0
```

## Opmerkingen

Wanneer **false**, is het basiselement verborgen maar kan nog steeds ruimte innemen, afhankelijk van andere phantom-instellingen. Komt overeen met het OMML-attribuut **m:show**.
