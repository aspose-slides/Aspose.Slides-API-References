## MathMatrix::get_MinColumnWidth() methode


Minimale kolombreedte in twips (1/20ste van een punt). De tussenruimte (ook aangeduid als “Column Gap” of “Gap Width”) wordt toegevoegd aan de MinColumnWidth om de totale Matrix [Column](../../../aspose.slides/column/) Spacing (afstand tussen dezelfde randen van verschillende kolommen) te bepalen. Standaard: 0.

```cpp
uint32_t Aspose::Slides::MathText::MathMatrix::get_MinColumnWidth() override
```

## Opmerkingen


Voorbeeld: 
```cpp
auto matrix = System::MakeObject<MathMatrix>(2, 3);
matrix->set_MinColumnWidth(20);
```
