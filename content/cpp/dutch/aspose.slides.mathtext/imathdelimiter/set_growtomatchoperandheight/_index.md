## IMathDelimiter::set_GrowToMatchOperandHeight(bool) methode

Specificeert de groei van BeginningCharacter, SeparatorCharacter, EndingCharacter. Wanneer true, groeit de delimiter verticaal om de operandhoogte te evenaren. De standaardwaarde is true

```cpp
virtual void Aspose::Slides::MathText::IMathDelimiter::set_GrowToMatchOperandHeight(bool value)=0
```

## Opmerkingen

Voorbeeld:
```cpp
auto delimiter = System::MakeObject<MathematicalText>(u"x")->Divide(u"y")->Enclose();
delimiter->set_GrowToMatchOperandHeight(false);
```
