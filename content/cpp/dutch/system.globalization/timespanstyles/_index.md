## TimeSpanStyles enum

Specificeert de opmaakopties die de tekenreeks-parsing aanpassen voor methoden die een tekenreeksweergave van een tijdsinterval omzetten naar een Timespan-object.

```cpp
enum class TimeSpanStyles : int32_t
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| None | 0 | Het tijdsinterval dat wordt weergegeven door de inptut-string wordt geïnterpreteerd als een negatief tijdsinterval alleen als er een minteken aanwezig is. |
| AssumeNegative | 1 | Het tijdsinterval dat wordt weergegeven door de inptut-string wordt altijd geïnterpreteerd als een negatief tijdsinterval. |
