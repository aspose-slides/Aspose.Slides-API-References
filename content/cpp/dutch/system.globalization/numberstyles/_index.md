## NumberStyles enum

Number style allowed when parsing.

```cpp
enum class NumberStyles : int32_t
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| None | 0 | Geen niet-cijfertekens. |
| AllowLeadingWhite | 1 | Sta leidende witruimtes toe. |
| AllowTrailingWhite | 2 | Sta afsluitende witruimtes toe. |
| AllowLeadingSign | 4 | Sta leidend teken toe. |
| Integer | n/a | Standaard gehele getal opmaak. |
| AllowTrailingSign | 8 | Sta afsluitend teken toe. |
| AllowParentheses | 16 | Sta haakjes toe voor negatieve waarden. |
| AllowDecimalPoint | 32 | Sta decimaalteken toe. |
| AllowThousands | 64 | Sta scheidingstekens voor groepen toe. |
| Number | n/a | Standaard samengesteld getalformaat. |
| AllowExponent | 128 | Sta exponent teken toe. |
| Float | n/a | Standaard zwevendekomma getalformaat. |
| AllowCurrencySymbol | 256 | Sta valutasymbool toe. |
| Currency | n/a | Standaard valutavorm. |
| Any | n/a | Sta elke opmaakspecificatie toe. |
| AllowHexSpecifier | 512 | Sta hexadecimale getallen toe. |
| HexNumber | n/a | Standaard hexadecimale getalformaat. |
