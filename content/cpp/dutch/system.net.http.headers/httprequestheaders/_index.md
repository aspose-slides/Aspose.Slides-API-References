## HttpRequestHeaders klasse

Stelt de verzameling van de 'Request'-headers voor. Objecten van deze klasse mogen alleen worden toegewezen met de [System::MakeObject()](../../system/makeobject/)-functie. Maak nooit een instantie van dit type op de stack of met operator new, aangezien dit resulteert in runtime-fouten en/of assertiefouten. Wikkel deze klasse altijd in een [System::SmartPtr](../../system/smartptr/)-pointer en gebruik deze pointer om deze als argument door te geven aan functies.

```cpp
class HttpRequestHeaders : public System::Net::Http::Headers::HttpHeaders
```
