## KeyInfoClause klasse


Alle implementaties van [KeyInfo](../keyinfo/) subelementen moeten deze abstracte klasse erven. Objecten van deze klasse mogen alleen worden toegewezen met behulp van de functie [System::MakeObject()](../../system/makeobject/). Maak nooit een exemplaar van dit type op de stack of met operator new, omdat dit zal leiden tot runtime-fouten en/of assertion-fouten. Wikkel deze klasse altijd in een [System::SmartPtr](../../system/smartptr/)-pointer en gebruik deze pointer om deze als argument aan functies door te geven.

```cpp
class KeyInfoClause : public System::Object
```
