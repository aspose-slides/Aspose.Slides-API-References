## RSAKeyValue klasse

Vertegenwoordigt het element '[RSAKeyValue](./)' van de XML-handtekening. Objecten van deze klasse mogen alleen worden gealloceerd met behulp van de functie [System::MakeObject()](../../system/makeobject/). Maak nooit een instantie van dit type op de stack of met operator new, omdat dit zal leiden tot runtime-fouten en/of assertiefouten. Wijzig deze klasse altijd in een [System::SmartPtr](../../system/smartptr/)-pointer en gebruik deze pointer om deze als argument aan functies door te geven.

```cpp
class RSAKeyValue : public System::Security::Cryptography::Xml::KeyInfoClause
```
