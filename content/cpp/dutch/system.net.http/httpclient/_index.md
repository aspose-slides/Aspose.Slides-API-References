## HttpClient klasse

Stelt een basisklasse van een HTTP-client voor voor het verzenden van verzoeken en ontvangen van antwoorden. Objecten van deze klasse mogen alleen worden toegewezen met de functie [System::MakeObject()](../../system/makeobject/). Maak nooit een instantie van dit type op de stack of met operator new, omdat dit leidt tot runtime-fouten en/of assertiefouten. Wikkel deze klasse altijd in een [System::SmartPtr](../../system/smartptr/)-pointer en gebruik deze pointer om deze door te geven aan functies als argument.

```cpp
class HttpClient : public System::Net::Http::HttpMessageInvoker
```
