## DashCap enum

Specificeert het type van een kap dat aan beide uiteinden van een streep in een gestippelde lijn wordt gebruikt.

```cpp
enum class DashCap
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Flat | 0 | Een vierkante kap die beide uiteinden van een streep afvlakt. |
| Round | 2 | Een ronde kap die beide uiteinden van een streep afrondt. |
| Triangle | 3 | Een driehoekige kap die beide uiteinden van een streep wijst. |
