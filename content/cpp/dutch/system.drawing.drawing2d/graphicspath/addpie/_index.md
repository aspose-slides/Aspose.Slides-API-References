## GraphicsPath::AddPie(float, float, float, float, float, float) methode

Voegt de opgegeven omtrek van de taartvorm toe aan het pad dat wordt vertegenwoordigd door het huidige object.

```cpp
void System::Drawing::Drawing2D::GraphicsPath::AddPie(float x, float y, float width, float height, float startAngle, float sweepAngle)
```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| x | **float** | De X-coördinaat van de linkerbovenhoek van de rechthoek die de ellips omsluit waaruit de taart wordt getekend |
| y | **float** | De Y-coördinaat van de linkerbovenhoek van de rechthoek die de ellips omsluit waaruit de taart wordt getekend |
| width | **float** | De breedte van de rechthoek die de ellips omsluit waaruit de taart wordt getekend |
| height | **float** | De hoogte van de rechthoek die de ellips omsluit waaruit de taart wordt getekend |
| startAngle | **float** | Geeft de beginhoek van de taart in graden aan, gemeten met de klok mee vanaf de X-as |
| sweepAngle | **float** | Geeft de hoek tussen de beginhoek en het einde van de taart aan |
