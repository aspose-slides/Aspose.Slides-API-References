## GrayScale klasse


Representeert een Gray Scale-effect. Converteert alle kleureffectwaarden naar een grijstint, overeenkomstig hun luminantie. Effect alfa (opaciteit) waarden blijven ongewijzigd.

```cpp
class GrayScale : public Aspose::Slides::Effects::ImageTransformOperation,
                  public Aspose::Slides::Effects::IGrayScale,
                  public Aspose::Slides::Effects::IVisualEffect
```
