## IAlphaFloor klasse

Stelt een Alpha Floor-effect voor. Alpha (dekkingsgraad) waarden kleiner dan 100 % worden naar nul veranderd. Met andere woorden, alles dat gedeeltelijk transparant is wordt volledig transparant.

```cpp
class IAlphaFloor : public virtual Aspose::Slides::Effects::IImageTransformOperation,
                    public Aspose::Slides::IAccessiblePVIObject<System::SharedPtr<Aspose::Slides::Effects::IAlphaFloorEffectiveData>>
```
