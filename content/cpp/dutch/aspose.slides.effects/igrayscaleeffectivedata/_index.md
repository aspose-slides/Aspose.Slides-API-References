## IGrayScaleEffectiveData klasse

Onveranderlijk object dat een Gray Scale-effect weergeeft. Converteert alle effect-kleurwaarden naar een tint grijs, overeenkomstig hun luminantie. Effect-alpha (doorzichtigheid) waarden blijven onaangetast.

class IGrayScaleEffectiveData : public virtual Aspose::Slides::Effects::IEffectEffectiveData
