## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [DataGrid](./datagrid/) | Dummy-klasse die het mogelijk maakt om vertaalde code te koppelen aan [DataGrid](./datagrid/)-referenties, maar deze niet uit te voeren. Bevat geen correct geïmplementeerde leden. Objecten van deze klasse mogen alleen worden gealloceerd met de [System::MakeObject()](../system/makeobject/)-functie. Maak nooit een instantie van dit type aan op de stack of met operator new, omdat dit leidt tot runtime-fouten en/of assertiefouten. Wikkel deze klasse altijd in een [System::SmartPtr](../system/smartptr/)-pointer en gebruik deze pointer om hem als argument aan functies door te geven. |
