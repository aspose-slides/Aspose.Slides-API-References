## Details_ExternalException klasse

Het basistype voor alle COM-interop-exceptions en structured exception handling (SEH) exceptions. Maak nooit handmatig instances van deze klasse aan. Gebruik in plaats daarvan de ExternalException klasse. Wikkel de ExternalException klasse-instances nooit in [System::SmartPtr](../../system/smartptr/).

```cpp
class Details_ExternalException : public System::Details_ExceptionWithErrorCode<Details_SystemException>
```
