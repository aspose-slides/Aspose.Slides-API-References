## HMACSHA512 klasse


Hash-gebaseerde Bericht [Authentication](../../system.security.authentication/) Code die de [SHA512](../sha512/) hash-functie gebruikt. Gedeeltelijk geïmplementeerd. Objecten van deze klasse mogen alleen worden toegewezen met de functie [System::MakeObject()](../../system/makeobject/). Maak nooit een instantie van dit type op de stack of met operator new, want dit leidt tot runtime-fouten en/of assertiefouten. Omhul altijd deze klasse in een [System::SmartPtr](../../system/smartptr/)-pointer en gebruik die pointer om deze als argument aan functies door te geven.

```cpp
class HMACSHA512 : public System::Security::Cryptography::HashAlgorithm
```
