## HMACSHA1 klasse

Hashgebaseerde bericht [Authentication](../../system.security.authentication/) code die de [SHA1](../sha1/) hash-functie gebruikt. Niet geïmplementeerd. Objecten van deze klasse mogen alleen worden toegewezen met de [System::MakeObject()](../../system/makeobject/)-functie. Maak nooit een exemplaar van dit type op de stack of met operator new, omdat dit zal leiden tot runtime-fouten en/of assertiefouten. Wikkel deze klasse altijd in een [System::SmartPtr](../../system/smartptr/)-pointer en gebruik die pointer om deze als argument aan functies door te geven.

```cpp
class HMACSHA1 : public System::Security::Cryptography::HashAlgorithm
```
