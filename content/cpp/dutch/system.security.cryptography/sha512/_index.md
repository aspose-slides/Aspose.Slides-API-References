## SHA512 klasse

Berekent de [SHA512](./) hash voor invoergegevens. In C++ [SHA512](./) is geen abstracte klasse. Objecten van deze klasse mogen alleen worden toegewezen met de [System::MakeObject()](../../system/makeobject/) functie. Maak nooit een instantie van dit type op de stack of met de operator new, omdat dit zal leiden tot runtime-fouten en/of assertiefouten. Wikkel deze klasse altijd in een [System::SmartPtr](../../system/smartptr/) pointer en gebruik deze pointer om deze als argument aan functies door te geven.

```cpp
class SHA512 : public System::Security::Cryptography::HashAlgorithm
```
