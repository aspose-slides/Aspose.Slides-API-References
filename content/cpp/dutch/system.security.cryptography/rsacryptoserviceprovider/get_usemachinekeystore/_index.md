## RSACryptoServiceProvider::get_UseMachineKeyStore() methode

Controleert of de sleutel wordt bewaard in de machineopslag in plaats van in de gebruikersopslag.

```cpp
static bool System::Security::Cryptography::RSACryptoServiceProvider::get_UseMachineKeyStore()
```

### Retourwaarde

True als de sleutel moet worden bewaard in de machineopslag, false als deze moet worden bewaard in de gebruikersopslag.
