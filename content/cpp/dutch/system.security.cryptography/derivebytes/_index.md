## DeriveBytes klasse

Abstracte klasse waarvan alle klassen die byte-reeksen van een opgegeven lengte afleiden, erven. Objecten van deze klasse mogen alleen worden gealloceerd met de functie [System::MakeObject()](../../system/makeobject/). Maak nooit een instantie van dit type op de stack of met operator new, omdat dit runtime-fouten en/of assert-fouten veroorzaakt. Wikkel deze klasse altijd in een [System::SmartPtr](../../system/smartptr/)-pointer en gebruik die pointer om deze aan functies als argument door te geven.

```cpp
class DeriveBytes : public System::Object
```
