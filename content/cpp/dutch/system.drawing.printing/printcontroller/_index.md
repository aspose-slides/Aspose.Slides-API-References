## PrintController klasse


Beheert hoe een document wordt afgedrukt wanneer wordt afgedrukt vanuit een [Windows](../../system.windows/) Forms-toepassing. Objecten van deze klasse mogen alleen worden toegewezen met behulp van de functie [System::MakeObject()](../../system/makeobject/). Maak nooit een instantie van dit type op de stack of met operator new, omdat dit runtime-fouten en/of assertiefouten oplevert. Wikkel deze klasse altijd in een [System::SmartPtr](../../system/smartptr/)-pointer en gebruik die pointer om het als argument aan functies door te geven.

```cpp
class PrintController : public System::Object
```
