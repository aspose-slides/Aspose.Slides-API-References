## ReflectionTypeLoadException typedef


ReflectionTypeLoadException wordt gegooid door de Module.GetTypes-methode als een of meer van de klassen in een module niet kunnen worden geladen. Verpak de ReflectionTypeLoadException-klasse-instanties nooit in [System::SmartPtr](../../system/smartptr/).

```cpp
using System::Reflection::ReflectionTypeLoadException = typedef System::ExceptionWrapper<Details_ReflectionTypeLoadException>
```
