## Details_TargetInvocationException klasse

TargetInvocationException wordt gegooid door methoden die via reflectie worden aangeroepen. Maak nooit handmatig instanties van deze klasse. Gebruik in plaats daarvan de TargetInvocationException klasse. Verpak de TargetInvocationException klasse-instanties nooit in [System::SmartPtr](../../system/smartptr/).

```cpp
class Details_TargetInvocationException : public System::Details_ApplicationException
```
