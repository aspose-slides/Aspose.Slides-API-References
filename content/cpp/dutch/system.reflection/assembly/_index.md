## Assembly klasse

[Reflection](../) klasse die assembly beschrijft. Support is beperkt omdat de regels behoorlijk verschillen tussen C# en C++. Objecten van deze klasse mogen alleen worden gealloceerd met de [System::MakeObject()](../../system/makeobject/) functie. Maak nooit een exemplaar van dit type op de stack of met operator new, aangezien dit zal leiden tot runtime fouten en/of assertiefouten. Wrap deze klasse altijd in een [System::SmartPtr](../../system/smartptr/)-pointer en gebruik deze pointer om deze als argument aan functies door te geven.

```cpp
class Assembly : public System::Object
```
