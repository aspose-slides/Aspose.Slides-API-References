## CollectionBase::get_Count() methode

Retourneert het aantal elementen dat in de collectie-instantie is opgenomen. Deze methode kan niet worden overschreven.

```cpp
int32_t System::Collections::CollectionBase<T>::get_Count()
```

### Retourwaarde

Het aantal elementen dat in de collectie-instantie is opgenomen. Het ophalen van de waarde van deze methode is een O(1)-operatie.
