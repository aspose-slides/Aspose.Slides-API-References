## IEnumeratorImplValueType::MoveNext() methode


Verplaatst de enumerator naar het volgende element. Als geen element eerder werd gerefereerd, wordt de referentie ingesteld op het eerste beschikbare element. Als het einde van de container is bereikt, gebeurt er niets.

```cpp
virtual bool System::Collections::IEnumeratorImplValueType<T>::MoveNext() override
```


### Retourwaarde

True als er een element beschikbaar is na de oproep, false anders.
