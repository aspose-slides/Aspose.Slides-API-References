## IEnumerator::MoveNext() methode


Verplaatst de enumerator naar het volgende element. Als er geen element eerder werd gerefereerd, stelt de referentie in op het eerste beschikbare element. Als het einde van de container is bereikt, doet het niets.

```cpp
virtual bool System::Collections::IEnumerator::MoveNext()=0
```


### Retourwaarde

True als er na de aanroep een element beschikbaar is, false anders.
