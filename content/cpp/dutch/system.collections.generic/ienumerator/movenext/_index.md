## IEnumerator::MoveNext() methode


Verplaatst de enumerator naar het volgende element. Als er vóór dat moment geen element werd gerefereerd, wordt de referentie ingesteld op het eerste beschikbare element. Als het einde van de container is bereikt, gebeurt er niets.

```cpp
virtual bool System::Collections::Generic::IEnumerator<T>::MoveNext()=0
```


### Returnwaarde

True als er een element beschikbaar is na de oproep, false anders.
