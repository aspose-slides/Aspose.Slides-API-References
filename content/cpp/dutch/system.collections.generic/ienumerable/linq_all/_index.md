## IEnumerable::LINQ_All(std::function\<bool(T)>) methode


Bepaalt of alle elementen van een reeks aan een voorwaarde voldoen.

```cpp
bool System::Collections::Generic::IEnumerable<T>::LINQ_All(std::function<bool(T)> predicate)
```


### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| predicate | std::function\<**bool**(T)> | Een functie om elk element te testen op een voorwaarde. |

### Retourwaarde

true als elk element van de bronreeks de test in de opgegeven predicate doorstaat, of als de reeks leeg is; anders false.
