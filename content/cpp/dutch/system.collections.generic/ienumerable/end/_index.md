## IEnumerable::end() methode

Haalt een iterator op die direct na het laatste element (indien aanwezig) van de collectie wijst. Deze iterator kan niet worden gebruikt om een verwezen object te wijzigen omdat [GetEnumerator()](../getenumerator/) een kopie-object van T retourneert.

```cpp
iterator System::Collections::Generic::IEnumerable<T>::end()
```

### Retourwaarde

Een iterator die direct na het laatste element (indien aanwezig) van de collectie wijst
