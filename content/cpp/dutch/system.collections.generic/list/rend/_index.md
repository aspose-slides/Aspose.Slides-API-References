## List::rend() methode


Haalt een omgekeerde iterator op voor een niet-bestaand element vóór het begin van de collectie.

```cpp
reverse_iterator System::Collections::Generic::List<T>::rend() noexcept
```


### Retourwaarde

Een omgekeerde iterator die wijst naar het theoretische element dat voorafgaand aan het eerste element in de lijst (laatste in omgekeerde volgorde).
