## DefaultComparer klasse

Standaard vergelijkingsklasse. Gebruikt operator < en operator == om waarden te vergelijken. Objecten van deze klasse mogen alleen worden gealloceerd met de [System::MakeObject()](../../system/makeobject/)-functie. Maak nooit een exemplaar van dit type op de stack of met operator new, omdat dit runtime-fouten en/of assertiefouten oplevert. Wikkel deze klasse altijd in een [System::SmartPtr](../../system/smartptr/)-pointer en gebruik deze pointer om deze als argument aan functies door te geven.

```cpp
template<class T,typename>class DefaultComparer : public System::Collections::Generic::IComparer<T>
```
