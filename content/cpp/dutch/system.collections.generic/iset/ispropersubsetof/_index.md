## ISet::IsProperSubsetOf(IEnumerablePtr) methode

Controleert of de huidige set een echte deelverzameling is van de andere container.

```cpp
virtual bool System::Collections::Generic::ISet<T>::IsProperSubsetOf(IEnumerablePtr other)=0
```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| other | [IEnumerablePtr](../ienumerableptr/) | Superset om tegen te controleren. |

### Retourwaarde

True als alle elementen in de huidige set aanwezig zijn in **other** en **other** meer elementen heeft dan de huidige set, false anders.
