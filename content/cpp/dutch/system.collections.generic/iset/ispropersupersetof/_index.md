## ISet::IsProperSupersetOf(IEnumerablePtr) methode


Controleert of de huidige set een strikte superset is van de andere container.

```cpp
virtual bool System::Collections::Generic::ISet<T>::IsProperSupersetOf(IEnumerablePtr other)=0
```


### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| other | [IEnumerablePtr](../ienumerableptr/) | Subset om tegen te controleren. |

### Retourwaarde

True als alle elementen in **other** aanwezig zijn in de set en de set meer elementen heeft dan **other**, false anders.
