## SortedList::rend() methode

Haalt een reverse-iterator op voor een niet-bestaand element vóór het begin van de collectie.

```cpp
reverse_iterator System::Collections::Generic::SortedList<TKey, TValue>::rend() noexcept
```

### Returnwaarde

Een reverse-iterator die wijst naar het theoretische element dat voorafgaat aan het eerste element in de map (laatste in reverse).
