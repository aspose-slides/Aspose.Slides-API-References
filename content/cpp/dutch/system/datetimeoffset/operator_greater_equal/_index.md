## DateTimeOffset::operator>=(const DateTimeOffset\&) const methode


Bepaalt of het huidige object de datum- en tijdwaarde vertegenwoordigt die later is dan of gelijk is aan de waarde die wordt vertegenwoordigd door het opgegeven [DateTimeOffset](../) object.

```cpp
bool System::DateTimeOffset::operator>=(const DateTimeOffset &other) const
```


### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| other | const [DateTimeOffset](../)\& | Het [DateTimeOffset](../) object om het huidige object mee te vergelijken |

### Retourwaarde

True als de datum- en tijdwaarde die wordt vertegenwoordigd door het huidige object later is dan of gelijk is aan de waarde die wordt vertegenwoordigd door **other**, anders - false
