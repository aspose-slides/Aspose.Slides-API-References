## Environment::get_Version() methode

Retourneert het [Version](../../version/) object dat de informatie over de versie van de common language runtime vertegenwoordigt. Het versienummer dat door deze methode wordt geretourneerd is echter een dummy en betekent niet dat alle bibliotheekklassen zich conformeren aan de geretourneerde versie.
