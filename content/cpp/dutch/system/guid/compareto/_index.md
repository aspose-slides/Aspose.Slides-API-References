## Guid::CompareTo(const Guid&) const methode


Voert een rekenkundige vergelijking uit van de GUID's die worden weergegeven door het huidige en het opgegeven object.

```cpp
int System::Guid::CompareTo(const Guid &g) const
```


### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| g | const [Guid](../)\& | De te vergelijken waarde |

### Retourwaarde

- 1 als de GUID die door het huidige object wordt voorgesteld kleiner is dan de GUID die door **g** wordt voorgesteld; 0 als de GUID's gelijk zijn; 1 als de GUID die door het huidige object wordt voorgesteld groter is dan de GUID die door **g** wordt voorgesteld
