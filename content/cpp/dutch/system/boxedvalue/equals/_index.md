## BoxedValue::Equals(ptr) methode


Bepaalt de gelijkheid van de verpakte waarden die worden vertegenwoordigd door het huidige en het opgegeven object.

```cpp
bool System::BoxedValue<T>::Equals(ptr obj) override
```


### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| obj | [ptr](../../object/ptr/) | Het object dat de verpakte waarde vertegenwoordigt die moet worden vergeleken met de verpakte waarde die wordt vertegenwoordigd door het huidige object |

## Retourwaarde

true als de verpakte waarde die wordt vertegenwoordigd door het huidige object en **obj** gelijk zijn, anders - false
