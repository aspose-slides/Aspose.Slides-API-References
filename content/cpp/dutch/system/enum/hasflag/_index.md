## Enum::HasFlag(E, E) methode


Bepaalt of de gespecificeerde bits zijn ingesteld in een bitwise-representatie van de opgegeven enum-waarde.

```cpp
static bool System::Enum<E, Guard>::HasFlag(E value, E mask)
```


### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| value | E | De enum-waarde om te testen |
| mask | E | Het masker om de bits van value te controleren |

### Retourwaarde

True als bits die zijn ingesteld in **mask** ook zijn ingesteld in **value**, anders - false
