## TypeInfo::GetCustomAttribute(const TypeInfo\&) const methode

Zoekt naar het aangepaste attribuut dat van het opgegeven type is en toegepast op het type dat wordt vertegenwoordigd door het huidige object.

```cpp
ObjectPtr System::TypeInfo::GetCustomAttribute(const TypeInfo &attributeType) const
```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| attributeType | const [TypeInfo](../)\& | De constante referentie naar het [TypeInfo](../) object dat het type van het te zoeken attribuut vertegenwoordigt |

### Retourwaarde

Een pointer naar een object dat het gevonden attribuut vertegenwoordigt, of een null-pointer als er geen attribuut werd gevonden dat voldoet aan de zoekcriteria
