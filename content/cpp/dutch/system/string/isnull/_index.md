## String::IsNull() const methode

Controleert of string als null wordt beschouwd. [String](../) is null en alleen als het wordt geconstrueerd via [String()](../string/) constructor, verplaatst, gekopieerd of toegewezen van een null string of [reset()](../reset/) methode werd aangeroepen.

```cpp
bool System::String::IsNull() const
```

### Retourwaarde

true als string als null wordt beschouwd, false anders.
