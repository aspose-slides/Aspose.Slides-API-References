```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| strA | const [String](../)\& | Eerste string om te vergelijken. |
| strB | const [String](../)\& | Tweede string om te vergelijken. |

### Retourwaarde
