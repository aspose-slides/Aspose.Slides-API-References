## String::end() const methode

Retourneert pointer naar het einde van de actuele stringbuffer. Heralloceert nooit iets. Garandeert niet dat de buffer null-terminated is.

```cpp
const UChar * System::String::end() const
```

### Returnwaarde

Pointer naar het eerste element na de actuele stringbuffer, null-terminated of niet.
