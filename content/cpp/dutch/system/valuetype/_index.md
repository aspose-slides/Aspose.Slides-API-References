## ValueType klasse

Baseclass voor waardetypen met [Object](../object/) overerving die om prestatie redenen wordt ingekort. Dit type moet op de stack worden gealloceerd en aan functies worden doorgegeven per waarde of per referentie. Gebruik nooit de [System::SmartPtr](../smartptr/) klasse om objecten van dit type te beheren.

```cpp
class ValueType
```
