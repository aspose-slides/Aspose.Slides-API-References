## DateTime::operator<=(DateTime) const methode

Bepaalt of het huidige object de datum- en tijdwaarde vertegenwoordigt die eerder is dan of gelijk is aan de waarde die wordt vertegenwoordigd door het opgegeven [DateTime](../)-object.

```cpp
constexpr bool System::DateTime::operator<=(DateTime other) const
```

### Argumenten

| Parameter | Type | Description |
| --- | --- | --- |
| other | [DateTime](../) | Het [DateTime](../)-object om het huidige object mee te vergelijken |

### Retourwaarde

True als de datum- en tijdwaarde die door het huidige object wordt vertegenwoordigd eerder is dan of gelijk is aan de waarde die wordt vertegenwoordigd door **other**, anders - false
