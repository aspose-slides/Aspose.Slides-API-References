## DateTime::FromBinary(int64_t) methode

Deserialiseert de datum-tijdwaarde van de opgegeven ongetekende 64-bits integer en stelt een nieuwe [DateTime](../) klasse in op die waarde.

```cpp
static DateTime System::DateTime::FromBinary(int64_t value)
```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| value | **int64_t** | De 64-bits integer om de datum-tijdwaarde van te deserialiseren |

### Retourwaarde

Een nieuwe instantie van [DateTime](../) klasse die de datum-tijdwaarde vertegenwoordigt die is gedeserialiseerd van de opgegeven ongetekende 64-bits integerwaarde
