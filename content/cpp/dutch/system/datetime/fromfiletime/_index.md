## DateTime::FromFileTime(int64_t) methode

Converteert de opgegeven File time naar een instantie van de [DateTime](../)-klasse die dezelfde datum- en tijdwaarde als lokale tijd vertegenwoordigt.

```cpp
static DateTime System::DateTime::FromFileTime(int64_t value)
```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| value | **int64_t** | File time om te converteren |

### Retourwaarde

Een nieuwe instantie van de [DateTime](../)-klasse die dezelfde datum en tijd vertegenwoordigt als **file_time**
