## DateTime::SpecifyKind(DateTime, DateTimeKind) methode

Construeert een nieuw [DateTime](../) object dat hetzelfde aantal ticks weergeeft als het opgegeven [DateTime](../) object en lokale tijd, UTC-tijd of geen van beide weergeeft zoals gespecificeerd door het argument **kind**.

```cpp
static DateTime System::DateTime::SpecifyKind(DateTime value, DateTimeKind kind)
```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| value | [DateTime](../) | Het [DateTime](../) object waarvan het aantal ticks gekopieerd moet worden |
| kind | [DateTimeKind](../../datetimekind/) | Specificeert of het nieuwe object lokale tijd, UTC-tijd of geen van beide moet weergeven. |

### Retourwaarde

Een nieuw [DateTime](../) object dat hetzelfde aantal ticks weergeeft als **value** en de DateTimeKind-waarde die gespecificeerd is door **kind**.
