## DateTime::Compare(DateTime, DateTime) methode

Vergelijkt twee waarden die worden weergegeven door de opgegeven instanties van de [DateTime](../) klasse en retourneert de waarde die de relatieve positie van de waarden op de tijdlijn aangeeft.

```cpp
static constexpr int System::DateTime::Compare(DateTime t1, DateTime t2)
```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| t1 | [DateTime](../) | De eerste te vergelijken |
| t2 | [DateTime](../) | De tweede te vergelijken |

### Retourwaarde

Een waarde die kleiner is dan 0 als **t1** eerder is dan **t2**; 0 als **t1** gelijk is aan **t2**; een waarde die groter is dan 0 als **t1** later is dan **t2**
