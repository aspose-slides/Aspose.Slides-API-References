## DateTime::operator<(DateTime) const methode


Bepaalt of het huidige object de datum- en tijdwaarde vertegenwoordigt die eerder is dan de waarde die wordt weergegeven door het gespecificeerde [DateTime](../) object.

```cpp
constexpr bool System::DateTime::operator<(DateTime other) const
```


### Argumenten

| Parameter | Type | Description |
| --- | --- | --- |
| other | [DateTime](../) | Het [DateTime](../) object om het huidige object mee te vergelijken |

### Retourwaarde

True als de datum- en tijdwaarde die wordt weergegeven door het huidige object eerder is dan de waarde die wordt weergegeven door **other**, anders - false
