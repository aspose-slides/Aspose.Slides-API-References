Bepaalt of het huidige object de datum- en tijdwaarde vertegenwoordigt die later is dan of gelijk aan de waarde die wordt vertegenwoordigd door het opgegeven [DateTime](../) object.

```cpp
constexpr bool System::DateTime::operator>=(DateTime other) const
```


### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| other | [DateTime](../) | Het [DateTime](../) object om het huidige object mee te vergelijken |

### Retourwaarde

True als de datum- en tijdwaarde die wordt vertegenwoordigd door het huidige object later is dan of gelijk aan de waarde die wordt vertegenwoordigd door **other**, anders - false
