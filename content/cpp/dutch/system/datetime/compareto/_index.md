## DateTime::CompareTo(DateTime) const methode


Vergelijkt twee datum- en tijdwaarden die worden gerepresenteerd door het huidige object en de opgegeven instantie van de [DateTime](../)-klasse en retourneert de waarde die de relatieve posities van de waarden op de tijdlijn aangeeft.

```cpp
constexpr int System::DateTime::CompareTo(DateTime value) const
```


### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| value | [DateTime](../) | Een instantie van de [DateTime](../)-klasse om het huidige object mee te vergelijken |

### Retourwaarde

Een waarde die kleiner is dan 0 als het huidige object een waarde vertegenwoordigt die eerder ligt dan die die wordt vertegenwoordigd door **value**; 0 als de door beide objecten vertegenwoordigde waarden gelijk zijn; een waarde die groter is dan 0 als de door het huidige object vertegenwoordigde waarde later ligt dan die die wordt vertegenwoordigd door **value**.
