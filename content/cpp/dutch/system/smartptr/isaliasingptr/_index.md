## SmartPtr::IsAliasingPtr() const methode

Controleert of de pointer naar een ander object wijst dan het eigendom (gemaakt door een aliasing constructor).

```cpp
bool System::SmartPtr<T>::IsAliasingPtr() const
```

### Retourwaarde

True als pointer een verschil heeft tussen het aangewezen en het eigen object, false anders.
