## SmartPtr::RemoveAliasing() const methode

Verwijdert aliasing (gecreëerd door een aliasing-constructor) van de pointer, zorgt ervoor dat hij (indien gedeeld) beheert of (indien zwak) bijhoudt naar hetzelfde object waarnaar hij wijst.

```cpp
SmartPtr_ System::SmartPtr<T>::RemoveAliasing() const
```

### Returnwaarde

De pointer naar hetzelfde object waar deze pointer naar wijst en die de levensduur van hetzelfde object bewaakt.
