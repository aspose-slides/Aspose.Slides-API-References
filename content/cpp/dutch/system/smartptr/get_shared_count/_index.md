## SmartPtr::get_shared_count() const methode


Haalt het aantal gedeelde pointers op dat bestaat voor het verwezen object, inclusief de huidige. Stelt dat de huidige pointer zich in gedeelde modus bevindt.

```cpp
int System::SmartPtr<T>::get_shared_count() const
```


### Retourwaarde

Aantal gedeelde pointers dat bestaat voor het verwezen object, indien aanwezig. Als de pointer null is, wordt 0 geretourneerd.
