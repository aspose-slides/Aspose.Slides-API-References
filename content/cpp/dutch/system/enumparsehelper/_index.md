Helper klasse die functionaliteit biedt voor het converteren van een tekenreeksrepresentatie van een enum-constante naar de overeenkomstige enum-waarde.

```cpp
template<class E,class G,class Guard>class EnumParseHelper
```

### Sjabloonparameters

| Parameter | Beschrijving |
| --- | --- |
| E | Het type van de enum waarmee de methoden van de klasse opereren |
| G | Tweede formele argument van [System::Enum](../enum/) om te gebruiken. |
| Guard | Formeel sjabloonargument om het beschikbare parseeralgoritme te selecteren. |
