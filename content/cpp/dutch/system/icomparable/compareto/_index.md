## IComparable::CompareTo(T) methode

Vergelijkt het huidige object met het opgegeven object.

```cpp
virtual int System::IComparable<T>::CompareTo(T other)=0
```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| other | T | Het object om te vergelijken met het huidige object |

### Retourwaarde

Een negatief getal als het huidige object vóór het opgegeven object komt in de sorteervolgorde; 0 als de vergeleken objecten gelijk zijn; een positief getal als het huidige object na het opgegeven object komt in de sorteervolgorde
