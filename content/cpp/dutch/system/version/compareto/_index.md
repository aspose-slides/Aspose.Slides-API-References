## Version::CompareTo(const Version\&) const methode

Vergelijkt de versies die door het huidige object en het opgegeven object worden vertegenwoordigd.

```cpp
int System::Version::CompareTo(const Version &ver) const
```


### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| ver | const [Version](../)\& | Een [Version](../) object om te vergelijken met het huidige object |

### Retourwaarde

- 1 als het versienummer dat door het huidige object wordt vertegenwoordigd kleiner is dan dat van **ver**; 0 als de versienummers gelijk zijn; 1 als het versienummer dat door het huidige object wordt vertegenwoordigd groter is dan de waarde die **ver** vertegenwoordigt
