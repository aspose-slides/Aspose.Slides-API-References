## Char::IsWhiteSpace(const char_t *, int) methode


Bepaalt of het teken op de opgegeven index in de opgegeven tekenbuffer wordt geclassificeerd als een witruimteteken.

```cpp
static bool System::Char::IsWhiteSpace(const char_t *str, int idx)
```


### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| str | const char_t * | Pointer naar het begin van de tekenbuffer |
| idx | int | Een index beginnend bij nul in de opgegeven buffer van het te testen teken |

### Retourwaarde

True als het teken op de opgegeven index een witruimteteken is, anders - false
