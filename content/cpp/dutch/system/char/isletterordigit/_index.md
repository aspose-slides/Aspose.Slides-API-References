## Char::IsLetterOrDigit(const char_t *, int) methode

Bepaalt of het teken op de opgegeven index in de opgegeven tekenbuffer is geclassificeerd als een Unicode-letter of een decimale cijfer.

```cpp
static bool System::Char::IsLetterOrDigit(const char_t *str, int idx)
```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| str | const char_t * | Pointer naar het begin van de tekenbuffer |
| idx | int | Nulgebaseerde index in de opgegeven buffer van het te testen teken |

### Retourwaarde

True als het teken op de opgegeven index een Unicode-letter of een decimale cijfer is, anders - false
