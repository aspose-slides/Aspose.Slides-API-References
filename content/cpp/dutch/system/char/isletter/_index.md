## Char::IsLetter(const char_t *, int) methode

Bepaalt of het teken op de opgegeven index in de opgegeven tekenbuffer is geclassificeerd als Unicode-letter.

```cpp
static bool System::Char::IsLetter(const char_t *str, int idx)
```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| str | const char_t * | Pointer naar het begin van de tekenbuffer |
| idx | int | Een index vanaf nul in de opgegeven buffer van het te testen teken |

### Retourwaarde

True als het teken op de opgegeven index een Unicode-letter is, anders - false
