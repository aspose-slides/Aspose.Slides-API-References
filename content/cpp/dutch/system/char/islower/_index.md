## Char::IsLower(const char_t *, int) methode


Bepaalt of het teken op de opgegeven index in de opgegeven tekenbuffer is geclassificeerd als een kleine letter.

```cpp
static bool System::Char::IsLower(const char_t *str, int idx)
```


### Argumenten

| Parameter | Type | Description |
| --- | --- | --- |
| str | const char_t * | Pointer naar het begin van de tekenbuffer |
| idx | int | Een nul-gebaseerde index in de opgegeven buffer van het te testen teken |

### Retourwaarde

True als het teken op de opgegeven index een kleine letter is, anders - false
