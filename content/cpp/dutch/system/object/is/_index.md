## Object::Is(const TypeInfo\&) const methode

Controleer of het object een instantie vertegenwoordigt van het type beschreven door targetType. Analogie van de C# 'is' operator.

```cpp
virtual bool System::Object::Is(const TypeInfo &targetType) const
```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| targetType | const [TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) structuur die het type beschrijft dat gebruikt wordt om het huidige object te testen. |

### Retourwaarde

True als het object van het gemarkeerde type of een subklasse daarvan is, false anders.
