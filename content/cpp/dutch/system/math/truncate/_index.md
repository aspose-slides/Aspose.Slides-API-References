## Math::Truncate(const Decimal\&) methode


Retourneert het [Decimal](../../decimal/) object dat een waarde vertegenwoordigt waarvan het gehele gedeelte gelijk is aan dat van de waarde die wordt weergegeven door het opgegeven [Decimal](../../decimal/) object, met alle fractionele cijfers verwijderd.

```cpp
static Decimal System::Math::Truncate(const Decimal &d)
```


### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| d | const [Decimal](../../decimal/)\& | Een decimaal getal |

### Retourwaarde

Een [Decimal](../../decimal/) object dat een decimale waarde vertegenwoordigt waarvan het gehele gedeelte gelijk is aan dat van de opgegeven waarde en de fractionele cijfers allemaal 0 zijn.

Retourneert een double-precisie floating-pointwaarde waarvan het gehele gedeelte gelijk is aan dat van de opgegeven waarde, met alle fractionele cijfers verwijderd.



### Argumenten

### Retourwaarde
