## Boolean::TryParse(const String\&, bool\&) method

Converteert de opgegeven string naar een waarde van het type bool.

```cpp
static bool System::Boolean::TryParse(const String &value, bool &result)
```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| value | const [String](../../string/)\& | De te converteren string. |
| result | **bool**\& | De referentie naar een bool-variabele waarin het resultaat van de conversie wordt geplaatst; het resultaat is true als de opgegeven string gelijk is aan \"True\" en false als de opgegeven string gelijk is aan \"False\". |

### Retourwaarde

True als de opgegeven string gelijk is aan \"True\" of \"False\", anders - false.
