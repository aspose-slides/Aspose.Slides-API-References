

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| obj | [ptr](../../object/ptr/) | Het object dat de ingepakte waarde vertegenwoordigt die moet worden vergeleken met de ingepakte waarde die wordt weergegeven door het huidige object |
