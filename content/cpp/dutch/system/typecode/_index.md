## TypeCode enum

Stelt het type van een object voor.

```cpp
enum class TypeCode
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Empty | 0 | Een null-referentie. |
| Object | 1 | Een algemeen type dat elke referentie- of waardetype vertegenwoordigt die niet expliciet wordt weergegeven door een ander TypeCode. |
| DBNull | 2 | Een database-null (kolom) waarde. |
| Boolean | 3 | Een eenvoudig type dat [Boolean](../boolean/) waarden van true of false vertegenwoordigt. |
| Char | 4 | Een integraal type dat ongeondertekende 16-bit gehele getallen met waarden tussen 0 en 65535 vertegenwoordigt. |
| SByte | 5 | Een integraal type dat ondertekende 8-bit gehele getallen met waarden tussen -128 en 127 vertegenwoordigt. |
| Byte | 6 | Een integraal type dat ongeondertekende 8-bit gehele getallen met waarden tussen 0 en 255 vertegenwoordigt. |
| Int16 | 7 | Een integraal type dat ondertekende 16-bit gehele getallen met waarden tussen -32768 en 32767 vertegenwoordigt. |
| UInt16 | 8 | Een integraal type dat ongeondertekende 16-bit gehele getallen met waarden tussen 0 en 65535 vertegenwoordigt. |
| Int32 | 9 | Een integraal type dat ondertekende 32-bit gehele getallen met waarden tussen -2147483648 en 2147483647 vertegenwoordigt. |
| UInt32 | 10 | Een integraal type dat ongeondertekende 32-bit gehele getallen met waarden tussen 0 en 4294967295 vertegenwoordigt. |
| Int64 | 11 | Een integraal type dat ondertekende 64-bit gehele getallen met waarden tussen -9223372036854775808 en 9223372036854775807 vertegenwoordigt. |
| UInt64 | 12 | Een integraal type dat ongeondertekende 64-bit gehele getallen met waarden tussen 0 en 18446744073709551615 vertegenwoordigt. |
| Single | 13 | Een zwevend-kommapunttype dat waarden van ongeveer 1,5 × 10 -45 tot 3,4 × 10 38 vertegenwoordigt met een precisie van 7 cijfers. |
| Double | 14 | Een zwevend-kommapunttype dat waarden van ongeveer 5,0 × 10 -324 tot 1,7 × 10 308 vertegenwoordigt met een precisie van 15-16 cijfers. |
| Decimal | 15 | Een eenvoudig type dat waarden van 1,0 × 10 -28 tot ongeveer 7,9 × 10 28 vertegenwoordigt met 28-29 significante cijfers. |
| DateTime | 16 | Een type dat een datum- en tijdwaarde vertegenwoordigt. |
| String | 18 | Een sealed-klasse type dat Unicode-tekenreeksen vertegenwoordigt. |
