## System::CheckedCast(TFrom) functie

Bepaalt of de opgegeven waarde binnen het bereik van waarden van type **TTo** valt en, indien ja, cast deze naar het type **TTo**.

```cpp
template<typename TTo,typename TFrom> TTo System::CheckedCast(TFrom value)
```

### Sjabloonparameters

| Parameter | Beschrijving |
| --- | --- |
| TTo | Het type waarnaar de opgegeven waarde moet worden gecast |
| TFrom | Het type van de opgegeven waarde |

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| value | TFrom | De te casten waarde |

### Retourwaarde

De waarde van type **TTo** die gelijk is aan **value**
