## Decimal::operator<(const Decimal\&) const methode

Bepaalt of de waarde die door het huidige object wordt vertegenwoordigd kleiner is dan de waarde die door het opgegeven object wordt vertegenwoordigd.

```cpp
bool System::Decimal::operator<(const Decimal &d) const
```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| d | const [Decimal](../)\& | Het [Decimal](../) object om het huidige object mee te vergelijken |

### Retourwaarde

True if the value represented by the current object is less than the value represented by **d**, otherwise - false
