## Decimal::Compare(const Decimal\&, const Decimal\&) methode


Bepaalt of de waarde die door het eerste [Decimal](../) object wordt gerepresenteerd kleiner is dan, gelijk aan of groter dan de waarde die door het tweede [Decimal](../) object wordt gerepresenteerd.

```cpp
static int System::Decimal::Compare(const Decimal &d1, const Decimal &d2)
```


### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| d1 | const [Decimal](../)\& | Het eerste vergelijkingsobject |
| d2 | const [Decimal](../)\& | Het tweede vergelijkingsobject |

### Retourwaarde

- 1 als de door **d1** gerepresenteerde waarde kleiner is dan de door **d2** gerepresenteerde waarde; 0 als de waarden gelijk zijn; 1 als de door **d1** gerepresenteerde waarde groter is dan de door **d2** gerepresenteerde waarde
