## Nullable::GetValueOrDefault(T) methode

Retourneert de waarde die wordt vertegenwoordigd door het huidige object of de opgegeven waarde als de waarde die wordt vertegenwoordigd door het huidige object null is.

```cpp
T System::Nullable<T>::GetValueOrDefault(T default_value)
```

### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| default_value | T | De waarde die wordt geretourneerd door de methode als de waarde die wordt vertegenwoordigd door het huidige object null is |

### Retourwaarde

Een kopie van de waarde die wordt vertegenwoordigd door het huidige object wordt geretourneerd als deze niet null is; anders wordt de opgegeven waarde geretourneerd
