## Array::crend() const methode

Retourneert een reverse iterator naar het element dat volgt op het laatste element van de omgekeerde container. Het komt overeen met het element dat voorafgaat aan het eerste element van de niet-omgekeerde container. Dit element fungeert als een tijdelijke aanduiding; proberen er toegang toe te krijgen resulteert in ongedefinieerd gedrag.

```cpp
const_reverse_iterator System::Array<T>::crend() const noexcept
```

### Returnwaarde

Een iterator die wijst naar het theoretische const-gekwalificeerde element dat voorafgaat aan het eerste element van de container.
