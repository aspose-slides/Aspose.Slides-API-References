## Array::begin() methode


Retourneert een iterator naar het eerste element van de container. Als de container leeg is, zal de geretourneerde iterator gelijk zijn aan [end()](../end/).

```cpp
iterator System::Array<T>::begin() noexcept
```


### Retourwaarde

Een iterator die naar het eerste element van de container wijst.

## Array::begin() const methode


Retourneert een iterator naar het eerste element van de const-gekwalificeerde container. Als de container leeg is, zal de geretourneerde iterator gelijk zijn aan [end()](../end/).

```cpp
const_iterator System::Array<T>::begin() const noexcept
```


### Retourwaarde

Een iterator die naar het eerste element van de const-gekwalificeerde container wijst.
