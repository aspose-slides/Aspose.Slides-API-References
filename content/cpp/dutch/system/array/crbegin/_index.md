## Array::crbegin() const methode


Geeft een reverse-iterator terug naar het eerste element van de omgekeerde container. Het komt overeen met het laatste element van de niet-omgekeerde container. Als de container leeg is, is de geretourneerde iterator gelijk aan [crend()](../crend/).

```cpp
const_reverse_iterator System::Array<T>::crbegin() const noexcept
```


### Returnwaarde

Een iterator die verwijst naar het laatste const-gekwalificeerde element van de container.
