## Array::cbegin() const methode

Retourneert een iterator naar het eerste const-kwalificeerde element van de container. Als de container leeg is, zal de geretourneerde iterator gelijk zijn aan [cend()](../cend/).

```cpp
const_iterator System::Array<T>::cbegin() const noexcept
```

### Retourwaarde

Een iterator die wijst naar het eerste const-kwalificeerde element van de container.
