## Array::cend() const method


Retourneert een iterator naar het element dat volgt op het laatste element van de container. Dit element fungeert als een tijdelijke aanduiding; proberen er toegang toe te krijgen resulteert in ongedefinieerd gedrag.

```cpp
const_iterator System::Array<T>::cend() const noexcept
```


### Retourwaarde

Een iterator die wijst naar het theoretisch const-gekwalificeerde element dat na het laatste element van de container geplaatst is.
