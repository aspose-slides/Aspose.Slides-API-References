## Array::rend() methode

Retourneert een reverse-iterator naar het element dat volgt op het laatste element van de omgekeerde container. Het correspondeert met het element dat voorafgaat aan het eerste element van de niet-omgekeerde container. Dit element fungeert als een placeholder; proberen er toegang toe te krijgen leidt tot ongedefinieerd gedrag.

```cpp
reverse_iterator System::Array<T>::rend() noexcept
```

### Returnwaarde

Een iterator die wijst naar het theoretische element dat voorafgaat aan het eerste element van de container.
