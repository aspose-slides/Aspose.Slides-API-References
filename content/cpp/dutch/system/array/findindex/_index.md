## Array::FindIndex(System::ArrayPtr\<T\>, System::Predicate\<T\>) methode


### Argumenten

| Parameter | Type | Beschrijving |

| match | [System::Predicate](../../predicate/)\<T\> | Een predicate die de voorwaarden definieert om array-elementen te vergelijken |
