## Array::rbegin() methode

Retourneert een reverse-iterator naar het eerste element van de omgekeerde container. Het komt overeen met het laatste element van de niet-omgekeerde container. Als de container leeg is, is de geretourneerde iterator gelijk aan [rend()](../rend/).

```cpp
reverse_iterator System::Array<T>::rbegin() noexcept
```

### Retourwaarde

Een iterator die wijst naar het laatste element van de container.

## Array::rbegin() const methode

```cpp
const_reverse_iterator System::Array<T>::rbegin() const noexcept
```

### Retourwaarde

Een iterator die wijst naar het laatste element van de const-gekwalificeerde container.
