## EnumValuesBase::GetValues(const TypeInfo\&) methode


Retourneert een array die alle waarden van het opgegeven enumeratietype bevat.

```cpp
static ArrayPtr<int64_t> System::EnumValuesBase::GetValues(const TypeInfo &type)
```


### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| type | const [TypeInfo](../../typeinfo/)\& | Het [TypeInfo](../../typeinfo/) object dat het type van de enumeratie vertegenwoordigt waarvan de waarden moeten worden geretourneerd |

### Retourwaarde

Een array die waarden bevat van alle enumeratie-constanten van het enumeratietype dat wordt gespecificeerd door **type**.
