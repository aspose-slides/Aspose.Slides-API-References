## SoapParameterStyle enum

Somt de formaten van parameters in een SOAP-bericht op.

```cpp
enum class SoapParameterStyle
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Default | 0 | Als '[SoapDocumentServiceAttribute](../soapdocumentserviceattribute/)' niet op de klasse wordt toegepast, is de standaardwaarde 'Wrapped'. |
| Bare | 1 | De parameters worden geplaatst in XML-elementen die het 'Body'-element volgen. |
| Wrapped | 2 | De parameters worden ingekapseld binnen één XML-element dat het 'Body'-element volgt. |
