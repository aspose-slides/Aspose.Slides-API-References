## SoapServiceRoutingStyle enum

Enumerates options of how a SOAP message is routed to the XML [Web](../../system.web/) service.

```cpp
enum class SoapServiceRoutingStyle
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| SoapAction | 0 | Het SOAP-bericht wordt gerouteerd op basis van het 'SOAPAction'-attribuut. |
| RequestElement | 1 | Het SOAP-bericht wordt gerouteerd op basis van het eerste onderliggende element na het 'Body'-element. |
