## SocketType enum

Enumereert de sockettypen.

```cpp
enum class SocketType
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Stream | 1 | Het type dat betrouwbare, tweeweg, op verbinding gebaseerde byte stromen ondersteunt zonder duplicatie van gegevens en zonder behoud van grenzen. |
| Dgram | 2 | Het type dat datagrammen ondersteunt, die verbindingloos, onbetrouwbaar zijn en een vaste maximale lengte hebben. |
| Raw | 3 | Het type dat toegang biedt tot het onderliggende transportprotocol. |
| Rdm | 4 | Het type dat verbindingloze, berichtgeoriënteerde, betrouwbaar afgeleverde berichten ondersteunt en berichtgrenzen in gegevens behoudt. |
| Seqpacket | 5 | Het type dat verbindinggeoriënteerde en betrouwbare tweeweg overdracht van geordende byte stromen over een netwerk biedt. |
| Unknown | n/a | Een onbekend type. |
