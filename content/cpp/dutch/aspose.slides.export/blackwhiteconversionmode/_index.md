## BlackWhiteConversionMode enum

Biedt opties die bepalen hoe afbeeldingen van dia's worden geconverteerd naar bi-tonale afbeeldingen.

```cpp
enum class BlackWhiteConversionMode
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Default | 0 | Specificeert geen converteeralgoritme. Het algoritme geïmplementeerd in de TIFF-codec wordt gebruikt. (Default) |
| Dithering | 1 | Specificeert het ditheringsalgoritme (Floyd-Steinberg). |
| DitheringFloydSteinberg | 2 | Specificeert het Floyd-Steinberg-ditheringsalgoritme. |
| Auto | 3 | Specificeert het automatisch berekende drempelsalgoritme (Otsu). |
| AutoOtsu | 4 | Specificeert het automatisch berekende Otsu-drempelsalgoritme. |
| Threshold25 | 5 | Specificeert het statische drempelsalgoritme (25%). |
| Threshold50 | 6 | Specificeert het statische drempelsalgoritme (50%). |
| Threshold75 | 7 | Specificeert het statische drempelsalgoritme (75%). |
