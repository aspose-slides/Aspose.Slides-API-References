## SvgEvent enum

Stelt opties voor SVG-vorm voor.

```cpp
enum class SvgEvent
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| OnFocusIn | 0 | Vindt plaats wanneer een element focus ontvangt, bijvoorbeeld wanneer een tekst geselecteerd wordt. |
| OnFocusOut | 1 | Vindt plaats wanneer een element focus verliest, bijvoorbeeld wanneer een tekst gedeselecteerd wordt. |
| OnActivate | 2 | Vindt plaats wanneer een element geactiveerd wordt, bijvoorbeeld door een muisklik of een toetsaanslag. |
| OnClick | 3 | Vindt plaats wanneer de knop van het aanwijzerapparaat wordt aangeklikt boven een element. |
| OnMouseDown | 4 | Vindt plaats wanneer de knop van het aanwijzerapparaat wordt ingedrukt boven een element. |
| OnMouseUp | 5 | Vindt plaats wanneer de knop van het aanwijzerapparaat wordt losgelaten boven een element. |
| OnMouseOver | 6 | Vindt plaats wanneer het aanwijzerapparaat zich naar een element beweegt. |
| OnMouseMove | 7 | Vindt plaats wanneer het aanwijzerapparaat wordt bewogen terwijl het zich boven een element bevindt. |
| OnMouseOut | 8 | Vindt plaats wanneer het aanwijzerapparaat zich van een element verwijdert. |
| OnLoad | 9 | Vindt plaats wanneer de user agent het element en zijn afstammelingen en alle verwezen bronnen volledig heeft geparseerd, die nodig zijn om het weer te geven. |
| OnUnload | 10 | Vindt plaats wanneer de [DOM](../../aspose.slides.dom/)-implementatie een document uit een venster of frame verwijdert. Alleen van toepassing op de buitenste svg-elementen. |
| OnAbort | 11 | Vindt plaats wanneer het laden van de pagina wordt gestopt voordat een element volledig geladen kon worden. |
| OnError | 12 | Vindt plaats wanneer een element niet correct wordt geladen of wanneer er een fout optreedt tijdens de uitvoering van een script. |
| OnResize | 13 | Vindt plaats wanneer een documentweergave wordt geschaald. Alleen van toepassing op de buitenste svg-elementen. |
| OnScroll | 14 | Vindt plaats wanneer een documentweergave wordt verschoven langs de X- of Y-as of beide. Alleen van toepassing op de buitenste svg-elementen. |
| OnZoom | 15 | Vindt plaats wanneer het zoomniveau van een documentweergave wordt gewijzigd. Alleen van toepassing op de buitenste svg-elementen. |
| OnBegin | 16 | Vindt plaats wanneer een animatie-element begint. |
| OnEnd | 17 | Vindt plaats wanneer een animatie-element eindigt. |
| OnRepeat | 18 | Vindt plaats wanneer een animatie-element wordt herhaald. |
