## NotesPositions enum

Geeft de regel weer voor het renderen van notities in een geëxporteerd document

```cpp
enum class NotesPositions
```

### Values

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| None | 0 | Specificeert dat notities helemaal niet worden weergegeven. |
| BottomFull | 1 | Specificeert dat notities volledig worden weergegeven met behulp van extra pagina's indien nodig. |
| BottomTruncated | 2 | Specificeert dat notities op slechts één pagina worden weergegeven. |
