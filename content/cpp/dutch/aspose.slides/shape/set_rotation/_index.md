## Shape::set_Rotation(float) methode

Stelt het aantal graden in waarmee de opgegeven vorm rond de z-as wordt gedraaid. Een positieve waarde geeft een klokwijzerrotatie aan; een negatieve waarde geeft een tegenklokrotatie aan. Schrijf **float**.

```cpp
void Aspose::Slides::Shape::set_Rotation(float value) override
```

## Opmerkingen

Geretourneerde waarde is altijd gedefinieerd (is niet std::numeric_limits<float>::quiet_NaN()). Toegewezen waarde moet gedefinieerd zijn (niet std::numeric_limits<float>::quiet_NaN()). U kunt ongedefinieerde waarden instellen voor RawFrame-instantie-eigenschappen.
