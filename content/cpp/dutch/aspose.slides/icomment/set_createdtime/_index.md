## IComment::set_CreatedTime(System::DateTime) methode

Stelt de tijd van een commentaarcreatie in. Als deze eigenschap wordt ingesteld op [DateTime::MinValue](../../../system/datetime/minvalue/), betekent dit dat er geen commentaartijd is ingesteld. Schrijf [System::DateTime](../../../system/datetime/).

```cpp
virtual void Aspose::Slides::IComment::set_CreatedTime(System::DateTime value)=0
```

## Opmerkingen

[Comment](../../comment/) tijd is een optionele parameter.
