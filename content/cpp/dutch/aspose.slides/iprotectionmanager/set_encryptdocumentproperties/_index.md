## IProtectionManager::set_EncryptDocumentProperties(bool) methode

Deze eigenschap is logisch, als de presentatie met een wachtwoord is beveiligd. Als true dan wordt documenteigenschappen versleuteld in het presentatiebestand. Als false dan zijn documenteigenschappen openbaar terwijl de presentatie versleuteld is. Schrijf **bool**.

virtual void Aspose::Slides::IProtectionManager::set_EncryptDocumentProperties(bool value)=0
