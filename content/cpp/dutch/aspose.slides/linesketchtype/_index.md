## LineSketchType enum


Representeert welk schets type of effect een shape heeft gekregen.

```cpp
enum class LineSketchType
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| NotDefined | -1 | Geeft aan dat een shape Sketch-effect niet gedefinieerd is. |
| None | 0 | Geeft aan dat een shape geen Sketch-effect heeft. Dit is gelijk aan dat deze property leeg is. |
| Curved | 1 | Geeft aan dat een shape het Curved-effect heeft, dat elke rand van de shape in één grote zachte boog verandert. |
| Freehand | 2 | Geeft aan dat een shape het Freehand-effect heeft, dat het dichtst overeenkomt met een onvolkomen getekende lijn. |
| Scribble | 3 | Geeft aan dat een shape het Scribble-effect heeft, dat een overdrijvende oscillatie heeft alsof het expres slordig is getekend. |
