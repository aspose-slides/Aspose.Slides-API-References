## ResourceLoadingAction enum

Specificeert de modus van het laden van externe bronnen.

```cpp
enum class ResourceLoadingAction
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Default | 0 | [Aspose.Slides](../) zal externe bron zoals gewoonlijk laden. |
| Skip | 1 | [Aspose.Slides](../) zal het laden van externe bronnen overslaan. Alleen een link zonder gegevens zal worden opgeslagen voor een afbeelding. |
| UserProvided | 2 | [Aspose.Slides](../) zal een byte array gebruiken die door de gebruiker in [IResourceLoadingArgs::SetData](../iresourceloadingargs/setdata/) is opgegeven als afbeeldingsgegevens. |
