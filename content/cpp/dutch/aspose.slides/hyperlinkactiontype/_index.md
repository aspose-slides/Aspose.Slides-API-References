## HyperlinkActionType enum

Stelt een type hyperlinkactie voor.

```cpp
enum class HyperlinkActionType
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Unknown | -1 | Niet-herkend actietype. |
| NoAction | 0 | Geen actie. |
| Hyperlink | 1 | Gebruikelijke hyperlink. |
| JumpFirstSlide | 2 | Ga naar de eerste dia van de presentatie. |
| JumpPreviousSlide | 3 | Ga naar de vorige dia. |
| JumpNextSlide | 4 | Ga naar de volgende dia. |
| JumpLastSlide | 5 | Ga naar de laatste dia van de presentatie. |
| JumpEndShow | 6 | Ga naar het einde van de diavoorstelling. |
| JumpLastViewedSlide | 7 | Ga naar de laatst bekeken dia. |
| JumpSpecificSlide | 8 | Ga naar de specifieke dia, aangeduid door de waarde [IHyperlink::get_TargetSlide](../ihyperlink/get_targetslide/). |
| StartCustomSlideShow | 9 | Start aangepaste diavoorstelling. |
| OpenFile | 10 | Open het verwezen bestand. |
| OpenPresentation | 11 | Open de verwezen presentatie. |
| StartStopMedia | 12 | Start/stop het afspelen van mediabestand. |
| StartMacro | 13 | Start met het uitvoeren van macroscript. |
| StartProgram | 14 | Start programma. |
