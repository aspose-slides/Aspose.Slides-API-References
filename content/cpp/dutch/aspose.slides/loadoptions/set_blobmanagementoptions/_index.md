## LoadOptions::set_BlobManagementOptions(System::SharedPtr\<IBlobManagementOptions\>) method

Stelt de opties voor die kunnen worden gebruikt om het gedrag van Binary Large Objects (BLOBs) te beheren, zoals het gebruik van tijdelijke bestanden of het maximale aantal BLOB-bytes in het geheugen. Deze opties zijn bedoeld om de beste verhouding tussen performance en geheugengebruik te realiseren voor een specifieke omgeving of vereisten.

```cpp
void Aspose::Slides::LoadOptions::set_BlobManagementOptions(System::SharedPtr<IBlobManagementOptions> value) override
```

## Opmerkingen

Een Binary Large Object (BLOB) is een binaire data opgeslagen als één entiteit - d.w.z. een BLOB kan een audio, video of de presentatie zelf zijn.
