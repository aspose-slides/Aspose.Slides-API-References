## IShape::set_Rotation(float) methode

Stelt het aantal graden in waarmee de opgegeven vorm rond de z-as wordt gedraaid. Een positieve waarde geeft een klokwijzerrotatie aan; een negatieve waarde geeft een tegenklokwijzerrotatie aan. Schrijf **float**.

```cpp
virtual void Aspose::Slides::IShape::set_Rotation(float value)=0
```

## Opmerkingen

De geretourneerde waarde is altijd gedefinieerd (is niet std::numeric_limits<float>::quiet_NaN()). De toegewezen waarde moet gedefinieerd zijn (niet std::numeric_limits<float>::quiet_NaN()). Je kunt ongedefinieerde waarden instellen voor RawFrame instantie-eigenschappen.
