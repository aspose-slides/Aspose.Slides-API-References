## IShape::get_Rotation() methode

Retourneert het aantal graden waarin de opgegeven vorm is geroteerd rond de z-as. Een positieve waarde geeft een klokwijzerige rotatie aan; een negatieve waarde geeft een tegen de klok in rotatie aan. Lees **float**.

```cpp
virtual float Aspose::Slides::IShape::get_Rotation()=0
```

## Opmerkingen


Geretourneerde waarde is altijd gedefinieerd (is niet std::numeric_limits<float>::quiet_NaN()). Toegewezen waarde moet gedefinieerd zijn (niet std::numeric_limits<float>::quiet_NaN()). U kunt ongedefinieerde waarden instellen voor RawFrame instance properties.
