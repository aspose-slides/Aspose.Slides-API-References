## Tab::CompareTo(System::SharedPtr\<ITab\>) methode


Vergelijkt de huidige instantie met een ander object van hetzelfde type.

```cpp
int32_t Aspose::Slides::Tab::CompareTo(System::SharedPtr<ITab> obj) override
```


### Argumenten

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| obj | [System::SharedPtr](../../../system/sharedptr/)\<[ITab](../../itab/)\> | Een object om te vergelijken met deze instantie. |

### Retourwaarde

Een 32-bits geheel getal dat de relatieve volgorde van de te vergelijken objecten aangeeft. De retourwaarde heeft de volgende betekenissen: * < 0 - Deze instantie is kleiner dan obj. * = 0 - Deze instantie is gelijk aan obj. * > 0 - Deze instantie is groter dan obj.
