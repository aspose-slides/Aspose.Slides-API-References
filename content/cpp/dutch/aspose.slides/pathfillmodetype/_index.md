## PathFillModeType enum

Specificeert de manier waarop een pad moet worden gevuld

```cpp
enum class PathFillModeType : uint8_t
```

### Values

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| None | 0 | Geen padvulling. Dit geeft aan dat het overeenkomstige pad geen vulling moet hebben. |
| Normal | 1 | Normale padvulling. Dit geeft aan dat het overeenkomstige pad een normaal getinte kleur op de vulling moet hebben. |
| Lighten | 2 | Verlicht padvulling. Dit geeft aan dat het overeenkomstige pad een licht getinte kleur op de vulling moet hebben. |
| LightenLess | 3 | Minder verlichte padvulling. Dit geeft aan dat het overeenkomstige pad een iets lichtere getinte kleur op de vulling moet hebben. |
| Darken | 4 | Donkere padvulling. Dit geeft aan dat het overeenkomstige pad een donkere getinte kleur op de vulling moet hebben. |
| DarkenLess | 5 | Minder donkere padvulling. Dit geeft aan dat het overeenkomstige pad een iets donkerdere getinte kleur op de vulling moet hebben. |
