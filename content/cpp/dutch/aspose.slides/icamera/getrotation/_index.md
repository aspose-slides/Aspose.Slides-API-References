## ICamera::GetRotation() methode

Een rotatie wordt gedefinieerd door het gebruik van een breedtegraadcoördinaat, een lengtegraadcoördinaat en een omwenteling rond de as als de breedte- en lengtegraadcoördinaten. eerste element in het retourarray - breedtegraad, tweede - lengtegraad, derde - omwenteling. Retourneert null als er geen rotatie is gedefinieerd.

```cpp
virtual System::ArrayPtr<float> Aspose::Slides::ICamera::GetRotation()=0
```

### Retourwaarde

Array van rotatiewaarden als **float**[].
