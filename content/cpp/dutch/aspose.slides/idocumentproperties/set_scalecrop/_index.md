## IDocumentProperties::set_ScaleCrop(bool) methode

Geeft de weergavemodus van de miniatuur van het document aan. Stel dit element in op **true** om de schaalvergroting van de documentminiatuur naar het scherm in te schakelen. Stel dit element in op **false** om bijsnijden van de documentminiatuur mogelijk te maken zodat alleen delen die op het scherm passen worden weergegeven. Schrijf **bool**.

virtual void Aspose::Slides::IDocumentProperties::set_ScaleCrop(bool value)=0
