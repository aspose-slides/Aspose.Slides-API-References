## FillType enum


Specificeert het binnenvultype van verschillende visuele objecten.

```cpp
enum class FillType : int8_t
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| NotDefined | -1 | Het vultype is niet gedefinieerd. |
| NoFill | 0 | Geen vulling toegepast. |
| Solid | 1 | Gegvuld met een effen kleur. |
| Gradient | 2 | De vulling is een verloop. |
| Pattern | 3 | Herhalend patroon wordt gebruikt om het object te vullen. |
| Picture | 4 | Een enkele afbeelding wordt gebruikt om het object te vullen. |
| Group | 5 | Het visuele object erft de vul-eigenschappen van de groep. |
