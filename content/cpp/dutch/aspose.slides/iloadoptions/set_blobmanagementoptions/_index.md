## ILoadOptions::set_BlobManagementOptions(System::SharedPtr\<IBlobManagementOptions\>) methode

Stelt de opties voor die gebruikt kunnen worden om Binary Large Objects (BLOBs) beheer-gedrag te beheren, zoals het gebruik van tijdelijke bestanden of maximale BLOB-bytes in het geheugen. Deze opties zijn bedoeld om de beste verhouding tussen prestaties en geheugengebruik in te stellen voor een bepaalde omgeving of vereisten.

```cpp
virtual void Aspose::Slides::ILoadOptions::set_BlobManagementOptions(System::SharedPtr<IBlobManagementOptions> value)=0
```

## Opmerkingen

Een Binary Large Object (BLOB) is binaire data die wordt opgeslagen als één entiteit - oftewel een BLOB kan een audio-, video- of presentatie-bestand zelf zijn.
