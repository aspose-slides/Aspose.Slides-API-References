## ITypeDescriptorContext klasse


Dummy-interface voor ITypeDescriptorContext-using code om te compileren. Objecten van deze klasse mogen alleen worden toegewezen met [System::MakeObject()](../../system/makeobject/) function. Maak nooit een instantie van dit type op de stack of met operator new, omdat dit resulteert in runtime-fouten en/of assert-fouten. Wikkel deze klasse altijd in een [System::SmartPtr](../../system/smartptr/) pointer en gebruik deze pointer om hem als argument door te geven aan functies.

```cpp
class ITypeDescriptorContext : public virtual System::Object
```
