## PropertyChangedEventArgs klasse

Argumenten van PropertyChanged-event. Objecten van deze klasse mogen alleen worden toegewezen met functie [System::MakeObject()](../../system/makeobject/). Maak nooit een instantie van dit type op de stack of met operator new, omdat dit zal leiden tot runtime-fouten en/of assertiefouten. Wikkel deze klasse altijd in een [System::SmartPtr](../../system/smartptr/)-pointer en gebruik deze pointer om deze door te geven aan functies als argument.

```cpp
class PropertyChangedEventArgs : public System::EventArgs
```
