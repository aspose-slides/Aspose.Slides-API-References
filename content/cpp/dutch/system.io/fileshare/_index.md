## FileShare enum

Specificeert welk type toegang andere [FileStream](../filestream/) objecten kunnen hebben tot een bestand dat wordt geopend.

```cpp
enum class FileShare
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| None | 0 | Geen toegang. |
| Read | 1 | Alleen-lezen toegang. |
| Write | 2 | Alleen-schrijven toegang. |
| ReadWrite | 3 | Lezen- en schrijftoegang. |
| Delete | 4 | Het bestand kan worden verwijderd. |
| Inheritable | 16 | Maakt het bestandshandvat erfenisbaar voor kindprocessen. |
