## StreamReader::Peek() methode


Leest één teken van de stream zonder de leescursor van de stream te wijzigen.

```cpp
virtual int System::IO::StreamReader::Peek() override
```


### Retourwaarde

Leest teken gecodeerd met UTF-16-codering; als het gelezen teken wordt gerepresenteerd door twee codepunten in UTF-16-codering, wordt alleen de hoge surrogaat geretourneerd; als er geen teken is gelezen, wordt -1 geretourneerd
