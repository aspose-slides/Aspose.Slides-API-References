## EncryptionPolicy enum

Somt de encryptiebeleid op.

```cpp
enum class EncryptionPolicy
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| RequireEncryption | 0 | Vereist versleuteling en staat een 'Null' cipher nooit toe. |
| AllowNoEncryption | 1 | Geeft de voorkeur aan volledige versleuteling, maar een 'Null' cipher kan worden gebruikt als de server akkoord gaat. |
| NoEncryption | 2 | Sta geen versleuteling toe en vraag dat een 'Null' cipher wordt gebruikt als het andere eindpunt een 'Null' cipher kan verwerken. |
