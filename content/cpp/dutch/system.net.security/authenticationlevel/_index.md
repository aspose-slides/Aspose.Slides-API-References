
### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| None | 0 | Er is geen authenticatie vereist voor de client en server. |
| MutualAuthRequested | 1 | Het verzoek faalt niet als de server niet geauthenticeerd is. |
| MutualAuthRequired | 2 | De huidige applicatie zal 'IOException' ontvangen wanneer de server niet geauthenticeerd is. |
