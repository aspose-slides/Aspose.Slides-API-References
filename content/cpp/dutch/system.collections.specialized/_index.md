| [NameValueCollection](./namevaluecollection/) | Collectie van geassocieerde [String](../system/string/)-sleutels en [String](../system/string/)-waarden die toegankelijk zijn via de sleutel of via de index. |
| [StringCollection](./stringcollection/) | Geïndexeerde lijst van strings. Objecten van deze klasse mogen alleen worden gealloceerd met [System::MakeObject()](../system/makeobject/) functie. Wikkel deze klasse altijd in [System::SmartPtr](../system/smartptr/) pointer en gebruik deze pointer om deze als argument aan functies door te geven. |

| [StringDictionary](./stringdictionary/) | [String](../system/string/) naar string woordenboek. Maak nooit een exemplaar van dit type op de stack of met operator new, omdat dit leidt tot runtime fouten en/of assertiefouten.
