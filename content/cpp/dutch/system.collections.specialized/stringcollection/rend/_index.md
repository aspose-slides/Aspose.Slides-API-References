## StringCollection::rend() methode

Retourneert een reverse iterator naar het element dat volgt op het laatste element van de omgekeerde container. Het komt overeen met het element dat voorafgaat aan het eerste element van de niet-omgekeerde container. Dit element fungeert als een placeholder; proberen er toegang toe te krijgen resulteert in ongedefinieerd gedrag.

```cpp
reverse_iterator System::Collections::Specialized::StringCollection::rend() noexcept
```

### Retourwaarde

Een iterator die wijst naar het theoretische element dat voorafgaat aan het eerste element van de container.
