## EmfType enum

Specificeert de typen van de records die in een EMF-bestand worden geplaatst.

```cpp
enum class EmfType
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| EmfOnly | n/a | [Windows](../../system.windows/) verbeterde metafile. Bevat GDI-commando's. Metafiles van dit type worden aangeduid als een EMF-bestand. |
| EmfPlusOnly | n/a | [Windows](../../system.windows/) verbeterde metafile plus. Bevat GDI+-commando's. Metafiles van dit type worden aangeduid als een EMF+-bestand. |
| EmfPlusDual | n/a | Dual [Windows](../../system.windows/) verbeterde metafile. Bevat equivalente GDI- en GDI+-commando's. Metafiles van dit type worden aangeduid als een EMF+-bestand. |
