## ImageLockMode enum


Specificeert de eigenschappen van het gebied van een afbeelding dat vergrendeld is.

```cpp
enum class ImageLockMode
```

### Waarden

| Name | Value | Description |
| --- | --- | --- |
| ReadOnly | 1 | Het gebied is alleen vergrendeld voor lezen. |
| WriteOnly | 2 | Het gebied is alleen vergrendeld voor schrijven. |
| ReadWrite | n/a | Het gebied is zowel vergrendeld voor lezen als voor schrijven. |
| UserInputBuffer | 4 | De afbeelding bevindt zich in een gebruikersinvoerguffer, waarbij de toegang wordt gecontroleerd door de gebruiker. |
