## MetafileFrameUnit enum

Specificeert de maateenheid voor het rechthoek dat wordt gebruikt om de grootte en positie van een metafile te bepalen.

```cpp
enum class MetafileFrameUnit
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Pixel | n/a | Specificeert een pixel als de maateenheid. |
| Point | n/a | Specificeert een printerpunt als de maateenheid. |
| Inch | n/a | Specificeert een inch als de maateenheid. |
| Document | n/a | Specificeert 1/300 van een inch als de maateenheid. |
| Millimeter | n/a | Specificeert een millimeter als de maateenheid. |
| GdiCompatible | n/a | Specificeert .01 millimeter als de maateenheid. Biedt compatibiliteit met GDI. |
