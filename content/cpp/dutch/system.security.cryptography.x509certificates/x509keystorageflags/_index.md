## X509KeyStorageFlags enum

Definieert hoe de sleutel moet worden opgeslagen.

```cpp
enum class X509KeyStorageFlags : int32_t
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| DefaultKeySet | 0 | Gebruik de standaard sleutelset. |
| UserKeySet | 1 | Gebruik de door de gebruiker geassocieerde opslag in plaats van de machine-lokale. |
| MachineKeySet | 2 | Gebruik de lokale machine-opslag in plaats van die van de gebruiker. |
| Exportable | 4 | Markeert geïmporteerde sleutels als exporteerbaar. |
| UserProtected | 8 | Informeer de gebruiker dat de sleutel wordt gebruikt. |
| PersistKeySet | 16 | De sleutel wordt bewaard bij het importeren van een certificaat. |
