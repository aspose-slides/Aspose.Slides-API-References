## X500DistinguishedNameFlags enum

X509-certificaat onderscheidende naam opmaakregels.

```cpp
enum class X500DistinguishedNameFlags
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| None | 0 | Geen bijzondere kenmerken. |
| Reversed | 1 | Naam is gereserveerd. |
| UseSemicolons | 16 | Gebruik puntkomma's. |
| DoNotUsePlusSign | 32 | Naam gebruikt geen plusteken. |
| DoNotUseQuotes | 64 | Schakelt aanhalingstekens in de naam uit. |
| UseCommas | 128 | Schakelt het gebruik van komma's in. |
| UseNewLines | 256 | Schakelt het gebruik van nieuwe regels in. |
| UseUTF8Encoding | 4096 | Schakelt over van Unicode naar UTF-8-codering. |
| UseT61Encoding | 8192 | Schakelt over naar T61-codering. |
| ForceUTF8Encoding | 16384 | Forceert het gebruik van UTF-8 bij het coderen van specifieke X500-sleutels. |
