## EnumeratorSelectManyAdapter::MoveNext() methode


Verplaatst de enumerator naar het volgende element. Als er eerder geen element werd gerefereerd, stelt hij de referentie in op het eerste beschikbare element. Als het einde van de container is bereikt, doet hij niets.

```cpp
bool System::Collections::Generic::Details::EnumeratorSelectManyAdapter<Source, Result>::MoveNext() override
```


### Retourwaarde

True if some element is available after call, false otherwise.
