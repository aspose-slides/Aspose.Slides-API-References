## has_method_compareto struct

Controleert of de CompareTo-methode bestaat in het opgegeven type. Indien ja, erft std::true_type, anders erft std::false_type. Kan worden gebruikt in std::enable_if.

```cpp
template<typename T,typename Sfinae>class has_method_compareto : public std::false_type
```

### Templateparameters

| Parameter | Beschrijving |
| --- | --- |
| T | Type om te controleren of de Equals-methode bestaat. |
| Sfinae | Formeel sjabloonargument voor SFINAE om te werken. |
