## EnumeratorOfTypeAdapter::MoveNext() methode

Verplaatst de enumerator naar het volgende element. Als er vóórheen geen element werd gerefereerd, stelt de referentie in op het eerste beschikbare element. Als het einde van de container is bereikt, gebeurt er niets.

```cpp
bool System::Collections::Generic::Details::EnumeratorOfTypeAdapter<Source, Result>::MoveNext() override
```

### Retourwaarde

True als er een element beschikbaar is na de aanroep, anders false.
