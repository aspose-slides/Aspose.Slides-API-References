## EnumeratorCastAdapter::MoveNext() method

Verplaatst de enumerator naar het volgende element. Als er eerder geen element werd gerefereerd, stelt hij de referentie in op het eerste beschikbare element. Als het einde van de container is bereikt, doet hij niets.

```cpp
bool System::Collections::Generic::Details::EnumeratorCastAdapter<Source, Result>::MoveNext() override
```

### Returnwaarde

True als er een element beschikbaar is na de aanroep, anders false.
