## EnumeratorSelectIndexAdapter::MoveNext() methode

Verplaatst de enumerator naar het volgende element. Als er geen element eerder was gerefereerd, wordt de referentie ingesteld op het eerste beschikbare element. Als het einde van de container is bereikt, gebeurt er niets.

```cpp
bool System::Collections::Generic::Details::EnumeratorSelectIndexAdapter<Source, Result>::MoveNext() override
```

### Retourwaarde

True als er een element beschikbaar is na de oproep, anders false.
