## EmptyEnumerator::MoveNext() methode


Verplaatst enumerator naar het volgende element. Als er eerder geen element werd geadresseerd, stelt de referentie in op het eerste beschikbare element. Als het einde van de container werd bereikt, doet het niets.

```cpp
bool System::Linq::Details::EmptyEnumerator<T>::MoveNext() override
```


### Retourwaarde

True als er een element beschikbaar is na de oproep, false anders.
