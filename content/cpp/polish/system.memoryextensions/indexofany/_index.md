## System::MemoryExtensions::IndexOfAny(const ReadOnlySpan\<T\>\&, const T\&, const T\&) funkcja

Znajduje indeks pierwszego wystąpienia dowolnej z dwóch określonych wartości w ReadOnlySpan<T>

```cpp
template<typename T> int32_t System::MemoryExtensions::IndexOfAny(const ReadOnlySpan<T> &span, const T &value0, const T &value1)
```

### Parametry szablonu

| Parametr | Opis |
| --- | --- |
| T | The type of elements in the span |

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| span | const [ReadOnlySpan](../../system/readonlyspan/)\<T\>\& | Span, w którym należy wyszukać |
| value0 | const T\& | Pierwsza wartość do wyszukania |
| value1 | const T\& | Druga wartość do wyszukania |

### Wartość zwracana

Indeks zerowy pierwszego wystąpienia lub -1, jeśli nie zostanie znaleziony
