## Klasy

| Klasa | Opis |
| --- | --- |
| [IKnownIssueWarningInfo](./iknownissuewarninginfo/) | Reprezentuje ostrzeżenie o znanym problemie, który nie zostanie naprawiony w najbliższej przyszłości. |
| [INotImplementedWarningInfo](./inotimplementedwarninginfo/) | Reprezentuje ostrzeżenie o znanej niezaimplementowanej funkcji, która nie zostanie zaimplementowana w najbliższej przyszłości. |
| [IObsoletePresLockingBehaviorWarningInfo](./iobsoletepreslockingbehaviorwarninginfo/) | To ostrzeżenie wskazuje, że używane jest przestarzałe zachowanie blokowania prezentacji. |
| [IPresentationSignedWarningInfo](./ipresentationsignedwarninginfo/) | To ostrzeżenie wskazuje, że odczytywana prezentacja posiada podpis, który zostanie usunięty podczas przetwarzania. |
| [IWarningCallback](./iwarningcallback/) | Interfejs dla klas, które otrzymują ostrzeżenia |
| [IWarningInfo](./iwarninginfo/) | Reprezentuje podstawowy interfejs dla wszystkich ostrzeżeń. |
