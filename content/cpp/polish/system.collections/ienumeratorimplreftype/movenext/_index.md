## IEnumeratorImplRefType::MoveNext() metoda

Przesuwa enumerator do następnego elementu. Jeśli żaden element nie był wcześniej odwoływany, ustawia odniesienie na pierwszy dostępny element. Jeśli osiągnięto koniec kontenera, nie wykonuje żadnej operacji.

```cpp
virtual bool System::Collections::IEnumeratorImplRefType<T>::MoveNext() override
```

### Wartość zwracana

True jeśli po wywołaniu dostępny jest jakiś element, false w przeciwnym razie.
