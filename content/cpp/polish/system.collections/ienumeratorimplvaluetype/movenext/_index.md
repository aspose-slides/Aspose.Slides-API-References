## IEnumeratorImplValueType::MoveNext() metoda


Przesuwa enumerator do następnego elementu. Jeśli żaden element nie był wcześniej odwoływany, ustawia odwołanie na pierwszy dostępny element. Jeśli osiągnięto koniec kontenera, nie wykonuje żadnej akcji.

```cpp
virtual bool System::Collections::IEnumeratorImplValueType<T>::MoveNext() override
```


### Wartość zwracana

True jeśli po wywołaniu dostępny jest jakiś element, false w przeciwnym razie.
