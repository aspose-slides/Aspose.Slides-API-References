## IEnumerator::MoveNext() metoda

Przesuwa iterator do następnego elementu. Jeśli wcześniej nie został odwołany żaden element, ustawia odwołanie na pierwszy dostępny element. Jeśli osiągnięto koniec kontenera, nie robi nic.

```cpp
virtual bool System::Collections::IEnumerator::MoveNext()=0
```

### Wartość zwracana

Prawda, jeśli po wywołaniu dostępny jest jakiś element, w przeciwnym razie fałsz.
