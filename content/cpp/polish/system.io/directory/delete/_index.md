## Directory::Delete(const String\&, bool) metoda


Usuwa określony plik lub katalog. Nie zgłasza wyjątków.

```cpp
static void System::IO::Directory::Delete(const String &path, bool recursive=false)
```


### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| path | const [String](../../../system/string/)\& | Ścieżka do katalogu lub pliku, który ma zostać usunięty |
| recursive | **bool** | Jeżeli **path** określa niepusty katalog, wtedy **recursive** określa, czy cała zawartość katalogu powinna być usunięta rekurencyjnie; jeśli katalog wskazany przez **path** nie jest pusty i **recursive** ma wartość 'false', operacja kończy się niepowodzeniem |
