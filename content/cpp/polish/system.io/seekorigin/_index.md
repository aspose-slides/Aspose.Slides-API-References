## SeekOrigin enum

Specifies the reference position in the stream relative to which the position to seek to is specified.

```cpp
enum class SeekOrigin
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| Begin | 0 | Początek strumienia. |
| Current | 1 | Bieżąca pozycja w strumieniu. |
| End | 2 | Koniec strumienia. |
