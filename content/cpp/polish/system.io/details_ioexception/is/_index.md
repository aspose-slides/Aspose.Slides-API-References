## Details_IOException::Is(const System::TypeInfo\&) const method

```cpp
bool System::IO::Details_IOException::Is(const System::TypeInfo &target) const override
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| target | const [System::TypeInfo](../../../system/typeinfo/)\& | [TypeInfo](../../../system/typeinfo/) struktura opisująca typ, względem którego sprawdzany jest bieżący obiekt. |

### Wartość zwracana

True jeśli obiekt jest typu oznaczonego lub jego podklasy, false w przeciwnym razie.

## Uwagi

Sprawdź, czy obiekt jest instancją typu opisanego przez targetType. Analog operatora C# 'is'.
