## FileShare enum

Określa, jaki rodzaj dostępu inne obiekty [FileStream](../filestream/) mogą mieć do otwieranego pliku.

```cpp
enum class FileShare
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| None | 0 | Brak dostępu. |
| Read | 1 | Dostęp tylko do odczytu. |
| Write | 2 | Dostęp tylko do zapisu. |
| ReadWrite | 3 | Dostęp do odczytu i zapisu. |
| Delete | 4 | Plik może być usunięty. |
| Inheritable | 16 | Umożliwia dziedziczenie uchwytu pliku przez procesy potomne. |
