## FileAttributes enum

Reprezentuje atrybuty katalogu lub pliku.

```cpp
enum class FileAttributes
```

### Values

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| Archive | 32 | Obiekt systemu plików jest kandydatem do usunięcia lub kopii zapasowej. |
| Compressed | 2048 | Obiekt systemu plików jest skompresowany. |
| Device | 64 | Nie używany. |
| Directory | 16 | Obiekt systemu plików jest katalogiem. |
| Encrypted | 16384 | Obiekt systemu plików jest zaszyfrowany. |
| Hidden | 2 | Obiekt systemu plików jest ukryty. |
| IntegrityStream | 32768 | Obiekt systemu plików zawiera wsparcie integralności danych. |
| Normal | 128 | Obiekt systemu plików jest plikiem bez specjalnych atrybutów. |
| NotContentIndexed | 8192 | Obiekt systemu plików nie będzie indeksowany przez usługę indeksowania treści. |
| NoScrubData | 131072 | Obiekt systemu plików nie jest uwzględniany w skanowaniu integralności danych. |
| Offline | 4096 | Obiekt systemu plików jest offline i jego dane nie są od razu dostępne. |
| ReadOnly | 1 | Obiekt systemu plików jest tylko do odczytu. |
| ReparsePoint | 1024 | Obiekt systemu plików jest plikiem zawierającym punkt ponownego przetworzenia. |
| SparseFile | 512 | Obiekt systemu plików jest plikiem rzadkim. |
| System | 4 | Obiekt systemu plików jest plikiem systemowym. |
| Temporary | 256 | Obiekt systemu plików jest plikiem tymczasowym. |
| Invalid | 0 | Nieprawidłowa wartość. |
