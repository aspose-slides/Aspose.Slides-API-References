## FileSystemInfo::get_Exists() metoda


Określa, czy encja odwoływana przez ścieżkę reprezentowaną przez bieżący obiekt istnieje.

```cpp
virtual bool System::IO::FileSystemInfo::get_Exists()=0
```


### Wartość zwracana

True jeśli encja odwoływana przez ścieżkę reprezentowaną przez bieżący obiekt istnieje, w przeciwnym razie - false
