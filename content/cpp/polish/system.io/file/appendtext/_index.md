## File::AppendText(const String\&) metoda

Tworzy obiekt [StreamWriter](../../streamwriter/), który dodaje tekst do określonego pliku używając kodowania UTF-8. Jeśli określony plik nie istnieje, zostaje utworzony.

```cpp
static StreamWriterPtr System::IO::File::AppendText(const String &path)
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| path | const [String](../../../system/string/)\& | Ścieżka do pliku, który ma zostać otwarty lub utworzony |

### Wartość zwracana

Wskaźnik współdzielony do utworzonego obiektu [StreamWriter](../../streamwriter/) powiązanego z określonym plikiem
