## StreamReader::Peek() metoda

Odczytuje pojedynczy znak ze strumienia bez zmiany kursora odczytu strumienia.

```cpp
virtual int System::IO::StreamReader::Peek() override
```

### Wartość zwracana

Odczytany znak zakodowany w kodowaniu UTF-16; jeśli odczytany znak jest reprezentowany przez dwa punkty kodowe w kodowaniu UTF-16, zwracany jest tylko wysoki surogat; jeśli nie odczytano żadnego znaku, zwracane jest -1
