## XPathItem::get_IsNode() metoda


Gdy zostanie przesłonięta w klasie pochodnej, pobiera wartość wskazującą, czy element reprezentuje węzeł [XPath](../../) lub wartość atomową.

```cpp
virtual bool System::Xml::XPath::XPathItem::get_IsNode()=0
```


### Wartość zwracana

**true** jeśli element reprezentuje węzeł [XPath](../../); **false** jeśli element reprezentuje wartość atomową.
