## XPathNamespaceScope enum

Definiuje zakres przestrzeni nazw.

```cpp
enum class XPathNamespaceScope
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| All | 0 | Zwraca wszystkie przestrzenie nazw zdefiniowane w zakresie bieżącego węzła. Obejmuje to **xmlns:xml**, które jest zawsze zadeklarowane domyślnie. Kolejność zwróconych przestrzeni nazw nie jest określona. |
| ExcludeXml | 1 | Zwraca wszystkie przestrzenie nazw zdefiniowane w zakresie bieżącego węzła, z wyłączeniem **xmlns:xml**. **xmlns:xml** jest zawsze zadeklarowane domyślnie. Kolejność zwróconych przestrzeni nazw nie jest określona. |
| Local | 2 | Zwraca wszystkie przestrzenie nazw zdefiniowane lokalnie w bieżącym węźle. |
