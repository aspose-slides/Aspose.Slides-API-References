## XPathNavigator::get_IsEmptyElement() metoda

Gdy zostanie nadpisana w klasie pochodnej, zwraca wartość wskazującą, czy bieżący węzeł jest pustym elementem bez znacznika końcowego.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::get_IsEmptyElement()=0
```

### Wartość zwracana

**true** if the current node is an empty element; otherwise, **false**.
