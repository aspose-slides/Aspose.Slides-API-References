## XPathNavigator::MoveToFirstAttribute() metoda


Gdy jest nadpisany w klasie pochodnej, przenosi [XPathNavigator](../) do pierwszego atrybutu bieżącego węzła.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToFirstAttribute()=0
```


### Wartość zwracana

**true** jeśli [XPathNavigator](../) zakończy się pomyślnie przy przenoszeniu do pierwszego atrybutu bieżącego węzła; w przeciwnym razie **false**. Jeśli **false**, pozycja [XPathNavigator](../) pozostaje niezmieniona.
