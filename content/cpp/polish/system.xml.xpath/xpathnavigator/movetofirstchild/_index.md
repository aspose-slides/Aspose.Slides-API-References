## XPathNavigator::MoveToFirstChild() metoda

Gdy zostanie nadpisana w klasie pochodnej, przenosi [XPathNavigator](../) do pierwszego węzła potomnego bieżącego węzła.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToFirstChild()=0
```

### Wartość zwracana

**true** jeśli [XPathNavigator](../) pomyślnie przemieszcza się do pierwszego węzła potomnego bieżącego węzła; w przeciwnym razie **false**. Jeśli **false**, pozycja [XPathNavigator](../) pozostaje niezmieniona.
