## XPathNavigator::get_LocalName() metoda

Gdy zostanie przesłonięta w klasie pochodnej, zwraca [XPathNavigator::get_Name](../get_name/) bieżącego węzła bez prefiksu przestrzeni nazw.

```cpp
virtual String System::Xml::XPath::XPathNavigator::get_LocalName()=0
```

### Wartość zwracana

Obiekt [String](../../../system/string/) zawierający lokalną nazwę bieżącego węzła lub [String::Empty](../../../system/string/empty/), jeśli bieżący węzeł nie ma nazwy (na przykład węzły tekstowe lub komentarze).
