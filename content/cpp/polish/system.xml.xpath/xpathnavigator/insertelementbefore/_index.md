## XPathNavigator::InsertElementBefore(String, String, String, String) metoda

Tworzy nowy element rodzeństwa przed bieżącym węzłem, używając określonego prefiksu przestrzeni nazw, nazwy lokalnej i adresu URI przestrzeni nazw, z określoną wartością.

```cpp
virtual void System::Xml::XPath::XPathNavigator::InsertElementBefore(String prefix, String localName, String namespaceURI, String value)
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| prefix | [String](../../../system/string/) | Prefiks przestrzeni nazw nowego elementu potomnego (jeśli istnieje). |
| localName | [String](../../../system/string/) | Nazwa lokalna nowego elementu potomnego (jeśli istnieje). |
| namespaceURI | [String](../../../system/string/) | Adres URI przestrzeni nazw nowego elementu potomnego (jeśli istnieje). [String::Empty](../../../system/string/empty/) i **nullptr** są równoważne. |
| value | [String](../../../system/string/) | Wartość nowego elementu potomnego. Jeśli [String::Empty](../../../system/string/empty/) lub **nullptr** zostaną przekazane, tworzony jest pusty element. |
