## XPathNavigator::get_HasAttributes() metoda

Zwraca wartość wskazującą, czy bieżący węzeł ma jakiekolwiek atrybuty.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::get_HasAttributes()
```

### Wartość zwracana

**true** jeśli bieżący węzeł ma atrybuty; zwraca **false**, jeśli bieżący węzeł nie ma atrybutów lub jeśli [XPathNavigator](../) nie jest ustawiony na węzeł elementu.
