## XPathNavigator::MoveToNextNamespace(XPathNamespaceScope) metoda


Gdy zostanie przesłonięta w klasie pochodnej, przenosi [XPathNavigator](../) do następnego węzła przestrzeni nazw pasującego do określonego XPathNamespaceScope.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToNextNamespace(XPathNamespaceScope namespaceScope)=0
```


### Argumenty

| Parameter | Type | Description |
| --- | --- | --- |
| namespaceScope | [XPathNamespaceScope](../../xpathnamespacescope/) | Wartość XPathNamespaceScope opisująca zakres przestrzeni nazw. |

### Wartość zwracana

**true** jeśli [XPathNavigator](../) zakończy się pomyślnie przenosząc do następnego węzła przestrzeni nazw; w przeciwnym razie **false**. Jeśli **false**, pozycja [XPathNavigator](../) pozostaje niezmieniona.
