## XPathNavigator::MoveToNamespace(String) metoda


Przenosi [XPathNavigator](../) do węzła przestrzeni nazw o określonym prefiksie przestrzeni nazw.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToNamespace(String name)
```


### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| name | [String](../../../system/string/) | Prefiks przestrzeni nazw węzła przestrzeni nazw. |

### Wartość zwracana

**true** jeśli [XPathNavigator](../) pomyślnie przeniesie się do określonej przestrzeni nazw; **false** jeśli nie znaleziono pasującego węzła przestrzeni nazw lub jeśli [XPathNavigator](../) nie jest pozycjonowany na węźle elementu. Jeśli **false**, pozycja [XPathNavigator](../) pozostaje niezmieniona.
