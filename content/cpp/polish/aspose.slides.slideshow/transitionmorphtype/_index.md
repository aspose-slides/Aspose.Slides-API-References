## TransitionMorphType enum

Reprezentuje typ przejścia morph.

```cpp
enum class TransitionMorphType
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| ByObject | 0 | Przejście morph zostanie wykonane z uwzględnieniem kształtów jako niepodzielnych obiektów. |
| ByWord | 1 | Przejście morph zostanie wykonane z przenoszeniem tekstu słowo po słowie, gdy jest to możliwe. |
| ByChar | 2 | Przejście morph zostanie wykonane z przenoszeniem tekstu znak po znaku, gdy jest to możliwe. |
