## SlideShowTransition::set_SoundIsBuiltIn(bool) metoda


Określa, czy ten dźwięk jest wbudowany, czy nie. Jeśli ten atrybut jest ustawiony na true, aplikacja generująca zostaje powiadomiona, aby sprawdzić atrybut name określony dla tego dźwięku w jej liście wbudowanych dźwięków i może wtedy wyświetlić niestandardową nazwę lub UI w razie potrzeby. Zapisuje **bool**.
