## IDataLabelCollection::get_IsVisible() metoda


False oznacza, że etykieta danych nie jest domyślnie widoczna (a więc wszystkie flagi Show*-flags (ShowValue, ...) właściwości DefaultDataLabelFormat są false). Tylko do odczytu **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelCollection::get_IsVisible()=0
```

## Uwagi


Jeśli etykieta danych jest domyślnie widoczna, możesz ją domyślnie ukryć za pomocą metody [Hide()](../hide/). Jednak jeśli etykieta danych nie jest domyślnie widoczna (IsVisible jest false), możesz ustawić etykietę danych \"widoczną 
domyślnie\" zmieniając flagi Show*-flags (ShowValue, ...) właściwości DefaultDataLabelFormat na stan true.
