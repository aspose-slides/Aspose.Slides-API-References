## IDataLabelCollection::Hide() metoda

Ukryj etykietę danych domyślnie, ustawiając wszystkie flagi Show*- (ShowValue, ...) właściwości DefaultDataLabelFormat na wartość false. IsVisible będzie false po tym.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelCollection::Hide()=0
```

## Uwagi

Jeśli etykieta danych nie jest domyślnie widoczna (IsVisible jest false), możesz uczynić etykietę danych „widoczną domyślnie”, ustawiając flagi Show*- (ShowValue, ...) właściwości DefaultDataLabelFormat na stan true.
