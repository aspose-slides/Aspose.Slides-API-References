## TickMarkType enum

Reprezentuje typ znacznika podziałki dla określonej osi.

```cpp
enum class TickMarkType
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| Cross | 0 | Określa, że znaczniki podziałki mają przecinać oś. |
| Inside | 1 | Określa, że znaczniki podziałki mają znajdować się wewnątrz obszaru wykresu. |
| None | 2 | Określa, że nie będzie znaczników podziałki. |
| Outside | 3 | Określa, że znaczniki podziałki mają znajdować się na zewnątrz obszaru wykresu. |
