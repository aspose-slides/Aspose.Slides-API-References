## IBaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType) metoda

Określa, czy właściwość AsCell lub AsLiteralString lub AsLiteralDouble jest aktualna. Innymi słowy określa typ wartości właściwości Data. Ta właściwość jest tylko do odczytu. Aby zmienić wartość tej właściwości, można użyć jednej z właściwości ChartDataPointCollection.DataSourceTypeFor<...>. Zapisz [DataSourceType](../../datasourcetype/).

virtual void Aspose::Slides::Charts::IBaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType value)=0
