## IChartSeries::get_BubbleSizeRepresentation() metoda

Określa, w jaki sposób wartości rozmiaru bąbelka są przedstawiane na wykresie bąbelkowym. Jest to właściwość nie tylko tej serii, ale wszystkich serii grupy serii nadrzędnej – jest to projekcja odpowiedniej właściwości grupy. Dlatego ta właściwość jest tylko do odczytu. Użyj właściwości ParentSeriesGroup, aby uzyskać dostęp do grupy serii nadrzędnej. Użyj [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_BubbleSizeRepresentation() właściwości odczyt/zapis, aby zmienić wartość.

```cpp
virtual BubbleSizeRepresentationType Aspose::Slides::Charts::IChartSeries::get_BubbleSizeRepresentation()=0
```

## Uwagi

Jest to projekcja właściwości [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_BubbleSizeRepresentation().
