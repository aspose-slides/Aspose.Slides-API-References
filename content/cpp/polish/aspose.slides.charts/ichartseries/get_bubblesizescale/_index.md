## IChartSeries::get_BubbleSizeScale() metoda

Określa współczynnik skalowania wykresu bąbelkowego (może wynosić od 0 do 300 procent domyślnego rozmiaru). Jest to właściwość nie tylko tego szeregu, ale wszystkich serii w grupie serii nadrzędnej – jest to projekcja odpowiedniej właściwości grupy. Dlatego właściwość ta jest tylko do odczytu. Użyj właściwości ParentSeriesGroup, aby uzyskać dostęp do grupy serii nadrzędnej. Użyj [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_BubbleSizeScale() właściwości odczyt/zapis, aby zmienić wartość.

```cpp
virtual int32_t Aspose::Slides::Charts::IChartSeries::get_BubbleSizeScale()=0
```

## Uwagi

Jest to projekcja właściwości [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_BubbleSizeScale().
