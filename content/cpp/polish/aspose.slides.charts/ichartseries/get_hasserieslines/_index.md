## IChartSeries::get_HasSeriesLines() metoda

Określa, czy istnieją linie serii dla tej serii i pokrewnych serii. Jest to właściwość nie tylko tej serii, ale wszystkich serii w nadrzędnej grupie serii – jest to projekcja odpowiedniej właściwości grupy. Dlatego ta właściwość jest tylko do odczytu. Użyj właściwości ParentSeriesGroup, aby uzyskać dostęp do nadrzędnej grupy serii. Użyj [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_HasSeriesLines() właściwości odczyt/zapis, aby zmienić wartość. Użyj właściwości ParentSeriesGroup.SeriesLinesFormat, aby sformatować linie serii. Tylko do odczytu **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IChartSeries::get_HasSeriesLines()=0
```

## Uwagi

Jest to projekcja właściwości [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_HasSeriesLines().
