## ErrorBarValueType enum

Reprezentuje typ wartości słupka błędu

```cpp
enum class ErrorBarValueType
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| Custom | 0 | Określa, że długość słupków błędu ma być wyznaczana na podstawie elementów Plus i Minus. |
| Fixed | 1 | Określa, że długość słupków błędu ma być stałą wartością określoną przez Error Bar Value. |
| Percentage | 2 | Określa, że długość słupków błędu ma stanowić procent wartości Error Bar Value danych. |
| StandardDeviation | 3 | Określa, że długość słupków błędu ma być odchyleniem standardowym Error Bar Value danych. |
| StandardError | 4 | Określa, że długość słupków błędu ma być błędem standardowym Error Bar Value danych. |
