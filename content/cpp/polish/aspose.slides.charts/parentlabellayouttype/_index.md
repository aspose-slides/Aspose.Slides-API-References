## ParentLabelLayoutType enum

Reprezentuje układ etykiet danych kategorii. Używany wyłącznie w serii Treemap.

```cpp
enum class ParentLabelLayoutType
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| Banner | 0 | Określa, że etykiety kategorii nadrzędnych są wyświetlane jako baner |
| None | 1 | Określa, że etykiety kategorii nadrzędnych nie są rysowane |
| Overlapping | 2 | Określa, że etykiety kategorii nadrzędnych są wyświetlane jako nachodzące na siebie |
