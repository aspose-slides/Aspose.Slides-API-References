## AxisAggregationType enum

Reprezentuje typ agregacji osi kategorii. Używany wyłącznie z seriami Histogram lub HistogramPareto.

```cpp
enum class AxisAggregationType
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| ByCategory | 0 | Agreguj według kategorii |
| Automatic | 1 | Agreguj kategorie automatycznie. |
| ByBinWidth | 2 | Agreguj kategorie według szerokości kosza. Właściwość IAxis::get(set)_BinWidth musi być ustawiona. |
| ByNumberOfBins | 3 | Agreguj kategorie według liczby koszy. Właściwość IAxis::get(set)_NumberOfBins musi być ustawiona. |
