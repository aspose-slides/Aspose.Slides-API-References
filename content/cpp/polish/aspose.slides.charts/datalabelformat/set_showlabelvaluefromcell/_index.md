## DataLabelFormat::set_ShowLabelValueFromCell(bool) metoda


Reprezentuje określone zachowanie wyświetlania wartości komórki etykiety danych wykresu. True wyświetla wartość komórki. False ukrywa. Zapisz **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLabelValueFromCell(bool value) override
```

## Uwagi


Jeśli rodzicem tego obiektu [DataLabelFormat](../) jest kolekcja [DataLabelCollection](../../datalabelcollection/) etykiet danych, to ta właściwość pobiera lub ustawia domyślną wartość właściwości ShowLabelValueFromCell dla nowych etykiet danych w kolekcji [DataLabelCollection](../../datalabelcollection/). Ustawienie tej właściwości na wartość powoduje również ustawienie tej wartości w właściwości ShowLabelValueFromCell dla wszystkich etykiet danych w kolekcji [DataLabelCollection](../../datalabelcollection/) (i.e. "DataLabels.DefaultDataLabelFormat.ShowLabelValueFromCell = val;" powoduje, że wszystkie DataLabels[i].ShowLabelValueFromCell są równe val).
