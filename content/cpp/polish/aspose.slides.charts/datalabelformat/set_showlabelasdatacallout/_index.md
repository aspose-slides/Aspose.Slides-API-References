## DataLabelFormat::set_ShowLabelAsDataCallout(bool) metoda


Określa, czy etykieta danych określonego wykresu ma być wyświetlana jako odwołanie danych czy jako etykieta danych.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLabelAsDataCallout(bool value) override
```

## Uwagi


Jeśli rodzicem tego obiektu [DataLabelFormat](../) jest kolekcja [DataLabelCollection](../../datalabelcollection/) etykiet danych, to ta własność pobiera lub ustawia domyślną wartość właściwości ShowLabelAsDataCallout dla nowych etykiet danych w kolekcji [DataLabelCollection](../../datalabelcollection/). Ustawienie tej własności na określoną wartość powoduje również ustawienie tej samej wartości w właściwości ShowLabelAsDataCallout dla wszystkich etykiet danych w kolekcji [DataLabelCollection](../../datalabelcollection/) (np. \"DataLabels.DefaultDataLabelFormat.ShowLabelAsDataCallout = val;\" powoduje, że wszystkie DataLabels[i].ShowLabelAsDataCallout są równe val).
