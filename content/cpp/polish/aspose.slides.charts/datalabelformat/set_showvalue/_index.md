## DataLabelFormat::set_ShowValue(bool) metoda

Reprezentuje zachowanie wyświetlania wartości procentowej etykiety danych określonego wykresu. True wyświetla wartość procentową. False ukrywa. Zapisz **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowValue(bool value) override
```

## Uwagi

Jeśli rodzicem tego [DataLabelFormat](../) obiektu jest kolekcja [DataLabelCollection](../../datalabelcollection/) etykiet danych, to ta właściwość odczytuje lub ustawia domyślną wartość właściwości ShowValue dla nowych etykiet danych w kolekcji [DataLabelCollection](../../datalabelcollection/). Ustawienie tej właściwości na określoną wartość ustawia tę samą wartość w właściwości ShowValue dla wszystkich etykiet danych w kolekcji [DataLabelCollection](../../datalabelcollection/) (np. "DataLabels.DefaultDataLabelFormat.ShowValue = val;" powoduje, że wszystkie DataLabels[i].ShowValue są równe val).
