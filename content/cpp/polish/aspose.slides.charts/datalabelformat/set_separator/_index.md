## DataLabelFormat::set_Separator(System::String) metoda

Ustawia lub zwraca Variant reprezentujący separator używany dla etykiet danych na wykresie. Zapisz [System::String](../../../system/string/).

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_Separator(System::String value) override
```

## Uwagi

Jeśli rodzicem tego obiektu [DataLabelFormat](../) jest zbiór [DataLabelCollection](../../datalabelcollection/) etykiet danych, wówczas ta własność pobiera lub ustawia domyślną wartość właściwości Separator dla nowych etykiet danych w zbiorze [DataLabelCollection](../../datalabelcollection/). Ustawienie tej własności na wartość powoduje również ustawienie tej wartości w właściwości Separator dla wszystkich etykiet danych w zbiorze [DataLabelCollection](../../datalabelcollection/) (np. \"DataLabels.DefaultDataLabelFormat.Separator = val;\" powoduje, że wszystkie DataLabels[i].Separator są równe val).
