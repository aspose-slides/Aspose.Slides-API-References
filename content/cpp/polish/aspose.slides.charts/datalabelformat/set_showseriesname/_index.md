## DataLabelFormat::set_ShowSeriesName(bool) metoda

Ustawia wartość logiczną wskazującą zachowanie wyświetlania nazwy serii dla etykiet danych na wykresie. True, aby wyświetlić nazwę serii. False, aby ukryć. Zapisz **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowSeriesName(bool value) override
```

## Uwagi

Jeśli rodzicem tego [DataLabelFormat](../) obiektu jest kolekcja [DataLabelCollection](../../datalabelcollection/) etykiet danych, to ta właściwość pobiera lub ustawia domyślną wartość właściwości ShowSeriesName dla nowych etykiet danych w kolekcji [DataLabelCollection](../../datalabelcollection/). Ustawienie tej właściwości na określoną wartość powoduje również ustawienie tej wartości w właściwości ShowSeriesName dla wszystkich etykiet danych w kolekcji [DataLabelCollection](../../datalabelcollection/) (np. "DataLabels.DefaultDataLabelFormat.ShowSeriesName = val;" powoduje, że wszystkie DataLabels[i].ShowSeriesName są równe val).
