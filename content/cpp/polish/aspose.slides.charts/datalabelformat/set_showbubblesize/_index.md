## DataLabelFormat::set_ShowBubbleSize(bool) metoda

Reprezentuje zachowanie wyświetlania wartości rozmiaru bąbelka etykiety danych określonego wykresu. True wyświetla wartość rozmiaru bąbelka. False ukrywa. Zapisz **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowBubbleSize(bool value) override
```

## Uwagi

Jeśli rodzicem tego [DataLabelFormat](../) obiektu jest kolekcja [DataLabelCollection](../../datalabelcollection/) etykiet danych, to ta właściwość pobiera lub ustawia domyślną wartość właściwości ShowBubbleSize dla nowych etykiet danych w kolekcji [DataLabelCollection](../../datalabelcollection/). Ustawienie tej właściwości na wartość powoduje również ustawienie tej wartości w właściwości ShowBubbleSize dla wszystkich etykiet danych w kolekcji [DataLabelCollection](../../datalabelcollection/) (i.e. \"DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;\" powoduje, że wszystkie DataLabels[i].ShowBubbleSize są równe val).
