## BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType) metoda


Określa, czy AsCell, AsCells, AsLiteralString lub AsLiteralDouble właściwość jest aktualna w potomkach. Inaczej mówiąc określa typ wartości właściwości Data. Zapisz [Charts::DataSourceType](../../datasourcetype/).

```cpp
void Aspose::Slides::Charts::BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType value) override
```

## Uwagi


Dla punktów w [ChartDataPointCollection](../../chartdatapointcollection/) ta właściwość jest tylko do odczytu. W takim przypadku, aby zmienić wartość tej właściwości, możesz użyć jednej z właściwości ChartDataPointCollection.DataSourceTypeFor<...>.
