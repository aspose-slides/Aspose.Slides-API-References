## IDataLabelFormat::set_ShowLabelAsDataCallout(bool) metoda


Określa, czy etykieta danych określonego wykresu będzie wyświetlana jako odwołanie danych, czy jako etykieta danych.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowLabelAsDataCallout(bool value)=0
```

## Uwagi


Jeśli rodzic tego obiektu [DataLabelFormat](../../datalabelformat/) jest kolekcją [DataLabelCollection](../../datalabelcollection/) etykiet danych, to właściwość ta pobiera lub ustawia domyślną wartość właściwości ShowLabelAsDataCallout dla nowych etykiet danych w kolekcji [DataLabelCollection](../../datalabelcollection/). Ustawienie tej właściwości powoduje również ustawienie tej samej wartości właściwości ShowLabelAsDataCallout dla wszystkich etykiet danych w kolekcji [DataLabelCollection](../../datalabelcollection/) (np. \"DataLabels.DefaultDataLabelFormat.ShowLabelAsDataCallout = val;\" powoduje, że wszystkie DataLabels[i].ShowLabelAsDataCallout są równe val).
