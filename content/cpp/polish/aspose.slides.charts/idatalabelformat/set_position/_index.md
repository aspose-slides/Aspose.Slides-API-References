## IDataLabelFormat::set_Position(LegendDataLabelPosition) metoda

Represents the position of the data label. Write [LegendDataLabelPosition](../../legenddatalabelposition/).

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_Position(LegendDataLabelPosition value)=0
```

## Uwagi

Jeśli rodzicem tego obiektu [DataLabelFormat](../../datalabelformat/) jest zbiór [DataLabelCollection](../../datalabelcollection/) etykiet danych, to ta właściwość pobiera lub ustawia domyślną wartość właściwości Position dla nowych etykiet danych w zbiorze [DataLabelCollection](../../datalabelcollection/). Reprezentuje pozycję dla obiektów [DataLabel](../../datalabel/). Ustawienie tej właściwości na wartość powoduje również ustawienie tej wartości w właściwości Position dla wszystkich etykiet danych w zbiorze [DataLabelCollection](../../datalabelcollection/) (i.e. "DataLabels.DefaultDataLabelFormat.Position = val;" co sprawia, że wszystkie DataLabels[i].Position są równe val).
