## IDataLabelFormat::set_IsNumberFormatLinkedToSource(bool) metoda

Zapisz **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_IsNumberFormatLinkedToSource(bool value)=0
```

## Uwagi

Jeśli rodzic tego [DataLabelFormat](../../datalabelformat/) obiektu jest [DataLabelCollection](../../datalabelcollection/) kolekcją etykiet danych, to ta właściwość pobiera lub ustawia domyślną wartość właściwości IsNumberFormatLinkedToSource dla nowych etykiet danych w [DataLabelCollection](../../datalabelcollection/) kolekcji. Ustawienie tej właściwości z wartością ustawia również tę wartość w właściwości IsNumberFormatLinkedToSource dla wszystkich etykiet danych w [DataLabelCollection](../../datalabelcollection/) kolekcji (i.e. \"DataLabels.DefaultDataLabelFormat.IsNumberFormatLinkedToSource = val;\" powoduje, że wszystkie DataLabels[i].IsNumberFormatLinkedToSource są równe val).
