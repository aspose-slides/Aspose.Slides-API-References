## IDataLabelFormat::set_ShowLegendKey(bool) metoda


Reprezentuje zachowanie wyświetlania klucza legendy etykiet danych określonego wykresu. True, jeśli klucz legendy etykiety danych jest widoczny. Zapisz **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowLegendKey(bool value)=0
```

## Uwagi


Jeśli rodzic tego [DataLabelFormat](../../datalabelformat/) obiektu jest kolekcją [DataLabelCollection](../../datalabelcollection/) etykiet danych, to ta właściwość pobiera lub ustawia domyślną wartość właściwości ShowLegendKey dla nowych etykiet danych w kolekcji [DataLabelCollection](../../datalabelcollection/). Ustawienie tej właściwości na wartość również ustawia tę wartość w właściwości ShowLegendKey dla wszystkich etykiet danych w kolekcji [DataLabelCollection](../../datalabelcollection/) (np. "DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;" powoduje, że wszystkie DataLabels[i].ShowLegendKey jest równe val).
