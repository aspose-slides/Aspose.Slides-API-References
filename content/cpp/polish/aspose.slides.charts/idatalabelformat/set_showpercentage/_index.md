## IDataLabelFormat::set_ShowPercentage(bool) metoda

Reprezentuje zachowanie wyświetlania wartości procentowej etykiety danych określonego wykresu. True wyświetla wartość procentową. False ukrywa ją. Zapisz **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowPercentage(bool value)=0
```

## Uwagi

Jeśli rodzic tego obiektu [DataLabelFormat](../../datalabelformat/) jest kolekcją [DataLabelCollection](../../datalabelcollection/) etykiet danych, wtedy ta właściwość pobiera lub ustawia domyślną wartość właściwości ShowPercentage dla nowych etykiet danych w kolekcji [DataLabelCollection](../../datalabelcollection/). Ustawienie tej właściwości na wartość powoduje również ustawienie tej wartości w właściwości ShowPercentage dla wszystkich etykiet danych w kolekcji [DataLabelCollection](../../datalabelcollection/) (i.e. \"DataLabels.DefaultDataLabelFormat.ShowPercentage = val;\" co powoduje, że wszystkie DataLabels[i].ShowPercentage są równe val).
