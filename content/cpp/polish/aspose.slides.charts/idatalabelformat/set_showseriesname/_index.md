## IDataLabelFormat::set_ShowSeriesName(bool) metoda


Ustawia wartość logiczną określającą zachowanie wyświetlania nazwy serii dla etykiet danych na wykresie. True, aby wyświetlić nazwę serii. False, aby ukryć. Zapisz **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowSeriesName(bool value)=0
```

## Uwagi


Jeśli rodzicem tego [DataLabelFormat](../../datalabelformat/) obiektu jest [DataLabelCollection](../../datalabelcollection/) zbiór etykiet danych, wtedy ta właściwość odczytuje lub ustawia domyślną wartość właściwości ShowSeriesName dla nowych etykiet danych w [DataLabelCollection](../../datalabelcollection/) zbiorze. Ustawienie tej właściwości z wartością ustawia tę samą wartość w właściwości ShowSeriesName dla wszystkich etykiet danych w [DataLabelCollection](../../datalabelcollection/) zbiorze (np. „DataLabels.DefaultDataLabelFormat.ShowSeriesName = val;” powoduje, że wszystkie DataLabels[i].ShowSeriesName są równe val).
