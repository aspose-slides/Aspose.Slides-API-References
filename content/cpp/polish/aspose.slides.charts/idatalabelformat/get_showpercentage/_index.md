## IDataLabelFormat::get_ShowPercentage() metoda

Reprezentuje zachowanie wyświetlania wartości procentowej etykiety danych określonego wykresu. True wyświetla wartość procentową. False ukrywa. Odczyt **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowPercentage()=0
```

## Uwagi

Jeśli rodzic tego obiektu [DataLabelFormat](../../datalabelformat/) jest kolekcją [DataLabelCollection](../../datalabelcollection/) etykiet danych, to właściwość ta pobiera lub ustawia domyślną wartość właściwości ShowPercentage dla nowych etykiet danych w kolekcji [DataLabelCollection](../../datalabelcollection/). Ustawienie tej właściwości z wartością ustawia również tę wartość w właściwości ShowPercentage dla wszystkich etykiet danych w kolekcji [DataLabelCollection](../../datalabelcollection/) (np. "DataLabels.DefaultDataLabelFormat.ShowPercentage = val;" powoduje, że wszystkie DataLabels[i].ShowPercentage są równe val).
