## TimeUnitType enum

Represents the base unit for the category axis

```cpp

```

| --- | --- | --- |
| None | 0 | Wartości będą wyświetlane tak jak są. |
| Days | 1 | Określa, że dane wykresu będą wyświetlane w dniach. |
