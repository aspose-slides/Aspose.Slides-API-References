## DataLabelCollection::Hide() metoda

Ustaw etykietę danych jako ukrytą domyślnie, ustawiając wszystkie flagi Show*- (ShowValue, ...) właściwości DefaultDataLabelFormat na wartość false. IsVisible będzie false po tej operacji.

```cpp
void Aspose::Slides::Charts::DataLabelCollection::Hide() override
```

## Uwagi

Jeśli etykieta danych nie jest widoczna domyślnie (IsVisible jest false), możesz ustawić etykietę danych jako "widoczną domyślnie" ustawiając flagi Show*- (ShowValue, ...) właściwości DefaultDataLabelFormat na wartość true.
