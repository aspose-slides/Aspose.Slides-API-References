## DataLabelCollection::get_IsVisible() metoda


False oznacza, że etykieta danych nie jest domyślnie widoczna (a więc wszystkie flagi Show*-flags (ShowValue, ...) właściwości DefaultDataLabelFormat mają wartość false). Tylko do odczytu **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelCollection::get_IsVisible() override
```

## Uwagi


Jeśli etykieta danych jest domyślnie widoczna, możesz ukryć ją domyślnie przy użyciu metody [Hide()](../hide/). Ale jeśli etykieta danych nie jest domyślnie widoczna (IsVisible jest false), możesz uczynić etykietę danych „widoczną 
domyślnie” ustawiając flagi Show*-flags (ShowValue, ...) właściwości DefaultDataLabelFormat na stan true.
