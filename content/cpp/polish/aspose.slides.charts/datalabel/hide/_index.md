## DataLabel::Hide() metoda


Ustaw etykietę danych jako ukrytą, ustawiając wszystkie flagi Show*-flags (ShowValue, ...) w stan false. IsVisible będzie false po tym.

```cpp
void Aspose::Slides::Charts::DataLabel::Hide() override
```

## Uwagi


Jeśli etykieta danych nie jest widoczna (IsVisible jest false), możesz uczynić etykietę danych widoczną, ustawiając flagi Show*-flags (ShowValue, ...) w stan true.
