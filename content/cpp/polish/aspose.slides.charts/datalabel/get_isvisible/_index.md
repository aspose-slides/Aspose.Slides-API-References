## DataLabel::get_IsVisible() metoda

False oznacza, że etykieta danych nie jest widoczna (i dlatego wszystkie flagi Show*-flags (ShowValue, ...) są false). Tylko do odczytu **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabel::get_IsVisible() override
```

## Uwagi

Jeśli etykieta danych jest widoczna, możesz ją ukryć metodą [Hide()](../hide/). Ale jeśli etykieta danych nie jest widoczna (IsVisible jest false), możesz uczynić etykietę danych widoczną, ustawiając flagi Show*-flags (ShowValue, ...) w stan true.
