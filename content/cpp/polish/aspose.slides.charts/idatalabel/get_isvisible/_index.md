## IDataLabel::get_IsVisible() metoda


False oznacza, że etykieta danych nie jest widoczna (a więc wszystkie flagi Show* (ShowValue, ...) są false). Tylko do odczytu **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabel::get_IsVisible()=0
```

## Uwagi


Jeśli etykieta danych jest widoczna, możesz ukryć ją za pomocą metody [Hide()](../hide/). Jednak jeśli etykieta danych nie jest widoczna (IsVisible jest false), możesz uczynić etykietę danych widoczną, ustawiając flagi Show* (ShowValue, ...) na stan true.
