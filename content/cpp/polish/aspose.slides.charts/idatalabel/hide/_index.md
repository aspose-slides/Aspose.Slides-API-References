## IDataLabel::Hide() metoda


Ukryj etykietę danych, ustawiając wszystkie flagi Show*-flags (ShowValue, ...) na stan false. IsVisible będzie false po tym.

```cpp
virtual void Aspose::Slides::Charts::IDataLabel::Hide()=0
```

## Uwagi


Jeśli etykieta danych nie jest widoczna (IsVisible jest false), możesz uczynić ją widoczną, ustawiając flagi Show*-flags (ShowValue, ...) na stan true.
