## ChartShapeType enum

Reprezentuje kształt wykresu.

```cpp
enum class ChartShapeType
```

### Wartości

| Name | Value | Description |
| --- | --- | --- |
| NotDefined | -1 | [Chart](../chart/) kształt nie jest zdefiniowany. |
| Box | 0 | Określa, że wykres zostanie narysowany w kształcie pudełka. |
| Cone | 1 | Określa, że wykres ma być rysowany jako stożek, z podstawą stożka na podłodze i wierzchołkiem stożka na szczycie wskaźnika danych. |
| ConeToMax | 2 | Określa, że wykres ma być rysowany z odciętymi stożkami tak, że wierzchołek stożka odpowiada maksymalnej wartości danych. |
| Cylinder | 3 | Określa, że wykres ma być rysowany jako cylinder. |
| Pyramid | 4 | Określa, że wykres ma być rysowany jako prostokątna piramida, z podstawą piramidy na podłodze i wierzchołkiem piramidy na szczycie wskaźnika danych. |
| PyramidToMaximum | 5 | Określa, że wykres ma być rysowany z odciętymi stożkami tak, że wierzchołek stożka odpowiada maksymalnej wartości danych. |
