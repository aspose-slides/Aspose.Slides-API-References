## IMathPhantom::set_Transp(bool) metoda


Ustawia wartość wskazującą, czy phantom jest przezroczysty dla reguł odstępów opartych na klasach.

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_Transp(bool value)=0
```

## Uwagi


Gdy **true**, operatory i symbole wewnątrz phantom nadal wpływają na odstępy matematyczne wokół phantom (tak jakby były widoczne). Gdy **false**, reguły odstępów oparte na klasach są ignorowane. Odpowiada atrybutowi OMML **m:transp**.
