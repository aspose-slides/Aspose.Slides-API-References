## IMathPhantom::get_ZeroWidth() metoda

Zwraca wartość wskazującą, czy szerokość elementu bazowego powinna być traktowana jako zero.

```cpp
virtual bool Aspose::Slides::MathText::IMathPhantom::get_ZeroWidth()=0
```

Gdy **true**, fantom nie rezerwuje poziomej przestrzeni dla swojego elementu bazowego. Odpowiada atrybutowi OMML **m:zeroWid**.
