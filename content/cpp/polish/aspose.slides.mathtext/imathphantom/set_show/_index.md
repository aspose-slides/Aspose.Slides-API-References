## IMathPhantom::set_Show(bool) metoda

Ustawia wartość określającą, czy element bazowy jest wyświetlany.

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_Show(bool value)=0
```

## Uwagi

Gdy **false**, element bazowy jest ukryty, ale może nadal zajmować miejsce w zależności od innych ustawień phantom. Odpowiada atrybutowi OMML **m:show**.
