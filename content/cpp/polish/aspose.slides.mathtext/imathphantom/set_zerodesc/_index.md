## IMathPhantom::set_ZeroDesc(bool) metoda


Ustawia wartość wskazującą, czy zstąpienie (głębokość poniżej linii bazowej) elementu bazowego ma być traktowane jako zero.

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_ZeroDesc(bool value)=0
```

## Uwagi


Gdy **true**, phantom nie obniża linii bazowej otaczającej linii matematycznej. Odpowiada atrybutowi OMML **m:zeroDesc**.
