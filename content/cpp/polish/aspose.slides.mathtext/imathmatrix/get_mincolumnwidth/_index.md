## IMathMatrix::get_MinColumnWidth() metoda


Minimalna szerokość kolumny w twipsach (1/20 części punktu) Odstęp (również określany jako \\u201CColumn Gap\\u201D lub \\u201CGap Width\\u201D) jest dodawany do MinColumnWidth, aby określić całkowity Matrix [Column](../../../aspose.slides/column/) Spacing (odległość między tymi samymi krawędziami różnych kolumn). Domyślnie: 0.

```cpp
virtual uint32_t Aspose::Slides::MathText::IMathMatrix::get_MinColumnWidth()=0
```

## Uwagi


Przykład: 
```cpp
auto matrix = System::MakeObject<MathMatrix>(2, 3);
matrix->set_MinColumnWidth(20);
```
