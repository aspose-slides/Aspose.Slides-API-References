## MathPhantom::set_Transp(bool) metoda


Ustawia wartość określającą, czy fantom jest przezroczysty dla reguł odstępów opartych na klasie.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_Transp(bool value) override
```

## Uwagi


Gdy **true**, operatory i symbole wewnątrz fantomu nadal wpływają na odstępy matematyczne wokół fantomu (tak jakby były widoczne). Gdy **false**, reguły odstępów oparte na klasie są ignorowane. Odpowiada atrybutowi OMML **m:transp**.
