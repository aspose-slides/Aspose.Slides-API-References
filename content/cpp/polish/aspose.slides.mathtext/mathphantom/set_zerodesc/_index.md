## MathPhantom::set_ZeroDesc(bool) metoda

Ustawia wartość określającą, czy zstąpienie (głębokość poniżej linii bazowej) elementu bazowego powinno być traktowane jako zero.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_ZeroDesc(bool value) override
```

## Uwagi

Gdy **true**, fantom nie obniża linii bazowej otaczającej linii matematycznej. Odpowiada atrybutowi OMML **m:zeroDesc**.
