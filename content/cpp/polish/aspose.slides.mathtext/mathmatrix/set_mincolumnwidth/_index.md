## MathMatrix::set_MinColumnWidth(uint32_t) metoda


Minimalna szerokość kolumny w twipach (1/20 punktu) Odstęp (również określany jako \\u201CColumn Gap\\u201D lub \\u201CGap Width\\u201D) jest dodawany do MinColumnWidth, aby określić całkowity Matrix [Column](../../../aspose.slides/column/) Spacing (odległość między takimi samymi krawędziami różnych kolumn). Domyślnie: 0.

```cpp
void Aspose::Slides::MathText::MathMatrix::set_MinColumnWidth(uint32_t value) override
```

## Uwagi


Przykład: 
```cpp
auto matrix = System::MakeObject<MathMatrix>(2, 3);
matrix->set_MinColumnWidth(20);
```
