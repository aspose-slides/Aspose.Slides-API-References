## MathMatrix::get_MinColumnWidth() method


Minimalna szerokość kolumny w twipach (1/20 części punktu). Odstęp (zwany także \\u201CColumn Gap\\u201D lub \\u201CGap Width\\u201D) jest dodawany do MinColumnWidth, aby określić całkowite Matrix [Column](../../../aspose.slides/column/) Spacing (odległość między tymi samymi krawędziami różnych kolumn). Domyślnie: 0.

```cpp
uint32_t Aspose::Slides::MathText::MathMatrix::get_MinColumnWidth() override
```

## Uwagi


Przykład: 
```cpp
auto matrix = System::MakeObject<MathMatrix>(2, 3);
matrix->set_MinColumnWidth(20);
```
