## MathJustification enum

Określa justowanie akapitu matematycznego (ciągu przylegających wystąpień tekstu matematycznego w tym samym akapicie)

```cpp
enum class MathJustification
```

### Wartości

| Name | Value | Description |
| --- | --- | --- |
| LeftJustified | 1 | Wyrównaj tekst matematyczny do lewej |
| RightJustified | 2 | Wyrównaj tekst matematyczny do prawej |
| Centered | 3 | Wyrównaj tekst matematyczny do środka |
| CenteredAsGroup | 4 | Wyśrodkuj na stronie całą grupę bloków matematycznych jako jedną całość. Oznacza to, że wystąpienia tekstu matematycznego mogą być wyrównane względem siebie, ale cała grupa tekstu matematycznego jest wyśrodkowana jako całość. |
