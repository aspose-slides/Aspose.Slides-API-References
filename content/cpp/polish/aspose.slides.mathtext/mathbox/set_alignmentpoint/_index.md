## MathBox::set_AlignmentPoint(bool) metoda

Gdy true, ten emulator operatora pełni funkcję punktu wyrównania; oznacza to, że wyznaczone punkty wyrównania w innych równaniach mogą być z nim wyrównane. Domyślnie: false

```cpp
void Aspose::Slides::MathText::MathBox::set_AlignmentPoint(bool value) override
```

## Uwagi

Przykład: 
```cpp
auto box = System::MakeObject<MathematicalText>(u"==")->ToBox();
box->set_AlignmentPoint(true);
```
