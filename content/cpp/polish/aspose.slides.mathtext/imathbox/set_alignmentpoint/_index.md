## IMathBox::set_AlignmentPoint(bool) metoda

Gdy true, ten emulator operatora służy jako punkt wyrównania; to znaczy, wyznaczone punkty wyrównania w innych równaniach mogą być z nim wyrównane. Domyślnie: false

```cpp
virtual void Aspose::Slides::MathText::IMathBox::set_AlignmentPoint(bool value)=0
```

## Uwagi

Przykład: 
```cpp
auto box = System::MakeObject<MathematicalText>(u"==")->ToBox();
box->set_AlignmentPoint(true);
```
