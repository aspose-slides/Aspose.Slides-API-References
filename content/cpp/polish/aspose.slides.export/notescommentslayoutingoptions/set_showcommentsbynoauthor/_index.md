## NotesCommentsLayoutingOptions::set_ShowCommentsByNoAuthor(bool) metoda

Ustawia widoczność komentarzy, które nie mają autora. Jeśli true, komentarze będą wyświetlane. (Obowiązuje tylko, jeśli komentarze są wyświetlane).

```cpp
void Aspose::Slides::Export::NotesCommentsLayoutingOptions::set_ShowCommentsByNoAuthor(bool value)
```

## Uwagi

Domyślna wartość to **false**.
