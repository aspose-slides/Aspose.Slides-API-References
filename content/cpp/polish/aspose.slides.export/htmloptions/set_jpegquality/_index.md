## HtmlOptions::set_JpegQuality(uint8_t) metoda

Ustawia wartość określającą jakość obrazów JPEG wewnątrz dokumentu PDF. Zapisz **uint8_t**.

```cpp
void Aspose::Slides::Export::HtmlOptions::set_JpegQuality(uint8_t value) override
```

## Uwagi

Działa tylko wtedy, gdy dokument zawiera obrazy JPEG.

Użyj tej właściwości, aby odczytać lub ustawić jakość obrazów w dokumencie podczas zapisywania w formacie PDF. Wartość może wynosić od 0 do 100, gdzie 0 oznacza najgorszą jakość, ale maksymalną kompresję, a 100 oznacza najlepszą jakość, ale minimalną kompresję.

Domyślna wartość to **95**.
