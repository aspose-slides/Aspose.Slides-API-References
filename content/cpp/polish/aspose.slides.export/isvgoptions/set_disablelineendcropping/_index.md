## ISSVGOptions::set_DisableLineEndCropping(bool) metoda

SVG 1.1 nie posiada możliwości definiowania wcięć dla znaczników. [Aspose.Slides](../../../aspose.slides/) Silnik zapisu SVG ma obejście tego problemu: przycina koniec linii ze strzałką, tak aby linia nie nachodziła na znaczniki. Ta opcja wyłącza takie zachowanie. Zapisz **bool**.

```cpp
virtual void Aspose::Slides::Export::ISVGOptions::set_DisableLineEndCropping(bool value)=0
```
