## PdfOptions::set_RasterizeUnsupportedFontStyles(bool) metoda


Wskazuje, czy tekst powinien być rastrowany jako bitmapa i zapisywany do PDF, gdy czcionka nie obsługuje pogrubienia. To podejście może poprawić jakość tekstu w powstałym PDF dla niektórych czcionek. Zapisz **bool**.

```cpp
void Aspose::Slides::Export::PdfOptions::set_RasterizeUnsupportedFontStyles(bool value) override
```

## Uwagi


Domyślnie jest **false**.
