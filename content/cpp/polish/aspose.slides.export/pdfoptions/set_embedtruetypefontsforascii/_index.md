## PdfOptions::set_EmbedTrueTypeFontsForASCII(bool) method


Określa, czy [Aspose.Slides](../../../aspose.slides/) osadzi wspólne czcionki dla tekstu ASCII (zakres kodów 33..127). [Fonts](../../../aspose.slides/fonts/) dla kodów znaków większych niż 127 są zawsze osadzane. Lista wspólnych czcionek zawiera podstawowe 14 czcionek PDF oraz dodatkowe czcionki określone przez użytkownika. Zapisz **bool**.

```cpp
void Aspose::Slides::Export::PdfOptions::set_EmbedTrueTypeFontsForASCII(bool value) override
```

## Uwagi


Domyślnie jest **true**.
