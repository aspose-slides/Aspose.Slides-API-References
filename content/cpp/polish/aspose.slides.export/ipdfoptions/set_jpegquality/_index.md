## IPdfOptions::set_JpegQuality(uint8_t) metoda


Ustawia wartość określającą jakość obrazów JPEG wewnątrz dokumentu PDF. Zapisz **uint8_t**.

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_JpegQuality(uint8_t value)=0
```

## Uwagi


Ma wpływ tylko wtedy, gdy dokument zawiera obrazy JPEG.

Użyj tej właściwości, aby odczytać lub ustawić jakość obrazów wewnątrz dokumentu podczas zapisywania w formacie PDF. Wartość może wahać się od 0 do 100, gdzie 0 oznacza najgorszą jakość, ale maksymalną kompresję, a 100 oznacza najlepszą jakość, ale minimalną kompresję.

Domyślna wartość to **100**.
