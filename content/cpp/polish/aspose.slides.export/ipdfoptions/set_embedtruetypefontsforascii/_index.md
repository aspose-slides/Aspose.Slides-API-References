## IPdfOptions::set_EmbedTrueTypeFontsForASCII(bool) metoda


True, aby osadzić czcionki TrueType dla znaków ASCII 32-127. [Fonts](../../../aspose.slides/fonts/) dla kodów znaków większych niż 127 są zawsze osadzane. Zapisz **bool**.

virtual void Aspose::Slides::Export::IPdfOptions::set_EmbedTrueTypeFontsForASCII(bool value)=0
