## IPdfOptions::set_RasterizeUnsupportedFontStyles(bool) metoda

Określa, czy tekst powinien być rastrowany jako bitmapa i zapisywany do pliku PDF, gdy czcionka nie obsługuje pogrubienia. To podejście może poprawić jakość tekstu w powstającym pliku PDF dla niektórych czcionek. Zapisz **bool**.

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_RasterizeUnsupportedFontStyles(bool value)=0
```

## Uwagi

Domyślnie jest **false**.
