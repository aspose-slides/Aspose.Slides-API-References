## CompareOptions enum


[String](../../system/string/) opcje porównania.

```cpp
enum class CompareOptions : int32_t
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| None | 0 | Brak specjalnych opcji. |
| IgnoreCase | 1 | Ignoruj wielkość liter. |
| IgnoreNonSpace | 2 | Ignoruj znaki łączące nie zajmujące miejsca, np. diakrytyki. |
| IgnoreSymbols | 4 | Uwzględniaj spacje, znaki interpunkcyjne i podobne. |
| IgnoreKanaType | 8 | Ignoruj typ kana (japoński). |
| IgnoreWidth | 16 | Ignoruj szerokość znaków przy porównywaniu ciągów. |
| OrdinalIgnoreCase | 268435456 | Porównanie porządkowe z ignorowaniem różnicy wielkości liter. |
| StringSort | 536870912 | Użyj algorytmu sortowania ciągów do porównywania znaków. |
| Ordinal | 1073741824 | Porównaj kody UTF bezpośrednio przy pierwszym porównaniu. |
