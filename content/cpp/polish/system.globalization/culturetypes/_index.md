## CultureTypes enum


Culture categories bitmask entries.

```cpp
enum class CultureTypes : int32_t
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| NeutralCultures | 1 | Kultura, która jest specyficzna dla języka, ale nie dla kraju ani regionu. |
| SpecificCultures | 2 | Specyficzna dla kraju/regionu. |
| InstalledWin32Cultures | 4 | Kultury zainstalowane w systemie operacyjnym. |
| AllCultures | n/a | Wszystkie dostępne kultury. |
| UserCustomCulture | 8 | Kultury definiowane przez użytkownika. |
| ReplacementCultures | 16 | Zastępniki definiowane przez użytkownika dla istniejących kultur. |
| WindowsOnlyCultures | 32 | Przestarzałe. |
| FrameworkCultures | 64 | Przestarzałe. |
