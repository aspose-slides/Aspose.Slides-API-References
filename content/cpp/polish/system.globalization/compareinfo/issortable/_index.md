## CompareInfo::IsSortable(char16_t) metoda

Sprawdza, czy określony znak jest sortowalny.

```cpp
static bool System::Globalization::CompareInfo::IsSortable(char16_t ch)
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| ch | char16_t | Znak Unicode. |

### Wartość zwracana

Prawda, jeśli **ch** jest sortowalny; w przeciwnym razie fałsz.

## CompareInfo::IsSortable(const String\&) metoda

Sprawdza, czy określony ciąg znaków jest sortowalny.

```cpp
static bool System::Globalization::CompareInfo::IsSortable(const String &text)
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| text | const [String](../../../system/string/)\& | Ciąg znaków. |

### Wartość zwracana

Prawda, jeśli **text** nie jest pusty i wszystkie znaki w **text** są sortowalne; w przeciwnym razie fałsz.
