## Details_CultureNotFoundException klasa


CultureNotFoundException jest rzucany, gdy próbuje się utworzyć kulturę, która nie jest dostępna. Nigdy nie twórz ręcznie instancji tej klasy. Zamiast tego użyj klasy CultureNotFoundException. Nigdy nie otaczaj instancji klasy CultureNotFoundException w [System::SmartPtr](../../system/smartptr/).

```cpp
class Details_CultureNotFoundException : public System::Details_ArgumentException
```
