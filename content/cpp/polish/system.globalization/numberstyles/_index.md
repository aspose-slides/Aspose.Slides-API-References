## NumberStyles enum

Number style allowed when parsing.

```cpp
enum class NumberStyles : int32_t
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| None | 0 | Brak znaków niebędących cyframi. |
| AllowLeadingWhite | 1 | Zezwalaj na początkowe białe znaki. |
| AllowTrailingWhite | 2 | Zezwalaj na końcowe białe znaki. |
| AllowLeadingSign | 4 | Zezwalaj na znak na początku. |
| Integer | n/a | Domyślne formatowanie liczby całkowitej. |
| AllowTrailingSign | 8 | Zezwalaj na znak na końcu. |
| AllowParentheses | 16 | Zezwalaj na nawiasy dla wartości ujemnych. |
| AllowDecimalPoint | 32 | Zezwalaj na separator dziesiętny. |
| AllowThousands | 64 | Zezwalaj na separator grupy. |
| Number | n/a | Domyślny format liczby złożonej. |
| AllowExponent | 128 | Zezwalaj na znak wykładnika. |
| Float | n/a | Domyślny format liczby zmiennoprzecinkowej. |
| AllowCurrencySymbol | 256 | Zezwalaj na symbol waluty. |
| Currency | n/a | Domyślny format waluty. |
| Any | n/a | Zezwalaj na dowolny specyfikator formatu. |
| AllowHexSpecifier | 512 | Zezwalaj na liczby szesnastkowe. |
| HexNumber | n/a | Domyślny format liczby szesnastkowej. |
