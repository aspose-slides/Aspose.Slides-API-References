## TimeSpanStyles enum

Określa opcje formatowania, które dostosowują analizę ciągu znaków dla metod konwertujących tekstową reprezentację przedziału czasu na obiekt Timespan.

```cpp
enum class TimeSpanStyles : int32_t
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| None | 0 | Przedział czasu reprezentowany przez ciąg znaków inptut jest interpretowany jako ujemny tylko wtedy, gdy występuje znak minus. |
| AssumeNegative | 1 | Przedział czasu reprezentowany przez ciąg znaków inptut jest zawsze interpretowany jako ujemny. |
