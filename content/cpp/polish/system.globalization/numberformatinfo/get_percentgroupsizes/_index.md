## NumberFormatInfo::get_PercentGroupSizes() const metoda

Zwraca liczbę cyfr w grupie wartości procentowych.

```cpp
ArrayPtr<int> System::Globalization::NumberFormatInfo::get_PercentGroupSizes() const
```

### Wartość zwracana

[Array](../../../system/array/) liczb cyfr w grupie, od lewej do prawej; każdy element musi wynosić od 1 do 9, ostatni może być 0, co oznacza \"combine all\"; ostatni element powtarza się.
