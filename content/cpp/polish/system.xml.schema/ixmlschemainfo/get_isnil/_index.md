## IXmlSchemaInfo::get_IsNil() metoda


Zwraca wartość wskazującą, czy wartość tego zweryfikowanego węzła XML jest **nil**.

```cpp
virtual bool System::Xml::Schema::IXmlSchemaInfo::get_IsNil()=0
```
