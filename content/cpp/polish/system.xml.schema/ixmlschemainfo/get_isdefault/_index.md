## IXmlSchemaInfo::get_IsDefault() metoda

Zwraca wartość wskazującą, czy ten zweryfikowany węzeł XML został ustawiony jako wynik zastosowania wartości domyślnej podczas walidacji schematu XML [Schema](../../) Definition Language (XSD).

```cpp
virtual bool System::Xml::Schema::IXmlSchemaInfo::get_IsDefault()=0
```

### Wartość zwracana

**true** jeśli ten zweryfikowany węzeł XML został ustawiony jako wynik zastosowania wartości domyślnej podczas walidacji schematu; w przeciwnym razie **false**.
