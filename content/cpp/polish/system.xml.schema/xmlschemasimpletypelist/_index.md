## XmlSchemaSimpleTypeList klasa

class XmlSchemaSimpleTypeList : public System::Xml::Schema::XmlSchemaSimpleTypeContent

Obiekty tej klasy powinny być tworzone wyłącznie przy użyciu funkcji [System::MakeObject()](../../system/makeobject/).
