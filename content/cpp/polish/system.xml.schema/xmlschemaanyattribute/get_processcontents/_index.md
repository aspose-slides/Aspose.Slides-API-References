## XmlSchemaAnyAttribute::get_ProcessContents() metoda

Zwraca informacje o tym, jak aplikacja lub procesor XML powinien obsługiwać walidację dokumentów XML dla atrybutów określonych przez element **anyAttribute**.

```cpp
XmlSchemaContentProcessing System::Xml::Schema::XmlSchemaAnyAttribute::get_ProcessContents()
```

### Wartość zwracana

Jedna z wartości XmlSchemaContentProcessing. Jeśli nie określono atrybutu **processContents**, domyślną wartością jest **Strict**.
