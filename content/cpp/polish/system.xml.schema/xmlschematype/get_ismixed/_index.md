## XmlSchemaType::get_IsMixed() metoda


Zwraca wartość wskazującą, czy ten typ ma mieszany model treści. To wywołanie jest ważne tylko w typie złożonym.

```cpp
virtual bool System::Xml::Schema::XmlSchemaType::get_IsMixed()
```


### Wartość zwracana

**true** jeśli typ ma mieszany model treści; w przeciwnym razie **false**. Domyślnie **false**.
