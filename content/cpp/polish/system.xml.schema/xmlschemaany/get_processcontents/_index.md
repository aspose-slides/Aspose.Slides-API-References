## XmlSchemaAny::get_ProcessContents() metoda

Zwraca informacje o tym, jak aplikacja lub procesor XML powinien obsługiwać walidację dokumentów XML dla elementów określonych przez element **any**.

```cpp
XmlSchemaContentProcessing System::Xml::Schema::XmlSchemaAny::get_ProcessContents()
```

### Wartość zwracana

Jedna z wartości XmlSchemaContentProcessing. Jeśli atrybut **processContents** nie jest określony, domyślną wartością jest **Strict**.
