## XmlSchemaElement::get_IsAbstract() metoda


Zwraca informację wskazującą, czy element może być użyty w dokumencie instancji.

```cpp
bool System::Xml::Schema::XmlSchemaElement::get_IsAbstract()
```


### Wartość zwracana

Jeśli **true**, element nie może wystąpić w dokumencie instancji. Domyślną wartością jest **false**. Opcjonalny.
