## XmlSchemaSet::get_IsCompiled() metoda


Zwraca wartość określającą, czy schematy języka definicyjnego XML [Schema](../../) (XSD) w [XmlSchemaSet](../) zostały skompilowane.

```cpp
bool System::Xml::Schema::XmlSchemaSet::get_IsCompiled()
```


### Wartość zwracana

**true** jeśli schematy w [XmlSchemaSet](../) zostały skompilowane od ostatniego czasu, gdy schemat został dodany lub usunięty z [XmlSchemaSet](../); w przeciwnym razie **false**.
