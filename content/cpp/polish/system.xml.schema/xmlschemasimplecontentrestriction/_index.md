## XmlSchemaSimpleContentRestriction klasa


Reprezentuje element **restriction** dla prostych treści z XML [Schema](../) określony przez Konsorcjum World Wide [Web](../../system.web/) (W3C). Ta klasa może być używana do tworzenia typów prostych przez ograniczenie. Takie ograniczenia mogą być użyte do zawężenia zakresu wartości elementu do podzbioru wartości określonych w odziedziczonym typie prostym.

```cpp
class XmlSchemaSimpleContentRestriction : public System::Xml::Schema::XmlSchemaContent
```
