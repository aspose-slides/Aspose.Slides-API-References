## XmlSchemaComplexContent::get_IsMixed() metoda

Zwraca informacje określające, czy typ ma mieszany model zawartości.

```cpp
bool System::Xml::Schema::XmlSchemaComplexContent::get_IsMixed()
```

### Wartość zwracana

Jeśli ta wartość jest **true**, dane znakowe mogą występować pomiędzy elementami potomnymi typu złożonego (mieszany model zawartości). Domyślną wartością jest **false**. Opcjonalne.
