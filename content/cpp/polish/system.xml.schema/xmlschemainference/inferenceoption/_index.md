## InferenceOption enum

Wpływa na informacje o występowaniu i typie, które są wyprowadzane przez klasę [XmlSchemaInference](../) dla elementów i atrybutów w dokumencie XML.

```cpp
enum class InferenceOption
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| Restricted | 0 | Wskazuje, że dla konkretnego elementu lub atrybutu powinno zostać wywnioskowane bardziej restrykcyjne zadeklarowanie schematu. |
| Relaxed | 1 | Wskazuje, że dla konkretnego elementu lub atrybutu powinno zostać wywnioskowane mniej restrykcyjne zadeklarowanie schematu. |
