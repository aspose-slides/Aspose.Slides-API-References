## XmlSchemaComplexType::get_IsAbstract() metoda


Zwraca informację określającą, czy element **complexType** może być używany w dokumencie instancji.

```cpp
bool System::Xml::Schema::XmlSchemaComplexType::get_IsAbstract()
```


### Wartość zwracana

Jeśli **true**, element nie może używać tego elementu **complexType** bezpośrednio i musi używać typu złożonego, który jest pochodną tego elementu **complexType**. Domyślnie jest **false**. Opcjonalne.
