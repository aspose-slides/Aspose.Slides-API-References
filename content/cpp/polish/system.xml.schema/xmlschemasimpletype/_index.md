## XmlSchemaSimpleType klasa

Reprezentuje element **simpleType** dla prostych treści z XML [Schema](../) określony przez World Wide [Web](../../system.web/) Consortium (W3C). Ta klasa definiuje prosty typ. Proste typy mogą określać informacje i ograniczenia dla wartości atrybutów lub elementów o treści wyłącznie tekstowej.

```cpp
class XmlSchemaSimpleType : public System::Xml::Schema::XmlSchemaType
```
