## EnumeratorSelectManyAdapter::MoveNext() metoda

Przesuwa enumerator do następnego elementu. Jeśli żaden element nie był wcześniej odwoływany, ustawia referencję na pierwszy dostępny element. Jeśli osiągnięto koniec kontenera, nie robi nic.

```cpp
bool System::Collections::Generic::Details::EnumeratorSelectManyAdapter<Source, Result>::MoveNext() override
```

### Wartość zwracana

True, jeśli po wywołaniu dostępny jest element, w przeciwnym razie false.
