## EnumeratorCastAdapter::MoveNext() metoda


Przesuwa enumerator do następnego elementu. Jeśli żaden element nie był wcześniej odwołany, ustawia odwołanie na pierwszy dostępny element. Jeśli osiągnięto koniec kontenera, nie wykonuje żadnej operacji.

```cpp
bool System::Collections::Generic::Details::EnumeratorCastAdapter<Source, Result>::MoveNext() override
```


### Wartość zwracana

True jeśli po wywołaniu dostępny jest jakikolwiek element, false w przeciwnym razie.
