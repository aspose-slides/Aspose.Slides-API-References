## EnumeratorOfTypeAdapter::MoveNext() metoda


Przesuwa wylicznik do następnego elementu. Jeśli żaden element nie był wcześniej odwoływany, ustawia odwołanie na pierwszy dostępny element. Jeśli osiągnięto koniec kontenera, nie robi nic.

```cpp
bool System::Collections::Generic::Details::EnumeratorOfTypeAdapter<Source, Result>::MoveNext() override
```


### Wartość zwracana

true, jeśli po wywołaniu dostępny jest jakiś element, false w przeciwnym razie.
