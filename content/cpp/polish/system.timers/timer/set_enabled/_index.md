## Timer::set_Enabled(bool) metoda

Uruchamia lub zatrzymuje timer. Uruchomienie timera nie resetuje odliczania czasu, jeśli timer jest już w trakcie działania.

```cpp
void System::Timers::Timer::set_Enabled(bool value)
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| value | **bool** | true aby uruchomić timer, false aby zatrzymać. |
