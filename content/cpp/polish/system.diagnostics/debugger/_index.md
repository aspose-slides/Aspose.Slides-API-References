## Debugger struktura


[Debugger](./) interfejs. To jest typ statyczny bez usług instancji. Nie należy tworzyć jego instancji w żaden sposób.

```cpp
class Debugger
```

## Metody

| Metoda | Opis |
| --- | --- |
| static void [Break](./break/)() | Inicjuje przerwanie debuggera (jeśli podłączony). |
| static **bool** [get_IsAttached](./get_isattached/)() | Sprawdza, czy debugger jest podłączony do bieżącej instancji aplikacji. |
