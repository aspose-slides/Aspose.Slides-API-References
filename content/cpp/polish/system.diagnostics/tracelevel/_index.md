## TraceLevel enum

Określa, które komunikaty mają być wyświetlane dla klas [System.Diagnostics.Debug](../debug/), [System.Diagnostics.Trace](../trace/) i System.Diagnostics.TraceSwitch.

```cpp
enum class TraceLevel
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| Off | 0 | Nie wyświetla żadnych komunikatów śledzenia i debugowania. |
| Error | 1 | Wyświetla komunikaty obsługi błędów. |
| Warning | 2 | Wyświetla ostrzeżenia i komunikaty obsługi błędów. |
| Info | 3 | Wyświetla komunikaty informacyjne, ostrzeżenia oraz komunikaty obsługi błędów. |
| Verbose | 4 | Wyświetla wszystkie komunikaty debugowania i śledzenia. |
