## Stopwatch klasa

Umożliwia pomiar czasu. Obiekty tej klasy powinny być alokowane wyłącznie przy użyciu [System::MakeObject()](../../system/makeobject/) funkcji. Nigdy nie twórz instancji tego typu na stosie ani przy użyciu operatora new, ponieważ spowoduje to błędy wykonania i/lub błędy asercji. Zawsze otaczaj tę klasę [System::SmartPtr](../../system/smartptr/) wskaźnikiem i używaj tego wskaźnika do przekazywania go do funkcji jako argument.

```cpp
class Stopwatch : public System::Object
```
