## Stopwatch::get_ElapsedMilliseconds() const metoda


Zwraca całkowity upłynięty czas mierzony przez bieżącą instancję, w milisekundach.

```cpp
int64_t System::Diagnostics::Stopwatch::get_ElapsedMilliseconds() const
```


### Wartość zwracana

Liczba całkowita reprezentująca łączną liczbę milisekund zmierzoną przez bieżącą instancję.
