## StringCollection::crbegin() const metoda

Zwraca odwrotny iterator do pierwszego elementu odwróconego kontenera. Odpowiada to ostatniemu elementowi nieodwróconego kontenera. Jeśli kontener jest pusty, zwrócony iterator jest równy [crend()](../crend/).

```cpp
const_reverse_iterator System::Collections::Specialized::StringCollection::crbegin() const noexcept
```

### Wartość zwracana

Iterator wskazujący na ostatni element kontenera oznaczony const.
