## StringCollection::crend() const method


Zwraca iterator odwrócony do elementu następującego po ostatnim elemencie odwróconego kontenera. Odpowiada elementowi poprzedzającemu pierwszy element nieodwróconego kontenera. Ten element pełni rolę symbolu zastępczego; próba jego odczytu skutkuje niezdefiniowanym zachowaniem.

```cpp
const_reverse_iterator System::Collections::Specialized::StringCollection::crend() const noexcept
```


### Wartość zwracana

Iterator wskazujący na teoretyczny element const-kwalifikowany poprzedzający pierwszy element kontenera.
