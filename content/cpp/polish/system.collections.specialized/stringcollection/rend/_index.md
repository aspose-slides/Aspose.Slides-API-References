## StringCollection::rend() metoda


Zwraca odwrócony iterator do elementu następującego po ostatnim elemencie odwróconego kontenera. Odpowiada on elementowi poprzedzającemu pierwszy element nieodwróconego kontenera. Ten element pełni rolę zastępczą; próba jego odczytu skutkuje niezdefiniowanym zachowaniem.

```cpp
reverse_iterator System::Collections::Specialized::StringCollection::rend() noexcept
```


### Wartość zwracana

Iterator wskazujący teoretyczny element poprzedzający pierwszy element kontenera.
