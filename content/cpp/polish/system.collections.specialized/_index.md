## Klasy

| Klasa | Opis |
| --- | --- |
| [BitVector32](./bitvector32/) | Udostępnia prosty lekki wektor bitowy z łatwym dostępem całkowitoliczbowym lub [Boolean](../system/boolean/) do 32-bitowego magazynu. |
| [NameValueCollection](./namevaluecollection/) | Kolekcja powiązanych kluczy [String](../system/string/) i wartości [String](../system/string/), które mogą być dostępne zarówno za pomocą klucza, jak i indeksu. |
| [StringCollection](./stringcollection/) | Indeksowana lista ciągów znaków. Obiekty tej klasy powinny być alokowane wyłącznie przy użyciu funkcji [System::MakeObject()](../system/makeobject/). Nigdy nie twórz instancji tego typu na stosie ani przy użyciu operatora new, ponieważ spowoduje to błędy czasu wykonywania i/lub awarie asercji. Zawsze opakowuj tę klasę w wskaźnik [System::SmartPtr](../system/smartptr/) i używaj tego wskaźnika do przekazywania jej do funkcji jako argumentu. |
| [StringCollectionPtr](./stringcollectionptr/) | Kolekcja wskaźników ciągów znaków z operatorem dostępu. |
| [StringDictionary](./stringdictionary/) | [String](../system/string/) do słownika ciągów znaków. Obiekty tej klasy powinny być alokowane wyłącznie przy użyciu funkcji [System::MakeObject()](../system/makeobject/). Nigdy nie twórz instancji tego typu na stosie ani przy użyciu operatora new, ponieważ spowoduje to błędy czasu wykonywania i/lub awarie asercji. Zawsze opakowuj tę klasę w wskaźnik [System::SmartPtr](../system/smartptr/) i używaj tego wskaźnika do przekazywania jej do funkcji jako argumentu. |

## Funkcje

| Funkcja | Opis |
| --- | --- |
| **bool** [operator==](./operator_equal_equal/)(**BitVector32::Section**, **BitVector32::Section**) | Sprawdza, czy dwa określone obiekty są równe. |
| **bool** [operator!=](./operator_not_equal/)(**BitVector32::Section**, **BitVector32::Section**) | Sprawdza, czy dwa określone obiekty nie są równe. |
