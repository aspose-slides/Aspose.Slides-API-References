## System::Greater(const ExpressionT\&, const ConstantT\&) funkcja

Implementuje translację wzorca relacyjnego '>'.

```cpp
template<class ExpressionT,class ConstantT> bool System::Greater(const ExpressionT &left, const ConstantT &constant)
```

### Parametry szablonu

| Parametr | Opis |
| --- | --- |
| ExpressionT | typ wyrażenia po lewej stronie. |
| ConstantT | typ wyrażenia stałej. |

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| left | const ExpressionT\& | wyrażenie, które zostanie sprawdzone. |
| constant | const ConstantT\& | wyrażenie, z którym porównywane jest lewe. |

### Wartość zwracana

true jeśli sprawdzanie typu zakończy się pomyślnie, false w przeciwnym razie.
