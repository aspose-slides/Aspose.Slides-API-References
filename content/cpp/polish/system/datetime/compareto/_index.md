## DateTime::CompareTo(DateTime) const metoda

Porównuje dwie wartości daty i czasu reprezentowane przez bieżący obiekt oraz określoną instancję klasy [DateTime](../) i zwraca wartość wskazującą względne pozycje wartości na osi czasu.

```cpp
constexpr int System::DateTime::CompareTo(DateTime value) const
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| value | [DateTime](../) | Instancja klasy [DateTime](../) do porównania z bieżącym obiektem |

### Wartość zwracana

Wartość mniejsza niż 0, jeśli bieżący obiekt reprezentuje wartość wcześniejszą niż ta reprezentowana przez **value**; 0, jeśli wartości reprezentowane przez oba obiekty są takie same; wartość większa niż 0, jeśli wartość reprezentowana przez bieżący obiekt jest późniejsza niż ta reprezentowana przez **value**.
