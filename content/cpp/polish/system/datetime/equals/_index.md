## DateTime::Equals(DateTime) const metoda

Określa, czy podana instancja klasy [DateTime](../) reprezentuje tę samą wartość daty i czasu co bieżący obiekt.

```cpp
constexpr bool System::DateTime::Equals(DateTime other) const
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| other | [DateTime](../) | Instancja klasy [DateTime](../) do porównania bieżącego obiektu |

### Wartość zwracana

Prawda, jeśli zarówno **other**, jak i bieżący obiekt reprezentują tę samą wartość, w przeciwnym razie - false

## DateTime::Equals(DateTime, DateTime) metoda

Określa, czy podane instancje klasy [DateTime](../) reprezentują tę samą wartość daty i czasu.

```cpp
static constexpr bool System::DateTime::Equals(DateTime t1, DateTime t2)
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| t1 | [DateTime](../) | Pierwszy porównywany |
| t2 | [DateTime](../) | Drugi porównywany |

### Wartość zwracana

Prawda, jeśli zarówno **t1**, jak i **t2** reprezentują tę samą wartość, w przeciwnym razie - false
