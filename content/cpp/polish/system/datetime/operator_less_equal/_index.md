## DateTime::operator<=(DateTime) const metoda

Określa, czy bieżący obiekt reprezentuje wartość daty i czasu, która jest wcześniejsza lub taka sama jak wartość reprezentowana przez określony [DateTime](../) obiekt.

```cpp
constexpr bool System::DateTime::operator<=(DateTime other) const
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| other | [DateTime](../) | [DateTime](../) obiekt do porównania z bieżącym obiektem |

### Wartość zwracana

True jeśli wartość daty i czasu reprezentowana przez bieżący obiekt jest wcześniejsza lub taka sama jak wartość reprezentowana przez **other**, w przeciwnym razie - false
