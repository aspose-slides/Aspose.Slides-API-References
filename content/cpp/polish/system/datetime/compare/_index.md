## DateTime::Compare(DateTime, DateTime) metoda

Porównuje dwie wartości reprezentowane przez określone instancje klasy [DateTime](../) i zwraca wartość wskazującą względne pozycje wartości na osi czasu.

```cpp
static constexpr int System::DateTime::Compare(DateTime t1, DateTime t2)
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| t1 | [DateTime](../) | Pierwszy porównywany |
| t2 | [DateTime](../) | Drugi porównywany |

### Wartość zwracana

Wartość mniejsza niż 0, jeśli **t1** jest wcześniejszy niż **t2**; 0, jeśli **t1** jest taki sam jak **t2**; wartość większa niż 0, jeśli **t1** jest późniejszy niż **t2**
