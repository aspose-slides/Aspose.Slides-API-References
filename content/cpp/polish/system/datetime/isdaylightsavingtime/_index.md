## DateTime::IsDaylightSavingTime() const metoda

Określa, czy wartość daty i czasu reprezentowana przez bieżący obiekt znajduje się w zakresie czasu letniego dla bieżącej strefy czasowej.

```cpp
bool System::DateTime::IsDaylightSavingTime() const
```

### Wartość zwracana

True jeśli wartość daty i czasu określona przez bieżący obiekt znajduje się w zakresie czasu letniego, w przeciwnym razie - false
