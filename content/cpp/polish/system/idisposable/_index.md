## IDisposable klasa

Definiuje metodę zwalniającą zasoby posiadane przez bieżący obiekt. Obiekty tej klasy powinny być alokowane wyłącznie przy użyciu funkcji [System::MakeObject()](../makeobject/). Nigdy nie twórz instancji tego typu na stosie ani przy pomocy operatora new, ponieważ spowoduje to błędy czasu wykonywania i/lub błędy asercji. Zawsze opakowuj tę klasę w wskaźnik [System::SmartPtr](../smartptr/) i używaj tego wskaźnika do przekazywania go jako argument do funkcji.

```cpp
class IDisposable : public virtual System::Object
```
