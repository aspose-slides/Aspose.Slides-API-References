## Environment::ExpandEnvironmentVariables(const String\&) metoda


Zastępuje nazwy zmiennych środowiskowych znalezione w podanym ciągu znaków wartościami tych zmiennych i zwraca wynikowy ciąg znaków.

```cpp
static String System::Environment::ExpandEnvironmentVariables(const String &name)
```


### Argumenty

| Parameter | Type | Description |
| --- | --- | --- |
| name | const [String](../../string/)\& | Ciąg znaków zawierający nazwy zmiennych środowiskowych |

### Wartość zwracana

Ciąg znaków będący wynikiem zastąpienia nazw zmiennych w **name** ich wartościami.
