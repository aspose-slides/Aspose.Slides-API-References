## Environment::get_UserInteractive() metoda

Określa, czy bieżący proces działa w trybie interaktywnym użytkownika.

```cpp
static bool System::Environment::get_UserInteractive()
```

### Wartość zwracana

True jeśli bieżący proces działa w trybie interaktywnym użytkownika, w przeciwnym razie - false
