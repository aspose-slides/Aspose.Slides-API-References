## Environment::get_Version() metoda

Zwraca obiekt [Version](../../version/) reprezentujący informacje o wersji środowiska uruchomieniowego języka wspólnego. Numer wersji zwracany przez tę metodę jest raczej fikcyjny i nie oznacza, że wszystkie klasy biblioteki zachowują się zgodnie z zwróconą wersją.

```cpp
static Version System::Environment::get_Version()
```
