## TimeSpan::operator>=(TimeSpan) const metoda

Określa, czy przedział czasu reprezentowany przez bieżący obiekt jest dłuższy niż lub równy przedziałowi czasu reprezentowanemu przez określony obiekt.

```cpp
constexpr bool System::TimeSpan::operator>=(TimeSpan value) const
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| value | [TimeSpan](../) | Obiekt [TimeSpan](../) do porównania z bieżącym obiektem |

### Wartość zwracana

True jeśli przedział czasu reprezentowany przez bieżący obiekt jest dłuższy niż lub równy przedziałowi czasu reprezentowanemu przez **value**, w przeciwnym razie - false
