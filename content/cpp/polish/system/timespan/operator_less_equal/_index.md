## TimeSpan::operator<=(TimeSpan) const metoda

Określa, czy przedział czasu reprezentowany przez bieżący obiekt jest krótszy niż lub równy przedziałowi czasu reprezentowanemu przez określony obiekt.

```cpp
constexpr bool System::TimeSpan::operator<=(TimeSpan value) const
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| value | [TimeSpan](../) | Obiekt [TimeSpan](../) do porównania bieżącego obiektu |

### Wartość zwracana

Prawda, jeśli przedział czasu reprezentowany przez bieżący obiekt jest krótszy niż lub równy przedziałowi czasu reprezentowanemu przez **value**, w przeciwnym razie - false
