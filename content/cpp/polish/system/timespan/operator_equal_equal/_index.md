## TimeSpan::operator==(TimeSpan) const metoda

Określa, czy przedział czasowy reprezentowany przez bieżący obiekt jest równy przedziałowi czasowemu reprezentowanemu przez określony obiekt.

```cpp
constexpr bool System::TimeSpan::operator==(TimeSpan value) const
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| value | [TimeSpan](../) | Obiekt [TimeSpan](../) do porównania z bieżącym obiektem |

### Wartość zwracana

true, jeśli bieżący obiekt i określony obiekt reprezentują ten sam przedział czasowy, w przeciwnym razie - false
