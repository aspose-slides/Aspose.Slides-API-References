## TimeSpan::Equals(TimeSpan) const metoda

```cpp
constexpr bool System::TimeSpan::Equals(TimeSpan value) const
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| value | [TimeSpan](../) | Obiekt [TimeSpan](../) służący do porównania bieżącego obiektu |

### Wartość zwracana
