## Guid::CompareTo(const Guid\&) const metoda


Wykonuje arytmetyczne porównanie identyfikatorów GUID reprezentowanych przez bieżący i określony obiekt.

```cpp
int System::Guid::CompareTo(const Guid &g) const
```


### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| g | const [Guid](../)\& | Porównywany element |

### Wartość zwracana

- 1 jeśli GUID reprezentowany przez bieżący obiekt jest mniejszy niż GUID reprezentowany przez **g**; 0 jeśli GUIDy są równe; 1 jeśli GUID reprezentowany przez bieżący obiekt jest większy niż GUID reprezentowany przez **g**
