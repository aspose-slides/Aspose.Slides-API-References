## Decimal::operator!=(const Decimal\&) const metoda


Określa, czy wartości reprezentowane przez bieżący obiekt i określony obiekt nie są równe.

```cpp
bool System::Decimal::operator!=(const Decimal &d) const
```


### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| d | const [Decimal](../)\& | Obiekt [Decimal](../) do porównania bieżącego obiektu |

### Wartość zwracana

true, jeśli wartość reprezentowana przez bieżący i określony obiekt nie jest równa, w przeciwnym razie - false

## Decimal::operator!=(std::nullptr_t) const metoda


Określa, czy wartość reprezentowana przez bieżący obiekt jest różna od 0.

```cpp
bool System::Decimal::operator!=(std::nullptr_t) const
```


### Wartość zwracana

true, jeśli wartość reprezentowana przez bieżący obiekt jest różna od 0, w przeciwnym razie - false
