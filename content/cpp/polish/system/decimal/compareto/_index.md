## Decimal::CompareTo(const Decimal\&) const metoda

Określa, czy wartość reprezentowana przez bieżący obiekt jest mniejsza, równa lub większa od wartości reprezentowanej przez określony obiekt.

```cpp
int System::Decimal::CompareTo(const Decimal &d) const
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| d | const [Decimal](../)\& | Porównywany |

### Wartość zwracana

- 1 jeśli wartość reprezentowana przez bieżący obiekt jest mniejsza od wartości reprezentowanej przez **d**; 0 jeśli wartości są równe; 1 jeśli wartość reprezentowana przez bieżący obiekt jest większa od wartości reprezentowanej przez **d**
