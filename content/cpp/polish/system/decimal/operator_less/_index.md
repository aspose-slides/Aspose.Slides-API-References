## Decimal::operator<(const Decimal\&) const metoda

Określa, czy wartość reprezentowana przez bieżący obiekt jest mniejsza od wartości reprezentowanej przez określony obiekt.

```cpp
bool System::Decimal::operator<(const Decimal &d) const
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| d | const [Decimal](../)\& | Obiekt [Decimal](../) do porównania bieżącego obiektu |

### Wartość zwracana

True jeśli wartość reprezentowana przez bieżący obiekt jest mniejsza od wartości reprezentowanej przez **d**, w przeciwnym razie - false
