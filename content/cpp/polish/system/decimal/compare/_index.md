## Decimal::Compare(const Decimal\&, const Decimal\&) metoda

Określa, czy wartość reprezentowana przez pierwszy obiekt [Decimal](../) jest mniejsza, równa lub większa niż wartość reprezentowana przez drugi obiekt [Decimal](../).

```cpp
static int System::Decimal::Compare(const Decimal &d1, const Decimal &d2)
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| d1 | const [Decimal](../)\& | Pierwszy porównywany |
| d2 | const [Decimal](../)\& | Drugi porównywany |

### Wartość zwracana

- 1 jeśli wartość reprezentowana przez **d1** jest mniejsza niż wartość reprezentowana przez **d2**; 0 jeśli wartości są równe; 1 jeśli wartość reprezentowana przez **d1** jest większa niż wartość reprezentowana przez **d2**
