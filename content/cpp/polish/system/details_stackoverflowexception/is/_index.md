```cpp
bool System::Details_StackOverflowException::Is(const System::TypeInfo &target) const override
```


### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struktura opisująca typ, względem którego testowany jest bieżący obiekt. |

### Wartość zwracana

## Uwagi


Sprawdź, czy obiekt jest instancją typu opisanego przez targetType. Odpowiednik operatora 'is' w C#.
