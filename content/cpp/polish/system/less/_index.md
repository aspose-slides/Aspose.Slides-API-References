## System::Less(const ExpressionT\&, const ConstantT\&) funkcja


Implementuje translację wzorca relatywnego '<'.

```cpp
template<class ExpressionT,class ConstantT> bool System::Less(const ExpressionT &left, const ConstantT &constant)
```


### Parametry szablonu

| Parametr | Opis |
| --- | --- |
| ExpressionT | typ wyrażenia po lewej. |
| ConstantT | typ wyrażenia stałej. |

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| left | const ExpressionT\& | wyrażenie, które zostanie sprawdzone. |
| constant | const ConstantT\& | wyrażenie, które zostanie porównane z lewym. |

### Wartość zwracana

true jeśli sprawdzenie typu zakończy się pomyślnie, false w przeciwnym razie.
