## ICloneable klasa


Definiuje metodę umożliwiającą klonowanie obiektów – tworzenie kopii obiektu. Obiekty tej klasy powinny być alokowane wyłącznie przy użyciu funkcji [System::MakeObject()](../makeobject/). Nigdy nie twórz instancji tego typu na stosie ani przy użyciu operatora new, ponieważ spowoduje to błędy czasu wykonywania i/lub awarie asercji. Zawsze owiń tę klasę wskaźnikiem [System::SmartPtr](../smartptr/) i używaj tego wskaźnika jako argumentu w funkcjach.

```cpp
class ICloneable : public virtual System::Object
```
