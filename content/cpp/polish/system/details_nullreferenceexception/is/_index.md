## Szczegóły_NullReferenceException::Is(const System::TypeInfo\&) const metoda




```cpp
bool System::Details_NullReferenceException::Is(const System::TypeInfo &target) const override
```


### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struktura opisująca typ, względem którego testowany jest bieżący obiekt. |

### Wartość zwracana

True jeśli obiekt jest typu oznaczonego lub jego podklasy, false w przeciwnym razie.
## Uwagi


Sprawdź, czy obiekt reprezentuje instancję typu opisanego przez targetType. Analog operatora 'is' w C#.
