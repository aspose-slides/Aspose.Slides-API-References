## System::LEqual(const ExpressionT\&, const ConstantT\&) funkcja

Implementuje tłumaczenie wzorca relatywnego '<='.

```cpp
template<class ExpressionT,class ConstantT> bool System::LEqual(const ExpressionT &left, const ConstantT &constant)
```

### Parametry szablonu

| Parametr | Opis |
| --- | --- |
| ExpressionT | typ wyrażenia po lewej stronie. |
| ConstantT | typ wyrażenia stałej. |

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| left | const ExpressionT\& | wyrażenie, które zostanie sprawdzone. |
| constant | const ConstantT\& | wyrażenie, które zostanie porównane z lewym. |

### Wartość zwracana

true jeśli sprawdzenie typu zakończy się powodzeniem, false w przeciwnym razie.
