## SmartPtr::get_shared_count() const metoda


Zwraca liczbę wskaźników współdzielonych istniejących do referencjonowanego obiektu, włącznie z bieżącym. Potwierdza, że bieżący wskaźnik znajduje się w trybie współdzielonym.

```cpp
int System::SmartPtr<T>::get_shared_count() const
```


### Wartość zwracana

Liczba wskaźników współdzielonych istniejących do referencjonowanego obiektu, jeśli istnieją. Jeśli wskaźnik jest nullem, zwraca 0.
