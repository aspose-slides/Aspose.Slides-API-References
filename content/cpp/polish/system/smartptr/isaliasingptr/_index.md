## SmartPtr::IsAliasingPtr() const metoda

Sprawdza, czy wskaźnik wskazuje na inny obiekt niż własny (utworzony przez konstruktor aliasujący).

```cpp
bool System::SmartPtr<T>::IsAliasingPtr() const
```

### Wartość zwracana

True jeśli wskaźnik wskazuje na inny obiekt niż własny, false w przeciwnym razie.
