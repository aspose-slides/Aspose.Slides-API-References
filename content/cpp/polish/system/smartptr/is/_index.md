## SmartPtr::Is(const System::TypeInfo\&) const metoda

Sprawdza, czy wskazany obiekt jest określonego typu lub jego typem podrzędnym. Odzwierciedla semantykę operatora C# 'is'.

```cpp
bool System::SmartPtr<T>::Is(const System::TypeInfo &target) const
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | Określa typ docelowy, względem którego wykonywane jest sprawdzenie. |

### Wartość zwracana

True jeśli sprawdzenie w stylu C# 'is' jest pozytywne, a false w przeciwnym przypadku.
