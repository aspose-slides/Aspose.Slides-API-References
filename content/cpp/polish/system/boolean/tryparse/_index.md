## Boolean::TryParse(const String\&, bool\&) metoda

Konwertuje podany ciąg znaków na wartość typu bool.

```cpp
static bool System::Boolean::TryParse(const String &value, bool &result)
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| value | const [String](../../string/)\& | Ciąg znaków do konwersji. |
| result | **bool**\& | Odniesienie do zmiennej typu bool, w której umieszczany jest wynik konwersji; wynik jest true, jeśli podany ciąg jest równy \"True\" i false, jeśli podany ciąg jest równy \"False\". |

### Wartość zwracana

True, jeśli podany ciąg jest równy \"True\" lub \"False\", w przeciwnym razie - false.
