## Boolean::Parse(const String\&) metoda

Konwertuje podany ciąg znaków na wartość typu bool.

```cpp
static bool System::Boolean::Parse(const String &value)
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| value | const [String](../../string/)\& | Ciąg znaków do konwersji. |

### Wartość zwracana

Zmienna typu bool, w której umieszczany jest wynik konwersji; wynik jest true, jeśli podany ciąg jest równy "True" i false, jeśli podany ciąg jest równy "False".
