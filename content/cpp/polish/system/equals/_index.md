## System::Equals(const TA\&, const TB\&) funkcja

Określa równość dwóch wartości stosując [operator==()](../operator_equal_equal/) do nich.

```cpp
template<typename TA,typename TB> bool System::Equals(const TA &a, const TB &b)
```

### Parametry szablonu

| Parametr | Opis |
| --- | --- |
| TA | Typ pierwszego porównywanego elementu |
| TB | Typ drugiego porównywanego elementu |

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| a | const TA\& | Pierwszy porównywany element |
| b | const TB\& | Drugi porównywany element |

### Wartość zwracana

Wartość logiczna zwrócona przez [operator==()](../operator_equal_equal/) zastosowaną do **a** i **b**
