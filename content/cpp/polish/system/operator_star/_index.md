## System::operator*(const T\&, const Decimal&) funkcja

Zwraca nową instancję klasy [Decimal](../decimal/), która reprezentuje wartość będącą wynikiem mnożenia podanej wartości i wartości reprezentowanej przez podany obiekt [Decimal](../decimal/).

```cpp
template<typename T,typename _> Decimal System::operator*(const T &x, const Decimal &d)
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| x | const T\& | Pierwszy mnożnik |
| d | const [Decimal](../decimal/)\& | Obiekt [Decimal](../decimal/) reprezentujący drugi mnożnik |

### Wartość zwracana

Nowa instancja klasy [Decimal](../decimal/), która reprezentuje wartość będącą wynikiem mnożenia **x** i wartości reprezentowanej przez **d**.
