## Details_MethodAccessException::Is(const System::TypeInfo\&) const metoda

```cpp
bool System::Details_MethodAccessException::Is(const System::TypeInfo &target) const override
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struktura opisująca typ, wobec którego testowany jest bieżący obiekt. |

### Wartość zwracana

True, jeśli obiekt jest oznaczonym typem lub jego podklasą, w przeciwnym razie false.

## Uwagi

Sprawdza, czy obiekt jest instancją typu opisanego przez targetType. Odpowiednik operatora 'is' w C#.
