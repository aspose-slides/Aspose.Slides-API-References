## String::IsNull() const method


Sprawdza, czy ciąg jest uznawany za null. [String](../) jest null i tylko wtedy, gdy został skonstruowany przy użyciu konstruktora [String()](../string/), przeniesiony, skopiowany lub przypisany z null ciągiem lub wywołano metodę [reset()](../reset/).

```cpp
bool System::String::IsNull() const
```


### Wartość zwracana

true, jeśli ciąg jest uznawany za null, false w przeciwnym razie.
