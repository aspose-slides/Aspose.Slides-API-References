## String::rend() const metoda

Zwraca odwrócony iterator do pozycji przed pierwszym znakiem (jeśli istnieje) aktualnego bufora ciągu znaków.

```cpp
reverse_iterator System::String::rend() const
```

### Wartość zwracana

Odwrócony iterator do elementu poprzedzającego pierwszy znak aktualnego bufora ciągu znaków (jeśli istnieje) lub do elementu tuż przed przydzielonym buforem.
