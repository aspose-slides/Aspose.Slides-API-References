## String::operator==(const String&) const metoda

Operator porównania równości.

```cpp
bool System::String::operator==(const String &str) const
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| str | const [String](../)& | [String](../) do porównania z bieżącym. |

### Wartość zwracana

true, jeśli oba ciągi są null lub oba nie są null i są zgodne, w przeciwnym razie false.

## String::operator==(std::nullptr_t) const metoda

Sprawdza, czy ciąg jest null. Stosuje tę samą logikę co wywołanie [IsNull()](../isnull/).

```cpp
bool System::String::operator==(std::nullptr_t) const
```

### Wartość zwracana

true, jeśli ciąg jest null, w przeciwnym razie false.
