## String::end() const metoda

Zwraca wskaźnik do końca aktualnego bufora ciągu znaków. Nigdy nie alokuje ponownie niczego. Nie gwarantuje, że bufor jest zakończony znakiem null.

```cpp
const UChar * System::String::end() const
```

### Wartość zwracana

Wskaźnik do pierwszego elementu po aktualnym buforze ciągu znaków, zakończonego lub nie zakończonego znakiem null.
