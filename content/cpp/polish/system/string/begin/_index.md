## String::begin() const metoda


Zwraca wskaźnik na początek aktualnego bufora ciągu znaków. Nigdy nie przydziela ponownie pamięci. Nie gwarantuje, że bufor jest zakończony znakiem null.

```cpp
const UChar * System::String::begin() const
```


### Wartość zwracana

Wskaźnik na aktualny bufor ciągu znaków, zakończony znakiem null lub nie.
