## DateTimeOffset::Compare(const DateTimeOffset\&, const DateTimeOffset\&) metoda


Porównuje dwa obiekty [DateTimeOffset](../).

```cpp
static int System::DateTimeOffset::Compare(const DateTimeOffset &first, const DateTimeOffset &second)
```


### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| first | const [DateTimeOffset](../)\& | Pierwszy obiekt do porównania. |
| second | const [DateTimeOffset](../)\& | Drugi obiekt do porównania. |

### Wartość zwracana

- 1 - jeśli **first** jest wcześniejszy niż **second**, 1 - jeśli **first** jest późniejszy niż **second**, 0 - jeśli **first** jest równy **second**.
