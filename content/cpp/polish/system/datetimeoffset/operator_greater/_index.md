## DateTimeOffset::operator>(const DateTimeOffset\&) const metoda

Określa, czy bieżący obiekt reprezentuje wartość daty i czasu, która jest późniejsza niż wartość reprezentowana przez określony obiekt [DateTimeOffset](../).

```cpp
bool System::DateTimeOffset::operator>(const DateTimeOffset &other) const
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| other | const [DateTimeOffset](../)\& | Obiekt [DateTimeOffset](../) do porównania z bieżącym obiektem |

### Wartość zwracana

True jeśli wartość daty i czasu reprezentowana przez bieżący obiekt jest późniejsza niż wartość reprezentowana przez **other**, w przeciwnym razie - false
