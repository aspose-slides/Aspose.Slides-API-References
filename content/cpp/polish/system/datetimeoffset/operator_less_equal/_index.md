## DateTimeOffset::operator<=(const DateTimeOffset\&) const method


Określa, czy bieżący obiekt reprezentuje wartość daty i czasu, która jest wcześniejsza lub równa wartości reprezentowanej przez podany obiekt [DateTimeOffset](../).

```cpp
bool System::DateTimeOffset::operator<=(const DateTimeOffset &other) const
```



### Argumenty

| Parameter | Type | Description |
| --- | --- | --- |
| other | const [DateTimeOffset](../)\& | Obiekt [DateTimeOffset](../) służący do porównania z bieżącym obiektem |

### Wartość zwracana

True jeśli wartość daty i czasu reprezentowana przez bieżący obiekt jest wcześniejsza lub równa wartości reprezentowanej przez **other**, w przeciwnym razie - false
