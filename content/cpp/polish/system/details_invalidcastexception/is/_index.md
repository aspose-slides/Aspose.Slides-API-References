## Details_InvalidCastException::Is(const System::TypeInfo\&) const method




```cpp
bool System::Details_InvalidCastException::Is(const System::TypeInfo &target) const override
```


### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struktura opisująca typ, względem którego sprawdzany jest bieżący obiekt. |

### Wartość zwracana

True jeśli obiekt jest typu oznaczonego lub jego podklasą, false w przeciwnym razie.
## Uwagi


Sprawdza, czy obiekt jest instancją typu opisanego przez targetType. Analog operatora 'is' w C#.
