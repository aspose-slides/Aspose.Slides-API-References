## Uri::IsHexEncoding(const String\&, int32_t) metoda

Określa, czy znak w podanym ciągu znaków na określonej pozycji jest kodowany w systemie szesnastkowym.

```cpp
static bool System::Uri::IsHexEncoding(const String &pattern, int32_t index)
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| pattern | const [String](../../string/)\& | Ciąg znaków do sprawdzenia |
| index | **int32_t** | Pozycja znaku do przetestowania, liczona od zera |

### Wartość zwracana

True jeśli podany znak jest kodowany w systemie szesnastkowym, w przeciwnym razie - false
