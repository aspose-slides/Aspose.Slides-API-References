## Enum::Compare(E, T) metoda

Performs the arithmetic comparison of the values of the specified enumeration constants.

```cpp
template<typename T,typename _> static int System::Enum<E, Guard>::Compare(E a, T b)
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| a | E | Pierwszy operand |
| b | T | Drugi operand |

### Wartość zwracana

- 1 jeśli **a** jest mniejsze niż **b**; 0 jeśli wartości są równe; 1 jeśli **a** jest większe niż **b**
