## Enum::HasFlag(E, E) metoda


Określa, czy określone bity są ustawione w bitowej reprezentacji określonej wartości wyliczeniowej.

```cpp
static bool System::Enum<E, Guard>::HasFlag(E value, E mask)
```


### Argumenty

| Parameter | Type | Description |
| --- | --- | --- |
| value | E | The enum value to test |
| mask | E | The mask to check value's bits against |

### Wartość zwracana

True, jeśli bity ustawione w **mask** są również ustawione w **value**, w przeciwnym razie - false
