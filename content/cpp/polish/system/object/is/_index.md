```cpp
virtual bool System::Object::Is(const TypeInfo &targetType) const
```


### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| targetType | const [TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struktura opisująca typ, względem którego testowany jest bieżący obiekt. |
