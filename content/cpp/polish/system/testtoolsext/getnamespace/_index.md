## TestToolsExt::GetNamespace(const char *, const char *, std::string\&) metoda

Retrieves namespace of specified test.

```cpp
static bool System::TestToolsExt::GetNamespace(const char *class_name, const char *method_name, std::string &name_space)
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| class_name | const char * | Klasa, której należy szukać. |
| method_name | const char * | Metoda, której należy szukać. |
| name_space | std::string\& | Zmienna, do której należy wstawić nazwę przestrzeni nazw, jeśli zostanie znaleziona. |

### Wartość zwracana

True jeśli metoda testowa zostanie znaleziona, false w przeciwnym razie.
