## IConvertible::ToByte(System::SharedPtr\<System::IFormatProvider\>) metoda


Konwertuje wartość tej instancji na równoważną 8-bitową liczbę całkowitą uint32_teger przy użyciu określonych informacji o formatowaniu zależnym od kultury.

```cpp
virtual uint8_t System::IConvertible::ToByte(System::SharedPtr<System::IFormatProvider> provider)=0
```


### Argumenty

| Parameter | Type | Description |
| --- | --- | --- |
| provider | [System::SharedPtr](../../sharedptr/)\<[System::IFormatProvider](../../iformatprovider/)\> | Implementacja interfejsu [System::IFormatProvider](../../iformatprovider/) dostarczająca informacje o formatowaniu zależnym od kultury. |

### Wartość zwracana

8-bitowa liczba całkowita bez znaku będąca równoważna wartości tej instancji.
