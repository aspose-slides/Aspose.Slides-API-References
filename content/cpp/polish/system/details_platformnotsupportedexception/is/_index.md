## Details_PlatformNotSupportedException::Is(const System::TypeInfo\&) const method




```cpp
bool System::Details_PlatformNotSupportedException::Is(const System::TypeInfo &target) const override
```


### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struktura opisująca typ, przeciwko któremu ma być sprawdzany bieżący obiekt. |

### Wartość zwracana

True jeśli obiekt jest typu oznaczonego lub jego podklasy, false w przeciwnym razie.

## Uwagi

Sprawdź, czy obiekt jest instancją typu opisanego przez targetType. Odpowiednik operatora 'is' w C#.
