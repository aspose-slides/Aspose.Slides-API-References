## Char::IsLowSurrogate(const char_t *, int) metoda


Określa, czy znak znajdujący się pod podanym indeksem w określonym buforze znaków jest niskim surrogatem.

```cpp
static bool System::Char::IsLowSurrogate(const char_t *str, int idx)
```


### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| str | const char_t * | Wskaźnik na początek bufora znaków |
| idx | int | Indeks zerowy w określonym buforze znaku do przetestowania |

### Wartość zwracana

True jeśli znak pod podanym indeksem jest niskim surrogatem, w przeciwnym razie - false
