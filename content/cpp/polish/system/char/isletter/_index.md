## Char::IsLetter(const char_t *, int) metoda


Określa, czy znak znajdujący się pod określonym indeksem w podanym buforze znaków jest klasyfikowany jako litera Unicode.

```cpp
static bool System::Char::IsLetter(const char_t *str, int idx)
```


### Argumenty

| Parameter | Type | Description |
| --- | --- | --- |
| str | const char_t * | Wskaźnik na początek bufora znaków |
| idx | int | Indeks zaczynający się od zera w określonym buforze, wskazujący znak do przetestowania |

### Wartość zwracana

True jeśli znak pod określonym indeksem jest literą Unicode, w przeciwnym razie - false
