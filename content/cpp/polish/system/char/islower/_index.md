## Char::IsLower(const char_t *, int) metoda


Określa, czy znak pod określonym indeksem w podanym buforze znaków jest klasyfikowany jako mała litera.

```cpp
static bool System::Char::IsLower(const char_t *str, int idx)
```


### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| str | const char_t * | Wskaźnik na początek bufora znaków |
| idx | int | Indeks zero-bazowy w podanym buforze znaku do przetestowania |

### Wartość zwracana

True, jeśli znak pod podanym indeksem jest małą literą, w przeciwnym razie - false
