## Char::IsPunctuation(const char_t *, int) metoda


Określa, czy znak pod określonym indeksem w podanym buforze znaków jest sklasyfikowany jako znak interpunkcyjny.

```cpp
static bool System::Char::IsPunctuation(const char_t *str, int idx)
```


### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| str | const char_t * | Wskaźnik do początku bufora znaków |
| idx | int | Indeks zerowy w określonym buforze dla znaku do przetestowania |

### Wartość zwracana

True jeśli znak pod określonym indeksem jest znakiem interpunkcyjnym, w przeciwnym razie - false
