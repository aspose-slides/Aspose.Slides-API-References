## Char::IsUpper(const String\&, int) metoda


Określa, czy znak znajdujący się pod określonym indeksem w podanym ciągu jest klasyfikowany jako wielka litera.

```cpp
static bool System::Char::IsUpper(const String &str, int idx)
```


### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| str | const [String](../../string/)\& | Ciąg zawierający znak. |
| idx | int | Indeks zerowy w podanym ciągu do sprawdzenia |

### Wartość zwracana

True jeśli znak pod określonym indeksem jest wielką literą, w przeciwnym razie - false
