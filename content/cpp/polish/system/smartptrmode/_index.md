## SmartPtrMode enum

```cpp
enum class SmartPtrMode : char
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| Shared | 0 | Shared mode: wskaźnik bierze udział w liczeniu odwołań. |
| Weak | 1 | Weak mode: wskaźnik nie uczestniczy w liczeniu odwołań. |
