## System::GEqual(const ExpressionT\&, const ConstantT\&) funkcja

Implementuje tłumaczenie wzorca relacji '>='.

```cpp
template<class ExpressionT,class ConstantT> bool System::GEqual(const ExpressionT &left, const ConstantT &constant)
```

### Parametry szablonu

| Parametr | Opis |
| --- | --- |
| ExpressionT | typ wyrażenia po lewej. |
| ConstantT | typ wyrażenia stałego. |

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| left | const ExpressionT\& | wyrażenie, które będzie sprawdzane. |
| constant | const ConstantT\& | wyrażenie, które będzie porównane z lewym wyrażeniem. |

### Wartość zwracana

true jeśli sprawdzanie typu zakończy się sukcesem, false w przeciwnym razie.
