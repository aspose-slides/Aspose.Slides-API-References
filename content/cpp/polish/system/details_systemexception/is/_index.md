## Szczegóły_SystemException::Is(const System::TypeInfo\&) const method




```cpp
bool System::Details_SystemException::Is(const System::TypeInfo &target) const override
```


### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struktura opisująca typ, z którym testowany jest bieżący obiekt. |

### Wartość zwracana

True, jeśli obiekt jest typem oznaczonym lub jego podklasą, false w przeciwnym razie.
## Uwagi

Sprawdź, czy obiekt reprezentuje instancję typu opisanego przez targetType. Analog operatora 'is' w C#.
