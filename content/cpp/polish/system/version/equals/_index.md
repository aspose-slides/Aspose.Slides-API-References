## Version::Equals(const Version\&) const metoda

```cpp
bool System::Version::Equals(const Version &ver) const
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| ver | const [Version](../)\& | Obiekt [Version](../) służący do porównania z bieżącym obiektem |

### Wartość zwracana

True jeśli numery wersji reprezentowane przez bieżący obiekt i określony obiekt są równe, w przeciwnym razie - false
