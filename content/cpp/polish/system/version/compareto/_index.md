## Version::CompareTo(const Version\&) const metoda


Porównuje wersje reprezentowane przez bieżący obiekt i określony obiekt.

```cpp
int System::Version::CompareTo(const Version &ver) const
```


### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| ver | const [Version](../)\& | Obiekt [Version](../) do porównania z bieżącym obiektem |

### Wartość zwracana

- 1 jeśli numer wersji reprezentowany przez bieżący obiekt jest mniejszy niż ten reprezentowany przez **ver**; 0 jeśli numery wersji są równe; 1 jeśli numer wersji reprezentowany przez bieżący obiekt jest większy niż wartość reprezentowana przez **ver**
