## UriFormat enum

Specifies how the URI is escaped.

```cpp
enum class UriFormat
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| UriEscaped | 1 | Kodowanie zgodnie z RFC-2396. |
| Unescaped | 2 | Brak kodowania. |
| SafeUnescaped | 3 | Tylko znaki, które mają zarezerwowane znaczenie w URI, są kodowane. |
