## Range::Equals(const Range\&) const metoda

Określa, czy bieżący zakres jest równy określonemu zakresowi.

```cpp
bool System::Range::Equals(const Range &other) const
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| other | const [Range](../)\& | Zakres, z którym należy porównać. |

### Wartość zwracana

True jeśli oba zakresy mają te same indeksy początkowe i końcowe, w przeciwnym razie false.
