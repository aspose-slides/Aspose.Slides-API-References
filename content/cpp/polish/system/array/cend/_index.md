## Array::cend() const metoda

Zwraca iterator do elementu następującego po ostatnim elemencie kontenera. Ten element pełni rolę symbolicznego wskaźnika; próba jego odczytu powoduje niezdefiniowane zachowanie.

```cpp
const_iterator System::Array<T>::cend() const noexcept
```

### Wartość zwracana

Iterator wskazujący na teoretyczny element oznaczony jako const, umieszczony po ostatnim elemencie kontenera.
