## Array::crend() const metoda


Zwraca odwrócony iterator do elementu następującego po ostatnim elemencie odwróconego kontenera. Odpowiada elementowi poprzedzającemu pierwszy element nieodwróconego kontenera. Ten element pełni rolę symbolicznego elementu, a próba jego dostępu skutkuje niezdefiniowanym zachowaniem.

```cpp
const_reverse_iterator System::Array<T>::crend() const noexcept
```


### Wartość zwracana

Iterator wskazujący na teoretyczny const-qualified element poprzedzający pierwszy element kontenera.
