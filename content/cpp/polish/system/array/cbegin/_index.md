## Array::cbegin() const metoda


Zwraca iterator do pierwszego elementu const-qualified w kontenerze. Jeśli kontener jest pusty, zwrócony iterator będzie równy [cend()](../cend/).

```cpp
const_iterator System::Array<T>::cbegin() const noexcept
```


### Wartość zwracana

Iterator wskazujący na pierwszy element const-qualified w kontenerze.
