## Array::rend() metoda


Zwraca iterator odwrotny do elementu następującego po ostatnim elemencie odwróconego kontenera. Odnosi się do elementu poprzedzającego pierwszy element nieodwróconego kontenera. Ten element pełni rolę znacznika; próba jego odczytu skutkuje niezdefiniowanym zachowaniem.

```cpp
reverse_iterator System::Array<T>::rend() noexcept
```


### Wartość zwracana

Iterator wskazujący na teoretyczny element poprzedzający pierwszy element kontenera.
