## Array::Resize(ArrayPtr\<Type\>\&, int) metoda

Zmienia rozmiar określonej tablicy na podaną wartość lub tworzy nową tablicę o określonym rozmiarze.

```cpp
template<typename Type> static void System::Array<T>::Resize(ArrayPtr<Type> &arr, int new_size)
```


### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| arr | [ArrayPtr](../../arrayptr/)\<[Type](../../object/type/)\>\& | [Array](../) aby zmienić rozmiar. Jeśli **arr** jest wskaźnikiem pustym, nowa tablica zostanie utworzona |
| new_size | int | Nowy rozmiar tablicy lub rozmiar nowej tablicy, gdy **arr** jest null |
