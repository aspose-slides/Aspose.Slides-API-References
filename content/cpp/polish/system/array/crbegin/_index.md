## Array::crbegin() const metoda

Zwraca iterator odwrócony wskazujący na pierwszy element odwróconego kontenera. Odpowiada on ostatniemu elementowi nieodwróconego kontenera. Jeśli kontener jest pusty, zwracany iterator jest równy [crend()](../crend/).

```cpp
const_reverse_iterator System::Array<T>::crbegin() const noexcept
```

### Wartość zwracana

Iterator wskazujący na ostatni element kontenera o kwalifikacji const.
