## StringComparison enum

Definiuje styl porównywania ciągów znaków.

```cpp
enum class StringComparison
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| CurrentCulture | 0 | Użyj bieżącej kultury. |
| CurrentCultureIgnoreCase | 1 | Użyj bieżącej kultury, ale ignoruj wielkość liter. |
| InvariantCulture | 2 | Użyj kultury niezmiennej. |
| InvariantCultureIgnoreCase | 3 | Użyj kultury niezmiennej, ale ignoruj wielkość liter. |
| Ordinal | 4 | Użyj reguł sortowania leksykalnego. |
| OrdinalIgnoreCase | 5 | Użyj reguł sortowania leksykalnego, ale ignoruj wielkość liter. |
