## Index::Equals(const Index\&) const metoda


Określa, czy bieżąca instancja i określony [Index](../) reprezentują tę samą pozycję.

```cpp
bool System::Index::Equals(const Index &other) const
```


### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| other | const [Index](../)\& | Indeks do porównania. |

### Wartość zwracana

True, jeśli oba indeksy mają tę samą wartość i kierunek, w przeciwnym razie false.
