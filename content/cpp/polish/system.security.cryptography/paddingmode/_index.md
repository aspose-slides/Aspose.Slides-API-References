## PaddingMode enum


Definiuje, jak traktować wiadomości, które są krótsze niż blok wymagany przez operację kryptograficzną.

```cpp
enum class PaddingMode
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| None | 1 | Brak wypełnienia. |
| PKCS7 | 2 | Użyj ciągu wypełniającego PKCS #7. |
| Zeros | 3 | Użyj zerowych bajtów. |
| ANSIX923 | 4 | Użyj ciągu wypełniającego ANSIX923. |
| ISO10126 | 5 | Użyj ciągu wypełniającego ISO10126. |
