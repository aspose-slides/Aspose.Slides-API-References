## SHA1CryptoServiceProvider klasa


[SHA1](../sha1/) implementacja CSP. Obiekty tej klasy powinny być przydzielane wyłącznie za pomocą funkcji [System::MakeObject()](../../system/makeobject/). Nigdy nie twórz instancji tego typu na stosie ani przy użyciu operatora new, ponieważ może to spowodować błędy czasu wykonania i/lub naruszenia asercji. Zawsze opakowuj tę klasę w wskaźnik [System::SmartPtr](../../system/smartptr/) i używaj tego wskaźnika jako argumentu funkcji.

```cpp
class SHA1CryptoServiceProvider : public System::Security::Cryptography::SHA1
```
