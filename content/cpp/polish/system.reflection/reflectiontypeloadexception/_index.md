## ReflectionTypeLoadException definicja typu

ReflectionTypeLoadException jest rzucany przez metodę Module.GetTypes, jeśli którakolwiek z klas w module nie zostanie załadowana. Nigdy nie owijaj instancji klasy ReflectionTypeLoadException w [System::SmartPtr](../../system/smartptr/).

```cpp
using System::Reflection::ReflectionTypeLoadException = typedef System::ExceptionWrapper<Details_ReflectionTypeLoadException>
```
