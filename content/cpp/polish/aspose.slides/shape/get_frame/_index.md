```cpp
System::SharedPtr<IShapeFrame> Aspose::Slides::Shape::get_Frame() override
```

## Uwagi

Wartość każdej właściwości zwróconego [IShapeFrame](../../ishapeframe/) nie jest niezdefiniowana (nie jest NaN ani NotDefined). Wartość każdej właściwości przypisanego [IShapeFrame](../../ishapeframe/) musi nie być niezdefiniowana (musi nie być NaN ani NotDefined). Można ustawiać niezdefiniowane wartości dla właściwości instancji RawFrame.
