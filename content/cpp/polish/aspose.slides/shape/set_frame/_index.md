## Uwagi


Wartość każdej właściwości zwróconej [IShapeFrame](../../ishapeframe/) instancji nie jest niezdefiniowana (nie jest NaN ani NotDefined). Wartość każdej właściwości przypisanej [IShapeFrame](../../ishapeframe/) instancji musi nie być niezdefiniowana (musi nie być NaN ani NotDefined). Można ustawiać niezdefiniowane wartości dla właściwości instancji RawFrame.
