## Shape::set_Rotation(float) metoda


Ustawia liczbę stopni, o które określony kształt jest obracany wokół osi Z. Wartość dodatnia oznacza obrót zgodny z ruchem wskazówek zegara; wartość ujemna oznacza obrót przeciwny do ruchu wskazówek zegara. Zapisz **float**.

```cpp
void Aspose::Slides::Shape::set_Rotation(float value) override
```

## Uwagi


Zwracana wartość jest zawsze określona (nie jest std::numeric_limits<float>::quiet_NaN()). Przypisana wartość musi być określona (nie std::numeric_limits<float>::quiet_NaN()). Można ustawić nieokreślone wartości dla właściwości instancji RawFrame.
