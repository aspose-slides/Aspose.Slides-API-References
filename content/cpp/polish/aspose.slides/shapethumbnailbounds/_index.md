## ShapeThumbnailBounds enum

Enumeration of types of shape thumbnail bounds.

```cpp
enum class ShapeThumbnailBounds
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| Slide | 0 | [Shape](../shape/) miniatura będzie mieć rozmiar równy rozmiarowi slajdu. [Shape](../shape/) pozycja zostanie zapisana. |
| Shape | 1 | [Shape](../shape/) miniatura będzie mieć rozmiar równy prostokątowi granic kształtu, uwzględniając ustawienia konturu kształtu. |
| Appearance | 2 | [Shape](../shape/) miniatura będzie mieć rozmiar równy wyglądowi kształtu (w granicach slajdu). Mogą wystąpić przypadki, gdy wygląd kształtu nie mieści się w granicach kształtu. Np. obrót, łączenie krawędzi pod ostrym kątem, efekty 3D, itp. |
