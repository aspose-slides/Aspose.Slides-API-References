## HyperlinkActionType enum

Represents a type of hyperlink action.

```cpp
enum class HyperlinkActionType
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| Unknown | -1 | Nierozpoznany typ działania. |
| NoAction | 0 | Brak działania. |
| Hyperlink | 1 | Standardowe hiperłącze. |
| JumpFirstSlide | 2 | Przejdź do pierwszego slajdu prezentacji. |
| JumpPreviousSlide | 3 | Przejdź do poprzedniego slajdu. |
| JumpNextSlide | 4 | Przejdź do następnego slajdu. |
| JumpLastSlide | 5 | Przejdź do ostatniego slajdu prezentacji. |
| JumpEndShow | 6 | Przejdź do końca pokazu slajdów. |
| JumpLastViewedSlide | 7 | Przejdź do ostatnio wyświetlanego slajdu. |
| JumpSpecificSlide | 8 | Przejdź do konkretnego slajdu, określonego przez wartość [IHyperlink::get_TargetSlide](../ihyperlink/get_targetslide/). |
| StartCustomSlideShow | 9 | Uruchom niestandardowy pokaz slajdów. |
| OpenFile | 10 | Otwórz odwołany plik. |
| OpenPresentation | 11 | Otwórz odwołaną prezentację. |
| StartStopMedia | 12 | Rozpocznij/zatrzymaj odtwarzanie pliku multimedialnego. |
| StartMacro | 13 | Rozpocznij wykonywanie skryptu makra. |
| StartProgram | 14 | Uruchom program. |
