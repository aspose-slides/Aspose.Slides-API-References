| Emf | 2 | Reprezentuje format obrazu rozszerzonego metafilu (EMF). |
| Wmf | 3 | Reprezentuje format obrazu metafilu Windows (WMF). |
| Gif | 4 | Reprezentuje format obrazu Graphics Interchange Format (GIF). |
| Jpeg | 5 | Reprezentuje format obrazu Joint Photographic Experts Group (JPEG). |
| Png | 6 | Reprezentuje format obrazu W3C Portable Network Graphics (PNG). |
| Tiff | 7 | Reprezentuje format obrazu Tagged Image File Format (TIFF). |
| Exif | 8 | Reprezentuje format Exchangeable Image File (Exif). |
| Icon | 9 | Reprezentuje format obrazu ikony Windows. |
