## LoadOptions::set_OnlyLoadDocumentProperties(bool) metoda

Ta właściwość ma sens, jeśli plik prezentacji jest chroniony hasłem. Wartość true oznacza, że z zaszyfrowanego pliku prezentacji należy załadować tylko właściwości dokumentu i zignorować hasło. Wartość false oznacza, że cała zaszyfrowana prezentacja musi zostać załadowana przy użyciu właściwego hasła. Jeśli prezentacja nie jest zaszyfrowana, wartość tej właściwości jest zawsze ignorowana. Jeśli właściwości dokumentu zaszyfrowanego pliku nie są publiczne i wartość właściwości jest true, właściwości dokumentu nie mogą być załadowane i zostanie zgłoszony wyjątek. Zapisz **bool**.

```cpp
void Aspose::Slides::LoadOptions::set_OnlyLoadDocumentProperties(bool value) override
```
