## LoadOptions::set_BlobManagementOptions(System::SharedPtr\<IBlobManagementOptions\>) metoda

Reprezentuje opcje, które mogą być użyte do zarządzania zachowaniem obsługi Binary Large Objects (BLOB) – np. używaniem plików tymczasowych lub maksymalną liczbą bajtów BLOB w pamięci. Opcje te mają na celu ustawienie najlepszego stosunku wydajności do zużycia pamięci dla konkretnego środowiska lub wymagań.

```cpp
void Aspose::Slides::LoadOptions::set_BlobManagementOptions(System::SharedPtr<IBlobManagementOptions> value) override
```

## Uwagi

Binary Large Object (BLOB) to dane binarne przechowywane jako pojedynczy byt – tj. BLOB może być samym dźwiękiem, wideo lub prezentacją.
