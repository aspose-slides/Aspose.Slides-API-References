## ISlideShowTransition::set_SoundIsBuiltIn(bool) metoda

Określa, czy ten dźwięk jest wbudowany. Jeśli atrybut ten ma wartość true, aplikacja generująca jest powiadamiana, aby sprawdzić atrybut name określony dla tego dźwięku na swojej liście wbudowanych dźwięków i może w razie potrzeby wyświetlić niestandardową nazwę lub UI. Zapisuje **bool**.

```cpp
virtual void Aspose::Slides::ISlideShowTransition::set_SoundIsBuiltIn(bool value)=0
```
