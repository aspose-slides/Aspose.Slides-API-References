## SensitivityLabelContentType enum

Reprezentuje typy oznaczania treści, które powinny być zastosowane w dokumencie.

```cpp
enum class SensitivityLabelContentType
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| None | 0 | Wskazuje, że etykieta jest zastosowana domyślnie lub automatycznie. |
| Header | 1 | Wskazuje, że etykieta została zastosowana ręcznie. Użyj dla dowolnej etykiety poufności, która została bezpośrednio zastosowana przez użytkownika. |
| Footer | 2 | Wskazuje, że etykieta została zastosowana ręcznie. Użyj dla dowolnej etykiety poufności, która została bezpośrednio zastosowana przez użytkownika. |
| Watermark | 4 | Wskazuje, że etykieta została zastosowana ręcznie. Użyj dla dowolnej etykiety poufności, która została bezpośrednio zastosowana przez użytkownika. |
| Encryption | 8 | Wskazuje, że etykieta została zastosowana ręcznie. Użyj dla dowolnej etykiety poufności, która została bezpośrednio zastosowana przez użytkownika. |
