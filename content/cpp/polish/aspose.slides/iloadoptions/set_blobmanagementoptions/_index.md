## ILoadOptions::set_BlobManagementOptions(System::SharedPtr\<IBlobManagementOptions\>) metoda

Reprezentuje opcje, które mogą być użyte do zarządzania zachowaniem obsługi Binary Large Objects (BLOBs), takimi jak użycie plików tymczasowych lub maksymalna liczba bajtów BLOBs w pamięci. Opcje te mają na celu ustawienie optymalnego stosunku wydajność/do zużycia pamięci dla konkretnego środowiska lub wymagań.

```cpp
virtual void Aspose::Slides::ILoadOptions::set_BlobManagementOptions(System::SharedPtr<IBlobManagementOptions> value)=0
```

## Uwagi

Binary Large Object (BLOB) to dane binarne przechowywane jako pojedynczy byt - np. BLOB może być dźwiękiem, wideo lub samą prezentacją.
