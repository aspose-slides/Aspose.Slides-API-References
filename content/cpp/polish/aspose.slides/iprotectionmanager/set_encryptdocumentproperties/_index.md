## IProtectionManager::set_EncryptDocumentProperties(bool) metoda

Ta właściwość ma sens, jeśli prezentacja jest zabezpieczona hasłem. Jeśli wartość jest true, to właściwości dokumentu są szyfrowane w pliku prezentacji. Jeśli wartość jest false, to właściwości dokumentu są publiczne, podczas gdy prezentacja jest szyfrowana. Zapisz **bool**.

virtual void Aspose::Slides::IProtectionManager::set_EncryptDocumentProperties(bool value)=0
