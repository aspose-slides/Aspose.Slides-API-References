## PathFillModeType enum

Określa sposób, w jaki ścieżka powinna być wypełniona

```cpp
enum class PathFillModeType : uint8_t
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| None | 0 | Brak wypełnienia ścieżki Określa, że odpowiednia ścieżka nie powinna mieć wypełnienia. |
| Normal | 1 | Normalne wypełnienie ścieżki Określa, że odpowiednia ścieżka powinna mieć normalnie zacieniony kolor zastosowany do it\\u2019s fill. |
| Lighten | 2 | Rozjaśnione wypełnienie ścieżki Określa, że odpowiednia ścieżka powinna mieć lekko zacieniony kolor zastosowany do it\\u2019s fill. |
| LightenLess | 3 | Mniej rozjaśnione wypełnienie ścieżki Określa, że odpowiednia ścieżka powinna mieć nieco jaśniejszy kolor zastosowany do it\\u2019s fill. |
| Darken | 4 | Ciemniejsze wypełnienie ścieżki Określa, że odpowiednia ścieżka powinna mieć ciemniejszy kolor zastosowany do it\\u2019s fill. |
| DarkenLess | 5 | Mniej ciemne wypełnienie ścieżki Określa, że odpowiednia ścieżka powinna mieć nieco ciemniejszy kolor zastosowany do it\\u2019s fill. |
