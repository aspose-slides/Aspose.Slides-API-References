## ICamera::GetRotation() metoda

Rotacja jest definiowana przy użyciu współrzędnej szerokości, współrzędnej długości oraz obrotu wokół osi jako współrzędnych szerokości i długości. pierwszy element w zwracanej tablicy - szerokość, drugi - długość, trzeci - obrót. Zwraca null, jeśli nie określono rotacji.

```cpp
virtual System::ArrayPtr<float> Aspose::Slides::ICamera::GetRotation()=0
```
