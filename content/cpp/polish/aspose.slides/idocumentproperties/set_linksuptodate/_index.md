## IDocumentProperties::set_LinksUpToDate(bool) metoda

Wskazuje, czy hiperłącza w dokumencie są aktualne. Ustaw ten element na **true**, aby wskazać, że hiperłącza są zaktualizowane. Ustaw ten element na **false**, aby wskazać, że hiperłącza są nieaktualne. Zapisz **bool**.

virtual void Aspose::Slides::IDocumentProperties::set_LinksUpToDate(bool value)=0
