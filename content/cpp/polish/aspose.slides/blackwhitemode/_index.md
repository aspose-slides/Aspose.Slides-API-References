## BlackWhiteMode enum

Określa, w jaki sposób kolorowy kształt powinien zostać przekształcony na czarno-biały.

```cpp
enum class BlackWhiteMode : int8_t
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| NotDefined | -1 | Właściwość nie jest ustawiona |
| Color | 0 | Obiekt jest renderowany z normalnym kolorowaniem |
| Automatic | 1 | Obiekt jest renderowany z automatycznym kolorowaniem |
| Gray | 2 | Obiekt jest renderowany z szarym kolorowaniem |
| LightGray | 3 | Obiekt jest renderowany z jasnoszarym kolorowaniem |
| InverseGray | 4 | Obiekt jest renderowany z odwróconym szarym kolorowaniem |
| GrayWhite | 5 | Obiekt jest renderowany z szarym i białym kolorowaniem |
| BlackGray | 6 | Obiekt jest renderowany z czarnym i szarym kolorowaniem |
| BlackWhite | 7 | Obiekt jest renderowany z czarnym i białym kolorowaniem |
| Black | 8 | Obiekt jest renderowany tylko z czarnym kolorowaniem |
| White | 9 | Obiekt jest renderowany z białym kolorowaniem |
| Hidden | 10 | Obiekt nie jest renderowany |
