## IShape::set_Frame(System::SharedPtr\<IShapeFrame\>) metoda

Ustawia właściwości ramki kształtu. Zapisz [IShapeFrame](../../ishapeframe/).

```cpp
virtual void Aspose::Slides::IShape::set_Frame(System::SharedPtr<IShapeFrame> value)=0
```

## Uwagi

Wartość każdej właściwości zwróconego [IShapeFrame](../../ishapeframe/) nie jest niezdefiniowana (nie jest NaN ani NotDefined). Wartość każdej właściwości przypisanego [IShapeFrame](../../ishapeframe/) musi nie być niezdefiniowana (musi nie być NaN ani NotDefined). Możesz ustawić niezdefiniowane wartości dla właściwości obiektu RawFrame.
