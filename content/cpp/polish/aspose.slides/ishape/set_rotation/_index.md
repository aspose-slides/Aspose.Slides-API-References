## IShape::set_Rotation(float) method


Ustawia liczbę stopni, o które określony kształt jest obrócony wokół osi z. Wartość dodatnia oznacza obrót zgodny z ruchem wskazówek zegara; wartość ujemna oznacza obrót przeciwny do ruchu wskazówek zegara. Zapisz **float**.

```cpp
virtual void Aspose::Slides::IShape::set_Rotation(float value)=0
```

## Uwagi


Zwracana wartość jest zawsze określona (nie jest std::numeric_limits<float>::quiet_NaN()). Przypisana wartość musi być określona (nie std::numeric_limits<float>::quiet_NaN()). Można ustawiać nieokreślone wartości dla właściwości instancji RawFrame.
