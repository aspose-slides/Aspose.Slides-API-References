## IShape::get_Frame() metoda


Zwraca właściwości ramki kształtu. Przeczytaj [IShapeFrame](../../ishapeframe/).

```cpp
virtual System::SharedPtr<IShapeFrame> Aspose::Slides::IShape::get_Frame()=0
```

## Uwagi


Wartość każdej właściwości zwróconego [IShapeFrame](../../ishapeframe/) nie jest niezdefiniowana (nie jest NaN ani NotDefined). Wartość każdej właściwości przypisanego [IShapeFrame](../../ishapeframe/) musi nie być niezdefiniowana (musi nie być NaN ani NotDefined). Możesz ustawić niezdefiniowane wartości dla właściwości instancji RawFrame.
