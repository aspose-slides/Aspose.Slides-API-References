## IShape::get_X() metoda


Pobiera współrzędną x lewego górnego rogu kształtu, mierzoną w punktach. Odczyt **float**.

```cpp
virtual float Aspose::Slides::IShape::get_X()=0
```

## Uwagi


Zwracana wartość jest zawsze określona i nigdy nie jest [std::numeric_limits<float>::quiet_NaN()](../). Przypisana wartość również musi być określona; przypisuj [std::numeric_limits<float>::quiet_NaN()](../) wyłącznie do właściwości instancji **RawFrame**.
