## InkEffectType enum

Określa zestaw predefiniowanych efektów wizualnych dla renderowania tuszu. Każdy efekt odpowiada teksturze lub obrazowi, który symuluje stylizowany wygląd tuszu. Te wartości mogą być użyte do dostosowania stylu wizualnego cyfrowych pociągnięć tuszu podczas renderowania.

```cpp
enum class InkEffectType
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| NotDefined | -1 | Efekt nie jest zdefiniowany lub jest nieznany. Ta wartość może być użyta jako domyślna lub zapasowa. |
| Bronze | 0 | Ciepła, brązowawa metaliczna tekstura przypominająca tusz w kolorze brązu. |
| Galaxy | 1 | Kolorowa, połyskująca tekstura przypominająca galaktykę, z kosmicznymi odcieniami. |
| Gold | 2 | Jasna, metaliczna złota tekstura, która nadaje pociągnięciom tuszu luksusowy wygląd. |
| Lava | 3 | Ognista tekstura przypominająca płynną lawę, z czerwonymi i pomarańczowymi odcieniami. |
| Ocean | 4 | Głęboki niebieski, płynna tekstura naśladująca fale oceanu lub tusz wodny. |
| RainbowGlitter | 5 | Kolorowy, błyszczący efekt tęczowego brokatu używany do świątecznych lub żywych pociągnięć tuszu. |
| RoseGold | 6 | Delikatna mieszanka różowego złota, podobna do różowego złota, dla eleganckich pociągnięć tuszu. |
| Silver | 7 | Chłodna, metaliczna srebrna tekstura symulująca klasyczny srebrny tusz. |
