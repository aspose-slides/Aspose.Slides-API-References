## XsltSettings::get_Default() metoda

Zwraca [XsltSettings](../) obiekt z domyślnymi ustawieniami. Obsługa funkcji **document()** XSLT i osadzonych bloków skryptów jest wyłączona.

```cpp
static SharedPtr<XsltSettings> System::Xml::Xsl::XsltSettings::get_Default()
```

### Wartość zwracana

Obiekt [XsltSettings](../) z opcjami [XsltSettings::set_EnableDocumentFunction](../set_enabledocumentfunction/) i [XsltSettings::set_EnableScript](../set_enablescript/) ustawionymi na **false**.
