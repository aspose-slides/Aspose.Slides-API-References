## XsltSettings::get_EnableDocumentFunction() metoda


Zwraca wartość określającą, czy włączyć obsługę funkcji XSLT **document()**.

```cpp
bool System::Xml::Xsl::XsltSettings::get_EnableDocumentFunction()
```


### Wartość zwracana

**true** aby obsługiwać funkcję XSLT **document()**; w przeciwnym razie **false**. Domyślnie jest **false**.
