## SoapHeaderDirection enum

Enumeruje kierunki nagłówka SOAP.

```cpp
enum class SoapHeaderDirection
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| In | 1 | Odbiorcą nagłówka SOAP jest usługa XML [Web](../../system.web/). |
| InOut | 3 | Odbiorcami nagłówka SOAP są zarówno usługa XML [Web](../../system.web/), jak i klient usługi XML [Web](../../system.web/). |
| Out | 2 | Odbiorcą nagłówka SOAP jest klient usługi XML [Web](../../system.web/). |
| Fault | 4 | Nagłówek SOAP jest wysyłany do klienta usługi XML [Web](../../system.web/), gdy metoda usługi XML [Web](../../system.web/) zgłasza wyjątek. |
