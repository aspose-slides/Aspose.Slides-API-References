## SoapDocumentServiceAttribute klasa

Ustawia domyślny format żądań i odpowiedzi SOAP. Obiekty tej klasy powinny być alokowane wyłącznie przy użyciu funkcji [System::MakeObject()](../../system/makeobject/). Nigdy nie twórz instancji tego typu na stosie ani przy użyciu operatora new, ponieważ spowoduje to błędy w czasie wykonywania i/lub błędy asercji. Zawsze otaczaj tę klasę wskaźnikiem [System::SmartPtr](../../system/smartptr/) i używaj tego wskaźnika do przekazywania go funkcjom jako argument.

```cpp
class SoapDocumentServiceAttribute : public System::Attribute
```
