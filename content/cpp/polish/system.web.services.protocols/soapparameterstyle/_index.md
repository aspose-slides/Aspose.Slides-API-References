## SoapParameterStyle enum

Wymienia formaty parametrów w wiadomości SOAP.

```cpp
enum class SoapParameterStyle
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| Default | 0 | Jeśli '[SoapDocumentServiceAttribute](../soapdocumentserviceattribute/)' nie jest zastosowane do klasy, to wartość domyślna to 'Wrapped'. |
| Bare | 1 | Parametry są umieszczane w elementach XML, które następują po elemencie 'Body'. |
| Wrapped | 2 | Parametry są zawarte w pojedynczym elemencie XML, który następuje po elemencie 'Body'. |
