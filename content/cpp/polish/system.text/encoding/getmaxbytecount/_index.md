## Encoding::GetMaxByteCount(int) metoda

Pobiera maksymalną liczbę bajtów potrzebnych do zakodowania określonej liczby znaków.

```cpp
virtual int System::Text::Encoding::GetMaxByteCount(int char_count)=0
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| char_count | int | Liczba znaków do zakodowania. |

### Wartość zwracana
