## XmlNodeChangedEventArgs::get_Action() metoda


Zwraca wartość wskazującą, jaki typ zdarzenia zmiany węzła ma miejsce.

```cpp
XmlNodeChangedAction System::Xml::XmlNodeChangedEventArgs::get_Action()
```


### Wartość zwracana

Jedna z wartości wyliczenia opisująca zdarzenie zmiany węzła. Wartość **Action** nie rozróżnia, kiedy zdarzenie wystąpiło (przed czy po). Można utworzyć osobne obsługiwacze zdarzeń, aby obsłużyć oba przypadki.
