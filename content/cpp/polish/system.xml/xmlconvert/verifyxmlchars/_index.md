## XmlConvert::VerifyXmlChars(const String\&) metoda


Zwraca przekazany ciąg znaków, jeśli wszystkie znaki oraz znaki par surrogatowych w argumencie ciągu są prawidłowymi znakami XML; w przeciwnym razie rzucany jest wyjątek XmlException z informacją o pierwszym napotkanym nieprawidłowym znaku.

```cpp
static String System::Xml::XmlConvert::VerifyXmlChars(const String &content)
```


### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| content | const [String](../../../system/string/)\& | [String](../../../system/string/) zawierający znaki do weryfikacji. |

### Wartość zwracana

Zwraca przekazany ciąg znaków, jeśli wszystkie znaki oraz znaki par surrogatowych w argumencie ciągu są prawidłowymi znakami XML; w przeciwnym razie rzucany jest wyjątek XmlException z informacją o pierwszym napotkanym nieprawidłowym znaku.
