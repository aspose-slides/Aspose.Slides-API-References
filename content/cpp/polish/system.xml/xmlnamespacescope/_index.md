## XmlNamespaceScope wyliczenie

Definiuje zakres przestrzeni nazw.

```cpp
enum class XmlNamespaceScope
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| All | 0 | Wszystkie przestrzenie nazw zdefiniowane w zakresie bieżącego węzła. Zawiera to przestrzeń nazw xmlns:xml, która zawsze jest zadeklarowana domyślnie. Kolejność zwróconych przestrzeni nazw nie jest określona. |
| ExcludeXml | 1 | Wszystkie przestrzenie nazw zdefiniowane w zakresie bieżącego węzła, z wyłączeniem przestrzeni nazw xmlns:xml, która zawsze jest zadeklarowana domyślnie. Kolejność zwróconych przestrzeni nazw nie jest określona. |
| Local | 2 | Wszystkie przestrzenie nazw, które są zdefiniowane lokalnie w bieżącym węźle. |
