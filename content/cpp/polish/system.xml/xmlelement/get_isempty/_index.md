## XmlElement::get_IsEmpty() metoda

Zwraca format tagu elementu.

```cpp
bool System::Xml::XmlElement::get_IsEmpty()
```

### Wartość zwracana

**true** jeśli element ma być serializowany w krótkim formacie tagu \"<tt><item/></tt>\"; **false** dla długiego formatu \"<tt><item></item></tt>\".
