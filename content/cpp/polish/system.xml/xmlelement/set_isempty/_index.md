## XmlElement::set_IsEmpty(bool) metoda

Ustawia format tagu elementu.

```cpp
void System::Xml::XmlElement::set_IsEmpty(bool value)
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| value | **bool** | Wartość do ustawienia. Podczas ustawiania tej wartości, jeśli zostanie ustawiona na **true**, potomkowie elementu zostają usunięci, a element jest serializowany w krótkim formacie tagu. Jeśli zostanie ustawiona na **false**, wartość jest zmieniana (niezależnie od tego, czy element ma zawartość); jeśli element jest pusty, jest serializowany w długim formacie. |
