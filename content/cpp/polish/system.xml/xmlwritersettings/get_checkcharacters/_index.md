## XmlWriterSettings::get_CheckCharacters() metoda


Zwraca wartość, która wskazuje, czy XML writer powinien sprawdzać, aby zapewnić, że wszystkie znaki w dokumencie spełniają sekcję \"2.2 Characters\" standardu W3C [XML 1.0 Recommendation](https://www.w3.org/TR/REC-xml/#charsets).

```cpp
bool System::Xml::XmlWriterSettings::get_CheckCharacters()
```


### Wartość zwracana

**true** aby przeprowadzić sprawdzanie znaków; w przeciwnym razie **false**. Domyślnie **true**.
