## XmlWriterSettings::get_NewLineChars() metoda

Zwraca ciąg znaków używany do podziału linii.

```cpp
String System::Xml::XmlWriterSettings::get_NewLineChars()
```

### Wartość zwracana

Ciąg znaków używany do podziału linii. Może być ustawiony na dowolną wartość tekstową. Jednak aby zapewnić poprawny XML, należy podawać wyłącznie prawidłowe znaki białe, takie jak spacje, tabulatory, powroty karetki lub znaki końca linii. Domyślnie jest to **\r\n** (powrót karetki, nowa linia).
