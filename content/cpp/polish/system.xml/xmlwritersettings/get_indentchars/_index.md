## XmlWriterSettings::get_IndentChars() metoda


Zwraca ciąg znaków używany przy wcięciach. To ustawienie jest używane, gdy wartość [XmlWriterSettings::set_Indent](../set_indent/) jest ustawiona na **true**.

```cpp
String System::Xml::XmlWriterSettings::get_IndentChars()
```


### Wartość zwracana

Ciąg znaków używany przy wcięciach. Może być ustawiony na dowolną wartość string. Jednakże, aby zapewnić poprawny XML, należy podawać tylko prawidłowe znaki białych odstępów, takie jak spacje, tabulatory, znaki powrotu karetki lub znaki nowej linii. Domyślnie są to dwa spacje.
