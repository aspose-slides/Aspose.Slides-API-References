## XmlWriterSettings::get_OmitXmlDeclaration() metoda


Zwraca wartość wskazującą, czy pominąć deklarację XML.

```cpp
bool System::Xml::XmlWriterSettings::get_OmitXmlDeclaration()
```


### Wartość zwracana

**true** aby pominąć deklarację XML; w przeciwnym razie **false**. Domyślnie jest **false**, deklaracja XML jest zapisywana.
