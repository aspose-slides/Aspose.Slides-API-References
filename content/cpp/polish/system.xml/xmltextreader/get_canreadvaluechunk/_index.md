## XmlTextReader::get_CanReadValueChunk() metoda


Zwraca wartość wskazującą, czy [XmlTextReader](../) implementuje metodę [XmlReader::ReadValueChunk](../../xmlreader/readvaluechunk/).

```cpp
bool System::Xml::XmlTextReader::get_CanReadValueChunk() override
```


### Wartość zwracana

**true**, jeśli [XmlTextReader](../) implementuje metodę [XmlReader::ReadValueChunk](../../xmlreader/readvaluechunk/); w przeciwnym razie **false**. Klasa [XmlTextReader](../) zawsze zwraca **false**.
