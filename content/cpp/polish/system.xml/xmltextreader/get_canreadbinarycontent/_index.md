## XmlTextReader::get_CanReadBinaryContent() metoda


Zwraca wartość wskazującą, czy [XmlTextReader](../) implementuje metody odczytu zawartości binarnej.

```cpp
bool System::Xml::XmlTextReader::get_CanReadBinaryContent() override
```


### Wartość zwracana

**true** jeśli metody odczytu zawartości binarnej są zaimplementowane; w przeciwnym razie **false**. Klasa [XmlTextReader](../) zawsze zwraca **true**.
