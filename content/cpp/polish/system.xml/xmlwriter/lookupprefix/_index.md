## XmlWriter::LookupPrefix(String) metoda


Gdy zostanie przesłonięta w klasie pochodnej, zwraca najbliższy prefiks zdefiniowany w bieżącym zakresie przestrzeni nazw dla namespace URI.

```cpp
virtual String System::Xml::XmlWriter::LookupPrefix(String ns)=0
```


### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| ns | [String](../../../system/string/) | Namespace URI, którego prefiks ma zostać znaleziony. |

### Wartość zwracana

Pasujący prefiks lub **nullptr**, jeśli w bieżącym zakresie nie zostanie znaleziona pasująca namespace URI.
