## XmlWriter::get_XmlSpace() metoda

Gdy zostanie przesłonięta w klasie pochodnej, zwraca XmlSpace reprezentujący bieżący zakres **xml:space**.

```cpp
virtual System::Xml::XmlSpace System::Xml::XmlWriter::get_XmlSpace()
```

### Wartość zwracana

XmlSpace reprezentujący bieżący zakres **xml:space**.

| Wartość | Znaczenie |
| --- | --- |
| `None`| To jest domyślne, jeśli nie istnieje zakres `xml:space`. |
| `Default`| Bieżący zakres to `xml:space="default"`. |
| `Preserve`| Bieżący zakres to `xml:space="preserve"`. |
