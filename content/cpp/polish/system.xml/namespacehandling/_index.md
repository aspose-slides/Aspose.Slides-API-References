## NamespaceHandling enum

Określa, czy usunąć duplikaty deklaracji namespace w [XmlWriter](../xmlwriter/).

```cpp
enum class NamespaceHandling
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| Default | 0 | Określa, że duplikaty deklaracji namespace nie będą usuwane. |
| OmitDuplicates | 1 | Określa, że duplikaty deklaracji namespace będą usuwane. Aby duplikat namespace został usunięty, prefiks i namespace muszą się zgadzać. |
