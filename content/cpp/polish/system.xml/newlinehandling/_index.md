## NewLineHandling enum

Określa, jak obsługiwać podziały wierszy.

```cpp
enum class NewLineHandling
```

### Values

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| Replace | 0 | Znaki nowej linii są zamieniane, aby pasowały do znaku określonego w wartości [XmlWriterSettings::set_NewLineChars](../xmlwritersettings/set_newlinechars/). |
| Entitize | 1 | Znaki nowej linii są przekształcane w encje. To ustawienie zachowuje wszystkie znaki, gdy wynik jest odczytywany przez normalizujący [XmlReader](../xmlreader/). |
| None | 2 | Znaki nowej linii pozostają niezmienione. Wynik jest taki sam jak wejście. |
