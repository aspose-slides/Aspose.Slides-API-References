## XmlValidatingReader::ReadString() metoda


Odczytuje zawartość elementu lub węzła tekstowego jako ciąg znaków.

```cpp
String System::Xml::XmlValidatingReader::ReadString() override
```


### Wartość zwracana

Zawartość elementu lub węzła tekstowego. Może to być pusty ciąg znaków, jeśli czytnik jest ustawiony na coś innego niż element lub węzeł tekstowy, lub jeśli nie ma więcej treści tekstowej do zwrócenia w bieżącym kontekście.
