## XmlValidatingReader::LookupNamespace(const String\&) metoda

Rozwiązuje prefiks przestrzeni nazw w zakresie bieżącego elementu.

```cpp
String System::Xml::XmlValidatingReader::LookupNamespace(const String &prefix) override
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| prefix | const [String](../../../system/string/)\& | Prefiks, którego Uniform Resource Identifier (URI) przestrzeni nazw chcesz rozwiązać. Aby dopasować domyślną przestrzeń nazw, przekaż pusty ciąg znaków. |

### Wartość zwracana

Identyfikator URI przestrzeni nazw, do którego mapuje prefiks, lub **nullptr**, jeśli nie znaleziono pasującego prefiksu.
