## XmlDocument::get_IsReadOnly() metoda


Zwraca wartość wskazującą, czy bieżący węzeł jest tylko do odczytu.

```cpp
bool System::Xml::XmlDocument::get_IsReadOnly() override
```


### Wartość zwracana

**true** jeśli bieżący węzeł jest tylko do odczytu; w przeciwnym razie **false**. [XmlDocument](../) węzły zawsze zwracają **false**.
