## XmlNode::GetPrefixOfNamespace(String) metoda

Wyszukuje najbliższą deklarację **xmlns** dla podanego URI przestrzeni nazw, która jest w zasięgu bieżącego węzła i zwraca prefiks określony w tej deklaracji.

```cpp
virtual String System::Xml::XmlNode::GetPrefixOfNamespace(String namespaceURI)
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| namespaceURI | [String](../../../system/string/) | URI przestrzeni nazw, którego prefiks chcesz znaleźć. |

### Wartość zwracana

Prefiks dla określonego URI przestrzeni nazw.
