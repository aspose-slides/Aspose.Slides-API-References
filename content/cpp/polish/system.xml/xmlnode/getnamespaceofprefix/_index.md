## XmlNode::GetNamespaceOfPrefix(String) metoda

Wyszukuje najbliższą deklarację **xmlns** dla podanego prefiksu, która jest w zasięgu bieżącego węzła i zwraca identyfikator URI przestrzeni nazw w deklaracji.

```cpp
virtual String System::Xml::XmlNode::GetNamespaceOfPrefix(String prefix)
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| prefix | [String](../../../system/string/) | Prefiks, którego identyfikatora URI przestrzeni nazw chcesz odnaleźć. |

### Wartość zwracana

Identyfikator URI przestrzeni nazw określonego prefiksu.
