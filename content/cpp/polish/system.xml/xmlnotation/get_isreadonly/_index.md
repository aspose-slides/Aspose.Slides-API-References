## XmlNotation::get_IsReadOnly() metoda


Zwraca wartość wskazującą, czy węzeł jest tylko do odczytu.

```cpp
bool System::Xml::XmlNotation::get_IsReadOnly() override
```


### Wartość zwracana

**true** jeśli węzeł jest tylko do odczytu; w przeciwnym razie **false**. Ponieważ węzły [XmlNotation](../) są tylko do odczytu, ta metoda zawsze zwraca **true**.
