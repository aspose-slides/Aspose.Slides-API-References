## XmlAttribute::get_Specified() metoda

Zwraca wartość wskazującą, czy wartość atrybutu została jawnie ustawiona.

```cpp
virtual bool System::Xml::XmlAttribute::get_Specified()
```

### Wartość zwracana

**true** jeśli ten atrybut został jawnie nadany wartość w oryginalnym dokumencie instancji; w przeciwnym razie **false**. Wartość **false** wskazuje, że wartość atrybutu pochodziła z DTD.
