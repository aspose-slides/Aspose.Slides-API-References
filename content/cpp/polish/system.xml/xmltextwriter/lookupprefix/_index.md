## XmlTextWriter::LookupPrefix(String) metoda

Zwraca najbliższy prefiks zdefiniowany w bieżącym zakresie przestrzeni nazw dla URI przestrzeni nazw.

```cpp
String System::Xml::XmlTextWriter::LookupPrefix(String ns) override
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| ns | [String](../../../system/string/) | URI przestrzeni nazw, którego prefiks chcesz znaleźć. |

### Wartość zwracana

Pasujący prefiks. Lub **nullptr**, jeśli w bieżącym zasięgu nie znaleziono pasującego URI przestrzeni nazw.
