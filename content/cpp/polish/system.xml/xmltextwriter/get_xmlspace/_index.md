## XmlTextWriter::get_XmlSpace() metoda


Zwraca obiekt XmlSpace reprezentujący bieżący **xml:space** zakres.

```cpp
System::Xml::XmlSpace System::Xml::XmlTextWriter::get_XmlSpace() override
```


### Wartość zwracana

Obiekt XmlSpace reprezentujący bieżący **xml:space** zakres.



| Wartość | Znaczenie |
| --- | --- |
| None | To jest wartość domyślna, jeśli nie istnieje zakres `xml:space`. |
| Default | Bieżący zakres to `xml:space="default"`. |
| Preserve | Bieżący zakres to `xml:space="preserve"`. |
