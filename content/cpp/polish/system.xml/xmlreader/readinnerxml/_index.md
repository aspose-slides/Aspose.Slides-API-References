## XmlReader::ReadInnerXml() metoda

Gdy zostanie nadpisana w klasie pochodnej, odczytuje całą zawartość, w tym znacznikowanie, jako ciąg znaków.

```cpp
virtual String System::Xml::XmlReader::ReadInnerXml()
```

### Wartość zwracana

Cała zawartość XML, w tym znacznikowanie, w bieżącym węźle. Jeśli bieżący węzeł nie ma dzieci, zwracany jest pusty ciąg znaków. Jeśli bieżący węzeł nie jest ani elementem, ani atrybutem, zwracany jest pusty ciąg znaków.
