## XmlReader::get_NamespaceURI() method


Gdy zostanie przesłonięta w klasie pochodnej, pobiera identyfikator URI przestrzeni nazw (zgodnie ze specyfikacją W3C Namespace) węzła, na którym znajduje się czytnik.

```cpp
virtual String System::Xml::XmlReader::get_NamespaceURI()=0
```


### Wartość zwracana

Identyfikator URI przestrzeni nazw bieżącego węzła; w przeciwnym razie pusty ciąg.
