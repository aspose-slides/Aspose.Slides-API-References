## XmlReader::ReadOuterXml() metoda


Gdy zostanie przesłonięta w klasie pochodnej, odczytuje zawartość, włącznie ze znacznikami, reprezentującą ten węzeł i wszystkie jego dzieci.

```cpp
virtual String System::Xml::XmlReader::ReadOuterXml()
```


### Wartość zwracana

Jeśli czytnik jest ustawiony na węźle elementu lub atrybutu, metoda zwraca całą zawartość XML, włącznie ze znacznikami, bieżącego węzła i wszystkich jego dzieci; w przeciwnym razie zwraca pusty łańcuch.
