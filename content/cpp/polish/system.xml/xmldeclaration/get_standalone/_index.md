## XmlDeclaration::get_Standalone() metoda


Zwraca wartość atrybutu standalone.

```cpp
String System::Xml::XmlDeclaration::get_Standalone()
```


### Wartość zwracana

Poprawne wartości to **yes**, jeśli wszystkie deklaracje jednostek wymagane przez dokument XML są zawarte w dokumencie, lub **no**, jeśli wymagana jest zewnętrzna definicja typu dokumentu (DTD). Jeśli atrybut standalone nie jest obecny w deklaracji XML, ta metoda zwraca [String::Empty](../../../system/string/empty/).
