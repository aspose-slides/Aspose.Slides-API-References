## WhitespaceHandling enum


Specifies how white space is handled.

```cpp
enum class WhitespaceHandling
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| All | 0 | Zwraca węzły **Whitespace** i **SignificantWhitespace**. To jest domyślne. |
| Significant | 1 | Zwraca wyłącznie węzły **SignificantWhitespace**. |
| None | 2 | Nie zwraca węzłów **Whitespace** ani **SignificantWhitespace**. |
