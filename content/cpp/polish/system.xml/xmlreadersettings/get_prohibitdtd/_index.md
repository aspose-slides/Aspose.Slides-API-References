## XmlReaderSettings::get_ProhibitDtd() metoda

Zwraca wartość wskazującą, czy zabronić przetwarzania definicji typu dokumentu (DTD) processing.

```cpp
bool System::Xml::XmlReaderSettings::get_ProhibitDtd()
```

### Wartość zwracana

**true** aby zabronić przetwarzania DTD; w przeciwnym razie **false**. Domyślnie **true**.

Deprecated
