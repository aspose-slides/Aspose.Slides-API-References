## XmlCharacterData::Substring(int32_t, int32_t) metoda


Zwraca podciąg pełnego ciągu znaków z określonego zakresu.

```cpp
virtual String System::Xml::XmlCharacterData::Substring(int32_t offset, int32_t count)
```


### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| offset | **int32_t** | Pozycja w ciągu znaków, od której rozpocząć pobieranie. Przesunięcie równe zero oznacza, że punkt początkowy znajduje się na początku danych. |
| count | **int32_t** | Liczba znaków do pobrania. |

### Wartość zwracana

Podciąg odpowiadający określonemu zakresowi.
