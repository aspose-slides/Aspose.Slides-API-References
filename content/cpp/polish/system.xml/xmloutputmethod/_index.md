## XmlOutputMethod enum

Określa metodę używaną do serializacji wyjścia [XmlWriter](../xmlwriter/).

```cpp
enum class XmlOutputMethod
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| Xml | 0 | Serializuj zgodnie z regułami XML 1.0. |
| Html | 1 | Serializuj zgodnie z regułami HTML określonymi przez XSLT. |
| Text | 2 | Serializuj wyłącznie bloki tekstu. |
| AutoDetect | 3 | Użyj reguł XSLT, aby w czasie wykonywania wybrać między metodami wyjścia [XmlOutputMethod::Xml](./) i [XmlOutputMethod::Html](./). |
