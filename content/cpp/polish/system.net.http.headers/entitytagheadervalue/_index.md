## EntityTagHeaderValue klasa


Reprezentuje wartość nagłówka 'Entity-Tag'. Obiekty tej klasy powinny być alokowane wyłącznie przy użyciu funkcji [System::MakeObject()](../../system/makeobject/). Nigdy nie twórz instancji tego typu na stosie ani przy użyciu operatora new, ponieważ spowoduje to błędy czasu wykonania i/lub awarie asercji. Zawsze opakuj tę klasę w wskaźnik [System::SmartPtr](../../system/smartptr/) i użyj tego wskaźnika do przekazania go do funkcji jako argument.

```cpp
class EntityTagHeaderValue : public System::ICloneable
```
