## HttpRequestHeaders::get_TransferEncodingChunked() metoda


Zwraca wartość wskazującą, czy wartość nagłówka 'Transfer-Encoding' zawiera 'Chunked'.

```cpp
Nullable<bool> System::Net::Http::Headers::HttpRequestHeaders::get_TransferEncodingChunked()
```

### Wartość zwracana

True, gdy wartość nagłówka 'Transfer-Encoding' zawiera 'Chunked', w przeciwnym razie false.
