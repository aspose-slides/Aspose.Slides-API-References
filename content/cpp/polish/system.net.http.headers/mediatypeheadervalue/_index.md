## MediaTypeHeaderValue klasa


Reprezentuje typ MIME w wartości nagłówka 'Content-Type'. Obiekty tej klasy powinny być alokowane wyłącznie przy użyciu funkcji [System::MakeObject()](../../system/makeobject/). Nigdy nie twórz instancji tego typu na stosie ani przy użyciu operatora new, ponieważ może to spowodować błędy wykonania i/lub naruszenia asercji. Zawsze opakowuj tę klasę w wskaźnik [System::SmartPtr](../../system/smartptr/) i używaj tego wskaźnika do przekazywania go funkcjom jako argument.

```cpp
class MediaTypeHeaderValue : public virtual System::ICloneable
```
