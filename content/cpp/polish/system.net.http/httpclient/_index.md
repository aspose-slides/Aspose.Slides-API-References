## HttpClient klasa

Reprezentuje klasę bazową klienta HTTP służącego do wysyłania żądań i odbierania odpowiedzi. Obiekty tej klasy powinny być alokowane wyłącznie przy użyciu funkcji [System::MakeObject()](../../system/makeobject/). Nigdy nie twórz instancji tego typu na stosie ani przy użyciu operatora new, ponieważ może to skutkować błędami wykonania i/lub naruszeniami asercji. Zawsze owiń tę klasę w wskaźnik [System::SmartPtr](../../system/smartptr/) i użyj tego wskaźnika do przekazywania go jako argumentu do funkcji.

```cpp
class HttpClient : public System::Net::Http::HttpMessageInvoker
```
