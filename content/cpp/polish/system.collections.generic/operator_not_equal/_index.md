## System::Collections::Generic::operator!=(const KeyValuePair\<TKey, TValue\>\&, const KeyValuePair\<TKey, TValue\>\&) funkcja

Porównuje dwie pary klucz-wartość używając odwróconej semantyki 'equals'.

```cpp
template<typename TKey,typename TValue> bool System::Collections::Generic::operator!=(const KeyValuePair<TKey, TValue> &left, const KeyValuePair<TKey, TValue> &right)
```

### Parametry szablonu

| Parametr | Opis |
| --- | --- |
| TKey | Typ klucza. |
| TValue | Typ wartości. |

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| left | const [KeyValuePair](../keyvaluepair/)\<TKey, TValue\>\& | Operand po lewej stronie. |
| right | const [KeyValuePair](../keyvaluepair/)\<TKey, TValue\>\& | Operand po prawej stronie. |

### Wartość zwracana

True, jeśli zarówno klucze, jak i wartości nie pasują, false w przeciwnym razie.
