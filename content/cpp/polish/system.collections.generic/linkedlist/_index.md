## Uwagi

Kontener listy powiązanej. Implementuje opakowanie nad std::list. Obiekty tej klasy powinny być przydzielane wyłącznie za pomocą funkcji [System::MakeObject()](../../system/makeobject/). Nigdy nie twórz instancji tego typu na stosie ani przy użyciu operatora new, ponieważ skutkuje to błędami czasu wykonania i/lub błędami asercji. Zawsze opakowuj tę klasę w wskaźnik [System::SmartPtr](../../system/smartptr/) i używaj tego wskaźnika do przekazywania jej do funkcji jako argument.

```cpp
#include <system/collections/linkedlist.h>
#include <system/smart_ptr.h>

using namespace System;
using namespace System::Collections::Generic;

int main()
{
  // Utwórz instancję klasy LinkedList.
  auto list = MakeObject<LinkedList<int>>();

  // Wypełnij listę powiązaną.
  list->AddFirst(1);
  list->AddLast(30);
  list->AddAfter(list->get_First(), 15);
  list->AddBefore(list->get_Last(), 25);

  // Wypisz elementy listy powiązanej.
  for (const auto item: list)
  {
    std::cout << item << ' ';
  }

  return 0;
}
/*
Ten przykład kodu generuje następujące wyjście:
1 15 25 30
*/
```
