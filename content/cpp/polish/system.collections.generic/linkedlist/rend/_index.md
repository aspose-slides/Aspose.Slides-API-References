## LinkedList::rend() metoda

Zwraca odwrócony iterator dla nieistniejącego elementu przed początkiem kolekcji.

```cpp
reverse_iterator System::Collections::Generic::LinkedList<T>::rend() noexcept
```

### Wartość zwracana

Odwrócony iterator wskazujący teoretyczny element poprzedzający pierwszy element w liście powiązanej (ostatni w kolejności odwróconej).

## LinkedList::rend() const metoda

Zwraca odwrócony iterator dla nieistniejącego elementu przed początkiem kolekcji oznaczonej jako const.

```cpp
const_reverse_iterator System::Collections::Generic::LinkedList<T>::rend() const noexcept
```
