## IEnumerable::end() metoda

Zwraca iterator wskazujący tuż po ostatnim elemencie (jeśli istnieje) kolekcji. Ten iterator nie może być użyty do zmiany referencjonowanego obiektu, ponieważ [GetEnumerator()](../getenumerator/) zwraca kopię obiektu typu T.

```cpp
iterator System::Collections::Generic::IEnumerable<T>::end()
```

### Wartość zwracana

Iterator wskazujący tuż po ostatnim elemencie (jeśli istnieje) kolekcji

## IEnumerable::end() const metoda

Zwraca iterator wskazujący tuż po ostatnim elemencie (jeśli istnieje) const-kwalifikowanej instancji kolekcji.

```cpp
const_iterator System::Collections::Generic::IEnumerable<T>::end() const
```

### Wartość zwracana

Iterator wskazujący tuż po ostatnim elemencie (jeśli istnieje) const-kwalifikowanej instancji kolekcji
