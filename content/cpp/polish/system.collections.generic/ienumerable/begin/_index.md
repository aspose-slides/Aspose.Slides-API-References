## IEnumerable::begin() metoda

Pobiera iterator wskazujący na pierwszy element (jeśli istnieje) kolekcji. Ten iterator nie może być używany do zmiany referowanego obiektu, ponieważ [GetEnumerator()](../getenumerator/) zwraca kopię obiektu typu T.

```cpp
iterator System::Collections::Generic::IEnumerable<T>::begin()
```

### Wartość zwracana

Iterator wskazujący na pierwszy element (jeśli istnieje) kolekcji

## IEnumerable::begin() const metoda

Pobiera iterator wskazujący na pierwszy element (jeśli istnieje) const-kwalifikowanej instancji kolekcji.

```cpp
const_iterator System::Collections::Generic::IEnumerable<T>::begin() const
```

### Wartość zwracana

Iterator wskazujący na pierwszy element (jeśli istnieje) const-kwalifikowanej instancji kolekcji
