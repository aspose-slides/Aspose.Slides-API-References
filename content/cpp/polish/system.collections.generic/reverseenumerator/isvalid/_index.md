## ReverseEnumerator::IsValid() const metoda

Sprawdza, czy [MoveNext()](../movenext/) został wywołany i koniec nie został osiągnięty.

```cpp
bool System::Collections::Generic::ReverseEnumerator<Container, Element>::IsValid() const
```
