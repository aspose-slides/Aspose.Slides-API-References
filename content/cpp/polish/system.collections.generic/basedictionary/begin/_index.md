## BaseDictionary::begin() const metoda

Zwraca iterator do KVPair-wrapper dla elementu klucz-wartość kontenera. Zaimplementowano w stylu C# – iterator powinien zwrócić KVPair-object z interfejsem get_Key() i get_Value(). Jeśli kontener jest pusty, zwrócony iterator będzie równy [end()](../../ienumerable/end/).

```cpp
const_iterator System::Collections::Generic::BaseDictionary<Map>::begin() const noexcept
```

### Wartość zwracana

Iterator wskazujący na pierwszy element kolekcji.
