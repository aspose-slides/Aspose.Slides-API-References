## XmlKnownDtds enumeracja


Ta [Resolvers::XmlKnownDtds](./) enumeracja jest używana przez [Resolvers::XmlPreloadedResolver](../xmlpreloadedresolver/) i określa, które dobrze znane DTD są rozpoznawane przez [Resolvers::XmlPreloadedResolver](../xmlpreloadedresolver/).

```cpp
enum class XmlKnownDtds
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| None | 0 | Określa, że [Resolvers::XmlPreloadedResolver](../xmlpreloadedresolver/) nie rozpozna żadnego z wstępnie zdefiniowanych DTD. |
| Xhtml10 | 1 | Określa, że [Resolvers::XmlPreloadedResolver](../xmlpreloadedresolver/) rozpozna DTD i encje zdefiniowane w XHTML 1.0. |
| Rss091 | 2 | Określa, że [Resolvers::XmlPreloadedResolver](../xmlpreloadedresolver/) rozpozna DTD i encje zdefiniowane w RSS 0.91. |
| All | 65535 | Określa, że [Resolvers::XmlPreloadedResolver](../xmlpreloadedresolver/) rozpozna wszystkie aktualnie obsługiwane DTD. To jest domyślne zachowanie. |
