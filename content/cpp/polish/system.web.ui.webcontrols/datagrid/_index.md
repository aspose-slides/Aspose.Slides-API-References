## DataGrid klasa

Klasa atrapa umożliwiająca łączenie przetłumaczonego kodu z [DataGrid](./) odwołaniami, ale nie wykonująca go. Nie zawiera prawidłowo zaimplementowanych członków. Obiekty tej klasy powinny być alokowane wyłącznie przy użyciu funkcji [System::MakeObject()](../../system/makeobject/). Nigdy nie twórz instancji tego typu na stosie ani przy użyciu operatora new, ponieważ spowoduje to błędy wykonania i/lub naruszenia asercji. Zawsze owiń tę klasę wskaźnikiem [System::SmartPtr](../../system/smartptr/) i używaj tego wskaźnika do przekazywania go jako argumentu funkcjom.

```cpp
class DataGrid : public System::Object
```
