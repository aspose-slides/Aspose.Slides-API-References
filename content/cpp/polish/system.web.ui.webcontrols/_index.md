## Klasy

| Klasa | Opis |
| --- | --- |
| [DataGrid](./datagrid/) | Klasa atrapa umożliwiająca łączenie przetłumaczonego kodu z odwołaniami [DataGrid](./datagrid/), ale nie wykonuje go. Nie zawiera poprawnie zaimplementowanych członków. Obiekty tej klasy powinny być alokowane wyłącznie przy użyciu funkcji [System::MakeObject()](../system/makeobject/). Nigdy nie twórz instancji tego typu na stosie ani przy użyciu operatora new, ponieważ spowoduje to błędy czasu wykonywania i/lub awarie asercji. Zawsze opakowuj tę klasę w wskaźnik [System::SmartPtr](../system/smartptr/) i używaj tego wskaźnika do przekazywania go jako argument do funkcji. |
