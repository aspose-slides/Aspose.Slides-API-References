## FlatStyle wyliczenie

Określa, czy kontrolka jest rysowana płasko lub trójwymiarowo.

```cpp
enum class FlatStyle
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| Flat | 0 | [Control](../control/) jest rysowane płasko. |
| Popup | 1 | [Control](../control/) jest rysowane płasko, chyba że mysz najedzie na nie, gdy jest rysowane w stylu 3D. |
| Standard | 2 | [Control](../control/) jest rysowane w stylu 3D. |
| System | 3 | Styl jest kontrolowany przez system operacyjny. |
