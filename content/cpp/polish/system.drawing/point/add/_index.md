## Point::Add(const Point\&, const Size\&) metoda

Dodaje wartości szerokości i wysokości określonego obiektu [Size](../../size/) do wartości współrzędnych X i Y określonego obiektu [Point](../) odpowiednio.

```cpp
static Point System::Drawing::Point::Add(const Point &point, const Size &size)
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| point | const [Point](../)\& | Punkt do przetłumaczenia |
| size | const [Size](../../size/)\& | Obiekt [Size](../../size/) określający wartości do dodania do współrzędnych **point** |

### Wartość zwracana

Nowy obiekt [Point](../), którego wartość współrzędnej X jest równa sumie wartości współrzędnej X **point** i wartości szerokości **size**, a wartość współrzędnej Y jest równa sumie wartości współrzędnej Y **point** i wartości wysokości **size**.
