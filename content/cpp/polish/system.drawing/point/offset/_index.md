## Point::Offset(int, int) metoda


Przesuwa wartość współrzędnych X i Y reprezentowaną przez bieżący obiekt o podane wartości.

```cpp
void System::Drawing::Point::Offset(int dx, int dy)
```


### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| dx | int | Wartość, o jaką przesuwa się wartość współrzędnej X |
| dy | int | Wartość, o jaką przesuwa się wartość współrzędnej Y |
