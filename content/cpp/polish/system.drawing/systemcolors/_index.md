## Klasa SystemColors

Klasa, która zapewnia zestaw wstępnie utworzonych [Color](../color/) obiektów reprezentujących kolory elementów wyświetlacza [Windows](../../system.windows/). Jest to typ statyczny bez usług instancji. Nigdy nie powinieneś tworzyć jego instancji w żaden sposób.

```cpp
class SystemColors
```
