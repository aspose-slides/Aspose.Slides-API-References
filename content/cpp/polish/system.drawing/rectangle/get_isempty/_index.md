## Rectangle::get_IsEmpty() const metoda

Określa, czy współrzędne X i Y lewego górnego rogu prostokąta reprezentowanego przez bieżący obiekt oraz jego szerokość i wysokość mają wartość 0.

```cpp
bool System::Drawing::Rectangle::get_IsEmpty() const
```

### Wartość zwracana

True jeśli współrzędne X i Y lewego górnego rogu prostokąta reprezentowanego przez bieżący obiekt oraz jego szerokość i wysokość mają wartość 0, w przeciwnym razie - false
