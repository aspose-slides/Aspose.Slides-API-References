## Rectangle::Offset(const Point\&) metoda

Przesuwa pozycję prostokąta reprezentowanego przez bieżący obiekt o podane wartości.

```cpp
void System::Drawing::Rectangle::Offset(const Point &pos)
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| pos | const [Point](../../point/)\& | Obiekt [Point](../../point/), który określa wartość, o którą prostokąt jest przesunięty; wartość współrzędnej X punktu określa ilość, którą należy dodać do współrzędnej X lewego górnego rogu prostokąta, a współrzędna Y punktu określa ilość, którą należy dodać do współrzędnej Y lewego górnego rogu prostokąta |

## Rectangle::Offset(int, int) metoda

Przesuwa pozycję prostokąta reprezentowanego przez bieżący obiekt o podane wartości.

```cpp
void System::Drawing::Rectangle::Offset(int x, int y)
```

### Argumenty

| Parametr | Typ | Opis |
