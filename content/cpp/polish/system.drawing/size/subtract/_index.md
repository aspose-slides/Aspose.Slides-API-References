## Size::Subtract(const Size\&, const Size\&) metoda


Zwraca nowy obiekt [Size](../), który jest wynikiem odejmowania **size2** od **size1**, tj. którego wartość szerokości jest wynikiem odejmowania **size2's** szerokości od **size1's** szerokości, a wartość wysokości jest wynikiem odejmowania **size2's** wysokości od **size1's** wysokości.

```cpp
static Size System::Drawing::Size::Subtract(const Size &size1, const Size &size2)
```

Obiekt [Size](../), który jest wynikiem odjęcia **size2** od **size1**
