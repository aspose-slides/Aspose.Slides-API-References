## StringDigitSubstitute wyliczenie


Określa, w jaki sposób cyfry w łańcuchu znaków są zastępowane zgodnie z ustawieniami regionalnymi lub językiem.

```cpp
enum class StringDigitSubstitute
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| User | 0 | Substitucja definiowana przez użytkownika. |
| None | 1 | Substitucja jest wyłączona. |
| National | 2 | Zastąp cyfry odpowiadające oficjalnemu językowi narodowemu ustawień regionalnych użytkownika. |
| Traditional | 3 | Zastąp cyfry odpowiadające rodzimemu skryptowi lub językowi użytkownika, które mogą nie być takie same jak oficjalny język narodowy ustawień regionalnych użytkownika. |
