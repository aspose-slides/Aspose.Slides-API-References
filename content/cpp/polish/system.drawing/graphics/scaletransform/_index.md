## Graphics::ScaleTransform(float, float, Drawing2D::MatrixOrder) metoda

Applies the specified scale vector to the world transformation matrix of the current object.

```cpp
void System::Drawing::Graphics::ScaleTransform(float sx, float sy, Drawing2D::MatrixOrder order=Drawing2D::MatrixOrder::Prepend)
```

### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| sx | **float** | Wartość, o którą skalowana jest macierz wzdłuż osi x |
| sy | **float** | Wartość, o którą skalowana jest macierz wzdłuż osi y |
| order | [Drawing2D::MatrixOrder](../../../system.drawing.drawing2d/matrixorder/) | Kolejność, w której wektor skalowania jest stosowany do macierzy |
