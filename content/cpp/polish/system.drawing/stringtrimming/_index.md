## StringTrimming enum

Określa, w jaki sposób znaki powinny być przycinane z łańcucha, który nie mieści się w kształcie układu.

```cpp
enum class StringTrimming
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| None | 0 | Brak przycinania. |
| Character | 1 | Przytnij do najbliższego znaku. |
| Word | 2 | Przytnij do najbliższego słowa. |
| EllipsisCharacter | 3 | Przytnij do najbliższego znaku i wstaw wielokropek na końcu ciągu. |
| EllipsisWord | 4 | Przytnij do najbliższego słowa i wstaw wielokropek na końcu ciągu. |
| EllipsisPath | 5 | Środek jest usuwany z przyciętych linii i zastępowany wielokropkiem. Zachowaj jak najwięcej ostatniego segmentu linii oddzielonego ukośnikiem. |
