## AuthenticationLevel enum

Flagi uwierzytelniania specyficzne dla WebRequest.

```cpp
enum class AuthenticationLevel
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| None | 0 | Uwierzytelnianie nie jest wymagane dla klienta i serwera. |
| MutualAuthRequested | 1 | Żądanie nie kończy się niepowodzeniem, jeśli serwer nie jest uwierzytelniony. |
| MutualAuthRequired | 2 | Bieżąca aplikacja otrzyma 'IOException', gdy serwer nie jest uwierzytelniony. |
