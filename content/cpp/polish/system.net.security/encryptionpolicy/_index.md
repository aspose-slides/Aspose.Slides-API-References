## EncryptionPolicy enum

Wylicza zasady szyfrowania.

```cpp
enum class EncryptionPolicy
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| RequireEncryption | 0 | Wymaga szyfrowania i nigdy nie zezwala na szyfr 'Null'. |
| AllowNoEncryption | 1 | Preferuje użycie pełnego szyfrowania, ale szyfr 'Null' może zostać użyty, jeśli serwer się zgodzi. |
| NoEncryption | 2 | Zezwala na brak szyfrowania i żąda, aby użyto szyfru 'Null', jeśli drugi punkt końcowy może obsłużyć szyfr 'Null'. |
