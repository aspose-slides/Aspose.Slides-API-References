## X500DistinguishedNameFlags enumeracja

Reguły formatowania wyróżniającej nazwy certyfikatu X509.

```cpp
enum class X500DistinguishedNameFlags
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| None | 0 | Brak specjalnych cech. |
| Reversed | 1 | Nazwa jest odwrócona. |
| UseSemicolons | 16 | Używaj średników. |
| DoNotUsePlusSign | 32 | Nazwa nie używa znaku plus. |
| DoNotUseQuotes | 64 | Wyłącza cudzysłowy w nazwie. |
| UseCommas | 128 | Włącza użycie przecinków. |
| UseNewLines | 256 | Włącza użycie nowych linii. |
| UseUTF8Encoding | 4096 | Przełącza z Unicode na kodowanie UTF-8. |
| UseT61Encoding | 8192 | Przełącza na kodowanie T61. |
| ForceUTF8Encoding | 16384 | Wymusza użycie UTF-8 przy kodowaniu określonych kluczy X500. |
