## X509Extension klasa

Obiekt rozszerzenia przechowujący dodatkowe informacje powiązane z certyfikatem X.509. Obiekty tej klasy powinny być alokowane wyłącznie przy użyciu funkcji [System::MakeObject()](../../system/makeobject/). Nigdy nie twórz instancji tego typu na stosie ani przy użyciu operatora new, ponieważ spowoduje to błędy w czasie wykonania i/lub błędy asercji. Zawsze owiń tę klasę wskaźnikiem [System::SmartPtr](../../system/smartptr/) i używaj tego wskaźnika do przekazywania go do funkcji jako argument.

```cpp
class X509Extension : public System::Security::Cryptography::AsnEncodedData
```
