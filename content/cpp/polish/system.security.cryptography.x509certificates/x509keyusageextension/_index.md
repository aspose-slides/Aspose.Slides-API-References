## X509KeyUsageExtension klasa

Obiekt rozszerzenia przechowujący dodatkowe informacje o użyciu klucza. Obiekty tej klasy powinny być alokowane wyłącznie przy użyciu funkcji [System::MakeObject()](../../system/makeobject/). Nigdy nie twórz instancji tego typu na stosie ani nie używaj operatora new, ponieważ może to skutkować błędami w czasie wykonywania i/lub naruszeniami asercji. Zawsze opakuj tę klasę we wskaźnik [System::SmartPtr](../../system/smartptr/) i użyj tego wskaźnika do przekazywania jej do funkcji jako argument.

```cpp
class X509KeyUsageExtension : public System::Security::Cryptography::X509Certificates::X509Extension
```
