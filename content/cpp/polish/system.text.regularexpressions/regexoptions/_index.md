## RegexOptions enum


[Regex](../regex/) opcje.

```cpp
enum class RegexOptions
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| None | 0 | Domyślne zachowanie. |
| Compiled | 1 | Kompiluj wyrażenie regularne w celu zwiększenia wydajności. Zawsze wykonywane domyślnie. |
| CultureInvariant | 2 | Użyj dopasowywania niezależnego od kultury. Ignorowane. |
| ECMAScript | 4 | Użyj składni ECMAScript. Ignorowane. |
| ExplicitCapture | 8 | Tylko jawne przechwytywanie. Ignorowane. |
| IgnoreCase | 16 | Ignoruj wielkość liter przy dopasowywaniu. |
| IgnorePatternWhitespace | 32 | Ignoruj białe znaki w wzorcu. Nieobsługiwane. |
| Multiline | 64 | Traktuj '^' i '$' jako początek i koniec wiersza, a nie całego ciągu. |
| RightToLeft | 128 | Dopasowywanie od prawej do lewej. Nieobsługiwane. |
| Singleline | 256 | Sprawia, że '.' dopasowuje dowolny znak bez wyjątków (zwykle znaki nowej linii nie są dopasowywane). |
