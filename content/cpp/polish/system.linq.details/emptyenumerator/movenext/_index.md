## EmptyEnumerator::MoveNext() metoda

Przesuwa enumerator do następnego elementu. Jeśli żaden element nie był wcześniej odwołany, ustawia odwołanie na pierwszy dostępny element. Jeśli osiągnięto koniec kontenera, nie wykonuje żadnej operacji.

```cpp
bool System::Linq::Details::EmptyEnumerator<T>::MoveNext() override
```

### Wartość zwracana

true, jeśli po wywołaniu dostępny jest jakiś element, w przeciwnym razie false.
