## KeyInfoX509Data klasa

Reprezentuje element 'X509Data'. Zawiera informacje o certyfikacie X.509v3 związane z kluczem walidacji lub szyfrowania. Obiekty tej klasy powinny być tworzone wyłącznie przy użyciu funkcji [System::MakeObject()](../../system/makeobject/). Nigdy nie twórz instancji tego typu na stosie ani przy użyciu operatora new, ponieważ spowoduje to błędy czasu wykonywania i/lub błędy asercji. Zawsze opakuj tę klasę w wskaźnik [System::SmartPtr](../../system/smartptr/) i użyj tego wskaźnika do przekazywania go do funkcji jako argument.

```cpp
class KeyInfoX509Data : public System::Security::Cryptography::Xml::KeyInfoClause
```
