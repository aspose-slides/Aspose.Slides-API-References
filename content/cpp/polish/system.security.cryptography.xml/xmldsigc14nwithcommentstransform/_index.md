## XmlDsigC14NWithCommentsTransform klasa


Reprezentuje transformację kanoniczną XML C14N dla podpisu cyfrowego z komentarzami. Obiekty tej klasy powinny być alokowane wyłącznie przy użyciu funkcji [System::MakeObject()](../../system/makeobject/). Nigdy nie twórz instancji tego typu na stosie ani przy użyciu operatora new, ponieważ spowoduje to błędy w czasie wykonania i/lub awarie asercji. Zawsze opakowuj tę klasę w wskaźnik [System::SmartPtr](../../system/smartptr/) i używaj tego wskaźnika jako argumentu w funkcjach.

```cpp
class XmlDsigC14NWithCommentsTransform : public System::Security::Cryptography::Xml::XmlDsigC14NTransform
```
