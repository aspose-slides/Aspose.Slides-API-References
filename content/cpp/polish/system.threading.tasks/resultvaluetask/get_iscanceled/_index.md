## ResultValueTask::get_IsCanceled() const metoda


Zwraca wartość wskazującą, czy zadanie zostało zakończone z powodu anulowania.

```cpp
bool System::Threading::Tasks::ResultValueTask<T>::get_IsCanceled() const
```


### Wartość zwracana

bool True, jeśli zadanie zostało anulowane; w przeciwnym razie false.
## Uwagi



Zwraca false, jeśli zadanie zawiera bezpośrednią wartość wyniku.
