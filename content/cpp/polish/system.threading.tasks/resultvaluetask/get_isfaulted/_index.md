## ResultValueTask::get_IsFaulted() const metoda

Pobiera wartość wskazującą, czy zadanie zakończyło się z powodu nieobsłużonego wyjątku.

```cpp
bool System::Threading::Tasks::ResultValueTask<T>::get_IsFaulted() const
```

### Wartość zwracana

bool True jeśli zadanie jest w stanie błędu; w przeciwnym razie false.

## Uwagi

Zwraca false, jeśli zadanie zawiera bezpośrednią wartość zwracaną.
