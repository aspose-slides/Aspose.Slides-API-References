## CancellationTokenRegistration::Dispose() metoda


Usuwa rejestrację i usuwa wywołanie zwrotne z powiązanego [CancellationTokenSource](../../cancellationtokensource/). Po wywołaniu tej metody, zarejestrowane wywołanie zwrotne nie będzie już wywoływane, gdy powiązany [CancellationTokenSource](../../cancellationtokensource/) zostanie anulowany.

```cpp
void System::Threading::CancellationTokenRegistration::Dispose()
```

## Uwagi



Bezpieczne jest wywoływanie tej metody wielokrotnie - kolejne wywołania nie będą miały wpływu.
