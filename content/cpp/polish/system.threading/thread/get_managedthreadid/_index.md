## Thread::get_ManagedThreadId() const metoda

Zwraca identyfikator wątku. Może być pobrany z systemu operacyjnego, ale jeśli identyfikator wątku systemu operacyjnego przekracza limity typu int, identyfikatory wątków mogą się zazębiać.

```cpp
int System::Threading::Thread::get_ManagedThreadId() const
```

### Wartość zwracana

Pseudo-unikalny identyfikator wątku.
