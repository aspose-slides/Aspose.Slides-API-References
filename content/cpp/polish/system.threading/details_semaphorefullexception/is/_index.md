```cpp
bool System::Threading::Details_SemaphoreFullException::Is(const System::TypeInfo &target) const override
```


### Argumenty

| Parametr | Typ | Opis |
| --- | --- | --- |
| target | const [System::TypeInfo](../../../system/typeinfo/)\& | [TypeInfo](../../../system/typeinfo/) struktura opisująca typ, przeciwko któremu testowany jest bieżący obiekt. |

### Wartość zwracana

## Uwagi

Sprawdź, czy obiekt jest instancją typu opisanego przez targetType. Analog operatora C# 'is' .
