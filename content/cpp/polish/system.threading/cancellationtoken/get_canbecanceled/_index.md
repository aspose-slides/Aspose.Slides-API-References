## CancellationToken::get_CanBeCanceled() const metoda


Określa, czy ten token może znajdować się w stanie anulowanym.

```cpp
bool System::Threading::CancellationToken::get_CanBeCanceled() const
```


### Wartość zwracana

true, jeśli ten token może znajdować się w stanie anulowanym; w przeciwnym razie false.
## Uwagi



Tokeny utworzone z [CancellationTokenSource](../../cancellationtokensource/) zwrócą true, podczas gdy token None zawsze zwróci false.
