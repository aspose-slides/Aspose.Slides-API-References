## LineJoin enum

Określa, jak łączone są kolejne linie lub krzywe.

```cpp
enum class LineJoin
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| Miter | 0 | Połączenie Miter, które tworzy ostry lub przycięty narożnik w zależności od tego, czy długość ścięcia przekracza limit ścięcia. |
| Bevel | 1 | Połączenie Bevel, które tworzy skośny narożnik. |
| Round | 2 | Połączenie Round, które tworzy płynną, okrągłą łuk między liniami. |
| MiterClipped | 3 | Połączenie MiterClipped, które tworzy ostry lub ścięty narożnik w zależności od tego, czy długość ścięcia przekracza limit ścięcia. |
