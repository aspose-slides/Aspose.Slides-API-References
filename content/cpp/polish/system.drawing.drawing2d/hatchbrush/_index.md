## HatchBrush klasa

Reprezentuje prostokątny pędzel ze stylem kreskowania, kolorem pierwszoplanowym i kolorem tła. Obiekty tej klasy powinny być alokowane wyłącznie przy użyciu funkcji [System::MakeObject()](../../system/makeobject/). Nigdy nie twórz instancji tego typu na stosie ani przy użyciu operatora new, ponieważ może to spowodować błędy w czasie wykonania i/lub naruszenia asercji. Zawsze opakowuj tę klasę w wskaźnik [System::SmartPtr](../../system/smartptr/) i używaj tego wskaźnika do przekazywania go jako argument do funkcji jako argument.

```cpp
class HatchBrush : public System::Drawing::Brush
```
