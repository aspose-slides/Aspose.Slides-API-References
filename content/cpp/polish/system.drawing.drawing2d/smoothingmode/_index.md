## SmoothingMode enum


Określa, jaki typ wygładzania (antyaliasingu) jest stosowany do linii, krzywych i krawędzi wypełnionych obszarów.

```cpp
enum class SmoothingMode
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| Invalid | n/a | Nieprawidłowa wartość. |
| Default | n/a | Domyślny tryb, bez antyaliasingu. |
| HighSpeed | n/a | Brak antyaliasingu, wysoka prędkość. |
| HighQuality | n/a | Renderowanie z antyaliasingiem, niska prędkość. |
| None | n/a | Brak antyaliasingu. |
| AntiAlias | n/a | Renderowanie z antyaliasingiem. |
