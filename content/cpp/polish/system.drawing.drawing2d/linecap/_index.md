## LineCap enum

Wskazuje dostępne style zakończenia, które obiekt [Pen](../../system.drawing/pen/) może zastosować do linii.

```cpp
enum class LineCap
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| Flat | 0 | Płaski koniec linii. |
| Square | 1 | Kwadratowy koniec linii. |
| Round | 2 | Zaokrąglony koniec linii. |
| Triangle | 3 | Trójkątny koniec linii. |
| NoAnchor | 16 | Brak kotwicy. |
| SquareAnchor | 17 | Kwadratowy koniec linii kotwicy. |
| RoundAnchor | 18 | Zaokrąglony koniec linii kotwicy. |
| DiamondAnchor | 19 | Diamentowy koniec linii kotwicy. |
| ArrowAnchor | 20 | Strzałkowy koniec linii kotwicy. |
| AnchorMask | 240 | Maska używana do sprawdzenia, czy koniec linii jest kotwicą. |
| Custom | 255 | Niestandardowy koniec. |
