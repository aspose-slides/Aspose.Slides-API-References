## Enum WrapMode

Określa, jak tekstura lub gradient jest rozmieszczany w trybie kafelkowym, gdy jest mniejszy niż wypełniany obszar.

```cpp
enum class WrapMode
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| Tile | 0 | Kafelkowuje gradient lub teksturę. |
| TileFlipX | 1 | Odwraca teksturę lub gradient w poziomie, a następnie kafelkowuje teksturę lub gradient. |
| TileFlipY | 2 | Odwraca teksturę lub gradient w pionie, a następnie kafelkowuje teksturę lub gradient. |
| TileFlipXY | 3 | Odwraca teksturę lub gradient w poziomie i pionie, a następnie kafelkowuje teksturę lub gradient. |
| Clamp | 4 | Przyciąga teksturę lub gradient do granicy obiektu. |
