## DashCap enum

Specifies the type of a cap used at the both ends of a dash in a dashed line.

```cpp
enum class DashCap
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| Flat | 0 | Kwadratowa końcówka, która prostokątowo zamyka oba końce kreski. |
| Round | 2 | Okrągła końcówka, która zaokrągla oba końce kreski. |
| Triangle | 3 | Trójkątna końcówka, która wskazuje oba końce kreski. |
