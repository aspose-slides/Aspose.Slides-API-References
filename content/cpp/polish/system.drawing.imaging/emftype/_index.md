## EmfType enum


Określa typy rekordów, które są umieszczane w pliku EMF.

```cpp
enum class EmfType
```

### Wartości

| Name | Value | Description |
| --- | --- | --- |
| EmfOnly | n/a | [Windows](../../system.windows/) rozszerzona metafila. Zawiera polecenia GDI. Pliki metafile tego typu są określane jako plik EMF. |
| EmfPlusOnly | n/a | [Windows](../../system.windows/) rozszerzona metafila plus. Zawiera polecenia GDI+. Pliki metafile tego typu są określane jako plik EMF+. |
| EmfPlusDual | n/a | Dual [Windows](../../system.windows/) rozszerzona metafila. Zawiera równoważne polecenia GDI i GDI+. Pliki metafile tego typu są określane jako plik EMF+. |
