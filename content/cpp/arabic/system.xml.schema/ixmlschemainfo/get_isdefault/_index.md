## IXmlSchemaInfo::get_IsDefault() طريقة


يعيد قيمة تشير إلى ما إذا تم تعيين عقدة XML المُحقّقة هذه كنتيجة لتطبيق القيمة الافتراضية أثناء التحقق من صحة مخطط XML [Schema](../../) Definition Language (XSD) validation.

```cpp
virtual bool System::Xml::Schema::IXmlSchemaInfo::get_IsDefault()=0
```


### قيمة الإرجاع

**true** إذا تم تعيين عقدة XML المُحقّقة هذه كنتيجة لتطبيق القيمة الافتراضية أثناء التحقق من صحة المخطط؛ وإلا، **false**.
