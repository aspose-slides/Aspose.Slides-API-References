## XmlSchemaComplexContentExtension فئة

يمثل عنصر **extension** من XML [Schema](../) كما هو محدد من قبل World Wide [Web](../../system.web/) Consortium (W3C). هذه الفئة مخصصة للأنواع المعقدة التي لديها نموذج محتوى معقد يتم اشتقاقه عن طريق التمديد. وهي توسّع النوع المعقّد بإضافة سمات أو عناصر.

```cpp
class XmlSchemaComplexContentExtension : public System::Xml::Schema::XmlSchemaContent
```
