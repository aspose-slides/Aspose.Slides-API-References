## XmlSchemaDerivationMethod تعداد

يوفر طرقًا مختلفة لمنع الاشتقاق.

```cpp
enum class XmlSchemaDerivationMethod
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| Empty | 0 | تجاوز طريقة الاشتقاق الافتراضية للسماح بأي اشتقاق. |
| Substitution | 1 | يشير إلى الاشتقاقات بواسطة **Substitution**. |
| Extension | 2 | يشير إلى الاشتقاقات بواسطة **Extension**. |
| Restriction | 4 | يشير إلى الاشتقاقات بواسطة **Restriction**. |
| List | 8 | يشير إلى الاشتقاقات بواسطة **List**. |
| Union | 16 | يشير إلى الاشتقاقات بواسطة **Union**. |
| All | 255 | **#all**. يشير إلى جميع طرق الاشتقاق. |
| None | 256 | يقبل طريقة الاشتقاق الافتراضية. |
