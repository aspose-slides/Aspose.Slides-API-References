## XmlSchemaSimpleContentExtension فئة


يمثل عنصر **extension** للمحتوى البسيط من XML [Schema](../) كما هو محدد من قبل اتحاد الويب العالمي [Web](../../system.web/) (W3C). يمكن استخدام هذه الفئة لاستنتاج أنواع بسيطة عن طريق التوسيع. تُستخدم مثل هذه الاستنتاجات لتمديد محتوى النوع البسيط للعنصر بإضافة سمات.

```cpp
class XmlSchemaSimpleContentExtension : public System::Xml::Schema::XmlSchemaContent
```
