
### قيمة الإرجاع

**true** إذا كان عنصر XML أو السمة المُتحقّق منها هو عقدة [XPath](../../../system.xml.xpath/)؛ **false** إذا كان عنصر XML أو السمة المُتحقّق منها هو قيمة ذرية.
