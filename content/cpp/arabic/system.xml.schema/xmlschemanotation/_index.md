## XmlSchemaNotation فئة


يمثِّل عنصر **الترميز** من XML [Schema](../) كما حددت اتحاد World Wide [Web](../../system.web/) (W3C). إعلان **الترميز** XML [Schema](../) هو إعادة بناء لإعلانات NOTATION XML 1.0. الغرض من الترميزات هو وصف تنسيق البيانات غير XML داخل مستند XML.

```cpp
class XmlSchemaNotation : public System::Xml::Schema::XmlSchemaAnnotated
```

## ملاحظات
