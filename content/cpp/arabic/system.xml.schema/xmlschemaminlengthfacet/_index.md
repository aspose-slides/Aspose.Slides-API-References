## XmlSchemaMinLengthFacet الفئة


يمثل عنصر **minLength** من XML [Schema](../) كما هو محدد من قبل اتحاد الويب العالمي [Web](../../system.web/) (W3C). يمكن استخدام هذه الفئة لتحديد قيد على الحد الأدنى لطول قيمة البيانات لعنصر **simpleType**. يجب أن يكون الطول أكبر من قيمة عنصر **minLength**.

```cpp
class XmlSchemaMinLengthFacet : public System::Xml::Schema::XmlSchemaNumericFacet
```
