## فئة X509ChainStatus

يخزن حالة سلسلة X509 ومعلومات الخطأ. يجب إنشاء كائنات هذه الفئة باستخدام الدالة [System::MakeObject()](../../system/makeobject/) فقط. لا تقم أبداً بإنشاء مثيل من هذا النوع على المكدس أو باستخدام operator new، لأن ذلك سيؤدي إلى أخطاء وقت التنفيذ و/أو أعطال التحقق. قم دائماً بلفّ هذه الفئة في مؤشر [System::SmartPtr](../../system/smartptr/) واستخدم هذا المؤشر لتمريره إلى الدوال كوسيطة.

```cpp
class X509ChainStatus : public System::Object
```
