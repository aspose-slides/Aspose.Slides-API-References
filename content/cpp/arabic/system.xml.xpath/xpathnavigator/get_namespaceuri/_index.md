## XPathNavigator::get_NamespaceURI() طريقة

عند تجاوزها في فئة مشتقة، تسترجع عنوان URI للمساحة الاسمية للعقدة الحالية.

```cpp
virtual String System::Xml::XPath::XPathNavigator::get_NamespaceURI()=0
```

### قيمة الإرجاع

كائن [String](../../../system/string/) يحتوي على عنوان URI للمساحة الاسمية للعقدة الحالية، أو [String::Empty](../../../system/string/empty/) إذا لم تكن للعقدة الحالية عنوان URI للمساحة الاسمية.
