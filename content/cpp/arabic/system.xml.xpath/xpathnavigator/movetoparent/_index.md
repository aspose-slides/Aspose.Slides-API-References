## XPathNavigator::MoveToParent() طريقة

When overridden in a derived class, moves the [XPathNavigator](../) to the parent node of the current node.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToParent()=0
```

### قيمة الإرجاع

**true** إذا كان الـ [XPathNavigator](../) ناجحًا في الانتقال إلى العقدة الأم للعقدة الحالية؛ وإلا، **false**. إذا كان **false**، يبقى موقع الـ [XPathNavigator](../) دون تغيير.
