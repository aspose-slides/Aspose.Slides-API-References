## XPathNavigator::get_LocalName() طريقة

```cpp
virtual String System::Xml::XPath::XPathNavigator::get_LocalName()=0
```

### قيمة الإرجاع

كائن [String](../../../system/string/) يحتوي على الاسم المحلي للعقدة الحالية، أو [String::Empty](../../../system/string/empty/) إذا لم يكن للعقدة الحالية اسم (على سبيل المثال، عقد نصية أو عقد تعليقات).
