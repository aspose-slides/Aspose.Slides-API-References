## XPathNavigator::MoveToAttribute(String, String) الطريقة

ينقل [XPathNavigator](../) إلى السمة التي لها الاسم المحلي ومساحة الاسم URI المتطابقة.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToAttribute(String localName, String namespaceURI)
```

### المعامل

| المعامل | النوع | الوصف |
| --- | --- | --- |
| localName | [String](../../../system/string/) | الاسم المحلي للصفة. |
| namespaceURI | [String](../../../system/string/) | URI مساحة الاسم للصفة؛ **nullptr** ل مساحة اسم فارغة. |

### قيمة الإرجاع

**true** إذا كان [XPathNavigator](../) ناجحًا في الانتقال إلى الصفة؛ وإلا، **false**. إذا كان **false**، يبقى موقع [XPathNavigator](../) دون تغيير.
