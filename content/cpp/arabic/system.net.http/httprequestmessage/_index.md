## HttpRequestMessage فئة


يمثل رسالة طلب HTTP. يجب تخصيص كائنات هذه الفئة باستخدام الدالة [System::MakeObject()](../../system/makeobject/) فقط. لا تقم بإنشاء مثيل من هذا النوع على المكدس أو باستخدام معامل new، حيث سيؤدي ذلك إلى أخطاء وقت التشغيل أو أعطال تأكيدية. قم دائمًا بلف هذه الفئة داخل مؤشر [System::SmartPtr](../../system/smartptr/) واستخدم هذا المؤشر لتمريره إلى الدوال كوسيط.

```cpp
class HttpRequestMessage : public System::IDisposable
```
