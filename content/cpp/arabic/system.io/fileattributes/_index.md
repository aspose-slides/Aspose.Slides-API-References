## تعداد FileAttributes

يمثل خصائص دليل أو ملف.

```cpp
enum class FileAttributes
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| Archive | 32 | كيان نظام الملفات هو مرشح للإزالة أو النسخ الاحتياطي. |
| Compressed | 2048 | كيان نظام الملفات مضغوط. |
| Device | 64 | غير مستخدم. |
| Directory | 16 | كيان نظام الملفات هو دليل. |
| Encrypted | 16384 | كيان نظام الملفات مشفر. |
| Hidden | 2 | كيان نظام الملفات مخفي. |
| IntegrityStream | 32768 | كيان نظام الملفات يحتوي على دعم سلامة البيانات. |
| Normal | 128 | كيان نظام الملفات هو ملف لا يحتوي على خصائص خاصة. |
| NotContentIndexed | 8192 | كيان نظام الملفات لن يتم فهرسته بواسطة خدمة فهرسة المحتوى. |
| NoScrubData | 131072 | كيان نظام الملفات غير مشمول في فحص سلامة البيانات. |
| Offline | 4096 | كيان نظام الملفات غير متصل ولا تتوفر بياناته على الفور. |
| ReadOnly | 1 | كيان نظام الملفات للقراءة فقط. |
| ReparsePoint | 1024 | كيان نظام الملفات هو ملف يحتوي على نقطة إعادة تحليل. |
| SparseFile | 512 | كيان نظام الملفات هو ملف متفرق. |
| System | 4 | كيان نظام الملفات هو ملف نظام. |
| Temporary | 256 | كيان نظام الملفات هو ملف مؤقت. |
| Invalid | 0 | قيمة غير صالحة. |
