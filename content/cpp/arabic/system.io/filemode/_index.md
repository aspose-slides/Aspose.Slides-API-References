## FileMode تعداد

Specifies how a file should be opened.

```cpp
enum class FileMode
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| CreateNew | 1 | إنشاء ملف جديد. إذا كان الملف موجودًا مسبقًا، يتم إلقاء استثناء. |
| Create | 2 | إنشاء ملف جديد. إذا كان الملف موجودًا مسبقًا، يتم استبداله. |
| Open | 3 | فتح ملف موجود. إذا لم يكن الملف موجودًا، يتم إلقاء استثناء. |
| OpenOrCreate | 4 | فتح ملف موجود أو إنشاء ملف جديد إذا لم يكن موجودًا. |
| Truncate | 5 | فتح ملف موجود وتقطيعه بحيث يصبح فارغًا. إذا لم يكن الملف موجودًا، يتم إلقاء استثناء. |
| Append | 6 | فتح ملف موجود والانتقال إلى نهايته أو إنشاء ملف جديد إذا لم يكن موجودًا. |
