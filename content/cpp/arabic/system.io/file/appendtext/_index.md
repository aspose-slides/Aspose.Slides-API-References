## File::AppendText(const String\&) طريقة

ينشئ كائن [StreamWriter](../../streamwriter/) يضيف النص إلى الملف المحدد باستخدام ترميز UTF-8. إذا لم يكن الملف المحدد موجودًا، يتم إنشاءه.

```cpp
static StreamWriterPtr System::IO::File::AppendText(const String &path)
```

| المعامل | النوع | الوصف |
| --- | --- | --- |
| path | const [String](../../../system/string/)\& | مسار الملف لفتحه أو إنشائه |

### قيمة الإرجاع

مؤشر مشترك إلى كائن [StreamWriter](../../streamwriter/) الذي تم إنشاؤه والمتعلق بالملف المحدد
