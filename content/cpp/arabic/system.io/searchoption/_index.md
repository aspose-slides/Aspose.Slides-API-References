## SearchOption تعداد

Specifies a search should be performed only in the current directory, or in the current directory and all its subdirectories.

```cpp
enum class SearchOption
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| AllDirectories | 0 | البحث في الدليل الحالي وجميع الدلائل الفرعية. |
| TopDirectoryOnly | 1 | البحث في الدليل الحالي فقط. |
