## InkEffectType تعداد

Specifies a set of predefined visual effects for ink rendering. Each effect corresponds to a texture or image that simulates a stylized ink appearance. These values can be used to customize the visual style of digital ink strokes during rendering.

```cpp
enum class InkEffectType
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| NotDefined | -1 | التأثير غير معرف أو غير معروف. يمكن استخدام هذه القيمة كافتراضية أو بديلة. |
| Bronze | 0 | نسيج معدني دافئ بني يماثل حبر البرونز. |
| Galaxy | 1 | نسيج ملون متلألئ يشبه المجرة، بألوان كونية. |
| Gold | 2 | نسيج ذهبي معدني ساطع يمنح حبر الخطوط مظهرًا فاخرًا. |
| Lava | 3 | نسيج ناري يشبه الحمم المنصهرة، بألوان أحمر وبرتقالي. |
| Ocean | 4 | نسيج أزرق عميق يشبه الأمواج أو الحبر المائي. |
| RainbowGlitter | 5 | تأثير بريق قوس قزح ملون يُستخدم للخطوط الاحتفالية أو الزاهية. |
| RoseGold | 6 | مزيج وردي-ذهبي ناعم يشبه الروز جولد، للخطوط الأنيقة. |
| Silver | 7 | نسيج فضي معدني بارد يحاكي حبر الفضة الكلاسيكي. |
