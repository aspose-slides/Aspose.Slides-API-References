## فئة WebServiceAttribute

يضيف معلومات إضافية إلى خدمة XML [Web](../../system.web/). يجب إنشاء كائنات هذه الفئة باستخدام الدالة [System::MakeObject()](../../system/makeobject/) فقط. لا تقم أبداً بإنشاء مثال من هذا النوع على المكدس أو باستخدام المشغل new، لأن ذلك سيؤدي إلى أخطاء في وقت التشغيل و/أو أخطاء تأكيدية. قم دائماً بلف هذه الفئة في مؤشر [System::SmartPtr](../../system/smartptr/) واستخدم هذا المؤشر لتمريرها إلى الدوال كمعامل.

```cpp
class WebServiceAttribute : public System::Attribute
```
