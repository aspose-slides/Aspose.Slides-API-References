## EncryptionPolicy تعداد

يعدّد سياسات التشفير.

```cpp
enum class EncryptionPolicy
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| RequireEncryption | 0 | يتطلب التشفير ولا يسمح أبداً بشيفرة 'Null'. |
| AllowNoEncryption | 1 | يفضّل استخدام تشفير كامل لكن يمكن استخدام شيفرة 'Null' إذا كان الخادم يوافق. |
| NoEncryption | 2 | يسمح بعدم التشفير ويطلب استخدام شيفرة 'Null' إذا كان الطرف الآخر قادرًا على التعامل مع شيفرة 'Null'. |
