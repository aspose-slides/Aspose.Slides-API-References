## AuthenticationLevel تعداد

علامات المصادقة الخاصة بـ WebRequest.

```cpp
enum class AuthenticationLevel
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| None | 0 | لا يتطلب المصادقة للعميل والخادم. |
| MutualAuthRequested | 1 | لا يفشل الطلب إذا لم يتم المصادقة على الخادم. |
| MutualAuthRequired | 2 | ستتلقى التطبيق الحالي استثناء 'IOException' عندما لا يتم المصادقة على الخادم. |
