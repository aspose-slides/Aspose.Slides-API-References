## SoapDocumentServiceAttribute الفئة

يضبط التنسيق الافتراضي لطلبات SOAP والاستجابات. يجب إنشاء كائنات هذه الفئة باستخدام الدالة [System::MakeObject()](../../system/makeobject/) فقط. لا تقم بإنشاء نسخة من هذا النوع على الذاكرة المؤقتة أو باستخدام العامل new، لأن ذلك سيتسبب في أخطاء وقت تشغيل و/أو أخطاء تأكيد. دائمًا قم بتغليف هذه الفئة في مؤشر [System::SmartPtr](../../system/smartptr/) واستخدم هذا المؤشر لتمريره إلى الدوال كوسيط.

```cpp
class SoapDocumentServiceAttribute : public System::Attribute
```
