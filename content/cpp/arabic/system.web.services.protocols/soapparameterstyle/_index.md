## SoapParameterStyle enum

يقوم بتعداد صيغ المعلمات في رسالة SOAP.

```cpp
enum class SoapParameterStyle
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| Default | 0 | إذا لم يتم تطبيق '[SoapDocumentServiceAttribute](../soapdocumentserviceattribute/)' على الـ صف، فإن القيمة الافتراضية هي 'Wrapped'. |
| Bare | 1 | يتم وضع المعلمات في عناصر XML التي تلي عنصر 'Body' العنصر. |
| Wrapped | 2 | يتم احتواء المعلمات داخل عنصر XML واحد يتبع عنصر 'Body' العنصر. |
