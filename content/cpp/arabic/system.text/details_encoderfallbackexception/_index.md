## فئة Details_EncoderFallbackException

استثناء يُرمى بواسطة [EncoderExceptionFallback](../encoderexceptionfallback/) عندما يفشل الترميز. لا تُنشئ أبداً مثيلات هذه الفئة يدويًا. استخدم فئة EncoderFallbackException بدلًا من ذلك. لا تُغلف أبدًا مثيلات فئة EncoderFallbackException داخل [System::SmartPtr](../../system/smartptr/).

```cpp
class Details_EncoderFallbackException : public System::Details_ArgumentException
```
