## GraphicsUnit enum

Represents a unit of measure.

```cpp
enum class GraphicsUnit
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| World | 0 | إحداثيات عالمية (وحدة غير مادية). |
| Display | 1 | وحدات القياس لجهاز العرض. |
| Pixel | 2 | بكسل الجهاز. |
| Point | 3 | نقطة الطابعة (1/72 من البوصة). |
| Inch | 4 | بوصة واحدة. |
| Document | 5 | 1/300 من البوصة. |
| Millimeter | 6 | مليمتر واحد. |
