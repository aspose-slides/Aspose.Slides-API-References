## Rectangle::Offset(const Point\&) طريقة

Offsets the position of the rectangle represented by the current object by the specified amounts.

```cpp
void System::Drawing::Rectangle::Offset(const Point &pos)
```

### المعاملات

| المعامل | النوع | الوصف |
| --- | --- | --- |
| pos | const [Point](../../point/)\& | كائن [Point](../../point/) الذي يحدد مقدار إزاحة المستطيل؛ قيمة X للنقطة تحدد مقدار الإضافة إلى إحداثي X للزاوية العلوية اليسرى للمستطيل وقيمة Y للنقطة تحدد مقدار الإضافة إلى إحداثي Y للزاوية العلوية اليسرى للمستطيل |
