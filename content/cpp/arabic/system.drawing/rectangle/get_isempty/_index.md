## Rectangle::get_IsEmpty() const طريقة

يحدد ما إذا كانت إحداثيات X و Y للزاوية العليا اليسرى للمستطيل الممثَّل بواسطة الكائن الحالي، وكذلك width و height، لديها قيم تساوي 0.

```cpp
bool System::Drawing::Rectangle::get_IsEmpty() const
```

### قيمة الإرجاع

True إذا كانت إحداثيات X و Y للزاوية العليا اليسرى للمستطيل الممثَّل بواسطة الكائن الحالي، وكذلك width و height، لديها قيم تساوي 0، وإلا - false
