## تعداد StringFormatFlags

يحدد معلومات العرض وتنسيق النص للسلاسل النصية.

```cpp
enum class StringFormatFlags
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| DirectionRightToLeft | 1 | اتجاه النص من اليمين إلى اليسار. |
| DirectionVertical | 2 | [Text](../../system.drawing.text/) مصفوف عموديًا. |
| FitBlackBox | 4 | يمكن لأجزاء الأحرف أن تخرج عن صندوق التخطيط. |
| DisplayFormatControl | 32 | يتم عرض أحرف التحكم. |
| NoFontFallback | 1024 | [Font](../font/) الرجوع غير مفعل. |
| MeasureTrailingSpaces | 2048 | يقوم بإدراج المسافة المتدلية في نهاية كل سطر. |
| NoWrap | 4096 | [Text](../../system.drawing.text/) الالتفاف غير مفعل. |
| LineLimit | 8192 | يتم تنسيق السطور بالكامل داخل المستطيل التنسيقي. |
| NoClip | 16384 | الأجزاء المتدلية من الرموز مسموح بإظهارها. |
