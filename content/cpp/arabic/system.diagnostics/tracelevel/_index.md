## TraceLevel enum

يحدد الرسائل التي يجب إخراجها لـ [System.Diagnostics.Debug](../debug/) و [System.Diagnostics.Trace](../trace/) وفئات System.Diagnostics.TraceSwitch.

```cpp
enum class TraceLevel
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| Off | 0 | إخراج لا توجد رسائل تتبع وتصحيح. |
| Error | 1 | إخراج رسائل معالجة الأخطاء. |
| Warning | 2 | إخراج التحذيرات ورسائل معالجة الأخطاء. |
| Info | 3 | إخراج رسائل معلوماتية، وتحذيرات، ورسائل معالجة الأخطاء. |
| Verbose | 4 | إخراج جميع رسائل التصحيح والتتبع. |
