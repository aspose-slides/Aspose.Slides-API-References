## DbConnectionStringBuilder فئة

API لإنشاء سلسلة الاتصال من الحقول المسماة. يجب تخصيص كائنات هذه الفئة فقط باستخدام الدالة [System::MakeObject()](../../system/makeobject/). لا تقم أبدًا بإنشاء نسخة من هذا النوع على المكدس أو باستخدام العامل new، لأن ذلك سيسبّب أخطاء وقت تشغيل أو أعطال تأكيد. احwrap هذه الفئة دائمًا في مؤشر [System::SmartPtr](../../system/smartptr/) واستخدم هذا المؤشر لتمريره إلى الدوال كمعامل.

```cpp
class DbConnectionStringBuilder : public System::Object
```
