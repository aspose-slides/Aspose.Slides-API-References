## الفئة DbProviderFactory

مزود للوصول إلى قاعدة البيانات. يجب تخصيص كائنات هذه الفئة فقط باستخدام الدالة [System::MakeObject()](../../system/makeobject/). لا تقم أبدًا بإنشاء مثيل لهذا النوع على المكدس أو باستخدام مشغل new، حيث سيؤدي ذلك إلى أخطاء وقت التشغيل أو أخطاء التحقق. احرص دائمًا على تغليف هذه الفئة بمؤشر [System::SmartPtr](../../system/smartptr/) واستخدام هذا المؤشر لتمريره إلى الدوال كوسيطة.

```cpp
class DbProviderFactory : public System::Object
```
