## BaseDictionary::end() const دالة

إرجاع مؤشر إلى الغلاف KVPair-wrapper لعنصر المفتاح-القيمة المتبع للعنصر الأخير في الحاوية. تم التنفيذ بنمط C# - يجب أن يُعيد المؤشر كائن KVPair-object مع واجهة get_Key() و get_Value(). يعمل هذا العنصر كعنصر نائب؛ محاولة الوصول إليه تؤدي إلى سلوك غير معرف.

```cpp
const_iterator System::Collections::Generic::BaseDictionary<Map>::end() const noexcept
```
