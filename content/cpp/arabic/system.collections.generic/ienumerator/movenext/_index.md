## IEnumerator::MoveNext() طريقة

يقوم بنقل المُعدد إلى العنصر التالي. إذا لم يتم الإشارة إلى أي عنصر مسبقًا، يضبط الإشارة إلى أول عنصر متاح. إذا تم الوصول إلى نهاية الحاوية، لا يفعل شيئًا.

```cpp
virtual bool System::Collections::Generic::IEnumerator<T>::MoveNext()=0
```

### قيمة الإرجاع

True إذا كان هناك عنصر متاح بعد الاستدعاء، false وإلا.
