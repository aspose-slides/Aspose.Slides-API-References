## MathPhantom::set_Transp(bool) طريقة

يضبط قيمة تشير إلى ما إذا كان الفانتوم شفافًا لقواعد التباعد المستندة إلى الفئة.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_Transp(bool value) override
```

## ملاحظات

عند **true**، العوامل والرموز داخل الفانتوم لا تزال تؤثر على التباعد الرياضي حول الفانتوم (كما لو كان مرئيًا). عند **false**، يتم تجاهل التباعد المستند إلى الفئة. يتطابق مع سمة OMML **m:transp**.
