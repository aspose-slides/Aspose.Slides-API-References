## MathPhantom::set_ZeroDesc(bool) طريقة

يضبط قيمة تشير إلى ما إذا كان الانحدار (العمق أسفل خط القاعدة) للعنصر الأساسي يجب أن يُعامل كصفر.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_ZeroDesc(bool value) override
```

## ملاحظات

عند **true**، لا يقوم الـ phantom بخفض خط القاعدة للخط الرياضي المحيط. يتوافق مع صفة OMML **m:zeroDesc**.
