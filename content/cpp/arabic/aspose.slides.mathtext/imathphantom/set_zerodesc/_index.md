## IMathPhantom::set_ZeroDesc(bool) طريقة

## ملاحظات

عند **true**، لا يقوم الفانتوم بخفض الخط الأساسي لسطر الرياضيات المحيط. يتطابق مع خاصية OMML **m:zeroDesc**.
