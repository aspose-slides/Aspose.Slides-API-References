## IMathPhantom::set_Transp(bool) طريقة


يحدد قيمة تُشير إلى ما إذا كان الـ phantom شفافًا لقواعد التباعد المعتمدة على الفئة.

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_Transp(bool value)=0
```

## ملاحظات


عند **true**، لا يزال المشغلات والرموز داخل الـ phantom تؤثر على التباعد الرياضي حول الـ phantom (كما لو كان مرئيًا). عند **false**، يتم تجاهل التباعد القائم على الفئة. يتطابق مع سمة OMML **m:transp**.
