## IMathPhantom::set_ZeroAsc(bool) طريقة

يحدد قيمة تشير إلى ما إذا كان صعود (ارتفاع فوق خط القاعدة) للعنصر الأساسي ينبغي معاملته كصفر.

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_ZeroAsc(bool value)=0
```

## ملاحظات

عند **true**، لا يرفع الفانتوم خط القاعدة للخط الرياضي المحيط. يتطابق مع سمة OMML **m:zeroAsc**.
