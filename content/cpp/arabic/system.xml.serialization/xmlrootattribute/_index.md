## XmlRootAttribute فئة

Marks the attribute target as an XML root element and controls its XML serialization. Objects of this فئة should only be allocated using [System::MakeObject()](../../system/makeobject/) function. Never create instance of this type on stack or using operator new, as it will result in runtime errors and/or assertion faults. Always wrap this فئة into [System::SmartPtr](../../system/smartptr/) pointer and use this pointer to pass it to functions as argument.

```cpp
class XmlRootAttribute : public System::Object
```
