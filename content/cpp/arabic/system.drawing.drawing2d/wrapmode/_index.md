## WrapMode تعداد

يحدد كيفية تكرار النسيج أو التدرج عندما يكون أصغر من المنطقة التي يتم ملؤها.

```cpp
enum class WrapMode
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| Tile | 0 | يقوم بتكرار التدرج أو النسيج. |
| TileFlipX | 1 | يعكس النسيج أو التدرج أفقيًا ثم يقوم بتكراره. |
| TileFlipY | 2 | يعكس النسيج أو التدرج عموديًا ثم يقوم بتكراره. |
| TileFlipXY | 3 | يعكس النسيج أو التدرج أفقيًا وعموديًا ثم يقوم بتكراره. |
| Clamp | 4 | يقيد النسيج أو التدرج إلى حدود الكائن. |
