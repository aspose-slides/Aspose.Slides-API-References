## PixelOffsetMode enum

Specifies how pixels are offset when being rendered.

```cpp
enum class PixelOffsetMode
```

### Values

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| Invalid | n/a | قيمة غير صالحة. |
| Default | n/a | الوضع الافتراضي. |
| HighSpeed | n/a | وضع منخفض الجودة (أداء عالي). |
| HighQuality | n/a | وضع عالي الجودة (أداء أقل). |
| None | n/a | بدون إزاحة بكسل. |
| Half | n/a | يتم إزاحة البكسلات بمقدار -0.5 وحدة أفقياً وعمودياً للحصول على مضاد تمويه عالي الأداء. |
