## AxisAggregationType enum

يمثل نوع التجميع لمحور الفئات. يُستخدم مع سلسلات Histogram أو HistogramPareto فقط.

```cpp
enum class AxisAggregationType
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| ByCategory | 0 | تجميع حسب الفئات |
| Automatic | 1 | تجميع الفئات تلقائيًا. |
| ByBinWidth | 2 | تجميع الفئات وفقًا لعرض الفواصل. يجب ضبط الخاصية IAxis::get(set)_BinWidth. |
| ByNumberOfBins | 3 | تجميع الفئات وفقًا لعدد الفواصل. يجب ضبط الخاصية IAxis::get(set)_NumberOfBins. |
