## ChartCategoryCollection::set_UseCells(bool) طريقة

إذا كان true فإن ورقة العمل تُستخدم لتخزين الفئات (هذه الحالة تدعم الفئات متعددة المستويات). إذا كان false فإن ورقة العمل لا تُستخدم لتخزين القيم (وهذه الحالة لا تدعم الفئات متعددة المستويات). كتابة **bool**.
