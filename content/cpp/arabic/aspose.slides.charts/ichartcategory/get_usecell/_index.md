## IChartCategory::get_UseCell() طريقة

إذا كان true فإن الخاصية AsCell فعلية. بعبارة أخرى، worksheet تُستخدم لتخزين الفئة (هذا الحالة تدعم فئة متعددة المستويات). إذا كان false فإن الخاصية AsLiteral فعلية. بعبارة أخرى، worksheet لا تُستخدم لتخزين الفئة (وهذا الحالة لا تدعم فئات متعددة المستويات). قراءة فقط **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IChartCategory::get_UseCell()=0
```

## ملاحظات

لتغيير قيمة هذه الخاصية (لكل الفئات في المجموعة) اضبط القيمة الجديدة إلى الخاصية ChartCategoryCollection.UseCells.
