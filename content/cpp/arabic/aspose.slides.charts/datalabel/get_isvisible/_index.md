## DataLabel::get_IsVisible() طريقة

False يعني أن تسمية البيانات غير مرئية (and so all Show*-flags (ShowValue, ...) are false). قراءة فقط **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabel::get_IsVisible() override
```

## ملاحظات

إذا كانت تسمية البيانات مرئية يمكنك إخفاؤها باستخدام [Hide()](../hide/) طريقة. ولكن إذا كانت تسمية البيانات غير مرئية (IsVisible is false) يمكنك جعلها مرئية عن طريق ضبط Show*-flags (ShowValue, ...) إلى الحالة true.
