## IDataLabelFormat::set_ShowLeaderLines(bool) طريقة

يمثل سلوك عرض خطوط القائد لتسمية البيانات في مخطط محدد. True تعرض خطوط القائد. False لإخفائها. اكتب **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowLeaderLines(bool value)=0
```

## ملاحظات

إذا كان عنصر [DataLabelFormat](../../datalabelformat/) الأب لهذا هو مجموعة [DataLabelCollection](../../datalabelcollection/) من تسميات البيانات، فإن هذه الخاصية تحصل أو تعين القيمة الافتراضية للخاصية ShowLeaderLines لتسميات البيانات الجديدة في مجموعة [DataLabelCollection](../../datalabelcollection/). ضبط هذه الخاصية بالقيمة يضبط أيضاً هذه القيمة للخاصية ShowLeaderLines لجميع تسميات البيانات في مجموعة [DataLabelCollection](../../datalabelcollection/) (على سبيل المثال "DataLabels.DefaultDataLabelFormat.ShowLeaderLines = val;" تسبب أن جميع DataLabels[i].ShowLeaderLines تساوي val).
