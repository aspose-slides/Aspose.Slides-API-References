## IDataLabelFormat::set_ShowLegendKey(bool) طريقة

يمثل سلوك عرض مفتاح وسيلة الإيضاح لتسمية البيانات في مخطط محدد. يكون True إذا كان مفتاح وسيلة الإيضاح لتسمية البيانات مرئياً. كتابة **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowLegendKey(bool value)=0
```

## الملاحظات

إذا كان الأصل لهذا الكائن [DataLabelFormat](../../datalabelformat/) هو مجموعة [DataLabelCollection](../../datalabelcollection/) لتسميات البيانات، فإن هذه الخاصية تحصل أو تعيين القيمة الافتراضية لخاصية ShowLegendKey للتسميات الجديدة في مجموعة [DataLabelCollection](../../datalabelcollection/). ضبط هذه الخاصية بالقيمة يؤدي أيضاً إلى تعيين هذه القيمة لخاصية ShowLegendKey لجميع تسميات البيانات في مجموعة [DataLabelCollection](../../datalabelcollection/) (أي "DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;" يتسبب في أن جميع DataLabels[i].ShowLegendKey يساوي val).
