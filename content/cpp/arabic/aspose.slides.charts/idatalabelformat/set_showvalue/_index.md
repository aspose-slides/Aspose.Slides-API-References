## IDataLabelFormat::set_ShowValue(bool) طريقة

يمثّل سلوك عرض قيمة النسبة المئوية لتسمية البيانات في مخطط محدد. true يعرض قيمة النسبة المئوية. false لإخفائها. اكتب **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowValue(bool value)=0
```

## ملاحظات

إذا كان الأصل لهذا الكائن [DataLabelFormat](../../datalabelformat/) هو مجموعة [DataLabelCollection](../../datalabelcollection/) من تسميات البيانات، فإن هذه الخاصية تحصل على أو تعيّن القيمة الافتراضية للخاصية ShowValue لتسميات البيانات الجديدة في مجموعة [DataLabelCollection](../../datalabelcollection/). تعيين هذه الخاصية بالقيمة أيضاً يعيّن هذه القيمة لخاصية ShowValue لجميع تسميات البيانات في مجموعة [DataLabelCollection](../../datalabelcollection/) (على سبيل المثال "DataLabels.DefaultDataLabelFormat.ShowValue = val;" يؤدي إلى أن تكون DataLabels[i].ShowValue مساوية لـ val).
