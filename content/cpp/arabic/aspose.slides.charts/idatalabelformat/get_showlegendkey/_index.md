## IDataLabelFormat::get_ShowLegendKey() طريقة

يمثل سلوك عرض مفتاح وسيلة الإيضاح لتسمية البيانات لمخطط محدد. True إذا كان مفتاح وسيلة الإيضاح لتسمية البيانات مرئيًا. إرجاع **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowLegendKey()=0
```

## ملاحظات

إذا كان عنصر [DataLabelFormat](../../datalabelformat/) الأب هو مجموعة [DataLabelCollection](../../datalabelcollection/) لتسميات البيانات فإن هذه الخاصية تحصل أو تحدد قيمة ShowLegendKey الافتراضية لتسميات البيانات الجديدة في مجموعة [DataLabelCollection](../../datalabelcollection/). ضبط هذه الخاصية بالقيمة سيضبط أيضًا هذه القيمة لخاصية ShowLegendKey لجميع تسميات البيانات في مجموعة [DataLabelCollection](../../datalabelcollection/) (أي "DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;" يؤدي إلى أن يكون ShowLegendKey لكل DataLabels[i] مساويًا للقيمة).
