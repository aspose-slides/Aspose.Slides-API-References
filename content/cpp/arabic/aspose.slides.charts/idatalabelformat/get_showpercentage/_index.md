## IDataLabelFormat::get_ShowPercentage() طريقة

يمثل سلوك عرض قيمة النسبة المئوية لتسمية البيانات لمخطط محدد. True يعرض قيمة النسبة المئوية. False لإخفائها. قراءة **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowPercentage()=0
```

## ملاحظات

إذا كان العنصر الأب لهذا [DataLabelFormat](../../datalabelformat/) هو مجموعة [DataLabelCollection](../../datalabelcollection/) لتسميات البيانات، فإن هذه الخاصية تحصل على أو تعيين القيمة الافتراضية لخاصية ShowPercentage لتسميات البيانات الجديدة في مجموعة [DataLabelCollection](../../datalabelcollection/). تعيين هذه الخاصية بقيمة يضبط أيضًا هذه القيمة لخاصية ShowPercentage لجميع تسميات البيانات في مجموعة [DataLabelCollection](../../datalabelcollection/) (i.e. \"DataLabels.DefaultDataLabelFormat.ShowPercentage = val;\" يؤدي إلى أن جميع DataLabels[i].ShowPercentage يساوي val).
