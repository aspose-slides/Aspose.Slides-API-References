## DataLabelFormat::set_ShowLegendKey(bool) طريقة

Represents a specified chart's data label legend key display behavior. True if the data label legend key is visible. Write **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLegendKey(bool value) override
```

## ملاحظات

إذا كان العنصر الأب لهذا [DataLabelFormat](../) هو مجموعة [DataLabelCollection](../../datalabelcollection/) لملصقات البيانات فإن هذه الخاصية تحصل أو تعيين القيمة الافتراضية لخاصية ShowLegendKey لملصقات البيانات الجديدة في مجموعة [DataLabelCollection](../../datalabelcollection/). تعيين هذه الخاصية بالقيمة يضبط أيضاً هذه القيمة لخاصية ShowLegendKey لجميع ملصقات البيانات في مجموعة [DataLabelCollection](../../datalabelcollection/) (أي "DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;" يؤدي إلى أن جميع DataLabels[i].ShowLegendKey يساوي val).
