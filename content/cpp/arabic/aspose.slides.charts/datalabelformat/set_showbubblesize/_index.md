## DataLabelFormat::set_ShowBubbleSize(bool) طريقة

يمثل سلوك عرض قيمة حجم الفقاعة لتسمية البيانات في مخطط محدد. True يعرض قيمة حجم الفقاعة. False لإخفائها. كتابة **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowBubbleSize(bool value) override
```

## ملاحظات

إذا كان الاصل لهذا الكائن [DataLabelFormat](../) هو مجموعة [DataLabelCollection](../../datalabelcollection/) من تسميات البيانات، فإن هذه الخاصية تحصل أو تعين القيمة الافتراضية لخاصية ShowBubbleSize لتسميات البيانات الجديدة في مجموعة [DataLabelCollection](../../datalabelcollection/). ضبط هذه الخاصية بالقيمة يضبط أيضًا هذه القيمة لخاصية ShowBubbleSize لجميع تسميات البيانات في مجموعة [DataLabelCollection](../../datalabelcollection/) (أي "DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;" ينتج أن جميع DataLabels[i].ShowBubbleSize يساوي val).
