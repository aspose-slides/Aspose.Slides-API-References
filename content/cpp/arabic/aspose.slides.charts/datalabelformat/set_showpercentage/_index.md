## DataLabelFormat::set_ShowPercentage(bool) طريقة

يمثل سلوك عرض قيمة النسبة المئوية لتسمية البيانات في مخطط محدد. **True** يعرض قيمة النسبة المئوية. **False** لإخفائها. اكتب **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowPercentage(bool value) override
```

## ملاحظات

إذا كان الأصل لهذا الكائن [DataLabelFormat](../) هو مجموعة [DataLabelCollection](../../datalabelcollection/) لتسميات البيانات، فإن هذه الخاصية تحصل على أو تعيين القيمة الافتراضية لخاصية ShowPercentage لتسميات البيانات الجديدة في مجموعة [DataLabelCollection](../../datalabelcollection/). ضبط هذه الخاصية بالقيمة يضبط أيضاً هذه القيمة لخاصية ShowPercentage لجميع تسميات البيانات في مجموعة [DataLabelCollection](../../datalabelcollection/) (مثلًا \"DataLabels.DefaultDataLabelFormat.ShowPercentage = val;\" يؤدي إلى أن تكون جميع DataLabels[i].ShowPercentage مساوية لـ val).
