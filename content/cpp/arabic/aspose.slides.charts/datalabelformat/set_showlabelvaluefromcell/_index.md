## DataLabelFormat::set_ShowLabelValueFromCell(bool) الطريقة

يمثل سلوك عرض قيمة خلية تسمية البيانات لمخطط محدد. True يعرض قيمة الخلية. False لإخفائها. اكتب **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLabelValueFromCell(bool value) override
```

## ملاحظات

إذا كان أصل هذا [DataLabelFormat](../) كائن هو مجموعة [DataLabelCollection](../../datalabelcollection/) من تسميات البيانات، فإن هذه الخاصية تحصل على أو تعين القيمة الافتراضية لخاصية ShowLabelValueFromCell لتسميات البيانات الجديدة في مجموعة [DataLabelCollection](../../datalabelcollection/). تعيين هذه الخاصية بقيمة أيضًا يعين هذه القيمة لخاصية ShowLabelValueFromCell لجميع تسميات البيانات في مجموعة [DataLabelCollection](../../datalabelcollection/) (أي "DataLabels.DefaultDataLabelFormat.ShowLabelValueFromCell = val;" تسبب في أن جميع DataLabels[i].ShowLabelValueFromCell يساوي val).
