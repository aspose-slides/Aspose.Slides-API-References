## DataLabelFormat::set_ShowSeriesName(bool) method

يُعيّن قيمة منطقية لتحديد سلوك عرض اسم السلسلة لتسميات البيانات على المخطط. True لإظهار اسم السلسلة. False لإخفائه. Write **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowSeriesName(bool value) override
```

## ملاحظات

إذا كان العنصر الأب لهذا الكائن [DataLabelFormat](../) هو مجموعة [DataLabelCollection](../../datalabelcollection/) لتسميات البيانات، فإن هذه الخاصية تحصل أو تُعيّن القيمة الافتراضية لخاصية ShowSeriesName لتسميات البيانات الجديدة في مجموعة [DataLabelCollection](../../datalabelcollection/). تعيين هذه الخاصية بالقيمة يؤدي أيضًا إلى تعيين هذه القيمة لخاصية ShowSeriesName لجميع تسميات البيانات في مجموعة [DataLabelCollection](../../datalabelcollection/) (أي "DataLabels.DefaultDataLabelFormat.ShowSeriesName = val;" يؤدي إلى أن تكون جميع DataLabels[i].ShowSeriesName مساوية لـ val).
