## DataLabelFormat::set_Separator(System::String) طريقة

يضبط أو يرجع Variant يمثل الفاصل المستخدم لتسميات البيانات في المخطط. اكتب [System::String](../../../system/string/).

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_Separator(System::String value) override
```

## ملاحظات

إذا كان الأصل لهذا الكائن [DataLabelFormat](../) هو مجموعة [DataLabelCollection](../../datalabelcollection/) لتسميات البيانات، فإن هذه الخاصية تحصل أو تُعيّن القيمة الافتراضية لخاصية Separator لتسميات البيانات الجديدة في مجموعة [DataLabelCollection](../../datalabelcollection/). تعيين هذه الخاصية بقيمة سيؤدي أيضًا إلى تعيين هذه القيمة لخاصية Separator لجميع تسميات البيانات في مجموعة [DataLabelCollection](../../datalabelcollection/) (مثال: \"DataLabels.DefaultDataLabelFormat.Separator = val;\" مما يجعل جميع DataLabels[i].Separator يساوي val).
