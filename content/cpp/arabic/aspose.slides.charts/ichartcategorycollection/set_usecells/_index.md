## IChartCategoryCollection::set_UseCells(bool) طريقة


إذا كان true فإن worksheet يُستخدم لتخزين الفئات (هذه الحالة تدعم فئات متعددة المستويات). إذا كان false فإن worksheet **ليس** يُستخدم لتخزين القيم (وهذه الحالة لا تدعم فئات متعددة المستويات). اكتب **bool**.

virtual void Aspose::Slides::Charts::IChartCategoryCollection::set_UseCells(bool value)=0
