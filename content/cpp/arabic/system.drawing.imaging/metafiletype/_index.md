## MetafileType enum

Represents a type of a graphic metafile.

```cpp
enum class MetafileType
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| Invalid | 0 | ملف تعريف رسومي غير صالح. |
| Wmf | 1 | WMF قياسي. |
| WmfPlaceable | 2 | صيغة [Metafile](../metafile/) القابلة للتموضع. |
| Emf | 3 | EMF (ليس EMF+). |
| EmfPlusOnly | 4 | EMF+ دون سجلات مزدوجة، منخفضة المستوى. |
| EmfPlusDual | 5 | EMF+ مع سجلات مزدوجة، منخفضة المستوى. |
