## HMACSHA1 فئة

رمز الرسالة المعتمد على التجزئة [Authentication](../../system.security.authentication/) الذي يستخدم دالة التجزئة [SHA1](../sha1/). غير مُنفَّذ. يجب تخصيص كائنات هذه الفئة فقط باستخدام دالة [System::MakeObject()](../../system/makeobject/). لا تقم بإنشاء مثال لهذا النوع على المكدس أو باستخدام المُعامل new، حيث سيؤدي ذلك إلى أخطاء وقت التشغيل و/أو أعطال التحقق. دائمًا غلف هذه الفئة في مؤشر [System::SmartPtr](../../system/smartptr/) واستخدم هذا المؤشر لتمريره إلى الدوال كمعامل.

```cpp
class HMACSHA1 : public System::Security::Cryptography::HashAlgorithm
```
