## بنية DSAParameters

[Data](../../system.data/) بنية معلمات خوارزمية [DSA](../dsa/). يجب تخصيص هذا النوع على المكدس وتمريره إلى الدوال بالقيمة أو بالمرجع. لا تستخدم الفئة [System::SmartPtr](../../system/smartptr/) لإدارة كائنات هذا النوع.

```cpp
class DSAParameters : public System::Object
```
