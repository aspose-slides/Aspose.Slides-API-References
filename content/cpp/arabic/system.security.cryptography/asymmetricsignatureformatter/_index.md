## AsymmetricSignatureFormatter class


الفئة الأساسية للمنسقات غير المتناظرة للتوقيع. يجب تخصيص كائنات هذه الفئة فقط باستخدام الدالة [System::MakeObject()](../../system/makeobject/). لا تقم أبدًا بإنشاء نسخة من هذا النوع على المكدس أو باستخدام عامل new، لأن ذلك سيؤدي إلى أخطاء وقت التنفيذ و/أو أخطاء التأكيد. دائمًا غلف هذه الفئة في المؤشر [System::SmartPtr](../../system/smartptr/) واستخدم هذا المؤشر لتمريره إلى الدوال كمعامل.

```cpp
class AsymmetricSignatureFormatter : public System::Object
```
