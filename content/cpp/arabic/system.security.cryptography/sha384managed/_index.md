## SHA384Managed الفئة

Managed [SHA384](../sha384/) hasher. Not implemented. Objects of this الفئة should only be allocated using [System::MakeObject()](../../system/makeobject/) دالة. Never create instance of this type on stack or using operator new, as it will result in أخطاء تشغيلية and/or أخطاء تأكيد. Always wrap this الفئة into [System::SmartPtr](../../system/smartptr/) pointer and use this pointer to pass it to دوال as argument.

```cpp
class SHA384Managed : public System::Security::Cryptography::SHA384
```
