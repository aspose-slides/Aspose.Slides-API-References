## AsymmetricAlgorithm الفئة

فئة أساسية مجردة لتشفير غير المتناظر. يجب إنشاء كائنات هذه الفئة باستخدام الدالة [System::MakeObject()](../../system/makeobject/) فقط. لا تُنشئ مثيلًا من هذا النوع على المكدس أو باستخدام المعامل new، لأن ذلك سيسبب أخطاء وقت التشغيل أو أخطاء تأكيد. قم دائمًا بلف هذه الفئة في مؤشر [System::SmartPtr](../../system/smartptr/) واستخدم هذا المؤشر لتمريره إلى الدوال كوسيط.

```cpp
class AsymmetricAlgorithm : public virtual System::Object,
                            public System::IDisposable
```
