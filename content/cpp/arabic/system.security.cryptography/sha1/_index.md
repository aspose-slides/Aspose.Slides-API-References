## فئة SHA1

يحسب [SHA1](./) تجزئة للبيانات المدخلة. في C++ [SHA1](./) ليست فئة تجريدية. يجب تخصيص كائنات هذه الفئة باستخدام الدالة [System::MakeObject()](../../system/makeobject/) فقط. لا تقم بإنشاء مثال من هذا النوع على المكدس أو باستخدام العامل new، لأن ذلك سيسبّب أخطاء وقت التشغيل أو عطل في التأكيد. يجب دائمًا تغليف هذه الفئة في مؤشر [System::SmartPtr](../../system/smartptr/) واستخدام هذا المؤشر لتمريره إلى الدوال كمعامل.

```cpp
class SHA1 : public System::Security::Cryptography::HashAlgorithm
```
