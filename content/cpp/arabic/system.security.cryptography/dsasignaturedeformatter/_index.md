## DSASignatureDeformatter فئة

يُستخدم للتحقق من توقيعات [DSA](../dsa/). يجب إنشاء كائنات هذه الفئة باستخدام الدالة [System::MakeObject()](../../system/makeobject/) فقط. لا تقم بإنشاء مثال من هذا النوع على المكدس أو باستخدام عامل new، لأنه سيؤدي إلى أخطاء وقت تشغيل أو أخطاء تأكيد. دائمًا قم بربط هذه الفئة بمؤشر [System::SmartPtr](../../system/smartptr/) واستخدم هذا المؤشر لتمريره إلى الدوال كمعامل.

```cpp
class DSASignatureDeformatter : public System::Security::Cryptography::AsymmetricSignatureDeformatter
```
