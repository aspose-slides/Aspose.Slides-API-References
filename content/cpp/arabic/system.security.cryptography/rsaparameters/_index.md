## RSAParameters بنية

[Data](../../system.data/) بنية معلمات خوارزمية [RSA](../rsa/). يجب تخصيص هذا النوع على المكدس وتمريره إلى الدوال بالقيمة أو بالمرجع. لا تستخدم أبداً فئة [System::SmartPtr](../../system/smartptr/) لإدارة كائنات هذا النوع.

```cpp
class RSAParameters : public System::Object
```
