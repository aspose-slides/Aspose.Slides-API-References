## فئة SHA512

يحسب تجزئة [SHA512](./) لبيانات الإدخال. في C++ [SHA512](./) ليست فئة تجريدية. يجب تخصيص كائنات هذه الفئة فقط باستخدام الدالة [System::MakeObject()](../../system/makeobject/). لا تقم أبداً بإنشاء مثيل من هذا النوع على المكدس أو باستخدام العامل new، لأن ذلك سيؤدي إلى أخطاء وقت التشغيل أو أخطاء التأكيد. احطِ دائماً هذه الفئة بمؤشر [System::SmartPtr](../../system/smartptr/) واستخدم هذا المؤشر لتمريره إلى الدوال كوسيطة.

```cpp
class SHA512 : public System::Security::Cryptography::HashAlgorithm
```
