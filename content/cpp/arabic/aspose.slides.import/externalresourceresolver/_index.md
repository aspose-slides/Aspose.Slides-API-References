## ملاحظات

قد يخلق استخدام هذا المحلّل ثغرة عندما يُوفر العميل ملف HTML أو SVG يجعل برنامج الخادم يحصل على ملف محلي أو شبكي. استخدمه بحذر. يُنصح بعدم تحديد [ExternalResourceResolver](./) نهائيًا (سيتم قراءة الكائنات المضمّنة فقط) أو إنشاء فئة فرعية تتحقق مما إذا كان الـ uri المحدد صالحًا.
