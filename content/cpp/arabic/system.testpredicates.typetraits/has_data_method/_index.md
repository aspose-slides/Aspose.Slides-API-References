## has_data_method بنية

يتحقق مما إذا كان النوع يمتلك الدالة data(). إذا كان كذلك، يرث std::true_type، وإلا يرث std::false_type.

```cpp
template<typename T,typename Enable>class has_data_method : public std::false_type
```

### معلمات القالب

| المعامل | الوصف |
| --- | --- |
| T | النوع المراد فحصه. |
| Enable | معامل رسمي لتمكين SFINAE. |
