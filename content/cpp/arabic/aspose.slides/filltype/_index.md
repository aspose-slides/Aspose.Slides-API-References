## FillType عدد

يحدد نوع التعبئة الداخلي لمختلف الكائنات البصرية.

```cpp
enum class FillType : int8_t
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| NotDefined | -1 | نوع التعبئة غير معرف. |
| NoFill | 0 | لم يتم تطبيق أي تعبئة. |
| Solid | 1 | مملوء بلون ثابت. |
| Gradient | 2 | التعبئة متدرجة. |
| Pattern | 3 | يُستخدم نمط متكرر لتعبئة الكائن. |
| Picture | 4 | يُستخدم صورة واحدة لتعبئة الكائن. |
| Group | 5 | الكائن المرئي يرث خصائص التعبئة من المجموعة. |
