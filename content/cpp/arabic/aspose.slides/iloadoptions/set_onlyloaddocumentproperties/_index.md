## ILoadOptions::set_OnlyLoadDocumentProperties(bool) طريقة

هذه الخاصية منطقية إذا كان ملف العرض محميًا بكلمة مرور. قيمة true تعني أن خصائص المستند فقط يجب تحميلها من ملف عرض مشفر ويجب تجاهل كلمة المرور. قيمة false تعني أن العرض المشفر بالكامل يجب تحميله باستخدام كلمة المرور الصحيحة. إذا لم يكن العرض مشفرًا فسيتم دائمًا تجاهل قيمة الخاصية. إذا لم تكن خصائص المستند لملف مشفر عامة وكانت قيمة الخاصية true فإن خصائص المستند لا يمكن تحميلها وسيتم رفع استثناء. يكتب **bool**.

```cpp
virtual void Aspose::Slides::ILoadOptions::set_OnlyLoadDocumentProperties(bool value)=0
```
