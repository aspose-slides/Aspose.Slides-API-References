## ILoadOptions::get_OnlyLoadDocumentProperties() طريقة


هذه الخاصية منطقية إذا كان ملف العرض محميًا بكلمة مرور. تعني القيمة true أن يتم تحميل خصائص المستند فقط من ملف عرض مشفر ويجب تجاهل كلمة المرور. تعني القيمة false أن يتم تحميل العرض المشفر بالكامل باستخدام كلمة المرور الصحيحة. إذا لم يكن العرض مشفرًا فسيتم دائمًا تجاهل قيمة الخاصية. إذا لم تكن خصائص المستند لملف مشفر عامة وكانت قيمة الخاصية true فإن خصائص المستند لا يمكن تحميلها وسيتم إلقاء استثناء. تقرأ **bool**.

```cpp
virtual bool Aspose::Slides::ILoadOptions::get_OnlyLoadDocumentProperties()=0
```
