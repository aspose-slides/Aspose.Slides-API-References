## Shape::set_Rotation(float) طريقة

يضبط عدد الدرجات التي يتم فيها تدوير الشكل المحدد حول محور z. القيمة الموجبة تشير إلى دوران باتجاه عقارب الساعة؛ القيمة السالبة تشير إلى دوران عكس اتجاه عقارب الساعة. اكتب **float**.

```cpp
void Aspose::Slides::Shape::set_Rotation(float value) override
```

## ملاحظات

القيمة المرجعة دائمًا معرفة (ليست std::numeric_limits<float>::quiet_NaN()). يجب أن تكون القيمة المعينة معرفة (ليس std::numeric_limits<float>::quiet_NaN()). يمكنك تعيين قيم غير معرفة لخصائص كائن RawFrame.
