## HyperlinkActionType تعداد

يمثل نوعًا من إجراءات الارتباط التشعبي.

```cpp
enum class HyperlinkActionType
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| Unknown | -1 | نوع الإجراء غير معروف. |
| NoAction | 0 | لا إجراء. |
| Hyperlink | 1 | ارتباط تشعبي عادي. |
| JumpFirstSlide | 2 | القفز إلى الشريحة الأولى في العرض التقديمي. |
| JumpPreviousSlide | 3 | القفز إلى الشريحة السابقة. |
| JumpNextSlide | 4 | القفز إلى الشريحة التالية. |
| JumpLastSlide | 5 | القفز إلى الشريحة الأخيرة في العرض التقديمي. |
| JumpEndShow | 6 | القفز إلى نهاية عرض الشرائح. |
| JumpLastViewedSlide | 7 | القفز إلى آخر شريحة تم مشاهدتها. |
| JumpSpecificSlide | 8 | القفز إلى الشريحة المحددة، المشار إليها بقيمة [IHyperlink::get_TargetSlide](../ihyperlink/get_targetslide/). |
| StartCustomSlideShow | 9 | بدء عرض شرائح مخصص. |
| OpenFile | 10 | فتح الملف المشار إليه. |
| OpenPresentation | 11 | فتح العرض التقديمي المشار إليه. |
| StartStopMedia | 12 | بدء/إيقاف تشغيل ملف الوسائط. |
| StartMacro | 13 | بدء تنفيذ برنامج الماكرو. |
| StartProgram | 14 | بدء البرنامج. |
