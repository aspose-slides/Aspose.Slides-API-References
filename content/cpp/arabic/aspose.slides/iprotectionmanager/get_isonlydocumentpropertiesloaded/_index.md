## IProtectionManager::get_IsOnlyDocumentPropertiesLoaded() طريقة

هذه الخاصية منطقية إذا كان ملف العرض محميًا بكلمة مرور وكانت خصائص المستند لهذا الملف عامة. قيمة true تعني أن خصائص المستند فقط يتم تحميلها من ملف عرض مشفر دون استخدام كلمة المرور. قيمة false تعني أن العرض المشفر بالكامل يتم تحميله باستخدام كلمة المرور الصحيحة، وليس فقط خصائص المستند. إذا لم يكن العرض مشفرًا فإن قيمة الخاصية تكون دائمًا false. إذا لم تكن خصائص المستند لملف مشفر عامة فإن قيمة الخاصية تكون دائمًا false. إذا كان PresentationEx.EncryptDocumentProperties يساوي true فإن قيمة الخاصية IsOnlyDocumentPropertiesLoaded تكون دائمًا false. قراءة فقط **bool**.

```cpp
virtual bool Aspose::Slides::IProtectionManager::get_IsOnlyDocumentPropertiesLoaded()=0
```
