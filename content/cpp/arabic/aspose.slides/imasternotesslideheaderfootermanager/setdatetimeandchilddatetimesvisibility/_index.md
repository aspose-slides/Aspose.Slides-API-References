## IMasterNotesSlideHeaderFooterManager::SetDateTimeAndChildDateTimesVisibility(bool) طريقة

يغيّر رؤية العنصر النائب للتاريخ والوقت في شريحة ملاحظات الماستر وجميع العناصر النائبة للتاريخ والوقت في الشرائح الفرعية. العناصر النائبة الفرعية تعني أن العناصر النائبة موجودة على الشرائح التابعة للملاحظات. الشرائح التابعة للملاحظات تستخدم وتعتمد على شريحة ملاحظات الماستر.

```cpp
virtual void Aspose::Slides::IMasterNotesSlideHeaderFooterManager::SetDateTimeAndChildDateTimesVisibility(bool isVisible)=0
```

### المعلمات

| Parameter | Type | Description |
| --- | --- | --- |
| isVisible | **bool** | true - يجعل العناصر النائبة للتاريخ والوقت مرئية، وإلا - يخفيها. |
