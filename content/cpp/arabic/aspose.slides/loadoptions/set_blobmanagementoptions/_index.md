## LoadOptions::set_BlobManagementOptions(System::SharedPtr\<IBlobManagementOptions\>) طريقة

يمثل الخيارات التي يمكن استخدامها لإدارة سلوك معالجة الكائنات الثنائية الكبيرة (BLOBs)، مثل استخدام الملفات المؤقتة أو الحد الأقصى للبايتات الخاصة بـ BLOBs في الذاكرة. تهدف هذه الخيارات إلى إعداد أفضل نسبة بين الأداء واستهلاك الذاكرة لبيئة أو متطلبات معينة.

```cpp
void Aspose::Slides::LoadOptions::set_BlobManagementOptions(System::SharedPtr<IBlobManagementOptions> value) override
```

## ملاحظات

الكائن الثنائي الكبير (BLOB) هو بيانات ثنائية مخزنة ككيان واحد - أي أن BLOB يمكن أن يكون صوتًا أو فيديو أو عرض تقديمي بحد ذاته.
