## LoadOptions::set_OnlyLoadDocumentProperties(bool) طريقة

هذه الخاصية تكون ذات معنى إذا كان ملف العرض محميًا بكلمة مرور. القيمة true تعني أن يتم تحميل خصائص المستند فقط من ملف عرض مشفر ويجب تجاهل كلمة المرور. القيمة false تعني أنه يجب تحميل العرض المشفر بالكامل باستخدام كلمة المرور الصحيحة. إذا لم يكن العرض مشفرًا فسيتم دائمًا تجاهل قيمة الخاصية. إذا لم تكن خصائص المستند لملف مشفر عامة وكانت قيمة الخاصية true فلن يتم تحميل خصائص المستند وسيتم إلقاء استثناء. اكتب **bool**.

```cpp
void Aspose::Slides::LoadOptions::set_OnlyLoadDocumentProperties(bool value) override
```
