## Details_CultureNotFoundException فئة

CultureNotFoundException يُرمى عندما يُحاول إنشاء ثقافة غير متوفرة. لا تنشئ مثيلات هذه الفئة يدويًا. استخدم فئة CultureNotFoundException بدلاً من ذلك. لا تقم بلف مثيلات فئة CultureNotFoundException داخل [System::SmartPtr](../../system/smartptr/).

```cpp
class Details_CultureNotFoundException : public System::Details_ArgumentException
```
