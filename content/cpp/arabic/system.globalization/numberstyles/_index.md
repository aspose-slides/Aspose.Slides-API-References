## NumberStyles enum

```cpp
enum class NumberStyles : int32_t
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| None | 0 | لا توجد رموز غير رقمية. |
| AllowLeadingWhite | 1 | السماح بالمسافات البيضاء في البداية. |
| AllowTrailingWhite | 2 | السماح بالمسافات البيضاء في النهاية. |
| AllowLeadingSign | 4 | السماح بالإشارة في البداية. |
| Integer | n/a | تنسيق عدد صحيح افتراضي. |
| AllowTrailingSign | 8 | السماح بالإشارة في النهاية. |
| AllowParentheses | 16 | السماح بالأقواس للقيم السالبة. |
| AllowDecimalPoint | 32 | السماح بالنقطة العشرية. |
| AllowThousands | 64 | السماح بفواصل المجموعات. |
| Number | n/a | تنسيق رقم مركب افتراضي. |
| AllowExponent | 128 | السماح بإشارة الأس. |
| Float | n/a | تنسيق عدد عشري افتراضي. |
| AllowCurrencySymbol | 256 | السماح برمز العملة. |
| Currency | n/a | تنسيق عملة افتراضي. |
| Any | n/a | السماح بأي محدد تنسيق. |
| AllowHexSpecifier | 512 | السماح بالأعداد السداسية عشرية. |
| HexNumber | n/a | تنسيق عدد سداسي عشري افتراضي. |
