## TimeSpanStyles تعداد

يحدد خيارات التنسيق التي تخصّص تحليل السلسلة للطرق التي تحول تمثيل سلسلة لفترة زمنية إلى كائن Timespan.

```cpp
enum class TimeSpanStyles : int32_t
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| None | 0 | الفترة الزمنية الممثلة بالسلسلة inptut تُفسَّر كفترة زمنية سلبية فقط إذا كان هناك إشارة سالبة. |
| AssumeNegative | 1 | الفترة الزمنية الممثلة بالسلسلة inptut تُفسَّر كفترة زمنية سلبية دائمًا. |
