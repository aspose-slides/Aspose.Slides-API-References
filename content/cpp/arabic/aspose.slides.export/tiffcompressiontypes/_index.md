## TiffCompressionTypes enum

```cpp
enum class TiffCompressionTypes
```

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| Default | 0 | يحدد مخطط الضغط الافتراضي (LZW). |
| None | 1 | يحدد عدم وجود ضغط. |
| CCITT3 | 2 | يحدد مخطط ضغط CCITT3. |
| CCITT4 | 3 | يحدد مخطط ضغط CCITT4. |
| LZW | 4 | يحدد مخطط ضغط LZW (الافتراضي). |
| RLE | 5 | يحدد مخطط ضغط RLE. |
