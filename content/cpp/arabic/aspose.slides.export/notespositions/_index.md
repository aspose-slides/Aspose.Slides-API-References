## عدد NotesPositions enum

يمثل القاعدة لعرض الملاحظات في المستند المُصدَّر

```cpp
enum class NotesPositions
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| None | 0 | يحدد أنه لا يجب عرض الملاحظات على الإطلاق. |
| BottomFull | 1 | يحدد أنه يجب عرض الملاحظات بالكامل باستخدام صفحات إضافية حسب الحاجة. |
| BottomTruncated | 2 | يحدد أنه يجب عرض الملاحظات في صفحة واحدة فقط. |
