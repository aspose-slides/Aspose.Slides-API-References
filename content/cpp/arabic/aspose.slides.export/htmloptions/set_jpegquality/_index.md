## HtmlOptions::set_JpegQuality(uint8_t) طريقة


## ملاحظات


يؤثر فقط عندما يحتوي المستند على صور JPEG.

استخدم هذه الخاصية للحصول على جودة الصور أو لتعيينها داخل المستند عند الحفظ بتنسيق PDF. يمكن أن تتراوح القيمة من 0 إلى 100 حيث يعني 0 أسوأ جودة ولكن أقصى ضغط و 100 يعني أفضل جودة ولكن أقل ضغط.

القيمة الافتراضية هي **95**.
