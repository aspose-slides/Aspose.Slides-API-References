## PdfOptions::set_JpegQuality(uint8_t) طريقة

يضبط قيمة تحدد جودة صور JPEG داخل مستند PDF. اكتب **uint8_t**.

```cpp
void Aspose::Slides::Export::PdfOptions::set_JpegQuality(uint8_t value) override
```

## ملاحظات

يؤثر فقط عندما يحتوي المستند على صور JPEG.

استخدم هذه الخاصية للحصول على جودة الصور أو تعيينها داخل المستند عند حفظه بصيغة PDF. يمكن أن تتراوح القيمة من 0 إلى 100 حيث تعني 0 أسوأ جودة مع أقصى ضغط و100 تعني أفضل جودة مع أقل ضغط.

القيمة الافتراضية هي **100**.
