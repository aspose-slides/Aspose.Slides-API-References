## IPdfOptions::get_JpegQuality() الطريقة

يُعيد قيمة تحدد جودة صور JPEG داخل مستند PDF. قراءة **uint8_t**.

```cpp
virtual uint8_t Aspose::Slides::Export::IPdfOptions::get_JpegQuality()=0
```

## ملاحظات

يؤثر فقط عندما يحتوي المستند على صور JPEG.

استخدم هذه الخاصية للحصول على جودة الصور داخل المستند أو لتعيينها عند الحفظ بصيغة PDF. قد تتراوح القيمة من 0 إلى 100 حيث يعني 0 أسوأ جودة ولكن أعلى ضغط و100 يعني أفضل جودة ولكن أقل ضغط.

القيمة الافتراضية هي **100**.
