## IPdfOptions::set_BestImagesCompressionRatio(bool) طريقة

يشير إلى ما إذا كان يجب اختيار أقوى ضغط (بدلاً من الضغط الافتراضي) لكل صورة تلقائيًا. إذا تم تعيينه إلى **bool**.true، فسيتم اختيار أنسب خوارزمية ضغط لكل صورة في العرض التقديمي، مما سيؤدي إلى حجم أصغر لمستند PDF الناتج.

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_BestImagesCompressionRatio(bool value)=0
```

## ملاحظات

اختيار أفضل نسبة ضغط للصور يتطلب حسابات مكثفة ويستهلك كمية إضافية من الذاكرة RAM، وهذا الخيار يكون **bool**.false افتراضيًا.

القيمة الافتراضية هي **bool**.false.
