## تعداد SvgEvent

يمثل خيارات شكل SVG.

```cpp
enum class SvgEvent
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| OnFocusIn | 0 | يحدث عندما يحصل عنصر على التركيز، مثل عندما يتم تحديد نص. |
| OnFocusOut | 1 | يحدث عندما يفقد عنصر التركيز، مثل عندما يتم إلغاء تحديد نص. |
| OnActivate | 2 | يحدث عندما يتم تنشيط عنصر، على سبيل المثال، عبر نقرة الفأرة أو ضغط مفتاح. |
| OnClick | 3 | يحدث عندما يتم النقر على زر جهاز الإشارة فوق عنصر. |
| OnMouseDown | 4 | يحدث عندما يتم ضغط زر جهاز الإشارة فوق عنصر. |
| OnMouseUp | 5 | يحدث عندما يتم تحرير زر جهاز الإشارة فوق عنصر. |
| OnMouseOver | 6 | يحدث عندما يتم تحريك جهاز الإشارة إلى عنصر. |
| OnMouseMove | 7 | يحدث عندما يتم تحريك جهاز الإشارة بينما هو فوق عنصر. |
| OnMouseOut | 8 | يحدث عندما يتحرك جهاز الإشارة بعيدًا عن عنصر. |
| OnLoad | 9 | يحدث عندما يقوم وكيل المستخدم بتحليل العنصر وسلالته وجميع الموارد المشار إليها بالكامل، المطلوبة لتصويره. |
| OnUnload | 10 | يحدث عندما يزيل تنفيذ [DOM](../../aspose.slides.dom/) مستندًا من نافذة أو إطار. ينطبق فقط على عناصر SVG الخارجية. |
| OnAbort | 11 | يحدث عندما يتم إيقاف تحميل الصفحة قبل أن يُسمح للعنصر بالتحميل بالكامل. |
| OnError | 12 | يحدث عندما لا يتم تحميل العنصر بشكل صحيح أو عندما يحدث خطأ أثناء تنفيذ البرنامج النصي. |
| OnResize | 13 | يحدث عندما يتم تغيير حجم عرض المستند. ينطبق فقط على عناصر SVG الخارجية. |
| OnScroll | 14 | يحدث عندما يتم إزاحة عرض المستند على طول المحور X أو Y أو كليهما. ينطبق فقط على عناصر SVG الخارجية. |
| OnZoom | 15 | يحدث عندما يتم تغيير مستوى التكبير لعرض المستند. ينطبق فقط على عناصر SVG الخارجية. |
| OnBegin | 16 | يحدث عندما يبدأ عنصر الرسوم المتحركة. |
| OnEnd | 17 | يحدث عندما ينتهي عنصر الرسوم المتحركة. |
| OnRepeat | 18 | يحدث عندما يكرر عنصر الرسوم المتحركة. |
