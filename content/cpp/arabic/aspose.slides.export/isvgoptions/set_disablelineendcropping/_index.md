## ISSVGOptions::set_DisableLineEndCropping(bool) طريقة

SVG 1.1 لا يملك القدرة على تحديد الهوامش للعلامات. [Aspose.Slides](../../../aspose.slides/) محرك كتابة SVG لديه حل لتلك المشكلة: يقوم بقص نهاية الخط بالسهم، لذا، لا يتقاطع الخط مع العلامات. هذا الخيار يُغلق هذا السلوك. اكتب **bool**.

virtual void Aspose::Slides::Export::ISVGOptions::set_DisableLineEndCropping(bool value)=0
