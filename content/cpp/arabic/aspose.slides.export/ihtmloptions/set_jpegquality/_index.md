## IHtmlOptions::set_JpegQuality(uint8_t) طريقة

يضبط قيمة تحدد جودة صور JPEG داخل مستند PDF. اكتب **uint8_t**.

```cpp
virtual void Aspose::Slides::Export::IHtmlOptions::set_JpegQuality(uint8_t value)=0
```

## ملاحظات

يظهر التأثير فقط عندما يحتوي المستند على صور JPEG.

استخدم هذه الخاصية للحصول على أو ضبط جودة الصور داخل المستند عند الحفظ بصيغة PDF. قد يتراوح القيمة من 0 إلى 100 حيث 0 يعني أسوأ جودة لكن أقصى ضغط و100 يعني أفضل جودة لكن أقل ضغط.

القيمة الافتراضية هي **95**.
