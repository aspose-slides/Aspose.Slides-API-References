## MarkdownSaveOptions::set_HandleRepeatedSpaces(Aspose::Slides::Export::HandleRepeatedSpaces) طريقة

يحدد كيفية التعامل مع أحرف المسافة العادية المتكررة أثناء تصدير Markdown.

```cpp
void Aspose::Slides::Export::MarkdownSaveOptions::set_HandleRepeatedSpaces(Aspose::Slides::Export::HandleRepeatedSpaces value)
```

## ملاحظات

هذه الخاصية تحدد ما إذا كانت المسافات المتتالية هي:* محفوظة كأحرف مسافة عادية،
* متناوبة بين المسافات العادية وكيانات المسافة غير القابلة للكسر (**&nbsp;**)،
* أو مستبدلة بالكامل (بعد الأولى) بـ **&nbsp;** للحفاظ على محاذاة بصرية في ناتج Markdown.

القيمة الافتراضية هي [HandleRepeatedSpaces::AlternateSpacesToNbsp](../../handlerepeatedspaces/).
