## TimeZone::IsDaylightSavingTime(DateTime) طريقة

يحدد ما إذا كانت قيمة التاريخ والوقت التي يمثلها كائن [DateTime](../../datetime/) المحدد تقع ضمن نطاق التوقيت الصيفي للمنطقة الزمنية التي يمثلها كائن [TimeZone](../) الحالي.

```cpp
virtual bool System::TimeZone::IsDaylightSavingTime(DateTime time)=0
```

### قيمة الإرجاع

True إذا كانت قيمة التاريخ والوقت التي يمثلها كائن [DateTime](../../datetime/) المحدد تقع ضمن نطاق التوقيت الصيفي للمنطقة الزمنية التي يمثلها كائن [TimeZone](../) الحالي، وإلا - false
