## طريقة Delegate< ReturnType(ArgumentTypes...)>::Empty() const

يحدد ما إذا كان كائن delegate الحالي فارغًا، على سبيل المثال لا يشير إلى أي كيان.

```cpp
bool System::Delegate<ReturnType(ArgumentTypes...)>::Empty() const
```

### قيمة الإرجاع

True إذا لم يكن كائن delegate الحالي يشير إلى دالة أو طريقة لكائن دالة، وإلا - false.
