## System::operator/(const T\&, const Decimal\&) دالة

تُرجِع نسخة جديدة من الفئة [Decimal](../decimal/) التي تمثِّل قيمة هي نتيجة قسمة القيمة المحدَّدة والقيمة التي يمثلها كائن [Decimal](../decimal/) المحدد.

```cpp
template<typename T,typename _> Decimal System::operator/(const T &x, const Decimal &d)
```

### المعاملات

| المعامل | النوع | الوصف |
| --- | --- | --- |
| x | const T\& | القيمة المراد قسْها |
| d | const [Decimal](../decimal/)\& | الكائن [Decimal](../decimal/) الذي يمثل المقسوم |

### قيمة الإرجاع

نسخة جديدة من الفئة [Decimal](../decimal/) التي تمثِّل قيمة هي نتيجة قسمة **x** على القيمة التي يمثلها **d**.
