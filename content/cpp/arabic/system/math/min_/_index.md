## Math::Min_(float, float) طريقة


Returns the smallest single-precision floating point value out of the two specified.

```cpp
float System::Math::Min_(float val1, float val2)
```


### المعاملات

| Parameter | Type | Description |
| --- | --- | --- |
| val1 | **float** | المقارنة الأولى |
| val2 | **float** | المقارنة الثانية |

### قيمة الإرجاع

أصغر قيمة من **val1** و **val2**؛ أو NaN إذا كان أحد العاملين NaN
