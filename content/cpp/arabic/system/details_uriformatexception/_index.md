## Details_UriFormatException فئة


UriFormatException يتم إلقاؤه عندما يكون تنسيق URI غير صالح. لا تقم بإنشاء مثيلات لهذه الفئة يدويًا. استخدم فئة UriFormatException بدلاً من ذلك. لا تقم أبدًا بلف مثيلات فئة UriFormatException داخل [System::SmartPtr](../smartptr/).

```cpp
class Details_UriFormatException : public System::Details_FormatException
```
