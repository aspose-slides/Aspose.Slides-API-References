## System::CheckedCast(TFrom) دالة

يحدد ما إذا كانت القيمة المحددة تقع ضمن نطاق قيم النوع **TTo** وإذا كان الأمر كذلك يقوم بتحويلها إلى النوع **TTo**.

```cpp
template<typename TTo,typename TFrom> TTo System::CheckedCast(TFrom value)
```

### معلمات القالب

| Parameter | Description |
| --- | --- |
| TTo | النوع الذي سيتم تحويل القيمة المحددة إليه |
| TFrom | النوع الخاص بالقيمة المحددة |

### المعطيات

| Parameter | Type | Description |
| --- | --- | --- |
| value | TFrom | القيمة المراد تحويلها |

### قيمة الإرجاع

القيمة من النوع **TTo** المكافئة لـ **value**
