## BadImageFormatException تعريف نوع

الاستثناء الذي يُرمى عندما تكون صورة ملف مكتبة الربط الديناميكي (DLL) أو برنامج تنفيذي غير صالحة. لا تقم بلف مثيلات BadImageFormatException الفئة في [System::SmartPtr](../smartptr/).

```cpp
using System::BadImageFormatException = typedef System::ExceptionWrapper<Details_BadImageFormatException>
```
