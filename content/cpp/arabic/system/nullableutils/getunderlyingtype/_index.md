## NullableUtils::GetUnderlyingType(const System::TypeInfo\&) طريقة

يرجع معامل النوع الأساسي للنوع القابل للإنكار المحدد.

```cpp
static const System::TypeInfo & System::NullableUtils::GetUnderlyingType(const System::TypeInfo &nullableType)
```

### المعلمات

| المعامل | النوع | الوصف |
| --- | --- | --- |
| nullableType | const [System::TypeInfo](../../typeinfo/)\& | كائن System.Type يصف نوعًا قابلًا للإنكار عام مغلق. |

### قيمة الإرجاع

معامل النوع للمعامل nullableType، إذا كان معامل nullableType نوعًا قابلًا للإنكار عام مغلق؛ وإلا فإن القيمة null
