## Array::begin() طريقة

تُرجِع مؤشرًا إلى العنصر الأول في الحاوية. إذا كانت الحاوية فارغة، سيكون المؤشر المرجع مساويًا لـ [end()](../end/).

```cpp
iterator System::Array<T>::begin() noexcept
```

### قيمة الإرجاع

مؤشر يشير إلى العنصر الأول في الحاوية.

## Array::begin() const طريقة

تُرجِع مؤشرًا إلى العنصر الأول في الحاوية المؤهَّلة بـ const. إذا كانت الحاوية فارغة، سيكون المؤشر المرجع مساويًا لـ [end()](../end/).

```cpp
const_iterator System::Array<T>::begin() const noexcept
```

### قيمة الإرجاع

مؤشر يشير إلى العنصر الأول في الحاوية المؤهَّلة بـ const.
