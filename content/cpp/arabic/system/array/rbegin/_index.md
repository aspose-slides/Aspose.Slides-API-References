## Array::rbegin() طريقة

يرجع مكرّرًا عكسيًا إلى العنصر الأول للحاوية المعكوسة. يتطابق مع العنصر الأخير للحاوية غير المعكوسة. إذا كانت الحاوية فارغة، يكون المكرّر المرتجع مساويًا لـ [rend()](../rend/).

```cpp
reverse_iterator System::Array<T>::rbegin() noexcept
```

### قيمة الإرجاع

مكرّر يشير إلى العنصر الأخير في الحاوية.

## Array::rbegin() const طريقة

يرجع مكرّرًا عكسيًا إلى العنصر الأول للحاوية المعكوسة. يتطابق مع العنصر الأخير للحاوية غير المعكوسة. إذا كانت الحاوية فارغة، يكون المكرّر المرتجع مساويًا لـ [rend()](../rend/).

```cpp
const_reverse_iterator System::Array<T>::rbegin() const noexcept
```

### قيمة الإرجاع

مكرّر يشير إلى العنصر الأخير في الحاوية ذات الصفة const.
