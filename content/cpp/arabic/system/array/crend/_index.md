## Array::crend() const طريقة

يعيد مؤشرًا عكسيًا إلى العنصر الذي يلي العنصر الأخير في الحاوية المعكوسة. وهو يطابق العنصر الذي يسبق أول عنصر في الحاوية غير المعكوسة. هذا العنصر يعمل كعنصر نائب، ومحاولة الوصول إليه تؤدي إلى سلوك غير معرف.

```cpp
const_reverse_iterator System::Array<T>::crend() const noexcept
```

### قيمة الإرجاع

مؤشر يشير إلى العنصر النظري المؤهل بـ const والذي يسبق أول عنصر في الحاوية.
