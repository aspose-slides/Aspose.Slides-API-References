## Environment::get_Version() طريقة

ترجع كائن [Version](../../version/) الذي يمثل المعلومات حول إصدار بيئة تشغيل اللغة المشتركة. الرقم الإصدار الذي يتم إرجاعه بواسطة هذه الطريقة هو مجرد قيمة تجريبية ولا يعني أن جميع فئات المكتبة تتصرف وفقًا للإصدار المُرجَع.

```cpp
static Version System::Environment::get_Version()
```
