## Boolean::TryParse(const String\&, bool\&) طريقة

يقوم بتحويل السلسلة المحددة إلى قيمة من نوع bool.

```cpp
static bool System::Boolean::TryParse(const String &value, bool &result)
```

### الوسائط

| المعامل | النوع | الوصف |
| --- | --- | --- |
| value | const [String](../../string/)\& | السلسلة المراد تحويلها. |
| result | **bool**\& | المرجع إلى متغير من نوع bool حيث يتم وضع نتيجة التحويل؛ النتيجة تكون true إذا كانت السلسلة المحددة مساوية لـ "True" و false إذا كانت السلسلة المحددة مساوية لـ "False". |

### قيمة الإرجاع

True إذا كانت السلسلة المحددة مساوية إما لـ "True" أو "False"، وإلا - false.
