## Boolean::Parse(const String\&) طريقة


يحوِّل السلسلة المحددة إلى قيمة من نوع bool.

```cpp
static bool System::Boolean::Parse(const String &value)
```


### المعاملات

| المعامل | النوع | الوصف |
| --- | --- | --- |
| value | const [String](../../string/)\& | السلسلة المراد تحويلها. |

### قيمة الإرجاع

متغيّر bool الذي يُوضع فيه نتيجة التحويل؛ النتيجة تكون true إذا كانت السلسلة المحددة مساوية لـ "True" وتكون false إذا كانت السلسلة المحددة مساوية لـ "False".
