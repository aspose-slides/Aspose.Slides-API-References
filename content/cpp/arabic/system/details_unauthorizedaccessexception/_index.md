## Details_UnauthorizedAccessException فئة


UnauthorizedAccessException يُرمى عندما يرفض نظام التشغيل الوصول بسبب خطأ إدخال/إخراج أو خطأ أمان. لا تقم بإنشاء مثيلات لهذه الفئة يدويًا. استخدم فئة UnauthorizedAccessException بدلاً من ذلك. لا تقم أبدًا بلف مثيلات فئة UnauthorizedAccessException داخل [System::SmartPtr](../smartptr/).

```cpp
class Details_UnauthorizedAccessException : public System::Details_SystemException
```
