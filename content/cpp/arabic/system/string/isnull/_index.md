## String::IsNull() const طريقة

يتحقق مما إذا كان string يعتبر null. [String](../) يكون null ولا يكون كذلك إلا إذا تم إنشاؤه عبر منشئ [String()](../string/)، أو تم نقله، أو نسخه، أو تعيينه من null string أو تم استدعاء طريقة [reset()](../reset/).

```cpp
bool System::String::IsNull() const
```

### قيمة الإرجاع

true إذا كان string يعتبر null، false غير ذلك.
