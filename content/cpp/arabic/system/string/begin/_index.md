## String::begin() const طريقة


يرجع مؤشراً إلى بداية مخزن السلسلة الفعلي. لا يعيد تخصيص أي شيء. لا يضمن أن يكون المخزن منتهيًا بـ null.

```cpp
const UChar * System::String::begin() const
```


### قيمة الإرجاع

مؤشر إلى مخزن السلسلة الفعلي، سواء كان منتهيًا بـ null أم لا.
