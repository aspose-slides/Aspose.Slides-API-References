## Decimal::Compare(const Decimal\&, const Decimal\&) طريقة

```cpp
static int System::Decimal::Compare(const Decimal &d1, const Decimal &d2)
```

### Arguments

| Parameter | Type | Description |
| --- | --- | --- |
| d1 | const [Decimal](../)\& | المعامل الأول |
| d2 | const [Decimal](../)\& | المعامل الثاني |

### Return Value

- 1 إذا كانت القيمة التي يمثلها **d1** أصغر من القيمة التي يمثلها **d2**؛ 0 إذا كانت القيم متساوية؛ 1 إذا كانت القيمة التي يمثلها **d1** أكبر من القيمة التي يمثلها **d2**
