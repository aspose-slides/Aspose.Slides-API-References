## Char::IsLetterOrDigit(const char_t *, int) طريقة

يحدد ما إذا كان الحرف في الفهرس المحدد داخل مخزن الحروف المحدد مصنفًا كحرف Unicode أو رقم عشري.

```cpp
static bool System::Char::IsLetterOrDigit(const char_t *str, int idx)
```

### المعاملات

| معامل | نوع | وصف |
| --- | --- | --- |
| str | const char_t * | مؤشر إلى بداية مخزن الحروف |
| idx | int | فهرس يبدأ من الصفر في المخزن المحدد للحرف الذي سيُختبر |

### قيمة الإرجاع

True إذا كان الحرف في الفهرس المحدد هو حرف Unicode أو رقم عشري، وإلا - false
