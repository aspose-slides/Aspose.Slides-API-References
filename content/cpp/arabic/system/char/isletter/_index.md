## Char::IsLetter(const char_t *, int) طريقة

يحدد ما إذا كان الحرف عند الفهرس المحدد في مخزن الأحرف المحدد يُصنف كحرف يونيكود.

```cpp
static bool System::Char::IsLetter(const char_t *str, int idx)
```

### المعاملات

| المعامل | النوع | الوصف |
| --- | --- | --- |
| str | const char_t * | مؤشر إلى بداية مخزن الأحرف |
| idx | int | فهرس يبدأ من الصفر في المخزن المحدد للحرف المراد اختباره |

### قيمة الإرجاع

True إذا كان الحرف في الفهرس المحدد حرفًا يونيكود، وإلا - false
