## Char::IsSurrogate(char_t) الطريقة

يحدد ما إذا كان الحرف المحدد وحدة شفرة UTF-16 بديلة.

```cpp
static bool System::Char::IsSurrogate(char_t c)
```

### الوسائط

| المعامل | النوع | الوصف |
| --- | --- | --- |
| c | char_t | حرف |

### قيمة الإرجاع

True إذا كان الحرف المحدد وحدة شفرة UTF-16 بديلة، وإلا - false
