## Char::IsSymbol(const char_t *, int) طريقة

يحدد ما إذا كان الحرف الموجود في الفهرس المحدد داخل مخزن الأحرف المحدد مصنَّفًا كحرف رمز.

```cpp
static bool System::Char::IsSymbol(const char_t *str, int idx)
```

### المعلمات

| المعامل | النوع | الوصف |
| --- | --- | --- |
| str | const char_t * | مؤشر إلى بداية مخزن الأحرف |
| idx | int | فهرس يبدأ من الصفر داخل المخزن لتحديد الحرف المراد اختباره |

### قيمة الإرجاع

True إذا كان الحرف في الفهرس المحدد هو حرف رمز، وإلا - false
