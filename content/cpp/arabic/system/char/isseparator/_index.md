## Char::IsSeparator(const char_t *, int) method

يحدد ما إذا كان الحرف الموجود في الفهرس المحدد داخل مخزن الحروف المحدد يُصنَّف كحرف فاصل.

```cpp
static bool System::Char::IsSeparator(const char_t *str, int idx)
```

### الوسائط

| المعامل | النوع | الوصف |
| --- | --- | --- |
| str | const char_t * | مؤشر إلى بداية مخزن الحروف |
| idx | int | فهرس يبدأ من الصفر في المخزن المحدد للحرف المراد اختباره |

### قيمة الإرجاع

صحيح إذا كان الحرف عند الفهرس المحدد هو حرف فاصل، وإلا - خطأ
