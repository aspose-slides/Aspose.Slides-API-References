## Char::IsDigit(const char_t *, int) طريقة

يحدد ما إذا كان الحرف في الفهرس المحدد داخل مخزن الأحرف المحدد يُصنَّف كرقم عشري.

```cpp
static bool System::Char::IsDigit(const char_t *str, int idx)
```

### المعاملات

| المعامل | النوع | الوصف |
| --- | --- | --- |
| str | const char_t * | مؤشر إلى بداية مخزن الأحرف |
| idx | int | فهرس يبدأ من الصفر في المخزن المحدد للرمز لاختباره |

### قيمة الإرجاع

True إذا كان الحرف في الفهرس المحدد رقمًا عشريًا، وإلا - false
