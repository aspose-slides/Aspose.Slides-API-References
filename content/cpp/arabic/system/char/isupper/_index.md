## Char::IsUpper(const String\&, int) طريقة

يحدد ما إذا كان الحرف الموجود في الفهرس المحدد في السلسلة المحددة مصنّفًا كحرف كبير.

```cpp
static bool System::Char::IsUpper(const String &str, int idx)
```

### المعاملات

| المعامل | النوع | الوصف |
| --- | --- | --- |
| str | const [String](../../string/)\& | السلسلة التي تحتوي على حرف. |
| idx | int | فهرس بصفر أساس في السلسلة المحددة للاختبار |

### قيمة الإرجاع

True إذا كان الحرف الموجود في الفهرس المحدد حرفًا كبيرًا، وإلا - false
