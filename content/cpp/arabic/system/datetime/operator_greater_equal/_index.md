```cpp
constexpr bool System::DateTime::operator>=(DateTime other) const
```

### الوسائط

| المعامل | النوع | الوصف |
| --- | --- | --- |
| other | [DateTime](../) | الكائن [DateTime](../) للمقارنة مع الكائن الحالي |

### قيمة الإرجاع

True إذا كانت قيمة التاريخ والوقت التي يمثلها الكائن الحالي لاحقة أو مساوية للقيمة التي يمثلها **other**، وإلا - false
