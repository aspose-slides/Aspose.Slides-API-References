## DateTime::IsDaylightSavingTime() const طريقة

يحدد ما إذا كان قيمة التاريخ والوقت التي يمثلها الكائن الحالي تقع ضمن نطاق التوقيت الصيفي للمنطقة الزمنية الحالية.

```cpp
bool System::DateTime::IsDaylightSavingTime() const
```

### قيمة الإرجاع

True إذا كانت قيمة التاريخ والوقت المحددة بواسطة الكائن الحالي تقع ضمن نطاق التوقيت الصيفي، وإلا - false
