## فئة ValueType

الصف الأساسي لأنواع القيم مع وراثة [Object](../object/) يتم تقصيرها لأسباب تتعلق بالأداء. يجب تخصيص هذا النوع على المكدس وتمريره إلى الدوال بالقيمة أو بالمرجع. لا تستخدم [System::SmartPtr](../smartptr/) فئة لإدارة كائنات هذا النوع.

```cpp
class ValueType
```
