## AuthenticationSchemes enum

Enumerates the authentication schemes.

```cpp
enum class AuthenticationSchemes
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| None | 0 | لا يلزم أي مصادقة. |
| Digest | 1 | مصادقة وصول موجزة. |
| Negotiate | 2 | يتفاوض مع العميل أي مخطط مصادقة سيستخدم (NTML أو Kerberos). |
| Ntlm | 4 | مصادقة NTLM. |
| Basic | 8 | مصادقة أساسية. |
| Anonymous | 32768 | مصادقة مجهولة. |
| IntegratedWindowsAuthentication | n/a | [Windows](../../system.windows/) المصادقة. |
