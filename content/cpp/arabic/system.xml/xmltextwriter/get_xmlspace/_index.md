### قيمة الإرجاع

XmlSpace يمثل نطاق **xml:space** الحالي.

| القيمة | المعنى |
| --- | --- |
| None | هذا هو الإعداد الافتراضي إذا لم يكن هناك نطاق `xml:space` موجود. |
| Default | النطاق الحالي هو `xml:space="default"`. |
| Preserve | النطاق الحالي هو `xml:space="preserve"`. |
