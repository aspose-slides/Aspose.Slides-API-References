## WhitespaceHandling enum

Specifies how white space is handled.

```cpp
enum class WhitespaceHandling
```

### القيم

| Name | Value | Description |
| --- | --- | --- |
| All | 0 | إرجاع عقد **Whitespace** و **SignificantWhitespace**. هذا هو الافتراضي. |
| Significant | 1 | إرجاع عقد **SignificantWhitespace** فقط. |
| None | 2 | لا تُرجع أي عقد **Whitespace** ولا أي عقد **SignificantWhitespace**. |
