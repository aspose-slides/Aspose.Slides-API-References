## XmlElement::set_IsEmpty(bool) طريقة


يضبط تنسيق العلامة للعنصر.

```cpp
void System::Xml::XmlElement::set_IsEmpty(bool value)
```


### الوسائط

| Parameter | Type | Description |
| --- | --- | --- |
| value | **bool** | القيمة لتعيينها. عند تعيين هذه القيمة، إذا تم تعيينها إلى **true**، يتم إزالة أبناء العنصر ويتم تسلسل العنصر بصيغة العلامة القصيرة. إذا تم تعيينها إلى **false**، يتم تغيير القيمة (بغض النظر عما إذا كان العنصر يحتوي على محتوى أم لا)؛ إذا كان العنصر فارغًا، يتم تسلسله بالصيغ الطويلة. |
