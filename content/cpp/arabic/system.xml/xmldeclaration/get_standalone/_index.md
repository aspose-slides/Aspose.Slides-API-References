## XmlDeclaration::get_Standalone() طريقة

إرجاع قيمة السمة standalone.

```cpp
String System::Xml::XmlDeclaration::get_Standalone()
```

### قيمة الإرجاع

القيم الصالحة هي **yes** إذا كانت جميع إعلانات الكيانات المطلوبة بواسطة مستند XML موجودة داخل المستند أو **no** إذا كان تعريف نوع المستند الخارجي (DTD) مطلوبًا. إذا لم تكن سمة standalone موجودة في إعلان XML، فإن هذه الطريقة تُرجع [String::Empty](../../../system/string/empty/).
