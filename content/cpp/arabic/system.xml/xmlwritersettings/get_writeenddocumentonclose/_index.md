## XmlWriterSettings::get_WriteEndDocumentOnClose() طريقة

```cpp
bool System::Xml::XmlWriterSettings::get_WriteEndDocumentOnClose()
```


### قيمة الإرجاع

**true** إذا تم إغلاق جميع وسوم العناصر غير المغلقة؛ وإلا، **false**. القيمة الافتراضية هي **true**.
