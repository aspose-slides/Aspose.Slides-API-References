## XmlWriterSettings::get_IndentChars() طريقة

يُرجع سلسلة الحروف المستخدمة للمسافة البادئة. يُستخدم هذا الإعداد عندما تكون قيمة [XmlWriterSettings::set_Indent](../set_indent/) مضبوطة على **true**.

```cpp
String System::Xml::XmlWriterSettings::get_IndentChars()
```

### قيمة الإرجاع

سلسلة الحروف المستخدمة للمسافة البادئة. يمكن تعيينها إلى أي قيمة نصية. ومع ذلك، لضمان XML صالح، يجب عليك تحديد فقط أحرف المسافات البيضاء الصالحة، مثل أحرف المسافة، والتابات، وإرجاعات العربة، أو تغذيات السطر. القيمة الافتراضية هي مسافتان.
