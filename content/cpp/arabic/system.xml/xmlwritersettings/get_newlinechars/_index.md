## XmlWriterSettings::get_NewLineChars() طريقة

يرجع سلسلة الأحرف المستخدمة في فصل الأسطر.

```cpp
String System::Xml::XmlWriterSettings::get_NewLineChars()
```

### قيمة الإرجاع

سلسلة الأحرف المستخدمة في فصل الأسطر. يمكن تعيينها إلى أي قيمة نصية. ومع ذلك، لضمان XML صالح، يجب عليك تحديد أحرف بيضاء صالحة فقط، مثل مسافات، تبويبات، إرجاع العربة، أو تغذيات السطر. القيمة الافتراضية هي **\r\n** (إرجاع العربة، سطر جديد).
