## XmlNodeOrder enum

يصف ترتيب المستند لعقدة مقارنة بالعقدة الثانية.

```cpp
enum class XmlNodeOrder
```

### Values

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| Before | 0 | العقدة الحالية لهذا navigator تقع قبل العقدة الحالية لل navigator الموفَّر. |
| After | 1 | العقدة الحالية لهذا navigator تقع بعد العقدة الحالية لل navigator الموفَّر. |
| Same | 2 | المستكشفان navigator موضعهما على نفس العقدة. |
| Unknown | 3 | لا يمكن تحديد مواضع العقدة في ترتيب المستند، بالنسبة لبعضها البعض. قد يحدث ذلك إذا كانت العقدتان موجودتين في أشجار مختلفة. |
