## XmlTextReader::get_IsEmptyElement() طريقة

تُعيد قيمة تشير إلى ما إذا كان العقد الحالي عنصرًا فارغًا (على سبيل المثال، **<MyElement/>**).

```cpp
bool System::Xml::XmlTextReader::get_IsEmptyElement() override
```

### قيمة الإرجاع

**true** إذا كان العقد الحالي عنصرًا ([XmlTextReader::get_NodeType](../get_nodetype/) القيمة تساوي [XmlNodeType::Element](../../xmlnodetype/)) ينتهي بـ **/>**؛ وإلا **false**.
