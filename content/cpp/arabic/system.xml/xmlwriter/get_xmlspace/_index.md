## XmlWriter::get_XmlSpace() طريقة


عند إعادة تعريفها في فئة مشتقة، تحصل على XmlSpace تمثل نطاق **xml:space** الحالي.

```cpp
virtual System::Xml::XmlSpace System::Xml::XmlWriter::get_XmlSpace()
```


### قيمة الإرجاع

XmlSpace تمثل نطاق **xml:space** الحالي.



| القيمة | المعنى |
| --- | --- |
| `None`| هذا هو الافتراضي إذا لم يكن هناك نطاق `xml:space` موجود. |
| `Default`| النطاق الحالي هو `xml:space="default"`. |
| `Preserve`| النطاق الحالي هو `xml:space="preserve"`. |
