## XmlReader::get_NamespaceURI() طريقة

عند تجاوزه في فئة مشتقة، يحصل على URI مساحة الاسم (كما هو معرف في مواصفات مساحة الاسم الخاصة بـ W3C) للعقدة التي يتم وضع القارئ عليها.

```cpp
virtual String System::Xml::XmlReader::get_NamespaceURI()=0
```

### قيمة الإرجاع

URI مساحة الاسم للعقدة الحالية؛ وإلا تكون سلسلة فارغة.
