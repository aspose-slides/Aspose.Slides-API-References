## XmlReader::get_HasValue() طريقة

When overridden in a derived class, gets a value indicating whether the current node can have a [XmlReader::get_Value](../get_value/) value.

```cpp
virtual bool System::Xml::XmlReader::get_HasValue()
```

### قيمة الإرجاع

**true** إذا كان العقدة التي يقع عليها القارئ حاليًا يمكن أن تحتوي على **Value**؛ وإلا، **false**. إذا كان **false**، فإن العقدة لها قيمة [String::Empty](../../../system/string/empty/).
