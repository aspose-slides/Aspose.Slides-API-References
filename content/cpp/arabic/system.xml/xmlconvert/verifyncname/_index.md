## XmlConvert::VerifyNCName(const String\&) طريقة

يتحقق من أن الاسم هو **NCName** صالح وفقًا لتوصية W3C للغة الترميز الموسعة. الـ **NCName** هو اسم لا يمكن أن يحتوي على نقطتين.

```cpp
static String System::Xml::XmlConvert::VerifyNCName(const String &name)
```

### الوسائط

| Parameter | Type | Description |
| --- | --- | --- |
| name | const [String](../../../system/string/)\& | الاسم للتحقق منه. |

### قيمة الإرجاع

الاسم إذا كان NCName صالحًا.
