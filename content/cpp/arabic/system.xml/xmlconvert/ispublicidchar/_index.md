## XmlConvert::IsPublicIdChar(char16_t) طريقة

Returns the passed-in character instance if the character in the argument is a valid public id character, otherwise **nullptr**.

```cpp
static bool System::Xml::XmlConvert::IsPublicIdChar(char16_t ch)
```

### الوسائط

| المعامل | النوع | الوصف |
| --- | --- | --- |
| ch | char16_t | كائن [Char](../../../system/char/) للتحقق منه. |

### قيمة الإرجاع

الحرف الممرَّر إذا كان الحرف هو حرف معرف عام صالح، وإلا **nullptr**.
