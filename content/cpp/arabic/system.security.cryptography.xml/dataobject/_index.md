## فئة DataObject

يعرف آلية غير مرتبطة بالتنسيق لنقل البيانات. يجب إنشاء كائنات هذه الفئة باستخدام الدالة [System::MakeObject()](../../system/makeobject/) فقط. لا تقم بإنشاء مثيل من هذا النوع على المكدس أو باستخدام operator new، لأن ذلك سيؤدي إلى أخطاء زمن التنفيذ و/أو أخطاء التأكيد. احرص دائمًا على تغليف هذه الفئة بمؤشر [System::SmartPtr](../../system/smartptr/) واستخدام هذا المؤشر لتمريرها إلى الدوال كمعامل.

```cpp
class DataObject : public System::Object
```
