## TransformChain فئة

يمثل سلسلة مرتبة من التحويلات. يجب تخصيص كائنات هذه الفئة باستخدام دالة [System::MakeObject()](../../system/makeobject/) فقط. لا تقم أبدًا بإنشاء مثال من هذا النوع على المكدس أو باستخدام المشغّل new، إذ سيتسبب ذلك في أخطاء وقت التشغيل أو أعطال التأكيد. دائمًا قم بلف هذه الفئة داخل مؤشر [System::SmartPtr](../../system/smartptr/) واستخدم هذا المؤشر لتمريره إلى الدوال كمعامل.

```cpp
class TransformChain : public System::Object
```
