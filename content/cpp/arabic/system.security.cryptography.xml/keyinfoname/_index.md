## فئة KeyInfoName

يمثل العنصر الفرعي 'KeyName' في XMLDSIG أو عنصر التشفير XML '[KeyInfo](../keyinfo/)'. يجب تخصيص كائنات هذه الفئة فقط باستخدام الدالة [System::MakeObject()](../../system/makeobject/). لا تقم بإنشاء مثيل من هذا النوع على المكدس أو باستخدام العامل new، حيث سيتسبب ذلك في أخطاء وقت التشغيل و/أو أخطاء تأكيد. دائمًا غلف هذه الفئة في مؤشر [System::SmartPtr](../../system/smartptr/) واستخدم هذا المؤشر لتمريره إلى الدوال كمعامل.

```cpp
class KeyInfoName : public System::Security::Cryptography::Xml::KeyInfoClause
```
