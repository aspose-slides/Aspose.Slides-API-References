## XmlDsigEnvelopedSignatureTransform الفئة

يمثل تحويل التوقيع المغلف لتوقيع XML. يجب تخصيص كائنات هذه الفئة فقط باستخدام الدالة [System::MakeObject()](../../system/makeobject/). لا تقم أبدًا بإنشاء نسخة من هذا النوع على المكدس أو باستخدام العامل new، لأنه سيؤدي إلى أخطاء في وقت التشغيل أو أخطاء تأكيد. احwrap هذه الفئة دائمًا في مؤشر [System::SmartPtr](../../system/smartptr/) واستخدم هذا المؤشر لتمريره إلى الدوال كوسيطة.

```cpp
class XmlDsigEnvelopedSignatureTransform : public System::Security::Cryptography::Xml::Transform
```
