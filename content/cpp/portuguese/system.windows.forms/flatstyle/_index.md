## FlatStyle enum

Define se o controle é desenhado plano ou tridimensional.

```cpp
enum class FlatStyle
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Flat | 0 | [Control](../control/) é desenhado plano. |
| Popup | 1 | [Control](../control/) é desenhado plano a menos que o mouse passe sobre ele quando está desenhado em 3D. |
| Standard | 2 | [Control](../control/) é desenhado em 3D. |
| System | 3 | O estilo é controlado pelo SO. |
