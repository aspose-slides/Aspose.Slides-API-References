## Details_HttpException::Is(const System::TypeInfo\&) const method




```cpp
bool System::Web::Details_HttpException::Is(const System::TypeInfo &target) const override
```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| target | const [System::TypeInfo](../../../system/typeinfo/)\& | estrutura [TypeInfo](../../../system/typeinfo/) que descreve o tipo contra o qual testar o objeto atual. |

### Valor de Retorno

True se o objeto for do tipo marcado ou de sua subclasse, false caso contrário.
## Observações

Verifica se o objeto representa uma instância do tipo descrito por targetType. Análogo ao operador 'is' de C#.
