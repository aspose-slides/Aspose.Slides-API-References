## HttpResponse classe

Classe dummy que permite vincular código traduzido com referências [HttpResponse](./), mas não executá-lo. Contém nenhum membro implementado corretamente. Objetos desta classe devem ser alocados apenas usando a função [System::MakeObject()](../../system/makeobject/). Nunca crie instância deste tipo na pilha ou usando o operador new, pois isso resultará em erros de tempo de execução e/ou falhas de asserção. Sempre envolva esta classe em um ponteiro [System::SmartPtr](../../system/smartptr/) e use esse ponteiro ao passá-lo para funções como argumento.

```cpp
class HttpResponse : public System::Object
```
