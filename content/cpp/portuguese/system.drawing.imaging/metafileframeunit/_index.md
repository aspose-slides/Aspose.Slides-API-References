## MetafileFrameUnit enum

Especifica a unidade de medida para o retângulo usado para dimensionar e posicionar um metafile.

```cpp
enum class MetafileFrameUnit
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Pixel | n/a | Especifica um pixel como unidade de medida. |
| Point | n/a | Especifica um ponto de impressora como unidade de medida. |
| Inch | n/a | Especifica uma polegada como unidade de medida. |
| Document | n/a | Especifica 1/300 de uma polegada como unidade de medida. |
| Millimeter | n/a | Especifica um milímetro como unidade de medida. |
| GdiCompatible | n/a | Especifica .01 milímetro como unidade de medida. Fornecido para compatibilidade com GDI. |
