## ImageLockMode enum

Especifica as propriedades da região de uma imagem que está sendo bloqueada.

```cpp
enum class ImageLockMode
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| ReadOnly | 1 | A região está bloqueada apenas para leitura. |
| WriteOnly | 2 | A região está bloqueada apenas para gravação. |
| ReadWrite | n/a | A região está bloqueada tanto para leitura quanto para gravação. |
| UserInputBuffer | 4 | A imagem está em um buffer de entrada do usuário, cujo acesso é controlado pelo usuário. |
