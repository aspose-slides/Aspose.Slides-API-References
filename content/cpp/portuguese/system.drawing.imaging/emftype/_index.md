## EmfType enum

Especifica os tipos de registros que são colocados em um arquivo EMF.

```cpp
enum class EmfType
```

### Valores

| Name | Value | Description |
| --- | --- | --- |
| EmfOnly | n/a | [Windows](../../system.windows/) metarquivo avançado. Contém comandos GDI. Metafiles desse tipo são referidos como um arquivo EMF. |
| EmfPlusOnly | n/a | [Windows](../../system.windows/) metarquivo avançado plus. Contém comandos GDI+. Metafiles desse tipo são referidos como um arquivo EMF+. |
| EmfPlusDual | n/a | Dual [Windows](../../system.windows/) metarquivo avançado. Contém comandos equivalentes GDI e GDI+. Metafiles desse tipo são referidos como um arquivo EMF+. |
