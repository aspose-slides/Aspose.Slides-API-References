## MetafileType enum

Representa um tipo de metafile gráfico.

```cpp
enum class MetafileType
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Invalid | 0 | Metarquivo inválido. |
| Wmf | 1 | WMF padrão. |
| WmfPlaceable | 2 | Formato [Metafile](../metafile/) posicionável. |
| Emf | 3 | EMF (não EMF+). |
| EmfPlusOnly | 4 | EMF+ sem registros duais, de nível inferior. |
| EmfPlusDual | 5 | EMF+ com registros duais, de nível inferior. |
