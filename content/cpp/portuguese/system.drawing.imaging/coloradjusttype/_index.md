## ColorAdjustType enum

Especifica quais objetos usam informações de ajuste de cor.

```cpp
enum class ColorAdjustType
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Default | 0 | Define informações de ajuste de cor usadas por todos os objetos que não possuem suas próprias informações de ajuste de cor. |
| Bitmap | 1 | Define informações de ajuste de cor para objetos [Bitmap](../../system.drawing/bitmap/). |
| Brush | 2 | Define informações de ajuste de cor para objetos [Brush](../../system.drawing/brush/). |
| Pen | 3 | Define informações de ajuste de cor para objetos [Pen](../../system.drawing/pen/). |
| Text | 4 | Define informações de ajuste de cor para texto. |
| Count | 5 | Especifica o número de tipos especificados. |
| Any | 6 | Especifica o número de tipos especificados. |
