## ColorMatrixFlag enum

Especifica os tipos de imagens e cores que serão afetados pelas configurações de ajuste de cor e escala de cinza de um objeto [ImageAttributes](../imageattributes/).

```cpp
enum class ColorMatrixFlag
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Default | 0 | Tanto as cores quanto os valores de escala de cinza são ajustados de cor. |
| SkipGrays | 1 | Os valores de escala de cinza não são ajustados de cor. |
| AltGrays | 2 | Somente os valores de escala de cinza são ajustados de cor. |
