## XmlKnownDtds enum

A enumeração [Resolvers::XmlKnownDtds](./) é usada por [Resolvers::XmlPreloadedResolver](../xmlpreloadedresolver/) e define quais DTDs bem conhecidos o [Resolvers::XmlPreloadedResolver](../xmlpreloadedresolver/) reconhece.

```cpp
enum class XmlKnownDtds
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| None | 0 | Especifica que o [Resolvers::XmlPreloadedResolver](../xmlpreloadedresolver/) não reconhecerá nenhum dos DTDs predefinidos. |
| Xhtml10 | 1 | Especifica que o [Resolvers::XmlPreloadedResolver](../xmlpreloadedresolver/) reconhecerá DTDs e entidades que são definidas em XHTML 1.0. |
| Rss091 | 2 | Especifica que o [Resolvers::XmlPreloadedResolver](../xmlpreloadedresolver/) reconhecerá DTDs e entidades que são definidas em RSS 0.91. |
| All | 65535 | Especifica que o [Resolvers::XmlPreloadedResolver](../xmlpreloadedresolver/) reconhecerá todos os DTDs atualmente suportados. Este é o comportamento padrão. |
