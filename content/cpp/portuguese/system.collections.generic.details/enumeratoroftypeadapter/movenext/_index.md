## EnumeratorOfTypeAdapter::MoveNext() método

Move o enumerador para o próximo elemento. Se nenhum elemento foi referenciado anteriormente, define a referência para o primeiro elemento disponível. Se o fim do contêiner for atingido, não faz nada.

```cpp
bool System::Collections::Generic::Details::EnumeratorOfTypeAdapter<Source, Result>::MoveNext() override
```

### Valor de Retorno

Verdadeiro se algum elemento estiver disponível após a chamada, falso caso contrário.
