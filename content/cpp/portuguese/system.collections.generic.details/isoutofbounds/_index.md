## System::Collections::Generic::Details::IsOutOfBounds(int, const Container\&) função

Verifica se o índice está fora dos limites do contêiner, excluindo o tamanho do contêiner.

```cpp
template<typename Container> bool System::Collections::Generic::Details::IsOutOfBounds(int idx, const Container &container)
```

### Parâmetros de modelo

| Parameter | Description |
| --- | --- |
| Container | Tipo do contêiner. |

### Argumentos

| Parameter | Type | Description |
| --- | --- | --- |
| idx | int | [Index](../../system/index/). |
| container | const Container\& | Contêiner contra o qual verificar o índice. |

### Valor de retorno

True if index is out of container bounds, false otherwise.
