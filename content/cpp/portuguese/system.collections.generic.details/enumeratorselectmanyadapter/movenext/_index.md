## EnumeratorSelectManyAdapter::MoveNext() método

Moves enumerator to the next element. If no element was referenced before, sets reference to the first element available. If container end was hit, does nothing.

```cpp
bool System::Collections::Generic::Details::EnumeratorSelectManyAdapter<Source, Result>::MoveNext() override
```

### Valor de retorno

True se algum elemento estiver disponível após a chamada, false caso contrário.
