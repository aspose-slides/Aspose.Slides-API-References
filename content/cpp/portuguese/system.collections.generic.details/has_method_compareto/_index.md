## has_method_compareto struct


Verifica se o método CompareTo existe no tipo especificado. Se sim, herda std::true_type; caso contrário, herda std::false_type. Pode ser usado em std::enable_if.

```cpp
template<typename T,typename Sfinae>class has_method_compareto : public std::false_type
```


### Parâmetros de modelo

| Parâmetro | Descrição |
| --- | --- |
| T | Tipo para verificar a existência do método Equals. |
| Sfinae | Argumento de modelo formal para que SFINAE funcione. |
