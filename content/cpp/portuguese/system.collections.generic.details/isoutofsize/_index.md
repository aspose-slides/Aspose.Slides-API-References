## System::Collections::Generic::Details::IsOutOfSize(int, const Container\&) função

Verifica se o índice está fora dos limites do contêiner, incluindo o tamanho do contêiner.

```cpp
template<typename Container> bool System::Collections::Generic::Details::IsOutOfSize(int count, const Container &container)
```

### Parâmetros de modelo

| Parâmetro | Descrição |
| --- | --- |
| Container | Tipo de contêiner. |

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| count | int | [Index](../../system/index/). |
| container | const Container\& | Contêiner contra o qual verificar o índice. |

### Valor de retorno

Verdadeiro se o índice estiver fora dos limites do contêiner, falso caso contrário.
