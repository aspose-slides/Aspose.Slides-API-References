## EnumeratorCastAdapter::MoveNext() método

Move o enumerador para o próximo elemento. Se nenhum elemento foi referenciado antes, define a referência para o primeiro elemento disponível. Se o final do contêiner for atingido, não faz nada.

```cpp
bool System::Collections::Generic::Details::EnumeratorCastAdapter<Source, Result>::MoveNext() override
```

### Valor de Retorno

True se algum elemento estiver disponível após a chamada, false caso contrário.
