## XPathNamespaceScope enum

Define o escopo de namespace.

```cpp
enum class XPathNamespaceScope
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| All | 0 | Retorna todos os namespaces definidos no escopo do nó atual. Isso inclui o namespace **xmlns:xml** que é sempre declarado implicitamente. A ordem dos namespaces retornados não está definida. |
| ExcludeXml | 1 | Retorna todos os namespaces definidos no escopo do nó atual, excluindo o namespace **xmlns:xml**. O namespace **xmlns:xml** é sempre declarado implicitamente. A ordem dos namespaces retornados não está definida. |
| Local | 2 | Retorna todos os namespaces que são definidos localmente no nó atual. |
