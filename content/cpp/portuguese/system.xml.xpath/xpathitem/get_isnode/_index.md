## XPathItem::get_IsNode() método

Quando sobrescrito em uma classe derivada, obtém um valor que indica se o item representa um [XPath](../../) nó ou um valor atômico.

```cpp
virtual bool System::Xml::XPath::XPathItem::get_IsNode()=0
```

### Valor de Retorno

**true** se o item representa um [XPath](../../) nó; **false** se o item representa um valor atômico.
