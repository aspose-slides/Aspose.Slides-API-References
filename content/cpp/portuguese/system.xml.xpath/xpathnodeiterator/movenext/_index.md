## XPathNodeIterator::MoveNext() method


Quando sobrescrito em uma classe derivada, move o objeto [XPathNavigator](../../xpathnavigator/) retornado pelo método [XPathNodeIterator::get_Current](../get_current/) para o próximo nó no conjunto de nós selecionados.

```cpp
virtual bool System::Xml::XPath::XPathNodeIterator::MoveNext()=0
```


### Valor de Retorno

**true** se o objeto [XPathNavigator](../../xpathnavigator/) foi movido para o próximo nó; **false** se não houver mais nós selecionados.
