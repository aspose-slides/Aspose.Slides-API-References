## XPathNavigator::MoveToNextAttribute() método

Quando substituído em uma classe derivada, move o [XPathNavigator](../) para o próximo atributo.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToNextAttribute()=0
```

### Valor de Retorno

**true** se o [XPathNavigator](../) for bem-sucedido ao mover para o próximo atributo; **false** se não houver mais atributos. Se **false**, a posição do [XPathNavigator](../) permanece inalterada.
