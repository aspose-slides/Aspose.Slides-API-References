## XPathNavigator::MoveToId(String) método


When overridden in a derived class, moves to the node that has an attribute of type **ID** whose value matches the specified [String](../../../system/string/).

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToId(String id)=0
```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| id | [String](../../../system/string/) | A [String](../../../system/string/) representing the **ID** value of the node to which you want to move. |

### Valor de Retorno

**true** se o [XPathNavigator](../) for bem-sucedido ao mover; caso contrário, **false**. Se **false**, a posição do navegador permanece inalterada.
