## XPathNavigator::MoveToPrevious() método

Quando sobrescrito em uma classe derivada, move o [XPathNavigator](../) para o nó irmão anterior ao nó atual.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToPrevious()=0
```

### Valor de Retorno

**true** se o [XPathNavigator](../) for bem-sucedido ao mover para o nó irmão anterior; caso contrário, **false** se não houver nó irmão anterior ou se o [XPathNavigator](../) estiver atualmente posicionado em um nó de atributo. Se **false**, a posição do [XPathNavigator](../) permanecerá inalterada.
