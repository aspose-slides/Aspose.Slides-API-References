## XPathNavigator::get_LocalName() método

Quando sobrescrito em uma classe derivada, obtém o [XPathNavigator::get_Name](../get_name/) do nó atual sem nenhum prefixo de namespace.

```cpp
virtual String System::Xml::XPath::XPathNavigator::get_LocalName()=0
```

### Valor de Retorno

Um [String](../../../system/string/) que contém o nome local do nó atual, ou [String::Empty](../../../system/string/empty/) se o nó atual não tiver um nome (por exemplo, nós de texto ou de comentário).
