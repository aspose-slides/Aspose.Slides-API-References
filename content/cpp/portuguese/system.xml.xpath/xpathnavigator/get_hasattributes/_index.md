## XPathNavigator::get_HasAttributes() método

Retorna um valor que indica se o nó atual tem algum atributo.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::get_HasAttributes()
```

### Valor de Retorno

**true** se o nó atual tem atributos; retorna **false** se o nó atual não tem atributos, ou se o [XPathNavigator](../) não está posicionado em um nó de elemento.
