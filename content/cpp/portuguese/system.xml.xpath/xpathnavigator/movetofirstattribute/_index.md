## XPathNavigator::MoveToFirstAttribute() método


Quando sobrescrito em uma classe derivada, move o [XPathNavigator](../) para o primeiro atributo do nó atual.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToFirstAttribute()=0
```


### Valor de Retorno

**true** se o [XPathNavigator](../) for bem-sucedido ao mover para o primeiro atributo do nó atual; caso contrário, **false**. Se **false**, a posição do [XPathNavigator](../) permanece inalterada.
