## XPathNavigator::get_NamespaceURI() método


Quando substituído em uma classe derivada, obtém a URI do namespace do nó atual.

```cpp
virtual String System::Xml::XPath::XPathNavigator::get_NamespaceURI()=0
```


### Valor de Retorno

Um [String](../../../system/string/) que contém a URI do namespace do nó atual, ou [String::Empty](../../../system/string/empty/) se o nó atual não tem URI de namespace.
