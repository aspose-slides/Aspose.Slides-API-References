## XPathNavigator::get_IsEmptyElement() method


Quando sobrescrito em uma classe derivada, obtém um valor que indica se o nó atual é um elemento vazio sem uma tag de elemento final.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::get_IsEmptyElement()=0
```


### Valor de Retorno

**true** se o nó atual for um elemento vazio; caso contrário, **false**.
