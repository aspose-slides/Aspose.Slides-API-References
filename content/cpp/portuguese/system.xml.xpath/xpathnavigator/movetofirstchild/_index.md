## XPathNavigator::MoveToFirstChild() método

Quando sobrescrito em uma classe derivada, move o [XPathNavigator](../) para o primeiro nó filho do nó atual.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToFirstChild()=0
```

### Valor de Retorno

**true** se o [XPathNavigator](../) for bem-sucedido ao mover para o primeiro nó filho do nó atual; caso contrário, **false**. Se **false**, a posição do [XPathNavigator](../) permanecerá inalterada.
