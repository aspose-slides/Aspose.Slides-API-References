## XPathNavigator::MoveToParent() método

Quando sobrescrito em uma classe derivada, move o [XPathNavigator](../) para o nó pai do nó atual.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToParent()=0
```

### Valor de Retorno

**true** se o [XPathNavigator](../) for bem-sucedido ao mover para o nó pai do nó atual; caso contrário, **false**. Se **false**, a posição do [XPathNavigator](../) não é alterada.
