## XPathNavigator::GetNamespace(String) método

Retorna o valor do nó de namespace correspondente ao nome local especificado.

```cpp
virtual String System::Xml::XPath::XPathNavigator::GetNamespace(String name)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| name | [String](../../../system/string/) | O nome local do nó de namespace. |

### Valor de Retorno

Um [String](../../../system/string/) que contém o valor do nó de namespace; [String::Empty](../../../system/string/empty/) se um nó de namespace correspondente não for encontrado, ou se o [XPathNavigator](../) não estiver posicionado em um nó de elemento.
