## XPathNavigator::MoveToNamespace(String) método

Move o [XPathNavigator](../) para o nó de namespace com o prefixo de namespace especificado.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToNamespace(String name)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| name | [String](../../../system/string/) | O prefixo de namespace do nó de namespace. |

### Valor de Retorno

**true** se o [XPathNavigator](../) for bem-sucedido ao mover para o namespace especificado; **false** se um nó de namespace correspondente não for encontrado, ou se o [XPathNavigator](../) não estiver posicionado em um nó de elemento. Se **false**, a posição do [XPathNavigator](../) permanece inalterada.
