## XmlCaseOrder enum


Especifica a ordem de classificação para letras maiúsculas e minúsculas.

```cpp
enum class XmlCaseOrder
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| None | 0 | Ignora a diferenciação entre maiúsculas e minúsculas. |
| UpperFirst | 1 | Letras maiúsculas são ordenadas antes das letras minúsculas. |
| LowerFirst | 2 | Letras minúsculas são ordenadas antes das letras maiúsculas. |
