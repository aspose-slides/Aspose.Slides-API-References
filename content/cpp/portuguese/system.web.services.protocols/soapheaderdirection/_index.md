## SoapHeaderDirection enum

Enumera as direções do cabeçalho SOAP.

```cpp
enum class SoapHeaderDirection
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| In | 1 | O destinatário do cabeçalho SOAP é o serviço XML [Web](../../system.web/). |
| InOut | 3 | Os destinatários do cabeçalho SOAP são tanto o serviço XML [Web](../../system.web/) quanto o cliente de serviço XML [Web](../../system.web/). |
| Out | 2 | O destinatário do cabeçalho SOAP é o cliente de serviço XML [Web](../../system.web/). |
| Fault | 4 | O cabeçalho SOAP é enviado ao cliente de serviço XML [Web](../../system.web/) quando uma exceção é lançada pelo método de serviço XML [Web](../../system.web/). |
