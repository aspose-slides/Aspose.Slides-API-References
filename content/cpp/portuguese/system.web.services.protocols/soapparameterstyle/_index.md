## SoapParameterStyle enum

Enumera os formatos dos parâmetros em uma mensagem SOAP.

```cpp
enum class SoapParameterStyle
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Default | 0 | Se '[SoapDocumentServiceAttribute](../soapdocumentserviceattribute/)' não for aplicado à classe, então o valor padrão é 'Wrapped'. |
| Bare | 1 | Os parâmetros são colocados em elementos XML que seguem o elemento 'Body'. |
| Wrapped | 2 | Os parâmetros são encapsulados dentro de um único elemento XML que segue o elemento 'Body'. |
