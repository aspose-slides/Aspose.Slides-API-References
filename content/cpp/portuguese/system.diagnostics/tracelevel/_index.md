## TraceLevel enum

Especifica quais mensagens devem ser enviadas para as classes [System.Diagnostics.Debug](../debug/), [System.Diagnostics.Trace](../trace/) e System.Diagnostics.TraceSwitch classes.

```cpp
enum class TraceLevel
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Off | 0 | Não gera mensagens de rastreamento e depuração. |
| Error | 1 | Emite mensagens de tratamento de erros. |
| Warning | 2 | Emite avisos e mensagens de tratamento de erros. |
| Info | 3 | Emite mensagens informativas, avisos e mensagens de tratamento de erros. |
| Verbose | 4 | Emite todas as mensagens de depuração e rastreamento. |
