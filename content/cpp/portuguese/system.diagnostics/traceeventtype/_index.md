## TraceEventType enum

Identifica o tipo de evento que causou o rastreamento.

```cpp
enum class TraceEventType
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Critical | 1 | Erro fatal ou falha da aplicação. |
| Error | 2 | Erro recuperável. |
| Warning | 4 | Problema não crítico. |
| Information | 8 | Mensagem informativa. |
| Verbose | 16 | Rastreamento de depuração. |
| Start | 256 | Início de uma operação lógica. |
| Stop | 512 | Parada de uma operação lógica. |
| Suspend | 1024 | Suspensão de uma operação lógica. |
| Resume | 2048 | Retomada de uma operação lógica. |
| Transfer | 4096 | Alteração da identidade de correlação. |
