## IMathPhantom::get_ZeroDesc() método


Obtém um valor que indica se a descida (profundidade abaixo da linha de base) do elemento base deve ser tratada como zero.

```cpp
virtual bool Aspose::Slides::MathText::IMathPhantom::get_ZeroDesc()=0
```

## Observações


Quando **true**, o phantom não abaixa a linha de base da linha matemática circundante. Corresponde ao atributo OMML **m:zeroDesc**.
