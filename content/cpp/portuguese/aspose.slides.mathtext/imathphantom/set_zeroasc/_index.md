## IMathPhantom::set_ZeroAsc(bool) método

Define um valor indicando se a ascensão (altura acima da linha de base) do elemento base deve ser tratada como zero.

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_ZeroAsc(bool value)=0
```

## Observações

Quando **true**, o phantom não eleva a linha de base da linha matemática ao redor. Corresponde ao atributo OMML **m:zeroAsc**.
