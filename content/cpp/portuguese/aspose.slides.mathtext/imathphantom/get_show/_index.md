## IMathPhantom::get_Show() método

Obtém um valor que indica se o elemento base está exibido.

```cpp
virtual bool Aspose::Slides::MathText::IMathPhantom::get_Show()=0
```

## Observações

Quando **false**, o elemento base está oculto, mas ainda pode ocupar espaço dependendo de outras configurações phantom. Corresponde ao atributo OMML **m:show**.
