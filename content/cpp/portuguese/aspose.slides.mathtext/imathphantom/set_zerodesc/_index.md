## IMathPhantom::set_ZeroDesc(bool) método

Define um valor que indica se a descida (profundidade abaixo da linha de base) do elemento base deve ser tratada como zero.

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_ZeroDesc(bool value)=0
```

## Observações

Quando **true**, o phantom não abaixa a linha de base da linha matemática circundante. Corresponde ao atributo OMML **m:zeroDesc**.
