## IMathPhantom::get_ZeroWidth() método


Obtém um valor que indica se a largura do elemento base deve ser tratada como zero.

```cpp
virtual bool Aspose::Slides::MathText::IMathPhantom::get_ZeroWidth()=0
```

## Observações


Quando **true**, o phantom não reserva espaço horizontal para sua base. Corresponde ao atributo OMML **m:zeroWid**.
