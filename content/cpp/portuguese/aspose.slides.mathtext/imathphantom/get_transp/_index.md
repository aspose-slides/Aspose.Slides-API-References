## IMathPhantom::get_Transp() método

Obtém um valor que indica se o fantasma é transparente para regras de espaçamento baseadas em classes.

```cpp
virtual bool Aspose::Slides::MathText::IMathPhantom::get_Transp()=0
```

## Observações

Quando **true**, operadores e símbolos dentro do fantasma ainda afetam o espaçamento matemático ao redor do fantasma (como se fosse visível). Quando **false**, o espaçamento baseado em classes é ignorado. Corresponde ao atributo OMML **m:transp**.
