## IMathPhantom::get_ZeroAsc() método


Obtém um valor que indica se a ascensão (altura acima da linha de base) do elemento base deve ser tratada como zero.

```cpp
virtual bool Aspose::Slides::MathText::IMathPhantom::get_ZeroAsc()=0
```

## Observações


Quando **true**, o phantom não eleva a linha de base da linha de matemática circundante. Corresponde ao atributo OMML **m:zeroAsc**.
