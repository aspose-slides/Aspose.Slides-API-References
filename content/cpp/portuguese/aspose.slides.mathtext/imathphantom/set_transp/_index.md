## IMathPhantom::set_Transp(bool) método

Define um valor que indica se o phantom é transparente para regras de espaçamento baseadas em classe.

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_Transp(bool value)=0
```

## Observações

Quando **true**, operadores e símbolos dentro do phantom ainda afetam o espaçamento matemático ao redor do phantom (como se estivesse visível). Quando **false**, o espaçamento baseado em classe é ignorado. Corresponde ao atributo OMML **m:transp**.
