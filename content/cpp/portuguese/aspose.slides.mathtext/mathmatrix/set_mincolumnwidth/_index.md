## MathMatrix::set_MinColumnWidth(uint32_t) método

Largura mínima da coluna em twips (1/20 de um ponto) O espaçamento de intervalo (também chamado de \u201CColumn Gap\u201D ou \u201CGap Width\u201D) é adicionado ao MinColumnWidth para determinar o total de Matrix [Column](../../../aspose.slides/column/) Espaçamento (distância entre as mesmas bordas de colunas diferentes). Default: 0.

```cpp
void Aspose::Slides::MathText::MathMatrix::set_MinColumnWidth(uint32_t value) override
```

## Observações

Exemplo: 
```cpp
auto matrix = System::MakeObject<MathMatrix>(2, 3);
matrix->set_MinColumnWidth(20);
```
