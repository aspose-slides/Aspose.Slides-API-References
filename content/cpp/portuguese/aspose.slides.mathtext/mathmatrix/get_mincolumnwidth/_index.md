## MathMatrix::get_MinColumnWidth() método

Largura mínima da coluna em twips (1/20 de um ponto) O espaçamento de lacuna (também referido como \\u201CColumn Gap\\u201D ou \\u201CGap Width\\u201D) é adicionado ao MinColumnWidth para determinar o total Matrix [Column](../../../aspose.slides/column/) Spacing (distância entre as mesmas arestas de diferentes colunas). Padrão: 0.

```cpp
uint32_t Aspose::Slides::MathText::MathMatrix::get_MinColumnWidth() override
```

## Observações

Exemplo: 
```cpp
auto matrix = System::MakeObject<MathMatrix>(2, 3);
matrix->set_MinColumnWidth(20);
```
