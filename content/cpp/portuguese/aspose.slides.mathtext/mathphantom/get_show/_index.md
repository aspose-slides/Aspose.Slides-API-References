## MathPhantom::get_Show() método

Obtém um valor que indica se o elemento base está exibido.

```cpp
bool Aspose::Slides::MathText::MathPhantom::get_Show() override
```

## Observações

Quando **false**, o elemento base está oculto, mas pode ainda ocupar espaço dependendo de outras configurações phantom. Corresponde ao atributo OMML **m:show**.
