## MathPhantom::get_ZeroAsc() método

Obtém um valor que indica se a ascensão (altura acima da linha de base) do elemento base deve ser tratada como zero.

```cpp
bool Aspose::Slides::MathText::MathPhantom::get_ZeroAsc() override
```

## Observações

Quando **true**, o phantom não eleva a linha de base da linha matemática ao redor. Corresponde ao atributo OMML **m:zeroAsc**.
