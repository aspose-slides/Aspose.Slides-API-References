## MathPhantom::set_ZeroAsc(bool) método


Define um valor que indica se a ascensão (altura acima da linha de base) do elemento base deve ser tratada como zero.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_ZeroAsc(bool value) override
```

## Observações


Quando **true**, o fantasma não eleva a linha de base da linha matemática circundante. Corresponde ao atributo OMML **m:zeroAsc**.
