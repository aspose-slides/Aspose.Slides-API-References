## MathPhantom::set_ZeroWidth(bool) método


Define um valor que indica se a largura do elemento base deve ser tratada como zero.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_ZeroWidth(bool value) override
```

## Observações


Quando **true**, o phantom não reserva espaço horizontal para sua base. Corresponde ao atributo OMML **m:zeroWid**.
