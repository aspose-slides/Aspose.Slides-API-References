## MathPhantom::set_Show(bool) método


Define um valor que indica se o elemento base é exibido.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_Show(bool value) override
```

## Observações


Quando **false**, o elemento base está oculto, mas pode ainda ocupar espaço dependendo de outras configurações de phantom. Corresponde ao atributo OMML **m:show**.
