## MathPhantom::set_ZeroDesc(bool) método

Define um valor que indica se a descida (profundidade abaixo da linha de base) do elemento base deve ser tratada como zero.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_ZeroDesc(bool value) override
```

## Observações

Quando **true**, o phantom não reduz a linha de base da linha matemática circundante. Corresponde ao atributo OMML **m:zeroDesc**.
