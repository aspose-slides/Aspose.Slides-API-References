## MathPhantom::get_ZeroDesc() método


Obtém um valor que indica se o descenso (profundidade abaixo da linha de base) do elemento base deve ser tratado como zero.

```cpp
bool Aspose::Slides::MathText::MathPhantom::get_ZeroDesc() override
```

## Observações


Quando **true**, o phantom não abaixa a linha de base da linha de matemática circundante. Corresponde ao atributo OMML **m:zeroDesc**.
