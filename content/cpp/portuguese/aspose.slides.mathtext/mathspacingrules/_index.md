## MathSpacingRules enum

Tipos de espaço (espaçamento horizontal) entre colunas de uma matriz

```cpp
enum class MathSpacingRules
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| SingleSpacingGap | 0 | Single (1 em para colunas ou 1 linha para linhas) |
| OneAndHalfSpacingGap | 1 | One and a half (1,5 ems para colunas ou 1,5 linhas para linhas) |
| DoubleSpacingGap | 2 | Double spacing (2 ems para colunas ou 2 linhas para linhas) |
| Exactly | 3 | Exactly value Para colunas, baseia-se no valor de ColumnGap, medido em twips Para linhas, baseia-se no valor de RowGap, medido em twips |
| Multiple | 4 | Multiple Para colunas, baseia-se no valor de ColumnGap, medido em incrementos de 0,5 em Para linhas, baseia-se no valor de RowGap, medido em linhas |
