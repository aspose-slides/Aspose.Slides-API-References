## Classe IMathBox


Especifica o empacotamento lógico (embalagem) do elemento matemático. Por exemplo, um objeto empacotado pode servir como um emulador de operador com ou sem um ponto de alinhamento, servir como um ponto de quebra de linha ou ser agrupado de modo a não permitir quebras de linha dentro dele. Por exemplo, o operador \"==\" deve ser empacotado para impedir quebras de linha.

```cpp
class IMathBox : public virtual Aspose::Slides::MathText::IMathElement
```
