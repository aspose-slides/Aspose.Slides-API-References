## IMathFraction classe

Especifica o objeto fração, constituído por um numerador e um denominador separados por uma barra de fração. A barra de fração pode ser horizontal ou diagonal, dependendo das propriedades da fração. O objeto fração também é usado para representar a função de pilha, que coloca um elemento acima de outro, sem barra de fração.

```cpp
class IMathFraction : public virtual Aspose::Slides::MathText::IMathElement
```
