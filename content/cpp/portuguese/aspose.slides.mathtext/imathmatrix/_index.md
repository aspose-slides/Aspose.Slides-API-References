## IMathMatrix classe

Especifica o objeto Matrix, consistindo de elementos filhos dispostos em uma ou mais linhas e colunas. É importante notar que as matrizes não possuem delimitadores embutidos. Para colocar a matriz entre colchetes, você deve usar o objeto delimitador ([IMathDelimiter](../imathdelimiter/)). Argumentos nulos podem ser usados para criar lacunas nas matrizes.

```cpp
class IMathMatrix : public virtual Aspose::Slides::MathText::IMathElement
```
