## IMathMatrix::set_MinColumnWidth(uint32_t) método

Largura mínima da coluna em twips (1/20 de um ponto) O espaçamento entre colunas (também referido como \\u201CColumn Gap\\u201D ou \\u201CGap Width\\u201D) é adicionado ao MinColumnWidth para determinar o total Matrix [Column](../../../aspose.slides/column/) Spacing (distância entre as mesmas bordas de colunas diferentes). Padrão: 0.

```cpp
virtual void Aspose::Slides::MathText::IMathMatrix::set_MinColumnWidth(uint32_t value)=0
```

## Observações

Exemplo:
```cpp
auto matrix = System::MakeObject<MathMatrix>(2, 3);
matrix->set_MinColumnWidth(20);
```
