## MathFraction classe


Specifica o objeto fração, constituído por um numerador e denominador separados por uma barra de fração. A barra de fração pode ser horizontal ou diagonal, dependendo das propriedades da fração. O objeto fração também é usado para representar a função de empilhamento, que coloca um elemento acima de outro, sem barra de fração.

```cpp
class MathFraction : public Aspose::Slides::MathText::MathElementBase,
                     public Aspose::Slides::MathText::IMathFraction,
                     public Aspose::Slides::MathText::IHasControlCharacterProperties
```
