## MemoryMarshal classe

Fornece implementação de marshaling de memória. Somente para compatibilidade com código traduzido, já que nenhum código gerenciado é suportado no lado C++. Este é um tipo estático sem serviços de instância. Você nunca deve criar instâncias dele por nenhum meio.

```cpp
class MemoryMarshal
```
