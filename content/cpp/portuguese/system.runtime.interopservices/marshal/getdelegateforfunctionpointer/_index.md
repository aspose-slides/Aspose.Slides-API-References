## Marshal::GetDelegateForFunctionPointer(IntPtr) método

Converte um ponteiro de função não gerenciado para um delegate do tipo especificado.

```cpp
template<typename TDelegate> static TDelegate System::Runtime::InteropServices::Marshal::GetDelegateForFunctionPointer(IntPtr ptr)
```

### Parâmetros de modelo

| Parâmetro | Descrição |
| --- | --- |
| TDelegate | O tipo do delegate a ser retornado. |

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| ptr | IntPtr | O ponteiro de função não gerenciado a ser convertido. |

### Valor de retorno

Uma instância do tipo de delegate especificado.
