## Collection::crend() const método


Obtém um iterador reverso para um elemento qualificado como const não existente antes do início da coleção.

```cpp
const_reverse_iterator System::Collections::ObjectModel::Collection<T>::crend() const noexcept
```


### Valor de Retorno

Um iterador reverso apontando para o elemento teórico qualificado como const que precede o primeiro elemento da lista (último em ordem reversa).
