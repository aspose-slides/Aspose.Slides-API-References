## PointF::PointF(const SizeF\&) construtor

```cpp

```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| size | const [SizeF](../../sizef/)\& | Um objeto [SizeF](../../sizef/) cujos valores de largura e altura são usados para inicializar os valores das coordenadas X e Y do objeto [PointF](../) que está sendo criado |
