## StringFormatFlags enum

Especifica as informações de exibição e layout para as strings de texto.

```cpp
enum class StringFormatFlags
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| DirectionRightToLeft | 1 | Direção do texto da direita para a esquerda. |
| DirectionVertical | 2 | [Text](../../system.drawing.text/) está alinhado verticalmente. |
| FitBlackBox | 4 | Partes dos caracteres podem ultrapassar a caixa de layout. |
| DisplayFormatControl | 32 | Caracteres de controle são exibidos. |
| NoFontFallback | 1024 | [Font](../font/) fallback está desativado. |
| MeasureTrailingSpaces | 2048 | Insere o espaço final no final de cada linha. |
| NoWrap | 4096 | [Text](../../system.drawing.text/) wrapping está desativado. |
| LineLimit | 8192 | Linhas inteiras são dispostas no retângulo de formatação. |
| NoClip | 16384 | Partes que ultrapassam dos glifos podem ser mostradas. |
