## classe SystemColors

Classe que fornece um conjunto de objetos [Color](../color/) precriados que representam as cores dos elementos de exibição [Windows](../../system.windows/). Este é um tipo estático sem serviços de instância. Você nunca deve criar instâncias dele por nenhum meio.

```cpp
class SystemColors
```
