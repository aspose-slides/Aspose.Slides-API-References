## Point::Add(const Point\&, const Size\&) método

Adiciona os valores de largura e altura do objeto [Size](../../size/) especificado aos valores das coordenadas X e Y do objeto [Point](../) especificado, respectivamente.

```cpp
static Point System::Drawing::Point::Add(const Point &point, const Size &size)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| point | const [Point](../)\& | O ponto a ser traduzido |
| size | const [Size](../../size/)\& | O objeto [Size](../../size/) que especifica os valores a serem adicionados aos valores das coordenadas do **point** |

### Valor de retorno

Um novo objeto [Point](../) cujo valor da coordenada X é igual à soma do valor da coordenada X do **point** e do valor de largura de **size**, e o valor da coordenada Y é igual à soma do valor da coordenada Y do **point** e do valor de altura de **size**
