## StringTrimming enum

Especifica como os caracteres devem ser cortados de uma string que não se ajusta à forma do layout.

```cpp
enum class StringTrimming
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| None | 0 | Sem corte. |
| Character | 1 | Cortar até o caractere mais próximo. |
| Word | 2 | Cortar até a palavra mais próxima. |
| EllipsisCharacter | 3 | Cortar até o caractere mais próximo e inserir reticências no final da string. |
| EllipsisWord | 4 | Cortar até a palavra mais próxima e inserir reticências no final da string. |
| EllipsisPath | 5 | O centro é removido das linhas cortadas e substituído por reticências. Mantenha o máximo possível do último segmento da linha delimitado por barra. |
