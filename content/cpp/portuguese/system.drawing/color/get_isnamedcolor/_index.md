## Color::get_IsNamedColor() const método

Retorna um valor que determina se a estrutura [Color](../) representa uma cor nomeada ou um membro da enumeração KnownColor.

```cpp
bool System::Drawing::Color::get_IsNamedColor() const
```

### Valor de Retorno

True se o [Color](../) foi criado usando o método FromName(String) ou o método [FromKnownColor(KnownColor)](../fromknowncolor/); caso contrário, retorna false.
