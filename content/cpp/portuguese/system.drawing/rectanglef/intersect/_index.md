Substitui o retângulo representado pelo objeto atual pelo retângulo que resulta da sua interseção com o retângulo representado pelo objeto especificado.

```cpp

```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| rect | const [RectangleF](../)\& | O objeto [RectangleF](../) que representa o retângulo a intersectar com o retângulo representado pelo objeto atual |

## RectangleF::Intersect(const RectangleF\&, const RectangleF\&) método

Retorna um retângulo que é resultado da interseção dos retângulos especificados.

```cpp
static RectangleF System::Drawing::RectangleF::Intersect(const RectangleF &a, const RectangleF &b)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| a | const [RectangleF](../)\& | O primeiro retângulo a intersectar |
| b | const [RectangleF](../)\& | O segundo retângulo a intersectar |

### Valor de retorno

O resultado da interseção de **a** com **b**
