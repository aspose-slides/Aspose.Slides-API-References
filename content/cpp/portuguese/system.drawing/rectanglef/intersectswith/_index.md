## RectangleF::IntersectsWith(const RectangleF\&) método


Determina se os retângulos representados pelo objeto atual e pelo objeto especificado se intersectam.

```cpp
bool System::Drawing::RectangleF::IntersectsWith(const RectangleF &rect)
```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| rect | const [RectangleF](../)\& | O retângulo a ser verificado |

### Valor de Retorno

True se os retângulos representados pelo objeto atual e **rect** se intersectarem, caso contrário - false
