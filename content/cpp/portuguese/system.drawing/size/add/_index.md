## Size::Add(const Size\&, const Size\&) método


Retorna um novo objeto [Size](../) que é a soma do objeto [Size](../) especificado, ou seja, cujo valor de largura é igual à soma dos valores de largura dos objetos especificados e cujo valor de altura é igual à soma dos valores de altura dos objetos especificados.

```cpp
static Size System::Drawing::Size::Add(const Size &size1, const Size &size2)
```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| size1 | const [Size](../)\& | O primeiro operando |
| size2 | const [Size](../)\& | O segundo operando |

### Valor de retorno

O objeto [Size](../) que é a soma de **size1** e **size2**
