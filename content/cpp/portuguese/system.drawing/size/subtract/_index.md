## Size::Subtract(const Size\&, const Size\&) método

Retorna um novo objeto [Size](../) que é o resultado da subtração de **size2** de **size1**, ou seja, cujo valor de largura é o resultado da subtração do valor de largura de **size2** do valor de largura de **size1** e o valor de altura é o resultado da subtração do valor de altura de **size2** do valor de altura de **size1**.

```cpp
static Size System::Drawing::Size::Subtract(const Size &size1, const Size &size2)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| size1 | const [Size](../)\& | O objeto [Size](../) de onde subtrair |
| size2 | const [Size](../)\& | O objeto [Size](../) a subtrair |

### Valor de Retorno

O objeto [Size](../) que é o resultado da subtração de **size2** de **size1**
