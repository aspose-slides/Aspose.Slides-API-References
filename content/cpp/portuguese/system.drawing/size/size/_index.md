## Size::Size() construtor

Constrói um novo objeto [Size](../) e inicializa seus valores de largura e altura com 0.

```cpp
System::Drawing::Size::Size()
```

## Size::Size(const Point\&) construtor

Constrói um novo objeto [Size](../) e inicializa seus valores de largura e altura com os valores das coordenadas X e Y do ponto especificado, respectivamente.

```cpp
System::Drawing::Size::Size(const Point &point)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| point | const [Point](../../point/)\& | Um objeto [Point](../../point/) cujas coordenadas X e Y são usadas para inicializar os valores de largura e altura do objeto [Size](../) que está sendo criado |

## Size::Size(int, int) construtor

Constrói um novo objeto [Size](../) e o inicializa com o valor especificado.

```cpp
System::Drawing::Size::Size(int width, int height)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| width | int | O valor para width |
| height | int | O valor de height |
