## SystemFonts classe


Fornece um conjunto de objetos [Font](../font/) pré-criados que representam fontes usadas para exibir texto em elementos de exibição [Windows](../../system.windows/). Este é um tipo estático sem serviços de instância. Você nunca deve criar instâncias dele por qualquer meio.

```cpp
class SystemFonts : public System::Object
```
