## StringDigitSubstitute enum

Especifica como os dígitos em uma string são substituídos de acordo com a localidade ou idioma.

```cpp
enum class StringDigitSubstitute
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| User | 0 | Substituição definida pelo usuário. |
| None | 1 | Substituição está desativada. |
| National | 2 | Substitui dígitos que correspondem ao idioma nacional oficial da localidade do usuário. |
| Traditional | 3 | Substitui dígitos que correspondem ao script ou idioma nativo do usuário, que pode não ser o mesmo que o idioma nacional oficial da localidade do usuário. |
