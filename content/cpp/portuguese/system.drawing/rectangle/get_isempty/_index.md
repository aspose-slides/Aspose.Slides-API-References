## Rectangle::get_IsEmpty() const método

Determina se as coordenadas X e Y do canto superior esquerdo do recangle representado pelo objeto atual, bem como sua largura e altura, têm valores iguais a 0.

```cpp
bool System::Drawing::Rectangle::get_IsEmpty() const
```

### Valor de Retorno

True se as coordenadas X e Y do canto superior esquerdo do recangle representado pelo objeto atual, bem como sua largura e altura, têm valores iguais a 0, caso contrário - false
