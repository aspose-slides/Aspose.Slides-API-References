## Rectangle::Intersect(const Rectangle\&) método


Substitui o retângulo representado pelo objeto atual pelo retângulo resultante da sua interseção com o retângulo representado pelo objeto especificado.

```cpp
void System::Drawing::Rectangle::Intersect(const Rectangle &rect)
```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| rect | const [Rectangle](../)\& | O objeto [Rectangle](../) que representa o retângulo a intersectar com o retângulo representado pelo objeto atual |

## Rectangle::Intersect(const Rectangle\&, const Rectangle\&) método


Retorna um retângulo que é o resultado da interseção dos retângulos especificados.

```cpp
static Rectangle System::Drawing::Rectangle::Intersect(const Rectangle &a, const Rectangle &b)
```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| a | const [Rectangle](../)\& | O primeiro retângulo a intersectar |
| b | const [Rectangle](../)\& | O segundo retângulo a intersectar |

### Valor de Retorno

O resultado da interseção de **a** com **b**
