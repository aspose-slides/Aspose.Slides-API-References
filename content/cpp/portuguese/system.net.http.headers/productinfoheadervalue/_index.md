## ProductInfoHeaderValue classe


Representa um produto ou um comentário em um valor do cabeçalho 'User-Agent'. Objetos desta classe devem ser alocados apenas usando a função [System::MakeObject()](../../system/makeobject/). Nunca crie instâncias deste tipo na pilha ou usando o operador new, pois isso resultará em erros de tempo de execução e/ou falhas de asserção. Sempre envolva esta classe em um ponteiro [System::SmartPtr](../../system/smartptr/) e use esse ponteiro para passá-lo às funções como argumento.

```cpp
class ProductInfoHeaderValue : public System::ICloneable
```
