## XmlSchemaElement::get_IsAbstract() método


Retorna informações que indicam se o elemento pode ser usado em um documento de instância.

```cpp
bool System::Xml::Schema::XmlSchemaElement::get_IsAbstract()
```


### Valor de retorno

Se **true**, o elemento não pode aparecer no documento de instância. O padrão é **false**. Opcional.
