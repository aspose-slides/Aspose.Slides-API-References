## XmlSchemaElement::get_IsNillable() método

Retorna informações que indicam se **xsi:nil** pode ocorrer nos dados da instância. Indica se um valor nulo explícito pode ser atribuído ao elemento.

```cpp
bool System::Xml::Schema::XmlSchemaElement::get_IsNillable()
```

### Valor de Retorno

Se nillable for **true**, isso permite que uma instância do elemento tenha o atributo **nil** definido como **true**. O atributo **nil** é definido como parte do namespace XML [Schema](../../) para instâncias. O padrão é **false**. Opcional.
