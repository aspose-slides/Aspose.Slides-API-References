## IXmlSchemaInfo::get_IsDefault() method

Retorna um valor que indica se este nó XML validado foi definido como resultado de um valor padrão aplicado durante a validação de esquema XML [Schema](../../) Definition Language (XSD).

```cpp
virtual bool System::Xml::Schema::IXmlSchemaInfo::get_IsDefault()=0
```

### Valor de Retorno

**true** se este nó XML validado foi definido como resultado de um valor padrão aplicado durante a validação do esquema; caso contrário, **false**.
