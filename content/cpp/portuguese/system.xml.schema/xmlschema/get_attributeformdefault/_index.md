## XmlSchema::get_AttributeFormDefault() método


Retorna o formulário para atributos declarados no namespace de destino do esquema.

```cpp
XmlSchemaForm System::Xml::Schema::XmlSchema::get_AttributeFormDefault()
```


### Valor de retorno

O valor XmlSchemaForm que indica se atributos do namespace de destino precisam ser qualificados com o prefixo do namespace. O padrão é [XmlSchemaForm::None](../../xmlschemaform/).
