## XmlSchema::get_BlockDefault() método

Retorna o atributo **blockDefault** que define o valor padrão do atributo **block** em elementos e tipos complexos no **targetNamespace** do esquema.

```cpp
XmlSchemaDerivationMethod System::Xml::Schema::XmlSchema::get_BlockDefault()
```

### Valor de Retorno

Um valor XmlSchemaDerivationMethod representando os diferentes métodos para impedir a derivação. O valor padrão é [XmlSchemaDerivationMethod::None](../../xmlschemaderivationmethod/).
