## XmlSchema::get_ElementFormDefault() método

Retorna o formulário para os elementos declarados no namespace de destino do esquema.

```cpp
XmlSchemaForm System::Xml::Schema::XmlSchema::get_ElementFormDefault()
```

### Valor de Retorno

O valor XmlSchemaForm que indica se os elementos do namespace de destino precisam ser qualificados com o prefixo do namespace. O padrão é [XmlSchemaForm::None](../../xmlschemaform/).
