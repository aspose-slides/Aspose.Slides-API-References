## XmlSchema::get_FinalDefault() método


Retorna o atributo **finalDefault** que define o valor padrão do atributo **final** em elementos e tipos complexos no namespace de destino do esquema.

```cpp
XmlSchemaDerivationMethod System::Xml::Schema::XmlSchema::get_FinalDefault()
```


### Valor de Retorno

Um valor XmlSchemaDerivationMethod que representa os diferentes métodos para impedir a derivação. O valor padrão é [XmlSchemaDerivationMethod::None](../../xmlschemaderivationmethod/).
