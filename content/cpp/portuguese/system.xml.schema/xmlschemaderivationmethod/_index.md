## XmlSchemaDerivationMethod enum


Fornece diferentes métodos para impedir a derivação.

```cpp
enum class XmlSchemaDerivationMethod
```

### Values

| Nome | Valor | Descrição |
| --- | --- | --- |
| Empty | 0 | Substitui o método de derivação padrão para permitir qualquer derivação. |
| Substitution | 1 | Refere-se a derivações por **Substitution**. |
| Extension | 2 | Refere-se a derivações por **Extension**. |
| Restriction | 4 | Refere-se a derivações por **Restriction**. |
| List | 8 | Refere-se a derivações por **List**. |
| Union | 16 | Refere-se a derivações por **Union**. |
| All | 255 | **#all**. Refere-se a todos os métodos de derivação. |
| None | 256 | Aceita o método de derivação padrão. |
