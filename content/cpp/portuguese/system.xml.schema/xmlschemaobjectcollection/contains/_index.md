## XmlSchemaObjectCollection::Contains(const SharedPtr\<XmlSchemaObject\>\&) method

```cpp
bool System::Xml::Schema::XmlSchemaObjectCollection::Contains(const SharedPtr<XmlSchemaObject> &item)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| item | const [SharedPtr](../../../system/sharedptr/)\<[XmlSchemaObject](../../xmlschemaobject/)\>\& | O [XmlSchemaObject](../../xmlschemaobject/). |

### Valor de Retorno

**true** se o nome qualificado especificado estiver na coleção; caso contrário, retorna **false**. Se **nullptr** for fornecido, **false** é retornado porque não há nome qualificado com um nome nulo.
