## XmlSchemaSet::get_IsCompiled() método


Retorna um valor que indica se os esquemas da linguagem de definição XML [Schema](../../) (XSD) no [XmlSchemaSet](../) foram compilados.

```cpp
bool System::Xml::Schema::XmlSchemaSet::get_IsCompiled()
```


### Valor de Retorno

**true** se os esquemas no [XmlSchemaSet](../) foram compilados desde a última vez que um esquema foi adicionado ou removido do [XmlSchemaSet](../); caso contrário, **false**.
