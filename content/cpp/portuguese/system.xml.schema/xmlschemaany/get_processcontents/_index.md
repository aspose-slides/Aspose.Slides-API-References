## XmlSchemaAny::get_ProcessContents() método

Retorna informações sobre como um aplicativo ou processador XML deve lidar com a validação de documentos XML para os elementos especificados pelo elemento **any**.

```cpp
XmlSchemaContentProcessing System::Xml::Schema::XmlSchemaAny::get_ProcessContents()
```

### Valor de Retorno

Um dos valores de XmlSchemaContentProcessing. Se nenhum atributo **processContents** for especificado, o padrão é **Strict**.
