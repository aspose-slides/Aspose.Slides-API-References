## XmlSchemaType::get_IsMixed() método


Retorna um valor que indica se este tipo possui um modelo de conteúdo misto. Esta chamada é válida apenas em um tipo complexo.

```cpp
virtual bool System::Xml::Schema::XmlSchemaType::get_IsMixed()
```


### Valor de retorno

**true** se o tipo possui um modelo de conteúdo misto; caso contrário, **false**. O padrão é **false**.
