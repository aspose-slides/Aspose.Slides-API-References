## XmlSchemaAttribute classe


Representa o elemento **attribute** do XML [Schema](../) conforme especificado pelo Consórcio World Wide [Web](../../system.web/) (W3C). Os atributos fornecem informações adicionais para outros elementos do documento. A tag de atributo é aninhada entre as tags de um elemento do documento para o esquema. O documento XML exibe atributos como itens nomeados na tag de abertura de um elemento.

```cpp
class XmlSchemaAttribute : public System::Xml::Schema::XmlSchemaAnnotated
```

## Observações



Objetos desta classe devem ser alocados apenas usando a função [System::MakeObject()](../../system/makeobject/). Nunca crie instâncias deste tipo na pilha ou usando o operador new, pois isso resultará em erros de tempo de execução e/ou falhas de asserção. Sempre encapsule esta classe em um ponteiro [System::SmartPtr](../../system/smartptr/) e use esse ponteiro para passá-lo a funções como argumento.
