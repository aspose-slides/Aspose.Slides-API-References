## XmlAtomicValue::get_IsNode() método

Retorna um valor que indica se o elemento XML validado ou atributo é um nó [XPath](../../../system.xml.xpath/) ou um valor atômico.

```cpp
bool System::Xml::Schema::XmlAtomicValue::get_IsNode() override
```

**true** se o elemento XML validado ou atributo for um nó [XPath](../../../system.xml.xpath/); **false** se o elemento XML validado ou atributo for um valor atômico.
