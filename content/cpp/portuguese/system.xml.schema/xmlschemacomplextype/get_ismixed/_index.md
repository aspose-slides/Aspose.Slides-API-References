## XmlSchemaComplexType::get_IsMixed() method


Retorna informações que determinam se o tipo complexo possui um modelo de conteúdo misto (marcações dentro do conteúdo).

```cpp
bool System::Xml::Schema::XmlSchemaComplexType::get_IsMixed() override
```


### Valor de Retorno

**true**, se dados de caractere podem aparecer entre elementos filhos deste tipo complexo; caso contrário, **false**. O padrão é **false**. Opcional.
