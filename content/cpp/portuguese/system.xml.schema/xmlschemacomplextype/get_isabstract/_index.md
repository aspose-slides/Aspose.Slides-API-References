## XmlSchemaComplexType::get_IsAbstract() método


Retorna a informação que determina se o elemento **complexType** pode ser usado no documento de instância.

```cpp
bool System::Xml::Schema::XmlSchemaComplexType::get_IsAbstract()
```


### Valor de Retorno

Se **true**, um elemento não pode usar este elemento **complexType** diretamente e deve usar um tipo complexo derivado deste elemento **complexType**. O padrão é **false**. Opcional.
