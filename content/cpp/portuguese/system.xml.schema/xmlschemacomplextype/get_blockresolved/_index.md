## XmlSchemaComplexType::get_BlockResolved() método

Retorna o valor após o tipo ter sido compilado para o conjunto de informações pós-validação de esquema (infoset). Esse valor indica como o tipo é aplicado quando **xsi:type** é usado no documento de instância.

```cpp
XmlSchemaDerivationMethod System::Xml::Schema::XmlSchemaComplexType::get_BlockResolved()
```

### Valor de Retorno

O valor do infoset pós-validação de esquema. O padrão é o valor **BlockDefault** no elemento **schema**.
