## XmlSchemaComplexContent::get_IsMixed() método

Retorna informações que determinam se o tipo tem um modelo de conteúdo misto.

```cpp
bool System::Xml::Schema::XmlSchemaComplexContent::get_IsMixed()
```

### Valor de Retorno

Se este valor for **true**, dados de caractere são permitidos entre os elementos filhos do tipo complexo (modelo de conteúdo misto). O padrão é **false**. Opcional.
