## XmlSchemaCompilationSettings::get_EnableUpaCheck() método


Retorna um valor que indica se o [XmlSchemaSet](../../xmlschemaset/) deve verificar violações de Unique Particle Attribution (UPA).

```cpp
bool System::Xml::Schema::XmlSchemaCompilationSettings::get_EnableUpaCheck()
```


### Valor de Retorno

**true** se o [XmlSchemaSet](../../xmlschemaset/) deve verificar violações de Unique Particle Attribution (UPA); caso contrário, **false**. O padrão é **true**.
