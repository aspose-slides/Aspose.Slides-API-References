## InferenceOption enum

Afeta a ocorrência e as informações de tipo inferidas pela classe [XmlSchemaInference](../) para elementos e atributos em um documento XML.

```cpp
enum class InferenceOption
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Restricted | 0 | Indica que uma declaração de esquema mais restritiva deve ser inferida para um elemento ou atributo específico. |
| Relaxed | 1 | Indica que uma declaração de esquema menos restritiva deve ser inferida para um elemento ou atributo específico. |
