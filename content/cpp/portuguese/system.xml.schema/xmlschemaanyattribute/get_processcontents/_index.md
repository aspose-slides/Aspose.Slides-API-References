## XmlSchemaAnyAttribute::get_ProcessContents() método

Retorna informações sobre como um aplicativo ou processador XML deve lidar com a validação de documentos XML para os atributos especificados pelo elemento **anyAttribute**.

```cpp
XmlSchemaContentProcessing System::Xml::Schema::XmlSchemaAnyAttribute::get_ProcessContents()
```

### Valor de Retorno

Um dos valores de XmlSchemaContentProcessing. Se nenhum atributo **processContents** for especificado, o padrão é **Strict**.
