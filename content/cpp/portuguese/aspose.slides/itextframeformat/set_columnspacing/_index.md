## ITextFrameFormat::set_ColumnSpacing(double) método

Define o espaço entre colunas de texto na área de texto (em pontos). Isso deve ser aplicado apenas quando houver mais de 1 coluna presente. Este valor deve ser um número positivo. Caso contrário, o valor será definido como zero. Escreva **double**.

virtual void Aspose::Slides::ITextFrameFormat::set_ColumnSpacing(double value)=0
