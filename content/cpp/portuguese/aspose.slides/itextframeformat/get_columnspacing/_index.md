## ITextFrameFormat::get_ColumnSpacing() método

Retorna o espaço entre colunas de texto na área de texto (em pontos). Isso deve ser aplicado somente quando houver mais de 1 coluna presente. Esse valor deve ser um número positivo. Caso contrário, o valor será definido como zero. Lê **double**.

```cpp
virtual double Aspose::Slides::ITextFrameFormat::get_ColumnSpacing()=0
```
