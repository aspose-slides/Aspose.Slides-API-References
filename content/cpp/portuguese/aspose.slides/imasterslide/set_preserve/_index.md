## IMasterSlide::set_Preserve(bool) método

Determina se o mestre correspondente é excluído quando todos os slides que seguem esse mestre são excluídos. Observação: [Aspose.Slides](../../) nunca removerá nenhum mestre não utilizado por si só, para realmente remover mestres não utilizados chame [IMasterSlideCollection::RemoveUnused](../../imasterslidecollection/removeunused/) Escreve **bool**.
