## IMasterSlide::get_Preserve() method


Determina se o mestre correspondente é excluído quando todos os slides que seguem esse mestre são excluídos. Nota: [Aspose.Slides](../../) nunca removerá nenhum mestre não utilizado por si só, para realmente remover mestres não utilizados chame [IMasterSlideCollection::RemoveUnused](../../imasterslidecollection/removeunused/) Leitura **bool**.

virtual bool Aspose::Slides::IMasterSlide::get_Preserve()=0
