## IDocumentProperties::set_ScaleCrop(bool) método

Indica o modo de exibição da miniatura do documento. Defina este elemento como **true** para habilitar o dimensionamento da miniatura do documento para a exibição. Defina este elemento como **false** para habilitar o corte da miniatura do documento, exibindo apenas as seções que se ajustam à exibição. Escreva **bool**.

virtual void Aspose::Slides::IDocumentProperties::set_ScaleCrop(bool value)=0
