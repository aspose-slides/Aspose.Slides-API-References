## IMasterSlideHeaderFooterManager::SetSlideNumberAndChildSlideNumbersVisibility(bool) method


Altera a visibilidade do marcador de número de página do slide mestre e de todos os marcadores de número de página filho. Marcadores filho significam que os marcadores estão contidos em slides de layout dependentes e em slides dependentes. Slides de layout dependentes e slides utilizam e dependem do slide mestre.

```cpp
virtual void Aspose::Slides::IMasterSlideHeaderFooterManager::SetSlideNumberAndChildSlideNumbersVisibility(bool isVisible)=0
```


### Arguments

| Parameter | Type | Description |
| --- | --- | --- |
| isVisible | **bool** | true - torna os marcadores de número de página visíveis, caso contrário - os oculta. |
