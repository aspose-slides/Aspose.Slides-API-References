## Shape::get_Rotation() método

Retorna o número de graus que a forma especificada está rotacionada em torno do eixo z. Um valor positivo indica rotação no sentido horário; um valor negativo indica rotação no sentido anti-horário. Leitura **float**.

```cpp
float Aspose::Slides::Shape::get_Rotation() override
```

## Observações

O valor retornado está sempre definido (não é std::numeric_limits<float>::quiet_NaN()). O valor atribuído deve estar definido (não std::numeric_limits<float>::quiet_NaN()). É possível definir valores indefinidos para as propriedades da instância RawFrame.
