## Shape::set_Rotation(float) método

Define o número de graus que a forma especificada é girada em torno do eixo z. Um valor positivo indica rotação no sentido horário; um valor negativo indica rotação no sentido anti-horário. Escreva **float**.

```cpp
void Aspose::Slides::Shape::set_Rotation(float value) override
```

## Observações

O valor retornado está sempre definido (não é std::numeric_limits<float>::quiet_NaN()). O valor atribuído deve ser definido (não std::numeric_limits<float>::quiet_NaN()). Você pode definir valores indefinidos para propriedades da instância RawFrame.
