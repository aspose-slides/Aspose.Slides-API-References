## Observações

O valor retornado está sempre definido e nunca [std::numeric_limits<float>::quiet_NaN()](../). O valor atribuído também deve estar definido; atribua [std::numeric_limits<float>::quiet_NaN()](../) apenas às propriedades de uma instância **RawFrame**.
