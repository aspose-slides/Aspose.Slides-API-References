## TextAutofitType enum


Representa o modo de ajuste automático de texto.

```cpp
enum class TextAutofitType : int8_t
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| NotDefined | -1 | Não definido. |
| None | 0 | Sem ajuste automático. |
| Normal | 1 | Ajuste automático normal. O tamanho da fonte e o espaçamento entre linhas serão reduzidos para caber na forma. |
| Shape | 2 | [Shape](../shape/) autofit. O tamanho de [Shape](../shape/) será alterado para caber no texto. |
