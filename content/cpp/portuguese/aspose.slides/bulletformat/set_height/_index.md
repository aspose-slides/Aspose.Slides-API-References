## BulletFormat::set_Height(float) método

Define a altura do marcador de um parágrafo sem herança. O valor std::numeric_limits<float>::quiet_NaN() determina que o marcador herda a altura da primeira porção do parágrafo. Escreva **float**.

```cpp
void Aspose::Slides::BulletFormat::set_Height(float value) override
```

## Observações

Um valor de altura negativo significa que a altura é fornecida em pontos e um valor positivo significa que a altura é uma porcentagem do texto circundante.
