## LineSketchType enum

Representa o tipo de esboço ou efeito atribuído a uma forma.

```cpp
enum class LineSketchType
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| NotDefined | -1 | Especifica que o efeito Sketch de uma forma está indefinido. |
| None | 0 | Especifica que uma forma não tem efeito Sketch. Isso é equivalente a esta propriedade estar vazia. |
| Curved | 1 | Especifica que uma forma tem o efeito Curved, que transforma cada borda da forma em uma grande curva suave. |
| Freehand | 2 | Especifica que uma forma tem o efeito Freehand, que se assemelha mais a uma linha desenhada imperfeitamente. |
| Scribble | 3 | Especifica que uma forma tem o efeito Scribble, que apresenta oscilações exageradas como se fosse desenhado propositalmente bagunçado. |
