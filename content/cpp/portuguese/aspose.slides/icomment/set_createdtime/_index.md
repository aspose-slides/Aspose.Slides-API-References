## IComment::set_CreatedTime(System::DateTime) método

Define o horário de criação de um comentário. Definir esta propriedade para [DateTime::MinValue](../../../system/datetime/minvalue/) significa que nenhum horário de comentário está definido. Escreva [System::DateTime](../../../system/datetime/).
