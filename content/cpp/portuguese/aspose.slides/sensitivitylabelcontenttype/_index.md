## SensitivityLabelContentType enum

Representa os tipos de marcação de conteúdo que devem ser aplicados a um documento.

```cpp
enum class SensitivityLabelContentType
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| None | 0 | Implica que a etiqueta é aplicada por padrão ou automaticamente. |
| Header | 1 | Implica que a etiqueta foi aplicada manualmente. Use para qualquer etiqueta de sensibilidade que foi aplicada diretamente pelo usuário. |
| Footer | 2 | Implica que a etiqueta foi aplicada manualmente. Use para qualquer etiqueta de sensibilidade que foi aplicada diretamente pelo usuário. |
| Watermark | 4 | Implica que a etiqueta foi aplicada manualmente. Use para qualquer etiqueta de sensibilidade que foi aplicada diretamente pelo usuário. |
| Encryption | 8 | Implica que a etiqueta foi aplicada manualmente. Use para qualquer etiqueta de sensibilidade que foi aplicada diretamente pelo usuário. |
