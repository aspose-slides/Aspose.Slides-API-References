## IAudio::get_BinaryData() método

Retorna uma cópia dos dados de um áudio. No caso de grande quantidade de dados, considere usar o método [IAudio::GetStream](../getstream/) para evitar o carregamento desnecessário dos dados do áudio na memória ou até mesmo OutOfMemoryException. Somente leitura **uint8_t**[].

```cpp
virtual System::ArrayPtr<uint8_t> Aspose::Slides::IAudio::get_BinaryData()=0
```
