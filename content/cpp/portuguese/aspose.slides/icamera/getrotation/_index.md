## ICamera::GetRotation() método

Uma rotação é definida através do uso de uma coordenada de latitude, uma coordenada de longitude e uma revolução em torno do eixo conforme as coordenadas de latitude e longitude. primeiro elemento no array de retorno - latitude, segundo - longitude, terceiro - revolução. Retorna null se nenhuma rotação estiver definida.

```cpp
virtual System::ArrayPtr<float> Aspose::Slides::ICamera::GetRotation()=0
```

### Valor de Retorno

Matriz de valores de rotação como **float**[].
