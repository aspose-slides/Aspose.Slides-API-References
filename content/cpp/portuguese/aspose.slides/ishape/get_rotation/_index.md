## IShape::get_Rotation() método

Retorna o número de graus que a forma especificada está girada em torno do eixo z. Um valor positivo indica rotação no sentido horário; um valor negativo indica rotação no sentido anti-horário. Leitura **float**.

```cpp
virtual float Aspose::Slides::IShape::get_Rotation()=0
```

## Observações

O valor retornado está sempre definido (não é std::numeric_limits<float>::quiet_NaN()). O valor atribuído deve ser definido (não std::numeric_limits<float>::quiet_NaN()). Você pode definir valores indefinidos para as propriedades de instância RawFrame.
