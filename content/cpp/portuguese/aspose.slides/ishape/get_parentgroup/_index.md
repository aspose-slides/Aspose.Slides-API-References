## IShape::get_ParentGroup() método

Retorna o objeto [GroupShape](../../groupshape/) pai se a forma estiver agrupada. Caso contrário, retorna nulo. Somente leitura [IGroupShape](../../igroupshape/).

```cpp
virtual System::SharedPtr<IGroupShape> Aspose::Slides::IShape::get_ParentGroup()=0
```

## Observações

A propriedade [IShape::get_IsGrouped](../get_isgrouped/) determina se a forma está agrupada.
