## ShapeElementFillSource enum

Representa como o elemento de forma deve ser preenchido.

```cpp
enum class ShapeElementFillSource : uint8_t
```

### Valores

| Name | Value | Description |
| --- | --- | --- |
| NoFill | 0 | Não preencha o primitivo. |
| Shape | 1 | Use o preenchimento da forma. |
| Lighten | 2 | Use o preenchimento clareado da forma. |
| LightenLess | 3 | Use um preenchimento menos clareado da forma. |
| Darken | 4 | Use o preenchimento escurecido da forma. |
| DarkenLess | 5 | Use um preenchimento menos escurecido da forma. |
