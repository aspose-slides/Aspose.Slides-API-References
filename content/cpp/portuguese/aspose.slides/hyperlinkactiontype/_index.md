## HyperlinkActionType enum

Representa um tipo de ação de hyperlink.

```cpp
enum class HyperlinkActionType
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| Unknown | -1 | Tipo de ação não reconhecido. |
| NoAction | 0 | Nenhuma ação. |
| Hyperlink | 1 | Hiperlink usual. |
| JumpFirstSlide | 2 | Ir para o primeiro slide da apresentação. |
| JumpPreviousSlide | 3 | Ir para o slide anterior. |
| JumpNextSlide | 4 | Ir para o próximo slide. |
| JumpLastSlide | 5 | Ir para o último slide da apresentação. |
| JumpEndShow | 6 | Ir para o final da apresentação de slides. |
| JumpLastViewedSlide | 7 | Ir para o último slide visualizado. |
| JumpSpecificSlide | 8 | Ir para o slide específico, referido pelo valor [IHyperlink::get_TargetSlide](../ihyperlink/get_targetslide/). |
| StartCustomSlideShow | 9 | Iniciar apresentação de slides customizada. |
| OpenFile | 10 | Abrir arquivo referenciado. |
| OpenPresentation | 11 | Abrir apresentação referenciada. |
| StartStopMedia | 12 | Iniciar/parar reprodução de arquivo de mídia. |
| StartMacro | 13 | Iniciar execução de script macro. |
| StartProgram | 14 | Iniciar programa. |
