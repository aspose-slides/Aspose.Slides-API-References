## IProtectionManager::get_IsEncrypted() método

Obtém um valor que indica se esta instância está criptografada. Somente leitura **bool**.

```cpp
virtual bool Aspose::Slides::IProtectionManager::get_IsEncrypted()=0
```

## Observações

**true** se a apresentação foi carregada de um arquivo criptografado ou o método [Encrypt(String)](../encrypt/) foi chamado ; caso contrário, **false**.
