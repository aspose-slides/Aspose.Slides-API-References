## IProtectionManager::set_EncryptDocumentProperties(bool) método

Esta propriedade faz sentido, se a apresentação estiver protegida por senha. Se verdadeiro, então as propriedades do documento são criptografadas no arquivo da apresentação. Se falso, então as propriedades do documento são públicas enquanto a apresentação está criptografada. Escreva **bool**.

```cpp
virtual void Aspose::Slides::IProtectionManager::set_EncryptDocumentProperties(bool value)=0
```
