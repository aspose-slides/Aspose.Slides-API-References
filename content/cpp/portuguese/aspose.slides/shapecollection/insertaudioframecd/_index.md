## ShapeCollection::InsertAudioFrameCD(int32_t, float, float, float, float) método

Cria um novo quadro de áudio vinculado a uma faixa de CD e o insere na coleção de formas no índice especificado.

```cpp
System::SharedPtr<IAudioFrame> Aspose::Slides::ShapeCollection::InsertAudioFrameCD(int32_t index, float x, float y, float width, float height) override
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| index | **int32_t** | O índice baseado em zero no qual inserir o quadro de áudio. |
| x | **float** | A coordenada x do novo quadro de áudio, em pontos. |
| y | **float** | A coordenada y do novo quadro de áudio, em pontos. |
| width | **float** | A largura do novo quadro de áudio, em pontos. |
| height | **float** | A altura do novo quadro de áudio, em pontos. |

### Valor de Retorno

O [IAudioFrame](../../iaudioframe/) recém-criado.
