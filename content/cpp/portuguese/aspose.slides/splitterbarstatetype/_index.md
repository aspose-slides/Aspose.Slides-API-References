## SplitterBarStateType enum

Especifica o estado em que a barra divisor deve ser exibida. A barra divisor separa uma região primária e uma região secundária dentro de uma área de visualização.

```cpp
enum class SplitterBarStateType
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Minimized | 0 | A região primária ocupa a menor quantidade de área de visualização permitida pelo aplicativo. |
| Restored | 1 | A região primária tem um tamanho intermediário específico. |
| Maximized | 2 | A região primária ocupa a maior quantidade de área de visualização permitida pelo aplicativo. |
