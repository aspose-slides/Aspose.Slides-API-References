## ISlideSize::get_Size() método


Obtém as dimensões do slide em pontos. Atribuir um novo valor redefine o valor [ISlideSize::get_Type](../get_type/) para [SlideSizeType::Custom](../../slidesizetype/) e define [ISlideSize::get_Orientation](../get_orientation/).

```cpp
virtual System::Drawing::SizeF Aspose::Slides::ISlideSize::get_Size()=0
```

## Observações


Atribuir um novo valor redefine a propriedade [ISlideSize::get_Type](../get_type/) para [SlideSizeType::Custom](../../slidesizetype/) e define o [Orientation](../../orientation/).
