## SensitivityLabelAssignmentType enum

Representa o método de atribuição para o rótulo de sensibilidade.

```cpp
enum class SensitivityLabelAssignmentType
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Standard | 0 | Use para qualquer rótulo de sensibilidade que não tenha sido aplicado diretamente pelo usuário. Isso inclui quaisquer rótulos padrão, rótulos aplicados automaticamente. |
| Privileged | 1 | Use para qualquer rótulo de sensibilidade que tenha sido aplicado diretamente pelo usuário. Isso inclui quaisquer rótulos de sensibilidade aplicados manualmente, bem como rotulagem recomendada ou obrigatória, ou qualquer recurso em que o usuário decide qual rótulo de sensibilidade aplicar. |
