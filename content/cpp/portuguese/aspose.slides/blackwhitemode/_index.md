## BlackWhiteMode enum

Determina como a forma colorida deve ser transformada em preto e branco.

```cpp
enum class BlackWhiteMode : int8_t
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| NotDefined | -1 | A propriedade não está definida |
| Color | 0 | O objeto é renderizado com coloração normal |
| Automatic | 1 | O objeto é renderizado com coloração automática |
| Gray | 2 | O objeto é renderizado com coloração cinza |
| LightGray | 3 | O objeto é renderizado com coloração cinza clara |
| InverseGray | 4 | O objeto é renderizado com coloração cinza inversa |
| GrayWhite | 5 | O objeto é renderizado com coloração cinza e branca |
| BlackGray | 6 | O objeto é renderizado com coloração preta e cinza |
| BlackWhite | 7 | O objeto é renderizado com coloração preta e branca |
| Black | 8 | O objeto é renderizado apenas com coloração preta |
| White | 9 | O objeto é renderizado com coloração branca |
| Hidden | 10 | O objeto não é renderizado |
