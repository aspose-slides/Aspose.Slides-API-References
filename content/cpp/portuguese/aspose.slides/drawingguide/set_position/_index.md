## DrawingGuide::set_Position(float) método


Define a posição do guia de desenho em pontos a partir do canto superior esquerdo do slide. Escreva **float**.

```cpp
void Aspose::Slides::DrawingGuide::set_Position(float value) override
```

## Observações


O intervalo típico de valores vai de zero até a altura do slide para um guia horizontal e de zero até a largura do slide para um guia vertical.
