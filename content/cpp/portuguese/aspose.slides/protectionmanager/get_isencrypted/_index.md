## ProtectionManager::get_IsEncrypted() método


Obtém um valor que indica se esta instância está criptografada. Somente leitura **bool**.

```cpp
bool Aspose::Slides::ProtectionManager::get_IsEncrypted() override
```

## Observações


**true** se a apresentação foi carregada a partir de um arquivo criptografado ou o método [Encrypt(String)](../../iprotectionmanager/encrypt/) foi chamado ; caso contrário, **false**.
