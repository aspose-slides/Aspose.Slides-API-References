## ISlideShowTransition::get_SoundIsBuiltIn() método


Especifica se este som é um som incorporado ou não. Se este atributo for definido como true, o aplicativo gerador é notificado a verificar o atributo name especificado para este som em sua lista de sons incorporados e pode então exibir um nome ou interface personalizada conforme necessário. Lê **bool**.

virtual bool Aspose::Slides::ISlideShowTransition::get_SoundIsBuiltIn()=0
