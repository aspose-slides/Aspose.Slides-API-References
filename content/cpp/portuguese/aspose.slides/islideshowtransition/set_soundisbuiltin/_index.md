## ISlideShowTransition::set_SoundIsBuiltIn(bool) método


Especifica se este som é ou não um som embutido. Se este atributo for definido como true, a aplicação geradora será notificada para verificar o atributo name especificado para este som em sua lista de sons embutidos e poderá, então, exibir um nome personalizado ou interface de usuário conforme necessário. Escreve **bool**.

virtual void Aspose::Slides::ISlideShowTransition::set_SoundIsBuiltIn(bool value)=0
