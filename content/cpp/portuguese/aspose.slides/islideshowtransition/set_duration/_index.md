## ISlideShowTransition::set_Duration(int32_t) método

Define a duração do efeito de transição do slide em milissegundos. Escreva **int32_t**.

```cpp
virtual void Aspose::Slides::ISlideShowTransition::set_Duration(int32_t value)=0
```

## Observações

Corresponde ao atributo **p14:dur** do elemento **p:transition** no esquema PresentationML. Se não for definido, a duração é determinada automaticamente com base na propriedade [Speed](../) e no tipo de transição.
