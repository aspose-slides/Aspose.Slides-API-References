## ISlideShowTransition::set_SoundName(System::String) método

Especifica um nome legível por humanos para o som da transição. O [ISlideShowTransition::set_Sound](../set_sound/) deve ser atribuído para obter ou definir o nome do som. Escreve [System::String](../../../system/string/).

```cpp
virtual void Aspose::Slides::ISlideShowTransition::set_SoundName(System::String value)=0
```

## Observações

Este nome aparece na interface do usuário do PowerPoint ao configurar o som da transição manualmente.
