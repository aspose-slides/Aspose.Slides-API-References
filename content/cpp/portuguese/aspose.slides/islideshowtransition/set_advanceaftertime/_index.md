## ISlideShowTransition::set_AdvanceAfterTime(uint32_t) método

Especifica o tempo, em milissegundos, após o qual a transição deve iniciar. Esta configuração pode ser usada em conjunto com o atributo advClick. Se este atributo não for especificado, então assume-se que não ocorrerá avanço automático. Grava **uint32_t**.

virtual void Aspose::Slides::ISlideShowTransition::set_AdvanceAfterTime(uint32_t value)=0
