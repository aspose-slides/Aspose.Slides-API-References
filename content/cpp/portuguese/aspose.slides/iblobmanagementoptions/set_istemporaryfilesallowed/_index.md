## IBlobManagementOptions::set_IsTemporaryFilesAllowed(bool) método

Esta propriedade define se arquivos temporários podem ser criados ao trabalhar com BLOBs, o que diminui significativamente o consumo de memória, mas requer permissões para criar arquivos.

```cpp
virtual void Aspose::Slides::IBlobManagementOptions::set_IsTemporaryFilesAllowed(bool value)=0
```

## Observações

Todos os arquivos serão excluídos após o trabalho com a apresentação ser concluído.
