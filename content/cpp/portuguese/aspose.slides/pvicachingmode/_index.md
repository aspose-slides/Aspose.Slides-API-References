## PVICachingMode enum

Representa diferentes níveis de cache para objetos efetivos PVI.

```cpp
enum class PVICachingMode
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| NoCaching | 0 | Modo clássico com criação de cada instância. |
| NotDefinedOnly | 1 | Usa cache de valores efetivos para formatos NotDefined, modo clássico para o restante. |
| Full | 2 | Usa cache de valores efetivos para todos os formatos. |
