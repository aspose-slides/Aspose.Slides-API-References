## ImageFormat enum

Representa o formato de arquivo da imagem.

```cpp
enum class ImageFormat
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| MemoryBmp | 0 | Representa o formato de um bitmap na memória. |
| Bmp | 1 | Representa o formato de imagem bitmap (BMP). |
| Emf | 2 | Representa o formato de imagem enhanced metafile (EMF). |
| Wmf | 3 | Representa o formato de imagem Windows metafile (WMF). |
| Gif | 4 | Representa o formato de imagem Graphics Interchange Format (GIF). |
| Jpeg | 5 | Representa o formato de imagem Joint Photographic Experts Group (JPEG). |
| Png | 6 | Representa o formato de imagem W3C Portable Network Graphics (PNG). |
| Tiff | 7 | Representa o formato de imagem Tagged Image File Format (TIFF). |
| Exif | 8 | Representa o formato Exchangeable Image File (Exif). |
| Icon | 9 | Representa o formato de imagem de ícone do Windows. |
