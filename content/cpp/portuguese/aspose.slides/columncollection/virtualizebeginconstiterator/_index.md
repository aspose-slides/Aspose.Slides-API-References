## ColumnCollection::virtualizeBeginConstIterator() const método

Obtém o iterador que aponta para o primeiro elemento (se houver) da instância qualificada como const da coleção.

```cpp
virtualized_iterator * Aspose::Slides::ColumnCollection::virtualizeBeginConstIterator() const override
```


### Valor de Retorno

Um iterador que aponta para o primeiro elemento (se houver) da instância const da coleção. Fornece implementação de iterador const para o primeiro elemento do contêiner.

Objeto iterador recém-criado.
