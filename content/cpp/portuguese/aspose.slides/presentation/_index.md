## Observações

O exemplo a seguir mostra como criar um PowerPoint [Presentation](./). 
```cpp
// Instancia um objeto Presentation que representa um arquivo de apresentação
System::SharedPtr<Presentation> presentation = System::MakeObject<Presentation>();

// Obtém o primeiro slide
auto slide = presentation->get_Slides()->idx_get(0);
// Adiciona uma autoshape do tipo linha
slide->get_Shapes()->AddAutoShape(ShapeType::Line, 50.0f, 150.0f, 300.0f, 0.0f);
// Salva o arquivo de apresentação.
presentation->Save(u"NewPresentation_out.pptx", SaveFormat::Pptx);
```
 O exemplo a seguir mostra como abrir e salvar [Presentation](./). 
```cpp
// Carregue qualquer arquivo suportado no Presentation, por exemplo ppt, pptx, odp etc.
System::SharedPtr<Presentation> presentation = System::MakeObject<Presentation>(u"Sample.odp");

// Salve o arquivo de apresentação.
presentation->Save(u"OutputPresenation.pptx", SaveFormat::Pptx);
```
