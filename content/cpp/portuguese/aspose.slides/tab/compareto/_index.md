## Tab::CompareTo(System::SharedPtr\<ITab\>) método

Compara a instância atual com outro objeto do mesmo tipo.

```cpp
int32_t Aspose::Slides::Tab::CompareTo(System::SharedPtr<ITab> obj) override
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| obj | [System::SharedPtr](../../../system/sharedptr/)\<[ITab](../../itab/)\> | Um objeto para comparar com esta instância. |

### Valor de Retorno

Um inteiro de 32 bits que indica a ordem relativa dos comparandos. O valor de retorno tem os seguintes significados:
* < 0 - Esta instância é menor que obj.
* = 0 - Esta instância é igual a obj.
* > 0 - Esta instância é maior que obj.
