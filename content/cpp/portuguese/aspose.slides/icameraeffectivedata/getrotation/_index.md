## ICameraEffectiveData::GetRotation() method


A rotação é definida pelo uso de uma coordenada de latitude, uma coordenada de longitude e uma revolução ao redor do eixo conforme as coordenadas de latitude e longitude. Primeiro elemento no array retornado – latitude, segundo – longitude, terceiro – revolução. Retorna nulo se nenhuma rotação estiver definida.

```cpp
virtual System::ArrayPtr<float> Aspose::Slides::ICameraEffectiveData::GetRotation()=0
```


### Valor de Retorno

Array de valores de rotação como **float**[].
