## ResultValueTask::get_IsCanceled() const método

Obtém um valor que indica se a tarefa foi concluída devido ao cancelamento.

```cpp
bool System::Threading::Tasks::ResultValueTask<T>::get_IsCanceled() const
```

### Valor de Retorno

bool True se a tarefa foi cancelada; caso contrário, false.
## Observações

Retorna false se a tarefa contém um valor de resultado direto.
