## ResultValueTask::get_IsFaulted() const método


Obtém um valor que indica se a tarefa foi concluída devido a uma exceção não tratada.

```cpp
bool System::Threading::Tasks::ResultValueTask<T>::get_IsFaulted() const
```


### Valor de Retorno

bool True se a tarefa está com falha; caso contrário, false.

## Observações



Retorna false se a tarefa contém um valor de resultado direto.
