## IOverrideThemeManager::get_IsOverrideThemeEnabled() método

Determina se [OverrideTheme](../../overridetheme/) sobrescreve o tema efetivo herdado ou não. Para habilitar [OverrideTheme](../../overridetheme/) para sobrescrita, use os métodos OverrideTheme.Init*(). Para desabilitar [OverrideTheme](../../overridetheme/) de sobrescrever, use o método [get_OverrideTheme()](../get_overridetheme/)->Clear(). Somente leitura **bool**.

```cpp
virtual bool Aspose::Slides::Theme::IOverrideThemeManager::get_IsOverrideThemeEnabled()=0
```
