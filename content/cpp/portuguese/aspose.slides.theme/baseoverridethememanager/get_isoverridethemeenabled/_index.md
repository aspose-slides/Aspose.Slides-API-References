## BaseOverrideThemeManager::get_IsOverrideThemeEnabled() método

Determina se [OverrideTheme](../../overridetheme/) substitui o tema efetivo herdado ou não. Para habilitar [OverrideTheme](../../overridetheme/) para substituição, use os métodos OverrideTheme.Init*(). Para desabilitar [OverrideTheme](../../overridetheme/) de substituir, use o método [OverrideTheme::Clear](../../overridetheme/clear/). Somente leitura **bool**.
