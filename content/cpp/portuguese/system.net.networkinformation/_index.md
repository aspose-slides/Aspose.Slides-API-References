## Classes

| Class | Description |
| --- | --- |
| [HostInformation](./hostinformation/) | Representa informações sobre um host. Objetos desta classe devem ser alocados apenas usando a função [System::MakeObject()](../system/makeobject/). Nunca crie uma instância deste tipo na pilha ou usando o operador new, pois isso resultará em erros de tempo de execução e/ou falhas de asserção. Sempre encapsule esta classe em um ponteiro [System::SmartPtr](../system/smartptr/) e use esse ponteiro para passá-la às funções como argumento. |
| [IPGlobalProperties](./ipglobalproperties/) | Representa informações sobre a conexão de rede do computador local.
