## HMACSHA512 classe


Código de Mensagem baseada em hash [Authentication](../../system.security.authentication/) que usa a função hash [SHA512](../sha512/). Parcialmente implementado. Objetos desta classe devem ser alocados apenas usando a função [System::MakeObject()](../../system/makeobject/). Nunca crie instância deste tipo na pilha ou usando o operador new, pois isso resultará em erros de tempo de execução e/ou falhas de asserção. Sempre envolva esta classe em um ponteiro [System::SmartPtr](../../system/smartptr/) e use esse ponteiro para passá-lo a funções como argumento.

```cpp
class HMACSHA512 : public System::Security::Cryptography::HashAlgorithm
```
