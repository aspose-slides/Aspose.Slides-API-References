## AsymmetricAlgorithm classe

Classe base abstrata para algoritmos de criptografia assimétrica. Objetos desta classe devem ser alocados apenas usando a função [System::MakeObject()](../../system/makeobject/). Nunca crie instância deste tipo na pilha ou usando o operador new, pois isso resultará em erros de tempo de execução e/ou falhas de asserção. Sempre envolva esta classe em um ponteiro [System::SmartPtr](../../system/smartptr/) e use esse ponteiro para passá-lo às funções como argumento.

```cpp
class AsymmetricAlgorithm : public virtual System::Object,
                            public System::IDisposable
```
