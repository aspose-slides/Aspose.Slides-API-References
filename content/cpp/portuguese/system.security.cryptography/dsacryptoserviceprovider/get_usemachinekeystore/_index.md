## DSACryptoServiceProvider::get_UseMachineKeyStore() método

Verifica se a chave persiste no armazenamento da máquina em vez do armazenamento do usuário.

```cpp
static bool System::Security::Cryptography::DSACryptoServiceProvider::get_UseMachineKeyStore()
```

### Valor de Retorno

True se a chave deve ser persistida no armazenamento da máquina, false se deve ser persistida no armazenamento do usuário.
