## RSAParameters struct

[Data](../../system.data/) estrutura dos parâmetros do algoritmo [RSA](../rsa/). Este tipo deve ser alocado na pilha e passado para funções por valor ou por referência. Nunca use a classe [System::SmartPtr](../../system/smartptr/) para gerenciar objetos deste tipo.

```cpp
class RSAParameters : public System::Object
```
