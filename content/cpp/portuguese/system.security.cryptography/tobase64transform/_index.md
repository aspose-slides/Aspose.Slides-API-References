## ToBase64Transform classe

Converte a instância da classe [CryptoStream](../cryptostream/) para base 64. Objetos desta classe devem ser alocados apenas usando a função [System::MakeObject()](../../system/makeobject/). Nunca crie instâncias desse tipo na pilha ou usando o operador new, pois isso resultará em erros de tempo de execução e/ou falhas de asserção. Sempre envolva esta classe em um ponteiro [System::SmartPtr](../../system/smartptr/) e use esse ponteiro para passá-lo a funções como argumento.

```cpp
class ToBase64Transform : public System::Security::Cryptography::ICryptoTransform
```
