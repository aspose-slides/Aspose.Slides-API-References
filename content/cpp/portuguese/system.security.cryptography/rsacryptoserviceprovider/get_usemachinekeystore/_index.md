## RSACryptoServiceProvider::get_UseMachineKeyStore() método


Verifica se a chave persiste no repositório da máquina em vez do repositório do usuário.

```cpp
static bool System::Security::Cryptography::RSACryptoServiceProvider::get_UseMachineKeyStore()
```


### Valor de Retorno

True se a chave deve ser persistida no repositório da máquina, false se deve ser persistida no repositório do usuário.
