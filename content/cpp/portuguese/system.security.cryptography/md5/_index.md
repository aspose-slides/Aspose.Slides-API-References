## MD5 classe

[MD5](./) algoritmo de hash. Objetos desta classe só devem ser alocados usando a função [System::MakeObject()](../../system/makeobject/). Nunca crie uma instância deste tipo na pilha ou usando o operador new, pois isso resultará em erros de tempo de execução e/ou falhas de asserção. Sempre encapsule esta classe em um ponteiro [System::SmartPtr](../../system/smartptr/) e use esse ponteiro para passá-lo a funções como argumento.

```cpp
class MD5 : public System::Security::Cryptography::HashAlgorithm
```
