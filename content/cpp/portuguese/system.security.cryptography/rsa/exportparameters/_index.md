## RSA::ExportParameters(bool) método


Exporta todos os parâmetros.

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| include_private_parameters | **bool** | true para exportar parâmetros privados e públicos, false para exportar apenas parâmetros públicos. |

### Valor de Retorno

Estrutura de parâmetros exportados.
