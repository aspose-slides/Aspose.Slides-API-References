## classe Rfc2898DeriveBytes

Implementa derivação de chave baseada em senha, PBKDF2. Objetos desta classe devem ser alocados apenas usando a função [System::MakeObject()](../../system/makeobject/). Nunca crie instâncias deste tipo na pilha ou usando o operador new, pois isso resultará em erros de tempo de execução e/ou falhas de asserção. Sempre envolva esta classe em um ponteiro [System::SmartPtr](../../system/smartptr/) e use esse ponteiro para passá-lo a funções como argumento.

```cpp
class Rfc2898DeriveBytes : public System::Security::Cryptography::DeriveBytes
```
