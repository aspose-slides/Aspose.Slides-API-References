## MD5CryptoServiceProvider classe


Algoritmo [MD5](../md5/) compatível com CSP. Não implementado. Objetos desta classe devem ser alocados apenas usando a função [System::MakeObject()](../../system/makeobject/). Nunca crie instância deste tipo na pilha ou usando o operador new, pois isso resultará em erros de tempo de execução e/ou falhas de asserção. Sempre encapsule esta classe em um ponteiro [System::SmartPtr](../../system/smartptr/) e use esse ponteiro para passá-lo a funções como argumento.

```cpp
class MD5CryptoServiceProvider : public System::Security::Cryptography::MD5
```
