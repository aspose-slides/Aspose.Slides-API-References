## IsList typedef

Verifica se o tipo é uma especialização de [System::Collections::Generic::List](../../system.collections.generic/list/). Se for, o membro value é definido como true, caso contrário é definido como false.

```cpp
using System::TestPredicates::TypeTraits::IsList = typedef std::is_same<T, System::Collections::Generic::List<typename T::ValueType> >
```
