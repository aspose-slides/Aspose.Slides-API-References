## Enumerable::Range(int32_t, int32_t) método

Gera uma sequência de números integrais dentro de um intervalo especificado.

```cpp
static SharedPtr<Collections::Generic::IEnumerable<int32_t>> System::Linq::Enumerable::Range(int32_t start, int32_t count)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| start | **int32_t** | O valor do primeiro inteiro na sequência. |
| count | **int32_t** | O número de inteiros sequenciais a gerar. |

### Valor de Retorno

Um IEnumerable de **int32_t** que contém um intervalo de números integrais sequenciais.
