## Classes

| Classe | Descrição |
| --- | --- |
| [Evidence](./evidence/) | Classe stub para código traduzido que usa a classe [Evidence](./evidence/) para compilar. Objetos desta classe devem ser alocados apenas usando a função [System::MakeObject()](../system/makeobject/). Nunca crie uma instância deste tipo na pilha ou usando o operador new, pois isso resultará em erros de tempo de execução e/ou falhas de asserção. Sempre envolva esta classe em um ponteiro [System::SmartPtr](../system/smartptr/) e use esse ponteiro para passá-lo às funções como argumento. |
