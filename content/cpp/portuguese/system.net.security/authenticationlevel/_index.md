## AuthenticationLevel enum

Sinais de autenticação específicos do WebRequest.

```cpp
enum class AuthenticationLevel
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| None | 0 | Nenhuma autenticação é necessária para o cliente e o servidor. |
| MutualAuthRequested | 1 | A solicitação não falha se o servidor não estiver autenticado. |
| MutualAuthRequired | 2 | A aplicação atual receberá 'IOException' quando o servidor não estiver autenticado. |
