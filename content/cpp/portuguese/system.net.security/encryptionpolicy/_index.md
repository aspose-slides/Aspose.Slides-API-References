## EncryptionPolicy enum


Enumera as políticas de criptografia.

```cpp
enum class EncryptionPolicy
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| RequireEncryption | 0 | Exigir criptografia e nunca permitir um cifrador 'Null'. |
| AllowNoEncryption | 1 | Preferir usar criptografia total, mas um cifrador 'Null' pode ser usado se o servidor concordar. |
| NoEncryption | 2 | Permitir nenhuma criptografia e solicitar que um cifrador 'Null' seja usado se o outro ponto final puder lidar com um cifrador 'Null'. |
