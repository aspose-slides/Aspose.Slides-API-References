## Observações

Usar este resolvedor pode criar uma vulnerabilidade quando um arquivo HTML ou SVG fornecido pelo cliente fizer o software do servidor obter um arquivo local ou de rede. Use com cautela. Recomenda-se não especificar [ExternalResourceResolver](./) de forma alguma (apenas objetos incorporados serão lidos) ou criar alguma subclasse que verifique se o uri especificado é válido.
