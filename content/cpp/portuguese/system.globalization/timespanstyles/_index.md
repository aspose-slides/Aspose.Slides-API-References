## TimeSpanStyles enum


Especifica as opções de formatação que personalizam a análise de strings para métodos que convertem uma representação de string de um intervalo de tempo em um objeto Timespan.

```cpp
enum class TimeSpanStyles : int32_t
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| None | 0 | O intervalo de tempo representado pela string inptut é interpretado como um intervalo de tempo negativo somente se um sinal negativo estiver presente. |
| AssumeNegative | 1 | O intervalo de tempo representado pela string inptut é interpretado como um intervalo de tempo negativo sempre. |
