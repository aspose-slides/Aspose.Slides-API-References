## NumberFormatInfo::get_PercentGroupSizes() const método


Obtém o número de dígitos por grupo de valor percentual.

```cpp
ArrayPtr<int> System::Globalization::NumberFormatInfo::get_PercentGroupSizes() const
```


### Valor de retorno

[Array](../../../system/array/) de dígitos por grupo, da esquerda para a direita; cada elemento deve ser de 1 a 9, o último pode ser 0 que significa \"combinar tudo\"; o último elemento se repete.
