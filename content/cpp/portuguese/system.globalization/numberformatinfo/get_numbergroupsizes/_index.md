## NumberFormatInfo::get_NumberGroupSizes() const método


Obtém o número de dígitos por grupo.

```cpp
ArrayPtr<int> System::Globalization::NumberFormatInfo::get_NumberGroupSizes() const
```


### Valor de Retorno

[Array](../../../system/array/) de dígitos por grupo, da esquerda para a direita; cada elemento deve ser de 1 a 9, o último pode ser 0 que significa \"combinar tudo\"; o último elemento se repete.
