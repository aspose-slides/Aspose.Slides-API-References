## NumberFormatInfo::ReadOnly(NumberFormatInfoPtr) método

Obtém a versão somente leitura do formatador.

```cpp
static NumberFormatInfoPtr System::Globalization::NumberFormatInfo::ReadOnly(NumberFormatInfoPtr nfi)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| nfi | [NumberFormatInfoPtr](../../numberformatinfoptr/) | Formatador para obter a versão somente leitura. |

### Valor de Retorno

Se **nfi** for somente leitura, retorna-o; caso contrário, cria uma cópia dele e a marca como somente leitura.
