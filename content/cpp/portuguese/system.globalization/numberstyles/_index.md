## NumberStyles enum

Estilo de número permitido ao analisar.

```cpp
enum class NumberStyles : int32_t
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| None | 0 | Nenhum símbolo não numérico. |
| AllowLeadingWhite | 1 | Permite espaços em branco iniciais. |
| AllowTrailingWhite | 2 | Permite espaços em branco finais. |
| AllowLeadingSign | 4 | Permite sinal inicial. |
| Integer | n/a | Formatação padrão de inteiro. |
| AllowTrailingSign | 8 | Permite sinal final. |
| AllowParentheses | 16 | Permite parênteses para valores negativos. |
| AllowDecimalPoint | 32 | Permite ponto decimal. |
| AllowThousands | 64 | Permite separadores de milhar. |
| Number | n/a | Formato padrão de número composto. |
| AllowExponent | 128 | Permite sinal de expoente. |
| Float | n/a | Formato padrão de número de ponto flutuante. |
| AllowCurrencySymbol | 256 | Permite símbolo de moeda. |
| Currency | n/a | Formato padrão de moeda. |
| Any | n/a | Permite qualquer especificador de formato. |
| AllowHexSpecifier | 512 | Permite números hexadecimais. |
| HexNumber | n/a | Formato padrão de número hexadecimal. |
