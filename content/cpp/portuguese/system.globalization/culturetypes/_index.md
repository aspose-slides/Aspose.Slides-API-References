## CultureTypes enum

Entradas de máscara de bits de categorias de cultura.

```cpp
enum class CultureTypes : int32_t
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| NeutralCultures | 1 | Cultura que é específica para idioma, mas não para país ou região. |
| SpecificCultures | 2 | Específica para país/região. |
| InstalledWin32Cultures | 4 | Culturas instaladas no SO. |
| AllCultures | n/a | Todas as culturas disponíveis. |
| UserCustomCulture | 8 | Culturas definidas pelo usuário. |
| ReplacementCultures | 16 | Substituições definidas pelo usuário para culturas existentes. |
| WindowsOnlyCultures | 32 | Obsoleto. |
| FrameworkCultures | 64 | Obsoleto. |
