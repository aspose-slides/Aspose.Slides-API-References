## CultureInfo::ReadOnly(const CultureInfoPtr\&) método

Obtém uma versão somente leitura da cultura.

```cpp
static CultureInfoPtr System::Globalization::CultureInfo::ReadOnly(const CultureInfoPtr &culture_info)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| culture_info | const [CultureInfoPtr](../../cultureinfoptr/)\& | Cultura a ser encapsulada como somente leitura. |

### Valor de Retorno

Se **culture_info** for somente leitura, retorna o mesmo objeto, caso contrário, cria uma cópia somente leitura.
