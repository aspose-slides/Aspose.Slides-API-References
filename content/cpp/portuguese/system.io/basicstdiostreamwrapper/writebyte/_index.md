## BasicSTDIOStreamWrapper::WriteByte(uint8_t) método


Se o modo de encapsulamento for binário, grava no fluxo o valor inteiro sem sinal de 8 bits especificado; caso contrário, converte-o para o tipo char_type e então grava o resultado no fluxo.

```cpp
virtual void System::IO::BasicSTDIOStreamWrapper<T, typename>::WriteByte(uint8_t value) override
```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| value | **uint8_t** | O valor a ser gravado |
