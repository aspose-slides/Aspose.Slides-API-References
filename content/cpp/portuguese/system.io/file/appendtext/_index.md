## File::AppendText(const String\&) método


Cria um objeto [StreamWriter](../../streamwriter/) que adiciona texto ao arquivo especificado usando codificação UTF-8. Se o arquivo especificado não existir, ele será criado.

```cpp
static StreamWriterPtr System::IO::File::AppendText(const String &path)
```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| path | const [String](../../../system/string/)\& | O caminho do arquivo a ser aberto ou criado |

### Valor de Retorno

Um ponteiro compartilhado para o objeto [StreamWriter](../../streamwriter/) criado associado ao arquivo especificado
