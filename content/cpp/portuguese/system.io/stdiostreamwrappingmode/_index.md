## STDIOStreamWrappingMode enum

Especifica o modo de operações de E/S que os wrappers executarão em fluxos semelhantes a std::iostream.

```cpp
enum class STDIOStreamWrappingMode
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Binary | 0 | Um modo que permite que operações de entrada decodifiquem dados de fluxo do tipo char_type em bytes e que operações de saída codifiquem bytes em dados do tipo char_type. |
| Conversion | 1 | Um modo que permite que operações de entrada convertam dados de fluxo do tipo char_type para o tipo **uint8_t** e vice-versa para operações de saída. |
