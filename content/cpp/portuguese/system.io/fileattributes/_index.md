## FileAttributes enum

Representa atributos de um diretório ou de um arquivo.

```cpp
enum class FileAttributes
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Archive | 32 | A entidade do sistema de arquivos é uma candidata para remoção ou backup. |
| Compressed | 2048 | A entidade do sistema de arquivos está compactada. |
| Device | 64 | Não usado. |
| Directory | 16 | A entidade do sistema de arquivos é um diretório. |
| Encrypted | 16384 | A entidade do sistema de arquivos está criptografada. |
| Hidden | 2 | A entidade do sistema de arquivos está oculta. |
| IntegrityStream | 32768 | A entidade do sistema de arquivos contém suporte à integridade de dados. |
| Normal | 128 | A entidade do sistema de arquivos é um arquivo que não possui atributos especiais. |
| NotContentIndexed | 8192 | A entidade do sistema de arquivos não será indexada pelo serviço de indexação de conteúdo. |
| NoScrubData | 131072 | A entidade do sistema de arquivos não está incluída na varredura de integridade de dados. |
| Offline | 4096 | A entidade do sistema de arquivos está offline e seus dados não estão imediatamente disponíveis. |
| ReadOnly | 1 | A entidade do sistema de arquivos é somente leitura. |
| ReparsePoint | 1024 | A entidade do sistema de arquivos é um arquivo que contém um ponto de reparse. |
| SparseFile | 512 | A entidade do sistema de arquivos é um arquivo esparso. |
| System | 4 | A entidade do sistema de arquivos é um arquivo de sistema. |
| Temporary | 256 | A entidade do sistema de arquivos é um arquivo temporário. |
| Invalid | 0 | Valor inválido. |
