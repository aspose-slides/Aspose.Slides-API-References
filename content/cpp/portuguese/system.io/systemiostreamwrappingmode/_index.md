## SystemIOStreamWrappingMode enum

Especifica o modo das operações de I/O que os wrappers executarão em fluxos semelhantes a [System::IO::Stream](../stream/).

```cpp
enum class SystemIOStreamWrappingMode
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Binary | 0 | Um modo que permite que as operações de entrada codifiquem os bytes do fluxo em dados char_type e decodifiquem os dados char_type em bytes do fluxo para operações de saída. |
| Conversion | 1 | Um modo que permite que as operações de entrada convertam os bytes do fluxo do tipo **uint8_t** para o tipo char_type e vice-versa para operações de saída. |
