## DirectoryInfo::Delete() método

Remove o diretório referenciado pelo caminho representado pelo objeto atual se o diretório estiver vazio.

```cpp
virtual void System::IO::DirectoryInfo::Delete() override
```

## DirectoryInfo::Delete(bool) método

Remove o diretório referenciado pelo caminho representado pelo objeto atual. Um parâmetro especifica se o conteúdo do diretório deve ser removido de forma recursiva caso o diretório não esteja vazio.

```cpp
void System::IO::DirectoryInfo::Delete(bool recursive)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| recursive | **bool** | Especifica se o conteúdo do diretório deve ser removido recursivamente caso ele não esteja vazio |
