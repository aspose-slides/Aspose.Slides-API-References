## BinaryReader::PeekChar() método

Lê um único caractere do fluxo de entrada sem alterar o cursor de leitura do fluxo.

```cpp
virtual int System::IO::BinaryReader::PeekChar()
```

### Valor de Retorno

Caractere lido codificado em UTF-16; se o caractere lido for representado por dois pontos de código em codificação UTF-16, então apenas o surrogate alto é retornado; se nenhum caractere for lido, -1 é retornado
