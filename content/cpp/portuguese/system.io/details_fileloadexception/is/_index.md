## Details_FileLoadException::Is(const System::TypeInfo\&) const method

```cpp
bool System::IO::Details_FileLoadException::Is(const System::TypeInfo &target) const override
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| target | const [System::TypeInfo](../../../system/typeinfo/)\& | [TypeInfo](../../../system/typeinfo/) estrutura que descreve o tipo a ser testado no objeto atual. |

### Valor de Retorno

True se o objeto for do tipo marcado ou de sua subclasse, false caso contrário.

## Observações

Verifique se o objeto representa uma instância do tipo descrito por targetType. Analógico ao operador 'is' do C#.
