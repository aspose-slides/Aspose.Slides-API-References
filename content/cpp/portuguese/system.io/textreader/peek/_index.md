## TextReader::Peek() método

Lê um único caractere do fluxo sem alterar o cursor de leitura do fluxo.

```cpp
virtual int System::IO::TextReader::Peek()
```

### Valor de Retorno

Caractere lido codificado em UTF-16; se o caractere lido for representado por dois pontos de código na codificação UTF-16, somente o surrogado alto é retornado; se nenhum caractere for lido, -1 é retornado
