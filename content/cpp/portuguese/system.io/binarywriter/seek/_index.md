## BinaryWriter::Seek(int, System::IO::SeekOrigin) método


Define a posição do fluxo representado pelo objeto atual.

```cpp
int64_t System::IO::BinaryWriter::Seek(int offset, System::IO::SeekOrigin origin=System::IO::SeekOrigin::Begin)
```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| offset | int | O deslocamento em bytes relativo a uma posição especificada por **origin** |
| origin | [System::IO::SeekOrigin](../../seekorigin/) | Especifica a posição a partir da qual e a direção para a qual o deslocamento é calculado |

### Valor de Retorno

A nova posição do fluxo
