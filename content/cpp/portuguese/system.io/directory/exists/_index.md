## Directory::Exists(const String\&) método

Determina se o caminho especificado refere-se a um diretório existente.

```cpp
static bool System::IO::Directory::Exists(const String &path)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| path | const [String](../../../system/string/)\& | O caminho a ser verificado |

### Valor de Retorno

True se o caminho especificado referir-se a um diretório existente, caso contrário - false
