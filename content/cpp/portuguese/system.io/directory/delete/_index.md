## Directory::Delete(const String\&, bool) método

Remove o arquivo ou diretório especificado. Não lança exceção.

```cpp
static void System::IO::Directory::Delete(const String &path, bool recursive=false)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| path | const [String](../../../system/string/)\& | O path para o diretório ou arquivo a ser removido |
| recursive | **bool** | Se **path** especifica um diretório não vazio, então **recursive** indica se todo o conteúdo do diretório deve ser removido recursivamente; se o diretório especificado por **path** não estiver vazio e **recursive** for 'false', a operação falha |
