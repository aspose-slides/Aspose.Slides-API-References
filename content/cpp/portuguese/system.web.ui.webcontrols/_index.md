## Classes

| Classe | Descrição |
| --- | --- |
| [DataGrid](./datagrid/) | Classe fictícia que torna possível vincular o código traduzido com referências [DataGrid](./datagrid/), mas não o executa. Não contém membros implementados corretamente. Objetos desta classe devem ser alocados apenas usando a função [System::MakeObject()](../system/makeobject/). Nunca crie instância deste tipo na pilha ou usando o operador new, pois isso resultará em erros de tempo de execução e/ou falhas de asserção. Sempre envolva esta classe em um ponteiro [System::SmartPtr](../system/smartptr/) e use esse ponteiro para passá-lo a funções como argumento. |
