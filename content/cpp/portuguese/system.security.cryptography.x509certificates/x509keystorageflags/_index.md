## X509KeyStorageFlags enum

Define como armazenar a chave.

```cpp
enum class X509KeyStorageFlags : int32_t
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| DefaultKeySet | 0 | Usa o conjunto de chaves padrão. |
| UserKeySet | 1 | Usa o armazenamento associado ao usuário em vez do local da máquina. |
| MachineKeySet | 2 | Usa o armazenamento local da máquina em vez do do usuário. |
| Exportable | 4 | Marca chaves importadas como exportáveis. |
| UserProtected | 8 | Notifica o usuário que a chave está sendo usada. |
| PersistKeySet | 16 | A chave é persistida ao importar o certificado. |
