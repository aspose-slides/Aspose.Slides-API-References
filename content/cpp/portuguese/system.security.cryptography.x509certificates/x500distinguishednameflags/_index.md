## X500DistinguishedNameFlags enum

Regras de formatação de nomes distintos de certificado X509.

```cpp
enum class X500DistinguishedNameFlags
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| None | 0 | Nenhuma característica especial. |
| Reversed | 1 | O nome está reservado. |
| UseSemicolons | 16 | Usa ponto e vírgula. |
| DoNotUsePlusSign | 32 | O nome não usa o sinal de mais. |
| DoNotUseQuotes | 64 | Desabilita aspas no nome. |
| UseCommas | 128 | Habilita o uso de vírgulas. |
| UseNewLines | 256 | Habilita o uso de quebras de linha. |
| UseUTF8Encoding | 4096 | Altera de usar Unicode para usar codificação UTF-8. |
| UseT61Encoding | 8192 | Altera para codificação T61. |
| ForceUTF8Encoding | 16384 | Força o uso de UTF-8 ao codificar chaves X500 específicas. |
