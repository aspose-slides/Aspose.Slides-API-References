## TransportType enum

Define o tipo de transporte permitido para o soquete.

```cpp
enum class TransportType
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Udp | 1 | O tipo de transporte UDP. |
| Connectionless | n/a | O tipo de transporte é sem conexão. |
| Tcp | 2 | O tipo de transporte TCP. |
| ConnectionOriented | n/a | O transporte é orientado por conexão. |
| All | 3 | Todos os tipos de transporte. |
