## FileWebResponse classe


Fornece implementação da classe abstrata [WebResponse](../webresponse/) para trabalhar com o sistema de arquivos. Objetos desta classe devem ser alocados apenas usando a função [System::MakeObject()](../../system/makeobject/). Nunca crie uma instância deste tipo na pilha ou usando o operador new, pois isso resultará em erros de tempo de execução e/ou falhas de asserção. Sempre encapsule esta classe em um ponteiro [System::SmartPtr](../../system/smartptr/) e use esse ponteiro para passá-lo a funções como argumento.

```cpp
class FileWebResponse : public System::Net::WebResponse
```
