## CookieCollection::get_IsOtherVersionSeen() método

Retorna um valor que indica se a coleção contém um cookie com uma versão que não é igual a [Cookie::MaxSupportedVersion](../../cookie/maxsupportedversion/).

```cpp
bool System::Net::CookieCollection::get_IsOtherVersionSeen()
```

### Valor de retorno

True quando a coleção contém um cookie com uma versão que não é igual a [Cookie::MaxSupportedVersion](../../cookie/maxsupportedversion/), caso contrário false.
