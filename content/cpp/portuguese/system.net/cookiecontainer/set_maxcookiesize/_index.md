## CookieContainer::set_MaxCookieSize(int32_t) método

Define o tamanho máximo do cookie.


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| value | **int32_t** | O valor que deve ser definido. |

## Observações

Um novo cookie será truncado quando seu tamanho exceder o tamanho máximo do cookie.
