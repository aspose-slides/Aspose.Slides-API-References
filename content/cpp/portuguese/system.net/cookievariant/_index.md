## enum CookieVariant

Enumera as especificações de cookies.

```cpp
enum class CookieVariant
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Unknown | 0 | A especificação de cookie desconhecida. |
| Plain | 1 | A especificação de cookie simples. |
| Rfc2109 | 2 | A especificação de cookie 'RFC 2109'. |
| Rfc2965 | 3 | A especificação de cookie 'RFC 2965'. |
| Default | 2 | O valor padrão igual a 'Rfc2109'. |
