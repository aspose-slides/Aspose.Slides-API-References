## ISVGOptions::set_DeletePicturesCroppedAreas(bool) método

Um sinalizador booleano indica se as partes recortadas permanecem como parte do documento. Se verdadeiro, as partes recortadas serão removidas, se falso elas serão serializadas no documento (o que pode levar a um arquivo maior). Escreva **bool**.
