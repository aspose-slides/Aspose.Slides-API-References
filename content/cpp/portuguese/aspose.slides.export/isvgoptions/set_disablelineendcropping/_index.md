## ISSVGOptions::set_DisableLineEndCropping(bool) método

O SVG 1.1 não possui capacidade de definir recuos para marcadores. [Aspose.Slides](../../../aspose.slides/) O motor de escrita SVG tem uma solução alternativa para esse problema: ele recorta a extremidade da linha com a seta, de modo que a linha não sobreponha os marcadores. Esta opção desativa esse comportamento. Escreva **bool**.

```cpp
virtual void Aspose::Slides::Export::ISVGOptions::set_DisableLineEndCropping(bool value)=0
```
