## ISVGOptions::get_DisableLineEndCropping() método

SVG 1.1 não possui capacidade de definir recuos para marcadores. [Aspose.Slides](../../../aspose.slides/) O mecanismo de escrita SVG tem uma solução alternativa para esse problema: ele corta a extremidade da linha com a seta, portanto, a linha não sobrepõe os marcadores. Essa opção desliga esse comportamento. Leia **bool**.

```cpp
virtual bool Aspose::Slides::Export::ISVGOptions::get_DisableLineEndCropping()=0
```
