## SvgEvent enum


Representa opções para forma SVG.

```cpp
enum class SvgEvent
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| OnFocusIn | 0 | Ocorre quando um elemento recebe foco, como quando um texto é selecionado. |
| OnFocusOut | 1 | Ocorre quando um elemento perde o foco, como quando um texto deixa de ser selecionado. |
| OnActivate | 2 | Ocorre quando um elemento é ativado, por exemplo, por meio de um clique do mouse ou de uma pressão de tecla. |
| OnClick | 3 | Ocorre quando o botão do dispositivo apontador é clicado sobre um elemento. |
| OnMouseDown | 4 | Ocorre quando o botão do dispositivo apontador é pressionado sobre um elemento. |
| OnMouseUp | 5 | Ocorre quando o botão do dispositivo apontador é liberado sobre um elemento. |
| OnMouseOver | 6 | Ocorre quando o dispositivo apontador é movido para um elemento. |
| OnMouseMove | 7 | Ocorre quando o dispositivo apontador é movido enquanto está sobre um elemento. |
| OnMouseOut | 8 | Ocorre quando o dispositivo apontador se afasta de um elemento. |
| OnLoad | 9 | Ocorre quando o agente de usuário analisou totalmente o elemento e seus descendentes e todos os recursos referenciados necessários para renderizá-lo. |
| OnUnload | 10 | Ocorre quando a implementação [DOM](../../aspose.slides.dom/) remove um documento de uma janela ou frame. Aplicável apenas a elementos svg externos. |
| OnAbort | 11 | Ocorre quando o carregamento da página é interrompido antes que um elemento tenha sido carregado completamente. |
| OnError | 12 | Ocorre quando um elemento não carrega corretamente ou quando ocorre um erro durante a execução do script. |
| OnResize | 13 | Ocorre quando a visualização do documento está sendo redimensionada. Aplicável apenas a elementos svg externos. |
| OnScroll | 14 | Ocorre quando a visualização do documento está sendo deslocada ao longo do eixo X ou Y ou de ambos. Aplicável apenas a elementos svg externos. |
| OnZoom | 15 | Ocorre quando o nível de zoom da visualização do documento está sendo alterado. Aplicável apenas a elementos svg externos. |
| OnBegin | 16 | Ocorre quando um elemento de animação começa. |
| OnEnd | 17 | Ocorre quando um elemento de animação termina. |
| OnRepeat | 18 | Ocorre quando um elemento de animação repete. |
