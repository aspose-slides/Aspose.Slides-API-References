## MarkdownSaveOptions::set_SlideNumberFormat(System::String) método

Define a string de formato usada para os cabeçalhos de número de slide na saída Markdown. O formato deve incluir o placeholder "{0}", que será substituído pelo índice do slide durante a exportação. Exemplo: "# Slide {0}" produzirá "# Slide 1", "# Slide 2", etc.
