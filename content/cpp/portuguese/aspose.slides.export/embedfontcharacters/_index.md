## EmbedFontCharacters enum

Representa a regra a ser usada para adicionar nova fonte incorporada em [IPresentation](../../aspose.slides/ipresentation/)

```cpp
enum class EmbedFontCharacters
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| OnlyUsed | 0 | Incorpora apenas os caracteres usados na apresentação (melhor para reduzir o tamanho do arquivo). |
| All | 1 | Incorpora todos os caracteres (melhor para edição por outras pessoas). |
