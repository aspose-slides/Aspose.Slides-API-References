## SVGOptions::set_DisableLineEndCropping(bool) método

O SVG 1.1 não possui capacidade de definir recuos para marcadores. [Aspose.Slides](../../../aspose.slides/) O mecanismo de escrita SVG tem uma solução alternativa para esse problema: ele corta o final da linha com a seta, de modo que a linha não sobreponha os marcadores. Esta opção desativa esse comportamento. Escreva **bool**.

void Aspose::Slides::Export::SVGOptions::set_DisableLineEndCropping(bool value) override
