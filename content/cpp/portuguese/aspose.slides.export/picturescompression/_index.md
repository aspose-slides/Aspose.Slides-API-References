## PicturesCompression enum


Representa o nível de compressão de imagens

```cpp
enum class PicturesCompression
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Dpi330 | 0 | Boa qualidade para telas de alta definição (HD) |
| Dpi220 | 1 | Qualidade excelente na maioria das impressoras e telas |
| Dpi150 | 2 | Boa para páginas da web e projetores |
| Dpi96 | 3 | Minimiza o tamanho do documento para compartilhamento |
| Dpi72 | 4 | Nível de compressão padrão |
| DocumentResolution | 5 | Usa a resolução do documento - a imagem não será comprimida e será usada no documento como está |
