## IPdfOptions::set_EmbedTrueTypeFontsForASCII(bool) método


True para incorporar fontes TrueType para caracteres ASCII de 32-127. [Fonts](../../../aspose.slides/fonts/) para códigos de caracteres superiores a 127 são sempre incorporados. Escreva **bool**.

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_EmbedTrueTypeFontsForASCII(bool value)=0
```

## Observações


O padrão é **true**.
