## IPdfOptions::set_RasterizeUnsupportedFontStyles(bool) método

Indica se o texto deve ser rasterizado como bitmap e salvo em PDF quando a fonte não oferece suporte a estilo negrito. Essa abordagem pode melhorar a qualidade do texto no PDF resultante para determinadas fontes. Escreva **bool**.

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_RasterizeUnsupportedFontStyles(bool value)=0
```

## Observações

O padrão é **false**.
