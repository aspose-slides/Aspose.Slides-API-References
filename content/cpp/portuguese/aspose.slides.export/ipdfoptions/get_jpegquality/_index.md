## IPdfOptions::get_JpegQuality() método

Retorna um valor que determina a qualidade das imagens JPEG dentro do documento PDF. Ler **uint8_t**.

```cpp
virtual uint8_t Aspose::Slides::Export::IPdfOptions::get_JpegQuality()=0
```

## Observações

Tem efeito somente quando um documento contém imagens JPEG.

Use esta propriedade para obter ou definir a qualidade das imagens dentro de um documento ao salvá-lo no formato PDF. O valor pode variar de 0 a 100, onde 0 significa pior qualidade, porém compressão máxima, e 100 significa melhor qualidade, porém compressão mínima.

O valor padrão é **100**.
