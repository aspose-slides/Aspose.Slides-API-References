## IPdfOptions::get_RasterizeUnsupportedFontStyles() método


Indica se o texto deve ser rasterizado como bitmap e salvo em PDF quando a fonte não suporta estilo em negrito. Esta abordagem pode melhorar a qualidade do texto no PDF resultante para certas fontes. Lê **bool**.

```cpp
virtual bool Aspose::Slides::Export::IPdfOptions::get_RasterizeUnsupportedFontStyles()=0
```

## Observações


O padrão é **false**.
