## IPdfOptions::set_BestImagesCompressionRatio(bool) método


Indica se a compressão mais eficaz (em vez da padrão) para cada imagem deve ser selecionada automaticamente. Se definido como **bool**.true, para cada imagem na apresentação o algoritmo de compressão mais apropriado será escolhido, o que levará a um tamanho menor do documento PDF resultante.

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_BestImagesCompressionRatio(bool value)=0
```

## Observações


A seleção da melhor proporção de compressão de imagem é computacionalmente cara e consome uma quantidade adicional de RAM, e esta opção está **bool**.false por padrão.

O padrão é **bool**.false.
