## SvgExternalFontsHandling enum


Representa uma forma de lidar com fontes externas usadas para desenho de texto.

```cpp
enum class SvgExternalFontsHandling
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| AddLinksToFontFiles | 0 | Adiciona links a arquivos de fonte separados na seção de estilo do arquivo SVG. |
| Embed | 1 | Salva os dados das fontes diretamente no arquivo SVG. Por favor, verifique todos os acordos de licença das fontes externas antes de usar esta opção. |
| Vectorize | 2 | Salva todo o texto que usa fontes externas como gráficos. |
