## IHtmlOptions::set_DeletePicturesCroppedAreas(bool) método

Um sinalizador booleano indica se as partes recortadas permanecem como parte do documento. Se true, as partes recortadas serão removidas; se false, serão serializadas no documento (o que pode possivelmente levar a um arquivo maior) Escreva **bool**.
