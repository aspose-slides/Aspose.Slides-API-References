## CommentsPositions enum


Representa a regra para renderizar comentários no documento exportado

```cpp
enum class CommentsPositions
```

### Values

| Nome | Valor | Descrição |
| --- | --- | --- |
| None | 0 | Especifica que os comentários não devem ser exibidos de forma alguma. |
| Bottom | 1 | Especifica que os comentários devem ser exibidos na parte inferior da página. |
| Right | 2 | Especifica que os comentários devem ser exibidos à direita da página. |
