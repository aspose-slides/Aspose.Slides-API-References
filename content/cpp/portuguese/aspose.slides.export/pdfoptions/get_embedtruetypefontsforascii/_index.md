## PdfOptions::get_EmbedTrueTypeFontsForASCII() método

Determina se [Aspose.Slides](../../../aspose.slides/) incorporará fontes comuns para texto ASCII (faixa de código 33..127). [Fonts](../../../aspose.slides/fonts/) para códigos de caracteres superiores a 127 são sempre incorporados. A lista de fontes comuns inclui as 14 fontes base do PDF e fontes adicionais especificadas pelo usuário. Ler **bool**.

```cpp
bool Aspose::Slides::Export::PdfOptions::get_EmbedTrueTypeFontsForASCII() override
```

## Observações

O padrão é **true**.
