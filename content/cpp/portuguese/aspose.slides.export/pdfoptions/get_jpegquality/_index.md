## PdfOptions::get_JpegQuality() método

Retorna um valor que determina a qualidade das imagens JPEG dentro do documento PDF. Leitura **uint8_t**.

```cpp
uint8_t Aspose::Slides::Export::PdfOptions::get_JpegQuality() override
```

## Observações

Tem efeito somente quando o documento contém imagens JPEG.

Use esta propriedade para obter ou definir a qualidade das imagens dentro de um documento ao salvá-lo no formato PDF. O valor pode variar de 0 a 100, onde 0 significa pior qualidade mas compressão máxima e 100 significa melhor qualidade mas compressão mínima.

O valor padrão é **100**.
