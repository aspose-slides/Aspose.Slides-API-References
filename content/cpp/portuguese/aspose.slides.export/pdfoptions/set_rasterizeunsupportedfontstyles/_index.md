## PdfOptions::set_RasterizeUnsupportedFontStyles(bool) método

Indica se o texto deve ser rasterizado como bitmap e salvo em PDF quando a fonte não oferece suporte ao estilo negrito. Esta abordagem pode melhorar a qualidade do texto no PDF resultante para determinadas fontes. Escreva **bool**.

```cpp
void Aspose::Slides::Export::PdfOptions::set_RasterizeUnsupportedFontStyles(bool value) override
```

## Observações
