## PdfOptions::set_EmbedTrueTypeFontsForASCII(bool) método

Determina se [Aspose.Slides](../../../aspose.slides/) incorporará fontes comuns para texto ASCII (faixa de códigos 33..127). [Fonts](../../../aspose.slides/fonts/) para códigos de caracteres superiores a 127 são sempre incorporados. A lista de fontes comuns inclui as 14 fontes base do PDF e fontes adicionais especificadas pelo usuário. Escreva **bool**.

```cpp
void Aspose::Slides::Export::PdfOptions::set_EmbedTrueTypeFontsForASCII(bool value) override
```

## Observações

O padrão é **true**.
