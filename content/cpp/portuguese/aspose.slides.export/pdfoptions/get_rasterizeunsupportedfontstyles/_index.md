## PdfOptions::get_RasterizeUnsupportedFontStyles() método


Indica se o texto deve ser rasterizado como bitmap e salvo em PDF quando a fonte não oferece suporte à formatação em negrito. Essa abordagem pode melhorar a qualidade do texto no PDF resultante para determinadas fontes. Leia **bool**.

```cpp
bool Aspose::Slides::Export::PdfOptions::get_RasterizeUnsupportedFontStyles() override
```

## Observações


O padrão é **false**.
