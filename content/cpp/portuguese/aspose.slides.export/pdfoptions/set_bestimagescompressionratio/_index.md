## PdfOptions::set_BestImagesCompressionRatio(bool) método

Indica se a compressão mais eficaz (em vez da padrão) para cada imagem deve ser selecionada automaticamente. Se definido como **bool**.true, para cada imagem na apresentação o algoritmo de compressão mais adequado será escolhido, o que resultará em um tamanho menor do documento PDF resultante.

```cpp
void Aspose::Slides::Export::PdfOptions::set_BestImagesCompressionRatio(bool value) override
```

## Observações

A seleção da melhor taxa de compressão de imagem é computacionalmente cara e consome uma quantidade adicional de RAM, e esta opção é **bool**.false por padrão.

O padrão é **bool**.false.
