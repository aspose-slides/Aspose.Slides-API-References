## ParentLabelLayoutType enum

Representa o layout dos rótulos de dados de categoria. Usado somente com séries Treemap.

```cpp
enum class ParentLabelLayoutType
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Banner | 0 | Especifica que os rótulos de categoria pai são exibidos como banner |
| None | 1 | Especifica que os rótulos de categoria pai não são desenhados |
| Overlapping | 2 | Especifica que os rótulos de categoria pai são exibidos como sobrepostos |
