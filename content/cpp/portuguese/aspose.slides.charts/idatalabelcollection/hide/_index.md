## IDataLabelCollection::Hide() método

Torne o rótulo de dados oculto por padrão definindo todos os sinalizadores Show*-flags (ShowValue, ...) da propriedade DefaultDataLabelFormat para o estado false. IsVisible será false após isso.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelCollection::Hide()=0
```

## Observações

Se o rótulo de dados não estiver visível por padrão (IsVisible é false) você pode tornar o rótulo de dados \"visível 
por padrão\" definindo os sinalizadores Show*-flags (ShowValue, ...) da propriedade DefaultDataLabelFormat para o estado true.
