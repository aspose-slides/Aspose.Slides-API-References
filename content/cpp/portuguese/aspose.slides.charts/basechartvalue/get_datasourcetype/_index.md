## BaseChartValue::get_DataSourceType() método

Especifica se a propriedade AsCell, AsCells, AsLiteralString ou AsLiteralDouble está presente nos descendentes. Em outras palavras, especifica o tipo de valor da propriedade Data. Consulte [Charts::DataSourceType](../../datasourcetype/).

```cpp
Aspose::Slides::Charts::DataSourceType Aspose::Slides::Charts::BaseChartValue::get_DataSourceType() override
```

## Observações

Para pontos em [ChartDataPointCollection](../../chartdatapointcollection/) esta propriedade é somente leitura. Nesse caso, para alterar o valor desta propriedade, você pode usar uma das propriedades ChartDataPointCollection.DataSourceTypeFor<...>.
