## BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType) método

Especifica se a propriedade AsCell, AsCells, AsLiteralString ou AsLiteralDouble está efetiva nos descendentes. Em outras palavras, especifica o tipo de valor da propriedade Data. Escreva [Charts::DataSourceType](../../datasourcetype/).

```cpp
void Aspose::Slides::Charts::BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType value) override
```

## Observações

Para pontos em [ChartDataPointCollection](../../chartdatapointcollection/) esta propriedade é somente leitura. Neste caso, para alterar o valor desta propriedade, você pode usar uma das propriedades ChartDataPointCollection.DataSourceTypeFor<...>.
