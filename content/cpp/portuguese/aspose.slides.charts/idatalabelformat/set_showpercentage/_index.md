## IDataLabelFormat::set_ShowPercentage(bool) método

Representa o comportamento de exibição do valor percentual do rótulo de dados de um gráfico especificado. True exibe o valor percentual. False oculta. Escreva **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowPercentage(bool value)=0
```

## Observações

Se o pai deste objeto [DataLabelFormat](../../datalabelformat/) for uma coleção [DataLabelCollection](../../datalabelcollection/) de rótulos de dados, então esta propriedade obtém ou define o valor padrão da propriedade ShowPercentage para os novos rótulos de dados na coleção [DataLabelCollection](../../datalabelcollection/). Definir esta propriedade com um valor também define esse valor para a propriedade ShowPercentage de todos os rótulos de dados na coleção [DataLabelCollection](../../datalabelcollection/) (ou seja, \"DataLabels.DefaultDataLabelFormat.ShowPercentage = val;\" faz com que todos DataLabels[i].ShowPercentage sejam iguais a val).
