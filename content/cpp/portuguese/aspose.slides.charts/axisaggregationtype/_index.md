## AxisAggregationType enum

Representa o tipo de agregação do eixo de categoria. Usado apenas com séries Histogram ou HistogramPareto.

```cpp
enum class AxisAggregationType
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| ByCategory | 0 | Agrega por categorias |
| Automatic | 1 | Agrega categorias automaticamente. |
| ByBinWidth | 2 | Agrega categorias por largura de intervalo. Propriedade IAxis::get(set)_BinWidth deve ser definida. |
| ByNumberOfBins | 3 | Agrega categorias por número de intervalos. Propriedade IAxis::get(set)_NumberOfBins deve ser definida. |
