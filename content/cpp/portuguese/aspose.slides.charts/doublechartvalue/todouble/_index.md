## DoubleChartValue::ToDouble() método


Converte para **double**.

```cpp
double Aspose::Slides::Charts::DoubleChartValue::ToDouble() override
```


### Valor de Retorno

Retorna LiteralDouble se DataSourceType for igual a DoubleLiterals. Se DataSourceType for igual a Worksheet, retorna o valor da célula convertido com sucesso para double, caso contrário retorna NaN.
