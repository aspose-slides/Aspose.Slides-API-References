## ErrorBarValueType enum

Representa o tipo de valor da barra de erro

```cpp
enum class ErrorBarValueType
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Custom | 0 | Especifica que o comprimento das barras de erro deve ser determinado pelos elementos Plus e Minus. |
| Fixed | 1 | Especifica que o comprimento das barras de erro deve ser o valor fixo determinado por Error Bar Value. |
| Percentage | 2 | Especifica que o comprimento das barras de erro deve ser percentual de Error Bar Value dos dados. |
| StandardDeviation | 3 | Especifica que o comprimento das barras de erro deve ser desvios padrão de Error Bar Value dos dados. |
| StandardError | 4 | Especifica que o comprimento das barras de erro deve ser erros padrão de Error Bar Value dos dados. |
