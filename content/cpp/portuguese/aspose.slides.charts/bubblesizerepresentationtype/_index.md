## BubbleSizeRepresentationType enum

Especifica as possíveis maneiras de representar dados como tamanhos de gráfico de bolhas.

```cpp
enum class BubbleSizeRepresentationType
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Area | 0 | Especifica que a área das bolhas deve ser proporcional ao valor de tamanho da bolha. |
| Width | 1 | Especifica que o raio das bolhas deve ser proporcional ao valor de tamanho da bolha. |
