## DataLabel::get_IsVisible() método


False significa que o rótulo de dados não está visível (e, portanto, todas as flags Show*- (ShowValue, ...) são falsas). Somente leitura **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabel::get_IsVisible() override
```

## Observações


Se o rótulo de dados está visível, você pode ocultá-lo com o método [Hide()](../hide/). Mas se o rótulo de dados não está visível (IsVisible é false), você pode torná-lo visível definindo as flags Show*- (ShowValue, ...) para o estado true.
