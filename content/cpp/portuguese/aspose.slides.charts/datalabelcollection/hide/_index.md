## DataLabelCollection::Hide() método

Faça o rótulo de dados oculto por padrão definindo todos os flags Show*- (ShowValue, ...) da propriedade DefaultDataLabelFormat para o estado false. IsVisible será false após isso.

```cpp
void Aspose::Slides::Charts::DataLabelCollection::Hide() override
```

## Observações

Se o rótulo de dados não estiver visível por padrão (IsVisible é false) você pode tornar o rótulo de dados "visível 
por padrão" definindo os flags Show*- (ShowValue, ...) da propriedade DefaultDataLabelFormat para o estado true.
