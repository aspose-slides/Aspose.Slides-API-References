## DataLabelCollection::get_IsVisible() método

Falso significa que o rótulo de dados não está visível por padrão (e, portanto, todas as flags Show* (ShowValue, ...) da propriedade DefaultDataLabelFormat são falsas). Somente leitura **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelCollection::get_IsVisible() override
```

## Observações

Se o rótulo de dados estiver visível por padrão, você pode torná-lo oculto por padrão com o método [Hide()](../hide/). Mas se o rótulo de dados não estiver visível por padrão (IsVisible é false), você pode tornar o rótulo de dados "visível por padrão" configurando as flags Show* (ShowValue, ...) da propriedade DefaultDataLabelFormat para o estado verdadeiro.
