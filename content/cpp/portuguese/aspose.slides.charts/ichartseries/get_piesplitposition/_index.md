## IChartSeries::get_PieSplitPosition() método

Especifica um valor que deve ser usado para determinar quais pontos de dados estão no segundo segmento ou barra em um gráfico de pizza-em-pizza ou barra-em-pizza. É usado em conjunto com a propriedade PieSplitBy. Esta é a propriedade não apenas desta série, mas de todas as séries do grupo de séries pai – esta é a projeção da propriedade de grupo apropriada. Portanto, esta propriedade é somente leitura. Use a propriedade ParentSeriesGroup para acessar o grupo de séries pai. Use [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_PieSplitPosition() propriedade de leitura/gravação para alterar o valor. Somente leitura **double**.

```cpp
virtual double Aspose::Slides::Charts::IChartSeries::get_PieSplitPosition()=0
```

## Observações

Esta é a projeção da propriedade [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_PieSplitPosition().
