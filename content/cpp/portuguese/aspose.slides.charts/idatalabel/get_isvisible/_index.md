## IDataLabel::get_IsVisible() método

False significa que o rótulo de dados não está visível (e, portanto, todas as flags Show* (ShowValue, ...) são falsas). Somente leitura **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabel::get_IsVisible()=0
```

## Observações

Se o rótulo de dados estiver visível, você pode ocultá-lo com o método [Hide()](../hide/). Mas se o rótulo de dados não estiver visível (IsVisible é false), você pode tornar o rótulo de dados visível definindo as flags Show* (ShowValue, ...) para o estado true.
