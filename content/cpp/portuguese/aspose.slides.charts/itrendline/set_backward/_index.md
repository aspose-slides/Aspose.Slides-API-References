## ITrendline::set_Backward(double) método

Especifica o número de categorias (ou unidades em um gráfico de dispersão) que a linha de tendência se estende antes dos dados da série que está sendo analisada. Em gráficos de dispersão e não dispersão, o valor deve ser qualquer valor não negativo. Escreva **double**.

virtual void Aspose::Slides::Charts::ITrendline::set_Backward(double value)=0
