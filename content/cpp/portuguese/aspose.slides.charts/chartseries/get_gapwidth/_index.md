## ChartSeries::get_GapWidth() método


Especifica o espaço entre agrupamentos de barras ou colunas, como uma porcentagem da largura da barra ou coluna. Esta é a propriedade não apenas desta série, mas de todas as séries do grupo de séries pai - esta é a projeção da propriedade de grupo apropriada. Portanto, esta propriedade é somente leitura. Use a propriedade ParentSeriesGroup para acessar o grupo de séries pai. Use [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_GapWidth() propriedade de leitura/gravação para alterar o valor. Somente leitura **int32_t**.

```cpp
int32_t Aspose::Slides::Charts::ChartSeries::get_GapWidth() override
```

## Observações


Esta é a projeção da propriedade [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_GapWidth().
