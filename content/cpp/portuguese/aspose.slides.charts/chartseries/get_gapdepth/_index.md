## ChartSeries::get_GapDepth() método


Retorna a distância, como porcentagem da largura do marcador, entre as séries de dados em um gráfico 3D. Esta é a propriedade não apenas desta série, mas de todas as séries do grupo de séries pai – é a projeção da propriedade correspondente do grupo. Portanto, esta propriedade é somente leitura. Use a propriedade ParentSeriesGroup para acessar o grupo de séries pai. Use a propriedade [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_GapDepth() leitura/escrita para alterar o valor. Somente leitura **int32_t**.

```cpp
int32_t Aspose::Slides::Charts::ChartSeries::get_GapDepth() override
```

## Observações


Esta é a projeção da propriedade [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_GapDepth().
