## ChartSeries::get_BubbleSizeScale() método


Especifica o fator de escala para o gráfico de bolhas (pode estar entre 0 e 300 por cento do tamanho padrão). Esta é a propriedade não apenas desta série, mas de todas as séries do grupo de séries pai – isto é a projeção da propriedade apropriada do grupo. Portanto, esta propriedade é somente leitura. Use a propriedade ParentSeriesGroup para acessar o grupo de séries pai. Use [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_BubbleSizeScale() propriedade read/write para alterar o valor.

```cpp
int32_t Aspose::Slides::Charts::ChartSeries::get_BubbleSizeScale() override
```

## Observações


Esta é a projeção da propriedade [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_BubbleSizeScale().
