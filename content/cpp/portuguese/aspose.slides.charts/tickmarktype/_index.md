## TickMarkType enum

Representa o tipo de marca de graduação para o eixo especificado.

```cpp
enum class TickMarkType
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Cross | 0 | Especifica que as marcas de graduação devem cruzar o eixo. |
| Inside | 1 | Especifica que as marcas de graduação devem estar dentro da área do gráfico. |
| None | 2 | Especifica que não haverá marcas de graduação. |
| Outside | 3 | Especifica que as marcas de graduação devem ficar fora da área do gráfico. |
