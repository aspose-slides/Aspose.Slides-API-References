## ErrorBarsFormat::get_ValueType() método

Representa possíveis formas de determinar o comprimento das barras de erro. No caso de tipo de valor personalizado, para especificar o valor, use a propriedade [IChartDataPoint::get_ErrorBarsCustomValues()](../../ichartdatapoint/get_errorbarscustomvalues/) do ponto de dados específico na coleção DataPoints da série. No caso de tipo de valor Fixed, Percentage ou StandardDeviation, use a propriedade Value para especificar o valor.

Leia [ErrorBarValueType](../../errorbarvaluetype/).
