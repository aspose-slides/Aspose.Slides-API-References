## LegendDataLabelPosition enum

Determina a posição dos rótulos de dados.

```cpp
enum class LegendDataLabelPosition
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| NotDefined | -1 | A posição não está definida. |
| Bottom | 0 | Especifica que os rótulos de dados devem ser exibidos abaixo do marcador de dados. |
| BestFit | 1 | Especifica que os rótulos de dados devem ser exibidos na melhor posição. |
| Center | 2 | Especifica que os rótulos de dados devem ser exibidos centralizados no marcador de dados. |
| InsideBase | 3 | Especifica que os rótulos de dados devem ser exibidos dentro da base do marcador de dados. |
| InsideEnd | 4 | Especifica que os rótulos de dados devem ser exibidos dentro do final do marcador de dados. |
| Left | 5 | Especifica que os rótulos de dados devem ser exibidos à esquerda do marcador de dados. |
| OutsideEnd | 6 | Especifica que os rótulos de dados devem ser exibidos fora do final do marcador de dados. |
| Right | 7 | Especifica que os rótulos de dados devem ser exibidos à direita do marcador de dados. |
| Top | 8 | Especifica que os rótulos de dados devem ser exibidos acima do marcador de dados. |
