## DataSourceType enum

Tipos de fonte de dados.

```cpp
enum class DataSourceType
```

### Valores

| Name | Value | Description |
| --- | --- | --- |
| Worksheet | 0 | Use objetos CellXls para armazenar XValue, YValue, Value ou BubbleSize do ponto de dados na planilha. |
| StringLiterals | 1 | Use variável de string de acesso rápido para armazenar XValue, YValue, Value ou BubbleSize do ponto de dados. Worksheet NÃO é usado para armazenar valores. |
| DoubleLiterals | 2 | Use variável double de acesso rápido para armazenar XValue, YValue, Value ou BubbleSize do ponto de dados. Worksheet NÃO é usado para armazenar valores. |
