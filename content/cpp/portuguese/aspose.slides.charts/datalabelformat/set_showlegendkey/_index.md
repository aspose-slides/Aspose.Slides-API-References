## DataLabelFormat::set_ShowLegendKey(bool) método


Representa o comportamento de exibição da chave da legenda dos rótulos de dados de um gráfico especificado. Verdadeiro se a chave da legenda do rótulo de dados estiver visível. Escreve **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLegendKey(bool value) override
```

## Observações


Se o pai deste objeto [DataLabelFormat](../) for uma coleção [DataLabelCollection](../../datalabelcollection/) de rótulos de dados, então esta propriedade obtém ou define o valor padrão da propriedade ShowLegendKey para os novos rótulos de dados na coleção [DataLabelCollection](../../datalabelcollection/). Definir esta propriedade com um valor também define esse valor na propriedade ShowLegendKey para todos os rótulos de dados na coleção [DataLabelCollection](../../datalabelcollection/) (ou seja, \"DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;\" faz com que todos DataLabels[i].ShowLegendKey seja igual a val).
