## DataLabelFormat::set_ShowBubbleSize(bool) método


Representa o comportamento de exibição do valor do tamanho da bolha do rótulo de dados de um gráfico especificado. True exibe o valor do tamanho da bolha. False oculta. Escreva **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowBubbleSize(bool value) override
```

## Observações


Se o pai deste objeto [DataLabelFormat](../) for uma coleção [DataLabelCollection](../../datalabelcollection/) de rótulos de dados, então esta propriedade obtém ou define o valor padrão da propriedade ShowBubbleSize para os novos rótulos de dados na coleção [DataLabelCollection](../../datalabelcollection/). Definir esta propriedade com um valor também define esse valor na propriedade ShowBubbleSize para todos os rótulos de dados na coleção [DataLabelCollection](../../datalabelcollection/) (ou seja, \"DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;\" faz com que todos DataLabels[i].ShowBubbleSize sejam iguais a val).
