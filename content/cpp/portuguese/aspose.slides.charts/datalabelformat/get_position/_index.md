## DataLabelFormat::get_Position() método


Representa a posição do rótulo de dados. Leia [LegendDataLabelPosition](../../legenddatalabelposition/).

```cpp
LegendDataLabelPosition Aspose::Slides::Charts::DataLabelFormat::get_Position() override
```

## Observações


Se o pai deste objeto [DataLabelFormat](../) for uma coleção [DataLabelCollection](../../datalabelcollection/) de rótulos de dados, então esta propriedade obtém ou define o valor padrão da propriedade Position para os novos rótulos de dados na coleção [DataLabelCollection](../../datalabelcollection/). Representa a posição para os objetos [DataLabel](../../datalabel/). Definir esta propriedade com um valor também define esse valor na propriedade Position para todos os rótulos de dados na coleção [DataLabelCollection](../../datalabelcollection/) (ou seja, "DataLabels.DefaultDataLabelFormat.Position = val;" faz com que todos DataLabels[i].Position sejam iguais a val).
