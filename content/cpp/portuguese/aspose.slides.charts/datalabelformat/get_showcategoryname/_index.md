## DataLabelFormat::get_ShowCategoryName() método


Representa o comportamento de exibição do nome da categoria do rótulo de dados de um gráfico especificado. True para exibir o nome da categoria para os rótulos de dados em um gráfico. False para ocultar. Leitura **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowCategoryName() override
```

## Observações


Se o pai deste objeto [DataLabelFormat](../) for uma coleção [DataLabelCollection](../../datalabelcollection/) de rótulos de dados, então esta propriedade obtém ou define o valor padrão da propriedade ShowCategoryName para os novos rótulos de dados na coleção [DataLabelCollection](../../datalabelcollection/). Definir esta propriedade com valor também define esse valor na propriedade ShowCategoryName para todos os rótulos de dados na coleção [DataLabelCollection](../../datalabelcollection/) (i.e. "DataLabels.DefaultDataLabelFormat.ShowCategoryName = val;" causa que todos DataLabels[i].ShowCategoryName sejam iguais a val).
