## DataLabelFormat::set_Position(LegendDataLabelPosition) método


Representa a posição do rótulo de dados. Escreva [LegendDataLabelPosition](../../legenddatalabelposition/).

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_Position(LegendDataLabelPosition value) override
```

## Observações


Se o pai deste objeto [DataLabelFormat](../) for uma coleção [DataLabelCollection](../../datalabelcollection/) de rótulos de dados, então esta propriedade obtém ou define o valor padrão da propriedade Position para os novos rótulos de dados na coleção [DataLabelCollection](../../datalabelcollection/). Representa a posição para os objetos [DataLabel](../../datalabel/). Definir esta propriedade com um valor também define esse valor na propriedade Position para todos os rótulos de dados na coleção [DataLabelCollection](../../datalabelcollection/) (por exemplo, "DataLabels.DefaultDataLabelFormat.Position = val;" faz com que todos DataLabels[i].Position sejam iguais a val).
