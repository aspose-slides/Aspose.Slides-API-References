## IChartCategoryCollection::set_UseCells(bool) método

Se for verdadeiro, a planilha é usada para armazenar categorias (este caso suporta categorias de vários níveis). Se for falso, a planilha NÃO é usada para armazenar valores (e este caso não suporta categorias de vários níveis). Escreva **bool**.

virtual void Aspose::Slides::Charts::IChartCategoryCollection::set_UseCells(bool value)=0
