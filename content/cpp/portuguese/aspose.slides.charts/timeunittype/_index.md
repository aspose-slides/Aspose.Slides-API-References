## TimeUnitType enum

Representa a unidade base para o eixo de categoria

```cpp
enum class TimeUnitType
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| None | 0 | Os valores serão exibidos como estão. |
| Days | 1 | Especifica que os dados do gráfico devem ser exibidos em dias. |
| Months | 2 | Especifica que os dados do gráfico devem ser exibidos em meses. |
| Years | 3 | Especifica que os dados do gráfico devem ser exibidos em anos. |
