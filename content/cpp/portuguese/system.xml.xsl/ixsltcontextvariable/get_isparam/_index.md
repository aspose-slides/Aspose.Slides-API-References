## IXsltContextVariable::get_IsParam() método

Retorna um valor que indica se a variável é um parâmetro Extensible Stylesheet Language Transformations (XSLT). Pode ser um parâmetro de uma folha de estilo ou de um modelo.

```cpp
virtual bool System::Xml::Xsl::IXsltContextVariable::get_IsParam()=0
```

### Valor de Retorno

**true** se a variável for um parâmetro XSLT; caso contrário, **false**.
