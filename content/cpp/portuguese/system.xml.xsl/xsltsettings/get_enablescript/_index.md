## XsltSettings::get_EnableScript() método

Returns a value indicating whether to enable support for embedded script blocks.

```cpp
bool System::Xml::Xsl::XsltSettings::get_EnableScript()
```

### Valor de Retorno

**true** para suportar blocos de script em folhas de estilo XSLT; caso contrário, **false**. O padrão é **false**.
