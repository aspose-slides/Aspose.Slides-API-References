## XsltSettings::get_EnableDocumentFunction() method

Retorna um valor que indica se o suporte à função **document()** do XSLT deve ser habilitado.

```cpp
bool System::Xml::Xsl::XsltSettings::get_EnableDocumentFunction()
```

### Valor de Retorno

**true** para suportar a função **document()** do XSLT; caso contrário, **false**. O padrão é **false**.
