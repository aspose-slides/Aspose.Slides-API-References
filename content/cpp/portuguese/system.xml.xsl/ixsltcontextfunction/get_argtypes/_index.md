## IXsltContextFunction::get_ArgTypes() método


Retorna os tipos da Linguagem de Caminho XML ([XPath](../../../system.xml.xpath/)) fornecidos para a lista de argumentos da função. Essas informações podem ser usadas para descobrir a assinatura da função, o que permite diferenciar entre funções sobrecarregadas.

```cpp
virtual ArrayPtr<System::Xml::XPath::XPathResultType> System::Xml::Xsl::IXsltContextFunction::get_ArgTypes()=0
```


### Valor de Retorno

Um array de XPathResultType representando os tipos para a lista de argumentos da função.
