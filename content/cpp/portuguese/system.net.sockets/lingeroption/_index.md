## LingerOption classe

Especifica se um socket permanecerá conectado após uma chamada aos métodos Close() ou Close(). Também especifica o período que o socket permanecerá conectado se o envio dos dados continuar. Objetos desta classe devem ser alocados apenas usando a função [System::MakeObject()](../../system/makeobject/). Nunca crie uma instância deste tipo na pilha ou usando o operador new, pois isso resultará em erros de tempo de execução e/ou falhas de asserção. Sempre encapsule esta classe em um ponteiro [System::SmartPtr](../../system/smartptr/) e use esse ponteiro para passá-lo a funções como argumento.

```cpp
class LingerOption : public System::Object
```
