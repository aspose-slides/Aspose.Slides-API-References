## XmlCharacterData::Substring(int32_t, int32_t) método

Recupera uma substring da string completa a partir do intervalo especificado.

```cpp
virtual String System::Xml::XmlCharacterData::Substring(int32_t offset, int32_t count)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| offset | **int32_t** | A posição dentro da string para iniciar a recuperação. Um offset zero indica que o ponto de partida está no início dos dados. |
| count | **int32_t** | O número de caracteres a serem recuperados. |

### Valor de Retorno

A substring correspondente ao intervalo especificado.
