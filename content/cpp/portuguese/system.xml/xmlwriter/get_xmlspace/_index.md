## XmlWriter::get_XmlSpace() método

Quando substituído em uma classe derivada, obtém um XmlSpace que representa o escopo atual de **xml:space**.

```cpp
virtual System::Xml::XmlSpace System::Xml::XmlWriter::get_XmlSpace()
```

### Valor de Retorno

Um XmlSpace que representa o escopo atual de **xml:space**.



| Valor | Significado |
| --- | --- |
| `None`| Este é o padrão se não existir nenhum escopo `xml:space`. |
| `Default`| O escopo atual é `xml:space="default"`. |
| `Preserve`| O escopo atual é `xml:space="preserve"`. |
