## XmlElement::set_IsEmpty(bool) método


Define o formato da tag do elemento.

```cpp
void System::Xml::XmlElement::set_IsEmpty(bool value)
```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| value | **bool** | O valor a ser definido. Ao definir este valor, se for definido como **true**, os filhos do elemento são removidos e o elemento é serializado no formato de tag curta. Se for definido como **false**, o valor é alterado (independentemente de o elemento ter conteúdo ou não); se o elemento estiver vazio, ele é serializado no formato longo. |
