## XmlElement::CloneNode(bool) método


Cria uma duplicata deste nó.

```cpp
SharedPtr<XmlNode> System::Xml::XmlElement::CloneNode(bool deep) override
```


### Argumentos

| Parameter | Type | Description |
| --- | --- | --- |
| deep | **bool** | **true** para clonar recursivamente a subárvore sob o nó especificado; **false** para clonar apenas o próprio nó (e seus atributos se o nó for um [XmlElement](../)). |

### Valor de Retorno

O nó clonado.
