## XmlElement::get_IsEmpty() method


Retorna o formato da tag do elemento.

```cpp
bool System::Xml::XmlElement::get_IsEmpty()
```


### Valor de Retorno

**true** se o elemento deve ser serializado no formato de tag curta \"<tt><item/></tt>\"; **false** para o formato longo \"<tt><item></item></tt>\".
