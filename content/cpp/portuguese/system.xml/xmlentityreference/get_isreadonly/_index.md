## XmlEntityReference::get_IsReadOnly() método

Retorna um valor que indica se o nó é somente leitura.

```cpp
bool System::Xml::XmlEntityReference::get_IsReadOnly() override
```

### Valor de Retorno

**true** se o nó é somente leitura; caso contrário **false**. Como os nós [XmlEntityReference](../) são somente leitura, este método sempre retorna **true**.
