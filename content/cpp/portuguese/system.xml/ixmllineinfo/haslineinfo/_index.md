## IXmlLineInfo::HasLineInfo() método


Retorna um valor que indica se a classe pode retornar informações de linha.

```cpp
virtual bool System::Xml::IXmlLineInfo::HasLineInfo()=0
```


### Valor de Retorno

**true** se [IXmlLineInfo::get_LineNumber](../get_linenumber/) e [IXmlLineInfo::get_LinePosition](../get_lineposition/) puderem ser fornecidos; caso contrário, **false**.
