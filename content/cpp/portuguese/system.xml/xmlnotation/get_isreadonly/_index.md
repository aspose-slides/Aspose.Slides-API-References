## XmlNotation::get_IsReadOnly() método

Retorna um valor que indica se o nó é somente leitura.

```cpp
bool System::Xml::XmlNotation::get_IsReadOnly() override
```

### Valor de retorno

**true** se o nó for somente leitura; caso contrário, **false**. Porque nós [XmlNotation](../) são somente leitura, este método sempre retorna **true**.
