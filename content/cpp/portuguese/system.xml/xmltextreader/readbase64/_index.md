## XmlTextReader::ReadBase64(const ArrayPtr\<uint8_t\>\&, int32_t, int32_t) method

```cpp
int32_t System::Xml::XmlTextReader::ReadBase64(const ArrayPtr<uint8_t> &array, int32_t offset, int32_t len)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| array | const [ArrayPtr](../../../system/arrayptr/)\<**uint8_t**\>\& | O array de caracteres que serve como buffer para o qual o conteúdo de texto é escrito. |
| offset | **int32_t** | O índice baseado em zero no array que especifica onde o método pode começar a escrever no buffer. |
| len | **int32_t** | O número de bytes a serem escritos no buffer. |

### Valor de retorno

O número de bytes escritos no buffer.
