## XmlTextReader::get_ProhibitDtd() método

Retorna um valor que indica se deve permitir o processamento de DTD.

```cpp
bool System::Xml::XmlTextReader::get_ProhibitDtd()
```

### Valor de retorno

**true** para impedir o processamento de DTD; caso contrário **false**. O padrão é **false**.

Obsoleto
:   Este método é obsoleto. Use [XmlTextReader::get_DtdProcessing](../get_dtdprocessing/) em vez disso.
