## XmlTextReader::get_IsDefault() método

Retorna um valor indicando se o nó atual é um atributo que foi gerado a partir do valor padrão definido no DTD ou no esquema.

```cpp
bool System::Xml::XmlTextReader::get_IsDefault() override
```

### Valor de Retorno

Este método sempre retorna **false**. ([XmlTextReader](../) não expande atributos padrão.)
