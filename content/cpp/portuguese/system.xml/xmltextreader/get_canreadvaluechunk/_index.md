## XmlTextReader::get_CanReadValueChunk() método


Retorna um valor que indica se o [XmlTextReader](../) implementa o método [XmlReader::ReadValueChunk](../../xmlreader/readvaluechunk/).

```cpp
bool System::Xml::XmlTextReader::get_CanReadValueChunk() override
```


### Valor de Retorno

**true** se o [XmlTextReader](../) implementa o método [XmlReader::ReadValueChunk](../../xmlreader/readvaluechunk/); caso contrário **false**. A classe [XmlTextReader](../) sempre retorna **false**.
