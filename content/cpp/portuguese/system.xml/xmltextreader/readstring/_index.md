## XmlTextReader::ReadString() método

Lê o conteúdo de um elemento ou de um nó de texto como uma string.

```cpp
String System::Xml::XmlTextReader::ReadString() override
```

### Valor de Retorno

O conteúdo do elemento ou nó de texto. Pode ser uma string vazia se o leitor estiver posicionado em algo que não seja um elemento ou nó de texto, ou se não houver mais conteúdo de texto para retornar no contexto atual. **Nota:** O nó de texto pode ser tanto um elemento quanto um nó de texto de atributo.
