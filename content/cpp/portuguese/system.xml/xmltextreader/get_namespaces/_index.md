## XmlTextReader::get_Namespaces() método

Retorna um valor indicando se o suporte a namespace deve ser habilitado.

```cpp
bool System::Xml::XmlTextReader::get_Namespaces()
```

### Valor de retorno

**true** para habilitar o suporte a namespace; caso contrário, **false**. O padrão é **true**.
