## XmlTextReader::get_CanReadBinaryContent() método


Retorna um valor que indica se o [XmlTextReader](../) implementa os métodos de leitura de conteúdo binário.

```cpp
bool System::Xml::XmlTextReader::get_CanReadBinaryContent() override
```


### Valor de Retorno

**true** se os métodos de leitura de conteúdo binário estiverem implementados; caso contrário, **false**. A classe [XmlTextReader](../) sempre retorna **true**.
