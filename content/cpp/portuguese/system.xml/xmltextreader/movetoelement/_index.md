## XmlTextReader::MoveToElement() método


Move para o elemento que contém o nó de atributo atual.

```cpp
bool System::Xml::XmlTextReader::MoveToElement() override
```


### Valor de retorno

**true** se o leitor estiver posicionado em um atributo (o leitor move para o elemento que possui o atributo); **false** se o leitor não estiver posicionado em um atributo (a posição do leitor não muda).
