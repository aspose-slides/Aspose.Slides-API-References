## XmlNodeOrder enum

Descreve a ordem do documento de um nó em comparação com um segundo nó.

```cpp
enum class XmlNodeOrder
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Before | 0 | O nó atual deste navegador está antes do nó atual do navegador fornecido. |
| After | 1 | O nó atual deste navegador está depois do nó atual do navegador fornecido. |
| Same | 2 | Os dois navegadores estão posicionados no mesmo nó. |
| Unknown | 3 | As posições dos nós não podem ser determinadas na ordem do documento, em relação uma à outra. Isso pode ocorrer se os dois nós estiverem em árvores diferentes. |
