## XmlTextWriter::LookupPrefix(String) método

Retorna o prefixo mais próximo definido no escopo atual de namespace para o URI do namespace.

```cpp

```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| ns | [String](../../../system/string/) | URI do namespace cujo prefixo você deseja encontrar. |

### Valor de Retorno
