## XmlTextWriter::get_Namespaces() método


Retorna um valor que indica se o suporte a namespaces deve ser realizado.

```cpp
bool System::Xml::XmlTextWriter::get_Namespaces()
```


### Valor de Retorno

**true** para suportar namespaces; caso contrário, **false**. O padrão é **true**.
