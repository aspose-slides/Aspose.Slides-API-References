## XmlTextWriter::get_IndentChar() método

Retorna qual caractere usar para indentação quando [XmlTextWriter::set_Formatting](../set_formatting/) está definido como [Formatting::Indented](../../formatting/).

```cpp
char16_t System::Xml::XmlTextWriter::get_IndentChar()
```

### Valor de Retorno

O caractere a ser usado para indentação. O padrão é espaço.
