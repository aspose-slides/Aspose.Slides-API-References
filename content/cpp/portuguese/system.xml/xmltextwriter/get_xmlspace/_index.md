## XmlTextWriter::get_XmlSpace() método

Retorna um XmlSpace que representa o escopo atual de **xml:space**.

```cpp
System::Xml::XmlSpace System::Xml::XmlTextWriter::get_XmlSpace() override
```

### Valor de retorno

Um XmlSpace que representa o escopo atual de **xml:space**.

| Valor | Significado |
| --- | --- |
| None | Este é o padrão se nenhum escopo `xml:space` existir. |
| Default | O escopo atual é `xml:space="default"`. |
| Preserve | O escopo atual é `xml:space="preserve"`. |
