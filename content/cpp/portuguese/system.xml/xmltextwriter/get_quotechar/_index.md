## XmlTextWriter::get_QuoteChar() método

Retorna qual caractere usar para citar valores de atributos.

```cpp
char16_t System::Xml::XmlTextWriter::get_QuoteChar()
```

### Valor de Retorno

O caractere a ser usado para citar valores de atributos. Deve ser uma aspas simples **'** ou uma aspas dupla **\"**. O padrão é uma aspas dupla.
