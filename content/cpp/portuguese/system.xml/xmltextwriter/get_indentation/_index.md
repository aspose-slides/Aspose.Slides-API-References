## XmlTextWriter::get_Indentation() method


Retorna quantos IndentChars devem ser escritos para cada nível na hierarquia quando [XmlTextWriter::set_Formatting](../set_formatting/) está definido como [Formatting::Indented](../../formatting/).

```cpp
int32_t System::Xml::XmlTextWriter::get_Indentation()
```


### Valor de Retorno

Número de **IndentChars** para cada nível. O padrão é 2.
