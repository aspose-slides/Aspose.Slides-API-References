## IXmlNamespaceResolver::LookupNamespace(const String\&) method

Retorna o URI do namespace mapeado para o prefixo especificado.

```cpp
virtual String System::Xml::IXmlNamespaceResolver::LookupNamespace(const String &prefix)=0
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| prefix | const [String](../../../system/string/)\& | O prefixo cujo URI de namespace você deseja encontrar. |

### Valor de retorno

O URI do namespace que está mapeado para o prefixo; **nullptr** se o prefixo não estiver mapeado para um URI de namespace.
