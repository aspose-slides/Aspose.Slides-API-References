## XmlNodeList::idx_get(int32_t) método


Retorna um nó no índice especificado.

```cpp
virtual SharedPtr<XmlNode> System::Xml::XmlNodeList::idx_get(int32_t i)
```


### Arguments

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| i | **int32_t** | O índice baseado em zero na lista de nós. |

### Return Value

O [XmlNode](../../xmlnode/) com o índice especificado na coleção. Se o índice for maior ou igual ao número de nós na lista, isso retorna **nullptr**.
