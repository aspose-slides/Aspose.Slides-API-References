## XmlAttribute::get_Specified() método


Retorna um valor que indica se o valor do atributo foi definido explicitamente.

```cpp
virtual bool System::Xml::XmlAttribute::get_Specified()
```


### Valor de Retorno

**true** se este atributo recebeu explicitamente um valor no documento de instância original; caso contrário, **false**. Um valor de **false** indica que o valor do atributo veio do DTD.
