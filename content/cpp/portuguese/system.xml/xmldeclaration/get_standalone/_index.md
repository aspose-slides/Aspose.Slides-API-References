## XmlDeclaration::get_Standalone() método


Retorna o valor do atributo standalone.

```cpp
String System::Xml::XmlDeclaration::get_Standalone()
```


### Valor de Retorno

Os valores válidos são **yes** se todas as declarações de entidade exigidas pelo documento XML estiverem contidas no documento ou **no** se for necessária uma definição externa de tipo de documento (DTD). Se um atributo standalone não estiver presente na declaração XML, este método retorna [String::Empty](../../../system/string/empty/).
