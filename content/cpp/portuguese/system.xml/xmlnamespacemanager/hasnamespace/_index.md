## XmlNamespaceManager::HasNamespace(String) método

Retorna um valor indicando se o prefixo fornecido tem um namespace definido para o escopo empilhado atual.

```cpp
virtual bool System::Xml::XmlNamespaceManager::HasNamespace(String prefix)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| prefix | [String](../../../system/string/) | O prefixo do namespace que você deseja encontrar. |

### Valor de Retorno

**true** se houver um namespace definido; caso contrário, **false**.
