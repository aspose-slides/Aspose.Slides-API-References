## WhitespaceHandling enum

Especifica como o espaço em branco é tratado.

```cpp
enum class WhitespaceHandling
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| All | 0 | Retorna nós **Whitespace** e **SignificantWhitespace**. Este é o padrão. |
| Significant | 1 | Retorna apenas nós **SignificantWhitespace**. |
| None | 2 | Não retorna nós **Whitespace** nem nós **SignificantWhitespace**. |
