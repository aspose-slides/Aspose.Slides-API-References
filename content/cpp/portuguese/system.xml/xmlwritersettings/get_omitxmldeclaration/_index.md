## XmlWriterSettings::get_OmitXmlDeclaration() método


Retorna um valor que indica se a declaração XML deve ser omitida.

```cpp
bool System::Xml::XmlWriterSettings::get_OmitXmlDeclaration()
```


### Valor de Retorno

**true** para omitir a declaração XML; caso contrário, **false**. O padrão é **false**, uma declaração XML é escrita.
