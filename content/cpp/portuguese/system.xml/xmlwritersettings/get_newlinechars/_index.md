## XmlWriterSettings::get_NewLineChars() método

Retorna a cadeia de caracteres a ser usada para quebras de linha.

```cpp
String System::Xml::XmlWriterSettings::get_NewLineChars()
```

### Valor de Retorno

A cadeia de caracteres a ser usada para quebras de linha. Isso pode ser definido para qualquer valor de string. No entanto, para garantir XML válido, você deve especificar apenas caracteres de espaço em branco válidos, como caracteres de espaço, tabulações, retornos de carro ou alimentações de linha. O padrão é **\r\n** (retorno de carro, nova linha).
