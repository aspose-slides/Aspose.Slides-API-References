## XmlWriterSettings::get_NewLineOnAttributes() método


Retorna um valor que indica se os atributos devem ser escritos em uma nova linha.

```cpp
bool System::Xml::XmlWriterSettings::get_NewLineOnAttributes()
```


### Valor de retorno

**true** para escrever atributos em linhas individuais; caso contrário, **false**. O padrão é **false**.
