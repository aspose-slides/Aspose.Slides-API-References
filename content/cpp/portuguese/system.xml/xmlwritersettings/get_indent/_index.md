## XmlWriterSettings::get_Indent() método

Retorna um valor que indica se deve indentar os elementos.

```cpp
bool System::Xml::XmlWriterSettings::get_Indent()
```

### Valor de Retorno

**true** para escrever elementos individuais em novas linhas e indentar; caso contrário, **false**. O padrão é **false**.
