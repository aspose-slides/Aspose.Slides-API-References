## XmlWriterSettings::get_IndentChars() método


Retorna a cadeia de caracteres a ser usada ao recuar. Essa configuração é usada quando o valor [XmlWriterSettings::set_Indent](../set_indent/) está definido como **true**.

```cpp
String System::Xml::XmlWriterSettings::get_IndentChars()
```


### Valor de Retorno

A cadeia de caracteres a ser usada ao recuar. Isso pode ser definido para qualquer valor de string. No entanto, para garantir XML válido, você deve especificar apenas caracteres de espaço em branco válidos, como caracteres de espaço, tabulações, retornos de carro ou quebras de linha. O padrão são dois espaços.
