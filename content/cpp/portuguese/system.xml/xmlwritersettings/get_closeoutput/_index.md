## XmlWriterSettings::get_CloseOutput() método

Retorna um valor indicando se o [XmlWriter](../../xmlwriter/) também deve fechar o fluxo subjacente ou TextWriter quando o método [XmlWriter::Close](../../xmlwriter/close/) for chamado.

```cpp
bool System::Xml::XmlWriterSettings::get_CloseOutput()
```

### Valor de retorno

**true** para também fechar o fluxo subjacente ou TextWriter; caso contrário, **false**. O padrão é **false**.
