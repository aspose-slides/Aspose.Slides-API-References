## XmlWriterSettings::get_CheckCharacters() método


Retorna um valor que indica se o escritor XML deve verificar para garantir que todos os caracteres no documento estejam em conformidade com a seção \"2.2 Characters\" da W3C [XML 1.0 Recommendation](https://www.w3.org/TR/REC-xml/#charsets).

```cpp
bool System::Xml::XmlWriterSettings::get_CheckCharacters()
```


### Valor de Retorno

**true** para fazer verificação de caracteres; caso contrário, **false**. O padrão é **true**.
