## XmlWriterSettings::set_NamespaceHandling(System::Xml::NamespaceHandling) método

Define um valor que indica se o [XmlWriter](../../xmlwriter/) deve remover declarações de namespace duplicadas ao gravar conteúdo XML. O comportamento padrão é que o gravador emita todas as declarações de namespace presentes no resolvedor de namespaces do gravador.

```cpp
void System::Xml::XmlWriterSettings::set_NamespaceHandling(System::Xml::NamespaceHandling value)
```

| --- | --- | --- |
| value | [System::Xml::NamespaceHandling](../../namespacehandling/) | O valor a ser definido. |
