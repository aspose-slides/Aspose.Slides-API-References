## XmlReader::get_NamespaceURI() método

Quando sobrescrito em uma classe derivada, obtém o URI do namespace (conforme definido na especificação de Namespace da W3C) do nó no qual o leitor está posicionado.

```cpp
virtual String System::Xml::XmlReader::get_NamespaceURI()=0
```

### Valor de Retorno

O URI do namespace do nó atual; caso contrário, uma string vazia.
