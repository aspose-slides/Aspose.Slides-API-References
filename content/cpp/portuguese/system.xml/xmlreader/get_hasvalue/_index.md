## XmlReader::get_HasValue() método


Quando sobrescrito em uma classe derivada, obtém um valor que indica se o nó atual pode ter um [XmlReader::get_Value](../get_value/) valor.

```cpp
virtual bool System::Xml::XmlReader::get_HasValue()
```


### Valor de retorno

**true** se o nó onde o leitor está posicionado atualmente puder ter um **Value**; caso contrário, **false**. Se **false**, o nó tem um valor de [String::Empty](../../../system/string/empty/).
