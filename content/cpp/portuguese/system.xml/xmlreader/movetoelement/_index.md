## XmlReader::MoveToElement() método


Quando sobrescrito em uma classe derivada, move-se para o elemento que contém o nó de atributo atual.

```cpp
virtual bool System::Xml::XmlReader::MoveToElement()=0
```


### Valor de retorno

**true** se o leitor estiver posicionado em um atributo (o leitor move-se para o elemento que possui o atributo); **false** se o leitor não estiver posicionado em um atributo (a posição do leitor não muda).
