## XmlReader::ReadInnerXml() método

Ao ser sobrescrito em uma classe derivada, lê todo o conteúdo, incluindo marcação, como uma string.

```cpp
virtual String System::Xml::XmlReader::ReadInnerXml()
```

### Valor de Retorno

Todo o conteúdo XML, incluindo marcação, no nó atual. Se o nó atual não tiver filhos, uma string vazia é retornada. Se o nó atual não for nem um elemento nem um atributo, uma string vazia é retornada.
