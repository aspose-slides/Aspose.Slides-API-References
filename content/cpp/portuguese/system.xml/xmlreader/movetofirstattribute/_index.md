## XmlReader::MoveToFirstAttribute() método

Quando sobrescrito em uma classe derivada, move para o primeiro atributo.

```cpp
virtual bool System::Xml::XmlReader::MoveToFirstAttribute()=0
```

### Valor de Retorno

**true** se um atributo existe (o leitor move para o primeiro atributo); caso contrário, **false** (a posição do leitor não muda).
