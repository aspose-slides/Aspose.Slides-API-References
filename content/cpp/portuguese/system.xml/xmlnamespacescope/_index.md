## XmlNamespaceScope enum

Define o escopo do namespace.

```cpp
enum class XmlNamespaceScope
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| All | 0 | Todos os namespaces definidos no escopo do nó atual. Isto inclui o namespace xmlns:xml que é sempre declarado implicitamente. A ordem dos namespaces retornados não é definida. |
| ExcludeXml | 1 | Todos os namespaces definidos no escopo do nó atual, excluindo o namespace xmlns:xml, que é sempre declarado implicitamente. A ordem dos namespaces retornados não é definida. |
| Local | 2 | Todos os namespaces que são definidos localmente no nó atual. |
