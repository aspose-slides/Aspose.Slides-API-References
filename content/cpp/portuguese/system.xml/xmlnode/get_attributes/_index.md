## XmlNode::get_Attributes() método


Retorna um [XmlAttributeCollection](../../xmlattributecollection/) contendo os atributos deste nó.

```cpp
virtual SharedPtr<XmlAttributeCollection> System::Xml::XmlNode::get_Attributes() final
```


### Valor de Retorno

Um [XmlAttributeCollection](../../xmlattributecollection/) contendo os atributos do nó. Se o nó for do tipo [XmlNodeType::Element](../../xmlnodetype/), os atributos do nó são retornados. Caso contrário, este método retorna **nullptr**.
