## XmlNode::GetPrefixOfNamespace(String) método

Procura a declaração **xmlns** mais próxima para o URI de namespace fornecido que está no escopo do nó atual e retorna o prefixo definido nessa declaração.

```cpp
virtual String System::Xml::XmlNode::GetPrefixOfNamespace(String namespaceURI)
```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| namespaceURI | [String](../../../system/string/) | O URI de namespace cujo prefixo você deseja encontrar. |

### Valor de Retorno

O prefixo para o URI de namespace especificado.
