## XmlNode::CloneNode(bool) método


Cria uma duplicata do nó, quando sobrescrito em uma classe derivada.

```cpp
virtual SharedPtr<XmlNode> System::Xml::XmlNode::CloneNode(bool deep)=0
```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| deep | **bool** | **true** para clonar recursivamente a subárvore sob o nó especificado; **false** para clonar apenas o próprio nó. |

### Valor de Retorno

O nó clonado.
