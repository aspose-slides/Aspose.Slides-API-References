## XmlNode::get_Prefix() método

Retorna o prefixo de namespace deste nó.

```cpp
virtual String System::Xml::XmlNode::get_Prefix()
```

### Valor de Retorno

O prefixo de namespace deste nó. Por exemplo, **Prefix** é **bk** para o elemento **<bk:book>**. Se não houver prefixo, este método retorna [String::Empty](../../../system/string/empty/).
