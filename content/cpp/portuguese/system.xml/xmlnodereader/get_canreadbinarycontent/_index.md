## XmlNodeReader::get_CanReadBinaryContent() method

Retorna um valor que indica se o [XmlNodeReader](../) implementa os métodos de leitura de conteúdo binário.

```cpp
bool System::Xml::XmlNodeReader::get_CanReadBinaryContent() override
```

### Valor de Retorno

**true** se os métodos de leitura de conteúdo binário forem implementados; caso contrário **false**. A classe [XmlNodeReader](../) sempre retorna **true**.
