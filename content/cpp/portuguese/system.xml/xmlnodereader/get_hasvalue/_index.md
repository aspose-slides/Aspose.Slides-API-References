## XmlNodeReader::get_HasValue() método

Retorna um valor que indica se o nó atual pode ter um [XmlNodeReader::get_Value](../get_value/) valor.

```cpp
bool System::Xml::XmlNodeReader::get_HasValue() override
```

### Valor de Retorno

**true** if the node on which the reader is currently positioned can have a **Value**; otherwise, **false**.
