## XmlNodeReader::get_IsEmptyElement() método


Retorna um valor indicando se o nó atual é um elemento vazio (por exemplo, **<MyElement/>**).

```cpp
bool System::Xml::XmlNodeReader::get_IsEmptyElement() override
```


### Valor de Retorno

**true** se o nó atual for um elemento ([XmlNodeReader::get_NodeType](../get_nodetype/) igual a [XmlNodeType::Element](../../xmlnodetype/)) e terminar com **/>**; caso contrário, **false**.
