## XmlNodeReader::get_CanResolveEntity() método

Retorna um valor que indica se este leitor pode analisar e resolver entidades.

```cpp
bool System::Xml::XmlNodeReader::get_CanResolveEntity() override
```

### Valor de Retorno

**true** se o leitor pode analisar e resolver entidades; caso contrário, **false**. [XmlNodeReader](../) sempre retorna **true**.
