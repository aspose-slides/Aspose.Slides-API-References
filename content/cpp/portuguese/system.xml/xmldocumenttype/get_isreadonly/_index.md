## XmlDocumentType::get_IsReadOnly() método

Retorna um valor que indica se o nó é somente leitura.

```cpp
bool System::Xml::XmlDocumentType::get_IsReadOnly() override
```

### Valor de Retorno

**true** se o nó for somente leitura; caso contrário, **false**. Como os nós DocumentType são somente leitura, este método sempre retorna **true**.
