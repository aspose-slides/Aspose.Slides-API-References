## XmlConvert::VerifyNCName(const String\&) method

Verifica se o nome é um **NCName** válido de acordo com a recomendação da W3C Extended Markup Language. Um **NCName** é um nome que não pode conter dois-pontos.

```cpp
static String System::Xml::XmlConvert::VerifyNCName(const String &name)
```

### Arguments

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| name | const [String](../../../system/string/)\& | O nome a ser verificado. |

### Valor de Retorno

O nome, se for um **NCName** válido.
