## XmlConvert::ToString(DateTimeOffset, const String\&) method

Converte o [DateTimeOffset](../../../system/datetimeoffset/) fornecido para um [String](../../../system/string/) no formato especificado.

```cpp

```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| value | [DateTimeOffset](../../../system/datetimeoffset/) | O [DateTimeOffset](../../../system/datetimeoffset/) a ser convertido. |
| format | const [String](../../../system/string/)\& | O formato para o qual **s** é convertido. O parâmetro de formato pode ser qualquer subconjunto da Recomendação W3C para o tipo XML dateTime. ### Valor de retorno

Uma representação [String](../../../system/string/) no formato especificado do [DateTimeOffset](../../../system/datetimeoffset/) fornecido.
