## XmlConvert::VerifyXmlChars(const String\&) método

Retorna a string passada se todos os caracteres e os caracteres de pares substitutos na string de argumento forem caracteres XML válidos; caso contrário, uma XmlException é lançada com informações sobre o primeiro caractere inválido encontrado.

```cpp
static String System::Xml::XmlConvert::VerifyXmlChars(const String &content)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| content | const [String](../../../system/string/)\& | [String](../../../system/string/) que contém caracteres a serem verificados. |

### Valor de Retorno

A string passada se todos os caracteres e os caracteres de pares substitutos na string de argumento forem caracteres XML válidos; caso contrário, uma XmlException é lançada com informações sobre o primeiro caractere inválido encontrado.
