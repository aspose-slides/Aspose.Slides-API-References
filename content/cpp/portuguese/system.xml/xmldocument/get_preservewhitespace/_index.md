## XmlDocument::get_PreserveWhitespace() método

Retorna um valor que indica se deve preservar espaços em branco no conteúdo do elemento.

```cpp
bool System::Xml::XmlDocument::get_PreserveWhitespace()
```

### Valor de Retorno

**true** para preservar espaços em branco; caso contrário **false**. O padrão é **false**.
