## XmlValidatingReader::get_NamespaceURI() método

Retorna o identificador uniforme de recursos de namespace (URI) (conforme definido na especificação de namespace do Consórcio World Wide [Web](../../../system.web/) (W3C)) do nó no qual o leitor está posicionado.

```cpp
String System::Xml::XmlValidatingReader::get_NamespaceURI() override
```

### Valor de Retorno

O URI do namespace do nó atual; caso contrário, uma string vazia.
