## XmlValidatingReader::get_IsEmptyElement() método

Retorna um valor que indica se o nó atual é um elemento vazio (por exemplo, **<MyElement/>**).

```cpp
bool System::Xml::XmlValidatingReader::get_IsEmptyElement() override
```

### Valor de Retorno

**true** se o nó atual for um elemento ([XmlValidatingReader::get_NodeType](../get_nodetype/) valor igual a [XmlNodeType::Element](../../xmlnodetype/)) que termina com **/>**; caso contrário, **false**.
