## XmlValidatingReader::MoveToElement() método


Move-se para o elemento que contém o nó de atributo atual.

```cpp
bool System::Xml::XmlValidatingReader::MoveToElement() override
```


### Valor de Retorno

**true** se o leitor estiver posicionado em um atributo (o leitor move-se para o elemento que possui o atributo); **false** se o leitor não estiver posicionado em um atributo (a posição do leitor não muda).
