## XmlValidatingReader::get_CanReadBinaryContent() método

Retorna um valor indicando se o [XmlValidatingReader](../) implementa os métodos de leitura de conteúdo binário.

```cpp
bool System::Xml::XmlValidatingReader::get_CanReadBinaryContent() override
```

### Valor de Retorno

**true** se os métodos de leitura de conteúdo binário forem implementados; caso contrário **false**. A classe [XmlValidatingReader](../) retorna **true**.
