## XmlValidatingReader::get_HasValue() método

Retorna um valor indicando se o nó atual pode ter um [XmlValidatingReader::get_Value](../get_value/) diferente de [String::Empty](../../../system/string/empty/).

```cpp
bool System::Xml::XmlValidatingReader::get_HasValue() override
```

### Valor de Retorno

**true** se o nó no qual o leitor está atualmente posicionado pode ter um **Value**; caso contrário, **false**.
