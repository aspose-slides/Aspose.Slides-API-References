## NamespaceHandling enum

Especifica se deve remover declarações de namespace duplicadas no [XmlWriter](../xmlwriter/).

```cpp
enum class NamespaceHandling
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Default | 0 | Especifica que declarações de namespace duplicadas não serão removidas. |
| OmitDuplicates | 1 | Especifica que declarações de namespace duplicadas serão removidas. Para que o namespace duplicado seja removido, o prefixo e o namespace devem coincidir. |
