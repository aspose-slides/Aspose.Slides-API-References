## XmlReaderSettings::get_ProhibitDtd() método

Retorna um valor que indica se o processamento de definição de tipo de documento (DTD) deve ser proibido.

```cpp
bool System::Xml::XmlReaderSettings::get_ProhibitDtd()
```

### Valor de Retorno

**true** para proibir o processamento de DTD; caso contrário **false**. O padrão é **true**.

Obsoleto
:   Este método está obsoleto. Use [XmlTextReader::get_DtdProcessing](../../xmltextreader/get_dtdprocessing/) em vez disso.
