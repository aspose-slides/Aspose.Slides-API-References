## XmlReaderSettings::get_IgnoreWhitespace() method

Retorna um valor que indica se deve ignorar espaços em branco insignificantes.

```cpp
bool System::Xml::XmlReaderSettings::get_IgnoreWhitespace()
```

### Valor de Retorno

**true** para ignorar espaços em branco; caso contrário, **false**. O padrão é **false**.
