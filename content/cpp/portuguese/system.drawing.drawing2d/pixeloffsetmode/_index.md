## PixelOffsetMode enum

Especifica como os pixels são deslocados ao serem renderizados.

```cpp
enum class PixelOffsetMode
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Invalid | n/a | Valor inválido. |
| Default | n/a | O modo padrão. |
| HighSpeed | n/a | Modo de baixa qualidade (alto desempenho). |
| HighQuality | n/a | Modo de alta qualidade (menor desempenho). |
| None | n/a | Sem deslocamento de pixel. |
| Half | n/a | Os pixels são deslocados em -0.5 unidades tanto horizontalmente quanto verticalmente para anti-aliasing de alto desempenho. |
