## LineCap enum

Indica os estilos de extremidade disponíveis com os quais um objeto [Pen](../../system.drawing/pen/) pode terminar uma linha.

```cpp
enum class LineCap
```

### Valores

| Name | Value | Description |
| --- | --- | --- |
| Flat | 0 | Extensão de linha plana. |
| Square | 1 | Extensão de linha quadrada. |
| Round | 2 | Extensão de linha arredondada. |
| Triangle | 3 | Extensão de linha triangular. |
| NoAnchor | 16 | Sem âncora. |
| SquareAnchor | 17 | Extensão de linha de âncora quadrada. |
| RoundAnchor | 18 | Extensão de linha de âncora arredondada. |
| DiamondAnchor | 19 | Extensão de linha de âncora em forma de diamante. |
| ArrowAnchor | 20 | Extensão de linha de âncora em forma de seta. |
| AnchorMask | 240 | Máscara usada para verificar se uma extremidade de linha é uma extremidade de âncora. |
| Custom | 255 | Extensão personalizada. |
