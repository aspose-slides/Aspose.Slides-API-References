## PenAlignment enum

Especifica o alinhamento de um objeto [Pen](../../system.drawing/pen/) em relação a uma linha de referência abstrata de largura 0.

```cpp
enum class PenAlignment
```

### Valores

| Name | Value | Description |
| --- | --- | --- |
| Center | 0 | O [Pen](../../system.drawing/pen/) é posicionado no centro da linha de referência. |
| Inset | 1 | O [Pen](../../system.drawing/pen/) é posicionado na parte interna da linha de referência. |
| Outset | 2 | O [Pen](../../system.drawing/pen/) é posicionado na parte externa da linha de referência. |
| Left | 3 | O [Pen](../../system.drawing/pen/) é posicionado à esquerda da linha de referência. |
| Right | 4 | O [Pen](../../system.drawing/pen/) é posicionado à direita da linha de referência. |
