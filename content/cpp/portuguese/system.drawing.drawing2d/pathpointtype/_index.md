## PathPointType enum

Especifica o tipo de um ponto de caminho.

```cpp
enum class PathPointType
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Start | 0 | O ponto inicial. |
| Line | 1 | Um segmento de linha. |
| Bezier | 3 | Curva de Bezier. |
| PathTypeMask | 7 | Um ponto de máscara de tipo. |
| DashMode | 16 | Especifica que um segmento é tracejado. |
| PathMarker | 32 | Um marcador de caminho. |
| CloseSubpath | 128 | O ponto final de um subcaminho. |
| Bezier3 | 3 | Curva de Bezier cúbica. |
