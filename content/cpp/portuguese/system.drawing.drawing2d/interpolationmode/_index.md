## InterpolationMode enum

Especifica um algoritmo a ser usado quando as imagens são rotacionadas ou dimensionadas.

```cpp
enum class InterpolationMode
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Invalid | n/a | Equivalente a [QualityMode::Invalid](../qualitymode/). |
| Default | n/a | Modo padrão. |
| Low | n/a | Baixa qualidade. |
| High | n/a | Alta qualidade. |
| Bilinear | n/a | Interpolação bilinear. |
| Bicubic | n/a | Interpolação bicúbica. |
| NearestNeighbor | n/a | Interpolação do vizinho mais próximo. |
| HighQualityBilinear | n/a | Interpolação bilinear de alta qualidade. |
| HighQualityBicubic | n/a | Interpolação bicúbica de alta qualidade. |
