## SmoothingMode enum

Especifica que tipo de suavização (antialiasing) é aplicada a linhas, curvas e bordas de áreas preenchidas.

```cpp
enum class SmoothingMode
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Invalid | n/a | Valor inválido. |
| Default | n/a | Modo padrão, sem antialiasing. |
| HighSpeed | n/a | Sem antialiasing, alta velocidade. |
| HighQuality | n/a | Renderização com antialiasing, baixa velocidade. |
| None | n/a | Sem antialising. |
| AntiAlias | n/a | Renderização com antialiasing. |
