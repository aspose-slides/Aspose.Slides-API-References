## Método Timer::set_Enabled(bool)

Inicia ou para o temporizador. Iniciar o temporizador não reinicia a contagem de tempo se o temporizador já estiver em execução.

```cpp
void System::Timers::Timer::set_Enabled(bool value)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| value | **bool** | true para iniciar o temporizador, false para parar. |
