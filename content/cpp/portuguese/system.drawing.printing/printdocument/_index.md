## PrintDocument classe


Envia saída para uma impressora, ao imprimir de uma aplicação [Windows](../../system.windows/) Forms. Objetos desta classe devem ser alocados apenas usando a função [System::MakeObject()](../../system/makeobject/). Nunca crie instância deste tipo na pilha ou usando o operador new, pois isso resultará em erros de tempo de execução e/ou falhas de asserção. Sempre encapsule esta classe em um ponteiro [System::SmartPtr](../../system/smartptr/) e use esse ponteiro para passá-la a funções como argumento.

```cpp
class PrintDocument : public System::Object
```
