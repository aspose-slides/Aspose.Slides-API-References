## PrintRange enum

Especifica quais páginas são impressas.

```cpp
enum class PrintRange
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| AllPages | 0 | Imprime todas as páginas. |
| Selection | 1 | Imprime as páginas selecionadas. |
| SomePages | 2 | Imprime páginas do intervalo especificado. |
| CurrentPage | 4194304 | Imprime a página atualmente exibida. |
