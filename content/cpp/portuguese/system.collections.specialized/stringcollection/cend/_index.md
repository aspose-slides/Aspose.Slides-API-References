## StringCollection::cend() const método

Retorna um iterador para o elemento que segue o último elemento do contêiner. Este elemento funciona como um marcador de posição; tentar acessá-lo resulta em comportamento indefinido.

```cpp
const_iterator System::Collections::Specialized::StringCollection::cend() const noexcept
```

### Valor de Retorno

Um iterador apontando para o elemento teórico const-qualificado colocado após o último elemento do contêiner.
