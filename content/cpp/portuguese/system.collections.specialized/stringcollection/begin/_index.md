## StringCollection::begin() método

Retorna um iterador para o primeiro elemento do contêiner. Se o contêiner estiver vazio, o iterador retornado será igual a [end()](../end/).

```cpp
iterator System::Collections::Specialized::StringCollection::begin() noexcept
```

### Valor de Retorno

Um iterador apontando para o primeiro elemento do contêiner.

## StringCollection::begin() const método

Retorna um iterador para o primeiro elemento do contêiner qualificado como const. Se o contêiner estiver vazio, o iterador retornado será igual a [end()](../end/).

```cpp
const_iterator System::Collections::Specialized::StringCollection::begin() const noexcept
```

### Valor de Retorno

Um iterador apontando para o primeiro elemento do contêiner qualificado como const.
