## CancellationToken::get_CanBeCanceled() const método


Obtém se este token pode estar no estado cancelado.

```cpp
bool System::Threading::CancellationToken::get_CanBeCanceled() const
```


### Valor de retorno

true se este token puder estar no estado cancelado; caso contrário, false.
## Observações



Tokens criados a partir de [CancellationTokenSource](../../cancellationtokensource/) retornam true, enquanto o token None sempre retornará false.
