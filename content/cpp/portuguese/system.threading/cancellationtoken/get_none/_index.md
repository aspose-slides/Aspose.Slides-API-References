## CancellationToken::get_None() método


Retorna um valor [System::Threading::CancellationToken](../) vazio.

```cpp
static CancellationToken System::Threading::CancellationToken::get_None()
```


### Valor de Retorno

Um token de cancelamento vazio que não pode ser cancelado.
## Observações



O token retornado nunca mudará para um estado cancelado.
