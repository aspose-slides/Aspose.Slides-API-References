## Detalhes_SynchronizationLockException::Is(const System::TypeInfo\&) const method

```cpp
bool System::Threading::Details_SynchronizationLockException::Is(const System::TypeInfo &target) const override
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| target | const [System::TypeInfo](../../../system/typeinfo/)\& | [TypeInfo](../../../system/typeinfo/) estrutura que descreve o tipo a ser testado contra o objeto atual. |

### Valor de Retorno

True se o objeto for do tipo marcado ou de sua subclasse, false caso contrário.

## Observações

Verifica se o objeto representa uma instância do tipo descrito por targetType. Análogo ao operador 'is' do C#.
