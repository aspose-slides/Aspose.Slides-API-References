## CancellationTokenRegistration::Dispose() método


Descarta o registro e remove a callback do [CancellationTokenSource](../../cancellationtokensource/) associado. Após chamar este método, a callback registrada não será mais invocada quando o [CancellationTokenSource](../../cancellationtokensource/) associado for cancelado.

```cpp
void System::Threading::CancellationTokenRegistration::Dispose()
```

## Observações



É seguro chamar este método várias vezes - chamadas subsequentes não terão efeito.
