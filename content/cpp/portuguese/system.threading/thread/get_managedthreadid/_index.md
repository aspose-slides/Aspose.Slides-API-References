## Thread::get_ManagedThreadId() const método

Obtém o identificador da thread. Pode ser obtido do SO, mas se o identificador da thread do SO exceder os limites de int, os ids das threads podem se sobrepor.

```cpp
int System::Threading::Thread::get_ManagedThreadId() const
```

### Valor de Retorno

Identificador de thread pseudo-único.
