## SlideShowTransition::set_SoundIsBuiltIn(bool) método


Especifica se este som é ou não um som incorporado. Se este atributo for definido como true, a aplicação geradora será notificada para verificar o atributo name especificado para este som em sua lista de sons incorporados e poderá então apresentar um nome ou UI personalizados, conforme necessário. Escreve **bool**.
