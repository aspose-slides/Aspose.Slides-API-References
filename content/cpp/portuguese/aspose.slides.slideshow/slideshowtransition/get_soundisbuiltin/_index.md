## SlideShowTransition::get_SoundIsBuiltIn() método

Especifica se este som é ou não um som embutido. Se este atributo for definido como true, a aplicação geradora é avisada para verificar o atributo name especificado para este som em sua lista de sons embutidos e pode então exibir um nome ou interface personalizada conforme necessário. Lê **bool**.
