## Classes

| Classe | Descrição |
| --- | --- |
| [Soap](./soap/) | Contém as constantes de string do SOAP. |
| [Soap12](./soap12/) | Contém as constantes de string da versão 1.2 do SOAP. |
| [WebServiceAttribute](./webserviceattribute/) | Adiciona informações adicionais ao serviço XML [Web](../system.web/). Objetos desta classe devem ser alocados apenas usando a função [System::MakeObject()](../system/makeobject/). Nunca crie instâncias desse tipo na pilha ou usando o operador new, pois isso resultará em erros de tempo de execução e/ou falhas de asserção. Sempre envolva esta classe em um ponteiro [System::SmartPtr](../system/smartptr/) e use esse ponteiro para passá-lo a funções como argumento. |
| [WebServiceBindingAttribute](./webservicebindingattribute/) | Usado para declarar uma ligação que define um ou mais métodos do serviço XML [Web](../system.web/). Objetos desta classe devem ser alocados apenas usando a função [System::MakeObject()](../system/makeobject/). Nunca crie instâncias desse tipo na pilha ou usando o operador new, pois isso resultará em erros de tempo de execução e/ou falhas de asserção. Sempre envolva esta classe em um ponteiro [System::SmartPtr](../system/smartptr/) e use esse ponteiro para passá-lo a funções como argumento. |
