## XmlDsigC14NTransform classe

Representa a transformação de canonização XML C14N para uma assinatura digital sem comentários. Objetos desta classe devem ser alocados apenas usando a função [System::MakeObject()](../../system/makeobject/). Nunca crie instâncias deste tipo na pilha ou usando o operador new, pois isso resultará em erros de tempo de execução e/ou falhas de asserção. Sempre encapsule esta classe em um ponteiro [System::SmartPtr](../../system/smartptr/) e use esse ponteiro para passá-lo a funções como argumento.

```cpp
class XmlDsigC14NTransform : public System::Security::Cryptography::Xml::Transform
```
