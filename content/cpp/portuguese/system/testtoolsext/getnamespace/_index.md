## TestToolsExt::GetNamespace(const char *, const char *, std::string\&) método

Recupera o namespace do teste especificado.

```cpp
static bool System::TestToolsExt::GetNamespace(const char *class_name, const char *method_name, std::string &name_space)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| class_name | const char * | Classe a ser procurada. |
| method_name | const char * | Método a ser procurado. |
| name_space | std::string\& | Variável para colocar o nome do namespace, se encontrado. |

### Valor de Retorno

Verdadeiro se o método de teste for encontrado, falso caso contrário.
