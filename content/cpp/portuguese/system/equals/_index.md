## System::Equals(const TA\&, const TB\&) função

Determina a igualdade de dois valores aplicando [operator==()](../operator_equal_equal/) a eles.

```cpp
template<typename TA,typename TB> bool System::Equals(const TA &a, const TB &b)
```

### Parâmetros de modelo

| Parâmetro | Descrição |
| --- | --- |
| TA | O tipo do primeiro comparando |
| TB | O tipo do segundo comparando |

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| a | const TA\& | O primeiro comparando |
| b | const TB\& | O segundo comparando |

### Valor de Retorno

O valor booleano retornado por [operator==()](../operator_equal_equal/) aplicado a **a** e **b**
