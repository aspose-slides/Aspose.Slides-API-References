## Boolean::TryParse(const String\&, bool\&) método


Converte a string especificada para um valor do tipo bool.

```cpp
static bool System::Boolean::TryParse(const String &value, bool &result)
```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| value | const [String](../../string/)\& | A string a ser convertida. |
| result | **bool**\& | A referência a uma variável bool onde o resultado da conversão é colocado; o resultado é true se a string especificada for igual a \"True\" e false se a string especificada for igual a \"False\". |

### Valor de Retorno

True se a string especificada for igual a \"True\" ou \"False\", caso contrário - false.
