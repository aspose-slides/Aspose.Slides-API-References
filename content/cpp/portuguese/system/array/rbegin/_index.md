## Array::rbegin() método

Retorna um iterador reverso para o primeiro elemento do contêiner invertido. Corresponde ao último elemento do contêiner não invertido. Se o contêiner estiver vazio, o iterador retornado será igual a [rend()](../rend/).

```cpp
reverse_iterator System::Array<T>::rbegin() noexcept
```

### Valor de Retorno

Um iterador apontando para o último elemento do contêiner.

## Array::rbegin() const método

Retorna um iterador reverso para o primeiro elemento do contêiner invertido. Corresponde ao último elemento do contêiner não invertido. Se o contêiner estiver vazio, o iterador retornado será igual a [rend()](../rend/).

```cpp
const_reverse_iterator System::Array<T>::rbegin() const noexcept
```

### Valor de Retorno

Um iterador apontando para o último elemento do contêiner qualificado como const.
