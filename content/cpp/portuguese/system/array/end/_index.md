## Array::end() método


Retorna um iterador para o elemento que segue o último elemento do contêiner. Este elemento funciona como um espaço reservado; tentar acessá-lo resulta em comportamento indefinido.

```cpp
iterator System::Array<T>::end() noexcept
```


### Valor de Retorno

Um iterador apontando para o elemento teórico colocado após o último elemento do contêiner.
