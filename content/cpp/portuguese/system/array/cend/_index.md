## Array::cend() const método

Retorna um iterador para o elemento que segue o último elemento do contêiner. Esse elemento funciona como um marcador; tentar acessá-lo resulta em comportamento indefinido.

```cpp
const_iterator System::Array<T>::cend() const noexcept
```

### Valor de retorno

Um iterador apontando para o elemento teórico const-qualificado colocado após o último elemento do contêiner.
