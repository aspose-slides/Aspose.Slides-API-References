## Array::crbegin() const método

Retorna um iterador reverso para o primeiro elemento do contêiner invertido. Corresponde ao último elemento do contêiner não invertido. Se o contêiner estiver vazio, o iterador retornado será igual a [crend()](../crend/).

```cpp
const_reverse_iterator System::Array<T>::crbegin() const noexcept
```

### Valor de Retorno

Um iterador apontando para o último elemento qualificado como const do contêiner.
