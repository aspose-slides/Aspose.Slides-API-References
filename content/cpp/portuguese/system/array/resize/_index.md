## Array::Resize(ArrayPtr\<Type\>\&, int) método

Altera o tamanho do array especificado para o valor especificado ou cria um novo array com o tamanho especificado.

```cpp
template<typename Type> static void System::Array<T>::Resize(ArrayPtr<Type> &arr, int new_size)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| arr | [ArrayPtr](../../arrayptr/)\<[Type](../../object/type/)\>\& | [Array](../) para redimensionar. Se **arr** for ponteiro nulo, o novo array será criado |
| new_size | int | O novo tamanho do array, ou o tamanho do novo array se **arr** for nulo |
