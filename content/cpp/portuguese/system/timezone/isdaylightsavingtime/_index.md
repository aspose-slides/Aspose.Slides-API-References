## TimeZone::IsDaylightSavingTime(DateTime) método


Determina se o valor de data e hora representado pelo objeto [DateTime](../../datetime/) especificado está dentro do intervalo de horário de verão para o fuso horário representado pelo objeto [TimeZone](../) atual.

```cpp
virtual bool System::TimeZone::IsDaylightSavingTime(DateTime time)=0
```


### Valor de Retorno

True se o valor de data e hora representado pelo objeto [DateTime](../../datetime/) especificado está dentro do intervalo de horário de verão do fuso horário representado pelo objeto [TimeZone](../) atual, caso contrário - false
