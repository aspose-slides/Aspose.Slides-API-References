## DateTime::FromUnixTime(time_t) método

Converte o valor Unix de tempo especificado para uma instância da classe [DateTime](../). PARA USO INTERNO.

```cpp
static DateTime System::DateTime::FromUnixTime(time_t value)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| value | time_t | Valor Unix de tempo a ser convertido |

### Valor de Retorno

Uma nova instância da classe [DateTime](../) que representa a mesma data e hora que **value**
