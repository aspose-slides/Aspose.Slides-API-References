## DateTime::Equals(DateTime) const método

Determina se a instância especificada da classe [DateTime](../) representa o mesmo valor de data e hora que o objeto atual.

```cpp
constexpr bool System::DateTime::Equals(DateTime other) const
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| other | [DateTime](../) | A instância da classe [DateTime](../) para comparar com o objeto atual |

### Valor de Retorno

Verdadeiro se tanto **other** quanto o objeto atual representarem o mesmo valor; caso contrário, falso
