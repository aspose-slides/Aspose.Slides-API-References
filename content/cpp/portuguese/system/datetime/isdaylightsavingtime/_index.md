## DateTime::IsDaylightSavingTime() const método

Determina se o valor de data e hora representado pelo objeto atual está dentro do intervalo do horário de verão para o fuso horário atual.

```cpp
bool System::DateTime::IsDaylightSavingTime() const
```

### Valor de Retorno

True se o valor de data e hora especificado pelo objeto atual estiver dentro do intervalo do horário de verão, caso contrário - false
