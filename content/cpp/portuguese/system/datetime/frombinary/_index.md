## DateTime::FromBinary(int64_t) método

Desserializa o valor de data e hora a partir do inteiro sem sinal de 64 bits especificado e define a nova instância da classe [DateTime](../) para esse valor.

```cpp
static DateTime System::DateTime::FromBinary(int64_t value)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| value | **int64_t** | O inteiro de 64 bits do qual desserializar o valor de data e hora |

### Valor de Retorno

Uma nova instância da classe [DateTime](../) representando o valor de data e hora desserializado a partir do inteiro sem sinal de 64 bits especificado
