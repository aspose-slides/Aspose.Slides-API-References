## DateTime::CompareTo(DateTime) const método

Compara dois valores de data e hora representados pelo objeto atual e a instância especificada da classe [DateTime](../) e retorna o valor que indica as posições relativas dos valores na linha do tempo.

```cpp
constexpr int System::DateTime::CompareTo(DateTime value) const
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| value | [DateTime](../) | Uma instância da classe [DateTime](../) para comparar com o objeto atual |

### Valor de Retorno

Um valor menor que 0 se o objeto atual representa um valor que é anterior ao representado por **value**; 0 se os valores representados por ambos os objetos são iguais; um valor maior que 0 se o valor representado pelo objeto atual for posterior ao representado por **value**.
