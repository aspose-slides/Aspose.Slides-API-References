## DateTime::Compare(DateTime, DateTime) método


Compara dois valores representados pelas instâncias especificadas da classe [DateTime](../) e retorna o valor que indica as posições relativas dos valores na linha do tempo.

```cpp
static constexpr int System::DateTime::Compare(DateTime t1, DateTime t2)
```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| t1 | [DateTime](../) | O primeiro comparando |
| t2 | [DateTime](../) | O segundo comparando |

### Valor de Retorno

Um valor menor que 0 se **t1** for anterior a **t2**; 0 se **t1** for o mesmo que **t2**; um valor maior que 0 se **t1** for posterior a **t2**
