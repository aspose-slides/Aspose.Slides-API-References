## SmartPtrInfo::operator!() const método


Verifica se o objeto info não aponta para um ponteiro não nulo.

```cpp
bool System::SmartPtrInfo::operator!() const
```


### Valor de retorno

Falso se o objeto info não apontar para nenhum ponteiro ou se o ponteiro referenciado for nulo, verdadeiro caso contrário.
