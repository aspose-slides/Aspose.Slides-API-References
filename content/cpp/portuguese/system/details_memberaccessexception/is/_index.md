## Details_MemberAccessException::Is(const System::TypeInfo\&) const method

```cpp
bool System::Details_MemberAccessException::Is(const System::TypeInfo &target) const override
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) estrutura que descreve o tipo contra o qual testar o objeto atual. |

### Valor de Retorno

True if object is of tagged type or its subclass, false otherwise.

## Observações

Verifica se o objeto representa uma instância do tipo descrito por targetType. Análogo ao operador 'is' do C#.
