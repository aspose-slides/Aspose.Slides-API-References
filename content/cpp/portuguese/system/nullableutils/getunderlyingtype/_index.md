## NullableUtils::GetUnderlyingType(const System::TypeInfo\&) método


Retorna o argumento de tipo subjacente do tipo anulável especificado.

```cpp
static const System::TypeInfo & System::NullableUtils::GetUnderlyingType(const System::TypeInfo &nullableType)
```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| nullableType | const [System::TypeInfo](../../typeinfo/)\& | Um objeto System.Type que descreve um tipo anulável genérico fechado. |

### Valor de Retorno

O argumento de tipo do parâmetro nullableType, se o parâmetro nullableType for um tipo anulável genérico fechado; caso contrário, null
