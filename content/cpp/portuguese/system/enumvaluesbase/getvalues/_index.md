## EnumValuesBase::GetValues(const TypeInfo\&) método

Retorna um array contendo todos os valores do tipo de enumeração especificado.

```cpp
static ArrayPtr<int64_t> System::EnumValuesBase::GetValues(const TypeInfo &type)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| type | const [TypeInfo](../../typeinfo/)\& | O objeto [TypeInfo](../../typeinfo/) que representa o tipo da enumeração cujos valores devem ser retornados |

### Valor de Retorno

Um array contendo valores de todas as constantes de enumeração do tipo de enumeração especificado por **type**.
