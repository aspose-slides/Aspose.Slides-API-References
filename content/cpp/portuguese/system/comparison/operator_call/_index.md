## Comparison::operator()(T, T) método

Invoca o objeto invocável apontado pelo objeto atual.

```cpp
bool System::Comparison<T>::operator()(T a, T b)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| a | T | O primeiro comparando |
| b | T | O segundo comparando |

### Valor de Retorno

Verdadeiro se **a** for menor que **b**, caso contrário - true
