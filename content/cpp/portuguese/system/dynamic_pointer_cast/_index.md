## System::dynamic_pointer_cast(SmartPtr\<X\> const\&) função


Converte ponteiros inteligentes usando dynamic_cast.

```cpp
template<class Y,class X> SmartPtr<Y> System::dynamic_pointer_cast(SmartPtr<X> const &x)
```


### Parâmetros do modelo

| Parâmetro | Descrição |
| --- | --- |
| X | Tipo do objeto apontado pelo ponteiro de origem. |
| Y | Tipo do objeto apontado pelo ponteiro de destino. |

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| x | [SmartPtr](../smartptr/)\<X\> const\& | Ponteiro de origem. |

### Valor de retorno

Ponteiro após a conversão.
