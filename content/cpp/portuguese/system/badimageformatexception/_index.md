## BadImageFormatException typedef

A exceção que é lançada quando a imagem de arquivo de uma biblioteca de vínculo dinâmico (DLL) ou de um programa executável é inválida. Nunca encapsule as instâncias da classe BadImageFormatException em [System::SmartPtr](../smartptr/).

```cpp
using System::BadImageFormatException = typedef System::ExceptionWrapper<Details_BadImageFormatException>
```
