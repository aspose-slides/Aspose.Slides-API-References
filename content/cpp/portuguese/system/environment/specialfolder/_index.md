## SpecialFolder enum

Representa pastas especiais do sistema.

```cpp
enum class SpecialFolder
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Desktop | 0 | A área de trabalho lógica. |
| Programs | 2 | A pasta que contém os grupos de programas do usuário. |
| Personal | 5 | A pasta que serve como repositório comum para documentos. |
| MyDocuments | 5 | O diretório "Meus Documentos". |
| Favorites | 6 | A pasta que serve como repositório comum para os itens favoritos do usuário. |
| Startup | 7 | A pasta que corresponde ao grupo de programas de Inicialização do usuário. |
| Recent | 8 | A pasta que contém os documentos mais recentemente usados pelo usuário. |
| SendTo | 9 | A pasta que serve como contêiner para os itens do menu Enviar Para. |
| StartMenu | 11 | A pasta que serve como contêiner para os itens do menu Iniciar. |
| MyMusic | 13 | O diretório "Minha Música". |
| DesktopDirectory | 16 | A pasta usada para armazenar fisicamente itens na área de trabalho. |
| MyComputer | 17 | O diretório "Meu Computador". |
| Templates | 21 | A pasta que serve como contêiner comum para modelos de documento. |
| ApplicationData | 26 | A pasta usada para armazenar dados específicos da aplicação para o usuário roaming atual. |
| LocalApplicationData | 28 | A pasta usada para armazenar dados específicos da aplicação para o usuário não roaming atual. |
| InternetCache | 32 | A pasta usada como armazenamento para arquivos temporários da Internet. |
| Cookies | 33 | A pasta usada como armazenamento para cookies da Internet. |
| History | 34 | A pasta usada como armazenamento para itens de histórico da Internet. |
| CommonApplicationData | 35 | A pasta usada para armazenar dados específicos da aplicação que são usados por todos os usuários. |
| System | 37 | A pasta do sistema. |
| ProgramFiles | 38 | A pasta de arquivos de programa. |
| MyPictures | 39 | A pasta "Minhas imagens". |
| UserProfile | 40 | A pasta de perfil do usuário. |
| CommonProgramFiles | 43 | O diretório usado como armazenamento para componentes compartilhados por aplicações. |
