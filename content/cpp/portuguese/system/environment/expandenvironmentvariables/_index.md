## Environment::ExpandEnvironmentVariables(const String\&) método

Substitui os nomes das variáveis de ambiente encontradas na string especificada pelos valores dessas variáveis e retorna a string resultante.

```cpp
static String System::Environment::ExpandEnvironmentVariables(const String &name)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| name | const [String](../../string/)\& | A string que contém os nomes das variáveis de ambiente |

### Valor de Retorno

A string que resulta da substituição dos nomes das variáveis em **name** pelos seus valores.
