## Environment::get_Version() método

Retorna o [Version](../../version/) objeto que representa as informações sobre a versão do runtime de linguagem comum. O número da versão retornado por este método é bastante fictício e não significa que todas as classes da biblioteca se comportem de acordo com a versão retornada.

```cpp
static Version System::Environment::get_Version()
```
