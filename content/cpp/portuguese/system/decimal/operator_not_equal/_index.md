## Decimal::operator!=(const Decimal\&) const método


Determina se os valores representados pelo objeto atual e pelo objeto especificado não são iguais.

```cpp
bool System::Decimal::operator!=(const Decimal &d) const
```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| d | const [Decimal](../)\& | O objeto [Decimal](../) para comparar com o objeto atual |

### Valor de Retorno

True se o valor representado pelos objetos atual e especificado não são iguais, caso contrário - false

```cpp
bool System::Decimal::operator!=(std::nullptr_t) const
```


### Valor de Retorno

True se o valor representado pelo objeto atual for diferente de 0, caso contrário - false
