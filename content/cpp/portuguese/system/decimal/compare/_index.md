## Decimal::Compare(const Decimal\&, const Decimal\&) método

Determina se o valor representado pelo primeiro objeto [Decimal](../) é menor que, igual a ou maior que o valor representado pelo segundo objeto [Decimal](../).

```cpp
static int System::Decimal::Compare(const Decimal &d1, const Decimal &d2)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| d1 | const [Decimal](../)\& | O primeiro comparando |
| d2 | const [Decimal](../)\& | O segundo comparando |

- 1 se o valor representado por **d1** for menor que o valor representado por **d2**; 0 se os valores forem iguais; 1 se o valor representado por **d1** for maior que o valor representado por **d2**
