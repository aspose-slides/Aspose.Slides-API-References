## System::BuildArray() função

Construa um array.

```cpp
template<typename T> Details::ObjectBuilder<Details::ArrayStorage<T>> System::BuildArray()
```

### Parâmetros de modelo

| Parâmetro | Descrição |
| --- | --- |
| T | Tipo de elemento do array a ser construído |

### Valor de retorno

ObjectBuilder configurado para construção de array

## Observações

Cria um ArrayPtr<T> e retorna um construtor para ele  
[Object](../object/) a construção deve ser concluída com a chamada [Get()](../get/)
