## Details_SystemException::Is(const System::TypeInfo\&) const method

```cpp
bool System::Details_SystemException::Is(const System::TypeInfo &target) const override
```

### Argumentos

| Parameter | Type | Description |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) estrutura que descreve o tipo contra o qual testar o objeto atual. |

### Valor de Retorno

True se o objeto for do tipo marcado ou de sua subclasse, false caso contrário.

## Observações

Verifique se o objeto representa uma instância do tipo descrito por targetType. Analógico do operador 'is' do C#.
