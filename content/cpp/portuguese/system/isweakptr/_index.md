## IsWeakPtr struct

Classe de traits para verificar se uma classe específica é uma especialização de [System::WeakPtr](../weakptr/). Não verifica se a instância está realmente em modo fraco.

```cpp
template<class T>class IsWeakPtr : public System::detail::is_a<T, System::WeakPtr>
```
