## Uri::IsHexEncoding(const String\&, int32_t) método


Determina se um caractere na string especificada na posição especificada está codificado em hexadecimal.

```cpp
static bool System::Uri::IsHexEncoding(const String &pattern, int32_t index)
```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| pattern | const [String](../../string/)\& | A string a ser verificada |
| index | **int32_t** | Posição baseada em zero do caractere a ser testado |

### Valor de Retorno

True se o caractere especificado estiver codificado em hexadecimal, caso contrário - false
