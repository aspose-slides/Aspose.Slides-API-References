## Version::CompareTo(const Version\&) const método

Compara as versões representadas pelo objeto atual e pelo objeto especificado.

```cpp
int System::Version::CompareTo(const Version &ver) const
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| ver | const [Version](../)\& | Um objeto [Version](../) para comparar com o objeto atual |

### Valor de Retorno

- 1 se o número da versão representado pelo objeto atual for menor que o representado por **ver**; 0 se os números das versões forem iguais; 1 se o número da versão representado pelo objeto atual for maior que o valor representado por **ver**
