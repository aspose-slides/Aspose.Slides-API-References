## Version::Parse(const String\&) método

Converte a representação em string de um número de versão em uma instância equivalente da classe [Version](../).

```cpp
static Version System::Version::Parse(const String &input)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| input | const [String](../../string/)\& | Uma string contendo a representação em string de um número de versão |

### Valor de Retorno

Uma instância da classe [Version](../) que representa o número da versão equivalente ao representado pelo **input**
