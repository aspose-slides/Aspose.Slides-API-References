## SmartPtrMode enum

[SmartPtr](../smartptr/) tipo de ponteiro: Weak ou Shared. Define se o ponteiro está sendo contado quando se decide se o objeto deve ser excluído ou não.

```cpp
enum class SmartPtrMode : char
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Shared | 0 | Shared modo: ponteiro participa da contagem de referências. |
| Weak | 1 | Weak modo: ponteiro não participa da contagem de referências. |
