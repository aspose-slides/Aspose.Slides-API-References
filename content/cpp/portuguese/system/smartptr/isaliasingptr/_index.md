## SmartPtr::IsAliasingPtr() const método

Verifica se o ponteiro aponta para outro objeto que não o de propriedade (criado por um construtor de aliasing).

```cpp
bool System::SmartPtr<T>::IsAliasingPtr() const
```

### Valor de Retorno

True se o ponteiro tem diferença entre os objetos apontado e de propriedade, false caso contrário.
