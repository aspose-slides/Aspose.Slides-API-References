## SmartPtr::get_shared_count() const method

Obtém o número de ponteiros compartilhados existentes para o objeto referenciado, incluindo o atual. Asserta que o ponteiro atual está em modo compartilhado.

```cpp
int System::SmartPtr<T>::get_shared_count() const
```

### Valor de retorno

Número de ponteiros compartilhados existentes para o objeto referenciado, se houver. Se o ponteiro for nulo, retorna 0.
