## SmartPtr::Is(const System::TypeInfo\&) const method

Checks if pointed object is of specific type or its child type. Follows C# 'is' semantics.

```cpp
bool System::SmartPtr<T>::Is(const System::TypeInfo &target) const
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | Especifica o tipo de destino a ser verificado. |

### Valor de Retorno

Verdadeiro se a verificação no estilo 'is' do C# for positiva e falso caso contrário.
