## HolderInitializer< T, false > struct

[HolderInitializer](../holderinitializer/) especialização para o caso em que T é um tipo de valor. O contexto de uso permite retornar referência a objetos temporários, pois é garantido que a instância será copiada pelo chamador. Assim, essa especialização é usada apenas como um stub e não faz nada.

```cpp
template<typename T>class HolderInitializer< T, false >
```
