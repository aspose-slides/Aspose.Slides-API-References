## Enum StringComparison

Define o estilo de comparação de strings.

```cpp
enum class StringComparison
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| CurrentCulture | 0 | Usa a cultura atual. |
| CurrentCultureIgnoreCase | 1 | Usa a cultura atual, mas ignora maiúsculas/minúsculas. |
| InvariantCulture | 2 | Usa a cultura invariável. |
| InvariantCultureIgnoreCase | 3 | Usa a cultura invariável, mas ignora maiúsculas/minúsculas. |
| Ordinal | 4 | Usa regras de ordenação ordinal. |
| OrdinalIgnoreCase | 5 | Usa regras de ordenação ordinal, mas ignora maiúsculas/minúsculas. |
