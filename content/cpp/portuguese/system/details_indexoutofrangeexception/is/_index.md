```cpp
bool System::Details_IndexOutOfRangeException::Is(const System::TypeInfo &target) const override
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) estrutura que descreve o tipo contra o qual o objeto atual deve ser testado. |

### Valor de Retorno

True se o objeto for do tipo marcado ou de sua subclasse, false caso contrário.

## Observações

Verifique se o objeto representa uma instância do tipo descrito por targetType. Análogo ao operador C# 'is'.
