## Details_RankException::Is(const System::TypeInfo\&) const method




```cpp
bool System::Details_RankException::Is(const System::TypeInfo &target) const override
```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) estrutura descrevendo o tipo contra o qual testar o objeto atual. |

### Valor de Retorno

Verdadeiro se o objeto for do tipo marcado ou de sua subclasse, falso caso contrário.
## Observações


Verifique se o objeto representa uma instância do tipo descrito por targetType. Analógico ao operador 'is' de C#.
