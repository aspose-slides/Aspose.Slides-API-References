## EnumParseHelper struct

Classe auxiliar que fornece funcionalidade para converter uma representação em string de constante enum em um valor enum equivalente.

```cpp
template<class E,class G,class Guard>class EnumParseHelper
```

### Parâmetros do modelo

| Parâmetro | Descrição |
| --- | --- |
| E | O tipo do enum com o qual os métodos da classe operam |
| G | Segundo argumento formal de [System::Enum](../enum/) a ser usado. |
| Guard | Argumento de modelo formal para selecionar o algoritmo de análise disponível. |
