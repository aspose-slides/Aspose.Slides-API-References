## BoxedValue::is() const método

Determina se o tipo do valor encapsulado representado pelo objeto atual é **V**.

```cpp
template<class V> bool System::BoxedValue<T>::is() const
```

### Parâmetros de modelo

| Parâmetro | Descrição |
| --- | --- |
| V | O tipo que é comparado com o tipo do valor encapsulado representado pelo objeto atual |

### Valor de retorno

Verdadeiro se o tipo do valor encapsulado representado pelo objeto atual for **V**, caso contrário - falso
