## Random::Random() construtor


Inicializa uma nova instância, usando um valor semente padrão dependente do tempo.

```cpp
System::Random::Random()
```

## Random::Random(int32_t) construtor


Inicializa uma nova instância da classe [System.Random](../), usando o valor da semente especificado.

```cpp
System::Random::Random(int32_t seed)
```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| seed | **int32_t** | A semente usada para gerar uma sequência de números pseudo-aleatórios |
