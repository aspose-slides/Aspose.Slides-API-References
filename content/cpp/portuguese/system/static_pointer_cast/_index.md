## System::static_pointer_cast(SmartPtr\<X\> const\&) function

Converte ponteiros inteligentes usando static_cast.

```cpp
template<class Y,class X> SmartPtr<Y> System::static_pointer_cast(SmartPtr<X> const &x)
```

### Parâmetros de modelo

| Parâmetro | Descrição |
| --- | --- |
| X | Tipo do objeto apontado pelo ponteiro de origem. |
| Y | Tipo do objeto apontado pelo ponteiro de destino. |

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| x | [SmartPtr](../smartptr/)\<X\> const\& | Ponteiro de origem. |

### Valor de retorno

Ponteiro após a conversão.
