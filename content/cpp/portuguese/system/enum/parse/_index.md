## Enum::Parse(const String\&, bool) método

Converte a string especificada em constante de enum equivalente.

```cpp
static E System::Enum<E, Guard>::Parse(const String &str, bool ignoreCase=false)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| str | const [String](../../string/)\& | [String](../../string/) que é interpretado como contendo o nome da constante de enum |
| ignoreCase | **bool** | Especifica se a diferenciação entre maiúsculas e minúsculas deve ser ignorada ao interpretar a string |

### Valor de Retorno

A constante de enumeração cujo nome está especificado em **str**
