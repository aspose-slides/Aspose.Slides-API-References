## Enum::HasFlag(E, E) método

Determina se os bits especificados estão definidos em uma representação binária do valor enum especificado.

```cpp
static bool System::Enum<E, Guard>::HasFlag(E value, E mask)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| value | E | O valor enum a ser testado |
| mask | E | A máscara usada para verificar os bits do valor |

### Valor de Retorno

Verdadeiro se os bits definidos em **mask** também estiverem definidos em **value**, caso contrário - falso
