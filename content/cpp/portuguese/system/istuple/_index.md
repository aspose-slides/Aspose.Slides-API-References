## System::IsTuple(const SharedPtr\<Object\>\&, int32_t) função


Verifica se o objeto é uma tupla (implementa a interface ITuple). Usado na implementação de padrão posicional.

```cpp
bool System::IsTuple(const SharedPtr<Object> &object, int32_t length)
```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| object | const [SharedPtr](../sharedptr/)\<[Object](../object/)\>\& | objeto a ser verificado. |
| length | **int32_t** | comprimento da tupla esperado |

### Valor de Retorno

o objeto é uma tupla e seu comprimento é igual ao esperado
