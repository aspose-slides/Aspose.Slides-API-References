## Char::IsLetter(const char_t *, int) método

Determina se o caractere no índice especificado no buffer de caracteres especificado é classificado como letra Unicode.

```cpp
static bool System::Char::IsLetter(const char_t *str, int idx)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| str | const char_t * | Ponteiro para o início do buffer de caracteres |
| idx | int | Índice baseado em zero no buffer especificado do caractere a ser testado |

### Valor de Retorno

Verdadeiro se o caractere no índice especificado for uma letra Unicode, caso contrário - falso
