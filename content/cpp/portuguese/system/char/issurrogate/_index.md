## Char::IsSurrogate(char_t) método

Determina se o caractere especificado é uma unidade de código substituta UTF-16.

```cpp
static bool System::Char::IsSurrogate(char_t c)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| c | char_t | Um caractere |

### Valor de Retorno

Verdadeiro se o caractere especificado for uma unidade de código substituta UTF-16, caso contrário - falso

## Char::IsSurrogate(const String\&, int) método

Determina se o caractere no índice especificado na string especificada é uma unidade de código substituta UTF-16.

```cpp
static bool System::Char::IsSurrogate(const String &s, int index)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| s | const [String](../../string/)\& | Uma string |
| index | int | O índice do caractere na string especificada |

### Valor de Retorno

Verdadeiro se o caractere no índice especificado for uma unidade de código substituta UTF-16, caso contrário - falso
