## Char::TryParse(const System::String\&, char_t\&) método

Tenta converter uma string que consiste em um único caractere em um caractere UTF-16. A função tem sucesso somente quando a string de entrada não é nula e tem comprimento exatamente de um caractere.

```cpp
static bool System::Char::TryParse(const System::String &s, char_t &result)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| s | const [System::String](../../string/)\& | [String](../../string/) para converter |
| result | char_t\& | A variável de saída que conterá o resultado da conversão se a conversão for bem-sucedida |

### Valor de Retorno

True se a conversão for bem-sucedida, caso contrário - false
