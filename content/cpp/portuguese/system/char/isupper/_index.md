## Char::IsUpper(const String\&, int) método


Determina se o caractere no índice especificado da string especificada é classificado como uma letra maiúscula.

```cpp
static bool System::Char::IsUpper(const String &str, int idx)
```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| str | const [String](../../string/)\& | A string que contém um caractere. |
| idx | int | Um índice baseado em zero na string especificada a ser testado |

### Valor de Retorno

True se o caractere no índice especificado for uma letra maiúscula, caso contrário - false

## Char::IsUpper(const char_t *, int) método


Determina se o caractere no índice especificado do buffer de caracteres especificado é classificado como uma letra maiúscula.

```cpp
static bool System::Char::IsUpper(const char_t *str, int idx)
```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| str | const char_t * | Ponteiro para o início do buffer de caracteres |
| idx | int | Um índice baseado em zero no buffer especificado do caractere a ser testado |

### Valor de Retorno

True se o caractere no índice especificado for uma letra maiúscula, caso contrário - false
