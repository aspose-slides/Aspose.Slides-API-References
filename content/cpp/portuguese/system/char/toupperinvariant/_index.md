## Char::ToUpperInvariant(char_t) método

Converte o caractere especificado para maiúsculas.

```cpp
static char_t System::Char::ToUpperInvariant(char_t c)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| c | char_t | Caractere a ser convertido |

### Valor de Retorno

O caractere especificado em maiúsculas se o caractere especificado for uma letra minúscula, caso contrário - o caractere especificado
