## Char::IsLetterOrDigit(const char_t *, int) method

Determina se o caractere no índice especificado no buffer de caracteres especificado é classificado como letra Unicode ou dígito decimal.

```cpp
static bool System::Char::IsLetterOrDigit(const char_t *str, int idx)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| str | const char_t * | Ponteiro para o início do buffer de caracteres |
| idx | int | Índice baseado em zero no buffer especificado do caractere a ser testado |

### Valor de Retorno

True se o caractere no índice especificado for letra Unicode ou dígito decimal, caso contrário - false
