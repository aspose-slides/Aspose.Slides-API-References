## Char::IsAsciiWhiteSpace(char_t) método

Determina se o caractere especificado é classificado como um caractere de espaço em branco ASCII.

```cpp
static constexpr bool System::Char::IsAsciiWhiteSpace(char_t c)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| c | char_t | O caractere a ser testado |

### Valor de retorno

True se o caractere especificado for um caractere de espaço em branco ASCII, caso contrário - false
