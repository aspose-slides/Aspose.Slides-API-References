## Char::IsDigit(const char_t *, int) método


Determina se o caractere no índice especificado no buffer de caracteres especificado é classificado como um dígito decimal.

```cpp
static bool System::Char::IsDigit(const char_t *str, int idx)
```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| str | const char_t * | Ponteiro para o início do buffer de caracteres |
| idx | int | Um índice baseado em zero no buffer especificado do caractere a ser testado |

### Valor de Retorno

True se o caractere no índice especificado for um dígito decimal, caso contrário - false
