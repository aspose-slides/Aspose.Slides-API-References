## Char::IsNumber(const char_t *, int) método

Determina se o caractere no índice especificado no buffer de caracteres especificado é classificado como um número.

```cpp
static bool System::Char::IsNumber(const char_t *str, int idx)
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| str | const char_t * | Ponteiro para o início do buffer de caracteres |
| idx | int | Um índice baseado em zero no buffer especificado do caractere a ser testado |

### Valor de Retorno

True se o caractere no índice especificado for um número, caso contrário - false

## Char::IsNumber(char_t) método

static bool System::Char::IsNumber(char_t c)

### Argumentos

| Parâmetro | Tipo | Descrição |
