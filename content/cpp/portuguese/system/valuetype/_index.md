## ValueType classe

Classe base para tipos de valor com [Object](../object/) herança sendo truncada por razões de desempenho. Esse tipo deve ser alocado na pilha e passado para funções por valor ou por referência. Nunca use a classe [System::SmartPtr](../smartptr/) para gerenciar objetos deste tipo.

```cpp
class ValueType
```
