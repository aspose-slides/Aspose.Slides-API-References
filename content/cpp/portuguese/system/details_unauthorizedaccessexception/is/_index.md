```cpp
bool System::Details_UnauthorizedAccessException::Is(const System::TypeInfo &target) const override
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) estrutura que descreve o tipo para testar o objeto atual contra. |

### Valor de Retorno

true se o objeto for do tipo marcado ou de sua subclasse, false caso contrário.

## Observações

Verifique se o objeto representa uma instância do tipo descrito por targetType. Análogo ao operador 'is' do C#.
