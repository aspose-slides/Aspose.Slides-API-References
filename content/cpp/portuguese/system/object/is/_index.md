## Object::Is(const TypeInfo\&) const método

Verifica se o objeto representa uma instância do tipo descrito por targetType. Análogo ao operador 'is' do C#.

```cpp
virtual bool System::Object::Is(const TypeInfo &targetType) const
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| targetType | const [TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) estrutura que descreve o tipo contra o qual o objeto atual deve ser testado. |

### Valor de Retorno

Verdadeiro se o objeto for do tipo marcado ou de sua subclasse, falso caso contrário.
