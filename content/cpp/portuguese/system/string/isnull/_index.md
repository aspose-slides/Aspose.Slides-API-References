## String::IsNull() const método

Verifica se a string é considerada nula. [String](../) é nula e somente se for construída via [String()](../string/) construtor, movida, copiada ou atribuída a partir de string nula ou [reset()](../reset/) método foi chamado.

```cpp
bool System::String::IsNull() const
```

### Valor de retorno

true se a string for considerada nula, false caso contrário.
