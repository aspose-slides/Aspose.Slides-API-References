## String::end() const método


Retorna ponteiro para o final do buffer de string atual. Nunca realoca nada. Não garante que o buffer seja terminado por nulo.

```cpp
const UChar * System::String::end() const
```


### Valor de retorno

Ponteiro para o primeiro elemento após o buffer de string atual, terminado por nulo ou não.
