## String::begin() const método


Retorna ponteiro para o início do buffer de string real. Nunca realoca nada. Não garante que o buffer seja terminado por nulo.

```cpp
const UChar * System::String::begin() const
```


### Valor de Retorno

Ponteiro para o buffer de string real, terminado por nulo ou não.
