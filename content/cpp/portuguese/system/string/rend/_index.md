## String::rend() const método

Retorna um iterador reverso para antes do primeiro caractere (se houver) do buffer de string atual.

```cpp
reverse_iterator System::String::rend() const
```

### Valor de Retorno

Iterador reverso para o elemento precedente ao primeiro caractere do buffer de string atual (se houver) ou para o elemento imediatamente antes do buffer alocado.
