## Detalhes_ArgumentOutOfRangeException::Is(const System::TypeInfo\&) const method




```cpp
bool System::Details_ArgumentOutOfRangeException::Is(const System::TypeInfo &target) const override
```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) structure describing the type to test current object against. |

### Valor de Retorno

Verdadeiro se o objeto for do tipo marcado ou de sua subclasse, falso caso contrário.
## Observações


Verifica se o objeto representa uma instância do tipo descrito por targetType. Analógico ao operador 'is' do C#.
