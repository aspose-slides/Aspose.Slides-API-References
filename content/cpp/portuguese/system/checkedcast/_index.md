## System::CheckedCast(TFrom) função


Determina se o valor especificado está dentro do intervalo de valores do tipo **TTo** e, se estiver, converte-o para o tipo **TTo**.

```cpp
template<typename TTo,typename TFrom> TTo System::CheckedCast(TFrom value)
```


### Parâmetros de modelo

| Parâmetro | Descrição |
| --- | --- |
| TTo | O tipo para o qual o valor especificado será convertido |
| TFrom | O tipo do valor especificado |

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| value | TFrom | O valor a ser convertido |

### Valor de retorno

O valor do tipo **TTo** equivalente a **value**
