## enum TypeCode

Representa o tipo de um objeto.

```cpp
enum class TypeCode
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| Empty | 0 | Uma referência nula. |
| Object | 1 | Um tipo geral que representa qualquer tipo de referência ou valor que não seja explicitamente representado por outro TypeCode. |
| DBNull | 2 | Um valor nulo de banco de dados (coluna). |
| Boolean | 3 | Um tipo simples que representa valores [Boolean](../boolean/) de verdadeiro ou falso. |
| Char | 4 | Um tipo integral que representa inteiros sem sinal de 16 bits com valores entre 0 e 65535. |
| SByte | 5 | Um tipo integral que representa inteiros com sinal de 8 bits com valores entre -128 e 127. |
| Byte | 6 | Um tipo integral que representa inteiros sem sinal de 8 bits com valores entre 0 e 255. |
| Int16 | 7 | Um tipo integral que representa inteiros com sinal de 16 bits com valores entre -32768 e 32767. |
| UInt16 | 8 | Um tipo integral que representa inteiros sem sinal de 16 bits com valores entre 0 e 65535. |
| Int32 | 9 | Um tipo integral que representa inteiros com sinal de 32 bits com valores entre -2147483648 e 2147483647. |
| UInt32 | 10 | Um tipo integral que representa inteiros sem sinal de 32 bits com valores entre 0 e 4294967295. |
| Int64 | 11 | Um tipo integral que representa inteiros com sinal de 64 bits com valores entre -9223372036854775808 e 9223372036854775807. |
| UInt64 | 12 | Um tipo integral que representa inteiros sem sinal de 64 bits com valores entre 0 e 18446744073709551615. |
| Single | 13 | Um tipo de ponto flutuante que representa valores variando aproximadamente de 1.5 x 10 -45 a 3.4 x 10 38 com precisão de 7 dígitos. |
| Double | 14 | Um tipo de ponto flutuante que representa valores variando aproximadamente de 5.0 x 10 -324 a 1.7 x 10 308 com precisão de 15-16 dígitos. |
| Decimal | 15 | Um tipo simples que representa valores variando de 1.0 x 10 -28 a aproximadamente 7.9 x 10 28 com 28-29 dígitos significativos. |
| DateTime | 16 | Um tipo que representa um valor de data e hora. |
| String | 18 | Um tipo de classe selada que representa cadeias de caracteres Unicode. |
