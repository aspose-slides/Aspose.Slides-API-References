## Math::Min_(float, float) método


Retorna o menor valor de ponto flutuante de precisão simples entre os dois especificados.

```cpp
float System::Math::Min_(float val1, float val2)
```


### Argumentos

| Parameter | Type | Description |
| --- | --- | --- |
| val1 | **float** | O primeiro comparando |
| val2 | **float** | O segundo comparando |

### Valor de Retorno

O menor valor entre **val1** e **val2**; ou NaN se um dos operandos for NaN
