## EnumGetNameHelper::GetName(T) método

Retorna o nome da string do valor constante do enum especificado.

```cpp
template<class T> static String System::EnumGetNameHelper<E, G, Guard>::GetName(T value)
```

### Parâmetros do modelo

| Parâmetro | Descrição |
| --- | --- |
| T | O tipo de valores de enum aceitos pelo método; **T** deve ser conversível para **E** |

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| value | T | O valor constante do enum cujo nome de string deve ser obtido |

### Valor de retorno

Um nome de string do valor constante do enum especificado
