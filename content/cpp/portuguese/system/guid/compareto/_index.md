## Guid::CompareTo(const Guid\&) const método

Realiza comparação aritmética dos GUIDs representados pelo objeto atual e pelo objeto especificado.

```cpp
int System::Guid::CompareTo(const Guid &g) const
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| g | const [Guid](../)\& | O comparando |

### Valor de Retorno

- 1 se o GUID representado pelo objeto atual for menor que o GUID representado por **g**; 0 se os GUIDs forem iguais; 1 se o GUID representado pelo objeto atual for maior que o GUID representado por **g**
