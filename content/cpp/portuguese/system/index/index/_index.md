## Index::Index(int32_t) construtor

Constrói uma instância que representa a posição especificada a partir do início de uma coleção.

```cpp
constexpr System::Index::Index(int32_t value) noexcept
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| value | **int32_t** | O índice baseado em zero a partir do início. |

## Index::Index(int32_t, bool) construtor

Constrói uma instância que representa o índice especificado.

```cpp
constexpr System::Index::Index(int32_t value, bool from_end) noexcept
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| value | **int32_t** | O valor do índice. |
| from_end | **bool** | Verdadeiro se o índice for relativo ao final da coleção. |
