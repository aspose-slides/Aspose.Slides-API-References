## DBNull classe


Representa um valor inexistente. Objetos desta classe devem ser alocados somente usando a função [System::MakeObject()](../makeobject/). Nunca crie instância deste tipo na pilha ou usando o operador new, pois isso resultará em erros de tempo de execução e/ou falhas de asserção. Sempre encapsule esta classe em um ponteiro [System::SmartPtr](../smartptr/) e use esse ponteiro para passá-lo a funções como argumento.

```cpp
class DBNull : public System::Object
```
