## System::GEqual(const ExpressionT\&, const ConstantT\&) função

Implementa a tradução de padrão relativo '>='.

```cpp
template<class ExpressionT,class ConstantT> bool System::GEqual(const ExpressionT &left, const ConstantT &constant)
```

### Parâmetros de modelo

| Parameter | Description |
| --- | --- |
| ExpressionT | tipo da expressão da esquerda. |
| ConstantT | tipo da expressão constante. |

### Argumentos

| Parameter | Type | Description |
| --- | --- | --- |
| left | const ExpressionT\& | expressão que será verificada. |
| constant | const ConstantT\& | expressão que será comparada com a da esquerda. |

### Valor de retorno

true se a verificação de tipo for bem-sucedida, false caso contrário.
