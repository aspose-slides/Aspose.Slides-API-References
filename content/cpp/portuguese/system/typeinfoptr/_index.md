## TypeInfoPtr struct

Wrapper para um ponteiro a uma instância da classe [TypeInfo](../typeinfo/). Este tipo deve ser alocado na pilha e passado para funções por valor ou por referência. Nunca use a classe [System::SmartPtr](../smartptr/) para gerenciar objetos deste tipo.
