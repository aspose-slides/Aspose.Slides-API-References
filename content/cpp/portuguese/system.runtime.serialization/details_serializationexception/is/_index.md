## Details_SerializationException::Is(const System::TypeInfo\&) const method

```cpp
bool System::Runtime::Serialization::Details_SerializationException::Is(const System::TypeInfo &target) const override
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| target | const [System::TypeInfo](../../../system/typeinfo/)\& | [TypeInfo](../../../system/typeinfo/) estrutura descrevendo o tipo contra o qual testar o objeto atual. |

### Valor de Retorno

True se o objeto for do tipo marcado ou de sua subclasse, false caso contrário.

## Observações

Verifica se o objeto representa uma instância do tipo descrito por targetType. Analógico do operador 'is' do C#.
