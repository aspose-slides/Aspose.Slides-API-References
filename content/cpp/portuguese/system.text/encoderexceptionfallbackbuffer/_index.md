## EncoderExceptionFallbackBuffer classe


[Buffer](../../system/buffer/) para estratégia de fallback de codificação que lança exceções. Na verdade não armazena nada, mas lança exceções. Objetos desta classe só devem ser alocados usando a função [System::MakeObject()](../../system/makeobject/). Nunca crie instância deste tipo na stack ou usando o operador new, pois isso resultará em erros de tempo de execução e/ou falhas de asserção. Sempre encapsule esta classe em um ponteiro [System::SmartPtr](../../system/smartptr/) e use esse ponteiro para passá-lo a funções como argumento.

```cpp
class EncoderExceptionFallbackBuffer : public System::Text::EncoderFallbackBuffer
```
