## UTF8Encoding::GetMaxByteCount(int) método

Obtém o número máximo de bytes necessários para codificar um número especificado de caracteres.

```cpp
int System::Text::UTF8Encoding::GetMaxByteCount(int char_count) override
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| char_count | int | Número de caracteres a codificar. |

### Valor de Retorno

Número de bytes suficiente para codificar qualquer cadeia de caracteres com o comprimento de caracteres especificado.
