## UTF8Encoding::GetPreamble() método

Obtém o preâmbulo da página de códigos.

```cpp
ArrayPtr<uint8_t> System::Text::UTF8Encoding::GetPreamble() override
```

### Valor de retorno

Se a emissão de identificador UTF-8 estiver habilitada, retorna um array com os caracteres BOM; caso contrário, retorna um array vazio.
