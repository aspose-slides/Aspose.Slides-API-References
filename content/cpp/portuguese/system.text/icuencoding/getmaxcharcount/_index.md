## ICUEncoding::GetMaxCharCount(int) método

Obtém o número máximo de caracteres necessários para decodificar um número especificado de bytes.

```cpp
int System::Text::ICUEncoding::GetMaxCharCount(int byte_count) override
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| byte_count | int | Número de bytes a decodificar. |

### Valor de Retorno

Número de bytes suficiente para decodificar qualquer string de comprimento de caracteres especificado.
