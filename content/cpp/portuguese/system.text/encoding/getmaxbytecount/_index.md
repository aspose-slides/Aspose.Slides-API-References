## Encoding::GetMaxByteCount(int) método


Obtém o número máximo de bytes necessários para codificar um número especificado de caracteres.

```cpp
virtual int System::Text::Encoding::GetMaxByteCount(int char_count)=0
```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| char_count | int | Número de caracteres a codificar. |

### Valor de Retorno

Número de bytes suficiente para codificar qualquer string com o comprimento de caracteres especificado.
