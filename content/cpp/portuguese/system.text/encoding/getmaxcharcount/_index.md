## Encoding::GetMaxCharCount(int) método

Obtenha o número máximo de caracteres necessários para decodificar um número especificado de bytes.

```cpp
virtual int System::Text::Encoding::GetMaxCharCount(int byte_count)=0
```

### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| byte_count | int | Número de bytes a decodificar. |

### Valor de retorno

Número de bytes suficiente para decodificar qualquer string com o comprimento de caracteres especificado.
