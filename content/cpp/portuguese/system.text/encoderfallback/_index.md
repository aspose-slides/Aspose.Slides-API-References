## EncoderFallback classe

Fornece API de fallback para lidar com erros de codificação. Objetos desta classe só devem ser alocados usando a função [System::MakeObject()](../../system/makeobject/). Nunca crie instâncias deste tipo na pilha ou usando o operador new, pois isso resultará em erros de tempo de execução e/ou falhas de asserção. Sempre encapsule esta classe em um ponteiro [System::SmartPtr](../../system/smartptr/) e use esse ponteiro para passá-lo às funções como argumento.

```cpp
class EncoderFallback : public System::Object
```
