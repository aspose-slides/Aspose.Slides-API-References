## Details_EncoderFallbackException classe


Exceção lançada por [EncoderExceptionFallback](../encoderexceptionfallback/) quando a codificação falha. Nunca crie instâncias desta classe manualmente. Use a classe EncoderFallbackException em vez disso. Nunca envolva instâncias da classe EncoderFallbackException em [System::SmartPtr](../../system/smartptr/).

```cpp
class Details_EncoderFallbackException : public System::Details_ArgumentException
```
