## List::rend() método


Obtém um iterador reverso para um elemento inexistente antes do início da coleção.

```cpp
reverse_iterator System::Collections::Generic::List<T>::rend() noexcept
```


### Valor de Retorno

Um iterador reverso apontando para o elemento teórico que precede o primeiro elemento da lista (último em ordem reversa).
