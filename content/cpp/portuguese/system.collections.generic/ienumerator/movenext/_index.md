## IEnumerator::MoveNext() método

Move o enumerador para o próximo elemento. Se nenhum elemento foi referenciado antes, define a referência para o primeiro elemento disponível. Se o fim do contêiner for atingido, não faz nada.

```cpp
virtual bool System::Collections::Generic::IEnumerator<T>::MoveNext()=0
```

### Valor de retorno

True se algum elemento estiver disponível após a chamada, false caso contrário.
