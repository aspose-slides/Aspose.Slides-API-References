## IEnumerable::begin() método


Obtém um iterador apontando para o primeiro elemento (se houver) da coleção. Este iterador não pode ser usado para alterar um objeto referenciado porque [GetEnumerator()](../getenumerator/) retorna um objeto cópia de T.

```cpp
iterator System::Collections::Generic::IEnumerable<T>::begin()
```


### Valor de Retorno

Um iterador apontando para o primeiro elemento (se houver) da coleção

## IEnumerable::begin() const método


Obtém um iterador apontando para o primeiro elemento (se houver) da instância da coleção qualificada como const.

```cpp
const_iterator System::Collections::Generic::IEnumerable<T>::begin() const
```


### Valor de Retorno

Um iterador apontando para o primeiro elemento (se houver) da instância da coleção qualificada como const
