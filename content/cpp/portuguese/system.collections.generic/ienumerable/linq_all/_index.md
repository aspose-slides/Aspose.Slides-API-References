## IEnumerable::LINQ_All(std::function\<bool(T)>) método


Determina se todos os elementos de uma sequência atendem a uma condição.

```cpp
bool System::Collections::Generic::IEnumerable<T>::LINQ_All(std::function<bool(T)> predicate)
```


### Argumentos

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| predicate | std::function\<**bool**(T)> | Uma função para testar cada elemento quanto a uma condição. |

### Valor de Retorno

true se cada elemento da sequência de origem passar no teste do predicado especificado, ou se a sequência estiver vazia; caso contrário, false.
