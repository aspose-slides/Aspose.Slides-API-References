## IEnumerable::end() método

Obtém um iterador que aponta imediatamente após o último elemento (se houver) da coleção. Este iterador não pode ser usado para alterar um objeto referenciado porque [GetEnumerator()](../getenumerator/) retorna uma cópia-objeto de T.

```cpp
iterator System::Collections::Generic::IEnumerable<T>::end()
```

### Valor de Retorno

Um iterador que aponta imediatamente após o último elemento (se houver) da coleção

## IEnumerable::end() const método

Obtém um iterador que aponta imediatamente após o último elemento (se houver) da instância da coleção qualificada como const.

```cpp
const_iterator System::Collections::Generic::IEnumerable<T>::end() const
```

### Valor de Retorno

Um iterador que aponta imediatamente após o último elemento (se houver) da instância da coleção qualificada como const
