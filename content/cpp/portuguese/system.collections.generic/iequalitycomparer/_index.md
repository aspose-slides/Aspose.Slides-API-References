## IEqualityComparer classe

Interface que fornece meios para comparar dois objetos quanto à igualdade. Objetos desta classe devem ser alocados apenas usando a função [System::MakeObject()](../../system/makeobject/). Nunca crie instâncias deste tipo na pilha ou usando o operador new, pois isso resultará em erros de tempo de execução e/ou falhas de asserção. Sempre envolva esta classe em um ponteiro [System::SmartPtr](../../system/smartptr/) e use esse ponteiro para passá-lo a funções como argumento.

```cpp
template<typename T>class IEqualityComparer : public virtual System::Object
```


### Parâmetros de modelo

| Parâmetro | Descrição |
| --- | --- |
| T | Tipo sendo comparado. |
