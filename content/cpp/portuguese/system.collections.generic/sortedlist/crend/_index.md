## SortedList::crend() const método


Obtém um iterador reverso para um elemento const qualificado não existente antes do início da coleção.

```cpp
const_reverse_iterator System::Collections::Generic::SortedList<TKey, TValue>::crend() const noexcept
```


### Valor de retorno

Um iterador reverso que aponta para o elemento const qualificado teórico que precede o primeiro elemento no mapa (último na ordem reversa).
