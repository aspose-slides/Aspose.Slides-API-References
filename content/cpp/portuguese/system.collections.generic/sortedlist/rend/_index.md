## SortedList::rend() método

Obtém um iterador reverso para um elemento inexistente antes do início da coleção.

```cpp
reverse_iterator System::Collections::Generic::SortedList<TKey, TValue>::rend() noexcept
```

### Valor de Retorno

Um iterador reverso apontando para o elemento teórico que precede o primeiro elemento no mapa (último em ordem reversa).
