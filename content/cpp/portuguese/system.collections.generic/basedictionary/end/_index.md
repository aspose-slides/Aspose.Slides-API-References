## BaseDictionary::end() const método

Retorna um iterator para o KVPair-wrapper do elemento chave-valor que segue o último elemento do contêiner. Implementado no estilo C# – o iterator deve retornar o KVPair-object com a interface get_Key() e get_Value(). Este elemento atua como um marcador de posição; tentar acessá-lo resulta em comportamento indefinido.

```cpp
const_iterator System::Collections::Generic::BaseDictionary<Map>::end() const noexcept
```

### Valor de Retorno

Um iterator apontando para o elemento teórico colocado após o elemento final da coleção.
