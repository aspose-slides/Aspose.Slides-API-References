## BaseDictionary::cbegin() const método

Retorna um iterador para o primeiro elemento do contêiner. Implementado no estilo STL. Se o contêiner estiver vazio, o iterador retornado será igual a [end()](../../ienumerable/end/).

```cpp
stl_const_iterator System::Collections::Generic::BaseDictionary<Map>::cbegin() const noexcept
```

### Valor de Retorno

Um iterador apontando para o primeiro elemento qualificado como const da coleção.
