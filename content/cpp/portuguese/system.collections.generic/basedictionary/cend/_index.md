## BaseDictionary::cend() const método

Retorna um iterador para o elemento que segue o último elemento do contêiner. Implementado no estilo STL. Este elemento funciona como um marcador de posição; tentar acessá-lo resulta em comportamento indefinido.

```cpp
stl_const_iterator System::Collections::Generic::BaseDictionary<Map>::cend() const noexcept
```

### Valor de Retorno

Um iterador apontando para o elemento teórico const-qualificado localizado após o elemento final da coleção.
