## BaseDictionary::begin() const método

Retorna um iterador para o KVPair-wrapper do elemento chave-valor do contêiner. Implementado no estilo C# - o iterador deve retornar o KVPair-object com a interface get_Key() e get_Value(). Se o contêiner estiver vazio, o iterador retornado será igual a [end()](../../ienumerable/end/).

```cpp
const_iterator System::Collections::Generic::BaseDictionary<Map>::begin() const noexcept
```

### Valor de Retorno

Um iterador apontando para o primeiro elemento da coleção.
