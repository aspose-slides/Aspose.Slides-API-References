## クラス

| クラス | 説明 |
| --- | --- |
| [IXmlSerializable](./ixmlserializable/) | XML のシリアライズとデシリアライズのためのカスタム書式設定を提供します。このクラスのオブジェクトは [System::MakeObject()](../system/makeobject/) 関数を使用してのみ割り当てるべきです。スタック上や operator new を使用してこの型のインスタンスを作成しないでください。そうしないとランタイムエラーやアサーション違反が発生します。このクラスは常に [System::SmartPtr](../system/smartptr/) ポインタでラップし、そのポインタを関数の引数として渡してください。 |
| [XmlAttributeOverrides](./xmlattributeoverrides/) | [XmlSerializer](./xmlserializer/) がオブジェクトのシリアライズまたはデシリアライズに使用されるときに属性の上書きを可能にします。このクラスのオブジェクトは [System::MakeObject()](../system/makeobject/) 関数を使用してのみ割り当てるべきです。スタック上や operator new を使用してこの型のインスタンスを作成しないでください。そうしないとランタイムエラーやアサーション違反が発生します。このクラスは常に [System::SmartPtr](../system/smartptr/) ポインタでラップし、そのポインタを関数の引数として渡してください。 |
| [XmlRootAttribute](./xmlrootattribute/) | 属性ターゲットを XML ルート要素としてマークし、その XML シリアライズを制御します。このクラスのオブジェクトは [System::MakeObject()](../system/makeobject/) 関数を使用してのみ割り当てるべきです。スタック上や operator new を使用してこの型のインスタンスを作成しないでください。そうしないとランタイムエラーやアサーション違反が発生します。このクラスは常に [System::SmartPtr](../system/smartptr/) ポインタでラップし、そのポインタを関数の引数として渡してください。 |
| [XmlSerializationReader](./xmlserializationreader/) | [XmlReader](../system.xml/xmlreader/) のエクスペリエンスを向上させるサービスクラスです。 |
| [XmlSerializationWriter](./xmlserializationwriter/) | [XmlWriter](../system.xml/xmlwriter/) のエクスペリエンスを向上させるサービスクラスです。 |
| [XmlSerializer](./xmlserializer/) | オブジェクトを XML ドキュメントにシリアライズおよびデシリアライズします。このクラスのオブジェクトは [System::MakeObject()](../system/makeobject/) 関数を使用してのみ割り当てるべきです。スタック上や operator new を使用してこの型のインスタンスを作成しないでください。そうしないとランタイムエラーやアサーション違反が発生します。このクラスは常に [System::SmartPtr](../system/smartptr/) ポインタでラップし、そのポインタを関数の引数として渡してください。 |

| [XmlSerializerNamespaces](./xmlserializernamespaces/) | [Serialization::XmlSerializer](./xmlserializer/) が XML ドキュメント インスタンスで修飾名を生成する際に使用する XML 名前空間とプレフィックスを含みます。 |
