## SoapServiceRoutingStyle 列挙型


SOAP メッセージが XML [Web](../../system.web/) サービスにどのようにルーティングされるかのオプションを列挙します。

```cpp
enum class SoapServiceRoutingStyle
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| SoapAction | 0 | SOAP メッセージは 'SOAPAction' 属性に基づいてルーティングされます。 |
| RequestElement | 1 | SOAP メッセージは 'Body' 要素の後の最初の子要素に基づいてルーティングされます。 |
