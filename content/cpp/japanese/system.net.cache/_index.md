## クラス

| クラス | 説明 |
| --- | --- |
| [HttpRequestCachePolicy](./httprequestcachepolicy/) | HTTP キャッシュ ポリシーで、RFC2616 の HTTP キャッシュ セマンティクスを表現します。このクラスのオブジェクトは [System::MakeObject()](../system/makeobject/) 関数を使用してのみ割り当てるべきです。この型のインスタンスをスタック上で作成したり operator new を使用したりしないでください。そうしないと実行時エラーやアサーション違反が発生します。常にこのクラスを [System::SmartPtr](../system/smartptr/) ポインタでラップし、そのポインタを関数への引数として渡してください。 |
| [RequestCachePolicy](./requestcachepolicy/) | [Http](../system.net.http/)、FTP などのキャッシュに使用される共通リクエスト キャッシュ ポリシーです。このクラスのオブジェクトは [System::MakeObject()](../system/makeobject/) 関数を使用してのみ割り当てるべきです。この型のインスタンスをスタック上で作成したり operator new を使用したりしないでください。そうしないと実行時エラーやアサーション違反が発生します。常にこのクラスを [System::SmartPtr](../system/smartptr/) ポインタでラップし、そのポインタを関数への引数として使用してください。 |
## 列挙体

| 列挙体 | 説明 |
| --- | --- |
| [RequestCacheLevel](./requestcachelevel/) | この列挙体は任意の [WebRequest](../system.net/webrequest/) に適用できるキャッシュ設定を表します。 |
| [HttpRequestCacheLevel](./httprequestcachelevel/) | この列挙体は HTTP のキャッシュ設定を表します。 |
| [HttpCacheAgeControl](./httpcacheagecontrol/) | CacheAgeControl はキャッシュ項目の年齢と新鮮さに関する設定を指定するために使用されます。 |
