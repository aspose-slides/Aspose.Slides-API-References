## EmptyEnumerator::MoveNext() メソッド


列挙子を次の要素に移動します。以前に要素が参照されていない場合、利用可能な最初の要素への参照を設定します。コンテナの末尾に達した場合は何もしません。

```cpp
bool System::Linq::Details::EmptyEnumerator<T>::MoveNext() override
```


### 戻り値

呼び出し後に要素が利用可能であれば True、そうでなければ false を返します。
