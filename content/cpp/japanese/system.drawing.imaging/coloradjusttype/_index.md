## ColorAdjustType 列挙型

どのオブジェクトがカラー調整情報を使用するかを指定します。

```cpp
enum class ColorAdjustType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Default | 0 | 独自のカラー調整情報を持たないすべてのオブジェクトで使用されるカラー調整情報を定義します。 |
| Bitmap | 1 | [Bitmap](../../system.drawing/bitmap/) オブジェクト用のカラー調整情報を定義します。 |
| Brush | 2 | [Brush](../../system.drawing/brush/) オブジェクト用のカラー調整情報を定義します。 |
| Pen | 3 | [Pen](../../system.drawing/pen/) オブジェクト用のカラー調整情報を定義します。 |
| Text | 4 | テキスト用のカラー調整情報を定義します。 |
| Count | 5 | 指定されたタイプ数を示します。 |
| Any | 6 | 指定されたタイプ数を示します。 |
