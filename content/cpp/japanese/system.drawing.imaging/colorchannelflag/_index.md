## ColorChannelFlag 列挙型

CMYK カラースペースのカラー チャネルを指定します。

```cpp
enum class ColorChannelFlag
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| ColorChannelC | 0 | シアン色チャンネルです。 |
| ColorChannelM | 1 | マゼンタ色チャンネルです。 |
| ColorChannelY | 2 | イエロー色チャンネルです。 |
| ColorChannelK | 3 | ブラック色チャンネルです。 |
| ColorChannelLast | 4 | 最後に選択されたチャンネルを使用すべきです。 |
