## ColorMatrixFlag 列挙体

[ImageAttributes](../imageattributes/) オブジェクトのカラーおよびグレースケール調整設定の影響を受ける画像と色のタイプを指定します。

```cpp
enum class ColorMatrixFlag
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Default | 0 | 色とグレースケールの両方の値がカラー調整されます。 |
| SkipGrays | 1 | グレースケールの値はカラー調整されません。 |
| AltGrays | 2 | グレースケールの値のみがカラー調整されます。 |
