## MetafileType 列挙型


グラフィック メタファイルのタイプを表します。

```cpp
enum class MetafileType
```

### Values

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Invalid | 0 | 無効なメタファイル。 |
| Wmf | 1 | 標準の WMF。 |
| WmfPlaceable | 2 | 配置可能な [Metafile](../metafile/) フォーマット。 |
| Emf | 3 | EMF（EMF+ ではありません）。 |
| EmfPlusOnly | 4 | EMF+ はデュアル、下位レコードなし。 |
| EmfPlusDual | 5 | EMF+ はデュアル、下位レコードあり。 |
