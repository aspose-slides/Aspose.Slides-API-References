## ImageLockMode 列挙型

画像のロック対象領域のプロパティを指定します。

```cpp
enum class ImageLockMode
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| ReadOnly | 1 | 領域は読み取り専用でロックされます。 |
| WriteOnly | 2 | 領域は書き込み専用でロックされます。 |
| ReadWrite | n/a | 領域は読み取りおよび書き込みの両方でロックされます。 |
| UserInputBuffer | 4 | 画像はユーザー入力バッファに格納され、アクセスはユーザーが制御します。 |
