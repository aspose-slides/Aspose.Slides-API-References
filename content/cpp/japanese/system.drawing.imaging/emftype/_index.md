## EmfType 列挙型

EMF ファイルに配置されるレコードのタイプを指定します。

```cpp
enum class EmfType
```

### 値

| Name | Value | Description |
| --- | --- | --- |
| EmfOnly | n/a | [Windows](../../system.windows/) 拡張メタファイル。GDI コマンドが含まれています。このタイプのメタファイルは EMF ファイルとして参照されます。 |
| EmfPlusOnly | n/a | [Windows](../../system.windows/) 拡張メタファイルプラス。GDI+ コマンドが含まれています。このタイプのメタファイルは EMF+ ファイルとして参照されます。 |
| EmfPlusDual | n/a | デュアル [Windows](../../system.windows/) 拡張メタファイル。GDI と GDI+ の同等のコマンドが含まれています。このタイプのメタファイルは EMF+ ファイルとして参照されます。 |
