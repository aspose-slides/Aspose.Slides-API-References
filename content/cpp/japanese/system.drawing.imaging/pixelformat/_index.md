## PixelFormat 列挙型


ピクセルのカラーデータ形式を指定します。

```cpp
enum class PixelFormat
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Indexed | 65536 | ピクセルデータにカラ―インデックス値が含まれることを示します。インデックスはシステムのカラーテーブル内の色へのインデックスです。 |
| Gdi | 131072 | ピクセルデータに GDI カラーが含まれることを示します。 |
| Alpha | 262144 | ピクセルデータに事前乗算されていないアルファ値が含まれることを示します。 |
| PAlpha | 524288 | ピクセルデータに事前乗算されたアルファ値が含まれることを示します。 |
| Extended | 1048576 | 予約されています。 |
| Canonical | 2097152 | 1 ピクセルあたり 32 ビット、24 ビットの色深度と 8 ビットのアルファチャンネルを持つピクセル形式を示します。 |
| Undefined | 0 | ピクセル形式が未定義であることを示します。 |
| DontCare | 0 | ピクセル形式が指定されていないことを示します。 |
| Format1bppIndexed | n/a | ピクセル形式が 1 ビット/ピクセルのインデックスカラーであることを示します。 |
| Format4bppIndexed | n/a | ピクセル形式が 4 ビット/ピクセルのインデックスカラーであることを示します。 |
| Format8bppIndexed | n/a | ピクセル形式が 8 ビット/ピクセルのインデックスカラーであることを示します。 |
| Format16bppGrayScale | n/a | ピクセル形式が 16 ビット/ピクセルで、カラー情報が 65536 段階のグレイスケールを表すことを示します。 |
| Format16bppRgb555 | n/a | ピクセル形式が 16 ビット/ピクセルで、赤・緑・青各 5 ビット、残りのビットは使用されないことを示します。 |
| Format16bppRgb565 | n/a | ピクセル形式が 16 ビット/ピクセルで、赤 5 ビット、緑 6 ビット、青 5 ビットの構成であることを示します。 |
| Format16bppArgb1555 | n/a | ピクセル形式が 16 ビット/ピクセルで、赤・緑・青各 5 ビットとアルファ 1 ビットで構成されていることを示します。 |
| Format24bppRgb | n/a | ピクセル形式が 24 ビット/ピクセルで、赤・緑・青各 8 ビットで構成されていることを示します。 |
| Format32bppRgb | n/a | ピクセル形式が 32 ビット/ピクセルで、赤・緑・青各 8 ビットで構成され、残りの 8 ビットは使用されないことを示します。 |
| Format32bppArgb | n/a | ピクセル形式が 32 ビット/ピクセルで、赤・緑・青各 8 ビットとアルファ 8 ビットで構成されていることを示します。 |
| Format32bppPArgb | n/a | ピクセル形式が 32 ビット/ピクセルで、赤・緑・青各 8 ビットとアルファ 8 ビットで構成され、赤・緑・青の各コンポーネントがアルファ値に従って事前乗算されていることを示します。 |
| Format48bppRgb | n/a | ピクセル形式が 48 ビット/ピクセルで、赤・緑・青各 16 ビットで構成されていることを示します。 |
| Format64bppArgb | n/a | ピクセル形式が 64 ビット/ピクセルで、赤・緑・青各 16 ビットとアルファ 16 ビットで構成されていることを示します。 |
| Format64bppPArgb | n/a | ピクセル形式が 64 ビット/ピクセルで、赤・緑・青各 16 ビットとアルファ 16 ビットで構成され、赤・緑・青の各コンポーネントがアルファ値に従って事前乗算されていることを示します。 |
| Format32bppCMYK | n/a | ピクセル形式が 32 ビット/ピクセルで、シアン、マゼンタ、イエロー、キー（黒）各 8 ビットで構成されていることを示します。 |
| Max | 16 | この列挙体の最大値を表します。 |
