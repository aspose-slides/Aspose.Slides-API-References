## MetafileFrameUnit 列挙型

メタファイルのサイズと位置を決定するために使用される矩形の測定単位を指定します。

```cpp
enum class MetafileFrameUnit
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Pixel | n/a | 測定単位としてピクセルを指定します。 |
| Point | n/a | 測定単位としてプリンターのポイントを指定します。 |
| Inch | n/a | 測定単位としてインチを指定します。 |
| Document | n/a | 測定単位としてインチの1/300を指定します。 |
| Millimeter | n/a | 測定単位としてミリメートルを指定します。 |
| GdiCompatible | n/a | 測定単位として0.01ミリメートルを指定します。GDI との互換性のために提供されています。 |
