## CacheControlHeaderValue::set_SharedMaxAge(Nullable\<TimeSpan\>) メソッド

```cpp
void System::Net::Http::Headers::CacheControlHeaderValue::set_SharedMaxAge(Nullable<TimeSpan> value)
```

| --- | --- | --- |
| value | [Nullable](../../../system/nullable/)\<[TimeSpan](../../../system/timespan/)\> | 設定しなければならない共有最大有効期限です。 |
