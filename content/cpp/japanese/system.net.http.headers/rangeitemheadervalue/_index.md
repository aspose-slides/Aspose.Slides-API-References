## RangeItemHeaderValue クラス


'[Range](../../system/range/)' ヘッダーの値内のバイト範囲を表します。このクラスのオブジェクトは [System::MakeObject()](../../system/makeobject/) 関数を使用してのみ割り当てるべきです。スタック上や operator new を使用してこの型のインスタンスを作成しないでください。これにより実行時エラーやアサーション違反が発生する可能性があります。このクラスは常に [System::SmartPtr](../../system/smartptr/) ポインタでラップし、そのポインタを関数の引数として渡すようにしてください。

```cpp
class RangeItemHeaderValue : public System::ICloneable
```
