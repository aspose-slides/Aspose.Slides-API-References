## HttpRequestHeaders::get_ConnectionClose() メソッド


'Connection' ヘッダーの値に 'Close' が含まれているかどうかを示す値を取得します。

```cpp
Nullable<bool> System::Net::Http::Headers::HttpRequestHeaders::get_ConnectionClose()
```


### 戻り値

'Connection' ヘッダーの値に 'Close' が含まれている場合は True、そうでない場合は false です。
