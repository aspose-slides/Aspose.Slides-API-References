## HttpRequestHeaders::get_TransferEncodingChunked() メソッド

「Transfer-Encoding」ヘッダーの値に「Chunked」が含まれているかどうかを示す値を取得します。

```cpp
Nullable<bool> System::Net::Http::Headers::HttpRequestHeaders::get_TransferEncodingChunked()
```

### 戻り値

「Transfer-Encoding」ヘッダーの値に「Chunked」が含まれている場合は true、そうでない場合は false を返します。
