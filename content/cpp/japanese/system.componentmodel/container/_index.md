## コンテナクラス


[Container](./) クラスを使用した翻訳コード用のダミークラスです。このクラスのオブジェクトは [System::MakeObject()](../../system/makeobject/) 関数を使用してのみ割り当てるべきです。スタック上や operator new を使用してこの型のインスタンスを作成しないでください。これにより実行時エラーやアサーション違反が発生する可能性があります。常にこのクラスを [System::SmartPtr](../../system/smartptr/) ポインタでラップし、そのポインタを引数として関数に渡すようにしてください。

```cpp
class Container : public System::Object
```
