## Details_Win32Exception クラス

Win32 エラーコードに対して例外をスローします。このクラスのインスタンスを手動で作成しないでください。代わりに Win32Exception クラスを使用してください。Win32Exception クラスのインスタンスを [System::SmartPtr](../../system/smartptr/) にラップしないでください。

```cpp
class Details_Win32Exception : public System::Details_ExceptionWithErrorCode<Details_SystemException>
```
