## CancellationToken::get_CanBeCanceled() const method


このトークンがキャンセル状態になることができるかどうかを取得します。

```cpp
bool System::Threading::CancellationToken::get_CanBeCanceled() const
```


### Return Value

このトークンがキャンセル状態になることが可能な場合は true、そうでない場合は false を返します。
## Remarks



[CancellationTokenSource](../../cancellationtokensource/) から作成されたトークンは true を返し、None トークンは常に false を返します。
