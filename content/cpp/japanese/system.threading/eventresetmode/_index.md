## EventResetMode 列挙型

イベントの状態がどのようにリセットされるかを示します。

```cpp
enum class EventResetMode
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| AutoReset | 0 | イベント状態は読み取り時に自動的にリセットされます。 |
| ManualReset | 1 | イベント状態は手動でリセットする必要があります。 |
