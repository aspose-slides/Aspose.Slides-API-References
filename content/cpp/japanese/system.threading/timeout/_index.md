## Timeout 構造体

[Threading](../) タイムアウトの特別な値。これはインスタンスサービスを持たない static 型です。いかなる手段でもそのインスタンスを作成してはなりません。

```cpp
class Timeout
```

## フィールド

| フィールド | 説明 |
| --- | --- |
| static [Infinite](./infinite/) | ミリ秒での無限タイムアウト。 |
| static [InfiniteTimespan](./infinitetimespan/) | [TimeSpan](../../system/timespan/) 型の無限タイムアウト。 |
