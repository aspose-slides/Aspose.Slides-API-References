## Thread::get_ManagedThreadId() const メソッド


スレッドの識別子を取得します。OS から取得できますが、OS のスレッド識別子が int の上限を超える場合、スレッドの ID が重複する可能性があります。

```cpp
int System::Threading::Thread::get_ManagedThreadId() const
```


### 戻り値

疑似一意のスレッド識別子です。
