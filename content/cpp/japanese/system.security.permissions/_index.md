## クラス

| クラス | 説明 |
| --- | --- |
| [SecurityPermission](./securitypermission/) | セキュリティ許可を表すクラスです。このクラスのオブジェクトは [System::MakeObject()](../system/makeobject/) 関数を使用してのみ割り当てるべきです。スタック上や operator new を使用してインスタンスを作成しないでください。そうすると実行時エラーやアサーション障害が発生します。このクラスは常に [System::SmartPtr](../system/smartptr/) ポインタでラップし、そのポインタを関数の引数として渡すようにしてください。 |
## 列挙型

| 列挙型 | 説明 |
| --- | --- |
| [PermissionState](./permissionstate/) | 許可の状態。 |
| [SecurityPermissionFlag](./securitypermissionflag/) | セキュリティ許可のフラグ。 |
