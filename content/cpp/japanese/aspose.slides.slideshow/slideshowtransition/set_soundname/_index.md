## SlideShowTransition::set_SoundName(System::String) メソッド

遷移のサウンドの人間が読み取れる名前を指定します。[ISlideShowTransition::set_Sound](../../../aspose.slides/islideshowtransition/set_sound/) はサウンド名を取得または設定するために割り当てる必要があります。[System::String](../../../system/string/) に書き込みます。

```cpp
void Aspose::Slides::SlideShow::SlideShowTransition::set_SoundName(System::String value) override
```

## 備考

この名前は、遷移サウンドを手動で設定する際に PowerPoint のユーザーインターフェイスに表示されます。
