## SlideShowTransition::set_SoundIsBuiltIn(bool) メソッド

このサウンドが組み込みサウンドかどうかを指定します。この属性が true に設定された場合、生成アプリケーションはこのサウンドの name 属性が組み込みサウンドのリストにあるかを確認するよう警告され、必要に応じてカスタム名または UI を表示できます。**bool** を書き込みます。

void Aspose::Slides::SlideShow::SlideShowTransition::set_SoundIsBuiltIn(bool value) override
