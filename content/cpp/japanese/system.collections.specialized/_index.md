## クラス

| クラス | 説明 |
| --- | --- |
| [BitVector32](./bitvector32/) | 32ビットストレージへの整数または[Boolean](../system/boolean/)アクセスが容易なシンプルで軽量なビットベクタを提供します。 |
| [NameValueCollection](./namevaluecollection/) | [String](../system/string/)キーと[String](../system/string/)値の関連コレクションで、キーまたはインデックスのいずれかでアクセスできます。 |
| [StringCollection](./stringcollection/) | 文字列のインデックス付きリスト。このクラスのオブジェクトは、[System::MakeObject()](../system/makeobject/)関数を使用してのみ割り当てるべきです。スタック上や operator new を使用してこの型のインスタンスを作成しないでください。そうしないと実行時エラーやアサーション違反が発生します。常にこのクラスを [System::SmartPtr](../system/smartptr/) ポインタでラップし、そのポインタを引数として関数に渡してください。 |
| [StringCollectionPtr](./stringcollectionptr/) | 文字列コレクションポインタ（アクセス演算子付き）。 |
| [StringDictionary](./stringdictionary/) | [String](../system/string/) から文字列への辞書。このクラスのオブジェクトは、[System::MakeObject()](../system/makeobject/)関数を使用してのみ割り当てるべきです。スタック上や operator new を使用してこの型のインスタンスを作成しないでください。そうしないと実行時エラーやアサーション違反が発生します。常にこのクラスを [System::SmartPtr](../system/smartptr/) ポインタでラップし、そのポインタを引数として関数に渡してください。 |
