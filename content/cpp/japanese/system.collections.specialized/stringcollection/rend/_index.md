## StringCollection::rend() メソッド


逆順コンテナの最後の要素の次の要素へのリバースイテレータを返します。これは、非逆順コンテナの最初の要素の直前の要素に対応します。この要素はプレースホルダーとして機能し、アクセスしようとすると未定義の動作になります。

```cpp
reverse_iterator System::Collections::Specialized::StringCollection::rend() noexcept
```


### 戻り値

コンテナの最初の要素の理論上の直前の要素を指すイテレータ。

## StringCollection::rend() const メソッド


逆順コンテナの最後の要素の次の要素へのリバースイテレータを返します。これは、非逆順コンテナの最初の要素の直前の要素に対応します。この要素はプレースホルダーとして機能し、アクセスしようとすると未定義の動作になります。

```cpp
const_reverse_iterator System::Collections::Specialized::StringCollection::rend() const noexcept
```


### 戻り値

const 修飾されたコンテナの最初の要素の理論上の直前の要素を指すイテレータ。
