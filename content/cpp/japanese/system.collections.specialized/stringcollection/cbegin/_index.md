## StringCollection::cbegin() const メソッド


コンテナの最初の const 修飾された要素へのイテレータを返します。コンテナが空の場合、返されるイテレータは [cend()](../cend/) と等しくなります。

```cpp
const_iterator System::Collections::Specialized::StringCollection::cbegin() const noexcept
```


### 戻り値

コンテナの最初の const 修飾された要素を指すイテレータ。
