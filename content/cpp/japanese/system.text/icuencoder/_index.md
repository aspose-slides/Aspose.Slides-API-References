## ICUEncoder クラス

[Encoder](../encoder/) は ICU を使用してエンコードします。このクラスのオブジェクトは [System::MakeObject()](../../system/makeobject/) 関数を使用してのみ割り当てるべきです。スタック上や operator new を使ってこの型のインスタンスを作成しないでください。そうすると実行時エラーやアサーション違反が発生します。このクラスは必ず [System::SmartPtr](../../system/smartptr/) ポインタでラップし、そのポインタを関数の引数として渡すようにしてください。

```cpp
class ICUEncoder : public System::Text::Encoder
```
