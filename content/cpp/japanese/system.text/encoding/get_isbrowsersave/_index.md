## Encoding::get_IsBrowserSave() メソッド

エンコーディングがブラウザーでコンテンツを保存するために使用できるかどうかを確認します。

```cpp
virtual bool System::Text::Encoding::get_IsBrowserSave()
```

### 戻り値

エンコーディングがブラウザーでコンテンツを保存するために使用できる場合は true、そうでない場合は false が返されます。
