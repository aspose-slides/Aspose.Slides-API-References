## Encoding::get_IsMailNewsDisplay() method

エンコーディングがメールクライアントでコンテンツの表示に使用できるかどうかをチェックします。

```cpp
virtual bool System::Text::Encoding::get_IsMailNewsDisplay()
```

### 戻り値

メールクライアントでコンテンツの表示にエンコーディングが使用できる場合は True、そうでない場合は false を返します。
