## Encoding::get_IsBrowserDisplay() メソッド


エンコーディングがブラウザーでコンテンツの表示に使用できるかどうかを確認します。

```cpp
virtual bool System::Text::Encoding::get_IsBrowserDisplay()
```


### 戻り値
