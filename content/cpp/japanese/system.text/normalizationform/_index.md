## NormalizationForm enum

Unicode 文字列を正規化する方法を定義します。

```cpp
enum class NormalizationForm
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| FormC | 1 | 完全な標準分解を使用し、シーケンスを主要な合成文字に置き換えます。 |
| FormD | 2 | 完全な標準分解を使用します。 |
| FormKC | 5 | 完全な互換性分解を使用し、シーケンスを主要な合成文字に置き換えます。 |
| FormKD | 6 | 完全な互換性分解を使用します。 |
