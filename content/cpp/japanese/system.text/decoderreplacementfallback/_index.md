## DecoderReplacementFallback クラス

誤ったシンボルをスタブに置き換えるフォールバック戦略を提供します。このクラスのオブジェクトは [System::MakeObject()](../../system/makeobject/) 関数を使用してのみ割り当てるべきです。スタック上や operator new を使用してこのタイプのインスタンスを作成しないでください。そうすると実行時エラーやアサーション障害が発生します。常にこのクラスを [System::SmartPtr](../../system/smartptr/) ポインタでラップし、そのポインタを引数として関数に渡して使用してください。

```cpp
class DecoderReplacementFallback : public System::Text::DecoderFallback
```
