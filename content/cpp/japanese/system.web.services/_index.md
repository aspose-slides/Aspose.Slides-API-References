## クラス

| クラス | 説明 |
| --- | --- |
| [Soap](./soap/) | SOAP の文字列定数を含みます。 |
| [Soap12](./soap12/) | SOAP バージョン 1.2 の文字列定数を含みます。 |
| [WebServiceAttribute](./webserviceattribute/) | XML [Web](../system.web/) サービスに追加情報を加えます。 このクラスのオブジェクトは [System::MakeObject()](../system/makeobject/) 関数を使用してのみ割り当てるべきです。 スタック上や operator new を使用してこの型のインスタンスを作成しないでください。実行時エラーやアサーション失敗の原因となります。 常にこのクラスを [System::SmartPtr](../system/smartptr/) ポインタでラップし、そのポインタを関数への引数として使用してください。 |
| [WebServiceBindingAttribute](./webservicebindingattribute/) | XML [Web](../system.web/) サービスの 1 つ以上のメソッドを定義するバインディングを宣言するために使用されます。 このクラスのオブジェクトは [System::MakeObject()](../system/makeobject/) 関数を使用してのみ割り当てるべきです。 スタック上や operator new を使用してこの型のインスタンスを作成しないでください。実行時エラーやアサーション失敗の原因となります。 常にこのクラスを [System::SmartPtr](../system/smartptr/) ポインタでラップし、そのポインタを関数への引数として使用してください。 |
