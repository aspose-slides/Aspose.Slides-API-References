## OrganizationChartLayoutType 列挙型

組織図における子ノードの書式設定タイプを表します。

```cpp
enum class OrganizationChartLayoutType
```

### 値

| Name | Value | Description |
| --- | --- | --- |
| Initial | 0 | 初期レイアウトタイプ |
| Standart | 1 | 子ノードを親ノードの下に水平に配置します。 |
| BothHanging | 2 | 子ノードを親ノードの左側と右側の両方に垂直に配置します。 |
| LeftHanging | 3 | 子ノードを親ノードの左側に垂直に配置します。 |
| RightHanging | 4 | 子ノードを親ノードの右側に垂直に配置します。 |
