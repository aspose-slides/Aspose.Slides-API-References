## XsltSettings::get_EnableScript() メソッド

埋め込みスクリプトブロックのサポートを有効にするかどうかを示す値を返します。

```cpp
bool System::Xml::Xsl::XsltSettings::get_EnableScript()
```

### 戻り値

**true** を返すと XSLT スタイルシート内のスクリプトブロックがサポートされます。**false** の場合はサポートされません。デフォルトは **false** です。
