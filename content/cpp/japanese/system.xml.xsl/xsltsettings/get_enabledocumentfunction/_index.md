## XsltSettings::get_EnableDocumentFunction() メソッド

XSLT **document()** 関数のサポートを有効にするかどうかを示す値を返します。

```cpp
bool System::Xml::Xsl::XsltSettings::get_EnableDocumentFunction()
```

### 戻り値

**true** は XSLT **document()** 関数をサポートすることを意味します。そうでない場合は **false**。デフォルトは **false** です。
