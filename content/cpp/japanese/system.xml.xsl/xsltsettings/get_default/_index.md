## XsltSettings::get_Default() メソッド


デフォルト設定を持つ [XsltSettings](../) オブジェクトを返します。XSLT **document()** 関数および埋め込みスクリプトブロックのサポートは無効になっています。

```cpp
static SharedPtr<XsltSettings> System::Xml::Xsl::XsltSettings::get_Default()
```


### 戻り値

[XsltSettings::set_EnableDocumentFunction](../set_enabledocumentfunction/) と [XsltSettings::set_EnableScript](../set_enablescript/) オプションが **false** に設定された [XsltSettings](../) オブジェクトです。
