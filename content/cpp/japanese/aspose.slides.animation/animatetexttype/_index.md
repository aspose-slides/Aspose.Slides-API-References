## AnimateTextType 列挙型

アニメーション効果のテキストアニメーションタイプを表します。

```cpp
enum class AnimateTextType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| AllAtOnce | 0 | すべてのテキストを一度にアニメーションします。 |
| ByWord | 1 | テキストを単語ごとにアニメーションします。 |
| ByLetter | 2 | テキストを文字ごとにアニメーションします。 |
