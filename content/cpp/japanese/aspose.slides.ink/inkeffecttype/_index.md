## InkEffectType 列挙型

インク描画用に事前定義された視覚効果のセットを指定します。各効果は、スタイライズされたインク外観をシミュレートするテクスチャまたは画像に対応しています。これらの値は、レンダリング中のデジタルインクストロークの視覚スタイルをカスタマイズするために使用できます。

```cpp
enum class InkEffectType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| NotDefined | -1 | 効果が定義されていないか、未知です。この値はデフォルトまたはフォールバックとして使用できます。 |
| Bronze | 0 | 温かみのある茶系金属テクスチャで、bronze inkに似ています。 |
| Galaxy | 1 | カラフルで煌めくテクスチャで、galaxyに似ており、宇宙的な色調です。 |
| Gold | 2 | 明るく金属的なgoldテクスチャで、インクストロークに豪華な外観を与えます。 |
| Lava | 3 | 溶けたlavaに似た炎のようなテクスチャで、赤とオレンジの色合いがあります。 |
| Ocean | 4 | 深い青色の流体のようなテクスチャで、oceanの波や水ベースのインクを模倣します。 |
| RainbowGlitter | 5 | カラフルで輝くRainbowGlitter効果で、祝祭的または鮮やかなインクストロークに使用されます。 |
| RoseGold | 6 | 柔らかなピンクとゴールドのブレンドで、rose goldに似ており、エレガントなインクストロークに適しています。 |
| Silver | 7 | クールで金属的なsilverテクスチャで、クラシックなシルバーインクをシミュレートします。 |
