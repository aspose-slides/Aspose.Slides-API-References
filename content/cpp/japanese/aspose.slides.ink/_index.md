## クラス

| クラス | 説明 |
| --- | --- |
| [IInk](./iink/) | スライド上のインクオブジェクトを表します。 |
| [IInkActions](./iinkactions/) | スライド上のインクオブジェクトを表します。 |
| [IInkBrush](./iinkbrush/) | トレースブラシを表します。 |
| [IInkTrace](./iinktrace/) | [Ink](./ink/) オブジェクト内の手書きラインを表します。 |
| [Ink](./ink/) | スライド上のインクオブジェクトを表します。 |
| [InkActions](./inkactions/) | インクアクションのルートを表します。 |
| [InkBrush](./inkbrush/) | inkBrush オブジェクトを表します。 |
| [InkTrace](./inktrace/) | Trace オブジェクトを表します。Trace 要素は、デジタイザーによって取得されたデータを記録するために使用されます。InkTraceFormat オブジェクトが指定する仕様に従ってエンコードされたポイントのシーケンスを含みます。 |
## 列挙型

| 列挙型 | 説明 |
| --- | --- |
| [InkEffectType](./inkeffecttype/) | インクレンダリング用の事前定義されたビジュアルエフェクトのセットを指定します。各エフェクトは、スタイライズされたインク外観をシミュレートするテクスチャまたは画像に対応します。これらの値は、レンダリング中のデジタルインクストロークの視覚スタイルをカスタマイズするために使用できます。 |
