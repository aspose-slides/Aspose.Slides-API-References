## AsymmetricSignatureFormatter クラス


非対称署名フォーマッタの基底クラスです。このクラスのオブジェクトは [System::MakeObject()](../../system/makeobject/) 関数を使用してのみ割り当てるべきです。スタック上や operator new を使用してこのタイプのインスタンスを作成しないでください。そうすると実行時エラーやアサーション失敗が発生する可能性があります。このクラスは常に [System::SmartPtr](../../system/smartptr/) ポインタでラップし、そのポインタを関数への引数として渡します。

```cpp
class AsymmetricSignatureFormatter : public System::Object
```
