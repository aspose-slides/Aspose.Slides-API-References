## ToBase64Transform クラス

[CryptoStream](../cryptostream/) クラスのインスタンスを base 64 に変換します。このクラスのオブジェクトは [System::MakeObject()](../../system/makeobject/) 関数を使用してのみ割り当てるべきです。スタック上や operator new を使用してこのタイプのインスタンスを作成しないでください。実行時エラーやアサーション違反が発生します。常にこのクラスを [System::SmartPtr](../../system/smartptr/) ポインタでラップし、そのポインタを関数への引数として使用してください。

```cpp
class ToBase64Transform : public System::Security::Cryptography::ICryptoTransform
```
