## MD5CryptoServiceProvider クラス


CSP互換の [MD5](../md5/) アルゴリズムです。実装されていません。このクラスのオブジェクトは [System::MakeObject()](../../system/makeobject/) 関数を使用してのみ割り当てるべきです。スタック上や operator new を使用してこの型のインスタンスを作成しないでください。ランタイムエラーやアサーション失敗の原因になります。このクラスは必ず [System::SmartPtr](../../system/smartptr/) ポインタでラップし、そのポインタを関数の引数として渡して使用してください。

```cpp
class MD5CryptoServiceProvider : public System::Security::Cryptography::MD5
```
