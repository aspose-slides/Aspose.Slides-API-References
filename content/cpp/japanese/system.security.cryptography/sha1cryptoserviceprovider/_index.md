## SHA1CryptoServiceProvider クラス

[SHA1](../sha1/) CSP 実装。 このクラスのオブジェクトは [System::MakeObject()](../../system/makeobject/) 関数を使用してのみ割り当てるべきです。 スタック上または operator new を使用してこの型のインスタンスを作成しないでください。これによりランタイムエラーやアサーション違反が発生する可能性があります。 常にこのクラスを [System::SmartPtr](../../system/smartptr/) ポインタでラップし、そのポインタを引数として関数に渡すようにしてください。

```cpp
class SHA1CryptoServiceProvider : public System::Security::Cryptography::SHA1
```
