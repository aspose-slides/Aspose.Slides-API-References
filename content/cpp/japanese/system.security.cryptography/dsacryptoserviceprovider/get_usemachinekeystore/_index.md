## DSACryptoServiceProvider::get_UseMachineKeyStore() メソッド

キーがユーザーストアではなくマシンストアに永続化されるかどうかを確認します。

```cpp
static bool System::Security::Cryptography::DSACryptoServiceProvider::get_UseMachineKeyStore()
```

### 戻り値

キーがマシンストアに永続化されるべき場合は true、ユーザーストアに永続化されるべき場合は false が返されます。
