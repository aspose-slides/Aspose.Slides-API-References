## HMACSHA1 クラス


ハッシュベースのメッセージ [Authentication](../../system.security.authentication/) コードで、[SHA1](../sha1/) ハッシュ関数を使用します。実装されていません。このクラスのオブジェクトは [System::MakeObject()](../../system/makeobject/) 関数を使用してのみ割り当てるべきです。スタック上や new 演算子でこの型のインスタンスを作成しないでください。実行時エラーやアサーション障害が発生します。このクラスは常に [System::SmartPtr](../../system/smartptr/) ポインタでラップし、そのポインタを関数の引数として渡すようにしてください。

```cpp
class HMACSHA1 : public System::Security::Cryptography::HashAlgorithm
```
