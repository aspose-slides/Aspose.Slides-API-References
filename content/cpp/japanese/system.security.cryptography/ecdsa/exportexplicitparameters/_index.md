## ECDsa::ExportExplicitParameters(bool) method

明示的なパラメータをエクスポートします。

```cpp
virtual ECParameters System::Security::Cryptography::ECDsa::ExportExplicitParameters(bool include_private_parameters)
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| include_private_parameters | **bool** | true の場合、プライベートとパブリックの両方のパラメータをエクスポートし、false の場合はパブリックパラメータのみをエクスポートします。 |

### 戻り値

エクスポートされたパラメータ構造体。
