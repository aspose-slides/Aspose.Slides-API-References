## X509NameType 列挙型

証明書の発行者またはサブジェクトに関連する X.509 証明書に含まれる名前のタイプ。

```cpp
enum class X509NameType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| SimpleName | 0 | サブジェクトまたは発行者のシンプル名。 |
| EmailName | 1 | メールアドレス。 |
| UpnName | 2 | UPN 名。 |
| DnsName | 3 | DNS 名。 |
| DnsFromAlternativeName | 4 | DNS 名に相当する代替 DNS 名。 |
| UrlName | 5 | URL。 |
