## TextRenderingHint 列挙型

```cpp
enum class TextRenderingHint
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| SystemDefault | 0 | システム既定のレンダリングヒントを持つグリフ。 |
| SingleBitPerPixelGridFit | 1 | ヒント付のグリフビットマップ。 |
| SingleBitPerPixel | 2 | ヒントなしのグリフビットマップ。 |
| AntiAliasGridFit | 3 | ヒント付きのアンチエイリアス。 |
| AntiAlias | 4 | ヒントなしのグリフアンチエイリアスビットマップ。 |
| ClearTypeGridFit | 5 | ヒント付きのグリフCTビットマップ。 |
