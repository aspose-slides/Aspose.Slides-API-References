## ReflectionTypeLoadException 型定義

ReflectionTypeLoadException は、モジュール内のクラスのいずれかの読み込みに失敗した場合に Module.GetTypes メソッドによってスローされます。ReflectionTypeLoadException クラスのインスタンスを [System::SmartPtr](../../system/smartptr/) にラップしないでください。

```cpp
using System::Reflection::ReflectionTypeLoadException = typedef System::ExceptionWrapper<Details_ReflectionTypeLoadException>
```
