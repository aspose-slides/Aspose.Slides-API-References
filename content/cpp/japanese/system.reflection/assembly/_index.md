## Assembly クラス

[Reflection](../) クラスはアセンブリを記述します。サポートは限定的です。規則は C# と C++ で大きく異なるためです。このクラスのオブジェクトは [System::MakeObject()](../../system/makeobject/) 関数を使用してのみ割り当てるべきです。スタック上や operator new を使用してこの型のインスタンスを作成しないでください。実行時エラーやアサーション失敗の原因となります。このクラスは常に [System::SmartPtr](../../system/smartptr/) ポインタでラップし、そのポインタを関数の引数として渡してください。

```cpp
class Assembly : public System::Object
```
