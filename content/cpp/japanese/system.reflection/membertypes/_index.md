## MemberTypes 列挙型


各メンバーの種類を示します。

```cpp
enum class MemberTypes
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Constructor | 1 | メンバーが Constructor であることを指定します。 |
| Event | 2 | メンバーが Event であることを指定します。 |
| Field | 4 | メンバーが Field であることを指定します。 |
| Method | 8 | メンバーが Method であることを指定します。 |
| Property | 16 | メンバーが Property であることを指定します。 |
| TypeInfo | 32 | メンバーが TypeInfo であることを指定します。 |
| Custom | 64 | メンバーが Custom のカスタム メンバー タイプであることを指定します。 |
| NestedType | 128 | メンバーが NestedType のネストされたタイプであることを指定します。 |
| All | 191 | すべてのメンバータイプを指定します。 |
