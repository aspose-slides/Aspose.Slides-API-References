## PathList クラス

[CookieCollection](../cookiecollection/) クラスのインスタンスのリストを表します。 このクラスのオブジェクトは [System::MakeObject()](../../system/makeobject/) 関数を使用してのみ割り当てるべきです。 スタック上または operator new を使用してこのタイプのインスタンスを作成しないでください。そうしないと実行時エラーやアサーション障害が発生する可能性があります。 このクラスは常に [System::SmartPtr](../../system/smartptr/) ポインタでラップし、そのポインタを関数への引数として使用してください。

```cpp
class PathList : public System::Object
```
