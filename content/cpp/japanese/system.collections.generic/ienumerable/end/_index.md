## IEnumerable::end() method

コレクションの最後の要素（存在する場合）の直後を指すイテレータを取得します。このイテレータは、[GetEnumerator()](../getenumerator/) が T のコピーオブジェクトを返すため、参照されたオブジェクトを変更するために使用できません。

```cpp
iterator System::Collections::Generic::IEnumerable<T>::end()
```

### 戻り値

コレクションの最後の要素（存在する場合）の直後を指すイテレータ

## IEnumerable::end() const method

コレクションの const 修飾されたインスタンスの最後の要素（存在する場合）の直後を指すイテレータを取得します。

```cpp
const_iterator System::Collections::Generic::IEnumerable<T>::end() const
```

### 戻り値

const 修飾されたインスタンスの最後の要素（存在する場合）の直後を指すイテレータ
