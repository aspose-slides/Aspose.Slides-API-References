## IEnumerable::begin() method

コレクションの最初の要素（存在する場合）を指すイテレータを取得します。このイテレータは、[GetEnumerator()](../getenumerator/) が T のコピーオブジェクトを返すため、参照されたオブジェクトを変更するために使用できません。

```cpp
iterator System::Collections::Generic::IEnumerable<T>::begin()
```

### 戻り値

コレクションの最初の要素（存在する場合）を指すイテレータ

## IEnumerable::begin() const method

const 修飾されたコレクションのインスタンスの最初の要素（存在する場合）を指すイテレータを取得します。

```cpp
const_iterator System::Collections::Generic::IEnumerable<T>::begin() const
```

### 戻り値

const 修飾されたコレクションのインスタンスの最初の要素（存在する場合）を指すイテレータ
