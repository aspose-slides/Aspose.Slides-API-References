## BaseDictionary::cbegin() const メソッド

コンテナの最初の要素へのイテレータを返します。STL スタイルで実装されています。コンテナが空の場合、返されるイテレータは [end()](../../ienumerable/end/) と等しくなります。

```cpp
stl_const_iterator System::Collections::Generic::BaseDictionary<Map>::cbegin() const noexcept
```

### 戻り値

コレクションの最初の const 修飾要素を指すイテレータです。
