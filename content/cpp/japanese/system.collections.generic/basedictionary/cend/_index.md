## BaseDictionary::cend() const メソッド

コンテナの最後の要素の次にある要素へのイテレータを返します。STL スタイルで実装されています。この要素はプレースホルダーとして機能します。アクセスしようとすると未定義の動作になります。

```cpp
stl_const_iterator System::Collections::Generic::BaseDictionary<Map>::cend() const noexcept
```

### 戻り値

コレクションの end 要素の後に配置された、理論上の const 修飾された要素を指すイテレータ。
