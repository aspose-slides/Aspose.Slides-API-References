## HttpResponse クラス

ダミークラスで、翻訳されたコードを [HttpResponse](./) 参照とリンクできるようにしますが、実行はしません。適切に実装されたメンバーは含まれていません。このクラスのオブジェクトは [System::MakeObject()](../../system/makeobject/) 関数を使用してのみ割り当てるべきです。スタック上や operator new を使用してこの型のインスタンスを作成しないでください。実行時エラーやアサーション障害が発生します。このクラスは常に [System::SmartPtr](../../system/smartptr/) ポインタでラップし、そのポインタを関数の引数として渡すようにしてください。

```cpp
class HttpResponse : public System::Object
```
