## クラス

| クラス | 説明 |
| --- | --- |
| [Control](./control/) | ダミークラスで、[Control](./control/) クラスを使用する翻訳済みコードがコンパイル可能になるようにします。メソッドは実装されていません。このクラスのオブジェクトは [System::MakeObject()](../system/makeobject/) 関数を使用してのみ割り当てるべきです。スタック上や operator new を使用してこの型のインスタンスを作成しないでください。ランタイムエラーやアサーションフォルトの原因になります。このクラスは常に [System::SmartPtr](../system/smartptr/) ポインタでラップし、そのポインタを関数への引数として渡してください。 |
| [Form](./form/) | ダミークラスで、[Form](./form/) クラスを使用する翻訳済みコードがコンパイル可能になるようにします。メソッドは実装されていません。このクラスのオブジェクトは [System::MakeObject()](../system/makeobject/) 関数を使用してのみ割り当てるべきです。スタック上や operator new を使用してこの型のインスタンスを作成しないでください。ランタイムエラーやアサーションフォルトの原因になります。このクラスは常に [System::SmartPtr](../system/smartptr/) ポインタでラップし、そのポインタを関数への引数として渡してください。 |
| [IButtonControl](./ibuttoncontrol/) | ダミークラスで、[IButtonControl](./ibuttoncontrol/) インターフェイスを使用する翻訳済みコードがコンパイル可能になるようにします。このクラスのオブジェクトは [System::MakeObject()](../system/makeobject/) 関数を使用してのみ割り当てるべきです。スタック上や operator new を使用してこの型のインスタンスを作成しないでください。ランタイムエラーやアサーションフォルトの原因になります。このクラスは常に [System::SmartPtr](../system/smartptr/) ポインタでラップし、そのポインタを関数への引数として渡してください。 |
| [Screen](./screen/) | ディスプレイに関する情報を提供します。[Windows](../system.windows/) のみ。この型はアクセス関数によってメモリ管理が行われるシングルトンです。直接インスタンスを作成しないでください。 |
