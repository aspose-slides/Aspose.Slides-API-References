## FormBorderStyle enum

Defines how the border is drawn.

```cpp
enum class FormBorderStyle
```

### Values

| 名前 | 値 | 説明 |
| --- | --- | --- |
| None | 0 | 全く境界線がありません。 |
| FixedSingle | 1 | [Single](../../system/single/) 境界線。 |
| Fixed3D | 2 | 3Dのような境界線。 |
| FixedDialog | 3 | ダイアログ スタイルの境界線。 |
| Sizable | 4 | サイズ変更可能な境界線。 |
| FixedToolWindow | 5 | サイズ変更できないツールウィンドウの境界線。 |
| SizableToolWindow | 6 | サイズ変更可能なツールウィンドウの境界線。 |
