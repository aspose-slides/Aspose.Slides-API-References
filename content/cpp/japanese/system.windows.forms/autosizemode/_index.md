## AutoSizeMode 列挙型

自動サイズ調整がどのように機能するかを定義します。

```cpp
enum class AutoSizeMode
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| GrowAndShrink | 0 | [Control](../control/) は必要に応じて拡大縮小します。手動でサイズ変更できません。 |
| GrowOnly | 1 | [Control](../control/) は必要に応じて拡大しますが、最小サイズ以下には縮小できません。手動でサイズ変更可能です。 |
