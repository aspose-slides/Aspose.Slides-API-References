## FlatStyle 列挙型

コントロールがフラットに描画されるか、3D風に描画されるかを定義します。

```cpp
enum class FlatStyle
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Flat | 0 | [Control](../control/) は平面で描画されます。 |
| Popup | 1 | [Control](../control/) はマウスが上にあると3D風に描画されるまで、平面で描画されます。 |
| Standard | 2 | [Control](../control/) は3D風に描画されます。 |
| System | 3 | スタイルは OS によって制御されます。 |
