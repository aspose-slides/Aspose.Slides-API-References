## クラス

| クラス | 説明 |
| --- | --- |
| [DataGrid](./datagrid/) | このダミークラスは、[DataGrid](./datagrid/) 参照とリンクされた翻訳コードを可能にしますが、実行はしません。適切に実装されたメンバーは含まれていません。このクラスのオブジェクトは [System::MakeObject()](../system/makeobject/) 関数を使用してのみ割り当てるべきです。スタック上またはoperator newを使用してこの型のインスタンスを作成しないでください。そうしないとランタイムエラーやアサーション違反が発生する可能性があります。常にこのクラスを [System::SmartPtr](../system/smartptr/) ポインタでラップし、そのポインタを引数として関数に渡すようにしてください。 |
