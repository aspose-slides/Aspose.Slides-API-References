## XmlSchemaContentType 列挙型

複合型のコンテンツモデルに対する列挙です。これはスキーマ検証後情報セット（infoset）内のコンテンツを表します。

```cpp
enum class XmlSchemaContentType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| TextOnly | 0 | テキストのみのコンテンツ。 |
| Empty | 1 | 空のコンテンツ。 |
| ElementOnly | 2 | 要素のみのコンテンツ。 |
| Mixed | 3 | 混在コンテンツ。 |
