## XmlSchemaSet::get_IsCompiled() メソッド

値を返します。この値は、XML [Schema](../../) 定義言語 (XSD) スキーマが [XmlSchemaSet](../) 内でコンパイルされているかどうかを示します。

```cpp
bool System::Xml::Schema::XmlSchemaSet::get_IsCompiled()
```

### 戻り値

**true** は、[XmlSchemaSet](../) 内のスキーマが、[XmlSchemaSet](../) からスキーマが追加または削除された最後の時点以降にコンパイルされている場合を示します。そうでない場合は、**false** です。
