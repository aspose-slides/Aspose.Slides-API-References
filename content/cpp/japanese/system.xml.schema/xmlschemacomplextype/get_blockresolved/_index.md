## XmlSchemaComplexType::get_BlockResolved() メソッド

型がコンパイルされ、スキーマ検証後の情報セット（infoset）に変換された後の値を返します。この値は、インスタンス文書で **xsi:type** が使用されたときに型がどのように適用されるかを示します。

```cpp
XmlSchemaDerivationMethod System::Xml::Schema::XmlSchemaComplexType::get_BlockResolved()
```

### 戻り値

スキーマ検証後の情報セットの値です。デフォルトは **schema** 要素の **BlockDefault** 値です。
