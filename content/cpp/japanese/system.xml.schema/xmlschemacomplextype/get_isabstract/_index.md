## XmlSchemaComplexType::get_IsAbstract() メソッド


インスタンス ドキュメントで **complexType** 要素を使用できるかどうかを判断する情報を返します。

```cpp
bool System::Xml::Schema::XmlSchemaComplexType::get_IsAbstract()
```


### 戻り値

**true** の場合、要素はこの **complexType** 要素を直接使用できず、この **complexType** 要素から派生した複合型を使用しなければなりません。デフォルトは **false** です。オプションです。
