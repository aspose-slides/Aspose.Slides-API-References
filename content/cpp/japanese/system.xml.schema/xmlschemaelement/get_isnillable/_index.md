## XmlSchemaElement::get_IsNillable() メソッド

インスタンス データで **xsi:nil** が発生する可能性があるかどうかを示す情報を返します。要素に明示的な **nil** 値を割り当てられるかどうかを示します。

```cpp
bool System::Xml::Schema::XmlSchemaElement::get_IsNillable()
```

### 戻り値

nillable が **true** の場合、要素のインスタンスが **nil** 属性を **true** に設定できるようになります。**nil** 属性はインスタンス用の XML [Schema](../../) 名前空間の一部として定義されています。デフォルトは **false** です。省略可能。
