## XmlSchemaSimpleTypeList クラス


XML [Schema](../) の **list** 要素を、World Wide [Web](../../system.web/) Consortium (W3C) が定義するように表します。このクラスは、指定されたデータ型の値のリストとして **simpleType** 要素を定義するために使用できます。

```cpp
class XmlSchemaSimpleTypeList : public System::Xml::Schema::XmlSchemaSimpleTypeContent
```

## 備考

このクラスのオブジェクトは [System::MakeObject()](../../system/makeobject/) 関数を使用してのみ割り当てるべきです。スタック上や operator new を使用してこの型のインスタンスを作成しないでください。そうすると実行時エラーやアサーション障害が発生します。常にこのクラスを [System::SmartPtr](../../system/smartptr/) ポインタでラップし、そのポインタを関数の引数として渡すようにしてください。
