## 備考

非推奨
:   [XmlSchemaCollection](./) クラスは廃止されました。代わりに [XmlSchemaSet](../xmlschemaset/) を使用してください。

このクラスのオブジェクトは [System::MakeObject()](../../system/makeobject/) 関数を使用してのみ割り当てるべきです。スタック上または operator new を使用してインスタンスを作成しないでください。そうすると実行時エラーやアサーションエラーが発生します。常にこのクラスを [System::SmartPtr](../../system/smartptr/) ポインタでラップし、そのポインタを関数への引数として渡してください。
