## XmlSchemaAttribute::get_AttributeType() メソッド

属性が保持するポストコンパイル解釈の **AttributeType** の値に基づくオブジェクトを、[XmlSchemaAttribute::get_SchemaType](../get_schematype/) または [XmlSchemaAttribute::get_SchemaTypeName](../get_schematypename/) の値に基づいて返します。

```cpp
SharedPtr<Object> System::Xml::Schema::XmlSchemaAttribute::get_AttributeType()
```

### 戻り値

ポストコンパイル解釈の **AttributeType** の値を保持するオブジェクト。

非推奨
:   推奨される代わりに get_AttributeSchemaType メソッドを使用してください。
