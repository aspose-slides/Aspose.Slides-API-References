## XmlSchemaComplexContent::get_IsMixed() メソッド


型が混合コンテンツモデルを持つかどうかを決定する情報を返します。

```cpp
bool System::Xml::Schema::XmlSchemaComplexContent::get_IsMixed()
```


### 戻り値

この値が **true** の場合、複合型の子要素間に文字データを含めることができます（混合コンテンツモデル）。デフォルトは **false** です。 任意。
