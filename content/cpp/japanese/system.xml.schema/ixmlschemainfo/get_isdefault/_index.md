## IXmlSchemaInfo::get_IsDefault() method


この検証された XML ノードが、XML [Schema](../../) 定義言語 (XSD) スキーマ検証中にデフォルトが適用された結果として設定されたかどうかを示す値を返します。

```cpp
virtual bool System::Xml::Schema::IXmlSchemaInfo::get_IsDefault()=0
```


### 戻り値

**true** この検証された XML ノードがスキーマ検証中にデフォルトが適用された結果として設定された場合; それ以外の場合は **false**.
