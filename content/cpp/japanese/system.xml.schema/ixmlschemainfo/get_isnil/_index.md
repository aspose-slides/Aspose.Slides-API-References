## IXmlSchemaInfo::get_IsNil() メソッド

この検証済み XML ノードの値が **nil** かどうかを示す値を返します。

```cpp
virtual bool System::Xml::Schema::IXmlSchemaInfo::get_IsNil()=0
```

### 戻り値

**true** は、この検証済み XML ノードの値が **nil** の場合です。それ以外の場合は **false** です。
