## XmlSchema::get_FinalDefault() メソッド

**finalDefault** 属性を返します。この属性は、スキーマの対象名前空間内の要素および複合型に対する **final** 属性のデフォルト値を設定します。

```cpp
XmlSchemaDerivationMethod System::Xml::Schema::XmlSchema::get_FinalDefault()
```

### 戻り値

派生を防止するさまざまな方法を表す XmlSchemaDerivationMethod 値です。デフォルト値は [XmlSchemaDerivationMethod::None](../../xmlschemaderivationmethod/) です。
