## XmlSchema::get_BlockDefault() メソッド


**blockDefault**属性を返します。この属性は、**block**属性のデフォルト値をスキーマの**targetNamespace**内の要素および複合型に設定します。

```cpp
XmlSchemaDerivationMethod System::Xml::Schema::XmlSchema::get_BlockDefault()
```


### 戻り値

XmlSchemaDerivationMethodの値で、派生を防止するさまざまな方法を表します。デフォルト値は[XmlSchemaDerivationMethod::None](../../xmlschemaderivationmethod/)です。
