## XmlSchemaType::get_IsMixed() メソッド


この型が混在コンテンツモデルを持つかどうかを示す値を返します。この呼び出しは複合型でのみ有効です。

```cpp
virtual bool System::Xml::Schema::XmlSchemaType::get_IsMixed()
```


### 戻り値

**true** 型が混在コンテンツモデルを持つ場合; それ以外は **false**。デフォルトは **false** です。
