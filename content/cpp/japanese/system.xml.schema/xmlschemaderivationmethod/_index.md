## XmlSchemaDerivationMethod 列挙型

派生を防止するさまざまな方法を提供します。

```cpp
enum class XmlSchemaDerivationMethod
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Empty | 0 | デフォルトの派生方法を上書きし、任意の派生を許可します。 |
| Substitution | 1 | **Substitution** による派生を参照します。 |
| Extension | 2 | **Extension** による派生を参照します。 |
| Restriction | 4 | **Restriction** による派生を参照します。 |
| List | 8 | **List** による派生を参照します。 |
| Union | 16 | **Union** による派生を参照します。 |
| All | 255 | **#all**。すべての派生方法を参照します。 |
| None | 256 | デフォルトの派生方法を受け入れます。 |
