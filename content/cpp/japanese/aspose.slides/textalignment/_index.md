## TextAlignment enum

異なるテキスト配置スタイルを表します。

```cpp
enum class TextAlignment
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| NotDefined | -1 | デフォルトの配置。 |
| Left | 0 | 左揃え。 |
| Center | 1 | 中央揃え。 |
| Right | 2 | 右揃え。 |
| Justify | 3 | 両端揃え。 |
| JustifyLow | 4 | 低いカシーダ配置。 |
| Distributed | 5 | 配置を均等に割り当て。 |
