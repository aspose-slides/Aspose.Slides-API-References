## IDocumentProperties::set_LinksUpToDate(bool) メソッド

ドキュメント内のハイパーリンクが最新かどうかを示します。ハイパーリンクが更新されていることを示すには、この要素を **true** に設定します。ハイパーリンクが古くなっていることを示すには、この要素を **false** に設定します。書き込みは **bool** 型です。

virtual void Aspose::Slides::IDocumentProperties::set_LinksUpToDate(bool value)=0
