## IDocumentProperties::set_ScaleCrop(bool) メソッド

ドキュメントのサムネイルの表示モードを示します。この要素を **true** に設定すると、サムネイルをディスプレイに合わせて拡大できます。この要素を **false** に設定すると、サムネイルをクロップして、ディスプレイに収まるセクションのみを表示します。書き込む型は **bool** です。

```cpp
virtual void Aspose::Slides::IDocumentProperties::set_ScaleCrop(bool value)=0
```
