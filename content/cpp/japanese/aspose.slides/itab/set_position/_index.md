## ITab::set_Position(double) メソッド

タブの位置を設定します。このプロパティを設定すると、コレクション内のタブのインデックスが変更され、Enumerator が無効になる可能性があります。**double** を書き込みます。

```cpp
virtual void Aspose::Slides::ITab::set_Position(double value)=0
```
