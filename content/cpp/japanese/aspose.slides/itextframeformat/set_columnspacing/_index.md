## ITextFrameFormat::set_ColumnSpacing(double) メソッド


テキスト領域内のテキスト列間のスペースを設定します（ポイント単位）。列が 1 列以上ある場合にのみ適用されるべきです。この値は正の数でなければなりません。そうでない場合、値は 0 に設定されます。**double** を書き込みます。

```cpp
virtual void Aspose::Slides::ITextFrameFormat::set_ColumnSpacing(double value)=0
```
