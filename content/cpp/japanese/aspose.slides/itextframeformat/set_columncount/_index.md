## ITextFrameFormat::set_ColumnCount(int32_t) メソッド

テキスト領域の列数を設定します。この値は正の数である必要があります。それ以外の場合、値は 0 に設定されます。値 0 は未定義の値を意味します。書き込みは **int32_t** です。

virtual void Aspose::Slides::ITextFrameFormat::set_ColumnCount(int32_t value)=0
