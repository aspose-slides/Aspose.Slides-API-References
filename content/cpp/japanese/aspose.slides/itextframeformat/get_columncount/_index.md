## ITextFrameFormat::get_ColumnCount() メソッド

テキスト領域の列数を返します。この値は正の数でなければなりません。そうでない場合、値は 0 に設定されます。値 0 は未定義の値を意味します。**int32_t** を読み取ります。

```cpp
virtual int32_t Aspose::Slides::ITextFrameFormat::get_ColumnCount()=0
```
