## ShapeAdjustmentType 列挙型

形状調整値のさまざまなタイプを指定します。

```cpp
enum class ShapeAdjustmentType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Custom | 0 | カスタムタイプ（不明な調整） |
| CornerSize | 1 | コーナーのサイズを制御します。 |
| LeftUpCorner | 2 | 左上コーナーを制御します。 |
| RightUpCorner | 3 | 右上コーナーを制御します。 |
| UpCorners | 4 | 上部のコーナーを制御します。 |
| DownCorners | 5 | 下部のコーナーを制御します。 |
| Thickness | 6 | 図形の厚さを制御します。 |
| ArrowTailThickness | 7 | 矢じりの太さを制御します。 |
| ArrowheadLength | 8 | 矢じりの長さを制御します。 |
| ArrowheadWidth | 9 | 矢じりの幅を制御します。 |
| Radius | 10 | 図形またはその一部の半径のサイズを制御します。 |
| Depth | 11 | 歯車の歯の深さまたはベベル効果を制御します。 |
| ShapePartOffset | 12 | 図形の一部が別の部分に対して持つオフセットを制御します。 |
| Angle | 13 | 図形またはその一部の角度を制御します。 |
| StartAngle | 14 | パイや円弧形状の開始角度です。 |
| EndAngle | 15 | パイや円弧形状の終了角度です。 |
| StartPointX | 16 | 吹き出し開始点の X 位置を制御します。 |
| StartPointY | 17 | 吹き出し開始点の Y 位置を制御します。 |
| ConnectorPoint1X | 18 | 吹き出し角度調整点の水平位置を制御します。 |
| ConnectorPoint1Y | 19 | 吹き出し角度調整点の垂直位置を制御します。 |
| ConnectorPoint2X | 20 | 吹き出し角度調整点の水平位置を制御します。 |
| ConnectorPoint2Y | 21 | 吹き出し角度調整点の垂直位置を制御します。 |
| ConnectorBendPositionX | 22 | コネクタの曲げ位置の水平位置を制御します。 |
| ConnectorBendPositionY | 23 | コネクタの曲げ位置の垂直位置を制御します。 |
| AttachY | 24 | 図形の垂直方向の接続点を制御します。 |
| AttachX | 25 | 図形の水平方向の接続点を制御します。 |
| CalloutHeight | 26 | 吹き出しの垂直サイズを制御します。 |
| CalloutWidth | 27 | 吹き出しの水平サイズを制御します。 |
| CalloutSize | 28 | 吹き出しのサイズを制御します。 |
| Curvature | 29 | 曲がった、波括弧、曲線矢印または形状の曲率です。 |
| HorizontalThickness | 30 | コーナー形状の水平厚さを制御します。 |
| VerticalThickness | 31 | コーナー形状の垂直厚さを制御します。 |
| VerticalSize | 32 | 図形の垂直サイズを制御します。 |
| HorizontalSize | 33 | 図形の水平サイズを制御します。 |
| Top | 34 | 図形の上側を制御します。 |
