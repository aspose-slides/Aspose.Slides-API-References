## TextAutofitType 列挙型

テキスト自動調整モードを表します。

```cpp
enum class TextAutofitType : int8_t
```

### 値

| Name | Value | Description |
| --- | --- | --- |
| NotDefined | -1 | 未定義。 |
| None | 0 | 自動調整なし。 |
| Normal | 1 | 通常の自動調整。フォントサイズと行間隔はシェイプに合わせて縮小されます。 |
| Shape | 2 | [Shape](../shape/) 自動調整。 [Shape](../shape/) サイズはテキストに合わせて変更されます。 |
