## ColorType enum

さまざまなカラーモードを表します。

```cpp
enum class ColorType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| NotDefined | -1 | 色はまったく定義されていません。 |
| RGB | 0 | 標準 24 ビット RGB カラー。 |
| RGBPercentage | 1 | 高精細 RGB カラー。 |
| HSL | 2 | 高精細 HSL カラー。 |
| Scheme | 3 | Scheme カラー。 |
| System | 4 | [System](../../system/) カラー。 |
| Preset | 5 | Preset カラー。 |
