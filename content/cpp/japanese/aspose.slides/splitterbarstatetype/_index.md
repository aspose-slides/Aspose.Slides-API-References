## SplitterBarStateType 列挙型

スプリッターバーが表示される状態を指定します。スプリッターバーは、表示領域内の主領域と副領域を分割します。

```cpp
enum class SplitterBarStateType
```

### 値

| Name | Value | Description |
| --- | --- | --- |
| Minimized | 0 | アプリケーションが許可する表示領域の最小量を主領域が占めます。 |
| Restored | 1 | 主領域は特定の中間サイズを持ちます。 |
| Maximized | 2 | アプリケーションが許可する表示領域の最大量を主領域が占めます。 |
