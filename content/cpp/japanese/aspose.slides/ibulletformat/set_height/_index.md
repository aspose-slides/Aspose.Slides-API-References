## IBulletFormat::set_Height(float) メソッド


継承しない段落の弾丸の高さを設定します。値 std::numeric_limits<float>::quiet_NaN() は、弾丸が段落の最初の部分から高さを継承することを決定します。**float** を書き込みます。

virtual void Aspose::Slides::IBulletFormat::set_Height(float value)=0
