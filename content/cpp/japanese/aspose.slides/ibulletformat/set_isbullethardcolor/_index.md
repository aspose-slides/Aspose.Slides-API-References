## IBulletFormat::set_IsBulletHardColor(NullableBool) メソッド


段落の最初の部分から色を継承するか、バレットが独自の色を持つかを決定します。**[NullableBool::True](../../nullablebool/)** はバレットが独自の色を持つ場合、**[NullableBool::False](../../nullablebool/)** はバレットが段落の最初の部分から色を継承する場合です。[NullableBool](../../nullablebool/) を書き込みます。

virtual void Aspose::Slides::IBulletFormat::set_IsBulletHardColor(NullableBool value)=0
