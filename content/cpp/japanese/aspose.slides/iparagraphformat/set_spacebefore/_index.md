## IParagraphFormat::set_SpaceBefore(float) メソッド

継承されない段落の最初の行の前のスペース量を設定します。正の値は、フォントサイズに対する余白のパーセンテージを指定します。負の値は、ポイントサイズで余白のサイズを指定します。書き込みは **float** です。

```cpp
virtual void Aspose::Slides::IParagraphFormat::set_SpaceBefore(float value)=0
```
