## IParagraphFormat::set_SpaceAfter(float) メソッド

段落の最後の行の後にある余白の量を設定します（継承なし）。正の値は、余白がフォントサイズの何パーセントになるかを指定します。負の値は、余白のサイズをポイント単位で指定します。型は **float** です。

```cpp
virtual void Aspose::Slides::IParagraphFormat::set_SpaceAfter(float value)=0
```
