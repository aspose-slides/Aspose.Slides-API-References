## LoadOptions::get_BlobManagementOptions() メソッド

Binary Large Objects (BLOB) の取り扱い動作を管理するために使用できるオプションを表します。たとえば、一時ファイルの使用やメモリ内の BLOB の最大バイト数などです。これらのオプションは、特定の環境または要件に対して、最適なパフォーマンスとメモリ消費のバランスを設定することを目的としています。

```cpp
System::SharedPtr<IBlobManagementOptions> Aspose::Slides::LoadOptions::get_BlobManagementOptions() override
```
## 備考

Binary Large Object (BLOB) は、単一のエンティティとして格納されるバイナリデータです。つまり、BLOB は音声、ビデオ、またはプレゼンテーションそのものになることがあります。
