## BulletFormat::get_Height() メソッド


段落が継承されていない場合の箇条書きの高さを返します。値 std::numeric_limits<float>::quiet_NaN() は、箇条書きが段落の最初の部分から高さを継承することを示します。**float** を読み取ります。

```cpp
float Aspose::Slides::BulletFormat::get_Height() override
```

## 備考


負の高さの値は高さがポイントで指定されていることを意味し、正の値は高さが周囲のテキストに対する割合であることを意味します。
