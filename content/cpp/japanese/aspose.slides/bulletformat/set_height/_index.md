## BulletFormat::set_Height(float) メソッド


継承なしで段落の箇条書きの高さを設定します。値 std::numeric_limits<float>::quiet_NaN() は、箇条書きが段落の最初の部分から高さを継承することを示します。**float** を記述します。

```cpp
void Aspose::Slides::BulletFormat::set_Height(float value) override
```

## 備考


負の高さの値は高さがポイントで指定されていることを意味し、正の値は高さが周囲のテキストの百分率であることを意味します。
