## IComment::set_CreatedTime(System::DateTime) メソッド

コメントの作成時刻を設定します。 このプロパティを [DateTime::MinValue](../../../system/datetime/minvalue/) に設定すると、コメントの時刻が設定されていないことを意味します。 [System::DateTime](../../../system/datetime/) を書き込みます。

```cpp
virtual void Aspose::Slides::IComment::set_CreatedTime(System::DateTime value)=0
```
