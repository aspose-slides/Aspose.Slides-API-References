## IBlobManagementOptions::set_IsTemporaryFilesAllowed(bool) メソッド

このプロパティは、BLOB を操作中に一時ファイルを作成できるかどうかを定義します。一時ファイルはメモリ使用量を大幅に減らしますが、ファイル作成の権限が必要です。

```cpp
virtual void Aspose::Slides::IBlobManagementOptions::set_IsTemporaryFilesAllowed(bool value)=0
```

## 備考

プレゼンテーションの作業が完了した後、すべてのファイルが削除されます。
