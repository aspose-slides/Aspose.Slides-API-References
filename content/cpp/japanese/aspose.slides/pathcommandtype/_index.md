## PathCommandType enum

グラフィックパスコマンドを表します

```cpp
enum class PathCommandType : uint8_t
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Close | 0 | ジオメトリパスを閉じます |
| MoveTo | 1 | ジオメトリパスの次の点の位置を設定します |
| LineTo | 2 | ジオメトリパスに直線を追加します |
| ArcTo | 3 | ジオメトリパスに指定された円弧を追加します。 |
| QuadBezierTo | 4 | ジオメトリパスに二次ベジエ曲線を追加します |
| CubicBezierTo | 5 | ジオメトリパスに三次ベジエ曲線を追加します |
