## IProtectionManager::set_EncryptDocumentProperties(bool) メソッド

このプロパティは、プレゼンテーションがパスワードで保護されている場合に意味があります。true の場合、ドキュメントプロパティはプレゼンテーション ファイル内で暗号化されます。false の場合、ドキュメントプロパティは公開され、プレゼンテーション自体は暗号化されます。書き込みは **bool** です。

```cpp
virtual void Aspose::Slides::IProtectionManager::set_EncryptDocumentProperties(bool value)=0
```
