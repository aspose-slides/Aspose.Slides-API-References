## ILoadOptions::set_BlobManagementOptions(System::SharedPtr\<IBlobManagementOptions\>) メソッド

Binary Large Objects (BLOBs) の取り扱い動作を管理するために使用できるオプションを表します。たとえば、一時ファイルの使用やメモリ内の BLOB の最大バイト数などです。これらのオプションは、特定の環境や要件に合わせて、最高のパフォーマンス/メモリ消費比率を設定することを目的としています。

```cpp
virtual void Aspose::Slides::ILoadOptions::set_BlobManagementOptions(System::SharedPtr<IBlobManagementOptions> value)=0
```

## 備考

Binary Large Object (BLOB) は、単一のエンティティとして格納されたバイナリデータです。つまり、BLOB は音声、動画、またはプレゼンテーションそのものになることがあります。
