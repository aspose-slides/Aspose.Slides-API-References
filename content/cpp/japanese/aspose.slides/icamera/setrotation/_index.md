## ICamera::SetRotation(float, float, float) メソッド

回転は、緯度座標、経度座標、および緯度と経度座標としての軸周りの回転を使用して定義されます。座標値のいずれかが std::numeric_limits<float>::quiet_NaN() の場合、すべての回転は未定義となります。

```cpp
virtual void Aspose::Slides::ICamera::SetRotation(float latitude, float longitude, float revolution)=0
```

| パラメータ | 型 | 説明 |

| latitude | **float** | 緯度の値 **float** |
| longitude | **float** | 経度の値 **float** |
| revolution | **float** | 回転値 **float** |
