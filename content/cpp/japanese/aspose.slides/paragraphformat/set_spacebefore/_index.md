## ParagraphFormat::set_SpaceBefore(float) メソッド


段落の最初の行の前にあるスペースの量を継承せずに設定します。正の値は、空白領域のサイズをフォントサイズのパーセンテージで指定します。負の値は、空白領域のサイズをポイントサイズで指定します。**float** を書き込みます。

```cpp
void Aspose::Slides::ParagraphFormat::set_SpaceBefore(float value) override
```
