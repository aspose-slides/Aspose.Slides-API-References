## TextFrameFormat::set_ColumnSpacing(double) メソッド

テキスト領域内のテキスト列間の間隔をポイント単位で設定します。これは、列が 1 つ以上ある場合にのみ適用されるべきです。この値は正の数でなければなりません。そうでない場合、値は 0 に設定されます。**double** 型で書き込みます。

void Aspose::Slides::TextFrameFormat::set_ColumnSpacing(double value) override
