## IShape::set_X(float) メソッド

形状の左上隅の x 座標をポイント単位で設定します。**float** を記述します。

```cpp
virtual void Aspose::Slides::IShape::set_X(float value)=0
```

## 備考

返される値は常に定義されており、[std::numeric_limits<float>::quiet_NaN()](../) になることはありません。割り当てられる値も定義されている必要があります。[std::numeric_limits<float>::quiet_NaN()](../) は **RawFrame** インスタンスのプロパティにのみ割り当ててください。
