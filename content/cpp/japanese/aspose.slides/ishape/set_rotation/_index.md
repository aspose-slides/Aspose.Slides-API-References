## IShape::set_Rotation(float) メソッド

指定されたシェイプが z 軸の周りに回転する角度（度）を設定します。正の値は時計回りの回転を示し、負の値は反時計回りの回転を示します。**float** を記述します。

```cpp
virtual void Aspose::Slides::IShape::set_Rotation(float value)=0
```

## 備考

返される値は常に定義されています（std::numeric_limits<float>::quiet_NaN() ではありません）。割り当てられる値も定義されている必要があります（std::numeric_limits<float>::quiet_NaN() ではありません）。RawFrame インスタンスのプロパティに未定義の値を設定することができます。
