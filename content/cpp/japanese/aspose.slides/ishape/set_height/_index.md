## 備考


返された値は常に定義されており、決して [std::numeric_limits<float>::quiet_NaN()](../) ではありません。割り当てられる値も定義されている必要があります。[std::numeric_limits<float>::quiet_NaN()](../) は **RawFrame** インスタンスのプロパティにのみ割り当ててください。
