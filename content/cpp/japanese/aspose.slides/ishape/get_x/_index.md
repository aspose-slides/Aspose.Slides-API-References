## IShape::get_X() メソッド

シェイプの左上隅の x 座標をポイント単位で取得します。**float** を読み取ります。

```cpp
virtual float Aspose::Slides::IShape::get_X()=0
```

## 備考

返される値は常に定義されており、[std::numeric_limits<float>::quiet_NaN()](../) になることはありません。代入される値も定義されている必要があります；**RawFrame** インスタンスのプロパティに対してのみ [std::numeric_limits<float>::quiet_NaN()](../) を代入してください。
