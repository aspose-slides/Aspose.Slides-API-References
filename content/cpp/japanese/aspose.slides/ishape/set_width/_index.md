## IShape::set_Width(float) メソッド

シェイプの幅をポイント単位で設定します。**float** を指定してください。

```cpp
virtual void Aspose::Slides::IShape::set_Width(float value)=0
```

## 備考

返される値は常に定義されており、[std::numeric_limits<float>::quiet_NaN()](../) になることはありません。割り当てる値も定義されたものでなければなりません。**RawFrame** インスタンスのプロパティにのみ [std::numeric_limits<float>::quiet_NaN()](../) を割り当ててください。
