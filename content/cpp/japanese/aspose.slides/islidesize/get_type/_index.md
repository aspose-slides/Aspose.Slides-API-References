## ISlideSize::get_Type() メソッド

スライドのサイズタイプを取得します。[SlideSizeType::Custom](../../slidesizetype/) 以外の任意の値を設定すると、事前定義された寸法に従って [ISlideSize::get_Size](../get_size/) が調整され、現在の [ISlideSize::get_Orientation](../get_orientation/) は保持されます。

```cpp
virtual SlideSizeType Aspose::Slides::ISlideSize::get_Type()=0
```

## 備考

[SlideSizeType::Custom](../../slidesizetype/) 以外の任意の値を設定すると、事前定義された寸法に従って [System::Drawing::Size](../../../system.drawing/size/) が調整され、現在の [Orientation](../../orientation/) は保持されます。
