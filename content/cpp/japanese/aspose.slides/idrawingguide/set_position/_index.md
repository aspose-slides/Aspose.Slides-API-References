## IDrawingGuide::set_Position(float) メソッド

描画ガイドの位置を、スライドの左上隅からポイント単位で設定します。**float** を記述してください。

```cpp
virtual void Aspose::Slides::IDrawingGuide::set_Position(float value)=0
```

## 備考

水平ガイドの場合は0からスライドの高さまで、垂直ガイドの場合は0からスライドの幅までが典型的な値の範囲です。
