## ITextSearchOptions::set_IncludeNotes(bool) メソッド

**true** を設定すると、テキスト検索、置換、またはハイライト操作を実行する際にスライドノートに含まれるテキストが対象に含まれます。デフォルト値は **false** です。

virtual void Aspose::Slides::ITextSearchOptions::set_IncludeNotes(bool value)=0
