## PathFillModeType 列挙型

パスを塗りつぶす方法を指定します

```cpp
enum class PathFillModeType : uint8_t
```

### 値

| Name | Value | Description |
| --- | --- | --- |
| None | 0 | パスに塗りつぶしがありません。これは、対応するパスに塗りつぶしがないことを示します。 |
| Normal | 1 | 通常のパス塗りつぶしです。これは、対応するパスの塗りつぶしに通常の陰影色が適用されることを示します。 |
| Lighten | 2 | 明るくするパス塗りつぶしです。これは、対応するパスの塗りつぶしに薄く陰影付けされた色が適用されることを示します。 |
| LightenLess | 3 | わずかに明るいパス塗りつぶしです。これは、対応するパスの塗りつぶしにやや明るい陰影色が適用されることを示します。 |
| Darken | 4 | 暗くするパス塗りつぶしです。これは、対応するパスの塗りつぶしに暗い陰影色が適用されることを示します。 |
| DarkenLess | 5 | わずかに暗いパス塗りつぶしです。これは、対応するパスの塗りつぶしにやや暗い陰影色が適用されることを示します。 |
