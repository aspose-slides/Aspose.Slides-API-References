## IPictureFillFormat::set_StretchOffsetLeft(float) メソッド

塗りつぶし矩形の左端を設定します。この矩形は、シェイプのバウンディングボックスの左端からのパーセンテージオフセットで定義されます。正のパーセンテージはインセットを指定し、負のパーセンテージはアウトセットを指定します。**float** を書き込みます。

```cpp
virtual void Aspose::Slides::IPictureFillFormat::set_StretchOffsetLeft(float value)=0
```
