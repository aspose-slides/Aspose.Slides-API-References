## Hyperlink::get_ExternalUrlOriginal() method

この部分の実際の内容に関係なく設定されたハイパーリンクを表します。

```cpp
System::String Aspose::Slides::Hyperlink::get_ExternalUrlOriginal() override
```

## 備考

PowerPoint は、部分内のリンクとそれに対応するテキストに対して特有の動作をします。有効な URL の形式でハイパーリンクのテキストを作成でき、リンクの実際のアドレスとは異なります。この場合、編集ウィンドウでリンクを表示すると、テキスト部分に合わせて変更されます。このプロパティはハイパーリンクの元の値を表します。
