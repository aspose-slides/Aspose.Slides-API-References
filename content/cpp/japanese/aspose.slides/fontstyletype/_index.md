## FontStyleType 列挙型

テキストに適用できる書式スタイルを定義します。

```cpp
enum class FontStyleType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Regular | 0 | 標準テキスト。 |
| Bold | 1 | 太字テキスト。 |
| Italic | 2 | 斜体テキスト。 |
| Underline | 4 | 下線付きテキスト。 |
| Strikeout | 8 | 横線で取り消し線が付いたテキスト。 |
