## Shape::set_Rotation(float) method

指定されたシェイプが Z 軸周りに回転する角度（度）を設定します。正の値は時計回りの回転を示し、負の値は反時計回りの回転を示します。書き込み型は **float** です。

```cpp
void Aspose::Slides::Shape::set_Rotation(float value) override
```

## 備考

返される値は常に定義されています（std::numeric_limits<float>::quiet_NaN() ではありません）。代入する値も定義されている必要があります（std::numeric_limits<float>::quiet_NaN() ではありません）。RawFrame インスタンスのプロパティには未定義の値を設定できます。
