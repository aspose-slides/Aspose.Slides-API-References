## Shape::set_Frame(System::SharedPtr\<IShapeFrame\>) メソッド

シェイプフレームのプロパティを設定します。[IShapeFrame](../../ishapeframe/)を書き込みます。

```cpp
void Aspose::Slides::Shape::set_Frame(System::SharedPtr<IShapeFrame> value) override
```

## 備考

返された [IShapeFrame](../../ishapeframe/) インスタンスの各プロパティの値は未定義ではありません（NaN または NotDefined ではありません）。割り当てられた [IShapeFrame](../../ishapeframe/) インスタンスの各プロパティの値は未定義であってはなりません（NaN または NotDefined ではない必要があります）。RawFrame インスタンスのプロパティには未定義の値を設定できます。
