## IHyperlink::get_ExternalUrlOriginal() メソッド

この部分の実際の内容に関係なく、この部分に設定されたハイパーリンクを表します。

```cpp
virtual System::String Aspose::Slides::IHyperlink::get_ExternalUrlOriginal()=0
```

## 備考

PowerPoint は、部分内のリンクとそれに対応するテキストに対して特有の動作を行います。リンクの実際のアドレスとは異なる、有効な URL 形式のテキストをハイパーリンクとして作成することが可能です。この場合、編集ウィンドウでリンクを表示すると、テキスト部分に合わせてリンクが変更されます。このプロパティはハイパーリンクの元の値を表します。
