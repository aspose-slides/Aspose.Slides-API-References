## IMasterSlide::set_Preserve(bool) メソッド


対応するマスタが、そのマスタに続くすべてのスライドが削除されたときに削除されるかどうかを決定します。注: [Aspose.Slides](../../) は単独で未使用のマスタを決して削除しません。未使用のマスタを実際に削除するには [IMasterSlideCollection::RemoveUnused](../../imasterslidecollection/removeunused/) を呼び出してください **bool** を書き込みます。

virtual void Aspose::Slides::IMasterSlide::set_Preserve(bool value)=0
