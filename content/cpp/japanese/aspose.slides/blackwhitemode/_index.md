## BlackWhiteMode enum

色付きシェイプがどのように白黒に変換されるかを決定します。

```cpp
enum class BlackWhiteMode : int8_t
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| NotDefined | -1 | プロパティが設定されていません |
| Color | 0 | オブジェクトは通常のカラーリングで描画されます |
| Automatic | 1 | オブジェクトは自動カラーリングで描画されます |
| Gray | 2 | オブジェクトはグレーのカラーリングで描画されます |
| LightGray | 3 | オブジェクトは薄いグレーのカラーリングで描画されます |
| InverseGray | 4 | オブジェクトは逆グレーのカラーリングで描画されます |
| GrayWhite | 5 | オブジェクトはグレーと白のカラーリングで描画されます |
| BlackGray | 6 | オブジェクトは黒とグレーのカラーリングで描画されます |
| BlackWhite | 7 | オブジェクトは黒と白のカラーリングで描画されます |
| Black | 8 | オブジェクトは黒のカラーリングのみで描画されます |
| White | 9 | オブジェクトは白のカラーリングで描画されます |
| Hidden | 10 | オブジェクトは描画されません |
