## IBackdrop3DScene::set_NormalVector(System::ArrayPtr\<float\>) メソッド

法線ベクトルを設定します。より正確に言えば、この属性はバックドロップ平面の面に対して法線となるベクトルを定義します。ベクトルは X、Y、Z 座標を定義する 3 つの float 値の配列で表されます。書き込み形式は **float**[] です。

```cpp
virtual void Aspose::Slides::IBackdrop3DScene::set_NormalVector(System::ArrayPtr<float> value)=0
```
