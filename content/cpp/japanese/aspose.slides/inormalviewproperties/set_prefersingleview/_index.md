## INormalViewProperties::set_PreferSingleView(bool) メソッド


ユーザーが3つのコンテンツ領域を持つ標準のノーマルビューではなく、全ウィンドウ単一コンテンツ領域を表示することを好むかどうかを指定します。有効にすると、アプリケーションはコンテンツ領域の1つをウィンドウ全体に表示することを選択できる場合があります。書き込みは **bool** です。

```cpp
virtual void Aspose::Slides::INormalViewProperties::set_PreferSingleView(bool value)=0
```
