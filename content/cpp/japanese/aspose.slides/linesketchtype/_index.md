## LineSketchType enum


シェイプに割り当てられたスケッチタイプまたはエフェクトを表します。

```cpp
enum class LineSketchType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| NotDefined | -1 | シェイプのスケッチ効果が未定義であることを示します。 |
| None | 0 | シェイプにスケッチ効果がないことを示します。これはこのプロパティが空であることと同等です。 |
| Curved | 1 | シェイプに Curved エフェクトがあることを示します。これはシェイプの各エッジを大きな滑らかな曲線に変換します。 |
| Freehand | 2 | シェイプに Freehand エフェクトがあることを示します。これは最も不完全に描かれた線に近いものです。 |
| Scribble | 3 | シェイプに Scribble エフェクトがあることを示します。これは意図的に乱雑に描かれたかのように誇張された揺れを持ちます。 |
