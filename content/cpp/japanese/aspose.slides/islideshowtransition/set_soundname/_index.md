## ISlideShowTransition::set_SoundName(System::String) メソッド


遷移サウンドの人が読める名前を指定します。[ISlideShowTransition::set_Sound](../set_sound/) はサウンド名を取得または設定するために割り当てる必要があります。[System::String](../../../system/string/) に書き込みます。

```cpp
virtual void Aspose::Slides::ISlideShowTransition::set_SoundName(System::String value)=0
```

## 備考


この名前は、遷移サウンドを手動で設定するときに PowerPoint のユーザーインターフェイスに表示されます。
