## ISlideShowTransition::get_SoundIsBuiltIn() メソッド

このサウンドが組み込みサウンドかどうかを指定します。この属性が true に設定されている場合、生成アプリケーションはこのサウンドの name 属性が組み込みサウンドのリストにあるかどうかを確認するよう警告され、必要に応じてカスタム名または UI を表示できます。**bool** を読み取ります。

```cpp
virtual bool Aspose::Slides::ISlideShowTransition::get_SoundIsBuiltIn()=0
```
