## ISlideShowTransition::set_SoundIsBuiltIn(bool) メソッド

このサウンドが組み込みサウンドかどうかを指定します。この属性が true に設定されている場合、生成アプリケーションはこのサウンドの name 属性が組み込みサウンドのリストにあるかどうかを確認するよう通知され、必要に応じてカスタム名や UI を表示できます。書き込みは **bool** です。

```cpp
virtual void Aspose::Slides::ISlideShowTransition::set_SoundIsBuiltIn(bool value)=0
```
