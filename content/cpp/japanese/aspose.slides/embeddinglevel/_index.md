## EmbeddingLevel 列挙型

フォントを埋め込むためのライセンス権を表します。

```cpp
enum class EmbeddingLevel : uint16_t
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Installable | 0 | [Fonts](../fonts/) この設定では、アプリケーションによってフォントが埋め込まれ、リモートシステムに永続的にインストールできることを示します。リモートシステムのユーザーは、そのフォントの元の購入者と同一の権利、義務、ライセンスを取得し、元の購入者と同じエンドユーザー使用許諾契約、著作権、意匠特許、または商標の対象となります。 |
| Restricted | 2 | [Fonts](../fonts/) このビットだけが設定されているものは、まず法的所有者の許可を得ずに、いかなる方法でも変更、埋め込み、または交換してはなりません。 |
| PreviewPrint | 4 | このビットが設定されている場合、フォントは埋め込むことができ、リモートシステムに一時的にロードされます。Preview & Print フォントを含むドキュメントは \"読み取り専用;\" 開く必要があり、ドキュメントに対して編集を行うことはできません。 |
| Editable | 8 | このビットが設定されている場合、フォントは埋め込むことができますが、他のシステムに一時的にのみインストールする必要があります。Preview & Print フォントとは対照的に、Editable フォントを含むドキュメントは読み取り用に開くことができ、編集が許可され、変更を保存することができます。 |
| NoSubsetting | 256 | このビットが設定されている場合、フォントは埋め込み前にサブセット化できません。ビット 0-3 および 9 で指定された他の埋め込み制限も適用されます。 |
| BitmapOnly | 512 | このビットが設定されている場合、フォントに含まれるビットマップのみが埋め込むことができます。アウトラインデータは埋め込めません。フォントにビットマップが存在しない場合、そのフォントは埋め込めないとみなされ、埋め込みサービスは失敗します。 |
