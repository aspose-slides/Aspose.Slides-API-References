## DigitShapes 列挙型

数字の表示方法を指定します。

```cpp
enum class DigitShapes : int32_t
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Context | 0 | 数字の形は前のテキストに依存します。 |
| None | 1 | 数字の形は変更されません。 |
| NativeNational | 2 | ASCII の数字 0..9 がネイティブの国数字に置き換えられます。 |
