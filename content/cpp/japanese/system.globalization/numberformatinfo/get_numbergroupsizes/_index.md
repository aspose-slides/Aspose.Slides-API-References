## NumberFormatInfo::get_NumberGroupSizes() const メソッド

グループごとの桁数を取得します。

```cpp
ArrayPtr<int> System::Globalization::NumberFormatInfo::get_NumberGroupSizes() const
```

### 戻り値

[Array](../../../system/array/) 桁数のグループ、左から右へ; 各要素は 1 から 9 の間でなければならず、最後の要素は 0 にでき、これは "すべて結合" を意味します; 最後の要素は繰り返されます。
