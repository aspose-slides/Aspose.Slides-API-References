## WeakPtr::get_weak() const メソッド

参照されたオブジェクトを取得します。ポインタが弱参照モードであることをアサートします。

```cpp
Object * System::WeakPtr<T>::get_weak() const
```

### 戻り値

参照されたオブジェクトへの生ポインタ（割り当てられ、期限切れでない場合）または nullptr。
