## Uri::IsHexEncoding(const String\&, int32_t) メソッド

指定された位置の文字が 16 進数でエンコードされているかどうかを判断します。

```cpp
static bool System::Uri::IsHexEncoding(const String &pattern, int32_t index)
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| pattern | const [String](../../string/)\& | チェックする文字列 |
| index | **int32_t** | テスト対象文字のゼロベース位置 |

### 戻り値

指定された文字が 16 進数でエンコードされている場合は true、そうでない場合は false
