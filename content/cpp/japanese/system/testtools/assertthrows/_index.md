## TestTools::AssertThrows(const std::function\<void()>\&) メソッド

関数が任意の型の例外をスローするかどうかをチェックします。

```cpp
static bool System::TestTools::AssertThrows(const std::function<void()> &func)
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| func | const std::function\<void()>\& | スローを確認する関数。 |

### 戻り値

関数がスローした場合は true、そうでなければ false。
