## Delegate< ReturnType(ArgumentTypes...)>::Empty() const メソッド

現在の delegate オブジェクトが空かどうかを判断します。たとえば、任意のエンティティを指していない場合です。

```cpp
bool System::Delegate<ReturnType(ArgumentTypes...)>::Empty() const
```

### 戻り値

現在の delegate オブジェクトが関数や関数オブジェクトのメソッドを指していない場合は true、そうでなければ false です。
