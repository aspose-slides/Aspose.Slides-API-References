## Array::cend() const メソッド


コンテナの最後の要素の次にある要素へのイテレータを返します。この要素はプレースホルダーとして機能し、アクセスしようとすると未定義の動作になります。

```cpp
const_iterator System::Array<T>::cend() const noexcept
```


### 戻り値

コンテナの最後の要素の後に配置された、理論上の const 修飾された要素を指すイテレータです。
