## Array::cbegin() const メソッド


コンテナの最初の const 修飾要素へのイテレータを返します。コンテナが空の場合、返されるイテレータは [cend()](../cend/) と等しくなります。

```cpp
const_iterator System::Array<T>::cbegin() const noexcept
```


### 戻り値

コンテナの最初の const 修飾要素を指すイテレータです。
