## Array::crend() const メソッド

リバースされたコンテナの最後の要素の次の要素への逆イテレータを返します。これは、リバースされていないコンテナの最初の要素の前の要素に対応します。この要素はプレースホルダとして機能し、アクセスしようとすると未定義の動作になります。

```cpp
const_reverse_iterator System::Array<T>::crend() const noexcept
```

### 戻り値

コンテナの最初の要素の前にある理論上の const 修飾要素を指すイテレータです。
