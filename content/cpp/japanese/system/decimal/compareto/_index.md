## Decimal::CompareTo(const Decimal\&) const メソッド


現在のオブジェクトが表す値が、指定されたオブジェクトが表す値より小さいか、等しいか、または大きいかを判断します。

```cpp
int System::Decimal::CompareTo(const Decimal &d) const
```


### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| d | const [Decimal](../)\& | 比較対象 |

### 戻り値

- 1 は、現在のオブジェクトが表す値が **d** が表す値より小さい場合; 0 は、値が等しい場合; 1 は、現在のオブジェクトが表す値が **d** が表す値より大きい場合
