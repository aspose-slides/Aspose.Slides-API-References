## Decimal::Compare(const Decimal\&, const Decimal\&) メソッド


最初の [Decimal](../) オブジェクトが表す値が、2番目の [Decimal](../) オブジェクトが表す値より小さいか、等しいか、または大きいかを判定します。

```cpp
static int System::Decimal::Compare(const Decimal &d1, const Decimal &d2)
```


### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| d1 | const [Decimal](../)\& | 最初の比較対象 |
| d2 | const [Decimal](../)\& | 2番目の比較対象 |

### 戻り値

- 1 は **d1** が表す値が **d2** が表す値より小さい場合、0 は値が等しい場合、1 は **d1** が表す値が **d2** が表す値より大きい場合です。
