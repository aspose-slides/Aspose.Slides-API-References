## WeakReference<>::get_IsAlive() const メソッド


現在の WeakReference オブジェクトが参照しているオブジェクトが削除されたかどうかを示すインジケータを取得します。

```cpp
bool System::WeakReference<>::get_IsAlive() const
```


### 戻り値

オブジェクトが期限切れでない場合は true、そうでない場合は false。
