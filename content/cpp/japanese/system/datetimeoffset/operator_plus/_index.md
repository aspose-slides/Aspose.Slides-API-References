## DateTimeOffset::operator+(TimeSpan) const メソッド

```cpp
DateTimeOffset System::DateTimeOffset::operator+(TimeSpan value) const
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| value | [TimeSpan](../../timespan/) | 現在のオブジェクトが表す値に加える時間間隔 |

### 戻り値

[DateTimeOffset](../) クラスの新しいインスタンスで、現在のオブジェクトが表す値と **値** の合計となる日付と時刻の値を表します。
