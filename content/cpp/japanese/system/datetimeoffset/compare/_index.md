## DateTimeOffset::Compare(const DateTimeOffset\&, const DateTimeOffset\&) メソッド

2つの[DateTimeOffset](../)オブジェクトを比較します。

```cpp
static int System::DateTimeOffset::Compare(const DateTimeOffset &first, const DateTimeOffset &second)
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| first | const [DateTimeOffset](../)\& | 比較対象の最初のオブジェクト。 |
| second | const [DateTimeOffset](../)\& | 比較対象の2番目のオブジェクト。 |

### 戻り値

- 1 - **first** が **second** よりも前の場合、1 - **first** が **second** よりも後の場合、0 - **first** が **second** と等しい場合。
