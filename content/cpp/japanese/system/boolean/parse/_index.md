## Boolean::Parse(const String\&) メソッド


指定された文字列を bool 型の値に変換します。

```cpp
static bool System::Boolean::Parse(const String &value)
```


### 引数

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| value | const [String](../../string/)\& | 変換する文字列。 |

### 戻り値

変換結果が格納される bool 変数; 指定された文字列が \"True\" と等しい場合は true、\"False\" と等しい場合は false となります。
