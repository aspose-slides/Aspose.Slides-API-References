## TimeSpan::operator<(TimeSpan) const メソッド

現在のオブジェクトが表す時間間隔が、指定されたオブジェクトが表す時間間隔より短いかどうかを判断します。

```cpp
constexpr bool System::TimeSpan::operator<(TimeSpan value) const
```

### 引数

| Parameter | Type | Description |
| --- | --- | --- |
| value | [TimeSpan](../) | 現在のオブジェクトと比較するための [TimeSpan](../) オブジェクト |

### 戻り値

現在のオブジェクトが表す時間間隔が **value** が表す時間間隔より短い場合は true、そうでなければ false
