## System::operator/(const T\&, const Decimal\&) 関数


[Decimal](../decimal/) クラスの新しいインスタンスを返します。このインスタンスは、指定された値と、指定された [Decimal](../decimal/) オブジェクトが表す値との除算結果を表します。

```cpp
template<typename T,typename _> Decimal System::operator/(const T &x, const Decimal &d)
```


### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| x | const T\& | 除算される値 |
| d | const [Decimal](../decimal/)\& | 除数を表す [Decimal](../decimal/) オブジェクト |

### 戻り値

[Decimal](../decimal/) クラスの新しいインスタンスで、**x** を **d** が表す値で除算した結果の値を表します。
