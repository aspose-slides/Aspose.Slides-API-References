## StringComparison 列挙型

Defines string comparison style.

```cpp
enum class StringComparison
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| CurrentCulture | 0 | 現在のカルチャを使用します。 |
| CurrentCultureIgnoreCase | 1 | 現在のカルチャを使用しますが、大文字と小文字を区別しません。 |
| InvariantCulture | 2 | 不変カルチャを使用します。 |
| InvariantCultureIgnoreCase | 3 | 不変カルチャを使用しますが、大文字と小文字を区別しません。 |
| Ordinal | 4 | 順序ソート規則を使用します。 |
| OrdinalIgnoreCase | 5 | 順序ソート規則を使用しますが、大文字と小文字を区別しません。 |
