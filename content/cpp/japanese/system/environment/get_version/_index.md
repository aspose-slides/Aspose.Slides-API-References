## Environment::get_Version() メソッド

このメソッドが返す [Version](../../version/) オブジェクトは、共通言語ランタイムのバージョンに関する情報を表します。このメソッドが返すバージョン番号は実質的にダミーであり、すべてのライブラリクラスが返されたバージョンに従って動作することを意味しません。

```cpp
static Version System::Environment::get_Version()
```
