| 名前 | 値 | 説明 |
| --- | --- | --- |
| Desktop | 0 | 論理的なデスクトップ。 |
| Programs | 2 | ユーザーのプログラム グループが含まれるフォルダー。 |
| Personal | 5 | 文書の共通リポジトリとして機能するフォルダー。 |
| MyDocuments | 5 | 「My Documents」ディレクトリ。 |
| Favorites | 6 | ユーザーのお気に入り項目の共通リポジトリとして機能するフォルダー。 |
| Startup | 7 | ユーザーのスタートアップ プログラム グループに対応するフォルダー。 |
| Recent | 8 | ユーザーが最近使用した文書が含まれるフォルダー。 |
| SendTo | 9 | 「送る」メニュー項目のコンテナとして機能するフォルダー。 |
| StartMenu | 11 | スタート メニュー項目のコンテナとして機能するフォルダー。 |
| MyMusic | 13 | 「My Music」ディレクトリ。 |
| DesktopDirectory | 16 | デスクトップ上にアイテムを実際に保存するために使用されるフォルダー。 |
| MyComputer | 17 | 「My Computer」ディレクトリ。 |
| Templates | 21 | 文書テンプレートの共通コンテナとして機能するフォルダー。 |
| ApplicationData | 26 | 現在のローミング ユーザー向けにアプリケーション固有データを保存するために使用されるフォルダー。 |

| InternetCache | 32 | 一時的なインターネット ファイルの保存先として使用されるフォルダー。 |
| Cookies | 33 | インターネット クッキーの保存先として使用されるフォルダー。 |
| History | 34 | インターネット履歴項目の保存先として使用されるフォルダー。 |
| CommonApplicationData | 35 | すべてのユーザーが使用するアプリケーション固有データを保存するために使用されるフォルダー。 |
| System | 37 | システムフォルダー。 |
| ProgramFiles | 38 | プログラム ファイル フォルダー。 |
