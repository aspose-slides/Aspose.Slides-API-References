## DateTime::get_Date() const メソッド


[DateTime](../) クラスの新しいインスタンスを返します。このインスタンスは、現在のオブジェクトが表す日付と時刻のうち、日付部分を表し、時刻部分の各コンポーネントは0に設定されています。

```cpp
constexpr DateTime System::DateTime::get_Date() const
```
