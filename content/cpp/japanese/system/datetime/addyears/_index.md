## DateTime::AddYears(int) const メソッド

現在のオブジェクトが表す日付と時刻の値に、年コンポーネントを指定された数だけ増加させたものと等しい日付と時刻の値を表す [DateTime](../) クラスの新しいインスタンスを返します。

```cpp
DateTime System::DateTime::AddYears(int value) const
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| value | int | 加算する年数です。値は正でも負でもかまいません |

### 戻り値

[DateTime](../) クラスの新しいインスタンスで、現在のオブジェクトが表す日付と時刻の値に、年コンポーネントを **value** だけ増加させたものと等しい日付と時刻の値を表します。
