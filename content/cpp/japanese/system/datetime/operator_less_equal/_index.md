## DateTime::operator<=(DateTime) const メソッド

現在のオブジェクトが、指定された[DateTime](../)オブジェクトが表す値と同じかそれよりも早い日付と時刻の値を表すかどうかを判断します。

```cpp
constexpr bool System::DateTime::operator<=(DateTime other) const
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| other | [DateTime](../) | 現在のオブジェクトと比較するための[DateTime](../)オブジェクト |

### 戻り値

現在のオブジェクトが表す日付と時刻の値が、**other** が表す値と同じかそれよりも早い場合は true、そうでない場合は false
