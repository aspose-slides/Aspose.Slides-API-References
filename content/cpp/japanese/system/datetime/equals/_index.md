## DateTime::Equals(DateTime) const メソッド


指定された [DateTime](../) クラスのインスタンスが現在のオブジェクトと同じ日付と時刻の値を表すかどうかを判断します。

```cpp
constexpr bool System::DateTime::Equals(DateTime other) const
```


### 引数

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| other | [DateTime](../) | 現在のオブジェクトと比較するための [DateTime](../) クラスのインスタンス |

### 戻り値

両方の **other** と現在のオブジェクトが同じ値を表す場合は true、そうでない場合は false
