## DateTime::AddTicks(int64_t) const メソッド

現在のオブジェクトが表す値と、指定された 100 ナノ秒間隔の数の合計となる日付と時刻の値を表す、[DateTime](../) クラスの新しいインスタンスを返します。

```cpp
DateTime System::DateTime::AddTicks(int64_t value) const
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| value | **int64_t** | 追加する 100 ナノ秒間隔の数。値は正または負にすることができます。 |

### 戻り値

[DateTime](../) クラスの新しいインスタンスで、現在のオブジェクトが表す値と **value** の 100 ナノ秒間隔の合計となる日付と時刻の値を表します。
