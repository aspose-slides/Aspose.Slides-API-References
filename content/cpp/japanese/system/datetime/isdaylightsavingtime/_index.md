## DateTime::IsDaylightSavingTime() const メソッド

現在のオブジェクトが表す日付と時刻の値が、現在のタイムゾーンのサマータイム（夏時間）の範囲に該当するかを判断します。

```cpp
bool System::DateTime::IsDaylightSavingTime() const
```

### 戻り値

現在のオブジェクトが指定する日付と時刻の値がサマータイム（夏時間）の範囲に該当する場合は true、そうでない場合は false
