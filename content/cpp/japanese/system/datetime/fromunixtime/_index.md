## DateTime::FromUnixTime(time_t) メソッド

指定された Unix 時間値を [DateTime](../) クラスのインスタンスに変換します。内部使用のみ。

```cpp
static DateTime System::DateTime::FromUnixTime(time_t value)
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| value | time_t | 変換する Unix 時間値 |

### 戻り値

[DateTime](../) クラスの新しいインスタンスで、**value** と同じ日付と時刻を表します。
