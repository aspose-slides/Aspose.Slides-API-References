## DateTime::AddMonths(int) const メソッド


現在のオブジェクトが表す値と指定された月数の合計である日付と時刻の値を表す、[DateTime](../) クラスの新しいインスタンスを返します。

```cpp
DateTime System::DateTime::AddMonths(int value) const
```


### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| value | int | 追加する月数；値は正でも負でも構いません |

### 戻り値

現在のオブジェクトが表す値と **value** 月の合計である日付と時刻の値を表す、[DateTime](../) クラスの新しいインスタンスです。
