## DateTime::FromFileTime(int64_t) メソッド

指定されたファイル時間を、ローカル時間と同じ日付と時刻の値を表す [DateTime](../) クラスのインスタンスに変換します。

```cpp
static DateTime System::DateTime::FromFileTime(int64_t value)
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| value | **int64_t** | 変換するファイル時間 |

### 戻り値

**file_time** と同じ日付と時刻を表す [DateTime](../) クラスの新しいインスタンスです。
