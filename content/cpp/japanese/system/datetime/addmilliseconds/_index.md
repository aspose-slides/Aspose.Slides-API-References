## DateTime::AddMilliseconds(double) const メソッド

現在のオブジェクトが表す値と指定されたミリ秒数の合計である日時値を表す [DateTime](../) クラスの新しいインスタンスを返します。

```cpp
DateTime System::DateTime::AddMilliseconds(double value) const
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| value | **double** | 加算するミリ秒数。値は正または負になる可能性があります |

### 戻り値

[DateTime](../) クラスの新しいインスタンスで、現在のオブジェクトが表す値と **value** ミリ秒の合計である日時値を表します。
