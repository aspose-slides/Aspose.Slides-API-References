## SmartPtrMode 列挙型


[SmartPtr](../smartptr/) ポインタのタイプ: 弱または共有。オブジェクトを削除するかどうかを決定する際に、ポインタが参照カウントの対象となるかを定義します。

```cpp
enum class SmartPtrMode : char
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Shared | 0 | 共有モード: ポインタは参照カウントに参加します。 |
| Weak | 1 | 弱モード: ポインタは参照カウントに参加しません。 |
