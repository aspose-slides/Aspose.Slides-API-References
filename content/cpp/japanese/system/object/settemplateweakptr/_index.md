## Object::SetTemplateWeakPtr(uint32_t) メソッド


n 番目のテンプレート引数を弱いポインタ（共有ポインタではなく）に設定します。コンテナ内のポインタを弱いモードに切り替えることができます。

```cpp
virtual void System::Object::SetTemplateWeakPtr(uint32_t argument)
```

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| argument | **uint32_t** | [Index](../../index/) のテンプレート引数を弱いポインタとして扱う。 |
