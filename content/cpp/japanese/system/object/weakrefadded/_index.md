## Object::WeakRefAdded() メソッド

弱参照カウントをインクリメントします。直接呼び出すべきではありません。代わりに、スマート ポインタまたは ThisProtector を使用してください。

```cpp
Detail::SmartPtrCounter * System::Object::WeakRefAdded()
```

### 戻り値

オブジェクトに関連付けられた参照カウント データ構造へのポインタ。
