

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) は、現在のオブジェクトに対してテストする型を記述する構造体です。 |

### 戻り値

## 備考
