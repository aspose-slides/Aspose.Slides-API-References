## Guid::CompareTo(const Guid\&) const メソッド

```cpp
int System::Guid::CompareTo(const Guid &g) const
```


### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| g | const [Guid](../)\& | 比較対象 |

### 戻り値
