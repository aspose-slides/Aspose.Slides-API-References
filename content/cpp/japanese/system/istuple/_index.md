## System::IsTuple(const SharedPtr\<Object\>\&, int32_t) 関数

オブジェクトがタプルかどうかを確認します（ITuple インターフェイスを実装しています）。位置パターン実装で使用されます。

```cpp
bool System::IsTuple(const SharedPtr<Object> &object, int32_t length)
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| object | const [SharedPtr](../sharedptr/)\<[Object](../object/)\>\& | 確認対象のオブジェクト。 |
| length | **int32_t** | 期待されるタプルの長さ |

### 戻り値

オブジェクトがタプルであり、その長さが期待されたものと等しい
