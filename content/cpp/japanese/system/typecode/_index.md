## TypeCode 列挙体

オブジェクトの型を表します。

```cpp
enum class TypeCode
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Empty | 0 | null 参照です。 |
| Object | 1 | 他の TypeCode で明示的に表されていない、任意の参照型または値型を表す一般的な型です。 |
| DBNull | 2 | データベースの null (列) 値です。 |
| Boolean | 3 | true または false の [Boolean](../boolean/) 値を表す単純型です。 |
| Char | 4 | 0 から 65535 までの値を持つ、符号なし 16 ビット整数を表す整数型です。 |
| SByte | 5 | -128 から 127 までの値を持つ、符号付き 8 ビット整数を表す整数型です。 |
| Byte | 6 | 0 から 255 までの値を持つ、符号なし 8 ビット整数を表す整数型です。 |
| Int16 | 7 | -32768 から 32767 までの値を持つ、符号付き 16 ビット整数を表す整数型です。 |
| UInt16 | 8 | 0 から 65535 までの値を持つ、符号なし 16 ビット整数を表す整数型です。 |
| Int32 | 9 | -2147483648 から 2147483647 までの値を持つ、符号付き 32 ビット整数を表す整数型です。 |
| UInt32 | 10 | 0 から 4294967295 までの値を持つ、符号なし 32 ビット整数を表す整数型です。 |
| Int64 | 11 | -9223372036854775808 から 9223372036854775807 までの値を持つ、符号付き 64 ビット整数を表す整数型です。 |
| UInt64 | 12 | 0 から 18446744073709551615 までの値を持つ、符号なし 64 ビット整数を表す整数型です。 |
| Single | 13 | 約 1.5 × 10⁻⁴⁵ から 3.4 × 10³⁸ までの値を表し、7 桁の精度を持つ浮動小数点型です。 |
| Double | 14 | 約 5.0 × 10⁻³²⁴ から 1.7 × 10³⁰⁸ までの値を表し、15〜16 桁の精度を持つ浮動小数点型です。 |
| Decimal | 15 | 約 1.0 × 10⁻²⁸ から 7.9 × 10²⁸ までの値を表し、28〜29 桁の有効数字を持つ単純型です。 |
| DateTime | 16 | 日付と時刻の値を表す型です。 |
| String | 18 | Unicode 文字列を表す sealed クラス型です。 |
