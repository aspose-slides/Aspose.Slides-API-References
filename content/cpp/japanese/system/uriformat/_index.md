## UriFormat 列挙型


URI がどのようにエスケープされるかを指定します。

```cpp
enum class UriFormat
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| UriEscaped | 1 | RFC-2396 に従ったエスケープです。 |
| Unescaped | 2 | エスケープなし。 |
| SafeUnescaped | 3 | URI で予約された意味を持つ文字のみがエスケープされます。 |
