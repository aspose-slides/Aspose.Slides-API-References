## SmartPtr::RemoveAliasing() const メソッド

ポインタからエイリアシング（エイリアシング コンストラクタによって作成される）を削除し、指している同じオブジェクトを（共有されている場合は管理し、弱参照の場合は追跡する）ことを保証します。

```cpp
SmartPtr_ System::SmartPtr<T>::RemoveAliasing() const
```

### 戻り値

このポインタが指す同じオブジェクトへのポインタであり、そのオブジェクトの存続期間を管理します。
