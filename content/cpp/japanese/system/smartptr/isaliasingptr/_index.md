## SmartPtr::IsAliasingPtr() const メソッド


ポインタが所有しているオブジェクトとは別のオブジェクトを指しているか（エイリアスコンストラクタで作成されたもの）を確認します。

```cpp
bool System::SmartPtr<T>::IsAliasingPtr() const
```


### 戻り値

ポインタが指しているオブジェクトと所有しているオブジェクトが異なる場合は true、そうでない場合は false を返します。
