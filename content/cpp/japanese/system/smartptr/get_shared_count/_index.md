## SmartPtr::get_shared_count() const メソッド


参照されたオブジェクトに存在する共有ポインタの数を取得します（現在のポインタを含む）。現在のポインタが共有モードであることをアサートします。

```cpp
int System::SmartPtr<T>::get_shared_count() const
```


### 戻り値

参照されたオブジェクトに存在する共有ポインタの数（存在する場合）。ポインタが null の場合は 0 を返します。
