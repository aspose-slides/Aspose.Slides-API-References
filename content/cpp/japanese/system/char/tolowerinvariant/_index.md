## Char::ToLowerInvariant(char_t) メソッド


指定された文字を小文字に変換します。

```cpp
static char_t System::Char::ToLowerInvariant(char_t c)
```


### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| c | char_t | 変換する文字 |

### 戻り値

指定された文字が大文字の場合は小文字に変換された文字を返し、そうでない場合は指定された文字をそのまま返します。
