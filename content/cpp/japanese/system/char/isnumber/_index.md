## Char::IsNumber(const char_t *, int) メソッド


指定された文字バッファ内の指定されたインデックスにある文字が数値として分類されるかどうかを判断します。

```cpp
static bool System::Char::IsNumber(const char_t *str, int idx)
```


### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| str | const char_t * | 文字バッファの先頭へのポインタ |
| idx | int | テスト対象の文字がある指定されたバッファ内の0ベースインデックス |

### 戻り値

指定されたインデックスにある文字が数値である場合は true、そうでない場合は false です。
