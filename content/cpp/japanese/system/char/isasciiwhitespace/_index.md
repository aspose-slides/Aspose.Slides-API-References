## Char::IsAsciiWhiteSpace(char_t) メソッド

指定された文字が ASCII の空白文字として分類されるかどうかを判定します。

```cpp
static constexpr bool System::Char::IsAsciiWhiteSpace(char_t c)
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| c | char_t | テスト対象の文字 |

### 戻り値

指定された文字が ASCII の空白文字である場合は True、そうでない場合は false
