## Char::IsLower(const char_t *, int) メソッド

指定された文字バッファ内の指定されたインデックスにある文字が小文字かどうかを判定します。

```cpp
static bool System::Char::IsLower(const char_t *str, int idx)
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| str | const char_t * | 文字バッファの先頭へのポインタ |
| idx | int | テスト対象文字の、指定されたバッファ内の 0 ベースインデックス |

### 戻り値

指定されたインデックスにある文字が小文字であれば true、そうでなければ false を返します。
