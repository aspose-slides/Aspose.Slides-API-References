## StringComparer::Compare(args_type, args_type) const メソッド


### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| x | [args_type](../args_type/) | LHS 文字列の値。 |
| y | [args_type](../args_type/) | RHS 文字列の値。 |

### 戻り値

**x** が **y** の前に来る場合は負の値、等しい場合は 0、その他の場合は正の値です。
