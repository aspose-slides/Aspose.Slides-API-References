## Version::CompareTo(const Version\&) const メソッド


現在のオブジェクトと指定されたオブジェクトが表すバージョンを比較します。

```cpp
int System::Version::CompareTo(const Version &ver) const
```


### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| ver | const [Version](../)\& | 現在のオブジェクトと比較するための [Version](../) オブジェクト |

### 戻り値

- 1 は、現在のオブジェクトが表すバージョン番号が **ver** が表すものより小さい場合; 0 はバージョン番号が等しい場合; 1 は、現在のオブジェクトが表すバージョン番号が **ver** が表す値より大きい場合
