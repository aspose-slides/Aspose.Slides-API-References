## Nullable::GetValueOrDefault(T) メソッド

現在のオブジェクトが表す値、または現在のオブジェクトが null の場合に指定された値を返します。

```cpp
T System::Nullable<T>::GetValueOrDefault(T default_value)
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| default_value | T | 現在のオブジェクトが null の場合にメソッドが返す値 |

### 戻り値

現在のオブジェクトが null でない場合は、その値のコピーが返され、そうでない場合は指定された値が返されます
