## System::GEqual(const ExpressionT\&, const ConstantT\&) 関数

'>=' の相対パターン変換を実装します。

```cpp
template<class ExpressionT,class ConstantT> bool System::GEqual(const ExpressionT &left, const ConstantT &constant)
```

### テンプレート パラメータ

| パラメータ | 説明 |
| --- | --- |
| ExpressionT | 左側の式の型。 |
| ConstantT | 定数式の型。 |

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| left | const ExpressionT\& | チェックされる式。 |
| constant | const ConstantT\& | 左側の式と比較される式。 |

### 戻り値

型チェックが成功した場合は true、そうでない場合は false。
