## String::IsNull() const メソッド


文字列が null とみなされるかどうかをチェックします。 [String](../) は null であり、[String()](../string/) コンストラクタで生成された場合、または null 文字列からムーブ、コピー、代入された場合、または [reset()](../reset/) メソッドが呼び出された場合にのみ null です。

```cpp
bool System::String::IsNull() const
```


### 戻り値

文字列が null とみなされる場合は true、そうでない場合は false。
