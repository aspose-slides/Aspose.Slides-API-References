## String::begin() const メソッド


実際の文字列バッファの先頭へのポインタを返します。何も再割り当てしません。バッファが null 終端であることは保証しません。

```cpp
const UChar * System::String::begin() const
```


### 戻り値

実際の文字列バッファへのポインタ、null 終端かどうかは問わない。
