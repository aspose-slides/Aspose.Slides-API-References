## String::end() const メソッド

実際の文字列バッファの末尾へのポインタを返します。決して再割り当ては行いません。バッファがヌル終端されていることは保証しません。

```cpp
const UChar * System::String::end() const
```

### 戻り値

実際の文字列バッファの後の最初の要素へのポインタ、ヌル終端されているかどうかにかかわらず。
