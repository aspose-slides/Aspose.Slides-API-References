## String::rend() const メソッド


実際の文字列バッファの最初の文字の前（存在する場合）への逆イテレータを返します。

```cpp
reverse_iterator System::String::rend() const
```


### 戻り値

実際の文字列バッファの最初の文字の前にある要素への逆イテレータ（存在する場合）または割り当てられたバッファの直前の要素への逆イテレータ。
