## String::IsNormalized(System::Text::NormalizationForm) const メソッド

指定された正規化形式を使用して、Unicode 文字列が正規化されているかどうかを確認します。

```cpp
bool System::String::IsNormalized(System::Text::NormalizationForm form) const
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| form | [System::Text::NormalizationForm](../../../system.text/normalizationform/) | 正規化形式。詳細は [System::Text::NormalizationForm](../../../system.text/normalizationform/) を参照してください。 |

### 戻り値

文字列がすでに正規化されている場合は true、そうでない場合は false を返します。
