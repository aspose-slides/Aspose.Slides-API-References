## EnumeratorCastAdapter::MoveNext() メソッド


列挙子を次の要素に移動します。以前に要素が参照されていなければ、利用可能な最初の要素への参照を設定します。コンテナの末尾に到達した場合、何もしません。

```cpp
bool System::Collections::Generic::Details::EnumeratorCastAdapter<Source, Result>::MoveNext() override
```


### 戻り値

呼び出し後に要素が利用可能であれば true、そうでなければ false が返されます。
