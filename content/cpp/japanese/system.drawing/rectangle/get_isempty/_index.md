## Rectangle::get_IsEmpty() const メソッド

現在のオブジェクトで表される矩形の左上隅の X および Y 座標と、幅と高さが 0 であるかどうかを判定します。

```cpp
bool System::Drawing::Rectangle::get_IsEmpty() const
```

### 戻り値

X と Y の座標が 0 であり、幅と高さも 0 の場合は True、そうでない場合は false
