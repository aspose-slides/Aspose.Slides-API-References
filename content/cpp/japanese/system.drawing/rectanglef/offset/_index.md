## RectangleF::Offset(const PointF\&) メソッド



### 引数

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| pos | const [PointF](../../pointf/)\& | [PointF](../../pointf/) オブジェクトは、矩形がオフセットされる量を指定します。ポイントの X 座標値は矩形の左上隅の X 座標に加える量を指定し、Y 座標は左上隅の Y 座標に加える量を指定します。 |
