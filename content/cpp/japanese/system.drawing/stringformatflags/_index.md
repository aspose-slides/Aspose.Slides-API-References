## StringFormatFlags 列挙型

文字列の表示とレイアウト情報を指定します。

```cpp
enum class StringFormatFlags
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| DirectionRightToLeft | 1 | 右から左へのテキスト方向です。 |
| DirectionVertical | 2 | [Text](../../system.drawing.text/) は垂直に配置されています。 |
| FitBlackBox | 4 | 文字の一部がレイアウトボックスからはみ出すことがあります。 |
| DisplayFormatControl | 32 | 制御文字が表示されます。 |
| NoFontFallback | 1024 | [Font](../font/) フォールバックが無効です。 |
| MeasureTrailingSpaces | 2048 | 各行の末尾に空白を挿入します。 |
| NoWrap | 4096 | [Text](../../system.drawing.text/) の折り返しが無効です。 |
| LineLimit | 8192 | 全行が書式設定矩形内にレイアウトされます。 |
| NoClip | 16384 | グリフのはみ出した部分が表示されることを許可します。 |
