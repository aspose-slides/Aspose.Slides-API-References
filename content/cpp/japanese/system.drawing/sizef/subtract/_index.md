## SizeF::Subtract(const SizeF\&, const SizeF\&) メソッド

**size2** を **size1** から減算した結果として新しい [SizeF](../) オブジェクトを返します。つまり、幅の値は **size1** の幅から **size2** の幅を減算した結果であり、 高さの値は **size1** の高さから **size2** の高さを減算した結果です。

```cpp
static SizeF System::Drawing::SizeF::Subtract(const SizeF &size1, const SizeF &size2)
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| size1 | const [SizeF](../)\& | 減算される [SizeF](../) オブジェクト |
| size2 | const [SizeF](../)\& | 減算する [SizeF](../) オブジェクト |

### 戻り値

[SizeF](../) オブジェクトは **size2** を **size1** から減算した結果です。
