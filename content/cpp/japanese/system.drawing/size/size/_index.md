## Size::Size() コンストラクタ

[Size](../) オブジェクトを新しく作成し、その幅と高さの値を 0 で初期化します。

```cpp
System::Drawing::Size::Size()
```

## Size::Size(const Point\&) コンストラクタ

[Size](../) オブジェクトを新しく作成し、指定されたポイントの X および Y 座標の値に対応して幅と高さの値を初期化します。

```cpp
System::Drawing::Size::Size(const Point &point)
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| point | const [Point](../../point/)\& | 作成中の [Size](../) オブジェクトの幅と高さの値を初期化するために使用される X および Y 座標を持つ [Point](../../point/) オブジェクト |

## Size::Size(int, int) コンストラクタ

[Size](../) オブジェクトを新しく作成し、指定された値で初期化します。

```cpp
System::Drawing::Size::Size(int width, int height)
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| width | int | 幅に設定する値 |
| height | int | 高さに設定する値 |
