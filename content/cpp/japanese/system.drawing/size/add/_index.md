## Size::Add(const Size\&, const Size\&) メソッド

指定された [Size](../) オブジェクトの合計である新しい [Size](../) オブジェクトを返します。つまり、その幅の値は指定されたオブジェクトの幅の値の合計と等しく、高さの値は指定されたオブジェクトの高さの値の合計と等しくなります。

```cpp
static Size System::Drawing::Size::Add(const Size &size1, const Size &size2)
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| size1 | const [Size](../)\& | 最初のオペランド |
| size2 | const [Size](../)\& | 2番目のオペランド |

### 戻り値

[Size](../) オブジェクトは **size1** と **size2** の合計です。
