## Size::Subtract(const Size\&, const Size\&) メソッド

[Size](../) オブジェクトを新しく返します。このオブジェクトは **size1** から **size2** を減算した結果であり、すなわち幅の値は **size1** の幅から **size2** の幅を減算した結果、 高さの値は **size1** の高さから **size2** の高さを減算した結果です。

```cpp
static Size System::Drawing::Size::Subtract(const Size &size1, const Size &size2)
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| size1 | const [Size](../)\& | [Size](../) オブジェクトから減算される |
| size2 | const [Size](../)\& | [Size](../) オブジェクトを減算する |

### 戻り値

[Size](../) オブジェクトは **size1** から **size2** を減算した結果です
