## CopyPixelOperation 列挙体

ピクセルコピー操作において、ソースカラーがデスティネーションカラーとどのように結合され最終的なカラーになるかを指定します。

```cpp
enum class CopyPixelOperation
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| NoMirrorBitmap | n/a | ビットマップはミラーリングされません。 |
| Blackness | 66 | 物理パレットのインデックス 0 のカラーを使用してデスティネーション領域を塗りつぶします。 |
| NotSourceErase | 1114278 | ソースカラーとデスティネーションカラーが OR 演算され、その結果のカラーが反転されます。 |
| NotSourceCopy | 3342344 | ソース領域が反転され、デスティネーションにコピーされます。 |
| SourceErase | 4457256 | デスティネーション領域の反転カラーがソース領域のカラーと AND 演算されます。 |
| DestinationInvert | 5570569 | デスティネーション領域が反転されます。 |
| PatInvert | 5898313 | デスティネーションデバイスコンテキストで現在選択されているブラシのカラーがデスティネーションのカラーと XOR 演算されます。 |
| SourceInvert | 6684742 | ソース領域とデスティネーション領域のカラーが XOR 演算されます。 |
| SourceAnd | 8913094 | ソース領域とデスティネーション領域のカラーが AND 演算されます。 |
| MergePaint | 12255782 | 反転されたソース領域のカラーがデスティネーション領域のカラーと OR 演算されます。 |
| MergeCopy | 12583114 | ソース領域のカラーがデスティネーションデバイスコンテキストで選択されているブラシのカラーと AND 演算されます。 |
| SourceCopy | 13369376 | ソース領域がデスティネーション領域に直接コピーされます。 |
| SourcePaint | 15597702 | ソース領域とデスティネーション領域のカラーが OR 演算されます。 |
| PatCopy | 15728673 | デスティネーションデバイスコンテキストで現在選択されているブラシがデスティネーションビットマップにコピーされます。 |
| PatPaint | 16452105 | デスティネーションデバイスコンテキストで現在選択されているブラシのカラーが反転されたソース領域のカラーと OR 演算され、その結果がデスティネーション領域のカラーと OR 演算されます。 |
| Whiteness | 16711778 | 物理パレットのインデックス 1 のカラーを使用してデスティネーション領域を塗りつぶします。 |
| CaptureBlt | 1073741824 | [Windows](../../system.windows/) がアプリケーションのウィンドウ上にレイヤーされている場合、結果の画像に含まれます。 |
