## SystemColors クラス

クラスは、[Color](../color/) オブジェクトの事前作成されたセットを提供し、[Windows](../../system.windows/) ディスプレイ要素の色を表します。これはインスタンスサービスを持たない静的型です。いかなる手段でもインスタンスを作成すべきではありません。

```cpp
class SystemColors
```
