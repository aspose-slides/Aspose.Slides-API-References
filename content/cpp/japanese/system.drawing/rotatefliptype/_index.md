## RotateFlipType 列挙体

Specifies the type of rotation and/or flipping operation.

```cpp
enum class RotateFlipType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| RotateNoneFlipNone | 0 | 回転なし、フリップなし。 |
| Rotate90FlipNone | 1 | 時計回りに90度回転し、フリップなし。 |
| Rotate180FlipNone | 2 | 時計回りに180度回転し、フリップなし。 |
| Rotate270FlipNone | 3 | 時計回りに270度回転し、フリップなし。 |
| RotateNoneFlipX | 4 | 水平フリップ、回転なし。 |
| Rotate90FlipX | 5 | 時計回りに90度回転し、水平フリップ。 |
| Rotate180FlipX | 6 | 時計回りに180度回転し、水平フリップ。 |
| Rotate270FlipX | 7 | 時計回りに270度回転し、水平フリップ。 |
| RotateNoneFlipY | n/a | 垂直フリップ、回転なし。 |
| Rotate90FlipY | n/a | 時計回りに90度回転し、垂直フリップ。 |
| Rotate180FlipY | n/a | 時計回りに180度回転し、垂直フリップ。 |
| Rotate270FlipY | n/a | 時計回りに270度回転し、垂直フリップ。 |
| RotateNoneFlipXY | n/a | 水平・垂直フリップ、回転なし。 |
| Rotate90FlipXY | n/a | 時計回りに90度回転し、水平および垂直フリップ。 |
| Rotate180FlipXY | n/a | 時計回りに180度回転し、水平および垂直フリップ。 |
| Rotate270FlipXY | n/a | 時計回りに270度回転し、水平および垂直フリップ。 |
