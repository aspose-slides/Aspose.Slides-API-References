## ContentAlignment 列挙体

コンテンツの配置を指定します。

```cpp
enum class ContentAlignment
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| TopLeft | 1 | 垂直方向に上部に、横方向に左側に揃えられます。 |
| TopCenter | 2 | 垂直方向に上部に、横方向は中央に揃えられます。 |
| TopRight | 4 | 垂直方向に上部に、横方向は右側に揃えられます。 |
| MiddleLeft | 16 | 垂直方向は中央に、横方向は左側に揃えられます。 |
| MiddleCenter | 32 | 垂直方向は中央に、横方向は中央に揃えられます。 |
| MiddleRight | 64 | 垂直方向は中央に、横方向は右側に揃えられます。 |
| BottomLeft | 256 | 垂直方向は下部に、横方向は左側に揃えられます。 |
| BottomCenter | 512 | 垂直方向は下部に、横方向は中央に揃えられます。 |
| BottomRight | 1024 | 垂直方向は下部に、横方向は右側に揃えられます。 |
