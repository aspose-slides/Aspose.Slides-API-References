## Image::IsAlphaPixelFormat(Imaging::PixelFormat) メソッド

指定されたピクセル形式がアルファ情報を含むかどうかを判定します。

```cpp
static bool System::Drawing::Image::IsAlphaPixelFormat(Imaging::PixelFormat pixfmt)
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| pixfmt | [Imaging::PixelFormat](../../../system.drawing.imaging/pixelformat/) | テスト対象のピクセル形式 |

### 戻り値

**pixfmt** がアルファ情報を含む場合は True、そうでない場合は false
