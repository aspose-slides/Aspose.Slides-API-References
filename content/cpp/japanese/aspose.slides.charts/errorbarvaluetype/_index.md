## ErrorBarValueType 列挙型

誤差棒の値のタイプを表します

```cpp
enum class ErrorBarValueType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Custom | 0 | 誤差棒の長さは Plus および Minus 要素によって決定されることを指定します。 |
| Fixed | 1 | 誤差棒の長さは Error Bar Value によって決定された固定値であることを指定します。 |
| Percentage | 2 | 誤差棒の長さはデータの Error Bar Value パーセントであることを指定します。 |
| StandardDeviation | 3 | 誤差棒の長さはデータの Error Bar Value 標準偏差であることを指定します。 |
| StandardError | 4 | 誤差棒の長さはデータの Error Bar Value 標準誤差であることを指定します。 |
