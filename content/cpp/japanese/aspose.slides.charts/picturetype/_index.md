## PictureType 列挙型


棒グラフの画像塗りつぶしモードを決定します。

```cpp
enum class PictureType
```

### Values

| 名前 | 値 | 説明 |
| --- | --- | --- |
| NotDefined | -1 | 未定義です。 |
| Stack | 0 | 画像は、最も長い積み上げバー内で最大15回繰り返すようにサイズが設定されます。 |
| StackScale | 1 | 画像は指定された単位数にサイズが設定され、バーの長さに沿って繰り返されます。 |
| Stretch | 2 | 画像は積み上げバー全体にストレッチされます。 |
