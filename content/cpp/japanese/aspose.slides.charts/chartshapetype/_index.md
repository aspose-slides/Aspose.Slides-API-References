## ChartShapeType 列挙型

チャートの形状を表します。

```cpp
enum class ChartShapeType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| NotDefined | -1 | [Chart](../chart/) shape は未定義です。 |
| Box | 0 | チャートは箱形状で描画されることを指定します。 |
| Cone | 1 | チャートは円錐として描画されることを指定します。円錐の底部は床にあり、円錐の先端はデータ マーカーの上部にあります。 |
| ConeToMax | 2 | チャートは円錐を切頭形にして描画し、円錐の先端が最大データ値になるように指定します。 |
| Cylinder | 3 | チャートは円柱として描画されることを指定します。 |
| Pyramid | 4 | チャートは長方形のピラミッドとして描画されることを指定します。ピラミッドの底部は床にあり、ピラミッドの先端はデータ マーカーの上部にあります。 |
| PyramidToMaximum | 5 | チャートはピラミッドを切頭形にして描画し、先端が最大データ値になるように指定します。 |
