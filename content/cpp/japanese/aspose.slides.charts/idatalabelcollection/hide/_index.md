## IDataLabelCollection::Hide() メソッド

デフォルトでデータラベルを非表示にするには、DefaultDataLabelFormat プロパティのすべての Show*-フラグ (ShowValue, ...) を false に設定します。この後、IsVisible は false になります。

```cpp
virtual void Aspose::Slides::Charts::IDataLabelCollection::Hide()=0
```

## 備考

データラベルがデフォルトで表示されない場合 (IsVisible は false) は、Show*-フラグ (ShowValue, ...) を true に設定してデータラベルを「表示 
デフォルトで」にできます。
