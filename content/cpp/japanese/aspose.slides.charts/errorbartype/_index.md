## ErrorBarType 列挙型


エラーバーのタイプを表します

```cpp
enum class ErrorBarType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Both | 0 | エラーバーが正方向と負方向の両方に表示されることを指定します。 |
| Minus | 1 | エラーバーが負方向にのみ表示されることを指定します。 |
| Plus | 2 | エラーバーが正方向にのみ表示されることを指定します。 |
