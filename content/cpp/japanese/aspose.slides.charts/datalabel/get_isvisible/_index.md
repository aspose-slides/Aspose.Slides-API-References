## DataLabel::get_IsVisible() メソッド


False はデータラベルが表示されないことを意味します (そしてすべての Show*-flags (ShowValue, ...) は false です)。 読み取り専用 **bool**。

```cpp
bool Aspose::Slides::Charts::DataLabel::get_IsVisible() override
```

## 備考


データラベルが表示されている場合、[Hide()](../hide/) メソッドで非表示にすることができます。 ただし、データラベルが表示されていない場合 (IsVisible が false) は、Show*-flags (ShowValue, ...) を true に設定してデータラベルを表示できます。
