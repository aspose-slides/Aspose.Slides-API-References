## IChartSeries::get_HasUpDownBars() メソッド

Line- または Stock-チャートに上下バーがあるかを判定します。これはこのシリーズだけでなく、親シリーズ グループのすべてのシリーズに対するプロパティであり、該当グループ プロパティの投影です。そのためこのプロパティは読み取り専用です。親シリーズグループにアクセスするには ParentSeriesGroup プロパティを使用してください。値を変更するには [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get_UpDownBars()->get(set)_HasUpDownBars() 読み取り/書き込みプロパティを使用します。上下バーの書式設定には [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get_UpDownBars() プロパティを使用してください。読み取り専用 **bool**。

```cpp
virtual bool Aspose::Slides::Charts::IChartSeries::get_HasUpDownBars()=0
```

## 備考

これはプロパティ [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get_UpDownBars()->get(set)_HasUpDownBars() の投影です。
