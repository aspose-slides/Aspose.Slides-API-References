## IRotation3D::set_RotationY(uint16_t) メソッド

Y軸（3D グラフの X 方向）周りの回転角度を設定します（0 度から 360 度の範囲）。このプロパティは ECMA-376 の 21.2.2.158 rotY（Y Rotation）項目および PowerPoint 2007 以降の \"X Rotation\" オプションに対応しています。書き込み型は **uint16_t** です。

```cpp
virtual void Aspose::Slides::Charts::IRotation3D::set_RotationY(uint16_t value)=0
```
