## IRotation3D::set_RotationX(int8_t) メソッド


X 軸周りの回転角度を設定します。つまり、3D チャートでは Y 方向の回転です（-90 度から 90 度の範囲）。このプロパティは ECMA-376 の 21.2.2.157 rotX (X Rotation) 項目および PowerPoint 2007+ の \"Y Rotation\" オプションに対応しています。**int8_t**を書き込みます。

```cpp
virtual void Aspose::Slides::Charts::IRotation3D::set_RotationX(int8_t value)=0
```
