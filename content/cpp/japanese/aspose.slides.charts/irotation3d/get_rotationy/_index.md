## IRotation3D::get_RotationY() メソッド

Y 軸周りの回転角度、すなわち 3D チャートの X 方向（0 度から 360 度の間）を返します。このプロパティは ECMA-376 の 21.2.2.158 rotY（Y Rotation）項目および PowerPoint 2007+ の \"X Rotation\" オプションに対応しています。**uint16_t** を読み取ります。

```cpp
virtual uint16_t Aspose::Slides::Charts::IRotation3D::get_RotationY()=0
```
