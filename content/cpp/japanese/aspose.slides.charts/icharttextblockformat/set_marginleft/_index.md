## IChartTextBlockFormat::set_MarginLeft(double) メソッド

[TextFrame](../../../aspose.slides/textframe/) の左余白（ポイント）を設定します。 このプロパティを変更すると、以下のチャート部品: [DataLabel](../../datalabel/) と [DataLabelFormat](../../datalabelformat/) にのみ特定の影響が生じる可能性があります（PowerPoint 2013 では完全にサポートされますが、PowerPoint 2007 ではレンダリングに効果がありません）。 書き込む型は **double**。

```cpp
virtual void Aspose::Slides::Charts::IChartTextBlockFormat::set_MarginLeft(double value)=0
```
