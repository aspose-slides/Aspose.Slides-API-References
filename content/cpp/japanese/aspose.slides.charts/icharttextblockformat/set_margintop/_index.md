## IChartTextBlockFormat::set_MarginTop(double) メソッド

[TextFrame](../../../aspose.slides/textframe/) の上余白（ポイント）を設定します。 このプロパティを変更すると、次のチャート部品 [DataLabel](../../datalabel/) と [DataLabelFormat](../../datalabelformat/) にのみ特定の影響を与える可能性があります（PowerPoint 2013 では完全にサポートされますが、PowerPoint 2007 ではレンダリングに効果がありません）。 **double** を書き込みます。

```cpp
virtual void Aspose::Slides::Charts::IChartTextBlockFormat::set_MarginTop(double value)=0
```
