## IChartTextBlockFormat::set_MarginBottom(double) メソッド


[TextFrame](../../../aspose.slides/textframe/) の下余白（ポイント）を設定します。 このプロパティを変更すると、次のチャート パーツ [DataLabel](../../datalabel/) と [DataLabelFormat](../../datalabelformat/) にのみ影響を与える可能性があります（PowerPoint 2013 では完全にサポートされます；PowerPoint 2007 では描画に効果がありません）。 **double** を書き込みます。

```cpp
virtual void Aspose::Slides::Charts::IChartTextBlockFormat::set_MarginBottom(double value)=0
```
