## IChartTextBlockFormat::set_AutofitType(TextAutofitType) メソッド

テキストの自動調整モードを設定します。 このプロパティを変更すると、次のチャート パーツに対してのみ特定の影響を与える可能性があります: [DataLabel](../../datalabel/) と [DataLabelFormat](../../datalabelformat/) (PowerPoint 2013 ではフルサポート; PowerPoint 2007 ではレンダリングに効果がありません)。 [TextAutofitType](../../../aspose.slides/textautofittype/) を書き込みます。

virtual void Aspose::Slides::Charts::IChartTextBlockFormat::set_AutofitType(TextAutofitType value)=0
