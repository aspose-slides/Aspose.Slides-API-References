## IChartTextBlockFormat::set_MarginRight(double) メソッド


[TextFrame](../../../aspose.slides/textframe/) の右余白（ポイント）を設定します。 このプロパティを変更すると、次のチャート パーツ [DataLabel](../../datalabel/) と [DataLabelFormat](../../datalabelformat/) にのみ特定の影響を与える可能性があります（PowerPoint 2013 では完全にサポートされますが、PowerPoint 2007 では描画に効果がありません）。 **double** を書き込みます。

```cpp
virtual void Aspose::Slides::Charts::IChartTextBlockFormat::set_MarginRight(double value)=0
```
