## DataLabelCollection::Hide() メソッド

データ ラベルをデフォルトで非表示にするには、DefaultDataLabelFormat プロパティのすべての Show*-フラグ（ShowValue, ...）を false に設定します。IsVisible はこの後 false になります。

```cpp
void Aspose::Slides::Charts::DataLabelCollection::Hide() override
```

## 注意

データ ラベルがデフォルトで非表示（IsVisible が false）である場合、DefaultDataLabelFormat プロパティの Show*-フラグ（ShowValue, ...）を true に設定することで、データ ラベルを \"visible 
by default\" にできます。
