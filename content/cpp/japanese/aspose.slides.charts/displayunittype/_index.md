## DisplayUnitType enum

表示されるデータの倍率を決定します。

```cpp
enum class DisplayUnitType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| None | 0 | 値はそのまま表示されます。 |
| Hundreds | 1 | チャート上の値を 100 で除算することを指定します。 |
| Thousands | 2 | チャート上の値を 1,000 で除算することを指定します。 |
| TenThousands | 3 | チャート上の値を 10,000 で除算することを指定します。 |
| HundredThousands | 4 | チャート上の値を 100,000 で除算することを指定します。 |
| Millions | 5 | チャート上の値を 1,000,000 で除算することを指定します。 |
| TenMillions | 6 | チャート上の値を 10,000,000 で除算することを指定します。 |
| HundredMillions | 7 | チャート上の値を 100,000,000 で除算することを指定します。 |
| Billions | 8 | チャート上の値を 1,000,000,000 で除算することを指定します。 |
| Trillions | 9 | チャート上の値を 1,000,000,000,000 で除算することを指定します。 |
| CustomValue | 10 | チャート上の値をカスタム値で除算することを指定します。 |
