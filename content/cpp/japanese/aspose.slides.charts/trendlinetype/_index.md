## TrendlineType 列挙型

トレンドラインのタイプを表します

```cpp
enum class TrendlineType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Exponential | 0 | トレンドラインは指数曲線になることを指定します。 |
| Linear | 1 | トレンドラインは直線になることを指定します。 |
| Logarithmic | 2 | トレンドラインは対数曲線になることを指定します（形式は , ここで log は自然対数です）。 |
| MovingAverage | 3 | トレンドラインは期間 Period の移動平均になることを指定します。 |
| Polynomial | 4 | トレンドラインは次数 Order の多項式曲線になることを指定します。 |
| Power | 5 | トレンドラインはべき曲線になることを指定します。 |
