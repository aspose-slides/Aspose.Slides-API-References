## TickLabelPositionType 列挙型

指定された軸上の目盛りラベルの位置タイプを表します。

```cpp
enum class TickLabelPositionType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| High | 0 | 軸ラベルが垂直軸の高い側に配置されることを指定します。 |
| Low | 1 | 軸ラベルが垂直軸の低い側に配置されることを指定します。 |
| NextTo | 2 | 軸ラベルが軸の隣に配置されることを指定します。 |
| None | 3 | 軸ラベルが描画されないことを指定します。 |
