## ChartSeries::set_Smooth(bool) メソッド

曲線のスムージングを表します。曲線のスムージングがラインチャートまたは散布図チャートで有効になっている場合は true です。ラインと、線で接続された散布図チャートにのみ適用されます。書き込み型は **bool**。
