## PieSplitType enum

このチャートタイプのデフォルトメカニズムを使用してデータ ポイントを分割するタイプを表します。

```cpp
enum class PieSplitType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Default | 0 | このチャートタイプのデフォルトメカニズムを使用してデータ ポイントを分割することを指定します。 |
| Custom | 1 | Custom Split の値に従って、データ ポイントを円グラフと第2のチャート間で分割することを指定します。 |
| ByPercentage | 2 | Split Position パーセンテージ未満のポイントを第2のチャートに配置することにより、データ ポイントを円グラフと第2のチャート間で分割することを指定します。 |
| ByPos | 3 | データ ポイントの最後の Split Position を第2のチャートに配置することにより、データ ポイントを円グラフと第2のチャート間で分割することを指定します。 |
| ByValue | 4 | Split Position 未満の値を持つデータ ポイントを第2のチャートに配置することにより、データ ポイントを円グラフと第2のチャート間で分割することを指定します。 |
