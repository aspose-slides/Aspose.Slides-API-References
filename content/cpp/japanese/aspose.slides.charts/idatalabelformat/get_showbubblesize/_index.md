## IDataLabelFormat::get_ShowBubbleSize() メソッド


特定のチャートのデータラベルバブルサイズ値の表示動作を表します。True はバブルサイズ値を表示します。False は非表示にします。読み取り **bool**。

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowBubbleSize()=0
```

## 備考


この [DataLabelFormat](../../datalabelformat/) オブジェクトの親が [DataLabelCollection](../../datalabelcollection/) データラベルのコレクションである場合、このプロパティは [DataLabelCollection](../../datalabelcollection/) コレクション内の新しいデータラベルの ShowBubbleSize プロパティのデフォルト値を取得または設定します。値を設定すると、この値は [DataLabelCollection](../../datalabelcollection/) コレクション内のすべてのデータラベルの ShowBubbleSize プロパティにも設定されます（例: "DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;" はすべての DataLabels[i].ShowBubbleSize が val と等しくなる原因となります）。
