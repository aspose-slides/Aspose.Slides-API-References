## IDataLabelFormat::get_IsNumberFormatLinkedToSource() method


**bool** を読み取ります。

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_IsNumberFormatLinkedToSource()=0
```

## 備考


この [DataLabelFormat](../../datalabelformat/) オブジェクトの親が [DataLabelCollection](../../datalabelcollection/) データラベルのコレクションである場合、このプロパティは [DataLabelCollection](../../datalabelcollection/) コレクション内の新しいデータラベルに対する IsNumberFormatLinkedToSource プロパティのデフォルト値を取得または設定します。値を設定すると、この値は [DataLabelCollection](../../datalabelcollection/) コレクション内のすべてのデータラベルの IsNumberFormatLinkedToSource プロパティにも設定されます（例: \"DataLabels.DefaultDataLabelFormat.IsNumberFormatLinkedToSource = val;\" により、すべての DataLabels[i].IsNumberFormatLinkedToSource が val と等しくなります）。
