## IDataLabelFormat::set_Position(LegendDataLabelPosition) メソッド

データラベルの位置を表します。[LegendDataLabelPosition](../../legenddatalabelposition/)を書きます。

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_Position(LegendDataLabelPosition value)=0
```

## 備考

この [DataLabelFormat](../../datalabelformat/) オブジェクトの親が [DataLabelCollection](../../datalabelcollection/) データラベルのコレクションである場合、このプロパティは [DataLabelCollection](../../datalabelcollection/) コレクション内の新しいデータラベルの Position プロパティの既定値を取得または設定します。[DataLabel](../../datalabel/) オブジェクトの位置を表します。  
このプロパティに値を設定すると、[DataLabelCollection](../../datalabelcollection/) コレクション内のすべてのデータラベルの Position プロパティにも同じ値が設定されます（例: "DataLabels.DefaultDataLabelFormat.Position = val;" により、すべての DataLabels[i].Position が val と等しくなります）。
