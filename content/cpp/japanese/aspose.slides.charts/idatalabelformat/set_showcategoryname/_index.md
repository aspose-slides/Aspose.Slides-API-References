## IDataLabelFormat::set_ShowCategoryName(bool) メソッド

指定されたチャートのデータラベルのカテゴリ名の表示動作を表します。True を指定すると、チャート上のデータラベルのカテゴリ名が表示され、False を指定すると非表示になります。**bool** で書き込みます。

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowCategoryName(bool value)=0
```

## 備考

この [DataLabelFormat](../../datalabelformat/) オブジェクトの親が [DataLabelCollection](../../datalabelcollection/) データラベルのコレクションである場合、このプロパティは [DataLabelCollection](../../datalabelcollection/) コレクション内の新しいデータラベルに対する ShowCategoryName プロパティのデフォルト値を取得または設定します。値を設定すると、このプロパティは [DataLabelCollection](../../datalabelcollection/) コレクション内のすべてのデータラベルの ShowCategoryName プロパティにも同じ値が設定されます（例: \"DataLabels.DefaultDataLabelFormat.ShowCategoryName = val;\" はすべての DataLabels[i].ShowCategoryName が val と等しくなることを引き起こします）。
