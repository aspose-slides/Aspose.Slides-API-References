## Rotation3D::set_RotationX(int8_t) メソッド

X 軸周りの回転角度を設定します（3D チャートの Y 方向、-90 度から 90 度の範囲）。このプロパティは ECMA-376 の 21.2.2.157 rotX（X 回転）項目および PowerPoint 2007+ の \"Y 回転\" オプションと一致します。**int8_t** を書き込みます。
