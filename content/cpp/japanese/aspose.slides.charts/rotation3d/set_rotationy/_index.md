## Rotation3D::set_RotationY(uint16_t) メソッド

Y 軸周りの回転角度を設定します。つまり 3D チャートの X 方向です (0〜360 度の間)。このプロパティは ECMA-376 の 21.2.2.158 rotY (Y Rotation) 項目および PowerPoint 2007+ の "X Rotation" オプションに対応しています。**uint16_t** を書き込みます。

void Aspose::Slides::Charts::Rotation3D::set_RotationY(uint16_t value) override
