## ErrorBarsFormat::set_ValueType(ErrorBarValueType) メソッド

エラーバーの長さを決定する可能な方法を表します。カスタム値タイプの場合、値を指定するには、シリーズの DataPoints コレクション内の特定のデータポイントの [IChartDataPoint::get_ErrorBarsCustomValues()](../../ichartdatapoint/get_errorbarscustomvalues/) プロパティを使用します。Fixed、Percentage、または StandardDeviation の値タイプの場合、値を指定するには Value プロパティを使用します。

[ErrorBarValueType](../../errorbarvaluetype/) を記述してください。

```cpp
void Aspose::Slides::Charts::ErrorBarsFormat::set_ValueType(ErrorBarValueType value) override
```
