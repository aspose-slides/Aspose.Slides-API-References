## IChartCategoryCollection::set_UseCells(bool) メソッド


true の場合、ワークシートはカテゴリの格納に使用されます（このケースは多層カテゴリをサポートします）。false の場合、ワークシートは値の格納に使用されません（このケースは多層カテゴリをサポートしません）。**bool** を書き込みます。
