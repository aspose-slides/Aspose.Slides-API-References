## DataLabelFormat::set_ShowPercentage(bool) メソッド

指定されたチャートのデータラベルのパーセンテージ値の表示動作を表します。True はパーセンテージ値を表示します。False は非表示にします。書き込み **bool**。

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowPercentage(bool value) override
```

## 備考

この [DataLabelFormat](../) オブジェクトの親が [DataLabelCollection](../../datalabelcollection/) データラベルのコレクションである場合、このプロパティは [DataLabelCollection](../../datalabelcollection/) コレクション内の新しいデータラベルに対する ShowPercentage プロパティのデフォルト値を取得または設定します。値を設定すると、このプロパティは [DataLabelCollection](../../datalabelcollection/) コレクション内のすべてのデータラベルの ShowPercentage プロパティにも同じ値を設定します（例：\"DataLabels.DefaultDataLabelFormat.ShowPercentage = val;\" はすべての DataLabels[i].ShowPercentage が val と等しくなることを引き起こします）。
