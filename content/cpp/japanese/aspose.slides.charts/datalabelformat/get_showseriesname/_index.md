## DataLabelFormat::get_ShowSeriesName() メソッド


チャート上のデータ ラベルに対するシリーズ名の表示動作を示す Boolean を返します。True の場合はシリーズ名を表示し、False の場合は非表示にします。Read **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowSeriesName() override
```

## 備考


この [DataLabelFormat](../) オブジェクトの親が [DataLabelCollection](../../datalabelcollection/) データ ラベルのコレクションである場合、このプロパティは [DataLabelCollection](../../datalabelcollection/) コレクション内の新しいデータ ラベルに対する ShowSeriesName プロパティの既定値を取得または設定します。値を設定すると、この値は [DataLabelCollection](../../datalabelcollection/) コレクション内のすべてのデータ ラベルの ShowSeriesName プロパティにも設定されます（例: "DataLabels.DefaultDataLabelFormat.ShowSeriesName = val;" により、すべての DataLabels[i].ShowSeriesName が val と等しくなります）。
