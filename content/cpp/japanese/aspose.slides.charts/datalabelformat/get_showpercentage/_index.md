## DataLabelFormat::get_ShowPercentage() メソッド

指定されたチャートのデータラベルのパーセンテージ値の表示動作を表します。True はパーセンテージ値を表示し、False は非表示にします。読み取り **bool**。

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowPercentage() override
```

## 備考

この [DataLabelFormat](../) オブジェクトの親が [DataLabelCollection](../../datalabelcollection/) データラベル コレクションの場合、このプロパティは [DataLabelCollection](../../datalabelcollection/) コレクション内の新しいデータラベルの ShowPercentage プロパティの既定値を取得または設定します。値を設定すると、この値は [DataLabelCollection](../../datalabelcollection/) コレクション内のすべてのデータラベルの ShowPercentage プロパティにも設定されます（例: "DataLabels.DefaultDataLabelFormat.ShowPercentage = val;" ではすべての DataLabels[i].ShowPercentage が val と等しくなります）。
