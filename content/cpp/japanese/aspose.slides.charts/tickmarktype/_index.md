## TickMarkType 列挙型

指定された軸の目盛線タイプを表します。

```cpp
enum class TickMarkType
```

### 列挙体の値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Cross | 0 | 目盛線は軸を横切ることを指定します。 |
| Inside | 1 | 目盛線はプロット領域の内部になることを指定します。 |
| None | 2 | 目盛線が存在しないことを指定します。 |
| Outside | 3 | 目盛線はプロット領域の外側になることを指定します。 |
