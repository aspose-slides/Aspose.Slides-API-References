## ChartCategoryCollection::set_UseCells(bool) メソッド


true の場合、ワークシートはカテゴリの保存に使用されます（このケースでは複数レベルのカテゴリをサポートします）。false の場合、ワークシートは値の保存に使用されません（このケースでは複数レベルのカテゴリをサポートしません）。書き込みは **bool** 。
