## IDataLabel::get_IsVisible() メソッド


False はデータ ラベルが表示されないことを意味します (そしてすべての Show*-flags (ShowValue, ...) は false です)。 読み取り専用 **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabel::get_IsVisible()=0
```

## 備考


データ ラベルが表示されている場合、[Hide()](../hide/) メソッドで非表示にできます。 ただし、データ ラベルが表示されていない場合 (IsVisible が false のとき)、Show*-flags (ShowValue, ...) を true に設定することでデータ ラベルを表示できます。
