## IDataLabel::Hide() メソッド


Show*-flags (ShowValue, ...) をすべて false に設定してデータ ラベルを非表示にします。IsVisible はこれ以降 false になります。

```cpp
virtual void Aspose::Slides::Charts::IDataLabel::Hide()=0
```

## 備考


データ ラベルが表示されていない場合 (IsVisible が false) は、Show*-flags (ShowValue, ...) を true に設定してデータ ラベルを表示できます。
