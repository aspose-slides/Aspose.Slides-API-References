## BaseChartValue::get_DataSourceType() メソッド

このプロパティが子クラスで AsCell、AsCells、AsLiteralString、または AsLiteralDouble のいずれかであるかを指定します。言い換えれば、Data プロパティの値の型を指定します。参照 [Charts::DataSourceType](../../datasourcetype/)。

```cpp
Aspose::Slides::Charts::DataSourceType Aspose::Slides::Charts::BaseChartValue::get_DataSourceType() override
```

## 備考

[ChartDataPointCollection](../../chartdatapointcollection/) のポイントの場合、このプロパティは読み取り専用です。この場合、このプロパティの値を変更するには、ChartDataPointCollection.DataSourceTypeFor<...> プロパティのいずれかを使用できます。
