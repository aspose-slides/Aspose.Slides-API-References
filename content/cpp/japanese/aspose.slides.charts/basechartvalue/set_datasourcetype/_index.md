## BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType) メソッド

このプロパティが子クラスで実際に使用されるかどうかを指定します。言い換えれば、Data プロパティの値の型を指定します。[Charts::DataSourceType](../../datasourcetype/)を書き込みます。

```cpp
void Aspose::Slides::Charts::BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType value) override
```

## 備考

[ChartDataPointCollection](../../chartdatapointcollection/) のポイントに対して、このプロパティは読み取り専用です。この場合、このプロパティの値を変更するには、ChartDataPointCollection.DataSourceTypeFor<...> プロパティのいずれかを使用できます。
