## IPdfOptions::set_EmbedTrueTypeFontsForASCII(bool) メソッド

ASCII 文字 32-127 の場合に TrueType フォントを埋め込むには true を指定します。[Fonts](../../../aspose.slides/fonts/) 文字コード 127 より大きい場合は常に埋め込まれます。**bool** を書き込みます。

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_EmbedTrueTypeFontsForASCII(bool value)=0
```

## 備考

デフォルトは **true**。
