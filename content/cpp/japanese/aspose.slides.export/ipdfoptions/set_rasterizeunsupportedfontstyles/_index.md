## IPdfOptions::set_RasterizeUnsupportedFontStyles(bool) メソッド

フォントが太字スタイルをサポートしていない場合に、テキストをビットマップとしてラスタライズし、PDFに保存するかどうかを示します。この方法は、特定のフォントに対して生成された PDF のテキスト品質を向上させる可能性があります。書き込み **bool**。

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_RasterizeUnsupportedFontStyles(bool value)=0
```

## 備考

デフォルトは **false** です。
