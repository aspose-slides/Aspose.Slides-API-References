## IPdfOptions::get_EmbedTrueTypeFontsForASCII() メソッド

True to embed true type fonts for ASCII characters 32-127. [Fonts](../../../aspose.slides/fonts/) は 127 より大きい文字コードの場合、常に埋め込まれます。Read **bool**.

```cpp
virtual bool Aspose::Slides::Export::IPdfOptions::get_EmbedTrueTypeFontsForASCII()=0
```

## 備考

Default is **true**.
