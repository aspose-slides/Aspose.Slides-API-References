## PdfOptions::set_EmbedTrueTypeFontsForASCII(bool) メソッド


[Aspose.Slides](../../../aspose.slides/) が ASCII (33..127 のコード範囲) のテキストに対して共通フォントを埋め込むかどうかを決定します。[Fonts](../../../aspose.slides/fonts/) は文字コードが 127 より大きい場合は常に埋め込まれます。共通フォントのリストには PDF のベース 14 フォントと追加のユーザー指定フォントが含まれます。戻り値は **bool** です。

```cpp
void Aspose::Slides::Export::PdfOptions::set_EmbedTrueTypeFontsForASCII(bool value) override
```

## 備考


デフォルトは **true** です。
