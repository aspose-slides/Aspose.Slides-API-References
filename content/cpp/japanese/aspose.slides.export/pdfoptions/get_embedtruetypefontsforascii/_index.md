## PdfOptions::get_EmbedTrueTypeFontsForASCII() メソッド


[Aspose.Slides](../../../aspose.slides/) が ASCII (33..127 のコード範囲) テキスト用に共通フォントを埋め込むかどうかを判定します。[Fonts](../../../aspose.slides/fonts/) は 127 を超える文字コードの場合、常に埋め込まれます。共通フォントリストには PDF の基本 14 フォントと、ユーザーが指定した追加フォントが含まれます。読み取りは **bool** です。

```cpp
bool Aspose::Slides::Export::PdfOptions::get_EmbedTrueTypeFontsForASCII() override
```

## 備考


デフォルトは **true** です。
