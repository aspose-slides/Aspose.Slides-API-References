## PdfOptions::get_RasterizeUnsupportedFontStyles() メソッド


フォントが太字スタイルをサポートしていない場合に、テキストをビットマップとしてラスタライズし、PDF に保存すべきかどうかを示します。このアプローチは、特定のフォントに対して生成された PDF のテキスト品質を向上させることができます。取得 **bool**.

```cpp
bool Aspose::Slides::Export::PdfOptions::get_RasterizeUnsupportedFontStyles() override
```

## 備考


デフォルトは **false** です。
