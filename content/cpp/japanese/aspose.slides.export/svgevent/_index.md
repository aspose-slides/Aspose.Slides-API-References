## SvgEvent 列挙体

SVG シェイプのオプションを表します。

```cpp
enum class SvgEvent
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| OnFocusIn | 0 | 要素がフォーカスを受け取ったときに発生します。たとえばテキストが選択されたときなどです。 |
| OnFocusOut | 1 | 要素がフォーカスを失ったときに発生します。たとえばテキストの選択が解除されたときなどです。 |
| OnActivate | 2 | 要素がアクティブになったときに発生します。たとえばマウスクリックやキー入力によってです。 |
| OnClick | 3 | 要素上でポインティングデバイスのボタンがクリックされたときに発生します。 |
| OnMouseDown | 4 | 要素上でポインティングデバイスのボタンが押されたときに発生します。 |
| OnMouseUp | 5 | 要素上でポインティングデバイスのボタンが離されたときに発生します。 |
| OnMouseOver | 6 | ポインティングデバイスが要素上に移動したときに発生します。 |
| OnMouseMove | 7 | ポインティングデバイスが要素上にある状態で移動したときに発生します。 |
| OnMouseOut | 8 | ポインティングデバイスが要素から離れたときに発生します。 |
| OnLoad | 9 | ユーザーエージェントが要素とその子孫、およびそれを描画するために必要なすべての参照リソースを完全に解析したときに発生します。 |
| OnUnload | 10 | [DOM](../../aspose.slides.dom/) の実装がウィンドウまたはフレームからドキュメントを削除したときに発生します。最も外側の svg 要素にのみ適用されます。 |
| OnAbort | 11 | 要素が完全にロードされる前にページの読み込みが停止されたときに発生します。 |
| OnError | 12 | 要素が正しくロードされなかった場合、またはスクリプト実行中にエラーが発生したときに発生します。 |
| OnResize | 13 | ドキュメントビューがリサイズされるときに発生します。最も外側の svg 要素にのみ適用されます。 |
| OnScroll | 14 | ドキュメントビューが X 軸、Y 軸、またはその両方に沿って移動するときに発生します。最も外側の svg 要素にのみ適用されます。 |
| OnZoom | 15 | ドキュメントビューのズームレベルが変更されるときに発生します。最も外側の svg 要素にのみ適用されます。 |
| OnBegin | 16 | アニメーション要素が開始したときに発生します。 |
| OnEnd | 17 | アニメーション要素が終了したときに発生します。 |
| OnRepeat | 18 | アニメーション要素が繰り返されたときに発生します。 |
