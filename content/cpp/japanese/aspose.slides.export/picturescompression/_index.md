## PicturesCompression enum

画像の圧縮レベルを表します

```cpp
enum class PicturesCompression
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Dpi330 | 0 | 高解像度（HD）ディスプレイ向けの高品質 |
| Dpi220 | 1 | ほとんどのプリンタと画面で優れた品質 |
| Dpi150 | 2 | ウェブページやプロジェクタ向けの適切な品質 |
| Dpi96 | 3 | 共有用にドキュメントサイズを最小化 |
| Dpi72 | 4 | デフォルトの圧縮レベル |
| DocumentResolution | 5 | ドキュメントの解像度を使用します - 画像は圧縮されず、そのままドキュメントに使用されます |
