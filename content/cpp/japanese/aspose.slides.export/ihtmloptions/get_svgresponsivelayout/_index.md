## IHtmlOptions::get_SvgResponsiveLayout() メソッド


SVG コンテナから width と height 属性を除外する場合は true に設定します。これによりレイアウトがレスポンシブになります。除外しない場合は false に設定します。**bool** を返します。

virtual bool Aspose::Slides::Export::IHtmlOptions::get_SvgResponsiveLayout()=0
