## IHtmlOptions::set_SvgResponsiveLayout(bool) メソッド

SVG コンテナから width と height 属性を除外するには True を設定します。これによりレイアウトがレスポンシブになります。そうでない場合は False を設定します。**bool** を書き込みます。

virtual void Aspose::Slides::Export::IHtmlOptions::set_SvgResponsiveLayout(bool value)=0
