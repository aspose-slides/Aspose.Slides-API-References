## ISVGOptions::set_DeletePicturesCroppedAreas(bool) メソッド

ブールフラグは、切り抜かれた部分がドキュメントの一部として残るかどうかを示します。true の場合、切り抜かれた部分は削除され、false の場合、ドキュメントにシリアライズされます（これによりファイルが大きくなる可能性があります）。**bool** を書き込みます。

virtual void Aspose::Slides::Export::ISVGOptions::set_DeletePicturesCroppedAreas(bool value)=0
