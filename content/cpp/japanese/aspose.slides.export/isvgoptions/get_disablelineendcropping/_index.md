## ISVGOptions::get_DisableLineEndCropping() メソッド


SVG 1.1 では、マーカーのインセットを定義する機能がありません。 [Aspose.Slides](../../../aspose.slides/) SVG ライティングエンジンはその問題に対する回避策を持っています：矢印付きの線の端を切り取ることで、線がマーカーと重ならないようにします。 このオプションはその動作を無効にします。 取得 **bool**。

```cpp
virtual bool Aspose::Slides::Export::ISVGOptions::get_DisableLineEndCropping()=0
```
