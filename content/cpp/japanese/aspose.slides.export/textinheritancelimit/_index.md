## TextInheritanceLimit 列挙型

テキストプロパティの継承深度を制御します。

```cpp
enum class TextInheritanceLimit
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| All | 0 | すべてのテキストプロパティを継承します。 |
| TextBox | 1 | [TextFrame](../../aspose.slides/textframe/) のスタイルからのみ継承します。 |
| ParagraphOnly | 2 | 段落用に定義されたプロパティのみを使用します。 |
