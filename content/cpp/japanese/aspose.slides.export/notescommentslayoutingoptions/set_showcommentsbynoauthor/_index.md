## NotesCommentsLayoutingOptions::set_ShowCommentsByNoAuthor(bool) メソッド


コメントの作成者がいない場合の表示可否を設定します。true の場合、コメントが表示されます。（コメントが表示されている場合にのみ適用されます）。

```cpp
void Aspose::Slides::Export::NotesCommentsLayoutingOptions::set_ShowCommentsByNoAuthor(bool value)
```

## 備考


デフォルト値は **false**.
