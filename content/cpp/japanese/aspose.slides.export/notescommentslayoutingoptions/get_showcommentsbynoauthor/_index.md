## NotesCommentsLayoutingOptions::get_ShowCommentsByNoAuthor() メソッド


著者が設定されていないコメントの表示可否を取得します。true の場合、コメントが表示されます。（コメントが表示されている場合にのみ適用されます。）

```cpp
bool Aspose::Slides::Export::NotesCommentsLayoutingOptions::get_ShowCommentsByNoAuthor()
```

## 備考


デフォルト値は **false** 。
