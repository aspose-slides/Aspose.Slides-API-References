## TiffCompressionTypes 列挙型

プレゼンテーションが TIFF 形式で圧縮される方法を制御するオプションを提供します。

```cpp
enum class TiffCompressionTypes
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Default | 0 | 既定の圧縮方式 (LZW) を指定します。 |
| None | 1 | 圧縮しないことを指定します。 |
| CCITT3 | 2 | CCITT3 圧縮方式を指定します。 |
| CCITT4 | 3 | CCITT4 圧縮方式を指定します。 |
| LZW | 4 | LZW 圧縮方式 (Default) を指定します。 |
| RLE | 5 | RLE 圧縮方式を指定します。 |
