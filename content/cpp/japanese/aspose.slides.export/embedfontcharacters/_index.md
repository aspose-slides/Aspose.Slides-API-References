## EmbedFontCharacters 列挙型

[IPresentation](../../aspose.slides/ipresentation/) に新しい埋め込みフォントを追加する際に使用するルールを表します。

```cpp
enum class EmbedFontCharacters
```

### Values

| 名前 | 値 | 説明 |
| --- | --- | --- |
| OnlyUsed | 0 | プレゼンテーションで使用されている文字だけを埋め込みます（ファイルサイズ削減に最適）。 |
| All | 1 | すべての文字を埋め込みます（他のユーザーが編集する場合に最適）。 |
