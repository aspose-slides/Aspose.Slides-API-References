## SVGOptions::set_DisableLineEndCropping(bool) メソッド

SVG 1.1 ではマーカーのインセットを定義する機能がありません。[Aspose.Slides](../../../aspose.slides/) SVG ライティング エンジンはこの問題に対する回避策として、矢印付きの線の端を切り取ることで、線がマーカーと重ならないようにします。このオプションはその動作を無効にします。**bool** を書き込みます。

```cpp
void Aspose::Slides::Export::SVGOptions::set_DisableLineEndCropping(bool value) override
```
