## Enumerable::Range(int32_t, int32_t) メソッド

指定された範囲内の整数のシーケンスを生成します。

```cpp
static SharedPtr<Collections::Generic::IEnumerable<int32_t>> System::Linq::Enumerable::Range(int32_t start, int32_t count)
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| start | **int32_t** | シーケンス内の最初の整数の値。 |
| count | **int32_t** | 生成する連続整数の数。 |

### 戻り値

**int32_t** の **IEnumerable** で、連続した整数の範囲を含みます。
