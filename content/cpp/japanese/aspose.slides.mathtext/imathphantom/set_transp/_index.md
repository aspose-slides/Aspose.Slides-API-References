## IMathPhantom::set_Transp(bool) メソッド

ファントムがクラスベースの間隔ルールに対して透明かどうかを示す値を設定します。

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_Transp(bool value)=0
```

## 備考

**true** の場合、ファントム内部の演算子や記号はファントム周囲の数学的間隔に依然として影響します（可視であるかのように）。**false** の場合、クラスベースの間隔は無視されます。OMML 属性 **m:transp** に対応します。
