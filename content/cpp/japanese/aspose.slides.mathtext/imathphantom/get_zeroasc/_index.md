## IMathPhantom::get_ZeroAsc() メソッド

ベース要素の上昇（ベースライン上の高さ）をゼロとして扱うかどうかを示す値を取得します。

```cpp
virtual bool Aspose::Slides::MathText::IMathPhantom::get_ZeroAsc()=0
```

## 備考

**true** の場合、ファントムは周囲の数式行のベースラインを上げません。OMML 属性 **m:zeroAsc** に対応します。
