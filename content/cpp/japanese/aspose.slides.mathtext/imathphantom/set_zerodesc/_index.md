## IMathPhantom::set_ZeroDesc(bool) メソッド

ベース要素の降下（ベースライン以下の深さ）を0として扱うかどうかを示す値を設定します。

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_ZeroDesc(bool value)=0
```

## 備考

**true** の場合、ファントムは周囲の数式行のベースラインを下げません。OMML 属性 **m:zeroDesc** に対応します。
