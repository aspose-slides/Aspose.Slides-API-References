## IMathPhantom クラス

子要素のレイアウトに影響を与えるが必ずしも表示しないファントム数学オブジェクト (<m:phant>) を表します。ファントムは基底式を非表示にしつつ、幅、高さ、または深さを保持して数式を整列させたりスペースを確保したりできます。表示と形状の動作は Show、ZeroWid、ZeroAsc、ZeroDesc、Transp などのプロパティで制御されます。

```cpp
class IMathPhantom : public virtual Aspose::Slides::MathText::IMathElement
```
