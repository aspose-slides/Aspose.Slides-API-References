## IMathPhantom::get_Transp() メソッド

クラスベースのスペーシング規則に対して、ファントムが透明かどうかを示す値を取得します。

```cpp
virtual bool Aspose::Slides::MathText::IMathPhantom::get_Transp()=0
```

## 備考

**true** のとき、ファントム内部の演算子や記号はファントム周囲の数式スペースに依然として影響します（可視であるかのように）。**false** のとき、クラスベースのスペーシングは無視されます。OMML 属性 **m:transp** に対応します。
