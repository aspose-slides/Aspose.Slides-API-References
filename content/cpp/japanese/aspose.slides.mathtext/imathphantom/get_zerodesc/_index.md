## IMathPhantom::get_ZeroDesc() メソッド

ベース要素の下降（ベースライン以下の深さ）をゼロとして扱うかどうかを示す値を取得します。

```cpp
virtual bool Aspose::Slides::MathText::IMathPhantom::get_ZeroDesc()=0
```

## 備考

**true** の場合、ファントムは周囲の数式行のベースラインを下げません。OMML 属性 **m:zeroDesc** に対応します。
