## IMathPhantom::get_Show() メソッド


ベース要素が表示されているかどうかを示す値を取得します。

```cpp
virtual bool Aspose::Slides::MathText::IMathPhantom::get_Show()=0
```

## 備考


**false** の場合、ベース要素は非表示になりますが、他のファントム設定に応じてスペースを占有することがあります。OMML 属性 **m:show** に対応します。
