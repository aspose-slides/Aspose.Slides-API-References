## MathPhantom::get_ZeroDesc() メソッド

ベース要素の降下（ベースライン以下の深さ）がゼロとして扱われるかどうかを示す値を取得します。

```cpp
bool Aspose::Slides::MathText::MathPhantom::get_ZeroDesc() override
```

## 備考

**true** の場合、ファントムは周囲の数式行のベースラインを下げません。OMML 属性 **m:zeroDesc** に対応します。
