## MathPhantom::get_Transp() メソッド

ファントムがクラスベースの間隔ルールに対して透明であるかどうかを示す値を取得します。

```cpp
bool Aspose::Slides::MathText::MathPhantom::get_Transp() override
```

## 備考

**true** の場合、ファントム内の演算子や記号はファントムの周囲の数式間隔に依然として影響を与えます（表示されているかのように）。**false** の場合、クラスベースの間隔は無視されます。OMML 属性 **m:transp** に対応します。
