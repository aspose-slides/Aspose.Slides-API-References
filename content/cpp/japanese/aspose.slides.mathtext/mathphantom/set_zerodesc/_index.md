## MathPhantom::set_ZeroDesc(bool) メソッド

基底要素の降下（ベースライン以下の深さ）をゼロとして扱うかどうかを示す値を設定します。

```cpp
void Aspose::Slides::MathText::MathPhantom::set_ZeroDesc(bool value) override
```

## 備考

**true** の場合、ファントムは周囲の数式行のベースラインを下げません。OMML 属性 **m:zeroDesc** に対応します。
