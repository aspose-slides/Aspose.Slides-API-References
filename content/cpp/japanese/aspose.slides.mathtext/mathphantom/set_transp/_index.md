## MathPhantom::set_Transp(bool) メソッド

クラスベースのスペーシング規則に対して、ファントムが透明であるかどうかを示す値を設定します。

```cpp
void Aspose::Slides::MathText::MathPhantom::set_Transp(bool value) override
```

## 備考

**true** の場合、ファントム内部の演算子や記号は、ファントムの周囲の数式スペーシングに依然として影響します（可視であるかのように）。**false** の場合、クラスベースのスペーシングは無視されます。OMML 属性 **m:transp** に対応します。
