## MathPhantom::set_Show(bool) method


ベース要素が表示されるかどうかを示す値を設定します。

```cpp
void Aspose::Slides::MathText::MathPhantom::set_Show(bool value) override
```

## 備考


**false** の場合、ベース要素は非表示になりますが、他のファントム設定に応じてスペースを占有したままになることがあります。OMML 属性 **m:show** に対応します。
