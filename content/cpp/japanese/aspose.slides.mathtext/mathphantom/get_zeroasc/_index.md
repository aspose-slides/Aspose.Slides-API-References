## MathPhantom::get_ZeroAsc() メソッド

ベース要素の上昇（ベースライン上方の高さ）がゼロとして扱われるかどうかを示す値を取得します。

```cpp
bool Aspose::Slides::MathText::MathPhantom::get_ZeroAsc() override
```

## 備考

**true** の場合、ファントムは周囲の数式行のベースラインを上げません。OMML 属性 **m:zeroAsc** に対応します。
