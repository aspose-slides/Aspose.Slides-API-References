## MathPhantom::get_Show() メソッド


ベース要素が表示されているかどうかを示す値を取得します。

```cpp
bool Aspose::Slides::MathText::MathPhantom::get_Show() override
```

## 備考


**false** のとき、ベース要素は非表示になりますが、他のファントム設定に応じてスペースを占有したままになる場合があります。OMML 属性 **m:show** に対応します。
