## MathJustification 列挙型

数式段落の配置を指定します（同じ段落内の隣接する数式テキストの系列）。

```cpp
enum class MathJustification
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| LeftJustified | 1 | 数式テキストを左揃えにする |
| RightJustified | 2 | 数式テキストを右揃えにする |
| Centered | 3 | 数式テキストを中央揃えにする |
| CenteredAsGroup | 4 | ページ上で数式ブロック全体を1つの単位として中央に配置します。これにより、数式テキストのインスタンス同士は相対的に配置できますが、全体としては中央揃えになります。 |
