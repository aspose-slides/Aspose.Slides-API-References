```cpp
bool System::Xml::XmlNotation::get_IsReadOnly() override
```


### 戻り値

**true** はノードが読み取り専用の場合、**false** はそれ以外の場合です。 [XmlNotation](../) ノードは読み取り専用であるため、このメソッドは常に **true** を返します。
