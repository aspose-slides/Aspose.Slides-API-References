## XmlWriter::get_Settings() メソッド

この [XmlWriter](../) インスタンスの作成に使用された [XmlWriterSettings](../../xmlwritersettings/) オブジェクトを返します。

```cpp
virtual SharedPtr<XmlWriterSettings> System::Xml::XmlWriter::get_Settings()
```

### 戻り値

[XmlWriterSettings](../../xmlwritersettings/) オブジェクトはこのライターインスタンスの作成に使用されます。このライターが [XmlWriter::Create](../create/) メソッドを使用して作成されていない場合、このメソッドは **nullptr** を返します。
