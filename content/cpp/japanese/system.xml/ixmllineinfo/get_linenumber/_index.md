## IXmlLineInfo::get_LineNumber() メソッド


現在の行番号を返します。

```cpp
virtual int32_t System::Xml::IXmlLineInfo::get_LineNumber()=0
```


### 戻り値

現在の行番号または 0 を返します（行情報が利用できない場合、例として、[IXmlLineInfo::HasLineInfo](../haslineinfo/) は **false** を返します）。
