## XmlReader::MoveToElement() メソッド


派生クラスでオーバーライドされた場合、現在の属性ノードを含む要素へ移動します。

```cpp
virtual bool System::Xml::XmlReader::MoveToElement()=0
```


### 戻り値

**true** 読み取り位置が属性上にある場合（読み取り位置は属性を所有する要素に移動します）； **false** 読み取り位置が属性上にない場合（読み取り位置は変更されません）。
