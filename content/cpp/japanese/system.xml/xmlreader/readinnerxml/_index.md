## XmlReader::ReadInnerXml() method


派生クラスでオーバーライドされた場合、マークアップを含むすべてのコンテンツを文字列として読み取ります。

```cpp
virtual String System::Xml::XmlReader::ReadInnerXml()
```


### 戻り値

現在のノードに含まれるすべての XML コンテンツ（マークアップを含む）。現在のノードに子がない場合は、空の文字列が返されます。現在のノードが要素でも属性でもない場合も、空の文字列が返されます。
