## XmlReader::get_EOF() メソッド

派生クラスでオーバーライドされた場合、リーダーがストリームの末尾に位置しているかどうかを示す値を取得します。

```cpp
virtual bool System::Xml::XmlReader::get_EOF()=0
```

### 戻り値

**true** if the reader is positioned at the end of the stream; otherwise, **false**.
