## XmlReader::get_NamespaceURI() メソッド

派生クラスでオーバーライドされた場合、リーダーが位置しているノードの名前空間 URI（W3C 名前空間仕様で定義されている）を取得します。

```cpp
virtual String System::Xml::XmlReader::get_NamespaceURI()=0
```

### 戻り値

現在のノードの名前空間 URI; それ以外の場合は空文字列です。
