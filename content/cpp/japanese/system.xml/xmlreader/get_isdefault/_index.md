## XmlReader::get_IsDefault() メソッド

派生クラスでオーバーライドされた場合、現在のノードが DTD またはスキーマで定義されたデフォルト値から生成された属性であるかどうかを示す値を取得します。

```cpp
virtual bool System::Xml::XmlReader::get_IsDefault()
```

### 戻り値

**true** 現在のノードが DTD またはスキーマで定義されたデフォルト値から生成された属性である場合; **false** 属性値が明示的に設定された場合。
