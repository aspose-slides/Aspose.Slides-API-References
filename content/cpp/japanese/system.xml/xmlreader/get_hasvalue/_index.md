## XmlReader::get_HasValue() メソッド


派生クラスでオーバーライドされた場合、現在のノードが [XmlReader::get_Value](../get_value/) 値を持つことができるかどうかを示す値を取得します。

```cpp
virtual bool System::Xml::XmlReader::get_HasValue()
```


### 戻り値

**true** の場合、リーダーが現在位置しているノードが **Value** を持つことができる場合です。それ以外の場合は **false** です。**false** の場合、ノードの値は [String::Empty](../../../system/string/empty/) です。
