## NamespaceHandling 列挙型

重複した名前空間宣言を [XmlWriter](../xmlwriter/) から削除するかどうかを指定します。

```cpp
enum class NamespaceHandling
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Default | 0 | 重複した名前空間宣言が削除されないことを指定します。 |
| OmitDuplicates | 1 | 重複した名前空間宣言が削除されることを指定します。 重複した名前空間を削除するには、プレフィックスと名前空間が一致している必要があります。 |
