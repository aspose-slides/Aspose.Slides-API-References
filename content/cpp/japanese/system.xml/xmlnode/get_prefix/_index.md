## XmlNode::get_Prefix() メソッド


このノードの名前空間プレフィックスを返します。

```cpp
virtual String System::Xml::XmlNode::get_Prefix()
```


### 戻り値

このノードの名前空間プレフィックスです。例えば、要素 **<bk:book>** の **Prefix** は **bk** です。プレフィックスがない場合、このメソッドは [String::Empty](../../../system/string/empty/) を返します。
