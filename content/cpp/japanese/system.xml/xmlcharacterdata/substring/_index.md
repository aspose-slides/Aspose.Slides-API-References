### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| offset | **int32_t** | 文字列内で取得を開始する位置です。オフセットが 0 の場合、開始点はデータの先頭であることを示します。 |
| count | **int32_t** | 取得する文字数です。 |

### 戻り値
