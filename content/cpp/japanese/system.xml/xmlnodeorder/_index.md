## XmlNodeOrder 列挙型

ノードが別のノードと比較したときの文書内順序を表します。

```cpp
enum class XmlNodeOrder
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Before | 0 | このナビゲータの現在のノードは、指定されたナビゲータの現在のノードの前にあります。 |
| After | 1 | このナビゲータの現在のノードは、指定されたナビゲータの現在のノードの後にあります。 |
| Same | 2 | 2 つのナビゲータは同じノード上に位置しています。 |
| Unknown | 3 | 文書順序でノードの位置を相互に決定できません。これは、2 つのノードが異なるツリーに存在する場合に発生する可能性があります。 |
