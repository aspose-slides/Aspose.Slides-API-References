## XmlReaderSettings::set_MaxCharactersInDocument(int64_t) メソッド

XML ドキュメント内で許容できる文字数の最大値を示す値を設定します。0 (ゼロ) の値は、XML ドキュメントのサイズに制限がないことを意味します。0 以外の値は、文字数で最大サイズを指定します。

void System::Xml::XmlReaderSettings::set_MaxCharactersInDocument(int64_t value)
