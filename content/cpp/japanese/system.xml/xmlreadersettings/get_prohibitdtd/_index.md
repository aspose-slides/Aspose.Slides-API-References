## XmlReaderSettings::get_ProhibitDtd() メソッド

ドキュメント型定義 (DTD) の処理を禁止するかどうかを示す値を返します。

```cpp
bool System::Xml::XmlReaderSettings::get_ProhibitDtd()
```

### 戻り値

**true** to prohibit DTD processing; otherwise **false**. The default is **true**.

非推奨
:   このメソッドは廃止されています。代わりに [XmlTextReader::get_DtdProcessing](../../xmltextreader/get_dtdprocessing/) を使用してください。
