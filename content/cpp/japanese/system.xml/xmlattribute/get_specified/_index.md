## XmlAttribute::get_Specified() メソッド


属性値が明示的に設定されたかどうかを示す値を返します。

```cpp
virtual bool System::Xml::XmlAttribute::get_Specified()
```


### 戻り値

**true** この属性が元のインスタンス文書で明示的に値が設定された場合; それ以外の場合は **false**。**false** の値は属性の値が DTD から来たことを示します。
