## XmlElement::set_IsEmpty(bool) メソッド


要素のタグ形式を設定します。

```cpp
void System::Xml::XmlElement::set_IsEmpty(bool value)
```


### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| value | **bool** | 設定する値。 この値を設定する際、**true** に設定すると、要素の子要素が削除され、要素は短いタグ形式でシリアライズされます。**false** に設定すると、要素の内容の有無に関わらず値が変更されます；要素が空の場合、長い形式でシリアライズされます。 |
