## WhitespaceHandling 列挙型

空白文字の処理方法を指定します。

```cpp
enum class WhitespaceHandling
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| All | 0 | **Whitespace** と **SignificantWhitespace** ノードを返します。これがデフォルトです。 |
| Significant | 1 | **SignificantWhitespace** ノードのみを返します。 |
| None | 2 | **Whitespace** も **SignificantWhitespace** もノードを返しません。 |
