## XmlTextWriter::get_XmlSpace() メソッド

現在の **xml:space** スコープを表す XmlSpace を返します。

```cpp
System::Xml::XmlSpace System::Xml::XmlTextWriter::get_XmlSpace() override
```

### 戻り値

現在の **xml:space** スコープを表す XmlSpace。

| 値 | 意味 |
| --- | --- |
| None | これは `xml:space` スコープが存在しない場合のデフォルトです。 |
| Default | 現在のスコープは `xml:space="default"` です。 |
| Preserve | 現在のスコープは `xml:space="preserve"` です。 |
