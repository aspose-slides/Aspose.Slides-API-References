## フォーマット列挙型

[XmlTextWriter](../xmltextwriter/) の書式オプションを指定します。

```cpp
enum class Formatting
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| None | 0 | 特別な書式設定は適用されません。デフォルトです。 |
| Indented | 1 | 子要素が [XmlTextWriter::set_Indentation](../xmltextwriter/set_indentation/) と [XmlTextWriter::set_IndentChar](../xmltextwriter/set_indentchar/) 設定に従ってインデントされます。 |
