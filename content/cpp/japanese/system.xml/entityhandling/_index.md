## EntityHandling 列挙型


[XmlTextReader](../xmltextreader/) または [XmlValidatingReader](../xmlvalidatingreader/) がエンティティを処理する方法を指定します。

```cpp
enum class EntityHandling
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| ExpandEntities | 1 | すべてのエンティティを展開し、展開されたノードを返します。 |
| ExpandCharEntities | 2 | 文字エンティティを展開し、一般エンティティを [XmlNodeType::EntityReference](../xmlnodetype/) ノードとして返します。 |
