## XmlValidatingReader::get_IsDefault() メソッド

現在のノードが、文書型定義（DTD）またはスキーマで定義されたデフォルト値から生成された属性であるかどうかを示す値を返します。

```cpp
bool System::Xml::XmlValidatingReader::get_IsDefault() override
```

### 戻り値

現在のノードが DTD またはスキーマで定義されたデフォルト値から生成された属性である場合は **true**、属性値が明示的に設定されている場合は **false**。
