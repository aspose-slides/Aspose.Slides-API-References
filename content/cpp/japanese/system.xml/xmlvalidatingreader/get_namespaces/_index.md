## XmlValidatingReader::get_Namespaces() メソッド


名前空間サポートを行うかどうかを示す値を返します。

```cpp
bool System::Xml::XmlValidatingReader::get_Namespaces()
```


### 戻り値

**true** を返して名前空間サポートを行います。そうでない場合は **false** を返します。既定は **true** です。
