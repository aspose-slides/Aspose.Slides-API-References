## XmlValidatingReader::set_XmlResolver(const SharedPtr\<System::Xml::XmlResolver\>\&) メソッド

外部の文書型定義（DTD）およびスキーマ位置参照を解決するために使用される[XmlResolver](../../xmlresolver/)を設定します。[XmlResolver](../../xmlresolver/)は、XML [Schema](../../../system.xml.schema/) 定義言語（XSD）スキーマで見つかるインポートまたはインクルード要素を処理するためにも使用されます。

void System::Xml::XmlValidatingReader::set_XmlResolver(const SharedPtr<System::Xml::XmlResolver> &value)
