## XmlNodeReader::MoveToElement() メソッド

現在の属性ノードを含む要素に移動します。

```cpp
bool System::Xml::XmlNodeReader::MoveToElement() override
```

### 戻り値

**true** 読み取り位置が属性上にある場合（読み取り位置は属性を所有する要素に移動します）； **false** 読み取り位置が属性上にない場合（読み取り位置は変更されません）。
