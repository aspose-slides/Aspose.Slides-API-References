## XmlNodeChangedEventArgs::get_Action() メソッド

発生しているノード変更イベントのタイプを示す値を返します。

```cpp
XmlNodeChangedAction System::Xml::XmlNodeChangedEventArgs::get_Action()
```

### 戻り値

ノード変更イベントを記述する列挙値のいずれかです。**Action** 値は、イベントが発生した時点（前または後）を区別しません。両方のインスタンスを処理するために、個別のイベントハンドラを作成できます。
