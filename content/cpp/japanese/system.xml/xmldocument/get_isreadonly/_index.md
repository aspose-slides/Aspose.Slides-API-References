## XmlDocument::get_IsReadOnly() メソッド

現在のノードが読み取り専用であるかどうかを示す値を返します。

```cpp
bool System::Xml::XmlDocument::get_IsReadOnly() override
```

### 戻り値

現在のノードが読み取り専用の場合は **true**、それ以外の場合は **false**。[XmlDocument](../) ノードは常に **false** を返します。
