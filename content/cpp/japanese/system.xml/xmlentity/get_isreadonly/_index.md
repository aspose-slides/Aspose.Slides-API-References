```cpp
bool System::Xml::XmlEntity::get_IsReadOnly() override
```


### 戻り値

ノードが読み取り専用の場合は **true**、それ以外の場合は **false** です。[XmlEntity](../) ノードは読み取り専用であるため、このメソッドは常に **true** を返します。
