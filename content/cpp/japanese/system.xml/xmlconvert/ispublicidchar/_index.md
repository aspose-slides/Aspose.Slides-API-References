## XmlConvert::IsPublicIdChar(char16_t) メソッド

引数の文字が有効な public id 文字である場合、渡された文字インスタンスを返し、そうでない場合は **nullptr** を返します。

```cpp
static bool System::Xml::XmlConvert::IsPublicIdChar(char16_t ch)
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| ch | char16_t | [Char](../../../system/char/) オブジェクトを検証します。 |

### 戻り値

文字が有効な public id 文字である場合は渡された文字を返し、そうでない場合は **nullptr** を返します。
