## XmlConvert::IsWhitespaceChar(char16_t) メソッド

渡された文字が有効な XML 空白文字かどうかをチェックします。

```cpp
static bool System::Xml::XmlConvert::IsWhitespaceChar(char16_t ch)
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| ch | char16_t | 検証する文字です。 |

### 戻り値

渡された文字が有効な XML 空白文字の場合は **true**、それ以外の場合は **false** です。
