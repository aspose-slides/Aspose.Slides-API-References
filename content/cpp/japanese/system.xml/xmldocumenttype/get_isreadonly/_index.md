## XmlDocumentType::get_IsReadOnly() メソッド


ノードが読み取り専用かどうかを示す値を返します。

```cpp
bool System::Xml::XmlDocumentType::get_IsReadOnly() override
```


### 戻り値

**true** の場合、ノードは読み取り専用です。そうでない場合は **false**。DocumentType ノードは読み取り専用であるため、このメソッドは常に **true** を返します。
