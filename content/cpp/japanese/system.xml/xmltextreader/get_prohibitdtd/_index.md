## XmlTextReader::get_ProhibitDtd() メソッド


DTD 処理を許可するかどうかを示す値を返します。

```cpp
bool System::Xml::XmlTextReader::get_ProhibitDtd()
```


### 戻り値

**true** は DTD 処理を禁止することを示します。**false** はそれ以外です。デフォルトは **false** です。

非推奨
:   このメソッドは廃止されています。代わりに [XmlTextReader::get_DtdProcessing](../get_dtdprocessing/) を使用してください。
