## XmlTextReader::get_HasValue() メソッド


現在のノードが [String::Empty](../../../system/string/empty/) 以外の [XmlTextReader::get_Value](../get_value/) を持つことができるかどうかを示す値を返します。

```cpp
bool System::Xml::XmlTextReader::get_HasValue() override
```


### 戻り値

**true** は、リーダーが現在位置しているノードが **Value** を持つことができる場合です; それ以外の場合は **false**。
