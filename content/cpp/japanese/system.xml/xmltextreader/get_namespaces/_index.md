## XmlTextReader::get_Namespaces() メソッド

名前空間サポートを行うかどうかを示す値を返します。

```cpp
bool System::Xml::XmlTextReader::get_Namespaces()
```

### 戻り値

**true** を指定すると名前空間サポートを行います。それ以外の場合は **false**。 デフォルトは **true**です。
