## XmlTextReader::get_IsEmptyElement() メソッド

現在のノードが空要素かどうかを示す値を返します（例: **<MyElement/>**）。

```cpp
bool System::Xml::XmlTextReader::get_IsEmptyElement() override
```

### 戻り値

**true** 現在のノードが要素 ([XmlTextReader::get_NodeType](../get_nodetype/) の値が [XmlNodeType::Element](../../xmlnodetype/) と等しい) で **/>** で終わる場合; それ以外は **false**。
