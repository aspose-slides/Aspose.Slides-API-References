```cpp
bool System::Xml::XmlTextReader::MoveToElement() override
```

### 戻り値

**true** は、リーダーが属性上に位置している場合 (リーダーは属性を所有する要素へ移動します)； **false** は、リーダーが属性上に位置していない場合 (リーダーの位置は変わりません)。
