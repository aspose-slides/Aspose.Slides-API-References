## XmlWriterSettings::get_WriteEndDocumentOnClose() メソッド

[XmlWriter](../../xmlwriter/) が、[XmlWriter::Close](../../xmlwriter/close/) メソッドが呼び出されたときに、未閉じの要素タグすべてに閉じタグを追加するかどうかを示す値を返します。

```cpp
bool System::Xml::XmlWriterSettings::get_WriteEndDocumentOnClose()
```

### 戻り値

**true** は、すべての未閉じ要素タグが閉じられる場合です。そうでなければ **false**。デフォルト値は **true** です。
