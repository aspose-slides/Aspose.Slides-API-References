## XmlWriterSettings::set_NamespaceHandling(System::Xml::NamespaceHandling) メソッド

XML コンテンツを書き込む際に、[XmlWriter](../../xmlwriter/) が重複する名前空間宣言を削除すべきかを示す値を設定します。既定の動作では、ライターは名前空間リゾルバーに存在するすべての名前空間宣言を出力します。

```cpp
void System::Xml::XmlWriterSettings::set_NamespaceHandling(System::Xml::NamespaceHandling value)
```

| --- | --- | --- |
| value | [System::Xml::NamespaceHandling](../../namespacehandling/) | 設定する値です。 |
