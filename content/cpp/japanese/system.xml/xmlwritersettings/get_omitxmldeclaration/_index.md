## XmlWriterSettings::get_OmitXmlDeclaration() メソッド


XML 宣言を省略するかどうかを示す値を返します。

```cpp
bool System::Xml::XmlWriterSettings::get_OmitXmlDeclaration()
```


### 戻り値

**true** は XML 宣言を省略することを示します。そうでない場合は **false**。デフォルトは **false** で、XML 宣言が書き込まれます。
