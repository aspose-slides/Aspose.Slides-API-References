## XmlWriterSettings::get_Indent() メソッド

要素をインデントするかどうかを示す値を返します。

```cpp
bool System::Xml::XmlWriterSettings::get_Indent()
```

### 戻り値

**true** は、個々の要素を新しい行に書き込みインデントすることを示します。そうでなければ **false**。デフォルトは **false** です。
