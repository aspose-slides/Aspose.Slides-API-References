## XmlWriterSettings::get_CloseOutput() メソッド


[XmlWriter](../../xmlwriter/) が [XmlWriter::Close](../../xmlwriter/close/) メソッドが呼び出されたときに、基になるストリームまたは TextWriter も閉じるかどうかを示す値を返します。

```cpp
bool System::Xml::XmlWriterSettings::get_CloseOutput()
```


### 戻り値

**true** は基になるストリームまたは TextWriter も閉じることを示し、そうでなければ **false**。デフォルトは **false** です。
