## XmlWriterSettings::get_NewLineChars() メソッド

行区切りに使用する文字列を返します。

```cpp
String System::Xml::XmlWriterSettings::get_NewLineChars()
```

### 戻り値

行区切りに使用する文字列です。任意の文字列値に設定できます。ただし、有効な XML を確保するために、スペース文字、タブ、復帰文字、改行文字などの有効な空白文字のみを指定すべきです。デフォルトは **\r\n**（復帰、改行）です。
