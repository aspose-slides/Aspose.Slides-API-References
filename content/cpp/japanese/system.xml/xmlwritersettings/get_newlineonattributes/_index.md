## XmlWriterSettings::get_NewLineOnAttributes() メソッド


属性を新しい行に書き込むかどうかを示す値を返します。

```cpp
bool System::Xml::XmlWriterSettings::get_NewLineOnAttributes()
```


### 戻り値

**true** は属性を個別の行に書き込むことを示し、**false** はそうでないことを示します。デフォルトは **false** です。
