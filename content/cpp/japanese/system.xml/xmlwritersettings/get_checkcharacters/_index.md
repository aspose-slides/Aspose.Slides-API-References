## XmlWriterSettings::get_CheckCharacters() メソッド


XML ライターがドキュメント内のすべての文字が W3C [XML 1.0 Recommendation](https://www.w3.org/TR/REC-xml/#charsets) の \"2.2 Characters\" セクションに準拠しているかどうかをチェックすべきかを示す値を返します。

```cpp
bool System::Xml::XmlWriterSettings::get_CheckCharacters()
```


### 戻り値

**true** to do character checking; otherwise, **false**. The default is **true**.
