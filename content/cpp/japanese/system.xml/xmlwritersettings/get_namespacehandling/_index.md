## XmlWriterSettings::get_NamespaceHandling() メソッド

XML コンテンツを書き込む際に、[XmlWriter](../../xmlwriter/) が重複した名前空間宣言を削除すべきかどうかを示す値を返します。既定の動作では、ライターはライターの名前空間リゾルバに存在するすべての名前空間宣言を出力します。

```cpp
System::Xml::NamespaceHandling System::Xml::XmlWriterSettings::get_NamespaceHandling()
```

### 戻り値

[XmlWriter](../../xmlwriter/) 内で重複した名前空間宣言を削除するかどうかを指定するために使用される NamespaceHandling 列挙体です。
