## XmlNamespaceManager::HasNamespace(String) メソッド

指定されたプレフィックスに対して、現在プッシュされたスコープに名前空間が定義されているかどうかを示す値を返します。

```cpp
virtual bool System::Xml::XmlNamespaceManager::HasNamespace(String prefix)
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| prefix | [String](../../../system/string/) | 検索したい名前空間のプレフィックスです。 |

### 戻り値

**true** が名前空間が定義されている場合; それ以外の場合は **false** 。
