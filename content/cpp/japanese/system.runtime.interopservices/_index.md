## クラス

| クラス | 説明 |
| --- | --- |
| [Details_ExternalException](./details_externalexception/) | すべての COM 相互運用例外および構造化例外処理 (SEH) 例外の基本例外型です。このクラスのインスタンスは決して手動で作成しないでください。代わりに ExternalException クラスを使用してください。ExternalException クラスのインスタンスを [System::SmartPtr](../system/smartptr/) にラップしないでください。 |
| [Marshal](./marshal/) | マーシャリング実装を提供します。C++ 側でマネージドコードがサポートされていないため、翻訳されたコードとの互換性のためだけに使用されます。これはインスタンスサービスを持たない静的型です。いかなる方法でもこの型のインスタンスを作成してはいけません。 |
| [MemoryMarshal](./memorymarshal/) | メモリ マーシャリング実装を提供します。C++ 側でマネージドコードがサポートされていないため、翻訳されたコードとの互換性のためだけに使用されます。これはインスタンスサービスを持たない静的型です。いかなる方法でもこの型のインスタンスを作成してはいけません。 |
