## XmlSortOrder 列挙型

ソート順を指定します。

```cpp
enum class XmlSortOrder
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Ascending | 1 | ノードは昇順にソートされます。例えば、数値 1、2、3、4 を昇順にソートすると 1,2,3,4 の順になります。 |
| Descending | 2 | ノードは降順にソートされます。例えば、数値 1、2、3、4 を降順にソートすると 4,3,2,1 の順になります。 |
