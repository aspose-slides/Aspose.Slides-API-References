## XmlCaseOrder 列挙型

大文字と小文字の文字の並び順を指定します。

```cpp
enum class XmlCaseOrder
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| None | 0 | 大文字と小文字を区別しません。 |
| UpperFirst | 1 | 大文字が小文字より先に並びます。 |
| LowerFirst | 2 | 小文字が大文字より先に並びます。 |
