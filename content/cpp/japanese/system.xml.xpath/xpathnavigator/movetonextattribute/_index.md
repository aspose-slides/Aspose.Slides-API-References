## XPathNavigator::MoveToNextAttribute() メソッド

派生クラスでオーバーライドされた場合、[XPathNavigator](../) を次の属性へ移動します。

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToNextAttribute()=0
```

### 戻り値

**true** は [XPathNavigator](../) が次の属性への移動に成功した場合です。**false** は属性がもうない場合です。**false** の場合、[XPathNavigator](../) の位置は変わりません。
