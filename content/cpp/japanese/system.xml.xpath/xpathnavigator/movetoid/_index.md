## XPathNavigator::MoveToId(String) メソッド

派生クラスでオーバーライドされた場合、指定された [String](../../../system/string/) と一致する値を持つ **ID** 型属性を持つノードへ移動します。

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToId(String id)=0
```

### 引数

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| id | [String](../../../system/string/) | 移動しようとしているノードの **ID** 値を表す [String](../../../system/string/)。 |

### 戻り値

**true** は [XPathNavigator](../) の移動が成功した場合; それ以外の場合は **false**。**false** の場合、ナビゲーターの位置は変更されません。
