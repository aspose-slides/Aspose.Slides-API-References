## XPathNodeIterator::MoveNext() method


派生クラスでオーバーライドされた場合、[XPathNodeIterator::get_Current](../get_current/) メソッドが返す [XPathNavigator](../../xpathnavigator/) オブジェクトを選択されたノードセットの次のノードに移動します。

```cpp
virtual bool System::Xml::XPath::XPathNodeIterator::MoveNext()=0
```


### 戻り値

**true** は [XPathNavigator](../../xpathnavigator/) オブジェクトが次のノードに移動した場合、**false** は選択されたノードがこれ以上ない場合です。
