## SoapBindingStyle 列挙型


この列挙型が適用される XML [Web](../../system.web/) サービスのクラス階層レベルにおけるアクションタイプを指定します。

```cpp
enum class SoapBindingStyle
```

### 列挙値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Default | 0 | 既定のアクションタイプです。 |
| Document | 1 | メッセージはドキュメント指向です。 |
| Rpc | 2 | メッセージには手続きを呼び出すためのパラメータ、またはその手続きの戻り値が含まれます。 |
