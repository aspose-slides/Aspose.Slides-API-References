## BasicSTDIOStreamWrapper::ReadByte() メソッド


ラッピングモードがバイナリの場合、最後にデコードされた文字のストレージから1バイトを読み取ります。それ以外の場合は、ストリームから1文字を読み取り、**uint8_t** 型に変換します。

```cpp
virtual int System::IO::BasicSTDIOStreamWrapper<T, typename>::ReadByte() override
```


### 戻り値

読み取り結果に相当する32ビット整数値
