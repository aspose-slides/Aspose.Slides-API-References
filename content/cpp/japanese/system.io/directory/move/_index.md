## Directory::Move(const String\&, const String\&) メソッド

指定されたエンティティを新しい場所に移動します。移動するエンティティがディレクトリである場合、そのディレクトリは内容すべてとともに移動されます。

```cpp
static void System::IO::Directory::Move(const String &sourceDirName, const String &destDirName)
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| sourceDirName | const [String](../../../system/string/)\& | 移動対象のディレクトリまたはファイル |
| destDirName | const [String](../../../system/string/)\& | **sourceDirName** の新しい場所 |
