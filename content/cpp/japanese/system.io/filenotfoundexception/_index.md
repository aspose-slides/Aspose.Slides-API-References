## FileNotFoundException 型定義

ディスク上に存在しないファイルにアクセスしようとしたときにスローされる例外です。FileNotFoundException クラスのインスタンスを [System::SmartPtr](../../system/smartptr/) にラップしないでください。

```cpp
using System::IO::FileNotFoundException = typedef System::ExceptionWrapper<Details_FileNotFoundException>
```
