## FileAccess 列挙型

ファイルを開くときのアクセス種別を指定します。

```cpp
enum class FileAccess
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Read | 1 | 読み取り専用アクセス。 |
| Write | 2 | 書き込み専用アクセス。 |
| ReadWrite | n/a | 読み取りおよび書き込みアクセス。 |
