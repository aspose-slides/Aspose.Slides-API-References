## FileSystemInfo::get_Exists() メソッド


現在のオブジェクトが表すパスによって参照されるエンティティが存在するかどうかを判断します。

```cpp
virtual bool System::IO::FileSystemInfo::get_Exists()=0
```


### 戻り値

現在のオブジェクトが表すパスによって参照されるエンティティが存在する場合は True、そうでない場合は false
