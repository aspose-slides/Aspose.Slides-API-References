## SearchOption 列挙体

検索は現在のディレクトリのみ、または現在のディレクトリとそのすべてのサブディレクトリで実行されることを指定します。

```cpp
enum class SearchOption
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| AllDirectories | 0 | 現在のディレクトリとすべてのサブディレクトリで検索します。 |
| TopDirectoryOnly | 1 | 現在のディレクトリのみで検索します。 |
