## FileAttributes 列挙体

ディレクトリまたはファイルの属性を表します。

```cpp
enum class FileAttributes
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Archive | 32 | ファイルシステムエンティティは削除またはバックアップの対象です。 |
| Compressed | 2048 | ファイルシステムエンティティは圧縮されています。 |
| Device | 64 | 使用されていません。 |
| Directory | 16 | ファイルシステムエンティティはディレクトリです。 |
| Encrypted | 16384 | ファイルシステムエンティティは暗号化されています。 |
| Hidden | 2 | ファイルシステムエンティティは非表示です。 |
| IntegrityStream | 32768 | ファイルシステムエンティティはデータ完全性サポートを含んでいます。 |
| Normal | 128 | ファイルシステムエンティティは特別な属性を持たないファイルです。 |
| NotContentIndexed | 8192 | ファイルシステムエンティティはコンテンツインデックスサービスによってインデックス付けされません。 |
| NoScrubData | 131072 | ファイルシステムエンティティはデータ完全性スキャンに含まれません。 |
| Offline | 4096 | ファイルシステムエンティティはオフラインで、データはすぐに利用できません。 |
| ReadOnly | 1 | ファイルシステムエンティティは読み取り専用です。 |
| ReparsePoint | 1024 | ファイルシステムエンティティは再解析ポイントを含むファイルです。 |
| SparseFile | 512 | ファイルシステムエンティティはスパースファイルです。 |
| System | 4 | ファイルシステムエンティティはシステムファイルです。 |
| Temporary | 256 | ファイルシステムエンティティは一時ファイルです。 |
| Invalid | 0 | 無効な値です。 |
