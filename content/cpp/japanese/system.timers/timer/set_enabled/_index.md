## Timer::set_Enabled(bool) メソッド

タイマーを開始または停止します。タイマーがすでに実行中の場合、開始しても時間のカウントは再開されません。

```cpp
void System::Timers::Timer::set_Enabled(bool value)
```

### 引数

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| value | **bool** | タイマーを開始する場合は true、停止する場合は false。 |
