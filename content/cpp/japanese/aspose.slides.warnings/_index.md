## クラス

| クラス | 説明 |
| --- | --- |
| [IKnownIssueWarningInfo](./iknownissuewarninginfo/) | 近い将来に修正されない既知の問題に関する警告を表します。 |
| [INotImplementedWarningInfo](./inotimplementedwarninginfo/) | 近い将来に実装されない既知の未実装機能に関する警告を表します。 |
| [IObsoletePresLockingBehaviorWarningInfo](./iobsoletepreslockingbehaviorwarninginfo/) | この警告は、廃止されたプレゼンテーションロック動作が使用されていることを示します。 |
| [IPresentationSignedWarningInfo](./ipresentationsignedwarninginfo/) | この警告は、読み込まれたプレゼンテーションに署名があり、この署名が処理中に削除されることを示します。 |
| [IWarningCallback](./iwarningcallback/) | 警告を受け取るクラス用のインターフェイスです。 |
| [IWarningInfo](./iwarninginfo/) | すべての警告の基本インターフェイスを表します。 |
## 列挙体

| 列挙体 | 説明 |
| --- | --- |
| [ReturnAction](./returnaction/) | 警告コールバックの決定オプションを表します。 |
| [WarningType](./warningtype/) | 警告の種類を表します。 |
