## TraceLevel 列挙体

[System.Diagnostics.Debug](../debug/)、[System.Diagnostics.Trace](../trace/) と System.Diagnostics.TraceSwitch クラスの出力メッセージを指定します。

```cpp
enum class TraceLevel
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Off | 0 | トレースおよびデバッグメッセージを出力しません。 |
| Error | 1 | エラーハンドリングメッセージを出力します。 |
| Warning | 2 | 警告とエラーハンドリングメッセージを出力します。 |
| Info | 3 | 情報メッセージ、警告、およびエラーハンドリングメッセージを出力します。 |
| Verbose | 4 | すべてのデバッグおよびトレースメッセージを出力します。 |
