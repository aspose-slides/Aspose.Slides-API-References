## デバッガ構造体


[Debugger](./) インターフェイス。これはインスタンスサービスを持たない静的型です。いかなる方法でもインスタンスを作成してはなりません。

```cpp
class Debugger
```

## メソッド

| メソッド | 説明 |
| --- | --- |
| static void [Break](./break/)() | デバッガのブレークを開始します（アタッチされている場合）。 |
| static **bool** [get_IsAttached](./get_isattached/)() | デバッガが現在のアプリケーションインスタンスにアタッチされているかどうかを確認します。 |
