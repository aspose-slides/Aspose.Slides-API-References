## DashCap 列挙体

ダッシュ線の両端に使用されるキャップのタイプを指定します。

```cpp
enum class DashCap
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Flat | 0 | ダッシュの両端を四角く整えるスクエアキャップです。 |
| Round | 2 | ダッシュの両端を丸く整える円形キャップです。 |
| Triangle | 3 | ダッシュの両端を三角形に整えるトライアングルキャップです。 |
