## InterpolationMode 列挙型

画像が回転またはスケーリングされる際に使用するアルゴリズムを指定します。

```cpp
enum class InterpolationMode
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Invalid | n/a | [QualityMode::Invalid](../qualitymode/) と同等です。 |
| Default | n/a | デフォルトモードです。 |
| Low | n/a | 低品質です。 |
| High | n/a | 高品質です。 |
| Bilinear | n/a | バイリニア補間です。 |
| Bicubic | n/a | バイキュービック補間です。 |
| NearestNeighbor | n/a | 最近傍補間です。 |
| HighQualityBilinear | n/a | 高品質バイリニア補間です。 |
| HighQualityBicubic | n/a | 高品質バイキュービック補間です。 |
