## LineCap 列挙型


[Pen](../../system.drawing/pen/) オブジェクトが線の終点に使用できる、利用可能なキャップスタイルを示します。

```cpp
enum class LineCap
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Flat | 0 | フラット線キャップ。 |
| Square | 1 | 四角形線キャップ。 |
| Round | 2 | 丸い線キャップ。 |
| Triangle | 3 | 三角形線キャップ。 |
| NoAnchor | 16 | アンカーなし。 |
| SquareAnchor | 17 | 四角形アンカー線キャップ。 |
| RoundAnchor | 18 | 丸いアンカー線キャップ。 |
| DiamondAnchor | 19 | ダイヤモンドアンカー線キャップ。 |
| ArrowAnchor | 20 | 矢印アンカー線キャップ。 |
| AnchorMask | 240 | ラインキャップがアンカーキャップかどうかを確認するために使用されるマスク。 |
| Custom | 255 | カスタムキャップ。 |
