## LineJoin enum

連続する直線または曲線がどのように接続されるかを指定します。

```cpp
enum class LineJoin
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Miter | 0 | Mitered join は、miter の長さが miter limit を超えるかどうかに応じて、鋭いまたは切り取られた角を生成します。 |
| Bevel | 1 | Bevel join は、対角的な角を生成します。 |
| Round | 2 | Round join は、線間に滑らかな円弧を生成します。 |
| MiterClipped | 3 | Mitered join は、miter の長さが miter limit を超えるかどうかに応じて、鋭いまたはベベル状の角を生成します。 |
