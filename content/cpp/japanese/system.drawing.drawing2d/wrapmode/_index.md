## WrapMode 列挙体


テクスチャまたはグラデーションが、塗りつぶし領域より小さい場合のタイル方法を指定します。

```cpp
enum class WrapMode
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Tile | 0 | グラデーションまたはテクスチャをタイル状に配置します。 |
| TileFlipX | 1 | テクスチャまたはグラデーションを水平方向に反転させ、次にテクスチャまたはグラデーションをタイル状に配置します。 |
| TileFlipY | 2 | テクスチャまたはグラデーションを垂直方向に反転させ、次にテクスチャまたはグラデーションをタイル状に配置します。 |
| TileFlipXY | 3 | テクスチャまたはグラデーションを水平方向および垂直方向に反転させ、次にテクスチャまたはグラデーションをタイル状に配置します。 |
| Clamp | 4 | テクスチャまたはグラデーションをオブジェクトの境界にクランプします。 |
