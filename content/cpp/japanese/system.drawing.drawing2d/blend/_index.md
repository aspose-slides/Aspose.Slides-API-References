## Blend クラス

[LinearGradientBrush](../lineargradientbrush/) オブジェクトのブレンド パターンを表します。このクラスのオブジェクトは [System::MakeObject()](../../system/makeobject/) 関数を使用してのみ割り当てるべきです。スタック上や operator new を使用してこの型のインスタンスを作成しないでください。ランタイム エラーやアサーション フォルトが発生する可能性があります。このクラスは常に [System::SmartPtr](../../system/smartptr/) ポインタでラップし、そのポインタを関数への引数として渡すようにしてください。

```cpp
class Blend : public System::Object
```
