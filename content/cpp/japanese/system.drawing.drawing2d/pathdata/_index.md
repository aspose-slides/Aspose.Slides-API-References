## PathData クラス

このクラスが表すパスを示すグラフィカルデータを格納します。オブジェクトは [System::MakeObject()](../../system/makeobject/) 関数を使用してのみ割り当てるべきです。スタック上または operator new を用いてこの型のインスタンスを作成しないでください。そうすると実行時エラーやアサーション違反が発生します。常にこのクラスを [System::SmartPtr](../../system/smartptr/) ポインタで包み、関数への引数としてそのポインタを使用してください。

```cpp
class PathData : public System::Object
```
