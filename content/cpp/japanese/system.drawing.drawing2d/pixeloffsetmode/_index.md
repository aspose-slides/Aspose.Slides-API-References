## PixelOffsetMode 列挙型

レンダリング時にピクセルがどのようにオフセットされるかを指定します。

```cpp
enum class PixelOffsetMode
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Invalid | n/a | 無効な値です。 |
| Default | n/a | デフォルトのモードです。 |
| HighSpeed | n/a | 低品質（高パフォーマンス）モードです。 |
| HighQuality | n/a | 高品質（低パフォーマンス）モードです。 |
| None | n/a | ピクセルのオフセットがありません。 |
| Half | n/a | 高性能なアンチエイリアシングのために、ピクセルは水平方向と垂直方向の両方で -0.5 ユニットだけオフセットされます。 |
