## MathPhantom::set_Transp(bool) 方法


設定一個值，以指示此幻影在基於類別的間距規則中是否為透明。

```cpp
void Aspose::Slides::MathText::MathPhantom::set_Transp(bool value) override
```

## 備註


當 **true** 時，幻影內的運算子與符號仍會影響幻影周圍的數學間距（如同可見）。當 **false** 時，基於類別的間距將被忽略。對應於 OMML 屬性 **m:transp**。
