## 類別

| 類別 | 說明 |
| --- | --- |
| [Collect](./collect/) | 表示一組旨在從 [Presentation](../aspose.slides/presentation/) 收集不同類型模型物件的方法。 |
| [Compress](./compress/) | 表示一組旨在壓縮 [Presentation](../aspose.slides/presentation/) 的方法。 |
| [Convert](./convert/) | 表示一組旨在轉換 [Presentation](../aspose.slides/presentation/) 的方法。 |
| [ForEach](./foreach/) | 表示一組旨在遍歷不同 [Presentation](../aspose.slides/presentation/) 模型物件的方法。這些方法若您需要遍歷並更改某些 [Presentation](../aspose.slides/presentation/)' 元素的格式或內容，會很有用，例如變更每個部分的格式。 |
| [Merger](./merger/) | 表示一組用於合併相同格式的 PowerPoint 簡報為單一檔案的方法。 |
