## IEnumerator 類別

列舉器的介面，可用於遍歷某些元素。此類別的物件應僅使用 [System::MakeObject()](../../system/makeobject/) 函式分配。切勿在堆疊上或使用 operator new 建立此類型的實例，因為這會導致執行時錯誤和/或斷言失敗。始終將此類別包裝成 [System::SmartPtr](../../system/smartptr/) 指標，並使用該指標作為參數傳遞給函式。

```cpp
class IEnumerator : public virtual System::IDisposable,
                    public virtual System::Object
```
