## IBlobManagementOptions::set_IsTemporaryFilesAllowed(bool) 方法


此屬性定義在處理 BLOB 時是否允許建立暫存檔，這可大幅降低記憶體使用量，但需要具備建立檔案的權限。

```cpp
virtual void Aspose::Slides::IBlobManagementOptions::set_IsTemporaryFilesAllowed(bool value)=0
```

## 備註


所有檔案會在簡報工作完成後被刪除。
