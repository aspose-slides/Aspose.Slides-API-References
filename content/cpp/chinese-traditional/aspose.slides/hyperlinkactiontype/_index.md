## HyperlinkActionType 列舉


表示一種類型的超連結動作。

```cpp
enum class HyperlinkActionType
```

### 值

| Name | Value | Description |
| --- | --- | --- |
| Unknown | -1 | 未辨識的動作類型。 |
| NoAction | 0 | 無動作。 |
| Hyperlink | 1 | 一般超連結。 |
| JumpFirstSlide | 2 | 跳至簡報的第一張投影片。 |
| JumpPreviousSlide | 3 | 跳至上一張投影片。 |
| JumpNextSlide | 4 | 跳至下一張投影片。 |
| JumpLastSlide | 5 | 跳至簡報的最後一張投影片。 |
| JumpEndShow | 6 | 跳至投影片放映的結束。 |
| JumpLastViewedSlide | 7 | 跳至最後檢視的投影片。 |
| JumpSpecificSlide | 8 | 跳至特定投影片，由 [IHyperlink::get_TargetSlide](../ihyperlink/get_targetslide/) 值指定。 |
| StartCustomSlideShow | 9 | 開始自訂投影片放映。 |
| OpenFile | 10 | 開啟參考的檔案。 |
| OpenPresentation | 11 | 開啟參考的簡報。 |
| StartStopMedia | 12 | 開始/停止播放媒體檔案。 |
| StartMacro | 13 | 開始執行巨集腳本。 |
| StartProgram | 14 | 啟動程式。 |
