## PathCommandType 列舉


表示圖形路徑指令

```cpp
enum class PathCommandType : uint8_t
```

### 值

| 名稱 | 值 | 描述 |
| --- | --- | --- |
| Close | 0 | 關閉幾何路徑 |
| MoveTo | 1 | 設定幾何路徑的下一個點位置 |
| LineTo | 2 | 將直線附加到幾何路徑 |
| ArcTo | 3 | 將指定的弧線附加到幾何路徑。 |
| QuadBezierTo | 4 | 將二次貝塞爾曲線附加到幾何路徑 |
| CubicBezierTo | 5 | 將三次貝塞爾曲線附加到幾何路徑 |
