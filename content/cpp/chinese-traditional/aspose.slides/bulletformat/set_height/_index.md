## BulletFormat::set_Height(float) method


設定段落的項目符號高度，且不繼承。值 std::numeric_limits<float>::quiet_NaN() 表示項目符號從段落中的第一個部分繼承高度。寫入 **float**。

```cpp
void Aspose::Slides::BulletFormat::set_Height(float value) override
```

## 備註


負的高度值表示高度以點為單位，正的值表示高度為周圍文字的百分比。
