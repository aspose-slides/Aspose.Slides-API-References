## Shape::set_Rotation(float) 方法


設定指定形狀繞 z 軸旋轉的角度（度數）。正值表示順時針旋轉；負值表示逆時針旋轉。寫入 **float**。

```cpp
void Aspose::Slides::Shape::set_Rotation(float value) override
```

## 備註


返回值始終為已定義（不是 std::numeric_limits<float>::quiet_NaN()）。指定的值必須為已定義（不是 std::numeric_limits<float>::quiet_NaN()）。您可以為 RawFrame 實例屬性設定未定義的值。
