## PathFillModeType 列舉

指定路徑應填充的方式

```cpp
enum class PathFillModeType : uint8_t
```

### 值

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| None | 0 | 無路徑填充 此說明對應的路徑不應有填充。 |
| Normal | 1 | 正常路徑填充 此說明對應的路徑應將正常陰影顏色套用於其填充。 |
| Lighten | 2 | 淡化路徑填充 此說明對應的路徑應將淡淡陰影顏色套用於其填充。 |
| LightenLess | 3 | 較淡化路徑填充 此說明對應的路徑應將稍微較淡的陰影顏色套用於其填充。 |
| Darken | 4 | 加深路徑填充 此說明對應的路徑應將較深陰影顏色套用於其填充。 |
| DarkenLess | 5 | 較加深路徑填充 此說明對應的路徑應將稍微較深的陰影顏色套用於其填充。 |
