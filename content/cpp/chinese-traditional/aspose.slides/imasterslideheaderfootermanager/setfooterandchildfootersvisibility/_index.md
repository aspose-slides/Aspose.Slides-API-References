## IMasterSlideHeaderFooterManager::SetFooterAndChildFootersVisibility(bool) 方法

變更母片投影片的頁腳佔位符以及所有子頁腳佔位符的可見性。子佔位符指的是位於依賴的版面配置投影片和依賴投影片上的佔位符。依賴的版面配置投影片和投影片使用並依賴於母片投影片。

```cpp
virtual void Aspose::Slides::IMasterSlideHeaderFooterManager::SetFooterAndChildFootersVisibility(bool isVisible)=0
```

### 參數

| Parameter | Type | Description |
| --- | --- | --- |
| isVisible | **bool** | true - 使頁腳佔位符可見，否則 - 隱藏它們。 |
