## ISlideShowTransition::set_SoundName(System::String) 方法


指定此過渡效果聲音的人類可讀名稱。必須指派 [ISlideShowTransition::set_Sound](../set_sound/) 以取得或設定聲音名稱。寫入 [System::String](../../../system/string/)。

```cpp
virtual void Aspose::Slides::ISlideShowTransition::set_SoundName(System::String value)=0
```

## 備註


此名稱會在 PowerPoint 使用者介面中手動設定過渡聲音時顯示。
