## FillType 列舉

指定各種視覺物件的內部填充類型。

```cpp
enum class FillType : int8_t
```

### 值

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| NotDefined | -1 | 填充類型未定義。 |
| NoFill | 0 | 未套用填充。 |
| Solid | 1 | 以純色填充。 |
| Gradient | 2 | 填充為漸層。 |
| Pattern | 3 | 使用重複圖案填充物件。 |
| Picture | 4 | 使用單一圖片填充物件。 |
| Group | 5 | 視覺物件從群組繼承填充屬性。 |
