## ImageFormat enum

表示影像的檔案格式。

```cpp
enum class ImageFormat
```

### 值

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| MemoryBmp | 0 | 表示記憶體中位圖的格式。 |
| Bmp | 1 | 表示位圖 (BMP) 影像格式。 |
| Emf | 2 | 表示增強型圖形檔 (EMF) 影像格式。 |
| Wmf | 3 | 表示 Windows 圖形檔 (WMF) 影像格式。 |
| Gif | 4 | 表示圖形交換格式 (GIF) 影像格式。 |
| Jpeg | 5 | 表示 Joint Photographic Experts Group (JPEG) 影像格式。 |
| Png | 6 | 表示 W3C 可攜式網路圖形 (PNG) 影像格式。 |
| Tiff | 7 | 表示標記式影像檔案格式 (TIFF) 影像格式。 |
| Exif | 8 | 表示可交換影像檔 (Exif) 格式。 |
| Icon | 9 | 表示 Windows 圖示影像格式。 |
