## IShape::set_Rotation(float) 方法


設定指定形狀繞 z 軸旋轉的角度（以度為單位）。正值表示順時針旋轉；負值表示逆時針旋轉。寫入 **float**。

```cpp
virtual void Aspose::Slides::IShape::set_Rotation(float value)=0
```

## 備註


返回值始終已定義（不是 std::numeric_limits<float>::quiet_NaN()）。指定的值必須已定義（不是 std::numeric_limits<float>::quiet_NaN()）。您可以為 RawFrame 實例屬性設定未定義的值。
