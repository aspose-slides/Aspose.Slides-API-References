## LineSketchType 列舉

表示已指派給形狀的草圖類型或效果。

```cpp
enum class LineSketchType
```

### Values

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| NotDefined | -1 | 指定形狀的 Sketch 效果未定義。 |
| None | 0 | 指定形狀沒有 Sketch 效果。這等同於此屬性為空。 |
| Curved | 1 | 指定形狀具有 Curved 效果，該效果會將形狀的每條邊緣變為一條大的柔和曲線。 |
| Freehand | 2 | 指定形狀具有 Freehand 效果，最接近於手繪的不完美線條。 |
| Scribble | 3 | 指定形狀具有 Scribble 效果，呈現誇張的振盪，如同故意畫得凌亂。 |
