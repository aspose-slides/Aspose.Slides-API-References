## BlobManagementOptions::set_IsTemporaryFilesAllowed(bool) 方法

此屬性定義在處理 BLOB 時是否允許建立暫存檔案，這可大幅降低記憶體使用量，但需要具備建立檔案的權限。

```cpp
void Aspose::Slides::BlobManagementOptions::set_IsTemporaryFilesAllowed(bool value) override
```

## 備註

所有檔案將在簡報工作完成後被刪除。
