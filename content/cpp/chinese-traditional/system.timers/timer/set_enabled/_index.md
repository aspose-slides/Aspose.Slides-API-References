## Timer::set_Enabled(bool) 方法

啟動或停止計時器。若計時器已在執行，啟動計時器不會重新開始時間計算。

```cpp
void System::Timers::Timer::set_Enabled(bool value)
```

### 參數

| 參數 | 類型 | 說明 |
| --- | --- | --- |
| value | **bool** | true 以啟動計時器，false 以停止。 |
