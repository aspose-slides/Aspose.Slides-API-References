## Timer::get_AutoReset() const method


檢查計時器是否處於自動重設模式。

```cpp
bool System::Timers::Timer::get_AutoReset() const
```


### 返回值

若計時器以迴圈方式觸發則傳回 true，若在首次觸發後停止則傳回 false。
