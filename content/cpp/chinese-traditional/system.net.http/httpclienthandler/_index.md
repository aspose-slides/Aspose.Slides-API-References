## HttpClientHandler 類別


Represents the default message handler used by the [HttpClient](../httpclient/) 類別. Objects of this 類別 should only be allocated using [System::MakeObject()](../../system/makeobject/) 函式. Never create instance of this type on stack or using operator new, as it will result in runtime errors and/or assertion faults. Always wrap this 類別 into [System::SmartPtr](../../system/smartptr/) pointer and use this pointer to pass it to functions as argument.

```cpp
class HttpClientHandler : public System::Net::Http::HttpMessageHandler
```
