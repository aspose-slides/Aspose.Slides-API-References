## X500DistinguishedNameFlags enum

X509 憑證辨別名稱格式規則。

```cpp
enum class X500DistinguishedNameFlags
```

### 值

| 名稱 | 值 | 描述 |
| --- | --- | --- |
| None | 0 | 沒有特殊特性。 |
| Reversed | 1 | 名稱已保留。 |
| UseSemicolons | 16 | 使用分號。 |
| DoNotUsePlusSign | 32 | 名稱不使用加號。 |
| DoNotUseQuotes | 64 | 禁用名稱中的引號。 |
| UseCommas | 128 | 啟用使用逗號。 |
| UseNewLines | 256 | 啟用使用換行。 |
| UseUTF8Encoding | 4096 | 從使用 Unicode 轉換為使用 UTF-8 編碼。 |
| UseT61Encoding | 8192 | 轉換為 T61 編碼。 |
| ForceUTF8Encoding | 16384 | 在編碼特定 X500 鍵時強制使用 UTF-8。 |
