## CacheControlHeaderValue::set_SharedMaxAge(Nullable\<TimeSpan\>) 方法

設定共享緩存的最大存活時間（以秒為單位），此值會覆寫 'Cache-Control' 標頭中的 'max-age' 指令或共享緩存的 'Expires' 標頭。

```cpp
void System::Net::Http::Headers::CacheControlHeaderValue::set_SharedMaxAge(Nullable<TimeSpan> value)
```
