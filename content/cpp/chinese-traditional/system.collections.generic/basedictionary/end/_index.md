## BaseDictionary::end() const 方法

傳回一個指向 KVPair-wrapper 的迭代器，該迭代器對應容器中最後一個元素之後的鍵值元素。以 C# 風格實作──迭代器應傳回具備 get_Key() 與 get_Value() 介面的 KVPair-object。此元素充當占位元；嘗試存取它會導致未定義的行為。

```cpp
const_iterator System::Collections::Generic::BaseDictionary<Map>::end() const noexcept
```

### 返回值

指向集合中結束元素之後的理論元素的迭代器。
