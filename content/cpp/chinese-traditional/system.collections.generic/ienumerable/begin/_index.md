## IEnumerable::begin() 方法

取得指向集合中第一個元素（如果有）的迭代器。此迭代器無法用於更改所引用的物件，因為 [GetEnumerator()](../getenumerator/) 會回傳 T 的複製物件。

```cpp
iterator System::Collections::Generic::IEnumerable<T>::begin()
```

### 回傳值

指向集合中第一個元素（如果有）的迭代器

## IEnumerable::begin() const 方法

取得指向集合中 const 限定實例之第一個元素（如果有）的迭代器。

```cpp
const_iterator System::Collections::Generic::IEnumerable<T>::begin() const
```

### 回傳值

指向 const 限定實例之第一個元素（如果有）的迭代器
