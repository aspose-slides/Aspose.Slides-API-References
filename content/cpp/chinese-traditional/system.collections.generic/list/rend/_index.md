## List::rend() 方法

取得一個指向集合開始之前（不存在的）元素的反向迭代器。

```cpp
reverse_iterator System::Collections::Generic::List<T>::rend() noexcept
```

### 返回值

一個指向列表中第一個元素之前的理論元素（反向的最後一個）的反向迭代器。

## List::rend() const 方法

取得一個指向 const 限定集合開始之前（不存在的）元素的反向迭代器。

```cpp
const_reverse_iterator System::Collections::Generic::List<T>::rend() const noexcept
```

### 返回值

一個指向 const 限定列表中第一個元素之前的理論元素（反向的最後一個）的反向迭代器。
