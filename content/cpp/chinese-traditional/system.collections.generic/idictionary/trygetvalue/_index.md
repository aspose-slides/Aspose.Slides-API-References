## IDictionary::TryGetValue(const TKey\&, TValue\&) const 方法


尋找值並在找到時檢索它。

```cpp
virtual bool System::Collections::Generic::IDictionary<TKey, TValue>::TryGetValue(const TKey &key, TValue &value) const =0
```


### 參數

| 參數 | 類型 | 描述 |
| --- | --- | --- |
| key | const TKey\& | 要查找的鍵。 |
| value | TValue\& | 用於存放檢索到的值的參考。 |

### 返回值

若找到且檢索到值則返回 true，否則返回 false。
