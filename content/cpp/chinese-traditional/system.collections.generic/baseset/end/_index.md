## BaseSet::end() const 方法

取得 const 限定集合結束之後的不存在元素的 iterator。

```cpp
const_iterator System::Collections::Generic::BaseSet<T, SET_T>::end() const noexcept
```

### 返回值

返回指向 const 限定之 hash set 中，位於結束元素之後的理論元素的 iterator。
