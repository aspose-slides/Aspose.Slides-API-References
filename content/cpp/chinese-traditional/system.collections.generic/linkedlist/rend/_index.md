## LinkedList::rend() 方法

取得指向集合起始之前之不存在元素的反向迭代器。

```cpp
reverse_iterator System::Collections::Generic::LinkedList<T>::rend() noexcept
```

### 返回值

指向鏈結串列中第一個元素之前之理論元素的反向迭代器（反向中的最後一個）。

## LinkedList::rend() const 方法

取得指向 const 限定集合起始之前之不存在元素的反向迭代器。

```cpp
const_reverse_iterator System::Collections::Generic::LinkedList<T>::rend() const noexcept
```

### 返回值

指向 const 限定鏈結串列中第一個元素之前之理論元素的反向迭代器（反向中的最後一個）。
