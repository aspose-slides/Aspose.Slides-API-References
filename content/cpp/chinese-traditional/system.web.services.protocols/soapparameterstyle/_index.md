## SoapParameterStyle 列舉

列舉 SOAP 訊息中的參數格式。

```cpp
enum class SoapParameterStyle
```

### 值

| 名稱 | 值 | 描述 |
| --- | --- | --- |
| Default | 0 | 如果未將 '[SoapDocumentServiceAttribute](../soapdocumentserviceattribute/)' 套用至類別，則預設值為 'Wrapped'。 |
| Bare | 1 | 參數被放置在緊接 'Body' 元素的 XML 元素中。 |
| Wrapped | 2 | 參數被封裝在緊接 'Body' 元素的單一 XML 元素中。 |
