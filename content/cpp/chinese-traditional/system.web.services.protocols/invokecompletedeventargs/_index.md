## InvokeCompletedEventArgs 類別


此類別的實例會作為參數傳遞給 InvokeCompletedEventHandler 委託。此類別的物件只能使用 [System::MakeObject()](../../system/makeobject/) 函式來配置。切勿在堆疊上或使用 new 運算子建立此類別的實例，因為會導致執行時錯誤和/或斷言失敗。請始終將此類別包裝成 [System::SmartPtr](../../system/smartptr/) 指標，並使用該指標將其作為參數傳遞給函式。

```cpp
class InvokeCompletedEventArgs : public System::ComponentModel::AsyncCompletedEventArgs
```
