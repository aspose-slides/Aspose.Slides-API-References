## SqlConnectionStringBuilder 類別

SQL-based 連線建構器。此類別的物件只能使用 [System::MakeObject()](../../system/makeobject/) 函式分配。切勿在堆疊上或使用 operator new 建立此類型的實例，因為這會導致執行時錯誤和/或斷言失敗。始終將此類別包裝成 [System::SmartPtr](../../system/smartptr/) 指標，並使用該指標將其作為參數傳遞給函式。

```cpp
class SqlConnectionStringBuilder : public System::Data::Common::DbConnectionStringBuilder
```
