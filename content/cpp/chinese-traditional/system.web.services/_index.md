## 類別

| 類別 | 說明 |
| --- | --- |
| [Soap](./soap/) | 包含 SOAP 的字串常數。 |
| [Soap12](./soap12/) | 包含 SOAP 版本 1.2 的字串常數。 |
| [WebServiceAttribute](./webserviceattribute/) | 為 XML [Web](../system.web/) 服務新增額外資訊。此類別的物件應僅透過 [System::MakeObject()](../system/makeobject/) 函式配置。切勿在堆疊上或使用 operator new 建立此類型的實例，因為會導致執行時錯誤或斷言失敗。請始終將此類別包裝成 [System::SmartPtr](../system/smartptr/) 指標，並使用該指標作為參數傳遞給函式。 |
| [WebServiceBindingAttribute](./webservicebindingattribute/) | 用於宣告一個綁定，該綁定定義 XML [Web](../system.web/) 服務的一個或多個方法。此類別的物件應僅透過 [System::MakeObject()](../system/makeobject/) 函式配置。切勿在堆疊上或使用 operator new 建立此類型的實例，因為會導致執行時錯誤或斷言失敗。請始終將此類別包裝成 [System::SmartPtr](../system/smartptr/) 指標，並使用該指標作為參數傳遞給函式。 |
