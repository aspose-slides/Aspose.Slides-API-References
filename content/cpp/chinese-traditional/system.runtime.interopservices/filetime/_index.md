## FILETIME 結構

保存檔案時間組件。此類型應在堆疊上分配，並以值或參考方式傳遞給函式。切勿使用 [System::SmartPtr](../../system/smartptr/) 類別來管理此類型的物件。

```cpp
class FILETIME
```
