## TrendlineType 列舉

表示趨勢線的類型

```cpp
enum class TrendlineType
```

### 值

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| Exponential | 0 | 指定趨勢線為指數曲線。 |
| Linear | 1 | 指定趨勢線為直線。 |
| Logarithmic | 2 | 指定趨勢線為對數曲線，形式為 ，其中 log 為自然對數。 |
| MovingAverage | 3 | 指定趨勢線為周期為 Period 的移動平均。 |
| Polynomial | 4 | 指定趨勢線為階數為 Order 的多項式曲線。 |
| Power | 5 | 指定趨勢線為冪曲線。 |
