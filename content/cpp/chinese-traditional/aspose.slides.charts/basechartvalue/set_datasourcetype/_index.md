## BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType) 方法

指定 AsCell、AsCells、AsLiteralString 或 AsLiteralDouble 屬性在衍生類別中是否為實際存在。換句話說，它指定 Data 屬性的值類型。寫入 [Charts::DataSourceType](../../datasourcetype/).

```cpp
void Aspose::Slides::Charts::BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType value) override
```

## 備註

對於 [ChartDataPointCollection](../../chartdatapointcollection/) 中的點，此屬性為唯讀。在此情況下，要變更此屬性的值，可使用 ChartDataPointCollection.DataSourceTypeFor<...> 屬性之一。
