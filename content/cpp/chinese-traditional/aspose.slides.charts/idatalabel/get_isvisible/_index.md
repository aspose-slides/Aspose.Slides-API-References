## IDataLabel::get_IsVisible() 方法

False 表示資料標籤不可見 (因此所有 Show*-flags (ShowValue, ...) 都是 false)。唯讀 **bool**。

```cpp
virtual bool Aspose::Slides::Charts::IDataLabel::get_IsVisible()=0
```

## 備註

如果資料標籤可見，您可以使用 [Hide()](../hide/) 方法將其隱藏。但如果資料標籤不可見 (IsVisible 為 false)，您可以透過將 Show*-flags (ShowValue, ...) 設為 true 來使資料標籤可見。
