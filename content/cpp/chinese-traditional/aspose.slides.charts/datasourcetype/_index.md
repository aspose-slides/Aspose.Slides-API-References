## DataSourceType 列舉

資料來源類型。

```cpp
enum class DataSourceType
```

### 值

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| Worksheet | 0 | 使用 CellXls 物件在工作表中存儲資料點的 XValue、YValue、Value 或 BubbleSize。 |
| StringLiterals | 1 | 使用快速存取字串變數來存儲資料點的 XValue、YValue、Value 或 BubbleSize。Worksheet 不用於存儲值。 |
| DoubleLiterals | 2 | 使用快速存取 double 變數來存儲資料點的 XValue、YValue、Value 或 BubbleSize。Worksheet 不用於存儲值。 |
