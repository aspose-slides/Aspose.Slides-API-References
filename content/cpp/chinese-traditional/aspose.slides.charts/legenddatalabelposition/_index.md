## LegendDataLabelPosition enum

確定資料標籤的位置。

```cpp
enum class LegendDataLabelPosition
```

### Values

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| NotDefined | -1 | 位置未定義。 |
| Bottom | 0 | 指定資料標籤應顯示在資料標記的下方。 |
| BestFit | 1 | 指定資料標籤應顯示在最佳位置。 |
| Center | 2 | 指定資料標籤應顯示在資料標記的中心位置。 |
| InsideBase | 3 | 指定資料標籤應顯示在資料標記基部內部。 |
| InsideEnd | 4 | 指定資料標籤應顯示在資料標記末端內部。 |
| Left | 5 | 指定資料標籤應顯示在資料標記的左側。 |
| OutsideEnd | 6 | 指定資料標籤應顯示在資料標記末端的外部。 |
| Right | 7 | 指定資料標籤應顯示在資料標記的右側。 |
| Top | 8 | 指定資料標籤應顯示在資料標記的上方。 |
