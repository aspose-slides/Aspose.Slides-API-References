## DataLabelFormat::set_Position(LegendDataLabelPosition) method

表示資料標籤的位置。寫入 [LegendDataLabelPosition](../../legenddatalabelposition/)。

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_Position(LegendDataLabelPosition value) override
```

## 備註

如果此 [DataLabelFormat](../) 物件的父項是 [DataLabelCollection](../../datalabelcollection/) 資料標籤集合，則此屬性取得或設定新資料標籤在 [DataLabelCollection](../../datalabelcollection/) 集合中的 Position 屬性的預設值。表示 [DataLabel](../../datalabel/) 物件的位置。將此屬性設定為某個值，同時也會將此值設定為 [DataLabelCollection](../../datalabelcollection/) 集合中所有資料標籤的 Position 屬性 (即 "DataLabels.DefaultDataLabelFormat.Position = val;" 會導致所有 DataLabels[i].Position 等於 val)。
