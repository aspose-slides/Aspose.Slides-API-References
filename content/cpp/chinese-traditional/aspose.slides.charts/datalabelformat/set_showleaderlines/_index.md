## DataLabelFormat::set_ShowLeaderLines(bool) 方法

表示指定圖表的資料標籤引導線顯示行為。True 會顯示引導線。False 則隱藏。寫入 **bool**。

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLeaderLines(bool value) override
```

## 備註

如果此 [DataLabelFormat](../) 物件的父項是 [DataLabelCollection](../../datalabelcollection/) 資料標籤集合，則此屬性會取得或設定 [DataLabelCollection](../../datalabelcollection/) 集合中新資料標籤的 ShowLeaderLines 屬性的預設值。將此屬性設定為某個值時，也會將此值設定為 [DataLabelCollection](../../datalabelcollection/) 集合中所有資料標籤的 ShowLeaderLines 屬性 (例如 "DataLabels.DefaultDataLabelFormat.ShowLeaderLines = val;" 使所有 DataLabels[i].ShowLeaderLines 等於 val)。
