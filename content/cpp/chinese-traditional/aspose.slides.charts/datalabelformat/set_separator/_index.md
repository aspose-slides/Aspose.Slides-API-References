## DataLabelFormat::set_Separator(System::String) 方法


設定或傳回表示圖表上資料標籤所使用分隔符的 Variant。寫入 [System::String](../../../system/string/)。

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_Separator(System::String value) override
```

## 備註


如果此 [DataLabelFormat](../) 物件的父項是 [DataLabelCollection](../../datalabelcollection/) 資料標籤集合，則此屬性會取得或設定 [DataLabelCollection](../../datalabelcollection/) 集合中新資料標籤的 Separator 屬性的預設值。將此屬性設定為某個值時，同時也會將該值設定到 [DataLabelCollection](../../datalabelcollection/) 集合中所有資料標籤的 Separator 屬性 (例如 "DataLabels.DefaultDataLabelFormat.Separator = val;" 會導致所有 DataLabels[i].Separator 等於 val)。
