## DataLabelFormat::set_ShowLabelAsDataCallout(bool) 方法

決定指定圖表的資料標籤是顯示為資料標註還是顯示為資料標籤。

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLabelAsDataCallout(bool value) override
```

## 備註

如果此 [DataLabelFormat](../) 物件的父項是 [DataLabelCollection](../../datalabelcollection/) 資料標籤的集合，則此屬性取得或設定 [DataLabelCollection](../../datalabelcollection/) 集合中新資料標籤的 ShowLabelAsDataCallout 屬性的預設值。將此屬性設定為某個值亦會將此值設定給 [DataLabelCollection](../../datalabelcollection/) 集合中所有資料標籤的 ShowLabelAsDataCallout 屬性（例如 "DataLabels.DefaultDataLabelFormat.ShowLabelAsDataCallout = val;" 會讓所有 DataLabels[i].ShowLabelAsDataCallout 等於 val）。
