## IDataLabelFormat::set_ShowPercentage(bool) 方法


表示特定圖表的資料標籤百分比值顯示行為。True 會顯示百分比值。False 會隱藏。寫入 **bool**。

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowPercentage(bool value)=0
```

## 說明


如果此 [DataLabelFormat](../../datalabelformat/) 物件的父項是 [DataLabelCollection](../../datalabelcollection/) 資料標籤集合，則此屬性取得或設定 [DataLabelCollection](../../datalabelcollection/) 集合中新資料標籤的 ShowPercentage 屬性的預設值。將此屬性設為某個值時，也會將此值設定給 [DataLabelCollection](../../datalabelcollection/) 集合中全部資料標籤的 ShowPercentage 屬性 (即 "DataLabels.DefaultDataLabelFormat.ShowPercentage = val;" 使所有 DataLabels[i].ShowPercentage 等於 val)。
