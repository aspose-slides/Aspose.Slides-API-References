## IDataLabelFormat::set_IsNumberFormatLinkedToSource(bool) 方法

寫入 **bool**。

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_IsNumberFormatLinkedToSource(bool value)=0
```

## 備註

如果此 [DataLabelFormat](../../datalabelformat/) 物件的父項是 [DataLabelCollection](../../datalabelcollection/) 資料標籤集合，則此屬性取得或設定 [DataLabelCollection](../../datalabelcollection/) 集合中新資料標籤的 IsNumberFormatLinkedToSource 屬性的預設值。將此屬性設為某個值時，也會將此值設定為 [DataLabelCollection](../../datalabelcollection/) 集合中所有資料標籤的 IsNumberFormatLinkedToSource 屬性 (例如 \"DataLabels.DefaultDataLabelFormat.IsNumberFormatLinkedToSource = val;\"，會使所有 DataLabels[i].IsNumberFormatLinkedToSource 等於 val)。
