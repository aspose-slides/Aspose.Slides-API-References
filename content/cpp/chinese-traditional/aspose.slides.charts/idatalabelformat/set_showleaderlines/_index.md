## IDataLabelFormat::set_ShowLeaderLines(bool) 方法


表示指定圖表的資料標籤引導線顯示行為。True 顯示引導線。False 隱藏。寫入 **bool**。

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowLeaderLines(bool value)=0
```

## 備註


如果此 [DataLabelFormat](../../datalabelformat/) 物件的父項是 [DataLabelCollection](../../datalabelcollection/) 資料標籤集合，則此屬性取得或設定新資料標籤在 [DataLabelCollection](../../datalabelcollection/) 集合中的 ShowLeaderLines 屬性的預設值。將此屬性設定為某值時，也會將該值設定給 [DataLabelCollection](../../datalabelcollection/) 集合中所有資料標籤的 ShowLeaderLines 屬性 (例如 \"DataLabels.DefaultDataLabelFormat.ShowLeaderLines = val;\" 會使所有 DataLabels[i].ShowLeaderLines 等於 val)。
