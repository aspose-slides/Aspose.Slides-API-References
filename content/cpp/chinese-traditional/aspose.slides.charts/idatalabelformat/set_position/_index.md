## IDataLabelFormat::set_Position(LegendDataLabelPosition) 方法


表示資料標籤的位置。寫入 [LegendDataLabelPosition](../../legenddatalabelposition/).

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_Position(LegendDataLabelPosition value)=0
```

## 備註


如果此 [DataLabelFormat](../../datalabelformat/) 物件的父項是 [DataLabelCollection](../../datalabelcollection/) 資料標籤集合，則此屬性會取得或設定 [DataLabelCollection](../../datalabelcollection/) 集合中新資料標籤的 Position 屬性的預設值。表示 [DataLabel](../../datalabel/) 物件的位置。以此屬性設定值時，亦會將此值設定為 [DataLabelCollection](../../datalabelcollection/) 集合中所有資料標籤的 Position 屬性 (例如 \"DataLabels.DefaultDataLabelFormat.Position = val;\"，導致所有 DataLabels[i].Position 等於 val)。
