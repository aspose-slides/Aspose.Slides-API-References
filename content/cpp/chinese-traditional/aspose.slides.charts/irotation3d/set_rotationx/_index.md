## IRotation3D::set_RotationX(int8_t) 方法

設定繞 X 軸的旋轉角度（即 3D 圖表的 Y 方向），範圍介於 -90 到 90 度。此屬性符合 ECMA-376 中的 21.2.2.157 rotX (X Rotation) 條目，亦與 PowerPoint 2007+ 的 "Y Rotation" 選項相對應。寫入 **int8_t**。

```cpp
virtual void Aspose::Slides::Charts::IRotation3D::set_RotationX(int8_t value)=0
```
