## AxisAggregationType enum

表示類別軸的彙總類型。僅用於 Histogram 或 HistogramPareto 系列。

```cpp
enum class AxisAggregationType
```

### Values

| 名稱 | 值 | 描述 |
| --- | --- | --- |
| ByCategory | 0 | 按類別彙總 |
| Automatic | 1 | 自動彙總類別。 |
| ByBinWidth | 2 | 按箱寬彙總類別。屬性 IAxis::get(set)_BinWidth 必須設定。 |
| ByNumberOfBins | 3 | 按箱數彙總類別。屬性 IAxis::get(set)_NumberOfBins 必須設定。 |
