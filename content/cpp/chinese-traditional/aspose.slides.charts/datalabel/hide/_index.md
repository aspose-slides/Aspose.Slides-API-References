## DataLabel::Hide() 方法


透過將所有 Show*-flags（ShowValue，...）設定為 false 狀態，使資料標籤隱藏。IsVisible 之後將為 false。

```cpp
void Aspose::Slides::Charts::DataLabel::Hide() override
```

## 備註


如果資料標籤不可見（IsVisible 為 false），您可以透過將 Show*-flags（ShowValue，...）設定為 true 狀態，使資料標籤重新可見。
