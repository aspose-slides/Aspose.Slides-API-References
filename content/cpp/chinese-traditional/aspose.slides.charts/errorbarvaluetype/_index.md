## ErrorBarValueType 列舉

表示錯誤棒值的類型

```cpp
enum class ErrorBarValueType
```

### 值

| 名稱 | 數值 | 描述 |
| --- | --- | --- |
| Custom | 0 | 指定錯誤棒的長度由 Plus 與 Minus 元素決定。 |
| Fixed | 1 | 指定錯誤棒的長度為由 Error Bar Value 所決定的固定值。 |
| Percentage | 2 | 指定錯誤棒的長度為資料的 Error Bar Value 百分比。 |
| StandardDeviation | 3 | 指定錯誤棒的長度為資料的 Error Bar Value 標準差。 |
| StandardError | 4 | 指定錯誤棒的長度為資料的 Error Bar Value 標準誤差。 |
