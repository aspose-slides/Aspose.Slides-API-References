## 類別

| 類別 | 說明 |
| --- | --- |
| [AlphaBiLevel](./alphabilevel/) | 表示 Alpha Bi-Level 效果。Alpha（不透明度）值小於閾值時會變為 0（完全透明），而大於或等於閾值的 alpha 值會變為 100%（完全不透明）。 |
| [AlphaCeiling](./alphaceiling/) | 表示 Alpha Ceiling 效果。Alpha（不透明度）值大於零時會變為 100%。換言之，任何部分不透明的項目都會變為完全不透明。 |
| [AlphaFloor](./alphafloor/) | 表示 Alpha Floor 效果。Alpha（不透明度）值小於 100% 時會變為零。換言之，任何部分透明的項目都會變為完全透明。 |
| [AlphaInverse](./alphainverse/) | 表示 Alpha Inverse 效果。Alpha（不透明度）值透過從 100% 減算的方式反轉。 |
| [AlphaModulate](./alphamodulate/) | 表示 Alpha Modulate 效果。效果的 alpha（不透明度）值會以固定百分比相乘。效果容器指定包含要調製的 alpha 值的效果。 |
| [AlphaModulateFixed](./alphamodulatefixed/) | 表示 Alpha Modulate Fixed 效果。效果的 alpha（不透明度）值會以固定百分比相乘。 |
| [AlphaReplace](./alphareplace/) | 表示 Alpha Replace 效果。效果的 alpha（不透明度）值會被固定的 alpha 取代。 |
| [BiLevel](./bilevel/) | 表示 Bi-Level（黑白）效果。輸入顏色的亮度若小於指定的閾值，則會變為黑色；亮度大於或等於指定值的則會變為白色。此效果不會影響 alpha 效果值。 |
| [Blur](./blur/) | 表示一個 [Blur](./blur/) 效果，套用於整個形狀，包括其填充。所有色彩通道，包括 alpha，皆受影響。 |
| [BrightnessContrast](./brightnesscontrast/) | 表示一個 [BrightnessContrast](./brightnesscontrast/) 效果。調整亮度與對比度 |
| [ColorChange](./colorchange/) | 表示 Color Change 效果。FromColor 的實例會被 ToColor 的實例取代。 |
| [ColorReplace](./colorreplace/) | 表示 Color Replacement 效果。所有效果顏色會變為固定顏色。Alpha 值不受影響。 |

| [EffectFactory](./effectfactory/) | 允許建立效果 |

| [Glow](./glow/) | 表示一個 [Glow](./glow/) 效果，於物件邊緣外添加彩色模糊輪廓。 |
| [GrayScale](./grayscale/) | 表示 Gray Scale 效果。將所有效果顏色值轉換為與其亮度相對應的灰階。效果的 alpha（不透明度）值不受影響。 |
| [HSL](./hsl/) | 表示 Hue/Saturation/Luminance 效果。色相、飽和度與亮度皆可相對於目前值進行調整。 |
