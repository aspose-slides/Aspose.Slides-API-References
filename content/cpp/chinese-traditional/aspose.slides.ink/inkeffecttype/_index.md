## InkEffectType 列舉


指定一組預定義的墨水渲染視覺效果。每個效果對應一種紋理或圖像，以模擬風格化的墨水外觀。這些值可用於在渲染過程中自訂數位墨水筆跡的視覺樣式。

```cpp
enum class InkEffectType
```

### 值

| Name | Value | Description |
| --- | --- | --- |
| NotDefined | -1 | 此效果未定義或未知。此值可作為預設或備援使用。 |
| Bronze | 0 | 溫暖的棕色金屬紋理，類似青銅墨水。 |
| Galaxy | 1 | 彩色且閃爍的紋理，類似星系，帶有宇宙色調。 |
| Gold | 2 | 明亮的金屬金色紋理，使墨水筆跡呈現奢華外觀。 |
| Lava | 3 | 火熱的紋理，類似熔岩，帶有紅色和橙色調。 |
| Ocean | 4 | 深藍色、類似流體的紋理，模擬海洋波浪或水性墨水。 |
| RainbowGlitter | 5 | 彩色且閃亮的彩虹亮粉效果，用於節慶或活潑的墨水筆跡。 |
| RoseGold | 6 | 柔和的粉金色混合，類似玫瑰金，用於優雅的墨水筆跡。 |
| Silver | 7 | 冷冽的金屬銀色紋理，模擬經典銀色墨水。 |
