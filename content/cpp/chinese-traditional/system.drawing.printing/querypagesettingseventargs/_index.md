## QueryPageSettingsEventArgs 類別

提供 QueryPageSettings 事件的資料。此類別的物件應僅使用 [System::MakeObject()](../../system/makeobject/) 函式進行配置。絕不要在堆疊上或使用 operator new 建立此類型的實例，因為這會導致執行時錯誤和/或斷言失敗。始終將此類別包裝成 [System::SmartPtr](../../system/smartptr/) 指標，並使用此指標將其作為參數傳遞給函式。

```cpp
class QueryPageSettingsEventArgs : private System::Drawing::Printing::PrintEventArgs
```
