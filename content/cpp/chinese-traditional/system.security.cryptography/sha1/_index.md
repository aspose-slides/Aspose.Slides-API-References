## SHA1 類別

計算 [SHA1](./) 雜湊值以處理輸入資料。 在 C++ 中，[SHA1](./) 不是抽象類別。 此類別的物件只能使用 [System::MakeObject()](../../system/makeobject/) 函式來分配。 切勿在堆疊上或使用 operator new 建立此類型的實例，因為會導致執行時錯誤和/或斷言失敗。 應始終將此類別包裝成 [System::SmartPtr](../../system/smartptr/) 指標，並使用此指標將其作為參數傳遞給函式。

```cpp
class SHA1 : public System::Security::Cryptography::HashAlgorithm
```
