## IDataReader 類別

介面，用於讀取連續資料。此類別的物件應僅透過 [System::MakeObject()](../../system/makeobject/) 函式分配。請勿在堆疊上或使用 operator new 建立此型別的實例，因為這會導致執行時錯誤和/或斷言失敗。請始終將此類別包裝成 [System::SmartPtr](../../system/smartptr/) 指標，並使用該指標作為參數傳遞給函式。

```cpp
class IDataReader : public System::Data::IDataRecord
```
