## 類別

| 類別 | 描述 |
| --- | --- |
| [IXmlSerializable](./ixmlserializable/) | 提供 XML 序列化與反序列化的自訂格式化。此類別的物件應僅使用 [System::MakeObject()](../system/makeobject/) 函式分配。切勿在堆疊上或使用 operator new 建立此類型的實例，因為會導致執行時錯誤和/或斷言失敗。請始終將此類別包裝成 [System::SmartPtr](../system/smartptr/) 指標，並使用此指標作為參數傳遞給函式。 |
| [XmlAttributeOverrides](./xmlattributeoverrides/) | 允許在使用 [XmlSerializer](./xmlserializer/) 序列化或反序列化物件時覆寫屬性。此類別的物件應僅使用 [System::MakeObject()](../system/makeobject/) 函式分配。切勿在堆疊上或使用 operator new 建立此類型的實例，因為會導致執行時錯誤和/或斷言失敗。請始終將此類別包裝成 [System::SmartPtr](../system/smartptr/) 指標，並使用此指標作為參數傳遞給函式。 |
| [XmlRootAttribute](./xmlrootattribute/) | 將屬性目標標記為 XML 根元素並控制其 XML 序列化。此類別的物件應僅使用 [System::MakeObject()](../system/makeobject/) 函式分配。切勿在堆疊上或使用 operator new 建立此類型的實例，因為會導致執行時錯誤和/或斷言失敗。請始終將此類別包裝成 [System::SmartPtr](../system/smartptr/) 指標，並使用此指標作為參數傳遞給函式。 |
| [XmlSerializationReader](./xmlserializationreader/) | 提升 [XmlReader](../system.xml/xmlreader/) 體驗的服務類別。 |
| [XmlSerializationWriter](./xmlserializationwriter/) | 提升 [XmlWriter](../system.xml/xmlwriter/) 體驗的服務類別。 |
| [XmlSerializer](./xmlserializer/) | 執行物件與 XML 文件之間的序列化與反序列化。此類別的物件應僅使用 [System::MakeObject()](../system/makeobject/) 函式分配。切勿在堆疊上或使用 operator new 建立此類型的實例，因為會導致執行時錯誤和/或斷言失敗。請始終將此類別包裝成 [System::SmartPtr](../system/smartptr/) 指標，並使用此指標作為參數傳遞給函式。 |
| [XmlSerializerImplementation](./xmlserializerimplementation/) | 供 [XmlSerializer](./xmlserializer/) 使用的內部類別。 |
| [XmlSerializerNamespaces](./xmlserializernamespaces/) | 包含 [Serialization::XmlSerializer](./xmlserializer/) 用於在 XML 文件實例中生成限定名稱的 XML 命名空間與前置詞。 |
