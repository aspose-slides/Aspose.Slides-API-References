## XmlRootAttribute 類別

標記屬性目標為 XML 根元素，並控制其 XML 序列化。此類別的物件只能使用 [System::MakeObject()](../../system/makeobject/) 函式來配置。切勿在堆疊上或使用 new 運算子建立此類型的實例，因為會導致執行時錯誤和/或斷言失敗。始終將此類別包裝成 [System::SmartPtr](../../system/smartptr/) 指標，並使用該指標將其作為參數傳遞給函式。

```cpp
class XmlRootAttribute : public System::Object
```
