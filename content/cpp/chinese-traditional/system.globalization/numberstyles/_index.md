## NumberStyles 列舉

解析時允許的數字樣式。

```cpp
enum class NumberStyles : int32_t
```

### 值

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| None | 0 | 沒有非數字符號。 |
| AllowLeadingWhite | 1 | 允許前置空白字元。 |
| AllowTrailingWhite | 2 | 允許尾隨空白字元。 |
| AllowLeadingSign | 4 | 允許前置符號。 |
| Integer | n/a | 預設的整數格式。 |
| AllowTrailingSign | 8 | 允許尾隨符號。 |
| AllowParentheses | 16 | 允許使用括號表示負值。 |
| AllowDecimalPoint | 32 | 允許小數點。 |
| AllowThousands | 64 | 允許千位分隔符。 |
| Number | n/a | 預設的組合數字格式。 |
| AllowExponent | 128 | 允許指數符號。 |
| Float | n/a | 預設的浮點數格式。 |
| AllowCurrencySymbol | 256 | 允許貨幣符號。 |
| Currency | n/a | 預設的貨幣格式。 |
| Any | n/a | 允許任何格式指定子。 |
| AllowHexSpecifier | 512 | 允許十六進位數字。 |
| HexNumber | n/a | 預設的十六進位格式。 |
