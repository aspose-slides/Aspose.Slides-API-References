## CultureTypes 列舉

Culture 類別位元遮罩項目。

```cpp
enum class CultureTypes : int32_t
```

### 值

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| NeutralCultures | 1 | 僅針對語言而非國家或地區的文化。 |
| SpecificCultures | 2 | 特定於國家/地區。 |
| InstalledWin32Cultures | 4 | 已安裝於作業系統的文化。 |
| AllCultures | n/a | 所有可用的文化。 |
| UserCustomCulture | 8 | 使用者自訂的文化。 |
| ReplacementCultures | 16 | 使用者自訂的取代現有文化。 |
| WindowsOnlyCultures | 32 | 已淘汰。 |
| FrameworkCultures | 64 | 已淘汰。 |
