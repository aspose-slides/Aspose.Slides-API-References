## TimeSpanStyles enum

指定格式化選項，以自訂字串解析，供將時間間隔的字串表示轉換為 Timespan 物件的方法使用。

```cpp
enum class TimeSpanStyles : int32_t
```

### 值

| 名稱 | 數值 | 說明 |
| --- | --- | --- |
| None | 0 | 由輸入字串表示的時間間隔僅在存在負號時才被解釋為負的時間間隔。 |
| AssumeNegative | 1 | 由輸入字串表示的時間間隔始終被解釋為負的時間間隔。 |
