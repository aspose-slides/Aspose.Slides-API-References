| Substitution | 1 | 指的是由 **Substitution** 所產生的衍生。 |
| Extension | 2 | 指的是由 **Extension** 所產生的衍生。 |
| Restriction | 4 | 指的是由 **Restriction** 所產生的衍生。 |
| List | 8 | 指的是由 **List** 所產生的衍生。 |
| Union | 16 | 指的是由 **Union** 所產生的衍生。 |
| All | 255 | **#all**。指所有衍生方法。 |
| None | 256 | 接受預設的衍生方法。 |
