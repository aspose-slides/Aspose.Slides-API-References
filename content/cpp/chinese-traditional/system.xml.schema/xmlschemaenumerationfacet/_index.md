## XmlSchemaEnumerationFacet 類別

代表來自 XML [Schema](../)、由全球 [Web](../../system.web/) 聯盟 (W3C) 所指定的 **enumeration** facet。此類別指定 simpleType 元素的有效值清單。宣告包含在 **restriction** 宣告中。

```cpp
class XmlSchemaEnumerationFacet : public System::Xml::Schema::XmlSchemaFacet
```

## 備註

此類別的物件僅應使用 [System::MakeObject()](../../system/makeobject/) 函式進行配置。切勿在堆疊上或使用 operator new 建立此型別的實例，因為會導致執行時錯誤和/或斷言失敗。始終將此類別包裝成 [System::SmartPtr](../../system/smartptr/) 指標，並使用該指標作為參數傳遞給函式。
