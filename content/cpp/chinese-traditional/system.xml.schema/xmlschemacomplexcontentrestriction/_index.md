## XmlSchemaComplexContentRestriction 類別


表示 XML [Schema](../) 中的 **restriction** 元素，依據全球資訊網 [Web](../../system.web/) 聯盟（W3C）所規範。此類別適用於以限制方式衍生之具複雜內容模型的複雜型別。它將複雜型別的內容限制為繼承的複雜型別的子集合。

```cpp
class XmlSchemaComplexContentRestriction : public System::Xml::Schema::XmlSchemaContent
```

## 備註



此類別的物件只能透過 [System::MakeObject()](../../system/makeobject/) 函式來配置。切勿在堆疊上或使用 new 運算子建立此類型的實例，因為會導致執行時錯誤或斷言失敗。應始終將此類別包裝成 [System::SmartPtr](../../system/smartptr/) 指標，並使用該指標作為參數傳遞給函式。
