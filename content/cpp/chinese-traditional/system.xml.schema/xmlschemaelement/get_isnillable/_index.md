## XmlSchemaElement::get_IsNillable() 方法


傳回指示 **xsi:nil** 是否可以出現在實例資料中的資訊。指出可以將明確的 nil 值指派給該元素。

```cpp
bool System::Xml::Schema::XmlSchemaElement::get_IsNillable()
```


### 返回值

如果 nillable 為 **true**，則允許該元素的實例將 **nil** 屬性設為 **true**。**nil** 屬性是作為 XML [Schema](../../) 命名空間的一部份為實例定義的。預設為 **false**。可選。
