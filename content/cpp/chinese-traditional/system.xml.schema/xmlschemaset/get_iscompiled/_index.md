## XmlSchemaSet::get_IsCompiled() 方法

傳回一個值，以指示 XML [Schema](../../) 定義語言 (XSD) 綱要在 [XmlSchemaSet](../) 中是否已編譯。

```cpp
bool System::Xml::Schema::XmlSchemaSet::get_IsCompiled()
```

### 返回值

**true** 如果 [XmlSchemaSet](../) 中的綱要自上次從 [XmlSchemaSet](../) 添加或移除結構描述以來已編譯；否則，**false**。
