## IXmlSchemaInfo::get_IsDefault() method


返回一個值，用以指示此已驗證的 XML 節點是否因在 XML [Schema](../../) 定義語言 (XSD) 綱要驗證期間套用預設而被設定。

```cpp
virtual bool System::Xml::Schema::IXmlSchemaInfo::get_IsDefault()=0
```


### 回傳值

**true** 若此已驗證的 XML 節點是因在綱要驗證期間套用預設而被設定；否則為 **false**。
