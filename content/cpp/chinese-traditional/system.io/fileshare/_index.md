## FileShare 列舉

Specifies what kind of access other [FileStream](../filestream/) objects can have to a file being opened.

```cpp
enum class FileShare
```

### Values

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| None | 0 | 無存取。 |
| Read | 1 | 唯讀存取。 |
| Write | 2 | 唯寫存取。 |
| ReadWrite | 3 | 讀寫存取。 |
| Delete | 4 | 可刪除檔案。 |
| Inheritable | 16 | 使檔案句柄可被子行程繼承。 |
