## FileAttributes 列舉

表示目錄或檔案的屬性。

```cpp
enum class FileAttributes
```

### 值

| 名稱 | 數值 | 描述 |
| --- | --- | --- |
| Archive | 32 | 檔案系統實體是候選的刪除或備份項目。 |
| Compressed | 2048 | 檔案系統實體已壓縮。 |
| Device | 64 | 未使用。 |
| Directory | 16 | 檔案系統實體是一個目錄。 |
| Encrypted | 16384 | 檔案系統實體已加密。 |
| Hidden | 2 | 檔案系統實體已隱藏。 |
| IntegrityStream | 32768 | 檔案系統實體包含資料完整性支援。 |
| Normal | 128 | 檔案系統實體是一個沒有特殊屬性的檔案。 |
| NotContentIndexed | 8192 | 檔案系統實體將不會被內容索引服務索引。 |
| NoScrubData | 131072 | 檔案系統實體不會包含在資料完整性掃描中。 |
| Offline | 4096 | 檔案系統實體離線，其資料無法立即取得。 |
| ReadOnly | 1 | 檔案系統實體為唯讀。 |
| ReparsePoint | 1024 | 檔案系統實體是一個包含重新解析點的檔案。 |
| SparseFile | 512 | 檔案系統實體是一個稀疏檔。 |
| System | 4 | 檔案系統實體是一個系統檔。 |
| Temporary | 256 | 檔案系統實體是一個暫存檔。 |
| Invalid | 0 | 無效的值。 |
