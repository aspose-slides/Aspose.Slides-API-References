## DateTime::Equals(DateTime) const method

判斷指定的 [DateTime](../) 類別實例是否與目前物件具有相同的日期和時間值。

```cpp
constexpr bool System::DateTime::Equals(DateTime other) const
```

### 參數

| 參數 | 類型 | 說明 |
| --- | --- | --- |
| other | [DateTime](../) | 與目前物件比較的 [DateTime](../) 類別實例 |

### 回傳值

如果 **other** 與目前物件皆表示相同的值則回傳 True，否則回傳 false

## DateTime::Equals(DateTime, DateTime) method

判斷指定的 [DateTime](../) 類別實例是否具有相同的日期和時間值。

```cpp
static constexpr bool System::DateTime::Equals(DateTime t1, DateTime t2)
```

### 參數

| 參數 | 類型 | 說明 |
| --- | --- | --- |
| t1 | [DateTime](../) | 第一個比較項 |
| t2 | [DateTime](../) | 第二個比較項 |

### 回傳值

如果 **t1** 與 **t2** 皆表示相同的值則回傳 True，否則回傳 false
