## DateTime::AddMonths(int) const 方法

返回一個新的 [DateTime](../) 類別實例，表示日期和時間值，該值是當前物件所代表的值與指定的月份數之和。

```cpp
DateTime System::DateTime::AddMonths(int value) const
```

### 參數

| Parameter | Type | Description |
| --- | --- | --- |
| value | int | 要新增的月份數；該值可以是正數或負數 |

### 傳回值

一個新的 [DateTime](../) 類別實例，表示日期和時間值，該值是當前物件所代表的值與 **value** 個月的總和。
