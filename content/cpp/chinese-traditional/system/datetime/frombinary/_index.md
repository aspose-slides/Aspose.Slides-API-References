## DateTime::FromBinary(int64_t) 方法


從指定的無號 64 位元整數反序列化日期時間值，並將 [DateTime](../) 類別的新實例設定為該值。

```cpp
static DateTime System::DateTime::FromBinary(int64_t value)
```


### 參數

| Parameter | Type | Description |
| --- | --- | --- |
| value | **int64_t** | 用於從中反序列化日期時間值的 64 位元整數 |

### 返回值

一個 [DateTime](../) 類別的新實例，代表從指定的無號 64 位元整數值反序列化的日期時間值
