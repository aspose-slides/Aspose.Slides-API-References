## DateTime::operator<=(DateTime) const 方法

判斷目前物件所表示的日期和時間值是否早於或等於指定的 [DateTime](../) 物件所表示的值。

```cpp
constexpr bool System::DateTime::operator<=(DateTime other) const
```

### 參數

| 參數 | 類型 | 說明 |
| --- | --- | --- |
| other | [DateTime](../) | 與目前物件比較的 [DateTime](../) 物件 |

### 返回值

若目前物件所表示的日期和時間值早於或等於 **other** 所表示的值，則返回 True；否則返回 false
