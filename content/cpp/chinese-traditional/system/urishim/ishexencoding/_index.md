## UriShim::IsHexEncoding(const String\&, int32_t) 方法


檢查給定的模式是否為轉義的十六進位形式。

```cpp
static bool System::UriShim::IsHexEncoding(const String &pattern, int32_t index)
```


### 參數

| 參數 | 型別 | 說明 |
| --- | --- | --- |
| pattern | const [String](../../string/)\& | [String](../../string/) 從中讀取轉義的十六進位形式。 |
| index | **int32_t** | 給定字串中的偏移量。 |

### 傳回值

若在給定位置有轉義的十六進位模式則回傳 True，否則回傳 false。
