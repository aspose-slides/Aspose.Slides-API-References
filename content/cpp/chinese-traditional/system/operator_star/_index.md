## System::operator*(const T\&, const Decimal\&) 函式

傳回一個 [Decimal](../decimal/) 類別的新執行個體，該執行個體表示指定值與由指定的 [Decimal](../decimal/) 物件所代表的值相乘的結果。

```cpp
template<typename T,typename _> Decimal System::operator*(const T &x, const Decimal &d)
```

### 參數

| 參數 | 類型 | 說明 |
| --- | --- | --- |
| x | const T\& | 第一個乘數 |
| d | const [Decimal](../decimal/)\& | 代表第二個乘數的 [Decimal](../decimal/) 物件 |

### 返回值

一個 [Decimal](../decimal/) 類別的新執行個體，該執行個體表示 **x** 與 **d** 所代表的值相乘的結果。
