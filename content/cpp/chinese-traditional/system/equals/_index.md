## System::Equals(const TA\&, const TB\&) 函式

確定兩個值的相等性，對它們套用 [operator==()](../operator_equal_equal/)。

```cpp
template<typename TA,typename TB> bool System::Equals(const TA &a, const TB &b)
```

### 模板參數

| 參數 | 說明 |
| --- | --- |
| TA | 第一個可比較項的類型 |
| TB | 第二個可比較項的類型 |

### 參數

| 參數 | 類型 | 說明 |
| --- | --- | --- |
| a | const TA\& | 第一個可比較項 |
| b | const TB\& | 第二個可比較項 |

### 返回值

由 [operator==()](../operator_equal_equal/) 套用於 **a** 和 **b** 後返回的布林值
