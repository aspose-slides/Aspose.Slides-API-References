## System::IsNaN(const T\&) 函式

判斷指定的值是否為非數值 (NaN) 值。

```cpp
template<typename T> bool System::IsNaN(const T &value)
```

### 模板參數

| 參數 | 說明 |
| --- | --- |
| T | 函式檢查之值的類型 |

### 引數

| 參數 | 類型 | 說明 |
| --- | --- | --- |
| value | const T\& | 要檢查的值 |

### 回傳值

若 **value** 為 NaN 值則回傳 True，否則 - false
