## Uri::IsHexEncoding(const String\&, int32_t) 方法

判斷指定字串中位於指定位置的字元是否為十六進位編碼。

```cpp
static bool System::Uri::IsHexEncoding(const String &pattern, int32_t index)
```

### 參數

| 參數 | 類型 | 描述 |
| --- | --- | --- |
| pattern | const [String](../../string/)\& | 要檢查的字串 |
| index | **int32_t** | 要測試的字元之以零為起始的位置 |

### 回傳值

如果指定的字元是十六進位編碼則傳回 True，否則傳回 false
