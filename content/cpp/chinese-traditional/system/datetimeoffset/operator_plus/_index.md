## DateTimeOffset::operator+(TimeSpan) const 方法

返回一個新的 [DateTimeOffset](../) 類別實例，該實例表示當前物件所代表的日期和時間值與指定時間間隔的總和。

```cpp
DateTimeOffset System::DateTimeOffset::operator+(TimeSpan value) const
```

### 參數

| 參數 | 類型 | 描述 |
| --- | --- | --- |
| value | [TimeSpan](../../timespan/) | 要加入到當前物件所代表的值的時間間隔 |

### 返回值

一個新的 [DateTimeOffset](../) 類別實例，表示當前物件所代表的日期和時間值與 **值** 的總和。
