## DateTimeOffset::operator<=(const DateTimeOffset\&) const method

判斷目前物件所代表的日期時間值是否早於或等於由指定的 [DateTimeOffset](../) 物件所代表的值。

```cpp
bool System::DateTimeOffset::operator<=(const DateTimeOffset &other) const
```

### Arguments

| 參數 | 型別 | 說明 |
| --- | --- | --- |
| other | const [DateTimeOffset](../)\& | 要與目前物件比較的 [DateTimeOffset](../) 物件 |

### Return Value

若目前物件所代表的日期時間值早於或等於 **other** 所代表的值，則傳回 true；否則傳回 false
