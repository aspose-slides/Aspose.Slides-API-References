## DateTimeOffset::operator!=(const DateTimeOffset\&) const 方法

判斷當前物件與指定的 [DateTimeOffset](../) 物件是否表示不同的日期和時間值。

```cpp
bool System::DateTimeOffset::operator!=(const DateTimeOffset &other) const
```

### 參數

| 參數 | 類型 | 說明 |
| --- | --- | --- |
| other | const [DateTimeOffset](../)\& | 用於將當前物件與之比較的 [DateTimeOffset](../) 物件 |

### 回傳值

如果當前物件與指定的物件表示不同的日期和時間值，則返回 true；否則返回 false
