## NullableUtils 類別

代表 C# [System.Nullable](../nullable/)（未指定類型參數）的靜態類別。由於 C++ 中無法重載類別模板，無法使用原始名稱。支援可指派為 null 的值類型。此類別不可被繼承。

```cpp
class NullableUtils
```
