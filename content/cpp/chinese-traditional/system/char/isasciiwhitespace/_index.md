## Char::IsAsciiWhiteSpace(char_t) 方法

判斷指定的字符是否被歸類為 ASCII 空白字符。

```cpp
static constexpr bool System::Char::IsAsciiWhiteSpace(char_t c)
```

### 參數

| 參數 | 類型 | 說明 |
| --- | --- | --- |
| c | char_t | 要測試的字符 |

### 返回值

若指定的字符是 ASCII 空白字符則返回 True，否則返回 false
