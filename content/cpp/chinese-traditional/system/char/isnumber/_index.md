## Char::IsNumber(const char_t *, int) 方法


判斷指定字符緩衝區中指定索引處的字符是否被歸類為數字。

```cpp
static bool System::Char::IsNumber(const char_t *str, int idx)
```


### 參數

| 參數 | 類型 | 說明 |
| --- | --- | --- |
| str | const char_t * | 指向字符緩衝區起始位置的指標 |
| idx | int | 在指定緩衝區中要測試的字符的零基索引 |

### 返回值

如果指定索引處的字元是數字，則返回 True；否則返回 false
