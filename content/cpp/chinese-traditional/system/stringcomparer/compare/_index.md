## StringComparer::Compare(args_type, args_type) const 方法

```cpp
virtual int System::StringComparer::Compare(args_type x, args_type y) const override
```


### 參數

| 參數 | 類型 | 說明 |
| --- | --- | --- |
| x | [args_type](../args_type/) | 左側字串值。 |
| y | [args_type](../args_type/) | 右側字串值。 |

### 回傳值

若 **x** 在 **y** 前則返回負值，若相等則返回零，否則返回正值。
