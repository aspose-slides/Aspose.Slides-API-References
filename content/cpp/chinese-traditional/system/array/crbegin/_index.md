## Array::crbegin() const 方法

傳回一個指向反向容器中第一個元素的反向迭代器。它對應於非反向容器的最後一個元素。如果容器為空，傳回的迭代器等於 [crend()](../crend/)。

```cpp
const_reverse_iterator System::Array<T>::crbegin() const noexcept
```

### 返回值

一個指向容器中最後一個具 const 限定的元素的迭代器。
