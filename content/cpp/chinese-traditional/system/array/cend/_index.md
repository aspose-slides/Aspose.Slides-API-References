## Array::cend() const 方法


傳回一個 iterator，指向容器中最後一個元素之後的元素。此元素作為佔位符；嘗試存取它會導致未定義的行為。

```cpp
const_iterator System::Array<T>::cend() const noexcept
```


### 回傳值

一個 iterator，指向容器中最後一個元素之後的理論上 const-qualified 元素。
