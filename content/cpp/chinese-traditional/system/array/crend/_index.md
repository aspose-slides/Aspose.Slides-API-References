## Array::crend() const method


傳回指向已反轉容器中最後一個元素之後之元素的反向迭代器。它對應於未反轉容器中第一個元素之前的元素。此元素充當佔位符，嘗試存取它會導致未定義的行為。

```cpp
const_reverse_iterator System::Array<T>::crend() const noexcept
```


### 返回值

指向容器中第一個元素之前之理論 const 限定元素的迭代器。
