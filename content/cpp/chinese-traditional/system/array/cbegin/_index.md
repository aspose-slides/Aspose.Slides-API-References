## Array::cbegin() const 方法

返回一個指向容器中第一個 const 限定元素的 iterator。如果容器為空，返回的 iterator 將等於 [cend()](../cend/)。

```cpp
const_iterator System::Array<T>::cbegin() const noexcept
```

### 回傳值

指向容器中第一個 const 限定元素的 iterator。
