## Array::end() 方法


傳回指向容器最後一個元素之後之元素的迭代器。此元素充當佔位符；若嘗試存取它，會導致未定義的行為。

```cpp
iterator System::Array<T>::end() noexcept
```


### 返回值

指向容器最後一個元素之後之理論元素的迭代器。

傳回指向具 const 限定的容器最後一個元素之後之元素的迭代器。此元素充當佔位符；若嘗試存取它，會導致未定義的行為。

```cpp
const_iterator System::Array<T>::end() const noexcept
```


### 返回值

指向具 const 限定的容器最後一個元素之後之理論元素的迭代器。
