## SmartPtr::Is(const System::TypeInfo\&) const 方法

檢查指向的物件是否為特定類型或其子類型。遵循 C# 'is' 語意。

```cpp
bool System::SmartPtr<T>::Is(const System::TypeInfo &target) const
```

### 參數

| 參數 | 類型 | 說明 |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | 指定要檢查的目標類型。 |

### 回傳值

如果 C# 'is' 形式的檢查為正則返回 True，否則返回 false。
