## SmartPtr::static_pointer_cast() const 方法

Casts pointer to different type using static_cast on pointed object.

```cpp
template<class Y> SmartPtr<Y> System::SmartPtr<T>::static_pointer_cast() const
```

### 模板參數

| 參數 | 說明 |
| --- | --- |
| Y | 指向物件的目標類型。 |

### 返回值

已更改類型的指標，始終為共享模式。
