## Boolean::Parse(const String\&) 方法

將指定的字串轉換為 bool 類型的值。

```cpp
static bool System::Boolean::Parse(const String &value)
```

### 參數

| 參數 | 類型 | 說明 |
| --- | --- | --- |
| value | const [String](../../string/)\& | 要轉換的字串。 |

### 回傳值

轉換結果會放入 bool 變數中；如果指定的字串等於 "True"，結果為 true；如果指定的字串等於 "False"，結果為 false。
