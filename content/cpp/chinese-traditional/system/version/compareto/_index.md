## Version::CompareTo(const Version\&) const 方法


比較目前物件與指定物件所代表的版本。

```cpp
int System::Version::CompareTo(const Version &ver) const
```


### 參數

| 參數 | 類型 | 說明 |
| --- | --- | --- |
| ver | const [Version](../)\& | 一個用於與目前物件比較的 [Version](../) 物件 |

### 返回值

- 1 如果目前物件所代表的版本號小於 **ver** 所代表的版本號；0 如果兩個版本號相等；1 如果目前物件所代表的版本號大於 **ver** 所代表的值
