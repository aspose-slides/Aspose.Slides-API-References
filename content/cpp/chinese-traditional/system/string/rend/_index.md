## String::rend() const 方法

返回指向實際字串緩衝區中（若有）第一個字元之前的反向迭代器。

```cpp
reverse_iterator System::String::rend() const
```

### 返回值

指向實際字串緩衝區中第一個字元之前（若有）的元素或指向已分配緩衝區之前的元素的反向迭代器。
