## String::CompareTo(const String&) const 方法

比較兩個字串，採用「小於-等於-大於」的方式。使用目前的文化設定。

```cpp
int System::String::CompareTo(const String &str) const
```

### 參數

| 參數 | 型別 | 說明 |
| --- | --- | --- |
| str | const [String](../)\& | [String](../) 用於與此比較。 |

### 返回值

如果此被認為低於 str，則返回負值；如果相等，則返回零；如果此大於 str，則返回正值。
