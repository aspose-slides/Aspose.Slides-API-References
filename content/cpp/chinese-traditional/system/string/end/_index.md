## String::end() const 方法


返回指向實際字串緩衝區結尾的指標。永不重新配置任何記憶體。不保證緩衝區以 null 結尾。

```cpp
const UChar * System::String::end() const
```


### 返回值

指向實際字串緩衝區之後的第一個元素的指標，可能為 null 結尾也可能不是。
