## String::begin() const 方法


返回指向實際字串緩衝區起始位置的指標。永不重新配置任何內容。不保證緩衝區以 null 結尾。

```cpp
const UChar * System::String::begin() const
```


### 返回值

指向實際字串緩衝區的指標，可為 null 結尾或非 null 結尾。
