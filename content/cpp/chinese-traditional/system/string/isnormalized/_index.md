## String::IsNormalized(System::Text::NormalizationForm) const 方法

檢查 Unicode 字串是否已根據指定的正規化形式正規化。

```cpp
bool System::String::IsNormalized(System::Text::NormalizationForm form) const
```

### 參數

| 參數 | 型別 | 說明 |
| --- | --- | --- |
| form | [System::Text::NormalizationForm](../../../system.text/normalizationform/) | 正規化形式，請參閱 [System::Text::NormalizationForm](../../../system.text/normalizationform/) 以獲得詳細資訊。 |
