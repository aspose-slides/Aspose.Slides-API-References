## String::IsNull() const 方法


檢查字串是否被視為 null。 [String](../) 為 null，且僅在透過 [String()](../string/) 建構函式建立、被移動、複製或從 null 字串指派，或呼叫 [reset()](../reset/) 方法時為 null。

```cpp
bool System::String::IsNull() const
```


### 回傳值

如果字串被視為 null 則返回 true，否則返回 false。
