## Delegate< ReturnType(ArgumentTypes...)>::Empty() const 方法


判斷目前的 delegate 物件是否為空，例如未指向任何實體。

```cpp
bool System::Delegate<ReturnType(ArgumentTypes...)>::Empty() const
```


### 返回值

如果目前的 delegate 物件未指向函式、函式物件的方法，則返回 true；否則返回 false。
