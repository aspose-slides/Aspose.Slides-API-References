## EnumParseHelper::Parse(const String\&, bool) 方法


將指定的字串轉換為等效的列舉常數值。

```cpp
static E System::EnumParseHelper<E, G, Guard>::Parse(const String &str, bool ignoreCase=false)
```


### 參數

| 參數 | 類型 | 說明 |
| --- | --- | --- |
| str | const [String](../../string/)\& | [String](../../string/) 會被解釋為包含列舉常數的名稱 |
| ignoreCase | **bool** | 指定在解釋字串時是否應忽略大小寫 |

### 返回值

列舉常數，其名稱在 **str** 中指定
