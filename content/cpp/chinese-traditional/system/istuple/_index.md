## System::IsTuple(const SharedPtr\<Object\>\&, int32_t) 函式


檢查物件是否為元組（實作 ITTuple 介面）。用於位置模式的實作。

```cpp
bool System::IsTuple(const SharedPtr<Object> &object, int32_t length)
```


### 參數

| 參數 | 型別 | 說明 |
| --- | --- | --- |
| object | const [SharedPtr](../sharedptr/)\<[Object](../object/)\>\& | 要檢查的物件。 |
| length | **int32_t** | 預期的元組長度 |

### 回傳值

物件是否為元組且其長度等於預期值
