## SmartPtrMode 列舉


[SmartPtr](../smartptr/) 指標類型：弱引用或共享。定義在決定是否刪除物件時，指標是否參與計數。

```cpp
enum class SmartPtrMode : char
```

### 值

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| Shared | 0 | Shared 模式：指標參與參考計數。 |
| Weak | 1 | Weak 模式：指標不參與參考計數。 |
