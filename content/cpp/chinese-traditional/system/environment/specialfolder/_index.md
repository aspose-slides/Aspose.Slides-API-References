## SpecialFolder 列舉

表示系統特殊資料夾。

```cpp
enum class SpecialFolder
```

### 值

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| Desktop | 0 | 邏輯 Desktop。 |
| Programs | 2 | 包含使用者程式群組的資料夾。 |
| Personal | 5 | 作為文件通用儲存庫的資料夾。 |
| MyDocuments | 5 | "My Documents" 目錄。 |
| Favorites | 6 | 作為使用者最愛項目通用儲存庫的資料夾。 |
| Startup | 7 | 對應使用者 Startup 程式群組的資料夾。 |
| Recent | 8 | 包含使用者最近使用的文件的資料夾。 |
| SendTo | 9 | 作為 "Send To" 功能表項目容器的資料夾。 |
| StartMenu | 11 | 作為 "Start" 功能表項目容器的資料夾。 |
| MyMusic | 13 | "My Music" 目錄。 |
| DesktopDirectory | 16 | 用於實體儲存桌面上項目的資料夾。 |
| MyComputer | 17 | "My Computer" 目錄。 |
| Templates | 21 | 作為文件範本通用容器的資料夾。 |
| ApplicationData | 26 | 用於儲存目前漫遊使用者之應用程式專屬資料的資料夾。 |
| LocalApplicationData | 28 | 用於儲存目前非漫遊使用者之應用程式專屬資料的資料夾。 |
| InternetCache | 32 | 用於暫存 Internet 暫時檔案的儲存空間。 |
| Cookies | 33 | 用於儲存 Internet Cookie 的儲存空間。 |
| History | 34 | 用於儲存 Internet 瀏覽歷史項目的儲存空間。 |
| CommonApplicationData | 35 | 用於儲存所有使用者共用之應用程式專屬資料的資料夾。 |
| System | 37 | 系統資料夾。 |
| ProgramFiles | 38 | 程式檔案資料夾。 |
| MyPictures | 39 | "My picutres" 資料夾。 |
| UserProfile | 40 | 使用者的個人資料夾。 |
| CommonProgramFiles | 43 | 用作應用程式共用元件儲存的目錄。 |
