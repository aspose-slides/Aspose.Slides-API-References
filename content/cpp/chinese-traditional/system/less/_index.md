## System::Less(const ExpressionT\&, const ConstantT\&) 函式

實作「<」相對模式翻譯。

```cpp
template<class ExpressionT,class ConstantT> bool System::Less(const ExpressionT &left, const ConstantT &constant)
```

### 模板參數

| 參數 | 描述 |
| --- | --- |
| ExpressionT | 左表達式類型。 |
| ConstantT | 常數表達式的類型。 |

### 參數

| 參數 | 類型 | 描述 |
| --- | --- | --- |
| left | const ExpressionT\& | 將被檢查的表達式。 |
| constant | const ConstantT\& | 將與左側表達式比較的表達式。 |

### 返回值

如果類型檢查成功則返回 true，否則返回 false。
