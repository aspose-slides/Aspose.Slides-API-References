## Decimal::Compare(const Decimal\&, const Decimal\&) 方法


判斷第一個 [Decimal](../) 物件所表示的值是否小於、等於或大於第二個 [Decimal](../) 物件所表示的值。

```cpp
static int System::Decimal::Compare(const Decimal &d1, const Decimal &d2)
```


### 參數

| 參數 | 類型 | 說明 |
| --- | --- | --- |
| d1 | const [Decimal](../)\& | 第一個比較項 |
| d2 | const [Decimal](../)\& | 第二個比較項 |

### 返回值

- 1 表示 **d1** 所表示的值小於 **d2** 所表示的值；0 表示兩個值相等；1 表示 **d1** 所表示的值大於 **d2** 所表示的值
