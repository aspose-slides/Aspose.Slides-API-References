## System::LEqual(const ExpressionT\&, const ConstantT\&) 函式

Implements '<=' relative pattern translation.

```cpp
template<class ExpressionT,class ConstantT> bool System::LEqual(const ExpressionT &left, const ConstantT &constant)
```

### 範本參數

| 參數 | 說明 |
| --- | --- |
| ExpressionT | 左側運算式類型。 |
| ConstantT | 常數運算式的類型。 |

### 引數

| 參數 | 類型 | 說明 |
| --- | --- | --- |
| left | const ExpressionT\& | 將被檢查的運算式。 |
| constant | const ConstantT\& | 將與左側運算式比較的運算式。 |

### 傳回值

如果類型檢查成功則為 true，否則為 false。
