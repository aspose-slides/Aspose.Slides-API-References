## Guid::CompareTo(const Guid\&) const 方法

```cpp
int System::Guid::CompareTo(const Guid &g) const
```

### 參數

| 參數 | 類型 | 描述 |
| --- | --- | --- |
| g | const [Guid](../)\& | 比較項 |

### 返回值

- 1：如果目前物件所表示的 GUID 小於 **g** 所表示的 GUID；0：如果 GUID 相等；1：如果目前物件所表示的 GUID 大於 **g** 所表示的 GUID
