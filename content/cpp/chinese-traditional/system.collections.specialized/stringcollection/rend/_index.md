## StringCollection::rend() 方法

傳回一個指向已反轉容器最後一個元素之後之元素的反向迭代器。它對應於未反轉容器第一個元素之前的元素。此元素僅作為佔位符，若嘗試存取則會導致未定義的行為。

```cpp
reverse_iterator System::Collections::Specialized::StringCollection::rend() noexcept
```

### 返回值

指向容器第一個元素之前之理論元素的迭代器。

## StringCollection::rend() const 方法

傳回一個指向已反轉容器最後一個元素之後之元素的反向迭代器。它對應於未反轉容器第一個元素之前的元素。此元素僅作為佔位符，若嘗試存取則會導致未定義的行為。

```cpp
const_reverse_iterator System::Collections::Specialized::StringCollection::rend() const noexcept
```

### 返回值

指向 const 限定容器第一個元素之前之理論元素的迭代器。
