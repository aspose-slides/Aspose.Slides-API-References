## XPathNavigator::MoveToFirstAttribute() 方法

當在衍生類別中覆寫時，將 [XPathNavigator](../) 移動到目前節點的第一個屬性。

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToFirstAttribute()=0
```

### 返回值

**true** 若 [XPathNavigator](../) 成功移動到目前節點的第一個屬性；否則為 **false**。如果 **false**，[XPathNavigator](../) 的位置保持不變。
