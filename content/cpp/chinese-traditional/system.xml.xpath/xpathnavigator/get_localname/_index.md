## XPathNavigator::get_LocalName() 方法


當在派生類別中被覆寫時，取得目前節點的 [XPathNavigator::get_Name](../get_name/)，且不含任何命名空間前置詞。

```cpp
virtual String System::Xml::XPath::XPathNavigator::get_LocalName()=0
```


### 返回值

一個 [String](../../../system/string/)，其中包含目前節點的本地名稱；如果目前節點沒有名稱（例如文字或註解節點），則為 [String::Empty](../../../system/string/empty/)。
