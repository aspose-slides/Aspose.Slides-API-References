## XPathNavigator::MoveToFirstChild() 方法


當在衍生類別中被覆寫時，將 [XPathNavigator](../) 移動到當前節點的第一個子節點。

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToFirstChild()=0
```


### 返回值

**true** 如果 [XPathNavigator](../) 成功移動到當前節點的第一個子節點，否則為 **false**。如果 **false**，[XPathNavigator](../) 的位置保持不變。
