## TraceLevel enum


指定要為 [System.Diagnostics.Debug](../debug/)、[System.Diagnostics.Trace](../trace/) 和 System.Diagnostics.TraceSwitch 類別輸出的訊息類型。

```cpp
enum class TraceLevel
```

### 值

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| Off | 0 | 不輸出追蹤和偵錯訊息。 |
| Error | 1 | 輸出錯誤處理訊息。 |
| Warning | 2 | 輸出警告和錯誤處理訊息。 |
| Info | 3 | 輸出資訊訊息、警告和錯誤處理訊息。 |
| Verbose | 4 | 輸出所有偵錯和追蹤訊息。 |
