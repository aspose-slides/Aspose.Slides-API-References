## PerformanceCounter 類別

用於 PerformanceCounter 的虛擬類別，以便編譯已翻譯的程式碼。此類別的物件只能透過 [System::MakeObject()](../../system/makeobject/) 函式配置。切勿在堆疊上或使用 operator new 建立此類型的實例，否則會導致執行時錯誤和/或斷言失敗。請始終將此類別包裝成 [System::SmartPtr](../../system/smartptr/) 指標，並使用該指標作為參數傳遞給函式。

```cpp
class PerformanceCounter : public System::Object
```
