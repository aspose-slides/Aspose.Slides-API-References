## AuthenticationLevel 列舉


WebRequest 特定的驗證旗標。

```cpp
enum class AuthenticationLevel
```

### 值

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| None | 0 | 客戶端與伺服器均不需要驗證。 |
| MutualAuthRequested | 1 | 如果伺服器未驗證，請求不會失敗。 |
| MutualAuthRequired | 2 | 當伺服器未驗證時，當前應用程式將收到 'IOException'。 |
