## EnumConverter 類別


Dummy 類別 for EnumConverter-using translated code to compile. 此類別的物件僅應使用 [System::MakeObject()](../../system/makeobject/) 函式配置。Never create instance of this type on stack or using operator new, as it will result in runtime errors and/or assertion faults. Always wrap this 類別 into [System::SmartPtr](../../system/smartptr/) 指標並使用此指標作為參數傳遞給函式。

```cpp
class EnumConverter : public System::ComponentModel::TypeConverter
```
