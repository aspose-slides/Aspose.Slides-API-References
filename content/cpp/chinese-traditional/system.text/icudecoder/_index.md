## ICUDecoder 類別

[Decoder](../decoder/) 使用 ICU 進行解碼。此類別的物件應僅透過 [System::MakeObject()](../../system/makeobject/) 函式分配。切勿在堆疊上或使用 operator new 建立此型別的實例，因為這會導致執行階段錯誤和/或斷言失敗。請始終將此類別封裝為 [System::SmartPtr](../../system/smartptr/) 指標，並使用該指標作為參數傳遞給函式。

```cpp
class ICUDecoder : public System::Text::Decoder
```
