## Thread::get_ManagedThreadId() const 方法


取得執行緒的識別碼。可以從作業系統取得，但如果作業系統的執行緒識別碼超過 int 限制，執行緒的 ID 可能會重疊。

```cpp
int System::Threading::Thread::get_ManagedThreadId() const
```


### 返回值

偽唯一的執行緒識別碼。
