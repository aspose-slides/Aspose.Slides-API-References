## IXsltContextFunction::get_ArgTypes() 方法

返回提供的 XML Path Language ([XPath](../../../system.xml.xpath/)) 類型，用於函式的參數清單。此資訊可用於偵測函式的簽名，從而區分重載的函式。

```cpp
virtual ArrayPtr<System::Xml::XPath::XPathResultType> System::Xml::Xsl::IXsltContextFunction::get_ArgTypes()=0
```

### 返回值

一個 XPathResultType 陣列，代表函式參數清單的類型。
