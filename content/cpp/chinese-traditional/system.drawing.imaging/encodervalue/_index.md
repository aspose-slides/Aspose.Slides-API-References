## EncoderValue 列舉

指定傳遞給 JPEG 或 TIFF 圖像編碼器的參數值。

```cpp
enum class EncoderValue
```

### 值

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| ColorTypeCMYK | 0 | CMYK 顏色空間。 |
| ColorTypeYCCK | 1 | YCCK 顏色空間。 |
| CompressionLZW | 2 | LZW 壓縮方法。 |
| CompressionCCITT3 | 3 | 指定 TIFF 影像的 CCITT3 壓縮方法。 |
| CompressionCCITT4 | 4 | 指定 TIFF 影像的 CCITT4 壓縮方法。 |
| CompressionRle | 5 | 指定 TIFF 影像的 RLE 壓縮方法。 |
| CompressionNone | 6 | 指定 TIFF 影像不進行壓縮。 |
| ScanMethodInterlaced | 7 | 交錯模式。 |
| ScanMethodNonInterlaced | 8 | 非交錯模式。 |
| VersionGif87 | 9 | 指定 TIFF 影像的 87 版。 |
| VersionGif89 | 10 | 指定 GIF 影像的 89a 版。 |
| RenderProgressive | 11 | 漸進模式。 |
| RenderNonProgressive | 12 | 非漸進模式。 |
| TransformRotate90 | 13 | 指定 JPEG 影像以無損方式順時針旋轉 90 度。 |
| TransformRotate180 | 14 | 指定 JPEG 影像以無損方式旋轉 180 度。 |
| TransformRotate270 | 15 | 指定 JPEG 影像以無損方式順時針旋轉 270 度。 |
| TransformFlipHorizontal | 16 | 指定 JPEG 影像以無損方式水平翻轉。 |
| TransformFlipVertical | 17 | 指定 JPEG 影像以無損方式垂直翻轉。 |
| MultiFrame | 18 | 多影格編碼。 |
| LastFrame | 19 | 多影格影像的最後一格。 |
| Flush | 20 | 編碼器物件將被關閉。 |
| FrameDimensionTime | 21 | 指定 GIF 影像的時間維度。 |
| FrameDimensionResolution | 22 | 解像度維度。 |
| FrameDimensionPage | 23 | 指定 TIFF 影像的頁面維度。 |
