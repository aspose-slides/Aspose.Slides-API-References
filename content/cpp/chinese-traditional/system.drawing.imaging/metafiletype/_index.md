## MetafileType 列舉


表示圖形圖元檔的類型。

```cpp
enum class MetafileType
```

### 值

| 名稱 | 值 | 描述 |
| --- | --- | --- |
| Invalid | 0 | 無效的圖元檔。 |
| Wmf | 1 | 標準 WMF。 |
| WmfPlaceable | 2 | 可放置的 [Metafile](../metafile/) 格式。 |
| Emf | 3 | EMF（非 EMF+）。 |
| EmfPlusOnly | 4 | EMF+，不含雙向、向下相容的記錄。 |
| EmfPlusDual | 5 | EMF+，具備雙向、向下相容的記錄。 |
