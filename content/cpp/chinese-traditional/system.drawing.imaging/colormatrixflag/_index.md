## ColorMatrixFlag 列舉

說明將受到 [ImageAttributes](../imageattributes/) 物件之顏色與灰階調整設定影響的影像與顏色類型。

```cpp
enum class ColorMatrixFlag
```

### 值

| 名稱 | 數值 | 說明 |
| --- | --- | --- |
| Default | 0 | 同時調整顏色與灰階值的顏色。 |
| SkipGrays | 1 | 灰階值不進行顏色調整。 |
| AltGrays | 2 | 僅調整灰階值的顏色。 |
