## MetafileFrameUnit 列舉

指定用於設定與定位圖形檔的矩形之測量單位。

```cpp
enum class MetafileFrameUnit
```

### 值

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| Pixel | n/a | 指定像素為測量單位。 |
| Point | n/a | 指定印表機的點為測量單位。 |
| Inch | n/a | 指定英吋為測量單位。 |
| Document | n/a | 指定英吋的 1/300 為測量單位。 |
| Millimeter | n/a | 指定公釐為測量單位。 |
| GdiCompatible | n/a | 指定 0.01 公釐為測量單位。提供與 GDI 相容的支援。 |
