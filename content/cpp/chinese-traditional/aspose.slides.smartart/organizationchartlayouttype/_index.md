## OrganizationChartLayoutType 列舉

表示組織圖中子節點的格式類型

```cpp
enum class OrganizationChartLayoutType
```

### Values

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| Initial | 0 | 初始佈局類型 |
| Standart | 1 | 將子節點水平放置於父節點之下。 |
| BothHanging | 2 | 將子節點垂直放置於父節點的左側和右側下方。 |
| LeftHanging | 3 | 將子節點垂直放置於父節點的左側下方。 |
| RightHanging | 4 | 將子節點垂直放置於父節點的右側下方。 |
