## ISSVGOptions::set_DisableLineEndCropping(bool) method


SVG 1.1 缺乏為標記定義內縮的功能。 [Aspose.Slides](../../../aspose.slides/) SVG 寫入引擎提供了此問題的變通方法：它會裁剪帶箭頭的線段末端，從而避免線條與標記重疊。 此選項會關閉此行為。 寫入 **bool**.

```cpp
virtual void Aspose::Slides::Export::ISVGOptions::set_DisableLineEndCropping(bool value)=0
```
