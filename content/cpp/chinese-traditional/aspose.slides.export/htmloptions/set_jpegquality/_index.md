## HtmlOptions::set_JpegQuality(uint8_t) 方法

設定決定 PDF 文件內 JPEG 圖像品質的值。寫入 **uint8_t**。

```cpp
void Aspose::Slides::Export::HtmlOptions::set_JpegQuality(uint8_t value) override
```

## 備註

僅在文件包含 JPEG 圖像時才會產生作用。

使用此屬性在以 PDF 格式儲存時取得或設定文件內圖像的品質。此值可以在 0 到 100 之間變化，其中 0 表示最低品質但最高壓縮，100 表示最高品質但最低壓縮。

預設值為 **95**。
