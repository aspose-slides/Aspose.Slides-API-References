## PdfOptions::set_JpegQuality(uint8_t) 方法


設定一個值，用來決定 PDF 文件中 JPEG 圖像的品質。寫入 **uint8_t**。

```cpp
void Aspose::Slides::Export::PdfOptions::set_JpegQuality(uint8_t value) override
```

## 備註


僅在文件包含 JPEG 圖像時才會生效。

使用此屬性在以 PDF 格式儲存文件時取得或設定文件內圖像的品質。該值可在 0 到 100 之間變化，其中 0 表示最差品質但最高壓縮，100 表示最佳品質但最低壓縮。

預設值為 **100**。
