## PdfOptions::set_EmbedTrueTypeFontsForASCII(bool) 方法

判斷 [Aspose.Slides](../../../aspose.slides/) 是否會為 ASCII (33..127 代碼範圍) 文字嵌入常用字型。[Fonts](../../../aspose.slides/fonts/) 大於 127 的字元代碼始終會被嵌入。常用字型清單包含 PDF 的基本 14 種字型以及使用者指定的其他字型。寫入 **bool**。

```cpp
void Aspose::Slides::Export::PdfOptions::set_EmbedTrueTypeFontsForASCII(bool value) override
```

## 備註

預設為 **true**。
