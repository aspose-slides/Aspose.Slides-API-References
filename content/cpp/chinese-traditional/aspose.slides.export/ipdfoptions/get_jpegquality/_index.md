## IPdfOptions::get_JpegQuality() 方法

傳回決定 PDF 文件內 JPEG 圖像品質的值。讀取 **uint8_t**。

```cpp
virtual uint8_t Aspose::Slides::Export::IPdfOptions::get_JpegQuality()=0
```

## 備註

僅在文件包含 JPEG 圖像時才會產生作用。

使用此屬性可在以 PDF 格式儲存時取得或設定文件內圖像的品質。該值可在 0 到 100 之間變化，其中 0 代表最低品質但最大壓縮，100 代表最高品質但最小壓縮。

預設值為 **100**。
