## IPdfOptions::set_JpegQuality(uint8_t) method

設定一個值，以決定 PDF 文件中 JPEG 圖像的品質。寫入 **uint8_t**。

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_JpegQuality(uint8_t value)=0
```

## 備註

僅在文件包含 JPEG 圖像時才會生效。

在以 PDF 格式儲存時，使用此屬性取得或設定文件內圖像的品質。此值範圍為 0 到 100，其中 0 表示最低品質但最高壓縮，100 表示最高品質但最低壓縮。

預設值為 **100**。
