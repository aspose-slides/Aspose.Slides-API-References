## IPdfOptions::set_BestImagesCompressionRatio(bool) 方法

指示是否應自動為每個圖像選擇最有效的壓縮（而非預設的），如果設定為 **bool**.true，則在簡報中的每個圖像都會選擇最合適的壓縮演算法，從而導致產生的 PDF 文件大小更小。

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_BestImagesCompressionRatio(bool value)=0
```

## 備註

最佳圖像壓縮比的選擇在計算上相當耗費資源，且需要額外的記憶體，且此選項預設為 **bool**.false。

預設為 **bool**.false。
