## Size::Subtract(const Size\&, const Size\&) 方法

返回一個新的 [Size](../) 物件，其結果為 **size2** 從 **size1** 的減法，即其寬度值為 **size1** 的寬度值減去 **size2** 的寬度值，且高度值為 **size1** 的高度值減去 **size2** 的高度值。

```cpp
static Size System::Drawing::Size::Subtract(const Size &size1, const Size &size2)
```

### 參數

| 參數 | 類型 | 說明 |
| --- | --- | --- |
| size1 | const [Size](../)\& | 要從其減去的 [Size](../) 物件 |
| size2 | const [Size](../)\& | 要減去的 [Size](../) 物件 |

### 回傳值

從 **size1** 減去 **size2** 後的結果 [Size](../) 物件
