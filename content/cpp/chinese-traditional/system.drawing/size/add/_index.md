## Size::Add(const Size\&, const Size\&) 方法

返回一個新的 [Size](../) 物件，其為指定 [Size](../) 物件的總和，即其寬度值等於指定物件寬度值的總和，高度值等於指定物件高度值的總和。

```cpp
static Size System::Drawing::Size::Add(const Size &size1, const Size &size2)
```

### 參數

| 參數 | 類型 | 說明 |
| --- | --- | --- |
| size1 | const [Size](../)\& | 第一個運算元 |
| size2 | const [Size](../)\& | 第二個運算元 |

### 回傳值

[Size](../) 物件，即 **size1** 與 **size2** 的總和
