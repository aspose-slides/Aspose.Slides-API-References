## Image::IsAlphaPixelFormat(Imaging::PixelFormat) 方法

Determines if the specified pixel format contains alpha information.

```cpp
static bool System::Drawing::Image::IsAlphaPixelFormat(Imaging::PixelFormat pixfmt)
```

### 參數

| 參數 | 型別 | 說明 |
| --- | --- | --- |
| pixfmt | [Imaging::PixelFormat](../../../system.drawing.imaging/pixelformat/) | 用於測試的像素格式 |

### 返回值

如果 **pixfmt** 包含 alpha 信息則為 true，否則為 false
