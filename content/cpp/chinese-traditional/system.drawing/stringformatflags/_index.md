## StringFormatFlags 列舉

指定文字字串的顯示與版面資訊。

```cpp
enum class StringFormatFlags
```

### 值

| Name | Value | Description |
| --- | --- | --- |
| DirectionRightToLeft | 1 | 從右至左的文字方向。 |
| DirectionVertical | 2 | [Text](../../system.drawing.text/) 垂直對齊。 |
| FitBlackBox | 4 | 字符的部分可以超出布局框。 |
| DisplayFormatControl | 32 | 控制字符將被顯示。 |
| NoFontFallback | 1024 | [Font](../font/) 回退已禁用。 |
| MeasureTrailingSpaces | 2048 | 在每行結尾插入尾隨空格。 |
| NoWrap | 4096 | [Text](../../system.drawing.text/) 換行已禁用。 |
| LineLimit | 8192 | 整行會在格式矩形中排版。 |
| NoClip | 16384 | 允許顯示字形的超出部分。 |
