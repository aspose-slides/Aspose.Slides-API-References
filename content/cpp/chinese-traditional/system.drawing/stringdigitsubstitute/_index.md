## StringDigitSubstitute 列舉

指定根據區域設定或語言，字串中的數字如何被替換。

```cpp
enum class StringDigitSubstitute
```

### 值

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| User | 0 | 使用者自訂的替換方式。 |
| None | 1 | 已停用替換。 |
| National | 2 | 替換對應使用者區域設定之官方國家語言的數字。 |
| Traditional | 3 | 替換對應使用者本土文字或語言的數字，可能與官方國家語言不同。 |
