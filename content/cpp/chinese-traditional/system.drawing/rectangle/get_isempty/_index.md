## Rectangle::get_IsEmpty() const 方法

判斷目前物件所表示的矩形的左上角的 X 與 Y 座標，以及其寬度與高度是否為 0。

```cpp
bool System::Drawing::Rectangle::get_IsEmpty() const
```

### 回傳值

如果 X 與 Y 座標以及寬度與高度為 0，則回傳 true，否則 - false
