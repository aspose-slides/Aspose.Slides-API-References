## ContentAlignment 列舉

指定內容的對齊方式。

```cpp
enum class ContentAlignment
```

### 值

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| TopLeft | 1 | 垂直向上對齊，水平向左對齊。 |
| TopCenter | 2 | 垂直向上對齊，水平居中對齊。 |
| TopRight | 4 | 垂直向上對齊，水平向右對齊。 |
| MiddleLeft | 16 | 垂直居中對齊，水平向左對齊。 |
| MiddleCenter | 32 | 垂直居中對齊，水平居中對齊。 |
| MiddleRight | 64 | 垂直居中對齊，水平向右對齊。 |
| BottomLeft | 256 | 垂直向下對齊，水平向左對齊。 |
| BottomCenter | 512 | 垂直向下對齊，水平居中對齊。 |
| BottomRight | 1024 | 垂直向下對齊，水平向右對齊。 |
