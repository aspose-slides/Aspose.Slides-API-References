## RectangleF::get_IsEmpty() const 方法


判斷目前物件所表示的矩形的左上角 X 與 Y 座標，以及其寬度與高度是否皆為 0。

```cpp
bool System::Drawing::RectangleF::get_IsEmpty() const
```


### 返回值

如果目前物件所表示的矩形的左上角 X 與 Y 座標，以及其寬度與高度皆為 0，則為 True，否則為 false
