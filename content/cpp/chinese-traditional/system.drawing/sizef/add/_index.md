## SizeF::Add(const SizeF\&, const SizeF\&) 方法

返回一個新的 [SizeF](../) 物件，該物件是指定的 [SizeF](../) 物件的總和，即其寬度值等於指定物件的寬度值之和，且高度值等於指定物件的高度值之和。

```cpp
static SizeF System::Drawing::SizeF::Add(const SizeF &size1, const SizeF &size2)
```

### 參數

| 參數 | 類型 | 說明 |
| --- | --- | --- |
| size1 | const [SizeF](../)\& | 第一個運算元 |
| size2 | const [SizeF](../)\& | 第二個運算元 |

### 回傳值

[SizeF](../) 物件，是 **size1** 與 **size2** 的總和
