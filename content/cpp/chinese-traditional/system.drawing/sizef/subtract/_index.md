## SizeF::Subtract(const SizeF\&, const SizeF\&) 方法

返回一個新的 [SizeF](../) 物件，其為 **size2** 從 **size1** 的減法結果，即其寬度值是從 **size1's** 寬度值減去 **size2's** 寬度值的結果，且高度值是從 **size1's** 高度值減去 **size2's** 高度值的結果。

```cpp
static SizeF System::Drawing::SizeF::Subtract(const SizeF &size1, const SizeF &size2)
```

### 參數

| 參數 | 類型 | 說明 |
| --- | --- | --- |
| size1 | const [SizeF](../)\& | 要從其中減去的 [SizeF](../) 物件 |
| size2 | const [SizeF](../)\& | 要減去的 [SizeF](../) 物件 |

### 傳回值

[SizeF](../) 物件，是從 **size1** 減去 **size2** 的結果
