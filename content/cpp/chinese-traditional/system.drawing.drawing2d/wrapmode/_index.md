## WrapMode 列舉


指定當紋理或漸層小於填充區域時的平鋪方式。

```cpp
enum class WrapMode
```

### 值

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| Tile | 0 | 平鋪漸層或紋理。 |
| TileFlipX | 1 | 水平翻轉紋理或漸層，然後平鋪紋理或漸層。 |
| TileFlipY | 2 | 垂直翻轉紋理或漸層，然後平鋪紋理或漸層。 |
| TileFlipXY | 3 | 水平與垂直翻轉紋理或漸層，然後平鋪紋理或漸層。 |
| Clamp | 4 | 將紋理或漸層限制在物件邊界內。 |
