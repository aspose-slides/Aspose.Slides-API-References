## PixelOffsetMode 列舉

指定在渲染時像素的位移方式。

```cpp
enum class PixelOffsetMode
```

### 值

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| Invalid | n/a | 無效的值。 |
| Default | n/a | 預設模式。 |
| HighSpeed | n/a | 低品質（高效能）模式。 |
| HighQuality | n/a | 高品質（效能較低）模式。 |
| None | n/a | 無像素位移。 |
| Half | n/a | 像素在水平和垂直方向上皆偏移 -0.5 單位，以達到高效能的抗鋸齒。 |
