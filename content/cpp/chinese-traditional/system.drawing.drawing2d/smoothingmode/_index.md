## SmoothingMode enum

指定對線條、曲線以及填充區域的邊緣套用何種平滑（抗鋸齒）方式。

```cpp
enum class SmoothingMode
```

### 值

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| Invalid | n/a | 無效值。 |
| Default | n/a | 預設模式，未使用抗鋸齒。 |
| HighSpeed | n/a | 不使用抗鋸齒，高速度。 |
| HighQuality | n/a | 使用抗鋸齒的渲染，低速度。 |
| None | n/a | 不使用抗鋸齒。 |
| AntiAlias | n/a | 使用抗鋸齒的渲染。 |
