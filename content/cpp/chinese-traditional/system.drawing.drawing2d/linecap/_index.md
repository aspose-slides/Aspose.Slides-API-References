## LineCap 列舉

指示 [Pen](../../system.drawing/pen/) 物件可以用來結束線條的可用端樣式。

```cpp
enum class LineCap
```

### 值

| 名稱 | 數值 | 說明 |
| --- | --- | --- |
| Flat | 0 | Flat 線帽。 |
| Square | 1 | Square 線帽。 |
| Round | 2 | Round 線帽。 |
| Triangle | 3 | Triangle 三角形線帽。 |
| NoAnchor | 16 | 無錨點。 |
| SquareAnchor | 17 | Square 錨點線帽。 |
| RoundAnchor | 18 | Round 錨點線帽。 |
| DiamondAnchor | 19 | Diamond 錨點線帽。 |
| ArrowAnchor | 20 | Arrow 錨點線帽。 |
| AnchorMask | 240 | 用於檢查線端是否為錨點端的遮罩。 |
| Custom | 255 | Custom 線帽。 |
