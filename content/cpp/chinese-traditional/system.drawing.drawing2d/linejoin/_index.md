## LineJoin 列舉

指定後續線條或曲線的連接方式。

```cpp
enum class LineJoin
```

### 值

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| Miter | 0 | 產生鋭角或被裁切的角落，取決於斜接長度是否超過斜接限制。 |
| Bevel | 1 | 產生對角角落的斜接。 |
| Round | 2 | 產生線條之間平滑的圓弧。 |
| MiterClipped | 3 | 產生鋭角或斜接角落，取決於斜接長度是否超過斜接限制。 |
