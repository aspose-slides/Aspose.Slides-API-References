## XmlReader::ReadInnerXml() 方法

當在衍生類別中覆寫時，會將所有內容（包括標記）讀取為字串。

```cpp
virtual String System::Xml::XmlReader::ReadInnerXml()
```

### 返回值

目前節點中的所有 XML 內容（包括標記）。如果目前節點沒有子項，則回傳空字串。如果目前節點既不是元素也不是屬性，則回傳空字串。
