## XmlReader::ReadString() method


當在派生類別中覆寫時，會將元素或文字節點的內容讀取為字串。然而，建議改用 [XmlReader::ReadElementContentAsString](../readelementcontentasstring/) 方法，因為它提供了更直接的方式來處理此操作。

```cpp
virtual String System::Xml::XmlReader::ReadString()
```


### 返回值

元素的內容或空字串。
