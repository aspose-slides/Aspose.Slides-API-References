## XmlReader::Read() 方法

When overridden in a derived class, reads the next node from the stream.

```cpp
virtual bool System::Xml::XmlReader::Read()=0
```

### 返回值

**true** 若成功讀取下一個節點，則返回；否則返回 **false**。
