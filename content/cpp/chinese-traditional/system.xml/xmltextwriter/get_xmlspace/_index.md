## XmlTextWriter::get_XmlSpace() method


返回一個 XmlSpace，表示目前 **xml:space** 範圍。

```cpp
System::Xml::XmlSpace System::Xml::XmlTextWriter::get_XmlSpace() override
```


### Return Value

返回一個 XmlSpace，表示目前 **xml:space** 範圍。



| Value | Meaning |
| --- | --- |
| None | 如果不存在 `xml:space` 範圍，則這是預設值。 |
| Default | 目前的範圍是 `xml:space="default"`。 |
| Preserve | 目前的範圍是 `xml:space="preserve"`。 |
