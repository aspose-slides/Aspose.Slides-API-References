## XmlElement::set_IsEmpty(bool) 方法

設定元素的標籤格式。

```cpp
void System::Xml::XmlElement::set_IsEmpty(bool value)
```

### 參數

| 參數 | 類型 | 說明 |
| --- | --- | --- |
| value | **bool** | 要設定的值。設定此值時，如果設為 **true**，元素的子項將被移除，且元素會以短標籤格式序列化。如果設為 **false**，值會被變更（無論元素是否有內容）；若元素為空，則會以長格式序列化。 |
