## XmlAttribute::get_LocalName() 方法


返回節點的本地名稱。

```cpp
String System::Xml::XmlAttribute::get_LocalName() override
```


### 返回值

屬性節點的名稱，已移除前置詞。以下範例 **<book bk:genre= 'novel'>**，該屬性的 **LocalName** 為 **genre**。
