## XmlNodeReader::get_IsDefault() 方法


返回一個值，指示目前的節點是否為從文件類型定義 (DTD) 或模式 中定義的預設值產生的屬性。

```cpp
bool System::Xml::XmlNodeReader::get_IsDefault() override
```


### 返回值

**true** 如果目前的節點是其值從 DTD 或 schema 中定義的預設值產生的屬性； **false** 如果屬性值是明確設定的。
