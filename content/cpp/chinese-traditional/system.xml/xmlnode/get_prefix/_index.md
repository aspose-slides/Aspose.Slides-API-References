## XmlNode::get_Prefix() 方法


傳回此節點的命名空間前置詞。

```cpp
virtual String System::Xml::XmlNode::get_Prefix()
```


### 返回值

此節點的命名空間前置詞。例如，**Prefix** 為 **bk**，對於元素 **<bk:book>**。如果沒有前置詞，此方法傳回 [String::Empty](../../../system/string/empty/)。
