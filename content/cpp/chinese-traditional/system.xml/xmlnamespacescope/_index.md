## XmlNamespaceScope 列舉

定義命名空間的範圍。

```cpp
enum class XmlNamespaceScope
```

### 值

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| All | 0 | 在目前節點的範圍內定義的所有命名空間。這包括始終隱式聲明的 xmlns:xml 命名空間。返回的命名空間順序未定義。 |
| ExcludeXml | 1 | 在目前節點的範圍內定義的所有命名空間，排除始終隱式聲明的 xmlns:xml 命名空間。返回的命名空間順序未定義。 |
| Local | 2 | 在目前節點本地定義的所有命名空間。 |
