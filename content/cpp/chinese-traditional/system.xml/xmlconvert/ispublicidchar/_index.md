## XmlConvert::IsPublicIdChar(char16_t) method

返回傳入的字符實例，如果參數中的字符是有效的 public id 字元，否則返回 **nullptr**。

```cpp
static bool System::Xml::XmlConvert::IsPublicIdChar(char16_t ch)
```

### 參數

| 參數 | 類型 | 描述 |
| --- | --- | --- |
| ch | char16_t | [Char](../../../system/char/) 物件以供驗證。 |

### 返回值

如果字元是有效的 public id 字元，則返回傳入的字元，否則返回 **nullptr**。
