## XmlConvert::VerifyNCName(const String\&) 方法


驗證名稱是否符合 W3C 擴充標記語言建議中的有效 **NCName**。**NCName** 是一種不能包含冒號的名稱。

```cpp
static String System::Xml::XmlConvert::VerifyNCName(const String &name)
```


### 參數

| 參數 | 類型 | 描述 |
| --- | --- | --- |
| name | const [String](../../../system/string/)\& | 要驗證的名稱。 |

### 傳回值

若為有效的 NCName，傳回該名稱。
