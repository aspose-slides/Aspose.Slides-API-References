## XmlWriterSettings::get_NewLineChars() 方法

傳回用於換行的字元字串。

```cpp
String System::Xml::XmlWriterSettings::get_NewLineChars()
```

### 返回值

用於換行的字元字串。此字串可以設定為任何字串值。然而，為了確保 XML 的有效性，您應僅指定有效的空白字元，例如空格字元、定位鍵、回車或換行。預設值為 **\r\n**（回車，換行）。
