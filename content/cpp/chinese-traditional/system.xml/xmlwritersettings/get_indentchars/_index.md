## XmlWriterSettings::get_IndentChars() 方法

返回在縮排時使用的字元字串。當 [XmlWriterSettings::set_Indent](../set_indent/) 的值設定為 **true** 時，會使用此設定。

```cpp
String System::Xml::XmlWriterSettings::get_IndentChars()
```

### 返回值

在縮排時使用的字元字串。此字串可以設定為任何字串值。然而，為確保有效的 XML，您應僅指定有效的空白字元，例如空格、製表符、回車或換行。預設為兩個空格。
