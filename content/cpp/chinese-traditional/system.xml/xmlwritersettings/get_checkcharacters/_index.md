## XmlWriterSettings::get_CheckCharacters() 方法

返回一個值，指示 XML writer 是否應檢查以確保文件中的所有字元符合 W3C [XML 1.0 Recommendation](https://www.w3.org/TR/REC-xml/#charsets) 的 \"2.2 Characters\" 章節。

```cpp
bool System::Xml::XmlWriterSettings::get_CheckCharacters()
```

### 返回值

**true** 代表執行字元檢查；否則為 **false**。預設為 **true**。
