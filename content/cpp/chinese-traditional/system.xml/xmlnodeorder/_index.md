## XmlNodeOrder 列舉

描述節點相對於第二個節點的文件順序。

```cpp
enum class XmlNodeOrder
```

### 值

| 名稱 | 值 | 描述 |
| --- | --- | --- |
| Before | 0 | 此導航器的當前節點位於提供的導航器的當前節點之前。 |
| After | 1 | 此導航器的當前節點位於提供的導航器的當前節點之後。 |
| Same | 2 | 兩個導航器定位於同一個節點。 |
| Unknown | 3 | 無法確定節點在文件順序中的相對位置。若兩個節點位於不同的樹中，可能會出現此情況。 |
