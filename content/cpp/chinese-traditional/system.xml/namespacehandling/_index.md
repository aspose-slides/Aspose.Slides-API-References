## NamespaceHandling 列舉

指定是否在 [XmlWriter](../xmlwriter/) 中移除重複的命名空間宣告。

```cpp
enum class NamespaceHandling
```

### 值

| 名稱 | 數值 | 說明 |
| --- | --- | --- |
| Default | 0 | 指定不會移除重複的命名空間宣告。 |
| OmitDuplicates | 1 | 指定會移除重複的命名空間宣告。若要移除重複的命名空間，前置詞和命名空間必須相符。 |
