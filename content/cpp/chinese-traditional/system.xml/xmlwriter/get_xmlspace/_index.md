## XmlWriter::get_XmlSpace() 方法


當在衍生類別中被覆寫時，取得表示目前 **xml:space** 範圍的 XmlSpace。

```cpp
virtual System::Xml::XmlSpace System::Xml::XmlWriter::get_XmlSpace()
```


### 返回值

表示目前 **xml:space** 範圍的 XmlSpace。



| 值 | 含義 |
| --- | --- |
| `None`| 如果沒有 `xml:space` 範圍，這是預設值。 |
| `Default`| 目前的範圍是 `xml:space="default"`。 |
| `Preserve`| 目前的範圍是 `xml:space="preserve"`。 |
