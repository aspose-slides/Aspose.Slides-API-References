## WhitespaceHandling enum


指定如何處理空白字元。

```cpp
enum class WhitespaceHandling
```

### 值

| 名稱 | 值 | 描述 |
| --- | --- | --- |
| All | 0 | 傳回 **Whitespace** 和 **SignificantWhitespace** 節點。這是預設值。 |
| Significant | 1 | 僅傳回 **SignificantWhitespace** 節點。 |
| None | 2 | 不傳回 **Whitespace** 也不傳回 **SignificantWhitespace** 節點。 |
