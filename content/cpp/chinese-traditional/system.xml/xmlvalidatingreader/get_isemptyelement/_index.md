## XmlValidatingReader::get_IsEmptyElement() method


傳回一個值，指示目前節點是否為空元素（例如，**<MyElement/>**）。

```cpp
bool System::Xml::XmlValidatingReader::get_IsEmptyElement() override
```


### Return Value

**true** 如果目前節點是一個以 **/>** 結束的元素（[XmlValidatingReader::get_NodeType](../get_nodetype/) 值等於 [XmlNodeType::Element](../../xmlnodetype/)）；否則，**false**。
