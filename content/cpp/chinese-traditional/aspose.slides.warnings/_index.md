## 類別

| 類別 | 說明 |
| --- | --- |
| [IKnownIssueWarningInfo](./iknownissuewarninginfo/) | 表示有關已知問題的警告，該問題在近期內不會被修復。 |
| [INotImplementedWarningInfo](./inotimplementedwarninginfo/) | 表示有關已知未實作功能的警告，該功能在近期內不會被實作。 |
| [IObsoletePresLockingBehaviorWarningInfo](./iobsoletepreslockingbehaviorwarninginfo/) | 此警告表示使用了已過時的簡報鎖定行為。 |
| [IPresentationSignedWarningInfo](./ipresentationsignedwarninginfo/) | 此警告表示正在讀取的簡報具有簽章，且該簽章將在處理過程中被移除。 |
| [IWarningCallback](./iwarningcallback/) | 接收警告的類別介面 |
| [IWarningInfo](./iwarninginfo/) | 表示所有警告的基礎介面。 |
