## RSACryptoServiceProvider::get_UseMachineKeyStore() metoda


Kontroluje, zda se klíč uchovává v úložišti stroje místo v úložišti uživatele.

```cpp
static bool System::Security::Cryptography::RSACryptoServiceProvider::get_UseMachineKeyStore()
```


### Návratová hodnota

True pokud by měl být klíč uložen v úložišti stroje, false pokud by měl být uložen v uživatelském úložišti.
