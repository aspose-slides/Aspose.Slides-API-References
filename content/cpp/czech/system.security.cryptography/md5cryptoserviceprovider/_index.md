## MD5CryptoServiceProvider třída


CSP-compatible [MD5](../md5/) algorithm. Not implemented. Objects of this třídy should only be allocated using [System::MakeObject()](../../system/makeobject/) function. Never create instance of this type on stack or using operator new, as it will result in runtime errors and/or assertion faults. Always wrap this třídu into [System::SmartPtr](../../system/smartptr/) pointer and use this pointer to pass it to functions as argument.

```cpp
class MD5CryptoServiceProvider : public System::Security::Cryptography::MD5
```
