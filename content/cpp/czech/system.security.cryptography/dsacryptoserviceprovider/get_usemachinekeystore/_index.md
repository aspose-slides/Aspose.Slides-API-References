## DSACryptoServiceProvider::get_UseMachineKeyStore() metoda


Kontroluje, zda se klíč ukládá v úložišti stroje místo v úložišti uživatele.

```cpp
static bool System::Security::Cryptography::DSACryptoServiceProvider::get_UseMachineKeyStore()
```


### Návratová hodnota

True pokud by měl být klíč uložen v úložišti stroje, false pokud by měl být klíč uložen v úložišti uživatele.
