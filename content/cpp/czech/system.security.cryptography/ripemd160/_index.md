## RIPEMD160 třída

Vypočítá [RIPEMD160](./) hash pro vstupní data. V C++ [RIPEMD160](./) není abstraktní třída. Objekty této třídy by měly být alokovány pouze pomocí funkce [System::MakeObject()](../../system/makeobject/). Nikdy nevytvářejte instance tohoto typu na zásobníku ani pomocí operátoru new, protože to povede k běhovým chybám a/nebo asertačním chybám. Vždy zabalte tuto třídu do ukazatele [System::SmartPtr](../../system/smartptr/) a použijte tento ukazatel k předání funkci jako argument.

```cpp
class RIPEMD160 : public System::Security::Cryptography::HashAlgorithm
```
