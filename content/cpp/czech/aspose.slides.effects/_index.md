| [AlphaBiLevel](./alphabilevel/) | Reprezentuje efekt Alpha Bi-Level. Hodnoty Alpha (Opacity) menší než práh jsou změněny na 0 (zcela průhledné) a hodnoty Alpha větší nebo rovny prahu jsou změněny na 100 % (zcela neprůhledné). |
| [AlphaCeiling](./alphaceiling/) | Reprezentuje efekt Alpha Ceiling. Hodnoty Alpha (opacity) větší než nula jsou změněny na 100 %. Jinak řečeno, cokoliv částečně neprůhledného se stane zcela neprůhledným. |
| [AlphaFloor](./alphafloor/) | Reprezentuje efekt Alpha Floor. Hodnoty Alpha (opacity) menší než 100 % jsou změněny na nulu. Jinak řečeno, cokoliv částečně průhledného se stane zcela průhledným. |
| [AlphaInverse](./alphainverse/) | Reprezentuje efekt Alpha Inverse. Hodnoty Alpha (opacity) jsou invertovány odečtením od 100 %. |
