## StringCollection::crend() const metoda

Vrací reverzní iterátor na prvek následující po posledním prvku reverzovaného kontejneru. Odpovídá prvku předcházejícímu prvnímu prvku ne-reverzovaného kontejneru. Tento prvek slouží jako zástupce, pokus o jeho přístup vede k nedefinovanému chování.

```cpp
const_reverse_iterator System::Collections::Specialized::StringCollection::crend() const noexcept
```

### Návratová hodnota

Iterátor ukazující na teoretický const-kvalifikovaný prvek předcházející prvnímu prvku kontejneru.
