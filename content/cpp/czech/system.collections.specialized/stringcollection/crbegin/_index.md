## StringCollection::crbegin() const metoda


Vrací reverzní iterátor na první prvek obráceného kontejneru. Odpovídá poslednímu prvku neobráceného kontejneru. Pokud je kontejner prázdný, vrácený iterátor je roven [crend()](../crend/).

```cpp
const_reverse_iterator System::Collections::Specialized::StringCollection::crbegin() const noexcept
```


### Návratová hodnota

Iterátor ukazující na poslední element kontejneru, který je const-qualified.
