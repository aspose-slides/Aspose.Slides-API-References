## EnumeratorSelectManyAdapter::MoveNext() metoda

Posouvá enumerátor na další prvek. Pokud nebyl předtím odkazován žádný prvek, nastaví odkaz na první dostupný prvek. Pokud byl dosažen konec kontejneru, neprovede nic.

```cpp
bool System::Collections::Generic::Details::EnumeratorSelectManyAdapter<Source, Result>::MoveNext() override
```

### Návratová hodnota

True pokud je po volání dostupný nějaký prvek, false jinak.
