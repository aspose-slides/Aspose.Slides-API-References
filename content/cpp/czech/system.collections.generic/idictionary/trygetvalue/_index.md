## IDictionary::TryGetValue(const TKey\&, TValue\&) const metoda

Looks for value and retreives it if found.

```cpp
virtual bool System::Collections::Generic::IDictionary<TKey, TValue>::TryGetValue(const TKey &key, TValue &value) const =0
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| key | const TKey\& | Klíč, který se hledá. |
| value | TValue\& | Reference, do které se uloží získaná hodnota. |

### Návratová hodnota

True pokud byla hodnota nalezena a získána, jinak false.
