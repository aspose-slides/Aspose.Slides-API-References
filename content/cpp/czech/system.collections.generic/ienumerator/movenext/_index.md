## IEnumerator::MoveNext() metoda

Posune enumerátor na další prvek. Pokud předtím nebyl odkazován žádný prvek, nastaví odkaz na první dostupný prvek. Pokud byl dosažen konec kontejneru, nedělá nic.

```cpp
virtual bool System::Collections::Generic::IEnumerator<T>::MoveNext()=0
```

### Návratová hodnota

True pokud je po volání k dispozici nějaký prvek, false jinak.
