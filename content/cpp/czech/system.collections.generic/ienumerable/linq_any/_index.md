## IEnumerable::LINQ_Any() metoda


Určuje, zda sekvence obsahuje nějaké prvky.

```cpp
bool System::Collections::Generic::IEnumerable<T>::LINQ_Any()
```


### Návratová hodnota

true, pokud zdrojová sekvence obsahuje nějaké prvky; jinak false.
