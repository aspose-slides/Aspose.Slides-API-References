## Details_SemaphoreFullException::Is(const System::TypeInfo\&) const method




```cpp
bool System::Threading::Details_SemaphoreFullException::Is(const System::TypeInfo &target) const override
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| target | const [System::TypeInfo](../../../system/typeinfo/)\& | [TypeInfo](../../../system/typeinfo/) struktura popisující typ, vůči kterému se testuje aktuální objekt. |

### Návratová hodnota

True, pokud je objekt označeného typu nebo jeho podtřídy, false jinak.
## Poznámky

Zkontroluje, zda objekt představuje instanci typu popsaného pomocí targetType. Analogie k operátoru C# 'is' operator.
