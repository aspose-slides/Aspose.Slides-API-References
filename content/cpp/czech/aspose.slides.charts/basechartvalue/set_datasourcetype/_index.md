## BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType) metoda


Určuje, zda je v potomcích skutečná vlastnost AsCell, AsCells, AsLiteralString nebo AsLiteralDouble. Jinak řečeno určuje typ hodnoty vlastnosti Data. Zapište [Charts::DataSourceType](../../datasourcetype/).

```cpp
void Aspose::Slides::Charts::BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType value) override
```

## Poznámky


Pro body v [ChartDataPointCollection](../../chartdatapointcollection/) je tato vlastnost jen pro čtení. V tomto případě můžete pro změnu hodnoty této vlastnosti použít jednu z vlastností ChartDataPointCollection.DataSourceTypeFor<...>.
