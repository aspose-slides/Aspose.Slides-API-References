## ChartCategory::get_UseCell() metoda

Pokud je true, pak je vlastnost AsCell aktuální. Jinými slovy, list se používá k ukládání kategorie (tento případ podporuje vícestupňovou kategorii). Pokud je false, pak je vlastnost AsLiteral aktuální. Jinými slovy, list NENÍ používán k ukládání kategorie (a tento případ nepodporuje vícestupňové kategorie). Pouze pro čtení **bool**.

```cpp
bool Aspose::Slides::Charts::ChartCategory::get_UseCell() override
```

## Poznámky

Pro změnu hodnoty této vlastnosti (pro všechny kategorie ve sbírce) nastavte novou hodnotu vlastnosti ChartCategoryCollection::get(set)_UseCells.
