## DataSourceType enum


Typy zdrojů dat.

```cpp
enum class DataSourceType
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| Worksheet | 0 | Použijte objekty CellXls pro ukládání XValue, YValue, Value nebo BubbleSize datového bodu v listu. |
| StringLiterals | 1 | Použijte rychlý přístup k řetězcové proměnné pro ukládání XValue, YValue, Value nebo BubbleSize datového bodu. Worksheet NENÍ používán pro ukládání hodnot. |
| DoubleLiterals | 2 | Použijte rychlý přístup k double proměnné pro ukládání XValue, YValue, Value nebo BubbleSize datového bodu. Worksheet NENÍ používán pro ukládání hodnot. |
