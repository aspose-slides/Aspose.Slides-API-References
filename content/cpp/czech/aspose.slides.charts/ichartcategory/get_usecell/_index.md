## IChartCategory::get_UseCell() metoda

Pokud je true, pak je vlastnost AsCell aktuální. Jinými slovy, list se používá pro ukládání kategorií (tento případ podporuje vícestupňovou kategorii). Pokud je false, pak je vlastnost AsLiteral aktuální. Jinými slovy, list NENÍ použit pro ukládání kategorií (a tento případ nepodporuje vícestupňové kategorie). Pouze ke čtení **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IChartCategory::get_UseCell()=0
```

## Poznámky

Pro změnu hodnoty této vlastnosti (pro všechny kategorie ve sbírce) nastavte novou hodnotu vlastnosti ChartCategoryCollection.UseCells.
