## ChartCategoryCollection::set_UseCells(bool) metoda

Pokud je true, pak se list použije pro ukládání kategorií (tento případ podporuje víceúrovňové kategorie). Pokud je false, pak se list NEPOUŽÍVÁ pro ukládání hodnot (a tento případ nepodporuje víceúrovňové kategorie). Zapište **bool**.
