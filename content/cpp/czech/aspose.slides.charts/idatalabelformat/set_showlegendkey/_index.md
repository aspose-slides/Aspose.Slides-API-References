## IDataLabelFormat::set_ShowLegendKey(bool) metoda

Representuje chování zobrazení legendy klíče popisku dat specifikovaného grafu. True, pokud je legenda klíče popisku dat viditelná. Zapište **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowLegendKey(bool value)=0
```

## Poznámky

Pokud je rodič tohoto objektu [DataLabelFormat](../../datalabelformat/) [DataLabelCollection](../../datalabelcollection/) kolekcí datových popisků, pak tato vlastnost získá nebo nastaví výchozí hodnotu vlastnosti ShowLegendKey pro nové datové popisky v kolekci [DataLabelCollection](../../datalabelcollection/). Nastavení této vlastnosti s hodnotou také nastaví tuto hodnotu do vlastnosti ShowLegendKey pro všechny datové popisky v kolekci [DataLabelCollection](../../datalabelcollection/) (tj. \"DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;\" způsobí, že všechny DataLabels[i].ShowLegendKey jsou rovny val).
