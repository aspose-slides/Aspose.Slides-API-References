## IDataLabelFormat::set_ShowLabelValueFromCell(bool) method

Reprezentuje chování zobrazování hodnoty buňky datové značky specifického grafu. True zobrazí hodnotu buňky. False skrývá. Zapište **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowLabelValueFromCell(bool value)=0
```

## Poznámky

Pokud je rodič tohoto [DataLabelFormat](../../datalabelformat/) objektu [DataLabelCollection](../../datalabelcollection/) kolekcí datových značek, pak tato vlastnost získá nebo nastaví výchozí hodnotu vlastnosti ShowLabelValueFromCell pro nové datové značky v kolekci [DataLabelCollection](../../datalabelcollection/). Nastavením této vlastnosti na hodnotu se také nastaví tato hodnota pro vlastnost ShowLabelValueFromCell u všech datových značek v kolekci [DataLabelCollection](../../datalabelcollection/) (t.j. \"DataLabels.DefaultDataLabelFormat.ShowLabelValueFromCell = val;\" způsobí, že všechny DataLabels[i].ShowLabelValueFromCell jsou rovny val).
