## IDataLabelFormat::set_ShowLeaderLines(bool) metoda


Representuje chování zobrazení vodicích čar popisků dat určeného grafu. True zobrazuje vodící čáry. False skrývá. Zapište **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowLeaderLines(bool value)=0
```

## Poznámky


Pokud je nadřazený objekt tohoto [DataLabelFormat](../../datalabelformat/) [DataLabelCollection](../../datalabelcollection/) sbírkou popisků dat, pak tato vlastnost získá nebo nastaví výchozí hodnotu vlastnosti ShowLeaderLines pro nové popisky dat ve [DataLabelCollection](../../datalabelcollection/) sbírce. Nastavení této vlastnosti s hodnotou také nastaví tuto hodnotu vlastnosti ShowLeaderLines pro všechny popisky dat ve [DataLabelCollection](../../datalabelcollection/) sbírce (i.e. "DataLabels.DefaultDataLabelFormat.ShowLeaderLines = val;" způsobí, že všechny DataLabels[i].ShowLeaderLines jsou rovny val).
