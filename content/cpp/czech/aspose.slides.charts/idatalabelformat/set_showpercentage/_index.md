## IDataLabelFormat::set_ShowPercentage(bool) metoda


Reprezentuje chování zobrazování procentuální hodnoty popisku dat specifikovaného grafu. True zobrazí procentuální hodnotu. False skryje. Zapište **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowPercentage(bool value)=0
```

## Poznámky


Pokud je rodič tohoto [DataLabelFormat](../../datalabelformat/) objektu [DataLabelCollection](../../datalabelcollection/) kolekcí popisků dat, pak tato vlastnost získá nebo nastaví výchozí hodnotu vlastnosti ShowPercentage pro nové popisky dat v kolekci [DataLabelCollection](../../datalabelcollection/). Nastavením této vlastnosti na hodnotu se také nastaví tato hodnota do vlastnosti ShowPercentage pro všechny popisky dat v kolekci [DataLabelCollection](../../datalabelcollection/) (tj. "DataLabels.DefaultDataLabelFormat.ShowPercentage = val;" způsobí, že všechny DataLabels[i].ShowPercentage jsou rovny val).
