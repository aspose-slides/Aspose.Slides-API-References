## IDataLabelFormat::get_ShowBubbleSize() metoda

Reprezentuje chování zobrazení hodnoty velikosti bubliny popisku dat určeného grafu. True zobrazuje hodnotu velikosti bubliny. False pro skrytí. Číst **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowBubbleSize()=0
```

## Poznámky

Pokud je nadřazeným objektu [DataLabelFormat](../../datalabelformat/) kolekce [DataLabelCollection](../../datalabelcollection/) popisků dat, pak tato vlastnost získá nebo nastaví výchozí hodnotu vlastnosti ShowBubbleSize pro nové popisky dat v kolekci [DataLabelCollection](../../datalabelcollection/). Nastavením této vlastnosti na hodnotu také nastaví tuto hodnotu pro vlastnost ShowBubbleSize všech popisků dat v kolekci [DataLabelCollection](../../datalabelcollection/) (i.e. \"DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;\" způsobí, že všechny DataLabels[i].ShowBubbleSize jsou rovny val).
