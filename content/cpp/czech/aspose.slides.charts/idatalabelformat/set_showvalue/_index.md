## IDataLabelFormat::set_ShowValue(bool) metoda

Reprezentuje chování zobrazování procentuální hodnoty popisku dat specifikovaného grafu. True zobrazí procentuální hodnotu. False ji skryje. Zapište **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowValue(bool value)=0
```

## Poznámky

Pokud je nadřazený objekt [DataLabelFormat](../../datalabelformat/) součástí kolekce [DataLabelCollection](../../datalabelcollection/) popisků dat, pak tato vlastnost získává nebo nastavuje výchozí hodnotu vlastnosti ShowValue pro nové popisky dat v kolekci [DataLabelCollection](../../datalabelcollection/). Nastavení této vlastnosti s hodnotou také nastaví tuto hodnotu vlastnosti ShowValue pro všechny popisky dat v kolekci [DataLabelCollection](../../datalabelcollection/) (tj. "DataLabels.DefaultDataLabelFormat.ShowValue = val;" způsobí, že všechny DataLabels[i].ShowValue jsou rovny val).
