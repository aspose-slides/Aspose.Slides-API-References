## IDataLabelFormat::get_ShowLeaderLines() metoda


Reprezentuje chování zobrazení úvodních čar popisků dat určeného grafu. True zobrazí úvodní čáry. False skryje. čte **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowLeaderLines()=0
```

## Poznámky


Pokud je rodič tohoto [DataLabelFormat](../../datalabelformat/) objektu kolekcí [DataLabelCollection](../../datalabelcollection/) popisků dat, pak tato vlastnost získá nebo nastaví výchozí hodnotu vlastnosti ShowLeaderLines pro nové popisky dat v kolekci [DataLabelCollection](../../datalabelcollection/). Nastavením této vlastnosti na hodnotu se tato hodnota také nastaví do vlastnosti ShowLeaderLines pro všechny popisky dat v kolekci [DataLabelCollection](../../datalabelcollection/) (i.e. "DataLabels.DefaultDataLabelFormat.ShowLeaderLines = val;" cause to all DataLabels[i].ShowLeaderLines is equal to val).
