## IDataLabelFormat::set_IsNumberFormatLinkedToSource(bool) metoda

Zapisuje **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_IsNumberFormatLinkedToSource(bool value)=0
```

## Poznámky

Pokud je nadřazený objekt tohoto [DataLabelFormat](../../datalabelformat/) součástí kolekce [DataLabelCollection](../../datalabelcollection/) popisků dat, pak tato vlastnost získá nebo nastaví výchozí hodnotu vlastnosti IsNumberFormatLinkedToSource pro nové popisky dat v kolekci [DataLabelCollection](../../datalabelcollection/). Nastavením této vlastnosti na hodnotu se také nastaví tato hodnota do vlastnosti IsNumberFormatLinkedToSource pro všechny popisky dat v kolekci [DataLabelCollection](../../datalabelcollection/) (tj. \"DataLabels.DefaultDataLabelFormat.IsNumberFormatLinkedToSource = val;\" způsobí, že všechna DataLabels[i].IsNumberFormatLinkedToSource jsou rovna val).
