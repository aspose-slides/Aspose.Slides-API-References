## IChartCategoryCollection::get_UseCells() metoda

Pokud je true, pak se list používá pro ukládání kategorií (tento případ podporuje víceúrovňové kategorie). Pokud je false, pak se list NE používá pro ukládání hodnot (a tento případ nepodporuje víceúrovňové kategorie). Čtení **bool**.

virtual bool Aspose::Slides::Charts::IChartCategoryCollection::get_UseCells()=0
