## IChartCategoryCollection::set_UseCells(bool) metoda

Pokud je true, pak se sešit používá k ukládání kategorií (tento případ podporuje víceúrovňové kategorie). Pokud je false, pak se sešit NEpoužívá k ukládání hodnot (a tento případ nepodporuje víceúrovňové kategorie). Zapište **bool**.

virtual void Aspose::Slides::Charts::IChartCategoryCollection::set_UseCells(bool value)=0
