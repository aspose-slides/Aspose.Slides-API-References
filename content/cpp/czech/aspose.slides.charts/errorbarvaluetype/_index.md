## ErrorBarValueType výčet

Reprezentuje typ hodnoty chybového pruhu

```cpp
enum class ErrorBarValueType
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| Custom | 0 | Určuje, že délka chybových pruhů bude určena prvky Plus a Minus. |
| Fixed | 1 | Určuje, že délka chybových pruhů bude pevná hodnota určená pomocí Error Bar Value. |
| Percentage | 2 | Určuje, že délka chybových pruhů bude procento Error Bar Value z dat. |
| StandardDeviation | 3 | Určuje, že délka chybových pruhů bude standardní odchylka Error Bar Value z dat. |
| StandardError | 4 | Určuje, že délka chybových pruhů bude standardní chyba Error Bar Value z dat. |
