## IDataLabel::Hide() metoda


Skryjte popisek dat nastavením všech příznaků Show*-flags (ShowValue, ...) do stavu false. IsVisible bude po tomto nastavení false.

```cpp
virtual void Aspose::Slides::Charts::IDataLabel::Hide()=0
```

## Poznámky


Pokud popisek dat není viditelný (IsVisible je false), můžete popisek dat zobrazit nastavením příznaků Show*-flags (ShowValue, ...) do stavu true.
