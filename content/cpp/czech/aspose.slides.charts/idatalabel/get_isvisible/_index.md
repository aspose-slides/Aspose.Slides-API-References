## IDataLabel::get_IsVisible() metoda

False znamená, že popisek dat není viditelný (a proto jsou všechny příznaky Show*-flags (ShowValue, ...) nepravdivé). Pouze pro čtení **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabel::get_IsVisible()=0
```

## Poznámky

Pokud je popisek dat viditelný, můžete jej skrýt pomocí metody [Hide()](../hide/). Ale pokud popisek dat není viditelný (IsVisible je false), můžete popisek dat zobrazit nastavením příznaků Show*-flags (ShowValue, ...) na true stav.
