## LayoutTargetType enum

If layout of the plot area defined manually this property specifies whether to layout the plot area by its inside (not including axis and axis labels) or outside (including axis and axis labels).

```cpp
enum class LayoutTargetType
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| Inner | 0 | Určuje, že velikost vykreslovací oblasti určuje velikost vykreslovací oblasti, bez značek a popisků os. |
| Outer | 1 | Určuje, že velikost vykreslovací oblasti určuje velikost vykreslovací oblasti, značky a popisky os. |
