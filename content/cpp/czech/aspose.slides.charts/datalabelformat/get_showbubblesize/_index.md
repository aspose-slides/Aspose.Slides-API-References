## DataLabelFormat::get_ShowBubbleSize() metoda

Reprezentuje chování zobrazení hodnoty velikosti bubliny popisku dat specifikovaného grafu. True zobrazí hodnotu velikosti bubliny. False ji skryje. Čtení **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowBubbleSize() override
```

## Poznámky

Pokud je nadřazený objekt tohoto [DataLabelFormat](../) a jedná se o kolekci [DataLabelCollection](../../datalabelcollection/) popisků dat, pak tato vlastnost získá nebo nastaví výchozí hodnotu vlastnosti ShowBubbleSize pro nové popisky dat ve sbírce [DataLabelCollection](../../datalabelcollection/). Nastavením této vlastnosti s hodnotou se také nastaví tato hodnota do vlastnosti ShowBubbleSize pro všechny popisky dat ve sbírce [DataLabelCollection](../../datalabelcollection/) (např. "DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;" způsobí, že všechny DataLabels[i].ShowBubbleSize jsou rovny val).
