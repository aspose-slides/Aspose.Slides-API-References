## DataLabelFormat::set_ShowValue(bool) metoda


Reprezentuje chování zobrazování procentuální hodnoty popisku dat určeného grafu. True zobrazí procentuální hodnotu. False ji skryje. Zapište **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowValue(bool value) override
```

## Remarks


Pokud je nadřazený element tohoto objektu [DataLabelFormat](../) kolekcí [DataLabelCollection](../../datalabelcollection/) popisků dat, pak tato vlastnost získá nebo nastaví výchozí hodnotu vlastnosti ShowValue pro nové popisky dat v kolekci [DataLabelCollection](../../datalabelcollection/). Nastavením této vlastnosti na hodnotu se také nastaví tato hodnota vlastnosti ShowValue pro všechny popisky dat v kolekci [DataLabelCollection](../../datalabelcollection/) (např. \"DataLabels.DefaultDataLabelFormat.ShowValue = val;\" způsobí, že všechny DataLabels[i].ShowValue jsou rovny val).
