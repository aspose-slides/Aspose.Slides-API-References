## DataLabelFormat::set_Position(LegendDataLabelPosition) metoda


Representuje polohu datového popisku. Zapište [LegendDataLabelPosition](../../legenddatalabelposition/).

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_Position(LegendDataLabelPosition value) override
```

## Poznámky


Pokud je nadřazený objekt tohoto [DataLabelFormat](../) typu [DataLabelCollection](../../datalabelcollection/) sbírkou datových popisků, pak tato vlastnost získá nebo nastaví výchozí hodnotu vlastnosti Position pro nové datové popisky ve sbírce [DataLabelCollection](../../datalabelcollection/). Representuje polohu pro objekty [DataLabel](../../datalabel/). Nastavení této vlastnosti na hodnotu také nastaví tuto hodnotu do vlastnosti Position pro všechny datové popisky ve sbírce [DataLabelCollection](../../datalabelcollection/) (např. \"DataLabels.DefaultDataLabelFormat.Position = val;\" což způsobí, že všechny DataLabels[i].Position mají stejnou hodnotu val).
