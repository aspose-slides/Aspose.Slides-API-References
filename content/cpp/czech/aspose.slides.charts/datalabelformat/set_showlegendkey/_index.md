## DataLabelFormat::set_ShowLegendKey(bool) metoda

Representuje chování zobrazení klíče legendy popisku dat určeného grafu. True, pokud je klíč legendy popisku dat viditelný. Zapište **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLegendKey(bool value) override
```

## Poznámky

Pokud je nadřazený objekt tohoto [DataLabelFormat](../) typu [DataLabelCollection](../../datalabelcollection/) kolekce popisků dat, pak tato vlastnost získá nebo nastaví výchozí hodnotu vlastnosti ShowLegendKey pro nové popisky dat v kolekci [DataLabelCollection](../../datalabelcollection/). Nastavení této vlastnosti s hodnotou také nastaví tuto hodnotu pro vlastnost ShowLegendKey všech popisků dat v kolekci [DataLabelCollection](../../datalabelcollection/) (např. "DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;" způsobí, že všechny DataLabels[i].ShowLegendKey jsou rovny val).
