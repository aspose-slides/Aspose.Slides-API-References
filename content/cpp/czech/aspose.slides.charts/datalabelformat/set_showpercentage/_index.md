## DataLabelFormat::set_ShowPercentage(bool) metoda


Reprezentuje chování zobrazování hodnoty procenta popisku dat pro zadaný graf. True zobrazí hodnotu procenta. False skryje. Zapište **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowPercentage(bool value) override
```

## Poznámky


Pokud je nadřazeným prvkem tohoto objektu [DataLabelFormat](../) [DataLabelCollection](../../datalabelcollection/) kolekce popisků dat, pak tato vlastnost získává nebo nastavuje výchozí hodnotu vlastnosti ShowPercentage pro nové popisky dat v kolekci [DataLabelCollection](../../datalabelcollection/). Nastavení této vlastnosti s hodnotou také nastaví tuto hodnotu vlastnosti ShowPercentage pro všechny popisky dat v kolekci [DataLabelCollection](../../datalabelcollection/) (tj. \"DataLabels.DefaultDataLabelFormat.ShowPercentage = val;\" způsobí, že všechny DataLabels[i].ShowPercentage jsou rovny val).
