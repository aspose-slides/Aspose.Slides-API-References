## DataLabelFormat::set_ShowLeaderLines(bool) metoda

Představuje chování zobrazování čar ukazatelů popisků dat pro konkrétní graf. True zobrazí čáry ukazatelů. False pro skrytí. Zapisujte **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLeaderLines(bool value) override
```

## Poznámky

Pokud je nadřazeným prvkem tohoto objektu [DataLabelFormat](../) kolekce [DataLabelCollection](../../datalabelcollection/) popisků dat, pak tato vlastnost získá nebo nastaví výchozí hodnotu vlastnosti ShowLeaderLines pro nové popisky dat v kolekci [DataLabelCollection](../../datalabelcollection/). Nastavení této vlastnosti na hodnotu také nastaví tuto hodnotu vlastnosti ShowLeaderLines pro všechny popisky dat v kolekci [DataLabelCollection](../../datalabelcollection/) (tj. "DataLabels.DefaultDataLabelFormat.ShowLeaderLines = val;" způsobí, že všechny DataLabels[i].ShowLeaderLines jsou rovny val).
