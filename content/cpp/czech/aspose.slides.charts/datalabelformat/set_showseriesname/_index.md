## DataLabelFormat::set_ShowSeriesName(bool) metoda


Nastavuje Boolean, který určuje chování zobrazování názvu série u datových popisků v grafu. True pro zobrazení názvu série. False pro skrytí. Zapište **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowSeriesName(bool value) override
```

## Poznámky


Pokud je nadřazený objekt tohoto [DataLabelFormat](../) objektu [DataLabelCollection](../../datalabelcollection/) kolekcí datových popisků, pak tato vlastnost získá nebo nastaví výchozí hodnotu vlastnosti ShowSeriesName pro nové datové popisky v kolekci [DataLabelCollection](../../datalabelcollection/). Nastavením této vlastnosti na hodnotu také nastavíte tuto hodnotu pro vlastnost ShowSeriesName u všech datových popisků v kolekci [DataLabelCollection](../../datalabelcollection/) (např. \"DataLabels.DefaultDataLabelFormat.ShowSeriesName = val;\" způsobí, že všechny DataLabels[i].ShowSeriesName jsou rovny val).
