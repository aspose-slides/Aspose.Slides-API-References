## DataLabelFormat::get_ShowLeaderLines() metoda


Reprezentuje chování zobrazení čar vodítek datových popisků specifikovaného grafu. True zobrazuje vodící čáry. False pro skrytí. Čte se **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowLeaderLines() override
```

## Poznámky


Pokud je rodič tohoto objektu [DataLabelFormat](../) kolekcí [DataLabelCollection](../../datalabelcollection/) datových popisků, pak tato vlastnost získá nebo nastaví výchozí hodnotu vlastnosti ShowLeaderLines pro nové datové popisky v kolekci [DataLabelCollection](../../datalabelcollection/). Nastavení této vlastnosti na hodnotu také nastaví tuto hodnotu pro vlastnost ShowLeaderLines u všech datových popisků v kolekci [DataLabelCollection](../../datalabelcollection/) (i.e. \"DataLabels.DefaultDataLabelFormat.ShowLeaderLines = val;\" způsobí, že všechny DataLabels[i].ShowLeaderLines jsou rovny val).
