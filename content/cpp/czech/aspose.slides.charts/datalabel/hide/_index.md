## DataLabel::Hide() method


Skryjte datový štítek nastavením všech příznaků Show*- (ShowValue, ...) do stavu false. IsVisible bude po tomto nastavení false.

```cpp
void Aspose::Slides::Charts::DataLabel::Hide() override
```

## Poznámky


Pokud datový štítek není viditelný (IsVisible je false), můžete jej zobrazit nastavením příznaků Show*- (ShowValue, ...) do stavu true.
