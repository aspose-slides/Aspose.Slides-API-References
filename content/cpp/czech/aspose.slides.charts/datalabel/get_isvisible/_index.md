## DataLabel::get_IsVisible() metoda


False znamená, že popisek dat není viditelný (a tak jsou všechny příznaky Show*-flags (ShowValue, ...) false). Pouze pro čtení **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabel::get_IsVisible() override
```

## Poznámky


Pokud je popisek dat viditelný, můžete jej skrýt pomocí metody [Hide()](../hide/). Pokud však popisek dat není viditelný (IsVisible je false), můžete popisek dat zobrazit nastavením příznaků Show*-flags (ShowValue, ...) do stavu true.
