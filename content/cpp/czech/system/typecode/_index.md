## TypeCode enum

Representuje typ objektu.

```cpp
enum class TypeCode
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| Empty | 0 | Nulová reference. |
| Object | 1 | Obecný typ představující libovolnou referenci nebo typ hodnoty, který není explicitně reprezentován jiným TypeCode. |
| DBNull | 2 | Databázová nulová hodnota (sloupce). |
| Boolean | 3 | Jednoduchý typ představující hodnoty [Boolean](../boolean/) true nebo false. |
| Char | 4 | Integrální typ představující neoznačená 16-bitová celá čísla s hodnotami od 0 do 65535. |
| SByte | 5 | Integrální typ představující podepsaná 8-bitová celá čísla s hodnotami od -128 do 127. |
| Byte | 6 | Integrální typ představující neoznačená 8-bitová celá čísla s hodnotami od 0 do 255. |
| Int16 | 7 | Integrální typ představující podepsaná 16-bitová celá čísla s hodnotami od -32768 do 32767. |
| UInt16 | 8 | Integrální typ představující neoznačená 16-bitová celá čísla s hodnotami od 0 do 65535. |
| Int32 | 9 | Integrální typ představující podepsaná 32-bitová celá čísla s hodnotami od -2147483648 do 2147483647. |
| UInt32 | 10 | Integrální typ představující neoznačená 32-bitová celá čísla s hodnotami od 0 do 4294967295. |
| Int64 | 11 | Integrální typ představující podepsaná 64-bitová celá čísla s hodnotami od -9223372036854775808 do 9223372036854775807. |
| UInt64 | 12 | Integrální typ představující neoznačená 64-bitová celá čísla s hodnotami od 0 do 18446744073709551615. |
| Single | 13 | Typ s plovoucí desetinnou čárkou představující hodnoty v rozmezí přibližně 1.5 x 10 -45 až 3.4 x 10 38 s přesností 7 číslic. |
| Double | 14 | Typ s plovoucí desetinnou čárkou představující hodnoty v rozmezí přibližně 5.0 x 10 -324 až 1.7 x 10 308 s přesností 15-16 číslic. |
| Decimal | 15 | Jednoduchý typ představující hodnoty v rozmezí 1.0 x 10 -28 až přibližně 7.9 x 10 28 s 28-29 významnými číslicemi. |
| DateTime | 16 | Typ představující hodnotu data a času. |
| String | 18 | Uzavřený typ třídy představující řetězce Unicode znaků. |
