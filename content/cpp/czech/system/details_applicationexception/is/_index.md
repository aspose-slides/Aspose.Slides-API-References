## Podrobnosti_ApplicationException::Is(const System::TypeInfo\&) const method

```cpp
bool System::Details_ApplicationException::Is(const System::TypeInfo &target) const override
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struktura popisující typ, proti kterému se testuje aktuální objekt. |

### Návratová hodnota

True pokud je objekt značkovaného typu nebo jeho podtřídy, false jinak.

## Poznámky

Zkontrolujte, zda objekt představuje instanci typu popsaného pomocí targetType. Analogie k operátoru C# 'is'.
