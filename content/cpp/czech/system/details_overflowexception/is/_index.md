## Details_OverflowException::Is(const System::TypeInfo\&) const metoda






```cpp
bool System::Details_OverflowException::Is(const System::TypeInfo &target) const override
```


### Argumenty

| Parameter | Typ | Popis |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struktura popisující typ, proti kterému má být testován aktuální objekt. |

### Návratová hodnota

True pokud je objekt označeného typu nebo jeho podtřídy, false jinak.
## Poznámky


Zkontrolujte, zda objekt představuje instanci typu popsaného parametrem targetType. Analogie k operátoru C# 'is'.
