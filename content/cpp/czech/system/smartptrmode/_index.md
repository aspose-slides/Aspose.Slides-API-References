## SmartPtrMode enum


[SmartPtr](../smartptr/) typ ukazatele: weak nebo shared. Definuje, zda je ukazatel počítán při rozhodování, zda objekt smazat či ne.

```cpp
enum class SmartPtrMode : char
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| Shared | 0 | Režim Shared: ukazatel se podílí na počítání referencí. |
| Weak | 1 | Režim Weak: ukazatel se neúčastní počítání referencí. |
