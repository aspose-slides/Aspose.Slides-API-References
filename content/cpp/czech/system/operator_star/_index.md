## System::operator*(const T\&, const Decimal\&) funkce

Vrací novou instanci třídy [Decimal](../decimal/), která představuje hodnotu, jež je výsledkem násobení zadané hodnoty a hodnoty reprezentované zadaným objektem [Decimal](../decimal/).

```cpp
template<typename T,typename _> Decimal System::operator*(const T &x, const Decimal &d)
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| x | const T\& | První násobitel |
| d | const [Decimal](../decimal/)\& | Objekt [Decimal](../decimal/) představující druhý násobitel |

### Návratová hodnota

Nová instance třídy [Decimal](../decimal/), která představuje hodnotu, jež je výsledkem násobení **x** a hodnoty reprezentované **d**.
