## Details_NotImplementedException::Is(const System::TypeInfo\&) const method


```cpp
bool System::Details_NotImplementedException::Is(const System::TypeInfo &target) const override
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struktura popisující typ, vůči kterému se testuje aktuální objekt. |

### Návratová hodnota

True pokud je objekt označeným typem nebo jeho podtřídou, false jinak.

## Poznámky

Zkontroluje, zda objekt představuje instanci typu popsaného parametrem targetType. Analogie operátoru C# 'is' operátoru.
