## Details_MethodAccessException třída


MemberAccessException je vyvolána, když je pokus o přístup k neexistující metodě nebo když přístup k metodě není povolen. Nikdy nevytvářejte instance této třídy ručně. Použijte třídu MethodAccessException. Nikdy neobalujte instance třídy MethodAccessException do [System::SmartPtr](../smartptr/).

```cpp
class Details_MethodAccessException : public System::Details_MemberAccessException
```
