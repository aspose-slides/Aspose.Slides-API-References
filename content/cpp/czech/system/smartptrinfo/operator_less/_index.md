## SmartPtrInfo::operator<(const SmartPtrInfo\&) const metoda



### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| other | const [SmartPtrInfo](../)\& | Informace o ukazateli, se kterým se porovnává. |

### Návratová hodnota

Vrací true, pokud hodnota ukazatele referencovaného aktuálním objektem info předchází hodnotě ukazatele druhého objektu, jinak false.
