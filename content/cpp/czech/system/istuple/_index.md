## System::IsTuple(const SharedPtr\<Object\>\&, int32_t) funkce

Kontroluje, zda je objekt n-tice (implementuje rozhraní ITuple). Používá se při implementaci pozičních vzorů.

```cpp
bool System::IsTuple(const SharedPtr<Object> &object, int32_t length)
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| object | const [SharedPtr](../sharedptr/)\<[Object](../object/)\>\& | objekt k ověření. |
| length | **int32_t** | očekávaná délka n-tice |

### Návratová hodnota

objekt je n-tice a jeho délka se rovná očekávané
