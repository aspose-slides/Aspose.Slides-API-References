## Decimal::Compare(const Decimal\&, const Decimal\&) metoda


Určuje, zda je hodnota reprezentovaná prvním objektem [Decimal](../) menší, rovná se nebo větší než hodnota reprezentovaná druhým objektem [Decimal](../).

```cpp
static int System::Decimal::Compare(const Decimal &d1, const Decimal &d2)
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| d1 | const [Decimal](../)\& | První porovnávaný |
| d2 | const [Decimal](../)\& | Druhý porovnávaný |

### Návratová hodnota

- 1 pokud je hodnota reprezentovaná **d1** menší než hodnota reprezentovaná **d2**; 0 pokud jsou hodnoty rovné; 1 pokud je hodnota reprezentovaná **d1** větší než hodnota reprezentovaná **d2**
