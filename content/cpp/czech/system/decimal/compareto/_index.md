## Decimal::CompareTo(const Decimal\&) const metoda

Určuje, zda je hodnota reprezentovaná aktuálním objektem menší, rovná se nebo větší než hodnota reprezentovaná zadaným objektem.

```cpp
int System::Decimal::CompareTo(const Decimal &d) const
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| d | const [Decimal](../)\& | Porovnávaný |

### Návratová hodnota

- 1 pokud je hodnota reprezentovaná aktuálním objektem menší než hodnota reprezentovaná **d**; 0 pokud jsou hodnoty rovny; 1 pokud je hodnota reprezentovaná aktuálním objektem větší než hodnota reprezentovaná **d**
