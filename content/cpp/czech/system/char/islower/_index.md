## Char::IsLower(const char_t *, int) metoda

Určuje, zda je znak na určeném indexu v zadaném bufferu znaků klasifikován jako malé písmeno.

```cpp
static bool System::Char::IsLower(const char_t *str, int idx)
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| str | const char_t * | Ukazatel na začátek bufferu znaků |
| idx | int | Nulový index v zadaném bufferu znaku, který se testuje |

### Návratová hodnota

True pokud je znak na určeném indexu malým písmenem, jinak - false
