## Char::IsUpper(const String\&, int) metoda

Určuje, zda je znak na zadaném indexu ve zadaném řetězci klasifikován jako velké písmeno.

```cpp
static bool System::Char::IsUpper(const String &str, int idx)
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| str | const [String](../../string/)\& | Řetězec obsahující char. |
| idx | int | Nulový index ve zadaném řetězci k testování |

### Návratová hodnota

True, pokud je znak na zadaném indexu velké písmeno, jinak - false
