## Char::IsLetterOrDigit(const char_t *, int) metoda

Určuje, zda je znak na zadaném indexu ve specifikovaném bufferu znaků klasifikován jako Unicode písmeno nebo desítková číslice.

```cpp
static bool System::Char::IsLetterOrDigit(const char_t *str, int idx)
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| str | const char_t * | Ukazatel na začátek bufferu znaků |
| idx | int | Nulový index ve specifikovaném bufferu znaku, který se testuje |

### Návratová hodnota

True pokud je znak na specifikovaném indexu Unicode písmenem nebo desítkovou číslicí, jinak - false

## Char::IsLetterOrDigit(char_t) metoda

Určuje, zda je zadaný znak klasifikován jako Unicode písmeno nebo desítková číslice.

```cpp
static bool System::Char::IsLetterOrDigit(char_t c)
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| c | char_t | Testovaný znak |

### Návratová hodnota

True pokud je znak na specifikovaném indexu Unicode písmenem nebo desítkovou číslicí, jinak - false
