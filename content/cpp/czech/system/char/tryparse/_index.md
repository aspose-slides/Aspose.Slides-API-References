## Char::TryParse(const System::String\&, char_t\&) metoda

Pokouší se převést řetězec obsahující jediný znak na znak UTF-16. Funkce uspěje jen když vstupní řetězec není null a má délku přesně jednoho znaku.

```cpp
static bool System::Char::TryParse(const System::String &s, char_t &result)
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| s | const [System::String](../../string/)\& | [String](../../string/) k převodu |
| result | char_t\& | Výstupní proměnná, která bude obsahovat výsledek konverze, pokud konverze uspěje |

### Návratová hodnota

True pokud konverze uspěla, jinak - false
