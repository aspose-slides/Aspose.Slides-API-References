## Char::IsSurrogate(char_t) metoda


Určuje, zda je zadaný znak jednotkou UTF-16 surrogate.

```cpp
static bool System::Char::IsSurrogate(char_t c)
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| c | char_t | Znak |

### Návratová hodnota

True pokud je zadaný znak jednotkou UTF-16 surrogate, jinak - false
