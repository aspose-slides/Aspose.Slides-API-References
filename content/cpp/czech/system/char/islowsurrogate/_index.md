## Char::IsLowSurrogate(const char_t *, int) metoda


Určuje, zda je znak na zadaném indexu v určeném bufferu znaků nízkým surogátem.

```cpp
static bool System::Char::IsLowSurrogate(const char_t *str, int idx)
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| str | const char_t * | Ukazatel na začátek bufferu znaků |
| idx | int | Index založený na nule v určeném bufferu pro testovaný znak |

### Návratová hodnota

True pokud je znak na zadaném indexu nízký surogát, jinak false
