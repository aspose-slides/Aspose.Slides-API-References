## Char::IsPunctuation(const char_t *, int) metoda

Určuje, zda je znak na zadaném indexu ve specifikovaném bufferu znaků klasifikován jako interpunkční znak.

```cpp
static bool System::Char::IsPunctuation(const char_t *str, int idx)
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| str | const char_t * | Ukazatel na začátek bufferu znaků |
| idx | int | Nulový index ve specifikovaném bufferu znaku, který se testuje |

### Návratová hodnota

True, pokud je znak na zadaném indexu interpunkční znak, jinak - false
