## Char::IsWhiteSpace(const char_t *, int) metoda

Určuje, zda je znak na zadaném indexu ve specifikovaném bufferu znaků klasifikován jako znak bílé mezery.

```cpp
static bool System::Char::IsWhiteSpace(const char_t *str, int idx)
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| str | const char_t * | Ukazatel na začátek bufferu znaků |
| idx | int | Nulový index ve specifikovaném bufferu znaku k testování |

### Návratová hodnota

True pokud je znak na zadaném indexu znakem bílé mezery, jinak - false

## Char::IsWhiteSpace(char_t) metoda

Určuje, zda je zadaný znak klasifikován jako znak bílé mezery.

static bool System::Char::IsWhiteSpace(char_t c)

### Argumenty

| Parametr | Typ | Popis |

| c | char_t | Znak k testování |

### Návratová hodnota

True pokud je znak na zadaném indexu znakem bílé mezery, jinak - false
