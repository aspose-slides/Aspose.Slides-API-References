## Char::IsSymbol(const char_t *, int) metoda


Určuje, zda je znak na zadaném indexu ve specifikovaném bufferu znaků klasifikován jako symbol.

```cpp
static bool System::Char::IsSymbol(const char_t *str, int idx)
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| str | const char_t * | Ukazatel na začátek bufferu znaků |
| idx | int | Index založený na nule v určeném bufferu znaku, který se má testovat |

### Návratová hodnota

True pokud je znak na zadaném indexu symbolem, jinak - false

## Char::IsSymbol(char_t) metoda


Určuje, zda je zadaný znak klasifikován jako symbol.

```cpp
static bool System::Char::IsSymbol(char_t c)
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| c | char_t | Znak, který se má testovat |

### Návratová hodnota

True pokud je zadaný znak symbolem, jinak - false
