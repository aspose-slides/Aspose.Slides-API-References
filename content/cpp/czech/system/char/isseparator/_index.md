## Char::IsSeparator(const char_t *, int) metoda

Určuje, zda je znak na zadaném indexu ve specifikovaném znakovém bufferu klasifikován jako oddělovací znak.

```cpp
static bool System::Char::IsSeparator(const char_t *str, int idx)
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| str | const char_t * | Ukazatel na začátek znakového bufferu |
| idx | int | Nulový index ve specifikovaném bufferu znaku, který se má testovat |

### Návratová hodnota

True, pokud je znak na zadaném indexu oddělovacím znakem, jinak - false

## Char::IsSeparator(char_t) metoda

Určuje, zda je zadaný znak klasifikován jako oddělovací znak.

```cpp
static bool System::Char::IsSeparator(char_t c)
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| c | char_t | Znak k testování |

### Návratová hodnota

True, pokud je zadaný znak oddělovacím znakem, jinak - false
