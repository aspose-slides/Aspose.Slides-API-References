## Char::IsNumber(const char_t *, int) metoda


Určuje, zda je znak na zadaném indexu ve specifikovaném znakové bufferu klasifikován jako číslo.

```cpp
static bool System::Char::IsNumber(const char_t *str, int idx)
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| str | const char_t * | Ukazatel na začátek znakové bufferu |
| idx | int | Nulový index ve specifikovaném bufferu znaku, který se má testovat |

### Návratová hodnota

True pokud je znak na zadaném indexu číslo, jinak - false
