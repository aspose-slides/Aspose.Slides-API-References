## Char::IsControl(const char_t *, int) metoda


Určuje, zda je znak na zadaném indexu ve specifikovaném bufferu znaků klasifikován jako řídící znak Unicode.

```cpp
static bool System::Char::IsControl(const char_t *str, int idx)
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| str | const char_t * | Ukazatel na začátek bufferu znaků |
| idx | int | Index začínající od nuly ve specifikovaném bufferu znaku, který se má testovat |

### Návratová hodnota

True, pokud je znak na zadaném indexu řídícím znakem Unicode, jinak - false

static bool System::Char::IsControl(char_t c)
