## Char::IsDigit(const char_t *, int) metoda

Určuje, zda je znak na zadaném indexu v zadaném bufferu znaků klasifikován jako desetinná číslice.

```cpp
static bool System::Char::IsDigit(const char_t *str, int idx)
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| str | const char_t * | Ukazatel na začátek bufferu znaků |
| idx | int | Nulový index ve specifikovaném bufferu znaku, který má být testován |

### Návratová hodnota

True, pokud je znak na zadaném indexu desetinnou číslicí, jinak - false
