## Char::IsLetter(const char_t *, int) metoda


Určuje, zda je znak na zadaném indexu v zadaném bufferu znaků klasifikován jako Unicode písmeno.

```cpp
static bool System::Char::IsLetter(const char_t *str, int idx)
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| str | const char_t * | Ukazatel na začátek bufferu znaků |
| idx | int | Nulový index v daném bufferu znaku, který se má testovat |

### Návratová hodnota

True pokud je znak na zadaném indexu Unicode písmeno, jinak - false
