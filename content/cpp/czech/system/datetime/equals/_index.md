## DateTime::Equals(DateTime) const metoda


Určuje, zda zadaná instance třídy [DateTime](../) představuje stejnou hodnotu data a času jako aktuální objekt.

```cpp
constexpr bool System::DateTime::Equals(DateTime other) const
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| other | [DateTime](../) | Instance třídy [DateTime](../) pro porovnání s aktuálním objektem |

### Návratová hodnota

True pokud oba **other** a aktuální objekt představují stejnou hodnotu, jinak - false

## DateTime::Equals(DateTime, DateTime) metoda


Určuje, zda zadané instance třídy [DateTime](../) představují stejnou hodnotu data a času.

```cpp
static constexpr bool System::DateTime::Equals(DateTime t1, DateTime t2)
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| t1 | [DateTime](../) | První porovnávaný operand |
| t2 | [DateTime](../) | Druhý porovnávaný operand |

### Návratová hodnota

True pokud oba **t1** a **t2** představují stejnou hodnotu, jinak - false
