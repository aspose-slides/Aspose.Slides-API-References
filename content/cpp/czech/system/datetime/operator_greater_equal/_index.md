## DateTime::operator>=(DateTime) const metoda

Určuje, zda aktuální objekt představuje hodnotu data a času, která je pozdější nebo stejná jako hodnota reprezentovaná zadaným objektem [DateTime](../).

```cpp
constexpr bool System::DateTime::operator>=(DateTime other) const
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| other | [DateTime](../) | [DateTime](../) objekt, se kterým se porovnává aktuální objekt |

### Návratová hodnota

True, pokud hodnota data a času reprezentovaná aktuálním objektem je pozdější nebo stejná jako hodnota reprezentovaná **other**, jinak - false
