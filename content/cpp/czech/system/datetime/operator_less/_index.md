## DateTime::operator<(DateTime) const metoda

Určuje, zda aktuální objekt představuje hodnotu data a času, která je dřívější než hodnota reprezentovaná zadaným objektem [DateTime](../).

```cpp
constexpr bool System::DateTime::operator<(DateTime other) const
```

### Argumenty

| Parameter | Type | Description |
| --- | --- | --- |
| other | [DateTime](../) | [DateTime](../) objekt pro porovnání s aktuálním objektem |

### Návratová hodnota

True pokud je hodnota data a času reprezentovaná aktuálním objektem dřívější než hodnota reprezentovaná **other**, jinak - false
