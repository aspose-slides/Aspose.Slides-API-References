## DateTime::CompareTo(DateTime) const metoda

Porovnává dva datum a časové hodnoty reprezentované aktuálním objektem a specifikovanou instancí třídy [DateTime](../) a vrací hodnotu udávající relativní polohu hodnot na časové ose.

```cpp
constexpr int System::DateTime::CompareTo(DateTime value) const
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| value | [DateTime](../) | Instance třídy [DateTime](../) pro porovnání s aktuálním objektem |

### Návratová hodnota

Hodnota menší než 0, pokud aktuální objekt představuje hodnotu dřívější než ta, kterou představuje **value**; 0, pokud jsou hodnoty reprezentované oběma objekty stejné; hodnota větší než 0, pokud hodnota reprezentovaná aktuálním objektem je pozdější než hodnota reprezentovaná **value**.
