## DateTime::AddSeconds(double) const metoda

Vrací novou instanci třídy [DateTime](../), která představuje hodnotu data a času, jež je součtem hodnoty reprezentované aktuálním objektem a zadaného počtu sekund.

```cpp
DateTime System::DateTime::AddSeconds(double value) const
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| value | **double** | Počet sekund k přidání; hodnota může být kladná nebo záporná |

### Návratová hodnota

Nová instance třídy [DateTime](../), která představuje hodnotu data a času, jež je součtem hodnoty reprezentované aktuálním objektem a **value** sekund
