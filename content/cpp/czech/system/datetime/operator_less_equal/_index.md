## DateTime::operator<=(DateTime) const metoda

Určuje, zda aktuální objekt představuje hodnotu data a času, která je dříve než nebo stejná jako hodnota reprezentovaná zadaným [DateTime](../) objektem.

```cpp
constexpr bool System::DateTime::operator<=(DateTime other) const
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| other | [DateTime](../) | Objekt [DateTime](../), se kterým se porovnává aktuální objekt |

### Návratová hodnota

True pokud je hodnota data a času reprezentovaná aktuálním objektem dříve než nebo stejná jako hodnota reprezentovaná **other**, jinak - false
