## DateTime::Add(TimeSpan) const metoda

Vrátí novou instanci třídy [DateTime](../), která představuje hodnotu data a času, která vznikne přičtením zadaného časového intervalu k hodnotě data a času reprezentované aktuálním objektem.

```cpp
DateTime System::DateTime::Add(TimeSpan value) const
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| value | [TimeSpan](../../timespan/) | Časový interval k přidání |

### Návratová hodnota

Nová instance třídy [DateTime](../), která představuje hodnotu data a času, která vznikne přičtením časového intervalu **tm** k hodnotě data a času reprezentované aktuálním objektem
