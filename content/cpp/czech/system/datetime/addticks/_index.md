## DateTime::AddTicks(int64_t) const metoda

Vrátí novou instanci třídy [DateTime](../) představující hodnotu data a času, která je součtem hodnoty reprezentované aktuálním objektem a zadaným počtem 100-nanosekundových intervalů.

```cpp
DateTime System::DateTime::AddTicks(int64_t value) const
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| value | **int64_t** | Počet 100-nanosekundových intervalů, které se mají přičíst; hodnota může být kladná i záporná |

### Návratová hodnota

Nová instance třídy [DateTime](../) představující hodnotu data a času, která je součtem hodnoty reprezentované aktuálním objektem a **value** 100-nanosekundových intervalů
