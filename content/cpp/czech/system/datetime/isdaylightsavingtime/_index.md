## DateTime::IsDaylightSavingTime() const metoda


Určuje, zda hodnota data a času reprezentovaná aktuálním objektem spadá do období letního času pro aktuální časové pásmo.

```cpp
bool System::DateTime::IsDaylightSavingTime() const
```


### Návratová hodnota

True pokud hodnota data a času specifikovaná aktuálním objektem spadá do období letního času, jinak - false
