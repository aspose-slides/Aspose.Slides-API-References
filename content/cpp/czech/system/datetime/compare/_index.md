## DateTime::Compare(DateTime, DateTime) metoda


Porovná dvě hodnoty reprezentované zadanými instancemi třídy [DateTime](../) a vrátí hodnotu indikující relativní polohu hodnot na časové ose.

```cpp
static constexpr int System::DateTime::Compare(DateTime t1, DateTime t2)
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| t1 | [DateTime](../) | První porovnávaný |
| t2 | [DateTime](../) | Druhý porovnávaný |

### Návratová hodnota

Hodnota menší než 0, pokud **t1** je dříve než **t2**; 0, pokud **t1** je stejné jako **t2**; hodnota větší než 0, pokud **t1** je později než **t2**
