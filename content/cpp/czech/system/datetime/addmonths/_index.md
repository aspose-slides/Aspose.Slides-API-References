## DateTime::AddMonths(int) const metoda


Vrátí novou instanci třídy [DateTime](../), která představuje hodnotu data a času, jež je součtem hodnoty reprezentované aktuálním objektem a zadaného počtu měsíců.

```cpp
DateTime System::DateTime::AddMonths(int value) const
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| value | int | Počet měsíců, které se mají přidat; hodnota může být kladná nebo záporná |

### Návratová hodnota

Nová instance třídy [DateTime](../), která představuje hodnotu data a času, jež je součtem hodnoty reprezentované aktuálním objektem a **value** měsíců
