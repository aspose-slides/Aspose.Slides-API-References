## DateTimeOffset::operator<=(const DateTimeOffset\&) const metoda

Určuje, zda aktuální objekt představuje hodnotu data a času, která je dříve než nebo stejná jako hodnota představovaná zadaným [DateTimeOffset](../) objektem.

```cpp
bool System::DateTimeOffset::operator<=(const DateTimeOffset &other) const
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| other | const [DateTimeOffset](../)\& | Objekt [DateTimeOffset](../) k porovnání s aktuálním objektem |

### Návratová hodnota

True pokud je hodnota data a času představovaná aktuálním objektem dříve než nebo stejná jako hodnota představovaná **other**, jinak - false
