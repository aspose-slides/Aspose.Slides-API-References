## DateTimeOffset::operator<(const DateTimeOffset\&) const metoda


Určuje, zda aktuální objekt představuje hodnotu data a času, která je dříve než hodnota reprezentovaná zadaným objektem [DateTimeOffset](../).

```cpp
bool System::DateTimeOffset::operator<(const DateTimeOffset &other) const
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| other | const [DateTimeOffset](../)\& | Objekt [DateTimeOffset](../) pro porovnání s aktuálním objektem |

### Návratová hodnota

True, pokud je hodnota data a času reprezentovaná aktuálním objektem dříve než hodnota reprezentovaná **other**, jinak - false
