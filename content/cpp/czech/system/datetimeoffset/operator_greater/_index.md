## DateTimeOffset::operator>(const DateTimeOffset\&) const metoda


Určuje, zda aktuální objekt představuje hodnotu data a času, která je pozdější než hodnota reprezentovaná zadaným objektem [DateTimeOffset](../).

```cpp
bool System::DateTimeOffset::operator>(const DateTimeOffset &other) const
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| other | const [DateTimeOffset](../)\& | Objekt [DateTimeOffset](../), se kterým se porovnává aktuální objekt |

### Návratová hodnota

True, pokud je hodnota data a času reprezentovaná aktuálním objektem pozdější než hodnota reprezentovaná **other**, jinak – false
