## TimeSpan::operator>=(TimeSpan) const method

Určuje, zda časový interval reprezentovaný aktuálním objektem je delší než nebo roven časovému intervalu reprezentovanému zadaným objektem.

```cpp
constexpr bool System::TimeSpan::operator>=(TimeSpan value) const
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| value | [TimeSpan](../) | Objekt [TimeSpan](../) pro porovnání s aktuálním objektem |

### Návratová hodnota

True pokud časový interval reprezentovaný aktuálním objektem je delší než nebo roven časovému intervalu reprezentovanému **value**, jinak - false
