## TimeSpan::operator!=(TimeSpan) const metoda

Určuje, zda časový interval reprezentovaný aktuálním objektem není roven časovému intervalu reprezentovanému zadaným objektem.

```cpp
constexpr bool System::TimeSpan::operator!=(TimeSpan value) const
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| value | [TimeSpan](../) | Objekt [TimeSpan](../) pro porovnání s aktuálním objektem |

### Návratová hodnota

True, pokud aktuální objekt a zadaný objekt představují různé časové intervaly, jinak – false
