## TimeSpan::operator==(TimeSpan) const metoda

Určuje, zda časový interval reprezentovaný aktuálním objektem je roven časovému intervalu reprezentovanému zadaným objektem.

```cpp
constexpr bool System::TimeSpan::operator==(TimeSpan value) const
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| value | [TimeSpan](../) | [TimeSpan](../) objekt, který se porovnává s aktuálním objektem |

### Návratová hodnota

True, pokud aktuální objekt a zadaný objekt představují stejný časový interval, jinak - false
