## TimeSpan::operator<(TimeSpan) const metoda

Určuje, zda je časový interval reprezentovaný aktuálním objektem kratší než časový interval reprezentovaný zadaným objektem.

```cpp
constexpr bool System::TimeSpan::operator<(TimeSpan value) const
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| value | [TimeSpan](../) | [TimeSpan](../) objekt, se kterým se porovnává aktuální objekt |

### Návratová hodnota

True pokud je časový interval reprezentovaný aktuálním objektem kratší než časový interval reprezentovaný **value**, jinak - false
