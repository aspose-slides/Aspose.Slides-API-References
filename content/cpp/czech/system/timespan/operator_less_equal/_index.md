## TimeSpan::operator<=(TimeSpan) const metoda


Určuje, zda je časový interval reprezentovaný aktuálním objektem kratší nebo roven časovému intervalu reprezentovanému zadaným objektem.

```cpp
constexpr bool System::TimeSpan::operator<=(TimeSpan value) const
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| value | [TimeSpan](../) | Objekt [TimeSpan](../) pro porovnání aktuálního objektu |

### Návratová hodnota

True pokud je časový interval reprezentovaný aktuálním objektem kratší nebo roven časovému intervalu reprezentovanému **value**, jinak - false
