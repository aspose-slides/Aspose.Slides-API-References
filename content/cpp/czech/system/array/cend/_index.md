## Array::cend() const metoda

Vrací iterátor na prvek následující po posledním prvku kontejneru. Tento prvek slouží jako zástupný prvek; pokus o jeho přístup vede k nedefinovanému chování.

```cpp
const_iterator System::Array<T>::cend() const noexcept
```

### Návratová hodnota

Iterátor ukazující na teoretický jako const kvalifikovaný prvek umístěný za posledním prvkem kontejneru.
