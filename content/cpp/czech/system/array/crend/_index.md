## Array::crend() const metoda

Vrací reverzní iterátor na prvek následující po posledním prvku reverzovaného kontejneru. Odpovídá prvku předcházejícímu prvnímu prvku nepřevráceného kontejneru. Tento prvek funguje jako zástupce, pokus o jeho přístup vede k nedefinovanému chování.

```cpp
const_reverse_iterator System::Array<T>::crend() const noexcept
```

### Návratová hodnota

Iterátor ukazující na teoretický const-kvalifikovaný prvek předcházející prvnímu prvku kontejneru.
