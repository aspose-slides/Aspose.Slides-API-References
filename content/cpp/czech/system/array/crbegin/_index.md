## Array::crbegin() const metoda

Vrací reverzní iterátor na první prvek reverzovaného kontejneru. Odpovídá poslednímu prvku nevráceného kontejneru. Pokud je kontejner prázdný, vrácený iterátor je roven [crend()](../crend/).

```cpp
const_reverse_iterator System::Array<T>::crbegin() const noexcept
```

### Návratová hodnota

Iterátor ukazující na poslední const-kvalifikovaný prvek kontejneru.
