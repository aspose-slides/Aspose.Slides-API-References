## Version::CompareTo(const Version\&) const metoda

Porovnává verze reprezentované aktuálním objektem a zadaným objektem.

```cpp
int System::Version::CompareTo(const Version &ver) const
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| ver | const [Version](../)\& | Objekt [Version](../) k porovnání s aktuálním objektem |

### Návratová hodnota

- 1 pokud je číslo verze reprezentované aktuálním objektem menší než číslo verze reprezentované **ver**; 0 pokud jsou čísla verzí stejná; 1 pokud je číslo verze reprezentované aktuálním objektem větší než hodnota reprezentovaná **ver**
