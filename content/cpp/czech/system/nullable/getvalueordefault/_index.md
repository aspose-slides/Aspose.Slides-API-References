## Nullable::GetValueOrDefault(T) metoda


Returns the value represented by the current object or the specified value if the value represented by the current object is null.

```cpp
T System::Nullable<T>::GetValueOrDefault(T default_value)
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| default_value | T | Hodnota vrácená metodou, pokud je hodnota reprezentovaná aktuálním objektem null |

### Návratová hodnota

Kopie hodnoty reprezentované aktuálním objektem, pokud není null, jinak je vrácena zadaná hodnota
