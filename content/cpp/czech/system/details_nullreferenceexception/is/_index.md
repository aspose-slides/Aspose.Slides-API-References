## Podrobnosti_NullReferenceException::Is(const System::TypeInfo\&) const method

```cpp
bool System::Details_NullReferenceException::Is(const System::TypeInfo &target) const override
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struktura popisující typ, vůči kterému se testuje aktuální objekt. |

### Návratová hodnota

Vrací true, pokud je objekt označeného typu nebo jeho podtřídy, jinak false.

## Poznámky

Zkontroluje, zda objekt představuje instanci typu popsaného pomocí targetType. Analogie operátoru C# 'is'.
