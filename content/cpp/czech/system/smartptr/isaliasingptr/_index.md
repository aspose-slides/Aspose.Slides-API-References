## SmartPtr::IsAliasingPtr() const metoda

Kontroluje, zda ukazatel odkazuje na jiný objekt než ten, který vlastní (vytvořený aliasovým konstruktorem).

```cpp
bool System::SmartPtr<T>::IsAliasingPtr() const
```

### Návratová hodnota

True pokud má ukazatel rozdíl mezi odkazovaným a vlastním objektem, false jinak.
