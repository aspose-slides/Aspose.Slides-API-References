## SmartPtr::Is(const System::TypeInfo\&) const metoda


Kontroluje, zda ukazovaný objekt je konkrétního typu nebo jeho podřízeného typu. Následuje sémantika C# 'is'.

```cpp
bool System::SmartPtr<T>::Is(const System::TypeInfo &target) const
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | Určuje typ cíle, proti kterému se provádí kontrola. |

### Návratová hodnota

True pokud je kontrola ve stylu C# 'is' pozitivní a false jinak.
