## SmartPtr::get_shared_count() const metoda


Vrací počet sdílených ukazatelů, které existují pro odkazovaný objekt, včetně aktuálního. Ověřuje, že aktuální ukazatel je ve sdíleném režimu.

```cpp
int System::SmartPtr<T>::get_shared_count() const
```


### Návratová hodnota

Počet sdílených ukazatelů existujících na odkazovaný objekt, pokud existuje. Pokud je ukazatel nulový, vrací 0.
