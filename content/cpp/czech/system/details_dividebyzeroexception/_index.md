## Details_DivideByZeroException třída

DivideByZeroException je vyvolána, když je v aritmetické operaci provedeno dělení 0. Nikdy nevytvářejte instance této třídy ručně. Používejte třídu DivideByZeroException místo toho. Nikdy neobaluje instance třídy DivideByZeroException do [System::SmartPtr](../smartptr/).

```cpp
class Details_DivideByZeroException : public System::Details_ArithmeticException
```
