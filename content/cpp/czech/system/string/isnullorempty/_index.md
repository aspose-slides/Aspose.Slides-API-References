## String::IsNullOrEmpty() const metoda

Kontroluje, zda je řetězec prázdný nebo je považován za null.

```cpp
bool System::String::IsNullOrEmpty() const
```

### Návratová hodnota

true, pokud je řetězec prázdný nebo null, jinak false.
