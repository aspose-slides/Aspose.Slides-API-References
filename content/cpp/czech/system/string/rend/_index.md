## String::rend() const metoda

Vrací reverzní iterátor na před první znak (pokud existuje) skutečného řetězcového bufferu.

```cpp
reverse_iterator System::String::rend() const
```

### Návratová hodnota

Reverzní iterátor na prvek předcházející prvnímu znaku skutečného řetězcového bufferu (pokud existuje) nebo na prvek těsně před alokovaným bufferem.
