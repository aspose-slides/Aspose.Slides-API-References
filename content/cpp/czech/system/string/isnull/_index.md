## String::IsNull() const metoda


Kontroluje, zda je řetězec považován za null. [String](../) je null a jen pokud je vytvořen pomocí konstruktoru [String()](../string/), přesunut, zkopírován nebo přiřazen z null řetězce nebo byla zavolána metoda [reset()](../reset/).

```cpp
bool System::String::IsNull() const
```


### Návratová hodnota

true, pokud je řetězec považován za null, false jinak.
