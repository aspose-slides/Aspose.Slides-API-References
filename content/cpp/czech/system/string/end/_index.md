## String::end() const metoda


Vrací ukazatel na konec aktuálního řetězcového bufferu. Nikdy neprovádí realokaci. Nezaručuje, že je buffer ukončen nulovým znakem.

```cpp
const UChar * System::String::end() const
```


### Návratová hodnota

Ukazatel na první prvek za aktuálním řetězcovým bufferem, ukončený nulovým znakem nebo ne.
