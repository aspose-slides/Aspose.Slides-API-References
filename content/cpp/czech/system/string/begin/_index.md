## String::begin() const metoda

Vrací ukazatel na začátek aktuálního bufferu řetězce. Nikdy neprovádí realokaci čehokoli. Nezaručuje, že je buffer ukončen nulovým znakem.

```cpp
const UChar * System::String::begin() const
```

### Návratová hodnota

Ukazatel na aktuální buffer řetězce, ukončený nulou nebo ne.
