## String::IsNullOrWhiteSpace(const String\&) metoda

Určuje, zda je zadaný řetězec null, prázdný, nebo se skládá pouze z bílých znaků.

```cpp
static bool System::String::IsNullOrWhiteSpace(const String &str)
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| str | const [String](../)\& | [String](../) ke kontrole. |

### Návratová hodnota

true pokud je řetězec null nebo prázdný, nebo se skládá výhradně z bílých znaků, false jinak.
