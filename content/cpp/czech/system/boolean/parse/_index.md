## Boolean::Parse(const String\&) metoda

Převede zadaný řetězec na hodnotu typu bool.

```cpp
static bool System::Boolean::Parse(const String &value)
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| value | const [String](../../string/)\& | Řetězec k převodu. |

### Návratová hodnota

Proměnná typu bool, do které se uloží výsledek převodu; výsledek je true, pokud je zadaný řetězec roven "True" a false, pokud je zadaný řetězec roven "False".
