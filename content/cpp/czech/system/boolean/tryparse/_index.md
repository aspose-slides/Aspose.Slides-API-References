## Boolean::TryParse(const String\&, bool\&) metoda

Převádí zadaný řetězec na hodnotu typu bool.

```cpp
static bool System::Boolean::TryParse(const String &value, bool &result)
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| value | const [String](../../string/)\& | Řetězec k převodu. |
| result | **bool**\& | Reference na proměnnou typu bool, do které se uloží výsledek převodu; výsledek je true, pokud je zadaný řetězec roven "True", a false, pokud je zadaný řetězec roven "False". |

### Návratová hodnota

True, pokud je zadaný řetězec roven buď "True" nebo "False", jinak - false.
