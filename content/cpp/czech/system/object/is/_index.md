## Object::Is(const TypeInfo\&) const metoda

Zkontrolujte, zda objekt představuje instanci typu popsaného parametrem targetType. Analogie operátoru 'is' v C#.

```cpp
virtual bool System::Object::Is(const TypeInfo &targetType) const
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| targetType | const [TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struktura popisující typ, proti kterému se testuje aktuální objekt. |

### Návratová hodnota

True pokud je objekt označeného typu nebo jeho podtřídy, false jinak.
