## Details_RankException::Is(const System::TypeInfo\&) const method




```cpp
bool System::Details_RankException::Is(const System::TypeInfo &target) const override
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struktura popisující typ, proti kterému se testuje aktuální objekt. |

### Návratová hodnota

## Poznámky


Zkontrolujte, zda objekt představuje instanci typu popsaného pomocí targetType. Analogie operátoru 'is' v C#.
