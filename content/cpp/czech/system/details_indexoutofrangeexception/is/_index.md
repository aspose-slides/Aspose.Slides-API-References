## Podrobnosti_IndexOutOfRangeException::Is(const System::TypeInfo\&) const metoda

```cpp
bool System::Details_IndexOutOfRangeException::Is(const System::TypeInfo &target) const override
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struktura popisující typ, vůči kterému se testuje aktuální objekt. |

### Návratová hodnota

True pokud objekt je označeného typu nebo jeho podtřídy, false jinak.

## Poznámky

Ověří, zda objekt představuje instanci typu popsaného parametrem targetType. Analogie operátoru C# 'is'.
