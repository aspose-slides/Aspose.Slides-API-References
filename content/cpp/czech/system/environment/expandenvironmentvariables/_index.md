## Environment::ExpandEnvironmentVariables(const String\&) metoda

```cpp
static String System::Environment::ExpandEnvironmentVariables(const String &name)
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| name | const [String](../../string/)\& | Řetězec obsahující názvy proměnných prostředí |

### Návratová hodnota

Řetězec, který vznikne nahrazením názvů proměnných v **name** jejich hodnotami.
