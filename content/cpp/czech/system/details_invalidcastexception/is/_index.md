## Details_InvalidCastException::Is(const System::TypeInfo\&) const metoda


```cpp
bool System::Details_InvalidCastException::Is(const System::TypeInfo &target) const override
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struktura popisující typ, proti kterému se testuje aktuální objekt. |

### Návratová hodnota

True pokud je objekt označeného typu nebo jeho podtřídy, false v opačném případě.

## Poznámky

Zkontrolujte, zda objekt představuje instanci typu popsaného pomocí targetType. Analogie operátoru C# 'is'.
