## TypeInfo::IsInstanceOfType(const SharedPtr\<Object\>\&) const metoda

Určuje, zda je zadaný objekt instancí aktuálního typu.

```cpp
bool System::TypeInfo::IsInstanceOfType(const SharedPtr<Object> &obj) const
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| obj | const [SharedPtr](../../sharedptr/)\<[Object](../../object/)\>\& | Objekt, který se porovnává s aktuálním typem |

true, pokud je aktuální typ v hierarchii dědičnosti objektu reprezentovaného proměnnou obj
