## NamespaceHandling enum

Určuje, zda odebrat duplicitní deklarace jmenných prostorů v [XmlWriter](../xmlwriter/).

```cpp
enum class NamespaceHandling
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| Default | 0 | Určuje, že duplicitní deklarace jmenných prostorů nebudou odstraněny. |
| OmitDuplicates | 1 | Určuje, že duplicitní deklarace jmenných prostorů budou odstraněny. Aby byl duplicitní jmenný prostor odstraněn, musí se shodovat předpona a jmenný prostor. |
