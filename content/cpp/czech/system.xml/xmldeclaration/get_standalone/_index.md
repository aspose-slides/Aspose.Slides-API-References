## XmlDeclaration::get_Standalone() metoda


Vrací hodnotu atributu standalone.

```cpp
String System::Xml::XmlDeclaration::get_Standalone()
```


### Návratová hodnota

Platné hodnoty jsou **yes**, pokud jsou všechny deklarace entit požadované XML dokumentem obsaženy v dokumentu, nebo **no**, pokud je vyžadována externí definice typu dokumentu (DTD). Pokud atribut standalone není přítomen v deklaraci XML, tato metoda vrací [String::Empty](../../../system/string/empty/).
