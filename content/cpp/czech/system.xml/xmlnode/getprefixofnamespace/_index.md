## XmlNode::GetPrefixOfNamespace(String) metoda

Vyhledá nejbližší deklaraci **xmlns** pro zadaný URI jmenného prostoru, která je v rozsahu aktuálního uzlu, a vrátí prefix definovaný v této deklaraci.

```cpp
virtual String System::Xml::XmlNode::GetPrefixOfNamespace(String namespaceURI)
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| namespaceURI | [String](../../../system/string/) | URI jmenného prostoru, jehož prefix chcete najít. |

### Návratová hodnota

Prefix pro zadaný URI jmenného prostoru.
