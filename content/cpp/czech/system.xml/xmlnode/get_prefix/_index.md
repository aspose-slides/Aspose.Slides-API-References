## XmlNode::get_Prefix() metoda


Vrací předponu jmenného prostoru tohoto uzlu.

```cpp
virtual String System::Xml::XmlNode::get_Prefix()
```


### Návratová hodnota

Předpona jmenného prostoru tohoto uzlu. Například **Prefix** je **bk** pro prvek **<bk:book>**. Pokud neexistuje předpona, tato metoda vrátí [String::Empty](../../../system/string/empty/).
