## XmlReaderSettings::get_ProhibitDtd() metoda

Vrací hodnotu, která určuje, zda zakázat zpracování dokumentové typové definice (DTD).

```cpp
bool System::Xml::XmlReaderSettings::get_ProhibitDtd()
```

### Návratová hodnota

**true** k zakázání zpracování DTD; jinak **false**. Výchozí hodnota je **true**.

Zastaralé
:   Tato metoda je zastaralá. Použijte [XmlTextReader::get_DtdProcessing](../../xmltextreader/get_dtdprocessing/) místo ní.
