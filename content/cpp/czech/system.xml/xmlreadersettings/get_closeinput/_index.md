## XmlReaderSettings::get_CloseInput() metoda


Vrací hodnotu, která udává, zda má být podkladový stream nebo TextReader uzavřen, když je čtečka uzavřena.

```cpp
bool System::Xml::XmlReaderSettings::get_CloseInput()
```


### Návratová hodnota

**true** k uzavření podkladového streamu nebo TextReaderu, když je čtečka uzavřena; jinak **false**. Výchozí hodnota je **false**.
