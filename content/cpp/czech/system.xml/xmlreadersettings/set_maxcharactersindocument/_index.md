## XmlReaderSettings::set_MaxCharactersInDocument(int64_t) metoda

Nastavuje hodnotu udávající maximální povolený počet znaků v XML dokumentu. Hodnota nula (0) znamená, že na velikost XML dokumentu nejsou žádná omezení. Hodnota různá od nuly určuje maximální velikost v počtu znaků.

```cpp
void System::Xml::XmlReaderSettings::set_MaxCharactersInDocument(int64_t value)
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| value | **int64_t** | Hodnota, která se má nastavit. |
