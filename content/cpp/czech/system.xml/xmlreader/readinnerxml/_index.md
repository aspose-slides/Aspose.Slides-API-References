## XmlReader::ReadInnerXml() metoda

Když je přepsána v odvozené třídě, načte veškerý obsah včetně značek jako řetězec.

```cpp
virtual String System::Xml::XmlReader::ReadInnerXml()
```

### Návratová hodnota

Veškerý XML obsah, včetně značek, v aktuálním uzlu. Pokud aktuální uzel nemá žádné potomky, vrátí se prázdný řetězec. Pokud aktuální uzel není ani element ani atribut, vrátí se prázdný řetězec.
