## XmlReader::get_IsEmptyElement() method


Když je přepsána v odvozené třídě, získá hodnotu, která určuje, zda je aktuální uzel prázdným prvkem (například **<MyElement/>**).

```cpp
virtual bool System::Xml::XmlReader::get_IsEmptyElement()=0
```


### Návratová hodnota

**true** pokud je aktuální uzel prvkem ([XmlReader::get_NodeType](../get_nodetype/) equals [XmlNodeType::Element](../../xmlnodetype/)) který končí **/>**; jinak **false**.
