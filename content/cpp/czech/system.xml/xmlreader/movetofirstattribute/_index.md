## XmlReader::MoveToFirstAttribute() metoda


Když je přepsána v odvozené třídě, přesune se na první atribut.

```cpp
virtual bool System::Xml::XmlReader::MoveToFirstAttribute()=0
```


### Návratová hodnota

**true** pokud existuje atribut (čtečka se přesune na první atribut); jinak, **false** (pozice čtečky se nezmění).
