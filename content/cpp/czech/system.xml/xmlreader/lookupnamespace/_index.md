## XmlReader::LookupNamespace(const String\&) metoda


Když je přepsána v odvozené třídě, vyřeší předponu jmenného prostoru v rozsahu aktuálního elementu.

```cpp
virtual String System::Xml::XmlReader::LookupNamespace(const String &prefix)=0
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| prefix | const [String](../../../system/string/)\& | Předpona, jejíž URI jmenného prostoru chcete vyřešit. Pro odpovídání výchozímu jmennému prostoru předáte prázdný řetězec. |

### Návratová hodnota

URI jmenného prostoru, ke kterému předpona mapuje, nebo **nullptr**, pokud není nalezena odpovídající předpona.
