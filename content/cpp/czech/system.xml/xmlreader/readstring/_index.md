## XmlReader::ReadString() metoda


Když je přepsána v odvozené třídě, čte obsah elementu nebo textového uzlu jako řetězec. Nicméně se doporučuje použít metodu [XmlReader::ReadElementContentAsString](../readelementcontentasstring/) místo toho, protože poskytuje přímější způsob, jak tuto operaci zpracovat.

```cpp
virtual String System::Xml::XmlReader::ReadString()
```


### Návratová hodnota

Obsah elementu nebo prázdný řetězec.
