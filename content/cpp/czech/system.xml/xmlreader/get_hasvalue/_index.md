## XmlReader::get_HasValue() metoda


Když je přepsána v odvozené třídě, získá hodnotu, která udává, zda aktuální uzel může mít [XmlReader::get_Value](../get_value/) hodnotu.

```cpp
virtual bool System::Xml::XmlReader::get_HasValue()
```


### Návratová hodnota

**true** pokud uzel, na kterém je čtenář právě umístěn, může mít **Value**; jinak **false**. Pokud je **false**, uzel má hodnotu [String::Empty](../../../system/string/empty/).
