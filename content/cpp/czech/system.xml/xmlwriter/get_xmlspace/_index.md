## XmlWriter::get_XmlSpace() metoda


Když je v odvozené třídě přepsáno, získá objekt XmlSpace představující aktuální rozsah **xml:space**.

```cpp
virtual System::Xml::XmlSpace System::Xml::XmlWriter::get_XmlSpace()
```


### Návratová hodnota

Objekt XmlSpace představující aktuální rozsah **xml:space**.



| Value | Meaning |
| --- | --- |
| `None`| Toto je výchozí, pokud neexistuje žádný rozsah `xml:space`. |
| `Default`| Aktuální rozsah je `xml:space="default"`. |
| `Preserve`| Aktuální rozsah je `xml:space="preserve"`. |
