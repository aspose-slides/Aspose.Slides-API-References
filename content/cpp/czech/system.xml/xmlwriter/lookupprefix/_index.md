## XmlWriter::LookupPrefix(String) metoda


When overridden in a derived class, returns the closest prefix defined in the current namespace scope for the namespace URI.

```cpp
virtual String System::Xml::XmlWriter::LookupPrefix(String ns)=0
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| ns | [String](../../../system/string/) | URI jmenného prostoru, jehož předponu chcete najít. |

### Návratová hodnota

Odpovídající předpona nebo **nullptr**, pokud v aktuálním rozsahu není nalezena odpovídající URI jmenného prostoru.
