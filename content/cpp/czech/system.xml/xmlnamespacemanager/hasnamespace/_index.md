## XmlNamespaceManager::HasNamespace(String) metoda


Vrací hodnotu, která určuje, zda zadaná předpona má definovaný prostor názvů pro aktuální zásobník.

```cpp
virtual bool System::Xml::XmlNamespaceManager::HasNamespace(String prefix)
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| prefix | [String](../../../system/string/) | Předpona prostoru názvů, kterou chcete najít. |

### Návratová hodnota

**true** pokud je definován prostor názvů; jinak **false**.
