## XmlAttribute::get_BaseURI() metoda

Vrací základní Uniform Resource Identifier (URI) uzlu.

```cpp
String System::Xml::XmlAttribute::get_BaseURI() override
```

### Návratová hodnota

Umístění, ze kterého byl uzel načten, nebo [String::Empty](../../../system/string/empty/), pokud uzel nemá základní URI. [Attribute](../../../system/attribute/) uzly mají stejný základní URI jako jejich vlastnický prvek. Pokud atributový uzel nemá vlastnický prvek, get_BaseURI vrací [String::Empty](../../../system/string/empty/).
