## XmlAttribute::get_Specified() metoda


Vrací hodnotu, která udává, zda byla hodnota atributu explicitně nastavena.

```cpp
virtual bool System::Xml::XmlAttribute::get_Specified()
```


### Návratová hodnota

**true** pokud byl tento atribut explicitně přiřazen hodnotě v původním instančním dokumentu; jinak **false**. Hodnota **false** naznačuje, že hodnota atributu pochází z DTD.
