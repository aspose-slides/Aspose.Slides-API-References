## XmlNotation::get_IsReadOnly() metoda

Vrací hodnotu, která udává, zda je uzel pouze pro čtení.

```cpp
bool System::Xml::XmlNotation::get_IsReadOnly() override
```

### Návratová hodnota

**true** pokud je uzel pouze pro čtení; jinak **false**. Protože [XmlNotation](../) uzly jsou pouze pro čtení, tato metoda vždy vrací **true**.
