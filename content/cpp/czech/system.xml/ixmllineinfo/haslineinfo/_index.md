## IXmlLineInfo::HasLineInfo() metoda

Vrací hodnotu, která udává, zda třída může vracet informace o řádku.

```cpp
virtual bool System::Xml::IXmlLineInfo::HasLineInfo()=0
```

### Návratová hodnota

**true** pokud mohou být poskytnuty [IXmlLineInfo::get_LineNumber](../get_linenumber/) a [IXmlLineInfo::get_LinePosition](../get_lineposition/); jinak **false**.
