## XmlDocument::get_PreserveWhitespace() metoda

Returns a value indicating whether to preserve white space in element content.

```cpp
bool System::Xml::XmlDocument::get_PreserveWhitespace()
```

### Návratová hodnota

**true** pro zachování bílých mezer; jinak **false**. Výchozí hodnota je **false**.
