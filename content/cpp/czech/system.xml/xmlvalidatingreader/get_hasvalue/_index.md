## XmlValidatingReader::get_HasValue() metoda


Vrací hodnotu, která určuje, zda může aktuální uzel mít [XmlValidatingReader::get_Value](../get_value/) jiný než [String::Empty](../../../system/string/empty/).

```cpp
bool System::Xml::XmlValidatingReader::get_HasValue() override
```


### Návratová hodnota

**true** pokud uzel, na kterém je čtečka aktuálně umístěna, může mít **Value**; jinak **false**.
