## XmlValidatingReader::LookupNamespace(const String\&) metoda


Vyřeší předponu jmenného prostoru v aktuálním rozsahu elementu.

```cpp
String System::Xml::XmlValidatingReader::LookupNamespace(const String &prefix) override
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| prefix | const [String](../../../system/string/)\& | Předpona, jejíž Uniform Resource Identifier (URI) jmenného prostoru chcete rozpoznat. Pro odpovídání výchozímu jmennému prostoru předáte prázdný řetězec. |

### Návratová hodnota

URI jmenného prostoru, na který je předpona mapována, nebo **nullptr**, pokud není nalezena odpovídající předpona.
