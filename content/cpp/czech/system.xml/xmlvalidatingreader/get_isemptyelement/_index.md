## XmlValidatingReader::get_IsEmptyElement() method


Vrací hodnotu, která určuje, zda je aktuální uzel prázdným elementem (například **<MyElement/>**).

```cpp
bool System::Xml::XmlValidatingReader::get_IsEmptyElement() override
```


### Návratová hodnota

**true** pokud je aktuální uzel elementem ([XmlValidatingReader::get_NodeType](../get_nodetype/) hodnota se rovná [XmlNodeType::Element](../../xmlnodetype/)) který končí **/>**; jinak **false**.
