## XmlEntity::get_IsReadOnly() metoda

Vrací hodnotu, která udává, zda je uzel jen pro čtení.

```cpp
bool System::Xml::XmlEntity::get_IsReadOnly() override
```

### Návratová hodnota

**true** pokud je uzel jen pro čtení; jinak **false**. Protože [XmlEntity](../) uzly jsou jen pro čtení, tato metoda vždy vrací **true**.
