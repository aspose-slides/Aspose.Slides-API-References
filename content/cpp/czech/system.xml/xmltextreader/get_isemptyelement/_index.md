## XmlTextReader::get_IsEmptyElement() metoda

Vrací hodnotu, která určuje, zda je aktuální uzel prázdný element (například **<MyElement/>**).

```cpp
bool System::Xml::XmlTextReader::get_IsEmptyElement() override
```

### Návratová hodnota

**true** pokud je aktuální uzel element ([XmlTextReader::get_NodeType](../get_nodetype/) hodnota se rovná [XmlNodeType::Element](../../xmlnodetype/)), který končí **/>**; jinak **false**.
