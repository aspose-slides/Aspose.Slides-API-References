## XmlTextReader::get_ProhibitDtd() metoda

Vrací hodnotu, která určuje, zda povolit zpracování DTD.

```cpp
bool System::Xml::XmlTextReader::get_ProhibitDtd()
```

### Návratová hodnota

**true** pro zakázání zpracování DTD; jinak **false**. Výchozí hodnota je **false**.

Zastaralé
:   Tato metoda je zastaralá. Použijte [XmlTextReader::get_DtdProcessing](../get_dtdprocessing/) místo toho.
