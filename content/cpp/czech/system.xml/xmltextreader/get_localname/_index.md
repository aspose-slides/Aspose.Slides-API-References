## XmlTextReader::get_LocalName() metoda

Vrací lokální název aktuálního uzlu.

```cpp
String System::Xml::XmlTextReader::get_LocalName() override
```

### Návratová hodnota

Název aktuálního uzlu s odebranou předponou. Například **LocalName** je **book** pro prvek **<bk:book>**. Pro typy uzlů, které nemají název (jako **[Text](../../../system.text/)**, **Comment**, a podobně), tato metoda vrací [String::Empty](../../../system/string/empty/).
