### Návratová hodnota

XmlSpace představující aktuální **xml:space** rozsah.

| Hodnota | Význam |
| --- | --- |
| None | Toto je výchozí hodnota, pokud neexistuje žádný rozsah `xml:space`. |
| Default | Aktuální rozsah je `xml:space="default"`. |
| Preserve | Aktuální rozsah je `xml:space="preserve"`. |
