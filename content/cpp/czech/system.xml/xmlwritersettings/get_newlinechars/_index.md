## XmlWriterSettings::get_NewLineChars() metoda


Vrací řetězec znaků používaný pro zalomení řádků.

```cpp
String System::Xml::XmlWriterSettings::get_NewLineChars()
```


### Návratová hodnota

Řetězec znaků používaný pro zalomení řádků. Lze jej nastavit na jakoukoli hodnotu řetězce. Přesto, aby XML bylo platné, byste měli uvádět pouze platné znaky bílého prostoru, jako jsou mezery, tabulátory, návraty vozíku nebo konce řádků. Výchozí hodnota je **\r\n** (návrat vozíku, nový řádek).
