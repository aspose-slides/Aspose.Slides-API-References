## XmlWriterSettings::get_IndentChars() metoda

Vrací řetězec znaků, který se použije při odsazování. Toto nastavení se používá, když je hodnota [XmlWriterSettings::set_Indent](../set_indent/) nastavena na **true**.

```cpp
String System::Xml::XmlWriterSettings::get_IndentChars()
```

### Návratová hodnota

Řetězec znaků, který se použije při odsazování. Může být nastaven na libovolnou řetězcovou hodnotu. Nicméně, aby byl XML platný, měli byste uvádět pouze platné znaky bílého prostoru, jako jsou mezerníky, tabulátory, návraty vozíku nebo konce řádků. Výchozí hodnota je dva mezery.
