## XmlWriterSettings::get_CheckCharacters() metoda

Vrací hodnotu, která určuje, zda by XML writer měl kontrolovat, aby byly všechny znaky v dokumentu v souladu s částí "2.2 Characters" standardu W3C [XML 1.0 Recommendation](https://www.w3.org/TR/REC-xml/#charsets).

```cpp
bool System::Xml::XmlWriterSettings::get_CheckCharacters()
```

### Návratová hodnota

**true** pro provedení kontroly znaků; jinak **false**. Výchozí hodnota je **true**.
