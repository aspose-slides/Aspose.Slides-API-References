## XmlWriterSettings::set_NamespaceHandling(System::Xml::NamespaceHandling) metoda


Nastavuje hodnotu, která určuje, zda má [XmlWriter](../../xmlwriter/) odstraňovat duplicitní deklarace jmenných prostorů při zápisu XML obsahu. Výchozí chování je, že zapisovač vypíše všechny deklarace jmenných prostorů, které jsou přítomny v řešiteli jmenných prostorů zapisovače.

```cpp
void System::Xml::XmlWriterSettings::set_NamespaceHandling(System::Xml::NamespaceHandling value)
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| value | [System::Xml::NamespaceHandling](../../namespacehandling/) | Hodnota, která se má nastavit. |
