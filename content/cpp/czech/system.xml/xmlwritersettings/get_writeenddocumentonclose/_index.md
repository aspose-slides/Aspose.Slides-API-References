## XmlWriterSettings::get_WriteEndDocumentOnClose() metoda


Vrací hodnotu, která určuje, zda [XmlWriter](../../xmlwriter/) přidá uzavírací značky ke všem neuzavřeným značkám elementů, když je volána metoda [XmlWriter::Close](../../xmlwriter/close/).

```cpp
bool System::Xml::XmlWriterSettings::get_WriteEndDocumentOnClose()
```


### Návratová hodnota

**true** pokud budou všechny neuzavřené značky elementů uzavřeny; jinak **false**. Výchozí hodnota je **true**.
