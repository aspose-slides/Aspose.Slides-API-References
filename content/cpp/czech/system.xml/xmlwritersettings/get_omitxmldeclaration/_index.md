## XmlWriterSettings::get_OmitXmlDeclaration() metoda

Vrací hodnotu, která určuje, zda má být XML deklarace vynechána.

```cpp
bool System::Xml::XmlWriterSettings::get_OmitXmlDeclaration()
```

### Návratová hodnota

**true** pro vynechání XML deklarace; jinak **false**. Výchozí je **false**, XML deklarace je zapisována.
