## XmlWriterSettings::get_CloseOutput() metoda


Vrací hodnotu, která udává, zda by [XmlWriter](../../xmlwriter/) měl také zavřít podkladový stream nebo TextWriter, když je zavolána metoda [XmlWriter::Close](../../xmlwriter/close/).

```cpp
bool System::Xml::XmlWriterSettings::get_CloseOutput()
```


### Návratová hodnota

**true** pro také zavření podkladového streamu nebo TextWriter; jinak **false**. Výchozí hodnota je **false**.
