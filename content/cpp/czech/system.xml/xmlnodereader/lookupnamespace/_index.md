## XmlNodeReader::LookupNamespace(const String\&) metoda

Vyřeší předponu jmenného prostoru v rozsahu aktuálního elementu.

```cpp
String System::Xml::XmlNodeReader::LookupNamespace(const String &prefix) override
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| prefix | const [String](../../../system/string/)\& | Předpona, pro kterou chcete získat URI jmenného prostoru. Pro odpovídání výchozímu jmennému prostoru předávejte prázdný řetězec. Tento řetězec nemusí být atomizován. |

### Návratová hodnota

URI jmenného prostoru, na který předpona odkazuje, nebo **nullptr**, pokud není nalezena odpovídající předpona.
