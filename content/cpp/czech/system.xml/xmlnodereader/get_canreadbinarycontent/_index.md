## XmlNodeReader::get_CanReadBinaryContent() method


Vrací hodnotu, která udává, zda [XmlNodeReader](../) implementuje metody pro čtení binárního obsahu.

```cpp
bool System::Xml::XmlNodeReader::get_CanReadBinaryContent() override
```


### Návratová hodnota

**true** pokud jsou metody pro čtení binárního obsahu implementovány; jinak **false**. Třída [XmlNodeReader](../) vždy vrací **true**.
