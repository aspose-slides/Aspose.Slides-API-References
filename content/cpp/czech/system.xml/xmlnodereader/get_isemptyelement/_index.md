## XmlNodeReader::get_IsEmptyElement() metoda

Vrací hodnotu, která udává, zda je aktuální uzel prázdným prvkem (například **<MyElement/>**).

```cpp
bool System::Xml::XmlNodeReader::get_IsEmptyElement() override
```

### Návratová hodnota

**true** pokud je aktuální uzel prvkem ([XmlNodeReader::get_NodeType](../get_nodetype/) rovná se [XmlNodeType::Element](../../xmlnodetype/)) a končí **/>**; jinak **false**.
