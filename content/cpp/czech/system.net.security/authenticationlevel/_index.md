## AuthenticationLevel výčet

Specifické autentizační příznaky pro WebRequest.

```cpp
enum class AuthenticationLevel
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| None | 0 | Pro klienta a server není vyžadována žádná autentizace. |
| MutualAuthRequested | 1 | Požadavek nevyhlásí chybu, pokud server není autentizován. |
| MutualAuthRequired | 2 | Aktuální aplikace obdrží 'IOException', pokud server není autentizován. |
