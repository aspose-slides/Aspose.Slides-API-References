## EncryptionPolicy enum

Vyjmenovává šifrovací politiky.

```cpp
enum class EncryptionPolicy
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| RequireEncryption | 0 | Vyžaduje šifrování a nikdy neumožňuje šifru 'Null'. |
| AllowNoEncryption | 1 | Preferuje použití plného šifrování, ale šifru 'Null' lze použít, pokud server souhlasí. |
| NoEncryption | 2 | Povolí žádné šifrování a požaduje, aby byla použita šifra 'Null', pokud druhý cíl dokáže šifru 'Null' zpracovat. |
