## výčet LineCap

Indicates the available cap styles with which a [Pen](../../system.drawing/pen/) object can end a line.

```cpp
enum class LineCap
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| Flat | 0 | Plochý koncový tvar čáry. |
| Square | 1 | Čtvercový koncový tvar čáry. |
| Round | 2 | Kulový koncový tvar čáry. |
| Triangle | 3 | Trojúhelníkový koncový tvar čáry. |
| NoAnchor | 16 | Žádná kotva. |
| SquareAnchor | 17 | Čtvercová kotva koncového tvaru čáry. |
| RoundAnchor | 18 | Kulatá kotva koncového tvaru čáry. |
| DiamondAnchor | 19 | Kosočtvercová kotva koncového tvaru čáry. |
| ArrowAnchor | 20 | Šipková kotva koncového tvaru čáry. |
| AnchorMask | 240 | Maska použitá k ověření, zda je koncový tvar čáry kotví. |
| Custom | 255 | Vlastní koncový tvar. |
