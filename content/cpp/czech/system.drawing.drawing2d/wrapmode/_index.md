## WrapMode výčet

Určuje, jak je textura nebo gradient dlaždicována, když je menší než oblast, která se má vyplnit.

```cpp
enum class WrapMode
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| Tile | 0 | Dlaždicuje gradient nebo texturu. |
| TileFlipX | 1 | Převrátí texturu nebo gradient vodorovně a poté je dlaždicuje. |
| TileFlipY | 2 | Převrátí texturu nebo gradient svisle a poté je dlaždicuje. |
| TileFlipXY | 3 | Převrátí texturu nebo gradient vodorovně i svisle a poté je dlaždicuje. |
| Clamp | 4 | Uzavře texturu nebo gradient k hranicím objektu. |
