## GraphicsPath::AddArc(float, float, float, float, float, float) metoda


Přidá zadaný eliptický oblouk do cesty reprezentované aktuálním objektem.

```cpp
void System::Drawing::Drawing2D::GraphicsPath::AddArc(float x, float y, float width, float height, float startAngle, float sweepAngle)
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| x | **float** | Souřadnice X levého horního rohu obdélníka, který ohraničuje elipsu, ze které je oblouk kreslen |
| y | **float** | Souřadnice Y levého horního rohu obdélníka, který ohraničuje elipsu, ze které je oblouk kreslen |
| width | **float** | Šířka levého horního rohu obdélníka, který ohraničuje elipsu, ze které je oblouk kreslen |
| height | **float** | Výška levého horního rohu obdélníka, který ohraničuje elipsu, ze které je oblouk kreslen |
| startAngle | **float** | Určuje počáteční úhel oblouku ve stupních, měřený ve směru hodinových ručiček od osy X |
| sweepAngle | **float** | Určuje úhel mezi počátečním úhlem a koncem oblouku |
