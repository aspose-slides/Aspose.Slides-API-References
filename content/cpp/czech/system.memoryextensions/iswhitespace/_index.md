## System::MemoryExtensions::IsWhiteSpace(const ReadOnlySpan\<char16_t\>\&) funkce

Kontroluje, zda celý rozsah obsahuje pouze znaky bílých mezer.

```cpp
bool System::MemoryExtensions::IsWhiteSpace(const ReadOnlySpan<char16_t> &span)
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| span | const [ReadOnlySpan](../../system/readonlyspan/)\<char16_t\>\& | Rozsah, který se má zkontrolovat na bílé znaky |

### Návratová hodnota

true pokud jsou všechny znaky v rozsahu bílé, false jinak
