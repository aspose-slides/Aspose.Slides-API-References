## XmlSchemaSet::get_IsCompiled() metoda


Vrací hodnotu, která určuje, zda byly schémata XML [Schema](../../) definice jazyka (XSD) v [XmlSchemaSet](../) zkompilovány.

```cpp
bool System::Xml::Schema::XmlSchemaSet::get_IsCompiled()
```


### Návratová hodnota

**true** pokud byla schémata v [XmlSchemaSet](../) zkompilována od posledního přidání nebo odebrání schématu z [XmlSchemaSet](../); jinak **false**.
