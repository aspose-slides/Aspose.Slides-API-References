## XmlSchemaGroup třída

Representuje element **group** z XML [Schema](../) podle specifikace World Wide [Web](../../system.web/) Consortium (W3C). Tato třída definuje skupiny na úrovni **schema**, které jsou odkazovány z komplexních typů. Skupinu deklarací elementů tak, aby mohly být začleněny jako skupina do definic komplexních typů.

```cpp
class XmlSchemaGroup : public System::Xml::Schema::XmlSchemaAnnotated
```

## Poznámky

Objekty této třídy by měly být alokovány pouze pomocí funkce [System::MakeObject()](../../system/makeobject/). Nikdy nevytvářejte instance tohoto typu na zásobníku ani pomocí operátoru new, protože to vede k chybám za běhu a/nebo selháním aserce. Vždy tuto třídu zabalte do ukazatele [System::SmartPtr](../../system/smartptr/) a používejte tento ukazatel k předávání jako argument funkcím.
