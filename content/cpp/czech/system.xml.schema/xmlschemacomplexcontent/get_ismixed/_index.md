## XmlSchemaComplexContent::get_IsMixed() metoda

Vrací informace, které určují, zda typ má smíšený obsahový model.

```cpp
bool System::Xml::Schema::XmlSchemaComplexContent::get_IsMixed()
```

### Návratová hodnota

Pokud je tato hodnota **true**, jsou mezi podřízenými elementy komplexního typu povolena znaková data (smíšený obsahový model). Výchozí hodnota je **false**. Volitelné.
