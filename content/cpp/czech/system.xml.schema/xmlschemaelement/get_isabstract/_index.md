## XmlSchemaElement::get_IsAbstract() metoda


Vrací informaci, která určuje, zda lze prvek použít v instančním dokumentu.

```cpp
bool System::Xml::Schema::XmlSchemaElement::get_IsAbstract()
```


### Návratová hodnota

Pokud je **true**, prvek se nesmí v instančním dokumentu objevit. Výchozí hodnota je **false**. Volitelné.
