## XmlSchemaElement::get_IsNillable() metoda


Vrací informaci, která udává, zda může **xsi:nil** nastat v instančních datech. Udává, zda může být prvku přiřazena explicitní hodnota nil.

```cpp
bool System::Xml::Schema::XmlSchemaElement::get_IsNillable()
```


### Návratová hodnota

Pokud je nillable **true**, umožní to instanci prvku mít atribut **nil** nastavený na **true**. Atribut **nil** je definován jako součást XML [Schema](../../) jmenného prostoru pro instance. Výchozí hodnota je **false**. Volitelné.
