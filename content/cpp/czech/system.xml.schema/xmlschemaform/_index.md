## XmlSchemaForm výčtový typ


Určuje, zda atributy nebo elementy musí být kvalifikovány předponou jmenného prostoru.

```cpp
enum class XmlSchemaForm
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| None | 0 | Forma elementu a atributu není ve schématu specifikována. |
| Qualified | 1 | Elementy a atributy musí být kvalifikovány předponou jmenného prostoru. |
| Unqualified | 2 | Elementy a atributy nevyžadují kvalifikaci předponou jmenného prostoru. |
