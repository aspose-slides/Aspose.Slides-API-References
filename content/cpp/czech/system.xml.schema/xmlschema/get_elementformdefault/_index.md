## XmlSchema::get_ElementFormDefault() metoda


Vrací formu pro prvky deklarované v cílovém jmenném prostoru schématu.

```cpp
XmlSchemaForm System::Xml::Schema::XmlSchema::get_ElementFormDefault()
```


### Návratová hodnota

Hodnota XmlSchemaForm, která určuje, zda jsou prvky z cílového jmenného prostoru povinně kvalifikovány předponou jmenného prostoru. Výchozí hodnota je [XmlSchemaForm::None](../../xmlschemaform/).
