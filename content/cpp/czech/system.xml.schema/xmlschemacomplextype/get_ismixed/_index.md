## XmlSchemaComplexType::get_IsMixed() metoda


Returns information that determines if the complex type has a mixed content model (markup within the content).

```cpp
bool System::Xml::Schema::XmlSchemaComplexType::get_IsMixed() override
```


### Návratová hodnota

**true**, pokud mohou být mezi podřízenými prvky tohoto komplexního typu přítomna znaková data; jinak **false**. Výchozí hodnota je **false**. Volitelné.
