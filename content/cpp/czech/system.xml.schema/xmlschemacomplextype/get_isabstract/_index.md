## XmlSchemaComplexType::get_IsAbstract() metoda


Vrací informaci, která určuje, zda lze prvek **complexType** použít v instančním dokumentu.

```cpp
bool System::Xml::Schema::XmlSchemaComplexType::get_IsAbstract()
```


### Návratová hodnota

Pokud je **true**, prvek nemůže tento **complexType** prvek použít přímo a musí použít komplexní typ odvozený od tohoto **complexType** prvku. Výchozí hodnota je **false**. Volitelné.
