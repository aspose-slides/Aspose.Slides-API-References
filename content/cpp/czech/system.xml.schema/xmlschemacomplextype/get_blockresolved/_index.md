## XmlSchemaComplexType::get_BlockResolved() metoda


Vrací hodnotu po tom, co byl typ zkompilován do post-schéma-validace informační sady (infoset). Tato hodnota určuje, jak je typ vynucován, když je v dokumentu instance použito **xsi:type**.

```cpp
XmlSchemaDerivationMethod System::Xml::Schema::XmlSchemaComplexType::get_BlockResolved()
```


### Návratová hodnota

Hodnota post-schéma-validované infosetu. Výchozí je hodnota **BlockDefault** na elementu **schema**.
