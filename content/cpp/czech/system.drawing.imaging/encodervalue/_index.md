## EncoderValue výčet

Určuje hodnotu parametru předávanou enkodéru JPEG nebo TIFF obrázku.

```cpp
enum class EncoderValue
```

| Název | Hodnota | Popis |

| CompressionRle | 5 | Určuje kompresní metodu RLE pro TIFF obrázek. |
| CompressionNone | 6 | Určuje žádnou kompresi pro TIFF obrázek. |
| ScanMethodInterlaced | 7 | Prokládaný režim. |
| ScanMethodNonInterlaced | 8 | Neprokládaný režim. |
| VersionGif87 | 9 | Určuje verzi 87 pro TIFF obrázek. |
| VersionGif89 | 10 | Určuje verzi 89a pro GIF obrázek. |
| RenderProgressive | 11 | Progresivní režim. |
| RenderNonProgressive | 12 | Neprogresivní režim. |
| TransformRotate90 | 13 | Určuje bezeztrátovou rotaci o 90 stupňů po směru hodinových ručiček pro JPEG obrázek. |

| TransformRotate270 | 15 | Určuje bezeztrátovou rotaci o 270 stupňů po směru hodinových ručiček pro JPEG obrázek. |

| MultiFrame | 18 | Kódování více snímků. |
| LastFrame | 19 | Poslední snímek více-snímkového obrázku. |
| Flush | 20 | Objekt enkodéru bude uzavřen. |
| FrameDimensionTime | 21 | Určuje časovou dimenzi snímku pro GIF obrázek. |
| FrameDimensionResolution | 22 | Dimenze snímku rozlišení. |
| FrameDimensionPage | 23 | Určuje dimenzi snímku stránky pro TIFF obrázek. |
