## FileShare výčet

Určuje, jaký typ přístupu mohou mít jiné [FileStream](../filestream/) objekty k otevíranému souboru.

```cpp
enum class FileShare
```

### Values

| Název | Hodnota | Popis |
| --- | --- | --- |
| None | 0 | Žádný přístup. |
| Read | 1 | Přístup jen pro čtení. |
| Write | 2 | Přístup jen pro zápis. |
| ReadWrite | 3 | Přístup pro čtení i zápis. |
| Delete | 4 | Soubor může být smazán. |
| Inheritable | 16 | Zpřístupní popisovač souboru dědit potomky. |
