## TextReader::Peek() metoda

Přečte jeden znak ze streamu, aniž by změnil čtecí kurzor streamu.

```cpp
virtual int System::IO::TextReader::Peek()
```

### Návratová hodnota

Přečtený znak kódovaný pomocí kódování UTF-16; pokud je přečtený znak v UTF-16 reprezentován dvěma kódy, vrátí se pouze vysoký surragate; pokud nebyl přečten žádný znak, vrátí se -1
