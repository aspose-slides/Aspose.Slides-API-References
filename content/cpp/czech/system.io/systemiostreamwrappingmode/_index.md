## SystemIOStreamWrappingMode enum

Určuje režim I/O operací, které obaly provedou na streamy podobné [System::IO::Stream](../stream/).

```cpp
enum class SystemIOStreamWrappingMode
```

### Hodnoty

| Name | Value | Description |
| --- | --- | --- |
| Binary | 0 | Režim, který umožňuje vstupním operacím kódovat bajty proudu do dat typu char_type a dekódovat data typu char_type do bajtů proudu pro výstupní operace. |
| Conversion | 1 | Režim, který umožňuje vstupním operacím převádět bajty proudu z typu **uint8_t** na typ char_type a naopak pro výstupní operace. |
