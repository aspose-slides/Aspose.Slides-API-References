## FileAttributes výčet

Reprezentuje atributy adresáře nebo souboru.

```cpp
enum class FileAttributes
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| Archive | 32 | Objekt souborového systému je kandidátem na odstranění nebo zálohování. |
| Compressed | 2048 | Objekt souborového systému je komprimován. |
| Device | 64 | Není používáno. |
| Directory | 16 | Objekt souborového systému je adresář. |
| Encrypted | 16384 | Objekt souborového systému je šifrován. |
| Hidden | 2 | Objekt souborového systému je skrytý. |
| IntegrityStream | 32768 | Objekt souborového systému obsahuje podporu integrity dat. |
| Normal | 128 | Objekt souborového systému je soubor, který nemá žádné speciální atributy. |
| NotContentIndexed | 8192 | Objekt souborového systému nebude indexován službou indexování obsahu. |
| NoScrubData | 131072 | Objekt souborového systému není zahrnut do skenu integrity dat. |
| Offline | 4096 | Objekt souborového systému je offline a jeho data nejsou okamžitě dostupná. |
| ReadOnly | 1 | Objekt souborového systému je jen pro čtení. |
| ReparsePoint | 1024 | Objekt souborového systému je soubor, který obsahuje přeinterpretovací bod. |
| SparseFile | 512 | Objekt souborového systému je řídký soubor. |
| System | 4 | Objekt souborového systému je systémový soubor. |
| Temporary | 256 | Objekt souborového systému je dočasný soubor. |
| Invalid | 0 | Neplatná hodnota. |
