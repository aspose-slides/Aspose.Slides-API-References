## STDIOStreamPositionPreference enum

Určuje, která pozice v proudu je upřednostňována jako společná pozice pro čtení a zápis, když std::basic_iostream a jeho potomci budou mít při vytvoření obalu odlišné pozice pro čtení a zápis.

```cpp
enum class STDIOStreamPositionPreference
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| Zero | 0 | Pozice Zero bude nastavena jako pozice pro čtení i zápis. |
| ReadPosition | 1 | Pozice gptr bude nastavena jako pozice pro čtení i zápis. |
| WritePosition | 2 | Pozice pptr bude nastavena jako pozice pro čtení i zápis. |
