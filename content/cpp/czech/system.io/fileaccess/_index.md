## FileAccess enum

Specifies the type of access when opening the file.

```cpp
enum class FileAccess
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| Read | 1 | Pouze pro čtení. |
| Write | 2 | Pouze pro zápis. |
| ReadWrite | n/a | Přístup pro čtení i zápis. |
