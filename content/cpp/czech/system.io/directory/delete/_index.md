```cpp
static void System::IO::Directory::Delete(const String &path, bool recursive=false)
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| path | const [String](../../../system/string/)\& | Cesta k adresáři nebo souboru, který má být odstraněn |
| recursive | **bool** | Pokud **path** určuje ne-prázdný adresář, pak **recursive** určuje, zda má být veškerý obsah adresáře odstraněn rekurzivně; pokud je adresář určený pomocí **path** ne-prázdný a **recursive** je 'false', operace selže |
