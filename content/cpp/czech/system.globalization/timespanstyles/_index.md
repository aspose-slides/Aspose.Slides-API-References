## TimeSpanStyles výčet


Určuje možnosti formátování, které přizpůsobují parsování řetězce pro metody, které převádějí textovou reprezentaci časového intervalu na objekt Timespan.

```cpp
enum class TimeSpanStyles : int32_t
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| None | 0 | Časový interval reprezentovaný vstupním řetězcem je interpretován jako záporný interval pouze pokud je přítomen záporný znak. |
| AssumeNegative | 1 | Časový interval reprezentovaný vstupním řetězcem je vždy interpretován jako záporný interval. |
