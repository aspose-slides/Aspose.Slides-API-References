## CompareInfo::IsSuffix(const String\&, const String\&, CompareOptions) const metoda

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| source | const [String](../../../system/string/)\& | Zdrojový řetězec. |

| options | [CompareOptions](../../compareoptions/) | Možnosti porovnání. |

True, pokud řetězec končí příponou; jinak false.
