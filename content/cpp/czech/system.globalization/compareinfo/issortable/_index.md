## CompareInfo::IsSortable(char16_t) metoda

Kontroluje, zda je zadaný znak seřaditelný.

```cpp
static bool System::Globalization::CompareInfo::IsSortable(char16_t ch)
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| ch | char16_t | Unicode znak. |

### Návratová hodnota

True pokud je **ch** seřaditelný; jinak false.

## CompareInfo::IsSortable(const String\&) metoda

Kontroluje, zda je zadaný řetězec seřaditelný.

```cpp
static bool System::Globalization::CompareInfo::IsSortable(const String &text)
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| text | const [String](../../../system/string/)\& | Řetězec. |

### Návratová hodnota

True pokud **text** není prázdný a všechny znaky v **text** jsou seřaditelné; jinak false.
