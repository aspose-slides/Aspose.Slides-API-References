## NumberStyles výčet

Styl čísla povolený při parsování.

```cpp
enum class NumberStyles : int32_t
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| None | 0 | Žádné symboly, které nejsou číslice. |
| AllowLeadingWhite | 1 | Povolit úvodní mezery. |
| AllowTrailingWhite | 2 | Povolit koncové mezery. |
| AllowLeadingSign | 4 | Povolit úvodní znaménko. |
| Integer | n/a | Výchozí formátování celých čísel. |
| AllowTrailingSign | 8 | Povolit koncové znaménko. |
| AllowParentheses | 16 | Povolit závorky pro záporné hodnoty. |
| AllowDecimalPoint | 32 | Povolit desetinnou čárku. |
| AllowThousands | 64 | Povolit oddělovače skupin. |
| Number | n/a | Výchozí kompozitní formát čísla. |
| AllowExponent | 128 | Povolit exponentové znaménko. |
| Float | n/a | Výchozí formát čísla s plovoucí desetinnou čárkou. |
| AllowCurrencySymbol | 256 | Povolit měnový symbol. |
| Currency | n/a | Výchozí formát měny. |
| Any | n/a | Povolit jakýkoli specifikátor formátu. |
| AllowHexSpecifier | 512 | Povolit šestnáctková čísla. |
| HexNumber | n/a | Výchozí formát šestnáctkového čísla. |
