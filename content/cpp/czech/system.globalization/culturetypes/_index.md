## CultureTypes enum

Culture categories bitmask entries.

```cpp
enum class CultureTypes : int32_t
```

### Values

| Název | Hodnota | Popis |
| --- | --- | --- |
| NeutralCultures | 1 | Kultura, která je specifická pro jazyk, ale ne pro zemi nebo region. |
| SpecificCultures | 2 | Specifické pro zemi/region. |
| InstalledWin32Cultures | 4 | Kultury nainstalované v OS. |
| AllCultures | n/a | Všechny dostupné kultury. |
| UserCustomCulture | 8 | Uživatelsky definované kultury. |
| ReplacementCultures | 16 | Uživatelsky definované nahrazení existujících kultur. |
| WindowsOnlyCultures | 32 | Zastaralé. |
| FrameworkCultures | 64 | Zastaralé. |
