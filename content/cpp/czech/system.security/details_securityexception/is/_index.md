## Details_SecurityException::Is(const System::TypeInfo\&) const metoda

```cpp
bool System::Security::Details_SecurityException::Is(const System::TypeInfo &target) const override
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| target | const [System::TypeInfo](../../../system/typeinfo/)\& | [TypeInfo](../../../system/typeinfo/) struktura popisující typ, proti kterému se má testovat aktuální objekt. |

### Návratová hodnota

True pokud je objekt označeného typu nebo jeho podtřídy, false jinak.

## Poznámky

Ověří, zda objekt představuje instanci typu popsaného pomocí targetType. Analogie C# operátoru 'is'.
