## XPathNavigator::get_IsEmptyElement() metoda

Když je přepsána v odvozené třídě, získá hodnotu, která určuje, zda je aktuální uzel prázdným prvkem bez ukončovací značky.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::get_IsEmptyElement()=0
```

### Návratová hodnota

**true** pokud je aktuální uzel prázdným prvkem; jinak **false**.
