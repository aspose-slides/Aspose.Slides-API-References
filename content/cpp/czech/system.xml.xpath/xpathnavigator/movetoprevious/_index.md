## XPathNavigator::MoveToPrevious() method


Když je přepsána v odvozené třídě, přesune [XPathNavigator](../) na předchozí sourozenecký uzel aktuálního uzlu.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToPrevious()=0
```


### Return Value

**true** pokud je [XPathNavigator](../) úspěšné při přesunu na předchozí sourozenecký uzel; jinak **false**, pokud neexistuje předchozí sourozenecký uzel nebo pokud je [XPathNavigator](../) aktuálně umístěn na uzlu atributu. Pokud **false**, pozice [XPathNavigator](../) zůstane nezměněna.
