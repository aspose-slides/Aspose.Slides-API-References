## XPathNavigator::MoveToAttribute(String, String) metoda

Přesune [XPathNavigator](../) na atribut s odpovídajícím místním názvem a URI jmenného prostoru.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToAttribute(String localName, String namespaceURI)
```

### Argumenty

| Parameter | Type | Description |
| --- | --- | --- |
| localName | [String](../../../system/string/) | Místní název atributu. |
| namespaceURI | [String](../../../system/string/) | URI jmenného prostoru atributu; **nullptr** pro prázdný jmenný prostor. |

### Návratová hodnota

**true** pokud je [XPathNavigator](../) úspěšné při přesunu na atribut; jinak **false**. Pokud **false**, pozice [XPathNavigator](../) zůstane nezměněna.
