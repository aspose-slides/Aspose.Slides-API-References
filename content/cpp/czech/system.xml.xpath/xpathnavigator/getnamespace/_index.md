## XPathNavigator::GetNamespace(String) metoda


Returns the value of the namespace node corresponding to the specified local name.

```cpp
virtual String System::Xml::XPath::XPathNavigator::GetNamespace(String name)
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| name | [String](../../../system/string/) | The local name of the namespace node. |

### Návratová hodnota

Instance typu [String](../../../system/string/) obsahující hodnotu uzlu jmenného prostoru; [String::Empty](../../../system/string/empty/) pokud není nalezen odpovídající uzel jmenného prostoru nebo pokud [XPathNavigator](../) není umístěn na uzel elementu.
