## XPathNavigator::get_HasAttributes() metoda

Vrací hodnotu, která určuje, zda má aktuální uzel nějaké atributy.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::get_HasAttributes()
```

### Návratová hodnota

**true** pokud má aktuální uzel atributy; vrací **false**, pokud aktuální uzel nemá žádné atributy, nebo pokud [XPathNavigator](../) není umístěn na elementový uzel.
