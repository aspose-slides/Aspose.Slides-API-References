## XPathNavigator::get_LocalName() metoda


Když je v odvozené třídě přepsáno, získá [XPathNavigator::get_Name](../get_name/) aktuálního uzlu bez jakékoli předpony jmenného prostoru.

```cpp
virtual String System::Xml::XPath::XPathNavigator::get_LocalName()=0
```


### Návratová hodnota

[String](../../../system/string/) obsahující lokální název aktuálního uzlu, nebo [String::Empty](../../../system/string/empty/), pokud aktuální uzel nemá název (například textové nebo komentářové uzly).
