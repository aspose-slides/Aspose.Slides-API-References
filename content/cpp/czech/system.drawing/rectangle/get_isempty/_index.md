## Rectangle::get_IsEmpty() const metoda


Určuje, zda mají souřadnice X a Y levého horního rohu obdélníku reprezentovaného aktuálním objektem, stejně jako jeho šířka a výška, hodnotu 0.

```cpp
bool System::Drawing::Rectangle::get_IsEmpty() const
```


### Návratová hodnota

True pokud mají souřadnice X a Y levého horního rohu obdélníku reprezentovaného aktuálním objektem, stejně jako jeho šířka a výška, hodnotu 0, jinak - false
