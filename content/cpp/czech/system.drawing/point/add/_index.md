## Point::Add(const Point&, const Size&) metoda

Přidá hodnoty šířky a výšky určeného [Size](../../size/) objektu k hodnotám souřadnic X a Y určeného [Point](../) objektu příslušně.

```cpp
static Point System::Drawing::Point::Add(const Point &point, const Size &size)
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| point | const [Point](../)\& | Parametr point k překladu |
| size | const [Size](../../size/)\& | Objekt [Size](../../size/), který určuje hodnoty, které se mají přidat k hodnotám souřadnic **point** |

### Návratová hodnota

Nový [Point](../) objekt, jehož hodnota souřadnice X je rovna součtu hodnoty souřadnice X **point** a hodnoty šířky **size** a hodnota souřadnice Y je rovna součtu hodnoty souřadnice Y **point** a hodnoty výšky **size**
