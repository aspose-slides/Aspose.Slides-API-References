## RectangleF::Offset(const PointF\&) metoda

Posune pozici obdélníku reprezentovaného aktuálním objektem o specifikované hodnoty.

```cpp
void System::Drawing::RectangleF::Offset(const PointF &pos)
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| pos | const [PointF](../../pointf/)\& | Objekt [PointF](../../pointf/), který určuje velikost posunu obdélníku; hodnota X souřadnice bodu určuje částku, která se přičte ke X souřadnici levého horního rohu obdélníku, a hodnota Y souřadnice bodu určuje částku, která se přičte ke Y souřadnici levého horního rohu obdélníku |
