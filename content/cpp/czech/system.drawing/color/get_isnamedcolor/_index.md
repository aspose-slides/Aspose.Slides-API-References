## Color::get_IsNamedColor() const metoda


Vrací hodnotu, která určuje, zda struktura [Color](../) představuje pojmenovanou barvu nebo člen výčtu KnownColor.

```cpp
bool System::Drawing::Color::get_IsNamedColor() const
```


### Návratová hodnota

True pokud byl [Color](../) vytvořen pomocí metody FromName(String) nebo metody [FromKnownColor(KnownColor)](../fromknowncolor/); jinak vrací false.
