## StringTrimming enum

Specifikuje, jak by měly být znaky oříznuty z řetězce, který se nevejde do tvaru rozvržení.

```cpp
enum class StringTrimming
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| None | 0 | Žádné ořezávání. |
| Character | 1 | Oříznout na nejbližší znak. |
| Word | 2 | Oříznout na nejbližší slovo. |
| EllipsisCharacter | 3 | Oříznout na nejbližší znak a vložit výpustku na konci řetězce. |
| EllipsisWord | 4 | Oříznout na nejbližší slovo a vložit výpustku na konci řetězce. |
| EllipsisPath | 5 | Střed je odstraněn z ořezaných řádků a nahrazen výpustkou. Zachovat co nejvíce posledního segmentu řádku odděleného lomítkem. |
