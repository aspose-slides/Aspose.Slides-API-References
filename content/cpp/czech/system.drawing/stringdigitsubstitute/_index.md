## Výčet StringDigitSubstitute

Určuje, jak jsou číslice v řetězci nahrazovány podle národního prostředí nebo jazyka.

```cpp
enum class StringDigitSubstitute
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| User | 0 | Uživatelsky definovaná náhrada. |
| None | 1 | Substituce je zakázána. |
| National | 2 | Nahrazuje číslice odpovídající oficiálnímu národnímu jazyku uživatelova národního prostředí. |
| Traditional | 3 | Nahrazuje číslice odpovídající uživatelovu rodnému písmu nebo jazyku, který nemusí být stejný jako oficiální národní jazyk uživatelova národního prostředí. |
