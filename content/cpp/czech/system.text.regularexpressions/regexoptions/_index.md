## RegexOptions enum


[Regex](../regex/) volby.

```cpp
enum class RegexOptions
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| None | 0 | Výchozí chování. |
| Compiled | 1 | Kompilovat regex pro výkon. Vždy provedeno ve výchozím nastavení. |
| CultureInvariant | 2 | Použít shodu nezávislou na kultuře. Ignorováno. |
| ECMAScript | 4 | Použít syntaxi ECMAScript. Ignorováno. |
| ExplicitCapture | 8 | Pouze explicitní zachytávání. Ignorováno. |
| IgnoreCase | 16 | Ignorovat velikost písmen při shodě. |
| IgnorePatternWhitespace | 32 | Ignorovat mezery v vzoru. Nepodporováno. |
| Multiline | 64 | Považovat '^' a '$' za začátek a konec řádku, ne za celý řetězec. |
| RightToLeft | 128 | Shoda zprava doleva. Nepodporováno. |
| Singleline | 256 | Způsobí, že '.' odpovídá libovolnému znaku bez výjimek (normálně se neporovnávají znaky nového řádku). |
