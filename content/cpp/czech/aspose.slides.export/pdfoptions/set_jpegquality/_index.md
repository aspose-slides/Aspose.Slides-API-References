## PdfOptions::set_JpegQuality(uint8_t) method

Nastaví hodnotu určující kvalitu JPEG obrázků uvnitř PDF dokumentu. Zapište **uint8_t**.

```cpp
void Aspose::Slides::Export::PdfOptions::set_JpegQuality(uint8_t value) override
```

## Poznámky

Má vliv pouze tehdy, když dokument obsahuje JPEG obrázky.

Použijte tuto vlastnost k získání nebo nastavení kvality obrázků v dokumentu při ukládání do formátu PDF. Hodnota se může pohybovat od 0 do 100, kde 0 znamená nejhorší kvalitu, ale maximální kompresi, a 100 znamená nejlepší kvalitu, ale minimální kompresi.

Výchozí hodnota je **100**.
