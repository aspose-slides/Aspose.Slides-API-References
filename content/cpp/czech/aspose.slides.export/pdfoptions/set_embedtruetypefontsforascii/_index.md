## PdfOptions::set_EmbedTrueTypeFontsForASCII(bool) metoda

Určuje, zda [Aspose.Slides](../../../aspose.slides/) vloží běžná písma pro text v ASCII (rozsah kódů 33..127). [Fonts](../../../aspose.slides/fonts/) pro znaky s kódy vyššími než 127 jsou vždy vloženy. Seznam běžných písem zahrnuje základních 14 písem PDF a další uživatelem určená písma. Zápis **bool**.

```cpp
void Aspose::Slides::Export::PdfOptions::set_EmbedTrueTypeFontsForASCII(bool value) override
```

## Poznámky

Výchozí hodnota je **true**.
