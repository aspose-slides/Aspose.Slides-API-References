## PdfOptions::get_EmbedTrueTypeFontsForASCII() metoda


Určuje, zda [Aspose.Slides](../../../aspose.slides/) bude vkládat běžná písma pro ASCII (rozsah kódů 33..127) text. [Fonts](../../../aspose.slides/fonts/) pro kódy znaků větší než 127 jsou vždy vkládány. Seznam běžných písem zahrnuje 14 základních písem PDF a další uživatelem specifikovaná písma. Číst **bool**.

```cpp
bool Aspose::Slides::Export::PdfOptions::get_EmbedTrueTypeFontsForASCII() override
```

## Poznámky


Výchozí hodnota je **true**.
