## NotesPositions enum

Reprezentuje pravidlo pro vykreslení poznámek do exportovaného dokumentu

```cpp
enum class NotesPositions
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| None | 0 | Určuje, že poznámky se vůbec nemají zobrazovat. |
| BottomFull | 1 | Určuje, že poznámky se mají plně zobrazit pomocí dalších stránek podle potřeby. |
| BottomTruncated | 2 | Určuje, že poznámky se mají zobrazit pouze na jedné stránce. |
