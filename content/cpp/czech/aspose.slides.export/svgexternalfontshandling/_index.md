## SvgExternalFontsHandling enum

Reprezentuje způsob, jak zacházet s externími fonty používanými pro vykreslování textu.

```cpp
enum class SvgExternalFontsHandling
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| AddLinksToFontFiles | 0 | Přidá odkazy na samostatné soubory fontů do sekce stylu SVG souboru. |
| Embed | 1 | Uloží data fontů přímo do SVG souboru. Před použitím této možnosti zkontrolujte licenční smlouvy všech externích fontů. |
| Vectorize | 2 | Uloží celý text používající externí fonty jako grafiku. |
