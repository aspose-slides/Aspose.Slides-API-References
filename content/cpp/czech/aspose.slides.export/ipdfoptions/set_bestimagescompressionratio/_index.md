## IPdfOptions::set_BestImagesCompressionRatio(bool) metoda

Určuje, zda má být pro každý obrázek automaticky vybráno nejúčinnější komprese (namísto výchozí). Pokud je nastaveno na **bool**.true, pro každý obrázek v prezentaci bude zvolen nejvhodnější kompresní algoritmus, což povede k menší velikosti výsledného PDF dokumentu.

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_BestImagesCompressionRatio(bool value)=0
```

## Poznámky

Výběr nejlepšího poměru komprese obrazu je výpočetně náročný a vyžaduje dodatečnou paměť RAM, a tato volba je ve výchozím nastavení **bool**.false.

Výchozí hodnota je **bool**.false.
