## IPdfOptions::get_SufficientResolution() metoda


Vrací hodnotu určující rozlišení obrázků v PDF dokumentu.

```cpp
virtual float Aspose::Slides::Export::IPdfOptions::get_SufficientResolution()=0
```

## Poznámky


Vlastnost ovlivňuje velikost souboru, čas exportu a kvalitu obrázku.

Výchozí hodnota je **96**.

Efekt tohoto parametru závisí na několika faktorech. Algoritmus se snaží získat nejlepší velikost výstupního obrázku podle hodnoty vlastnosti, velikosti zdrojového obrázku a velikosti rámečku obrázku. Použití podobných hodnot vlastnosti může dát stejný výsledek. Doporučuje se použít krok 16 nebo 32 pro viditelný efekt.

Přečíst **float**.
