## IPdfOptions::set_RasterizeUnsupportedFontStyles(bool) metoda


Indikuje, zda by měl být text rasterizován jako bitmapa a uložen do PDF, pokud písmo nepodporuje tučné stylování. Tento přístup může zlepšit kvalitu textu ve výsledném PDF pro konkrétní písma. Zapište **bool**.

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_RasterizeUnsupportedFontStyles(bool value)=0
```

## Poznámky


Výchozí hodnota je **false**.
