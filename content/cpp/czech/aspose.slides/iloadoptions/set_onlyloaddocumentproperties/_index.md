## ILoadOptions::set_OnlyLoadDocumentProperties(bool) metoda

Tato vlastnost dává smysl, pokud je soubor prezentace chráněn heslem. Hodnota true znamená, že musí být načteny pouze vlastnosti dokumentu z šifrovaného souboru prezentace a heslo musí být ignorováno. Hodnota false znamená, že celá šifrovaná prezentace musí být načtena pomocí správného hesla. Pokud prezentace není šifrována, hodnota vlastnosti je vždy ignorována. Pokud vlastnosti dokumentu šifrovaného souboru nejsou veřejné a hodnota vlastnosti je true, pak nelze načíst vlastnosti dokumentu a bude vyvolána výjimka. Zapíše **bool**.

virtual void Aspose::Slides::ILoadOptions::set_OnlyLoadDocumentProperties(bool value)=0
