## IShape::get_Frame() metoda


Vrací vlastnosti rámce tvaru. Přečtěte si [IShapeFrame](../../ishapeframe/).

```cpp
virtual System::SharedPtr<IShapeFrame> Aspose::Slides::IShape::get_Frame()=0
```

## Poznámky


Hodnota každé vlastnosti vrácené instance [IShapeFrame](../../ishapeframe/) není nedefinovaná (není NaN ani NotDefined). Hodnota každé vlastnosti přiřazené instance [IShapeFrame](../../ishapeframe/) musí být definovaná (nesmí být NaN ani NotDefined). Můžete nastavit nedefinované hodnoty pro vlastnosti instance RawFrame.
