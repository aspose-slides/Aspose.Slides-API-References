## IShape::get_Height() metoda

Vrátí výšku tvaru, měřenou v bodech. Pouze pro čtení **float**.

```cpp
virtual float Aspose::Slides::IShape::get_Height()=0
```

## Poznámky

Vrácená hodnota je vždy definována a nikdy není [std::numeric_limits<float>::quiet_NaN()](../). Přiřazená hodnota také musí být definována; přiřaďte [std::numeric_limits<float>::quiet_NaN()](../) pouze k vlastnostem instance **RawFrame**.
