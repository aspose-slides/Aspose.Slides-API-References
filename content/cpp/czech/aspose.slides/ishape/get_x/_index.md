## IShape::get_X() metoda

Získá souřadnici x levého horního rohu tvaru, měřenou v bodech. Čte **float**.

```cpp
virtual float Aspose::Slides::IShape::get_X()=0
```

## Poznámky

Vrácená hodnota je vždy definovaná a nikdy není [std::numeric_limits<float>::quiet_NaN()](../). Přiřazená hodnota musí být také definovaná; přiřaďte [std::numeric_limits<float>::quiet_NaN()](../) pouze k vlastnostem instance **RawFrame**.
