## IShape::set_Rotation(float) metoda

Nastavuje počet stupňů, o které je určený tvar otočen kolem osy z. Kladná hodnota označuje otáčení po směru hodinových ručiček; záporná hodnota označuje otáčení proti směru hodinových ručiček. Zapište **float**.

```cpp
virtual void Aspose::Slides::IShape::set_Rotation(float value)=0
```

## Poznámky

Vrácená hodnota je vždy definována (není std::numeric_limits<float>::quiet_NaN()). Přiřazená hodnota musí být definována (není std::numeric_limits<float>::quiet_NaN()). Můžete nastavit nedefinované hodnoty pro vlastnosti instance RawFrame.
