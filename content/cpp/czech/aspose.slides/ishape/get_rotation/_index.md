## IShape::get_Rotation() metoda

Vrací počet stupňů, o který je zadaný tvar otočený kolem osy z. Kladná hodnota označuje otáčení po směru hodinových ručiček; záporná hodnota označuje otáčení proti směru hodinových ručiček. Číst **float**.

```cpp
virtual float Aspose::Slides::IShape::get_Rotation()=0
```

## Poznámky

Vrácená hodnota je vždy definována (není std::numeric_limits<float>::quiet_NaN()). Přiřazená hodnota musí být definována (není std::numeric_limits<float>::quiet_NaN()). Můžete nastavit nedefinované hodnoty pro vlastnosti instance RawFrame.
