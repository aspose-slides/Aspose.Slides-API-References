## PersistenceType výčet

Určuje metodu používanou k uložení vlastností ActiveX controlu.

```cpp
enum class PersistenceType
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| NotDefined | -1 | ID perzistence nebylo zadáno. |
| PersistPropertyBag | 0 | Specifikuje, že ActiveX control je perzistován pomocí perzistence založené na property-bag. Perzistence založená na property-bag ukládá ActiveX control pomocí kolekce párů název-hodnota, které určují data perzistovaná ActiveX controlem. |
| PersistStream | 1 | Specifikuje, že ActiveX control je perzistován pomocí perzistence založené na proudu, která nepodporuje inicializaci ActiveX controlu do výchozího stavu. |
| PersistStreamInit | 2 | Specifikuje, že ActiveX control je perzistován pomocí perzistence založené na proudu, která podporuje inicializaci ActiveX controlu do výchozího stavu. |
| PersistStorage | 3 | Specifikuje, že ActiveX control je perzistován pomocí perzistence založené na úložišti. |
