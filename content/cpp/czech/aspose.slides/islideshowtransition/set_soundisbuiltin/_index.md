## ISSlideShowTransition::set_SoundIsBuiltIn(bool) metoda

Specifikuje, zda je tento zvuk vestavěným zvukem. Pokud je tento atribut nastaven na true, pak je generující aplikace upozorněna, aby zkontrolovala atribut name určený pro tento zvuk v jejím seznamu vestavěných zvuků a může následně zobrazit vlastní název nebo uživatelské rozhraní podle potřeby. Zapisuje **bool**.

virtual void Aspose::Slides::ISlideShowTransition::set_SoundIsBuiltIn(bool value)=0
