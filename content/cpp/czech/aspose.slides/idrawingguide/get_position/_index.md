## IDrawingGuide::get_Position() metoda

Vrací pozici kreslicího vodítka v bodech od horního levého rohu snímku. Čte se **float**.

```cpp
virtual float Aspose::Slides::IDrawingGuide::get_Position()=0
```

## Poznámky

Typický rozsah hodnot je od nuly do výšky snímku pro vodorovné vodítko a od nuly do šířky snímku pro svislé vodítko.
