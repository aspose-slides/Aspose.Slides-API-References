## BlobManagementOptions::set_PresentationLockingBehavior(Aspose::Slides::PresentationLockingBehavior) metoda


Tato vlastnost určuje, zda instance třídy [Presentation](../../presentation/) může být vlastníkem zdroje - souboru nebo proudu během životnosti instance. Pokud je instance vlastníkem, zamkne zdroj. To pomáhá zlepšit využití paměti a výkon při práci s BLOBy, ale zdroj (proud nebo soubor) nelze změnit během životnosti instance [Presentation](../../presentation/)'s.
