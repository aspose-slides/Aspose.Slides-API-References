## ResourceLoadingAction výčet

Specifikuje režim načítání externích zdrojů.

```cpp
enum class ResourceLoadingAction
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| Default | 0 | [Aspose.Slides](../) načte externí zdroj jako obvykle. |
| Skip | 1 | [Aspose.Slides](../) vynechá načítání externího zdroje. Pouze odkaz bez dat bude uložen pro obrázek. |
| UserProvided | 2 | [Aspose.Slides](../) použije pole bajtů poskytnuté uživatelem v [IResourceLoadingArgs::SetData](../iresourceloadingargs/setdata/) jako data obrázku. |
