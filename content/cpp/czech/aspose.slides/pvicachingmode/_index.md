## PVICachingMode enum

Representuje různé úrovně cache pro efektivní objekty PVI.

```cpp
enum class PVICachingMode
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| NoCaching | 0 | Klasický režim s vytvářením každé instance. |
| NotDefinedOnly | 1 | Použít cache efektivních hodnot pro formáty NotDefined, klasický režim pro ostatní. |
| Full | 2 | Použít cache efektivních hodnot pro všechny formáty. |
