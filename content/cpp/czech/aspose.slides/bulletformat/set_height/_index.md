## BulletFormat::set_Height(float) metoda

Nastavuje výšku odrážky odstavce bez dědičnosti. Hodnota std::numeric_limits<float>::quiet_NaN() určuje, že odrážka dědí výšku z první části v odstavci. Zapište **float**.

```cpp
void Aspose::Slides::BulletFormat::set_Height(float value) override
```

## Poznámky

Záporná hodnota výšky znamená, že výška je uvedena v bodech, a kladná hodnota znamená, že výška je procentuální podíl na okolním textu.
