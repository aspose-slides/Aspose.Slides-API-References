## ShapeThumbnailBounds enum

Výčet typů ohraničení náhledových miniatur tvarů.

```cpp
enum class ShapeThumbnailBounds
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| Slide | 0 | [Shape](../shape/) miniatura bude mít velikost rovnající se velikosti snímku. [Shape](../shape/) pozice bude uložena. |
| Shape | 1 | [Shape](../shape/) miniatura bude mít velikost rovnající se obdélníku ohraničení tvaru s ohledem na nastavení obrysu tvaru. |
| Appearance | 2 | [Shape](../shape/) miniatura bude mít velikost rovnající se vzhledu tvaru (v ohraničení snímku). Může se stát, že vzhled tvaru se nevejde do ohraničení tvaru. Např. rotace, šikmý spoj ostrého úhlu, 3D efekty, atd. |
