## Tab::CompareTo(System::SharedPtr\<ITab\>) metoda


Porovnává aktuální instanci s jiným objektem stejného typu.

```cpp
int32_t Aspose::Slides::Tab::CompareTo(System::SharedPtr<ITab> obj) override
```


### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| obj | [System::SharedPtr](../../../system/sharedptr/)\<[ITab](../../itab/)\> | Objekt, se kterým se porovnává tato instance. |

### Návratová hodnota

32bitové celé číslo, které udává relativní pořadí porovnávaných objektů. Návratová hodnota má tyto významy: * < 0 - Tato instance je menší než obj.
* = 0 - Tato instance je rovna obj.
* > 0 - Tato instance je větší než obj.
