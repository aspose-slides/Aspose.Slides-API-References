## Shape::get_Frame() metoda

Vrací vlastnosti rámce tvaru. Přečtěte si [IShapeFrame](../../ishapeframe/).

```cpp
System::SharedPtr<IShapeFrame> Aspose::Slides::Shape::get_Frame() override
```

## Poznámky

Hodnota každé vlastnosti vrácené instance [IShapeFrame](../../ishapeframe/) není undefined (není NaN ani NotDefined). Hodnota každé vlastnosti přiřazené instance [IShapeFrame](../../ishapeframe/) musí být not undefined (must be not NaN or NotDefined). Můžete nastavit undefined hodnoty pro vlastnosti instance RawFrame.
