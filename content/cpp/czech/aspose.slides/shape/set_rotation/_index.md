## Shape::set_Rotation(float) metoda


Nastaví počet stupňů, o které je daný tvar otočen kolem osy z. Kladná hodnota značí otáčení ve směru hodinových ručiček; záporná hodnota značí otáčení proti směru hodinových ručiček. Zapište **float**.

```cpp
void Aspose::Slides::Shape::set_Rotation(float value) override
```

## Poznámky


Vrácená hodnota je vždy definována (není std::numeric_limits<float>::quiet_NaN()). Přiřazená hodnota musí být definována (není std::numeric_limits<float>::quiet_NaN()). Můžete nastavit nedefinované hodnoty pro vlastnosti instance RawFrame.
