## Poznámky


Vrácená hodnota je vždy definována a nikdy není [std::numeric_limits<float>::quiet_NaN()](../). Přiřazená hodnota musí být také definována; přiřaďte [std::numeric_limits<float>::quiet_NaN()](../) pouze vlastnostem instance **RawFrame**.
