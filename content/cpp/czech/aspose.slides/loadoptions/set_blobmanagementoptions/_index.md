## LoadOptions::set_BlobManagementOptions(System::SharedPtr\<IBlobManagementOptions\>) metoda


Representuje možnosti, které lze použít k řízení chování manipulace s Binary Large Objects (BLOBs), například použití dočasných souborů nebo maximální počet bajtů BLOBů v paměti. Tyto možnosti jsou určeny k nastavení nejlepšího poměru výkonu a spotřeby paměti pro konkrétní prostředí nebo požadavky.

```cpp
void Aspose::Slides::LoadOptions::set_BlobManagementOptions(System::SharedPtr<IBlobManagementOptions> value) override
```

## Poznámky


Binary Large Object (BLOB) je binární data uložená jako jedinečná entita – tj. BLOB může být samotný audio soubor, video nebo prezentace.
