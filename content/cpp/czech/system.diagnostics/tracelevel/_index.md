## TraceLevel výčtový typ

Určuje, jaké zprávy se mají vypisovat pro třídy [System.Diagnostics.Debug](../debug/), [System.Diagnostics.Trace](../trace/) a System.Diagnostics.TraceSwitch.

```cpp
enum class TraceLevel
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| Off | 0 | Nevypisovat žádné sledovací a ladicí zprávy. |
| Error | 1 | Vypisovat zprávy o zpracování chyb. |
| Warning | 2 | Vypisovat varování a zprávy o zpracování chyb. |
| Info | 3 | Vypisovat informativní zprávy, varování a zprávy o zpracování chyb. |
| Verbose | 4 | Vypisovat všechny ladicí a sledovací zprávy. |
