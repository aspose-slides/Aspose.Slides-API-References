## Process::WaitForExit(int) metoda

Čeká, až proces skončí. Není implementováno.

```cpp
bool System::Diagnostics::Process::WaitForExit(int milliseconds)
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| milliseconds | int | Maximální čekací prodleva. |

### Návratová hodnota

True pokud je proces dokončen, false pokud překročí časový limit.
