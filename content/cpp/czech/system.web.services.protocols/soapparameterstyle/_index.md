## SoapParameterStyle enum

Vypisuje formáty parametrů ve zprávě SOAP.

```cpp
enum class SoapParameterStyle
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| Default | 0 | Pokud není na třídu použito '[SoapDocumentServiceAttribute](../soapdocumentserviceattribute/)', pak je výchozí hodnota 'Wrapped'. |
| Bare | 1 | Parametry jsou umístěny v XML prvcích, které následují prvek 'Body'. |
| Wrapped | 2 | Parametry jsou zabaleny do jediného XML prvku, který následuje prvek 'Body'. |
