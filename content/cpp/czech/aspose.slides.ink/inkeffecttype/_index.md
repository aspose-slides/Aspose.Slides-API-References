## InkEffectType enum

Určuje sadu předdefinovaných vizuálních efektů pro vykreslování inkoustu. Každý efekt odpovídá textuře nebo obrázku, který simuluje stylizovaný vzhled inkoustu. Tyto hodnoty lze použít k přizpůsobení vizuálního stylu digitálních tahů inkoustu při vykreslování.

```cpp
enum class InkEffectType
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| NotDefined | -1 | Efekt není definován nebo je neznámý. Tuto hodnotu lze použít jako výchozí nebo náhradní. |
| Bronze | 0 | Teplá, hnědavá kovová textura připomínající bronzový inkoust. |
| Galaxy | 1 | Barevná, třpytivá textura připomínající galaxii s kosmickými tóny. |
| Gold | 2 | Zářivá, kovová zlatá textura, která dodává tahům inkoustu luxusní vzhled. |
| Lava | 3 | Ohnivá textura připomínající roztavenou lávu s červenými a oranžovými odstíny. |
| Ocean | 4 | Tmavě modrá, tekutě připomínající textura, která napodobuje oceánské vlny nebo vodní inkoust. |
| RainbowGlitter | 5 | Barevný, třpytivý duhový glitterový efekt používaný pro slavnostní nebo živé tahy inkoustu. |
| RoseGold | 6 | Měkká růžovo-zlatá směs podobná růžovému zlatému, pro elegantní tahy inkoustu. |
| Silver | 7 | Chladná, kovová stříbrná textura, která simuluje klasický stříbrný inkoust. |
