## Timer::set_Enabled(bool) metoda

Spouští nebo zastavuje časovač. Spuštění časovače nerestartuje počítání času, pokud je časovač již spuštěn.

```cpp
void System::Timers::Timer::set_Enabled(bool value)
```

### Argumenty

| Parametr | Typ | Popis |
| --- | --- | --- |
| value | **bool** | true pro spuštění časovače, false pro zastavení. |
