## XsltSettings::get_EnableScript() metoda

Vrací hodnotu, která udává, zda povolit podporu vložených skriptových bloků.

```cpp
bool System::Xml::Xsl::XsltSettings::get_EnableScript()
```

### Návratová hodnota

**true** pokud má být podpora skriptových bloků v XSLT stylech; jinak **false**. Výchozí hodnota je **false**.
