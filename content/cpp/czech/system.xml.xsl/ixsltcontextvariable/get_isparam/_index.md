## IXsltContextVariable::get_IsParam() metoda

Vrací hodnotu, která udává, zda je proměnná parametrem Extensible Stylesheet Language Transformations (XSLT). Může se jednat o parametr stylového listu nebo šablony.

```cpp
virtual bool System::Xml::Xsl::IXsltContextVariable::get_IsParam()=0
```

### Návratová hodnota

**true** pokud je proměnná parametrem XSLT; jinak **false**.
