## ResultValueTask::get_IsFaulted() const metoda

Získá hodnotu, která určuje, zda úloha byla dokončena kvůli neodchycené výjimce.

```cpp
bool System::Threading::Tasks::ResultValueTask<T>::get_IsFaulted() const
```

### Návratová hodnota

bool True, pokud je úloha v chybovém stavu; jinak false.

## Poznámky

Vrací false, pokud úloha obsahuje přímou hodnotu výsledku.
