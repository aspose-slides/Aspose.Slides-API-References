## IMathPhantom::set_ZeroDesc(bool) metoda

Nastavuje hodnotu, která určuje, zda má být sestup (hloubka pod základní čárou) základního elementu považován za nulu.

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_ZeroDesc(bool value)=0
```

Když je **true**, fantom nesnižuje základní čáru okolní matematické řádky. Odpovídá atributu OMML **m:zeroDesc**.
