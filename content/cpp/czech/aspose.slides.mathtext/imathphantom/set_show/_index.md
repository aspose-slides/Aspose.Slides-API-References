## IMathPhantom::set_Show(bool) metoda


Nastaví hodnotu, která určuje, zda je základní prvek zobrazen.

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_Show(bool value)=0
```

## Poznámky


Když je **false**, je základní prvek skrytý, ale může stále zabírat místo v závislosti na dalších nastaveních phantom. Odpovídá atributu OMML **m:show**.
