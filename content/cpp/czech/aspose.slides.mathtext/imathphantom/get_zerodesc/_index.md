## IMathPhantom::get_ZeroDesc() metoda

Vrací hodnotu, která udává, zda má být klesání (hloubka pod základní čárou) základního prvku považováno za nulu.

```cpp
virtual bool Aspose::Slides::MathText::IMathPhantom::get_ZeroDesc()=0
```

## Poznámky

Když je **true**, fantom nesnižuje základní čáru okolní matematické řádky. Odpovídá atributu OMML **m:zeroDesc**.
