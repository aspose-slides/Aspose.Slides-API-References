## IMathPhantom::set_Transp(bool) metoda


Nastaví hodnotu určující, zda je phantom průhledný pro pravidla rozestupů založená na třídách.

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_Transp(bool value)=0
```

## Poznámky


Když **true**, operátory a symboly uvnitř phantomu stále ovlivňují matematické rozestupy kolem phantomu (jako by byl viditelný). Když **false**, rozestupy založené na třídě jsou ignorovány. Odpovídá atributu OMML **m:transp**.
