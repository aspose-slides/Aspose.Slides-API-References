## MathNaryOperator třída

Specifikuje N-ární matematický objekt, jako je součet a integrál. Skládá se z operátoru, základu (nebo operandu) a volitelných horních a dolních mezí. Příklady N-árních operátorů jsou: Součet, sjednocení, průnik, integrál

```cpp
class MathNaryOperator : public Aspose::Slides::MathText::MathElementBase,
                         public Aspose::Slides::MathText::IMathNaryOperator,
                         public Aspose::Slides::MathText::IHasControlCharacterProperties
```
