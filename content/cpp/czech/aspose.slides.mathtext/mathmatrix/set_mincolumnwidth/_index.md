## MathMatrix::set_MinColumnWidth(uint32_t) metoda

Minimální šířka sloupce v twipsech (1/20 bodu) Mezery mezi sloupci (také označované jako "Column Gap" nebo "Gap Width") jsou přidány k MinColumnWidth pro určení celkové Matrix [Column](../../../aspose.slides/column/) mezery (vzdálenost mezi stejnými okraji různých sloupců). Výchozí: 0.

```cpp
void Aspose::Slides::MathText::MathMatrix::set_MinColumnWidth(uint32_t value) override
```

## Poznámky

Příklad:
```cpp
auto matrix = System::MakeObject<MathMatrix>(2, 3);
matrix->set_MinColumnWidth(20);
```
