## IMathFraction třída

Určuje objekt zlomku, který se skládá z čitatele a jmenovatele oddělených zlomkovou čarou. Zlomková čára může být vodorovná nebo šikmá, v závislosti na vlastnostech zlomku. Objekt zlomku je také používán k reprezentaci funkce zásobníku, která umisťuje jeden prvek nad druhý, bez zlomkové čáry.

```cpp
class IMathFraction : public virtual Aspose::Slides::MathText::IMathElement
```
