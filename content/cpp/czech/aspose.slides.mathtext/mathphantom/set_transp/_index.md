## MathPhantom::set_Transp(bool) metoda


Nastavuje hodnotu, která určuje, zda je phantom průhledný pro pravidla mezery založená na třídách.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_Transp(bool value) override
```

## Poznámky


Když je **true**, operátory a symboly uvnitř phantomu stále ovlivňují matematické mezery kolem phantomu (jako kdyby byl viditelný). Když je **false**, pravidla mezery založená na třídách jsou ignorována. Odpovídá atributu OMML **m:transp**.
