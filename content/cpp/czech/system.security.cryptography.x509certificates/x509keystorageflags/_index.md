## X509KeyStorageFlags enum


Definuje, jak ukládat klíč.

```cpp
enum class X509KeyStorageFlags : int32_t
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| DefaultKeySet | 0 | Použít výchozí sadu klíčů. |
| UserKeySet | 1 | Použít úložiště spojené s uživatelem místo lokálního stroje. |
| MachineKeySet | 2 | Použít úložiště lokálního stroje místo uživatelského. |
| Exportable | 4 | Označuje importované klíče jako exportovatelné. |
| UserProtected | 8 | Upozornit uživatele, že klíč je používán. |
| PersistKeySet | 16 | Klíč je zachován při importu certifikátu. |
