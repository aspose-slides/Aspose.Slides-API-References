## Details_SocketException třída


Representuje výjimku vyvolanou, když nastane chyba socketu. Nikdy nevytvářejte instance této třídy ručně. Použijte místo toho třídu SocketException. Nikdy neobalujte instance třídy SocketException do [System::SmartPtr](../../system/smartptr/).

```cpp
class Details_SocketException : public System::Details_Exception
```
