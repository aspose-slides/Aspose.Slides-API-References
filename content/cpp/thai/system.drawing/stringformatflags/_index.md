## StringFormatFlags enum

ระบุข้อมูลการแสดงผลและการจัดวางสำหรับสตริงข้อความ.

```cpp
enum class StringFormatFlags
```

### Values

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| DirectionRightToLeft | 1 | ทิศทางข้อความจากขวาไปซ้าย. |
| DirectionVertical | 2 | [Text](../../system.drawing.text/) ถูกจัดแนวในแนวตั้ง. |
| FitBlackBox | 4 | ส่วนของอักขระสามารถล้นออกนอกกล่องการจัดวางได้. |
| DisplayFormatControl | 32 | อักขระควบคุมจะแสดงผล. |
| NoFontFallback | 1024 | [Font](../font/) fallback ถูกปิดใช้งาน. |
| MeasureTrailingSpaces | 2048 | แทรกช่องว่างต่อท้ายที่ส่วนท้ายของแต่ละบรรทัด. |
| NoWrap | 4096 | [Text](../../system.drawing.text/) wrapping ถูกปิดใช้งาน. |
| LineLimit | 8192 | บรรทัดทั้งหมดจะถูกจัดวางในสี่เหลี่ยมรูปแบบ. |
| NoClip | 16384 | ส่วนที่ล้นของ glyphs จะได้รับการแสดง. |
