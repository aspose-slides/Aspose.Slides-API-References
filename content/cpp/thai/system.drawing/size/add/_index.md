## Size::Add(const Size\&, const Size\&) เมธอด

ส่งคืนอ็อบเจกต์ [Size](../) ใหม่ที่เป็นผลรวมของอ็อบเจกต์ [Size](../) ที่ระบุ, คือค่าความกว้างเท่ากับผลรวมของค่าความกว้างของอ็อบเจกต์ที่ระบุและค่าความสูงเท่ากับผลรวมของค่าความสูงของอ็อบเจกต์ที่ระบุ

```cpp
static Size System::Drawing::Size::Add(const Size &size1, const Size &size2)
```

### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| size1 | const [Size](../)\& | ตัวดำเนินการตัวแรก |
| size2 | const [Size](../)\& | ตัวดำเนินการตัวที่สอง |

### ค่าที่ส่งคืน

อ็อบเจกต์ [Size](../) ที่เป็นผลรวมของ **size1** และ **size2**
