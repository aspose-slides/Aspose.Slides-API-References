```cpp
bool System::Drawing::Size::Equals(const Size &size) const
```

### Arguments

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| size | const [Size](../)\& | วัตถุที่ใช้เปรียบเทียบกับวัตถุปัจจุบัน |

### ค่าที่ส่งกลับ

True หากวัตถุเท่ากัน, มิฉะนั้น - false
