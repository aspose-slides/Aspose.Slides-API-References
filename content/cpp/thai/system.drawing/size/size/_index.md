## Size::Size() คอนสตรัคเตอร์

สร้างอ็อบเจ็กต์ [Size](../) ใหม่และกำหนดค่า ความกว้างและความสูงเป็น 0.

```cpp
System::Drawing::Size::Size()
```

## Size::Size(const Point\&) คอนสตรัคเตอร์

สร้างอ็อบเจ็กต์ [Size](../) ใหม่และกำหนดค่า ความกว้างและความสูงด้วยค่าพิกัด X และ Y ของจุดที่ระบุอย่างสอดคล้องกัน.

```cpp
System::Drawing::Size::Size(const Point &point)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| point | const [Point](../../point/)\& | อ็อบเจ็กต์ [Point](../../point/) ที่ใช้พิกัด X และ Y เพื่อกำหนดค่า ความกว้างและความสูงของอ็อบเจ็กต์ [Size](../) ที่กำลังสร้าง |

## Size::Size(int, int) คอนสตรัคเตอร์

สร้างอ็อบเจ็กต์ [Size](../) ใหม่และกำหนดค่าให้กับมันด้วยค่าที่ระบุ.

```cpp
System::Drawing::Size::Size(int width, int height)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| width | int | ค่าที่ใช้สำหรับความกว้าง |
| height | int | ค่าของความสูง |
