## Size::Subtract(const Size\&, const Size\&) เมธอด


คืนอ็อบเจกต์ [Size](../) ใหม่ที่เป็นผลของการลบ **size2** จาก **size1**, ตัวอย่างเช่น ค่าความกว้างเป็นผลของการลบค่าความกว้างของ **size2** จากค่าความกว้างของ **size1** และค่าความสูงเป็นผลของการลบค่าความสูงของ **size2** จากค่าความสูงของ **size1**.

```cpp
static Size System::Drawing::Size::Subtract(const Size &size1, const Size &size2)
```


### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| size1 | const [Size](../)\& | อ็อบเจกต์ [Size](../) ที่จะลบจาก |
| size2 | const [Size](../)\& | อ็อบเจกต์ [Size](../) ที่จะลบ |

### ค่าที่คืนกลับ

อ็อบเจกต์ [Size](../) ที่เป็นผลของการลบ **size2** จาก **size1**
