## Rectangle::Inflate(int, int) เมธอด

เพิ่มความกว้างและความสูงของสี่เหลี่ยมที่แสดงโดยอ็อบเจ็กต์ปัจจุบันโดยคงตำแหน่งของศูนย์กลางเชิงเรขาคณิตของสี่เหลี่ยมไว้ ความกว้างและความสูงจะเพิ่มในทั้งสองทิศทางตามจำนวนที่ระบุ

```cpp
void System::Drawing::Rectangle::Inflate(int width, int height)
```

### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| width | int | จำนวนที่ความกว้างของสี่เหลี่ยมจะเพิ่มในทั้งสองทิศทาง |
| height | int | จำนวนที่ความสูงของสี่เหลี่ยมจะเพิ่มในทั้งสองทิศทาง |

## Rectangle::Inflate(const Size\&) เมธอด

เพิ่มความกว้างและความสูงของสี่เหลี่ยมที่แสดงโดยอ็อบเจ็กต์ปัจจุบันโดยคงตำแหน่งของศูนย์กลางเชิงเรขาคณิตของสี่เหลี่ยมไว้ ความกว้างและความสูงจะเพิ่มในทั้งสองทิศทางตามจำนวนที่ระบุโดยค่า width และ height ของอ็อบเจ็กต์ size ที่กำหนดไว้สอดคล้องกัน

```cpp
void System::Drawing::Rectangle::Inflate(const Size &size)
```

### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| size | const [Size](../../size/)\& | อ็อบเจ็กต์ [Size](../../size/) ที่ระบุจำนวนที่ต้องเพิ่มความกว้างและความสูงของสี่เหลี่ยม |

## Rectangle::Inflate(const Rectangle\&, int, int) เมธอด
