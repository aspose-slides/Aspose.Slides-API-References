## Rectangle::IntersectsWith(const Rectangle\&) เมธอด

กำหนดว่ารูปสี่เหลี่ยมที่แทนโดยอ็อบเจ็กต์ปัจจุบันและอ็อบเจ็กต์ที่ระบุมีการตัดกันหรือไม่

```cpp
bool System::Drawing::Rectangle::IntersectsWith(const Rectangle &rect)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| rect | const [Rectangle](../)\& | สี่เหลี่ยมที่จะตรวจสอบ |

### ค่าที่ส่งกลับ

True หากสี่เหลี่ยมที่แสดงโดยอ็อบเจ็กต์ปัจจุบันและ **rect** มีการตัดกัน, มิฉะนั้น - false
