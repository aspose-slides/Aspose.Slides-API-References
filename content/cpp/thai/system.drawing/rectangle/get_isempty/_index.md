## Rectangle::get_IsEmpty() const เมธอด

กำหนดว่าค่า X และ Y ของมุมบนซ้ายของสี่เหลี่ยมที่แสดงโดยอ็อบเจ็กต์ปัจจุบัน รวมถึงความกว้างและความสูง มีค่าเป็น 0 หรือไม่.

```cpp
bool System::Drawing::Rectangle::get_IsEmpty() const
```

### ค่าที่ส่งกลับ

True หากค่า X และ Y ของมุมบนซ้ายของสี่เหลี่ยมที่แสดงโดยอ็อบเจ็กต์ปัจจุบัน รวมถึงความกว้างและความสูง มีค่าเป็น 0, มิฉะนั้น - false
