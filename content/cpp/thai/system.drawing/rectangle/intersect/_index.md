## Rectangle::Intersect(const Rectangle\&) เมธอด

แทนที่สี่เหลี่ยมที่แสดงโดยอ็อบเจ็กต์ปัจจุบันด้วยสี่เหลี่ยมที่เป็นผลลัพธ์จากการตัดกันกับสี่เหลี่ยมที่แสดงโดยอ็อบเจ็กต์ที่ระบุ

```cpp
void System::Drawing::Rectangle::Intersect(const Rectangle &rect)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| rect | const [Rectangle](../)\& | อ็อบเจ็กต์ [Rectangle](../) ที่แสดงสี่เหลี่ยมที่จะทำการตัดกับสี่เหลี่ยมที่แสดงโดยอ็อบเจ็กต์ปัจจุบัน |

## Rectangle::Intersect(const Rectangle\&, const Rectangle\&) เมธอด

ส่งคืนสี่เหลี่ยมที่เป็นผลลัพธ์จากการตัดกันของสี่เหลี่ยมที่ระบุ

```cpp
static Rectangle System::Drawing::Rectangle::Intersect(const Rectangle &a, const Rectangle &b)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| a | const [Rectangle](../)\& | สี่เหลี่ยมแรกเพื่อทำการตัด |
| b | const [Rectangle](../)\& | สี่เหลี่ยมที่สองเพื่อทำการตัด |

### ค่าที่ส่งกลับ

ผลลัพธ์ของการตัดกันของ **a** กับ **b**
