## Rectangle::Offset(const Point\&) เมธอด

เลื่อนตำแหน่งของสี่เหลี่ยมที่แทนด้วยอ็อบเจ็กต์ปัจจุบันโดยระบุจำนวนที่ต้องการ

```cpp
void System::Drawing::Rectangle::Offset(const Point &pos)
```

### Arguments

| Parameter | Type | Description |
| --- | --- | --- |
| pos | const [Point](../../point/)\& | อ็อบเจ็กต์ [Point](../../point/) ที่ระบุจำนวนที่สี่เหลี่ยมจะถูกเลื่อน; ค่า X ของจุดกำหนดจำนวนที่จะเพิ่มไปยังพิกัด X ของมุมซ้ายบนของสี่เหลี่ยมและค่า Y ของจุดกำหนดจำนวนที่จะเพิ่มไปยังพิกัด Y ของมุมซ้ายบนของสี่เหลี่ยม |

## Rectangle::Offset(int, int) เมธอด

เลื่อนตำแหน่งของสี่เหลี่ยมที่แทนด้วยอ็อบเจ็กต์ปัจจุบันโดยระบุจำนวนที่ต้องการ

```cpp
void System::Drawing::Rectangle::Offset(int x, int y)
```

### Arguments

| Parameter | Type | Description |
| --- | --- | --- |
| x | int | ค่าที่จะเพิ่มไปยังพิกัด X ปัจจุบันของสี่เหลี่ยม |
| y | int | ค่าที่จะเพิ่มไปยังพิกัด Y ปัจจุบันของสี่เหลี่ยม |
