## Rectangle::Equals(const Rectangle\&) const เมธอด

กำหนดว่าผลสี่เหลี่ยมที่แสดงโดยอ็อบเจกต์ปัจจุบันและอ็อบเจกต์ที่ระบุเป็นอันเหมือนกันหรือไม่.

```cpp
bool System::Drawing::Rectangle::Equals(const Rectangle &rect) const
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| rect | const [Rectangle](../)\& | อ็อบเจกต์ [Rectangle](../) เพื่อเปรียบเทียบกับอ็อบเจกต์ปัจจุบัน |

### ค่าที่ส่งกลับ

True หากผลสี่เหลี่ยมที่แสดงโดยอ็อบเจกต์ปัจจุบันและอ็อบเจกต์ที่ระบุเป็นอันเหมือนกัน, ไม่เช่นนั้น - false
