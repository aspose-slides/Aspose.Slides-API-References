## ImageConverter คลาส

แปลงวัตถุ [Image](../image/) จากประเภทข้อมูลหนึ่งไปยังอีกประเภทหนึ่ง. วัตถุของคลาสนี้ควรจัดสรรโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น. อย่าสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ operator new, เพราะจะทำให้เกิดข้อผิดพลาดใน runtime และ/หรือการล้มเหลวของการตรวจสอบ. ต้องห่อคลาสนี้ด้วย pointer [System::SmartPtr](../../system/smartptr/) เสมอและใช้ pointer นี้เพื่อส่งเป็นอาร์กิวเมนต์ให้กับฟังก์ชันต่าง ๆ.

```cpp
class ImageConverter : public System::ComponentModel::TypeConverter
```
