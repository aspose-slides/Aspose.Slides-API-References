## SizeF::Equals(const SizeF\&) const เมธอด

```cpp
bool System::Drawing::SizeF::Equals(const SizeF &size) const
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| size | const [SizeF](../)\& | ออบเจ็กต์สำหรับเปรียบเทียบกับออบเจ็กต์ปัจจุบัน |

### ค่าที่ส่งกลับ

True ถ้าออบเจ็กต์เท่ากัน, มิฉะนั้น - false
