## SizeF::Add(const SizeF\&, const SizeF\&) เมธอด

คืนค่าอ็อบเจ็กต์ [SizeF](../) ใหม่ที่เป็นผลรวมของอ็อบเจ็กต์ [SizeF](../) ที่ระบุไว้ กล่าวคือค่า width มีค่าเท่ากับผลรวมของค่า width ของอ็อบเจ็กต์ที่ระบุและค่า height มีค่าเท่ากับผลรวมของค่า height ของอ็อบเจ็กต์ที่ระบุ

```cpp
static SizeF System::Drawing::SizeF::Add(const SizeF &size1, const SizeF &size2)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| size1 | const [SizeF](../)\& | ตัวดำเนินการแรก |
| size2 | const [SizeF](../)\& | ตัวดำเนินการที่สอง |

### ค่าที่ส่งกลับ

อ็อบเจ็กต์ [SizeF](../) ที่เป็นผลรวมของ **size1** และ **size2**
