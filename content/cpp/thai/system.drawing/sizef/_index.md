## SizeF คลาส

แสดงถึงคู่ของค่าจุดลอยตัวความละเอียดเดี่ยวที่แสดงความกว้างและความสูงของภาพ. ประเภทนี้ควรจัดสรรบนสแตกและส่งผ่านไปยังฟังก์ชันโดยค่า หรือโดยการอ้างอิง. ไม่ควรใช้คลาส [System::SmartPtr](../../system/smartptr/) เพื่อจัดการวัตถุของประเภทนี้.

```cpp
class SizeF
```
