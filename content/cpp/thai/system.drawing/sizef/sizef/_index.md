## SizeF::SizeF() คอนสตรัคเตอร์

สร้างอ็อบเจ็กต์ [SizeF](../) ใหม่และตั้งค่าความกว้างและความสูงเป็น 0.

```cpp
System::Drawing::SizeF::SizeF()
```

## SizeF::SizeF(const PointF\&) คอนสตรัคเตอร์

สร้างอ็อบเจ็กต์ [SizeF](../) ใหม่และตั้งค่าความกว้างและความสูงโดยใช้ค่าพิกัด X และ Y ของจุดที่ระบุตามลำดับ.

```cpp
System::Drawing::SizeF::SizeF(const PointF &point)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| point | const [PointF](../../pointf/)\& | อ็อบเจ็กต์ [Point](../../point/) ที่พิกัด X และ Y ของมันใช้เพื่อกำหนดค่า width และ height ของอ็อบเจ็กต์ [SizeF](../) ที่กำลังสร้าง |

## SizeF::SizeF(float, float) คอนสตรัคเตอร์

สร้างอ็อบเจ็กต์ [SizeF](../) ใหม่และตั้งค่าโดยใช้ค่าที่ระบุ.

```cpp
System::Drawing::SizeF::SizeF(float width, float height)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| width | **float** | ค่าที่ใช้กำหนดความกว้าง |
| height | **float** | ค่าที่ใช้กำหนดความสูง |
