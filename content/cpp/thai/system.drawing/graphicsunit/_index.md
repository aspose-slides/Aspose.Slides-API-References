## GraphicsUnit enum

แสดงถึงหน่วยการวัด.

```cpp
enum class GraphicsUnit
```

### ค่าต่างๆ

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| World | 0 | พิกัด World (หน่วยที่ไม่เป็นเชิงกายภาพ). |
| Display | 1 | หน่วยการวัดของอุปกรณ์แสดงผล. |
| Pixel | 2 | พิกเซลของอุปกรณ์. |
| Point | 3 | หน่วยจุดของเครื่องพิมพ์ (1/72 นิ้ว). |
| Inch | 4 |หนึ่งนิ้ว. |
| Document | 5 | 1/300 นิ้ว. |
| Millimeter | 6 | หนึ่งมิลลิเมตร. |
