## คลาส Point

แสดงถึงคู่ของพิกัด X และ Y ที่เป็นจำนวนเต็มของจุดบนระนาบสองมิติ. ชนิดนี้ควรจัดสรรบนสแตกและส่งผ่านไปยังฟังก์ชันโดยค่า หรือโดยการอ้างอิง. อย่าใช้คลาส [System::SmartPtr](../../system/smartptr/) เพื่อจัดการอ็อบเจ็กต์ของชนิดนี้.

```cpp
class Point
```
