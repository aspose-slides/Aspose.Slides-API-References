## Point::Point() คอนสตรัคเตอร์

สร้างอ็อบเจกต์ [Point](../) ใหม่และกำหนดค่า X และ Y ให้เป็น 0.

```cpp
System::Drawing::Point::Point()
```

## Point::Point(int, int) คอนสตรัคเตอร์

สร้างอ็อบเจกต์ [Point](../) ใหม่และกำหนดค่าเริ่มต้นด้วยค่าที่ระบุ.

```cpp
System::Drawing::Point::Point(int x, int y)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| x | int | ค่าพิกัด X |
| y | int | ค่าพิกัด Y |

## Point::Point(const Size\&) คอนสตรัคเตอร์

สร้างอ็อบเจกต์ [Point](../) ใหม่และกำหนดค่า X และ Y ให้ตรงกับค่าความกว้างและความสูงของอ็อบเจกต์ [SizeF](../../sizef/) ที่ระบุ

```cpp
System::Drawing::Point::Point(const Size &size)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| size | const [Size](../../size/)\& | อ็อบเจกต์ [SizeF](../../sizef/) ที่ค่าความกว้างและความสูงของมันใช้เพื่อกำหนดค่าพิกัด X และ Y ของอ็อบเจกต์ [Point](../) ที่กำลังสร้าง |

## Point::Point(int) คอนสตรัคเตอร์

สร้างอ็อบเจกต์ [Point](../) ใหม่และกำหนดค่าพิกัด X ด้วยบิตสูง 16 บิตของจำนวนเต็ม 32-บิตที่ระบุ และกำหนดค่าพิกัด Y ด้วยบิตต่ำ 16 บิตของค่าจำนวนเต็ม 32-บิตนั้น

```cpp
System::Drawing::Point::Point(int dw)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| dw | int | ค่าเต็มจำนวน 32-บิตที่บิตสูง 16 บิตระบุค่าพิกัด X และบิตต่ำ 16 บิตระบุค่าพิกัด Y ของอ็อบเจกต์ที่กำลังสร้าง |
