## Point::Offset(int, int) เมธอด

ทำการออฟเซ็ตค่าพิกัด X และ Y ของอ็อบเจ็กต์ปัจจุบันด้วยค่าที่ระบุ

```cpp
void System::Drawing::Point::Offset(int dx, int dy)
```

### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| dx | int | ค่าที่ใช้เพื่อออฟเซ็ตค่าพิกัด X |
| dy | int | ค่าที่ใช้เพื่อออฟเซ็ตค่าพิกัด Y |

## Point::Offset(Point) เมธอด

ทำการออฟเซ็ตพิกัด X และ Y ของอ็อบเจ็กต์ปัจจุบันโดยค่าของพิกัด X และ Y ที่เป็นตัวแทนของอ็อบเจ็กต์ [Point](../) ที่ระบุอย่างสอดคล้องกัน

```cpp
void System::Drawing::Point::Offset(Point point)
```

### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| point | [Point](../) | อ็อบเจ็กต์ [Point](../) ที่ระบุค่าที่จะออฟเซ็ตพิกัด X และ Y |
