## RectangleF::Offset(const PointF\&) เมธอด

เลื่อนตำแหน่งของสี่เหลี่ยมที่แสดงโดยอ็อบเจกต์ปัจจุบันด้วยจำนวนที่ระบุ

```cpp
void System::Drawing::RectangleF::Offset(const PointF &pos)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| pos | const [PointF](../../pointf/)\& | ออบเจกต์ [PointF](../../pointf/) ที่ระบุจำนวนที่สี่เหลี่ยมจะถูกเลื่อน; ค่าพิกัด X ของจุดระบุจำนวนที่ต้องเพิ่มไปยังพิกัด X ของมุมซ้ายบนของสี่เหลี่ยมและพิกัด Y ของจุดระบุจำนวนที่ต้องเพิ่มไปยังพิกัด Y ของมุมซ้ายบนของสี่เหลี่ยม |

## RectangleF::Offset(float, float) เมธอด

เลื่อนตำแหน่งของสี่เหลี่ยมที่แสดงโดยอ็อบเจกต์ปัจจุบันด้วยจำนวนที่ระบุ

```cpp
void System::Drawing::RectangleF::Offset(float x, float y)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| x | **float** | ค่าที่จะเพิ่มไปยังพิกัด X ปัจจุบันของสี่เหลี่ยม |
| y | **float** | ค่าที่จะเพิ่มไปยังพิกัด Y ปัจจุบันของสี่เหลี่ยม |
