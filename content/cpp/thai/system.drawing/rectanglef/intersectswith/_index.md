## RectangleF::IntersectsWith(const RectangleF\&) เมธอด

กำหนดว่ารูปสี่เหลี่ยมที่แสดงโดยอ็อบเจ็กต์ปัจจุบันและอ็อบเจ็กต์ที่ระบุมีการตัดกันหรือไม่

```cpp
bool System::Drawing::RectangleF::IntersectsWith(const RectangleF &rect)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| rect | const [RectangleF](../)\& | สี่เหลี่ยมที่จะตรวจสอบ |

### ค่าที่ส่งคืน

True หากรูปสี่เหลี่ยมที่แสดงโดยอ็อบเจ็กต์ปัจจุบันและ **rect** ตัดกัน, มิฉะนั้น - false
