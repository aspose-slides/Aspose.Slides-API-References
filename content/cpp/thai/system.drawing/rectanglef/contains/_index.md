## RectangleF::Contains(float, float) เมธอด

กำหนดว่าจุดที่ระบุอยู่ภายในสี่เหลี่ยมที่แสดงโดยออบเจกต์ปัจจุบันหรือไม่

```cpp
bool System::Drawing::RectangleF::Contains(float x, float y)
```

### Arguments

| Parameter | Type | Description |
| --- | --- | --- |
| x | **float** | พิกัด X ของจุดที่ต้องตรวจสอบ |
| y | **float** | พิกัด Y ของจุดที่ต้องตรวจสอบ |

### Return Value

True หากจุดที่ระบุอยู่ภายในสี่เหลี่ยมที่แสดงโดยออบเจกต์ปัจจุบัน, มิฉะนั้น - false
