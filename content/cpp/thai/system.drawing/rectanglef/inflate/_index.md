## RectangleF::Inflate(float, float) เมธอด

เพิ่มความกว้างและความสูงของสี่เหลี่ยมที่แทนโดยอ็อบเจ็กต์ปัจจุบัน โดยคงตำแหน่งของศูนย์กลางเรขาคณิตของสี่เหลี่ยมไว้ ความกว้างและความสูงจะเพิ่มในทิศทางทั้งสองตามจำนวนที่ระบุ

```cpp
void System::Drawing::RectangleF::Inflate(float width, float height)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| width | **float** | จำนวนที่ความกว้างของสี่เหลี่ยมจะเพิ่มในทิศทางทั้งสอง |
| height | **float** | จำนวนที่ความสูงของสี่เหลี่ยมจะเพิ่มในทิศทางทั้งสอง |

## RectangleF::Inflate(const SizeF\&) เมธอด

เพิ่มความกว้างและความสูงของสี่เหลี่ยมที่แทนโดยอ็อบเจ็กต์ปัจจุบัน โดยคงตำแหน่งของศูนย์กลางเรขาคณิตของสี่เหลี่ยมไว้ ความกว้างและความสูงจะเพิ่มในทิศทางทั้งสองตามค่าที่ระบุโดยค่าความกว้างและความสูงของอ็อบเจ็กต์ขนาดที่ระบุตามลำดับ

```cpp
void System::Drawing::RectangleF::Inflate(const SizeF &size)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| size | const [SizeF](../../sizef/)\& | อ็อบเจ็กต์ [SizeF](../../sizef/) ที่ระบุจำนวนที่จะเพิ่มความกว้างและความสูงของสี่เหลี่ยม |
