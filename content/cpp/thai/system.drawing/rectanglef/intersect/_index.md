## RectangleF::Intersect(const RectangleF\&) เมธอด


## RectangleF::Intersect(const RectangleF\&, const RectangleF\&) เมธอด


คืนค่าสี่เหลี่ยมที่เป็นผลลัพธ์ของการตัดกันของสี่เหลี่ยมที่ระบุ

```cpp
static RectangleF System::Drawing::RectangleF::Intersect(const RectangleF &a, const RectangleF &b)
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| a | const [RectangleF](../)\& | สี่เหลี่ยมแรกที่ต้องทำการตัด |
| b | const [RectangleF](../)\& | สี่เหลี่ยมที่สองที่ต้องทำการตัด |

### ค่ารีเทิร์น

ผลลัพธ์ของการตัด **a** กับ **b**
