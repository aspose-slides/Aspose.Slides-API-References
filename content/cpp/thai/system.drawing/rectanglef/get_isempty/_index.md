## RectangleF::get_IsEmpty() const เมธอด


กำหนดว่าพิกัด X และ Y ของมุมซ้ายบนของรูปสี่เหลี่ยมที่แสดงโดยอ็อบเจ็กต์ปัจจุบันรวมถึงความกว้างและความสูงของมันมีค่าเป็น 0 หรือไม่.

```cpp
bool System::Drawing::RectangleF::get_IsEmpty() const
```


### ค่าที่ส่งกลับ

จริง หากพิกัด X และ Y ของมุมซ้ายบนของรูปสี่เหลี่ยมที่แสดงโดยอ็อบเจ็กต์ปัจจุบันรวมถึงความกว้างและความสูงของมันมีค่าเป็น 0, ไม่เช่นนั้น - เท็จ
