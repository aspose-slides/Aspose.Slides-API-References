## CharacterRange::operator!=(const CharacterRange&) const เมธอด

กำหนดว่าตัวอ็อบเจกต์ปัจจุบันและตัวที่ระบุเป็นช่วงที่แยกจากกันหรือไม่

```cpp
bool System::Drawing::CharacterRange::operator!=(const CharacterRange &cr) const
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| cr | const [CharacterRange](../)\& | อ็อบเจกต์ [CharacterRange](../) ที่ใช้เปรียบเทียบกับอ็อบเจกต์ปัจจุบัน |

### ค่าที่ส่งกลับ

เป็นจริงถ้า **cr** และอ็อบเจกต์ปัจจุบันเป็นช่วงที่แตกต่างกัน, มิฉะนั้น - false
