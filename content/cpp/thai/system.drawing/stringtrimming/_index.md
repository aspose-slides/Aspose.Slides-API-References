## StringTrimming enum

ระบุว่าควรตัดอักขระอย่างไรจากสตริงที่ไม่พอดีกับรูปแบบการจัดวาง

```cpp
enum class StringTrimming
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| None | 0 | ไม่มีการตัด. |
| Character | 1 | ตัดให้ตรงกับอักขระที่ใกล้ที่สุด. |
| Word | 2 | ตัดให้ตรงกับคำที่ใกล้ที่สุด. |
| EllipsisCharacter | 3 | ตัดให้ตรงกับอักขระที่ใกล้ที่สุดและแทรกอิลลิปส์ที่ส่วนท้ายของสตริง. |
| EllipsisWord | 4 | ตัดให้ตรงกับคำที่ใกล้ที่สุดและแทรกอิลลิปส์ที่ส่วนท้ายของสตริง. |
| EllipsisPath | 5 | ส่วนกลางจะถูกลบออกจากบรรทัดที่ถูกตัดและแทนที่ด้วยอิลลิปส์ เก็บส่วนที่เหลือของส่วนสุดท้ายที่คั่นด้วยเครื่องหมายทับให้มากที่สุดเท่าที่ทำได้. |
