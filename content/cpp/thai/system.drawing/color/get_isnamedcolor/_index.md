## Color::get_IsNamedColor() const เมธอด

คืนค่าที่บ่งชี้ว่ารูปร่าง [Color](../) แทนสีที่มีชื่อหรือเป็นสมาชิกของการประกาศค่า KnownColor หรือไม่

```cpp
bool System::Drawing::Color::get_IsNamedColor() const
```

### ค่าที่ส่งคืน

True หาก [Color](../) ถูกสร้างโดยใช้ FromName(String) เมธอด หรือ [FromKnownColor(KnownColor)](../fromknowncolor/) เมธอด; มิฉะนั้นจะคืนค่า false
