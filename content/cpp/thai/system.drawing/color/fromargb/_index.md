## Color::FromArgb(int) เมธอด


สร้างอินสแตนซ์ของคลาส [Color](../) ที่แสดงสีที่ระบุ

```cpp
static Color System::Drawing::Color::FromArgb(int argb)
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| argb | int | ค่าระดับ 32 บิต ARGB ของสีที่จะแสดงโดยอ็อบเจกต์ที่กำลังสร้าง |

### ค่าที่ส่งกลับ

อ็อบเจกต์ที่แสดงสีที่ระบุ

## Color::FromArgb(int, int, int, int) เมธอด


สร้างอินสแตนซ์ของคลาส [Color](../) ที่แสดงสีที่ระบุ

```cpp
static Color System::Drawing::Color::FromArgb(int alpha, int red, int green, int blue)
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| alpha | int | ค่าของส่วนอัลฟ่าในสี |
| red | int | ค่าของส่วนสีแดงในสี |
| green | int | ค่าของส่วนสีเขียวในสี |
| blue | int | ค่าของส่วนสีน้ำเงินในสี |

### ค่าที่ส่งกลับ

อ็อบเจกต์ที่แสดงสีที่ระบุ

## Color::FromArgb(int, int, int) เมธอด

```cpp
static Color System::Drawing::Color::FromArgb(int red, int green, int blue)
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| red | int | ค่าของส่วนสีแดงในสี |
| green | int | ค่าของส่วนสีเขียวในสี |
| blue | int | ค่าของส่วนสีน้ำเงินในสี |

### ค่าที่ส่งกลับ

อ็อบเจกต์ที่แสดงสีที่ระบุ

## Color::FromArgb(int, Color) เมธอด


สร้างอินสแตนซ์ของคลาส [Color](../) ที่แสดงสีที่ระบุ

```cpp
static Color System::Drawing::Color::FromArgb(int alpha, Color base_color)
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| alpha | int | ค่าของส่วนอัลฟ่าในสี |
| base_color | [Color](../) | อินสแตนซ์ของอ็อบเจกต์ [Color](../) ที่แสดงส่วนสีแดง สีเขียว และสีน้ำเงินของสีที่จะแสดงโดยอ็อบเจกต์ที่กำลังสร้าง |

### ค่าที่ส่งกลับ

อ็อบเจกต์ที่แสดงสีที่ระบุ
