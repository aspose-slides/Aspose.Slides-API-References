## Brush คลาส


คลาสฐานสำหรับคลาสที่แทน filler ที่ใช้เติมภายในของรูปร่างกราฟิกส์. ออบเจ็กต์ของคลาสนี้ควรสร้างขึ้นโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น. อย่าสร้างอินสแตนซ์ของชนิดนี้บนสแตคหรือโดยใช้ operator new, เนื่องจากจะทำให้เกิดข้อผิดพลาดขณะรันไทม์และ/หรือข้อผิดพลาดการตรวจสอบ. ควรห่อคลาสนี้ด้วยพอยน์เตอร์ [System::SmartPtr](../../system/smartptr/) และใช้พอยน์เตอร์นี้เพื่อส่งผ่านเป็นอาร์กิวเมนต์ให้กับฟังก์ชัน.

```cpp
class Brush : public System::ICloneable,
              public System::IDisposable
```
