## Graphics::IsVisible(Point) เมธอด


กำหนดว่าจุดที่ระบุอยู่ภายในบริเวณคลิปที่มองเห็นของอ็อบเจกต์ [Graphics](../) ปัจจุบันหรือไม่

```cpp
bool System::Drawing::Graphics::IsVisible(Point point)
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| point | [Point](../../point/) | จุด point ที่ต้องตรวจสอบ |

### ค่าที่คืน

True if **point** is contained within the visible clip region of the current [Graphics](../) object, otherwise - false
