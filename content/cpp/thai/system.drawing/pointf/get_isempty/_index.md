## PointF::get_IsEmpty() const เมธอด


ตรวจสอบว่าค่า X และ Y ของพิกัดเป็นศูนย์หรือไม่.

```cpp
bool System::Drawing::PointF::get_IsEmpty() const
```


### ค่าที่ส่งกลับ

True หากค่าพิกัด X และ Y ของอ็อบเจ็กต์ปัจจุบันเป็น 0; มิฉะนั้น - false
