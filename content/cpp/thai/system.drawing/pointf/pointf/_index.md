## PointF::PointF() คอนสตรัคเตอร์

สร้างอ็อบเจ็กต์ [PointF](../) ใหม่และกำหนดค่า X และ Y ของพิกัดเป็น 0.

```cpp
System::Drawing::PointF::PointF()
```

## PointF::PointF(float, float) คอนสตรัคเตอร์

สร้างอ็อบเจ็กต์ [PointF](../) ใหม่และกำหนดค่าโดยใช้ค่าที่ระบุ.

```cpp
System::Drawing::PointF::PointF(float x, float y)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| x | **float** | ค่าของพิกัด X |
| y | **float** | ค่ของพิกัด Y |

## PointF::PointF(const SizeF\&) คอนสตรัคเตอร์

สร้างอ็อบเจ็กต์ [PointF](../) ใหม่และกำหนดค่าพิกัด X และ Y ด้วยค่า width และ height ของอ็อบเจ็กต์ [SizeF](../../sizef/) ที่ระบุไว้ตามลำดับ.

```cpp
System::Drawing::PointF::PointF(const SizeF &size)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| size | const [SizeF](../../sizef/)\& | อ็อบเจ็กต์ [SizeF](../../sizef/) ที่มีค่า width และ height ถูกใช้เพื่อกำหนดค่าพิกัด X และ Y ของอ็อบเจ็กต์ [PointF](../) ที่กำลังสร้าง |
