## HttpContext คลาส

คลาสจำลองที่ทำให้สามารถเชื่อมโยงโค้ดที่แปลกับอ้างอิง [HttpContext](./) ได้ แต่ไม่ทำการเรียกใช้งานจริง มีสมาชิกที่ไม่ได้ถูกทำงานอย่างถูกต้อง วัตถุของคลาสนี้ควรจัดสรรด้วยฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น ไม่ควรสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ operator new เนื่องจากจะทำให้เกิดข้อผิดพลาดขณะรันไทม์และ/หรือการตรวจสอบความถูกต้อง ควรหุ้มคลาสนี้ด้วยพอยน์เตอร์ [System::SmartPtr](../../system/smartptr/) และใช้พอยน์เตอร์นี้ส่งเป็นอาร์กิวเมนต์ให้ฟังก์ชัน

```cpp
class HttpContext : public System::Object
```
