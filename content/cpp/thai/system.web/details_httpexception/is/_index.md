## รายละเอียด_HttpException::Is(const System::TypeInfo\&) const method


```cpp
bool System::Web::Details_HttpException::Is(const System::TypeInfo &target) const override
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| target | const [System::TypeInfo](../../../system/typeinfo/)\& | [TypeInfo](../../../system/typeinfo/) โครงสร้างที่อธิบายประเภทที่ต้องทดสอบอ็อบเจ็กต์ปัจจุบัน |

### ค่าที่ส่งกลับ

True หากอ็อบเจ็กต์เป็นประเภทที่แท็กหรือเป็นคลาสย่อยของมัน, false ไม่เช่นนั้น

## หมายเหตุ

ตรวจสอบว่าอ็อบเจ็กต์เป็นอินสแตนซ์ของประเภทที่อธิบายโดย targetType หรือไม่. เป็นเทียบเคียงของโอเปอเรเตอร์ ‘is’ ของ C#.
