## RSACryptoServiceProvider::set_UseMachineKeyStore(bool) เมธอด

กำหนดว่ากุญแจจะคงอยู่ในที่เก็บของเครื่องหรือไม่ แทนที่จะอยู่ในที่เก็บของผู้ใช้.

```cpp
static void System::Security::Cryptography::RSACryptoServiceProvider::set_UseMachineKeyStore(bool value)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| value | **bool** | True หากกุญแจควรคงอยู่ในที่เก็บของเครื่อง, false หากควรคงอยู่ในที่เก็บของผู้ใช้. |
