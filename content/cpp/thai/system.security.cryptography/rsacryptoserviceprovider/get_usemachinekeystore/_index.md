## RSACryptoServiceProvider::get_UseMachineKeyStore() เมธอด


ตรวจสอบว่ากุญแจจะถูกเก็บไว้ในที่เก็บของเครื่องหรือที่เก็บของผู้ใช้.

```cpp
static bool System::Security::Cryptography::RSACryptoServiceProvider::get_UseMachineKeyStore()
```


### ค่าที่ส่งกลับ

True หากกุญแจควรถูกเก็บไว้ในที่เก็บของเครื่อง, false หากกุญแจควรถูกเก็บไว้ในที่เก็บของผู้ใช้.
