## AsymmetricSignatureFormatter คลาส

คลาสพื้นฐานสำหรับ asymmetric signature formatters. อ็อบเจ็กต์ของคลาสนี้ควรจัดสรรโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น. ห้ามสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ operator new เนื่องจากจะทำให้เกิดข้อผิดพลาดรันไทม์และ/หรือ assertion fault. ควรห่อคลาสนี้ด้วย pointer [System::SmartPtr](../../system/smartptr/) และใช้ pointer นี้เพื่อส่งเป็นอากิวเมนต์ให้ฟังก์ชัน.

```cpp
class AsymmetricSignatureFormatter : public System::Object
```
