## RIPEMD160 คลาส

คำนวณแฮช [RIPEMD160](./) สำหรับข้อมูลอินพุต. ใน C++ [RIPEMD160](./) ไม่ใช่คลาสเชิงนามธรรม. อ็อบเจกต์ของคลาสนี้ควรจัดสรรโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น. ห้ามสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ operator new เนื่องจากจะทำให้เกิดข้อผิดพลาดรันไทม์และ/หรือข้อผิดพลาดการอ้างอิง. ควรห่อคลาสนี้ไว้ในพอยเตอร์ [System::SmartPtr](../../system/smartptr/) และใช้พอยเตอร์นี้เพื่อส่งเป็นอาร์กิวเมนต์ให้กับฟังก์ชันต่าง ๆ.

```cpp
class RIPEMD160 : public System::Security::Cryptography::HashAlgorithm
```
