## PaddingMode enum

กำหนดวิธีการจัดการข้อความที่สั้นกว่าบล็อกที่ต้องการโดยการดำเนินการเข้ารหัส.

```cpp
enum class PaddingMode
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| None | 1 | ไม่มีการเติม. |
| PKCS7 | 2 | Use PKCS #7 padding string. |
| Zeros | 3 | ใช้ไบต์ศูนย์. |
| ANSIX923 | 4 | Use ANSIX923 padding string. |
| ISO10126 | 5 | Use ISO10126 padding string. |
