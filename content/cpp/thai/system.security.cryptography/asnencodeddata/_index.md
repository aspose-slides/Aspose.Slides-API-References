## AsnEncodedData คลาส


ข้อมูลที่เข้ารหัสตาม ASN.1. วัตถุของคลาสนี้ควรสร้างขึ้นโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น. อย่าสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ตัวดำเนินการ new, เพราะจะทำให้เกิดข้อผิดพลาดรันไทม์และ/หรือการตรวจสอบข้อแม้. ควรห่อหุ้มคลาสนี้ด้วยตัวชี้ [System::SmartPtr](../../system/smartptr/) แล้วใช้ตัวชี้นี้เพื่อส่งเป็นอาร์กูเมนต์ให้ฟังก์ชัน.

```cpp
class AsnEncodedData : public System::Object
```
