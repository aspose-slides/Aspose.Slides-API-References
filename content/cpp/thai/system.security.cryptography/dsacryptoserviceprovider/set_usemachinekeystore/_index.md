## DSACryptoServiceProvider::set_UseMachineKeyStore(bool) เมธอด


กำหนดว่ากุญแจจะถูกเก็บไว้ในที่เก็บของเครื่องแทนที่จะเป็นที่เก็บของผู้ใช้.

```cpp
static void System::Security::Cryptography::DSACryptoServiceProvider::set_UseMachineKeyStore(bool value)
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| value | **bool** | True หากกุญแจควรถูกเก็บไว้ในที่เก็บของเครื่อง, false หากควรถูกเก็บไว้ในที่เก็บของผู้ใช้. |
