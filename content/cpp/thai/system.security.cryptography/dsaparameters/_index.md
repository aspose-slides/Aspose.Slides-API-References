## DSAParameters struct

[Data](../../system.data/) โครงสร้างของพารามิเตอร์อัลกอริทึม [DSA](../dsa/). ชนิดนี้ควรจัดสรรบนสแตกและส่งผ่านไปยังฟังก์ชันโดยค่า หรือโดยอ้างอิง. อย่าใช้คลาส [System::SmartPtr](../../system/smartptr/) เพื่อจัดการกับอ็อบเจ็กต์ของชนิดนี้.

```cpp
class DSAParameters : public System::Object
```
