## SHA512Managed คลาส

Managed [SHA384](../sha384/) hasher. ยังไม่ได้ดำเนินการ. วัตถุของคลาสนี้ควรจะสงวนหน่วยความจำโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น. อย่าสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ operator new เพราะจะทำให้เกิดข้อผิดพลาดเวลารันและ/หรือการตรวจสอบความถูกต้อง. ห่อหุ้มคลาสนี้ในตัวชี้ [System::SmartPtr](../../system/smartptr/) เสมอและใช้ตัวชี้นี้เพื่อส่งเป็นอาร์กิวเมนต์ให้กับฟังก์ชัน.

```cpp
class SHA512Managed : public System::Security::Cryptography::SHA512
```
