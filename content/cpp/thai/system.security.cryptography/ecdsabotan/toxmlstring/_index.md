```cpp
String System::Security::Cryptography::ECDsaBotan::ToXmlString(bool include_private_parameters) override
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| include_private_parameters | **bool** | True เพื่อส่งออกพารามิเตอร์ส่วนตัวและสาธารณะทั้งสอง, false เพื่อส่งออกพารามิเตอร์สาธารณะเท่านั้น. |
