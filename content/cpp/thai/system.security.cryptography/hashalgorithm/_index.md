## คลาส HashAlgorithm

คลาสพื้นฐานสำหรับอัลกอริทึมการแฮช. อ็อบเจกต์ของคลาสนี้ควรจัดสรรให้ใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น. อย่าสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ operator new เพราะจะทำให้เกิดข้อผิดพลาดเวลารันและ/หรือการตรวจสอบข้อผิดพลาด. อย่าลืมห่อคลาสนี้ไว้ด้วยพอยน์เตอร์ [System::SmartPtr](../../system/smartptr/) และใช้พอยน์เตอร์นี้เพื่อส่งเป็นอาร์กิวเมนต์ให้กับฟังก์ชัน.

```cpp
class HashAlgorithm : public System::Security::Cryptography::ICryptoTransform
```
