## ECDsa::ExportParameters(bool) เมธอด

ส่งออกพารามิเตอร์ที่ระบุชื่อหรือพารามิเตอร์แบบชัดเจน

```cpp
virtual ECParameters System::Security::Cryptography::ECDsa::ExportParameters(bool include_private_parameters)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| include_private_parameters | **bool** | True เพื่อส่งออกทั้งพารามิเตอร์ส่วนตัวและสาธารณะ, false เพื่อส่งออกพารามิเตอร์สาธารณะเท่านั้น. |

### ค่าที่ส่งคืน

โครงสร้างพารามิเตอร์ที่ส่งออก.
