## หมายเหตุ

การใช้ resolver นี้อาจทำให้เกิดช่องโหว่าเมื่อไฟล์ HTML หรือ SVG ที่มาจากไคลเอนต์ทำให้ซอฟต์แวร์เซิร์ฟเวอร์ติดตั้งไฟล์ในเครื่องหรือบนเครือข่ายได้. ใช้งานด้วยความระมัดระวัง. แนะนำให้ไม่ระบุ [ExternalResourceResolver](./) เลย (จะอ่านเฉพาะอ็อบเจกต์ฝังอยู่) หรือสร้างซับคลาสที่ตรวจสอบว่า uri ที่ระบุเป็นค่าที่ถูกต้องหรือไม่.
