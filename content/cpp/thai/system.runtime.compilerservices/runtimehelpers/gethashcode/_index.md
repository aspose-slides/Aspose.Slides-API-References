## RuntimeHelpers::GetHashCode(SmartPtr\<T\> const\&) เมธอด

รับค่ารหัสแฮชสำหรับชนิดใดก็ได้ เรียก [Object::GetHashCode()](../../../system/object/gethashcode/) เพื่อทำเช่นนั้น.

```cpp
template<typename T> static int System::Runtime::CompilerServices::RuntimeHelpers::GetHashCode(SmartPtr<T> const &obj)
```

### พารามิเตอร์แม่แบบ

| พารามิเตอร์ | คำอธิบาย |
| --- | --- |
| T | ประเภทที่ต้องการรับรหัสแฮชสำหรับ. |

### อากิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| obj | [SmartPtr](../../../system/smartptr/)\<T\> const\& | [Object](../../../system/object/) ที่จะรับข้อมูลจาก. |

### ค่าที่ส่งคืน

ค่ารหัสแฮชที่คำนวณโดยการทำงานของเป้าหมาย.
