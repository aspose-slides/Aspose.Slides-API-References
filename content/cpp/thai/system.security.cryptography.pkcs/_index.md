## คลาส

| Class | Description |
| --- | --- |
| [CmsSigner](./cmssigner/) | ให้ API เพื่อลงนามวัตถุโดยใช้ CMS. ไม่ลงนามวัตถุด้วยตนเอง, ใช้คลาส SignedCMS เพื่อทำเช่นนั้น. ยังไม่ได้ทำการใช้งาน. วัตถุของคลาสนี้ควรจะถูกจัดสรรโดยใช้ฟังก์ชัน [System::MakeObject()](../system/makeobject/) เท่านั้น. อย่าสร้างอินสแตนซ์ของชนิดนี้บนสแต็กหรือโดยใช้ operator new, เนื่องจากจะทำให้เกิดข้อผิดพลาดรันไทม์และ/หรือข้อผิดพลาดการตรวจสอบ. ควรห่อคลาสนี้ในตัวชี้ [System::SmartPtr](../system/smartptr/) เสมอและใช้ตัวชี้นี้เพื่อส่งผ่านเป็นอาร์กิวเมนต์ให้กับฟังก์ชัน. |
| [ContentInfo](./contentinfo/) | ข้อมูลเนื้อหาตามที่กำหนดโดยมาตรฐาน CMS/PKCS #7. ยังไม่ได้ทำการใช้งาน. วัตถุของคลาสนี้ควรจะถูกจัดสรรโดยใช้ฟังก์ชัน [System::MakeObject()](../system/makeobject/) เท่านั้น. อย่าสร้างอินสแตนซ์ของชนิดนี้บนสแต็กหรือโดยใช้ operator new, เนื่องจากจะทำให้เกิดข้อผิดพลาดรันไทม์และ/หรือข้อผิดพลาดการตรวจสอบ. ควรห่อคลาสนี้ในตัวชี้ [System::SmartPtr](../system/smartptr/) เสมอและใช้ตัวชี้นี้เพื่อส่งผ่านเป็นอาร์กิวเมนต์ให้กับฟังก์ชัน. |
