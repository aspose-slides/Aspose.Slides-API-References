## HttpClientHandler คลาส


เป็นตัวจัดการข้อความเริ่มต้นที่ใช้โดยคลาส [HttpClient](../httpclient/). วัตถุของคลาสนี้ควรจะจัดสรรโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น. ห้ามสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ operator new เนื่องจากจะทำให้เกิดข้อผิดพลาดรันไทม์และ/หรือข้อผิดพลาดการอ้างอิง. ควรห่อหุ้มคลาสนี้ด้วยตัวชี้ [System::SmartPtr](../../system/smartptr/) เสมอและใช้ตัวชี้นี้เพื่อส่งต่อให้ฟังก์ชันเป็นอาร์กิวเมนต์.

```cpp
class HttpClientHandler : public System::Net::Http::HttpMessageHandler
```
