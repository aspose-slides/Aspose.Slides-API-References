## HttpMessageInvoker คลาส

อนุญาตให้แอปพลิเคชันเรียกเมธอด Send บนสายการทำงานของ HTTP handler ได้ ออบเจ็กต์ของคลาสนี้ควรสร้างผ่านฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น อย่าสร้างอินสแตนซ์ของชนิดนี้บนสแตกหรือใช้ operator new เนื่องจากจะทำให้เกิดข้อผิดพลาดรันไทม์และ/หรือการอ้างอิงที่ผิดพลาด ควรรัดคลาสนี้เป็นพอยน์เตอร์ [System::SmartPtr](../../system/smartptr/) เสมอและใช้พอยน์เตอร์นี้ส่งเป็นอาร์กิวเมนต์ให้ฟังก์ชัน

```cpp
class HttpMessageInvoker : public System::IDisposable
```
