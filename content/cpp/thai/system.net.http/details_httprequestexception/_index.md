## Details_HttpRequestException คลาส


คลาสข้อยกเว้นพื้นฐานถูกโยนโดยคลาส [HttpClient](../httpclient/) และ [HttpMessageHandler](../httpmessagehandler/). ห้ามสร้างอินสแตนซ์ของคลาสนี้ด้วยตนเอง. ใช้คลาส HttpRequestException แทน. ห้ามห่อหุ้มอินสแตนซ์ของคลาส HttpRequestException ไว้ใน [System::SmartPtr](../../system/smartptr/).

```cpp
class Details_HttpRequestException : public System::Details_Exception
```
