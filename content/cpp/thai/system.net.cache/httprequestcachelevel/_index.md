## HttpRequestCacheLevel enum


enum อธิบายการตั้งค่าแคชสำหรับ HTTP.

```cpp
enum class HttpRequestCacheLevel
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Default | 0 | ตอบสนองคำขอสำหรับทรัพยากรโดยใช้สำเนาที่แคชของทรัพยากรหรือโดยส่งคำขอไปยังเซิร์ฟเวอร์. |
| BypassCache | 1 | ตอบสนองคำขอโดยใช้เซิร์ฟเวอร์. |
| CacheOnly | 2 | ใช้แคชของไคลเอนต์เสมอเพื่อดึงทรัพยากร. |
| CacheIfAvailable | 3 | ตอบสนองคำขอสำหรับทรัพยากรจากแคชหากทรัพยากรพร้อมใช้งาน, ไม่เช่นนั้นจะส่งคำขอไปยังเซิร์ฟเวอร์. |
| Revalidate | 4 | ใช้สำเนาทรัพยากรในเครื่องหากเวลาประทับของไคลเอนต์เท่ากับเวลาประทับของทรัพยากรบนเซิร์ฟเวอร์. ไม่เช่นนั้นจะดาวน์โหลดทรัพยากรจากเซิร์ฟเวอร์. |
| Reload | 5 | ทรัพยากรจะถูกดาวน์โหลดจากเซิร์ฟเวอร์เสมอ. |
| NoCacheNoStore | 6 | ไม่เคยตอบสนองคำขอโดยใช้ทรัพยากรจากแคชและไม่ทำการแคชทรัพยากร. |
| CacheOrNextCacheOnly | 7 | ตอบสนองคำขอสำหรับทรัพยากรจากแคชของคอมพิวเตอร์ท้องถิ่นหรือจากแคชระยะไกลบน LAN. |
| Refresh | 8 | ตอบสนองคำขอโดยใช้เซิร์ฟเวอร์หรือแคชอื่นที่ไม่ใช่แคชท้องถิ่น. |
