## RequestCacheLevel enum

The enum นี้อธิบายการตั้งค่าแคชที่ใช้ได้กับทุก [WebRequest](../../system.net/webrequest/).

```cpp
enum class RequestCacheLevel
```

### ค่าต่างๆ

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Default | 0 | ตอบสนองคำขอสำหรับทรัพยากรโดยใช้สำเนาที่เก็บไว้ในแคชของทรัพยากรหรือโดยส่งคำขอไปยังเซิร์ฟเวอร์ |
| BypassCache | 1 | ตอบสนองคำขอโดยใช้เซิร์ฟเวอร์ ไม่ดึงรายการใดจากแคช |
| CacheOnly | 2 | ตอบสนองคำขอสำหรับทรัพยากรจากแคชเท่านั้น เมื่อทรัพยากรไม่ได้อยู่ในแคชของไคลเอนต์ จะเกิดข้อยกเว้น WebException |
| CacheIfAvailable | 3 | ตอบสนองคำขอสำหรับทรัพยากรจากแคชหากทรัพยากรพร้อมใช้งาน มิฉะนั้นจะส่งคำขอไปยังเซิร์ฟเวอร์ |
| Revalidate | 4 | ใช้สำเนาทรัพยากรในเครื่องหากเวลาประทับของไคลเอนต์ตรงกับเวลาประทับของทรัพยากรบนเซิร์ฟเวอร์ มิฉะนั้นจะดาวน์โหลดทรัพยากรจากเซิร์ฟเวอร์ |
| Reload | 5 | ทรัพยากรถูกดาวน์โหลดจากเซิร์ฟเวอร์เสมอ |
| NoCacheNoStore | 6 | ไม่เคยตอบสนองคำขอโดยใช้ทรัพยากรจากแคชและไม่เก็บทรัพยากรในแคช |
