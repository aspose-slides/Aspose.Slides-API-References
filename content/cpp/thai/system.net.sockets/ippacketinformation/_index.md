## IPPacketInformation คลาส

แสดงข้อมูลเกี่ยวกับแพ็กเกจ. อ็อบเจ็กต์ของคลาสนี้ควรสร้างผ่านฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น. อย่าสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ operator new เนื่องจากจะทำให้เกิดข้อผิดพลาดรันไทม์และ/หรือการตรวจสอบข้อผิดพลาด. เสมอห่อคลาสนี้ในพอยน์เตอร์ [System::SmartPtr](../../system/smartptr/) และใช้พอยน์เตอร์นี้เพื่อส่งเป็นอาร์กิวเมนต์ให้ฟังก์ชัน.

```cpp
class IPPacketInformation : public System::Object
```
