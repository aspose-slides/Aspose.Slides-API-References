## enum SocketType

ระบุประเภทของซ็อกเก็ต.

```cpp
enum class SocketType
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Stream | 1 | ประเภทที่รองรับสตรีมไบต์แบบเชื่อมต่อสองทางที่เชื่อถือได้โดยไม่มีการทำสำเนาข้อมูลและไม่มีการรักษาขอบเขต. |
| Dgram | 2 | ประเภทที่รองรับดาตะแกรม ซึ่งเป็นข้อความแบบไม่มีการเชื่อมต่อและไม่มีความน่าเชื่อถือที่มีความยาวสูงสุดคงที่. |
| Raw | 3 | ประเภทที่รองรับการเข้าถึงโปรโตคอลการส่งข้อมูลพื้นฐาน. |
| Rdm | 4 | ประเภทที่รองรับข้อความแบบไม่มีการเชื่อมต่อที่มุ่งเน้นข้อความและส่งมอบได้อย่างเชื่อถือได้ รวมถึงรักษาขอบเขตของข้อความในข้อมูล. |
| Seqpacket | 5 | ประเภทที่ให้การถ่ายโอนสตรีมไบต์ตามลำดับแบบเชื่อมต่อและเชื่อถือได้สองทางผ่านเครือข่าย. |
| Unknown | n/a | ประเภทที่ไม่ทราบ. |
