## คลาส LingerOption

ระบุว่าซ็อกเก็ตจะคงการเชื่อมต่ออยู่หลังจากเรียกเมธอด Close() หรือ Close() หรือไม่ รวมถึงระบุระยะเวลาที่ซ็อกเก็ตจะคงการเชื่อมต่อหากการส่งข้อมูลยังดำเนินต่ออยู่ วัตถุของคลาสนี้ควรสร้างด้วยฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น อย่าสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ operator new เพราะจะทำให้เกิดข้อผิดพลาดเวลารันและ/หรือการ fault ของ assertion เสมอ ควรห่อคลาสนี้ด้วยพอยน์เตอร์ [System::SmartPtr](../../system/smartptr/) แล้วใช้พอยน์เตอร์นี้เพื่อส่งเป็นอาร์กิวเมนต์ให้กับฟังก์ชัน

```cpp
class LingerOption : public System::Object
```
