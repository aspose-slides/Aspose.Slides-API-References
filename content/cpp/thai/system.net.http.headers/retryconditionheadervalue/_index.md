## RetryConditionHeaderValue คลาส


เป็นตัวแทนค่าของส่วนหัว 'Retry-After' วัตถุของคลาสนี้ควรจัดสรรเฉพาะด้วยฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น ไม่ควรสร้างอินสแตนซ์ของชนิดนี้บนสแตกหรือใช้ operator new เนื่องจากจะทำให้เกิดข้อผิดพลาด runtime และ/หรือ assertion faults ควรห่อคลาสนี้ไว้ในพอยเตอร์ [System::SmartPtr](../../system/smartptr/) และใช้พอยเตอร์นี้เพื่อส่งเป็นอาร์กิวเมนต์ให้กับฟังก์ชัน

```cpp
class RetryConditionHeaderValue : public System::ICloneable
```
