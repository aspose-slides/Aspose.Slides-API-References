## ProductInfoHeaderValue คลาส

แสดงถึงผลิตภัณฑ์หรือความคิดเห็นในค่าของหัวข้อ 'User-Agent' วัตถุของคลาสนี้ควรได้รับการจัดสรรเพียงโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น อย่าสร้างอินสแตนซ์ของชนิดนี้บนสแตกหรือโดยใช้ตัวดำเนินการ new เนื่องจากจะทำให้เกิดข้อผิดพลาดเวลาเรียกใช้งานและ/หรือข้อผิดพลาดการยืนยันค่า ควรห่อหุ้มคลาสนี้ด้วยตัวชี้ [System::SmartPtr](../../system/smartptr/) เสมอและใช้ตัวชี้นี้เพื่อส่งผ่านเป็นอากิวเมนต์ให้ฟังก์ชัน

```cpp
class ProductInfoHeaderValue : public System::ICloneable
```
