## DataSet คลาส

ชุดของข้อมูลที่จัดเก็บในตารางพร้อมความสัมพันธ์บางอย่างระหว่างกัน. อ็อบเจ็กต์ของคลาสนี้ควรได้รับการจัดสรรเฉพาะโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/). อย่าสร้างอินสแตนซ์ของชนิดนี้บนสแตกหรือโดยใช้ตัวดำเนินการ new, เนื่องจากจะทำให้เกิดข้อผิดพลาดเวลาเรียกใช้และ/หรือข้อบกพร่องของการตรวจสอบ. ควรห่อคลาสนี้ไว้ในพอยน์เตอร์ [System::SmartPtr](../../system/smartptr/) และใช้พอยน์เตอร์นี้เพื่อส่งผ่านเป็นอาร์กูเมนต์ให้ฟังก์ชัน.

```cpp
class DataSet : public System::Object
```
