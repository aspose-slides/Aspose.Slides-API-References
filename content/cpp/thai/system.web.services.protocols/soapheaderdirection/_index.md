## SoapHeaderDirection enum

ระบุทิศทางของส่วนหัว SOAP.

```cpp
enum class SoapHeaderDirection
```
### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| In | 1 | ผู้รับส่วนหัว SOAP คือบริการ XML [Web](../../system.web/) |
| InOut | 3 | ผู้รับส่วนหัว SOAP ทั้งสองคือบริการ XML [Web](../../system.web/) และไคลเอนต์บริการ XML [Web](../../system.web/) |
| Out | 2 | ผู้รับส่วนหัว SOAP คือไคลเอนต์บริการ XML [Web](../../system.web/) |
| Fault | 4 | ส่วนหัว SOAP จะถูกส่งไปยังไคลเอนต์บริการ XML [Web](../../system.web/) เมื่อข้อยกเว้นถูกโยนโดยเมธอดบริการ XML [Web](../../system.web/) |
