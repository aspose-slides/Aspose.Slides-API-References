## SoapServiceRoutingStyle enum


แสดงรายการตัวเลือกของวิธีการที่ข้อความ SOAP ถูกกำหนดเส้นทางไปยังบริการ XML [Web](../../system.web/).

```cpp
enum class SoapServiceRoutingStyle
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| SoapAction | 0 | ข้อความ SOAP ถูกกำหนดเส้นทางโดยอิงจากแอตทริบิวต์ 'SOAPAction' |
| RequestElement | 1 | ข้อความ SOAP ถูกกำหนดเส้นทางโดยอิงจากองค์ประกอบลูกแรกหลังจากองค์ประกอบ 'Body' |
