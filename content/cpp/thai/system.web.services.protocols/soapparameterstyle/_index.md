## SoapParameterStyle enum

ระบุรูปแบบของพารามิเตอร์ในข้อความ SOAP.

```cpp
enum class SoapParameterStyle
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Default | 0 | หากไม่ใช้ '[SoapDocumentServiceAttribute](../soapdocumentserviceattribute/)' กับคลาส ค่าเริ่มต้นจะเป็น 'Wrapped'. |
| Bare | 1 | พารามิเตอร์จะถูกวางในองค์ประกอบ XML ที่ตามหลังองค์ประกอบ 'Body'. |
| Wrapped | 2 | พารามิเตอร์ถูกห่อหุ้มไว้ในองค์ประกอบ XML เดียวที่ตามหลังองค์ประกอบ 'Body'. |
