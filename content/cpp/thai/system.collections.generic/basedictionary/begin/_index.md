## BaseDictionary::begin() const เมธอด


ส่งคืนตัววนซ้ำไปยัง KVPair-wrapper สำหรับ key-value-element ของ container. ดำเนินการในสไตล์ C# - ตัววนซ้ำควรส่งคืน KVPair-object ด้วยอินเทอร์เฟซ get_Key() และ get_Value() หาก container ว่าง ตัววนซ้ำที่ส่งคืนจะเท่ากับ [end()](../../ienumerable/end/).

```cpp
const_iterator System::Collections::Generic::BaseDictionary<Map>::begin() const noexcept
```


### ค่าที่ส่งคืน

ตัววนซ้ำที่ชี้ไปยังอิลิเมนต์แรกของคอลเลกชัน.
