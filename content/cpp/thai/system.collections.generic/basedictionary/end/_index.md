## BaseDictionary::end() const เมธอด

คืนค่าอิเทรเตอร์ไปยัง KVPair-wrapper สำหรับ key-value-element ที่ตามหลังสมาชิกสุดท้ายของคอนเทนเนอร์. Implemented in C# style - iterator ควรคืน KVPair-object พร้อมอินเทอร์เฟซ get_Key() และ get_Value(). องค์ประกอบนี้ทำหน้าที่เป็นตัวแทน; การพยายามเข้าถึงจะทำให้เกิดพฤติกรรมที่ไม่กำหนด.

```cpp
const_iterator System::Collections::Generic::BaseDictionary<Map>::end() const noexcept
```

### ค่าที่ส่งคืน

อิเทรเตอร์ที่ชี้ไปยังองค์ประกอบเชิงทฤษฎีที่วางหลังจากองค์ประกอบสุดท้ายของคอลเลกชัน.
