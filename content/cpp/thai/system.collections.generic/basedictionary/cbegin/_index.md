## BaseDictionary::cbegin() const เมธอด

คืนค่า iterator ไปยังองค์ประกอบแรกของคอนเทนเนอร์. ดำเนินการตามรูปแบบ STL. หากคอนเทนเนอร์ไม่มีค่า iterator ที่คืนจะเท่ากับ [end()](../../ienumerable/end/).

```cpp
stl_const_iterator System::Collections::Generic::BaseDictionary<Map>::cbegin() const noexcept
```

### ค่าที่ส่งกลับ

iterator ที่ชี้ไปยังองค์ประกอบแรกที่กำหนดเป็น const ของคอลเลกชัน.
