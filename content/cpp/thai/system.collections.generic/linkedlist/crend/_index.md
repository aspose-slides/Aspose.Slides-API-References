## LinkedList::crend() const เมธอด

รับอิเทอเรเตอร์ย้อนกลับสำหรับอิลีเมนต์ที่ไม่มีอยู่จริงและมีคุณสมบัติ const ก่อนจุดเริ่มต้นของคอลเลกชัน.

```cpp
const_reverse_iterator System::Collections::Generic::LinkedList<T>::crend() const noexcept
```

### ค่าที่ส่งคืน

อิเทอเรเตอร์ย้อนกลับที่ชี้ไปยังอิลีเมนต์ที่มีคุณสมบัติ const ตามทฤษฎีซึ่งอยู่ก่อนอิลีเมนต์แรกในลิงก์ลิสต์ (ตำแหน่งสุดท้ายเมื่อย้อนกลับ).
