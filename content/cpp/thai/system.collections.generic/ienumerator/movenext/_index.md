## IEnumerator::MoveNext() เมธอด


ย้าย enumerator ไปยังองค์ประกอบถัดไป หากไม่มีองค์ประกอบใดถูกอ้างอิงก่อนหน้านี้ จะตั้งค่าอ้างอิงไปยังองค์ประกอบแรกที่พบ หากถึงจุดสิ้นสุดของคอนเทนเนอร์ จะไม่ทำอะไร

```cpp
virtual bool System::Collections::Generic::IEnumerator<T>::MoveNext()=0
```


### ค่าที่ส่งกลับ

คืนค่า true หากมีองค์ประกอบบางอย่างพร้อมใช้งานหลังจากเรียก, false ในกรณีอื่น
