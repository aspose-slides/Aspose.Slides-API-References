```cpp
virtual bool System::Collections::Generic::ISet<T>::IsSubsetOf(IEnumerablePtr other)=0
```

### Arguments

| Parameter | Type | Description |
| --- | --- | --- |
| other | [IEnumerablePtr](../ienumerableptr/) | Superset ที่ใช้ในการตรวจสอบ |

### Return Value

True หากทุกองค์ประกอบในเซตปัจจุบันมีอยู่ใน **other**, false หากไม่เป็นเช่นนั้น.
