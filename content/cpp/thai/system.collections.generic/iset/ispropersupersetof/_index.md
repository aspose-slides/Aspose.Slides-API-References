## ISet::IsProperSupersetOf(IEnumerablePtr) เมธอด

ตรวจสอบว่าชุดปัจจุบันเป็นซุปเซ็ตที่เคร่งครัดของคอนเทนเนอร์อื่นหรือไม่。

```cpp
virtual bool System::Collections::Generic::ISet<T>::IsProperSupersetOf(IEnumerablePtr other)=0
```

### Arguments

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| other | [IEnumerablePtr](../ienumerableptr/) | ชุดย่อยเพื่อเปรียบเทียบ. |

### Return Value

True if all elements in **other** are present in set and set has more elements that **other**, false otherwise.
