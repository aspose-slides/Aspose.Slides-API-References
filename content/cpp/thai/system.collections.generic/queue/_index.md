## หมายเหตุ


[Queue](./) คอนเทนเนอร์ที่ห่อหุ้ม STL list. อ็อบเจ็กต์ของคลาสนี้ควรจัดสรรโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น. อย่าสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือใช้ operator new เพราะจะทำให้เกิดข้อผิดพลาดขณะทำงานและ/หรือการตรวจสอบ assert. ควรห่อคลาสนี้ด้วยพอยน์เตอร์ [System::SmartPtr](../../system/smartptr/) และใช้พอยน์เตอร์นี้ส่งเป็นอาร์กิวเมนต์ให้ฟังก์ชัน.

```cpp
#include <system/collections/queue.h>
#include <system/smart_ptr.h>

using namespace System;
using namespace System::Collections::Generic;

void PrintItems(const SmartPtr<IEnumerable<int>> &queue)
{
  for (const int item: queue)
  {
    std::cout << item << ' ';
  }
  std::cout << std::endl;
}

int main()
{
  // สร้างอินสแตนซ์ของคลาส Queue.
  auto queue = MakeObject<Queue<int>>();

  // เติมคิว.
  queue->Enqueue(1);
  queue->Enqueue(2);
  queue->Enqueue(3);

  // พิมพ์รายการแรกของคิว. เมธอด Peek ไม่ลบรายการออกจากคิว.
  std::cout << queue->Peek() << std::endl;
  // พิมพ์รายการของคิว.
  PrintItems(queue);

  // พิมพ์รายการแรกของคิว. เมธอด Dequeue ลบรายการออกจากคิว.
  std::cout << queue->Dequeue() << std::endl;
  // พิมพ์รายการของคิว.
  PrintItems(queue);

  return 0;
}
/*
ตัวอย่างโค้ดนี้แสดงผลลัพธ์ต่อไปนี้:
1
1 2 3
1
2 3
*/
```
