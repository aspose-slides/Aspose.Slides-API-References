## ReverseEnumerator::IsValid() const เมธอด


ตรวจสอบว่ามีการเรียก [MoveNext()](../movenext/) หรือไม่และยังไม่ได้ถึงจุดสิ้นสุด.

```cpp
bool System::Collections::Generic::ReverseEnumerator<Container, Element>::IsValid() const
```


### ค่าที่ส่งกลับ

false หาก [MoveNext()](../movenext/) ไม่ได้ถูกเรียกเลยหรือถึงจุดสิ้นสุดของคอนเทนเนอร์; true ในกรณีอื่น.
