## IList::get_IsFixedSize() เมธอด


ตรวจสอบว่าคอลเลกชันมีขนาดคงที่หรือไม่.

```cpp
bool System::Collections::Generic::IList<T>::get_IsFixedSize()
```


### ค่าที่ส่งกลับ

true หากขนาดของคอลเลกชันไม่สามารถเปลี่ยนแปลงได้, false หากไม่เป็นเช่นนั้น.
