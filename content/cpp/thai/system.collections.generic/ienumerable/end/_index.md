## IEnumerable::end() เมธอด

รับตัวอีเทอเรเตอร์ที่ชี้ไปหลังองค์ประกอบสุดท้าย (ถ้ามี) ของคอลเลกชัน ตัวอีเทอเรเตอร์นี้ไม่สามารถใช้ในการเปลี่ยนแปลงอ็อบเจกต์ที่อ้างอิงได้ เนื่องจาก [GetEnumerator()](../getenumerator/) คืนค่าตัวคัดลอกของ T.

```cpp
iterator System::Collections::Generic::IEnumerable<T>::end()
```

### ค่าที่คืน

อีเทอเรเตอร์ที่ชี้ไปหลังองค์ประกอบสุดท้าย (ถ้ามี) ของคอลเลกชัน

const_iterator System::Collections::Generic::IEnumerable<T>::end() const
