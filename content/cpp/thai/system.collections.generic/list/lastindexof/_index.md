## List::LastIndexOf(const T\&) const เมธอด

ค้นหาวัตถุที่ระบุและส่งคืนดัชนีแบบศูนย์ฐานของการปรากฏครั้งสุดท้ายภายในรายการทั้งหมด

```cpp
int32_t System::Collections::Generic::List<T>::LastIndexOf(const T &item) const
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| item | const T\& | วัตถุที่ต้องการค้นหาในรายการ |

### ค่าที่ส่งกลับ

ดัชนีแบบศูนย์ฐานของการปรากฏครั้งสุดท้ายของ item ภายใน [List](../) ทั้งหมด หากพบ; มิฉะนั้น, -1.
