## List::end() เมธอด


รับ iterator สำหรับองค์ประกอบที่ไม่มีอยู่หลังส่วนสุดของคอลเลกชัน

```cpp
iterator System::Collections::Generic::List<T>::end() noexcept
```


### ค่าที่ส่งกลับ

iterator ที่ชี้ไปยังองค์ประกอบเชิงทฤษฎีที่วางไว้หลังองค์ประกอบสุดท้ายใน list

## List::end() const เมธอด


รับ iterator สำหรับองค์ประกอบที่ไม่มีอยู่หลังส่วนสุดของคอลเลกชันที่เป็น const

```cpp
const_iterator System::Collections::Generic::List<T>::end() const noexcept
```


### ค่าที่ส่งกลับ

iterator ที่ชี้ไปยังองค์ประกอบเชิงทฤษฎีที่วางไว้หลังองค์ประกอบสุดท้ายในอินสแตนซ์ของ list ที่เป็น const
