## List::TrueForAll(System::Predicate\<T\>) เมธอด


เป็นการตรวจสอบว่าทุกองค์ประกอบในคอลเลกชันตรงกับเงื่อนไขที่กำหนดโดยพรีดิเคตที่ระบุหรือไม่.

```cpp
bool System::Collections::Generic::List<T>::TrueForAll(System::Predicate<T> match)
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| match | [System::Predicate](../../../system/predicate/)\<T\> | พรีดิเคตเพื่อใช้ตรวจสอบองค์ประกอบ |

### ค่าที่ส่งกลับ

เป็น true หากทุกองค์ประกอบตรงกับเงื่อนไข, false หากไม่เป็นเช่นนั้น
