## List::cend() const เมธอด

รับ iterator สำหรับอิลิเมนต์ที่มีคุณลักษณะ const แต่ไม่มีอยู่จริง ซึ่งอยู่หลังส่วนสุดท้ายของ collection.

```cpp
const_iterator System::Collections::Generic::List<T>::cend() const noexcept
```

### ค่าที่ส่งคืน

iterator ที่ชี้ไปยังอิลิเมนต์ที่มีคุณลักษณะ const ที่เป็นทฤษฎีซึ่งถูกวางไว้หลังอิลิเมนต์สุดท้ายใน list.
