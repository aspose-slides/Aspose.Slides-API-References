## List::Exists(System::Predicate\<T\>) เมธอด

ตรวจสอบว่ามีองค์ประกอบที่ตรงตามเงื่อนไขที่ระบุอยู่ในรายการหรือไม่.

```cpp
bool System::Collections::Generic::List<T>::Exists(System::Predicate<T> match)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| match | [System::Predicate](../../../system/predicate/)\<T\> | Predicate เพื่อเช็คองค์ประกอบ. |

### ค่าที่ส่งกลับ

คืนค่า true หากพบองค์ประกอบที่ตรงกัน, คืนค่า false หากไม่พบ.
