## List::crend() const เมธอด


รับอีเทอเรเตอร์ย้อนกลับสำหรับองค์ประกอบที่ไม่มีอยู่จริงที่เป็น const-qualified ก่อนจุดเริ่มต้นของคอลเลกชัน.

```cpp
const_reverse_iterator System::Collections::Generic::List<T>::crend() const noexcept
```


### ค่าที่ส่งกลับ

อีเทอเรเตอร์ย้อนกลับที่ชี้ไปยังองค์ประกอบที่เป็น const-qualified ตามทฤษฎีซึ่งมาก่อนองค์ประกอบแรกในรายการ (เป็นรายการสุดท้ายเมื่อย้อนกลับ).
