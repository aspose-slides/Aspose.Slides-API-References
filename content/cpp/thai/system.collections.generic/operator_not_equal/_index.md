## System::Collections::Generic::operator!=(const KeyValuePair\<TKey, TValue\>\&, const KeyValuePair\<TKey, TValue\>\&) ฟังก์ชัน

เปรียบเทียบสองคู่คีย์-ค่าโดยใช้ความหมาย 'equals' แบบผกผัน

```cpp
template<typename TKey,typename TValue> bool System::Collections::Generic::operator!=(const KeyValuePair<TKey, TValue> &left, const KeyValuePair<TKey, TValue> &right)
```

### พารามิเตอร์แม่แบบ

| Parameter | Description |
| --- | --- |
| TKey | ประเภทคีย์ |
| TValue | ประเภทค่า |

### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| left | const [KeyValuePair](../keyvaluepair/)\<TKey, TValue\>\& | ตัวดำเนินการด้านซ้าย |
| right | const [KeyValuePair](../keyvaluepair/)\<TKey, TValue\>\& | ตัวดำเนินการด้านขวา |

### ค่าที่ส่งคืน

True หากคีย์และค่าทั้งสองไม่ตรงกัน, false ในกรณีอื่น
