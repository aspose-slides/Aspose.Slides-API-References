## BaseSet::cend() const เมธอด

รับตัววนสำหรับองค์ประกอบที่ไม่มีอยู่จริงที่มีคุณสมบัติ const ซึ่งอยู่หลังตำแหน่งสุดท้ายของคอลเลกชัน.

```cpp
const_iterator System::Collections::Generic::BaseSet<T, SET_T>::cend() const noexcept
```

### ค่าที่ส่งคืน

ตัววนที่ชี้ไปยังองค์ประกอบที่มีคุณสมบัติ const อย่างทฤษฎีซึ่งวางไว้หลังองค์ประกอบสุดท้ายใน hash set.
