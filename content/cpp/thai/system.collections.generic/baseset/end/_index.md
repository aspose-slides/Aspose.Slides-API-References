## BaseSet::end() const เมธอด

รับตัว iterator สำหรับองค์ประกอบที่ไม่มีอยู่ซึ่งอยู่หลังส่วนสุดท้ายของคอลเลกชันที่มีการกำหนด const.

```cpp
const_iterator System::Collections::Generic::BaseSet<T, SET_T>::end() const noexcept
```

### ค่าที่ส่งกลับ

ตัว iterator ที่ชี้ไปยังองค์ประกอบเชิงทฤษฎีที่ถูกวางไว้หลังจากองค์ประกอบสุดท้ายในอินสแตนซ์ของ hash set ที่กำหนดค่า const.
