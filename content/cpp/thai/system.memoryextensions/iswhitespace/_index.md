## System::MemoryExtensions::IsWhiteSpace(const ReadOnlySpan\<char16_t\>\&) ฟังก์ชัน

ตรวจสอบว่า span ทั้งหมดประกอบด้วยอักขระช่องว่างเท่านั้น

```cpp
bool System::MemoryExtensions::IsWhiteSpace(const ReadOnlySpan<char16_t> &span)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| span | const [ReadOnlySpan](../../system/readonlyspan/)\<char16_t\>\& | สแปนที่ต้องตรวจสอบสำหรับช่องว่าง |

### ค่าที่ส่งคืน

true หากอักขระทั้งหมดในสแปนเป็นช่องว่าง, false ในกรณีอื่น
