```cpp

```

### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| x | **float** | พิกัด X ของมุมซ้ายบนของสี่เหลี่ยมที่กำหนดขอบเขตของรูปไข่ที่ใช้วาดพาย |
| y | **float** | พิกัด Y ของมุมซ้ายบนของสี่เหลี่ยมที่กำหนดขอบเขตของรูปไข่ที่ใช้วาดพาย |
| width | **float** | ความกว้างของมุมซ้ายบนของสี่เหลี่ยมที่กำหนดขอบเขตของรูปไข่ที่ใช้วาดพาย |
| height | **float** | ความสูงของมุมซ้ายบนของสี่เหลี่ยมที่กำหนดขอบเขตของรูปไข่ที่ใช้วาดพาย |
| startAngle | **float** | ระบุมุมเริ่มต้นของพายเป็นองศา วัดตามเข็มนาฬิกาจากแกน X |
| sweepAngle | **float** | ระบุมุมระหว่างมุมเริ่มต้นกับจุดสิ้นสุดของพาย |
