## GraphicsPath::AddArc(float, float, float, float, float, float) เมธอด

```cpp
void System::Drawing::Drawing2D::GraphicsPath::AddArc(float x, float y, float width, float height, float startAngle, float sweepAngle)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| x | **float** | พิกัด X ของมุมบนซ้ายของสี่เหลี่ยมที่ล้อมรอบวงรีที่อาร์คถูกวาดจาก |
| y | **float** | พิกัด Y ของมุมบนซ้ายของสี่เหลี่ยมที่ล้อมรอบวงรีที่อาร์คถูกวาดจาก |
| width | **float** | ความกว้างของมุมบนซ้ายของสี่เหลี่ยมที่ล้อมรอบวงรีที่อาร์คถูกวาดจาก |
| height | **float** | ความสูงของมุมบนซ้ายของสี่เหลี่ยมที่ล้อมรอบวงรีที่อาร์คถูกวาดจาก |
| startAngle | **float** | ระบุมุมเริ่มต้นของอาร์คเป็นองศา วัดตามเข็มนาฬิกาจากแกน X |
| sweepAngle | **float** | ระบุมุมระหว่างมุมเริ่มต้นและจุดสิ้นสุดของอาร์ค |
