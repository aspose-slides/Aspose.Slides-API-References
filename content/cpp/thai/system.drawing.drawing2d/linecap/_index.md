## LineCap enum

Indicates the available cap styles with which a [Pen](../../system.drawing/pen/) object can end a line.

```cpp
enum class LineCap
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| Flat | 0 | Flat ปลายเส้น. |
| Square | 1 | Square ปลายเส้น. |
| Round | 2 | Round ปลายเส้น. |
| Triangle | 3 | Triangular ปลายเส้น. |
| NoAnchor | 16 | ไม่มี anchor. |
| SquareAnchor | 17 | Square anchor ปลายเส้น. |
| RoundAnchor | 18 | Round anchor ปลายเส้น. |
| DiamondAnchor | 19 | Diamond anchor ปลายเส้น. |
| ArrowAnchor | 20 | Arrow anchor ปลายเส้น. |
| AnchorMask | 240 | มาสก์ที่ใช้ตรวจสอบว่าปลายเส้นเป็น anchor cap หรือไม่. |
| Custom | 255 | Custom ปลายเส้น. |
