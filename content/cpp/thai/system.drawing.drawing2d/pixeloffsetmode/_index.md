## PixelOffsetMode enum

ระบุว่าพิกเซลจะถูกชดเชยอย่างไรเมื่อทำการเรนเดอร์

```cpp
enum class PixelOffsetMode
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Invalid | n/a | ค่าไม่ถูกต้อง. |
| Default | n/a | โหมดเริ่มต้น. |
| HighSpeed | n/a | โหมดคุณภาพต่ำ (ประสิทธิภาพสูง). |
| HighQuality | n/a | โหมดคุณภาพสูง (ประสิทธิภาพต่ำ). |
| None | n/a | ไม่มีการชดเชยพิกเซล. |
| Half | n/a | พิกเซลจะถูกชดเชยด้วย -0.5 หน่วยในแนวนอนและแนวตั้งเพื่อการทำแอนตี้อะลิอาสิงที่มีประสิทธิภาพสูง. |
