## InterpolationMode enum

ระบุอัลกอริธึมที่ใช้เมื่อภาพถูกหมุนหรือปรับขนาด.

```cpp
enum class InterpolationMode
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Invalid | n/a | เทียบเท่ากับ [QualityMode::Invalid](../qualitymode/). |
| Default | n/a | โหมดเริ่มต้น. |
| Low | n/a | คุณภาพต่ำ. |
| High | n/a | คุณภาพสูง. |
| Bilinear | n/a | การประมาณค่าแบบ Bilinear. |
| Bicubic | n/a | การประมาณค่าแบบ Bicubic. |
| NearestNeighbor | n/a | การประมาณค่าแบบ NearestNeighbor. |
| HighQualityBilinear | n/a | การประมาณค่าแบบ Bilinear คุณภาพสูง. |
| HighQualityBicubic | n/a | การประมาณค่าแบบ Bicubic คุณภาพสูง. |
