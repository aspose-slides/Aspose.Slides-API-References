## DashCap enum

กำหนดประเภทของฝาปิดที่ใช้ที่ปลายทั้งสองของเส้นขีดในเส้นประ.

```cpp
enum class DashCap
```

### Values

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Flat | 0 | ฝาปิดแบบสี่เหลี่ยมที่ทำให้ปลายสองของเส้นขีดเป็นสี่เหลี่ยม |
| Round | 2 | ฝาปิดแบบวงกลมที่ทำให้ปลายสองของเส้นขีดเป็นรูปโค้ง |
| Triangle | 3 | ฝาปิดแบบสามเหลี่ยมที่ชี้ที่ปลายสองของเส้นขีด |
