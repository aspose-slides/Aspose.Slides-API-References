## CombineMode enum

ระบุวิธีการรวมพื้นที่ตัดคลิป

```cpp
enum class CombineMode
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Replace | 0 | พื้นที่ตัดคลิปหนึ่งจะถูกแทนที่ด้วยอีกพื้นที่ตัดคลิปหนึ่ง |
| Intersect | 1 | สองพื้นที่ตัดคลิปจะถูกรวมโดยนำส่วนตัดกันของมัน |
| Union | 2 | สองพื้นที่ตัดคลิปจะถูกรวมโดยการรวมของทั้งสอง |
| Xor | 3 | สองพื้นที่ตัดคลิปจะถูกรวมโดยเก็บส่วนที่อยู่ในหนึ่งในสองพื้นที่เท่านั้น ไม่รวมส่วนที่อยู่ในทั้งสองพร้อมกัน |
| Exclude | 4 | สองพื้นที่ตัดคลิปจะถูกรวมโดยนำส่วนของพื้นที่แรกที่ไม่ตัดกับพื้นที่ที่สอง |
| Complement | 5 | สองพื้นที่ตัดคลิปจะถูกรวมโดยนำส่วนของพื้นที่ที่สองที่ไม่ตัดกับพื้นที่แรก |
