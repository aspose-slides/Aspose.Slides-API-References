## LineJoin enum

ระบุวิธีการเชื่อมต่อเส้นหรือโค้งที่ต่อเนื่องกัน

```cpp
enum class LineJoin
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Miter | 0 | การเชื่อมแบบมิตเตอร์ที่ให้มุมคมหรือมุมตัด ขึ้นอยู่กับว่าความยาวของมิตเตอร์เกินขีดจำกัดมิตเตอร์หรือไม่ |
| Bevel | 1 | การเชื่อมแบบบีเวลที่ให้มุมเป็นทแยง |
| Round | 2 | การเชื่อมแบบราวน์ที่ให้โค้งวงกลมราบรื่นระหว่างเส้น |
| MiterClipped | 3 | การเชื่อมแบบมิตเตอร์ที่ให้มุมคมหรือมุมบีเวล ขึ้นอยู่กับว่าความยาวของมิตเตอร์เกินขีดจำกัดมิตเตอร์หรือไม่ |
