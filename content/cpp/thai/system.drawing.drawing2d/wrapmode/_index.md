## WrapMode enum

ระบุวิธีการกระเบื้องเทกเจอร์หรือไล่สีเมื่อมันมีขนาดเล็กกว่าพื้นที่ที่ต้องเติม

```cpp
enum class WrapMode
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Tile | 0 | กระเบื้องไล่สีหรือเทกเจอร์ |
| TileFlipX | 1 | สลับเทกเจอร์หรือไล่สีแนวนอนแล้วกระเบื้องเทกเจอร์หรือไล่สี |
| TileFlipY | 2 | สลับเทกเจอร์หรือไล่สีแนวตั้งแล้วกระเบื้องเทกเจอร์หรือไล่สี |
| TileFlipXY | 3 | สลับเทกเจอร์หรือไล่สีแนวนอนและแนวตั้งแล้วกระเบื้องเทกเจอร์หรือไล่สี |
| Clamp | 4 | ควบคุมเทกเจอร์หรือไล่สีให้เป็นตามขอบวัตถุ |
