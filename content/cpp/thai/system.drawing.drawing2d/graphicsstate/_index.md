## GraphicsState คลาส

แทนสถานะของอ็อบเจ็กต์ [Graphics](../../system.drawing/graphics/). อ็อบเจ็กต์ของคลาสนี้ควรสร้างโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น. ห้ามสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือด้วยตัวดำเนินการ new เนื่องจากจะทำให้เกิดข้อผิดพลาดระหว่างรันไทม์และ/หรือการตรวจสอบล้มเหลว. ควรห่อคลาสนี้ด้วยพอยน์เตอร์ [System::SmartPtr](../../system/smartptr/) เสมอและใช้พอยน์เตอร์นี้เพื่อส่งเป็นอาร์กิวเมนต์ให้ฟังก์ชัน.

```cpp
class GraphicsState : public System::MarshalByRefObject
```
