## SmoothingMode enum

ระบุประเภทของการทำให้เส้น โค้ง และขอบของพื้นที่ที่เติมสี มีการทำให้เรียบ (antialiasing) อย่างไร

```cpp
enum class SmoothingMode
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| Invalid | n/a | ค่าไม่ถูกต้อง. |
| Default | n/a | โหมดค่าเริ่มต้น, ไม่ทำ antialiasing. |
| HighSpeed | n/a | ไม่มี antialiasing, ความเร็วสูง. |
| HighQuality | n/a | การเรนเดอร์แบบ antialiased, ความเร็วต่ำ. |
| None | n/a | ไม่มี antialising. |
| AntiAlias | n/a | การเรนเดอร์แบบ antialiased. |
