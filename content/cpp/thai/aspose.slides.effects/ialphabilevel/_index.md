## IAlphaBiLevel คลาส


แทนค่าเอฟเฟกต์ Alpha Bi-Level. ค่าความทึบ (Alpha) ที่น้อยกว่าขีดจำกัดจะถูกเปลี่ยนเป็น 0 (โปร่งใสเต็มที่) และค่าความทึบที่เท่ากับหรือมากกว่าขีดจำกัดจะถูกเปลี่ยนเป็น 100% (ทึบเต็มที่)

```cpp
class IAlphaBiLevel : public virtual Aspose::Slides::Effects::IImageTransformOperation,
                      public Aspose::Slides::IAccessiblePVIObject<System::SharedPtr<Aspose::Slides::Effects::IAlphaBiLevelEffectiveData>>
```
