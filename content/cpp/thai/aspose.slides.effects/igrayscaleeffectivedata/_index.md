## IGrayScaleEffectiveData คลาส

อ็อบเจ็กต์ที่ไม่เปลี่ยนแปลงซึ่งแสดงผลเอฟเฟกต์แบบระดับสีเทา. แปลงค่าสีของเอฟเฟกต์ทั้งหมดให้เป็นเฉดสีเทาที่สอดคล้องกับความสว่างของมัน. ค่าความโปร่งใส (alpha) ของเอฟเฟกต์ไม่ได้รับผลกระทบ.

```cpp
class IGrayScaleEffectiveData : public virtual Aspose::Slides::Effects::IEffectEffectiveData
```
