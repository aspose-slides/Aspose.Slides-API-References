## IAlphaBiLevelEffectiveData คลาส

อ็อบเจ็กต์ที่ไม่สามารถเปลี่ยนแปลงได้ซึ่งเป็นตัวแทนของเอฟเฟกต์ Alpha Bi-Level. ค่า Alpha (Opacity) ที่น้อยกว่าค่าธรณีจะถูกเปลี่ยนเป็น 0 (โปร่งใสเต็มที่) และค่า alpha ที่มากกว่าหรือเท่ากับค่าธรณีจะถูกเปลี่ยนเป็น 100% (ทึบเต็มที่).

```cpp
class IAlphaBiLevelEffectiveData : public virtual Aspose::Slides::Effects::IEffectEffectiveData
```
