## ILuminanceEffectiveData คลาส

แสดงถึงเอฟเฟกต์ [Luminance](../luminance/). Brightness ทำการเปลี่ยนสีทั้งหมดให้ใกล้กับสีขาวหรือสีดำอย่างเชิงเส้น. Contrast ปรับสเกลสีทั้งหมดให้ห่างกันหรือใกล้กันมากขึ้นหรือน้อยลง.

```cpp
class ILuminanceEffectiveData : public virtual Aspose::Slides::Effects::IEffectEffectiveData
```
