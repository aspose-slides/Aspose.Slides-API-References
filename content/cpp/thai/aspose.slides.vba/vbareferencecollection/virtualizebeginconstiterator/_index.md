```cpp
virtualized_iterator * Aspose::Slides::Vba::VbaReferenceCollection::virtualizeBeginConstIterator() const override
```

### ค่าที่ส่งคืน

Iterator ที่ชี้ไปยังองค์ประกอบแรก (หากมี)ของอินสแตนซ์ที่กำหนดเป็น const ของคอลเลกชัน ให้การใช้งาน const iterator กับองค์ประกอบแรกของคอนเทนเนอร์.

อ็อบเจ็กต์ iterator ที่สร้างใหม่.
