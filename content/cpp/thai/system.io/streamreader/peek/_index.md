## StreamReader::Peek() เมธอด

อ่านอักขระเดี่ยวหนึ่งตัวจากสตรีมโดยไม่เปลี่ยนตำแหน่งเคอร์เซอร์การอ่านของสตรีม.

```cpp
virtual int System::IO::StreamReader::Peek() override
```

### ค่าที่ส่งคืน

อักขระที่อ่านถูกเข้ารหัสด้วย UTF-16; หากอักขระที่อ่านถูกแทนด้วยสองโค้ดพอยต์ในการเข้ารหัส UTF-16 จะคืนค่าตัวรอสูงเท่านั้น; หากไม่ได้อ่านอักขระใด ๆ จะคืนค่า -1
