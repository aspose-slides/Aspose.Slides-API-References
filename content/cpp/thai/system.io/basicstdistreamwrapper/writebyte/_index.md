## BasicSTDIStreamWrapper::WriteByte(uint8_t) เมธอด

หาก wrapping mode เป็นไบนารี จะเขียนค่า unsigned 8-bit integer ที่ระบุลงใน stream, มิฉะนั้นจะทำการแปลงเป็นชนิด char_type แล้วเขียนผลลัพธ์ลงใน stream. ไม่รองรับ!

```cpp
virtual void System::IO::BasicSTDIStreamWrapper<T, typename>::WriteByte(uint8_t value) override
```

| --- | --- | --- |
| value | **uint8_t** | ค่าที่จะเขียน |
