## FileStream::Flush() เมธอด

ล้างบัฟเฟอร์ของสตรีมนี้และเขียนข้อมูลที่บัฟเฟอร์ทั้งหมดไปยังไฟล์พื้นฐาน.

```cpp
void System::IO::FileStream::Flush() override
```

## FileStream::Flush(bool) เมธอด

ล้างบัฟเฟอร์ของสตรีมนี้และเขียนข้อมูลที่บัฟเฟอร์ทั้งหมดไปยังไฟล์พื้นฐาน. เป็นคำพ้องความหมายของเมธอด [Flush()](./).

```cpp
void System::IO::FileStream::Flush(bool flush_to_disk)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| flush_to_disk | **bool** | True เพื่อทำการล้างบัฟเฟอร์ทั้งหมด, มิฉะนั้น - false. |
