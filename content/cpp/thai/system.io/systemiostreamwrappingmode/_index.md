## SystemIOStreamWrappingMode enum

ระบุโหมดของการดำเนินการ I/O ที่ wrapper จะทำบนสตรีมแบบ [System::IO::Stream](../stream/)-like

```cpp
enum class SystemIOStreamWrappingMode
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Binary | 0 | โหมดที่อนุญาตให้การดำเนินการอินพุตเข้ารหัสไบต์ของสตรีมเป็นข้อมูล char_type และถอดรหัสข้อมูล char_type เป็นไบต์ของสตรีมสำหรับการดำเนินการเอาต์พุต |
| Conversion | 1 | โหมดที่อนุญาตให้การดำเนินการอินพุตแปลงไบต์ของสตรีมจากชนิด **uint8_t** เป็นชนิด char_type และกลับกันสำหรับการดำเนินการเอาต์พุต |
