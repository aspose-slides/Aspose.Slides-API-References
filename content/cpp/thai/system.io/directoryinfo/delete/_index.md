## DirectoryInfo::Delete() เมธอด

```cpp
virtual void System::IO::DirectoryInfo::Delete() override
```

## DirectoryInfo::Delete(bool) เมธอด

ลบไดเรกทอรีที่อ้างอิงโดยเส้นทางที่อ็อบเจกต์ปัจจุบันแทน พารามิเตอร์ระบุว่าควรลบเนื้อหาของไดเรกทอรีแบบเรียกซ้ำหรือไม่ หากไดเรกทอรีไม่ว่าง.

```cpp
void System::IO::DirectoryInfo::Delete(bool recursive)
```
