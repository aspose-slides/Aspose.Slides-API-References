## STDIOStreamWrappingMode enum

ระบุโหมดของการทำงาน I/O ที่ตัวหุ้มจะดำเนินการบนสตรีมแบบคล้าย std::iostreams

```cpp
enum class STDIOStreamWrappingMode
```

### ค่า

| Name | Value | Description |
| --- | --- | --- |
| Binary | 0 | โหมดที่อนุญาตให้การดำเนินการอินพุตถอดรหัสข้อมูลสตรีมของประเภท char_type เป็นไบต์ และเข้ารหัสไบต์เป็นข้อมูลประเภท char_type สำหรับการดำเนินการเอาต์พุต. |
| Conversion | 1 | โหมดที่อนุญาตให้การดำเนินการอินพุตแปลงข้อมูลสตรีมจากประเภท char_type เป็นประเภท **uint8_t** และกลับกันสำหรับการดำเนินการเอาต์พุต. |
