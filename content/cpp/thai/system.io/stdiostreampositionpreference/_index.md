## STDIOStreamPositionPreference enum

กำหนดว่าตำแหน่งใดในสตรีมที่เป็นที่ต้องการเป็นตำแหน่งการอ่านและเขียนร่วมกันเมื่อ `std::basic_iostream` และคลาสลูกจะมีตำแหน่งการอ่านและเขียนที่ต่างกันในเวลาที่สร้างตัวห่อ.

```cpp
enum class STDIOStreamPositionPreference
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Zero | 0 | ตำแหน่ง Zero จะถูกตั้งเป็นตำแหน่งการอ่านและเขียน. |
| ReadPosition | 1 | ตำแหน่ง gptr จะถูกตั้งเป็นตำแหน่งการอ่านและเขียน. |
| WritePosition | 2 | ตำแหน่ง pptr จะถูกตั้งเป็นตำแหน่งการอ่านและเขียน. |
