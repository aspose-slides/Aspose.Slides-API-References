## FileShare enum

ระบุว่าชนิดการเข้าถึงใดที่วัตถุ [FileStream](../filestream/) อื่น ๆ สามารถมีต่อไฟล์ที่กำลังเปิด

```cpp
enum class FileShare
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| None | 0 | ไม่มีการเข้าถึง. |
| Read | 1 | การเข้าถึงแบบอ่านอย่างเดียว. |
| Write | 2 | การเข้าถึงแบบเขียนอย่างเดียว. |
| ReadWrite | 3 | การเข้าถึงแบบอ่านและเขียน. |
| Delete | 4 | ไฟล์สามารถถูกลบได้. |
| Inheritable | 16 | ทำให้ตัวจัดการไฟล์สืบทอดได้โดยกระบวนการลูก. |
