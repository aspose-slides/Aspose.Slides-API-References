## File::Exists(const String\&) เมธอด


กำหนดว่าพาธที่ระบุอ้างอิงไฟล์ที่มีอยู่หรือไม่.

```cpp
static bool System::IO::File::Exists(const String &path)
```


### Arguments

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| path | const [String](../../../system/string/)\& | พาธที่ต้องการทดสอบ |

### ค่าที่ส่งกลับ

True หาก **path** อ้างอิงไฟล์ที่มีอยู่, มิฉะนั้น - false
