## FileSystemInfo::get_Exists() เมธอด

กำหนดว่าหน่วยข้อมูลที่อ้างอิงโดยเส้นทางที่แสดงโดยอ็อบเจกต์ปัจจุบันมีอยู่หรือไม่

```cpp
virtual bool System::IO::FileSystemInfo::get_Exists()=0
```

### ค่าที่ส่งกลับ

True หากหน่วยข้อมูลที่อ้างอิงโดยเส้นทางที่แสดงโดยอ็อบเจกต์ปัจจุบันมีอยู่, มิฉะนั้น - false
