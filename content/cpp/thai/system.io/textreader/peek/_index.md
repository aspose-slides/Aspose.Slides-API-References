## TextReader::Peek() เมธอด

อ่านอักขระหนึ่งตัวจากสตรีมโดยไม่เปลี่ยนตำแหน่งเคอร์เซอร์การอ่านของสตรีม.

```cpp
virtual int System::IO::TextReader::Peek()
```

### ค่าที่ส่งกลับ

อ่านอักขระที่เข้ารหัสด้วย UTF-16; หากอักขระที่อ่านได้ถูกแทนด้วยสองโค้ดพอยต์ใน UTF-16 จะคืนเฉพาะ high surrogate; หากไม่มีอักขระใดถูกอ่านจะคืนค่า -1
