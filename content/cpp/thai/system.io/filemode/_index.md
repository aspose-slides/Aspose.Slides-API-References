## FileMode enum

ระบุวิธีการเปิดไฟล์

```cpp
enum class FileMode
```

### Values

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| CreateNew | 1 | สร้างไฟล์ใหม่ หากไฟล์มีอยู่แล้ว จะเกิดข้อยกเว้น |
| Create | 2 | สร้างไฟล์ใหม่ หากไฟล์มีอยู่แล้ว จะถูกเขียนทับ |
| Open | 3 | เปิดไฟล์ที่มีอยู่ หากไฟล์ไม่มีอยู่ จะเกิดข้อยกเว้น |
| OpenOrCreate | 4 | เปิดไฟล์ที่มีอยู่หรือสร้างไฟล์ใหม่หากไม่มีไฟล์นั้น |
| Truncate | 5 | เปิดไฟล์ที่มีอยู่และตัดให้เป็นไฟล์เปล่า หากไฟล์ไม่มีอยู่ จะเกิดข้อยกเว้น |
| Append | 6 | เปิดไฟล์ที่มีอยู่และเลื่อนไปที่ส่วนท้ายของไฟล์ หรือสร้างไฟล์ใหม่หากไม่มีไฟล์นั้น |
