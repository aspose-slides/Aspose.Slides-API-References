## FileInfo::OpenText() เมธอด


เปิดไฟล์ที่มีอยู่แล้วที่ตำแหน่งที่ระบุโดยเส้นทางที่เป็นตัวแทนของอ็อบเจกต์ปัจจุบันเพื่ออ่านข้อความโดยใช้การเข้ารหัส UTF-8 โดยไม่มีการแชร์

```cpp
StreamReaderPtr System::IO::FileInfo::OpenText()
```


### ค่าที่ส่งกลับ

หนึ่ง pointer แบบ shared ไปยังอ็อบเจกต์ [StreamWriter](../../streamwriter/) ที่เชื่อมโยงกับไฟล์ที่เปิด
