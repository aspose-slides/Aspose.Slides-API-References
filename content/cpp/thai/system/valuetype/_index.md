## ValueType คลาส

Baseclass สำหรับประเภทค่าที่มีการสืบทอด [Object](../object/) ถูกตัดทอนเพื่อประสิทธิภาพ. ประเภทนี้ควรจัดสรรบนสแตกและส่งผ่านไปยังฟังก์ชันโดยค่า หรือโดยการอ้างอิง. ห้ามใช้คลาส [System::SmartPtr](../smartptr/) เพื่อจัดการอ็อบเจ็กต์ของประเภทนี้.

```cpp
class ValueType
```
