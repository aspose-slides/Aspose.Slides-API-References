## Details_Exception::what() const เมธอด

ดำเนินการเมธอด [what()](./) ซึ่งถูกเรียกโดยคลาส [ExceptionWrapper](../../exceptionwrapper/). แม้ว่าแม้คลาสนี้จะไม่ได้สืบทอดจาก std::exception คลาสที่สืบทอดสามารถใช้สมาชิก protected/private เพื่อดำเนินการตรรกะของพวกเขา. การย้ายการดำเนินการเมธอดนี้ไปยัง [ExceptionWrapper](../../exceptionwrapper/) อาจทำให้ตรรกะนั้นเสียหาย.

```cpp
virtual const char * System::Details_Exception::what() const noexcept
```
