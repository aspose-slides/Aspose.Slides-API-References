## System::IsPositiveInfinity(const T\&) ฟังก์ชัน

```cpp
template<typename T> bool System::IsPositiveInfinity(const T &value)
```

### พารามิเตอร์ของเทมเพลต

| พารามิเตอร์ | คำอธิบาย |
| --- | --- |
| T | ชนิดของค่าที่ฟังก์ชันตรวจสอบ |

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| value | const T\& | ค่าที่จะตรวจสอบ |

### ค่าที่คืนกลับ

True if **value** represents positive infinity, otherwise - false
