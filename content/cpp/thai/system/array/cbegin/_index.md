## Array::cbegin() const เมธอด


ส่งคืน iterator ไปยังองค์ประกอบที่มีคุณสมบัติ const ตัวแรกของคอนเทนเนอร์ หากคอนเทนเนอร์ว่าง iterator ที่ส่งคืนจะเท่ากับ [cend()](../cend/).

```cpp
const_iterator System::Array<T>::cbegin() const noexcept
```


### ค่าที่ส่งคืน

iterator ที่ชี้ไปยังองค์ประกอบที่มีคุณสมบัติ const ตัวแรกของคอนเทนเนอร์.
