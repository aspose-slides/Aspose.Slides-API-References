## Array::begin() เมธอด

ส่งคืน iterator ไปยังองค์ประกอบแรกของคอนเทนเนอร์ หากคอนเทนเนอร์ว่าง iterator ที่ส่งคืนจะเท่ากับ [end()](../end/).

```cpp
iterator System::Array<T>::begin() noexcept
```

### ค่าที่คืนกลับ

iterator ที่ชี้ไปยังองค์ประกอบแรกของคอนเทนเนอร์.

## Array::begin() const เมธอด

ส่งคืน iterator ไปยังองค์ประกอบแรกของคอนเทนเนอร์ที่มีการกำหนด const หากคอนเทนเนอร์ว่าง iterator ที่ส่งคืนจะเท่ากับ [end()](../end/).

```cpp
const_iterator System::Array<T>::begin() const noexcept
```

### ค่าที่คืนกลับ

iterator ที่ชี้ไปยังองค์ประกอบแรกของคอนเทนเนอร์ที่มีการกำหนด const.
