## Array::cend() const เมธอด


คืนค่า iterator ไปยังองค์ประกอบที่อยู่ถัดจากองค์ประกอบสุดท้ายของคอนเทนเนอร์. องค์ประกอบนี้ทำหน้าที่เป็นตัวแทน; การพยายามเข้าถึงมันจะทำให้เกิดพฤติกรรมที่ไม่กำหนดค่า.

```cpp
const_iterator System::Array<T>::cend() const noexcept
```


### ค่าที่ส่งกลับ

iterator ที่ชี้ไปยังองค์ประกอบที่มีคุณสมบัติ const อย่างทฤษฎี ซึ่งอยู่หลังองค์ประกอบสุดท้ายของคอนเทนเนอร์.
