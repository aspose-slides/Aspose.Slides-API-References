## Array::end() เมธอด


ส่งคืนอิเทอเรเตอร์เพื่อชี้ไปยังองค์ประกอบที่ตามหลังองค์ประกอบสุดท้ายของคอนเทนเนอร์ ตัวองค์ประกอบนี้ทำหน้าที่เป็นตำแหน่งสำรอง; การพยายามเข้าถึงมันจะทำให้เกิดพฤติกรรมที่ไม่กำหนด

```cpp
iterator System::Array<T>::end() noexcept
```


### ค่าที่ส่งคืน

อิเทอเรเตอร์ที่ชี้ไปยังองค์ประกอบเชิงทฤษฎีที่วางไว้หลังจากองค์ประกอบสุดท้ายของคอนเทนเนอร์

## Array::end() const เมธอด


ส่งคืนอิเทอเรเตอร์เพื่อชี้ไปยังองค์ประกอบที่ตามหลังองค์ประกอบสุดท้ายของคอนเทนเนอร์ที่มีคุณลักษณะ const นี้ ตัวองค์ประกอบนี้ทำหน้าที่เป็นตำแหน่งสำรอง; การพยายามเข้าถึงมันจะทำให้เกิดพฤติกรรมที่ไม่กำหนด

```cpp
const_iterator System::Array<T>::end() const noexcept
```


### ค่าที่ส่งคืน

อิเทอเรเตอร์ที่ชี้ไปยังองค์ประกอบเชิงทฤษฎีที่วางไว้หลังจากองค์ประกอบสุดท้ายของคอนเทนเนอร์ที่มีคุณลักษณะ const
