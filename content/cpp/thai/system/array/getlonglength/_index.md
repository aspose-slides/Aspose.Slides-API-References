## Array::GetLongLength(int) เมธอด

ส่งคืนจำนวนขององค์ประกอบในมิติที่ระบุเป็นจำนวนเต็ม 64 บิต.

```cpp
int64_t System::Array<T>::GetLongLength(int dimension)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| dimension | int | มิติที่ต้องการคืนความยาว |

### ค่าที่ส่งคืน

จำนวนเต็ม 64 บิตที่แสดงจำนวนขององค์ประกอบในมิติที่ระบุ
