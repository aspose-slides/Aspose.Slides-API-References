## Array::crend() const เมธอด

คืนอีเทอเรเตอร์ย้อนกลับไปยังสมาชิกที่อยู่ถัดจากสมาชิกสุดท้ายของคอนเทนเนอร์ที่กลับด้าน. มันสอดคล้องกับสมาชิกที่อยู่ก่อนหน้าสมาชิกแรกของคอนเทนเนอร์ที่ไม่ได้กลับด้าน. สมาชิกนี้ทำหน้าที่เป็นตำแหน่งที่เก็บไว้, การพยายามเข้าถึงมันจะทำให้เกิดพฤติกรรมที่ไม่กำหนด.

```cpp
const_reverse_iterator System::Array<T>::crend() const noexcept
```

### ค่าที่ส่งคืน

อีเทอเรเตอร์ที่ชี้ไปยังสมาชิกที่มีคุณลักษณะ const ตามทฤษฎีและอยู่ก่อนสมาชิกแรกของคอนเทนเนอร์.
