## Array::crbegin() const เมธอด

ส่งกลับ reverse iterator ไปยังอิลเมนต์แรกของคอนเทนเนอร์ที่ได้รับการย้อนกลับ. มันสอดคล้องกับอิลเมนต์สุดท้ายของคอนเทนเนอร์ที่ไม่ได้ย้อนกลับ. หากคอนเทนเนอร์ว่าง iterator ที่ส่งกลับจะเท่ากับ [crend()](../crend/).

```cpp
const_reverse_iterator System::Array<T>::crbegin() const noexcept
```

### ค่าที่คืนกลับ

iterator ที่ชี้ไปยังอิลเมนต์สุดท้ายที่มีคุณสมบัติ const ของคอนเทนเนอร์.
