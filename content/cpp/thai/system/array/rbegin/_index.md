## Array::rbegin() เมธอด

คืนค่าอิเทอเรเตอร์ย้อนกลับไปยังอีลิเมนต์แรกของคอนเทนเนอร์ที่ย้อนกลับแล้ว มันสอดคล้องกับอีลิเมนต์สุดท้ายของคอนเทนเนอร์ที่ไม่ย้อนกลับ หากคอนเทนเนอร์ว่าง อิเทอเรเตอร์ที่คืนจะเท่ากับ [rend()](../rend/).

```cpp
reverse_iterator System::Array<T>::rbegin() noexcept
```

### ค่าที่ส่งคืน

อิเทอเรเตอร์ที่ชี้ไปยังอีลิเมนต์สุดท้ายของคอนเทนเนอร์

## Array::rbegin() const เมธอด

คืนค่าอิเทอเรเตอร์ย้อนกลับไปยังอีลิเมนต์แรกของคอนเทนเนอร์ที่ย้อนกลับแล้ว มันสอดคล้องกับอีลิเมนต์สุดท้ายของคอนเทนเนอร์ที่ไม่ย้อนกลับ หากคอนเทนเนอร์ว่าง อิเทอเรเตอร์ที่คืนจะเท่ากับ [rend()](../rend/).

```cpp
const_reverse_iterator System::Array<T>::rbegin() const noexcept
```

### ค่าที่ส่งคืน

อิเทอเรเตอร์ที่ชี้ไปยังอีลิเมนต์สุดท้ายของคอนเทนเนอร์ที่กำหนดเป็น const.
