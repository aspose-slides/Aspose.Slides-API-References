
### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) โครงสร้างที่อธิบายประเภทที่จะทดสอบอ็อบเจ็กต์ปัจจุบัน |

### ค่าที่คืน

True หากอ็อบเจ็กต์เป็นประเภทที่กำหนดหรือเป็นคลาสย่อยของประเภทนั้น, false ในกรณีอื่น

## หมายเหตุ

ตรวจสอบว่าอ็อบเจ็กต์เป็นอินสแตนซ์ของประเภทที่อธิบายโดย targetType หรือไม่. เป็นการทำงานคล้ายกับตัวดำเนินการ 'is' ของ C#.
