## System::IsTuple(const SharedPtr\<Object\>\&, int32_t) ฟังก์ชัน

ตรวจสอบว่าวัตถุเป็น tuple (implements ITuple interface). ใช้ในการทำงานของ pattern ตามตำแหน่ง.

```cpp
bool System::IsTuple(const SharedPtr<Object> &object, int32_t length)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| object | const [SharedPtr](../sharedptr/)\<[Object](../object/)\>\& | วัตถุที่จะตรวจสอบ. |
| length | **int32_t** | ความยาวของ tuple ที่คาดหวัง |

### ค่าที่ส่งกลับ

วัตถุเป็น tuple และความยาวของมันเท่ากับค่าที่คาดหวัง
