## Enum::Parse(const String\&, bool) เมธอด

```cpp
static E System::Enum<E, Guard>::Parse(const String &str, bool ignoreCase=false)
```

### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| str | const [String](../../string/)\& | [String](../../string/) ที่ถูกตีความว่าเป็นชื่อของค่าคงที่ enum |
| ignoreCase | **bool** | ระบุว่าควรละเว้นตัวพิมพ์ใหญ่/เล็กหรือไม่เมื่อแปลความสตริง |
