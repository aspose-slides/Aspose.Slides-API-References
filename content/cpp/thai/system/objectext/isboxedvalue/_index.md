ตรวจสอบว่าวัตถุเป็นค่าที่บรรจุไว้หรือไม่.

```cpp
static bool System::ObjectExt::IsBoxedValue(const SmartPtr<Object> &obj)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| obj | const [SmartPtr](../../smartptr/)\<[Object](../../object/)\>\& | [Object](../../object/) เพื่อทดสอบว่าค่าเป็นแบบบรรจุหรือไม่. |

### ค่าที่ส่งกลับ

คืนค่า true หาก **obj** เป็นค่าที่บรรจุไว้, false ในกรณีอื่น.
