## TimeZone::IsDaylightSavingTime(DateTime) เมธอด

กำหนดว่าค่าเวลาและวันเวลาที่แสดงโดยอ็อบเจ็กต์ [DateTime](../../datetime/) ที่ระบุอยู่เป็นช่วงเวลาออมแสงของเขตเวลา ที่แสดงโดยอ็อบเจ็กต์ [TimeZone](../) ปัจจุบันหรือไม่

```cpp
virtual bool System::TimeZone::IsDaylightSavingTime(DateTime time)=0
```

### ค่าที่ส่งกลับ

True หากค่าเวลาและวันเวลาที่แสดงโดยอ็อบเจ็กต์ [DateTime](../../datetime/) ที่ระบุอยู่อยู่ในช่วงเวลาออมแสงของเขตเวลาที่แสดงโดยอ็อบเจ็กต์ [TimeZone](../) ปัจจุบัน, มิฉะนั้น - false
