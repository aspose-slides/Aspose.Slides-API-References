## ValueTuple::Equals(SharedPtr\<Object\>) เมธอด

กำหนดว่าตัวอ็อบเจกต์ปัจจุบันและตัวอ็อบเจกต์ที่ระบุเป็นอ็อบเจกต์เดียวกันหรือไม่

```cpp
bool System::ValueTuple<Args>::Equals(SharedPtr<Object> obj)
```

### อาร์กิวเมนท์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| obj | [SharedPtr](../../sharedptr/)\<[Object](../../object/)\> | อ็อบเจกต์ที่ใช้เปรียบเทียบกับอ็อบเจกต์ปัจจุบัน |

### ค่าที่ส่งกลับ

true ถ้าตัวอ็อบเจกต์ปัจจุบันและตัวอ็อบเจกต์ที่ระบุเป็นอ็อบเจกต์เดียวกัน, หากไม่เป็นเช่นนั้นให้เป็น false

## ValueTuple::Equals(const ValueTuple\&) เมธอด




```cpp
bool System::ValueTuple<Args>::Equals(const ValueTuple &other)
```
