## TypeInfo::IsInstanceOfType(const SharedPtr\<Object\>\&) const method

กำหนดว่าอ็อบเจ็กต์ที่ระบุเป็นอินสแตนซ์ของประเภทปัจจุบันหรือไม่.

```cpp
bool System::TypeInfo::IsInstanceOfType(const SharedPtr<Object> &obj) const
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| obj | const [SharedPtr](../../sharedptr/)\<[Object](../../object/)\>\& | อ็อบเจ็กต์ที่จะเปรียบเทียบกับประเภทปัจจุบัน |

### ค่าที่ส่งกลับ

true หากประเภทปัจจุบันอยู่ในลำดับชั้นการสืบทอดของอ็อบเจ็กต์ที่แทนด้วย obj
