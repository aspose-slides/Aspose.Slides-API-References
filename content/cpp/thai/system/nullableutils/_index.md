## NullableUtils คลาส

เป็นตัวแทนของคลาส static C# [System.Nullable](../nullable/) (ไม่มีพารามิเตอร์ชนิด) static class. ไม่สามารถใช้ชื่อเดิมได้เนื่องจากไม่สามารถ overload class templates ใน C++ ได้. รองรับชนิดค่า (value type) ที่สามารถกำหนดค่า null ได้. คลาสนี้ไม่สามารถสืบทอดได้.

```cpp
class NullableUtils
```
