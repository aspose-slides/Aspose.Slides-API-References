## System::GEqual(const ExpressionT\&, const ConstantT\&) ฟังก์ชัน

ดำเนินการแปลรูปแบบสัมพัทธ์ '>='

```cpp
template<class ExpressionT,class ConstantT> bool System::GEqual(const ExpressionT &left, const ConstantT &constant)
```


### พารามิเตอร์เทมเพลต

| Parameter | Description |
| --- | --- |
| ExpressionT | ประเภทของนิพจน์ด้านซ้าย |
| ConstantT | ประเภทของนิพจน์ค่าคงที่ |

### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| left | const ExpressionT\& | นิพจน์ที่จะถูกตรวจสอบ |
| constant | const ConstantT\& | นิพจน์ที่จะถูกเปรียบเทียบกับด้านซ้าย |

### ค่าที่คืน

true หากการตรวจสอบประเภทสำเร็จ, false หากไม่สำเร็จ.
