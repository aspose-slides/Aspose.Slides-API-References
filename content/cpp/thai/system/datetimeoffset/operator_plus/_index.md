## DateTimeOffset::operator+(TimeSpan) const เมธอด

Returns a new instance of [DateTimeOffset](../) คลาส that represents the date and time value that is the sum of the value represented by the current object and the specified time span.

```cpp
DateTimeOffset System::DateTimeOffset::operator+(TimeSpan value) const
```

### Arguments

| พารามิเตอร์ | ประเภท | รายละเอียด |
| --- | --- | --- |
| value | [TimeSpan](../../timespan/) | The time span to add to the value represented by the current object |

### ค่าที่ส่งคืน

A new instance of [DateTimeOffset](../) คลาส that represents the date and time value that is the sum of the value represented by the current object and **value**.
