## DateTimeOffset::EqualsExact(const DateTimeOffset\&) const เมธอด

ตรวจสอบว่าสองวัตถุ [DateTimeOffset](../) แสดงจุดเวลาเดียวกันและมีออฟเซ็ตเดียวกัน.

```cpp
bool System::DateTimeOffset::EqualsExact(const DateTimeOffset &other) const
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| other | const [DateTimeOffset](../)\& | [Object](../../object/) เพื่อเปรียบเทียบ. |

### ค่าที่ส่งกลับ

true หากวัตถุปัจจุบันเท่ากันอย่างแม่นยำกับ **other**, มิฉะนั้น - false.
