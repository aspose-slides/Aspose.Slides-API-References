## SmartPtrInfo::operator bool() const เมธอด

```cpp
System::SmartPtrInfo::operator bool() const
```

### ค่าที่ส่งคืน

True หากอ็อบเจ็กต์ info ชี้ไปยังพอยน์เตอร์และพอยน์เตอร์นี้ไม่เป็นค่า null, false ในกรณีอื่น.
