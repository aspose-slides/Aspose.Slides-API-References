## SmartPtrInfo::operator!() const วิธีการ


ตรวจสอบว่า info object ไม่ได้ชี้ไปยังพอยน์เตอร์ที่ไม่เป็นค่า null.

```cpp
bool System::SmartPtrInfo::operator!() const
```


### ค่าที่ส่งกลับ

False หาก info object ไม่ได้ชี้ไปยังพอยน์เตอร์ใด ๆ หรือหากพอยน์เตอร์ที่อ้างอิงเป็นค่า null, true ในกรณีอื่น.
