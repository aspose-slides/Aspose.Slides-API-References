## IConvertible::ToUInt32(System::SharedPtr\<System::IFormatProvider\>) เมธอด

แปลงค่าของอินสแตนซ์นี้ให้เป็น uint32_teger 32-บิตที่เทียบเท่าโดยใช้ข้อมูลการฟอร์แมตตามวัฒนธรรมที่ระบุ

```cpp
virtual uint32_t System::IConvertible::ToUInt32(System::SharedPtr<System::IFormatProvider> provider)=0
```

### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| provider | [System::SharedPtr](../../sharedptr/)\<[System::IFormatProvider](../../iformatprovider/)\> | การนำไปใช้ของอินเทอร์เฟซ [System::IFormatProvider](../../iformatprovider/) ที่ให้ข้อมูลการฟอร์แมตตามวัฒนธรรม |

### ค่าที่คืน

ค่าจำนวนเต็มบวก 32 บิตที่เทียบเท่ากับค่าของอินสแตนซ์นี้
