## System::static_pointer_cast(SmartPtr\<X\> const\&) ฟังก์ชัน

แปลง smart pointers โดยใช้ static_cast.

```cpp
template<class Y,class X> SmartPtr<Y> System::static_pointer_cast(SmartPtr<X> const &x)
```

### พารามิเตอร์เทมเพลต

| พารามิเตอร์ | คำอธิบาย |
| --- | --- |
| X | ชนิดของวัตถุที่พอยน์เตอร์ชี้ |
| Y | ชนิดของพอยน์เตอร์เป้าหมายที่ชี้ |

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| x | [SmartPtr](../smartptr/)\<X\> const\& | พอยน์เตอร์ต้นฉบับ |

### ค่าที่ส่งกลับ

พอยน์เตอร์หลังการแปลง.
