## SmartPtr::RemoveAliasing() const เมธอด

ลบการอ้างอิง (ที่สร้างโดยตัวสร้างการอ้างอิง) จากพอยน์เตอร์, ทำให้แน่ใจว่ามันจัดการ (if shared) หรือ ติดตาม (if weak) วัตถุเดียวกันที่มันชี้ไป.

```cpp
SmartPtr_ System::SmartPtr<T>::RemoveAliasing() const
```

### ค่าที่ส่งคืน

พอยน์เตอร์ไปยังวัตถุเดียวกันที่พอยน์เตอร์นี้ชี้ไปซึ่งดูแลอายุการใช้งานของวัตถุเดียวกัน.
