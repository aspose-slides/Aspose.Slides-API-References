## SmartPtr::IsWeak() const เมธอด


ตรวจสอบว่าตัวชี้อยู่ในโหมดอ่อนหรือไม่.

```cpp
bool System::SmartPtr<T>::IsWeak() const
```


### ค่าที่ส่งกลับ

True หากตัวชี้อยู่ในโหมดอ่อน, false หากไม่เป็นเช่นนั้น.
