## SmartPtr::Is(const System::TypeInfo\&) const เมธอด

```cpp
bool System::SmartPtr<T>::Is(const System::TypeInfo &target) const
```

### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | ระบุตัวประเภทเป้าหมายที่จะตรวจสอบ |

### ค่าที่ส่งกลับ

True หากการตรวจสอบแบบ `'is'` ของ C# ให้ผลลัพธ์เป็นบวกและ false ในกรณีอื่น
