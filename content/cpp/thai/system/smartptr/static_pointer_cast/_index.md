## SmartPtr::static_pointer_cast() const เมธอด

แปลงพอยน์เตอร์เป็นประเภทที่แตกต่างโดยใช้ static_cast กับอ็อบเจกต์ที่ถูกชี้

```cpp
template<class Y> SmartPtr<Y> System::SmartPtr<T>::static_pointer_cast() const
```

### พารามิเตอร์แม่แบบ

| พารามิเตอร์ | คำอธิบาย |
| --- | --- |
| Y | ประเภทเป้าหมายของอ็อบเจกต์ที่ถูกชี้. |

### ค่าที่ส่งคืน

พอยน์เตอร์ที่มีประเภทเปลี่ยนแปลงแล้วซึ่งอยู่ในโหมด shared เสมอ
