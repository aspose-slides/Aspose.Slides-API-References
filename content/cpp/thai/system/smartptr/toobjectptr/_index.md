## SmartPtr::ToObjectPtr() const เมธอด

แปลงประเภทพอยน์เตอร์ใด ๆ ให้เป็นพอยน์เตอร์ไปยัง [Object](../../object/). ไม่จำเป็นต้องให้ประเภท Pointee_ สมบูรณ์.

```cpp
SmartPtr<Object> System::SmartPtr<T>::ToObjectPtr() const
```

### ค่าที่ส่งคืน

พอยน์เตอร์ดิบไปยังอ็อบเจ็กต์ที่อ้างอิง (ถ้ามี) หรือ nullptr.
