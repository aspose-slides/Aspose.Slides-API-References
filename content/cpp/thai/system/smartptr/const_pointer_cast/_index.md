## SmartPtr::const_pointer_cast() const เมธอด

แปลงตัวชี้เป็นชนิดอื่นโดยใช้ const_cast กับอ็อบเจกต์ที่ชี้ไป.

```cpp
template<class Y> SmartPtr<Y> System::SmartPtr<T>::const_pointer_cast() const
```

### พารามิเตอร์เทมแพลต

| พารามิเตอร์ | คำอธิบาย |
| --- | --- |
| Y | ชนิดเป้าหมายของอ็อบเจกต์ที่ชี้ไป |

### ค่าที่คืน

ตัวชี้ของประเภทที่เปลี่ยนแปลงซึ่งอยู่ในโหมดแชร์เสมอ
