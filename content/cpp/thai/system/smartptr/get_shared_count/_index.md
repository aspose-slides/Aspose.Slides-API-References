## SmartPtr::get_shared_count() const เมธอด

รับจำนวนตัวชี้แบบแชร์ที่มีอยู่ต่อวัตถุที่อ้างถึงรวมถึงตัวปัจจุบันด้วย. ตรวจสอบว่าตัวชี้ปัจจุบันอยู่ในโหมดแชร์

```cpp
int System::SmartPtr<T>::get_shared_count() const
```

### ค่าที่คืน

จำนวนตัวชี้แบบแชร์ที่มีอยู่ต่อวัตถุที่อ้างถึง, หากมี. หากตัวชี้เป็น null, คืนค่า 0.
