## SmartPtr::IsAliasingPtr() const เมธอด

ตรวจสอบว่าตัวชี้ชี้ไปยังออบเจกต์อื่นที่ไม่ใช่ออบเจกต์ที่เป็นเจ้าของ (สร้างโดยคอนสตรัคเตอร์ aliasing)

```cpp
bool System::SmartPtr<T>::IsAliasingPtr() const
```

### ค่าที่ส่งกลับ

True ถ้าตัวชี้มีความแตกต่างระหว่างออบเจกต์ที่ชี้และออบเจกต์ที่เป็นเจ้าของ, false มิฉะนั้น.
