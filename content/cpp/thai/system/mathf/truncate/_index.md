## MathF::Truncate(float) วิธีการ

คืนค่า float-precision floating point value ที่มีส่วนจำนวนเต็มเท่ากับของค่าที่ระบุ โดยละทิ้งตำแหน่งเศษทั้งหมด

```cpp
static float System::MathF::Truncate(float x)
```

### Arguments

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| x | **float** | จำนวนทศนิยม |

### ค่าที่คืน

ค่า float-precision floating point value ที่ส่วนจำนวนเต็มเท่ากับของค่าที่ระบุและตำแหน่งเศษทั้งหมดเป็น 0.
