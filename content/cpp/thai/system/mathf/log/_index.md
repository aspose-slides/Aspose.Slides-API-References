## MathF::Log(float) เมธอด

คืนค่าลอการิทึมธรรมชาติของค่าที่ระบุ.

```cpp
static float System::MathF::Log(float x)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| x | **float** | ค่าจุดลอยตัวความแม่นยำแบบ float |

### ค่าที่ส่งกลับ

ลอการิทึมธรรมชาติของ **d**

## MathF::Log(float, float) เมธอด

คืนค่าลอการิทึมของค่าที่ระบุในฐานที่ระบุ.

```cpp
static float System::MathF::Log(float a, float newBase)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| a | **float** | ค่าจุดลอยตัวความแม่นยำแบบ float |
| newBase | **float** | ฐานของลอการิทึม |

### ค่าที่ส่งกลับ

ลอการิทึมของ **a** ในฐาน **newBase**
