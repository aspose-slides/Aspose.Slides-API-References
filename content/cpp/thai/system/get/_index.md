## System::Get(const SharedPtr\<Object\>\&) ฟังก์ชัน

ฟังก์ชันเพื่อดึงองค์ประกอบที่ N จากทูเพิลที่ระบุ. การกำหนดค่าเพิ่มเติมสำหรับวัตถุฐาน.

```cpp
template<std::size_t> auto System::Get(const SharedPtr<Object> &object)
```

### พารามิเตอร์แม่แบบ

| พารามิเตอร์ | คำอธิบาย |
| --- | --- |
| N | ดัชนีขององค์ประกอบ. |

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| object | const [SharedPtr](../sharedptr/)\<[Object](../object/)\>\& | วัตถุที่จะตรวจสอบ. |

### ค่าที่คืนกลับ

ค่าขององค์ประกอบที่ N ของทูเพิลที่แปลงเป็นวัตถุ.

## System::Get(T\&, const Index\&) ฟังก์ชัน

การทำงานสำหรับนิพจน์ collection[index].

```cpp
template<typename T> auto & System::Get(T &collection, const Index &index)
```

### พารามิเตอร์แม่แบบ

| พารามิเตอร์ | คำอธิบาย |
| --- | --- |
| T | ชนิดของคอลเลกชัน. |

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| collection | T\& | วัตถุคอลเลกชัน. |
| index | const [Index](../index/)\& | ดัชนีขององค์ประกอบชนิด [System.Index](../index/). |

### ค่าที่คืนกลับ

องค์ประกอบคอลเลกชันที่ออฟเซ็ตที่คำนวณได้.

## System::Get(T\&, const Range\&) ฟังก์ชัน

คืนส่วนหนึ่งของคอลเลกชันที่ระบุโดยช่วงที่ให้มา.

```cpp
template<typename T> auto System::Get(T &collection, const Range &range)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| collection | T\& | คอลเลกชันที่ต้องการตัด. |
| range | const [Range](../range/)\& | ช่วงที่กำหนดขอบเขตของการตัด. |

### ค่าที่คืนกลับ

มุมมองหรือส่วนหนึ่งของคอลเลกชันจากออฟเซ็ตเริ่มต้นและความยาวที่คำนวณได้.
