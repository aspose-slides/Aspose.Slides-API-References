## Version::Equals(const Version\&) const เมธอด

กำหนดว่าตัวเลขรุ่นที่แทนโดยออบเจ็กต์ปัจจุบันและออบเจ็กต์ที่ระบุเป็นค่าเท่ากันหรือไม่.

```cpp
bool System::Version::Equals(const Version &ver) const
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | รายละเอียด |
| --- | --- | --- |
| ver | const [Version](../)\& | [Version](../) อ็อบเจ็กต์เพื่อเปรียบเทียบกับออบเจ็กต์ปัจจุบัน |

### ค่าที่ส่งคืน

True หากตัวเลขรุ่นที่แทนโดยออบเจ็กต์ปัจจุบันและออบเจ็กต์ที่ระบุเท่ากัน, มิฉะนั้น - false
