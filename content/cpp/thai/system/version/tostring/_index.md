## Version::ToString() const เมธอด

คืนค่าการแสดงผลเป็น string ของหมายเลขเวอร์ชันที่แทนโดยอ็อบเจกต์ปัจจุบัน.

```cpp
String System::Version::ToString() const
```

## Version::ToString(int) const เมธอด

คืนค่าการแสดงผลเป็น string ของจำนวนส่วนที่ระบุของหมายเลขเวอร์ชันที่แทนโดยอ็อบเจกต์ปัจจุบัน.

```cpp
String System::Version::ToString(int fieldCount) const
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| fieldCount | int | จำนวนส่วนของหมายเลขเวอร์ชันที่ต้องการรวมในการแสดงผลเป็น string ที่ส่งคืน |
