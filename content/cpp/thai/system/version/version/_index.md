## Version::Version(int, int, int, int) คอนสตรัคเตอร์

สร้างอินสแตนซ์ที่เป็นตัวแทนของค่าตัวเลขเวอร์ชัน major, minor, build และ revision ที่ระบุ

```cpp
System::Version::Version(int major, int minor, int build, int revision)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| major | int | หมายเลขเวอร์ชันหลัก |
| minor | int | หมายเลขเวอร์ชันรอง |
| build | int | หมายเลขการสร้าง |
| revision | int | หมายเลขการแก้ไข |
