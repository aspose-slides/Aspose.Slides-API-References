## System::IsNaN(const T\&) ฟังก์ชัน


กำหนดว่าค่าที่ระบุเป็นค่า Not-A-Number หรือไม่

```cpp
template<typename T> bool System::IsNaN(const T &value)
```


### พารามิเตอร์แม่แบบ

| พารามิเตอร์ | คำอธิบาย |
| --- | --- |
| T | ประเภทของค่าที่ฟังก์ชันตรวจสอบ |

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| value | const T\& | ค่าที่จะตรวจสอบ |

### ค่าที่ส่งคืน

คืนค่า true หาก **value** เป็นค่า NaN, มิฉะนั้น - false
