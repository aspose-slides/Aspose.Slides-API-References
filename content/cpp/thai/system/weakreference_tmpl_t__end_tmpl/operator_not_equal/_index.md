## WeakReference< T >::operator!=(std::nullptr_t) const เมธอด

ตรวจสอบว่าอ็อบเจ็กต์ที่อ้างอิงไม่เป็น null.

```cpp
bool System::WeakReference<T>::operator!=(std::nullptr_t) const
```


### ค่าที่ส่งคืน

True หากอ็อบเจ็กต์ที่อ้างอิงไม่เป็น null, false อย่างอื่น

## WeakReference< T >::operator!=(const WeakReference\<T\>\&) const เมธอด


เปรียบเทียบอ็อบเจ็กต์ที่อ้างอิงกับอินสแตนซ์อื่นของคลาส WeakReference

```cpp
bool System::WeakReference<T>::operator!=(const WeakReference<T> &other) const
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| other | const [WeakReference](../weakreference/)\<T\>\& | [Object](../../object/) เปรียบเทียบกับ. |

### ค่าที่ส่งคืน

True หากอ็อบเจ็กต์ที่เปรียบเทียบอ้างอิงอ็อบเจ็กต์ที่แตกต่างกัน, false หากอ็อบเจ็กต์เหมือนกัน.
