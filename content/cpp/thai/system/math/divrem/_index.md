## Math::DivRem(int, int, int\&) เมธอด

คำนวณผลหารของจำนวนเต็ม 32-bit สองค่าและเศษส่วน.

```cpp
static int System::Math::DivRem(int a, int b, int &result)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | รายละเอียด |
| --- | --- | --- |
| a | int | ตัวตั้ง |
| b | int | ตัวหาร |
| result | int\& | พารามิเตอร์ผลลัพธ์ที่บรรจุเศษที่ได้จากการหาร **a** ด้วย **b** |

### ค่าที่คืนกลับ

การอ้างอิงของ **a** และ **b**
