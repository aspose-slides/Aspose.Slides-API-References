## Math::Log(double) เมธอด

Returns the natural logarithm of the specified value.

```cpp
static double System::Math::Log(double d)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| d | **double** | ค่าตัวเลขแบบ double-precision |

### ค่าที่ส่งคืน

ลอการิทึมธรรมชาติของ **d**

## Math::Log(double, double) เมธอด

Returns the logarithm of the specified value in the specified base.

```cpp
static double System::Math::Log(double a, double newBase)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| a | **double** | ค่าตัวเลขแบบ double-precision |
| newBase | **double** | ฐานของลอการิทึม |

### ค่าที่ส่งคืน

ลอการิทึมของ **a** ในฐาน **newBase**
