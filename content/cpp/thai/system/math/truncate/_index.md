## Math::Truncate(const Decimal\&) เมธอด

คืนค่าอ็อบเจกต์ [Decimal](../../decimal/) ที่แสดงค่าซึ่งส่วนจำนวนเต็มเท่ากับส่วนจำนวนเต็มของค่าที่แสดงโดยอ็อบเจกต์ [Decimal](../../decimal/) ที่ระบุโดยละทิ้งตำแหน่งเศษส่วนทั้งหมด

```cpp
static Decimal System::Math::Truncate(const Decimal &d)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| d | const [Decimal](../../decimal/)\& | ตัวเลขทศนิยม |

### ค่าที่ส่งคืน

อ็อบเจกต์ [Decimal](../../decimal/) ที่แสดงค่าทศนิยมซึ่งส่วนจำนวนเต็มเท่ากับของค่าที่ระบุและตำแหน่งเศษส่วนทั้งหมดเป็น 0

## Math::Truncate(double) เมธอด

คืนค่าจุดลอยความละเอียดคู่ที่ส่วนจำนวนเต็มเท่ากับของค่าที่ระบุโดยละทิ้งตำแหน่งเศษส่วนทั้งหมด

```cpp
static double System::Math::Truncate(double d)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| d | **double** | ตัวเลขทศนิยม |

### ค่าที่ส่งคืน

ค่าจุดลอยความละเอียดคู่ที่ส่วนจำนวนเต็มเท่ากับของค่าที่ระบุและตำแหน่งเศษส่วนทั้งหมดเป็น 0
