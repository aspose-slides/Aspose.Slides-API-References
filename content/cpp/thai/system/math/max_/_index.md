## Math::Max_(float, float) method

คืนค่าตัวเลขแบบ floating point ความแม่นยำเดี่ยวที่ใหญ่ที่สุดจากสองค่าที่ระบุ

```cpp
float System::Math::Max_(float val1, float val2)
```

### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| val1 | **float** | ตัวเปรียบเทียบแรก |
| val2 | **float** | ตัวเปรียบเทียบที่สอง |

### ค่าที่ส่งกลับ

ค่าที่ใหญ่ที่สุดระหว่าง **val1** และ **val2**; หรือ NaN หากหนึ่งในตัวดำเนินการเป็น NaN
