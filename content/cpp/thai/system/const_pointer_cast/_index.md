## System::const_pointer_cast(SmartPtr\<X\> const\&) ฟังก์ชัน

ทำการแคสต์พอยน์เตอร์อัจฉริยะโดยใช้ const_cast.

```cpp
template<class Y,class X> SmartPtr<Y> System::const_pointer_cast(SmartPtr<X> const &x)
```

### พารามิเตอร์แม่แบบ

| Parameter | Description |
| --- | --- |
| X | ชนิดของพอยน์เตอร์ต้นแบบที่ชี้ |
| Y | ชนิดของพอยน์เตอร์เป้าหมายที่ชี้ |

### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| x | [SmartPtr](../smartptr/)\<X\> const\& | พอยน์เตอร์ต้นแบบ |

### ค่าที่คืน

พอยน์เตอร์หลังการแคสต์.
