## IAsyncResult::get_IsCompleted() เมธอด

```cpp
virtual bool System::IAsyncResult::get_IsCompleted()=0
```


### ค่าที่ส่งคืน

True หากการดำเนินงานแบบอะซิงโครนัสได้เสร็จสมบูรณ์, มิฉะนั้น - false
