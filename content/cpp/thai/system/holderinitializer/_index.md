## HolderInitializer struct

คลาสนี้ใช้เพื่อให้ได้อ้างอิงที่คงอยู่กับอินสแตนซ์ของอ็อบเจกต์ ไม่ว่าจะเป็น lvalue หรือ rvalue ก็ตาม เพื่อให้ได้อ้างอิงดังกล่าว ให้ใช้เมธอด `HoldIfTemporary` ซึ่งมีโอเวอร์โหลดสามแบบ สองแบบรับ rvalue เป็นพารามิเตอร์และคืนอ้างอิงกลับไป ส่วนแบบที่สามรับ lvalue เป็นพารามิเตอร์ ทำการคัดลอกเป็นพอยเตอร์ แล้วคืนอ้างอิงไปยังสำเนานั้น นอกจากนี้คลาสยังมีเมธอด `Hold` เพื่อเก็บค่าที่ส่งเข้ามาโดยไม่มีเงื่อนไข (ใช้เพื่อคัดลอกค่าของตัวแปรภายในสแตกหรืออ้างอิงลูกของมัน)

```cpp
template<typename T,bool>class HolderInitializer
```

### พารามิเตอร์เทมเพลต

| พารามิเตอร์ | คำอธิบาย |
| --- | --- |
| T | ประเภทของอ็อบเจกต์ที่จะเก็บไว้ |
| R | true หาก T เป็นประเภทอ้างอิง (การพิเศษ[SmartPtr](../smartptr/) หรือประเภท[System::String](../string/)) และต้องการการเก็บอ้างอิงชั่วคราว, false ในกรณีอื่น |
