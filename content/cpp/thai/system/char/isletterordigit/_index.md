## Char::IsLetterOrDigit(const char_t *, int) วิธีการ


กำหนดว่าตัวอักษรที่ตำแหน่งที่ระบุในบัฟเฟอร์อักขระที่กำหนดนั้นจัดเป็นอักขระ Unicode ที่เป็นตัวอักษรหรือเป็นตัวเลขฐานสิบหรือไม่

```cpp
static bool System::Char::IsLetterOrDigit(const char_t *str, int idx)
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| str | const char_t * | ตัวชี้ไปยังจุดเริ่มต้นของบัฟเฟอร์อักขระ |
| idx | int | ดัชนีเริ่มต้นที่ 0 ในบัฟเฟอร์ที่ระบุของอักขระที่จะทดสอบ |

### ค่าที่ส่งกลับ

True หากอักขระที่ตำแหน่งที่ระบุเป็นอักขระ Unicode ที่เป็นตัวอักษรหรือเลขฐานสิบ, มิฉะนั้น - false

## Char::IsLetterOrDigit(char_t) วิธีการ


กำหนดว่าตัวอักษรที่ระบุเป็นอักขระ Unicode ที่เป็นตัวอักษรหรือเป็นตัวเลขฐานสิบหรือไม่

```cpp
static bool System::Char::IsLetterOrDigit(char_t c)
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| c | char_t | ตัวอักษรที่จะทดสอบ |

### ค่าที่ส่งกลับ

True หากตัวอักษรที่ระบุเป็นอักขระ Unicode ที่เป็นตัวอักษรหรือเลขฐานสิบ, มิฉะนั้น - false
