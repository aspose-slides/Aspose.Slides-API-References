## Char::IsSymbol(const char_t *, int) เมธอด

กำหนดว่าตัวอักษรที่ตำแหน่งที่ระบุในบัฟเฟอร์ตัวอักษรที่กำหนดเป็นอักขระสัญลักษณ์หรือไม่

```cpp
static bool System::Char::IsSymbol(const char_t *str, int idx)
```

### Arguments

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| str | const char_t * | Pointer to the beginning of the character buffer |
| idx | int | A zero-based index in the specified buffer of the character to test |

### Return Value

true หากตัวอักษรที่ตำแหน่งที่ระบุเป็นอักขระสัญลักษณ์, ในกรณีอื่น - false

## Char::IsSymbol(char_t) เมธอด

กำหนดว่าตัวอักษรที่ระบุเป็นอักขระสัญลักษณ์หรือไม่

```cpp
static bool System::Char::IsSymbol(char_t c)
```

### Arguments

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| c | char_t | The character to test |

### Return Value

true หากตัวอักษรที่ระบุเป็นอักขระสัญลักษณ์, ในกรณีอื่น - false
