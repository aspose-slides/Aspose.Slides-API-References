## Char::IsUpper(const String\&, int) เมธอด


กำหนดว่าตัวอักษรที่ตำแหน่งที่ระบุในสตริงที่ระบุเป็นตัวอักษรพิมพ์ใหญ่หรือไม่

```cpp
static bool System::Char::IsUpper(const String &str, int idx)
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| str | const [String](../../string/)\& | สตริงที่มีอักขระ |
| idx | int | ดัชนีเริ่มจากศูนย์ในสตริงที่ระบุเพื่อทดสอบ |

### ค่าที่คืน

True หากตัวอักษรที่ตำแหน่งที่ระบุเป็นตัวอักษรพิมพ์ใหญ่, มิฉะนั้น - false

## Char::IsUpper(const char_t *, int) เมธอด


กำหนดว่าตัวอักษรที่ตำแหน่งที่ระบุในบัฟเฟอร์อักขระที่ระบุเป็นตัวอักษรพิมพ์ใหญ่หรือไม่

```cpp
static bool System::Char::IsUpper(const char_t *str, int idx)
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| str | const char_t * | ตัวชี้ไปยังจุดเริ่มต้นของบัฟเฟอร์อักขระ |
| idx | int | ดัชนีเริ่มจากศูนย์ในบัฟเฟอร์ที่ระบุเพื่อทดสอบอักขระ |

### ค่าที่คืน

True หากตัวอักษรที่ตำแหน่งที่ระบุเป็นตัวอักษรพิมพ์ใหญ่, มิฉะนั้น - false

## Char::IsUpper(char_t) เมธอด


กำหนดว่าตัวอักษรที่ระบุเป็นตัวอักษรพิมพ์ใหญ่หรือไม่

```cpp
static bool System::Char::IsUpper(char_t c)
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| c | char_t | อักขระที่ต้องการทดสอบ |

### ค่าที่คืน

True หากตัวอักษรที่ระบุเป็นตัวอักษรพิมพ์ใหญ่, มิฉะนั้น - false
