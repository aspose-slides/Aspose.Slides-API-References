## Char::IsPunctuation(const char_t *, int) เมธอด

กำหนดว่ามีอักขระที่ตำแหน่งที่ระบุในบัฟเฟอร์อักขระที่ระบุเป็นอักขระเครื่องหมายวรรคตอนหรือไม่

```cpp
static bool System::Char::IsPunctuation(const char_t *str, int idx)
```

### อากิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| str | const char_t * | ตัวชี้ไปยังจุดเริ่มต้นของบัฟเฟอร์อักขระ |
| idx | int | ดัชนีเริ่มจากศูนย์ในบัฟเฟอร์ที่ระบุของอักขระที่ต้องการทดสอบ |

### ค่าที่คืน

จริง หากอักขระที่ตำแหน่งที่ระบุเป็นอักขระเครื่องหมายวรรคตอน, มิฉะนั้น - เท็จ

## Char::IsPunctuation(char_t) เมธอด

กำหนดว่ามีอักขระที่ระบุเป็นอักขระเครื่องหมายวรรคตอนหรือไม่

```cpp
static bool System::Char::IsPunctuation(char_t c)
```

### อากิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| c | char_t | อักขระที่ต้องการทดสอบ |

### ค่าที่คืน

จริง หากอักขระที่ระบุเป็นอักขระเครื่องหมายวรรคตอน, มิฉะนั้น - เท็จ
