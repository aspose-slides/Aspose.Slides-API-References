## Char::IsWhiteSpace(const char_t *, int) method

กำหนดว่าตัวอักษรที่ตำแหน่งที่ระบุในบัฟเฟอร์อักขระที่ระบุดังกล่าวเป็นอักขระช่องว่างหรือไม่

```cpp
static bool System::Char::IsWhiteSpace(const char_t *str, int idx)
```

### Arguments

| Parameter | Type | Description |
| --- | --- | --- |
| str | const char_t * | ตัวชี้ไปยังจุดเริ่มต้นของบัฟเฟอร์อักขระ |
| idx | int | ดัชนีเริ่มต้นที่ 0 ในบัฟเฟอร์ที่ระบุของอักขระที่ต้องตรวจสอบ |

### Return Value

True หากอักขระที่ตำแหน่งที่ระบุเป็นอักขระช่องว่าง มิฉะนั้น - false
