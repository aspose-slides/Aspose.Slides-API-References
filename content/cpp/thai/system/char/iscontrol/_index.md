## Char::IsControl(const char_t *, int) เมธอด

กำหนดว่าที่อักขระในตำแหน่งที่ระบุในบัฟเฟอร์อักขระที่กำหนดถูกจัดประเภทเป็นอักขระควบคุม Unicode หรือไม่

```cpp
static bool System::Char::IsControl(const char_t *str, int idx)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| str | const char_t * | ตัวชี้ไปยังจุดเริ่มต้นของบัฟเฟอร์อักขระ |
| idx | int | ดัชนีเริ่มจากศูนย์ในบัฟเฟอร์ที่ระบุของอักขระที่ต้องการทดสอบ |

### ค่าที่คืนกลับ

คืนค่า true หากอักขระที่ตำแหน่งกำหนดเป็นอักขระควบคุม Unicode, ไม่เช่นนั้น - false

## Char::IsControl(char_t) เมธอด

กำหนดว่าที่อักขระที่ระบุถูกจัดประเภทเป็นอักขระควบคุม Unicode หรือไม่

```cpp
static bool System::Char::IsControl(char_t c)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| c | char_t | อักขระที่ต้องการทดสอบ |

### ค่าที่คืนกลับ

คืนค่า true หากอักขระที่ระบุเป็นอักขระควบคุม Unicode, ไม่เช่นนั้น - false
