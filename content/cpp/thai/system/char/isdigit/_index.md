## Char::IsDigit(const char_t *, int) เมธอด

กำหนดว่าตัวอักษรที่ตำแหน่งที่ระบุในบัฟเฟอร์อักขระที่กำหนดนั้นเป็นเลขฐานสิบหรือไม่

```cpp
static bool System::Char::IsDigit(const char_t *str, int idx)
```

### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| str | const char_t * | ตัวชี้ไปยังตำแหน่งเริ่มต้นของบัฟเฟอร์อักขระ |
| idx | int | ดัชนีเริ่มต้นที่ศูนย์ในบัฟเฟอร์ที่ระบุของตัวอักษรที่ต้องทดสอบ |

### ค่าที่ส่งกลับ

จริง หากตัวอักษรที่ตำแหน่งที่ระบุเป็นเลขฐานสิบ, ไม่เช่นนั้น - เท็จ
