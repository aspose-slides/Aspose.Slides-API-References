## Char::IsSeparator(const char_t *, int) เมธอด


กำหนดว่าตัวอักษรที่ตำแหน่งที่ระบุในบัฟเฟอร์ตัวอักษรที่กำหนดถูกจัดประเภทเป็นอักขระตัวแบ่งหรือไม่

```cpp
static bool System::Char::IsSeparator(const char_t *str, int idx)
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| str | const char_t * | ตัวชี้ไปยังจุดเริ่มต้นของบัฟเฟอร์ตัวอักษร |
| idx | int | ดัชนีฐานศูนย์ในบัฟเฟอร์ที่ระบุตัวอักษรที่จะทดสอบ |

### ค่าที่ส่งคืน

จริงถ้าตัวอักษรที่ตำแหน่งที่ระบุเป็นอักขระตัวแบ่ง, ในกรณีอื่น - เท็จ

## Char::IsSeparator(char_t) เมธอด


กำหนดว่าตัวอักษรที่ระบุถูกจัดประเภทเป็นอักขระตัวแบ่งหรือไม่

```cpp
static bool System::Char::IsSeparator(char_t c)
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| c | char_t | ตัวอักษรที่จะทดสอบ |

### ค่าที่ส่งคืน

จริงถ้าตัวอักษรที่ระบุเป็นอักขระตัวแบ่ง, ในกรณีอื่น - เท็จ
