## Char::IsNumber(const char_t *, int) เมธอด


กำหนดว่าตัวอักษรที่ตำแหน่งที่ระบุในบัฟเฟอร์อักขระที่ระบุถูกจัดประเภทเป็นตัวเลขหรือไม่.

```cpp
static bool System::Char::IsNumber(const char_t *str, int idx)
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| str | const char_t * | ตัวชี้ไปยังจุดเริ่มต้นของบัฟเฟอร์อักขระ |
| idx | int | ดัชนีเริ่มจากศูนย์ในบัฟเฟอร์ที่ระบุของตัวอักษรที่จะทดสอบ |

### ค่าที่คืน

true ถ้าตัวอักษรที่ตำแหน่งที่ระบุเป็นตัวเลข, มิฉะนั้น - false

## Char::IsNumber(char_t) เมธอด


กำหนดว่าตัวอักษรที่ระบุถูกจัดประเภทเป็นตัวเลขหรือไม่.

```cpp
static bool System::Char::IsNumber(char_t c)
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| c | char_t | ตัวอักษรที่จะทดสอบ |

### ค่าที่คืน

true ถ้าตัวอักษรที่ระบุเป็นตัวเลข, มิฉะนั้น - false
