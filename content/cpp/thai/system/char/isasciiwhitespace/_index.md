## Char::IsAsciiWhiteSpace(char_t) เมธอด

กำหนดว่าตัวอักษรที่ระบุจัดเป็นอักขระเว้นวรรค ASCII หรือไม่

```cpp
static constexpr bool System::Char::IsAsciiWhiteSpace(char_t c)
```

### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| c | char_t | ตัวอักษรที่ต้องการทดสอบ |

### ค่าที่คืนกลับ

คืนค่า true หากตัวอักษรที่ระบุเป็นอักขระเว้นวรรค ASCII, มิฉะนั้น - false
