## Char::IsLower(const char_t *, int) method

กำหนดว่าตัวอักษรที่ตำแหน่งที่ระบุในบัฟเฟอร์อักขระที่ระบุเป็นอักษรตัวพิมพ์เล็กหรือไม่

```cpp
static bool System::Char::IsLower(const char_t *str, int idx)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| str | const char_t * | Pointer to the beginning of the character buffer |
| idx | int | A zero-based index in the specified buffer of the character to test |

### ค่าที่คืนกลับ

True หากอักขระที่ตำแหน่งที่ระบุเป็นอักษรตัวพิมพ์เล็ก, หรือ - false

## Char::IsLower(char_t) method

กำหนดว่าตัวอักษรที่ระบุเป็นอักษรตัวพิมพ์เล็กหรือไม่

```cpp
static bool System::Char::IsLower(char_t c)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| c | char_t | ตัวอักษรที่ต้องการทดสอบ |

### ค่าที่คืนกลับ

True หากอักขระที่ตำแหน่งที่ระบุเป็นอักษรตัวพิมพ์เล็ก, หรือ - false

## Char::IsLower(const String\&, int) method

กำหนดว่าตัวอักษรที่ตำแหน่งที่ระบุในสตริงที่ระบุเป็นอักษรตัวพิมพ์เล็กหรือไม่

```cpp
static bool System::Char::IsLower(const String &str, int idx)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| str | const [String](../../string/)\& | สตริง |
| idx | int | ดัชนีเริ่มจากศูนย์ในสตริงที่ระบุเพื่อทดสอบ |

### ค่าที่คืนกลับ

True หากอักขระที่ตำแหน่งที่ระบุเป็นอักษรตัวพิมพ์เล็ก, หรือ - false
