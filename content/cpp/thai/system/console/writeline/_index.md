## Console::WriteLine() เมธอด

ส่งออกตัวกำหนดบรรทัดปัจจุบันไปยังสตรีมเอาต์พุตมาตรฐาน

```cpp
static void System::Console::WriteLine()
```

## Console::WriteLine(const SharedPtr\<T\>\&) เมธอด

ส่งออกการแสดงผลเป็นสตริงของอ็อบเจกต์ที่ระบุ พร้อมด้วยตัวกำหนดบรรทัดปัจจุบันไปยังสตรีมเอาต์พุตมาตรฐาน

```cpp
template<class T> static void System::Console::WriteLine(const SharedPtr<T> &object)
```

### พารามิเตอร์เทมเพลต

| พารามิเตอร์ | คำอธิบาย |
| --- | --- |
| T | ประเภทของอ็อบเจกต์ที่ต้องการส่งออก |

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| object | const [SharedPtr](../../sharedptr/)\<T\>\& | [Object](../../object/) เพื่อส่งออก |
