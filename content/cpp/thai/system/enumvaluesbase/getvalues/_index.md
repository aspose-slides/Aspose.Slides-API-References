## EnumValuesBase::GetValues(const TypeInfo\&) เมธอด

ส่งกลับอาร์เรย์ที่มีค่าทั้งหมดของประเภท enumeration ที่ระบุ

```cpp
static ArrayPtr<int64_t> System::EnumValuesBase::GetValues(const TypeInfo &type)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| type | const [TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) วัตถุที่แทนประเภทของ enumeration ที่ค่าจะถูกส่งคืน |

### ค่าที่ส่งกลับ

อาร์เรย์ที่มีค่าของคอนสแตนต์ enumeration ทั้งหมดของประเภท enumeration ที่ระบุโดย **type**.
