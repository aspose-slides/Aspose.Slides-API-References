## System::operator/(const T\&, const Decimal\&) ฟังก์ชัน

ส่งกลับอินสแตนซ์ใหม่ของคลาส [Decimal](../decimal/) ที่แสดงค่าเป็นผลจากการหารค่าที่ระบุกับค่าที่แสดงโดยวัตถุ [Decimal](../decimal/) ที่ระบุ.

```cpp
template<typename T,typename _> Decimal System::operator/(const T &x, const Decimal &d)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| x | const T\& | ค่าที่ต้องหาร |
| d | const [Decimal](../decimal/)\& | วัตถุ [Decimal](../decimal/) ที่เป็นตัวแทนของตัวหาร |

### ค่าที่ส่งคืน

อินสแตนซ์ใหม่ของคลาส [Decimal](../decimal/) ที่แสดงค่าซึ่งเป็นผลจากการหาร **x** ด้วยค่าที่แสดงโดย **d**.
