## System::Set(ExpressionT\&, const ExpressionT\&) ฟังก์ชัน

ดำเนินการแปลรูปแบบ 'var'

```cpp
template<class ExpressionT> bool System::Set(ExpressionT &var, const ExpressionT &value)
```

### พารามิเตอร์แม่แบบ

| พารามิเตอร์ | คำอธิบาย |
| --- | --- |
| ExpressionT | ชนิดของตัวแปร. |

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| var | ExpressionT\& | อ้างอิงไปยังตัวแปรที่ต้องการกำหนดค่า. |
| value | const ExpressionT\& | ค่าที่จะกำหนดให้กับตัวแปร. |

### ค่าที่คืนกลับ

เสมอเป็น true (รูปแบบนี้จะตรงเสมอ).
