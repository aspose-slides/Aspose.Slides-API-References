## BoxedValue::Equals(ptr) เมธอด


Determines the equality of the boxed values represented by the current and specified objects.

```cpp
bool System::BoxedValue<T>::Equals(ptr obj) override
```


### Arguments

| Parameter | Type | Description |
| --- | --- | --- |
| obj | [ptr](../../object/ptr/) | วัตถุที่เป็นตัวแทนค่ากล่องที่ต้องเปรียบเทียบกับค่ากล่องที่แสดงโดยอ็อบเจ็กต์ปัจจุบัน |

### Return Value

True ถ้าค่ากล่องที่แสดงโดยอ็อบเจ็กต์ปัจจุบันและ **obj** เท่ากัน, มิฉะนั้น - false
