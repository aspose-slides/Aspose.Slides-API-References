```cpp
virtual bool System::StringComparer::Equals(String x, String y) const override
```

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| x | [String](../../string/) | ค่า string ด้านซ้าย. |
| y | [String](../../string/) | ค่า string ด้านขวา. |

### ค่าที่ส่งกลับ

True หากสตริงเท่ากัน, false ในกรณีอื่น.
