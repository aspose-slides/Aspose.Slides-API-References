## Delegate< ReturnType(ArgumentTypes...)>::Empty() const เมธอด

กำหนดว่าวัตถุ delegate ปัจจุบันเป็นค่าว่างหรือไม่ เช่น ไม่ชี้ไปยังเอนทิตีใด ๆ

```cpp
bool System::Delegate<ReturnType(ArgumentTypes...)>::Empty() const
```

### ค่าที่ส่งคืน

True หากวัตถุ delegate ปัจจุบันไม่ได้ชี้ไปยังฟังก์ชัน หรือเมธอดของอ็อบเจ็กต์ฟังก์ชัน มิฉะนั้น - false.
