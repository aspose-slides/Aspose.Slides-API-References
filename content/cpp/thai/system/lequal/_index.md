## System::LEqual(const ExpressionT\&, const ConstantT\&) ฟังก์ชัน

ดำเนินการแปลรูปแบบสัมพันธ์ '<='

```cpp
template<class ExpressionT,class ConstantT> bool System::LEqual(const ExpressionT &left, const ConstantT &constant)
```

### พารามิเตอร์แม่แบบ

| พารามิเตอร์ | คำอธิบาย |
| --- | --- |
| ExpressionT | ประเภทของนิพจน์ทางซ้าย |
| ConstantT | ประเภทของนิพจน์คงที่ |

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| left | const ExpressionT\& | นิพจน์ที่ต้องตรวจสอบ |
| constant | const ConstantT\& | นิพจน์ที่จะเปรียบเทียบกับทางซ้าย |

### ค่าที่ส่งกลับ

true หากการตรวจสอบประเภทสำเร็จ, false หากไม่สำเร็จ.
