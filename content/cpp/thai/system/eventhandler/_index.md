## EventHandler ประเภทนิยาม

แทนวิธีการที่ตอบสนองและประมวลผลเหตุการณ์ ประเภทนี้ควรจัดสรรบนสแตกและส่งผ่านให้ฟังก์ชันโดยค่า หรือโดยการอ้างอิง อย่าใช้คลาส [System::SmartPtr](../smartptr/) เพื่อจัดการอ็อบเจกต์ประเภทนี้

```cpp
using System::EventHandler = typedef MulticastDelegate<void(System::SharedPtr<Object>, TEventArgs)>
```
