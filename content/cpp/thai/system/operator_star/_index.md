## System::operator*(const T\&, const Decimal\&) ฟังก์ชัน

ส่งคืนอินสแตนซ์ใหม่ของคลาส [Decimal](../decimal/) ที่แสดงค่าซึ่งเป็นผลของการคูณค่าที่ระบุและค่าที่แสดงโดยอ็อบเจ็กต์ [Decimal](../decimal/) ที่ระบุ

```cpp
template<typename T,typename _> Decimal System::operator*(const T &x, const Decimal &d)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| x | const T\& | ตัวคูณตัวแรก |
| d | const [Decimal](../decimal/)\& | อ็อบเจ็กต์ [Decimal](../decimal/) ที่เป็นตัวแทนของตัวคูณตัวที่สอง |

### ค่าที่ส่งกลับ

อินสแตนซ์ใหม่ของคลาส [Decimal](../decimal/) ที่แสดงค่าซึ่งเป็นผลของการคูณ **x** และค่าที่แสดงโดย **d**.
