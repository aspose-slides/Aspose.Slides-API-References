## DateTime::Equals(DateTime) const เมธอด


กำหนดว่าตัวอย่างที่ระบุของคลาส [DateTime](../) แทนค่าที่เป็นวันที่และเวลาที่เหมือนกับวัตถุปัจจุบันหรือไม่.

```cpp
constexpr bool System::DateTime::Equals(DateTime other) const
```


### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| other | [DateTime](../) | อินสแตนซ์ของคลาส [DateTime](../) เพื่อเปรียบเทียบกับวัตถุปัจจุบัน |

### ค่าที่ส่งคืน

จริง หาก **other** และวัตถุปัจจุบันมีค่าเดียวกัน, มิฉะนั้น - เท็จ

## DateTime::Equals(DateTime, DateTime) เมธอด


กำหนดว่าตัวอย่างที่ระบุของคลาส [DateTime](../) แทนค่าที่เป็นวันที่และเวลาที่เหมือนกันหรือไม่.

```cpp
static constexpr bool System::DateTime::Equals(DateTime t1, DateTime t2)
```


### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| t1 | [DateTime](../) | ตัวเปรียบเทียบแรก |
| t2 | [DateTime](../) | ตัวเปรียบเทียบที่สอง |

### ค่าที่ส่งคืน

จริง หาก **t1** และ **t2** มีค่าเดียวกัน, มิฉะนั้น - เท็จ
