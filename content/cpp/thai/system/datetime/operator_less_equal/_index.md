## DateTime::operator<=(DateTime) const เมธอด

กำหนดว่าวัตถุปัจจุบันเป็นค่าของวันที่และเวลาที่ก่อนหรือเท่ากับค่าที่แสดงโดยอ็อบเจ็กต์ [DateTime](../) ที่ระบุ

```cpp
constexpr bool System::DateTime::operator<=(DateTime other) const
```

### Arguments

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| other | [DateTime](../) | [DateTime](../) ที่ใช้เปรียบเทียบกับอ็อบเจ็กต์ปัจจุบัน |

### Return Value

คืนค่า true หากค่าของวันที่และเวลาในอ็อบเจ็กต์ปัจจุบันเป็นค่าวันที่และเวลาที่ก่อนหรือเท่ากับค่าที่แสดงโดย **other** หากไม่เป็นเช่นนั้น จะคืนค่า false
