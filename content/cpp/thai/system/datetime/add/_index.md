## DateTime::Add(TimeSpan) const เมธอด

คืนค่าออบเจ็กต์ใหม่ของคลาส [DateTime](../) ที่แสดงค่าที่เป็นวันที่และเวลา ซึ่งเป็นผลมาจากการบวกช่วงเวลาที่ระบุกับค่าที่เป็นวันที่และเวลาที่แสดงโดยออบเจ็กต์ปัจจุบัน.

```cpp
DateTime System::DateTime::Add(TimeSpan value) const
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| value | [TimeSpan](../../timespan/) | ช่วงเวลาที่จะเพิ่ม |

### ค่าที่คืนกลับ

ออบเจ็กต์ใหม่ของคลาส [DateTime](../) ที่แสดงค่าที่เป็นวันที่และเวลา ซึ่งเป็นผลมาจากการบวกช่วงเวลา **tm** กับค่าที่เป็นวันที่และเวลาที่แสดงโดยออบเจ็กต์ปัจจุบัน
