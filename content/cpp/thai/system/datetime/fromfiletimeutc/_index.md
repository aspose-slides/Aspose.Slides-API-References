## DateTime::FromFileTimeUtc(int64_t) เมธอด

แปลงเวลา File ที่ระบุให้เป็นอินสแตนซ์ของคลาส [DateTime](../) ซึ่งแสดงค่าเดียวกันของวันที่และเวลาในรูปแบบเวลา UTC

```cpp
static DateTime System::DateTime::FromFileTimeUtc(int64_t file_time)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| file_time | **int64_t** | เวลาไฟล์ที่ต้องการแปลง |

### ค่าที่ส่งกลับ

อินสแตนซ์ใหม่ของคลาส [DateTime](../) ที่แสดงวันและเวลาเดียวกันกับ **file_time**
