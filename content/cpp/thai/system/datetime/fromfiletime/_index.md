## DateTime::FromFileTime(int64_t) method

```cpp
static DateTime System::DateTime::FromFileTime(int64_t value)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| value | **int64_t** | File time ที่จะแปลง |

### ค่าที่ส่งกลับ

อินสแตนซ์ใหม่ของคลาส [DateTime](../) ที่แสดงค่าวันและเวลาเดียวกันกับ **file_time**
