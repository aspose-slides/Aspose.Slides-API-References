## DateTime::AddYears(int) const เมธอด

ส่งคืนอินสแตนซ์ใหม่ของคลาส [DateTime](../) ที่แสดงค่าที่เป็นวันที่และเวลาเท่ากับค่าที่เป็นตัวแทนโดยอ็อบเจกต์ปัจจุบันโดยที่ส่วนปีเพิ่มขึ้นตามจำนวนที่ระบุ

```cpp
DateTime System::DateTime::AddYears(int value) const
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| value | int | จำนวนปีที่ต้องเพิ่ม; ค่าดังกล่าวอาจเป็นจำนวนบวกหรือจำนวนลบ |

### ค่าที่ส่งคืน

อินสแตนซ์ใหม่ของคลาส [DateTime](../) ที่แสดงค่าที่เป็นวันที่และเวลาเท่ากับค่าที่เป็นตัวแทนโดยอ็อบเจกต์ปัจจุบันโดยที่ส่วนปีเพิ่มขึ้นตาม **value**
