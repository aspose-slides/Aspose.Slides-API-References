## DateTime::AddTicks(int64_t) const เมธอด

ส่งคืนอินสแตนซ์ใหม่ของคลาส [DateTime](../) ที่แสดงค่า วันที่และเวลา ซึ่งเป็นผลรวมของค่าที่แสดงโดยอ็อบเจกต์ปัจจุบันและจำนวนช่วงเวลา 100-nanosecond ที่ระบุ

```cpp
DateTime System::DateTime::AddTicks(int64_t value) const
```

### พารามิเตอร์

| Parameter | Type | Description |
| --- | --- | --- |
| value | **int64_t** | จำนวนช่วงเวลา 100-nanosecond ที่จะเพิ่ม; ค่าจะเป็นค่าบวกหรือค่าลบ |

### ค่าที่ส่งคืน

อินสแตนซ์ใหม่ของคลาส [DateTime](../) ที่แสดงค่า วันที่และเวลา ซึ่งเป็นผลรวมของค่าที่แสดงโดยอ็อบเจกต์ปัจจุบันและ **value** ช่วงเวลา 100-nanosecond
