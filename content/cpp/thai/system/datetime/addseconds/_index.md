## DateTime::AddSeconds(double) const เมธอด


ส่งคืนอินสแตนซ์ใหม่ของคลาส [DateTime](../) ที่แสดงค่าที่วันที่และเวลา ซึ่งเป็นผลรวมของค่าที่แสดงโดยอ็อบเจ็กต์ปัจจุบันและจำนวนวินาทีที่ระบุ

```cpp
DateTime System::DateTime::AddSeconds(double value) const
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| value | **double** | จำนวนวินาทีที่จะเพิ่ม; ค่าที่สามารถเป็นบวกหรือเชิงลบ |

### ค่าที่คืน

อินสแตนซ์ใหม่ของคลาส [DateTime](../) ที่แสดงค่าที่วันที่และเวลา ซึ่งเป็นผลรวมของค่าที่แสดงโดยอ็อบเจ็กต์ปัจจุบันและ **value** วินาที
