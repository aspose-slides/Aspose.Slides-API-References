## DateTime::AddDays(double) const เมธอด

ส่งกลับอินสแตนซ์ใหม่ของคลาส [DateTime](../) ที่แทนค่า วันที่และเวลา ซึ่งเป็นผลรวมของค่าที่แทนโดยอ็อบเจกต์ปัจจุบันและจำนวนวันที่ระบุ

```cpp
DateTime System::DateTime::AddDays(double value) const
```

### อาร์กิวเมนท์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| value | **double** | จำนวนวันที่จะเพิ่ม; ค่าที่ระบุอาจเป็นบวกหรือเป็นลบ |

### ค่าที่ส่งคืน

อินสแตนซ์ใหม่ของคลาส [DateTime](../) ที่แทนค่า วันที่และเวลา ซึ่งเป็นผลรวมของค่าที่แทนโดยอ็อบเจกต์ปัจจุบันและ **value** วัน
