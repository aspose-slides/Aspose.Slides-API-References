## DateTime::operator+(TimeSpan) const เมธอด


ส่งคืนอ็อบเจกต์ใหม่ของคลาส [DateTime](../) ที่แสดงค่าที่เป็นวันที่และเวลา ซึ่งเป็นผลบวกของค่าที่อ็อบเจกต์ปัจจุบันแสดงและช่วงเวลาที่ระบุ.

```cpp
DateTime System::DateTime::operator+(TimeSpan value) const
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| value | [TimeSpan](../../timespan/) | ช่วงเวลาที่เพิ่มให้กับค่าที่อ็อบเจกต์ปัจจุบันแสดง |

### ค่าที่ส่งคืน

อ็อบเจกต์ใหม่ของคลาส [DateTime](../) ที่แสดงค่าที่เป็นวันที่และเวลา ซึ่งเป็นผลบวกของค่าที่อ็อบเจกต์ปัจจุบันแสดง **value**.
