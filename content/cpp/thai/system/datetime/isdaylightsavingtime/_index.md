## เมธอด DateTime::IsDaylightSavingTime() const

กำหนดว่าค่า วันที่และเวลา ที่แสดงโดยอ็อบเจ็กต์ปัจจุบัน อยู่ในช่วงเวลาปรับเปลี่ยนแสงอาทิตย์สำหรับโซนเวลาปัจจุบันหรือไม่

```cpp
bool System::DateTime::IsDaylightSavingTime() const
```

### ค่าที่ส่งคืน

True หากค่า วันที่และเวลา ที่ระบุโดยอ็อบเจ็กต์ปัจจุบัน อยู่ในช่วงเวลาปรับเปลี่ยนแสงอาทิตย์, มิฉะนั้น - false
