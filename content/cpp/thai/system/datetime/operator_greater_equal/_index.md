## DateTime::operator>=(DateTime) const เมธอด

กำหนดว่าวัตถุปัจจุบันแสดงค่า วันที่และเวลา ที่อยู่หลังหรือเท่ากับค่าที่แสดงโดยวัตถุ [DateTime](../) ที่ระบุ

```cpp
constexpr bool System::DateTime::operator>=(DateTime other) const
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| other | [DateTime](../) | วัตถุ [DateTime](../) เพื่อเปรียบเทียบกับวัตถุปัจจุบัน |

### ค่าที่ส่งคืน

จริง หากค่า วันที่และเวลา ที่แสดงโดยวัตถุปัจจุบันอยู่หลังหรือเท่ากับค่าที่แสดงโดย **other**, มิฉะนั้น - เท็จ
