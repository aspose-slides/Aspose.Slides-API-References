## DateTime::AddHours(double) const เมธอด


ส่งคืนอินสแตนซ์ใหม่ของคลาส [DateTime](../) ที่แสดงค่าวันที่และเวลา ซึ่งเป็นผลรวมของค่าที่แสดงโดยอ็อบเจกต์ปัจจุบันและจำนวนชั่วโมงที่ระบุ

```cpp
DateTime System::DateTime::AddHours(double value) const
```


### อาร์กิวเมนท์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| value | **double** | จำนวนชั่วโมงที่ต้องการเพิ่ม; ค่าที่ระบุอาจเป็นบวกหรือเป็นลบ |

### ค่าที่ส่งกลับ

อินสแตนซ์ใหม่ของคลาส [DateTime](../) ที่แสดงค่าวันที่และเวลา ซึ่งเป็นผลรวมของค่าที่แสดงโดยอ็อบเจกต์ปัจจุบันและ **value** ชั่วโมง
