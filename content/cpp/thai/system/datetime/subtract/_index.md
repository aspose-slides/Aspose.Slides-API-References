## DateTime::Subtract(TimeSpan) const เมธอด

ส่งคืนอินสแตนซ์ใหม่ของคลาส [DateTime](../) ที่แสดงค่าตำแหน่งวันที่และเวลา ซึ่งเป็นผลของการลบช่วงเวลา ที่ระบุออกจากค่าที่แสดงโดยอ็อบเจกต์ปัจจุบัน

```cpp
DateTime System::DateTime::Subtract(TimeSpan duration) const
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| duration | [TimeSpan](../../timespan/) | ช่วงเวลาที่จะลบ |

### ค่าที่คืน

อินสแตนซ์ใหม่ของคลาส [DateTime](../) ที่แสดงค่าตำแหน่งวันที่และเวลา ซึ่งเป็นผลของการลบ **duration** จากค่าที่แสดงโดยอ็อบเจกต์ปัจจุบัน

## DateTime::Subtract(DateTime) const เมธอด

ส่งคืนอินสแตนซ์ของคลาส [TimeSpan](../../timespan/) ที่แสดงช่วงเวลาระหว่างค่าตำแหน่งวันที่และเวลาที่แสดงโดยอ็อบเจกต์ปัจจุบันและอ็อบเจกต์ที่ระบุ

```cpp
constexpr TimeSpan System::DateTime::Subtract(DateTime value) const
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| value | [DateTime](../) | อินสแตนซ์ของคลาส [DateTime](../) ที่ทำเครื่องหมายหนึ่งด้านของช่วงเวลาที่จะคำนวณ |

### ค่าที่คืน

อินสแตนซ์ของคลาส [TimeSpan](../../timespan/) ที่แสดงช่วงเวลาระหว่างค่าตำแหน่งวันที่และเวลาที่แสดงโดยอ็อบเจกต์ปัจจุบันและ **value**
