## DateTime::operator==(DateTime) const เมธอด

กำหนดว่าวัตถุปัจจุบันและวัตถุ [DateTime](../) ที่ระบุแสดงค่าที่เป็นวันและเวลาเดียวกันหรือไม่.

```cpp
constexpr bool System::DateTime::operator==(DateTime other) const
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| other | [DateTime](../) | วัตถุ [DateTime](../) ที่ใช้เปรียบเทียบกับวัตถุปัจจุบัน |

### ค่าที่คืนกลับ

คืนค่า true หากวัตถุปัจจุบันและวัตถุที่ระบุแสดงวันที่และเวลาเดียวกัน, มิฉะนั้นคืนค่า false

## DateTime::operator==(std::nullptr_t) const เมธอด

```cpp
constexpr bool System::DateTime::operator==(std::nullptr_t) const
```
