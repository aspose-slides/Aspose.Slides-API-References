## DateTime::AddMinutes(double) const เมธอด

ส่งคืนอินสแตนซ์ใหม่ของคลาส [DateTime](../) ที่แทนค่าที่เป็นวันที่และเวลา ซึ่งเป็นผลรวมของค่าที่แทนโดยอ็อบเจกต์ปัจจุบันและจำนวนนาทีที่ระบุ

```cpp
DateTime System::DateTime::AddMinutes(double value) const
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| value | **double** | จำนวนนาทีที่ต้องเพิ่ม; ค่าสามารถเป็นจำนวนบวกหรือลบ |

### ค่าที่ส่งคืน

อินสแตนซ์ใหม่ของคลาส [DateTime](../) ที่แทนค่าที่เป็นวันที่และเวลา ซึ่งเป็นผลรวมของค่าที่แทนโดยอ็อบเจกต์ปัจจุบันและนาที **value**
