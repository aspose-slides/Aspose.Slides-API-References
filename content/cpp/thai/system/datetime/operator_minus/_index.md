## DateTime::operator-(TimeSpan) const เมธอด


ส่งคืนอินสแตนซ์ใหม่ของคลาส [DateTime](../) ที่แทนค่าเดือนและเวลาซึ่งเป็นผลของการลบช่วงเวลาที่ระบุจากค่าที่แทนโดยอ็อบเจ็กต์ปัจจุบัน

```cpp
DateTime System::DateTime::operator-(TimeSpan value) const
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | รายละเอียด |
| --- | --- | --- |
| value | [TimeSpan](../../timespan/) | ช่วงเวลาที่ต้องลบ |

### ค่าที่คืน

อินสแตนซ์ใหม่ของคลาส [DateTime](../) ที่แทนค่าเดือนและเวลาซึ่งเป็นผลของการลบ **value** จากค่าที่แทนโดยอ็อบเจ็กต์ปัจจุบัน

## DateTime::operator-(DateTime) const เมธอด


ส่งคืนอินสแตนซ์ของคลาส [TimeSpan](../../timespan/) ที่แทนช่วงเวลาระหว่างค่าเดือนและเวลาที่แทนโดยอ็อบเจ็กต์ปัจจุบันและอ็อบเจ็กต์ที่ระบุ

```cpp
constexpr TimeSpan System::DateTime::operator-(DateTime value) const
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | รายละเอียด |
| --- | --- | --- |
| value | [DateTime](../) | อินสแตนซ์ของคลาส [DateTime](../) ที่ทำเครื่องหมายด้านหนึ่งของช่วงเวลาที่จะคำนวณ |

### ค่าที่คืน

อินสแตนซ์ของคลาส [TimeSpan](../../timespan/) ที่แทนช่วงเวลาระหว่างค่าเดือนและเวลาที่แทนโดยอ็อบเจ็กต์ปัจจุบันและ **value**.
