## DateTime::CompareTo(DateTime) const เมธอด

เปรียบเทียบค่าวันที่และเวลาสองค่า ที่แสดงโดยอ็อบเจ็กต์ปัจจุบันและอินสแตนซ์ที่ระบุของคลาส [DateTime](../) และคืนค่าที่บ่งบอกตำแหน่งสัมพันธ์ของค่าเหล่านั้นบนเส้นเวลา.

```cpp
constexpr int System::DateTime::CompareTo(DateTime value) const
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | รายละเอียด |
| --- | --- | --- |
| value | [DateTime](../) | อินสแตนซ์ของคลาส [DateTime](../) เพื่อเปรียบเทียบกับอ็อบเจ็กต์ปัจจุบัน |

### ค่าที่ส่งกลับ

ค่าที่น้อยกว่า 0 หากอ็อบเจ็กต์ปัจจุบันแสดงค่าที่เกิดก่อนค่าที่แสดงโดย **value**; 0 หากค่าที่แสดงโดยอ็อบเจ็กต์ทั้งสองเหมือนกัน; ค่าที่มากกว่า 0 หากค่าที่แสดงโดยอ็อบเจ็กต์ปัจจุบันเกิดหลังค่าที่แสดงโดย **value**
