## DateTime::Compare(DateTime, DateTime) เมธอด

เปรียบเทียบค่าทั้งสองที่แสดงโดยอินสแตนซ์ที่ระบุของคลาส [DateTime](../) และคืนค่าที่บ่งบอกตำแหน่งสัมพันธ์ของค่าบนเส้นเวลา

```cpp
static constexpr int System::DateTime::Compare(DateTime t1, DateTime t2)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| t1 | [DateTime](../) | ค่าที่เปรียบเทียบแรก |
| t2 | [DateTime](../) | ค่าที่เปรียบเทียบที่สอง |

### ค่าที่คืน

ค่าหนึ่งที่น้อยกว่า 0 หาก **t1** มีค่าน้อยกว่าก่อน **t2**; 0 หาก **t1** เท่ากับ **t2**; ค่าหนึ่งที่มากกว่า 0 หาก **t1** มีค่าหลัง **t2**
