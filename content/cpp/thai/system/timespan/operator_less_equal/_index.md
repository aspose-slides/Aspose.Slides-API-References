## TimeSpan::operator<=(TimeSpan) const เมธอด


กำหนดว่าช่วงเวลาที่อ็อบเจ็กต์ปัจจุบันแสดงนั้นสั้นกว่า หรือเท่ากับช่วงเวลาที่อ็อบเจ็กต์ที่ระบุแสดงหรือไม่

```cpp
constexpr bool System::TimeSpan::operator<=(TimeSpan value) const
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| value | [TimeSpan](../) | อ็อบเจ็กต์ [TimeSpan](../) เพื่อเปรียบเทียบกับอ็อบเจ็กต์ปัจจุบัน |

### ค่าที่คืน

จริงถ้าช่วงเวลาที่แสดงโดยอ็อบเจ็กต์ปัจจุบันสั้นกว่า หรือเท่ากับช่วงเวลาที่แสดงโดย **value**, มิฉะนั้น - เท็จ
