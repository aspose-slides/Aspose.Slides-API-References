## TimeSpan::operator==(TimeSpan) const เมธอด

```cpp
constexpr bool System::TimeSpan::operator==(TimeSpan value) const
```

### พารามิเตอร์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| value | [TimeSpan](../) | วัตถุ [TimeSpan](../) เพื่อเปรียบเทียบกับอ็อบเจ็กต์ปัจจุบัน |

### ค่าที่ส่งกลับ

True หากอ็อบเจ็กต์ปัจจุบันและอ็อบเจ็กต์ที่ระบุแสดงช่วงเวลาเดียวกัน, มิฉะนั้น - false
