## TimeSpan::TimeSpan() ตัวสร้าง

สร้างอ็อบเจ็กต์ [TimeSpan](../) ที่เป็นตัวแทนของช่วงเวลาเป็นศูนย์

```cpp
constexpr System::TimeSpan::TimeSpan()
```

## TimeSpan::TimeSpan(int64_t) ตัวสร้าง

สร้างอินสแตนซ์ของคลาส [TimeSpan](../) ที่เป็นตัวแทนของช่วงเวลาที่ระบุ

```cpp
constexpr System::TimeSpan::TimeSpan(int64_t ticks)
```

### Arguments

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| ticks | **int64_t** | ช่วงเวลาที่จะเป็นตัวแทนของอินสแตนซ์ที่กำลังสร้าง แสดงเป็นจำนวนช่วงเวลา 100-นาโนวินาที |

## TimeSpan::TimeSpan(int, int, int) ตัวสร้าง

สร้างอินสแตนซ์ของคลาส [TimeSpan](../) ที่เป็นตัวแทนของช่วงเวลาที่เท่ากับผลรวมของจำนวนชั่วโมง นาที และวินาทีที่ระบุ

```cpp
System::TimeSpan::TimeSpan(int hours, int minutes, int seconds)
```

### Arguments

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| hours | int | จำนวนชั่วโมงในส่วนชั่วโมงของช่วงเวลาที่จะเป็นตัวแทนของอินสแตนซ์ที่กำลังสร้าง |
| minutes | int | จำนวนนาทีในส่วนนาทีของช่วงเวลาที่จะเป็นตัวแทนของอินสแตนซ์ที่กำลังสร้าง |
| seconds | int | จำนวนวินาทีในส่วนวินาทีของช่วงเวลาที่จะเป็นตัวแทนของอินสแตนซ์ที่กำลังสร้าง |

## TimeSpan::TimeSpan(int, int, int, int, int) ตัวสร้าง

สร้างอินสแตนซ์ของคลาส [TimeSpan](../) ที่เป็นตัวแทนของช่วงเวลาที่เท่ากับผลรวมของจำนวนชั่วโมง นาที วินาที และมิลลิวินาทีที่ระบุ

```cpp
System::TimeSpan::TimeSpan(int days, int hours, int minutes, int seconds, int milliseconds=0)
```

### Arguments

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| days | int | จำนวนวันในส่วนวันของช่วงเวลาที่จะเป็นตัวแทนของอินสแตนซ์ที่กำลังสร้าง |
| hours | int | จำนวนชั่วโมงในส่วนชั่วโมงของช่วงเวลาที่จะเป็นตัวแทนของอินสแตนซ์ที่กำลังสร้าง |
| minutes | int | จำนวนนาทีในส่วนนาทีของช่วงเวลาที่จะเป็นตัวแทนของอินสแตนซ์ที่กำลังสร้าง |
| seconds | int | จำนวนวินาทีในส่วนวินาทีของช่วงเวลาที่จะเป็นตัวแทนของอินสแตนซ์ที่กำลังสร้าง |
| milliseconds | int | จำนวนมิลลิวินาทีในส่วนมิลลิวินาทีของช่วงเวลาที่จะเป็นตัวแทนของอินสแตนซ์ที่กำลังสร้าง |

## TimeSpan::TimeSpan(const TimeSpan\&) ตัวสร้าง

สร้างอ็อบเจ็กต์ [TimeSpan](../) ที่เป็นตัวแทนของช่วงเวลาที่เท่ากับช่วงเวลาที่อ็อบเจ็กต์ [TimeSpan](../) ที่ระบุเป็นตัวแทน

```cpp
constexpr System::TimeSpan::TimeSpan(const TimeSpan &)=default
```
