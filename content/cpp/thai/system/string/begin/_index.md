## String::begin() const เมธอด

คืนค่าพอยน์เตอร์ไปยังจุดเริ่มต้นของบัฟเฟอร์สตริงจริง. ไม่ทำการจัดสรรใหม่ใดๆ. ไม่รับประกันว่าบัฟเฟอร์จะเป็น null-terminated.

```cpp
const UChar * System::String::begin() const
```

### ค่าที่ส่งกลับ

พอยน์เตอร์ไปยังบัฟเฟอร์สตริงจริง ไม่ว่าจะ null-terminated หรือไม่.
