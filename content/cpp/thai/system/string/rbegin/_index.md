## String::rbegin() const เมธอด


ส่งกลับ reverse iterator ไปยังอักขระตัวสุดท้าย (หากมี) ของบัฟเฟอร์สตริงจริง.

```cpp
reverse_iterator System::String::rbegin() const
```


### ค่าที่คืนกลับ

Reverse iterator ไปยังอักขระตัวสุดท้ายของบัฟเฟอร์สตริงจริง (หากมี) หรือเท่ากับ [rend()](../rend/).
