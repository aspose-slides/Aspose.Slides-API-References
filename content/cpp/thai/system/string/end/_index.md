## String::end() const เมธอด

คืนค่าพอยน์เตอร์ไปยังตำแหน่งสุดท้ายของบัฟเฟอร์สตริงจริง ไม่ทำการจัดสรรใหม่ใด ๆ ไม่รับประกันว่าบัฟเฟอร์จะเป็น null-terminated

```cpp
const UChar * System::String::end() const
```

### ค่าที่ส่งคืน

พอยน์เตอร์ไปยังอีลีเมนต์แรกหลังจากบัฟเฟอร์สตริงจริง ไม่ว่าจะเป็น null-terminated หรือไม่
