## String::IsNormalized(System::Text::NormalizationForm) const เมธอด


ตรวจสอบว่าสตริงยูนิโคดถูกทำให้เป็นรูปแบบการทำให้เป็นมาตรฐานหรือไม่โดยใช้รูปแบบการทำให้เป็นมาตรฐานที่ระบุ

```cpp
bool System::String::IsNormalized(System::Text::NormalizationForm form) const
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| form | [System::Text::NormalizationForm](../../../system.text/normalizationform/) | รูปแบบการทำให้เป็นมาตรฐาน, ดู [System::Text::NormalizationForm](../../../system.text/normalizationform/) สำหรับรายละเอียด |

### ค่าที่ส่งกลับ

true หากสตริงถูกทำให้เป็นมาตรฐานแล้ว, false ในกรณีอื่น
