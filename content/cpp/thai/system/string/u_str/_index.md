## String::u_str() const เมธอด

คืนค่าเป็นบัฟเฟอร์ null-terminated ที่ใช้สไตล์ของ ICU อาจทำการจัดสรรใหม่ให้สตริง.

```cpp
const UChar * System::String::u_str() const
```

### ค่าที่คืน

ตัวชี้ไปยังบัฟเฟอร์สตริงที่เป็น null-terminated
