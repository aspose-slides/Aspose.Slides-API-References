## String::IsNullOrWhiteSpace(const String\&) เมธอด

บ่งชี้ว่าสตริงที่ระบุเป็นค่า null, ว่างเปล่า หรือประกอบด้วยอักขระ whitespace เท่านั้น.

```cpp
static bool System::String::IsNullOrWhiteSpace(const String &str)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| str | const [String](../)\& | [String](../) เพื่อตรวจสอบ. |

### ค่าที่ส่งกลับ

true หากสตริงเป็นค่า null หรือว่างเปล่าหรือประกอบด้วยอักขระ whitespace เท่านั้น, false ในกรณีอื่น.
