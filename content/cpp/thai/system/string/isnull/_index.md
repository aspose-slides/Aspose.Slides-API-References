## String::IsNull() const เมธอด


ตรวจสอบว่า string ถูกพิจารณาเป็นค่า null หรือไม่. [String](../) จะเป็นค่า null เฉพาะเมื่อมันถูกสร้างโดยคอนสตรัคเตอร์ [String()](../string/), ถูกย้าย, คัดลอก หรือกำหนดค่าจาก string ที่เป็น null หรือเมธอด [reset()](../reset/) ถูกเรียกใช้.

```cpp
bool System::String::IsNull() const
```


### ค่าที่ส่งกลับ

true หาก string ถูกพิจารณาเป็นค่า null, false ในกรณีอื่น.
