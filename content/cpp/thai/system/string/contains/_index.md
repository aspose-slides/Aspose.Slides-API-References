## String::Contains(const String\&) const เมธอด

ตรวจสอบว่า str เป็นสตริงย่อยของสตริงปัจจุบันหรือไม่.

```cpp
bool System::String::Contains(const String &str) const
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| str | const [String](../)\& | สตริงที่ค้นหา. |

### ค่าที่คืนค่า

true หากพบสตริงย่อย, false หากไม่พบ.
