## String::rend() const เมธอด

คืนค่า reverse iterator ไปยังตำแหน่งก่อนอักขระตัวแรก (หากมี) ของบัฟเฟอร์สตริงจริง.

```cpp
reverse_iterator System::String::rend() const
```

### ค่าที่คืน

Reverse iterator ไปยังองค์ประกอบที่อยู่ก่อนอักขระตัวแรกของบัฟเฟอร์สตริงจริง (หากมี) หรือไปยังองค์ประกอบที่อยู่ก่อนบัฟเฟอร์ที่จัดสรรไว้.
