## Random::Random() คอนสตรัคเตอร์

เริ่มต้นอินสแตนซ์ใหม่โดยใช้ค่า seed เริ่มต้นที่ขึ้นกับเวลา

```cpp
System::Random::Random()
```

## Random::Random(int32_t) คอนสตรัคเตอร์

เริ่มต้นอินสแตนซ์ใหม่ของคลาส [System.Random](../) โดยใช้ค่า seed ที่ระบุ

```cpp
System::Random::Random(int32_t seed)
```

### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| seed | **int32_t** | seed ที่ใช้ในการสร้างลำดับตัวเลขเทียมสุ่ม |
