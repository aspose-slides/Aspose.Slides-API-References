## Uri::CheckSchemeName(const String\&) เมธอด

ตรวจสอบว่ารูปแบบ (scheme) ที่ระบุเป็นรูปแบบที่ถูกต้องหรือไม่

```cpp
static bool System::Uri::CheckSchemeName(const String &schemeName)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| schemeName | const [String](../../string/)\& | ชื่อของ scheme ที่จะทดสอบ |

### ค่าที่ส่งกลับ

true หากสตริงที่ระบุเป็น scheme ที่ถูกต้อง, มิฉะนั้น - false
