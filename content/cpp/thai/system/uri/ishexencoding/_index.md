## Uri::IsHexEncoding(const String\&, int32_t) method

```cpp
static bool System::Uri::IsHexEncoding(const String &pattern, int32_t index)
```

### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| pattern | const [String](../../string/)\& | สตริงที่ต้องตรวจสอบ |
| index | **int32_t** | ตำแหน่งอักขระที่ต้องทดสอบโดยอิงจากศูนย์ |

### ค่าที่ส่งกลับ

True ถ้าตัวอักษรที่ระบุถูกเข้ารหัสเป็นฐานสิบหก, ในกรณีอื่น - false
