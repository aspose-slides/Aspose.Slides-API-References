## Comparison::operator()(T, T) เมธอด

เรียกใช้อ็อบเจ็กต์ที่เรียกได้ซึ่งชี้โดยอ็อบเจ็กต์ปัจจุบัน.

```cpp
bool System::Comparison<T>::operator()(T a, T b)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| a | T | ค่าเปรียบเทียบแรก |
| b | T | ค่าเปรียบเทียบที่สอง |

### ค่ารีเทิร์น

True หาก **a** น้อยกว่า **b**, มิฉะนั้น - true
