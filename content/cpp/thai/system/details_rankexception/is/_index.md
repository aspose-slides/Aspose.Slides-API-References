## Details_RankException::Is(const System::TypeInfo\&) const เมธอด

```cpp
bool System::Details_RankException::Is(const System::TypeInfo &target) const override
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) โครงสร้างที่อธิบายประเภทที่ใช้ทดสอบวัตถุปัจจุบันกับ. |

### ค่าที่ส่งคืน

True หากวัตถุเป็นประเภทที่มีแท็กหรือคลาสย่อยของมัน, false มิฉะนั้น.

## หมายเหตุ

ตรวจสอบว่าวัตถุเป็นอินสแตนซ์ของประเภทที่อธิบายโดย targetType หรือไม่. ตัวคล้ายกับตัวดำเนินการ 'is' ของ C#.
