## Guid::Equals(const Guid\&) const เมธอด

ตรวจสอบว่า GUID ที่แสดงโดยอ็อบเจ็กต์ปัจจุบันและอ็อบเจ็กต์ที่ระบุเท่ากันหรือไม่.

```cpp
bool System::Guid::Equals(const Guid &g) const
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| g | const [Guid](../)\& | ตัวเปรียบเทียบ |

### ค่าที่คืนกลับ

True หาก GUID ที่แสดงโดยอ็อบเจ็กต์ปัจจุบันและอ็อบเจ็กต์ที่ระบุเท่ากัน, มิฉะนั้น - false
