## Guid::operator==(const Guid\&) const เมธอด

กำหนดว่า GUIDs ที่แสดงโดยอ็อบเจ็กต์ปัจจุบันและอ็อบเจ็กต์ที่ระบุมีค่าเท่ากันหรือไม่。

```cpp
bool System::Guid::operator==(const Guid &b) const
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| b | const [Guid](../)\& | ค่าที่เปรียบเทียบ |

### ค่าที่ส่งกลับ

True หาก GUIDs ที่แสดงโดยอ็อบเจ็กต์ปัจจุบันและอ็อบเจ็กต์ที่ระบุมีค่าเท่ากัน, มิฉะนั้น - false
