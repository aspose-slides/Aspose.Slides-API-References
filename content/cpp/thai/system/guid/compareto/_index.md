## Guid::CompareTo(const Guid\&) const เมธอด

ทำการเปรียบเทียบเชิงคณิตศาสตร์ของ GUID ที่แสดงโดยอ็อบเจ็กต์ปัจจุบันและอ็อบเจ็กต์ที่ระบุ

```cpp
int System::Guid::CompareTo(const Guid &g) const
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| g | const [Guid](../)\& | ตัวเปรียบเทียบ |

### ค่าที่คืน

- 1 ถ้า GUID ที่แสดงโดยอ็อบเจ็กต์ปัจจุบันมีค่าน้อยกว่า GUID ที่แสดงโดย **g**; 0 ถ้า GUID เท่ากัน; 1 ถ้า GUID ที่แสดงโดยอ็อบเจ็กต์ปัจจุบันมีค่ามากกว่า GUID ที่แสดงโดย **g**
