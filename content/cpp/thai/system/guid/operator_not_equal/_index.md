## Guid::operator!=(const Guid\&) const เมธอด

```cpp
bool System::Guid::operator!=(const Guid &b) const
```

### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| b | const [Guid](../)\& | ค่าเปรียบเทียบ |

### ค่ารีเทิร์น

True หาก GUIDs ที่แสดงโดยวัตถุปัจจุบันและวัตถุที่ระบุไม่เท่ากัน, ไม่เช่นนั้น - false
