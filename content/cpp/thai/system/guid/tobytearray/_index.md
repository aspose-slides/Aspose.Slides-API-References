## Guid::ToByteArray() const เมธอด

แปลง GUID ที่แสดงโดยอ็อบเจกต์ปัจจุบันเป็นอาร์เรย์ของไบต์

```cpp
ArrayPtr<uint8_t> System::Guid::ToByteArray() const
```

### ค่ารีเทิร์น

อาร์เรย์ของไบต์ที่ประกอบด้วยไบต์ซึ่งเป็นส่วนประกอบของ GUID ที่เป็นตัวแทนของอ็อบเจกต์ปัจจุบัน
