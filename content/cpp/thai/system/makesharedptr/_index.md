## System::MakeSharedPtr(X *) ฟังก์ชัน


แปลงพอยน์เตอร์ดิบเป็นพอยน์เตอร์อัจฉริยะ

```cpp
template<class X> SmartPtr<X> System::MakeSharedPtr(X *p)
```


### พารามิเตอร์แม่แบบ

| Parameter | Description |
| --- | --- |
| X | ประเภทของพอยน์ท์ |

### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| p | X * | พอยน์เตอร์ดิบไปยังอ็อบเจกต์ |

### ค่าที่คืน

สัญญาณอัจฉริยะที่แชร์ไปยังอ็อบเจกต์

## System::MakeSharedPtr(const X *) ฟังก์ชัน


แปลงพอยน์เตอร์ดิบเป็นพอยน์เตอร์อัจฉริยะ  การโหลดซ้ำสำหรับพอยน์เตอร์คอนสท์ท์ มีประโยชน์เช่นเมื่อใช้ตัวแปร 'this' ในเมธอด C# ที่แปลเป็นคอนสท์ท์

```cpp
template<class X> SmartPtr<X> System::MakeSharedPtr(const X *p)
```


### พารามิเตอร์แม่แบบ

| Parameter | Description |
| --- | --- |
| X | ประเภทของพอยน์ท์ |

### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| p | const X * | พอยน์เตอร์ดิบไปยังอ็อบเจกต์ |

### ค่าที่คืน

สัญญาณอัจฉริยะที่แชร์ไปยังอ็อบเจกต์
