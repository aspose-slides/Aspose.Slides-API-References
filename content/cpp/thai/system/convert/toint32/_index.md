## Convert::ToInt32(bool) เมธอด

แปลงค่า boolean ที่ระบุเป็นจำนวนเต็มมีเครื่องหมาย 32 บิตที่เทียบเท่า

```cpp
static constexpr int System::Convert::ToInt32(bool value)
```
