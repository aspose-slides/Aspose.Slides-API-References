## Convert::ToUInt16(bool) เมธอด

แปลงค่าบูลีนที่ระบุเป็นจำนวนเต็มไม่มีเครื่องหมายขนาด 16-บิตที่เทียบเท่า.

```cpp
static constexpr uint16_t System::Convert::ToUInt16(bool value)
```
