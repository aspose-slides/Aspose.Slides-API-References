## Nullable::ToString() const เมธอด

แปลงค่าที่แสดงโดยอ็อบเจ็กต์ปัจจุบันเป็นสตริง.

```cpp
String System::Nullable<T>::ToString() const
```

### ค่าที่ส่งกลับ

การแสดงผลเป็นสตริงของค่าที่แสดงโดยอ็อบเจ็กต์ปัจจุบันหรือสตริงว่างหากค่าที่แสดงโดยอ็อบเจ็กต์ปัจจุบันเป็น null
