## Object::Is(const TypeInfo\&) const method

ตรวจสอบว่าอ็อบเจกต์เป็นอินสแตนซ์ของประเภทที่อธิบายโดย targetType หรือไม่. เป็นลักษณะเดียวกับตัวดำเนินการ 'is' ของ C#.

```cpp
virtual bool System::Object::Is(const TypeInfo &targetType) const
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| targetType | const [TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) โครงสร้างที่อธิบายประเภทเพื่อทดสอบอ็อบเจกต์ปัจจุบัน |

### ค่าที่ส่งคืน

True หากอ็อบเจกต์เป็นประเภทที่แท็กหรือเป็นคลาสตยาทของมัน, false ในกรณีอื่น
