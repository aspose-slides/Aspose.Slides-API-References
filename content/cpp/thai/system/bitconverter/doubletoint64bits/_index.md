## BitConverter::DoubleToInt64Bits(double) เมธอด

คืนค่าเป็นจำนวนเต็ม 64 บิตที่การแสดงผลไบนารีเท่ากับการแสดงผลไบนารีของค่าที่ระบุแบบ double-precision floating point

```cpp
static int64_t System::BitConverter::DoubleToInt64Bits(double value)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| value | **double** | ค่าแบบจุดลอยตัวความแม่นคู่ double |

### ค่าที่ส่งคืน

ค่าจำนวนเต็ม 64 บิตที่การแสดงผลไบนารีเท่ากับของค่าที่ระบุ
