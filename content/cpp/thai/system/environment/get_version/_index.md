## Environment::get_Version() เมธอด

ส่งกลับอ็อบเจ็กต์ [Version](../../version/) ที่แสดงข้อมูลเกี่ยวกับเวอร์ชันของ Common Language Runtime. หมายเลขเวอร์ชันที่ส่งกลับโดยเมธอดนี้ค่อนข้างเป็นค่าเทียมและไม่ได้หมายความว่าคลาสทั้งหมดในไลบรารีทำงานสอดคล้องกับเวอร์ชันที่ส่งกลับ.

```cpp
static Version System::Environment::get_Version()
```
