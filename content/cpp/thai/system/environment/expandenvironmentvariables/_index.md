## Environment::ExpandEnvironmentVariables(const String\&) เมธอด


แทนที่ชื่อของตัวแปรสภาพแวดล้อมที่พบในสตริ่งที่ระบุด้วยค่าของตัวแปรเหล่านั้นและส่งคืนสตริ่งผลลัพธ์.

```cpp
static String System::Environment::ExpandEnvironmentVariables(const String &name)
```


### อาร์กิวเมนท์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| name | const [String](../../string/)\& | สตริ่งที่ประกอบด้วยชื่อของตัวแปรสภาพแวดล้อม |

### ค่าที่คืน

สตริ่งที่ได้จากการแทนที่ชื่อของตัวแปรใน **name** ด้วยค่าของมัน.
