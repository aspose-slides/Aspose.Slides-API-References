```cpp
constexpr System::Index::Index() noexcept
```

## Index::Index(int32_t) คอนสตรัคเตอร์

สร้างอินสแตนซ์ที่แทนตำแหน่งที่ระบุจากจุดเริ่มต้นของคอลเลกชัน.

```cpp
constexpr System::Index::Index(int32_t value) noexcept
```

### พารามิเตอร์

| Parameter | Type | Description |
| --- | --- | --- |
| value | **int32_t** | ดัชนีที่นับตั้งแต่ศูนย์จากจุดเริ่มต้น. |

## Index::Index(int32_t, bool) คอนสตรัคเตอร์


### พารามิเตอร์

| Parameter | Type | Description |
| --- | --- | --- |
| value | **int32_t** | ค่าดัชนี. |
| from_end | **bool** | จริง หากดัชนีสัมพันธ์กับจุดสิ้นสุดของคอลเลกชัน. |
