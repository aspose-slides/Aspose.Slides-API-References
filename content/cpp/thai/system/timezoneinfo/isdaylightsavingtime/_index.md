## TimeZoneInfo::IsDaylightSavingTime(DateTime) const เมธอด

ตรวจสอบว่าข้อมูลวันและเวลา ที่ระบุ อยู่ในช่วงเวลาออมแสงหรือไม่.

```cpp
bool System::TimeZoneInfo::IsDaylightSavingTime(DateTime date_time) const
```

### อาร์กิวเมนท์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| date_time | [DateTime](../../datetime/) | วันที่และเวลา. |

### ค่าที่คืน

True หาก date_time อยู่ในช่วงเวลาออมแสง.
