## TimeZoneInfo::IsDaylightSavingTimeNoThrow(DateTime) const เมธอด

ตรวจสอบว่าค่าวันที่และเวลาเฉพาะอยู่ในช่วงเวลาการเปลี่ยนแปลงแสงอาทิตย์หรือไม่

```cpp
bool System::TimeZoneInfo::IsDaylightSavingTimeNoThrow(DateTime date_time) const
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| date_time | [DateTime](../../datetime/) | วันที่และเวลา |

### ค่าที่ส่งกลับ

True หาก date_time เป็นเวลาเปลี่ยนแปลงแสงอาทิตย์
