## TimeZoneInfo::IsAmbiguousTime(DateTime) const เมธอด

ตรวจสอบว่ารายการวันและเวลาที่ระบุมีความกำกวมและสามารถแมพเป็นเวลามาตรฐาน UTC หลายค่าได้.

```cpp
bool System::TimeZoneInfo::IsAmbiguousTime(DateTime date_time) const
```

### Arguments

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| date_time | [DateTime](../../datetime/) | วันและเวลา. |

### Return Value

True ถ้า date_time มีความกำกวม.
