## SmartPtrMode enum

[SmartPtr](../smartptr/) ประเภทตัวชี้: weak หรือ shared. กำหนดว่าตัวชี้จะถูกนับหรือไม่เมื่อพิจารณาว่าจะลบอ็อบเจกต์หรือไม่.

```cpp
enum class SmartPtrMode : char
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Shared | 0 | Shared mode: ตัวชี้มีส่วนร่วมในการนับอ้างอิง. |
| Weak | 1 | Weak mode: ตัวชี้ไม่เข้าร่วมการนับอ้างอิง. |
