## Decimal::Compare(const Decimal\&, const Decimal\&) เมธอด

กำหนดว่าค่าที่แสดงโดยอ็อบเจกต์ [Decimal](../) ตัวแรกน้อยกว่า เท่ากับ หรือมากกว่าค่าที่แสดงโดยอ็อบเจกต์ [Decimal](../) ตัวที่สอง

```cpp
static int System::Decimal::Compare(const Decimal &d1, const Decimal &d2)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| d1 | const [Decimal](../)\& | ค่าที่เปรียบเทียบตัวแรก |
| d2 | const [Decimal](../)\& | ค่าที่เปรียบเทียบตัวที่สอง |

### ค่าที่ส่งกลับ

- 1 หากค่าที่แสดงโดย **d1** น้อยกว่าค่าที่แสดงโดย **d2**; 0 หากค่าทั้งสองเท่ากัน; 1 หากค่าที่แสดงโดย **d1** มากกว่าค่าที่แสดงโดย **d2**
