## Decimal::operator==(const Decimal\&) const method


กำหนดว่าค่าที่แสดงโดยอ็อบเจ็กต์ปัจจุบันและอ็อบเจ็กต์ที่ระบุเท่ากันหรือไม่.

```cpp
bool System::Decimal::operator==(const Decimal &d) const
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| d | const [Decimal](../)\& | อ็อบเจ็กต์ [Decimal](../) ที่ใช้เปรียบเทียบกับอ็อบเจ็กต์ปัจจุบัน |

### ค่าที่ส่งกลับ

True หากค่าที่แสดงโดยอ็อบเจ็กต์ปัจจุบันและอ็อบเจ็กต์ที่ระบุเท่ากัน, ไม่เช่นนั้น - false
