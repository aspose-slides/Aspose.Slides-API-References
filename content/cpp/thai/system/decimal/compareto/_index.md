## Decimal::CompareTo(const Decimal\&) const เมธอด

กำหนดว่าค่าที่แทนโดยอ็อบเจกต์ปัจจุบันน้อยกว่า เท่ากับ หรือ มากกว่าค่าที่แทนโดยอ็อบเจกต์ที่ระบุ

```cpp
int System::Decimal::CompareTo(const Decimal &d) const
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| d | const [Decimal](../)\& | ตัวเปรียบเทียบ |

### ค่าที่ส่งกลับ

- 1 หากค่าที่แทนโดยอ็อบเจกต์ปัจจุบันน้อยกว่าค่าที่แทนโดย **d**; 0 หากค่าทั้งสองเท่ากัน; 1 หากค่าที่แทนโดยอ็อบเจกต์ปัจจุบันมากกว่าค่าที่แทนโดย **d**
