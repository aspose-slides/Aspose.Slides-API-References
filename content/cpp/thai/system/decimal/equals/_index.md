## Decimal::Equals(const Decimal\&) const method

กำหนดว่า ค่าที่แสดงโดยอ็อบเจกต์ปัจจุบันและอ็อบเจกต์ที่ระบุเท่ากันหรือไม่

```cpp
bool System::Decimal::Equals(const Decimal &d) const
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| d | const [Decimal](../)\& | อ็อบเจกต์ [Decimal](../) ที่ใช้เปรียบเทียบกับอ็อบเจกต์ปัจจุบัน |

### ค่าที่ส่งกลับ

True หากค่าที่แสดงโดยอ็อบเจกต์ปัจจุบันและอ็อบเจกต์ที่ระบุเท่ากัน, มิฉะนั้น - false
