## Decimal::operator>=(const Decimal\&) const เมธอด

Determines if the value represented by the current object is greater than or equal to the value represented by the specified object.

```cpp
bool System::Decimal::operator>=(const Decimal &d) const
```

### อาร์กิวเมนท์

| Parameter | Type | Description |
| --- | --- | --- |
| d | const [Decimal](../)\& | [Decimal](../) อ็อบเจ็กต์ที่ใช้เปรียบเทียบกับอ็อบเจ็กต์ปัจจุบัน |

### Return Value

True หากค่าที่แทนโดยอ็อบเจ็กต์ปัจจุบันมากกว่าหรือเท่ากับค่าที่แทนโดย **d**, มิฉะนั้น - false
