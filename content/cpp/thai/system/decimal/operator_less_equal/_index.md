## Decimal::operator<=(const Decimal\&) const เมธอด

กำหนดว่าค่าที่แสดงโดยอ็อบเจ็กต์ปัจจุบันน้อยกว่าหรือเท่ากับค่าที่แสดงโดยอ็อบเจ็กต์ที่ระบุหรือไม่

```cpp
bool System::Decimal::operator<=(const Decimal &d) const
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| d | const [Decimal](../)\& | อ็อบเจ็กต์ [Decimal](../) เพื่อเปรียบเทียบกับอ็อบเจ็กต์ปัจจุบัน |

### ค่าที่ส่งคืน

True หากค่าที่แสดงโดยอ็อบเจ็กต์ปัจจุบันน้อยกว่าหรือเท่ากับค่าที่แสดงโดย **d**, ไม่เช่นนั้น - false
