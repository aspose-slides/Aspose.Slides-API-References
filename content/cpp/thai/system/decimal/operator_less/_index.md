## Decimal::operator<(const Decimal\&) const เมธอด

กำหนดว่าค่าที่แทนโดยอ็อบเจ็กต์ปัจจุบันน้อยกว่าค่าที่แทนโดยอ็อบเจ็กต์ที่ระบุหรือไม่

```cpp
bool System::Decimal::operator<(const Decimal &d) const
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| d | const [Decimal](../)\& | อ็อบเจ็กต์ [Decimal](../) ที่ใช้เปรียบเทียบกับอ็อบเจ็กต์ปัจจุบัน |

### ค่าที่ส่งกลับ

จริงหากค่าที่แทนโดยอ็อบเจ็กต์ปัจจุบันน้อยกว่าค่าที่แทนโดย **d**, มิฉะนั้น - เท็จ
