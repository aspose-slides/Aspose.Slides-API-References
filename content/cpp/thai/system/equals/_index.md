## System::Equals(const TA\&, const TB\&) ฟังก์ชัน

กำหนดความเท่ากันของสองค่าโดยใช้ [operator==()](../operator_equal_equal/) กับพวกมัน.

```cpp
template<typename TA,typename TB> bool System::Equals(const TA &a, const TB &b)
```

### พารามิเตอร์แม่แบบ

| Parameter | Description |
| --- | --- |
| TA | ชนิดของตัวเปรียบเทียบตัวแรก |
| TB | ชนิดของตัวเปรียบเทียบตัวที่สอง |

### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| a | const TA\& | ตัวเปรียบเทียบตัวแรก |
| b | const TB\& | ตัวเปรียบเทียบตัวที่สอง |

### ค่าที่ส่งคืน

ค่าบูลีนที่ส่งคืนโดย [operator==()](../operator_equal_equal/) ที่ประยุกต์กับ **a** และ **b**
