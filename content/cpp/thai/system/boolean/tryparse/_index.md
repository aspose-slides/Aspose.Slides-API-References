## Boolean::TryParse(const String\&, bool\&) เมธอด

แปลงสตริงที่ระบุเป็นค่าประเภท bool

```cpp
static bool System::Boolean::TryParse(const String &value, bool &result)
```

### Arguments

| Parameter | Type | Description |
| --- | --- | --- |
| value | const [String](../../string/)\& | สตริงที่จะทำการแปลง |
| result | **bool**\& | การอ้างอิงถึงตัวแปร bool ที่ผลลัพธ์ของการแปลงจะถูกใส่; ผลลัพธ์จะเป็น true หากสตริงที่ระบุเท่ากับ \"True\" และ false หากสตริงที่ระบุเท่ากับ \"False\" |

### Return Value

True หากสตริงที่ระบุเท่ากับ \"True\" หรือ \"False\"; มิฉะนั้น - false.
