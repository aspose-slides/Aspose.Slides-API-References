## Boolean::Parse(const String\&) เมธอด


แปลงสตริงที่ระบุให้เป็นค่าประเภท bool.

```cpp
static bool System::Boolean::Parse(const String &value)
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| value | const [String](../../string/)\& | สตริงที่จะทำการแปลง. |

### ค่าที่คืนกลับ

ตัวแปร bool ที่ผลลัพธ์ของการแปลงถูกเก็บ; ผลลัพธ์จะเป็น true หากสตริงที่ระบุเท่ากับ "True"และเป็น false หากสตริงที่ระบุเท่ากับ "False".
