## EnumParseHelper โครงสร้าง

คลาสช่วยเหลือที่ให้ฟังก์ชันการแปลงการแทนสตริงของค่าคงที่ enum ให้เป็นค่าของ enum ที่เทียบเท่า.

```cpp
template<class E,class G,class Guard>class EnumParseHelper
```

### พารามิเตอร์เทมเพลต

| Parameter | Description |
| --- | --- |
| E | ประเภทของ enum ที่เมธอดของคลาสทำงานด้วย |
| G | อาร์กิวเมนต์รูปแบบที่สองของ [System::Enum](../enum/) ที่จะใช้ |
| Guard | อาร์กิวเมนต์เทมเพลตแบบฟอร์มเพื่อเลือกอัลกอริทึมการพาร์เซที่ใช้ได้ |

## เมธอด

| Method | Description |
| --- | --- |
| static E [Parse](./parse/)(const [String](../string/)\&, **bool**) | แปลงสตริงที่ระบุให้เป็นค่าคงที่ enum ที่เทียบเท่า |
