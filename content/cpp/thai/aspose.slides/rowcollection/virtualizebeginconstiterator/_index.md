```cpp
virtualized_iterator * Aspose::Slides::RowCollection::virtualizeBeginConstIterator() const override
```


### ค่าที่ส่งกลับ

iterator ที่ชี้ไปยังองค์ประกอบแรก (ถ้ามี)ของอินสแตนซ์ที่มีการกำหนด const ของคอลเลกชัน ให้การทำงานของ const iterator กับองค์ประกอบแรกของคอนเทนเนอร์.
