## BlobManagementOptions::set_PresentationLockingBehavior(Aspose::Slides::PresentationLockingBehavior) เมธอด

คุณสมบัตินี้กำหนดว่าตัวอย่างของคลาส [Presentation](../../presentation/) สามารถเป็นเจ้าของแหล่งข้อมูล - ไฟล์หรือสตรีมระหว่างอายุการใช้งานของตัวอย่างได้หรือไม่ หากตัวอย่างเป็นเจ้าของ มันจะล็อกแหล่งข้อมูล สิ่งนี้ช่วยปรับปรุงการใช้หน่วยความจำและประสิทธิภาพขณะทำงานกับ BLOBs แต่แหล่งข้อมูล (สตรีมหรือไฟล์) ไม่สามารถเปลี่ยนแปลงได้ระหว่างอายุการใช้งานของ [Presentation](../../presentation/)'s instance lifetime.

```cpp
void Aspose::Slides::BlobManagementOptions::set_PresentationLockingBehavior(Aspose::Slides::PresentationLockingBehavior value) override
```
