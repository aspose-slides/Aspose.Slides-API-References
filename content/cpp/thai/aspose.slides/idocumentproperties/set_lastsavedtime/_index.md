## IDocumentProperties::set_LastSavedTime(System::DateTime) method


คืนค่าวันที่การนำเสนอถูกแก้ไขครั้งสุดท้าย. ค่าจะอยู่ในรูปแบบ UTC.P อ่านอย่างเดียวในกรณีของ Presentation.DocumentProperties (เนื่องจากจะถูกอัปเดตภายในขณะกระบวนการบันทึกวัตถุ [IPresentation](../../ipresentation/)). สามารถเปลี่ยนได้ผ่านอินสแตนซ์ [DocumentProperties](../../documentproperties/) ที่ส่งกลับโดยเมธอด [IPresentationInfo::ReadDocumentProperties](../../ipresentationinfo/readdocumentproperties/) โปรดดูตัวอย่างในสรุปเมธอด [IPresentationInfo::UpdateDocumentProperties](../../ipresentationinfo/updatedocumentproperties/).

```cpp
virtual void Aspose::Slides::IDocumentProperties::set_LastSavedTime(System::DateTime value)=0
```
