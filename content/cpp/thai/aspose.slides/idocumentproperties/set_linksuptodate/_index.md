## IDocumentProperties::set_LinksUpToDate(bool) เมธอด

ระบุว่าลิงก์ไฮเปอร์ลิงก์ในเอกสารเป็นปัจจุบันหรือไม่. ตั้งค่าองค์ประกอบนี้เป็น **true** เพื่อระบุว่าลิงก์ไฮเปอร์ลิงก์ได้รับการอัปเดต. ตั้งค่าองค์ประกอบนี้เป็น **false** เพื่อระบุว่าลิงก์ไฮเปอร์ลิงก์ล้าสมัย. เขียนเป็น **bool**.

```cpp
virtual void Aspose::Slides::IDocumentProperties::set_LinksUpToDate(bool value)=0
```
