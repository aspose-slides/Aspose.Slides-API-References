## IDocumentProperties::set_HyperlinksChanged(bool) เมธอด

ระบุว่ามีการอัปเดตไฮเปอร์ลิงก์หนึ่งหรือหลายรายการในส่วนนี้โดยผู้ผลิตเท่านั้น การเปิดเอกสารโดยผู้ผลิตคนถัดไปจะต้องอัปเดตความสัมพันธ์ของไฮเปอร์ลิงก์ด้วยไฮเปอร์ลิงก์ใหม่ที่ระบุในส่วนนี้ เขียน **bool**.

```cpp
virtual void Aspose::Slides::IDocumentProperties::set_HyperlinksChanged(bool value)=0
```
