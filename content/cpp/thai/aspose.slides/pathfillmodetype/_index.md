## PathFillModeType enum

Specifies the manner in which a path should be filled

```cpp
enum class PathFillModeType : uint8_t
```

### Values

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| None | 0 | ไม่มีการเติมเส้นทาง ค่านี้ระบุว่าเส้นที่สอดคล้องควรไม่มีการเติมสีเลย. |
| Normal | 1 | การเติมเส้นทางแบบปกติ ค่านี้ระบุว่าเส้นที่สอดคล้องควรมีสีที่มีเฉดสีปกติถูกนำไปใช้กับ it\\u2019s fill. |
| Lighten | 2 | การเติมเส้นทางแบบทำให้สว่างขึ้น ค่านี้ระบุว่าเส้นที่สอดคล้องควรมีสีที่มีเฉดสีอ่อนถูกนำไปใช้กับ it\\u2019s fill. |
| LightenLess | 3 | การเติมเส้นทางแบบทำให้สว่างน้อยลง ค่านี้ระบุว่าเส้นที่สอดคล้องควรมีสีที่มีเฉดสีอ่อนกว่านั้นเล็กน้อยถูกนำไปใช้กับ it\\u2019s fill. |
| Darken | 4 | การเติมเส้นทางแบบทำให้มืดลง ค่านี้ระบุว่าเส้นที่สอดคล้องควรมีสีที่มีเฉดสีเข้มถูกนำไปใช้กับ it\\u2019s fill. |
| DarkenLess | 5 | การเติมเส้นทางแบบทำให้มืดน้อยลง ค่านี้ระบุว่าเส้นที่สอดคล้องควรมีสีที่มีเฉดสีเข้มกว่าเล็กน้อยถูกนำไปใช้กับ it\\u2019s fill. |
