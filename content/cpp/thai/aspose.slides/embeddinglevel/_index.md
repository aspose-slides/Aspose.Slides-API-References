## EmbeddingLevel enum

แสดงสิทธิ์การใช้งานสำหรับการฝังฟอนต์

```cpp
enum class EmbeddingLevel : uint16_t
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| Installable | 0 | [Fonts](../fonts/) กับการตั้งค่านี้ระบุว่าพวกมันสามารถฝังและติดตั้งอย่างถาวรบนระบบระยะไกลโดยแอปพลิเคชัน ผู้ใช้ของระบบระยะไกลจะได้รับสิทธิ์ ภาระผูกพันและใบอนุญาตที่เหมือนกันสำหรับฟอนต์นั้นเช่นเดียวกับผู้ซื้อดั้งเดิมของฟอนต์ และต้องปฏิบัติตามข้อตกลงการใช้งานสุดท้าย ลิขสิทธิ์ สิทธิบัตรการออกแบบ และ/หรือเครื่องหมายการค้าเดียวกับผู้ซื้อดั้งเดิม |
| Restricted | 2 | [Fonts](../fonts/) ที่มีบิตนี้ตั้งค่าไว้เท่านั้นต้องไม่ถูกแก้ไข ฝังหรือแลกเปลี่ยนในลักษณะใดก็ตามโดยไม่ได้รับอนุญาตจากผู้ถือสิทธิ์กฎหมายก่อน |
| PreviewPrint | 4 | เมื่อบิตนี้ตั้งค่าไว้ ฟอนต์สามารถฝังและโหลดชั่วคราวบนระบบระยะไกล เอกสารที่มีฟอนต์ Preview & Print ต้องเปิดเป็น "read-only;" ไม่สามารถแก้ไขเอกสารได้ |
| Editable | 8 | เมื่อบิตนี้ตั้งค่าไว้ ฟอนต์สามารถฝังได้แต่ต้องติดตั้งแบบชั่วคราวบนระบบอื่นเท่านั้น แตกต่างจากฟอนต์ Preview & Print เอกสารที่มีฟอนต์ Editable สามารถเปิดเพื่ออ่านได้ การแก้ไขได้รับอนุญาต และการเปลี่ยนแปลงสามารถบันทึกได้ |
| NoSubsetting | 256 | เมื่อบิตนี้ตั้งค่าไว้ ฟอนต์จะไม่สามารถทำการ subset ก่อนการฝังได้ ข้อจำกัดการฝังอื่นที่ระบุในบิต 0-3 และ 9 ก็จะมีผลเช่นกัน |
| BitmapOnly | 512 | เมื่อบิตนี้ตั้งค่าไว้ จะสามารถฝังเฉพาะบิตแมพที่อยู่ในฟอนต์ได้เท่านั้น ไม่สามารถฝังข้อมูลเส้นขอบได้ หากฟอนต์ไม่มีบิตแมพใด ๆ จะถือว่าฟอนต์ไม่สามารถฝังได้และบริการการฝังจะล้มเหลว |
