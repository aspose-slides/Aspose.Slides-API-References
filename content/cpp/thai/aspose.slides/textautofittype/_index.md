## TextAutofitType enum

แสดงโหมดการปรับขนาดข้อความอัตโนมัติ.

```cpp
enum class TextAutofitType : int8_t
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| NotDefined | -1 | ไม่ได้กำหนด. |
| None | 0 | ไม่มีการปรับขนาดอัตโนมัติ. |
| Normal | 1 | การปรับขนาดอัตโนมัติแบบปกติ. ขนาดฟอนต์และระยะห่างระหว่างบรรทัดจะถูกลดลงเพื่อให้พอดีกับรูปร่าง. |
| Shape | 2 | [Shape](../shape/) การปรับขนาดอัตโนมัติ. [Shape](../shape/) ขนาดจะถูกเปลี่ยนเพื่อให้พอดีกับข้อความ. |
