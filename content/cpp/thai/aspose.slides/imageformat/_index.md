## ImageFormat enum

Represents the file format of the image.

```cpp
enum class ImageFormat
```

### Values

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| MemoryBmp | 0 | ระบุรูปแบบของบิตแมพในหน่วยความจำ. |
| Bmp | 1 | ระบุรูปแบบภาพบิตแมพ (BMP). |
| Emf | 2 | ระบุรูปแบบภาพเมตาไฟล์ที่ขยาย (EMF). |
| Wmf | 3 | ระบุรูปแบบภาพเมตาไฟล์ของ Windows (WMF). |
| Gif | 4 | ระบุรูปแบบภาพ Graphics Interchange Format (GIF). |
| Jpeg | 5 | ระบุรูปแบบภาพ Joint Photographic Experts Group (JPEG). |
| Png | 6 | ระบุรูปแบบภาพ W3C Portable Network Graphics (PNG). |
| Tiff | 7 | ระบุรูปแบบภาพ Tagged Image File Format (TIFF). |
| Exif | 8 | ระบุรูปแบบไฟล์ภาพที่แลกเปลี่ยนได้ (Exif). |
