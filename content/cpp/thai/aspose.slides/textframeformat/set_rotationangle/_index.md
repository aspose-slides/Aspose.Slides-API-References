## TextFrameFormat::set_RotationAngle(float) เมธอด


ระบุการหมุนแบบกำหนดเองที่จะถูกนำไปใช้กับข้อความภายในกล่องขอบเขต หากไม่ระบุ จะใช้การหมุนของรูปร่างที่แนบมานั้น หากระบุแล้ว การหมุนนี้จะถูกนำไปใช้แยกจากรูปร่าง กล่าวคือ รูปร่างอาจมีการหมุนที่ใช้ร่วมกับข้อความที่มีการหมุนของตนเอง การหมุนของข้อความที่แสดงผลที่ได้สรุปจากคุณสมบัตินี้และประเภทแนวตั้งที่กำหนดไว้ล่วงหน้าในคุณสมบัติ TextVerticalType เขียนเป็น **float**.

```cpp
void Aspose::Slides::TextFrameFormat::set_RotationAngle(float value) override
```

## หมายเหตุ

พิจารณากรณีที่รูปร่างมีการหมุน 90 องศาตามเข็มนาฬิกา หากเพิ่มการหมุน -90 องศาตรงข้ามเข็มนาฬิกาให้กับข้อความในรูปร่างนั้น ผลลัพธ์คือรูปร่างจะดูเหมือนถูกหมุน แต่ข้อความภายในจะดูเหมือนไม่ได้รับการหมุนเลย.
