## PathCommandType enum

แทนคำสั่งกราฟิกของเส้นทาง

```cpp
enum class PathCommandType : uint8_t
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| Close | 0 | ปิดเส้นทางเรขาคณิต |
| MoveTo | 1 | กำหนดตำแหน่งจุดถัดไปของเส้นทางเรขาคณิต |
| LineTo | 2 | เพิ่มเส้นตรงลงในเส้นทางเรขาคณิต |
| ArcTo | 3 | เพิ่มส่วนโค้งที่ระบุลงในเส้นทางเรขาคณิต. |
| QuadBezierTo | 4 | เพิ่มเส้นโค้งเบเซียร์ระดับสองลงในเส้นทางเรขาคณิต |
| CubicBezierTo | 5 | เพิ่มเส้นโค้งเบเซียร์ระดับสามลงในเส้นทางเรขาคณิต |
