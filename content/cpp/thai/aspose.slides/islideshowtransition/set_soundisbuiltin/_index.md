## ISlideShowTransition::set_SoundIsBuiltIn(bool) เมธอด


ระบุว่าเสียงนี้เป็นเสียงแบบในตัวหรือไม่ หากแอตทริบิวต์นี้ตั้งค่าเป็น true แอปพลิเคชันที่สร้างจะได้รับการแจ้งให้ตรวจสอบแอตทริบิวต์ name ที่ระบุสำหรับเสียงนี้ในรายการเสียงแบบในตัวของมันและจากนั้นสามารถแสดงชื่อหรือ UI ที่กำหนดเองตามความต้องการ เขียน **bool**.

```cpp
virtual void Aspose::Slides::ISlideShowTransition::set_SoundIsBuiltIn(bool value)=0
```
