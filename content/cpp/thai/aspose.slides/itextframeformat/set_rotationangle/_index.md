## ITextFrameFormat::set_RotationAngle(float) เมธอด


ระบุการหมุนแบบกำหนดเองที่นำไปใช้กับข้อความภายในกล่องขอบเขต หากไม่ได้ระบุ การหมุนของรูปร่างที่แนบมาจะถูกใช้ หากระบุแล้ว การหมุนนี้จะถูกนำไปใช้โดยอิสระจากรูปร่าง กล่าวคือ รูปร่างอาจมีการหมุนเพิ่มขึ้นพร้อมกับข้อความเองที่มีการหมุน การวนค่าอัตราการหมุนของข้อความที่ได้จากคุณสมบัตินี้และประเภทแนวตั้งที่กำหนดไว้ล่วงหน้าในคุณสมบัติ TextVerticalType เขียนเป็น **float**.

```cpp
virtual void Aspose::Slides::ITextFrameFormat::set_RotationAngle(float value)=0
```

## หมายเหตุ


พิจารณากรณีที่รูปร่างมีการหมุน 90 องศาตามเข็มนาฬิกา นอกจากนี้ข้อความภายในยังมีการหมุน -90 องศาทวนเข็มนาฬิกา ส่งผลให้รูปร่างที่ได้ดูเหมือนมีการหมุน แต่ข้อความภายในดูเหมือนยังไม่ได้หมุนเลย
