## IBackdrop3DScene::set_UpVector(System::ArrayPtr\<float\>) เมธอด

ตั้งค่าเวกเตอร์ที่เป็นตัวแทนของด้านบน. เพื่อความชัดเจนยิ่งขึ้น, แอตทริบิวต์นี้กำหนดเวกเตอร์ที่เป็นตัวแทนของด้านบนสัมพันธ์กับหน้าของพื้นหลัง. เวกเตอร์แทนด้วยอาเรย์ของค่าตัวเลข float 3 ตัวที่กำหนดพิกัด X, Y และ Z. เขียน **float**[].

virtual void Aspose::Slides::IBackdrop3DScene::set_UpVector(System::ArrayPtr<float> value)=0
