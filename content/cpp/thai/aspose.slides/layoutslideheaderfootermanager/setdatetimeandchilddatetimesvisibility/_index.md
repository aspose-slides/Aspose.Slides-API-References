## LayoutSlideHeaderFooterManager::SetDateTimeAndChildDateTimesVisibility(bool) เมธอด

เปลี่ยนแปลงการมองเห็นของ placeholder วันที่และเวลาในสไลด์เค้าโครงและ placeholder ของวันที่และเวลาในสไลด์ลูกทั้งหมด. placeholder ลูกหมายถึง placeholder ที่อยู่บนสไลด์ที่ขึ้นอยู่. สไลด์ที่ขึ้นอยู่จะใช้และพึ่งพาสไลด์เค้าโครง.

```cpp
void Aspose::Slides::LayoutSlideHeaderFooterManager::SetDateTimeAndChildDateTimesVisibility(bool isVisible) override
```
