## IBlobManagementOptions::set_MaxBlobsBytesInMemory(uint64_t) เมธอด

กำหนดขนาดรวมสูงสุด (เป็นไบต์) ที่ BLOB ทั้งหมดอาจใช้ในหน่วยความจำ โดยค่าเริ่มต้น BLOB ทั้งหมดจะถูกโหลดเข้าสู่หน่วยความจำ; เพียงเมื่อเกินขีดจำกัดนี้จึงใช้กลไกทางเลือก (เช่น ไฟล์ชั่วคราว) การเก็บ BLOB ในหน่วยความจำจะเพิ่มประสิทธิภาพสูงสุดแต่ก็อาจทำให้ใช้หน่วยความจำมากมาก ใช้คุณสมบัตินี้เพื่อปรับพฤติกรรมให้สอดคล้องกับสภาพแวดล้อมหรือความต้องการของคุณ.

```cpp
virtual void Aspose::Slides::IBlobManagementOptions::set_MaxBlobsBytesInMemory(uint64_t value)=0
```

## หมายเหตุ

ค่าตัวนี้จะถูกละเว้นหาก [IBlobManagementOptions::set_IsTemporaryFilesAllowed](../set_istemporaryfilesallowed/) ถูกตั้งค่าเป็น false เนื่องจากหน่วยความจำจะเป็นตำแหน่งจัดเก็บเดียวที่มีอยู่และการจำกัดการใช้ BLOB ในหน่วยความจำจะไม่มีผล.

ค่าตั้งต้นคือ 629,145,600 ไบต์ (600 MB).

คุณสามารถตั้งค่าคุณสมบัตินี้เป็นศูนย์ได้ แต่ยังจะมีการสงวนหน่วยความจำขั้นต่ำเล็กน้อยอยู่.
