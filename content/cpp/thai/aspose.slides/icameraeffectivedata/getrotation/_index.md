## ICameraEffectiveData::GetRotation() method


การหมุนถูกกำหนดโดยการใช้พิกัดละติจูด, พิกัดลองจิจูด, และการหมุนรอบแกนเป็นพิกัดละติจูดและลองจิจูด. ส่วนแรกในอาเรย์ผลลัพธ์ - ละติจูด, ส่วนที่สอง - ลองจิจูด, ส่วนที่สาม - การหมุน. คืนค่า null หากไม่มีการกำหนดการหมุน.

```cpp
virtual System::ArrayPtr<float> Aspose::Slides::ICameraEffectiveData::GetRotation()=0
```


### ค่าที่ส่งกลับ

Array of rotation values as **float**[].
