```cpp

```

### ค่าที่ส่งคืน

iterator ที่ชี้ไปข้างหลังองค์ประกอบสุดท้าย (ถ้ามี)ของอินสแตนซ์ที่กำหนด const ของคอลเลกชัน ให้การทำงานของ const iterator ไปยังจุดสิ้นสุดของคอนเทนเนอร์.

อ็อบเจ็กต์ iterator ที่สร้างใหม่.
