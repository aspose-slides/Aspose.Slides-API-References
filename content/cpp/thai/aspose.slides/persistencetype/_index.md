## PersistenceType enum

ระบุวิธีที่ใช้เก็บคุณสมบัติของคอนโทรล ActiveX.

```cpp
enum class PersistenceType
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| NotDefined | -1 | รหัสการคงสภาพไม่ได้ระบุ. |
| PersistPropertyBag | 0 | ระบุว่าคอนโทรล ActiveX จะถูกคงสภาพโดยใช้การคงสภาพแบบ property-bag. การคงสภาพแบบ property-bag เก็บคอนโทรล ActiveX โดยใช้คอลเลกชันของคู่ชื่อและค่า ซึ่งระบุข้อมูลที่คงสภาพโดยคอนโทรล ActiveX. |
| PersistStream | 1 | ระบุว่าคอนโทรล ActiveX จะถูกคงสภาพโดยใช้การคงสภาพแบบ stream-based ซึ่งไม่รองรับการเริ่มต้นคอนโทรล ActiveX ไปยังสถานะเริ่มต้น. |
| PersistStreamInit | 2 | ระบุว่าคอนโทรล ActiveX จะถูกคงสภาพโดยใช้การคงสภาพแบบ stream-based ที่รองรับการเริ่มต้นคอนโทรล ActiveX ไปยังสถานะเริ่มต้น. |
| PersistStorage | 3 | ระบุว่าคอนโทรล ActiveX จะถูกคงสภาพโดยใช้การคงสภาพแบบ storage-based. |
