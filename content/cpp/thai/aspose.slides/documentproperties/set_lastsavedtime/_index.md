## DocumentProperties::set_LastSavedTime(System::DateTime) เมธอด

ส่งคืนวันที่การนำเสนอถูกแก้ไขครั้งสุดท้าย. ค่าจะอยู่ในรูปแบบ UTC. แบบอ่านอย่างเดียวในกรณีของ [Presentation::get_DocumentProperties](../../presentation/get_documentproperties/) (เพราะจะถูกอัพเดตภายในระหว่างกระบวนการบันทึกวัตถุ [IPresentation](../../ipresentation/)). สามารถเปลี่ยนได้ผ่านอินสแตนซ์ [DocumentProperties](../) ที่ส่งกลับโดยเมธอด [IPresentationInfo::ReadDocumentProperties](../../ipresentationinfo/readdocumentproperties/) โปรดดูตัวอย่างในสรุปเมธอด [IPresentationInfo::UpdateDocumentProperties](../../ipresentationinfo/updatedocumentproperties/).

```cpp
void Aspose::Slides::DocumentProperties::set_LastSavedTime(System::DateTime value) override
```
