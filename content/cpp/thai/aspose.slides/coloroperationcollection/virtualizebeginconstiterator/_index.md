## ColorOperationCollection::virtualizeBeginConstIterator() const เมธอด

รับอ็อบเจ็กต์ iterator ที่ชี้ไปยังองค์ประกอบแรก (ถ้ามี) ของอินสแตนซ์ที่เป็น const-qualified ของคอลเลกชัน.

```cpp
virtualized_iterator * Aspose::Slides::ColorOperationCollection::virtualizeBeginConstIterator() const override
```

### ค่าที่ส่งกลับ

อ็อบเจ็กต์ iterator ที่ชี้ไปยังองค์ประกอบแรก (ถ้ามี) ของอินสแตนซ์ที่เป็น const-qualified ของคอลเลกชัน ให้การทำงานของ const iterator สำหรับองค์ประกอบแรกของคอนเทนเนอร์.

อ็อบเจ็กต์ iterator ที่สร้างใหม่.
