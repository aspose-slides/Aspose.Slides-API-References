## LoadOptions::get_OnlyLoadDocumentProperties() เมธอด


คุณสมบัตินี้มีความหมายเมื่อไฟล์งานนำเสนอต้องการรหัสผ่าน. ค่า true หมายความว่าเฉพาะคุณสมบัติของเอกสารเท่านั้นที่ต้องโหลดจากไฟล์งานนำเสนอที่เข้ารหัสและต้องละเว้นรหัสผ่าน. ค่า false หมายความว่าต้องโหลดงานนำเสนอที่เข้ารหัสทั้งหมดโดยใช้รหัสผ่านที่ถูกต้อง. หากงานนำเสนอไม่ได้ถูกเข้ารหัส ค่าของคุณสมบัติก็จะถูกละเว้นเสมอ. หากคุณสมบัติของเอกสารในไฟล์ที่เข้ารหัสไม่ได้เป็นสาธารณะและค่าของคุณสมบัตเป็น true แล้วคุณสมบัติของเอกสารจะไม่สามารถโหลดได้และจะเกิดข้อยกเว้น. อ่าน **bool**.

```cpp
bool Aspose::Slides::LoadOptions::get_OnlyLoadDocumentProperties() override
```
