## LoadOptions::set_BlobManagementOptions(System::SharedPtr\<IBlobManagementOptions\>) เมธอด

แสดงตัวเลือกที่สามารถใช้ในการจัดการพฤติกรรมการจัดการ Binary Large Objects (BLOBs) เช่น การใช้ไฟล์ชั่วคราวหรือจำนวนไบต์สูงสุดของ BLOBs ในหน่วยความจำ ตัวเลือกเหล่านี้มีจุดประสงค์เพื่อกำหนดอัตราส่วนการทำงานที่ดีที่สุดต่อการใช้หน่วยความจำสำหรับสภาพแวดล้อมหรือความต้องการที่เฉพาะเจาะจง

```cpp
void Aspose::Slides::LoadOptions::set_BlobManagementOptions(System::SharedPtr<IBlobManagementOptions> value) override
```

## หมายเหตุ

Binary Large Object (BLOB) คือข้อมูลไบนารีที่เก็บเป็นเอกลักษณ์เดียว - เช่น BLOB สามารถเป็นไฟล์เสียง, วิดีโอ หรือการนำเสนอเอง
