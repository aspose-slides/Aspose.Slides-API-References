## LoadOptions::set_OnlyLoadDocumentProperties(bool) เมธอด


คุณสมบัตินี้มีความหมายเมื่อไฟล์งานนำเสนอถูกป้องกันด้วยรหัสผ่าน ค่า true หมายถึงจะโหลดเฉพาะคุณสมบัติของเอกสารจากไฟล์งานนำเสนอที่เข้ารหัสและจะละเว้นรหัสผ่าน ค่า false หมายถึงจะโหลดงานนำเสนอที่เข้ารหัสทั้งหมดโดยใช้รหัสผ่านที่ถูกต้อง หากงานนำเสนอไม่ได้เข้ารหัสแล้วค่าคุณสมบัติก็จะถูกละเว้นเสมอ หากคุณสมบัติของเอกสารในไฟล์ที่เข้ารหัสไม่ได้เป็นสาธารณะและค่าคุณสมบัติเป็น true แล้วคุณสมบัติของเอกสารจะไม่สามารถโหลดได้และจะเกิดข้อยกเว้นขึ้น เขียน **bool**.

```cpp
void Aspose::Slides::LoadOptions::set_OnlyLoadDocumentProperties(bool value) override
```
