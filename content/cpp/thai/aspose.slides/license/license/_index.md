## License::License() คอนสตรัคเตอร์

เริ่มต้นอินสแตนซ์ใหม่ของคลาสนี้.

```cpp
Aspose::Slides::License::License()
```

## หมายเหตุ

ในตัวอย่างนี้ จะพยายามค้นหาไฟล์ใบอนุญาตชื่อ MyLicense.lic ในโฟลเดอร์ที่ประกอบส่วนประกอบ, ในโฟลเดอร์ที่มี calling assembly, ในโฟลเดอร์ของ entry assembly และจากนั้นในทรัพยากรที่ฝังอยู่ของ calling assembly.

```cpp
auto license = MakeObject<License>();
license->SetLicense(u"MyLicense.lic");
```
