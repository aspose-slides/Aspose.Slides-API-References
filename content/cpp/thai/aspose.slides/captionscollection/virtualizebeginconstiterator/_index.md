## CaptionsCollection::virtualizeBeginConstIterator() const method

รับ iterator ที่ชี้ไปยังองค์ประกอบแรก (ถ้ามี)ของ const-qualified ของคอลเลกชัน.

```cpp
virtualized_iterator * Aspose::Slides::CaptionsCollection::virtualizeBeginConstIterator() const override
```

### ค่าที่ส่งกลับ

Iterator ที่ชี้ไปยังองค์ประกอบแรก (ถ้ามี)ของ const-qualified ของคอลเลกชัน ให้การนำเสนอ const iterator สำหรับองค์ประกอบแรกของคอนเทนเนอร์.

อ็อบเจ็กต์ iterator ที่สร้างขึ้นใหม่.
