## FillType enum

กำหนดประเภทการเติมภายในของวัตถุภาพต่าง ๆ

```cpp
enum class FillType : int8_t
```

### Values

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| NotDefined | -1 | ประเภทการเติมยังไม่ได้กำหนด. |
| NoFill | 0 | ไม่มีการเติม. |
| Solid | 1 | เติมด้วยสีทึบ. |
| Gradient | 2 | การเติมเป็นแบบไล่สี. |
| Pattern | 3 | ใช้ลายซ้ำเพื่อเติมวัตถุ. |
| Picture | 4 | ใช้รูปภาพเดียวเพื่อเติมวัตถุ. |
| Group | 5 | วัตถุภาพสืบทอดคุณสมบัติการเติมจากกลุ่ม. |
