## IProtectionManager::get_IsOnlyDocumentPropertiesLoaded() เมธอด


คุณสมบัตินี้มีเหตุผลเมื่อไฟล์พรีเซนเทชันถูกป้องกันด้วยรหัสผ่านและคุณสมบัติของเอกสารในไฟล์นี้เป็นสาธารณะ. ค่า true หมายถึงว่าจะโหลดเฉพาะคุณสมบัติของเอกสารจากไฟล์พรีเซนเทชันที่เข้ารหัสโดยไม่ใช้รหัสผ่าน. ค่า false หมายถึงว่าจะโหลดพรีเซนเทชันที่เข้ารหัสทั้งหมดโดยใช้รหัสผ่านที่ถูกต้อง ไม่ได้โหลดเฉพาะคุณสมบัติของเอกสารเท่านั้น. หากพรีเซนเทชันไม่ได้ถูกเข้ารหัส ค่า property จะเป็น false เสมอ. หากคุณสมบัติของเอกสารในไฟล์ที่เข้ารหัสไม่เป็นสาธารณะ ค่า property จะเป็น false เสมอ. หาก PresentationEx.EncryptDocumentProperties เป็น true ค่า property IsOnlyDocumentPropertiesLoaded จะเป็น false เสมอ. อ่านอย่างเดียว **bool**.

```cpp
virtual bool Aspose::Slides::IProtectionManager::get_IsOnlyDocumentPropertiesLoaded()=0
```
