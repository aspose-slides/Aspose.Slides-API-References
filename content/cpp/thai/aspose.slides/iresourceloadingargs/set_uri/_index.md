## IResourceLoadingArgs::set_Uri(System::String) เมธอด

URI ของทรัพยากรที่ใช้สำหรับการดาวน์โหลดถ้า [IResourceLoadingCallback::ResourceLoading()](../../iresourceloadingcallback/resourceloading/) คืนค่า [ResourceLoadingAction::Default](../../resourceloadingaction/). โดยเริ่มต้นจะถูกตั้งค่าเป็น URI ดั้งเดิมของทรัพยากร แต่สามารถกำหนดใหม่เป็นค่าใด ๆ ได้

```cpp
virtual void Aspose::Slides::IResourceLoadingArgs::set_Uri(System::String value)=0
```
