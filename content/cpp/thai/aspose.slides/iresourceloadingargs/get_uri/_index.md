## IResourceLoadingArgs::get_Uri() เมธอด

URI ของทรัพยากรที่ใช้สำหรับดาวน์โหลดหาก [IResourceLoadingCallback::ResourceLoading()](../../iresourceloadingcallback/resourceloading/) คืนค่า [ResourceLoadingAction::Default](../../resourceloadingaction/). โดยเริ่มต้นจะถูกตั้งเป็น URI ดั้งเดิมของทรัพยากร แต่สามารถกำหนดค่าใหม่เป็นค่าใดก็ได้.

```cpp
virtual System::String Aspose::Slides::IResourceLoadingArgs::get_Uri()=0
```
