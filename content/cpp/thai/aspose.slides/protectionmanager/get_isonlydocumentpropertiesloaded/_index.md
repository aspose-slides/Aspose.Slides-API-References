## ProtectionManager::get_IsOnlyDocumentPropertiesLoaded() เมธอด

คุณสมบัตินี้มีความหมาย หากไฟล์การนำเสนอถูกป้องกันด้วยรหัสผ่านและคุณสมบัติของเอกสารของไฟล์นี้เป็นสาธารณะ ค่าเป็น true หมายถึงจะโหลดเฉพาะคุณสมบัติของเอกสารจากไฟล์การนำเสนอที่เข้ารหัสโดยไม่ใช้รหัสผ่าน ค่าเป็น false หมายถึงจะโหลดการนำเสนอที่เข้ารหัสทั้งหมดโดยใช้รหัสผ่านที่ถูกต้อง ไม่ได้โหลดเฉพาะคุณสมบัติของเอกสารเท่านั้น หากการนำเสนอไม่ได้ถูกเข้ารหัสค่าของคุณสมบัติจะแม่นั้นเป็น false หากคุณสมบัติของเอกสารของไฟล์ที่เข้ารหัสไม่เป็นสาธารณะค่าของคุณสมบัติจะแม่นั้นเป็น false หาก Presentation.EncryptDocumentProperties เป็น true แล้วค่า IsOnlyDocumentPropertiesLoaded จะเป็น false เสมอ อ่านอย่างเดียว **bool**.

```cpp
bool Aspose::Slides::ProtectionManager::get_IsOnlyDocumentPropertiesLoaded() override
```
