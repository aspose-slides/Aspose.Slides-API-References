## ILoadOptions::set_OnlyLoadDocumentProperties(bool) เมธอด

คุณสมบัตินี้มีความหมายถ้าไฟล์งานนำเสนอถูกป้องกันด้วยรหัสผ่าน. ค่าที่เป็น true หมายถึงจะต้องโหลดเฉพาะคุณสมบัติของเอกสารจากไฟล์งานนำเสนอที่เข้ารหัสและต้องละเลยรหัสผ่าน. ค่าที่เป็น false หมายถึงจะต้องโหลดงานนำเสนอที่เข้ารหัสทั้งหมดโดยใช้รหัสผ่านที่ถูกต้อง. หากงานนำเสนอไม่ได้ถูกเข้ารหัสค่าคุณสมบัติจะถูกละเลยเสมอ. หากคุณสมบัติของเอกสารในไฟล์ที่เข้ารหัสไม่เป็นสาธารณะและค่าคุณสมบัติเป็น true จะไม่สามารถโหลดคุณสมบัติของเอกสารได้และจะมีการโยนข้อยกเว้น. เขียน **bool**.

```cpp
virtual void Aspose::Slides::ILoadOptions::set_OnlyLoadDocumentProperties(bool value)=0
```
