## ILoadOptions::get_OnlyLoadDocumentProperties() เมธอด

คุณสมบัตินี้มีความหมาย หากไฟล์งานนำเสนอถูกตั้งรหัสผ่าน ค่าที่เป็น true หมายความว่าจะต้องโหลดเฉพาะคุณสมบัติของเอกสารจากไฟล์งานนำเสนอที่เข้ารหัสและละเว้นรหัสผ่าน ค่าที่เป็น false หมายความว่าจะต้องโหลดไฟล์งานนำเสนอที่เข้ารหัสทั้งหมดโดยใช้รหัสผ่านที่ถูกต้อง หากไฟล์งานนำเสนอไม่ได้เข้ารหัส ค่าคุณสมบัติก็จะถูกละเว้นเสมอ หากคุณสมบัติของเอกสารในไฟล์ที่เข้ารหัสไม่ได้เปิดเผยและค่าคุณสมบัตเป็น true แล้วคุณสมบัติของเอกสารจะไม่สามารถโหลดได้และจะเกิดข้อยกเว้น อ่าน **bool**.

```cpp
virtual bool Aspose::Slides::ILoadOptions::get_OnlyLoadDocumentProperties()=0
```
