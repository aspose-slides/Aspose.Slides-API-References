## BulletFormat::set_Height(float) เมธอด

กำหนดความสูงของสัญลักษณ์หัวข้อของย่อหน้าโดยไม่มีการสืบทอด ค่าของ std::numeric_limits<float>::quiet_NaN() กำหนดให้สัญลักษณ์หัวข้อสืบทอดความสูงจากส่วนแรกในย่อหน้า เขียน **float**.

```cpp
void Aspose::Slides::BulletFormat::set_Height(float value) override
```

## หมายเหตุ

ค่าความสูงที่เป็นค่าติดลบหมายถึงความสูงที่ระบุเป็นหน่วยจุด และค่าที่เป็นบวกหมายถึงความสูงเป็นเปอร์เซ็นต์ของข้อความโดยรอบ.
