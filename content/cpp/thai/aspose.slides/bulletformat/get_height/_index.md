## BulletFormat::get_Height() เมธอด

คืนค่าความสูงของสัญลักษณ์หัวข้อของย่อหน้าที่ไม่มีการสืบทอด. ค่า std::numeric_limits<float>::quiet_NaN() ระบว่าหัวข้อสืบทอดความสูงจากส่วนแรกของย่อหน้า. อ่าน **float**.

```cpp
float Aspose::Slides::BulletFormat::get_Height() override
```

## หมายเหตุ

ค่าความสูงเป็นค่าลบหมายความว่าความสูงกำหนดเป็นหน่วยจุดและค่าบวกหมายความว่าความสูงเป็นเปอร์เซ็นต์ของข้อความโดยรอบ.
