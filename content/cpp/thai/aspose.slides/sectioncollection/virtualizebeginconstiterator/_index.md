## SectionCollection::virtualizeBeginConstIterator() const เมธอด

รับ iterator ที่ชี้ไปยังองค์ประกอบแรก (ถ้ามี) ของอินสแตนซ์ที่กำหนดให้เป็น const ของคอลเลกชัน

```cpp
virtualized_iterator * Aspose::Slides::SectionCollection::virtualizeBeginConstIterator() const override
```

### ค่าที่คืน

อิเทอเรเตอร์ที่ชี้ไปยังองค์ประกอบแรก (ถ้ามี) ของอินสแตนซ์ที่กำหนดให้เป็น const ของคอลเลกชัน ให้การทำงานของ const iterator สำหรับองค์ประกอบแรกของคอนเทนเนอร์

อ็อบเจกต์ iterator ที่สร้างใหม่
