## LineSketchType enum

ระบุประเภทสเก็ตช์หรือเอฟเฟกต์ที่กำหนดให้กับรูปร่าง

```cpp
enum class LineSketchType
```

### Values

| ชื่อ | ค่า | รายละเอียด |
| --- | --- | --- |
| NotDefined | -1 | ระบุว่ารูปร่างมีเอฟเฟกต์ Sketch ที่ไม่ได้กำหนดค่า |
| None | 0 | ระบุว่ารูปร่างไม่มีเอฟเฟกต์ Sketch. นี้เทียบเท่ากับคุณสมบัตินี้ว่างเปล่า |
| Curved | 1 | ระบุว่ารูปร่างมีเอฟเฟกต์ Curved ซึ่งจะทำให้ขอบของรูปร่างแต่ละด้านกลายเป็นโค้งใหญ่ที่อ่อนโยน |
| Freehand | 2 | ระบุว่ารูปร่างมีเอฟเฟกต์ Freehand ซึ่งมีลักษณะคล้ายกับเส้นที่วาดอย่างไม่สมบูรณ์ที่สุด |
| Scribble | 3 | ระบุว่ารูปร่างมีเอฟเฟกต์ Scribble ซึ่งมีการสั่นไหวเกินจริงเสมือนถูกวาดอย่างเลอะเทอะโดยเจตนา |
