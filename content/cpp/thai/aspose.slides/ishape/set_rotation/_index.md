## IShape::set_Rotation(float) เมธอด


กำหนดจำนวนองศาที่รูปร่างที่ระบุจะหมุนรอบแกน z ค่าบวกบ่งบอกการหมุนตามเข็มนาฬิกา; ค่าลบบ่งบอกการหมุนทวนเข็มนาฬิกา เขียนเป็น **float**.

```cpp
virtual void Aspose::Slides::IShape::set_Rotation(float value)=0
```

## หมายเหตุ


ค่าที่คืนมาจะถูกกำหนดเสมอ (ไม่ใช่ std::numeric_limits<float>::quiet_NaN()). ค่าที่กำหนดต้องถูกกำหนด (ไม่ใช่ std::numeric_limits<float>::quiet_NaN()). คุณสามารถตั้งค่าเป็นค่าว่างสำหรับคุณสมบัติของอินสแตนซ์ RawFrame.
