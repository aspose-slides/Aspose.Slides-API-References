## IShape::get_X() เมธอด

รับค่าพิกัด x ของมุมบนซ้ายของรูปร่าง หน่วยเป็นพอยต์ อ่าน **float**.

```cpp
virtual float Aspose::Slides::IShape::get_X()=0
```

## หมายเหตุ

ค่าที่คืนกลับมาจะกำหนดอยู่เสมอและไม่เคย [std::numeric_limits<float>::quiet_NaN()](../). ค่าที่กำหนดต้องกำหนดอยู่เช่นกัน; กำหนด [std::numeric_limits<float>::quiet_NaN()](../) เฉพาะกับคุณสมบัติของอินสเทนซ์ **RawFrame** เท่านั้น.
