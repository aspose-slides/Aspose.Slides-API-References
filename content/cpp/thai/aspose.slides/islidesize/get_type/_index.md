## ISlideSize::get_Type() เมธอด


รับค่าชนิดของขนาดสไลด์. การกำหนดค่าใด ๆ นอกจาก [SlideSizeType::Custom](../../slidesizetype/) จะปรับ [ISlideSize::get_Size](../get_size/) ตามขนาดที่กำหนดล่วงหน้า โดยคงไว้ซึ่ง [ISlideSize::get_Orientation](../get_orientation/) ปัจจุบัน.

```cpp
virtual SlideSizeType Aspose::Slides::ISlideSize::get_Type()=0
```

## หมายเหตุ


การกำหนดค่าใด ๆ นอกจาก [SlideSizeType::Custom](../../slidesizetype/) จะปรับ [System::Drawing::Size](../../../system.drawing/size/) ตามขนาดที่กำหนดล่วงหน้า โดยคงไว้ซึ่ง [Orientation](../../orientation/) ปัจจุบัน.
