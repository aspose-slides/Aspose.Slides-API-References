## IMasterSlideHeaderFooterManager::SetSlideNumberAndChildSlideNumbersVisibility(bool) เมธอด


เปลี่ยนการแสดงผลของตัวกำหนดตำแหน่งหมายเลขหน้าสไลด์หลักและตัวกำหนดตำแหน่งหมายเลขหน้าสไลด์ลูกทั้งหมด. ตัวกำหนดตำแหน่งของสไลด์ลูกหมายถึงตัวกำหนดที่อยู่ในสไลด์เลเอาต์ที่พึ่งพาและสไลด์ที่พึ่งพา. สไลด์เลเอาต์ที่พึ่งพาและสไลด์เหล่านั้นใช้และขึ้นอยู่กับสไลด์หลัก.

```cpp
virtual void Aspose::Slides::IMasterSlideHeaderFooterManager::SetSlideNumberAndChildSlideNumbersVisibility(bool isVisible)=0
```


### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| isVisible | **bool** | true - ทำให้ตัวกำหนดตำแหน่งหมายเลขหน้าปรากฏ, ในกรณีอื่น - ซ่อนมัน. |
