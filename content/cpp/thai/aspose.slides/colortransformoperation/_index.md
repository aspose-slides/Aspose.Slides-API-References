## ColorTransformOperation enum

กำหนดการแปลงสี

```cpp
enum class ColorTransformOperation
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Tint | 0 | ทำให้สีอ่อนลง. พารามิเตอร์อยู่ในช่วงระหว่าง 0 (สีเดิม) และ 1 (สีขาว). |
| Shade | 1 | ทำให้สีเข้มลง. พารามิเตอร์อยู่ในช่วงระหว่าง 0 (สีเดิม) และ 1 (สีดำ). |
| Complement | 2 | เปลี่ยนสีเป็นสีเติมเต็มของ RGB. m = Max(r, g, b); r = m - r; g = m - g; b = m - b; |
| Inverse | 3 | เปลี่ยนสีเป็นสีตรงกันข้าม. r = 1 - r; g = 1 - g; b = 1 - b; |
| Grayscale | 4 | เปลี่ยนสีเป็นสีเทาที่มีความสว่างเท่าเดิม. พารามิเตอร์ถูกละเว้น. |
| SetAlpha | 5 | กำหนดคอมโพเนนต์อัลฟาของสี. พารามิเตอร์อยู่ในช่วงระหว่าง 0 (โปร่งใส) และ 1 (ทึบ). |
| AddAlpha | 6 | เพิ่มค่าพารามิเตอร์ให้กับคอมโพเนนต์อัลฟของสี. พารามิเตอร์อยู่ในช่วงระหว่าง -1 และ 1. |
| MultiplyAlpha | 7 | คูณคอมโพเนนต์อัลฟากับค่าพารามิเตอร์. |
| SetHue | 8 | เปลี่ยนคอมโพเนนต์สี (Hue) ของสีให้เป็นค่าพารามิเตอร์. พารามิเตอร์อยู่ในช่วงระหว่าง 0 ถึง 360. |
| AddHue | 9 | เพิ่มค่าพารามิเตอร์ให้กับคอมโพเนนต์สี (Hue) ของสี. พารามิเตอร์อยู่ในช่วงระหว่าง -360 ถึง 360. |
| MultiplyHue | 10 | คูณคอมโพเนนต์สี (Hue) กับค่าพารามิเตอร์. |
| SetSaturation | 11 | เปลี่ยนคอมโพเนนต์ความอิ่มสี (Saturation) ของสีให้เป็นค่าพารามิเตอร์. พารามิเตอร์อยู่ในช่วงระหว่าง 0 และ 1. |
| AddSaturation | 12 | เพิ่มค่าพารามิเตอร์ให้กับคอมโพเนนต์ความอิ่มสี (Saturation) ของสี. พารามิเตอร์อยู่ในช่วงระหว่าง -1 และ 1. |
| MultiplySaturation | 13 | คูณคอมโพเนนต์ความอิ่มสี (Saturation) กับค่าพารามิเตอร์. |
| SetLuminance | 14 | เปลี่ยนคอมโพเนนต์ความสว่าง (Luminance) ของสีให้เป็นค่าพารามิเตอร์. พารามิเตอร์อยู่ในช่วงระหว่าง 0 และ 1. |
| AddLuminance | 15 | เพิ่มค่าพารามิเตอร์ให้กับคอมโพเนนต์ความสว่าง (Luminance) ของสี. พารามิเตอร์อยู่ในช่วงระหว่าง -1 และ 1. |
| MultiplyLuminance | 16 | คูณคอมโพเนนต์ความสว่าง (Luminance) กับค่าพารามิเตอร์. |
| SetRed | 17 | เปลี่ยนคอมโพเนนต์สีแดงของสีให้เป็นค่าพารามิเตอร์. พารามิเตอร์อยู่ในช่วงระหว่าง 0 และ 1. |
| AddRed | 18 | เพิ่มค่าพารามิเตอร์ให้กับคอมโพเนนต์สีแดงของสี. พารามิเตอร์อยู่ในช่วงระหว่าง -1 และ 1. |
| MultiplyRed | 19 | คูณคอมโพเนนต์สีแดงกับพารามิเตอร์. |
| SetGreen | 20 | เปลี่ยนคอมโพเนนต์สีเขียวของสีให้เป็นค่าพารามิเตอร์. พารามิเตอร์อยู่ในช่วงระหว่าง 0 และ 1. |
| AddGreen | 21 | เพิ่มค่าพารามิเตอร์ให้กับคอมโพเนนต์สีเขียวของสี. พารามิเตอร์อยู่ในช่วงระหว่าง -1 และ 1. |
| MultiplyGreen | 22 | คูณคอมโพเนนต์สีเขียวของสีกับค่าพารามิเตอร์. |
| SetBlue | 23 | เปลี่ยนคอมโพเนนต์สีน้ำเงินของสีให้เป็นค่าพารามิเตอร์. พารามิเตอร์อยู่ในช่วงระหว่าง 0 ถึง 360. |
| AddBlue | 24 | เพิ่มค่าพารามิเตอร์ให้กับคอมโพเนนต์สีน้ำเงินของสี. พารามิเตอร์อยู่ในช่วงระหว่าง -1 และ 1. |
| MultiplyBlue | 25 | คูณคอมโพเนนต์สีน้ำเงินของสีกับค่าพารามิเตอร์. |
| Gamma | 26 | การแก้ไขค่าแกมม่า. พารามิเตอร์ถูกละเว้น. |
| InverseGamma | 27 | การแก้ไขค่าแกมม่าแบบกลับกัน. พารามิเตอร์ถูกละเว้น. |
