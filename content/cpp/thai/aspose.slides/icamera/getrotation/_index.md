## ICamera::GetRotation() method


การหมุนจะถูกกำหนดโดยการใช้พิกัดละติจูด, พิกัดลองจิจูด, และการหมุนรอบแกนตามพิกัดละติจูดและพิกัดลองจิจูด. สมาชิกแรกในอาเรย์ผลลัพธ์ - ละติจูด, สมาชิกที่สอง - ลองจิจูด, สมาชิกที่สาม - การหมุน. ส่งค่ากลับ null หากไม่มีการกำหนดการหมุน.

```cpp
virtual System::ArrayPtr<float> Aspose::Slides::ICamera::GetRotation()=0
```


### Return Value

อาเรย์ของค่าการหมุนเป็น **float**[].
