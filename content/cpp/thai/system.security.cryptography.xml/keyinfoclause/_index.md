## KeyInfoClause คลาส

การนำไปใช้ทั้งหมดของส่วนย่อย [KeyInfo](../keyinfo/) จำเป็นต้องสืบทอดคลาสเชิงนามธรรมนี้. ออบเจ็กต์ของคลาสนี้ควรจะจัดสรรเฉพาะโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น. ห้ามสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ตัวดำเนินการ new เพราะจะทำให้เกิดข้อผิดพลาดระหว่างทำงานและ/หรือความล้มเหลวของการอ้างอิง. ควรห่อคลาสนี้ในตัวชี้ [System::SmartPtr](../../system/smartptr/) เสมอและใช้ตัวชี้นี้เพื่อส่งผ่านเป็นอาร์กิวเมนต์ให้กับฟังก์ชัน.

```cpp
class KeyInfoClause : public System::Object
```
