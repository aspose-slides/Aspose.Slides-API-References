## KeyInfoName คลาส

แสดงถึง subelement 'KeyName' ของ XMLDSIG หรือ element การเข้ารหัส XML '[KeyInfo](../keyinfo/)' . วัตถุของคลาสนี้ควรจัดสรรเท่านั้นโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) . อย่าสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ตัวดำเนินการ new, เพราะจะทำให้เกิดข้อผิดพลาดเวลาเรียกใช้และ/หรือความล้มเหลวของการตรวจสอบ. ให้ห่อคลาสนี้ในตัวชี้ [System::SmartPtr](../../system/smartptr/) และใช้ตัวชี้นี้เพื่อส่งเป็นอาร์กิวเมนต์ให้กับฟังก์ชัน.

```cpp
class KeyInfoName : public System::Security::Cryptography::Xml::KeyInfoClause
```
