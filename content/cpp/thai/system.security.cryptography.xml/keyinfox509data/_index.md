## KeyInfoX509Data class

แทนที่องค์ประกอบ 'X509Data' มีข้อมูลใบรับรอง X.509v3 ที่เกี่ยวข้องกับคีย์การตรวจสอบหรือการเข้ารหัส วัตถุของคลาสนี้ควรสร้างโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น อย่าสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ operator new เนื่องจากจะทำให้เกิดข้อผิดพลาดเวลารันและ/หรือข้อผิดพลาดการยืนยัน ควรห่อหุ้มคลาสนี้ด้วยพอยน์เตอร์ [System::SmartPtr](../../system/smartptr/) และใช้พอยน์เตอร์นี้เพื่อส่งเป็นอากิวเมนต์ให้กับฟังก์ชัน

```cpp
class KeyInfoX509Data : public System::Security::Cryptography::Xml::KeyInfoClause
```
