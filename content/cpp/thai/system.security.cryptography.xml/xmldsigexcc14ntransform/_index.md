## XmlDsigExcC14NTransform คลาส


แสดงถึงการแปลง XML canonicalization C14N แบบ exclusive สำหรับลายเซ็นดิจิทัลโดยไม่มีคอมเมนต์ อ็อบเจ็กต์ของคลาสนี้ควรถูกจัดสรรเฉพาะโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) ไม่ควรสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ operator new เพราะจะทำให้เกิดข้อผิดพลาดเวลาทำงานและ/หรือข้อผิดพลาดการตรวจสอบ ควรห่อคลาสนี้ด้วยพอยเตอร์ [System::SmartPtr](../../system/smartptr/) และใช้พอยเตอร์นี้ส่งเป็นอาร์กิวเมนต์ให้ฟังก์ชันต่างๆ

```cpp
class XmlDsigExcC14NTransform : public System::Security::Cryptography::Xml::Transform
```
