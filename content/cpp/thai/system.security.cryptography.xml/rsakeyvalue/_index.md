## RSAKeyValue คลาส

เป็นตัวแทนขององค์ประกอบ '[RSAKeyValue](./)' ของลายเซ็น XML. วัตถุของคลาสนี้ควรจัดสรรโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น. ห้ามสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ operator new เนื่องจากจะทำให้เกิดข้อผิดพลาดขณะทำงานและ/หรือการอ้างอิงที่ผิดพลาด. ควรห่อคลาสนี้ไว้ในพอยน์เตอร์ [System::SmartPtr](../../system/smartptr/) และใช้พอยน์เตอร์นี้ในการส่งเป็นอาร์กิวเมนต์ให้กับฟังก์ชัน.

```cpp
class RSAKeyValue : public System::Security::Cryptography::Xml::KeyInfoClause
```
