## TrendlineType enum

แสดงประเภทของเส้นแนวโน้ม

```cpp
enum class TrendlineType
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| Exponential | 0 | ระบุว่าเส้นแนวโน้มจะเป็นเส้นโค้งเอ็กซ์โพเนนเชียลในรูปแบบนี้ |
| Linear | 1 | ระบุว่าเส้นแนวโน้มจะเป็นเส้นตรงในรูปแบบนี้ |
| Logarithmic | 2 | ระบุว่าเส้นแนวโน้มจะเป็นเส้นโค้งลอการิทึมในรูปแบบนี้, โดยที่ log คือลอการิทึมธรรมชาติ |
| MovingAverage | 3 | ระบุว่าเส้นแนวโน้มจะเป็นค่าเฉลี่ยเคลื่อนที่ของระยะ Period |
| Polynomial | 4 | ระบุว่าเส้นแนวโน้มจะเป็นเส้นโค้งพหุนามของลำดับ Order ในรูปแบบนี้ |
| Power | 5 | ระบุว่าเส้นแนวโน้มจะเป็นเส้นโค้งพาวเวอร์ในรูปแบบนี้ |
