## IDataLabelFormat::set_ShowLabelValueFromCell(bool) เมธอด

แสดงพฤติกรรมการแสดงค่าของเซลล์ป้ายกำกับข้อมูลสำหรับแผนภูมิที่ระบุ. True แสดงค่าของเซลล์. False เพื่อซ่อน. เขียน **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowLabelValueFromCell(bool value)=0
```

## หมายเหตุ

หากพาเรนต์ของอ็อบเจ็กต์ [DataLabelFormat](../../datalabelformat/) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายกำกับข้อมูลแล้วคุณสมบัตินี้จะรับหรือกำหนดค่าดีฟอลต์ของคุณสมบัติ ShowLabelValueFromCell สำหรับป้ายกำกับข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). การตั้งค่าคุณสมบัตินี้ด้วยค่าจะกำหนดค่านั้นให้กับคุณสมบัติ ShowLabelValueFromCell สำหรับป้ายกำกับข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น "DataLabels.DefaultDataLabelFormat.ShowLabelValueFromCell = val;" ทำให้ DataLabels[i].ShowLabelValueFromCell มีค่าเท่ากับ val).
