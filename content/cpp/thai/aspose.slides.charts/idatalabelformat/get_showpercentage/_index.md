## IDataLabelFormat::get_ShowPercentage() เมธอด


แสดงพฤติกรรมการแสดงค่าร้อยละของป้ายข้อมูลของแผนภูมิที่ระบุ ค่าจริง (True) จะแสดงค่าร้อยละ ค่าผิด (False) เพื่อซ่อน อ่าน **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowPercentage()=0
```

## หมายเหตุ


หากพาเรนท์ของอ็อบเจ็กต์ [DataLabelFormat](../../datalabelformat/) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้วคุณสมบัตินี้จะรับหรือกำหนดค่าตั้งต้นของคุณสมบัติ ShowPercentage สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) การตั้งค่าคุณสมบัตินี้ด้วยค่าใดค่าหนึ่งจะตั้งค่าค่านั้นให้กับคุณสมบัติ ShowPercentage ของป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น "DataLabels.DefaultDataLabelFormat.ShowPercentage = val;" ทำให้ DataLabels[i].ShowPercentage มีค่าเท่ากับ val).
