## IDataLabelFormat::get_ShowBubbleSize() เมธอด


แสดงพฤติกรรมการแสดงค่า bubble size ของป้ายข้อมูลในแผนภูมิที่ระบุ. True แสดงค่า bubble size. False เพื่อซ่อน. อ่าน **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowBubbleSize()=0
```

## หมายเหตุ


หากพาเรนต์ของอ็อบเจ็กต์ [DataLabelFormat](../../datalabelformat/) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้วคุณสมบัตินี้จะรับหรือกำหนดค่าปริยายของคุณสมบัติ ShowBubbleSize สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). การตั้งค่าคุณสมบัตินี้ด้วยค่าใด ๆ ยังจะกำหนดค่าดังกล่าวให้กับคุณสมบัติ ShowBubbleSize ของป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น \"DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;\" ทำให้ DataLabels[i].ShowBubbleSize มีค่าเท่ากับ val).
