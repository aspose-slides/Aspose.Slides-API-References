## IDataLabelFormat::get_ShowCategoryName() เมธอด

แทนพฤติกรรมการแสดงชื่อหมวดของป้ายข้อมูลในแผนภูมที่กำหนด. True เพื่อแสดงชื่อหมวดสำหรับป้ายข้อมูลบนแผนภูมิ. False เพื่อซ่อน. อ่าน **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowCategoryName()=0
```

## หมายเหตุ

หากพาเรนท์ของวัตถุ [DataLabelFormat](../../datalabelformat/) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้วคุณสมบัตินี้จะรับหรือกำหนดค่าปริยายของคุณสมบัติ ShowCategoryName สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). การตั้งค่าคุณสมบัตินี้ด้วยค่าจะกำหนดค่านี้ให้กับคุณสมบัติ ShowCategoryName สำหรับป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น "DataLabels.DefaultDataLabelFormat.ShowCategoryName = val;" ทำให้ DataLabels[i].ShowCategoryName มีค่าเท่ากับ val).
