## IDataLabelFormat::set_Position(LegendDataLabelPosition) เมธอด

แสดงตำแหน่งของป้ายข้อมูล. เขียน [LegendDataLabelPosition](../../legenddatalabelposition/).

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_Position(LegendDataLabelPosition value)=0
```

## หมายเหตุ

หากพาเรนท์ของวัตถุ [DataLabelFormat](../../datalabelformat/) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้วคุณสมบัตินี้จะรับหรือกำหนดค่าพื้นฐานของคุณสมบัติ Position สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). แสดงตำแหน่งสำหรับวัตถุ [DataLabel](../../datalabel/). การตั้งคุณสมบัตินี้ด้วยค่า จะกำหนดค่านี้ให้กับคุณสมบัติ Position ของป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น "DataLabels.DefaultDataLabelFormat.Position = val;" ทำให้ DataLabels[i].Position มีค่าเท่ากับ val).
