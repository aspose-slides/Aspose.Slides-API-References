## IDataLabelFormat::get_ShowLegendKey() เมธอด

แสดงพฤติกรรมการแสดงคีย์ของป้ายข้อมูลในแผนภูมิที่ระบุ. เป็นจริงหากคีย์ของป้ายข้อมูลแสดงผล. อ่าน **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowLegendKey()=0
```

## หมายเหตุ

หากพาเรนต์ของอ็อบเจกต์ [DataLabelFormat](../../datalabelformat/) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้วคุณสมบัตินี้จะรับหรือกำหนดค่าตั้งต้นของคุณสมบัติ ShowLegendKey สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). การตั้งค่าคุณสมบัตินี้ด้วยค่าใดค่าหนึ่งยังทำให้ค่านี้ถูกตั้งค่าให้กับคุณสมบัติ ShowLegendKey ของป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น "DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;" ทำให้ DataLabels[i].ShowLegendKey มีค่าเท่ากับ val).
