## IDataLabelFormat::set_ShowLegendKey(bool) เมธอด

แสดงพฤติกรรมการแสดงคีย์คำอธิบายข้อมูลของแผนภูมิที่ระบุ หากคีย์คำอธิบายข้อมูลมองเห็นได้ จะเป็นค่า True. เขียน **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowLegendKey(bool value)=0
```

## หมายเหตุ

หากพาเรนต์ของอ็อบเจ็กต์ [DataLabelFormat](../../datalabelformat/) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้ว คุณสมบัตินี้จะรับหรือกำหนดค่าพื้นฐานของคุณสมบัติ ShowLegendKey สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). การตั้งค่าคุณสมบัตินี้ด้วยค่าใดค่าหนึ่งจะยังตั้งค่านั้นให้กับคุณสมบัติ ShowLegendKey ของป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น "DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;" ทำให้ DataLabels[i].ShowLegendKey ทั้งหมดเท่ากับ val).
