## IDataLabelFormat::set_ShowCategoryName(bool) เมธอด

แทนพฤติกรรมการแสดงชื่อประเภทของป้ายข้อมูลในแผนภูมิที่ระบุ โดยกำหนดเป็น True เพื่อแสดงชื่อประเภทสำหรับป้ายข้อมูลบนแผนภูมิ และเป็น False เพื่อซ่อน เขียน **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowCategoryName(bool value)=0
```
## หมายเหตุ

หากพาเรนต์ของอ็อบเจ็กต์ [DataLabelFormat](../../datalabelformat/) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้วคุณสมบัตินี้จะรับหรือกำหนดค่าพรีเซ็ตของคุณสมบัติ ShowCategoryName สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). การตั้งค่าคุณสมบัตินี้ด้วยค่าใดค่าหนึ่งจะยังตั้งค่าค่าดังกล่าวให้กับคุณสมบัติ ShowCategoryName ของป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น "DataLabels.DefaultDataLabelFormat.ShowCategoryName = val;" ทำให้ DataLabels[i].ShowCategoryName มีค่าเท่ากับ val).
