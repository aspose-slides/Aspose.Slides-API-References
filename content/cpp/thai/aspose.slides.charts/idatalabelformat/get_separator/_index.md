## IDataLabelFormat::get_Separator() เมธอด


กำหนดหรือคืนค่า Variant ที่แสดงถึงตัวคั่นที่ใช้สำหรับป้ายข้อมูลบนแผนภูมิ. อ่าน [System::String](../../../system/string/).

```cpp
virtual System::String Aspose::Slides::Charts::IDataLabelFormat::get_Separator()=0
```

## หมายเหตุ


หากพาเรนท์ของอ็อบเจ็กต์ [DataLabelFormat](../../datalabelformat/) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้วคุณสมบัตินี้จะรับหรือกำหนดค่าเริ่มต้นของคุณสมบัติ Separator สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). การกำหนดคุณสมบัตินี้ด้วยค่า จะกำหนดค่าดังกล่าวให้กับคุณสมบัติ Separator ของป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น "DataLabels.DefaultDataLabelFormat.Separator = val;" จะทำให้ DataLabels[i].Separator มีค่าเท่ากับ val).
