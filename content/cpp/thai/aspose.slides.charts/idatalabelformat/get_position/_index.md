## IDataLabelFormat::get_Position() เมธอด

แสดงตำแหน่งของป้ายข้อมูล. อ่าน [LegendDataLabelPosition](../../legenddatalabelposition/).

```cpp
virtual LegendDataLabelPosition Aspose::Slides::Charts::IDataLabelFormat::get_Position()=0
```

## หมายเหตุ

หากพาเรนต์ของอ็อบเจกต์ [DataLabelFormat](../../datalabelformat/) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้วคุณสมบัตินี้จะรับหรือกำหนดค่าปริยายของคุณสมบัติ Position สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). แสดงตำแหน่งสำหรับอ็อบเจกต์ [DataLabel](../../datalabel/). การตั้งค่าคุณสมบัตินี้ด้วยค่า จะกำหนดค่านั้นให้กับคุณสมบัติ Position สำหรับป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น "DataLabels.DefaultDataLabelFormat.Position = val;" ทำให้ DataLabels[i].Position ทั้งหมดเท่ากับค่า val).
