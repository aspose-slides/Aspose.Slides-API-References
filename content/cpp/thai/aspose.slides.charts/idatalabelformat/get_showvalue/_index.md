## IDataLabelFormat::get_ShowValue() เมธอด


แสดงพฤติกรรมการแสดงค่าร้อยละของป้ายข้อมูลในแผนภูมิที่ระบุ. True แสดงค่าร้อยละ. False เพื่อซ่อน. อ่าน **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowValue()=0
```

## หมายเหตุ


หากพาเรนท์ของวัตถุ [DataLabelFormat](../../datalabelformat/) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้ว คุณสมบัตินี้จะรับหรือกำหนดค่าปริยายของคุณสมบัติ ShowValue สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). การตั้งค่าคุณสมบัตินี้ด้วยค่าจะตั้งค่าดังกล่าวให้กับคุณสมบัติ ShowValue สำหรับป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น \"DataLabels.DefaultDataLabelFormat.ShowValue = val;\" ทำให้ DataLabels[i].ShowValue เท่ากับ val).
