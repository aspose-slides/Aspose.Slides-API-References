## IDataLabelFormat::get_ShowLabelAsDataCallout() เมธอด

กำหนดว่าป้ายข้อมูลของแผนภูมิที่ระบุจะถูกแสดงเป็นข้อมูลอ้างอิงหรือเป็นป้ายข้อมูล.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowLabelAsDataCallout()=0
```

## หมายเหตุ

ถ้าพ่อแม่ของอ็อบเจกต์ [DataLabelFormat](../../datalabelformat/) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้วคุณสมบัตินี้จะรับหรือกำหนดค่าปริยายของคุณสมบัติ ShowLabelAsDataCallout สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) การตั้งค่าคุณสมบัตินี้ด้วยค่าจะยังตั้งค่าค่านี้ให้กับคุณสมบัติ ShowLabelAsDataCallout ของป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น \"DataLabels.DefaultDataLabelFormat.ShowLabelAsDataCallout = val;\" ทำให้ DataLabels[i].ShowLabelAsDataCallout ทั้งหมดเท่ากับ val).
