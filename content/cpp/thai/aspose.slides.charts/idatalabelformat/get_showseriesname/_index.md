## IDataLabelFormat::get_ShowSeriesName() เมธอด


คืนค่า Boolean เพื่อระบุพฤติกรรมการแสดงชื่อชุดข้อมูลสำหรับป้ายข้อมูลบนแผนภูมิ. True เพื่อแสดงชื่อชุดข้อมูล. False เพื่อซ่อน. อ่าน **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowSeriesName()=0
```

## หมายเหตุ


หากวัตถุ [DataLabelFormat](../../datalabelformat/) พาเรนต์เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้วคุณสมบัตินี้จะรับหรือกำหนดค่าดีฟอลต์ของคุณสมบัติ ShowSeriesName สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). การตั้งค่าให้กับคุณสมบัตินี้ด้วยค่าจะกำหนดค่าดังกล่าวให้กับคุณสมบัติ ShowSeriesName ของป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น "DataLabels.DefaultDataLabelFormat.ShowSeriesName = val;" ทำให้ DataLabels[i].ShowSeriesName มีค่าเท่ากับ val).
