## IDataLabelFormat::get_ShowLabelValueFromCell() เมธอด

แสดงพฤติกรรมการแสดงค่าของเซลล์ป้ายข้อมูลในแผนภูมิที่ระบุ. True แสดงค่าของเซลล์. False เพื่อซ่อน. อ่าน **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowLabelValueFromCell()=0
```

## หมายเหตุ

หากพาเรนท์ของอ็อบเจ็กต์ [DataLabelFormat](../../datalabelformat/) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้ว property นี้จะรับหรือกำหนดค่าปริยายของ property ShowLabelValueFromCell สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). ตั้งค่า property นี้ด้วยค่า จะกำหนดค่าดังกล่าวให้กับ property ShowLabelValueFromCell สำหรับป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (i.e. \"DataLabels.DefaultDataLabelFormat.ShowLabelValueFromCell = val;\" cause to all DataLabels[i].ShowLabelValueFromCell is equal to val).
