## IDataLabelFormat::set_ShowBubbleSize(bool) เมธอด

แสดงถึงพฤติกรรมการแสดงค่าขนาดฟองของป้ายข้อมูลในแผนภูมิที่ระบุ. True แสดงค่าขนาดฟอง. False ซ่อน. เขียน **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowBubbleSize(bool value)=0
```

## หมายเหตุ

หากพาเรนต์ของวัตถุ [DataLabelFormat](../../datalabelformat/) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้วคุณสมบัตินี้จะรับหรือกำหนดค่าเริ่มต้นของคุณสมบัติ ShowBubbleSize สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). การตั้งค่าคุณสมบัตินี้ด้วยค่าจะกำหนดค่านั้นให้กับคุณสมบัติ ShowBubbleSize สำหรับป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น "DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;" ทำให้ DataLabels[i].ShowBubbleSize มีค่าเท่ากับ val).
