## IDataLabelFormat::set_ShowPercentage(bool) เมธอด

แสดงพฤติกรรมการแสดงค่าร้อยละของป้ายข้อมูลในแผนภูมิที่กำหนด ค่า **True** จะแสดงค่าร้อยละ ค่า **False** จะซ่อน เขียน **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowPercentage(bool value)=0
```

## หมายเหตุ

หากพาเรนท์ของวัตถุ [DataLabelFormat](../../datalabelformat/) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้ว property นี้จะรับหรือกำหนดค่าตั้งต้นของ property ShowPercentage สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) การตั้งค่า property นี้ด้วยค่าใดค่าหนึ่งจะกำหนดค่านั้นให้กับ property ShowPercentage ของป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น \"DataLabels.DefaultDataLabelFormat.ShowPercentage = val;\" ทำให้ทุก DataLabels[i].ShowPercentage มีค่าเท่ากับ val).
