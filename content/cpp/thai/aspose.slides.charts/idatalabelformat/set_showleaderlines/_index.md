## IDataLabelFormat::set_ShowLeaderLines(bool) เมธอด

Represents a specified chart's data label leader lines display behavior. True displays the leader lines. False to hide. Write **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowLeaderLines(bool value)=0
```

## หมายเหตุ

หากพาเรนท์ของวัตถุ [DataLabelFormat](../../datalabelformat/) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้วคุณสมบัตินี้จะรับหรือกำหนดค่าพื้นฐานของคุณสมบัติ ShowLeaderLines สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). การตั้งค่าคุณสมบัตินี้ด้วยค่าเดียวกันจะตั้งค่าค่าดังกล่าวให้กับคุณสมบัติ ShowLeaderLines ของป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น \"DataLabels.DefaultDataLabelFormat.ShowLeaderLines = val;\" ทำให้ DataLabels[i].ShowLeaderLines มีค่าเท่ากับ val).
