## ErrorBarsFormat::get_ValueType() เมธอด

แสดงวิธีที่เป็นไปได้ในการกำหนดความยาวของ error bars. ในกรณีของ custom value type เพื่อระบุค่าใช้ [IChartDataPoint::get_ErrorBarsCustomValues()](../../ichartdatapoint/get_errorbarscustomvalues/) property ของจุดข้อมูลเฉพาะในคอลเลกชัน DataPoints ของ series. ในกรณีของ Fixed, Percentage หรือ StandardDeviation value type ใช้ Value property เพื่อระบุค่า.

อ่าน [ErrorBarValueType](../../errorbarvaluetype/).
