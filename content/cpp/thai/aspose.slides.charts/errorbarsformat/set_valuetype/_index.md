## ErrorBarsFormat::set_ValueType(ErrorBarValueType) เมธอด


แทนวิธีการที่เป็นไปได้ในการกำหนดความยาวของแถบข้อผิดพลาด ในกรณีที่ใช้ประเภทค่าที่กำหนดเองเพื่อระบุค่าจะใช้คุณสมบัติ [IChartDataPoint::get_ErrorBarsCustomValues()](../../ichartdatapoint/get_errorbarscustomvalues/) ของจุดข้อมูลเฉพาะในคอลเลกชัน DataPoints ของ series ในกรณีที่ใช้ประเภทค่า Fixed, Percentage หรือ StandardDeviation ให้ใช้คุณสมบัติ Value เพื่อระบุค่า. 

เขียน [ErrorBarValueType](../../errorbarvaluetype/).
