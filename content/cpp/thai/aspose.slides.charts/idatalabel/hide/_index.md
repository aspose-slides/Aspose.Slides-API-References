## IDataLabel::Hide() เมธอด

ทำให้ป้ายข้อมูลถูกซ่อนโดยตั้งค่าแฟล็ก Show*-ทั้งหมด (ShowValue, ...) ให้เป็นสถานะ false. IsVisible จะเป็น false หลังจากนี้.

```cpp
virtual void Aspose::Slides::Charts::IDataLabel::Hide()=0
```

## หมายเหตุ

หากป้ายข้อมูลไม่แสดงผล (IsVisible เป็น false) คุณสามารถทำให้ป้ายข้อมูลแสดงผลได้โดยตั้งค่าแฟล็ก Show*- (ShowValue, ...) ให้เป็นสถานะ true.
