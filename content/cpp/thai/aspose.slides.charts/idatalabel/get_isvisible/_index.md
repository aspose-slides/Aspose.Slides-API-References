## IDataLabel::get_IsVisible() เมธอด

False หมายความว่า data label ไม่แสดงผล (และ flag ทั้งหมดของ Show* (ShowValue, ...) จะเป็น false) อ่านอย่างเดียว **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabel::get_IsVisible()=0
```

## หมายเหตุ

หาก data label แสดงผลอยู่คุณสามารถทำให้มันซ่อนได้ด้วย [Hide()](../hide/) เมธอด แต่หาก data label ไม่แสดงผล (IsVisible เป็น false) คุณสามารถทำให้ data label แสดงผลได้โดยตั้งค่า Show*-flags (ShowValue, ...) ให้เป็นสถานะ true
