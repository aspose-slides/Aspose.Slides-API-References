## TickLabelPositionType enum

แสดงประเภทตำแหน่งของป้าย tick-mark บนแกนที่ระบุ

```cpp
enum class TickLabelPositionType
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| High | 0 | ระบุว่าป้ายแกนจะอยู่ที่ส่วนปลายสูงของแกนตั้งฉาก |
| Low | 1 | ระบุว่าป้ายแกนจะอยู่ที่ส่วนปลายต่ำของแกนตั้งฉาก |
| NextTo | 2 | ระบุว่าป้ายแกนจะอยู่ใกล้แกน |
| None | 3 | ระบุว่าป้ายแกนจะไม่ถูกวาด |
