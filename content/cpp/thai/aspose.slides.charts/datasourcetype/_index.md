## DataSourceType enum


ประเภทแหล่งข้อมูล

```cpp
enum class DataSourceType
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Worksheet | 0 | ใช้วัตถุ CellXls สำหรับเก็บ XValue, YValue, Value หรือ BubbleSize ของจุดข้อมูลใน worksheet |
| StringLiterals | 1 | ใช้ตัวแปรสตริงที่เข้าถึงเร็วสำหรับเก็บ XValue, YValue, Value หรือ BubbleSize ของจุดข้อมูล Worksheet ไม่ได้ใช้สำหรับเก็บค่า |
| DoubleLiterals | 2 | ใช้ตัวแปร double ที่เข้าถึงเร็วสำหรับเก็บ XValue, YValue, Value หรือ BubbleSize ของจุดข้อมูล Worksheet ไม่ได้ใช้สำหรับเก็บค่า |
