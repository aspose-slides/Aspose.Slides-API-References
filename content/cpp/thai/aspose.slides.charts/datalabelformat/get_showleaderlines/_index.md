## DataLabelFormat::get_ShowLeaderLines() เมธอด

ระบุพฤติกรรมการแสดงเส้นเชื่อมป้ายข้อมูลของแผนภูมิที่ระบุ ค่า True แสดงเส้นเชื่อม, False เพื่อซ่อน. อ่าน **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowLeaderLines() override
```

## หมายเหตุ

หากพาเรนต์ของวัตถุ [DataLabelFormat](../) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้ว property นี้จะรับหรือกำหนดค่าเริ่มต้นของ property ShowLeaderLines สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). การตั้งค่า property นี้ด้วยค่าใดค่าหนึ่งยังตั้งค่าค่านี้ให้กับ property ShowLeaderLines ของป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น "DataLabels.DefaultDataLabelFormat.ShowLeaderLines = val;" ทำให้ DataLabels[i].ShowLeaderLines ทั้งหมดเท่ากับ val).
