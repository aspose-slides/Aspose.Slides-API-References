## DataLabelFormat::set_ShowLabelValueFromCell(bool) เมธอด

แสดงพฤติกรรมการแสดงค่าของเซลล์ป้ายข้อมูลของแผนภูมิที่ระบุ. True แสดงค่าของเซลล์. False เพื่อซ่อน. เขียน **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLabelValueFromCell(bool value) override
```

## หมายเหตุ

หากพาเรนท์ของอ็อบเจกต์ [DataLabelFormat](../) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้วคุณสมบัตินี้จะรับหรือกำหนดค่าเริ่มต้นของคุณสมบัติ ShowLabelValueFromCell สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). การกำหนดค่าคุณสมบัตินี้ด้วยค่าใดค่าหนึ่งยังทำให้ค่าดังกล่าวถูกกำหนดให้กับคุณสมบัติ ShowLabelValueFromCell ของป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (i.e. "DataLabels.DefaultDataLabelFormat.ShowLabelValueFromCell = val;" cause to all DataLabels[i].ShowLabelValueFromCell is equal to val).
