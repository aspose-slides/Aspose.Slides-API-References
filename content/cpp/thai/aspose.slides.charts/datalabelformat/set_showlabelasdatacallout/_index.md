## DataLabelFormat::set_ShowLabelAsDataCallout(bool) เมธอด


กำหนดว่าป้ายข้อมูลของแผนภูมิที่ระบุจะถูกแสดงเป็นการอธิบายข้อมูลหรือเป็นป้ายข้อมูล.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLabelAsDataCallout(bool value) override
```

## หมายเหตุ


หากพาเรนต์ของอ็อบเจกต์ [DataLabelFormat](../) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้วคุณสมบัตินี้จะรับหรือกำหนดค่าเริ่มต้นของคุณสมบัติ ShowLabelAsDataCallout สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). การตั้งค่าคุณสมบัตินี้ด้วยค่าเดียวกันจะตั้งค่าค่านี้ให้กับคุณสมบัติ ShowLabelAsDataCallout สำหรับป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น \"DataLabels.DefaultDataLabelFormat.ShowLabelAsDataCallout = val;\" ทำให้ DataLabels[i].ShowLabelAsDataCallout มีค่าเท่ากับ val).
