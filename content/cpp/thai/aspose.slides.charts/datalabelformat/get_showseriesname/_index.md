## DataLabelFormat::get_ShowSeriesName() เมธอด

ส่งคืนค่า Boolean เพื่อระบุพฤติกรรมการแสดงชื่อชุดข้อมูลสำหรับป้ายข้อมูลบนแผนภูมิ. True เพื่อแสดงชื่อชุดข้อมูล. False เพื่อซ่อน. อ่าน **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowSeriesName() override
```

## หมายเหตุ

หากพาเรนต์ของวัตถุ [DataLabelFormat](../) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้วคุณสมบัตินี้จะรับหรือกำหนดค่าเริ่มต้นของคุณสมบัติ ShowSeriesName สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). การตั้งค่าคุณสมบัตินี้ด้วยค่าใดค่าหนึ่งจะกำหนดค่านี้ให้กับคุณสมบัติ ShowSeriesName ของป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น "DataLabels.DefaultDataLabelFormat.ShowSeriesName = val;" ทำให้ DataLabels[i].ShowSeriesName มีค่าเท่ากับ val).
