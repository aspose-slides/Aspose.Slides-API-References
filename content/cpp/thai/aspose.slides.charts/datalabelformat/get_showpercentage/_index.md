## DataLabelFormat::get_ShowPercentage() method

แสดงพฤติกรรมการแสดงค่าร้อยละของป้ายข้อมูลของแผนภูมิที่ระบุ. True จะแสดงค่าร้อยละ. False เพื่อซ่อน. อ่าน **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowPercentage() override
```

## หมายเหตุ

หากพาเรนต์ของอ็อบเจ็กต์ [DataLabelFormat](../) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้วคุณสมบัตินี้จะรับหรือกำหนดค่าตั้งต้นของคุณสมบัติ ShowPercentage สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). ตั้งค่าคุณสมบัตินี้ด้วยค่าจะยังตั้งค่าสำหรับคุณสมบัติ ShowPercentage ของป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น "DataLabels.DefaultDataLabelFormat.ShowPercentage = val;" ทำให้ DataLabels[i].ShowPercentage มีค่าเท่ากับ val).
