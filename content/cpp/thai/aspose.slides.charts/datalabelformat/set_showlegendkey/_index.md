## DataLabelFormat::set_ShowLegendKey(bool) เมธอด


แทนพฤติกรรมการแสดงคีย์คำอธิบายข้อมูลของแผนภูมิที่ระบุ หากคีย์คำอธิบายข้อมูลมองเห็นได้ จะเป็น true เขียนเป็น **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLegendKey(bool value) override
```

## หมายเหตุ


หากพาเรนท์ของอ็อบเจ็กต์ [DataLabelFormat](../) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้วคุณสมบัตินี้จะรับหรือกำหนดค่าดีฟอลต์ของคุณสมบัติ ShowLegendKey สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) การตั้งค่าคุณสมบัตินี้ด้วยค่าใดค่าหนึ่งก็จะตั้งค่าที่เดียวกันให้กับคุณสมบัติ ShowLegendKey ของป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น \"DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;\" ทำให้ DataLabels[i].ShowLegendKey ทั้งหมดมีค่าเท่ากับ val).
