## DataLabelFormat::set_Position(LegendDataLabelPosition) เมธอด


แสดงตำแหน่งของป้ายข้อมูล. เขียน [LegendDataLabelPosition](../../legenddatalabelposition/).

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_Position(LegendDataLabelPosition value) override
```

## หมายเหตุ


หากพาเรนท์ของวัตถุ [DataLabelFormat](../) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้วคุณสมบัตินี้จะรับหรือกำหนดค่าเริ่มต้นของคุณสมบัติ Position สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). แสดงตำแหน่งสำหรับอ็อบเจ็กต์ [DataLabel](../../datalabel/). การตั้งค่าคุณสมบัตินี้ด้วยค่าจะยังตั้งค่าค่านี้ให้กับคุณสมบัติ Position ของป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น "DataLabels.DefaultDataLabelFormat.Position = val;" ทำให้ DataLabels[i].Position มีค่าเท่ากับ val).
