## DataLabelFormat::get_ShowBubbleSize() เมธอด


แสดงพฤติกรรมการแสดงค่าขนาดฟองของป้ายข้อมูลสำหรับแผนภูมิที่ระบุ. True แสดงค่าขนาดฟอง. False เพื่อซ่อน. อ่าน **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowBubbleSize() override
```

## หมายเหตุ


หากพาเรนท์ของอ็อบเจ็กต์ [DataLabelFormat](../) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้วคุณสมบัตินี้จะรับหรือกำหนดค่าเริ่มต้นของคุณสมบัติ ShowBubbleSize สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). ตั้งค่าคุณสมบัตินี้ด้วยค่าใดค่าหนึ่งก็จะตั้งค่าค่านั้นให้กับคุณสมบัติ ShowBubbleSize สำหรับป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (i.e. \"DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;\" ทำให้ DataLabels[i].ShowBubbleSize มีค่าเท่ากับ val).
