## DataLabelFormat::set_ShowLeaderLines(bool) เมธอด


แสดงพฤติกรรมการแสดงเส้นนำของป้ายข้อมูลในแผนภูมิกำหนด. True แสดงเส้นนำ. False เพื่อซ่อน. เขียน **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLeaderLines(bool value) override
```

## หมายเหตุ


ถ้า parent ของ [DataLabelFormat](../) object เป็น [DataLabelCollection](../../datalabelcollection/) collection ของป้ายข้อมูลแล้ว property นี้จะรับหรือกำหนดค่าเริ่มต้นของ property ShowLeaderLines สำหรับป้ายข้อมูลใหม่ใน [DataLabelCollection](../../datalabelcollection/) collection. การตั้งค่า property นี้ด้วยค่าใดๆ จะตั้งค่านั้นให้กับ property ShowLeaderLines ของป้ายข้อมูลทั้งหมดใน [DataLabelCollection](../../datalabelcollection/) collection (เช่น \"DataLabels.DefaultDataLabelFormat.ShowLeaderLines = val;\" ทำให้ DataLabels[i].ShowLeaderLines มีค่าเท่ากับ val).
