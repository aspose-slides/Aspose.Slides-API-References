## หมายเหตุ

หาก parent ของวัตถุ [DataLabelFormat](../) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้ว property นี้จะรับหรือกำหนดค่าตั้งต้นของ property IsNumberFormatLinkedToSource สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). การตั้งค่า property นี้ด้วยค่าใดค่าหนึ่งยังทำให้ค่าดังกล่าวถูกกำหนดให้กับ property IsNumberFormatLinkedToSource ของป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น "DataLabels.DefaultDataLabelFormat.IsNumberFormatLinkedToSource = val;" ทำให้ทุก DataLabels[i].IsNumberFormatLinkedToSource มีค่าเท่ากับ val).
