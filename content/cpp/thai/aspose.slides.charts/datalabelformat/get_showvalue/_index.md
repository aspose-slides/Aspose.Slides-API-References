## DataLabelFormat::get_ShowValue() เมธอด

แสดงถึงพฤติกรรมการแสดงค่าเปอร์เซ็นต์ของป้ายข้อมูลในแผนภูมิที่กำหนด. True แสดงค่าเปอร์เซ็นต์. False ซ่อนค่า. อ่าน **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowValue() override
```

## หมายเหตุ

หากพาเรนต์ของวัตถุ [DataLabelFormat](../) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้วคุณสมบัตินี้จะรับหรือกำหนดค่าตั้งต้นของคุณสมบัติ ShowValue สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). ตั้งค่าคุณสมบัตินี้ด้วยค่าเดียวกันจะกำหนดค่านี้ให้กับคุณสมบัติ ShowValue สำหรับป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น \"DataLabels.DefaultDataLabelFormat.ShowValue = val;\" ทำให้ DataLabels[i].ShowValue มีค่าเท่ากับ val).
