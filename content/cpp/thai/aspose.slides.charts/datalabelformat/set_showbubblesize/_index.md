## DataLabelFormat::set_ShowBubbleSize(bool) เมธอด

เป็นการกำหนดพฤติกรรมการแสดงค่าขนาดฟองของป้ายข้อมูลในแผนภูมิที่ระบุ ค่าจริงจะแสดงค่าขนาดฟอง ค่เท็จจะซ่อน ไม่คืนค่า **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowBubbleSize(bool value) override
```


## หมายเหตุ

หากพาเรนต์ของวัตถุ [DataLabelFormat](../) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้วคุณสมบัตินี้จะรับหรือกำหนดค่าดีฟอลต์ของคุณสมบัติ ShowBubbleSize สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) การกำหนดค่าคุณสมบัตินี้ด้วยค่าใดค่าหนึ่งจะตั้งค่าค่านั้นให้กับคุณสมบัติ ShowBubbleSize ของป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น “DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;” ทำให้ DataLabels[i].ShowBubbleSize มีค่าเท่ากับ val)
