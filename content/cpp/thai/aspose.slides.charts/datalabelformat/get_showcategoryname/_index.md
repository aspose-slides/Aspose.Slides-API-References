## DataLabelFormat::get_ShowCategoryName() เมธอด

แสดงถึงพฤติกรรมการแสดงชื่อประเภทของป้ายข้อมูลในแผนภูมิกำหนดค่า เป็น true เพื่อแสดงชื่อประเภทสำหรับป้ายข้อมูลบนแผนภูมิ และเป็น false เพื่อซ่อน อ่าน **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowCategoryName() override
```

## หมายเหตุ

หากพาเรนท์ของอ็อบเจ็กต์ [DataLabelFormat](../) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้วคุณสมบัตินี้จะรับหรือกำหนดค่าตั้งต้นของคุณสมบัติ ShowCategoryName สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). การตั้งค่าคุณสมบัตินี้ด้วยค่าจะยังตั้งค่าค่านี้ให้กับคุณสมบัติ ShowCategoryName ของป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น "DataLabels.DefaultDataLabelFormat.ShowCategoryName = val;" ทำให้ทุก DataLabels[i].ShowCategoryName มีค่าเท่ากับ val).
