## DataLabelFormat::set_ShowSeriesName(bool) เมธอด

ตั้งค่า Boolean เพื่อระบุพฤติกรรมการแสดงชื่อชุดข้อมูลของป้ายข้อมูลบนแผนภูมิ. true เพื่อแสดงชื่อชุดข้อมูล. false เพื่อซ่อน. เขียน **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowSeriesName(bool value) override
```

## หมายเหตุ

หากพาเรนต์ของอ็อบเจกต์ [DataLabelFormat](../) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้ว property นี้จะรับหรือกำหนดค่าเริ่มต้นของ property ShowSeriesName สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). การตั้งค่า property นี้ด้วยค่าจะยังตั้งค่าดังกล่าวให้กับ property ShowSeriesName ของป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น "DataLabels.DefaultDataLabelFormat.ShowSeriesName = val;" ทำให้ DataLabels[i].ShowSeriesName ทั้งหมดเท่ากับ val).
