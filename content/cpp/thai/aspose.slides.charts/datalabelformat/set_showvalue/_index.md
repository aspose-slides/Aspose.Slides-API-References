## DataLabelFormat::set_ShowValue(bool) เมธอด


แสดงพฤติกรรมการแสดงค่าร้อยละของป้ายข้อมูลในแผนภูมิที่ระบุ. ค่า True แสดงค่าร้อยละ. ค่า False เพื่อซ่อน. เขียน **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowValue(bool value) override
```

## หมายเหตุ


ถ้า parent ของอ็อบเจ็กต์ [DataLabelFormat](../) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของป้ายข้อมูลแล้ว property นี้จะรับหรือกำหนดค่าเริ่มต้นของ property ShowValue สำหรับป้ายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). การตั้งค่า property นี้ด้วยค่าใดค่าหนึ่งจะตั้งค่าดังกล่าวให้กับ property ShowValue ของป้ายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น \"DataLabels.DefaultDataLabelFormat.ShowValue = val;\" ทำให้ DataLabels[i].ShowValue มีค่าเท่ากับ val).
