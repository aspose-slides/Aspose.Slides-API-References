## DataLabelFormat::get_ShowLegendKey() เมธอด


แสดงพฤติกรรมการแสดงคีย์ของคำอธิบายข้อมูลในแผนภูมิที่ระบุ. เป็น True หากคีย์ของคำอธิบายข้อมูลมองเห็นได้. อ่าน **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowLegendKey() override
```

## หมายเหตุ


หากพาเรนต์ของอ็อบเจ็กต์ [DataLabelFormat](../) นี้เป็นคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) ของคำอธิบายข้อมูลแล้ว คุณสมบัตินี้จะรับหรือกำหนดค่าปริยายของคุณสมบัติ ShowLegendKey สำหรับคำอธิบายข้อมูลใหม่ในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/). การตั้งค่าคุณสมบัตินี้ด้วยค่าใดค่าหนึ่งจะตั้งค่าค่านั้นให้กับคุณสมบัติ ShowLegendKey ของคำอธิบายข้อมูลทั้งหมดในคอลเลกชัน [DataLabelCollection](../../datalabelcollection/) (เช่น "DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;" ทำให้ DataLabels[i].ShowLegendKey มีค่าเท่ากับ val).
