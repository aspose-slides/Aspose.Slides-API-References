## IChartData::SetRange(System::String) เมธอด


ตั้งค่าช่วงข้อมูลของแผนภูมิ. ซีรีส์และประเภทจะได้รับการอัปเดตตามช่วงข้อมูลใหม่. หากจำนวนซีรีส์ในช่วงข้อมูลมากกว่าจำนวนซีรีส์ในข้อมูลแผนภูมิ จะมีการเพิ่มซีรีส์เพิ่มเติมที่มีประเภทเดียวกับซีรีส์สุดท้ายในคอลเลกชันปัจจุบันไปยังท้ายของคอลเลกชัน.

```cpp
virtual void Aspose::Slides::Charts::IChartData::SetRange(System::String formula)=0
```


### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| formula | [System::String](../../../system/string/) | สูตรช่วงข้อมูลของเซลล์. ตัวอย่างเช่น: \"Sheet1!$A$1:$C$4\" , \"SomeSheetName!A1:B100\", \"Sheet1!$A$1:$B$5;Sheet1!$D$1:$D$5\". |
