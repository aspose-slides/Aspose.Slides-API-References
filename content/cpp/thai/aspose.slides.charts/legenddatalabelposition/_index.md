## LegendDataLabelPosition enum

กำหนดตำแหน่งของป้ายข้อมูล.

```cpp
enum class LegendDataLabelPosition
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| NotDefined | -1 | ตำแหน่งไม่ได้กำหนด |
| Bottom | 0 | ระบุว่าป้ายข้อมูลจะถูกแสดงด้านล่างของเครื่องหมายข้อมูล |
| BestFit | 1 | ระบุว่าป้ายข้อมูลจะถูกแสดงในตำแหน่งที่ดีที่สุด |
| Center | 2 | ระบุว่าป้ายข้อมูลจะถูกแสดงกึ่งกลางบนเครื่องหมายข้อมูล |
| InsideBase | 3 | ระบุว่าป้ายข้อมูลจะถูกแสดงภายในฐานของเครื่องหมายข้อมูล |
| InsideEnd | 4 | ระบุว่าป้ายข้อมูลจะถูกแสดงภายในส่วนปลายของเครื่องหมายข้อมูล |
| Left | 5 | ระบุว่าป้ายข้อมูลจะถูกแสดงทางด้านซ้ายของเครื่องหมายข้อมูล |
| OutsideEnd | 6 | ระบุว่าป้ายข้อมูลจะถูกแสดงนอกส่วนปลายของเครื่องหมายข้อมูล |
| Right | 7 | ระบุว่าป้ายข้อมูลจะถูกแสดงทางด้านขวาของเครื่องหมายข้อมูล |
| Top | 8 | ระบุว่าป้ายข้อมูลจะถูกแสดงเหนือเครื่องหมายข้อมูล |
