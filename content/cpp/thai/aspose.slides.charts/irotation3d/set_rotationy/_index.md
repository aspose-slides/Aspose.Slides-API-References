## IRotation3D::set_RotationY(uint16_t) เมธอด

กำหนดค่ามุมการหมุนรอบแกน Y หรือที่เรียกว่าทิศทาง X สำหรับแผนภูมิ 3 มิติ (ระหว่าง 0 ถึง 360 องศา) คุณสมบัตินี้สอดคล้องกับรายการ 21.2.2.158 rotY (การหมุน Y) ใน ECMA-376 และกับตัวเลือก “การหมุน X” ใน PowerPoint 2007+ เขียน **uint16_t**.

virtual void Aspose::Slides::Charts::IRotation3D::set_RotationY(uint16_t value)=0
