## IRotation3D::set_RotationX(int8_t) เมธอด


กำหนดค่ามุมการหมุนรอบแกน X หรือที่เรียกว่าในทิศทาง Y สำหรับแผนภูมิ 3 มิติ (ระหว่าง -90 ถึง 90 องศา) คุณสมบัตินี้สอดคล้องกับรายการ 21.2.2.157 rotX (X Rotation) ใน ECMA-376 และกับตัวเลือก \"Y Rotation\" ใน PowerPoint 2007+ เขียน **int8_t**.

virtual void Aspose::Slides::Charts::IRotation3D::set_RotationX(int8_t value)=0
