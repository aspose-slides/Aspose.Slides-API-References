## IChartCategory::get_UseCell() เมธอด

หาก true แล้วคุณสมบัติ AsCell มีค่าเป็นจริง. อีกนัยหนึ่ง worksheet ถูกใช้เพื่อเก็บหมวดหมู่ (กรณีนี้สนับสนุนหมวดหมู่หลายระดับ). หาก false แล้วคุณสมบัติ AsLiteral มีค่าเป็นจริง. อีกนัยหนึ่ง worksheet ไม่ได้ถูกใช้เพื่อเก็บหมวดหมู่ (และกรณีนี้ไม่รองรับหมวดหมู่หลายระดับ). อ่านอย่างเดียว **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IChartCategory::get_UseCell()=0
```

## หมายเหตุ

หากต้องการเปลี่ยนค่าของคุณสมบัตินี้ (สำหรับทุกหมวดหมู่ใน collection) ให้ตั้งค่าใหม่ให้กับคุณสมบัติ ChartCategoryCollection.UseCells.
