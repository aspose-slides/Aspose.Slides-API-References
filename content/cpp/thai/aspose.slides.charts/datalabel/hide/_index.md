## DataLabel::Hide() เมธอด


ทำให้ป้ายข้อมูลซ่อนโดยตั้งค่า Show*-flags (ShowValue, ...) เป็นสถานะ false. IsVisible จะเป็น false หลังจากนี้.

```cpp
void Aspose::Slides::Charts::DataLabel::Hide() override
```

## หมายเหตุ


ถ้าป้ายข้อมูลไม่แสดง (IsVisible เป็น false) คุณสามารถทำให้ป้ายข้อมูลแสดงได้โดยตั้งค่า Show*-flags (ShowValue, ...) ให้เป็นสถานะ true.
