## DataLabel::get_IsVisible() เมธอด

False หมายความว่าป้ายข้อมูลไม่ได้ปรากฏ (และดังนั้นทุก Show*-flags (ShowValue, ...) จะเป็นค่า false). อ่านอย่างเดียว **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabel::get_IsVisible() override
```

## หมายเหตุ

หากป้ายข้อมูลปรากฏ คุณสามารถทำให้มันซ่อนได้ด้วย [Hide()](../hide/) เมธอด. แต่ถ้าป้ายข้อมูลไม่ปรากฏ (IsVisible เป็น false) คุณสามารถทำให้ป้ายข้อมูลปรากฏได้โดยตั้งค่า Show*-flags (ShowValue, ...) ให้เป็นสถานะ true.
