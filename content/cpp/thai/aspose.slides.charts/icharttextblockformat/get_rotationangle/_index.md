## IChartTextBlockFormat::get_RotationAngle() เมธอด


ระบุการหมุนแบบกำหนดเองที่ถูกนำไปใช้กับข้อความภายในกล่องขอบเขต หากไม่ได้ระบุ การหมุนของรูปร่างที่แนบมาจะถูกใช้ หากได้ระบุแล้วจะนำไปใช้แยกจากรูปร่าง กล่าวคือ รูปร่างอาจมีการหมุนเพิ่มขึ้นพร้อมกับข้อความที่มีการหมุนของตนเอง ค่าที่ได้จากการหมุนของข้อความที่แสดงผลสรุปจากคุณสมบัตินี้และประเภทแนวตั้งที่กำหนดล่วงหน้าในคุณสมบัติ TextVerticalType อ่าน **float**.

```cpp
virtual float Aspose::Slides::Charts::IChartTextBlockFormat::get_RotationAngle()=0
```

## หมายเหตุ


ให้พิจารณากรณีที่รูปร่างมีการหมุน 90 องศาตามเข็มนาฬิกาที่นำไปใช้กับมัน นอกจากนี้ข้อความเองยังมีการหมุน -90 องศาตรงกันข้ามเข็มนาฬิกาที่นำไปใช้กับมัน แล้วรูปร่างที่ได้จะดูเหมือนถูกหมุน แต่ข้อความภายในจะดูเหมือนไม่ได้หมุนเลย.
