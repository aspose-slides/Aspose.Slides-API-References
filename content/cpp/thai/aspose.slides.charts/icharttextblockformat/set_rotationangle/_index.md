## IChartTextBlockFormat::set_RotationAngle(float) เมธอด

ระบุการหมุนแบบกำหนดเองที่ถูกนำไปใช้กับข้อความภายในกล่องขอบเขต หากไม่ได้ระบุ จะใช้การหมุนของรูปทรงที่แนบมาด้วย หากระบุแล้ว การหมุนนี้จะถูกนำไปใช้แยกจากรูปทรง กล่าวคือ รูปทรงอาจมีการหมุนเพิ่มขึ้นในขณะที่ข้อความเองก็มีการหมุนเช่นเดียวกัน ค่าที่ได้ของการหมุนข้อความที่แสดงผลสรุปจากคุณสมบัตินี้และประเภทแนวตั้งที่กำหนดไว้ล่วงหน้าในคุณสมบัติ TextVerticalType เขียนเป็น **float**.

```cpp
virtual void Aspose::Slides::Charts::IChartTextBlockFormat::set_RotationAngle(float value)=0
```

## หมายเหตุ

พิจารณากรณีที่รูปทรงมีการหมุน 90 องศา ตามเข็มนาฬิกา จากนั้นข้อความภายในก็มีการหมุน -90 องศา ทวนเข็มนาฬิกา การหมุนเหล่านี้ทำให้รูปทรงดูเหมือนว่าถูกหมุน แต่ข้อความภายในดูเหมือนไม่ได้ถูกหมุนเลย.
