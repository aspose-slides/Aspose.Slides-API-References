## ErrorBarValueType enum

แสดงประเภทของค่าบาร์ความคลาดเคลื่อน

```cpp
enum class ErrorBarValueType
```

### ค่าต่างๆ

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Custom | 0 | ระบุว่าความยาวของบาร์ความคลาดเคลื่อนจะถูกกำหนดโดยองค์ประกอบ Plus และ Minus |
| Fixed | 1 | ระบุว่าความยาวของบาร์ความคลาดเคลื่อนจะเป็นค่าคงที่ที่กำหนดโดย Error Bar Value |
| Percentage | 2 | ระบุว่าความยาวของบาร์ความคลาดเคลื่อนจะเป็นเปอร์เซ็นต์ Error Bar Value ของข้อมูล |
| StandardDeviation | 3 | ระบุว่าความยาวของบาร์ความคลาดเคลื่อนจะเป็นส่วนเบี่ยงเบนมาตรฐาน Error Bar Value ของข้อมูล |
| StandardError | 4 | ระบุว่าความยาวของบาร์ความคลาดเคลื่อนจะเป็นค่าความคลาดเคลื่อนมาตรฐาน Error Bar Value ของข้อมูล |
