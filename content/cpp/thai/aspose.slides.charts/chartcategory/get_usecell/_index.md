## ChartCategory::get_UseCell() วิธีการ

หากเป็น true แล้วคุณสมบัติ AsCell จะเป็นค่าจริง อีกนัยหนึ่ง แผ่นงานจะถูกใช้เพื่อเก็บหมวดหมู่ (กรณีนี้รองรับหมวดหมู่หลายระดับ) หากเป็น false แล้วคุณสมบัติ AsLiteral จะเป็นค่าจริง อีกนัยหนึ่ง แผ่นงาน **ไม่**ถูกใช้เพื่อเก็บหมวดหมู่ (และกรณีนี้ไม่รองรับหมวดหมู่หลายระดับ) อ่านอย่างเดียว **bool**.

```cpp
bool Aspose::Slides::Charts::ChartCategory::get_UseCell() override
```

## หมายเหตุ

เพื่อเปลี่ยนค่าของคุณสมบัตินี้ (สำหรับทุกหมวดหมู่ในคอลเลกชัน) ให้กำหนดค่าที่ใหม่ให้กับคุณสมบัติ ChartCategoryCollection::get(set)_UseCells
