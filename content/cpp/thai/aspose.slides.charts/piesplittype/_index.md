## PieSplitType enum

อธิบายประเภทของจุดการแยกในพายหรือแถบที่สองบนแผนภูมิประเภทพาย-ของพายหรือแถบ-ของพาย

```cpp
enum class PieSplitType
```

### ค่าต่าง ๆ

| Name | Value | รายละเอียด |
| --- | --- | --- |
| Default | 0 | ระบุว่าจุดข้อมูลจะถูกแยกโดยใช้กลไกค่าเริ่มต้นสำหรับประเภทแผนภูมินี้ |
| Custom | 1 | ระบุว่าจุดข้อมูลจะถูกแยกระหว่างพายและแผนภูมิที่สองตามค่า Custom Split |
| ByPercentage | 2 | ระบุว่าจุดข้อมูลจะถูกแยกระหว่างพายและแผนภูมิที่สองโดยใส่จุดที่มีเปอร์เซ็นต์น้อยกว่า Split Position ในแผนภูมิที่สอง |
| ByPos | 3 | ระบุว่าจุดข้อมูลจะถูกแยกระหว่างพายและแผนภูมิที่สองโดยใส่ตำแหน่ง Split Position สุดท้ายของจุดข้อมูลในแผนภูมิที่สอง |
| ByValue | 4 | ระบุว่าจุดข้อมูลจะถูกแยกระหว่างพายและแผนภูมิที่สองโดยใส่จุดข้อมูลที่มีค่า น้อยกว่า Split Position ในแผนภูมิที่สอง |
