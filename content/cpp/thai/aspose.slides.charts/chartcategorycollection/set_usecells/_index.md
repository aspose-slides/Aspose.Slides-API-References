## ChartCategoryCollection::set_UseCells(bool) วิธีการ


หากเป็น true แล้ว worksheet จะถูกใช้สำหรับเก็บหมวดหมู่ (กรณีนี้สนับสนุนหมวดหมู่หลายระดับ) หากเป็น false แล้ว worksheet จะ NOT ถูกใช้สำหรับเก็บค่า (และกรณีนี้ไม่สนับสนุนหมวดหมู่หลายระดับ) เขียน **bool**.
