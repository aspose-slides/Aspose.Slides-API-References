## ChartShapeType enum

Represents a shape of chart.

```cpp
enum class ChartShapeType
```

### ค่า

| Name | Value | Description |
| --- | --- | --- |
| NotDefined | -1 | [Chart](../chart/) shape ไม่ได้ถูกกำหนด. |
| Box | 0 | ระบุว่าแผนภูมิจะถูกวาดด้วยรูปร่างแบบกล่อง. |
| Cone | 1 | ระบุว่าแผนภูมิจะถูกวาดเป็นกรวย โดยฐานของกรวยวางบนพื้นและจุดของกรวยอยู่ที่ยอดของเครื่องหมายข้อมูล. |
| ConeToMax | 2 | ระบุว่าแผนภูมิจะถูกวาดด้วยกรวยตัดส่วนที่ทำให้จุดของกรวยเป็นค่าข้อมูลสูงสุด. |
| Cylinder | 3 | ระบุว่าแผนภูมิจะถูกวาดเป็นทรงกระบอก. |
| Pyramid | 4 | ระบุว่าแผนภูมิจะถูกวาดเป็นพีระมิดสี่เหลี่ยมโดยฐานของพีระมิดวางบนพื้นและจุดของพีระมิดอยู่ที่ยอดของเครื่องหมายข้อมูล. |
| PyramidToMaximum | 5 | ระบุว่าแผนภูมิจะถูกวาดด้วยกรวยตัดส่วนที่ทำให้จุดของกรวยเป็นค่าข้อมูลสูงสุด. |
