## IChartCategoryCollection::set_UseCells(bool) เมธอด

ถ้าเป็น true แล้ว worksheet จะถูกใช้สำหรับเก็บหมวดหมู่ (กรณีนี้รองรับหมวดหมู่หลายระดับ) หากเป็น false แล้ว worksheet จะ NOT ถูกใช้สำหรับเก็บค่า (และกรณีนี้ไม่รองรับหมวดหมู่หลายระดับ) เขียน **bool**.
