## ChartSeries::get_FirstSliceAngle() เมธอด

ระบุมุมของส่วนแรกของแผนภูมิพายหรือโดนัท, หน่วยเป็นองศา (ตามเข็มนาฬิกาตั้งแต่บน, ตั้งแต่ 0 ถึง 360 องศา). นี่เป็นคุณสมบัติไม่เพียงของซีรีส์นี้เท่านั้น แต่ยังของทุกซีรีส์ในกลุ่มซีรีส์พาเร็นท์ - เป็นการฉายของคุณสมบัติของกลุ่มที่เหมาะสม. ดังนั้นคุณสมบัตินี้เป็นแบบอ่านอย่างเดียว. ใช้คุณสมบัติ ParentSeriesGroup เพื่อเข้าถึงกลุ่มซีรีส์พาเร็นท์. ใช้ [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_FirstSliceAngle() คุณสมบัติอ่าน/เขียนเพื่อเปลี่ยนค่า. อ่านอย่างเดียว **uint16_t**.

```cpp
uint16_t Aspose::Slides::Charts::ChartSeries::get_FirstSliceAngle() override
```

## หมายเหตุ

นี่คือการฉายของคุณสมบัติ [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_FirstSliceAngle().
