## ChartSeriesCollection::virtualizeBeginConstIterator() const เมธอด

รับ iterator ที่ชี้ไปยังองค์ประกอบแรก (หากมี) ของอินสแตนซ์ที่มีคุณลักษณะ const ของคอลเลกชัน.

```cpp
virtualized_iterator * Aspose::Slides::Charts::ChartSeriesCollection::virtualizeBeginConstIterator() const override
```

### ค่าที่ส่งคืน
