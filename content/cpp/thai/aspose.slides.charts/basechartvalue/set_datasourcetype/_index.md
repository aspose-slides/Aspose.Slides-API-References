## BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType) เมธอด

ระบุว่า AsCell, AsCells, AsLiteralString หรือ AsLiteralDouble คุณสมบัติ มีอยู่จริงในคลาสลูกหรือไม่ อีกอย่างหนึ่ง มันระบุประเภทของค่าของคุณสมบัติ Data เขียน [Charts::DataSourceType](../../datasourcetype/).

```cpp
void Aspose::Slides::Charts::BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType value) override
```

## หมายเหตุ

สำหรับจุดใน [ChartDataPointCollection](../../chartdatapointcollection/) คุณสมบัตินี้เป็นแบบอ่านอย่างเดียว ในกรณีนี้เพื่อเปลี่ยนค่าของคุณสมบัตินี้ คุณสามารถใช้หนึ่งในคุณสมบัติของ ChartDataPointCollection.DataSourceTypeFor<...>.
