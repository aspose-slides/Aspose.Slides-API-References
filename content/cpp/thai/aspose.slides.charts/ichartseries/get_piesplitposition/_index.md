## IChartSeries::get_PieSplitPosition() เมธอด

ระบุค่าที่จะใช้เพื่อกำหนดจุดข้อมูลใดอยู่ในพายหรือแถบที่สองบนแผนภูมิ pie-of-pie หรือ bar-of-pie ใช้ร่วมกับคุณสมบัติ PieSplitBy นี้เป็นคุณสมบัติไม่เพียงของชุดข้อมูลนี้แต่ของชุดข้อมูลทั้งหมดในกลุ่มชุดข้อมูลหลัก – เป็นการฉายของคุณสมบัติกลุ่มที่เหมาะสม ดังนั้นคุณสมบัตินี้เป็นแบบอ่านอย่างเดียว ใช้คุณสมบัติ ParentSeriesGroup เพื่อเข้าถึงกลุ่มชุดข้อมูลหลัก ใช้ [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_PieSplitPosition() คุณสมบัติอ่าน/เขียนเพื่อเปลี่ยนค่า อ่านอย่างเดียว **double**.

```cpp
virtual double Aspose::Slides::Charts::IChartSeries::get_PieSplitPosition()=0
```

## หมายเหตุ

นี่คือการฉายของคุณสมบัติ [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_PieSplitPosition().
