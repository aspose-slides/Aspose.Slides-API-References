## IChartSeries::get_Smooth() เมธอด

แสดงการทำให้เส้นโค้งเรียบ. เป็น True หากการทำให้เส้นโค้งเรียบเปิดใช้งานสำหรับแผนภูมิเส้นหรือแผนภูมิกระจาย. ใช้ได้เฉพาะกับแผนภูมิเส้นและแผนภูมิกระจายที่เชื่อมต่อด้วยเส้น. อ่าน **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IChartSeries::get_Smooth()=0
```
