## IChartSeries::get_HasUpDownBars() เมธอด


กำหนดว่ากราฟแบบเส้นหรือแบบหุ้นมีแถบขึ้น/ลงหรือไม่. นี้เป็นคุณสมบัติไม่เพียงของชุดข้อมูลนี้เท่านั้น แต่ของชุดข้อมูลทั้งหมดในกลุ่มชุดข้อมูลแม่ - เป็นการฉายของคุณสมบัติของกลุ่มที่เหมาะสม. ดังนั้นคุณสมบัตินี้เป็นแบบอ่านอย่างเดียว. ใช้คุณสมบัติ ParentSeriesGroup เพื่อเข้าถึงกลุ่มชุดข้อมูลแม่. ใช้ [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get_UpDownBars()->get(set)_HasUpDownBars() คุณสมบัติอ่าน/เขียนเพื่อเปลี่ยนค่า. ใช้คุณสมบัติ [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get_UpDownBars() เพื่อจัดรูปแบบแถบขึ้น/ลง. อ่านอย่างเดียว **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IChartSeries::get_HasUpDownBars()=0
```

## หมายเหตุ


นี่เป็นการฉายของคุณสมบัติ [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get_UpDownBars()->get(set)_HasUpDownBars().
