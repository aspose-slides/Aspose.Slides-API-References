## IChartSeries::get_BubbleSizeScale() เมธอด

ระบุปัจจัยสเกลสำหรับแผนภูมิกระจุก (สามารถอยู่ระหว่าง 0 ถึง 300 เปอร์เซ็นต์ของขนาดเริ่มต้น) นี่เป็นคุณสมบัติไม่เพียงของซีรีส์นี้แต่ของทั้งหมดในกลุ่มซีรีส์แม่ - นี่คือการฉายของคุณสมบัติของกลุ่มที่เหมาะสม ดังนั้นคุณสมบัตินี้เป็นอ่านอย่างเดียว ใช้คุณสมบัติ ParentSeriesGroup เพื่อเข้าถึงกลุ่มซีรีส์แม่ ใช้ [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_BubbleSizeScale() คุณสมบัติอ่าน/เขียนเพื่อเปลี่ยนค่า.

```cpp
virtual int32_t Aspose::Slides::Charts::IChartSeries::get_BubbleSizeScale()=0
```

## หมายเหตุ

นี่คือการฉายของคุณสมบัติ [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_BubbleSizeScale().
