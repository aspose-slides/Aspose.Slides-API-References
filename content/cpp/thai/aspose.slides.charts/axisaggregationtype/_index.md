## AxisAggregationType enum

แสดงประเภทการรวมของแกนหมวดหมู่ ใช้กับซีรีส์ Histogram หรือ HistogramPareto เท่านั้น.

```cpp
enum class AxisAggregationType
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| ByCategory | 0 | รวมตามหมวดหมู่ |
| Automatic | 1 | รวมหมวดหมู่โดยอัตโนมัติ. |
| ByBinWidth | 2 | รวมหมวดหมู่ตามความกว้างของบินด์. Property IAxis::get(set)_BinWidth ต้องตั้งค่า. |
| ByNumberOfBins | 3 | รวมหมวดหมู่ตามจำนวนของบินด์. Property IAxis::get(set)_NumberOfBins ต้องตั้งค่า. |
