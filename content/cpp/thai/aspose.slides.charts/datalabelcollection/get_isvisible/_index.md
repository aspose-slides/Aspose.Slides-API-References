## DataLabelCollection::get_IsVisible() เมธอด


False หมายถึงป้ายข้อมูลไม่แสดงโดยค่าเริ่มต้น (และดังนั้นทุก Show*-flags (ShowValue, ...) ของคุณสมบัติ DefaultDataLabelFormat จะเป็น false) อ่านอย่างเดียว **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelCollection::get_IsVisible() override
```

## หมายเหตุ


If data label is visible by default you can make it hidden by default with [Hide()](../hide/) เมธอด. แต่หากป้ายข้อมูลไม่แสดงโดยค่าเริ่มต้น (IsVisible เป็น false) คุณสามารถทำให้ป้ายข้อมูล "แสดงโดยค่าเริ่มต้น" ด้วยการตั้งค่า Show*-flags (ShowValue, ...) ของคุณสมบัติ DefaultDataLabelFormat ให้เป็นสถานะ true
