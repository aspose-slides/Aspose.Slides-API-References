## DataLabelCollection::Hide() เมธอด

ทำให้ป้ายข้อมูลซ่อนโดยค่าเริ่มต้นโดยตั้งค่า Show*-flags (ShowValue, ...) ของคุณสมบัติ DefaultDataLabelFormat เป็นสถานะ false. IsVisible จะเป็น false หลังจากนี้.

```cpp
void Aspose::Slides::Charts::DataLabelCollection::Hide() override
```

## หมายเหตุ

หากป้ายข้อมูลไม่แสดงโดยค่าเริ่มต้น (IsVisible เป็น false) คุณสามารถทำให้ป้ายข้อมูล \"visible 
by default\" ด้วยการตั้งค่า Show*-flags (ShowValue, ...) ของคุณสมบัติ DefaultDataLabelFormat เป็นสถานะ true.
