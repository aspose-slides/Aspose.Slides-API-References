## MarkerStyleType enum

กำหนดรูปแบบของเครื่องหมายบนจุดข้อมูลของแผนภูมิ.

```cpp
enum class MarkerStyleType
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| NotDefined | -1 |  |
| Circle | 0 | ระบุให้วาดวงกลมที่แต่ละจุดข้อมูล. |
| Dash | 1 | ระบุให้วาดเส้นประที่แต่ละจุดข้อมูล. |
| Diamond | 2 | ระบุให้วาดรูปสี่เหลี่ยมเพชรที่แต่ละจุดข้อมูล. |
| Dot | 3 | ระบุให้วาดจุดที่แต่ละจุดข้อมูล. |
| None | 4 | ระบุว่าไม่มีอะไรถูกวาดที่แต่ละจุดข้อมูล. |
| Picture | 5 | ระบุให้วาดรูปภาพที่แต่ละจุดข้อมูล. |
| Plus | 6 | ระบุให้วาดเครื่องหมายบวกที่แต่ละจุดข้อมูล. |
| Square | 7 | ระบุให้วาดสี่เหลี่ยมที่แต่ละจุดข้อมูล. |
| Star | 8 | ระบุให้วาดดาวที่แต่ละจุดข้อมูล. |
| Triangle | 9 | ระบุให้วาดรูปสามเหลี่ยมที่แต่ละจุดข้อมูล. |
| X | 10 | ระบุให้วาดสัญลักษณ์ X ที่แต่ละจุดข้อมูล. |
