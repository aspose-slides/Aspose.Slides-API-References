## ThreadPool::SetMaxThreads(int, int) เมธอด

ตั้งค่าจำนวนเธรดที่ pool ถือครอง

```cpp
static bool System::Threading::ThreadPool::SetMaxThreads(int wt, int cpt)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| wt | int | จำนวนสูงสุดของเธรดผู้ทำงาน |
| cpt | int | จำนวนสูงสุดของเธรด [IO](../../../system.io/) |

### ค่าที่ส่งคืน

True หากพารามิเตอร์ได้รับการยอมรับ, false ในกรณีอื่น
