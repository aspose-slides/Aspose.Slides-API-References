```cpp
enum class XPathNamespaceScope
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| All | 0 | ส่งกลับ namespace ทั้งหมดที่กำหนดไว้ในขอบเขตของโหนดปัจจุบัน รวมถึง namespace **xmlns:xml** ที่จะประกาศโดยอัตโนมัติเสมอ ลำดับของ namespace ที่ส่งกลับไม่มีการกำหนด |
| ExcludeXml | 1 | ส่งกลับ namespace ทั้งหมดที่กำหนดไว้ในขอบเขตของโหนดปัจจุบัน ยกเว้น namespace **xmlns:xml**. namespace **xmlns:xml** จะถูกประกาศโดยอัตโนมัติเสมอ ลำดับของ namespace ที่ส่งกลับไม่มีการกำหนด |
| Local | 2 | ส่งกลับ namespace ทั้งหมดที่กำหนดไว้ในระดับท้องถิ่นของโหนดปัจจุบัน |
