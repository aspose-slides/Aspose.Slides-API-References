## XmlCaseOrder enum

ระบุลำดับการจัดเรียงสำหรับตัวอักษรพิมพ์ใหญ่และพิมพ์เล็ก

```cpp
enum class XmlCaseOrder
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| None | 0 | เพิกเฉยต่อการแยกแยะตัวอักษร |
| UpperFirst | 1 | ตัวอักษรพิมพ์ใหญ่จะถูกจัดเรียงก่อนตัวพิมพ์เล็ก |
| LowerFirst | 2 | ตัวอักษรพิมพ์เล็กจะถูกจัดเรียงก่อนตัวพิมพ์ใหญ่ |
