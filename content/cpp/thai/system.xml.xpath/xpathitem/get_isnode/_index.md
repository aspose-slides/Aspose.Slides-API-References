## XPathItem::get_IsNode() เมธอด


เมื่อทำการเขียนทับในคลาสที่สืบทอด, จะได้รับค่าที่บ่งบอกว่ารายการเป็นโหนด [XPath](../../) หรือเป็นค่าอะตอมิก.

```cpp
virtual bool System::Xml::XPath::XPathItem::get_IsNode()=0
```


### ค่าที่ส่งกลับ

**true** หากรายการเป็นโหนด [XPath](../../); **false** หากรายการเป็นค่าอะตอมิก.
