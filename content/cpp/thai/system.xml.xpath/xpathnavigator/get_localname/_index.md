## XPathNavigator::get_LocalName() เมธอด


เมื่อถูก override ในคลาสที่สืบทอด, จะดึง [XPathNavigator::get_Name](../get_name/) ของโหนดปัจจุบันโดยไม่มีคำนำหน้าช่วงชื่อ.

```cpp
virtual String System::Xml::XPath::XPathNavigator::get_LocalName()=0
```


### ค่าที่ส่งคืน

เป็น [String](../../../system/string/) ที่ประกอบด้วยชื่อท้องถิ่นของโหนดปัจจุบัน, หรือ [String::Empty](../../../system/string/empty/) หากโหนดปัจจุบันไม่มีชื่อ (เช่น โหนดข้อความหรือคอมเมนต์).
