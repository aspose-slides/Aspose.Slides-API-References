## XPathNavigator::MoveToNextAttribute() เมธอด

When overridden in a derived class, จะย้าย [XPathNavigator](../) ไปยังแอตทริบิวต์ถัดไป.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToNextAttribute()=0
```

### ค่าที่ส่งคืน

**true** หาก [XPathNavigator](../) สำเร็จในการย้ายไปยังแอตทริบิวต์ถัดไป; **false** หากไม่มีแอตทริบิวต์เพิ่มเติม. หาก **false**, ตำแหน่งของ [XPathNavigator](../) จะไม่เปลี่ยนแปลง.
