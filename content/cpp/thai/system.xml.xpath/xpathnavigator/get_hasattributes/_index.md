## XPathNavigator::get_HasAttributes() เมธอด

คืนค่าที่บ่งชี้ว่าโหนดปัจจุบันมีแอตทริบิวต์หรือไม่.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::get_HasAttributes()
```

### ค่าที่ส่งกลับ

**true** หากโหนดปัจจุบันมีแอตทริบิวต์; คืนค่า **false** หากโหนดปัจจุบันไม่มีแอตทริบิวต์, หรือหาก [XPathNavigator](../) ไม่ได้อยู่บนโหนดประเภท element.
