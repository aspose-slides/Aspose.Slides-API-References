## XPathNavigator::MoveToId(String) เมธอด

เมื่อทำการเขียนทับในคลาสที่สืบทอด จะย้ายไปยังโหนดที่มีแอตทริบิวต์ประเภท **ID** ที่ค่าตรงกับ [String](../../../system/string/) ที่ระบุ

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToId(String id)=0
```

### พารามิเตอร์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| id | [String](../../../system/string/) | [String](../../../system/string/) ที่แสดงถึงค่า **ID** ของโหนดที่คุณต้องการย้ายไป. |

### ค่ารีเทิร์น

**true** หากการย้ายของ [XPathNavigator](../) สำเร็จ; มิฉะนั้น **false**. หาก **false**, ตำแหน่งของ navigator จะไม่เปลี่ยนแปลง.
