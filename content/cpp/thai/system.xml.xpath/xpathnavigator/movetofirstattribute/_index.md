## XPathNavigator::MoveToFirstAttribute() เมธอด

เมื่อถูก override ในคลาสที่สืบทอด, จะย้าย [XPathNavigator](../) ไปยังแอตทริบิวต์แรกของโหนดปัจจุบัน.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToFirstAttribute()=0
```

### ค่าที่คืน

**true** หาก [XPathNavigator](../) สำเร็จในการย้ายไปยังแอตทริบิวต์แรกของโหนดปัจจุบัน; มิฉะนั้น, **false**. หาก **false**, ตำแหน่งของ [XPathNavigator](../) จะไม่เปลี่ยนแปลง.
