## XPathNavigator::MoveToAttribute(String, String) method

ย้าย [XPathNavigator](../) ไปยังแอตทริบิวต์ที่มีชื่อท้องถิ่นและ URI ของเนมสเปซที่ตรงกัน.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToAttribute(String localName, String namespaceURI)
```

### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| localName | [String](../../../system/string/) | ชื่อท้องถิ่นของแอตทริบิวต์ |
| namespaceURI | [String](../../../system/string/) | URI ของเนมสเปซของแอตทริบิวต์; **nullptr** สำหรับเนมสเปซที่ว่างเปล่า |

### ค่าที่ส่งกลับ

**true** หากการย้าย [XPathNavigator](../) ไปยังแอตทริบิวต์สำเร็จ; มิฉะนั้น **false**. ถ้า **false**, ตำแหน่งของ [XPathNavigator](../) จะไม่เปลี่ยนแปลง
