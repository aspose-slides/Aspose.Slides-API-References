## XPathNavigator::MoveToFirstChild() เมธอด


When overridden in a derived class, moves the [XPathNavigator](../) to the first child node of the current node.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToFirstChild()=0
```


### ค่าที่ส่งคืน

**true** หาก [XPathNavigator](../) ทำการย้ายไปยังโหนดลูกตัวแรกของโหนดปัจจุบันสำเร็จ; มิฉะนั้น, **false**. หาก **false**, ตำแหน่งของ [XPathNavigator](../) จะไม่เปลี่ยนแปลง.
