## XPathNavigator::MoveToParent() เมธอด

เมื่อเขียนทับในคลาสที่สืบทอด, จะย้าย [XPathNavigator](../) ไปยังโหนดแม่ของโหนดปัจจุบัน.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToParent()=0
```

### ค่าที่ส่งกลับ

**true** หาก [XPathNavigator](../) ย้ายไปยังโหนดแม่ของโหนดปัจจุบันสำเร็จ; มิฉะนั้น **false**. หาก **false**, ตำแหน่งของ [XPathNavigator](../) จะไม่เปลี่ยนแปลง.
