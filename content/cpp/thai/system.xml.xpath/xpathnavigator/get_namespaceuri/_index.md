## XPathNavigator::get_NamespaceURI() เมธอด


เมื่อถูกเขียนทับในคลาสที่สืบทอด, จะรับค่า namespace URI ของโหนดปัจจุบัน.

```cpp
virtual String System::Xml::XPath::XPathNavigator::get_NamespaceURI()=0
```


### ค่าที่ส่งกลับ

เป็น [String](../../../system/string/) ที่เก็บ namespace URI ของโหนดปัจจุบัน, หรือ [String::Empty](../../../system/string/empty/) หากโหนดปัจจุบันไม่มี namespace URI.
