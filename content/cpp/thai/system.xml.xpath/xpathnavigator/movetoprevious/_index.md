## XPathNavigator::MoveToPrevious() เมธอด


เมื่อถูกเขียนทับในคลาสที่สืบทอด, จะย้าย [XPathNavigator](../) ไปยังโหนดพี่น้องก่อนหน้าของโหนดปัจจุบัน.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToPrevious()=0
```


### ค่าที่ส่งคืน

**true** หาก [XPathNavigator](../) สำเร็จในการย้ายไปยังโหนดพี่น้องก่อนหน้า; มิฉะนั้น, **false** หากไม่มีโหนดพี่น้องก่อนหน้า หรือหาก [XPathNavigator](../) อยู่ในตำแหน่งโหนดแอตทริบิวต์ ณ ปัจจุบัน. หาก **false**, ตำแหน่งของ [XPathNavigator](../) จะไม่เปลี่ยนแปลง.
