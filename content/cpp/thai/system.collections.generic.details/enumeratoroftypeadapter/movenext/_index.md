## EnumeratorOfTypeAdapter::MoveNext() เมธอด


ย้าย enumerator ไปยังองค์ประกอบถัดไป หากไม่มีองค์ประกอบใดถูกอ้างอิงก่อนหน้า จะตั้งค่าอ้างอิงเป็นองค์ประกอบแรกที่มีอยู่ หากถึงจุดสิ้นสุดของคอนเทนเนอร์ จะไม่ทำอะไร

```cpp
bool System::Collections::Generic::Details::EnumeratorOfTypeAdapter<Source, Result>::MoveNext() override
```


### ค่าที่คืน

True หากมีองค์ประกอบบางอย่างพร้อมให้ใช้หลังจากเรียก, false ในกรณีอื่น
