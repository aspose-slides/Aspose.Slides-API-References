## EnumeratorSelectAdapter::MoveNext() เมธอด

ย้าย enumerator ไปยัง element ถัดไป หากไม่มี element ใดถูกอ้างอิงมาก่อน จะตั้งค่า reference ให้เป็น element แรกที่มีอยู่ หาก container สิ้นสุดแล้ว จะไม่ทำอะไร

```cpp
bool System::Collections::Generic::Details::EnumeratorSelectAdapter<Source, Result>::MoveNext() override
```

### ค่าที่คืน

True หากมี element ที่พร้อมใช้งานหลังจากการเรียก, false ในกรณีอื่น
