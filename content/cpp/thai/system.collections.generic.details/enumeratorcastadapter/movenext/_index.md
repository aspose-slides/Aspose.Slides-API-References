## EnumeratorCastAdapter::MoveNext() เมธอด

ย้าย enumerator ไปยังองค์ประกอบถัดไป หากไม่มีองค์ประกอบใดถูกอ้างอิงก่อนหน้านี้ จะตั้งค่าอ้างอิงไปยังองค์ประกอบแรกที่มี หากถึงจุดสิ้นสุดของคอนเทนเนอร์ จะไม่ทำอะไร

```cpp
bool System::Collections::Generic::Details::EnumeratorCastAdapter<Source, Result>::MoveNext() override
```

### ค่าที่คืน

True หากมีองค์ประกอบบางส่วนพร้อมให้เรียกใช้หลังจากเรียกเมธอดนี้, false หากไม่มี
