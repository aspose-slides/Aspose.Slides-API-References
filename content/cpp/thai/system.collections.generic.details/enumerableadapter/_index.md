## EnumerableAdapter คลาส

Enumerable ถูกใช้โดยเมธอดส่วนขยาย IEnumerable.Cast() และ IEnumerable.OfType().

```cpp
template<typename Source,typename Result,typename EnumeratorAdapter>class EnumerableAdapter : public System::Collections::Generic::IEnumerable<Result>
```


### พารามิเตอร์แม่แบบ

| พารามิเตอร์ | คำอธิบาย |
| --- | --- |
| Source | ประเภทต้นทางของอิลิเมนต์ในคอลเลกชัน. |
| Result | ประเภทผลลัพธ์ของอิลิเมนต์ในคอลเลกชัน. |
| EnumeratorAdapter | ประเภทของตัวแปลง enumerator. |
