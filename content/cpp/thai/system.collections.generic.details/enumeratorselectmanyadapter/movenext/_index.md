## EnumeratorSelectManyAdapter::MoveNext() เมธอด

ย้ายตัววนซ้ำไปยังองค์ประกอบถัดไป หากไม่มีองค์ประกอบใดถูกอ้างอิงก่อนหน้า จะตั้งค่าการอ้างอิงเป็นองค์ประกอบแรกที่สามารถใช้ได้ หากถึงจุดสิ้นสุดของคอนเทนเนอร์ จะไม่มีการทำอะไร

```cpp
bool System::Collections::Generic::Details::EnumeratorSelectManyAdapter<Source, Result>::MoveNext() override
```

### ค่าที่ส่งกลับ

True หากมีองค์ประกอบบางอย่างพร้อมใช้งานหลังจากเรียก, false ในกรณีอื่น
