## System::Collections::Generic::Details::IsOutOfSize(int, const Container\&) ฟังก์ชัน


ตรวจสอบว่าดัชนีอยู่นอกขอบเขตของคอนเทนเนอร์หรือไม่ รวมถึงขนาดของคอนเทนเนอร์

```cpp
template<typename Container> bool System::Collections::Generic::Details::IsOutOfSize(int count, const Container &container)
```


### พารามิเตอร์แม่แบบ

| Parameter | Description |
| --- | --- |
| Container | ประเภทของคอนเทนเนอร์. |

### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| count | int | [Index](../../system/index/). |
| container | const Container\& | คอนเทนเนอร์ที่ใช้ตรวจสอบดัชนี. |

### ค่าที่ส่งกลับ

true หากดัชนีอยู่นอกขอบเขตของคอนเทนเนอร์, false ไม่เช่นนั้น.
