## Timer::set_Enabled(bool) เมธอด

เริ่มหรือหยุดตัวจับเวลา. การเริ่มต้นตัวจับเวลาไม่ทำให้การนับเวลากลับมาเริ่มใหม่หากตัวจับเวลาอยู่ระหว่างทำงานอยู่แล้ว.

```cpp
void System::Timers::Timer::set_Enabled(bool value)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| value | **bool** | true เพื่อเริ่มตัวจับเวลา, false เพื่อหยุด. |
