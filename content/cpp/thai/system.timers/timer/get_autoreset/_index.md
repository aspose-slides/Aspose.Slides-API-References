## Timer::get_AutoReset() const เมธอด

ตรวจสอบว่าไทม์เมอร์อยู่ในโหมดรีเซ็ตอัตโนมัติหรือไม่.

```cpp
bool System::Timers::Timer::get_AutoReset() const
```

### ค่าที่ส่งกลับ

true หากไทม์เมอร์ทำงานวนซ้ำ, false หากหยุดหลังจากการเรียกครั้งแรก.
