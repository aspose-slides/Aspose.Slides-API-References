## Form คลาส


คลาสจำลองเพื่อทำให้โค้ดที่แปลใช้คลาส [Form](./) สามารถคอมไพล์ได้. เมธอดไม่ได้ทำการ implement. วัตถุของคลาสนี้ควรจะจัดสรรโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น. ห้ามสร้างอินสแตนซ์ของชนิดนี้บนสแตกหรือโดยใช้ operator new, เพราะจะทำให้เกิดข้อผิดพลาดรันไทม์และ/หรือการตรวจสอบความถูกต้อง. เสมอห่อคลาสนี้ในพอยเตอร์ [System::SmartPtr](../../system/smartptr/) และใช้พอยเตอร์นี้เพื่อส่งเป็นอาร์กิวเมนต์ให้ฟังก์ชัน.

```cpp
class Form : public System::Windows::Forms::Control
```
