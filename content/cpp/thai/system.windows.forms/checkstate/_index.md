## CheckState enum

สถานะของคอนโทรลที่สามารถทำเครื่องหมายได้ (เช่น กล่องกาเครื่องหมาย).

```cpp
enum class CheckState
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Unchecked | 0 | ไม่ได้เลือก. |
| Checked | 1 | ทำเครื่องหมายแล้ว. |
| Indeterminate | 2 | สถานะการเปลี่ยนแปลงซึ่งส่วนใหญ่จะแสดงเป็นสีเทา. |
