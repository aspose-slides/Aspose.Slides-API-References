## FlatStyle enum

กำหนดว่าควบคุมจะถูกวาดเป็นแบบแบนหรือแบบสามมิติ

```cpp
enum class FlatStyle
```

### ค่า

| Name | Value | Description |
| --- | --- | --- |
| Flat | 0 | [Control](../control/) ถูกวาดเป็นแบบแบน. |
| Popup | 1 | [Control](../control/) ถูกวาดเป็นแบบแบนเว้นแต่เมาส์เคลื่อนที่เหนือมันเมื่อมันถูกวาดแบบ 3 มิติ. |
| Standard | 2 | [Control](../control/) ถูกวาดแบบ 3 มิติ. |
| System | 3 | สไตล์ถูกควบคุมโดย OS. |
