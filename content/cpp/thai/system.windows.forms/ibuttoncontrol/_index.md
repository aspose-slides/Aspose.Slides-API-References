## IButtonControl คลาส

คลาสเทียมเพื่อให้โค้ดแปลที่ใช้ [IButtonControl](./) interface สามารถคอมไพล์ได้. วัตถุของคลาสนี้ควรจะจัดสรรโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น. อย่าสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ operator new เพราะจะทำให้เกิดข้อผิดพลาดเวลารันและ/หรือการตรวจสอบ assertion. ควรห่อคลาสนี้ด้วยตัวชี้ [System::SmartPtr](../../system/smartptr/) แล้วใช้ตัวชี้นี้เพื่อส่งผ่านเป็นอาร์กิวเมนต์ให้กับฟังก์ชัน.

```cpp
class IButtonControl : public virtual System::Object
```
