## AutoSizeMode enum

กำหนดวิธีการทำงานของการปรับขนาดอัตโนมัติ

```cpp
enum class AutoSizeMode
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| GrowAndShrink | 0 | [Control](../control/) เติบโตและหดตัวตามที่จำเป็น ไม่สามารถปรับขนาดด้วยตนเองได้ |
| GrowOnly | 1 | [Control](../control/) เติบโตตามที่จำเป็นแต่ไม่สามารถหดตัวต่ำกว่าขนาดขั้นต่ำได้ สามารถปรับขนาดด้วยตนเองได้ |
