## JulianCalendar::IsLeapMonth(int, int, int) const เมธอด

ตรวจสอบว่าเดือนเป็นอธิกเดือนหรือไม่.

```cpp
bool System::Globalization::JulianCalendar::IsLeapMonth(int year, int month, int era) const override
```

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |

| month | int | เดือน. |

True หากเดือนที่ระบุเป็นเดือนอธิกเดือน, false ในกรณีอื่น.
