## NumberFormatInfo::get_NumberGroupSizes() const เมธอด


รับค่าจำนวนหลักต่อกลุ่ม.

```cpp
ArrayPtr<int> System::Globalization::NumberFormatInfo::get_NumberGroupSizes() const
```


### ค่าที่คืน

[Array](../../../system/array/) ของหลักต่อกลุ่มจากซ้ายไปขวา; แต่ละองค์ประกอบต้องเป็น 1 ถึง 9, ตัวสุดท้ายสามารถเป็น 0 ซึ่งหมายถึง \"combine all\"; ตัวสุดท้ายจะทำซ้ำ.
