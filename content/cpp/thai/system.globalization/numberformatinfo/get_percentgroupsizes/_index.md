## NumberFormatInfo::get_PercentGroupSizes() const เมธอด


รับจำนวนหลักของตัวเลขต่อแต่ละกลุ่มค่าร้อยละ.

```cpp
ArrayPtr<int> System::Globalization::NumberFormatInfo::get_PercentGroupSizes() const
```


### ค่าที่ส่งคืน

[Array](../../../system/array/) ของหลักต่อกลุ่มจากซ้ายไปขวา; แต่ละองค์ประกอบต้องเป็นค่าตั้งแต่ 1 ถึง 9, องค์ประกอบสุดท้ายสามารถเป็น 0 ซึ่งหมายถึง \"combine all\"; องค์ประกอบสุดท้ายทำซ้ำ.
