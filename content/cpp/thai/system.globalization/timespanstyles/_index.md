## TimeSpanStyles enum

ระบุตัวเลือกการจัดรูปแบบที่ปรับแต่งการแยกวิเคราะห์สตริงสำหรับเมธอดที่แปลงการแทนค่าข้อความของช่วงเวลาเป็นอ็อบเจกต์ Timespan

```cpp
enum class TimeSpanStyles : int32_t
```

### Values

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| None | 0 | ช่วงเวลาที่แสดงด้วยสตริงอินพุตจะถูกตีความเป็นช่วงเวลาลบเท่านั้นเมื่อมีสัญลักษณ์ลบอยู่ |
| AssumeNegative | 1 | ช่วงเวลาที่แสดงด้วยสตริงอินพุตจะถูกตีความเป็นช่วงเวลาลบเสมอ |
