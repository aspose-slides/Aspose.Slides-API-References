## DateTimeFormatInfo::get_IsReadOnly() const เมธอด

ตรวจสอบว่า ตัวจัดรูปแบบเป็นแบบอ่านอย่างเดียวหรือไม่.

```cpp
bool System::Globalization::DateTimeFormatInfo::get_IsReadOnly() const
```

### ค่าที่ส่งคืน

True หากตัวจัดรูปแบบเป็นแบบอ่านอย่างเดียว, false หากไม่เป็นเช่นนั้น.
