## DateTimeFormatInfo::ReadOnly(const DateTimeFormatInfoPtr\&) เมธอด

รับเวอร์ชันแบบอ่านอย่างเดียวของตัวจัดรูปแบบ.

```cpp
static DateTimeFormatInfoPtr System::Globalization::DateTimeFormatInfo::ReadOnly(const DateTimeFormatInfoPtr &info)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| info | const [DateTimeFormatInfoPtr](../../datetimeformatinfoptr/)\& | ตัวจัดรูปแบบเพื่อรับเวอร์ชันแบบอ่านอย่างเดียว |

### ค่าที่ส่งคืน

หาก **info** เป็นแบบอ่านอย่างเดียว จะส่งคืนค่าเดิม มิฉะนั้นจะสร้างสำเนาและทำให้เป็นแบบอ่านอย่างเดียว.
