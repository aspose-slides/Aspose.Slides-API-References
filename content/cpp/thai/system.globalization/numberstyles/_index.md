## NumberStyles enum

รูปแบบตัวเลขที่อนุญาตเมื่อทำการแยกวิเคราะห์.

```cpp
enum class NumberStyles : int32_t
```

### ค่า

| Name | Value | Description |
| --- | --- | --- |
| None | 0 | ไม่มีสัญลักษณ์ที่ไม่ใช่ตัวเลข |
| AllowLeadingWhite | 1 | อนุญาตช่องว่างนำหน้า |
| AllowTrailingWhite | 2 | อนุญาตช่องว่างตามหลัง |
| AllowLeadingSign | 4 | อนุญาตเครื่องหมายนำหน้า |
| Integer | n/a | รูปแบบจำนวนเต็มเริ่มต้น |
| AllowTrailingSign | 8 | อนุญาตเครื่องหมายตามหลัง |
| AllowParentheses | 16 | อนุญาตวงเล็บสำหรับค่าลบ |
| AllowDecimalPoint | 32 | อนุญาตจุดทศนิยม |
| AllowThousands | 64 | อนุญาตตัวคั่นกลุ่ม |
| Number | n/a | รูปแบบตัวเลขผสมเริ่มต้น |
| AllowExponent | 128 | อนุญาตเครื่องหมายเลขชี้กำลัง |
| Float | n/a | รูปแบบจำนวนจุดลอยตามค่าเริ่มต้น |
| AllowCurrencySymbol | 256 | อนุญาตสัญลักษณ์สกุลเงิน |
| Currency | n/a | รูปแบบสกุลเงินเริ่มต้น |
| Any | n/a | อนุญาตตัวระบุรูปแบบใดๆ |
| AllowHexSpecifier | 512 | อนุญาตตัวเลขฐานสิบหก |
| HexNumber | n/a | รูปแบบตัวเลขฐานสิบหกเริ่มต้น |
