## XmlNodeReader::MoveToElement() เมธอด

ย้ายไปยังองค์ประกอบที่มีโหนดแอตทริบิวต์ปัจจุบัน

```cpp
bool System::Xml::XmlNodeReader::MoveToElement() override
```

### ค่าที่ส่งคืน

**true** ถ้ารีเดอร์อยู่ที่แอตทริบิวต์ (รีเดอร์ย้ายไปยังองค์ประกอบที่เป็นเจ้าของแอตทริบิวต์); **false** ถ้ารีเดอร์ไม่ได้อยู่ที่แอตทริบิวต์ (ตำแหน่งของรีเดอร์ไม่มีการเปลี่ยนแปลง)
