## XmlNodeReader::ReadString() เมธอด

อ่านเนื้อหาขององค์ประกอบหรือโหนดข้อความเป็นสตริง.

```cpp
String System::Xml::XmlNodeReader::ReadString() override
```

### ค่าที่ส่งคืน

เนื้อหาขององค์ประกอบหรือโหนดที่คล้ายข้อความ (สิ่งนี้อาจรวมถึง CDATA, [Text](../../../system.text/) โหนด, และอื่น ๆ) ซึ่งอาจเป็นสตริงว่างหากรีดเดอร์อยู่ในตำแหน่งที่ไม่ใช่องค์ประกอบหรือโหนดข้อความ, หรือหากไม่มีเนื้อหาข้อความเพิ่มเติมให้ส่งคืนในบริบทปัจจุบัน. หมายเหตุ: โหนดข้อความอาจเป็นองค์ประกอบหรือโหนดข้อความของแอตทริบิวต์.
