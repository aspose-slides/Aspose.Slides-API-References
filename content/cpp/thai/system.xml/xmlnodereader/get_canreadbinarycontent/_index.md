## XmlNodeReader::get_CanReadBinaryContent() เมธอด

ส่งค่ากลับที่บ่งชี้ว่า [XmlNodeReader](../) ทำการใช้งานเมธอดการอ่านเนื้อหาไบนารี

```cpp
bool System::Xml::XmlNodeReader::get_CanReadBinaryContent() override
```

### ค่าที่ส่งกลับ

**true** หากเมธอดการอ่านเนื้อหาไบนารีถูกใช้งาน; มิฉะนั้น **false**. คลาส [XmlNodeReader](../) จะส่งค่ากลับเป็น **true** เสมอ.
