## XmlNodeReader::get_IsDefault() เมธอด

ส่งค่ากลับที่บ่งชี้ว่าโหนดปัจจุบันเป็นแอตทริบิวต์ที่ถูกสร้างจากค่าเริ่มต้นที่กำหนดในคำจำกัดความประเภทเอกสาร (DTD) หรือสคีม่า

```cpp
bool System::Xml::XmlNodeReader::get_IsDefault() override
```

### ค่าที่ส่งคืน

**true** หากโหนดปัจจุบันเป็นแอตทริบิวต์ที่ค่าถูกสร้างจากค่าเริ่มต้นที่กำหนดใน DTD หรือสคีม่า; **false** หากค่าของแอตทริบิวต์ถูกตั้งค่าโดยตรง
