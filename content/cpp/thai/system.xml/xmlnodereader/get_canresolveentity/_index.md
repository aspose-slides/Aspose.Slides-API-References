## XmlNodeReader::get_CanResolveEntity() เมธอด


ส่งค่าที่ระบุว่าผู้อ่านนี้สามารถแยกวิเคราะห์และแก้ไขเอนทิตี้ได้หรือไม่.

```cpp
bool System::Xml::XmlNodeReader::get_CanResolveEntity() override
```


### ค่าที่ส่งกลับ

**true** หากผู้อ่านสามารถแยกวิเคราะห์และแก้ไขเอนทิตี้ได้; มิฉะนั้น, **false**. [XmlNodeReader](../) จะส่งค่ากลับ **true** เสมอ.
