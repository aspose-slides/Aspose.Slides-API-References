## XmlNodeReader::get_IsEmptyElement() เมธอด

คืนค่าแสดงว่าตอนนี้โหนดเป็นองค์ประกอบที่ว่างเปล่าหรือไม่ (เช่น **<MyElement/>**).

```cpp
bool System::Xml::XmlNodeReader::get_IsEmptyElement() override
```

### ค่าที่ส่งกลับ

**true** หากโหนดปัจจุบันเป็นองค์ประกอบ ([XmlNodeReader::get_NodeType](../get_nodetype/) เท่ากับ [XmlNodeType::Element](../../xmlnodetype/)) และสิ้นสุดด้วย **/>**; มิฉะนั้น **false**.
