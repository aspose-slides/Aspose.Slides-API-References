## XmlDocumentType::get_IsReadOnly() เมธอด

คืนค่าที่บ่งบอกว่าโหนดเป็นแบบอ่านอย่างเดียวหรือไม่.

```cpp
bool System::Xml::XmlDocumentType::get_IsReadOnly() override
```

### ค่าที่ส่งคืน

**true** หากโหนดเป็นแบบอ่านอย่างเดียว; มิฉะนั้น, **false**. เนื่องจากโหนด DocumentType เป็นแบบอ่านอย่างเดียว, เมธอดนี้จะคืนค่า **true** เสมอ.
