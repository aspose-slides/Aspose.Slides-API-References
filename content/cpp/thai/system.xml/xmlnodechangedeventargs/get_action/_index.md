## XmlNodeChangedEventArgs::get_Action() method

คืนค่าหนึ่งที่บ่งบอกประเภทของเหตุการณ์การเปลี่ยนแหน่งโหนดที่กำลังเกิดขึ้น.

```cpp
XmlNodeChangedAction System::Xml::XmlNodeChangedEventArgs::get_Action()
```

### ค่าที่คืนกลับ

หนึ่งในค่าของ enumeration ที่อธิบายเหตุการณ์การเปลี่ยนแหน่งโหนด. ค่า **Action** ไม่แยกแยะว่าเหตุการณ์เกิดขึ้นเมื่อใด (ก่อนหรือหลัง). คุณสามารถสร้างตัวจัดการเหตุการณ์แยกต่างหากเพื่อจัดการกับทั้งสองกรณี.
