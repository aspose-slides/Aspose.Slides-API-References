## XmlNotation::get_IsReadOnly() เมธอด

คืนค่าซึ่งบ่งบอกว่าโหนดเป็นแบบอ่านอย่างเดียวหรือไม่.

```cpp
bool System::Xml::XmlNotation::get_IsReadOnly() override
```

### ค่าที่ส่งคืน

**true** หากโหนดเป็นแบบอ่านอย่างเดียว; มิฉะนั้น, **false**. เนื่องจากโหนด [XmlNotation](../) เป็นแบบอ่านอย่างเดียว, เมธอดนี้จะคืนค่า **true** เสมอ.
