## XmlConvert::IsXmlChar(char16_t) เมธอด

ตรวจสอบว่าตัวอักษรที่ส่งเข้ามาเป็นอักขระ XML ที่ถูกต้องหรือไม่.

```cpp
static bool System::Xml::XmlConvert::IsXmlChar(char16_t ch)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| ch | char16_t | อักขระที่ต้องตรวจสอบ. |

### ค่าที่ส่งกลับ

**true** หากตัวอักษรที่ส่งเข้ามาเป็นอักขระ XML ที่ถูกต้อง; มิฉะนั้น **false**.
