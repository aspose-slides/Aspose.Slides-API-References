## XmlConvert::VerifyWhitespace(const String\&) เมธอด

คืนค่าตัวอย่างสตริงที่ส่งเข้ามาหากอักขระทั้งหมดในอาร์กิวเมนต์สตริงเป็นอักขระช่องว่างที่ถูกต้อง

```cpp
static String System::Xml::XmlConvert::VerifyWhitespace(const String &content)
```

### พารามิเตอร์

| Parameter | Type | Description |
| --- | --- | --- |
| content | const [String](../../../system/string/)\& | [String](../../../system/string/) เพื่อตรวจสอบ. |

### ค่าที่ส่งคืน

ตัวอย่างสตริงที่ส่งเข้ามาหากอักขระทั้งหมดในอาร์กิวเมนต์สตริงเป็นอักขระช่องว่างที่ถูกต้อง, หากไม่เป็นเช่นนั้นจะคืนค่า **nullptr**.
