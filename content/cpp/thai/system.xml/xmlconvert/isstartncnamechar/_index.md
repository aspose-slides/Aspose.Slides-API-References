## XmlConvert::IsStartNCNameChar(char16_t) method

ตรวจสอบว่าตัวอักษรที่ส่งเข้ามาเป็นประเภทอักขระเริ่มต้นชื่อที่ถูกต้องหรือไม่.

```cpp
static bool System::Xml::XmlConvert::IsStartNCNameChar(char16_t ch)
```

### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| ch | char16_t | อักขระที่ต้องตรวจสอบ. |

### ค่าที่คืน

**true** หากอักขระเป็นประเภทอักขระเริ่มต้นชื่อที่ถูกต้อง; มิฉะนั้น **false**.
