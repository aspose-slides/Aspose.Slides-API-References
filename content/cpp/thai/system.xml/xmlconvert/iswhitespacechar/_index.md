## XmlConvert::IsWhitespaceChar(char16_t) เมธอด


ตรวจสอบว่าตัวอักษรที่ส่งเข้ามาเป็นอักขระช่องว่าง XML ที่ถูกต้องหรือไม่.

```cpp
static bool System::Xml::XmlConvert::IsWhitespaceChar(char16_t ch)
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| ch | char16_t | ตัวอักษรที่จะตรวจสอบ. |

### ค่าที่ส่งกลับ

**true** if the passed in character is a valid XML whitespace character; otherwise, **false**.
