## XmlConvert::VerifyXmlChars(const String\&) เมธอด


ส่งคืนสตริงที่ส่งเข้าไปหากอักขระทั้งหมดและอักขระคู่สแรโกรทำในอาร์กิวเมนต์สตริงเป็นอักขระ XML ที่ถูกต้อง มิฉะนั้นจะโยน XmlException พร้อมข้อมูลเกี่ยวกับอักขระที่ไม่ถูกต้องตัวแรกที่พบ.

```cpp
static String System::Xml::XmlConvert::VerifyXmlChars(const String &content)
```

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| content | const [String](../../../system/string/)\& | [String](../../../system/string/) ที่มีอักขระสำหรับตรวจสอบ. |

### ค่าที่คืนกลับ

สตริงที่ส่งเข้าไปหากอักขระทั้งหมดและอักขระคู่สแรโกรทำในอาร์กิวเมนต์สตริงเป็นอักขระ XML ที่ถูกต้อง มิฉะนั้นจะโยน XmlException พร้อมข้อมูลเกี่ยวกับอักขระที่ไม่ถูกต้องตัวแรกที่พบ.
