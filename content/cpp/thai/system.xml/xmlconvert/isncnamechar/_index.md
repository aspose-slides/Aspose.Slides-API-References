## XmlConvert::IsNCNameChar(char16_t) เมธอด

Checks whether the passed-in character is a valid non-colon character type.

```cpp
static bool System::Xml::XmlConvert::IsNCNameChar(char16_t ch)
```

### อาร์กิวเมนท์

| Parameter | Type | Description |
| --- | --- | --- |
| ch | char16_t | อักขระที่ต้องตรวจสอบว่าเป็นอักขระที่ไม่มีเครื่องหมายโคลอน |

### ค่าที่ส่งกลับ

**true** หากอักขระเป็นประเภทอักขระที่ไม่มีเครื่องหมายโคลอน; มิฉะนั้น **false**.
