## XmlConvert::ToString(DateTimeOffset, const String\&) เมธอด

แปลง [DateTimeOffset](../../../system/datetimeoffset/) ที่ให้มาเป็น [String](../../../system/string/) ในรูปแบบที่ระบุ

```cpp
static String System::Xml::XmlConvert::ToString(DateTimeOffset value, const String &format)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| value | [DateTimeOffset](../../../system/datetimeoffset/) | [DateTimeOffset](../../../system/datetimeoffset/) ที่จะถูกแปลง |
| format | const [String](../../../system/string/)\& | รูปแบบที่ **s** จะถูกแปลง รูปแบบพารามิเตอร์สามารถเป็นส่วนย่อยใด ๆ ของคำแนะนำของ W3C สำหรับประเภท XML dateTime สำหรับข้อมูลเพิ่มเติมดูส่วน [dateTime](https://www.w3.org/TR/xmlschema-2/#dateTime) ของสเปคริเคชัน XML [Schema](../../../system.xml.schema/) |

### ค่าที่ส่งกลับ

[String](../../../system/string/) ที่แสดงในรูปแบบที่ระบุของ [DateTimeOffset](../../../system/datetimeoffset/) ที่ให้มา
