## XmlElement::RemoveAttributeAt(int32_t) เมธอด


ลบโหนดแอตทริบิวต์ที่มีดัชนีที่ระบุออกจากองค์ประกอบ (หากแอตทริบิวต์ที่ลบมีค่าพื้นฐาน จะถูกแทนที่ทันที)

```cpp
virtual SharedPtr<XmlNode> System::Xml::XmlElement::RemoveAttributeAt(int32_t i)
```


### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| i | **int32_t** | ดัชนีของโหนดที่จะลบ โหนดแรกมีดัชนีเป็น 0. |

### ค่าที่คืน

โหนดแอตทริบิวต์ที่ลบหรือ **nullptr** หากไม่มีโหนดที่ดัชนีที่ระบุ
