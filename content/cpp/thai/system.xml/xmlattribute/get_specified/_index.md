## XmlAttribute::get_Specified() เมธอด

ส่งคืนค่าที่บ่งชี้ว่าค่าของแอตทริบิวต์ถูกตั้งค่าอย่างชัดเจนหรือไม่.

```cpp
virtual bool System::Xml::XmlAttribute::get_Specified()
```

### ค่าที่ส่งคืน

**true** หากแอตทริบิวต์นี้ได้รับการกำหนดค่าอย่างชัดเจนในเอกสารอินสแตนซ์ดั้งเดิม; มิฉะนั้น, **false**. ค่าของ **false** แสดงว่าค่าของแอตทริบิวต์มาจาก DTD.
