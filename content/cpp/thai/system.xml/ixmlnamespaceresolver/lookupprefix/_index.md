## IXmlNamespaceResolver::LookupPrefix(const String\&) เมธอด

ส่งคืนคำนำหน้าที่ถูกแมพกับ URI ของเนมสเปซที่ระบุ.

```cpp
virtual String System::Xml::IXmlNamespaceResolver::LookupPrefix(const String &namespaceName)=0
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| namespaceName | const [String](../../../system/string/)\& | URI ของเนมสเปซที่คุณต้องการค้นหาคำนำหน้า. |

### ค่าที่ส่งกลับ

คำนำหน้าที่ถูกแมพกับ URI ของเนมสเปซ; **nullptr** หาก URI ของเนมสเปซไม่ได้ถูกแมพกับคำนำหน้า.
