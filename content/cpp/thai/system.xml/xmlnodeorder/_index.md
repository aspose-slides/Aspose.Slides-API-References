## XmlNodeOrder enum

อธิบายลำดับเอกสารของโหนดเมื่อเทียบกับโหนดที่สอง

```cpp
enum class XmlNodeOrder
```

### ค่าต่างๆ

| Name | Value | Description |
| --- | --- | --- |
| Before | 0 | โหนดปัจจุบันของ navigator นี้อยู่ก่อนโหนดปัจจุบันของ navigator ที่จัดหาให้ |
| After | 1 | โหนดปัจจุบันของ navigator นี้อยู่หลังโหนดปัจจุบันของ navigator ที่จัดหาให้ |
| Same | 2 | navigator ทั้งสองถูกวางตำแหน่งบนโหนดเดียวกัน |
| Unknown | 3 | ไม่สามารถกำหนดตำแหน่งโหนดในลำดับเอกสารได้เมื่อเทียบกัน เนื่องจากอาจเกิดขึ้นหากโหนดสองโหนดอยู่ในต้นไม้ที่แตกต่างกัน |
