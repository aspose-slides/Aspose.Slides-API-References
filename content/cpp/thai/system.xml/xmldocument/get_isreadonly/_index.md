## XmlDocument::get_IsReadOnly() เมธอด

คืนค่าที่บ่งบอกว่าโหนดปัจจุบันเป็นแบบอ่านอย่างเดียวหรือไม่.

```cpp
bool System::Xml::XmlDocument::get_IsReadOnly() override
```

### ค่าที่ส่งคืน

**true** หากโหนดปัจจุบันเป็นแบบอ่านอย่างเดียว; มิฉะนั้น **false**. [XmlDocument](../) โหนดจะคืนค่า **false** เสมอ.
