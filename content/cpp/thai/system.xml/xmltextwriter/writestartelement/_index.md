## XmlTextWriter::WriteStartElement(const String\&, const String\&, const String\&) เมธอด

เขียนแท็กเริ่มต้นที่ระบุและเชื่อมโยงกับเนมสเปซและคำนำหน้าที่ให้ไว้.

```cpp
void System::Xml::XmlTextWriter::WriteStartElement(const String &prefix, const String &localName, const String &ns) override
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| prefix | const [String](../../../system/string/)\& | คำนำหน้าเนมสเปซขององค์ประกอบ. |
| localName | const [String](../../../system/string/)\& | ชื่อท้องถิ่นขององค์ประกอบ. |
| ns | const [String](../../../system/string/)\& | URI ของเนมสเปซที่เชื่อมโยงกับองค์ประกอบ. หากเนมสเปซนี้อยู่ในขอบเขตแล้วและมีคำนำหน้าที่เชื่อมโยงอยู่ ตัวเขียนจะเขียนคำนำหน้านั้นโดยอัตโนมัติด้วย. |
