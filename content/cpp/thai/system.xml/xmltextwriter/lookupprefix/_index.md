## XmlTextWriter::LookupPrefix(String) เมธอด


คืนค่าพรีฟิกซ์ที่ใกล้ที่สุดที่กำหนดในสโคปเนมสเปซปัจจุบันสำหรับ URI ของเนมสเปซ

```cpp
String System::Xml::XmlTextWriter::LookupPrefix(String ns) override
```


### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| ns | [String](../../../system/string/) | URI ของเนมสเปซที่คุณต้องการค้นหาพรีฟิกซ์ |

### ค่าที่คืนกลับ

พรีฟิกซ์ที่ตรงกัน หรือ **nullptr** หากไม่พบ URI ของเนมสเปซที่ตรงกันในสโคปปัจจุบัน
