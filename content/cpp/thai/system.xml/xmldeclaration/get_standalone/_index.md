## XmlDeclaration::get_Standalone() method


ส่งคืนค่าของแอตทริบิวต์ standalone.

```cpp
String System::Xml::XmlDeclaration::get_Standalone()
```


### ค่าที่ส่งคืน

ค่าที่ถูกต้องคือ **yes** หากการประกาศเอนทิตีทั้งหมดที่จำเป็นโดยเอกสาร XML ถูกบรรจุอยู่ในเอกสาร หรือ **no** หากต้องการการกำหนดประเภทเอกสารภายนอก (DTD). หากแอตทริบิวต์ standalone ไม่ปรากฏในประกาศ XML วิธีการนี้จะส่งคืน [String::Empty](../../../system/string/empty/).
