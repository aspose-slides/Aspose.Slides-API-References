## XmlNamespaceScope enum

กำหนดขอบเขตของเนมสเปซ

```cpp
enum class XmlNamespaceScope
```

### ค่า

| Name | Value | Description |
| --- | --- | --- |
| All | 0 | เนมสเปซทั้งหมดที่กำหนดในขอบเขตของโหนดปัจจุบัน ซึ่งรวมถึงเนมสเปซ xmlns:xml ซึ่งจะถูกประกาศโดยอัตโนมัติตลอดเวลา ลำดับของเนมสเปซที่ส่งกลับจะไม่ได้กำหนด |
| ExcludeXml | 1 | เนมสเปซทั้งหมดที่กำหนดในขอบเขตของโหนดปัจจุบัน ยกเว้นเนมสเปซ xmlns:xml ซึ่งจะถูกประกาศโดยอัตโนมัติตลอดเวลา ลำดับของเนมสเปซที่ส่งกลับจะไม่ได้กำหนด |
| Local | 2 | เนมสเปซทั้งหมดที่กำหนดในระดับท้องถิ่นของโหนดปัจจุบัน |
