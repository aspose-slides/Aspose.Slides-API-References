## XmlTextReader::ReadString() เมธอด

อ่านเนื้อหาของอิลิเมนต์หรือโหนดข้อความเป็นสตริง.

```cpp
String System::Xml::XmlTextReader::ReadString() override
```

### ค่าที่ส่งกลับ

เนื้อหาของอิลิเมนต์หรือโหนดข้อความ ตัวนี้อาจเป็นสตริงว่างหากผู้อ่านอยู่ที่ตำแหน่งที่ไม่ใช่อิลิเมนต์หรือโหนดข้อความ หรือหากไม่มีเนื้อความเพิ่มเติมให้ส่งกลับในบริบทปัจจุบัน **หมายเหตุ:** โหนดข้อความอาจเป็นอิลิเมนต์หรือโหนดข้อความของแอตทริบิวต์
