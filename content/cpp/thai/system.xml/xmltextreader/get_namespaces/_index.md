```cpp
bool System::Xml::XmlTextReader::get_Namespaces()
```

### ค่าที่ส่งคืน

**true** เพื่อทำการสนับสนุน namespace; มิฉะนั้น, **false**. ค่าเริ่มต้นคือ **true**.
