## XmlTextReader::get_HasValue() เมธอด

คืนค่าเพื่อระบุว่าโหนดปัจจุบันสามารถมี [XmlTextReader::get_Value](../get_value/) ที่ไม่ใช่ [String::Empty](../../../system/string/empty/) หรือไม่.

```cpp
bool System::Xml::XmlTextReader::get_HasValue() override
```

### ค่าที่ส่งคืน

**true** หากโหนดที่ผู้อ่านอยู่ในตำแหน่งปัจจุบันสามารถมี **Value**; มิฉะนั้น **false**.
