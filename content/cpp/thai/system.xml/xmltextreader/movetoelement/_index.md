## XmlTextReader::MoveToElement() เมธอด

ย้ายไปยังองค์ประกอบที่บรรจุโหนดแอตทริบิวต์ปัจจุบัน

```cpp
bool System::Xml::XmlTextReader::MoveToElement() override
```

### ค่าที่ส่งคืน

**true** หากผู้อ่านอยู่ในตำแหน่งของแอตทริบิวต์ (ผู้อ่านจะย้ายไปยังอิลิเมนต์ที่เป็นเจ้าของแอตทริบิวต์); **false** หากผู้อ่านไม่ได้อยู่ในตำแหน่งของแอตทริบิวต์ (ตำแหน่งของผู้อ่านจะไม่เปลี่ยนแปลง).
