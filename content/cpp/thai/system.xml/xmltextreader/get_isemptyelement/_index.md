## XmlTextReader::get_IsEmptyElement() เมธอด

ส่งคืนค่าที่ระบุว่าปัจจุบันโหนดเป็นอิลีเมนต์เปล่าหรือไม่ (เช่น **<MyElement/>**).

```cpp
bool System::Xml::XmlTextReader::get_IsEmptyElement() override
```

### ค่าที่ส่งคืน

**true** หากโหนดปัจจุบันเป็นอิลีเมนต์ (ค่า [XmlTextReader::get_NodeType](../get_nodetype/) เท่ากับ [XmlNodeType::Element](../../xmlnodetype/)) ที่จบด้วย **/>**; มิฉะนั้น **false**.
