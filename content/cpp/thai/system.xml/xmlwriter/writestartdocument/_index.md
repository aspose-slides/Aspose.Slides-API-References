## XmlWriter::WriteStartDocument() เมธอด

เมื่อถูกเขียนทับในคลาสที่สืบทอด, จะเขียนการประกาศ XML ด้วยเวอร์ชัน "1.0".

```cpp
virtual void System::Xml::XmlWriter::WriteStartDocument()=0
```

## XmlWriter::WriteStartDocument(bool) เมธอด

เมื่อถูกเขียนทับในคลาสที่สืบทอด, จะเขียนการประกาศ XML ด้วยเวอร์ชัน "1.0" และแอตทริบิวต์ standalone.

```cpp
virtual void System::Xml::XmlWriter::WriteStartDocument(bool standalone)=0
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| standalone | **bool** | ถ้า **true**, จะเขียน "standalone=yes"; ถ้า **false**, จะเขียน "standalone=no". |
