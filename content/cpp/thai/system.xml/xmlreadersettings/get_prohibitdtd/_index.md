## XmlReaderSettings::get_ProhibitDtd() เมธอด


คืนค่าเพื่อระบุว่าควรห้ามการประมวลผล document type definition (DTD) หรือไม่.

```cpp
bool System::Xml::XmlReaderSettings::get_ProhibitDtd()
```


### ค่าที่ส่งคืน

**true** เพื่อห้ามการประมวลผล DTD; มิฉะนั้น **false**. ค่าเริ่มต้นคือ **true**.

เลิกใช้
:   เมธอดนี้ล้าสมัย. ใช้ [XmlTextReader::get_DtdProcessing](../../xmltextreader/get_dtdprocessing/) แทน.
