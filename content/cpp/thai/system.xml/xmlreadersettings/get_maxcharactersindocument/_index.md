## XmlReaderSettings::get_MaxCharactersInDocument() เมธอด

ส่งค่ากลับที่บ่งบอกจำนวนอักขระสูงสุดที่อนุญาตในเอกสาร XML ค่าเป็นศูนย์ (0) หมายถึงไม่มีการจำกัดขนาดของเอกสาร XML ค่าไม่เป็นศูนย์ระบุขนาดสูงสุดเป็นอักขระ

```cpp
int64_t System::Xml::XmlReaderSettings::get_MaxCharactersInDocument()
```

### ค่าที่ส่งกลับ

จำนวนอักขระสูงสุดที่อนุญาตในเอกสาร XML ค่าเริ่มต้นคือ 0.
