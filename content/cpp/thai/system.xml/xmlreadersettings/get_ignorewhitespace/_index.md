## XmlReaderSettings::get_IgnoreWhitespace() เมธอด

คืนค่าแสดงว่าให้ละเว้นช่องว่างที่ไม่มีความหมายหรือไม่.

```cpp
bool System::Xml::XmlReaderSettings::get_IgnoreWhitespace()
```

### ค่ารีเทิร์น

**true** เพื่อไม่สนใจช่องว่าง; มิฉะนั้น **false**. ค่าเริ่มต้นคือ **false**.
