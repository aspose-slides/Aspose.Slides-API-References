## XmlReaderSettings::get_CloseInput() เมธอด

คืนค่าหนึ่งที่บ่งบอกว่าควรปิดสตรีมพื้นฐานหรือ TextReader เมื่อปิดตัวอ่านหรือไม่.

```cpp
bool System::Xml::XmlReaderSettings::get_CloseInput()
```

### ค่าที่ส่งคืน

**true** เพื่อปิดสตรีมพื้นฐานหรือ TextReader เมื่อปิดตัวอ่าน; มิฉะนั้น **false**. ค่าเริ่มต้นคือ **false**.
