```cpp
virtual bool System::Xml::XmlReader::get_EOF()=0
```

### ค่าที่ส่งคืน

**true** หากตัวอ่านอยู่ที่ตำแหน่งสุดท้ายของสตรีม; มิฉะนั้น, **false**.
