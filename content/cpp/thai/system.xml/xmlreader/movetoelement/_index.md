## XmlReader::MoveToElement() เมธอด

When overridden in a derived class, moves to the element that contains the current attribute node.

```cpp
virtual bool System::Xml::XmlReader::MoveToElement()=0
```

### ค่าที่ส่งกลับ

**true** หากตัวอ่านอยู่ที่แอตทริบิวต์ (ตัวอ่านจะย้ายไปยังองค์ประกอบที่เป็นเจ้าของแอตทริบิวต์); **false** หากตัวอ่านไม่ได้อยู่ที่แอตทริบิวต์ (ตำแหน่งของตัวอ่านจะไม่เปลี่ยนแปลง).
