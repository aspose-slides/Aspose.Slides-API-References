## XmlReader::get_NamespaceURI() เมธอด

```cpp
virtual String System::Xml::XmlReader::get_NamespaceURI()=0
```


### ค่า Return

ค่า namespace URI ของโหนดปัจจุบัน; หรือสตริงว่าง.
