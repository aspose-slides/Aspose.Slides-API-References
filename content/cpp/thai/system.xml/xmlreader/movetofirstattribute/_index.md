## XmlReader::MoveToFirstAttribute() เมธอด

เมื่อเขียนทับในคลาสที่สืบทอด, จะย้ายไปยังแอตทริบิวต์แรก.

```cpp
virtual bool System::Xml::XmlReader::MoveToFirstAttribute()=0
```

### ค่าที่ส่งคืน

**true** หากมีแอตทริบิวต์ (ผู้อ่านย้ายไปยังแอตทริบิวต์แรก); มิฉะนั้น, **false** (ตำแหน่งของผู้อ่านไม่เปลี่ยนแปลง).
