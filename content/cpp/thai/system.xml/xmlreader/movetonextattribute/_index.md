## XmlReader::MoveToNextAttribute() เมธอด


เมื่อถูกทำซ้ำในคลาสที่สืบทอด จะย้ายไปยังแอตทริบิวต์ถัดไป.

```cpp
virtual bool System::Xml::XmlReader::MoveToNextAttribute()=0
```


### ค่าที่ส่งคืน

**true** หากมีแอตทริบิวต์ถัดไป; **false** หากไม่มีแอตทริบิวต์เพิ่มเติม.
