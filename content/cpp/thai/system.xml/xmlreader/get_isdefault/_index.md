## XmlReader::get_IsDefault() เมธอด


เมื่อทำการ override ในคลาสที่สืบทอด, จะได้ค่าที่บ่งบอกว่าโหนดปัจจุบันเป็นแอตทริบิวต์ที่สร้างจากค่าดีฟอลท์ที่กำหนดใน DTD หรือสคีม่า.

```cpp
virtual bool System::Xml::XmlReader::get_IsDefault()
```


### ค่าที่ส่งกลับ

**true** หากโหนดปัจจุบันเป็นแอตทริบิวต์ที่ค่าของมันถูกสร้างจากค่าดีฟอลท์ที่กำหนดใน DTD หรือสคีม่า; **false** หากค่าของแอตทริบิวต์ถูกตั้งค่าโดยเจตนา.
