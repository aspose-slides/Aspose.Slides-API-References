## XmlReader::IsNameToken(const String\&) เมธอด

ส่งคืนค่าที่บ่งบอกว่าพารามิเตอร์สตริงเป็นโทเค็นชื่อ XML ที่ถูกต้องหรือไม่.

```cpp
static bool System::Xml::XmlReader::IsNameToken(const String &str)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| str | const [String](../../../system/string/)\& | โทเค็นชื่อที่ต้องตรวจสอบ. |

### ค่าที่ส่งคืน

**true** หากเป็นโทเค็นชื่อที่ถูกต้อง; มิฉะนั้น **false**.
