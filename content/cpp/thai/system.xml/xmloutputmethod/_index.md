## XmlOutputMethod enum

ระบุวิธีที่ใช้ในการแปลง [XmlWriter](../xmlwriter/) output.

```cpp
enum class XmlOutputMethod
```

### ค่าต่าง ๆ

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Xml | 0 | แปลงตามกฎของ XML 1.0 |
| Html | 1 | แปลงตามกฎของ HTML ที่ระบุโดย XSLT |
| Text | 2 | แปลงเฉพาะบล็อกข้อความเท่านั้น |
| AutoDetect | 3 | ใช้กฎของ XSLT เพื่อเลือกระหว่างวิธีการส่งออก [XmlOutputMethod::Xml](./) และ [XmlOutputMethod::Html](./) ในเวลาที่ทำงาน |
