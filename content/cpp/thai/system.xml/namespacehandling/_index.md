## NamespaceHandling enum

```cpp
enum class NamespaceHandling
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Default | 0 | ระบุว่าการประกาศเนมสเปซที่ซ้ำกันจะไม่ถูกลบออก |
| OmitDuplicates | 1 | ระบุว่าการประกาศเนมสเปซที่ซ้ำกันจะถูกลบออก สำหรับการลบเนมสเปซที่ซ้ำกัน จำเป็นต้องตรงกันทั้งคำนำหน้าและเนมสเปซ |
