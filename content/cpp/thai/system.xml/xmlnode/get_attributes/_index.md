## XmlNode::get_Attributes() เมธอด


ส่งคืน [XmlAttributeCollection](../../xmlattributecollection/) ที่บรรจุแอตทริบิวต์ของโหนดนี้.

```cpp
virtual SharedPtr<XmlAttributeCollection> System::Xml::XmlNode::get_Attributes() final
```


### ค่าที่ส่งคืน

เป็น [XmlAttributeCollection](../../xmlattributecollection/) ที่บรรจุแอตทริบิวต์ของโหนด หากโหนดเป็นประเภท [XmlNodeType::Element](../../xmlnodetype/) แอตทริบิวต์ของโหนดจะถูกส่งคืน มิฉะนั้นเมธอดนี้จะส่งคืน **nullptr**.
