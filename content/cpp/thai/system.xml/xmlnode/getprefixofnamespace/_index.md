## XmlNode::GetPrefixOfNamespace(String) เมธอด

ค้นหาการประกาศ **xmlns** ที่ใกล้เคียงที่สุดสำหรับ URI ของเนมส페ซที่กำหนดซึ่งอยู่ในขอบเขตของโหนดปัจจุบันและคืนค่าชื่อพรีฟิกซ์ที่กำหนดไว้ในประกาศนั้น.

```cpp
virtual String System::Xml::XmlNode::GetPrefixOfNamespace(String namespaceURI)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| namespaceURI | [String](../../../system/string/) | URI ของเนมส페ซที่คุณต้องการค้นหาพรีฟิกซ์ |

### ค่าที่ส่งกลับ

พรีฟิกซ์สำหรับ URI ของเนมส페ซที่ระบุ
