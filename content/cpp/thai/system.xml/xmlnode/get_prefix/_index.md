## XmlNode::get_Prefix() เมธอด

ส่งค่าคำนำหน้าชื่อเนมสเปซของโหนดนี้.

```cpp
virtual String System::Xml::XmlNode::get_Prefix()
```

### ค่าที่ส่งคืน

คำนำหน้าชื่อเนมสเปซของโหนดนี้. ตัวอย่างเช่น **Prefix** มีค่าเป็น **bk** สำหรับองค์ประกอบ **<bk:book>**. หากไม่มีคำนำหน้าเมธอดนี้จะส่งคืน [String::Empty](../../../system/string/empty/).
