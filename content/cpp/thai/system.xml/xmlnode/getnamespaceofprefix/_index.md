```cpp
virtual String System::Xml::XmlNode::GetNamespaceOfPrefix(String prefix)
```


### Arguments

| Parameter | Type | Description |
| --- | --- | --- |
| prefix | [String](../../../system/string/) | คำนำหน้าที่คุณต้องการค้นหา namespace URI ของมัน. |

### Return Value

ค่าที่คืนคือ namespace URI ของคำนำหน้าที่ระบุ.
