## XmlValidatingReader::MoveToElement() เมธอด

ย้ายไปยังองค์ประกอบที่บรรจุโหนดแอตทริบิวต์ปัจจุบัน

```cpp
bool System::Xml::XmlValidatingReader::MoveToElement() override
```

### ค่าที่ส่งกลับ

**true** หากผู้อ่านอยู่บนแอตทริบิวต์ (ผู้อ่านย้ายไปยังองค์ประกอบที่เป็นเจ้าของแอตทริบิวต์); **false** หากผู้อ่านไม่ได้อยู่บนแอตทริบิวต์ (ตำแหน่งของผู้อ่านจะไม่เปลี่ยนแปลง).
