## XmlValidatingReader::get_IsDefault() เมธอด


คืนค่าแสดงว่าตัวโหนดปัจจุบันเป็นแอตทริบิวต์ที่สร้างจากค่าตั้งต้นที่กำหนดไว้ใน document type definition (DTD) หรือ schema.

```cpp
bool System::Xml::XmlValidatingReader::get_IsDefault() override
```


### ค่าที่ส่งกลับ

**true** หากตัวโหนดปัจจุบันเป็นแอตทริบิวต์ที่ค่าของมันถูกสร้างจากค่าตั้งต้นที่กำหนดใน DTD หรือ schema; **false** หากค่าของแอตทริบิวต์ถูกตั้งค่าอย่างชัดเจน.
