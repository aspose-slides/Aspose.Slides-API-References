```cpp
bool System::Xml::XmlValidatingReader::get_IsEmptyElement() override
```


### ค่าที่ส่งกลับ

**true** หากโหนดปัจจุบันเป็นองค์ประกอบ ([XmlValidatingReader::get_NodeType](../get_nodetype/) มีค่าเท่ากับ [XmlNodeType::Element](../../xmlnodetype/)) ซึ่งลงท้ายด้วย **/>**; มิฉะนั้น, **false**.
