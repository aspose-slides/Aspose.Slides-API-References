## XmlWriterSettings::get_NewLineOnAttributes() เมธอด


ส่งค่ากลับที่บ่งบอกว่าควรเขียนแอตทริบิวต์ในบรรทัดใหม่หรือไม่.

```cpp
bool System::Xml::XmlWriterSettings::get_NewLineOnAttributes()
```


### ค่าที่คืน

**true** เพื่อเขียนแอตทริบิวต์ในแต่ละบรรทัด; หากไม่ใช่จะเป็น **false**. ค่าเริ่มต้นคือ **false**.
