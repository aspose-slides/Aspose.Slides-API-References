## XmlWriterSettings::get_WriteEndDocumentOnClose() เมธอด

ส่งคืนค่าที่บ่งบอกว่าหน่วย [XmlWriter](../../xmlwriter/) จะเพิ่มแท็กปิดให้กับแท็กองค์ประกอบที่ยังไม่ได้ปิดทั้งหมดหรือไม่เมื่อเมธอด [XmlWriter::Close](../../xmlwriter/close/) ถูกเรียกใช้.

```cpp
bool System::Xml::XmlWriterSettings::get_WriteEndDocumentOnClose()
```

### ค่าที่ส่งกลับ

**true** หากแท็กองค์ประกอบที่ยังไม่ได้ปิดทั้งหมดจะถูกปิด; หากไม่เช่นนั้น, **false**. ค่าเริ่มต้นคือ **true**.
