## XmlWriterSettings::get_CheckCharacters() เมธอด

ส่งคืนค่าที่บ่งบอกว่า XML writer ควรตรวจสอบเพื่อให้แน่ใจว่าตัวอักษรทั้งหมดในเอกสารถูกต้องตามส่วน \"2.2 Characters\" ของ W3C [XML 1.0 Recommendation](https://www.w3.org/TR/REC-xml/#charsets).

```cpp
bool System::Xml::XmlWriterSettings::get_CheckCharacters()
```

### ค่าที่ส่งคืน

**true** เพื่อทำการตรวจสอบอักขระ; มิฉะนั้น **false**. ค่าเริ่มต้นคือ **true**.
