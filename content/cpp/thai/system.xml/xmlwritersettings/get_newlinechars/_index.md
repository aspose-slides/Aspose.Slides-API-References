## XmlWriterSettings::get_NewLineChars() เมธอด

คืนค่ารายการอักขระที่ใช้สำหรับการแยกบรรทัด

```cpp
String System::Xml::XmlWriterSettings::get_NewLineChars()
```

### ค่าที่ส่งกลับ

รายการอักขระที่ใช้สำหรับการแยกบรรทัด สามารถตั้งค่าเป็นสตริงใดก็ได้ อย่างไรก็ตาม เพื่อให้เป็น XML ที่ถูกต้อง ควรระบุเฉพาะอักขระช่องว่างที่เป็นค่าที่ถูกต้อง เช่น อักขระช่องว่าง, แท็บ, แคร่จิ้ง หรือฟีดบรรทัด ค่าเริ่มต้นคือ **\r\n** (แคร่จิ้ง, บรรทัดใหม่)
