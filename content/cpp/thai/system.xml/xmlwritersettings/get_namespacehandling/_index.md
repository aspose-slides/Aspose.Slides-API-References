## XmlWriterSettings::get_NamespaceHandling() เมธอด


คืนค่าที่บ่งชี้ว่า [XmlWriter](../../xmlwriter/) ควรลบการประกาศเนมสเปซที่ซ้ำกันหรือไม่ขณะเขียนเนื้อหา XML. พฤติกรรมเริ่มต้นคือผู้เขียนจะส่งออกการประกาศเนมสเปซทั้งหมดที่มีอยู่ในตัวแก้ไขเนมสเปซของผู้เขียน.

```cpp
System::Xml::NamespaceHandling System::Xml::XmlWriterSettings::get_NamespaceHandling()
```


### ค่าที่ส่งคืน

การนับประเภท NamespaceHandling ที่ใช้ระบุว่าควรลบการประกาศเนมสเปซที่ซ้ำกันใน [XmlWriter](../../xmlwriter/).
