## XmlWriterSettings::get_OmitXmlDeclaration() เมธอด

ส่งกลับค่าที่บ่งชี้ว่าจะละการประกาศ XML หรือไม่.

```cpp
bool System::Xml::XmlWriterSettings::get_OmitXmlDeclaration()
```

### ค่าที่ส่งกลับ

**true** เพื่อจะละการประกาศ XML; มิฉะนั้น **false**. ค่าเริ่มต้นคือ **false**, จะมีการเขียนการประกาศ XML.
