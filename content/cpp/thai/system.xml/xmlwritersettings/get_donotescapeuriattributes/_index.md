## XmlWriterSettings::get_DoNotEscapeUriAttributes() เมธอด


คืนค่าที่ระบุว่า [XmlWriter](../../xmlwriter/) ไม่ทำการ escape คุณลักษณะ URI.

```cpp
bool System::Xml::XmlWriterSettings::get_DoNotEscapeUriAttributes()
```


### ค่าที่ส่งกลับ

**true** หาก [XmlWriter](../../xmlwriter/) ไม่ทำการ escape คุณลักษณะ URI; มิฉะนั้น **false**. ค่าเริ่มต้นคือ **false**.
