## WarningType enum

แสดงถึงประเภทของคำเตือน

```cpp
enum class WarningType
```

### Values

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| SourceFileCorruption | 0 | พบปัญหาในเอกสารต้นฉบับซึ่งทำให้เป็นไปได้สูงว่าเอกสารจะไม่สามารถเปิดได้หากบันทึกในรูปแบบเดิมของมัน |
| DataLoss | 1 | ข้อความ/แผนภูมิ/รูปภาพหรือข้อมูลอื่นจะหายไปอย่างสมบูรณ์จากต้นไม้ของเอกสารหลังการโหลด หรือจากเอกสารที่สร้างขึ้นหลังการบันทึก |
| MajorFormattingLoss | 2 | การสูญเสียรูปแบบอย่างมาก |
| MinorFormattingLoss | 3 | การสูญเสียรูปแบบเล็กน้อย |
| CompatibilityIssue | 4 | นี่เป็นปัญหาที่ทราบกันซึ่งจะทำให้เอกสารไม่สามารถเปิดได้โดยตัวแทนผู้ใช้บางชนิด หรือเวอร์ชันก่อนหน้าของตัวแทนผู้ใช้ |
| UnexpectedContent | 99 | บางเนื้อหาในเอกสารต้นฉบับไม่สามารถระบุได้ (เช่น ไม่รองรับ) ซึ่งอาจทำให้เกิดปัญหา หรืออาจไม่ทำให้เกิดปัญหาและทำให้สูญเสียข้อมูล/รูปแบบได้ |
