## EncoderReplacementFallback คลาส

ให้กลยุทธ์การสำรองในการแทนที่สัญลักษณ์ที่ผิดพลาดด้วยสเต็ป. วัตถุของคลาสนี้ควรได้รับการจัดสรรเฉพาะโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/). อย่าสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ operator new, เพราะจะทำให้เกิดข้อผิดพลาดเวลารันและ/หรือข้อผิดพลาดการประมวลผล. ควรห่อคลาสนี้ด้วยพอยเตอร์ [System::SmartPtr](../../system/smartptr/) และใช้พอยเตอร์นี้เพื่อส่งผ่านเป็นอากิวเมนต์ให้กับฟังก์ชัน.

```cpp
class EncoderReplacementFallback : public System::Text::EncoderFallback
```
