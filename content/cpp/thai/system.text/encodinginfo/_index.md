## EncodingInfo คลาส

ข้อมูลสรุปเกี่ยวกับการเข้ารหัส วัตถุของคลาสนี้ควรจัดสรรด้วยฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น ไม่ควรสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ operator new เพราะจะทำให้เกิดข้อผิดพลาดขณะรันไทม์และ/หรือข้อผิดพลาดการตรวจสอบ อย่าลืมห่อคลาสนี้ด้วยตัวชี้ [System::SmartPtr](../../system/smartptr/) แล้วใช้ตัวชี้นี้ส่งเป็นอาร์กิวเมนต์ให้กับฟังก์ชันต่าง ๆ

```cpp
class EncodingInfo : public System::Object
```
