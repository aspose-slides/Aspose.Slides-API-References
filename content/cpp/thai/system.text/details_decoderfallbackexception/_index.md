## Details_DecoderFallbackException คลาส

ข้อยกเว้นที่ถูกโยนโดย [DecoderExceptionFallback](../decoderexceptionfallback/) เมื่อการถอดรหัสล้มเหลว. ห้ามสร้างอินสแตนซ์ของคลาสนี้ด้วยตนเอง. ใช้คลาส DecoderFallbackException แทน. ห้ามห่อหุ้มอินสแตนซ์ของคลาส DecoderFallbackException เข้าไปใน [System::SmartPtr](../../system/smartptr/).

```cpp
class Details_DecoderFallbackException : public System::Details_ArgumentException
```
