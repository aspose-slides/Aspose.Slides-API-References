## EncoderExceptionFallback คลาส

ให้กลยุทธ์การสำรอง (fallback) ที่ทำให้เกิดการโยนข้อยกเว้น. วัตถุของคลาสนี้ควรสร้างด้วยฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น. ห้ามสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ operator new เพราะจะทำให้เกิดข้อผิดพลาดระหว่างทำงานและ/หรือข้อบกพร่องของการตรวจสอบ. ควรห่อหุ้มคลาสนี้ด้วยตัวชี้ [System::SmartPtr](../../system/smartptr/) และใช้ตัวชี้นี้เพื่อส่งผ่านเป็นอาร์กิวเมนต์ให้กับฟังก์ชัน.

```cpp
class EncoderExceptionFallback : public System::Text::EncoderFallback
```
