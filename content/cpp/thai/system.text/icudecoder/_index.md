## คลาส ICUDecoder


[Decoder](../decoder/) ที่ใช้ ICU สำหรับการถอดรหัส. ออบเจกต์ของคลาสนี้ควรได้รับการจัดสรรเฉพาะด้วยฟังก์ชัน [System::MakeObject()](../../system/makeobject/). อย่าสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ operator new เพราะมันจะทำให้เกิดข้อผิดพลาดเวลารันและ/หรือการละเมิด assertion. ห่อหุ้มคลาสนี้เสมอด้วยพอยน์เตอร์ [System::SmartPtr](../../system/smartptr/) และใช้พอยน์เตอร์นี้เพื่อส่งเป็นอาร์กิวเมนต์ให้กับฟังก์ชันต่างๆ.

```cpp
class ICUDecoder : public System::Text::Decoder
```
