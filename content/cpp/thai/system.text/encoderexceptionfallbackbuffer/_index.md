## EncoderExceptionFallbackBuffer คลาส


[Buffer](../../system/buffer/) สำหรับกลยุทธ์การสำรองการเข้ารหัสที่โยนข้อยกเว้น. จริงๆ แล้วไม่ได้เก็บอะไรเลย แต่จะโยนข้อยกเว้นแทน. ออบเจ็กต์ของคลาสนี้ควรได้รับการจัดสรรเฉพาะโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/). ห้ามสร้างอินสแตนซ์ของชนิดนี้บนสแตกหรือโดยใช้ operator new เนื่องจากจะทำให้เกิดข้อผิดพลาดระหว่างการทำงานและ/หรือข้อผิดพลาดการตรวจสอบ. ห่อหุ้มคลาสนี้ด้วยพอยเตอร์ [System::SmartPtr](../../system/smartptr/) เสมอและใช้พอยเตอร์นี้เพื่อส่งผ่านให้ฟังก์ชันเป็นอาร์กิวเมนต์.

```cpp
class EncoderExceptionFallbackBuffer : public System::Text::EncoderFallbackBuffer
```
