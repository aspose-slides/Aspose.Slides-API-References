## AfterAnimationType enum

แสดงประเภทการเคลื่อนไหวหลังจากเอฟเฟกต์การเคลื่อนไหว

```cpp
enum class AfterAnimationType
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| DoNotDim | 0 | ไม่ทำให้มืดหลังการเคลื่อนไหว |
| Color | 1 | สีหลังการเคลื่อนไหว |
| HideAfterAnimation | 2 | ซ่อนหลังประเภท [Animation](../) |
| HideOnNextMouseClick | 3 | ซ่อนเมื่อคลิกเมาส์ครั้งต่อไปหลังการเคลื่อนไหว |
