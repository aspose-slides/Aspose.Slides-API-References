## MarkdownSaveOptions::set_HandleRepeatedSpaces(Aspose::Slides::Export::HandleRepeatedSpaces) เมธอด

กำหนดวิธีการจัดการกับอักขระช่องว่างทั่วไปที่ซ้ำกันระหว่างการส่งออกเป็น Markdown.

```cpp
void Aspose::Slides::Export::MarkdownSaveOptions::set_HandleRepeatedSpaces(Aspose::Slides::Export::HandleRepeatedSpaces value)
```

## หมายเหตุ

* คงไว้เป็นอักขระช่องว่างทั่วไป,
* สลับระหว่างช่องว่างทั่วไปและเอนทิตีช่องว่างไม่แยกบรรทัด (**&nbsp;**),
* หรือแทนที่ทั้งหมด (หลังจากอันแรก) ด้วย **&nbsp;** เพื่อรักษาการจัดแนวภาพในผลลัพธ์ Markdown

ค่าตั้งต้นคือ [HandleRepeatedSpaces::AlternateSpacesToNbsp](../../handlerepeatedspaces/).
