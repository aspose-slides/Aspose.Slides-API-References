## IPdfOptions::get_SufficientResolution() method


Returns a value determining resolution of images inside PDF document.

```cpp
virtual float Aspose::Slides::Export::IPdfOptions::get_SufficientResolution()=0
```

## หมายเหตุ


คุณสมบัติมีผลต่อขนาดไฟล์ เวลาในการส่งออกและคุณภาพของภาพ

ค่าตั้งต้นคือ **96**.

ผลของพารามิเตอร์นี้ขึ้นอยู่กับปัจจัยบางอย่าง. อัลกอริทึมพยายามหาขนาดภาพผลลัพธ์ที่ดีที่สุดตามค่าของคุณสมบัติ ขนาดภาพต้นฉบับและขนาดเฟรมของภาพ. การใช้ค่าคุณสมบัติที่คล้ายกันอาจให้ผลลัพธ์เดียวกัน. แนะนำให้ใช้ขั้นที่ 16 หรือ 32 เพื่อให้เห็นผลที่ชัดเจน.

อ่าน **float**.
