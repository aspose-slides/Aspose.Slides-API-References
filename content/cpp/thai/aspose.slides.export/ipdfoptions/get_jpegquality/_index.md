## IPdfOptions::get_JpegQuality() เมธอด

คืนค่าที่กำหนดคุณภาพของภาพ JPEG ภายในเอกสาร PDF. อ่านเป็น **uint8_t**.

```cpp
virtual uint8_t Aspose::Slides::Export::IPdfOptions::get_JpegQuality()=0
```

## หมายเหตุ

มีผลต่อเมื่อเอกสารมีภาพ JPEG เท่านั้น.

ใช้คุณสมบัตินี้เพื่อรับหรือกำหนดคุณภาพของภาพภายในเอกสารเมื่อบันทึกเป็นรูปแบบ PDF. ค่าจะอยู่ระหว่าง 0 ถึง 100 โดย 0 หมายถึงคุณภาพต่ำสุดแต่การบีบอัดสูงสุดและ 100 หมายถึงคุณภาพดีที่สุดแต่การบีบอัดต่ำสุด.

ค่าตั้งต้นคือ **100**.
