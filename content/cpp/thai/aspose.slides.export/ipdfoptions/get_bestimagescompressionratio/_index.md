## IPdfOptions::get_BestImagesCompressionRatio() เมธอด


ระบุว่าควรเลือกการบีบอัดที่มีประสิทธิภาพที่สุด (แทนการบีบอัดค่าเริ่มต้น) สำหรับแต่ละรูปภาพโดยอัตโนมัติหรือไม่ หากตั้งค่าเป็น **bool**.true จะเลือกอัลกอริธึมการบีบอัดที่เหมาะสมที่สุดสำหรับรูปภาพแต่ละภาพในงานนำเสนอ ซึ่งจะทำให้ขนาดของไฟล์ PDF ที่ได้มีขนาดเล็กลง

```cpp
virtual bool Aspose::Slides::Export::IPdfOptions::get_BestImagesCompressionRatio()=0
```

## หมายเหตุ


การเลือกอัตราการบีบอัดภาพที่ดีที่สุดใช้ทรัพยากรการคำนวณสูงและต้องการหน่วยความจำ RAM เพิ่มเติม โดยค่าปริยายของตัวเลือกนี้คือ **bool**.false
