## IPdfOptions::get_RasterizeUnsupportedFontStyles() เมธอด

```cpp
virtual bool Aspose::Slides::Export::IPdfOptions::get_RasterizeUnsupportedFontStyles()=0
```

## หมายเหตุ

ค่าเริ่มต้นคือ **false**.
