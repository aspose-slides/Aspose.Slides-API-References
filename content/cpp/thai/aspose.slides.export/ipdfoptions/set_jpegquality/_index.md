## IPdfOptions::set_JpegQuality(uint8_t) เมธอด

กำหนดค่าที่เป็นตัวกำหนดคุณภาพของภาพ JPEG ภายในเอกสาร PDF. Write **uint8_t**.

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_JpegQuality(uint8_t value)=0
```

## หมายเหตุ

Has effect only when a document contains JPEG images.

ใช้คุณสมบัตินี้เพื่อรับหรือกำหนดคุณภาพของภาพภายในเอกสารเมื่อบันทึกเป็นรูปแบบ PDF. ค่าอาจอยู่ระหว่าง 0 ถึง 100 โดยที่ 0 หมายถึงคุณภาพแย่ที่สุดแต่การบีบอัดสูงสุดและ 100 หมายถึงคุณภาพดีที่สุดแต่การบีบอัดต่ำสุด.

The default value is **100**.
