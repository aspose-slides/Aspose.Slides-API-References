## IPdfOptions::get_EmbedTrueTypeFontsForASCII() เมธอด


ตั้งค่าเป็น true เพื่อฝังฟอนต์ True Type สำหรับอักขระ ASCII 32-127. [Fonts](../../../aspose.slides/fonts/) สำหรับรหัสอักขระที่มากกว่า 127 จะถูกฝังเสมอ. อ่าน **bool**.

```cpp
virtual bool Aspose::Slides::Export::IPdfOptions::get_EmbedTrueTypeFontsForASCII()=0
```

## หมายเหตุ


ค่าเริ่มต้นคือ **true**.
