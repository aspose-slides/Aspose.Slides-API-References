## IPdfOptions::set_EmbedTrueTypeFontsForASCII(bool) เมธอด

เป็นจริงเพื่อฝังฟอนต์ true type สำหรับอักขระ ASCII 32-127. [Fonts](../../../aspose.slides/fonts/) สำหรับรหัสอักขระที่มากกว่า 127 จะถูกฝังเสมอ. เขียน **bool**.

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_EmbedTrueTypeFontsForASCII(bool value)=0
```

## หมายเหตุ

ค่าเริ่มต้นคือ **true**.
