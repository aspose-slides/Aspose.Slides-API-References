## IPdfOptions::set_BestImagesCompressionRatio(bool) เมธอด

ระบุว่าควรเลือกการบีบอัดที่มีประสิทธิภาพที่สุด (แทนการบีบอัดเริ่มต้น) สำหรับแต่ละภาพโดยอัตโนมัติหรือไม่ หากตั้งค่าเป็น **bool**.true จะเลือกอัลกอริทึมการบีบอัดที่เหมาะสมที่สุดสำหรับแต่ละภาพในงานนำเสนอ ซึ่งจะทำให้ขนาดของเอกสาร PDF ที่ได้มีขนาดเล็กลง

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_BestImagesCompressionRatio(bool value)=0
```

## หมายเหตุ

การเลือกอัตราการบีบอัดภาพที่ดีที่สุดต้องใช้การคำนวณที่มีค่าใช้จ่ายสูงและใช้หน่วยความจำ RAM เพิ่มเติม และตัวเลือกนี้มีค่าเริ่มต้นเป็น **bool**.false

ค่าเริ่มต้นคือ **bool**.false.
