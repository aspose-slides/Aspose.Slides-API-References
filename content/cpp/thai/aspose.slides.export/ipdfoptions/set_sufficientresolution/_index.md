## IPdfOptions::set_SufficientResolution(float) เมธอด

กำหนดค่าที่ใช้กำหนดความละเอียดของภาพภายในเอกสาร PDF.

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_SufficientResolution(float value)=0
```

## หมายเหตุ

คุณสมบัตินี้มีผลต่อขนาดไฟล์, เวลาในการส่งออกและคุณภาพของภาพ.

ค่าปริยายคือ **96**.

ผลของพารามิเตอร์นี้ขึ้นอยู่กับปัจจัยหลายอย่าง. อัลกอริทึมพยายามหาขนาดภาพเอาต์พุตที่ดีที่สุดตามค่าของคุณสมบัติ, ขนาดภาพต้นฉบับและขนาดเฟรมของภาพ. การใช้ค่าคุณสมบัติที่คล้ายกันอาจให้ผลลัพธ์เดียวกัน. แนะนำให้ใช้ขั้นตอน 16 หรือ 32 เพื่อให้เห็นผลลัพธ์ที่ชัดเจน.

เขียน **float**.
