## ISVGOptions::get_DisableLineEndCropping() เมธอด

SVG 1.1 ไม่มีความสามารถในการกำหนดอินเซ็ตสำหรับมาร์คเกอร์. [Aspose.Slides](../../../aspose.slides/) เครื่องมือเขียน SVG มีวิธีแก้ปัญหานี้: มันตัดส่วนท้ายของเส้นด้วยลูกศร, ดังนั้นเส้นจะไม่ทับซ้อนกับมาร์คเกอร์. ตัวเลือกนี้ปิดการทำเช่นนี้. อ่าน **bool**.

```cpp
virtual bool Aspose::Slides::Export::ISVGOptions::get_DisableLineEndCropping()=0
```
