## ISVGOptions::set_DisableLineEndCropping(bool) เมธอด


SVG 1.1 ไม่สามารถกำหนดการเยื้องสำหรับมาร์คเกอร์ได้. [Aspose.Slides](../../../aspose.slides/) เครื่องมือเขียน SVG มีวิธีแก้ไขปัญหานี้: มันจะตัดส่วนปลายของเส้นที่มีลูกศร เพื่อลดการทับซ้อนกับมาร์คเกอร์. ตัวเลือกนี้จะปิดพฤติกรรมดังกล่าว. เขียน **bool**.

```cpp
virtual void Aspose::Slides::Export::ISVGOptions::set_DisableLineEndCropping(bool value)=0
```
