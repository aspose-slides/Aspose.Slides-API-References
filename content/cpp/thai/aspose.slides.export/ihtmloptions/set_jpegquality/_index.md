## IHtmlOptions::set_JpegQuality(uint8_t) เมธอด

กำหนดค่าที่ระบุคุณภาพของภาพ JPEG ภายในเอกสาร PDF เขียนเป็น **uint8_t**.

```cpp
virtual void Aspose::Slides::Export::IHtmlOptions::set_JpegQuality(uint8_t value)=0
```

## หมายเหตุ

มีผลเฉพาะเมื่อเอกสารมีภาพ JPEG

ใช้คุณสมบัตินี้เพื่อรับหรือกำหนดคุณภาพของภาพภายในเอกสารเมื่อบันทึกเป็นรูปแบบ PDF ค่าที่กำหนดอาจอยู่ระหว่าง 0 ถึง 100 โดยที่ 0 หมายถึงคุณภาพแย่ที่สุดแต่การบีบอัดสูงสุดและ 100 หมายถึงคุณภาพดีที่สุดแต่การบีบอัดต่ำสุด

ค่าเริ่มต้นคือ **95**.
