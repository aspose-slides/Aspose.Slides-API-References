## IHtmlOptions::get_JpegQuality() เมธอด

คืนค่าที่กำหนดคุณภาพของภาพ JPEG ภายในเอกสาร PDF. อ่าน **uint8_t**.

```cpp
virtual uint8_t Aspose::Slides::Export::IHtmlOptions::get_JpegQuality()=0
```

## หมายเหตุ

มีผลเพียงเมื่อเอกสารมีภาพ JPEG.

ใช้คุณสมบัตินี้เพื่อรับหรือกำหนดคุณภาพของภาพภายในเอกสารเมื่อบันทึกเป็นรูปแบบ PDF. ค่าอาจอยู่ระหว่าง 0 ถึง 100 โดยที่ 0 หมายถึงคุณภาพต่ำที่สุดแต่การบีบอัดสูงสุดและ 100 หมายถึงคุณภาพดีที่สุดแต่การบีบอัดต่ำสุด.

ค่าปริยายคือ **95**.
