## PdfOptions::set_JpegQuality(uint8_t) เมธอด


กำหนดค่าที่ระบุคุณภาพของภาพ JPEG ภายในเอกสาร PDF เขียนเป็น **uint8_t**.

```cpp
void Aspose::Slides::Export::PdfOptions::set_JpegQuality(uint8_t value) override
```

## หมายเหตุ


มีผลเฉพาะเมื่อเอกสารมีภาพ JPEG

ใช้คุณสมบัตินี้เพื่อรับหรือกำหนดคุณภาพของภาพภายในเอกสารเมื่อบันทึกเป็นรูปแบบ PDF ค่าที่กำหนดอาจอยู่ระหว่าง 0 ถึง 100 โดยที่ 0 หมายถึงคุณภาพแย่ที่สุดแต่การบีบอัดสูงสุด และ 100 หมายถึงคุณภาพดีที่สุดแต่การบีบอัดต่ำสุด.

ค่าปริยายคือ **100**.
