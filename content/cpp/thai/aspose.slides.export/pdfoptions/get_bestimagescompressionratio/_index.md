## PdfOptions::get_BestImagesCompressionRatio() เมธอด


บ่งบอกว่า การบีบอัดที่มีประสิทธิภาพสูงสุด (แทนการบีบอัดค่าเริ่มต้น) สำหรับแต่ละภาพต้องถูกเลือกโดยอัตโนมัติหรือไม่ หากตั้งค่าเป็น **bool**.true, สำหรับแต่ละภาพในงานนำเสนอจะเลือกอัลกอริทึมการบีบอัดที่เหมาะสมที่สุด ซึ่งจะทำให้ขนาดของเอกสาร PDF ที่ได้มีขนาดเล็กลง.

```cpp
bool Aspose::Slides::Export::PdfOptions::get_BestImagesCompressionRatio() override
```

## หมายเหตุ


การเลือกอัตราการบีบอัดภาพที่ดีที่สุดใช้ทรัพยากรการคำนวณสูงและต้องใช้ RAM เพิ่มเติม และตัวเลือกนี้มีค่าเริ่มต้นเป็น **bool**.false

ค่าเริ่มต้นคือ **bool**.false.
