## PdfOptions::get_JpegQuality() เมธอด


ส่งคืนค่าที่กำหนดคุณภาพของภาพ JPEG ภายในเอกสาร PDF. อ่าน **uint8_t**.

```cpp
uint8_t Aspose::Slides::Export::PdfOptions::get_JpegQuality() override
```

## หมายเหตุ


มีผลเฉพาะเมื่อเอกสารมีภาพ JPEG.

ใช้คุณสมบัตินี้เพื่อรับหรือกำหนดคุณภาพของภาพภายในเอกสารเมื่อบันทึกในรูปแบบ PDF. ค่าอาจอยู่ระหว่าง 0 ถึง 100 โดยที่ 0 หมายถึงคุณภาพต่ำสุดแต่การบีบอัดสูงสุดและ 100 หมายถึงคุณภาพดีที่สุดแต่การบีบอัดต่ำสุด.

ค่าตั้งต้นคือ **100**.
