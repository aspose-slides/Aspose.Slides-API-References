## PdfOptions::set_EmbedTrueTypeFontsForASCII(bool) เมธอด

กำหนดว่า [Aspose.Slides](../../../aspose.slides/) จะฝังแบบอักษรทั่วไปสำหรับข้อความ ASCII (ช่วงโค้ด 33..127) หรือไม่. [Fonts](../../../aspose.slides/fonts/) สำหรับรหัสอักขระที่มากกว่า 127 จะถูกฝังเสมอ. รายการแบบอักษรทั่วไปรวมถึงแบบอักษรพื้นฐาน 14 ตัวของ PDF และแบบอักษรเพิ่มเติมที่ผู้ใช้ระบุ. เขียน **bool**.

```cpp
void Aspose::Slides::Export::PdfOptions::set_EmbedTrueTypeFontsForASCII(bool value) override
```

## หมายเหตุ

ค่าเริ่มต้นคือ **true**.
