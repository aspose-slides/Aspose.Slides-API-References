## PdfOptions::set_BestImagesCompressionRatio(bool) เมธอด

ระบุว่า ควรเลือกการบีบอัดที่มีประสิทธิภาพสูงสุด (แทนการบีบอัดเริ่มต้น) สำหรับแต่ละภาพโดยอัตโนมัติหรือไม่ หากตั้งค่าเป็น **bool**.true, สำหรับแต่ละภาพในงานนำเสนออัลกอริธึมการบีบอัดที่เหมาะสมที่สุดจะถูกเลือก ซึ่งจะทำให้ขนาดของเอกสาร PDF ที่ได้มีขนาดเล็กลง.

```cpp
void Aspose::Slides::Export::PdfOptions::set_BestImagesCompressionRatio(bool value) override
```

## หมายเหตุ

การเลือกอัตราการบีบอัดภาพที่ดีที่สุดใช้การประมวลผลที่มีค่าใช้จ่ายสูงและต้องใช้ RAM เพิ่มเติม และตัวเลือกนี้มีค่าเริ่มต้นเป็น **bool**.false

ค่าพื้นฐานคือ **bool**.false.
