## PdfOptions::set_SufficientResolution(float) เมธอด

กำหนดค่าที่กำหนดความละเอียดของภาพภายในเอกสาร PDF.

```cpp
void Aspose::Slides::Export::PdfOptions::set_SufficientResolution(float value) override
```

## หมายเหตุ

คุณสมบัตินี้ส่งผลต่อขนาดไฟล์, เวลาในการส่งออกและคุณภาพของภาพ.

ค่าตั้งต้นคือ **96**.

ผลของพารามิเตอร์นี้ขึ้นอยู่กับปัจจัยหลายอย่าง อัลกอริทึมพยายามหาขนาดภาพเอาต์พุตที่ดีที่สุดตามค่าของคุณสมบัตินี้, ขนาดภาพต้นฉบับและขนาดเฟรมของภาพ การใช้ค่าคุณสมบัติที่คล้ายกันอาจให้ผลลัพธ์เดียวกัน แนะนำให้ใช้ขั้นตอน 16 หรือ 32 เพื่อให้เห็นผลที่ชัดเจน.

เขียน **float**.
