## SVGOptions::set_DisableLineEndCropping(bool) เมธอด

SVG 1.1 ไม่สามารถกำหนดระยะขอบสำหรับมาร์คเกอร์ได้. [Aspose.Slides](../../../aspose.slides/) เครื่องเขียน SVG มีวิธีแก้ไขสำหรับปัญหานั้น: มันตัดส่วนท้ายของเส้นที่มีลูกศร เพื่อให้เส้นไม่ทับซ้อนกับมาร์คเกอร์. ตัวเลือกนี้จะปิดพฤติกรรมดังกล่าว. เขียน **bool**.

```cpp
void Aspose::Slides::Export::SVGOptions::set_DisableLineEndCropping(bool value) override
```
