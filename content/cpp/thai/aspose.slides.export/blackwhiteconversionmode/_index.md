## BlackWhiteConversionMode enum

ให้ตัวเลือกที่ควบคุมวิธีการแปลงภาพของสไลด์ให้เป็นภาพสีสองระดับ.

```cpp
enum class BlackWhiteConversionMode
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| Default | 0 | ระบุไม่มีอัลกอริทึมการแปลง จะใช้อัลกอริทึมที่ดำเนินการใน TIFF codec (Default) |
| Dithering | 1 | ระบุอัลกอริทึมดิสถรี (Floyd-Steinberg). |
| DitheringFloydSteinberg | 2 | ระบุอัลกอริทึมดิสถรี Floyd-Steinberg. |
| Auto | 3 | ระบุอัลกอริทึมค่ากั้นที่คำนวณอัตโนมัติ (Otsu). |
| AutoOtsu | 4 | ระบุอัลกอริทึมค่ากั้นของ Otsu ที่คำนวณอัตโนมัติ. |
| Threshold25 | 5 | ระบุอัลกอริทึมค่ากั้นแบบคงที่ (25%). |
| Threshold50 | 6 | ระบุอัลกอริทึมค่ากั้นแบบคงที่ (50%). |
| Threshold75 | 7 | ระบุอัลกอริทึมค่ากั้นแบบคงที่ (75%). |
