## CompressionLevel enum

กำหนดระดับการบีบอัด ZIP สำหรับไฟล์ OpenXML ระดับที่สูงขึ้นให้การบีบอัดที่ดีกว่าแต่มีค่าใช้จ่ายเป็นการประมวลผลที่ช้าลง.

```cpp
enum class CompressionLevel
```

### ค่า

| Name | Value | Description |
| --- | --- | --- |
| None | 0 | ไม่มีการบีบอัด ไฟล์จะถูกเก็บไว้ตามต้นฉบับ. |
| Level1 | 1 | การบีบอัดที่เร็วที่สุดพร้อมอัตราการบีบอัดที่ต่ำที่สุด. |
| Level2 | 2 | การบีบอัดที่เร็วกว่าโดยมีอัตราการบีบอัดที่ดีกว่าเล็กน้อยเมื่อเทียบกับ [CompressionLevel::Level1](./). |
| Level3 | 3 | ให้การบีบอัดที่ดีกว่า [CompressionLevel::Level2](./) พร้อมผลกระทบต่อประสิทธิภาพระดับปานกลาง. |
| Level4 | 4 | ให้การบีบอัดที่ดีกว่า [CompressionLevel::Level3](./). |
| Level5 | 5 | ให้การบีบอัดที่ปรับปรุงขึ้นเมื่อเทียบกับ [CompressionLevel::Level4](./) พร้อมเวลาในการประมวลผลที่เพิ่มขึ้น. |
| Level6 | 6 | การบีบอัดมาตรฐาน ให้สมดุลที่ดีระหว่างความเร็วการบีบอัดและขนาดไฟล์ เป็นระดับการบีบอัดเริ่มต้น. |
| Level7 | 7 | ให้การบีบอัดที่สูงกว่า [CompressionLevel::Level6](./) พร้อมการประมวลผลที่ช้าลง. |
| Level8 | 8 | ให้การบีบอัดที่สูงกว่า [CompressionLevel::Level7](./). |
| Level9 | 9 | การบีบอัดสูงสุด สร้างขนาดไฟล์ที่เล็กที่สุดด้วยความเร็วการประมวลผลที่ช้าที่สุด. |
