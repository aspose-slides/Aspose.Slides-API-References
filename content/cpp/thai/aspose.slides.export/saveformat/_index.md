```cpp
enum class SaveFormat
```

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Ppt | 0 | บันทึกงานนำเสนอในรูปแบบ PPT. |
| Pdf | 1 | บันทึกงานนำเสนอในรูปแบบ PDF. |

| Tiff | 5 | บันทึกงานนำเสนอเป็นภาพ TIFF หลายหน้า. |
| Odp | 6 | บันทึกงานนำเสนอในรูปแบบ ODP. |
| Pptm | 7 | บันทึกงานนำเสนอในรูปแบบ PPTM (งานนำเสนอที่เปิดใช้งานมาโคร) format. |
| Ppsm | 9 | บันทึกงานนำเสนอในรูปแบบ PPSM (สไลด์โชว์ที่เปิดใช้งานมาโคร) format. |

| Html | 13 | บันทึกงานนำเสนอในรูปแบบ HTML. |
| Swf | 15 | บันทึกงานนำเสนอในรูปแบบ SWF. |
| Otp | 17 | บันทึกงานนำเสนอในรูปแบบ OTP (แม่แบบงานนำเสนอ) format. |
| Pps | 19 | บันทึกงานนำเสนอในรูปแบบ PPS. |
| Pot | 20 | บันทึกงานนำเสนอในรูปแบบ POT. |
| Fodp | 21 | บันทึกงานนำเสนอในรูปแบบ FODP. |
| Gif | 22 | บันทึกงานนำเสนอในรูปแบบ GIF. |
| Html5 | 23 | บันทึกงานนำเสนอในรูปแบบ HTML โดยใช้ระบบเทมเพลต HTML5 ใหม่. |
| Md | 24 | บันทึกงานนำเสนอในรูปแบบ Markdown |
