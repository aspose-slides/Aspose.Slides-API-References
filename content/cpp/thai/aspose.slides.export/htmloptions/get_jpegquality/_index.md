## HtmlOptions::get_JpegQuality() เมธอด

คืนค่าที่กำหนดคุณภาพของภาพ JPEG ภายในเอกสาร PDF. อ่าน **uint8_t**.

```cpp
uint8_t Aspose::Slides::Export::HtmlOptions::get_JpegQuality() override
```

## หมายเหตุ

มีผลเฉพาะเมื่อเอกสารมีภาพ JPEG.

ใช้คุณสมบัตินี้เพื่อรับหรือกำหนดคุณภาพของภาพภายในเอกสารเมื่อบันทึกในรูปแบบ PDF. ค่าที่อาจอยู่ระหว่าง 0 ถึง 100 โดยที่ 0 หมายถึงคุณภาพแย่ที่สุดแต่มีการบีบอัดสูงสุดและ 100 หมายถึงคุณภาพดีที่สุดแต่การบีบอัดน้อยที่สุด.

ค่าปริยายคือ **95**.
