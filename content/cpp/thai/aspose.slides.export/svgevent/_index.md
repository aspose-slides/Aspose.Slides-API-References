## SvgEvent enum

แสดงตัวเลือกสำหรับรูปแบบ SVG.

```cpp
enum class SvgEvent
```

### ค่าต่าง ๆ

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| OnFocusIn | 0 | เกิดขึ้นเมื่อองค์ประกอบได้รับโฟกัส เช่น เมื่อข้อความถูกเลือก. |
| OnFocusOut | 1 | เกิดขึ้นเมื่อองค์ประกอบสูญเสียโฟกัส เช่น เมื่อข้อความไม่ถูกเลือก. |
| OnActivate | 2 | เกิดขึ้นเมื่อองค์ประกอบถูกเรียกใช้งาน เช่น ผ่านการคลิกเมาส์หรือการกดแป้น. |
| OnClick | 3 | เกิดขึ้นเมื่อปุ่มอุปกรณ์ชี้ถูกคลิกบนองค์ประกอบ. |
| OnMouseDown | 4 | เกิดขึ้นเมื่อปุ่มอุปกรณ์ชี้ถูกกดบนองค์ประกอบ. |
| OnMouseUp | 5 | เกิดขึ้นเมื่อปุ่มอุปกรณ์ชี้ถูกปล่อยบนองค์ประกอบ. |
| OnMouseOver | 6 | เกิดขึ้นเมื่ออุปกรณ์ชี้เคลื่อนที่เข้าสู่องค์ประกอบ. |
| OnMouseMove | 7 | เกิดขึ้นเมื่ออุปกรณ์ชี้เคลื่อนที่ขณะอยู่เหนือองค์ประกอบ. |
| OnMouseOut | 8 | เกิดขึ้นเมื่ออุปกรณ์ชี้เคลื่อนที่ออกจากองค์ประกอบ. |
| OnLoad | 9 | เกิดขึ้นเมื่อเอเจนต์ผู้ใช้ได้ทำการแยกวิเคราะห์องค์ประกอบและส่วนย่อยของมันรวมถึงทรัพยากรที่อ้างอิงทั้งหมดที่จำเป็นต่อการเรนเดอร์อย่างสมบูรณ์. |
| OnUnload | 10 | เกิดขึ้นเมื่อการทำงานของ [DOM](../../aspose.slides.dom/) ลบเอกสารออกจากหน้าต่างหรือเฟรม ใช้ได้เฉพาะกับองค์ประกอบ svg ที่อยู่นอกสุดเท่านั้น. |
| OnAbort | 11 | เกิดขึ้นเมื่อการโหลดหน้าถูกหยุดก่อนที่องค์ประกอบจะได้รับการโหลดอย่างสมบูรณ์. |
| OnError | 12 | เกิดขึ้นเมื่อองค์ประกอบไม่โหลดอย่างถูกต้องหรือเมื่อเกิดข้อผิดพลาดระหว่างการดำเนินการสคริปต์. |
| OnResize | 13 | เกิดขึ้นเมื่อมุมมองเอกสารถูกปรับขนาดใหม่ ใช้ได้เฉพาะกับองค์ประกอบ svg ที่อยู่นอกสุดเท่านั้น. |
| OnScroll | 14 | เกิดขึ้นเมื่อมุมมองเอกสารถูกเลื่อนตามแกน X หรือ Y หรือทั้งสองแกน ใช้ได้เฉพาะกับองค์ประกอบ svg ที่อยู่นอกสุดเท่านั้น. |
| OnZoom | 15 | เกิดขึ้นเมื่อระดับการซูมของมุมมองเอกสารถูกเปลี่ยน ใช้ได้เฉพาะกับองค์ประกอบ svg ที่อยู่นอกสุดเท่านั้น. |
| OnBegin | 16 | เกิดขึ้นเมื่อองค์ประกอบแอนิเมชันเริ่มทำงาน. |
| OnEnd | 17 | เกิดขึ้นเมื่อองค์ประกอบแอนิเมชันสิ้นสุด. |
| OnRepeat | 18 | เกิดขึ้นเมื่อองค์ประกอบแอนิเมชันทำซ้ำ. |
