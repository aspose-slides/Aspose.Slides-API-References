## LinkEmbedDecision enum

กำหนดว่าจะประมวลผลวัตถุอย่างไรระหว่างการบันทึก.

```cpp
enum class LinkEmbedDecision
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Link | 0 | วัตถุจะถูกจัดเก็บเป็นภายนอกโดยอ้างอิงผ่าน URL |
| Embed | 1 | วัตถุควรถูกฝังในไฟล์ที่สร้างขึ้นหากทำได้ หากการฝังเป็นไปไม่ได้ GetUrl จะถูกเรียกและตามผลลัพธ์ วัตถุจะถูกอ้างอิงผ่าน URL หรือถูกละเลย |
| Ignore | 2 | วัตถุจะถูกละเลย |
