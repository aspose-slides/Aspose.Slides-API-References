## TiffCompressionTypes enum

Provides options that control how a presentation is compressed in TIFF format.

```cpp
enum class TiffCompressionTypes
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Default | 0 | ระบุโครงสร้างการบีบอัดเริ่มต้น (LZW). |
| None | 1 | ระบุว่าไม่มีการบีบอัด. |
| CCITT3 | 2 | ระบุโครงสร้างการบีบอัด CCITT3. |
| CCITT4 | 3 | ระบุโครงสร้างการบีบอัด CCITT4. |
| LZW | 4 | ระบุโครงสร้างการบีบอัด LZW (Default). |
| RLE | 5 | ระบุโครงสร้างการบีบอัด RLE. |
