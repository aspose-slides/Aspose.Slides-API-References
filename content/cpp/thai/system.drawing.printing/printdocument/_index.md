## PrintDocument คลาส

ส่งเอาต์พุตไปยังเครื่องพิมพ์เมื่อพิมพ์จากแอปพลิเคชัน [Windows](../../system.windows/) Forms. อ็อบเจ็กต์ของคลาสนี้ควรจัดสรรโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น. ห้ามสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ตัวดำเนินการ new เพราะจะทำให้เกิดข้อผิดพลาดเวลารันและ/หรือการตรวจสอบความถูกต้องล้มเหลว. หมั่นห่อหุ้มคลาสนี้ด้วยพอยเตอร์ [System::SmartPtr](../../system/smartptr/) และใช้พอยเตอร์นี้เพื่อส่งผ่านไปยังฟังก์ชันเป็นอาร์กิวเมนต์.

```cpp
class PrintDocument : public System::Object
```
