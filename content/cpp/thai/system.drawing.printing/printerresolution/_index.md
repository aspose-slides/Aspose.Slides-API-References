## PrinterResolution คลาส


แสดงถึงความละเอียดของเครื่องพิมพ์. อ็อบเจกต์ของคลาสนี้ควรจัดสรรโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น. ไม่ควรสร้างอินสแตนซ์ของชนิดนี้บนสแตกหรือโดยใช้ตัวดำเนินการ new เนื่องจากจะทำให้เกิดข้อผิดพลาดขณะรันไทม์และ/หรือการอ้างอิงที่ไม่ถูกต้อง. ควรห่อคลาสนี้ด้วยพอยเตอร์ [System::SmartPtr](../../system/smartptr/) และใช้พอยเตอร์นี้เพื่อส่งผ่านให้ฟังก์ชันเป็นอาร์กิวเมนต์.

```cpp
class PrinterResolution : public System::Object
```
