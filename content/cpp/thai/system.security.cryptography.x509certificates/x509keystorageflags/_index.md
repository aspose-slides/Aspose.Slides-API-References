## X509KeyStorageFlags enum

กำหนดวิธีการจัดเก็บคีย์.

```cpp
enum class X509KeyStorageFlags : int32_t
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| DefaultKeySet | 0 | ใช้ชุดคีย์เริ่มต้น. |
| UserKeySet | 1 | ใช้ที่เก็บที่เชื่อมโยงกับผู้ใช้แทนที่เก็บในเครื่อง. |
| MachineKeySet | 2 | ใช้ที่เก็บของเครื่องท้องถิ่นแทนที่เก็บของผู้ใช้. |
| Exportable | 4 | ทำเครื่องหมายคีย์ที่นำเข้าว่าสามารถส่งออกได้. |
| UserProtected | 8 | แจ้งผู้ใช้ว่ากำลังใช้คีย์. |
| PersistKeySet | 16 | คีย์จะถูกบันทึกคงไว้เมื่อทำการนำเข้าใบรับรอง. |
