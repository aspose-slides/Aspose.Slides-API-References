## X509Extension คลาส

ออบเจ็กต์ส่วนขยายสำหรับเก็บข้อมูลเพิ่มเติมที่เชื่อมโยงกับใบรับรอง X.509. ออบเจ็กต์ของคลาสนี้ควรจัดสรรโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น. อย่าสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ operator new เนื่องจากจะทำให้เกิดข้อผิดพลาดในเวลารันไทม์และ/หรือข้อผิดพลาดการตรวจสอบ. ควรห่อคลาสนี้ด้วยพอยน์เตอร์ [System::SmartPtr](../../system/smartptr/) และใช้พอยน์เตอร์นี้ในการส่งเป็นอาร์กิวเมนต์ให้กับฟังก์ชันต่าง ๆ.

```cpp
class X509Extension : public System::Security::Cryptography::AsnEncodedData
```
