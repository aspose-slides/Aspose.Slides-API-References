## X500DistinguishedNameFlags enum

X509 certificate distinguished name formatting rules.

```cpp
enum class X500DistinguishedNameFlags
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| None | 0 | ไม่มีคุณลักษณะพิเศษ. |
| Reversed | 1 | ชื่อถูกจองไว้. |
| UseSemicolons | 16 | ใช้เซมิโคลอน. |
| DoNotUsePlusSign | 32 | ชื่อไม่ใช้สัญลักษณ์บวก. |
| DoNotUseQuotes | 64 | ปิดการใช้เครื่องหมายคำพูดในชื่อ. |
| UseCommas | 128 | เปิดการใช้คอมม่า. |
| UseNewLines | 256 | เปิดการใช้บรรทัดใหม่. |
| UseUTF8Encoding | 4096 | เปลี่ยนจากการใช้ Unicode ไปเป็นการใช้การเข้ารหัส UTF-8. |
| UseT61Encoding | 8192 | เปลี่ยนเป็นการเข้ารหัส T61. |
| ForceUTF8Encoding | 16384 | บังคับให้ใช้ UTF-8 เมื่อเข้ารหัสคีย์ X500 เฉพาะ. |
