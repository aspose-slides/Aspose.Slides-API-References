## X509ContentType enum

รูปแบบของใบรับรอง X.509.

```cpp
enum class X509ContentType
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Unknown | 0 | ใบรับรองที่ไม่ทราบ. |
| Cert | 1 | [Single](../../system/single/) ใบรับรอง. |
| SerializedCert | 2 | ใบรับรองเดี่ยวที่ทำการซีเรียลไลซ์. |
| Pkcs12 | 3 | ใบรับรองที่มีรูปแบบ PKCS #12. |
| Pfx | 3 | ใบรับรองที่มีรูปแบบ PFX. |
| SerializedStore | 4 | ที่เก็บใบรับรองที่ทำการซีเรียลไลซ์. |
| Pkcs7 | 5 | ใบรับรองที่มีรูปแบบ PKCS #7 ที่ผ่านการรับรอง. |
| Authenticode | 6 | ใบรับรอง X.509 Authenticode. |
