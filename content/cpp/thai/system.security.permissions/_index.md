## คลาส

| Class | คำอธิบาย |
| --- | --- |
| [SecurityPermission](./securitypermission/) | คลาสที่อธิบายสิทธิ์ความปลอดภัย. อ็อบเจ็กต์ของคลาสนี้ควรจะจัดสรรเท่านั้นโดยใช้ฟังก์ชัน [System::MakeObject()](../system/makeobject/). ห้ามสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ตัวดำเนินการ new เนื่องจากจะทำให้เกิดข้อผิดพลาดขณะทำงานและ/หรือการตรวจสอบความถูกต้องล้มเหลว. ควรห่อคลาสนี้ไว้ในพอยน์เตอร์ [System::SmartPtr](../system/smartptr/) เสมอและใช้พอยน์เตอร์นี้เพื่อส่งผ่านไปยังฟังก์ชันเป็นอาร์กิวเมนต์. |
## เอนม

| Enum | คำอธิบาย |
| --- | --- |
| [PermissionState](./permissionstate/) | สถานะของสิทธิ์. |
| [SecurityPermissionFlag](./securitypermissionflag/) | แฟล็กของสิทธิ์ความปลอดภัย. |
