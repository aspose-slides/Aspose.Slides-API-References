## MetafileFrameUnit enum

ระบุหน่วยการวัดสำหรับสี่เหลี่ยมที่ใช้กำหนดขนาดและตำแหน่งของเมตาไฟล์

```cpp
enum class MetafileFrameUnit
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Pixel | n/a | ระบุพิกเซลเป็นหน่วยการวัด |
| Point | n/a | ระบุหน่วยจุดของเครื่องพิมพ์เป็นหน่วยการวัด |
| Inch | n/a | ระบุหน่วยนิ้วเป็นหน่วยการวัด |
| Document | n/a | ระบุ 1/300 นิ้วเป็นหน่วยการวัด |
| Millimeter | n/a | ระบุมิลลิเมตรเป็นหน่วยการวัด |
| GdiCompatible | n/a | ระบุ 0.01 มิลลิเมตรเป็นหน่วยการวัด ให้สำหรับความเข้ากันได้กับ GDI |
