## ColorMatrixFlag enum

```cpp
enum class ColorMatrixFlag
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Default | 0 | ทั้งสีและค่าระดับสีจะถูกปรับสี |
| SkipGrays | 1 | ค่าระดับสีจะไม่ถูกปรับสี |
| AltGrays | 2 | เฉพาะค่าระดับสีจะถูกปรับสี |
