## EncoderValue enum

```cpp
enum class EncoderValue
```

| Name | Value | Description |
| --- | --- | --- |
| ColorTypeCMYK | 0 | พื้นที่สี CMYK. |

| CompressionLZW | 2 | วิธีการบีบอัด LZW. |

| ScanMethodInterlaced | 7 | โหมดสลับบรรทัด. |
| ScanMethodNonInterlaced | 8 | โหมดไม่สลับบรรทัด. |

| TransformRotate180 | 14 | ระบุการหมุนแบบไม่สูญเสียข้อมูล 180 องศาสำหรับภาพ JPEG. |
| TransformRotate270 | 15 | ระบุการหมุนแบบไม่สูญเสียข้อมูล 270 องศาตามเข็มนาฬิกาสำหรับภาพ JPEG. |
| TransformFlipHorizontal | 16 | ระบุการพลิกแนวนอนแบบไม่สูญเสียข้อมูลสำหรับภาพ JPEG. |
