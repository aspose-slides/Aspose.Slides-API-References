## ImageFlags enum

แสดงคุณสมบัติของข้อมูลพิกเซลที่เป็นตัวแทนโดยอ็อบเจ็กต์ [Image](../../system.drawing/image/).

```cpp
enum class ImageFlags
```

### Values

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| None | 0 |  |
| Scalable | 1 | ปรับขนาดได้. |
| HasAlpha | 2 | มีข้อมูลแอลฟา. |
| HasTranslucent | 4 | มีค่าตำแหน่งแอลฟาที่มากกว่า 0 และน้อยกว่า 255. |
| PartiallyScalable | 8 |  |
| ColorSpaceRgb | 16 | ข้อมูลพิกเซลแสดงในสีสเปซ RGB. |
| ColorSpaceCmyk | 32 | ข้อมูลพิกเซลแสดงในสีสเปซ CMYK. |
| ColorSpaceGray | 64 | ข้อมูลพิกเซลเป็นสีเทา. |
| ColorSpaceYcbcr | 128 | ข้อมูลพิกเซลแสดงในสีสเปซ YCBCR. |
| ColorSpaceYcck | 256 | ข้อมูลพิกเซลแสดงในสีสเปซ YCCK. |
| HasRealDpi | 4096 | ข้อมูล DPI ถูกเก็บในภาพ. |
| HasRealPixelSize | 8192 | ขนาดของพิกเซลถูกเก็บในภาพ. |
| ReadOnly | 65536 | ข้อมูลพิกเซลเป็นแบบอ่านอย่างเดียว. |
| Caching | 131072 | สามารถแคชเพื่อการเข้าถึงที่เร็วขึ้น. |
