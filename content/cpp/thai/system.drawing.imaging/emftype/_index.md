## EmfType enum


Specifies the types of the records that are placed in an EMF file.

```cpp
enum class EmfType
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| EmfOnly | n/a | [Windows](../../system.windows/) เมตาฟไฟล์ที่ปรับปรุงแล้ว. ประกอบด้วยคำสั่ง GDI. เมตาฟไฟล์ประเภทนี้จะถูกเรียกว่าไฟล์ EMF. |
| EmfPlusOnly | n/a | [Windows](../../system.windows/) เมตาฟไฟล์ที่ปรับปรุงแล้วแบบ plus. ประกอบด้วยคำสั่ง GDI+. เมตาฟไฟล์ประเภทนี้จะถูกเรียกว่าไฟล์ EMF+. |
| EmfPlusDual | n/a | Dual [Windows](../../system.windows/) เมตาฟไฟล์ที่ปรับปรุงแล้ว. ประกอบด้วยคำสั่ง GDI และ GDI+ ที่เทียบเท่า. เมตาฟไฟล์ประเภทนี้จะถูกเรียกว่าไฟล์ EMF+. |
