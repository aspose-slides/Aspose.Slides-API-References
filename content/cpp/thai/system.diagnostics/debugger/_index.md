## Debugger struct


[Debugger](./) อินเทอร์เฟซ. นี้เป็นประเภทสแตติกที่ไม่มีบริการอินสแตนซ์. คุณไม่ควรสร้างอินสแตนซ์ของมันด้วยวิธีใดๆ

```cpp
class Debugger
```

| เมธอด | คำอธิบาย |
| --- | --- |
| static void [Break](./break/)() | เริ่มต้นการหยุดดีบักเกอร์ (หากเชื่อมต่อ). |
| static **bool** [get_IsAttached](./get_isattached/)() | ตรวจสอบว่าดีบักเกอร์เชื่อมต่อกับอินสแตนซ์แอปพลิเคชันปัจจุบันหรือไม่. |
