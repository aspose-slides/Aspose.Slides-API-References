## Process::WaitForExit(int) เมธอด

รอให้กระบวนการออกจากการทำงาน ยังไม่ได้ดำเนินการ.

```cpp
bool System::Diagnostics::Process::WaitForExit(int milliseconds)
```

### อาร์กิวเมนต์

| Parameter | Type | Description |
| --- | --- | --- |
| milliseconds | int | Maximum waiting delay. |

### ค่าที่ส่งคืน

True หากกระบวนการเสร็จสิ้น, false หากเวลาหมด.

## Process::WaitForExit() เมธอด

รอให้กระบวนการออกจากการทำงานและจะไม่คืนค่าจนกว่าจะเสร็จสิ้น.

```cpp
void System::Diagnostics::Process::WaitForExit()
```
