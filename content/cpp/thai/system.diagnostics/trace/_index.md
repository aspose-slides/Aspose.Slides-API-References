## Trace struct

ให้ส่วนต่อประสานเพื่อเข้าถึง debugger trace (หากมี). ทำงานในโหมด [Debug](../debug/) เท่านั้น. นี้คือประเภทแบบ static ที่ไม่มีบริการตัวอย่าง. คุณไม่ควรสร้างอินสแตนซ์ของมันด้วยวิธีใด ๆ.

```cpp
class Trace
```

## เมธอด

| เมธอด | คำอธิบาย |
| --- | --- |
| static void [Flush](./flush/)() | ล้างบัฟเฟอร์เอาต์พุตและทำให้ข้อมูลที่บัฟเฟอร์ไวถูกรายงานไปยังผู้ฟัง |
| static void [WriteLine](./writeline/)(const [String](../../system/string/)\&) | เขียนบรรทัดไปยัง debugger trace |
