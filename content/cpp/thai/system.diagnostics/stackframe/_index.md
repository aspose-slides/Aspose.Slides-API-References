## StackFrame คลาส


รับข้อมูลเกี่ยวกับเฟรมสแตกเดียว. MSVS เท่านั้น. วัตถุของคลาสนี้ควรจะจัดสรรโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น. อย่าสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือใช้ operator new, เนื่องจากจะทำให้เกิดข้อผิดพลาดเวลารันและ/หรือการประกันข้อผิดพลาด. ควรห่อคลาสนี้ในตัวชี้ [System::SmartPtr](../../system/smartptr/) และใช้ตัวชี้นี้เพื่อส่งไปยังฟังก์ชันเป็นอาร์กิวเมนต์.

```cpp
class StackFrame : public System::Object
```
