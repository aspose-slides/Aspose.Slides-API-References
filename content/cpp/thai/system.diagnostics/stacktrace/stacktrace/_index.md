## StackTrace::StackTrace() ตัวสร้าง

สร้าง stack trace ที่อธิบายสถานะของสแตกในปัจจุบัน.

```cpp
System::Diagnostics::StackTrace::StackTrace()
```
## StackTrace::StackTrace(bool) ตัวสร้าง

สร้าง stack trace ที่อธิบายสถานะของสแตกในปัจจุบัน.

```cpp
System::Diagnostics::StackTrace::StackTrace(bool isFileInfoNeeded)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| isFileInfoNeeded | **bool** | True เพื่อบันทึกชื่อไฟล์, หมายเลขบรรทัด, และหมายเลขคอลัมน์; otherwise, false |

## StackTrace::StackTrace(const StackTrace\&) ตัวสร้าง

ไม่มีการคัดลอก.

```cpp
System::Diagnostics::StackTrace::StackTrace(const StackTrace &)=delete
```
