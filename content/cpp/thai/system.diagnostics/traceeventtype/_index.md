## TraceEventType enum

ระบุประเภทของเหตุการณ์ที่ทำให้เกิดการติดตาม

```cpp
enum class TraceEventType
```

### Values

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Critical | 1 | ข้อผิดพลาดร้ายแรงหรือการล่มของแอปพลิเคชัน |
| Error | 2 | ข้อผิดพลาดที่สามารถกู้คืนได้ |
| Warning | 4 | ปัญหาที่ไม่ร้ายแรง |
| Information | 8 | ข้อความข้อมูล |
| Verbose | 16 | การติดตามเพื่อการดีบัก |
| Start | 256 | การเริ่มต้นของการดำเนินการเชิงตรรกะ |
| Stop | 512 | การหยุดของการดำเนินการเชิงตรรกะ |
| Suspend | 1024 | การระงับของการดำเนินการเชิงตรรกะ |
| Resume | 2048 | การทำงานต่อของการดำเนินการเชิงตรรกะ |
| Transfer | 4096 | การเปลี่ยนแปลงของอัตลักษณ์การเชื่อมโยง |
