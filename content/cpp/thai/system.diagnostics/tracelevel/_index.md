## TraceLevel enum

ระบุว่าข้อความใดจะถูกส่งออกสำหรับ [System.Diagnostics.Debug](../debug/), [System.Diagnostics.Trace](../trace/) และคลาส System.Diagnostics.TraceSwitch

```cpp
enum class TraceLevel
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Off | 0 | ไม่แสดงข้อความการติดตามและดีบั๊ก |
| Error | 1 | แสดงข้อความการจัดการข้อผิดพลาด |
| Warning | 2 | แสดงคำเตือนและข้อความการจัดการข้อผิดพลาด |
| Info | 3 | แสดงข้อความสารสนเทศ, คำเตือน, และข้อความการจัดการข้อผิดพลาด |
| Verbose | 4 | แสดงข้อความดีบั๊กและการติดตามทั้งหมด |
