## IEnumeratorImplValueType::MoveNext() เมธอด

ย้ายตัววนรอบไปยังองค์ประกอบถัดไป หากไม่มีองค์ประกอบที่อ้างถึงก่อนหน้านี้ จะตั้งค่าอ้างอิงไปยังองค์ประกอบแรกที่มีอยู่ หากถึงจุดสิ้นสุดของคอนเทนเนอร์ จะไม่ทำอะไร

```cpp
virtual bool System::Collections::IEnumeratorImplValueType<T>::MoveNext() override
```

### ค่าที่ส่งคืน

True หากมีองค์ประกอบบางอย่างพร้อมใช้งานหลังจากการเรียก, false ในกรณีอื่น
