## IEnumeratorImplRefType::MoveNext() เมธอด


ย้ายตัว enumerator ไปยังสมาชิกถัดไป หากไม่มีสมาชิกที่อ้างอิงมาก่อน จะตั้งค่าอ้างอิงไปยังสมาชิกแรกที่มีอยู่ หากถึงจุดสิ้นสุดของคอนเทนเนอร์ จะไม่ทำอะไร.

```cpp
virtual bool System::Collections::IEnumeratorImplRefType<T>::MoveNext() override
```


### ค่าที่ส่งกลับ

True หากมีสมาชิกบางตัวพร้อมใช้งานหลังจากการเรียก, false หากไม่มี.
