## AuthenticationLevel enum

แฟล็กการตรวจสอบสิทธิ์ที่เฉพาะสำหรับ WebRequest.

```cpp
enum class AuthenticationLevel
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| None | 0 | ไม่จำเป็นต้องมีการตรวจสอบสิทธิ์สำหรับไคลเอนต์และเซิร์ฟเวอร์ |
| MutualAuthRequested | 1 | คำขอจะไม่ล้มเหลหากเซิร์ฟเวอร์ไม่ได้รับการตรวจสอบสิทธิ์ |
| MutualAuthRequired | 2 | แอปพลิเคชันปัจจุบันจะได้รับ 'IOException' เมื่อเซิร์ฟเวอร์ไม่ได้รับการตรวจสอบสิทธิ์ |
