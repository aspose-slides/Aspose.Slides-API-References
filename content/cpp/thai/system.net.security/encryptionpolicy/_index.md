## EncryptionPolicy enum


แสดงรายการนโยบายการเข้ารหัส.

```cpp
enum class EncryptionPolicy
```

### Values

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| RequireEncryption | 0 | บังคับให้เข้ารหัสและไม่อนุญาตให้ใช้ซิฟเฟอร์ 'Null' |
| AllowNoEncryption | 1 | แนะนำให้ใช้การเข้ารหัสเต็มรูปแบบ แต่สามารถใช้ซิฟเฟอร์ 'Null' หากเซิร์ฟเวอร์ยอมรับ |
| NoEncryption | 2 | อนุญาตให้ไม่มีการเข้ารหัสและขอให้ใช้ซิฟเฟอร์ 'Null' หากปลายทางอื่นสามารถจัดการซิฟเฟอร์ 'Null' ได้ |
