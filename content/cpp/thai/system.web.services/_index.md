## คลาส

| คลาส | คำอธิบาย |
| --- | --- |
| [Soap](./soap/) | บรรจุค่าสตริงคงที่ของ SOAP. |
| [Soap12](./soap12/) | บรรจุค่าสตริงคงที่ของ SOAP เวอร์ชัน 1.2. |
| [WebServiceAttribute](./webserviceattribute/) | เพิ่มข้อมูลเพิ่มเติมให้กับบริการ XML [Web](../system.web/). วัตถุของคลาสนี้ควรจัดสรรเฉพาะโดยใช้ฟังก์ชัน [System::MakeObject()](../system/makeobject/). ห้ามสร้างอินสแตนซ์ของประเภทนี้บนสแต็กหรือโดยใช้ operator new เนื่องจากจะทำให้เกิดข้อผิดพลาดรันไทม์และ/หรือการละเมิดการอ้างอิง. ห่อหุ้มคลาสนี้ด้วยพอยน์เตอร์ [System::SmartPtr](../system/smartptr/) เสมอและใช้พอยน์เตอร์นี้เพื่อส่งเป็นอาร์กิวเมนต์ให้กับฟังก์ชัน. |
| [WebServiceBindingAttribute](./webservicebindingattribute/) | ใช้ประกาศการผูกที่กำหนดหนึ่งหรือหลายเมธอดของบริการ XML [Web](../system.web/). วัตถุของคลาสนี้ควรจัดสรรเฉพาะโดยใช้ฟังก์ชัน [System::MakeObject()](../system/makeobject/). ห้ามสร้างอินสแตนซ์ของประเภทนี้บนสแต็กหรือโดยใช้ operator new เนื่องจากจะทำให้เกิดข้อผิดพลาดรันไทม์และ/หรือการละเมิดการอ้างอิง. ห่อหุ้มคลาสนี้ด้วยพอยน์เตอร์ [System::SmartPtr](../system/smartptr/) เสมอและใช้พอยน์เตอร์นี้เพื่อส่งเป็นอาร์กิวเมนต์ให้กับฟังก์ชัน. |
