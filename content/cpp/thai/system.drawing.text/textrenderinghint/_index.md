## TextRenderingHint enum

ระบุคุณภาพของการเรนเดอร์ข้อความ.

```cpp
enum class TextRenderingHint
```

### ค่าต่างๆ

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| SystemDefault | 0 | Glyph ด้วยคำแนะนำการเรนเดอร์ตามค่าเริ่มต้นของระบบ |
| SingleBitPerPixelGridFit | 1 | บิตแมพ Glyph พร้อมการแนะนำ |
| SingleBitPerPixel | 2 | บิตแมพ Glyph ไม่มีการแนะนำ |
| AntiAliasGridFit | 3 | Anti-aliasing พร้อมการแนะนำ |
| AntiAlias | 4 | Glyph anti-alias bitmap ไม่มีการแนะนำ |
| ClearTypeGridFit | 5 | Glyph CT bitmap พร้อมการแนะนำ |
