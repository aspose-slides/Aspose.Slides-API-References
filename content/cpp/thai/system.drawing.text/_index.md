## คลาส

| คลาส | คำอธิบาย |
| --- | --- |
| [FontCollection](./fontcollection/) | คลาสพื้นฐานสำหรับคอลเลกชันฟอนต์ที่ติดตั้งและส่วนตัว. วัตถุของคลาสนี้ควรจัดสรรโดยใช้ฟังก์ชัน [System::MakeObject()](../system/makeobject/) เท่านั้น. ห้ามสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ตัวดำเนินการ new เนื่องจากจะทำให้เกิดข้อผิดพลาดเวลารันและ/หรือการตรวจสอบล้มเหลว. ห่อคลาสนี้ด้วยตัวชี้ [System::SmartPtr](../system/smartptr/) เสมอและใช้ตัวชี้นี้เพื่อส่งผ่านให้ฟังก์ชันเป็นอากิวเมนต์. |
| [InstalledFontCollection](./installedfontcollection/) | แสดงคอลเลกชันของฟอนต์ที่ติดตั้งในระบบ. ยังไม่ได้ดำเนินการ. วัตถุของคลาสนี้ควรจัดสรรโดยใช้ฟังก์ชัน [System::MakeObject()](../system/makeobject/) เท่านั้น. ห้ามสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ตัวดำเนินการ new เนื่องจากจะทำให้เกิดข้อผิดพลาดเวลารันและ/หรือการตรวจสอบล้มเหลว. ห่อคลาสนี้ด้วยตัวชี้ [System::SmartPtr](../system/smartptr/) เสมอและใช้ตัวชี้นี้เพื่อส่งผ่านให้ฟังก์ชันเป็นอากิวเมนต์. |
| [PrivateFontCollection](./privatefontcollection/) | แสดงคอลเลกชันของฟอนต์แฟมิลีกที่จัดทำโดยแอปพลิเคชันไคลเอ็นต์. วัตถุของคลาสนี้ควรจัดสรรโดยใช้ฟังก์ชัน [System::MakeObject()](../system/makeobject/) เท่านั้น. ห้ามสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ตัวดำเนินการ new เนื่องจากจะทำให้เกิดข้อผิดพลาดเวลารันและ/หรือการตรวจสอบล้มเหลว. ห่อคลาสนี้ด้วยตัวชี้ [System::SmartPtr](../system/smartptr/) เสมอและใช้ตัวชี้นี้เพื่อส่งผ่านให้ฟังก์ชันเป็นอากิวเมนต์. |
