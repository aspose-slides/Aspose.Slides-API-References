## WebProxy::IsBypassed(System::SharedPtr\<Uri\>) เมธอด

ตรวจสอบว่าเซิร์ฟเวอร์พร็อกซี่ไม่ได้ถูกใช้สำหรับ URI ที่ระบุหรือไม่.

```cpp
bool System::Net::WebProxy::IsBypassed(System::SharedPtr<Uri> host)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| host | [System::SharedPtr](../../../system/sharedptr/)\<[Uri](../../../system/uri/)\> | URI ที่จะตรวจสอบ. |

### ค่าที่ส่งกลับ

True เมื่อเซิร์ฟเวอร์พร็อกซี่ไม่ถูกใช้สำหรับ URI ที่ระบุ, มิฉะนั้น false.
