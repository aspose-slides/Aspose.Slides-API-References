## IWebProxy คลาส

อินเทอร์เฟซนี้ใช้สำหรับการดำเนินการเข้าถึงพร็อกซี่ของคลาส [WebRequest](../webrequest/). ออบเจ็กต์ของคลาสนี้ควรสร้างขึ้นเฉพาะโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/). อย่าสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ตัวดำเนินการ new, เนื่องจากจะทำให้เกิดข้อผิดพลาดเวลาเรียกใช้และ/หรือข้อผิดพลาดการตรวจสอบ. ควรห่อคลาสนี้ด้วยพอยน์เตอร์ [System::SmartPtr](../../system/smartptr/) และใช้พอยน์เตอร์นี้เพื่อส่งผ่านเป็นอาร์กิวเมนต์ให้กับฟังก์ชัน.

```cpp
class IWebProxy : public virtual System::Object
```
