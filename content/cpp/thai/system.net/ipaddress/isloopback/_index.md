## IPAddress::IsLoopback(System::SharedPtr\<IPAddress\>) เมธอด

Returns a value that indicates if the specified address is a loopback address.

```cpp
static bool System::Net::IPAddress::IsLoopback(System::SharedPtr<IPAddress> address)
```

### อาร์กิวเมนต์

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| address | [System::SharedPtr](../../../system/sharedptr/)\<[IPAddress](../)\> | ที่อยู่ที่ต้องตรวจสอบ. |

### ค่าที่ส่งคืน

True เมื่อที่อยู่ที่ระบุเป็นที่อยู่ loopback, มิฉะนั้นเป็น false.
