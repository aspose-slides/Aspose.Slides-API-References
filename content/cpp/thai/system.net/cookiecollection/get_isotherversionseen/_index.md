## CookieCollection::get_IsOtherVersionSeen() เมธอด

ส่งคืนค่าที่บ่งชี้ว่าคอลเลกชันมีคุกกี้ที่มีเวอร์ชันไม่เท่ากับ [Cookie::MaxSupportedVersion](../../cookie/maxsupportedversion/).

```cpp
bool System::Net::CookieCollection::get_IsOtherVersionSeen()
```

### ค่าที่ส่งคืน

เป็น true เมื่อคอลเลกชันมีคุกกี้ที่มีเวอร์ชันไม่เท่ากับ [Cookie::MaxSupportedVersion](../../cookie/maxsupportedversion/) มิฉะนั้นเป็น false.
