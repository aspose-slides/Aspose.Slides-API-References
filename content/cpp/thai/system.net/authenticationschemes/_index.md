## AuthenticationSchemes enum

```cpp
enum class AuthenticationSchemes
```

### Values

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| None | 0 | ไม่จำเป็นต้องตรวจสอบสิทธิ์ |
| Digest | 1 | การตรวจสอบสิทธิ์แบบ Digest |
| Negotiate | 2 | เจรจากับไคลเอนต์เพื่อกำหนดว่าจะใช้โหมดการตรวจสอบสิทธิ์ใด (NTML หรือ Kerberos). |
| Ntlm | 4 | การตรวจสอบสิทธิ์ NTLM. |
| Basic | 8 | การตรวจสอบสิทธิ์พื้นฐาน. |
| Anonymous | 32768 | การตรวจสอบสิทธิ์แบบนิรนาม. |
| IntegratedWindowsAuthentication | n/a | [Windows](../../system.windows/) การตรวจสอบสิทธิ์. |
