## TransportType enum

กำหนดประเภทการส่งข้อมูลที่อนุญาตสำหรับซ็อกเก็ต.

```cpp
enum class TransportType
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Udp | 1 | ประเภทการส่งข้อมูล UDP. |
| Connectionless | n/a | ประเภทการส่งข้อมูลเป็นแบบไม่มีการเชื่อมต่อ. |
| Tcp | 2 | ประเภทการส่งข้อมูล TCP. |
| ConnectionOriented | n/a | การส่งข้อมูลเป็นแบบเชื่อมต่อทิศทาง. |
| All | 3 | ประเภทการส่งข้อมูลทั้งหมด. |
