## คลาส

| คลาส | คำอธิบาย |
| --- | --- |
| [DataGrid](./datagrid/) | คลาสจำลองที่ทำให้สามารถเชื่อมโยงโค้ดที่แปลกับอ้างอิง [DataGrid](./datagrid/) ได้ แต่ไม่ทำการเรียกใช้งาน. มีสมาชิกที่ไม่มีการนำไปใช้อย่างเหมาะสม. วัตถุของคลาสนี้ควรจัดสรรด้วยฟังก์ชัน [System::MakeObject()](../system/makeobject/) เท่านั้น. ห้ามสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ operator new เนื่องจากจะทำให้เกิดข้อผิดพลาดขณะรันไทม์และ/หรือข้อผิดพลาดการยืนยัน. ควรห่อคลาสนี้ด้วยพอยน์เตอร์ [System::SmartPtr](../system/smartptr/) เสมอและใช้พอยน์เตอร์นี้เพื่อส่งเป็นอาร์กิวเมนต์ให้กับฟังก์ชัน. |
