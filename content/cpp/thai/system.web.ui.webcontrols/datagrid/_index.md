## DataGrid คลาส

คลาส Dummy ที่ทำให้สามารถเชื่อมโยงโค้ดที่แปลกับอ้างอิง [DataGrid](./) ได้ แต่ไม่ได้ทำการประมวลผล มีสมาชิกที่ไม่ได้ถูกนำไปใช้จริง ควรสร้างออบเจกต์ของคลาสนี้โดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น ไม่ควรสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือใช้ operator new เนื่องจากจะทำให้เกิดข้อผิดพลาดเวลารันและ/หรือการละเมิดการยืนยัน ควรห่อคลาสนี้ด้วยพอยเตอร์ [System::SmartPtr](../../system/smartptr/) และใช้พอยเตอร์นี้เพื่อส่งผ่านไปยังฟังก์ชันเป็นอาร์กิวเมนต์

```cpp
class DataGrid : public System::Object
```
