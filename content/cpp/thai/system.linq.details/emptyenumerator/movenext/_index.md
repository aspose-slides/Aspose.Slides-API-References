## EmptyEnumerator::MoveNext() เมธอด

Moves enumerator ไปยังองค์ประกอบถัดไป หากไม่มีองค์ประกอบใดถูกอ้างอิงก่อนหน้านี้ จะตั้งค่าการอ้างอิงไปยังองค์ประกอบแรกที่มีอยู่ หากถึงจุดสิ้นสุดของคอนเทนเนอร์ จะไม่มีการกระทำใด

```cpp
bool System::Linq::Details::EmptyEnumerator<T>::MoveNext() override
```

### ค่าที่คืน

True หากมีองค์ประกอบบางอย่างพร้อมใช้งานหลังจากการเรียก, false ในกรณีอื่น
