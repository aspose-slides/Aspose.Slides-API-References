## StringCollection::crbegin() const เมธอด


คืนค่า iterator แบบย้อนกลับไปยังองค์ประกอบแรกของคอนเทนเนอร์ที่ถูกย้อนกลับ จะสอดคล้องกับองค์ประกอบสุดท้ายของคอนเทนเนอร์ที่ไม่ได้ย้อนกลับ หากคอนเทนเนอร์ว่าง iterator ที่คืนค่าจะเท่ากับ [crend()](../crend/).

```cpp
const_reverse_iterator System::Collections::Specialized::StringCollection::crbegin() const noexcept
```


### ค่าที่ส่งคืน

Iterator ที่ชี้ไปยังองค์ประกอบสุดท้ายที่มี const ของคอนเทนเนอร์
