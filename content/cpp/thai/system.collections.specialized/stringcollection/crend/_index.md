## StringCollection::crend() const เมธอด

ส่งคืน reverse iterator ไปยังองค์ประกอบที่อยู่ถัดจากองค์ประกอบสุดท้ายของคอนเทนเนอร์ที่ถูกกลับด้าน มันสอดคล้องกับองค์ประกอบที่อยู่ก่อนหน้าทำรายการแรกของคอนเทนเนอร์ที่ไม่ได้กลับด้าน องค์ประกอบนี้ทำหน้าที่เป็นตัวแทน หากพยายามเข้าถึงจะทำให้เกิดพฤติกรรมที่ไม่กำหนด

```cpp
const_reverse_iterator System::Collections::Specialized::StringCollection::crend() const noexcept
```

### ค่าที่ส่งกลับ

ตัววนซ้ำที่ชี้ไปยังองค์ประกอบที่มี const-qualified อย่างทฤษฎีซึ่งอยู่ก่อนองค์ประกอบแรกของคอนเทนเนอร์
