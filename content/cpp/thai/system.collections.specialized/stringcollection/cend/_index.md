## StringCollection::cend() const เมธอด

คืน iterator ไปยังองค์ประกอบที่อยู่ถัดจากองค์ประกอบสุดท้ายของคอนเทนเนอร์ องค์ประกอบนี้ทำหน้าที่เป็นตัวแทน; การพยายามเข้าถึงจะส่งผลให้เกิดพฤติกรรมที่ไม่กำหนด

```cpp
const_iterator System::Collections::Specialized::StringCollection::cend() const noexcept
```

### ค่าที่คืน

iterator ที่ชี้ไปยังองค์ประกอบที่เป็น const-qualified อย่างทฤษฎีซึ่งอยู่หลังองค์ประกอบสุดท้ายของคอนเทนเนอร์
