## StringCollection::rbegin() เมธอด


คืนตัววนซ้ำแบบย้อนกลับไปยังอิลเมนต์แรกของคอนเทนเนอร์ที่ถูกกลับด้าน มันสอดคล้องกับอิลเมนต์สุดท้ายของคอนเทนเนอร์ที่ไม่ได้กลับด้าน หากคอนเทนเนอร์ว่าง iterator ที่คืนค่ามีค่าเท่ากับ [rend()](../rend/).

```cpp
reverse_iterator System::Collections::Specialized::StringCollection::rbegin() noexcept
```


### ค่าที่ส่งคืน

ตัว iterator ที่ชี้ไปยังอิลเมนต์สุดท้ายของคอนเทนเนอร์.

## StringCollection::rbegin() const เมธอด


คืนตัววนซ้ำแบบย้อนกลับไปยังอิลเมนต์แรกของคอนเทนเนอร์ที่ถูกกลับด้าน มันสอดคล้องกับอิลเมนต์สุดท้ายของคอนเทนเนอร์ที่ไม่ได้กลับด้าน หากคอนเทนเนอร์ว่าง iterator ที่คืนค่ามีค่าเท่ากับ [rend()](../rend/).

```cpp
const_reverse_iterator System::Collections::Specialized::StringCollection::rbegin() const noexcept
```


### ค่าที่ส่งคืน

ตัว iterator ที่ชี้ไปยังอิลเมนต์สุดท้ายของคอนเทนเนอร์ที่มีคุณสมบัติ const.
