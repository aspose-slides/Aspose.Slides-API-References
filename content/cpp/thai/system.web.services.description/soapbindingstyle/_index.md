## SoapBindingStyle enum

```cpp
enum class SoapBindingStyle
```

### ค่าต่างๆ

| Name | Value | Description |
| --- | --- | --- |
| Default | 0 | ประเภทการกระทำเริ่มต้น |
| Document | 1 | ข้อความมีลักษณะเป็นเอกสาร |
| Rpc | 2 | ข้อความประกอบด้วยพารามิเตอร์สำหรับเรียกกระบวนการหรือค่าที่ส่งกลับของกระบวนการนั้น |
