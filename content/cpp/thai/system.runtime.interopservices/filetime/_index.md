## โครงสร้าง FILETIME

เก็บส่วนประกอบของเวลาไฟล์. ชนิดนี้ควรจัดสรรบนสแตกและส่งผ่านไปยังฟังก์ชันโดยค่า หรือโดยการอ้างอิง. อย่าใช้คลาส [System::SmartPtr](../../system/smartptr/) เพื่อจัดการอ็อบเจกต์ของชนิดนี้.

```cpp
class FILETIME
```
