## IXsltContextVariable::get_IsParam() เมธอด

```cpp
virtual bool System::Xml::Xsl::IXsltContextVariable::get_IsParam()=0
```

### ค่าที่ส่งกลับ

**true** หากตัวแปรเป็นพารามิเตอร์ XSLT; มิฉะนั้น **false**.
