## XsltSettings::get_EnableScript() เมธอด


ส่งค่ากลับซึ่งบ่งบอกว่าควรเปิดการสนับสนุนบล็อกสคริปต์ที่ฝังอยู่หรือไม่.

```cpp
bool System::Xml::Xsl::XsltSettings::get_EnableScript()
```


### ค่าที่ส่งคืน

**true** เพื่อสนับสนุนบล็อกสคริปต์ในสไตล์ชีต XSLT; มิฉะนั้น, **false**. ค่าเริ่มต้นคือ **false**.
