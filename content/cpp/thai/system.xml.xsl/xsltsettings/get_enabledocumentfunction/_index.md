## XsltSettings::get_EnableDocumentFunction() เมธอด

คืนค่าเป็นบูลีนที่บ่งบอกว่าควรเปิดการสนับสนุนฟังก์ชัน **document()** ของ XSLT หรือไม่

```cpp
bool System::Xml::Xsl::XsltSettings::get_EnableDocumentFunction()
```

### ค่าที่ส่งคืน

**true** เพื่อสนับสนุนฟังก์ชัน **document()** ของ XSLT; มิฉะนั้น, **false**. ค่าเริ่มต้นคือ **false**.
