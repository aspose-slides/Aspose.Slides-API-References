## DbConnectionStringBuilder คลาส

API เพื่อสร้างค่าสตริงการเชื่อมต่อของฟิลด์ที่มีชื่อ. วัตถุของคลาสนี้ควรถูกจัดสรรเท่านั้นโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/). ไม่ควรสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ operator new, เนื่องจากจะทำให้เกิดข้อผิดพลาดเวลารันและ/หรือการผิดพลาดของการตรวจสอบ. ควรห่อหุ้มคลาสนี้ด้วยตัวชี้ [System::SmartPtr](../../system/smartptr/) และใช้ตัวชี้นี้เพื่อส่งให้ฟังก์ชันเป็นอาร์กิวเมนต์.

```cpp
class DbConnectionStringBuilder : public System::Object
```
