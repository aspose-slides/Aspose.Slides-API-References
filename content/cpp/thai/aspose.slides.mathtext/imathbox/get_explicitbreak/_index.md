## IMathBox::get_ExplicitBreak() เมธอด


การหยุดอย่างชัดเจนระบุว่ามีการขึ้นบรรทัดใหม่ที่จุดเริ่มต้นของวัตถุ Box หรือไม่ เพื่อให้บรรทัดห่อหุ้มที่จุดเริ่มต้นของวัตถุ Box. ระบุหมายเลขของตัวดำเนินการบนบรรทัดก่อนหน้าของข้อความคณิตศาสตร์ซึ่งจะใช้เป็นจุดจัดแนวสำหรับบรรทัดปัจจุบันของข้อความคณิตศาสตร์ ค่าที่เป็นไปได้: 1..255 ค่าเริ่มต้น: 0 (ไม่มีการหยุดอย่างชัดเจน)

```cpp
virtual uint8_t Aspose::Slides::MathText::IMathBox::get_ExplicitBreak()=0
```

## หมายเหตุ


ตัวอย่าง: 
```cpp
auto box = System::MakeObject<MathematicalText>(u"==")->ToBox();
box->set_ExplicitBreak(1);
```
