## IMathBox::set_ExplicitBreak(uint8_t) เมธอด


การหยุดบรรทัดโดยชัดเจนระบุว่ามีการตัดบรรทัดที่จุดเริ่มต้นของวัตถุ Box หรือไม่ ซึ่งทำให้บรรทัดห่อหุ้มที่จุดเริ่มต้นของวัตถุ Box. ระบุจำนวนของตัวดำเนินการในบรรทัดก่อนหน้าของข้อความคณิตศาสตร์ซึ่งจะใช้เป็นจุดจัดแนวสำหรับบรรทัดปัจจุบันของข้อความคณิตศาสตร์ ค่าที่เป็นไปได้: 1..255 ค่าเริ่มต้น: 0 (ไม่มีการหยุดบรรทัดโดยชัดเจน)

```cpp
virtual void Aspose::Slides::MathText::IMathBox::set_ExplicitBreak(uint8_t value)=0
```

## หมายเหตุ


ตัวอย่าง: 
```cpp
auto box = System::MakeObject<MathematicalText>(u"==")->ToBox();
box->set_ExplicitBreak(1);
```
