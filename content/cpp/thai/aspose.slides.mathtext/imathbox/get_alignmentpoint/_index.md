## IMathBox::get_AlignmentPoint() เมธอด

When true, this operator emulator serves as an alignment point; that is, designated alignment points in other equations can be aligned with it. ค่าเริ่มต้น: false

```cpp
virtual bool Aspose::Slides::MathText::IMathBox::get_AlignmentPoint()=0
```

## หมายเหตุ

ตัวอย่าง:
```cpp
auto box = System::MakeObject<MathematicalText>(u"==")->ToBox();
box->set_AlignmentPoint(true);
```
