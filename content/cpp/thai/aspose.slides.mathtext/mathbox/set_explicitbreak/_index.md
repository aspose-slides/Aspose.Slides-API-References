## MathBox::set_ExplicitBreak(uint8_t) method


การแตกบรรทัดอย่างชัดเจนระบุว่ามีการขึ้นบรรทัดใหม่ที่จุดเริ่มต้นของวัตถุ Box หรือไม่ ซึ่งทำให้ข้อความห่อหุ้มที่จุดเริ่มต้นของวัตถุ Box นี้บรรทัดต่อบรรทัด ระบุจำนวนของตัวดำเนินการในบรรทัดก่อนหน้าของข้อความคณิตศาสตร์ที่ใช้เป็นจุดจัดแนวสำหรับบรรทัดปัจจุบันของข้อความคณิตศาสตร์ ค่าที่เป็นไปได้: 1..255 ค่าเริ่มต้น: 0 (ไม่มีการแตกบรรทัดอย่างชัดเจน)

```cpp
void Aspose::Slides::MathText::MathBox::set_ExplicitBreak(uint8_t value) override
```

## หมายเหตุ


ตัวอย่าง: 
```cpp
auto box = System::MakeObject<MathematicalText>(u"==")->ToBox();
box->set_ExplicitBreak(1);
```
