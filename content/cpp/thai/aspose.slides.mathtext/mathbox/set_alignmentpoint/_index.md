## MathBox::set_AlignmentPoint(bool) เมธอด

เมื่อเป็น true, ตัวจำลองตัวดำเนินการนี้ทำหน้าที่เป็นจุดจัดแนว; กล่าวคือ จุดจัดแนวที่กำหนดในสมการอื่น ๆ สามารถจัดแนวกับมันได้ ค่าเริ่มต้น: false

```cpp
void Aspose::Slides::MathText::MathBox::set_AlignmentPoint(bool value) override
```
## หมายเหตุ

ตัวอย่าง: 
```cpp
auto box = System::MakeObject<MathematicalText>(u"==")->ToBox();
box->set_AlignmentPoint(true);
```
