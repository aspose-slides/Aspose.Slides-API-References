## MathBox::get_ExplicitBreak() เมธอด

การตัดบรรทัดโดยชัดเจนกำหนดว่ามีการตัดบรรทัดที่จุดเริ่มต้นของอ็อบเจกต์ Box หรือไม่ ซึ่งทำให้ข้อความห่อหุ้มที่จุดเริ่มต้นของอ็อบเจกต์ Box. กำหนดจำนวนของตัวดำเนินการในบรรทัดก่อนหน้าของข้อความคณิตศาสตร์ที่จะใช้เป็นจุดจัดแนวสำหรับบรรทัดปัจจุบันของข้อความคณิตศาสตร์ ค่าที่เป็นไปได้: 1..255 ค่าเริ่มต้น: 0 (ไม่มีการตัดบรรทัดโดยชัดเจน)

```cpp
uint8_t Aspose::Slides::MathText::MathBox::get_ExplicitBreak() override
```

## หมายเหตุ

ตัวอย่าง:
```cpp
auto box = System::MakeObject<MathematicalText>(u"==")->ToBox();
box->set_ExplicitBreak(1);
```
