## IMathPhantom::get_Transp() เมธอด


รับค่าที่บ่งบอกว่า phantom มีความโปร่งใสหรือไม่สำหรับกฎการเว้นระยะตามคลาส.

```cpp
virtual bool Aspose::Slides::MathText::IMathPhantom::get_Transp()=0
```

## หมายเหตุ


เมื่อ **true**, ตัวดำเนินการและสัญลักษณ์ภายใน phantom ยังส่งผลต่อการเว้นระยะทางคณิตศาสตร์รอบ phantom (เหมือนกับที่มองเห็น). เมื่อ **false**, การเว้นระยะตามคลาสจะถูกละเว้น. สอดคล้องกับแอตทริบิวต์ OMML **m:transp**.
