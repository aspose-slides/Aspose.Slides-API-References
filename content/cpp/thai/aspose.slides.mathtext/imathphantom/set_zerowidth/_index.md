## IMathPhantom::set_ZeroWidth(bool) เมธอด

ตั้งค่าที่บ่งชี้ว่าความกว้างขององค์ประกอบฐานควรถือว่าเป็นศูนย์หรือไม่.

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_ZeroWidth(bool value)=0
```

## หมายเหตุ

เมื่อ **true**, phantom ไม่จองพื้นที่แนวนอนสำหรับฐานของมัน. สอดคล้องกับแอตทริบิวต์ OMML **m:zeroWid**.
