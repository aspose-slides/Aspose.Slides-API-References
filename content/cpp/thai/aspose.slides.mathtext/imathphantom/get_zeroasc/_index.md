## IMathPhantom::get_ZeroAsc() เมธอด


รับค่าที่ระบุว่าการขึ้น (ความสูงเหนือเส้นฐาน) ขององค์ประกอบฐานควรถือว่าเป็นศูนย์หรือไม่.

```cpp
virtual bool Aspose::Slides::MathText::IMathPhantom::get_ZeroAsc()=0
```

## หมายเหตุ


เมื่อ **true** ตัว phantom จะไม่ยกเส้นฐานของบรรทัดคณิตศาสตร์โดยรอบ. สอดคล้องกับแอตทริบิวต์ OMML **m:zeroAsc**.
