```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_Show(bool value)=0
```

## หมายเหตุ

เมื่อ **false** องค์ประกอบฐานจะถูกซ่อนไว้แต่ยังอาจใช้พื้นที่อยู่ขึ้นอยู่กับการตั้งค่า phantom อื่น ๆ. สอดคล้องกับแอตทริบิวต์ OMML **m:show**.
