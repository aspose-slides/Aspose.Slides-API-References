## IMathPhantom::set_Transp(bool) เมธอด


กำหนดค่าที่บ่งชี้ว่า phantom เป็นแบบโปร่งใสสำหรับกฎการเว้นระยะแบบคลาสหรือไม่.

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_Transp(bool value)=0
```

## หมายเหตุ


เมื่อ **true**, ตัวดำเนินการและสัญลักษณ์ภายใน phantom จะยังคงมีผลต่อการเว้นระยะคณิตศาสตร์รอบ phantom (เสมือนว่าเป็นที่มองเห็น). เมื่อ **false**, การเว้นระยะแบบคลาสจะถูกละเว้น. สอดคล้องกับแอตทริบิวต์ OMML **m:transp**.
