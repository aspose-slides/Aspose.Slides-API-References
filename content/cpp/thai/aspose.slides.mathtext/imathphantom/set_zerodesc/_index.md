## IMathPhantom::set_ZeroDesc(bool) เมธอด

กำหนดค่าที่ระบุว่าการลงล่าง (ความลึกต่ำกว่ามาตรฐาน) ขององค์ประกอบฐานควรถือเป็นศูนย์หรือไม่。

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_ZeroDesc(bool value)=0
```

## หมายเหตุ

เมื่อ **true**, phantom ไม่ทำให้เส้นฐานของบรรทัดคณิตศาสตร์โดยรอบต่ำลง. สอดคล้องกับแอตทริบิวต์ OMML **m:zeroDesc**.
