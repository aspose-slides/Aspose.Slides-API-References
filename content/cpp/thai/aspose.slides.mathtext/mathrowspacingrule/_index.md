## MathRowSpacingRule enum

The type of vertical spacing between columns in a matrix or array

```cpp
enum class MathRowSpacingRule
```

### Values

| ชื่อ | ค่า | รายละเอียด |
| --- | --- | --- |
| SingleLineGap | 0 | ช่องว่างบรรทัดเดียว |
| OneAndAHalfLineGap | 1 | ช่องว่างบรรทัดหนึ่งและครึ่ง |
| TwoLineGap | 2 | ช่องว่างสองบรรทัด |
| Exactly | 3 | อย่างแม่นยำ (อ้างอิงค่าของคุณสมบัติ RowSpacing, วัดเป็นจุด) |
| Multiple | 4 | หลายค่า (อ้างอิงค่าของคุณสมบัติ RowSpacing, วัดเป็นบรรทัด) |
