## MathPhantom::set_ZeroAsc(bool) เมธอด


กำหนดค่าที่บ่งชี้ว่าการขึ้น (ความสูงเหนือเส้นฐาน) ขององค์ประกอบฐานควรถือเป็นศูนย์หรือไม่.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_ZeroAsc(bool value) override
```

## หมายเหตุ


เมื่อ **true**, phantom ไม่ยกเส้นฐานของบรรทัดคณิตศาสตร์รอบข้าง. สอดคล้องกับแอตทริบิวต์ OMML **m:zeroAsc**.
