## MathPhantom::set_Show(bool) เมธอด

กำหนดค่าที่บ่งบอกว่าตัวองค์ประกอบฐานจะแสดงหรือไม่.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_Show(bool value) override
```

## หมายเหตุ

เมื่อ **false**, ตัวองค์ประกอบฐานจะถูกซ่อนไว้แต่ยังอาจคงครอบครองพื้นที่อยู่ขึ้นอยู่กับการตั้งค่า phantom อื่น ๆ. สอดคล้องกับแอตทริบิวต์ OMML **m:show**.
