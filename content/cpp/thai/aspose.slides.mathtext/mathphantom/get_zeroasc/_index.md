## MathPhantom::get_ZeroAsc() เมธอด


รับค่าที่บ่งชี้ว่าการยกขึ้น (ความสูงเหนือเส้นฐาน) ขององค์ประกอบฐานควรถูกพิจารณาเป็นศูนย์หรือไม่.

```cpp
bool Aspose::Slides::MathText::MathPhantom::get_ZeroAsc() override
```

## หมายเหตุ


เมื่อ **true**, phantom จะไม่ยกเส้นฐานของบรรทัดคณิตศาสตร์รอบข้าง. ตรงกับแอตทริบิวต์ OMML **m:zeroAsc**.
