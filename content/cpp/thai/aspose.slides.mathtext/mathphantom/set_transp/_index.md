## MathPhantom::set_Transp(bool) เมธอด

กำหนดค่าที่บ่งบอกว่า phantom มีความโปร่งใสสำหรับกฎการเว้นระยะตามคลาสหรือไม่.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_Transp(bool value) override
```

## หมายเหตุ

เมื่อ **true** ตัวดำเนินการและสัญลักษณ์ภายใน phantom ยังคงส่งผลต่อการเว้นระยะทางคณิตศาสตร์รอบ phantom (เหมือนกับมองเห็นได้) เมื่อ **false** การเว้นระยะตามคลาสจะถูกละเลย สอดคล้องกับแอตทริบิวต์ OMML **m:transp**.
