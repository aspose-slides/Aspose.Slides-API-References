## IMathMatrix::get_RowGapRule() เมธอด

ประเภทของช่องว่างแนวตั้งระหว่างแถวของเมทริกซ์; หน่วยช่องว่างแนวตั้งสามารถเป็นบรรทัดหรือจุด (จัดเก็บเป็น twips) ได้ ค่าเริ่มต้น: SingleSpacingGap (0)

```cpp
virtual MathSpacingRules Aspose::Slides::MathText::IMathMatrix::get_RowGapRule()=0
```

## หมายเหตุ

ตัวอย่าง:
```cpp
auto matrix = System::MakeObject<MathMatrix>(2, 3);
matrix->set_RowGapRule(MathSpacingRules::OneAndHalfSpacingGap);
```
