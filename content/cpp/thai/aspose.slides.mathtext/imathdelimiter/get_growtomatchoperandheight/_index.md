## IMathDelimiter::get_GrowToMatchOperandHeight() เมธอด

ระบุการเติบโตของ BeginningCharacter, SeparatorCharacter, EndingCharacter เมื่อเป็น true, ตัวคั่นจะเติบโตในแนวตั้งเพื่อให้ตรงกับความสูงของ operand. ค่าเริ่มต้นคือ true

```cpp
virtual bool Aspose::Slides::MathText::IMathDelimiter::get_GrowToMatchOperandHeight()=0
```

## หมายเหตุ

ตัวอย่าง: 
```cpp
auto delimiter = System::MakeObject<MathematicalText>(u"x")->Divide(u"y")->Enclose();
delimiter->set_GrowToMatchOperandHeight(false);
```
