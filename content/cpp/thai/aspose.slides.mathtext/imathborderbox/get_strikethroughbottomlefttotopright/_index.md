## IMathBorderBox::get_StrikethroughBottomLeftToTopRight() เมธอด


Strikethrough Bottom-Left to Top-Right (ค่าเริ่มต้นคือ false). ระบุสถานะที่ซ่อนหรือแสดงของเส้นทแยงมุมแบบ strikethrough ตั้งแต่มุมซ้ายล่างถึงมุมขวาบนของ border box.

```cpp
virtual bool Aspose::Slides::MathText::IMathBorderBox::get_StrikethroughBottomLeftToTopRight()=0
```

## หมายเหตุ


ตัวอย่าง: 
```cpp
auto borderBox = System::MakeObject<MathematicalText>(u"x+y+z")->ToBorderBox();
borderBox->set_StrikethroughBottomLeftToTopRight(true);
```
