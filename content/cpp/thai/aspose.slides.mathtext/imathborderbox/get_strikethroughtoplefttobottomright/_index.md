## IMathBorderBox::get_StrikethroughTopLeftToBottomRight() เมธอด

ขีดทับจากมุมซ้ายบนไปมุมขวาล่าง (ค่าเริ่มต้นเป็น false) ระบุสถานะที่ซ่อนหรือแสดงของเส้นทแยงมุมที่ขีดทับจากมุมซ้ายบนไปมุมขวาล่างของกล่องขอบ.

```cpp
virtual bool Aspose::Slides::MathText::IMathBorderBox::get_StrikethroughTopLeftToBottomRight()=0
```

## หมายเหตุ

ตัวอย่าง: 
```cpp
auto borderBox = System::MakeObject<MathematicalText>(u"x+y+z")->ToBorderBox();
borderBox->set_StrikethroughTopLeftToBottomRight(true);
```
