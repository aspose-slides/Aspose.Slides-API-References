## InkEffectType enum

ระบุชุดของเอฟเฟกต์ภาพลักษณ์ที่กำหนดล่วงหน้าสำหรับการเรนเดอร์หมึก ทุกเอฟเฟกต์สอดคล้องกับพื้นผิวหรือภาพที่จำลองลักษณะหมึกสไตล์เฉพาะ ค่าเหล่านี้สามารถใช้เพื่อปรับแต่งสไตล์ภาพของเส้นหมึกดิจิทัลระหว่างการเรนเดอร์ตามต้องการ

```cpp
enum class InkEffectType
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| NotDefined | -1 | เอฟเฟกต์ไม่ได้กำหนดหรือไม่ทราบค่า สามารถใช้เป็นค่าเริ่มต้นหรือสำรองได้ |
| Bronze | 0 | พื้นผิวโลหะสีน้ำตาลอุ่นคล้ายหมึกบรอนซ์ |
| Galaxy | 1 | พื้นผิวสีสันส่องแสงคล้ายกาแล็กซี่ มีโทนสีจักรวาล |
| Gold | 2 | พื้นผิวทองโลหะสว่างที่ทำให้เส้นหมึกดูหรูหรา |
| Lava | 3 | พื้นผิวไฟลาวาที่เหมือนลาวาเย็น ลาวา มีเฉดสีแดงและส้ม |
| Ocean | 4 | พื้นผิวสีน้ำเงินเข้มไหลคล้ายคลื่นมหาสมุทรหรือหมึกแบบน้ำ |
| RainbowGritter | 5 | เอฟเฟกต์แสงระยิบระยับแบบรุ้งสีสันสดใส ใช้สำหรับเส้นหมึกที่มีอารมณ์ฉลองหรือสดใส |
| RoseGold | 6 | การผสมสีชมพู-ทองอ่อนคล้ายโรสโกลด์ สำหรับเส้นหมึกที่ดูหรูหรา |
| Silver | 7 | พื้นผิวสีเงินเย็นแบบโลหะที่จำลองหมึกสีเงินคลาสสิก |
