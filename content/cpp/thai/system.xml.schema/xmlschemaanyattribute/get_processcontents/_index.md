## XmlSchemaAnyAttribute::get_ProcessContents() เมธอด

ส่งคืนข้อมูลเกี่ยวกับวิธีที่แอปพลิเคชันหรือโปรเซสเซอร์ XML ควรจัดการการตรวจสอบความถูกต้องของเอกสาร XML สำหรับแอตทริบิวต์ที่ระบุโดยองค์ประกอบ **anyAttribute** element.

```cpp
XmlSchemaContentProcessing System::Xml::Schema::XmlSchemaAnyAttribute::get_ProcessContents()
```

### ค่าที่ส่งคืน

หนึ่งในค่า XmlSchemaContentProcessing. หากไม่ได้ระบุแอตทริบิวต์ **processContents** attribute, ค่าเริ่มต้นคือ **Strict**.
