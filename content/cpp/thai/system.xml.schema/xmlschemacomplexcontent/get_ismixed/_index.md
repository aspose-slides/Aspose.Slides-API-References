## XmlSchemaComplexContent::get_IsMixed() เมธอด

ส่งคืนข้อมูลที่กำหนดว่าประเภทมีโมเดลเนื้อหาผสมหรือไม่.

```cpp
bool System::Xml::Schema::XmlSchemaComplexContent::get_IsMixed()
```

### ค่าที่ส่งกลับ

หากค่านี้เป็น **true**, ข้อมูลอักขระจะได้รับอนุญาตให้ปรากฏระหว่างองค์ประกอบลูกของประเภทซับซ้อน (โมเดลเนื้อหาผสม) ค่าเริ่มต้นคือ **false**. ไม่บังคับ.
