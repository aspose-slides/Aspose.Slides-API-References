## XmlSchemaComplexType::get_IsMixed() เมธอด


ส่งคืนข้อมูลที่กำหนดว่าชนิดซับซ้อนมีรูปแบบเนื้อหาผสม (มาร์กอัปภายในเนื้อหา) หรือไม่.

```cpp
bool System::Xml::Schema::XmlSchemaComplexType::get_IsMixed() override
```


### ค่าที่ส่งกลับ

**true**, หากข้อมูลตัวอักษรสามารถปรากฏระหว่างองค์ประกอบลูกของชนิดซับซ้อนนี้; มิฉะนั้น **false**. ค่าเริ่มต้นคือ **false**. ไม่บังคับ.
