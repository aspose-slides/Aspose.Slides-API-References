## XmlSchemaComplexType::get_IsAbstract() เมธอด


คืนข้อมูลที่ระบุว่าองค์ประกอบ **complexType** สามารถใช้ในเอกสารอินสแตนซ์ได้หรือไม่.

```cpp
bool System::Xml::Schema::XmlSchemaComplexType::get_IsAbstract()
```


### ค่าที่ส่งกลับ

หาก **true**, องค์ประกอบไม่สามารถใช้ **complexType** นี้โดยตรงได้และต้องใช้ประเภทเชิงซ้อนที่สืบทอดจาก **complexType** นี้ ค่าเริ่มต้นคือ **false**. ไม่บังคับ.
