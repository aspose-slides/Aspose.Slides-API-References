## XmlSchemaMinExclusiveFacet คลาส

เป็นตัวแทนขององค์ประกอบ **minExclusive** จาก XML [Schema](../) ตามที่กำหนดโดย World Wide [Web](../../system.web/) Consortium (W3C). คลาสนี้สามารถใช้เพื่อกำหนดข้อจำกัดบนค่าต่ำสุดขององค์ประกอบ **simpleType**. ค่าขององค์ประกอบต้องมากกว่าค่าขององค์ประกอบ **minExclusive**.

```cpp
class XmlSchemaMinExclusiveFacet : public System::Xml::Schema::XmlSchemaFacet
```

## หมายเหตุ

อ็อบเจ็กต์ของคลาสนี้ควรจัดสรรเฉพาะโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/). อย่าสร้างอินสแตนซ์ของประเภทนี้บนสแต็กหรือโดยใช้ operator new เพราะจะทำให้เกิดข้อผิดพลาดรันไทม์และ/หรือการระบุข้อผิดพลาด. ควรห่อหุ้มคลาสนี้ด้วยพอยน์เตอร์ [System::SmartPtr](../../system/smartptr/) เสมอและใช้พอยน์เตอร์นี้ส่งเป็นอาร์กิวเมนต์ให้ฟังก์ชัน.
