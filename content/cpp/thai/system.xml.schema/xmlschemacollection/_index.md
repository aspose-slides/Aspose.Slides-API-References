## หมายเหตุ

ล้าสมัย
:   คลาส [XmlSchemaCollection](./) ไม่แนะนำให้ใช้. ใช้ [XmlSchemaSet](../xmlschemaset/) แทน.

วัตถุของคลาสนี้ควรจัดสรรเฉพาะโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/). ไม่ควรสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ตัวดำเนินการ new เพราะจะทำให้เกิดข้อผิดพลาดขณะรันไทม์และ/หรือข้อผิดพลาดการตรวจสอบ. ควรห่อคลาสนี้ด้วยพอยน์เตอร์ [System::SmartPtr](../../system/smartptr/) เสมอและใช้พอยน์เตอร์นี้เพื่อส่งผ่านเป็นอากูเมนต์ให้กับฟังก์ชันต่าง ๆ.
