## InferenceOption enum

ส่งผลต่อการปรากฏและข้อมูลประเภทที่สรุปโดยคลาส [XmlSchemaInference](../) สำหรับองค์ประกอบและแอตทริบิวต์ในเอกสาร XML.

```cpp
enum class InferenceOption
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Restricted | 0 | ระบุว่าควรสรุปการประกาศสคีมาที่เข้มงวดกว่า สำหรับองค์ประกอบหรือแอตทริบิวต์เฉพาะ |
| Relaxed | 1 | ระบุว่าควรสรุปการประกาศสคีมาที่ไม่เข้มงวดสำหรับองค์ประกอบหรือแอตทริบิวต์เฉพาะ |
