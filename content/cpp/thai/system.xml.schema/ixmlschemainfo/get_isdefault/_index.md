## IXmlSchemaInfo::get_IsDefault() เมธอด

ส่งคืนค่าที่บ่งบอกว่าโหนด XML ที่ตรวจสอบแล้วนี้ถูกตั้งค่าเป็นผลลัพธ์ของค่าเริ่มต้นที่นำมาใช้ระหว่างการตรวจสอบสคีม่า XML [Schema](../../) Definition Language (XSD) schema validation.

```cpp
virtual bool System::Xml::Schema::IXmlSchemaInfo::get_IsDefault()=0
```

### ค่าที่ส่งคืน

**true** หากโหนด XML ที่ตรวจสอบแล้วนี้ถูกตั้งค่าเป็นผลลัพธ์ของค่าเริ่มต้นที่นำมาใช้ระหว่างการตรวจสอบสคีม่า; มิฉะนั้น **false**.
