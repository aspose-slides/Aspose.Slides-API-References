## XmlSchema::get_ElementFormDefault() เมธอด


ส่งคืนรูปแบบสำหรับอีลิเมนต์ที่ประกาศในเนมสเปซเป้าหมายของสคีมา.

```cpp
XmlSchemaForm System::Xml::Schema::XmlSchema::get_ElementFormDefault()
```


### ค่าที่คืน

ค่าของ XmlSchemaForm ที่บ่งชี้ว่าอีลิเมนต์จากเนมสเปซเป้าหมายจำเป็นต้องมีคำนำหน้าของเนมสเปซหรือไม่ ค่าตั้งต้นคือ [XmlSchemaForm::None](../../xmlschemaform/).
