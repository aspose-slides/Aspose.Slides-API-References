## XmlSchema::get_AttributeFormDefault() เมธอด

คืนค่ารูปแบบสำหรับแอตทริบิวต์ที่ประกาศในเนมสเปซเป้าหมายของสคีม่า.

```cpp
XmlSchemaForm System::Xml::Schema::XmlSchema::get_AttributeFormDefault()
```

### ค่าที่คืน

ค่าชนิด XmlSchemaForm ที่ระบุว่าต้องทำให้แอตทริบิวต์จากเนมสเปซเป้าหมายมีคำนำหน้าเนมสเปซหรือไม่ ค่าเริ่มต้นคือ [XmlSchemaForm::None](../../xmlschemaform/).
