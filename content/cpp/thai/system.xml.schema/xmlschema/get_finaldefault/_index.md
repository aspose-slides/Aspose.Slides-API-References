## XmlSchema::get_FinalDefault() เมธอด


คืนค่าแอตทริบิวต์ **finalDefault** ซึ่งกำหนดค่าปริยายของแอตทริบิวต์ **final** บนองค์ประกอบและประเภทเชิงซ้อนในเนมสเปซเป้าหมายของสคีม่า.

```cpp
XmlSchemaDerivationMethod System::Xml::Schema::XmlSchema::get_FinalDefault()
```


### ค่าที่ส่งคืน

ค่าชนิด XmlSchemaDerivationMethod ที่แสดงถึงวิธีต่าง ๆ สำหรับป้องกันการสืบทอด ค่าเริ่มต้นคือ [XmlSchemaDerivationMethod::None](../../xmlschemaderivationmethod/).
