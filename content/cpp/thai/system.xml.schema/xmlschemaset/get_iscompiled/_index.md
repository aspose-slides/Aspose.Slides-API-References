## XmlSchemaSet::get_IsCompiled() เมธอด


ส่งค่ากลับที่ระบุว่าภาษาแบบกำหนด XML [Schema](../../) (XSD) schemas ใน [XmlSchemaSet](../) ถูกคอมไพล์หรือไม่.

```cpp
bool System::Xml::Schema::XmlSchemaSet::get_IsCompiled()
```


### ค่าที่ส่งคืน

**true** หาก schemas ใน [XmlSchemaSet](../) ถูกคอมไพล์ตั้งแต่ครั้งสุดท้ายที่ schema ถูกเพิ่มหรือเพิกถอนจาก [XmlSchemaSet](../); มิฉะนั้น **false**.
