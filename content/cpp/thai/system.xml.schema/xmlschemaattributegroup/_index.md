## XmlSchemaAttributeGroup คลาส


เป็นตัวแทนขององค์ประกอบ **attributeGroup** จาก XML [Schema](../) ตามที่ระบุโดย World Wide [Web](../../system.web/) Consortium (W3C). AttributesGroups ให้กลไกสำหรับการจัดกลุ่มชุดของการประกาศแอททริบิวต์เพื่อให้สามารถนำเข้าเป็นกลุ่มในการกำหนดประเภทเชิงซ้อนได้.

```cpp
class XmlSchemaAttributeGroup : public System::Xml::Schema::XmlSchemaAnnotated
```

## หมายเหตุ



วัตถุของคลาสนี้ควรสร้างโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น. อย่าสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ operator new เนื่องจากจะทำให้เกิดข้อผิดพลาดรันไทม์และ/หรือการยืนยันข้อผิดพลาด. ควรห่อคลาสนี้ด้วยพอยน์เตอร์ [System::SmartPtr](../../system/smartptr/) และใช้พอยน์เตอร์นี้เพื่อส่งผ่านเป็นอากิวเมนต์ให้กับฟังก์ชัน.
