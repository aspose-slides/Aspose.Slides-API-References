## XmlSchemaDerivationMethod enum

ให้วิธีการต่าง ๆ สำหรับป้องกันการสืบทอด.

```cpp
enum class XmlSchemaDerivationMethod
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Empty | 0 | แทนที่วิธีการสืบทอดค่าเริ่มต้นเพื่ออนุญาตให้มีการสืบทอดใด ๆ. |
| Substitution | 1 | อ้างอิงถึงการสืบทอดโดย **Substitution**. |
| Extension | 2 | อ้างอิงถึงการสืบทอดโดย **Extension**. |
| Restriction | 4 | อ้างอิงถึงการสืบทอดโดย **Restriction**. |
| List | 8 | อ้างอิงถึงการสืบทอดโดย **List**. |
| Union | 16 | อ้างอิงถึงการสืบทอดโดย **Union**. |
| All | 255 | **#all**. อ้างอิงถึงวิธีการสืบทอดทั้งหมด. |
| None | 256 | ยอมรับวิธีการสืบทอดค่าเริ่มต้น. |
