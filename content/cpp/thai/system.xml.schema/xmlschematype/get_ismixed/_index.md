## XmlSchemaType::get_IsMixed() เมธอด

```cpp
virtual bool System::Xml::Schema::XmlSchemaType::get_IsMixed()
```


### ค่าที่ส่งกลับ

**true** if the type has a mixed content model; otherwise, **false**. The default is **false**.
