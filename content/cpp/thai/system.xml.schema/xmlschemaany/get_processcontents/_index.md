## XmlSchemaAny::get_ProcessContents() เมธอด

ส่งคืนข้อมูลเกี่ยวกับวิธีที่แอปพลิเคชันหรือโปรเซสเซอร์ XML ควรจัดการการตรวจสอบความถูกต้องของเอกสาร XML สำหรับองค์ประกอบที่ระบุโดยองค์ประกอบ **any**.

```cpp
XmlSchemaContentProcessing System::Xml::Schema::XmlSchemaAny::get_ProcessContents()
```

### ค่าที่ส่งคืน

หนึ่งในค่าของ XmlSchemaContentProcessing. หากไม่มีแอตทริบิวต์ **processContents** ถูกระบุค่าเริ่มต้นคือ **Strict**.
