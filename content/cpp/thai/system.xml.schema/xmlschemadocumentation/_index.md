## XmlSchemaDocumentation คลาส

```cpp
class XmlSchemaDocumentation : public System::Xml::Schema::XmlSchemaObject
```

## หมายเหตุ

อ็อบเจ็กต์ของคลาสนี้ควรจัดสรรโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น. อย่าสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ operator new เนื่องจากจะทำให้เกิดข้อผิดพลาดเวลาเรียกใช้และ/หรือการประกันความถูกต้อง. ควรหุ้มหรือ wrapper คลาสนี้ด้วยพอยน์เตอร์ [System::SmartPtr](../../system/smartptr/) และใช้พอยน์เตอร์นี้เพื่อส่งเป็นอาร์กิวเมนต์ให้กับฟังก์ชัน.
