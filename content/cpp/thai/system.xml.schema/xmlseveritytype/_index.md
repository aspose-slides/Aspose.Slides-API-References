## XmlSeverityType enum

แสดงถึงระดับความรุนแรงของเหตุการณ์การตรวจสอบความถูกต้อง

```cpp
enum class XmlSeverityType
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| Error | 0 | ระบุว่ามีข้อผิดพลาดในการตรวจสอบเกิดขึ้นขณะตรวจสอบเอกสารอินสแตนซ์ ซึ่งใช้กับการกำหนดประเภทเอกสาร (DTDs) และ XML [Schema](../) definition language (XSD) schema. ข้อจำกัดความถูกต้องของ World Wide [Web](../../system.web/) Consortium (W3C) ถือเป็นข้อผิดพลาด หากไม่มีตัวจัดการเหตุการณ์การตรวจสอบถูกสร้างขึ้น ข้อผิดพลาดจะทำให้เกิดการโยนข้อยกเว้น |
| Warning | 1 | ระบุว่ามีเหตุการณ์การตรวจสอบเกิดขึ้นซึ่งไม่ใช่ข้อผิดพลาด คำเตือนมักจะออกเมื่อไม่มี DTD หรือ XML [Schema](../) เพื่อใช้ตรวจสอบองค์ประกอบหรือแอตทริบิวต์ใดๆ แตกต่างจากข้อผิดพลาด คำเตือนจะไม่ทำให้เกิดการโยนข้อยกเว้นหากไม่มีตัวจัดการเหตุการณ์การตรวจสอบ |
