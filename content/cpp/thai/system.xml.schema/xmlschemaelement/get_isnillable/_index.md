## XmlSchemaElement::get_IsNillable() เมธอด


ส่งคืนข้อมูลที่บ่งบอกว่า **xsi:nil** สามารถเกิดในข้อมูลอินสแตนซ์ได้หรือไม่. ระบุว่าค่าที่เป็น nil อย่างชัดเจนสามารถกำหนดให้กับองค์ประกอบได้หรือไม่.

```cpp
bool System::Xml::Schema::XmlSchemaElement::get_IsNillable()
```


### Return Value

หาก nillable เป็น **true** จะทำให้อินสแตนซ์ขององค์ประกอบมีแอตทริบิวต์ **nil** ถูกตั้งค่าเป็น **true**. แอตทริบิวต์ **nil** ถูกกำหนดเป็นส่วนหนึ่งของเนมสเปซ XML [Schema](../../) สำหรับอินสแตนซ์. ค่าเริ่มต้นคือ **false**. ไม่บังคับ.
