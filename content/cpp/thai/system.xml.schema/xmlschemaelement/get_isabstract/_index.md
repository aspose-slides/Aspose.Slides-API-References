## XmlSchemaElement::get_IsAbstract() เมธอด


ส่งคืนข้อมูลเพื่อระบุว่าองค์ประกอบนี้สามารถใช้ในเอกสารอินสแตนซ์ได้หรือไม่.

```cpp
bool System::Xml::Schema::XmlSchemaElement::get_IsAbstract()
```


### ค่าที่ส่งคืน

หาก **true**, องค์ประกอบไม่สามารถปรากฏในเอกสารอินสแตนซ์ได้ ค่าเริ่มต้นคือ **false**. ไม่บังคับ.
