## ProgressChangedEventArgs คลาส


อินสแตนซ์ของคลาสนี้จะถูกส่งเป็นอาร์กิวเมนต์ให้กับตัวมอบหมาย ProgressChangedEventHandler. วัตถุของคลาสนี้ควรสร้างด้วยฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น. ไม่ควรสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ตัวดำเนินการ new, เนื่องจากจะทำให้เกิดข้อผิดพลาดเวลาเรียกใช้และ/หรือการตรวจสอบความถูกต้อง. ควรห่อคลาสนี้ด้วยพอยน์เตอร์ [System::SmartPtr](../../system/smartptr/) และใช้พอยน์เตอร์นี้ในการส่งผ่านเป็นอาร์กิวเมนต์ให้กับฟังก์ชัน.

```cpp
class ProgressChangedEventArgs : public System::EventArgs
```
