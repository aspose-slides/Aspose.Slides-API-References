## ITypeDescriptorContext คลาส


อินเทอร์เฟซปลอมสำหรับโค้ดที่ใช้ ITypeDescriptorContext เพื่อคอมไพล์. วัตถุของคลาสนี้ควรได้รับการจัดสรรเฉพาะโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/). อย่าสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ operator new เนื่องจากจะทำให้เกิดข้อผิดพลาดเวลารันและ/หรือข้อผิดพลาดการอ้างอิง. ควรห่อคลาสนี้ไว้ในตัวชี้ [System::SmartPtr](../../system/smartptr/) และใช้ตัวชี้นี้ส่งให้ฟังก์ชันเป็นอาร์กิวเมนต์.

```cpp
class ITypeDescriptorContext : public virtual System::Object
```
