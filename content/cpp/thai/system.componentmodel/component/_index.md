## Component คลาส


คลาสตัวอย่างเพื่อทำให้โค้ดที่แปลโดยใช้ [Component](./) คลาสตสามารถคอมไพล์ได้. อ็อบเจ็กต์ของคลาสนี้ควรถูกจัดสรรเฉพาะโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/). ห้ามสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้โอเปอเรเตอร์ new เนื่องจากจะทำให้เกิดข้อผิดพลาดเวลารันและ/หรือการผิดพลาดการยืนยันค่า. หมั่นห่อคลาสนี้ด้วยพอยน์เตอร์ [System::SmartPtr](../../system/smartptr/) และใช้พอยน์เตอร์นี้เพื่อส่งผ่านเป็นอาร์กิวเมนต์ให้กับฟังก์ชัน.

```cpp
class Component : public System::MarshalByRefObject,
                  public System::ComponentModel::IComponent
```
