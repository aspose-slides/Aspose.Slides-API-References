## TypeDescriptor คลาส

คลาสจำลองสำหรับโค้ดที่ใช้ TypeDescriptor เพื่อให้คอมไพล์ได้หลังจากแปลภาษา. วัตถุของคลาสนี้ควรจะจัดสรรโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น. อย่าสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้ operator new เนื่องจากจะทำให้เกิดข้อผิดพลาดรันไทม์และ/หรือข้อบกพร่องจากการตรวจสอบ. ให้ห่อหุ้มคลาสนี้ด้วยตัวชี้ [System::SmartPtr](../../system/smartptr/) และใช้ตัวชี้นี้เพื่อส่งผ่านเป็นอากูเมนต์ให้กับฟังก์ชัน.

```cpp
class TypeDescriptor : public System::Object
```
