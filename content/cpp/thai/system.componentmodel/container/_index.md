## คลาสคอนเทนเนอร์


คลาสจำลองสำหรับโค้ดที่แปลโดยใช้คลาส [Container](./) เพื่อทำงาน ตัวอ็อบเจกต์ของคลาสนี้ควรจัดสรรโดยใช้ฟังก์ชัน [System::MakeObject()](../../system/makeobject/) เท่านั้น อย่าสร้างอินสแตนซ์ของประเภทนี้บนสแตกหรือโดยใช้โอเปอเรเตอร์ new เพราะจะทำให้เกิดข้อผิดพลาดรันไทม์และ/หรือข้อผิดพลาดการอัตนัย ให้วนคลาสนี้ด้วยพอยน์เตอร์ [System::SmartPtr](../../system/smartptr/) และใช้พอยน์เตอร์นี้ส่งเป็นอาร์กูเมนต์ให้ฟังก์ชัน

```cpp
class Container : public System::Object
```
