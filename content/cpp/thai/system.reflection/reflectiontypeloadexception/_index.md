## ReflectionTypeLoadException typedef

ReflectionTypeLoadException ถูกโยงโดยเมธอด Module.GetTypes หากคลาสใดในโมดูลไม่สามารถโหลดได้ ไม่ควรห่อหุ้มอินสแตนซ์ของคลาส ReflectionTypeLoadException เข้าไปใน [System::SmartPtr](../../system/smartptr/).

```cpp
using System::Reflection::ReflectionTypeLoadException = typedef System::ExceptionWrapper<Details_ReflectionTypeLoadException>
```
