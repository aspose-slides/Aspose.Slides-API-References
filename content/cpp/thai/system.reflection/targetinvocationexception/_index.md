## TargetInvocationException ประเภทนิยาม

TargetInvocationException ถูกขว้างออกโดยเมธอดที่เรียกผ่านการสะท้อน. อย่าใส่อินสแตนซ์ของคลาส TargetInvocationException ลงใน [System::SmartPtr](../../system/smartptr/).

```cpp
using System::Reflection::TargetInvocationException = typedef System::ExceptionWrapper<Details_TargetInvocationException>
```
