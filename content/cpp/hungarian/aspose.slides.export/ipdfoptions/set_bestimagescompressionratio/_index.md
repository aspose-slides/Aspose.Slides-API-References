## IPdfOptions::set_BestImagesCompressionRatio(bool) metódus

Jelzi, hogy minden képnél a legoptimálisabb tömörítést (az alapértelmezett helyett) automatikusan ki kell-e választani. Ha **bool**.true értékre van beállítva, a prezentáció minden képéhez a legmegfelelőbb tömörítési algoritmus lesz kiválasztva, ami a létrejövő PDF-dokumentum kisebb méretéhez vezet.

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_BestImagesCompressionRatio(bool value)=0
```

## Megjegyzések

A legjobb képtömörítési arány kiválasztása számításigényes és további RAM-ot igényel, ezért ez a beállítás alapértelmezés szerint **bool**.false.

Az alapértelmezett **bool**.false.
