## SvgExternalFontsHandling enumeráció

A szövegrajzoláshoz használt külső betűtípusok kezelésének módját reprezentálja.

```cpp
enum class SvgExternalFontsHandling
```

### Értékek

| Név | Érték | Leírás |
| --- | --- | --- |
| AddLinksToFontFiles | 0 | Hivatkozások hozzáadása a különálló betűtípusfájlokra az SVG fájl stílus szekciójához. |
| Embed | 1 | Betűtípusadatok közvetlen mentése az SVG fájlba. Kérjük, ellenőrizze az összes külső betűtípus licencszerződését, mielőtt ezt a beállítást használja. |
| Vectorize | 2 | Az összes, külső betűtípusokkal megjelenített szöveg mentése grafikaként. |
