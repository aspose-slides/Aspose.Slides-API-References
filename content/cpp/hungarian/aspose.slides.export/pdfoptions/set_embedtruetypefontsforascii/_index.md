## PdfOptions::set_EmbedTrueTypeFontsForASCII(bool) metódus


Meghatározza, hogy a [Aspose.Slides](../../../aspose.slides/) beágyazza-e a közös betűtípusokat az ASCII (33..127 kódtartomány) szöveghez. [Fonts](../../../aspose.slides/fonts/) a 127-nél nagyobb karakterkódokhoz mindig beágyazott. A közös betűtípusok listája tartalmazza a PDF alapértelmezett 14 betűtípusát és további felhasználó által megadott betűtípusokat. Írja **bool**.

```cpp
void Aspose::Slides::Export::PdfOptions::set_EmbedTrueTypeFontsForASCII(bool value) override
```

## Megjegyzések


Az alapértelmezett **true**.
