## SVGOptions::set_DisableLineEndCropping(bool) metódus

Az SVG 1.1 nem képes meghatározni a jelölők belső távolságait. [Aspose.Slides](../../../aspose.slides/) SVG írómotor megoldást nyújt erre a problémára: levágja a vonal végét a nyíllal, így a vonal nem fed rá a jelölőkre. Ez az opció kikapcsolja ezt a viselkedést. Írja **bool**.

```cpp
void Aspose::Slides::Export::SVGOptions::set_DisableLineEndCropping(bool value) override
```
