## PixelOffsetMode enum

Megadja, hogyan vannak eltolva a pixelek rendereléskor.

```cpp
enum class PixelOffsetMode
```

### Values

| Név | Érték | Leírás |
| --- | --- | --- |
| Invalid | n/a | Érvénytelen érték. |
| Default | n/a | Az alapértelmezett mód. |
| HighSpeed | n/a | Alacsony minőségű (magas teljesítményű) mód. |
| HighQuality | n/a | Nagy minőségű (alacsonyabb teljesítményű) mód. |
| None | n/a | Nincs pixel eltolás. |
| Half | n/a | A pixeleket -0.5 egységgel eltolják vízszintesen és függőlegesen a magas teljesítményű anti-aliasing érdekében. |
