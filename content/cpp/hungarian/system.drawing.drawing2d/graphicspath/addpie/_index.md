## GraphicsPath::AddPie(float, float, float, float, float, float) metódus

Hozzáadja a megadott pite alakzat körvonalát az aktuális objektum által képviselt úthoz.

```cpp
void System::Drawing::Drawing2D::GraphicsPath::AddPie(float x, float y, float width, float height, float startAngle, float sweepAngle)
```


### Argumentumok

| Parameter | Type | Description |
| --- | --- | --- |
| x | **float** | Az X koordináta a téglalap bal felső sarkának, amely körülveszi azt az ellipszist, amelyből a pite rajzolódik |
| y | **float** | Az Y koordináta a téglalap bal felső sarkának, amely körülveszi azt az ellipszist, amelyből a pite rajzolódik |
| width | **float** | A téglalap szélessége, amely körülveszi azt az ellipszist, amelyből a pite rajzolódik |
| height | **float** | A téglalap magassága, amely körülveszi azt az ellipszist, amelyből a pite rajzolódik |
| startAngle | **float** | A pite kezdő szöge fokban, az X tengelytől óramutató járásával megegyező irányban mérve |
| sweepAngle | **float** | A kezdő szög és a pite vége közötti szög |
