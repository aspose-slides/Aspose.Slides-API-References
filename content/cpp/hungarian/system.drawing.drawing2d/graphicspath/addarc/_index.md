## GraphicsPath::AddArc(float, float, float, float, float, float) metódus


Hozzáadja a megadott elliptikus ívet az aktuális objektum által képviselt útvonalhoz.

```cpp
void System::Drawing::Drawing2D::GraphicsPath::AddArc(float x, float y, float width, float height, float startAngle, float sweepAngle)
```


### Paraméterek

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| x | **float** | Az ívet meghatározó ellipszist körülvevő téglalap bal felső sarkának X koordinátája |
| y | **float** | Az ívet meghatározó ellipszist körülvevő téglalap bal felső sarkának Y koordinátája |
| width | **float** | Az ívet meghatározó ellipszist körülvevő téglalap szélessége |
| height | **float** | Az ívet meghatározó ellipszist körülvevő téglalap magassága |
| startAngle | **float** | Meghatározza az ív kezdő szögét fokban, az X-tengellyel óramutató járásával megegyező irányban mérve |
| sweepAngle | **float** | Meghatározza a kezdő és a végső szög közötti szöget |
