## LineJoin enumeráció

Megadja, hogyan csatlakoznak egymást követő vonalak vagy görbék.

```cpp
enum class LineJoin
```

### Értékek

| Name | Value | Description |
| --- | --- | --- |
| Miter | 0 | Miter csatlakozás, amely éles vagy levágott sarkot hoz létre attól függően, hogy a vágás hossza meghaladja-e a vágáskorlátot. |
| Bevel | 1 | Bevel csatlakozás, amely átlós sarkot hoz létre. |
| Round | 2 | Round csatlakozás, amely sima körívvel kapcsolja össze a vonalakat. |
| MiterClipped | 3 | Miter csatlakozás, amely éles vagy ferdén levágott sarkot hoz létre attól függően, hogy a vágás hossza meghaladja-e a vágáskorlátot. |
