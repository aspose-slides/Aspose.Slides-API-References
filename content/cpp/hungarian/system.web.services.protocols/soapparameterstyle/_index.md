## SoapParameterStyle enum

Felsorolja a paraméterformátumokat egy SOAP üzenetben.

```cpp
enum class SoapParameterStyle
```

### Értékek

| Név | Érték | Leírás |
| --- | --- | --- |
| Default | 0 | Ha a '[SoapDocumentServiceAttribute](../soapdocumentserviceattribute/)' nincs alkalmazva az osztályra, akkor az alapértelmezett érték a 'Wrapped'. |
| Bare | 1 | A paramétereket olyan XML elemekbe helyezik, amelyek a 'Body' elem után következnek. |
| Wrapped | 2 | A paraméterek egyetlen XML elemben vannak beágyazva, amely a 'Body' elem után következik. |
