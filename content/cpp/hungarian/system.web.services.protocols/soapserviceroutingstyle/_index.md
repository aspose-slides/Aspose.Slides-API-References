## SoapServiceRoutingStyle enumeráció


Felsorolja a lehetőségeket arra vonatkozóan, hogyan irányítódik a SOAP üzenet az XML [Web](../../system.web/) szolgáltatáshoz.

```cpp
enum class SoapServiceRoutingStyle
```

### Értékek

| Név | Érték | Leírás |
| --- | --- | --- |
| SoapAction | 0 | A SOAP üzenet a 'SOAPAction' attribútum alapján kerül irányításra. |
| RequestElement | 1 | A SOAP üzenet a 'Body' elem után található első gyermekelem alapján kerül irányításra. |
