## InvokeCompletedEventArgs osztály


Egy példánya ennek az osztálynak átadásra kerül argumentumként az InvokeCompletedEventHandler delegátának. Az osztály objektumait csak a [System::MakeObject()](../../system/makeobject/) függvénnyel szabad létrehozni. Soha ne hozzon létre példányt a stacken vagy az operator new használatával, mert ez futásidejű hibákhoz és/vagy állítási hibákhoz vezet. Mindig csomagolja be ezt az osztályt egy [System::SmartPtr](../../system/smartptr/) mutatóba, és használja ezt a mutatót az argumentumként történő átadáshez a függvényeknek.

```cpp
class InvokeCompletedEventArgs : public System::ComponentModel::AsyncCompletedEventArgs
```
