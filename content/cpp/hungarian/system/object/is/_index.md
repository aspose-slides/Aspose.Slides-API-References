## Object::Is(const TypeInfo\&) const metódus


Ellenőrzi, hogy az objektum a targetType által leírt típus példánya-e. A C# 'is' operátor analógja.

```cpp
virtual bool System::Object::Is(const TypeInfo &targetType) const
```


### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| targetType | const [TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struktúra, amely leírja a típust, amellyel a jelenlegi objektumot tesztelik. |

### Visszatérési érték

True, ha az objektum a címkézett típus vagy annak alosztálya, false egyébként.
