## Boolean::TryParse(const String\&, bool\&) metódus


Átalakítja a megadott karakterláncot bool típusú értékké.

```cpp
static bool System::Boolean::TryParse(const String &value, bool &result)
```


### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| value | const [String](../../string/)\& | A konvertálandó karakterlánc. |
| result | **bool**\& | A bool változóra mutató referencia, ahová a konverzió eredménye kerül; az eredmény igaz, ha a megadott karakterlánc egyenlő a "True" értékkel, és hamis, ha a megadott karakterlánc egyenlő a "False" értékkel. |

### Visszatérési érték

Igaz, ha a megadott karakterlánc egyenlő a "True" vagy a "False" értékkel, egyébként hamis.
