## Boolean::Parse(const String\&) metódus

Átalakítja a megadott karakterláncot egy bool típusú értékké.

```cpp
static bool System::Boolean::Parse(const String &value)
```

### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| value | const [String](../../string/)\& | A konvertálandó karakterlánc. |

### Visszatérési érték

A bool változó, amelybe a konverzió eredménye kerül; az eredmény true, ha a megadott karakterlánc egyenlő a \"True\" értékkel, és false, ha a megadott karakterlánc egyenlő a \"False\" értékkel.
