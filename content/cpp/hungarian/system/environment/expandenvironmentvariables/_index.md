## Environment::ExpandEnvironmentVariables(const String\&) metódus

Lecseréli a megadott karakterláncban található környezeti változók nevét a változók értékeire, és visszaadja a kapott karakterláncot.

```cpp
static String System::Environment::ExpandEnvironmentVariables(const String &name)
```

### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| name | const [String](../../string/)\& | A karakterlánc, amely a környezeti változók neveit tartalmazza |

### Visszatérési érték

A karakterlánc, amely a **name** változóneveinek helyettesítése után kapott értékekkel jön létre.
