## Environment::get_Version() metódus


Visszaadja a [Version](../../version/) objektumot, amely a közös nyelvi futtatókörnyezet verziójával kapcsolatos információkat képviseli. A metódus által visszaadott verziószám meglehetősen példaképző, és nem jelenti azt, hogy az összes könyvtári osztály a visszaadott verziónak megfelelően viselkedik.

```cpp
static Version System::Environment::get_Version()
```
