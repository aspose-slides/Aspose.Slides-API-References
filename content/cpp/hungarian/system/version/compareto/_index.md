## Version::CompareTo(const Version\&) const metódus

Összehasonlítja a jelenlegi objektum és a megadott objektum által képviselt verziókat.

```cpp
int System::Version::CompareTo(const Version &ver) const
```

### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| ver | const [Version](../)\& | A [Version](../) objektum, amellyel összehasonlítja az aktuális objektumot |

### Visszatérési érték

- 1, ha az aktuális objektum által képviselt verziószám kisebb, mint a **ver** által képviselt; 0, ha a verziószámok egyenlőek; 1, ha az aktuális objektum által képviselt verziószám nagyobb, mint a **ver** által képviselt érték
