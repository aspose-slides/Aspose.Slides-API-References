## Version::Equals(const Version\&) const metódus

Megállapítja, hogy a jelenlegi és a megadott objektumok által képviselt verziószámok egyenlőek-e.

```cpp
bool System::Version::Equals(const Version &ver) const
```

### Arguments

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| ver | const [Version](../)\& | Egy [Version](../) objektum, amellyel a jelenlegi objektumot összehasonlítják |

### Return Value

True, ha a verziószámok, amelyeket a jelenlegi objektum és a megadott objektum képvisel, egyenlőek, egyébként - false
