## System::IsTuple(const SharedPtr\<Object\>\&, int32_t) függvény

```cpp
bool System::IsTuple(const SharedPtr<Object> &object, int32_t length)
```

### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| object | const [SharedPtr](../sharedptr/)\<[Object](../object/)\>\& | ellenőrizendő objektum. |
| length | **int32_t** | várt tuple hossza |
