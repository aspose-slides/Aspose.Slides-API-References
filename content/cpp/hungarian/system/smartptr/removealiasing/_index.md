## SmartPtr::RemoveAliasing() const módszer


Eltávolítja az aliasolást (amelyet egy aliasolási konstruktor hoz létre) a mutatóból, és biztosítja, hogy ugyanazt az objektumot kezelje (ha megosztott) vagy kövesse (ha gyenge), amelyre mutat.

```cpp
SmartPtr_ System::SmartPtr<T>::RemoveAliasing() const
```


### Visszatérési érték

Az ugyanarra az objektumra mutató pointer, amely gondoskodik az ugyanazon objektum élettartamáról.
