## SmartPtr::get_shared_count() const metódus


A hivatkozott objektumra mutató meglévő megosztott mutatók számát adja vissza, beleértve a jelenlegit. Kijelenti, hogy a jelenlegi mutató megosztott módban van.

```cpp
int System::SmartPtr<T>::get_shared_count() const
```


### Visszatérési érték

A hivatkozott objektumra mutató meglévő megosztott mutatók száma, ha van. Ha a mutató null, 0-t ad vissza.
