## SmartPtr::static_pointer_cast() const metódus

Átkonvertálja a mutatót más típusra a static_cast segítségével a mutatott objektumon.

```cpp
template<class Y> SmartPtr<Y> System::SmartPtr<T>::static_pointer_cast() const
```

### Sablonparaméterek

| Paraméter | Leírás |
| --- | --- |
| Y | A mutatott objektum cél típusa. |

### Visszatérési érték

A módosított típusú mutató, amely mindig megosztott módban van.
