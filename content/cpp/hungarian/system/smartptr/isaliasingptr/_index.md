## SmartPtr::IsAliasingPtr() const metódus

Ellenőrzi, hogy a mutató egy másik, a tulajdonolt objektumtól eltérő objektumra mutat-e (egy aliasing konstruktor által létrehozott).

```cpp
bool System::SmartPtr<T>::IsAliasingPtr() const
```

### Visszatérési érték

True ha a mutatónak eltérése van a mutatott és a tulajdonolt objektumok között, false egyébként.
