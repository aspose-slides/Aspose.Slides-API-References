## TypeInfo::IsInstanceOfType(const SharedPtr\<Object\>\&) const metódus

Megállapítja, hogy a megadott objektum példány-e a jelenlegi típusnak.

```cpp
bool System::TypeInfo::IsInstanceOfType(const SharedPtr<Object> &obj) const
```

### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| obj | const [SharedPtr](../../sharedptr/)\<[Object](../../object/)\>\& | Az objektum, amelyet a jelenlegi típussal hasonlítunk össze |

### Visszatérési érték
