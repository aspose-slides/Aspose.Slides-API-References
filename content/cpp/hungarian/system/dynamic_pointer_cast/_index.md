## System::dynamic_pointer_cast(SmartPtr\<X\> const\&) függvény


Dinamikus_cast használatával átkonvertálja az okos mutatókat.

```cpp
template<class Y,class X> SmartPtr<Y> System::dynamic_pointer_cast(SmartPtr<X> const &x)
```


### Sablonparaméterek

| Paraméter | Leírás |
| --- | --- |
| X | Forrás mutató által mutatott típus. |
| Y | Cél mutató által mutatott típus. |

### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| x | [SmartPtr](../smartptr/)\<X\> const\& | Forrás mutató. |

### Visszatérési érték

Mutató a konvertálás után.
