## DateTime::operator!=(DateTime) const metódus

Megállapítja, hogy a jelenlegi objektum és a megadott [DateTime](../) objektum különböző dátum- és időértékeket képvisel-e.

```cpp
constexpr bool System::DateTime::operator!=(DateTime other) const
```

### Argumentumok

| Parameter | Type | Description |
| --- | --- | --- |
| other | [DateTime](../) | A [DateTime](../) objektum, amellyel a jelenlegi objektumot összehasonlítják |

### Visszatérési érték

True, ha a jelenlegi objektum és a megadott objektum különböző dátum- és időértékeket képvisel, egyébként - false
