## DateTime::AddMinutes(double) const metódus

Returns a new instance of the [DateTime](../) class representing the date and time value which is the sum of the value represented by the current object and the specified number of minutes.

```cpp
DateTime System::DateTime::AddMinutes(double value) const
```

### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| value | **double** | A hozzáadandó percek száma; az érték lehet pozitív vagy negatív |

### Visszatérési érték

Egy új [DateTime](../) osztálypéldány, amely a dátum és idő értéket képviseli, amely a jelenlegi objektum által képviselt érték és **value** perc összege
