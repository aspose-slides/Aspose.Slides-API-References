## DateTime::Compare(DateTime, DateTime) metódus


Összehasonlít két értéket, amelyeket a megadott [DateTime](../) osztály példányai képviselnek, és visszaadja azt az értéket, amely jelzi az értékek relatív helyzetét az idővonalon.

```cpp
static constexpr int System::DateTime::Compare(DateTime t1, DateTime t2)
```


### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| t1 | [DateTime](../) | Az első összehasonlítandó |
| t2 | [DateTime](../) | A második összehasonlítandó |

### Visszatérési érték

Egy olyan érték, amely kisebb, mint 0, ha **t1** korábbi, mint **t2**; 0, ha **t1** megegyezik **t2**-vel; egy olyan érték, amely nagyobb, mint 0, ha **t1** későbbi, mint **t2**.
