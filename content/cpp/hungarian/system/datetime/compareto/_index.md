## DateTime::CompareTo(DateTime) const metódus


Összehasonlít két dátum- és időértéket, amelyeket az aktuális objektum és a [DateTime](../) osztály megadott példánya reprezentál, és visszaad egy értéket, amely jelzi az értékek relatív helyzetét az idővonalon.

```cpp
constexpr int System::DateTime::CompareTo(DateTime value) const
```


### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| value | [DateTime](../) | A [DateTime](../) osztály egy példánya, amellyel összehasonlítja az aktuális objektumot |

### Visszatérési érték

Egy érték, amely kisebb, mint 0, ha az aktuális objektum egy korábbi értéket képvisel, mint amelyet a **value** képvisel; 0, ha a két objektum által képviselt értékek megegyeznek; egy érték, amely nagyobb, mint 0, ha az aktuális objektum által képviselt érték későbbi, mint amelyet a **value** képvisel.
