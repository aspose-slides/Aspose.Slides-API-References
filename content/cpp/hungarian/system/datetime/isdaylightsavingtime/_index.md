## DateTime::IsDaylightSavingTime() const metódus

Meghatározza, hogy a jelenlegi objektum által képviselt dátum- és időérték beleesik-e a nyári időszámítás időszakába az aktuális időzónában.

```cpp
bool System::DateTime::IsDaylightSavingTime() const
```

### Visszatérési érték

True ha a jelenlegi objektum által megadott dátum- és időérték beleesik a nyári időszámítás időszakába, különben - false
