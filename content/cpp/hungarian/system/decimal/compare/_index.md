## Decimal::Compare(const Decimal\&, const Decimal\&) metódus

Megállapítja, hogy az első [Decimal](../) objektum által képviselt érték kisebb-e, egyenlő vagy nagyobb-e a második [Decimal](../) objektum által képviselt értéknél.

```cpp
static int System::Decimal::Compare(const Decimal &d1, const Decimal &d2)
```

### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| d1 | const [Decimal](../)\& | Az első összehasonlítandó |
| d2 | const [Decimal](../)\& | A második összehasonlítandó |

### Visszatérési érték

- 1, ha a **d1** által képviselt érték kisebb, mint a **d2** által képviselt érték; 0, ha az értékek egyenlőek; 1, ha a **d1** által képviselt érték nagyobb a **d2** által képviselt értéknél
