## Decimal::CompareTo(const Decimal\&) const metódus


Megállapítja, hogy a jelenlegi objektum által képviselt érték kisebb-e, egyenlő, vagy nagyobb, mint a megadott objektum által képviselt érték.

```cpp
int System::Decimal::CompareTo(const Decimal &d) const
```


### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| d | const [Decimal](../)\& | Az összehasonlítandó |

### Visszatérési érték

- 1, ha a jelenlegi objektum által képviselt érték kisebb, mint a **d** által képviselt érték; 0, ha az értékek egyenlőek; 1, ha a jelenlegi objektum által képviselt érték nagyobb, mint a **d** által képviselt érték
