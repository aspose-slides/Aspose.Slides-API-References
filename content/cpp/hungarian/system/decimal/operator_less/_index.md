## Decimal::operator<(const Decimal\&) const metódus

Megállapítja, hogy az aktuális objektum által reprezentált érték kisebb-e, mint a megadott objektum által reprezentált érték.

```cpp
bool System::Decimal::operator<(const Decimal &d) const
```

### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| d | const [Decimal](../)\& | A [Decimal](../) objektum, amellyel az aktuális objektumot összehasonlítjuk |

### Visszatérési érték

True ha a jelenlegi objektum által reprezentált érték kisebb, mint a **d** által reprezentált érték, különben - false
