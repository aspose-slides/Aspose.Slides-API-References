## SmartPtrMode enum


[SmartPtr](../smartptr/) pointer típus: weak vagy shared. Meghatározza, hogy a pointer számlálásra kerül-e, amikor eldől, hogy törölni kell-e az objektumot vagy sem.

```cpp
enum class SmartPtrMode : char
```

### Értékek

| Név | Érték | Leírás |
| --- | --- | --- |
| Shared | 0 | Shared mód: a pointer részt vesz a hivatkozásszámlálásban. |
| Weak | 1 | Weak mód: a pointer nem vesz részt a hivatkozásszámlálásban. |
