## Array::crend() const metódus

Visszatér egy fordított iterátorral az utolsó elem után következő elemre a fordított tárolóban. Ez megfelel a nem fordított tároló első eleme előtt álló elemnek. Ez az elem helyőrzőként funkcionál, és a hozzáférés megkísérlése definiálatlan viselkedéshez vezet.

```cpp
const_reverse_iterator System::Array<T>::crend() const noexcept
```

### Visszatérési érték

Egy iterátor, amely a tároló első elemét megelőző elméleti const-kvalifikált elemre mutat.
