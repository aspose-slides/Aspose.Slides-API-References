## Array::cbegin() const metódus


Visszaad egy iterátort a tároló első const-kvalifikált eleméhez. Ha a tároló üres, a visszaadott iterátor egyenlő lesz a [cend()](../cend/).

```cpp
const_iterator System::Array<T>::cbegin() const noexcept
```


### Visszatérési érték

Egy iterátor, amely a tároló első const-kvalifikált elemére mutat.
