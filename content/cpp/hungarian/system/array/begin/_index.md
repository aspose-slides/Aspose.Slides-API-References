## Array::begin() metódus


Visszaad egy iterátort a tároló első elemére. Ha a tároló üres, a visszaadott iterátor egyenlő lesz a [end()](../end/).

```cpp
iterator System::Array<T>::begin() noexcept
```


### Visszatérési érték

Egy iterátor, amely a tároló első elemére mutat.

## Array::begin() const metódus


Visszaad egy iterátort a const-kvalifikált tároló első elemére. Ha a tároló üres, a visszaadott iterátor egyenlő lesz a [end()](../end/).

```cpp
const_iterator System::Array<T>::begin() const noexcept
```


### Visszatérési érték

Egy iterátor, amely a const-kvalifikált tároló első elemére mutat.
