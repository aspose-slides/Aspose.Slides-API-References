## Array::crbegin() const metódus

Visszaad egy fordított iterátort a megfordított tároló első eleméhez. Ez a nem megfordított tároló utolsó elemének felel meg. Ha a tároló üres, a visszaadott iterátor egyenlő [crend()](../crend/).

```cpp
const_reverse_iterator System::Array<T>::crbegin() const noexcept
```

### Visszatérési érték

Egy iterátor, amely a tároló utolsó const-kvantifikált elemére mutat.
