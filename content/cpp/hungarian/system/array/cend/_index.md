## Array::cend() const metódus


Visszaad egy iterátort az utolsó elem után következő elemre a tárolóban. Ez az elem helyőrzőként működik; megpróbálni elérni azt határozatlan viselkedéshez vezet.

```cpp
const_iterator System::Array<T>::cend() const noexcept
```


### Visszatérési érték

Egy iterátor, amely az elméleti const-kvalifikált elemre mutat, amely az utolsó elem után helyezkedik el a tárolóban.
