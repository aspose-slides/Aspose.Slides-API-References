## Char::IsNumber(const char_t *, int) metódus

Megállapítja, hogy a megadott karakterpufferben a megadott indexnél lévő karakter számnak minősül-e.

```cpp
static bool System::Char::IsNumber(const char_t *str, int idx)
```

### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| str | const char_t * | A karakterpuffer elejére mutató mutató |
| idx | int | A tesztelendő karakterhez tartozó nullától kezdődő index a megadott pufferben |

### Visszatérési érték

Igaz, ha a megadott indexnél lévő karakter szám, egyébként - hamis
