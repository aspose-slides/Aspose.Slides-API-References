## Char::IsLowSurrogate(const char_t *, int) metódus

Meghatározza, hogy a megadott karakterpufferben a megadott indexnél lévő karakter alacsony szurogat-e.

```cpp
static bool System::Char::IsLowSurrogate(const char_t *str, int idx)
```

### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| str | const char_t * | Mutató a karakterpuffer elejére |
| idx | int | Nulla-alapú index a megadott pufferben a tesztelendő karakterhez |

### Visszatérési érték

Igaz, ha a megadott indexnél lévő karakter alacsony szurogat, egyébként - hamis
