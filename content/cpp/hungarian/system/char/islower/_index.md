```cpp
static bool System::Char::IsLower(const char_t *str, int idx)
```


### Argumentumok

| Parameter | Type | Description |
| --- | --- | --- |
| str | const char_t * | Mutató a karakterpuffer elejére |
| idx | int | Nulláral kezdődő index a megadott pufferben a tesztelendő karakterhez |

### Visszatérési érték
