## Char::IsSeparator(const char_t *, int) metódus


Megállapítja, hogy a megadott karakterpufferben a megadott indexnél lévő karakter el van-e osztályozva elválasztó karakterként.

```cpp
static bool System::Char::IsSeparator(const char_t *str, int idx)
```


### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| str | const char_t * | Pointer to the beginning of the character buffer |
| idx | int | A zero-based index in the specified buffer of the character to test |

### Visszatérési érték

True, ha a megadott indexnél lévő karakter elválasztó karakter, egyébként - false

## Char::IsSeparator(char_t) metódus


Megállapítja, hogy a megadott karakter el van-e osztályozva elválasztó karakterként.

```cpp
static bool System::Char::IsSeparator(char_t c)
```


### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| c | char_t | The character to test |

### Visszatérési érték

True, ha a megadott karakter elválasztó karakter, egyébként - false
