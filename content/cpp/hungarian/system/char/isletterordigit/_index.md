## Char::IsLetterOrDigit(const char_t *, int) metódus

Megállapítja, hogy a megadott karakterpufferben a megadott indexnél lévő karakter Unicode betűként vagy decimális számjegyként van-e osztályozva.

```cpp
static bool System::Char::IsLetterOrDigit(const char_t *str, int idx)
```

### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| str | const char_t * | Mutató a karakterpuffer elejére |
| idx | int | Nulla-alapú index a megadott pufferben a tesztelendő karakterhez |

### Visszatérési érték

Igaz, ha a megadott indexnél lévő karakter Unicode betű vagy decimális számjegy, egyébként - hamis
