## Char::IsSymbol(const char_t *, int) metódus


Megállapítja, hogy a megadott karakterpufferben a megadott indexnél lévő karakter szimbólumként van-e osztályozva.

```cpp
static bool System::Char::IsSymbol(const char_t *str, int idx)
```


### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| str | const char_t * | Pointer to the beginning of the character buffer |
| idx | int | A zero-based index in the specified buffer of the character to test |

### Visszatérési érték

True, ha a megadott indexnél lévő karakter szimbólum, egyébként - false

## Char::IsSymbol(char_t) metódus


Megállapítja, hogy a megadott karakter szimbólumként van-e osztályozva.

```cpp
static bool System::Char::IsSymbol(char_t c)
```


### Argumentumok

| Paraméter | Típus | Leírás |

| c | char_t | A tesztelendő karakter |

### Visszatérési érték

True, ha a megadott karakter szimbólum, egyébként - false
