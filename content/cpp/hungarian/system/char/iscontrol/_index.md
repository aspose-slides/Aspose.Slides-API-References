## Char::IsControl(const char_t *, int) metódus


Megállapítja, hogy a megadott karakterpufferben a megadott indexen lévő karakter Unicode vezérlőkarakternek minősül-e.

```cpp
static bool System::Char::IsControl(const char_t *str, int idx)
```


### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| str | const char_t * | Mutató a karakterpuffer elejére |
| idx | int | A nullától induló index a megadott pufferben a tesztelendő karakterhez |

### Visszatérési érték

True, ha a megadott indexen lévő karakter Unicode vezérlőkarakter, egyébként - false
