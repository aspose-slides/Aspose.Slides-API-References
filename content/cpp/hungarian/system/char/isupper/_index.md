## Char::IsUpper(const String\&, int) method

Meghatározza, hogy a megadott indexen lévő karakter a megadott stringben nagybetűnek minősül-e.

```cpp
static bool System::Char::IsUpper(const String &str, int idx)
```

### Argumentumok

| Parameter | Type | Description |
| --- | --- | --- |
| str | const [String](../../string/)\& | A karaktert tartalmazó string. |
| idx | int | A megadott stringben tesztelni kívánt nulla alapú index. |

### Visszatérési érték

True, ha a megadott indexen lévő karakter nagybetű, egyébként – false
