## Char::IsWhiteSpace(const char_t *, int) metódus

Megállapítja, hogy a megadott indexen lévő karakter a megadott karakterpufferben fehér szóköz karakternek minősül-e.

```cpp
static bool System::Char::IsWhiteSpace(const char_t *str, int idx)
```

### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| str | const char_t * | Mutató a karakterpuffer elejére |
| idx | int | A vizsgálandó karakterhez tartozó, a megadott pufferben lévő nulla-alapú index |

### Visszatérési érték

Igaz, ha a megadott indexen lévő karakter fehér szóköz karakter, egyébként - hamis
