## String::rend() const metódus

Visszaad egy fordított iterátort az első karakter előtti (ha van) pozícióra a tényleges karakterlánc pufferben.

```cpp
reverse_iterator System::String::rend() const
```

### Visszatérési érték

Fordított iterátor az első karaktert megelőző elemre a tényleges karakterlánc pufferben (ha létezik), vagy az allokált puffer előtti elemre.
