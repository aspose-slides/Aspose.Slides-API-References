## String::IsNull() const metódus

Ellenőrzi, hogy a karakterlánc nullaként van-e tekintve. [String](../) null, ha és csak ha [String()](../string/) konstruktorral lett létrehozva, áthelyezve, másolva vagy null karakterláncból hozzárendelve, vagy ha a [reset()](../reset/) metódust meghívták.

```cpp
bool System::String::IsNull() const
```

### Visszatérési érték

true, ha a karakterlánc nullaként van tekintve, false egyébként.
