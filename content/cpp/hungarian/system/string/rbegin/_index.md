## String::rbegin() const metódus

Visszaad egy fordított iterátort az aktuális karakterlánc buffer utolsó karakteréhez (ha van).

```cpp
reverse_iterator System::String::rbegin() const
```

### Visszatérési érték

Fordított iterátor az aktuális karakterlánc buffer utolsó karakteréhez (ha van), vagy ugyanaz, mint a [rend()](../rend/).
