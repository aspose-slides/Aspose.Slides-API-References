## String::begin() const módszer


Visszaad egy mutatót a tényleges karakterlánc-puffer elejére. Soha nem újraosztja a memóriát. Nem garantálja, hogy a puffer nullával van befejezve.

```cpp
const UChar * System::String::begin() const
```


### Visszatérési érték

Mutató a tényleges karakterlánc-pufferre, legyen az nullával befejezett vagy sem.
