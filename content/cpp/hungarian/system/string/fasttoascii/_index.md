## String::FastToAscii(char, int) const metódus

Megpróbálja átalakítani a [String](../)-t egy ASCII karakterlánccá.

```cpp
int System::String::FastToAscii(char buffer[], int buffer_size) const
```

### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| buffer | char | A buffer az eredményül kapott karakterlánc tárolására. |
| buffer_size | int | [Buffer](../../buffer/) mérete. |

### Visszatérési érték

Az eredményül kapott karakterlánc hossza, vagy -1, ha a [String](../) nem ASCII karakterlánc.
