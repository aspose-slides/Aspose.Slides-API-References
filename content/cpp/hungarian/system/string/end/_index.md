## String::end() const metódus

Visszaadja a mutatót a tényleges karakterlánc-puffer végére. Soha nem újraallokál semmit. Nem garantálja, hogy a puffer nullával lezárva van.

```cpp
const UChar * System::String::end() const
```

### Visszatérési érték

Mutató az első elemre a tényleges karakterlánc-puffer után, nullával lezárva vagy anélkül.
