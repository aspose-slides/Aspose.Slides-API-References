## Részletek_OverflowException::Is(const System::TypeInfo\&) const metódus




```cpp
bool System::Details_OverflowException::Is(const System::TypeInfo &target) const override
```


### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struktúra, amely leírja a típust, amellyel a jelenlegi objektumot teszteljük. |

### Visszatérési érték

True, ha az objektum a megcímkézett típusú vagy annak alosztálya, false egyébként.

## Megjegyzések

Ellenőrizze, hogy az objektum a targetType által leírt típus példánya-e. A C# 'is' operátor analógja.
