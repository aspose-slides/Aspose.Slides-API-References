## System::operator/(const T\&, const Decimal\&) függvény

Visszaad egy új [Decimal](../decimal/) osztálypéldányt, amely egy olyan értéket képvisel, amely a megadott érték és a megadott [Decimal](../decimal/) objektum által képviselt érték osztásának eredménye.

```cpp
template<typename T,typename _> Decimal System::operator/(const T &x, const Decimal &d)
```

### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| x | const T\& | A felosztandó érték |
| d | const [Decimal](../decimal/)\& | A [Decimal](../decimal/) objektum, amely az osztót képviseli |

### Visszatérési érték

Egy új [Decimal](../decimal/) osztálypéldányt, amely egy olyan értéket képvisel, amely **x** osztásának eredménye a **d** által képviselt értékkel.
