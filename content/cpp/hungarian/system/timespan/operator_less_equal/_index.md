## TimeSpan::operator<=(TimeSpan) const metódus

Megállapítja, hogy a jelenlegi objektum által képviselt időintervallum rövidebb vagy egyenlő-e a megadott objektum által képviselt időintervallummal.

```cpp
constexpr bool System::TimeSpan::operator<=(TimeSpan value) const
```

### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| value | [TimeSpan](../) | Az [TimeSpan](../) objektum, amelyhez a jelenlegi objektumot hasonlítják |

### Visszatérési érték

True, ha a jelenlegi objektum által képviselt időintervallum rövidebb vagy egyenlő a **value** által képviselt időintervallummal, egyébként - false
