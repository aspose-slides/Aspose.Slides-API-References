## TimeSpan::operator>=(TimeSpan) const metódus

Megállapítja, hogy a jelenlegi objektum által képviselt időintervallum hosszabb-e vagy egyenlő a megadott objektum által képviselt időintervallummal.

```cpp
constexpr bool System::TimeSpan::operator>=(TimeSpan value) const
```

### Arguments

| Parameter | Type | Description |
| --- | --- | --- |
| value | [TimeSpan](../) | A [TimeSpan](../) objektum, amellyel a jelenlegi objektumot összehasonlítják |

### Return Value

True ha a jelenlegi objektum által képviselt időintervallum hosszabb vagy egyenlő a **value** által képviselt időintervallummal, egyébként - false
