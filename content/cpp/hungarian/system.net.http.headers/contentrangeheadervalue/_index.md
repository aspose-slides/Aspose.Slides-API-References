## ContentRangeHeaderValue osztály

A 'Content-Range' fejléc értékét reprezentálja. Ennek az osztálynak a példányait csak a [System::MakeObject()](../../system/makeobject/) függvény használatával szabad allokálni. Soha ne hozzon létre példányt a stack-en vagy az new operátorral, mert ez futási hibákat és/vagy állítási hibákat eredményez. Mindig csomagolja be ezt az osztályt egy [System::SmartPtr](../../system/smartptr/) mutatóba, és ezt a mutatót használja argumentumként a függvényeknek.

```cpp
class ContentRangeHeaderValue : public System::ICloneable
```
