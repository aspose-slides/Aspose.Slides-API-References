## XmlWriterSettings::get_NewLineChars() metódus

Visszaadja a sortörésekhez használandó karakterláncot.

```cpp
String System::Xml::XmlWriterSettings::get_NewLineChars()
```

### Visszatérési érték

A sortörésekhez használandó karakterlánc. Ez bármelyik karakterlánc értékre beállítható. Azonban a megfelelő XML biztosítása érdekében csak érvényes szóközkaraktereket szabad megadni, például szóközöket, tabulátorokat, kocsivisszákat vagy sortöréseket. Alapértelmezés szerint **\r\n** (kocsivissza, új sor).
