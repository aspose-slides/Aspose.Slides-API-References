## XmlWriterSettings::get_CheckCharacters() metódus

Visszaad egy értéket, amely jelzi, hogy az XML író ellenőrizze-e, hogy a dokumentum összes karaktere megfelel-e a W3C [XML 1.0 Recommendation](https://www.w3.org/TR/REC-xml/#charsets) \"2.2 Characters\" szakaszának.

```cpp
bool System::Xml::XmlWriterSettings::get_CheckCharacters()
```

### Visszatérési érték

**true** a karakterellenőrzéshez; egyébként **false**. Az alapértelmezett érték **true**.
