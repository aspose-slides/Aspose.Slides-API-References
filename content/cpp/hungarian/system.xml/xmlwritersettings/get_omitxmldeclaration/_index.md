## XmlWriterSettings::get_OmitXmlDeclaration() metódus

Visszaad egy értéket, amely jelzi, hogy ki kell-e hagyni az XML deklarációt.

```cpp
bool System::Xml::XmlWriterSettings::get_OmitXmlDeclaration()
```

### Visszatérési érték

**true** a XML deklaráció kihagyásához; egyébként **false**. Alapértelmezés szerint **false**, egy XML deklaráció íródik.
