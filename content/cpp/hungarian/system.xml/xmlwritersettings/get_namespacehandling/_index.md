## XmlWriterSettings::get_NamespaceHandling() metódus


Egy értéket ad vissza, amely jelzi, hogy a [XmlWriter](../../xmlwriter/) el kell-e távolítania a duplikált névtérdeklarációkat XML tartalom írásakor. Az alapértelmezett viselkedés az, hogy az író minden névtérdeklarációt kiír, amely a író névtere feloldójában jelen van.

```cpp
System::Xml::NamespaceHandling System::Xml::XmlWriterSettings::get_NamespaceHandling()
```


### Visszatérési érték

A NamespaceHandling felsorolás, amelyet a [XmlWriter](../../xmlwriter/) duplikált névtérdeklarációk eltávolításának meghatározására használnak.
