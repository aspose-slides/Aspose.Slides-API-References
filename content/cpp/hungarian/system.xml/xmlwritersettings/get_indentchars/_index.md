## XmlWriterSettings::get_IndentChars() metódus

Visszaadja a behúzáshoz használandó karakterláncot. Ez a beállítás akkor kerül alkalmazásra, amikor a [XmlWriterSettings::set_Indent](../set_indent/) érték **true**-ra van állítva.

```cpp
String System::Xml::XmlWriterSettings::get_IndentChars()
```

### Visszatérési érték

A behúzáshoz használandó karakterlánc. Bármilyen karakterlánc értékre beállítható. Azonban a valid XML biztosítása érdekében csak érvényes üres karaktereket kell megadni, például szóköz karaktereket, tabulátorokat, kocsivisszéseket vagy sortöréseket. Alapértelmezés szerint két szóköz.
