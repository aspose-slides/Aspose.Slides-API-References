## XmlNamespaceScope enum

Meghatározza a névtér hatókörét.

```cpp
enum class XmlNamespaceScope
```

### Értékek

| Név | Érték | Leírás |
| --- | --- | --- |
| All | 0 | Az aktuális csomópont hatókörében definiált összes névtér. Ez tartalmazza az xmlns:xml névteret, amely mindig implicit módon van deklarálva. A visszaadott névterek sorrendje nincs meghatározva. |
| ExcludeXml | 1 | Az aktuális csomópont hatókörében definiált összes névtér, az xmlns:xml névtér kivételével, amely mindig implicit módon van deklarálva. A visszaadott névterek sorrendje nincs meghatározva. |
| Local | 2 | Az aktuális csomópontnál helyileg definiált összes névtér. |
