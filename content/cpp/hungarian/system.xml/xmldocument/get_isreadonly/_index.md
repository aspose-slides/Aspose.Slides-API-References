## XmlDocument::get_IsReadOnly() metódus

Visszaad egy értéket, amely jelzi, hogy az aktuális csomópont csak olvasható-e.

```cpp
bool System::Xml::XmlDocument::get_IsReadOnly() override
```

### Visszatérési érték

**true** ha az aktuális csomópont csak olvasható; egyébként **false**. [XmlDocument](../) csomópontok mindig **false**-t adnak vissza.
