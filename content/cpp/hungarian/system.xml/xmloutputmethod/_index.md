## XmlOutputMethod enum

Megadja a [XmlWriter](../xmlwriter/) kimenet sorosításához használt módszert.

```cpp
enum class XmlOutputMethod
```

### Értékek

| Név | Érték | Leírás |
| --- | --- | --- |
| Xml | 0 | Sorosítás az XML 1.0 szabályai szerint. |
| Html | 1 | Sorosítás az XSLT által meghatározott HTML szabályok szerint. |
| Text | 2 | Csak szövegblokkokat sorosít. |
| AutoDetect | 3 | Az XSLT szabályok használata a [XmlOutputMethod::Xml](./) és [XmlOutputMethod::Html](./) kimeneti módszerek közti választáshoz futásidőben. |
