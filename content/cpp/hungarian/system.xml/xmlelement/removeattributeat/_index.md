## XmlElement::RemoveAttributeAt(int32_t) metódus


Eltávolítja a megadott indexű attribútumcsomópontot az elemről. (Ha az eltávolított attribútumnak alapértelmezett értéke van, az azonnal helyettesítésre kerül).

```cpp
virtual SharedPtr<XmlNode> System::Xml::XmlElement::RemoveAttributeAt(int32_t i)
```


### Arguments

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| i | **int32_t** | A törlendő csomópont indexe. Az első csomópont indexe 0. |

### Return Value

A eltávolított attribútumcsomópont, vagy **nullptr**, ha a megadott indexen nincs csomópont.
