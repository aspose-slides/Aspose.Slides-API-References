## XmlConvert::ToString(DateTimeOffset, const String\&) metódus


Átalakítja a megadott [DateTimeOffset](../../../system/datetimeoffset/)-t egy [String](../../../system/string/)-ra a megadott formátumban.

```cpp
static String System::Xml::XmlConvert::ToString(DateTimeOffset value, const String &format)
```


### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| value | [DateTimeOffset](../../../system/datetimeoffset/) | A [DateTimeOffset](../../../system/datetimeoffset/) amelyet konvertálunk. |
| format | const [String](../../../system/string/)\& | A formátum, amelyre **s** konvertálódik. A formátum paraméter a W3C XML dateTime típusra vonatkozó ajánlás bármely részhalmaza lehet. További információért lásd a [dateTime](https://www.w3.org/TR/xmlschema-2/#dateTime) szakaszt az XML [Schema](../../../system.xml.schema/) specifikációban. |

### Visszatérési érték

Egy [String](../../../system/string/) ábrázolás a megadott formátumban a szállított [DateTimeOffset](../../../system/datetimeoffset/)-ról.
