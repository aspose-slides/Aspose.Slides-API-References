## XmlConvert::VerifyXmlChars(const String\&) módszer


Visszaadja a beadott karakterláncot, ha a karakterlánc argumentumban szereplő összes karakter és helyettesítő pár karakter érvényes XML karakter, egyébként egy XmlException dobódik, amely információkat tartalmaz az első található érvénytelen karakterről.

```cpp
static String System::Xml::XmlConvert::VerifyXmlChars(const String &content)
```


### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| content | const [String](../../../system/string/)\& | [String](../../../system/string/) amely a verifikálandó karaktereket tartalmaz. |

### Visszatérési érték

A beadott karakterlánc, ha a karakterlánc argumentumban szereplő összes karakter és helyettesítő pár karakter érvényes XML karakter, egyébként egy XmlException dobódik, amely információkat tartalmaz az első található érvénytelen karakterről.
