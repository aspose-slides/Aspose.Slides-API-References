## XmlConvert::VerifyNCName(const String\&) metódus


Ellenőrzi, hogy a név érvényes **NCName**-e a W3C Extended Markup Language ajánlása szerint. Az **NCName** egy olyan név, amely nem tartalmazhat kettőspontot.

```cpp
static String System::Xml::XmlConvert::VerifyNCName(const String &name)
```


### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| name | const [String](../../../system/string/)\& | A verifierendő név. |

### Visszatérési érték

A név, ha az érvényes NCName.
