```cpp
static bool System::Xml::XmlConvert::IsXmlSurrogatePair(char16_t lowChar, char16_t highChar)
```

### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| lowChar | char16_t | A validálandó szurrogát karakter. |
| highChar | char16_t | A validálandó szurrogát karakter. |
