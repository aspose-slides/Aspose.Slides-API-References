## XmlNodeOrder enum

Leírja egy csomópont dokumentumsorrendjét egy másik csomóponthoz képest.

```cpp
enum class XmlNodeOrder
```

### Értékek

| Név | Érték | Leírás |
| --- | --- | --- |
| Before | 0 | Az aktuális navigátor jelenlegi csomópontja a megadott navigátor jelenlegi csomópontja előtt van. |
| After | 1 | Az aktuális navigátor jelenlegi csomópontja a megadott navigátor jelenlegi csomópontja után van. |
| Same | 2 | A két navigátor ugyanarra a csomópontra mutat. |
| Unknown | 3 | A csomópontok pozíciója nem határozható meg a dokumentum sorrendjében egymáshoz képest. Ez akkor fordulhat elő, ha a két csomópont különböző fákban van. |
