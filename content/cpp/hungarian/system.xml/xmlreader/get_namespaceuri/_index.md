## XmlReader::get_NamespaceURI() metódus


Amikor egy leszármaztatott osztályban felülírják, visszaadja a névtér URI-ját (ahogyan azt a W3C névtér specifikáció definiálja) azon csomópontnál, ahol az olvasó megtalálható.

```cpp
virtual String System::Xml::XmlReader::get_NamespaceURI()=0
```


### Visszatérési érték

Az aktuális csomópont névtér-URI-ja; egyébként egy üres karakterlánc.
