## XmlReader::ReadString() metódus


Ha egy származtatott osztályban felül van írva, beolvassa egy elem vagy szövegcsomópont tartalmát karakterláncként. Azonban ajánlott a [XmlReader::ReadElementContentAsString](../readelementcontentasstring/) metódust használni helyette, mivel ez egy egyszerűbb módot biztosít a művelet kezelésére.

```cpp
virtual String System::Xml::XmlReader::ReadString()
```


### Visszatérési érték

Az elem tartalma vagy egy üres karakterlánc.
