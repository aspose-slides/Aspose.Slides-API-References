## NamespaceHandling enum

Megadja, hogy a duplikált névtérdeklarációkat el kell-e távolítani a [XmlWriter](../xmlwriter/)-ban.

```cpp
enum class NamespaceHandling
```

### Értékek

| Név | Érték | Leírás |
| --- | --- | --- |
| Default | 0 | Megadja, hogy a duplikált névtérdeklarációk nem lesznek eltávolítva. |
| OmitDuplicates | 1 | Megadja, hogy a duplikált névtérdeklarációk el lesznek távolítva. Ahhoz, hogy a duplikált névtér el legyen távolítva, a prefixnek és a névtérnek egyeznie kell. |
