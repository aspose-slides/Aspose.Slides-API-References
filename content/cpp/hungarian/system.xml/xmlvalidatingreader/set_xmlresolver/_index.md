## XmlValidatingReader::set_XmlResolver(const SharedPtr\<System::Xml::XmlResolver\>\&) metódus

Beállítja a [XmlResolver](../../xmlresolver/)-t, amelyet a külső dokumentumtípus-definíció (DTD) és sémahely-referencia feloldására használnak. A [XmlResolver](../../xmlresolver/) is használható a XML [Schema](../../../system.xml.schema/) definíciós nyelv (XSD) sémákban található import vagy include elemek kezelésére.
