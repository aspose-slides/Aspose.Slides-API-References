## XmlValidatingReader::LookupNamespace(const String\&) metódus


Feloldja a névtér előtagot az aktuális elem hatókörében.

```cpp
String System::Xml::XmlValidatingReader::LookupNamespace(const String &prefix) override
```


### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| prefix | const [String](../../../system/string/)\& | Az előtag, amelynek névtér Uniform Resource Identifier (URI) értékét szeretné feloldani. Az alapértelmezett névtérhez való illeszkedéshez adjon meg egy üres karakterláncot. |

### Visszatérési érték

A névtér URI, amelyhez az előtag tartozik, vagy **nullptr**, ha nincs megfelelő előtag.
