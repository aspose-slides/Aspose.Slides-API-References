## XmlAttribute::get_Specified() metódus


Visszaad egy értéket, amely jelzi, hogy az attribútum értéke kifejezetten meg lett-e adva.

```cpp
virtual bool System::Xml::XmlAttribute::get_Specified()
```


### Visszatérési érték

**true** ha ez az attribútum kifejezetten értéket kapott az eredeti példány dokumentumban; egyébként **false**. A **false** érték azt jelzi, hogy az attribútum értéke a DTD-ből származik.
