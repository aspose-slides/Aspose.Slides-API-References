## XmlTextReader::get_IsEmptyElement() metódus


Visszaad egy értéket, amely jelzi, hogy az aktuális csomópont egy üres elem-e (például **<MyElement/>**).

```cpp
bool System::Xml::XmlTextReader::get_IsEmptyElement() override
```


### Visszatérési érték

**true** ha az aktuális csomópont egy elem ([XmlTextReader::get_NodeType](../get_nodetype/) érték egyenlő [XmlNodeType::Element](../../xmlnodetype/)), amely **/>**-vel végződik; egyébként **false**.
