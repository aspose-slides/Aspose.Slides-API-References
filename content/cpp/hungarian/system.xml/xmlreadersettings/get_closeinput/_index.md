## XmlReaderSettings::get_CloseInput() method


A visszatérési érték azt jelzi, hogy az alapul szolgáló stream vagy TextReader le kell-e zárni, amikor az olvasó le van zárva.

```cpp
bool System::Xml::XmlReaderSettings::get_CloseInput()
```


### Visszatérési érték

**true**, ha az alapul szolgáló stream vagy TextReader le kell zárni, amikor az olvasó le van zárva; egyébként **false**. Az alapértelmezett érték **false**.
