## XmlReaderSettings::get_ProhibitDtd() metódus


Visszaad egy értéket, amely azt jelzi, hogy tiltani kell-e a dokumentumtípus-definíció (DTD) feldolgozását.

```cpp
bool System::Xml::XmlReaderSettings::get_ProhibitDtd()
```


### Visszatérési érték

**true** a DTD feldolgozás tiltásához; egyébként **false**. Az alapértelmezett **true**.
