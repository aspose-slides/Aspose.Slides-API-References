## HttpContent osztály


Az HTTP entitás tartalmát képviseli. Ennek az osztálynak a [Object](../../system/object/) csak a [System::MakeObject()](../../system/makeobject/) függvénnyel allokálható. Soha ne hozzon létre példányt ebből a típusból a veremben vagy az new operátor segítségével, mert ez futásidejű hibákhoz és/vagy állítási hibákhoz vezet. Mindig csomagolja be ezt az osztályt egy [System::SmartPtr](../../system/smartptr/) mutatóba, és használja ezt a mutatót az argumentumként való átadásra a függvényeknek.

```cpp
class HttpContent : public System::IDisposable
```
