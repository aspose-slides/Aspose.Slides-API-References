## Details_HttpRequestException osztály

Használja helyette a HttpRequestException osztályt. Soha ne csomagolja a HttpRequestException osztály példányait [System::SmartPtr](../../system/smartptr/)-be.

```cpp
class Details_HttpRequestException : public System::Details_Exception
```
