## CultureTypes enum

Culture categories bitmask entries.

```cpp
enum class CultureTypes : int32_t
```

### Values

| Név | Érték | Leírás |
| --- | --- | --- |
| NeutralCultures | 1 | Nyelvre specifikus kultúra, de országra vagy régióra nem vonatkozik. |
| SpecificCultures | 2 | Országra/régióra specifikus. |
| InstalledWin32Cultures | 4 | Az operációs rendszerben telepített kultúrák. |
| AllCultures | n/a | Minden elérhető kultúra. |
| UserCustomCulture | 8 | Felhasználó által meghatározott kultúrák. |
| ReplacementCultures | 16 | Felhasználó által meghatározott helyettesítők a meglévő kultúrákhoz. |
| WindowsOnlyCultures | 32 | Elavult. |
| FrameworkCultures | 64 | Elavult. |
