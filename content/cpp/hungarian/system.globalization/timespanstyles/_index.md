## TimeSpanStyles enum

Meghatározza a formázási beállításokat, amelyek testreszabják a karakterlánc elemzését azokhoz a metódusokhoz, amelyek egy időintervallum szöveges ábrázolását Timespan objektummá konvertálják.

```cpp
enum class TimeSpanStyles : int32_t
```

### Értékek

| Név | Érték | Leírás |
| --- | --- | --- |
| None | 0 | Az inptut karakterlánc által képviselt időintervallum negatív időintervallumként értelmeződik csak akkor, ha negatív előjel található. |
| AssumeNegative | 1 | Az inptut karakterlánc által képviselt időintervallum mindig negatív időintervallumként értelmeződik. |
