## CompareOptions enum

[String](../../system/string/) összehasonlítási beállítások.

```cpp
enum class CompareOptions : int32_t
```

### Értékek

| Név | Érték | Leírás |
| --- | --- | --- |
| None | 0 | Nincsenek speciális beállítások. |
| IgnoreCase | 1 | Kis- és nagybetű figyelmen kívül hagyása. |
| IgnoreNonSpace | 2 | A nem térközös kombináló karakterek figyelmen kívül hagyása, pl. diakritikus jelek. |
| IgnoreSymbols | 4 | Fehér helyek, írásjelek stb. figyelembevétele. |
| IgnoreKanaType | 8 | A kana típus figyelmen kívül hagyása (japán). |
| IgnoreWidth | 16 | A karakter szélesség figyelmen kívül hagyása karakterláncok összehasonlításakor. |
| OrdinalIgnoreCase | 268435456 | Sorrend szerinti összehasonlítás kis- és nagybetű különbség figyelmen kívül hagyásával. |
| StringSort | 536870912 | Karakterek összehasonlításához string-rendezési algoritmus használata. |
| Ordinal | 1073741824 | Az első összehasonlítás során a UTF-kódok közvetlen összehasonlítása. |
