## StringCollection::cbegin() const metódus

Visszaad egy iterátort a tároló első const-kvalifikált elemére. Ha a tároló üres, a visszaadott iterátor egyenlő lesz [cend()](../cend/)-val.

```cpp
const_iterator System::Collections::Specialized::StringCollection::cbegin() const noexcept
```

### Visszatérési érték

Egy iterátor, amely a tároló első const-kvalifikált elemére mutat.
