## StringCollection::crend() const metódus

Visszaad egy fordított iterátort az az elemre, amely a fordított tároló utolsó elemét követi. Ez megfelel annak az elemnek, amely a nem fordított tároló első elemét megelőzi. Ez az elem egy helykitöltőként működik; megpróbálni elérni meghatározatlan viselkedést eredményez.

```cpp
const_reverse_iterator System::Collections::Specialized::StringCollection::crend() const noexcept
```

### Visszatérési érték

Egy iterátor, amely a tároló első elemét megelőző elméleti const-kvalifikált elemre mutat.
