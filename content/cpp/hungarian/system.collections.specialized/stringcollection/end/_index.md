## StringCollection::end() metódus


Visszaad egy iterátort az utolsó elem után következő elemre a tárolóban. Ez az elem helykitöltőként funkcionál; megpróbálni elérni azt meghatározatlan viselkedést eredményez.

```cpp
iterator System::Collections::Specialized::StringCollection::end() noexcept
```


### Visszatérési érték

Egy iterátor, amely az utolsó elem után elméletileg elhelyezkedő elemre mutat a tárolóban.

const_iterator System::Collections::Specialized::StringCollection::end() const noexcept
