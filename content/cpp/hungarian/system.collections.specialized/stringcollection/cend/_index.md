## StringCollection::cend() const metódus

Visszaad egy iterátort a tároló utolsó elemét követő elemre. Ez az elem helyőrzőként működik; megpróbálja elérni, akkor meghatározatlan viselkedés lép fel.

```cpp
const_iterator System::Collections::Specialized::StringCollection::cend() const noexcept
```

### Visszatérési érték

Egy iterátor, amely az elméleti const-kvalifikált elemre mutat, amely a tároló utolsó eleme után helyezkedik el.
