## BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType) módszer


Megadja, hogy az AsCell, AsCells, AsLiteralString vagy AsLiteralDouble tulajdonság valódi-e az leszármazottakban. Más szóval meghatározza a Data tulajdonság értékének típusát. Írja be [Charts::DataSourceType](../../datasourcetype/).

```cpp
void Aspose::Slides::Charts::BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType value) override
```

## Megjegyzések


A [ChartDataPointCollection](../../chartdatapointcollection/) pontok esetében ez a tulajdonság csak olvasható. Ebben az esetben a tulajdonság értékének megváltoztatásához használhatja a ChartDataPointCollection.DataSourceTypeFor<...> tulajdonságok egyikét.
