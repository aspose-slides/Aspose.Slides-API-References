## DataLabelFormat::set_ShowLegendKey(bool) metódus

Egy adott diagram adatcímke-jelmagyarázat kulcs megjelenítési viselkedését reprezentálja. Igaz, ha az adatcímke-jelmagyarázat kulcs látható. Írja **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLegendKey(bool value) override
```

## Megjegyzések

Ha ennek a [DataLabelFormat](../) objektumnak a szülője egy [DataLabelCollection](../../datalabelcollection/) adatcímke-gyűjtemény, akkor ez a tulajdonság lekéri vagy beállítja a ShowLegendKey tulajdonság alapértelmezett értékét az új adatcímkékre a [DataLabelCollection](../../datalabelcollection/) gyűjteményben. Ennek a tulajdonságnak az értékével történő beállítás továbbá ezt az értéket beállítja a ShowLegendKey tulajdonságra az összes adatcímkére a [DataLabelCollection](../../datalabelcollection/) gyűjteményben (azaz "DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;" okozza, hogy minden DataLabels[i].ShowLegendKey egyenlő legyen a val értékkel).
