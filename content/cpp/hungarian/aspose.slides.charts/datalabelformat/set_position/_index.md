## DataLabelFormat::set_Position(LegendDataLabelPosition) metódus

A címke pozícióját jelöli. Írja [LegendDataLabelPosition](../../legenddatalabelposition/).

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_Position(LegendDataLabelPosition value) override
```

## Megjegyzések

Ha ennek a [DataLabelFormat](../) objektumnak a szülője egy [DataLabelCollection](../../datalabelcollection/) adatcímke-gyűjtemény, akkor ez a tulajdonság beállítja vagy lekéri az új adatcímkék Position tulajdonságának alapértelmezett értékét a [DataLabelCollection](../../datalabelcollection/) gyűjteményben. A [DataLabel](../../datalabel/) objektumok pozícióját jelöli. Ennek a tulajdonságnak az értékével való beállítás a Position tulajdonság értékét is beállítja az összes adatcímke esetén a [DataLabelCollection](../../datalabelcollection/) gyűjteményben (pl. "DataLabels.DefaultDataLabelFormat.Position = val;" ami miatt minden DataLabels[i].Position egyenlő lesz a val értékkel).
