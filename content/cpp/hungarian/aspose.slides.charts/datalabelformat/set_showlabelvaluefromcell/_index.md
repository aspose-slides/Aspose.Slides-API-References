## DataLabelFormat::set_ShowLabelValueFromCell(bool) metódus

Egy megadott diagram adatcímkéjének cellaérték megjelenítési viselkedését reprezentálja. A true megjeleníti a cellaértéket. A false elrejti. Írja **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLabelValueFromCell(bool value) override
```

## Megjegyzések

Ha ennek a [DataLabelFormat](../) objektumnak a szülője egy [DataLabelCollection](../../datalabelcollection/) adatcímke-gyűjtemény, akkor ez a tulajdonság lekérdezi vagy beállítja a ShowLabelValueFromCell tulajdonság alapértelmezett értékét az új adatcímkékhez a [DataLabelCollection](../../datalabelcollection/) gyűjteményben. Ennek a tulajdonságnak az értékkel történő beállítása ugyancsak beállítja ezt az értéket a ShowLabelValueFromCell tulajdonságra a [DataLabelCollection](../../datalabelcollection/) gyűjtemény összes adatcímkéjében (azaz "DataLabels.DefaultDataLabelFormat.ShowLabelValueFromCell = val;" miatt minden DataLabels[i].ShowLabelValueFromCell egyenlő lesz val értékkel).
