## DataLabelFormat::set_ShowCategoryName(bool) metódus

Képviseli egy megadott diagram adatcímkéjének kategórianév megjelenítési viselkedését. True megjeleníti a kategórianév a diagram adatcímkéin. False elrejti. Írja **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowCategoryName(bool value) override
```

## Megjegyzések

Ha ennek a [DataLabelFormat](../) objektumnak a szülője egy [DataLabelCollection](../../datalabelcollection/) adatcímke-gyűjtemény, akkor ez a tulajdonság a [DataLabelCollection](../../datalabelcollection/) gyűjteményben lévő új adatcímkék ShowCategoryName tulajdonságának alapértelmezett értékét adja vissza vagy állítja be. Ennek a tulajdonságnak az értékkel való beállítása ugyanakkor ezt az értéket a [DataLabelCollection](../../datalabelcollection/) gyűjtemény összes adatcímkéjének ShowCategoryName tulajdonságára is alkalmazza (az "DataLabels.DefaultDataLabelFormat.ShowCategoryName = val;" miatt minden DataLabels[i].ShowCategoryName egyenlő lesz a val értékkel).
