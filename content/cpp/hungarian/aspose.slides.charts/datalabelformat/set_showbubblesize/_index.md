## DataLabelFormat::set_ShowBubbleSize(bool) metódus

Egy meghatározott diagram adatcímke buborékméret érték megjelenítési viselkedését reprezentálja. A True megjeleníti a buborékméret értéket. A False elrejti. Írja **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowBubbleSize(bool value) override
```

## Megjegyzések

Ha ennek a [DataLabelFormat](../) objektumnak a szülője egy [DataLabelCollection](../../datalabelcollection/) adatcímke-gyűjtemény, akkor ez a tulajdonság lekéri vagy beállítja a ShowBubbleSize tulajdonság alapértelmezett értékét az új adatcímkék számára a [DataLabelCollection](../../datalabelcollection/) gyűjteményben. Ezzel a tulajdonsággal megadott érték beállítja ezt az értéket a ShowBubbleSize tulajdonságra a [DataLabelCollection](../../datalabelcollection/) gyűjtemény összes adatcímkéjére (azaz "DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;" eredményezi, hogy minden DataLabels[i].ShowBubbleSize egyenlő lesz a val értékkel).
