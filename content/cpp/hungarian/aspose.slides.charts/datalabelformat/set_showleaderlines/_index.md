## DataLabelFormat::set_ShowLeaderLines(bool) metódus

Egy adott diagram adatcímke vezetővonalainak megjelenítési viselkedését reprezentálja. A true megjeleníti a vezetővonalakat. A false elrejti őket. Írja **bool** típusú értékkel.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLeaderLines(bool value) override
```

## Megjegyzések

Ha ennek a [DataLabelFormat](../) objektumnak a szülője egy [DataLabelCollection](../../datalabelcollection/) adatcímke-gyűjtemény, akkor ez a tulajdonság lekéri vagy beállítja a ShowLeaderLines tulajdonság alapértelmezett értékét az új adatcímkék számára a [DataLabelCollection](../../datalabelcollection/) gyűjteményben. Ennek a tulajdonságnak az értékkel való beállítása ugyanakkor beállítja ezt az értéket a ShowLeaderLines tulajdonságra az összes adatcímkénél a [DataLabelCollection](../../datalabelcollection/) gyűjteményben (pl. „DataLabels.DefaultDataLabelFormat.ShowLeaderLines = val;” okozza, hogy minden DataLabels[i].ShowLeaderLines egyenlő legyen a val értékkel).
