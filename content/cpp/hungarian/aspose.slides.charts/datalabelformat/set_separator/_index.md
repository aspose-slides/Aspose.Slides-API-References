## DataLabelFormat::set_Separator(System::String) metódus

Beállítja vagy visszaadja a diagram adatcímkéinél használt elválasztót képviselő Variant-et. Írja [System::String](../../../system/string/).

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_Separator(System::String value) override
```

## Megjegyzések

Ha ennek a [DataLabelFormat](../) objektumnak a szülője egy [DataLabelCollection](../../datalabelcollection/) adatcímke-gyűjtemény, akkor ez a tulajdonság a [DataLabelCollection](../../datalabelcollection/) gyűjteményben lévő új adatcímkék Separator tulajdonságának alapértelmezett értékét adja vissza vagy állítja be. Ennek a tulajdonságnak az értékkel történő beállítása szintén ezt az értéket a [DataLabelCollection](../../datalabelcollection/) gyűjteményben lévő összes adatcímke Separator tulajdonságára állítja (azaz "DataLabels.DefaultDataLabelFormat.Separator = val;" okozza, hogy minden DataLabels[i].Separator egyenlő legyen a val-val).
