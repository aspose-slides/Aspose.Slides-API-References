## DataLabelFormat::set_ShowPercentage(bool) metódus


Egy meghatározott diagram adatcímke százalékérték megjelenítési viselkedését reprezentálja. A True megjeleníti a százalékértéket. A False elrejti. Írja a **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowPercentage(bool value) override
```

## Megjegyzések


Ha ennek a [DataLabelFormat](../) objektumnak a szülője egy [DataLabelCollection](../../datalabelcollection/) adatcímke-gyűjtemény, akkor ez a tulajdonság a [DataLabelCollection](../../datalabelcollection/) gyűjteményben lévő új adatcímkék ShowPercentage tulajdonságának alapértelmezett értékét adja vissza vagy állítja be. Ennek a tulajdonságnak az értékkel való beállítása szintén beállítja ezt az értéket a [DataLabelCollection](../../datalabelcollection/) gyűjteményben lévő összes adatcímke ShowPercentage tulajdonságára (azaz "DataLabels.DefaultDataLabelFormat.ShowPercentage = val;" okozza, hogy minden DataLabels[i].ShowPercentage egyenlő legyen a val értékkel).
