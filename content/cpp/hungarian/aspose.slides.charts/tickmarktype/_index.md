## TickMarkType enum

A megadott tengelyhez tartozó jelölővonal típusát reprezentálja.

```cpp
enum class TickMarkType
```

### Értékek

| Név | Érték | Leírás |
| --- | --- | --- |
| Cross | 0 | Megadja, hogy a jelölővonalak áthaladnak a tengelyen. |
| Inside | 1 | Megadja, hogy a jelölővonalak a diagram területén belül helyezkednek el. |
| None | 2 | Megadja, hogy ne legyenek jelölővonalak. |
| Outside | 3 | Megadja, hogy a jelölővonalak a diagram területén kívül legyenek. |
