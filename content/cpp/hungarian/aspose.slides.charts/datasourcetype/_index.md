## DataSourceType enum

Adatforrás típusok.

```cpp
enum class DataSourceType
```

### Értékek

| Név | Érték | Leírás |
| --- | --- | --- |
| Worksheet | 0 | Használjon CellXls objektumokat az XValue, YValue, Value vagy BubbleSize adatpont tárolásához a munkalapon. |
| StringLiterals | 1 | Használjon gyors hozzáférésű karakterlánc változót az XValue, YValue, Value vagy BubbleSize adatpont tárolásához. A Worksheet NEM használatos az értékek tárolásához. |
| DoubleLiterals | 2 | Használjon gyors hozzáférésű double változót az XValue, YValue, Value vagy BubbleSize adatpont tárolásához. A Worksheet NEM használatos az értékek tárolásához. |
