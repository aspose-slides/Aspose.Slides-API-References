## IDataLabelFormat::get_ShowLabelValueFromCell() metódus


Egy meghatározott diagram adatcímke cellaérték megjelenítési viselkedését reprezentálja. True megjeleníti a cellaértéket. False elrejti. Olvasás **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowLabelValueFromCell()=0
```

## Megjegyzések


Ha ennek a [DataLabelFormat](../../datalabelformat/) objektumnak a szülője egy [DataLabelCollection](../../datalabelcollection/) adatcímlek gyűjteménye, akkor ez a tulajdonság lekéri vagy beállítja a ShowLabelValueFromCell tulajdonság alapértelmezett értékét az új adatcímkékhez a [DataLabelCollection](../../datalabelcollection/) gyűjteményben. A tulajdonság értékének beállítása ugyanakkor ezt az értéket a ShowLabelValueFromCell tulajdonságra is beállítja a [DataLabelCollection](../../datalabelcollection/) gyűjtemény összes adatcímkéjén (i.e. \"DataLabels.DefaultDataLabelFormat.ShowLabelValueFromCell = val;\" miatt minden DataLabels[i].ShowLabelValueFromCell egyenlő lesz val-vel).
