## IDataLabelFormat::set_ShowBubbleSize(bool) metódus


Képviseli egy meghatározott diagram adatcímkének a buborékméret értékének megjelenítési viselkedését. Az True megjeleníti a buborékméret értékét. A False elrejti. Írja **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowBubbleSize(bool value)=0
```

## Megjegyzések


Ha ennek a [DataLabelFormat](../../datalabelformat/) objektumnak a szülője egy [DataLabelCollection](../../datalabelcollection/) adatcímke-gyűjtemény, akkor ez a tulajdonság lekéri vagy beállítja a ShowBubbleSize tulajdonság alapértelmezett értékét az új adatcímkék számára a [DataLabelCollection](../../datalabelcollection/) gyűjteményben. Ennek a tulajdonságnak az értékkel történő beállítása szintén ezt az értéket állítja be a ShowBubbleSize tulajdonságnak a [DataLabelCollection](../../datalabelcollection/) gyűjtemény összes adatcímkére (i.e. \"DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;\" ami azt eredményezi, hogy minden DataLabels[i].ShowBubbleSize egyenlő lesz a val értékkel).
