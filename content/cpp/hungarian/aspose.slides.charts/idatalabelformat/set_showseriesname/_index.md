## IDataLabelFormat::set_ShowSeriesName(bool) metódus


Beállít egy logikai értéket, amely a diagram adatcímkéinél a sorozatnév megjelenítési viselkedését jelzi. True a sorozatnév megjelenítéséhez. False a rejtéshez. Írja **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowSeriesName(bool value)=0
```

## Megjegyzések


Ha ennek a [DataLabelFormat](../../datalabelformat/) objektumnak a szülője egy [DataLabelCollection](../../datalabelcollection/) adatcímke-gyűjtemény, akkor ez a tulajdonság lekéri vagy beállítja a ShowSeriesName tulajdonság alapértelmezett értékét az új adatcímkéknél a [DataLabelCollection](../../datalabelcollection/) gyűjteményben. Ennek a tulajdonságnak az értékkel való beállítása szintén ezt az értéket állítja a ShowSeriesName tulajdonságra a [DataLabelCollection](../../datalabelcollection/) gyűjtemény összes adatcímkéjében (azaz "DataLabels.DefaultDataLabelFormat.ShowSeriesName = val;" okozza, hogy minden DataLabels[i].ShowSeriesName egyenlő legyen a val értékkel).
