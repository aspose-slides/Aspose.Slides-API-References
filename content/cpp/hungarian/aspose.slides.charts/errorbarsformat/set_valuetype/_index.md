## ErrorBarsFormat::set_ValueType(ErrorBarValueType) metódus

A hibaoszlopok hosszának meghatározásának lehetséges módjait jelenti. Egyéni értéktípus esetén az érték megadásához használja a [IChartDataPoint::get_ErrorBarsCustomValues()](../../ichartdatapoint/get_errorbarscustomvalues/) tulajdonságot a sorozat DataPoints gyűjteményének egy adott adatpontjában. Fixed, Percentage vagy StandardDeviation értéktípus esetén használja a Value tulajdonságot az érték megadásához.

Írja [ErrorBarValueType](../../errorbarvaluetype/).

```cpp
void Aspose::Slides::Charts::ErrorBarsFormat::set_ValueType(ErrorBarValueType value) override
```
