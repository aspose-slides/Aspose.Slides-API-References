## DataLabel::Hide() metódus


A data label elrejtése úgy történik, hogy az összes Show*-flaget (ShowValue, ...) hamis állapotra állítja. Az IsVisible ezután hamis lesz.

```cpp
void Aspose::Slides::Charts::DataLabel::Hide() override
```

## Megjegyzés


Ha a data label nem látható (IsVisible hamis), a data label láthatóvá tehető úgy, hogy az Show*-flageket (ShowValue, ...) igaz állapotra állítja.
