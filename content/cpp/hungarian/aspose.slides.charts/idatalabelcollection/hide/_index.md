## IDataLabelCollection::Hide() metódus

Az adatcímkét alapértelmezés szerint rejtetté teheti az összes Show*-flag (ShowValue, ...) a DefaultDataLabelFormat tulajdonságban false állapotra állításával. Az IsVisible hamis lesz ezután.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelCollection::Hide()=0
```

## Megjegyzések

Ha az adatcímke alapértelmezés szerint nem látható (IsVisible hamis), akkor a adatcímkét \"látható \nalapértelmezés szerint\" a Show*-flags (ShowValue, ...) a DefaultDataLabelFormat tulajdonságban true állapotra állításával teheti láthatóvá.
