## ErrorBarValueType enum


Represents type of error bar value

```cpp
enum class ErrorBarValueType
```

### Értékek

| Név | Érték | Leírás |
| --- | --- | --- |
| Custom | 0 | Megadja, hogy a hibasávok hossza a Plus és Minus elemek által legyen meghatározva. |
| Fixed | 1 | Megadja, hogy a hibasávok hossza a Error Bar Value által meghatározott fix érték legyen. |
| Percentage | 2 | Megadja, hogy a hibasávok hossza a Error Bar Value százaléka legyen az adatoknak. |
| StandardDeviation | 3 | Megadja, hogy a hibasávok hossza az Error Bar Value szórásának megfelelően legyen az adatoknál. |
| StandardError | 4 | Megadja, hogy a hibasávok hossza az Error Bar Value standard hibái legyen az adatoknál. |
