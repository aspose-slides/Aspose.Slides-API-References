## DataLabelCollection::Hide() metódus


Az adatcímkét alapértelmezés szerint rejtetté teheti az összes Show*-flags (ShowValue, ...) a DefaultDataLabelFormat tulajdonságban false állapotra állításával. Az IsVisible hamis lesz ezután.

```cpp
void Aspose::Slides::Charts::DataLabelCollection::Hide() override
```

## Megjegyzés


Ha az adatcímke alapértelmezés szerint nem látható (IsVisible hamis), akkor a adatcímkét „alapértelmezés szerint láthatóvá” teheti az Show*-flags (ShowValue, ...) a DefaultDataLabelFormat tulajdonságban true állapotra állításával.
