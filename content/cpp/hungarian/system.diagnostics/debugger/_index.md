## Debugger struktúra

```cpp
class Debugger
```

| Módszer | Leírás |

| static **bool** [get_IsAttached](./get_isattached/)() | Ellenőrzi, hogy a hibakereső csatlakoztatva van-e a jelenlegi alkalmazáspéldányhoz. |
