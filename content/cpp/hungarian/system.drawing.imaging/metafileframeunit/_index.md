## MetafileFrameUnit enum

Megadja a méretezéshez és pozicionáláshoz használt téglalap mértékegységét a metafájlban.

```cpp
enum class MetafileFrameUnit
```

### Értékek

| Név | Érték | Leírás |
| --- | --- | --- |
| Pixel | n/a | Megadja a képpontot mértékegységként. |
| Point | n/a | Megadja a nyomtató pontot mértékegységként. |
| Inch | n/a | Megadja az hüvelyket mértékegységként. |
| Document | n/a | Megadja a hüvelyk 1/300-át mértékegységként. |
| Millimeter | n/a | Megadja a millimétert mértékegységként. |
| GdiCompatible | n/a | Megadja a .01 millimétert mértékegységként. A GDI-vel való kompatibilitás érdekében biztosítva. |
