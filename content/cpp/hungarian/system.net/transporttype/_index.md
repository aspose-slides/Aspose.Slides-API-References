## TransportType enum

Meghatározza a socket számára engedélyezett szállítási típust.

```cpp
enum class TransportType
```

### Értékek

| Név | Érték | Leírás |
| --- | --- | --- |
| Udp | 1 | Az UDP szállítási típus. |
| Connectionless | n/a | A szállítási típus kapcsolat nélküli. |
| Tcp | 2 | A TCP szállítási típus. |
| ConnectionOriented | n/a | A szállítás kapcsolat-orientált. |
