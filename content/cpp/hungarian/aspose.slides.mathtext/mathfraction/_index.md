## MathFraction osztály

Meghatározza a tört objektumot, amely számlálóval és nevezővel, egy törtvonallal elválasztva áll. A törtvonal lehet vízszintes vagy átlós, a tört tulajdonságaitól függően. A törtobjektum a stack függvény ábrázolására is használható, amely egy elemet egy másik fölé helyez, törtvonal nélkül.

```cpp
class MathFraction : public Aspose::Slides::MathText::MathElementBase,
                     public Aspose::Slides::MathText::IMathFraction,
                     public Aspose::Slides::MathText::IHasControlCharacterProperties
```
