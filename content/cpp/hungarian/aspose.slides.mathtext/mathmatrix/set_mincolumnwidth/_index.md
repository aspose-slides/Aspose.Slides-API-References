## MathMatrix::set_MinColumnWidth(uint32_t) method


Minimum oszlop szélesség twipben (1/20th of a point) A hézag távolság (also referred to as \u201CColumn Gap\u201D vagy \u201CGap Width\u201D) hozzáadódik a MinColumnWidth-hez, hogy meghatározza a teljes Matrix [Column](../../../aspose.slides/column/) Spacing-et (distance between the same edges of different columns). Default: 0.

```cpp
void Aspose::Slides::MathText::MathMatrix::set_MinColumnWidth(uint32_t value) override
```

## Megjegyzések

```cpp
auto matrix = System::MakeObject<MathMatrix>(2, 3);
```
