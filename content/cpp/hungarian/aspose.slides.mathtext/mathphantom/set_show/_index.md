## MathPhantom::set_Show(bool) metódus

Sets a value indicating whether the base element is displayed.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_Show(bool value) override
```

## Megjegyzések

When **false**, the base element is hidden but may still occupy space depending on other phantom settings. Az OMML attribútum **m:show**-nek felel meg.
