## MathPhantom::set_Transp(bool) metódus

Beállít egy értéket, amely azt jelzi, hogy a fantom átlátszó-e az osztályalapú szóköz szabályokhoz.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_Transp(bool value) override
```

## Megjegyzések

Amikor **true**, a fantomon belüli operátorok és szimbólumok továbbra is befolyásolják a matematikai szóközöket a fantom körül (mintha láthatóak lennének). Amikor **false**, az osztályalapú szóköz figyelmen kívül marad. Ennek megfelelően az OMML attribútum **m:transp**.
