## MathPhantom::set_ZeroWidth(bool) metódus

Beállít egy értéket, amely megadja, hogy a báziselem szélességét nullának kell-e tekinteni.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_ZeroWidth(bool value) override
```

## Megjegyzések

Ha **true**, a fantom nem foglal helyet vízszintesen a báziselemének. Ennek megfelelője az OMML attribútum **m:zeroWid**.
