## IMathPhantom::set_Transp(bool) metódus


Beállít egy értéket, amely azt jelzi, hogy a fantom átlátszó-e az osztályalapú távolságszabályok esetén.

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_Transp(bool value)=0
```

## Megjegyzések


Ha **true**, a fantomon belüli operátorok és szimbólumok továbbra is befolyásolják a fantom körüli matematikai távolságot (mintha látható lenne). Ha **false**, az osztályalapú távolság figyelmen kívül marad. Ennek megfelelő OMML attribútum a **m:transp**.
