## IMathMatrix::set_MinColumnWidth(uint32_t) metódus


A minimum oszlopszélesség twipben (a pont 1/20-a). Az oszloptávolság (más néven „Column Gap” vagy „Gap Width”) hozzáadódik a MinColumnWidth-hez, hogy meghatározza a teljes Matrix [Column](../../../aspose.slides/column/) távolságot (a különböző oszlopok azonos élei közti távolság). Alapértelmezett: 0.

```cpp
virtual void Aspose::Slides::MathText::IMathMatrix::set_MinColumnWidth(uint32_t value)=0
```

## Megjegyzés


Példa: 
```cpp
auto matrix = System::MakeObject<MathMatrix>(2, 3);
matrix->set_MinColumnWidth(20);
```
