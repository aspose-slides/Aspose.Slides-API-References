## FlatStyle enum

Meghatározza, hogy a vezérlő lapos vagy háromdimenziós módon legyen-e megjelenítve.

```cpp
enum class FlatStyle
```

### Értékek

| Név | Érték | Leírás |
| --- | --- | --- |
| Flat | 0 | [Control](../control/) lapos módon van megjelenítve. |
| Popup | 1 | [Control](../control/) lapos módon van megjelenítve, hacsak az egér nem mozog fölé, ekkor háromdimenziós módú. |
| Standard | 2 | [Control](../control/) háromdimenziós módon van megjelenítve. |
| System | 3 | A stílust az operációs rendszer vezérli. |
