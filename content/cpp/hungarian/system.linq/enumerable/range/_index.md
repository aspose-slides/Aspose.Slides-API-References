## Enumerable::Range(int32_t, int32_t) metódus


Létrehoz egy sor egész számot egy meghatározott tartományon belül.

```cpp
static SharedPtr<Collections::Generic::IEnumerable<int32_t>> System::Linq::Enumerable::Range(int32_t start, int32_t count)
```


### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| start | **int32_t** | Az első egész szám értéke a sorozatban. |
| count | **int32_t** | A generálandó egymást követő egész számok száma. |

### Visszatérési érték

Egy **int32_t** típusú IEnumerable, amely egymást követő egész számok tartományát tartalmaz.
