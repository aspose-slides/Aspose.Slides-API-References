## XmlDsigExcC14NTransform osztály


A digitális aláírásokhoz a megjegyzések nélküli kizárólagos C14N XML kanonikalizációs transzformációt képviseli. Ennek az osztálynak a példányait csak a [System::MakeObject()](../../system/makeobject/) függvénnyel szabad lefoglalni. Mindig csomagolja be ezt az osztályt egy [System::SmartPtr](../../system/smartptr/) mutatóba, és ezt a mutatót használja a függvények argumentumaként.
