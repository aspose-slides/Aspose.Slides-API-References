## Directory::Delete(const String\&, bool) metódus


Eltávolítja a megadott fájlt vagy könyvtárat. Nem dob kivételt.

```cpp
static void System::IO::Directory::Delete(const String &path, bool recursive=false)
```


### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| path | const [String](../../../system/string/)\& | Az elérési út a eltávolítandó könyvtárhoz vagy fájlhoz |
| recursive | **bool** | Ha a **path** egy nem üres könyvtárat jelöl, akkor a **recursive** azt határozza meg, hogy a könyvtár teljes tartalma rekurzívan legyen-e eltávolítva; ha a **path** által megadott könyvtár nem üres, és a **recursive** 'false', akkor a művelet sikertelen lesz |
