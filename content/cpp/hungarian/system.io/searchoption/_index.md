## SearchOption enum

Megadja, hogy a keresést csak az aktuális könyvtárban, vagy az aktuális könyvtárban és az összes alkönyvtárában kell végrehajtani.

```cpp
enum class SearchOption
```

### Values

| Név | Érték | Leírás |
| --- | --- | --- |
| AllDirectories | 0 | Keresés az aktuális könyvtárban és az összes alkönyvtárában. |
| TopDirectoryOnly | 1 | Keresés csak az aktuális könyvtárban. |
