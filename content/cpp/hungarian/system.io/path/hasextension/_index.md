## Path::HasExtension(const String\&) metódus

```cpp
static bool System::IO::Path::HasExtension(const String &path)
```

### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| path | const [String](../../../system/string/)\& | Ellenőrzendő path |

### Visszatérési érték

True, ha a **path** egy kiterjesztéssel rendelkező fájlra hivatkozik, egyébként - false
