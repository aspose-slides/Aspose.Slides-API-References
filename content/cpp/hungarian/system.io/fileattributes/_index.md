## FileAttributes enum


Represents attributes of a directory or a file.

```cpp
enum class FileAttributes
```

### Értékek

| Név | Érték | Leírás |
| --- | --- | --- |
| Archive | 32 | A fájlrendszer-objektum egy eltávolításra vagy mentésre szánt jelölt. |
| Compressed | 2048 | A fájlrendszer-objektum tömörített. |
| Device | 64 | Nem használt. |
| Directory | 16 | A fájlrendszer-objektum egy könyvtár. |
| Encrypted | 16384 | A fájlrendszer-objektum titkosított. |
| Hidden | 2 | A fájlrendszer-objektum rejtett. |
| IntegrityStream | 32768 | A fájlrendszer-objektum adat-integritás támogatást tartalmaz. |
| Normal | 128 | A fájlrendszer-objektum egy fájl, amelynek nincs különleges attribútuma. |
| NotContentIndexed | 8192 | A fájlrendszer-objektum nem lesz indexelve a tartalomindexelő szolgáltatás által. |
| NoScrubData | 131072 | A fájlrendszer-objektum nem szerepel az adat-integritás vizsgálatban. |
| Offline | 4096 | A fájlrendszer-objektum offline, és az adatai nem érhetők el azonnal. |
| ReadOnly | 1 | A fájlrendszer-objektum csak olvasható. |
| ReparsePoint | 1024 | A fájlrendszer-objektum egy fájl, amely reparse pontot tartalmaz. |
| SparseFile | 512 | A fájlrendszer-objektum egy ritka fájl. |
| System | 4 | A fájlrendszer-objektum egy rendszerfájl. |
| Temporary | 256 | A fájlrendszer-objektum egy ideiglenes fájl. |
| Invalid | 0 | Érvénytelen érték. |
