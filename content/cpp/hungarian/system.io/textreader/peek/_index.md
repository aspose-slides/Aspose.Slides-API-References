## TextReader::Peek() metódus


Olvas egyetlen karaktert az adatfolyamból anélkül, hogy módosítaná az adatfolyam olvasási kurzorát.

```cpp
virtual int System::IO::TextReader::Peek()
```


### Return Value

A beolvasott karakter UTF-16 kódolással van kódolva; ha a beolvasott karaktert két kódpont ábrázolja UTF-16 kódolásban, akkor csak a magas szurrogát adja vissza; ha nem olvasott karakter, -1 lesz visszaadva
