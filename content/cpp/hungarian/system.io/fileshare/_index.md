## FileShare enum

Specifies what kind of access other [FileStream](../filestream/) objects can have to a file being opened.

```cpp
enum class FileShare
```

### Values

| Név | Érték | Leírás |
| --- | --- | --- |
| None | 0 | Nincs hozzáférés. |
| Read | 1 | Csak olvasási hozzáférés. |
| Write | 2 | Csak írási hozzáférés. |
| ReadWrite | 3 | Olvasási és írási hozzáférés. |
| Delete | 4 | A fájlt törölni lehet. |
| Inheritable | 16 | A fájlkezelő örökölhetővé válik gyermek folyamatok számára. |
