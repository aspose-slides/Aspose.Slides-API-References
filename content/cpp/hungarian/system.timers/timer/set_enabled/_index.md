## Timer::set_Enabled(bool) módszer


Elindítja vagy leállítja az időzítőt. Az időzítő elindítása nem indítja újra az időmérést, ha az időzítő már fut.

```cpp
void System::Timers::Timer::set_Enabled(bool value)
```


### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| value | **bool** | true a timer elindításához, false a leállításhoz. |
