## AuthenticationLevel enum

WebRequest-specifikus hitelesítési zászlók.

```cpp
enum class AuthenticationLevel
```

### Értékek

| Név | Érték | Leírás |
| --- | --- | --- |
| None | 0 | A kliens és a szerver számára nincs szükség hitelesítésre. |
| MutualAuthRequested | 1 | A kérés nem hibázik, ha a szerver nincs hitelesítve. |
| MutualAuthRequired | 2 | A jelenlegi alkalmazás 'IOException' kivételt kap, ha a szerver nincs hitelesítve. |
