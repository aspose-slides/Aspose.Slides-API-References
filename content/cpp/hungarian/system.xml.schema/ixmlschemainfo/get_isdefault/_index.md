## IXmlSchemaInfo::get_IsDefault() metódus


Visszaad egy értéket, amely jelzi, hogy ez a validált XML csomópont a XML [Schema](../../) Definition Language (XSD) sémaellenőrzés során alkalmazott alapértelmezett eredményeként lett beállítva.

```cpp
virtual bool System::Xml::Schema::IXmlSchemaInfo::get_IsDefault()=0
```


### Visszatérési érték

**true** ha ez a validált XML csomópont a sémaellenőrzés során alkalmazott alapértelmezett eredményeként lett beállítva; egyébként **false**.
