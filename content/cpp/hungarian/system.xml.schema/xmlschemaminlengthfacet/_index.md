## XmlSchemaMinLengthFacet osztály


Az **minLength** elem képviseli az XML [Schema](../)-t, ahogy a World Wide [Web](../../system.web/) Consortium (W3C) meghatározza. Ez az osztály használható a **simpleType** elem adatértékének minimális hosszára vonatkozó korlátozás megadására. A hossznak nagyobbnak kell lennie a **minLength** elem értékénél.

```cpp
class XmlSchemaMinLengthFacet : public System::Xml::Schema::XmlSchemaNumericFacet
```
