## XmlSchemaElement::get_IsNillable() method

Visszaad információt arról, hogy a **xsi:nil** megjelenhet-e az példány adatában. Jelzi, hogy egy explicit nil érték hozzárendelhető-e az elemhez.

```cpp
bool System::Xml::Schema::XmlSchemaElement::get_IsNillable()
```

### Visszatérési érték

Ha a nillable **true**, akkor ez lehetővé teszi egy elem példányának, hogy a **nil** attribútum **true** értékre legyen állítva. A **nil** attribútum az XML [Schema](../../) névtér részeként van definiálva a példányok számára. Az alapértelmezett érték **false**. Opcionális.
