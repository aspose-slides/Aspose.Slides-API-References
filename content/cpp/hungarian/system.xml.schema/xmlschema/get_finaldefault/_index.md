## XmlSchema::get_FinalDefault() metódus

Returns the **finalDefault** attribute which sets the default value of the **final** attribute on elements and complex types in the target namespace of the schema.

```cpp
XmlSchemaDerivationMethod System::Xml::Schema::XmlSchema::get_FinalDefault()
```

### Visszatérési érték

Az XmlSchemaDerivationMethod érték, amely a származtatás megakadályozásának különböző módszereit képviseli. Az alapértelmezett érték [XmlSchemaDerivationMethod::None](../../xmlschemaderivationmethod/).
