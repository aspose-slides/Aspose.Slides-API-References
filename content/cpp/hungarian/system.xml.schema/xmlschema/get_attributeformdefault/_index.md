## XmlSchema::get_AttributeFormDefault() metódus

Visszaadja a séma célterületében deklarált attribútumok formáját.

```cpp
XmlSchemaForm System::Xml::Schema::XmlSchema::get_AttributeFormDefault()
```

### Visszatérési érték

Az XmlSchemaForm érték, amely azt jelzi, hogy a célterületből származó attribútumoknak kötelező-e névtérelőtaggal rendelkezniük. Az alapértelmezett [XmlSchemaForm::None](../../xmlschemaform/).
