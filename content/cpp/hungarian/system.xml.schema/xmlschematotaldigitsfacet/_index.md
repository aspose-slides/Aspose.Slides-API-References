## XmlSchemaTotalDigitsFacet osztály

A **totalDigits** tulajdonságot képviseli az XML [Schema](../)-ből, ahogy a World Wide [Web](../../system.web/) Consortium (W3C) meghatározta. Ez az osztály használható a **simpleType** elem értékéhez megadható számjegyek számának korlátozására. A **totalDigits** értékének pozitív egésznek kell lennie.

```cpp
class XmlSchemaTotalDigitsFacet : public System::Xml::Schema::XmlSchemaNumericFacet
```
