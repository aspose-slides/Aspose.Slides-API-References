## XmlSchemaForm enum

Megmutatja, hogy az attribútumokat vagy elemeket névtér előtaggal kell-e kvalifikálni.

```cpp
enum class XmlSchemaForm
```

### Values

| Név | Érték | Leírás |
| --- | --- | --- |
| None | 0 | Az elem és attribútum formája nincs meghatározva a sémában. |
| Qualified | 1 | Az elemeket és attribútumokat névtér előtaggal kell ellátni. |
| Unqualified | 2 | Az elemek és attribútumok nem kötelezőek, hogy névtér előtaggal legyenek ellátva. |
