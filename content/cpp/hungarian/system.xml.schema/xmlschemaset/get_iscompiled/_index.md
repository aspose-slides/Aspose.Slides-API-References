## XmlSchemaSet::get_IsCompiled() metódus


Visszatér egy értékkel, amely azt jelzi, hogy az XML [Schema](../../) definíciós nyelv (XSD) sémái a [XmlSchemaSet](../)-ben le vannak-e fordítva.

```cpp
bool System::Xml::Schema::XmlSchemaSet::get_IsCompiled()
```


### Visszatérési érték

**true** ha a sémák a [XmlSchemaSet](../)-ben le lettek fordítva azóta, hogy egy séma hozzá lett adva vagy eltávolítva a [XmlSchemaSet](../)-ből; egyébként, **false**.
