## XmlSchemaUnique osztály


Represents the **unique** element from XML [Schema](../) as specified by the World Wide [Web](../../system.web/) Consortium (W3C). This class can be used to identify a unique constraint among a set of elements.

```cpp
class XmlSchemaUnique : public System::Xml::Schema::XmlSchemaIdentityConstraint
```

## Megjegyzések



Az osztály objektumait csak a [System::MakeObject()](../../system/makeobject/) függvény használatával szabad allokálni. Soha ne hozzon létre példányokat ebben a típusban a stack-en vagy az operator new használatával, mivel futásidejű hibákhoz és/vagy assert hibákhoz vezethet. Mindig csomagolja be ezt az osztályt egy [System::SmartPtr](../../system/smartptr/) mutatóba, és használja ezt a mutatót az objektum függvényekhez argumentumként történő átadásához.
