## XmlSchemaObject osztály


Represents the root class for the [Xml](../../system.xml/) schema object model hierarchy and serves as a base class for classes such as the [XmlSchema](../xmlschema/) class.

## Megjegyzések



Az osztály objektumait csak a [System::MakeObject()](../../system/makeobject/) függvénnyel szabad lefoglalni. Soha ne hozza létre ennek a típusnak a példányait a stacken vagy az operator new használatával, mivel ez futásidejű hibákat és/vagy állítási hibákat eredményez. Mindig csomagolja be az osztályt egy [System::SmartPtr](../../system/smartptr/) mutatóba, és használja ezt a mutatót az argumentumként való átadásra a függvényeknek.
