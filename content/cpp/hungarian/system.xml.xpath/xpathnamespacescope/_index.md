## XPathNamespaceScope enum

Meghatározza a névtér hatókörét.

```cpp
enum class XPathNamespaceScope
```

### Értékek

| Név | Érték | Leírás |
| --- | --- | --- |
| All | 0 | Visszaadja az összes névteret, amely a jelenlegi csomópont hatókörében definiálva van. Ez tartalmazza a **xmlns:xml** névteret, amelyet mindig implicit módon deklarálnak. A visszaadott névterek sorrendje nincs definiálva. |
| ExcludeXml | 1 | Visszaadja az összes névteret, amely a jelenlegi csomópont hatókörében definiálva van, kivéve a **xmlns:xml** névteret. A **xmlns:xml** névteret mindig implicit módon deklarálják. A visszaadott névterek sorrendje nincs definiálva. |
| Local | 2 | Visszaadja az összes névteret, amely a jelenlegi csomóponton helyileg definiálva van. |
