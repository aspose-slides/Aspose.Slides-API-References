## XPathNavigator::MoveToParent() metódus


When overridden in a derived class, moves the [XPathNavigator](../) to the parent node of the current node.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToParent()=0
```

### Return Value

**true** ha a [XPathNavigator](../) sikeresen a jelenlegi csomópont szülőcsomópontjára mozog; egyébként **false**. Ha **false**, a [XPathNavigator](../) pozíciója változatlan marad.
