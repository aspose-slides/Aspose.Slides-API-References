## XPathNavigator::get_LocalName() metódus

Ha egy származtatott osztályban felülírják, visszaadja a [XPathNavigator::get_Name](../get_name/) a jelenlegi csomópontból névtér előtag nélkül.

```cpp
virtual String System::Xml::XPath::XPathNavigator::get_LocalName()=0
```

### Visszatérési érték

Egy [String](../../../system/string/) amely a jelenlegi csomópont helyi nevét tartalmazza, vagy [String::Empty](../../../system/string/empty/) ha a jelenlegi csomópont nem rendelkezik névvel (például szöveg vagy megjegyzés csomópontok).
