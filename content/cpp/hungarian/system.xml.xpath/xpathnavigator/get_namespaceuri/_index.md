## XPathNavigator::get_NamespaceURI() metódus

Amikor egy származtatott osztályban felülírják, a jelenlegi csomópont namespace URI-ját adja vissza.

```cpp
virtual String System::Xml::XPath::XPathNavigator::get_NamespaceURI()=0
```

### Visszatérési érték

Egy [String](../../../system/string/), amely a jelenlegi csomópont namespace URI-ját tartalmazza, vagy [String::Empty](../../../system/string/empty/), ha a jelenlegi csomópontnak nincs namespace URI-ja.
