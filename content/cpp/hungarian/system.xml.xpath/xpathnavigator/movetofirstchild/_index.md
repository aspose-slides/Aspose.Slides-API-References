## XPathNavigator::MoveToFirstChild() metódus

When overridden in a derived class, moves the [XPathNavigator](../) to the first child node of the current node.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToFirstChild()=0
```


### Visszatérési érték

**true** ha a [XPathNavigator](../) sikeresen az első gyermekcsomópontra mozdul el az aktuális csomópontban; egyébként **false**. Ha **false**, a [XPathNavigator](../) pozíciója változatlan marad.
