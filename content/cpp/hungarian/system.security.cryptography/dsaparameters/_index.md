## DSAParameters struct


[Data](../../system.data/) struktúra a [DSA](../dsa/) algoritmus paramétereiről. Ennek a típusnak a stack-en kell legyen, és értékkel vagy referenciával kell átadni a függvényeknek. Soha ne használja a [System::SmartPtr](../../system/smartptr/) osztályt ennek a típusnak az objektumainak kezelésére.

```cpp
class DSAParameters : public System::Object
```
