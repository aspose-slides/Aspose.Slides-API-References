## HMAC osztály

A Hash-alapú üzenet [Authentication](../../system.security.authentication/) kód ([HMAC](./)) minden megvalósításának örökölni kell ezt az absztrakt osztályt. Az osztály objektumait csak a [System::MakeObject()](../../system/makeobject/) függvény használatával szabad lefoglalni. Soha ne hozzon létre példányt ebből a típusból a stacken vagy az new operátor használatával, mert ez futásidejű hibákat és/vagy állítási hibákat eredményez. Mindig tekerje be ezt az osztályt egy [System::SmartPtr](../../system/smartptr/) mutatóba, és használja ezt a mutatót a függvények argumentumaként való átadásra.

```cpp
class HMAC : public System::Security::Cryptography::HashAlgorithm
```
