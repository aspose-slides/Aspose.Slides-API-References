## RSAPKCS1SignatureFormatter osztály

Aláírja az adatokat egy [RSA](../rsa/) PKCS #1 v1.5 aláírással. Ennek az osztálynak az objektumait csak a [System::MakeObject()](../../system/makeobject/) függvény segítségével szabad lefoglalni. Sose hozzon létre példányt ebből a típusból veremben vagy az új operátor segítségével, mert ez futásidejű hibákat és/vagy állítási hibákat eredményez. Mindig csomagolja be ezt az osztályt egy [System::SmartPtr](../../system/smartptr/) mutatóba, és használja ezt a mutatót az objektum függvények argumentumaként történő átadásához.

```cpp
class RSAPKCS1SignatureFormatter : public System::Security::Cryptography::AsymmetricSignatureFormatter
```
