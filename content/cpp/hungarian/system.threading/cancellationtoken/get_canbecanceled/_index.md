## CancellationToken::get_CanBeCanceled() const metódus

Megadja, hogy ez a token képes-e a törölt állapotban lenni.

```cpp
bool System::Threading::CancellationToken::get_CanBeCanceled() const
```


### Visszatérési érték

true, ha ez a token képes a törölt állapotban lenni; egyébként false.

## Megjegyzések


A [CancellationTokenSource](../../cancellationtokensource/)-ból létrehozott tokenek true értéket adnak vissza, míg a None token mindig false értéket ad.
