

### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| wt | int | A munkavégző szálak maximális száma. |
| cpt | int | A [IO](../../../system.io/) szálak maximális száma. |

### Visszatérési érték
