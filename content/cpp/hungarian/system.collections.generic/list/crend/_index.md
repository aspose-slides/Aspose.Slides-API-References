## List::crend() const metódus

Visszafelé iterátort ad egy nem létező const-kvalifikált elemhez, amely a gyűjtemény kezdete előtt helyezkedik el.

```cpp
const_reverse_iterator System::Collections::Generic::List<T>::crend() const noexcept
```

### Visszatérési érték

Egy visszafelé mutató iterátor, amely a listában az első elem előtt található elméleti const-kvalifikált elemre mutat (visszafele az utolsó).
