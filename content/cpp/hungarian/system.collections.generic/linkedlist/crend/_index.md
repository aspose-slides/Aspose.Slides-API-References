## LinkedList::crend() const metódus

Visszaad egy fordított iterátort egy nem létező const-kvalifikált elemhez, amely a gyűjtemény kezdete előtt található.

```cpp
const_reverse_iterator System::Collections::Generic::LinkedList<T>::crend() const noexcept
```

### Visszatérési érték

Egy fordított iterátor, amely az elméleti const-kvalifikált elemre mutat, amely az összekapcsolt lista első eleme előtt helyezkedik el (fordított sorrendben az utolsó).
