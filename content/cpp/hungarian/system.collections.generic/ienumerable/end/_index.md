## IEnumerable::end() metódus

Lekéri az iterátort, amely a gyűjtemény (ha van) utolsó eleme után mutat. Ez az iterátor nem használható a hivatkozott objektum módosítására, mivel [GetEnumerator()](../getenumerator/) egy T típusú másolat-objektumot ad vissza.

```cpp
iterator System::Collections::Generic::IEnumerable<T>::end()
```

### Visszatérési érték

Egy iterátor, amely a gyűjtemény (ha van) utolsó eleme után mutat

## IEnumerable::end() const metódus

Lekéri az iterátort, amely a const-kvalifikált gyűjtemény példány (ha van) utolsó eleme után mutat.

```cpp
const_iterator System::Collections::Generic::IEnumerable<T>::end() const
```

### Visszatérési érték

Egy iterátor, amely a const-kvalifikált gyűjtemény példány (ha van) utolsó eleme után mutat
