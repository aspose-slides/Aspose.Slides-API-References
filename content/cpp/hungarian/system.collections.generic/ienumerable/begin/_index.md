## IEnumerable::begin() metódus

Visszaad egy iterátort, amely a gyűjtemény első elemére (ha van) mutat. Ez az iterátor nem használható a hivatkozott objektum módosítására, mivel [GetEnumerator()](../getenumerator/) egy T másolat-objektumot ad vissza.

```cpp
iterator System::Collections::Generic::IEnumerable<T>::begin()
```

### Visszatérési érték

Egy iterátor, amely a gyűjtemény első elemére (ha van) mutat

## IEnumerable::begin() const metódus

Visszaad egy iterátort, amely a gyűjtemény konstans-kvalifikált példányának első elemére (ha van) mutat.

```cpp
const_iterator System::Collections::Generic::IEnumerable<T>::begin() const
```

### Visszatérési érték

Egy iterátor, amely a gyűjtemény konstans-kvalifikált példányának első elemére (ha van) mutat
