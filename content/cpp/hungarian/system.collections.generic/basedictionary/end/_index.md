## BaseDictionary::end() const metódus

Visszaad egy iterátort a KVPair-wrapperhez a konténer utolsó eleme után következő kulcs-érték elemhez. C# stílusban implementálva – az iterátornak a KVPair-objectet kell visszaadnia a get_Key() és get_Value() interfésszel. Ez az elem helyőrzőként működik; hozzáférés megkísérlése meghatározatlan viselkedést eredményez.

```cpp
const_iterator System::Collections::Generic::BaseDictionary<Map>::end() const noexcept
```

### Visszatérési érték

Egy iterátor, amely a gyűjtemény vég elemét követő elméleti elemre mutat.
