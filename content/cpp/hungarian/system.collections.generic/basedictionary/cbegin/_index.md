## BaseDictionary::cbegin() const metódus


Visszaad egy iterátort a tároló első eleméhez. STL-stílusban megvalósítva. Ha a tároló üres, a visszaadott iterátor megegyezik a [end()](../../ienumerable/end/)-vel.

```cpp
stl_const_iterator System::Collections::Generic::BaseDictionary<Map>::cbegin() const noexcept
```


### Visszatérési érték

Egy iterátor, amely a gyűjtemény első const minősítéssel rendelkező elemére mutat.
