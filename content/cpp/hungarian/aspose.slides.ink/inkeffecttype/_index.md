## InkEffectType enum

Megadja az előre meghatározott vizuális hatások egy halmazát a tinta megjelenítéséhez. Minden hatás egy textúrához vagy képhez tartozik, amely szimulálja a stilizált tinta megjelenést. Ezek az értékek használhatók a digitális tintavonalak megjelenítés közbeni vizuális stílusának testreszabására.

```cpp
enum class InkEffectType
```

### Értékek

| Név | Érték | Leírás |
| --- | --- | --- |
| NotDefined | -1 | A hatás nincs definiálva vagy ismeretlen. Ez az érték használható alapértelmezettként vagy visszatérési értékként. |
| Bronze | 0 | Meleg, barnás fémes textúra, amely a bronz tintához hasonlít. |
| Galaxy | 1 | Színes, csillogó textúra, amely egy galaxisra hasonlít, kozmikus árnyalatokkal. |
| Gold | 2 | Fényes, fémes arany textúra, amely a tintavonalaknak luxus megjelenést kölcsönöz. |
| Lava | 3 | Tűzias textúra, amely a folyó lávára hasonlít, piros és narancssárga árnyalatokkal. |
| Ocean | 4 | Mélykék, folyadékszerű textúra, amely az óceáni hullámokat vagy vízbázisú tintát utánozza. |
| RainbowGlitter | 5 | Színes, csillogó szivárvány csillám hatás, amelyet ünnepi vagy élénk tintavonalakhoz használnak. |
| RoseGold | 6 | Puha rózsaszín-arany keverék, amely a rózsaaranyhoz hasonló, elegáns tintavonalakhoz. |
| Silver | 7 | Hideg, fémes ezüst textúra, amely a klasszikus ezüst tintát szimulálja. |
