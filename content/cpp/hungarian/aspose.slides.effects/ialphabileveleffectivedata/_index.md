## IAlphaBiLevelEffectiveData osztály


Megváltoztathatatlan objektum, amely egy Alpha Bi-Level hatást ábrázol. Az Alpha (Átlátszóság) értékek, amelyek kisebbek a küszöbnél, 0-ra (teljesen átlátszó) változnak, és az alfa értékek, amelyek nagyobbak vagy egyenlők a küszöbbel, 100%-ra (teljesen átlátszatlan) változnak.

```cpp
class IAlphaBiLevelEffectiveData : public virtual Aspose::Slides::Effects::IEffectEffectiveData
```
