## AlphaBiLevel osztály

Egy Alpha kétszintű hatást képvisel. Az Alpha (Opacity) értékek, amelyek kisebbek a küszöbnél, 0-ra (teljesen átlátszó) változnak, a küszöbnél nagyobb vagy egyenlő Alpha értékek 100%-ra (teljesen átlátszatlan) változnak.

```cpp
class AlphaBiLevel : public Aspose::Slides::Effects::ImageTransformOperation,
                     public Aspose::Slides::Effects::IAlphaBiLevel,
                     public Aspose::Slides::Effects::IVisualEffect
```
