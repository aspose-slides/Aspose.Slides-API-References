## IDuotoneEffectiveData osztály


Immutable object which represents a [Duotone](../duotone/) effect. For each pixel, combines clr1 and clr2 through a linear interpolation to determine the new color for that pixel.

```cpp
class IDuotoneEffectiveData : public virtual Aspose::Slides::Effects::IEffectEffectiveData
```
