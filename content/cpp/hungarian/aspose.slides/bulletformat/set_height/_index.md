## BulletFormat::set_Height(float) metódus


Beállítja a bekezdés golyó magasságát öröklődés nélkül. A std::numeric_limits<float>::quiet_NaN() érték meghatározza, hogy a golyó a bekezdés első részéből örökli a magasságot. Írja **float**.

```cpp
void Aspose::Slides::BulletFormat::set_Height(float value) override
```

## Megjegyzések


A negatív magasságérték azt jelenti, hogy a magasság pontokban van megadva, míg a pozitív érték azt jelenti, hogy a magasság a környező szöveg százaléka.
