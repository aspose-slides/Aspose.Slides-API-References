## LoadOptions::set_BlobManagementOptions(System::SharedPtr\<IBlobManagementOptions\>) metódus

Ezek a beállítások a legjobb teljesítmény-memória felhasználási arány elérését célozzák egy adott környezet vagy követelmények esetén.

```cpp
void Aspose::Slides::LoadOptions::set_BlobManagementOptions(System::SharedPtr<IBlobManagementOptions> value) override
```

## Megjegyzések


A Bináris Nagy Objektum (BLOB) egy bináris adat, amely egyetlen egységként tárolódik – például a BLOB lehet egy hang-, video- vagy prezentációs fájl.
