## LoadOptions::get_BlobManagementOptions() metódus

Az opciókat képviseli, amelyek felhasználhatók a Binary Large Objects (BLOB-ok) kezelési viselkedésének kezelésére, például ideiglenes fájlok használata vagy a memória maximális BLOB bájtok száma esetén. Ezek az opciók a legjobb teljesítmény/memóriafogyasztás arány beállítására szolgálnak egy adott környezet vagy követelmények esetén.

```cpp
System::SharedPtr<IBlobManagementOptions> Aspose::Slides::LoadOptions::get_BlobManagementOptions() override
```

## Megjegyzés

A Binary Large Object (BLOB) egy bináris adat, amely egyetlen entitásként van tárolva - azaz a BLOB lehet egy hang, videó vagy prezentáció önmagában.
