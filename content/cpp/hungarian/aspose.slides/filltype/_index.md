## FillType enum

Meghatározza a különféle vizuális objektumok belső kitöltési típusát.

```cpp
enum class FillType : int8_t
```

### Értékek

| Név | Érték | Leírás |
| --- | --- | --- |
| NotDefined | -1 | A kitöltés típusa nincs meghatározva. |
| NoFill | 0 | Nincs kitöltés alkalmazva. |
| Solid | 1 | Kitöltve egy egységes színnel. |
| Gradient | 2 | A kitöltés színátmenetes. |
| Pattern | 3 | Ismétlődő minta használatos az objektum kitöltésére. |
| Picture | 4 | Egyetlen kép használatos az objektum kitöltésére. |
| Group | 5 | A vizuális objektum örökli a kitöltési tulajdonságokat a csoporttól. |
