## ITextFrameFormat::set_ColumnCount(int32_t) metódus


Beállítja az oszlopok számát a szövegtérben. Ennek az értéknek pozitív számnak kell lennie. Ellenkező esetben az érték nulla lesz. A 0 érték azt jelenti, hogy a érték nincs meghatározva. Írja **int32_t**.

virtual void Aspose::Slides::ITextFrameFormat::set_ColumnCount(int32_t value)=0
