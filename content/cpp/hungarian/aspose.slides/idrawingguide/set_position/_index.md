## IDrawingGuide::set_Position(float) metódus


Beállítja a rajzvezető pozícióját pontban a dia bal felső sarkától számítva. Írja **float**.

```cpp
virtual void Aspose::Slides::IDrawingGuide::set_Position(float value)=0
```

## Megjegyzés


A tipikus értéktartomány nulla és a dia magassága között van egy vízszintes vezető esetén, illetve nulla és a dia szélessége között egy függőleges vezető esetén.
