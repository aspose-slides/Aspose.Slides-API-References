## LayoutSlideHeaderFooterManager::SetFooterAndChildFootersVisibility(bool) method

Módosítja a diák elrendezésének lábléchelyőrzőjének és az összes gyermeklábléchelyőrző láthatóságát. A gyermekhelyőrzők olyan helyőrzők, amelyek a függő diákon találhatók. A függő diák a mesterdia használatával és függőségével működnek.

```cpp
void Aspose::Slides::LayoutSlideHeaderFooterManager::SetFooterAndChildFootersVisibility(bool isVisible) override
```

### Arguments

| Parameter | Type | Description |
| --- | --- | --- |
| isVisible | **bool** | true – lábléchelyőrzőket láthatóvá teszi, egyébként elrejti őket. |
