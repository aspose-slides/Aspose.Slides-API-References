## ILoadOptions::set_BlobManagementOptions(System::SharedPtr\<IBlobManagementOptions\>) metódus

A beállítások, amelyeket a Bináris nagy objektumok (BLOBs) kezelési viselkedésének szabályozására lehet használni, például ideiglenes fájlok használata vagy a memóriában tárolható maximális BLOB bájtok száma. Ezek a beállítások arra szolgálnak, hogy az adott környezet vagy követelmények számára a legjobb teljesítmény/memóriafogyasztás arányt érjék el.

```cpp
virtual void Aspose::Slides::ILoadOptions::set_BlobManagementOptions(System::SharedPtr<IBlobManagementOptions> value)=0
```

## Megjegyzések

A Bináris nagy objektum (BLOB) bináris adat, amely egyetlen egységként tárolódik – vagyis a BLOB lehet egy hang, videó vagy akár egy prezentáció is.
