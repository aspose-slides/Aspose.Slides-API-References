## ILoadOptions::get_BlobManagementOptions() metódus

A lehetőségek azt képviselik, amelyek a Binary Large Objects (BLOBs) kezelésének viselkedését szabályozzák, például ideiglenes fájlok használata vagy a memória maximális BLOB bájtja. Ezek a lehetőségek a legjobb teljesítmény-memória fogyasztási arány beállítását célozzák egy adott környezethez vagy követelményekhez.

```cpp
virtual System::SharedPtr<IBlobManagementOptions> Aspose::Slides::ILoadOptions::get_BlobManagementOptions()=0
```

## Megjegyzések

A Binary Large Object (BLOB) egy bináris adat, amely egyetlen egységként van tárolva – vagyis a BLOB lehet egy hang, videó vagy bemutató maga.
