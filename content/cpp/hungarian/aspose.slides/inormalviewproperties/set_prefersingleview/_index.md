## INormalViewProperties::set_PreferSingleView(bool) metódus

Meghatározza, hogy a felhasználó előnyben részesíti-e egy teljesablakos egyetlen tartalom régió megjelenítését a három tartalom régióval rendelkező szabványos normál nézet helyett. Ha engedélyezve van, az alkalmazás dönthet úgy, hogy az egyik tartalom régiót az egész ablakban jeleníti meg. Írja **bool**.

```cpp
virtual void Aspose::Slides::INormalViewProperties::set_PreferSingleView(bool value)=0
```
