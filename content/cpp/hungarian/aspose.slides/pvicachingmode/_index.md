## PVICachingMode enum

Represents different levels of caching for PVI effective objects.

```cpp
enum class PVICachingMode
```

### Values

| Név | Érték | Leírás |
| --- | --- | --- |
| NoCaching | 0 | Klasszikus mód, minden példány létrehozásával. |
| NotDefinedOnly | 1 | Használja a hatékony értékek gyorsítótárazását a NotDefined formátumokhoz, a többit klasszikus módban. |
| Full | 2 | Használja a hatékony értékek gyorsítótárazását minden formátumhoz. |
