## IShape::set_Rotation(float) metódus


Beállítja a megadott alakzat z-tengely körüli forgatásának fokszámát. A pozitív érték az óramutató járásával megegyező forgatást jelzi; a negatív érték az óramutató járásával ellentétes forgatást jelzi. Írja **float**.

```cpp
virtual void Aspose::Slides::IShape::set_Rotation(float value)=0
```

## Megjegyzések


A visszatérő érték mindig definiált (nem std::numeric_limits<float>::quiet_NaN()). A hozzárendelt értéknek definiáltnak kell lennie (nem std::numeric_limits<float>::quiet_NaN()). A RawFrame példány tulajdonságaihoz beállíthatók nem definiált értékek.
