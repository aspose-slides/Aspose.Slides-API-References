## DocumentProperties::set_LastSavedTime(System::DateTime) metódus


Visszaadja a prezentáció utolsó módosításának dátumát. Az értékek UTC-ben vannak. Csak olvasható a(z) [Presentation::get_DocumentProperties](../../presentation/get_documentproperties/) esetén (mivel a(z) [IPresentation](../../ipresentation/) objektum mentési folyamata során belsőleg frissül). A(z) [DocumentProperties](../) példányon keresztül módosítható, amelyet a(z) [IPresentationInfo::ReadDocumentProperties](../../ipresentationinfo/readdocumentproperties/) metódus ad vissza. Tekintse meg a példát a(z) [IPresentationInfo::UpdateDocumentProperties](../../ipresentationinfo/updatedocumentproperties/) metódus összefoglalójában.

```cpp
void Aspose::Slides::DocumentProperties::set_LastSavedTime(System::DateTime value) override
```
