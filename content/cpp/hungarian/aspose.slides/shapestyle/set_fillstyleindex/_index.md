## ShapeStyle::set_FillStyleIndex(int16_t) metódus

Beállítja a forma kitöltési oszlopindexét a stílusmátrixokban. 0 azt jelenti, hogy nincs kitöltés, a pozitív érték - az index a téma kitöltési stílusaiban, a negatív érték - az index a téma háttérstílusaiban. Írja **int16_t**.
