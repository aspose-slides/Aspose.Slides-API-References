## Shape::set_Rotation(float) metódus

Beállítja a megadott alakzat z-tengely körüli elforgatásának fokszámát. A pozitív érték az óramutató járásával megegyező forgást jelzi; a negatív érték az óramutató járásával ellentétes forgást jelzi. Írja **float**.

```cpp
void Aspose::Slides::Shape::set_Rotation(float value) override
```

## Megjegyzések

A visszatérő érték mindig definiált (nem std::numeric_limits<float>::quiet_NaN()). A hozzárendelt értéknek definiáltnak kell lennie (nem std::numeric_limits<float>::quiet_NaN()). A RawFrame példány tulajdonságaihoz beállíthat nem definiált értékeket.
