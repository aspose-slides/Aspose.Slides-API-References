## LineSketchType enum

Azt jelöli, hogy egy alakra melyik vázlat típus vagy effektus lett hozzárendelve.

```cpp
enum class LineSketchType
```

### Értékek

| Név | Érték | Leírás |
| --- | --- | --- |
| NotDefined | -1 | Megadja, hogy egy alak Sketch effektusa nincs definiálva. |
| None | 0 | Megadja, hogy egy alaknak nincs Sketch effektusa. Ez ekvivalens a tulajdonság ürességével. |
| Curved | 1 | Megadja, hogy egy alaknak a Curved effektusa van, amely az alak minden élét egy nagy, enyhe görbévé alakítja. |
| Freehand | 2 | Megadja, hogy egy alaknak a Freehand effektusa van, amely a leginkább hasonlít egy hibásan megrajzolt vonalra. |
| Scribble | 3 | Megadja, hogy egy alaknak a Scribble effektusa van, amely túlzott oszcillációval rendelkezik, mintha szándékosan rendezetlenül lenne megrajzolva. |
