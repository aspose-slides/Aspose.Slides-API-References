## XmlKnownDtds enum


A [Resolvers::XmlKnownDtds](./) felsorolás a [Resolvers::XmlPreloadedResolver](../xmlpreloadedresolver/) által használt, és meghatározza, hogy a [Resolvers::XmlPreloadedResolver](../xmlpreloadedresolver/) mely jól ismert DTD-ket ismeri fel.

```cpp
enum class XmlKnownDtds
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| None | 0 | Meghatározza, hogy a [Resolvers::XmlPreloadedResolver](../xmlpreloadedresolver/) ne ismerjen fel egyetlen előre definiált DTD-t sem. |
| Xhtml10 | 1 | Meghatározza, hogy a [Resolvers::XmlPreloadedResolver](../xmlpreloadedresolver/) felismerje az XHTML 1.0-ban definiált DTD-ket és entitásokat. |
| Rss091 | 2 | Meghatározza, hogy a [Resolvers::XmlPreloadedResolver](../xmlpreloadedresolver/) felismerje az RSS 0.91-ben definiált DTD-ket és entitásokat. |
| All | 65535 | Meghatározza, hogy a [Resolvers::XmlPreloadedResolver](../xmlpreloadedresolver/) az összes jelenleg támogatott DTD-t felismerje. Ez az alapértelmezett viselkedés. |
