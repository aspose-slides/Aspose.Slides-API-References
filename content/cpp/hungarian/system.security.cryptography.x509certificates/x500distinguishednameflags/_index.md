## X500DistinguishedNameFlags enumeráció

X509 tanúsítvány megkülönböztetett név formázási szabályai.

```cpp
enum class X500DistinguishedNameFlags
```

### Értékek

| Név | Érték | Leírás |
| --- | --- | --- |
| None | 0 | Nincs különleges jellemző. |
| Reversed | 1 | A név fenntartott. |
| UseSemicolons | 16 | Pontosvesszőket használ. |
| DoNotUsePlusSign | 32 | A név nem használ pluszjelet. |
| DoNotUseQuotes | 64 | A névben letiltja az idézőjeleket. |
| UseCommas | 128 | Vesszők használatát engedélyezi. |
| UseNewLines | 256 | Új sorok használatát engedélyezi. |
| UseUTF8Encoding | 4096 | Átvált a Unicode helyett az UTF-8 kódolás használatára. |
| UseT61Encoding | 8192 | T61 kódolásra vált. |
| ForceUTF8Encoding | 16384 | Kényszeríti az UTF-8 használatát bizonyos X500 kulcsok kódolásakor. |
