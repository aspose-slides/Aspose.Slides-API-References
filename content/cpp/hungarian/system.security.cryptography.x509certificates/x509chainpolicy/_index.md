## X509ChainPolicy osztály

A láncszabály, amelyet az X509 tanúsítványlánc felépítésekor alkalmaznak. Ennek az osztálynak az objektumait csak a [System::MakeObject()](../../system/makeobject/) függvény segítségével szabad lefoglalni. Soha ne hozzon létre példányt ebből a típusból a veremben vagy az operator new használatával, mivel ez futásidejű hibákat és/vagy állítási hibákat eredményez. Mindig csomagolja be ezt az osztályt egy [System::SmartPtr](../../system/smartptr/) pointerbe, és használja ezt a pointert az argumentumként történő függvényhívásokhoz.

```cpp
class X509ChainPolicy : public System::Object
```
