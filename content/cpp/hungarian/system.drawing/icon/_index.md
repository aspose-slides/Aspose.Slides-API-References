## Ikon osztály


Egy [Windows](../../system.windows/) ikont képvisel. Az osztály példányait csak a [System::MakeObject()](../../system/makeobject/) függvény segítségével szabad lefoglalni. Soha ne hozzon létre példányt a stacken vagy az operator new használatával, mivel ez futásidejű hibákat és/vagy állítási hibákat eredményez. Mindig csomagolja be ezt az osztályt egy [System::SmartPtr](../../system/smartptr/) mutatóba, és ezt a mutatót használja az objektum függvények argumentumaként való átadásához.

```cpp
class Icon : public System::Object
```
