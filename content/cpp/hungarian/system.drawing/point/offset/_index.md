## Point::Offset(int, int) metódus


Az aktuális objektum által képviselt X és Y koordináta értékét eltolja a megadott értékekkel.

```cpp
void System::Drawing::Point::Offset(int dx, int dy)
```


### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| dx | int | Az X koordináta értékét eltoló érték |
| dy | int | Az Y koordináta értékét eltoló érték |

## Point::Offset(Point) metódus


Az aktuális objektum által képviselt X és Y koordinátákat eltolja a megadott [Point](../) objektum által képviselt X és Y koordináták értékeivel megfelelően.

```cpp
void System::Drawing::Point::Offset(Point point)
```


### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| point | [Point](../) | A(z) [Point](../) objektum, amely meghatározza az X és Y koordináták eltolásához szükséges értékeket |
