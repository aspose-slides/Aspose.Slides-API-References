## RectangleF::get_IsEmpty() const metódus

Megállapítja, hogy a jelenlegi objektum által képviselt recangle bal felső sarkának X és Y koordinátái, valamint a szélessége és magassága 0 értékkel rendelkeznek-e.

```cpp
bool System::Drawing::RectangleF::get_IsEmpty() const
```

### Visszatérési érték

True ha X és Y koordinátái a recangle bal felső sarkában, amelyet a jelenlegi objektum képvisel, valamint a szélessége és magassága 0 értékkel rendelkeznek, egyébként - false
