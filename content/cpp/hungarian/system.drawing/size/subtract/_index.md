## Size::Subtract(const Size\&, const Size\&) metódus

Új [Size](../) objektumot ad vissza, amely a **size2**-től **size1**-től való kivonás eredménye, vagyis amelynek a szélességértéke **size2's** szélességértékének **size1's** szélességértékéből való kivonás eredménye, és a magasságértéke **size2's** magasságértékének **size1's** magasságértékéből való kivonás eredménye.

```cpp
static Size System::Drawing::Size::Subtract(const Size &size1, const Size &size2)
```

### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| size1 | const [Size](../)\& | [Size](../) objektum, amelyből kivonás történik |
| size2 | const [Size](../)\& | [Size](../) objektum, amelyet kivonnak |

### Visszatérési érték

[Size](../) objektum, amely a **size2**-tól **size1**-tól való kivonás eredménye
