## StringDigitSubstitute enum

Megadja, hogy a karakterláncban lévő számjegyeket hogyan helyettesítik a helyi beállítás vagy nyelv szerint.

```cpp
enum class StringDigitSubstitute
```

### Értékek

| Név | Érték | Leírás |
| --- | --- | --- |
| User | 0 | User által meghatározott helyettesítés. |
| None | 1 | A helyettesítés le van tiltva. |
| National | 2 | A felhasználó helyi beállításainak hivatalos nemzeti nyelvének megfelelő számjegyek helyettesítése. |
| Traditional | 3 | A felhasználó natív írásrendszerének vagy nyelvének megfelelő számjegyek helyettesítése, amely esetleg nem egyezik a felhasználó helyi beállításainak hivatalos nemzeti nyelvével. |
