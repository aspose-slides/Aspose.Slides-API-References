## StringTrimming enum


Megadja, hogyan kell a karaktereket levágni egy olyan karakterláncról, amely nem fér bele a layout alakba.

```cpp
enum class StringTrimming
```

### Értékek

| Név | Érték | Leírás |
| --- | --- | --- |
| None | 0 | Nincs vágás. |
| Character | 1 | Vágás a legközelebbi karakterhez. |
| Word | 2 | Vágás a legközelebbi szóhoz. |
| EllipsisCharacter | 3 | Vágás a legközelebbi karakterhez, és ellipszis beszúrása a karakterlánc végén. |
| EllipsisWord | 4 | Vágás a legközelebbi szóhoz, és ellipszis beszúrása a karakterlánc végén. |
| EllipsisPath | 5 | A középső rész eltávolításra kerül a levágott sorokból, és ellipszissel helyettesítik. A sor utolsó, perjellel elválasztott szegmensének a lehető legtöbb megtartása. |
