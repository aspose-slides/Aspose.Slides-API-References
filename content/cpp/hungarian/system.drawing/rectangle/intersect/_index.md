```cpp
void System::Drawing::Rectangle::Intersect(const Rectangle &rect)
```

### Argumentumok

| Parameter | Type | Description |
| --- | --- | --- |
| rect | const [Rectangle](../)\& | [Rectangle](../) objektum, amely a téglalapot képviseli, amelyet a jelenlegi objektum által képviselt téglalappal kell metszeni |

| b | const [Rectangle](../)\& | A második metszendő téglalap |
