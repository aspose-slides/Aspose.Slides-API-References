## Rectangle::Offset(const Point\&) metódus

Eltolja a jelenlegi objektum által képviselt téglalap pozícióját a megadott mennyiségekkel.

```cpp
void System::Drawing::Rectangle::Offset(const Point &pos)
```

### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| pos | const [Point](../../point/)\& | A [Point](../../point/) objektum, amely meghatározza a téglalap eltolásának mértékét; a pont X koordináta értéke adja meg a téglalap bal felső sarkának X koordinátájához hozzáadandó értéket, és a pont Y koordinátája adja meg a bal felső sarok Y koordinátájához hozzáadandó értéket |

## Rectangle::Offset(int, int) metódus

Eltolja a jelenlegi objektum által képviselt téglalap pozícióját a megadott mennyiségekkel.

```cpp
void System::Drawing::Rectangle::Offset(int x, int y)
```

### Argumentumok

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| x | int | Az érték, amelyet a téglalap jelenlegi X koordinátájához kell hozzáadni |
| y | int | Az érték, amelyet a téglalap jelenlegi Y koordinátájához kell hozzáadni |
