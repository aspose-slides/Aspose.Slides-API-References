## Rectangle::get_IsEmpty() const metódus

Meghatározza, hogy a jelenlegi objektum által képviselt téglalap bal felső sarkának X és Y koordinátái, valamint szélessége és magassága 0 értékűek-e.

```cpp
bool System::Drawing::Rectangle::get_IsEmpty() const
```

### Visszatérési érték

True ha X és Y koordinátái a jelenlegi objektum által képviselt téglalap bal felső sarkának, valamint szélessége és magassága 0 értékűek, egyébként - false
