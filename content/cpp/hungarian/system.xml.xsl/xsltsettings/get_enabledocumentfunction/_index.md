## XsltSettings::get_EnableDocumentFunction() metódus

Returns a value indicating whether to enable support for the XSLT **document()** function.

```cpp
bool System::Xml::Xsl::XsltSettings::get_EnableDocumentFunction()
```

### Visszatérési érték

**true** a XSLT **document()** függvény támogatásához; egyébként **false**. Az alapértelmezett érték **false**.
