## XsltSettings::get_Default() metódus


Visszaad egy [XsltSettings](../) objektumot az alapértelmezett beállításokkal. Az XSLT **document()** függvény és a beágyazott szkriptblokkok támogatása le van tiltva.

```cpp
static SharedPtr<XsltSettings> System::Xml::Xsl::XsltSettings::get_Default()
```


### Visszatérési érték

Egy [XsltSettings](../) objektum, amelyben a [XsltSettings::set_EnableDocumentFunction](../set_enabledocumentfunction/) és [XsltSettings::set_EnableScript](../set_enablescript/) beállítások **false** értékre vannak állítva.
