## IXsltContextVariable::get_IsParam() metódus


Visszaad egy értéket, amely jelzi, hogy a változó egy Extensible Stylesheet Language Transformations (XSLT) paraméter-e. Ez lehet egy stíluslap vagy egy sablon paramétere.

```cpp
virtual bool System::Xml::Xsl::IXsltContextVariable::get_IsParam()=0
```


### Visszatérési érték

**true** ha a változó XSLT paraméter, egyébként **false**.
