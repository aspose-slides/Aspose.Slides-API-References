## RegexOptions enum

[Regex](../regex/) opciók.

```cpp
enum class RegexOptions
```

### Értékek

| Név | Érték | Leírás |
| --- | --- | --- |
| None | 0 | Alapértelmezett viselkedés. |
| Compiled | 1 | Regex lefordítása a teljesítmény érdekében. Alapértelmezés szerint mindig megtörténik. |
| CultureInvariant | 2 | Kultúrafüggetlen egyezés használata. Figyelmen kívül hagyva. |
| ECMAScript | 4 | ECMAScript szintaxis használata. Figyelmen kívül hagyva. |
| ExplicitCapture | 8 | Kizárólag explicit rögzítés. Figyelmen kívül hagyva. |
| IgnoreCase | 16 | Nagy- és kisbetű figyelmen kívül hagyása egyezéskor. |
| IgnorePatternWhitespace | 32 | Szóközök figyelmen kívül hagyása a mintában. Nem támogatott. |
| Multiline | 64 | ^ és $ karakterek sor elejének és végének tekintése, nem a teljes karakterláncnak. |
| RightToLeft | 128 | Jobbról balra irányú egyezés. Nem támogatott. |
| Singleline | 256 | A '.' bármely karaktert egyezővé tesz kivétel nélkül (normál esetben az újsor karakterek nem egyeznek). |
