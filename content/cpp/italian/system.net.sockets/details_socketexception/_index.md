## Details_SocketException classe


Rappresenta l'eccezione generata quando si verifica un errore di socket. Non creare mai istanze di questa classe manualmente. Usa invece la classe SocketException. Non avvolgere mai le istanze della classe SocketException in [System::SmartPtr](../../system/smartptr/).

```cpp
class Details_SocketException : public System::Details_Exception
```
