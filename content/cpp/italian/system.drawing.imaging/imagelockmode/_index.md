## ImageLockMode enum

Specifica le proprietà dell'area di un'immagine che viene bloccata.

```cpp
enum class ImageLockMode
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| ReadOnly | 1 | L'area è bloccata solo per la lettura. |
| WriteOnly | 2 | L'area è bloccata solo per la scrittura. |
| ReadWrite | n/a | L'area è bloccata sia per la lettura che per la scrittura. |
| UserInputBuffer | 4 | L'immagine risiede in un buffer di input dell'utente, il cui accesso è controllato dall'utente. |
