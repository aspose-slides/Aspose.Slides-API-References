## ColorAdjustType enum

Specifica quali oggetti utilizzano le informazioni di regolazione del colore.

```cpp
enum class ColorAdjustType
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Default | 0 | Definisce le informazioni di regolazione del colore che sono utilizzate da tutti gli oggetti che non possiedono proprie informazioni di regolazione del colore. |
| Bitmap | 1 | Definisce le informazioni di regolazione del colore per gli oggetti [Bitmap](../../system.drawing/bitmap/). |
| Brush | 2 | Definisce le informazioni di regolazione del colore per gli oggetti [Brush](../../system.drawing/brush/). |
| Pen | 3 | Definisce le informazioni di regolazione del colore per gli oggetti [Pen](../../system.drawing/pen/). |
| Text | 4 | Definisce le informazioni di regolazione del colore per il testo. |
| Count | 5 | Specifica il numero di tipi specificati. |
| Any | 6 | Specifica il numero di tipi specificati. |
