## Classi

| Classe | Descrizione |
| --- | --- |
| [Evidence](./evidence/) | Classe stub per codice tradotto che utilizza la classe [Evidence](./evidence/) per compilare. Gli oggetti di questa classe dovrebbero essere allocati solo mediante la funzione [System::MakeObject()](../system/makeobject/). Non creare mai un'istanza di questo tipo sullo stack o utilizzando operator new, poiché ciò provocherà errori di runtime e/o errori di asserzione. Avvolgere sempre questa classe in un puntatore [System::SmartPtr](../system/smartptr/) e utilizzare questo puntatore per passarlo alle funzioni come argomento. |
