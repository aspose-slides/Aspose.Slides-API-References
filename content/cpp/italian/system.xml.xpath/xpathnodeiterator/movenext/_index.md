## XPathNodeIterator::MoveNext() metodo


Quando sovrascritto in una classe derivata, sposta l'oggetto [XPathNavigator](../../xpathnavigator/) restituito dal metodo [XPathNodeIterator::get_Current](../get_current/) al nodo successivo nel set di nodi selezionato.

```cpp
virtual bool System::Xml::XPath::XPathNodeIterator::MoveNext()=0
```


### Valore di ritorno

**true** se l'oggetto [XPathNavigator](../../xpathnavigator/) è stato spostato al nodo successivo; **false** se non ci sono più nodi selezionati.
