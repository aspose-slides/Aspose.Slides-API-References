## XPathNavigator::MoveToNamespace(String) metodo

Sposta il [XPathNavigator](../) al nodo namespace con il prefisso namespace specificato.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToNamespace(String name)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| name | [String](../../../system/string/) | Il prefisso namespace del nodo namespace. |

### Valore di ritorno

**true** se il [XPathNavigator](../) riesce a spostarsi al namespace specificato; **false** se non è stato trovato un nodo namespace corrispondente, o se il [XPathNavigator](../) non è posizionato su un nodo elemento. Se **false**, la posizione del [XPathNavigator](../) rimane invariata.
