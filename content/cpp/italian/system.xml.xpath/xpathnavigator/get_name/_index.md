## XPathNavigator::get_Name() metodo


Quando viene sovrascritto in una classe derivata, restituisce il nome qualificato del nodo corrente.

```cpp
virtual String System::Xml::XPath::XPathNavigator::get_Name()=0
```


### Valore restituito

Un [String](../../../system/string/) che contiene il [XPathNavigator::get_Name](./) qualificato del nodo corrente, o [String::Empty](../../../system/string/empty/) se il nodo corrente non ha un nome (ad esempio, nodi di testo o commento).
