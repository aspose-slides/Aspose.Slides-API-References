## XPathNavigator::get_NamespaceURI() metodo

Quando sovrascritto in una classe derivata, restituisce l'URI dello spazio dei nomi del nodo corrente.

```cpp
virtual String System::Xml::XPath::XPathNavigator::get_NamespaceURI()=0
```

### Valore di ritorno

Un [String](../../../system/string/) che contiene l'URI dello spazio dei nomi del nodo corrente, o [String::Empty](../../../system/string/empty/) se il nodo corrente non ha un URI dello spazio dei nomi.
