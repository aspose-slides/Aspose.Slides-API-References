## XPathNavigator::MoveToFirstAttribute() metodo


Quando sovrascritto in una classe derivata, sposta il [XPathNavigator](../) sul primo attributo del nodo corrente.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToFirstAttribute()=0
```


### Valore di ritorno

**true** se il [XPathNavigator](../) riesce a spostarsi sul primo attributo del nodo corrente; altrimenti, **false**. Se **false**, la posizione del [XPathNavigator](../) rimane invariata.
