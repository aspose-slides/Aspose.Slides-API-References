## XPathNavigator::get_LocalName() metodo

Quando sovrascritto in una classe derivata, restituisce il [XPathNavigator::get_Name](../get_name/) del nodo corrente senza alcun prefisso di namespace.

```cpp
virtual String System::Xml::XPath::XPathNavigator::get_LocalName()=0
```

### Valore di ritorno

Un [String](../../../system/string/) che contiene il nome locale del nodo corrente, o [String::Empty](../../../system/string/empty/) se il nodo corrente non ha un nome (ad esempio, nodi di testo o di commento).
