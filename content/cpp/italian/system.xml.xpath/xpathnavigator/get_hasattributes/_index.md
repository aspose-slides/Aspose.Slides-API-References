## XPathNavigator::get_HasAttributes() metodo

Restituisce un valore che indica se il nodo corrente ha degli attributi.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::get_HasAttributes()
```

### Valore di ritorno

**true** se il nodo corrente ha attributi; restituisce **false** se il nodo corrente non ha attributi, oppure se [XPathNavigator](../) non è posizionato su un nodo elemento.
