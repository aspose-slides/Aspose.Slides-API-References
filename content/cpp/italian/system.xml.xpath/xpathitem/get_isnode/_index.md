## XPathItem::get_IsNode() metodo

Quando viene sovrascritto in una classe derivata, ottiene un valore che indica se l'elemento rappresenta un [XPath](../../) nodo o un valore atomico.

```cpp
virtual bool System::Xml::XPath::XPathItem::get_IsNode()=0
```

### Valore di ritorno

**true** se l'elemento rappresenta un [XPath](../../) nodo; **false** se l'elemento rappresenta un valore atomico.
