## XmlSchemaElement::get_DefaultValue() metodo


Restituisce il valore predefinito dell'elemento se il suo contenuto è un tipo semplice o se il contenuto dell'elemento è **textOnly**.

```cpp
String System::Xml::Schema::XmlSchemaElement::get_DefaultValue()
```


### Valore di ritorno

Il valore predefinito per l'elemento. Il valore predefinito è **nullptr**. Opzionale.
