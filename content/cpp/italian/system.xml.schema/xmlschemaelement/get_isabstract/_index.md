## XmlSchemaElement::get_IsAbstract() metodo


Restituisce informazioni per indicare se l'elemento può essere utilizzato in un documento di istanza.

```cpp
bool System::Xml::Schema::XmlSchemaElement::get_IsAbstract()
```


### Valore di ritorno

Se **true**, l'elemento non può apparire nel documento di istanza. Il valore predefinito è **false**. Opzionale.
