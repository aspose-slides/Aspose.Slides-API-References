## XmlSchemaSet::get_IsCompiled() metodo

Restituisce un valore che indica se gli schemi XML [Schema](../../) linguaggio di definizione (XSD) nella [XmlSchemaSet](../) sono stati compilati.

```cpp
bool System::Xml::Schema::XmlSchemaSet::get_IsCompiled()
```

### Valore restituito

**true** se gli schemi nella [XmlSchemaSet](../) sono stati compilati dall'ultima volta che uno schema è stato aggiunto o rimosso dalla [XmlSchemaSet](../); altrimenti, **false**.
