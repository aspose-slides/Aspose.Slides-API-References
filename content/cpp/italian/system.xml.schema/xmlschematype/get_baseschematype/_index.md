## XmlSchemaType::get_BaseSchemaType() metodo

Restituisce il tipo di oggetto post-compilazione o il tipo di dato integrato XML [Schema](../../) Definition Language (XSD), elemento simpleType o elemento complexType. Questo è un valore del set di informazioni post-compilazione dello schema.

```cpp
SharedPtr<Object> System::Xml::Schema::XmlSchemaType::get_BaseSchemaType()
```

### Valore di ritorno

Il tipo di dato XSD integrato, elemento simpleType o elemento complexType.
