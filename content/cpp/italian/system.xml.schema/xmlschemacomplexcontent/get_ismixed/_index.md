## XmlSchemaComplexContent::get_IsMixed() metodo


Restituisce informazioni che determinano se il tipo ha un modello di contenuto misto.

```cpp
bool System::Xml::Schema::XmlSchemaComplexContent::get_IsMixed()
```


### Valore di ritorno

Se questo valore è **true**, i dati di carattere sono consentiti tra gli elementi figli del tipo complesso (modello di contenuto misto). Il valore predefinito è **false**. Opzionale.
