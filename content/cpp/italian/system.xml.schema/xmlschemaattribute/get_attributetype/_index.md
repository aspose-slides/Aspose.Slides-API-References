## XmlSchemaAttribute::get_AttributeType() metodo

Restituisce l'oggetto basato sul valore [XmlSchemaAttribute::get_SchemaType](../get_schematype/) o [XmlSchemaAttribute::get_SchemaTypeName](../get_schematypename/) dell'attributo che contiene l'interpretazione post-compilazione del valore **AttributeType**.

```cpp
SharedPtr<Object> System::Xml::Schema::XmlSchemaAttribute::get_AttributeType()
```

### Valore di ritorno

L'oggetto che contiene l'interpretazione post-compilazione del valore **AttributeType**.

Obsoleto
:   È consigliato usare il metodo get_AttributeSchemaType invece.
