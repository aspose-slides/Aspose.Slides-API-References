## XmlSchemaParticle::get_MinOccursString() metodo


Restituisce il numero come valore stringa. Il numero minimo di volte in cui la particella può verificarsi.

```cpp
String System::Xml::Schema::XmlSchemaParticle::get_MinOccursString()
```


### Valore di ritorno

Il numero come valore stringa. [String::Empty](../../../system/string/empty/) indica che **MinOccurs** è uguale al valore predefinito. Il valore predefinito è **nullptr**.
