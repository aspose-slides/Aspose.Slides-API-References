## XmlSchemaCompilationSettings::get_EnableUpaCheck() metodo

Restituisce un valore che indica se [XmlSchemaSet](../../xmlschemaset/) deve verificare le violazioni di Unique Particle Attribution (UPA).

```cpp
bool System::Xml::Schema::XmlSchemaCompilationSettings::get_EnableUpaCheck()
```

### Valore di ritorno

**true** se [XmlSchemaSet](../../xmlschemaset/) deve verificare le violazioni di Unique Particle Attribution (UPA); altrimenti, **false**. Il valore predefinito è **true**.
