## InferenceOption enum

Influisce sull'occorrenza e le informazioni di tipo dedotte dalla classe [XmlSchemaInference](../) per gli elementi e gli attributi in un documento XML.

```cpp
enum class InferenceOption
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Restricted | 0 | Indica che per un particolare elemento o attributo dovrebbe essere dedotta una dichiarazione di schema più restrittiva. |
| Relaxed | 1 | Indica che per un particolare elemento o attributo dovrebbe essere dedotta una dichiarazione di schema meno restrittiva. |
