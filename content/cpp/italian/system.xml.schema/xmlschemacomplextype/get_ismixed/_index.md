## XmlSchemaComplexType::get_IsMixed() metodo

Restituisce informazioni che determinano se il tipo complesso ha un modello di contenuto misto (markup all'interno del contenuto).

```cpp
bool System::Xml::Schema::XmlSchemaComplexType::get_IsMixed() override
```

### Valore di ritorno

**true**, se i dati carattere possono apparire tra gli elementi figlio di questo tipo complesso; altrimenti, **false**. Il valore predefinito è **false**. Opzionale.
