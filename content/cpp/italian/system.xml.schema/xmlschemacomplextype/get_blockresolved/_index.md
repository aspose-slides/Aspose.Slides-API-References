## XmlSchemaComplexType::get_BlockResolved() metodo

Restituisce il valore dopo che il tipo è stato compilato nel set di informazioni post-validazione dello schema (infoset). Questo valore indica come il tipo viene applicato quando **xsi:type** è utilizzato nel documento di istanza.

```cpp
XmlSchemaDerivationMethod System::Xml::Schema::XmlSchemaComplexType::get_BlockResolved()
```

### Valore restituito

Il valore del set di informazioni post-validazione dello schema. Il valore predefinito è **BlockDefault** sull'elemento **schema**.
