### Valore di ritorno

L'attributo **block** impedisce che un tipo complesso venga utilizzato nel tipo di derivazione specificato. Il valore predefinito è [XmlSchemaDerivationMethod::None](../../xmlschemaderivationmethod/). Facoltativo.
