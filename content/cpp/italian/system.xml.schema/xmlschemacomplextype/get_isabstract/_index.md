## XmlSchemaComplexType::get_IsAbstract() metodo


Restituisce le informazioni che determinano se l'elemento **complexType** può essere usato nel documento istanza.

```cpp
bool System::Xml::Schema::XmlSchemaComplexType::get_IsAbstract()
```


### Valore di ritorno

Se **true**, un elemento non può utilizzare direttamente questo elemento **complexType** e deve utilizzare un tipo complesso che sia derivato da questo elemento **complexType**. Il valore predefinito è **false**. Opzionale.
