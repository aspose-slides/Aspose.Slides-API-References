## IXmlSchemaInfo::get_IsDefault() metodo

Restituisce un valore che indica se questo nodo XML convalidato è stato impostato come risultato di un valore predefinito applicato durante la validazione dello schema XML [Schema](../../) Definition Language (XSD) schema validation.

```cpp
virtual bool System::Xml::Schema::IXmlSchemaInfo::get_IsDefault()=0
```

### Valore di ritorno

**true** se questo nodo XML convalidato è stato impostato come risultato di un valore predefinito applicato durante la validazione dello schema; altrimenti, **false**.
