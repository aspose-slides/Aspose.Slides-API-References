## Dettagli_HttpException::Is(const System::TypeInfo\&) const method

```cpp
bool System::Web::Details_HttpException::Is(const System::TypeInfo &target) const override
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| target | const [System::TypeInfo](../../../system/typeinfo/)\& | [TypeInfo](../../../system/typeinfo/) struttura che descrive il tipo contro cui testare l'oggetto corrente. |

### Valore di ritorno

True se l'oggetto è di tipo etichettato o della sua sottoclasse, false altrimenti.

## Osservazioni

Verifica se l'oggetto rappresenta un'istanza del tipo descritto da targetType. Analogo dell'operatore C# 'is' operator.
