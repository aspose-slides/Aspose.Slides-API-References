## SortedList::crend() const metodo

Restituisce un iteratore inverso per un elemento qualificato const non esistente prima dell'inizio della collezione.

```cpp
const_reverse_iterator System::Collections::Generic::SortedList<TKey, TValue>::crend() const noexcept
```

### Valore di ritorno

Un iteratore inverso che punta all'elemento teorico qualificato const precedente il primo elemento nella mappa (ultimo in ordine inverso).
