## List::rend() metodo


Restituisce un iteratore inverso per un elemento inesistente precedente l'inizio della collezione.

```cpp
reverse_iterator System::Collections::Generic::List<T>::rend() noexcept
```


### Valore di ritorno

Un iteratore inverso che punta all'elemento teorico che precede il primo elemento nella lista (ultimo in ordine inverso).



### Valore di ritorno

Un iteratore inverso che punta all'elemento teorico che precede il primo elemento nella lista qualificata const (ultimo in ordine inverso).
