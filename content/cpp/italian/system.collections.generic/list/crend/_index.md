## List::crend() const metodo


Restituisce un iteratore inverso per un elemento const-qualified non esistente prima dell’inizio della collezione.

```cpp
const_reverse_iterator System::Collections::Generic::List<T>::crend() const noexcept
```


### Valore di ritorno

Un iteratore inverso che punta all’elemento const-qualified teorico che precede il primo elemento nella lista (ultimo in ordine inverso).
