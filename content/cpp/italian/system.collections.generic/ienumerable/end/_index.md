## IEnumerable::end() metodo


Restituisce un iteratore che punta subito dopo l'ultimo elemento (se presente) della collezione. Questo iteratore non può essere usato per modificare l'oggetto di riferimento perché [GetEnumerator()](../getenumerator/) restituisce un oggetto copia di T.

```cpp
iterator System::Collections::Generic::IEnumerable<T>::end()
```


### Valore di ritorno

Un iteratore che punta subito dopo l'ultimo elemento (se presente) della collezione

## IEnumerable::end() const metodo


Restituisce un iteratore che punta subito dopo l'ultimo elemento (se presente) dell'istanza della collezione qualificata come const.

```cpp
const_iterator System::Collections::Generic::IEnumerable<T>::end() const
```


### Valore di ritorno

Un iteratore che punta subito dopo l'ultimo elemento (se presente) dell'istanza della collezione qualificata come const
