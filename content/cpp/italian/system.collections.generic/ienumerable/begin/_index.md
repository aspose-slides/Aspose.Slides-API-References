## IEnumerable::begin() metodo

Restituisce un iteratore che punta al primo elemento (se presente) della collezione. Questo iteratore non può essere usato per modificare l'oggetto referenziato perché [GetEnumerator()](../getenumerator/) restituisce una copia dell'oggetto di tipo T.

```cpp
iterator System::Collections::Generic::IEnumerable<T>::begin()
```


### Valore di ritorno

Un iteratore che punta al primo elemento (se presente) della collezione

## IEnumerable::begin() const metodo

Restituisce un iteratore che punta al primo elemento (se presente) dell'istanza della collezione qualificata come const.

```cpp
const_iterator System::Collections::Generic::IEnumerable<T>::begin() const
```


### Valore di ritorno

Un iteratore che punta al primo elemento (se presente) dell'istanza della collezione qualificata come const
