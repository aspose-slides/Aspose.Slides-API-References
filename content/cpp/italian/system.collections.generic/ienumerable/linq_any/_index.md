## IEnumerable::LINQ_Any() metodo


Determina se una sequenza contiene elementi.

```cpp
bool System::Collections::Generic::IEnumerable<T>::LINQ_Any()
```


### Valore di ritorno

true se la sequenza di origine contiene elementi; altrimenti, false.

## IEnumerable::LINQ_Any(std::function\<bool(T)>) metodo


Determina se esiste un elemento di una sequenza o se soddisfa una condizione.

```cpp

```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| predicate | std::function\<**bool**(T)> | Una funzione per verificare se ciascun elemento soddisfa una condizione. |

### Valore di ritorno

true se la sequenza di origine contiene elementi; altrimenti, false.
