## IEnumerator::MoveNext() metodo


Sposta l'iteratore al prossimo elemento. Se nessun elemento era referenziato prima, imposta il riferimento al primo elemento disponibile. Se è stato raggiunto la fine del contenitore, non fa nulla.

```cpp
virtual bool System::Collections::Generic::IEnumerator<T>::MoveNext()=0
```


### Valore di ritorno

True se qualche elemento è disponibile dopo la chiamata, false altrimenti.
