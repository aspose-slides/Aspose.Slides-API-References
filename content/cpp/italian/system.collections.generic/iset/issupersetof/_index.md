## ISet::IsSupersetOf(IEnumerablePtr) metodo

Verifica se l'insieme corrente è un superset di un altro contenitore.

```cpp
virtual bool System::Collections::Generic::ISet<T>::IsSupersetOf(IEnumerablePtr other)=0
```

### Argomenti

| Parameter | Type | Description |
| --- | --- | --- |
| other | [IEnumerablePtr](../ienumerableptr/) | Sottoinsieme contro cui verificare. |

### Valore di ritorno

Vero se tutti gli elementi in **other** sono presenti nell'insieme, falso altrimenti.
