## ISet::IsSubsetOf(IEnumerablePtr) metodo

Verifica se il set corrente è un sottoinsieme di un altro contenitore.

```cpp
virtual bool System::Collections::Generic::ISet<T>::IsSubsetOf(IEnumerablePtr other)=0
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| other | [IEnumerablePtr](../ienumerableptr/) | Superinsieme da verificare. |

### Valore di ritorno

True se tutti gli elementi nel set corrente sono presenti in **other**, false altrimenti.
