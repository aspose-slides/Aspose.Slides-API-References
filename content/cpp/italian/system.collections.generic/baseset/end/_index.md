## BaseSet::end() const metodo

Restituisce un iteratore per un elemento non esistente situato dopo la fine della collezione qualificata come const.

```cpp
const_iterator System::Collections::Generic::BaseSet<T, SET_T>::end() const noexcept
```

### Valore di ritorno

Un iteratore che punta all'elemento teorico posizionato dopo l'elemento di fine nella istanza qualificata come const del set hash.
