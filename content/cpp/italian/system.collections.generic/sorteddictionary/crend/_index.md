## SortedDictionary::crend() const metodo

Restituisce un iteratore inverso per un elemento non esistente qualificato const prima dell'inizio della collezione.

```cpp
const_reverse_iterator System::Collections::Generic::SortedDictionary<TKey, TValue>::crend() const noexcept
```

### Valore di ritorno

Un iteratore inverso che punta all'elemento teorico qualificato const che precede il primo elemento nella mappa (ultimo in ordine inverso).
