## SortedDictionary::rend() metodo

Restituisce un iteratore inverso per un elemento non esistente prima dell'inizio della raccolta.

```cpp
reverse_iterator System::Collections::Generic::SortedDictionary<TKey, TValue>::rend() noexcept
```

### Valore di ritorno

Un iteratore inverso che punta all'elemento teorico precedente il primo elemento nella mappa (ultimo in ordine inverso).

## SortedDictionary::rend() const metodo

Restituisce un iteratore inverso per un elemento non esistente prima dell'inizio della raccolta qualificata come const.

```cpp
const_reverse_iterator System::Collections::Generic::SortedDictionary<TKey, TValue>::rend() const noexcept
```

### Valore di ritorno

Un iteratore inverso che punta all'elemento teorico precedente il primo elemento nella mappa qualificata come const (ultimo in ordine inverso).
