## IDictionary::TryGetValue(const TKey\&, TValue\&) const method


Cerca il valore e lo recupera se trovato.

```cpp
virtual bool System::Collections::Generic::IDictionary<TKey, TValue>::TryGetValue(const TKey &key, TValue &value) const =0
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| key | const TKey\& | Chiave da cercare. |
| value | TValue\& | Riferimento dove memorizzare il valore recuperato. |

### Valore di ritorno

true se il valore è stato trovato e recuperato, false altrimenti.
