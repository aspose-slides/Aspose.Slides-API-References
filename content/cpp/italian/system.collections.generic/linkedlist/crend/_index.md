## LinkedList::crend() const metodo


Restituisce un iteratore inverso per un elemento non esistente qualificato come const prima dell'inizio della collezione.

```cpp
const_reverse_iterator System::Collections::Generic::LinkedList<T>::crend() const noexcept
```


### Valore restituito

Un iteratore inverso che punta all'elemento teorico qualificato come const precedente al primo elemento nella lista collegata (ultimo in ordine inverso).
