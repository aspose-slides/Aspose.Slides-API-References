## BaseDictionary::begin() const metodo


Restituisce un iteratore al KVPair-wrapper per l'elemento chiave-valore del contenitore. Implementato nello stile C# - l'iteratore dovrebbe restituire l'oggetto KVPair con l'interfaccia get_Key() e get_Value(). Se il contenitore è vuoto, l'iteratore restituito sarà uguale a [end()](../../ienumerable/end/).

```cpp
const_iterator System::Collections::Generic::BaseDictionary<Map>::begin() const noexcept
```


### Valore di ritorno

Un iteratore che punta al primo elemento della raccolta.
