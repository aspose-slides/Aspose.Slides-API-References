## BaseDictionary::cbegin() const metodo


Restituisce un iteratore al primo elemento del contenitore. Implementato in stile STL. Se il contenitore è vuoto, l'iteratore restituito sarà uguale a [end()](../../ienumerable/end/).

```cpp
stl_const_iterator System::Collections::Generic::BaseDictionary<Map>::cbegin() const noexcept
```


### Valore di ritorno

Un iteratore che punta al primo elemento della collezione qualificato const.
