## BaseDictionary::end() const metodo

Restituisce un iteratore al KVPair-wrapper per l'elemento chiave-valore che segue l'ultimo elemento del contenitore. Implementato in stile C# - l'iteratore dovrebbe restituire il KVPair-object con l'interfaccia get_Key() e get_Value(). Questo elemento funge da segnaposto; provare ad accedervi genera un comportamento indefinito.

```cpp
const_iterator System::Collections::Generic::BaseDictionary<Map>::end() const noexcept
```

### Valore di ritorno

Un iteratore che punta all'elemento teorico posizionato dopo l'elemento di fine della collezione.
