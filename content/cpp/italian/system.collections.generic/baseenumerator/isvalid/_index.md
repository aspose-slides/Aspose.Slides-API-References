## BaseEnumerator::IsValid() const metodo

Verifica se [MoveNext()](../movenext/) è stato chiamato e se la fine non è stata raggiunta.

```cpp
bool System::Collections::Generic::BaseEnumerator<Container, Element>::IsValid() const
```

### Valore di ritorno

false se [MoveNext()](../movenext/) non è stato chiamato affatto o se la fine del contenitore è stata raggiunta; true altrimenti.
