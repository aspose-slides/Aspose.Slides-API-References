## ChartCategory::get_UseCell() metodo

Se true allora la proprietà AsCell è effettiva. In altre parole, il foglio di lavoro è utilizzato per memorizzare la categoria (questo caso supporta una categoria a più livelli). Se false allora la proprietà AsLiteral è effettiva. In altre parole, il foglio di lavoro NON è utilizzato per memorizzare la categoria (e questo caso non supporta categorie a più livelli). Solo lettura **bool**.

```cpp
bool Aspose::Slides::Charts::ChartCategory::get_UseCell() override
```

## Osservazioni

Per modificare il valore di questa proprietà (per tutte le categorie nella collezione) impostare il nuovo valore sulla proprietà ChartCategoryCollection::get(set)_UseCells.
