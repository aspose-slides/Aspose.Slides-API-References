## IDataLabelFormat::set_ShowPercentage(bool) metodo


Rappresenta il comportamento di visualizzazione del valore percentuale dell'etichetta dati di un grafico specificato. True visualizza il valore percentuale. False per nascondere. Scrivi **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowPercentage(bool value)=0
```

## Osservazioni


Se il genitore di questo oggetto [DataLabelFormat](../../datalabelformat/) è una collezione [DataLabelCollection](../../datalabelcollection/) di etichette dati, allora questa proprietà ottiene o imposta il valore predefinito della proprietà ShowPercentage per le nuove etichette dati nella collezione [DataLabelCollection](../../datalabelcollection/). Impostare questa proprietà con un valore imposta anche questo valore nella proprietà ShowPercentage per tutte le etichette dati nella collezione [DataLabelCollection](../../datalabelcollection/) (ad esempio \"DataLabels.DefaultDataLabelFormat.ShowPercentage = val;\" fa sì che tutti i DataLabels[i].ShowPercentage siano uguali a val).
