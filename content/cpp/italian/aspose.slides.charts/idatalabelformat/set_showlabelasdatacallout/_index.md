## IDataLabelFormat::set_ShowLabelAsDataCallout(bool) method

Determina se l'etichetta dei dati del grafico specificato verrà visualizzata come data callout o come etichetta dei dati.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowLabelAsDataCallout(bool value)=0
```
## Note

Se il genitore di questo [DataLabelFormat](../../datalabelformat/) oggetto è una collezione [DataLabelCollection](../../datalabelcollection/) di etichette dei dati, allora questa proprietà ottiene o imposta il valore predefinito della proprietà ShowLabelAsDataCallout per le nuove etichette dei dati nella collezione [DataLabelCollection](../../datalabelcollection/). Impostare questa proprietà con valore imposta anche questo valore sulla proprietà ShowLabelAsDataCallout per tutte le etichette dei dati nella collezione [DataLabelCollection](../../datalabelcollection/) (i.e. \"DataLabels.DefaultDataLabelFormat.ShowLabelAsDataCallout = val;\" cause to all DataLabels[i].ShowLabelAsDataCallout is equal to val).
