## IDataLabelFormat::set_ShowValue(bool) metodo


Rappresenta il comportamento di visualizzazione del valore percentuale dell'etichetta dati di un grafico specificato. True visualizza il valore percentuale. False lo nasconde. Scrivi **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowValue(bool value)=0
```

## Osservazioni


Se il genitore di questo [DataLabelFormat](../../datalabelformat/) oggetto è una [DataLabelCollection](../../datalabelcollection/) raccolta di etichette dati, questa proprietà ottiene o imposta il valore predefinito della proprietà ShowValue per le nuove etichette dati nella [DataLabelCollection](../../datalabelcollection/) raccolta. Impostare questa proprietà con valore imposta anche questo valore alla proprietà ShowValue per tutte le etichette dati nella [DataLabelCollection](../../datalabelcollection/) raccolta (cioè \"DataLabels.DefaultDataLabelFormat.ShowValue = val;\" causa che tutti DataLabels[i].ShowValue siano uguali a val).
