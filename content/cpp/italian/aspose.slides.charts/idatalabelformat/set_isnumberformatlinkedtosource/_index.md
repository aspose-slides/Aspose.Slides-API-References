## Osservazioni


Se il genitore di questo [DataLabelFormat](../../datalabelformat/) oggetto è una [DataLabelCollection](../../datalabelcollection/) collezione di etichette dati, questa proprietà ottiene o imposta il valore predefinito della proprietà IsNumberFormatLinkedToSource per le nuove etichette dati nella [DataLabelCollection](../../datalabelcollection/) collezione. Impostare questa proprietà con valore imposta anche questo valore alla proprietà IsNumberFormatLinkedToSource per tutte le etichette dati nella [DataLabelCollection](../../datalabelcollection/) collezione (ad esempio "DataLabels.DefaultDataLabelFormat.IsNumberFormatLinkedToSource = val;" causa che tutti DataLabels[i].IsNumberFormatLinkedToSource siano uguali a val).
