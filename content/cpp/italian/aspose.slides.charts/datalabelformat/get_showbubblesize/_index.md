## DataLabelFormat::get_ShowBubbleSize() metodo


Rappresenta il comportamento di visualizzazione del valore della dimensione della bolla dell’etichetta dati di un grafico specificato. True visualizza il valore della dimensione della bolla. False lo nasconde. Leggi **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowBubbleSize() override
```

## Osservazioni


Se il genitore di questo oggetto [DataLabelFormat](../) è una raccolta [DataLabelCollection](../../datalabelcollection/) di etichette dati, allora questa proprietà ottiene o imposta il valore predefinito della proprietà ShowBubbleSize per le nuove etichette dati nella raccolta [DataLabelCollection](../../datalabelcollection/). Impostare questa proprietà con un valore imposta anche questo valore alla proprietà ShowBubbleSize per tutte le etichette dati nella raccolta [DataLabelCollection](../../datalabelcollection/) (cioè \"DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;\" fa sì che tutti DataLabels[i].ShowBubbleSize siano uguali a val).
