## DataLabelFormat::set_ShowPercentage(bool) metodo


Rappresenta il comportamento di visualizzazione del valore percentuale dell'etichetta dei dati di un grafico specificato. True visualizza il valore percentuale. False per nascondere. Scrivi **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowPercentage(bool value) override
```

## Osservazioni


Se il genitore di questo [DataLabelFormat](../) oggetto è una [DataLabelCollection](../../datalabelcollection/) collezione di etichette dei dati, questa proprietà ottiene o imposta il valore predefinito della ShowPercentage proprietà per le nuove etichette dei dati nella [DataLabelCollection](../../datalabelcollection/) collezione. Impostare questa proprietà con un valore imposta anche questo valore alla ShowPercentage proprietà per tutte le etichette dei dati nella [DataLabelCollection](../../datalabelcollection/) collezione (ad es. \"DataLabels.DefaultDataLabelFormat.ShowPercentage = val;\" causa che tutti DataLabels[i].ShowPercentage siano uguali a val).
