## DataLabelFormat::get_ShowCategoryName() metodo

Rappresenta il comportamento di visualizzazione del nome della categoria dell’etichetta dei dati di un grafico specificato. True per visualizzare il nome della categoria per le etichette dei dati su un grafico. False per nascondere. Leggi **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowCategoryName() override
```

## Osservazioni

Se il genitore di questo [DataLabelFormat](../) oggetto è una raccolta [DataLabelCollection](../../datalabelcollection/) di etichette dei dati, allora questa proprietà ottiene o imposta il valore predefinito della proprietà ShowCategoryName per le nuove etichette dei dati nella raccolta [DataLabelCollection](../../datalabelcollection/). Impostare questa proprietà con un valore imposta anche questo valore alla proprietà ShowCategoryName per tutte le etichette dei dati nella raccolta [DataLabelCollection](../../datalabelcollection/) (ad es. "DataLabels.DefaultDataLabelFormat.ShowCategoryName = val;" provoca che tutti DataLabels[i].ShowCategoryName siano uguali a val).
