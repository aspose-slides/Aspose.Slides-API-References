## DataLabelFormat::get_IsNumberFormatLinkedToSource() method

Lettura **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_IsNumberFormatLinkedToSource() override
```

## Osservazioni

Se il genitore di questo oggetto [DataLabelFormat](../) è una raccolta [DataLabelCollection](../../datalabelcollection/) di etichette dati, questa proprietà ottiene o imposta il valore predefinito della proprietà IsNumberFormatLinkedToSource per le nuove etichette dati nella raccolta [DataLabelCollection](../../datalabelcollection/). Impostare questa proprietà con un valore imposta anche questo valore alla proprietà IsNumberFormatLinkedToSource per tutte le etichette dati nella raccolta [DataLabelCollection](../../datalabelcollection/) (ad esempio "DataLabels.DefaultDataLabelFormat.IsNumberFormatLinkedToSource = val;" provoca che tutti DataLabels[i].IsNumberFormatLinkedToSource sia uguale a val).
