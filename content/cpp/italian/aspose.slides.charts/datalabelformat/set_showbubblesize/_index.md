## DataLabelFormat::set_ShowBubbleSize(bool) metodo


Rappresenta il comportamento di visualizzazione del valore della dimensione della bolla dell'etichetta dati di un grafico specificato. True visualizza il valore della dimensione della bolla. False lo nasconde. Scrivi **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowBubbleSize(bool value) override
```

## Note


Se il genitore di questo oggetto [DataLabelFormat](../) è una raccolta [DataLabelCollection](../../datalabelcollection/) di etichette dati, questa proprietà ottiene o imposta il valore predefinito della proprietà ShowBubbleSize per le nuove etichette dati nella raccolta [DataLabelCollection](../../datalabelcollection/). Impostare questa proprietà con un valore imposta anche questo valore sulla proprietà ShowBubbleSize per tutte le etichette dati nella raccolta [DataLabelCollection](../../datalabelcollection/) (ad esempio "DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;" fa sì che tutti DataLabels[i].ShowBubbleSize siano uguali a val).
