## DataLabelFormat::get_ShowSeriesName() metodo

Restituisce un Boolean per indicare il comportamento di visualizzazione del nome della serie per le etichette dati su un grafico. True per mostrare il nome della serie. False per nascondere. Leggi **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowSeriesName() override
```

## Osservazioni

Se il genitore di questo [DataLabelFormat](../) oggetto è una raccolta [DataLabelCollection](../../datalabelcollection/) di etichette dati, allora questa proprietà ottiene o imposta il valore predefinito della proprietà ShowSeriesName per le nuove etichette dati nella raccolta [DataLabelCollection](../../datalabelcollection/). Impostare questa proprietà con valore imposta anche questo valore alla proprietà ShowSeriesName per tutte le etichette dati nella raccolta [DataLabelCollection](../../datalabelcollection/) (ad es. "DataLabels.DefaultDataLabelFormat.ShowSeriesName = val;" causa che tutti DataLabels[i].ShowSeriesName siano uguali a val).
