## DataLabelFormat::get_Position() metodo


Rappresenta la posizione dell'etichetta dati. Leggi [LegendDataLabelPosition](../../legenddatalabelposition/).

```cpp
LegendDataLabelPosition Aspose::Slides::Charts::DataLabelFormat::get_Position() override
```

## Osservazioni


Se il genitore di questo oggetto [DataLabelFormat](../) è una raccolta [DataLabelCollection](../../datalabelcollection/) di etichette dati, allora questa proprietà ottiene o imposta il valore predefinito della proprietà Position per le nuove etichette dati nella raccolta [DataLabelCollection](../../datalabelcollection/). Rappresenta la posizione per gli oggetti [DataLabel](../../datalabel/). Impostare questa proprietà con un valore imposta anche questo valore sulla proprietà Position per tutte le etichette dati nella raccolta [DataLabelCollection](../../datalabelcollection/) (ad es. "DataLabels.DefaultDataLabelFormat.Position = val;" fa sì che tutti DataLabels[i].Position sia uguale a val).
