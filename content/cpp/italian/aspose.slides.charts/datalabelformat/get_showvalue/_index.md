## DataLabelFormat::get_ShowValue() metodo


Rappresenta il comportamento di visualizzazione del valore percentuale dell'etichetta dati di un grafico specificato. True visualizza il valore percentuale. False per nascondere. Leggi **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowValue() override
```

## Osservazioni


Se il genitore di questo oggetto [DataLabelFormat](../) è una raccolta [DataLabelCollection](../../datalabelcollection/) di etichette dati, allora questa proprietà ottiene o imposta il valore predefinito della proprietà ShowValue per le nuove etichette dati nella raccolta [DataLabelCollection](../../datalabelcollection/). Impostare questa proprietà con un valore imposta anche questo valore sulla proprietà ShowValue per tutte le etichette dati nella raccolta [DataLabelCollection](../../datalabelcollection/) (ad es. \"DataLabels.DefaultDataLabelFormat.ShowValue = val;\" causa che tutti DataLabels[i].ShowValue siano uguali a val).
