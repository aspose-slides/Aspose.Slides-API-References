## DataLabelFormat::get_Separator() method


Imposta o restituisce un Variant che rappresenta il separatore utilizzato per le etichette dei dati in un grafico. Leggi [System::String](../../../system/string/).

```cpp
System::String Aspose::Slides::Charts::DataLabelFormat::get_Separator() override
```

## Osservazioni


Se il genitore di questo [DataLabelFormat](../) oggetto è una [DataLabelCollection](../../datalabelcollection/) raccolta di etichette dei dati, questa proprietà ottiene o imposta il valore predefinito della proprietà Separator per le nuove etichette dei dati nella [DataLabelCollection](../../datalabelcollection/) raccolta. Impostare questa proprietà con un valore imposta anche questo valore alla proprietà Separator per tutte le etichette dei dati nella [DataLabelCollection](../../datalabelcollection/) raccolta (ad esempio "DataLabels.DefaultDataLabelFormat.Separator = val;" provoca che tutti i DataLabels[i].Separator siano uguali a val).
