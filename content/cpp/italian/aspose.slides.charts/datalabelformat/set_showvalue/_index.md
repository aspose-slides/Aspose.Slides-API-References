## DataLabelFormat::set_ShowValue(bool) metodo

Rappresenta il comportamento di visualizzazione del valore percentuale dell'etichetta dati di un grafico specificato. True visualizza il valore percentuale. False per nascondere. Scrivi **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowValue(bool value) override
```

## Osservazioni

Se il genitore di questo oggetto [DataLabelFormat](../) è una collezione [DataLabelCollection](../../datalabelcollection/) di etichette dati, questa proprietà ottiene o imposta il valore predefinito della proprietà ShowValue per le nuove etichette dati nella collezione [DataLabelCollection](../../datalabelcollection/). Impostare questa proprietà con un valore imposta anche questo valore alla proprietà ShowValue per tutte le etichette dati nella collezione [DataLabelCollection](../../datalabelcollection/) (ad esempio "DataLabels.DefaultDataLabelFormat.ShowValue = val;" causa che tutti DataLabels[i].ShowValue siano uguali a val).
