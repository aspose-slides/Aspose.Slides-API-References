## ParentLabelLayoutType enum

Rappresenta il layout delle etichette dei dati di categoria. Utilizzato solo con le serie Treemap.

```cpp
enum class ParentLabelLayoutType
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Banner | 0 | Specifica che le etichette della categoria padre vengono visualizzate come banner |
| None | 1 | Specifica che le etichette della categoria padre non vengono disegnate |
| Overlapping | 2 | Specifica che le etichette della categoria padre vengono visualizzate come sovrapposte |
