## ChartSeries::get_HasSeriesLines() metodo

Determina se esistono linee di serie per questa serie e le serie correlate. Questa proprietà non è solo di questa serie ma di tutte le serie del gruppo di serie padre - è una proiezione della proprietà di gruppo appropriata. Pertanto questa proprietà è di sola lettura. Utilizza la proprietà ParentSeriesGroup per accedere al gruppo di serie padre. Usa la proprietà [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_HasSeriesLines() di lettura/scrittura per modificare il valore. Usa la proprietà ParentSeriesGroup.SeriesLinesFormat per formattare le linee di serie. Solo lettura **bool**.

```cpp
bool Aspose::Slides::Charts::ChartSeries::get_HasSeriesLines() override
```

## Note

Questa è la proiezione della proprietà [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_HasSeriesLines().
