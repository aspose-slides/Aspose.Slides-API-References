## enumerazione DataSourceType

Tipi di origine dati.

```cpp
enum class DataSourceType
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Worksheet | 0 | Utilizzare gli oggetti CellXls per memorizzare XValue, YValue, Value o BubbleSize del punto dati nel foglio di lavoro. |
| StringLiterals | 1 | Utilizzare una variabile stringa ad accesso rapido per memorizzare XValue, YValue, Value o BubbleSize del punto dati. Il foglio di lavoro NON viene utilizzato per memorizzare i valori. |
| DoubleLiterals | 2 | Utilizzare una variabile double ad accesso rapido per memorizzare XValue, YValue, Value o BubbleSize del punto dati. Il foglio di lavoro NON viene utilizzato per memorizzare i valori. |
