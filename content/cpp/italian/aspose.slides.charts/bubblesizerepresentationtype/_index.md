## BubbleSizeRepresentationType enum


Specifica i possibili modi per rappresentare i dati come dimensioni di un grafico a bolle.

```cpp
enum class BubbleSizeRepresentationType
```

### Valori

| Name | Value | Description |
| --- | --- | --- |
| Area | 0 | Specifica che l'area delle bolle deve essere proporzionale al valore di dimensione della bolla. |
| Width | 1 | Specifica che il raggio delle bolle deve essere proporzionale al valore di dimensione della bolla. |
