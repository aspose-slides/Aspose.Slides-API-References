## DataLabel::get_IsVisible() metodo

False significa che l'etichetta dei dati non è visibile (e quindi tutti i flag Show*- (ShowValue, ...) sono falsi). Solo lettura **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabel::get_IsVisible() override
```

## Osservazioni

Se l'etichetta dei dati è visibile puoi nasconderla con il metodo [Hide()](../hide/). Ma se l'etichetta dei dati non è visibile (IsVisible è false) puoi renderla visibile impostando i flag Show*- (ShowValue, ...) allo stato true.
