## DataLabel::Hide() metodo


Rendi l'etichetta dei dati nascosta impostando tutti i flag Show*- (ShowValue, ...) allo stato false. IsVisible sarà false dopo questo.

```cpp
void Aspose::Slides::Charts::DataLabel::Hide() override
```

## Osservazioni


Se l'etichetta dei dati non è visibile (IsVisible è false) è possibile rendere l'etichetta dei dati visibile impostando i flag Show*- (ShowValue, ...) allo stato true.
