## IChartSeries::get_HasUpDownBars() metodo

Determina se un grafico a linee o a bolle ha barre su/giù. Questa è la proprietà non solo di questa serie ma di tutte le serie del gruppo di serie genitore — è la proiezione della proprietà di gruppo corrispondente. Pertanto questa proprietà è di sola lettura. Usa la proprietà ParentSeriesGroup per accedere al gruppo di serie genitore. Usa [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get_UpDownBars()->get(set)_HasUpDownBars() proprietà di lettura/scrittura per modificare il valore. Usa la proprietà [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get_UpDownBars() per formattare le barre su/giù. Di sola lettura **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IChartSeries::get_HasUpDownBars()=0
```

## Note

Questa è la proiezione della proprietà [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get_UpDownBars()->get(set)_HasUpDownBars().
