## IChartSeries::get_HasSeriesLines() metodo


Determina se esistono linee di serie per questa serie e le serie correlate. Questa è la proprietà non solo di questa serie ma di tutte le serie del gruppo di serie genitore - è la proiezione della proprietà di gruppo appropriata. Pertanto questa proprietà è sola lettura. Usa la proprietà ParentSeriesGroup per accedere al gruppo di serie genitore. Usa [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_HasSeriesLines() proprietà lettura/scrittura per modificare il valore. Usa la proprietà ParentSeriesGroup.SeriesLinesFormat per formattare le linee di serie. Solo lettura **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IChartSeries::get_HasSeriesLines()=0
```

## Osservazioni


Questa è la proiezione della proprietà [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_HasSeriesLines().
