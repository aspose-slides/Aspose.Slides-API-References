## IChartSeries::get_BubbleSizeScale() metodo


Specifica il fattore di scala per il grafico a bolle (può essere compreso tra 0 e 300 percento della dimensione predefinita). Questa è la proprietà non solo di questa serie ma di tutte le serie del gruppo di serie padre – è la proiezione della proprietà di gruppo appropriata. Pertanto questa proprietà è di sola lettura. Usa la proprietà ParentSeriesGroup per accedere al gruppo di serie padre. Usa [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_BubbleSizeScale() proprietà read/write per modificare il valore.

```cpp
virtual int32_t Aspose::Slides::Charts::IChartSeries::get_BubbleSizeScale()=0
```

## Osservazioni


Questa è la proiezione della proprietà [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_BubbleSizeScale().
