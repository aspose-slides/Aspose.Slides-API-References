## IChartSeries::get_PieSplitPosition() metodo

Specifica un valore da utilizzare per determinare quali punti dati si trovano nella seconda fetta o barra in un grafico a torta di torta o a barra di torta. Viene utilizzato insieme alla proprietà PieSplitBy. Questa è la proprietà non solo di questa serie ma di tutte le serie del gruppo di serie genitore – è la proiezione della proprietà di gruppo appropriata. Pertanto questa proprietà è solo lettura. Utilizzare la proprietà ParentSeriesGroup per accedere al gruppo di serie genitore. Utilizzare [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_PieSplitPosition() proprietà lettura/scrittura per modificare il valore. Solo lettura **double**.

```cpp
virtual double Aspose::Slides::Charts::IChartSeries::get_PieSplitPosition()=0
```

## Osservazioni

Questa è la proiezione della proprietà [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_PieSplitPosition().
