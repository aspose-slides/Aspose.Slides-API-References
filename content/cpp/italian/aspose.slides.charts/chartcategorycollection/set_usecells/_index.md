## ChartCategoryCollection::set_UseCells(bool) metodo

Se true allora il foglio di lavoro è usato per memorizzare le categorie (questo caso supporta categorie a più livelli). Se false allora il foglio di lavoro NON è usato per memorizzare i valori (e questo caso non supporta categorie a più livelli). Scrivi **bool**.

void Aspose::Slides::Charts::ChartCategoryCollection::set_UseCells(bool value) override
