## IDataLabelCollection::Hide() metodo

Rendi l'etichetta dati nascosta per impostazione predefinita impostando tutti i flag Show*- (ShowValue, ...) della proprietà DefaultDataLabelFormat su false. IsVisible sarà false dopo questa operazione.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelCollection::Hide()=0
```

## Osservazioni

Se l'etichetta dati non è visibile per impostazione predefinita (IsVisible è false) è possibile rendere l'etichetta dati \"visible \nby default\" impostando i flag Show*- (ShowValue, ...) della proprietà DefaultDataLabelFormat su true.
