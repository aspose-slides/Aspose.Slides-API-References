## TrendlineType enum

Rappresenta il tipo di linea di tendenza

```cpp
enum class TrendlineType
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Exponential | 0 | Specifica che la trendline deve essere una curva esponenziale nella forma. |
| Linear | 1 | Specifica che la trendline deve essere una linea nella forma. |
| Logarithmic | 2 | Specifica che la trendline deve essere una curva logaritmica nella forma, dove log è il logaritmo naturale. |
| MovingAverage | 3 | Specifica che la trendline deve essere una media mobile del periodo Period. |
| Polynomial | 4 | Specifica che la trendline deve essere una curva polinomiale di ordine Order nella forma. |
| Power | 5 | Specifica che la trendline deve essere una curva di potenza nella forma. |
