## IChartCategoryCollection::set_UseCells(bool) metodo

Se vero, il foglio di lavoro viene utilizzato per memorizzare le categorie (questo caso supporta categorie a più livelli). Se falso, il foglio di lavoro NON viene utilizzato per memorizzare i valori (e questo caso non supporta categorie a più livelli). Scrivi **bool**.
