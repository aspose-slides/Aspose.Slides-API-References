## DataLabelCollection::Hide() metodo

Rendi l'etichetta dati nascosta per impostazione predefinita impostando tutti i flag Show*- (ShowValue, ...) della proprietà DefaultDataLabelFormat su stato false. IsVisible sarà false dopo questa operazione.

```cpp
void Aspose::Slides::Charts::DataLabelCollection::Hide() override
```

## Osservazioni

Se l'etichetta dati non è visibile per impostazione predefinita (IsVisible è false) è possibile rendere l'etichetta dati \"visibile \nper impostazione predefinita\" impostando i flag Show*- (ShowValue, ...) della proprietà DefaultDataLabelFormat su stato true.
