## DataLabelCollection::get_IsVisible() metodo

False indica che l'etichetta dei dati non è visibile per impostazione predefinita (e quindi tutti i flag Show*-flags (ShowValue, ...) della proprietà DefaultDataLabelFormat sono false). Sola lettura **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelCollection::get_IsVisible() override
```

## Osservazioni

Se l'etichetta dei dati è visibile per impostazione predefinita, è possibile nasconderla per impostazione predefinita con il metodo [Hide()](../hide/). Ma se l'etichetta dei dati non è visibile per impostazione predefinita (IsVisible è false) è possibile rendere l'etichetta dei dati "visibile per impostazione predefinita" impostando i flag Show*-flags (ShowValue, ...) della proprietà DefaultDataLabelFormat allo stato true.
