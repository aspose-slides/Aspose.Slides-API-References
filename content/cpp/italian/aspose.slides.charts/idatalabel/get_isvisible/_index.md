## IDataLabel::get_IsVisible() metodo

False indica che l'etichetta dei dati non è visibile (e quindi tutti i flag Show*-flags (ShowValue, ...) sono false). Solo lettura **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabel::get_IsVisible()=0
```

## Osservazioni

Se l'etichetta dei dati è visibile puoi nasconderla con il metodo [Hide()](../hide/). Ma se l'etichetta dei dati non è visibile (IsVisible è false) puoi rendere visibile l'etichetta dei dati impostando i flag Show*-flags (ShowValue, ...) allo stato true.
