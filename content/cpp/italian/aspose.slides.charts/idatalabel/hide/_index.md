## IDataLabel::Hide() metodo

Rende l'etichetta dei dati nascosta impostando tutti i flag Show*- (ShowValue, ...) nello stato false. IsVisible sarà false dopo questa operazione.

```cpp
virtual void Aspose::Slides::Charts::IDataLabel::Hide()=0
```

## Osservazioni

Se l'etichetta dei dati non è visibile (IsVisible è false) è possibile renderla visibile impostando i flag Show*- (ShowValue, ...) nello stato true.
