## BaseChartValue::get_DataSourceType() metodo

Specifica se la proprietà AsCell, AsCells, AsLiteralString o AsLiteralDouble è effettiva nelle classi discendenti. In altre parole specifica il tipo di valore della proprietà Data. Leggi [Charts::DataSourceType](../../datasourcetype/).

```cpp
Aspose::Slides::Charts::DataSourceType Aspose::Slides::Charts::BaseChartValue::get_DataSourceType() override
```

## Osservazioni

Per i punti in [ChartDataPointCollection](../../chartdatapointcollection/) questa proprietà è di sola lettura. In questo caso, per modificare il valore di questa proprietà è possibile utilizzare una delle proprietà ChartDataPointCollection.DataSourceTypeFor<...>.
