## BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType) metodo

Specifica se la proprietà AsCell, AsCells, AsLiteralString o AsLiteralDouble è effettiva nei discendenti. In altre parole specifica il tipo di valore della proprietà Data. Scrivi [Charts::DataSourceType](../../datasourcetype/).

```cpp
void Aspose::Slides::Charts::BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType value) override
```

## Osservazioni

Per i punti in [ChartDataPointCollection](../../chartdatapointcollection/) questa proprietà è di sola lettura. In questo caso, per modificare il valore di questa proprietà puoi usare una delle proprietà ChartDataPointCollection.DataSourceTypeFor<...>.
