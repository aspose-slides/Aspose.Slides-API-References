## ChartTypeCharacterizer::IsChartTypeScatter(ChartType) metodo

Restituisce true se chartType è uno dei sottotipi Scatter. Il set di sottotipi corrisponde al set appropriato in PowerPoint (vedi la finestra di dialogo "Change Chart Type" in PowerPoint): [ChartType::ScatterWithMarkers](../../charttype/), [ChartType::ScatterWithSmoothLines](../../charttype/), [ChartType::ScatterWithSmoothLinesAndMarkers](../../charttype/), [ChartType::ScatterWithStraightLines](../../charttype/), [ChartType::ScatterWithStraightLinesAndMarkers](../../charttype/).
