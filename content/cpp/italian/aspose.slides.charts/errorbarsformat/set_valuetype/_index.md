## ErrorBarsFormat::set_ValueType(ErrorBarValueType) metodo

Rappresenta i possibili modi per determinare la lunghezza delle barre di errore. In caso di tipo di valore personalizzato per specificare il valore, utilizzare la proprietà [IChartDataPoint::get_ErrorBarsCustomValues()](../../ichartdatapoint/get_errorbarscustomvalues/) del punto dati specifico nella raccolta DataPoints della serie. In caso di tipo di valore Fixed, Percentage o StandardDeviation, utilizzare la proprietà Value per specificare il valore.

Scrivi [ErrorBarValueType](../../errorbarvaluetype/).
