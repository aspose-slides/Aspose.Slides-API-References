## ErrorBarsFormat::get_ValueType() metodo

Rappresenta i possibili modi per determinare la lunghezza delle barre di errore. Nel caso di tipo di valore personalizzato, utilizzare la proprietà [IChartDataPoint::get_ErrorBarsCustomValues()](../../ichartdatapoint/get_errorbarscustomvalues/) del punto dati specifico nella collezione DataPoints di series. Nel caso di tipo di valore Fixed, Percentage o StandardDeviation, utilizzare la proprietà Value per specificare il valore.

Leggi [ErrorBarValueType](../../errorbarvaluetype/).
