## TickLabelPositionType enum

Rappresenta il tipo di posizione delle etichette dei segni di graduazione sull'asse specificato.

```cpp
enum class TickLabelPositionType
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| High | 0 | Specifica che le etichette dell'asse devono trovarsi all'estremità alta dell'asse perpendicolare. |
| Low | 1 | Specifica che le etichette dell'asse devono trovarsi all'estremità bassa dell'asse perpendicolare. |
| NextTo | 2 | Specifica che le etichette dell'asse devono trovarsi accanto all'asse. |
| None | 3 | Specifica che le etichette dell'asse non vengono disegnate. |
