## IChartCategory::get_UseCell() metodo

Se vero, la proprietà AsCell è effettiva. In altre parole, il foglio di calcolo è usato per memorizzare la categoria (questo caso supporta una categoria a più livelli). Se falso, la proprietà AsLiteral è effettiva. In altre parole, il foglio di calcolo NON è usato per memorizzare la categoria (e questo caso non supporta categorie a più livelli). Solo lettura **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IChartCategory::get_UseCell()=0
```

## Osservazioni

Per modificare il valore di questa proprietà (per tutte le categorie nella raccolta) impostare il nuovo valore nella proprietà ChartCategoryCollection.UseCells.
