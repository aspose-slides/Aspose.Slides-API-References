## IBaseChartValue::get_DataSourceType() metodo

Specifica se la proprietà AsCell o AsLiteralString o AsLiteralDouble è attuale. In altre parole specifica il tipo di valore della proprietà Data. Questa proprietà è di sola lettura. Per modificare il valore di questa proprietà puoi usare una delle proprietà ChartDataPointCollection.DataSourceTypeFor<...>. Leggi [DataSourceType](../../datasourcetype/).
