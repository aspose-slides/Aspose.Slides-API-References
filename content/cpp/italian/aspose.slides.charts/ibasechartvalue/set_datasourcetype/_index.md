## IBaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType) metodo

Specifica se la proprietà AsCell o AsLiteralString o AsLiteralDouble è effettiva. In altre parole, specifica il tipo di valore della proprietà Data. Questa proprietà è di sola lettura. Per modificare il valore di questa proprietà, è possibile utilizzare una delle proprietà ChartDataPointCollection.DataSourceTypeFor<...>. Scrivi [DataSourceType](../../datasourcetype/).
