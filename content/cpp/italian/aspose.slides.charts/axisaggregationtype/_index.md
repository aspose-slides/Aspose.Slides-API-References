## AxisAggregationType enum

Rappresenta il tipo di aggregazione dell'asse di categoria. Utilizzato solo con le serie Histogram o HistogramPareto.

```cpp
enum class AxisAggregationType
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| ByCategory | 0 | Aggrega per categorie |
| Automatic | 1 | Aggrega le categorie automaticamente. |
| ByBinWidth | 2 | Aggrega le categorie per larghezza del contenitore. Property IAxis::get(set)_BinWidth must be setted. |
| ByNumberOfBins | 3 | Aggrega le categorie per numero di contenitori. Property IAxis::get(set)_NumberOfBins must be setted. |
