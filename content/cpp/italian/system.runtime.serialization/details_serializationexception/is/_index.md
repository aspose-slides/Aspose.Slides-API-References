## Details_SerializationException::Is(const System::TypeInfo\&) const metodo




```cpp
bool System::Runtime::Serialization::Details_SerializationException::Is(const System::TypeInfo &target) const override
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| target | const [System::TypeInfo](../../../system/typeinfo/)\& | [TypeInfo](../../../system/typeinfo/) struttura che descrive il tipo contro cui testare l'oggetto corrente. |

### Valore di ritorno

True se l'oggetto è del tipo contrassegnato o della sua sottoclasse, false altrimenti.
## Note

Verifica se l'oggetto rappresenta un'istanza del tipo descritto da targetType. Analogo dell'operatore C# 'is'.
