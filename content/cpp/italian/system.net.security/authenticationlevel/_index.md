## AuthenticationLevel enum


Flag di autenticazione specifici per WebRequest.

```cpp
enum class AuthenticationLevel
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| None | 0 | Non è richiesta alcuna autenticazione per il client e il server. |
| MutualAuthRequested | 1 | La richiesta non fallisce se il server non è autenticato. |
| MutualAuthRequired | 2 | L'applicazione corrente riceverà 'IOException' quando il server non è autenticato. |
