## SlideShowTransition::set_SoundName(System::String) metodo

Specifica un nome leggibile dall'uomo per il suono della transizione. Il [ISlideShowTransition::set_Sound](../../../aspose.slides/islideshowtransition/set_sound/) deve essere assegnato per ottenere o impostare il nome del suono. Scrive [System::String](../../../system/string/).

```cpp
void Aspose::Slides::SlideShow::SlideShowTransition::set_SoundName(System::String value) override
```

## Osservazioni

Questo nome appare nell'interfaccia utente di PowerPoint quando si configura manualmente il suono della transizione.
