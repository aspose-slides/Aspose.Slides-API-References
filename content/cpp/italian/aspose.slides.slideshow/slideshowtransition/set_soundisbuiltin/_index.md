## SlideShowTransition::set_SoundIsBuiltIn(bool) metodo

Specifica se questo suono è un suono incorporato o meno. Se questo attributo è impostato su true l'applicazione generatrice viene avvisata di controllare l'attributo name specificato per questo suono nella sua lista di suoni incorporati e può quindi visualizzare un nome o un'interfaccia personalizzati, se necessario. Scrive **bool**.
