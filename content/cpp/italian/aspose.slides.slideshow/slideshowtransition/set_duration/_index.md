## SlideShowTransition::set_Duration(int32_t) metodo

Imposta la durata dell'effetto di transizione della diapositiva in millisecondi. Scrivi **int32_t**.

```cpp
void Aspose::Slides::SlideShow::SlideShowTransition::set_Duration(int32_t value) override
```

## Osservazioni

Corrisponde all'attributo **p14:dur** dell'elemento **p:transition** nello schema PresentationML. Se non impostata, la durata viene determinata automaticamente in base alla proprietà [Speed](../) e al tipo di transizione.
