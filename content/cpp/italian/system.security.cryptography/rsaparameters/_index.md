## RSAParameters struct


[Data](../../system.data/) struttura dei parametri dell'algoritmo [RSA](../rsa/). Questo tipo dovrebbe essere allocato sullo stack e passato alle funzioni per valore o per riferimento. Non utilizzare mai la classe [System::SmartPtr](../../system/smartptr/) per gestire gli oggetti di questo tipo.

```cpp
class RSAParameters : public System::Object
```
