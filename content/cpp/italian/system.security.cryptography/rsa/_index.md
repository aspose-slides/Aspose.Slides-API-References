## RSA classe

Classe base per le implementazioni dell'algoritmo [RSA](./). Gli oggetti di questa classe dovrebbero essere allocati solo usando la funzione [System::MakeObject()](../../system/makeobject/). Non creare mai un'istanza di questo tipo sullo stack o usando operator new, poiché porterà a errori di esecuzione e/o a fallimenti di asserzione. Avvolgi sempre questa classe in un puntatore [System::SmartPtr](../../system/smartptr/) e usa questo puntatore per passarlo alle funzioni come argomento.

```cpp
class RSA : public System::Security::Cryptography::AsymmetricAlgorithm
```
