## ToBase64Transform classe


Converte l'istanza della classe [CryptoStream](../cryptostream/) in base 64. Gli oggetti di questa classe dovrebbero essere allocati solo utilizzando la funzione [System::MakeObject()](../../system/makeobject/). Non creare mai un'istanza di questo tipo nello stack o utilizzando l'operatore new, poiché ciò provocherà errori di runtime e/o violazioni di asserzione. Avvolgi sempre questa classe in un puntatore [System::SmartPtr](../../system/smartptr/) e utilizza questo puntatore per passarla alle funzioni come argomento.

```cpp
class ToBase64Transform : public System::Security::Cryptography::ICryptoTransform
```
