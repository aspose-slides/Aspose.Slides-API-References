## AsymmetricAlgorithm classe


Abstract base class for asymmetric encryption algorithms. Objects of this classe should only be allocated using [System::MakeObject()](../../system/makeobject/) funzione. Never create instance of this type on stack or using operator new, as it will result in runtime errors and/or assertion faults. Always wrap this classe into [System::SmartPtr](../../system/smartptr/) pointer and use this pointer to pass it to functions as argument.

```cpp
class AsymmetricAlgorithm : public virtual System::Object,
                            public System::IDisposable
```
