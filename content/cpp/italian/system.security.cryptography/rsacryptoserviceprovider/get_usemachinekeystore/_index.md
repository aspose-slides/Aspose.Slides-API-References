## RSACryptoServiceProvider::get_UseMachineKeyStore() metodo


Verifica se la chiave persiste nell'archivio della macchina invece che in quello dell'utente.

```cpp
static bool System::Security::Cryptography::RSACryptoServiceProvider::get_UseMachineKeyStore()
```


### Valore restituito

True se la chiave deve essere conservata nell'archivio della macchina, false se deve essere conservata nell'archivio dell'utente.
