## GraphicsUnit enum

Rappresenta un'unità di misura.

```cpp
enum class GraphicsUnit
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| World | 0 | World coordinate (unità non fisica). |
| Display | 1 | Le unità di misura del dispositivo di visualizzazione. |
| Pixel | 2 | Un pixel del dispositivo. |
| Point | 3 | Un point della stampante (1/72 di un pollice). |
| Inch | 4 | Un pollice. |
| Document | 5 | 1/300 di un pollice. |
| Millimeter | 6 | Un millimetro. |
