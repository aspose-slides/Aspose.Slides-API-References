
## RectangleF::Intersect(const RectangleF\&, const RectangleF\&) metodo


Restituisce un rettangolo che è il risultato dell'intersezione dei rettangoli specificati.

```cpp
static RectangleF System::Drawing::RectangleF::Intersect(const RectangleF &a, const RectangleF &b)
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| a | const [RectangleF](../)\& | Il primo rettangolo da intersecare |
| b | const [RectangleF](../)\& | Il secondo rettangolo da intersecare |

### Valore restituito

Il risultato dell'intersezione di **a** con **b**
