## SizeF::Add(const SizeF\&, const SizeF\&) metodo

Restituisce un nuovo oggetto [SizeF](../) che è la somma degli oggetti [SizeF](../) specificati, cioè il cui valore di larghezza è uguale alla somma dei valori di larghezza degli oggetti specificati e il valore di altezza è uguale alla somma dei valori di altezza degli oggetti specificati.

```cpp
static SizeF System::Drawing::SizeF::Add(const SizeF &size1, const SizeF &size2)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| size1 | const [SizeF](../)\& | Il primo operando |
| size2 | const [SizeF](../)\& | Il secondo operando |

### Valore di ritorno

L'oggetto [SizeF](../) che è la somma di **size1** e **size2**
