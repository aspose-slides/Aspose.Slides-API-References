## SystemColors classe

Classe che fornisce un set di oggetti [Color](../color/) precreati che rappresentano i colori degli elementi di visualizzazione [Windows](../../system.windows/). Questo è un tipo statico senza servizi di istanza. Non dovresti mai creare istanze di esso con alcun mezzo.

```cpp
class SystemColors
```
