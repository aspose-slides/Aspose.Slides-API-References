## StringDigitSubstitute enum

Specifica come le cifre in una stringa vengono sostituite in base alla locale o alla lingua.

```cpp
enum class StringDigitSubstitute
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| User | 0 | Sostituzione definita dall'utente. |
| None | 1 | La sostituzione è disabilitata. |
| National | 2 | Sostituisce le cifre che corrispondono alla lingua nazionale ufficiale della locale dell'utente. |
| Traditional | 3 | Sostituisce le cifre che corrispondono alla scrittura o lingua nativa dell'utente, che può non essere la stessa della lingua nazionale ufficiale della locale dell'utente. |
