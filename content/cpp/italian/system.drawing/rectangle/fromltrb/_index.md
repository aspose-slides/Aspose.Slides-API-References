## Rectangle::FromLTRB(int, int, int, int) metodo


Crea un nuovo oggetto [Rectangle](../) che rappresenta un rettangolo con le posizioni dei bordi specificate.

```cpp
static Rectangle System::Drawing::Rectangle::FromLTRB(int left, int top, int right, int bottom)
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| left | int | La coordinata X del bordo sinistro del rettangolo |
| top | int | La coordinata Y del bordo superiore del rettangolo |
| right | int | La coordinata X del bordo destro del rettangolo |
| bottom | int | La coordinata Y del bordo inferiore del rettangolo |

### Valore di ritorno

Un'istanza della classe [Rectangle](../) che rappresenta il rettangolo specificato
