## Rectangle::get_IsEmpty() const metodo

Determina se le coordinate X e Y dell'angolo superiore sinistro del rettangolo rappresentato dall'oggetto corrente, nonché la sua larghezza e altezza, hanno valore 0.

```cpp
bool System::Drawing::Rectangle::get_IsEmpty() const
```

### Valore di ritorno

True se le coordinate X e Y dell'angolo superiore sinistro del rettangolo rappresentato dall'oggetto corrente, nonché la sua larghezza e altezza, hanno valore 0, altrimenti - false
