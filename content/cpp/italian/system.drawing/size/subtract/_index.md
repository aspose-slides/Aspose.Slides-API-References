## Size::Subtract(const Size\&, const Size\&) metodo

Restituisce un nuovo oggetto [Size](../) che è il risultato della sottrazione di **size2** da **size1**, ovvero il cui valore di larghezza è il risultato della sottrazione del valore di larghezza di **size2** dal valore di larghezza di **size1** e il valore di altezza è il risultato della sottrazione del valore di altezza di **size2** dal valore di altezza di **size1**.

```cpp
static Size System::Drawing::Size::Subtract(const Size &size1, const Size &size2)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| size1 | const [Size](../)\& | L'oggetto [Size](../) da cui sottrarre |
| size2 | const [Size](../)\& | L'oggetto [Size](../) da sottrarre |

### Valore di ritorno

L'oggetto [Size](../) che è il risultato della sottrazione di **size2** da **size1**
