## Size::Size() costruttore

Crea un nuovo oggetto [Size](../) e lo inizializza con i valori di width e height pari a 0.

```cpp
System::Drawing::Size::Size()
```

## Size::Size(const Point\&) costruttore

Crea un nuovo oggetto [Size](../) e lo inizializza con i valori di width e height corrispondenti ai valori delle coordinate X e Y del punto specificato.

```cpp
System::Drawing::Size::Size(const Point &point)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| point | const [Point](../../point/)\& | Un oggetto [Point](../../point/) le cui coordinate X e Y sono usate per inizializzare i valori di width e height dell'oggetto [Size](../) in fase di creazione |

## Size::Size(int, int) costruttore

Crea un nuovo oggetto [Size](../) e lo inizializza con il valore specificato.

```cpp
System::Drawing::Size::Size(int width, int height)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| width | int | Il valore per width |
| height | int | Il valore di height |
