## Size::Round(const SizeF\&) metodo


Crea un oggetto [Size](../) a partire dall'oggetto [SizeF](../../sizef/) specificato arrotondando i valori di larghezza e altezza dell'oggetto [SizeF](../../sizef/) ai valori interi più vicini.

```cpp
static Size System::Drawing::Size::Round(const SizeF &size)
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| size | const [SizeF](../../sizef/)\& | L'oggetto [SizeF](../../sizef/) da convertire per costruire l'oggetto [Size](../) |

### Valore di ritorno

Un oggetto [Size](../) costruito da **size**
