## Size::Add(const Size\&, const Size\&) metodo

Restituisce un nuovo oggetto [Size](../) che è la somma dell'oggetto [Size](../) specificato, cioè il cui valore di larghezza è uguale alla somma dei valori di larghezza degli oggetti specificati e il valore di altezza è uguale alla somma dei valori di altezza degli oggetti specificati.

```cpp
static Size System::Drawing::Size::Add(const Size &size1, const Size &size2)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| size1 | const [Size](../)\& | Il primo operando |
| size2 | const [Size](../)\& | Il secondo operando |

### Valore di ritorno

L'oggetto [Size](../) che è la somma di **size1** e **size2**
