## ImageFormat enum

Rappresenta il formato file dell'immagine.

```cpp
enum class ImageFormat
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| MemoryBmp | 0 | Rappresenta il formato di un bitmap in memoria. |
| Bmp | 1 | Rappresenta il formato immagine bitmap (BMP). |
| Emf | 2 | Rappresenta il formato immagine metafile avanzato (EMF). |
| Wmf | 3 | Rappresenta il formato immagine metafile Windows (WMF). |
| Gif | 4 | Rappresenta il formato immagine Graphics Interchange Format (GIF). |
| Jpeg | 5 | Rappresenta il formato immagine Joint Photographic Experts Group (JPEG). |
| Png | 6 | Rappresenta il formato immagine Portable Network Graphics (PNG) del W3C. |
| Tiff | 7 | Rappresenta il formato immagine Tagged Image File Format (TIFF). |
| Exif | 8 | Rappresenta il formato Exchangeable Image File (Exif). |
| Icon | 9 | Rappresenta il formato immagine icona Windows. |
