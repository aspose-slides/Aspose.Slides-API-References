## ILoadOptions::set_BlobManagementOptions(System::SharedPtr\<IBlobManagementOptions\>) metodo

Rappresenta le opzioni che possono essere usate per gestire il comportamento di manipolazione di oggetti binari di grandi dimensioni (BLOB), ad esempio l'uso di file temporanei o il numero massimo di byte BLOB in memoria. Queste opzioni sono intese per impostare il miglior rapporto prestazioni/consumo di memoria per un ambiente o requisiti particolari.

```cpp
virtual void Aspose::Slides::ILoadOptions::set_BlobManagementOptions(System::SharedPtr<IBlobManagementOptions> value)=0
```

## Osservazioni

Un oggetto binario di grandi dimensioni (BLOB) è un dato binario memorizzato come entità singola - cioè BLOB può essere un audio, un video o una presentazione stessa.
