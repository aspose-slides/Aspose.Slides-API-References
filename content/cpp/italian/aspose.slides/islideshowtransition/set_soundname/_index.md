## ISlideShowTransition::set_SoundName(System::String) metodo

Specifica un nome leggibile dall'utente per il suono della transizione. Il [ISlideShowTransition::set_Sound](../set_sound/) deve essere assegnato per ottenere o impostare il nome del suono. Scrive [System::String](../../../system/string/).

```cpp
virtual void Aspose::Slides::ISlideShowTransition::set_SoundName(System::String value)=0
```

## Osservazioni

Questo nome appare nell'interfaccia utente di PowerPoint quando si configura manualmente il suono della transizione.
