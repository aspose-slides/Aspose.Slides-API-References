## ISlideShowTransition::set_Duration(int32_t) metodo

Imposta la durata dell'effetto di transizione della diapositiva in millisecondi. Scrivi **int32_t**.

```cpp
virtual void Aspose::Slides::ISlideShowTransition::set_Duration(int32_t value)=0
```

## Osservazioni

Corresponde all'attributo **p14:dur** dell'elemento **p:transition** nello schema PresentationML. Se non impostato, la durata viene determinata automaticamente in base alla proprietà [Speed](../) e al tipo di transizione.
