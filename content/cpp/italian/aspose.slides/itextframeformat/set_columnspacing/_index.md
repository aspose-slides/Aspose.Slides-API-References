## ITextFrameFormat::set_ColumnSpacing(double) metodo

Imposta lo spazio tra le colonne di testo nell'area di testo (in punti). Questo dovrebbe essere applicato solo quando è presente più di 1 colonna. Questo valore deve essere un numero positivo. In caso contrario, il valore sarà impostato a zero. Scrivi **double**.

```cpp
virtual void Aspose::Slides::ITextFrameFormat::set_ColumnSpacing(double value)=0
```
