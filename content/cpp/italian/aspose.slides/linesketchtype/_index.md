## LineSketchType enum

Rappresenta quale tipo di schizzo o effetto è stato assegnato a una forma.

```cpp
enum class LineSketchType
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| NotDefined | -1 | Specifica che l'effetto Sketch di una forma è indefinito. |
| None | 0 | Specifica che una forma non ha alcun effetto Sketch. Questo è equivalente a una proprietà vuota. |
| Curved | 1 | Specifica che una forma ha l'effetto Curved, che trasforma ogni bordo della forma in una grande curva delicata. |
| Freehand | 2 | Specifica che una forma ha l'effetto Freehand, che assomiglia maggiormente a una linea disegnata in modo imperfetto. |
| Scribble | 3 | Specifica che una forma ha l'effetto Scribble, che presenta un'oscillazione esagerata come se fosse disegnata volutamente caotica. |
