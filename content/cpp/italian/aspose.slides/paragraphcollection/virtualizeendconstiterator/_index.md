## ParagraphCollection::virtualizeEndConstIterator() const metodo

Ottiene l'iteratore che punta subito dopo l'ultimo elemento (se presente) dell'istanza const-qualified della collezione.

```cpp
virtualized_iterator * Aspose::Slides::ParagraphCollection::virtualizeEndConstIterator() const override
```

### Valore di ritorno

Un iteratore che punta subito dopo l'ultimo elemento (se presente) dell'istanza const-qualified della collezione fornisce l'implementazione dell'iteratore const alla fine del contenitore.

Oggetto iteratore appena creato.
