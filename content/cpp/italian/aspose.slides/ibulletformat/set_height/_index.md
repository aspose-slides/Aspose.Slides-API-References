## IBulletFormat::set_Height(float) metodo

Imposta l'altezza del punto elenco di un paragrafo senza ereditarietà. Il valore std::numeric_limits<float>::quiet_NaN() determina che il bullet eredita l'altezza dalla prima porzione del paragrafo. Scrivi **float**.

virtual void Aspose::Slides::IBulletFormat::set_Height(float value)=0
