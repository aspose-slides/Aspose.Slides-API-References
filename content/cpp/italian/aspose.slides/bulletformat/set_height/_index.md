## BulletFormat::set_Height(float) metodo

Imposta l'altezza del punto elenco di un paragrafo senza ereditarietà. Il valore std::numeric_limits<float>::quiet_NaN() indica che il punto elenco eredita l'altezza dalla prima porzione nel paragrafo. Scrivi **float**.

```cpp
void Aspose::Slides::BulletFormat::set_Height(float value) override
```

## Osservazioni

Un valore di altezza negativo indica che l'altezza è espressa in punti, mentre un valore positivo indica che l'altezza è una percentuale del testo circostante.
