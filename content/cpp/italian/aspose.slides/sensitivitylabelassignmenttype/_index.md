## SensitivityLabelAssignmentType enum

Rappresenta il metodo di assegnazione per l'etichetta di sensibilità.

```cpp
enum class SensitivityLabelAssignmentType
```

### Valori

| Name | Value | Description |
| --- | --- | --- |
| Standard | 0 | Da utilizzare per qualsiasi etichetta di sensibilità che non è stata applicata direttamente dall'utente. Include tutte le etichette predefinite, le etichette applicate automaticamente. |
| Privileged | 1 | Da utilizzare per qualsiasi etichetta di sensibilità che è stata applicata direttamente dall'utente. Include le etichette di sensibilità applicate manualmente così come l'etichettatura consigliata o obbligatoria o qualsiasi funzionalità in cui l'utente decide quale etichetta di sensibilità applicare. |
