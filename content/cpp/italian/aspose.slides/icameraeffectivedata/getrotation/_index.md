## ICameraEffectiveData::GetRotation() metodo

Una rotazione è definita mediante l'uso di una coordinata di latitudine, una coordinata di longitudine e una rivoluzione attorno all'asse come le coordinate di latitudine e longitudine. Il primo elemento nell'array restituito è la latitudine, il secondo è la longitudine, il terzo è la rivoluzione. Restituisce null se non è definita alcuna rotazione.

```cpp
virtual System::ArrayPtr<float> Aspose::Slides::ICameraEffectiveData::GetRotation()=0
```

### Valore di ritorno

Array di valori di rotazione come **float**[].
