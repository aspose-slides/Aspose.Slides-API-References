## LoadOptions::set_BlobManagementOptions(System::SharedPtr\<IBlobManagementOptions\>) metodo

Rappresenta le opzioni che possono essere usate per gestire il comportamento di gestione dei Binary Large Objects (BLOBs), come l'utilizzo di file temporanei o il numero massimo di byte dei BLOBs in memoria. Queste opzioni sono concepite per impostare il miglior rapporto prestazioni/consumo di memoria per un ambiente o requisiti particolari.

```cpp
void Aspose::Slides::LoadOptions::set_BlobManagementOptions(System::SharedPtr<IBlobManagementOptions> value) override
```

## Osservazioni

Un Binary Large Object (BLOB) è un dato binario memorizzato come un'unica entità - cioè BLOB può essere un audio, un video o una presentazione stessa.
