## IShape::set_Rotation(float) metodo


Imposta il numero di gradi di cui la forma specificata è ruotata intorno all'asse z. Un valore positivo indica rotazione in senso orario; un valore negativo indica rotazione in senso antiorario. Scrivi **float**.

```cpp
virtual void Aspose::Slides::IShape::set_Rotation(float value)=0
```

## Osservazioni


Il valore restituito è sempre definito (non è std::numeric_limits<float>::quiet_NaN()). Il valore assegnato deve essere definito (non è std::numeric_limits<float>::quiet_NaN()). È possibile impostare valori non definiti per le proprietà dell'istanza RawFrame.
