## IShape::set_Frame(System::SharedPtr\<IShapeFrame\>) metodo

virtual void Aspose::Slides::IShape::set_Frame(System::SharedPtr<IShapeFrame> value)=0

## Osservazioni

Il valore di ogni proprietà dell'istanza [IShapeFrame](../../ishapeframe/) restituita non è indefinito (non è NaN o NotDefined). Il valore di ogni proprietà dell'istanza [IShapeFrame](../../ishapeframe/) assegnata deve non essere indefinito (deve non essere NaN o NotDefined). È possibile impostare valori indefiniti per le proprietà dell'istanza RawFrame.
