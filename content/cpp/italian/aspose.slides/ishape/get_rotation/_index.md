## IShape::get_Rotation() metodo

Restituisce il numero di gradi di cui la forma specificata è ruotata attorno all'asse z. Un valore positivo indica una rotazione in senso orario; un valore negativo indica una rotazione in senso antiorario. Leggi **float**.

```cpp
virtual float Aspose::Slides::IShape::get_Rotation()=0
```

## Osservazioni

Il valore restituito è sempre definito (non è std::numeric_limits<float>::quiet_NaN()). Il valore assegnato deve essere definito (non std::numeric_limits<float>::quiet_NaN()). È possibile impostare valori non definiti per le proprietà dell'istanza RawFrame.
