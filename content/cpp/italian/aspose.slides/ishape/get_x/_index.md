## IShape::get_X() metodo


Restituisce la coordinata x dell'angolo superiore sinistro della forma, misurata in punti. Lettura **float**.

```cpp
virtual float Aspose::Slides::IShape::get_X()=0
```

## Osservazioni


Il valore restituito è sempre definito e mai [std::numeric_limits<float>::quiet_NaN()](../). Il valore assegnato deve essere anch'esso definito; assegnare [std::numeric_limits<float>::quiet_NaN()](../) solo alle proprietà di un'istanza **RawFrame**.
