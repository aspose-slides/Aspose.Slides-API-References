## SectionCollection::virtualizeBeginConstIterator() const metodo

Restituisce un iteratore che punta al primo elemento (se presente) dell'istanza qualificata come const della raccolta.

```cpp
virtualized_iterator * Aspose::Slides::SectionCollection::virtualizeBeginConstIterator() const override
```

### Valore restituito

Un iteratore che punta al primo elemento (se presente) dell'istanza qualificata come const della raccolta. Fornisce l'implementazione dell'iteratore const al primo elemento del contenitore.

Oggetto iteratore appena creato.
