## ProtectionManager::get_EncryptDocumentProperties() metodo

Questa proprietà ha senso, se la presentazione è protetta da password. Se true allora le proprietà del documento sono criptate nel file della presentazione. Se false allora le proprietà del documento sono pubbliche mentre la presentazione è criptata. Leggi **bool**.
