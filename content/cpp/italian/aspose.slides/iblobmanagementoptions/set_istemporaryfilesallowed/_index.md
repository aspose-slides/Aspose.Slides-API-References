## IBlobManagementOptions::set_IsTemporaryFilesAllowed(bool) metodo

Questa proprietà definisce se i file temporanei possono essere creati durante il lavoro con i BLOB, il che riduce notevolmente il consumo di memoria ma richiede i permessi per creare file.

```cpp
virtual void Aspose::Slides::IBlobManagementOptions::set_IsTemporaryFilesAllowed(bool value)=0
```

## Osservazioni

Tutti i file verranno eliminati al termine del lavoro con la presentazione.
