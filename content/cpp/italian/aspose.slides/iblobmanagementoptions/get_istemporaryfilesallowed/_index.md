## IBlobManagementOptions::get_IsTemporaryFilesAllowed() metodo


Questa proprietà definisce se è possibile creare file temporanei durante il lavoro con i BLOB, il che riduce notevolmente il consumo di memoria ma richiede permessi per creare i file.

```cpp
virtual bool Aspose::Slides::IBlobManagementOptions::get_IsTemporaryFilesAllowed()=0
```

## Osservazioni


Tutti i file verranno eliminati al termine del lavoro con la presentazione.
