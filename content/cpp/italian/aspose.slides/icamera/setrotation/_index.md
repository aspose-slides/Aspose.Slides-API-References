## ICamera::SetRotation(float, float, float) metodo


Una rotazione è definita mediante l'uso di una coordinata di latitudine, una coordinata di longitudine e una rivoluzione attorno all'asse come le coordinate di latitudine e longitudine. Se il valore di una qualsiasi coordinata è std::numeric_limits<float>::quiet_NaN(), tutta la rotazione è indefinita.

```cpp
virtual void Aspose::Slides::ICamera::SetRotation(float latitude, float longitude, float revolution)=0
```

| latitude | **float** | Valore di latitudine **float** |
| longitude | **float** | Valore di longitudine **float** |
| revolution | **float** | Valore di rivoluzione **float** |
