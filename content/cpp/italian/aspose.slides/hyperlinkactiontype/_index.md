## HyperlinkActionType enum

Rappresenta un tipo di azione del collegamento ipertestuale.

```cpp
enum class HyperlinkActionType
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Unknown | -1 | Tipo di azione non riconosciuto. |
| NoAction | 0 | Nessuna azione. |
| Hyperlink | 1 | Collegamento ipertestuale normale. |
| JumpFirstSlide | 2 | Passa alla prima diapositiva della presentazione. |
| JumpPreviousSlide | 3 | Passa alla diapositiva precedente. |
| JumpNextSlide | 4 | Passa alla diapositiva successiva. |
| JumpLastSlide | 5 | Passa all'ultima diapositiva della presentazione. |
| JumpEndShow | 6 | Passa alla fine della presentazione. |
| JumpLastViewedSlide | 7 | Passa all'ultima diapositiva visualizzata. |
| JumpSpecificSlide | 8 | Passa alla diapositiva specifica, indicata dal valore [IHyperlink::get_TargetSlide](../ihyperlink/get_targetslide/). |
| StartCustomSlideShow | 9 | Avvia presentazione personalizzata. |
| OpenFile | 10 | Apri il file referenziato. |
| OpenPresentation | 11 | Apri la presentazione referenziata. |
| StartStopMedia | 12 | Avvia/ferma la riproduzione del file multimediale. |
| StartMacro | 13 | Inizia l'esecuzione dello script macro. |
| StartProgram | 14 | Avvia il programma. |
