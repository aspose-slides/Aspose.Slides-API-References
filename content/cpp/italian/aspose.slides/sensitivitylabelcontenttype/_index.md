## SensitivityLabelContentType enum

Rappresenta i tipi di marcatura del contenuto che devono essere applicati a un documento.

```cpp
enum class SensitivityLabelContentType
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| None | 0 | Indica che l'etichetta viene applicata per impostazione predefinita o automaticamente. |
| Header | 1 | Indica che l'etichetta è stata applicata manualmente. Utilizzare per qualsiasi etichetta di sensibilità che è stata applicata direttamente dall'utente. |
| Footer | 2 | Indica che l'etichetta è stata applicata manualmente. Utilizzare per qualsiasi etichetta di sensibilità che è stata applicata direttamente dall'utente. |
| Watermark | 4 | Indica che l'etichetta è stata applicata manualmente. Utilizzare per qualsiasi etichetta di sensibilità che è stata applicata direttamente dall'utente. |
| Encryption | 8 | Indica che l'etichetta è stata applicata manualmente. Utilizzare per qualsiasi etichetta di sensibilità che è stata applicata direttamente dall'utente. |
