## IProtectionManager::set_EncryptDocumentProperties(bool) metodo

Questa proprietà ha senso, se la presentazione è protetta da password. Se vero, le proprietà del documento sono cifrate nel file della presentazione. Se falso, le proprietà del documento sono pubbliche mentre la presentazione è cifrata. Scrivi **bool**.

virtual void Aspose::Slides::IProtectionManager::set_EncryptDocumentProperties(bool value)=0
