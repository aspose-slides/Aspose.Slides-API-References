## CommentCollection::virtualizeEndConstIterator() const metodo


Ottiene un iteratore che punta subito dopo l'ultimo elemento (se presente) dell'istanza qualificata come const della collezione.

```cpp
virtualized_iterator * Aspose::Slides::CommentCollection::virtualizeEndConstIterator() const override
```


### Valore di ritorno

Un iteratore che punta subito dopo l'ultimo elemento (se presente) dell'istanza qualificata come const della collezione fornisce l'implementazione dell'iteratore const alla fine del contenitore. 

Oggetto iteratore appena creato.
