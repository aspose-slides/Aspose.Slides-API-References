## IDocumentProperties::get_AppVersion() metodo

Restituisce la versione dell'app. Sola lettura [System::String](../../../system/string/).

```cpp
virtual System::String Aspose::Slides::IDocumentProperties::get_AppVersion()=0
```

## Osservazioni

Il contenuto di questo elemento deve essere nel formato XX.YYYY, dove X e Y rappresentano valori numerici; in caso contrario, il documento sarà considerato non conforme. [Aspose.Slides](../../) rappresenta la sua versione nel formato XX.YYZZ, dove: XX - versione principale YY - versione secondaria ZZ - versione patch. Per esempio, il valore 23.0105 significa la versione [Aspose.Slides](../../) 23.1.5.
