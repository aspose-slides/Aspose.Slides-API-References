## INormalViewProperties::set_PreferSingleView(bool) metodo


Specifica se l'utente preferisce visualizzare una regione a contenuto unico a schermo intero rispetto alla vista normale standard con tre regioni di contenuto. Se abilitata, l'applicazione può scegliere di visualizzare una delle regioni di contenuto nell'intera finestra. Scrivi **bool**.

virtual void Aspose::Slides::INormalViewProperties::set_PreferSingleView(bool value)=0
