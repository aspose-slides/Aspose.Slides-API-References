## Shape::set_X(float) metodo

Imposta la coordinata x dell'angolo superiore sinistro della forma, misurata in punti. Scrivi **float**.

```cpp
void Aspose::Slides::Shape::set_X(float value) override
```

## Osservazioni

Il valore restituito è sempre definito e mai [std::numeric_limits<float>::quiet_NaN()](../). Il valore assegnato deve essere anch'esso definito; assegna [std::numeric_limits<float>::quiet_NaN()](../) solo alle proprietà di un'istanza di **RawFrame**.
