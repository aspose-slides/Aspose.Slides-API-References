## Shape::get_Rotation() metodo

Restituisce il numero di gradi di cui la forma specificata è ruotata attorno all'asse z. Un valore positivo indica una rotazione in senso orario; un valore negativo indica una rotazione in senso antiorario. Leggi **float**.

```cpp
float Aspose::Slides::Shape::get_Rotation() override
```

## Osservazioni

Il valore restituito è sempre definito (non è std::numeric_limits<float>::quiet_NaN()). Il valore assegnato deve essere definito (non std::numeric_limits<float>::quiet_NaN()). È possibile impostare valori indefiniti per le proprietà dell'istanza RawFrame.
