## Osservazioni

Il valore restituito è sempre definito e mai [std::numeric_limits<float>::quiet_NaN()](../). Il valore assegnato deve essere anch'esso definito; assegna [std::numeric_limits<float>::quiet_NaN()](../) solo alle proprietà di un'istanza **RawFrame**.
