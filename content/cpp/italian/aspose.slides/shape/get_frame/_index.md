## Osservazioni

Il valore di ogni proprietà dell'istanza [IShapeFrame](../../ishapeframe/) restituita non è indefinito (non è NaN o NotDefined). Il valore di ogni proprietà dell'istanza [IShapeFrame](../../ishapeframe/) assegnata deve essere non indefinito (deve essere non NaN o NotDefined). È possibile impostare valori indefiniti per le proprietà dell'istanza RawFrame.
