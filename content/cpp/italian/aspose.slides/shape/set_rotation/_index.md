## Shape::set_Rotation(float) metodo

Imposta il numero di gradi di rotazione della forma specificata attorno all'asse z. Un valore positivo indica rotazione in senso orario; un valore negativo indica rotazione in senso antiorario. Scrivi **float**.

```cpp
void Aspose::Slides::Shape::set_Rotation(float value) override
```

## Osservazioni

Il valore restituito è sempre definito (non è std::numeric_limits<float>::quiet_NaN()). Il valore assegnato deve essere definito (non std::numeric_limits<float>::quiet_NaN()). È possibile impostare valori non definiti per le proprietà dell'istanza RawFrame.
