## SoapBindingStyle enumerazione

Specifica il tipo di azione nel servizio XML [Web](../../system.web/) a livello della gerarchia della classe a cui si applica questa enumerazione.

```cpp
enum class SoapBindingStyle
```

### Valori

| Nome | Valore | Descrizione |

| Default | 0 | Il tipo di azione predefinito. |
| Document | 1 | Il messaggio è orientato al documento. |
| Rpc | 2 | Il messaggio contiene i parametri per chiamare una procedura o i valori di ritorno di quella procedura. |
