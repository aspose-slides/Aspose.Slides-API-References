## has_method_compareto struct

Verifica se il metodo CompareTo esiste nel tipo specificato. In tal caso, eredita std::true_type, altrimenti eredita std::false_type. Può essere usato in std::enable_if.

```cpp
template<typename T,typename Sfinae>class has_method_compareto : public std::false_type
```

### Parametri del template

| Parametro | Descrizione |
| --- | --- |
| T | Tipo da verificare per l'esistenza del metodo Equals. |
| Sfinae | Argomento template formale per far funzionare SFINAE. |
