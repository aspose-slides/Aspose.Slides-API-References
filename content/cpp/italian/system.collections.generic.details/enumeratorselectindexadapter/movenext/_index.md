## EnumeratorSelectIndexAdapter::MoveNext() metodo

Sposta l'enumeratore al prossimo elemento. Se nessun elemento era stato referenziato prima, imposta il riferimento al primo elemento disponibile. Se è stato raggiunto la fine del contenitore, non fa nulla.

```cpp
bool System::Collections::Generic::Details::EnumeratorSelectIndexAdapter<Source, Result>::MoveNext() override
```

### Valore di ritorno

True se qualche elemento è disponibile dopo la chiamata, false altrimenti.
