## EnumeratorCastAdapter::MoveNext() metodo


Sposta l'enumeratore al prossimo elemento. Se nessun elemento era stato referenziato prima, imposta il riferimento sul primo elemento disponibile. Se si è raggiunta la fine del contenitore, non fa nulla.

```cpp
bool System::Collections::Generic::Details::EnumeratorCastAdapter<Source, Result>::MoveNext() override
```


### Valore restituito

True se qualche elemento è disponibile dopo la chiamata, false altrimenti.
