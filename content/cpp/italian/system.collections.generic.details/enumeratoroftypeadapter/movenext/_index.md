## EnumeratorOfTypeAdapter::MoveNext() metodo

Sposta l'enumeratore al prossimo elemento. Se nessun elemento era stato referenziato prima, imposta il riferimento al primo elemento disponibile. Se si raggiunge la fine del contenitore, non fa nulla.

```cpp
bool System::Collections::Generic::Details::EnumeratorOfTypeAdapter<Source, Result>::MoveNext() override
```

### Valore restituito

True se qualche elemento è disponibile dopo la chiamata, false altrimenti.
