## System::Collections::Generic::Details::IsOutOfSize(int, const Container\&) funzione

Verifica se l'indice è fuori dai limiti del contenitore, inclusa la dimensione del contenitore.

```cpp
template<typename Container> bool System::Collections::Generic::Details::IsOutOfSize(int count, const Container &container)
```

### Parametri del modello

| Parametro | Descrizione |
| --- | --- |
| Container | Tipo di contenitore. |

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| count | int | [Index](../../system/index/). |
| container | const Container\& | Contenitore su cui verificare l'indice. |

### Valore restituito

True se l'indice è fuori dai limiti del contenitore, false altrimenti.
