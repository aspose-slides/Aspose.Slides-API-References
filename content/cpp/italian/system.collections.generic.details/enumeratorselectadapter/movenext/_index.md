## EnumeratorSelectAdapter::MoveNext() metodo

Sposta l'enumeratore al prossimo elemento. Se non è stato referenziato alcun elemento prima, imposta il riferimento al primo elemento disponibile. Se si è raggiunta la fine del contenitore, non fa nulla.

```cpp
bool System::Collections::Generic::Details::EnumeratorSelectAdapter<Source, Result>::MoveNext() override
```

### Valore di ritorno

True se è disponibile qualche elemento dopo la chiamata, false altrimenti.
