## SearchOption enum

Specifica che la ricerca deve essere eseguita solo nella directory corrente, o nella directory corrente e in tutte le sue sottodirectory.

```cpp
enum class SearchOption
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| AllDirectories | 0 | Cerca nella directory corrente e in tutte le sue sottodirectory. |
| TopDirectoryOnly | 1 | Cerca solo nella directory corrente. |
