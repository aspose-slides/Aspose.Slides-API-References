## BasicSTDIOStreamWrapper::ReadByte() metodo


Se la modalità di wrapping è binaria, legge un singolo byte dall'archivio dell'ultimo carattere decodificato; altrimenti legge un singolo carattere dallo stream e lo converte al tipo **uint8_t**.

```cpp
virtual int System::IO::BasicSTDIOStreamWrapper<T, typename>::ReadByte() override
```


### Valore di ritorno

Un valore intero a 32 bit equivalente al risultato della lettura
