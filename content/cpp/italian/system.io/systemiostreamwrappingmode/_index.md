## SystemIOStreamWrappingMode enum

Specifica la modalità delle operazioni di I/O che i wrapper eseguiranno su flussi simili a [System::IO::Stream](../stream/).

```cpp
enum class SystemIOStreamWrappingMode
```

### Values

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Binary | 0 | Una modalità che consente alle operazioni di input di codificare i byte del flusso in dati di tipo char_type e decodificare i dati di tipo char_type in byte del flusso per le operazioni di output. |
| Conversion | 1 | Una modalità che consente alle operazioni di input di convertire i byte del flusso dal tipo **uint8_t** al tipo char_type e viceversa per le operazioni di output. |
