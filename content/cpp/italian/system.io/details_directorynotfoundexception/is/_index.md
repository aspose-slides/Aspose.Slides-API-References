## Details_DirectoryNotFoundException::Is(const System::TypeInfo\&) const method




```cpp
bool System::IO::Details_DirectoryNotFoundException::Is(const System::TypeInfo &target) const override
```


### Argomenti

| Parameter | Type | Description |
| --- | --- | --- |
| target | const [System::TypeInfo](../../../system/typeinfo/)\& | [TypeInfo](../../../system/typeinfo/) struttura che descrive il tipo contro cui verificare l'oggetto corrente. |

### Valore di ritorno

True se l'oggetto è del tipo etichettato o di una sua sottoclasse, false altrimenti.
## Osservazioni


Verifica se l'oggetto rappresenta un'istanza del tipo descritto da targetType. Analogo dell'operatore C# 'is'.
