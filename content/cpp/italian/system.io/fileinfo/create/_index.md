## FileInfo::Create() metodo


Crea un file nella posizione specificata dal percorso rappresentato dall'oggetto corrente e lo apre per lettura e scrittura, in modalità truncate e senza condivisione.

```cpp
FileStreamPtr System::IO::FileInfo::Create()
```


### Valore di ritorno

Un oggetto [FileStream](../../filestream/) associato al file creato
