## FileSystemInfo::get_Exists() metodo

Determina se l'entità a cui si riferisce il percorso rappresentato dall'oggetto corrente esiste.

```cpp
virtual bool System::IO::FileSystemInfo::get_Exists()=0
```

### Valore di ritorno

True se l'entità a cui si riferisce il percorso rappresentato dall'oggetto corrente esiste, altrimenti - false
