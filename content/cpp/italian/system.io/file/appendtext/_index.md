## File::AppendText(const String\&) metodo


Crea un oggetto [StreamWriter](../../streamwriter/) che aggiunge testo al file specificato utilizzando la codifica UTF-8. Se il file specificato non esiste, viene creato.

```cpp
static StreamWriterPtr System::IO::File::AppendText(const String &path)
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| path | const [String](../../../system/string/)\& | Il percorso del file da aprire o creare |

### Valore di ritorno

Un puntatore condiviso all'oggetto [StreamWriter](../../streamwriter/) creato associato al file specificato
