## Directory::Move(const String\&, const String\&) metodo


Sposta l'entità specificata nella nuova posizione. Se l'entità da spostare è una directory, viene spostata con tutto il suo contenuto.

```cpp
static void System::IO::Directory::Move(const String &sourceDirName, const String &destDirName)
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| sourceDirName | const [String](../../../system/string/)\& | Una directory o file da spostare |
| destDirName | const [String](../../../system/string/)\& | La nuova posizione di **sourceDirName** |
