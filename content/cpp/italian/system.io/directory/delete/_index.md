## Directory::Delete(const String\&, bool) metodo

Rimuove il file o la directory specificati. Non genera eccezioni.

```cpp
static void System::IO::Directory::Delete(const String &path, bool recursive=false)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| path | const [String](../../../system/string/)\& | Il percorso della directory o del file da rimuovere |
| recursive | **bool** | Se **path** specifica una directory non vuota, allora **recursive** specifica se tutto il contenuto della directory deve essere rimosso ricorsivamente; se la directory specificata da **path** non è vuota e **recursive** è 'false' l'operazione fallisce |
