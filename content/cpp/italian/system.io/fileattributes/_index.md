## FileAttributes enum

Rappresenta gli attributi di una directory o di un file.

```cpp
enum class FileAttributes
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| Archive | 32 | L'entità del file system è un candidato per la rimozione o il backup. |
| Compressed | 2048 | L'entità del file system è compressa. |
| Device | 64 | Non utilizzato. |
| Directory | 16 | L'entità del file system è una directory. |
| Encrypted | 16384 | L'entità del file system è crittografata. |
| Hidden | 2 | L'entità del file system è nascosta. |
| IntegrityStream | 32768 | L'entità del file system contiene supporto all'integrità dei dati. |
| Normal | 128 | L'entità del file system è un file che non ha attributi speciali. |
| NotContentIndexed | 8192 | L'entità del file system non sarà indicizzata dal servizio di indicizzazione dei contenuti. |
| NoScrubData | 131072 | L'entità del file system non è inclusa nella scansione dell'integrità dei dati. |
| Offline | 4096 | L'entità del file system è offline e i suoi dati non sono immediatamente disponibili. |
| ReadOnly | 1 | L'entità del file system è di sola lettura. |
| ReparsePoint | 1024 | L'entità del file system è un file che contiene un punto di reparse. |
| SparseFile | 512 | L'entità del file system è un file sparso. |
| System | 4 | L'entità del file system è un file di sistema. |
| Temporary | 256 | L'entità del file system è un file temporaneo. |
| Invalid | 0 | Valore non valido. |
