## DirectoryInfo::Delete(bool) metodo


Rimuove la directory a cui si riferisce il percorso rappresentato dall'oggetto corrente. Un parametro specifica se il contenuto della directory deve essere rimosso ricorsivamente se la directory non è vuota.

```cpp
void System::IO::DirectoryInfo::Delete(bool recursive)
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| recursive | **bool** | Specifica se il contenuto della directory deve essere rimosso ricorsivamente se non è vuota |
