## TraceLevel enum


Specifica quali messaggi emettere per le classi [System.Diagnostics.Debug](../debug/), [System.Diagnostics.Trace](../trace/) e System.Diagnostics.TraceSwitch.

```cpp
enum class TraceLevel
```

### Values

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Off | 0 | Non emette messaggi di tracciamento e debug. |
| Error | 1 | Emette messaggi di gestione degli errori. |
| Warning | 2 | Emette avvisi e messaggi di gestione degli errori. |
| Info | 3 | Emette messaggi informativi, avvisi e messaggi di gestione degli errori. |
| Verbose | 4 | Emette tutti i messaggi di debug e tracciamento. |
