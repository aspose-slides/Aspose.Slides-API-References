## TraceEventType enum


Identifica il tipo di evento che ha causato la traccia.

```cpp
enum class TraceEventType
```

### Values

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Critical | 1 | Errore fatale o crash dell'applicazione. |
| Error | 2 | Errore recuperabile. |
| Warning | 4 | Problema non critico. |
| Information | 8 | Messaggio informativo. |
| Verbose | 16 | Traccia di debug. |
| Start | 256 | Avvio di un'operazione logica. |
| Stop | 512 | Interruzione di un'operazione logica. |
| Suspend | 1024 | Sospensione di un'operazione logica. |
| Resume | 2048 | Ripresa di un'operazione logica. |
| Transfer | 4096 | Modifica dell'identità di correlazione. |
