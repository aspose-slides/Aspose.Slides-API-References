## Classi

| Classe | Descrizione |
| --- | --- |
| [FontCollection](./fontcollection/) | Una classe base per raccolte di font installati e privati. Gli oggetti di questa classe devono essere allocati solo usando la funzione [System::MakeObject()](../system/makeobject/). Non creare mai un'istanza di questo tipo sullo stack o usando operator new, poiché ciò provocherà errori di runtime e/o guasti di asserzione. Avvolgere sempre questa classe in un puntatore [System::SmartPtr](../system/smartptr/) e usare questo puntatore per passarlo alle funzioni come argomento. |
| [InstalledFontCollection](./installedfontcollection/) | Rappresenta la raccolta dei font installati nel sistema. NON IMPLEMENTATO. Gli oggetti di questa classe devono essere allocati solo usando la funzione [System::MakeObject()](../system/makeobject/). Non creare mai un'istanza di questo tipo sullo stack o usando operator new, poiché ciò proverà errori di runtime e/o guasti di asserzione. Avvolgere sempre questa classe in un puntatore [System::SmartPtr](../system/smartptr/) e usare questo puntatore per passarlo alle funzioni come argomento. |
| [PrivateFontCollection](./privatefontcollection/) | Rappresenta una raccolta di famiglie di font fornita dall'applicazione client. Gli oggetti di questa classe devono essere allocati solo usando la funzione [System::MakeObject()](../system/makeobject/). Non creare mai un'istanza di questo tipo sullo stack o usando operator new, poiché ciò proverà errori di runtime e/o guasti di asserzione. Avvolgere sempre questa classe in un puntatore [System::SmartPtr](../system/smartptr/) e usare questo puntatore per passarlo alle funzioni come argomento. |
