## EmptyEnumerator::MoveNext() metodo

Sposta l'enumeratore al prossimo elemento. Se nessun elemento è stato referenziato prima, imposta il riferimento al primo elemento disponibile. Se si è raggiunta la fine del contenitore, non fa nulla.

```cpp
bool System::Linq::Details::EmptyEnumerator<T>::MoveNext() override
```

### Valore di ritorno

True se è disponibile qualche elemento dopo la chiamata, false altrimenti.
