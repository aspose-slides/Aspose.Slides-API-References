## TransportType enum

Definisce il tipo di trasporto consentito per il socket.

```cpp
enum class TransportType
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Udp | 1 | Il tipo di trasporto UDP. |
| Connectionless | n/a | Il tipo di trasporto è connectionless. |
| Tcp | 2 | Il tipo di trasporto TCP. |
| ConnectionOriented | n/a | Il trasporto è connection oriented. |
| All | 3 | All tipi di trasporto. |
