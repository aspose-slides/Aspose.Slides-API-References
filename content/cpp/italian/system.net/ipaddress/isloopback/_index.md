## IPAddress::IsLoopback(System::SharedPtr\<IPAddress\>) metodo

Restituisce un valore che indica se l'indirizzo specificato è un indirizzo di loopback.

```cpp
static bool System::Net::IPAddress::IsLoopback(System::SharedPtr<IPAddress> address)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| address | [System::SharedPtr](../../../system/sharedptr/)\<[IPAddress](../)\> | L'indirizzo da verificare. |

### Valore di ritorno

True quando l'indirizzo specificato è un indirizzo di loopback, altrimenti false.
