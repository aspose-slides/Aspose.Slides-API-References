## IPAddress::TryParse(String, System::SharedPtr\<IPAddress\>\&) metodo

Prova a convertire una stringa fornita in un'istanza della classe [IPAddress](../).

```cpp
static bool System::Net::IPAddress::TryParse(String ipString, System::SharedPtr<IPAddress> &address)
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| ipString | [String](../../../system/string/) | Una stringa da analizzare. |
| address | [System::SharedPtr](../../../system/sharedptr/)\<[IPAddress](../)\>\& | Un'istanza a cui verrà assegnato l'oggetto analizzato. |

### Valore di ritorno

True quando l'analisi è completata con successo, altrimenti false.
