## ResultValueTask::get_IsCanceled() const metodo


Restituisce un valore che indica se l'attività è stata completata a causa della cancellazione.

```cpp
bool System::Threading::Tasks::ResultValueTask<T>::get_IsCanceled() const
```


### Valore restituito

bool True se l'attività è stata annullata; altrimenti, false.
## Osservazioni



Restituisce false se l'attività contiene un valore di risultato diretto.
