## ResultValueTask::get_IsFaulted() const metodo

Restituisce un valore che indica se l'attività è terminata a causa di un'eccezione non gestita.

```cpp
bool System::Threading::Tasks::ResultValueTask<T>::get_IsFaulted() const
```

### Valore restituito

bool True se l'attività è in errore; altrimenti, false.

## Osservazioni

Restituisce false se l'attività contiene un valore risultato diretto.
