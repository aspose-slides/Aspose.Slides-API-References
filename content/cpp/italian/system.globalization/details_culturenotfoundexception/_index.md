## Details_CultureNotFoundException classe


CultureNotFoundException viene sollevata quando si tenta di creare una cultura che non è disponibile. Non creare mai istanze di questa classe manualmente. Usa invece la classe CultureNotFoundException. Non avvolgere mai le istanze della classe CultureNotFoundException in [System::SmartPtr](../../system/smartptr/).

```cpp
class Details_CultureNotFoundException : public System::Details_ArgumentException
```
