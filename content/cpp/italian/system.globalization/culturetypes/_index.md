## CultureTypes enum

Voci del bitmask delle categorie culturali.

```cpp
enum class CultureTypes : int32_t
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| NeutralCultures | 1 | Cultura specifica per la lingua ma non per il paese o la regione. |
| SpecificCultures | 2 | Specifico per paese/regione. |
| InstalledWin32Cultures | 4 | Culture installate nel OS. |
| AllCultures | n/a | Tutte le culture disponibili. |
| UserCustomCulture | 8 | Culture definite dall'utente. |
| ReplacementCultures | 16 | Sostituzioni definite dall'utente per le culture esistenti. |
| WindowsOnlyCultures | 32 | Obsoleto. |
| FrameworkCultures | 64 | Obsoleto. |
