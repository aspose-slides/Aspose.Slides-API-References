## NumberFormatInfo::get_PercentGroupSizes() const metodo


Restituisce il numero di cifre per gruppo di valore percentuale.

```cpp
ArrayPtr<int> System::Globalization::NumberFormatInfo::get_PercentGroupSizes() const
```


### Valore di ritorno

[Array](../../../system/array/) di cifre per gruppo, da sinistra a destra; ogni elemento deve essere da 1 a 9, l'ultimo può essere 0 che significa \"combina tutti\"; l'ultimo elemento si ripete.
