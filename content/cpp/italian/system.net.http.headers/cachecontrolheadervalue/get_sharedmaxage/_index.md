## CacheControlHeaderValue::get_SharedMaxAge() metodo

Restituisce il valore dell'età massima condivisa in secondi che sovrascrive la direttiva 'max-age' nell'intestazione 'Cache-Control' o nell'intestazione 'Expires' per una cache condivisa.

```cpp
Nullable<TimeSpan> System::Net::Http::Headers::CacheControlHeaderValue::get_SharedMaxAge()
```

### Valore di ritorno

Il valore dell'età massima condivisa in secondi che sovrascrive la direttiva 'max-age' nell'intestazione 'Cache-Control' o nell'intestazione 'Expires' per una cache condivisa.
