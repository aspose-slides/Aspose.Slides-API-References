## HttpRequestHeaders::get_TransferEncodingChunked() metodo

Restituisce un valore che indica se il valore dell'intestazione 'Transfer-Encoding' contiene 'Chunked'.

```cpp
Nullable<bool> System::Net::Http::Headers::HttpRequestHeaders::get_TransferEncodingChunked()
```

### Valore restituito

True quando il valore dell'intestazione 'Transfer-Encoding' contiene 'Chunked', altrimenti false.
