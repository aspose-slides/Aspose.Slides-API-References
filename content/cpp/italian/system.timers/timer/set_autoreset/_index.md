## Timer::set_AutoReset(bool) metodo

Imposta il timer in modalità auto-reset o lo disattiva.

```cpp
void System::Timers::Timer::set_AutoReset(bool autoreset)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| autoreset | **bool** | true per far sì che il timer venga invocato in un ciclo, false per fermarlo dopo la prima invocazione. |
