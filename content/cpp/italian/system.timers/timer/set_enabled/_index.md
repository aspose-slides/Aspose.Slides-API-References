## Timer::set_Enabled(bool) metodo

Avvia o arresta il timer. L'avvio del timer non ripristina il conteggio del tempo se il timer è già in esecuzione.

```cpp
void System::Timers::Timer::set_Enabled(bool value)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| value | **bool** | true per avviare il timer, false per arrestarlo. |
