## Details_EncoderFallbackException classe


Eccezione sollevata da [EncoderExceptionFallback](../encoderexceptionfallback/) quando la codifica fallisce. Non creare mai istanze di questa classe manualmente. Utilizza invece la classe EncoderFallbackException. Non avvolgere mai le istanze della classe EncoderFallbackException in [System::SmartPtr](../../system/smartptr/).

```cpp
class Details_EncoderFallbackException : public System::Details_ArgumentException
```
