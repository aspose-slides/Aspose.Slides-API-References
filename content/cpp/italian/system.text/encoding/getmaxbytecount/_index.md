## Encoding::GetMaxByteCount(int) metodo

Ottiene il numero massimo di byte necessari per codificare un numero specificato di caratteri.

```cpp
virtual int System::Text::Encoding::GetMaxByteCount(int char_count)=0
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| char_count | int | Numero di caratteri da codificare. |

### Valore di ritorno

Numero di byte sufficienti per codificare qualsiasi stringa della lunghezza di caratteri specificata.
