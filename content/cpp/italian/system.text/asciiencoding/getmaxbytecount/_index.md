## ASCIIEncoding::GetMaxByteCount(int) metodo


Restituisce il numero massimo di byte possibile per contenere una stringa di una data quantità di caratteri.

```cpp
int System::Text::ASCIIEncoding::GetMaxByteCount(int char_count) override
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| char_count | int | Quantità di caratteri. |

### Valore di ritorno
