## HtmlOptions::set_DeletePicturesCroppedAreas(bool) metodo


Un flag booleano indica se le parti ritagliate rimangono come parte del documento. Se vero, le parti ritagliate verranno rimosse; se false, saranno serializzate nel documento (che può eventualemente portare a un file più grande)
