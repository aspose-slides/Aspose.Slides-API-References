## PdfOptions::set_JpegQuality(uint8_t) metodo

Imposta un valore che determina la qualità delle immagini JPEG all'interno del documento PDF. Scrivi **uint8_t**.

```cpp
void Aspose::Slides::Export::PdfOptions::set_JpegQuality(uint8_t value) override
```

## Note

Ha effetto solo quando un documento contiene immagini JPEG.

Usa questa proprietà per ottenere o impostare la qualità delle immagini all'interno di un documento quando lo salvi in formato PDF. Il valore può variare da 0 a 100 dove 0 indica la peggiore qualità ma la massima compressione e 100 indica la migliore qualità ma la compressione minima.

Il valore predefinito è **100**.
