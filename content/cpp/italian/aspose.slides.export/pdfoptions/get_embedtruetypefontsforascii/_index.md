## PdfOptions::get_EmbedTrueTypeFontsForASCII() method


Determina se [Aspose.Slides](../../../aspose.slides/) incorporerà i font comuni per il testo ASCII (intervallo di codici 33..127). [Fonts](../../../aspose.slides/fonts/) per i codici di carattere superiori a 127 sono sempre incorporati. L'elenco dei font comuni include i 14 font di base di PDF e font aggiuntivi specificati dall'utente. Leggi **bool**.

```cpp
bool Aspose::Slides::Export::PdfOptions::get_EmbedTrueTypeFontsForASCII() override
```

## Osservazioni


Il valore predefinito è **true**.
