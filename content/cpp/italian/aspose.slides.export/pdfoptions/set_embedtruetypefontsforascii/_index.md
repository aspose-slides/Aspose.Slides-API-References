## PdfOptions::set_EmbedTrueTypeFontsForASCII(bool) metodo

Determina se [Aspose.Slides](../../../aspose.slides/) includerà i font comuni per il testo ASCII (intervallo di codici 33..127). [Fonts](../../../aspose.slides/fonts/) per i codici dei caratteri superiori a 127 sono sempre incorporati. L'elenco dei font comuni include i 14 font di base di PDF e i font aggiuntivi specificati dall'utente. Scrivi **bool**.

```cpp
void Aspose::Slides::Export::PdfOptions::set_EmbedTrueTypeFontsForASCII(bool value) override
```

## Osservazioni

Il valore predefinito è **true**.
