## PdfOptions::get_BestImagesCompressionRatio() metodo


Indica se la compressione più efficace (invece di quella predefinita) per ogni immagine deve essere selezionata automaticamente. Se impostato su **bool**.true, per ogni immagine nella presentazione verrà scelto l'algoritmo di compressione più appropriato, il che porterà a una dimensione minore del documento PDF risultante.

```cpp
bool Aspose::Slides::Export::PdfOptions::get_BestImagesCompressionRatio() override
```

## Osservazioni


La selezione del migliore rapporto di compressione delle immagini è computazionalmente costosa e richiede una quantità aggiuntiva di RAM, e questa opzione è **bool**.false per impostazione predefinita.

Il valore predefinito è **bool**.false.
