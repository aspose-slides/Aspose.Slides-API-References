## IHtmlOptions::get_DeletePicturesCroppedAreas() metodo


Una bandiera boolean indica se le parti ritagliate rimangono come parte del documento. Se true le parti ritagliate verranno rimosse, se false saranno serializzate nel documento (il che può portare a un file più grande) Leggi **bool**.
