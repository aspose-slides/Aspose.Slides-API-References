## IHtmlOptions::set_DeletePicturesCroppedAreas(bool) metodo

Una bandiera booleana indica se le parti ritagliate rimangono come parte del documento. Se true le parti ritagliate saranno rimosse, se false saranno serializzate nel documento (il che può portare a un file più grande) Scrivi **bool**.
