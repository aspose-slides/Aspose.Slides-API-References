## PicturesCompression enum

Rappresenta il livello di compressione delle immagini

```cpp
enum class PicturesCompression
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Dpi330 | 0 | Buona qualità per schermi ad alta definizione (HD) |
| Dpi220 | 1 | Qualità eccellente sulla maggior parte delle stampanti e degli schermi |
| Dpi150 | 2 | Buona per pagine web e proiettori |
| Dpi96 | 3 | Minimizza le dimensioni del documento per la condivisione |
| Dpi72 | 4 | Livello di compressione predefinito |
| DocumentResolution | 5 | Usa la risoluzione del documento - l'immagine non sarà compressa e verrà utilizzata nel documento così com'è |
