## ISVGOptions::get_DeletePicturesCroppedAreas() metodo

Un flag booleano indica se le parti ritagliate rimangono parte del documento. Se true le parti ritagliate verranno rimosse, se false saranno serializzate nel documento (il che può eventualmente portare a un file più grande) Leggi **bool**.
