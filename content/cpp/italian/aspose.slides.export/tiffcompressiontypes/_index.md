## TiffCompressionTypes enum


Fornisce opzioni che controllano come una presentazione viene compressa nel formato TIFF.

```cpp
enum class TiffCompressionTypes
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Default | 0 | Specifica lo schema di compressione predefinito (LZW). |
| None | 1 | Specifica nessuna compressione. |
| CCITT3 | 2 | Specifica lo schema di compressione CCITT3. |
| CCITT4 | 3 | Specifica lo schema di compressione CCITT4. |
| LZW | 4 | Specifica lo schema di compressione LZW (Predefinito). |
| RLE | 5 | Specifica lo schema di compressione RLE. |
