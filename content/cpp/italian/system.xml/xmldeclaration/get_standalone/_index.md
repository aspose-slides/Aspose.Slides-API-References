## XmlDeclaration::get_Standalone() metodo

Restituisce il valore dell'attributo standalone.

```cpp
String System::Xml::XmlDeclaration::get_Standalone()
```

### Valore di ritorno

I valori validi sono **yes** se tutte le dichiarazioni di entità richieste dal documento XML sono contenute nel documento o **no** se è necessario un documento di definizione del tipo esterno (DTD). Se un attributo standalone non è presente nella dichiarazione XML, questo metodo restituisce [String::Empty](../../../system/string/empty/).
