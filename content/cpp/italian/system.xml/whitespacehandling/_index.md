## WhitespaceHandling enum

Specifica come viene gestito lo spazio bianco.

```cpp
enum class WhitespaceHandling
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| All | 0 | Restituisce i nodi **Whitespace** e **SignificantWhitespace**. Questo è il valore predefinito. |
| Significant | 1 | Restituisce solo i nodi **SignificantWhitespace**. |
| None | 2 | Non restituisce nodi **Whitespace** né **SignificantWhitespace**. |
