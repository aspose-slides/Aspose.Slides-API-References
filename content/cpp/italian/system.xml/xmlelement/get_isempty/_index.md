## XmlElement::get_IsEmpty() metodo

Restituisce il formato del tag dell'elemento.

```cpp
bool System::Xml::XmlElement::get_IsEmpty()
```

### Valore di ritorno

**true** se l'elemento deve essere serializzato nel formato tag breve \"<tt><item/></tt>\"; **false** per il formato lungo \"<tt><item></item></tt>\".
