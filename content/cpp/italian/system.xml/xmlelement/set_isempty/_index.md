## XmlElement::set_IsEmpty(bool) metodo


Imposta il formato del tag dell'elemento.

```cpp
void System::Xml::XmlElement::set_IsEmpty(bool value)
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| value | **bool** | Il valore da impostare. Quando si imposta questo valore, se impostato a **true**, i figli dell'elemento vengono rimossi e l'elemento viene serializzato nel formato di tag breve. Se impostato a **false**, il valore viene modificato (indipendentemente dal fatto che l'elemento abbia o meno contenuto); se l'elemento è vuoto, viene serializzato nel formato lungo. |
