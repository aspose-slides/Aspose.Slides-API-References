## XmlValidatingReader::get_CanResolveEntity() metodo


Restituisce un valore che indica se questo lettore può analizzare e risolvere le entità.

```cpp
bool System::Xml::XmlValidatingReader::get_CanResolveEntity() override
```


### Valore restituito

**true** se il lettore può analizzare e risolvere le entità; altrimenti, **false**. [XmlValidatingReader](../) restituisce sempre **true**.
