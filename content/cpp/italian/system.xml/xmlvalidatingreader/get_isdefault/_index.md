## XmlValidatingReader::get_IsDefault() metodo

Restituisce un valore che indica se il nodo corrente è un attributo generato dal valore predefinito definito nella definizione del tipo di documento (DTD) o nello schema.

```cpp
bool System::Xml::XmlValidatingReader::get_IsDefault() override
```

### Valore restituito

**true** se il nodo corrente è un attributo il cui valore è stato generato dal valore predefinito definito nel DTD o nello schema; **false** se il valore dell'attributo è stato impostato esplicitamente.
