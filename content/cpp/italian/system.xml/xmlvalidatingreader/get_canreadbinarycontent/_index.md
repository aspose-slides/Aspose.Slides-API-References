## XmlValidatingReader::get_CanReadBinaryContent() metodo

```cpp
bool System::Xml::XmlValidatingReader::get_CanReadBinaryContent() override
```

**true** se i metodi di lettura del contenuto binario sono implementati; altrimenti **false**. La classe [XmlValidatingReader](../) restituisce **true**.
