## XmlValidatingReader::ReadString() metodo

Legge il contenuto di un elemento o di un nodo di testo come stringa.

```cpp
String System::Xml::XmlValidatingReader::ReadString() override
```

### Valore di ritorno

Il contenuto dell'elemento o del nodo di testo. Può essere una stringa vuota se il lettore è posizionato su qualcosa di diverso da un elemento o nodo di testo, oppure se non è presente altro contenuto testuale da restituire nel contesto corrente.
