## XmlDocument::get_IsReadOnly() metodo

Restituisce un valore che indica se il nodo corrente è di sola lettura.

```cpp
bool System::Xml::XmlDocument::get_IsReadOnly() override
```

### Valore di ritorno

**true** se il nodo corrente è di sola lettura; altrimenti **false**. I nodi [XmlDocument](../) restituiscono sempre **false**.
