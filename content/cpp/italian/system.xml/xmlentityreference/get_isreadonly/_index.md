## XmlEntityReference::get_IsReadOnly() metodo


Restituisce un valore che indica se il nodo è di sola lettura.

```cpp
bool System::Xml::XmlEntityReference::get_IsReadOnly() override
```


### Valore di ritorno

**true** se il nodo è di sola lettura; altrimenti **false**. Poiché i nodi [XmlEntityReference](../) sono di sola lettura, questo metodo restituisce sempre **true**.
