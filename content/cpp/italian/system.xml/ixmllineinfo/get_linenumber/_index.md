## IXmlLineInfo::get_LineNumber() metodo


Restituisce il numero di riga corrente.

```cpp
virtual int32_t System::Xml::IXmlLineInfo::get_LineNumber()=0
```


### Valore restituito

Il numero di riga corrente o 0 se le informazioni sulla riga non sono disponibili (per esempio, [IXmlLineInfo::HasLineInfo](../haslineinfo/) restituisce **false**).
