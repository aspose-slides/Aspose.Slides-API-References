## IXmlLineInfo::get_LinePosition() metodo


Restituisce la posizione corrente della riga.

```cpp
virtual int32_t System::Xml::IXmlLineInfo::get_LinePosition()=0
```


### Valore di ritorno

La posizione corrente della riga o 0 se non sono disponibili informazioni sulla riga (ad esempio, [IXmlLineInfo::HasLineInfo](../haslineinfo/) restituisce **false**).
