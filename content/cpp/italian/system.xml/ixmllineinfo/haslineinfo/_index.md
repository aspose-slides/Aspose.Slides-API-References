## IXmlLineInfo::HasLineInfo() metodo

Restituisce un valore che indica se la classe può restituire le informazioni di riga.

```cpp
virtual bool System::Xml::IXmlLineInfo::HasLineInfo()=0
```

### Valore di ritorno

**true** se [IXmlLineInfo::get_LineNumber](../get_linenumber/) e [IXmlLineInfo::get_LinePosition](../get_lineposition/) possono essere forniti; altrimenti, **false**.
