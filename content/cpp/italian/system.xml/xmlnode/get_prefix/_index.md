## XmlNode::get_Prefix() metodo


Restituisce il prefisso di spazio dei nomi di questo nodo.

```cpp
virtual String System::Xml::XmlNode::get_Prefix()
```


### Valore di ritorno

Il prefisso di spazio dei nomi di questo nodo. Per esempio, **Prefix** è **bk** per l'elemento **<bk:book>**. Se non esiste alcun prefisso, questo metodo restituisce [String::Empty](../../../system/string/empty/).
