## XmlWriterSettings::set_NamespaceHandling(System::Xml::NamespaceHandling) metodo

Imposta un valore che indica se [XmlWriter](../../xmlwriter/) deve rimuovere le dichiarazioni di namespace duplicate durante la scrittura del contenuto XML. Il comportamento predefinito è che lo scrittore emetta tutte le dichiarazioni di namespace presenti nel risolutore di namespace dello scrittore.

```cpp
void System::Xml::XmlWriterSettings::set_NamespaceHandling(System::Xml::NamespaceHandling value)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| value | [System::Xml::NamespaceHandling](../../namespacehandling/) | Il valore da impostare. |
