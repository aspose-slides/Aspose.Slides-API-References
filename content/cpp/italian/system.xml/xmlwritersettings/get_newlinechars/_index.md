## XmlWriterSettings::get_NewLineChars() metodo


Restituisce la stringa di caratteri da utilizzare per le interruzioni di riga.

```cpp
String System::Xml::XmlWriterSettings::get_NewLineChars()
```


### Valore di ritorno

La stringa di caratteri da utilizzare per le interruzioni di riga. Può essere impostata a qualsiasi valore di stringa. Tuttavia, per garantire XML valido, si dovrebbero specificare solo caratteri di spazio bianchi validi, come caratteri di spazio, tabulazioni, ritorni a capo o interruzioni di riga. Il valore predefinito è **\r\n** (ritorno a capo, nuova linea).
