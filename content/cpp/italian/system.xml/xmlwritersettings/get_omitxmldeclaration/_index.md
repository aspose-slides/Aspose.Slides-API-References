## XmlWriterSettings::get_OmitXmlDeclaration() metodo


Restituisce un valore che indica se omettere una dichiarazione XML.

```cpp
bool System::Xml::XmlWriterSettings::get_OmitXmlDeclaration()
```


### Valore restituito

**true** per omettere la dichiarazione XML; altrimenti, **false**. Il valore predefinito è **false**, viene scritta una dichiarazione XML.
