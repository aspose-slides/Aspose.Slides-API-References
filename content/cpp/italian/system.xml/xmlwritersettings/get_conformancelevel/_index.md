## XmlWriterSettings::get_ConformanceLevel() metodo

Restituisce il livello di conformità che lo scrittore XML verifica nell'output XML.

```cpp
System::Xml::ConformanceLevel System::Xml::XmlWriterSettings::get_ConformanceLevel()
```

### Valore di ritorno

Uno dei valori dell'enumerazione che specifica il livello di conformità (documento, frammento, o rilevamento automatico). Il valore predefinito è [ConformanceLevel::Document](../../conformancelevel/).
