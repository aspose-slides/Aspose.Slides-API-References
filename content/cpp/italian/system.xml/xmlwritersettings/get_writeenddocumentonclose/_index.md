## XmlWriterSettings::get_WriteEndDocumentOnClose() metodo


Restituisce un valore che indica se il [XmlWriter](../../xmlwriter/) aggiungerà i tag di chiusura a tutti i tag di elemento non chiusi quando viene chiamato il metodo [XmlWriter::Close](../../xmlwriter/close/).

```cpp
bool System::Xml::XmlWriterSettings::get_WriteEndDocumentOnClose()
```


### Valore di ritorno

**true** se tutti i tag di elemento non chiusi verranno chiusi; altrimenti, **false**. Il valore predefinito è **true**.
