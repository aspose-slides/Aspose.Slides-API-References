## XmlWriterSettings::get_IndentChars() metodo


Restituisce la stringa di caratteri da utilizzare per l'indentazione. Questa impostazione viene utilizzata quando il valore [XmlWriterSettings::set_Indent](../set_indent/) è impostato su **true**.

```cpp
String System::Xml::XmlWriterSettings::get_IndentChars()
```


### Valore restituito

La stringa di caratteri da utilizzare per l'indentazione. Questa può essere impostata a qualsiasi valore stringa. Tuttavia, per garantire XML valido, è necessario specificare solo caratteri di spazio bianchi validi, come spazi, tabulazioni, ritorni a capo o avanzamenti di riga. Il valore predefinito è due spazi.
