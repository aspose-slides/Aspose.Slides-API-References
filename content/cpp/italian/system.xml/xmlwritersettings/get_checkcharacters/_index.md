## XmlWriterSettings::get_CheckCharacters() metodo


Restituisce un valore che indica se lo scrittore XML deve verificare che tutti i caratteri nel documento siano conformi alla sezione \"2.2 Characters\" dello standard W3C [XML 1.0 Recommendation](https://www.w3.org/TR/REC-xml/#charsets).

```cpp
bool System::Xml::XmlWriterSettings::get_CheckCharacters()
```


### Valore di ritorno

**true** per eseguire il controllo dei caratteri; altrimenti, **false**. Il valore predefinito è **true**.
