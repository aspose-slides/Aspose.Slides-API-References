## XmlWriterSettings::get_DoNotEscapeUriAttributes() metodo


Restituisce un valore che indica se il [XmlWriter](../../xmlwriter/) non esegue l'escape degli attributi URI.

```cpp
bool System::Xml::XmlWriterSettings::get_DoNotEscapeUriAttributes()
```


### Valore restituito

**true** se il [XmlWriter](../../xmlwriter/) non esegue l'escape degli attributi URI; altrimenti, **false**. Il valore predefinito è **false**.
