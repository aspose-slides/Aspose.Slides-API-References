## XmlWriter::get_XmlSpace() method

Quando sovrascritto in una classe derivata, ottiene un XmlSpace che rappresenta l'ambito **xml:space** corrente.

```cpp
virtual System::Xml::XmlSpace System::Xml::XmlWriter::get_XmlSpace()
```

### Valore di ritorno

Un XmlSpace che rappresenta l'ambito **xml:space** corrente.

| Valore | Significato |
| --- | --- |
| `None`| Questo è il valore predefinito se non esiste alcun ambito `xml:space`. |
| `Default`| L'ambito corrente è `xml:space="default"`. |
| `Preserve`| L'ambito corrente è `xml:space="preserve"`. |
