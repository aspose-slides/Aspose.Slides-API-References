## XmlNodeReader::get_HasValue() metodo


Restituisce un valore che indica se il nodo corrente può avere un valore [XmlNodeReader::get_Value](../get_value/).

```cpp
bool System::Xml::XmlNodeReader::get_HasValue() override
```


### Valore restituito

**true** se il nodo su cui il lettore è attualmente posizionato può avere un **Value**; altrimenti, **false**.
