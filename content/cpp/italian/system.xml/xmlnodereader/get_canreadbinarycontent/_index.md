## XmlNodeReader::get_CanReadBinaryContent() metodo

Restituisce un valore che indica se il [XmlNodeReader](../) implementa i metodi di lettura del contenuto binario.

```cpp
bool System::Xml::XmlNodeReader::get_CanReadBinaryContent() override
```

### Valore di ritorno

**true** se i metodi di lettura del contenuto binario sono implementati; altrimenti **false**. Il [XmlNodeReader](../) classe restituisce sempre **true**.
