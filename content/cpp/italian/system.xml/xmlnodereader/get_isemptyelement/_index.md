## XmlNodeReader::get_IsEmptyElement() metodo

Restituisce un valore che indica se il nodo corrente è un elemento vuoto (ad esempio, **<MyElement/>**).

```cpp
bool System::Xml::XmlNodeReader::get_IsEmptyElement() override
```

### Valore di ritorno

**true** se il nodo corrente è un elemento ([XmlNodeReader::get_NodeType](../get_nodetype/) uguale a [XmlNodeType::Element](../../xmlnodetype/)) e termina con **/>**; altrimenti, **false**.
