## XmlReaderSettings::get_IgnoreWhitespace() metodo

Restituisce un valore che indica se ignorare gli spazi bianchi insignificanti.

```cpp
bool System::Xml::XmlReaderSettings::get_IgnoreWhitespace()
```

### Valore restituito

**true** per ignorare gli spazi bianchi; altrimenti **false**. Il valore predefinito è **false**.
