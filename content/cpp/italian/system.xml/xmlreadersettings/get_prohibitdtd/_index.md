## XmlReaderSettings::get_ProhibitDtd() metodo

Restituisce un valore che indica se è necessario proibire l'elaborazione della definizione del tipo di documento (DTD).

```cpp
bool System::Xml::XmlReaderSettings::get_ProhibitDtd()
```

### Valore di ritorno

**true** per proibire l'elaborazione DTD; altrimenti **false**. Il valore predefinito è **true**.

Obsoleto
:   Questo metodo è obsoleto. Usa [XmlTextReader::get_DtdProcessing](../../xmltextreader/get_dtdprocessing/) invece.
