## XmlReaderSettings::set_MaxCharactersInDocument(int64_t) metodo

Imposta un valore che indica il numero massimo consentito di caratteri in un documento XML. Un valore zero (0) indica nessun limite alla dimensione del documento XML. Un valore non zero specifica la dimensione massima, in caratteri.
