## XmlReaderSettings::get_CloseInput() metodo


Restituisce un valore che indica se lo stream sottostante o TextReader dovrebbe essere chiuso quando il lettore viene chiuso.

```cpp
bool System::Xml::XmlReaderSettings::get_CloseInput()
```


### Valore restituito

**true** per chiudere lo stream sottostante o TextReader quando il lettore viene chiuso; altrimenti **false**. Il valore predefinito è **false**.
