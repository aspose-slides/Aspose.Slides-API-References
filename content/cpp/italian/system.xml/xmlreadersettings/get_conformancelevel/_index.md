## XmlReaderSettings::get_ConformanceLevel() metodo

Restituisce il livello di conformità a cui il [XmlReader](../../xmlreader/) dovrà conformarsi.

```cpp
System::Xml::ConformanceLevel System::Xml::XmlReaderSettings::get_ConformanceLevel()
```

### Valore di ritorno

Uno dei valori dell'enumerazione che specifica il livello di conformità che il lettore XML applicherà. Il valore predefinito è [ConformanceLevel::Document](../../conformancelevel/).
