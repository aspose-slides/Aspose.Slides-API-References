## XmlAttribute::get_Specified() metodo


Restituisce un valore che indica se il valore dell'attributo è stato impostato esplicitamente.

```cpp
virtual bool System::Xml::XmlAttribute::get_Specified()
```


### Valore di ritorno

**true** se questo attributo è stato assegnato esplicitamente a un valore nel documento di istanza originale; altrimenti, **false**. Un valore **false** indica che il valore dell'attributo proviene dal DTD.
