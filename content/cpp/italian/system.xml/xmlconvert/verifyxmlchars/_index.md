## XmlConvert::VerifyXmlChars(const String\&) metodo


Restituisce la stringa passata se tutti i caratteri e le coppie di caratteri surrogati nell'argomento stringa sono caratteri XML validi, altrimenti viene lanciata un'XmlException con informazioni sul primo carattere non valido riscontrato.

```cpp
static String System::Xml::XmlConvert::VerifyXmlChars(const String &content)
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| content | const [String](../../../system/string/)\& | [String](../../../system/string/) che contiene i caratteri da verificare. |

### Valore restituito

Restituisce la stringa passata se tutti i caratteri e le coppie di caratteri surrogati nell'argomento stringa sono caratteri XML validi, altrimenti viene lanciata un'XmlException con informazioni sul primo carattere non valido riscontrato.
