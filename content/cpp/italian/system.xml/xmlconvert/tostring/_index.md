## XmlConvert::ToString(DateTimeOffset, const String\&) metodo

Converte il [DateTimeOffset](../../../system/datetimeoffset/) fornito in un [String](../../../system/string/) nel formato specificato.

```cpp
static String System::Xml::XmlConvert::ToString(DateTimeOffset value, const String &format)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| value | [DateTimeOffset](../../../system/datetimeoffset/) | Il [DateTimeOffset](../../../system/datetimeoffset/) da convertire. |
| format | const [String](../../../system/string/)\& | Il formato a cui **s** viene convertito. Il parametro format può essere qualsiasi sottoinsieme della Raccomandazione W3C per il tipo XML dateTime. Per ulteriori informazioni, vedere la sezione [dateTime](https://www.w3.org/TR/xmlschema-2/#dateTime) della specifica XML [Schema](../../../system.xml.schema/). |

### Valore di ritorno

Una rappresentazione [String](../../../system/string/) nel formato specificato del [DateTimeOffset](../../../system/datetimeoffset/) fornito.
