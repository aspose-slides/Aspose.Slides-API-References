## XmlConvert::VerifyNCName(const String\&) metodo

Verifica che il nome sia un **NCName** valido secondo la raccomandazione W3C Extended Markup Language. Un **NCName** è un nome che non può contenere due punti.

```cpp
static String System::Xml::XmlConvert::VerifyNCName(const String &name)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| name | const [String](../../../system/string/)\& | Il nome da verificare. |

### Valore di ritorno

Il nome, se è un NCName valido.
