## XmlNodeChangedEventArgs::get_Action() metodo

Restituisce un valore che indica quale tipo di evento di modifica del nodo si sta verificando.

```cpp
XmlNodeChangedAction System::Xml::XmlNodeChangedEventArgs::get_Action()
```

### Valore restituito

Uno dei valori dell'enumerazione che descrive l'evento di modifica del nodo. Il valore **Action** non differenzia quando l'evento si è verificato (prima o dopo). È possibile creare gestori di eventi separati per gestire entrambe le istanze.
