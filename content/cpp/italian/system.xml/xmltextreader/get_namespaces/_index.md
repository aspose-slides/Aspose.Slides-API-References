## XmlTextReader::get_Namespaces() metodo

Restituisce un valore che indica se abilitare il supporto dei namespace.

```cpp
bool System::Xml::XmlTextReader::get_Namespaces()
```

### Valore di ritorno

**true** per abilitare il supporto dei namespace; altrimenti, **false**. Il valore predefinito è **true**.
