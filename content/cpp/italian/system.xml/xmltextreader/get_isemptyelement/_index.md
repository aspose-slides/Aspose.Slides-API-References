## XmlTextReader::get_IsEmptyElement() metodo


Restituisce un valore che indica se il nodo corrente è un elemento vuoto (ad esempio, **<MyElement/>**).

```cpp
bool System::Xml::XmlTextReader::get_IsEmptyElement() override
```


### Valore di ritorno

**true** se il nodo corrente è un elemento ([XmlTextReader::get_NodeType](../get_nodetype/) valore è uguale a [XmlNodeType::Element](../../xmlnodetype/)) che termina con **/>**; altrimenti, **false**.
