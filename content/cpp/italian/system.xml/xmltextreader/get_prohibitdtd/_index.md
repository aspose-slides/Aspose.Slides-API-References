## XmlTextReader::get_ProhibitDtd() metodo


Restituisce un valore che indica se consentire l'elaborazione DTD.

```cpp
bool System::Xml::XmlTextReader::get_ProhibitDtd()
```


### Valore di ritorno

**true** per vietare l'elaborazione DTD; altrimenti **false**. Il valore predefinito è **false**.

Deprecato
:   Questo metodo è obsoleto. Usa [XmlTextReader::get_DtdProcessing](../get_dtdprocessing/) al suo posto.
