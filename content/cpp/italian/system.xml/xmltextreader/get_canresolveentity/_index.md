## XmlTextReader::get_CanResolveEntity() metodo


Restituisce un valore che indica se questo lettore può analizzare e risolvere le entità.

```cpp
bool System::Xml::XmlTextReader::get_CanResolveEntity() override
```


### Valore restituito

**true** se il lettore può analizzare e risolvere le entità; altrimenti, **false**. La classe [XmlTextReader](../) restituisce sempre **true**.
