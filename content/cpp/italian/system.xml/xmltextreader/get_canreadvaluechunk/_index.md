## XmlTextReader::get_CanReadValueChunk() metodo


Restituisce un valore che indica se il [XmlTextReader](../) implementa il metodo [XmlReader::ReadValueChunk](../../xmlreader/readvaluechunk/).

```cpp
bool System::Xml::XmlTextReader::get_CanReadValueChunk() override
```


### Valore di ritorno

**true** se il [XmlTextReader](../) implementa il metodo [XmlReader::ReadValueChunk](../../xmlreader/readvaluechunk/); altrimenti **false**. La classe [XmlTextReader](../) restituisce sempre **false**.
