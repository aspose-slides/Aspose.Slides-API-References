## XmlTextReader::get_CanReadBinaryContent() metodo


Restituisce un valore che indica se il [XmlTextReader](../) implementa i metodi di lettura del contenuto binario.

```cpp
bool System::Xml::XmlTextReader::get_CanReadBinaryContent() override
```


### Valore restituito

**true** se i metodi di lettura del contenuto binario sono implementati; altrimenti **false**. La classe [XmlTextReader](../) restituisce sempre **true**.
