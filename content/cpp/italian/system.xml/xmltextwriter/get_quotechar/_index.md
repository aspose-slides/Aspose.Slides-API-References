## XmlTextWriter::get_QuoteChar() metodo


Restituisce quale carattere utilizzare per citare i valori degli attributi.

```cpp
char16_t System::Xml::XmlTextWriter::get_QuoteChar()
```


### Valore di ritorno

Il carattere da utilizzare per citare i valori degli attributi. Deve essere una virgoletta singola **'** o una virgoletta doppia **\"**. Il valore predefinito è una virgoletta doppia.
