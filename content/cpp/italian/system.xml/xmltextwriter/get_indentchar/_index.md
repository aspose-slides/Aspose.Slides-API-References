## XmlTextWriter::get_IndentChar() metodo

Restituisce quale carattere utilizzare per l'indentazione quando [XmlTextWriter::set_Formatting](../set_formatting/) è impostato a [Formatting::Indented](../../formatting/).

```cpp
char16_t System::Xml::XmlTextWriter::get_IndentChar()
```

### Valore di ritorno

Il carattere da utilizzare per l'indentazione. Il valore predefinito è lo spazio.
