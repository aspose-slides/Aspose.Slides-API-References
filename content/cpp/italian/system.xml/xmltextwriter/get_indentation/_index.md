## XmlTextWriter::get_Indentation() metodo

Restituisce quanti IndentChars scrivere per ogni livello nella gerarchia quando [XmlTextWriter::set_Formatting](../set_formatting/) è impostato su [Formatting::Indented](../../formatting/).

```cpp
int32_t System::Xml::XmlTextWriter::get_Indentation()
```

### Valore restituito

Numero di **IndentChars** per ogni livello. Il valore predefinito è 2.
