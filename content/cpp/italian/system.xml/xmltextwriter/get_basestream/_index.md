## XmlTextWriter::get_BaseStream() metodo

Restituisce l'oggetto stream sottostante.

```cpp
SharedPtr<IO::Stream> System::Xml::XmlTextWriter::get_BaseStream()
```

### Valore di ritorno

Lo stream a cui il [XmlTextWriter](../) sta scrivendo o **nullptr** se il [XmlTextWriter](../) è stato costruito usando un TextWriter che non eredita dalla classe StreamWriter.
