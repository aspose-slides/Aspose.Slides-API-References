## XmlTextWriter::LookupPrefix(String) metodo

Restituisce il prefisso più vicino definito nell'ambito del namespace corrente per il namespace URI.

```cpp
String System::Xml::XmlTextWriter::LookupPrefix(String ns) override
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| ns | [String](../../../system/string/) | Namespace URI il cui prefisso si desidera trovare. |

### Valore di ritorno

Il prefisso corrispondente. O **nullptr** se nessun namespace URI corrispondente è trovato nell'ambito corrente.
