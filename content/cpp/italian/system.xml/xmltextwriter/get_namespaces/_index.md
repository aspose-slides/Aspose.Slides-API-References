## XmlTextWriter::get_Namespaces() metodo


Restituisce un valore che indica se abilitare il supporto degli spazi dei nomi.

```cpp
bool System::Xml::XmlTextWriter::get_Namespaces()
```


### Valore di ritorno

**true** per supportare gli spazi dei nomi; altrimenti, **false**. Il valore predefinito è **true**.
