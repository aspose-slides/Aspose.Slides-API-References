## IXmlNamespaceResolver::LookupPrefix(const String\&) metodo

Restituisce il prefisso che è associato all'URI dello spazio dei nomi specificato.

```cpp
virtual String System::Xml::IXmlNamespaceResolver::LookupPrefix(const String &namespaceName)=0
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| namespaceName | const [String](../../../system/string/)\& | L'URI dello spazio dei nomi di cui si desidera trovare il prefisso. |

### Valore di ritorno

Il prefisso che è associato all'URI dello spazio dei nomi; **nullptr** se l'URI dello spazio dei nomi non è associato a un prefisso.
