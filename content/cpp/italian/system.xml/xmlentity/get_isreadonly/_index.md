## XmlEntity::get_IsReadOnly() metodo


Restituisce un valore che indica se il nodo è di sola lettura.

```cpp
bool System::Xml::XmlEntity::get_IsReadOnly() override
```


### Valore restituito

**true** se il nodo è di sola lettura; altrimenti, **false**. Poiché i nodi [XmlEntity](../) sono di sola lettura, questo metodo restituisce sempre **true**.
