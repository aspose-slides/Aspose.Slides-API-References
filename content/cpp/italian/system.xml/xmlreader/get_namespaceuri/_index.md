## XmlReader::get_NamespaceURI() metodo

Quando viene sovrascritto in una classe derivata, restituisce l'URI dello spazio dei nomi (come definito nella specifica W3C Namespace) del nodo su cui è posizionato il lettore.

```cpp
virtual String System::Xml::XmlReader::get_NamespaceURI()=0
```

### Valore di ritorno

L'URI dello spazio dei nomi del nodo corrente; altrimenti una stringa vuota.
