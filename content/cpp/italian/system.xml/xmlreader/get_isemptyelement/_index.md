## XmlReader::get_IsEmptyElement() method

Quando viene sovrascritto in una classe derivata, restituisce un valore che indica se il nodo corrente è un elemento vuoto (ad esempio, **<MyElement/>**).

```cpp
virtual bool System::Xml::XmlReader::get_IsEmptyElement()=0
```

### Valore di ritorno

**true** se il nodo corrente è un elemento ([XmlReader::get_NodeType](../get_nodetype/) uguale a [XmlNodeType::Element](../../xmlnodetype/)) che termina con **/>**; altrimenti, **false**.
