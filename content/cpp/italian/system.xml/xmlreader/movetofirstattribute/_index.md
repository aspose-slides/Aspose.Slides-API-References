## XmlReader::MoveToFirstAttribute() metodo


Quando sovrascritto in una classe derivata, si sposta al primo attributo.

```cpp
virtual bool System::Xml::XmlReader::MoveToFirstAttribute()=0
```


### Valore di ritorno

**true** se un attributo esiste (il lettore si sposta al primo attributo); altrimenti, **false** (la posizione del lettore non cambia).
