## XmlReader::get_IsDefault() method

Quando viene sovrascritto in una classe derivata, restituisce un valore che indica se il nodo corrente è un attributo generato dal valore predefinito definito nel DTD o nello schema.

```cpp
virtual bool System::Xml::XmlReader::get_IsDefault()
```

### Valore di ritorno

**true** se il nodo corrente è un attributo il cui valore è stato generato dal valore predefinito definito nel DTD o nello schema; **false** se il valore dell'attributo è stato impostato esplicitamente.
