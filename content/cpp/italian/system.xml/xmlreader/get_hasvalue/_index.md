## XmlReader::get_HasValue() metodo


Quando viene sovrascritto in una classe derivata, restituisce un valore che indica se il nodo corrente può avere un valore [XmlReader::get_Value](../get_value/).

```cpp
virtual bool System::Xml::XmlReader::get_HasValue()
```


### Valore restituito

**true** se il nodo su cui il lettore è attualmente posizionato può avere un **Value**; altrimenti, **false**. Se **false**, il nodo ha un valore di [String::Empty](../../../system/string/empty/).
