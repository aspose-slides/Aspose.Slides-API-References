## XmlReader::MoveToNextAttribute() metodo


Quando viene sovrascritto in una classe derivata, passa all'attributo successivo.

```cpp
virtual bool System::Xml::XmlReader::MoveToNextAttribute()=0
```


### Valore di ritorno

**true** se esiste un attributo successivo; **false** se non ci sono altri attributi.
