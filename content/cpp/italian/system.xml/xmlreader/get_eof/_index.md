## XmlReader::get_EOF() metodo

Quando sovrascritto in una classe derivata, restituisce un valore che indica se il lettore è posizionato alla fine del flusso.

```cpp
virtual bool System::Xml::XmlReader::get_EOF()=0
```

### Valore di ritorno

**true** se il lettore è posizionato alla fine del flusso; altrimenti, **false**.
