## XmlNamespaceManager::HasNamespace(String) metodo


Restituisce un valore che indica se il prefisso fornito ha un namespace definito per lo scopo attualmente spinto.

```cpp
virtual bool System::Xml::XmlNamespaceManager::HasNamespace(String prefix)
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| prefix | [String](../../../system/string/) | Il prefisso del namespace che si desidera trovare. |

### Valore di ritorno

**true** se è definito un namespace; altrimenti, **false**.
