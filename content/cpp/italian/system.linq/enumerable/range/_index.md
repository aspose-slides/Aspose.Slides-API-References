## Enumerable::Range(int32_t, int32_t) metodo


Genera una sequenza di numeri interi all'interno di un intervallo specificato.

```cpp
static SharedPtr<Collections::Generic::IEnumerable<int32_t>> System::Linq::Enumerable::Range(int32_t start, int32_t count)
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| start | **int32_t** | Il valore del primo intero nella sequenza. |
| count | **int32_t** | Il numero di interi sequenziali da generare. |

### Valore di ritorno

Un IEnumerable di **int32_t** che contiene un intervallo di numeri interi sequenziali.
