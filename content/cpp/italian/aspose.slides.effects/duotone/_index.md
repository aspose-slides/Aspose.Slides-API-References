## Duotone classe

Rappresenta un effetto [Duotone](./). Per ogni pixel, combina Color1 e Color2 mediante un'interpolazione lineare per determinare il nuovo colore di quel pixel.

```cpp
class Duotone : public Aspose::Slides::Effects::ImageTransformOperation,
                public Aspose::Slides::Effects::IDuotone,
                public Aspose::Slides::Effects::IVisualEffect
```
