## Classi

| Classe | Descrizione |
| --- | --- |
| [BitVector32](./bitvector32/) | Fornisce un semplice vettore di bit leggero con facile accesso intero o [Boolean](../system/boolean/) a una memoria da 32 bit. |
| [NameValueCollection](./namevaluecollection/) | Raccolta di chiavi [String](../system/string/) associate e valori [String](../system/string/) che possono essere accessi sia con la chiave sia con l'indice. |
| [StringCollection](./stringcollection/) | Elenco indicizzato di stringhe. Gli oggetti di questa classe dovrebbero essere allocati solo utilizzando la funzione [System::MakeObject()](../system/makeobject/). Non creare mai un'istanza di questo tipo sullo stack o usando l'operatore new, poiché causerà errori di runtime e/o fault di asserzione. Avvolgi sempre questa classe in un puntatore [System::SmartPtr](../system/smartptr/) e usa questo puntatore per passarlo alle funzioni come argomento. |
| [StringCollectionPtr](./stringcollectionptr/) | Raccolta di stringhe puntatore con operatore di accesso. |
| [StringDictionary](./stringdictionary/) | [String](../system/string/) a dizionario di stringhe. Gli oggetti di questa classe dovrebbero essere allocati solo utilizzando la funzione [System::MakeObject()](../system/makeobject/). Non creare mai un'istanza di questo tipo sullo stack o usando l'operatore new, poiché causerà errori di runtime e/o fault di asserzione. Avvolgi sempre questa classe in un puntatore [System::SmartPtr](../system/smartptr/) e usa questo puntatore per passarlo alle funzioni come argomento. |
