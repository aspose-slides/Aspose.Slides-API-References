## StringCollection classe

Elenco indicizzato di stringhe. Gli oggetti di questa classe dovrebbero essere allocati solo tramite la funzione [System::MakeObject()](../../system/makeobject/). Non creare mai un'istanza di questo tipo sullo stack o usando l'operatore new, poiché ciò provocherà errori di runtime e/o errori di asserzione. Avvolgi sempre questa classe in un puntatore [System::SmartPtr](../../system/smartptr/) e utilizza questo puntatore per passarlo alle funzioni come argomento.

```cpp
class StringCollection : public System::Collections::Generic::IEnumerable<System::String>
```
