## StringCollection::cend() const metodo

Restituisce un iteratore all'elemento successivo all'ultimo elemento del contenitore. Questo elemento funge da segnaposto; tentare di accedervi provoca un comportamento indefinito.

```cpp
const_iterator System::Collections::Specialized::StringCollection::cend() const noexcept
```

### Valore di ritorno

Un iteratore che punta all'elemento teorico const-qualificato posizionato dopo l'ultimo elemento del contenitore.
