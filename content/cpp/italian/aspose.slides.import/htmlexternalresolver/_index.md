## Osservazioni

Deprecato
:   Obsoleto. Usa [ExternalResourceResolver](../externalresourceresolver/) invece. Sarà rimosso nella versione 17.12.

L'utilizzo di questo risolutore potrebbe creare una vulnerabilità quando un file HTML fornito dal client induce il software server a ottenere un file locale o di rete. Usare con cautela. È consigliato non specificare [HtmlExternalResolver](./) affatto (verranno letti solo gli oggetti incorporati) o creare una sottoclasse che verifichi se l'uri specificato è valido.
