## Classes

| Class | Description |
| --- | --- |
| [DataGrid](./datagrid/) | Classe Dummy che rende possibile collegare il codice tradotto con i riferimenti [DataGrid](./datagrid/), ma non eseguirlo. Non contiene membri implementati correttamente. Gli oggetti di questa classe dovrebbero essere allocati solo usando la funzione [System::MakeObject()](../system/makeobject/). Non creare mai un'istanza di questo tipo sullo stack o usando l'operatore new, poiché provocherà errori di runtime e/o errori di asserzione. Avvolgi sempre questa classe in un puntatore [System::SmartPtr](../system/smartptr/) e usa questo puntatore per passarla alle funzioni come argomento. |
