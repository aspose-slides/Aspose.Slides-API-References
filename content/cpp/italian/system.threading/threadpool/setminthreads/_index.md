## ThreadPool::SetMinThreads(int, int) metodo


Imposta il numero minimo di thread posseduti dal pool.

```cpp
static bool System::Threading::ThreadPool::SetMinThreads(int wt, int cpt)
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| wt | int | Numero minimo di thread di lavoro. |
| cpt | int | Numero minimo di [IO](../../../system.io/) thread. |

### Valore restituito

True se i parametri sono stati accettati, false altrimenti.
