## Thread::get_ManagedThreadId() const metodo


Ottiene l'identificatore del thread. Può essere ottenuto dal OS, ma se l'identificatore del thread del OS supera i limiti di int, gli ID dei thread possono sovrapporsi.

```cpp
int System::Threading::Thread::get_ManagedThreadId() const
```


### Valore di ritorno

Identificatore pseudo-unico del thread.
