## Thread::get_IsThreadPoolThread() metodo

Verifica se il thread è posseduto da un pool di thread.

```cpp
bool System::Threading::Thread::get_IsThreadPoolThread()
```

### Valore restituito

True se il thread fa parte di [ThreadPool](../../threadpool/), false altrimenti.
