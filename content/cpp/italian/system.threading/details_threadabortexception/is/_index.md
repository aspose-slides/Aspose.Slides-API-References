## Details_ThreadAbortException::Is(const System::TypeInfo\&) const method




```cpp
bool System::Threading::Details_ThreadAbortException::Is(const System::TypeInfo &target) const override
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| target | const [System::TypeInfo](../../../system/typeinfo/)\& | [TypeInfo](../../../system/typeinfo/) struttura che descrive il tipo da testare con l'oggetto corrente. |

### Valore di ritorno

True se l'oggetto è di tipo contrassegnato o della sua sottoclasse, false altrimenti.
## Osservazioni


Verifica se l'oggetto rappresenta un'istanza del tipo descritto da targetType. Analogo dell'operatore 'is' di C#.
