## X509NameType enum

Tipo di nome contenuto nel certificato X.509 che riguarda sia l'emittente sia il soggetto del certificato.

```cpp
enum class X509NameType
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| SimpleName | 0 | Nome semplice del soggetto o dell'emittente. |
| EmailName | 1 | Indirizzo email. |
| UpnName | 2 | Nome UPN. |
| DnsName | 3 | Nome DNS. |
| DnsFromAlternativeName | 4 | Nome DNS alternativo equivalente al nome DNS. |
| UrlName | 5 | URL. |
