## X500DistinguishedNameFlags enum

Regole di formattazione del nome distinto del certificato X509.

```cpp
enum class X500DistinguishedNameFlags
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| None | 0 | Nessuna caratteristica speciale. |
| Reversed | 1 | Il nome è riservato. |
| UseSemicolons | 16 | Usa i punti e virgola. |
| DoNotUsePlusSign | 32 | Il nome non utilizza il segno più. |
| DoNotUseQuotes | 64 | Disabilita le virgolette nel nome. |
| UseCommas | 128 | Abilita l'uso delle virgole. |
| UseNewLines | 256 | Abilita l'uso di nuove righe. |
| UseUTF8Encoding | 4096 | Passa dall'uso di Unicode all'uso della codifica UTF-8. |
| UseT61Encoding | 8192 | Passa alla codifica T61. |
| ForceUTF8Encoding | 16384 | Forza l'uso di UTF-8 durante la codifica di chiavi X500 specifiche. |
