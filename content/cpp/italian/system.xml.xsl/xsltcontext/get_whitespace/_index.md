## XsltContext::get_Whitespace() metodo

Quando viene sovrascritto in una classe derivata, restituisce un valore che indica se includere i nodi di spazio bianco nell'output.

```cpp
virtual bool System::Xml::Xsl::XsltContext::get_Whitespace()=0
```

### Valore restituito

**true** per verificare i nodi di spazio bianco nel documento di origine per includerli nell'output; **false** per non valutare i nodi di spazio bianco. Il valore predefinito è **true**.
