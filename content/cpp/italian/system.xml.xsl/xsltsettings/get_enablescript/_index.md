## XsltSettings::get_EnableScript() metodo

Restituisce un valore che indica se abilitare il supporto per i blocchi script incorporati.

```cpp
bool System::Xml::Xsl::XsltSettings::get_EnableScript()
```

### Valore restituito

**true** per supportare i blocchi script nei fogli di stile XSLT; altrimenti, **false**. Il valore predefinito è **false**.
