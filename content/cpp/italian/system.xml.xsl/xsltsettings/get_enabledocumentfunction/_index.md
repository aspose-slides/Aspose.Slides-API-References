## XsltSettings::get_EnableDocumentFunction() method


Restituisce un valore che indica se abilitare il supporto per la funzione **document()** di XSLT.

```cpp
bool System::Xml::Xsl::XsltSettings::get_EnableDocumentFunction()
```


### Valore di ritorno

**true** per supportare la funzione **document()** di XSLT; altrimenti, **false**. Il valore predefinito è **false**.
