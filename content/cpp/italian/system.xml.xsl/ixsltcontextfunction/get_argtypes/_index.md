## IXsltContextFunction::get_ArgTypes() metodo


Restituisce i tipi forniti dal linguaggio XML Path Language ([XPath](../../../system.xml.xpath/)) per l'elenco degli argomenti della funzione. Queste informazioni possono essere utilizzate per individuare la firma della funzione, consentendo di distinguere tra funzioni sovraccariche.

```cpp
virtual ArrayPtr<System::Xml::XPath::XPathResultType> System::Xml::Xsl::IXsltContextFunction::get_ArgTypes()=0
```


### Valore restituito

Un array di XPathResultType che rappresenta i tipi per l'elenco degli argomenti della funzione.
