## FlatStyle enum


Definisce se il controllo è disegnato piatto o tridimensionale.

```cpp
enum class FlatStyle
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Flat | 0 | [Control](../control/) è disegnato piatto. |
| Popup | 1 | [Control](../control/) è disegnato piatto a meno che il mouse non si sposti sopra di esso quando è disegnato in stile 3D. |
| Standard | 2 | [Control](../control/) è disegnato in stile 3D. |
| System | 3 | Lo stile è controllato dal SO. |
