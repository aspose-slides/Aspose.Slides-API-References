## Classi

| Classe | Descrizione |
| --- | --- |
| [Control](./control/) | Classe fittizia per rendere il codice tradotto che utilizza la classe [Control](./control/) compilabile. I metodi non sono implementati. Gli oggetti di questa classe dovrebbero essere allocati solo mediante la funzione [System::MakeObject()](../system/makeobject/). Non creare mai un'istanza di questo tipo nello stack o usando l'operatore new, poiché proverà errori di runtime e/o fault di asserzione. Avvolgi sempre questa classe in un puntatore [System::SmartPtr](../system/smartptr/) e utilizza questo puntatore per passarla alle funzioni come argomento. |
| [Form](./form/) | Classe fittizia per rendere il codice tradotto che utilizza la classe [Form](./form/) compilabile. I metodi non sono implementati. Non creare mai un'istanza di questo tipo nello stack o usando l'operatore new, poiché proverà errori di runtime e/o fault di asserzione.
