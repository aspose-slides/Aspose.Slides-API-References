## classe SecureString

Stringa sicura, rappresenta testo che dovrebbe essere mantenuto confidenziale. Questa classe NON CRIPTA i dati interni. Gli oggetti di questa classe devono essere allocati solo usando la funzione [System::MakeObject()](../../system/makeobject/). Non creare mai istanze di questo tipo sullo stack o usando l'operatore new, poiché ciò provocherà errori di runtime e/o fault di asserzione. Avvolgi sempre questa classe in un puntatore [System::SmartPtr](../../system/smartptr/) e usa questo puntatore per passarlo alle funzioni come argomento.

```cpp
class SecureString : public System::IDisposable
```
