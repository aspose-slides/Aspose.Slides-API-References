## MathBorderBox::set_StrikethroughBottomLeftToTopRight(bool) metodo

Barrato da sinistra in basso a destra in alto (il valore predefinito è false). Specifica lo stato nascosto o mostrato di una linea di barrato diagonale dall'angolo in basso a sinistra all'angolo in alto a destra della casella del bordo.

```cpp
void Aspose::Slides::MathText::MathBorderBox::set_StrikethroughBottomLeftToTopRight(bool value) override
```

## Osservazioni

Esempio:
```cpp
auto borderBox = System::MakeObject<MathBorderBox>(System::MakeObject<MathematicalText>(u"x"));
borderBox->set_StrikethroughBottomLeftToTopRight(true);
```
