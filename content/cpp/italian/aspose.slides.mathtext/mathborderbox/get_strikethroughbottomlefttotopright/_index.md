## MathBorderBox::get_StrikethroughBottomLeftToTopRight() metodo

Strikethrough Bottom-Left to Top-Right (il valore predefinito è false). Specifica lo stato nascosto o mostrato di una linea diagonale di barrato dal bordo inferiore sinistro all'angolo superiore destro della casella del bordo.

```cpp
bool Aspose::Slides::MathText::MathBorderBox::get_StrikethroughBottomLeftToTopRight() override
```

## Osservazioni

Esempio: 
```cpp
auto borderBox = System::MakeObject<MathBorderBox>(System::MakeObject<MathematicalText>(u"x"));
borderBox->set_StrikethroughBottomLeftToTopRight(true);
```
