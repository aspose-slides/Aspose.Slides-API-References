## MathBorderBox::set_StrikethroughTopLeftToBottomRight(bool) metodo

Barrato dall'angolo superiore sinistro all'angolo inferiore destro (il valore predefinito è false). Specifica lo stato nascosto o mostrato di una linea diagonale barrata dall'angolo superiore sinistro all'angolo inferiore destro del border box.

```cpp
void Aspose::Slides::MathText::MathBorderBox::set_StrikethroughTopLeftToBottomRight(bool value) override
```

## Osservazioni

Esempio: 
```cpp
auto borderBox = System::MakeObject<MathBorderBox>(System::MakeObject<MathematicalText>(u"x"));
borderBox->set_StrikethroughTopLeftToBottomRight(true);
```
