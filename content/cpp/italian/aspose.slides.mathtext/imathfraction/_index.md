## IMathFraction classe

Specifica l'oggetto frazione, costituito da un numeratore e un denominatore separati da una barra di frazione. La barra di frazione può essere orizzontale o diagonale, a seconda delle proprietà della frazione. L'oggetto frazione è anche usato per rappresentare la funzione di apilamento, che posiziona un elemento sopra un altro, senza barra di frazione.

```cpp
class IMathFraction : public virtual Aspose::Slides::MathText::IMathElement
```
