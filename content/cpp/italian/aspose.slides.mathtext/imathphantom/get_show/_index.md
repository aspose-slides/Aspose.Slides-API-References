## IMathPhantom::get_Show() metodo


Restituisce un valore che indica se l'elemento base è visualizzato.

```cpp
virtual bool Aspose::Slides::MathText::IMathPhantom::get_Show()=0
```

## Osservazioni


Quando **false**, l'elemento base è nascosto ma può comunque occupare spazio a seconda di altre impostazioni phantom. Corrisponde all'attributo OMML **m:show**.
