## IMathPhantom::set_ZeroAsc(bool) metodo


Imposta un valore che indica se l'ascesa (altezza sopra la linea di base) dell'elemento base deve essere considerata zero.

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_ZeroAsc(bool value)=0
```

## Osservazioni


Quando **true**, il phantom non alza la linea di base della linea matematica circostante. Corrisponde all'attributo OMML **m:zeroAsc**.
