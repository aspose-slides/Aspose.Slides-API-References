## IMathPhantom::set_ZeroDesc(bool) metodo


Imposta un valore che indica se la discesa (profondità al di sotto della linea di base) dell'elemento base deve essere trattata come zero.

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_ZeroDesc(bool value)=0
```

## Osservazioni


Quando **true**, il phantom non abbassa la linea di base della linea matematica circostante. Corrisponde all'attributo OMML **m:zeroDesc**.
