## IMathPhantom::get_ZeroAsc() metodo

Restituisce un valore che indica se l'ascesa (altezza sopra la linea di base) dell'elemento di base deve essere trattata come zero.

```cpp
virtual bool Aspose::Slides::MathText::IMathPhantom::get_ZeroAsc()=0
```

## Osservazioni

When **true**, the phantom does not raise the baseline of the surrounding math line. Corrisponde all'attributo OMML **m:zeroAsc**.
