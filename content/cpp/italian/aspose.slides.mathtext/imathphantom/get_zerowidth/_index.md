## IMathPhantom::get_ZeroWidth() metodo


Restituisce un valore che indica se la larghezza dell'elemento base deve essere considerata zero.

```cpp
virtual bool Aspose::Slides::MathText::IMathPhantom::get_ZeroWidth()=0
```

## Note


Quando **true**, il phantom non riserva spazio orizzontale per la sua base. Corrisponde all'attributo OMML **m:zeroWid**.
