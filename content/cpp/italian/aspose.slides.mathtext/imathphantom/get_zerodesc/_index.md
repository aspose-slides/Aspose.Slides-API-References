## IMathPhantom::get_ZeroDesc() metodo

Restituisce un valore che indica se la discesa (profondità al di sotto della linea di base) dell'elemento base debba essere trattata come zero.

```cpp
virtual bool Aspose::Slides::MathText::IMathPhantom::get_ZeroDesc()=0
```

## Osservazioni

Quando **true**, il phantom non abbassa la linea di base della linea matematica circostante. Corrisponde all'attributo OMML **m:zeroDesc**.
