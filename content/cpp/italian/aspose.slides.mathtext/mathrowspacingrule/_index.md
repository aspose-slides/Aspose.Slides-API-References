## MathRowSpacingRule enum

Il tipo di spaziatura verticale tra colonne in una matrice o array

```cpp
enum class MathRowSpacingRule
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| SingleLineGap | 0 | intervallo di una riga |
| OneAndAHalfLineGap | 1 | intervallo di una riga e mezza |
| TwoLineGap | 2 | intervallo di due righe |
| Exactly | 3 | Esattamente (si basa sul valore della proprietà RowSpacing, misurato in punti) |
| Multiple | 4 | Multiplo (si basa sul valore della proprietà RowSpacing, misurato in linee) |
