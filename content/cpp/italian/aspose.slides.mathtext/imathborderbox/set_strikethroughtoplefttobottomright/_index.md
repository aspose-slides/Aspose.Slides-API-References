## IMathBorderBox::set_StrikethroughTopLeftToBottomRight(bool) metodo

Barrato dall'angolo in alto a sinistra a quello in basso a destra (il valore predefinito è false). Specifica lo stato nascosto o mostrato di una linea diagonale barrata dall'angolo in alto a sinistra a quello in basso a destra della border box.

```cpp
virtual void Aspose::Slides::MathText::IMathBorderBox::set_StrikethroughTopLeftToBottomRight(bool value)=0
```

## Osservazioni

Esempio: 
```cpp
auto borderBox = System::MakeObject<MathematicalText>(u"x+y+z")->ToBorderBox();
borderBox->set_StrikethroughTopLeftToBottomRight(true);
```
