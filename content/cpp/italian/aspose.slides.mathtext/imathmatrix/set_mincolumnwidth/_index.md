## IMathMatrix::set_MinColumnWidth(uint32_t) metodo

Larghezza minima della colonna in twip (1/20 di punto). La spaziatura del gap (nota anche come \\u201CSpazio colonna\\u201D o \\u201CLarghezza gap\\u201D) viene aggiunta a MinColumnWidth per determinare la totale Matrix [Column](../../../aspose.slides/column/) Spaziatura (distanza tra gli stessi bordi di colonne diverse). Predefinito: 0.

```cpp
virtual void Aspose::Slides::MathText::IMathMatrix::set_MinColumnWidth(uint32_t value)=0
```

## Osservazioni

Esempio:
```cpp
auto matrix = System::MakeObject<MathMatrix>(2, 3);
matrix->set_MinColumnWidth(20);
```
