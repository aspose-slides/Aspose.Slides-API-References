## MathBox class

Specifica il raggruppamento logico (pacchettizzazione) di un elemento matematico. Ad esempio, un oggetto boxed può servire come emulatore di operatore con o senza un punto di allineamento, servire come punto di interruzione di linea, o essere raggruppato in modo da non consentire interruzioni di linea all'interno. Per esempio, l'operatore \"==\" dovrebbe essere boxed per prevenire interruzioni di linea.

```cpp
class MathBox : public Aspose::Slides::MathText::MathElementBase,
                public Aspose::Slides::MathText::IMathBox,
                public Aspose::Slides::MathText::IHasControlCharacterProperties
```
