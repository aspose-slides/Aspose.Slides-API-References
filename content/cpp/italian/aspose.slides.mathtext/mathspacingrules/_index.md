## MathSpacingRules enum

Tipi di spazio (spaziatura orizzontale) tra le colonne di una matrice

```cpp
enum class MathSpacingRules
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| SingleSpacingGap | 0 | Singola (1 em per le colonne o 1 riga per le righe) |
| OneAndHalfSpacingGap | 1 | Una volta e mezzo (1.5 em per le colonne o 1.5 righe per le righe) |
| DoubleSpacingGap | 2 | Doppia spaziatura (2 em per le colonne o 2 righe per le righe) |
| Exactly | 3 | Valore esatto Per le colonne, fare affidamento al valore di ColumnGap, misurato in twips Per le righe, fare affidamento al valore di RowGap, misurato in twips |
| Multiple | 4 | Multiplo Per le colonne, fare affidamento al valore di ColumnGap, misurato in incrementi di 0.5 em Per le righe, fare affidamento al valore di RowGap, misurato in linee |
