## MathPhantom::get_ZeroAsc() metodo


Restituisce un valore che indica se l'ascesa (altezza sopra la linea di base) dell'elemento di base deve essere trattata come zero.

```cpp
bool Aspose::Slides::MathText::MathPhantom::get_ZeroAsc() override
```

## Osservazioni


Quando **true**, il phantom non solleva la linea di base della riga matematica circostante. Corrisponde all'attributo OMML **m:zeroAsc**.
