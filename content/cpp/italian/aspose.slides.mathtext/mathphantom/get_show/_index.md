## MathPhantom::get_Show() metodo

Restituisce un valore che indica se l'elemento base è visualizzato.

```cpp
bool Aspose::Slides::MathText::MathPhantom::get_Show() override
```

## Osservazioni

Quando **false**, l'elemento base è nascosto ma può ancora occupare spazio a seconda di altre impostazioni phantom. Correlato all'attributo OMML **m:show**.
