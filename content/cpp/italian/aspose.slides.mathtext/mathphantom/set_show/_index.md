## MathPhantom::set_Show(bool) metodo


Imposta un valore che indica se l'elemento base è visualizzato.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_Show(bool value) override
```

## Osservazioni


Quando **false**, l'elemento base è nascosto ma può comunque occupare spazio a seconda di altre impostazioni phantom. Corrisponde all'attributo OMML **m:show**.
