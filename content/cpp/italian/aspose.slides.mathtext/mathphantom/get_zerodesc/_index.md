## MathPhantom::get_ZeroDesc() metodo

Restituisce un valore che indica se la discesa (profondità al di sotto della linea di base) dell'elemento base deve essere trattata come zero.

```cpp
bool Aspose::Slides::MathText::MathPhantom::get_ZeroDesc() override
```

## Osservazioni

Quando **true**, il fantasma non abbassa la linea di base della riga matematica circostante. Corrisponde all'attributo OMML **m:zeroDesc**.
