## MathPhantom::get_ZeroWidth() metodo

Restituisce un valore che indica se la larghezza dell'elemento base deve essere considerata zero.

```cpp
bool Aspose::Slides::MathText::MathPhantom::get_ZeroWidth() override
```

## Osservazioni

Quando **true**, il fantasma non riserva spazio orizzontale per la sua base. Corrisponde all'attributo OMML **m:zeroWid**.
