## MathPhantom::set_ZeroDesc(bool) metodo

Imposta un valore che indica se la discesa (profondità sotto la linea di base) dell'elemento di base deve essere considerata zero.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_ZeroDesc(bool value) override
```

## Osservazioni

Quando **true**, il phantom non abbassa la linea di base della riga matematica circostante. Corrisponde all'attributo OMML **m:zeroDesc**.
