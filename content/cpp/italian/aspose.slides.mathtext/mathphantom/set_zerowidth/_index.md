## MathPhantom::set_ZeroWidth(bool) metodo


Imposta un valore che indica se la larghezza dell'elemento base deve essere considerata zero.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_ZeroWidth(bool value) override
```

## Osservazioni


Quando **true**, il phantom non riserva spazio orizzontale per la sua base. Corrisponde all'attributo OMML **m:zeroWid**.
