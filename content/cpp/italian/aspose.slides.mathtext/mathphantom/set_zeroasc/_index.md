## MathPhantom::set_ZeroAsc(bool) method

Imposta un valore che indica se l'ascesa (altezza sopra la linea di base) dell'elemento base dovrebbe essere trattata come zero.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_ZeroAsc(bool value) override
```

## Osservazioni

Quando **true**, il phantom non alza la linea di base della riga matematica circostante. Corrisponde all'attributo OMML **m:zeroAsc**.
