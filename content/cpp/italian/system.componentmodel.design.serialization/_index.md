## Classi

| Classe | Descrizione |
| --- | --- |
| [InstanceDescriptor](./instancedescriptor/) | Classe fittizia per il codice che utilizza [InstanceDescriptor](./instancedescriptor/) per compilare. Gli oggetti di questa classe dovrebbero essere allocati solo utilizzando la funzione [System::MakeObject()](../system/makeobject/). Non creare mai istanze di questo tipo sullo stack o usando l'operatore new, poiché ciò provocherà errori di runtime e/o fault di asserzione. Avvolgi sempre questa classe in un puntatore [System::SmartPtr](../system/smartptr/) e usa questo puntatore per passarlo alle funzioni come argomento. |
