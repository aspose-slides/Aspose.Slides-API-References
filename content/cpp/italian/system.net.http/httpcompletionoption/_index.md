## HttpCompletionOption enum

Indica quando un'operazione [HttpClient](../httpclient/) dovrebbe essere completata.

```cpp
enum class HttpCompletionOption
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| ResponseContentRead | 0 | L'operazione dovrebbe essere completata dopo la lettura del contenuto della risposta. |
| ResponseHeadersRead | 1 | L'operazione dovrebbe essere completata dopo la lettura delle intestazioni di una risposta. |
