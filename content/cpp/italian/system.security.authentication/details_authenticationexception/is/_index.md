## Dettagli_AuthenticationException::Is(const System::TypeInfo\&) const method

```cpp
bool System::Security::Authentication::Details_AuthenticationException::Is(const System::TypeInfo &target) const override
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| target | const [System::TypeInfo](../../../system/typeinfo/)\& | [TypeInfo](../../../system/typeinfo/) struttura che descrive il tipo da confrontare con l'oggetto corrente. |

### Valore di ritorno

True se l'oggetto è del tipo contrassegnato o di una sua sottoclasse, false altrimenti.

## Osservazioni

Verifica se l'oggetto rappresenta un'istanza del tipo descritto da targetType. Analogo dell'operatore C# 'is'.
