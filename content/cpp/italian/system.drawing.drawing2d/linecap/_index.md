## LineCap enum

Indica gli stili di cap disponibili con cui un oggetto [Pen](../../system.drawing/pen/) può terminare una linea.

```cpp
enum class LineCap
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Flat | 0 | Cap di linea piatta. |
| Square | 1 | Cap di linea quadrata. |
| Round | 2 | Cap di linea rotonda. |
| Triangle | 3 | Cap di linea triangolare. |
| NoAnchor | 16 | Nessun ancoraggio. |
| SquareAnchor | 17 | Cap di linea con ancoraggio quadrato. |
| RoundAnchor | 18 | Cap di linea con ancoraggio rotondo. |
| DiamondAnchor | 19 | Cap di linea con ancoraggio a diamante. |
| ArrowAnchor | 20 | Cap di linea con ancoraggio a freccia. |
| AnchorMask | 240 | Maschera usata per verificare se un cap di linea è un cap di ancoraggio. |
| Custom | 255 | Cap personalizzato. |
