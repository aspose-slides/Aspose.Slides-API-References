## DashCap enum

Specifica il tipo di cappuccio usato su entrambe le estremità di un trattino in una linea tratteggiata.

```cpp
enum class DashCap
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Flat | 0 | Un cappuccio quadrato che chiude a quadrato entrambe le estremità di un trattino. |
| Round | 2 | Un cappuccio circolare che arrotonda entrambe le estremità di un trattino. |
| Triangle | 3 | Un cappuccio triangolare che punta entrambe le estremità di un trattino. |
