## LineJoin enum


Specifica come le linee o curve successive vengono unite.

```cpp
enum class LineJoin
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| Miter | 0 | Giunzione a spigolo che produce un angolo affilato o ritagliato a seconda che la lunghezza del miter superi il limite del miter. |
| Bevel | 1 | Giunzione a smusso che produce un angolo diagonale. |
| Round | 2 | Giunzione arrotondata che produce un arco circolare liscio tra le linee. |
| MiterClipped | 3 | Giunzione a spigolo che produce un angolo affilato o smussato a seconda che la lunghezza del miter superi il limite del miter. |
