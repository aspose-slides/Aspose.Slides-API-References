## SmoothingMode enum

Specifica quale tipo di antialiasing (levigatura) viene applicato a linee, curve e bordi delle aree riempite.

```cpp
enum class SmoothingMode
```

### Valori

| Name | Value | Description |
| --- | --- | --- |
| Invalid | n/a | Valore non valido. |
| Default | n/a | Modalità predefinita, senza antialiasing. |
| HighSpeed | n/a | Nessun antialiasing, alta velocità. |
| HighQuality | n/a | Rendering antialiasing, bassa velocità. |
| None | n/a | Nessun antialiasing. |
| AntiAlias | n/a | Rendering antialiasing. |
