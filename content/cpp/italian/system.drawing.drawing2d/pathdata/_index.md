## PathData classe

Contiene i dati grafici che rappresentano un percorso. Gli oggetti di questa classe dovrebbero essere allocati solo usando la funzione [System::MakeObject()](../../system/makeobject/). Non creare mai istanze di questo tipo nello stack o usando l'operatore new, poiché ciò provocherà errori di runtime e/o errori di asserzione. Avvolgi sempre questa classe in un puntatore [System::SmartPtr](../../system/smartptr/) e usa tale puntatore per passarlo alle funzioni come argomento.

```cpp
class PathData : public System::Object
```
