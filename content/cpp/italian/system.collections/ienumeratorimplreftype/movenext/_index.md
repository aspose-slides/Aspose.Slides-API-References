## IEnumeratorImplRefType::MoveNext() metodo


Sposta l'enumeratore al prossimo elemento. Se nessun elemento è stato referenziato prima, imposta il riferimento al primo elemento disponibile. Se viene raggiunta la fine del contenitore, non fa nulla.

```cpp
virtual bool System::Collections::IEnumeratorImplRefType<T>::MoveNext() override
```


### Valore di ritorno

True se qualche elemento è disponibile dopo la chiamata, false altrimenti.
