## IEnumeratorImplValueType::MoveNext() metodo


Sposta l'enumeratore al prossimo elemento. Se non è stato riferito alcun elemento prima, imposta il riferimento al primo elemento disponibile. Se si è raggiunta la fine del contenitore, non fa nulla.

```cpp
virtual bool System::Collections::IEnumeratorImplValueType<T>::MoveNext() override
```


### Valore di ritorno

True if some element is available after call, false otherwise.
