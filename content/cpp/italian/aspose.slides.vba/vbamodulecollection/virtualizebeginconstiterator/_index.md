## VbaModuleCollection::virtualizeBeginConstIterator() const metodo

```cpp
virtualized_iterator * Aspose::Slides::Vba::VbaModuleCollection::virtualizeBeginConstIterator() const override
```

### Valore restituito

Un iteratore che punta al primo elemento (se presente) dell'istanza const-qualified della collezione fornisce l'implementazione dell'iteratore const al primo elemento del contenitore.

Oggetto iteratore appena creato.
