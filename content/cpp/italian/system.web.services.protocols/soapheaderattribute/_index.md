## SoapHeaderAttribute classe


Specifica l'intestazione SOAP che il metodo del servizio XML [Web](../../system.web/) o il client del servizio XML [Web](../../system.web/) può elaborare. Gli oggetti di questa classe dovrebbero essere allocati solo tramite la funzione [System::MakeObject()](../../system/makeobject/). Non creare mai un'istanza di questo tipo sullo stack o usando l'operatore new, poiché ciò provocherà errori di runtime e/o fault di asserzione. Avvolgi sempre questa classe in un puntatore [System::SmartPtr](../../system/smartptr/) e usa questo puntatore per passarlo alle funzioni come argomento.

```cpp
class SoapHeaderAttribute : public System::Attribute
```
