## ValueType classe


Classe base per i tipi valore con l'ereditarietà [Object](../object/) troncata per ragioni di prestazioni. Questo tipo dovrebbe essere allocato nello stack e passato alle funzioni per valore o per riferimento. Non usare mai [System::SmartPtr](../smartptr/) classe per gestire gli oggetti di questo tipo.

```cpp
class ValueType
```
