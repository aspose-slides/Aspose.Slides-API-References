## Math::Pow(double, double) metodo

Restituisce il valore specificato elevato alla potenza specificata.

```cpp
static double System::Math::Pow(double x, double y)
```

### Argomenti

| Parameter | Type | Description |
| --- | --- | --- |
| x | **double** | Il valore da elevare alla potenza specificata |
| y | **double** | La potenza a cui elevare il valore specificato |

### Valore di ritorno

**x** elevato alla potenza di **y**
