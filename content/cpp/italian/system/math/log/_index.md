## Math::Log(double) metodo

Restituisce il logaritmo naturale del valore specificato.

```cpp
static double System::Math::Log(double d)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| d | **double** | Un valore in virgola mobile a doppia precisione |

### Valore di ritorno

Il logaritmo naturale di **d**

### Argomenti

| Parametro | Tipo | Descrizione |

| a | **double** | Un valore in virgola mobile a doppia precisione |
| newBase | **double** | La base del logaritmo |

### Valore di ritorno

Il logaritmo di **a** nella base **newBase** base
