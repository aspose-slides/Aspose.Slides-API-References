## Math::DivRem(int, int, int\&) metodo

Calcola il quoziente di due interi a 32 bit e il resto.

```cpp
static int System::Math::DivRem(int a, int b, int &result)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| a | int | Il dividendo |
| b | int | Il divisore |
| result | int\& | Il parametro di output che contiene il resto risultante dalla divisione di **a** per **b** |

### Valore restituito

Il quoziente di **a** e **b**
