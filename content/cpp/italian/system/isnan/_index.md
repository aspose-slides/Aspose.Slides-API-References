## System::IsNaN(const T\&) funzione

Determina se il valore specificato è un valore Not-A-Number.

```cpp
template<typename T> bool System::IsNaN(const T &value)
```

### Parametri del modello

| Parametro | Descrizione |
| --- | --- |
| T | Il tipo del valore verificato dalla funzione |

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| value | const T\& | Il valore da verificare |

### Valore di ritorno

True se **value** è un valore NaN, otherwise - false
