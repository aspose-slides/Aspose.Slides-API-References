enum class SpecialFolder

### Valori

| Name | Value | Description |
| --- | --- | --- |
| Desktop | 0 | Il Desktop logico. |
| Programs | 2 | La cartella che contiene i gruppi di programmi dell'utente. |
| Personal | 5 | La cartella che funge da archivio comune per i documenti. |
| MyDocuments | 5 | La directory "My Documents". |
| Favorites | 6 | La cartella che funge da archivio comune per gli elementi preferiti dell'utente. |
| Startup | 7 | La cartella che corrisponde al gruppo di programmi di avvio dell'utente. |
| Recent | 8 | La cartella che contiene i documenti più recenti utilizzati dall'utente. |
| SendTo | 9 | La cartella che funge da contenitore per le voci del menu Invia a. |
| StartMenu | 11 | La cartella che funge da contenitore per le voci del menu Start. |
| MyMusic | 13 | La directory "My Music". |
| DesktopDirectory | 16 | La cartella usata per archiviare fisicamente gli oggetti sul desktop. |
| MyComputer | 17 | La directory "My Computer". |
| Templates | 21 | La cartella che funge da contenitore comune per i modelli di documento. |
| ApplicationData | 26 | La cartella usata per memorizzare dati specifici dell'applicazione per l'utente roaming corrente. |
| LocalApplicationData | 28 | La cartella usata per memorizzare dati specifici dell'applicazione per l'utente non roaming corrente. |
| InternetCache | 32 | La cartella usata come archivio per i file Internet temporanei. |

| UserProfile | 40 | La cartella del profilo dell'utente. |
| CommonProgramFiles | 43 | La directory usata come archivio per i componenti condivisi dalle applicazioni. |
