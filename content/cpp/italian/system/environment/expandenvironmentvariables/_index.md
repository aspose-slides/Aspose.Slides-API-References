## Environment::ExpandEnvironmentVariables(const String\&) method


Sostituisce i nomi delle variabili d'ambiente trovati nella stringa specificata con i valori di tali variabili e restituisce la stringa risultante.

```cpp
static String System::Environment::ExpandEnvironmentVariables(const String &name)
```


### Argomenti

| Parameter | Type | Description |
| --- | --- | --- |
| name | const [String](../../string/)\& | La stringa contenente i nomi delle variabili d'ambiente |

### Valore di ritorno

La stringa che risulta dalla sostituzione dei nomi delle variabili in **name** con i loro valori.
