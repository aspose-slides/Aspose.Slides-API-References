## Environment::get_Version() metodo

Restituisce l'oggetto [Version](../../version/) che rappresenta le informazioni sulla versione del runtime del linguaggio comune. Il numero di versione restituito da questo metodo è piuttosto fittizio e non implica che tutte le classi della libreria si comportino in conformità con la versione restituita.

```cpp
static Version System::Environment::get_Version()
```
