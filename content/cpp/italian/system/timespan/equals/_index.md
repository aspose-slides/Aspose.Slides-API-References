## TimeSpan::Equals(TimeSpan) const method


Determina se l'intervallo di tempo rappresentato dall'oggetto corrente è uguale all'intervallo di tempo rappresentato dall'oggetto specificato.

```cpp
constexpr bool System::TimeSpan::Equals(TimeSpan value) const
```


### Argomenti

| Parameter | Type | Description |
| --- | --- | --- |
| value | [TimeSpan](../) | L'oggetto [TimeSpan](../) da confrontare con l'oggetto corrente |

### Valore restituito

True se l'oggetto corrente e l'oggetto specificato rappresentano lo stesso intervallo di tempo, altrimenti - false
