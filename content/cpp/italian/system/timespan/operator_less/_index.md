## TimeSpan::operator<(TimeSpan) const metodo

Determina se l'intervallo di tempo rappresentato dall'oggetto corrente è più breve dell'intervallo di tempo rappresentato dall'oggetto specificato.

```cpp
constexpr bool System::TimeSpan::operator<(TimeSpan value) const
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| value | [TimeSpan](../) | L'oggetto [TimeSpan](../) con cui confrontare l'oggetto corrente |

### Valore restituito

Vero se l'intervallo di tempo rappresentato dall'oggetto corrente è più breve dell'intervallo di tempo rappresentato da **value**, altrimenti - falso
