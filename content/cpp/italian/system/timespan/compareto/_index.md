## TimeSpan::CompareTo(TimeSpan) const metodo

Confronta l'oggetto corrente con gli oggetti specificati.

```cpp
constexpr int System::TimeSpan::CompareTo(TimeSpan value) const
```

### Argomenti

| Parameter | Type | Description |
| --- | --- | --- |
| value | [TimeSpan](../) | L'oggetto [TimeSpan](../) da confrontare con l'oggetto corrente |

### Valore restituito

- 1 se l'oggetto corrente rappresenta l'intervallo più breve di **value**; 0 se l'oggetto corrente rappresenta l'intervallo uguale a **value**; 1 se l'oggetto corrente rappresenta l'intervallo più lungo di **value**
