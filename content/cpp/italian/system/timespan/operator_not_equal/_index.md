## TimeSpan::operator!=(TimeSpan) const metodo


Determina se l'intervallo di tempo rappresentato dall'oggetto corrente non è uguale all'intervallo di tempo rappresentato dall'oggetto specificato.

```cpp
constexpr bool System::TimeSpan::operator!=(TimeSpan value) const
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| value | [TimeSpan](../) | L'oggetto [TimeSpan](../) da confrontare con l'oggetto corrente |

### Valore di ritorno

True se l'oggetto corrente e l'oggetto specificato rappresentano intervalli di tempo diversi, altrimenti - false
