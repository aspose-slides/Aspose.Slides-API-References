## Enum::Parse(const String\&, bool) metodo


Converte la stringa specificata nella costante enum equivalente.

```cpp
static E System::Enum<E, Guard>::Parse(const String &str, bool ignoreCase=false)
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| str | const [String](../../string/)\& | [String](../../string/) che è interpretato come contenente il nome della costante enum |
| ignoreCase | **bool** | Specifica se il caso deve essere ignorato durante l'interpretazione della stringa |

### Valore di ritorno

La costante di enumerazione il cui nome è specificato in **str**
