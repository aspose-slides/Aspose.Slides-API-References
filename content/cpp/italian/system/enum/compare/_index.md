## Enum::Compare(E, T) metodo

Esegue il confronto aritmetico dei valori delle costanti enum specificate.

```cpp
template<typename T,typename _> static int System::Enum<E, Guard>::Compare(E a, T b)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| a | E | Il primo comparando |
| b | T | Il secondo comparando |

### Valore restituito

- 1 se **a** è minore di **b**; 0 se i valori sono uguali; 1 se **a** è maggiore di **b**
