## Decimal::Compare(const Decimal\&, const Decimal\&) metodo

Determina se il valore rappresentato dal primo oggetto [Decimal](../) è minore, uguale o maggiore del valore rappresentato dal secondo oggetto [Decimal](../).

```cpp
static int System::Decimal::Compare(const Decimal &d1, const Decimal &d2)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| d1 | const [Decimal](../)\& | Il primo comparando |
| d2 | const [Decimal](../)\& | Il secondo comparando |

### Valore di ritorno

- 1 se il valore rappresentato da **d1** è minore del valore rappresentato da **d2**; 0 se i valori sono uguali; 1 se il valore rappresentato da **d1** è maggiore del valore rappresentato da **d2**
