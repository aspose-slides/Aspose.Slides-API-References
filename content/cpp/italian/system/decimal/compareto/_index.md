## Decimal::CompareTo(const Decimal\&) const metodo

Determina se il valore rappresentato dall'oggetto corrente è minore, uguale o maggiore del valore rappresentato dall'oggetto specificato.

```cpp
int System::Decimal::CompareTo(const Decimal &d) const
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| d | const [Decimal](../)\& | Il comparando |

### Valore di ritorno

- 1 se il valore rappresentato dall'oggetto corrente è minore del valore rappresentato da **d**; 0 se i valori sono uguali; 1 se il valore rappresentato dall'oggetto corrente è maggiore del valore rappresentato da **d**
