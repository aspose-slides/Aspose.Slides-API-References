## Decimal::operator>=(const Decimal\&) const metodo

Determina se il valore rappresentato dall'oggetto corrente è maggiore o uguale al valore rappresentato dall'oggetto specificato.

```cpp
bool System::Decimal::operator>=(const Decimal &d) const
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| d | const [Decimal](../)\& | L'oggetto [Decimal](../) da confrontare con l'oggetto corrente |

### Valore di ritorno

True se il valore rappresentato dall'oggetto corrente è maggiore o uguale al valore rappresentato da **d**, altrimenti - false
