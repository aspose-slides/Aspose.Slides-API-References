## Object::Is(const TypeInfo\&) const method

Verifica se l'oggetto rappresenta un'istanza del tipo descritto da targetType. Analogo dell'operatore 'is' di C#.

```cpp
virtual bool System::Object::Is(const TypeInfo &targetType) const
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| targetType | const [TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struttura che descrive il tipo contro cui testare l'oggetto corrente. |

### Valore di ritorno

True se l'oggetto è del tipo contrassegnato o della sua sottoclasse, false altrimenti.
