## Boolean::TryParse(const String\&, bool\&) metodo

Converte la stringa specificata in un valore di tipo bool.

```cpp
static bool System::Boolean::TryParse(const String &value, bool &result)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| value | const [String](../../string/)\& | La stringa da convertire. |
| result | **bool**\& | Il riferimento a una variabile bool in cui viene inserito il risultato della conversione; il risultato è true se la stringa specificata è uguale a "True" e false se la stringa specificata è uguale a "False". |

### Valore restituito

True se la stringa specificata è uguale a "True" o "False", altrimenti - false.
