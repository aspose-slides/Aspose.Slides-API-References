## Details_MethodAccessException::Is(const System::TypeInfo\&) const metodo




```cpp
bool System::Details_MethodAccessException::Is(const System::TypeInfo &target) const override
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struttura che descrive il tipo da confrontare con l'oggetto corrente. |

### Valore restituito

True se l'oggetto è del tipo contrassegnato o della sua sottoclasse, false altrimenti.
## Osservazioni

Verifica se l'oggetto rappresenta un'istanza del tipo descritto da targetType. Analogo dell'operatore C# 'is' operator.
