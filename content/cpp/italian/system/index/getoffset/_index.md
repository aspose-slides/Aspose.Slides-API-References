## Index::GetOffset(int32_t) const metodo

Converte il [Index](../) corrente in un offset dall'inizio di una collezione con la lunghezza specificata.

```cpp
int32_t System::Index::GetOffset(int32_t length) const
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| length | **int32_t** | La lunghezza della collezione. |

### Valore di ritorno

L'offset a base zero dall'inizio della collezione.
