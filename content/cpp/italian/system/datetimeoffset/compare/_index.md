## DateTimeOffset::Compare(const DateTimeOffset&, const DateTimeOffset&) metodo

Confronta due oggetti [DateTimeOffset](../).

```cpp
static int System::DateTimeOffset::Compare(const DateTimeOffset &first, const DateTimeOffset &second)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| first | const [DateTimeOffset](../)\& | Primo oggetto da confrontare. |
| second | const [DateTimeOffset](../)\& | Secondo oggetto da confrontare. |

### Valore di ritorno

- 1 - se **first** è precedente a **second**, 1 - se **first** è successivo a **second**, 0 - se **first** è uguale a **second**.
