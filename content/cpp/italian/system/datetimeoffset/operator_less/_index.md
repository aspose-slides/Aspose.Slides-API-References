## DateTimeOffset::operator<(const DateTimeOffset\&) const metodo


Determina se l'oggetto corrente rappresenta il valore di data e ora che è precedente al valore rappresentato dall'oggetto [DateTimeOffset](../) specificato.

```cpp
bool System::DateTimeOffset::operator<(const DateTimeOffset &other) const
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| other | const [DateTimeOffset](../)\& | L'oggetto [DateTimeOffset](../) con cui confrontare l'oggetto corrente |

### Valore di ritorno

True se il valore di data e ora rappresentato dall'oggetto corrente è precedente al valore rappresentato da **other**, altrimenti - false
