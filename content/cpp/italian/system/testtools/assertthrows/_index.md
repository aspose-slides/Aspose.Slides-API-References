## TestTools::AssertThrows(const std::function\<void()>\&) metodo

Verifica se la funzione solleva un'eccezione di qualsiasi tipo.

```cpp
static bool System::TestTools::AssertThrows(const std::function<void()> &func)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| func | const std::function\<void()>\& | Funzione da verificare per il lancio. |

### Valore restituito

True se la funzione solleva, false altrimenti.
