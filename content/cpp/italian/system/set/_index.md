Implementa la traduzione del pattern 'var'.


### Parametri del modello

| Parametro | Descrizione |

| ExpressionT | tipo della variabile. |

| Parametro | Tipo | Descrizione |

sempre vero (questo pattern corrisponde sempre).
