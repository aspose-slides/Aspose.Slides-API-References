## String::rend() const metodo


Restituisce l'iteratore inverso al carattere precedente il primo (se presente) del buffer della stringa effettiva.

```cpp
reverse_iterator System::String::rend() const
```


### Valore restituito

Iteratore inverso all'elemento precedente il primo carattere del buffer di stringa effettivo (se presente) o all'elemento subito prima del buffer allocato.
