## String::end() const metodo

Restituisce un puntatore alla fine del buffer di stringa attuale. Non riassegna mai nulla. Non garantisce che il buffer sia terminato con carattere nullo.

```cpp
const UChar * System::String::end() const
```

### Valore di ritorno

Puntatore al primo elemento dopo il buffer di stringa attuale, terminato o meno con carattere nullo.
