## String::IsNull() const metodo


Verifica se la stringa è considerata nulla. [String](../) è nulla e solo se è costruita tramite il costruttore [String()](../string/), spostata, copiata o assegnata da una stringa nulla o [reset()](../reset/) metodo è stato chiamato.

```cpp
bool System::String::IsNull() const
```


### Valore restituito

true se la stringa è considerata nulla, false altrimenti.
