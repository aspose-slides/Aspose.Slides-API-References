## Uri::IsHexEncoding(const String\&, int32_t) metodo

Determina se un carattere nella stringa specificata alla posizione specificata è codificato esadecimalmente.

```cpp
static bool System::Uri::IsHexEncoding(const String &pattern, int32_t index)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| pattern | const [String](../../string/)\& | La stringa da controllare |
| index | **int32_t** | Posizione basata su zero del carattere da testare |

### Valore di ritorno

True se il carattere specificato è codificato esadecimalmente, altrimenti - false
