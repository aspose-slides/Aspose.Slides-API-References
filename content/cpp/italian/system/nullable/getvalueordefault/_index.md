## Nullable::GetValueOrDefault(T) metodo


Restituisce il valore rappresentato dall'oggetto corrente o il valore specificato se il valore rappresentato dall'oggetto corrente è nullo.

```cpp
T System::Nullable<T>::GetValueOrDefault(T default_value)
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| default_value | T | Il valore restituito dal metodo se il valore rappresentato dall'oggetto corrente è nullo |

### Valore di ritorno

Una copia del valore rappresentato dall'oggetto corrente viene restituita se non è nullo; altrimenti viene restituito il valore specificato
