## DateTime::FromFileTime(int64_t) metodo

Converte il File time specificato in un'istanza della classe [DateTime](../) che rappresenta lo stesso valore di data e ora come tempo locale.

```cpp
static DateTime System::DateTime::FromFileTime(int64_t value)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| value | **int64_t** | File time da convertire |

### Valore di ritorno

Una nuova istanza della classe [DateTime](../) che rappresenta la stessa data e ora di **file_time**
