## DateTime::Equals(DateTime) const metodo


Determina se l'istanza specificata della classe [DateTime](../) rappresenta lo stesso valore di data e ora dell'oggetto corrente.

```cpp
constexpr bool System::DateTime::Equals(DateTime other) const
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| other | [DateTime](../) | L'istanza della classe [DateTime](../) da confrontare con l'oggetto corrente |

### Valore restituito

True se sia **other** che l'oggetto corrente rappresentano lo stesso valore, altrimenti - false

## DateTime::Equals(DateTime, DateTime) metodo


Determina se le istanze specificate della classe [DateTime](../) rappresentano lo stesso valore di data e ora.

```cpp
static constexpr bool System::DateTime::Equals(DateTime t1, DateTime t2)
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| t1 | [DateTime](../) | Il primo comparando |
| t2 | [DateTime](../) | Il secondo comparando |

### Valore restituito

True se sia **t1** che **t2** rappresentano lo stesso valore, altrimenti - false
