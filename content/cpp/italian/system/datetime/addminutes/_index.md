## DateTime::AddMinutes(double) const metodo

Restituisce una nuova istanza della classe [DateTime](../) che rappresenta il valore di data e ora che è la somma del valore rappresentato dall'oggetto corrente e del numero specificato di minuti.

```cpp
DateTime System::DateTime::AddMinutes(double value) const
```

### Argomenti

| Parameter | Type | Description |
| --- | --- | --- |
| value | **double** | Il numero di minuti da aggiungere; il valore può essere positivo o negativo |

### Valore di ritorno

Una nuova istanza della classe [DateTime](../) che rappresenta il valore di data e ora che è la somma del valore rappresentato dall'oggetto corrente e **value** minuti
