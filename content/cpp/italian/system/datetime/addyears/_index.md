## DateTime::AddYears(int) const metodo


Restituisce una nuova istanza della classe [DateTime](../) che rappresenta il valore data e ora uguale a quello rappresentato dall'oggetto corrente con il componente anno aumentato del numero specificato.

```cpp
DateTime System::DateTime::AddYears(int value) const
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| value | int | Il numero di anni da aggiungere; il valore può essere positivo o negativo |

### Valore restituito

Una nuova istanza della classe [DateTime](../) che rappresenta il valore data e ora uguale a quello rappresentato dall'oggetto corrente con il componente anno aumentato di **value**
