## DateTime::FromBinary(int64_t) metodo

Deserializza il valore data e ora dall’intero senza segno a 64 bit specificato e imposta una nuova istanza della classe [DateTime](../) a tale valore.

```cpp
static DateTime System::DateTime::FromBinary(int64_t value)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| value | **int64_t** | L'intero a 64 bit da cui deserializzare il valore data e ora |

### Valore di ritorno

Una nuova istanza della classe [DateTime](../) che rappresenta il valore data e ora deserializzato dall’intero senza segno a 64 bit specificato
