## DateTime::FromFileTimeUtc(int64_t) metodo


Converte il tempo file specificato in un'istanza della classe [DateTime](../) che rappresenta lo stesso valore di data e ora come tempo UTC.

```cpp
static DateTime System::DateTime::FromFileTimeUtc(int64_t file_time)
```


### Argomenti

| Parameter | Type | Description |
| --- | --- | --- |
| file_time | **int64_t** | Tempo file da convertire |

### Valore di ritorno

Una nuova istanza della classe [DateTime](../) che rappresenta la stessa data e ora di **file_time**
