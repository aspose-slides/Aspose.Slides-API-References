## DateTime::AddTicks(int64_t) const metodo

Restituisce una nuova istanza della classe [DateTime](../) che rappresenta il valore di data e ora risultante dalla somma del valore rappresentato dall'oggetto corrente e del numero specificato di intervalli di 100 nanosecondi.

```cpp
DateTime System::DateTime::AddTicks(int64_t value) const
```

### Argomenti

| Parameter | Type | Description |
| --- | --- | --- |
| value | **int64_t** | Il numero di intervalli di 100 nanosecondi da aggiungere; value può essere positivo o negativo |

### Valore restituito

Una nuova istanza della classe [DateTime](../) che rappresenta il valore di data e ora risultante dalla somma del valore rappresentato dall'oggetto corrente e **value** intervalli di 100 nanosecondi
