## DateTime::CompareTo(DateTime) const metodo

Confronta due valori di data e ora rappresentati dall'oggetto corrente e dall'istanza specificata della classe [DateTime](../) e restituisce il valore che indica le posizioni relative dei valori sulla linea temporale.

```cpp
constexpr int System::DateTime::CompareTo(DateTime value) const
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| value | [DateTime](../) | Un'istanza della classe [DateTime](../) con cui confrontare l'oggetto corrente |

### Valore di ritorno

Un valore minore di 0 se l'oggetto corrente rappresenta un valore precedente a quello rappresentato da **value**; 0 se i valori rappresentati da entrambi gli oggetti sono gli stessi; un valore maggiore di 0 se il valore rappresentato dall'oggetto corrente è successivo a quello rappresentato da **value**
