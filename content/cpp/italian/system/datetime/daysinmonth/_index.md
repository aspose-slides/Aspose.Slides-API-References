## DateTime::DaysInMonth(int, int) metodo

Restituisce il numero di giorni nel month specificato dell'anno specificato.

```cpp
static int System::DateTime::DaysInMonth(int year, int month)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| year | int | Il year |
| month | int | Il numero ordinale del month |

### Valore restituito

Il numero di giorni è il month specificato dell'anno specificato
