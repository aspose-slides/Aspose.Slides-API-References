## DateTime::operator<=(DateTime) const metodo

Determina se l'oggetto corrente rappresenta il valore di data e ora che è precedente o uguale al valore rappresentato dall'oggetto [DateTime](../) specificato.

```cpp
constexpr bool System::DateTime::operator<=(DateTime other) const
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| other | [DateTime](../) | L'oggetto [DateTime](../) con cui confrontare l'oggetto corrente |

### Valore di ritorno

True se il valore di data e ora rappresentato dall'oggetto corrente è precedente o uguale al valore rappresentato da **other**, altrimenti - false
