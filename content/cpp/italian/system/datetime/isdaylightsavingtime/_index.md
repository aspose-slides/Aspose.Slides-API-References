## DateTime::IsDaylightSavingTime() const metodo

Determina se il valore di data e ora rappresentato dall'oggetto corrente rientra nell'intervallo dell'ora legale per il fuso orario corrente.

```cpp
bool System::DateTime::IsDaylightSavingTime() const
```

### Valore restituito

True se il valore di data e ora specificato dall'oggetto corrente rientra nell'intervallo dell'ora legale, altrimenti - false
