## DateTime::operator>(DateTime) const metodo

Determina se l'oggetto corrente rappresenta il valore data e ora che è successivo al valore rappresentato dall'oggetto [DateTime](../) specificato.

```cpp
constexpr bool System::DateTime::operator>(DateTime other) const
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| other | [DateTime](../) | L'oggetto [DateTime](../) da confrontare con l'oggetto corrente |

### Valore di ritorno

True se il valore data e ora rappresentato dall'oggetto corrente è successivo al valore rappresentato da **other**, altrimenti - false
