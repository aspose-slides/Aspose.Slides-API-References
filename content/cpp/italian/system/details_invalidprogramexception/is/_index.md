## Dettagli_InvalidProgramException::Is(const System::TypeInfo\&) const metodo




```cpp
bool System::Details_InvalidProgramException::Is(const System::TypeInfo &target) const override
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struttura che descrive il tipo da confrontare con l'oggetto corrente. |

### Valore di ritorno

True se l'oggetto è del tipo etichettato o di una sua sottoclasse, false altrimenti.
## Note


Verifica se l'oggetto rappresenta un'istanza del tipo descritto da targetType. Analogo all'operatore 'is' di C#.
