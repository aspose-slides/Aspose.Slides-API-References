## TypeCode enum


Rappresenta il tipo di un oggetto.

```cpp
enum class TypeCode
```

### Valori

| Name | Value | Description |
| --- | --- | --- |
| Empty | 0 | Un riferimento nullo. |
| Object | 1 | Un tipo generico che rappresenta qualsiasi riferimento o tipo valore non rappresentato esplicitamente da un altro TypeCode. |
| DBNull | 2 | Un valore null di database (colonna). |
| Boolean | 3 | Un tipo semplice che rappresenta i valori [Boolean](../boolean/) di true o false. |
| Char | 4 | Un tipo integrale che rappresenta interi non firmati a 16 bit con valori compresi tra 0 e 65535. |
| SByte | 5 | Un tipo integrale che rappresenta interi con segno a 8 bit con valori compresi tra -128 e 127. |
| Byte | 6 | Un tipo integrale che rappresenta interi non firmati a 8 bit con valori compresi tra 0 e 255. |
| Int16 | 7 | Un tipo integrale che rappresenta interi con segno a 16 bit con valori compresi tra -32768 e 32767. |
| UInt16 | 8 | Un tipo integrale che rappresenta interi non firmati a 16 bit con valori compresi tra 0 e 65535. |
| Int32 | 9 | Un tipo integrale che rappresenta interi con segno a 32 bit con valori compresi tra -2147483648 e 2147483647. |
| UInt32 | 10 | Un tipo integrale che rappresenta interi non firmati a 32 bit con valori compresi tra 0 e 4294967295. |
| Int64 | 11 | Un tipo integrale che rappresenta interi con segno a 64 bit con valori compresi tra -9223372036854775808 e 9223372036854775807. |
| UInt64 | 12 | Un tipo integrale che rappresenta interi non fermati a 64 bit con valori compresi tra 0 e 18446744073709551615. |
| Single | 13 | Un tipo a virgola mobile che rappresenta valori compresi tra circa 1.5 x 10 -45 e 3.4 x 10 38 con una precisione di 7 cifre. |
| Double | 14 | Un tipo a virgola mobile che rappresenta valori compresi tra circa 5.0 x 10 -324 e 1.7 x 10 308 con una precisione di 15-16 cifre. |
| Decimal | 15 | Un tipo semplice che rappresenta valori compresi tra 1.0 x 10 -28 e circa 7.9 x 10 28 con 28-29 cifre significative. |
| DateTime | 16 | Un tipo che rappresenta un valore di data e ora. |
| String | 18 | Un tipo di classe sigillata che rappresenta stringhe di caratteri Unicode. |
