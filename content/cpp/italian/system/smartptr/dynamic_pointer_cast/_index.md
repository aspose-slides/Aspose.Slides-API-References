## SmartPtr::dynamic_pointer_cast() const metodo

Converte il puntatore a un tipo diverso usando dynamic_cast sull'oggetto puntato.

```cpp
template<class Y> SmartPtr<Y> System::SmartPtr<T>::dynamic_pointer_cast() const
```

### Parametri del modello

| Parametro | Descrizione |
| --- | --- |
| Y | Tipo di destinazione dell'oggetto puntato. |

### Valore di ritorno

Puntatore del tipo modificato, sempre in modalità condivisa.
