## SmartPtr::const_pointer_cast() const metodo

Effettua il cast del puntatore a un tipo diverso usando const_cast sull'oggetto puntato.

```cpp
template<class Y> SmartPtr<Y> System::SmartPtr<T>::const_pointer_cast() const
```

### Parametri del template

| Parametro | Descrizione |
| --- | --- |
| Y | Tipo di destinazione dell'oggetto puntato. |

### Valore di ritorno

Puntatore di tipo modificato, sempre in modalità condivisa.
