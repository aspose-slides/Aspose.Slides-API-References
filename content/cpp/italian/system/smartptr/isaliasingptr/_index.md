## SmartPtr::IsAliasingPtr() const metodo

Verifica se il puntatore fa riferimento a un oggetto diverso da quello posseduto (creato da un costruttore di aliasing).

```cpp
bool System::SmartPtr<T>::IsAliasingPtr() const
```

### Valore di ritorno

True se il puntatore ha una differenza tra gli oggetti puntati e posseduti, false altrimenti.
