## SmartPtr::get_shared_count() const metodo

Restituisce il numero di puntatori condivisi che esistono per l'oggetto referenziato, incluso quello corrente. Verifica che il puntatore corrente sia in modalità condivisa.

```cpp
int System::SmartPtr<T>::get_shared_count() const
```

### Valore di ritorno

Numero di puntatori condivisi esistenti per l'oggetto referenziato, se presente. Se il puntatore è nullo, restituisce 0.
