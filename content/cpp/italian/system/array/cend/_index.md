## Array::cend() const metodo

Restituisce un iteratore all'elemento successivo all'ultimo elemento del contenitore. Questo elemento funge da segnaposto; tentare di accedervi produce un comportamento indefinito.

```cpp
const_iterator System::Array<T>::cend() const noexcept
```

### Valore di ritorno

Un iteratore che punta all'elemento teorico const-qualificato collocato dopo l'ultimo elemento del contenitore.
