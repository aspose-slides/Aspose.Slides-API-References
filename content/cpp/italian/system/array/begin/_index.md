## Array::begin() metodo


Restituisce un iteratore al primo elemento del contenitore. Se il contenitore è vuoto, l'iteratore restituito sarà uguale a [end()](../end/).

```cpp
iterator System::Array<T>::begin() noexcept
```


### Valore di ritorno

Un iteratore che punta al primo elemento del contenitore.

## Array::begin() const metodo


Restituisce un iteratore al primo elemento del contenitore qualificato come const. Se il contenitore è vuoto, l'iteratore restituito sarà uguale a [end()](../end/).

```cpp
const_iterator System::Array<T>::begin() const noexcept
```


### Valore di ritorno

Un iteratore che punta al primo elemento del contenitore qualificato come const.
