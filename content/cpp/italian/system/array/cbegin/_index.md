## Array::cbegin() const metodo

Restituisce un iteratore al primo elemento qualificato come const del contenitore. Se il contenitore è vuoto, l'iteratore restituito sarà uguale a [cend()](../cend/).

```cpp
const_iterator System::Array<T>::cbegin() const noexcept
```

### Valore di ritorno

Un iteratore che punta al primo elemento qualificato come const del contenitore.
