## Dettagli_TypeInitializationException::Is(const System::TypeInfo\&) const method




```cpp
bool System::Details_TypeInitializationException::Is(const System::TypeInfo &target) const override
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) structure describing the type to test current object against. |

### Valore restituito

True se l'oggetto è del tipo etichettato o di una sua sottoclasse, false altrimenti.
## Osservazioni

Verifica se l'oggetto rappresenta un'istanza del tipo descritto da targetType. Analogo dell'operatore C# 'is' operator.
