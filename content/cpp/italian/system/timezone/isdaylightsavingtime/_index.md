## TimeZone::IsDaylightSavingTime(DateTime) metodo

Determina se il valore di data e ora rappresentato dall'oggetto [DateTime](../../datetime/) specificato rientra nell'intervallo dell'ora legale per il fuso orario rappresentato dall'oggetto [TimeZone](../) corrente.

```cpp
virtual bool System::TimeZone::IsDaylightSavingTime(DateTime time)=0
```

### Valore di ritorno

True se il valore di data e ora rappresentato dall'oggetto [DateTime](../../datetime/) specificato rientra nell'intervallo dell'ora legale del fuso orario rappresentato dall'oggetto [TimeZone](../) corrente, altrimenti - false
