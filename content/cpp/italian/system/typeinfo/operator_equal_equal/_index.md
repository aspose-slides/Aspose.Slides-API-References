## TypeInfo::operator==(const TypeInfo\&) const metodo


Determina se l'oggetto corrente e gli oggetti [TypeInfo](../) specificati sono uguali.

```cpp
bool System::TypeInfo::operator==(const TypeInfo &info) const
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| info | const [TypeInfo](../)\& | L'oggetto [TypeInfo](../) da confrontare |

### Valore di ritorno

True se gli hash degli oggetti sono uguali, altrimenti - false
