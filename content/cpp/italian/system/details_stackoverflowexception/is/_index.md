## Details_StackOverflowException::Is(const System::TypeInfo\&) const method

```cpp
bool System::Details_StackOverflowException::Is(const System::TypeInfo &target) const override
```

### Argomenti

| Parameter | Type | Description |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struttura che descrive il tipo da testare con l'oggetto corrente. |

### Valore restituito

True se l'oggetto è del tipo contrassegnato o della sua sottoclasse, false altrimenti.

## Osservazioni

Verifica se l'oggetto rappresenta un'istanza del tipo descritto da targetType. Analogo dell'operatore 'is' di C#.
