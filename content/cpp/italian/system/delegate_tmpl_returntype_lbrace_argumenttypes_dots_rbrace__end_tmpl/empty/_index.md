## Delegate< ReturnType(ArgumentTypes...)>::Empty() const metodo

Determina se l'oggetto delegate corrente è vuoto, ad es. non punta a nessuna entità.

```cpp
bool System::Delegate<ReturnType(ArgumentTypes...)>::Empty() const
```

### Valore restituito

True se l'oggetto delegate corrente non punta a una funzione, a un metodo di un oggetto funzione, altrimenti - false.
