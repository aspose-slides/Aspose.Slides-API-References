## Char::IsSymbol(const char_t *, int) metodo

Determina se il carattere all'indice specificato nel buffer di caratteri specificato è classificato come carattere simbolo.

```cpp
static bool System::Char::IsSymbol(const char_t *str, int idx)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| str | const char_t * | Puntatore all'inizio del buffer di caratteri |
| idx | int | Un indice a base zero nel buffer specificato del carattere da testare |

### Valore di ritorno

True se il carattere all'indice specificato è un carattere simbolo, altrimenti - false

## Char::IsSymbol(char_t) metodo

Determina se il carattere specificato è classificato come carattere simbolo.

```cpp
static bool System::Char::IsSymbol(char_t c)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| c | char_t | Il carattere da testare |

### Valore di ritorno

True se il carattere specificato è un carattere simbolo, altrimenti - false
