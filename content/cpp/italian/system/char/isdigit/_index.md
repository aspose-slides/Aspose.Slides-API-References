## Char::IsDigit(const char_t *, int) metodo

Determina se il carattere all'indice specificato nel buffer di caratteri specificato è classificato come cifra decimale.

```cpp
static bool System::Char::IsDigit(const char_t *str, int idx)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| str | const char_t * | Puntatore all'inizio del buffer di caratteri |
| idx | int | Indice basato su zero nel buffer specificato del carattere da testare |

### Valore di ritorno

True se il carattere all'indice specificato è una cifra decimale, altrimenti - false
