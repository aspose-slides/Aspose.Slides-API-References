## Char::IsLetterOrDigit(const char_t *, int) metodo


Determina se il carattere all'indice specificato nel buffer di caratteri specificato è classificato come lettera Unicode o cifra decimale.

```cpp
static bool System::Char::IsLetterOrDigit(const char_t *str, int idx)
```


### Argomenti

| Parameter | Type | Description |
| --- | --- | --- |
| str | const char_t * | Puntatore all'inizio del buffer di caratteri |
| idx | int | Un indice basato su zero nel buffer specificato del carattere da testare |

### Valore di ritorno

True se il carattere all'indice specificato è una lettera Unicode o una cifra decimale, altrimenti - false
