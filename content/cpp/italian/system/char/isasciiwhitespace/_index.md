## Char::IsAsciiWhiteSpace(char_t) method

Determina se il carattere specificato è classificato come un carattere di spazio bianco ASCII.

```cpp
static constexpr bool System::Char::IsAsciiWhiteSpace(char_t c)
```

### Argomenti

| Parameter | Type | Description |
| --- | --- | --- |
| c | char_t | Il carattere da testare |

### Valore di ritorno

True se il carattere specificato è un carattere di spazio bianco ASCII, altrimenti - false
