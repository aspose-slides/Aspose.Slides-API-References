## Char::IsSurrogate(char_t) metodo


Determina se il carattere specificato è un'unità di codice surrogate UTF-16.

```cpp
static bool System::Char::IsSurrogate(char_t c)
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| c | char_t | Un carattere |

### Valore di ritorno

True se il carattere specificato è un'unità di codice surrogate UTF-16, altrimenti - false

## Char::IsSurrogate(const String\&, int) metodo


Determina se il carattere all'indice specificato nella stringa specificata è un'unità di codice surrogate UTF-16.

```cpp
static bool System::Char::IsSurrogate(const String &s, int index)
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| s | const [String](../../string/)\& | Una stringa |
| index | int | L'indice del carattere nella stringa specificata |

### Valore di ritorno

True se il carattere all'indice specificato è un'unità di codice surrogate UTF-16, altrimenti - false
