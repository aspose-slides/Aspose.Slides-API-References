## Char::IsLetter(const char_t *, int) method


Determina se il carattere all'indice specificato nel buffer di caratteri specificato è classificato come lettera Unicode.

```cpp
static bool System::Char::IsLetter(const char_t *str, int idx)
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| str | const char_t * | Puntatore all'inizio del buffer di caratteri |
| idx | int | Un indice basato su zero nel buffer specificato del carattere da verificare |

### Valore di ritorno

True se il carattere all'indice specificato è una lettera Unicode, altrimenti - false
