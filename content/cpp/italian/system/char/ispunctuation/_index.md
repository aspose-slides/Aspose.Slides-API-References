## Char::IsPunctuation(const char_t *, int) metodo

Determina se il carattere all'indice specificato nel buffer di caratteri specificato è classificato come carattere di punteggiatura.

```cpp
static bool System::Char::IsPunctuation(const char_t *str, int idx)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| str | const char_t * | Puntatore all'inizio del buffer di caratteri |
| idx | int | Un indice a base zero nel buffer specificato del carattere da testare |

### Valore restituito

True se il carattere all'indice specificato è un carattere di punteggiatura, altrimenti - false
