## Char::IsUpper(const String\&, int) metodo


Determina se il carattere all'indice specificato nella stringa specificata è classificato come una lettera maiuscola.

```cpp
static bool System::Char::IsUpper(const String &str, int idx)
```


### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| str | const [String](../../string/)\& | La stringa contenente un char. |
| idx | int | Un indice basato su zero nella stringa specificata da testare |

### Valore di ritorno

True se il carattere all'indice specificato è una lettera maiuscola, altrimenti - false

| Parametro | Tipo | Descrizione |

| idx | int | Un indice basato su zero nel buffer specificato del carattere da testare |

True se il carattere all'indice specificato è una lettera maiuscola, altrimenti - false
