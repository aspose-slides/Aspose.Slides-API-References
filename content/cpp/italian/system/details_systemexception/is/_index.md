## Dettagli_SystemException::Is(const System::TypeInfo\&) const metodo

```cpp
bool System::Details_SystemException::Is(const System::TypeInfo &target) const override
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) struttura che descrive il tipo contro il quale testare l'oggetto corrente. |

### Valore di ritorno

True se l'oggetto è del tipo etichettato o di una sua sottoclasse, false altrimenti.

## Osservazioni

Verifica se l'oggetto rappresenta un'istanza del tipo descritto da targetType. Analogo dell'operatore 'is' di C#.
