## Dettagli_NullReferenceException::Is(const System::TypeInfo\&) const metodo

```cpp
bool System::Details_NullReferenceException::Is(const System::TypeInfo &target) const override
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | Struttura [TypeInfo](../../typeinfo/) che descrive il tipo contro cui testare l'oggetto corrente. |

### Valore di ritorno

True se l'oggetto è del tipo etichettato o di una sua sottoclasse, false altrimenti.
## Osservazioni

Verifica se l'oggetto rappresenta un'istanza del tipo descritto da targetType. Analogo dell'operatore 'is' di C#.
