## TestToolsExt::GetNamespace(const char *, const char *, std::string\&) metodo

Recupera lo spazio dei nomi del test specificato.

```cpp
static bool System::TestToolsExt::GetNamespace(const char *class_name, const char *method_name, std::string &name_space)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| class_name | const char * | Classe da cercare. |
| method_name | const char * | Metodo da cercare. |
| name_space | std::string\& | Variabile in cui inserire il nome dello spazio dei nomi, se trovato. |

### Valore di ritorno

True se il metodo di test è stato trovato, false altrimenti.
