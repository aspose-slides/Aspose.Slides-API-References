## Guid::Parse(const String\&) metodo

Converte la rappresentazione stringa specificata di un GUID in un oggetto [Guid](../) equivalente.

```cpp
static Guid System::Guid::Parse(const String &input)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| input | const [String](../../string/)\& | La stringa che contiene la rappresentazione stringa del GUID |

### Valore restituito

Un oggetto [Guid](../) che rappresenta un GUID equivalente a quello rappresentato da **input**
