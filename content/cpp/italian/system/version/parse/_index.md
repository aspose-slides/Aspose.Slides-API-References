## Version::Parse(const String\&) metodo

Converte la rappresentazione testuale di un numero di versione in un'istanza equivalente della classe [Version](../).

```cpp
static Version System::Version::Parse(const String &input)
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| input | const [String](../../string/)\& | Una stringa contenente la rappresentazione testuale di un numero di versione |

### Valore di ritorno

Un'istanza della classe [Version](../) che rappresenta il numero di versione equivalente a quello rappresentato da **input**
