## Version::CompareTo(const Version\&) const metodo

Confronta le versioni rappresentate dall'oggetto corrente e dall'oggetto specificato.

```cpp
int System::Version::CompareTo(const Version &ver) const
```

### Argomenti

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| ver | const [Version](../)\& | Un oggetto [Version](../) da confrontare con l'oggetto corrente |

### Valore restituito

- 1 se il numero di versione rappresentato dall'oggetto corrente è inferiore a quello rappresentato da **ver**; 0 se i numeri di versione sono uguali; 1 se il numero di versione rappresentato dall'oggetto corrente è maggiore del valore rappresentato da **ver**
