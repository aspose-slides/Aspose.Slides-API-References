## FlatStyle enumeración

Define si el control se dibuja plano o tridimensional.

```cpp
enum class FlatStyle
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Flat | 0 | [Control](../control/) se dibuja plano. |
| Popup | 1 | [Control](../control/) se dibuja plano a menos que el ratón se mueva sobre él cuando se dibuja con apariencia 3D. |
| Standard | 2 | [Control](../control/) se dibuja con apariencia 3D. |
| System | 3 | El estilo está controlado por el Sistema Operativo. |
