## RSA::ExportParameters(bool) método

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| include_private_parameters | **bool** | True para exportar tanto los parámetros privados como los públicos, false para exportar solo los parámetros públicos. |

### Valor devuelto

Estructura de parámetros exportados.
