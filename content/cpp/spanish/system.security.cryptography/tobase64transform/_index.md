## ToBase64Transform clase

Convierte la instancia de la clase [CryptoStream](../cryptostream/) a base 64. Los objetos de esta clase solo deben asignarse usando la función [System::MakeObject()](../../system/makeobject/). Nunca cree una instancia de este tipo en la pila ni usando el operador new, ya que provocará errores en tiempo de ejecución y/o fallos de aserción. Siempre envuelva esta clase en un puntero [System::SmartPtr](../../system/smartptr/) y use ese puntero para pasarlo a funciones como argumento.

```cpp
class ToBase64Transform : public System::Security::Cryptography::ICryptoTransform
```
