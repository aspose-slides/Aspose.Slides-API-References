## PaddingMode enumeración

Define cómo tratar los mensajes que son más cortos que el bloque requerido por la operación cripto.

```cpp
enum class PaddingMode
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| None | 1 | Sin relleno. |
| PKCS7 | 2 | Utiliza la cadena de relleno PKCS #7. |
| Zeros | 3 | Utiliza bytes cero. |
| ANSIX923 | 4 | Utiliza la cadena de relleno ANSIX923. |
| ISO10126 | 5 | Utiliza la cadena de relleno ISO10126. |
