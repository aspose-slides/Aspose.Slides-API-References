## AuthenticationLevel enumeración

Indicadores de autenticación específicos de WebRequest.

```cpp
enum class AuthenticationLevel
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| None | 0 | No se requiere autenticación para el cliente y el servidor. |
| MutualAuthRequested | 1 | La solicitud no falla si el servidor no está autenticado. |
| MutualAuthRequired | 2 | La aplicación actual recibirá 'IOException' cuando el servidor no esté autenticado. |
