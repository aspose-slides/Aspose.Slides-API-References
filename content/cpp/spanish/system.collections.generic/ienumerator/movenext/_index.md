## IEnumerator::MoveNext() método


Mueve el enumerador al siguiente elemento. Si no se había referenciado ningún elemento antes, establece la referencia al primer elemento disponible. Si se alcanza el final del contenedor, no hace nada.

```cpp
virtual bool System::Collections::Generic::IEnumerator<T>::MoveNext()=0
```


### Valor devuelto

Verdadero si hay algún elemento disponible después de la llamada, falso en caso contrario.
