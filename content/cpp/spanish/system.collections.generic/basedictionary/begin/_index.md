## BaseDictionary::begin() const method

Devuelve un iterador al KVPair-wrapper para el elemento clave-valor del contenedor. Implementado al estilo C# - el iterador debe devolver el KVPair-object con la interfaz get_Key() y get_Value(). Si el contenedor está vacío, el iterador devuelto será igual a [end()](../../ienumerable/end/).

```cpp
const_iterator System::Collections::Generic::BaseDictionary<Map>::begin() const noexcept
```

### Valor de retorno

Un iterador que apunta al primer elemento de la colección.
