## BaseDictionary::cend() const método

Devuelve un iterador al elemento que sigue al último elemento del contenedor. Implementado al estilo STL. Este elemento actúa como un marcador de posición; intentar acceder a él produce un comportamiento indefinido.

```cpp
stl_const_iterator System::Collections::Generic::BaseDictionary<Map>::cend() const noexcept
```

### Valor de retorno

Un iterador que apunta al elemento teórico calificado como const colocado después del elemento final de la colección.
