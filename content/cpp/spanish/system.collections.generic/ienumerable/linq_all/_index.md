## IEnumerable::LINQ_All(std::function\<bool(T)>) method


Determina si todos los elementos de una secuencia cumplen una condición.

```cpp
bool System::Collections::Generic::IEnumerable<T>::LINQ_All(std::function<bool(T)> predicate)
```


### Argumentos

| Parameter | Type | Description |
| --- | --- | --- |
| predicate | std::function\<**bool**(T)> | Una función para probar cada elemento con una condición. |

### Valor devuelto

true si cada elemento de la secuencia de origen supera la prueba en el predicado especificado, o si la secuencia está vacía; de lo contrario, false.
