## IEnumerable::LINQ_Any() método

Determina si una secuencia contiene elementos.

```cpp
bool System::Collections::Generic::IEnumerable<T>::LINQ_Any()
```

### Valor devuelto

true si la secuencia de origen contiene elementos; de lo contrario, false.
