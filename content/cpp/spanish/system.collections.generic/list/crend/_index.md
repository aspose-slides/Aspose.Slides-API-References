## List::crend() const método

Obtiene un iterador inverso para un elemento const calificado que no existe antes del inicio de la colección.

```cpp
const_reverse_iterator System::Collections::Generic::List<T>::crend() const noexcept
```

### Valor devuelto

Un iterador inverso que apunta al elemento teórico const calificado que precede al primer elemento de la lista (último en orden inverso).
