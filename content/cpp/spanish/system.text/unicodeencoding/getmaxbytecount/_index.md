## UnicodeEncoding::GetMaxByteCount(int) método

Obtiene el número máximo de bytes necesario para codificar un número especificado de caracteres.

```cpp
int System::Text::UnicodeEncoding::GetMaxByteCount(int char_count) override
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| char_count | int | Número de caracteres a codificar. |

### Valor de retorno

Número de bytes suficiente para codificar cualquier cadena de la longitud de caracteres dada.
