## UnicodeEncoding::GetMaxCharCount(int) método

Obtenga el número máximo de caracteres necesarios para decodificar un número especificado de bytes.

```cpp
int System::Text::UnicodeEncoding::GetMaxCharCount(int byte_count) override
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| byte_count | int | Número de bytes a decodificar. |

### Valor de retorno

Número de bytes suficiente para decodificar cualquier cadena con la longitud de caracteres dada.
