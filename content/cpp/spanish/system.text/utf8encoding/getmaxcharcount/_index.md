## UTF8Encoding::GetMaxCharCount(int) método

Obtenga el número máximo de caracteres necesarios para decodificar un número especificado de bytes.

```cpp
int System::Text::UTF8Encoding::GetMaxCharCount(int byte_count) override
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| byte_count | int | Número de bytes a decodificar. |

### Valor de retorno
