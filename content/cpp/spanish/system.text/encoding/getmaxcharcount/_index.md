## Encoding::GetMaxCharCount(int) método

Obtiene el número máximo de caracteres necesarios para decodificar una cantidad especificada de bytes.

```cpp
virtual int System::Text::Encoding::GetMaxCharCount(int byte_count)=0
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| byte_count | int | Número de bytes a decodificar. |

### Valor devuelto

Número de bytes suficiente para decodificar cualquier cadena de la longitud de caracteres dada.
