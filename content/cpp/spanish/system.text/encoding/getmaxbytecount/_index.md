## Encoding::GetMaxByteCount(int) método


Obtenga la cantidad máxima de bytes necesarios para codificar un número especificado de caracteres.

```cpp
virtual int System::Text::Encoding::GetMaxByteCount(int char_count)=0
```


### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| char_count | int | Número de caracteres a codificar. |

### Valor de retorno

Número de bytes suficiente para codificar cualquier cadena con la longitud de caracteres especificada.
