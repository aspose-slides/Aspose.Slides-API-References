## ICUEncoding::GetMaxByteCount(int) método

Obtenga la cantidad máxima de bytes necesarios para codificar un número especificado de caracteres.

```cpp
int System::Text::ICUEncoding::GetMaxByteCount(int char_count) override
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| char_count | int | Número de caracteres a codificar. |

### Valor devuelto

Número de bytes suficiente para codificar cualquier cadena con la longitud de caracteres dada.
