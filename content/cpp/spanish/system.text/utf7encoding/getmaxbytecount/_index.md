## UTF7Encoding::GetMaxByteCount(int) método

Obtenga el número máximo de bytes necesarios para codificar un número especificado de caracteres.

```cpp
int System::Text::UTF7Encoding::GetMaxByteCount(int char_count) override
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| char_count | int | Número de caracteres a codificar. |

### Valor devuelto

Número de bytes suficiente para codificar cualquier cadena de la longitud de caracteres dada.
