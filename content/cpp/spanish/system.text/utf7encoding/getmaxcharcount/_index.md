## UTF7Encoding::GetMaxCharCount(int) método

Obtener el número máximo de caracteres necesarios para decodificar una cantidad especificada de bytes.

```cpp
int System::Text::UTF7Encoding::GetMaxCharCount(int byte_count) override
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| byte_count | int | Número de bytes a decodificar. |

### Valor de retorno

Número de bytes suficiente para decodificar cualquier cadena de la longitud de caracteres especificada.
