## BaseOverrideThemeManager::get_IsOverrideThemeEnabled() método

Determina si [OverrideTheme](../../overridetheme/) sobrescribe el tema efectivo heredado o no. Para habilitar [OverrideTheme](../../overridetheme/) para sobrescribir, utilice los métodos OverrideTheme.Init*(). Para deshabilitar [OverrideTheme](../../overridetheme/) de sobrescribir, utilice el método [OverrideTheme::Clear](../../overridetheme/clear/). Solo lectura **bool**.
