## IOverrideThemeManager::get_IsOverrideThemeEnabled() método

Determina si [OverrideTheme](../../overridetheme/) sobrescribe el tema efectivo heredado o no. Para habilitar [OverrideTheme](../../overridetheme/) para sobrescribir, use los métodos OverrideTheme.Init*(). Para deshabilitar [OverrideTheme](../../overridetheme/) de sobrescribir, use el método [get_OverrideTheme()](../get_overridetheme/)->Clear(). Solo lectura **bool**.

virtual bool Aspose::Slides::Theme::IOverrideThemeManager::get_IsOverrideThemeEnabled()=0
