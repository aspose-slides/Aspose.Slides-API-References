## IsEnumerable struct

Comprueba si el tipo tiene la especialización [System::Collections::Generic::IEnumerable](../../system.collections.generic/ienumerable/) como tipo base. Si es así, el miembro value se establece en true, de lo contrario se establece en false.

```cpp
template<typename T,typename Enable>class IsEnumerable : public std::false_type
```
