## MetafileFrameUnit enum

Especifica la unidad de medida del rectángulo utilizado para dimensionar y posicionar un metafile.

```cpp
enum class MetafileFrameUnit
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Pixel | n/a | Especifica un píxel como unidad de medida. |
| Point | n/a | Especifica un punto de impresora como unidad de medida. |
| Inch | n/a | Especifica una pulgada como unidad de medida. |
| Document | n/a | Especifica 1/300 de una pulgada como unidad de medida. |
| Millimeter | n/a | Especifica un milímetro como unidad de medida. |
| GdiCompatible | n/a | Especifica .01 milímetro como unidad de medida. Proporcionado para compatibilidad con GDI. |
