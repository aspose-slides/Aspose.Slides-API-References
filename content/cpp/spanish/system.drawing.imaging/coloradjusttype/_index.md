## ColorAdjustType enum

Especifica qué objetos utilizan la información de ajuste de color.

```cpp
enum class ColorAdjustType
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Default | 0 | Define la información de ajuste de color que se usa en todos los objetos que no tienen su propia información de ajuste de color. |
| Bitmap | 1 | Define la información de ajuste de color para objetos [Bitmap](../../system.drawing/bitmap/). |
| Brush | 2 | Define la información de ajuste de color para objetos [Brush](../../system.drawing/brush/). |
| Pen | 3 | Define la información de ajuste de color para objetos [Pen](../../system.drawing/pen/). |
| Text | 4 | Define la información de ajuste de color para texto. |
| Count | 5 | Especifica el número de tipos especificados. |
| Any | 6 | Especifica el número de tipos especificados. |
