## Timer::get_Interval() const método

Obtiene el intervalo del temporizador.

```cpp
double System::Timers::Timer::get_Interval() const
```

### Valor devuelto

Intervalo entre invocaciones consecutivas del temporizador o entre el inicio del temporizador y la primera invocación, en milisegundos.
