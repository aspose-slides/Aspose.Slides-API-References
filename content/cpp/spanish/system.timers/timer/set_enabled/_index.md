## Timer::set_Enabled(bool) método


Inicia o detiene el temporizador. Iniciar el temporizador no reinicia el recuento del tiempo si el temporizador ya está en ejecución.

```cpp
void System::Timers::Timer::set_Enabled(bool value)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| value | **bool** | true para iniciar el temporizador, false para detenerlo. |
