## TraceLevel enum

Specifica qué mensajes se deben emitir para las clases [System.Diagnostics.Debug](../debug/), [System.Diagnostics.Trace](../trace/) y System.Diagnostics.TraceSwitch.

```cpp
enum class TraceLevel
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Off | 0 | No generar mensajes de rastreo y depuración. |
| Error | 1 | Generar mensajes de manejo de errores. |
| Warning | 2 | Generar advertencias y mensajes de manejo de errores. |
| Info | 3 | Generar mensajes informativos, advertencias y mensajes de manejo de errores. |
| Verbose | 4 | Generar todos los mensajes de depuración y rastreo. |
