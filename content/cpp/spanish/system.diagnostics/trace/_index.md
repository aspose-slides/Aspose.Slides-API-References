## Estructura Trace


Proporciona una interfaz para acceder al rastreo del depurador (si lo hay). Funciona solo en modo [Debug](../debug/). Este es un tipo estático sin servicios de instancia. Nunca debe crear instancias de él por ningún medio.

```cpp
class Trace
```
