## Clase EventWaitHandle

Evento que puede enviarse a un hilo en espera. Los objetos de esta clase solo deben asignarse mediante la función [System::MakeObject()](../../system/makeobject/). Nunca cree una instancia de este tipo en la pila ni usando el operador new, ya que producirá errores de tiempo de ejecución y/o fallas de aserción. Siempre envuelva esta clase en un puntero [System::SmartPtr](../../system/smartptr/) y use ese puntero para pasarlo a las funciones como argumento.

```cpp
class EventWaitHandle : public System::Threading::WaitHandle
```
