## CancellationTokenSource::Dispose() método

Libera todos los recursos utilizados por el [CancellationTokenSource](../).

```cpp
void System::Threading::CancellationTokenSource::Dispose() override
```

## Observaciones

Desregistra todas las devoluciones de llamada y hace que el token sea inutilizable. 
Las llamadas múltiples son seguras y no tienen efecto adicional.
