## Thread::get_ManagedThreadId() const método


Obtiene el identificador del hilo. Puede obtenerse del SO, pero si el identificador del hilo del SO supera los límites de int, los id de los hilos pueden intersectarse.

```cpp
int System::Threading::Thread::get_ManagedThreadId() const
```
