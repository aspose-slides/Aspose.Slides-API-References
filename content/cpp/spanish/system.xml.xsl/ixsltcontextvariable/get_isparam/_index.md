## IXsltContextVariable::get_IsParam() método


Devuelve un valor que indica si la variable es un parámetro de Extensible Stylesheet Language Transformations (XSLT). Puede ser un parámetro de una hoja de estilo o una plantilla.

```cpp
virtual bool System::Xml::Xsl::IXsltContextVariable::get_IsParam()=0
```


### Valor devuelto

**true** si la variable es un parámetro XSLT; de lo contrario, **false**.
