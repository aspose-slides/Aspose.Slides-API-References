## XsltSettings::get_EnableScript() método

Devuelve un valor que indica si se debe habilitar el soporte para bloques de script incrustados.

```cpp
bool System::Xml::Xsl::XsltSettings::get_EnableScript()
```

### Valor devuelto

**true** para soportar bloques de script en hojas de estilo XSLT; de lo contrario, **false**. El valor predeterminado es **false**.
