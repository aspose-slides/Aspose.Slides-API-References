## XsltSettings::get_EnableDocumentFunction() método

Devuelve un valor que indica si se debe habilitar el soporte para la función **document()** de XSLT.

```cpp
bool System::Xml::Xsl::XsltSettings::get_EnableDocumentFunction()
```

### Valor devuelto

**true** para soportar la función **document()** de XSLT; de lo contrario, **false**. El valor predeterminado es **false**.
