## XsltSettings::get_Default() método


Devuelve un objeto [XsltSettings](../) con la configuración predeterminada. El soporte para la función **document()** de XSLT y los bloques de script incrustados está deshabilitado.

```cpp
static SharedPtr<XsltSettings> System::Xml::Xsl::XsltSettings::get_Default()
```


### Valor devuelto

Un objeto [XsltSettings](../) con las opciones [XsltSettings::set_EnableDocumentFunction](../set_enabledocumentfunction/) y [XsltSettings::set_EnableScript](../set_enablescript/) establecidas en **false**.
