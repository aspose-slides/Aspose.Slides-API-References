## IXsltContextFunction::get_ArgTypes() método

Devuelve los tipos del Lenguaje de Ruta XML ([XPath](../../../system.xml.xpath/)) suministrados para la lista de argumentos de la función. Esta información puede utilizarse para descubrir la firma de la función, lo que permite diferenciar entre funciones sobrecargadas.

```cpp
virtual ArrayPtr<System::Xml::XPath::XPathResultType> System::Xml::Xsl::IXsltContextFunction::get_ArgTypes()=0
```

### Valor de retorno

Una matriz de XPathResultType que representa los tipos de la lista de argumentos de la función.
