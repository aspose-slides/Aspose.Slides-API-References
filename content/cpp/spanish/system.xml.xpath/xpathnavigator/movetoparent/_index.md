## XPathNavigator::MoveToParent() método

Cuando se sobrescribe en una clase derivada, mueve el [XPathNavigator](../) al nodo padre del nodo actual.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToParent()=0
```

### Valor devuelto

**true** si el [XPathNavigator](../) se mueve con éxito al nodo padre del nodo actual; de lo contrario, **false**. Si **false**, la posición del [XPathNavigator](../) no cambia.
