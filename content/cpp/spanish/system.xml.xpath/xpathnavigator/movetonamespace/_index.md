## XPathNavigator::MoveToNamespace(String) método

Mueve el [XPathNavigator](../) al nodo de espacio de nombres con el prefijo de espacio de nombres especificado.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToNamespace(String name)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| name | [String](../../../system/string/) | El prefijo de espacio de nombres del nodo de espacio de nombres. |

### Valor devuelto

**true** si el [XPathNavigator](../) se mueve con éxito al espacio de nombres especificado; **false** si no se encontró un nodo de espacio de nombres coincidente, o si el [XPathNavigator](../) no está posicionado en un nodo elemento. Si **false**, la posición del [XPathNavigator](../) no cambia.
