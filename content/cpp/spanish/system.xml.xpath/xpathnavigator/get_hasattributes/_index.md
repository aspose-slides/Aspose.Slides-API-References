## XPathNavigator::get_HasAttributes() método

Devuelve un valor que indica si el nodo actual tiene algún atributo.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::get_HasAttributes()
```

### Valor de retorno

**true** si el nodo actual tiene atributos; devuelve **false** si el nodo actual no tiene atributos, o si el [XPathNavigator](../) no está posicionado en un nodo de elemento.
