## XPathNavigator::GetNamespace(String) method

Devuelve el valor del nodo de espacio de nombres correspondiente al nombre local especificado.

```cpp
virtual String System::Xml::XPath::XPathNavigator::GetNamespace(String name)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| name | [String](../../../system/string/) | El nombre local del nodo de espacio de nombres. |

### Valor devuelto

Un [String](../../../system/string/) que contiene el valor del nodo de espacio de nombres; [String::Empty](../../../system/string/empty/) si no se encuentra un nodo de espacio de nombres coincidente, o si el [XPathNavigator](../) no está posicionado en un nodo de elemento.
