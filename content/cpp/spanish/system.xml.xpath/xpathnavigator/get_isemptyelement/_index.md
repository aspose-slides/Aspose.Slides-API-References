## XPathNavigator::get_IsEmptyElement() método



When overridden in a derived class, obtiene un valor que indica si el nodo actual es un elemento vacío sin una etiqueta de elemento de cierre.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::get_IsEmptyElement()=0
```


### Valor de retorno

**true** si el nodo actual es un elemento vacío; de lo contrario, **false**.
