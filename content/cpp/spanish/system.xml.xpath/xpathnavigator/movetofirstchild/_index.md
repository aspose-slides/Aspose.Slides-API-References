## XPathNavigator::MoveToFirstChild() método


Cuando se sobrescribe en una clase derivada, mueve el [XPathNavigator](../) al primer nodo hijo del nodo actual.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToFirstChild()=0
```


### Valor devuelto

**true** si el [XPathNavigator](../) se mueve con éxito al primer nodo hijo del nodo actual; de lo contrario, **false**. Si **false**, la posición del [XPathNavigator](../) no se altera.
