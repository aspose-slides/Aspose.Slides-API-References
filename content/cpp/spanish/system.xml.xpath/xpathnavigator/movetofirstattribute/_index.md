## XPathNavigator::MoveToFirstAttribute() método

Cuando se anula en una clase derivada, mueve el [XPathNavigator](../) al primer atributo del nodo actual.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToFirstAttribute()=0
```

### Valor devuelto

**true** si el [XPathNavigator](../) se mueve con éxito al primer atributo del nodo actual; de lo contrario, **false**. Si **false**, la posición del [XPathNavigator](../) no cambia.
