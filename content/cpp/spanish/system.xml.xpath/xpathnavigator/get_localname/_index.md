## XPathNavigator::get_LocalName() método

Cuando se sobrescribe en una clase derivada, obtiene el [XPathNavigator::get_Name](../get_name/) del nodo actual sin ningún prefijo de espacio de nombres.

```cpp
virtual String System::Xml::XPath::XPathNavigator::get_LocalName()=0
```

### Valor de retorno

Un [String](../../../system/string/) que contiene el nombre local del nodo actual, o [String::Empty](../../../system/string/empty/) si el nodo actual no tiene un nombre (por ejemplo, nodos de texto o de comentario).
