## XPathNavigator::MoveToNextAttribute() método


Cuando se sobrescribe en una clase derivada, mueve el [XPathNavigator](../) al siguiente atributo.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToNextAttribute()=0
```


### Valor devuelto

**true** si el [XPathNavigator](../) se realiza con éxito al mover al siguiente atributo; **false** si no hay más atributos. Si **false**, la posición del [XPathNavigator](../) no cambia.
