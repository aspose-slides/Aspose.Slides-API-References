## XmlCaseOrder enumeración

Especifica el orden de clasificación para letras mayúsculas y minúsculas.

```cpp
enum class XmlCaseOrder
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| None | 0 | Ignorar mayúsculas y minúsculas. |
| UpperFirst | 1 | Las letras mayúsculas se ordenan antes que las minúsculas. |
| LowerFirst | 2 | Las letras minúsculas se ordenan antes que las mayúsculas. |
