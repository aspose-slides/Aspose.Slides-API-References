## XPathNodeIterator::MoveNext() método


Cuando se sobrescribe en una clase derivada, mueve el objeto [XPathNavigator](../../xpathnavigator/) devuelto por el método [XPathNodeIterator::get_Current](../get_current/) al siguiente nodo en el conjunto de nodos seleccionados.

```cpp
virtual bool System::Xml::XPath::XPathNodeIterator::MoveNext()=0
```


### Valor de retorno

**true** si el objeto [XPathNavigator](../../xpathnavigator/) se movió al siguiente nodo; **false** si no hay más nodos seleccionados.
