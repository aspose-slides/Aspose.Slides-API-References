## StringCollection::cend() const método

Devuelve un iterador al elemento que sigue al último elemento del contenedor. Este elemento actúa como marcador de posición; intentar acceder a él produce un comportamiento indefinido.

```cpp
const_iterator System::Collections::Specialized::StringCollection::cend() const noexcept
```

### Valor de retorno

Un iterador que apunta al elemento teórico calificado como const ubicado después del último elemento del contenedor.
