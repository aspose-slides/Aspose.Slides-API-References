## StringCollection::rbegin() método

Devuelve un iterador inverso al primer elemento del contenedor invertido. Corresponde al último elemento del contenedor no invertido. Si el contenedor está vacío, el iterador devuelto es igual a [rend()](../rend/).

```cpp
reverse_iterator System::Collections::Specialized::StringCollection::rbegin() noexcept
```

### Valor devuelto

Un iterador que apunta al último elemento del contenedor.

## StringCollection::rbegin() const método

Devuelve un iterador inverso al primer elemento del contenedor invertido. Corresponde al último elemento del contenedor no invertido. Si el contenedor está vacío, el iterador devuelto es igual a [rend()](../rend/).

```cpp
const_reverse_iterator System::Collections::Specialized::StringCollection::rbegin() const noexcept
```

### Valor devuelto

Un iterador que apunta al último elemento del contenedor calificado como const.
