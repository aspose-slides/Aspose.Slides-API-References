## SpecialFolder enum

Representa carpetas especiales del sistema.

```cpp
enum class SpecialFolder
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Desktop | 0 | El escritorio lógico. |
| Programs | 2 | La carpeta que contiene los grupos de programas del usuario. |
| Personal | 5 | La carpeta que sirve como repositorio común para documentos. |
| MyDocuments | 5 | El directorio "My Documents". |
| Favorites | 6 | La carpeta que sirve como repositorio común para los elementos favoritos del usuario. |
| Startup | 7 | La carpeta que corresponde al grupo de programas de inicio del usuario. |
| Recent | 8 | La carpeta que contiene los documentos más recientemente usados del usuario. |
| SendTo | 9 | La carpeta que sirve como contenedor para los elementos del menú Enviar a. |
| StartMenu | 11 | La carpeta que sirve como contenedor para los elementos del menú Inicio. |
| MyMusic | 13 | El directorio "My Music". |
| DesktopDirectory | 16 | La carpeta que se usa para almacenar físicamente los elementos en el escritorio. |
| MyComputer | 17 | El directorio "My Computer". |
| Templates | 21 | La carpeta que sirve como contenedor común para plantillas de documentos. |
| ApplicationData | 26 | La carpeta que se usa para almacenar datos específicos de la aplicación para el usuario roaming actual. |
| LocalApplicationData | 28 | La carpeta que se usa para almacenar datos específicos de la aplicación para el usuario no roaming actual. |
| InternetCache | 32 | La carpeta que se usa como almacenamiento para archivos temporales de Internet. |
| Cookies | 33 | La carpeta que se usa como almacenamiento para cookies de Internet. |
| History | 34 | La carpeta que se usa como almacenamiento para elementos del historial de Internet. |
| CommonApplicationData | 35 | La carpeta que se usa para almacenar datos específicos de la aplicación que son utilizados por todos los usuarios. |
| System | 37 | La carpeta del sistema. |
| ProgramFiles | 38 | La carpeta de archivos del programa. |
| MyPictures | 39 | El directorio "My picutres". |
| UserProfile | 40 | La carpeta del perfil del usuario. |
| CommonProgramFiles | 43 | El directorio usado como almacenamiento para componentes que son compartidos por aplicaciones. |
