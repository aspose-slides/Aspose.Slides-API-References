## Environment::get_Version() método

Devuelve el objeto [Version](../../version/) que representa la información sobre la versión del tiempo de ejecución de lenguaje común. El número de versión devuelto por este método es más bien ficticio y no significa que todas las clases de la biblioteca se comporten de acuerdo con la versión devuelta.

```cpp
static Version System::Environment::get_Version()
```
