## TypeInfoPtr estructura

Envoltorio para un puntero a una instancia de la clase [TypeInfo](../typeinfo/). Este tipo debe asignarse en la pila y pasarse a funciones por valor o por referencia. Nunca use la clase [System::SmartPtr](../smartptr/) para gestionar objetos de este tipo.

```cpp
class TypeInfoPtr
```
