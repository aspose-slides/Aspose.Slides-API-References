## NullableUtils::GetUnderlyingType(const System::TypeInfo\&) método

Devuelve el argumento de tipo subyacente del tipo nullable especificado.

```cpp
static const System::TypeInfo & System::NullableUtils::GetUnderlyingType(const System::TypeInfo &nullableType)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| nullableType | const [System::TypeInfo](../../typeinfo/)\& | Un objeto System.Type que describe un tipo nullable genérico cerrado. |

### Valor devuelto

El argumento de tipo del parámetro nullableType, si el parámetro nullableType es un tipo nullable genérico cerrado; de lo contrario, null
