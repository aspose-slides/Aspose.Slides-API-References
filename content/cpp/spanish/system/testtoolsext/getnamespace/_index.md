## TestToolsExt::GetNamespace(const char *, const char *, std::string\&) método

Obtiene el espacio de nombres de la prueba especificada.

```cpp
static bool System::TestToolsExt::GetNamespace(const char *class_name, const char *method_name, std::string &name_space)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| class_name | const char * | Clase a buscar. |
| method_name | const char * | Método a buscar. |
| name_space | std::string\& | Variable donde colocar el nombre del espacio de nombres, si se encuentra. |

### Valor de retorno

Verdadero si se encuentra el método de prueba, falso de lo contrario.
