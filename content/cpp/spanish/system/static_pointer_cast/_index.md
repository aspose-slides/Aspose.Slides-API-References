## System::static_pointer_cast(SmartPtr\<X\> const\&) function


Realiza conversiones de punteros inteligentes usando static_cast.

```cpp
template<class Y,class X> SmartPtr<Y> System::static_pointer_cast(SmartPtr<X> const &x)
```


### Parámetros de plantilla

| Parámetro | Descripción |
| --- | --- |
| X | Tipo del elemento apuntado por el puntero de origen. |
| Y | Tipo del elemento apuntado por el puntero de destino. |

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| x | [SmartPtr](../smartptr/)\<X\> const\& | Puntero de origen. |

### Valor devuelto

Puntero después de la conversión.
