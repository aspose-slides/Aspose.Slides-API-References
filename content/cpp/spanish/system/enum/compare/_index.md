## Enum::Compare(E, T) método

Realiza la comparación aritmética de los valores de las constantes de enumeración especificadas.

```cpp
template<typename T,typename _> static int System::Enum<E, Guard>::Compare(E a, T b)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| a | E | El primer comparando |
| b | T | El segundo comparando |

### Valor devuelto

- 1 si **a** es menor que **b**; 0 si los valores son iguales; 1 si **a** es mayor que **b**
