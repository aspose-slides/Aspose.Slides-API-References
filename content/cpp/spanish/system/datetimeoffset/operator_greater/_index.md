## DateTimeOffset::operator>(const DateTimeOffset\&) const método


Determina si el objeto actual representa el valor de fecha y hora que es posterior al valor representado por el objeto [DateTimeOffset](../) especificado.

```cpp
bool System::DateTimeOffset::operator>(const DateTimeOffset &other) const
```


### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| other | const [DateTimeOffset](../)\& | El objeto [DateTimeOffset](../) con el que comparar el objeto actual |

### Valor devuelto

Verdadero si el valor de fecha y hora representado por el objeto actual es posterior al valor representado por **other**, de lo contrario - false
