## Delegate< ReturnType(ArgumentTypes...)>::Empty() const método


Determina si el objeto delegate actual está vacío, p.ej. no apunta a ninguna entidad.

```cpp
bool System::Delegate<ReturnType(ArgumentTypes...)>::Empty() const
```


### Valor de retorno

True si el objeto delegate actual no apunta a una función, a un método de un objeto función, de lo contrario - false.
