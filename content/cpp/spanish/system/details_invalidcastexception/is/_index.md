## Details_InvalidCastException::Is(const System::TypeInfo\&) const method

```cpp
bool System::Details_InvalidCastException::Is(const System::TypeInfo &target) const override
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) estructura que describe el tipo contra el que se prueba el objeto actual. |

### Valor de retorno

True si el objeto es del tipo etiquetado o de su subclase, false en caso contrario.

## Observaciones

Comprueba si el objeto representa una instancia del tipo descrito por targetType. Análogo al operador 'is' de C#.
