## System::Set(ExpressionT\&, const ExpressionT\&) función

Implementa la traducción del patrón 'var'.

```cpp
template<class ExpressionT> bool System::Set(ExpressionT &var, const ExpressionT &value)
```

### Parámetros de plantilla

| Parámetro | Descripción |
| --- | --- |
| ExpressionT | tipo de variable. |

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| var | ExpressionT\& | referencia a la variable a inicializar. |
| value | const ExpressionT\& | valor a asignar a la variable. |

### Valor de retorno

siempre verdadero (este patrón siempre coincide).
