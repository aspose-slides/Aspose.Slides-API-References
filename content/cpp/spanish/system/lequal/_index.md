## System::LEqual(const ExpressionT\&, const ConstantT\&) función

Implements '<=' relative pattern translation.

```cpp
template<class ExpressionT,class ConstantT> bool System::LEqual(const ExpressionT &left, const ConstantT &constant)
```

### Parámetros de plantilla

| Parámetro | Descripción |
| --- | --- |
| ExpressionT | tipo de expresión izquierda. |
| ConstantT | tipo de expresión constante. |

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| left | const ExpressionT\& | expresión que se comprobará. |
| constant | const ConstantT\& | expresión que se comparará con la de la izquierda. |

### Valor devuelto

true si la comprobación de tipo es exitosa, false en caso contrario.
