## StringComparison enumeración


Define el estilo de comparación de cadenas.

```cpp
enum class StringComparison
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| CurrentCulture | 0 | Utiliza la cultura actual. |
| CurrentCultureIgnoreCase | 1 | Utiliza la cultura actual, pero ignora mayúsculas y minúsculas. |
| InvariantCulture | 2 | Utiliza la cultura invariable. |
| InvariantCultureIgnoreCase | 3 | Utiliza la cultura invariable, pero ignora mayúsculas y minúsculas. |
| Ordinal | 4 | Utiliza reglas de orden ordinal. |
| OrdinalIgnoreCase | 5 | Utiliza reglas de orden ordinal, pero ignora mayúsculas y minúsculas. |
