## Decimal::CompareTo(const Decimal\&) const método

Determina si el valor representado por el objeto actual es menor que, igual a o mayor que el valor representado por el objeto especificado.

```cpp
int System::Decimal::CompareTo(const Decimal &d) const
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| d | const [Decimal](../)\& | El comparando |

### Valor devuelto

- 1 si el valor representado por el objeto actual es menor que el valor representado por **d**; 0 si los valores son iguales; 1 si el valor representado por el objeto actual es mayor que el valor representado por **d**
