## MathF::Pow(float, float) método

Devuelve el valor especificado elevado a la potencia especificada.

```cpp
static float System::MathF::Pow(float x, float y)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| x | **float** | El valor que se elevará a la potencia especificada |
| y | **float** | La potencia a la que se elevará el valor especificado |

### Valor devuelto

**x** elevado a la potencia de **y**
