## Uri::IsHexEncoding(const String\&, int32_t) método

Determina si un carácter en la cadena especificada en la posición especificada está codificado en hexadecimal.

```cpp
static bool System::Uri::IsHexEncoding(const String &pattern, int32_t index)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| pattern | const [String](../../string/)\& | La cadena a comprobar |
| index | **int32_t** | Posición basada en cero del carácter a probar |

### Valor devuelto

Verdadero si el carácter especificado está codificado en hexadecimal, de lo contrario - falso
