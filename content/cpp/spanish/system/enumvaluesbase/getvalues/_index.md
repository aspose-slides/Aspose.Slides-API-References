## EnumValuesBase::GetValues(const TypeInfo\&) método

Devuelve una matriz que contiene todos los valores del tipo de enumeración especificado.

```cpp
static ArrayPtr<int64_t> System::EnumValuesBase::GetValues(const TypeInfo &type)
```

### Argumentos

| Parameter | Type | Description |
| --- | --- | --- |
| type | const [TypeInfo](../../typeinfo/)\& | El objeto [TypeInfo](../../typeinfo/) que representa el tipo de la enumeración cuyos valores se devolverán |

### Valor devuelto

Una matriz que contiene los valores de todas las constantes de enumeración del tipo de enumeración especificado por **type**.
