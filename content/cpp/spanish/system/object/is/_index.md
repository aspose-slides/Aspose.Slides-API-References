## Object::Is(const TypeInfo\&) const método

Comprueba si el objeto representa una instancia del tipo descrito por targetType. Análogo al operador 'is' de C#.

```cpp
virtual bool System::Object::Is(const TypeInfo &targetType) const
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| targetType | const [TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) estructura que describe el tipo contra el que se prueba el objeto actual. |

### Valor devuelto

True si el objeto es de tipo etiquetado o su subclase, false en caso contrario.
