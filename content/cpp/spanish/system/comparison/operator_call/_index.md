## Comparison::operator()(T, T) método

Invoca el objeto invocable al que apunta el objeto actual.

```cpp
bool System::Comparison<T>::operator()(T a, T b)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| a | T | El primer comparando |
| b | T | El segundo comparando |

### Valor devuelto

True si **a** es menor que **b**, de lo contrario - true
