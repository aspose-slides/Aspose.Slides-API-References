## Detalles_ArgumentNullException::Is(const System::TypeInfo\&) const method

```cpp
bool System::Details_ArgumentNullException::Is(const System::TypeInfo &target) const override
```

### Parámetros

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) estructura que describe el tipo contra el cual probar el objeto actual. |

### Valor devuelto

Verdadero si el objeto es del tipo etiquetado o de su subclase, falso en caso contrario.

## Comentarios

Compruebe si el objeto representa una instancia del tipo descrito por targetType. Análogo al operador 'is' de C#.
