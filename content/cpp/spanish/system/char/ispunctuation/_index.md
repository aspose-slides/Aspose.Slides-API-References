## Char::IsPunctuation(const char_t *, int) método


Determina si el carácter en el índice especificado del búfer de caracteres especificado está clasificado como un carácter de puntuación.

```cpp
static bool System::Char::IsPunctuation(const char_t *str, int idx)
```


### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| str | const char_t * | Puntero al comienzo del búfer de caracteres |
| idx | int | Un índice basado en cero en el búfer especificado del carácter a probar |

### Valor devuelto

True si el carácter en el índice especificado es un carácter de puntuación, de lo contrario - false

static bool System::Char::IsPunctuation(char_t c)
