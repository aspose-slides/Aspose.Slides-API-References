## Char::IsControl(const char_t *, int) método


Determina si el carácter en el índice especificado del búfer de caracteres especificado se clasifica como carácter de control Unicode.

```cpp
static bool System::Char::IsControl(const char_t *str, int idx)
```


### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| str | const char_t * | Puntero al comienzo del búfer de caracteres |
| idx | int | Un índice basado en cero en el búfer especificado del carácter a probar |

### Valor de retorno

True si el carácter en el índice especificado es un carácter de control Unicode, de lo contrario - false
