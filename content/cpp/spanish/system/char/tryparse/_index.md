## Char::TryParse(const System::String\&, char_t\&) método


Intenta convertir una cadena que consta de un solo carácter a un carácter UTF-16. La función tiene éxito solo cuando la cadena de entrada no es nula y tiene una longitud exacta de un carácter.

```cpp
static bool System::Char::TryParse(const System::String &s, char_t &result)
```


### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| s | const [System::String](../../string/)\& | [String](../../string/) para convertir |
| result | char_t\& | La variable de salida que contendrá el resultado de la conversión si la conversión tiene éxito |

### Valor devuelto

True si la conversión tuvo éxito, de lo contrario - false
