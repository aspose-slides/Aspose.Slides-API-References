## Char::IsLetterOrDigit(const char_t *, int) método

Determina si el carácter en el índice especificado del búfer de caracteres especificado está clasificado como letra Unicode o un dígito decimal.

```cpp
static bool System::Char::IsLetterOrDigit(const char_t *str, int idx)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| str | const char_t * | Puntero al inicio del búfer de caracteres |
| idx | int | Índice basado en cero en el búfer especificado del carácter a probar |

### Valor devuelto

Verdadero si el carácter en el índice especificado es letra Unicode o un dígito decimal, de lo contrario - falso
