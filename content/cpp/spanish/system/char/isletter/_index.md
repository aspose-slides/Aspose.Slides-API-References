## Char::IsLetter(const char_t *, int) método

Determina si el carácter en el índice especificado del búfer de caracteres especificado está clasificado como letra Unicode.

```cpp
static bool System::Char::IsLetter(const char_t *str, int idx)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| str | const char_t * | Puntero al comienzo del búfer de caracteres |
| idx | int | Un índice basado en cero en el búfer especificado del carácter a probar |

### Valor devuelto

True si el carácter en el índice especificado es una letra Unicode, de lo contrario - false
