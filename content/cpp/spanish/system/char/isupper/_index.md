## Char::IsUpper(const String\&, int) método


Determina si el carácter en el índice especificado de la cadena especificada está clasificado como una letra mayúscula.

```cpp
static bool System::Char::IsUpper(const String &str, int idx)
```


### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| str | const [String](../../string/)\& | La cadena que contiene un carácter. |
| idx | int | Un índice basado en cero en la cadena especificada para probar |

### Valor de retorno

True si el carácter en el índice especificado es una letra mayúscula, de lo contrario - false
