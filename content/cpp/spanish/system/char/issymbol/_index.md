## Char::IsSymbol(const char_t *, int) método


Determina si el carácter en el índice especificado del búfer de caracteres especificado está clasificado como un carácter símbolo.

```cpp
static bool System::Char::IsSymbol(const char_t *str, int idx)
```


### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| str | const char_t * | Puntero al inicio del buffer de caracteres |
| idx | int | Índice basado en cero en el buffer especificado del carácter a probar |

### Valor de retorno

True si el carácter en el índice especificado es un carácter símbolo, de lo contrario - false

static bool System::Char::IsSymbol(char_t c)
