## Char::IsSeparator(const char_t *, int) método


Determina si el carácter en el índice especificado del búfer de caracteres especificado está clasificado como un carácter separador.

```cpp
static bool System::Char::IsSeparator(const char_t *str, int idx)
```


### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| str | const char_t * | Puntero al inicio del búfer de caracteres |
| idx | int | Un índice basado en cero en el búfer especificado del carácter a probar |

### Valor devuelto

True si el carácter en el índice especificado es un carácter separador, de lo contrario - false

static bool System::Char::IsSeparator(char_t c)
