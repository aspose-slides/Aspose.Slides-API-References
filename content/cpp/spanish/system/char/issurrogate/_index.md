## Char::IsSurrogate(char_t) method

Determina si el carácter especificado es una unidad de código sustituto UTF-16.

```cpp
static bool System::Char::IsSurrogate(char_t c)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| c | char_t | Un carácter |

### Valor de retorno

True si el carácter especificado es una unidad de código sustituto UTF-16, de lo contrario - false

## Char::IsSurrogate(const String\&, int) method

Determina si el carácter en el índice especificado de la cadena especificada es una unidad de código sustituto UTF-16.

```cpp
static bool System::Char::IsSurrogate(const String &s, int index)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| s | const [String](../../string/)\& | Una cadena |
| index | int | El índice del carácter en la cadena especificada |

### Valor de retorno

True si el carácter en el índice especificado es una unidad de código sustituto UTF-16, de lo contrario - false
