## Details_StackOverflowException::Is(const System::TypeInfo\&) const method

```cpp
bool System::Details_StackOverflowException::Is(const System::TypeInfo &target) const override
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) estructura que describe el tipo contra el que probar el objeto actual. |

### Valor devuelto

Verdadero si el objeto es del tipo marcado o de su subclase, falso en caso contrario.

## Comentarios

Comprueba si el objeto representa una instancia del tipo descrito por targetType. Análogo al operador 'is' de C#.
