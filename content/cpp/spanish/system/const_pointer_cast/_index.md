## System::const_pointer_cast(SmartPtr\<X\> const\&) function


Casts smart pointers using const_cast.

```cpp
template<class Y,class X> SmartPtr<Y> System::const_pointer_cast(SmartPtr<X> const &x)
```


### Parámetros de plantilla

| Parámetro | Descripción |
| --- | --- |
| X | Tipo del objeto apuntado por el puntero de origen. |
| Y | Tipo del objeto apuntado por el puntero de destino. |

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| x | [SmartPtr](../smartptr/)\<X\> const\& | Puntero de origen. |

### Valor devuelto

Puntero después del cast.
