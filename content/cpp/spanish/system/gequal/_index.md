## System::GEqual(const ExpressionT\&, const ConstantT\&) función

Implementa la traducción del patrón relativo '>='.

```cpp
template<class ExpressionT,class ConstantT> bool System::GEqual(const ExpressionT &left, const ConstantT &constant)
```

### Parámetros de plantilla

| Parámetro | Descripción |
| --- | --- |
| ExpressionT | tipo de expresión izquierda. |
| ConstantT | tipo de expresión constante. |

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| left | const ExpressionT\& | expresión que será verificada. |
| constant | const ConstantT\& | expresión que será comparada con la izquierda. |

### Valor de retorno

true si la verificación de tipos es exitosa, false en caso contrario.
