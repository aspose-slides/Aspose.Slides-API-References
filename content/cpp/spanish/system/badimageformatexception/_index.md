## BadImageFormatException typedef

La excepción que se lanza cuando la imagen de archivo de una biblioteca de enlace dinámico (DLL) o de un programa ejecutable es inválida. Nunca envuelva las instancias de la clase BadImageFormatException en [System::SmartPtr](../smartptr/).

```cpp
using System::BadImageFormatException = typedef System::ExceptionWrapper<Details_BadImageFormatException>
```
