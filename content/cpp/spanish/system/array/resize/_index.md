## Array::Resize(ArrayPtr\<Type\>\&, int) método

Cambia el tamaño de la matriz especificada al valor indicado o crea una nueva matriz con el tamaño especificado.

```cpp
template<typename Type> static void System::Array<T>::Resize(ArrayPtr<Type> &arr, int new_size)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| arr | [ArrayPtr](../../arrayptr/)\<[Type](../../object/type/)\>\& | [Array](../) para redimensionar. Si **arr** es un puntero nulo, se creará la nueva matriz |
| new_size | int | El nuevo tamaño de la matriz, o el tamaño de la nueva matriz si **arr** es nulo |
