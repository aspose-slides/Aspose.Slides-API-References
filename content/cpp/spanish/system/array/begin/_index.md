## Array::begin() método


Devuelve un iterador al primer elemento del contenedor. Si el contenedor está vacío, el iterador devuelto será igual a [end()](../end/).

```cpp
iterator System::Array<T>::begin() noexcept
```


### Valor de retorno

Un iterador que apunta al primer elemento del contenedor.

## Array::begin() const método


Devuelve un iterador al primer elemento del contenedor calificado como const. Si el contenedor está vacío, el iterador devuelto será igual a [end()](../end/).

```cpp
const_iterator System::Array<T>::begin() const noexcept
```


### Valor de retorno

Un iterador que apunta al primer elemento del contenedor calificado como const.
