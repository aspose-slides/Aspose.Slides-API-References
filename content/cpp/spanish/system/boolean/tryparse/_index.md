## Boolean::TryParse(const String\&, bool\&) método

Convierte la cadena especificada a un valor de tipo bool.

```cpp
static bool System::Boolean::TryParse(const String &value, bool &result)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| value | const [String](../../string/)\& | La cadena a convertir. |
| result | **bool**\& | La referencia a una variable bool donde se coloca el resultado de la conversión; el resultado es true si la cadena especificada es igual a \"True\" y false si la cadena especificada es igual a \"False\". |

### Valor de retorno

True si la cadena especificada es igual a \"True\" o \"False\", de lo contrario - false.
