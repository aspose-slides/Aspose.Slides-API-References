## Nullable::GetValueOrDefault(T) método


Devuelve el valor representado por el objeto actual o el valor especificado si el valor representado por el objeto actual es nulo.

```cpp
T System::Nullable<T>::GetValueOrDefault(T default_value)
```


### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| default_value | T | El valor devuelto por el método si el valor representado por el objeto actual es nulo |

### Valor devuelto

Una copia del valor representado por el objeto actual si no es nulo; de lo contrario se devuelve el valor especificado
