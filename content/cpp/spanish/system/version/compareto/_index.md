## Version::CompareTo(const Version\&) const método


Compara las versiones representadas por el objeto actual y el objeto especificado.

```cpp
int System::Version::CompareTo(const Version &ver) const
```


### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| ver | const [Version](../)\& | Un objeto [Version](../) para comparar con el objeto actual |

## Valor devuelto

- 1 si el número de versión representado por el objeto actual es menor que el representado por **ver**; 0 si los números de versión son iguales; 1 si el número de versión representado por el objeto actual es mayor que el valor representado por **ver**
