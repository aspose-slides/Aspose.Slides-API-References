## Math::Log(double) método

Devuelve el logaritmo natural del valor especificado.

```cpp
static double System::Math::Log(double d)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| d | **double** | Un valor de punto flotante de double precisión |

### Valor devuelto

El logaritmo natural de **d**

## Math::Log(double, double) método

Devuelve el logaritmo del valor especificado en la base especificada.

```cpp
static double System::Math::Log(double a, double newBase)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| a | **double** | Un valor de punto flotante de double precisión |
| newBase | **double** | La base del logaritmo |

### Valor devuelto

El logaritmo de **a** en la base **newBase**
