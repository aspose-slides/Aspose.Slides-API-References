## System::IsInfinity(const T\&) función

Determina si el valor especificado representa infinitud.

```cpp
template<typename T> bool System::IsInfinity(const T &value)
```

### Parámetros de plantilla

| Parámetro | Descripción |
| --- | --- |
| T | El tipo del valor verificado por la función |

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| value | const T\& | El valor a verificar |

### Valor devuelto

Verdadero si **value** representa infinitud, de lo contrario - falso
