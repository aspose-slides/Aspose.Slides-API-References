## System::IsNaN(const T\&) función


Determina si el valor especificado es un valor Not-A-Number.

```cpp
template<typename T> bool System::IsNaN(const T &value)
```


### Parámetros de plantilla

| Parámetro | Descripción |
| --- | --- |
| T | El tipo del valor verificado por la función |

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| value | const T\& | El valor a comprobar |

### Valor devuelto

True if **value** is a NaN value, otherwise - false
