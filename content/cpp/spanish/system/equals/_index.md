## System::Equals(const TA\&, const TB\&) función

Determina la igualdad de dos valores aplicando [operator==()](../operator_equal_equal/) a ellos.

```cpp
template<typename TA,typename TB> bool System::Equals(const TA &a, const TB &b)
```

### Parámetros de plantilla

| Parámetro | Descripción |
| --- | --- |
| TA | El tipo del primer comparando |
| TB | El tipo del segundo comparando |

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| a | const TA\& | El primer comparando |
| b | const TB\& | El segundo comparando |

### Valor devuelto

El valor booleano devuelto por [operator==()](../operator_equal_equal/) aplicado a **a** y **b**
