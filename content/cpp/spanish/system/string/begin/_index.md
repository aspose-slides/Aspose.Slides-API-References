## String::begin() const método


Devuelve un puntero al inicio del búfer de cadena real. Nunca vuelve a asignar nada. No garantiza que el búfer esté terminado en nulo.

```cpp
const UChar * System::String::begin() const
```


### Valor devuelto

Puntero al búfer de cadena real, con terminación nula o sin ella.
