## String::rend() const método

Devuelve un iterador inverso al carácter anterior al primer carácter (si lo hay) del búfer de cadena real.

```cpp
reverse_iterator System::String::rend() const
```

### Valor devuelto

Iterador inverso al elemento que precede al primer carácter del búfer de cadena real (si lo hay) o al elemento justo antes del búfer asignado.
