## String::IsNull() const método


Comprueba si la cadena se considera nula. [String](../) es nula y solo si se construye mediante el constructor [String()](../string/), se mueve, se copia o se asigna desde una cadena nula o se llamó al método [reset()](../reset/).

```cpp
bool System::String::IsNull() const
```


### Valor de retorno

true si la cadena se considera nula, false de lo contrario.
