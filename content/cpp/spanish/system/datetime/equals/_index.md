## DateTime::Equals(DateTime) const método

Determina si la instancia especificada de la clase [DateTime](../) representa el mismo valor de fecha y hora que el objeto actual.

```cpp
constexpr bool System::DateTime::Equals(DateTime other) const
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| other | [DateTime](../) | La instancia de la clase [DateTime](../) para comparar el objeto actual |

### Valor de retorno

True si tanto **other** como el objeto actual representan el mismo valor, de lo contrario - false
