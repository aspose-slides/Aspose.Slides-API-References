## DateTime::FromBinary(int64_t) método


Deserializa el valor de fecha y hora del entero sin signo de 64 bits especificado y establece la nueva instancia de la clase [DateTime](../) a ese valor.

```cpp
static DateTime System::DateTime::FromBinary(int64_t value)
```


### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| value | **int64_t** | El entero de 64 bits del cual deserializar el valor de fecha y hora |

### Valor de retorno

Una nueva instancia de la clase [DateTime](../) que representa el valor de fecha y hora deserializado del entero sin signo de 64 bits especificado
