## DateTime::AddMinutes(double) const método

Devuelve una nueva instancia de la clase [DateTime](../) que representa el valor de fecha y hora que es la suma del valor representado por el objeto actual y el número especificado de minutos.

```cpp
DateTime System::DateTime::AddMinutes(double value) const
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| value | **double** | El número de minutos a añadir; el valor puede ser positivo o negativo |

### Valor devuelto

Una nueva instancia de la clase [DateTime](../) que representa el valor de fecha y hora que es la suma del valor representado por el objeto actual y **value** minutos
