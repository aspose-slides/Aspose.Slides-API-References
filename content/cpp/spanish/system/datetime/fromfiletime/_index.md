## DateTime::FromFileTime(int64_t) método


Convierte el tiempo de archivo especificado en una instancia de la clase [DateTime](../) que representa el mismo valor de fecha y hora que la hora local.

```cpp
static DateTime System::DateTime::FromFileTime(int64_t value)
```


### Arguments

| Parameter | Type | Description |
| --- | --- | --- |
| value | **int64_t** | Tiempo de archivo a convertir |

### Return Value

Una nueva instancia de la clase [DateTime](../) que representa la misma fecha y hora que **file_time**
