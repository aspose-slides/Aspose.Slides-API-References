## DateTime::AddYears(int) const método

Devuelve una nueva instancia de la [DateTime](../) clase que representa el valor de fecha y hora igual al representado por el objeto actual con el componente del año incrementado en el número especificado.

```cpp
DateTime System::DateTime::AddYears(int value) const
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| value | int | El número de años a añadir; el valor puede ser positivo o negativo |

### Valor de retorno

Una nueva instancia de la [DateTime](../) clase que representa el valor de fecha y hora igual al representado por el objeto actual con el componente del año incrementado en **value**
