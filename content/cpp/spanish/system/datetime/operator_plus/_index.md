## DateTime::operator+(TimeSpan) const method

```cpp
DateTime System::DateTime::operator+(TimeSpan value) const
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| value | [TimeSpan](../../timespan/) | El intervalo de tiempo que se suma al valor representado por el objeto actual |

### Valor devuelto

Una nueva instancia de la clase [DateTime](../) que representa el valor de fecha y hora que es la suma del valor representado por el objeto actual y **value**.
