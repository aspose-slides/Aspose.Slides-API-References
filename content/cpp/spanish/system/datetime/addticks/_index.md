## DateTime::AddTicks(int64_t) const método

Devuelve una nueva instancia de la clase [DateTime](../) que representa el valor de fecha y hora que es la suma del valor representado por el objeto actual y el número especificado de intervalos de 100-nanosegundos.

```cpp
DateTime System::DateTime::AddTicks(int64_t value) const
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| value | **int64_t** | El número de intervalos de 100-nanosegundos a añadir; el valor puede ser positivo o negativo |

### Valor devuelto

Una nueva instancia de la clase [DateTime](../) que representa el valor de fecha y hora que es la suma del valor representado por el objeto actual y **value** de intervalos de 100-nanosegundos
