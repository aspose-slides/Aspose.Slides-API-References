## DateTime::operator<(DateTime) const método

Determina si el objeto actual representa el valor de fecha y hora que es anterior al valor representado por el objeto [DateTime](../) especificado.

```cpp
constexpr bool System::DateTime::operator<(DateTime other) const
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| other | [DateTime](../) | El objeto [DateTime](../) con el que comparar el objeto actual |

### Valor de retorno

Verdadero si el valor de fecha y hora representado por el objeto actual es anterior al valor representado por **other**, de lo contrario - falso
