## EnumGetNameHelper::GetName(T) método

Devuelve el nombre de cadena del valor constante del enum especificado.

```cpp

```

### Parámetros de plantilla

| Parameter | Description |
| --- | --- |
| T | El tipo de valores enum que acepta el método; **T** debe ser convertible a **E** |

### Argumentos

| Parameter | Type | Description |
| --- | --- | --- |
| value | T | El valor constante del enum cuyo nombre en forma de cadena debe obtenerse |

### Valor devuelto

Un nombre en forma de cadena del valor constante del enum especificado
