## EnumGetNameHelper estructura

Clase auxiliar que proporciona la funcionalidad de obtener el nombre en forma de cadena de una constante de enumeración.

```cpp
template<class E,class G,class Guard>class EnumGetNameHelper
```

### Parámetros de plantilla

| Parámetro | Descripción |
| --- | --- |
| E | El tipo del enum con el que operan los métodos de la clase |
| G | No utilizado |
| Guard | No utilizado |
## Métodos

| Método | Descripción |
| --- | --- |
| static [String](../string/) [GetName](./getname/)(T) | Devuelve el nombre en forma de cadena del valor constante del enum especificado. |
