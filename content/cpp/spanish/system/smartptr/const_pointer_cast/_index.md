## SmartPtr::const_pointer_cast() const método

Convierte el puntero a un tipo diferente usando const_cast en el objeto apuntado.

```cpp
template<class Y> SmartPtr<Y> System::SmartPtr<T>::const_pointer_cast() const
```

### Parámetros de plantilla

| Parámetro | Descripción |
| --- | --- |
| Y | Tipo objetivo del objeto apuntado. |

### Valor de retorno

Puntero del tipo modificado que siempre está en modo compartido.
