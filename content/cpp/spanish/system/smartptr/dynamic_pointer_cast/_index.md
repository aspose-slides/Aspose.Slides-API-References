## SmartPtr::dynamic_pointer_cast() const método

Convierte el puntero a un tipo diferente usando dynamic_cast sobre el objeto apuntado.

```cpp
template<class Y> SmartPtr<Y> System::SmartPtr<T>::dynamic_pointer_cast() const
```

### Parámetros de plantilla

| Parámetro | Descripción |
| --- | --- |
| Y | Tipo de destino del objeto apuntado. |

### Valor devuelto

Puntero del tipo cambiado que siempre está en modo compartido.
