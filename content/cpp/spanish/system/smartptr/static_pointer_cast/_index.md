## SmartPtr::static_pointer_cast() const método

Convierte el puntero a un tipo diferente usando static_cast sobre el objeto apuntado.

```cpp
template<class Y> SmartPtr<Y> System::SmartPtr<T>::static_pointer_cast() const
```

### Parámetros de plantilla

| Parámetro | Descripción |
| --- | --- |
| Y | Tipo objetivo del objeto apuntado. |

### Valor devuelto

Puntero del tipo cambiado que siempre está en modo compartido.
