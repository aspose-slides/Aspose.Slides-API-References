## SmartPtr::IsAliasingPtr() const método


Comprueba si el puntero apunta a otro objeto distinto al poseído (creado por un constructor alias).

```cpp
bool System::SmartPtr<T>::IsAliasingPtr() const
```


### Valor devuelto

True si el puntero tiene una diferencia entre los objetos apuntados y poseídos, false en caso contrario.
