## SmartPtr::get_shared_count() const método

Obtiene el número de punteros compartidos que existen al objeto referenciado, incluido el actual. Asegura que el puntero actual esté en modo compartido.

```cpp
int System::SmartPtr<T>::get_shared_count() const
```


### Valor de retorno

Número de punteros compartidos que existen al objeto referenciado, si los hay. Si el puntero es nulo, devuelve 0.
