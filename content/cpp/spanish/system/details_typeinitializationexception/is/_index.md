## Details_TypeInitializationException::Is(const System::TypeInfo\&) const método

```cpp
bool System::Details_TypeInitializationException::Is(const System::TypeInfo &target) const override
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| target | const [System::TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) estructura que describe el tipo contra el cual se prueba el objeto actual. |

### Valor devuelto

True si el objeto es del tipo etiquetado o de su subclase, false de lo contrario.

## Observaciones

Comprueba si el objeto representa una instancia del tipo descrito por targetType. Análogo al operador 'is' de C#.
