## TimeSpan::CompareTo(TimeSpan) const método

Compara el objeto actual con los objetos especificados.

```cpp
constexpr int System::TimeSpan::CompareTo(TimeSpan value) const
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| value | [TimeSpan](../) | El objeto [TimeSpan](../) con el que comparar el objeto actual |

### Valor devuelto

- 1 si el objeto actual representa el intervalo que es más corto que **value**; 0 si el objeto actual representa el intervalo que es igual a **value**; 1 si el objeto actual representa el intervalo que es más largo que **value**
