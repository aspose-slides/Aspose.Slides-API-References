## HolderInitializer< T, false > estructura


[HolderInitializer](../holderinitializer/) especialización para el caso en que T es un tipo de valor., El contexto de uso permite devolver una referencia a objetos temporales, ya que se garantiza que la instancia será copiada por el llamador. Por lo tanto, esta especialización se usa solo como un stub y no hace nada.

```cpp
template<typename T>class HolderInitializer< T, false >
```
