## System::CheckedCast(TFrom) función

Determina si el valor especificado se encuentra dentro del rango de valores del tipo **TTo** y, de ser así, lo convierte al tipo **TTo**.

```cpp
template<typename TTo,typename TFrom> TTo System::CheckedCast(TFrom value)
```

### Parámetros de plantilla

| Parámetro | Descripción |
| --- | --- |
| TTo | El tipo al cual se debe convertir el valor especificado |
| TFrom | El tipo del valor especificado |

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| value | TFrom | El valor a convertir |

### Valor devuelto

El valor de tipo **TTo** equivalente a **value**
