## System::Less(const ExpressionT\&, const ConstantT\&) función


Implementa la traducción de patrones relativos '<'.

```cpp
template<class ExpressionT,class ConstantT> bool System::Less(const ExpressionT &left, const ConstantT &constant)
```


### Parámetros de plantilla

| Parámetro | Descripción |
| --- | --- |
| ExpressionT | tipo de expresión izquierda. |
| ConstantT | tipo de expresión constante. |

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| left | const ExpressionT\& | expresión que se verificará. |
| constant | const ConstantT\& | expresión que se comparará con la de la izquierda. |

### Valor de retorno

true si la verificación de tipos es exitosa, false en caso contrario.
