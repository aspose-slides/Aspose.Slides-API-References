## EnumParseHelper estructura

Clase auxiliar que proporciona funcionalidad para convertir una representación de cadena de una constante enum en su valor enum equivalente.

```cpp
template<class E,class G,class Guard>class EnumParseHelper
```

### Parámetros de plantilla

| Parámetro | Descripción |
| --- | --- |
| E | El tipo del enum con el que operan los métodos de la clase |
| G | Segundo argumento formal de [System::Enum](../enum/) para usar. |
| Guard | Argumento formal de plantilla para seleccionar el algoritmo de análisis disponible. |
## Métodos

| Método | Descripción |
| --- | --- |
| static E [Parse](./parse/)(const [String](../string/)\&, **bool**) | Convierte la cadena especificada en el valor de constante enum equivalente. |
