## enumeración NumberStyles

Estilo de número permitido al analizar.

```cpp
enum class NumberStyles : int32_t
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| None | 0 | Sin símbolos que no sean dígitos. |
| AllowLeadingWhite | 1 | Permitir espacios en blanco iniciales. |
| AllowTrailingWhite | 2 | Permitir espacios finales. |
| AllowLeadingSign | 4 | Permitir signo inicial. |
| Integer | n/a | Formato entero predeterminado. |
| AllowTrailingSign | 8 | Permitir signo final. |
| AllowParentheses | 16 | Permitir paréntesis para valores negativos. |
| AllowDecimalPoint | 32 | Permitir punto decimal. |
| AllowThousands | 64 | Permitir separadores de grupos. |
| Number | n/a | Formato de número compuesto predeterminado. |
| AllowExponent | 128 | Permitir signo de exponente. |
| Float | n/a | Formato de número de punto flotante predeterminado. |
| AllowCurrencySymbol | 256 | Permitir símbolo de moneda. |
| Currency | n/a | Formato de moneda predeterminado. |
| Any | n/a | Permitir cualquier especificador de formato. |
| AllowHexSpecifier | 512 | Permitir números hexadecimales. |
| HexNumber | n/a | Formato de número hexadecimal predeterminado. |
