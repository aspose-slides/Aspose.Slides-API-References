## NumberFormatInfo::get_PercentGroupSizes() const método

Obtiene la cantidad de dígitos por grupo de valores de porcentaje.

```cpp
ArrayPtr<int> System::Globalization::NumberFormatInfo::get_PercentGroupSizes() const
```

### Valor de retorno

[Array](../../../system/array/) de dígitos por grupo, de izquierda a derecha; cada elemento debe ser de 1 a 9, el último puede ser 0 que significa "combinar todo"; el último elemento se repite.
