## NumberFormatInfo::get_NumberGroupSizes() const método


Obtiene el número de dígitos por grupo.

```cpp
ArrayPtr<int> System::Globalization::NumberFormatInfo::get_NumberGroupSizes() const
```


### Valor de retorno

[Array](../../../system/array/) de dígitos por grupo, de izquierda a derecha; cada elemento debe ser de 1 a 9, el último puede ser 0 lo que significa \"combinar todo\"; el último elemento se repite.
