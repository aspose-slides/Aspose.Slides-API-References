## CompareInfo::IsSortable(char16_t) método

Comprueba si un carácter especificado es ordenable.

```cpp
static bool System::Globalization::CompareInfo::IsSortable(char16_t ch)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| ch | char16_t | Carácter Unicode. |

### Valor devuelto

True si **ch** es ordenable; de lo contrario false.

```cpp
static bool System::Globalization::CompareInfo::IsSortable(const String &text)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| text | const [String](../../../system/string/)\& | Una cadena. |

### Valor devuelto

True si **text** no está vacío y todos los caracteres en **text** son ordenables; de lo contrario false.
