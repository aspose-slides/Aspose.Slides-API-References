## DigitShapes enum

Especifica la visualización de los dígitos.

```cpp
enum class DigitShapes : int32_t
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Context | 0 | La forma del dígito depende del texto previo. |
| None | 1 | La forma del dígito no se cambia. |
| NativeNational | 2 | Los dígitos ASCII 0..9 se sustituyen por dígitos nacionales nativos. |
