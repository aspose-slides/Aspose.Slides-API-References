## CultureTypes enum

Culture categories bitmask entries.

```cpp
enum class CultureTypes : int32_t
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| NeutralCultures | 1 | Cultura que es específica para el idioma pero no para el país o la región. |
| SpecificCultures | 2 | Específica para el país/región. |
| InstalledWin32Cultures | 4 | Culturas instaladas en el sistema operativo. |
| AllCultures | n/a | Todas las culturas disponibles. |
| UserCustomCulture | 8 | Culturas definidas por el usuario. |
| ReplacementCultures | 16 | Reemplazos definidos por el usuario para culturas existentes. |
| WindowsOnlyCultures | 32 | Obsoleto. |
| FrameworkCultures | 64 | Obsoleto. |
