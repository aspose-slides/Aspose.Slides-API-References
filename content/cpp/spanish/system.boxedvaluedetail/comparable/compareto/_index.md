## Comparable::CompareTo(T) método

Compara el objeto actual con el objeto especificado.

```cpp
int System::BoxedValueDetail::Comparable<T, Self>::CompareTo(T other) override
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| other | T | El objeto con el que comparar el objeto actual |

### Valor devuelto

Un número negativo si el objeto actual precede al objeto especificado en el orden de clasificación; 0 si los objetos comparados son iguales; número positivo si el objeto actual sigue al objeto especificado en el orden de clasificación
