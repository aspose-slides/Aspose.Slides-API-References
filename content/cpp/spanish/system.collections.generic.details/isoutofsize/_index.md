## System::Collections::Generic::Details::IsOutOfSize(int, const Container\&) función


Comprueba si el índice está fuera de los límites del contenedor, incluido el tamaño del contenedor.

```cpp
template<typename Container> bool System::Collections::Generic::Details::IsOutOfSize(int count, const Container &container)
```


### Parámetros de plantilla

| Parámetro | Descripción |
| --- | --- |
| Container | Tipo de contenedor. |

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| count | int | [Index](../../system/index/). |
| container | const Container\& | Contenedor contra el que se verifica el índice. |

### Valor devuelto

True si el índice está fuera de los límites del contenedor, false de lo contrario.
