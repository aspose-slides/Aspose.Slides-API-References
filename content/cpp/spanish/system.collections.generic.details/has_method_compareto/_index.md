## has_method_compareto struct

Comprueba si el método CompareTo existe en el tipo especificado. Si es así, hereda std::true_type, de lo contrario hereda std::false_type. Puede usarse en std::enable_if.

```cpp
template<typename T,typename Sfinae>class has_method_compareto : public std::false_type
```

### Parámetros de plantilla

| Parámetro | Descripción |
| --- | --- |
| T | Tipo para comprobar la existencia del método Equals. |
| Sfinae | Argumento de plantilla formal para que SFINAE funcione. |
