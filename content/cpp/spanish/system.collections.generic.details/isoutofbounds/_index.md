## System::Collections::Generic::Details::IsOutOfBounds(int, const Container\&) función


Comprueba si el índice está fuera de los límites del contenedor, excluyendo el tamaño del contenedor.

```cpp
template<typename Container> bool System::Collections::Generic::Details::IsOutOfBounds(int idx, const Container &container)
```


### Parámetros de plantilla

| Parámetro | Descripción |
| --- | --- |
| Container | Tipo de contenedor. |

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| idx | int | [Index](../../system/index/). |
| container | const Container\& | Contenedor contra el que comprobar el índice. |

### Valor devuelto

True si el índice está fuera de los límites del contenedor, false en caso contrario.
