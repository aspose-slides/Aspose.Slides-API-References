## has_method_compareto_shared_ptr struct


Comprueba si el método CompareTo(SharedPtr<T>) existe en el tipo especificado. En caso afirmativo, hereda std::true_type, de lo contrario hereda std::false_type. Puede usarse en std::enable_if.

```cpp
template<typename T,typename Sfinae>class has_method_compareto_shared_ptr : public std::false_type
```


### Parámetros de plantilla

| Parámetro | Descripción |
| --- | --- |
| T | Tipo para comprobar la existencia del método Equals. |
| Sfinae | Argumento formal de plantilla para que SFINAE funcione. |
