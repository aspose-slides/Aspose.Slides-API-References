## Enumerable::Range(int32_t, int32_t) método

Genera una secuencia de números integrales dentro de un rango especificado.

```cpp
static SharedPtr<Collections::Generic::IEnumerable<int32_t>> System::Linq::Enumerable::Range(int32_t start, int32_t count)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| start | **int32_t** | El valor del primer entero en la secuencia. |
| count | **int32_t** | El número de enteros secuenciales a generar. |

### Valor devuelto

Un IEnumerable de **int32_t** que contiene un rango de números integrales secuenciales.
