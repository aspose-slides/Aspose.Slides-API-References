
### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| target | const [System::TypeInfo](../../../system/typeinfo/)\& | [TypeInfo](../../../system/typeinfo/) estructura que describe el tipo contra el que probar el objeto actual. |

### Valor devuelto

True si el objeto es del tipo etiquetado o de su subclase, false en caso contrario.
## Observaciones

Comprueba si el objeto representa una instancia del tipo descrito por targetType. Análogo al operador 'is' de C#.
