## ReflectionTypeLoadException definición de tipo


ReflectionTypeLoadException se lanza mediante el método Module.GetTypes si alguna de las clases en un módulo no se puede cargar. Nunca envuelva las instancias de la clase ReflectionTypeLoadException en [System::SmartPtr](../../system/smartptr/).

```cpp
using System::Reflection::ReflectionTypeLoadException = typedef System::ExceptionWrapper<Details_ReflectionTypeLoadException>
```
