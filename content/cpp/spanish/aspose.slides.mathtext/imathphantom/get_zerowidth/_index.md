## IMathPhantom::get_ZeroWidth() método

Obtiene un valor que indica si el ancho del elemento base debe tratarse como cero.

```cpp
virtual bool Aspose::Slides::MathText::IMathPhantom::get_ZeroWidth()=0
```

## Observaciones

Cuando **true**, el fantasma no reserva espacio horizontal para su base. Corresponde al atributo OMML **m:zeroWid**.
