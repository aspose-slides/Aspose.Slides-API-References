## IMathPhantom::get_Show() método


Obtiene un valor que indica si el elemento base se muestra.

```cpp
virtual bool Aspose::Slides::MathText::IMathPhantom::get_Show()=0
```

## Observaciones


Cuando **false**, el elemento base está oculto pero puede seguir ocupando espacio dependiendo de otras configuraciones fantasma. Corresponde al atributo OMML **m:show**.
