## IMathPhantom::set_ZeroWidth(bool) método

Establece un valor que indica si el ancho del elemento base debe tratarse como cero.

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_ZeroWidth(bool value)=0
```

## Observaciones

Cuando **true**, el fantasma no reserva espacio horizontal para su base. Corresponde al atributo OMML **m:zeroWid**.
