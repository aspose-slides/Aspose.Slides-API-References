## IMathPhantom::set_ZeroDesc(bool) método

Establece un valor que indica si el descenso (profundidad bajo la línea base) del elemento base debe tratarse como cero.

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_ZeroDesc(bool value)=0
```

## Observaciones

Cuando **true**, el fantasma no baja la línea base de la línea matemática circundante. Corresponde al atributo OMML **m:zeroDesc**.
