## Clase IMathBox

Especifica el embalaje lógico (encapsulamiento) de un elemento matemático. Por ejemplo, un objeto empaquetado puede servir como un emulador de operador con o sin un punto de alineación, servir como punto de salto de línea, o agruparse de forma que no se permitan saltos de línea dentro. Por ejemplo, el operador \"==\" debe estar empaquetado para evitar saltos de línea.

```cpp
class IMathBox : public virtual Aspose::Slides::MathText::IMathElement
```
