## IMathMatrix::set_MinColumnWidth(uint32_t) método


Anchura mínima de columna en twips (1/20 de punto) El espaciado de la brecha (también denominado “Column Gap” o “Gap Width”) se añade a MinColumnWidth para determinar el total Matrix [Column](../../../aspose.slides/column/) Spacing (distancia entre los mismos bordes de diferentes columnas). Predeterminado: 0.

```cpp
virtual void Aspose::Slides::MathText::IMathMatrix::set_MinColumnWidth(uint32_t value)=0
```

## Observaciones


Ejemplo: 
```cpp
auto matrix = System::MakeObject<MathMatrix>(2, 3);
matrix->set_MinColumnWidth(20);
```
