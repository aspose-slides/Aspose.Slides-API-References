## MathJustification enum

Especifica la justificación del párrafo matemático (una serie de instancias adyacentes de texto matemático dentro del mismo párrafo)

```cpp
enum class MathJustification
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| LeftJustified | 1 | Alinear el texto matemático a la izquierda |
| RightJustified | 2 | Alinear el texto matemático a la derecha |
| Centered | 3 | Alinear el texto matemático al centro |
| CenteredAsGroup | 4 | Centrar en la página todo el grupo de bloques de matemáticas como una sola unidad. Esto significa que las instancias de texto matemático pueden alinearse entre sí, pero todo el grupo de texto matemático se centra como un todo. |
