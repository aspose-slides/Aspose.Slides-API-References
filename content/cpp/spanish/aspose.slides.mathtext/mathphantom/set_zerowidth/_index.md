## MathPhantom::set_ZeroWidth(bool) método

Establece un valor que indica si el ancho del elemento base debe considerarse cero.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_ZeroWidth(bool value) override
```

## Observaciones

Cuando **true**, el fantasma no reserva espacio horizontal para su base. Corresponde al atributo OMML **m:zeroWid**.
