## MathPhantom::set_Show(bool) método


Establece un valor que indica si el elemento base se muestra.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_Show(bool value) override
```

## Observaciones


Cuando **false**, el elemento base está oculto pero puede seguir ocupando espacio dependiendo de otras configuraciones fantasma. Corresponde al atributo OMML **m:show**.
