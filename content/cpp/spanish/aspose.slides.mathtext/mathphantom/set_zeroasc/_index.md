## MathPhantom::set_ZeroAsc(bool) método


Establece un valor que indica si el ascenso (altura sobre la línea base) del elemento base debe tratarse como cero.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_ZeroAsc(bool value) override
```

## Observaciones


Cuando **true**, el fantasma no eleva la línea base de la línea matemática circundante. Corresponde al atributo OMML **m:zeroAsc**.
