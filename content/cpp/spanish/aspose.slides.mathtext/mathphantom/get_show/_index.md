## MathPhantom::get_Show() método

Obtiene un valor que indica si el elemento base se muestra.

```cpp
bool Aspose::Slides::MathText::MathPhantom::get_Show() override
```

## Observaciones

Cuando **false**, el elemento base está oculto pero aún puede ocupar espacio según otras configuraciones phantom. Corresponde al atributo OMML **m:show**.
