## MathPhantom::set_ZeroDesc(bool) método

Establece un valor que indica si el descenso (profundidad por debajo de la línea base) del elemento base debe tratarse como cero.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_ZeroDesc(bool value) override
```

## Observaciones

Cuando **true**, el fantasma no baja la línea base de la línea matemática circundante. Corresponde al atributo OMML **m:zeroDesc**.
