## MathBox clase

Especifica el empaquetado lógico (encajado) del elemento matemático. Por ejemplo, un objeto empaquetado puede servir como un emulador de operador con o sin un punto de alineación, servir como un punto de ruptura de línea, o agruparse de manera que no se permitan rupturas dentro. Por ejemplo, el operador \"==\" debe empaquetarse para evitar rupturas de línea.

```cpp
class MathBox : public Aspose::Slides::MathText::MathElementBase,
                public Aspose::Slides::MathText::IMathBox,
                public Aspose::Slides::MathText::IHasControlCharacterProperties
```
