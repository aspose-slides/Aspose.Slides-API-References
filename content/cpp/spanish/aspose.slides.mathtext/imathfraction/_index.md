## IMathFraction clase

Especifica el objeto fracción, compuesto por un numerador y un denominador separados por una barra de fracción. La barra de fracción puede ser horizontal o diagonal, dependiendo de las propiedades de la fracción. El objeto fracción también se usa para representar la función de apilamiento, que coloca un elemento sobre otro, sin barra de fracción.

```cpp
class IMathFraction : public virtual Aspose::Slides::MathText::IMathElement
```
