## IMathBlock clase

Especifica una instancia de texto matemático que está contenida dentro de un [MathParagraph](../mathparagraph/) y comienza en una línea propia. Todas las zonas matemáticas, incluidas ecuaciones, expresiones, matrices de ecuaciones o expresiones y fórmulas, están representadas por un bloque matemático.

```cpp
class IMathBlock : public Aspose::Slides::MathText::IMathElementCollection,
                   public virtual Aspose::Slides::MathText::IMathElement
```
