## SoapHeaderAttribute clase

Especifica el encabezado SOAP que el método de servicio XML [Web](../../system.web/) o el cliente de servicio XML [Web](../../system.web/) puede procesar. Los objetos de esta clase solo deben asignarse usando la función [System::MakeObject()](../../system/makeobject/). Nunca cree una instancia de este tipo en la pila ni usando el operador new, ya que resultará en errores de tiempo de ejecución y/o fallas de aserción. Siempre envuelva esta clase en un puntero [System::SmartPtr](../../system/smartptr/) y use dicho puntero para pasarlo a funciones como argumento.

```cpp
class SoapHeaderAttribute : public System::Attribute
```
