## SmoothingMode enum

Especifica qué tipo de suavizado (antialiasing) se aplica a líneas, curvas y bordes de áreas rellenas.

```cpp
enum class SmoothingMode
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Invalid | n/a | Valor inválido. |
| Default | n/a | Modo predeterminado, sin antialiasing. |
| HighSpeed | n/a | Sin antialiasing, alta velocidad. |
| HighQuality | n/a | Renderizado con antialiasing, baja velocidad. |
| None | n/a | Sin antialising. |
| AntiAlias | n/a | Renderizado con antialiasing. |
