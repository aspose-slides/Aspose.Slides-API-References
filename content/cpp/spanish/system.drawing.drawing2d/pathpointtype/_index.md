## PathPointType enum


Specifies the type of a path point.

```cpp
enum class PathPointType
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Start | 0 | El punto inicial. |
| Line | 1 | Un segmento de línea. |
| Bezier | 3 | Curva Bézier. |
| PathTypeMask | 7 | Un punto de máscara de tipo. |
| DashMode | 16 | Especifica que un segmento está punteado. |
| PathMarker | 32 | Un marcador de ruta. |
| CloseSubpath | 128 | El punto final de un subtrayecto. |
| Bezier3 | 3 | Curva Bézier cúbica. |
