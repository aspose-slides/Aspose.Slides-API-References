## enum DashCap

Especifica el tipo de tapa que se utiliza en ambos extremos de una línea de guiones.

```cpp
enum class DashCap
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Flat | 0 | Una tapa cuadrada que corta ambos extremos de una línea de guiones. |
| Round | 2 | Una tapa circular que redondea ambos extremos de una línea de guiones. |
| Triangle | 3 | Una tapa triangular que apunta en ambos extremos de una línea de guiones. |
