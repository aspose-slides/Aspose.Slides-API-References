## PixelOffsetMode enum

Especifica cómo se desplazan los píxeles al renderizarse.

```cpp
enum class PixelOffsetMode
```

### Valores

| Name | Value | Description |
| --- | --- | --- |
| Invalid | n/a | Valor no válido. |
| Default | n/a | El modo predeterminado. |
| HighSpeed | n/a | Modo de baja calidad (alto rendimiento). |
| HighQuality | n/a | Modo de alta calidad (menor rendimiento). |
| None | n/a | Sin desplazamiento de píxeles. |
| Half | n/a | Los píxeles se desplazan -0.5 unidades tanto horizontal como verticalmente para anti-aliasing de alto rendimiento. |
