## Clases

| Clase | Descripción |
| --- | --- |
| [ConcurrentDictionary](./concurrentdictionary/) | Implementación de diccionario seguro para hilos. Objetos de esta clase solo deben asignarse usando la función [System::MakeObject()](../system/makeobject/). Nunca cree una instancia de este tipo en la pila o usando operator new, ya que resultará en errores de tiempo de ejecución y/o fallos de aserción. Siempre envuelva esta clase en un puntero [System::SmartPtr](../system/smartptr/) y use ese puntero para pasarla a funciones como argumento. |
