## ResultValueTask::get_IsFaulted() const método


Obtiene un valor que indica si la tarea se completó debido a una excepción no controlada.

```cpp
bool System::Threading::Tasks::ResultValueTask<T>::get_IsFaulted() const
```


### Valor de retorno

## Observaciones
