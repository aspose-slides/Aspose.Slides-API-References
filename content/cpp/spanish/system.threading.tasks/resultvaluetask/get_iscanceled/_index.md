## ResultValueTask::get_IsCanceled() const método


Obtiene un valor que indica si la tarea se completó debido a que fue cancelada.

```cpp
bool System::Threading::Tasks::ResultValueTask<T>::get_IsCanceled() const
```


### Valor de retorno

bool True si la tarea fue cancelada; de lo contrario, false.
## Observaciones



Devuelve false si la tarea contiene un valor de resultado directo.
