## Clase DataGrid

Clase ficticia que permite enlazar código traducido con referencias [DataGrid](./), pero no lo ejecuta. No contiene miembros implementados correctamente. Los objetos de esta clase solo deben asignarse usando la función [System::MakeObject()](../../system/makeobject/). Nunca cree una instancia de este tipo en la pila ni usando el operador new, ya que provocará errores en tiempo de ejecución y/o fallos de aserción. Siempre encapsule esta clase en un puntero [System::SmartPtr](../../system/smartptr/) y utilice ese puntero para pasarlo a funciones como argumento.

```cpp
class DataGrid : public System::Object
```
