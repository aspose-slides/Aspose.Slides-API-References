| [DataGrid](./datagrid/) | Clase ficticia que permite enlazar código traducido con referencias [DataGrid](./datagrid/), pero no lo ejecuta. No contiene miembros implementados correctamente. Los objetos de esta clase solo deben asignarse usando la función [System::MakeObject()](../system/makeobject/). Nunca cree una instancia de este tipo en la pila o mediante el operador new, ya que provocará errores de tiempo de ejecución y/o fallas de aserción. Siempre envuelva esta clase en un puntero [System::SmartPtr](../system/smartptr/) y use ese puntero para pasarlo a funciones como argumento. |
