## SslProtocols enum

Enumera los protocolos criptográficos.

```cpp
enum class SslProtocols
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| None | 0 | El sistema operativo elige un protocolo para usar. |
| Ssl2 | 12 | El protocolo SSL 2.0. |
| Ssl3 | 48 | El protocolo SSL 3.0. |
| Tls | 192 | El protocolo TLS 1.0. |
| Default | 240 | Permite que solo se usen los protocolos SSL 3.0 o TLS 1.0. |

| Tls12 | 3072 | El protocolo TLS 1.2. |
