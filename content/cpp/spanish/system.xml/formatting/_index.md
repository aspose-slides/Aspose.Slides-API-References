## Enumeración de formato


Especifica opciones de formato para el [XmlTextWriter](../xmltextwriter/).

```cpp
enum class Formatting
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| None | 0 | No se aplica formato especial. Este es el valor predeterminado. |
| Indented | 1 | Hace que los elementos secundarios se sangren según la configuración de [XmlTextWriter::set_Indentation](../xmltextwriter/set_indentation/) y [XmlTextWriter::set_IndentChar](../xmltextwriter/set_indentchar/). |
