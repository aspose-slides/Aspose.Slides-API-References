## XmlNodeChangedEventArgs::get_Action() método

Devuelve un valor que indica qué tipo de evento de cambio de nodo está ocurriendo.

```cpp
XmlNodeChangedAction System::Xml::XmlNodeChangedEventArgs::get_Action()
```

### Valor devuelto

Uno de los valores de enumeración que describe el evento de cambio de nodo. El valor **Action** no diferencia entre cuándo ocurrió el evento (antes o después). Puedes crear controladores de eventos separados para manejar ambas instancias.
