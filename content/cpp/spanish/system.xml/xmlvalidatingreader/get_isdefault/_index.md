## XmlValidatingReader::get_IsDefault() método

Devuelve un valor que indica si el nodo actual es un atributo que se generó a partir del valor predeterminado definido en la definición de tipo de documento (DTD) o en el esquema.

```cpp
bool System::Xml::XmlValidatingReader::get_IsDefault() override
```

### Valor de retorno

**true** si el nodo actual es un atributo cuyo valor se generó a partir del valor predeterminado definido en el DTD o esquema; **false** si el valor del atributo se estableció explícitamente.
