## XmlValidatingReader::get_IsEmptyElement() método


Devuelve un valor que indica si el nodo actual es un elemento vacío (por ejemplo, **<MyElement/>**).

```cpp
bool System::Xml::XmlValidatingReader::get_IsEmptyElement() override
```


### Valor devuelto

**true** si el nodo actual es un elemento ([XmlValidatingReader::get_NodeType](../get_nodetype/) valor es igual a [XmlNodeType::Element](../../xmlnodetype/)) que termina con **/>**; de lo contrario, **false**.
