## XmlValidatingReader::get_HasValue() método


Devuelve un valor que indica si el nodo actual puede tener un [XmlValidatingReader::get_Value](../get_value/) distinto de [String::Empty](../../../system/string/empty/).

```cpp
bool System::Xml::XmlValidatingReader::get_HasValue() override
```


### Valor de retorno
