## XmlElement::get_IsEmpty() método

Devuelve el formato de etiqueta del elemento.

```cpp
bool System::Xml::XmlElement::get_IsEmpty()
```

### Valor devuelto

**true** si el elemento debe serializarse en el formato de etiqueta corta \"<tt><item/></tt>\"; **false** para el formato largo \"<tt><item></item></tt>\".
