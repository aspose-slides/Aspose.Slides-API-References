## XmlNodeReader::get_IsEmptyElement() método


Devuelve un valor que indica si el nodo actual es un elemento vacío (por ejemplo, **<MyElement/>**).

```cpp
bool System::Xml::XmlNodeReader::get_IsEmptyElement() override
```


### Valor de retorno

**true** si el nodo actual es un elemento ([XmlNodeReader::get_NodeType](../get_nodetype/) es igual a [XmlNodeType::Element](../../xmlnodetype/)) y termina con **/>**; de lo contrario, **false**.
