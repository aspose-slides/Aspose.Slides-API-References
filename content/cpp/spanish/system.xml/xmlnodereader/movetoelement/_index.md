## XmlNodeReader::MoveToElement() método


Se traslada al elemento que contiene el nodo de atributo actual.

```cpp
bool System::Xml::XmlNodeReader::MoveToElement() override
```


### Valor devuelto

**true** si el lector está posicionado en un atributo (el lector se traslada al elemento que posee el atributo); **false** si el lector no está posicionado en un atributo (la posición del lector no cambia).
