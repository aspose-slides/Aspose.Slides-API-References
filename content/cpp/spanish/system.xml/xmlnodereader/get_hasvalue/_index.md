## XmlNodeReader::get_HasValue() método

Devuelve un valor que indica si el nodo actual puede tener un [XmlNodeReader::get_Value](../get_value/) valor.

```cpp
bool System::Xml::XmlNodeReader::get_HasValue() override
```

### Valor de retorno

**true** si el nodo en el que el lector está posicionado actualmente puede tener un **Value**; de lo contrario, **false**.
