## XmlWriter::LookupPrefix(String) método

Cuando se sobrescribe en una clase derivada, devuelve el prefijo más próximo definido en el alcance actual del espacio de nombres para el URI del espacio de nombres.

```cpp
virtual String System::Xml::XmlWriter::LookupPrefix(String ns)=0
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| ns | [String](../../../system/string/) | El URI del espacio de nombres cuyo prefijo desea encontrar. |

### Valor de retorno

El prefijo coincidente o **nullptr** si no se encuentra un URI de espacio de nombres coincidente en el alcance actual.
