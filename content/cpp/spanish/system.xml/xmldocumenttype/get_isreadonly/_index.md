## XmlDocumentType::get_IsReadOnly() método


Devuelve un valor que indica si el nodo es de solo lectura.

```cpp
bool System::Xml::XmlDocumentType::get_IsReadOnly() override
```


### Valor de retorno

**true** si el nodo es de solo lectura; de lo contrario, **false**. Debido a que los nodos DocumentType son de solo lectura, este método siempre devuelve **true**.
