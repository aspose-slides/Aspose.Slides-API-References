## XmlAttribute::get_LocalName() método


Devuelve el nombre local del nodo.

```cpp
String System::Xml::XmlAttribute::get_LocalName() override
```


### Valor devuelto

El nombre del nodo de atributo con el prefijo eliminado. En el siguiente ejemplo **<book bk:genre= 'novel'>**, el **LocalName** del atributo es **genre**.
