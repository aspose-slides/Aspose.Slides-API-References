## XmlAttribute::get_Specified() método

Devuelve un valor que indica si el valor del atributo se estableció explícitamente.

```cpp
virtual bool System::Xml::XmlAttribute::get_Specified()
```

### Valor de retorno

**true** si este atributo recibió explícitamente un valor en el documento de instancia original; de lo contrario, **false**. Un valor de **false** indica que el valor del atributo proviene del DTD.
