## EntityHandling enum

Especifica cómo el [XmlTextReader](../xmltextreader/) o [XmlValidatingReader](../xmlvalidatingreader/) manejan las entidades.

```cpp
enum class EntityHandling
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| ExpandEntities | 1 | Expande todas las entidades y devuelve los nodos expandidos. |
| ExpandCharEntities | 2 | Expande entidades de caracteres y devuelve entidades generales como nodos [XmlNodeType::EntityReference](../xmlnodetype/). |
