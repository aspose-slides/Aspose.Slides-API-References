## XmlWriterSettings::get_WriteEndDocumentOnClose() método


Devuelve un valor que indica si [XmlWriter](../../xmlwriter/) añadirá etiquetas de cierre a todas las etiquetas de elemento sin cerrar cuando se llame al [XmlWriter::Close](../../xmlwriter/close/) método.

```cpp
bool System::Xml::XmlWriterSettings::get_WriteEndDocumentOnClose()
```


### Valor devuelto

**true** si todas las etiquetas de elemento sin cerrar se cierran; de lo contrario, **false**. El valor predeterminado es **true**.
