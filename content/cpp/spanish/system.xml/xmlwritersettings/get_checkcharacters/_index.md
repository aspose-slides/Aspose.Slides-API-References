## XmlWriterSettings::get_CheckCharacters() método

Devuelve un valor que indica si el escritor XML debe comprobar que todos los caracteres del documento cumplan la sección \"2.2 Characters\" del W3C [XML 1.0 Recommendation](https://www.w3.org/TR/REC-xml/#charsets).

```cpp
bool System::Xml::XmlWriterSettings::get_CheckCharacters()
```

### Valor devuelto

**true** para realizar la comprobación de caracteres; de lo contrario, **false**. El valor predeterminado es **true**.
