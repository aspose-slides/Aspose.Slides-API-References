## XmlWriterSettings::get_CloseOutput() método

Devuelve un valor que indica si [XmlWriter](../../xmlwriter/) también debe cerrar el flujo subyacente o TextWriter cuando se llama al método [XmlWriter::Close](../../xmlwriter/close/).

```cpp
bool System::Xml::XmlWriterSettings::get_CloseOutput()
```

### Valor de retorno

**true** para también cerrar el flujo subyacente o TextWriter; de lo contrario, **false**. El valor predeterminado es **false**.
