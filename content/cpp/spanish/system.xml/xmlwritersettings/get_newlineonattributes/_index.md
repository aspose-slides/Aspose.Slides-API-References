## XmlWriterSettings::get_NewLineOnAttributes() método

Devuelve un valor que indica si se deben escribir los atributos en una nueva línea.

```cpp
bool System::Xml::XmlWriterSettings::get_NewLineOnAttributes()
```

### Valor devuelto

**true** para escribir los atributos en líneas individuales; de lo contrario, **false**. El predeterminado es **false**.
