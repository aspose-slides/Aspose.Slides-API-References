## XmlWriterSettings::get_OmitXmlDeclaration() método


Devuelve un valor que indica si se debe omitir una declaración XML.

```cpp
bool System::Xml::XmlWriterSettings::get_OmitXmlDeclaration()
```


### Valor de retorno

**true** para omitir la declaración XML; de lo contrario, **false**. El valor predeterminado es **false**, se escribe una declaración XML.
