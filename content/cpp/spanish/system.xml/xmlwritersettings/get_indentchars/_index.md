## XmlWriterSettings::get_IndentChars() método


Devuelve la cadena de caracteres que se utiliza para la sangría. Esta configuración se usa cuando el valor [XmlWriterSettings::set_Indent](../set_indent/) está establecido en **true**.

```cpp
String System::Xml::XmlWriterSettings::get_IndentChars()
```


### Valor de retorno

La cadena de caracteres que se utiliza para la sangría. Puede establecerse a cualquier valor de cadena. Sin embargo, para garantizar XML válido, debe especificar solo caracteres de espacio en blanco válidos, como espacios, tabulaciones, retornos de carro o saltos de línea. El valor predeterminado son dos espacios.
