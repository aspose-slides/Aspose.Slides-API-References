## XmlWriterSettings::get_Indent() método


Devuelve un valor que indica si se deben sangrar los elementos.

```cpp
bool System::Xml::XmlWriterSettings::get_Indent()
```


### Valor de retorno

**true** para escribir cada elemento en una nueva línea y sangrar; de lo contrario, **false**. El valor predeterminado es **false**.
