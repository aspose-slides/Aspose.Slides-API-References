## XmlTextReader::get_Namespaces() método


Devuelve un valor que indica si se debe habilitar el soporte de espacios de nombres.

```cpp
bool System::Xml::XmlTextReader::get_Namespaces()
```


### Valor devuelto

**true** para habilitar el soporte de espacios de nombres; de lo contrario, **false**. El valor predeterminado es **true**.
