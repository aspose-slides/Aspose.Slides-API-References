## XmlTextReader::get_ProhibitDtd() método


Devuelve un valor que indica si se permite el procesamiento de DTD.

```cpp
bool System::Xml::XmlTextReader::get_ProhibitDtd()
```


### Valor devuelto

**true** para prohibir el procesamiento de DTD; de lo contrario **false**. El valor predeterminado es **false**.

Obsoleto
:   Este método está obsoleto. Use [XmlTextReader::get_DtdProcessing](../get_dtdprocessing/) en su lugar.
