## XmlTextReader::ReadString() método


Lee el contenido de un elemento o un nodo de texto como una cadena.

```cpp
String System::Xml::XmlTextReader::ReadString() override
```


### Valor devuelto

El contenido del elemento o del nodo de texto. Puede ser una cadena vacía si el lector está posicionado en algo que no sea un elemento o un nodo de texto, o si no hay más contenido de texto que devolver en el contexto actual. **Nota:** El nodo de texto puede ser un nodo de elemento o un nodo de texto de atributo.
