## XmlTextWriter::get_Namespaces() método

Devuelve un valor que indica si se debe hacer soporte de namespace.

```cpp
bool System::Xml::XmlTextWriter::get_Namespaces()
```

### Valor devuelto

**true** para soportar namespaces; de lo contrario, **false**. El valor predeterminado es **true**.
