## XmlTextWriter::get_QuoteChar() método

Devuelve qué carácter se debe usar para citar los valores de los atributos.

```cpp
char16_t System::Xml::XmlTextWriter::get_QuoteChar()
```

### Valor devuelto

El carácter que se debe usar para citar los valores de los atributos. Debe ser una comilla simple **'** o una comilla doble **\"**. El valor predeterminado es una comilla doble.
