## XmlTextWriter::get_XmlSpace() método


Devuelve un XmlSpace que representa el ámbito actual **xml:space**.

```cpp
System::Xml::XmlSpace System::Xml::XmlTextWriter::get_XmlSpace() override
```


### Valor devuelto

Un XmlSpace que representa el ámbito actual **xml:space**.



| Valor | Significado |
| --- | --- |
| None | Este es el valor predeterminado si no existe ningún ámbito `xml:space`. |
| Default | El ámbito actual es `xml:space="default"`. |
| Preserve | El ámbito actual es `xml:space="preserve"`. |
