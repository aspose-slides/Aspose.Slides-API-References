## XmlNamespaceManager::HasNamespace(String) método

Devuelve un valor que indica si el prefijo suministrado tiene un espacio de nombres definido para el ámbito actual apilado.

```cpp
virtual bool System::Xml::XmlNamespaceManager::HasNamespace(String prefix)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| prefix | [String](../../../system/string/) | El prefijo del espacio de nombres que desea encontrar. |

### Valor devuelto

**true** si hay un espacio de nombres definido; de lo contrario, **false**.
