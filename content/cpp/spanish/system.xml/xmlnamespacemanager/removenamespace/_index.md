## XmlNamespaceManager::RemoveNamespace(String, String) método

Elimina el espacio de nombres proporcionado para el prefijo dado.

```cpp
virtual void System::Xml::XmlNamespaceManager::RemoveNamespace(String prefix, String uri)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| prefix | [String](../../../system/string/) | El prefijo para el espacio de nombres. |
| uri | [String](../../../system/string/) | El espacio de nombres a eliminar para el prefijo dado. El espacio de nombres eliminado proviene del alcance de espacio de nombres actual. Los espacios de nombres fuera del alcance actual se ignoran. |
