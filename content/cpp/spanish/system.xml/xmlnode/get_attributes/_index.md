## XmlNode::get_Attributes() método


Devuelve un [XmlAttributeCollection](../../xmlattributecollection/) que contiene los atributos de este nodo.

```cpp
virtual SharedPtr<XmlAttributeCollection> System::Xml::XmlNode::get_Attributes() final
```


### Valor devuelto

Un [XmlAttributeCollection](../../xmlattributecollection/) que contiene los atributos del nodo. Si el nodo es del tipo [XmlNodeType::Element](../../xmlnodetype/), se devuelven los atributos del nodo. De lo contrario, este método devuelve **nullptr**.
