## XmlNode::CreateNavigator() method

Creates an XPathNavigator for navigating this object.

```cpp
SharedPtr<XPath::XPathNavigator> System::Xml::XmlNode::CreateNavigator() override
```

### Valor devuelto

Un objeto XPathNavigator utilizado para navegar el nodo. El XPathNavigator está posicionado en el nodo desde el cual se llamó al método. No está posicionado en la raíz del documento.
