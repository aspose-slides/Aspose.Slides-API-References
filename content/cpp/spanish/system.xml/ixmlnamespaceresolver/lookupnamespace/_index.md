## IXmlNamespaceResolver::LookupNamespace(const String\&) método

Devuelve el URI del espacio de nombres asignado al prefijo especificado.

```cpp
virtual String System::Xml::IXmlNamespaceResolver::LookupNamespace(const String &prefix)=0
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| prefix | const [String](../../../system/string/)\& | El prefijo cuyo URI de espacio de nombres desea encontrar. |

### Valor devuelto

El URI del espacio de nombres que está asignado al prefijo; **nullptr** si el prefijo no está asignado a un URI de espacio de nombres.
