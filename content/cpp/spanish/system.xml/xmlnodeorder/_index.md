## XmlNodeOrder enum

Describe el orden del documento de un nodo en comparación con un segundo nodo.

```cpp
enum class XmlNodeOrder
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Before | 0 | El nodo actual de este navegante está antes del nodo actual del navegante suministrado. |
| After | 1 | El nodo actual de este navegante está después del nodo actual del navegante suministrado. |
| Same | 2 | Los dos navegantes están posicionados en el mismo nodo. |
| Unknown | 3 | Las posiciones de los nodos no pueden determinarse en orden de documento, en relación mutua. Esto podría ocurrir si los dos nodos residen en árboles diferentes. |
