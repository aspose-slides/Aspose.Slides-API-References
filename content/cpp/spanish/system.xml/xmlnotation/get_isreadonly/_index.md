## XmlNotation::get_IsReadOnly() método

Devuelve un valor que indica si el nodo es de solo lectura.

```cpp
bool System::Xml::XmlNotation::get_IsReadOnly() override
```

### Valor devuelto

**true** si el nodo es de solo lectura; de lo contrario, **false**. Porque los nodos [XmlNotation](../) son de solo lectura, este método siempre devuelve **true**.
