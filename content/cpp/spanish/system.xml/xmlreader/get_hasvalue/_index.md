## XmlReader::get_HasValue() método

Cuando se sobrescribe en una clase derivada, obtiene un valor que indica si el nodo actual puede tener un valor [XmlReader::get_Value](../get_value/).

```cpp
virtual bool System::Xml::XmlReader::get_HasValue()
```

### Valor de retorno

**true** si el nodo en el que el lector está actualmente posicionado puede tener un **Value**; de lo contrario, **false**. Si **false**, el nodo tiene un valor de [String::Empty](../../../system/string/empty/).
