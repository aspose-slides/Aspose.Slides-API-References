## XmlReader::ReadString() método

Cuando se sobrescribe en una clase derivada, lee el contenido de un elemento o nodo de texto como una cadena. Sin embargo, se recomienda usar el método [XmlReader::ReadElementContentAsString](../readelementcontentasstring/) en su lugar, porque proporciona una forma más directa de manejar esta operación.

```cpp
virtual String System::Xml::XmlReader::ReadString()
```

### Valor devuelto

El contenido del elemento o una cadena vacía.
