## XmlReader::MoveToElement() método

Cuando se sobrescribe en una clase derivada, se desplaza al elemento que contiene el nodo de atributo actual.

```cpp
virtual bool System::Xml::XmlReader::MoveToElement()=0
```

### Valor de retorno

**true** si el lector está posicionado en un atributo (el lector se desplaza al elemento que posee el atributo); **false** si el lector no está posicionado en un atributo (la posición del lector no cambia).
