## XmlReader::get_IsEmptyElement() método


Cuando se sobrescribe en una clase derivada, obtiene un valor que indica si el nodo actual es un elemento vacío (por ejemplo, **<MyElement/>**).

```cpp
virtual bool System::Xml::XmlReader::get_IsEmptyElement()=0
```


### Valor devuelto

**true** si el nodo actual es un elemento ([XmlReader::get_NodeType](../get_nodetype/) es igual a [XmlNodeType::Element](../../xmlnodetype/)) que termina con **/>**; de lo contrario, **false**.
