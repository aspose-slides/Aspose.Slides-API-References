## XmlReaderSettings::get_IgnoreComments() método

Devuelve un valor que indica si se deben ignorar los comentarios.

```cpp
bool System::Xml::XmlReaderSettings::get_IgnoreComments()
```

### Valor devuelto

**true** para ignorar los comentarios; de lo contrario **false**. El valor predeterminado es **false**.
