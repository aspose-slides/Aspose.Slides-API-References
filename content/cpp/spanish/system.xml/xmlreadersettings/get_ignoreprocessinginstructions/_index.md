## XmlReaderSettings::get_IgnoreProcessingInstructions() método

Devuelve un valor que indica si se deben ignorar las instrucciones de procesamiento.

```cpp
bool System::Xml::XmlReaderSettings::get_IgnoreProcessingInstructions()
```

### Valor devuelto

**true** para ignorar las instrucciones de procesamiento; de lo contrario **false**. El valor predeterminado es **false**.
