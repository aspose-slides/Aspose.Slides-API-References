## XmlReaderSettings::get_CloseInput() método

Devuelve un valor que indica si el flujo subyacente o TextReader debe cerrarse cuando se cierra el lector.

```cpp
bool System::Xml::XmlReaderSettings::get_CloseInput()
```

### Valor de retorno

**true** para cerrar el flujo subyacente o TextReader cuando se cierra el lector; de lo contrario **false**. El valor predeterminado es **false**.
