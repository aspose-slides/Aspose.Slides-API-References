## XmlReaderSettings::get_IgnoreWhitespace() método


Devuelve un valor que indica si se debe ignorar el espacio en blanco insignificante.

```cpp
bool System::Xml::XmlReaderSettings::get_IgnoreWhitespace()
```


### Valor de retorno

**true** para ignorar el espacio en blanco; de lo contrario **false**. El valor predeterminado es **false**.
