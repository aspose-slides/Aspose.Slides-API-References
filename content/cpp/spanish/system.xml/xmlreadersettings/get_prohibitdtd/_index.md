## XmlReaderSettings::get_ProhibitDtd() método


Devuelve un valor que indica si se debe prohibir el procesamiento de la definición de tipo de documento (DTD).

```cpp
bool System::Xml::XmlReaderSettings::get_ProhibitDtd()
```


### Valor de retorno

**true** para prohibir el procesamiento de DTD; de lo contrario, **false**. El valor predeterminado es **true**.

Obsoleto
:   Este método está obsoleto. Use [XmlTextReader::get_DtdProcessing](../../xmltextreader/get_dtdprocessing/) en su lugar.
