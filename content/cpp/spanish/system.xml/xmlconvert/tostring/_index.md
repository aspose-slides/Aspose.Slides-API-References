## XmlConvert::ToString(DateTimeOffset, const String\&) método

```cpp

```


### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| value | [DateTimeOffset](../../../system/datetimeoffset/) | El [DateTimeOffset](../../../system/datetimeoffset/) a convertir. |
| format | const [String](../../../system/string/)\& | El formato al que **s** se convierte. El parámetro de formato puede ser cualquier subconjunto de la Recomendación W3C para el tipo XML dateTime. ### Valor devuelto

Una representación [String](../../../system/string/) en el formato especificado del [DateTimeOffset](../../../system/datetimeoffset/) suministrado.
