## XmlConvert::VerifyNCName(const String\&) método


Verifica que el nombre sea un **NCName** válido según la recomendación del Lenguaje de Marcado Extendido de la W3C. Un **NCName** es un nombre que no puede contener dos puntos.

```cpp
static String System::Xml::XmlConvert::VerifyNCName(const String &name)
```


### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| name | const [String](../../../system/string/)\& | El nombre a verificar. |

### Valor devuelto

El nombre, si es un NCName válido.
