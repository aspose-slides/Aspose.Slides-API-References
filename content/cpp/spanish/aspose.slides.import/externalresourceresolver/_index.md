## Observaciones

El uso de este resolvedor podría crear una vulnerabilidad cuando un archivo HTML o SVG provisto por el cliente haga que el software del servidor obtenga un archivo local o de red. Úselo con precaución. Se recomienda no especificar [ExternalResourceResolver](./) en absoluto (solo se leerán los objetos incrustados) o crear alguna subclase que verifique si el uri especificado es válido.
