## IFillOverlay clase

Representa un efecto de superposición de relleno. Una superposición de relleno puede usarse para especificar un relleno adicional para un objeto y mezclar los dos rellenos juntos.

```cpp
class IFillOverlay : public virtual Aspose::Slides::Effects::IImageTransformOperation,
                     public Aspose::Slides::IAccessiblePVIObject<System::SharedPtr<Aspose::Slides::Effects::IFillOverlayEffectiveData>>
```
