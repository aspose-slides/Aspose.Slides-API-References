## PVICachingMode enum

Representa diferentes niveles de almacenamiento en caché para los objetos efectivos de PVI.

```cpp
enum class PVICachingMode
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| NoCaching | 0 | Modo clásico con creación de cada instancia. |
| NotDefinedOnly | 1 | Usar almacenamiento en caché de valores efectivos para formatos NotDefined, modo clásico para el resto. |
| Full | 2 | Usar almacenamiento en caché de valores efectivos para todos los formatos. |
