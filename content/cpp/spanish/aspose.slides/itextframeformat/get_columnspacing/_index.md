## ITextFrameFormat::get_ColumnSpacing() método

Devuelve el espacio entre columnas de texto en el área de texto (en puntos). Esto solo debe aplicarse cuando haya más de 1 columna presente. Este valor debe ser un número positivo. De lo contrario, el valor se establecerá a cero. Lee **double**.

```cpp
virtual double Aspose::Slides::ITextFrameFormat::get_ColumnSpacing()=0
```
