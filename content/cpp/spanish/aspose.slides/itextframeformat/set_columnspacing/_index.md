## ITextFrameFormat::set_ColumnSpacing(double) método


Establece el espacio entre las columnas de texto en el área de texto (en puntos). Esto solo debe aplicarse cuando hay más de 1 columna presente. Este valor debe ser un número positivo. De lo contrario, el valor se establecerá en cero. Escriba **double**.

virtual void Aspose::Slides::ITextFrameFormat::set_ColumnSpacing(double value)=0
