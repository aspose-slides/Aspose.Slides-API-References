## ISSlideShowTransition::get_SoundIsBuiltIn() método

Especifica si este sonido es un sonido incorporado o no. Si este atributo se establece en true, la aplicación generadora se alerta para comprobar el atributo name especificado para este sonido en su lista de sonidos incorporados y luego puede presentar un nombre personalizado o una interfaz de usuario según sea necesario. Lee **bool**.

```cpp
virtual bool Aspose::Slides::ISlideShowTransition::get_SoundIsBuiltIn()=0
```
