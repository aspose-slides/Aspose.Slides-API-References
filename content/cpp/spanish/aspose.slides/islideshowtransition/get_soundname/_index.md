## ISlideShowTransition::get_SoundName() método

Especifica un nombre legible por humanos para el sonido de la transición. El [ISlideShowTransition::set_Sound](../set_sound/) debe asignarse para obtener o establecer el nombre del sonido. Lee [System::String](../../../system/string/).

```cpp
virtual System::String Aspose::Slides::ISlideShowTransition::get_SoundName()=0
```

## Observaciones

Este nombre aparece en la interfaz de usuario de PowerPoint al configurar el sonido de la transición manualmente.
