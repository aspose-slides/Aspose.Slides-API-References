## ISlideShowTransition::get_AdvanceAfterTime() método

Especifica el tiempo, en milisegundos, después del cual debe iniciarse la transición. Esta configuración puede usarse junto con el atributo advClick. Si este atributo no se especifica, se asume que no habrá avance automático. Lee **uint32_t**.

```cpp
virtual uint32_t Aspose::Slides::ISlideShowTransition::get_AdvanceAfterTime()=0
```
