## ISlideShowTransition::set_AdvanceAfterTime(uint32_t) method

Especifica el tiempo, en milisegundos, después del cual debe iniciarse la transición. Esta configuración puede usarse junto con el atributo advClick. Si este atributo no se especifica, se asume que no se producirá un avance automático. Escribe **uint32_t**.

virtual void Aspose::Slides::ISlideShowTransition::set_AdvanceAfterTime(uint32_t value)=0
