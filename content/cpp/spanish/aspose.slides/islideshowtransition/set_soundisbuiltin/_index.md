## ISlideShowTransition::set_SoundIsBuiltIn(bool) método

Especifica si este sonido es un sonido incorporado o no. Si este atributo se establece en true, la aplicación generadora se alerta para comprobar el atributo name especificado para este sonido en su lista de sonidos incorporados y puede entonces presentar un nombre personalizado o una interfaz de usuario según sea necesario. Escribe **bool**.

virtual void Aspose::Slides::ISlideShowTransition::set_SoundIsBuiltIn(bool value)=0
