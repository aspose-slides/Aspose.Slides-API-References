## Tab::CompareTo(System::SharedPtr\<ITab\>) método


Compara la instancia actual con otro objeto del mismo tipo.

```cpp
int32_t Aspose::Slides::Tab::CompareTo(System::SharedPtr<ITab> obj) override
```


### Arguments

| Parameter | Type | Description |
| --- | --- | --- |
| obj | [System::SharedPtr](../../../system/sharedptr/)\<[ITab](../../itab/)\> | Un objeto para comparar con esta instancia. |

### Return Value

Un entero de 32 bits que indica el orden relativo de los comparandos. El valor de retorno tiene los siguientes significados:
* < 0 - Esta instancia es menor que obj.
* = 0 - Esta instancia es igual a obj.
* > 0 - Esta instancia es mayor que obj.
