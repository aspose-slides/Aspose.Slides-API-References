## ILightRigEffectiveData::GetRotation() método


Una rotación se define mediante el uso de una coordenada de latitud, una coordenada de longitud y una revolución alrededor del eje según las coordenadas de latitud y longitud. El primer elemento del arreglo devuelto es la latitud, el segundo es la longitud y el tercero es la revolución.

```cpp
virtual System::ArrayPtr<float> Aspose::Slides::ILightRigEffectiveData::GetRotation()=0
```


### Valor de retorno

Coordenadas de rotación como **float**[]
