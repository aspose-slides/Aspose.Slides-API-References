## BlackWhiteMode enum

Determina cómo se debe transformar una forma coloreada a blanco y negro.

```cpp
enum class BlackWhiteMode : int8_t
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| NotDefined | -1 | La propiedad no está establecida |
| Color | 0 | El objeto se renderiza con coloración normal |
| Automatic | 1 | El objeto se renderiza con coloración automática |
| Gray | 2 | El objeto se renderiza con coloración gris |
| LightGray | 3 | El objeto se renderiza con coloración gris claro |
| InverseGray | 4 | El objeto se renderiza con coloración gris inverso |
| GrayWhite | 5 | El objeto se renderiza con coloración gris y blanco |
| BlackGray | 6 | El objeto se renderiza con coloración negra y gris |
| BlackWhite | 7 | El objeto se renderiza con coloración negra y blanca |
| Black | 8 | El objeto se renderiza solo con coloración negra |
| White | 9 | El objeto se renderiza con coloración blanca |
| Hidden | 10 | El objeto no se renderiza |
