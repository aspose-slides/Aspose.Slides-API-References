## SensitivityLabelAssignmentType enum

Representa el método de asignación para la etiqueta de sensibilidad.

```cpp
enum class SensitivityLabelAssignmentType
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Standard | 0 | Uso para cualquier etiqueta de sensibilidad que no haya sido aplicada directamente por el usuario. Esto incluye cualquier etiqueta predeterminada, etiquetas aplicadas automáticamente. |
| Privileged | 1 | Uso para cualquier etiqueta de sensibilidad que haya sido aplicada directamente por el usuario. Esto incluye cualquier etiqueta de sensibilidad aplicada manualmente, así como el etiquetado recomendado u obligatorio o cualquier función donde el usuario decide qué etiqueta de sensibilidad aplicar. |
