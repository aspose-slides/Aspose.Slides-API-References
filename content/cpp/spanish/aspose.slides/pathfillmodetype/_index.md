## PathFillModeType enumeración


Especifica la forma en que una ruta debe rellenarse

```cpp
enum class PathFillModeType : uint8_t
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| None | 0 | Sin relleno de ruta Esto especifica que la ruta correspondiente no debe tener relleno. |
| Normal | 1 | Relleno de ruta normal Esto especifica que la ruta correspondiente debe tener un color sombreado de forma normal aplicado a su relleno. |
| Lighten | 2 | Aclarar relleno de ruta Esto especifica que la ruta correspondiente debe tener un color ligeramente sombreado aplicado a su relleno. |
| LightenLess | 3 | Aclarado menos del relleno de ruta Esto especifica que la ruta correspondiente debe tener un color ligeramente más claro aplicado a su relleno. |
| Darken | 4 | Relleno de ruta oscurecido Esto especifica que la ruta correspondiente debe tener un color más oscuro aplicado a su relleno. |
| DarkenLess | 5 | Relleno de ruta ligeramente oscurecido Esto especifica que la ruta correspondiente debe tener un color un poco más oscuro aplicado a su relleno. |
