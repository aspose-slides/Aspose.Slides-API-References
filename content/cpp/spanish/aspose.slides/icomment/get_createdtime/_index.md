## IComment::get_CreatedTime() método

Devuelve la hora de creación de un comentario. Establecer esta propiedad a [DateTime::MinValue](../../../system/datetime/minvalue/) significa que no se ha establecido la hora del comentario. Lea [System::DateTime](../../../system/datetime/).

```cpp
virtual System::DateTime Aspose::Slides::IComment::get_CreatedTime()=0
```
