## IComment::set_CreatedTime(System::DateTime) method

Establece el tiempo de creación de un comentario. Establecer esta propiedad a [DateTime::MinValue](../../../system/datetime/minvalue/) significa que no se ha establecido un tiempo de comentario. Escriba [System::DateTime](../../../system/datetime/).

virtual void Aspose::Slides::IComment::set_CreatedTime(System::DateTime value)=0
