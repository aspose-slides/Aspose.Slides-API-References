## LightRig::GetRotation() método


Una rotación se define mediante el uso de una coordenada de latitud, una coordenada de longitud y una revolución alrededor del eje según las coordenadas de latitud y longitud. primer elemento en la matriz devuelta - latitud, segundo - longitud, tercero - revolución. Devuelve null si no se define ninguna rotación.
