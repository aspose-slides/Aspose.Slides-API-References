## TextFrameFormat::set_ColumnSpacing(double) método

Establece el espacio entre columnas de texto en el área de texto (en puntos). Esto solo debe aplicarse cuando hay más de 1 columna presente. Este valor debe ser un número positivo. De lo contrario, el valor se establecerá a cero. Escriba **double**.

void Aspose::Slides::TextFrameFormat::set_ColumnSpacing(double value) override
