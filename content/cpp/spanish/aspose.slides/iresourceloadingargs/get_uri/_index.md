## IResourceLoadingArgs::get_Uri() método


URI del recurso que se utiliza para la descarga si [IResourceLoadingCallback::ResourceLoading()](../../iresourceloadingcallback/resourceloading/) devuelve [ResourceLoadingAction::Default](../../resourceloadingaction/). Inicialmente está establecido en el URI original del recurso, pero puede redefinirse a cualquier valor.
