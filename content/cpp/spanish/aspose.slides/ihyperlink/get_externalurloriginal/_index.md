## IHyperlink::get_ExternalUrlOriginal() método


Representa un hipervínculo que se establece para esta porción sin tener en cuenta el contenido real de la porción.

```cpp
virtual System::String Aspose::Slides::IHyperlink::get_ExternalUrlOriginal()=0
```

## Observaciones


PowerPoint se comporta de manera específica con los enlaces y su texto correspondiente en una porción. Permite crear texto para el hipervínculo en forma de una URL válida, diferente de la dirección real del enlace. En este caso, cuando se visualiza el enlace en la ventana de edición, se cambiará para que coincida con la porción de texto. Esta propiedad representa el valor original del hipervínculo.
