## INormalViewProperties::set_PreferSingleView(bool) método

Especifica si el usuario prefiere ver una región de contenido único a pantalla completa en lugar de la vista normal estándar con tres regiones de contenido. Si está habilitado, la aplicación puede elegir mostrar una de las regiones de contenido en toda la ventana. Escriba **bool**.

virtual void Aspose::Slides::INormalViewProperties::set_PreferSingleView(bool value)=0
