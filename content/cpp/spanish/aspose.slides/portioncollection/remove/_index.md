## PortionCollection::Remove(System::SharedPtr\<IPortion\>) método

```cpp
bool Aspose::Slides::PortionCollection::Remove(System::SharedPtr<IPortion> item) override
```


### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| item | [System::SharedPtr](../../../system/sharedptr/)\<[IPortion](../../iportion/)\> | El objeto a eliminar del [ICollection](../../../system.collections.generic/icollection/). |

### Valor de retorno

true si *item* se eliminó correctamente del [ICollection](../../../system.collections.generic/icollection/); de lo contrario, false. Este método también devuelve false si *item* no se encuentra en el [ICollection](../../../system.collections.generic/icollection/) original.
