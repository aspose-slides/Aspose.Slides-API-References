## SensitivityLabelContentType enumeración

Representa los tipos de marcado de contenido que deben aplicarse a un documento.

```cpp
enum class SensitivityLabelContentType
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| None | 0 | Implica que la etiqueta se aplique por defecto o automáticamente. |
| Header | 1 | Implica que la etiqueta se aplicó manualmente. Úsela para cualquier etiqueta de sensibilidad que haya sido aplicada directamente por el usuario. |
| Footer | 2 | Implica que la etiqueta se aplicó manualmente. Úsela para cualquier etiqueta de sensibilidad que haya sido aplicada directamente por el usuario. |
| Watermark | 4 | Implica que la etiqueta se aplicó manualmente. Úsela para cualquier etiqueta de sensibilidad que haya sido aplicada directamente por el usuario. |
