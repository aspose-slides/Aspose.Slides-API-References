## IDocumentProperties::set_ScaleCrop(bool) método

Indica el modo de visualización de la miniatura del documento. Establezca este elemento en **true** para habilitar el escalado de la miniatura del documento a la pantalla. Establezca este elemento en **false** para habilitar el recorte de la miniatura del documento y mostrar solo las secciones que se ajusten a la pantalla. Escriba **bool**.

virtual void Aspose::Slides::IDocumentProperties::set_ScaleCrop(bool value)=0
