## IDocumentProperties::set_LinksUpToDate(bool) método


Indica si los hipervínculos en un documento están actualizados. Establezca este elemento a **true** para indicar que los hipervínculos están actualizados. Establezca este elemento a **false** para indicar que los hipervínculos están desactualizados. Escriba **bool**.

virtual void Aspose::Slides::IDocumentProperties::set_LinksUpToDate(bool value)=0
