## IDocumentProperties::get_LinksUpToDate() método

Indica si los hipervínculos en un documento están actualizados. Establezca este elemento en **true** para indicar que los hipervínculos están actualizados. Establezca este elemento en **false** para indicar que los hipervínculos están desactualizados. Leer **bool**.

```cpp
virtual bool Aspose::Slides::IDocumentProperties::get_LinksUpToDate()=0
```
