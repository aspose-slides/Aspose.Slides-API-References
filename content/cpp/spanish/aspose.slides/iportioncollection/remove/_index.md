## IPortionCollection::Remove(System::SharedPtr\<IPortion\>) método

Elimina la primera aparición de un objeto específico del [ICollection](../../../system.collections.generic/icollection/).

```cpp
virtual bool Aspense::Slides::IPortionCollection::Remove(System::SharedPtr<IPortion> item)=0
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| item | [System::SharedPtr](../../../system/sharedptr/)\<[IPortion](../../iportion/)\> | El objeto que se eliminará del [ICollection](../../../system.collections.generic/icollection/). |

### Valor devuelto

true si *item* se eliminó correctamente del [ICollection](../../../system.collections.generic/icollection/); de lo contrario, false. Este método también devuelve false si *item* no se encuentra en el [ICollection](../../../system.collections.generic/icollection/) original.
