## DocumentProperties::set_ScaleCrop(bool) método

Indica el modo de visualización de la miniatura del documento. Establezca este elemento en **true** para habilitar el escalado de la miniatura del documento a la pantalla. Establezca este elemento en **false** para habilitar el recorte de la miniatura del documento y mostrar solo las secciones que se ajustan a la pantalla. Escriba **bool**.

void Aspose::Slides::DocumentProperties::set_ScaleCrop(bool value) override
