## DocumentProperties::set_LinksUpToDate(bool) método

Indica si los hipervínculos en un documento están actualizados. Establezca este elemento en **true** para indicar que los hipervínculos están actualizados. Establezca este elemento en **false** para indicar que los hipervínculos están desactualizados. Escriba **bool**.
