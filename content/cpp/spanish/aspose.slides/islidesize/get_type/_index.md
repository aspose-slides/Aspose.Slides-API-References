## ISlideSize::get_Type() método

Obtiene el tipo de tamaño de diapositiva. Asignar cualquier valor excepto [SlideSizeType::Custom](../../slidesizetype/) ajusta el [ISlideSize::get_Size](../get_size/) de acuerdo con las dimensiones predefinidas, mientras se conserva el [ISlideSize::get_Orientation](../get_orientation/) actual.

```cpp
virtual SlideSizeType Aspose::Slides::ISlideSize::get_Type()=0
```

## Observaciones

Asignar cualquier valor distinto de [SlideSizeType::Custom](../../slidesizetype/) ajusta el [System::Drawing::Size](../../../system.drawing/size/) de acuerdo con las dimensiones predefinidas, mientras se conserva el [Orientation](../../orientation/) actual.
