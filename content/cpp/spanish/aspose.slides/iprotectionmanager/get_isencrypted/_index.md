## IProtectionManager::get_IsEncrypted() método


Obtiene un valor que indica si esta instancia está cifrada. Solo lectura **bool**.

```cpp
virtual bool Aspose::Slides::IProtectionManager::get_IsEncrypted()=0
```

## Observaciones


**true** si la presentación se cargó desde un archivo cifrado o el método [Encrypt(String)](../encrypt/) fue llamado; de lo contrario, **false**.
