## IProtectionManager::set_EncryptDocumentProperties(bool) método

Esta propiedad tiene sentido si la presentación está protegida con contraseña. Si true entonces las propiedades del documento se cifran en el archivo de la presentación. Si false entonces las propiedades del documento son públicas mientras la presentación está cifrada. Escribe **bool**.
