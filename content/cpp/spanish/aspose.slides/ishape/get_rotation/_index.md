## IShape::get_Rotation() método


Devuelve el número de grados que la forma especificada está rotada alrededor del eje z. Un valor positivo indica rotación en sentido horario; un valor negativo indica rotación en sentido antihorario. Lectura **float**.

```cpp
virtual float Aspose::Slides::IShape::get_Rotation()=0
```

## Observaciones


El valor devuelto siempre está definido (no es std::numeric_limits<float>::quiet_NaN()). El valor asignado debe estar definido (no es std::numeric_limits<float>::quiet_NaN()). Puede establecer valores indefinidos para las propiedades de instancia de RawFrame.
