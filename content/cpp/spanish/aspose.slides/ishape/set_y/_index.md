## Observaciones


El valor devuelto siempre está definido y nunca [std::numeric_limits<float>::quiet_NaN()](../). El valor asignado también debe estar definido; asigne [std::numeric_limits<float>::quiet_NaN()](../) solo a propiedades de una instancia de **RawFrame**.
