## TextAutofitType enum

Representa el modo de ajuste automático de texto.

```cpp
enum class TextAutofitType : int8_t
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| NotDefined | -1 | No definido. |
| None | 0 | Sin ajuste automático. |
| Normal | 1 | Ajuste automático normal. El tamaño de fuente y el espaciado de línea se reducirán para ajustar la forma. |
| Shape | 2 | [Shape](../shape/) ajuste automático. El tamaño de [Shape](../shape/) se cambiará para ajustar el texto. |
