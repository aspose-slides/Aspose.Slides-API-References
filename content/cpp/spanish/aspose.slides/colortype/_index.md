## ColorType enum

Representa diferentes modos de color.

```cpp
enum class ColorType
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| NotDefined | -1 | El color no está definido en absoluto. |
| RGB | 0 | Color RGB estándar de 24 bits. |
| RGBPercentage | 1 | Color RGB de alta definición. |
| HSL | 2 | Color HSL de alta definición. |
| Scheme | 3 | Color de esquema. |
| System | 4 | [System](../../system/) color. |
| Preset | 5 | Color preestablecido. |
