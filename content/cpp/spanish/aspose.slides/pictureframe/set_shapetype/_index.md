## PictureFrame::set_ShapeType(Aspose::Slides::ShapeType) método




```cpp
void Aspose::Slides::PictureFrame::set_ShapeType(Aspose::Slides::ShapeType value) override
```

## Observaciones


Establece el tipo [AutoShape](../../autoshape/) para un [PictureFrame](../). Hay permitidos todos los elementos del conjunto [Slides::ShapeType](../../shapetype/), excepto todos los tipos de líneas:

[ShapeType::Line](../../shapetype/),

[ShapeType::StraightConnector1](../../shapetype/),

[ShapeType::BentConnector2](../../shapetype/),

[ShapeType::BentConnector3](../../shapetype/),

[ShapeType::BentConnector4](../../shapetype/),

[ShapeType::BentConnector5](../../shapetype/),

[ShapeType::CurvedConnector2](../../shapetype/),

[ShapeType::CurvedConnector3](../../shapetype/),

[ShapeType::CurvedConnector4](../../shapetype/),

[ShapeType::CurvedConnector5](../../shapetype/).

Escriba [Slides::ShapeType](../../shapetype/).
