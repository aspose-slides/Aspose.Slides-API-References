## FILETIME estructura

Contiene los componentes de tiempo de archivo. Este tipo debe asignarse en la pila y pasarse a funciones por valor o por referencia. Nunca use la clase [System::SmartPtr](../../system/smartptr/) para gestionar objetos de este tipo.

```cpp
class FILETIME
```
