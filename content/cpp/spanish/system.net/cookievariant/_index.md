## enumeración CookieVariant

Enumera las especificaciones de cookies.

```cpp
enum class CookieVariant
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Unknown | 0 | La especificación de cookie desconocida. |
| Plain | 1 | La especificación de cookie simple. |
| Rfc2109 | 2 | La especificación de cookie 'RFC 2109'. |
| Rfc2965 | 3 | La especificación de cookie 'RFC 2965'. |
| Default | 2 | El valor predeterminado igual a 'Rfc2109'. |
