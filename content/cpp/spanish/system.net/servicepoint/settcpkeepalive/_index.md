## ServicePoint::SetTcpKeepAlive(bool, int32_t, int32_t) método

Establece el valor que indica si la opción 'Keep-Alive' está habilitada.

```cpp
void System::Net::ServicePoint::SetTcpKeepAlive(bool enabled, int32_t keepAliveTime, int32_t keepAliveInterval)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| enabled | **bool** | Un valor que indica si la opción 'Keep-Alive' está habilitada. |
| keepAliveTime | **int32_t** | Un tiempo de espera en milisegundos después del cual se enviará el primer paquete 'Keep-Alive'. |
| keepAliveInterval | **int32_t** | Un tiempo de espera en milisegundos entre el envío de paquetes 'Keep-Alive'. |
