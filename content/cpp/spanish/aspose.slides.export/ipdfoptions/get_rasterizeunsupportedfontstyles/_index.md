## IPdfOptions::get_RasterizeUnsupportedFontStyles() método


Indica si el texto debe rasterizarse como un mapa de bits y guardarse en PDF cuando la fuente no admite estilo en negrita. Este enfoque puede mejorar la calidad del texto en el PDF resultante para ciertas fuentes. Lee **bool**.

```cpp
virtual bool Aspose::Slides::Export::IPdfOptions::get_RasterizeUnsupportedFontStyles()=0
```

## Observaciones


El valor predeterminado es **false**.
