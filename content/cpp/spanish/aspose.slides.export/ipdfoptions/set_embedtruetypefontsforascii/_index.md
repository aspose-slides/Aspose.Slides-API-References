## IPdfOptions::set_EmbedTrueTypeFontsForASCII(bool) método

True para incrustar fuentes TrueType para los caracteres ASCII 32-127. [Fonts](../../../aspose.slides/fonts/) para los códigos de carácter mayores de 127 siempre se incrustan. Escriba **bool**.

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_EmbedTrueTypeFontsForASCII(bool value)=0
```

## Observaciones

El valor predeterminado es **true**.
