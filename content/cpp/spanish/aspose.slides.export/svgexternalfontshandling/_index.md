## SvgExternalFontsHandling enum

Representa una forma de manejar fuentes externas utilizadas para el dibujo de texto.

```cpp
enum class SvgExternalFontsHandling
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| AddLinksToFontFiles | 0 | Añade enlaces a archivos de fuentes separados a la sección de estilo del archivo SVG. |
| Embed | 1 | Guarda los datos de fuentes directamente en el archivo SVG. Por favor, revise todos los acuerdos de licencia de fuentes externas antes de usar esta opción. |
| Vectorize | 2 | Guarda todo el texto que utiliza fuentes externas como gráficos. |
