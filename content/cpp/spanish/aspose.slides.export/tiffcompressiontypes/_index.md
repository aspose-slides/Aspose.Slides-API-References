## TiffCompressionTypes enum

Proporciona opciones que controlan cómo se comprime una presentación en formato TIFF.

```cpp
enum class TiffCompressionTypes
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Default | 0 | Especifica el esquema de compresión predeterminado (LZW). |
| None | 1 | Especifica que no hay compresión. |
| CCITT3 | 2 | Especifica el esquema de compresión CCITT3. |
| CCITT4 | 3 | Especifica el esquema de compresión CCITT4. |
| LZW | 4 | Especifica el esquema de compresión LZW (Default). |
| RLE | 5 | Especifica el esquema de compresión RLE. |
