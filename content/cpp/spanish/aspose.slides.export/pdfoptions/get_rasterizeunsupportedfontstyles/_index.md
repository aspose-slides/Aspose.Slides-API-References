## PdfOptions::get_RasterizeUnsupportedFontStyles() método

Indica si el texto debe rasterizarse como un mapa de bits y guardarse en PDF cuando la fuente no admite estilo negrita. Este enfoque puede mejorar la calidad del texto en el PDF resultante para ciertas fuentes. Lee **bool**.

```cpp
bool Aspose::Slides::Export::PdfOptions::get_RasterizeUnsupportedFontStyles() override
```

## Comentarios

El valor predeterminado es **false**.
