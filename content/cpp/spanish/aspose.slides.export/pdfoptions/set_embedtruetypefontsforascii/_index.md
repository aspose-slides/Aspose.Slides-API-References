## PdfOptions::set_EmbedTrueTypeFontsForASCII(bool) method


Determina si [Aspose.Slides](../../../aspose.slides/) incorporará fuentes comunes para texto ASCII (rango de códigos 33..127). [Fonts](../../../aspose.slides/fonts/) para códigos de caracteres mayores a 127 siempre se incrustan. La lista de fuentes comunes incluye las 14 fuentes base de PDF y fuentes adicionales especificadas por el usuario. Escribe **bool**.

```cpp
void Aspose::Slides::Export::PdfOptions::set_EmbedTrueTypeFontsForASCII(bool value) override
```

## Observaciones


El valor predeterminado es **true**.
