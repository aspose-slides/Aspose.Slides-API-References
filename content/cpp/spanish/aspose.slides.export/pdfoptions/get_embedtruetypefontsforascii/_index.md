## PdfOptions::get_EmbedTrueTypeFontsForASCII() método


Determina si [Aspose.Slides](../../../aspose.slides/) incluirá fuentes comunes para texto ASCII (rango de códigos 33..127). [Fonts](../../../aspose.slides/fonts/) para códigos de carácter mayores de 127 siempre se incorporan. La lista de fuentes comunes incluye las 14 fuentes base de PDF y fuentes adicionales especificadas por el usuario. Lectura **bool**.

```cpp
bool Aspose::Slides::Export::PdfOptions::get_EmbedTrueTypeFontsForASCII() override
```

## Observaciones


El valor predeterminado es **true**.
