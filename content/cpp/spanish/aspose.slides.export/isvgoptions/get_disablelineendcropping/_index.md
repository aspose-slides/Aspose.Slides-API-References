## ISVGOptions::get_DisableLineEndCropping() método

SVG 1.1 carece de capacidad para definir inserciones para marcadores. [Aspose.Slides](../../../aspose.slides/) El motor de escritura SVG tiene una solución alternativa para ese problema: recorta el extremo de la línea con la flecha, de modo que la línea no se superponga a los marcadores. Esta opción desactiva dicho comportamiento. Leer **bool**.

```cpp
virtual bool Aspose::Slides::Export::ISVGOptions::get_DisableLineEndCropping()=0
```
