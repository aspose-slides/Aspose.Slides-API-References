## ISVGOptions::set_DisableLineEndCropping(bool) método


SVG 1.1 carece de la capacidad de definir inserciones para los marcadores. [Aspose.Slides](../../../aspose.slides/) El motor de escritura SVG tiene una solución alternativa para ese problema: recorta el extremo de la línea con la flecha, de modo que la línea no se superponga a los marcadores. Esta opción desactiva ese comportamiento. Escriba **bool**.

```cpp
virtual void Aspose::Slides::Export::ISVGOptions::set_DisableLineEndCropping(bool value)=0
```
