## ISVGOptions::set_DeletePicturesCroppedAreas(bool) método

Una bandera booleana indica si las partes recortadas permanecen como parte del documento. Si true, las partes recortadas se eliminarán, si false se serializarán en el documento (lo que puede posible conducir a un archivo más grande). Escriba **bool**.
