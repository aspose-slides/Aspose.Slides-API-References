## NotesCommentsLayoutingOptions::set_ShowCommentsByNoAuthor(bool) método

Establece la visibilidad de los comentarios que no tienen autor. Si es true entonces los comentarios se mostrarán. (Se aplica solo si los comentarios se muestran).

```cpp
void Aspose::Slides::Export::NotesCommentsLayoutingOptions::set_ShowCommentsByNoAuthor(bool value)
```

## Observaciones

El valor predeterminado es **false**.
