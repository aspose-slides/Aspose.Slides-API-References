## TextInheritanceLimit enumeración

Controla la profundidad de la herencia de las propiedades de texto.

```cpp
enum class TextInheritanceLimit
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| All | 0 | Hereda todas las propiedades de texto. |
| TextBox | 1 | Hereda solo del estilo de [TextFrame](../../aspose.slides/textframe/). |
| ParagraphOnly | 2 | Utiliza solo las propiedades definidas para el párrafo. |
