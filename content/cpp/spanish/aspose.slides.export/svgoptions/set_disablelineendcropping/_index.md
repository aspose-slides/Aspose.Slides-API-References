## SVGOptions::set_DisableLineEndCropping(bool) método


SVG 1.1 carece de la capacidad de definir inserciones para los marcadores. [Aspose.Slides](../../../aspose.slides/) El motor de escritura SVG tiene una solución alternativa para ese problema: recorta el extremo de la línea con la flecha, por lo que la línea no se superpone a los marcadores. Esta opción desactiva dicho comportamiento. Escriba **bool**.

```cpp
void Aspose::Slides::Export::SVGOptions::set_DisableLineEndCropping(bool value) override
```
