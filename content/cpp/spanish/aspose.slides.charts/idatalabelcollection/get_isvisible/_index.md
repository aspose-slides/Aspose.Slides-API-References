## IDataLabelCollection::get_IsVisible() método


False significa que la etiqueta de datos no es visible por defecto (y, por lo tanto, todos los indicadores Show*-flags (ShowValue, ...) de la propiedad DefaultDataLabelFormat son false). Solo lectura **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelCollection::get_IsVisible()=0
```

## Comentarios


Si la etiqueta de datos es visible por defecto puedes ocultarla por defecto con el método [Hide()](../hide/). Pero si la etiqueta de datos no es visible por defecto (IsVisible es false) puedes hacer que la etiqueta de datos \"visible 
por defecto\" configurando los indicadores Show*-flags (ShowValue, ...) de la propiedad DefaultDataLabelFormat a estado true.
