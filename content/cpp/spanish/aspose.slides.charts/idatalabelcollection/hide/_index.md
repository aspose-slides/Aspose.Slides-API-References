## IDataLabelCollection::Hide() método

Ocultar la etiqueta de datos por defecto estableciendo todas las banderas Show*-flags (ShowValue, ...) de la propiedad DefaultDataLabelFormat a estado falso. IsVisible será false después de esto.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelCollection::Hide()=0
```

## Observaciones

Si la etiqueta de datos no es visible por defecto (IsVisible es false) puedes hacer que la etiqueta de datos "visible por defecto" configurando las banderas Show*-flags (ShowValue, ...) de la propiedad DefaultDataLabelFormat a estado verdadero.
