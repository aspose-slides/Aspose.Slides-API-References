## BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType) método

Especifica si la propiedad AsCell, AsCells, AsLiteralString o AsLiteralDouble está activa en los descendientes. En otras palabras, especifica el tipo de valor de la propiedad Data. Escriba [Charts::DataSourceType](../../datasourcetype/).

```cpp
void Aspose::Slides::Charts::BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType value) override
```

## Observaciones

Para los puntos en [ChartDataPointCollection](../../chartdatapointcollection/) esta propiedad es de solo lectura. En este caso, para cambiar el valor de esta propiedad puede usar una de las propiedades ChartDataPointCollection.DataSourceTypeFor<...>.
