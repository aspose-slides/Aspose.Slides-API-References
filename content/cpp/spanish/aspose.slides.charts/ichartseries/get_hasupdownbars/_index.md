## IChartSeries::get_HasUpDownBars() método


Determina si un gráfico de línea o de acciones tiene barras arriba/abajo. Esta es la propiedad no solo de esta serie sino de todas las series del grupo de series principal, es la proyección de la propiedad correspondiente del grupo. Por lo tanto, esta propiedad es solo lectura. Utilice la propiedad ParentSeriesGroup para acceder al grupo de series principal. Utilice [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get_UpDownBars()->get(set)_HasUpDownBars() propiedad de lectura/escritura para cambiar el valor. Utilice la propiedad [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get_UpDownBars() para formatear las barras arriba/abajo. Solo lectura **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IChartSeries::get_HasUpDownBars()=0
```

## Observaciones


Esta es la proyección de la propiedad [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get_UpDownBars()->get(set)_HasUpDownBars().
