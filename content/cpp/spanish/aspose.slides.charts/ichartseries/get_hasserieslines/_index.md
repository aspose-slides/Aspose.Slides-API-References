## IChartSeries::get_HasSeriesLines() método

Determina si existen líneas de serie para esta serie y series afines. Esta es la propiedad no solo de esta serie sino de todas las series del grupo de series principal,- es la proyección de la propiedad de grupo correspondiente. Por lo tanto, esta propiedad es de solo lectura. Utilice la propiedad ParentSeriesGroup para acceder al grupo de series principal. Utilice [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_HasSeriesLines() como propiedad de lectura/escritura para cambiar el valor. Utilice la propiedad ParentSeriesGroup.SeriesLinesFormat para formatear las líneas de serie. Solo lectura **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IChartSeries::get_HasSeriesLines()=0
```
