## IChartSeries::get_PieSplitPosition() método


Especifica un valor que se debe usar para determinar qué puntos de datos están en el segundo pastel o barra en un gráfico de pie-of-pie o bar-of-pie. Se usa junto con la propiedad PieSplitBy. Esta es la propiedad no solo de esta serie, sino de todas las series del grupo de series padre, - es una proyección de la propiedad de grupo correspondiente. Por lo tanto, esta propiedad es de solo lectura. Utilice la propiedad ParentSeriesGroup para acceder al grupo de series padre. Utilice [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_PieSplitPosition() propiedad de lectura/escritura para cambiar el valor. Solo lectura **double**.

```cpp
virtual double Aspose::Slides::Charts::IChartSeries::get_PieSplitPosition()=0
```

## Observaciones


Esta es la proyección de la propiedad [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_PieSplitPosition().
