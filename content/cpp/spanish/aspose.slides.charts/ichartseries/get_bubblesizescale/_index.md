## IChartSeries::get_BubbleSizeScale() método


Especifica el factor de escala para el gráfico de burbujas (puede estar entre 0 y 300 por ciento del tamaño predeterminado). Esta es la propiedad no solo de esta serie sino de todas las series del grupo de series padre - es la proyección de la propiedad de grupo correspondiente. Por lo tanto, esta propiedad es de solo lectura. Use la propiedad ParentSeriesGroup para acceder al grupo de series padre. Use [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_BubbleSizeScale() propiedad de lectura/escritura para cambiar el valor.

```cpp
virtual int32_t Aspose::Slides::Charts::IChartSeries::get_BubbleSizeScale()=0
```

## Observaciones


Esta es la proyección de la propiedad [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_BubbleSizeScale().
