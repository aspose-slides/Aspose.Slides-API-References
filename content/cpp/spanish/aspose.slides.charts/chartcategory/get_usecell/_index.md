## ChartCategory::get_UseCell() método


Si es verdadero, la propiedad AsCell es la actual. En otras palabras, la hoja de cálculo se usa para almacenar la categoría (este caso admite una categoría de varios niveles). Si es falso, la propiedad AsLiteral es la actual. En otras palabras, la hoja de cálculo NO se usa para almacenar la categoría (y este caso no admite categorías de varios niveles). Solo lectura **bool**.

```cpp
bool Aspose::Slides::Charts::ChartCategory::get_UseCell() override
```

## Observaciones


Para cambiar el valor de esta propiedad (para todas las categorías en la colección) establezca el nuevo valor en la propiedad ChartCategoryCollection::get(set)_UseCells.
