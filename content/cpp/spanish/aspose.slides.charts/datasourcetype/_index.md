## DataSourceType enumeración

Tipos de origen de datos.

```cpp
enum class DataSourceType
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Worksheet | 0 | Utilice objetos CellXls para almacenar XValue, YValue, Value o BubbleSize del punto de datos en la hoja de cálculo. |
| StringLiterals | 1 | Utilice una variable de cadena de acceso rápido para almacenar XValue, YValue, Value o BubbleSize del punto de datos. Worksheet NO se utiliza para almacenar valores. |
| DoubleLiterals | 2 | Utilice una variable double de acceso rápido para almacenar XValue, YValue, Value o BubbleSize del punto de datos. Worksheet NO se utiliza para almacenar valores. |
