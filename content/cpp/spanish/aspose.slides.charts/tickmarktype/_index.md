## Enumeración TickMarkType

Representa el tipo de marca de graduación para el eje especificado.

```cpp
enum class TickMarkType
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Cross | 0 | Especifica que las marcas de graduación cruzarán el eje. |
| Inside | 1 | Especifica que las marcas de graduación estarán dentro del área del gráfico. |
| None | 2 | Especifica que no habrá marcas de graduación. |
| Outside | 3 | Especifica que las marcas de graduación estarán fuera del área del gráfico. |
