## ChartCategoryCollection::set_UseCells(bool) método


Si true entonces la hoja de cálculo se usa para almacenar categorías (este caso admite categorías multinivel). Si false entonces la hoja de cálculo NO se usa para almacenar valores (y este caso no admite categorías multinivel). Escriba **bool**.
