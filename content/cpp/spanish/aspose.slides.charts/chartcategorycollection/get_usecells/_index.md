## ChartCategoryCollection::get_UseCells() método


Si es true entonces worksheet se usa para almacenar categorías (este caso admite categorías de varios niveles). Si es false entonces worksheet NO se usa para almacenar valores (y este caso no admite categorías de varios niveles). Leer **bool**.
