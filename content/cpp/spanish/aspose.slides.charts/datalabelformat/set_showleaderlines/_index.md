## DataLabelFormat::set_ShowLeaderLines(bool) método


Representa el comportamiento de visualización de las líneas guía de la etiqueta de datos de un gráfico especificado. True muestra las líneas guía. False las oculta. Escriba **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLeaderLines(bool value) override
```

## Observaciones


Si el padre de este objeto [DataLabelFormat](../) es una colección [DataLabelCollection](../../datalabelcollection/) de etiquetas de datos, entonces esta propiedad obtiene o establece el valor predeterminado de la propiedad ShowLeaderLines para las nuevas etiquetas de datos en la colección [DataLabelCollection](../../datalabelcollection/). Establecer esta propiedad con un valor también asigna ese valor a la propiedad ShowLeaderLines de todas las etiquetas de datos en la colección [DataLabelCollection](../../datalabelcollection/) (p. ej., \"DataLabels.DefaultDataLabelFormat.ShowLeaderLines = val;\" hace que todas las DataLabels[i].ShowLeaderLines sean iguales a val).
