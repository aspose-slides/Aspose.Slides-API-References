## Observaciones

Si el padre de este objeto [DataLabelFormat](../../datalabelformat/) es una colección [DataLabelCollection](../../datalabelcollection/) de etiquetas de datos, entonces esta propiedad obtiene o establece el valor predeterminado de la propiedad IsNumberFormatLinkedToSource para las nuevas etiquetas de datos en la colección [DataLabelCollection](../../datalabelcollection/). Establecer esta propiedad con un valor también asigna ese valor a la propiedad IsNumberFormatLinkedToSource para todas las etiquetas de datos en la colección [DataLabelCollection](../../datalabelcollection/) (es decir, \"DataLabels.DefaultDataLabelFormat.IsNumberFormatLinkedToSource = val;\" causa que todos los DataLabels[i].IsNumberFormatLinkedToSource sean iguales a val).
