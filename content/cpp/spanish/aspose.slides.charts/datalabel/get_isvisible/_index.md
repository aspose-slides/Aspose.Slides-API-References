## DataLabel::get_IsVisible() método

False significa que la etiqueta de datos no es visible (y por lo tanto todas las banderas Show*-flags (ShowValue, ...) son false). Solo lectura **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabel::get_IsVisible() override
```

## Observaciones

Si la etiqueta de datos es visible puedes ocultarla con el método [Hide()](../hide/). Pero si la etiqueta de datos no es visible (IsVisible is false) puedes hacerla visible estableciendo las banderas Show*-flags (ShowValue, ...) en estado true.
