## PieSplitType enumeración

Representa un tipo de puntos de división en el segundo pastel o barra en un gráfico de pastel-sobre-pastel o barra-sobre-pastel.

```cpp
enum class PieSplitType
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Default | 0 | Especifica que los puntos de datos se dividirán utilizando el mecanismo predeterminado para este tipo de gráfico. |
| Custom | 1 | Especifica que los puntos de datos se dividirán entre el pastel y el segundo gráfico de acuerdo con los valores Custom Split. |
| ByPercentage | 2 | Especifica que los puntos de datos se dividirán entre el pastel y el segundo gráfico colocando los puntos con porcentaje inferior a Split Position percent en el segundo gráfico. |
| ByPos | 3 | Especifica que los puntos de datos se dividirán entre el pastel y el segundo gráfico colocando la última Split Position de los puntos de datos en el segundo gráfico. |
| ByValue | 4 | Especifica que los puntos de datos se dividirán entre el pastel y el segundo gráfico colocando los puntos de datos con valor inferior a Split Position en el segundo gráfico. |
