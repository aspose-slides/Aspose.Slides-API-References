## ParentLabelLayoutType enum


Representa el diseño de las etiquetas de datos de categoría. Se usa solo con series Treemap.

```cpp
enum class ParentLabelLayoutType
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Banner | 0 | Especifica que las etiquetas de categoría principal se muestran como banner |
| None | 1 | Especifica que las etiquetas de categoría principal no se dibujan |
| Overlapping | 2 | Especifica que las etiquetas de categoría principal se muestran superpuestas |
