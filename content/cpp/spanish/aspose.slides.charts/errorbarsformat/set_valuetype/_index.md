## ErrorBarsFormat::set_ValueType(ErrorBarValueType) method


Representa las posibles formas de determinar la longitud de las barras de error. En caso de tipo de valor personalizado para especificar el valor, use la propiedad [IChartDataPoint::get_ErrorBarsCustomValues()](../../ichartdatapoint/get_errorbarscustomvalues/) del punto de datos específico en la colección DataPoints de la serie. En caso de los tipos de valor Fixed, Percentage o StandardDeviation, use la propiedad Value para especificar el valor. 

Escriba [ErrorBarValueType](../../errorbarvaluetype/).
