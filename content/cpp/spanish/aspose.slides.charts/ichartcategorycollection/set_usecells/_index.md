## IChartCategoryCollection::set_UseCells(bool) método


Si es verdadero, la hoja de cálculo se utiliza para almacenar categorías (este caso admite categorías de varios niveles). Si es falso, la hoja de cálculo NO se utiliza para almacenar valores (y este caso no admite categorías de varios niveles). Escriba **bool**.

virtual void Aspose::Slides::Charts::IChartCategoryCollection::set_UseCells(bool value)=0
