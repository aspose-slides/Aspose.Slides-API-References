## IChartCategoryCollection::get_UseCells() método

Si es true entonces la hoja de cálculo se usa para almacenar categorías (este caso admite categorías de varios niveles). Si es false entonces la hoja de cálculo NO se usa para almacenar valores (y este caso no admite categorías de varios niveles). Leer **bool**.

virtual bool Aspose::Slides::Charts::IChartCategoryCollection::get_UseCells()=0
