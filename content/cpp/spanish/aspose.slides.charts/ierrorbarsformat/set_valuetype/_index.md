## IErrorBarsFormat::set_ValueType(ErrorBarValueType) método


Representa formas posibles de determinar la longitud de las barras de error. En caso de tipo de valor personalizado para especificar el valor, use la propiedad [IChartDataPoint::get_ErrorBarsCustomValues()](../../ichartdatapoint/get_errorbarscustomvalues/) del punto de datos específico en la colección DataPoints de la serie.
