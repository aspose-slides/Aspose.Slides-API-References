## ChartSeries::get_HasUpDownBars() método

Determina si el gráfico de líneas o de acciones tiene barras de subida/bajada. Esta es la propiedad no solo de esta serie sino de todas las series del grupo de series padre, es una proyección de la propiedad correspondiente del grupo. Por lo tanto, esta propiedad es de solo lectura. Utilice la propiedad ParentSeriesGroup para acceder al grupo de series padre. Utilice la propiedad de lectura/escritura [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get_UpDownBars()->get(set)_HasUpDownBars() para cambiar el valor. Utilice la propiedad [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get_UpDownBars() para dar formato a las barras de subida/bajada. Solo lectura **bool**.

```cpp
bool Aspose::Slides::Charts::ChartSeries::get_HasUpDownBars() override
```

## Observaciones
