## TrendlineType enum

Representa el tipo de línea de tendencia

```cpp
enum class TrendlineType
```

### Valores

| Name | Value | Description |
| --- | --- | --- |
| Exponential | 0 | Especifica que la línea de tendencia será una curva exponencial en la forma. |
| Linear | 1 | Especifica que la línea de tendencia será una línea en la forma. |
| Logarithmic | 2 | Especifica que la línea de tendencia será una curva logarítmica en la forma, donde log es el logaritmo natural. |
| MovingAverage | 3 | Especifica que la línea de tendencia será un promedio móvil del período Period. |
| Polynomial | 4 | Especifica que la línea de tendencia será una curva polinómica de orden Order en la forma. |
| Power | 5 | Especifica que la línea de tendencia será una curva de potencia en la forma. |
