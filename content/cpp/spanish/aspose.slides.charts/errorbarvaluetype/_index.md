## ErrorBarValueType enum

Representa el tipo de valor de barra de error

```cpp
enum class ErrorBarValueType
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Custom | 0 | Especifica que la longitud de las barras de error se determinará mediante los elementos Plus y Minus. |
| Fixed | 1 | Especifica que la longitud de las barras de error será el valor fijo determinado por Error Bar Value. |
| Percentage | 2 | Especifica que la longitud de las barras de error será el porcentaje Error Bar Value de los datos. |
| StandardDeviation | 3 | Especifica que la longitud de las barras de error será Error Bar Value desviaciones estándar de los datos. |
| StandardError | 4 | Especifica que la longitud de las barras de error será Error Bar Value errores estándar de los datos. |
