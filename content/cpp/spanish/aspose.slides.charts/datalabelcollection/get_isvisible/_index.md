## DataLabelCollection::get_IsVisible() método

False indica que la etiqueta de datos no es visible por defecto (y por lo tanto todas las banderas Show*-flags (ShowValue, ...) de la propiedad DefaultDataLabelFormat son falsas). Solo lectura **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelCollection::get_IsVisible() override
```

## Observaciones

Si la etiqueta de datos es visible por defecto, puedes ocultarla por defecto con el método [Hide()](../hide/). Pero si la etiqueta de datos no es visible por defecto (IsVisible es false) puedes hacer que la etiqueta de datos "visible por defecto" estableciendo las banderas Show*-flags (ShowValue, ...) de la propiedad DefaultDataLabelFormat en estado verdadero.
