## IDataLabel::Hide() método


Haga que la etiqueta de datos esté oculta estableciendo todas las banderas Show*-flags (ShowValue, ...) al estado false. IsVisible será false después de esto.

```cpp
virtual void Aspose::Slides::Charts::IDataLabel::Hide()=0
```

## Observaciones


Si la etiqueta de datos no es visible (IsVisible es false) puede hacer que la etiqueta de datos sea visible estableciendo las banderas Show*-flags (ShowValue, ...) al estado true.
