## ErrorBarType enum

Representa el tipo de barra de error

```cpp
enum class ErrorBarType
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Both | 0 | Especifica que las barras de error se muestren en las direcciones positiva y negativa. |
| Minus | 1 | Especifica que las barras de error se muestren solo en la dirección negativa. |
| Plus | 2 | Especifica que las barras de error se muestren solo en la dirección positiva. |
