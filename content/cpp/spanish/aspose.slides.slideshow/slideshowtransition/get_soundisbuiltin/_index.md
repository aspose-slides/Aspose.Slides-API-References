## SlideShowTransition::get_SoundIsBuiltIn() método


Especifica si este sonido es o no un sonido incorporado. Si este atributo se establece en true, la aplicación generadora se alerta para comprobar el atributo name especificado para este sonido en su lista de sonidos incorporados y puede entonces mostrar un nombre personalizado o una UI según sea necesario. Lee **bool**.
