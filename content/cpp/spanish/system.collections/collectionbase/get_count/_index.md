## CollectionBase::get_Count() método


Devuelve el número de elementos contenidos en la instancia de la colección. Este método no puede ser sobrescrito.

```cpp
int32_t System::Collections::CollectionBase<T>::get_Count()
```


### Valor devuelto

El número de elementos contenidos en la instancia de la colección. Obtener el valor de este método es una operación O(1).
