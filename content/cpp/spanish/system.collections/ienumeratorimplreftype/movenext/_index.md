## IEnumeratorImplRefType::MoveNext() método


Mueve el enumerador al siguiente elemento. Si no se había referenciado ningún elemento antes, establece la referencia al primer elemento disponible. Si se alcanza el final del contenedor, no hace nada.

```cpp
virtual bool System::Collections::IEnumeratorImplRefType<T>::MoveNext() override
```


### Valor devuelto

True si hay algún elemento disponible después de la llamada, false de lo contrario.
