## XmlSchemaComplexType::get_IsAbstract() método

Devuelve la información que determina si el elemento **complexType** puede usarse en el documento de instancia.

```cpp
bool System::Xml::Schema::XmlSchemaComplexType::get_IsAbstract()
```

### Valor de retorno

Si **true**, un elemento no puede usar este elemento **complexType** directamente y debe usar un tipo complejo que se derive de este elemento **complexType**. El valor predeterminado es **false**. Opcional.
