## XmlSchemaComplexType::get_BlockResolved() método

Devuelve el valor después de que el tipo se haya compilado al conjunto de información de postvalidación de esquema (infoset). Este valor indica cómo se aplica el tipo cuando se usa **xsi:type** en el documento de instancia.

```cpp
XmlSchemaDerivationMethod System::Xml::Schema::XmlSchemaComplexType::get_BlockResolved()
```

### Valor devuelto

El valor del infoset postvalidado. El valor predeterminado es **BlockDefault** en el elemento **schema**.
