## XmlSchemaComplexType::get_IsMixed() método

Devuelve información que determina si el tipo complejo tiene un modelo de contenido mixto (marcado dentro del contenido).

```cpp
bool System::Xml::Schema::XmlSchemaComplexType::get_IsMixed() override
```

### Valor de retorno

**true**, si los datos de carácter pueden aparecer entre los elementos secundarios de este tipo complejo; de lo contrario, **false**. El valor predeterminado es **false**. Opcional.
