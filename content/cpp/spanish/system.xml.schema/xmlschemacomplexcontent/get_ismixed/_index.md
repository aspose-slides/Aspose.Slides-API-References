## XmlSchemaComplexContent::get_IsMixed() método


Devuelve información que determina si el tipo tiene un modelo de contenido mixto.

```cpp
bool System::Xml::Schema::XmlSchemaComplexContent::get_IsMixed()
```


### Valor de retorno

Si este valor es **true**, se permite que los datos de caracteres aparezcan entre los elementos hijos del tipo complejo (modelo de contenido mixto). El valor predeterminado es **false**. Opcional.
