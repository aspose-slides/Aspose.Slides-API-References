## XmlSchemaObjectCollection::Contains(const SharedPtr\<XmlSchemaObject\>\&) método


Indica si el [XmlSchemaObject](../../xmlschemaobject/) especificado está en el [XmlSchemaObjectCollection](../).

```cpp
bool System::Xml::Schema::XmlSchemaObjectCollection::Contains(const SharedPtr<XmlSchemaObject> &item)
```


### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| item | const [SharedPtr](../../../system/sharedptr/)\<[XmlSchemaObject](../../xmlschemaobject/)\>\& | El [XmlSchemaObject](../../xmlschemaobject/). |

### Valor devuelto

**true** si el nombre calificado especificado está en la colección; de lo contrario, devuelve **false**. Si se suministra **nullptr**, se devuelve **false** porque no hay un nombre calificado con un nombre nulo.
