## IXmlSchemaInfo::get_IsDefault() método


Devuelve un valor que indica si este nodo XML validado se estableció como resultado de un valor predeterminado aplicado durante la validación del esquema XML [Schema](../../) Definition Language (XSD).

```cpp
virtual bool System::Xml::Schema::IXmlSchemaInfo::get_IsDefault()=0
```


### Valor devuelto

**true** si este nodo XML validado se estableció como resultado de un valor predeterminado aplicado durante la validación del esquema; de lo contrario, **false**.
