## XmlSchema::get_ElementFormDefault() método

Devuelve la forma para los elementos declarados en el espacio de nombres objetivo del esquema.

```cpp
XmlSchemaForm System::Xml::Schema::XmlSchema::get_ElementFormDefault()
```

### Valor de retorno

El valor XmlSchemaForm que indica si los elementos del espacio de nombres objetivo deben estar calificados con el prefijo del espacio de nombres. El valor predeterminado es [XmlSchemaForm::None](../../xmlschemaform/).
