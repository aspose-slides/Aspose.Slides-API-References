## XmlSchema::get_FinalDefault() método

Devuelve el atributo **finalDefault** que establece el valor predeterminado del atributo **final** en los elementos y tipos complejos en el espacio de nombres de destino del esquema.

```cpp
XmlSchemaDerivationMethod System::Xml::Schema::XmlSchema::get_FinalDefault()
```

### Valor de retorno

Un valor XmlSchemaDerivationMethod que representa los diferentes métodos para evitar la derivación. El valor predeterminado es [XmlSchemaDerivationMethod::None](../../xmlschemaderivationmethod/).
