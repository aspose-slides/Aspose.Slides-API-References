## XmlSchemaAnyAttribute::get_ProcessContents() método

Devuelve información sobre cómo una aplicación o procesador XML debe manejar la validación de documentos XML para los atributos especificados por el elemento **anyAttribute**.

```cpp
XmlSchemaContentProcessing System::Xml::Schema::XmlSchemaAnyAttribute::get_ProcessContents()
```

### Valor de retorno

Uno de los valores de XmlSchemaContentProcessing. Si no se especifica el atributo **processContents**, el predeterminado es **Strict**.
