## XmlSchemaCompilationSettings::get_EnableUpaCheck() método


Devuelve un valor que indica si el [XmlSchemaSet](../../xmlschemaset/) debe comprobar las violaciones de Atribución Única de Partículas (UPA).

```cpp
bool System::Xml::Schema::XmlSchemaCompilationSettings::get_EnableUpaCheck()
```


### Valor devuelto

**true** si el [XmlSchemaSet](../../xmlschemaset/) debe comprobar las violaciones de Atribución Única de Partículas (UPA); de lo contrario, **false**. El valor predeterminado es **true**.
