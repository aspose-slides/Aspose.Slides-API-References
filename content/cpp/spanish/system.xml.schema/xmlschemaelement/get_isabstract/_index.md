## XmlSchemaElement::get_IsAbstract() método


Devuelve información que indica si el elemento puede usarse en un documento de instancia.

```cpp
bool System::Xml::Schema::XmlSchemaElement::get_IsAbstract()
```


### Valor devuelto

Si **true**, el elemento no puede aparecer en el documento de instancia. El valor predeterminado es **false**. Opcional.
