## XmlSchemaAny::get_ProcessContents() método


Devuelve información sobre cómo una aplicación o procesador XML debe manejar la validación de documentos XML para los elementos especificados por el elemento **any**.

```cpp
XmlSchemaContentProcessing System::Xml::Schema::XmlSchemaAny::get_ProcessContents()
```

Uno de los valores de XmlSchemaContentProcessing. Si no se especifica el atributo **processContents**, el predeterminado es **Strict**.
