## XmlSchemaForm enumeración

Indica si los atributos o elementos deben estar calificados con un prefijo de espacio de nombres.

```cpp
enum class XmlSchemaForm
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| None | 0 | El formulario de elemento y atributo no está especificado en el esquema. |
| Qualified | 1 | Los elementos y atributos deben estar calificados con un prefijo de espacio de nombres. |
| Unqualified | 2 | Los elementos y atributos no requieren estar calificados con un prefijo de espacio de nombres. |
