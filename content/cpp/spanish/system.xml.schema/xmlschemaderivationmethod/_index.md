## XmlSchemaDerivationMethod enum

Proporciona diferentes métodos para prevenir la derivación.

```cpp
enum class XmlSchemaDerivationMethod
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Empty | 0 | Reemplaza el método de derivación predeterminado para permitir cualquier derivación. |
| Substitution | 1 | Se refiere a derivaciones por **Substitution**. |
| Extension | 2 | Se refiere a derivaciones por **Extension**. |
| Restriction | 4 | Se refiere a derivaciones por **Restriction**. |
| List | 8 | Se refiere a derivaciones por **List**. |
| Union | 16 | Se refiere a derivaciones por **Union**. |
| All | 255 | **#all**. Se refiere a todos los métodos de derivación. |
| None | 256 | Acepta el método de derivación predeterminado. |
