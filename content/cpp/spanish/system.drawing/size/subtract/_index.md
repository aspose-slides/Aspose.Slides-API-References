## Size::Subtract(const Size\&, const Size\&) método


Devuelve un nuevo objeto [Size](../) que es el resultado de la sustracción de **size2** de **size1**, es decir, cuyo valor de ancho es el resultado de la sustracción del valor de ancho de **size2** del valor de ancho de **size1** y cuyo valor de alto es el resultado de la sustracción del valor de alto de **size2** del valor de alto de **size1**.

```cpp
static Size System::Drawing::Size::Subtract(const Size &size1, const Size &size2)
```


### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| size1 | const [Size](../)\& | El objeto [Size](../) del cual restar |
| size2 | const [Size](../)\& | El objeto [Size](../) a restar |

### Valor de retorno

El objeto [Size](../) que es el resultado de la sustracción de **size2** de **size1**
