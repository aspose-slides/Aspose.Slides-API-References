## Rectangle::FromLTRB(int, int, int, int) método

Construye un nuevo objeto [Rectangle](../) que representa un rectángulo con las ubicaciones de borde especificadas.

```cpp
static Rectangle System::Drawing::Rectangle::FromLTRB(int left, int top, int right, int bottom)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| left | int | La coordenada X del borde izquierdo del rectángulo |
| top | int | La coordenada Y del borde superior del rectángulo |
| right | int | La coordenada X del borde derecho del rectángulo |
| bottom | int | La coordenada Y del borde inferior del rectángulo |

### Valor de retorno

Una instancia de la clase [Rectangle](../) que representa el rectángulo especificado
