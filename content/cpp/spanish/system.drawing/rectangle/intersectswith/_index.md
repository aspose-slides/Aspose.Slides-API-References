## Rectangle::IntersectsWith(const Rectangle\&) método

Determina si los rectángulos representados por el objeto actual y el especificado se intersectan.

```cpp
bool System::Drawing::Rectangle::IntersectsWith(const Rectangle &rect)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| rect | const [Rectangle](../)\& | El rectángulo a comprobar |

### Valor devuelto

True si los rectángulos representados por el objeto actual y **rect** se intersectan, de lo contrario - false
