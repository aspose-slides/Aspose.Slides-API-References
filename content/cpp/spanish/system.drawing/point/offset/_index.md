## Point::Offset(int, int) método

Desplaza los valores de las coordenadas X e Y representados por el objeto actual según los valores especificados.

```cpp
void System::Drawing::Point::Offset(int dx, int dy)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| dx | int | El valor con el que se desplaza el valor de la coordenada X |
| dy | int | El valor con el que se desplaza el valor de la coordenada Y |

## Point::Offset(Point) método

Desplaza las coordenadas X e Y representadas por el objeto actual mediante los valores de las coordenadas X e Y representados por el objeto [Point](../) especificado, respectivamente.

```cpp
void System::Drawing::Point::Offset(Point point)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| point | [Point](../) | El objeto [Point](../) que especifica los valores con los que se desplazan las coordenadas X e Y |
