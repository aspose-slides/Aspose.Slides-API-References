## SystemFonts clase


Proporciona un conjunto de objetos [Font](../font/) precreados que representan fuentes utilizadas para mostrar texto en elementos de pantalla [Windows](../../system.windows/). Este es un tipo estático sin servicios de instancia. Nunca debe crear instancias de él por ningún medio.

```cpp
class SystemFonts : public System::Object
```
