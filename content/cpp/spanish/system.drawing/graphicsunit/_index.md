## GraphicsUnit enum

Representa una unidad de medida.

```cpp
enum class GraphicsUnit
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| World | 0 | Coordenada del mundo (unidad no física). |
| Display | 1 | Las unidades de medida del dispositivo de pantalla. |
| Pixel | 2 | Un píxel del dispositivo. |
| Point | 3 | Un punto de impresora (1/72 de pulgada). |
| Inch | 4 | Una pulgada. |
| Document | 5 | 1/300 de pulgada. |
| Millimeter | 6 | Un milímetro. |
