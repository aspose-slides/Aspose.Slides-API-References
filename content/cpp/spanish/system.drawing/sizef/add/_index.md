## SizeF::Add(const SizeF\&, const SizeF\&) método

Devuelve un nuevo objeto [SizeF](../) que es una suma de los objetos [SizeF](../) especificados, es decir, cuyo valor de width es igual a la suma de los valores de width de los objetos especificados y cuyo valor de height es igual a la suma de los valores de height de los objetos especificados.

```cpp
static SizeF System::Drawing::SizeF::Add(const SizeF &size1, const SizeF &size2)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| size1 | const [SizeF](../)\& | El primer operando |
| size2 | const [SizeF](../)\& | El segundo operando |

### Valor de retorno

El objeto [SizeF](../) que es la suma de **size1** y **size2**
