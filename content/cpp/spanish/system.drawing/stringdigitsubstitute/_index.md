## StringDigitSubstitute enumeración

Especifica cómo se sustituyen los dígitos en una cadena según la configuración regional o el idioma.

```cpp
enum class StringDigitSubstitute
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| User | 0 | Sustitución definida por el usuario. |
| None | 1 | La sustitución está deshabilitada. |
| National | 2 | Sustituir dígitos que correspondan al idioma nacional oficial de la configuración regional del usuario. |
| Traditional | 3 | Sustituir dígitos que correspondan al sistema de escritura o idioma nativo del usuario, que puede no ser el mismo que el idioma nacional oficial de la configuración regional del usuario. |
