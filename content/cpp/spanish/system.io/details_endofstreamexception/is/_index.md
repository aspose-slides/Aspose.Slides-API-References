## Detalles_EndOfStreamException::Is(const System::TypeInfo\&) const method

```cpp
bool System::IO::Details_EndOfStreamException::Is(const System::TypeInfo &target) const override
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| target | const [System::TypeInfo](../../../system/typeinfo/)\& | estructura [TypeInfo](../../../system/typeinfo/) que describe el tipo contra el cual se prueba el objeto actual. |

### Valor devuelto

Verdadero si el objeto es del tipo etiquetado o de su subclase, falso en caso contrario.

## Observaciones

Comprueba si el objeto representa una instancia del tipo descrito por targetType. Análogo al operador 'is' de C#.
