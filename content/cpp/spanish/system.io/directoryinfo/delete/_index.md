## DirectoryInfo::Delete() método

Elimina el directorio referenciado por la ruta representada por el objeto actual si el directorio está vacío.

```cpp
virtual void System::IO::DirectoryInfo::Delete() override
```

## DirectoryInfo::Delete(bool) método

Elimina el directorio referenciado por la ruta representada por el objeto actual. Un parámetro especifica si el contenido del directorio debe eliminarse recursivamente si el directorio no está vacío.

```cpp
void System::IO::DirectoryInfo::Delete(bool recursive)
```

### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| recursive | **bool** | Especifica si el contenido del directorio debe eliminarse recursivamente si no está vacío |
