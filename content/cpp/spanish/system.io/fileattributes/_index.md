## FileAttributes enumeración

Representa los atributos de un directorio o un archivo.

```cpp
enum class FileAttributes
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Archive | 32 | La entidad del sistema de archivos es un candidato para eliminación o copia de seguridad. |
| Compressed | 2048 | La entidad del sistema de archivos está comprimida. |
| Device | 64 | No se usa. |
| Directory | 16 | La entidad del sistema de archivos es un directorio. |
| Encrypted | 16384 | La entidad del sistema de archivos está encriptada. |
| Hidden | 2 | La entidad del sistema de archivos está oculta. |
| IntegrityStream | 32768 | La entidad del sistema de archivos contiene soporte de integridad de datos. |
| Normal | 128 | La entidad del sistema de archivos es un archivo que no tiene atributos especiales. |
| NotContentIndexed | 8192 | La entidad del sistema de archivos no será indexada por el servicio de indexación de contenido. |
| NoScrubData | 131072 | La entidad del sistema de archivos no está incluida en el escaneo de integridad de datos. |
| Offline | 4096 | La entidad del sistema de archivos está offline y sus datos no están disponibles inmediatamente. |
| ReadOnly | 1 | La entidad del sistema de archivos es de solo lectura. |
| ReparsePoint | 1024 | La entidad del sistema de archivos es un archivo que contiene un punto de reparse. |
| SparseFile | 512 | La entidad del sistema de archivos es un archivo disperso. |
| System | 4 | La entidad del sistema de archivos es un archivo del sistema. |
| Temporary | 256 | La entidad del sistema de archivos es un archivo temporal. |
| Invalid | 0 | Valor no válido. |
