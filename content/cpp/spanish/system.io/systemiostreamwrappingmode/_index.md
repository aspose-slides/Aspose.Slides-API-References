## SystemIOStreamWrappingMode enum

Especifica el modo de operaciones de E/S que los envoltorios realizarán sobre flujos similares a [System::IO::Stream](../stream/).

```cpp
enum class SystemIOStreamWrappingMode
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Binary | 0 | Un modo que permite que las operaciones de entrada codifiquen los bytes del flujo en datos de tipo char_type y decodifiquen los datos de tipo char_type en bytes del flujo para operaciones de salida. |
| Conversion | 1 | Un modo que permite que las operaciones de entrada conviertan los bytes del flujo del tipo **uint8_t** al tipo char_type y viceversa para operaciones de salida. |
