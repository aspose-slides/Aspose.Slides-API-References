## File::AppendText(const String\&) método


Crea un objeto [StreamWriter](../../streamwriter/) que agrega texto al archivo especificado usando codificación UTF-8. Si el archivo especificado no existe, se crea.

```cpp
static StreamWriterPtr System::IO::File::AppendText(const String &path)
```


### Argumentos

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| path | const [String](../../../system/string/)\& | La ruta del archivo que se abrirá o creará |

### Valor devuelto

Un puntero compartido al objeto [StreamWriter](../../streamwriter/) creado asociado con el archivo especificado
