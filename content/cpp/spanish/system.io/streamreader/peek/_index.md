## StreamReader::Peek() método

Lee un solo carácter del flujo sin cambiar el cursor de lectura del flujo.

```cpp
virtual int System::IO::StreamReader::Peek() override
```

### Valor de retorno

Carácter leído codificado en UTF-16; si el carácter leído está representado por dos puntos de código en la codificación UTF-16, solo se devuelve el sustituto alto; si no se leyó ningún carácter, se devuelve -1
