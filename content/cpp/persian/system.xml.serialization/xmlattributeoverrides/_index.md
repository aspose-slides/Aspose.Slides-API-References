## XmlAttributeOverrides کلاس

امکان نادیده‌گیری ویژگی‌ها را زمانی که [XmlSerializer](../xmlserializer/) برای سریالیزه یا دیسریالیزه کردن یک شیء استفاده می‌شود، فراهم می‌کند. اشیای این کلاس باید فقط با استفاده از تابع [System::MakeObject()](../../system/makeobject/) تخصیص یابند. هرگز نمونه‌ای از این نوع را روی پشته یا با استفاده از عملگر new ایجاد نکنید، زیرا منجر به خطاهای زمان اجرا و/یا اشکالات ادعا می‌شود. همیشه این کلاس را درون اشاره‌گر [System::SmartPtr](../../system/smartptr/) بپیچید و از این اشاره‌گر برای عبور آن به عنوان آرگومان به توابع استفاده کنید.

```cpp
class XmlAttributeOverrides : public System::Object
```
