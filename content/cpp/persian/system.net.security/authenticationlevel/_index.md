## AuthenticationLevel enum

WebRequest-specific authentication flags.

```cpp
enum class AuthenticationLevel
```

### مقادیر

| نام | مقدار | توضیحات |
| --- | --- | --- |
| None | 0 | برای مشتری و سرور نیازی به احراز هویت نیست. |
| MutualAuthRequested | 1 | اگر سرور احراز هویت نشود، درخواست شکست نمی‌خورد. |
| MutualAuthRequired | 2 | در صورتی که سرور احراز هویت نشود، برنامه جاری خطای 'IOException' دریافت می‌کند. |
