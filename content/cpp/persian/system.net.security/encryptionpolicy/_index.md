## EncryptionPolicy enum

سیاست‌های رمزگذاری را فهرست می‌کند.

```cpp
enum class EncryptionPolicy
```

### Values

| نام | مقدار | توضیح |
| --- | --- | --- |
| RequireEncryption | 0 | الزام به رمزگذاری و هرگز اجازه استفاده از رمز 'Null' را نمی‌دهد. |
| AllowNoEncryption | 1 | استفاده از رمزگذاری کامل را ترجیح می‌دهد اما در صورت موافقت سرور می‌توان از رمز 'Null' استفاده کرد. |
| NoEncryption | 2 | بدون رمزگذاری اجازه می‌دهد و درخواست می‌کند که در صورت توانایی نقطه انتهایی دیگر برای پردازش رمز 'Null'، از آن استفاده شود. |
