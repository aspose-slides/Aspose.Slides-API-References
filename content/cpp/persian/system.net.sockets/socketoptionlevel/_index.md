## SocketOptionLevel enum


سطح‌های گزینه‌های سوکت را برای کلاس '[Socket](../socket/)' تعریف می‌کند.

```cpp
enum class SocketOptionLevel
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| Socket | 65535 | گزینه‌های سوکت مشخص‌شده برای تمام سوکت‌ها اعمال می‌شود. |
| IP | n/a | گزینه‌های سوکت مشخص‌شده برای سوکت‌های IP اعمال می‌شود. |
| IPv6 | n/a | گزینه‌های سوکت مشخص‌شده برای سوکت‌های IPv6 اعمال می‌شود. |
| Tcp | n/a | گزینه‌های سوکت مشخص‌شده برای سوکت‌های TCP اعمال می‌شود. |
| Udp | n/a | گزینه‌های سوکت مشخص‌شده برای سوکت‌های UDP اعمال می‌شود. |
