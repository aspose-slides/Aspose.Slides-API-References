## کلاس HttpClientHandler

نماینده‌ی پیش‌فرض هندلر پیام که توسط کلاس [HttpClient](../httpclient/) استفاده می‌شود. اشیای این کلاس باید فقط با استفاده از تابع [System::MakeObject()](../../system/makeobject/) تخصیص یابند. هرگز نمونه‌ای از این نوع را روی پشته یا با اپراتور new ایجاد نکنید، زیرا باعث خطاهای زمان اجرا و/یا اشکالات تأیید می‌شود. همیشه این کلاس را درون اشاره‌گر [System::SmartPtr](../../system/smartptr/) بپیچید و از این اشاره‌گر برای ارسال به توابع به عنوان آرگومان استفاده کنید.

```cpp
class HttpClientHandler : public System::Net::Http::HttpMessageHandler
```
