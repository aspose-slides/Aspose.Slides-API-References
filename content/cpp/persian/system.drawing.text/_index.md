## کلاس‌ها

| کلاس | توضیح |
| --- | --- |
| [FontCollection](./fontcollection/) | یک کلاس پایه برای مجموعه‌های قلم نصب شده و خصوصی. اشیای این کلاس باید فقط با استفاده از تابع [System::MakeObject()](../system/makeobject/) اختصاص داده شوند. هرگز نمونه‌ای از این نوع را بر روی پشته یا با استفاده از عملگر new ایجاد نکنید، زیرا منجر به خطاهای زمان اجرا و/یا خطاهای اعتبارسنجی می‌شود. همیشه این کلاس را در یک اشاره‌گر [System::SmartPtr](../system/smartptr/) بپیچید و از این اشاره‌گر برای پاس دادن به توابع به‌عنوان آرگومان استفاده کنید. |
| [InstalledFontCollection](./installedfontcollection/) | نمایش‌دهندهٔ مجموعهٔ قلم‌های نصب شده در سیستم است. پیاده‌سازی نشده. اشیای این کلاس باید فقط با استفاده از تابع [System::MakeObject()](../system/makeobject/) اختصاص داده شوند. هرگز نمونه‌ای از این نوع را بر روی پشته یا با استفاده از عملگر new ایجاد نکنید، زیرا منجر به خطاهای زمان اجرا و/یا خطاهای اعتبارسنجی می‌شود. همیشه این کلاس را در یک اشاره‌گر [System::SmartPtr](../system/smartptr/) بپیچید و از این اشاره‌گر برای پاس دادن به توابع به‌عنوان آرگومان استفاده کنید. |
| [PrivateFontCollection](./privatefontcollection/) | نمایش‌دهندهٔ مجموعه‌ای از خانواده‌های قلم ارائه شده توسط برنامهٔ مشتری است. اشیای این کلاس باید فقط با استفاده از تابع [System::MakeObject()](../system/makeobject/) اختصاص داده شوند. هرگز نمونه‌ای از این نوع را بر روی پشته یا با استفاده از عملگر new ایجاد نکنید، زیرا منجر به خطاهای زمان اجرا و/یا خطاهای اعتبارسنجی می‌شود. همیشه این کلاس را در یک اشاره‌گر [System::SmartPtr](../system/smartptr/) بپیچید و از این اشاره‌گر برای پاس دادن به توابع به‌عنوان آرگومان استفاده کنید. |
