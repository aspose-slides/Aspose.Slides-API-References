## XPathNavigator::InsertElementBefore(String, String, String, String) متد

یک عنصر هم‌رشته جدید قبل از گرهٔ فعلی ایجاد می‌کند که از پیشوند نام‌فضا، نام محلی و URI نام‌فضای مشخص‌شده استفاده می‌نماید و مقدار مشخص‌شده را دارد.

```cpp
virtual void System::Xml::XPath::XPathNavigator::InsertElementBefore(String prefix, String localName, String namespaceURI, String value)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| prefix | [String](../../../system/string/) | پیشوند نام‌فضای عنصر فرزند جدید (در صورت وجود). |
| localName | [String](../../../system/string/) | نام محلی عنصر فرزند جدید (در صورت وجود). |
| namespaceURI | [String](../../../system/string/) | URI نام‌فضای عنصر فرزند جدید (در صورت وجود). [String::Empty](../../../system/string/empty/) و **nullptr** معادل هستند. |
| value | [String](../../../system/string/) | مقدار عنصر فرزند جدید. اگر [String::Empty](../../../system/string/empty/) یا **nullptr** پاس داده شوند، عنصر خالی ایجاد می‌شود. |
