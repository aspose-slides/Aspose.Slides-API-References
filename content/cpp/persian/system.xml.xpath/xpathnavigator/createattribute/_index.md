## XPathNavigator::CreateAttribute(String, String, String, String) متد

یک گرهٔ ویژگی را بر روی گرهٔ عنصر فعلی با استفاده از پیشوند فضای نام، نام محلی و URI فضای نام تعیین‌شده، همراه با مقدار مشخص‌شده، ایجاد می‌کند.

```cpp
virtual void System::Xml::XPath::XPathNavigator::CreateAttribute(String prefix, String localName, String namespaceURI, String value)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| prefix | [String](../../../system/string/) | پیشوند فضای نام گرهٔ ویژگی جدید (در صورت وجود). |
| localName | [String](../../../system/string/) | نام محلی گرهٔ ویژگی جدید که نمی‌تواند [String::Empty](../../../system/string/empty/) یا **nullptr** باشد. |
| namespaceURI | [String](../../../system/string/) | URI فضای نام برای گرهٔ ویژگی جدید (در صورت وجود). |
| value | [String](../../../system/string/) | مقدار گرهٔ ویژگی جدید. اگر [String::Empty](../../../system/string/empty/) یا **nullptr** پاس داده شود، یک گرهٔ ویژگی خالی ایجاد می‌شود. |
