## XPathNavigator::MoveToAttribute(String, String) متد

[XPathNavigator](../) را به ویژگی که نام محلی و URI فضای نام مطابقت دارد منتقل می‌کند.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToAttribute(String localName, String namespaceURI)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| localName | [String](../../../system/string/) | نام محلی ویژگی. |
| namespaceURI | [String](../../../system/string/) | URI فضای نام ویژگی؛ **nullptr** برای فضای نام خالی. |

### مقدار بازگشت

**true** اگر [XPathNavigator](../) به‌طور موفقیت‌آمیزی به ویژگی منتقل شود؛ در غیر این صورت **false**. اگر **false** باشد، موقعیت [XPathNavigator](../) تغییر نمی‌کند.
