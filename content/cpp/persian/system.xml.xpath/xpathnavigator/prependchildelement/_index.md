## XPathNavigator::PrependChildElement(String, String, String, String) متد

یک عنصر فرزند جدید را در ابتدای فهرست گره‌های فرزند گرهٔ جاری، با استفاده از پیشوند فضای نام، نام محلی و URI فضای نام مشخص شده همراه با مقدار تعیین‌شده، ایجاد می‌کند.

```cpp
virtual void System::Xml::XPath::XPathNavigator::PrependChildElement(String prefix, String localName, String namespaceURI, String value)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| prefix | [String](../../../system/string/) | پیشوند فضای نام عنصر فرزند جدید (در صورت وجود). |
| localName | [String](../../../system/string/) | نام محلی عنصر فرزند جدید (در صورت وجود). |
| namespaceURI | [String](../../../system/string/) | URI فضای نام عنصر فرزند جدید (در صورت وجود). [String::Empty](../../../system/string/empty/) و **nullptr** معادل هستند. |
| value | [String](../../../system/string/) | مقدار عنصر فرزند جدید. اگر [String::Empty](../../../system/string/empty/) یا **nullptr** عبور داده شوند، یک عنصر خالی ایجاد می‌شود. |
