
### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| prefix | const [String](../../../system/string/)\& | پیشوندی که می‌خواهید URI فضای‌نام را برای آن حل کنید. برای مطابقت با فضای‌نام پیش‌فرض، [String::Empty](../../../system/string/empty/) را پاس دهید. |

## مقدار بازگشت

یک [String](../../../system/string/) که شامل URI فضای‌نام اختصاص داده شده به پیشوند فضای‌نام مشخص شده است؛ **nullptr** اگر هیچ URI فضانامی به پیشوند مشخص شده اختصاص داده نشده باشد. [String](../../../system/string/) بازگردانده شده اتمی شده است.
