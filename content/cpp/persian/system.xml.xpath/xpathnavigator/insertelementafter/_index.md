## XPathNavigator::InsertElementAfter(String, String, String, String) متد

Creates a new sibling element after the current node using the namespace prefix, local name and namespace URI specified, with the value specified.

```cpp
virtual void System::Xml::XPath::XPathNavigator::InsertElementAfter(String prefix, String localName, String namespaceURI, String value)
```

| localName | [String](../../../system/string/) | نام محلی عنصر فرزند جدید (در صورت وجود). |
| namespaceURI | [String](../../../system/string/) | URI فضای نام عنصر فرزند جدید (در صورت وجود). [String::Empty](../../../system/string/empty/) و **nullptr** معادل هستند. |
| value | [String](../../../system/string/) | مقدار عنصر فرزند جدید. اگر [String::Empty](../../../system/string/empty/) یا **nullptr** ارسال شوند، یک عنصر خالی ایجاد می‌شود. |
