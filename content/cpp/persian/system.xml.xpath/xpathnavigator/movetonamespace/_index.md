## XPathNavigator::MoveToNamespace(String) متد

[XPathNavigator](../) را به گرهٔ فضای نام با پیشوند فضای نام مشخص شده منتقل می‌کند.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToNamespace(String name)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| name | [String](../../../system/string/) | پیشوند فضای نام گرهٔ فضای نام. |

### مقدار بازگشت

**true** اگر [XPathNavigator](../) موفق به جابجایی به فضای نام مشخص شده شود؛ **false** اگر گرهٔ فضای نام منطبق یافت نشود، یا اگر [XPathNavigator](../) روی گرهٔ عنصر قرار نگرفته باشد. اگر **false**، موقعیت [XPathNavigator](../) بدون تغییر می‌ماند.
