## XPathNavigator::get_HasAttributes() متد

یک مقدار برمی‌گرداند که نشان می‌دهد آیا گرهٔ جاری دارای هرگونه ویژگی است یا خیر.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::get_HasAttributes()
```

### مقدار بازگشتی

**true** اگر گرهٔ جاری دارای ویژگی باشد؛ **false** برگردانده می‌شود اگر گرهٔ جاری ویژگی نداشته باشد، یا اگر [XPathNavigator](../) روی یک گرهٔ عنصر قرار نگرفته باشد.
