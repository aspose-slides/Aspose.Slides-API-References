## XPathNavigator::AppendChildElement(String, String, String, String) متد

یک گره عنصر کودک جدید در انتهای لیست گره‌های کودک گرهٔ فعلی ایجاد می‌کند که از پیشوند فضای نام، نام محلی و URI فضای نام مشخص‌شده با مقدار داده‌شده استفاده می‌کند.

```cpp
virtual void System::Xml::XPath::XPathNavigator::AppendChildElement(String prefix, String localName, String namespaceURI, String value)
```


### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| prefix | [String](../../../system/string/) | پیشوند فضای نام گره عنصر کودک جدید (در صورت وجود). |
| localName | [String](../../../system/string/) | نام محلی گره عنصر کودک جدید (در صورت وجود). |
| namespaceURI | [String](../../../system/string/) | URI فضای نام گره عنصر کودک جدید (در صورت وجود). [String::Empty](../../../system/string/empty/) و **nullptr** برابر هستند. |
| value | [String](../../../system/string/) | مقدار گره عنصر کودک جدید. اگر [String::Empty](../../../system/string/empty/) یا **nullptr** ارسال شود، یک عنصر خالی ایجاد می‌شود. |
