## IsEnumerable ساختار

بررسی می‌کند که آیا نوع دارای تخصص [System::Collections::Generic::IEnumerable](../../system.collections.generic/ienumerable/) به عنوان نوع پایه است. اگر چنین باشد، عضو value برابر با true تنظیم می‌شود، در غیر این صورت برابر با false تنظیم می‌شود.

```cpp
template<typename T,typename Enable>class IsEnumerable : public std::false_type
```
