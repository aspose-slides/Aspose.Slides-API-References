## IsList typedef


اگر نوع یک تخصص [System::Collections::Generic::List](../../system.collections.generic/list/) باشد بررسی می‌کند. در این صورت، عضو value برابر true تنظیم می‌شود، در غیر این صورت برابر false تنظیم می‌شود.

```cpp
using System::TestPredicates::TypeTraits::IsList = typedef std::is_same<T, System::Collections::Generic::List<typename T::ValueType> >
```
