## has_data_method ساختار

بررسی می‌کند آیا یک نوع متد data() دارد. اگر داشته باشد، از std::true_type ارث می‌برد، در غیر اینصورت از std::false_type ارث می‌برد.

```cpp
template<typename T,typename Enable>class has_data_method : public std::false_type
```

### پارامترهای قالب

| پارامتر | توضیح |
| --- | --- |
| T | نوعی که باید بررسی شود. |
| Enable | آرگومان رسمی برای کارکرد SFINAE. |
