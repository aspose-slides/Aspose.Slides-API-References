## BothEnumerable تعریف نوع

بررسی می‌کند که آیا هر دو آرگومان نوع IEnumerable هستند یا خیر. اگر چنین باشد، عضو value برابر با true تنظیم می‌شود، در غیر این صورت برابر با false تنظیم می‌شود.

```cpp
using System::TestPredicates::TypeTraits::BothEnumerable = typedef std::integral_constant<bool, IsEnumerable<T1>::value && IsEnumerable<T2>::value>
```
