## WarningType enum

نمایش یک نوع هشدار.

```cpp
enum class WarningType
```

### مقادیر

| Name | Value | Description |
| --- | --- | --- |
| SourceFileCorruption | 0 | یک مشکل در سند منبع شناسایی شده است که به شدت احتمال می‌دهد سند در صورت ذخیره شدن در قالب اصلی خود قابل باز شدن نباشد. |
| DataLoss | 1 | متن/نمودار/تصویر یا داده‌های دیگر کاملاً از درخت سند پس از بارگذاری یا از سند ایجاد شده پس از ذخیره‌سازی غائب خواهند شد. |
| MajorFormattingLoss | 2 | از دست رفتن قالب‌بندی عمده. |
| MinorFormattingLoss | 3 | از دست رفتن قالب‌بندی جزئی. |
| CompatibilityIssue | 4 | این یک مشکل شناخته‌شده است که مانع باز شدن سند توسط برخی عوامل کاربری یا نسخه‌های قبلی آنها می‌شود. |
| UnexpectedContent | 99 | برخی محتواهای در سند منبع قابل شناسایی نیستند (یعنی پشتیبانی نمی‌شوند)، این ممکن است منجر به بروز مشکلات یا از دست رفتن داده/قالب‌بندی شود. |
