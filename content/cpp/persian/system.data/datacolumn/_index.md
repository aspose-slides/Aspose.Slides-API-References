## DataColumn کلاس

ستونی را در داده‌ها توصیف می‌کند. اشیای این کلاس باید تنها با استفاده از تابع [System::MakeObject()](../../system/makeobject/) تخصیص داده شوند. هرگز نمونه‌ای از این نوع را روی پشته یا با استفاده از عملگر new ایجاد نکنید، زیرا منجر به خطاهای زمان اجرا و/یا اشتباهات تضمین می‌شود. همیشه این کلاس را در یک اشاره‌گر [System::SmartPtr](../../system/smartptr/) بپیچید و از این اشاره‌گر برای گذراندن آن به توابع به عنوان آرگومان استفاده کنید.

```cpp
class DataColumn : public System::Object
```
