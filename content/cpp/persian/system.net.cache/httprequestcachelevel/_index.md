## HttpRequestCacheLevel enum

این enum تنظیمات کش برای HTTP را توصیف می‌کند.

```cpp
enum class HttpRequestCacheLevel
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| Default | 0 | درخواست برای یک منبع را یا با استفاده از نسخهٔ ذخیره‌شدهٔ منبع یا با ارسال درخواست برای منبع به سرور برآورده می‌کند. |
| BypassCache | 1 | درخواست را با استفاده از سرور برآورده می‌کند. |
| CacheOnly | 2 | همیشه از کش کلاینت برای دریافت منبع استفاده می‌کند. |
| CacheIfAvailable | 3 | در صورتی که منبع در کش موجود باشد، درخواست برای منبع را از کش برآورده می‌کند؛ در غیر این صورت درخواست را به سرور ارسال می‌کند. |
| Revalidate | 4 | اگر برچسب زمانی کلاینت با برچسب زمانی منبع در سرور یکسان باشد، از نسخهٔ محلی منبع استفاده می‌کند. در غیر این صورت، منبع از سرور دانلود می‌شود. |
| Reload | 5 | منبع همیشه از سرور دانلود می‌شود. |
| NoCacheNoStore | 6 | هرگز درخواست را با استفاده از منابع ذخیره‌شده برآورده نمی‌کند و منابع را کش نمی‌کند. |
| CacheOrNextCacheOnly | 7 | درخواست برای یک منبع را یا از کش کامپیوتر محلی یا از کش راه‌دور در شبکهٔ LAN برآورده می‌کند. |
| Refresh | 8 | درخواست را با استفاده از سرور یا کشی جز کش محلی برآورده می‌کند. |
