## RequestCacheLevel enum

این enum تنظیمات حافظهٔ پنهان را که برای هر [WebRequest](../../system.net/webrequest/) قابل‌استفاده است، توصیف می‌کند.

```cpp
enum class RequestCacheLevel
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| Default | 0 | درخواست برای یک منبع را یا با استفاده از نسخهٔ ذخیره‌شدهٔ منبع از حافظهٔ پنهان یا با ارسال درخواست برای منبع به سرور برآورده می‌کند. |
| BypassCache | 1 | درخواست را با استفاده از سرور برآورده می‌کند. هیچ مدخل‌ای از حافظهٔ پنهان استفاده نمی‌شود. |
| CacheOnly | 2 | درخواست برای یک منبع را فقط از حافظهٔ پنهان برآورده می‌کند. زمانی که منبع در حافظهٔ پنهان کلاینت موجود نباشد، WebException رخ خواهد داد. |
| CacheIfAvailable | 3 | اگر منبع در حافظهٔ پنهان موجود باشد، درخواست برای آن را از حافظهٔ پنهان برآورده می‌کند؛ در غیر این صورت درخواست به سرور ارسال می‌شود. |
| Revalidate | 4 | اگر زمان‌مهر کلاینت با زمان‌مهر منبع در سرور یکسان باشد، از نسخهٔ محلی منبع استفاده می‌کند. در غیر این صورت، منبع از سرور دانلود می‌شود. |
| Reload | 5 | منبع همیشه از سرور دانلود می‌شود. |
| NoCacheNoStore | 6 | هرگز درخواست را با استفاده از منابع از حافظهٔ پنهان برآورده نمی‌کند و منابع را در حافظهٔ پنهان ذخیره نمی‌کند. |
