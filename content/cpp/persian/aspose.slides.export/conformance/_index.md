## enum انطباق

Specifies the conformance class to which the PresentationML document conforms.

```cpp
enum class Conformance
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| Ecma376_2006 | 0 | مشخص می‌کند که سند با ECMA376:2006 سازگار است. |
| Iso29500_2008_Transitional | 1 | مشخص می‌کند که سند با کلاس انطباق ISO/IEC 29500:2008 Transitional سازگار است. |
| Iso29500_2008_Strict | 2 | مشخص می‌کند که سند با کلاس انطباق ISO/IEC 29500:2008 Strict سازگار است. |
