## MarkdownSaveOptions::get_HandleRepeatedSpaces() const متد

مشخص می‌کند که کاراکترهای فاصلهٔ معمولی تکراری در هنگام خروجی‌گیری Markdown چگونه مدیریت شوند.

```cpp
Aspose::Slides::Export::HandleRepeatedSpaces Aspose::Slides::Export::MarkdownSaveOptions::get_HandleRepeatedSpaces() const
```

## توضیحات

* به عنوان کاراکترهای فاصلهٔ معمولی حفظ می‌شود،
* بین کاراکترهای فاصلهٔ معمولی و نهادهای فاصلهٔ غیرقابل شکست (**&nbsp;**) جابجا می‌شود،
* یا به طور کامل (پس از اولین) با **&nbsp;** جایگزین می‌شود تا تراز بصری در خروجی Markdown حفظ شود.
