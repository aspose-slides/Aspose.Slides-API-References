## MarkdownSaveOptions::set_HandleRepeatedSpaces(Aspose::Slides::Export::HandleRepeatedSpaces) متد

مشخص می‌کند که کاراکترهای فضای خالی منظم تکراری در هنگام خروجی‌گیری به‌صورت Markdown چگونه باید پردازش شوند.

```cpp
void Aspose::Slides::Export::MarkdownSaveOptions::set_HandleRepeatedSpaces(Aspose::Slides::Export::HandleRepeatedSpaces value)
```

## توضیحات

این ویژگی تعیین می‌کند که آیا فضاهای متوالی:
* حفظ به عنوان کاراکترهای فضای خالی منظم،
* جابجا شدن بین فضاهای منظم و نهادهای فضای غیرقابل شکستن (**&nbsp;**)،
* یا کاملاً جایگزین (پس از اولین) با **&nbsp;** برای حفظ ترازبندی بصری در خروجی Markdown.

مقدار پیش‌فرض [HandleRepeatedSpaces::AlternateSpacesToNbsp](../../handlerepeatedspaces/) است.
