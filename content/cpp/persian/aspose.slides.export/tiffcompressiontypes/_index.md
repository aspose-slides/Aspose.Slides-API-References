## TiffCompressionTypes enum

گزینه‌هایی را فراهم می‌کند که کنترل می‌کنند یک ارائه چگونه در فرمت TIFF فشرده شود.

```cpp
enum class TiffCompressionTypes
```

### Values

| نام | مقدار | توضیح |
| --- | --- | --- |
| Default | 0 | طرح فشرده‌سازی پیش‌فرض (LZW) را مشخص می‌کند. |
| None | 1 | هیچ فشرده‌سازی‌ای را مشخص نمی‌کند. |
| CCITT3 | 2 | طرح فشرده‌سازی CCITT3 را مشخص می‌کند. |
| CCITT4 | 3 | طرح فشرده‌سازی CCITT4 را مشخص می‌کند. |
| LZW | 4 | طرح فشرده‌سازی LZW (پیش‌فرض) را مشخص می‌کند. |
| RLE | 5 | طرح فشرده‌سازی RLE را مشخص می‌کند. |
