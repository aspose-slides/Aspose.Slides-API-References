## BlackWhiteConversionMode enum

گزینه‌هایی را فراهم می‌کند که نحوهٔ تبدیل تصاویر اسلایدها به تصاویر دو رنگی را کنترل می‌کند.

```cpp
enum class BlackWhiteConversionMode
```

### Values

| نام | مقدار | توضیح |
| --- | --- | --- |
| Default | 0 | الگوریتم تبدیل خاصی را مشخص نمی‌کند. الگوریتم پیاده‌سازی‌شده در کدک TIFF استفاده خواهد شد. (Default) |
| Dithering | 1 | الگوریتم دیتیرینگ (Floyd-Steinberg) را مشخص می‌کند. |
| DitheringFloydSteinberg | 2 | الگوریتم دیتیرینگ Floyd-Steinberg را مشخص می‌کند. |
| Auto | 3 | الگوریتم آستانه محاسبه‌شده به‌صورت خودکار (Otsu) را مشخص می‌کند. |
| AutoOtsu | 4 | الگوریتم آستانه Otsu محاسبه‌شده به‌صورت خودکار را مشخص می‌کند. |
| Threshold25 | 5 | الگوریتم آستانه ثابت (25٪) را مشخص می‌کند. |
| Threshold50 | 6 | الگوریتم آستانه ثابت (50٪) را مشخص می‌کند. |
| Threshold75 | 7 | الگوریتم آستانه ثابت (75٪) را مشخص می‌کند. |
