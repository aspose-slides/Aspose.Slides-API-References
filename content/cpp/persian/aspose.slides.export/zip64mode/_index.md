## Zip64Mode enum

مشخص می‌کند که چه زمانی باید افزونه‌های فرمت ZIP64 برای فایل OpenXML استفاده شود.

```cpp
enum class Zip64Mode
```

### مقادیر

| نام | مقدار | توضیحات |
| --- | --- | --- |
| Never | 0 | از افزونه‌های فرمت ZIP64 استفاده نشود. |
| IfNecessary | 1 | در صورت نیاز از افزونه‌های فرمت ZIP64 استفاده شود. |
| Always | 2 | همیشه از افزونه‌های فرمت ZIP64 استفاده شود. |

## نکات

فایل OpenXML یک بایگانی ZIP است که حداکثر ۴ گیگابایت (۲^۳۲ بایت) برای اندازهٔ فشرده‌نشدهٔ یک فایل، اندازهٔ فشردهٔ یک فایل و کل اندازهٔ بایگانی، و همچنین حداکثر ۶۵٬۵۳۵ (۲^۱۶-۱) فایل در بایگانی دارد. افزونه‌های فرمت ZIP64 این محدودیت‌ها را به ۲^۶۴ افزایش می‌دهند.
