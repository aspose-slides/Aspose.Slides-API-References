## EmbedFontCharacters enum

نمایش می‌دهد قاعده‌ای که برای افزودن قلم جاسازی جدید به [IPresentation](../../aspose.slides/ipresentation/) استفاده می‌شود.

```cpp

```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| OnlyUsed | 0 | فقط حروف استفاده شده در ارائه را جاسازی می‌کند (بهترین گزینه برای کاهش اندازه فایل). |
| All | 1 | تمام حروف را جاسازی می‌کند (بهترین گزینه برای ویرایش توسط افراد دیگر). |
