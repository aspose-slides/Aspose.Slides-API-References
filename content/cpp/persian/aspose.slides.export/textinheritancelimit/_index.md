## TextInheritanceLimit enum

عمق وراثت ویژگی‌های متن را کنترل می‌کند.

```cpp
enum class TextInheritanceLimit
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| All | 0 | تمام ویژگی‌های متن را به ارث می‌برد. |
| TextBox | 1 | فقط از سبک [TextFrame](../../aspose.slides/textframe/) به ارث می‌برد. |
| ParagraphOnly | 2 | فقط از ویژگی‌های تعریف‌شده برای پاراگراف استفاده می‌کند. |
