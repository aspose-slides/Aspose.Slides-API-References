## SVGOptions::set_DisableLineEndCropping(bool) متد

SVG 1.1 قابلیت تعریف تو رفتگی‌ها برای نشانگرها را ندارد. [Aspose.Slides](../../../aspose.slides/) موتور نوشتن SVG یک راه حل برای این مشکل دارد: انتهای خط را با پیکانی برش می‌دهد، بنابراین خط با نشانگرها همپوشانی نمی‌کند. این گزینه این رفتار را غیرفعال می‌کند. نوشتن **bool**.

```cpp
void Aspose::Slides::Export::SVGOptions::set_DisableLineEndCropping(bool value) override
```
