## SvgExternalFontsHandling enum

نمایش یک روش برای مدیریت قلم‌های خارجی استفاده‌شده برای رسم متن.

```cpp
enum class SvgExternalFontsHandling
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| AddLinksToFontFiles | 0 | افزودن پیوندها به پرونده‌های قلم جداگانه در بخش style فایل SVG. |
| Embed | 1 | ذخیره داده‌های قلم‌ها به‌صورت مستقیم در فایل SVG. لطفاً قبل از استفاده از این گزینه، تمامی توافق‌نامه‌های مجوز قلم‌های خارجی را بررسی کنید. |
| Vectorize | 2 | ذخیره تمام متن با استفاده از قلم‌های خارجی به‌صورت گرافیک. |
