## PdfOptions::set_JpegQuality(uint8_t) متد


یک مقدار تنظیم می‌کند که کیفیت تصاویر JPEG داخل سند PDF را تعیین می‌کند. **uint8_t** را بنویسید.

```cpp
void Aspose::Slides::Export::PdfOptions::set_JpegQuality(uint8_t value) override
```

## توضیحات


تنها زمانی مؤثر است که سند شامل تصاویر JPEG باشد.

از این ویژگی برای دریافت یا تنظیم کیفیت تصاویر داخل یک سند هنگام ذخیره در قالب PDF استفاده کنید. مقدار می‌تواند از 0 تا 100 متفاوت باشد که در آن 0 به معنی بدترین کیفیت اما حداکثر فشرده‌سازی و 100 به معنی بهترین کیفیت اما حداقل فشرده‌سازی است.

مقدار پیش‌فرض **100** است.
