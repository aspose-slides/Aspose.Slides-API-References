## PdfOptions::set_EmbedTrueTypeFontsForASCII(bool) متد

تعیین می‌کند که آیا [Aspose.Slides](../../../aspose.slides/) فونت‌های رایج را برای متن ASCII (محدوده کد 33..127) جاسازی خواهد کرد. [Fonts](../../../aspose.slides/fonts/) برای کدهای کاراکتر بزرگ‌تر از 127 همیشه جاسازی می‌شوند. فهرست فونت‌های رایج شامل 14 فونت پایه PDF و فونت‌های کاربر تعریف‌شده اضافه می‌باشد. نوشتن **bool**.

```cpp
void Aspose::Slides::Export::PdfOptions::set_EmbedTrueTypeFontsForASCII(bool value) override
```

## توضیحات

پیش‌فرض **true** است.
