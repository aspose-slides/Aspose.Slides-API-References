## HandleRepeatedSpaces enum

مشخص می‌کند که کاراکترهای فضا (space) تکراری معمولی در زمان خروجی‌گیری Markdown چگونه باید مدیریت شوند.

```cpp
enum class HandleRepeatedSpaces
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| None | 0 | تمام فضاها به‌عنوان کاراکترهای فضا معمولی بدون هیچ تغییری حفظ می‌شوند. هیچ تبدیلی اعمال نمی‌شود و فضاهای متوالی متعدد همان‌گونه صادر می‌شوند. |
| AlternateSpacesToNbsp | 1 | دنباله‌های دو یا بیشتر فضاهای معمولی متوالی را با جابجا کردن بین کاراکترهای فضا معمولی و نهادهای فضای غیرشکن (**&nbsp;**) تبدیل می‌کند. اولین فضا همیشه به‌عنوان یک فضا معمولی حفظ می‌شود. |
| MultipleSpacesToNbsp | 2 | دنباله‌های دو یا بیشتر فضاهای معمولی متوالی را با حفظ اولین فضا به‌عنوان کاراکتر فضا معمولی و جایگزینی همه فضاهای بعدی با نهادهای فضای غیرشکن (**&nbsp;**) تبدیل می‌کند. |
