## CompressionLevel enum

سطوح فشرده‌سازی ZIP را برای فایل OpenXML مشخص می‌کند. سطوح بالاتر فشرده‌سازی بهتر ولی با هزینه پردازش کندتر فراهم می‌کنند.

```cpp
enum class CompressionLevel
```

### Values

| نام | مقدار | توضیح |
| --- | --- | --- |
| None | 0 | هیچ فشرده‌سازی‌ای اعمال نمی‌شود. فایل‌ها همان‌طور که هستند ذخیره می‌شوند. |
| Level1 | 1 | سریع‌ترین فشرده‌سازی با کم‌ترین نسبت فشرده‌سازی. |
| Level2 | 2 | فشرده‌سازی سریع‌تر با نسبت فشرده‌سازی اندکی بهتر نسبت به [CompressionLevel::Level1](./). |
| Level3 | 3 | فشرده‌سازی بهتری نسبت به [CompressionLevel::Level2](./) ارائه می‌دهد با تأثیر متوسط بر عملکرد. |
| Level4 | 4 | فشرده‌سازی بهتری نسبت به [CompressionLevel::Level3](./) ارائه می‌دهد. |
| Level5 | 5 | فشرده‌سازی بهبود یافته‌ای نسبت به [CompressionLevel::Level4](./) فراهم می‌کند با زمان پردازش اضافی. |
| Level6 | 6 | فشرده‌سازی استاندارد، تعادلی مناسب بین سرعت فشرده‌سازی و اندازه فایل فراهم می‌کند. سطح فشرده‌سازی پیش‌فرض. |
| Level7 | 7 | فشرده‌سازی بالاتری نسبت به [CompressionLevel::Level6](./) ارائه می‌دهد با پردازش کندتر. |
| Level8 | 8 | فشرده‌سازی بالاتری نسبت به [CompressionLevel::Level7](./) فراهم می‌کند. |
| Level9 | 9 | حداکثر فشرده‌سازی. کوچک‌ترین اندازه فایل را با کندترین سرعت پردازش تولید می‌کند. |
