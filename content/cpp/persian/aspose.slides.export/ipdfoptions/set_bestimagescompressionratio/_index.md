## IPdfOptions::set_BestImagesCompressionRatio(bool) متد


مشخص می‌کند که آیا فشرده‌سازی مؤثرترین (به‌جای حالت پیش‌فرض) برای هر تصویر باید به‌صورت خودکار انتخاب شود. اگر به **bool**.true تنظیم شود، برای هر تصویر در ارائه‌نامه، الگوریتم فشرده‌سازی مناسب‌ترین انتخاب می‌شود که منجر به کوچکتر شدن اندازه سند PDF می‌شود.

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_BestImagesCompressionRatio(bool value)=0
```
