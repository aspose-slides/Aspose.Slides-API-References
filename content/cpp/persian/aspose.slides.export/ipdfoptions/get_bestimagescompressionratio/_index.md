## IPdfOptions::get_BestImagesCompressionRatio() متد

نشان می‌دهد آیا فشرده‌سازی مؤثرترین (به جای فشرده‌سازی پیش‌فرض) برای هر تصویر باید به‌صورت خودکار انتخاب شود. اگر به **bool**.true تنظیم شود، برای هر تصویر در ارائه، مناسب‌ترین الگوریتم فشرده‌سازی انتخاب می‌شود که منجر به کوچک‌تر شدن اندازهٔ سند PDF تولید شده می‌گردد.

```cpp
virtual bool Aspose::Slides::Export::IPdfOptions::get_BestImagesCompressionRatio()=0
```

انتخاب بهترین نسبت فشرده‌سازی تصویر از لحاظ محاسباتی هزینه‌بر است و مقدار اضافی RAM مصرف می‌کند، و این گزینه به‌صورت پیش‌فرض **bool**.false است.
