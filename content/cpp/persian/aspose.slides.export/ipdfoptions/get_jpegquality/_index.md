## IPdfOptions::get_JpegQuality() متد


یک مقدار را برمی‌گرداند که کیفیت تصاویر JPEG داخل سند PDF را تعیین می‌کند. خواندنی **uint8_t**.

```cpp
virtual uint8_t Aspose::Slides::Export::IPdfOptions::get_JpegQuality()=0
```

## توضیحات


تنها زمانی مؤثر است که سندی حاوی تصاویر JPEG باشد.

از این ویژگی برای دریافت یا تنظیم کیفیت تصاویر داخل سند هنگام ذخیره به قالب PDF استفاده کنید. مقدار می‌تواند بین 0 تا 100 باشد که 0 به معنی پایین‌ترین کیفیت ولی بیشترین فشرده‌سازی و 100 به معنی بالاترین کیفیت ولی کمترین فشرده‌سازی است.

مقدار پیش‌فرض **100** است.
