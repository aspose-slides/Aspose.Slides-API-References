## HtmlOptions::get_JpegQuality() متد

مقداری را برمی‌گرداند که کیفیت تصاویر JPEG داخل سند PDF را تعیین می‌کند. خواندنی **uint8_t**.

```cpp
uint8_t Aspose::Slides::Export::HtmlOptions::get_JpegQuality() override
```

## توضیحات

فقط زمانی اثر دارد که سند شامل تصاویر JPEG باشد.

از این ویژگی برای دریافت یا تنظیم کیفیت تصاویر داخل یک سند هنگام ذخیره در فرمت PDF استفاده کنید. مقدار می‌تواند بین 0 تا 100 باشد که در آن 0 به معنای کمترین کیفیت اما بیشترین فشرده‌سازی و 100 به معنای بهترین کیفیت اما کمترین فشرده‌سازی است.

مقدار پیش‌فرض **95** است.
