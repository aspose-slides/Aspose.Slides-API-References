## FtpWebResponse کلاس

کلاس Dummy امکان لینک‌کردن کد ترجمه‌شده با ارجاعات [FtpWebResponse](./) را فراهم می‌کند، اما آن را اجرا نمی‌کند. هیچ عضو به‌درستی پیاده‌سازی شده‌ای ندارد. اشیاء این کلاس باید فقط با استفاده از تابع [System::MakeObject()](../../system/makeobject/) اختصاص داده شوند. هرگز نمونه‌ای از این نوع را روی پشته یا با استفاده از عملگر new ایجاد نکنید، زیرا منجر به خطاهای زمان‌اجرایی و/یا نقص‌های اظهاری می‌شود. همیشه این کلاس را در یک اشاره‌گر [System::SmartPtr](../../system/smartptr/) بپیچانید و از این اشاره‌گر برای پاس کردن به توابع به‌عنوان آرگومان استفاده کنید.

```cpp
class FtpWebResponse : public System::Net::WebResponse
```
