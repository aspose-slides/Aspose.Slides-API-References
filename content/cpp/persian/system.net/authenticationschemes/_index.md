## AuthenticationSchemes enum

طرح‌های احراز هویت را فهرست می‌کند.

```cpp
enum class AuthenticationSchemes
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| None | 0 | هیچ احراز هویتی لازم نیست. |
| Digest | 1 | احراز هویت دسترسی Digest. |
| Negotiate | 2 | با مشتری توافق می‌کند که کدام طرح احراز هویت استفاده شود (NTML یا Kerberos). |
| Ntlm | 4 | احراز هویت NTLM. |
| Basic | 8 | احراز هویت Basic. |
| Anonymous | 32768 | احراز هویت Anonymous. |
| IntegratedWindowsAuthentication | n/a | [Windows](../../system.windows/) احراز هویت. |
