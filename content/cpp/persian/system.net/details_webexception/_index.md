## Details_WebException کلاس

نمایانگر استثنایی است که توسط [WebRequest](../webrequest/) در صورت بروز خطا پرتاب می‌شود. هرگز نمونه‌های این کلاس را به صورت دستی ایجاد نکنید. به‌جای آن از کلاس WebException استفاده کنید. هرگز نمونه‌های کلاس WebException را داخل [System::SmartPtr](../../system/smartptr/) پیچ ندهید.

```cpp
class Details_WebException : public System::Details_InvalidOperationException
```
