## Details_Win32Exception کلاس

یک استثنا برای کد خطای Win32 پرتاب می‌کند. هرگز نمونه‌هایی از این کلاس را به‌صورت دستی ایجاد نکنید. به‌جای آن از کلاس Win32Exception استفاده کنید. هرگز نمونه‌های کلاس Win32Exception را درون [System::SmartPtr](../../system/smartptr/) نپیچید.

```cpp
class Details_Win32Exception : public System::Details_ExceptionWithErrorCode<Details_SystemException>
```
