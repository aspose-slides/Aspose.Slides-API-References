## TypeDescriptor کلاس

کلاس ساختگی برای کدهای استفاده‌کننده از TypeDescriptor که پس از ترجمه کامپایل شوند. اشیاء این کلاس باید فقط با استفاده از تابع [System::MakeObject()](../../system/makeobject/) اختصاص یابند. هرگز نمونه‌ای از این نوع را روی پشته یا با استفاده از operator new ایجاد نکنید، زیرا منجر به خطاهای زمان اجرا و/یا خطاهای تأیید می‌شود. همیشه این کلاس را در یک اشاره‌گر [System::SmartPtr](../../system/smartptr/) بپیچید و از این اشاره‌گر برای عبور به‌عنوان آرگومان به توابع استفاده کنید.

```cpp
class TypeDescriptor : public System::Object
```
