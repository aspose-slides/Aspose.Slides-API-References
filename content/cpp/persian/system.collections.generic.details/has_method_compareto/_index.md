## has_method_compareto ساختار

بررسی می‌کند که آیا متد CompareTo در نوع مشخص وجود دارد یا نه. اگر وجود داشته باشد، از std::true_type ارث می‌برد، در غیر این صورت از std::false_type ارث می‌برد. می‌تواند در std::enable_if استفاده شود.

```cpp
template<typename T,typename Sfinae>class has_method_compareto : public std::false_type
```

### پارامترهای قالب

| Parameter | Description |
| --- | --- |
| T | نوعی برای بررسی وجود متد Equals. |
| Sfinae | آرگومان قالبی رسمی برای کارکرد SFINAE. |
