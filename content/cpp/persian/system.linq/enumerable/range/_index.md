## Enumerable::Range(int32_t, int32_t) متد

یک دنباله از اعداد صحیح را در یک بازهٔ مشخص تولید می‌کند.

```cpp
static SharedPtr<Collections::Generic::IEnumerable<int32_t>> System::Linq::Enumerable::Range(int32_t start, int32_t count)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| start | **int32_t** | مقدار اولین عدد صحیح در دنباله. |
| count | **int32_t** | تعداد اعداد صحیح متوالی که باید تولید شود. |

### مقدار بازگشت

یک IEnumerable از **int32_t** که شامل یک بازه از اعداد صحیح متوالی است.
