## SoapServiceRoutingStyle enum

گزینه‌های نحوه مسیریابی پیام SOAP به سرویس XML [Web](../../system.web/) را فهرست می‌کند.

```cpp
enum class SoapServiceRoutingStyle
```

### مقادیر

| نام | مقدار | شرح |
| --- | --- | --- |
| SoapAction | 0 | پیام SOAP بر اساس ویژگی 'SOAPAction' مسیریابی می‌شود. |
| RequestElement | 1 | پیام SOAP بر اساس اولین عنصر فرزند پس از عنصر 'Body' مسیریابی می‌شود. |
