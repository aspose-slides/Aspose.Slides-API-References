```cpp
enum class SoapHeaderDirection
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| In | 1 | گیرنده‌ی هدر SOAP سرویس XML [Web](../../system.web/) است. |
| InOut | 3 | گیرندگان هدر SOAP هم سرویس XML [Web](../../system.web/) و هم سرویس‌کلاینت XML [Web](../../system.web/) هستند. |
| Out | 2 | گیرنده‌ی هدر SOAP سرویس‌کلاینت XML [Web](../../system.web/) است. |
| Fault | 4 | هدر SOAP به سرویس‌کلاینت XML [Web](../../system.web/) ارسال می‌شود زمانی که استثنایی توسط متد سرویس XML [Web](../../system.web/) پرتاب می‌شود. |
