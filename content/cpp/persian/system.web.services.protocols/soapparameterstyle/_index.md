## SoapParameterStyle enum

Enumerates the parameters formats in a SOAP message.

```cpp
enum class SoapParameterStyle
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| Default | 0 | اگر '[SoapDocumentServiceAttribute](../soapdocumentserviceattribute/)' به class اعمال نشده باشد، مقدار پیش‌فرض 'Wrapped' است. |
| Bare | 1 | پارامترها در عناصر XML قرار می‌گیرند که پس از عنصر 'Body' می‌آیند. |
| Wrapped | 2 | پارامترها در یک عنصر XML واحد که پس از عنصر 'Body' می‌آید، محصور می‌شوند. |
