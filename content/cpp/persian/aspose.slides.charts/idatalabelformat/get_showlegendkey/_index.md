## IDataLabelFormat::get_ShowLegendKey() متد


رفتار نمایش کلید افسانه برچسب داده‌ای یک نمودار مشخص را توصیف می‌کند. اگر کلید افسانه برچسب داده‌ای قابل مشاهده باشد، مقدار True برگردانده می‌شود. خواندنی **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowLegendKey()=0
```
## توضیحات


اگر والد این شیء [DataLabelFormat](../../datalabelformat/) یک مجموعه [DataLabelCollection](../../datalabelcollection/) از برچسب‌های داده باشد، این ویژگی مقدار پیش‌فرض ویژگی ShowLegendKey را برای برچسب‌های داده جدید در مجموعه [DataLabelCollection](../../datalabelcollection/) دریافت یا تنظیم می‌کند. تنظیم این ویژگی با مقدار، همین مقدار را برای ویژگی ShowLegendKey تمام برچسب‌های داده در مجموعه [DataLabelCollection](../../datalabelcollection/) نیز تنظیم می‌کند (به عنوان مثال "DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;" منجر می‌شود که تمام DataLabels[i].ShowLegendKey برابر با val باشد).
