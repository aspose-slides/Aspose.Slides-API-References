## IDataLabelFormat::set_Separator(System::String) متد

یک Variant که جداکننده مورد استفاده برای برچسب‌های داده در نمودار را نمایش می‌دهد، تنظیم یا باز می‌گرداند. [System::String](../../../system/string/) را بنویسید.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_Separator(System::String value)=0
```

## ملاحظات

اگر والد این شیء [DataLabelFormat](../../datalabelformat/) یک مجموعه [DataLabelCollection](../../datalabelcollection/) از برچسب‌های داده باشد، این ویژگی مقدار پیش‌فرض ویژگی Separator را برای برچسب‌های داده جدید در مجموعه [DataLabelCollection](../../datalabelcollection/) دریافت یا تنظیم می‌کند. تنظیم این ویژگی با مقدار، همین مقدار را برای ویژگی Separator تمام برچسب‌های داده در مجموعه [DataLabelCollection](../../datalabelcollection/) تنظیم می‌نماید (به عنوان مثال "DataLabels.DefaultDataLabelFormat.Separator = val;" موجب می‌شود که همه DataLabels[i].Separator برابر با val باشد).
