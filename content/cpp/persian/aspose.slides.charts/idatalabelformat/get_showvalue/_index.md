## IDataLabelFormat::get_ShowValue() متد


نمایانگر رفتار نمایش مقدار درصد برچسب دادهٔ یک نمودار مشخص. مقدار True مقدار درصد را نمایش می‌دهد. مقدار False مخفی می‌کند. خواندنی **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowValue()=0
```

## توضیحات


اگر والد این شیء [DataLabelFormat](../../datalabelformat/) یک مجموعهٔ [DataLabelCollection](../../datalabelcollection/) از برچسب‌های داده باشد، این ویژگی مقدار پیش‌فرض ویژگی ShowValue را برای برچسب‌های دادهٔ جدید در مجموعهٔ [DataLabelCollection](../../datalabelcollection/) دریافت یا تنظیم می‌کند. تنظیم این ویژگی با مقدار همچنین این مقدار را برای ویژگی ShowValue تمام برچسب‌های داده در مجموعهٔ [DataLabelCollection](../../datalabelcollection/) تنظیم می‌گردد (به عنوان مثال \"DataLabels.DefaultDataLabelFormat.ShowValue = val;\" باعث می‌شود تمام DataLabels[i].ShowValue برابر با val باشد).
