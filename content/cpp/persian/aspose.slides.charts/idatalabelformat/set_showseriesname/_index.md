## IDataLabelFormat::set_ShowSeriesName(bool) متد

یک مقدار بولی را تنظیم می‌کند تا رفتار نمایش نام سری برای برچسب‌های داده در یک نمودار را نشان دهد. برای نمایش نام سری مقدار True را قرار دهید. برای مخفی کردن مقدار False را قرار دهید. نوشتن **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowSeriesName(bool value)=0
```

## ملاحظات

اگر والد این [DataLabelFormat](../../datalabelformat/) شیء یک [DataLabelCollection](../../datalabelcollection/) مجموعه از برچسب‌های داده باشد، این خاصیت مقدار پیش‌فرض خاصیت ShowSeriesName را برای برچسب‌های داده جدید در مجموعهٔ [DataLabelCollection](../../datalabelcollection/) دریافت یا تنظیم می‌کند. تنظیم این خاصیت با مقدار، این مقدار را برای خاصیت ShowSeriesName تمام برچسب‌های داده در مجموعهٔ [DataLabelCollection](../../datalabelcollection/) نیز تنظیم می‌کند (به عنوان مثال "DataLabels.DefaultDataLabelFormat.ShowSeriesName = val;" باعث می‌شود تمام DataLabels[i].ShowSeriesName برابر با val باشد).
