## IDataLabelFormat::set_ShowBubbleSize(bool) متد

نمایانگر رفتار نمایش مقدار اندازه حباب برچسب داده‌ای نمودار مشخص‌شده است. مقدار True مقدار اندازه حباب را نمایش می‌دهد. مقدار False مخفی می‌کند. نوشتن **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowBubbleSize(bool value)=0
```

## توضیحات

اگر والد این شیء [DataLabelFormat](../../datalabelformat/) یک مجموعه [DataLabelCollection](../../datalabelcollection/) از برچسب‌های داده باشد، این ویژگی مقدار پیش‌فرض ویژگی ShowBubbleSize را برای برچسب‌های دادهٔ جدید در مجموعه [DataLabelCollection](../../datalabelcollection/) دریافت یا تنظیم می‌کند. تنظیم این ویژگی با مقدار، همچنین این مقدار را برای ویژگی ShowBubbleSize تمام برچسب‌های داده در مجموعه [DataLabelCollection](../../datalabelcollection/) تنظیم می‌کند (به عنوان مثال "DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;" که باعث می‌شود همه‌ DataLabels[i].ShowBubbleSize برابر با val باشد).
