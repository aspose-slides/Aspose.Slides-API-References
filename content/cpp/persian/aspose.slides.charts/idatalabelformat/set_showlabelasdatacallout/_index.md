## IDataLabelFormat::set_ShowLabelAsDataCallout(bool) متد

تعیین می‌کند که برچسب دادهٔ نمودار مشخص شده به‌صورت فراخوان داده یا به‌صورت برچسب داده نمایش داده شود.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowLabelAsDataCallout(bool value)=0
```

## توضیحات

اگر والد این شیء [DataLabelFormat](../../datalabelformat/) یک مجموعهٔ [DataLabelCollection](../../datalabelcollection/) برچسب‌های داده باشد، این ویژگی مقدار پیش‌فرض ویژگی ShowLabelAsDataCallout را برای برچسب‌های دادهٔ جدید در مجموعهٔ [DataLabelCollection](../../datalabelcollection/) دریافت یا تنظیم می‌کند. تنظیم این ویژگی با مقدار، همین مقدار را برای ویژگی ShowLabelAsDataCallout تمام برچسب‌های داده در مجموعهٔ [DataLabelCollection](../../datalabelcollection/) تنظیم می‌کند (به این معنی که "DataLabels.DefaultDataLabelFormat.ShowLabelAsDataCallout = val;" باعث می‌شود که تمام DataLabels[i].ShowLabelAsDataCallout برابر با val باشد).
