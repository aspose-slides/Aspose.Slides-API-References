## IDataLabelFormat::set_ShowLegendKey(bool) متد


رفتار نمایش کلید افسانه برچسب دادهٔ یک نمودار مشخص را نشان می‌دهد. در صورتی که کلید افسانه برچسب داده قابل مشاهده باشد true است. نوشتن **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowLegendKey(bool value)=0
```

## توضیحات


اگر والد این شیء [DataLabelFormat](../../datalabelformat/) یک مجموعهٔ [DataLabelCollection](../../datalabelcollection/) از برچسب‌های داده باشد، این خصوصیت مقدار پیش‌فرض ویژگی ShowLegendKey را برای برچسب‌های داده جدید در مجموعهٔ [DataLabelCollection](../../datalabelcollection/) دریافت یا تنظیم می‌کند. تنظیم این خصوصیت با مقدار، همین مقدار را برای ویژگی ShowLegendKey تمام برچسب‌های داده در مجموعهٔ [DataLabelCollection](../../datalabelcollection/) نیز تنظیم می‌نماید (به عنوان مثال \"DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;\" باعث می‌شود که تمام DataLabels[i].ShowLegendKey برابر با val باشد).
