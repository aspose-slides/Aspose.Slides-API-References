## IDataLabelFormat::get_ShowPercentage() متد

نمایش رفتار مقدار درصد برچسب داده یک نمودار مشخص را نشان می‌دهد. مقدار true مقدار درصد را نمایش می‌دهد. مقدار false برای مخفی کردن استفاده می‌شود. مقدار **bool** خوانده می‌شود.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowPercentage()=0
```

## توضیحات

اگر والد این شیء [DataLabelFormat](../../datalabelformat/) یک مجموعه [DataLabelCollection](../../datalabelcollection/) از برچسب‌های داده باشد، این ویژگی مقدار پیش‌فرض ویژگی ShowPercentage را برای برچسب‌های داده جدید در مجموعه [DataLabelCollection](../../datalabelcollection/) دریافت یا تنظیم می‌کند. تنظیم این ویژگی با مقدار، همچنین این مقدار را برای ویژگی ShowPercentage تمام برچسب‌های داده در مجموعه [DataLabelCollection](../../datalabelcollection/) تنظیم می‌گیرد (به عنوان مثال "DataLabels.DefaultDataLabelFormat.ShowPercentage = val;" باعث می‌شود همه DataLabels[i].ShowPercentage برابر با val باشد).
