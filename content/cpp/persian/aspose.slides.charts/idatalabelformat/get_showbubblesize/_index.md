## IDataLabelFormat::get_ShowBubbleSize() متد

رفتار نمایش مقدار حجم حباب برچسب دادهٔ یک نمودار مشخص را توصیف می‌کند. مقدار True حجم حباب را نمایش می‌دهد. مقدار False برای مخفی کردن. خواندنی **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowBubbleSize()=0
```

## توضیحات

اگر والد این شیء [DataLabelFormat](../../datalabelformat/) یک مجموعهٔ [DataLabelCollection](../../datalabelcollection/) از برچسب‌های داده باشد، این ویژگی مقدار پیش‌فرض ویژگی ShowBubbleSize را برای برچسب‌های دادهٔ جدید در مجموعهٔ [DataLabelCollection](../../datalabelcollection/) دریافت یا تنظیم می‌کند. تنظیم این ویژگی با مقدار، همچنین این مقدار را برای ویژگی ShowBubbleSize تمام برچسب‌های داده در مجموعهٔ [DataLabelCollection](../../datalabelcollection/) تنظیم می‌کند (به عنوان مثال "DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;" باعث می‌شود تمام DataLabels[i].ShowBubbleSize برابر با val شود).
