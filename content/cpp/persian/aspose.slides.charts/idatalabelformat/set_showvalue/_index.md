## IDataLabelFormat::set_ShowValue(bool) متد


رفتار نمایش مقدار درصد برچسب دادهٔ نمودار مشخص شده را نشان می‌دهد. True مقدار درصد را نمایش می‌دهد. False برای مخفی کردن استفاده می‌شود. بنویسید **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowValue(bool value)=0
```

## ملاحظات


اگر والد این شیء [DataLabelFormat](../../datalabelformat/) یک مجموعهٔ [DataLabelCollection](../../datalabelcollection/) از برچسب‌های داده باشد، این ویژگی مقدار پیش‌فرض ویژگی ShowValue را برای برچسب‌های دادهٔ جدید در مجموعهٔ [DataLabelCollection](../../datalabelcollection/) دریافت یا تنظیم می‌کند. تنظیم این ویژگی با مقدار، همچنین این مقدار را برای ویژگی ShowValue تمام برچسب‌های داده در مجموعهٔ [DataLabelCollection](../../datalabelcollection/) تنظیم می‌گردد (به‌معنی "DataLabels.DefaultDataLabelFormat.ShowValue = val;" باعث می‌شود همهٔ DataLabels[i].ShowValue برابر با val باشد).
