## IDataLabelFormat::set_ShowPercentage(bool) متد


نمایانگر رفتار نمایش مقدار درصد برچسب داده‌های یک نمودار مشخص است. True مقدار درصد را نمایش می‌دهد. False برای مخفی‌کردن. مقدار **bool** نوشته می‌شود.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowPercentage(bool value)=0
```

## توضیحات


اگر والد این شیء [DataLabelFormat](../../datalabelformat/) یک مجموعه [DataLabelCollection](../../datalabelcollection/) از برچسب‌های داده باشد، این ویژگی مقدار پیش‌فرض ویژگی ShowPercentage را برای برچسب‌های داده جدید در مجموعه [DataLabelCollection](../../datalabelcollection/) دریافت یا تنظیم می‌کند. تنظیم این ویژگی با مقدار، همان مقدار را برای ویژگی ShowPercentage همه برچسب‌های داده در مجموعه [DataLabelCollection](../../datalabelcollection/) تنظیم می‌کند (به عنوان مثال "DataLabels.DefaultDataLabelFormat.ShowPercentage = val;" باعث می‌شود همه DataLabels[i].ShowPercentage برابر با val شود).
