## IDataLabelFormat::get_ShowCategoryName() متد


نمایانگر رفتار نمایش نام دسته‌بندی برچسب داده‌های یک نمودار خاص است. مقدار True برای نمایش نام دسته‌بندی برای برچسب‌های داده در نمودار است. مقدار False برای مخفی‌سازی. فقط خواندنی **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowCategoryName()=0
```

## ملاحظات


اگر والد این شیء [DataLabelFormat](../../datalabelformat/) یک [DataLabelCollection](../../datalabelcollection/) مجموعه از برچسب‌های داده باشد، این خصوصیت مقدار پیش‌فرض ویژگی ShowCategoryName را برای برچسب‌های داده جدید در مجموعه [DataLabelCollection](../../datalabelcollection/) به‌دست می‌آورد یا تنظیم می‌کند. تنظیم این خصوصیت با مقدار، همچنین این مقدار را برای ویژگی ShowCategoryName تمام برچسب‌های داده در مجموعه [DataLabelCollection](../../datalabelcollection/) تنظیم می‌کند (به‌عنوان مثال "DataLabels.DefaultDataLabelFormat.ShowCategoryName = val;" باعث می‌شود تمام DataLabels[i].ShowCategoryName برابر با val باشد).
