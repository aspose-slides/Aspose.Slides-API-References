## IDataLabelFormat::get_ShowLabelValueFromCell() متد


نمایانگر رفتار نمایش مقدار سلول برچسب دادهٔ نمودار مشخص است. True مقدار سلول را نمایش می‌دهد. False برای مخفی کردن. خواندن **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowLabelValueFromCell()=0
```

## توضیحات

اگر والد این شیء [DataLabelFormat](../../datalabelformat/) یک مجموعهٔ [DataLabelCollection](../../datalabelcollection/) از برچسب‌های داده باشد، این ویژگی مقدار پیش‌فرض ویژگی ShowLabelValueFromCell را برای برچسب‌های دادهٔ جدید در مجموعهٔ [DataLabelCollection](../../datalabelcollection/) دریافت یا تنظیم می‌کند. تنظیم این ویژگی با مقدار، همچنین این مقدار را برای ویژگی ShowLabelValueFromCell تمام برچسب‌های داده در مجموعهٔ [DataLabelCollection](../../datalabelcollection/) تنظیم می‌کند (به عنوان مثال "DataLabels.DefaultDataLabelFormat.ShowLabelValueFromCell = val;" باعث می‌شود همهٔ DataLabels[i].ShowLabelValueFromCell برابر با val باشد).
