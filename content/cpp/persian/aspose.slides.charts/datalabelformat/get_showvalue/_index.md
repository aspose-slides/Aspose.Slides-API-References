## DataLabelFormat::get_ShowValue() متد

نمایش رفتار مقدار درصد برچسب دادهٔ یک نمودار مشخص را نمایان می‌کند. مقدار true مقدار درصد را نمایش می‌دهد. مقدار false برای مخفی کردن استفاده می‌شود. خواندنی **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowValue() override
```

## توضیحات

اگر والد این شیء [DataLabelFormat](../) یک مجموعهٔ [DataLabelCollection](../../datalabelcollection/) از برچسب‌های داده باشد، این ویژگی مقدار پیش‌فرض ویژگی ShowValue را برای برچسب‌های دادهٔ جدید در مجموعهٔ [DataLabelCollection](../../datalabelcollection/) دریافت یا تنظیم می‌کند. تنظیم این ویژگی با مقدار، همچنین این مقدار را برای ویژگی ShowValue تمام برچسب‌های داده در مجموعهٔ [DataLabelCollection](../../datalabelcollection/) تعیین می‌کند (به عنوان مثال "DataLabels.DefaultDataLabelFormat.ShowValue = val;" باعث می‌شود تمام DataLabels[i].ShowValue برابر با val باشد).
