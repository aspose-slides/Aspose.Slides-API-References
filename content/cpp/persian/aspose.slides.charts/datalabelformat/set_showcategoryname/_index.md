## DataLabelFormat::set_ShowCategoryName(bool) متد

نمایش رفتار نام دسته برچسب دادهٔ یک نمودار مشخص را نشان می‌دهد. True برای نمایش نام دسته برای برچسب‌های داده در یک نمودار. False برای مخفی کردن. نوشتن **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowCategoryName(bool value) override
```

## توضیحات

اگر والد این شیء [DataLabelFormat](../) یک مجموعهٔ [DataLabelCollection](../../datalabelcollection/) از برچسب‌های داده باشد، این ویژگی مقدار پیش‌فرض ویژگی ShowCategoryName را برای برچسب‌های دادهٔ جدید در مجموعهٔ [DataLabelCollection](../../datalabelcollection/) می‌گیرد یا تنظیم می‌کند. تنظیم این ویژگی با مقدار، همچنین این مقدار را برای ویژگی ShowCategoryName تمام برچسب‌های داده در مجموعهٔ [DataLabelCollection](../../datalabelcollection/) تنظیم می‌کند (به عنوان مثال "DataLabels.DefaultDataLabelFormat.ShowCategoryName = val;" باعث می‌شود همهٔ DataLabels[i].ShowCategoryName برابر با val باشد).
