## DataLabelFormat::set_ShowValue(bool) متد

رفتار نمایش مقدار درصد برچسب دادهٔ نمودار مشخص شده را توصیف می‌کند. مقدار True مقدار درصد را نمایش می‌دهد. مقدار False برای مخفی کردن است. بنویسید **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowValue(bool value) override
```

## توضیحات

اگر والد این شیء [DataLabelFormat](../) یک مجموعهٔ [DataLabelCollection](../../datalabelcollection/) از برچسب‌های داده باشد، این ویژگی مقدار پیش‌فرض ویژگی ShowValue را برای برچسب‌های دادهٔ جدید در مجموعهٔ [DataLabelCollection](../../datalabelcollection/) دریافت یا تنظیم می‌کند. تنظیم این ویژگی با مقدار، همچنین این مقدار را برای ویژگی ShowValue تمام برچسب‌های داده در مجموعهٔ [DataLabelCollection](../../datalabelcollection/) تنظیم می‌کند (به عنوان مثال "DataLabels.DefaultDataLabelFormat.ShowValue = val;" باعث می‌شود همهٔ DataLabels[i].ShowValue برابر با val باشد).
