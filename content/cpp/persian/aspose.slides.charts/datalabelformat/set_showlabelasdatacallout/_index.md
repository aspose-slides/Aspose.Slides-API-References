## DataLabelFormat::set_ShowLabelAsDataCallout(bool) متد

مشخّص می‌کند که برچسب دادهٔ نمودار مشخص شده به‌صورت فراخوان داده نمایش داده شود یا به‌صورت برچسب داده.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLabelAsDataCallout(bool value) override
```

## توضیحات

اگر والد این [DataLabelFormat](../) شیء یک مجموعهٔ [DataLabelCollection](../../datalabelcollection/) از برچسب‌های داده باشد، این ویژگی مقدار پیش‌فرض ویژگی ShowLabelAsDataCallout را برای برچسب‌های دادهٔ جدید در مجموعهٔ [DataLabelCollection](../../datalabelcollection/) دریافت یا تنظیم می‌کند. تنظیم این ویژگی با مقدار، همچنین این مقدار را برای ویژگی ShowLabelAsDataCallout تمام برچسب‌های داده در مجموعهٔ [DataLabelCollection](../../datalabelcollection/) تنظیم می‌گردد (به عنوان مثال \"DataLabels.DefaultDataLabelFormat.ShowLabelAsDataCallout = val;\" باعث می‌شود که تمام DataLabels[i].ShowLabelAsDataCallout برابر با val باشد).
