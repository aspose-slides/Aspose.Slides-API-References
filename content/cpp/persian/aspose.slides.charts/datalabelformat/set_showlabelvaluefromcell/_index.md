## DataLabelFormat::set_ShowLabelValueFromCell(bool) متد

رفتار نمایش مقدار سلول برچسب داده برای نمودار مشخصی را نشان می‌دهد. مقدار True مقدار سلول را نمایش می‌دهد. مقدار False برای پنهان کردن استفاده می‌شود. بنویسید **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLabelValueFromCell(bool value) override
```

## توضیحات

اگر والد این شیء [DataLabelFormat](../) یک مجموعه [DataLabelCollection](../../datalabelcollection/) از برچسب‌های داده باشد، این ویژگی مقدار پیش‌فرض ویژگی ShowLabelValueFromCell را برای برچسب‌های داده جدید در مجموعه [DataLabelCollection](../../datalabelcollection/) دریافت یا تنظیم می‌کند. تنظیم این ویژگی با مقدار، همان مقدار را برای ویژگی ShowLabelValueFromCell تمام برچسب‌های داده در مجموعه [DataLabelCollection](../../datalabelcollection/) نیز تنظیم می‌نماید (مثلاً "DataLabels.DefaultDataLabelFormat.ShowLabelValueFromCell = val;" باعث می‌شود تمام DataLabels[i].ShowLabelValueFromCell برابر با val شود).
