## DataLabelFormat::get_ShowBubbleSize() متد

نمایانگر رفتار نمایش مقدار اندازه حباب برچسب داده برای یک نمودار مشخص است. True مقدار اندازه حباب را نمایش می‌دهد. False برای مخفی کردن. خواندن **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowBubbleSize() override
```

## توضیحات

اگر والد این شیء [DataLabelFormat](../) یک مجموعه [DataLabelCollection](../../datalabelcollection/) برچسب‌های داده باشد، این ویژگی مقدار پیش‌فرض ویژگی ShowBubbleSize را برای برچسب‌های داده جدید در مجموعه [DataLabelCollection](../../datalabelcollection/) دریافت یا تنظیم می‌کند. تنظیم این ویژگی با مقدار، همین مقدار را برای ویژگی ShowBubbleSize تمام برچسب‌های داده در مجموعه [DataLabelCollection](../../datalabelcollection/) تنظیم می‌کند (به عنوان مثال "DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;" باعث می‌شود تمام DataLabels[i].ShowBubbleSize برابر با val باشد).
