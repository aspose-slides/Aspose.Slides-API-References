## DataLabelFormat::set_Separator(System::String) متد

یک Variant را که جداساز استفاده‌شده برای برچسب‌های داده در یک نمودار را نشان می‌دهد، تنظیم یا برمی‌گرداند. نوشتن [System::String](../../../system/string/).

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_Separator(System::String value) override
```

## توضیحات

اگر والد این شیء [DataLabelFormat](../) یک مجموعه [DataLabelCollection](../../datalabelcollection/) از برچسب‌های داده باشد، این ویژگی مقدار پیش‌فرض ویژگی Separator را برای برچسب‌های داده جدید در مجموعه [DataLabelCollection](../../datalabelcollection/) دریافت یا تنظیم می‌کند. تنظیم این ویژگی با مقدار، همین مقدار را برای ویژگی Separator تمام برچسب‌های داده در مجموعه [DataLabelCollection](../../datalabelcollection/) تنظیم می‌کند (به عنوان مثال "DataLabels.DefaultDataLabelFormat.Separator = val;" باعث می‌شود همه DataLabels[i].Separator برابر با val باشد).
