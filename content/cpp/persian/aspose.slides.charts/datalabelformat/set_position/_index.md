## DataLabelFormat::set_Position(LegendDataLabelPosition) متد

موقعیت برچسب داده را نشان می‌دهد. [LegendDataLabelPosition](../../legenddatalabelposition/) را بنویسید.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_Position(LegendDataLabelPosition value) override
```

## توضیحات

اگر والد این شیء [DataLabelFormat](../) یک مجموعه [DataLabelCollection](../../datalabelcollection/) از برچسب‌های داده باشد، این ویژگی مقدار پیش‌فرض ویژگی Position را برای برچسب‌های داده جدید در مجموعه [DataLabelCollection](../../datalabelcollection/) دریافت یا تنظیم می‌کند. موقعیت را برای اشیاء [DataLabel](../../datalabel/) نشان می‌دهد. تنظیم این ویژگی با مقدار، این مقدار را نیز برای ویژگی Position تمام برچسب‌های داده در مجموعه [DataLabelCollection](../../datalabelcollection/) تنظیم می‌کند (مثلاً "DataLabels.DefaultDataLabelFormat.Position = val;" باعث می‌شود تمام DataLabels[i].Position برابر با val شود).
