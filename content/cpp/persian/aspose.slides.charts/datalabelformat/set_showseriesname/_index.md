## DataLabelFormat::set_ShowSeriesName(bool) متد

یک Boolean را برای نشان دادن رفتار نمایش نام سری برای برچسب‌های داده در یک نمودار تنظیم می‌کند. برای نمایش نام سری مقدار True وارد کنید. برای پنهان کردن مقدار False. نوشتن **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowSeriesName(bool value) override
```

## ملاحظات

اگر والد این شیء [DataLabelFormat](../) یک مجموعه [DataLabelCollection](../../datalabelcollection/) از برچسب‌های داده باشد، این ویژگی مقدار پیش‌فرض ویژگی ShowSeriesName را برای برچسب‌های داده جدید در مجموعه [DataLabelCollection](../../datalabelcollection/) دریافت یا تنظیم می‌کند. تنظیم این ویژگی با مقدار، آن مقدار را برای ویژگی ShowSeriesName تمام برچسب‌های داده در مجموعه [DataLabelCollection](../../datalabelcollection/) نیز تنظیم می‌کند (به عنوان مثال "DataLabels.DefaultDataLabelFormat.ShowSeriesName = val;" باعث می‌شود همه DataLabels[i].ShowSeriesName برابر با val باشد).
