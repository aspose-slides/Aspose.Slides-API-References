## DataLabelFormat::set_ShowBubbleSize(bool) متد


رفتار نمایش مقدار اندازه حباب برچسب داده یک نمودار مشخص را نشان می‌دهد. مقدار True اندازه حباب را نمایش می‌دهد. مقدار False برای مخفی کردن استفاده می‌شود. نوشتن **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowBubbleSize(bool value) override
```

## توضیحات


اگر والد این شیء [DataLabelFormat](../) یک مجموعه [DataLabelCollection](../../datalabelcollection/) از برچسب‌های داده باشد، این ویژگی مقدار پیش‌فرض ویژگی ShowBubbleSize را برای برچسب‌های داده جدید در مجموعه [DataLabelCollection](../../datalabelcollection/) دریافت یا تنظیم می‌کند. تنظیم این ویژگی با مقدار، همچنین این مقدار را برای ویژگی ShowBubbleSize تمام برچسب‌های داده در مجموعه [DataLabelCollection](../../datalabelcollection/) اعمال می‌کند (به عنوان مثال "DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;" باعث می‌شود که تمام DataLabels[i].ShowBubbleSize برابر با val باشد).
