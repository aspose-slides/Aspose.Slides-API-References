## DataLabelFormat::set_ShowLeaderLines(bool) متد


رفتار نمایش خطوط رهبری برچسب داده‌های نمودار مشخص‌شده را نشان می‌دهد. مقدار True خطوط رهبری را نمایش می‌دهد. مقدار False برای مخفی کردن. نوع **bool** نوشته می‌شود.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLeaderLines(bool value) override
```

## توضیحات


اگر والد این شیء [DataLabelFormat](../) یک مجموعه [DataLabelCollection](../../datalabelcollection/) برچسب‌های داده باشد، این ویژگی مقدار پیش‌فرض خصوصیت ShowLeaderLines را برای برچسب‌های داده جدید در مجموعه [DataLabelCollection](../../datalabelcollection/) دریافت یا تنظیم می‌کند. تنظیم این ویژگی با مقدار همچنین این مقدار را برای خصوصیت ShowLeaderLines تمام برچسب‌های داده در مجموعه [DataLabelCollection](../../datalabelcollection/) تنظیم می‌گردد (به عنوان مثال "DataLabels.DefaultDataLabelFormat.ShowLeaderLines = val;" باعث می‌شود همه DataLabels[i].ShowLeaderLines برابر با val باشد).
