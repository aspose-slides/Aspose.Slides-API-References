## DataLabelFormat::set_ShowPercentage(bool) متد

نمایش رفتار مقدار درصد برچسب داده‌های یک نمودار مشخص را توصیف می‌کند. True مقدار درصد را نمایش می‌دهد. False برای مخفی کردن. نوشتن **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowPercentage(bool value) override
```

## نکات

اگر والد این شیء [DataLabelFormat](../) یک مجموعه [DataLabelCollection](../../datalabelcollection/) از برچسب‌های داده باشد، این ویژگی مقدار پیش‌فرض ویژگی ShowPercentage را برای برچسب‌های داده جدید در مجموعه [DataLabelCollection](../../datalabelcollection/) دریافت یا تنظیم می‌کند. تنظیم این ویژگی با مقدار، همین مقدار را برای ویژگی ShowPercentage همه برچسب‌های داده در مجموعه [DataLabelCollection](../../datalabelcollection/) نیز تنظیم می‌کند (به عنوان مثال "DataLabels.DefaultDataLabelFormat.ShowPercentage = val;" منجر می‌شود که تمام DataLabels[i].ShowPercentage برابر با val باشد).
