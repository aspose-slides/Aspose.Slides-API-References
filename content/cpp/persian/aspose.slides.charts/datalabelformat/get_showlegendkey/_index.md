## DataLabelFormat::get_ShowLegendKey() متد


نمایش رفتار کلید افسانه برچسب داده برای نمودار مشخص را توصیف می‌کند. اگر کلید افسانه برچسب داده قابل مشاهده باشد، مقدار True است. خواندنی **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowLegendKey() override
```

## توضییات


اگر پدر این شیء [DataLabelFormat](../) یک مجموعه [DataLabelCollection](../../datalabelcollection/) از برچسب‌های داده باشد، این ویژگی مقدار پیش‌فرض ویژگی ShowLegendKey را برای برچسب‌های داده جدید در مجموعه [DataLabelCollection](../../datalabelcollection/) دریافت یا تنظیم می‌کند. تنظیم این ویژگی با مقدار، همچنین این مقدار را برای ویژگی ShowLegendKey تمام برچسب‌های داده در مجموعه [DataLabelCollection](../../datalabelcollection/) تنظیم می‌کند (به عنوان مثال "DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;" باعث می‌شود تمام DataLabels[i].ShowLegendKey برابر با val شود).
