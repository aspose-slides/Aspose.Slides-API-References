## DataLabelFormat::set_ShowLegendKey(bool) متد

نمایش رفتار کلید افسانه برچسب داده یک نمودار مشخص را نشان می‌دهد. True اگر کلید افسانه برچسب داده قابل مشاهده باشد. نوشت **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowLegendKey(bool value) override
```

## توضیحات

اگر والد این [DataLabelFormat](../) شیء یک مجموعه [DataLabelCollection](../../datalabelcollection/) از برچسب‌های داده باشد، این ویژگی مقدار پیش‌فرض ویژگی ShowLegendKey را برای برچسب‌های داده جدید در مجموعه [DataLabelCollection](../../datalabelcollection/) دریافت یا تنظیم می‌کند. تنظیم این ویژگی با مقدار، همان‌طور مقدار را برای ویژگی ShowLegendKey تمام برچسب‌های داده در مجموعه [DataLabelCollection](../../datalabelcollection/) تنظیم می‌کند (یعنی "DataLabels.DefaultDataLabelFormat.ShowLegendKey = val;" باعث می‌شود همه DataLabels[i].ShowLegendKey برابر با val باشد).
