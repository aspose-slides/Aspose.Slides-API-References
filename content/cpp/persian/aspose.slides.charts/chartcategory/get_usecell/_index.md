## ChartCategory::get_UseCell() متد

اگر مقدار true باشد، ویژگی AsCell فعال است. به عبارت دیگر، worksheet برای ذخیرهٔ دسته استفاده می‌شود (این حالت از دسته‌بندی چندسطحه‌ای پشتیبانی می‌کند). اگر مقدار false باشد، ویژگی AsLiteral فعال است. به عبارت دیگر، worksheet برای ذخیرهٔ دسته استفاده نمی‌شود (و این حالت از دسته‌بندی‌های چندسطحی پشتیبانی نمی‌کند). فقط-خواندنی **bool**.

```cpp
bool Aspose::Slides::Charts::ChartCategory::get_UseCell() override
```

## توضیحات

برای تغییر مقدار این ویژگی (برای همه دسته‌ها در مجموعه) مقدار جدید را به ویژگی ChartCategoryCollection::get(set)_UseCells اختصاص دهید.
