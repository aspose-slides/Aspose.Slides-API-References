## IDataLabelCollection::Hide() متد

با تنظیم همه پرچم‌های Show* (ShowValue، ...) از ویژگی DefaultDataLabelFormat به حالت false، مقدار برچسب داده به‌صورت پیش‌فرض مخفی می‌شود. IsVisible برابر false خواهد بود.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelCollection::Hide()=0
```

## توضیحات

اگر برچسب داده به‌صورت پیش‌فرض قابل مشاهده نباشد (IsVisible برابر false)، می‌توانید با تنظیم پرچم‌های Show* (ShowValue، ...) از ویژگی DefaultDataLabelFormat به حالت true، برچسب داده را «قابل مشاهده به‌صورت پیش‌فرض» کنید.
