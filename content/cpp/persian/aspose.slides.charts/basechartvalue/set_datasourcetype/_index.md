## BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType) متد


مشخص می‌کند که آیا ویژگی AsCell، AsCells، AsLiteralString یا AsLiteralDouble در توابع فرزند واقعی است. به عبارت دیگر، نوع مقدار ویژگی Data را مشخص می‌کند. بنویسید [Charts::DataSourceType](../../datasourcetype/).

```cpp
void Aspose::Slides::Charts::BaseChartValue::set_DataSourceType(Aspose::Slides::Charts::DataSourceType value) override
```

## توضیحات


برای نقاط در [ChartDataPointCollection](../../chartdatapointcollection/) این ویژگی فقط-خواندنی است. در این حالت برای تغییر مقدار این ویژگی می‌توانید از یکی از ویژگی‌های ChartDataPointCollection.DataSourceTypeFor<...> استفاده کنید.
