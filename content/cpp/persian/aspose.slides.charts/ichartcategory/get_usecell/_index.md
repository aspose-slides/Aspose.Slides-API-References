## IChartCategory::get_UseCell() متد

اگر مقدار true باشد، ویژگی AsCell فعال است. به عبارت دیگر، کاربرگ برای ذخیره‌سازی دسته‌بندی استفاده می‌شود (این حالت از دسته‌بندی چندسطحی پشتیبانی می‌کند). اگر مقدار false باشد، ویژگی AsLiteral فعال است. به عبارت دیگر، کاربرگ برای ذخیره‌سازی دسته‌بندی استفاده نمی‌شود (و این حالت از دسته‌بندی‌های چندسطحی پشتیبانی نمی‌کند). فقط-خواندنی **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IChartCategory::get_UseCell()=0
```

## توضیحات

برای تغییر مقدار این ویژگی (برای همه دسته‌بندی‌ها در مجموعه) مقدار جدید را به ویژگی ChartCategoryCollection.UseCells اختصاص دهید.
