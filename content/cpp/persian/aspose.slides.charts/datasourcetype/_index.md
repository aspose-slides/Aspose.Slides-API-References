## DataSourceType enum


انواع منبع داده.

```cpp
enum class DataSourceType
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| Worksheet | 0 | از شیءهای CellXls برای ذخیره XValue، YValue، Value یا BubbleSize نقطه داده در ورک‌شیت استفاده کنید. |
| StringLiterals | 1 | از متغیر رشته‌ای با دسترسی سریع برای ذخیره XValue، YValue، Value یا BubbleSize نقطه داده استفاده کنید. Worksheet برای ذخیره مقادیر استفاده نمی‌شود. |
| DoubleLiterals | 2 | از متغیر عددی دوبل با دسترسی سریع برای ذخیره XValue، YValue، Value یا BubbleSize نقطه داده استفاده کنید. Worksheet برای ذخیره مقادیر استفاده نمی‌شود. |
