## ParentLabelLayoutType enum

چیدمان برچسب‌های داده دسته را نشان می‌دهد. فقط برای سری‌های Treemap استفاده می‌شود.

```cpp
enum class ParentLabelLayoutType
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| Banner | 0 | مشخص می‌کند که برچسب‌های دسته والد به صورت بنر نمایش داده شوند |
| None | 1 | مشخص می‌کند که برچسب‌های دسته والد ترسیم نمی‌شوند |
| Overlapping | 2 | مشخص می‌کند که برچسب‌های دسته والد به صورت هم‌پوشانی نمایش داده شوند |
