## ChartSeries::get_PieSplitPosition() متد

مقداری را مشخص می‌کند که برای تعیین اینکه کدام نقاط داده در پای دوم یا میلهٔ دوم در نمودار pie-of-pie یا bar-of-pie قرار دارند، استفاده می‌شود. همراه با ویژگی PieSplitBy استفاده می‌شود. این ویژگی نه فقط این سری بلکه تمام سری‌های گروه سری والد را شامل می‌شود؛ این بازتاب ویژگی مناسب گروه است. بنابراین این ویژگی فقط خواندنی است. از ویژگی ParentSeriesGroup برای دسترسی به گروه سری والد استفاده کنید. برای تغییر مقدار، از ویژگی [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_PieSplitPosition() قابل خواندن/نوشتن استفاده کنید. فقط خواندنی **double**.

```cpp
double Aspose::Slides::Charts::ChartSeries::get_PieSplitPosition() override
```
