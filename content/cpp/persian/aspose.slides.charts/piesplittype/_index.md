## PieSplitType enum

نشان‌دهندهٔ نوعی از نقاط تقسیم در دایره یا نوار دوم در یک نمودار پای-پای یا بار-پای است.

```cpp
enum class PieSplitType
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| Default | 0 | مشخص می‌کند که نقاط داده باید با استفاده از مکانیزم پیش‌فرض برای این نوع نمودار تقسیم شوند. |
| Custom | 1 | مشخص می‌کند که نقاط داده باید بین پای اصلی و نمودار دوم مطابق با مقادیر تقسیم سفارشی تقسیم شوند. |
| ByPercentage | 2 | مشخص می‌کند که نقاط داده باید بین پای اصلی و نمودار دوم تقسیم شوند به‌طوری که نقاطی با درصد کمتر از Split Position در نمودار دوم قرار گیرند. |
| ByPos | 3 | مشخص می‌کند که نقاط داده باید بین پای اصلی و نمودار دوم تقسیم شوند به‌طوری که آخرین Split Position از نقاط داده در نمودار دوم قرار گیرد. |
| ByValue | 4 | مشخص می‌کند که نقاط داده باید بین پای اصلی و نمودار دوم تقسیم شوند به‌طوری که نقاطی با مقدار کمتر از Split Position در نمودار دوم قرار گیرند. |
