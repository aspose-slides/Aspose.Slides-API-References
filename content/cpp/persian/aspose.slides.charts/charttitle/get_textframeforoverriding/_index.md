## متد ChartTitle::get_TextFrameForOverriding()

می‌تواند یک متن قالب‌بندی شده غنی را شامل شود. اگر این ویژگی مقدار null نداشته باشد، این مقدار متن قالب‌بندی شده متن تولید خودکار را بازنویسی می‌کند. متن تولید خودکار یک ویژگی ضمنی از برچسب داده، برچسب واحد نمایش محور مقدار، عنوان محور، عنوان نمودار، برچسب خط روند است. متن تولید خودکار با ویژگی [IFormattedTextContainer::get_TextFormat](../../iformattedtextcontainer/get_textformat/) قالب‌بندی می‌شود. فقط-خواندنی [ITextFrame](../../../aspose.slides/itextframe/).

```cpp
System::SharedPtr<ITextFrame> Aspose::Slides::Charts::ChartTitle::get_TextFrameForOverriding() override
```
