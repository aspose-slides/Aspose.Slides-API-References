## IDataLabel::get_IsVisible() متد

False به این معنی است که برچسب داده قابل مشاهده نیست (و بنابراین همه Show*-flags (ShowValue, ...) برابر false هستند). فقط خواندنی **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabel::get_IsVisible()=0
```

## توضیحات

اگر برچسب داده قابل مشاهده باشد می‌توانید آن را با [Hide()](../hide/) متد مخفی کنید. اما اگر برچسب داده قابل مشاهده نباشد (IsVisible برابر false است) می‌توانید با تنظیم Show*-flags (ShowValue, ...) به حالت true، برچسب داده را قابل مشاهده کنید.
