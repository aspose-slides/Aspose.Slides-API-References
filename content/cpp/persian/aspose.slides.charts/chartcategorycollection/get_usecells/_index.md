## ChartCategoryCollection::get_UseCells() متد

اگر مقدار true باشد worksheet برای ذخیرهٔ دسته‌ها استفاده می‌شود (این حالت از دسته‌های چند سطحی پشتیبانی می‌کند). اگر مقدار false باشد worksheet برای ذخیرهٔ مقادیر استفاده نمی‌شود (و این حالت از دسته‌های چند سطحی پشتیبانی نمی‌کند). خوانده می‌شود **bool**.
