## ChartCategoryCollection::set_UseCells(bool) متد


اگر مقدار true باشد، worksheet برای ذخیره‌کردن دسته‌ها استفاده می‌شود (این حالت از دسته‌های چندسطحی پشتیبانی می‌کند). اگر مقدار false باشد، worksheet برای ذخیره‌کردن مقادیر استفاده نمی‌شود (و این حالت از دسته‌های چندسطحی پشتیبانی نمی‌کند). نوشتن **bool**.

```cpp
void Aspose::Slides::Charts::ChartCategoryCollection::set_UseCells(bool value) override
```
