## IChartCategoryCollection::set_UseCells(bool) متد

اگر مقدار true باشد، برگه کار برای ذخیره‌سازی دسته‌ها استفاده می‌شود (این حالت از دسته‌های چندسطحی پشتیبانی می‌کند). اگر مقدار false باشد، برگه کار برای ذخیره‌سازی مقادیر استفاده نمی‌شود (و این حالت از دسته‌های چندسطحی پشتیبانی نمی‌کند). نوشتن **bool**.

```cpp
virtual void Aspose::Slides::Charts::IChartCategoryCollection::set_UseCells(bool value)=0
```
