## IChartCategoryCollection::get_UseCells() متد

اگر true باشد، برگه‌کاری برای ذخیره دسته‌ها استفاده می‌شود (این حالت از دسته‌های چندسطحی پشتیبانی می‌کند). اگر false باشد، برگه‌کاری برای ذخیره مقادیر استفاده نمی‌شود (و این حالت از دسته‌های چندسطحی پشتیبانی نمی‌کند). خواندنی **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IChartCategoryCollection::get_UseCells()=0
```
