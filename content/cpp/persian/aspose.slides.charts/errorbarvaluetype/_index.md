## ErrorBarValueType enum

نوع مقدار نوار خطا را نشان می‌دهد

```cpp
enum class ErrorBarValueType
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| Custom | 0 | مشخص می‌کند که طول نوارهای خطا باید توسط عناصر Plus و Minus تعیین شود. |
| Fixed | 1 | مشخص می‌کند که طول نوارهای خطا باید مقدار ثابت تعیین‌شده توسط Error Bar Value باشد. |
| Percentage | 2 | مشخص می‌کند که طول نوارهای خطا باید درصد Error Bar Value از داده‌ها باشد. |
| StandardDeviation | 3 | مشخص می‌کند که طول نوارهای خطا باید انحرافات استاندارد Error Bar Value از داده‌ها باشد. |
| StandardError | 4 | مشخص می‌کند که طول نوارهای خطا باید خطاهای استاندارد Error Bar Value از داده‌ها باشد. |
