## AxisAggregationType enum

نمایانگر نوع تجمیع محور دسته‌بندی است. فقط با سری‌های Histogram یا HistogramPareto استفاده می‌شود.

```cpp
enum class AxisAggregationType
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| ByCategory | 0 | تجمیع بر اساس دسته‌ها |
| Automatic | 1 | دسته‌ها به طور خودکار تجمیع می‌شوند. |
| ByBinWidth | 2 | تجمیع بر اساس عرض سطل. ویژگی IAxis::get(set)_BinWidth باید تنظیم شود. |
| ByNumberOfBins | 3 | تجمیع بر اساس تعداد سطل‌ها. ویژگی IAxis::get(set)_NumberOfBins باید تنظیم شود. |
