## TrendlineType enum

Represents type of trend line

```cpp
enum class TrendlineType
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| Exponential | 0 | مشخص می‌کند که خط روند باید یک منحنی نمایی باشد. |
| Linear | 1 | مشخص می‌کند که خط روند باید یک خط باشد. |
| Logarithmic | 2 | مشخص می‌کند که خط روند باید یک منحنی لگاریتمی باشد، که در آن log لگاریتم طبیعی است. |
| MovingAverage | 3 | مشخص می‌کند که خط روند باید یک میانگین متحرک با دوره Period باشد. |
| Polynomial | 4 | مشخص می‌کند که خط روند باید یک منحنی چندجمله‌ای با مرتبه Order باشد. |
| Power | 5 | مشخص می‌کند که خط روند باید یک منحنی توان باشد. |
