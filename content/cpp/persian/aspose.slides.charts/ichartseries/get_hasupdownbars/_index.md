## IChartSeries::get_HasUpDownBars() method

تشخیص می‌دهد که آیا نمودار خطی یا نمودار سهام دارای نوارهای بالا/پایین است. این ویژگی نه فقط برای این سری، بلکه برای تمام سری‌های گروه سری والد است - این یک پیش‌نمایی از ویژگی مربوط به گروه می‌باشد. به همین دلیل این ویژگی فقط-خواندنی است. از ویژگی ParentSeriesGroup برای دسترسی به گروه سری والد استفاده کنید. برای تغییر مقدار، از ویژگی read/write [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get_UpDownBars()->get(set)_HasUpDownBars() استفاده کنید. برای قالب‌بندی نوارهای بالا/پایین، از ویژگی [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get_UpDownBars() استفاده کنید. فقط-خواندنی **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IChartSeries::get_HasUpDownBars()=0
```

## یادداشت‌ها
