## IChartSeries::get_GapDepth() متد


فاصله را به‌عنوان درصدی از عرض نشانگر بین مجموعه داده‌ها در یک نمودار 3 بعدی برمی‌گرداند. این ویژگی نه تنها برای این سری بلکه برای تمام سری‌های گروه سری پدر است — این یک بازتاب ویژگی گروه مناسب است. بنابراین این ویژگی فقط خواندنی است. برای دسترسی به گروه سری پدر از ویژگی ParentSeriesGroup استفاده کنید. از ویژگی [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_GapDepth() قابل خواندن/نوشتن برای تغییر مقدار استفاده کنید. فقط خواندنی **int32_t**.

```cpp
virtual int32_t Aspose::Slides::Charts::IChartSeries::get_GapDepth()=0
```
