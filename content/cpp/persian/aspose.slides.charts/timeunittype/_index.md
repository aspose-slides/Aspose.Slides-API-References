## TimeUnitType enum

واحد پایه برای محور دسته را نمایندگی می‌کند

```cpp
enum class TimeUnitType
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| None | 0 | مقدارها همان‌گونه که هستند نمایش داده می‌شوند. |
| Days | 1 | مشخص می‌کند که داده‌های نمودار باید بر حسب روز نمایش داده شوند. |
| Months | 2 | مشخص می‌کند که داده‌های نمودار باید بر حسب ماه نمایش داده شوند. |
| Years | 3 | مشخص می‌کند که داده‌های نمودار باید بر حسب سال نمایش داده شوند. |
