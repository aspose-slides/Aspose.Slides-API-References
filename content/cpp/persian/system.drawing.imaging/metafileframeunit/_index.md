## MetafileFrameUnit enum

Specifies the unit of measurement for the rectangle used to size and position a metafile.

```cpp
enum class MetafileFrameUnit
```

### Values

| نام | مقدار | توضیح |
| --- | --- | --- |
| Pixel | n/a | واحد اندازه‌گیری را به صورت پیکسل مشخص می‌کند. |
| Point | n/a | واحد اندازه‌گیری را به صورت نقطه چاپگر مشخص می‌کند. |
| Inch | n/a | واحد اندازه‌گیری را به صورت اینچ مشخص می‌کند. |
| Document | n/a | واحد اندازه‌گیری را به صورت 1/300 اینچ مشخص می‌کند. |
| Millimeter | n/a | واحد اندازه‌گیری را به صورت میلی‌متر مشخص می‌کند. |
| GdiCompatible | n/a | واحد اندازه‌گیری را به صورت .01 میلی‌متر مشخص می‌کند. برای سازگاری با GDI فراهم شده است. |
