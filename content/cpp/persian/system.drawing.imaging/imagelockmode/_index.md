## ImageLockMode enum

خصوصیات ناحیه‌ای از تصویر که قفل شده است را مشخص می‌کند.

```cpp
enum class ImageLockMode
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| ReadOnly | 1 | ناحیه فقط برای خواندن قفل شده است. |
| WriteOnly | 2 | ناحیه فقط برای نوشتن قفل شده است. |
| ReadWrite | n/a | ناحیه هم برای خواندن و هم برای نوشتن قفل شده است. |
| UserInputBuffer | 4 | تصویر در یک بافر ورودی کاربر قرار دارد که دسترسی به آن توسط کاربر کنترل می‌شود. |
