## ColorAdjustType enum

Specifies which objects use color adjustment information.

```cpp
enum class ColorAdjustType
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| Default | 0 | اطلاعات تنظیم رنگ را تعریف می‌کند که توسط تمام اشیائی که اطلاعات تنظیم رنگ خاص خود را ندارند، استفاده می‌شود. |
| Bitmap | 1 | اطلاعات تنظیم رنگ را برای اشیاء [Bitmap](../../system.drawing/bitmap/) تعریف می‌کند. |
| Brush | 2 | اطلاعات تنظیم رنگ را برای اشیاء [Brush](../../system.drawing/brush/) تعریف می‌کند. |
| Pen | 3 | اطلاعات تنظیم رنگ را برای اشیاء [Pen](../../system.drawing/pen/) تعریف می‌کند. |
| Text | 4 | اطلاعات تنظیم رنگ را برای متن تعریف می‌کند. |
| Count | 5 | تعداد انواع مشخص‌شده را تعیین می‌کند. |
| Any | 6 | تعداد انواع مشخص‌شده را تعیین می‌کند. |
