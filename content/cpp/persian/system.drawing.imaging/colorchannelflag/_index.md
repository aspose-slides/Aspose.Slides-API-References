## ColorChannelFlag enum

مشخص می‌کند که یک کانال رنگ در فضای رنگی CMYK است.

```cpp
enum class ColorChannelFlag
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| ColorChannelC | 0 | کانال رنگ سیان. |
| ColorChannelM | 1 | کانال رنگ ماژنتا. |
| ColorChannelY | 2 | کانال رنگ زرد. |
| ColorChannelK | 3 | کانال رنگ مشکی. |
| ColorChannelLast | 4 | باید از آخرین کانال انتخاب شده استفاده شود. |
