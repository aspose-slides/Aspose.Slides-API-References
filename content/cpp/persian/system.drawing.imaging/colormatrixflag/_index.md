## ColorMatrixFlag enum

انواع تصویرها و رنگ‌هایی را که تحت تأثیر تنظیمات تنظیم رنگ و خاکستری یک شیء [ImageAttributes](../imageattributes/) قرار می‌گیرند، مشخص می‌کند.

```cpp
enum class ColorMatrixFlag
```

### مقادیر

| Name | Value | Description |
| --- | --- | --- |
| Default | 0 | هر دو رنگ و مقادیر خاکستری تنظیم رنگ می‌شوند. |
| SkipGrays | 1 | مقادیر خاکستری تنظیم رنگ نمی‌شوند. |
| AltGrays | 2 | فقط مقادیر خاکستری تنظیم رنگ می‌شوند. |
