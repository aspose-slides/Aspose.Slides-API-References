## enum EmfType

انواع رکوردهایی را که در یک فایل EMF قرار می‌گیرند، مشخص می‌کند.

```cpp
enum class EmfType
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| EmfOnly | n/a | [Windows](../../system.windows/) متافایل پیشرفته. شامل دستورات GDI است. متافایل‌های این نوع به عنوان یک فایل EMF شناخته می‌شوند. |
| EmfPlusOnly | n/a | [Windows](../../system.windows/) متافایل پیشرفته پلاس. شامل دستورات GDI+ است. متافایل‌های این نوع به عنوان یک فایل EMF+ شناخته می‌شوند. |
| EmfPlusDual | n/a | متافایل پیشرفته دوگانه [Windows](../../system.windows/). شامل دستورات معادل GDI و GDI+ است. متافایل‌های این نوع به عنوان یک فایل EMF+ شناخته می‌شوند. |
