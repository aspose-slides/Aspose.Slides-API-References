## StringCollection::rbegin() متد

یک iterator معکوس به اولین عنصر از container معکوس شده را برمی‌گرداند. این iterator معادل آخرین عنصر از container غیرمعکوس است. اگر container خالی باشد، iterator برگردانده شده برابر با [rend()](../rend/) است.

```cpp
reverse_iterator System::Collections::Specialized::StringCollection::rbegin() noexcept
```

### مقدار بازگشتی

یک iterator که به آخرین عنصر container اشاره می‌کند.
