## StringCollection::crend() const متد

یک تکرارگر معکوس به عنصر پس از آخرین عنصر ظرف معکوس شده باز می‌گرداند. این متناظر با عنصر پیش از اولین عنصر ظرف غیرمعکوس است. این عنصر به‌عنوان یک جای‌دار عمل می‌کند و تلاش برای دسترسی به آن منجر به رفتار نامشخص می‌شود.

```cpp
const_reverse_iterator System::Collections::Specialized::StringCollection::crend() const noexcept
```

### مقدار بازگشتی

یک تکرارگر که به عنصر نظری const-محدود شده پیش از اولین عنصر ظرف اشاره می‌کند.
