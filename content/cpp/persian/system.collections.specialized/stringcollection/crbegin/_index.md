## StringCollection::crbegin() const متد


یک تکرارگر معکوس به اولین عنصرِ ظرف معکوس شده برمی‌گرداند. این مقدار به آخرین عنصرِ ظرف غیرمعکوس شده مربوط است. اگر ظرف خالی باشد، تکرارگر بازگردانده‌شده برابر با [crend()](../crend/) است.

```cpp
const_reverse_iterator System::Collections::Specialized::StringCollection::crbegin() const noexcept
```


### مقدار بازگشتی

یک تکرارگر که به آخرین عنصر const-qualifiedِ ظرف اشاره می‌کند.
