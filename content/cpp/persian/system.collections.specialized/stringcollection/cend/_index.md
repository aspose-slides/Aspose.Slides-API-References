## StringCollection::cend() const متد

```cpp
const_iterator System::Collections::Specialized::StringCollection::cend() const noexcept
```

### مقدار بازگشتی

یک تکرارگر که به عنصر نظری const-qualified پس از آخرین عنصر container اشاره دارد.
