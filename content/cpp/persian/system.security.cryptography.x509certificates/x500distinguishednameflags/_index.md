## X500DistinguishedNameFlags enum

قواعد قالب‌بندی نام متمایز گواهی X509.

```cpp
enum class X500DistinguishedNameFlags
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| None | 0 | هیچ ویژگی خاصی وجود ندارد. |
| Reversed | 1 | نام رزرو شده است. |
| UseSemicolons | 16 | از نقطه‌ویرگول استفاده می‌شود. |
| DoNotUsePlusSign | 32 | نام از علامت به‌علاوه استفاده نمی‌کند. |
| DoNotUseQuotes | 64 | نقل‌قول‌ها در نام غیرفعال می‌شوند. |
| UseCommas | 128 | استفاده از کاماها فعال می‌شود. |
| UseNewLines | 256 | استفاده از خطوط جدید فعال می‌شود. |
| UseUTF8Encoding | 4096 | از استفاده از یونیکد به استفاده از رمزگذاری UTF-8 تغییر می‌کند. |
| UseT61Encoding | 8192 | به رمزگذاری T61 تغییر می‌کند. |
| ForceUTF8Encoding | 16384 | استفاده از UTF-8 را هنگام رمزگذاری کلیدهای خاص X500 مجبور می‌کند. |
