## TraceLevel enum

Specifies what messages to output for the [System.Diagnostics.Debug](../debug/), [System.Diagnostics.Trace](../trace/) and System.Diagnostics.TraceSwitch classes.

```cpp
enum class TraceLevel
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| Off | 0 | هیچ پیام ردیابی و اشکال‌زدایی خروجی نمی‌دهد. |
| Error | 1 | پیام‌های مدیریت خطا خروجی می‌دهد. |
| Warning | 2 | پیام‌های هشدار و مدیریت خطا خروجی می‌دهد. |
| Info | 3 | پیام‌های اطلاعاتی، هشدار و مدیریت خطا خروجی می‌دهد. |
| Verbose | 4 | تمام پیام‌های اشکال‌زدایی و ردیابی خروجی می‌دهد. |
