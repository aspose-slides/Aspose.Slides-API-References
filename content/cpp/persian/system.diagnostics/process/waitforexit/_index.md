## Process::WaitForExit(int) متد

صبر می‌کند تا پردازش خاتمه یابد. پیاده‌سازی نشده.

```cpp
bool System::Diagnostics::Process::WaitForExit(int milliseconds)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| milliseconds | int | حداکثر تأخیر انتظار. |

### مقدار برگشتی

True اگر پردازش تمام شده باشد، false اگر زمان‌سهم بیش از حد باشد.
