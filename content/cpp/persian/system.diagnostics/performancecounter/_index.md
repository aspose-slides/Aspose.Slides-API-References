## PerformanceCounter کلاس

کلاس نمونه برای استفاده از PerformanceCounter به‌منظور ترجمه کد برای کامپایل. اشیاء این کلاس باید فقط با استفاده از تابع [System::MakeObject()](../../system/makeobject/) اختصاص داده شوند. هرگز نمونه‌ای از این نوع را بر روی پشته یا با استفاده از عملگر new ایجاد نکنید، زیرا منجر به خطاهای زمان اجرا و/یا خطاهای assert می‌شود. همیشه این کلاس را در یک اشاره‌گر [System::SmartPtr](../../system/smartptr/) بسته‌بندی کنید و از این اشاره‌گر برای عبور به‌عنوان آرگومان به توابع استفاده کنید.

```cpp
class PerformanceCounter : public System::Object
```
