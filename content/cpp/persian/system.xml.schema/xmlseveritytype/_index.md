## XmlSeverityType enum

نمایشگر شدت رویداد اعتبارسنجی است.

```cpp
enum class XmlSeverityType
```

### مقادیر

| Name | Value | Description |
| --- | --- | --- |
| Error | 0 | نشان می‌دهد که هنگام اعتبارسنجی سند نمونه، یک خطای اعتبارسنجی رخ داده است. این برای تعریف‌های نوع سند (DTDs) و زبان تعریف XML [Schema](../) (XSD) اعمال می‌شود. قیدهای اعتبارسنجی [Web](../../system.web/) جهانی (W3C) به‌عنوان خطا در نظر گرفته می‌شوند. اگر هیچ هندلر رویداد اعتبارسنجی ایجاد نشده باشد، خطاها یک exception پرتاب می‌کنند. |
| Warning | 1 | نشان می‌دهد که یک رویداد اعتبارسنجی رخ داده است که خطا نیست. یک هشدار معمولاً زمانی صادر می‌شود که DTD وجود نداشته باشد یا XML [Schema](../) برای اعتبارسنجی یک عنصر یا ویژگی خاص موجود نباشد. برخلاف خطاها، هشدارها در صورت عدم وجود هندلر رویداد اعتبارسنجی exception پرتاب نمی‌کنند. |
