## XmlAtomicValue::get_IsNode() متد

یک مقدار برمی‌گرداند که نشان می‌دهد آیا عنصر یا ویژگی XML معتبر یک گره [XPath](../../../system.xml.xpath/) است یا یک مقدار اتمی.

```cpp
bool System::Xml::Schema::XmlAtomicValue::get_IsNode() override
```

### مقدار بازگشت

**true** اگر عنصر یا ویژگی XML معتبر یک گره [XPath](../../../system.xml.xpath/) باشد؛ **false** اگر عنصر یا ویژگی XML معتبر یک مقدار اتمی باشد.
