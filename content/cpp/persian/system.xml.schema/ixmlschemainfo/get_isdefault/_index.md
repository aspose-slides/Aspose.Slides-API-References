```cpp
virtual bool System::Xml::Schema::IXmlSchemaInfo::get_IsDefault()=0
```

### مقدار بازگشت

**true** اگر این گره XML معتبر به عنوان نتیجه اعمال یک مقدار پیش‌فرض در طول اعتبارسنجی طرح‌نامه تنظیم شده باشد؛ در غیر این صورت، **false**.
