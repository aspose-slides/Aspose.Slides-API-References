```cpp
enum class InferenceOption
```

### Values

| نام | مقدار | توضیح |

| Restricted | 0 | نشان می‌دهد که یک اعلان طرح‌بندی محدودتر برای یک عنصر یا ویژگی خاص باید استخراج شود. |
