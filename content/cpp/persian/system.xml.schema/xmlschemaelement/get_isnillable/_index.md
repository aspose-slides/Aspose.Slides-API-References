## XmlSchemaElement::get_IsNillable() متد


اطلاعی را برمی‌گرداند که نشان می‌دهد آیا **xsi:nil** می‌تواند در داده‌های نمونه رخ دهد. نشان می‌دهد آیا یک مقدار nil صریح می‌تواند به عنصر اختصاص داده شود.

```cpp
bool System::Xml::Schema::XmlSchemaElement::get_IsNillable()
```


### مقدار بازگشتی

اگر nillable برابر **true** باشد، این امکان را برای یک نمونه از عنصر فراهم می‌کند که ویژگی **nil** برابر **true** تنظیم شود. ویژگی **nil** به عنوان بخشی از فضای نام XML [Schema](../../) برای نمونه‌ها تعریف می‌شود. پیش‌فرض **false** است. اختیاری.
