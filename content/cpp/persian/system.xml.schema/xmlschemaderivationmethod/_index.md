## XmlSchemaDerivationMethod enum

روش‌های مختلفی برای جلوگیری از اشتقاق فراهم می‌کند.

```cpp
enum class XmlSchemaDerivationMethod
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| Empty | 0 | روش پیش‌فرض اشتقاق را نادیده می‌گیرد تا هر نوع اشتقاقی مجاز باشد. |
| Substitution | 1 | به اشتقاق‌ها توسط **Substitution** اشاره می‌کند. |
| Extension | 2 | به اشتقاق‌ها توسط **Extension** اشاره می‌کند. |
| Restriction | 4 | به اشتقاق‌ها توسط **Restriction** اشاره می‌کند. |
| List | 8 | به اشتقاق‌ها توسط **List** اشاره می‌کند. |
| Union | 16 | به اشتقاق‌ها توسط **Union** اشاره می‌کند. |
| All | 255 | **#all**. به تمام روش‌های اشتقاق اشاره می‌کند. |
| None | 256 | روش پیش‌فرض اشتقاق را می‌پذیرد. |
