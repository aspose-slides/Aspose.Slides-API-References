## XmlSchemaComplexType::get_BlockResolved() متد


مقدار را پس از آنکه نوع به مجموعه اطلاعات پس از اعتبارسنجی طرح (infoset) کامپایل شده باشد برمی‌گرداند. این مقدار نشان می‌دهد که نوع چگونه در زمان استفاده از **xsi:type** در سند نمونه اعمال می‌شود.

```cpp
XmlSchemaDerivationMethod System::Xml::Schema::XmlSchemaComplexType::get_BlockResolved()
```


### مقدار بازگشت

مقدار infoset پس از اعتبارسنجی طرح. مقدار پیش‌فرض **BlockDefault** روی عنصر **schema** است.
