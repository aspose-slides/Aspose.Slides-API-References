## XmlSchemaComplexType::get_IsAbstract() متد


اطلاعاتی را برمی‌گرداند که تعیین می‌کند آیا عنصر **complexType** می‌تواند در سند نمونه استفاده شود.

```cpp
bool System::Xml::Schema::XmlSchemaComplexType::get_IsAbstract()
```


### مقدار برگشتی

اگر **true** باشد، یک عنصر نمی‌تواند به‌صورت مستقیم از این عنصر **complexType** استفاده کند و باید از نوع پیچیده‌ای استفاده کند که از این عنصر **complexType** مشتق شده باشد. مقدار پیش‌فرض **false** است. اختیاری.
