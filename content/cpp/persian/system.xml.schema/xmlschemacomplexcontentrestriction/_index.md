## XmlSchemaComplexContentRestriction کلاس

عنصر **محدودیت** از XML [Schema](../) را همان‌گونه که توسط کنسرسیوم World Wide [Web](../../system.web/) (W3C) تعریف شده است، نمایش می‌دهد. این کلاس برای نوع‌های پیچیده‌ای است که مدل محتوی پیچیده آنها توسط محدودیت استخراج شده است. این محدودیت محتویات نوع پیچیده را به زیرمجموعه‌ای از نوع پیچیده ارث‌برده شده محدود می‌کند.

```cpp
class XmlSchemaComplexContentRestriction : public System::Xml::Schema::XmlSchemaContent
```

## توضیحات

اشیای این کلاس باید فقط با استفاده از تابع [System::MakeObject()](../../system/makeobject/) تخصیص داده شوند. هرگز نمونه‌های این نوع را روی پشته یا با استفاده از عملگر new ایجاد نکنید، زیرا منجر به خطاهای زمان اجرا و/یا شکست‌های اعتبارسنجی می‌شود. همیشه این کلاس را در یک اشاره‌گر [System::SmartPtr](../../system/smartptr/) بسته‌بندی کنید و از این اشاره‌گر برای عبور به توابع به عنوان آرگومان استفاده کنید.
