## XmlSchemaForm enum

نشان می‌دهد آیا صفت‌ها یا عناصر باید با پیشوند فضای‌نامی تعیین شوند یا خیر.

```cpp
enum class XmlSchemaForm
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| None | 0 | فرم عنصر و صفت در طرح‌واره مشخص نشده است. |
| Qualified | 1 | عناصر و صفت‌ها باید با یک پیشوند فضای‌نامی تعیین شوند. |
| Unqualified | 2 | عناصر و صفت‌ها نیازی به تعیین پیشوند فضای‌نامی ندارند. |
