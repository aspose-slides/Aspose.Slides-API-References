## XmlSchemaAny::get_ProcessContents() متد


اطلاعاتی را برمی‌گرداند که نحوه‌ای را که یک برنامه یا پردازشگر XML باید اعتبارسنجی اسناد XML را برای عناصری که توسط عنصر **any** مشخص شده‌اند، مدیریت کند.

```cpp
XmlSchemaContentProcessing System::Xml::Schema::XmlSchemaAny::get_ProcessContents()
```


### مقدار بازگشت

یکی از مقادیر XmlSchemaContentProcessing. اگر هیچ ویژگی **processContents** مشخص نشود، مقدار پیش‌فرض **Strict** است.
