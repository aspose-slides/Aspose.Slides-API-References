## PrintRange enum

مشخص می‌کند که کدام صفحات چاپ می‌شوند.

```cpp
enum class PrintRange
```

### مقدارها

| نام | مقدار | توضیح |
| --- | --- | --- |
| AllPages | 0 | تمام صفحات را چاپ می‌کند. |
| Selection | 1 | صفحات انتخاب‌شده را چاپ می‌کند. |
| SomePages | 2 | صفحات را از بازه مشخص‌شده چاپ می‌کند. |
| CurrentPage | 4194304 | صفحهٔ فعلی نمایش‌داده‌شده را چاپ می‌کند. |
