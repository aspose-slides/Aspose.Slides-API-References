## StandardPrintController کلاس

یک کنترل‌کننده چاپ را مشخص می‌کند که اطلاعات را به پرینتر ارسال می‌کند. اشیاء این کلاس باید فقط با استفاده از تابع [System::MakeObject()](../../system/makeobject/) تخصیص داده شوند. هرگز نمونه‌ای از این نوع را روی پشته یا با استفاده از عملگر new ایجاد نکنید، زیرا منجر به خطاهای زمان اجرا و/یا اشکالات ادعایی می‌شود. همیشه این کلاس را در یک پوینتر [System::SmartPtr](../../system/smartptr/) بپیچید و از این پوینتر برای عبور به توابع به عنوان آرگومان استفاده کنید.

```cpp
class StandardPrintController : public System::Drawing::Printing::PrintController
```
