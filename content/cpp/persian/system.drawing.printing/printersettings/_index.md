## PrinterSettings کلاس

نمایانگر تنظیمات یک چاپگر است. اشیای این کلاس باید فقط با استفاده از تابع [System::MakeObject()](../../system/makeobject/) ایجاد شوند. هرگز نمونه‌ای از این نوع را روی استک یا با استفاده از عملگر new ایجاد نکنید، چرا که منجر به خطاهای زمان اجرا و/یا شکست‌های اعتبارسنجی می‌شود. همیشه این کلاس را درون اشاره‌گر [System::SmartPtr](../../system/smartptr/) بپیچید و از این اشاره‌گر برای عبور به عنوان آرگومان به توابع استفاده کنید.

```cpp
class PrinterSettings : public System::Object
```
