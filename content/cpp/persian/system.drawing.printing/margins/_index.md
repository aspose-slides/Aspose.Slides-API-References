## Margins کلاس


حاشیه‌های یک صفحه چاپ‌شده را نشان می‌دهد. اشیاء این کلاس باید فقط با استفاده از تابع [System::MakeObject()](../../system/makeobject/) اختصاص داده شوند. هیچ‌گاه نمونه‌ای از این نوع را روی پشته یا با استفاده از عملگر new ایجاد نکنید، چرا که منجر به خطاهای زمان اجرا و/یا نقص‌های assertion می‌شود. همیشه این کلاس را در یک اشاره‌گر [System::SmartPtr](../../system/smartptr/) بپیچید و از این اشاره‌گر برای ارسال به توابع به عنوان آرگومان استفاده کنید.

```cpp
class Margins : public System::Object
```
