## کلاس IAlphaModulate

نمایانگر اثر Alpha Modulate است. مقادیر alpha (شفافیت) اثر با درصد ثابت‌ای ضرب می‌شوند. کانتینر اثر، اثری را که حاوی مقادیر alpha برای مدوله‌سازی است، مشخص می‌کند.

class IAlphaModulate : public virtual Aspose::Slides::Effects::IImageTransformOperation,
