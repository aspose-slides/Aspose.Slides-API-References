## کلاس AlphaBiLevel

نمایانگر اثر Alpha Bi-Level است. مقادیر Alpha (شفافیت) که کمتر از آستانه هستند به 0 (کاملاً شفاف) تبدیل می‌شوند و مقادیر Alpha که بزرگتر یا مساوی آستانه هستند به 100٪ (کاملاً مات) تبدیل می‌شوند.

```cpp
class AlphaBiLevel : public Aspose::Slides::Effects::ImageTransformOperation,
                     public Aspose::Slides::Effects::IAlphaBiLevel,
                     public Aspose::Slides::Effects::IVisualEffect
```
