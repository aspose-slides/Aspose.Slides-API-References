## IAlphaBiLevel کلاس

نمایانگر یک اثر Alpha Bi-Level است. مقادیر Alpha (شفافیت) که کمتر از آستانه هستند به 0 (کاملاً شفاف) و مقادیر Alpha که برابر یا بزرگتر از آستانه هستند به 100٪ (کاملاً مات) تغییر می‌یابند.

```cpp
class IAlphaBiLevel : public virtual Aspose::Slides::Effects::IImageTransformOperation,
                      public Aspose::Slides::IAccessiblePVIObject<System::SharedPtr<Aspose::Slides::Effects::IAlphaBiLevelEffectiveData>>
```
