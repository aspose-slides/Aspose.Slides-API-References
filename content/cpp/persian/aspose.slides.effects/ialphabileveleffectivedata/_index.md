## کلاس IAlphaBiLevelEffectiveData

شیء غیرقابل تغییر که نمایانگر اثر Alpha Bi-Level است. مقادیر Alpha (Opacity) کمتر از آستانه به 0 (کاملاً شفاف) و مقادیر Alpha برابر یا بزرگ‌تر از آستانه به 100٪ (کاملاً مات) تغییر می‌یابند.

```cpp
class IAlphaBiLevelEffectiveData : public virtual Aspose::Slides::Effects::IEffectEffectiveData
```
