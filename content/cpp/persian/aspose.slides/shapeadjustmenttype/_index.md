## ShapeAdjustmentType enum

انواع مختلف مقادیر تنظیم شکل را مشخص می‌کند.

```cpp
enum class ShapeAdjustmentType
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| Custom | 0 | نوع سفارشی (تنظیمات ناشناخته) |
| CornerSize | 1 | اندازهٔ گوشه‌ها را کنترل می‌کند. |
| LeftUpCorner | 2 | گوشهٔ بالا-چپ را کنترل می‌کند. |
| RightUpCorner | 3 | گوشهٔ بالا-راست را کنترل می‌کند. |
| UpCorners | 4 | گوشه‌های بالایی را کنترل می‌کند. |
| DownCorners | 5 | گوشه‌های پایینی را کنترل می‌کند. |
| Thickness | 6 | ضخامت شکل را کنترل می‌کند. |
| ArrowTailThickness | 7 | ضخامت دم پیکان را کنترل می‌کند. |
| ArrowheadLength | 8 | طول سر پیکان را کنترل می‌کند. |
| ArrowheadWidth | 9 | عرض سر پیکان را کنترل می‌کند. |
| Radius | 10 | اندازهٔ شعاع شکل یا قسمت آن را کنترل می‌کند. |
| Depth | 11 | عمق دندانه‌های چرخ‌دنده یا اثر بریده را کنترل می‌کند. |
| ShapePartOffset | 12 | جابه‌جایی یک قسمت از شکل نسبت به قسمت دیگر را کنترل می‌کند. |
| Angle | 13 | زاویهٔ شکل یا قسمت آن را کنترل می‌کند. |
| StartAngle | 14 | زاویهٔ شروع برای شکل‌های دایره‌ای و قوسی. |
| EndAngle | 15 | زاویهٔ پایان برای شکل‌های دایره‌ای و قوسی. |
| StartPointX | 16 | موقعیت X نقطهٔ شروع callout را کنترل می‌کند. |
| StartPointY | 17 | موقعیت Y نقطهٔ شروع callout را کنترل می‌کند. |
| ConnectorPoint1X | 18 | موقعیت افقی نقطهٔ تنظیم زاویهٔ callout را کنترل می‌کند. |
| ConnectorPoint1Y | 19 | موقعیت عمودی نقطهٔ تنظیم زاویهٔ callout را کنترل می‌کند. |
| ConnectorPoint2X | 20 | موقعیت افقی نقطهٔ تنظیم زاویهٔ callout را کنترل می‌کند. |
| ConnectorPoint2Y | 21 | موقعیت عمودی نقطهٔ تنظیم زاویهٔ callout را کنترل می‌کند. |
| ConnectorBendPositionX | 22 | موقعیت افقی انعطاف در کانکتور را کنترل می‌کند. |
| ConnectorBendPositionY | 23 | موقعیت عمودی انعطاف در کانکتور را کنترل می‌کند. |
| AttachY | 24 | نقطهٔ اتصال عمودی شکل را کنترل می‌کند. |
| AttachX | 25 | نقطهٔ اتصال افقی شکل را کنترل می‌کند. |
| CalloutHeight | 26 | اندازهٔ عمودی callout را کنترل می‌کند. |
| CalloutWidth | 27 | اندازهٔ افقی callout را کنترل می‌کند. |
| CalloutSize | 28 | اندازهٔ callout را کنترل می‌کند. |
| Curvature | 29 | انحنای یک خم، براکت، پیکان منحنی یا شکل. |
| HorizontalThickness | 30 | ضخامت افقی شکل گوشه‌ای را کنترل می‌کند. |
| VerticalThickness | 31 | ضخامت عمودی شکل گوشه‌ای را کنترل می‌کند. |
| VerticalSize | 32 | اندازهٔ عمودی شکل را کنترل می‌کند. |
| HorizontalSize | 33 | اندازهٔ افقی شکل را کنترل می‌کند. |
| Top | 34 | بخش بالای یک شکل را کنترل می‌کند. |
