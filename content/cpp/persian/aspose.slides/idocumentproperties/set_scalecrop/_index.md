## IDocumentProperties::set_ScaleCrop(bool) متد


نمایش حالت بندانگشتی سند را نشان می‌دهد. این عنصر را به **true** تنظیم کنید تا مقیاس‌گذاری بندانگشتی سند برای نمایش فعال شود. این عنصر را به **false** تنظیم کنید تا برش بندانگشتی سند فعال شود تا فقط بخش‌هایی که با نمایشگر سازگار هستند نشان داده شوند. **bool** بنویسید.

```cpp
virtual void Aspose::Slides::IDocumentProperties::set_ScaleCrop(bool value)=0
```
