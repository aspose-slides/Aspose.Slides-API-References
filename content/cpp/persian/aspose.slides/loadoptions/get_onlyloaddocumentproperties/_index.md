## LoadOptions::get_OnlyLoadDocumentProperties() متد


این ویژگی زمانی معنی دارد که فایل ارائه با رمز محافظت شده باشد. مقدار true به این معناست که فقط خصوصیات سند باید از یک فایل ارائه رمزگذاری‌شده بارگذاری شود و رمز عبور نادیده گرفته شود. مقدار false به این معناست که کل ارائه رمزگذاری‌شده باید با استفاده از رمز عبور صحیح بارگذاری شود. اگر ارائه رمزگذاری نشده باشد، مقدار ویژگی همیشه نادیده گرفته می‌شود. اگر خصوصیات سند یک فایل رمزگذاری‌شده عمومی نباشند و مقدار ویژگی true باشد، خصوصیات سند قابل بارگذاری نیستند و یک استثنا پرتاب خواهد شد. بخوانید **bool**.

```cpp
bool Aspose::Slides::LoadOptions::get_OnlyLoadDocumentProperties() override
```
