## LoadOptions::set_OnlyLoadDocumentProperties(bool) متد

این ویژگی در صورتی معنا دارد که فایل ارائه با رمز عبور محافظت شده باشد. مقدار true به این معنی است که فقط خصوصیات سند باید از یک فایل ارائه رمزگذاری شده بارگذاری شود و رمز عبور نادیده گرفته شود. مقدار false به این معنی است که کل ارائه رمزگذاری شده باید با استفاده از رمز عبور صحیح بارگذاری شود. اگر ارائه رمزگذاری نشده باشد، مقدار ویژگی همیشه نادیده گرفته می‌شود. اگر خصوصیات سند یک فایل رمزگذاری شده عمومی نباشند و مقدار ویژگی true باشد، خصوصیات سند قابل بارگذاری نیستند و استثنا پرتاب می‌شود. نوشتن **bool**.

void Aspose::Slides::LoadOptions::set_OnlyLoadDocumentProperties(bool value) override
