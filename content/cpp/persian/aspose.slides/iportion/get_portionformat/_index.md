## IPortion::get_PortionFormat() متد


یک شیء قالب‌بندی را برمی‌گرداند که شامل ویژگی‌های قالب‌بندی به‌صورت صریح تنظیم‌شده‌ی بخش متن است بدون اعمال وراثت. فقط خواندنی [IPortionFormat](../../iportionformat/).

```cpp
virtual System::SharedPtr<IPortionFormat> Aspose::Slides::IPortion::get_PortionFormat()=0
```

## توضیحات


شیء قالب‌بندی فقط شامل پارامترهای قالب‌بندی تعریف‌شده برای بخش فعلی است و داده‌های ارث‌بری اعمال نمی‌شوند.

برای دریافت مقادیر مؤثر شامل مقادیر ارث‌بری، از متد [IPortionFormat::GetEffective](../../iportionformat/geteffective/) استفاده کنید.
