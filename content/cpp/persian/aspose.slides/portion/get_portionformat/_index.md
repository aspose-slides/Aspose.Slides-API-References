## Portion::get_PortionFormat() متد


باز می‌گرداند شیء قالب‌بندی که شامل ویژگی‌های قالب‌بندی به‌صورت صریح تنظیم‌شدهٔ بخش متن است که هیچ ‌وراثتی اعمال نشده است. فقط‌خواندنی [IPortionFormat](../../iportionformat/).

```cpp
System::SharedPtr<IPortionFormat> Aspose::Slides::Portion::get_PortionFormat() override
```

## نکات

شیء قالب‌بندی فقط شامل پارامترهای قالب‌بندی تعریف‌شده برای بخش فعلی است و داده‌های وراثت‌شده اعمال نمی‌شوند.

برای دریافت مقادیر مؤثر شامل مقادیر وراثت‌شده، از متد [PortionFormat::GetEffective](../../portionformat/geteffective/) استفاده کنید.
