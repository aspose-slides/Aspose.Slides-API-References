## ZoomImageType enum

تعریف می‌کند که آیا شیء Zoom از پیش‌نمایش slide یا تصویر Cover استفاده می‌کند.

```cpp
enum class ZoomImageType
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| Preview | 1 | از تصویر slide یا بخش استفاده می‌شود. |
| Cover | 2 | از یک تصویر سفارشی استفاده می‌شود. |
