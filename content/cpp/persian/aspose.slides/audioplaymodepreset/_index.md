## AudioPlayModePreset enum

ثابت‌هایی که نحوه پخش صدا را تعریف می‌کنند.

```cpp
enum class AudioPlayModePreset
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| Mixed | -1 |  |
| Auto | 0 | به‌صورت خودکار پخش می‌شود. |
| OnClick | 1 | فقط زمانی که نماد کلیک شود، پخش می‌شود. |
| AllSlides | 2 | در تمام اسلایدها پخش می‌شود. لطفاً به جای آن از متد [IAudioFrame::set_PlayAcrossSlides()](../iaudioframe/set_playacrossslides/) استفاده کنید. |
| InClickSequence | 3 | به‌صورت خودکار با یک کلیک پخش می‌شود. |
