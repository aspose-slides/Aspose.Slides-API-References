## IBlobManagementOptions::set_MaxBlobsBytesInMemory(uint64_t) متد

حداکثر حجم کل (بر حسب بایت) که همه BLOBها می‌توانند در حافظه اشغال کنند را تعریف می‌کند. به طور پیش‌فرض، همه BLOBها در حافظه بارگذاری می‌شوند؛ تنها پس از رسیدن به این حد، مکانیزم‌های جایگزین (مانند فایل‌های موقت) به کار گرفته می‌شوند. نگه داشتن BLOBها در حافظه عملکرد را به حداکثر می‌رساند اما می‌تواند منجر به استفاده بالا از حافظه شود. از این ویژگی برای تطبیق رفتار با محیط یا نیازهای خود استفاده کنید.

```cpp
virtual void Aspose::Slides::IBlobManagementOptions::set_MaxBlobsBytesInMemory(uint64_t value)=0
```

## توضیحات

اگر [IBlobManagementOptions::set_IsTemporaryFilesAllowed](../set_istemporaryfilesallowed/) برابر false تنظیم شود، این مقدار نادیده گرفته می‌شود، چرا که حافظه تنها مکان ذخیره‌سازی در دسترس است و محدود کردن استفاده از BLOBهای در-حافظه هیچ اثری ندارد.

مقدار پیش‌فرض 629,145,600 بایت (600 مگابایت) است.

می‌توانید این ویژگی را روی صفر تنظیم کنید، اما مقدار کمی حداقل حافظه همچنان رزرو خواهد شد.
