## PVICachingMode enum

نمایش سطوح مختلف کش برای اشیای مؤثر PVI.

```cpp
enum class PVICachingMode
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| NoCaching | 0 | حالت کلاسیک با ایجاد هر نمونه. |
| NotDefinedOnly | 1 | از کش مقادیر مؤثر برای فرمت‌های NotDefined استفاده کنید، حالت کلاسیک برای بقیه. |
| Full | 2 | از کش مقادیر مؤثر برای تمام فرمت‌ها استفاده شود. |
