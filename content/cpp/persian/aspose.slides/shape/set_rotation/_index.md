## Shape::set_Rotation(float) متد

تعداد درجه‌هایی که شکل مشخص شده حول محور z چرخانده می‌شود را تنظیم می‌کند. مقدار مثبت نشان‌دهنده چرخش ساعت‌گرد؛ مقدار منفی نشان‌دهنده چرخش پاد ساعت‌گرد است. بنویسید **float**.

```cpp
void Aspose::Slides::Shape::set_Rotation(float value) override
```

## توضیحات

مقدار بازگردانده‌شده همیشه تعریف‌شده است (نه std::numeric_limits<float>::quiet_NaN()). مقدار اختصاص‌یافته باید تعریف‌شده باشد (نه std::numeric_limits<float>::quiet_NaN()). می‌توانید مقادیر تعریف‌نشده را برای ویژگی‌های نمونه RawFrame تنظیم کنید.
