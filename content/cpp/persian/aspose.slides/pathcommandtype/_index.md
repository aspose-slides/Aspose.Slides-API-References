## PathCommandType enum

دستورات مسیر گرافیکی را نمایش می‌دهد

```cpp
enum class PathCommandType : uint8_t
```

### مقادیر

| Name | Value | Description |
| --- | --- | --- |
| Close | 0 | مسیر هندسی را می‌بندد |
| MoveTo | 1 | موقعیت نقطه بعدی مسیر هندسی را تنظیم می‌کند |
| LineTo | 2 | خطی به مسیر هندسی اضافه می‌کند |
| ArcTo | 3 | قوس مشخص شده را به مسیر هندسی اضافه می‌کند. |
| QuadBezierTo | 4 | منحنی Bézier درجه دو را به مسیر هندسی اضافه می‌کند |
| CubicBezierTo | 5 | منحنی Bézier درجه سه را به مسیر هندسی اضافه می‌کند |
