## PersistenceType enum

روشی که برای ذخیره‌سازی ویژگی‌های کنترل ActiveX استفاده می‌شود را مشخص می‌کند.

```cpp
enum class PersistenceType
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| NotDefined | -1 | شناسه پایداری مشخص نشده است. |
| PersistPropertyBag | 0 | مشخص می‌کند که کنترل ActiveX با استفاده از پایداری مبتنی بر property-bag ذخیره می‌شود. پایداری مبتنی بر property-bag، کنترل ActiveX را از طریق مجموعه‌ای از جفت‌های نام و مقدار که داده‌های ذخیره‌شده توسط کنترل ActiveX را تعیین می‌کنند، ذخیره می‌کند. |
| PersistStream | 1 | مشخص می‌کند که کنترل ActiveX با استفاده از پایداری مبتنی بر جریان ذخیره می‌شود که از مقداردهی اولیه کنترل ActiveX به وضعیت پیش‌فرض پشتیبانی نمی‌کند. |
| PersistStreamInit | 2 | مشخص می‌کند که کنترل ActiveX با استفاده از پایداری مبتنی بر جریان ذخیره می‌شود که از مقداردهی اولیه کنترل ActiveX به وضعیت پیش‌فرض پشتیبانی می‌کند. |
| PersistStorage | 3 | مشخص می‌کند که کنترل ActiveX با استفاده از پایداری مبتنی بر ذخیره‌سازی ذخیره می‌شود. |
