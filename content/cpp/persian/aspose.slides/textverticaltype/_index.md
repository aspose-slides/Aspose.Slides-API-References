## TextVerticalType enum

```cpp
enum class TextVerticalType : int8_t
```

| نام | مقدار | توضیح |

| NotDefined | -1 | تعریف نشده. |
| Horizontal | 0 | متن افقی. |
| Vertical | 1 | متن عمودی. |
| Vertical270 | 2 | متن عمودی با زاویه ۲۷۰ درجه. |
| WordArtVertical | 3 | متن عمودی WordArt. |
| EastAsianVertical | 4 | متن عمودی آسیای شرقی. |
| MongolianVertical | 5 | متن عمودی مغولی. |
| WordArtVerticalRightToLeft | 6 | متن عمودی WordArt از راست به چپ. |
