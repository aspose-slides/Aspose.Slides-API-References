## ShapeElementStrokeSource enum

نشان می‌دهد که عنصر شکل چگونه باید رسم شود.

```cpp
enum class ShapeElementStrokeSource : uint8_t
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| NoStroke | 0 | خط‌کشی اولیه انجام نمی‌شود. |
| Shape | 1 | از [LineFormat](../lineformat/) شکل استفاده کنید. |
| OwnStroke | 2 | از خط‌کشی خود استفاده کنید. |
