## FillType enum

نوع پر کردن داخلی اشیای بصری مختلف را مشخص می‌کند.

```cpp
enum class FillType : int8_t
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| NotDefined | -1 | نوع پر کردن تعریف نشده است. |
| NoFill | 0 | بدون پر کردن اعمال شده. |
| Solid | 1 | با رنگ ثابت پر شده است. |
| Gradient | 2 | پر کردن به صورت گرادیان است. |
| Pattern | 3 | الگوی تکراری برای پر کردن شیء استفاده می‌شود. |
| Picture | 4 | یک تصویر واحد برای پر کردن شیء استفاده می‌شود. |
| Group | 5 | شیء تصویری ویژگی‌های پر کردن را از گروه به ارث می‌برد. |
