## DocumentProperties::set_ScaleCrop(bool) متد

حالت نمایش تصویر بندانگشتی سند را نشان می‌دهد. برای فعال‌سازی مقیاس‌بندی تصویر بندانگشتی سند به نمایش، این عنصر را به **true** تنظیم کنید. برای فعال‌سازی برش تصویر بندانگشتی سند به‌طوری که فقط بخش‌های مناسب برای نمایش نشان داده شوند، این عنصر را به **false** تنظیم کنید. نوع داده **bool**.

```cpp
void Aspose::Slides::DocumentProperties::set_ScaleCrop(bool value) override
```
