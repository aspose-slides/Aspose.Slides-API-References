## IProtectionManager::set_EncryptDocumentProperties(bool) متد

این ویژگی منطقی است، اگر ارائه با رمز عبور محافظت شده باشد. اگر true باشد، خصوصیات سند در فایل ارائه رمزنگاری می‌شوند. اگر false باشد، خصوصیات سند عمومی هستند در حالی که ارائه رمزنگاری شده است. مقدار **bool** نوشته می‌شود.

```cpp
virtual void Aspose::Slides::IProtectionManager::set_EncryptDocumentProperties(bool value)=0
```
