## IShape::set_Rotation(float) متد

تعداد درجه‌هایی که شکل مشخص‌شده حول محور z می‌چرخد را تنظیم می‌کند. مقدار مثبت نشان‌دهنده چرخش ساعت‌گرد است؛ مقدار منفی نشان‌دهنده چرخش پاد ساعت‌گرد است. بنویسید **float**.

```cpp
virtual void Aspose::Slides::IShape::set_Rotation(float value)=0
```

## توضیحات

مقدار برگشتی همیشه تعریف‌شده است (این مقدار std::numeric_limits<float>::quiet_NaN() نیست). مقدار اختصاص داده‌شده نیز باید تعریف‌شده باشد (نه std::numeric_limits<float>::quiet_NaN()). می‌توانید مقادیر تعریف‌نشده را برای ویژگی‌های نمونه RawFrame تنظیم کنید.
