## ColorType enum

حالت‌های رنگی مختلف را نشان می‌دهد.

```cpp
enum class ColorType
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| NotDefined | -1 | رنگ به‌طور کامل تعریف نشده است. |
| RGB | 0 | رنگ استاندارد ۲۴ بیتی RGB. |
| RGBPercentage | 1 | رنگ RGB با وضوح بالا. |
| HSL | 2 | رنگ HSL با وضوح بالا. |
| Scheme | 3 | رنگ طرح‌بندی. |
| System | 4 | [System](../../system/) رنگ. |
| Preset | 5 | رنگ پیش‌تنظیم. |
