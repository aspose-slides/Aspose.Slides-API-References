## ResourceLoadingAction enum

حالت بارگذاری منبع خارجی را مشخص می‌کند.

```cpp
enum class ResourceLoadingAction
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| Default | 0 | [Aspose.Slides](../) منبع خارجی را به‌صورت معمول بارگذاری خواهد کرد. |
| Skip | 1 | [Aspose.Slides](../) بارگذاری منبع خارجی را نادیده می‌گیرد. فقط پیوند بدون داده برای یک تصویر ذخیره خواهد شد. |
| UserProvided | 2 | [Aspose.Slides](../) آرایه بایت ارائه‌شده توسط کاربر در [IResourceLoadingArgs::SetData](../iresourceloadingargs/setdata/) را به عنوان داده تصویر استفاده خواهد کرد. |
