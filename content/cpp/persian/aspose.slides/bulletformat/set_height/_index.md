## BulletFormat::set_Height(float) متد

ارتفاع گلولهٔ یک پاراگراف را بدون ارث‌برداری تنظیم می‌کند. مقدار std::numeric_limits<float>::quiet_NaN() تعیین می‌کند که گلوله ارتفاع را از اولین بخش در پاراگراف به ارث می‌برد. نوشتن **float**.

```cpp
void Aspose::Slides::BulletFormat::set_Height(float value) override
```
