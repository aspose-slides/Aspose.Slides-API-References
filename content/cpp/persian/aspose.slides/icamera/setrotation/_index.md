## ICamera::SetRotation(float, float, float) متد

یک چرخش از طریق استفاده از مختصات عرض جغرافیایی، مختصات طول جغرافیایی و یک دورانی حول محور به عنوان مختصات عرض و طول تعریف می‌شود. اگر هر یک از مقادیر مختصات برابر با std::numeric_limits<float>::quiet_NaN() باشد، تمام چرخش نامشخص است.

```cpp
virtual void Aspose::Slides::ICamera::SetRotation(float latitude, float longitude, float revolution)=0
```
