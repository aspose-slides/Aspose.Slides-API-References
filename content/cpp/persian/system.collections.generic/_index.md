| ساختار | توضیح |

| [DictionaryHashSelector](./dictionaryhashselector/) | انتخاب‌کننده تابع هش برای کلاس [Dictionary](./dictionary/). این پیاده‌سازی از هش‌گذاری STL استفاده می‌کند در صورتی که گزینه دیگری ارائه نشده باشد. |
| [EqualityComparerAdapter](./equalitycompareradapter/) | آداپتری که امکان استفاده از [IEqualityComparer](./iequalitycomparer/) با مجموعه‌ها و الگوریتم‌های سبک STL را فراهم می‌کند. اگر [IEqualityComparer](./iequalitycomparer/) تنظیم شده باشد از آن استفاده می‌کند. اگر تنظیم نشده باشد، از عملگر ==، [Object::Equals](../system/object/equals/) یا T::Equals استفاده می‌کند، هرکدام که موجود باشد. |
| [EqualityComparerHashAdapter](./equalitycomparerhashadapter/) | آداپتری برای استفاده از [IEqualityComparer](./iequalitycomparer/) برای هش‌گذاری. اگر شیء مقایسه‌کننده تنظیم شده باشد از آن استفاده می‌کند؛ در غیر این صورت از روش هش موجود که با ساختار [DictionaryHashSelector](./dictionaryhashselector/) انتخاب می‌شود، استفاده می‌کند. |
