## ReverseEnumerator::IsValid() const متد

بررسی می‌کند که آیا [MoveNext()](../movenext/) فراخوانی شده باشد و پایان رسیده نباشد.

```cpp
bool System::Collections::Generic::ReverseEnumerator<Container, Element>::IsValid() const
```

### مقدار بازگشت

false اگر [MoveNext()](../movenext/) هیچ‌وقت فراخوانی نشده باشد یا به انتهای مخزن برسد؛ true در غیر این صورت.
