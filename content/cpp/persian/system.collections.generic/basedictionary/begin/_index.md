## BaseDictionary::begin() const متد

یک تکرارگر را به KVPair-wrapper برای عنصر کلید-مقدار کانتینر باز می‌گرداند. به سبک C# پیاده‌سازی شده است - تکرارگر باید KVPair-object را با واسط get_Key() و get_Value() بازگرداند. اگر کانتینر خالی باشد، تکرارگر بازگردانده‌شده برابر با [end()](../../ienumerable/end/) خواهد بود.

```cpp
const_iterator System::Collections::Generic::BaseDictionary<Map>::begin() const noexcept
```

### مقدار بازگشتی

یک تکرارگر که به اولین عنصر مجموعه اشاره دارد.
