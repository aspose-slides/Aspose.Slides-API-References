## BaseDictionary::cend() const متد


یک iterator را برمی‌گرداند که به عنصری که پس از آخرین عنصر در container می‌آید اشاره می‌کند. به سبک STL-style پیاده‌سازی شده است. این عنصر به عنوان یک placeholder عمل می‌کند؛ تلاش برای دسترسی به آن منجر به undefined behavior می‌شود.

```cpp
stl_const_iterator System::Collections::Generic::BaseDictionary<Map>::cend() const noexcept
```


### مقدار بازگشتی

یک iterator که به عنصر نظری const-qualified قرار گرفته پس از عنصر انتهایی collection اشاره دارد.
