## BaseDictionary::cbegin() const متد

یک iterator را برمی‌گرداند که به اولین عنصر مجموعه اشاره دارد. به سبک STL پیاده‌سازی شده است. اگر مجموعه خالی باشد، iterator بازگردانده‌شده برابر با [end()](../../ienumerable/end/) خواهد بود.

```cpp
stl_const_iterator System::Collections::Generic::BaseDictionary<Map>::cbegin() const noexcept
```

### مقدار بازگشت

یک iterator که به اولین عنصر const-qualified مجموعه اشاره می‌کند.
