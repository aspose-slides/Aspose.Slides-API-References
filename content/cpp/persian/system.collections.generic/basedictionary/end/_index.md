## BaseDictionary::end() const متد

یک تکرارگر به KVPair-wrapper برای عنصر کلید-مقداری که پس از آخرین عنصر محفظه قرار دارد برمی‌گرداند. به سبک C# پیاده‌سازی شده است — تکرارگر باید شیء KVPair-object را با رابط get_Key() و get_Value() برگرداند. این عنصر به عنوان placeholder عمل می‌کند؛ تلاش برای دسترسی به آن منجر به رفتار نامشخص می‌شود.

```cpp
const_iterator System::Collections::Generic::BaseDictionary<Map>::end() const noexcept
```

### مقدار بازگشت

یک تکرارگر که به عنصر نظری قرار گرفته پس از عنصر انتهایی مجموعه اشاره دارد.
