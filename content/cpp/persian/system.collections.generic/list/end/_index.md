## متد List::end()

یک iterator برای عنصر غیر موجودی که پشت عنصر انتهایی مجموعه قرار دارد را دریافت می‌کند.

```cpp
iterator System::Collections::Generic::List<T>::end() noexcept
```

### مقدار برگشت

یک iterator که به عنصر نظری قرار گرفته پس از عنصر انتهایی در فهرست اشاره می‌کند.

## متد List::end() const

یک iterator برای عنصر غیر موجودی که پشت عنصر انتهایی مجموعه‌ای که const-qualified است، دریافت می‌کند.

```cpp
const_iterator System::Collections::Generic::List<T>::end() const noexcept
```

### مقدار برگشت

یک iterator که به عنصر نظری قرار گرفته پس از عنصر انتهایی در نمونه const-qualified فهرست اشاره می‌کند.
