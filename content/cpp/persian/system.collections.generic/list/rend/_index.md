## List::rend() متد

یک مکرر معکوس برای عنصری غیرموجود پیش از شروع مجموعه دریافت می‌کند.

```cpp
reverse_iterator System::Collections::Generic::List<T>::rend() noexcept
```

### مقدار برگشتی

یک مکرر معکوس که به عنصر نظری پیش از اولین عنصر در لیست (آخرین در حالت معکوس) اشاره می‌کند.

## List::rend() const متد

یک مکرر معکوس برای عنصری غیرموجود پیش از شروع مجموعه‌ای که به صورت const تعریف شده دریافت می‌کند.

```cpp
const_reverse_iterator System::Collections::Generic::List<T>::rend() const noexcept
```

### مقدار برگشتی

یک مکرر معکوس که به عنصر نظری پیش از اولین عنصر در فهرست const-qualified (آخرین در حالت معکوس) اشاره می‌کند.
