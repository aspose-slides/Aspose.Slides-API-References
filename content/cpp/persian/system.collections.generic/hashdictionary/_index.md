## HashDictionary کلاس

قالب برای کلاس [HashDictionary](./) (در حال حاضر پیاده‌سازی نشده). اشیاء این کلاس باید فقط با استفاده از تابع [System::MakeObject()](../../system/makeobject/) تخصیص داده شوند. هرگز نمونه‌ای از این نوع را روی پشته یا با استفاده از operator new ایجاد نکنید، زیرا منجر به خطاهای زمان اجرا و/یا خطاهای اعتبارسنجی می‌شود. همیشه این کلاس را در یک اشاره‌گر [System::SmartPtr](../../system/smartptr/) بپیچید و از این اشاره‌گر برای عبور آن به عنوان آرگومان به توابع استفاده کنید.

```cpp
template<typename T,typename T2>class HashDictionary
```
