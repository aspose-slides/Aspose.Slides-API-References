## IComparer کلاس

رابطی که دو شی را در مفهوم بزرگتر-مساوی-کوچکتر مقایسه می‌کند. اشیاء این کلاس باید فقط با استفاده از تابع [System::MakeObject()](../../system/makeobject/) تخصیص یابند. هرگز نمونه‌ای از این نوع را روی پشته یا با استفاده از عملگر new ایجاد نکنید، زیرا منجر به خطاهای زمان اجرا و/یا خطاهای ادعا خواهد شد. همیشه این کلاس را در یک اشاره‌گر [System::SmartPtr](../../system/smartptr/) بسته‌بندی کنید و از این اشاره‌گر برای عبور آن به توابع به عنوان آرگومان استفاده کنید.

```cpp
template<typename T>class IComparer : public virtual System::Object
```
