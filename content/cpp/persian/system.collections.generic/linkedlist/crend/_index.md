## LinkedList::crend() const متد

یک iterator معکوس برای عنصری const-qualified که قبل از شروع مجموعه وجود ندارد، دریافت می‌کند.

```cpp
const_reverse_iterator System::Collections::Generic::LinkedList<T>::crend() const noexcept
```

### مقدار بازگشتی

یک iterator معکوس که به عنصر نظری const-qualified که قبل از اولین عنصر در linked list (آخرین در جهت معکوس) اشاره می‌کند.
