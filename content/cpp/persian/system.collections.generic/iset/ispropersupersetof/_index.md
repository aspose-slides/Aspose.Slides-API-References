## ISet::IsProperSupersetOf(IEnumerablePtr) method

بررسی می‌کند که آیا مجموعهٔ فعلی یک فوق‌مجموعهٔ صحیح از مخزن دیگر است.

```cpp
virtual bool System::Collections::Generic::ISet<T>::IsProperSupersetOf(IEnumerablePtr other)=0
```

### Arguments

| Parameter | Type | Description |
| --- | --- | --- |
| other | [IEnumerablePtr](../ienumerableptr/) | زیرمجموعه‌ای که مقابل آن بررسی می‌شود. |

### Return Value

True اگر تمام عناصر **other** در مجموعه موجود باشند و مجموعه عناصر بیشتری نسبت به **other** دارد، در غیر این صورت false.
