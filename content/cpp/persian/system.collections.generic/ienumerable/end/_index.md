## IEnumerable::end() متد

یک iterator را برمی‌گرداند که درست پس از آخرین عنصر (در صورت وجود) مجموعه قرار دارد. این iterator نمی‌تواند برای تغییر شیء مرجع استفاده شود زیرا [GetEnumerator()](../getenumerator/) یک شیء کپی از T را باز می‌گرداند.

```cpp
iterator System::Collections::Generic::IEnumerable<T>::end()
```

### مقدار برگشتی

یک iterator که درست پس از آخرین عنصر (در صورت وجود) مجموعه قرار دارد

## IEnumerable::end() const متد

یک iterator را برمی‌گرداند که درست پس از آخرین عنصر (در صورت وجود) نمونه const-qualified مجموعه قرار دارد.

```cpp
const_iterator System::Collections::Generic::IEnumerable<T>::end() const
```
