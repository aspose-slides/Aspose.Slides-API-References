## IEnumerable::LINQ_Any() متد

تعیین می‌کند آیا دنباله شامل حداقل یک عنصر است.

```cpp
bool System::Collections::Generic::IEnumerable<T>::LINQ_Any()
```

### Return Value

true اگر دنباله منبع شامل هر عنصر باشد؛ در غیر این صورت false.

## IEnumerable::LINQ_Any(std::function\<bool(T)>) متد

تعیین می‌کند آیا هر عنصر از یک دنباله وجود دارد یا شرطی را برآورده می‌کند.

```cpp
bool System::Collections::Generic::IEnumerable<T>::LINQ_Any(std::function<bool(T)> predicate)
```

### Arguments

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| predicate | std::function\<**bool**(T)> | یک تابع برای آزمون هر عنصر نسبت به یک شرط. |

### Return Value

true اگر دنباله منبع شامل هر عنصر باشد؛ در غیر این صورت false.
