## PaddingMode enum

نحوهٔ برخورد با پیام‌هایی که کوتاه‌تر از بلوک مورد نیاز عملیات رمزنگاری هستند را تعریف می‌کند.

```cpp
enum class PaddingMode
```

### مقادیر

| Name | Value | Description |
| --- | --- | --- |
| None | 1 | بدون پر کردن. |
| PKCS7 | 2 | از رشته پر کردن PKCS #7 استفاده کنید. |
| Zeros | 3 | از بایت‌های صفر استفاده کنید. |
| ANSIX923 | 4 | از رشته پر کردن ANSIX923 استفاده کنید. |
| ISO10126 | 5 | از رشته پر کردن ISO10126 استفاده کنید. |
