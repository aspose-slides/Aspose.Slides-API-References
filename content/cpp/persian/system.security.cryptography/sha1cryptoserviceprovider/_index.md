## SHA1CryptoServiceProvider کلاس


[SHA1](../sha1/) CSP implementation. Objects of this کلاس should only be allocated using [System::MakeObject()](../../system/makeobject/) function. Never create instance of this type on stack or using operator new, as it will result in runtime errors and/or assertion faults. Always wrap this کلاس into [System::SmartPtr](../../system/smartptr/) pointer and use this pointer to pass it to functions as argument.

```cpp
class SHA1CryptoServiceProvider : public System::Security::Cryptography::SHA1
```
