## Rfc2898DeriveBytes کلاس

پیاده‌سازی مشتق‌کلید مبتنی بر رمز عبور، PBKDF2. اشیای این کلاس باید فقط با استفاده از تابع [System::MakeObject()](../../system/makeobject/) تخصیص داده شوند. هرگز نمونه‌ای از این نوع را روی پشته یا با استفاده از operator new ایجاد نکنید، زیرا منجر به خطاهای زمان اجرا و/یا اشکالات صحت‌سنجی می‌شود. همیشه این کلاس را در یک اشاره‌گر [System::SmartPtr](../../system/smartptr/) بسته‌بندی کنید و از این اشاره‌گر برای پاس دادن به توابع به‌عنوان آرگومان استفاده کنید.

```cpp
class Rfc2898DeriveBytes : public System::Security::Cryptography::DeriveBytes
```
