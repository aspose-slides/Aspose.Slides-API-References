## RSACryptoServiceProvider::get_UseMachineKeyStore() متد


بررسی می‌کند که آیا کلید در فروشگاه ماشین به جای فروشگاه کاربر نگهداری می‌شود یا خیر.

```cpp
static bool System::Security::Cryptography::RSACryptoServiceProvider::get_UseMachineKeyStore()
```

### مقدار بازگشت

True اگر کلید باید در فروشگاه ماشین نگهداری شود، false اگر باید در فروشگاه کاربر نگهداری شود.
