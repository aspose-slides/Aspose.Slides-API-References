## توضیحات

منسوخ
:   منسوخ شده. به جای آن از [ExternalResourceResolver](../externalresourceresolver/) استفاده کنید. در انتشار 17.12 حذف خواهد شد.

استفاده از این resolver می‌تواند یک آسیب‌پذیری ایجاد کند زمانی که فایل HTML ارائه‌شده توسط مشتری باعث می‌شود نرم‌افزار سرور فایل‌های محلی یا شبکه‌ای را دریافت کند. با احتیاط استفاده کنید. توصیه می‌شود [HtmlExternalResolver](./) را اصلاً مشخص نکنید (فقط اشیاء توکار خوانده می‌شوند) یا یک زیرکلاس ایجاد کنید که بررسی کند آیا URI مشخص شده معتبر است یا نه.
