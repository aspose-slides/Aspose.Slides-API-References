## EncoderExceptionFallbackBuffer کلاس


[Buffer](../../system/buffer/) برای استراتژی بازگشت رمزگذاری که استثنا می‌اندازد. در واقع چیزی ذخیره نمی‌کند، بلکه پرتاب می‌کند. اشیاء این کلاس باید فقط با استفاده از تابع [System::MakeObject()](../../system/makeobject/) تخصیص داده شوند. هرگز نمونه‌ای از این نوع را روی پشته یا با استفاده از عملگر new ایجاد نکنید، زیرا منجر به خطاهای زمان اجرا و/یا نقص‌های اعتبارسنجی می‌شود. همیشه این کلاس را در نشانگر [System::SmartPtr](../../system/smartptr/) بپیچید و از این نشانگر برای انتقال به توابع به‌عنوان آرگومان استفاده کنید.

```cpp
class EncoderExceptionFallbackBuffer : public System::Text::EncoderFallbackBuffer
```
