## NormalizationForm enum

Defines how to normalize Unicode string.

```cpp
enum class NormalizationForm
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| FormC | 1 | از تجزیهٔ کامل کاننونی استفاده کنید، سپس توالی‌ها را با ترکیب‌های اصلیشان جایگزین کنید. |
| FormD | 2 | از تجزیهٔ کامل کاننونی استفاده کنید. |
| FormKC | 5 | از تجزیهٔ کامل سازگاری استفاده کنید، سپس توالی‌ها را با ترکیب‌های اصلیشان جایگزین کنید. |
| FormKD | 6 | از تجزیهٔ کامل سازگاری استفاده کنید. |
