## Encoding::get_IsBrowserDisplay() متد

بررسی می‌کند که آیا کدگذاری می‌تواند برای نمایش محتوا در مرورگر استفاده شود یا خیر.

```cpp
virtual bool System::Text::Encoding::get_IsBrowserDisplay()
```

### مقدار بازگشت

True اگر کدگذاری بتواند در مرورگر برای نمایش محتوا استفاده شود، در غیر این صورت false.
