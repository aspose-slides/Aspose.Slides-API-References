## RetryConditionHeaderValue کلاس

نمایانگر مقدار هدر 'Retry-After' است. اشیاء این کلاس باید فقط با استفاده از تابع [System::MakeObject()](../../system/makeobject/) ایجاد شوند. هرگز نمونه‌ای از این نوع را بر روی پشته یا با اپراتور new ایجاد نکنید، زیرا منجر به خطاهای زمان اجرا و/یا اشکال‌های تأیید می‌شود. همیشه این کلاس را در اشاره‌گر [System::SmartPtr](../../system/smartptr/) بپیچید و از این اشاره‌گر برای ارسال به توابع به عنوان آرگومان استفاده کنید.

```cpp
class RetryConditionHeaderValue : public System::ICloneable
```
