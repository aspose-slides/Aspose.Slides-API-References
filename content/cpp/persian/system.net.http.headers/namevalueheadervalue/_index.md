## NameValueHeaderValue کلاس


یک جفت کلید/مقدار برای استفاده در هدرها را نشان می‌دهد. اشیاء این کلاس باید فقط با استفاده از تابع [System::MakeObject()](../../system/makeobject/) اختصاص داده شوند. هیچ‌گاه نمونه‌ای از این نوع را روی پشته یا با استفاده از عملگر new ایجاد نکنید، زیرا منجر به خطاهای زمان اجرا و/یا اشکالات ادعا می‌شود. همیشه این کلاس را در یک اشاره‌گر [System::SmartPtr](../../system/smartptr/) بسته‌بندی کنید و از این اشاره‌گر برای پاس کردن به توابع به‌عنوان آرگومان استفاده کنید.

```cpp
class NameValueHeaderValue : public virtual System::ICloneable
```
