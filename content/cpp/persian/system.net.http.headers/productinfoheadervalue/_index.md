## ProductInfoHeaderValue کلاس

نمایانگر یک محصول یا یک توضیح در مقدار هدر 'User-Agent' است. اشیائی از این کلاس باید فقط با استفاده از تابع [System::MakeObject()](../../system/makeobject/) اختصاص داده شوند. هرگز نمونه‌ای از این نوع را روی پشته یا با استفاده از عملگر new ایجاد نکنید، زیرا منجر به خطاهای زمان اجرا و/یا اشکالات ادعا می‌شود. همیشه این کلاس را درون اشاره‌گر [System::SmartPtr](../../system/smartptr/) بپیچید و از این اشاره‌گر برای گذراندن به توابع به‌عنوان آرگومان استفاده کنید.

```cpp
class ProductInfoHeaderValue : public System::ICloneable
```
