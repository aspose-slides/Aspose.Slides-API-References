## CancellationToken::get_CanBeCanceled() const متد


مشخص می‌کند که آیا این توکن قابلیت داشتن وضعیت لغو شده را دارد یا خیر.

```cpp
bool System::Threading::CancellationToken::get_CanBeCanceled() const
```


### مقدار بازگشت

true اگر این توکن قابلیت داشتن وضعیت لغو شده را داشته باشد؛ در غیر این صورت false.
## توضیحات
