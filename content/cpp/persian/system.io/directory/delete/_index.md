## Directory::Delete(const String&, bool) متد

مسیر مشخص‌شدهٔ فایل یا دایرکتوری را حذف می‌کند. خطا پرتاب نمی‌شود.

```cpp
static void System::IO::Directory::Delete(const String &path, bool recursive=false)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| path | const [String](../../../system/string/)\& | مسیر دایرکتوری یا فایلی که باید حذف شود |
| recursive | **bool** | اگر **path** یک دایرکتوری غیر خالی را مشخص کند، **recursive** تعیین می‌کند که آیا تمام محتویات دایرکتوری به صورت بازگشتی حذف شوند؛ اگر دایرکتوری مشخص‌شده توسط **path** خالی نباشد و **recursive** برابر با 'false' باشد، عملیات شکست می‌خورد |
