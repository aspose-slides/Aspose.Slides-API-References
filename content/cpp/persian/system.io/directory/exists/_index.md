## متد Directory::Exists(const String\&)  

تشخیص می‌دهد که آیا مسیر مشخص به یک دایرکتوری موجود اشاره دارد یا خیر.

```cpp
static bool System::IO::Directory::Exists(const String &path)
```

### پارامترها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| path | const [String](../../../system/string/)\& | مسیری که باید بررسی شود |

### مقدار بازگشت

True اگر مسیر مشخص به یک دایرکتوری موجود اشاره داشته باشد، در غیر این صورت - false
