## MemoryStream::TryGetBuffer(ArraySegment\<uint8_t\>\&) متد


آرایه‌ای از بایت‌های بدون علامت را که این جریان از آن ساخته شده است، برمی‌گرداند.

```cpp
bool System::IO::MemoryStream::TryGetBuffer(ArraySegment<uint8_t> &buffer)
```


### پارامترها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| buffer | [ArraySegment](../../../system/arraysegment/)\<**uint8_t**\>\& | آرایه بایت - پارامتر خروجی. وقتی این متد مقدار true برمی‌گرداند، بخش آرایه بایتی که این جریان از آن ساخته شده است؛ وقتی مقدار false برمی‌گرداند، این پارامتر به مقدار پیش‌فرض تنظیم می‌شود. |

### مقدار بازگشتی

در صورتی که تبدیل موفق بوده باشد مقدار true بازگردانده می‌شود.
