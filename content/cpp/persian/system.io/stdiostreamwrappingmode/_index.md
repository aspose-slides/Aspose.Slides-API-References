## STDIOStreamWrappingMode enum

حالت عملیات ورودی/خروجی را که wrapperها روی جریان‌های شبیه std::iostreams-like انجام می‌دهند، مشخص می‌کند.

```cpp
enum class STDIOStreamWrappingMode
```

### Values

| نام | مقدار | توضیح |
| --- | --- | --- |
| Binary | 0 | حالتى که اجازه می‌دهد عملیات ورودی داده‌های جریان از نوع char_type را به بایت‌ها رمزگشایی کند و بایت‌ها را برای عملیات خروجی به داده‌های نوع char_type رمزگذاری کند. |
| Conversion | 1 | حالتى که اجازه می‌دهد عملیات ورودی داده‌های جریان را از نوع char_type به نوع **uint8_t** تبدیل کند و برای عملیات خروجی برعکس آن را انجام دهد. |
