## FileMode enum

نحوه باز شدن یک فایل را مشخص می‌کند.

```cpp
enum class FileMode
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| CreateNew | 1 | یک فایل جدید ایجاد می‌کند. اگر فایل قبلاً وجود داشته باشد، استثنا پرتاب می‌شود. |
| Create | 2 | یک فایل جدید ایجاد می‌کند. اگر فایل قبلاً وجود داشته باشد، بازنویسی می‌شود. |
| Open | 3 | یک فایل موجود را باز می‌کند. اگر فایل وجود نداشته باشد، استثنا پرتاب می‌شود. |
| OpenOrCreate | 4 | یک فایل موجود را باز می‌کند یا اگر وجود نداشته باشد، یک فایل جدید ایجاد می‌کند. |
| Truncate | 5 | یک فایل موجود را باز می‌کند و آن را به‌طوری که خالی باشد، قطع می‌کند. اگر فایل وجود نداشته باشد، استثنا پرتاب می‌شود. |
| Append | 6 | یک فایل موجود را باز می‌کند و به انتهای آن می‌رود یا اگر وجود نداشته باشد، یک فایل جدید ایجاد می‌کند. |
