## FileShare enum

مشخص می‌کند که اشیای دیگر [FileStream](../filestream/) چه نوع دسترسی‌ای به فایلی که در حال باز شدن است دارند.

```cpp
enum class FileShare
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| None | 0 | بدون دسترسی. |
| Read | 1 | دسترسی فقط خواندنی. |
| Write | 2 | دسترسی فقط نوشتنی. |
| ReadWrite | 3 | دسترسی خواندن و نوشتن. |
| Delete | 4 | فایل می‌تواند حذف شود. |
| Inheritable | 16 | دستگیرهٔ فایل را برای فرایندهای فرزند قابل وراثت می‌کند. |
