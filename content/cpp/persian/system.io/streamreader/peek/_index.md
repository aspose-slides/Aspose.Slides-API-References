## StreamReader::Peek() متد

یک کاراکتر از جریان می‌خواند بدون اینکه مکان‌نمای خواندن جریان تغییر کند.

```cpp
virtual int System::IO::StreamReader::Peek() override
```

### مقدار بازگشتی

کاراکتر خوانده شده با کدگذاری UTF-16 باز می‌گردد؛ اگر کاراکتر خوانده شده توسط دو کدپوینت در کدگذاری UTF-16 نمایش داده شود، فقط سُرگات بالا برگردانده می‌شود؛ اگر هیچ کاراکتری خوانده نشود مقدار -1 برگردانده می‌شود.
