## NumberStyles enum

قالب عددی که هنگام تجزیه مجاز است.

```cpp
enum class NumberStyles : int32_t
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| None | 0 | بدون نمادهای غیرعدد. |
| AllowLeadingWhite | 1 | اجازه فضاهای سفید پیش‌رو. |
| AllowTrailingWhite | 2 | اجازه فضاهای سفید پایانی. |
| AllowLeadingSign | 4 | اجازه علامت پیش‌رو. |
| Integer | n/a | قالب پیش‌فرض عدد صحیح. |
| AllowTrailingSign | 8 | اجازه علامت پایانی. |
| AllowParentheses | 16 | اجازه پرانتز برای مقادیر منفی. |
| AllowDecimalPoint | 32 | اجازه نقطه اعشاری. |
| AllowThousands | 64 | اجازه جداسازهای گروه. |
| Number | n/a | قالب پیش‌فرض عدد ترکیبی. |
| AllowExponent | 128 | اجازه علامت توان. |
| Float | n/a | قالب پیش‌فرض عدد ممیز شناور. |
| AllowCurrencySymbol | 256 | اجازه نماد ارز. |
| Currency | n/a | قالب پیش‌فرض ارز. |
| Any | n/a | اجازه هر مشخص‌کننده قالب. |
| AllowHexSpecifier | 512 | اجازه اعداد هگزادسیمال. |
| HexNumber | n/a | قالب پیش‌فرض عدد هگزادسیمال. |
