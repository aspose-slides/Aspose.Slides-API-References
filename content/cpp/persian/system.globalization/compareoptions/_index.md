## CompareOptions enum

[String](../../system/string/) گزینه‌های مقایسه.

```cpp
enum class CompareOptions : int32_t
```

### مقادیر

| Name | Value | Description |
| --- | --- | --- |
| None | 0 | بدون گزینه‌های خاص. |
| IgnoreCase | 1 | حروف بزرگ و کوچک را نادیده بگیرد. |
| IgnoreNonSpace | 2 | حروف ترکیبی غیر فاصله‌دار (مانند علامت‌های ترکیبی) را نادیده بگیرد. |
| IgnoreSymbols | 4 | فاصله‌ها، علائم نقطه‌گذاری و غیره را شامل می‌شود. |
| IgnoreKanaType | 8 | نوع کانا (ژاپنی) را نادیده بگیرد. |
| IgnoreWidth | 16 | عرض کاراکتر را هنگام مقایسه رشته‌ها نادیده بگیرد. |
| OrdinalIgnoreCase | 268435456 | مقایسه ترتیبی با نادیده‌گیری تفاوت حروف. |
| StringSort | 536870912 | از الگوریتم مرتب‌سازی رشته برای مقایسه کاراکترها استفاده می‌کند. |
| Ordinal | 1073741824 | کدهای UTF را به طور مستقیم برای اولین مقایسه مقایسه می‌کند. |
