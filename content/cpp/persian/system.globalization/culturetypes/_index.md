## CultureTypes enum

دسته‌های فرهنگی به‌صورت بیت-ماسک.

```cpp
enum class CultureTypes : int32_t
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| NeutralCultures | 1 | فرهنگی که مخصوص زبان است اما برای کشور یا منطقه نیست. |
| SpecificCultures | 2 | خاص به کشور/منطقه. |
| InstalledWin32Cultures | 4 | فرهنگ‌های نصب‌شده در سیستم‌عامل. |
| AllCultures | n/a | تمام فرهنگ‌های موجود. |
| UserCustomCulture | 8 | فرهنگ‌های تعریف‌شده توسط کاربر. |
| ReplacementCultures | 16 | جایگزینی‌های تعریف‌شده توسط کاربر برای فرهنگ‌های موجود. |
| WindowsOnlyCultures | 32 | منسوخ. |
| FrameworkCultures | 64 | منسوخ. |
