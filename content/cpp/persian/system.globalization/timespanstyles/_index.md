## TimeSpanStyles enum

گزینه‌های قالب‌بندی را مشخص می‌کند که تجزیه رشته را برای متدهایی که نمایهٔ رشته‌ای یک بازهٔ زمانی را به شیء Timespan تبدیل می‌کنند، سفارشی می‌سازد.

```cpp
enum class TimeSpanStyles : int32_t
```

### Values

| نام | مقدار | توضیح |
| --- | --- | --- |
| None | 0 | فاصلهٔ زمانی که توسط رشته ورودی نمایان می‌شود، فقط در صورتی که علامت منفی موجود باشد، به عنوان یک فاصلهٔ زمانی منفی تفسیر می‌شود. |
| AssumeNegative | 1 | فاصلهٔ زمانی که توسط رشته ورودی نمایان می‌شود، همیشه به عنوان یک فاصلهٔ زمانی منفی تفسیر می‌شود. |
