## SortKey کلاس

نقشه‌برداری یک رشته به کلید مرتب‌سازی آن. اشیاء این کلاس باید فقط با استفاده از تابع [System::MakeObject()](../../system/makeobject/) تخصیص داده شوند. هرگز نمونه‌ای از این نوع را روی پشته یا با استفاده از عملگر new ایجاد نکنید، زیرا منجر به خطاهای زمان اجرا و/یا نقص‌های اعتبارسنجی می‌شود. همیشه این کلاس را در یک پوینتر [System::SmartPtr](../../system/smartptr/) بپیچید و از این پوینتر برای ارسال به توابع به‌عنوان آرگومان استفاده کنید.

```cpp
class SortKey : public System::Object
```
