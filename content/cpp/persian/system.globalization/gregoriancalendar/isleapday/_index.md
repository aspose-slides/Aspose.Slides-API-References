## GregorianCalendar::IsLeapDay(int, int, int, int) const متد

بررسی می‌کند که آیا روز سال کبیسه است یا خیر.

```cpp
bool System::Globalization::GregorianCalendar::IsLeapDay(int year, int month, int day, int era) const override
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| year | int | سال. |
| month | int | ماه. |
| day | int | روز. |
| era | int | دوره. |

### مقدار بازگشت

True اگر تاریخ مشخص شده سال کبیسه باشد، در غیر این صورت false.
