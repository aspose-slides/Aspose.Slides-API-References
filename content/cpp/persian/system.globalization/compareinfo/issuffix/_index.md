## CompareInfo::IsSuffix(const String\&, const String\&, CompareOptions) const متد

بررسی می‌کند که آیا رشتهٔ مشخص‌شده با پسوند مشخص‌شده خاتمه می‌یابد یا نه، با استفاده از گزینه‌های مقایسهٔ مشخص شده.

```cpp
virtual bool System::Globalization::CompareInfo::IsSuffix(const String &source, const String &suffix, CompareOptions options) const
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| source | const [String](../../../system/string/)\& | رشتهٔ منبع. |
| suffix | const [String](../../../system/string/)\& | رشتهٔ پسوند. |
| options | [CompareOptions](../../compareoptions/) | گزینه‌های مقایسه. |

### مقدار بازگشتی

True اگر رشته با پسوند خاتمه یابد؛ در غیر این صورت false.
