## CompareInfo::IsSortable(char16_t) متد


بررسی می‌کند که آیا یک کاراکتر مشخص قابل مرتب‌سازی است یا خیر.

```cpp
static bool System::Globalization::CompareInfo::IsSortable(char16_t ch)
```


### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| ch | char16_t | کاراکتر یونیکد. |

### مقدار بازگشت

اگر **ch** قابل مرتب‌سازی باشد، True؛ در غیر این صورت False.

## CompareInfo::IsSortable(const String\&) متد


بررسی می‌کند که آیا یک رشته مشخص قابل مرتب‌سازی است یا خیر.

```cpp
static bool System::Globalization::CompareInfo::IsSortable(const String &text)
```


### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| text | const [String](../../../system/string/)\& | یک رشته. |

### مقدار بازگشت

اگر **text** خالی نباشد و تمام کاراکترهای آن قابل مرتب‌سازی باشند، True؛ در غیر این صورت False.
