## Size::Add(const Size\&, const Size\&) متد

یک شیء جدید [Size](../) را برمی‌گرداند که مجموع شیء [Size](../) مشخص‌شده است، یعنی مقداری که مقدار عرض آن برابر مجموع مقادیر عرض اشیاء مشخص‌شده و مقدار ارتفاع آن برابر مجموع مقادیر ارتفاع اشیاء مشخص‌شده است.

```cpp
static Size System::Drawing::Size::Add(const Size &size1, const Size &size2)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| size1 | const [Size](../)\& | عملوند اول |
| size2 | const [Size](../)\& | عملوند دوم |

### مقدار بازگشت

شیء [Size](../) که مجموع **size1** و **size2** است
