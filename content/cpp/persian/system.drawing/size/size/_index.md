## Size::Size() سازنده

یک شیء جدید [Size](../) می‌سازد و مقادیر عرض و ارتفاع آن را با ۰ مقداردهی می‌کند.

```cpp
System::Drawing::Size::Size()
```

## Size::Size(const Point\&) سازنده

یک شیء جدید [Size](../) می‌سازد و مقادیر عرض و ارتفاع آن را به‌صورت متناظر با مقادیر مختصات X و Y نقطه مشخص شده مقداردهی می‌کند.

```cpp
System::Drawing::Size::Size(const Point &point)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| point | const [Point](../../point/)\& | [Point](../../point/) یک شیء است که مختصات X و Y آن برای مقداردهی عرض و ارتفاع شیء [Size](../) ایجادشده استفاده می‌شود. |

## Size::Size(int, int) سازنده

یک شیء جدید [Size](../) می‌سازد و آن را با مقدار مشخص شده مقداردهی می‌کند.

```cpp
System::Drawing::Size::Size(int width, int height)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| width | int | مقدار برای عرض |
| height | int | مقدار برای ارتفاع |
