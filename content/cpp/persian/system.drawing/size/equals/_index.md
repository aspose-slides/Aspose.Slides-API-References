## Size::Equals(const Size\&) const متد

تعیین می‌کند که آیا شیء فعلی و شیء مشخص‌شده برابر هستند، یعنی همان جفت مقادیر عرض و ارتفاع را نمایان می‌کنند.

```cpp
bool System::Drawing::Size::Equals(const Size &size) const
```

### Arguments

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| size | const [Size](../)\& | شیئی که برای مقایسه با شیء فعلی استفاده می‌شود |

### Return Value

True اگر اشیا برابر باشند، در غیر این صورت - false
