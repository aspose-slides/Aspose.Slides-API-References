## StringTrimming enum

مشخص می‌کند که چگونه کاراکترها باید از رشته‌ای که شکل چیدمان را متناسب نمی‌کند، برش داده شوند.

```cpp
enum class StringTrimming
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| None | 0 | بدون برش. |
| Character | 1 | به نزدیک‌ترین کاراکتر برش دهید. |
| Word | 2 | به نزدیک‌ترین کلمه برش دهید. |
| EllipsisCharacter | 3 | به نزدیک‌ترین کاراکتر برش دهید و در انتهای رشته نقطه‌چین (ellipsis) قرار دهید. |
| EllipsisWord | 4 | به نزدیک‌ترین کلمه برش دهید و در انتهای رشته نقطه‌چین (ellipsis) قرار دهید. |
| EllipsisPath | 5 | بخش مرکزی خطوط برش داده شده حذف می‌شود و با یک نقطه‌چین جایگزین می‌شود. تا حد امکان بخش انتهایی خط که با اسلش جدا شده است، حفظ می‌شود. |
