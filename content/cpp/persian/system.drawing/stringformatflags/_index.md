## StringFormatFlags enum

Specifies the display and layout information for the strings of text.

```cpp
enum class StringFormatFlags
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| DirectionRightToLeft | 1 | جهت متن راست به چپ. |
| DirectionVertical | 2 | [Text](../../system.drawing.text/) به صورت عمودی تنظیم شده است. |
| FitBlackBox | 4 | بخش‌هایی از نویسه‌ها می‌توانند از جعبهٔ چینش بیرون بزنند. |
| DisplayFormatControl | 32 | کاراکترهای کنترل نمایش داده می‌شوند. |
| NoFontFallback | 1024 | [Font](../font/) fallback غیرفعال است. |
| MeasureTrailingSpaces | 2048 | فضای پایانی را در انتهای هر سطر اضافه می‌کند. |
| NoWrap | 4096 | [Text](../../system.drawing.text/) wrapping غیرفعال است. |
| LineLimit | 8192 | سطرهای کامل در مستطیل قالب‌بندی چینش می‌شوند. |
| NoClip | 16384 | بخش‌های سرریز گلیف‌ها اجازه نمایش دارند. |
