## RectangleF::Intersect(const RectangleF\&) متد

مستطیلی که توسط شیء فعلی نمایان شده است را با مستطیلی که از تقاطع آن با مستطیلی که توسط شیء مشخص‌شده نمایان شده است، به دست می‌آید، جایگزین می‌کند.

```cpp
void System::Drawing::RectangleF::Intersect(const RectangleF &rect)
```

### آرگومان‌ها

| Parameter | Type | Description |
| --- | --- | --- |
| rect | const [RectangleF](../)\& | شیء [RectangleF](../) که مستطیلی را که باید با مستطیلی که توسط شیء فعلی نمایان شده است، تقاطع شود، نمایان می‌کند |
