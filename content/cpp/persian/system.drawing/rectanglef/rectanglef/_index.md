## RectangleF::RectangleF() سازنده

یک نمونه جدید از شیٔ [RectangleF](../) را می‌سازد که نمایانگر یک مستطیل با مختصات X و Y و مقادیر عرض و ارتفاع برابر با ۰ است.

```cpp
System::Drawing::RectangleF::RectangleF()
```

## RectangleF::RectangleF(float, float, float, float) سازنده

یک نمونه جدید از شیٔ [RectangleF](../) را می‌سازد که نمایانگر یک مستطیل با مختصات مشخص گوشه بالای چپ و عرض و ارتفاع می‌باشد.

```cpp
System::Drawing::RectangleF::RectangleF(float x, float y, float width, float height)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| x | **float** | مقدار مختصات X گوشه بالای چپ مستطیل |
| y | **float** | مقدار مختصات Y گوشه بالای چپ مستطیل |
| width | **float** | عرض مستطیل |
| height | **float** | ارتفاع مستطیل |

## RectangleF::RectangleF(const PointF\&, const SizeF\&) سازنده

یک نمونه جدید از شیٔ [RectangleF](../) را می‌سازد که نمایانگر یک مستطیل با مختصات گوشه بالای چپ آن که به‌صورت یک نمونه از کلاس [PointF](../../pointf/) مشخص شده و عرض و ارتفاع آن به‌صورت یک نمونه از کلاس [SizeF](../../sizef/) تعیین شده است.

```cpp
System::Drawing::RectangleF::RectangleF(const PointF &location, const SizeF &size)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| location | const [PointF](../../pointf/)\& | موقعیت گوشه بالای چپ مستطیل را مشخص می‌کند |
| size | const [SizeF](../../sizef/)\& | عرض و ارتفاع مستطیل را مشخص می‌کند |

## RectangleF::RectangleF(const Rectangle\&) سازنده

یک نمونه جدید از شیٔ [RectangleF](../) را می‌سازد که نمایانگر مستطیلی برابر با مستطیل مشخص‌شده است.

```cpp
System::Drawing::RectangleF::RectangleF(const Rectangle &rect)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| rect | const [Rectangle](../../rectangle/)\& | یک نمونه از کلاس [Rectangle](../../rectangle/) که موقعیت و اندازه مستطیل مورد نمایاندن توسط شیء ساخته‌شده را تعیین می‌کند |
