## RectangleF::get_IsEmpty() const متد

تعیین می‌کند که آیا مختصات X و Y گوشهٔ بالا-چپ مستطیل نمایان‌شده توسط شیء فعلی و همچنین عرض و ارتفاع آن دارای مقدار 0 هستند یا خیر.

```cpp
bool System::Drawing::RectangleF::get_IsEmpty() const
```

### مقدار بازگشت

True اگر مختصات X و Y گوشهٔ بالا-چپ مستطیل نمایان‌شده توسط شیء فعلی و همچنین عرض و ارتفاع آن مقدار 0 داشته باشند، در غیر اینصورت - false
