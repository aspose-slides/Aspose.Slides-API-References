## RectangleF::Inflate(float, float) متد

عرض و ارتفاع مستطیلی که توسط شیء جاری نمایان می‌شود را افزایش می‌دهد و موقعیت مرکز هندسی مستطیل را حفظ می‌کند. عرض و ارتفاع در هر دو جهت به مقدارهای مشخص‌شده افزایش می‌یابند.

```cpp
void System::Drawing::RectangleF::Inflate(float width, float height)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| width | **float** | مقدارى که عرض مستطیل باید در هر دو جهت افزایش یابد |
| height | **float** | مقدارى که ارتفاع مستطیل باید در هر دو جهت افزایش یابد |

## RectangleF::Inflate(const SizeF\&) متد

عرض و ارتفاع مستطیلی که توسط شیء جاری نمایان می‌شود را افزایش می‌دهد و موقعیت مرکز هندسی مستطیل را حفظ می‌کند. عرض و ارتفاع در هر دو جهت به مقداری که توسط مقادیر width و height شیء SizeF مشخص شده است، به‌صورت متناظر افزایش می‌یابند.

```cpp
void System::Drawing::RectangleF::Inflate(const SizeF &size)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| size | const [SizeF](../../sizef/)\& | شیء [SizeF](../../sizef/) که مقدارهایی را برای افزایش عرض و ارتفاع مستطیل مشخص می‌کند |

## RectangleF::Inflate(const RectangleF\&, float, float) متد

عرض و ارتفاع مستطیلی که توسط شیء مشخص‌شده نمایان می‌شود را افزایش می‌دهد و موقعیت مرکز هندسی مستطیل را حفظ می‌کند. عرض و ارتفاع در هر دو جهت به مقدارهای مشخص شده افزایش می‌یابند.

```cpp
static RectangleF System::Drawing::RectangleF::Inflate(const RectangleF &rect, float x, float y)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| rect | const [RectangleF](../)\& | یک مستطیل برای بزرگ‌سازی |
| x | **float** | مقدارى که عرض مستطیل باید در هر دو جهت افزایش یابد |
| y | **float** | مقدارى که ارتفاع مستطیل باید در هر دو جهت افزایش یابد |
