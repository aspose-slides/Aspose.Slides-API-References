## StringDigitSubstitute enum

مشخص می‌کند که چگونه اعداد در یک رشته بر اساس منطقه یا زبان جایگزین می‌شوند.

```cpp
enum class StringDigitSubstitute
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| User | 0 | جایگزینی تعریف‌شده توسط کاربر. |
| None | 1 | جایگزینی غیرفعال است. |
| National | 2 | اعداد را که با زبان رسمی ملی منطقه کاربر مطابقت دارند جایگزین می‌کند. |
| Traditional | 3 | اعداد را که با نگارش یا زبان بومی کاربر مطابقت دارند، که ممکن است با زبان رسمی ملی منطقه کاربر یکسان نباشد، جایگزین می‌کند. |
