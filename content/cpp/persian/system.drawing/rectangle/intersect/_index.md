## Rectangle::Intersect(const Rectangle\&) متد

مستطیل نمایندگی‌شده توسط شیء فعلی را با مستطیلی که از تقاطع آن با مستطیل نمایندگی‌شده توسط شیء مشخص‌شده به‌دست می‌آید، جایگزین می‌کند.

```cpp
void System::Drawing::Rectangle::Intersect(const Rectangle &rect)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| rect | const [Rectangle](../)\& | شیء [Rectangle](../) که نمایندگی‌کنندهٔ مستطیلی است که مستطیل نمایندگی‌شده توسط شیء فعلی با آن تقاطع می‌شود |

## Rectangle::Intersect(const Rectangle\&, const Rectangle\&) متد

مستطیلی را باز می‌گرداند که نتیجهٔ تقاطع مستطیل‌های مشخص‌شده است.

```cpp
static Rectangle System::Drawing::Rectangle::Intersect(const Rectangle &a, const Rectangle &b)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| a | const [Rectangle](../)\& | اولین مستطیلی که باید تقاطع شود |
| b | const [Rectangle](../)\& | دومین مستطیلی که باید تقاطع شود |

### مقدار برگشتی

نتیجهٔ تقاطع **a** با **b**
