## Rectangle::Inflate(int, int) متد

عرض و ارتفاع مستطیلی که توسط شیء جاری نمایاندہ می‌شود را افزایش می‌دهد، در حالی که مکان مرکز هندسی مستطیل حفظ می‌شود. عرض و ارتفاع در هر دو جهت به میزان‌های مشخص شده افزایش می‌یابند.

```cpp
void System::Drawing::Rectangle::Inflate(int width, int height)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| width | int | مقداری که عرض مستطیل در هر دو جهت باید افزایش یابد |
| height | int | مقداری که ارتفاع مستطیل در هر دو جهت باید افزایش یابد |

## Rectangle::Inflate(const Size\&) متد

عرض و ارتفاع مستطیلی که توسط شیء جاری نمایاندہ می‌شود را افزایش می‌دهد، در حالی که مکان مرکز هندسی مستطیل حفظ می‌شود. عرض و ارتفاع در هر دو جهت به مقدارهای مشخص شده توسط مقادیر width و height شیء size مشخص شده به‌صورت متناظر افزایش می‌یابند.
