```cpp
bool System::Drawing::Color::get_IsNamedColor() const
```

### مقدار برگشتی

در صورتی که [Color](../) با استفاده از متد FromName(String) یا متد [FromKnownColor(KnownColor)](../fromknowncolor/) ساخته شده باشد، true برگردانده می‌شود؛ در غیر این صورت، false برگردانده می‌شود.
