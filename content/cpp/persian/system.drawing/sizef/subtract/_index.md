## SizeF::Subtract(const SizeF\&, const SizeF\&) متد

یک شی جدید [SizeF](../) را بر می‌گرداند که نتیجهٔ کم کردن **size2** از **size1** است، یعنی مقداری که عرض آن برابر با نتیجهٔ کم کردن مقدار عرض **size2's** از مقدار عرض **size1's** و ارتفاع آن برابر با نتیجهٔ کم کردن مقدار ارتفاع **size2's** از مقدار ارتفاع **size1's** است.

```cpp
static SizeF System::Drawing::SizeF::Subtract(const SizeF &size1, const SizeF &size2)
```

| size2 | const [SizeF](../)\& | شی [SizeF](../) برای کسر |

### مقدار بازگشت

شی [SizeF](../) که نتیجهٔ کم کردن **size2** از **size1** است.
