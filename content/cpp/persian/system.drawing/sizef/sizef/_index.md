## SizeF::SizeF() سازنده

یک شیء جدید [SizeF](../) ساخته و مقادیر width و height آن را با 0 مقداردهی اولیه می‌کند.

```cpp
System::Drawing::SizeF::SizeF()
```

## SizeF::SizeF(const PointF\&) سازنده

یک شیء جدید [SizeF](../) ساخته و مقادیر width و height آن را به‌صورت متناظر با مقادیر مختصات X و Y نقطهٔ مشخص شده مقداردهی می‌کند.

```cpp
System::Drawing::SizeF::SizeF(const PointF &point)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| point | const [PointF](../../pointf/)\& | یک شی [Point](../../point/) که مختصات X و Y آن برای مقداردهی اولیه به مقدار width و height شی [SizeF](../) که در حال ایجاد است استفاده می‌شود |

## SizeF::SizeF(float, float) سازنده

```cpp
System::Drawing::SizeF::SizeF(float width, float height)
```

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| width | **float** | مقدار برای width |
| height | **float** | مقدار height |
