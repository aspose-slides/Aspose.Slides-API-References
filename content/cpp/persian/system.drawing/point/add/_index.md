## Point::Add(const Point\&, const Size\&) متد

عرض و ارتفاع مقادیر شیء [Size](../../size/) مشخص‌شده را به مقادیر مختصات X و Y شیء [Point](../) مشخص‌شده به‌صورت متناظر اضافه می‌کند.

```cpp
static Point System::Drawing::Point::Add(const Point &point, const Size &size)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| point | const [Point](../)\& | نقطه برای تبدیل |
| size | const [Size](../../size/)\& | شیء [Size](../../size/) که مقادیری را که باید به مقادیر مختصات **point** اضافه شود، مشخص می‌کند |

### مقدار بازگشتی

یک شیء جدید [Point](../) که مقدار مختصات X آن برابر با جمع مقدار مختصات X **point** و مقدار عرض **size** و مقدار مختصات Y آن برابر با جمع مقدار مختصات Y **point** و مقدار ارتفاع **size** است
