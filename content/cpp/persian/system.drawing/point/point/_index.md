## Point::Point() سازنده

یک شیء جدید [Point](../) ایجاد می‌کند و مقادیر مختصات X و Y آن را با 0 مقداردهی می‌کند.

```cpp
System::Drawing::Point::Point()
```

## Point::Point(int, int) سازنده

یک شیء جدید [Point](../) ایجاد می‌کند و آن را با مقادیر مشخص‌شده مقداردهی می‌کند.

```cpp
System::Drawing::Point::Point(int x, int y)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| x | int | مقدار مختصات X |
| y | int | مقدار مختصات Y |

## Point::Point(const Size\&) سازنده

یک شیء جدید [Point](../) ایجاد می‌کند و مقادیر مختصات X و Y آن را به ترتیب با مقادیر عرض و ارتفاع شیء [SizeF](../../sizef/) مشخص‌شده مقداردهی می‌کند.

```cpp
System::Drawing::Point::Point(const Size &size)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| size | const [Size](../../size/)\& | شیء [SizeF](../../sizef/) ای که مقادیر عرض و ارتفاع آن برای مقداردهی مقادیر مختصات X و Y شیء [Point](../) در حال ایجاد استفاده می‌شود |

## Point::Point(int) سازنده

یک شیء جدید [Point](../) ایجاد می‌کند و مقدار مختصات X آن را با مقداری که از بیت‌های 16 بالای عدد صحیح 32 بیتی مشخص‌شده تشکیل شده است مقداردهی می‌کند و مقدار مختصات Y آن را با مقداری که از بیت‌های 16 پایین همان عدد صحیح 32 بیتی تشکیل شده، مقداردهی می‌کند.

```cpp
System::Drawing::Point::Point(int dw)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| dw | int | مقدار عدد صحیح 32 بیتی که بیت‌های 16 بالای آن مقدار مختصات X و بیت‌های 16 پایین آن مقدار مختصات Y شیء در حال ایجاد را تعیین می‌کند |
