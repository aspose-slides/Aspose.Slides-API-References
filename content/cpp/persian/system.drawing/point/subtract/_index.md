## Point::Subtract(const Point\&, const Size\&) متد

مقادیر عرض و ارتفاع شیء [Size](../../size/) مشخص‌شده را به‌صورت متناظر از مقادیر مختصات X و Y شیء [Point](../) مشخص‌شده کم می‌کند.

```cpp
static Point System::Drawing::Point::Subtract(const Point &point, const Size &size)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| point | const [Point](../)\& | نقطه‌ای که باید جابجا شود |
| size | const [Size](../../size/)\& | شیء [Size](../../size/) که مقادیر را برای کم کردن از مقادیر مختصات **point** مشخص می‌کند |

### مقدار بازگشتی

یک شیء جدید [Point](../) که مقدار مختصات X آن برابر با نتیجهٔ کم کردن مقدار عرض **size** از مقدار مختصات X **point** و مقدار مختصات Y آن برابر با نتیجهٔ کم کردن مقدار ارتفاع **size** از مقدار مختصات Y **point** است.
