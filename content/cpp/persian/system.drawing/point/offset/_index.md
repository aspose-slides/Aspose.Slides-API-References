## Point::Offset(int, int) متد

مختصات X و Y شیء فعلی را با مقادیر مشخص‌شده جابجا می‌کند.

```cpp
void System::Drawing::Point::Offset(int dx, int dy)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| dx | int | مقدار جابجایی مختصات X |
| dy | int | مقدار جابجایی مختصات Y |

## Point::Offset(Point) متد

مختصات X و Y شیء فعلی را با مقادیر مختصات X و Y شیء [Point](../) مشخص‌شده به‌صورت متناظر جابجا می‌کند.

```cpp
void System::Drawing::Point::Offset(Point point)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| point | [Point](../) | شیء [Point](../) که مقادیر برای جابجایی مختصات X و Y را مشخص می‌کند |
