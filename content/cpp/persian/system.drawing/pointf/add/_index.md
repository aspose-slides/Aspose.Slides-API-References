## PointF::Add(const PointF\&, const SizeF\&) متد

عرض و ارتفاع شی [SizeF](../../sizef/) مشخص‌شده را به مقدار مختصات X و Y شی [PointF](../) مشخص‌شده به‌صورت متناظر اضافه می‌کند.

```cpp
static PointF System::Drawing::PointF::Add(const PointF &point, const SizeF &size)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| point | const [PointF](../)\& | نقطه برای ترجمه |
| size | const [SizeF](../../sizef/)\& | شی [SizeF](../../sizef/) که مقادیر را برای افزودن به مقادیر مختصات **point** مشخص می‌کند |

### مقدار بازگشتی

شی جدید [PointF](../) که مقدار مختصات X آن برابر مجموع مقدار مختصات X **point** و مقدار عرض **size** و مقدار مختصات Y آن برابر مجموع مقدار مختصات Y **point** و مقدار ارتفاع **size** است
