## PointF::PointF() سازنده

یک شیء جدید [PointF](../) را ایجاد می‌کند و مقادیر مختصات X و Y آن را با ۰ مقداردهی اولیه می‌کند.

```cpp
System::Drawing::PointF::PointF()
```

## PointF::PointF(float, float) سازنده

یک شیء جدید [PointF](../) را ایجاد می‌کند و آن را با مقادیر مشخص‌شده مقداردهی اولیه می‌کند.

```cpp
System::Drawing::PointF::PointF(float x, float y)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| x | **float** | مقدار مختصات X |
| y | **float** | مقدار مختصات Y |

## PointF::PointF(const SizeF\&) سازنده

یک شیء جدید [PointF](../) را ایجاد می‌کند و مقادیر مختصات X و Y آن را به‌صورت متناظر با مقادیر عرض و ارتفاع شیء [SizeF](../../sizef/) مشخص‌شده مقداردهی اولیه می‌نماید.

```cpp
System::Drawing::PointF::PointF(const SizeF &size)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| size | const [SizeF](../../sizef/)\& | شیء [SizeF](../../sizef/)‌ای که مقادیر عرض و ارتفاع آن برای مقداردهی اولیه مقادیر مختصات X و Y شیء [PointF](../) در حال ایجاد استفاده می‌شود |
