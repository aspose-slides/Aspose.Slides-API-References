## PointF::Subtract(const PointF\&, const SizeF\&) متد

عرض و ارتفاع مقادیر شیء [SizeF](../../sizef/) مشخص‌شده را به ترتیب از مقادیر مختصات X و Y شیء [PointF](../) مشخص‌شده کم می‌کند.

```cpp
static PointF System::Drawing::PointF::Subtract(const PointF &point, const SizeF &size)
```

### آرگومان‌ها

| Parameter | Type | Description |
| --- | --- | --- |
| point | const [PointF](../)\& | نقطه برای ترجمه |
| size | const [SizeF](../../sizef/)\& | شیء [SizeF](../../sizef/) که مقادیر را برای کسر از مقادیر مختصات **point** مشخص می‌کند |

### مقدار بازگشت

یک شیء جدید [PointF](../) که مقدار مختصات X آن برابر با نتیجهٔ کسر مقدار عرض **size** از مقدار مختصات X **point** و مقدار مختصات Y آن برابر با نتیجهٔ کسر مقدار ارتفاع **size** از مقدار مختصات Y **point** است
