## کلاس‌ها

| کلاس | توضیح |
| --- | --- |
| [IInk](./iink/) | یک شیء جوهر را در یک اسلاید نشان می‌دهد. |
| [IInkActions](./iinkactions/) | یک شیء جوهر را در یک اسلاید نشان می‌دهد. |
| [IInkBrush](./iinkbrush/) | یک قلم‌کش ردیابی را نشان می‌دهد. |

| [InkBrush](./inkbrush/) | یک شیء inkBrush را نشان می‌دهد. |
| [InkTrace](./inktrace/) | یک شیء Trace را نشان می‌دهد. یک عنصر Trace برای ضبط داده‌های ضبط‌شده توسط دیجیتایزر استفاده می‌شود. این عنصر شامل دنباله‌ای از نقاط است که بر اساس مشخصات ارائه‌شده توسط شیء InkTraceFormat رمزگذاری شده‌اند. |

## نمادها

| نماد | توضیح |
| --- | --- |
| [InkEffectType](./inkeffecttype/) | مجموعه‌ای از افکت‌های بصری پیش‌تعریف‌شده برای رندرینگ جوهر را مشخص می‌کند. هر افکت به یک بافت یا تصویر که ظاهر جوهر استایل‌شده را شبیه‌سازی می‌کند، مربوط می‌شود. این مقادیر می‌توانند برای سفارشی‌سازی سبک بصری خطوط دیجیتال جوهر در هنگام رندرینگ استفاده شوند. |
