## InkEffectType enum

یک مجموعه از افکت‌های بصری پیش‌تعریف‌شده برای رندر جوهر را مشخص می‌کند. هر افکت به یک بافت یا تصویر که ظاهر جوهر استایل‌شده‌ای را شبیه‌سازی می‌کند، مربوط است. این مقادیر می‌توانند برای سفارشی‌سازی سبک بصری خطوط دیجیتال جوهر هنگام رندر استفاده شوند.

```cpp
enum class InkEffectType
```

### Values

| نام | مقدار | توضیح |
| --- | --- | --- |
| NotDefined | -1 | اثر تعریف نشده است یا ناشناخته است. این مقدار می‌تواند به‌عنوان پیش‌فرض یا جایگزین استفاده شود. |
| Bronze | 0 | یک بافت گرم، قهوه‌ای-متمایل فلزی که شبیه جوهر برنز است. |
| Galaxy | 1 | یک بافت رنگارنگ و درخشان که شبیه کهکشان است، با رنگ‌های کیهانی. |
| Gold | 2 | یک بافت روشن و فلزی طلاییش که به خطوط جوهر ظاهر لوکسی می‌بخشد. |
| Lava | 3 | یک بافت آتشین که شبیه لاوۀ مذاب است، با رنگ‌های قرمز و نارنجی. |
| Ocean | 4 | یک بافت عمیق‌آبی و شبیه‌به‌مایهٔ سیال که امواج اقیانوس یا جوهر مبتنی بر آب را تقلید می‌کند. |
| RainbowGlitter | 5 | یک افکت رنگارنگ، درخشان و براق رنگین‌کمان که برای خطوط جوهر جشن‌گونه یا زنده استفاده می‌شود. |
| RoseGold | 6 | یک ترکیب نرم صورتی-طلایی، مشابه rose gold، برای خطوط جوهر شیک. |
| Silver | 7 | یک بافت سرد و فلزی نقره‌ای که جوهر نقره‌ای کلاسیک را شبیه‌سازی می‌کند. |
