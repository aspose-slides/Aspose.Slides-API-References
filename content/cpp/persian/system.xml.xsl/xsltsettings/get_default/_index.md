## XsltSettings::get_Default() متد

```cpp
static SharedPtr<XsltSettings> System::Xml::Xsl::XsltSettings::get_Default()
```

### مقدار بازگشت

یک شیء [XsltSettings](../) با گزینه‌های [XsltSettings::set_EnableDocumentFunction](../set_enabledocumentfunction/) و [XsltSettings::set_EnableScript](../set_enablescript/) که به **false** تنظیم شده‌اند.
