## کلاس DefaultBoxedValue

[BoxedValue](../boxedvalue/) پیاده‌سازی کلاس. امکان اعلام تخصص‌های BoxingValue را بدون تکرار کدهای مشترک فراهم می‌کند. اشیاء این کلاس باید فقط با استفاده از تابع [System::MakeObject()](../makeobject/) تخصیص یابند. هرگز نمونه‌ای از این نوع را روی پشته یا با استفاده از عملگر new ایجاد نکنید، زیرا منجر به خطاهای زمان اجرا و/یا خطای ادعایی می‌شود. همیشه این کلاس را در اشاره‌گری [System::SmartPtr](../smartptr/) بپیچید و از این اشاره‌گر برای انتقال به توابع به‌صورت آرگومان استفاده کنید.

```cpp
template<class T>class DefaultBoxedValue : public System::Object
```
