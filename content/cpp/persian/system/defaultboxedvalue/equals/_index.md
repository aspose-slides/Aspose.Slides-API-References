## DefaultBoxedValue::Equals(ptr) متد

برابری مقادیر بسته‌شده‌ای که توسط شیء جاری و شیء مشخص‌شده بیان می‌شوند را تعیین می‌کند.

```cpp
bool System::DefaultBoxedValue<T>::Equals(ptr obj) override
```

### آرگومان‌ها

| Parameter | Type | Description |
| --- | --- | --- |
| obj | [ptr](../../object/ptr/) | شیئی که مقدار بسته‌شده‌ای را که باید با مقدار بسته‌شده‌ی نمایان‌سازی شده توسط شیء جاری مقایسه شود، نمایان می‌کند. |

### مقدار بازگشت

True اگر مقدار بسته‌شده‌ای که توسط شیء جاری و **obj** نمایان شده‌اند برابر باشند، در غیر این صورت - false
