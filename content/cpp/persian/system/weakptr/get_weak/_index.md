## WeakPtr::get_weak() const متد

شیء ارجاع‌شده را دریافت می‌کند. تأیید می‌کند که اشاره‌گر در حالت ضعیف است.

```cpp
Object * System::WeakPtr<T>::get_weak() const
```

### مقدار بازگشتی

اشاره‌گر خام به شیء ارجاع‌شده (در صورت اختصاص داده‌شدن و عدم تاریخ‌گذشت) یا nullptr.
