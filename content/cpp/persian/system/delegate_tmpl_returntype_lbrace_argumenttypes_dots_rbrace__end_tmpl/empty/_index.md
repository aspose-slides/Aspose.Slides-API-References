## Delegate< ReturnType(ArgumentTypes...)>::Empty() const متد

تعیین می‌کند که آیا شیء delegate فعلی خالی است، به عنوان مثال به هیچ موجودی اشاره نمی‌کند.

```cpp
bool System::Delegate<ReturnType(ArgumentTypes...)>::Empty() const
```

### مقدار بازگشت

True اگر شیء delegate فعلی به یک تابع، یک متد از یک شیء تابع اشاره نداشته باشد، در غیر این صورت - false.
