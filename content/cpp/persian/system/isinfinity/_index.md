## System::IsInfinity(const T\&) تابع

تعیین می‌کند که آیا مقدار مشخص‌شده نمایانگر بی‌نهایت است.

```cpp
template<typename T> bool System::IsInfinity(const T &value)
```

### پارامترهای الگو

| پارامتر | توضیح |
| --- | --- |
| T | نوع مقدار بررسی‌شده توسط تابع |

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| value | const T\& | مقداری که باید بررسی شود |

### مقدار برگشت

اگر **value** نمایانگر بی‌نهایت باشد true، در غیر این صورت false
