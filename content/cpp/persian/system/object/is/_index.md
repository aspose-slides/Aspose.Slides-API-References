## Object::Is(const TypeInfo\&) const متد


Check if object represents an instance of type described by targetType. Analog of C# 'is' operator.

```cpp
virtual bool System::Object::Is(const TypeInfo &targetType) const
```


### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| targetType | const [TypeInfo](../../typeinfo/)\& | [TypeInfo](../../typeinfo/) ساختاری که نوعی را توصیف می‌کند که برای آزمون شیء جاری استفاده می‌شود. |

### مقدار بازگشتی

True اگر شیء از نوع برچسب‌گذاری‌شده یا زیرکلاس آن باشد، false در غیر این صورت.
