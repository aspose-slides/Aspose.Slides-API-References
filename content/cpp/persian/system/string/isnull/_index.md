## String::IsNull() const متد


بررسی می‌کند که آیا رشته به عنوان null در نظر گرفته می‌شود. [String](../) null است و تنها در صورتی که از طریق سازنده [String()](../string/) ساخته شده باشد، جابجا، کپی یا از رشته null اختصاص داده شود یا [reset()](../reset/) متد فراخوانی شد.

```cpp
bool System::String::IsNull() const
```


### مقدار بازگشت

در صورتی که رشته به عنوان null در نظر گرفته شود true و در غیر این صورت false.
