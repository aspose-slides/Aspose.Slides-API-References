## String::rend() const متد


یک مرورگر معکوس به موقعیت قبل از اولین کاراکتر (در صورت وجود) بافر رشتهٔ واقعی برمی‌گرداند.

```cpp
reverse_iterator System::String::rend() const
```


### مقدار بازگشتی

مرورگر معکوس به عنصری که قبل از اولین کاراکتر بافر رشتهٔ واقعی (در صورت وجود) قرار دارد یا به عنصری که دقیقاً قبل از بافر اختصاص داده شده است.
