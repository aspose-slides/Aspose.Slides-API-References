## String::IsNullOrWhiteSpace(const String\&) متد

نشانه می‌دهد که آیا رشتهٔ مشخص‌شده null، خالی یا فقط شامل کاراکترهای فضای سفید است.

```cpp
static bool System::String::IsNullOrWhiteSpace(const String &str)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| str | const [String](../)\& | [String](../) برای بررسی. |

### مقدار بازگشتی

true اگر رشته null یا خالی باشد یا منحصراً شامل کاراکترهای فضای سفید باشد، در غیر این صورت false.
