## String::IsNullOrEmpty() const متد


بررسی می‌کند که آیا رشته خالی است یا به عنوان null در نظر گرفته می‌شود.

```cpp
bool System::String::IsNullOrEmpty() const
```


### مقدار بازگشت

true اگر رشته خالی یا null باشد، در غیر این صورت false.
