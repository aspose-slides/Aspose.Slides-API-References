## String::end() const متد

بازگرداندن اشاره‌گری به انتهای بافر رشتهٔ واقعی. هرگز چیزی را دوباره تخصیص نمی‌دهد. تضمین نمی‌کند که بافر دارای پایان نال باشد.

```cpp
const UChar * System::String::end() const
```

### مقدار بازگشتی

اشاره‌گری به اولین عنصر پس از بافر رشتهٔ واقعی، نال‌پایان یا بدون نال.
