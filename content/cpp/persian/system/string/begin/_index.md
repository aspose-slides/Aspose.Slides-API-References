## روش String::begin() const

پانویسی به نقطهٔ ابتدای بافر رشتهٔ واقعی را برمی‌گرداند. هرگز چیزی را مجدداً تخصیص نمی‌دهد. تضمین نمی‌کند که بافر به‌صورت null-terminated باشد.

```cpp
const UChar * System::String::begin() const
```

### مقدار بازگشت

پانویسی به بافر رشتهٔ واقعی، به‌صورت null-terminated یا نه.
