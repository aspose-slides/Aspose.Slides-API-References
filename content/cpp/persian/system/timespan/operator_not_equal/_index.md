```cpp
constexpr bool System::TimeSpan::operator!=(TimeSpan value) const
```

### مقدار برگشتی

True اگر شیء فعلی و شیء مشخص‌شده بازه‌های زمانی متفاوتی را نشان دهند، در غیر این صورت - false
