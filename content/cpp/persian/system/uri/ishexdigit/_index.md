## Uri::IsHexDigit(char16_t) متد

```cpp
static bool System::Uri::IsHexDigit(char16_t character)
```

### پارامترها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| character | char16_t | کاراکتر برای بررسی |

### مقدار بازگشتی

True اگر کاراکتر مشخص شده یک رقم هگزا دسیمال باشد، در غیر اینصورت - false
