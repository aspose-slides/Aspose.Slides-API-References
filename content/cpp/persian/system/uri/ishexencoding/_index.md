## Uri::IsHexEncoding(const String&, int32_t) متد

مشخص می‌کند آیا کاراکتری در رشتهٔ مشخص‌شده در موقعیت مشخص‌شده به صورت هگزادسیمال کدگذاری شده است یا خیر.

```cpp
static bool System::Uri::IsHexEncoding(const String &pattern, int32_t index)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| pattern | const [String](../../string/)\& | رشته‌ای که باید بررسی شود |
| index | **int32_t** | موقعیت صفر-پایه کاراکتر برای تست |

### مقدار بازگشتی

True if the specified character is hexadecimal encoded, otherwise - false
