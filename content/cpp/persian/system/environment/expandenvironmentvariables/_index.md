## Environment::ExpandEnvironmentVariables(const String\&) متد

نام‌های متغیرهای محیطی موجود در رشتهٔ مشخص‌شده را با مقادیر آن متغیرها جایگزین می‌کند و رشتهٔ حاصل را برمی‌گرداند.

```cpp
static String System::Environment::ExpandEnvironmentVariables(const String &name)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| name | const [String](../../string/)\& | رشته‌ای که شامل نام‌های متغیرهای محیطی است |

### مقدار بازگشت

رشته‌ای که از جایگزینی نام‌های متغیر در **name** با مقادیر آن‌ها حاصل می‌شود.
