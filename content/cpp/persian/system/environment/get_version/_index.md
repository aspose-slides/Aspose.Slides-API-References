## Environment::get_Version() متد

یک شیء [Version](../../version/) را برمی‌گرداند که اطلاعات مربوط به نسخهٔ زمان اجرای زبان مشترک را نشان می‌دهد. عدد نسخه‌ای که توسط این متد برگردانده می‌شود تا حدی ساختگی است و به این معنی نیست که تمام کلاس‌های کتابخانه بر مبنای نسخهٔ برگشت داده‌شده رفتار کنند.

```cpp
static Version System::Environment::get_Version()
```
