## EnumValuesBase::Parse(const TypeInfo\&, const String\&, bool) متد


یک شیء را برمی‌گرداند که نمایانگر مقدار ثابت شمارشی از نوع شمارشی مشخص‌شده با نام مشخص‌شده است.

```cpp
static SharedPtr<Object> System::EnumValuesBase::Parse(const TypeInfo &type, const String &str, bool ignoreCase)
```


### پارامترها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| type | const [TypeInfo](../../typeinfo/)\& | شیء [TypeInfo](../../typeinfo/) که نوع مقدار شمارشی بازگردانده‌شده را نشان می‌دهد |
| str | const [String](../../string/)\& | نام ثابت enum |
| ignoreCase | **bool** | مشخص می‌کند که آیا هنگام تفسیر نام ثابت enum به حروف بزرگ/کوچک توجه شود |

### مقدار بازگشتی

شیء‌ای که نمایانگر مقدار ثابت enum است که نام آن در **str** مشخص شده است.
