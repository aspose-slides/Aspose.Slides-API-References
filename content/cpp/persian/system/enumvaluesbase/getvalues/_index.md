## EnumValuesBase::GetValues(const TypeInfo\&) متد

```cpp
static ArrayPtr<int64_t> System::EnumValuesBase::GetValues(const TypeInfo &type)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| type | const [TypeInfo](../../typeinfo/)\& | شیء [TypeInfo](../../typeinfo/) که نوع شمارشی که مقادیر آن برگردانده می‌شود را نمایان می‌سازد |

### مقدار بازگشتی

آرایه‌ای شامل مقادیر تمام ثابت‌های شمارشی نوع شمارشی که توسط **type** مشخص شده است.
