## MathF::RoundImpl(float, int, MidpointRounding) متد


مقدار مشخص‌شده را به نزدیک‌ترین مقدار با تعداد رقم‌های کسری مشخص گرد می‌کند. یک پارامتر رفتار تابع را زمانی که مقدار مشخص‌شده به طور مساوی به دو عدد نزدیک‌ترین نزدیک باشد، تعیین می‌کند.

```cpp
static float System::MathF::RoundImpl(float value, int digits, MidpointRounding mode)
```


### آرگومان‌ها

| Parameter | Type | Description |
| --- | --- | --- |
| value | **float** | مقدار برای گرد کردن |
| digits | int | تعداد رقم‌های کسری در مقدار گرد شده |
| mode | [MidpointRounding](../../midpointrounding/) | نحوه انجام گرد کردن را زمانی که **value** به طور مساوی به دو عدد نزدیک‌ترین نزدیک باشد، مشخص می‌کند. |

### مقدار بازگشتی

عدد با تعداد رقم‌های مشخص‌شده که به **value** نزدیک‌ترین است
