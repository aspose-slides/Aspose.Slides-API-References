## BoxedValue::is() const متد

مشخص می‌کند که آیا نوع مقدار بسته‌بندی‌شده نمایانده‌شده توسط شی فعلی **V** است یا خیر.

```cpp
template<class V> bool System::BoxedValue<T>::is() const
```

### پارامترهای قالب

| پارامتر | توضحیح |
| --- | --- |
| V | نوعی که با نوع مقدار بسته‌بندی‌شده نمایانده‌شده توسط شی فعلی مقایسه می‌شود |

### مقدار بازگشتی

True اگر نوع مقدار بسته‌بندی‌شده نمایانده‌شده توسط شی فعلی **V** باشد، در غیر این صورت - false
