## System::Equals(const TA\&, const TB\&) تابع

برابری دو مقدار را با اعمال [operator==()](../operator_equal_equal/) به آن‌ها تعیین می‌کند.

```cpp
template<typename TA,typename TB> bool System::Equals(const TA &a, const TB &b)
```

### پارامترهای الگو

| Parameter | Description |
| --- | --- |
| TA | نوع مقایسه‌گر اول |
| TB | نوع مقایسه‌گر دوم |

### آرگومان‌ها

| Parameter | Type | Description |
| --- | --- | --- |
| a | const TA\& | مقایسه‌گر اول |
| b | const TB\& | مقایسه‌گر دوم |

### مقدار بازگشت

مقدار بولی بازگشت داده شده توسط [operator==()](../operator_equal_equal/) که بر **a** و **b** اعمال شده است
