## توضیحات

```cpp
#include "system/math.h"
#include <iostream>

int main()
{
  using namespace System;

  // مقادیر مطلق را چاپ می‌کند.
  for (int i = -1; i < 2; ++i)
  {
    std::cout << Math::Abs(i) << " ";
  }
  std::cout << std::endl;

  // سینوس PI/2 و کسینوس PI را چاپ می‌کند.
  std::cout << "sin(PI/2)=" << Math::Sin(Math::PI/2) << "; cos(PI)=" << Math::Cos(Math::PI) << std::endl;

  return 0;
}
/*
این مثال کد خروجی زیر را تولید می‌کند:
1 0 1
sin(PI/2)=1; cos(PI)=-1
*/
```
