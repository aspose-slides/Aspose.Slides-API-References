## Math::Max_(float, float) متد

```cpp
float System::Math::Max_(float val1, float val2)
```

### Arguments

| Parameter | Type | Description |
| --- | --- | --- |
| val1 | **float** | مقدار مقایسه‌ای اول |
| val2 | **float** | مقدار مقایسه‌ای دوم |

### Return Value

بزرگ‌ترین مقدار بین **val1** و **val2**؛ یا NaN اگر یکی از عملوندها NaN باشد
