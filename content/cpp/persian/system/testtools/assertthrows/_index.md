## TestTools::AssertThrows(const std::function\<void()>\&) متد

بررسی می‌کند که آیا تابع استثنایی از هر نوعی پرتاب می‌کند.

```cpp
static bool System::TestTools::AssertThrows(const std::function<void()> &func)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| func | const std::function\<void()>\& | تابعی که برای بررسی پرتاب شدن بررسی می‌شود. |

### مقدار بازگشت

True اگر تابع پرتاب شود، false در غیر این صورت.
