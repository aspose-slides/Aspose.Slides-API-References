## Decimal::CompareTo(const Decimal\&) const متد

تعیین می‌کند که آیا مقدار نمایان‌ساز شیء جاری کمتر، برابر یا بزرگتر از مقداری است که توسط شیء مشخص‌شده نمایان می‌شود.

```cpp
int System::Decimal::CompareTo(const Decimal &d) const
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| d | const [Decimal](../)\& | مقدار مقایسه |

### مقدار بازگشت

- 1 اگر مقدار نمایان‌ساز شیء جاری کمتر از مقداری باشد که توسط **d** نمایان شده است؛ 0 اگر مقادیر برابر باشند؛ 1 اگر مقدار نمایان‌ساز شیء جاری بزرگتر از مقداری باشد که توسط **d** نمایان شده است
