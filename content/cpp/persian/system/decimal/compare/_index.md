## Decimal::Compare(const Decimal\&, const Decimal\&) متد

مشخص می‌کند که آیا مقدار نمایان‌شده توسط شیء [Decimal](../) اول کمتر، مساوی یا بزرگتر از مقدار نمایان‌شده توسط شیء [Decimal](../) دوم است.

```cpp
static int System::Decimal::Compare(const Decimal &d1, const Decimal &d2)
```

### آرگومان‌ها

| پارامتر | نوع | توضیحات |
| --- | --- | --- |
| d1 | const [Decimal](../)\& | مقایسه‌کنندهٔ اول |
| d2 | const [Decimal](../)\& | مقایسه‌کنندهٔ دوم |

### مقدار بازگشت

- 1 اگر مقداری که توسط **d1** نمایان شده کمتر از مقداری که توسط **d2** نمایان شده باشد؛ 0 اگر مقادیر برابر باشند؛ 1 اگر مقداری که توسط **d1** نمایان شده بزرگتر از مقداری که توسط **d2** نمایان شده باشد
