## ساختار HolderInitializer

این کلاس برای دریافت ارجاع ثابت به شیء نمونه استفاده می‌شود، چه lvalue باشد چه rvalue. برای به‌دست آمدن چنین ارجاعی، از متد 'HoldIfTemporary' استفاده کنید که دارای سه overload است. دو مورد آن rvalue را به عنوان پارامتر می‌گیرند و فقط ارجاع به آن را برمی‌گردانند. مورد سوم، برعکس، lvalue را به عنوان پارامتر می‌گیرد، یک کپی نشانگر ایجاد می‌کند، سپس ارجاع به آن کپی را برمی‌گرداند. همچنین، کلاس دارای متد 'Hold' برای نگه‌داشتن مقدار پاس‌خورده به‌صورت بدون شرط است (برای کپی کردن مقادیر متغیرهای محلی روی-استک یا ارجاعات فرزند آن استفاده می‌شود)

```cpp
template<typename T,bool>class HolderInitializer
```

### پارامترهای قالب

| پارامتر | توضیح |
| --- | --- |
| T | نوع شیئی که باید نگهداری شود. |
| R | True، اگر T یک نوع مرجع باشد (تخصص [SmartPtr](../smartptr/) یا نوع [System::String](../string/))، و نگه‌داشتن ارجاع‌های موقت واقعاً لازم باشد، در غیر این صورت false. |
