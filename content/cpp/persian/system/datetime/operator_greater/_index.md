## DateTime::operator>(DateTime) const متد

تعیین می‌کند که آیا شیء فعلی مقدار تاریخ و زمان را نشان می‌دهد که پس از مقداری که توسط شیء [DateTime](../) مشخص‌شده نمایان شده است.

```cpp
constexpr bool System::DateTime::operator>(DateTime other) const
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| other | [DateTime](../) | شیء [DateTime](../) برای مقایسه با شیء فعلی |

### مقدار بازگشت

True اگر مقدار تاریخ و زمان نمایان‌شده توسط شیء فعلی بعد از مقداری باشد که **other** نشان می‌دهد، در غیر این صورت - false
