## DateTime::Equals(DateTime) const متد


مشخص می‌کند که آیا نمونهٔ مشخص‌شده از کلاس [DateTime](../) مقدار تاریخ و زمان یکسانی با شیء جاری دارد یا خیر.

```cpp
constexpr bool System::DateTime::Equals(DateTime other) const
```


### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| other | [DateTime](../) | نمونه‌ای از کلاس [DateTime](../) برای مقایسه شیء جاری |

### مقدار بازگشت

True اگر هم **other** و هم شیء جاری مقدار یکسانی داشته باشند، در غیر این صورت - false

## DateTime::Equals(DateTime, DateTime) متد


مشخص می‌کند که آیا نمونه‌های مشخص‌شده از کلاس [DateTime](../) مقدار تاریخ و زمان یکسانی دارند یا خیر.

```cpp
static constexpr bool System::DateTime::Equals(DateTime t1, DateTime t2)
```


### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| t1 | [DateTime](../) | اولین مقایسه‌شونده |
| t2 | [DateTime](../) | دومین مقایسه‌شونده |

### مقدار بازگشت

True اگر هم **t1** و هم **t2** مقدار یکسانی داشته باشند، در غیر این صورت - false
