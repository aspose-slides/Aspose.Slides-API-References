## DateTime::IsDaylightSavingTime() const متد

تعیین می‌کند که آیا مقدار تاریخ و زمان نمایان‌گر توسط شیء فعلی در بازهٔ ساعت تابستانی برای منطقهٔ زمانی جاری قرار می‌گیرد یا نه.

```cpp
bool System::DateTime::IsDaylightSavingTime() const
```

### مقدار بازگشت

True اگر مقدار تاریخ و زمان مشخص‌شده توسط شیء فعلی در بازهٔ ساعت تابستانی باشد، در غیر این صورت - false
