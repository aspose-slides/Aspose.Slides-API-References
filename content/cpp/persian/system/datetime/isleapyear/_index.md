## DateTime::IsLeapYear(int) متد

تعیین می‌کند آیا سال مشخص شده یک سال کبیسه است.

```cpp
static bool System::DateTime::IsLeapYear(int year)
```

### Arguments

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| year | int | سال برای بررسی |

### مقدار برگشت

True اگر سال مشخص شده یک سال کبیسه باشد، در غیر این صورت - false
