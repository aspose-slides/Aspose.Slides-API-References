```cpp
static DateTime System::DateTime::FromFileTimeUtc(int64_t file_time)
```

### Arguments

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| file_time | **int64_t** | زمان فایل برای تبدیل |

### Return Value

یک نمونه جدید از کلاس [DateTime](../) که نشان‌دهنده همان تاریخ و زمان به عنوان **file_time** است
