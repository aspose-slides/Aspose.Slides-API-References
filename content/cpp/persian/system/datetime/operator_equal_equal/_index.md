## DateTime::operator==(DateTime) const متد

تعیین می‌کند آیا شی جاری و شی [DateTime](../) مشخص شده نمایانگر مقدار تاریخ و زمان یکسان هستند یا خیر.

```cpp
constexpr bool System::DateTime::operator==(DateTime other) const
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| other | [DateTime](../) | شی [DateTime](../) برای مقایسه با شی جاری |

### مقدار بازگشتی

True اگر شی جاری و شی مشخص شده نمایانگر مقدار تاریخ و زمان یکسان باشند، در غیر این صورت - false
