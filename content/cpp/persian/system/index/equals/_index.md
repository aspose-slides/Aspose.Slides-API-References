## Index::Equals(const Index\&) const متد

تعیین می‌کند که آیا نمونهٔ جاری و [Index](../) مشخص‌شده همان موقعیت را نشان می‌دهند.

```cpp
bool System::Index::Equals(const Index &other) const
```

### پارامترها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| other | const [Index](../)\& | اندیس برای مقایسه با. |

### مقدار بازگشت

True اگر هر دو اندیس مقدار و جهت یکسان داشته باشند، در غیر این صورت false.
