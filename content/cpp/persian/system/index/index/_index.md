## Index::Index() سازنده

یک نمونه ایجاد می‌کند که نقطه شروع یک مجموعه را نشان می‌دهد.

```cpp
constexpr System::Index::Index() noexcept
```

## Index::Index(int32_t) سازنده

یک نمونه ایجاد می‌کند که موقعیت مشخص‌شده از ابتدای مجموعه را نشان می‌دهد.

```cpp
constexpr System::Index::Index(int32_t value) noexcept
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| value | **int32_t** | شاخص صفر مبنایی از ابتداء. |

## Index::Index(int32_t, bool) سازنده

یک نمونه ایجاد می‌کند که شاخص مشخص‌شده را نشان می‌دهد.

```cpp
constexpr System::Index::Index(int32_t value, bool from_end) noexcept
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| value | **int32_t** | مقدار شاخص. |
| from_end | **bool** | درست اگر شاخص نسبت به انتهای مجموعه باشد. |
