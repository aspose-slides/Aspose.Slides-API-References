## EventHandler typedef


نمایش یک متد است که به یک رویداد واکنش نشان می‌دهد و آن را پردازش می‌کند. این نوع باید بر روی پشته تخصیص داده شود و به توابع به‌صورت مقدار یا اشاره‌گر پاس داده شود. هرگز از کلاس [System::SmartPtr](../smartptr/) برای مدیریت اشیای این نوع استفاده نکنید.

```cpp
using System::EventHandler = typedef MulticastDelegate<void(System::SharedPtr<Object>, TEventArgs)>
```
