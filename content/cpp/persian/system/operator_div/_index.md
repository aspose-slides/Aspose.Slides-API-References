## System::operator/(const T\&, const Decimal\&) تابع

یک نمونه جدید از کلاس [Decimal](../decimal/) برمی‌گرداند که نمایانگر مقداری است که نتیجه تقسیم مقدار مشخص‌شده و مقدار نمایان‌سازی‌شده توسط شیء [Decimal](../decimal/) مشخص‌شده می‌باشد.

```cpp
template<typename T,typename _> Decimal System::operator/(const T &x, const Decimal &d)
```

### پارامترها

| پارامتر | نوع | توضیحات |
| --- | --- | --- |
| x | const T\& | مقداری که باید تقسیم شود |
| d | const [Decimal](../decimal/)\& | شیء [Decimal](../decimal/) که مخرج را نمایان می‌کند |

### مقدار برگشت

یک نمونه جدید از کلاس [Decimal](../decimal/) که نمایانگر مقداری است که نتیجه تقسیم **x** بر مقدار نمایان‌شده توسط **d** می‌باشد.
