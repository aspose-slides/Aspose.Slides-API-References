## Array::cbegin() const متد

یک iterator به اولین عنصر const-qualified از container برمی‌گرداند. اگر container خالی باشد، iterator بازگردانده‌شده برابر با [cend()](../cend/) خواهد بود.

```cpp
const_iterator System::Array<T>::cbegin() const noexcept
```

### مقدار بازگشت

یک iterator که به اولین عنصر const-qualified از container اشاره می‌کند.
