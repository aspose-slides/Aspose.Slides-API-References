## Array::begin() متد

یک iterator به اولین عنصر کانتینر برمی‌گرداند. اگر کانتینر خالی باشد، iterator بازگشتی برابر با [end()](../end/) خواهد بود.

```cpp
iterator System::Array<T>::begin() noexcept
```

### مقدار بازگشت

یک iterator که به اولین عنصر کانتینر اشاره می‌کند.

## Array::begin() const متد

یک iterator به اولین عنصر کانتینر با کیفیت const برمی‌گرداند. اگر کانتینر خالی باشد، iterator بازگشتی برابر با [end()](../end/) خواهد بود.

```cpp
const_iterator System::Array<T>::begin() const noexcept
```

### مقدار بازگشت

یک iterator که به اولین عنصر کانتینر با کیفیت const اشاره می‌کند.
