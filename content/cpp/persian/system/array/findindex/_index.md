## Array::FindIndex(System::ArrayPtr\<T\>, System::Predicate\<T\>) متد

اولین عنصری را که در آرایهٔ مشخص‌شده وجود دارد و شرایط پیش‌شرط را برآورده می‌کند جستجو می‌کند.

```cpp
static int System::Array<T>::FindIndex(System::ArrayPtr<T> arr, System::Predicate<T> match)
```

### Arguments

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| arr | [System::ArrayPtr](../../arrayptr/)\<T\> | [Array](../) برای جستجو یک عنصر در |
| match | [System::Predicate](../../predicate/)\<T\> | پیش‌شرطی که شرایط تطبیق عناصر آرایه را تعریف می‌کند |

### Return Value

شاخص اولین عنصری که در آرایه وجود دارد و شرایط تعریف‌شده توسط پیش‌شرط را برآورده می‌کند، در غیر این صورت -1
