## Array::crbegin() const method


یک تکرارگر معکوس به اولین عنصر از کانتینر معکوس‌شده برمی‌گرداند. این مقدار مربوط به آخرین عنصر از کانتینر غیرمعکوس است. اگر کانتینر خالی باشد، تکرارگر بازگردانده‌شده برابر با [crend()](../crend/) است.

```cpp
const_reverse_iterator System::Array<T>::crbegin() const noexcept
```


### مقدار بازگشت

یک تکرارگر که به آخرین عنصر const-qualified از کانتینر اشاره می‌کند.
