## Array::ConstrainedCopy(const ArrayPtr\<SrcType\>\&, int64_t, const ArrayPtr\<DstType\>\&, int64_t, int64_t) متد


تعدادی از عناصر را از یک [System.Array](../) که از منبع مشخص شده شروع می‌شود، کپی می‌کند.

```cpp
template<typename SrcType,typename DstType> static void System::Array<T>::ConstrainedCopy(const ArrayPtr<SrcType> &srcArray, int64_t srcIndex, const ArrayPtr<DstType> &dstArray, int64_t dstIndex, int64_t count)
```


### پارامترهای قالب

| پارامتر | توضیح |
| --- | --- |
| SrcType | نوع عناصری که در آرایهٔ منبع هستند |
| DstType | نوع عناصری که در آرایهٔ مقصد هستند |

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| srcArray | const [ArrayPtr](../../arrayptr/)\<SrcType\>\& | آرایهٔ منبع |
| srcIndex | **int64_t** | [Index](../../index/) در آرایهٔ منبع که ابتدای بازهٔ آیتم‌های قابل کپی را نشان می‌دهد |
| dstArray | const [ArrayPtr](../../arrayptr/)\<DstType\>\& | آرایهٔ مقصد |
| dstIndex | **int64_t** | [Index](../../index/) در آرایهٔ مقصد برای شروع درج آیتم‌های کپی شده |
| count | **int64_t** | تعداد عناصری که باید کپی شوند |
