## Array::Resize(ArrayPtr\<Type\>\&, int) method

اندازهٔ آرایهٔ مشخص‌شده را به مقدار مشخص‌شده تغییر می‌دهد یا آرایهٔ جدیدی با اندازهٔ مشخص ایجاد می‌کند.

```cpp
template<typename Type> static void System::Array<T>::Resize(ArrayPtr<Type> &arr, int new_size)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| arr | [ArrayPtr](../../arrayptr/)\<[Type](../../object/type/)\>\& | [Array](../) برای تغییر اندازه. اگر **arr** مقدار null-pointer باشد، آرایهٔ جدید ایجاد خواهد شد |
| new_size | int | اندازهٔ جدید آرایه، یا اندازهٔ آرایهٔ جدید اگر **arr** null باشد |
