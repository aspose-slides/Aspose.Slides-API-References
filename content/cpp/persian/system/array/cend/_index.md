## Array::cend() const متد


یک تکرارگر به عنصری که پس از آخرین عنصر کانتینر قرار دارد، برمی‌گرداند. این عنصر به عنوان یک جایدار عمل می‌کند؛ تلاش برای دسترسی به آن منجر به رفتار تعریف‌نشده می‌شود.

```cpp
const_iterator System::Array<T>::cend() const noexcept
```


### مقدار بازگشت

یک تکرارگر که به عنصر نظری const-qualified پس از آخرین عنصر کانتینر اشاره دارد.
