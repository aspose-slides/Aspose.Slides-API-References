## Array::rbegin() متد


یک iterator معکوس به اولین عنصر از container معکوس‌شده بر می‌گرداند. این iterator مربوط به آخرین عنصر از container غیرمعکوس است. اگر container خالی باشد، iterator بازگردانده‌شده برابر با [rend()](../rend/) است.

```cpp
reverse_iterator System::Array<T>::rbegin() noexcept
```


### مقدار بازگشت

یک iterator که به آخرین عنصر از container اشاره می‌کند.

## Array::rbegin() const متد


یک iterator معکوس به اولین عنصر از container معکوس‌شده بر می‌گرداند. این iterator مربوط به آخرین عنصر از container غیرمعکوس است. اگر container خالی باشد، iterator بازگردانده‌شده برابر با [rend()](../rend/) است.

```cpp
const_reverse_iterator System::Array<T>::rbegin() const noexcept
```


### مقدار بازگشت

یک iterator که به آخرین عنصر از container دارای ویژگی const اشاره می‌کند.
