## Char::IsPunctuation(const char_t *, int) متد

تعیین می‌کند که آیا کاراکتر در ایندکس مشخص شده در بافر کاراکتری مشخص‌شده به عنوان کاراکتر نقطه‌گذاری طبقه‌بندی می‌شود یا خیر.

```cpp
static bool System::Char::IsPunctuation(const char_t *str, int idx)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| str | const char_t * | اشاره‌گر به ابتدای بافر کاراکتر |
| idx | int | اندیس صفر-پایه در بافر مشخص‌شده برای کاراکتر مورد آزمایش |

### مقدار بازگشتی

True اگر کاراکتر در ایندکس مشخص‌شده یک کاراکتر نقطه‌گذاری باشد، در غیر این صورت False

## Char::IsPunctuation(char_t) متد

تعیین می‌کند که آیا کاراکتر مشخص‌شده به عنوان کاراکتر نقطه‌گذاری طبقه‌بندی می‌شود یا خیر.

```cpp
static bool System::Char::IsPunctuation(char_t c)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| c | char_t | کاراکتر مورد آزمایش |

### مقدار بازگشتی

True اگر کاراکتر مشخص‌شده یک کاراکتر نقطه‌گذاری باشد، در غیر این صورت False
