## Char::IsWhiteSpace(const char_t *, int) متد

Determines whether the character at the specified index in the specified character buffer is classified as a white space character.

```cpp
static bool System::Char::IsWhiteSpace(const char_t *str, int idx)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| str | const char_t * | اشاره به ابتدای بافر کاراکتر |
| idx | int | یک اندیس صفرپایه در بافر مشخص برای کاراکتر مورد آزمون |

### مقدار بازگشتی

در صورتی که کاراکتر در اندیس مشخص یک کاراکتر فضای سفید باشد، مقدار true؛ در غیر این صورت - false
