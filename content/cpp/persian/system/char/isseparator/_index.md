## Char::IsSeparator(const char_t *, int) متد


مشخص می‌کند که آیا کاراکتر در اندیس مشخص‌شده در بافر کاراکتر داده‌شده به‌عنوان کاراکتر جداساز طبقه‌بندی شده است یا خیر.

```cpp
static bool System::Char::IsSeparator(const char_t *str, int idx)
```

### پارامترها

| پارامتر | نوع | شرح |
| --- | --- | --- |
| str | const char_t * | اشاره‌گر به ابتدای بافر کاراکتر |
| idx | int | یک اندیس صفر مبنا در بافر مشخص شده برای کاراکتر مورد آزمون |

### مقدار بازگشت

True اگر کاراکتر در اندیس مشخص‌شده کاراکتر جداساز باشد، در غیر این صورت false

## Char::IsSeparator(char_t) متد


مشخص می‌کند که آیا کاراکتر مشخص‌شده به‌عنوان کاراکتر جداساز طبقه‌بندی شده است یا خیر.

```cpp
static bool System::Char::IsSeparator(char_t c)
```

### پارامترها

| پارامتر | نوع | شرح |
| --- | --- | --- |
| c | char_t | کاراکتر مورد آزمون |

### مقدار بازگشت

True اگر کاراکتر مشخص‌شده کاراکتر جداساز باشد، در غیر این صورت false
