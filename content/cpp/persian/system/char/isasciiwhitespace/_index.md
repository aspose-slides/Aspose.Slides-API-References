## Char::IsAsciiWhiteSpace(char_t) متد

مشخص می‌کند که آیا کاراکتر مشخص شده به عنوان یک کاراکتر فضای سفید ASCII طبقه‌بندی شده است یا خیر.

```cpp
static constexpr bool System::Char::IsAsciiWhiteSpace(char_t c)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| c | char_t | کاراکتر برای تست |

### مقدار بازگشت

True اگر کاراکتر مشخص شده یک کاراکتر فضای سفید ASCII باشد، در غیر این صورت false
