## Char::TryParse(const System::String\&, char_t\&) متد

سعی می‌کند یک رشته شامل یک کاراکتر واحد را به کاراکتر UTF-16 تبدیل کند. این تابع فقط زمانی موفق می‌شود که رشتهٔ ورودی تهی نباشد و دقیقاً یک کاراکتر داشته باشد.

```cpp
static bool System::Char::TryParse(const System::String &s, char_t &result)
```

### پارامترها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| s | const [System::String](../../string/)\& | [String](../../string/) برای تبدیل |
| result | char_t\& | متغیر خروجی که در صورت موفقیت تبدیل، نتیجه تبدیل را در خود نگه می‌دارد |

## مقدار بازگشت

True اگر تبدیل موفق شد، در غیر این صورت - false
