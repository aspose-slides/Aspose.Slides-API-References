## Char::IsLowSurrogate(const char_t *, int) متد

تعیین می‌کند آیا کاراکتر در اندیس مشخص شده در بافر کاراکتری داده شده یک low surrogate است یا نه.

```cpp
static bool System::Char::IsLowSurrogate(const char_t *str, int idx)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| str | const char_t * | اشاره‌گری به ابتدای بافر کاراکتر |
| idx | int | یک اندیس صفر-پایه در بافر مشخص شده برای کاراکتری که باید تست شود |

### مقدار بازگشت

True اگر کاراکتر در اندیس مشخص شده یک low surrogate باشد، در غیر این صورت false

static bool System::Char::IsLowSurrogate(char_t c)
