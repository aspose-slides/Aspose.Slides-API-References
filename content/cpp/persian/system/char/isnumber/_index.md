## Char::IsNumber(const char_t *, int) method


تعیین می‌کند که آیا کاراکتر موجود در اندیس مشخص در بافر کاراکتری داده شده به عنوان عدد شناخته می‌شود یا نه.

```cpp
static bool System::Char::IsNumber(const char_t *str, int idx)
```


### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| str | const char_t * | اشاره‌گر به ابتدای بافر کاراکتری |
| idx | int | اندیس صفر-پایه در بافر مشخص برای کاراکتری که باید تست شود |

### مقدار بازگشت

True اگر کاراکتر در اندیس مشخص عدد باشد، در غیر این صورت - false
