## Char::IsLetter(const char_t *, int) متد

مشخص می‌کند که آیا کاراکتر موجود در شاخص مشخص شده در بافر کاراکتر مشخص شده به عنوان حرف یونیکد طبقه‌بندی می‌شود یا خیر.

```cpp
static bool System::Char::IsLetter(const char_t *str, int idx)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| str | const char_t * | اشاره‌گر به ابتدای بافر کاراکتر |
| idx | int | یک شاخص صفر مبنا در بافر مشخص برای کاراکتر مورد آزمایش |

### مقدار بازگشت

اگر کاراکتر موجود در شاخص مشخص شده یک حرف یونیکد باشد، مقدار true و در غیر این صورت false برگردانده می‌شود.

static bool System::Char::IsLetter(char_t c)
