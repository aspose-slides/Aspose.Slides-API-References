## Char::IsDigit(const char_t *, int) متد

مشخص می‌کند که آیا کاراکتر در ایندکس مشخص شده در بافر کاراکتری مشخص شده به‌عنوان یک رقم دسیمال دسته‌بندی شده است.

```cpp
static bool System::Char::IsDigit(const char_t *str, int idx)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| str | const char_t * | اشاره‌گر به ابتداِ بافر کاراکتری |
| idx | int | ایندکس صفر-مبتنی در بافر مشخص شده برای کاراکتر مورد آزمایش |

### مقدار بازگشت

True اگر کاراکتر در ایندکس مشخص شده یک رقم دسیمال باشد، در غیر این صورت - false

## Char::IsDigit(const String\&, const int32_t) متد

مشخص می‌کند که آیا کاراکتر در ایندکس مشخص شده در رشتهٔ مشخص شده به‌عنوان یک رقم دسیمال دسته‌بندی شده است.

```cpp
static bool System::Char::IsDigit(const String &str, const int32_t idx)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| str | const [String](../../string/)\& | یک رشته |
| idx | const **int32_t** | یک ایندکس صفر-مبتنی در بافر مشخص شده برای کاراکتر مورد آزمایش |

### مقدار بازگشت

True اگر کاراکتر در ایندکس مشخص شده یک رقم دسیمال باشد، در غیر این صورت - false
