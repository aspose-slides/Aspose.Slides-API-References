## Char::IsControl(const char_t *, int) متد


مشخص می‌کند آیا کاراکتر در ایندکس مشخص‌شده در بافر کاراکتری مشخص‌شده به‌عنوان کاراکتر کنترل یونیکد طبقه‌بندی شده است یا خیر.

```cpp
static bool System::Char::IsControl(const char_t *str, int idx)
```


### آرگومان‌ها

| Parameter | Type | Description |
| --- | --- | --- |
| str | const char_t * | اشاره‌گر به ابتدای بافر کاراکتر |
| idx | int | ایندکس صفر-محور کاراکتر مورد آزمایش در بافر مشخص‌شده |

### مقدار بازگشتی

True اگر کاراکتر در ایندکس مشخص‌شده یک کاراکتر کنترل یونیکد باشد، در غیر این صورت - false
