## Char::IsLower(const char_t *, int) متد

مشخص می‌کند که آیا کاراکتر در اندیس مشخص‌شده در بافر کاراکتری داده شده به عنوان حرف کوچک طبقه‌بندی شده است یا خیر.

```cpp
static bool System::Char::IsLower(const char_t *str, int idx)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| str | const char_t * | اشاره‌گر به ابتدای بافر کاراکتر |
| idx | int | یک اندیس صفر-پایه در بافر مشخص‌شده برای کاراکتری که باید تست شود |

### مقدار بازگشت

True اگر کاراکتر در اندیس مشخص‌شده حرف کوچک باشد، در غیر اینصورت - false
