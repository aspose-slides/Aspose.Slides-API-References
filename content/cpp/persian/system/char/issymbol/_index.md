## Char::IsSymbol(const char_t *, int) متد

تشخیص می‌دهد که کاراکتر در ایندکس مشخص‌شده در بافر کاراکتری داده‌شده به عنوان کاراکتر نماد طبقه‌بندی شده است.

```cpp
static bool System::Char::IsSymbol(const char_t *str, int idx)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| str | const char_t * | نشانگر به ابتدای بافر کاراکتر |
| idx | int | ایندکس صفر-مبنا در بافر مشخص‌شده برای کاراکتر مورد آزمون |

### مقدار بازگشتی

True اگر کاراکتر در ایندکس مشخص‌شده یک کاراکتر نماد باشد، در غیر این صورت - false

## Char::IsSymbol(char_t) متد

تشخیص می‌دهد که کاراکتر مشخص‌شده به عنوان کاراکتر نماد طبقه‌بندی شده است.

```cpp
static bool System::Char::IsSymbol(char_t c)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| c | char_t | کاراکتر مورد آزمون |

### مقدار بازگشتی

True اگر کاراکتر مشخص‌شده یک کاراکتر نماد باشد، در غیر این صورت - false
