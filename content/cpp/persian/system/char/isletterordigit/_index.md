## Char::IsLetterOrDigit(const char_t *, int) متد

تعیین می‌کند آیا کاراکتر موجود در ایندکس مشخص‌شده در بافر کاراکتری مشخص‌شده به‌عنوان حرف یونیکد یا رقم دسیمال طبقه‌بندی شده است یا خیر.

```cpp
static bool System::Char::IsLetterOrDigit(const char_t *str, int idx)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| str | const char_t * | اشاره‌گر به ابتدای بافر کاراکتر |
| idx | int | یک ایندکس مبتنی بر صفر در بافر مشخص برای کاراکتری که آزمایش می‌شود |

### مقدار بازگشتی

درست اگر کاراکتر موجود در ایندکس مشخص‌شده یک حرف یونیکد یا رقم دسیمال باشد، در غیر این صورت - نادرست
