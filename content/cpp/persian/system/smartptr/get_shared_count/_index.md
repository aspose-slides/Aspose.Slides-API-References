## SmartPtr::get_shared_count() const متد

تعداد اشاره‌گرهای اشتراکی موجود به شیء مرجع را به‌همراه اشاره‌گر فعلی دریافت می‌کند. اطمینان می‌دهد که اشاره‌گر فعلی در حالت اشتراک است.

```cpp
int System::SmartPtr<T>::get_shared_count() const
```

### مقدار بازگشت

تعداد اشاره‌گرهای اشتراکی موجود به شیء مرجع، در صورت وجود. اگر اشاره‌گر null باشد، ۰ را برمی‌گرداند.
