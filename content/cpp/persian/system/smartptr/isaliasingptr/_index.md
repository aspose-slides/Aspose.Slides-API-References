## SmartPtr::IsAliasingPtr() const متد


بررسی می‌کند که آیا اشاره‌گر به شیء دیگری به جز شیء مالک (ساخته شده توسط سازندهٔ aliasing) اشاره دارد.

```cpp
bool System::SmartPtr<T>::IsAliasingPtr() const
```


### مقدار بازگشتی

در صورتی که اشاره‌گر تفاوتی بین شیء مورد اشاره و شیء مالک داشته باشد، مقدار true برگردانده می‌شود؛ در غیر این صورت false.
