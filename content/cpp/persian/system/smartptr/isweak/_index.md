## SmartPtr::IsWeak() const متد

بررسی می‌کند که آیا اشاره‌گر در حالت weak است.

```cpp
bool System::SmartPtr<T>::IsWeak() const
```

### مقدار بازگشت

True اگر اشاره‌گر در حالت weak باشد، در غیر این صورت false.
