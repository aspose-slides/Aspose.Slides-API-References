## SmartPtr::IsShared() const متد

بررسی می‌کند که آیا اشاره‌گر در حالت اشتراکی است یا نه.

```cpp
bool System::SmartPtr<T>::IsShared() const
```

### مقدار بازگشت

True اگر اشاره‌گر در حالت اشتراکی باشد، در غیر این صورت false.
