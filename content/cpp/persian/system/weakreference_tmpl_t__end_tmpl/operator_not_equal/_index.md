## WeakReference< T >::operator!=(std::nullptr_t) const متد

بررسی می‌کند که آیا شیء مرجع مقدار null نیست.

```cpp
bool System::WeakReference<T>::operator!=(std::nullptr_t) const
```

### مقدار بازگشت

True اگر شیء مرجع مقدار null نباشد، false در غیر این صورت.

## WeakReference< T >::operator!=(const WeakReference\<T\>\&) const متد

شیء مرجع را با یک نمونه دیگر از کلاس WeakReference مقایسه می‌کند.

```cpp
bool System::WeakReference<T>::operator!=(const WeakReference<T> &other) const
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| other | const [WeakReference](../weakreference/)\<T\>\& | [Object](../../object/) مقایسه با. |

### مقدار بازگشت

True اگر اشیاء مقایسه‌شده به اشیاء متفاوتی اشاره داشته باشند، false اگر اشیاء یکسان باشند.
