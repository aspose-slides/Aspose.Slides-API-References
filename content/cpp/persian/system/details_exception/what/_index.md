## Details_Exception::what() const متد

[what()](./) متد پیاده‌سازی می‌شود که توسط کلاس [ExceptionWrapper](../../exceptionwrapper/) فراخوانی می‌شود. علیرغم این که این کلاس از std::exception ارث‌بری نمی‌کند، کلاس‌های مشتق می‌توانند از اعضای protected/private برای پیاده‌سازی منطق خود استفاده کنند. انتقال این پیاده‌سازی متد به [ExceptionWrapper](../../exceptionwrapper/) ممکن است آن منطق را بشکند.

```cpp
virtual const char * System::Details_Exception::what() const noexcept
```
