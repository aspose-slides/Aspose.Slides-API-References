## System::IsPositiveInfinity(const T\&) function

تعیین می‌کند که آیا مقدار مشخص شده نمایانگر بی‌نهایت مثبت است یا خیر.

```cpp
template<typename T> bool System::IsPositiveInfinity(const T &value)
```

### پارامترهای قالب

| پارامتر | توضیح |
| --- | --- |
| T | نوع مقداری که توسط تابع بررسی می‌شود |

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| value | const T\& | مقداری که باید بررسی شود |

### مقدار برگردانده شده

در صورتی که **value** نمایانگر بی‌نهایت مثبت باشد، true؛ در غیر این صورت false
