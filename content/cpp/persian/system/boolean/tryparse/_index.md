## Boolean::TryParse(const String\&, bool\&) متد

تبدیل رشتهٔ مشخص‌شده به مقداری از نوع bool.

```cpp
static bool System::Boolean::TryParse(const String &value, bool &result)
```

### پارامترها

| Parameter | Type | Description |
| --- | --- | --- |
| value | const [String](../../string/)\& | رشته‌ای برای تبدیل. |
| result | **bool**\& | مرجع به یک متغیر bool که نتیجهٔ تبدیل در آن قرار می‌گیرد؛ نتیجه true است اگر رشتهٔ مشخص‌شده برابر "True" باشد و false اگر برابر "False" باشد. |

### مقدار بازگشتی

True اگر رشتهٔ مشخص‌شده برابر "True" یا "False" باشد، در غیر این صورت - false.
