## Boolean::Parse(const String\&) متد

Converts the specified string to a value of bool type.

```cpp
static bool System::Boolean::Parse(const String &value)
```

### آرگومان‌ها

| Parameter | Type | Description |
| --- | --- | --- |
| value | const [String](../../string/)\& | رشته‌ای که باید تبدیل شود. |

### مقدار بازگشت

متغیر bool که نتیجه تبدیل در آن قرار می‌گیرد؛ نتیجه true است اگر رشتهٔ مشخص‌شده برابر با "True" باشد و false اگر رشتهٔ مشخص‌شده برابر با "False" باشد.
