## System::Greater(const ExpressionT\&, const ConstantT\&) تابع

پیاده‌سازی ترجمه الگو نسبی '>'.

```cpp
template<class ExpressionT,class ConstantT> bool System::Greater(const ExpressionT &left, const ConstantT &constant)
```

### پارامترهای قالب

| Parameter | Description |
| --- | --- |
| ExpressionT | نوع عبارت چپ. |
| ConstantT | نوع عبارت ثابت. |

### آرگومان‌ها

| Parameter | Type | Description |
| --- | --- | --- |
| left | const ExpressionT\& | عبارتی که بررسی می‌شود. |
| constant | const ConstantT\& | عبارتی که با عبارت چپ مقایسه می‌شود. |

### مقدار بازگشت

true اگر بررسی نوع موفق باشد، false در غیر این صورت.
