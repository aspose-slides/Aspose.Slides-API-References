## TypeInfo::GetCustomAttribute(const TypeInfo\&) const متد

برای ویژگی سفارشی که نوع مشخص‌شده را دارد و به نوعی که توسط شیء فعلی نمایان شده است، جستجو می‌کند.

```cpp
ObjectPtr System::TypeInfo::GetCustomAttribute(const TypeInfo &attributeType) const
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| attributeType | const [TypeInfo](../)\& | مرجع ثابت به شیء [TypeInfo](../) که نمایانگر نوع ویژگی برای جستجو است |

### مقدار بازگشتی

یک اشاره‌گر به شیء‌ای که ویژگی یافت‌شده را نمایندگی می‌کند، یا null-pointer اگر هیچ ویژگی‌ای مطابق معیارهای جستجو پیدا نشد
