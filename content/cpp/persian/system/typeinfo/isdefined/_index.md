## TypeInfo::IsDefined(const TypeInfo\&, bool) const متد

اجرا نشده. نشان می‌دهد که آیا یک یا بیش از یک ویژگی از نوع مشخص‌شده یا انواع مشتق‌شدهٔ آن بر این عضو اعمال شده است یا خیر.

```cpp
bool System::TypeInfo::IsDefined(const TypeInfo &attributeType, bool inherit) const
```

### پارامترها

| Parameter | Type | Description |
| --- | --- | --- |
| attributeType | const [TypeInfo](../)\& | نوع ویژگی سفارشی برای جستجو. جستجو شامل انواع مشتق‌شده می‌شود. |
| inherit | **bool** | true برای جستجو در زنجیرهٔ وراثت این عضو به‌منظور یافتن ویژگی‌ها؛ در غیر این صورت false. این پارامتر برای خصوصیات و رویدادها نادیده گرفته می‌شود. |

### مقدار برگشتی

true اگر یک یا بیش از یک نمونه از attributeType یا هر یک از انواع مشتق‌شدهٔ آن بر این عضو اعمال شده باشد؛ در غیر این صورت false.
