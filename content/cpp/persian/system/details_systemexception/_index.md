## Details_SystemException کلاس

کلاسی پایه برای کلاس‌هایی که استثنای سیستم (نه برنامه) را نمایندگی می‌کنند. هیچ‌گاه نمونه‌های این کلاس را به صورت دستی ایجاد نکنید. به‌جای آن از کلاس SystemException استفاده کنید. هرگز نمونه‌های کلاس SystemException را داخل [System::SmartPtr](../smartptr/) نپوشانید.

```cpp
class Details_SystemException : public System::Details_Exception
```
