## SmartPtrInfo::operator!() const متد


بررسی می‌کند که آیا شیء info به اشاره‌گری غیر تهی اشاره نمی‌کند.

```cpp
bool System::SmartPtrInfo::operator!() const
```


### مقدار بازگشت

False اگر شیء info به هیچ اشاره‌گری اشاره نکند یا اگر اشاره‌گر مرجع null باشد، در غیر این صورت true.
