## SmartPtrInfo::operator bool() const متد

بررسی می‌کند آیا شیء info به اشاره‌گر غیر تهی اشاره می‌کند یا خیر.

```cpp
System::SmartPtrInfo::operator bool() const
```

### مقدار بازگشت

True اگر شیء info به اشاره‌گر اشاره کند و این اشاره‌گر تهی نباشد؛ در غیر این صورت false.
