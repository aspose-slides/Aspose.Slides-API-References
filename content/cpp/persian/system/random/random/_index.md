## Random::Random() سازنده

شمارشی جدید را مقداردهی اولیه می‌کند، با استفاده از مقدار بذر پیش‌فرض وابسته به زمان.

```cpp
System::Random::Random()
```

## Random::Random(int32_t) سازنده

شمارشی جدید از کلاس [System.Random](../) مقداردهی اولیه می‌کند، با استفاده از مقدار بذر مشخص‌شده.

```cpp
System::Random::Random(int32_t seed)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| seed | **int32_t** | بذری که برای تولید یک دنباله عدد تصادفی شبه-تصادفی استفاده می‌شود |
