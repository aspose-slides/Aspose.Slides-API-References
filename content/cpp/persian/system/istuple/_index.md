## System::IsTuple(const SharedPtr\<Object\>\&, int32_t) تابع

بررسی می‌کند که آیا شیء یک تاپل است (اینترفیس ITuple را پیاده‌سازی می‌کند). در پیاده‌سازی الگوی موقعیتی استفاده می‌شود.

```cpp
bool System::IsTuple(const SharedPtr<Object> &object, int32_t length)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| object | const [SharedPtr](../sharedptr/)\<[Object](../object/)\>\& | شیء برای بررسی. |
| length | **int32_t** | طول پیش‌بینی‌شده تاپل |

### مقدار بازگشتی

شیء یک تاپل است و طول آن برابر با مقدار پیش‌بینی‌شده است
