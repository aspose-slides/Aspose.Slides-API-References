## ValueType کلاس

Baseclass برای نوع‌های مقدار با [Object](../object/) inheritance که به‌دلیل بهینه‌سازی عملکرد کوتاه می‌شود. این نوع باید در stack تخصیص یابد و به توابع به صورت مقدار یا ارجاع پاس داده شود. هرگز از کلاس [System::SmartPtr](../smartptr/) برای مدیریت اشیاء این نوع استفاده نکنید.

```cpp
class ValueType
```
