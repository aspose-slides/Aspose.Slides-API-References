## System::IsNaN(const T\&) تابع

تعیین می‌کند که آیا مقدار مشخص‌شده مقدار Not-A-Number (NaN) است.

```cpp
template<typename T> bool System::IsNaN(const T &value)
```

### پارامترهای قالب

| پارامتر | توضیح |
| --- | --- |
| T | نوع مقداری که توسط تابع بررسی می‌شود |

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| value | const T\& | مقداری که باید بررسی شود |

### مقدار بازگشت

True اگر **value** مقدار NaN باشد، در غیر این صورت - false
