## Version::Version(int, int, int, int) سازنده

یک نمونه را می‌سازد که مقادیر اصلی، ثانویه، ساخت و بازنگری مشخص‌شده را نمایان می‌کند.

```cpp
System::Version::Version(int major, int minor, int build, int revision)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| major | int | شماره نسخه اصلی |
| minor | int | شماره نسخه ثانویه |
| build | int | شماره ساخت |
| revision | int | شماره بازنگری |
