## DateTimeOffset::operator>=(const DateTimeOffset\&) const متد


تعیین می‌کند که آیا شیء جاری نمایانگر مقدار تاریخ و زمان است که بعدتر از یا همان مقدار نمایانگر توسط شیء [DateTimeOffset](../) مشخص‌شده باشد.

```cpp
bool System::DateTimeOffset::operator>=(const DateTimeOffset &other) const
```


### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| other | const [DateTimeOffset](../)\& | شیء [DateTimeOffset](../) برای مقایسه شیء جاری با |

### مقدار بازگشتی

True اگر مقدار تاریخ و زمان نمایانگر توسط شیء جاری بعدتر از یا همان مقدار نمایانگر توسط **other** باشد، در غیر این صورت false
