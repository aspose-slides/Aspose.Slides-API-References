## DateTimeOffset::operator<(const DateTimeOffset\&) const method

تعیین می‌کند که آیا شیء فعلی مقدار تاریخ و زمان قبلی نسبت به مقداری که توسط شیء [DateTimeOffset](../) مشخص شده است را نشان می‌دهد یا خیر.

```cpp
bool System::DateTimeOffset::operator<(const DateTimeOffset &other) const
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| other | const [DateTimeOffset](../)\& | شیء [DateTimeOffset](../) برای مقایسه با شیء فعلی |

### مقدار بازگشت

True اگر مقدار تاریخ و زمان نشان‌داده‌شده توسط شیء فعلی قبل از مقداری باشد که توسط **other** نمایان شده است، در غیر این‌صورت - false
