## DateTimeOffset::Compare(const DateTimeOffset\&, const DateTimeOffset\&) متد


دو شیء [DateTimeOffset](../) را مقایسه می‌کند.

```cpp
static int System::DateTimeOffset::Compare(const DateTimeOffset &first, const DateTimeOffset &second)
```


### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| first | const [DateTimeOffset](../)\& | شیء اول برای مقایسه. |
| second | const [DateTimeOffset](../)\& | شیء دوم برای مقایسه. |

### مقدار بازگشت

- 1 - اگر **first** زودتر از **second** باشد، 1 - اگر **first** بعد از **second** باشد، 0 - اگر **first** برابر **second** باشد.
