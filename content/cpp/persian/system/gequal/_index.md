## System::GEqual(const ExpressionT\&, const ConstantT\&) تابع

الگوهای نسبی '>=' را پیاده‌سازی می‌کند.

```cpp
template<class ExpressionT,class ConstantT> bool System::GEqual(const ExpressionT &left, const ConstantT &constant)
```

### پارامترهای الگو

| پارامتر | توضیح |
| --- | --- |
| ExpressionT | نوع عبارت سمت چپ. |
| ConstantT | نوع عبارت ثابت. |

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| left | const ExpressionT\& | عبارت‌ای که بررسی می‌شود. |
| constant | const ConstantT\& | عبارت‌ای که با عبارت سمت چپ مقایسه می‌شود. |

### مقدار بازگشتی

true اگر بررسی نوع موفق باشد، در غیر این صورت false.
