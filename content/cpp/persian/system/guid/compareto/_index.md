## Guid::CompareTo(const Guid\&) const متد


انجام مقایسه حسابی GUIDها که توسط شیء جاری و شیء مشخص‌شده نشان داده می‌شوند.

```cpp
int System::Guid::CompareTo(const Guid &g) const
```


### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| g | const [Guid](../)\& | مقایسه‌شونده |

### مقدار بازگشت

- 1 اگر GUID نمایان‌گر توسط شیء جاری کمتر از GUID نمایان‌گر توسط **g** باشد؛ 0 اگر GUIDها برابر باشند؛ 1 اگر GUID نمایان‌گر توسط شیء جاری بزرگتر از GUID نمایان‌گر توسط **g** باشد
