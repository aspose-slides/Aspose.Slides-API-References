## Guid::TryParse(const String\&, Guid\&) متد

سعی می‌کند رشتهٔ مشخص‌شده را به شی [Guid](../) تبدیل کند.

```cpp
static bool System::Guid::TryParse(const String &input, Guid &g)
```

### Arguments

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| input | const [String](../../string/)\& | رشته‌ای برای تبدیل |
| g | [Guid](../)\& | شی [Guid](../) خروجی، در صورت موفقیت. |

### Return Value

True, اگر رشتهٔ ورودی نمایانگر [Guid](../) معتبر باشد، در غیر این صورت false.
