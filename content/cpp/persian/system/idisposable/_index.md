## کلاس IDisposable


متدهایی را تعریف می‌کند که منابع متعلق به شیء فعلی را آزاد می‌کنند. اشیاء این کلاس باید فقط با استفاده از تابع [System::MakeObject()](../makeobject/) ساخته شوند. هرگز نمونه‌ای از این نوع را روی پشته یا با عملگر new ایجاد نکنید، زیرا منجر به خطاهای زمان اجرا و/یا اشکال‌های ادعایی می‌شود. همیشه این کلاس را در یک اشاره‌گر [System::SmartPtr](../smartptr/) بپیچید و از این اشاره‌گر برای عبور به توابع به‌عنوان آرگومان استفاده کنید.

```cpp
class IDisposable : public virtual System::Object
```
