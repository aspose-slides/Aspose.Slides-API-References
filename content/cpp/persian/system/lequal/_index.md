```cpp
template<class ExpressionT,class ConstantT> bool System::LEqual(const ExpressionT &left, const ConstantT &constant)
```


### پارامترهای قالب

| پارامتر | توضیحات |
| --- | --- |
| ExpressionT | نوع عبارت چپ. |
| ConstantT | نوع عبارت ثابت. |

### آرگومان‌ها

| پارامتر | نوع | توضیحات |
| --- | --- | --- |
| left | const ExpressionT\& | عبارت‌ای که بررسی خواهد شد. |
| constant | const ConstantT\& | عبارت‌ای که با عبارت چپ مقایسه می‌شود. |

### مقدار بازگشت

در صورتی که بررسی نوع موفق باشد true و در غیر این صورت false.
