## Attribute::GetCustomAttribute(const TypeInfo\&, const TypeInfo\&) متد

یک ویژگی سفارشی از نوع مشخص شده که به نوع مشخص شده اعمال شده است را برمی‌گرداند.

```cpp
static Object::ptr System::Attribute::GetCustomAttribute(const TypeInfo &type, const TypeInfo &attributeType)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| type | const [TypeInfo](../../typeinfo/)\& | نوع ویژگی که بازیابی می‌شود |
| attributeType | const [TypeInfo](../../typeinfo/)\& | نوع ویژگی برای بازیابی |

### مقدار بازگشتی

یک ویژگی بازیابی‌شده یا null اگر نوع مشخص شده ویژگی از نوع موردنظر نداشته باشد.
