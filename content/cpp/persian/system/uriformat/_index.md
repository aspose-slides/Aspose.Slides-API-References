## UriFormat enum


مشخص می‌کند که URI چگونه رمزگذاری می‌شود.

```cpp
enum class UriFormat
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| UriEscaped | 1 | رمزگذاری بر اساس RFC-2396. |
| Unescaped | 2 | بدون رمزگذاری. |
| SafeUnescaped | 3 | فقط کاراکترهایی که معنای رزرو شده در URI دارند، رمزگذاری می‌شوند. |
