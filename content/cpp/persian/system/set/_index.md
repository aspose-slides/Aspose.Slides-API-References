## System::Set(ExpressionT\&, const ExpressionT\&) تابع


### پارامترهای قالب

| پارامتر | توضیح |
| --- | --- |
| ExpressionT | نوع متغیر. |

### آرگومان‌ها

| پارامتر | نوع | توضیح |
