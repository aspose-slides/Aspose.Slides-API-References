## کلاس‌ها

| کلاس | توضیح |
| --- | --- |
| [Control](./control/) | کلاس ساختگی برای قابل کامپایل کردن کد ترجمه‌شده‌ای که از کلاس [Control](./control/) استفاده می‌کند. متدها پیاده‌سازی نشده‌اند. اشیاء این کلاس باید فقط با استفاده از تابع [System::MakeObject()](../system/makeobject/) تخصیص داده شوند. هرگز نمونه‌ای از این نوع را روی پشته یا با استفاده از عملگر new ایجاد نکنید، زیرا منجر به خطاهای زمان اجرا و/یا خطاهای استنتاج می‌شود. همیشه این کلاس را درون یک اشاره‌گر [System::SmartPtr](../system/smartptr/) بپیچید و از این اشاره‌گر برای پاس کردن به توابع به عنوان آرگومان استفاده کنید. |
| [Form](./form/) | کلاس ساختگی برای قابل کامپایل کردن کد ترجمه‌شده‌ای که از کلاس [Form](./form/) استفاده می‌کند. متدها پیاده‌سازی نشده‌اند. اشیاء این کلاس باید فقط با استفاده از تابع [System::MakeObject()](../system/makeobject/) تخصیص داده شوند. هرگز نمونه‌ای از این نوع را روی پشته یا با استفاده از عملگر new ایجاد نکنید، زیرا منجر به خطاهای زمان اجرا و/یا خطاهای استنتاج می‌شود. همیشه این کلاس را درون یک اشاره‌گر [System::SmartPtr](../system/smartptr/) بپیچید و از این اشاره‌گر برای پاس کردن به توابع به عنوان آرگومان استفاده کنید. |
| [IButtonControl](./ibuttoncontrol/) | کلاس ساختگی برای قابل کامپایل کردن کد ترجمه‌شده‌ای که از اینترفیس [IButtonControl](./ibuttoncontrol/) استفاده می‌کند. اشیاء این کلاس باید فقط با استفاده از تابع [System::MakeObject()](../system/makeobject/) تخصیص داده شوند. هرگز نمونه‌ای از این نوع را روی پشته یا با استفاده از عملگر new ایجاد نکنید، زیرا منجر به خطاهای زمان اجرا و/یا خطاهای استنتاج می‌شود. همیشه این کلاس را درون یک اشاره‌گر [System::SmartPtr](../system/smartptr/) بپیچید و از این اشاره‌گر برای پاس کردن به توابع به عنوان آرگومان استفاده کنید. |
| [Screen](./screen/) | اطلاعاتی در مورد نمایشگرها فراهم می‌کند. فقط [Windows](../system.windows/). این یک نوع تک‌نمونه (singleton) است که مدیریت حافظه توسط تابع(های) دسترسی انجام می‌شود. شما هرگز نباید مستقیماً نمونه‌ای از آن ایجاد کنید. |
