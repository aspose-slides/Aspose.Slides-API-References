## FlatStyle enum

تعریف می‌کند که آیا کنترل به صورت صاف یا سه‌بعدی رسم می‌شود.

```cpp
enum class FlatStyle
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| Flat | 0 | [Control](../control/) به صورت صاف رسم می‌شود. |
| Popup | 1 | [Control](../control/) به صورت صاف رسم می‌شود مگر اینکه موس بر روی آن حرکت کند زمانی که به صورت 3D مشابه رسم می‌شود. |
| Standard | 2 | [Control](../control/) به صورت 3D مشابه رسم می‌شود. |
| System | 3 | استایل توسط سیستم‌عامل کنترل می‌شود. |
