## AutoSizeMode enum

نحوه عملکرد autosize را تعریف می‌کند.

```cpp
enum class AutoSizeMode
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| GrowAndShrink | 0 | [Control](../control/) به‌صورت خودکار بزرگ و کوچک می‌شود. نمی‌تواند به‌صورت دستی تغییر اندازه دهد. |
| GrowOnly | 1 | [Control](../control/) به‌صورت خودکار بزرگ می‌شود اما نمی‌تواند زیر حداقل اندازه کوچک شود. می‌تواند به‌صورت دستی تغییر اندازه دهد. |
