## Control کلاس

Dummy کلاس برای اینکه کد ترجمه‌شده‌ای که از کلاس [Control](./) استفاده می‌کند، قابل کامپایل باشد. متدها پیاده‌سازی نشده‌اند. اشیاء این کلاس باید فقط با استفاده از تابع [System::MakeObject()](../../system/makeobject/) تخصیص داده شوند. هرگز نمونه‌ای از این نوع را در پشته یا با استفاده از عملگر new ایجاد نکنید، زیرا منجر به خطاهای زمان اجرا و/یا خطاهای اثبات خواهد شد. همیشه این کلاس را در یک اشاره‌گر [System::SmartPtr](../../system/smartptr/) بپیچانید و از این اشاره‌گر برای پاس دادن به توابع به عنوان آرگومان استفاده کنید.

```cpp
class Control : public System::Object
```
