## CheckState enum

State of checkable control (e. g. checkbox).

```cpp
enum class CheckState
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| Unchecked | 0 | انتخاب‌نشده. |
| Checked | 1 | انتخاب‌شده. |
| Indeterminate | 2 | حالت انتقال که معمولاً به‌صورت سایه‌دار نشان داده می‌شود. |
