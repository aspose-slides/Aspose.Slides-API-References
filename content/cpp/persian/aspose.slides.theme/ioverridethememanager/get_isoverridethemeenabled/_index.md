## IOverrideThemeManager::get_IsOverrideThemeEnabled() متد

تعیین می‌کند که آیا [OverrideTheme](../../overridetheme/) تم مؤثر به‌ارث‌برده را جایگزین می‌کند یا خیر. برای فعال‌سازی [OverrideTheme](../../overridetheme/) برای جایگزینی، از متدهای OverrideTheme.Init*() استفاده کنید. برای غیرفعال‌سازی [OverrideTheme](../../overridetheme/) از جایگزینی، از متد [get_OverrideTheme()](../get_overridetheme/)->Clear() استفاده کنید. فقط-خواندنی **bool**.

```cpp
virtual bool Aspose::Slides::Theme::IOverrideThemeManager::get_IsOverrideThemeEnabled()=0
```
