## IMathBorderBox::set_StrikethroughTopLeftToBottomRight(bool) متد

خط‌خراش از بالا-چپ به پایین-راست (پیش‌فرض false است). وضعیت مخفی یا نمایش داده‌شده یک خط مورب خط‌خراش را از گوشهٔ بالا-چپ تا گوشهٔ پایین-راست جعبهٔ حاشیه مشخص می‌کند.

```cpp
virtual void Aspose::Slides::MathText::IMathBorderBox::set_StrikethroughTopLeftToBottomRight(bool value)=0
```

## توضیحات

مثال: 
```cpp
auto borderBox = System::MakeObject<MathematicalText>(u"x+y+z")->ToBorderBox();
borderBox->set_StrikethroughTopLeftToBottomRight(true);
```
