## IMathBorderBox::get_StrikethroughBottomLeftToTopRight() متد

Strikethrough Bottom-Left to Top-Right (به‌طور پیش‌فرض false است). وضعیت مخفی یا نمایش داده شده یک خط مورب خط خورده را از گوشه پایین-چپ تا گوشه بالای-راست جعبه حاشیه مشخص می‌کند.

```cpp
virtual bool Aspose::Slides::MathText::IMathBorderBox::get_StrikethroughBottomLeftToTopRight()=0
```

## نکات

مثال:
```cpp
auto borderBox = System::MakeObject<MathematicalText>(u"x+y+z")->ToBorderBox();
borderBox->set_StrikethroughBottomLeftToTopRight(true);
```
