## IMathMatrix::set_MinColumnWidth(uint32_t) متد

حداقل عرض ستون بر حسب تویپ (1/20th of a point) فاصله‌ی گپ (که به عنوان \u201CColumn Gap\u201D یا \u201CGap Width\u201D نیز شناخته می‌شود) به MinColumnWidth اضافه می‌شود تا کل Matrix [Column](../../../aspose.slides/column/) Spacing (فاصله بین لبه‌های مشابه ستون‌های مختلف) تعیین شود. پیش‌فرض: 0.

```cpp
virtual void Aspose::Slides::MathText::IMathMatrix::set_MinColumnWidth(uint32_t value)=0
```

## توضیحات

مثال:
```cpp
auto matrix = System::MakeObject<MathMatrix>(2, 3);
matrix->set_MinColumnWidth(20);
```
