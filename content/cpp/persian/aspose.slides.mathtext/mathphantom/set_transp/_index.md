## MathPhantom::set_Transp(bool) متد


مقداری را تنظیم می‌کند که نشان می‌دهد آیا فانتوم برای قوانین فاصله‌گذاری مبتنی بر کلاس شفاف است یا خیر.

```cpp
void Aspose::Slides::MathText::MathPhantom::set_Transp(bool value) override
```

## توضیحات


زمانی که **true** باشد، عملگرها و نمادهای داخل فانتوم همچنان بر فاصله‌گذاری ریاضی اطراف فانتوم تأثیر می‌گذارند (همانند وقتی که قابل مشاهده باشد). زمانی که **false** باشد، فاصله‌گذاری مبتنی بر کلاس نادیده گرفته می‌شود. متناظر با ویژگی OMML **m:transp** است.
