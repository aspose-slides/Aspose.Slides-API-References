## IMathPhantom::set_Transp(bool) متد

مقداری را تنظیم می‌کند که نشان می‌دهد آیا فانتوم برای قواعد فاصله‌گذاری مبتنی بر کلاس شفاف است یا نه.

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_Transp(bool value)=0
```

## توضیحات

زمانی که **true**، عملگرها و نمادهای داخل فانتوم همچنان بر فاصله‌گذاری ریاضی اطراف فانتوم تأثیر می‌گذارند (همانند قابل رؤیت بودن). زمانی که **false**، فاصله‌گذاری مبتنی بر کلاس نادیده گرفته می‌شود. مطابق با ویژگی OMML **m:transp**.
