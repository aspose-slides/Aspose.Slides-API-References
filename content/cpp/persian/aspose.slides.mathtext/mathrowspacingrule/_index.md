## MathRowSpacingRule enum

نوع فاصله عمودی بین ستون‌ها در یک ماتریکس یا آرایه

```cpp
enum class MathRowSpacingRule
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| SingleLineGap | 0 | فاصله یک‌خطی |
| OneAndAHalfLineGap | 1 | فاصله یک‌خط و نیم |
| TwoLineGap | 2 | فاصله دو خطی |
| Exactly | 3 | به‌صورت دقیق (به مقدار ویژگی RowSpacing وابسته است، به نقطه اندازه‌گیری می‌شود) |
| Multiple | 4 | چندگانه (به مقدار ویژگی RowSpacing وابسته است، به خط اندازه‌گیری می‌شود) |
