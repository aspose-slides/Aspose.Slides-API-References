## XmlNodeReader::ReadString() متد

محتوای یک عنصر یا گرهٔ متنی را به‌صورت رشته می‌خواند.

```cpp
String System::Xml::XmlNodeReader::ReadString() override
```

### مقدار بازگشتی

محتویات عنصر یا گرهٔ متنی (این می‌تواند شامل CDATA، [Text](../../../system.text/) گره‌ها و غیره باشد). این می‌تواند یک رشتهٔ خالی باشد اگر خواننده روی چیزی غیر از عنصر یا گرهٔ متنی قرار دارد، یا اگر محتوای متنی بیشتری برای برگرداندن در زمینهٔ فعلی وجود نداشته باشد. نکته: گرهٔ متنی می‌تواند یک عنصر یا گرهٔ متن ویژگی باشد.
