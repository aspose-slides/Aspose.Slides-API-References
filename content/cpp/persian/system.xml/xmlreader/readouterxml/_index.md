## XmlReader::ReadOuterXml() متد

هنگامی‌که در یک کلاس مشتق‌شده بازنویسی شود، محتوا را شامل نشانه‌گذاری که این گره و تمام فرزندان آن را نمایان می‌کند، می‌خواند.

```cpp
virtual String System::Xml::XmlReader::ReadOuterXml()
```

### مقدار بازگشت

اگر خواننده روی یک گره عنصر یا ویژگی قرار گرفته باشد، این متد تمام محتوای XML شامل نشانه‌گذاری گرهٔ فعلی و تمام فرزندان آن را باز می‌گرداند؛ در غیر این صورت، یک رشتهٔ خالی برمی‌گرداند.
