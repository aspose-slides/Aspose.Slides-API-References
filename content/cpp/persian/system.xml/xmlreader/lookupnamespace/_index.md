## XmlReader::LookupNamespace(const String\&) متد

زمانی که در یک کلاس‌ مشتق بازنویسی شود، پیشوند فضای‌نام را در محدوده عنصر جاری حل می‌کند.

```cpp
virtual String System::Xml::XmlReader::LookupNamespace(const String &prefix)=0
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| prefix | const [String](../../../system/string/)\& | پیشوندی که می‌خواهید URI فضای‌نام آن را حل کنید. برای تطبیق با فضای‌نام پیش‌فرض، یک رشته خالی را پاس دهید. |

### مقدار بازگشتی

URI فضای‌نامی که پیشوند به آن نگاشت می‌شود یا **nullptr** اگر پیشوند متطابقی یافت نشود.
