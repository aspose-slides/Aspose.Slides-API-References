## XmlReader::ReadInnerXml() متد

هنگامی که در یک کلاس مشتق بازنویسی شود، تمام محتوای شامل نشانه‌گذاری را به‌صورت رشته می‌خواند.

```cpp
virtual String System::Xml::XmlReader::ReadInnerXml()
```

### مقدار بازگشتی

تمام محتوای XML شامل نشانه‌گذاری در گرهٔ جاری. اگر گرهٔ جاری فرزندی نداشته باشد، یک رشتهٔ خالی برگردانده می‌شود. اگر گرهٔ جاری نه یک عنصر باشد و نه یک ویژگی، یک رشتهٔ خالی برگردانده می‌شود.
