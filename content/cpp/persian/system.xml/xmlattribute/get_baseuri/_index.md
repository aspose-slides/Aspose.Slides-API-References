## XmlAttribute::get_BaseURI() متد


URI پایهٔ Uniform Resource Identifier (URI) گره را برمی‌گرداند.

```cpp
String System::Xml::XmlAttribute::get_BaseURI() override
```


### مقدار بازگشت

مکانی که گره از آن بارگذاری شده است یا [String::Empty](../../../system/string/empty/) اگر گره URI پایه‌ای نداشته باشد. گره‌های [Attribute](../../../system/attribute/) همان URI پایه را به عنوان عنصر مالک خود دارند. اگر یک گره ویژگی صاحب عنصری نداشته باشد، get_BaseURI [String::Empty](../../../system/string/empty/) را باز می‌گرداند.
