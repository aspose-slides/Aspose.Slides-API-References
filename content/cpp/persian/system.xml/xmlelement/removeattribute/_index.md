## XmlElement::RemoveAttribute(String) متد

یک ویژگی را با نام حذف می‌کند.

```cpp
virtual void System::Xml::XmlElement::RemoveAttribute(String name)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| name | [String](../../../system/string/) | نام ویژگی که باید حذف شود. این یک نام کامل است. با مقدار **get_Name** گرهٔ مطابقت‌دهنده مقایسه می‌شود. |

## XmlElement::RemoveAttribute(String, String) متد

یک ویژگی را با نام محلی و URI فضا نام مشخص حذف می‌کند. (اگر ویژگی حذف‌شده مقدار پیش‌فرض داشته باشد، بلافاصله جایگزین می‌شود).

```cpp
virtual void System::Xml::XmlElement::RemoveAttribute(String localName, String namespaceURI)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| localName | [String](../../../system/string/) | نام محلی ویژگی که باید حذف شود. |
| namespaceURI | [String](../../../system/string/) | URI فضا نام ویژگی که باید حذف شود. |
