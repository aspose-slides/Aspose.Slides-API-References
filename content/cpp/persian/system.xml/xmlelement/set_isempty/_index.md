## XmlElement::set_IsEmpty(bool) متد

قالب تگ عنصر را تنظیم می‌کند.

```cpp
void System::Xml::XmlElement::set_IsEmpty(bool value)
```

### آرگومان‌ها

| پارامتر | نوع | توضیحات |
| --- | --- | --- |
| value | **bool** | مقداری که باید تنظیم شود. هنگام تنظیم این مقدار، اگر به **true** تنظیم شود، فرزندان عنصر حذف می‌شوند و عنصر به صورت قالب تگ کوتاه سریال‌سازی می‌شود. اگر به **false** تنظیم شود، مقدار تغییر می‌کند (بدون در نظر گرفتن اینکه عنصر محتوا دارد یا نه)؛ اگر عنصر خالی باشد، به صورت قالب طولانی سریال‌سازی می‌شود. |
