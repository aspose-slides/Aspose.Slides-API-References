## XmlElement::RemoveAttributeAt(int32_t) متد


گرهٔ ویژگی را با شاخص مشخص شده از عنصر حذف می‌کند. (اگر ویژگی حذف‌شده مقدار پیش‌فرض داشته باشد، بلافاصله جایگزین می‌شود).

```cpp
virtual SharedPtr<XmlNode> System::Xml::XmlElement::RemoveAttributeAt(int32_t i)
```


### آرگومان‌ها

| Parameter | Type | Description |
| --- | --- | --- |
| i | **int32_t** | شاخص گره‌ای که باید حذف شود. اولین گره شاخص 0 دارد. |

### مقدار بازگشت

گرهٔ ویژگی حذف‌شده یا **nullptr** اگر گره‌ای با شاخص داده شده وجود نداشته باشد.
