```cpp
bool System::Xml::XmlElement::get_IsEmpty()
```

### مقدار بازگشت

**true** اگر عنصر باید به صورت برچسب کوتاه \"<tt><item/></tt>\" سریالایز شود؛ **false** برای فرمت طولانی \"<tt><item></item></tt>\".
