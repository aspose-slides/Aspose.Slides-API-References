## XmlDeclaration::get_Standalone() متد

مقدار ویژگی standalone را برمی‌گرداند.

```cpp
String System::Xml::XmlDeclaration::get_Standalone()
```

### مقدار بازگشتی

مقدارهای معتبر **yes** هستند اگر تمام اعلان‌های موجودیت مورد نیاز توسط سند XML درون سند موجود باشد یا **no** اگر یک تعریف نوع سند خارجی (DTD) مورد نیاز باشد. اگر ویژگی standalone در اعلامیه XML موجود نباشد، این متد [String::Empty](../../../system/string/empty/) را برمی‌گرداند.
