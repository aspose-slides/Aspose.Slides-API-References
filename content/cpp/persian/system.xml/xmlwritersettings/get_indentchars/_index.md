## XmlWriterSettings::get_IndentChars() متد

رشتهٔ کاراکتری که برای تورفتگی استفاده می‌شود را برمی‌گرداند. این تنظیم زمانی به کار می‌رود که مقدار [XmlWriterSettings::set_Indent](../set_indent/) روی **true** تنظیم شده باشد.

```cpp
String System::Xml::XmlWriterSettings::get_IndentChars()
```

### مقدار بازگشتی

رشتهٔ کاراکتری که برای تورفتگی استفاده می‌شود. می‌توان آن را به هر مقدار رشته‌ای تنظیم کرد. با این حال، برای اطمینان از معتبر بودن XML، باید تنها کاراکترهای سفید معتبر، مانند کاراکترهای فاصله، تب، بازگشت carriage یا خط جدید را مشخص کنید. مقدار پیش‌فرض دو فاصله است.
