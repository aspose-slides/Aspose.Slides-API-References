## XmlWriterSettings::get_Indent() متد

Returns a value indicating whether to indent elements.

```cpp
bool System::Xml::XmlWriterSettings::get_Indent()
```

### مقدار بازگشت

**true** برای نوشتن هر عنصر در خطوط جدید و تورفتگی؛ در غیر این صورت **false**. مقدار پیش‌فرض **false** است.
