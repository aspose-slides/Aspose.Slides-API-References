## XmlWriterSettings::get_OmitXmlDeclaration() متد

Returns a value indicating whether to omit an XML declaration.

```cpp
bool System::Xml::XmlWriterSettings::get_OmitXmlDeclaration()
```

### مقدار بازگشتی

**true** برای حذف اعلان XML؛ در غیر این صورت، **false**. مقدار پیش‌فرض **false** است و اعلان XML نوشته می‌شود.
