## XmlWriterSettings::get_NamespaceHandling() متد

یک مقدار را برمی‌گرداند که نشان می‌دهد آیا [XmlWriter](../../xmlwriter/) باید اعلان‌های فضای نام تکراری را هنگام نوشتن محتوای XML حذف کند. رفتار پیش‌فرض این است که نویسنده تمام اعلان‌های فضای نام موجود در حل‌کننده فضای نام نویسنده را خروجی دهد.

```cpp
System::Xml::NamespaceHandling System::Xml::XmlWriterSettings::get_NamespaceHandling()
```

### مقدار بازگشتی

enumeration NamespaceHandling که برای تعیین اینکه آیا اعلان‌های فضای نام تکراری در [XmlWriter](../../xmlwriter/) حذف شوند استفاده می‌شود.
