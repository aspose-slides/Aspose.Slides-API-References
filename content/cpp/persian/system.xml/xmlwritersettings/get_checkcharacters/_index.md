## XmlWriterSettings::get_CheckCharacters() متد

مقداری را برمی‌گرداند که نشان می‌دهد آیا نویسندهٔ XML باید بررسی کند تا اطمینان حاصل شود تمام کاراکترهای سند با بخش \"2.2 Characters\" از W3C [XML 1.0 Recommendation](https://www.w3.org/TR/REC-xml/#charsets) مطابقت دارند یا نه.

```cpp
bool System::Xml::XmlWriterSettings::get_CheckCharacters()
```

### مقدار بازگشتی

**true** برای انجام بررسی کاراکترها؛ در غیر این صورت، **false**. مقدار پیش‌فرض **true** است.
