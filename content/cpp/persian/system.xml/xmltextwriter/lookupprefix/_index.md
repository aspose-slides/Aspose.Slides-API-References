## XmlTextWriter::LookupPrefix(String) متد

پیشوند نزدیک‌ترین که در محدودهٔ فضای نام فعلی برای URI فضای نام تعریف شده است را برمی‌گرداند.

```cpp
String System::Xml::XmlTextWriter::LookupPrefix(String ns) override
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| ns | [String](../../../system/string/) | URI فضای نامی که می‌خواهید پیشوند آن را پیدا کنید. |

### مقدار بازگشتی

پیشوند مطابقت‌دار. یا **nullptr** اگر URI فضای نام مطابقت‌دار در محدودهٔ فعلی یافت نشود.
