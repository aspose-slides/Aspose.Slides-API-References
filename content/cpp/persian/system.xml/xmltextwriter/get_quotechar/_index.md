## XmlTextWriter::get_QuoteChar() متد

کاراکتری را که برای نقل قول مقادیر ویژگی‌ها استفاده می‌شود بر می‌گرداند.

```cpp
char16_t System::Xml::XmlTextWriter::get_QuoteChar()
```

### مقدار بازگشتی

کاراکتری که برای نقل قول مقادیر ویژگی‌ها استفاده می‌شود. این کاراکتر باید یک کوتیشن تک‌نقش **'** یا یک کوتیشن دو‌نقش **\"** باشد. مقدار پیش‌فرض یک کوتیشن دو‌نقش است.
