## WhitespaceHandling enum


مشخص می‌کند که فضای سفید چگونه مدیریت می‌شود.

```cpp
enum class WhitespaceHandling
```

### Values

| نام | مقدار | توضیح |
| --- | --- | --- |
| All | 0 | بازگرداندن گره‌های **Whitespace** و **SignificantWhitespace**. این مقدار پیش‌فرض است. |
| Significant | 1 | فقط گره‌های **SignificantWhitespace** را بازگرداند. |
| None | 2 | هیچ گره‌ای از نوع **Whitespace** و هیچ گره‌ای از نوع **SignificantWhitespace** بازگردانده نمی‌شود. |
