## XmlWriter::LookupPrefix(String) متد

هنگامی که در یک کلاس مشتق‌شده بازنویسی می‌شود، نزدیک‌ترین پیشوند تعریف‌شده در محدوده فضای نام فعلی برای URI فضای نام را برمی‌گرداند.

```cpp
virtual String System::Xml::XmlWriter::LookupPrefix(String ns)=0
```

### پارامترها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| ns | [String](../../../system/string/) | URI فضای نام که پیشوند آن را می‌خواهید پیدا کنید. |

### مقدار بازگشت

پیشوند مطابق یا **nullptr** اگر URI فضای نام مطابقی در محدوده فعلی یافت نشود.
