## XmlTextReader::get_IsEmptyElement() متد

یک مقدار بازمی‌گرداند که نشان می‌دهد آیا گرهٔ فعلی یک عنصر خالی است (به عنوان مثال، **<MyElement/>**).

```cpp
bool System::Xml::XmlTextReader::get_IsEmptyElement() override
```

### مقدار بازگشت

**true** اگر گرهٔ فعلی یک عنصر ([XmlTextReader::get_NodeType](../get_nodetype/) مقدار برابر [XmlNodeType::Element](../../xmlnodetype/)) باشد که با **/>** تمام می‌شود؛ در غیر این صورت، **false**.
