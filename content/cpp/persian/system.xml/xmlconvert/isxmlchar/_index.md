## XmlConvert::IsXmlChar(char16_t) متد

بررسی می‌کند که آیا کاراکتر وارد شده یک کاراکتر معتبر XML است یا نه.

```cpp
static bool System::Xml::XmlConvert::IsXmlChar(char16_t ch)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| ch | char16_t | کاراکتری که باید اعتبارسنجی شود. |

### مقدار بازگشت

**true** اگر کاراکتر وارد شده یک کاراکتر معتبر XML باشد؛ در غیر این صورت **false**.
