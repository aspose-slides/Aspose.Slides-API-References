## XmlConvert::IsXmlSurrogatePair(char16_t, char16_t) متد

بررسی می‌کند که آیا جفت کاراکترهای سوروگیت ورودی یک کاراکتر معتبر XML است.

```cpp
static bool System::Xml::XmlConvert::IsXmlSurrogatePair(char16_t lowChar, char16_t highChar)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| lowChar | char16_t | کاراکتر سوروگیت برای اعتبارسنجی. |
| highChar | char16_t | کاراکتر سوروگیت برای اعتبارسنجی. |

### مقدار بازگشتی

**true** اگر جفت کاراکتر سوروگیت ورودی یک کاراکتر معتبر XML باشد؛ در غیر این صورت **false**.
