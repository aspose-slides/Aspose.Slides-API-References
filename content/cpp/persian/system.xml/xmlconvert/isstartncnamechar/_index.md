## XmlConvert::IsStartNCNameChar(char16_t) متد

بررسی می‌کند که آیا کاراکتر ورودی یک نوع کاراکتر Start Name Character معتبر است.

```cpp
static bool System::Xml::XmlConvert::IsStartNCNameChar(char16_t ch)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| ch | char16_t | کاراکتری که باید اعتبارسنجی شود. |

### مقدار بازگشت

**true** اگر کاراکتر یک نوع کاراکتر Start Name Character معتبر باشد؛ در غیر این صورت، **false**.
