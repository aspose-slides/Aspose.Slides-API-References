## XmlReaderSettings::get_MaxCharactersInDocument() متد

یک مقدار را برمی‌گرداند که حداکثر تعداد کاراکترهای مجاز در یک سند XML را نشان می‌دهد. مقدار صفر (0) به این معنی است که هیچ محدودیتی برای اندازه سند XML وجود ندارد. مقدار غیرصفر حداکثر اندازه را برحسب کاراکتر تعیین می‌کند.

```cpp
int64_t System::Xml::XmlReaderSettings::get_MaxCharactersInDocument()
```

### مقدار برگشتی

حداکثر تعداد کاراکترهای مجاز در یک سند XML. مقدار پیش‌فرض صفر است.
