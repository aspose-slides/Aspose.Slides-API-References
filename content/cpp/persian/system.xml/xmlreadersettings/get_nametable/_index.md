## XmlReaderSettings::get_NameTable() متد

[XmlNameTable](../../xmlnametable/) مورد استفاده برای مقایسه‌های رشته‌ای اتمی را برمی‌گرداند.

```cpp
SharedPtr<XmlNameTable> System::Xml::XmlReaderSettings::get_NameTable()
```

### مقدار بازگشت

[XmlNameTable](../../xmlnametable/) که تمام رشته‌های اتمی استفاده‌شده توسط تمام نمونه‌های [XmlReader](../../xmlreader/) ایجاد شده با استفاده از این شیء [XmlReaderSettings](../) را ذخیره می‌کند. مقدار پیش‌فرض **nullptr** است. نمونه ایجادشده [XmlReader](../../xmlreader/) در صورتی که این مقدار **nullptr** باشد، از یک [NameTable](../../nametable/) خالی جدید استفاده خواهد کرد.
