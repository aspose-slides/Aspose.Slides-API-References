## NewLineHandling enum

نحوه‌ی پردازش شکست‌های خط را مشخص می‌کند.

```cpp
enum class NewLineHandling
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| Replace | 0 | کاراکترهای خط جدید برای مطابقت با کاراکتری که در مقدار [XmlWriterSettings::set_NewLineChars](../xmlwritersettings/set_newlinechars/) مشخص شده است، جایگزین می‌شوند. |
| Entitize | 1 | کاراکترهای خط جدید انتیتی می‌شوند. این تنظیم تمام کاراکترها را هنگام خواندن خروجی توسط [XmlReader](../xmlreader/) نرمال‌ساز حفظ می‌کند. |
| None | 2 | کاراکترهای خط جدید بدون تغییر می‌مانند. خروجی همان ورودی است. |
