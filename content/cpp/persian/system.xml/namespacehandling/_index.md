## NamespaceHandling enum

Specifies whether to remove duplicate namespace declarations in the [XmlWriter](../xmlwriter/).

```cpp
enum class NamespaceHandling
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| Default | 0 | مشخص می‌کند که اعلام‌نام‌های فضای‌نام تکراری حذف نخواهند شد. |
| OmitDuplicates | 1 | مشخص می‌کند که اعلام‌نام‌های فضای‌نام تکراری حذف خواهند شد. برای حذف فضای‌نام تکراری، پیشوند و نام‌فضا باید مطابقت داشته باشند. |
