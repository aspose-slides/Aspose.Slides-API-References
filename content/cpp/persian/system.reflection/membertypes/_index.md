## MemberTypes enum

هر نوع عضو را علامت‌گذاری می‌کند.

```cpp
enum class MemberTypes
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| Constructor | 1 | مشخص می‌کند که عضو یک سازنده است. |
| Event | 2 | مشخص می‌کند که عضو یک رویداد است. |
| Field | 4 | مشخص می‌کند که عضو یک فیلد است. |
| Method | 8 | مشخص می‌کند که عضو یک متد است. |
| Property | 16 | مشخص می‌کند که عضو یک ویژگی است. |
| TypeInfo | 32 | مشخص می‌کند که عضو یک نوع است. |
| Custom | 64 | مشخص می‌کند که عضو یک نوع عضو سفارشی است. |
| NestedType | 128 | مشخص می‌کند که عضو یک نوع تو در تو است. |
| All | 191 | تمام انواع اعضا را مشخص می‌کند. |
