## Details_ReflectionTypeLoadException کلاس

ReflectionTypeLoadException هنگام فراخوانی روش Module.GetTypes پرتاب می‌شود اگر هر یک از کلاس‌های موجود در یک ماژول نتوانند بارگذاری شوند. هرگز به‌صورت دستی نمونه‌های این کلاس را ایجاد نکنید. به‌جای آن از کلاس ReflectionTypeLoadException استفاده کنید. هرگز نمونه‌های کلاس ReflectionTypeLoadException را درون [System::SmartPtr](../../system/smartptr/) بسته‌بندی نکنید.

```cpp
class Details_ReflectionTypeLoadException : public System::Details_Exception
```
