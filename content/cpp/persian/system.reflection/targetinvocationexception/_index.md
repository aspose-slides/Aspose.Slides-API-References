## TargetInvocationException تعریف نوع

TargetInvocationException توسط روش‌هایی که از طریق بازتاب فراخوانی می‌شوند، پرتاب می‌شود. هرگز نمونه‌های کلاس TargetInvocationException را در [System::SmartPtr](../../system/smartptr/) قرار ندهید.

```cpp
using System::Reflection::TargetInvocationException = typedef System::ExceptionWrapper<Details_TargetInvocationException>
```
