## Regex::get_RightToLeft() متد

بررسی می‌کند که آیا مطابقت به حالت راست به چپ انجام می‌شود یا خیر.

```cpp
bool System::Text::RegularExpressions::Regex::get_RightToLeft()
```

### مقدار برگشتی

True اگر مطابقت به صورت راست به چپ انجام شود، false اگر به صورت چپ به راست انجام شود.
