## RegexOptions enum

[Regex](../regex/) گزینه‌ها.

```cpp
enum class RegexOptions
```

### مقادیر

| نام | مقدار | شرح |
| --- | --- | --- |
| None | 0 | رفتار پیش‌فرض. |
| Compiled | 1 | برای بهبود عملکرد regex را کامپایل می‌کند. همیشه به‌صورت پیش‌فرض انجام می‌شود. |
| CultureInvariant | 2 | از تطبیق مستقل از فرهنگ استفاده می‌شود. نادیده گرفته می‌شود. |
| ECMAScript | 4 | از سینتکس ECMAScript استفاده می‌شود. نادیده گرفته می‌شود. |
| ExplicitCapture | 8 | فقط ضبط صریح. نادیده گرفته می‌شود. |
| IgnoreCase | 16 | در تطبیق حروف را نادیده بگیرد. |
| IgnorePatternWhitespace | 32 | فاصله‌های خالی را در الگو نادیده بگیرد. پشتیبانی نمی‌شود. |
| Multiline | 64 | کاراکترهای '^' و '$' را به‌عنوان شروع و پایان خط، نه کل رشته در نظر بگیرد. |
| RightToLeft | 128 | تطبیق از راست به چپ. پشتیبانی نمی‌شود. |
| Singleline | 256 | به '.' اجازه می‌دهد که هر کاراکتری را بدون استثناها مطابقت دهد (به‌طور معمول، کاراکترهای خط جدید مطابقت داده نمی‌شوند). |
