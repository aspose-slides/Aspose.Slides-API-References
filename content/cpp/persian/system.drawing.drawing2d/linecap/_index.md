## LineCap enum

سبک‌های سر انتهایی موجود که یک شیء [Pen](../../system.drawing/pen/) می‌تواند برای پایان یک خط استفاده کند را نشان می‌دهد.

```cpp
enum class LineCap
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| Flat | 0 | سر خط صاف. |
| Square | 1 | سر خط مربع. |
| Round | 2 | سر خط گرد. |
| Triangle | 3 | سر خط مثلثی. |
| NoAnchor | 16 | بدون لنگر. |
| SquareAnchor | 17 | سر خط لنگر مربع. |
| RoundAnchor | 18 | سر خط لنگر گرد. |
| DiamondAnchor | 19 | سر خط لنگر الماسی. |
| ArrowAnchor | 20 | سر خط لنگر پیکان. |
| AnchorMask | 240 | ماسکی که برای بررسی اینکه آیا سر خط یک سر لنگر است استفاده می‌شود. |
| Custom | 255 | سر خط سفارشی. |
