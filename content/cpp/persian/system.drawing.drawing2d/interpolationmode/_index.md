
### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| Invalid | n/a | معادل [QualityMode::Invalid](../qualitymode/). |
| Default | n/a | حالت پیش‌فرض. |
| Low | n/a | کیفیت پایین. |
| High | n/a | کیفیت بالا. |
| Bilinear | n/a | درون‌یابی دوخطی. |
| Bicubic | n/a | درون‌یابی بیکوبیک. |

| HighQualityBilinear | n/a | درون‌یابی بای‌لاینر با کیفیت بالا. |
