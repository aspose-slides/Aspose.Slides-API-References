## GraphicsPath::AddPie(float, float, float, float, float, float) متد

خطوط مرزی مشخص‌شدهٔ شکل پی را به مسیری که توسط آبجکت جاری نمایان شده است، اضافه می‌کند.

```cpp
void System::Drawing::Drawing2D::GraphicsPath::AddPie(float x, float y, float width, float height, float startAngle, float sweepAngle)
```

### Arguments

| Parameter | Type | Description |
| --- | --- | --- |
| x | **float** | مختصات X گوشهٔ بالا-چپ مستطیلی که بیضی را محصور می‌کند |
| y | **float** | مختصات Y گوشهٔ بالا-چپ مستطیلی که بیضی را محصور می‌کند |
| width | **float** | عرض مستطیلی که گوشهٔ بالا-چپ آن مختصات X و Y را دارد و بیضی را محصور می‌کند |
| height | **float** | ارتفاع مستطیلی که گوشهٔ بالا-چپ آن مختصات X و Y را دارد و بیضی را محصور می‌کند |
| startAngle | **float** | زاویهٔ شروع شکل پی را بر حسب درجه، به جهت ساعتگرد از محور X اندازه‌گیری می‌کند |
| sweepAngle | **float** | زاویهٔ بین زاویهٔ شروع و انتهای شکل پی را مشخص می‌کند |
