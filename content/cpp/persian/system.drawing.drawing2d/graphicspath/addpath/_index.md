## GraphicsPath::AddPath(const SharedPtr\<GraphicsPath\>\&, bool) متد

مسیر مشخص‌شده را به مسیری که توسط شیء جاری نمایش داده می‌شود اضافه می‌کند.

```cpp
void System::Drawing::Drawing2D::GraphicsPath::AddPath(const SharedPtr<GraphicsPath> &path, bool connect)
```

### آرگومان‌ها

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| path | const [SharedPtr](../../../system/sharedptr/)\<[GraphicsPath](../)\>\& | مسیری که باید اضافه شود |
| connect | **bool** | True مشخص می‌کند که آخرین شکل اول در **path** بخشی از آخرین شکل مسیر نمایش داده شده توسط شیء جاری است؛ false مشخص می‌کند که شکل اول در **path** و آخرین شکل مسیر نمایش داده شده توسط شیء جاری شکل‌های جداگانه‌ای هستند |
