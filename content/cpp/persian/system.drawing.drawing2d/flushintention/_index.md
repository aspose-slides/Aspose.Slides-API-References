## FlushIntention enum

```cpp
enum class FlushIntention
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| Flush | 0 | بلافاصله خاتمه می‌یابد. |
| Sync | 1 | به زودی‌ترین زمان ممکن اجرا می‌شود. |
