## WrapMode enum

مشخص می‌کند که یک تکستچر یا یک گرادیان هنگامیکه کوچکتر از ناحیه پرشده باشد، چگونه تایل می‌شود.

```cpp
enum class WrapMode
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| Tile | 0 | گرادیان یا تکستچر را تایل می‌کند. |
| TileFlipX | 1 | تکستچر یا گرادیان را به‌صورت افقی معکوس می‌کند و سپس آن را تایل می‌کند. |
| TileFlipY | 2 | تکستچر یا گرادیان را به‌صورت عمودی معکوس می‌کند و سپس آن را تایل می‌کند. |
| TileFlipXY | 3 | تکستچر یا گرادیان را به‌صورت افقی و عمودی معکوس می‌کند و سپس آن را تایل می‌کند. |
| Clamp | 4 | تکستچر یا گرادیان را به مرز شیء می‌چسباند. |
