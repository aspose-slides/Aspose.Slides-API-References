## PixelOffsetMode enum

Specifies how pixels are offset when being rendered.

```cpp
enum class PixelOffsetMode
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| Invalid | n/a | مقدار نامعتبر. |
| Default | n/a | حالت پیش‌فرض. |
| HighSpeed | n/a | حالت با کیفیت پایین (کارایی بالا). |
| HighQuality | n/a | حالت با کیفیت بالا (کارایی کمتر). |
| None | n/a | بدون جابه‌جایی پیکسل. |
| Half | n/a | پیکسل‌ها به مقدار -0.5 واحد به‌صورت افقی و عمودی جابه‌جا می‌شوند برای آنتی‌الیاسینگ با کارایی بالا. |
