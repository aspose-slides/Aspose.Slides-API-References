## ContentAlignment 열거형

콘텐츠 정렬을 지정합니다.

```cpp
enum class ContentAlignment
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| TopLeft | 1 | 수직으로 위에 정렬되고, 수평으로 왼쪽에 정렬됩니다. |
| TopCenter | 2 | 수직으로 위에 정렬되고, 수평으로 가운데에 정렬됩니다. |
| TopRight | 4 | 수직으로 위에 정렬되고, 수평으로 오른쪽에 정렬됩니다. |
| MiddleLeft | 16 | 수직으로 중간에 정렬되고, 수평으로 왼쪽에 정렬됩니다. |
| MiddleCenter | 32 | 수직으로 중간에 정렬되고, 수평으로 가운데에 정렬됩니다. |
| MiddleRight | 64 | 수직으로 중간에 정렬되고, 수평으로 오른쪽에 정렬됩니다. |
| BottomLeft | 256 | 수직으로 아래에 정렬되고, 수평으로 왼쪽에 정렬됩니다. |
| BottomCenter | 512 | 수직으로 아래에 정렬되고, 수평으로 가운데에 정렬됩니다. |
| BottomRight | 1024 | 수직으로 아래에 정렬되고, 수평으로 오른쪽에 정렬됩니다. |
