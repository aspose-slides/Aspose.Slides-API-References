## RectangleF::Offset(const PointF\&) 메서드

현재 개체가 나타내는 사각형의 위치를 지정된 양만큼 이동시킵니다.

```cpp
void System::Drawing::RectangleF::Offset(const PointF &pos)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| pos | const [PointF](../../pointf/)\& | [PointF](../../pointf/) 객체는 사각형이 오프셋되는 양을 지정합니다; 포인트의 X 좌표 값은 사각형 왼쪽 위 모서리의 X 좌표에 더할 양을 지정하고 포인트의 Y 좌표는 사각형 왼쪽 위 모서리의 Y 좌표에 더할 양을 지정합니다 |
