## RectangleF::FromLTRB(float, float, float, float) 메서드

지정된 가장자리 위치를 가진 사각형을 나타내는 새로운 [RectangleF](../) 객체를 생성합니다.

```cpp
static RectangleF System::Drawing::RectangleF::FromLTRB(float left, float top, float right, float bottom)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| left | **float** | 사각형 왼쪽 가장자리의 X 좌표 |
| top | **float** | 사각형 위쪽 가장자리의 Y 좌표 |
| right | **float** | 사각형 오른쪽 가장자리의 X 좌표 |
| bottom | **float** | 사각형 아래쪽 가장자리의 Y 좌표 |

### 반환 값

지정된 사각형을 나타내는 [RectangleF](../) 클래스의 인스턴스
