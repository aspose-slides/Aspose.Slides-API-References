## Point::Round(const PointF\&) 메서드

지정된 [PointF](../../pointf/) 객체를 사용하여 [Point](../) 객체를 생성하며, [PointF](../../pointf/) 객체의 X 및 Y 좌표 값을 가장 가까운 정수 값으로 반올림합니다.

```cpp
static Point System::Drawing::Point::Round(const PointF &point)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| point | const [PointF](../../pointf/)\& | [PointF](../../pointf/) 객체에서 [Point](../) 객체를 생성하기 위한 |

## 반환 값

[Point](../) 객체는 **point** 로부터 생성됩니다.
