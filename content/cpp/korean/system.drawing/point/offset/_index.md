## Point::Offset(int, int) 메서드

현재 객체가 나타내는 X 및 Y 좌표 값을 지정된 값만큼 오프셋합니다.

```cpp
void System::Drawing::Point::Offset(int dx, int dy)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| dx | int | X 좌표 값을 오프셋할 값 |
| dy | int | Y 좌표 값을 오프셋할 값 |

## Point::Offset(Point) 메서드

현재 객체가 나타내는 X 및 Y 좌표를 지정된 [Point](../) 객체가 나타내는 X 및 Y 좌표 값에 각각 오프셋합니다.

```cpp
void System::Drawing::Point::Offset(Point point)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| point | [Point](../) | [Point](../) 객체는 X 및 Y 좌표를 오프셋할 값을 지정합니다 |
