## Rectangle::Offset(const Point\&) 메서드

현재 객체가 나타내는 사각형의 위치를 지정된 양만큼 이동합니다.

```cpp
void System::Drawing::Rectangle::Offset(const Point &pos)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| pos | const [Point](../../point/)\& | [Point](../../point/) 개체는 사각형이 이동하는 양을 지정합니다; 점의 X 좌표값은 사각형 왼쪽 위 모서리의 X 좌표에 추가할 양을 지정하고, 점의 Y 좌표값은 사각형 왼쪽 위 모서리의 Y 좌표에 추가할 양을 지정합니다. |
