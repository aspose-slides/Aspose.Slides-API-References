## SizeF::Add(const SizeF\&, const SizeF\&) 메서드

새로운 [SizeF](../) 객체를 반환합니다. 이 객체는 지정된 [SizeF](../) 객체들의 합으로, 너비 값은 지정된 객체들의 너비 값 합과 같고 높이 값은 지정된 객체들의 높이 값 합과 같습니다.

```cpp
static SizeF System::Drawing::SizeF::Add(const SizeF &size1, const SizeF &size2)
```

### 인수

| Parameter | Type | Description |
| --- | --- | --- |
| size1 | const [SizeF](../)\& | 첫 번째 피연산자 |
| size2 | const [SizeF](../)\& | 두 번째 피연산자 |

### 반환값

**size1**과 **size2**의 합인 [SizeF](../) 객체
