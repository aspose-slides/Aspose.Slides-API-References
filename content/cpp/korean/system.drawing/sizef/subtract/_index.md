## SizeF::Subtract(const SizeF\&, const SizeF\&) 메서드

새로운 [SizeF](../) 객체를 반환합니다. 이 객체는 **size2**를 **size1**에서 뺀 결과이며, 즉 **size2's** 너비 값이 **size1's** 너비 값에서 뺀 결과와 **size2's** 높이 값이 **size1's** 높이 값에서 뺀 결과를 가집니다.

```cpp
static SizeF System::Drawing::SizeF::Subtract(const SizeF &size1, const SizeF &size2)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| size1 | const [SizeF](../)\& | 빼는 대상이 되는 [SizeF](../) 객체 |
| size2 | const [SizeF](../)\& | 빼야 할 [SizeF](../) 객체 |

### 반환값

[SizeF](../) 객체는 **size2**를 **size1**에서 뺀 결과입니다.
