## Size::Subtract(const Size\&, const Size\&) 메서드

새로운 [Size](../) 객체를 반환합니다. 이 객체는 **size2**를 **size1**에서 뺀 결과이며, 즉 **size1's** 너비 값은 **size2's** 너비 값을 **size1's**에서 뺀 결과이고, 높이 값은 **size2's** 높이 값을 **size1's**에서 뺀 결과입니다.

```cpp
static Size System::Drawing::Size::Subtract(const Size &size1, const Size &size2)
```

### 인수

| 매개변수 | 유형 | 설명 |
| --- | --- | --- |
| size1 | const [Size](../)\& | [Size](../) 객체를 뺄 대상 |
| size2 | const [Size](../)\& | [Size](../) 객체를 뺄 대상 |

### 반환값

[Size](../) 객체는 **size1**에서 **size2**를 뺀 결과입니다.
