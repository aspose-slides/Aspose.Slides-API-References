## Size::Size() 생성자

[Size](../) 객체를 새로 생성하고 width와 height 값을 0으로 초기화합니다.

```cpp
System::Drawing::Size::Size()
```

## Size::Size(const Point\&) 생성자

[Size](../) 객체를 새로 생성하고 width와 height 값을 해당 포인트의 X 및 Y 좌표값으로 각각 초기화합니다.

```cpp
System::Drawing::Size::Size(const Point &point)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| point | const [Point](../../point/)\& | [Point](../../point/) 객체의 X 및 Y 좌표를 사용하여 생성 중인 [Size](../) 객체의 width와 height 값을 초기화하는 데 사용됩니다. |

## Size::Size(int, int) 생성자

[Size](../) 객체를 새로 생성하고 지정된 값으로 초기화합니다.

```cpp
System::Drawing::Size::Size(int width, int height)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| width | int | width에 대한 값 |
| height | int | height의 값 |
