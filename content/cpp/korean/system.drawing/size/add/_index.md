## Size::Add(const Size\&, const Size\&) 메서드

지정된 [Size](../) 객체의 합인 새 [Size](../) 객체를 반환합니다. 즉, 너비 값은 지정된 객체들의 너비 값 합과 같고 높이 값은 지정된 객체들의 높이 값 합과 같습니다.

```cpp
static Size System::Drawing::Size::Add(const Size &size1, const Size &size2)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| size1 | const [Size](../)\& | 첫 번째 피연산자 |
| size2 | const [Size](../)\& | 두 번째 피연산자 |

### 반환 값

[Size](../) 객체는 **size1**과 **size2**의 합입니다.
