## SystemColors 클래스

사전 생성된 [Color](../color/) 객체 집합을 제공하는 클래스이며, [Windows](../../system.windows/) 디스플레이 요소의 색상을 나타냅니다. 이것은 인스턴스 서비스가 없는 정적 타입입니다. 어떠한 방법으로도 인스턴스를 생성해서는 안 됩니다.

```cpp
class SystemColors
```
