## StringFormatFlags 열거형

텍스트 문자열의 표시 및 레이아웃 정보를 지정합니다.

```cpp
enum class StringFormatFlags
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| DirectionRightToLeft | 1 | 오른쪽에서 왼쪽으로 텍스트 방향. |
| DirectionVertical | 2 | [Text](../../system.drawing.text/)는 수직으로 정렬됩니다. |
| FitBlackBox | 4 | 문자 일부가 레이아웃 박스를 넘어설 수 있습니다. |
| DisplayFormatControl | 32 | 제어 문자가 표시됩니다. |
| NoFontFallback | 1024 | [Font](../font/) 폴백이 비활성화되었습니다. |
| MeasureTrailingSpaces | 2048 | 각 줄 끝에 후행 공백을 삽입합니다. |
| NoWrap | 4096 | [Text](../../system.drawing.text/) 래핑이 비활성화되었습니다. |
| LineLimit | 8192 | 전체 줄이 서식 사각형에 배치됩니다. |
| NoClip | 16384 | 글리프의 넘치는 부분이 표시될 수 있습니다. |
