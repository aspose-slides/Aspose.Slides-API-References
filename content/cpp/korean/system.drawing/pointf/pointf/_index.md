## PointF::PointF() 생성자

새로운 [PointF](../) 객체를 생성하고 X 및 Y 좌표 값을 0으로 초기화합니다.

```cpp
System::Drawing::PointF::PointF()
```

## PointF::PointF(float, float) 생성자

새로운 [PointF](../) 객체를 생성하고 지정된 값으로 초기화합니다.

```cpp
System::Drawing::PointF::PointF(float x, float y)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| x | **float** | X 좌표의 값 |
| y | **float** | Y 좌표의 값 |

## PointF::PointF(const SizeF\&) 생성자

새로운 [PointF](../) 객체를 생성하고 X 및 Y 좌표 값을 해당 [SizeF](../../sizef/) 객체의 너비와 높이 값으로 각각 초기화합니다.

```cpp
System::Drawing::PointF::PointF(const SizeF &size)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| size | const [SizeF](../../sizef/)\& | [SizeF](../../sizef/) 객체로, 그 너비와 높이 값을 사용하여 생성되는 [PointF](../) 객체의 X 및 Y 좌표 값을 초기화합니다. |
