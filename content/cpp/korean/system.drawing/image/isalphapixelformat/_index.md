## Image::IsAlphaPixelFormat(Imaging::PixelFormat) 메서드

지정된 픽셀 형식에 알파 정보가 포함되어 있는지 확인합니다.

```cpp
static bool System::Drawing::Image::IsAlphaPixelFormat(Imaging::PixelFormat pixfmt)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| pixfmt | [Imaging::PixelFormat](../../../system.drawing.imaging/pixelformat/) | 테스트할 픽셀 형식 |

### 반환 값

픽셀 형식 **pixfmt**에 알파 정보가 포함되어 있으면 true, 그렇지 않으면 false
