## StringDigitSubstitute 열거형

문자열의 숫자가 로케일 또는 언어에 따라 어떻게 치환되는지 지정합니다.

```cpp
enum class StringDigitSubstitute
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| User | 0 | 사용자 정의 치환. |
| None | 1 | 치환이 비활성화되었습니다. |
| National | 2 | 사용자 로케일의 공식 국가 언어에 해당하는 숫자를 치환합니다. |
| Traditional | 3 | 사용자 로케일의 공식 국가 언어와 다를 수 있는 사용자의 기본 스크립트 또는 언어에 해당하는 숫자를 치환합니다. |
