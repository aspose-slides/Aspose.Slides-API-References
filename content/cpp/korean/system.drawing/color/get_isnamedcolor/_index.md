```cpp
bool System::Drawing::Color::get_IsNamedColor() const
```

### 반환 값

True if the [Color](../) was created using either the FromName(String) method or the [FromKnownColor(KnownColor)](../fromknowncolor/) method; otherwise, false를 반환합니다.
