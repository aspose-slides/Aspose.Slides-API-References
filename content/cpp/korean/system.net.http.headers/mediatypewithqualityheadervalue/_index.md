## MediaTypeWithQualityHeaderValue 클래스

‘Content-Type’ 헤더 값에 추가 품질 요소가 포함된 MIME 타입을 나타냅니다. 이 클래스의 객체는 [System::MakeObject()](../../system/makeobject/) 함수만 사용해 할당해야 합니다. 스택에 직접 생성하거나 operator new를 사용해 인스턴스를 만들지 마십시오. 이렇게 하면 런타임 오류 및/또는 어설션 오류가 발생할 수 있습니다. 항상 이 클래스를 [System::SmartPtr](../../system/smartptr/) 포인터에 래핑하고 해당 포인터를 함수 인수로 전달하십시오.

```cpp
class MediaTypeWithQualityHeaderValue : public System::Net::Http::Headers::MediaTypeHeaderValue
```
