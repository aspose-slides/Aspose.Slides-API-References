## HttpResponseHeaders::get_TransferEncodingChunked() 메서드


값을 가져옵니다. 이 값은 'Transfer-Encoding' 헤더 값에 'Chunked'가 포함되어 있는지를 나타냅니다.

```cpp
Nullable<bool> System::Net::Http::Headers::HttpResponseHeaders::get_TransferEncodingChunked()
```


### 반환 값

'Transfer-Encoding' 헤더 값에 'Chunked'가 포함된 경우 True, 그렇지 않으면 false.
