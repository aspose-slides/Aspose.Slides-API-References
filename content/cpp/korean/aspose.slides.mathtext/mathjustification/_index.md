## MathJustification 열거형

수학 단락(같은 단락 내에서 인접한 수학 텍스트 인스턴스 시리즈)의 정렬을 지정합니다.

```cpp
enum class MathJustification
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| LeftJustified | 1 | 수학 텍스트를 왼쪽에 맞춥니다 |
| RightJustified | 2 | 수학 텍스트를 오른쪽에 맞춥니다 |
| Centered | 3 | 수학 텍스트를 가운데에 맞춥니다 |
| CenteredAsGroup | 4 | 페이지에서 전체 수학 블록 그룹을 단일 단위로 가운데에 맞춥니다. 이는 수학 텍스트 인스턴스들이 서로에 대해 정렬될 수 있지만, 전체 수학 텍스트 그룹이 전체적으로 가운데에 배치된다는 의미입니다. |
