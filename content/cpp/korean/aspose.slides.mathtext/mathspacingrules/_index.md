## MathSpacingRules 열거형

열의 열 사이의 간격(수평 간격) 유형

```cpp
enum class MathSpacingRules
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| SingleSpacingGap | 0 | 단일 (열에 대해 1 em 또는 행에 대해 1 라인) |
| OneAndHalfSpacingGap | 1 | 1.5배 (열에 대해 1.5 em, 행에 대해 1.5 라인) |
| DoubleSpacingGap | 2 | 이중 간격 (열에 대해 2 em, 행에 대해 2 라인) |
| Exactly | 3 | 정확히 지정된 값 열에 대해서는 ColumnGap 값을 사용하며 twip 단위, 행에 대해서는 RowGap 값을 사용하며 twip 단위 |
| Multiple | 4 | 다중 열에 대해서는 ColumnGap 값을 0.5 em 단위로 사용, 행에 대해서는 RowGap 값을 라인 단위로 사용 |
