## IMathPhantom::get_Transp() 메서드


팬텀의 투명 여부를 나타내는 값을 가져옵니다. 이는 클래스 기반 간격 규칙에 해당합니다.

```cpp
virtual bool Aspose::Slides::MathText::IMathPhantom::get_Transp()=0
```

## 비고


**true**인 경우, 팬텀 내부의 연산자와 기호는 팬텀 주변의 수학적 간격에 계속 영향을 줍니다(보이는 것처럼). **false**인 경우, 클래스 기반 간격이 무시됩니다. OMML 속성 **m:transp**와 대응됩니다.
