## IMathPhantom::set_Transp(bool) 메서드


클래스 기반 간격 규칙에 대해 팬텀이 투명한지 여부를 나타내는 값을 설정합니다.

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_Transp(bool value)=0
```

## 비고


**true**인 경우, 팬텀 내부의 연산자와 기호는 팬텀 주변의 수학적 간격에 계속 영향을 미칩니다(보이는 것처럼). **false**인 경우, 클래스 기반 간격이 무시됩니다. OMML 속성 **m:transp**에 해당합니다.
