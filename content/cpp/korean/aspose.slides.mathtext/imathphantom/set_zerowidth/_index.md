## IMathPhantom::set_ZeroWidth(bool) 메서드


기본 요소의 너비를 0으로 처리할지 여부를 나타내는 값을 설정합니다.

```cpp
virtual void Aspose::Slides::MathText::IMathPhantom::set_ZeroWidth(bool value)=0
```

## 비고


값이 **true**인 경우, 팬텀은 기본 요소에 대한 가로 공간을 예약하지 않습니다. 이는 OMML 속성 **m:zeroWid**와 대응됩니다.
