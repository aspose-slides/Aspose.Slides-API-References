## MathRowSpacingRule enum

행렬 또는 배열에서 열 사이의 수직 간격 유형

```cpp
enum class MathRowSpacingRule
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| SingleLineGap | 0 | 단일 라인 간격 |
| OneAndAHalfLineGap | 1 | 한 줄 반 간격 |
| TwoLineGap | 2 | 두 줄 간격 |
| Exactly | 3 | 정확히 (RowSpacing 속성의 값을 사용하고, 포인트 단위로 측정) |
| Multiple | 4 | 다중 (RowSpacing 속성의 값을 사용하고, 라인 단위로 측정) |
