## MathPhantom::get_Transp() 메서드

클래스 기반 간격 규칙에 대해 팬텀이 투명한지 여부를 나타내는 값을 가져옵니다.

```cpp
bool Aspose::Slides::MathText::MathPhantom::get_Transp() override
```

## 비고

**true**일 때, 팬텀 내부의 연산자와 기호는 팬텀 주위의 수학적 간격에 여전히 영향을 미칩니다(보이는 것처럼). **false**일 때, 클래스 기반 간격이 무시됩니다. OMML 속성 **m:transp**에 해당합니다.
