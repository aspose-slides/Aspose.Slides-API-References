## NotesPositions 열거형

노트를 내보낸 문서에 렌더링하는 규칙을 나타냅니다

```cpp
enum class NotesPositions
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| None | 0 | 노트가 전혀 표시되지 않도록 지정합니다. |
| BottomFull | 1 | 필요에 따라 추가 페이지를 사용하여 노트를 전체 표시하도록 지정합니다. |
| BottomTruncated | 2 | 노트를 한 페이지에만 표시하도록 지정합니다. |
