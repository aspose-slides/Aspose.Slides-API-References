## EmbedFontCharacters 열거형

```cpp
enum class EmbedFontCharacters
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| OnlyUsed | 0 | 프레젠테이션에 사용된 문자만 포함합니다 (파일 크기를 줄이는 데 가장 좋음). |
| All | 1 | 모든 문자를 포함합니다 (다른 사람이 편집하기에 가장 좋음). |
