## PdfOptions::get_BestImagesCompressionRatio() 메서드

각 이미지에 대해 가장 효과적인 압축(기본 압축 대신)이 자동으로 선택되어야 하는지를 나타냅니다. **bool**.true 로 설정하면 프레젠테이션의 모든 이미지에 대해 가장 적절한 압축 알고리즘이 선택되어 결과 PDF 문서의 크기가 더 작아집니다.

```cpp
bool Aspose::Slides::Export::PdfOptions::get_BestImagesCompressionRatio() override
```

## 비고

최고 이미지 압축 비율 선택은 계산 비용이 많이 들고 추가적인 RAM을 사용하며, 이 옵션은 기본값으로 **bool**.false 입니다.

기본값은 **bool**.false 입니다.
