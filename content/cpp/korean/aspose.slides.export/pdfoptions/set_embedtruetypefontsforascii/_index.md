## PdfOptions::set_EmbedTrueTypeFontsForASCII(bool) 메서드

[Aspose.Slides](../../../aspose.slides/)가 ASCII(33..127 코드 범위) 텍스트에 대한 일반 글꼴을 포함할지 결정합니다. [Fonts](../../../aspose.slides/fonts/)는 127보다 큰 문자 코드는 항상 포함됩니다. 일반 글꼴 목록에는 PDF의 기본 14글꼴과 추가 사용자 지정 글꼴이 포함됩니다. **bool**를 기록합니다.

```cpp
void Aspose::Slides::Export::PdfOptions::set_EmbedTrueTypeFontsForASCII(bool value) override
```

## 비고

기본값은 **true** 입니다.
