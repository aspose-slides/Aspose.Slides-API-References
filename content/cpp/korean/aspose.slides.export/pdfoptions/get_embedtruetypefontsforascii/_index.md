## PdfOptions::get_EmbedTrueTypeFontsForASCII() 메서드

ASCII(33..127 코드 범위) 텍스트에 대해 [Aspose.Slides](../../../aspose.slides/)가 일반 글꼴을 포함할지 여부를 결정합니다. 문자 코드가 127보다 큰 경우 [Fonts](../../../aspose.slides/fonts/)는 항상 포함됩니다. 일반 글꼴 목록에는 PDF의 기본 14글꼴과 추가 사용자 지정 글꼴이 포함됩니다. 읽기 **bool**.

```cpp
bool Aspose::Slides::Export::PdfOptions::get_EmbedTrueTypeFontsForASCII() override
```

## 비고

기본값은 **true**입니다.
