## PdfOptions::set_BestImagesCompressionRatio(bool) method


각 이미지에 대해 기본 압축 대신 가장 효과적인 압축을 자동으로 선택해야 하는지 여부를 나타냅니다. **bool**.true 로 설정하면 프레젠테이션의 모든 이미지에 대해 가장 적합한 압축 알고리즘이 선택되어 결과 PDF 문서의 크기가 더 작아집니다.

```cpp
void Aspose::Slides::Export::PdfOptions::set_BestImagesCompressionRatio(bool value) override
```

## 비고


최고 이미지 압축 비율 선택은 계산 비용이 많이 들며 추가적인 RAM을 사용하고, 이 옵션은 기본값으로 **bool**.false 입니다.

기본값은 **bool**.false 입니다.
