## LinkEmbedDecision 열거형


저장하는 동안 객체가 어떻게 처리되는지 결정합니다.

```cpp
enum class LinkEmbedDecision
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Link | 0 | 객체가 외부에 저장되며 URL로 참조됩니다 |
| Embed | 1 | 가능하면 객체를 생성된 파일에 삽입해야 합니다. 삽입이 불가능한 경우 GetUrl이 호출되고 결과에 따라 객체가 URL로 참조되거나 무시됩니다 |
| Ignore | 2 | 객체가 무시됩니다 |
