## TiffCompressionTypes enum

TIFF 형식으로 프레젠테이션이 압축되는 방식을 제어하는 옵션을 제공합니다.

```cpp
enum class TiffCompressionTypes
```

### Values

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Default | 0 | 기본 압축 방식(LZW)을 지정합니다. |
| None | 1 | 압축을 사용하지 않음을 지정합니다. |
| CCITT3 | 2 | CCITT3 압축 방식을 지정합니다. |
| CCITT4 | 3 | CCITT4 압축 방식을 지정합니다. |
| LZW | 4 | LZW 압축 방식을 지정합니다(기본). |
| RLE | 5 | RLE 압축 방식을 지정합니다. |
