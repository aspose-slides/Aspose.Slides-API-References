## IPdfOptions::set_EmbedTrueTypeFontsForASCII(bool) 메서드


ASCII 문자 32-127에 대해 True를 지정하면 TrueType 글꼴이 포함됩니다. [Fonts](../../../aspose.slides/fonts/) 문자 코드가 127보다 큰 경우는 항상 포함됩니다. **bool** 를 씁니다.

```cpp
virtual void Aspose::Slides::Export::IPdfOptions::set_EmbedTrueTypeFontsForASCII(bool value)=0
```

## 비고


기본값은 **true**입니다.
