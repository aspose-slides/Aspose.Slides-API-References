## SvgExternalFontsHandling 열거형

외부 폰트를 텍스트 그리기에 사용하는 방법을 나타냅니다.

```cpp
enum class SvgExternalFontsHandling
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| AddLinksToFontFiles | 0 | SVG 파일의 스타일 섹션에 별도의 폰트 파일에 대한 링크를 추가합니다. |
| Embed | 1 | 폰트 데이터를 SVG 파일에 직접 저장합니다. 이 옵션을 사용하기 전에 모든 외부 폰트 라이선스 계약을 확인하십시오. |
| Vectorize | 2 | 외부 폰트를 사용하는 모든 텍스트를 그래픽으로 저장합니다. |
