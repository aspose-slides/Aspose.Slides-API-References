```cpp
enum class Conformance
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Ecma376_2006 | 0 | 문서가 ECMA376:2006에 적합함을 지정합니다. |
| Iso29500_2008_Transitional | 1 | 문서가 ISO/IEC 29500:2008 Transitional 적합성 클래스에 적합함을 지정합니다. |
