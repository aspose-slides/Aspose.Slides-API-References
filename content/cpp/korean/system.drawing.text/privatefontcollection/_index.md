## PrivateFontCollection 클래스

클라이언트 애플리케이션이 제공하는 글꼴 패밀리 컬렉션을 나타냅니다. 이 클래스의 객체는 [System::MakeObject()](../../system/makeobject/) 함수를 사용하여 할당해야 합니다. 스택에 직접 생성하거나 operator new를 사용해 인스턴스를 만들면 런타임 오류 및/또는 어설션 오류가 발생합니다. 항상 이 클래스를 [System::SmartPtr](../../system/smartptr/) 포인터로 감싸고, 해당 포인터를 함수 인자로 전달하세요.

```cpp
class PrivateFontCollection : public System::Drawing::Text::FontCollection
```
