## Random::Random() 생성자

새 인스턴스를 초기화하며, 시간에 따라 변하는 기본 시드 값을 사용합니다.

```cpp
System::Random::Random()
```

## Random::Random(int32_t) 생성자

[System.Random](../) 클래스의 새 인스턴스를 초기화하며, 지정된 시드 값을 사용합니다.

```cpp
System::Random::Random(int32_t seed)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| seed | **int32_t** | 의사 난수 시퀀스를 생성하는 데 사용되는 시드 |
