## TypeCode 열거형


객체의 유형을 나타냅니다.

```cpp
enum class TypeCode
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Empty | 0 | null 참조. |
| Object | 1 | 다른 TypeCode에서 명시적으로 표현되지 않은 모든 참조 또는 값 형식을 나타내는 일반 형식. |
| DBNull | 2 | 데이터베이스 null(열) 값. |
| Boolean | 3 | true 또는 false 값을 나타내는 간단한 형식 [Boolean](../boolean/). |
| Char | 4 | 값이 0에서 65535 사이인 부호 없는 16비트 정수를 나타내는 정수 형식. |
| SByte | 5 | 값이 -128에서 127 사이인 부호 있는 8비트 정수를 나타내는 정수 형식. |
| Byte | 6 | 값이 0에서 255 사이인 부호 없는 8비트 정수를 나타내는 정수 형식. |
| Int16 | 7 | 값이 -32768에서 32767 사이인 부호 있는 16비트 정수를 나타내는 정수 형식. |
| UInt16 | 8 | 값이 0에서 65535 사이인 부호 없는 16비트 정수를 나타내는 정수 형식. |
| Int32 | 9 | 값이 -2147483648에서 2147483647 사이인 부호 있는 32비트 정수를 나타내는 정수 형식. |
| UInt32 | 10 | 값이 0에서 4294967295 사이인 부호 없는 32비트 정수를 나타내는 정수 형식. |
| Int64 | 11 | 값이 -9223372036854775808에서 9223372036854775807 사이인 부호 있는 64비트 정수를 나타내는 정수 형식. |
| UInt64 | 12 | 값이 0에서 18446744073709551615 사이인 부호 없는 64비트 정수를 나타내는 정수 형식. |
| Single | 13 | 대략 1.5 x 10 -45에서 3.4 x 10 38 사이의 값을 7자리 정밀도로 나타내는 부동 소수점 형식. |
| Double | 14 | 대략 5.0 x 10 -324에서 1.7 x 10 308 사이의 값을 15-16자리 정밀도로 나타내는 부동 소수점 형식. |
| Decimal | 15 | 값이 1.0 x 10 -28에서 대략 7.9 x 10 28 사이이며 28-29자리 유효숫자를 가진 간단한 형식. |
| DateTime | 16 | 날짜와 시간 값을 나타내는 형식. |
| String | 18 | Unicode 문자 문자열을 나타내는 sealed 클래스 형식. |
