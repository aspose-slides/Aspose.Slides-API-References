## BitConverter::DoubleToInt64Bits(double) 메서드


지정된 double-precision 부동 소수점 값의 이진 표현과 동일한 이진 표현을 가진 64비트 정수 값을 반환합니다.

```cpp
static int64_t System::BitConverter::DoubleToInt64Bits(double value)
```


### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| value | **double** | double-precision 부동 소수점 값 |

### 반환 값

지정된 값과 동일한 이진 표현을 가진 64비트 정수 값
