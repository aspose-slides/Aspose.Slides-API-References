## TimeZone::IsDaylightSavingTime(DateTime) 메서드

지정된 [DateTime](../../datetime/) 객체가 현재 [TimeZone](../) 객체가 나타내는 시간대의 일광 절약 시간 범위에 포함되는지 판단합니다.

```cpp
virtual bool System::TimeZone::IsDaylightSavingTime(DateTime time)=0
```

### 반환 값

지정된 [DateTime](../../datetime/) 객체가 현재 [TimeZone](../) 객체가 나타내는 시간대의 일광 절약 시간 범위에 속하면 true, 그렇지 않으면 - false
