## DateTime::AddTicks(int64_t) const 메서드


Returns a new instance of the [DateTime](../) 클래스 representing the date and time value which is the sum of the value represented by the current object and the specified number of 100-nanosecond intervals.

```cpp
DateTime System::DateTime::AddTicks(int64_t value) const
```


### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| value | **int64_t** | 추가할 100 나노초 간격의 수; 값은 양수 또는 음수가 될 수 있습니다. |

### 반환값

A new instance of the [DateTime](../) 클래스 representing the date and time value which is the sum of the value represented by the current object and **value** of 100-nanosecond intervals
