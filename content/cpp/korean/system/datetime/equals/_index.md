## DateTime::Equals(DateTime) const 메서드


[DateTime](../) 클래스의 지정된 인스턴스가 현재 객체와 동일한 날짜와 시간 값을 나타내는지 결정합니다.

```cpp
constexpr bool System::DateTime::Equals(DateTime other) const
```


### 인수

| 매개변수 | 유형 | 설명 |
| --- | --- | --- |
| other | [DateTime](../) | 현재 객체와 비교할 [DateTime](../) 클래스의 인스턴스 |

### 반환값

두 **other** 및 현재 객체가 동일한 값을 나타내면 true, 그렇지 않으면 false

## DateTime::Equals(DateTime, DateTime) 메서드


[DateTime](../) 클래스의 지정된 인스턴스들이 동일한 날짜와 시간 값을 나타내는지 결정합니다.

```cpp
static constexpr bool System::DateTime::Equals(DateTime t1, DateTime t2)
```


### 인수

| 매개변수 | 유형 | 설명 |
| --- | --- | --- |
| t1 | [DateTime](../) | 첫 번째 비교 대상 |
| t2 | [DateTime](../) | 두 번째 비교 대상 |

### 반환값

두 **t1** 및 **t2**가 동일한 값을 나타내면 true, 그렇지 않으면 false
