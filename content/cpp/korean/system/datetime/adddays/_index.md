## DateTime::AddDays(double) const 메서드

현재 객체가 나타내는 값에 지정된 일 수를 더한 날짜 및 시간 값을 나타내는 [DateTime](../) 클래스의 새 인스턴스를 반환합니다.

```cpp
DateTime System::DateTime::AddDays(double value) const
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| value | **double** | 추가할 일 수; 값은 양수이거나 음수일 수 있습니다 |

### 반환 값

현재 객체가 나타내는 값에 **value** 일수를 더한 날짜 및 시간 값을 나타내는 [DateTime](../) 클래스의 새 인스턴스
