## DateTime::AddMonths(int) const 메서드

현재 객체가 나타내는 값과 지정된 개월 수의 합인 날짜와 시간 값을 나타내는 새 [DateTime](../) 클래스 인스턴스를 반환합니다.

```cpp
DateTime System::DateTime::AddMonths(int value) const
```

### 인수

| 매개변수 | 유형 | 설명 |
| --- | --- | --- |
| value | int | 추가할 개월 수; value는 양수 또는 음수가 될 수 있습니다 |

### 반환 값

현재 객체가 나타내는 값과 **value**개월의 합인 날짜와 시간 값을 나타내는 새 [DateTime](../) 클래스 인스턴스를 반환합니다.
