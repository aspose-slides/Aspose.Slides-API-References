## DateTime::FromFileTime(int64_t) 메서드

지정된 파일 시간을 로컬 시간과 동일한 날짜와 시간 값을 나타내는 [DateTime](../) 클래스의 인스턴스로 변환합니다.

```cpp
static DateTime System::DateTime::FromFileTime(int64_t value)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| value | **int64_t** | 변환할 파일 시간 |

### 반환 값

새로운 [DateTime](../) 클래스의 인스턴스이며, **file_time**와 동일한 날짜와 시간을 나타냅니다.
