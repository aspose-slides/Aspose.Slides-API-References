## DateTime::FromBinary(int64_t) 메서드

지정된 부호 없는 64비트 정수에서 날짜 및 시간 값을 역직렬화하고, 해당 값을 [DateTime](../) 클래스의 새 인스턴스로 설정합니다.

```cpp
static DateTime System::DateTime::FromBinary(int64_t value)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| value | **int64_t** | 날짜 및 시간 값을 역직렬화할 64비트 정수 |

### 반환 값

지정된 부호 없는 64비트 정수 값에서 역직렬화된 날짜 및 시간 값을 나타내는 [DateTime](../) 클래스의 새 인스턴스
