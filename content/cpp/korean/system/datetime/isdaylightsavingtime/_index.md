## DateTime::IsDaylightSavingTime() const 메서드


현재 객체가 나타내는 날짜 및 시간 값이 현재 표준시의 일광 절약 시간 범위에 해당하는지 확인합니다.

```cpp
bool System::DateTime::IsDaylightSavingTime() const
```


### 반환 값

현재 객체가 지정한 날짜 및 시간 값이 일광 절약 시간 범위에 해당하면 True, 그렇지 않으면 - false
