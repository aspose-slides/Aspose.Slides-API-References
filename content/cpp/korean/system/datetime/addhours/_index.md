## DateTime::AddHours(double) const 메서드

현재 객체가 나타내는 값과 지정된 시간 수를 합한 날짜 및 시간 값을 나타내는 새로운 [DateTime](../) 클래스 인스턴스를 반환합니다.

```cpp
DateTime System::DateTime::AddHours(double value) const
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| value | **double** | 추가할 시간 수; 값은 양수 또는 음수가 될 수 있습니다. |

### 반환값

현재 객체가 나타내는 값과 **value** 시간을 합한 날짜 및 시간 값을 나타내는 새로운 [DateTime](../) 클래스 인스턴스를 반환합니다.
