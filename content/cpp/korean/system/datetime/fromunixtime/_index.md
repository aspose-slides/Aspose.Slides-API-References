## DateTime::FromUnixTime(time_t) 메서드

static DateTime System::DateTime::FromUnixTime(time_t value)

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| value | time_t | 변환할 Unix 시간 값 |

### 반환 값

[DateTime](../) 클래스의 새 인스턴스로 **value**와 동일한 날짜와 시간을 나타냅니다.
