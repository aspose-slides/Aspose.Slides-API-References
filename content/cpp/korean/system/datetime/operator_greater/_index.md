## DateTime::operator>(DateTime) const 메서드


현재 객체가 지정된 [DateTime](../) 객체가 나타내는 값보다 이후의 날짜 및 시간 값을 나타내는지 결정합니다.

```cpp
constexpr bool System::DateTime::operator>(DateTime other) const
```


### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| other | [DateTime](../) | 현재 객체와 비교할 [DateTime](../) 객체 |

### 반환 값

현재 객체가 나타내는 날짜 및 시간 값이 **other**가 나타내는 값보다 이후인 경우 true, 그렇지 않으면 false
