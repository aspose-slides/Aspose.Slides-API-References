## DateTime::AddMinutes(double) const 메서드

현재 객체가 나타내는 값과 지정된 분 수를 합한 날짜 및 시간 값을 나타내는 새 [DateTime](../) 클래스 인스턴스를 반환합니다.

```cpp
DateTime System::DateTime::AddMinutes(double value) const
```

### 인수

| Parameter | Type | Description |
| --- | --- | --- |
| value | **double** | 추가할 분의 수; 값은 양수이거나 음수일 수 있습니다 |

### 반환 값

현재 객체가 나타내는 값과 **value** 분을 합한 날짜 및 시간 값을 나타내는 새 [DateTime](../) 클래스 인스턴스.
