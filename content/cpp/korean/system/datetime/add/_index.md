## DateTime::Add(TimeSpan) const 메서드

```cpp
DateTime System::DateTime::Add(TimeSpan value) const
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| value | [TimeSpan](../../timespan/) | 추가할 시간 간격 |

새 인스턴스 [DateTime](../) 클래스의, **tm** 시간 간격을 현재 객체가 나타내는 날짜 및 시간 값에 추가한 결과를 나타내는 날짜 및 시간 값
