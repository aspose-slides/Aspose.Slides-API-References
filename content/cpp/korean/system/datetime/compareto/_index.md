## DateTime::CompareTo(DateTime) const 메서드


[DateTime](../) 클래스를 지정된 인스턴스와 현재 객체가 나타내는 두 날짜 및 시간 값을 비교하고, 시간 축에서 값들의 상대적인 위치를 나타내는 값을 반환합니다.

```cpp
constexpr int System::DateTime::CompareTo(DateTime value) const
```


### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| value | [DateTime](../) | 현재 객체와 비교하기 위한 [DateTime](../) 클래스의 인스턴스 |

### 반환값

현재 객체가 **value**가 나타내는 값보다 이전을 나타내면 0보다 작은 값; 두 객체가 나타내는 값이 동일하면 0; 현재 객체가 **value**가 나타내는 값보다 이후를 나타내면 0보다 큰 값
