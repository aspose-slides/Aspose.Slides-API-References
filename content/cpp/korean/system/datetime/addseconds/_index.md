## DateTime::AddSeconds(double) const 메서드

현재 객체가 나타내는 값과 지정된 초 수의 합인 날짜 및 시간 값을 나타내는 [DateTime](../) 클래스의 새 인스턴스를 반환합니다.

```cpp
DateTime System::DateTime::AddSeconds(double value) const
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| value | **double** | 추가할 초 수; 값은 양수 또는 음수가 될 수 있습니다 |

### 반환 값

현재 객체가 나타내는 값과 **value** 초의 합인 날짜 및 시간 값을 나타내는 [DateTime](../) 클래스의 새 인스턴스입니다.
