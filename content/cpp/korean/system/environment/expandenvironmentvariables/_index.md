## Environment::ExpandEnvironmentVariables(const String\&) 메서드

환경 변수 이름을 지정된 문자열에서 찾아 해당 변수의 값으로 교체하고 결과 문자열을 반환합니다.

```cpp
static String System::Environment::ExpandEnvironmentVariables(const String &name)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| name | const [String](../../string/)\& | 환경 변수 이름을 포함하는 문자열 |

### 반환 값

변수 이름을 **name**에 있는 값으로 교체한 결과 문자열.
