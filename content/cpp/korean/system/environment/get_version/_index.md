## Environment::get_Version() 메서드

[Version](../../version/) 객체를 반환합니다. 이 객체는 공용 언어 런타임 버전에 대한 정보를 나타냅니다. 이 메서드가 반환하는 버전 번호는 실제와 다르며, 반환된 버전이 모든 라이브러리 클래스가 해당 버전에 따라 동작한다는 의미는 아닙니다.

```cpp
static Version System::Environment::get_Version()
```
