## SmartPtrMode 열거형


[SmartPtr](../smartptr/) 포인터 유형: weak 또는 shared. 포인터가 객체를 삭제할지 여부를 결정할 때 카운트되는지 정의합니다.

```cpp
enum class SmartPtrMode : char
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Shared | 0 | Shared 모드: 포인터가 참조 카운팅에 참여합니다. |
| Weak | 1 | Weak 모드: 포인터가 참조 카운팅에 참여하지 않습니다. |
