## UriParser 클래스

새 URI 스키마를 구문 분석하는 데 사용됩니다. [System::MakeObject()](../makeobject/) 함수를 사용하여 이 클래스의 객체를 할당해야 합니다. 스택에 직접 생성하거나 operator new를 사용해서 이 유형의 인스턴스를 만들지 마세요. 이렇게 하면 런타임 오류 및/또는 어설션 오류가 발생합니다. 항상 이 클래스를 [System::SmartPtr](../smartptr/) 포인터로 감싸고, 해당 포인터를 인수로 함수에 전달하십시오.

