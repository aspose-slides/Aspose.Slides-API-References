## Guid::CompareTo(const Guid\&) const 메서드

현재 및 지정된 객체가 나타내는 GUID를 산술적으로 비교합니다.

```cpp
int System::Guid::CompareTo(const Guid &g) const
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| g | const [Guid](../)\& | 비교 대상 |

### 반환 값

- 1: 현재 객체가 나타내는 GUID가 **g**가 나타내는 GUID보다 작을 경우; 0: GUID가 동일할 경우; 1: 현재 객체가 나타내는 GUID가 **g**가 나타내는 GUID보다 클 경우
