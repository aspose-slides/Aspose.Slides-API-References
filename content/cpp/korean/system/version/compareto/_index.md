## Version::CompareTo(const Version\&) const 메서드


현재 객체가 나타내는 버전과 지정된 객체가 나타내는 버전을 비교합니다.

```cpp
int System::Version::CompareTo(const Version &ver) const
```

### 인수

| 매개변수 | 유형 | 설명 |
| --- | --- | --- |
| ver | const [Version](../)\& | 현재 객체와 비교할 [Version](../) 객체 |

### 반환 값

- 1은 현재 객체가 나타내는 버전 번호가 **ver**이 나타내는 버전 번호보다 작을 때; 0은 버전 번호가 같은 경우; 1은 현재 객체가 나타내는 버전 번호가 **ver**이 나타내는 값보다 클 때
