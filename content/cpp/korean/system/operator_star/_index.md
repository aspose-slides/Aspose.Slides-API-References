## System::operator*(const T\&, const Decimal\&) 함수

지정된 값과 지정된 [Decimal](../decimal/) 객체가 나타내는 값의 곱셈 결과를 나타내는 [Decimal](../decimal/) 클래스의 새 인스턴스를 반환합니다.

```cpp
template<typename T,typename _> Decimal System::operator*(const T &x, const Decimal &d)
```

### 인수

| 매개변수 | 유형 | 설명 |
| --- | --- | --- |
| x | const T\& | 첫 번째 곱셈 인자 |
| d | const [Decimal](../decimal/)\& | 두 번째 곱셈 인자를 나타내는 [Decimal](../decimal/) 객체 |

### 반환 값

[Decimal](../decimal/) 클래스의 새 인스턴스로, **x**와 **d**가 나타내는 값의 곱셈 결과를 나타냅니다.
