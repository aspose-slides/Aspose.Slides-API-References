## DateTimeOffset::operator+(TimeSpan) const 메서드

현재 객체가 나타내는 값과 지정된 시간 간격의 합인 날짜 및 시간 값을 나타내는 [DateTimeOffset](../) 클래스의 새 인스턴스를 반환합니다.

```cpp
DateTimeOffset System::DateTimeOffset::operator+(TimeSpan value) const
```

### 인수

| 매개변수 | 유형 | 설명 |
| --- | --- | --- |
| value | [TimeSpan](../../timespan/) | 현재 객체가 나타내는 값에 추가할 시간 간격 |

### 반환 값

현재 객체가 나타내는 값과 **value**의 합인 날짜 및 시간 값을 나타내는 [DateTimeOffset](../) 클래스의 새 인스턴스를 반환합니다.
