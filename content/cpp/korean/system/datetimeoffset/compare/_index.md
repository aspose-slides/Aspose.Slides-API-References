## DateTimeOffset::Compare(const DateTimeOffset\&, const DateTimeOffset\&) 메서드


두 개의 [DateTimeOffset](../) 객체를 비교합니다.

```cpp
static int System::DateTimeOffset::Compare(const DateTimeOffset &first, const DateTimeOffset &second)
```


### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| first | const [DateTimeOffset](../)\& | 비교할 첫 번째 객체. |
| second | const [DateTimeOffset](../)\& | 비교할 두 번째 객체. |

### 반환 값

- 1 - **first**가 **second**보다 이전인 경우, 1 - **first**가 **second**보다 이후인 경우, 0 - **first**가 **second**와 같은 경우.
