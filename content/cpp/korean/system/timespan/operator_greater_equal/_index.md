## TimeSpan::operator>=(TimeSpan) const method


현재 객체가 나타내는 시간 간격이 지정된 객체가 나타내는 시간 간격보다 길거나 같은지 여부를 결정합니다.

```cpp
constexpr bool System::TimeSpan::operator>=(TimeSpan value) const
```


### 매개변수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| value | [TimeSpan](../) | 현재 객체와 비교할 [TimeSpan](../) 객체 |

### 반환 값

현재 객체가 나타내는 시간 간격이 **value**가 나타내는 시간 간격보다 길거나 같으면 true, 그렇지 않으면 false
