## TimeSpan::operator!=(TimeSpan) const 메서드


현재 객체가 나타내는 시간 간격이 지정된 객체가 나타내는 시간 간격과 같지 않은지 여부를 확인합니다.

```cpp
constexpr bool System::TimeSpan::operator!=(TimeSpan value) const
```


### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| value | [TimeSpan](../) | 현재 객체와 비교할 [TimeSpan](../) 객체 |

### 반환값

현재 객체와 지정된 객체가 서로 다른 시간 간격을 나타내면 true, 그렇지 않으면 false
