## TimeSpan::Subtract(TimeSpan) const 메서드

```cpp
TimeSpan System::TimeSpan::Subtract(TimeSpan value) const
```

| value | [TimeSpan](../) | 빼려는 시간 간격을 나타내는 [TimeSpan](../) 객체 |

### 반환 값

새로운 [TimeSpan](../) 클래스 인스턴스를 반환하며, 이는 지정된 객체가 나타내는 시간 간격을 현재 객체가 나타내는 시간 간격에서 빼는 결과인 시간 간격을 나타냅니다.
