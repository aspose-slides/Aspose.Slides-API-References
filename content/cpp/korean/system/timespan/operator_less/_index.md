## TimeSpan::operator<(TimeSpan) const method

현재 객체가 나타내는 시간 간격이 지정된 객체가 나타내는 시간 간격보다 짧은지 여부를 결정합니다.

```cpp
constexpr bool System::TimeSpan::operator<(TimeSpan value) const
```

### Arguments

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| value | [TimeSpan](../) | 현재 객체와 비교할 [TimeSpan](../) 객체 |

### Return Value

현재 객체가 나타내는 시간 간격이 **value**가 나타내는 시간 간격보다 짧으면 True, 그렇지 않으면 false
