## TimeSpan::operator-(TimeSpan) const 메서드

새 [TimeSpan](../) 클래스를 나타내는 인스턴스를 반환합니다. 이 인스턴스는 지정된 객체가 나타내는 시간 간격을 현재 객체가 나타내는 시간 간격에서 빼서 얻은 결과인 시간 간격을 나타냅니다.

```cpp
TimeSpan System::TimeSpan::operator-(TimeSpan value) const
```

### 매개변수

| 매개변수 | 유형 | 설명 |
| --- | --- | --- |
| value | [TimeSpan](../) | [TimeSpan](../) 객체로, 빼려는 시간 간격을 나타냅니다 |

### 반환값

새 [TimeSpan](../) 클래스를 나타내는 인스턴스로, 지정된 객체가 나타내는 시간 간격을 현재 객체가 나타내는 시간 간격에서 빼서 얻은 결과인 시간 간격을 나타냅니다.
