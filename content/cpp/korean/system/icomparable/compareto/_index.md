## IComparable::CompareTo(T) 메서드


현재 객체를 지정된 객체와 비교합니다.

```cpp
virtual int System::IComparable<T>::CompareTo(T other)=0
```


### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| other | T | 현재 객체와 비교할 객체 |

### 반환값

정렬 순서에서 현재 객체가 지정된 객체보다 앞선 경우 음수; 비교된 객체가 동일하면 0; 현재 객체가 지정된 객체보다 뒤에 오는 경우 양수
