주어진 패턴이 이스케이프된 16진수 형식인지 확인합니다.

```cpp
static bool System::UriShim::IsHexEncoding(const String &pattern, int32_t index)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| pattern | const [String](../../string/)\& | [String](../../string/)에서 이스케이프된 16진수 형식을 읽기 위해. |
| index | **int32_t** | 주어진 문자열의 오프셋. |

### 반환 값
