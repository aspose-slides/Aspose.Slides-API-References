## IConvertible::ToBoolean(System::SharedPtr\<System::IFormatProvider\>) 메서드

이 인스턴스의 값을 지정된 문화별 형식 정보를 사용하여 동등한 [Boolean](../../boolean/) 값으로 변환합니다.

```cpp
virtual bool System::IConvertible::ToBoolean(System::SharedPtr<System::IFormatProvider> provider)=0
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| provider | [System::SharedPtr](../../sharedptr/)\<[System::IFormatProvider](../../iformatprovider/)\> | [System::IFormatProvider](../../iformatprovider/) 인터페이스 구현은 문화별 형식 정보를 제공합니다. |

### 반환값

이 인스턴스의 값과 동등한 [Boolean](../../boolean/) 값입니다.
