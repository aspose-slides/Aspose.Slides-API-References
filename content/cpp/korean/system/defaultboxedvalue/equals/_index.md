## DefaultBoxedValue::Equals(ptr) 메서드


현재 객체와 지정된 객체가 나타내는 박스된 값들의 동등성을 결정합니다.

```cpp
bool System::DefaultBoxedValue<T>::Equals(ptr obj) override
```


### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| obj | [ptr](../../object/ptr/) | 현재 객체가 나타내는 박스된 값과 비교할 박스된 값을 나타내는 객체 |

### 반환값

현재 객체가 나타내는 박스된 값과 **obj**가 동일하면 true, 그렇지 않으면 false
