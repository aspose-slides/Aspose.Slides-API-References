## System::LEqual(const ExpressionT&, const ConstantT&) 함수

‘<=’ 상대 패턴 변환을 구현합니다.

```cpp
template<class ExpressionT,class ConstantT> bool System::LEqual(const ExpressionT &left, const ConstantT &constant)
```

### 템플릿 매개변수

| 매개변수 | 설명 |
| --- | --- |
| ExpressionT | 좌측 식 유형. |
| ConstantT | 상수 식의 타입. |

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| left | const ExpressionT& | 검사될 식. |
| constant | const ConstantT& | 좌측과 비교될 식. |

### 반환 값

형식 검사가 성공하면 true, 그렇지 않으면 false.
