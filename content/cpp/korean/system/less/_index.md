## System::Less(const ExpressionT\&, const ConstantT\&) 함수

‘<’ 연산자에 대한 상대 패턴 변환을 구현합니다.

```cpp
template<class ExpressionT,class ConstantT> bool System::Less(const ExpressionT &left, const ConstantT &constant)
```

### 템플릿 매개변수

| 매개변수 | 설명 |
| --- | --- |
| ExpressionT | 왼쪽 식 유형. |
| ConstantT | 상수 식의 유형. |

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| left | const ExpressionT\& | 검사될 식. |
| constant | const ConstantT\& | 좌측 식과 비교될 식. |

### 반환값

형식 검사가 성공하면 true, 그렇지 않으면 false.
