## Decimal::CompareTo(const Decimal\&) const method


현재 객체가 나타내는 값이 지정된 객체가 나타내는 값보다 작거나, 같은지, 큰지를 결정합니다.

```cpp
int System::Decimal::CompareTo(const Decimal &d) const
```


### 인수

| 매개변수 | 유형 | 설명 |
| --- | --- | --- |
| d | const [Decimal](../)\& | 비교 대상 |

### 반환값

- 1: 현재 객체가 나타내는 값이 **d**가 나타내는 값보다 작을 경우; 0: 값이 동일할 경우; 1: 현재 객체가 나타내는 값이 **d**가 나타내는 값보다 클 경우
