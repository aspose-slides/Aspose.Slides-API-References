## Decimal::operator>=(const Decimal\&) const 메서드

현재 객체가 나타내는 값이 지정된 객체가 나타내는 값보다 크거나 같은지 확인합니다.

```cpp
bool System::Decimal::operator>=(const Decimal &d) const
```

### 인수

| Parameter | Type | Description |
| --- | --- | --- |
| d | const [Decimal](../)\& | 현재 객체와 비교할 [Decimal](../) 객체 |

### 반환 값

현재 객체가 나타내는 값이 **d**가 나타내는 값보다 크거나 같으면 true, 그렇지 않으면 false
