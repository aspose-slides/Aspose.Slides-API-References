## Decimal::operator>(const Decimal\&) const 메서드

```cpp
bool System::Decimal::operator>(const Decimal &d) const
```

### 인수

| 매개변수 | 유형 | 설명 |
| --- | --- | --- |
| d | const [Decimal](../)\& | [Decimal](../) 객체, 현재 객체와 비교하는 대상 |

### 반환값

현재 객체가 나타내는 값이 **d**가 나타내는 값보다 크면 **true**, 그렇지 않으면 **false**
