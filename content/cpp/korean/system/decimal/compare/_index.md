## Decimal::Compare(const Decimal\&, const Decimal\&) 메서드

첫 번째 [Decimal](../) 객체가 나타내는 값이 두 번째 [Decimal](../) 객체가 나타내는 값보다 작거나, 같은지, 혹은 큰지를 결정합니다.

```cpp
static int System::Decimal::Compare(const Decimal &d1, const Decimal &d2)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| d1 | const [Decimal](../)\& | 첫 번째 비교 대상 |
| d2 | const [Decimal](../)\& | 두 번째 비교 대상 |

### 반환값

- 1 은 **d1** 로 표시된 값이 **d2** 로 표시된 값보다 작을 때; 0 은 값이 동일할 때; 1 은 **d1** 로 표시된 값이 **d2** 로 표시된 값보다 클 때
