## Decimal::operator<=(const Decimal\&) const 메서드


현재 객체가 나타내는 값이 지정된 객체가 나타내는 값보다 작거나 같은지 확인합니다.

```cpp
bool System::Decimal::operator<=(const Decimal &d) const
```


### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| d | const [Decimal](../)\& | 현재 객체와 비교하기 위한 [Decimal](../) 객체 |

### 반환값

현재 객체가 나타내는 값이 **d**가 나타내는 값보다 작거나 같으면 true, 그렇지 않으면 false
