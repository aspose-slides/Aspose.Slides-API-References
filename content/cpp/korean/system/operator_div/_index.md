## System::operator/(const T\&, const Decimal\&) 함수


[Decimal](../decimal/) 클래스의 새 인스턴스로, 지정된 값과 지정된 [Decimal](../decimal/) 객체가 나타내는 값을 나눈 결과 값을 나타냅니다.

```cpp
template<typename T,typename _> Decimal System::operator/(const T &x, const Decimal &d)
```


### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| x | const T\& | 나눌 값 |
| d | const [Decimal](../decimal/)\& | 피제수를 나타내는 [Decimal](../decimal/) 객체 |

### 반환 값

[Decimal](../decimal/) 클래스의 새 인스턴스로, **x**를 **d**가 나타내는 값으로 나눈 결과 값을 나타냅니다.
