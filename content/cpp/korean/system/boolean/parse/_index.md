## Boolean::Parse(const String\&) 메서드

지정된 문자열을 bool 형식의 값으로 변환합니다.

```cpp
static bool System::Boolean::Parse(const String &value)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| value | const [String](../../string/)\& | 변환할 문자열입니다. |

### 반환값

변환 결과가 저장되는 bool 변수이며, 지정된 문자열이 "True"와 같으면 결과는 true이고, 지정된 문자열이 "False"와 같으면 결과는 false입니다.
