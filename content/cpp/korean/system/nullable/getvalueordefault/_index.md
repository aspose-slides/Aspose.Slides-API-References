## Nullable::GetValueOrDefault(T) 메서드

현재 객체가 나타내는 값을 반환하거나, 현재 객체가 null인 경우 지정된 값을 반환합니다.

```cpp
T System::Nullable<T>::GetValueOrDefault(T default_value)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| default_value | T | 현재 객체가 null일 경우 메서드가 반환하는 값 |

### 반환값

현재 객체가 null이 아니면 현재 객체가 나타내는 값의 복사본이 반환되고, 그렇지 않으면 지정된 값이 반환됩니다.

## Nullable::GetValueOrDefault() 메서드

```cpp
T System::Nullable<T>::GetValueOrDefault()
```
