## SmartPtr::RemoveAliasing() const 메서드


포인터에서 별칭( aliasing constructor에 의해 생성된)을 제거하고, 포인터가 가리키는 동일한 객체를 (shared인 경우 관리하고) (weak인 경우 추적하도록 보장합니다.

```cpp
SmartPtr_ System::SmartPtr<T>::RemoveAliasing() const
```


### 반환값

이 포인터가 가리키는 동일한 객체에 대한 포인터이며 해당 객체의 수명을 관리합니다.
