## SmartPtr::IsAliasingPtr() const 메서드

포인터가 소유된 객체가 아닌 다른 객체를 가리키는지(별칭 생성자를 통해 생성된 경우) 확인합니다.

```cpp
bool System::SmartPtr<T>::IsAliasingPtr() const
```

### 반환값

포인터가 가리키는 객체와 소유된 객체가 다르면 true, 그렇지 않으면 false를 반환합니다.
