## SmartPtr::get_shared_count() const 메서드

참조된 객체에 존재하는 공유 포인터의 수를 가져옵니다(현재 포인터 포함). 현재 포인터가 공유 모드에 있음을 보증합니다.

```cpp
int System::SmartPtr<T>::get_shared_count() const
```

### 반환값

참조된 객체에 존재하는 공유 포인터의 수(있는 경우). 포인터가 null이면 0을 반환합니다.
