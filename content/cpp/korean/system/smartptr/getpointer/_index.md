## SmartPtr::GetPointer() const 메서드


포인터가 가리키는 객체(있는 경우)를 반환하거나 nullptr를 반환합니다. [get()](../get/)와 동일합니다.

```cpp
Pointee_ * System::SmartPtr<T>::GetPointer() const
```


### 반환 값

참조된 객체(있는 경우)의 원시 포인터 또는 nullptr.
