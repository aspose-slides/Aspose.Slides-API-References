## StringComparison 열거형

문자열 비교 스타일을 정의합니다.

```cpp
enum class StringComparison
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| CurrentCulture | 0 | 현재 문화권을 사용합니다. |
| CurrentCultureIgnoreCase | 1 | 현재 문화권을 사용하지만 대소문자를 무시합니다. |
| InvariantCulture | 2 | 불변 문화권을 사용합니다. |
| InvariantCultureIgnoreCase | 3 | 불변 문화권을 사용하지만 대소문자를 무시합니다. |
| Ordinal | 4 | 순서 정렬 규칙을 사용합니다. |
| OrdinalIgnoreCase | 5 | 순서 정렬 규칙을 사용하지만 대소문자를 무시합니다. |
