## BoxedValueBase 클래스

이 기본 클래스는 인터페이스를 정의하고 박스된 값을 나타내는 파생 클래스의 몇몇 기본 메서드를 구현합니다. 이 클래스의 객체는 [System::MakeObject()](../makeobject/) 함수를 사용하여 할당해야 합니다. 스택에 직접 생성하거나 operator new를 사용하여 인스턴스를 만들지 마세요. 이렇게 하면 런타임 오류 및/또는 어설션 오류가 발생합니다. 항상 이 클래스를 [System::SmartPtr](../smartptr/) 포인터로 감싸고, 해당 포인터를 함수 인자로 전달하십시오.

```cpp
class BoxedValueBase : public virtual System::Object
```
