## String::end() const 메서드

실제 문자열 버퍼의 끝을 가리키는 포인터를 반환합니다. 아무 것도 재할당하지 않습니다. 버퍼가 널 종료된다고 보장하지 않습니다.

```cpp
const UChar * System::String::end() const
```

### 반환값

실제 문자열 버퍼 이후 첫 번째 요소를 가리키는 포인터이며, 널 종료 여부와 관계 없습니다.
