## String::IsNormalized(System::Text::NormalizationForm) const 메서드

Unicode 문자열이 지정된 정규화 형식을 사용하여 정규화되었는지 확인합니다.

```cpp
bool System::String::IsNormalized(System::Text::NormalizationForm form) const
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| form | [System::Text::NormalizationForm](../../../system.text/normalizationform/) | 정규화 형식, 자세한 내용은 [System::Text::NormalizationForm](../../../system.text/normalizationform/)를 참조하십시오. |

### 반환값

문자열이 이미 정규화된 경우 true, 그렇지 않으면 false.
