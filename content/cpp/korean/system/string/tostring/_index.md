## String::ToString() const 메서드


[String](../) 클래스를 처리하기 위한 래퍼이며, 값 유형 객체에서 [ToString()](./)가 호출되는 상황에서 사용됩니다.

```cpp
String System::String::ToString() const
```


### 반환값

현재 문자열의 복사본입니다. 현재 문자열이 null 문자열인 경우 null 문자열로 간주됩니다.
