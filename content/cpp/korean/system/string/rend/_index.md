## String::rend() const 메서드

실제 문자열 버퍼의 첫 번째 문자 앞(있는 경우)으로 가리키는 역방향 반복자를 반환합니다.

```cpp
reverse_iterator System::String::rend() const
```

### 반환 값

실제 문자열 버퍼의 첫 번째 문자 앞에 있는 요소(있는 경우) 또는 할당된 버퍼 바로 앞의 요소를 가리키는 역방향 반복자입니다.
