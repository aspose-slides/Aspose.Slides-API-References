## String::begin() const 메서드


실제 문자열 버퍼의 시작을 가리키는 포인터를 반환합니다. 절대 재할당하지 않습니다. 버퍼가 null-terminated인지 여부는 보장하지 않습니다.

```cpp
const UChar * System::String::begin() const
```


### 반환 값

실제 문자열 버퍼를 가리키는 포인터이며, null-terminated 여부는 상관없습니다.
