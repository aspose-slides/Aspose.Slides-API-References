```cpp
bool System::BoxedValue<ValueTuple<Args...>>::Equals(ptr obj) override
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| obj | [ptr](../../object/ptr/) | 현재 객체가 나타내는 박싱된 값과 비교할 박싱된 값을 나타내는 객체 |
