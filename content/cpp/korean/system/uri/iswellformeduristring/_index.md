## Uri::IsWellFormedUriString(const String\&, UriKind) 메서드

```cpp
static bool System::Uri::IsWellFormedUriString(const String &uriString, UriKind uriKind)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| uriString | const [String](../../string/)\& | 테스트할 URI |
| uriKind | [UriKind](../../urikind/) | 지정된 URI의 유형 |

### 반환값

지정된 URI가 올바른 형식이면 true, 그렇지 않으면 - false
