## Uri::IsHexEncoding(const String\&, int32_t) 메서드

지정된 위치의 지정된 문자열에 있는 문자가 16진수 인코딩인지 확인합니다.

```cpp
static bool System::Uri::IsHexEncoding(const String &pattern, int32_t index)
```

### 인수

| 매개변수 | 유형 | 설명 |
| --- | --- | --- |
| pattern | const [String](../../string/)\& | 확인할 문자열 |
| index | **int32_t** | 테스트할 문자의 0 기반 위치 |

### 반환 값

지정된 문자가 16진수 인코딩이면 True, 그렇지 않으면 false
