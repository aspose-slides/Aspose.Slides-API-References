## Char::Parse(const String\&) 메서드

```cpp
static char_t System::Char::Parse(const String &value)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| value | const [String](../../string/)\& | 변환할 문자열. |

## 반환 값

지정된 문자열이 정확히 1자일 경우, 첫 번째이자 유일한 문자를 반환합니다.
