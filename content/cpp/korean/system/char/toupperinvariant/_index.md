## Char::ToUpperInvariant(char_t) 메서드

지정된 문자를 대문자로 변환합니다.

```cpp
static char_t System::Char::ToUpperInvariant(char_t c)
```

### 인수

| 매개변수 | 유형 | 설명 |
| --- | --- | --- |
| c | char_t | 변환할 문자 |

### 반환값

지정된 문자가 소문자이면 대문자로 변환한 문자이고, 그렇지 않으면 지정된 문자 그대로입니다.
