## Char::IsNumber(const char_t *, int) 메서드

지정된 문자 버퍼의 지정된 인덱스에 있는 문자가 숫자로 분류되는지 여부를 확인합니다.

```cpp
static bool System::Char::IsNumber(const char_t *str, int idx)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| str | const char_t * | 문자 버퍼의 시작을 가리키는 포인터 |
| idx | int | 테스트할 문자의 버퍼 내 0 기반 인덱스 |

### 반환값

지정된 인덱스에 있는 문자가 숫자인 경우 true, 그렇지 않으면 false
