## Char::IsSymbol(const char_t *, int) 메서드

지정된 문자 버퍼에서 지정된 인덱스에 있는 문자가 기호 문자로 분류되는지 여부를 결정합니다.

```cpp
static bool System::Char::IsSymbol(const char_t *str, int idx)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| str | const char_t * | 문자 버퍼의 시작을 가리키는 포인터 |
| idx | int | 테스트할 문자에 대한 지정된 버퍼 내의 0 기반 인덱스 |

### 반환 값

지정된 인덱스에 있는 문자가 기호 문자이면 True, 그렇지 않으면 false

static bool System::Char::IsSymbol(char_t c)
