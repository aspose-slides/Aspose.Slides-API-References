## Char::ToLowerInvariant(char_t) 메서드


지정된 문자를 소문자로 변환합니다.

```cpp
static char_t System::Char::ToLowerInvariant(char_t c)
```


### 매개변수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| c | char_t | 변환할 문자 |

### 반환값

지정된 문자가 대문자이면 소문자로 변환된 문자이며, 그렇지 않으면 지정된 문자 그대로입니다.
