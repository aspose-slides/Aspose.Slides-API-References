## Char::TryParse(const System::String\&, char_t\&) 메서드


문자 하나로 구성된 문자열을 UTF-16 문자로 변환하려고 시도합니다. 입력 문자열이 null이 아니고 정확히 한 문자 길이일 때만 함수가 성공합니다.

```cpp
static bool System::Char::TryParse(const System::String &s, char_t &result)
```


### 인수

| Parameter | Type | Description |
| --- | --- | --- |
| s | const [System::String](../../string/)\& | [String](../../string/) 변환할 |
| result | char_t\& | 변환이 성공하면 결과를 포함하게 될 출력 변수 |

### 반환값

True if conversion succeeded, otherwise - false
