## Char::GetUnicodeCategory(char_t) 메서드

지정된 문자에 대한 Unicode 카테고리를 나타내는 값을 반환합니다.

```cpp
static Globalization::UnicodeCategory System::Char::GetUnicodeCategory(char_t ch)
```

### 인수

| 매개변수 | 유형 | 설명 |
| --- | --- | --- |
| ch | char_t | 분류할 문자 |

### 반환 값

UnicodeCategory 열거형의 값 중 하나로, 지정된 문자가 속한 Unicode 카테고리를 나타냅니다.
