## System::Equals(const TA\&, const TB\&) 함수

두 값에 [operator==()](../operator_equal_equal/)을 적용하여 동등성을 결정합니다.

```cpp
template<typename TA,typename TB> bool System::Equals(const TA &a, const TB &b)
```

### 템플릿 매개변수

| 매개변수 | 설명 |
| --- | --- |
| TA | 첫 번째 비교 대상의 형식 |
| TB | 두 번째 비교 대상의 형식 |

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| a | const TA\& | 첫 번째 비교 대상 |
| b | const TB\& | 두 번째 비교 대상 |

### 반환값

[operator==()](../operator_equal_equal/)가 **a**와 **b**에 적용되어 반환되는 부울 값
