## Array::rend() 메서드

역방향 컨테이너의 마지막 요소 다음에 위치하는 요소에 대한 역방향 반복자를 반환합니다. 이는 비역방향 컨테이너의 첫 번째 요소 앞에 있는 요소에 해당합니다. 이 요소는 자리 표시자 역할을 하며, 접근을 시도하면 정의되지 않은 동작이 발생합니다.

```cpp
reverse_iterator System::Array<T>::rend() noexcept
```

### 반환값

컨테이너의 첫 번째 요소 앞에 있는 이론적인 요소를 가리키는 반복자입니다.

역방향 컨테이너의 마지막 요소 다음에 위치하는 요소에 대한 역방향 반복자를 반환합니다. 이는 비역방향 컨테이너의 첫 번째 요소 앞에 있는 요소에 해당합니다. 이 요소는 자리 표시자 역할을 하며, 접근을 시도하면 정의되지 않은 동작이 발생합니다.

```cpp
const_reverse_iterator System::Array<T>::rend() const noexcept
```

### 반환값

const 한정 컨테이너의 첫 번째 요소 앞에 있는 이론적인 요소를 가리키는 반복자입니다.
