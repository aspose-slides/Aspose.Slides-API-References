## Array::begin() 메서드


컨테이너의 첫 번째 요소에 대한 이터레이터를 반환합니다. 컨테이너가 비어 있는 경우, 반환된 이터레이터는 [end()](../end/)와 같습니다.

```cpp
iterator System::Array<T>::begin() noexcept
```


### 반환값

컨테이너의 첫 번째 요소를 가리키는 이터레이터.

## Array::begin() const 메서드


const 한정자를 가진 컨테이너의 첫 번째 요소에 대한 이터레이터를 반환합니다. 컨테이너가 비어 있는 경우, 반환된 이터레이터는 [end()](../end/)와 같습니다.

```cpp
const_iterator System::Array<T>::begin() const noexcept
```


### 반환값

const 한정자를 가진 컨테이너의 첫 번째 요소를 가리키는 이터레이터.
