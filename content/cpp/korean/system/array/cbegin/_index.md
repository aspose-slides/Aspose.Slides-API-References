## Array::cbegin() const 메서드

컨테이너의 첫 번째 const 한정 요소에 대한 반복자를 반환합니다. 컨테이너가 비어 있는 경우 반환된 반복자는 [cend()](../cend/)와 같습니다.

```cpp
const_iterator System::Array<T>::cbegin() const noexcept
```

### 반환값

컨테이너의 첫 번째 const 한정 요소를 가리키는 반복자.
