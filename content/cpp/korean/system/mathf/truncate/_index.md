## MathF::Truncate(float) 메서드

지정된 값과 동일한 정수 부분을 가지고, 모든 소수 부분을 버린 부동 소수점(float) 값을 반환합니다.

```cpp
static float System::MathF::Truncate(float x)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| x | **float** | 10진수 |

### 반환값

지정된 값과 동일한 정수 부분을 가지고, 소수 부분이 모두 0인 부동 소수점(float) 값을 반환합니다.
