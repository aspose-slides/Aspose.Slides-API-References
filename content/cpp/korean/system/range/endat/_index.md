```cpp

```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| end | const [Index](../../index/)\& | 범위의 종료 인덱스. |

### 반환값

[Range](../) 객체는 컬렉션의 시작에서 시작하여 **end**에서 끝납니다.
