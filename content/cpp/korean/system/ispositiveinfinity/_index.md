## System::IsPositiveInfinity(const T\&) 함수

지정된 값이 양의 무한대를 나타내는지 확인합니다.

```cpp
template<typename T> bool System::IsPositiveInfinity(const T &value)
```

### 템플릿 매개변수

| 매개변수 | 설명 |
| --- | --- |
| T | 함수가 검사하는 값의 유형 |

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| value | const T\& | 확인할 값 |

### 반환값

값이 양의 무한대를 나타내면 **value**가 true, 그렇지 않으면 false
