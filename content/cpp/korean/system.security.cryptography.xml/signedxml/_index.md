## SignedXml 클래스

XML 서명 및 검증에 사용됩니다. 이 클래스의 객체는 [System::MakeObject()](../../system/makeobject/) 함수를 사용해서만 할당되어야 합니다. 스택에 직접 인스턴스를 생성하거나 operator new를 사용하면 런타임 오류 및/또는 단언 오류가 발생합니다. 항상 이 클래스를 [System::SmartPtr](../../system/smartptr/) 포인터에 감싸고, 해당 포인터를 인수로 함수에 전달하세요.

```cpp
class SignedXml : public System::Object
```
