## IEnumeratorImplRefType::MoveNext() 메서드

열거자를 다음 요소로 이동합니다. 이전에 요소가 참조되지 않은 경우, 사용 가능한 첫 번째 요소에 대한 참조를 설정합니다. 컨테이너의 끝에 도달하면 아무 작업도 수행하지 않습니다.

```cpp
virtual bool System::Collections::IEnumeratorImplRefType<T>::MoveNext() override
```

### 반환 값

호출 후 사용 가능한 요소가 있으면 true, 그렇지 않으면 false.
