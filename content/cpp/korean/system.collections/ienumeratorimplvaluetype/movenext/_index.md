## IEnumeratorImplValueType::MoveNext() 메서드

enumerator를 다음 요소로 이동합니다. 이전에 요소가 참조되지 않았다면, 사용 가능한 첫 번째 요소를 참조하도록 설정합니다. 컨테이너 끝에 도달하면 아무 것도 하지 않습니다.

```cpp
virtual bool System::Collections::IEnumeratorImplValueType<T>::MoveNext() override
```

### 반환 값

호출 후 사용할 수 있는 요소가 있으면 true, 그렇지 않으면 false.
