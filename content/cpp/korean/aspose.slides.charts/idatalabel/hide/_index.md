## IDataLabel::Hide() 메서드


ShowValue 등 모든 Show*-플래그를 false 상태로 설정하여 데이터 레이블을 숨깁니다. IsVisible는 이 후 false가 됩니다.

```cpp
virtual void Aspose::Slides::Charts::IDataLabel::Hide()=0
```

## 비고


데이터 레이블이 표시되지 않는 경우(IsVisible가 false) ShowValue 등 Show*-플래그를 true 상태로 설정하여 데이터 레이블을 표시할 수 있습니다.
