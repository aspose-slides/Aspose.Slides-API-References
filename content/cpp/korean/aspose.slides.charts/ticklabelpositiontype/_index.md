## TickLabelPositionType 열거형

지정된 축에 대한 눈금 레이블의 위치 유형을 나타냅니다.

```cpp
enum class TickLabelPositionType
```

### 값

| Name | Value | Description |
| --- | --- | --- |
| High | 0 | 축 레이블이 수직 축의 높은 쪽 끝에 배치되어야 함을 지정합니다. |
| Low | 1 | 축 레이블이 수직 축의 낮은 쪽 끝에 배치되어야 함을 지정합니다. |
| NextTo | 2 | 축 레이블이 축 옆에 배치되어야 함을 지정합니다. |
| None | 3 | 축 레이블이 그려지지 않음을 지정합니다. |
