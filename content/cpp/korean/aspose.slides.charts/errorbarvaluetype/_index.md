## ErrorBarValueType 열거형

오류 막대값의 유형을 나타냅니다

```cpp
enum class ErrorBarValueType
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Custom | 0 | 오류 막대의 길이가 Plus와 Minus 요소에 의해 결정됨을 지정합니다. |
| Fixed | 1 | 오류 막대의 길이가 Error Bar Value에 의해 결정된 고정값임을 지정합니다. |
| Percentage | 2 | 오류 막대의 길이가 데이터의 Error Bar Value 퍼센트임을 지정합니다. |
| StandardDeviation | 3 | 오류 막대의 길이가 데이터의 Error Bar Value 표준 편차임을 지정합니다. |
| StandardError | 4 | 오류 막대의 길이가 데이터의 Error Bar Value 표준 오차임을 지정합니다. |
