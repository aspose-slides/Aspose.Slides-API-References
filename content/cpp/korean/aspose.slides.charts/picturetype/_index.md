## PictureType 열거형

바 차트 그림 채우기 모드를 결정합니다.

```cpp
enum class PictureType
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| NotDefined | -1 | 정의되지 않음. |
| Stack | 0 | 그림이 가장 긴 누적 막대에서 최대 15번 반복하도록 크기가 조정됩니다. |
| StackScale | 1 | 그림이 지정된 단위 수로 크기가 조정되고 막대 길이만큼 반복됩니다. |
| Stretch | 2 | 그림이 누적 막대 전체 길이까지 늘려집니다. |
