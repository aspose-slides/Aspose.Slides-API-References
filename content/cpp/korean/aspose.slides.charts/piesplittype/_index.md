## PieSplitType 열거형

두 번째 파이 또는 바에 해당하는 파이-오브-파이 혹은 바-오브-파이 차트에서 분할 포인트의 유형을 나타냅니다.

```cpp
enum class PieSplitType
```

### Values

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Default | 0 | 데이터 포인트가 이 차트 유형에 대한 기본 메커니즘을 사용하여 분할됨을 지정합니다. |
| Custom | 1 | 데이터 포인트가 파이와 두 번째 차트 사이를 Custom Split 값에 따라 분할함을 지정합니다. |
| ByPercentage | 2 | 데이터 포인트가 파이와 두 번째 차트 사이를 Split Position 퍼센트보다 낮은 백분율을 가진 포인트를 두 번째 차트에 배치함으로써 분할함을 지정합니다. |
| ByPos | 3 | 데이터 포인트가 파이와 두 번째 차트 사이를 데이터 포인트의 마지막 Split Position을 두 번째 차트에 배치함으로써 분할함을 지정합니다. |
| ByValue | 4 | 데이터 포인트가 파이와 두 번째 차트 사이를 Split Position보다 작은 값을 가진 데이터 포인트를 두 번째 차트에 배치함으로써 분할함을 지정합니다. |
