## ErrorBarsFormat::set_ValueType(ErrorBarValueType) 메서드

오류 막대의 길이를 결정하는 가능한 방법을 나타냅니다. 사용자 정의 값 유형의 경우 값 지정에 시리즈의 DataPoints 컬렉션에 있는 특정 데이터 포인트의 [IChartDataPoint::get_ErrorBarsCustomValues()](../../ichartdatapoint/get_errorbarscustomvalues/) 속성을 사용합니다. Fixed, Percentage 또는 StandardDeviation 값 유형의 경우 값을 지정하기 위해 Value 속성을 사용합니다.
