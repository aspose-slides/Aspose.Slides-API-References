## ChartSeries::get_GapDepth() 메서드

3D 차트에서 데이터 계열 간의 거리를 마커 너비의 백분율로 반환합니다. 이 속성은 이 계열에만 해당되는 것이 아니라 상위 시리즈 그룹의 모든 계열에 적용되는 속성의 투영입니다. 따라서 이 속성은 읽기 전용입니다. 상위 시리즈 그룹에 접근하려면 ParentSeriesGroup 속성을 사용하십시오. 값을 변경하려면 [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_GapDepth() 읽기/쓰기 속성을 사용하십시오. 읽기 전용 **int32_t**.

```cpp
int32_t Aspose::Slides::Charts::ChartSeries::get_GapDepth() override
```

## 비고
