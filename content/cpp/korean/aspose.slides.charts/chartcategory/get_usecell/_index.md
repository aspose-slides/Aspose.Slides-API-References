## ChartCategory::get_UseCell() 메서드


true이면 AsCell 속성이 실제값입니다. 즉, worksheet가 카테고리를 저장하는 데 사용됩니다(이 경우 다계층 카테고리를 지원합니다). false이면 AsLiteral 속성이 실제값입니다. 즉, worksheet가 카테고리를 저장하는 데 사용되지 않으며(이 경우 다계층 카테고리를 지원하지 않습니다). 읽기 전용 **bool**.

```cpp
bool Aspose::Slides::Charts::ChartCategory::get_UseCell() override
```

## 비고


이 속성의 값을 변경하려면(컬렉션에 있는 모든 카테고리에 대해) ChartCategoryCollection::get(set)_UseCells 속성에 새 값을 설정하십시오.
