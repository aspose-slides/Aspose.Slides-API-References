## AxisAggregationType 열거형

카테고리 축의 집계 유형을 나타냅니다. Histogram 또는 HistogramPareto 시리즈와 함께 사용됩니다.

```cpp
enum class AxisAggregationType
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| ByCategory | 0 | 카테고리별로 집계 |
| Automatic | 1 | 카테고리를 자동으로 집계합니다. |
| ByBinWidth | 2 | 빈 너비별로 카테고리를 집계합니다. 속성 IAxis::get(set)_BinWidth가 설정되어야 합니다. |
| ByNumberOfBins | 3 | 빈 수에 따라 카테고리를 집계합니다. 속성 IAxis::get(set)_NumberOfBins가 설정되어야 합니다. |
