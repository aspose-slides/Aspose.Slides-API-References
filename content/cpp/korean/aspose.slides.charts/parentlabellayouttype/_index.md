## ParentLabelLayoutType enum

카테고리 데이터 레이블의 레이아웃을 나타냅니다. Treemap 시리즈와 함께 사용할 때만 적용됩니다.

```cpp
enum class ParentLabelLayoutType
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Banner | 0 | 부모 카테고리 레이블이 배너 형태로 표시됨을 지정합니다 |
| None | 1 | 부모 카테고리 레이블이 그려지지 않음을 지정합니다 |
| Overlapping | 2 | 부모 카테고리 레이블이 겹쳐서 표시됨을 지정합니다 |
