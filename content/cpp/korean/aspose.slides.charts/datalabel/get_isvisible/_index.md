## DataLabel::get_IsVisible() 메서드

False는 데이터 레이블이 표시되지 않음을 의미합니다(따라서 모든 Show*-flags(ShowValue, ...)가 false입니다). 읽기 전용 **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabel::get_IsVisible() override
```

## 비고

데이터 레이블이 표시되는 경우 [Hide()](../hide/) 메서드를 사용하여 숨길 수 있습니다. 하지만 데이터 레이블이 표시되지 않는 경우(IsVisible가 false) Show*-flags(ShowValue, ...)를 true 상태로 설정하여 데이터 레이블을 표시할 수 있습니다.
