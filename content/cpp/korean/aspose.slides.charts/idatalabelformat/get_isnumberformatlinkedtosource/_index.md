## IDataLabelFormat::get_IsNumberFormatLinkedToSource() 메서드

Read **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_IsNumberFormatLinkedToSource()=0
```

## 비고

만약 이 [DataLabelFormat](../../datalabelformat/) 객체의 부모가 [DataLabelCollection](../../datalabelcollection/) 데이터 레이블 컬렉션이라면, 이 속성은 [DataLabelCollection](../../datalabelcollection/) 컬렉션의 새 데이터 레이블에 대한 IsNumberFormatLinkedToSource 속성의 기본 값을 가져오거나 설정합니다. 이 속성을 값과 함께 설정하면 [DataLabelCollection](../../datalabelcollection/) 컬렉션의 모든 데이터 레이블에 대한 IsNumberFormatLinkedToSource 속성에도 해당 값이 설정됩니다 (예: \"DataLabels.DefaultDataLabelFormat.IsNumberFormatLinkedToSource = val;\" 은 모든 DataLabels[i].IsNumberFormatLinkedToSource가 val과 같아지게 합니다).
