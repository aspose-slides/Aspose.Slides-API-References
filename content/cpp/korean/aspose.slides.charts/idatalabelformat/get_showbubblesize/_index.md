## IDataLabelFormat::get_ShowBubbleSize() 메서드


지정된 차트의 데이터 레이블 버블 크기 값 표시 동작을 나타냅니다. True는 버블 크기 값을 표시하고, False는 숨깁니다. 읽기 전용 **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowBubbleSize()=0
```

## 비고


만약 이 [DataLabelFormat](../../datalabelformat/) 객체의 부모가 [DataLabelCollection](../../datalabelcollection/) 데이터 레이블 컬렉션이라면, 이 속성은 [DataLabelCollection](../../datalabelcollection/) 컬렉션의 새 데이터 레이블에 대한 ShowBubbleSize 속성의 기본 값을 가져오거나 설정합니다. 값을 지정하여 이 속성을 설정하면 [DataLabelCollection](../../datalabelcollection/) 컬렉션의 모든 데이터 레이블에 대한 ShowBubbleSize 속성에도 동일한 값이 설정됩니다(예: "DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;" 로 모든 DataLabels[i].ShowBubbleSize가 val과 동일해짐).
