## IDataLabelFormat::set_ShowBubbleSize(bool) 메서드

지정된 차트의 데이터 레이블 버블 크기 값 표시 동작을 나타냅니다. True는 버블 크기 값을 표시합니다. False는 숨깁니다. 작성 **bool**.

```cpp
virtual void Aspose::Slides::Charts::IDataLabelFormat::set_ShowBubbleSize(bool value)=0
```

## 비고

만약 이 [DataLabelFormat](../../datalabelformat/) 객체의 부모가 [DataLabelCollection](../../datalabelcollection/) 데이터 레이블 컬렉션이면, 이 속성은 [DataLabelCollection](../../datalabelcollection/) 컬렉션의 새 데이터 레이블에 대한 ShowBubbleSize 속성의 기본값을 가져오거나 설정합니다. 이 속성을 값으로 설정하면 [DataLabelCollection](../../datalabelcollection/) 컬렉션의 모든 데이터 레이블에 대한 ShowBubbleSize 속성에도 동일한 값이 설정됩니다 (i.e. \"DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;\" cause to all DataLabels[i].ShowBubbleSize is equal to val).
