## IDataLabelFormat::get_ShowLabelAsDataCallout() 메서드


지정된 차트의 데이터 레이블이 데이터 호출로 표시될지 데이터 레이블로 표시될지를 결정합니다.

```cpp
virtual bool Aspose::Slides::Charts::IDataLabelFormat::get_ShowLabelAsDataCallout()=0
```

## 비고


이 [DataLabelFormat](../../datalabelformat/) 객체의 상위가 [DataLabelCollection](../../datalabelcollection/) 데이터 레이블 컬렉션인 경우, 이 속성은 [DataLabelCollection](../../datalabelcollection/) 컬렉션의 새 데이터 레이블에 대한 ShowLabelAsDataCallout 속성의 기본값을 가져오거나 설정합니다. 값을 사용하여 이 속성을 설정하면 [DataLabelCollection](../../datalabelcollection/) 컬렉션의 모든 데이터 레이블에 대한 ShowLabelAsDataCallout 속성에도 이 값이 설정됩니다(예: "DataLabels.DefaultDataLabelFormat.ShowLabelAsDataCallout = val;" 은 모든 DataLabels[i].ShowLabelAsDataCallout이 val과 같아지게 합니다).
