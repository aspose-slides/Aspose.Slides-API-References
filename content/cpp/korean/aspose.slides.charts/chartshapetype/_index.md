## ChartShapeType enum

차트 모양을 나타냅니다.

```cpp
enum class ChartShapeType
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| NotDefined | -1 | [Chart](../chart/) shape is not defined. |
| Box | 0 | 차트가 박스 형태로 그려지도록 지정합니다. |
| Cone | 1 | 차트가 원뿔 형태로 그려지도록 지정합니다. 원뿔의 바닥은 바닥에 놓이고 원뿔의 꼭대기는 데이터 마커의 상단에 위치합니다. |
| ConeToMax | 2 | 차트가 절단된 원뿔 형태로 그려지도록 지정합니다. 원뿔의 꼭대기가 최대 데이터 값이 되도록 합니다. |
| Cylinder | 3 | 차트가 원통 형태로 그려지도록 지정합니다. |
| Pyramid | 4 | 차트가 직사각형 피라미드 형태로 그려지도록 지정합니다. 피라미드의 바닥은 바닥에 놓이고 피라미드의 꼭대기는 데이터 마커의 상단에 위치합니다. |
| PyramidToMaximum | 5 | 차트가 절단된 피라미드 형태로 그려지도록 지정합니다. 피라미드의 꼭대기가 최대 데이터 값이 되도록 합니다. |
