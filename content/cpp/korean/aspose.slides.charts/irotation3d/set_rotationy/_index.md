## IRotation3D::set_RotationY(uint16_t) 메서드


Y축을 중심으로 회전 각도를 설정합니다, 즉 3D 차트의 X 방향에 해당합니다 (0도에서 360도 사이). 이 속성은 ECMA-376의 21.2.2.158 rotY (Y Rotation) 항목 및 PowerPoint 2007+의 "X Rotation" 옵션과 일치합니다. **uint16_t** 로 작성합니다.

virtual void Aspose::Slides::Charts::IRotation3D::set_RotationY(uint16_t value)=0
