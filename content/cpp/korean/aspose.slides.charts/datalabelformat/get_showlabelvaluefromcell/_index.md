## DataLabelFormat::get_ShowLabelValueFromCell() 메서드

지정된 차트의 데이터 레이블 셀 값 표시 동작을 나타냅니다. True는 셀 값을 표시합니다. False는 숨깁니다. 읽기 **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowLabelValueFromCell() override
```

## 비고

만약 이 [DataLabelFormat](../) 객체의 부모가 [DataLabelCollection](../../datalabelcollection/) 데이터 레이블 컬렉션이라면, 이 속성은 [DataLabelCollection](../../datalabelcollection/) 컬렉션의 새 데이터 레이블에 대한 ShowLabelValueFromCell 속성의 기본값을 가져오거나 설정합니다. 이 속성을 값으로 설정하면 [DataLabelCollection](../../datalabelcollection/) 컬렉션의 모든 데이터 레이블에 대한 ShowLabelValueFromCell 속성에도 해당 값이 설정됩니다 (예: "DataLabels.DefaultDataLabelFormat.ShowLabelValueFromCell = val;" 로 모든 DataLabels[i].ShowLabelValueFromCell가 val와 동일해집니다).
