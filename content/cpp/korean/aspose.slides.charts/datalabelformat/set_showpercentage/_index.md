## DataLabelFormat::set_ShowPercentage(bool) 메서드

지정된 차트의 데이터 레이블 백분율 값 표시 동작을 나타냅니다. True는 백분율 값을 표시합니다. False는 숨깁니다. **bool** 형식으로 기록합니다.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_ShowPercentage(bool value) override
```

## 비고

만약 이 [DataLabelFormat](../) 객체의 상위가 [DataLabelCollection](../../datalabelcollection/) 데이터 레이블 컬렉션이라면, 이 속성은 [DataLabelCollection](../../datalabelcollection/) 컬렉션에 있는 새로운 데이터 레이블에 대한 ShowPercentage 속성의 기본값을 가져오거나 설정합니다. 값을 지정하여 이 속성을 설정하면 [DataLabelCollection](../../datalabelcollection/) 컬렉션에 있는 모든 데이터 레이블의 ShowPercentage 속성에도 이 값이 설정됩니다 (예: \"DataLabels.DefaultDataLabelFormat.ShowPercentage = val;\" 로 인해 모든 DataLabels[i].ShowPercentage가 val와 동일해집니다).
