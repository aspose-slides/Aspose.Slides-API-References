## DataLabelFormat::get_ShowBubbleSize() 메서드

지정된 차트의 데이터 레이블 버블 크기 값 표시 동작을 나타냅니다. True는 버블 크기 값을 표시합니다. False는 숨깁니다. 읽기 **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelFormat::get_ShowBubbleSize() override
```

## 비고

이 [DataLabelFormat](../) 객체의 상위가 [DataLabelCollection](../../datalabelcollection/) 데이터 레이블 컬렉션인 경우, 이 속성은 [DataLabelCollection](../../datalabelcollection/) 컬렉션의 새 데이터 레이블에 대한 ShowBubbleSize 속성의 기본값을 가져오거나 설정합니다. 이 속성을 값으로 설정하면 [DataLabelCollection](../../datalabelcollection/) 컬렉션의 모든 데이터 레이블에 대해 ShowBubbleSize 속성에 해당 값이 설정됩니다(예: "DataLabels.DefaultDataLabelFormat.ShowBubbleSize = val;" 로 인해 모든 DataLabels[i].ShowBubbleSize가 val과 동일해집니다).
