## DataLabelFormat::set_IsNumberFormatLinkedToSource(bool) 메서드

Write **bool**.

```cpp
void Aspose::Slides::Charts::DataLabelFormat::set_IsNumberFormatLinkedToSource(bool value) override
```

## 비고

만약 이 [DataLabelFormat](../) 객체의 상위가 [DataLabelCollection](../../datalabelcollection/) 데이터 레이블 컬렉션이면, 이 속성은 [DataLabelCollection](../../datalabelcollection/) 컬렉션에 있는 새로운 데이터 레이블의 IsNumberFormatLinkedToSource 속성에 대한 기본값을 가져오거나 설정합니다. 이 속성을 값으로 설정하면 [DataLabelCollection](../../datalabelcollection/) 컬렉션의 모든 데이터 레이블에 대해 IsNumberFormatLinkedToSource 속성에 같은 값이 적용됩니다(예: \"DataLabels.DefaultDataLabelFormat.IsNumberFormatLinkedToSource = val;\" 때문에 모든 DataLabels[i].IsNumberFormatLinkedToSource가 val와 동일해집니다).
