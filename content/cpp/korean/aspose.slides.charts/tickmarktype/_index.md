## TickMarkType 열거형

지정된 축에 대한 눈금 표시 유형을 나타냅니다.

```cpp
enum class TickMarkType
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Cross | 0 | 눈금 표시가 축을 교차하도록 지정합니다. |
| Inside | 1 | 눈금 표시가 플롯 영역 안에 있도록 지정합니다. |
| None | 2 | 눈금 표시가 없도록 지정합니다. |
| Outside | 3 | 눈금 표시가 플롯 영역 밖에 있도록 지정합니다. |
