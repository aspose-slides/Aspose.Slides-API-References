## DataLabelCollection::get_IsVisible() 메서드

False는 데이터 레이블이 기본적으로 보이지 않음을 의미합니다(따라서 DefaultDataLabelFormat 속성의 모든 Show*-flags(ShowValue, ...)가 false입니다). 읽기 전용 **bool**.

```cpp
bool Aspose::Slides::Charts::DataLabelCollection::get_IsVisible() override
```

## 참고 사항

데이터 레이블이 기본적으로 보이는 경우 [Hide()](../hide/) 메서드를 사용하여 기본적으로 숨길 수 있습니다. 그러나 데이터 레이블이 기본적으로 보이지 않는 경우(IsVisible가 false) DefaultDataLabelFormat 속성의 Show*-flags(ShowValue, ...)를 true 상태로 설정하여 데이터 레이블을 "기본적으로 보이게" 할 수 있습니다.
