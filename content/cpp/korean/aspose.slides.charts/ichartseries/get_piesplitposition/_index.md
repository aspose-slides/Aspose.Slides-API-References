## IChartSeries::get_PieSplitPosition() 메서드

두 번째 파이 또는 바가 파이-오브-파이 또는 바-오브-파이 차트에서 어느 데이터 포인트에 해당하는지를 결정하는 데 사용되는 값을 지정합니다. PieSplitBy 속성과 함께 사용됩니다. 이 속성은 이 시리즈뿐만 아니라 상위 시리즈 그룹의 모든 시리즈에 적용되는 속성으로, 해당 그룹 속성의 투영입니다. 따라서 이 속성은 읽기 전용입니다. 상위 시리즈 그룹에 접근하려면 ParentSeriesGroup 속성을 사용하십시오. 값을 변경하려면 [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_PieSplitPosition() 읽기/쓰기 속성을 사용하십시오. 읽기 전용 **double**.

```cpp
virtual double Aspose::Slides::Charts::IChartSeries::get_PieSplitPosition()=0
```

## 비고

이는 속성 [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_PieSplitPosition()의 투영입니다.
