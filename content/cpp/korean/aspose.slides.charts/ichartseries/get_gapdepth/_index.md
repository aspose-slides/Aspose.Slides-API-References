## IChartSeries::get_GapDepth() 메서드


마커 너비의 백분율로 3D 차트의 데이터 계열 사이의 거리를 반환합니다. 이 속성은 이 계열뿐만 아니라 상위 계열 그룹의 모든 계열에 적용되는 속성의 투영입니다. 따라서 이 속성은 읽기 전용입니다. 상위 계열 그룹에 접근하려면 ParentSeriesGroup 속성을 사용하십시오. 값을 변경하려면 [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_GapDepth() 읽기/쓰기 속성을 사용하십시오. 읽기 전용 **int32_t**.

```cpp
virtual int32_t Aspose::Slides::Charts::IChartSeries::get_GapDepth()=0
```

## 비고


이것은 속성 [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get(set)_GapDepth()의 투영입니다.
