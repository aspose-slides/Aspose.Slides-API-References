## IChartSeries::get_HasUpDownBars() 메서드

라인 차트 또는 주식 차트에 상하 막대가 있는지 결정합니다. 이 속성은 이 시리즈뿐만 아니라 상위 시리즈 그룹의 모든 시리즈에 적용되며, 해당 그룹 속성의 투영입니다. 따라서 이 속성은 읽기 전용입니다. ParentSeriesGroup 속성을 사용하여 상위 시리즈 그룹에 접근하십시오. [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get_UpDownBars()->get(set)_HasUpDownBars() 읽기/쓰기 속성을 사용하여 값을 변경하십시오. [get_ParentSeriesGroup()](../get_parentseriesgroup/)->get_UpDownBars() 속성을 사용하여 상하 막대를 형식화하십시오. 읽기 전용 **bool**.

```cpp
virtual bool Aspose::Slides::Charts::IChartSeries::get_HasUpDownBars()=0
```
