## ServicePoint::SetTcpKeepAlive(bool, int32_t, int32_t) 메서드

‘Keep-Alive’ 옵션이 활성화되어 있는지를 나타내는 값을 설정합니다.

```cpp
void System::Net::ServicePoint::SetTcpKeepAlive(bool enabled, int32_t keepAliveTime, int32_t keepAliveInterval)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| enabled | **bool** | ‘Keep-Alive’ 옵션이 활성화되어 있는지를 나타내는 값. |
| keepAliveTime | **int32_t** | 첫 번째 ‘Keep-Alive’ 패킷이 전송되기까지의 시간(밀리초)입니다. |
| keepAliveInterval | **int32_t** | ‘Keep-Alive’ 패킷을 전송하는 사이의 시간(밀리초)입니다. |
