## CookieCollection::get_IsOtherVersionSeen() 메서드


컬렉션에 버전이 [Cookie::MaxSupportedVersion](../../cookie/maxsupportedversion/)와 같지 않은 쿠키가 포함되어 있는지 여부를 나타내는 값을 반환합니다.

```cpp
bool System::Net::CookieCollection::get_IsOtherVersionSeen()
```


### 반환 값

컬렉션에 버전이 [Cookie::MaxSupportedVersion](../../cookie/maxsupportedversion/)와 같지 않은 쿠키가 포함되어 있는 경우 true이며, 그렇지 않으면 false입니다.
