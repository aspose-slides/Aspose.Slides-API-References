## TransportType 열거형

Defines the transport type allowed for the socket.

```cpp
enum class TransportType
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Udp | 1 | UDP 전송 유형입니다. |
| Connectionless | n/a | 전송 유형은 연결이 없습니다. |
| Tcp | 2 | TCP 전송 유형입니다. |
| ConnectionOriented | n/a | 전송은 연결 지향입니다. |
| All | 3 | 모든 전송 유형입니다. |
