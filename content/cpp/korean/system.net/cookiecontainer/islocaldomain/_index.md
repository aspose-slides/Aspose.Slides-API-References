## CookieContainer::IsLocalDomain(String) 메서드


Checks if the specified domain is localhost.

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| host | [String](../../../system/string/) | 확인할 도메인. |

### 반환값
