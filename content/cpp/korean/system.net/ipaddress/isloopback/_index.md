## IPAddress::IsLoopback(System::SharedPtr\<IPAddress\>) 메서드

지정된 주소가 루프백 주소인지 여부를 나타내는 값을 반환합니다.

```cpp
static bool System::Net::IPAddress::IsLoopback(System::SharedPtr<IPAddress> address)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| address | [System::SharedPtr](../../../system/sharedptr/)\<[IPAddress](../)\> | 확인할 주소입니다. |

### 반환값

지정된 주소가 루프백 주소이면 true, 그렇지 않으면 false를 반환합니다.
