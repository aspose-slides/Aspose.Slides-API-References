## IWebRequestCreate 클래스

Provides the methods for creating the [WebRequest](../webrequest/) 클래스 instances. Objects of this 클래스 should only be allocated using [System::MakeObject()](../../system/makeobject/) 함수. Never create instance of this type on stack or using operator new, as it will result in runtime errors and/or assertion faults. Always wrap this 클래스 into [System::SmartPtr](../../system/smartptr/) 포인터 and use this 포인터 to pass it to functions as argument.

```cpp
class IWebRequestCreate : public System::Object
```
