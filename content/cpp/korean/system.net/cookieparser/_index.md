## CookieParser 클래스


쿠키 헤더를 파싱하고 [Cookie](../cookie/) 클래스의 인스턴스를 생성하는 데 사용됩니다. 이 클래스의 객체는 [System::MakeObject()](../../system/makeobject/) 함수를 사용하여 할당해야 합니다. 스택에 이 유형의 인스턴스를 생성하거나 operator new를 사용하면 런타임 오류 및/또는 어설션 오류가 발생합니다. 항상 이 클래스를 [System::SmartPtr](../../system/smartptr/) 포인터에 래핑하고 해당 포인터를 함수 인수로 전달하세요.

```cpp
class CookieParser : public System::Object
```
