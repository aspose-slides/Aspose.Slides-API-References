## SmoothingMode 열거형

채워진 영역의 선, 곡선 및 가장자리에 적용되는 부드러움(안티앨리어싱) 유형을 지정합니다.

```cpp
enum class SmoothingMode
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Invalid | n/a | 잘못된 값. |
| Default | n/a | 기본 모드이며, 안티앨리어싱이 적용되지 않습니다. |
| HighSpeed | n/a | 안티앨리어싱이 없으며, 고속. |
| HighQuality | n/a | 안티앨리어싱 렌더링이며, 저속. |
| None | n/a | 안티앨리어싱이 없습니다. |
| AntiAlias | n/a | 안티앨리어싱 렌더링. |
