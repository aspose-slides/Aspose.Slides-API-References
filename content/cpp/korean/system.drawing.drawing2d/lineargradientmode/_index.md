```cpp
enum class LinearGradientMode
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Horizontal | 0 | 왼쪽에서 오른쪽으로. |
| Vertical | 1 | 아래에서 위로. |
| ForwardDiagonal | 2 | 왼쪽 위 모서리에서 오른쪽 아래 모서리까지. |
| BackwardDiagonal | 3 | 오른쪽 위 모서리에서 왼쪽 아래 모서리까지. |
