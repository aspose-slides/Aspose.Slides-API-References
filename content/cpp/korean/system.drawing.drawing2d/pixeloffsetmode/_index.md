```cpp
enum class PixelOffsetMode
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Invalid | n/a | 잘못된 값. |
| Default | n/a | 기본 모드. |
| HighSpeed | n/a | 저품질(고성능) 모드. |
| HighQuality | n/a | 고품질(낮은 성능) 모드. |

| Half | n/a | 픽셀은 고성능 안티앨리어싱을 위해 가로와 세로 모두 -0.5 단위만큼 오프셋됩니다. |
