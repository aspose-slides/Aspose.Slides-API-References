## LineCap 열거형

선의 끝을 지정할 수 있는 [Pen](../../system.drawing/pen/) 객체에 사용 가능한 캡 스타일을 나타냅니다.

```cpp
enum class LineCap
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Flat | 0 | 플랫 라인 캡. |
| Square | 1 | 스퀘어 라인 캡. |
| Round | 2 | 라운드 라인 캡. |
| Triangle | 3 | 삼각형 라인 캡. |
| NoAnchor | 16 | 앵커 없음. |
| SquareAnchor | 17 | 스퀘어 앵커 라인 캡. |
| RoundAnchor | 18 | 라운드 앵커 라인 캡. |
| DiamondAnchor | 19 | 다이아몬드 앵커 라인 캡. |
| ArrowAnchor | 20 | 화살표 앵커 라인 캡. |
| AnchorMask | 240 | 라인 캡이 앵커 캡인지 확인하는 데 사용되는 마스크. |
| Custom | 255 | 사용자 정의 캡. |
