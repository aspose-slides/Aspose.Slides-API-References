## PenAlignment 열거형

Specifies the alignment of a [Pen](../../system.drawing/pen/) object relative to an abstract reference 0-width line.

```cpp
enum class PenAlignment
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Center | 0 | [Pen](../../system.drawing/pen/)가 기준 라인의 중앙에 배치됩니다. |
| Inset | 1 | [Pen](../../system.drawing/pen/)가 기준 라인의 안쪽에 배치됩니다. |
| Outset | 2 | [Pen](../../system.drawing/pen/)가 기준 라인의 바깥쪽에 배치됩니다. |
| Left | 3 | [Pen](../../system.drawing/pen/)가 기준 라인의 왼쪽에 배치됩니다. |
| Right | 4 | [Pen](../../system.drawing/pen/)가 기준 라인의 오른쪽에 배치됩니다. |
