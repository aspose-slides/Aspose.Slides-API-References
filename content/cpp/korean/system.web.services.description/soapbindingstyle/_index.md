## SoapBindingStyle 열거형

이 열거형이 적용되는 클래스 계층 수준의 XML [Web](../../system.web/) 서비스에서 작업 유형을 지정합니다.

```cpp
enum class SoapBindingStyle
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Default | 0 | 기본 작업 유형입니다. |
| Document | 1 | 메시지는 문서 지향입니다. |
| Rpc | 2 | 메시지는 프로시저를 호출하기 위한 매개변수 또는 해당 프로시저의 반환 값을 포함합니다. |
