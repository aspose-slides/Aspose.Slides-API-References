## FileNotFoundException 타입 정의

디스크에 존재하지 않는 파일에 접근하려는 시도가 실패할 때 발생하는 예외입니다. FileNotFoundException 클래스 인스턴스를 [System::SmartPtr](../../system/smartptr/)에 절대로 감싸지 마십시오.

```cpp
using System::IO::FileNotFoundException = typedef System::ExceptionWrapper<Details_FileNotFoundException>
```
