## StreamReader::Peek() 메서드

스트림의 읽기 커서를 변경하지 않고 스트림에서 단일 문자를 읽습니다.

```cpp
virtual int System::IO::StreamReader::Peek() override
```

### 반환 값

UTF-16 인코딩으로 인코딩된 읽은 문자; UTF-16 인코딩에서 두 개의 코드 포인트로 표현되는 경우 고위 서러게이트만 반환됩니다; 문자를 읽지 못한 경우 -1이 반환됩니다
