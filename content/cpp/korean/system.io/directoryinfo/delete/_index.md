## DirectoryInfo::Delete() 메서드


디렉터리가 비어 있을 경우 현재 객체가 나타내는 경로에 해당하는 디렉터리를 제거합니다.

```cpp
virtual void System::IO::DirectoryInfo::Delete() override
```

## DirectoryInfo::Delete(bool) 메서드


현재 객체가 나타내는 경로에 해당하는 디렉터리를 제거합니다. 매개변수는 디렉터리가 비어 있지 않을 경우 디렉터리 내용이 재귀적으로 제거되어야 하는지를 지정합니다.

```cpp
void System::IO::DirectoryInfo::Delete(bool recursive)
```


### 매개변수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| recursive | **bool** | 디렉터리가 비어 있지 않은 경우 디렉터리 내용이 재귀적으로 제거되어야 하는지를 지정합니다 |
