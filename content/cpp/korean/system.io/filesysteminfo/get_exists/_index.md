## FileSystemInfo::get_Exists() 메서드

현재 객체가 나타내는 경로에 의해 참조되는 엔터티가 존재하는지 확인합니다.

```cpp
virtual bool System::IO::FileSystemInfo::get_Exists()=0
```

### 반환 값

현재 객체가 나타내는 경로에 의해 참조되는 엔터티가 존재하면 true, 그렇지 않으면 - false
