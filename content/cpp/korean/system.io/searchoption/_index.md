## SearchOption 열거형

현재 디렉터리만 또는 현재 디렉터리와 모든 하위 디렉터리에서 검색을 수행해야 함을 지정합니다.

```cpp
enum class SearchOption
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| AllDirectories | 0 | 현재 디렉터리와 모든 하위 디렉터리에서 검색합니다. |
| TopDirectoryOnly | 1 | 현재 디렉터리에서만 검색합니다. |
