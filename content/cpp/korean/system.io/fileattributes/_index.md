## FileAttributes 열거형

디렉터리 또는 파일의 속성을 나타냅니다.

```cpp
enum class FileAttributes
```

### 값

| Name | Value | Description |
| --- | --- | --- |
| Archive | 32 | 파일 시스템 엔터티는 삭제 또는 백업 대상입니다. |
| Compressed | 2048 | 파일 시스템 엔터티가 압축되었습니다. |
| Device | 64 | 사용되지 않음. |
| Directory | 16 | 파일 시스템 엔터티는 디렉터리입니다. |
| Encrypted | 16384 | 파일 시스템 엔터티가 암호화되었습니다. |
| Hidden | 2 | 파일 시스템 엔터티가 숨겨져 있습니다. |
| IntegrityStream | 32768 | 파일 시스템 엔터티는 데이터 무결성 지원을 포함합니다. |
| Normal | 128 | 파일 시스템 엔터티는 특별한 속성이 없는 파일입니다. |
| NotContentIndexed | 8192 | 파일 시스템 엔터티는 콘텐츠 인덱싱 서비스에 의해 색인되지 않습니다. |
| NoScrubData | 131072 | 파일 시스템 엔터티는 데이터 무결성 검사에 포함되지 않습니다. |
| Offline | 4096 | 파일 시스템 엔터티가 오프라인이며 데이터가 즉시 사용할 수 없습니다. |
| ReadOnly | 1 | 파일 시스템 엔터티는 읽기 전용입니다. |
| ReparsePoint | 1024 | 파일 시스템 엔터티는 재구성 포인트를 포함하는 파일입니다. |
| SparseFile | 512 | 파일 시스템 엔터티는 스파스 파일입니다. |
| System | 4 | 파일 시스템 엔터티는 시스템 파일입니다. |
| Temporary | 256 | 파일 시스템 엔터티는 임시 파일입니다. |
| Invalid | 0 | 잘못된 값입니다. |
