## STDIOStreamPositionPreference enum

스트림에서 일반적인 읽기 및 쓰기 위치로 선호되는 위치가 `std::basic_iostream` 및 그 파생 클래스가 래퍼 생성 시 서로 다른 읽기와 쓰기 위치를 가질 때 결정합니다.

```cpp
enum class STDIOStreamPositionPreference
```

### Values

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Zero | 0 | Zero 위치는 읽기 및 쓰기 위치로 설정됩니다. |
| ReadPosition | 1 | gptr 위치는 읽기 및 쓰기 위치로 설정됩니다. |
| WritePosition | 2 | pptr 위치는 읽기 및 쓰기 위치로 설정됩니다. |
