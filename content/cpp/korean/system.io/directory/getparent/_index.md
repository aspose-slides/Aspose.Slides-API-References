## Directory::GetParent(const String\&) 메서드

지정된 엔터티의 상위 디렉터리를 나타내는 [DirectoryInfo](../../directoryinfo/) 객체에 대한 공유 포인터를 반환합니다.

```cpp
static DirectoryInfoPtr System::IO::Directory::GetParent(const String &path)
```

### 매개변수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| path | const [String](../../../system/string/)\& | 상위 디렉터리를 얻고자 하는 엔터티의 경로 |

### 반환값

**path** 로 지정된 엔터티의 상위 디렉터리를 나타내는 [DirectoryInfo](../../directoryinfo/) 객체에 대한 공유 포인터
