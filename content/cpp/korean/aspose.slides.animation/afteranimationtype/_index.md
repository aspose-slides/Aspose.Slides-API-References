애니메이션 효과의 애니메이션 후 유형을 나타냅니다.

```cpp
enum class AfterAnimationType
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| DoNotDim | 0 | 애니메이션 후 흐려지지 않음. |
| Color | 1 | 색상 애니메이션 후 유형. |
| HideAfterAnimation | 2 | 숨기기 후 [Animation](../) 유형 |
| HideOnNextMouseClick | 3 | 다음 마우스 클릭 후 숨기기. |
