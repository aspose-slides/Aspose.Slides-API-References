## InkEffectType 열거형

디지털 잉크 렌더링을 위한 미리 정의된 시각 효과 집합을 지정합니다. 각 효과는 스타일화된 잉크 외관을 시뮬레이션하는 텍스처 또는 이미지에 해당합니다. 이러한 값은 렌더링 중 디지털 잉크 스트로크의 시각 스타일을 사용자 지정하는 데 사용할 수 있습니다.

```cpp
enum class InkEffectType
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| NotDefined | -1 | 효과가 정의되지 않았거나 알 수 없습니다. 이 값은 기본값이나 대체값으로 사용할 수 있습니다. |
| Bronze | 0 | 청동 잉크와 유사한 따뜻하고 갈색을 띤 금속 텍스처. |
| Galaxy | 1 | 우주 색조를 가진 다채롭고 반짝이는 은하와 같은 텍스처. |
| Gold | 2 | 잉크 스트로크에 고급스러운 외관을 부여하는 밝은 금속성 금 텍스처. |
| Lava | 3 | 빨강과 주황색 색조를 가진 용융된 용암과 같은 불길한 텍스처. |
| Ocean | 4 | 바다 파도 또는 수성 잉크를 흉내낸 깊은 파란색의 유동성 텍스처. |
| RainbowGlitter | 5 | 축제 분위기 또는 활기찬 잉크 스트로크에 사용되는 다채롭고 반짝이는 무지개 글리터 효과. |
| RoseGold | 6 | 우아한 잉크 스트로크를 위한 로즈 골드와 유사한 부드러운 핑크-골드 혼합 색상. |
| Silver | 7 | 고전적인 은잉크를 시뮬레이션하는 차갑고 금속성 은 텍스처. |
