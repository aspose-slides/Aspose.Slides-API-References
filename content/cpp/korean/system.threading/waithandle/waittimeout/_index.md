## WaitTimeout 필드

함수가 반환해야 하는 특수값이며, 그렇지 않으면 배열에서 신호가 발생한 객체의 인덱스를 반환합니다. 시간이 초과되고 아무런 신호도 없을 경우입니다.

```cpp
static const int System::Threading::WaitHandle::WaitTimeout
```
