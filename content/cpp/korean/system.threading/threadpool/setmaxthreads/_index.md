## ThreadPool::SetMaxThreads(int, int) 메서드

풀에 할당된 스레드 수를 설정합니다.

```cpp
static bool System::Threading::ThreadPool::SetMaxThreads(int wt, int cpt)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| wt | int | 작업자 스레드의 최대 수. |
| cpt | int | [IO](../../../system.io/) 스레드의 최대 수. |

### 반환 값

매개변수가 허용되면 true, 그렇지 않으면 false.
