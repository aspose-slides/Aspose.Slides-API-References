## ColorMatrixFlag 열거형

[ImageAttributes](../imageattributes/) 객체의 색상 및 그레이스케일 조정 설정에 의해 영향을 받는 이미지와 색상의 유형을 지정합니다.

```cpp
enum class ColorMatrixFlag
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Default | 0 | 색상과 그레이스케일 값 모두 색상 조정됩니다. |
| SkipGrays | 1 | 그레이스케일 값은 색상 조정되지 않습니다. |
| AltGrays | 2 | 그레이스케일 값만 색상 조정됩니다. |
