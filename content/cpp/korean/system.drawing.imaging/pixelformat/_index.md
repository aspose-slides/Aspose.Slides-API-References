## PixelFormat 열거형

픽셀의 색 데이터 형식을 지정합니다.

```cpp
enum class PixelFormat
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Indexed | 65536 | 픽셀 데이터에 색 인덱스 값이 포함되어 있음을 지정합니다. 이는 시스템 색상표의 색에 대한 인덱스임을 의미합니다. |
| Gdi | 131072 | 픽셀 데이터에 GDI 색상이 포함되어 있음을 지정합니다. |
| Alpha | 262144 | 픽셀 데이터에 사전 곱셈되지 않은 alpha 값이 포함되어 있음을 지정합니다. |
| PAlpha | 524288 | 픽셀 데이터에 사전 곱셈된 alpha 값이 포함되어 있음을 지정합니다. |
| Extended | 1048576 | 예약됨. |
| Canonical | 2097152 | 픽셀당 32비트, 24비트 색 깊이 및 8비트 alpha 채널을 갖는 픽셀 형식을 지정합니다. |
| Undefined | 0 | 픽셀 형식이 정의되지 않았음을 지정합니다. |
| DontCare | 0 | 픽셀 형식이 지정되지 않았습니다. |
| Format1bppIndexed | n/a | 픽셀 형식이 픽셀당 1비트 인덱스 색상임을 지정합니다. |
| Format4bppIndexed | n/a | 픽셀 형식이 픽셀당 4비트 인덱스 색상임을 지정합니다. |
| Format8bppIndexed | n/a | 픽셀 형식이 픽셀당 8비트 인덱스 색상임을 지정합니다. |
| Format16bppGrayScale | n/a | 픽셀 형식이 픽셀당 16비트임을 지정합니다. 색상 정보는 65,536 단계의 회색을 지정합니다. |
| Format16bppRgb555 | n/a | 픽셀 형식이 픽셀당 16비트이며, 빨강, 초록, 파랑 각 구성 요소에 5비트를 사용하고 나머지 비트는 사용되지 않음을 지정합니다. |
| Format16bppRgb565 | n/a | 픽셀 형식이 픽셀당 16비트이며, 빨강에 5비트, 초록에 6비트, 파랑에 5비트를 사용함을 지정합니다. |
| Format16bppArgb1555 | n/a | 픽셀 형식이 픽셀당 16비트이며, 빨강, 초록, 파랑 각 구성 요소에 5비트와 alpha에 1비트를 사용함을 지정합니다. |
| Format24bppRgb | n/a | 픽셀 형식이 픽셀당 24비트이며, 빨강, 초록, 파랑 각 구성 요소에 8비트를 사용함을 지정합니다. |
| Format32bppRgb | n/a | 픽셀 형식이 픽셀당 32비트이며, 빨강, 초록, 파랑 각 구성 요소에 8비트를 사용하고 남은 8비트는 사용되지 않음을 지정합니다. |
| Format32bppArgb | n/a | 픽셀 형식이 픽셀당 32비트이며, 빨강, 초록, 파랑 각 구성 요소에 8비트와 alpha에 8비트를 사용함을 지정합니다. |
| Format32bppPArgb | n/a | 픽셀 형식이 픽셀당 32비트이며, 빨강, 초록, 파랑 각 구성 요소에 8비트와 alpha에 8비트를 사용함을 지정합니다. 빨강, 초록, 파랑 구성 요소는 alpha 값에 따라 사전 곱셈됩니다. |
| Format48bppRgb | n/a | 픽셀 형식이 픽셀당 48비트이며, 빨강, 초록, 파랑 각 구성 요소에 16비트를 사용함을 지정합니다. |
| Format64bppArgb | n/a | 픽셀 형식이 픽셀당 64비트이며, 빨강, 초록, 파랑 각 구성 요소에 16비트와 alpha에 16비트를 사용함을 지정합니다. |
| Format64bppPArgb | n/a | 픽셀 형식이 픽셀당 64비트이며, 빨강, 초록, 파랑 각 구성 요소에 16비트와 alpha에 16비트를 사용함을 지정합니다. 빨강, 초록, 파랑 구성 요소는 alpha 값에 따라 사전 곱셈됩니다. |
| Format32bppCMYK | n/a | 픽셀 형식이 픽셀당 32비트이며, 시안, 마젠타, 옐로, 키 구성 요소 각각에 8비트를 사용함을 지정합니다. |
| Max | 16 | 이 열거형의 최대 값입니다. |
