## ImageLockMode 열거형

이미지의 잠금 영역의 속성을 지정합니다.

```cpp
enum class ImageLockMode
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| ReadOnly | 1 | 해당 영역은 읽기 전용으로 잠깁니다. |
| WriteOnly | 2 | 해당 영역은 쓰기 전용으로 잠깁니다. |
| ReadWrite | n/a | 해당 영역은 읽기와 쓰기 모두에 대해 잠깁니다. |
| UserInputBuffer | 4 | 이미지는 사용자 입력 버퍼에 위치하며, 접근은 사용자가 제어합니다. |
