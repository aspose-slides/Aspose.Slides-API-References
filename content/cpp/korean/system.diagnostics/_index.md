## 구조체

| 구조체 | 설명 |
| --- | --- |
| [Debug](./debug/) | 등록된 리스너에게 디버그 정보를 전송할 수 있는 디버그 메서드의 컬렉션입니다. 모든 출력 함수는 [Debug](./debug/) 전용으로 동작합니다. 이는 인스턴스 서비스를 제공하지 않는 정적 타입이며, 어떠한 방법으로도 인스턴스를 생성해서는 안 됩니다. |
| [Debugger](./debugger/) | [Debugger](./debugger/) 인터페이스입니다. 이는 인스턴스 서비스를 제공하지 않는 정적 타입이며, 어떠한 방법으로도 인스턴스를 생성해서는 안 됩니다. |
| [Trace](./trace/) | 디버거 트레이스(있는 경우)에 접근하기 위한 인터페이스를 제공합니다. [Debug](./debug/) 모드 전용으로 동작합니다. 이는 인스턴스 서비스를 제공하지 않는 정적 타입이며, 어떠한 방법으로도 인스턴스를 생성해서는 안 됩니다. |
