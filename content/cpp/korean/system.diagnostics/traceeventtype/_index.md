## TraceEventType 열거형


추적을 발생시킨 이벤트 유형을 식별합니다.

```cpp
enum class TraceEventType
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Critical | 1 | 심각한 오류 또는 애플리케이션 충돌. |
| Error | 2 | 복구 가능한 오류. |
| Warning | 4 | 비심각한 문제. |
| Information | 8 | 정보 메시지. |
| Verbose | 16 | 디버깅 추적. |
| Start | 256 | 논리 연산 시작. |
| Stop | 512 | 논리 연산 중지. |
| Suspend | 1024 | 논리 연산 일시 정지. |
| Resume | 2048 | 논리 연산 재개. |
| Transfer | 4096 | 상관 관계 ID 변경. |
