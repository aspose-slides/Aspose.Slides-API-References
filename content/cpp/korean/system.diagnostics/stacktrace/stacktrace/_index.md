```cpp
System::Diagnostics::StackTrace::StackTrace()
```

## StackTrace::StackTrace(bool) 생성자

현재 스택 상태를 설명하는 스택 트레이스를 생성합니다.

```cpp
System::Diagnostics::StackTrace::StackTrace(bool isFileInfoNeeded)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| isFileInfoNeeded | **bool** | 파일 이름, 라인 번호 및 열 번호를 캡처하려면 true; 그렇지 않으면 false |
