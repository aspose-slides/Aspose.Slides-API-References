## TraceLevel 열거형

[System.Diagnostics.Debug](../debug/), [System.Diagnostics.Trace](../trace/) 및 System.Diagnostics.TraceSwitch 클래스에 대해 어떤 메시지를 출력할지 지정합니다.

```cpp
enum class TraceLevel
```

### Values

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Off | 0 | 추적 및 디버깅 메시지를 출력하지 않습니다. |
| Error | 1 | 오류 처리 메시지를 출력합니다. |
| Warning | 2 | 경고 및 오류 처리 메시지를 출력합니다. |
| Info | 3 | 정보 메시지, 경고 및 오류 처리 메시지를 출력합니다. |
| Verbose | 4 | 모든 디버깅 및 추적 메시지를 출력합니다. |
