## XmlTokenizedType 열거형

문자열에 대한 XML 유형을 나타냅니다. 이를 통해 문자열을 특정 XML 유형으로 읽을 수 있습니다. 예를 들어 CDATA 섹션 유형이 있습니다.

```cpp
enum class XmlTokenizedType
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| CDATA | 0 | CDATA 유형. |
| ID | 1 | ID 유형. |
| IDREF | 2 | IDREF 유형. |
| IDREFS | 3 | IDREFS 유형. |
| ENTITY | 4 | ENTITY 유형. |
| ENTITIES | 5 | ENTITIES 유형. |
| NMTOKEN | 6 | NMTOKEN 유형. |
| NMTOKENS | 7 | NMTOKENS 유형. |
| NOTATION | 8 | NOTATION 유형. |
| ENUMERATION | 9 | ENUMERATION 유형. |
| QName | 10 | QName 유형. |
| NCName | 11 | NCName 유형. |
| None | 12 | 유형 없음. |
