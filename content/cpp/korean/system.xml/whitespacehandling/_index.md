```cpp
enum class WhitespaceHandling
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| All | 0 | **Whitespace**와 **SignificantWhitespace** 노드를 반환합니다. 이것이 기본값입니다. |
| Significant | 1 | **SignificantWhitespace** 노드만 반환합니다. |
| None | 2 | **Whitespace**와 **SignificantWhitespace** 노드를 반환하지 않습니다. |
