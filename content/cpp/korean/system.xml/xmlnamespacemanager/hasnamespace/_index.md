## XmlNamespaceManager::HasNamespace(String) 메서드

현재 푸시된 범위에 대해 제공된 접두사에 네임스페이스가 정의되어 있는지 여부를 반환합니다.

```cpp
virtual bool System::Xml::XmlNamespaceManager::HasNamespace(String prefix)
```

### 인수

| 매개변수 | 유형 | 설명 |
| --- | --- | --- |
| prefix | [String](../../../system/string/) | 찾고자 하는 네임스페이스의 접두사입니다. |

### 반환 값

**true** if there is a namespace defined; otherwise, **false**.
