## XmlTextReader::MoveToElement() 메서드

현재 속성 노드를 포함하는 요소로 이동합니다.

```cpp
bool System::Xml::XmlTextReader::MoveToElement() override
```

### 반환값

**true** 리더가 속성에 배치된 경우(리더가 해당 속성을 소유하는 요소로 이동함); **false** 리더가 속성에 배치되지 않은 경우(리더의 위치가 변경되지 않음).
