## XmlTextReader::get_IsEmptyElement() 메서드


현재 노드가 빈 요소인지 여부를 나타내는 값을 반환합니다 (예: **<MyElement/>**).

```cpp
bool System::Xml::XmlTextReader::get_IsEmptyElement() override
```


### 반환 값

**true** 현재 노드가 요소([XmlTextReader::get_NodeType](../get_nodetype/) 값이 [XmlNodeType::Element](../../xmlnodetype/)와 같은)이며 **/>** 로 끝나는 경우; 그렇지 않으면 **false**.
