## XmlTextReader::get_HasValue() 메서드

```cpp
bool System::Xml::XmlTextReader::get_HasValue() override
```


### 반환값

현재 판독기가 위치한 노드가 **Value**를 가질 수 있으면 **true**; 그렇지 않으면 **false**.
