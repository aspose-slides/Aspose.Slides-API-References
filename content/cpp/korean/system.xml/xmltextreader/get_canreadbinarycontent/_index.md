## XmlTextReader::get_CanReadBinaryContent() 메서드

[XmlTextReader](../) 가 바이너리 콘텐츠 읽기 메서드를 구현하는지 여부를 나타내는 값을 반환합니다.

```cpp
bool System::Xml::XmlTextReader::get_CanReadBinaryContent() override
```

### 반환값

바이너리 콘텐츠 읽기 메서드가 구현된 경우 **true**, 그렇지 않은 경우 **false**. [XmlTextReader](../) 클래스는 항상 **true**를 반환합니다.
