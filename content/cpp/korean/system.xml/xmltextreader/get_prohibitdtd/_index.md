## XmlTextReader::get_ProhibitDtd() 메서드


DTD 처리를 허용할지 여부를 나타내는 값을 반환합니다.

```cpp
bool System::Xml::XmlTextReader::get_ProhibitDtd()
```


### 반환 값

**true**를 반환하면 DTD 처리를 허용하지 않으며, 그렇지 않으면 **false**를 반환합니다. 기본값은 **false**입니다.

더 이상 사용되지 않음
:   이 메서드는 더 이상 사용되지 않습니다. 대신 [XmlTextReader::get_DtdProcessing](../get_dtdprocessing/)를 사용하십시오.
