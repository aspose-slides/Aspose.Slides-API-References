## XmlElement::set_IsEmpty(bool) 메서드


요소의 태그 형식을 설정합니다.

```cpp
void System::Xml::XmlElement::set_IsEmpty(bool value)
```


### 인수

| Parameter | Type | Description |
| --- | --- | --- |
| value | **bool** | 설정할 값입니다. 이 값을 설정할 때 **true** 로 설정하면 요소의 자식이 제거되고 요소가 짧은 태그 형식으로 직렬화됩니다. **false** 로 설정하면 값이 변경됩니다(요소에 내용이 있든 없든); 요소가 비어 있으면 긴 형식으로 직렬화됩니다. |
