## XmlNotation::get_IsReadOnly() method


노드가 읽기 전용인지 여부를 나타내는 값을 반환합니다.

```cpp
bool System::Xml::XmlNotation::get_IsReadOnly() override
```


### 반환 값

노드가 읽기 전용인 경우 **true**, 그렇지 않은 경우 **false**. [XmlNotation](../) 노드는 읽기 전용이므로, 이 메서드는 항상 **true**를 반환합니다.
