## XmlNodeOrder enum

문서에서 노드가 두 번째 노드와 비교했을 때의 순서를 설명합니다.

```cpp
enum class XmlNodeOrder
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Before | 0 | 이 탐색기의 현재 노드는 제공된 탐색기의 현재 노드보다 앞에 있습니다. |
| After | 1 | 이 탐색기의 현재 노드는 제공된 탐색기의 현재 노드보다 뒤에 있습니다. |
| Same | 2 | 두 탐색기가 같은 노드에 위치합니다. |
| Unknown | 3 | 두 노드의 위치를 문서 순서상에서 서로 상대적으로 판단할 수 없습니다. 두 노드가 서로 다른 트리에 있을 경우 발생할 수 있습니다. |
