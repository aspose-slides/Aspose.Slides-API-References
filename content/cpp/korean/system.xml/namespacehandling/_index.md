## NamespaceHandling 열거형

중복 네임스페이스 선언을 [XmlWriter](../xmlwriter/)에서 제거할지 여부를 지정합니다.

```cpp
enum class NamespaceHandling
```

### 값

| Name | Value | Description |
| --- | --- | --- |
| Default | 0 | 중복 네임스페이스 선언이 제거되지 않도록 지정합니다. |
| OmitDuplicates | 1 | 중복 네임스페이스 선언이 제거되도록 지정합니다. 중복 네임스페이스를 제거하려면 접두사와 네임스페이스가 일치해야 합니다. |
