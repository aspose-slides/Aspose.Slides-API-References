## XmlTextWriter::get_Indentation() 메서드

계층 구조의 각 레벨에 쓸 **IndentChars** 수를 반환합니다. [XmlTextWriter::set_Formatting](../set_formatting/)가 [Formatting::Indented](../../formatting/)로 설정된 경우.

```cpp
int32_t System::Xml::XmlTextWriter::get_Indentation()
```

### 반환값

각 레벨당 **IndentChars** 수입니다. 기본값은 2입니다.
