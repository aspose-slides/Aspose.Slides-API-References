## XmlTextWriter::LookupPrefix(String) 메서드

현재 네임스페이스 범위에서 지정된 네임스페이스 URI에 대해 가장 가까운 접두사를 반환합니다.

```cpp
String System::Xml::XmlTextWriter::LookupPrefix(String ns) override
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| ns | [String](../../../system/string/) | 접두사를 찾고자 하는 네임스페이스 URI. |

### 반환값

일치하는 접두사. 현재 범위에 일치하는 네임스페이스 URI가 없으면 **nullptr**를 반환합니다.
