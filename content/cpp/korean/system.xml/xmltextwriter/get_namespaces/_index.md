## XmlTextWriter::get_Namespaces() 메서드

네임스페이스 지원을 할지 여부를 나타내는 값을 반환합니다.

```cpp
bool System::Xml::XmlTextWriter::get_Namespaces()
```

### 반환 값

**true** 를 반환하여 네임스페이스를 지원하고, 그렇지 않으면 **false** 를 반환합니다. 기본값은 **true** 입니다.
