## XmlTextWriter::get_XmlSpace() 메서드

Returns an XmlSpace representing the current **xml:space** scope.

```cpp
System::Xml::XmlSpace System::Xml::XmlTextWriter::get_XmlSpace() override
```

### 반환 값

현재 **xml:space** 범위를 나타내는 XmlSpace.

| 값 | 의미 |
| --- | --- |
| None | 이것은 `xml:space` 범위가 존재하지 않을 때 기본값입니다. |
| Default | 현재 범위는 `xml:space="default"` 입니다. |
| Preserve | 현재 범위는 `xml:space="preserve"` 입니다. |
