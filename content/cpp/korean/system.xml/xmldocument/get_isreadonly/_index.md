## XmlDocument::get_IsReadOnly() 메서드


현재 노드가 읽기 전용인지 여부를 나타내는 값을 반환합니다.

```cpp
bool System::Xml::XmlDocument::get_IsReadOnly() override
```


### 반환값

현재 노드가 읽기 전용이면 **true**; 그렇지 않으면 **false**. [XmlDocument](../) 노드는 항상 **false**를 반환합니다.
