## XmlDocument::get_PreserveWhitespace() 메서드

요소 콘텐츠에서 공백을 유지할지 여부를 나타내는 값을 반환합니다.

```cpp
bool System::Xml::XmlDocument::get_PreserveWhitespace()
```

### 반환 값

**true**를 반환하면 공백을 유지하고, 그렇지 않으면 **false**를 반환합니다. 기본값은 **false**입니다.
