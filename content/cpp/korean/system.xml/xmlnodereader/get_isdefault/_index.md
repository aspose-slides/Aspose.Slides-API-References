## XmlNodeReader::get_IsDefault() 메서드

현재 노드가 문서 유형 정의(DTD) 또는 스키마에서 정의된 기본값으로부터 생성된 속성인지 여부를 나타내는 값을 반환합니다.

```cpp
bool System::Xml::XmlNodeReader::get_IsDefault() override
```

### 반환 값

**true** 현재 노드가 DTD 또는 스키마에 정의된 기본값으로부터 생성된 값의 속성인 경우; **false** 속성 값이 명시적으로 설정된 경우.
