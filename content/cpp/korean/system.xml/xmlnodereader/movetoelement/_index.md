## XmlNodeReader::MoveToElement() 메서드


현재 속성 노드를 포함하는 요소로 이동합니다.

```cpp
bool System::Xml::XmlNodeReader::MoveToElement() override
```


### 반환 값

**true** 경우, 리더가 속성에 위치할 때 (리더는 해당 속성을 포함하는 요소로 이동합니다); **false** 경우, 리더가 속성에 위치하지 않을 때 (리더의 위치는 변경되지 않습니다).
