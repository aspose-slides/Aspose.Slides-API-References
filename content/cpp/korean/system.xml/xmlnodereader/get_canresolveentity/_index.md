## XmlNodeReader::get_CanResolveEntity() 메서드


이 판독기가 엔터티를 구문 분석하고 해결할 수 있는지 여부를 나타내는 값을 반환합니다.

```cpp
bool System::Xml::XmlNodeReader::get_CanResolveEntity() override
```


### 반환 값

**true**이면 판독기가 엔터티를 구문 분석하고 해결할 수 있는 경우; 그렇지 않으면 **false**. [XmlNodeReader](../)는 항상 **true**를 반환합니다.
