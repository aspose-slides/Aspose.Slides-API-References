## XmlValidatingReader::get_NamespaceURI() 메서드

Returns the 네임스페이스 Uniform Resource Identifier (URI) (as defined in the 월드 와이드 [Web](../../../system.web/) 컨소시엄 (W3C) 네임스페이스 specification) of the node on which the reader is positioned.

```cpp
String System::Xml::XmlValidatingReader::get_NamespaceURI() override
```

### 반환값

현재 노드의 네임스페이스 URI; 그렇지 않으면 빈 문자열.
