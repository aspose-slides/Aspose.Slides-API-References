## XmlReaderSettings::get_MaxCharactersInDocument() 메서드


XML 문서에서 허용되는 최대 문자 수를 나타내는 값을 반환합니다. 값이 0이면 XML 문서 크기에 제한이 없음을 의미합니다. 0이 아닌 값은 문자 단위의 최대 크기를 지정합니다.

```cpp
int64_t System::Xml::XmlReaderSettings::get_MaxCharactersInDocument()
```


### 반환 값

XML 문서에서 허용되는 최대 문자 수입니다. 기본값은 0입니다.
