## XmlReaderSettings::get_IgnoreWhitespace() 메서드


불필요한 공백을 무시할지 여부를 나타내는 값을 반환합니다.

```cpp
bool System::Xml::XmlReaderSettings::get_IgnoreWhitespace()
```


### 반환 값

**true** 를 반환하면 공백을 무시하고, 그렇지 않으면 **false** 를 반환합니다. 기본값은 **false** 입니다.
