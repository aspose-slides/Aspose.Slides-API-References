## XmlReaderSettings::get_ProhibitDtd() 메서드

문서 유형 정의(DTD) 처리 금지를 나타내는 값을 반환합니다.

```cpp
bool System::Xml::XmlReaderSettings::get_ProhibitDtd()
```

### 반환 값

**true** to prohibit DTD processing; otherwise **false**. The default is **true**.

사용 중단
:   이 메서드는 더 이상 사용되지 않습니다. 대신 [XmlTextReader::get_DtdProcessing](../../xmltextreader/get_dtdprocessing/)을 사용하세요.
