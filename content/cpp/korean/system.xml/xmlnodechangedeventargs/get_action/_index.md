## XmlNodeChangedEventArgs::get_Action() 메서드


노드 변경 이벤트의 유형을 나타내는 값을 반환합니다.

```cpp
XmlNodeChangedAction System::Xml::XmlNodeChangedEventArgs::get_Action()
```


### 반환값

노드 변경 이벤트를 설명하는 열거형 값 중 하나입니다. **Action** 값은 이벤트가 발생한 시점(이전 또는 이후)을 구분하지 않습니다. 두 경우 모두를 처리하기 위해 별도의 이벤트 핸들러를 만들 수 있습니다.
