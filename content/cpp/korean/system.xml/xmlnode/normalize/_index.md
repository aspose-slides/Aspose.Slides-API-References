## XmlNode::Normalize() 메서드

이 [XmlNode](../) 아래의 서브 트리 전체 깊이에 있는 모든 [XmlText](../../xmltext/) 노드를 \"normal\" 형태로 변환합니다. 이 형태에서는 마크업(즉, 태그, 주석, 처리 명령, CDATA 섹션 및 엔터티 참조)만이 [XmlText](../../xmltext/) 노드를 구분하며, 인접한 [XmlText](../../xmltext/) 노드가 없습니다.

```cpp
virtual void System::Xml::XmlNode::Normalize()
```
