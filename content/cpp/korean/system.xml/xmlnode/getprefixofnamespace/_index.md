## XmlNode::GetPrefixOfNamespace(String) 메서드

현재 노드에서 범위에 있는 지정된 네임스페이스 URI에 대한 가장 가까운 **xmlns** 선언을 찾고 해당 선언에 정의된 접두사를 반환합니다.

```cpp
virtual String System::Xml::XmlNode::GetPrefixOfNamespace(String namespaceURI)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| namespaceURI | [String](../../../system/string/) | 접두사를 찾고자 하는 네임스페이스 URI. |

### 반환값

지정된 네임스페이스 URI에 대한 접두사.
