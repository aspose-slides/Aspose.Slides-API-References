## XmlConvert::IsPublicIdChar(char16_t) 메서드

인수의 문자가 유효한 public id 문자이면 전달된 문자 인스턴스를 반환하고, 그렇지 않으면 **nullptr**를 반환합니다.

```cpp
static bool System::Xml::XmlConvert::IsPublicIdChar(char16_t ch)
```

### 매개변수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| ch | char16_t | [Char](../../../system/char/) 개체를 검증합니다. |

### 반환 값

문자가 유효한 public id 문자이면 전달된 문자를 반환하고, 그렇지 않으면 **nullptr**를 반환합니다.
