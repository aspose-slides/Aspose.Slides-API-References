## XmlConvert::VerifyXmlChars(const String\&) 메서드


전달된 문자열의 모든 문자와 서러게이트 쌍 문자가 유효한 XML 문자이면 해당 문자열을 반환하고, 그렇지 않을 경우 첫 번째 잘못된 문자를 나타내는 정보를 포함한 XmlException이 발생합니다.

```cpp
static String System::Xml::XmlConvert::VerifyXmlChars(const String &content)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| content | const [String](../../../system/string/)\& | [String](../../../system/string/)는 확인할 문자를 포함합니다. |

### 반환 값

전달된 문자열의 모든 문자와 서러게이트 쌍 문자가 유효한 XML 문자이면 해당 문자열을 반환하고, 그렇지 않을 경우 첫 번째 잘못된 문자를 나타내는 정보를 포함한 XmlException이 발생합니다.
