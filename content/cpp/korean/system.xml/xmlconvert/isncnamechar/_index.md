## XmlConvert::IsNCNameChar(char16_t) 메서드


전달된 문자가 유효한 콜론이 없는 문자 유형인지 검사합니다.

```cpp
static bool System::Xml::XmlConvert::IsNCNameChar(char16_t ch)
```


### 매개변수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| ch | char16_t | 콜론이 없는 문자로 확인할 문자. |

### 반환값

**true**는 문자가 유효한 콜론이 없는 문자 유형인 경우이며, 그렇지 않으면 **false**입니다.
