## XmlConvert::IsXmlSurrogatePair(char16_t, char16_t) 메서드


전달된 서러게이트 문자 쌍이 유효한 XML 문자인지 확인합니다.

```cpp
static bool System::Xml::XmlConvert::IsXmlSurrogatePair(char16_t lowChar, char16_t highChar)
```


### 인수

| Parameter | Type | Description |
| --- | --- | --- |
| lowChar | char16_t | 검증할 서러게이트 문자입니다. |
| highChar | char16_t | 검증할 서러게이트 문자입니다. |

### 반환 값

**true** 이면 전달된 서러게이트 문자 쌍이 유효한 XML 문자이며, 그렇지 않으면 **false**.
