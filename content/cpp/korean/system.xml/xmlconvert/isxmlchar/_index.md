## XmlConvert::IsXmlChar(char16_t) 메서드

Checks if the passed-in character is a valid XML character.

```cpp
static bool System::Xml::XmlConvert::IsXmlChar(char16_t ch)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| ch | char16_t | 유효성을 검사할 문자. |

### 반환값

**true**는 전달된 문자가 유효한 XML 문자인 경우; 그렇지 않으면 **false**.
