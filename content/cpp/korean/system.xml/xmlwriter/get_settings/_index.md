## XmlWriter::get_Settings() 메서드


이 [XmlWriter](../) 인스턴스를 만드는 데 사용된 [XmlWriterSettings](../../xmlwritersettings/) 객체를 반환합니다.

```cpp
virtual SharedPtr<XmlWriterSettings> System::Xml::XmlWriter::get_Settings()
```


### 반환 값

[XmlWriterSettings](../../xmlwritersettings/) 객체는 이 writer 인스턴스를 만드는 데 사용됩니다. 이 writer가 [XmlWriter::Create](../create/) 메서드를 사용하여 생성되지 않은 경우, 이 메서드는 **nullptr**를 반환합니다.
