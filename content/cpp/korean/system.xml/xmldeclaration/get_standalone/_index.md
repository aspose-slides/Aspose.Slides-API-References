## XmlDeclaration::get_Standalone() 메서드

standalone 속성의 값을 반환합니다.

```cpp
String System::Xml::XmlDeclaration::get_Standalone()
```

### 반환값

XML 문서에 필요한 모든 엔터티 선언이 문서 내에 포함되어 있으면 **yes**, 외부 DTD가 필요하면 **no**가 유효한 값입니다. XML 선언에 standalone 속성이 없으면 이 메서드는 [String::Empty](../../../system/string/empty/)를 반환합니다.
