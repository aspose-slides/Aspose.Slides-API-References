## XmlAttribute::get_Specified() 메서드


속성 값이 명시적으로 설정되었는지 여부를 나타내는 값을 반환합니다.

```cpp
virtual bool System::Xml::XmlAttribute::get_Specified()
```


### 반환 값

**true** 이 속성이 원본 인스턴스 문서에서 명시적으로 값을 부여받은 경우; 그렇지 않으면 **false**. **false** 값은 해당 속성의 값이 DTD에서 가져온 것임을 나타냅니다.
