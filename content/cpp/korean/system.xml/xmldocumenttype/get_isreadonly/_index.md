## XmlDocumentType::get_IsReadOnly() 메서드


노드가 읽기 전용인지 여부를 나타내는 값을 반환합니다.

```cpp
bool System::Xml::XmlDocumentType::get_IsReadOnly() override
```


### 반환 값

**true** if the node is read-only; otherwise, **false**. DocumentType 노드는 읽기 전용이므로, 이 메서드는 항상 **true**를 반환합니다.
