## XmlReader::ReadInnerXml() 메서드

파생 클래스에서 재정의될 경우, 모든 콘텐츠(마크업 포함)를 문자열로 읽어옵니다.

```cpp
virtual String System::Xml::XmlReader::ReadInnerXml()
```

### 반환 값

현재 노드에 있는 모든 XML 콘텐츠(마크업 포함). 현재 노드에 자식이 없으면 빈 문자열이 반환됩니다. 현재 노드가 요소도 속성도 아니면 빈 문자열이 반환됩니다.
