## XmlReader::MoveToElement() 메서드

파생 클래스에서 재정의될 경우, 현재 속성 노드를 포함하는 요소로 이동합니다.

```cpp
virtual bool System::Xml::XmlReader::MoveToElement()=0
```

### 반환값

**true**: 리더가 속성에 위치한 경우(리더가 해당 속성을 소유하는 요소로 이동함); **false**: 리더가 속성에 위치하지 않은 경우(리더의 위치가 변경되지 않음).
