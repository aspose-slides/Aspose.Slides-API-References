## XmlReader::get_Settings() 메서드

이 [XmlReader](../) 인스턴스를 생성하는 데 사용된 [XmlReaderSettings](../../xmlreadersettings/) 객체를 반환합니다.

```cpp
virtual SharedPtr<XmlReaderSettings> System::Xml::XmlReader::get_Settings()
```

### 반환 값

[XmlReaderSettings](../../xmlreadersettings/) 객체는 이 리더 인스턴스를 생성하는 데 사용됩니다. 이 리더가 [XmlReader::Create](../create/) 메서드를 사용하여 생성되지 않은 경우, 이 메서드는 **nullptr**를 반환합니다.
