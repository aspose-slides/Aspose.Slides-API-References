## XmlReader::get_EOF() 메서드

파생 클래스에서 재정의될 때, 리더가 스트림의 끝에 위치해 있는지를 나타내는 값을 가져옵니다.

```cpp
virtual bool System::Xml::XmlReader::get_EOF()=0
```

### 반환값

리더가 스트림의 끝에 위치하면 **true**, 그렇지 않으면 **false**.
