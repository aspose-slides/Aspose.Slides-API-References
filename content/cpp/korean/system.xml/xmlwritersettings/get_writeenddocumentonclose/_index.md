## XmlWriterSettings::get_WriteEndDocumentOnClose() 메서드

값을 반환하며, [XmlWriter](../../xmlwriter/)가 [XmlWriter::Close](../../xmlwriter/close/) 메서드가 호출될 때 모든 닫히지 않은 요소 태그에 닫는 태그를 추가할지 여부를 나타냅니다.

```cpp
bool System::Xml::XmlWriterSettings::get_WriteEndDocumentOnClose()
```

### 반환 값

**true**이면 모든 닫히지 않은 요소 태그가 닫히고, 그렇지 않으면 **false**. 기본값은 **true**입니다.
