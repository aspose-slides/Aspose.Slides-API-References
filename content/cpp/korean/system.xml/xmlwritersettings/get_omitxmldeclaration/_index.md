## XmlWriterSettings::get_OmitXmlDeclaration() method


XML 선언을 생략할지 여부를 나타내는 값을 반환합니다.

```cpp
bool System::Xml::XmlWriterSettings::get_OmitXmlDeclaration()
```


### 반환값

**true**는 XML 선언을 생략함을 의미하고, **false**는 그렇지 않음을 의미합니다. 기본값은 **false**이며, XML 선언이 작성됩니다.
