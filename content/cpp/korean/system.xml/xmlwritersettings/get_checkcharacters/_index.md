## XmlWriterSettings::get_CheckCharacters() 메서드

문서의 모든 문자들이 W3C [XML 1.0 Recommendation](https://www.w3.org/TR/REC-xml/#charsets)의 "2.2 Characters" 섹션을 준수하는지 확인하도록 XML writer가 검사해야 하는지를 나타내는 값을 반환합니다.

```cpp
bool System::Xml::XmlWriterSettings::get_CheckCharacters()
```

### 반환 값

**true** 는 문자 검사를 수행하도록; 그렇지 않으면 **false**. 기본값은 **true** 입니다.
