## XmlWriterSettings::get_Indent() 메서드

요소를 들여쓰기 할지 여부를 나타내는 값을 반환합니다.

```cpp
bool System::Xml::XmlWriterSettings::get_Indent()
```

### 반환값

**true** 를 반환하면 개별 요소를 새 줄에 쓰고 들여쓰기를 수행합니다; 그렇지 않으면 **false** 를 반환합니다. 기본값은 **false** 입니다.
