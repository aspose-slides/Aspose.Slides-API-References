## XmlWriterSettings::get_NamespaceHandling() 메서드


XML 콘텐츠를 작성할 때 [XmlWriter](../../xmlwriter/)가 중복 네임스페이스 선언을 제거해야 하는지를 나타내는 값을 반환합니다. 기본 동작은 작성기의 네임스페이스 해결기에 존재하는 모든 네임스페이스 선언을 출력하는 것입니다.

```cpp
System::Xml::NamespaceHandling System::Xml::XmlWriterSettings::get_NamespaceHandling()
```


### 반환 값

NamespaceHandling 열거형은 [XmlWriter](../../xmlwriter/)에서 중복 네임스페이스 선언을 제거할지 여부를 지정하는 데 사용됩니다.
