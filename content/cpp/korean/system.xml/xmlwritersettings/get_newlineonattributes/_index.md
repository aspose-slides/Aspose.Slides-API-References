## XmlWriterSettings::get_NewLineOnAttributes() 메서드

속성을 새로운 줄에 기록할지 여부를 나타내는 값을 반환합니다.

```cpp
bool System::Xml::XmlWriterSettings::get_NewLineOnAttributes()
```

### 반환 값

**true**를 사용하면 속성을 개별 줄에 기록합니다; 그렇지 않으면 **false**. 기본값은 **false**입니다.
