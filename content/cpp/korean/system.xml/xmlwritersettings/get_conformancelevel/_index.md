## XmlWriterSettings::get_ConformanceLevel() 메서드

```cpp
System::Xml::ConformanceLevel System::Xml::XmlWriterSettings::get_ConformanceLevel()
```

### 반환 값

적합성 수준(문서, 조각, 또는 자동 감지)을 지정하는 열거형 값 중 하나입니다. 기본값은 [ConformanceLevel::Document](../../conformancelevel/)입니다.
