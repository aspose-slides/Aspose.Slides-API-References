## System::MemoryExtensions::IsWhiteSpace(const ReadOnlySpan\<char16_t\>\&) 함수

전체 span이 공백 문자만으로 구성되어 있는지 확인합니다.

```cpp
bool System::MemoryExtensions::IsWhiteSpace(const ReadOnlySpan<char16_t> &span)
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| span | const [ReadOnlySpan](../../system/readonlyspan/)\<char16_t\>\& | 공백을 확인할 span |

### 반환 값

span의 모든 문자가 공백이면 true, 그렇지 않으면 false
