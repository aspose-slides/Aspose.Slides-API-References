## XsltSettings::get_EnableDocumentFunction() 메서드


XSLT **document()** 함수에 대한 지원을 활성화할지 여부를 나타내는 값을 반환합니다.

```cpp
bool System::Xml::Xsl::XsltSettings::get_EnableDocumentFunction()
```


### 반환 값

**true**는 XSLT **document()** 함수를 지원함을 의미하고, **false**는 지원하지 않음을 의미합니다. 기본값은 **false**입니다.
