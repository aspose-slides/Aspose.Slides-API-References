## XsltSettings::get_EnableScript() 메서드

임베디드 스크립트 블록에 대한 지원을 활성화할지 여부를 나타내는 값을 반환합니다.

```cpp
bool System::Xml::Xsl::XsltSettings::get_EnableScript()
```

### 반환 값

**true** to support script blocks in XSLT 스타일 시트; otherwise, **false**. The default is **false**.
