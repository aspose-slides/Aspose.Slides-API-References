## IXsltContextVariable::get_IsParam() 메서드


변수가 Extensible Stylesheet Language Transformations (XSLT) 매개변수인지 여부를 나타내는 값을 반환합니다. 이는 스타일 시트 또는 템플릿에 대한 매개변수가 될 수 있습니다.

```cpp
virtual bool System::Xml::Xsl::IXsltContextVariable::get_IsParam()=0
```


### 반환 값

변수가 XSLT 매개변수인 경우 **true**; 그렇지 않은 경우 **false**.
