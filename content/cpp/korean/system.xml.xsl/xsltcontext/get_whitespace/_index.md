## XsltContext::get_Whitespace() 메서드


파생 클래스에서 재정의될 때, 출력에 공백 노드를 포함할지 여부를 나타내는 값을 가져옵니다.

```cpp
virtual bool System::Xml::Xsl::XsltContext::get_Whitespace()=0
```


### 반환값

**true**는 출력에 포함하기 위해 소스 문서의 공백 노드를 확인하도록; **false**는 공백 노드를 평가하지 않도록 합니다. 기본값은 **true**입니다.
