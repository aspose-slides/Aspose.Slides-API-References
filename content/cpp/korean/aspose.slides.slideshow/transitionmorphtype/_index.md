## TransitionMorphType 열거형

Morph 전환 유형을 나타냅니다.

```cpp
enum class TransitionMorphType
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| ByObject | 0 | Morph 전환은 도형을 분리할 수 없는 객체로 간주하여 수행됩니다. |
| ByWord | 1 | Morph 전환은 가능한 경우 텍스트를 단어 단위로 전송하면서 수행됩니다. |
| ByChar | 2 | Morph 전환은 가능한 경우 텍스트를 문자 단위로 전송하면서 수행됩니다. |
