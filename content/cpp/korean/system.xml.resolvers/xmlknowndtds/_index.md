## XmlKnownDtds 열거형

[Resolvers::XmlKnownDtds](./) 열거형은 [Resolvers::XmlPreloadedResolver](../xmlpreloadedresolver/)에서 사용되며 [Resolvers::XmlPreloadedResolver](../xmlpreloadedresolver/)가 인식하는 잘 알려진 DTD를 정의합니다.

```cpp
enum class XmlKnownDtds
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| None | 0 | [Resolvers::XmlPreloadedResolver](../xmlpreloadedresolver/)가 사전 정의된 DTD를 전혀 인식하지 않도록 지정합니다. |
| Xhtml10 | 1 | [Resolvers::XmlPreloadedResolver](../xmlpreloadedresolver/)가 XHTML 1.0에 정의된 DTD와 엔티티를 인식하도록 지정합니다. |
| Rss091 | 2 | [Resolvers::XmlPreloadedResolver](../xmlpreloadedresolver/)가 RSS 0.91에 정의된 DTD와 엔티티를 인식하도록 지정합니다. |
| All | 65535 | [Resolvers::XmlPreloadedResolver](../xmlpreloadedresolver/)가 현재 지원되는 모든 DTD를 인식하도록 지정합니다. 이는 기본 동작입니다. |
