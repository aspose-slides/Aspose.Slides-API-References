## EncryptionPolicy 열거형

암호화 정책을 열거합니다.

```cpp
enum class EncryptionPolicy
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| RequireEncryption | 0 | 암호화를 요구하고 'Null' 암호를 절대 허용하지 않습니다. |
| AllowNoEncryption | 1 | 전체 암호화를 선호하지만 서버가 동의하면 'Null' 암호를 사용할 수 있습니다. |
| NoEncryption | 2 | 암호화를 허용하지 않으며 상대 엔드포인트가 'Null' 암호를 처리할 수 있으면 'Null' 암호를 사용하도록 요청합니다. |
