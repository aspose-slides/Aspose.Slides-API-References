## XmlSortOrder enum

정렬 순서를 지정합니다.

```cpp
enum class XmlSortOrder
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Ascending | 1 | 노드는 오름차순으로 정렬됩니다. 예를 들어, 숫자 1,2,3 및 4가 오름차순으로 정렬되면 1,2,3,4으로 표시됩니다. |
| Descending | 2 | 노드는 내림차순으로 정렬됩니다. 예를 들어, 숫자 1,2,3 및 4가 내림차순으로 정렬되면 표시됩니다, 4,3,2,1. |
