```cpp
enum class XmlCaseOrder
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| None | 0 | 대소문자를 무시합니다. |
| UpperFirst | 1 | 대문자는 소문자보다 먼저 정렬됩니다. |
