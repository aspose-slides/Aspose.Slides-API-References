## XPathNavigator::MoveToFirstChild() 메서드


파생 클래스에서 재정의될 때, [XPathNavigator](../)를 현재 노드의 첫 번째 자식 노드로 이동합니다.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToFirstChild()=0
```


### 반환값

**true** if the [XPathNavigator](../)가 현재 노드의 첫 번째 자식 노드로 이동하는 데 성공하면; 그렇지 않으면 **false**. **false**인 경우, [XPathNavigator](../)의 위치는 변경되지 않습니다.
