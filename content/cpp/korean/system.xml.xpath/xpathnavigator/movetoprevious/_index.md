## XPathNavigator::MoveToPrevious() 메서드


파생 클래스에서 재정의될 경우, [XPathNavigator](../)를 현재 노드의 이전 형제 노드로 이동합니다.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToPrevious()=0
```


### 반환 값

**true**는 [XPathNavigator](../)가 이전 형제 노드로 이동하는 데 성공했을 때; 그렇지 않으면 **false**는 이전 형제 노드가 없거나 [XPathNavigator](../)가 현재 속성 노드에 위치해 있을 때. **false**인 경우, [XPathNavigator](../)의 위치는 변경되지 않습니다.
