## XPathNavigator::get_HasAttributes() 메서드


현재 노드에 속성이 있는지 여부를 나타내는 값을 반환합니다.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::get_HasAttributes()
```


### 반환 값

**true** 현재 노드에 속성이 있는 경우; **false** 현재 노드에 속성이 없거나 [XPathNavigator](../) 가 요소 노드에 위치하지 않은 경우 반환합니다.
