```cpp
virtual String System::Xml::XPath::XPathNavigator::get_NamespaceURI()=0
```

### 반환값

현재 노드의 네임스페이스 URI를 포함하는 [String](../../../system/string/)이며, 현재 노드에 네임스페이스 URI가 없을 경우 [String::Empty](../../../system/string/empty/)입니다.
