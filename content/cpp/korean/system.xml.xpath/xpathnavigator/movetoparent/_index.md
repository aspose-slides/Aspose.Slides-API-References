## XPathNavigator::MoveToParent() 메서드


파생 클래스에서 재정의될 때, [XPathNavigator](../)를 현재 노드의 상위 노드로 이동합니다.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::MoveToParent()=0
```


### 반환 값

**true** if the [XPathNavigator](../)이 현재 노드의 상위 노드로 성공적으로 이동했을 경우; 그렇지 않으면 **false**. **false**인 경우, [XPathNavigator](../)의 위치는 변경되지 않습니다.
