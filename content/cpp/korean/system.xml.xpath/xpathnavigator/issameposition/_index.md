## XPathNavigator::IsSamePosition(SharedPtr\<XPathNavigator\>) 메서드

파생 클래스에서 재정의될 경우, 현재 [XPathNavigator](../)가 지정된 [XPathNavigator](../)와 동일한 위치에 있는지 결정합니다.

```cpp
virtual bool System::Xml::XPath::XPathNavigator::IsSamePosition(SharedPtr<XPathNavigator> other)=0
```

### 매개변수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| other | [SharedPtr](../../../system/sharedptr/)\<[XPathNavigator](../)\> | 이 [XPathNavigator](../)와 비교할 [XPathNavigator](../). |

### 반환값

**true** 두 [XPathNavigator](../) 객체가 동일한 위치에 있는 경우; 그렇지 않으면 **false**.
