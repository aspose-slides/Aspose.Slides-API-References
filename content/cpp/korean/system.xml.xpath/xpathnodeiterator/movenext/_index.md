## XPathNodeIterator::MoveNext() 메서드

파생 클래스에서 재정의될 때, [XPathNavigator](../../xpathnavigator/) 개체를 [XPathNodeIterator::get_Current](../get_current/) 메서드가 반환한 것을 선택된 노드 집합의 다음 노드로 이동합니다.

```cpp
virtual bool System::Xml::XPath::XPathNodeIterator::MoveNext()=0
```

### 반환값

**true** [XPathNavigator](../../xpathnavigator/) 개체가 다음 노드로 이동한 경우; **false** 더 이상 선택된 노드가 없을 경우.
