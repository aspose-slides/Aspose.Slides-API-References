## X500DistinguishedNameFlags enum

X509 인증서 구분 이름 형식 규칙.

```cpp
enum class X500DistinguishedNameFlags
```

### 값

| Name | Value | Description |
| --- | --- | --- |
| None | 0 | 특별한 특성이 없습니다. |
| Reversed | 1 | 이름이 예약되었습니다. |
| UseSemicolons | 16 | 세미콜론을 사용합니다. |
| DoNotUsePlusSign | 32 | 이름에 플러스 기호를 사용하지 않습니다. |
| DoNotUseQuotes | 64 | 이름에서 따옴표를 비활성화합니다. |
| UseCommas | 128 | 쉼표 사용을 활성화합니다. |
| UseNewLines | 256 | 새 줄 사용을 활성화합니다. |
| UseUTF8Encoding | 4096 | Unicode 대신 UTF-8 인코딩을 사용하도록 전환합니다. |
| UseT61Encoding | 8192 | T61 인코딩으로 전환합니다. |
| ForceUTF8Encoding | 16384 | 특정 X500 키를 인코딩할 때 UTF-8 사용을 강제합니다. |
