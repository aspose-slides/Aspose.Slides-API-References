## X509NameType 열거형

인증서의 발행인 또는 소유자와 관련된 X.509 인증서에 포함된 이름 유형입니다.

```cpp
enum class X509NameType
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| SimpleName | 0 | 주체 또는 발행인의 단순 이름입니다. |
| EmailName | 1 | 이메일 주소입니다. |
| UpnName | 2 | UPN 이름입니다. |
| DnsName | 3 | DNS 이름입니다. |
| DnsFromAlternativeName | 4 | DNS 이름에 해당하는 대체 DNS 이름입니다. |
| UrlName | 5 | URL입니다. |
