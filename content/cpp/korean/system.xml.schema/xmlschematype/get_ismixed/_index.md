## XmlSchemaType::get_IsMixed() 메서드

이 형식에 혼합 콘텐츠 모델이 있는지 여부를 나타내는 값을 반환합니다. 이 호출은 복합 형식에서만 유효합니다.

```cpp
virtual bool System::Xml::Schema::XmlSchemaType::get_IsMixed()
```

### 반환 값

**true** 형식에 혼합 콘텐츠 모델이 있으면; 그렇지 않으면 **false**. 기본값은 **false**입니다.
