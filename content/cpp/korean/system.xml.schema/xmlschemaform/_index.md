## XmlSchemaForm 열거형

속성 또는 요소에 네임스페이스 접두사가 필요하도록 지정합니다.

```cpp
enum class XmlSchemaForm
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| None | 0 | 스키마에서 요소 및 속성 형식이 지정되지 않았습니다. |
| Qualified | 1 | 요소 및 속성은 네임스페이스 접두사로 지정되어야 합니다. |
| Unqualified | 2 | 요소 및 속성은 네임스페이스 접두사로 지정할 필요가 없습니다. |
