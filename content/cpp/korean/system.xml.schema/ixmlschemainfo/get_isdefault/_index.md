## IXmlSchemaInfo::get_IsDefault() 메서드


이 유효성 검사된 XML 노드가 XML [Schema](../../) 정의 언어 (XSD) 스키마 검증 중 기본값이 적용된 결과로 설정되었는지 여부를 나타내는 값을 반환합니다.

```cpp
virtual bool System::Xml::Schema::IXmlSchemaInfo::get_IsDefault()=0
```


### 반환 값

**true** 이 유효성 검사된 XML 노드가 스키마 검증 중 기본값이 적용된 결과로 설정된 경우; 그렇지 않으면 **false**.
