## XmlSchemaComplexType::get_BlockResolved() 메서드


타입이 사후 스키마 검증 정보 집합(infoset)으로 컴파일된 후의 값을 반환합니다. 이 값은 인스턴스 문서에서 **xsi:type**이 사용될 때 타입이 어떻게 적용되는지를 나타냅니다.

```cpp
XmlSchemaDerivationMethod System::Xml::Schema::XmlSchemaComplexType::get_BlockResolved()
```


### 반환 값

사후 스키마 검증된 infoset 값입니다. 기본값은 **schema** 요소의 **BlockDefault** 값입니다.
