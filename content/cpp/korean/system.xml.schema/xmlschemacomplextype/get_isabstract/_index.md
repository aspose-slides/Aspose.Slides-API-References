## XmlSchemaComplexType::get_IsAbstract() method


인스턴스 문서에서 **complexType** 요소를 사용할 수 있는지 결정하는 정보를 반환합니다.

```cpp
bool System::Xml::Schema::XmlSchemaComplexType::get_IsAbstract()
```


### 반환 값

**true**인 경우, 요소는 이 **complexType** 요소를 직접 사용할 수 없으며 이 **complexType** 요소에서 파생된 복합 유형을 사용해야 합니다. 기본값은 **false**입니다. 선택 사항.
