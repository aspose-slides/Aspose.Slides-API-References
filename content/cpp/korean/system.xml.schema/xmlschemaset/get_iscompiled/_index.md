## XmlSchemaSet::get_IsCompiled() 메서드

XML [Schema](../../) 정의 언어 (XSD) 스키마가 [XmlSchemaSet](../)에 컴파일되었는지 여부를 나타내는 값을 반환합니다.

```cpp
bool System::Xml::Schema::XmlSchemaSet::get_IsCompiled()
```

### 반환값

**true** 은 [XmlSchemaSet](../)의 스키마가 마지막으로 스키마가 [XmlSchemaSet](../)에 추가되거나 제거된 이후 컴파일된 경우이며, 그렇지 않으면 **false**.
