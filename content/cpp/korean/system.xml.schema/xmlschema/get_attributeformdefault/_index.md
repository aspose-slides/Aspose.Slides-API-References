## XmlSchema::get_AttributeFormDefault() 메서드


스키마의 대상 네임스페이스에 선언된 속성에 대한 형식을 반환합니다.

```cpp
XmlSchemaForm System::Xml::Schema::XmlSchema::get_AttributeFormDefault()
```


### 반환값

대상 네임스페이스의 속성이 네임스페이스 접두사로 지정되어야 하는지를 나타내는 XmlSchemaForm 값입니다. 기본값은 [XmlSchemaForm::None](../../xmlschemaform/)입니다.
