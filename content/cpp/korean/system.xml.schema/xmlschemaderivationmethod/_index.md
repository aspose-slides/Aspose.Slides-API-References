## XmlSchemaDerivationMethod 열거형

파생을 방지하기 위한 다양한 방법을 제공합니다.

```cpp
enum class XmlSchemaDerivationMethod
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Empty | 0 | 기본 파생 방법을 재정의하여 모든 파생을 허용합니다. |
| Substitution | 1 | 파생이 **Substitution**에 해당합니다. |
| Extension | 2 | 파생이 **Extension**에 해당합니다. |
| Restriction | 4 | 파생이 **Restriction**에 해당합니다. |
| List | 8 | 파생이 **List**에 해당합니다. |
| Union | 16 | 파생이 **Union**에 해당합니다. |
| All | 255 | **#all**. 모든 파생 방법을 의미합니다. |
| None | 256 | 기본 파생 방법을 사용합니다. |
