## XmlSchemaContentType 열거형

```cpp
enum class XmlSchemaContentType
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| TextOnly | 0 | 텍스트 전용 내용. |
| Empty | 1 | 빈 내용. |
| ElementOnly | 2 | 요소 전용 내용. |
| Mixed | 3 | 혼합 내용. |
