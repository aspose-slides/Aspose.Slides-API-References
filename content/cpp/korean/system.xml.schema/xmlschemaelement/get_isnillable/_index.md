## XmlSchemaElement::get_IsNillable() 메서드


인스턴스 데이터에서 **xsi:nil**이 발생할 수 있는지를 나타내는 정보를 반환합니다. 요소에 명시적인 nil 값을 할당할 수 있는지를 나타냅니다.

```cpp
bool System::Xml::Schema::XmlSchemaElement::get_IsNillable()
```


### 반환 값

`nillable`가 **true**이면 요소의 인스턴스에 **nil** 속성을 **true**로 설정할 수 있습니다. **nil** 속성은 인스턴스를 위한 XML [Schema](../../) 네임스페이스의 일부로 정의됩니다. 기본값은 **false**입니다. 선택 사항.
