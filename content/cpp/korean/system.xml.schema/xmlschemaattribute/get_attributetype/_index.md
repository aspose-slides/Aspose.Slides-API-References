## XmlSchemaAttribute::get_AttributeType() 메서드


속성의 **AttributeType** 값에 대한 사후 컴파일 해석을 보유하는 [XmlSchemaAttribute::get_SchemaType](../get_schematype/) 또는 [XmlSchemaAttribute::get_SchemaTypeName](../get_schematypename/) 값을 기반으로 객체를 반환합니다.

```cpp
SharedPtr<Object> System::Xml::Schema::XmlSchemaAttribute::get_AttributeType()
```


### 반환 값

**AttributeType** 값에 대한 사후 컴파일 해석을 보유하는 객체입니다.

사용 중단
:   대신 get_AttributeSchemaType 메서드를 사용하는 것이 권장됩니다.
