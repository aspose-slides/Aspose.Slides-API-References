## XmlSchemaValidity 열거형

XML 항목의 유효성을 나타내며, [XmlSchemaValidator](../xmlschemavalidator/) 클래스에 의해 검증됩니다.

```cpp
enum class XmlSchemaValidity
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| NotKnown | 0 | XML 항목의 유효성을 알 수 없습니다. |
| Valid | 1 | XML 항목이 유효합니다. |
| Invalid | 2 | XML 항목이 유효하지 않습니다. |
