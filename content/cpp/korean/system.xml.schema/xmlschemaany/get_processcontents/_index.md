```cpp
XmlSchemaContentProcessing System::Xml::Schema::XmlSchemaAny::get_ProcessContents()
```

### 반환 값

XmlSchemaContentProcessing 값 중 하나입니다. **processContents** 속성이 지정되지 않은 경우 기본값은 **Strict**입니다.
