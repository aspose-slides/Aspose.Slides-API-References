## ICUEncoder 클래스


[Encoder](../encoder/) ICU를 사용하여 인코딩합니다. 이 클래스의 객체는 [System::MakeObject()](../../system/makeobject/) 함수를 사용하여 할당해야 합니다. 이 유형의 인스턴스를 스택에 직접 생성하거나 operator new를 사용해서는 안 됩니다. 이렇게 하면 런타임 오류 및/또는 어설션 오류가 발생합니다. 항상 이 클래스를 [System::SmartPtr](../../system/smartptr/) 포인터로 감싸고, 해당 포인터를 함수 인자로 전달하십시오.

```cpp
class ICUEncoder : public System::Text::Encoder
```
