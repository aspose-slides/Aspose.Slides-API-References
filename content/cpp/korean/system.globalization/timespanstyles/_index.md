## TimeSpanStyles 열거형

시간 간격을 문자열 표현으로 변환하는 메서드의 문자열 구문 분석을 사용자 정의하는 형식 옵션을 지정합니다.

```cpp
enum class TimeSpanStyles : int32_t
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| None | 0 | inptut 문자열에 의해 표시된 시간 간격은 음수 기호가 있는 경우에만 음수 시간 간격으로 해석됩니다. |
| AssumeNegative | 1 | inptut 문자열에 의해 표시된 시간 간격은 항상 음수 시간 간격으로 해석됩니다. |
