## IdnMapping 클래스

[IdnMapping](./)는 이름을 Punycode로 매핑하는 데 사용됩니다. 이 클래스의 객체는 [System::MakeObject()](../../system/makeobject/) 함수로만 할당해야 합니다. 스택이나 operator new를 사용해 인스턴스를 생성하면 런타임 오류 및/또는 단언 오류가 발생합니다. 항상 이 클래스를 [System::SmartPtr](../../system/smartptr/) 포인터로 감싸고, 해당 포인터를 함수 인수로 전달하십시오.

```cpp
class IdnMapping : public System::Object
```
