## CultureTypes 열거형

Culture categories bitmask entries.

```cpp
enum class CultureTypes : int32_t
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| NeutralCultures | 1 | 언어에 특정하지만 국가 또는 지역에는 해당되지 않는 문화. |
| SpecificCultures | 2 | 국가/지역에 특화된 문화. |
| InstalledWin32Cultures | 4 | 운영 체제에 설치된 문화. |
| AllCultures | n/a | 모든 사용 가능한 문화. |
| UserCustomCulture | 8 | 사용자 정의 문화. |
| ReplacementCultures | 16 | 기존 문화에 대한 사용자 정의 교체. |
| WindowsOnlyCultures | 32 | 폐기됨. |
| FrameworkCultures | 64 | 폐기됨. |
