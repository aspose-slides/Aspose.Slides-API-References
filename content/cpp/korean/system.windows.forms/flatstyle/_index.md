## FlatStyle 열거형


컨트롤이 평면으로 그려지는지 또는 3차원으로 그려지는지를 정의합니다.

```cpp
enum class FlatStyle
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Flat | 0 | [Control](../control/) 가 평면으로 그려집니다. |
| Popup | 1 | [Control](../control/) 은 평면으로 그려지지만, 마우스가 위에 올려질 때는 3D처럼 그려집니다. |
| Standard | 2 | [Control](../control/) 은 3D처럼 그려집니다. |
| System | 3 | 스타일은 OS에 의해 제어됩니다. |
