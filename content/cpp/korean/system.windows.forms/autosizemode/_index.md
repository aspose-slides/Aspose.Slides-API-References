## AutoSizeMode 열거형


자동 크기 조정이 작동하는 방식을 정의합니다.

```cpp
enum class AutoSizeMode
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| GrowAndShrink | 0 | [Control](../control/) 필요에 따라 늘어나고 줄어듭니다. 수동으로 크기를 조정할 수 없습니다. |
| GrowOnly | 1 | [Control](../control/) 필요에 따라 늘어나지만 최소 크기 이하로 줄어들 수 없습니다. 수동으로 크기를 조정할 수 있습니다. |
