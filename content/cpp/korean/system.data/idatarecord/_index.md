## IDataRecord 클래스

열이 있는 레코드에 대한 인터페이스. 이 클래스의 객체는 [System::MakeObject()](../../system/makeobject/) 함수를 사용하여 할당해야 합니다. 스택에 직접 생성하거나 new 연산자를 사용해 인스턴스를 만들면 런타임 오류 및/또는 어설션 오류가 발생합니다. 항상 이 클래스를 [System::SmartPtr](../../system/smartptr/) 포인터에 래핑하고 해당 포인터를 인수로 함수에 전달하십시오.

```cpp
class IDataRecord : public virtual System::Object
```
