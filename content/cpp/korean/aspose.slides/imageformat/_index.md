## ImageFormat 열거형

이미지의 파일 형식을 나타냅니다.

```cpp
enum class ImageFormat
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| MemoryBmp | 0 | 메모리 내 비트맵 형식을 나타냅니다. |
| Bmp | 1 | 비트맵 (BMP) 이미지 형식을 나타냅니다. |
| Emf | 2 | 향상된 메타파일 (EMF) 이미지 형식을 나타냅니다. |
| Wmf | 3 | Windows 메타파일 (WMF) 이미지 형식을 나타냅니다. |
| Gif | 4 | 그래픽 교환 형식 (GIF) 이미지 형식을 나타냅니다. |
| Jpeg | 5 | 공동 사진 전문가 그룹 (JPEG) 이미지 형식을 나타냅니다. |
| Png | 6 | W3C 포터블 네트워크 그래픽스 (PNG) 이미지 형식을 나타냅니다. |
| Tiff | 7 | 태그된 이미지 파일 형식 (TIFF) 이미지 형식을 나타냅니다. |
| Exif | 8 | 교환 가능한 이미지 파일 (Exif) 형식을 나타냅니다. |
| Icon | 9 | Windows 아이콘 이미지 형식을 나타냅니다. |
