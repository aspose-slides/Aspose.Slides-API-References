## MasterSlideHeaderFooterManager::SetDateTimeAndChildDateTimesVisibility(bool) 메서드


마스터 슬라이드 날짜-시간 자리표시자의 가시성과 모든 하위 날짜-시간 자리표시자의 가시성을 변경합니다. 하위 자리표시자는 종속 레이아웃 슬라이드 및 종속 슬라이드에 포함된 자리표시자를 의미합니다. 종속 레이아웃 슬라이드와 슬라이드는 마스터 슬라이드를 사용하고 의존합니다.

```cpp
void Aspose::Slides::MasterSlideHeaderFooterManager::SetDateTimeAndChildDateTimesVisibility(bool isVisible) override
```


### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| isVisible | **bool** | true - 날짜-시간 자리표시자를 표시하고, 그렇지 않으면 숨깁니다. |
