## MasterSlideHeaderFooterManager::SetFooterAndChildFootersVisibility(bool) 메서드

마스터 슬라이드 푸터 자리 표시자와 모든 자식 푸터 자리 표시자의 가시성을 변경합니다. 자식 자리 표시자는 종속 레이아웃 슬라이드와 종속 슬라이드에 포함된 자리 표시자를 의미합니다. 종속 레이아웃 슬라이드와 슬라이드는 마스터 슬라이드에 의존하고 사용됩니다.

```cpp
void Aspose::Slides::MasterSlideHeaderFooterManager::SetFooterAndChildFootersVisibility(bool isVisible) override
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| isVisible | **bool** | true - 푸터 자리 표시자를 보이게 하며, false - 숨깁니다. |
