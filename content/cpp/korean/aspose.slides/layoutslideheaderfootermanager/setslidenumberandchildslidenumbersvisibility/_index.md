## LayoutSlideHeaderFooterManager::SetSlideNumberAndChildSlideNumbersVisibility(bool) 메서드

레이아웃 슬라이드 페이지 번호 자리 표시자와 모든 하위 페이지 번호 자리 표시자의 가시성을 변경합니다. 하위 자리 표시자는 종속 슬라이드에 포함된 자리 표시자를 의미합니다. 종속 슬라이드는 레이아웃 슬라이드를 사용하고 의존합니다.

```cpp
void Aspose::Slides::LayoutSlideHeaderFooterManager::SetSlideNumberAndChildSlideNumbersVisibility(bool isVisible) override
```

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| isVisible | **bool** | true - 페이지 번호 자리 표시자를 표시하고, 그렇지 않으면 숨깁니다. |
