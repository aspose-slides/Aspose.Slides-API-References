## Shape::get_Rotation() 메서드

지정된 도형이 z축을 중심으로 회전한 각도를 도 단위로 반환합니다. 양수 값은 시계 방향 회전을 나타내고, 음수 값은 반시계 방향 회전을 나타냅니다. 읽기 전용 **float**.

```cpp
float Aspose::Slides::Shape::get_Rotation() override
```

## 비고

반환값은 항상 정의되어 있습니다 (std::numeric_limits<float>::quiet_NaN()이 아닙니다). 할당된 값도 정의되어 있어야 합니다 (std::numeric_limits<float>::quiet_NaN()이 아님). RawFrame 인스턴스 속성에 대해 정의되지 않은 값을 설정할 수 있습니다.
