## Shape::set_Rotation(float) 메서드

지정된 도형이 z축을 중심으로 회전하는 각도를 도(degree) 단위로 설정합니다. 양수 값은 시계 방향 회전을 의미하고, 음수 값은 반시계 방향 회전을 의미합니다. **float** 형식으로 씁니다.

```cpp
void Aspose::Slides::Shape::set_Rotation(float value) override
```

## 비고

반환 값은 항상 정의되어 있습니다( std::numeric_limits<float>::quiet_NaN() 가 아닙니다). 할당된 값도 정의되어 있어야 합니다( std::numeric_limits<float>::quiet_NaN() 가 아닙니다). RawFrame 인스턴스 속성에 대해 정의되지 않은 값을 설정할 수 있습니다.
