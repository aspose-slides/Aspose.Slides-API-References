## Shape::set_Frame(System::SharedPtr\<IShapeFrame\>) 메서드

도형 프레임의 속성을 설정합니다. [IShapeFrame](../../ishapeframe/)를 씁니다.

```cpp
void Aspose::Slides::Shape::set_Frame(System::SharedPtr<IShapeFrame> value) override
```

## 비고

반환된 [IShapeFrame](../../ishapeframe/) 인스턴스의 각 속성 값은 undefined가 아닙니다 (NaN 또는 NotDefined가 아님). 할당된 [IShapeFrame](../../ishapeframe/) 인스턴스의 각 속성 값은 undefined가 아니어야 합니다 (NaN 또는 NotDefined가 아니어야 합니다). RawFrame 인스턴스의 속성에 undefined 값을 설정할 수 있습니다.
