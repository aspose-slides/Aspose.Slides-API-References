## DocumentProperties::set_ScaleCrop(bool) 메서드

문서 썸네일의 표시 모드를 나타냅니다. 이 요소를 **true** 로 설정하면 문서 썸네일을 디스플레이에 맞게 확대하도록 합니다. 이 요소를 **false** 로 설정하면 디스플레이에 맞는 섹션만 표시하도록 문서 썸네일을 잘라냅니다. 값은 **bool** 형식입니다.

```cpp
void Aspose::Slides::DocumentProperties::set_ScaleCrop(bool value) override
```
