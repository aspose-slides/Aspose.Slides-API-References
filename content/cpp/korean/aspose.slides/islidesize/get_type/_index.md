## ISlideSize::get_Type() 메서드


슬라이드 크기 유형을 가져옵니다. [SlideSizeType::Custom](../../slidesizetype/)를 제외한 모든 값을 할당하면 사전 정의된 치수에 따라 [ISlideSize::get_Size](../get_size/)가 조정되며, 현재 [ISlideSize::get_Orientation](../get_orientation/)는 유지됩니다.

```cpp
virtual SlideSizeType Aspose::Slides::ISlideSize::get_Type()=0
```

## 비고


[SlideSizeType::Custom](../../slidesizetype/)를 제외한 모든 값을 할당하면 사전 정의된 치수에 따라 [System::Drawing::Size](../../../system.drawing/size/)가 조정되고, 현재 [Orientation](../../orientation/)는 유지됩니다.
