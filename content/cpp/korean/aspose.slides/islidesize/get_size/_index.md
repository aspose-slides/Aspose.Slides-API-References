## ISlideSize::get_Size() 메서드


슬라이드 차원을 포인트 단위로 가져옵니다. 새 값을 할당하면 [ISlideSize::get_Type](../get_type/) 값을 [SlideSizeType::Custom](../../slidesizetype/)(으)로 재설정하고 [ISlideSize::get_Orientation](../get_orientation/)을 설정합니다.

```cpp
virtual System::Drawing::SizeF Aspose::Slides::ISlideSize::get_Size()=0
```

## 비고


새 값을 할당하면 [ISlideSize::get_Type](../get_type/) 속성을 [SlideSizeType::Custom](../../slidesizetype/)(으)로 재설정하고 [Orientation](../../orientation/)을 설정합니다.
