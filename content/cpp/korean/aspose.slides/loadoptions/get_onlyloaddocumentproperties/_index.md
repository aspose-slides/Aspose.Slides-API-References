## LoadOptions::get_OnlyLoadDocumentProperties() 메서드


이 속성은 프레젠테이션 파일이 비밀번호로 보호된 경우에 의미가 있습니다. true 값은 암호화된 프레젠테이션 파일에서 문서 속성만 로드하고 비밀번호는 무시해야 함을 의미합니다. false 값은 올바른 비밀번호를 사용하여 전체 암호화된 프레젠테이션을 로드해야 함을 의미합니다. 프레젠테이션이 암호화되지 않은 경우 속성 값은 항상 무시됩니다. 암호화된 파일의 문서 속성이 공개되지 않았고 속성 값이 true인 경우 문서 속성을 로드할 수 없으며 예외가 발생합니다. 읽기 **bool**.

```cpp
bool Aspose::Slides::LoadOptions::get_OnlyLoadDocumentProperties() override
```
