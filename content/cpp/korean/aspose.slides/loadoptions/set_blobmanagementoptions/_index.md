## LoadOptions::set_BlobManagementOptions(System::SharedPtr\<IBlobManagementOptions\>) 메서드

Binary Large Objects (BLOBs)의 처리 동작을 관리하기 위해 사용할 수 있는 옵션을 나타냅니다. 예를 들어 임시 파일을 사용하거나 메모리 내 최대 BLOB 바이트 수 등을 포함합니다. 이러한 옵션은 특정 환경이나 요구 사항에 대해 최고의 성능/메모리 사용 비율을 설정하도록 설계되었습니다.

```cpp
void Aspose::Slides::LoadOptions::set_BlobManagementOptions(System::SharedPtr<IBlobManagementOptions> value) override
```

## 비고

Binary Large Object (BLOB)는 단일 엔터티로 저장되는 바이너리 데이터이며, 오디오, 비디오 또는 프레젠테이션 자체가 될 수 있습니다.
