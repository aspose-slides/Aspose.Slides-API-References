## LoadOptions::get_BlobManagementOptions() 메서드

Binary Large Objects (BLOBs) 처리 동작을 관리하는 옵션을 나타냅니다. 예를 들어 임시 파일 사용이나 메모리 내 최대 BLOB 바이트 수와 같은 옵션을 설정할 수 있습니다. 이러한 옵션은 특정 환경이나 요구 사항에 대해 최상의 성능/메모리 사용 비율을 설정하기 위해 설계되었습니다.

```cpp
System::SharedPtr<IBlobManagementOptions> Aspose::Slides::LoadOptions::get_BlobManagementOptions() override
```

## 비고

Binary Large Object (BLOB)은 단일 엔터티로 저장되는 바이너리 데이터이며, 예를 들어 오디오, 비디오 또는 프레젠테이션 자체가 될 수 있습니다.
