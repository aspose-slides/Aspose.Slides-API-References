## IDrawingGuide::set_Position(float) 메서드


드로잉 가이드의 위치를 슬라이드의 왼쪽 위 모서리에서부터 포인트 단위로 설정합니다. **float**를 입력합니다.

```cpp
virtual void Aspose::Slides::IDrawingGuide::set_Position(float value)=0
```

## 비고


일반적인 값 범위는 수평 가이드의 경우 0부터 슬라이드 높이까지이며, 수직 가이드의 경우 0부터 슬라이드 너비까지입니다.
