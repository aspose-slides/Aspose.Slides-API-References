## PVICachingMode 열거형

PVI 효과적인 객체에 대한 다양한 캐싱 수준을 나타냅니다.

```cpp
enum class PVICachingMode
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| NoCaching | 0 | 모든 인스턴스를 생성하는 클래식 모드. |
| NotDefinedOnly | 1 | NotDefined 형식에 대해 효율적인 값 캐싱을 사용하고, 나머지는 클래식 모드 사용. |
| Full | 2 | 모든 형식에 대해 효율적인 값 캐싱을 사용. |
