## IHyperlink::get_ExternalUrlOriginal() 메서드

Represents a hyperlink that is set for this portion without regard to the actual content of the portion.

```cpp
virtual System::String Aspose::Slides::IHyperlink::get_ExternalUrlOriginal()=0
```

## 비고

PowerPoint는 구간 내의 링크와 해당 텍스트에 대해 특별히 동작합니다. 실제 링크 주소와 다른 유효한 URL 형태로 하이퍼링크 텍스트를 생성할 수 있습니다. 이 경우, 편집 창에서 링크를 볼 때 텍스트 구간에 맞게 변경됩니다. 이 속성은 하이퍼링크의 원래 값을 나타냅니다.
