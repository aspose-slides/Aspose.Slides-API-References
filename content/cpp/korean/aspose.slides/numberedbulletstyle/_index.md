## NumberedBulletStyle 열거형

번호 매겨진 글머리표의 스타일을 나타냅니다.

```cpp
enum class NumberedBulletStyle : int8_t
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| NotDefined | -1 | 정의되지 않음. |
| BulletAlphaLCPeriod | 0 | 소문자 알파벳 문자와 마침표가 있습니다. 예: a., b., c., ... |
| BulletAlphaUCPeriod | 1 | 대문자 알파벳 문자와 마침표가 있습니다. 예: A., B., C., ... |
| BulletArabicParenRight | 2 | 닫는 괄호가 있는 아라비아 숫자입니다. 예: 1), 2), 3), ... |
| BulletArabicPeriod | 3 | 마침표가 있는 아라비아 숫자입니다. 예: 1., 2., 3., ... |
| BulletRomanLCParenBoth | 4 | 양쪽 괄호가 있는 소문자 로마 숫자입니다. 예: (i), (ii), (iii), ... |
| BulletRomanLCParenRight | 5 | 닫는 괄호가 있는 소문자 로마 숫자입니다. 예: i), ii), iii), ... |
| BulletRomanLCPeriod | 6 | 마침표가 있는 소문자 로마 숫자입니다. 예: i., ii., iii., ... |
| BulletRomanUCPeriod | 7 | 마침표가 있는 대문자 로마 숫자입니다. 예: I., II., III., ... |
| BulletAlphaLCParenBoth | 8 | 양쪽 괄호가 있는 소문자 알파벳 문자입니다. 예: (a), (b), (c), ... |
| BulletAlphaLCParenRight | 9 | 닫는 괄호가 있는 소문자 알파벳 문자입니다. 예: a), b), c), ... |
| BulletAlphaUCParenBoth | 10 | 양쪽 괄호가 있는 대문자 알파벳 문자입니다. 예: (A), (B), (C), ... |
| BulletAlphaUCParenRight | 11 | 닫는 괄호가 있는 대문자 알파벳 문자입니다. 예: A), B), C), ... |
| BulletArabicParenBoth | 12 | 양쪽 괄호가 있는 아라비아 숫자입니다. 예: (1), (2), (3), ... |
| BulletArabicPlain | 13 | 아라비아 숫자입니다. 예: 1, 2, 3, ... |
| BulletRomanUCParenBoth | 14 | 양쪽 괄호가 있는 대문자 로마 숫자입니다. 예: (I), (II), (III), ... |
| BulletRomanUCParenRight | 15 | 닫는 괄호가 있는 대문자 로마 숫자입니다. 예: I), II), III), ... |
| BulletSimpChinPlain | 16 | 마침표가 없는 간체 중국어. |
| BulletSimpChinPeriod | 17 | 마침표가 있는 간체 중국어. |
| BulletCircleNumDBPlain | 18 | 10까지는 이중 바이트 원형 번호이며, 11부터는 아라비아 숫자입니다. |
| BulletCircleNumWDWhitePlain | 19 | 텍스트와 같은 색상의 원이 그려진 숫자 (Wingdings 흰색 원 번호). 11부터는 아라비아 숫자입니다. |
| BulletCircleNumWDBlackPlain | 20 | 일반 텍스트 색상의 원형 배경을 가진 그림자 색상 번호 (Wingdings 검은 원 번호). |
| BulletTradChinPlain | 21 | 마침표가 없는 전통 중국어. |
| BulletTradChinPeriod | 22 | 마침표가 있는 전통 중국어. |
| BulletArabicAlphaDash | 23 | 아라비아어 알파벳 문자와 대시가 있습니다. |
| BulletArabicAbjadDash | 24 | 아라비아어 아프자드 알파벳과 대시가 있습니다. |
| BulletHebrewAlphaDash | 25 | 히브리어 알파벳 문자와 대시가 있습니다. |
| BulletKanjiKoreanPlain | 26 | 일본어/한국어 숫자이며 마침표가 없습니다. |
| BulletKanjiKoreanPeriod | 27 | 일본어/한국어 숫자이며 마침표가 있습니다. |
| BulletArabicDBPlain | 28 | 이중 바이트 아라비아 번호 체계 (구두점 없음). |
| BulletArabicDBPeriod | 29 | 이중 바이트 아라비아 번호 체계이며 이중 바이트 마침표가 있습니다. |
| BulletThaiAlphaPeriod | 30 | 태국 알파벳 마침표. |
| BulletThaiAlphaParenRight | 31 | 태국 알파벳 괄호 - 오른쪽. |
| BulletThaiAlphaParenBoth | 32 | 태국 알파벳 괄호 - 모두. |
| BulletThaiNumPeriod | 33 | 태국 숫자 마침표. |
| BulletThaiNumParenRight | 34 | 태국 숫자 괄호 - 오른쪽. |
| BulletThaiNumParenBoth | 35 | 태국 숫자 괄호 - 모두. |
| BulletHindiAlphaPeriod | 36 | 힌두어 알파벳 마침표 - 모음. |
| BulletHindiNumPeriod | 37 | 힌두어 숫자 마침표. |
| BulletKanjiSimpChinDBPeriod | 38 | 간체 중국어 DBPeriod 한자. |
| BulletHindiNumParenRight | 39 | 힌두어 숫자 괄호 - 오른쪽. |
| BulletHindiAlpha1Period | 40 | 힌두어 알파벳 마침표 - 자음. |
