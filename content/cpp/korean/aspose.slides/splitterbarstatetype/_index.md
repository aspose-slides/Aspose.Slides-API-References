## SplitterBarStateType enum

스플리터 바가 표시되어야 하는 상태를 지정합니다. 스플리터 바는 보기 영역 내에서 기본 영역과 보조 영역을 구분합니다.

```cpp
enum class SplitterBarStateType
```

### Values

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Minimized | 0 | 기본 영역이 애플리케이션이 허용하는 보기 영역 중 가장 적은 양을 차지합니다. |
| Restored | 1 | 기본 영역이 특정 중간 크기를 가집니다. |
| Maximized | 2 | 기본 영역이 애플리케이션이 허용하는 보기 영역 중 가장 큰 양을 차지합니다. |
