## IProtectionManager::set_EncryptDocumentProperties(bool) 메서드

프레젠테이션이 암호로 보호된 경우에만 이 속성이 의미가 있습니다.  
true인 경우, 문서 속성이 프레젠테이션 파일에 암호화됩니다.  
false인 경우, 프레젠테이션은 암호화된 상태이지만 문서 속성은 공개됩니다.  
**bool** 형식으로 작성합니다.

```cpp
virtual void Aspose::Slides::IProtectionManager::set_EncryptDocumentProperties(bool value)=0
```
