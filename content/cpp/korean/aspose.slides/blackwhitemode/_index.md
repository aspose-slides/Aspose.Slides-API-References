## BlackWhiteMode 열거형

색상이 있는 도형이 흑백으로 변환되는 방식을 결정합니다.

```cpp
enum class BlackWhiteMode : int8_t
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| NotDefined | -1 | 속성이 설정되지 않았습니다 |
| Color | 0 | 객체가 일반 색상으로 렌더링됩니다 |
| Automatic | 1 | 객체가 자동 색상으로 렌더링됩니다 |
| Gray | 2 | 객체가 회색으로 렌더링됩니다 |
| LightGray | 3 | 객체가 밝은 회색으로 렌더링됩니다 |
| InverseGray | 4 | 객체가 역회색으로 렌더링됩니다 |
| GrayWhite | 5 | 객체가 회색 및 흰색으로 렌더링됩니다 |
| BlackGray | 6 | 객체가 검은색 및 회색으로 렌더링됩니다 |
| BlackWhite | 7 | 객체가 검은색 및 흰색으로 렌더링됩니다 |
| Black | 8 | 객체가 검은색만으로 렌더링됩니다 |
| White | 9 | 객체가 흰색으로 렌더링됩니다 |
| Hidden | 10 | 객체가 렌더링되지 않습니다 |
