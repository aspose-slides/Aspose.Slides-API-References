## PersistenceType 열거형

ActiveX control의 속성을 저장하는 데 사용되는 방법을 지정합니다.

```cpp
enum class PersistenceType
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| NotDefined | -1 | Persistance id가 지정되지 않았습니다. |
| PersistPropertyBag | 0 | ActiveX control이 속성 가방 기반 지속성을 사용하여 지속된다고 지정합니다. 속성 가방 기반 지속성은 이름과 값 쌍의 컬렉션을 통해 ActiveX control이 지속하는 데이터를 지정합니다. |
| PersistStream | 1 | ActiveX control이 스트림 기반 지속성을 사용하여 지속된다고 지정합니다. 이 지속성은 ActiveX control을 기본 상태로 초기화하는 것을 지원하지 않습니다. |
| PersistStreamInit | 2 | ActiveX control이 스트림 기반 지속성을 사용하여 지속된다고 지정합니다. 이 지속성은 ActiveX control을 기본 상태로 초기화하는 것을 지원합니다. |
| PersistStorage | 3 | ActiveX control이 스토리지 기반 지속성을 사용하여 지속된다고 지정합니다. |
