## SensitivityLabelAssignmentType 열거형

민감도 레이블에 대한 할당 방법을 나타냅니다.

```cpp
enum class SensitivityLabelAssignmentType
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Standard | 0 | 사용자가 직접 적용하지 않은 모든 민감도 레이블에 사용합니다. 여기에는 기본 레이블 및 자동으로 적용된 레이블이 포함됩니다. |
| Privileged | 1 | 사용자가 직접 적용한 모든 민감도 레이블에 사용합니다. 여기에는 수동으로 적용된 민감도 레이블과 권장 또는 필수 라벨링, 사용자가 적용할 민감도 레이블을 선택하는 모든 기능이 포함됩니다. |
