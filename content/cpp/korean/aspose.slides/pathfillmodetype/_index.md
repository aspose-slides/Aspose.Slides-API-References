## PathFillModeType 열거형

경로를 채워야 하는 방식을 지정합니다.

```cpp
enum class PathFillModeType : uint8_t
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| None | 0 | No Path Fill은 해당 경로에 채우기가 없음을 지정합니다. |
| Normal | 1 | Normal Path Fill은 해당 경로에 일반적으로 음영 처리된 색상이 채우기에 적용됨을 지정합니다. |
| Lighten | 2 | Lighten Path Fill은 해당 경로에 가볍게 음영 처리된 색상이 채우기에 적용됨을 지정합니다. |
| LightenLess | 3 | Lighten Path Fill Less는 해당 경로에 약간 더 밝은 음영 색상이 채우기에 적용됨을 지정합니다. |
| Darken | 4 | Darken Path Fill은 해당 경로에 더 어두운 음영 색상이 채우기에 적용됨을 지정합니다. |
| DarkenLess | 5 | Darken Path Fill Less는 해당 경로에 약간 더 어두운 음영 색상이 채우기에 적용됨을 지정합니다. |
