## ISlideShowTransition::set_Duration(int32_t) 메서드

슬라이드 전환 효과의 지속 시간을 밀리초 단위로 설정합니다. **int32_t** 을 씁니다.

```cpp
virtual void Aspose::Slides::ISlideShowTransition::set_Duration(int32_t value)=0
```

## 참고

PresentationML 스키마의 **p:transition** 요소에 있는 **p14:dur** 속성에 해당합니다. 설정하지 않으면, 지속 시간은 [Speed](../) 속성과 전환 유형에 따라 자동으로 결정됩니다.
