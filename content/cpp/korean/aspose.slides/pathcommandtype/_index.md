## PathCommandType 열거형

그래픽 경로 명령을 나타냅니다

```cpp
enum class PathCommandType : uint8_t
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Close | 0 | 기하학 경로를 닫습니다 |
| MoveTo | 1 | 기하학 경로의 다음 점 위치를 설정합니다 |
| LineTo | 2 | 기하학 경로에 선을 추가합니다 |
| ArcTo | 3 | 지정된 호를 기하학 경로에 추가합니다. |
| QuadBezierTo | 4 | 기하학 경로에 2차 베지어 곡선을 추가합니다 |
| CubicBezierTo | 5 | 기하학 경로에 3차 베지어 곡선을 추가합니다 |
