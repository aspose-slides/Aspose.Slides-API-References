## IDocumentProperties::set_LastSavedTime(System::DateTime) 메서드

프레젠테이션이 마지막으로 수정된 날짜를 반환합니다. 값은 UTC.P에 있습니다. Presentation.DocumentProperties의 경우 읽기 전용입니다([IPresentation](../../ipresentation/) 객체 저장 과정 중 내부적으로 업데이트되기 때문). [DocumentProperties](../../documentproperties/) 인스턴스를 통해 [IPresentationInfo::ReadDocumentProperties](../../ipresentationinfo/readdocumentproperties/) 메서드가 반환하는 값으로 변경할 수 있습니다. 자세한 예제는 [IPresentationInfo::UpdateDocumentProperties](../../ipresentationinfo/updatedocumentproperties/) 메서드 요약을 참조하십시오.

virtual void Aspose::Slides::IDocumentProperties::set_LastSavedTime(System::DateTime value)=0
