## IDocumentProperties::set_ScaleCrop(bool) 메서드

문서 썸네일의 표시 모드를 나타냅니다. 이 요소를 **true** 로 설정하면 문서 썸네일을 디스플레이에 맞게 확대합니다. 이 요소를 **false** 로 설정하면 디스플레이에 맞는 섹션만 표시하도록 문서 썸네일을 잘라냅니다. **bool** 형식으로 작성합니다.

```cpp
virtual void Aspose::Slides::IDocumentProperties::set_ScaleCrop(bool value)=0
```
