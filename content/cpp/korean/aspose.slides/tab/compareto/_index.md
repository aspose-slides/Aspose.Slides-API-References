## Tab::CompareTo(System::SharedPtr\<ITab\>) 메서드

현재 인스턴스를 동일한 유형의 다른 객체와 비교합니다.

```cpp
int32_t Aspose::Slides::Tab::CompareTo(System::SharedPtr<ITab> obj) override
```

### 인수

| 매개변수 | 유형 | 설명 |
| --- | --- | --- |
| obj | [System::SharedPtr](../../../system/sharedptr/)\<[ITab](../../itab/)\> | 이 인스턴스와 비교할 객체입니다. |

## 반환값

비교 대상들의 상대 순서를 나타내는 32비트 정수입니다. 반환값은 다음과 같은 의미를 가집니다:
* < 0 - 이 인스턴스는 obj보다 작습니다.
* = 0 - 이 인스턴스는 obj와 같습니다.
* > 0 - 이 인스턴스는 obj보다 큽니다.
