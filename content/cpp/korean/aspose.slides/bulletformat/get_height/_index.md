## BulletFormat::get_Height() 메서드


상속이 없는 문단의 글머리 기호 높이를 반환합니다. 값 std::numeric_limits<float>::quiet_NaN() 은(는) 글머리 기호가 문단의 첫 번째 부분에서 높이를 상속함을 나타냅니다. 읽기 **float**.

```cpp
float Aspose::Slides::BulletFormat::get_Height() override
```

## 비고


음수 높이 값은 높이가 포인트 단위로 지정된다는 의미이며, 양수 값은 높이가 주변 텍스트의 비율임을 의미합니다.
