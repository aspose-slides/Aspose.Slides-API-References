## ILoadOptions::get_BlobManagementOptions() 메서드

Binary Large Objects (BLOBs) 관리 동작을 설정하는 옵션을 나타냅니다. 예를 들어 임시 파일 사용이나 메모리 내 최대 BLOBs 바이트 수와 같은 옵션이 포함됩니다. 이러한 옵션은 특정 환경이나 요구 사항에 대해 최상의 성능/메모리 소비 비율을 설정하도록 설계되었습니다.

```cpp
virtual System::SharedPtr<IBlobManagementOptions> Aspose::Slides::ILoadOptions::get_BlobManagementOptions()=0
```

## 비고

BLOB(Binary Large Object)은 단일 엔터티로 저장되는 바이너리 데이터이며, 즉 BLOB은 오디오, 비디오 또는 프레젠테이션 자체가 될 수 있습니다.
