## ILoadOptions::set_OnlyLoadDocumentProperties(bool) 메서드

이 속성은 프레젠테이션 파일이 비밀번호로 보호된 경우에 의미가 있습니다. true 값을 지정하면 암호화된 프레젠테이션 파일에서 문서 속성만 로드되고 비밀번호는 무시됩니다. false 값을 지정하면 올바른 비밀번호를 사용하여 전체 암호화된 프레젠테이션을 로드합니다. 프레젠테이션이 암호화되지 않은 경우에는 속성 값이 항상 무시됩니다. 암호화된 파일의 문서 속성이 공개되지 않았고 속성 값이 true인 경우 문서 속성을 로드할 수 없으며 예외가 발생합니다. **bool**을 기록합니다.

```cpp
virtual void Aspose::Slides::ILoadOptions::set_OnlyLoadDocumentProperties(bool value)=0
```
