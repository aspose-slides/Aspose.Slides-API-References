## LineSketchType enum

형상이 할당된 스케치 유형 또는 효과를 나타냅니다.

```cpp
enum class LineSketchType
```

### Values

| 이름 | 값 | 설명 |
| --- | --- | --- |
| NotDefined | -1 | 형상의 스케치 효과가 정의되지 않았음을 지정합니다. |
| None | 0 | 형상에 스케치 효과가 없음을 지정합니다. 이는 해당 속성이 비어 있는 것과 동일합니다. |
| Curved | 1 | 형상에 Curved 효과가 적용되어 형상의 각 가장자리가 하나의 부드러운 곡선으로 변환됩니다. |
| Freehand | 2 | 형상에 Freehand 효과가 적용되어 가장 가까이 불완전하게 그린 선과 유사합니다. |
| Scribble | 3 | 형상에 Scribble 효과가 적용되어 마치 의도적으로 지저분하게 그린 듯 과장된 진동을 나타냅니다. |
