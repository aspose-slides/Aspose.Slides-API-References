## IShape::get_Y() 메서드

Gets the y-coordinate of the shape's upper-left corner, measured in points. Read **float**.

```cpp
virtual float Aspose::Slides::IShape::get_Y()=0
```

## 비고

반환된 값은 항상 정의되어 있으며 [std::numeric_limits<float>::quiet_NaN()](../)가 아닙니다. 할당되는 값도 정의되어 있어야 하며, **RawFrame** 인스턴스의 속성에만 [std::numeric_limits<float>::quiet_NaN()](../)를 할당하십시오.
