## FillType 열거형

다양한 시각 객체의 내부 채우기 유형을 지정합니다.

```cpp
enum class FillType : int8_t
```

### Values

| 이름 | 값 | 설명 |
| --- | --- | --- |
| NotDefined | -1 | 채우기 유형이 정의되지 않았습니다. |
| NoFill | 0 | 채우기가 적용되지 않습니다. |
| Solid | 1 | 단색으로 채워집니다. |
| Gradient | 2 | 채우기가 그라데이션입니다. |
| Pattern | 3 | 반복 패턴을 사용하여 객체를 채웁니다. |
| Picture | 4 | 단일 그림을 사용하여 객체를 채웁니다. |
| Group | 5 | 시각적 객체가 그룹으로부터 채우기 속성을 상속합니다. |
