## EnumeratorCastAdapter::MoveNext() 메서드

열거자를 다음 요소로 이동합니다. 이전에 참조된 요소가 없으면, 사용 가능한 첫 번째 요소에 대한 참조를 설정합니다. 컨테이너 끝에 도달하면 아무 것도 수행하지 않습니다.

```cpp
bool System::Collections::Generic::Details::EnumeratorCastAdapter<Source, Result>::MoveNext() override
```

### 반환 값

호출 후 사용할 수 있는 요소가 있으면 true, 그렇지 않으면 false.
