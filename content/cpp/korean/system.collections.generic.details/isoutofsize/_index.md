## System::Collections::Generic::Details::IsOutOfSize(int, const Container\&) 함수

인덱스가 컨테이너 범위를 벗어났는지 확인합니다. 컨테이너 크기도 포함합니다.

```cpp
template<typename Container> bool System::Collections::Generic::Details::IsOutOfSize(int count, const Container &container)
```

### 템플릿 매개변수

| 매개변수 | 설명 |
| --- | --- |
| Container | 컨테이너 유형. |

### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| count | int | [Index](../../system/index/). |
| container | const Container\& | 인덱스를 확인할 컨테이너. |

### 반환 값

인덱스가 컨테이너 범위를 벗어나면 true, 아니면 false.
