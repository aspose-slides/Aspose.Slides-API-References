## Component 클래스

Dummy 클래스는 [Component](./) 클래스를 사용한 번역된 코드를 컴파일 가능하게 만들기 위한 것입니다. 이 클래스의 객체는 [System::MakeObject()](../../system/makeobject/) 함수를 사용하여만 할당해야 합니다. 스택에 인스턴스를 생성하거나 new 연산자를 사용하면 런타임 오류 및/또는 어설션 오류가 발생합니다. 항상 이 클래스를 [System::SmartPtr](../../system/smartptr/) 포인터로 감싸고 이 포인터를 함수 인자로 전달하세요.

```cpp
class Component : public System::MarshalByRefObject,
                  public System::ComponentModel::IComponent
```
