## HttpCompletionOption 열거형

다음 시점에 [HttpClient](../httpclient/) 작업이 완료되어야 하는지를 나타냅니다.

```cpp
enum class HttpCompletionOption
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| ResponseContentRead | 0 | 응답 내용을 읽은 후 작업이 완료되어야 합니다. |
| ResponseHeadersRead | 1 | 응답의 헤더를 읽은 후 작업이 완료되어야 합니다. |
