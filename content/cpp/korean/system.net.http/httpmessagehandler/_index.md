## HttpMessageHandler 클래스

HTTP 메시지 핸들러의 기본 유형을 나타냅니다. 이 클래스의 객체는 [System::MakeObject()](../../system/makeobject/) 함수를 사용하여 할당해야 합니다. 스택에 직접 생성하거나 operator new를 사용하여 인스턴스를 만들면 런타임 오류 및/또는 어설션 오류가 발생합니다. 항상 이 클래스를 [System::SmartPtr](../../system/smartptr/) 포인터에 래핑하고 해당 포인터를 함수 인자로 전달하십시오.

```cpp
class HttpMessageHandler : public System::IDisposable
```
