## Timer::set_Enabled(bool) 메서드


타이머를 시작하거나 중지합니다. 타이머가 이미 실행 중인 경우, 타이머를 시작해도 시간 계산을 다시 시작하지 않습니다.

```cpp
void System::Timers::Timer::set_Enabled(bool value)
```


### 인수

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| value | **bool** | 타이머를 시작하려면 true, 중지하려면 false. |
