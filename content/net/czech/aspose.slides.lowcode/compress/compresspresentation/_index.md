## Metoda Compress.CompressPresentation

Snižuje velikost prezentace aplikací všech dostupných kroků komprese:

* Odstraňuje nepoužívané hlavní snímky [`RemoveUnusedMasterSlides`](../removeunusedmasterslides).
* Odstraňuje nepoužívané rozložení snímků [`RemoveUnusedLayoutSlides`](../removeunusedlayoutslides).
* Uchovává pouze glyfy skutečně použité v vložených fontech [`CompressEmbeddedFonts`](../compressembeddedfonts).
* Snižuje rozlišení obrázků na 150 DPI a maže oříznuté oblasti obrázků [`CompressImages`](../compressimages).

```csharp
public static void CompressPresentation(Presentation presentation)
```

| Parametr | Typ | Popis |
| --- | --- | --- |
| presentation | Presentation | Prezentace ke kompresi. |

### Výjimky

| výjimka | podmínka |
| --- | --- |
| ArgumentNullException | *presentation* je `null`. |

### Poznámky

Chcete-li přizpůsobit kompresi, například použít jiné rozlišení obrázku nebo krok přeskočit, zavolejte jednotlivé metody výše místo této. Oříznuté oblasti obrázků jsou trvale odstraněny a v PowerPointu nelze je obnovit.

### Příklady

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    Aspose.Slides.LowCode.Compress.CompressPresentation(pres);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
