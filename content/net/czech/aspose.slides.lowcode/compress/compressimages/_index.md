## Compress.CompressImages metoda

Snižuje rozlišení obrázků v prezentaci a odstraňuje jejich oříznuté oblasti, podobně jako funkce PowerPointu „Compress Pictures“ použita na všechny obrázky. Obrázky na snímcích, rozvrhových snímcích a hlavních snímcích jsou zpracovány, včetně obrázků uvnitř seskupených tvarů a výplní obrázků tvarů.

```csharp
public static void CompressImages(IPresentation presentation, PicturesCompression resolution)
```

| Parametr | Typ | Popis |
| --- | --- | --- |
| presentation | IPresentation | Prezentace, která má být zpracována. |
| resolution | PicturesCompression | Cílové rozlišení relativní k velikosti, při které je každý obrázek zobrazena. DocumentResolution ponechává obrázky beze změny. |

### Výjimky

| výjimka | podmínka |
| --- | --- |
| ArgumentNullException | *presentation* je `null`. |

### Poznámky

Obrázky, které již mají cílové rozlišení nebo jsou pod ním, zůstávají beze změny; obrázky nejsou nikdy zvětšovány.

Není zpracováno: pozadí snímků, výplně buněk tabulky, grafy, SmartArt, GIF obrázky (pro zachování animace), SVG a metafily (EMF/WMF) obrázky.

Oříznuté oblasti jsou trvale odstraněny a nelze je v PowerPointu obnovit.

### Příklady

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    CompressImages(pres, PicturesCompression.Dpi150);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
