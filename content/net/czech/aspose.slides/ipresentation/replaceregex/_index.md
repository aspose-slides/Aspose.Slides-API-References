## IPresentation.ReplaceRegex metoda

Nahradí všechny shody regulárního výrazu zadaným řetězcem.

```csharp
public void ReplaceRegex(Regex regex, string newText, IFindResultCallback callback)
```

| Parametr | Typ | Popis |
| --- | --- | --- |
| regex | Regex | Regulární výraz Regex pro získání řetězců, které se mají nahradit. |
| newText | String | Řetězec pro nahrazení všech výskytů řetězců, které mají být nahrazeny. |
| callback | IFindResultCallback | Objekt zpětného volání pro přijímání výsledků vyhledávání [`IFindResultCallback`](../../ifindresultcallback). |

### Příklady

Následující ukázkový kód ukazuje, jak nahradit text pomocí regulárního výrazu zadaným řetězcem.

```csharp
[C#]
using (Presentation presentation = new Presentation("SomePresentation.pptx"))
{
	Regex regex = new Regex(@"\b[^\s]{10,}\b");
	// Nahradí všechna slova s 10 a více znaky znakem '***'
	presentation.ReplaceRegex(regex, "***", null);
	presentation.Save("SomePresentation-out.pptx", SaveFormat.Pptx);
}
```
