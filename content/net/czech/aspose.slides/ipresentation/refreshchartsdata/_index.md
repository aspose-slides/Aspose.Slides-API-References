## IPresentation.RefreshChartsData method

Načte znovu data pro všechny grafy v prezentaci ze svých zdrojových sešitů.

```csharp
public void RefreshChartsData(bool skipFailedCharts = true)
```

| Parametr | Typ | Popis |
| --- | --- | --- |
| skipFailedCharts | Boolean | Určuje, zda proces obnovy pokračuje, pokud se graf nepodaří aktualizovat. Pokud `true`, grafy, které vyvolají výjimku, jsou přeskočeny; jinak je výjimka propagována. |

### Příklady

```csharp
using (var presentation = new Presentation("PresentationWithCharts.pptx"))
{
    presentation.RefreshChartsData();
    presentation.Save("PresentationWithCharts-out.pptx", SaveFormat.Pptx);
}
```
