## Presentation.RefreshChartsData metoda

Znovu načte data všech grafů v prezentaci z jejich zdrojových sešitů.

```csharp
public void RefreshChartsData(bool skipFailedCharts = true)
```

| Parametr | Typ | Popis |
| --- | --- | --- |
| skipFailedCharts | Boolean | Určuje, zda proces obnovení pokračuje, pokud aktualizace grafu selže. Pokud je `true`, grafy, které způsobí výjimku, jsou přeskočeny; jinak je výjimka propagována. |

### Příklady

```csharp
using (var presentation = new Presentation("PresentationWithCharts.pptx"))
{
    presentation.RefreshChartsData();
    presentation.Save("PresentationWithCharts-out.pptx", SaveFormat.Pptx);
}
```
