## IVideoFrame.VolumeValue vlastnost

Vrací nebo nastavuje přesnou hlasitost videa jako procento. Hodnota je vyjádřena jako procento od 0 do 100. Použijte tuto vlastnost k čtení nebo nastavení hodnot hlasitosti, které jsou přesnější než předdefinované úrovně dostupné přes vlastnost [`Volume`](../volume). Read/write Single.

```csharp
public float VolumeValue { get; set; }
```

### Příklady

Příklad:

```csharp
[C#]
using (Presentation pres = new Presentation("video.pptx"))
{
    IVideoFrame videoFrame = (IVideoFrame)pres.Slides[0].Shapes[0];

    // Přečtěte aktuální přesnou hlasitost a nastavte ji na 75,5 procenta.
    float currentVolume = videoFrame.VolumeValue;
    videoFrame.VolumeValue = 75.5f;

    pres.Save("video_with_volume.pptx", SaveFormat.Pptx);
}
```
