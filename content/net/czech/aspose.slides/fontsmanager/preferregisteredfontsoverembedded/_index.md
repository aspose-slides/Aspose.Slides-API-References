## FontsManager.PreferRegisteredFontsOverEmbedded vlastnost

Určuje, zda mají být registrovaná písma upřednostňována před vloženými písmy se stejným názvem a stylem. Pokud je povoleno, odpovídající vložená písma jsou během exportu dočasně nahrazena registrovanými písmy.

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### Poznámky

Výchozí hodnota je **false**.

### Příklady

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
