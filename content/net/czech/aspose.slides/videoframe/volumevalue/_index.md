## VideoFrame.VolumeValue vlastnost

Vrací nebo nastavuje přesnou hlasitost videa v procentech. Hodnota je vyjádřena v procentech od 0 do 100. Použijte tuto vlastnost k načtení nebo nastavení hodnot hlasitosti, které jsou přesnější než předdefinované úrovně dostupné prostřednictvím vlastnosti [`Volume`](../volume). Číst/Zapisovat Single.

```csharp
public float VolumeValue { get; set; }
```

### Příklady

Příklad:

```csharp
[C#]
using (Presentation pres = new Presentation("video.pptx"))
{
    IVideoFrame videoFrame = (IVideoFrame)pres.Slides[0].Shapes[0];

    // Přečtěte aktuální přesnou hlasitost a nastavte ji na 75.5 procent.
    float currentVolume = videoFrame.VolumeValue;
    videoFrame.VolumeValue = 75.5f;

    pres.Save("video_with_volume.pptx", SaveFormat.Pptx);
}
```
