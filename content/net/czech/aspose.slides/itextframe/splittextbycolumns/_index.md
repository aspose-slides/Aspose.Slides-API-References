## ITextFrame.SplitTextByColumns metoda

Rozdělí textový obsah [`ITextFrame`](../../itextframe) na pole řetězců, kde každý prvek odpovídá samostatnému textovému sloupci v rámci rámečku.

```csharp
public string[] SplitTextByColumns()
```

### Návratová hodnota

Pole řetězců, kde každý řetězec představuje textový obsah konkrétního sloupce v [`ITextFrame`](../../itextframe).

### Poznámky

Pokud textový rámec neobsahuje více sloupců, vrácené pole bude mít jediný prvek obsahující celý text. Prázdné sloupce budou v poli reprezentovány prázdnými řetězci.

### Příklady

Následující příklad ukazuje, jak použít `SplitTextByColumns`:

```csharp
using (Presentation pres = new Presentation("example.pptx"))
{
    // Získá první tvar na snímku a přetypuje jej na ITextFrame
    ITextFrame textFrame = pres.Slides[0].Shapes[0] as ITextFrame;
    // Rozdělí obsah textového rámce do sloupců
    string[] columnsText = textFrame.SplitTextByColumns();
    // Vypíše text každého sloupce do konzole
    foreach (string column in columnsText)
        Console.WriteLine(column);
}
```
