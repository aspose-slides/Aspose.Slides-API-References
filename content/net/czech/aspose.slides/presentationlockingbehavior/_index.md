## Výčet PresentationLockingBehavior

Reprezentuje chování při zacházení se zdrojem [`IPresentation`](../ipresentation) (soubor nebo Stream) během načítání a práce s instancí [`IPresentation`](../ipresentation).

```csharp
public enum PresentationLockingBehavior
```

### Hodnoty

| Název | Hodnota | Popis |
| --- | --- | --- |
| LoadAndRelease | `0` | Zdroj bude zamčen pouze po dobu provádění konstruktoru [`IPresentation`](../ipresentation). Pokud je [`IsTemporaryFilesAllowed`](../iblobmanagementoptions/istemporaryfilesallowed) nastaven na false, všechny BLOBy budou načteny do paměti. V opačném případě mohou být použity jiné prostředky, například dočasné soubory. Toto chování je pomalejší než KeepLocked a pokud je možné předat vlastnictví zdroje [`IPresentation`](../ipresentation), doporučuje se použít KeepLocked. |
| KeepLocked | `1` | Zdroj bude zamčen po celou životnost instance [`IPresentation`](../ipresentation), dokud nebude uvolněn. [`IsTemporaryFilesAllowed`](../iblobmanagementoptions/istemporaryfilesallowed) musí být nastaven na true, aby bylo možné toto chování použít, jinak bude vyvolána výjimka. Toto chování se doporučuje, je rychlejší a spotřebuje méně paměti než LoadAndRelease. |

### Poznámky

Zdroj je parametr předaný konstruktoru [`IPresentation`](../ipresentation). V níže uvedeném příkladu je zdroj soubor "pres.pptx":

```csharp
LoadOptions loadOptions = new LoadOptions { 
  BlobManagementOptions = { PresentationLockingBehavior = PresentationLockingBehavior.KeepLocked } };
using (IPresentation pres = new Presentation("pres.pptx", loadOptions)) { }
```

Pro tento příklad bude zdroj (soubor "pres.pptx") zamčen po celou životnost instance [`IPresentation`](../ipresentation), tj. ostatní proces jej nemůže měnit ani mazat.
