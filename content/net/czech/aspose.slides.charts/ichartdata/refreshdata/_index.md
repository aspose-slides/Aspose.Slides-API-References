## IChartData.RefreshData metoda

Obnoví data grafu načtením z zdrojového sešitu.

```csharp
public void RefreshData()
```

### Výjimky

| výjimka | podmínka |
| --- | --- |
| InvalidOperationException | Vyvoláno, když formát sešitu není podporován, nebo když je [`DataSourceType`](../datasourcetype) typu ExternalWorkbook a externí sešit nelze získat nebo načíst. |

### Poznámky

Pokud graf používá externí sešit, musí být sešit přístupný v čase volání.

### Příklady

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
