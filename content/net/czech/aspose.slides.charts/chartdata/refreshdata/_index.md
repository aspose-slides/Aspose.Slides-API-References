## ChartData.RefreshData metoda

Obnoví data grafu načtením z původního sešitu.

```csharp
public void RefreshData()
```

### Výjimky

| výjimka | podmínka |
| --- | --- |
| InvalidOperationException | Vyvolána, když není podporován formát sešitu nebo když je [`DataSourceType`](../datasourcetype) typ ExternalWorkbook a externí sešit nelze získat nebo načíst. |

### Poznámky

Pokud graf používá externí sešit, musí být sešit během volání přístupný.

### Příklady

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
