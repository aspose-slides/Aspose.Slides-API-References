## IChartCategory.UseCell vlastnost

Pokud je true, pak je platná vlastnost AsCell. Jinými slovy, pracovní list se používá k uložení kategorie (tento případ podporuje vícestupňovou kategorii). Pokud je false, pak je platná vlastnost AsLiteral. Jinými slovy, pracovní list NENÍ používán k uložení kategorie (a tento případ nepodporuje vícestupňové kategorie). Pouze pro čtení Boolean.

```csharp
public bool UseCell { get; }
```

### Poznámky

Pro změnu hodnoty této vlastnosti (pro všechny kategorie ve sbírce) nastavte novou hodnotu na vlastnost ChartCategoryCollection.UseCells.
