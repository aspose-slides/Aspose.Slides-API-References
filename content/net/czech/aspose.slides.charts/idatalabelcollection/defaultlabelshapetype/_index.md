## IDataLabelCollection.DefaultLabelShapeType vlastnost

Získá nebo nastaví výchozí typ tvaru pro popisky dat. Vrací NotDefined, pokud není definován žádný tvar.

```csharp
public ShapeType DefaultLabelShapeType { get; set; }
```

### Poznámky

Nastavení této vlastnosti také nastaví vlastnost [`LabelShapeType`](../../idatalabel/labelshapetype) pro všechny popisky dat ve sbírce na stejnou hodnotu.

### Příklady

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[1];
    var firstSeries = chart.ChartData.Series[0];

    // Nastavte typ tvaru všech popisků dat v první sérii na Ellipse.
    firstSeries.Labels.DefaultLabelShapeType = ShapeType.Ellipse;

    pres.Save("ChartWithEllipseLabels.pptx", SaveFormat.Pptx);
}
```
