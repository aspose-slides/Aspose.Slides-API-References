## ChartCategory.UseCell vlastnost

Pokud je true, pak je vlastnost AsCell aktuální. Jinými slovy, list se používá pro ukládání kategorie (tento případ podporuje víceúrovňovou kategorii). Pokud je false, pak je vlastnost AsLiteral aktuální. Jinými slovy, list se NEpoužívá pro ukládání kategorie (a tento případ nepodporuje víceúrovňové kategorie). Pouze pro čtení Boolean.

```csharp
public bool UseCell { get; }
```

### Poznámky

Pro změnu hodnoty této vlastnosti (pro všechny kategorie ve sbírce) nastavte novou hodnotu na vlastnost ChartCategoryCollection.UseCells.
