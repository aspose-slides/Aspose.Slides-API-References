## DataLabelCollection.IsVisible Eigenschaft

False bedeutet, dass das Datenetikett standardmäßig nicht sichtbar ist (und daher alle Show*-Flags (ShowValue, ...) der DefaultDataLabelFormat Eigenschaft false sind). Nur-Lese-Boolean.

```csharp
public bool IsVisible { get; }
```

### Hinweise

Wenn das Datenetikett standardmäßig sichtbar ist, können Sie es mit der Hide()-Methode standardmäßig ausblenden. Wenn das Datenetikett jedoch standardmäßig nicht sichtbar ist (IsVisible ist false), können Sie das Datenetikett „standardmäßig sichtbar“ machen, indem Sie die Show*-Flags (ShowValue, ...) der DefaultDataLabelFormat-Eigenschaft auf den wahren Zustand setzen.
