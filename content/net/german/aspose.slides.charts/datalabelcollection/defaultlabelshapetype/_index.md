## DataLabelCollection.DefaultLabelShapeType Eigenschaft

Ruft den Standard-Formtyp für Datenbeschriftungen ab oder legt ihn fest. Gibt NotDefined zurück, wenn keine Form definiert ist.

```csharp
public ShapeType DefaultLabelShapeType { get; set; }
```

### Anmerkungen

Durch das Festlegen dieser Eigenschaft wird auch die [`LabelShapeType`](../../idatalabel/labelshapetype)-Eigenschaft für alle Datenbeschriftungen in der Sammlung auf denselben Wert gesetzt.

### Beispiele

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[1];
    var firstSeries = chart.ChartData.Series[0];

    // Setzt den Formtyp aller Datenbeschriftungen in der ersten Serie auf Ellipse.
    firstSeries.Labels.DefaultLabelShapeType = ShapeType.Ellipse;

    pres.Save("ChartWithEllipseLabels.pptx", SaveFormat.Pptx);
}
```
