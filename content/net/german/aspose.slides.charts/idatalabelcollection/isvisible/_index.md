## IDataLabelCollection.IsVisible Eigenschaft

False bedeutet, dass Datenbeschriftung standardmäßig nicht sichtbar ist (und daher alle Show*-Flags (ShowValue, ...) der DefaultDataLabelFormat Eigenschaft false sind). Nur lesbar Boolean.

```csharp
public bool IsVisible { get; }
```

### Bemerkungen

Wenn die Datenbeschriftung standardmäßig sichtbar ist, können Sie sie mit der Hide()-Methode standardmäßig ausblenden. Wenn die Datenbeschriftung jedoch standardmäßig nicht sichtbar ist (IsVisible ist false), können Sie die Datenbeschriftung "standardmäßig sichtbar" machen, indem Sie die Show*-Flags (ShowValue, ...) der DefaultDataLabelFormat-Eigenschaft auf den wahren Zustand setzen.
