## ChartData.RefreshData Methode

Lädt die Diagrammdaten neu, indem sie aus dem Quellarbeitsbuch erneut geladen werden.

```csharp
public void RefreshData()
```

### Ausnahmen

| Ausnahme | Bedingung |
| --- | --- |
| InvalidOperationException | Wird ausgelöst, wenn das Arbeitsbuchformat nicht unterstützt wird oder wenn [`DataSourceType`](../datasourcetype) ExternalWorkbook ist und das externe Arbeitsbuch nicht zugegriffen oder geladen werden kann. |

### Anmerkungen

Wenn das Diagramm ein externes Arbeitsbuch verwendet, muss das Arbeitsbuch zum Zeitpunkt des Aufrufs zugänglich sein.

### Beispiele

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
