## IDataLabel.Hide Methode

Macht das Datenbeschriftungsfeld unsichtbar, indem alle Show*-Flags (ShowValue, ...) auf den falschen Zustand gesetzt werden. IsVisible wird danach false sein.

```csharp
public void Hide()
```

### Hinweise

Wenn das Datenbeschriftungsfeld nicht sichtbar ist (IsVisible ist false), können Sie das Datenbeschriftungsfeld sichtbar machen, indem Sie die Show*-Flags (ShowValue, ...) auf den wahren Zustand setzen.
