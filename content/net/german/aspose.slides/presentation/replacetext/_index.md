## Presentation.ReplaceText Methode

Ersetzt alle Vorkommen des angegebenen Textes durch einen anderen angegebenen Text.

```csharp
public void ReplaceText(string oldText, string newText, ITextSearchOptions options, 
    IFindResultCallback callback)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| oldText | String | Die Zeichenkette, die ersetzt werden soll. |
| newText | String | Die Zeichenkette, die alle Vorkommen von oldText ersetzt. |
| options | ITextSearchOptions | Optionen für die Textsuche [`ITextSearchOptions`](../../itextsearchoptions). |
| callback | IFindResultCallback | Das Callback-Objekt zum Empfangen von Suchergebnissen [`IFindResultCallback`](../../ifindresultcallback). |

### Beispiele

Der folgende Beispielcode zeigt, wie ein angegebener String durch einen anderen angegebenen String ersetzt wird.

```csharp
[C#]
using (Presentation presentation = new Presentation("SomePresentation.pptx"))
{
	// Ersetzt alle einzelnen Vorkommen von 'the' durch '***'
	presentation.ReplaceText("the", "***", new TextSearchOptions() {WholeWordsOnly = true}, null);
	presentation.Save("SomePresentation-out2.pptx", SaveFormat.Pptx);
}
```
