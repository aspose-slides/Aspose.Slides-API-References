## IPresentation.RefreshChartsData Methode

Lädt die Daten für alle Diagramme in der Präsentation aus ihren Quellarbeitsmappen neu.

```csharp
public void RefreshChartsData(bool skipFailedCharts = true)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| skipFailedCharts | Boolean | Bestimmt, ob der Aktualisierungsvorgang fortgesetzt wird, wenn ein Diagramm nicht aktualisiert werden kann. Wenn `true`, werden Diagramme, die eine Ausnahme auslösen, übersprungen; andernfalls wird die Ausnahme weitergegeben. |

### Beispiele

```csharp
using (var presentation = new Presentation("PresentationWithCharts.pptx"))
{
    presentation.RefreshChartsData();
    presentation.Save("PresentationWithCharts-out.pptx", SaveFormat.Pptx);
}
```
