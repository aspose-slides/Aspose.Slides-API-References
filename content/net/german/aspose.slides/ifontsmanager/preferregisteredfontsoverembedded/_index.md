## IFontsManager.PreferRegisteredFontsOverEmbedded Eigenschaft

Legt fest, ob registrierte Schriftarten gegenüber eingebetteten Schriftarten mit demselben Schriftartnamen und Stil bevorzugt werden sollen. Wenn aktiviert, werden passende eingebettete Schriftarten während des Exports temporär durch die entsprechenden registrierten Schriftarten ersetzt.

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### Anmerkungen

Standard ist **false**.

### Beispiele

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
