## IFontsManager.GetFontBytes Methode

Ruft das Byte-Array ab, das die Font-Daten für einen angegebenen Font-Stil und Font-Daten darstellt.

```csharp
public byte[] GetFontBytes(IFontData fontData, FontStyleType fontStyle)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| fontData | IFontData | Das Font-Datenobjekt, das die Informationen über die Schrift [`IFontData`](../../ifontdata) enthält. |
| fontStyle | FontStyleType | Der Stil der Schrift, für die die Daten abgerufen werden sollen [`FontStyleType`](../../fontstyletype). |

### Rückgabewert

Ein Byte-Array, das die Font-Daten für den angegebenen Font-Stil enthält. Wenn die Font-Daten oder der Stil nicht gefunden werden, wird null zurückgegeben.

### Beispiele

```csharp
[C#]
using (Presentation pres = new Presentation ("Presentation.pptx"))
{
    // Alle in der Präsentation verwendeten Schriftarten abrufen
    IFontData[] fonts = pres.FontsManager.GetFonts();

    // Das Byte-Array erhalten, das den regulären Stil der ersten Schriftart in der Präsentation darstellt
    byte[] bytes = pres.FontsManager.GetFontBytes(fonts[0], FontStyleType.Regular);
}
```
