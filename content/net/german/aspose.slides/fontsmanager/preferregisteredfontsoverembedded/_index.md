## FontsManager.PreferRegisteredFontsOverEmbedded Eigenschaft

Gibt an, ob registrierte Schriftarten gegenüber eingebetteten Schriftarten mit demselben Schriftartnamen und derselben Schriftartstil bevorzugt werden sollen. Wenn aktiviert, werden passende eingebettete Schriftarten während des Exports vorübergehend durch die entsprechenden registrierten Schriftarten ersetzt.

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### Bemerkungen

Standard ist **false**.

### Beispiele

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
