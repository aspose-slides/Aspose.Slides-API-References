## GetSubstitutions(int[]) {#getsubstitutions_1}

Ruft die Informationen zu Schriften ab, die beim Rendern der angegebenen Folien ersetzt werden.

```csharp
public IEnumerable<FontSubstitutionInfo> GetSubstitutions(int[] slides)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| slides | Int32[] | Ein Array von Folien-Indizes, für die Schriftart-Substitutionsinformationen abgerufen werden sollen, beginnend bei 1. |

### Rückgabewert

Eine Sammlung aller Schriftart-Substitutionen ([`FontSubstitutionInfo`](../../fontsubstitutioninfo)) für die angegebenen Folien.

### Beispiele

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    int[] targetSlides = { 1, 2, 5 };
    foreach (var fontSubstitution in pres.FontsManager.GetSubstitutions(targetSlides))
    {
        Console.WriteLine("{0} -> {1}", fontSubstitution.OriginalFontName, fontSubstitution.SubstitutedFontName);
    }
}
```
