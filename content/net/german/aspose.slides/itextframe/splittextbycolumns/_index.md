## ITextFrame.SplitTextByColumns method

Teilt den Textinhalt des [`ITextFrame`](../../itextframe) in ein Array von Zeichenketten, wobei jedes Element einer separaten Textspalte im Rahmen entspricht.

```csharp
public string[] SplitTextByColumns()
```

### Rückgabewert

Ein Array von Zeichenketten, wobei jede Zeichenkette den Textinhalt einer bestimmten Spalte im [`ITextFrame`](../../itextframe) darstellt.

### Bemerkungen

Wenn der Textrahmen nicht mehrere Spalten enthält, hat das zurückgegebene Array ein einziges Element, das den gesamten Text enthält. Leere Spalten werden im Array als leere Zeichenketten dargestellt.

### Beispiele

Das folgende Beispiel demonstriert, wie man `SplitTextByColumns` verwendet:

```csharp
using (Presentation pres = new Presentation("example.pptx"))
{
    // Hole das erste Shape auf der Folie und wandle es in ITextFrame um
    ITextFrame textFrame = pres.Slides[0].Shapes[0] as ITextFrame;
    // Teile den Inhalt des Textframes in Spalten auf
    string[] columnsText = textFrame.SplitTextByColumns();
    // Gib den Text jeder Spalte in der Konsole aus
    foreach (string column in columnsText)
        Console.WriteLine(column);
}
```
