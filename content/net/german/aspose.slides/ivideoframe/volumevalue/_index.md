## IVideoFrame.VolumeValue Eigenschaft

Gibt die genaue Videolautstärke als Prozentsatz zurück oder legt sie fest. Der Wert wird als Prozentsatz von 0 bis 100 angegeben. Verwenden Sie diese Eigenschaft, um Lautstärkewerte zu lesen oder festzulegen, die präziser sind als die vordefinierten Stufen, die über die [`Volume`](../volume) Eigenschaft verfügbar sind. Lese-/Schreib Single.

```csharp
public float VolumeValue { get; set; }
```

### Beispiele

Beispiel:

```csharp
[C#]
using (Presentation pres = new Presentation("video.pptx"))
{
    IVideoFrame videoFrame = (IVideoFrame)pres.Slides[0].Shapes[0];

    // Lesen Sie die aktuelle genaue Lautstärke und setzen Sie sie auf 75,5 Prozent.
    float currentVolume = videoFrame.VolumeValue;
    videoFrame.VolumeValue = 75.5f;

    pres.Save("video_with_volume.pptx", SaveFormat.Pptx);
}
```
