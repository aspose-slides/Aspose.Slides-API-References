## VideoFrame.VolumeValue Eigenschaft

Gibt die exakte Lautstärke des Videos als Prozentsatz zurück oder legt sie fest. Der Wert wird als Prozentsatz von 0 bis 100 ausgedrückt. Verwenden Sie diese Eigenschaft, um Lautstärkewerte zu lesen oder festzulegen, die genauer sind als die vordefinierten Stufen, die über die [`Volume`](../volume)-Eigenschaft verfügbar sind. Lesen/Schreiben Single.

```csharp
public float VolumeValue { get; set; }
```

### Beispiele

Beispiel:

```csharp
[C#]
using (Presentation pres = new Presentation("video.pptx"))
{
    IVideoFrame videoFrame = (IVideoFrame)pres.Slides[0].Shapes[0];

    // Lese die aktuelle exakte Lautstärke und setze sie auf 75,5 Prozent.
    float currentVolume = videoFrame.VolumeValue;
    videoFrame.VolumeValue = 75.5f;

    pres.Save("video_with_volume.pptx", SaveFormat.Pptx);
}
```
