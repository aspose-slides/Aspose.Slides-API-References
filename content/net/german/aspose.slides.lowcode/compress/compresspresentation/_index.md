## Compress.CompressPresentation Methode

Reduziert die Größe einer Präsentation, indem alle verfügbaren Komprimierungsschritte angewendet werden:

* Entfernt ungenutzte Master-Folien [`RemoveUnusedMasterSlides`](../removeunusedmasterslides).
* Entfernt ungenutzte Layout-Folien [`RemoveUnusedLayoutSlides`](../removeunusedlayoutslides).
* Behalte nur die tatsächlich in eingebetteten Schriftarten verwendeten Glyphen [`CompressEmbeddedFonts`](../compressembeddedfonts).
* Reduziert die Bildauflösung auf 150 DPI und löscht beschnittene Bildbereiche [`CompressImages`](../compressimages).

```csharp
public static void CompressPresentation(Presentation presentation)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| presentation | Presentation | Die zu komprimierende Präsentation. |

### Ausnahmen

| Ausnahme | Bedingung |
| --- | --- |
| ArgumentNullException | *presentation* ist `null`. |

### Hinweise

Um die Komprimierung anzupassen, beispielsweise um eine andere Bildauflösung zu verwenden oder einen Schritt zu überspringen, rufen Sie die oben aufgeführten Methoden einzeln anstelle dieser auf. Beschnittene Bildbereiche werden dauerhaft entfernt und können in PowerPoint nicht wiederhergestellt werden.

### Beispiele

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    Aspose.Slides.LowCode.Compress.CompressPresentation(pres);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
