## Compress.CompressImages Methode

Reduziert die Auflösung von Bildern in der Präsentation und löscht deren zugeschnittene Bereiche, ähnlich wie PowerPoint-"Compress Pictures", das auf alle Bilder angewendet wird. Bilder auf Folien, Layoutfolien und Masterfolien werden verarbeitet, einschließlich Bildern innerhalb von Gruppierungen und Bildfüllungen von Formen.

```csharp
public static void CompressImages(IPresentation presentation, PicturesCompression resolution)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| presentation | IPresentation | Die zu verarbeitende Präsentation. |
| resolution | PicturesCompression | Zielauflösung relativ zur Größe, in der jedes Bild angezeigt wird. DocumentResolution lässt Bilder unverändert. |

### Ausnahmen

| Ausnahme | Bedingung |
| --- | --- |
| ArgumentNullException | *presentation* ist `null`. |

### Hinweise

Bilder, die bereits die Zielauflösung erreichen oder darunter liegen, bleiben unverändert; Bilder werden niemals vergrößert.

Nicht verarbeitet: Folienhintergründe, Tabellenzellenfüllungen, Diagramme, SmartArt, GIF-Bilder (zur Bewahrung der Animation), SVG- und Metadatei-Bilder (EMF/WMF).

Zugeschnittene Bereiche werden dauerhaft entfernt und können in PowerPoint nicht wiederhergestellt werden.

### Beispiele

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    CompressImages(pres, PicturesCompression.Dpi150);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
