## BlackWhiteConversionMode Aufzählung

Stellt Optionen bereit, die steuern, wie die Folienbilder in bitonale Bilder umgewandelt werden.

```csharp
public enum BlackWhiteConversionMode
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Default | `0` | Gibt an, dass kein Konvertierungsalgorithmus verwendet wird. Der im TIFF-Codec implementierte Algorithmus wird verwendet. (Standard) |

| DitheringFloydSteinberg | `2` | Gibt den Floyd-Steinberg-Dithering-Algorithmus an. |
