## Compress.CompressImages 方法

將簡報中的圖片解析度降低，並刪除其裁剪區域，類似於 PowerPoint 的「Compress Pictures」套用於所有圖片的效果。會處理投影片、版面投影片和母片上的圖片，包括群組圖形內的圖片以及圖形的圖片填充。

```csharp
public static void CompressImages(IPresentation presentation, PicturesCompression resolution)
```

| 參數 | 類型 | 說明 |
| --- | --- | --- |
| presentation | IPresentation | 要處理的簡報。 |
| resolution | PicturesCompression | 相對於每張圖片實際顯示大小的目標解析度。DocumentResolution 會保持圖片不變。 |

### 例外情況

| 例外 | 條件 |
| --- | --- |
| ArgumentNullException | *presentation* 為 `null`。 |

### 備註

已在目標解析度或更低的圖片將保持不變；圖片絕不會被放大。

未處理的項目：投影片背景、表格儲存格填充、圖表、SmartArt、GIF 圖片（為保留動畫）、SVG 與圖語檔（EMF/WMF）圖片。

裁剪區域會永久移除，且無法在 PowerPoint 中復原。

### 範例

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    CompressImages(pres, PicturesCompression.Dpi150);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
