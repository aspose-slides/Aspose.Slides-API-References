## Compress.CompressPresentation 方法

透過套用所有可用的壓縮步驟來減少簡報的大小：

* 移除未使用的母版投影片 [`RemoveUnusedMasterSlides`](../removeunusedmasterslides)。
* 移除未使用的版面配置投影片 [`RemoveUnusedLayoutSlides`](../removeunusedlayoutslides)。
* 只保留嵌入字型中實際使用的字形 [`CompressEmbeddedFonts`](../compressembeddedfonts)。
* 將圖片解析度降至 150 DPI，並刪除圖片的裁切區域 [`CompressImages`](../compressimages)。

```csharp
public static void CompressPresentation(Presentation presentation)
```

| 參數 | 類型 | 說明 |
| --- | --- | --- |
| presentation | Presentation | 要壓縮的簡報。 |

### 例外

| 例外 | 條件 |
| --- | --- |
| ArgumentNullException | *presentation* 為 `null`。 |

### 備註

若要自訂壓縮，例如使用不同的圖片解析度或跳過某個步驟，請個別呼叫上述列出的方法，而不是此方法。圖片的裁切區域會永久移除，且無法在 PowerPoint 中還原。

### 範例

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    Aspose.Slides.LowCode.Compress.CompressPresentation(pres);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
