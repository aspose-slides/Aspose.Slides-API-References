## PieSplitType 列舉

表示在 pie-of-pie 或 bar-of-pie 圖表的第二個餅或條形上的分割點類型。

```csharp
public enum PieSplitType
```

### 值

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| Default | `0` | 指定資料點應使用此圖表類型的預設機制分割。 |
| Custom | `1` | 指定資料點應根據 Custom Split 值在餅圖和第二圖表之間分割。 |
| ByPercentage | `2` | 指定資料點應透過將百分比小於 Split Position 百分比的點放入第二圖表，從而在餅圖和第二圖表之間分割。 |
| ByPos | `3` | 指定資料點應透過將資料點的最後 Split Position 放入第二圖表，從而在餅圖和第二圖表之間分割。 |
| ByValue | `4` | 指定資料點應透過將值小於 Split Position 的資料點放入第二圖表，從而在餅圖和第二圖表之間分割。 |
