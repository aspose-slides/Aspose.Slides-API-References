## ChartData.RefreshData 方法

重新整理圖表資料，從來源活頁簿重新載入。

```csharp
public void RefreshData()
```

### 例外

| 例外 | 條件 |
| --- | --- |
| InvalidOperationException | 當活頁簿格式不受支援，或當 [`DataSourceType`](../datasourcetype) 為 ExternalWorkbook 且無法存取或載入外部活頁簿時拋出此例外。 |

### 備註

如果圖表使用外部活頁簿，呼叫時必須能存取該活頁簿。

### 範例

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
