## ChartSeriesGroup.GapDepth 屬性

取得或設定 3D 圖表中資料系列之間的距離，以標記寬度的百分比表示。此值必須介於 0 到 500 之間。讀/寫 UInt16。

```csharp
public ushort GapDepth { get; set; }
```

### 備註

此屬性適用於以下類型的系列：3D 條形和柱形子類型（另請參閱 [`IsBar3DChart`](../../charttypecharacterizer/isbar3dchart) 方法），Line3D、Area3D、StackedArea3D、PercentsStackedArea3D。
