## ChartDataPoint.CachedBubbleSize 屬性

取得圖表資料點的快取氣泡大小。唯讀 [`ICachedChartValue`](../../icachedchartvalue).

```csharp
public ICachedChartValue CachedBubbleSize { get; }
```

### 範例

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[0];
    foreach (var series in chart.ChartData.Series)
    {
        // 列印圖表系列的所有快取氣泡大小值。
        foreach (var point in series.DataPoints)
            Console.WriteLine(point.CachedBubbleSize.ToDouble());
    }
}
```
