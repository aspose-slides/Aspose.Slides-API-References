## IFontsManager.GetFontBytes 方法

檢索表示指定字體樣式和字體資料之字體資料的位元組陣列。

```csharp
public byte[] GetFontBytes(IFontData fontData, FontStyleType fontStyle)
```

| 參數 | 類型 | 描述 |
| --- | --- | --- |
| fontData | IFontData | 包含關於字體資訊的字體資料物件 [`IFontData`](../../ifontdata)。 |
| fontStyle | FontStyleType | 要檢索資料之字體的樣式 [`FontStyleType`](../../fontstyletype)。 |

### 返回值

包含指定字體樣式之字體資料的位元組陣列。如果未找到字體資料或樣式，則傳回 null。

### 範例

```csharp
[C#]
using (Presentation pres = new Presentation ("Presentation.pptx"))
{
    // 擷取簡報中使用的所有字型
    IFontData[] fonts = pres.FontsManager.GetFonts();

    // 取得簡報中第一個字型的常規樣式之位元組陣列
    byte[] bytes = pres.FontsManager.GetFontBytes(fonts[0], FontStyleType.Regular);
}
```
