## NormalViewProperties 類別

表示普通視圖屬性。普通視圖由三個內容區域組成：幻燈片本身、一個側邊內容區域，以及一個底部內容區域。

```csharp
public class NormalViewProperties : INormalViewProperties
```

## 屬性

| 名稱 | 說明 |
| --- | --- |
| [HorizontalBarState](../../aspose.slides/normalviewproperties/horizontalbarstate) { get; set; } | 指定水平分割條應顯示的狀態。水平分割條將幻燈片與幻燈片下方的內容區域分開。 |
| [PreferSingleView](../../aspose.slides/normalviewproperties/prefersingleview) { get; set; } | 指定使用者是否偏好以全視窗單一內容區域取代具有三個內容區域的標準普通視圖。啟用後，應用程式可能會選擇在整個視窗中顯示其中一個內容區域。可讀寫 Boolean。 |
| [RestoredLeft](../../aspose.slides/normalviewproperties/restoredleft) { get; } | 此元素指定普通視圖側邊內容區域的大小，當區域處於可變還原大小（既未最小化也未最大化）時。唯讀 [`INormalViewRestoredProperties`](../inormalviewrestoredproperties)。 |
| [RestoredTop](../../aspose.slides/normalviewproperties/restoredtop) { get; } | 此元素指定普通視圖頂部幻燈片區域的大小，當區域處於可變還原大小（既未最小化也未最大化）時。唯讀 [`INormalViewRestoredProperties`](../inormalviewrestoredproperties)。 |
| [ShowOutlineIcons](../../aspose.slides/normalviewproperties/showoutlineicons) { get; set; } | 指定在普通視圖模式的任何內容區域顯示大綱內容時，應用程式是否應顯示圖示。可讀寫 Boolean。 |
| [SnapVerticalSplitter](../../aspose.slides/normalviewproperties/snapverticalsplitter) { get; set; } | 指定當側邊區域足夠小時，垂直分割條是否應自動貼合至最小化狀態。可讀寫 Boolean。 |
| [VerticalBarState](../../aspose.slides/normalviewproperties/verticalbarstate) { get; set; } | 指定垂直分割條應顯示的狀態。垂直分割條將幻燈片與側邊內容區域分開。 |

### 範例

以下範例說明如何設定 PowerPoint 簡報的 ViewProperties.NormalViewProperties 屬性。

```csharp
[C#]
//實例化表示簡報檔案的簡報物件
using (Presentation pres = new Presentation("demo.pptx"))
{
    pres.ViewProperties.NormalViewProperties.HorizontalBarState = SplitterBarStateType.Restored;
    pres.ViewProperties.NormalViewProperties.VerticalBarState = SplitterBarStateType.Maximized;
    pres.ViewProperties.NormalViewProperties.RestoredTop.AutoAdjust = true;
    pres.ViewProperties.NormalViewProperties.RestoredTop.DimensionSize = 80;
    pres.ViewProperties.NormalViewProperties.ShowOutlineIcons = true;
    pres.Save("presentation_normal_view_state.pptx", SaveFormat.Pptx);
}
```
