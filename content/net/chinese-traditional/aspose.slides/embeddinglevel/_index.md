## EmbeddingLevel 列舉

表示字型嵌入的授權權利。

```csharp
[Flags]
public enum EmbeddingLevel : ushort
```

### 值

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| Installable | `0` | 此設定的字型表示可以由應用程式嵌入並永久安裝於遠端系統。遠端系統的使用者取得與原始字型購買者相同的權利、義務與授權，並受相同的最終使用者授權協議、版權、外觀設計專利和/或商標條款約束。 |
| Restricted | `2` | 只有此位元被設定的字型在未先取得合法所有者許可前，禁止以任何方式修改、嵌入或交換。 |
| PreviewPrint | `4` | 設定此位元時，字型可嵌入，並暫時載入遠端系統。包含 Preview &amp; Print 字型的文件必須以「唯讀」模式開啟；文件不可進行編輯。 |
| Editable | `8` | 設定此位元時，字型可嵌入，但只能暫時安裝於其他系統。與 Preview &amp; Print 字型不同，包含 Editable 字型的文件可開啟閱讀，允許編輯，且變更可儲存。 |
| NoSubsetting | `100` | 設定此位元時，字型在嵌入前不得進行子集化。位元 0-3 以及 9 所規定的其他嵌入限制亦同時適用。 |
| BitmapOnly | `200` | 設定此位元時，僅允許嵌入字型內含的點陣圖。輪廓資料不得嵌入。若字型內沒有可用的點陣圖，則視為無法嵌入，嵌入服務將失敗。 |
