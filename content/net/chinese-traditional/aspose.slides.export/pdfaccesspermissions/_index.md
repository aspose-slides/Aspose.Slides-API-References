## PdfAccessPermissions 列舉

Contains a set of flags specifying which access permissions should be granted when the document is opened with user access.

```csharp
[Flags]
public enum PdfAccessPermissions
```

### 值

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| None | `0` | 指定使用者沒有存取權限。 |
| PrintDocument | `4` | 指定使用者是否可以列印文件（可能無法達到最高品質，取決於是否同時設定了位元 HighQualityPrint）。 |
| ModifyContent | `8` | 指定使用者是否可以透過除位元 AddOrModifyFields、FillExistingFields、AssembleDocument 所控制的操作之外的其他操作來修改文件內容。 |
| CopyTextAndGraphics | `10` | 指定使用者是否可以透過除位元 ExtractTextAndGraphics 所控制的操作之外的其他操作，複製或以其他方式擷取文件中的文字與圖形。 |
| AddOrModifyFields | `20` | 指定使用者是否可以新增或修改文字註釋、填寫互動式表單欄位，且在同時設定位元 ModifyContent 時，建立或修改互動式表單欄位（包括簽名欄位）。 |
| FillExistingFields | `100` | 指定使用者是否可以填寫已存在的互動式表單欄位（包括簽名欄位），即使位元 AddOrModifyFields 未設定。 |
| ExtractTextAndGraphics | `200` | 指定使用者是否可以擷取文字與圖形，以協助身心障礙使用者的可及性或其他目的。 |
| AssembleDocument | `400` | 指定使用者是否可以組合文件（插入、旋轉或刪除頁面，以及建立書籤或縮圖），即使位元 ModifyContent 未設定。 |
| HighQualityPrint | `800` | 指定使用者是否可以列印文件至可產生 PDF 內容完整數位副本的表現形式。當此位元未設定（且位元 PrintDocument 已設定）時，列印僅限於外觀的低階表現形式，可能會降低品質。 |
