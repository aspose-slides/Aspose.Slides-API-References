## CompressionLevel 列舉

指定 OpenXML 檔案的 ZIP 壓縮等級。較高的等級可提供更好的壓縮效果，但會降低處理速度。

```csharp
public enum CompressionLevel
```

### 值

| 名稱 | 值 | 說明 |
| --- | --- | --- |
| None | `0` | 未套用壓縮。檔案保持原樣儲存。 |
| Level1 | `1` | 最快的壓縮且壓縮比最低。 |
| Level2 | `2` | 比 Level1 更快的壓縮，且壓縮比略有提升。 |
| Level3 | `3` | 比 Level2 提供更好的壓縮，且對效能影響適中。 |
| Level4 | `4` | 比 Level3 提供更好的壓縮。 |
| Level5 | `5` | 比 Level4 有更佳的壓縮，但需要額外的處理時間。 |
| Level6 | `6` | 標準壓縮，於壓縮速度與檔案大小之間取得良好平衡。為預設的壓縮等級。 |
| Level7 | `7` | 比 Level6 提供更高的壓縮，但處理速度較慢。 |
| Level8 | `8` | 比 Level7 提供更高的壓縮。 |
| Level9 | `9` | 最大壓縮。產生最小的檔案大小，但處理速度最慢。 |
