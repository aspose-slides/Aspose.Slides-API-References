## IMathMatrix インターフェイス

行と列が 1 つ以上ある子要素で構成された Matrix オブジェクトを指定します。Matrix には組み込みのデリミタがないことに注意することが重要です。Matrix を括弧で囲むには、デリミタオブジェクト (IMathDelimiter) を使用する必要があります。Null 引数を使用して Matrix に空白を作成できます。

```csharp
public interface IMathMatrix : IMathElement
```
