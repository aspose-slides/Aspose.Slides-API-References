## Compress.CompressImages メソッド

プレゼンテーション内の画像の解像度を下げ、トリミングされた領域を削除します。これは、PowerPoint の「Compress Pictures」をすべての画像に適用したものに相当します。スライド、レイアウトスライド、マスタースライド上の画像、グループ シェイプ内の画像やシェイプの画像塗りつぶしも処理されます。

```csharp
public static void CompressImages(IPresentation presentation, PicturesCompression resolution)
```

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| presentation | IPresentation | 処理対象のプレゼンテーション。 |
| resolution | PicturesCompression | 各画像が表示されるサイズに対する目標解像度。DocumentResolution を指定すると画像は変更されません。 |

### 例外

| 例外 | 条件 |
| --- | --- |
| ArgumentNullException | *presentation* は `null` です。 |

### 備考

目標解像度以下の画像は変更されず、そのまま残ります。画像が拡大されることはありません。

処理対象外: スライドの背景、テーブルセルの塗りつぶし、チャート、SmartArt、アニメーションを保持するための GIF 画像、SVG およびメタファイル (EMF/WMF) 画像。

トリミングされた領域は永久に削除され、PowerPoint では復元できません。

### 例

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    CompressImages(pres, PicturesCompression.Dpi150);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
