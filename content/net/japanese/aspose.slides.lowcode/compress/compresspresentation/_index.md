## Compress.CompressPresentation メソッド

利用可能なすべての圧縮手順を適用してプレゼンテーションのサイズを縮小します:

* 未使用のマスタースライドを削除します [`RemoveUnusedMasterSlides`](../removeunusedmasterslides)。
* 未使用のレイアウトスライドを削除します [`RemoveUnusedLayoutSlides`](../removeunusedlayoutslides)。
* 埋め込みフォントで実際に使用されているグリフのみを保持します [`CompressEmbeddedFonts`](../compressembeddedfonts)。
* 画像の解像度を 150 DPI に減らし、画像の切り抜かれた領域を削除します [`CompressImages`](../compressimages)。

```csharp
public static void CompressPresentation(Presentation presentation)
```

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| presentation | Presentation | 圧縮対象のプレゼンテーション。 |

### 例外

| 例外 | 条件 |
| --- | --- |
| ArgumentNullException | *presentation* が `null` です。 |

### 備考

圧縮をカスタマイズする場合、たとえば異なる画像解像度を使用したり手順をスキップしたりするには、このメソッドの代わりに上記のメソッドを個別に呼び出します。画像の切り抜かれた領域は永久に削除され、PowerPoint では復元できません。

### 例

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    Aspose.Slides.LowCode.Compress.CompressPresentation(pres);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
