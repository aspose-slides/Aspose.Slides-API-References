## IChartSeriesGroup.GapDepth プロパティ

取得または設定します。このプロパティは、3D チャートにおけるデータ系列間の距離をマーカー幅のパーセンテージで表します。値は 0 から 500 の間でなければなりません。読み取り/書き込み UInt16。

```csharp
public ushort GapDepth { get; set; }
```

### 備考
