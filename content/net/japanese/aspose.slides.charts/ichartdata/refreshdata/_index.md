## IChartData.RefreshData メソッド

ソースブックから再読み込みすることにより、チャート データを更新します。

```csharp
public void RefreshData()
```

### 例外

| 例外 | 条件 |
| --- | --- |
| InvalidOperationException | サポートされていないブック形式の場合、または [`DataSourceType`](../datasourcetype) が ExternalWorkbook で外部ブックにアクセスできない、または読み込めない場合にスローされます。 |

### 備考

チャートが外部ブックを使用している場合、呼び出し時にブックにアクセス可能である必要があります。

### 例

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
