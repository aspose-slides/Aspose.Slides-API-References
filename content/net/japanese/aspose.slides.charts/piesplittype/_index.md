## PieSplitType 列挙型

pie-of-pie または bar-of-pie グラフの第二の円または棒における分割ポイントのタイプを表します。

```csharp
public enum PieSplitType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Default | `0` | データ ポイントはこのチャート タイプのデフォルト メカニズムを使用して分割されることを指定します。 |
| Custom | `1` | データ ポイントはカスタム スプリット値に従って、円と第二のチャートの間で分割されることを指定します。 |
| ByPercentage | `2` | データ ポイントは、パーセンテージが Split Position パーセント未満のポイントを第二のチャートに配置することにより分割されることを指定します。 |
| ByPos | `3` | データ ポイントは、データ ポイントの最後の Split Position を第二のチャートに配置することにより分割されることを指定します。 |
| ByValue | `4` | データ ポイントは、値が Split Position 未満のデータ ポイントを第二のチャートに配置することにより分割されることを指定します。 |
