## ChartData.RefreshData メソッド

ソース ワークブックから再読み込みして、チャート データを更新します。

```csharp
public void RefreshData()
```

### 例外

| 例外 | 条件 |
| --- | --- |
| InvalidOperationException | ワークブック形式がサポートされていない場合、または[`DataSourceType`](../datasourcetype)がExternalWorkbookで外部ワークブックにアクセスできない、または読み込めない場合にスローされます。 |

### 備考

チャートが外部ワークブックを使用している場合、呼び出し時にワークブックにアクセスできる必要があります。

### 例

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
