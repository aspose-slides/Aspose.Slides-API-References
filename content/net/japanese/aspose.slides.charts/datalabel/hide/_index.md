## DataLabel.Hide メソッド

すべての Show*-フラグ（ShowValue、...）を false に設定することでデータ ラベルを非表示にします。IsVisible はこの後 false になります。

```csharp
public void Hide()
```

### 備考

データ ラベルが表示されていない場合（IsVisible が false のとき）、Show*-フラグ（ShowValue、...）を true に設定することでデータ ラベルを表示できます。
