## IChartCategory.CachedValue プロパティ

チャートカテゴリのキャッシュされた値を取得します。読み取り専用 [`ICachedChartValue`](../../icachedchartvalue)。

```csharp
public ICachedChartValue CachedValue { get; }
```

### 例

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[0];
    
    // すべてのキャッシュされたチャートカテゴリの値を出力します。
    foreach (var category in chart.ChartData.Categories)
        Console.WriteLine(category.CachedValue.ToString());
}
```
