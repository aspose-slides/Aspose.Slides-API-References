## EmbeddingLevel 列挙型

フォントを埋め込むためのライセンス権利を表します。

```csharp
[Flags]
public enum EmbeddingLevel : ushort
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Installable | `0` | この設定のフォントは、アプリケーションによってリモートシステムに埋め込まれ、永続的にインストールできることを示します。リモートシステムのユーザーは、そのフォントについて元の購入者と同じ権利、義務、ライセンスを取得し、元の購入者と同一のエンドユーザー使用許諾契約、著作権、意匠特許、または商標の対象となります。 |
| Restricted | `2` | このビットだけが設定されているフォントは、法的所有者の許可を事前に取得せずに、いかなる方法でも変更、埋め込み、または交換してはなりません。 |
| PreviewPrint | `4` | このビットが設定されている場合、フォントは埋め込むことができ、リモートシステムに一時的にロードされます。プレビュー &amp; 印刷フォントを含むドキュメントは "read-only;" で開く必要があり、ドキュメントへの編集は行えません。 |
| Editable | `8` | このビットが設定されている場合、フォントは埋め込むことができますが、他のシステムには一時的にのみインストールする必要があります。プレビュー &amp; 印刷フォントとは対照的に、Editable フォントを含むドキュメントは読み取り用に開くことができ、編集が許可され、変更を保存できます。 |
| NoSubsetting | `100` | このビットが設定されている場合、埋め込む前にフォントをサブセット化することはできません。ビット0-3および9で指定された他の埋め込み制限も適用されます。 |
| BitmapOnly | `200` | このビットが設定されている場合、フォントに含まれるビットマップのみが埋め込むことができます。アウトラインデータは埋め込むことができません。フォントにビットマップが全く含まれていない場合、そのフォントは埋め込み不可とみなされ、埋め込みサービスは失敗します。 |
