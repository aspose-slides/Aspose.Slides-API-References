## PdfAccessPermissions wyliczenie

Zawiera zestaw flag określających, które uprawnienia dostępu powinny zostać przyznane, gdy dokument zostanie otwarty z dostępem użytkownika.

```csharp
[Flags]
public enum PdfAccessPermissions
```

### Wartości

| Nazwa | Wartość | Opis |
| --- | --- | --- |
| None | `0` | Określa, że użytkownik nie ma uprawnień dostępu. |
| PrintDocument | `4` | Określa, czy użytkownik może drukować dokument (być może nie w najwyższej jakości, w zależności od tego, czy bit HighQualityPrint jest również ustawiony). |
| ModifyContent | `8` | Określa, czy użytkownik może modyfikować zawartość dokumentu poprzez operacje inne niż te kontrolowane przez bity AddOrModifyFields, FillExistingFields, AssembleDocument. |
| CopyTextAndGraphics | `10` | Określa, czy użytkownik może kopiować lub w inny sposób wyodrębniać tekst i grafikę z dokumentu poprzez operacje inne niż te kontrolowane przez bit ExtractTextAndGraphics. |
| AddOrModifyFields | `20` | Określa, czy użytkownik może dodawać lub modyfikować adnotacje tekstowe, wypełniać interaktywne pola formularzy oraz, jeśli bit ModifyContent jest również ustawiony, tworzyć lub modyfikować interaktywne pola formularzy (w tym pola podpisu). |
| FillExistingFields | `100` | Określa, czy użytkownik może wypełniać istniejące interaktywne pola formularzy (w tym pola podpisu), nawet jeśli bit AddOrModifyFields jest wyczyszczony. |
| ExtractTextAndGraphics | `200` | Określa, czy użytkownik może wyodrębniać tekst i grafikę w celu zapewnienia dostępności dla osób niepełnosprawnych lub w innych celach. |
| AssembleDocument | `400` | Określa, czy użytkownik może składać dokument (wstawiać, obracać lub usuwać strony oraz tworzyć zakładki lub miniatury), nawet jeśli bit ModifyContent jest wyczyszczony. |
| HighQualityPrint | `800` | Określa, czy użytkownik może drukować dokument do reprezentacji, z której można wygenerować wierną cyfrową kopię zawartości PDF. Gdy ten bit jest wyczyszczony (i bit PrintDocument jest ustawiony), drukowanie jest ograniczone do niskopoziomowej reprezentacji wyglądu, być może o obniżonej jakości. |
