## IDataLabelCollection.DefaultLabelShapeType właściwość

Pobiera lub ustawia domyślny typ kształtu etykiet danych. Zwraca NotDefined, jeśli nie określono kształtu.

```csharp
public ShapeType DefaultLabelShapeType { get; set; }
```

### Uwagi

Ustawienie tej właściwości ustawia również właściwość [`LabelShapeType`](../../idatalabel/labelshapetype) dla wszystkich etykiet danych w kolekcji na tę samą wartość.

### Przykłady

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[1];
    var firstSeries = chart.ChartData.Series[0];

    // Ustaw typ kształtu wszystkich etykiet danych w pierwszej serii na Ellipse.
    firstSeries.Labels.DefaultLabelShapeType = ShapeType.Ellipse;

    pres.Save("ChartWithEllipseLabels.pptx", SaveFormat.Pptx);
}
```
