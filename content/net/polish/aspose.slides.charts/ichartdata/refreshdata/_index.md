## IChartData.RefreshData metoda

Odświeża dane wykresu, ponownie ładując je z źródłowego skoroszytu.

```csharp
public void RefreshData()
```

### Wyjątki

| wyjątek | warunek |
| --- | --- |
| InvalidOperationException | Rzucany, gdy format skoroszytu nie jest obsługiwany lub gdy [`DataSourceType`](../datasourcetype) jest ExternalWorkbook i zewnętrzny skoroszyt nie może zostać dostępny lub załadowany. |

### Uwagi

Jeśli wykres używa zewnętrznego skoroszytu, skoroszyt musi być dostępny w momencie wywołania.

### Przykłady

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
