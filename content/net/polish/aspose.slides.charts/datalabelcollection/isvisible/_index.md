## DataLabelCollection.IsVisible właściwość

False oznacza, że etykieta danych nie jest domyślnie widoczna (i dlatego wszystkie flagi Show*-flags (ShowValue, ...) właściwości DefaultDataLabelFormat są ustawione na false). Tylko do odczytu Boolean.

```csharp
public bool IsVisible { get; }
```

### Uwagi

Jeśli etykieta danych jest domyślnie widoczna, możesz ukryć ją domyślnie metodą Hide(). Jednak jeśli etykieta danych nie jest domyślnie widoczna (IsVisible jest false), możesz ustawić etykietę danych „widoczną domyślnie” ustawiając flagi Show*-flags (ShowValue, ...) właściwości DefaultDataLabelFormat na stan true.
