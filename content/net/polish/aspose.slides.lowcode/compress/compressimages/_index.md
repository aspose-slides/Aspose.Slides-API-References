## Compress.CompressImages metoda

Zmniejsza rozdzielczość obrazów w prezentacji i usuwa ich przycięte obszary, podobnie jak funkcja „Compress Pictures” w PowerPoint zastosowana do wszystkich obrazów. Obrazy na slajdach, slajdach układu i slajdach głównych są przetwarzane, w tym obrazy wewnątrz grup kształtów oraz wypełnienia obrazami kształtów.

```csharp
public static void CompressImages(IPresentation presentation, PicturesCompression resolution)
```

| Parametr | Typ | Opis |
| --- | --- | --- |
| presentation | IPresentation | Prezentacja do przetworzenia. |
| resolution | PicturesCompression | Docelowa rozdzielczość w stosunku do rozmiaru, w jakim każdy obraz jest wyświetlany. DocumentResolution pozostawia obrazy niezmienione. |

### Wyjątki

| wyjątek | warunek |
| --- | --- |
| ArgumentNullException | *presentation* jest `null`. |

### Uwagi

Obrazy już o rozdzielczości równej lub niższej od docelowej pozostają niezmienione; obrazy nigdy nie są skalowane w górę.

Nie przetwarzane: tła slajdów, wypełnienia komórek tabel, wykresy, SmartArt, obrazy GIF (aby zachować animację), obrazy SVG oraz metafile (EMF/WMF).

Przycięte obszary są usuwane trwale i nie mogą zostać przywrócone w programie PowerPoint.

### Przykłady

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    CompressImages(pres, PicturesCompression.Dpi150);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
