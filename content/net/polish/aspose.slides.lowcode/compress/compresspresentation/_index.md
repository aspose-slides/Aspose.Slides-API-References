## Metoda Compress.CompressPresentation

Zmniejsza rozmiar prezentacji, stosując wszystkie dostępne kroki kompresji:

* Usuwa nieużywane slajdy wzorcowe [`RemoveUnusedMasterSlides`](../removeunusedmasterslides).
* Usuwa nieużywane slajdy układu [`RemoveUnusedLayoutSlides`](../removeunusedlayoutslides).
* Zachowuje tylko glify faktycznie użyte w osadzonych czcionkach [`CompressEmbeddedFonts`](../compressembeddedfonts).
* Zmniejsza rozdzielczość obrazów do 150 DPI i usuwa przycięte fragmenty obrazów [`CompressImages`](../compressimages).

```csharp
public static void CompressPresentation(Presentation presentation)
```

| Parametr | Typ | Opis |
| --- | --- | --- |
| presentation | Presentation | Prezentacja do kompresji. |

### Wyjątki

| wyjątek | warunek |
| --- | --- |
| ArgumentNullException | *presentation* jest `null`. |

### Uwagi

Aby dostosować kompresję, na przykład używać innej rozdzielczości obrazu lub pominąć krok, wywołaj wymienione powyżej metody indywidualnie zamiast tej. Przycięte fragmenty obrazów są usuwane trwale i nie mogą zostać przywrócone w programie PowerPoint.

### Przykłady

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    Aspose.Slides.LowCode.Compress.CompressPresentation(pres);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
