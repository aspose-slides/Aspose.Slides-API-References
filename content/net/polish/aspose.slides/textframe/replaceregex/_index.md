## TextFrame.ReplaceRegex method

Zastępuje wszystkie dopasowania wyrażenia regularnego podanym ciągiem znaków.

```csharp
public void ReplaceRegex(Regex regex, string newText, IFindResultCallback callback)
```

| Parametr | Typ | Opis |
| --- | --- | --- |
| regex | Regex | Wyrażenie regularne Regex, które określa ciągi znaków do zastąpienia. |
| newText | String | Ciąg znaków, który zastępuje wszystkie wystąpienia ciągów do zamiany. |
| callback | IFindResultCallback | Obiekt wywołania zwrotnego służący do zapisywania wyniku operacji zamiany [`IFindResultCallback`](../../ifindresultcallback). |

### Przykłady

The following sample code shows how to replace text using regular expression with specified string.

```csharp
[C#]
using (Presentation presentation = new Presentation("SomePresentation.pptx")){
	Regex regex = new Regex(@"\b[^\s]{10,}\b");
	// Zamień wszystkie słowa o 10 lub większej liczbie znaków na '***'
	((AutoShape)presentation.Slides[0].Shapes[0]).TextFrame.ReplaceRegex(regex, "***", null);
	presentation.Save("SomePresentation-out.pptx", SaveFormat.Pptx);
}
```
