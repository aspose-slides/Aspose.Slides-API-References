## GetSubstitutions() {#getsubstitutions}

Pobiera informacje o czcionkach, które zostaną zastąpione podczas renderowania prezentacji.

```csharp
public IEnumerable<FontSubstitutionInfo> GetSubstitutions()
```

### Wartość zwracana

Zbiór wszystkich zastąpień czcionek [`FontSubstitutionInfo`](../../fontsubstitutioninfo).

### Przykłady

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    foreach (var fontSubstitution in pres.FontsManager.GetSubstitutions())
    {
        Console.WriteLine("{0} -> {1}", fontSubstitution.OriginalFontName, fontSubstitution.SubstitutedFontName);
    }
}        
```

## GetSubstitutions(int[]) {#getsubstitutions_1}

Pobiera informacje o czcionkach, które zostaną zastąpione podczas renderowania określonych slajdów.

```csharp
public IEnumerable<FontSubstitutionInfo> GetSubstitutions(int[] slides)
```

| Parametr | Typ | Opis |
| --- | --- | --- |
| slides | Int32[] | Tablica indeksów slajdów, dla których należy pobrać informacje o zastępowaniu czcionek, zaczynając od 1. |

### Wartość zwracana

Zbiór wszystkich zastąpień czcionek ([`FontSubstitutionInfo`](../../fontsubstitutioninfo)) dla określonych slajdów.

### Przykłady

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    int[] targetSlides = { 1, 2, 5 };
    foreach (var fontSubstitution in pres.FontsManager.GetSubstitutions(targetSlides))
    {
        Console.WriteLine("{0} -> {1}", fontSubstitution.OriginalFontName, fontSubstitution.SubstitutedFontName);
    }
}
```
