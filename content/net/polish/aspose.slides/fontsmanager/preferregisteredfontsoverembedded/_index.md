## FontsManager.PreferRegisteredFontsOverEmbedded właściwość

Określa, czy zarejestrowane czcionki powinny mieć pierwszeństwo przed osadzonymi czcionkami o tej samej nazwie i stylu. Gdy jest włączona, pasujące osadzone czcionki są tymczasowo zastępowane odpowiednimi zarejestrowanymi czcionkami podczas eksportu.

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### Uwagi

Domyślnie jest **false**.

### Przykłady

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
