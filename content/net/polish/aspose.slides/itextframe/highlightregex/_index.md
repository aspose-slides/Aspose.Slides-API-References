## ITextFrame.HighlightRegex metoda

Podświetla wszystkie dopasowania wyrażenia regularnego podanym kolorem.

```csharp
public void HighlightRegex(Regex regex, Color highlightColor, IFindResultCallback callback)
```

| Parametr | Typ | Opis |
| --- | --- | --- |
| regex | Regex | Wyrażenie regularne Regex służące do pobierania ciągów do podświetlenia. |
| highlightColor | Color | Kolor służący do podświetlenia tekstu. |
| callback | IFindResultCallback | Obiekt wywołania zwrotnego służący do odbierania wyników wyszukiwania [`IFindResultCallback`](../../ifindresultcallback). |

### Przykłady

Poniższy przykład kodu pokazuje, jak podświetlić tekst w TextFrame przy użyciu wyrażenia regularnego.

```csharp
[C#]
using (Presentation presentation = new Presentation("SomePresentation.pptx"))
{
	Regex regex = new Regex(@"\b[^\s]{10,}\b");
	// podświetlanie wszystkich wyrazów o długości 10 lub więcej znaków
	((AutoShape)presentation.Slides[0].Shapes[0]).TextFrame.HighlightRegex(regex, Color.Blue, null);
	presentation.Save("SomePresentation-out.pptx", SaveFormat.Pptx);
}
```
