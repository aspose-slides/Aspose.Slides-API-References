## IVideoFrame.VolumeValue właściwość

Zwraca lub ustawia dokładną głośność wideo jako procent. Wartość jest wyrażona jako procent od 0 do 100. Użyj tej właściwości, aby odczytać lub ustawić wartości głośności, które są dokładniejsze niż poziomy predefiniowane dostępne przez właściwość [`Volume`](../volume). Odczyt/zapis Single.

```csharp
public float VolumeValue { get; set; }
```

### Przykłady

Przykład:

```csharp
[C#]
using (Presentation pres = new Presentation("video.pptx"))
{
    IVideoFrame videoFrame = (IVideoFrame)pres.Slides[0].Shapes[0];

    // Odczytaj bieżącą dokładną głośność i ustaw ją na 75.5 procent.
    float currentVolume = videoFrame.VolumeValue;
    videoFrame.VolumeValue = 75.5f;

    pres.Save("video_with_volume.pptx", SaveFormat.Pptx);
}
```
