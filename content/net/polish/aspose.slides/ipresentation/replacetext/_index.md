## IPresentation.ReplaceText metoda

Zastępuje wszystkie wystąpienia określonego tekstu innym określonym tekstem.

```csharp
public void ReplaceText(string oldText, string newText, ITextSearchOptions options, 
    IFindResultCallback callback)
```

| Parametr | Typ | Opis |
| --- | --- | --- |
| oldText | String | Łańcuch, który ma zostać zastąpiony. |
| newText | String | Łańcuch, który zastępuje wszystkie wystąpienia oldText. |
| options | ITextSearchOptions | Opcje wyszukiwania tekstu [`ITextSearchOptions`](../../itextsearchoptions). |
| callback | IFindResultCallback | Obiekt zwrotny służący do odbierania wyników wyszukiwania [`IFindResultCallback`](../../ifindresultcallback). |

### Przykłady

Poniższy przykładowy kod pokazuje, jak zastąpić jeden określony ciąg innym określonym ciągiem.

```csharp
[C#]
using (Presentation presentation = new Presentation("SomePresentation.pptx"))
{
	// Zastąp wszystkie oddzielne wystąpienia słowa 'the' ciągiem '***'
	presentation.ReplaceText("the", "***", new TextSearchOptions() {WholeWordsOnly = true}, null);
	presentation.Save("SomePresentation-out2.pptx", SaveFormat.Pptx);
}
```
