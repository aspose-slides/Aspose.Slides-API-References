## IPresentation.RefreshChartsData metoda

Ponownie wczytuje dane wszystkich wykresów w prezentacji z ich źródłowych skoroszytów.

```csharp
public void RefreshChartsData(bool skipFailedCharts = true)
```

| Parametr | Typ | Opis |
| --- | --- | --- |
| skipFailedCharts | Boolean | Określa, czy proces odświeżania kontynuuje, gdy wykres nie może zostać zaktualizowany. Jeśli `true`, wykresy powodujące wyjątek są pomijane; w przeciwnym razie wyjątek jest propagowany. |

### Przykłady

```csharp
using (var presentation = new Presentation("PresentationWithCharts.pptx"))
{
    presentation.RefreshChartsData();
    presentation.Save("PresentationWithCharts-out.pptx", SaveFormat.Pptx);
}
```
