## DataLabelCollection.DefaultLabelShapeType property

Gets or sets the default shape type for data labels. Returns NotDefined if no shape is defined.

```csharp
public ShapeType DefaultLabelShapeType { get; set; }
```

### Remarks

Setting this property also sets the [`LabelShapeType`](../../idatalabel/labelshapetype) property for all data labels in the collection to the same value.

### Examples

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[1];
    var firstSeries = chart.ChartData.Series[0];

    // Set the shape type of all data labels in the first series to Ellipse.
    firstSeries.Labels.DefaultLabelShapeType = ShapeType.Ellipse;

    pres.Save("ChartWithEllipseLabels.pptx", SaveFormat.Pptx);
}
```
