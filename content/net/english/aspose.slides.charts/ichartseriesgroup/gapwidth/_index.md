## IChartSeriesGroup.GapWidth property

Gets or sets the space between bar or column clusters, as a percentage of the bar or column width. The value must be between 0 and 500. Read/write UInt16.

```csharp
public ushort GapWidth { get; set; }
```

### Remarks

This property applies to series of the following types: All bar and column subtypes, BarOfPie, PieOfPie, BoxAndWhisker, Funnel, Histogram, Waterfall.
