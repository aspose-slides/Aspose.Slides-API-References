## ChartData.RefreshData method

Refreshes the chart data by reloading it from the source workbook.

```csharp
public void RefreshData()
```

### Exceptions

| exception | condition |
| --- | --- |
| InvalidOperationException | Thrown when the workbook format is not supported, or when [`DataSourceType`](../datasourcetype) is ExternalWorkbook and the external workbook cannot be accessed or loaded. |

### Remarks

If the chart uses an external workbook, the workbook must be accessible at the time of the call.

### Examples

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
