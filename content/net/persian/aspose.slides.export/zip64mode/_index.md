## شمارش Zip64Mode

زمان استفاده از افزونه‌های فرمت ZIP64 برای فایل OpenXML را مشخص می‌کند.

```csharp
public enum Zip64Mode
```

### مقادیر

| Name | Value | Description |
| --- | --- | --- |
| Never | `0` | از افزونه‌های فرمت ZIP64 استفاده نکنید. |
| IfNecessary | `1` | در صورت نیاز از افزونه‌های فرمت ZIP64 استفاده کنید. |
| Always | `2` | همیشه از افزونه‌های فرمت ZIP64 استفاده کنید. |

### توضیحات

فایل OpenXML یک آرشیو ZIP است که دارای محدودیت ۴ گیگابایت (۲^۳۲ بایت) برای اندازهٔ غیر فشردهٔ یک فایل، اندازهٔ فشردهٔ یک فایل و اندازهٔ کل آرشیو، همچنین محدودیت ۶۵ ۵۳۵ (۲^۱۶-۱) فایل در آرشیو می‌باشد. افزونه‌های فرمت ZIP64 این محدودیت‌ها را تا ۲^۶۴ افزایش می‌دهند.
