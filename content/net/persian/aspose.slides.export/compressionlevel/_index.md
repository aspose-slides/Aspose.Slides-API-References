## CompressionLevel enum

سطوح فشرده‌سازی ZIP را برای فایل OpenXML مشخص می‌کند. سطوح بالاتر فشرده‌سازی بهتری ارائه می‌دهند، اما پردازش کندتری را به دنبال دارند.

```csharp
public enum CompressionLevel
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| None | `0` | هیچ فشرده‌سازی‌ای اعمال نمی‌شود. فایل‌ها به همان شکل ذخیره می‌شوند. |
| Level1 | `1` | سریع‌ترین فشرده‌سازی با نسبت فشرده‌سازی پایین‌ترین. |
| Level2 | `2` | فشرده‌سازی سریع‌تر با نسبت فشرده‌سازی کمی بهتر نسبت به Level1. |
| Level3 | `3` | فشرده‌سازی بهتری نسبت به Level2 ارائه می‌دهد با تأثیر متوسط بر عملکرد. |
| Level4 | `4` | فشرده‌سازی بهتری نسبت به Level3 ارائه می‌دهد. |
| Level5 | `5` | فشرده‌سازی بهبود یافته نسبت به Level4 ارائه می‌دهد با زمان پردازش بیشتری. |
| Level6 | `6` | فشرده‌سازی استاندارد، تعادل خوبی بین سرعت فشرده‌سازی و اندازه فایل ارائه می‌دهد. سطح فشرده‌سازی پیش‌فرض. |
| Level7 | `7` | فشرده‌سازی بالاتری نسبت به Level6 ارائه می‌دهد با پردازش کندتر. |
| Level8 | `8` | فشرده‌سازی بالاتری نسبت به Level7 ارائه می‌دهد. |
| Level9 | `9` | حداکثر فشرده‌سازی. کوچک‌ترین اندازه فایل را با کندترین سرعت پردازش تولید می‌کند. |
