## ExternalResourceResolver کلاس

کلاس Callback برای حل منابع خارجی در هنگام وارد کردن اسناد Html و Svg استفاده می‌شود. استفاده از این حل‌کننده می‌تواند خطرات امنیتی ایجاد کند زمانی که فایل HTML یا SVG ارائه‌شده توسط مشتری باعث می‌شود نرم‌افزار سرور به فایل‌های محلی یا شبکه‌ای دسترسی پیدا کند. با احتیاط استفاده کنید. توصیه می‌شود ExternalResourceResolver را به‌طور کامل مشخص نکنید (فقط اشیای ضمیمه شده خوانده می‌شوند) یا زیرکلاسی ایجاد کنید که بررسی کند آیا uri مشخص شده معتبر است.

```csharp
public class ExternalResourceResolver : IExternalResourceResolver
```
