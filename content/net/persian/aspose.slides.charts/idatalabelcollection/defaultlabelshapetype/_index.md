## IDataLabelCollection.DefaultLabelShapeType ویژگی

دریافت یا تنظیم نوع شکل پیش‌فرض برای برچسب‌های داده. در صورت عدم تعریف شکل، مقدار NotDefined برگردانده می‌شود.

```csharp
public ShapeType DefaultLabelShapeType { get; set; }
```

### توضیحات

تنظیم این ویژگی همچنین ویژگی [`LabelShapeType`](../../idatalabel/labelshapetype) را برای همه برچسب‌های داده در مجموعه به همان مقدار تنظیم می‌کند.

### مثال‌ها

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[1];
    var firstSeries = chart.ChartData.Series[0];

    // نوع شکل تمام برچسب‌های داده در سری اول را به Ellipse تنظیم می‌کند.
    firstSeries.Labels.DefaultLabelShapeType = ShapeType.Ellipse;

    pres.Save("ChartWithEllipseLabels.pptx", SaveFormat.Pptx);
}
```
