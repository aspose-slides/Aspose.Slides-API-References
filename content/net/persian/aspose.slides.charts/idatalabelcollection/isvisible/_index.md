## IDataLabelCollection.IsVisible ویژگی

False به این معنی است که برچسب داده به طور پیش‌فرض قابل مشاهده نیست (و بنابراین تمام Show*-flags (ShowValue, ...) از ویژگی DefaultDataLabelFormat برابر false هستند). فقط خواندنی Boolean.

```csharp
public bool IsVisible { get; }
```

### توضیحات

اگر برچسب داده به طور پیش‌فرض قابل مشاهده باشد، می‌توانید آن را به‌طور پیش‌فرض پنهان کنید با استفاده از متد Hide(). اما اگر برچسب داده به طور پیش‌فرض قابل مشاهده نباشد (IsVisible برابر false است) می‌توانید برچسب داده را به «قابل مشاهده به‌طور پیش‌فرض» تبدیل کنید با تنظیم Show*-flags (ShowValue, ...) از ویژگی DefaultDataLabelFormat به حالت true.
