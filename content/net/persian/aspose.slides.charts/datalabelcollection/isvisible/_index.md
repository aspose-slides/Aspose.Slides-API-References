## خصوصیت DataLabelCollection.IsVisible

False به این معنی است که برچسب داده به طور پیش‌فرض قابل مشاهده نیست (و بنابراین همه Show*-flags (ShowValue, ...) از ویژگی DefaultDataLabelFormat نیز false هستند). فقط-خواندنی Boolean.

```csharp
public bool IsVisible { get; }
```

### توضیحات

اگر برچسب داده به طور پیش‌فرض قابل مشاهده باشد، می‌توانید با متد Hide() آن را به‌صورت پیش‌فرض مخفی کنید. اما اگر برچسب داده به طور پیش‌فرض قابل مشاهده نباشد (IsVisible برابر false است) می‌توانید با تنظیم Show*-flags (ShowValue, ...) از ویژگی DefaultDataLabelFormat به حالت true، برچسب داده را «به طور پیش‌فرض قابل مشاهده» کنید.
