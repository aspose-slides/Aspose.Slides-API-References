## SetExternalWorkbook(string) {#setexternalworkbook}

یک کتاب کار خارجی را به عنوان منبع داده برای نمودار تنظیم می‌کند. داده‌های نمودار از کتاب کار هدف به‌روزرسانی می‌شوند.

```csharp
public void SetExternalWorkbook(string workbookPath)
```

| Parameter | Type | Description |
| --- | --- | --- |
| workbookPath | String | مسیر به کتاب کار هدف |

### استثناها

| استثنا | شرط |
| --- | --- |
| InvalidOperationException | کتاب کار خارجی در دسترس نیست یا نمی‌تواند بارگذاری شود. |

### مثال‌ها

```csharp
[C#]
using (Presentation pres = new Presentation())

   IChart chart = pres.Slides[0].Shapes.AddChart(ChartType.Pie, 50, 50, 400, 600, true);
   IChartData chartData = chart.ChartData;
   (chartData as ChartData).SetExternalWorkbook("../../workbook.xlsx");

```

## SetExternalWorkbook(string, bool) {#setexternalworkbook_1}

یک کتاب کار خارجی را به عنوان منبع داده برای نمودار تنظیم می‌کند.

```csharp
public void SetExternalWorkbook(string workbookPath, bool updateChartData)
```

| Parameter | Type | Description |
| --- | --- | --- |
| workbookPath | String | مسیر به کتاب کار هدف |
| updateChartData | Boolean | اگر مقدار false باشد فقط مسیر کتاب کار به‌روزرسانی می‌شود. داده‌های نمودار بارگذاری و به‌روزرسانی نمی‌شوند. می‌توان از آن زمانی استفاده کرد که کتاب کار هدف وجود نداشته باشد یا در دسترس نباشد. اگر مقدار true باشد داده‌های نمودار از کتاب کار هدف به‌روزرسانی می‌شود. |
