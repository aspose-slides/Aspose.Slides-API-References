## IChartData.RefreshData متد

داده‌های نمودار را با بارگذاری مجدد از کتاب‌کار منبع تازه‌سازی می‌کند.

```csharp
public void RefreshData()
```

### استثناها

| استثنا | شرط |
| --- | --- |
| InvalidOperationException | زمانی که فرمت کتاب‌کار پشتیبانی نمی‌شود یا زمانی که [`DataSourceType`](../datasourcetype) برابر با ExternalWorkbook است و کتاب‌کار خارجی قابل دسترسی یا بارگذاری نیست، استثنا رخ می‌دهد. |

### توضیحات

اگر نمودار از یک کتاب‌کار خارجی استفاده کند، کتاب‌کار باید در زمان فراخوانی قابل دسترسی باشد.

### مثال‌ها

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
