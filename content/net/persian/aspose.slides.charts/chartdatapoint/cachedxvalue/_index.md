## ChartDataPoint.CachedXValue ویژگی

مقدار X ذخیره‌شده یک نقطه دادهٔ نمودار را دریافت می‌کند. فقط خواندنی [`ICachedChartValue`](../../icachedchartvalue).

```csharp
public ICachedChartValue CachedXValue { get; }
```

### مثال‌ها

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[0];
    foreach (var series in chart.ChartData.Series)
    {
        // تمام مقادیر X ذخیره‌شدهٔ سری نمودار را چاپ می‌کند.
        foreach (var point in series.DataPoints)
            Console.WriteLine(point.CachedXValue.ToDouble());
    }
}
```
