## ChartCategory.UseCell ویژگی

اگر مقدار true باشد، ویژگی AsCell فعال است. به عبارت دیگر، worksheet برای ذخیره‌سازی دسته استفاده می‌شود (این حالت از دسته‌بندی چندسطحی پشتیبانی می‌کند). اگر مقدار false باشد، ویژگی AsLiteral فعال است. به عبارت دیگر، worksheet برای ذخیره‌سازی دسته استفاده نمی‌شود (و این حالت از دسته‌بندی‌های چندسطحی پشتیبانی نمی‌کند). فقط-خواندنی Boolean.

```csharp
public bool UseCell { get; }
```

### توضیحات

برای تغییر مقدار این ویژگی (برای همه دسته‌ها در مجموعه) مقدار جدید را به ویژگی ChartCategoryCollection.UseCells تنظیم کنید.
