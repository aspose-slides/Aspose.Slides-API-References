## ChartData.RefreshData متد

داده‌های نمودار را با بارگیری مجدد از دفتر کار منبع تازه‌سازی می‌کند.

```csharp
public void RefreshData()
```

### استثناها

| استثنا | شرط |
| --- | --- |
| InvalidOperationException | در صورتی که قالب دفتر کار پشتیبانی نشود یا وقتی [`DataSourceType`](../datasourcetype) به عنوان ExternalWorkbook باشد و دفتر کار خارجی قابل دسترسی یا بارگیری نباشد، پرتاب می‌شود. |

### توضیحات

اگر نمودار از دفتر کار خارجی استفاده کند، دفتر کار باید در زمان فراخوانی قابل دسترسی باشد.

### مثال‌ها

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
