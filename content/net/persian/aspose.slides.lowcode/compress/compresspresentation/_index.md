## Compress.CompressPresentation متد

حجم یک ارائه را با اعمال تمام مراحل فشرده‌سازی موجود کاهش می‌دهد:

* اسلایدهای اصلی استفاده نشده [`RemoveUnusedMasterSlides`](../removeunusedmasterslides) را حذف می‌کند.
* اسلایدهای طرح‌بندی استفاده نشده [`RemoveUnusedLayoutSlides`](../removeunusedlayoutslides) را حذف می‌کند.
* تنها نمادهای واقعاً در قلم‌های جاسازی‌شده استفاده شده را نگه می‌دارد [`CompressEmbeddedFonts`](../compressembeddedfonts).
* رزولوشن تصویر را به 150 DPI کاهش می‌دهد و نواحی برش‌خورده‌ی تصاویر را حذف می‌کند [`CompressImages`](../compressimages).

```csharp
public static void CompressPresentation(Presentation presentation)
```

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| presentation | Presentation | ارائه‌ای که باید فشرده شود. |

### استثناها

| استثنا | شرط |

### توضیحات

برای سفارشی‌سازی فشرده‌سازی، به عنوان مثال برای استفاده از رزولوشن تصویر متفاوت یا برای عبور از یک مرحله، به‌جای این متد، متدهای فهرست‌شده در بالا را به‌صورت جداگانه صدا بزنید. نواحی برش‌خورده‌ی تصاویر به‌صورت دائمی حذف می‌شوند و در PowerPoint قابل بازگرداندن نیستند.

### مثال‌ها

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    Aspose.Slides.LowCode.Compress.CompressPresentation(pres);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
