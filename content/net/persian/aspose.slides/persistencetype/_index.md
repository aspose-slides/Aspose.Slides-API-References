## شمارش PersistenceType

روشی را که برای ذخیرهٔ ویژگی‌های کنترل ActiveX استفاده می‌شود، تعیین می‌کند.

```csharp
public enum PersistenceType
```

### مقادیر

| نام | مقدار | توضیح |
| --- | --- | --- |
| NotDefined | `-1` | شناسهٔ persistence مشخص نشده است. |
| PersistPropertyBag | `0` | مشخص می‌کند که کنترل ActiveX با استفاده از persistence مبتنی بر property-bag ذخیره می‌شود. persistence مبتنی بر property-bag یک کنترل ActiveX را از طریق مجموعه‌ای از جفت‌های نام و مقدار که داده‌های ذخیره‌شده توسط کنترل ActiveX را مشخص می‌کنند، ذخیره می‌کند. |
| PersistStream | `1` | مشخص می‌کند که کنترل ActiveX با استفاده از persistence مبتنی بر stream ذخیره می‌شود که از مقداردهی اولیهٔ کنترل ActiveX به حالت پیش‌فرض پشتیبانی نمی‌کند. |
| PersistStreamInit | `2` | مشخص می‌کند که کنترل ActiveX با استفاده از persistence مبتنی بر stream ذخیره می‌شود که از مقداردهی اولیهٔ کنترل ActiveX به حالت پیش‌فرض پشتیبانی می‌کند. |
| PersistStorage | `3` | مشخص می‌کند که کنترل ActiveX با استفاده از persistence مبتنی بر storage ذخیره می‌شود. |
