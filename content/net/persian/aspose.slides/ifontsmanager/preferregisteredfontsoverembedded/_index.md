## IFontsManager.PreferRegisteredFontsOverEmbedded ویژگی

مشخص می‌کند که آیا فونت‌های ثبت‌شده باید نسبت به فونت‌های جاسازی‌شده با نام و سبک یکسان ترجیح داده شوند یا خیر. وقتی فعال باشد، فونت‌های جاسازی‌شده‌ی مطابق به‌صورت موقت با فونت‌های ثبت‌شده‌ی متناظر در طول عملیات خروجی جایگزین می‌شوند.

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### توضیحات

مقدار پیش‌فرض **false** است.

### مثال‌ها

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
