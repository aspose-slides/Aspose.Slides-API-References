## IFontsManager.GetFontEmbeddingLevel method

سطح جاسازی یک فونت را از آرایه بایت داده شده و نام فونت تعیین می‌کند.

```csharp
public EmbeddingLevel GetFontEmbeddingLevel(byte[] fontBytes, string fontName)
```

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| fontBytes | Byte[] | آرایه بایت حاوی داده‌های فونت. |
| fontName | String | نام فونت. |

### مقدار بازگشتی

سطح جاسازی فونت مشخص شده.

### استثناها

| استثنا | شرط |
| --- | --- |
| ArgumentNullException | در صورتی که *fontBytes* برابر null باشد، پرتاب می‌شود. |

### مثال‌ها

```csharp
[C#]
using (Presentation pres = new Presentation(pptxFileName))
{
    // تمام فونت‌های استفاده‌شده در ارائه را بازیابی کنید
    IFontData[] fontDatas = pres.FontsManager.GetFonts();

    // آرایه بایتی که نمایانگر سبک معمولی اولین فونت در ارائه است را دریافت کنید
    byte[] bytes = pres.FontsManager.GetFontBytes(fontDatas[0], FontStyle.Regular);

    // سطح جاسازی فونت را تعیین کنید
    EmbeddingLevel embeddingLevel = pres.FontsManager.GetFontEmbeddingLevel(bytes, fontDatas[0].FontName);
}
```
