## IVideoFrame.VolumeValue ویژگی

دریافت یا تنظیم دقیق حجم ویدیو به صورت درصدی. مقدار به صورت درصدی از 0 تا 100 بیان می‌شود. از این ویژگی برای خواندن یا تنظیم مقادیر حجمی که دقیق‌تر از سطوح پیش‌تعریف‌شدهٔ موجود از طریق ویژگی [`Volume`](../volume) هستند استفاده کنید. خواندن/نوشتن Single.

```csharp
public float VolumeValue { get; set; }
```

### مثال‌ها

مثال:

```csharp
[C#]
using (Presentation pres = new Presentation("video.pptx"))
{
    IVideoFrame videoFrame = (IVideoFrame)pres.Slides[0].Shapes[0];

    // خواندن حجم دقیق فعلی و تنظیم آن به 75.5 درصد.
    float currentVolume = videoFrame.VolumeValue;
    videoFrame.VolumeValue = 75.5f;

    pres.Save("video_with_volume.pptx", SaveFormat.Pptx);
}
```
