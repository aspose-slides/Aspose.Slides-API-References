## PresentationLockingBehavior شمارش

رفتار مربوط به نحوهٔ برخورد با منبع [`IPresentation`](../ipresentation) (فایل یا Stream) هنگام بارگذاری و کار با یک نمونهٔ [`IPresentation`](../ipresentation) را توصیف می‌کند.

```csharp
public enum PresentationLockingBehavior
```

### مقادیر

| نام | مقدار | توضیحات |
| --- | --- | --- |
| LoadAndRelease | `0` | منبع فقط برای مدت اجرای سازندهٔ [`IPresentation`](../ipresentation) قفل خواهد شد. اگر [`IsTemporaryFilesAllowed`](../iblobmanagementoptions/istemporaryfilesallowed) برابر false تنظیم شود، تمام BLOBها در حافظه بارگذاری می‌شوند. در غیر این صورت، ممکن است روش‌های دیگری مانند فایل‌های موقت استفاده شوند. این رفتار نسبت به KeepLocked کندتر است و اگر امکان انتقال مالکیت منبع به [`IPresentation`](../ipresentation) وجود داشته باشد، استفاده از KeepLocked توصیه می‌شود. |
| KeepLocked | `1` | منبع برای تمام دورهٔ حیات نمونهٔ [`IPresentation`](../ipresentation) قفل می‌ماند، تا زمانی که آن تخلیه شود. برای استفاده از این رفتار، باید [`IsTemporaryFilesAllowed`](../iblobmanagementoptions/istemporaryfilesallowed) برابر true تنظیم شود؛ در غیر این صورت استثنایی پرتاب خواهد شد. این رفتار توصیه می‌شود، سریع‌تر است و نسبت به LoadAndRelease حافظه کمتری مصرف می‌کند. |

### توضیحات

منبع، پارامتری است که به سازندهٔ [`IPresentation`](../ipresentation) پاس داده می‌شود. در مثال زیر، منبع فایل "pres.pptx" است:

```csharp
LoadOptions loadOptions = new LoadOptions { 
  BlobManagementOptions = { PresentationLockingBehavior = PresentationLockingBehavior.KeepLocked } };
using (IPresentation pres = new Presentation("pres.pptx", loadOptions)) { }
```

در این مثال، منبع (فایل "pres.pptx") برای تمام دورهٔ حیات نمونهٔ [`IPresentation`](../ipresentation) قفل می‌ماند، یعنی توسط پردازش دیگر نمی‌تواند تغییر یا حذف شود.
