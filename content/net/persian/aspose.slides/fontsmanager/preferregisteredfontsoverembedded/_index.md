## FontsManager.PreferRegisteredFontsOverEmbedded ویژگی

مشخص می‌کند آیا فونت‌های ثبت‌شده باید نسبت به فونت‌های جاسازی‌شده با همان نام و استایل فونت ترجیح داده شوند یا خیر. وقتی فعال باشد، فونت‌های جاسازی‌شدهٔ منطبق به‌صورت موقت با فونت‌های ثبت‌شدهٔ متناظر در طول خروجی جایگزین می‌شوند.

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### توضیحات

پیش‌فرض **false** است.

### مثال‌ها

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
