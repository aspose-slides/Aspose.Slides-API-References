## GetSubstitutions() {#getsubstitutions}

اطلاعات مربوط به قلم‌هایی که در رندر ارائه جایگزین خواهند شد را دریافت می‌کند.

```csharp
public IEnumerable<FontSubstitutionInfo> GetSubstitutions()
```

### مقدار بازگشتی

مجموعه‌ای از همه جایگزینی‌های قلم [`FontSubstitutionInfo`](../../fontsubstitutioninfo).

### مثال‌ها

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    foreach (FontSubstitutionInfo fontSubstitution in pres.FontsManager.GetSubstitutions())
    {
        Console.WriteLine("{0} -> {1}", fontSubstitution.OriginalFontName, fontSubstitution.SubstitutedFontName);
    }
}        
```

## GetSubstitutions(int[]) {#getsubstitutions_1}

اطلاعات مربوط به قلم‌هایی که در رندر اسلایدهای مشخص شده جایگزین می‌شوند را دریافت می‌کند.

```csharp
public IEnumerable<FontSubstitutionInfo> GetSubstitutions(int[] slides)
```

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| slides | Int32[] | یک آرایه از شاخص‌های اسلایدهایی که اطلاعات جایگزینی قلم برای آن‌ها بازیابی می‌شود، شروع از 1. |

### مقدار بازگشتی

یک مجموعه از تمام جایگزینی‌های قلم ([`FontSubstitutionInfo`](../../fontsubstitutioninfo)) برای اسلایدهای مشخص شده.

### مثال‌ها

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    int[] targetSlides = { 1, 2, 5 };
    foreach (var fontSubstitution in pres.FontsManager.GetSubstitutions(targetSlides))
    {
        Console.WriteLine("{0} -> {1}", fontSubstitution.OriginalFontName, fontSubstitution.SubstitutedFontName);
    }
}
```
