## FontsManager.GetFontEmbeddingLevel متد

سطح جاسازی یک قلم را بر اساس آرایه بایت داده‌شده و نام قلم تعیین می‌کند.

```csharp
public EmbeddingLevel GetFontEmbeddingLevel(byte[] fontBytes, string fontName)
```

| پارامتر | نوع | توضیحات |
| --- | --- | --- |
| fontBytes | Byte[] | آرایه بایتی که حاوی داده‌های قلم است. |
| fontName | String | نام قلم. |

### مقدار بازگشت

سطح جاسازی قلم مشخص‌شده.

### استثناها

| exception | condition |
| --- | --- |
| ArgumentNullException | زمانی که *fontBytes* مقدار null باشد، پرتاب می‌شود. |

### مثال‌ها

```csharp
[C#]
using (Presentation pres = new Presentation(pptxFileName))
{
    // تمام قلم‌های استفاده‌شده در ارائه را بازیابی کنید
    IFontData[] fontDatas = pres.FontsManager.GetFonts();

    // آرایه بایتی که نمایانگر سبک عادی اولین قلم در ارائه است را دریافت کنید
    byte[] bytes = pres.FontsManager.GetFontBytes(fontDatas[0], FontStyle.Regular);

    // سطح جاسازی قلم را تعیین کنید
    EmbeddingLevel embeddingLevel = pres.FontsManager.GetFontEmbeddingLevel(bytes, fontDatas[0].FontName);
}
```
