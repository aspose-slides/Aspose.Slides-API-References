## TextFrame.ReplaceRegex متد

تمام تطابق‌های عبارت منظم را با رشتهٔ مشخص‌شده جایگزین می‌کند.

```csharp
public void ReplaceRegex(Regex regex, string newText, IFindResultCallback callback)
```

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| regex | Regex | عبارت منظم Regex برای دریافت رشته‌هایی که باید جایگزین شوند. |
| newText | String | رشته‌ای که تمام وقوع رشته‌های مورد جایگزینی را جایگزین می‌کند. |
| callback | IFindResultCallback | شیء Callback برای ذخیرهٔ نتیجهٔ عملیات جایگزینی [`IFindResultCallback`](../../ifindresultcallback). |

### مثال‌ها

کد نمونهٔ زیر نشان می‌دهد چگونه متن را با استفاده از عبارت منظم و رشتهٔ مشخص‌شده جایگزین کنیم.

```csharp
[C#]
using (Presentation presentation = new Presentation("SomePresentation.pptx")){
	Regex regex = new Regex(@"\b[^\s]{10,}\b");
	// تمام کلمات با 10 یا بیشتر کاراکتر را با '***' جایگزین می‌کند
	((AutoShape)presentation.Slides[0].Shapes[0]).TextFrame.ReplaceRegex(regex, "***", null);
	presentation.Save("SomePresentation-out.pptx", SaveFormat.Pptx);
}
```
