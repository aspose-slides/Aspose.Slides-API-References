## متد TextFrame.SplitTextByColumns

متن محتوی [`ITextFrame`](../../itextframe) را به یک آرایه از رشته‌ها تقسیم می‌کند که هر عنصر به یک ستون متن جداگانه درون فریم مربوط می‌شود.

```csharp
public string[] SplitTextByColumns()
```

### مقدار بازگشت

یک آرایه از رشته‌ها که هر رشته محتوای متن یک ستون خاص در [`ITextFrame`](../../itextframe) را نشان می‌دهد.

### ملاحظات

اگر فریم متن شامل چندین ستون نباشد، آرایه‌ی بازگردانده‌شده یک عنصر واحد شامل متن کامل خواهد داشت. ستون‌های خالی به‌صورت رشته‌های خالی در آرایه نشان داده می‌شوند.

### مثال‌ها

مثال زیر نحوه استفاده از `SplitTextByColumns` را نشان می‌دهد:

```csharp
using (Presentation pres = new Presentation("example.pptx"))
{
    // دریافت اولین شکل در اسلاید و تبدیل آن به ITextFrame
    ITextFrame textFrame = pres.Slides[0].Shapes[0] as ITextFrame;
    // تقسیم محتوای فریم متن به ستون‌ها
    string[] columnsText = textFrame.SplitTextByColumns();
    // چاپ متن هر ستون در کنسول
    foreach (string column in columnsText)
        Console.WriteLine(column);
}
```
