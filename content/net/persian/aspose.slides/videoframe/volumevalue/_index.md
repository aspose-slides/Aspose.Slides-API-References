## VideoFrame.VolumeValue ویژگی

مقدار دقیق حجم ویدئو را به صورت درصد برمی‌گرداند یا تنظیم می‌کند. این مقدار به صورت درصدی از 0 تا 100 بیان می‌شود. از این ویژگی برای خواندن یا تنظیم مقادیر حجم استفاده کنید که دقیق‌تر از سطوح پیش‌تعریف شده در دسترس از طریق ویژگی [`Volume`](../volume) هستند. قابل خواندن/قابل نوشتن Single.

```csharp
public float VolumeValue { get; set; }
```

### مثال‌ها

مثال:

```csharp
[C#]
using (Presentation pres = new Presentation("video.pptx"))
{
    IVideoFrame videoFrame = (IVideoFrame)pres.Slides[0].Shapes[0];

    // حجم دقیق فعلی را بخوانید و آن را روی ۷۵.۵ درصد تنظیم کنید.
    float currentVolume = videoFrame.VolumeValue;
    videoFrame.VolumeValue = 75.5f;

    pres.Save("video_with_volume.pptx", SaveFormat.Pptx);
}
```
