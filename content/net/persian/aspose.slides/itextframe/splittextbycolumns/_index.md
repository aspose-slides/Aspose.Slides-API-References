## ITextFrame.SplitTextByColumns متد

متن محتوی [`ITextFrame`](../../itextframe) را به یک آرایه از رشته‌ها تقسیم می‌کند که هر عنصر متناظر با یک ستون متن جداگانه در داخل قاب است.

```csharp
public string[] SplitTextByColumns()
```

### مقدار برگشتی

یک آرایه از رشته‌ها که هر رشته محتوی متن یک ستون خاص در [`ITextFrame`](../../itextframe) را نشان می‌دهد.

### توضیحات

اگر فریم متن شامل چندین ستون نباشد، آرایه بازگشتی یک عنصر خواهد داشت که متن کامل را شامل می‌شود. ستون‌های خالی به صورت رشته‌های خالی در آرایه نمایان می‌شوند.

### نمونه‌ها

مثال زیر نشان می‌دهد چگونه از `SplitTextByColumns` استفاده شود:

```csharp
using (Presentation pres = new Presentation("example.pptx"))
{
    // دریافت اولین شکل در اسلاید و تبدیل آن به ITextFrame
    ITextFrame textFrame = pres.Slides[0].Shapes[0] as ITextFrame;
    // تقسیم محتوای فریم متن به ستون‌ها
    string[] columnsText = textFrame.SplitTextByColumns();
    // چاپ متن هر ستون در کنسول
    foreach (string column in columnsText)
        Console.WriteLine(column);
}
```
