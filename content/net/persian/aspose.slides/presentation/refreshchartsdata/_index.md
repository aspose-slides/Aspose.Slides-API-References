## Presentation.RefreshChartsData متد

داده‌های تمام نمودارها را در ارائه از کتاب‌های کاری منبعشان دوباره بارگذاری می‌کند.

```csharp
public void RefreshChartsData(bool skipFailedCharts = true)
```

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| skipFailedCharts | Boolean | مشخص می‌کند آیا فرآیند تازه‌سازی در صورت به‌روزرسانی نشدن یک نمودار ادامه پیدا می‌کند یا نه. اگر `true` باشد، نمودارهایی که منجر به استثنا می‌شوند رد می‌شوند؛ در غیر این صورت استثنا منتشر می‌شود. |

### مثال‌ها

```csharp
using (var presentation = new Presentation("PresentationWithCharts.pptx"))
{
    presentation.RefreshChartsData();
    presentation.Save("PresentationWithCharts-out.pptx", SaveFormat.Pptx);
}
```
