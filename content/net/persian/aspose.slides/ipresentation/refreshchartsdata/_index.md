## IPresentation.RefreshChartsData متد

داده‌ها را برای تمام نمودارها در ارائه از دفترهای کاری منبع آن‌ها بارگذاری مجدد می‌کند.

```csharp
public void RefreshChartsData(bool skipFailedCharts = true)
```

| پارامتر | نوع | توضیح |
| --- | --- | --- |
| skipFailedCharts | Boolean | تعیین می‌کند آیا فرآیند تازه‌سازی ادامه یابد اگر نموداری به‌روزرسانی نشود. اگر `true` باشد، نمودارهایی که باعث استثنا می‌شوند رد می‌شوند؛ در غیر اینصورت استثنا منتشر می‌شود. |

### مثال‌ها

```csharp
using (var presentation = new Presentation("PresentationWithCharts.pptx"))
{
    presentation.RefreshChartsData();
    presentation.Save("PresentationWithCharts-out.pptx", SaveFormat.Pptx);
}
```
