## PdfAccessPermissions تعداد

Contains a set of flags specifying which access permissions should be granted when the document is opened with user access.

```csharp
[Flags]
public enum PdfAccessPermissions
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| None | `0` | يحدد أن المستخدم لا يمتلك أذونات وصول. |
| PrintDocument | `4` | يحدد ما إذا كان يجوز للمستخدم طباعة المستند (ربما ليس بأعلى مستوى جودة، حسب ما إذا كانت البت HighQualityPrint مضبوطة أيضًا). |
| ModifyContent | `8` | يحدد ما إذا كان يجوز للمستخدم تعديل محتويات المستند عبر عمليات غير تلك التي تتحكم بها البتات AddOrModifyFields و FillExistingFields و AssembleDocument. |
| CopyTextAndGraphics | `10` | يحدد ما إذا كان يجوز للمستخدم نسخ أو استخراج النص والرسومات من المستند عبر عمليات غير تلك التي تتحكم بها البت ExtractTextAndGraphics. |
| AddOrModifyFields | `20` | يحدد ما إذا كان يجوز للمستخدم إضافة أو تعديل التعليقات النصية، ملء حقول النماذج التفاعلية، وإذا كانت البت ModifyContent مضبوطة أيضًا، إنشاء أو تعديل حقول النماذج التفاعلية (بما في ذلك حقول التوقيع). |
| FillExistingFields | `100` | يحدد ما إذا كان يجوز للمستخدم ملء حقول النماذج التفاعلية الموجودة (بما في ذلك حقول التوقيع)، حتى لو كانت البت AddOrModifyFields غير مفعلة. |
| ExtractTextAndGraphics | `200` | يحدد ما إذا كان يجوز للمستخدم استخراج النص والرسومات لدعم إمكانية الوصول للمستخدمين ذوي الإعاقات أو لأغراض أخرى. |
| AssembleDocument | `400` | يحدد ما إذا كان يجوز للمستخدم تجميع المستند (إدراج أو تدوير أو حذف صفحات وإنشاء إشارات مرجعية أو صور مصغرة)، حتى لو كانت البت ModifyContent غير مفعلة. |
| HighQualityPrint | `800` | يحدد ما إذا كان يجوز للمستخدم طباعة المستند إلى تمثيل يمكن منه إنشاء نسخة رقمية دقيقة من محتوى PDF. عندما تكون هذه البت غير مفعلة (والبت PrintDocument مفعلة)، يقتصر الطباعة على تمثيل منخفض المستوى للمظهر، وربما بجودة منخفضة. |
