## Compress.CompressImages طريقة

يقلل دقة الصور في العرض التقديمي ويحذف المناطق المقصوصة، مشابهًا لأداة “ضغط الصور” في PowerPoint التي تُطبّق على جميع الصور. تُعالج الصور على الشرائح، شرائح التخطيط والشرائح الرئيسية، بما في ذلك الصور داخل الأشكال الجماعية وملء الصور للأشكال.

```csharp
public static void CompressImages(IPresentation presentation, PicturesCompression resolution)
```

| معمل | نوع | وصف |
| --- | --- | --- |
| presentation | IPresentation | العرض التقديمي للمعالجة. |
| resolution | PicturesCompression | الدقة المستهدفة نسبةً إلى الحجم الذي يُعرض فيه كل صورة. DocumentResolution يترك الصور دون تغيير. |

### الاستثناءات

| الاستثناء | الشرط |
| --- | --- |
| ArgumentNullException | *presentation* هو `null`. |

### ملاحظات

الصور التي تكون بالفعل عند الدقة المستهدفة أو أدناها تُترك دون تغيير؛ ولا يتم تكبير الصور أبداً.

غير معالجة: خلفيات الشرائح، تعبئة خلايا الجداول، المخططات، SmartArt، صور GIF (للحفاظ على الرسوم المتحركة)، صور SVG وملفات الميتافايل (EMF/WMF).

تتم إزالة المناطق المقصوصة بشكل دائم ولا يمكن استعادتها في PowerPoint.

### أمثلة

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    CompressImages(pres, PicturesCompression.Dpi150);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
