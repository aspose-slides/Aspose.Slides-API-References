## IChartData.RefreshData طريقة

يقوم بتحديث بيانات المخطط عن طريق إعادة تحميلها من دفتر العمل المصدر.

```csharp
public void RefreshData()
```

### الاستثناءات

| استثناء | الشرط |
| --- | --- |
| InvalidOperationException | يتم رمي الاستثناء عندما لا يتم دعم تنسيق دفتر العمل، أو عندما [`DataSourceType`](../datasourcetype) يكون ExternalWorkbook ولا يمكن الوصول إلى دفتر العمل الخارجي أو تحميله. |

### ملاحظات

إذا كان المخطط يستخدم دفتر عمل خارجي، يجب أن يكون دفتر العمل قابلاً للوصول في وقت الاستدعاء.

### أمثلة

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
