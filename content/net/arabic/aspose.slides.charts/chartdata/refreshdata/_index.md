## طريقة ChartData.RefreshData

يقوم بتحديث بيانات المخطط عن طريق إعادة تحميلها من دفتر العمل المصدر.

```csharp
public void RefreshData()
```

### الاستثناءات

| الاستثناء | الشرط |
| --- | --- |
| InvalidOperationException | يتم رمي الاستثناء عندما لا يكون تنسيق دفتر العمل مدعومًا، أو عندما يكون [`DataSourceType`](../datasourcetype) هو ExternalWorkbook ولا يمكن الوصول إلى دفتر العمل الخارجي أو تحميله. |

### ملاحظات

إذا كان المخطط يستخدم دفتر عمل خارجي، يجب أن يكون دفتر العمل متاحًا في وقت الاستدعاء.

### أمثلة

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
