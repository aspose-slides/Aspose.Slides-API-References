## IDataLabelCollection.IsVisible property

False يعني أن تسمية البيانات غير مرئية بشكل افتراضي (وبالتالي جميع علمات Show*-flags (ShowValue, ...) للخاصية DefaultDataLabelFormat هي false). للقراءة فقط Boolean.

```csharp
public bool IsVisible { get; }
```

### ملاحظات

إذا كانت تسمية البيانات مرئية بشكل افتراضي يمكنك جعلها مخيفة بشكل افتراضي باستخدام الطريقة Hide(). ولكن إذا كانت تسمية البيانات غير مرئية بشكل افتراضي (IsVisible هو false) يمكنك جعل تسمية البيانات "مرئية بشكل افتراضي" عن طريق ضبط علمات Show*-flags (ShowValue, ...) للخاصية DefaultDataLabelFormat إلى الحالة true.
