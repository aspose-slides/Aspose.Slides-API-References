## IDataLabelCollection.DefaultLabelShapeType الخاصية

تحصل أو تعيّن نوع الشكل الافتراضي لتسميات البيانات. تُعيد NotDefined إذا لم يتم تعريف أي شكل.

```csharp
public ShapeType DefaultLabelShapeType { get; set; }
```

### ملاحظات

تعيين هذه الخاصية يضبط أيضًا الخاصية [`LabelShapeType`](../../idatalabel/labelshapetype) لجميع تسميات البيانات في المجموعة إلى نفس القيمة.

### أمثلة

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[1];
    var firstSeries = chart.ChartData.Series[0];

    // حدد نوع الشكل لجميع تسميات البيانات في السلسلة الأولى إلى Ellipse.
    firstSeries.Labels.DefaultLabelShapeType = ShapeType.Ellipse;

    pres.Save("ChartWithEllipseLabels.pptx", SaveFormat.Pptx);
}
```
