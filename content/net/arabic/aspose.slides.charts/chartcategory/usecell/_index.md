## ChartCategory.UseCell خاصية

إذا كان true فإن خاصية AsCell سارية. بمعنى آخر، يتم استخدام worksheet لتخزين الفئة (هذا الحالة تدعم فئة متعددة المستويات). إذا كان false فإن خاصية AsLiteral سارية. بمعنى آخر، لا يتم استخدام worksheet لتخزين الفئة (وهذا الحالة لا تدعم فئات متعددة المستويات). قيمة Boolean للقراءة فقط.

```csharp
public bool UseCell { get; }
```
