## IChartCategory.UseCell خاصية

If true then AsCell خاصية is actual. In other words, worksheet is used for storing category (this case supports a multi-level category). If false then AsLiteral خاصية is actual. In other words, worksheet is NOT used for storing category (and this case doesn't support a multi-level categories). Boolean للقراءة فقط.
