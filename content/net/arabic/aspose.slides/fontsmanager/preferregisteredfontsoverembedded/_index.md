## FontsManager.PreferRegisteredFontsOverEmbedded خاصية

يحدد ما إذا كان يجب تفضيل الخطوط المسجلة على الخطوط المضمنة التي لها نفس اسم الخط والنمط. عندما يتم تمكينه، يتم استبدال الخطوط المضمنة المطابقة مؤقتًا بالخطوط المسجلة المقابلة أثناء التصدير.

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### ملاحظات

القيمة الافتراضية هي **false**.

### أمثلة

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
