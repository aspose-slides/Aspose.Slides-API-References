## PresentationLockingBehavior تعداد

يمثل السلوك المتعلق بمعالجة مصدر [`IPresentation`](../ipresentation) (ملف أو Stream) أثناء التحميل والعمل مع نسخة من [`IPresentation`](../ipresentation).

```csharp
public enum PresentationLockingBehavior
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| LoadAndRelease | `0` | سيتم قفل المصدر فقط لمدة تنفيذ المُنشئ [`IPresentation`](../ipresentation). إذا تم تعيين [`IsTemporaryFilesAllowed`](../iblobmanagementoptions/istemporaryfilesallowed) إلى false، سيُحمَّل جميع BLOBs في الذاكرة. وإلا، قد تُستخدم وسائل أخرى مثل الملفات المؤقتة. هذا السلوك أبطأ من KeepLocked، وإذا كان من الممكن تمرير ملكية المصدر إلى [`IPresentation`](../ipresentation)، يوصى باستخدام KeepLocked. |
| KeepLocked | `1` | سيتم قفل المصدر طوال عمر نسخة [`IPresentation`](../ipresentation) بالكامل، حتى يتم التخلص منها. يجب تعيين [`IsTemporaryFilesAllowed`](../iblobmanagementoptions/istemporaryfilesallowed) إلى true لاستخدام هذا السلوك، وإلا سيتم رمي استثناء. هذا السلوك موصى به، فهو أسرع ويستهلك ذاكرة أقل من LoadAndRelease. |

### ملاحظات

المصدر هو المعامل المُمرَّر إلى المُنشئ [`IPresentation`](../ipresentation). في المثال أدناه، المصدر هو ملف "pres.pptx":

```csharp
LoadOptions loadOptions = new LoadOptions { 
  BlobManagementOptions = { PresentationLockingBehavior = PresentationLockingBehavior.KeepLocked } };
using (IPresentation pres = new Presentation("pres.pptx", loadOptions)) { }
```

في هذا المثال، سيتم قفل المصدر (ملف "pres.pptx") لمدة عمر نسخة [`IPresentation`](../ipresentation)، أي لا يمكن تغييره أو حذفه بواسطة العملية الأخرى.
