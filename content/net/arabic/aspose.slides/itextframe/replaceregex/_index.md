## ITextFrame.ReplaceRegex method

يستبدل جميع المطابقات للتعبير النمطي بالسلسلة المحددة.

```csharp
public void ReplaceRegex(Regex regex, string newText, IFindResultCallback callback)
```

| Parameter | Type | Description |
| --- | --- | --- |
| regex | Regex | التعبير النمطي Regex للحصول على السلاسل التي سيتم استبدالها. |
| newText | String | السلسلة التي ستحل محل جميع تكرارات السلاسل التي سيتم استبدالها. |
| callback | IFindResultCallback | كائن رد النداء لاستقبال نتائج البحث [`IFindResultCallback`](../../ifindresultcallback). |

### أمثلة

الكود التالي يوضح كيفية استبدال النص باستخدام التعبير النمطي والسلسلة المحددة.

```csharp
[C#]
using (Presentation presentation = new Presentation("SomePresentation.pptx"))
{
	Regex regex = new Regex(@"\b[^\s]{10,}\b");
	// استبدال جميع الكلمات التي تحتوي على 10 أحرف أو أكثر بـ '***'
	((AutoShape)presentation.Slides[0].Shapes[0]).TextFrame.ReplaceRegex(regex, "***", null);
	presentation.Save("SomePresentation-out.pptx", SaveFormat.Pptx);
}
```
