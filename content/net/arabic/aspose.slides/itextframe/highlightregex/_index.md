## طريقة ITextFrame.HighlightRegex

يسلط الضوء على جميع التطابقات للتعبير النمطي باستخدام اللون المحدد.

```csharp
public void HighlightRegex(Regex regex, Color highlightColor, IFindResultCallback callback)
```

| Parameter | Type | Description |
| --- | --- | --- |
| regex | Regex | التعبير النمطي Regex للحصول على السلاسل التي سيتم تسليط الضوء عليها. |
| highlightColor | Color | اللون لتسليط الضوء على النص. |
| callback | IFindResultCallback | كائن الاستدعاء لتلقي نتائج البحث [`IFindResultCallback`](../../ifindresultcallback). |

### أمثلة

يوضح مثال الشيفرة التالي كيفية تسليط الضوء على النص داخل TextFrame باستخدام تعبير نمطي.

```csharp
[C#]
using (Presentation presentation = new Presentation("SomePresentation.pptx"))
{
	Regex regex = new Regex(@"\b[^\s]{10,}\b");
	// تسليط الضوء على جميع الكلمات التي تتكون من 10 أحرف أو أكثر
	((AutoShape)presentation.Slides[0].Shapes[0]).TextFrame.HighlightRegex(regex, Color.Blue, null);
	presentation.Save("SomePresentation-out.pptx", SaveFormat.Pptx);
}
```
