## TextFrame.ReplaceRegex طريقة

يستبدل جميع التطابقات للتعبير المنتظم بالسلسلة المحددة.

```csharp
public void ReplaceRegex(Regex regex, string newText, IFindResultCallback callback)
```

| Parameter | Type | Description |
| --- | --- | --- |
| regex | Regex | التعبير المنتظم Regex للحصول على السلاسل التي سيتم استبدالها. |
| newText | String | السلسلة التي ستحل محل جميع السلاسل التي سيتم استبدالها. |
| callback | IFindResultCallback | كائن Callback لحفظ نتيجة عملية الاستبدال [`IFindResultCallback`](../../ifindresultcallback). |

### أمثلة

الكود النموذجي التالي يوضح كيفية استبدال النص باستخدام تعبير منتظم بسلسلة محددة.

```csharp
[C#]
using (Presentation presentation = new Presentation("SomePresentation.pptx")){
	Regex regex = new Regex(@"\b[^\s]{10,}\b");
	// استبدال جميع الكلمات التي تحتوي على 10 أحرف أو أكثر بـ '***'
	((AutoShape)presentation.Slides[0].Shapes[0]).TextFrame.ReplaceRegex(regex, "***", null);
	presentation.Save("SomePresentation-out.pptx", SaveFormat.Pptx);
}
```
