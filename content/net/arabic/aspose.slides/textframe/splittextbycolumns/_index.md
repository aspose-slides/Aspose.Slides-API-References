## TextFrame.SplitTextByColumns طريقة

يقسم محتوى النص في [`ITextFrame`](../../itextframe) إلى مصفوفة من السلاسل، حيث يُطابق كل عنصر عمود نص منفصل داخل الإطار.

```csharp
public string[] SplitTextByColumns()
```

### قيمة الإرجاع

مصفوفة من السلاسل، حيث تمثل كل سلسلة محتوى النص لعمود محدد في [`ITextFrame`](../../itextframe).

### ملاحظات

إذا لم يحتوي إطار النص على أعمدة متعددة، فإن المصفوفة المرتجعة سيحتوي عنصر واحد فقط يحتوي على النص الكامل. سيتم تمثيل الأعمدة الفارغة كسلاسل فارغة في المصفوفة.

### أمثلة

يوضح المثال التالي كيفية استخدام `SplitTextByColumns`:

```csharp
using (Presentation pres = new Presentation("example.pptx"))
{
    // الحصول على الشكل الأول في الشريحة وتحويله إلى ITextFrame
    ITextFrame textFrame = pres.Slides[0].Shapes[0] as ITextFrame;
    // تقسيم محتوى إطار النص إلى أعمدة
    string[] columnsText = textFrame.SplitTextByColumns();
    // طباعة نص كل عمود إلى وحدة التحكم
    foreach (string column in columnsText)
        Console.WriteLine(column);
}
```
