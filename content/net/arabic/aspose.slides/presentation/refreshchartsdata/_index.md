## Presentation.RefreshChartsData طريقة

يعيد تحميل البيانات لجميع المخططات في العرض التقديمي من دفاتر العمل المصدر.

```csharp
public void RefreshChartsData(bool skipFailedCharts = true)
```

| معامل | نوع | وصف |
| --- | --- | --- |
| skipFailedCharts | Boolean | يحدّد ما إذا كانت عملية التحديث تستمر إذا فشل المخطط في التحديث. إذا كان `true`، يتم تخطي المخططات التي تتسبب في استثناء؛ وإلا يتم نشر الاستثناء. |

### أمثلة

```csharp
using (var presentation = new Presentation("PresentationWithCharts.pptx"))
{
    presentation.RefreshChartsData();
    presentation.Save("PresentationWithCharts-out.pptx", SaveFormat.Pptx);
}
```
