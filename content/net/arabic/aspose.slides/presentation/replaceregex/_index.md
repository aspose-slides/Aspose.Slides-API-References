## Presentation.ReplaceRegex طريقة

يستبدل جميع التطابقات للتعبير النمطي بالسلسلة المحددة.

```csharp
public void ReplaceRegex(Regex regex, string newText, IFindResultCallback callback)
```

| Parameter | Type | Description |
| --- | --- | --- |
| regex | Regex | التعبير النمطي Regex للحصول على السلاسل المراد استبدالها. |
| newText | String | السلسلة التي ستستبدل جميع حدوثات السلاسل المراد استبدالها. |
| callback | IFindResultCallback | كائن callback لتلقي نتائج البحث [`IFindResultCallback`](../../ifindresultcallback). |

### أمثلة

يوضح المثال التالي كيفية استبدال النص باستخدام التعبير النمطي مع السلسلة المحددة.

```csharp
[C#]
using (Presentation presentation = new Presentation("SomePresentation.pptx"))
{
	Regex regex = new Regex(@"\b[^\s]{10,}\b");
	// استبدال جميع الكلمات التي تتكون من 10 أحرف أو أكثر بـ '***'
	presentation.ReplaceRegex(regex, "***", null);
	presentation.Save("SomePresentation-out.pptx", SaveFormat.Pptx);
}
```
