## IVideoFrame.VolumeValue خاصية

تُعيد أو تُعيّن حجم الفيديو الدقيق كنسبة مئوية. القيمة تُعبّر عنها كنسبة مئوية من 0 إلى 100. استخدم هذه الخاصية لقراءة أو تعيين قيم حجم الصوت التي تكون أكثر دقة من المستويات المحددة مسبقًا المتاحة عبر خاصية [`Volume`](../volume). قراءة/كتابة Single.

```csharp
public float VolumeValue { get; set; }
```

### أمثلة

مثال:

```csharp
[C#]
using (Presentation pres = new Presentation("video.pptx"))
{
    IVideoFrame videoFrame = (IVideoFrame)pres.Slides[0].Shapes[0];

    // اقرأ الحجم الدقيق الحالي واضبطه على 75.5 بالمئة.
    float currentVolume = videoFrame.VolumeValue;
```
