## VideoFrame.VolumeValue خاصية

تعيد أو تعيّن حجم الفيديو الدقيق كنسبة مئوية. القيمة معبر عنها كنسبة مئوية من 0 إلى 100. استخدم هذه الخاصية لقراءة أو تعيين قيم الصوت التي تكون أكثر دقة من المستويات المعرفة مسبقًا المتاحة عبر خاصية [`Volume`](../volume). قراءة/كتابة Single.

```csharp
public float VolumeValue { get; set; }
```

### أمثلة

مثال:

```csharp
[C#]
using (Presentation pres = new Presentation("video.pptx"))
{
    IVideoFrame videoFrame = (IVideoFrame)pres.Slides[0].Shapes[0];

    // قراءة الحجم الدقيق الحالي وتعيينه إلى 75.5 بالمئة.
    float currentVolume = videoFrame.VolumeValue;
    videoFrame.VolumeValue = 75.5f;

    pres.Save("video_with_volume.pptx", SaveFormat.Pptx);
}
```
