## IPresentation.ReplaceRegex طريقة

يقوم باستبدال جميع التطابقات للعبارة النمطية بالسلسلة المحددة.

```csharp
public void ReplaceRegex(Regex regex, string newText, IFindResultCallback callback)
```

| Parameter | Type | Description |
| --- | --- | --- |
| regex | Regex | التعبير النمطي Regex للحصول على السلاسل المستبدلة. |
| newText | String | السلسلة لاستبدال جميع تكرارات السلاسل التي يجب استبدالها. |
| callback | IFindResultCallback | كائن رد النداء لاستلام نتائج البحث [`IFindResultCallback`](../../ifindresultcallback). |

### أمثلة

يعرض عينة الشيفرة التالية كيفية استبدال النص باستخدام التعبير النمطي بالسلسلة المحددة.

```csharp
[C#]
using (Presentation presentation = new Presentation("SomePresentation.pptx"))
{
	Regex regex = new Regex(@"\b[^\s]{10,}\b");
	// استبدال جميع الكلمات التي تتكون من 10 أحرف أو أكثر بـ '***'
	presentation.ReplaceRegex(regex, "***", null);
	presentation.Save("SomePresentation-out.pptx", SaveFormat.Pptx);
}
```
