## IPresentation.ReplaceText طريقة

يقوم باستبدال جميع مرات ظهور النص المحدد بنص آخر محدد.

```csharp
public void ReplaceText(string oldText, string newText, ITextSearchOptions options, 
    IFindResultCallback callback)
```

| المعامل | النوع | الوصف |
| --- | --- | --- |
| oldText | String | السلسلة المراد استبدالها. |
| newText | String | السلسلة التي ستستبدل جميع مرات ظهور oldText. |
| options | ITextSearchOptions | خيارات البحث النصي [`ITextSearchOptions`](../../itextsearchoptions). |
| callback | IFindResultCallback | كائن الاستدعاء الخلفي لاستلام نتائج البحث [`IFindResultCallback`](../../ifindresultcallback). |

### أمثلة

توضح الشفرة النموذجية التالية كيفية استبدال سلسلة محددة بأخرى محددة.

```csharp
[C#]
using (Presentation presentation = new Presentation("SomePresentation.pptx"))
{
	// استبدال جميع مرات ظهور كلمة 'the' المنفصلة بـ '***'
	presentation.ReplaceText("the", "***", new TextSearchOptions() {WholeWordsOnly = true}, null);
	presentation.Save("SomePresentation-out2.pptx", SaveFormat.Pptx);
}
```
