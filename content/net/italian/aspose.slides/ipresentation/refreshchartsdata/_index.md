## IPresentation.RefreshChartsData metodo

Ricarica i dati per tutti i grafici nella presentazione dalle loro cartelle di lavoro di origine.

```csharp
public void RefreshChartsData(bool skipFailedCharts = true)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| skipFailedCharts | Boolean | Determina se il processo di aggiornamento continua in caso un grafico non riesca ad aggiornarsi. Se `true`, i grafici che causano un'eccezione vengono ignorati; altrimenti l'eccezione viene propagata. |

### Esempi

```csharp
using (var presentation = new Presentation("PresentationWithCharts.pptx"))
{
    presentation.RefreshChartsData();
    presentation.Save("PresentationWithCharts-out.pptx", SaveFormat.Pptx);
}
```
