## FontsManager.PreferRegisteredFontsOverEmbedded proprietà

Specifica se i font registrati devono essere preferiti rispetto ai font incorporati con lo stesso nome e stile. Quando abilitato, i font incorporati corrispondenti vengono temporaneamente sostituiti con i font registrati corrispondenti durante l'esportazione.

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### Osservazioni

Il valore predefinito è **false**.

### Esempi

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
