## FontsManager.GetFontBytes metodo

Recupera l'array di byte che rappresenta i dati del font per uno stile del font e dati del font specificati.

```csharp
public byte[] GetFontBytes(IFontData fontData, FontStyleType fontStyle)
```

| Parameter | Type | Description |
| --- | --- | --- |
| fontData | IFontData | L'oggetto dati del font contenente le informazioni sul font [`IFontData`](../../ifontdata). |
| fontStyle | FontStyleType | Lo stile del font per il quale devono essere recuperati i dati [`FontStyleType`](../../fontstyletype). |

### Valore di ritorno

Un array di byte contenente i dati del font per lo stile del font specificato. Se i dati del font o lo stile non vengono trovati, restituisce null.

### Esempi

```csharp
[C#]
using (Presentation pres = new Presentation ("Presentation.pptx"))
{
    // Recupera tutti i font utilizzati nella presentazione
    IFontData[] fonts = pres.FontsManager.GetFonts();

    // Ottiene l'array di byte che rappresenta lo stile regolare del primo font nella presentazione
    byte[] bytes = pres.FontsManager.GetFontBytes(fonts[0], FontStyleType.Regular);
}
```
