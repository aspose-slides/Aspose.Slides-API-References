## Metodo Presentation.RefreshChartsData

Ricarica i dati di tutti i grafici nella presentazione dai relativi fogli di lavoro di origine.

```csharp
public void RefreshChartsData(bool skipFailedCharts = true)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| skipFailedCharts | Boolean | Determina se il processo di aggiornamento continua quando un grafico non riesce ad aggiornarsi. Se `true`, i grafici che causano un'eccezione vengono ignorati; altrimenti l'eccezione viene propagata. |

### Esempi

```csharp
using (var presentation = new Presentation("PresentationWithCharts.pptx"))
{
    presentation.RefreshChartsData();
    presentation.Save("PresentationWithCharts-out.pptx", SaveFormat.Pptx);
}
```
