## IVideoFrame.VolumeValue proprietà

Restituisce o imposta il volume esatto del video come percentuale. Il valore è espresso come percentuale da 0 a 100. Utilizza questa proprietà per leggere o impostare valori di volume più precisi rispetto ai livelli predefiniti disponibili tramite la proprietà [`Volume`](../volume). Lettura/scrittura Single.

```csharp
public float VolumeValue { get; set; }
```

### Esempi

Esempio:

```csharp
[C#]
using (Presentation pres = new Presentation("video.pptx"))
{
    IVideoFrame videoFrame = (IVideoFrame)pres.Slides[0].Shapes[0];

    // Leggi il volume esatto corrente e impostalo al 75.5 percento.
    float currentVolume = videoFrame.VolumeValue;
    videoFrame.VolumeValue = 75.5f;

    pres.Save("video_with_volume.pptx", SaveFormat.Pptx);
}
```
