## IFontsManager.PreferRegisteredFontsOverEmbedded proprietà

Specifica se i caratteri registrati devono avere la precedenza sui caratteri incorporati con lo stesso nome e stile. Quando è abilitata, i caratteri incorporati corrispondenti vengono temporaneamente sostituiti dai relativi caratteri registrati durante l'esportazione.

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### Osservazioni

Il valore predefinito è **false**.

### Esempi

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
