Il valore true indica che solo le proprietà del documento vengono caricate da un file di presentazione cifrato senza utilizzare la password. Il valore false indica che l'intera presentazione cifrata viene caricata usando la password corretta, non solo le proprietà del documento vengono caricate. Se la presentazione non è cifrata, il valore della proprietà è sempre false. Se le proprietà del documento di un file cifrato non sono pubbliche, il valore della proprietà è sempre false. Se PresentationEx.EncryptDocumentProperties è true, allora il valore della proprietà IsOnlyDocumentPropertiesLoaded è sempre false. Solo lettura Boolean. |
