## Metodo Compress.CompressImages

Riduce la risoluzione delle immagini nella presentazione ed elimina le aree ritagliate, simile a “Compress Pictures” di PowerPoint applicato a tutte le immagini. Le immagini nelle diapositive, nelle diapositive master e nelle diapositive di layout vengono elaborate, incluse le immagini all'interno di gruppi di forme e i riempimenti immagine delle forme.

```csharp
public static void CompressImages(IPresentation presentation, PicturesCompression resolution)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| presentation | IPresentation | La presentazione da elaborare. |
| resolution | PicturesCompression | Risoluzione target relativa alle dimensioni con cui viene visualizzata ogni immagine. DocumentResolution mantiene le immagini invariate. |

### Eccezioni

| eccezione | condizione |
| --- | --- |
| ArgumentNullException | *presentation* è `null`. |

### Note

Le immagini già alla risoluzione target o inferiore rimangono inalterate; le immagini non vengono mai ingrandite.

Non elaborate: sfondi delle diapositive, riempimenti delle celle delle tabelle, grafici, SmartArt, immagini GIF (per preservare l'animazione), immagini SVG e metafile (EMF/WMF).

Le aree ritagliate vengono rimosse permanentemente e non possono essere ripristinate in PowerPoint.

### Esempi

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    CompressImages(pres, PicturesCompression.Dpi150);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
