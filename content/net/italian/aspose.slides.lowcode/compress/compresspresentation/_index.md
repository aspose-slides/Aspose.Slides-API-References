## Metodo Compress.CompressPresentation

Riduce le dimensioni di una presentazione applicando tutti i passaggi di compressione disponibili:

* Rimuove le diapositive master inutilizzate [`RemoveUnusedMasterSlides`](../removeunusedmasterslides).
* Rimuove le diapositive layout inutilizzate [`RemoveUnusedLayoutSlides`](../removeunusedlayoutslides).
* Mantiene solo i glifi effettivamente usati nei caratteri incorporati [`CompressEmbeddedFonts`](../compressembeddedfonts).
* Riduce la risoluzione delle immagini a 150 DPI ed elimina le aree ritagliate delle immagini [`CompressImages`](../compressimages).

```csharp
public static void CompressPresentation(Presentation presentation)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| presentation | Presentation | La presentazione da comprimere. |

### Eccezioni

| eccezione | condizione |
| --- | --- |
| ArgumentNullException | *presentation* è `null`. |

### Osservazioni

Per personalizzare la compressione, ad esempio per usare una risoluzione dell’immagine diversa o per saltare un passaggio, chiamare individualmente i metodi elencati sopra anziché questo. Le aree ritagliate delle immagini vengono rimosse definitivamente e non possono essere ripristinate in PowerPoint.

### Esempi

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    Aspose.Slides.LowCode.Compress.CompressPresentation(pres);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
