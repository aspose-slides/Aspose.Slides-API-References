## InkEffectType enumerazione

Specifica un insieme di effetti visivi predefiniti per il rendering dell'inchiostro. Ogni effetto corrisponde a una texture o immagine che simula un aspetto stilizzato dell'inchiostro. Questi valori possono essere usati per personalizzare lo stile visivo delle tracce di inchiostro digitale durante il rendering.

```csharp
public enum InkEffectType
```

### Valori

| Name | Value | Description |
| --- | --- | --- |
| NotDefined | `-1` | L'effetto non è definito o è sconosciuto. Questo valore può essere usato come predefinito o di riserva. |
| Bronze | `0` | Una texture metallica calda e brunita che somiglia a inchiostro di bronzo. |
| Galaxy | `1` | Una texture colorata e scintillante che ricorda una galassia, con tonalità cosmiche. |
| Gold | `2` | Una texture metallica dorata brillante che conferisce alle tracce di inchiostro un aspetto lussuoso. |
| Lava | `3` | Una texture infuocata che ricorda lava fusa, con tonalità rosse e arancioni. |
| Ocean | `4` | Una texture blu profondo, fluida, che imita le onde dell'oceano o l'inchiostro a base d'acqua. |
| RainbowGlitter | `5` | Un effetto glitter arcobaleno colorato e scintillante usato per tracce di inchiostro festive o vivaci. |
| RoseGold | `6` | Una miscela morbida di rosa e oro, simile al rose gold, per tracce di inchiostro eleganti. |
| Silver | `7` | Una texture metallica argentata e fresca che simula l'inchiostro argento classico. |
