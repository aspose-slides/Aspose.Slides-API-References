## IDataLabel.Hide metodo

Rendi l’etichetta dati nascosta impostando tutti i flag Show*- (ShowValue, ...) nello stato false. IsVisible sarà false dopo questo.

```csharp
public void Hide()
```

### Osservazioni

Se l’etichetta dati non è visibile (IsVisible è false) puoi renderla visibile impostando i flag Show*- (ShowValue, ...) nello stato true.
