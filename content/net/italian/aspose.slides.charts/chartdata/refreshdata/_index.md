## ChartData.RefreshData method

Aggiorna i dati del grafico ricaricandoli dal workbook di origine.

```csharp
public void RefreshData()
```

### Eccezioni

| eccezione | condizione |
| --- | --- |
| InvalidOperationException | Generata quando il formato del workbook non è supportato, oppure quando [`DataSourceType`](../datasourcetype) è ExternalWorkbook e il workbook esterno non può essere accessibile o caricato. |

### Osservazioni

Se il grafico utilizza un workbook esterno, il workbook deve essere accessibile al momento della chiamata.

### Esempi

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
