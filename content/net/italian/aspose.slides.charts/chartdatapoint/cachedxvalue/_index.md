## ChartDataPoint.CachedXValue proprietà

Ottiene il valore X memorizzato nella cache di un punto dati del grafico. Solo lettura [`ICachedChartValue`](../../icachedchartvalue).

### Esempi

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[0];
    foreach (var series in chart.ChartData.Series)
    {
        // Stampa tutti i valori X memorizzati nella cache della serie del grafico.
        foreach (var point in series.DataPoints)
            Console.WriteLine(point.CachedXValue.ToDouble());
    }
}
```
