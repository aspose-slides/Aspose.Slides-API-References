## IChartData.RefreshData metodo

Aggiorna i dati del grafico ricaricandoli dal foglio di lavoro di origine.

```csharp
public void RefreshData()
```

### Eccezioni

| eccezione | condizione |
| --- | --- |
| InvalidOperationException | Lanciata quando il formato del foglio di lavoro non è supportato, o quando [`DataSourceType`](../datasourcetype) è ExternalWorkbook e il foglio di lavoro esterno non può essere acceduto o caricato. |

### Osservazioni

Se il grafico utilizza un foglio di lavoro esterno, il foglio di lavoro deve essere accessibile al momento della chiamata.

### Esempi

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
