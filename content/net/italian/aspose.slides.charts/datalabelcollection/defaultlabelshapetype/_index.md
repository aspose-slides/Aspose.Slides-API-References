## DataLabelCollection.DefaultLabelShapeType proprietà

Ottiene o imposta il tipo di forma predefinito per le etichette dati. Restituisce NotDefined se non è definita alcuna forma.

```csharp
public ShapeType DefaultLabelShapeType { get; set; }
```

### Osservazioni

Impostare questa proprietà imposta anche la proprietà [`LabelShapeType`](../../idatalabel/labelshapetype) per tutte le etichette dati nella raccolta allo stesso valore.

### Esempi

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[1];
    var firstSeries = chart.ChartData.Series[0];

    // Imposta il tipo di forma di tutte le etichette dati nella prima serie a Ellipse.
    firstSeries.Labels.DefaultLabelShapeType = ShapeType.Ellipse;

    pres.Save("ChartWithEllipseLabels.pptx", SaveFormat.Pptx);
}
```
