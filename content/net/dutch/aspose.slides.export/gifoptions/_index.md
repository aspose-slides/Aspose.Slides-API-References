### Voorbeelden

Het volgende voorbeeld laat zien hoe presentaties te converteren naar een geanimeerde GIF met aangepaste instellingen.

```csharp
[C#]
using (Presentation pres = new Presentation("pres.pptx"))
{
    pres.Save("pres.gif", SaveFormat.Gif, new GifOptions
    {
        FrameSize = new Size(960, 720), // de grootte van de resulterende GIF
        DefaultDelay = 2000, // hoe lang elke dia getoond wordt totdat deze wordt gewijzigd naar de volgende
        TransitionFps = 35 // verhoog FPS om de kwaliteit van de overgangsanimatie te verbeteren
    });
}
```
