## Compress.CompressImages methode

Vermindert de resolutie van afbeeldingen in de presentatie en verwijdert hun bijgesneden delen, vergelijkbaar met PowerPoint's "Compress Pictures" toegepast op alle afbeeldingen. Afbeeldingen op dia's, lay-outdia's en masterdia's worden verwerkt, inclusief afbeeldingen binnen groepsvormen en afbeeldingvullingen van vormen.

```csharp
public static void CompressImages(IPresentation presentation, PicturesCompression resolution)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| presentation | IPresentation | De te verwerken presentatie. |
| resolution | PicturesCompression | Doelresolutie relatief ten opzichte van de grootte waarop elke afbeelding wordt weergegeven. DocumentResolution laat afbeeldingen ongewijzigd. |

### Uitzonderingen

| uitzondering | conditie |
| --- | --- |
| ArgumentNullException | *presentation* is `null`. |

### Opmerkingen

Afbeeldingen die al op of onder de doelresolutie zijn, blijven ongewijzigd; afbeeldingen worden nooit opgeschaald.

Niet verwerkt: dia-achtergronden, tabelcelfullingen, grafieken, SmartArt, GIF-afbeeldingen (om animatie te behouden), SVG- en metafile (EMF/WMF) afbeeldingen.

Bijsneden delen worden permanent verwijderd en kunnen niet worden hersteld in PowerPoint.

### Voorbeelden

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    CompressImages(pres, PicturesCompression.Dpi150);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
