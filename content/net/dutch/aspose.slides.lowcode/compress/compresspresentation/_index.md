## Compress.CompressPresentation methode

Vermindert de grootte van een presentatie door alle beschikbare compressiestappen toe te passen:

* Verwijdert ongebruikte masterslides [`RemoveUnusedMasterSlides`](../removeunusedmasterslides).
* Verwijdert ongebruikte layoutslides [`RemoveUnusedLayoutSlides`](../removeunusedlayoutslides).
* Behoudt alleen de werkelijk gebruikte glyphs in ingesloten lettertypen [`CompressEmbeddedFonts`](../compressembeddedfonts).
* Verlaagt de resolutie van afbeeldingen tot 150 DPI en verwijdert bijgesneden gebieden van afbeeldingen [`CompressImages`](../compressimages).

```csharp
public static void CompressPresentation(Presentation presentation)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| presentation | Presentation | De presentation om te comprimeren. |

### Uitzonderingen

| uitzondering | conditie |
| --- | --- |
| ArgumentNullException | *presentation* is `null`. |

### Opmerkingen

Om compressie aan te passen, bijvoorbeeld om een andere afbeeldingsresolutie te gebruiken of een stap over te slaan, roep de hierboven genoemde methoden afzonderlijk aan in plaats van deze. Bijgesneden gebieden van afbeeldingen worden permanent verwijderd en kunnen niet worden hersteld in PowerPoint.

### Voorbeelden

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    Aspose.Slides.LowCode.Compress.CompressPresentation(pres);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
