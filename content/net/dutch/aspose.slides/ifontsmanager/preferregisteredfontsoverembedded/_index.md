## IFontsManager.PreferRegisteredFontsOverEmbedded eigenschap

Geeft aan of geregistreerde lettertypen moeten worden geprefereerd boven ingebedde lettertypen met dezelfde lettertype-naam en stijl. Indien ingeschakeld, worden overeenkomende ingebedde lettertypen tijdelijk vervangen door de bijbehorende geregistreerde lettertypen tijdens het exporteren.

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### Opmerkingen

Standaard is **false**.

### Voorbeelden

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
