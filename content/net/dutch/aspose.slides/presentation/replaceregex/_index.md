## Presentation.ReplaceRegex methode

Vervangt alle overeenkomsten van de reguliere expressie door de opgegeven tekenreeks.

```csharp
public void ReplaceRegex(Regex regex, string newText, IFindResultCallback callback)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| regex | Regex | De reguliere expressie Regex om te vervangen tekenreeksen op te halen. |
| newText | String | De tekenreeks om alle voorkomen van de te vervangen tekenreeksen te vervangen. |
| callback | IFindResultCallback | Het callback object voor het ontvangen van zoekresultaten [`IFindResultCallback`](../../ifindresultcallback). |

### Voorbeelden

De volgende codevoorbeeld toont hoe tekst te vervangen met een reguliere expressie en de opgegeven tekenreeks.

```csharp
[C#]
using (Presentation presentation = new Presentation("SomePresentation.pptx"))
{
	Regex regex = new Regex(@"\b[^\s]{10,}\b");
	// Vervang alle woorden van 10 of meer tekens door '***'
	presentation.ReplaceRegex(regex, "***", null);
	presentation.Save("SomePresentation-out.pptx", SaveFormat.Pptx);
}
```
