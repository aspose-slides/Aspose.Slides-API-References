## FontsManager.PreferRegisteredFontsOverEmbedded eigenschap

Geeft aan of geregistreerde lettertypen voorrang moeten krijgen boven ingesloten lettertypen met dezelfde lettertype-naam en stijl. Wanneer ingeschakeld, worden overeenkomende ingesloten lettertypen tijdelijk vervangen door de overeenkomstige geregistreerde lettertypen tijdens het exporteren.

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### Opmerkingen

Standaard is **false**.

### Voorbeelden

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
