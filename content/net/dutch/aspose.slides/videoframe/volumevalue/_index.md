## VideoFrame.VolumeValue eigenschap

Geeft het exacte videovolume terug of stelt het in als een percentage. De waarde wordt weergegeven als een percentage van 0 tot 100. Gebruik deze eigenschap om volume-waarden te lezen of in te stellen die preciezer zijn dan de vooraf gedefinieerde niveaus die beschikbaar zijn via de [`Volume`](../volume) eigenschap. Lezen/schrijven Single.

```csharp
public float VolumeValue { get; set; }
```

### Voorbeelden

Voorbeeld:

```csharp
[C#]
using (Presentation pres = new Presentation("video.pptx"))
{
    IVideoFrame videoFrame = (IVideoFrame)pres.Slides[0].Shapes[0];

    // Lees het huidige exacte volume en stel het in op 75.5 procent.
    float currentVolume = videoFrame.VolumeValue;
    videoFrame.VolumeValue = 75.5f;

    pres.Save("video_with_volume.pptx", SaveFormat.Pptx);
}
```
