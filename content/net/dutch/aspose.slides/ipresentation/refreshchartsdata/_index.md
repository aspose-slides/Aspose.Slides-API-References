## IPresentation.RefreshChartsData methode

Laadt de gegevens voor alle grafieken in de presentatie opnieuw vanuit hun bronwerkboeken.

```csharp
public void RefreshChartsData(bool skipFailedCharts = true)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| skipFailedCharts | Boolean | Bepaalt of het vernieuwingsproces doorgaat als een grafiek niet kan worden bijgewerkt. Als `true`, worden grafieken die een uitzondering veroorzaken overgeslagen; anders wordt de uitzondering doorgegeven. |

### Voorbeelden

```csharp
using (var presentation = new Presentation("PresentationWithCharts.pptx"))
{
    presentation.RefreshChartsData();
    presentation.Save("PresentationWithCharts-out.pptx", SaveFormat.Pptx);
}
```
