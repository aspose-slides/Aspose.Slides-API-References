## IDataLabelCollection.DefaultLabelShapeType eigenschap

Haalt op of stelt het standaardvormtype voor gegevenslabels in. Retourneert NotDefined als er geen vorm is gedefinieerd.

```csharp
public ShapeType DefaultLabelShapeType { get; set; }
```

### Opmerkingen

Het instellen van deze eigenschap stelt ook de [`LabelShapeType`](../../idatalabel/labelshapetype) eigenschap voor alle gegevenslabels in de collectie in op dezelfde waarde.

### Voorbeelden

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[1];
    var firstSeries = chart.ChartData.Series[0];

    // Stel het vormtype van alle gegevenslabels in de eerste reeks in op Ellipse.
    firstSeries.Labels.DefaultLabelShapeType = ShapeType.Ellipse;

    pres.Save("ChartWithEllipseLabels.pptx", SaveFormat.Pptx);
}
```
