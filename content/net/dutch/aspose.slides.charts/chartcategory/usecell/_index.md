## ChartCategory.UseCell eigenschap

Als true dan is AsCell eigenschap van kracht. Met andere woorden wordt werkblad gebruikt voor het opslaan van een categorie (dit geval ondersteunt een meerlagige categorie). Als false dan is AsLiteral eigenschap van kracht. Met andere woorden wordt werkblad NIET gebruikt voor het opslaan van een categorie (en dit geval ondersteunt geen meerlagige categorieën). Alleen-lezen Boolean.

```csharp
public bool UseCell { get; }
```

### Opmerkingen

Om de waarde van deze eigenschap te wijzigen (voor alle categorieën in de collectie) stel je de nieuwe waarde in op ChartCategoryCollection.UseCells eigenschap.
