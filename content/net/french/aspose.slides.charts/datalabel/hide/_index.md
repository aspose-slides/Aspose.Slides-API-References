## DataLabel.Hide méthode

Rendre l'étiquette de données masquée en définissant tous les indicateurs Show*-flags (ShowValue, ...) sur l'état false. IsVisible sera false après cela.

```csharp
public void Hide()
```

### Remarques

Si l'étiquette de données n'est pas visible (IsVisible est false), vous pouvez rendre l'étiquette de données visible en définissant les indicateurs Show*-flags (ShowValue, ...) sur l'état true.
