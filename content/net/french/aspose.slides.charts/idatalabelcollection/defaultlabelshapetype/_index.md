## IDataLabelCollection.DefaultLabelShapeType propriété

Obtient ou définit le type de forme par défaut pour les étiquettes de données. Retourne NotDefined si aucune forme n'est définie.

```csharp
public ShapeType DefaultLabelShapeType { get; set; }
```

### Remarques

La définition de cette propriété définit également la propriété [`LabelShapeType`](../../idatalabel/labelshapetype) pour toutes les étiquettes de données de la collection à la même valeur.

### Exemples

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[1];
    var firstSeries = chart.ChartData.Series[0];

    // Définir le type de forme de toutes les étiquettes de données de la première série sur Ellipse.
    firstSeries.Labels.DefaultLabelShapeType = ShapeType.Ellipse;

    pres.Save("ChartWithEllipseLabels.pptx", SaveFormat.Pptx);
}
```
