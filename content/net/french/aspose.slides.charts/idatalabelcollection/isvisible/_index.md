## IDataLabelCollection.IsVisible propriété

False signifie que l'étiquette de données n'est pas visible par défaut (et donc tous les indicateurs Show*-flags (ShowValue, ...) de la propriété DefaultDataLabelFormat sont false). Lecture seule Boolean.

```csharp
public bool IsVisible { get; }
```

### Remarques

Si l'étiquette de données est visible par défaut, vous pouvez la masquer par défaut avec la méthode Hide(). Mais si l'étiquette de données n'est pas visible par défaut (IsVisible est false), vous pouvez rendre l'étiquette de données « visible par défaut » en définissant les indicateurs Show*-flags (ShowValue, ...) de la propriété DefaultDataLabelFormat à l'état true.
