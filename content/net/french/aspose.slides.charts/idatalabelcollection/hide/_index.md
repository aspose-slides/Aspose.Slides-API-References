## IDataLabelCollection.Hide method

Masquez l'étiquette de données par défaut en définissant tous les drapeaux Show*- (ShowValue, ...) de la propriété DefaultDataLabelFormat sur l'état false. IsVisible sera false après cela.

```csharp
public void Hide()
```

### Remarques

Si l'étiquette de donnée n'est pas visible par défaut (IsVisible est false), vous pouvez rendre l'étiquette de donnée « visible par défaut » en définissant les drapeaux Show*- (ShowValue, ...) de la propriété DefaultDataLabelFormat sur l'état true.
