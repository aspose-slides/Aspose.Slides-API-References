## PieSplitType énumération

Représente un type de points de division dans le deuxième secteur ou la deuxième barre d'un graphique pie-of-pie ou bar-of-pie.

```csharp
public enum PieSplitType
```

### Valeurs

| Name | Value | Description |
| --- | --- | --- |
| Default | `0` | Spécifie que les points de données doivent être divisés en utilisant le mécanisme par défaut pour ce type de graphique. |
| Custom | `1` | Spécifie que les points de données doivent être divisés entre le secteur et le deuxième graphique selon les valeurs Custom Split. |
| ByPercentage | `2` | Spécifie que les points de données doivent être divisés entre le secteur et le deuxième graphique en plaçant les points dont le pourcentage est inférieur à Split Position pour cent dans le deuxième graphique. |
| ByPos | `3` | Spécifie que les points de données doivent être divisés entre le secteur et le deuxième graphique en plaçant la dernière Split Position des points de données dans le deuxième graphique. |
| ByValue | `4` | Spécifie que les points de données doivent être divisés entre le secteur et le deuxième graphique en plaçant les points de données dont la valeur est inférieure à Split Position dans le deuxième graphique. |
