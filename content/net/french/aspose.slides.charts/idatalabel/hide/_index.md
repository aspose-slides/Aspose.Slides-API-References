## IDataLabel.Hide méthode

Masquez l'étiquette de données en définissant tous les indicateurs Show*-flags (ShowValue, ...) à l'état false. IsVisible sera false après cela.

```csharp
public void Hide()
```

### Remarques

Si l'étiquette de données n'est pas visible (IsVisible est false) vous pouvez rendre l'étiquette de données visible en définissant les indicateurs Show*-flags (ShowValue, ...) à l'état true.
