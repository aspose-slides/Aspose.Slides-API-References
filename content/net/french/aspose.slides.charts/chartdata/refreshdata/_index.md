## ChartData.RefreshData méthode

Actualise les données du graphique en les rechargeant depuis le classeur source.

```csharp
public void RefreshData()
```

### Exceptions

| exception | condition |
| --- | --- |
| InvalidOperationException | Lancée lorsque le format du classeur n'est pas pris en charge, ou lorsque [`DataSourceType`](../datasourcetype) est ExternalWorkbook et que le classeur externe ne peut pas être accédé ou chargé. |

### Remarques

Si le graphique utilise un classeur externe, le classeur doit être accessible au moment de l'appel.

### Exemples

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
