## DataLabelCollection.IsVisible propriété

False signifie que l'étiquette de données n'est pas visible par défaut (et que tous les indicateurs Show*-flags (ShowValue, ...) de la propriété DefaultDataLabelFormat sont à false). Booléen en lecture seule.

```csharp
public bool IsVisible { get; }
```

### Remarques

Si l'étiquette de données est visible par défaut, vous pouvez la rendre cachée par défaut avec la méthode Hide(). Mais si l'étiquette de données n'est pas visible par défaut (IsVisible est false), vous pouvez rendre l'étiquette de données « visible par défaut » en réglant les indicateurs Show*-flags (ShowValue, ...) de la propriété DefaultDataLabelFormat sur l'état true.
