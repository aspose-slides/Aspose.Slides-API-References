## SmartArtLayoutType énumération

Représente le type de mise en page d'un diagramme SmartArt.

```csharp
public enum SmartArtLayoutType
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| AccentProcess | `0` | Utilisé pour afficher une progression, une chronologie ou des étapes séquentielles dans une tâche, un processus ou un flux de travail. Fonctionne bien pour illustrer les textes de niveau 1 et de niveau 2. |
| AccentedPicture | `1` | Utilisé pour présenter une idée centrale, photographique, avec des idées connexes sur le côté. Le texte de niveau 1 supérieur apparaît au-dessus de l'image centrale. | AlternatingPictureBlocks | `4` | Utilisé pour présenter une série d'images de haut en bas. Le texte apparaît alternativement à droite ou à gauche de l'image. |
