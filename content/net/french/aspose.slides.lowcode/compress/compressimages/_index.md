## Compress.CompressImages méthode

Réduit la résolution des images de la présentation et supprime leurs zones recadrées, similaire à "Compress Pictures" de PowerPoint appliqué à toutes les images. Les images sur les diapositives, les diapositives de disposition et les diapositives maîtres sont traitées, y compris les images à l'intérieur des formes groupées et les remplissages d'images des formes.

```csharp
public static void CompressImages(IPresentation presentation, PicturesCompression resolution)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| presentation | IPresentation | La présentation à traiter. |
| resolution | PicturesCompression | Résolution cible relative à la taille à laquelle chaque image est affichée. DocumentResolution laisse les images inchangées. |

### Exceptions

| exception | condition |
| --- | --- |
| ArgumentNullException | *presentation* est `null`. |

### Remarques

Les images déjà à la résolution cible ou en dessous sont laissées inchangées ; les images ne sont jamais agrandies.

Non traité : arrière-plans de diapositives, remplissages de cellules de tableau, graphiques, SmartArt, images GIF (pour préserver l'animation), images SVG et méta-fichiers (EMF/WMF).

Les zones recadrées sont supprimées de façon permanente et ne peuvent pas être restaurées dans PowerPoint.

### Exemples

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    CompressImages(pres, PicturesCompression.Dpi150);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
