## Compress.CompressPresentation méthode

Réduit la taille d’une présentation en appliquant toutes les étapes de compression disponibles :

* Supprime les diapos maîtres inutilisées [`RemoveUnusedMasterSlides`](../removeunusedmasterslides).
* Supprime les diapos de mise en page inutilisées [`RemoveUnusedLayoutSlides`](../removeunusedlayoutslides).
* Conserve uniquement les glyphes réellement utilisés dans les polices incorporées [`CompressEmbeddedFonts`](../compressembeddedfonts).
* Réduit la résolution des images à 150 DPI et supprime les zones recadrées des images [`CompressImages`](../compressimages).

```csharp
public static void CompressPresentation(Presentation presentation)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| presentation | Presentation | La présentation à compresser. |

### Exceptions

| exception | condition |
| --- | --- |
| ArgumentNullException | *presentation* est `null`. |

### Remarques

Pour personnaliser la compression, par exemple pour utiliser une résolution d’image différente ou pour sauter une étape, appelez les méthodes répertoriées ci-dessus individuellement au lieu de celle-ci. Les zones recadrées des images sont supprimées de façon permanente et ne peuvent pas être restaurées dans PowerPoint.

### Exemples

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    Aspose.Slides.LowCode.Compress.CompressPresentation(pres);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
