## MarkdownSaveOptions.MarkdownImageSavingHandler delegate

Appelé pour chaque image non SVG (bitmap ou metafile) lors de l'exportation Markdown. Retournez `true` pour utiliser le *lien* spécifié, ou `false` pour appliquer la logique d'enregistrement par défaut.

```csharp
public delegate bool MarkdownImageSavingHandler(IImage image, ImageFormat format, ref string link);
```

| image | IImage | L'image exportée (bitmap ou metafile). |
| format | ImageFormat | Le format de l'image. |
| link | String& | Le lien Markdown à utiliser lors du retour de `true`. |
