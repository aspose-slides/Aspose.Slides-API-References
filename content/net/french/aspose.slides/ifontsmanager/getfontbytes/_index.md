## IFontsManager.GetFontBytes méthode

Récupère le tableau d'octets représentant les données de police pour un style de police et des données de police spécifiés.

```csharp
public byte[] GetFontBytes(IFontData fontData, FontStyleType fontStyle)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| fontData | IFontData | L'objet de données de police contenant les informations sur la police [`IFontData`](../../ifontdata). |
| fontStyle | FontStyleType | Le style de la police pour lequel les données doivent être récupérées [`FontStyleType`](../../fontstyletype). |

### Valeur de retour

Un tableau d'octets contenant les données de police pour le style de police spécifié. Si les données de police ou le style ne sont pas trouvés, renvoie null.

### Exemples

```csharp
[C#]
using (Presentation pres = new Presentation ("Presentation.pptx"))
{
    // Récupérer toutes les polices utilisées dans la présentation
    IFontData[] fonts = pres.FontsManager.GetFonts();

    // Obtenir le tableau d'octets représentant le style régulier de la première police de la présentation
    byte[] bytes = pres.FontsManager.GetFontBytes(fonts[0], FontStyleType.Regular);
}
```
