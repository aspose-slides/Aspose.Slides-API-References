## IVideoFrame.VolumeValue propriété

Renvoie ou définit le volume vidéo exact en pourcentage. La valeur est exprimée en pourcentage de 0 à 100. Utilisez cette propriété pour lire ou définir des valeurs de volume plus précises que les niveaux prédéfinis disponibles via la propriété [`Volume`](../volume). Lecture/écriture Single.

```csharp
public float VolumeValue { get; set; }
```

### Exemples

Exemple :

```csharp
[C#]
using (Presentation pres = new Presentation("video.pptx"))
{
    IVideoFrame videoFrame = (IVideoFrame)pres.Slides[0].Shapes[0];

    // Lire le volume exact actuel et le définir à 75,5 pour cent.
    float currentVolume = videoFrame.VolumeValue;
    videoFrame.VolumeValue = 75.5f;

    pres.Save("video_with_volume.pptx", SaveFormat.Pptx);
}
```
