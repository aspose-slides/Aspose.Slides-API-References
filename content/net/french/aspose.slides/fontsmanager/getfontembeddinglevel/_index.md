## FontsManager.GetFontEmbeddingLevel méthode

Détermine le niveau d'incorporation d'une police à partir du tableau d'octets fourni et du nom de la police.

```csharp
public EmbeddingLevel GetFontEmbeddingLevel(byte[] fontBytes, string fontName)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| fontBytes | Byte[] | Le tableau d'octets contenant les données de la police. |
| fontName | String | Le nom de la police. |

### Valeur de retour

Le niveau d'incorporation de la police spécifiée.

### Exceptions

| exception | condition |
| --- | --- |
| ArgumentNullException | Levée lorsque *fontBytes* est nul. |

### Exemples

```csharp
[C#]
using (Presentation pres = new Presentation(pptxFileName))
{
    // Récupère toutes les polices utilisées dans la présentation
    IFontData[] fontDatas = pres.FontsManager.GetFonts();

    // Obtient le tableau d'octets représentant le style normal de la première police de la présentation
    byte[] bytes = pres.FontsManager.GetFontBytes(fontDatas[0], FontStyle.Regular);

    // Détermine le niveau d'incorporation de la police
    EmbeddingLevel embeddingLevel = pres.FontsManager.GetFontEmbeddingLevel(bytes, fontDatas[0].FontName);
}
```
