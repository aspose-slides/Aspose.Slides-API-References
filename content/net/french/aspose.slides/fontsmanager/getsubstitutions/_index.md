## GetSubstitutions() {#getsubstitutions}

Obtient les informations sur les polices qui seront remplacées lors du rendu de la présentation.

```csharp
public IEnumerable<FontSubstitutionInfo> GetSubstitutions()
```

### Valeur de retour

Collection de toutes les substitutions de polices [`FontSubstitutionInfo`](../../fontsubstitutioninfo).

### Exemples

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    foreach (FontSubstitutionInfo fontSubstitution in pres.FontsManager.GetSubstitutions())
    {
        Console.WriteLine("{0} -> {1}", fontSubstitution.OriginalFontName, fontSubstitution.SubstitutedFontName);
    }
}        
```

## GetSubstitutions(int[]) {#getsubstitutions_1}

Obtient les informations sur les polices qui seront remplacées lors du rendu des diapositives spécifiées.

```csharp
public IEnumerable<FontSubstitutionInfo> GetSubstitutions(int[] slides)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| slides | Int32[] | Un tableau d'index de diapositives pour lesquelles récupérer les informations de substitution de police, commençant à 1. |

### Valeur de retour

Une collection de toutes les substitutions de polices ([`FontSubstitutionInfo`](../../fontsubstitutioninfo)) pour les diapositives spécifiées.

### Exemples

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    int[] targetSlides = { 1, 2, 5 };
    foreach (var fontSubstitution in pres.FontsManager.GetSubstitutions(targetSlides))
    {
        Console.WriteLine("{0} -> {1}", fontSubstitution.OriginalFontName, fontSubstitution.SubstitutedFontName);
    }
}
```
