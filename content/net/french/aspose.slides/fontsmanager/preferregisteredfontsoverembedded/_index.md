## FontsManager.PreferRegisteredFontsOverEmbedded propriété

Spécifie si les polices enregistrées doivent être privilégiées par rapport aux polices intégrées portant le même nom et le même style. Lorsqu'elle est activée, les polices intégrées correspondantes sont temporairement remplacées par les polices enregistrées correspondantes lors de l'exportation.

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### Remarques

La valeur par défaut est **false**.

### Exemples

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
