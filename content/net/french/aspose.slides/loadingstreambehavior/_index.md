## LoadingStreamBehavior enumeration

Le Stream passe a une methode est considere comme un Binary Large Object (BLOB) (voir [`IBlobManagementOptions`](../iblobmanagementoptions) description). Les valeurs de cette enumeration identifient comment le Stream doit etre trate lorsqu'il est passe a la methode. En fonction des exigences, differentes decisions peuvent etre prises pour fournir le comportement le plus efficace.

```csharp
public enum LoadingStreamBehavior
```

### Values

| Nom | Valeur | Description |
| --- | --- | --- |
| ReadStreamAndRelease | `0` | Le stream sera lu jusqua la fin puis libere - c'est-a-dire qu'il sera garanti que ce stream ne sera pas utilise par l'instance [`IPresentation`](../ipresentation) a l avenir. Il peut etre ferme par le code client ou utilise de toute autre maniere. |
| KeepLocked | `1` | Le stream sera verrouille dans l'objet [`IPresentation`](../ipresentation), c'est-a-dire que la propriete du stream sera transferee. L'objet [`IPresentation`](../ipresentation) sera responsable de disposer correctement du stream lorsque cet objet sera lui-meme dispose. Ce comportement est extremement utile lorsque vous devez serialiser un gros fichier BLOB (tel qu'une grande video ou un audio - voir [`IBlobManagementOptions`](../iblobmanagementoptions) description) et que vous souhaitez eviter de charger ce fichier en memoire ou d'autres problemes de performances. Vous pouvez simplement ouvrir le FileStream pour ce fichier et le passer a une methode, en choisissant KeepLocked LoadingStreamBehavior. |
