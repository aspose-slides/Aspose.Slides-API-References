## Compress.CompressPresentation método

Reduz o tamanho de uma apresentação aplicando todas as etapas de compressão disponíveis:

* Remove slides mestre não utilizados [`RemoveUnusedMasterSlides`](../removeunusedmasterslides).
* Remove slides de layout não utilizados [`RemoveUnusedLayoutSlides`](../removeunusedlayoutslides).
* Mantém apenas os glifos realmente usados nas fontes incorporadas [`CompressEmbeddedFonts`](../compressembeddedfonts).
* Reduz a resolução das imagens para 150 DPI e exclui áreas recortadas das imagens [`CompressImages`](../compressimages).

```csharp
public static void CompressPresentation(Presentation presentation)
```

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| presentation | Presentation | A apresentação a ser comprimida. |

### Exceções

| exceção | condição |
| --- | --- |
| ArgumentNullException | *presentation* é `null`. |

### Observações

Para personalizar a compressão, por exemplo para usar uma resolução de imagem diferente ou para pular uma etapa, chame os métodos listados acima individualmente em vez deste. As áreas recortadas das imagens são removidas permanentemente e não podem ser restauradas no PowerPoint.

### Exemplos

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    Aspose.Slides.LowCode.Compress.CompressPresentation(pres);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
