## Compress.CompressImages método

Reduz a resolução das imagens na apresentação e exclui suas áreas recortadas, similar ao “Compactar Imagens” do PowerPoint aplicado a todas as imagens. Imagens em slides, slides de layout e slides mestre são processadas, incluindo imagens dentro de formas agrupadas e preenchimentos de imagem de formas.

```csharp
public static void CompressImages(IPresentation presentation, PicturesCompression resolution)
```

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| presentation | IPresentation | A apresentação a ser processada. |
| resolution | PicturesCompression | Resolução alvo relativa ao tamanho no qual cada imagem é exibida. DocumentResolution deixa as imagens inalteradas. |

### Exceções

| exceção | condição |
| --- | --- |
| ArgumentNullException | *presentation* é `null`. |

### Observações

Imagens já na resolução alvo ou abaixo dela permanecem inalteradas; imagens nunca são ampliadas.

Não processado: fundos de slide, preenchimentos de célula de tabela, gráficos, SmartArt, imagens GIF (para preservar a animação), imagens SVG e metafile (EMF/WMF).

Áreas recortadas são removidas permanentemente e não podem ser restauradas no PowerPoint.

### Exemplos

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    CompressImages(pres, PicturesCompression.Dpi150);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
