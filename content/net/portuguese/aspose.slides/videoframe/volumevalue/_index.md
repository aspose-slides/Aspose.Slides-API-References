## VideoFrame.VolumeValue propriedade

Retorna ou define o volume exato do vídeo como uma porcentagem. O valor é expresso como uma porcentagem de 0 a 100. Use esta propriedade para ler ou definir valores de volume que são mais precisos do que os níveis predefinidos disponíveis através da [`Volume`](../volume) propriedade. Leitura/gravação Single.

```csharp
public float VolumeValue { get; set; }
```

### Exemplos

Exemplo:

```csharp
[C#]
using (Presentation pres = new Presentation("video.pptx"))
{
    IVideoFrame videoFrame = (IVideoFrame)pres.Slides[0].Shapes[0];

    // Leia o volume exato atual e defina-o para 75,5 por cento.
    float currentVolume = videoFrame.VolumeValue;
    videoFrame.VolumeValue = 75.5f;

    pres.Save("video_with_volume.pptx", SaveFormat.Pptx);
}
```
