## Presentation.RefreshChartsData método

Recarrega os dados de todos os gráficos na apresentação a partir de suas planilhas de origem.

```csharp
public void RefreshChartsData(bool skipFailedCharts = true)
```

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| skipFailedCharts | Boolean | Determina se o processo de atualização continua caso um gráfico falhe ao atualizar. Se `true`, os gráficos que causam uma exceção são ignorados; caso contrário, a exceção é propagada. |

### Exemplos

```csharp
using (var presentation = new Presentation("PresentationWithCharts.pptx"))
{
    presentation.RefreshChartsData();
    presentation.Save("PresentationWithCharts-out.pptx", SaveFormat.Pptx);
}
```
