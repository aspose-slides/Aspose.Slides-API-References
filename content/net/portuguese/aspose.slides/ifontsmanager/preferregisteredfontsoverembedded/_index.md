## IFontsManager.PreferRegisteredFontsOverEmbedded property

Especifica se as fontes registradas devem ser preferidas em relação às fontes incorporadas com o mesmo nome e estilo de fonte. Quando habilitado, as fontes incorporadas correspondentes são temporariamente substituídas pelas fontes registradas correspondentes durante a exportação.

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### Observações

O padrão é **false**.

### Exemplos

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
