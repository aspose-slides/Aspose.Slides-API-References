## Enumeração LineSketchType

Representa o tipo de esboço ou efeito atribuído a uma forma.

```csharp
public enum LineSketchType
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| NotDefined | `-1` | Especifica que o efeito de esboço de uma forma é indefinido. |
| None | `0` | Especifica que uma forma não tem efeito de esboço. Isso é equivalente a esta propriedade estar vazia. |
| Curved | `1` | Especifica que uma forma tem o efeito Curved, que transforma cada borda da forma em uma grande curva suave. |
| Freehand | `2` | Especifica que uma forma tem o efeito Freehand, que se assemelha mais a uma linha desenhada de forma imperfeita. |
| Scribble | `3` | Especifica que uma forma tem o efeito Scribble, que possui oscilações exageradas como se fosse desenhada intencionalmente bagunçada. |
