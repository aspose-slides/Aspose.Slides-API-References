## ChartSeriesGroup.GapDepth propriedade

Gets or sets the distance between data series in a 3D chart, as a percentage of the marker width. The value must be between 0 and 500. Read/write UInt16.

```csharp
public ushort GapDepth { get; set; }
```

### Observações

This property applies to series of the following types: 3D bar and column subtypes (see also [`IsBar3DChart`](../../charttypecharacterizer/isbar3dchart) método), Line3D, Area3D, StackedArea3D, PercentsStackedArea3D.
