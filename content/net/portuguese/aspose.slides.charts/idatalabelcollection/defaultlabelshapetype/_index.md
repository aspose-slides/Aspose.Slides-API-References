## IDataLabelCollection.DefaultLabelShapeType propriedade

Obtém ou define o tipo de forma padrão para rótulos de dados. Retorna NotDefined se nenhuma forma estiver definida.

```csharp
public ShapeType DefaultLabelShapeType { get; set; }
```

### Observações

Definir esta propriedade também define a propriedade [`LabelShapeType`](../../idatalabel/labelshapetype) para todos os rótulos de dados na coleção com o mesmo valor.

### Exemplos

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[1];
    var firstSeries = chart.ChartData.Series[0];

    // Define o tipo de forma de todos os rótulos de dados na primeira série como Ellipse.
    firstSeries.Labels.DefaultLabelShapeType = ShapeType.Ellipse;

    pres.Save("ChartWithEllipseLabels.pptx", SaveFormat.Pptx);
}
```
