## IDataLabel.LabelShapeType propriedade

Obtém ou define o tipo de forma do rótulo de dados. Retorna NotDefined se nenhuma forma estiver definida.

```csharp
public ShapeType LabelShapeType { get; set; }
```

### Exemplos

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[1];
    var firstSeries = chart.ChartData.Series[0];

    // Define o tipo de forma do primeiro rótulo de dados como Ellipse.
    firstSeries.Labels[0].LabelShapeType = ShapeType.Ellipse;

    pres.Save("ChartWithEllipseLabel.pptx", SaveFormat.Pptx);
}
```
