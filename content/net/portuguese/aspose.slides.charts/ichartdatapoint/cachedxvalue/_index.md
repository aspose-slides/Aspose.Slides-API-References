## IChartDataPoint.CachedXValue propriedade

Obtém o valor X armazenado em cache de um ponto de dados do gráfico. Somente leitura [`ICachedChartValue`](../../icachedchartvalue).

### Exemplos

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[0];
    foreach (var series in chart.ChartData.Series)
    {
        // Imprime todos os valores X armazenados em cache da série do gráfico.

}
```
