## ChartData.RefreshData método

Atualiza os dados do gráfico recarregando-os a partir da pasta de trabalho de origem.

```csharp
public void RefreshData()
```

### Exceções

| exceção | condição |
| --- | --- |
| InvalidOperationException | Lançada quando o formato da pasta de trabalho não é suportado, ou quando [`DataSourceType`](../datasourcetype) é ExternalWorkbook e a pasta de trabalho externa não pode ser acessada ou carregada. |

### Observações

Se o gráfico usar uma pasta de trabalho externa, a pasta de trabalho deve estar acessível no momento da chamada.

### Exemplos

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
