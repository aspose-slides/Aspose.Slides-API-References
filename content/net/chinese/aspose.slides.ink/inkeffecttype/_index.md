## InkEffectType 枚举

指定一组预定义的墨水渲染视觉效果。每种效果对应一种纹理或图像，用于模拟样式化的墨水外观。这些值可用于在渲染期间自定义数字墨迹的视觉样式。

```csharp
public enum InkEffectType
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| NotDefined | `-1` | 效果未定义或未知。此值可用作默认或回退值。 |
| Bronze | `0` | 一种温暖的棕色金属纹理，类似青铜墨水。 |
| Galaxy | `1` | 一种多彩、闪烁的纹理，类似星系，带有宇宙色调。 |
| Gold | `2` | 一种明亮的金属金色纹理，使墨迹呈现奢华外观。 |
| Lava | `3` | 一种炽热的纹理，类似熔化的岩浆，带有红色和橙色的色调。 |
| Ocean | `4` | 一种深蓝色、如流体般的纹理，模仿海浪或水基墨水。 |
| RainbowGlitter | `5` | 一种多彩、闪亮的彩虹亮粉效果，用于节日或鲜艳的墨迹。 |
| RoseGold | `6` | 一种柔和的粉金色混合，类似玫瑰金，用于优雅的墨迹。 |
| Silver | `7` | 一种冷色调的金属银色纹理，模拟经典的银墨水。 |
