## EmbeddingLevel 枚举

表示用于嵌入字体的许可权。

```csharp
[Flags]
public enum EmbeddingLevel : ushort
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| Installable | `0` | 具有此设置的字体表示它们可以被嵌入并永久安装在远程系统上，由应用程序完成。远程系统的用户获得与原始购买者相同的该字体的权利、义务和许可，并受相同的最终用户许可协议、版权、设计专利和/或商标约束，就像原始购买者一样。 |
| Restricted | `2` | 仅设置此位的字体不得在未先获得合法所有者许可的情况下以任何方式修改、嵌入或交换。 |
| PreviewPrint | `4` | 当此位被设置时，字体可以被嵌入，并临时加载到远程系统。包含预览&amp;打印字体的文档必须以只读方式打开；文档不可进行编辑。 |
| Editable | `8` | 当此位被设置时，字体可以被嵌入，但只能在其他系统上临时安装。与预览&amp;打印字体相比，包含可编辑字体的文档可打开进行阅读，允许编辑，并且可以保存更改。 |
| NoSubsetting | `100` | 当此位被设置时，字体在嵌入前不得进行子集化。位 0-3 和 9 中指定的其他嵌入限制也适用。 |
| BitmapOnly | `200` | 当此位被设置时，仅可以嵌入字体中包含的位图。轮廓数据不能被嵌入。如果字体中没有可用的位图，则该字体被视为不可嵌入，嵌入服务将失败。 |
