## PdfAccessPermissions 枚举

包含一组标志，指定在使用用户访问打开文档时应授予的访问权限。

```csharp
[Flags]
public enum PdfAccessPermissions
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| None | `0` | 指定用户没有访问权限。 |
| PrintDocument | `4` | 指定用户是否可以打印文档（可能未达到最高质量级别，取决于是否同时设置了位 HighQualityPrint）。 |
| ModifyContent | `8` | 指定用户是否可以通过除位 AddOrModifyFields、FillExistingFields、AssembleDocument 控制的操作之外的其他操作修改文档内容。 |
| CopyTextAndGraphics | `10` | 指定用户是否可以通过除位 ExtractTextAndGraphics 控制的操作之外的其他操作复制或提取文档中的文本和图形。 |
| AddOrModifyFields | `20` | 指定用户是否可以添加或修改文本批注、填写交互式表单字段，并且在位 ModifyContent 也被设置时，创建或修改交互式表单字段（包括签名字段）。 |
| FillExistingFields | `100` | 指定用户是否可以填写已有的交互式表单字段（包括签名字段），即使位 AddOrModifyFields 未设置。 |
| ExtractTextAndGraphics | `200` | 指定用户是否可以提取文本和图形，以支持残障用户的可访问性或用于其他目的。 |
| AssembleDocument | `400` | 指定用户是否可以组装文档（插入、旋转或删除页面并创建书签或缩略图），即使位 ModifyContent 未设置。 |
| HighQualityPrint | `800` | 指定用户是否可以将文档打印为能够生成 PDF 内容忠实数字副本的表示。当此位未设置且位 PrintDocument 已设置时，打印将受限于外观的低层次表示，可能质量下降。 |
