## CompressionLevel 枚举

指定 OpenXML 文件的 ZIP 压缩级别。更高的级别可以提供更好的压缩率，但会导致处理速度变慢。

```csharp
public enum CompressionLevel
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| None | `0` | 未应用压缩。文件保持原样存储。 |
| Level1 | `1` | 最快的压缩，压缩比最低。 |
| Level2 | `2` | 比 Level1 稍快的压缩，压缩比略有提升。 |
| Level3 | `3` | 在适度的性能影响下，提供比 Level2 更好的压缩。 |
| Level4 | `4` | 提供比 Level3 更好的压缩。 |
| Level5 | `5` | 在额外的处理时间下，提供比 Level4 改进的压缩。 |
| Level6 | `6` | 标准压缩，在压缩速度和文件大小之间提供良好的平衡。默认压缩级别。 |
| Level7 | `7` | 在处理速度较慢的情况下，提供比 Level6 更高的压缩。 |
| Level8 | `8` | 提供比 Level7 更高的压缩。 |
| Level9 | `9` | 最大压缩。产生最小的文件大小，但处理速度最慢。 |
