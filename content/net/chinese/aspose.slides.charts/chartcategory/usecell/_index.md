## ChartCategory.UseCell 属性

如果为 true，则 AsCell 属性为实际。换句话说，工作表用于存储类别（此情况支持多级类别）。如果为 false，则 AsLiteral 属性为实际。换句话说，工作表不用于存储类别（且此情况不支持多级类别）。只读 Boolean。

```csharp
public bool UseCell { get; }
```

### 备注

要更改此属性的值（针对集合中的所有类别），请将新值设置为 ChartCategoryCollection.UseCells 属性。
