## IDataLabelCollection.IsVisible 属性

False 表示数据标签默认不可见（并且 DefaultDataLabelFormat 属性的所有 Show*-flags（ShowValue，...）均为 false）。只读 Boolean。

```csharp
public bool IsVisible { get; }
```

### 备注

如果数据标签默认可见，则可以使用 Hide() 方法将其默认隐藏。若数据标签默认不可见（IsVisible 为 false），则可以通过将 DefaultDataLabelFormat 属性的 Show*-flags（ShowValue，...）设置为 true 状态，使数据标签“默认可见”。
