## IChartSeriesGroup.GapDepth 属性

获取或设置在 3D 图表中数据系列之间的距离，以标记宽度的百分比表示。该值必须介于 0 和 500 之间。读/写 UInt16.

```csharp
public ushort GapDepth { get; set; }
```

### 备注

此属性适用于以下类型的系列：3D bar and column subtypes、Line3D、Area3D、StackedArea3D、PercentsStackedArea3D。
