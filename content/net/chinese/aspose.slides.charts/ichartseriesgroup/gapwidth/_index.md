## IChartSeriesGroup.GapWidth 属性

获取或设置条形或柱形簇之间的空间，以条形或柱形宽度的百分比表示。值必须在0到500之间。读/写 UInt16。

```csharp
public ushort GapWidth { get; set; }
```

### 备注

此属性适用于以下类型的系列：所有条形和柱形子类型，BarOfPie，PieOfPie，BoxAndWhisker，Funnel，Histogram，Waterfall。
