## ChartSeriesGroup.GapDepth 属性

获取或设置 3D 图表中数据系列之间的距离，作为标记宽度的百分比。该值必须在 0 与 500 之间。读写 UInt16。

```csharp
public ushort GapDepth { get; set; }
```

### 备注

此属性适用于以下类型的系列：3D bar and column subtypes（另见 [`IsBar3DChart`](../../charttypecharacterizer/isbar3dchart) 方法），Line3D，Area3D，StackedArea3D，PercentsStackedArea3D。
