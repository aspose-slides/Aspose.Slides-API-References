## ChartSeriesGroup.GapWidth 属性

获取或设置条形图或柱形图簇之间的间距，作为条形图或柱形图宽度的百分比。该值必须在 0 到 500 之间。读/写 UInt16.

```csharp
public ushort GapWidth { get; set; }
```

### 备注
