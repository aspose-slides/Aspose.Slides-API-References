## IChartData.RefreshData 方法

通过从源工作簿重新加载来刷新图表数据。

```csharp
public void RefreshData()
```

### 异常

| 异常 | 条件 |
| --- | --- |
| InvalidOperationException | 当工作簿格式不受支持，或当 [`DataSourceType`](../datasourcetype) 为 ExternalWorkbook 且无法访问或加载外部工作簿时抛出。 |

### 备注

如果图表使用外部工作簿，则在调用时必须能够访问该工作簿。

### 示例

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
