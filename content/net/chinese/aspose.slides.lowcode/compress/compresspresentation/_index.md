## Compress.CompressPresentation 方法

通过应用所有可用的压缩步骤来减小演示文稿的大小：

* 删除未使用的母版幻灯片 [`RemoveUnusedMasterSlides`](../removeunusedmasterslides).
* 删除未使用的布局幻灯片 [`RemoveUnusedLayoutSlides`](../removeunusedlayoutslides).
* 仅保留嵌入字体中实际使用的字形 [`CompressEmbeddedFonts`](../compressembeddedfonts).
* 将图片分辨率降低至 150 DPI 并删除图片的裁剪区域 [`CompressImages`](../compressimages).

```csharp
public static void CompressPresentation(Presentation presentation)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| presentation | Presentation | 要压缩的演示文稿。 |

### 异常

| 异常 | 条件 |
| --- | --- |
| ArgumentNullException | *presentation* 为 `null`。 |

### 备注

要自定义压缩，例如使用不同的图片分辨率或跳过某个步骤，请单独调用上述方法，而不是调用此方法。图片的裁剪区域会被永久删除，且在 PowerPoint 中无法恢复。

### 示例

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    Aspose.Slides.LowCode.Compress.CompressPresentation(pres);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
