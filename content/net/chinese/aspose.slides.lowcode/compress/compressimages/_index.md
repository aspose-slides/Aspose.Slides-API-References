## Compress.CompressImages 方法

降低演示文稿中图片的分辨率并删除其裁剪区域，类似于 PowerPoint 对所有图片应用的 “Compress Pictures”。对幻灯片、版式幻灯片和母版幻灯片中的图片进行处理，包括组形状中的图片以及形状的图片填充。

```csharp
public static void CompressImages(IPresentation presentation, PicturesCompression resolution)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| presentation | IPresentation | 需要处理的演示文稿。 |
| resolution | PicturesCompression | 相对于每张图片显示尺寸的目标分辨率。DocumentResolution 保持图片不变。 |

### 异常

| 异常 | 条件 |
| --- | --- |
| ArgumentNullException | *presentation* 为 `null`。 |

### 备注

已达到或低于目标分辨率的图片保持不变；图片永不放大。

未处理的内容：幻灯片背景、表格单元格填充、图表、SmartArt、GIF 图像（以保留动画）、SVG 和元文件（EMF/WMF）图像。

裁剪区域将被永久删除，且无法在 PowerPoint 中恢复。

### 示例

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    CompressImages(pres, PicturesCompression.Dpi150);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
