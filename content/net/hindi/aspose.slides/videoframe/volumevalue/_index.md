## VideoFrame.VolumeValue गुण

Returns or sets the exact video volume as a percentage. The value is expressed as a percentage from 0 to 100. Use this property to read or set volume values that are more precise than the predefined levels available through the [`Volume`](../volume) property. पढ़ें/लिखें Single.

```csharp
public float VolumeValue { get; set; }
```

### उदाहरण

Example:

```csharp
[C#]
using (Presentation pres = new Presentation("video.pptx"))
{
    IVideoFrame videoFrame = (IVideoFrame)pres.Slides[0].Shapes[0];

    // वर्तमान सटीक वॉल्यूम पढ़ें और इसे 75.5 प्रतिशत पर सेट करें।
    float currentVolume = videoFrame.VolumeValue;
    videoFrame.VolumeValue = 75.5f;

    pres.Save("video_with_volume.pptx", SaveFormat.Pptx);
}
```
