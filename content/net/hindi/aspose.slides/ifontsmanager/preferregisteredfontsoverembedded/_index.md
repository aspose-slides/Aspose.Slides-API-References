## IFontsManager.PreferRegisteredFontsOverEmbedded प्रॉपर्टी

निर्दिष्ट करता है कि समान फ़ॉन्ट नाम और शैली वाले एम्बेडेड फ़ॉन्ट्स की बजाय पंजीकृत फ़ॉन्ट्स को प्राथमिकता दी जानी चाहिए या नहीं। सक्षम होने पर, मेल खाते एम्बेडेड फ़ॉन्ट्स को निर्यात के दौरान अस्थायी रूप से संबंधित पंजीकृत फ़ॉन्ट्स से बदल दिया जाता है।

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### टिप्पणी

डिफ़ॉल्ट **false** है।

### उदाहरण

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
