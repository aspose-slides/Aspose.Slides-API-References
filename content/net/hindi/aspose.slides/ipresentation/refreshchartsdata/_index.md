## IPresentation.RefreshChartsData मेथड

प्रेजेंटेशन में सभी चार्ट्स के डेटा को उनके स्रोत वर्कबुक्स से पुनः लोड करता है।

```csharp
public void RefreshChartsData(bool skipFailedCharts = true)
```

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| skipFailedCharts | Boolean | निर्धारित करता है कि यदि कोई चार्ट अपडेट होने में विफल रहता है तो रीफ़्रेश प्रक्रिया जारी रहती है या नहीं। यदि `true` है, तो वह चार्ट्स जो अपवाद उत्पन्न करते हैं उन्हें छोड़ दिया जाता है; अन्यथा अपवाद आगे बढ़ाया जाता है। |

### उदाहरण

```csharp
using (var presentation = new Presentation("PresentationWithCharts.pptx"))
{
    presentation.RefreshChartsData();
    presentation.Save("PresentationWithCharts-out.pptx", SaveFormat.Pptx);
}
```
