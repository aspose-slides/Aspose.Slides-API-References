## TextFrame.HighlightRegex विधि

निर्दिष्ट रंग के साथ नियमित अभिव्यक्ति के सभी मिलान को हाइलाइट करता है।

```csharp
public void HighlightRegex(Regex regex, Color highlightColor, IFindResultCallback callback)
```

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| regex | Regex | हाइलाइट करने के लिए स्ट्रिंग्स प्राप्त करने हेतु नियमित अभिव्यक्ति Regex। |
| highlightColor | Color | पाठ को हाइलाइट करने के लिये रंग। |
| callback | IFindResultCallback | खोज परिणाम प्राप्त करने के लिये कॉलबैक ऑब्जेक्ट [`IFindResultCallback`](../../ifindresultcallback)। |

### उदाहरण

निम्नलिखित कोड उदाहरण दिखाता है कि कैसे नियमित अभिव्यक्ति का उपयोग करके TextFrame में पाठ को हाइलाइट किया जाए।

```csharp
[C#]
using (Presentation presentation = new Presentation("SomePresentation.pptx"))
{
	Regex regex = new Regex(@"\b[^\s]{10,}\b");
	// 10 या अधिक अक्षरों वाले सभी शब्दों को हाइलाइट कर रहा है
	((AutoShape)presentation.Slides[0].Shapes[0]).TextFrame.HighlightRegex(regex, Color.Blue, null);
	presentation.Save("SomePresentation-out.pptx", SaveFormat.Pptx);
}
```
