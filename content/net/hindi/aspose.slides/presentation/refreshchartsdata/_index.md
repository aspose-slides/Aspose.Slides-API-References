## Presentation.RefreshChartsData मेथड

प्रेजेंटेशन में सभी चार्ट्स का डेटा उनके स्रोत वर्कबुक्स से पुनः लोड करता है।

```csharp
public void RefreshChartsData(bool skipFailedCharts = true)
```

| पैरामीटर | प्रकार | विवरण |
| --- | --- | --- |
| skipFailedCharts | Boolean | निर्धारित करता है कि यदि कोई चार्ट अपडेट नहीं हो पाता है तो रीफ़्रेश प्रक्रिया जारी रहेगी या नहीं। यदि `true` हो तो वह चार्ट जो अपवाद उत्पन्न करता है, उसे छोड़ दिया जाता है; अन्यथा अपवाद को आगे बढ़ाया जाता है। |

### उदाहरण

```csharp
using (var presentation = new Presentation("PresentationWithCharts.pptx"))
{
    presentation.RefreshChartsData();
    presentation.Save("PresentationWithCharts-out.pptx", SaveFormat.Pptx);
}
```
