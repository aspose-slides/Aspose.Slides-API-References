## ITextFrame.SplitTextByColumns मेथड

[`ITextFrame`](../../itextframe) के टेक्स्ट कंटेंट को स्ट्रिंग्स की एरे में विभाजित करता है, जहाँ प्रत्येक तत्व फ्रेम के भीतर एक अलग टेक्स्ट कॉलम के अनुरूप होता है।

```csharp
public string[] SplitTextByColumns()
```

### रिटर्न वैल्यू

एक स्ट्रिंग्स की एरे, जहाँ प्रत्येक स्ट्रिंग [`ITextFrame`](../../itextframe) में एक विशिष्ट कॉलम के टेक्स्ट कंटेंट को दर्शाती है।

### टिप्पणियाँ

यदि टेक्स्ट फ्रेम में कई कॉलम नहीं हैं, तो वापस किया गया एरे एक ही तत्व में पूर्ण टेक्स्ट रखेगा। खाली कॉलम एरे में खाली स्ट्रिंग्स के रूप में दर्शाए जाएंगे।

### उदाहरण

निम्न उदाहरण दर्शाता है कि `SplitTextByColumns` का उपयोग कैसे किया जाता है:

```csharp
using (Presentation pres = new Presentation("example.pptx"))
{
    // स्लाइड पर पहली शेप प्राप्त करें और इसे ITextFrame में कास्ट करें
    ITextFrame textFrame = pres.Slides[0].Shapes[0] as ITextFrame;
    // टेक्स्ट फ्रेम की सामग्री को कॉलम में विभाजित करें
    string[] columnsText = textFrame.SplitTextByColumns();
    // प्रत्येक कॉलम का टेक्स्ट कंसोल पर प्रिंट करें
    foreach (string column in columnsText)
        Console.WriteLine(column);
}
```
