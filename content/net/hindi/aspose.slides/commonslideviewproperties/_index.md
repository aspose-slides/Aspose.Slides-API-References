### उदाहरण

निम्नलिखित उदाहरण दिखाता है कि PowerPoint प्रेजेंटेशन के स्लाइड के लिए ज़ूम मान कैसे सेट किया जाए।

```csharp
[C#]
// एक Presentation ऑब्जेक्ट बनाता है जो प्रेज़ेंटेशन फ़ाइल का प्रतिनिधित्व करता है
using (Presentation presentation = new Presentation("demo.pptx"))
{
    // Presentation के व्यू गुणों को सेट करना
    presentation.ViewProperties.SlideViewProperties.Scale = 100; // स्लाइड व्यू के लिए प्रतिशत में ज़ूम मान
	presentation.ViewProperties.NotesViewProperties.Scale = 100; // नोट्स व्यू के लिए प्रतिशत में ज़ूम मान
    presentation.Save("Zoom_out.pptx", SaveFormat.Pptx);
}
```
