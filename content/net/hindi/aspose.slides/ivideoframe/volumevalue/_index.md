## IVideoFrame.VolumeValue प्रॉपर्टी

वीडियो की सटीक वॉल्यूम को प्रतिशत के रूप में लौटाता है या सेट करता है। मान 0 से 100 के बीच प्रतिशत के रूप में व्यक्त किया जाता है। इस प्रॉपर्टी का उपयोग करके ऐसे वॉल्यूम मान पढ़ें या सेट करें जो [`Volume`](../volume) प्रॉपर्टी के माध्यम से उपलब्ध पूर्वनिर्धारित स्तरों से अधिक सटीक हों। पढ़ने/लिखने योग्य Single.

```csharp
public float VolumeValue { get; set; }
```

### उदाहरण

उदाहरण:

```csharp
[C#]
using (Presentation pres = new Presentation("video.pptx"))
{
    IVideoFrame videoFrame = (IVideoFrame)pres.Slides[0].Shapes[0];

    // वर्तमान सटीक वॉल्यूम पढ़ें और इसे 75.5 प्रतिशत पर सेट करें।
    float currentVolume = videoFrame.VolumeValue;
    videoFrame.VolumeValue = 75.5f;

    pres.Save("video_with_volume.pptx", SaveFormat.Pptx);
}
```
