## ChartData.RefreshData मेथड

स्रोत वर्कबुक से पुनः लोड करके चार्ट डेटा को रीफ़्रेश करता है।

```csharp
public void RefreshData()
```

### अपवाद

| अपवाद | स्थिति |
| --- | --- |
| InvalidOperationException | जब वर्कबुक फ़ॉर्मेट समर्थित नहीं है, या जब [`DataSourceType`](../datasourcetype) ExternalWorkbook है और बाहरी वर्कबुक तक पहुँच नहीं हो पा रही है या लोड नहीं किया जा सकता। |

### टिप्पणियाँ

यदि चार्ट बाहरी वर्कबुक का उपयोग करता है, तो कॉल के समय वर्कबुक सुलभ होनी चाहिए।

### उदाहरण

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
