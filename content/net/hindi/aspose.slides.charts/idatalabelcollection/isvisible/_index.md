## IDataLabelCollection.IsVisible प्रॉपर्टी

False का अर्थ है कि डेटा लेबल डिफ़ॉल्ट रूप से दिखाई नहीं देता (और इसलिए DefaultDataLabelFormat प्रॉपर्टी के सभी Show*-flags (ShowValue, ...) false होते हैं). Read-only Boolean.

```csharp
public bool IsVisible { get; }
```

### टिप्पणियाँ

यदि डेटा लेबल डिफ़ॉल्ट रूप से दिखाई देता है तो आप Hide() मेथड से इसे डिफ़ॉल्ट रूप से छिपा सकते हैं। लेकिन यदि डेटा लेबल डिफ़ॉल्ट रूप से दिखाई नहीं देता (IsVisible false है) तो आप Show*-flags (ShowValue, ...) को true स्थिति में सेट करके डेटा लेबल को "visible by default" बना सकते हैं।
