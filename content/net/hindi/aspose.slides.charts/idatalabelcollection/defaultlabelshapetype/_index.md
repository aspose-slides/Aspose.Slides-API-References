## IDataLabelCollection.DefaultLabelShapeType प्रॉपर्टी

डेटा लेबल्स के लिए डिफ़ॉल्ट शेपे प्रकार को प्राप्त करता है या सेट करता है। यदि कोई शेपे परिभाषित नहीं है तो NotDefined वापस करता है।

```csharp
public ShapeType DefaultLabelShapeType { get; set; }
```

### टिप्पणी

इस प्रॉपर्टी को सेट करने से संग्रह में सभी डेटा लेबल्स के लिए [`LabelShapeType`](../../idatalabel/labelshapetype) प्रॉपर्टी भी समान मान पर सेट हो जाती है।

### उदाहरण

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[1];
    var firstSeries = chart.ChartData.Series[0];

    // पहली श्रृंखला में सभी डेटा लेबल्स के शेपे प्रकार को Ellipse पर सेट करें।
    firstSeries.Labels.DefaultLabelShapeType = ShapeType.Ellipse;

    pres.Save("ChartWithEllipseLabels.pptx", SaveFormat.Pptx);
}
```
