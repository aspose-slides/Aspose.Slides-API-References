## DataLabelCollection.DefaultLabelShapeType प्रॉपर्टी

डेटा लेबल के लिए डिफ़ॉल्ट शेप टाइप को प्राप्त करता है या सेट करता है। यदि कोई शेप परिभाषित नहीं है तो NotDefined लौटाता है।

```csharp
public ShapeType DefaultLabelShapeType { get; set; }
```

### टिप्पणियाँ

इस प्रॉपर्टी को सेट करने से संग्रह में सभी डेटा लेबल के लिए [`LabelShapeType`](../../idatalabel/labelshapetype) प्रॉपर्टी भी समान मान पर सेट हो जाती है।

### उदाहरण

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[1];
    var firstSeries = chart.ChartData.Series[0];

    // पहले सीरीज़ में सभी डेटा लेबल के शेप टाइप को Ellipse पर सेट करता है।
    firstSeries.Labels.DefaultLabelShapeType = ShapeType.Ellipse;

    pres.Save("ChartWithEllipseLabels.pptx", SaveFormat.Pptx);
}
```
