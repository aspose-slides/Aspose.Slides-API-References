## DataLabelCollection.IsVisible प्रॉपर्टी

False का अर्थ है कि डेटा लेबल डिफ़ॉल्ट रूप से दृश्यमान नहीं है (और इसलिए DefaultDataLabelFormat प्रॉपर्टी के सभी Show*-फ़्लैग (ShowValue, ...) false होते हैं)। पढ़ने-केवल Boolean.

```csharp
public bool IsVisible { get; }
```

### टिप्पणी

यदि डेटा लेबल डिफ़ॉल्ट रूप से दृश्यमान है तो आप इसे Hide() मेथड के साथ डिफ़ॉल्ट रूप से छिपा सकते हैं। लेकिन यदि डेटा लेबल डिफ़ॉल्ट रूप से दृश्यमान नहीं है (IsVisible false है) तो आप Show*-फ़्लैग (ShowValue, ...) को true स्थिति पर सेट करके DefaultDataLabelFormat प्रॉपर्टी के साथ डेटा लेबल को "डिफ़ॉल्ट रूप से दृश्यमान" बना सकते हैं।
