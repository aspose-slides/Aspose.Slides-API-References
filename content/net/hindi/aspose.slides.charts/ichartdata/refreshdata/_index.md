## IChartData.RefreshData मेथड

स्रोत workbook से लोड करके चार्ट डेटा को रीफ़्रेश करता है।

```csharp
public void RefreshData()
```

### अपवाद

| अपवाद | स्थिति |
| --- | --- |
| InvalidOperationException | जब workbook स्वरूप समर्थित नहीं है, या जब [`DataSourceType`](../datasourcetype) ExternalWorkbook है और बाहरी workbook को पहुंचा नहीं जा सकता या लोड नहीं किया जा सकता। |

### टिप्पणियाँ

यदि चार्ट एक बाहरी workbook का उपयोग करता है, तो कॉल के समय workbook सुलभ होना चाहिए।

### उदाहरण

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
