## FontsManager.PreferRegisteredFontsOverEmbedded 속성

같은 글꼴 이름 및 스타일을 가진 등록된 글꼴과 포함된 글꼴 중에서 등록된 글꼴을 선호할지 여부를 지정합니다. 사용하도록 설정하면, 일치하는 포함된 글꼴이 내보내기 중에 해당 등록된 글꼴로 일시적으로 교체됩니다.

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### 비고

기본값은 **false**입니다.

### 예제

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
