## Zip64Mode 열거형

OpenXML 파일에 대해 ZIP64 형식 확장을 언제 사용할지 지정합니다.

```csharp
public enum Zip64Mode
```

### 값

| Name | Value | Description |
| --- | --- | --- |
| Never | `0` | ZIP64 형식 확장을 사용하지 않습니다. |
| IfNecessary | `1` | 필요한 경우 ZIP64 형식 확장을 사용합니다. |
| Always | `2` | 항상 ZIP64 형식 확장을 사용합니다. |

### 비고

OpenXML 파일은 파일의 압축 해제 크기, 압축 크기 및 전체 아카이브 크기에 4 GB(2^32 바이트) 제한과 아카이브 내 파일 수가 65,535(2^16-1)개로 제한되는 ZIP 아카이브입니다. ZIP64 형식 확장은 제한을 2^64까지 늘립니다.
