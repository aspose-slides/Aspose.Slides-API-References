## Compress.CompressPresentation 메서드

프레젠테이션의 크기를 사용 가능한 모든 압축 단계를 적용하여 줄입니다:

* 사용되지 않는 마스터 슬라이드를 제거합니다 [`RemoveUnusedMasterSlides`](../removeunusedmasterslides).
* 사용되지 않는 레이아웃 슬라이드를 제거합니다 [`RemoveUnusedLayoutSlides`](../removeunusedlayoutslides).
* 삽입된 글꼴에서 실제로 사용된 글리프만 유지합니다 [`CompressEmbeddedFonts`](../compressembeddedfonts).
* 그림 해상도를 150 DPI로 낮추고 잘린 영역을 삭제합니다 [`CompressImages`](../compressimages).

```csharp
public static void CompressPresentation(Presentation presentation)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| presentation | Presentation | 압축할 프레젠테이션입니다. |

### 예외

| 예외 | 조건 |
| --- | --- |
| ArgumentNullException | *presentation* 은 `null`입니다. |

### 참고

압축을 사용자 정의하려면, 예를 들어 다른 그림 해상도를 사용하거나 단계를 건너뛰려면 이 메서드 대신 위에 나열된 메서드를 개별적으로 호출하십시오. 그림의 잘린 영역은 영구적으로 제거되며 PowerPoint에서 복원할 수 없습니다.

### 예제

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    Aspose.Slides.LowCode.Compress.CompressPresentation(pres);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
