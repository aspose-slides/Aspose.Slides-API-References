## Compress.CompressImages 메서드

프레젠테이션의 그림 해상도를 낮추고 잘라낸 영역을 삭제합니다. 이는 PowerPoint의 "Compress Pictures"를 모든 그림에 적용한 것과 유사합니다. 슬라이드, 레이아웃 슬라이드 및 마스터 슬라이드의 그림이 처리되며, 그룹 도형 내부의 그림 및 도형의 그림 채우기도 포함됩니다.

```csharp
public static void CompressImages(IPresentation presentation, PicturesCompression resolution)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| presentation | IPresentation | 처리할 프레젠테이션입니다. |
| resolution | PicturesCompression | 각 그림이 표시되는 크기에 대한 상대적인 목표 해상도입니다. DocumentResolution은 그림을 변경하지 않습니다. |

### 예외

| 예외 | 조건 |
| --- | --- |
| ArgumentNullException | *presentation* is `null`. |

### 비고

목표 해상도와 같거나 낮은 그림은 변경되지 않으며, 그림이 확대되는 일은 없습니다.

처리되지 않음: 슬라이드 배경, 표 셀 채우기, 차트, SmartArt, GIF 이미지(애니메이션 유지), SVG 및 메타파일(EMF/WMF) 이미지.

잘라낸 영역은 영구적으로 제거되며 PowerPoint에서 복원할 수 없습니다.

### 예제

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    CompressImages(pres, PicturesCompression.Dpi150);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
