## DataLabel.Hide 메서드

Show*-flags(ShowValue, ...)를 모두 false 상태로 설정하여 데이터 레이블을 숨깁니다. 이 후 IsVisible는 false가 됩니다.

```csharp
public void Hide()
```

### 비고

데이터 레이블이 보이지 않는 경우(IsVisible가 false) Show*-flags(ShowValue, ...)를 true 상태로 설정하여 데이터 레이블을 표시할 수 있습니다.
