## ChartData.RefreshData 메서드

소스 워크북에서 다시 로드하여 차트 데이터를 새로 고칩니다.

```csharp
public void RefreshData()
```

### 예외

| 예외 | 조건 |
| --- | --- |
| InvalidOperationException | 워크북 형식이 지원되지 않거나, [`DataSourceType`](../datasourcetype)가 ExternalWorkbook이고 외부 워크북에 액세스하거나 로드할 수 없는 경우에 발생합니다. |

### 비고

차트가 외부 워크북을 사용하는 경우, 호출 시 워크북에 접근할 수 있어야 합니다.

### 예제

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
