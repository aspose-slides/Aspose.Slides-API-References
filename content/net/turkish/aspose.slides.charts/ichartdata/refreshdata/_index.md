## IChartData.RefreshData metodu

Kaynak çalışma kitabından yeniden yükleyerek grafik verilerini yeniler.

```csharp
public void RefreshData()
```

### İstisnalar

| istisna | koşul |
| --- | --- |
| InvalidOperationException | Çalışma kitabı biçimi desteklenmediğinde veya [`DataSourceType`](../datasourcetype) ExternalWorkbook olduğunda ve harici çalışma kitabına erişilemediğinde veya yüklenemediğinde fırlatılır. |

### Açıklamalar

Grafik harici bir çalışma kitabı kullanıyorsa, çalışma kitabı çağrı sırasında erişilebilir olmalıdır.

### Örnekler

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
