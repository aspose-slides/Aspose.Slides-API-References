## DataLabelCollection.DefaultLabelShapeType özelliği

Veri etiketleri için varsayılan şekil türünü alır veya ayarlar. Şekil tanımlı değilse NotDefined döndürür.

```csharp
public ShapeType DefaultLabelShapeType { get; set; }
```

### Açıklamalar

Bu özelliği ayarlamak, koleksiyondaki tüm veri etiketleri için [`LabelShapeType`](../../idatalabel/labelshapetype) özelliğini aynı değere ayarlar.

### Örnekler

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[1];
    var firstSeries = chart.ChartData.Series[0];

    // İlk serideki tüm veri etiketlerinin şekil türünü Ellipse olarak ayarlar.
    firstSeries.Labels.DefaultLabelShapeType = ShapeType.Ellipse;

    pres.Save("ChartWithEllipseLabels.pptx", SaveFormat.Pptx);
}
```
