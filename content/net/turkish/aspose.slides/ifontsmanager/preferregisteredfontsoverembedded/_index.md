## IFontsManager.PreferRegisteredFontsOverEmbedded özelliği

Aynı yazı tipi adı ve stili olan gömülü yazı tiplerine göre, kayıtlı yazı tiplerinin tercih edilip edilmeyeceğini belirtir. Etkinleştirildiğinde, eşleşen gömülü yazı tipleri dışa aktarım sırasında geçici olarak karşılık gelen kayıtlı yazı tipleriyle değiştirilir.

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### Açıklamalar

Varsayılan **false**.

### Örnekler

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
