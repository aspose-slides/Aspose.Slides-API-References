## IVideoFrame.VolumeValue özelliği

Videonun tam ses seviyesini yüzde olarak döndürür veya ayarlar. Değer, 0 ile 100 arasında bir yüzde olarak ifade edilir. Bu özelliği, [`Volume`](../volume) özelliği aracılığıyla kullanılabilen önceden tanımlı seviyelerden daha hassas ses düzeyi değerlerini okumak veya ayarlamak için kullanın. Okuma/Yazma Single.

```csharp
public float VolumeValue { get; set; }
```

### Örnekler

Örnek:

```csharp
[C#]
using (Presentation pres = new Presentation("video.pptx"))
{
    IVideoFrame videoFrame = (IVideoFrame)pres.Slides[0].Shapes[0];

    // Geçerli tam ses seviyesini okuyun ve %75.5 olarak ayarlayın.
    float currentVolume = videoFrame.VolumeValue;
    videoFrame.VolumeValue = 75.5f;

    pres.Save("video_with_volume.pptx", SaveFormat.Pptx);
}
```
