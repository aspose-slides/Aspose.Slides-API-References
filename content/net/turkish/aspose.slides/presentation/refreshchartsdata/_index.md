## Presentation.RefreshChartsData metod

Sunumdaki tüm grafiklerin verilerini kaynak çalışma kitaplarından yeniden yükler.

```csharp
public void RefreshChartsData(bool skipFailedCharts = true)
```

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| skipFailedCharts | Boolean | Bir grafiğin güncellenememesi durumunda yenileme sürecinin devam edip etmeyeceğini belirler. `true` ise, istisna oluşturan grafikler atlanır; aksi takdirde istisna yayılır. |

### Örnekler

```csharp
using (var presentation = new Presentation("PresentationWithCharts.pptx"))
{
    presentation.RefreshChartsData();
    presentation.Save("PresentationWithCharts-out.pptx", SaveFormat.Pptx);
}
```
