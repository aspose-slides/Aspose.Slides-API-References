## FontsManager.PreferRegisteredFontsOverEmbedded özellik

Kayıtlı yazı tiplerinin aynı yazı tipi adı ve stiline sahip gömülü yazı tiplerine göre tercih edilip edilmeyeceğini belirtir. Etkinleştirildiğinde, eşleşen gömülü yazı tipleri dışa aktarım sırasında geçici olarak ilgili kayıtlı yazı tipleriyle değiştirilir.

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### Açıklamalar

Varsayılan **false** değeridir.

### Örnekler

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
