### Örnekler

Aşağıdaki örnek, özel ayarlar kullanarak sunumları hareketli GIF'e dönüştürmeyi gösterir.

```csharp
[C#]
using (Presentation pres = new Presentation("pres.pptx"))
{
    pres.Save("pres.gif", SaveFormat.Gif, new GifOptions
    {
        FrameSize = new Size(960, 720), // oluşturulan GIF'in boyutu
        DefaultDelay = 2000, // her slaytın bir sonraki slayta geçmeden ne kadar süre gösterileceği
        TransitionFps = 35 // daha iyi geçiş animasyonu kalitesi için FPS'i artırın
    });
}
```
