## IFontsManager.PreferRegisteredFontsOverEmbedded ιδιότητα

Καθορίζει αν οι εγγεγραμμένες γραμματοσειρές πρέπει να προτιμώνται αντί των ενσωματωμένων γραμματοσειρών με το ίδιο όνομα και στυλ. Όταν ενεργοποιηθεί, οι αντίστοιχες ενσωματωμένες γραμματοσειρές αντικαθίστανται προσωρινά με τις αντίστοιχες εγγεγραμμένες γραμματοσειρές κατά την εξαγωγή.

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### Σχόλια

Η προεπιλογή είναι **false**.

### Παραδείγματα

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
